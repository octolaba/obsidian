# Star QMD

Vault search runs through the qmd command-line tool in BM25, vector or deep modes, the last combining query expansion with reranking. A sidebar or modal exposes per-scope commands, index and embedding status, history and suggestions when a query returns nothing. Results carry highlighted matches and can be previewed, opened or copied.
