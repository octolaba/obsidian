# Redact

Redacts the selected text through a command or shortcut, replacing characters while preserving control characters such as tabs and newlines. The redaction character is configurable, defaulting to a full block, and spaces and symbols can each be kept, redacted, or deleted.

```cue
plugin: {
    id:     "redact"
    name:   "Redact"
    author: "intelskya"
    repo:   "intelskya/obsidian-redact"

    html_url:    "https://community.obsidian.md/plugins/redact"
    github_url:  "https://github.com/intelskya/obsidian-redact"
    description: "Redact selected text with a command or shortcut. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Redact selected text with a configurable command that replaces characters while preserving control characters like tabs and newlines. Set a custom redaction character (default █) and choose how to handle spaces and symbols: keep, redact, or delete."
```
