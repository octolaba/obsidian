# Chord Lyrics

Chord Lyrics places chord names above lyrics inside chordlyrics blocks, detecting automatically which lines carry chords and highlighting them. Chords and lyrics wrap together so their alignment survives line breaks, section headers are shown, and lines can be marked by hand when the detection is not wanted. The colors are customizable.

```cue
plugin: {
    id:     "chord-lyrics"
    name:   "Chord Lyrics"
    author: "nevernotmove"
    repo:   "nevernotmove/obsidian-chordlyrics"

    html_url:    "https://community.obsidian.md/plugins/chord-lyrics"
    github_url:  "https://github.com/nevernotmove/obsidian-chordlyrics"
    description: "Display chord names over lyrics. Supports line wrapping, section headers and auto-detection."
    about:       "Display chords above lyrics in Markdown via chordlyrics blocks with automatic chord/lyric detection and chord highlighting. Wrap chords and lyrics responsively while keeping alignment, show section headers, mark lines manually with %c/%t, and customize colors."

    stats: {
        downloads:  5775
        updated_at: 1672503216000
    }
}
```
