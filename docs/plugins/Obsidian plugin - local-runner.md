# Local Runner

Starts local shell commands from Obsidian's right sidebar and shows their live stdout and stderr in per-command tabs. Several commands run concurrently, any running process can be stopped, and logs are monitored in real time; the recorded text names npm, npx, pytest and cargo as examples. The description is written in Chinese and this summary follows the English About text.
