# Luhman

Provides commands for handling a zettelkasten whose filenames are Luhmann-style IDs such as 12a56g. Child and sibling notes are created from the current one, using the selected text as the title or prompting for one. Notes can also be searched by their first Markdown H1 in order to open them or to insert a link.

```cue
plugin: {
    id:     "luhman"
    name:   "Luhman"
    author: "dyldog"
    repo:   "dyldog/luhman-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/luhman"
    github_url:  "https://github.com/dyldog/luhman-obsidian-plugin"
    description: "Commands for handling a zettelkasten with Luhman-style IDs as filenames."
    about:       "Create child and sibling notes using Luhmann-style ID filenames (e.g., 12a56g), using selected text as the title or prompting for one. Search notes by their first Markdown H1 to open them or insert links to the file."

    stats: {
        downloads:  17626
        updated_at: 1684280976000
    }
}
```
