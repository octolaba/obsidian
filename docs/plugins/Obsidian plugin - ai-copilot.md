# AI Copilot

AI Copilot chats with notes, a selection or the entire vault in a context-aware sidebar with multi-session tabs, project scoping, mentions and web search. Selected text can be summarized, rewritten, expanded, simplified or continued. It connects to OpenAI, Anthropic, Gemini, Groq or local Ollama models and extends through MCP servers and custom skills.
