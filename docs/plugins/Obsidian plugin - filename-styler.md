# FileName Styler

FileName Styler changes how file names appear in the file explorer while the names on disk stay as they are, hiding timestamp IDs through predefined timestamp patterns or custom regular expressions. Prefixes, suffixes, colors and emoji icons are added on top. Styles are restricted to folders, and several profiles can be combined.

```cue
plugin: {
    id:     "filename-styler"
    name:   "FileName Styler"
    author: "marc-f"
    repo:   "marc-f/obsidian-file-name-styler"

    html_url:    "https://community.obsidian.md/plugins/filename-styler"
    github_url:  "https://github.com/marc-f/obsidian-file-name-styler"
    description: "Customize and style file names in the file explorer using patterns, prefixes, suffixes, colors, and icons."
    about:       "Hide timestamp IDs and style file names in the sidebar using predefined timestamp patterns or custom regular expressions. Add prefixes, suffixes, colors, and emoji icons; restrict styles to folders and combine multiple profiles while keeping original filenames on disk."

    stats: {
        downloads:  2569
        updated_at: 1745482050000
    }
}
```
