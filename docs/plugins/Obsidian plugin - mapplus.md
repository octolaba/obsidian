# MapPlus

MapPlus adds a customizable map layout inside Obsidian Bases that is built to stay responsive on large vaults and shows thumbnails for locations. Coordinates are read from note frontmatter or base properties. It adds a tag hierarchy with prioritization, timeline filtering by date with grouping and a date slider, and optional search geocoding.
