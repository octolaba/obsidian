# Markmap to CSV

Markmap to CSV converts markmap-style Markdown into CSV. Headings are parsed up to level two, and the lists under each second-level heading become CSV rows ready for import into a spreadsheet.

```cue
plugin: {
    id:     "markmap-to-csv"
    name:   "Markmap to CSV"
    author: "pj4316"
    repo:   "pj4316/markmap-to-csv-obsidian"

    html_url:    "https://community.obsidian.md/plugins/markmap-to-csv"
    github_url:  "https://github.com/pj4316/markmap-to-csv-obsidian"
```
