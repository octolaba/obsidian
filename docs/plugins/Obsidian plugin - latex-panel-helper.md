# LaTeX Panel Helper

LaTeX Panel Helper provides a panel of LaTeX symbols grouped by category with real-time search, inserting a symbol or snippet at the cursor with automatic spacing and returning focus to the editor. The symbol library is edited as JSON, and the panel is docked in the sidebar or popped out into a floating window, with the interface following English or Chinese.

    id:     "latex-panel-helper"
    name:   "LaTeX Panel Helper"
