# Arcadia Hub

Browses GitHub repositories, issues, pull requests and Actions from an Obsidian sidebar. Issues can be created from the current note with title and body pre-filled, CI status monitored, and repositories switched without leaving Obsidian. NotebookLM sync and a Claude Code bridge are offered as premium extras.

```cue
plugin: {
    id:     "arcadia-hub"
    name:   "Arcadia Hub"
    author: "arcadia-studio"
    repo:   "arcadia-studio/obsidian-arcadia-hub"

    html_url:    "https://community.obsidian.md/plugins/arcadia-hub"
    github_url:  "https://github.com/arcadia-studio/obsidian-arcadia-hub"
    description: "GitHub integration: browse issues, pull requests, and repos from your notes. Create issues directly from note content. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Browse GitHub repos, issues, pull requests, and Actions from an Obsidian sidebar. Create issues from the current note (title and body pre-filled), monitor CI/Actions status, and switch repositories without leaving Obsidian. Enable premium AI extras like NotebookLM sync and a Claude Code bridge."

    stats: {
        downloads:  89
        updated_at: 1781119970000
    }
}
```
