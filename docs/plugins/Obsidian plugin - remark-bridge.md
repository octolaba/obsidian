# reMark Bridge

Pushes the active note to a reMarkable tablet with a single command, over HTTP to a locally hosted reMark Bridge, so the data stays on the user's own infrastructure. The status bar displays live sync status and failures raise explicit error notices.

```cue
plugin: {
    id:     "remark-bridge"
    name:   "reMark Bridge"
    author: "bggbtac"
    repo:   "bggbtac/obsidian-remark-bridge"

    html_url:    "https://community.obsidian.md/plugins/remark-bridge"
    github_url:  "https://github.com/bggbtac/obsidian-remark-bridge"
    description: "Push notes to a reMarkable tablet and monitor your reMark Bridge sync status. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Push the active Obsidian note to your reMarkable tablet with a single command. Display live reMark Bridge sync status in the status bar, surface clear error notices on failures, and connect over HTTP to a locally hosted reMark Bridge so data stays on your infrastructure."
```
