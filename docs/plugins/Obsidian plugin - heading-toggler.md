# Heading Toggler

Heading Toggler converts normal text into headings from H1 to H6 and back without typing # characters. Commands that increase, decrease or toggle the heading level can be bound to hotkeys.

```cue
plugin: {
    id:     "heading-toggler"
    name:   "Heading Toggler"
    author: "lord-turmoil"
    repo:   "lord-turmoil/heading-toggler-obsidian"

    html_url:    "https://community.obsidian.md/plugins/heading-toggler"
    github_url:  "https://github.com/lord-turmoil/heading-toggler-obsidian"
    description: "Easily toggle heading levels in Markdown documents with shortcuts."
    about:       "Toggle heading levels quickly without typing # characters, converting normal text to H1–H6 and back. Bind commands to hotkeys to increase, decrease, or toggle heading levels."

    stats: {
        downloads:  831

}
```
