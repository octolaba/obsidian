# Bookmarks Caller

Bookmarks Caller opens bookmarks from a keyboard-first modal that searches and launches files, folders, searches, graphs, headings, blocks or URLs. Items are opened with one-letter keys, arrow selection or clicks, and an entire bookmark group can be opened in a single action.
