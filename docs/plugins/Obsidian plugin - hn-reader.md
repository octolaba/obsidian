# HN Reader

HN Reader browses the Hacker News Top, New, Best, Ask HN and Show HN feeds inside Obsidian, in a sidebar panel or a new tab. A story is saved with one click to a reading-list note or to the daily note, with tags and YAML frontmatter appended automatically. How many stories are loaded is configurable.

```cue
plugin: {
    id:     "hn-reader"
    name:   "HN Reader"
    author: "Anton Liberant"
    repo:   "anliberant/hn-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/hn-reader"
    github_url:  "https://github.com/anliberant/hn-obsidian-plugin"
    description: "Browse top Hacker News stories and save them to your reading list - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Browse Hacker News Top, New, Best, Ask HN, and Show HN feeds inside Obsidian and open them in a sidebar panel or a new tab. Save stories to a reading-list note or a daily note with one click, auto-append tags and YAML frontmatter, and choose how many stories to load."

    stats: {
        downloads:  79
        updated_at: 1780228226000
    }
}
```
