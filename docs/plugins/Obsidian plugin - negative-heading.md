# Negative Heading

Renders Discord-style lines that begin with a minus and a hash as compact, muted subheadings in Reading View, Live Preview and Source Mode. A command toggles that marker, inline Markdown formatting is kept while the token itself is dimmed, list items are supported, and code, math and inline code are skipped.

```cue
plugin: {
    id:     "negative-heading"
    name:   "Negative Heading"
    author: "cyne-wulf"
    repo:   "cyne-wulf/obsidian-negative-heading"

    html_url:    "https://community.obsidian.md/plugins/negative-heading"
    github_url:  "https://github.com/cyne-wulf/obsidian-negative-heading"
    description: "Render Discord-style \"-#\" lines as compact headings in reading view and the editor."
    about:       "Render Discord-style -# lines as compact, muted subheadings in Reading View, Live Preview, and Source Mode. Toggle -# with a smart command, keep inline Markdown formatting while dimming the -# token, skip code/math/inline code, and support list items."

}
```
