# Timeline Schedule

Timeline Schedule generates inline timelines from human-readable time strings written inside a schedule codeblock, turning entries such as walking the dog for 30min into timed events. An autofill mode prepends time blocks with Start and Finish markers, while a pretty preview renders the schedule from a start line or from the current time.

```cue
plugin: {
    id:     "timeline-schedule"
    name:   "Timeline Schedule"
    author: "ebonsignori"
    repo:   "ebonsignori/obsidian-timeline-schedule"

    html_url:    "https://community.obsidian.md/plugins/timeline-schedule"
    github_url:  "https://github.com/ebonsignori/obsidian-timeline-schedule"
    description: "Inline timelines generated from human-readable time strings, e.g. 'Walk dog (30min)' in a ```schedule codeblock."
    about:       "Generate inline timelines from human-readable time strings inside a schedule codeblock, converting entries like \"Walk dog (30min)\" into timed events. Use autofill to prepend time blocks with [Start] and [Finish], or use pretty preview to render schedules from a start line or the current time."
