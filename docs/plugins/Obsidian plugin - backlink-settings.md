# Backlink Settings

Backlink Settings saves defaults for the backlinks, or Linked mentions, pane at the bottom of a note: sort order, collapse state and whether more context is shown. Those defaults are applied each time a note opens, so the pane is displayed consistently.

```cue
plugin: {
    id:     "backlink-settings"
    name:   "Backlink Settings"
    author: "calvinwyoung"
    repo:   "calvinwyoung/obsidian-backlink-settings"

    html_url:    "https://community.obsidian.md/plugins/backlink-settings"
    github_url:  "https://github.com/calvinwyoung/obsidian-backlink-settings"
    description: "Allow saving default settings for the backlinks / \"Linked mentions\" pane at the bottom of notes."
    about:       "Save default settings for the backlinks (Linked mentions) pane — set preferred sort order, collapse state, and whether to show more context. Apply those defaults automatically each time a note opens for consistent backlink displays."

    stats: {
        downloads:  2355

}
```
