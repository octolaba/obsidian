# Mehrmaid

Renders Obsidian Markdown inside Mermaid node labels when the node content is wrapped in double quotes. Images, LaTeX math, tables, external links and internal Obsidian links appear inside graph nodes while node sizing is preserved. Diagrams otherwise follow standard Mermaid graph syntax.

```cue
plugin: {
    id:     "mehrmaid"
    name:   "Mehrmaid"
    author: "huterguier"
    repo:   "huterguier/obsidian-mehrmaid"

    html_url:    "https://community.obsidian.md/plugins/mehrmaid"
    github_url:  "https://github.com/huterguier/obsidian-mehrmaid"
    description: "Enables you to put Markdown inside of Mermaid diagrams."
    about:       "Render Obsidian Markdown inside Mermaid node labels by wrapping node content in double quotes. Display images, LaTeX math, tables, external links and internal Obsidian links directly inside graph nodes while preserving node sizing. Follow standard Mermaid graph syntax."

    stats: {
        downloads:  38182
        updated_at: 1713867308000
    }
}
```
