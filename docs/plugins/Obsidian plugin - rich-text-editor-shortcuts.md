# Rich Text Editor Shortcuts

Rich Text Editor Shortcuts adds Notion-style keyboard shortcuts for inline formatting. Unchecked and checked checkboxes are created by typing a bracket sequence followed by a space, and checkboxes toggle with Mod-Shift-Enter. A clipboard URL wraps the current selection as a link with Mod-V, local vault links are created with Mod-Shift-K, and underline toggles with Mod-U.
