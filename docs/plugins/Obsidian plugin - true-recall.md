# True Recall

Provides an Anki-like flashcard system inside Obsidian, reviewing cards with FSRS spaced repetition so scheduling adapts to recall. Cards are written inline or generated from selected text with AI, and the data lives in a portable SQLite database. Projects, queries and a browser organise the collection, Anki import and export are supported, and dashboards and widgets track progress.
