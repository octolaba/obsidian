# Mnemoloop

Mnemoloop handles local-first spaced repetition with FSRS scheduling and, by design, never writes into the notes being studied. Each flashcard is stored as its own Markdown file, which its recorded text says keeps source notes pristine and git-friendly. Cards are detected as stale when their sources change, and a responsive dashboard supports study on desktop and mobile.

```cue
plugin: {
    id:     "mnemoloop"
    name:   "Mnemoloop"
    author: "Marco Pozzecco"
    repo:   "marco-pozzecco/mnemoloop-plugin"

    html_url:    "https://community.obsidian.md/plugins/mnemoloop"
    github_url:  "https://github.com/marco-pozzecco/mnemoloop-plugin"
    description: "Local-first spaced repetition with FSRS scheduling that never touches your notes. Better retention without note pollution. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Manage spaced repetition with FSRS scheduling directly inside Obsidian. Store each flashcard as its own Markdown file to keep source notes pristine and git-friendly. Detect stale cards when sources change and study on desktop or mobile with a responsive dashboard."

    stats: {
        downloads:  264
        updated_at: 1783343491000
    }
}
```
