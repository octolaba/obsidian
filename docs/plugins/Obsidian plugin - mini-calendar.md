# Mini Calendar

Mini Calendar shows a compact one-week calendar directly under the File Explorer while the folder tree above stays scrollable. Weeks can be navigated, today reached in one step, and clicking a date opens or creates the Daily Note, with dots marking existing notes and unfinished tasks. The Daily Notes folder, filename format and templates are respected.
