# Opal Companion

Opal Companion is a visual picker for the per-note options of the Opal theme. Page states, accent recolours, layout, callouts, coloured highlights, task states and image layouts are applied with one click, and each is previewed before it is applied.

```cue
plugin: {
    id:     "opal-companion"
    name:   "Opal Companion"
    author: "Cyrius Weng"
    repo:   "cyriusweng/opal-companion"

    html_url:    "https://community.obsidian.md/plugins/opal-companion"
    github_url:  "https://github.com/cyriusweng/opal-companion"
    description: "Companion for the Opal theme: a visual picker for per-note page states, accent recolour, layout, callouts, coloured highlights, task states and image layouts — preview each before you apply it. - This plugin has not been manually reviewed by Obsidian staff."

    }
}
```
