# Headless Mode

Headless Mode hides every Obsidian window and removes the macOS Dock icon while the application keeps running from a menu bar or tray icon. Headless is toggled from the tray menu or the command palette, or entered at launch, and it holds until it is unchecked. The recorded purpose is to let syncs, automations and vault-watching plugins run without Dock or window clutter.
