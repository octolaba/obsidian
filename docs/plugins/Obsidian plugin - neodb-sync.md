# NeoDB Sync

Syncs NeoDB collection data into notes, covering shelf items such as wishlist, progress, complete and dropped, as well as collections, notes and reviews. Templates are customizable and a custom NeoDB domain can be set. NeoDB-exported JSON can also be imported, and the note format and storage location are controlled from the settings.
