# Hedgesync

Hedgesync links an Obsidian note to a HedgeDoc document through a frontmatter key and keeps the two in step. Linked documents are pushed, pulled and opened, with optional auto-push or live sync for the active note. HedgeDoc documents can be created from notes and notes from HedgeDoc URLs or identifiers, and a vault-wide pull preserves frontmatter.

```cue
plugin: {
    id:     "hedgesync"
    name:   "Hedgesync"
    author: "tionis"
    repo:   "tionis/obsidian-hedgesync"

    html_url:    "https://community.obsidian.md/plugins/hedgesync"
    github_url:  "https://github.com/tionis/obsidian-hedgesync"
    description: "Sync notes with HedgeDoc documents using frontmatter links and hedgesync. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync Obsidian Markdown notes with HedgeDoc using a frontmatter key to map each note to a HedgeDoc document. Push, pull, and open linked documents; enable optional auto-push or true live sync for the active note; create HedgeDoc docs from notes or notes from HedgeDoc URLs/IDs; run a vault-wide pull while preserving frontmatter."
```
