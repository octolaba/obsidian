# downloadPDF

Downloads every PDF linked from the notes and stores each file in the parent folder of the note that links to it. The downloadPDF command in the command palette starts the fetch.

```cue
plugin: {
    id:     "downloadpdf"
    name:   "downloadPDF"
    author: "frieda21"
    repo:   "frieda21/downloadPDF"

    html_url:    "https://community.obsidian.md/plugins/downloadpdf"
    github_url:  "https://github.com/frieda21/downloadPDF"
    description: "Allows you to download all included PDF files."
    about:       "Download all PDFs linked across your notes and save each into the parent folder of its linking file. Invoke the downloadPDF command from the command palette to fetch and store PDFs locally."

    stats: {
        downloads:  1188
        updated_at: 1730736389000
    }
}
```
