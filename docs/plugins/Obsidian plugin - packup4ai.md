# packUp4AI

Collects notes linked from the open file, and optionally those linking back to it, across several hops to assemble a focused context bundle for external AI chatbots. Relationships are shown in an interactive graph sized by word count alongside statistics, and the bundle can be exported to the clipboard or to Markdown.
