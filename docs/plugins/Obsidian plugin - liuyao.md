# Liuyao

Renders Liuyao hexagram diagrams from fenced code blocks, taking a six-digit code or trigram names and an optional date. When a date is present the six gods are shown, and the diagram also carries the family and hexagram name, relation text on each line, and the world or response markers where they apply.

```cue
plugin: {
    id:     "liuyao"
    name:   "Liuyao"
    author: "Kasukabe Tsumugi"
    repo:   "baendlorel/obsidian-liuyao"

    html_url:    "https://community.obsidian.md/plugins/liuyao"
    github_url:  "https://github.com/baendlorel/obsidian-liuyao"
    description: "Render Liuyao hexagrams from fenced code blocks. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render six-line liuyao divination diagrams from fenced liuyao blocks using a six-digit code or trigram names and an optional date. Show six gods when a date is present, display family and hexagram name, annotate each line with relation text, and mark 世 or 应 when applicable."

    stats: {
        downloads:  155
        updated_at: 1782957647000
    }
}
```
