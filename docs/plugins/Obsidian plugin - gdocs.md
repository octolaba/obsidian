# GDocs

Opens and embeds Google Drive shortcut files such as gdoc, gsheet, gslides, gdraw and gform documents in a Web View. Those extensions are registered in the file explorer, and the linked Google URL is opened in a Web View tab or in the system browser.

```cue
plugin: {
    id:     "gdocs"
    name:   "GDocs"
    author: "Olivier Rouiller"
    repo:   "oilandrust/obsidian-gdocs"

    html_url:    "https://community.obsidian.md/plugins/gdocs"
    github_url:  "https://github.com/oilandrust/obsidian-gdocs"
    description: "Open and Embed Google Drive shortcut files (.gdoc, .gsheet, etc.) in a Web View. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open and embed Google Drive shortcut files (.gdoc, .gsheet, .gslides, .gdraw, .gform, etc.) directly in Web View. Register those extensions in the file explorer and launch the linked Google URL in a Web View tab or your system browser."

    stats: {
        downloads:  651
        updated_at: 1782039318000
    }
}
```
