# Move Files

Moves the files linked from an open note, such as images and PDFs, into a new folder named after that note, and updates the links in the note to their new locations. The open note itself can be moved as well, and the original folder structure can be preserved inside the new asset folder.

```cue
plugin: {
    id:     "move-files"
    name:   "Move Files"
    author: "nitishkhurana"
    repo:   "nitishkhurana/obsidian-move-files-plugin"

    html_url:    "https://community.obsidian.md/plugins/move-files"
    github_url:  "https://github.com/nitishkhurana/obsidian-move-files-plugin"
    description: "Moves all the files linked to a open md file to a folder and updates the link in md file."
    about:       "Move linked files (images, PDFs, JPGs, etc.) into a new folder named \"{note name} files\" and automatically update links in the note to their new locations. Choose to also move the open note and preserve the original folder structure when creating the asset folder."

    stats: {
        downloads:  1371
        updated_at: 1772527923000
    }
}
```
