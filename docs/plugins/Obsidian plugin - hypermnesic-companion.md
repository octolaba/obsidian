# Hypermnesic Companion

Hypermnesic Companion surfaces related notes and an interrogable reinvention nudge from a tailnet hypermnesic index while writing, triggered when typing pauses. A status-bar popover, an optional sidebar and a dockable thinking panel offer navigable related notes, Socratic prompts, selection recall and forgetting-curve ranking. It is read-only and states that it never writes to the vault.
