# Pinax

Pinax builds config-driven dashboards over an existing vault from a single profile JSON file that hot-reloads as it is edited. Widgets for folder lists, tables, boards, heatmaps, stats, iframes and custom content read and rewrite frontmatter, refresh automatically and offer undoable actions. The recorded inputs describe the dashboards as domain-agnostic and buildable by an LLM.
