# Folder notes

Creates a note inside a folder that opens when the folder name is clicked, so the folder is read without collapsing it, in the way Notion offers. Notes can be created for every existing folder and opened by path. Templates are applied to them, including through Templater.

```cue
plugin: {
    id:     "folder-notes"
    name:   "Folder notes"
    author: "lostpaul"
    repo:   "lostpaul/obsidian-folder-notes"

    html_url:    "https://community.obsidian.md/plugins/folder-notes"
    github_url:  "https://github.com/lostpaul/obsidian-folder-notes"
    description: "Create notes within folders that can be accessed without collapsing the folder, similar to the functionality offered in Notion."
    about:       "Attach notes to folders and open them by clicking a folder name, mirroring Notion-style folder pages. Create notes for every existing folder, open folder notes via path, and apply templates with Templater support for consistent folder pages."

    stats: {
        downloads:  380451
        updated_at: 1780646869000
    }
}
```
