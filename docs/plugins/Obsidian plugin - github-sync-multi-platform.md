# GitHub Sync (Multi-Platform)

Syncs notes across desktop and mobile through the GitHub REST API, so no local Git client is needed. Sync is event-driven with a five-second debounce, conflicts are resolved by hash comparison, private repositories and binary files up to ten megabytes are supported, and a web dashboard reports sync statistics.
