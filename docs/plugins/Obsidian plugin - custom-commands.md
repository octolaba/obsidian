# Custom Commands

Creates custom commands that open a specific note, create a note from an optional template, insert a text snippet, or chain several commands into a sequence, each runnable from the command palette or a hotkey. Commands can carry dynamic date and time placeholders, and a note can be opened in the current tab, a new tab or a new window.

```cue
plugin: {
    id:     "custom-commands"
    name:   "Custom Commands"
    author: "staaaaaaaaaan"
    repo:   "staaaaaaaaaan/obsidian-custom-commands"

    html_url:    "https://community.obsidian.md/plugins/custom-commands"
    github_url:  "https://github.com/staaaaaaaaaan/obsidian-custom-commands"
    description: "Create custom commands to be executed in the command palette, and by hotkey. Currently supports opening specific notes, creating notes, inserting snippets, and executing sequences of commands."
    about:       "Create personalized commands to open specific notes, create new notes with optional templates, insert text snippets, or chain multiple commands into sequences. Include dynamic date/time placeholders and choose whether notes open in the current tab, a new tab, or a new window."

    stats: {
        downloads:  1831
        updated_at: 1774373369000
    }
}
```
