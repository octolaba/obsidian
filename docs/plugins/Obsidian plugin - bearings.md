# Bearings

Bearings builds collapsible tree views of a vault's structure whose scope changes dynamically as you move through it. Hierarchical relationships such as parents and children and coordinate ones such as references and associations are reconstructed from the links listed under configured YAML frontmatter property keys.

```cue
plugin: {
    id:     "bearings"
    name:   "Bearings"
    author: "jeetsukumaran"
    repo:   "jeetsukumaran/obsidian-bearings"

    html_url:    "https://community.obsidian.md/plugins/bearings"
    github_url:  "https://github.com/jeetsukumaran/obsidian-bearings"
    description: "Flow through dynamically-scoped collapsible tree views of your vault's semantic and logical architectures."
    about:       "Navigate your note graph with dynamically scoped, expanding tree views driven by YAML frontmatter property keys. Map hierarchical (parents/children) and coordinate (references/associations) relationships by following links listed under those property names."

    stats: {
        downloads:  2371
        updated_at: 1727907645000
    }
}
```
