# Illuminator

Illuminator makes white backgrounds transparent and converts images to WebP when they are pasted or through an image's right-click menu, updating the image link in the note. Processing runs entirely locally in a Web Worker. Its recorded inputs note that the original file is overwritten, so backups are advised, and that the plugin is intended for light-themed vaults.

```cue
plugin: {
    id:     "illuminator"
    name:   "Illuminator"
    author: "tiezjin"
    repo:   "tiezjin/illuminator"

    html_url:    "https://community.obsidian.md/plugins/illuminator"
    github_url:  "https://github.com/tiezjin/illuminator"
    description: "Automatically removes white backgrounds from images on paste and converts them to optimized WebP. Perfect for maintaining legibility and visual harmony in light-themed vaults. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Make white backgrounds transparent and convert images into compact WebP when you paste or right-click an image, auto-updating the image link in your notes. Process images entirely locally in a Web Worker for privacy; changes overwrite the original file, so keep backups and prefer use in Light Mode."

    stats: {
        downloads:  173
        updated_at: 1779067727000
    }
}
```
