# Extract Highlights to Note

Extract Highlights to Note creates a note containing only the highlighted passages (==...==) of the active note, preserving timestamps where they are present. The result is saved to a selected folder and the original note can optionally be deleted. It works on mobile, desktop and remote vaults.

```cue
plugin: {
    id:     "extract-highlights"
    name:   "Extract Highlights to Note"
    author: "DevidCode"
    repo:   "devidcode/obsidian-extract-highlights"

    html_url:    "https://community.obsidian.md/plugins/extract-highlights"
    github_url:  "https://github.com/devidcode/obsidian-extract-highlights"
    description: "Creates a clean note containing only the highlighted passages (==...==) of the active note. Works on mobile, desktop and remote. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create a new note containing only highlights (==...==) from the active note, preserving timestamps when present. Choose to delete the original and save the result to a selected folder; works on mobile and desktop."

    stats: {
        downloads:  134
        updated_at: 1782585879000
    }
}
```
