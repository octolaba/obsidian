# Giphy

Searches Giphy and inserts animated GIFs into a note, either by keyword search or through a random-GIF command. Results are browsed in a modal, where a GIF can be previewed before it is inserted.

```cue
plugin: {
    id:     "giphy"
    name:   "Giphy"
    author: "lucjager"
    repo:   "lucjager/giphy-plugin"

    html_url:    "https://community.obsidian.md/plugins/giphy"
    github_url:  "https://github.com/lucjager/giphy-plugin"
    description: "Search and insert gifs in a note."
    about:       "Search and insert animated GIFs from Giphy directly into notes using keyword search or a random-GIF command. Preview GIFs before insertion and browse results in a modal."

    stats: {
        downloads:  2488
        updated_at: 1721111035000
    }
}
```
