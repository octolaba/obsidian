# Codex Workflow

Codex Workflow launches the Codex CLI from the current vault through a ribbon icon, a command, or a compact launcher in the right sidebar. The terminal opens in the vault directory and receives a configurable startup prompt, which can interpolate the vault path and the active file path.

```cue
plugin: {
    id:     "codex-workflow"
    name:   "Codex Workflow"
    author: "yifu-tian"
    repo:   "yifu-tian/obsidian-codex-workflow"

    html_url:    "https://community.obsidian.md/plugins/codex-workflow"
    github_url:  "https://github.com/yifu-tian/obsidian-codex-workflow"
    description: "Use Codex to manage your personal knowledge base. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Launch Codex CLI from the current vault using a ribbon icon, command, or compact right‑sidebar launcher. Open your terminal in the vault directory and pass a configurable startup prompt (supports {{vaultPath}} and {{activeFilePath}}) to Codex."

    stats: {
        downloads:  179
        updated_at: 1777284028000
    }
}
```
