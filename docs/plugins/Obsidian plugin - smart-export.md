# Smart Export

Smart Export follows wikilinks from a root note to a configurable depth and joins the resulting note tree into a single export. The output is XML, print-friendly Markdown, or a customizable Markdown template formatted for both human readers and language models. Link direction, content and title depth, and excluded folders, tags or properties are configurable, links can be rewritten as Obsidian heading links, and the export goes to the clipboard or a new note with a token estimate.
