# Slides Extended Mobile Preview

Slides Extended Mobile Preview renders the active Markdown note as a Reveal.js slide deck in a view meant for Obsidian Mobile. It supports horizontal and vertical slide separators, speaker notes, slide backgrounds including wikilink images, a theme set from frontmatter, and bundled Reveal themes. Navigation is by touch or by the previous and next controls at the bottom.
