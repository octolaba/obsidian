# External Links

External Links lists the external links of a note in the right side panel. For each URL it also shows which notes in the vault link to it, and those notes can be opened directly from the list. External references across the vault can therefore be audited from one place.

```cue
plugin: {
    id:     "external-links"
    name:   "External Links"
    author: "jivimberg"
    repo:   "jivimberg/external-links"

    html_url:    "https://community.obsidian.md/plugins/external-links"
    github_url:  "https://github.com/jivimberg/external-links"
    description: "List external links on the right side panel."
    about:       "List all external links in a note and show which notes in your vault link to each URL. Navigate directly to linking notes and audit external references across your vault."

    stats: {
        downloads:  3071
        updated_at: 1732910403000
    }
}
```
