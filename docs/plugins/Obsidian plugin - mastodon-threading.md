# Mastodon Threading

Mastodon Threading composes and posts threads to Mastodon from within Obsidian, assembling snippets, images and other media into ordered replies. Separators are inserted between fragments, and the order and length of each fragment are shown while composing. Media descriptions can be added for accessibility, and either a single post or a whole thread is submitted while server limits and visibility are checked.

```cue
plugin: {
    id:     "mastodon-threading"
    name:   "Mastodon Threading"
    author: "elpamplina"
    repo:   "elpamplina/mastodon-threading"

    html_url:    "https://community.obsidian.md/plugins/mastodon-threading"
    github_url:  "https://github.com/elpamplina/mastodon-threading"
    description: "Compose and post threads to Mastodon."
    about:       "Compose and post Mastodon threads from Obsidian, assembling snippets, images and media into ordered replies. Insert separators, visualize fragment order and length, add media descriptions for accessibility, and submit single posts or entire threads while checking server limits and visibility."
```
