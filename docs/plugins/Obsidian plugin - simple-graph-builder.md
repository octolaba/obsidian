# Simple Graph Builder

Simple Graph Builder extracts entities from notes with an LLM and assembles them into a knowledge graph, using ten fixed entity types, free-form relationship verbs and detail fields. It records support for Claude, OpenAI, Gemini and Ollama, and adds hybrid entity resolution together with wikilink processing. The resulting graph is explored through an interactive graph view and queried with AI natural-language search.
