# Canvas Presentation

Canvas Presentation displays canvas cards as a slide sequence, with cards marked by slide numbers to define the presentation order. That sequence is stored in a control card, and Next and Previous navigate through the slideshow.

```cue
plugin: {
    id:     "canvas-presentation"
    name:   "Canvas Presentation"
    author: "quorafind"
    repo:   "quorafind/Obsidian-Canvas-Presentation"

    html_url:    "https://community.obsidian.md/plugins/canvas-presentation"
    github_url:  "https://github.com/quorafind/Obsidian-Canvas-Presentation"
    description: "Display cards based on sequence."
    about:       "Create slide sequences on Canvas by marking cards with slide numbers to define presentation order. Store the sequence in a control card and navigate slides with Next or Previous to run the slideshow."
```
