# 13th Age Statblocks

The plugin renders 13th Age statblocks inline in a note. It ships SRD content that monsters can be based on and formats stats, attacks, defenses and quick-reference details for game preparation.

```cue
plugin: {
    id:     "13th-age-statblocks"
    name:   "13th Age Statblocks"
    author: "ben"
    repo:   "ben/obsidian-13th-age-statblocks"

    html_url:    "https://community.obsidian.md/plugins/13th-age-statblocks"
    github_url:  "https://github.com/ben/obsidian-13th-age-statblocks"
    description: "Render 13th Age statblocks."
    about:       "Render 13th Age statblocks inline and draw on included SRD content to base your monsters. Create clean, formatted monster entries showing stats, attacks, defenses, and quick-reference details for game prep."

    stats: {
        downloads:  4668
        updated_at: 1709754303000
    }
}
```
