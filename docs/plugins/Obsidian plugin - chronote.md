# Chronote

Chronote turns notes into a spaced-repetition study tool, scoring each note per review and scheduling the next one, with the review state kept in the note's frontmatter. Study sessions can be linked to Google Calendar, and a multi-provider AI agent generates flashcards and quizzes, plans study blocks and searches the vault.
