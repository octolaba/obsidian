# Fullscreen Image

Opens an image in a lightbox that fits it to the available viewport and either covers the full window or stays inside the active pane. Zooming works with buttons, the mouse wheel, pinch or a double-click, and panning is available when zoomed. The recorded text states that everything stays local, with no note edits, telemetry or network requests.
