# Life Calendar

Life Calendar draws a life-in-weeks, or memento mori, calendar with one row of 52 squares per year showing completed weeks, the current week and the weeks remaining to a planning horizon. Planning phases and categories can be added and filtered, and dated event markers taken from notes or from inline configuration open the linked event note.

    id:     "life-calendar"
    name:   "Life Calendar"
