# Simple Checklist

Simple Checklist gathers every open todo across the vault into one side panel, grouped by source file and sorted by last modified. Clicking an entry jumps to its line, checking it marks the task done in the file with a small confetti burst, and entries can be deleted from the panel. Wiki and Markdown links render inline, and the panel updates live as notes are edited.
