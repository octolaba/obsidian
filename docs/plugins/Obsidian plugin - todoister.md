# Todoister

Todoister syncs the todos of the active file to Todoist and back, keeping Obsidian markdown tasks and Todoist tasks aligned in both directions. Existing Todoist tasks are imported by pasting their task URLs, and the synchronized lists stay consistent across desktop and mobile.

```cue
plugin: {
    id:     "todoister"
    name:   "Todoister"
    author: "erblack"
    repo:   "erblack/obsidian-todoister"

    html_url:    "https://community.obsidian.md/plugins/todoister"
    github_url:  "https://github.com/erblack/obsidian-todoister"

    about:       "Sync todos from the active note to Todoist and back with two-way synchronization between Obsidian markdown tasks and Todoist. Import existing Todoist tasks by pasting task URLs and keep lists synchronized across desktop and mobile."
```
