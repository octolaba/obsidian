# Extract Highlights

Extract Highlights copies the highlights of the current Markdown note to the clipboard as a bullet list, recognizing the double equals, double asterisk and mark tag delimiters. The note title can be included or hidden, footnote links back to the source file can be added, and highlights can be turned into Obsidian links to form an ad-hoc MOC. Entries can also be auto-capitalized for consistency.

```cue
plugin: {
    id:     "extract-highlights-plugin"
    name:   "Extract Highlights"
    author: "akaalias"
    repo:   "akaalias/extract-highlights-plugin"

    html_url:    "https://community.obsidian.md/plugins/extract-highlights-plugin"
    github_url:  "https://github.com/akaalias/extract-highlights-plugin"
    description: "Extract all ==highlights== in a note into your clipboard."
    about:       "Create and extract highlights from the current Markdown note to your clipboard as a bullet list, recognizing ==, ** and <mark></mark> highlight delimiters. Include or hide the note title, add footnote links back to source files, convert highlights into Obsidian links for an ad‑hoc MOC, and auto‑capitalize entries for consistency."

    stats: {
        downloads:  23499
        updated_at: 1614247342000
    }
}
```
