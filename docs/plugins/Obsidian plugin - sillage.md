# Sillage

Sillage runs the Mistral Vibe CLI from Obsidian on desktop, adding a streamed chat sidebar with stop, copy and insert controls, persistent resumable sessions, and per-turn cost and duration telemetry. Note commands summarize, extract action items in Tasks format, rewrite or translate a selection, and local skill files register themselves as commands.
