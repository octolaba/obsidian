# AnyBlock

Takes any Markdown fragment, a list, heading, table, quote, code block or container, as a block and renders it as something else: tables, tabs, cards, columns, mindmaps, markmap, mermaid or PlantUML diagrams, timelines, JSON charts or node trees. It parses across Obsidian, CodeMirror, Markdown-it and Remark environments, and keeps the note itself free of extra syntax so the content stays readable and maintainable without the plugin.
