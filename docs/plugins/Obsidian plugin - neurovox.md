# NeuroVox

NeuroVox records voice inside a note and embeds the audio there for playback. Recordings are transcribed with AI, and custom prompts turn the transcript into summaries, extracted to-dos or other output, embedded as callouts at the cursor.

```cue
plugin: {
    id:     "neurovox"
    name:   "NeuroVox"
    author: "synaptic-labs-ai"
    repo:   "synaptic-labs-ai/NeuroVox"

    html_url:    "https://community.obsidian.md/plugins/neurovox"
    github_url:  "https://github.com/synaptic-labs-ai/NeuroVox"
```
