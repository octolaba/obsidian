# Rich Table

Rich Table renders interactive tables from fenced code blocks, with cell merges, inline editing, typed and choice columns, per-cell styling and an editable title and footer. Rows and columns are reordered by dragging, and the editor offers heading and internal-link autocomplete alongside spreadsheet-like controls.
