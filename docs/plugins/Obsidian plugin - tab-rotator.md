# Tab Rotator

Rotates the open files to the left or right at a configurable interval. Rotation can be started, stopped and reversed, and applied to a single split or to all splits in the main window.

```cue
plugin: {
    id:     "tab-rotator"
    name:   "Tab Rotator"
    author: "autohub7"
    repo:   "autohub7/obsidian-tab-rotator"

    html_url:    "https://community.obsidian.md/plugins/tab-rotator"
    github_url:  "https://github.com/autohub7/obsidian-tab-rotator"
    description: "Rotate opened files to the left or right with a specified interval."
    about:       "Rotate open tabs automatically to the left or right at a configurable interval. Start, stop, and reverse rotation, and apply it to a single split or all splits in the main window."
```
