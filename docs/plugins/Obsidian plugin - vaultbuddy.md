# VaultBuddy

Keeps an AI chat assistant in the sidebar that answers from the vault's own notes. Relevant passages are retrieved and scattered information connected, summaries are generated with automatic source citations, and several curl-compatible models can be switched between. Conversations are saved automatically and API keys are stored locally with encryption.
