# Open File by Magic Date

This plugin opens files whose names follow a date pattern, so a hotkey and a Moment.js pattern jump straight to a daily, weekly, monthly or yearly note. Single keystrokes can also be mapped to open the most recent anchor, such as the most recent Monday, or the first file matching a search query.

```cue
plugin: {
    id:     "obsidian-open-file-by-magic-date"
    name:   "Open File by Magic Date"
    author: "simplgy"
    repo:   "simplgy/obsidian-open-file-by-magic-date"

    html_url:    "https://community.obsidian.md/plugins/obsidian-open-file-by-magic-date"
    github_url:  "https://github.com/simplgy/obsidian-open-file-by-magic-date"
    description: "Define a hotkey and Moment.js pattern for the file that is most important to you (eg: your daily/weekly/monthly note)."
    about:       "Open files using date-patterned filenames (e.g., {YYYY-MM-DD}, {mon: YYYY-MM-DD}) to jump to daily, weekly, monthly, or yearly notes. Map single keystrokes to open the most recent anchor (like most recent Monday) or the first file matching a search query."

    stats: {
        downloads:  4293
        updated_at: 1679192630000
    }
}
```
