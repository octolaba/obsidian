# Toggle

Toggle adds Notion-style collapsible toggles written with paired pipe-and-angle markers, rendering a clickable triangle that folds and unfolds the content with a single click. Header folding inside a toggle is scoped so that the global outline stays intact, code fences can be made collapsible, and toggle titles show a Copy button on hover. It is built on Obsidian's core folding engine.
