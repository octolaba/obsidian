# TaskChute Plus

TaskChute Plus manages the day's tasks in a single view with date navigation and configurable time slots. Starting and stopping a task records its real execution time, kept as execution logs and yearly heatmaps, and recurring routines can be created and run. Tasks link to projects, per-task reminders can be set, and schedules export to Google Calendar.
