# CFR Find

CFR Find indexes the vault in a background worker and returns ranked, typo-tolerant results with prefix matching across Markdown, Canvas and plaintext files. Matches inside the active note can be jumped to, and queries accept phrase, exclusion, extension and path filters. Indexing runs in the background and result highlighting is kept lightweight so the interface stays responsive, and the plugin states that it was inspired by Omnisearch and can optionally index PDF, image and Office documents.
