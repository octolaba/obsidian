# New Filename

New Filename replaces the default name given to new notes with one of your choosing, in place of Undefined. Leaving the setting blank makes the plugin generate a UUID filename instead.

```cue
plugin: {
    id:     "new-file-name"
    name:   "New Filename"
    author: "thelonewanderer4"
    repo:   "thelonewanderer4/obsidian-uuid-title"

    html_url:    "https://community.obsidian.md/plugins/new-file-name"
    github_url:  "https://github.com/thelonewanderer4/obsidian-uuid-title"
    description: "Change the default filename used for new notes"
    about:       "Set a default filename to replace \"Undefined\" for new notes. Leave the setting blank to generate a UUID filename automatically."

    stats: {
        downloads:  932
        updated_at: 1735251230000
    }
}
```
