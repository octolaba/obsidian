# Stashpad Docs

The contents of the current note are used to create a new Stashpad Doc. The new document is then opened in the browser for viewing and sharing.

```cue
plugin: {
    id:     "stashpad-docs"
    name:   "Stashpad Docs"
    author: "stashpad"
    repo:   "stashpad/obsidian-to-stashpad"

    html_url:    "https://community.obsidian.md/plugins/stashpad-docs"
    github_url:  "https://github.com/stashpad/obsidian-to-stashpad"
    description: "Create a Stashpad Doc from your notes."
    about:       "Share the current Obsidian note to Stashpad Docs by creating a new Stashpad Doc with the note's contents. Open the new doc in your browser for immediate viewing and sharing."

    stats: {
        downloads:  344
        updated_at: 1716317353000
    }
}
```
