# Auto Embed

Auto Embed renders links with Obsidian's embed syntax so previews appear in place of raw iframes. It handles sites such as Imgur, CodePen, Steam, Reddit, TikTok, Spotify and SoundCloud, accepts inline options for width, height or disabling an embed, and falls back to a full-page embed for unsupported sites.

```cue
plugin: {
    id:     "auto-embed"
    name:   "Auto Embed"
    author: "gnoxnahte"
    repo:   "gnoxnahte/obsidian-auto-embed"

    html_url:    "https://community.obsidian.md/plugins/auto-embed"
    github_url:  "https://github.com/gnoxnahte/obsidian-auto-embed"
    description: "Helps to embed links using markdown instead of iframe."
    about:       "Embed links directly in notes using Obsidian's embed syntax to display previews instead of raw iframes. Support popular sites like Imgur, CodePen, Steam, Reddit, TikTok, Spotify and SoundCloud, accept inline options for width/height or disabling embeds, and fallback to full-page embeds for unsupported sites."
```
