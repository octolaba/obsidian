# PDF Folder to Markdowns

Converts a folder of PDFs into individual Markdown notes, each embedding its source PDF. The source folder can optionally be renamed with a suffix, PDFs follow the vault's attachment settings so that they sit beside the notes, and a Templater or core template can be applied after the conversion.

```cue
plugin: {
    id:     "pdf-folder-to-markdowns"
    name:   "PDF Folder to Markdowns"
    author: "crishood"
    repo:   "crishood/pdf-folder-to-markdowns"

    html_url:    "https://community.obsidian.md/plugins/pdf-folder-to-markdowns"
    github_url:  "https://github.com/crishood/pdf-folder-to-markdowns"
    description: "Convert a folder of PDFs into Markdown files with embedded PDFs"
    about:       "Convert a folder of PDFs into individual Markdown notes with each PDF embedded. Create notes for every PDF, optionally rename the source folder with a suffix, follow Obsidian attachment settings to move PDFs beside notes, and apply a Templater or core template after conversion."

    stats: {
        downloads:  5606
        updated_at: 1766853764000
    }
}
```
