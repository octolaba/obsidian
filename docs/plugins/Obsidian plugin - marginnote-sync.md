# MarginNote Sync

MarginNote Sync imports annotations, highlights, notes and mind maps from MarginNote 4 into Obsidian as per-book Markdown files with YAML frontmatter and Canvas mind maps. It reads MarginNote's live SQLite database for incremental updates and rebuilds the hierarchical mind maps. Callouts and wikilinks are rendered, and marginnote4app deep links back to the source are preserved.
