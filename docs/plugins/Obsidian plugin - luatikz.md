# LuaTikZ

Renders TikZ code blocks with the local LuaLaTeX installation, with full package and TikZ library support including pgfplots, circuitikz, math mode and standard LaTeX commands. Previews appear inline and live, helper macros and autocomplete assist writing, and SVG output can be exported or copied. LaTeX errors are mapped back to lines of the block, right-to-left and Hebrew text are supported, and dark-mode inversion is optional.
