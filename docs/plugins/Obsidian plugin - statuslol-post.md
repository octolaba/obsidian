# OMG.lol Publisher

Posts are published and updated on weblog.lol from notes, with frontmatter supplying dates, tags, slugs and permalinks and an option to rename the note on publishing. Status updates go to status.lol with an optional cross-post to social.lol. Images are uploaded to some.pics while the originals and a log are kept, and selected text becomes a Paste.lol snippet whose address is copied back.

```cue
plugin: {
    id:     "statuslol-post"
    name:   "OMG.lol Publisher"
    author: "ericmwalk"
    repo:   "ericmwalk/obsidian-omglol-publisher"

    html_url:    "https://community.obsidian.md/plugins/statuslol-post"
    github_url:  "https://github.com/ericmwalk/obsidian-omglol-publisher"
    description: "Allows you to post to weblogs.lol, status.lol, some.pics and paste.lol."
    about:       "Publish and update weblog.lol posts from notes using frontmatter for dates, tags, slugs and permalinks, and optionally rename notes on publish. Post status updates to status.lol (toggle cross-post to social.lol), upload images to some.pics while keeping originals and logs, and create Paste.lol snippets from selected text with the URL copied back."

    stats: {
        downloads:  330
        updated_at: 1781784525000
    }
}
```
