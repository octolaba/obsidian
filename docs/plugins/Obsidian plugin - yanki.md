# Yanki

Syncs a folder of Markdown notes in the vault to Anki, mapping each note to a single Anki note in plain Markdown syntax. The folder hierarchy is converted into matching Anki decks automatically.

```cue
plugin: {
    id:     "yanki"
    name:   "Yanki"
    author: "kitschpatrol"
    repo:   "kitschpatrol/yanki-obsidian"

    html_url:    "https://community.obsidian.md/plugins/yanki"
    github_url:  "https://github.com/kitschpatrol/yanki-obsidian"
    description: "Sync flashcards from a folder in your vault to Anki. Pure Markdown syntax. No fuss."
```
