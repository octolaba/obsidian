# LiviUtils

Bundles assorted utility and quality-of-life features into a single meta-plugin. The feature recorded in its description is embedding arbitrary files, canvases included, directly into a note so that richer content can be included inline.

```cue
plugin: {
    id:     "livi-utils"
    name:   "LiviUtils"
    author: "Olivia"
    repo:   "lunarwatcher/obsidian-utils"

    html_url:    "https://community.obsidian.md/plugins/livi-utils"
    github_url:  "https://github.com/lunarwatcher/obsidian-utils"
    description: "Meta-plugin with misc. utility and QoL features. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add miscellaneous quality-of-life and utility features to Obsidian in a single bundled plugin. Embed arbitrary files, including canvases, directly into notes to include rich content."

    stats: {
        downloads:  99
        updated_at: 1778714974000
    }
}
```
