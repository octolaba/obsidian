# Redirect HTTPS to Local

Converts Obsidian's own scheme links into standard HTTPS redirect URLs, so they work on external platforms such as Slack, Notion, and the web. Shareable links are generated and copied with proper URL encoding, the redirect domain is customizable, and a toast confirms the copy. It works across platforms.

```cue
plugin: {
    id:     "redirect-link-https-to-local"
    name:   "Redirect HTTPS to Local"
    author: "iamjjanga-ouo"
    repo:   "iamjjanga-ouo/obsidian-link"

    html_url:    "https://community.obsidian.md/plugins/redirect-link-https-to-local"
    github_url:  "https://github.com/iamjjanga-ouo/obsidian-link"
    description: "Convert redirect HTTPS to local redirect URL for better compatibility with external platforms. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert Obsidian obsidian:// links into standard HTTPS redirect URLs for compatibility with Slack, Notion, and web platforms. Generate and copy shareable links with proper URL encoding, customizable redirect domains, cross-platform support, and toast confirmation."

    stats: {

}
```
