# CalloutX

CalloutX explores and previews the custom callout icons defined in a custom-callouts.css file through a searchable modal and a settings tab. Callouts can be added, edited, renamed or deleted with custom names, colors and Lucide icons. The CSS snippet is imported into the snippets folder automatically when it is missing.
