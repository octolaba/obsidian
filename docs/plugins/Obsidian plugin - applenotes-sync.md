# AppleNotes Sync

Syncs notes from the macOS Notes app into the local vault, running only on a manual refresh or a command rather than continuously. Images, tables and other content are preserved, and specified folders inside Notes are mapped to the Obsidian target folder. It works on macOS only.

```cue
plugin: {
    id:     "applenotes-sync"
    name:   "AppleNotes Sync"
    author: "fengshuzi"
    repo:   "fengshuzi/applenotes-sync"

    html_url:    "https://community.obsidian.md/plugins/applenotes-sync"
    github_url:  "https://github.com/fengshuzi/applenotes-sync"
    description: "Sync notes from the macOS Notes app to your local Vault. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync macOS Notes to Obsidian, only when manually refreshed or triggered by a command. Preserve images, tables, and other content, and map specified folders within Notes to the Obsidian target folder (macOS only)."

    }
}
```
