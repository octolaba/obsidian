# Minimalism UI

Minimalism UI reshapes the interface into a minimal macOS-style writing environment with a frosted-glass sidebar, a merged Outline and Properties view, simplified panels and refined typography and block styles. A single-page mode with an LRU tab cache and cross-tab back and forward navigation can be enabled, a Home note assigned, and smooth scrolling plus subtle page-load and heading animations added. The recorded description compares the result to Typora, with note status information on the left and the note content on the right.
