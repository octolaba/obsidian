# Fancy Kanban

Fancy Kanban embeds Kanban boards in notes and renders them inline alongside the surrounding content. Cards are dragged between columns, each board defines its own relational fields, and a card is edited in a modal or in a standalone board view. The board data is stored as a human-readable Markdown table.
