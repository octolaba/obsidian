# TTRPG Tools - Timeline

TTRPG Tools - Timeline renders timelines from note frontmatter, either in Markdown code blocks or in Bases views, using a vertical or horizontal layout. Its recorded description, written in German, names the Calendarium frontmatter fields fc-date and fc-end as the input. Visuals and entry sizing are customizable, entries can carry images and summaries, and native hover popovers give quick page previews.

```cue
plugin: {
    id:     "simple-timeline"
    name:   "TTRPG Tools - Timeline"
    author: "Johannes Schwartz"
    repo:   "jareika/Simple-Timeline"

    html_url:    "https://community.obsidian.md/plugins/simple-timeline"
    github_url:  "https://github.com/jareika/Simple-Timeline"
    description: "Timeline-Renderer für Calendarium-Frontmatter (fc-date/fc-end). 200×315 Bild, Callout-Stil, native Popover, mobilfreundlich. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render timelines from note frontmatter in Markdown code blocks or Bases views, using vertical or horizontal layouts. Customize visuals and entry sizing, include images and summaries, and show hover popovers for quick page previews."

    stats: {
        downloads:  9478
        updated_at: 1779891897000
    }
}
```
