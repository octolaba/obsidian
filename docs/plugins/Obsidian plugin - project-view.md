# Project View

Organizes notes into projects, each keeping its own folders, specific notes, pinned items, and named panes. Selecting a project from a left-sidebar list restores its open tabs, scroll position, cursor, and undo history without reopening the files. On desktop, projects can be synced with Google Drive.
