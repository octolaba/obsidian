# Markdown Image Maker

Markdown Image Maker exports a Markdown file or a selected passage as styled, paginated images through a local converter, with live previews before export. Images can be saved to the vault root, the current file's folder, the attachment folder or a custom folder, and image links can optionally be inserted back into the source note. It runs on Obsidian desktop only.

```cue
plugin: {
    id:     "markdown-image-maker"
    name:   "Markdown Image Maker"
    author: "suntinglu777"
    repo:   "sunxiaoqiqi/markdown-image-maker"

    html_url:    "https://community.obsidian.md/plugins/markdown-image-maker"
    github_url:  "https://github.com/sunxiaoqiqi/markdown-image-maker"

Use a local converter backend and run on Obsidian desktop only."
