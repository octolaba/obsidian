# TokenBar

TokenBar shows the local token count of the active note in Obsidian's status bar, with a primary tokenizer that defaults to GPT. Hovering the status item compares counts for GPT, Qwen and DeepSeek alongside estimates for Claude and Gemini. Only text is counted, with embedded images and attachments excluded, and the counting runs entirely locally on desktop.

```cue
plugin: {
    id:     "tokenbar"
    name:   "TokenBar"
    author: "sn1p4am"
    repo:   "sn1p4am/TokenBar"

    html_url:    "https://community.obsidian.md/plugins/tokenbar"
    github_url:  "https://github.com/sn1p4am/TokenBar"
    description: "Shows local token counts for the active note in the status bar. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display the active note's local token count in Obsidian's status bar and set a primary tokenizer (default: GPT). Hover the status item to compare GPT, Qwen, DeepSeek and estimated Claude/Gemini counts; count text only—excluding embedded images and attachments—and run fully locally (desktop-only)."

    stats: {
        downloads:  46
        updated_at: 1783566603000
    }
}
```
