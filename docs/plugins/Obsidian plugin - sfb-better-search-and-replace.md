# Better Search and Replace

Better Search and Replace docks a floating search bar at the top of the editor with live match highlighting and a real-time inline diff preview that shows removals struck through and replacements as green ghost text. Full JavaScript regular expressions with capture groups are supported, matches are stepped through one at a time, and either the current match or all matches can be replaced, on desktop and mobile.
