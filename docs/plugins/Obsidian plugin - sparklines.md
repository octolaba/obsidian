# Sparklines

Code blocks are converted into inline SVG sparklines that render in paragraphs, tables and other contexts of a note. The numeric data comes from a literal array or from a frontmatter key, and color, width and stroke are controlled through simple inline options.

```cue

    id:     "sparklines"
    name:   "Sparklines"
    author: "deeplook"
    repo:   "deeplook/obsidian-sparklines"

    html_url:    "https://community.obsidian.md/plugins/sparklines"
    github_url:  "https://github.com/deeplook/obsidian-sparklines"
```
