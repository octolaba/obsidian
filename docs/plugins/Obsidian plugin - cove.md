# Cove

Cove manages bookmarks as plain Markdown files with YAML frontmatter inside a vault folder, so the collection stays portable and searchable without a proprietary database. Bookmarks can be browsed in Compact, Cards, Kanban or Tree layouts, and title, description, image, favicon and reading time are fetched automatically. Items map to real subfolders with drag-to-move, and the plugin runs health checks and bulk batch operations over the collection.
