# Callout Copy Buttons

Callout Copy Buttons adds Copy (Markdown) and Copy (plain text) buttons to callout blocks for quick clipboard export. Button appearance and behavior are customizable with a live preview of the changes. The inputs note that Markdown copy works only in Source Mode and top-level Reading Mode, while plain-text copy uses rendered innerText and may vary when callouts are folded.

```cue
plugin: {
    id:     "callout-copy-buttons"
    name:   "Callout Copy Buttons"
    author: "alythobani"
    repo:   "alythobani/obsidian-callout-copy-buttons"

    html_url:    "https://community.obsidian.md/plugins/callout-copy-buttons"
    github_url:  "https://github.com/alythobani/obsidian-callout-copy-buttons"
    description: "Adds copy buttons to callout blocks in your notes."
    about:       "Add \"Copy (Markdown)\" and \"Copy (plain text)\" buttons to callout blocks for quick clipboard export. Customize button appearance and behavior and preview changes live. Be aware Markdown copy works only in Source Mode and top-level Reading Mode; plain-text copy uses rendered innerText and may vary when callouts are folded."

    stats: {
        downloads:  3205

    }
}
```
