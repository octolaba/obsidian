# Resonance

Resonance records audio from the main microphone and optional extra inputs while producing live Whisper transcripts and post-session summaries through Ollama or a cloud provider. Sessions are kept in a built-in Library holding audio, transcripts, summaries and diagnostics, with tools to inspect, recover, clean up or bulk-delete those artifacts. The recorded description calls it local-first.
