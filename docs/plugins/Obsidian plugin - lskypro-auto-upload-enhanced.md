# Image To Lskypro Enhanced

Uploads local and remote note images to Lsky Pro from the clipboard, drag-and-drop, local files or remote links, supporting both the older and the newer Lsky Pro APIs. Remote images are first downloaded into a configurable folder before the current note's images are uploaded and their links replaced with Lsky URLs. Context-menu actions and a single floating progress notice cover the operations.
