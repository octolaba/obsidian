# URL File Preview

Previews Windows .url shortcut files as a compact card inside Obsidian, where the address can be edited inline. Unknown INI keys and sections are preserved, links open in the default application or in a web viewer, and a shortcut can be converted into a Markdown note. The recorded About states that every change and action stays local, with no network requests.

```cue
plugin: {
    id:     "url-file-preview"
    name:   "URL File Preview"
    author: "Gabriel"
    repo:   "turingexmachina/obsidian-url-file-preview"

    html_url:    "https://community.obsidian.md/plugins/url-file-preview"
    github_url:  "https://github.com/turingexmachina/obsidian-url-file-preview"
    description: "Preview and edit Windows .url shortcut files — edit the URL inline, open in your default app or the web viewer, and convert to a Markdown note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Preview Windows .url shortcut files as a compact card inside Obsidian. Edit the URL inline, preserve unknown INI keys and sections, and open or convert links with one click — all changes and actions stay local with no network requests."

    stats: {
        downloads:  21
        updated_at: 1783989698000
    }
}
```
