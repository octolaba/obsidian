# JW Convention Program

Imports official convention files in .jwpub or RTF-ZIP form and turns them into structured, linked Markdown notes in the vault. Each convention gets its own named folder, with day subfolders for regional conventions, numbered programme items and generated overview files. Talk sections are linked, and clickable scripture references and JW Library deeplinks are inserted.

```cue
plugin: {
    id:     "jw-congregation-program"
    name:   "JW Convention Program"
    author: "Lukas Schütter"
    repo:   "realsteeldeal/obsidian-jw-congregation"

    html_url:    "https://community.obsidian.md/plugins/jw-congregation-program"
    github_url:  "https://github.com/realsteeldeal/obsidian-jw-congregation"
    description: "Importiert JW-Kongressprogramme (.jwpub / RTF-ZIP) und erstellt strukturierte Notizen im Vault. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Importiere offizielle Kongressdateien (.jwpub oder RTF‑ZIP) und erstelle daraus strukturierte, verlinkte Markdown‑Notizen im Vault. Lege pro Kongress einen benannten Ordner (bei Regionalkongressen Tages‑Unterordner), nummeriere Programmpunkte, erzeuge Übersichtsdateien, verlinke Vortragsabschnitte und füge klickbare Bibelstellen sowie JW‑Library‑Deeplinks ein."

    stats: {
```
