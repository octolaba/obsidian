# EngramQuest

Turns notes into flashcard review decks, gamified quest maps and visual memory maps on Canvas, keeping the cards inline so the original Markdown is left untouched. Cards are written by hand or generated with AI in question-and-answer, multi-line and cloze formats, with images. Review uses FSRS spaced repetition, and the recorded description names Claude Code, Gemini CLI and Cursor as the supported AI tooling.
