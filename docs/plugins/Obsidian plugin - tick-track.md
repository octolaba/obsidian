# Tick Track

Tick Track records time on list items and native Markdown checkboxes, starting and stopping as a task's status is toggled. Start times are shown inline and durations appended in seconds, minutes or hours, state cycling moves a task from TODO through DOING to DONE, and clicking a DOING checkbox in live preview finishes the task and records the elapsed time.
