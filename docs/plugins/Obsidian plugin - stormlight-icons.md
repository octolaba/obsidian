# Stormlight RPG Icons

Inline code tokens following a short strm pattern are rendered as styled action-icon glyphs in Reading mode and Live Preview. Tokens are brief and case-insensitive, so the underlying text stays searchable while a compact CSS glyph is displayed. The recorded description identifies the glyphs as Stormlight roleplaying game icons.

```cue
plugin: {
    id:     "stormlight-icons"
    name:   "Stormlight RPG Icons"
    author: "eonfuzz"
    repo:   "eonfuzz/stormlight-actions"

    html_url:    "https://community.obsidian.md/plugins/stormlight-icons"
    github_url:  "https://github.com/eonfuzz/stormlight-actions"
    description: "Displays Stormlight RPG Icons. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render inline code tokens like `strm:r` as styled action-icon glyphs in Reading mode and Live Preview. Type simple case-insensitive tokens using the strm:<token> pattern (e.g. r, 1, u, f, o, c) to keep searchable text while showing compact CSS glyphs."

    stats: {
        downloads:  121
        updated_at: 1765534528000
    }
}
```
