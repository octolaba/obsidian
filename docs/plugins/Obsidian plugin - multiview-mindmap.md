# multiview-mindmap

Edits mindmaps interactively while keeping them synchronized with Markdown in both directions, offering Basic, Folder, Tag and CoT structural views, a focus layout and inline node editing. Nodes are expanded or decomposed with AI assistance. Mindmaps export to slides, images, HTML and Markdown, import from OPML and XMind, and support full undo and redo with keyboard-driven navigation.
