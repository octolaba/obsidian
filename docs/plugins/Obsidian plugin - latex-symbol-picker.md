# LaTeX Symbol Picker

LaTeX Symbol Picker offers a side panel in which a symbol is drawn or searched for and then inserted at the cursor, wrapping the command in math delimiters when the cursor is not already inside math. Recognition is done by a bundled Detexify-style handwriting classifier that works offline and covers only symbols that Obsidian's MathJax can render.
