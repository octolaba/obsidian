# Details Markdown

Renders Markdown inside native HTML details and summary blocks in reading view. Headings, lists, tables, internal links, embeds and code fences inside the folded content display as ordinary Markdown, while malformed or unclosed blocks are left untouched. The project states that live preview behavior is unchanged until support is added.

```cue
plugin: {
    id:     "details-markdown"
    name:   "Details Markdown"
    author: "Nickolay Kondratyev"
    repo:   "nickolay-kondratyev/obsidian-plugin-collapsible-details"

    html_url:    "https://community.obsidian.md/plugins/details-markdown"
    github_url:  "https://github.com/nickolay-kondratyev/obsidian-plugin-collapsible-details"
    description: "Render Markdown (headings, lists, tables, links, embeds) inside native HTML details blocks in Reading view. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render Markdown inside native HTML <details>/<summary> blocks in Reading view. Preserve headings, lists, tables, internal links, embeds and code fences so folded content displays exactly like regular Markdown; leave malformed or unclosed blocks untouched. Keep Live Preview behavior unchanged until support is added."
```
