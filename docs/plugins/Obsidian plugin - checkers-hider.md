# Checkers Hider

Checkers Hider hides completed and custom-status checklist items from view without changing the underlying notes. Hiding is toggled from the command palette, a status-bar icon or an optional ribbon item, and single-character markers decide which statuses are hidden and which are kept. Nested bullets can be hidden as well, all checkboxes can be shown while editing, and an inline or frontmatter tag disables hiding for one page.

```cue
plugin: {
    id:     "checkers-hider"
    name:   "Checkers Hider"
    author: "Andrei"
    repo:   "mr-asa/obsidian-checkers-hider"

    html_url:    "https://community.obsidian.md/plugins/checkers-hider"
    github_url:  "https://github.com/mr-asa/obsidian-checkers-hider"
    description: "Hide or show completed and custom-status checklist items in Obsidian. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Hide completed and custom-status checklist items in Obsidian without changing your notes. Toggle hiding from the command palette, status-bar icon, or optional ribbon; configure single-character markers to hide or keep, optionally hide nested bullets, and show all checkboxes while editing. Disable hiding per page with an inline or frontmatter tag."

    stats: {
        downloads:  132
        updated_at: 1780066198000
    }
}
```
