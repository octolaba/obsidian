# Share Page

Share Page publishes a note as a styled webpage through htmlto.link and copies the public link. More than thirty templates and several theme variants are available, card width is chosen between 360 and 800 pixels, shared links can be removed, share_link and share_updated are written to frontmatter, and the API base URL can point at a self-hosted instance.

```cue
plugin: {
    id:     "htmlto-link"
    name:   "Share Page"
    author: "licc168"
    repo:   "licc168/obsidian-htmlto-link"

    html_url:    "https://community.obsidian.md/plugins/htmlto-link"
    github_url:  "https://github.com/licc168/obsidian-htmlto-link"
    description: "Instantly share a note as a beautiful webpage and copy the public link. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Share any Obsidian note as a styled webpage and copy the public link instantly via htmlto.link. Pick from 30+ templates and multiple theme variants, choose card widths (360–800px), remove shared links, write share_link/share_updated to frontmatter, and use a self-hostable API base URL."

    stats: {

}
```
