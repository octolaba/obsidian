# Noesis

Noesis answers questions asked across the notes in a vault, grounding each answer in that content. By default it runs on a local LLM, and it can instead use compatible external APIs that the user manages. The recorded description states that knowledge stays on your machine, that there is no external telemetry, analytics or tracking, and that the plugin is built for simplicity rather than for advanced users.
