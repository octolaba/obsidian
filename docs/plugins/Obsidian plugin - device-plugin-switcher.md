# Device Extensions Switcher

Chooses which community plugins are enabled on desktop, on mobile, on both, or nowhere, while a single shared configuration folder is kept. The per-device active state is applied without syncing plugin files or plugin settings automatically.

```cue
plugin: {
    id:     "device-plugin-switcher"
    name:   "Device Extensions Switcher"
    author: "Stanislav Levyshchev"
    repo:   "yvelious/device-plugin-switcher"

    html_url:    "https://community.obsidian.md/plugins/device-plugin-switcher"
    github_url:  "https://github.com/yvelious/device-plugin-switcher"
    description: "Choose which community plugins are enabled on desktop, mobile, both, or disabled. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Choose which Obsidian community plugins are enabled on desktop, mobile, both, or disabled while keeping a single shared .obsidian configuration folder. Apply device-specific active plugin states without syncing plugin files or plugin settings automatically, preserving a unified config while controlling per-device plugin activity."

    stats: {
        downloads:  159
        updated_at: 1782228802000
    }
}
```
