# Markwhen File Sync

Markwhen File Sync synchronizes properties from notes with a Markwhen .mw timeline file, in both directions and with optional automatic sync and status-tag support. Events can be grouped, sorted and filtered by note properties. Existing timeline headers are preserved, and dates given only as a month or a year are handled.

    id:     "markfilesync"
    name:   "Markwhen File Sync"
    author: "rouvenjahnke"
