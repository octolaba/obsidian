# Note Open Tracker Plus

Note Open Tracker Plus counts how often each note is opened, on desktop and on mobile, and can optionally record the events as append-only NDJSON. Its analytics report covers all-time opens, opens in the last 30, 90 and 365 days, trending scores derived from those windows, and the most recently opened notes.

    id:     "note-open-tracker-plus"
    name:   "Note Open Tracker Plus"

    repo:   "srivadrevu/obsidian-note-open-tracker-plus"

    html_url:    "https://community.obsidian.md/plugins/note-open-tracker-plus"
