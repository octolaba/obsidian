# Whisper

Records or uploads audio on desktop and mobile and transcribes it through Whisper-compatible APIs, including OpenAI, Groq, Azure and local endpoints. The transcript can be post-processed by a language model to clean up grammar, drop filler words, format Markdown and extract action items. Notes are generated from a template with a derived title and the audio embedded.

```cue
plugin: {
    id:     "whisper"
    name:   "Whisper"
    author: "nikdanilov"
    repo:   "nikdanilov/whisper-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/whisper"
    github_url:  "https://github.com/nikdanilov/whisper-obsidian-plugin"
    description: "Speech-to-text using OpenAI Whisper."
    about:       "Record or upload audio on desktop or mobile and transcribe using Whisper-compatible APIs (OpenAI, Groq, Azure, or local endpoints). Post-process results with an LLM to clean grammar, remove filler words, format as Markdown, extract action items, and auto-generate titled, templated notes with embedded audio."
```
