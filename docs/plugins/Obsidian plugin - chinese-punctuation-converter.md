# Chinese Punctuation Converter

Chinese Punctuation Converter replaces Chinese punctuation with the corresponding English punctuation as the text is typed. The conversion can be toggled off, applied to the whole current document in one click, and restricted to a chosen set of symbols.

```cue
plugin: {
    id:     "chinese-punctuation-converter"
    name:   "Chinese Punctuation Converter"
    author: "enthusjast"
    repo:   "enthusjast/obsidian-punctuation-converter"

    html_url:    "https://community.obsidian.md/plugins/chinese-punctuation-converter"
    github_url:  "https://github.com/enthusjast/obsidian-punctuation-converter"
    description: "自动将中文标点转化为对应的英文标点. Automatically convert Chinese punctuation to corresponding English punctuation. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert Chinese punctuation to matching English punctuation in real time as you type. Toggle conversion on or off, apply one-click conversion to the current document, and customize which symbols are converted."

    stats: {
        downloads:  207
        updated_at: 1779529721000
    }
}
```
