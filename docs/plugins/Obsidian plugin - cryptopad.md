# CryptoPad

Encrypts and decrypts selected text inline through keyboard shortcuts influenced by vim, with the shortcuts listed in the user interface. The plugin states that it uses AES-256-GCM with PBKDF2-SHA256 key derivation and works client-side, so nothing leaves the vault.

```cue
plugin: {
    id:     "cryptopad"
    name:   "CryptoPad"
    author: "CryptoPad"
    repo:   "riogesulgon/obsidian-cryptopad"

    html_url:    "https://community.obsidian.md/plugins/cryptopad"
    github_url:  "https://github.com/riogesulgon/obsidian-cryptopad"
    description: "Encrypt and decrypt text efficiently using keyboard shortcuts - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Use keyboard shortcuts influenced by vim to efficiently encrypt and decrypt text. Keyboard shortcuts are list on the user interface. Encrypt and decrypt selected text inline using AES-256-GCM with PBKDF2-SHA256 key derivation, all client-side so nothing leaves your vault."

    stats: {
        downloads:  82
        updated_at: 1782225545000
    }
}
```
