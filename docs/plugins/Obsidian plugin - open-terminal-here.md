# Open Terminal Here

Open Terminal Here opens a terminal at the directory of the current file. It is triggered from the editor or file explorer context menu, the command palette or an optional ribbon button, and the terminal it launches is configurable between Terminal, iTerm, PowerShell, Windows Terminal and others.

```cue
plugin: {
    id:     "open-terminal-here"
    name:   "Open Terminal Here"
    author: "ryofeeee"
    repo:   "ryofeeee/obsidian-open-terminal-here"

    html_url:    "https://community.obsidian.md/plugins/open-terminal-here"
    github_url:  "https://github.com/ryofeeee/obsidian-open-terminal-here"
    description: "Open a terminal at the current file's directory from the editor or file explorer context menu. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open a terminal at the current file's directory with one click or a command. Use editor or explorer context menus, the command palette, or an optional ribbon button to launch your preferred terminal (Terminal, iTerm, PowerShell, Windows Terminal, etc.)."

    stats: {
        downloads:  257
        updated_at: 1778926103000
    }
}
```
