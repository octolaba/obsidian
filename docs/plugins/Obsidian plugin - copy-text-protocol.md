# Copy Text Protocol

Copy Text Protocol creates clickable links in notes that silently copy a command, a piece of boilerplate, a template or a search string to the clipboard. A built-in keyboard command turns any selection or the clipboard contents into such a link without manual URL encoding. Hovering with Ctrl or Cmd previews the contents the link would copy.
