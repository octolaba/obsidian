# Calculite

Calculite is a standard calculator with a simple button layout for arithmetic such as totals, averages and countdowns without leaving a note. It opens as a floating calculator on desktop and as a compact tab on mobile. The current equation is kept across an Obsidian restart when the calculator tab stays open.
