# Ultra Zen Mode

Hides sidebars, the tab bar, the status bar, note properties and optionally the inline title to clear the screen for reading and writing. A floating exit button in the bottom-right corner brings the interface back, and the mode can be toggled at any time. It works on desktop, tablet and mobile.

    id:     "ultra-zen-mode"
    name:   "Ultra Zen Mode"
    author: "Marcos"
    repo:   "marckfp/ultra-zen-mode"

    html_url:    "https://community.obsidian.md/plugins/ultra-zen-mode"
    github_url:  "https://github.com/marckfp/ultra-zen-mode"
    description: "Enter a distraction-free zen mode by hiding sidebars, properties, title and status bar. Works on desktop and mobile. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Clear the screen for distraction-free reading and writing by hiding sidebars, tab bar, status bar, note properties, and an optional inline title. Reveal the interface instantly with a subtle floating exit button in the bottom-right or toggle Zen Mode anytime; works on desktop, tablet, and mobile."
