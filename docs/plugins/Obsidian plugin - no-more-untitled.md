# No More Untitled

No More Untitled walks through the Markdown notes still named Untitled or Untitled n one at a time, showing each with its path, modified time and a rendered preview. Each note can be deleted, renamed while keeping its folder and extension, or kept, and a compact checklist mode allows bulk deletion behind an explicit confirmation.

```cue
plugin: {
    id:     "no-more-untitled"
    name:   "No More Untitled"
    author: "woodamsclark"
    repo:   "woodamsclark/no-more-untitled"

    html_url:    "https://community.obsidian.md/plugins/no-more-untitled"
    github_url:  "https://github.com/woodamsclark/no-more-untitled"
    description: "Review, rename, or delete accumulated Untitled notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Review untitled Markdown notes named Untitled or Untitled n one at a time with path, modified time, and a rendered preview. Delete, rename (preserving folder and extension), or keep notes, or switch to a compact checklist for bulk deletion with explicit confirmation."

    stats: {
        downloads:  35
        updated_at: 1784121980000
    }
}
```
