# Yijing Oracle

Casts the I Ching with a three-coin oracle and presents the hexagram texts of Richard Wilhelm. Each reading is saved as a Markdown note carrying the hexagram, changing lines, resulting hexagram and question in frontmatter, or inserted at the cursor, from a sidebar panel or from commands. Interface and texts switch between English and German in a classic or gender-neutral register, and the readings stay local with no cloud service.

```cue
plugin: {
    id:     "yijing-oracle"
    name:   "Yijing Oracle"
    author: "Johannes Kaindl"
    repo:   "johannes-kaindl/yijing-oracle"

    html_url:    "https://community.obsidian.md/plugins/yijing-oracle"
    github_url:  "https://github.com/johannes-kaindl/yijing-oracle"
    description: "Cast the I Ching (Yijing) in your vault: three-coin oracle with Wilhelm hexagram texts, readings saved as notes. Local-first, no cloud. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Cast the I Ching inside Obsidian with a three-coin oracle and Richard Wilhelm hexagram texts. Save each reading as a Markdown note (frontmatter: hexagram, changing_lines, resulting, question) in your vault or insert at the cursor via the sidebar panel or commands. Switch UI/texts between English and German and pick classic or gender‑neutral register."
```
