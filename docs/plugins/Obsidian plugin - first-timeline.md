# 1st Timeline

Renders plain text into timelines, with date parsing that accepts Chinese date words and precise times and with event content written in full Markdown. Aggregated timelines can be generated from frontmatter, long lists fold automatically, and events falling on today are highlighted with a hover distance to today. Colors, sizing and ordering are configurable.

```cue
plugin: {
    id:     "first-timeline"
    name:   "1st Timeline"
    author: "lnabc03"
    repo:   "lnabc03/1st-Timeline"

    html_url:    "https://community.obsidian.md/plugins/first-timeline"
    github_url:  "https://github.com/lnabc03/1st-Timeline"
    description: "A simple, elegant, and Chinese-friendly timeline rendering plugin. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render simple text into elegant, Chinese-friendly timelines with robust date parsing (including Chinese date words), precise time support, and full Markdown event content. Generate aggregated timelines from frontmatter, auto-fold long lists, highlight today’s events, show hover distance-to-today, and customize colors, sizing and ordering."

    stats: {
        downloads:  200
        updated_at: 1780838395000
    }
}
```
