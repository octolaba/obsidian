# MathLive

MathLive provides a visual MathLive editor for inserting and editing inline or display math in notes, offered as a faster alternative to writing MathJax by hand. Images of copied formulas can be converted into editable LaTeX through cloud or local OCR, and the result is inserted for cleanup.
