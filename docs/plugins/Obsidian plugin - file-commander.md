# File Commander

File Commander applies batch operations to large sets of notes: selection, deletion, moving, tagging, tag replacement and frontmatter property renaming. It renames embedded images sequentially, converts image links to relative or minimal paths, and finds broken or unreferenced images as well as empty, untagged or isolated notes. Files can be filtered and sorted, selection counts are shown, and quick actions are available from the right-click menu.
