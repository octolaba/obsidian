# Pixel Pets

Pixel Pets opens a movable pet view in the vault and populates it with pixel pets, recorded as 22 cats with seven or more animations, across ten backgrounds. Pets are named and customised, and they can be played fetch with, petted or made to follow the cursor. A Catbot answers using the vault's context.
