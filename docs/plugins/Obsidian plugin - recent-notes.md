# Recent Notes

Lists recently edited notes on a timeline grouped by period, such as Today, Yesterday, and This Week. Entries can be filtered by file type and show thumbnails, cleaned first-line previews, and edit timestamps. Notes can be pinned, folders excluded, and the view is kept fast with caching.

    id:     "recent-notes"
    name:   "Recent Notes"
    author: "kamil-rudnicki"
