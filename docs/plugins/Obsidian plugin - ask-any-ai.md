# Ask Any AI

Runs a language model over selected text and inserts the result in place inside the current note. Wikilinks in the selection can be expanded into their linked content, inline or template system prompts loaded from a prompts folder, and the insertion position chosen as after, replace or end. Copilot, Claude, Gemini and local command-line tools are supported as providers.
