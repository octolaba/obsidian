# Claude Code Skills

Runs a Claude Code skill against highlighted text from the editor's context menu and streams the response into a persistent side panel that stays open across notes. Multi-turn context is preserved, a freeform chat is available beside the skill runs, and a full conversation can be exported as a vault note.

    id:     "claude-code-skills"
    name:   "Claude Code Skills"
    author: "p3nguln5"
    repo:   "p3nguln5/obsidian-claude-code-skills"

    html_url:    "https://community.obsidian.md/plugins/claude-code-skills"
