# Zen Mode

Zen Mode hides most of the Obsidian interface so that a single file or document fills the view, leaving one button to restore it. Sidebars collapse and restore automatically, and the plugin adds full-screen viewing, adjustable padding, and options to hide properties or the inline title. A draggable top bar carries a device-aware exit button.
