# Local Image Resizer

Resizes, converts and compresses JPEG, PNG and WebP images locally while the originals are preserved. Dimensions can be linked or independent and a target file size can be set, results are previewed, and the output is saved beside the original or replaces an embedded image in the current note. The recorded text states that all processing stays local, with no uploads and no accounts.
