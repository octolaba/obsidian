# JW Relink

Converts JW.ORG finder and share links found in notes into a form that JW Library can read. The rewritten links open the referenced content in the JW Library app.

```cue
plugin: {
    id:     "jw-relink"
    name:   "JW Relink"
    author: "floydv149"
    repo:   "floydv149/JW-Relink"

    html_url:    "https://community.obsidian.md/plugins/jw-relink"
    github_url:  "https://github.com/floydv149/JW-Relink"
    description: "Tranforms links from JW.ORG to JW Library compatible ones. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert JW.ORG finder and share links in your notes into JW Library–readable format. Rewrite links so the JW Library app opens the referenced content correctly."

    stats: {
        downloads:  56
        updated_at: 1782989777000
    }
}
```
