# Mind Elixir Mind Map

Mind Elixir Mind Map turns a Markdown file into an interactive mind map with Mind Elixir, parsing headers and lists into hierarchical nodes and updating live in a split pane. Inline maps can be embedded with mindelixir code blocks, the root node taken from the filename or the first H1, and the map remains interactive on mobile.
