# docxidian

Opens docx files inside Obsidian and edits them in place, writing changes back to the original file in the vault. A document can also be embedded read-only in a note through a file embed for inline viewing.

```cue
plugin: {
    id:     "docxidian"
    name:   "docxidian"
    author: "kpaede"
    repo:   "kpaede/docxidian"

    html_url:    "https://community.obsidian.md/plugins/docxidian"
    github_url:  "https://github.com/kpaede/docxidian"
    description: "Open, edit, and embed DOCX documents. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open .docx files directly inside Obsidian and edit them in-place, saving changes back to the original vault file. Embed read-only .docx documents in notes using ![[filename.docx]] for inline viewing."

        downloads:  958

    }
}
```
