# Edge TTS

Reads a selection or a whole note aloud through the Microsoft Edge read-aloud text-to-speech service, with a choice of voices and locales and adjustable playback speed. It can generate an MP3 and embed it, preview voices, and queue several notes for continuous playback with looping and auto-scroll, on desktop and mobile.
