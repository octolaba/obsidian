# Sidebar Resizer

Sidebar Resizer adjusts the width of the left and right sidebars. Widths increase or decrease in pixels or percent, sidebars toggle or expand and collapse between a standard width and zero, and the available width can be distributed evenly between the two.

```cue
plugin: {
    id:     "sidebar-resizer"
    name:   "Sidebar Resizer"
    author: "jeetsukumaran"
    repo:   "jeetsukumaran/obsidian-sidebar-resizer"

    html_url:    "https://community.obsidian.md/plugins/sidebar-resizer"
    github_url:  "https://github.com/jeetsukumaran/obsidian-sidebar-resizer"
    description: "Adjust the sidebar sizes easily."
    about:       "Adjust left and right sidebar widths in Obsidian. Increase or decrease sizes in px or %, toggle or expand/collapse to standard or zero widths, and evenly distribute widths between sidebars."
```
