# Glasp

Imports Glasp highlights and notes into the vault, writing them into a note in a chosen folder. A Glasp access token is used so the annotations mirrored in the vault stay in step with the ones in Glasp.

```cue
plugin: {
    id:     "glasp"
    name:   "Glasp"
    author: "glasp-co"
    repo:   "glasp-co/obsidian-glasp-plugin"

    html_url:    "https://community.obsidian.md/plugins/glasp"
    github_url:  "https://github.com/glasp-co/obsidian-glasp-plugin"
    description: "Import your Glasp highlights and notes into your vault."
    about:       "Import Glasp highlights and notes into Obsidian, exporting them to a note in a selected folder. Mirror Glasp annotations in your vault using your Glasp access token to keep highlights and notes synchronized."
```
