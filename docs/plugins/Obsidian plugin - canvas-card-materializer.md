# Canvas Card-Materializer

Canvas Card-Materializer converts Canvas text cards into Markdown files in a single action, replacing the nodes on the canvas while keeping the layout intact. Arrows are preserved as clickable backlinks, and notes are categorized automatically into folders derived from card color. Each generated file records canvas_id and canvas_color in its frontmatter.
