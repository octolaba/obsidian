# Mobile PDF Exporter

Mobile PDF Exporter exports preview-style PDFs on mobile and desktop in one click, laying the page out from the rendered preview DOM. Text stays selectable through a real PDF text layer, images are embedded, code, tables, quotes and callouts keep their styling, and blocks avoid breaking across pages where possible. Excalidraw files are exported as image PDFs with automatic lower-resolution retries and page slicing, and the interface text is Auto, Chinese or English with a bundled Chinese font for offline use.
