# Act Like VSCode

Act Like VSCode gives Obsidian VS Code-style tabs that preview on a single click and pin on a double click. The file explorer is colored by archive status, with unarchived notes green and archived notes gray, tag badges appear beside filenames, and minimalist file and folder icons replace the defaults.

    id:     "act-like-vscode"
    name:   "Act Like VSCode"
