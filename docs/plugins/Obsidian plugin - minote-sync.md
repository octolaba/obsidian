# Minote Sync

Minote Sync pulls Xiaomi Cloud notes into the vault, converting them to Markdown and saving them in a chosen folder. Creation and modification times are preserved, images are downloaded and converted, Xiaomi-specific tags are cleaned, and untitled notes receive generated titles. Updates run incrementally or as a forced full overwrite, and non-China Xiaomi cloud accounts are supported.
