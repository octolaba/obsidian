# Header Enhancer

Header Enhancer numbers Markdown headers hierarchically and keeps the numbering updated in real time across the vault. Links that point at a heading are rewritten automatically, and backlinks are batch-updated when a heading changes. Per-file defaults are read from YAML, and header and title fonts are customizable with live preview.

```cue
plugin: {
    id:     "header-enhancer"
    name:   "Header Enhancer"
    author: "hobeedzc"
    repo:   "hobeedzc/obsidian-header-enhancer-plugin"

    html_url:    "https://community.obsidian.md/plugins/header-enhancer"
    github_url:  "https://github.com/hobeedzc/obsidian-header-enhancer-plugin"
    description: "Level up your headers, customize your notes. Header Enhancer makes your notes header better and more useful."
    about:       "Auto-number Markdown headers hierarchically and update numbers in real time vault-wide. Rewrite [[file#header]] links automatically and batch-update backlinks when headings change. Apply per-file YAML defaults and customize header/title fonts with live preview."

    stats: {
        downloads:  10704
        updated_at: 1781620445000
    }
}
```
