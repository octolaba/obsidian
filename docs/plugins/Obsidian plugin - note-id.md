# Note ID

Note ID displays notes by their ID and sorts them alphanumerically, so related ideas cluster together and gaps in a sequence become visible — a structure aimed at manuscripts and at Zettelkasten Folgezettel. New notes can be created as continuations or branches, and an ID can be set relative to another note. It also builds a table-of-contents view and searches fuzzily by title, ID or TOC entry.
