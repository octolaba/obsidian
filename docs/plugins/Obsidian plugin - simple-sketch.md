# simple-sketch

simple-sketch adds a dedicated view for minimalist sketches with a small, productivity-focused interface. Drawing tools cover a freehand pencil, lines, rectangles, ellipses and text, alongside erase and undo. Finished sketches are saved into the vault or downloaded as an image.
