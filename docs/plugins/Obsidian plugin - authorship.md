# Authorship

Tracks authorship inside the editor, distinguishing typed from pasted input and highlighting AI-generated, pasted and reference text in color. A selection can be marked by hand as AI, Self or Reference, and highlighting can be toggled on demand. Annotations are stored at the end of the Markdown file following the Markdown Annotations specification with SHA-256 validation, and everything runs locally.

```cue
plugin: {
    id:     "authorship"
    name:   "Authorship"
    author: "rflpazini"
    repo:   "rflpazini/obsidian-authorship"

    html_url:    "https://community.obsidian.md/plugins/authorship"
    github_url:  "https://github.com/rflpazini/obsidian-authorship"
    description: "Track and visualize text authorship in the editor. Distinguishes typed, pasted, AI-generated, and reference text with color-coded highlights. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Track and visualize text authorship by detecting typed vs pasted input and highlighting AI-generated, pasted, and reference text in the editor. Mark selections manually as AI, Self, or Reference and toggle highlighting on demand. Store authorship annotations at the end of Markdown files using the Markdown Annotations spec with SHA-256 validation and operate fully locally."

    stats: {
        downloads:  161
        updated_at: 1775332950000
    }
}
```
