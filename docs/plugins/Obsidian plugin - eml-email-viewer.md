# EML Email Viewer

Opens local .eml files from the file explorer in a dedicated read-only view. Headers, plain text, sanitized HTML and the raw MIME source sit in separate tabs beside attachment metadata, parse warnings and a search box. Remote images, scripts, external styles, forms and active HTML attributes are blocked while a message is displayed.
