# Tidemark

Tidemark substitutes YAML frontmatter values into a note wherever a double-brace variable appears, and it supports defaults and nested dot paths. Filled values are copied or permanently replaced by line, by selection or across the whole document, and live color-coded highlights distinguish defined, fallback and missing variables.

```cue
plugin: {
    id:     "tidemark"
    name:   "Tidemark"
    author: "Real-Fruit-Snacks"
    repo:   "real-fruit-snacks/Tidemark"

    html_url:    "https://community.obsidian.md/plugins/tidemark"
    github_url:  "https://github.com/real-fruit-snacks/Tidemark"
    description: "Replace {{variables}} with YAML frontmatter values on demand - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Define variables in a note's YAML frontmatter and reference them with {{variable}}, {{var:default}} or nested dot paths to substitute values. Copy or permanently replace filled values by line, selection, or entire document and see live color-coded highlights for defined, fallback, and missing variables."

    stats: {
        downloads:  102
        updated_at: 1784469148000
    }
}
```
