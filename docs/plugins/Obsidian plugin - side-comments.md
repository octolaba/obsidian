# Side Comments

Side Comments annotates Markdown without touching the source file: highlights, underlines, strikethroughs and comments on selected text are stored in sidecar JSON files. The annotations are managed in a right-side panel, and each one links back to its place in the source.

```cue
plugin: {
    id:     "side-comments"
    name:   "Side Comments"
    author: "FAN"
    repo:   "guoxueziliao/side-comments"

    html_url:    "https://community.obsidian.md/plugins/side-comments"
    github_url:  "https://github.com/guoxueziliao/side-comments"
    description: "Non-invasive side comments and reading annotations for Obsidian Markdown notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Annotate Markdown with non-invasive side comments stored as sidecar JSON files so source files stay unchanged. Add highlights, underlines, strikethroughs, or comments to selected text and manage annotations in a right-side panel that links back to the source."

    stats: {
        downloads:  468
        updated_at: 1780038976000
    }
}
```
