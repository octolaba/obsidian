# Letterboxd Mirror

Letterboxd Mirror syncs Letterboxd diary entries into the vault as individual notes and can batch-import history from a Letterboxd export. Film notes are enriched with TMDB data, note templates are written with Eta, and synchronisation can run automatically at startup.
