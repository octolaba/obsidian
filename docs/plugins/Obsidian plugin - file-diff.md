# File Diff

File Diff compares the active file with another file and shows the differences inline. Changes are merged between the two files and applied as needed. It also finds Syncthing sync conflicts across the vault and steps through them so each conflict is merged in turn.

```cue

    id:     "file-diff"
    name:   "File Diff"
    author: "friebetill"
    repo:   "friebetill/obsidian-file-diff"

    github_url:  "https://github.com/friebetill/obsidian-file-diff"
```
