# Random broken link

Opens a random broken link from the vault, so unresolved links and the missing notes behind them come to the surface. Jumping through them leads to creating or repairing the target files and closing the holes in the graph.

```cue
plugin: {
    id:     "random-broken-link"
    name:   "Random broken link"
    author: "jantatesa"
    repo:   "jantatesa/obsidian-open-random-broken-link"

    html_url:    "https://community.obsidian.md/plugins/random-broken-link"
    github_url:  "https://github.com/jantatesa/obsidian-open-random-broken-link"
    description: "Expand your knowledge by visiting random broken links."
    about:       "Open a random broken link in your vault to surface missing notes and knowledge gaps. Jump through unresolved links to create or repair target files and close holes in your graph."

    stats: {
        downloads:  407
        updated_at: 1762074111000
    }
}
```
