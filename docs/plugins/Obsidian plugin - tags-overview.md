# Tags Overview

Tags Overview is an extended tags panel that lists tagged files as a list or a table and shows related tags beside them. Files can be filtered by several tags combined with AND or OR, and nested tags shown as a tree or as a flat list. Front-matter property filters narrow the result further.

```cue
plugin: {
    id:     "tags-overview"
    name:   "Tags Overview"
    author: "christianwannerstedt"
    repo:   "christianwannerstedt/obsidian-tags-overview"

    html_url:    "https://community.obsidian.md/plugins/tags-overview"
    github_url:  "https://github.com/christianwannerstedt/obsidian-tags-overview"
    description: "An extended tags panel where tagged files can be easily viewed, filtered, and accessed."
    about:       "Explore and manage tags with an extended panel that shows tagged files in list or table view and displays related tags. Filter by multiple tags (AND/OR), view nested tags as a tree or flat list, and add front-matter property filters to narrow results."

    stats: {

    }
}
```
