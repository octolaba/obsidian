# Importer

Converts data from other applications and file formats into plain-text Markdown files usable in Obsidian. The recorded sources include Apple Notes, Evernote, Notion, Google Keep, OneNote, Roam, Bear, CSV and HTML, among many other formats.

```cue
plugin: {
    id:     "obsidian-importer"
    name:   "Importer"
    author: "Obsidian"
    repo:   "obsidianmd/obsidian-importer"

    html_url:    "https://community.obsidian.md/plugins/obsidian-importer"
    github_url:  "https://github.com/obsidianmd/obsidian-importer"
    description: "Convert your data to Markdown files you can use in Obsidian. Works with Apple Notes, OneNote, Evernote, Notion, Google Keep, and many other formats."
    about:       "Import notes from other apps and file formats into your Obsidian vault. Convert them to plain-text Markdown with support for Apple Notes, Evernote, Notion, Google Keep, OneNote, Roam, Bear, CSV, HTML and more."
```
