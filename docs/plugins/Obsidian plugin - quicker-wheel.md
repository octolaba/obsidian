# Quicker Wheel

Opens a Quicker-style radial command wheel from a tap or a floating button, giving access to Obsidian commands, files, URIs and scripts. Actions run through eight-direction swipes, a short press opens the wheel and a long press with drag moves the button. Slots are bound to commands or files, and tapping an empty cell creates an action.
