# NerdFont Icon Picker

NerdFont Icon Picker adds a searchable Nerd Font icon picker for inserting icons into notes and into interface elements. Rendering those icons correctly requires setting a Nerd Font as the text and interface font.

```cue

    id:     "nerdfont-icon-picker"
    name:   "NerdFont Icon Picker"
    author: "xavwe"
    repo:   "xavwe/obsidian-nerdfont-icon-picker"
```
