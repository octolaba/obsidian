# Temp Note Maker

Temp Note Maker creates date-stamped temporary notes for short-term use. Expired notes are removed according to a retention period in days, either automatically at startup or on demand from the command palette.

```cue
plugin: {
    id:     "tmp-maker"
    name:   "Temp Note Maker"
    author: "maiananthan"
    repo:   "maiananthan/tmp-maker"

    html_url:    "https://community.obsidian.md/plugins/tmp-maker"
    github_url:  "https://github.com/maiananthan/tmp-maker"
    description: "Creates temporary notes with today's date and auto-cleans old notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create date-stamped temporary notes for short-term use. Remove expired temp files automatically at startup or on demand via the command palette based on retention days."
```
