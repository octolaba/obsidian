# Scroll to Top

This plugin adds a status-bar button that jumps to the top, or to the bottom, of the current note. A ribbon button scrolls to the cursor or the selection in edit mode, and the button style and behavior are customizable.

```cue
plugin: {
    id:     "obsidian-scroll-to-top-plugin"
    name:   "Scroll to Top"
    author: "cloudhao1999"
    repo:   "cloudhao1999/obsidian-scroll-to-top-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-scroll-to-top-plugin"
```
