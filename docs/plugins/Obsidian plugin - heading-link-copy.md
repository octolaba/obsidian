# Heading Linker and Refactor

Heading Linker and Refactor copies a Markdown link to a heading from the editor or from the outline through the right-click menu. The path can be relative or full-vault, and parent headings can be included to build a hierarchical anchor or left out to link only the target heading.

```cue
plugin: {
    id:     "heading-link-copy"
    name:   "Heading Linker and Refactor"
    author: "wilmtang"
    repo:   "wilmtang/obsidian-heading-linker"

    html_url:    "https://community.obsidian.md/plugins/heading-link-copy"
    github_url:  "https://github.com/wilmtang/obsidian-heading-linker"
    description: "Copy a markdown link to a heading with configurable path and hierarchy. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Copy markdown links to specific headings from the editor or outline via right-click. Choose relative or full-vault paths and include parent headings to create hierarchical anchors or link only the target heading."

    stats: {
        downloads:  177
        updated_at: 1783729137000
    }
}
```
