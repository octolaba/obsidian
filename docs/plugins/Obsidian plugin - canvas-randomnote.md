# Canvas Random Note

Canvas Random Note adds random notes from the vault to the active canvas in a grid, drawn either from all markdown files or from the results of the current search. The inputs warn against running its commands in rapid succession, because it edits canvas data directly and the canvas may go out of sync.

```cue
plugin: {
    id:     "canvas-randomnote"
    name:   "Canvas Random Note"
    author: "jmilldotdev"
    repo:   "jmilldotdev/obsidian-canvas-randomnote"

    html_url:    "https://community.obsidian.md/plugins/canvas-randomnote"
    github_url:  "https://github.com/jmilldotdev/obsidian-canvas-randomnote"
    description: "Add random notes from your vault to the canvas."
    about:       "Add random notes to the active Canvas in a grid, selecting from all markdown files or from results of the current search. Avoid running commands in rapid succession, as the plugin edits Canvas data directly and may cause the Canvas to go out of sync."
```
