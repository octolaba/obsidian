# Task Manager

Task Manager collects daily reports, unfinished and overdue tasks, and future plans into a compact right sidebar. Today's daily report can be opened or created from that sidebar without overwriting an existing note. Markdown checklists are gathered from daily notes and grouped by planned date and status, future items are kept in one file, and completion timestamps are written back into the source notes.
