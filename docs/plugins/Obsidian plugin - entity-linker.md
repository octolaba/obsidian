# Entity Linker

Links selected text or the title of the active note to standard entities from OpenAlex, Wikidata and Wikipedia. Matching entities are suggested for a research term, and entity notes are created from the OpenAlex search results.

```cue
plugin: {
    id:     "entity-linker"
    name:   "Entity Linker"
    author: "ankush-chander"
    repo:   "ankush-chander/obsidian-entity-linker"

    html_url:    "https://community.obsidian.md/plugins/entity-linker"
    github_url:  "https://github.com/ankush-chander/obsidian-entity-linker"
    description: "Link research terms to standard entities"
    about:       "Link selected text or the active note title to standard entities from OpenAlex, Wikidata, and Wikipedia. Suggest matching entities and create corresponding entity notes using OpenAlex search results."

    stats: {
        downloads:  670
        updated_at: 1721197165000
    }
}
```
