# Smart Fold

Smart Fold gives fine-grained control over folding Markdown heading sections. Individual levels from H1 to H6 can be toggled, a Smart Fold command collapses leaf-node sections, and the global fold depth is increased or decreased with commands. Files can be folded automatically when opened, and ribbon icons give quick access.

```cue
plugin: {
    id:     "smart-fold"
    name:   "Smart Fold"
    author: "shenfan19"
    repo:   "shenfan19/smart-fold"

    html_url:    "https://community.obsidian.md/plugins/smart-fold"
    github_url:  "https://github.com/shenfan19/smart-fold"
    description: "Smart tools for efficiently folding markdown sections. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Control Markdown heading folding with precise, lightweight tools. Toggle individual H1–H6 levels, apply Smart Fold to collapse leaf-node sections, increase or decrease global fold depth, auto-fold on file open, and add ribbon icons for quick access."
```
