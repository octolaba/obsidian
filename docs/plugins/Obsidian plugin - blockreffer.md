# Blockreffer

Blockreffer searches the vault for blocks that carry a block id and shows the matching results. Selected blocks can be embedded into a note, producing block-level links that reuse content across files.

```cue
plugin: {
    id:     "blockreffer"
    name:   "Blockreffer"
    author: "tyler-dot-earth"
    repo:   "tyler-dot-earth/obsidian-blockreffer"

    html_url:    "https://community.obsidian.md/plugins/blockreffer"
    github_url:  "https://github.com/tyler-dot-earth/obsidian-blockreffer"
    description: "Search and embed blocks with ^block-references."
    about:       "Search your vault for blocks referenced with ^block-refs (block IDs) and display matching results. Embed those referenced blocks into notes to create direct block-level links and reuse content across files."

    stats: {
        downloads:  1878

    }
}
```
