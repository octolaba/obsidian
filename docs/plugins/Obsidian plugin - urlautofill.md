# Extended Browser

Embeds websites inside Obsidian so that pages can be viewed without leaving the vault. When such an embedded site is opened, the plugin fills in the URL and the login credentials automatically.

```cue
plugin: {
    id:     "urlautofill"
    name:   "Extended Browser"
    author: "Sharbel Marshi"
    repo:   "sharbelmarshi/obsidian-url-autofill-plugin"

    html_url:    "https://community.obsidian.md/plugins/urlautofill"
    github_url:  "https://github.com/sharbelmarshi/obsidian-url-autofill-plugin"
    description: "Embed websites and automatically fill URLs and login credentials when you open them. - This plugin has not been manually reviewed by Obsidian staff."

    stats: {
        downloads:  153
        updated_at: 1783177127000
    }
}
```
