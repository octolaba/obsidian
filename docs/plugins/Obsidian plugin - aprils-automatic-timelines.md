# April Automatic Timelines

Generates timelines from notes tagged with date metadata, for storytelling and historical overviews. Notes carrying start and end dates together with a render flag become event cards whose title, body and image can be overridden per card. A timeline is assembled by inserting a timeline code block, and the rendering is theme-agnostic.
