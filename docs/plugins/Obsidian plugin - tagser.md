# Tagser

Tagser edits the tags property of a note from the right pane while that note is open. Individual tag values can be added, removed or renamed, and the updates are applied to the note in real time.

```cue
plugin: {
    id:     "tagser"
    name:   "Tagser"
    author: "caorol"
    repo:   "caorol/obsidian-plugin-tagser"

    html_url:    "https://community.obsidian.md/plugins/tagser"
    github_url:  "https://github.com/caorol/obsidian-plugin-tagser"
    description: "Edit the value of the `tags` property. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Edit a note’s tags directly from the right pane while the note is open. Add, remove, or rename individual tag values and have updates applied to the note in real time."
```
