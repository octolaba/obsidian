# Scrybble

Scrybble synchronises documents from a reMarkable tablet into the vault. Each document arrives as a single page-organized Markdown file whose handwritten notes, highlights and typed text are searchable, with reMarkable tags kept in frontmatter and page headings.

```cue
plugin: {
    id:     "scrybble.ink"
    name:   "Scrybble"
    author: "scrybbling-together"
    repo:   "scrybbling-together/scrybble"

    html_url:    "https://community.obsidian.md/plugins/scrybble.ink"
    github_url:  "https://github.com/scrybbling-together/scrybble"
    description: "Synchronize highlights from your ReMarkable tablet."
    about:       "Sync handwritten notes, highlights and typed text from your reMarkable tablet into Obsidian as a single, page-organized Markdown file per document with searchable content. Bring ebooks, PDFs and quick notes into your vault and keep reMarkable tags in frontmatter and page headings for easy organization."
```
