# Claude Sidebar

Runs Claude Code in the Obsidian sidebar and provides a full embedded terminal for interactive sessions. Several Claude tabs can sit side by side, and a session can be launched from a folder's context menu, including in YOLO mode. The backend can be switched between Claude Code, Codex, OpenCode and Gemini CLI.

```cue
plugin: {
    id:     "claude-sidebar"
    name:   "Claude Sidebar"
    author: "derek-larson14"
    repo:   "derek-larson14/obsidian-claude-sidebar"

    html_url:    "https://community.obsidian.md/plugins/claude-sidebar"
    github_url:  "https://github.com/derek-larson14/obsidian-claude-sidebar"
    description: "Run Claude Code in your sidebar. - This plugin has not been manually reviewed by Obsidian staff."

Open multiple Claude tabs side-by-side, launch sessions from a folder's context menu (including YOLO mode), and switch between Claude Code, Codex, OpenCode, or Gemini CLI backends."
