# Kikijiki Habit Tracker

Tracks habits inside notes by adding configurable habit tags, using a prefix and habit name, to the current document. A Habit Panel shows the resulting overview, which can be managed and positioned.

```cue

    id:     "kikijiki-habit-tracker"
    name:   "Kikijiki Habit Tracker"
    author: "kikijiki"
    repo:   "kikijiki/obsidian-habit-tracker"

    html_url:    "https://community.obsidian.md/plugins/kikijiki-habit-tracker"
```
