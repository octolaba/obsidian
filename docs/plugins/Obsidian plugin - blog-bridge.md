# Blog Bridge

Blog Bridge syncs Markdown notes to GitHub-backed static-site blogs, committing post files and images directly or opening a pull request from a custom branch. Framework presets map paths and frontmatter, preserving existing metadata and filling in a missing title or date. A sync status page batch-syncs and tracks which notes have been modified.

    id:     "blog-bridge"
    name:   "Blog Bridge"
