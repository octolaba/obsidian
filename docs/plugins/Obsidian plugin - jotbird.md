# JotBird

JotBird publishes a note from the vault to a shareable web page on JotBird with one click, and no account is required. Local images are uploaded automatically, and callouts and Mermaid diagrams are rendered on the published page. The published URL and its expiration date are saved into the note's frontmatter.

```cue
plugin: {
    id:     "jotbird"
    name:   "JotBird"
    author: "jotbirdhq"
    repo:   "jotbirdhq/obsidian-jotbird"

    html_url:    "https://community.obsidian.md/plugins/jotbird"
    github_url:  "https://github.com/jotbirdhq/obsidian-jotbird"
```
