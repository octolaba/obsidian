# Automation

Automation executes command-palette commands when specified Obsidian events occur. Any available command can be linked to an event, so the action runs automatically across the vault.

```cue
plugin: {
    id:     "automation"
    name:   "Automation"
    author: "benature"
    repo:   "benature/obsidian-automation"

    html_url:    "https://community.obsidian.md/plugins/automation"
    github_url:  "https://github.com/benature/obsidian-automation"
    description: "Execute commands on specific events."
    about:       "Trigger command-palette commands when specified Obsidian events occur. Link events to any available command to run actions automatically across your vault."

    stats: {
        downloads:  5207
        updated_at: 1717155455000
    }
}
```
