# Editor Autofocus

Focuses the editor when a note shorter than three lines is opened, so typing can start immediately. If that note begins with a heading, the first line is selected instead, so the title can be renamed directly.

```cue
plugin: {
    id:     "editor-autofocus"
    name:   "Editor Autofocus"
    author: "mgussekloo"
    repo:   "mgussekloo/obsidian-editor-autofocus"

    html_url:    "https://community.obsidian.md/plugins/editor-autofocus"
    github_url:  "https://github.com/mgussekloo/obsidian-editor-autofocus"
    description: "Autofocus the editor when opening a new file."
    about:       "Autofocus the editor when opening notes shorter than three lines to start typing immediately. Select the first-line heading (if present) to rename the title directly."

    stats: {
        downloads:  2617
        updated_at: 1699819284000
    }
}
```
