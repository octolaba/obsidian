# Bangumi Sync

Bangumi Sync imports Bangumi favorites into notes, carrying over ratings, short reviews, tags and progress in episodes, volumes or chapters for anime, manga, novels, games and music. Templates generate Dataview-ready info tables, and two-way sync for comments and tags, conflict detection, batch editing and automatic syncing can be enabled.

    id:     "bangumi-sync"
    name:   "Bangumi Sync"
