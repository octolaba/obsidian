# Orthography

This plugin checks and fixes orthography errors in text, covering English spelling and grammar with one-click corrections and inline suggestions. It offers error search and optional Todo and Grammarly integration. The recorded text describes it as an alpha build that can be unstable, does not work reliably in Live Preview, and advises backing up notes.
