# Geulo

Imports liked YouTube videos and playlists into Obsidian so they can be searched and organized alongside notes. Videos are searched and filtered by type, turned into notes in one click, added to the daily note and summarized by AI, and liked videos can be removed from the sidebar.

```cue
plugin: {
    id:     "geulo-youtube-liked-video"
    name:   "Geulo"
    author: "Junyoung Bang"
    repo:   "zzunebye/obsidian-google-liked-video"

    html_url:    "https://community.obsidian.md/plugins/geulo-youtube-liked-video"
    github_url:  "https://github.com/zzunebye/obsidian-google-liked-video"
    description: "Fetch all the YouTube videos you have liked, search and sort them with multiple sort options, and add them to your daily note."
    about:       "Import your YouTube liked videos and playlists into Obsidian for searchable, organized access alongside your notes. Generate AI video summaries, create one-click video notes, add videos to daily notes, search and filter by type, and remove liked videos from the sidebar."

    stats: {
        downloads:  1800
        updated_at: 1771555268000
    }
}
```
