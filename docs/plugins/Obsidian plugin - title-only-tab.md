# Title-Only Tab

Title-Only Tab sets the name of an editor tab to the title value in a note's YAML frontmatter, aimed at Jekyll users. Long filenames are replaced by the frontmatter title so that tab labels stay concise and readable.

```cue
plugin: {
    id:     "title-only-tab"
    name:   "Title-Only Tab"
    author: "tristone13th"
    repo:   "tristone13th/obsidian-title-only-tab"

    html_url:    "https://community.obsidian.md/plugins/title-only-tab"
    github_url:  "https://github.com/tristone13th/obsidian-title-only-tab"
    description: "Set tab name to title in frontmatter for Jekyll users"
    about:       "Set tab names to the YAML frontmatter \"title\" value for Jekyll notes. Replace long filenames in editor tabs with the frontmatter title to display concise, readable tab labels."

}
```
