# Simple Folder Icon

Simple Folder Icon adds an icon before the name of configured folders in the file explorer. The SVG files can live anywhere in the vault, and the folder and icon pairs are managed from the plugin settings.

```cue
plugin: {
    id:     "simple-folder-icon"
    name:   "Simple Folder Icon"
    author: "Mirco Macrelli"
    repo:   "mircomacrelli/simple-folder-icon"

    html_url:    "https://community.obsidian.md/plugins/simple-folder-icon"
    github_url:  "https://github.com/mircomacrelli/simple-folder-icon"
    description: "Automatically add an icon before the name of the configured folders in the file explorer. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add an icon before the name of configured folders in the file explorer. Place SVG files anywhere in your vault and manage folder–icon pairs from the plugin settings."

    stats: {
        downloads:  60
        updated_at: 1782552515000
    }
}
```
