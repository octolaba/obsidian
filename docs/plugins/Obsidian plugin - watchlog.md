# WatchLog

WatchLog tracks anime, movies and TV shows with episode-level progress, watchlists, groups, pins and fuzzy search, plus widgets that embed in notes. It shows per-type progress, time watched and time remaining, and suggestions, and it can schedule recurring release alerts with countdowns.
