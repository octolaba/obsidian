# Hydrate

Hydrate is a note agent with MCP support that answers questions about the vault, summarizes, and surfaces connections between notes. It searches by meaning, generates outlines and content, and synthesizes research material. Its recorded inputs state that an account and a subscription are needed for the AI features, that it connects to remote AI services, and that anonymous analytics are collected.
