# Lavadocs

Lavadocs shares one-off notes from the vault as hosted, shareable copies through a sidebar action. Authentication uses a Lava Key or the URL of a self-hosted Lavadocs instance.

```cue
plugin: {
    id:     "lavadocs"
    name:   "Lavadocs"
    author: "saaliklok"
    repo:   "saaliklok/lavadocs-obsidian"

    html_url:    "https://community.obsidian.md/plugins/lavadocs"
    github_url:  "https://github.com/saaliklok/lavadocs-obsidian"
    description: "Public docs, from the fires of your vault."
    about:       "Share one-off Obsidian notes to Lavadocs via a sidebar action to create shareable, hosted copies. Connect using your Lava Key or a self-hosted Lavadocs URL to authenticate and publish notes instantly."

        downloads:  944

}
```
