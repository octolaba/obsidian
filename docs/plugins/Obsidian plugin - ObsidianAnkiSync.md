# Anki Sync

Anki Sync writes flashcards in Obsidian with a markup-based syntax and synchronizes them to Anki through sync blocks that create, update and delete cards. Markdown math, code, images and tables are rendered, and cloze deletions work inside LaTeX and code or through highlights and clozeblock. Decks can be backed up automatically and targeted per file or per block.

    id:     "ObsidianAnkiSync"
