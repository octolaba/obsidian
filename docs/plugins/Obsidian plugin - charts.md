# Charts for Bases

The plugin adds a chart layout to Bases, so a set of notes can be displayed as interactive bar or line charts. The layout is drawn without external dependencies and reads note properties for its axes.

```cue
plugin: {
    id:     "charts"
    name:   "Charts for Bases"
    author: "Nikita Gaziev"
    repo:   "zobweyt/obsidian-charts"

    html_url:    "https://community.obsidian.md/plugins/charts"
    github_url:  "https://github.com/zobweyt/obsidian-charts"
    description: "Adds a chart layout to bases so you can display notes as interactive bar or line charts. - This plugin has not been manually reviewed by Obsidian staff."

    stats: {
        downloads:  885
        updated_at: 1782058389000
    }
}
```
