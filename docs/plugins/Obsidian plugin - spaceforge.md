# Spaceforge

Notes are turned into flashcards scheduled by FSRS or by an enhanced SM-2 algorithm, and multiple-choice questions are generated from note content by AI. A dedicated sidebar lists the items coming up for review. An integrated Pomodoro timer runs focused study sessions and tracks progress, and the recorded description also names a calendar event manager.
