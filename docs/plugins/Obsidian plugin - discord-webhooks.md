# Discord Webhooks

Stores several Discord webhooks for reuse, with one of them set as the default for sending selected text from the editor or preview. Preset messages, including rich embed JSON, can be created, edited and sent through any saved webhook, and each preset is exposed as its own command.

```cue
plugin: {
    id:     "discord-webhooks"
    name:   "Discord Webhooks"
    author: "Rato Kuzmanić"
    repo:   "ratokuzmanic/obsidian-discord-webhooks"

    html_url:    "https://community.obsidian.md/plugins/discord-webhooks"
    github_url:  "https://github.com/ratokuzmanic/obsidian-discord-webhooks"
    description: "Send selected text or preset messages using saved Discord webhooks. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Save multiple Discord webhooks for reuse and pick a default to send selected text directly from the editor or preview. Create, edit, and send preset messages (including rich embed JSON) through any saved webhook and expose one-command-per-message commands for quick sending."

    stats: {
        downloads:  316
        updated_at: 1780749316000
    }
}
```
