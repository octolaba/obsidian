# Graph Explorer Base View

Adds a Bases view that renders the notes matching a Base query as an interactive force-directed graph, keeping node positions per view. Explored and unexplored state and maturity are tracked through frontmatter, and roles, confidence, tags or dates can drive node colour and shape. Notes open in a resizable side panel.

    id:     "graph-explorer-base-view"
    name:   "Graph Explorer Base View"
    author: "Sébastien Dubois"

    html_url:    "https://community.obsidian.md/plugins/graph-explorer-base-view"

Track explored/unexplored state and maturity via frontmatter, visualize roles, confidence, tags or dates with node color/shape, and open notes in a resizable side panel."
