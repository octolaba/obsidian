# Pokemon Showdown Viewer

Pokemon Showdown Viewer renders teams built in the Pokemon Showdown team builder as readable cards inside Obsidian. A showdown code block is pasted into the note, and each entry's species, item, ability, EVs, nature and moves are laid out in a formatted view.

```cue
plugin: {
    id:     "showdown-viewer"
    name:   "Pokemon Showdown Viewer"
    author: "lwatson"
    repo:   "watsonlu/obsidian-showdown-viewer"

    html_url:    "https://community.obsidian.md/plugins/showdown-viewer"
    github_url:  "https://github.com/watsonlu/obsidian-showdown-viewer"
    description: "Renders Pokemon built using the Pokemon Showdown team builder in Obsidian. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render Pokémon teams in Pokémon Showdown format as clean, readable cards inside Obsidian. Paste a \"showdown\" code block to display each Pokémon's species, item, ability, EVs, nature, and moves in a formatted view."

    stats: {
        downloads:  90
        updated_at: 1781615553000
    }
}
```
