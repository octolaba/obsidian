# MDFriday Sync

Synchronizes an Obsidian vault across desktop and mobile through CouchDB replication, with end-to-end AES-256 and HKDF encryption. A managed backend is used or a server self-hosted, hidden configuration files are included, and conflicts are resolved during live sync. Sync is restricted selectively by file type.
