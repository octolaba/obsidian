# Vault Timeline

Indexes every note by date into a global chronological timeline, taking the date from YAML frontmatter and falling back to the file creation time. Day, week, month, year and decade views can be switched, events colored by tag, start and end dates rendered as spans, and results searched and filtered by tags or folders. A minimap and tooltips accompany the view, and clicking or right-clicking an event opens the note or runs a quick action.
