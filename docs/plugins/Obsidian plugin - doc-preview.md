# Doc Preview

Previews PowerPoint and Word documents inside Obsidian through a headless local LibreOffice installation, so the real application never opens. Previews refresh when the file changes on disk, including edits made by an AI agent, and jump to the changed slide or page. The viewer offers zoom, rotation, a thumbnail rail, arrow-key navigation and download, and is desktop only.
