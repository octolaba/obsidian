# Copy as Latex

Copy as Latex converts Obsidian Markdown into LaTeX-ready output, mapping headings, bold and italic text, math, lists and links to their LaTeX equivalents. Code blocks keep their language for listings, internal citations become cite commands and caret references become ref commands, which is aimed at export.

```cue
plugin: {
    id:     "copy-as-latex"
    name:   "Copy as Latex"
    author: "mo-seph"
    repo:   "mo-seph/obsidian-copy-as-latex"

    html_url:    "https://community.obsidian.md/plugins/copy-as-latex"
    github_url:  "https://github.com/mo-seph/obsidian-copy-as-latex"
    description: "Quickly copy Markdown as LaTeX, with citations."
    about:       "Convert Obsidian Markdown into LaTeX-ready output, mapping headings, bold/italic, math, lists and links to their LaTeX equivalents. Preserve code blocks with language for listings, turn internal @citations into \\cite and ^references into \\ref for easy export."
```
