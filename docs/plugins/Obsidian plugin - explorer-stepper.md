# Explorer Stepper

Moves to the previous or next file in the current folder with configurable hotkeys. Only direct child files count — Markdown, images, PDFs and Canvas — nested folders are excluded, and names are ordered with locale-aware natural sorting so file2 precedes file10. Stepping stops at the first and last file instead of wrapping, and notices appear in English or Chinese.

```cue
plugin: {
    id:     "explorer-stepper"
    name:   "Explorer Stepper"
    author: "kefate"
    repo:   "kefate/obsidian-explorer-stepper"

    html_url:    "https://community.obsidian.md/plugins/explorer-stepper"
    github_url:  "https://github.com/kefate/obsidian-explorer-stepper"
    description: "Navigate to the previous or next file in the current folder. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Navigate to the previous or next file in the current folder using configurable hotkeys. Include direct child files (Markdown, images, PDFs, Canvas), sort names with locale-aware natural ordering so file2 comes before file10, exclude nested folders, and stop at the first/last file without wrapping while showing notices in English or Chinese."

    stats: {
        downloads:  90
        updated_at: 1781517480000
    }
}
```
