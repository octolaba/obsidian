# AI for Templater

Extends the Templater plugin so templates can call OpenAI-compatible LLMs directly. Template commands generate text, ask questions and insert the model response into the note. Local models are supported as well as the OpenAI API, which needs an API key and an internet connection.

```cue
plugin: {
    id:     "ai-templater"
    name:   "AI for Templater"
    author: "tfthacker"
    repo:   "tfthacker/obsidian-ai-templater"

    html_url:    "https://community.obsidian.md/plugins/ai-templater"
    github_url:  "https://github.com/tfthacker/obsidian-ai-templater"
    description: "AI Extension for the Templater plugin with the OpenAI Client Library."
    about:       "Extend Templater to call OpenAI-compatible LLMs directly from your templates. Generate text, ask questions, and insert model responses into notes with simple Templater commands. Support local models or the OpenAI API (requires API key and internet for OpenAI)."

    stats: {
        downloads:  12881
        updated_at: 1774710452000
    }
}
```
