# Adamantine Pick

Adamantine Pick renders Pikchr diagrams as inline SVG inside notes, client-side and offline, without installing or compiling Pikchr. Fenced pikchr code blocks become viewable diagrams, and the embeddable SVG stays available for styling or scripting.
