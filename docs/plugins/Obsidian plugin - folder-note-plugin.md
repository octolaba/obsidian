# Folder Note

Attaches a descriptive Markdown note to a folder, opened by clicking that folder in the file explorer. New folder notes are created with a modifier click, using an inside-folder, outside-folder or index-file method. Folder contents are displayed as a card or strip overview, and folder and note names are kept in sync.
