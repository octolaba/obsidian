# Atomic

Syncs notes to an Atomic server so the vault can be searched by meaning, combining keyword and vector results with snippets. Similar notes surface in a sidebar, wiki articles are synthesized by a language model with citations, and an agentic retrieval assistant answers questions in chat. A spatial knowledge-graph canvas is provided for exploring the result.
