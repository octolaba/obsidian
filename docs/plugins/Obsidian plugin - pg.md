# Postgres DB

Postgres DB connects to multiple PostgreSQL databases and runs SQL written in fenced code blocks inside the vault. Queries execute inline and results are browsed in a side panel with scrollable tables and cell popups. The recorded inputs also list schema-aware autocomplete and export of results as timestamped CSV files.
