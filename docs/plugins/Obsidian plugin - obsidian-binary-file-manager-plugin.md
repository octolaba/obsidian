# Binary File Manager

Binary File Manager detects new binary files in the vault, such as images and PDFs, and creates a Markdown file of metadata for each. That companion note exposes the binary to full-text search, tags, aliases and internal or embedded links, and its metadata is generated from customizable templates or through Templater.
