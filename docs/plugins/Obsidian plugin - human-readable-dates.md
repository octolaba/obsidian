# Human Readable Dates

Human Readable Dates displays dates in Live Preview as relative phrases such as Yesterday, 2 hours ago or In 3 days, while the original date strings stay in the note. Moving the cursor onto a transformed date reveals the original text for editing, and the relative display returns once the cursor moves away.

    id:     "human-readable-dates"
    name:   "Human Readable Dates"

    github_url:  "https://github.com/tbergeron/obsidian-human-readable-dates"
    description: "Displays dates as human-readable relative dates in live preview. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Transform dates in Live Preview into human-readable relative phrases like \"Yesterday\", \"2 hours ago\", or \"In 3 days\" while preserving the original date strings in your notes. Reveal and edit the original date by moving the cursor over any transformed date; the human-readable display returns when you move the cursor away."
