# Explorer Hider

Hides files and folders from the explorer and from bookmarks by maintaining CSS rules automatically. Rules are added from the right-click menu, matching a file exactly and a folder by prefix, and they stay editable; an eye button in the ribbon toggles visibility. The rules are either saved as a snippet or injected directly.

```cue
plugin: {
    id:     "explorer-hider"
    name:   "Explorer Hider"
    author: "Mara"
    repo:   "mara-li/obsidian-explorer-hider"

    html_url:    "https://community.obsidian.md/plugins/explorer-hider"
    github_url:  "https://github.com/mara-li/obsidian-explorer-hider"
    description: "Hide a file or a folder from the explorer (and bookmarks) using a little bit of auto-managed CSS."
    about:       "Hide files and folders from the Explorer and Bookmarks using persistent, editable CSS rules. Manage rules via right-click (exact-match for files, starts-with for folders), toggle visibility with the eye ribbon button, and save rules as a snippet or inject them directly."
```
