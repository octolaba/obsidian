# Article Annotator

Highlights article content and attaches annotations to the selected text, collecting the annotation cards in the sidebar for review. Cards are reordered by drag-and-drop and clicked to jump back to the original text. The recorded description models the interface on the commenting interface of Microsoft Word and states that only Windows is supported at present.
