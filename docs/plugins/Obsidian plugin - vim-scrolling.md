# Vim Scrolling

Vim Scrolling adds vim-style scrolling to reading mode when Obsidian's vim key bindings are enabled. It intercepts j, k, Ctrl+D, Ctrl+U, gg and G to scroll instantly by line, by half a page, or to the top and bottom. Switching back to source mode realigns the editor cursor.

```cue
plugin: {
    id:     "vim-scrolling"
    name:   "Vim Scrolling"
    author: "xlongfeng"
    repo:   "xlongfeng/obsidian-vim-scrolling"

    html_url:    "https://community.obsidian.md/plugins/vim-scrolling"
    github_url:  "https://github.com/xlongfeng/obsidian-vim-scrolling"
    description: "Adds vim-style scrolling (j/k, Ctrl+D/U, gg, G) in reading mode when vim key bindings are enabled. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add vim-style scrolling to reading mode when Obsidian's vim key bindings are enabled. Intercept j, k, Ctrl+D, Ctrl+U, gg and G to scroll instantly (line, half-page, top/bottom) and realign the editor cursor when switching back to source mode."
```
