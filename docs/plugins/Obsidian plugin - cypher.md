# Cypher

Hides the text of a note behind a diagrammatic, icon-based cypher, so the content is unrecognizable to a viewer. Text is transformed in real time or over a selected passage, upper- and lowercase letters use distinct icons, and backspace handling keeps edits clean. A single toggle reverts to plain text.
