# Canvas Enhance

Canvas Enhance extends Obsidian Canvas with an Overview Mode, a keyboard-driven mindmap, a slide-style presentation mode, flowchart shapes and richer node and edge styling. Nodes stay navigable and readable when zoomed out, Tab and Enter create child and sibling nodes, and presentations run fullscreen with transitions. Canvas files are also integrated into the graph and backlinks.
