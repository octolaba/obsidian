# HTML Viewer

HTML Viewer renders HTML and HTM files inside Obsidian in a sandboxed view with scripts off by default. Scripts can be switched on for games, D3 or ECharts visualizations, WebGL visuals and other interactive documents, and the view toggles between raw source and rendered output or refreshes the file from disk.

```cue
plugin: {
    id:     "html-viewer"
    name:   "HTML Viewer"
    author: "jialinzhang24"
    repo:   "jialinzhang24/obsidian-html-viewer"

    html_url:    "https://community.obsidian.md/plugins/html-viewer"
    github_url:  "https://github.com/jialinzhang24/obsidian-html-viewer"
    description: "Render .html files in a sandboxed view. Toggle scripts ON for games, visualizations, and interactive documents. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render .html/.htm files directly inside Obsidian. Sandbox content by default (Scripts OFF) and toggle Scripts ON for games, D3/ECharts, WebGL visuals, or other interactive documents. Switch between raw source and rendered view and refresh files from disk."

    stats: {
        downloads:  1972
        updated_at: 1778379232000
    }
}
```
