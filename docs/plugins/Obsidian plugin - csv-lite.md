# CSV Lite

Opens and edits a CSV file in a workspace view as a readable table, with numbered rows and columns, search, a pinned column, a raw source toggle and inline cell editing. Rows and columns are managed from the header's right-click menu. Delimiters are detected automatically and can be switched non-destructively, and URLs and Markdown links render as clickable.
