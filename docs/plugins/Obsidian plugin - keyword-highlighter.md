# Keyword Highlighter

Highlights configured keywords in notes using custom font and background colors, so they stand out while scanning. Keywords can be added, edited or removed, and matching can be case-sensitive or case-insensitive. Default tags such as TODO, ADD and FIXME are provided, and regex patterns can be defined for more advanced matching.

```cue
plugin: {
    id:     "keyword-highlighter"
    name:   "Keyword Highlighter"
    author: "marcel-goldammer"
    repo:   "marcel-goldammer/obsidian-keyword-highlighter"

    html_url:    "https://community.obsidian.md/plugins/keyword-highlighter"
    github_url:  "https://github.com/marcel-goldammer/obsidian-keyword-highlighter"
    description: "Automatically highlight specified keywords within your notes for enhanced visibility and quick reference."
    about:       "Highlight configured keywords in your notes with custom font and background colors for quick visual scanning. Add, edit, or remove keywords and choose case-sensitive or case-insensitive matching. Use default tags like TODO, ADD, FIXME or define regex patterns for advanced matching."
```
