# Semantic Notes Vault MCP

Semantic Notes Vault MCP runs a Model Context Protocol server inside the vault, exposing notes to assistants that speak MCP, among them Claude Desktop, Claude Code, Continue, Cline and Copilot. A one-click .mcpb bundle wires up Claude Desktop and other compatible applications. Through the server an assistant gets semantic search, link and graph traversal and read-write access, so that it can explore concepts and synthesize across notes rather than reading one file at a time.
