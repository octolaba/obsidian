# Check and Delete

Check and Delete removes completed checklist items with a single button press. It recognizes the Markdown checklist markers for a checked line and deletes those lines, which is aimed at clearing temporary list items quickly.

```cue
plugin: {
    id:     "check-and-delete"
    name:   "Check and Delete"
    author: "danitiate"
    repo:   "danitiate/check-and-delete"

    html_url:    "https://community.obsidian.md/plugins/check-and-delete"
    github_url:  "https://github.com/danitiate/check-and-delete"
    description: "Quickly clean up temporary list-items with the press of a button"
    about:       "Delete completed checklist items with a single button press. Recognize Markdown checklist markers like (x) or (X) and remove checked lines instantly to save time on cleanup."
```
