# Iconify

Iconify adds custom icons to Obsidian under unique iconId identifiers and allows default application icons to be swapped out. The icons integrate with plugins such as Callout Manager, Commander and Better Properties, and its recorded inputs note that Obsidian must be restarted after new icons are added.

plugin: {
    id:     "iconify"
    name:   "Iconify"
    author: "Moz"
    repo:   "moziar/Obsidian-Iconify"

    html_url:    "https://community.obsidian.md/plugins/iconify"
    github_url:  "https://github.com/moziar/Obsidian-Iconify"
