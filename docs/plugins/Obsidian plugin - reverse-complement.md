# Reverse Complement

Reverse Complement converts a selected nucleotide sequence into its reverse complement from a right-click menu. The converted sequence is generated or written back in place of the selection, inside the note.

```cue
plugin: {
    id:     "reverse-complement"
    name:   "Reverse Complement"
    author: "Björn Johansson"
    repo:   "bjornfjohansson/reverse-complement"

    html_url:    "https://community.obsidian.md/plugins/reverse-complement"
    github_url:  "https://github.com/bjornfjohansson/reverse-complement"
    description: "Right-click menu to convert selected DNA to its reverse complement. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert selected nucleotide sequences into their reverse complement directly inside notes. Generate or replace sequence text inline for quick sequence editing and analysis."

    stats: {
        downloads:  646

    }
}
```
