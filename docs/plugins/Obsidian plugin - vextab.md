# Vextab

Vextab renders guitar tablature and standard music notation from Vextab code blocks inside a note. Fenced vextab or tab blocks are supported, and a quicktab shorthand exists for fast jotting on mobile, turning plain-text notation into visual scores.

    id:     "vextab"
