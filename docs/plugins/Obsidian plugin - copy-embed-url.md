# Copy Embed Code

Copy Embed Code adds a right-click option that copies the embed code for an image in Live Preview, Reading view and nested transclusions. Local images are copied as wiki-style embeds and external images as Markdown image links, regardless of how deeply the image is nested.

```cue
plugin: {
    id:     "copy-embed-url"
    name:   "Copy Embed Code"
    author: "dustinho"
    repo:   "dustinho/obsidian-copy-embed-code"

    html_url:    "https://community.obsidian.md/plugins/copy-embed-url"
    github_url:  "https://github.com/dustinho/obsidian-copy-embed-code"
    description: "Adds a 'Copy Embed Code' option to right-click context menu for images. Works in Live Preview and Reading Mode, including nested embeds. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Copy embed code for any image via a right-click menu in Live Preview, Reading view, and nested transclusions. Get local images as wiki-style embeds (![[file.png]]) and external images as markdown image links, copied to clipboard regardless of nesting depth."

}
```
