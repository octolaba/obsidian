# S3 Image Sync

Scans the images used by local notes, uploads them to S3-compatible storage such as Cloudflare R2, AWS S3 or MinIO, and replaces the local Markdown links with public URLs. The recorded inputs describe a mobile-friendly, image-first interface with responsive preview cards, progress animations and instant selection.
