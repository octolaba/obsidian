# Bases Image Gallery

Bases Image Gallery adds a masonry image gallery view for Bases that needs no setup, rendering images directly in the Base view. Images can be filtered by folder or other criteria, so galleries can be built standalone or embedded with minimal configuration.

```cue
plugin: {
    id:     "bases-image-gallery"
    name:   "Bases Image Gallery"
    author: "Gilbert Hyatt"
    repo:   "ghyatt/obsidian-bases-image-gallery"

    html_url:    "https://community.obsidian.md/plugins/bases-image-gallery"
    github_url:  "https://github.com/ghyatt/obsidian-bases-image-gallery"
    description: "A zero-setup masonry image gallery view for Bases. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create a zero-setup masonry image gallery in Obsidian using Bases, rendering images directly in the Base view. Filter images by folder or other criteria to build dynamic standalone or embedded galleries with minimal configuration."
```
