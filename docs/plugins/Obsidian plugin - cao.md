# CAO

CAO integrates Claude and OpenAI-compatible models for chatting inside notes. Conversations are stored as editable Markdown notes with foldable callout formatting and image embedding. Templates can be created, wikilinks attached as context, and the Anthropic and OpenAI-compatible APIs switched between.
