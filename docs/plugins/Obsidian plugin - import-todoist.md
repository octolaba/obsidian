# Import Todoist tasks

Imports Todoist tasks as Markdown tasks, inserting all of them at the current cursor position. The recorded inputs suggest pairing it with the Tasks plugin to view and manage the imported tasks inside notes.

```cue
plugin: {
    id:     "import-todoist"
    name:   "Import Todoist tasks"
    author: "dukex"
    repo:   "dukex/obsidian-import-todoist"

    html_url:    "https://community.obsidian.md/plugins/import-todoist"
    github_url:  "https://github.com/dukex/obsidian-import-todoist"
    description: "Import Todoist tasks as Markdown tasks."
    about:       "Import all Todoist tasks into Obsidian and insert them at the current cursor position. Pair with the Tasks plugin to view and manage imported tasks inside your notes."
```
