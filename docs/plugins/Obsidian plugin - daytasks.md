# DayTasks

Manages tasks inside daily notes as collapsible cards carrying subtasks, dependencies, priorities, estimates, tags and optional detail notes. A task list view collects tasks across days with grouping, filtering and sorting, and stable identifiers keep cards, subtasks, dependencies and detail notes pointing at the same task.
