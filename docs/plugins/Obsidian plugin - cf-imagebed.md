# CF ImageBed

CF ImageBed uploads images to CloudFlare ImgBed by drag-and-drop, paste, right-click or command, inserting the resulting Markdown link automatically. Remote images can be fetched for rehosting and links batch-replaced across the current note. It runs on desktop and on mobile, where camera and album sources are available.

```cue
plugin: {
    id:     "cf-imagebed"
    name:   "CF ImageBed"
    author: "fantasy-ke"
    repo:   "fantasy-ke/obsidian-cf-imgbed"

    html_url:    "https://community.obsidian.md/plugins/cf-imagebed"
    github_url:  "https://github.com/fantasy-ke/obsidian-cf-imgbed"
    description: "Upload images to CloudFlare ImgBed's plugin, which supports drag and drop, paste and select file uploads. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Upload images to CloudFlare ImgBed directly from Obsidian via drag-and-drop, paste, right-click or command and insert Markdown links automatically. Fetch remote images to rehost, batch-replace links in the current note, and use on desktop or mobile with camera and album support."

    stats: {
        downloads:  249
        updated_at: 1782208246000
    }
}
```
