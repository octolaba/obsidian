# Feishu Inbox

Feishu Inbox syncs quick notes from a Feishu or Lark group chat into a vault-relative Markdown inbox note with one click. New messages are pulled manually, duplicate imports are avoided and system events are ignored. It runs through your own Feishu or Lark custom app, whose secrets are stored locally.

    id:     "feishu-inbox"
    name:   "Feishu Inbox"
