# Markdown Mindmap

Markdown Mindmap renders configurable leveled trees from the links recorded in note frontmatter, with each map defined in a mindmap code block that updates live as files change. Maps are laid out left to right and can be navigated interactively: nodes open notes on click, hovering highlights the lineage, subtrees collapse and expand, and the view pans, zooms, searches and filters with saved views. Cards can show progress or stacked category bars.
