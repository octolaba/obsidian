# Open in Zed

Open in Zed opens the current vault, a selected folder or a single note in the Zed editor from a ribbon button, the command palette or the file and folder context menus. The active note can be opened at its exact line and column. Zed has to be installed and the plugin pointed at its CLI binary before launching works.

```cue
plugin: {
    id:     "open-in-zed"
    name:   "Open in Zed"
    author: "hauntedhost"
    repo:   "hauntedhost/obsidian-open-zed"

    html_url:    "https://community.obsidian.md/plugins/open-in-zed"
    github_url:  "https://github.com/hauntedhost/obsidian-open-zed"
    description: "Open the current vault, folder, or note in the Zed editor. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open the current vault, a selected folder, or a specific note in Zed via ribbon button, command palette, or file/folder context menu. Jump the active note to Zed at the cursor's exact line and column. Install and point the plugin to the Zed CLI binary to enable launching."

    stats: {
        downloads:  112
        updated_at: 1778107976000
    }
}
```
