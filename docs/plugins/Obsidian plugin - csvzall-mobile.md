# csvzall Mobile

A mobile counterpart to the csvzall desktop plugin that views and edits CSV files through a WebAssembly build of the desktop CLI. The recorded inputs state that charts and Markdown tables generated on the desktop remain visible on mobile, while this version supports viewing and editing only.

```cue
plugin: {
    id:     "csvzall-mobile"
    name:   "csvzall Mobile"
    author: "Vincent La"
    repo:   "vincentlaucsb/obsidian-csvzall-mobile"

    html_url:    "https://community.obsidian.md/plugins/csvzall-mobile"
    github_url:  "https://github.com/vincentlaucsb/obsidian-csvzall-mobile"
    description: "A fast CSV viewer and editor for Obsidian Mobile - This plugin has not been manually reviewed by Obsidian staff."
    about:       "This is a mobile-friendly version of the csvzall desktop plugin. It allows editing and viewing using a fast WebAssembly version of the desktop CLI. Note: While desktop generated charts and Markdown tables are visible on mobile without any special plugins, the mobile-version only supports editing and viewing."

    stats: {
        downloads:  51
        updated_at: 1783061029000
    }
}
```
