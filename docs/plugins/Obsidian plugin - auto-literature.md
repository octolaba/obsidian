# autoLiterature

autoLiterature detects paper identifiers in notes and fetches metadata for arXiv, DOI, medRxiv and bioRxiv entries, including title, authors, journal and date. It can download and organize the PDFs with flexible naming, and it replaces the identifier in place with a customizable Markdown summary.

    id:     "auto-literature"
    name:   "autoLiterature"
    author: "hucorz"
    repo:   "hucorz/obsidian-autoLiterature"
