# Share via Notepad Tab

Share via Notepad Tab posts a whole note or a highlighted selection to Notepad Tab from inside Obsidian. Two dedicated Command Palette commands send either the current note or the current selection.

```cue
plugin: {
    id:     "share-via-notepad-tab"
    name:   "Share via Notepad Tab"
    author: "revolter"
    repo:   "revolter/obsidian-share-via-notepad-tab-plugin"
```
