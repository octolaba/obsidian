# Print

Prints the current note, a selected range of text, or all Markdown notes in a folder, from the command palette, the ribbon, or the context menu. Note titles and frontmatter can be included, folder notes combined into a single output or separated by page breaks at horizontal rules, and the generated HTML previewed for debugging.
