# Zotero Notes Sync

Zotero Notes Sync syncs notes from Zotero Desktop into the vault as individual Markdown files whose frontmatter carries the Zotero key, parent title, creators, year, tags, dates and zotero:// links. Sync runs from one click or the command palette, synced notes are browsable through an _index.md, and results are reviewed in a manifest JSON file. It requires the Zotero Desktop local API.

```cue

    id:     "zotero-notes-sync"
    name:   "Zotero Notes Sync"
    author: "lojeunhou"

    html_url:    "https://community.obsidian.md/plugins/zotero-notes-sync"

Run one-click or command-palette sync, browse synced notes via _index.md, and review results in .zotero-notes-manifest.json; requires Zotero Desktop local API."
