# Stratify Mindmap

Markdown notes are turned into editable mind maps whose nodes are edited directly and written back to Markdown, on desktop and on mobile. Structures convert between heading, hybrid and list forms, nodes are rearranged by drag-and-drop or from the keyboard, branches collapse, and visual themes are chosen. Maps export as PNG images, and editing supports undo and redo.
