# WhatsApp backup importer

Imports an exported WhatsApp chat archive in zip form into the vault and converts the messages into organised Markdown files. Photos, videos and other attachments are stored in subfolders of a chosen folder, and links to them are inserted into the imported chat notes.

```cue
plugin: {
    id:     "whatsapp-backup"
    name:   "WhatsApp backup importer"
    author: "luigicerone"
    repo:   "luigicerone/obsidian-whatsapp-backup-importer"

    html_url:    "https://community.obsidian.md/plugins/whatsapp-backup"
    github_url:  "https://github.com/luigicerone/obsidian-whatsapp-backup-importer"
    description: "Import WhatsApp export inside your vault."
    about:       "Import exported WhatsApp chat archives (.zip) into your vault and convert messages into organized Markdown files. Store photos, videos, and other attachments in subfolders and insert links to them inside the imported chat notes in a folder you choose."

    stats: {
        downloads:  1024
        updated_at: 1738695458000
    }
}
```
