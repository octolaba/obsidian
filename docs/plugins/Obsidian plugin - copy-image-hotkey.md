# Copy Image Hotkey

Copy Image Hotkey copies the actual image file to the clipboard when an image embed is selected in source mode and the copy shortcut is pressed. The image pastes into other applications intact, and PNG, JPG, GIF, BMP, TIFF, WebP and SVG are supported.

```cue
plugin: {
    id:     "copy-image-hotkey"
    name:   "Copy Image Hotkey"
    author: "aliir74"
    repo:   "aliir74/copy-image-hotkey"

    html_url:    "https://community.obsidian.md/plugins/copy-image-hotkey"
    github_url:  "https://github.com/aliir74/copy-image-hotkey"
    description: "Cmd+C copies the actual image when an image embed is selected in source mode. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Copy the actual image file to your clipboard with Cmd/Ctrl+C when an image embed is selected in Obsidian. Paste the image into other apps intact; supports PNG, JPG/JPEG, GIF, BMP, TIFF, WebP and SVG."

    stats: {
        downloads:  158
        updated_at: 1777685153000
    }
}
```
