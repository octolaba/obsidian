# Embed 3D

Embed 3D embeds local 3D models in notes, covering the STL, GLB, OBJ with MTL, FBX and 3MF formats, and can open them from the file explorer. Scene appearance, lighting, autorotation, scale, HDR backgrounds and grid layouts are customizable, and snapshots or card views can be captured.
