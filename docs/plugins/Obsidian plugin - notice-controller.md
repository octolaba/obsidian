# Notification Controller

Manages the notices Obsidian shows at startup by removing debug notices automatically after a configurable delay, so they are cleared once the workspace is ready. A settings tab sets that delay or keeps the notices persistent instead.

```cue
plugin: {
    id:     "notice-controller"
    name:   "Notification Controller"
    author: "juan-miii"
    repo:   "juan-miii/obsidian-notice-plugin"

    html_url:    "https://community.obsidian.md/plugins/notice-controller"
    github_url:  "https://github.com/juan-miii/obsidian-notice-plugin"
    description: "Manages notifications at startup."
    about:       "Remove startup debug notices in Obsidian automatically after a configurable delay so notices are cleared once the workspace is ready. Add a settings tab to set the delay or keep notices persistent."

    stats: {
        downloads:  2160
        updated_at: 1740503461000
    }
}
```
