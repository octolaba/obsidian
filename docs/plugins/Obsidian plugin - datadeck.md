# DataDeck

Opens CSV files as editable table, card, kanban, habit dashboard, tasks board, single-entry reader and travel map views, and saves edits back to the original CSV. Charts carry best-fit lines with R2 overlays, categorical and size encodings, aggregates and PNG export. Views can be embedded in notes, columns holding notes render as Markdown, and conflicting versions found on disk are stashed to an Archive.
