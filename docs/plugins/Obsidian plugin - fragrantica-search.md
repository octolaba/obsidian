# Fragrantica Search

Searches the Fragrantica website from a note through a double-exclamation trigger that gives live autocomplete for perfumes. A result is inserted as a markdown link, as the perfume's cover image, or as a stylized social card.

```cue
plugin: {
    id:     "fragrantica-search"
    name:   "Fragrantica Search"
    author: "Aleksander Pugowski"
    repo:   "pug0r/obsidian-fragrantica-plugin"

    html_url:    "https://community.obsidian.md/plugins/fragrantica-search"
    github_url:  "https://github.com/pug0r/obsidian-fragrantica-plugin"
    description: "Searches for fragrances on the Fragrantica website. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Search Fragrantica from your notes with the !! trigger to get live autocomplete for perfumes. Insert a markdown link, the perfume's cover image (-i) or a stylized social card (-c) directly into your note."

    stats: {
        downloads:  21
        updated_at: 1783872834000
    }
}
```
