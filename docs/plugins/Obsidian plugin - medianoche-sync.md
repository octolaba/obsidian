# Medianoche Sync

Syncs and triages article notes exported from Medianoche, adding star, archive and delete actions whose result is written into the note's YAML frontmatter for Medianoche to read back into its reading library. The recorded description names RSS, web clipper and read-later sources alongside exported AI Summary and AI Comments content. Reading view, Live Preview and Source mode are supported on desktop and mobile.

```cue

    id:     "medianoche-sync"
    name:   "Medianoche Sync"
    author: "ohida"
    repo:   "ohida/medianoche-sync"

    html_url:    "https://community.obsidian.md/plugins/medianoche-sync"
    github_url:  "https://github.com/ohida/medianoche-sync"
    description: "Sync and triage Medianoche article notes in Obsidian: RSS, web clipper, read later, star, archive, delete, AI Summary, and AI Comments. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync and triage Medianoche-exported article notes inside Obsidian. Medianoche Sync adds star, archive, and delete actions to notes exported from Medianoche, writes changes to YAML frontmatter, and lets Medianoche sync those changes back to your reading library. It supports Reading view, Live Preview, Source mode, desktop, mobile, and exported AI Summary and AI Comments content."
```
