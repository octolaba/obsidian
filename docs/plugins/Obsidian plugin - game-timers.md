# Game Timers

Runs several countdown timers in a dedicated sidebar with pause, resume, cancel and repeat, keeping their state across reloads. Timers are created ad hoc or from reusable color-coded presets with optional warning times and desktop notifications, launchers are embedded through game-timer code blocks, and the next timer to expire is shown in the status bar.
