# Tasks Kanban

Tasks Kanban displays tasks on a Kanban board with a column per status: todo, in progress and done. Dragging a card between columns updates its status in the source file, kept in real-time sync through the Tasks plugin. The board is filtered with Tasks query syntax, and clicking a card opens its source note.
