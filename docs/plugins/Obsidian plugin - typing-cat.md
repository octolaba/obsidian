# Typing Cat

Puts a cat overlay on the screen that types along in real time, sweating during intense bursts and showing a heart when clicked. Typing speed is tracked in WPM, CPM or CPS with an optional on-screen speedometer. Position, size, opacity and orientation are configurable.

```cue
plugin: {
    id:     "typing-cat"
    name:   "Typing Cat"
    author: "jefrry"
    repo:   "jefrry/obsidian-typing-cat"

    html_url:    "https://community.obsidian.md/plugins/typing-cat"
    github_url:  "https://github.com/jefrry/obsidian-typing-cat"
    description: "A cozy typing cat that keeps you company and tracks your typing speed. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add a cozy cat overlay that types along with you in real time and gives playful visual cues (sweats during intense bursts, shows a heart when clicked). Track typing speed in WPM, CPM, or CPS with an optional on-screen speedometer. Customize position, size, opacity, and orientation."

    stats: {
        downloads:  216
        updated_at: 1769765484000
    }
}
```
