# File Metadata

File Metadata shows file information, text statistics, link and code counts, image EXIF data and a clickable indented document outline in a right sidebar, without altering frontmatter. Any value is copied with a click, further options sit on the right-click menu, and sections can be collapsed. Reading time and readability are shown alongside the statistics.

```cue
plugin: {
    id:     "file-metadata"
    name:   "File Metadata"
    author: "August"
    repo:   "aicayzer/obsidian-file-metadata"

    html_url:    "https://community.obsidian.md/plugins/file-metadata"
    github_url:  "https://github.com/aicayzer/obsidian-file-metadata"
    description: "Shows file metadata, text statistics, and document outline in the sidebar. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "View file info, text statistics, link and code counts, image EXIF, and a clickable indented document outline in a right sidebar without altering frontmatter. Copy any value with a click or right‑click for options, collapse sections, and see reading time and readability at a glance."

    stats: {
        downloads:  454
        updated_at: 1778849831000
    }
}
```
