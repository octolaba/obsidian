# Vim Yank Highlight

Vim Yank Highlight briefly highlights the region yanked in Obsidian's Vim mode with a subtle animation. The feedback marks what was copied without altering core Vim behavior.

```cue
plugin: {
    id:     "vim-yank-highlight"
    name:   "Vim Yank Highlight"
    author: "aleksey-rowan"
    repo:   "aleksey-rowan/obsidian-vim-yank-highlight"

    html_url:    "https://community.obsidian.md/plugins/vim-yank-highlight"
    github_url:  "https://github.com/aleksey-rowan/obsidian-vim-yank-highlight"
    description: "Highlight yanked text in Vim mode. Enjoy that subtle animation you've missed so much."
    about:       "Highlight yanked text in Obsidian's Vim mode with a subtle animation to make the yanked region immediately apparent. Provide unobtrusive visual feedback after yank operations without altering core Vim behavior."
```
