# Vault Size History

Graphs how many files the vault holds over time, giving a historical view of its growth. Counts can be split into custom file categories defined by path-based filters, and individual lines toggled in the legend to compare trends.

    id:     "vault-size-history"
    name:   "Vault Size History"
    author: "technerium"
    repo:   "technerium/obsidian-vault-size-history"
