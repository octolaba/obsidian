# Shamsi Date Converter

Shamsi Date Converter converts Gregorian date properties in notes to Shamsi (Jalali/Persian) dates. Multiple start and end or custom date-property pairs are supported, conversion runs automatically when a source date changes and can also be triggered from the command palette, and the Shamsi output format is configurable.

```cue
plugin: {
    id:     "shamsi-date-converter"
    name:   "Shamsi Date Converter"
    author: "milad-s5"
    repo:   "milad-s5/obsidian-shamsi-date-converter"

    html_url:    "https://community.obsidian.md/plugins/shamsi-date-converter"
    github_url:  "https://github.com/milad-s5/obsidian-shamsi-date-converter"
    description: "Automatically converts Gregorian dates to Shamsi (Jalali/Persian) dates. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert Gregorian date properties in notes to Shamsi (Jalali/Persian) dates, supporting multiple start/end or custom date-property pairs. Update conversions automatically when source dates change and trigger manual conversion via the command palette; choose flexible Shamsi output formats."
```
