# brAIn

brAIn answers questions about the vault with a ChatGPT-backed chatbot that ingests and indexes Markdown notes for context. Documents are indexed and then queried from an in-app chat, and the recorded inputs state that embeddings are generated locally by default while OpenAI provides the model responses.
