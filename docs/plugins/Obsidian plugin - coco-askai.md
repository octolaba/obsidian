# CoCo AskAI

Answers questions with an AI that draws on the current note's content and the conversation history. Answers appear in multi-card pop-ups that can be resized and dragged, models are chosen inside the prompt, filters and model tags narrow a request, and a customizable right-click menu drives the interactions. It is distributed as closed source.
