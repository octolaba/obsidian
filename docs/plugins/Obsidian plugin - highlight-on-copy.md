# Highlight on Copy

Highlight on Copy briefly highlights the selected text when it is copied to the clipboard. The short animation flashes over the selection to confirm that the copy happened.

```cue

    id:     "highlight-on-copy"
    name:   "Highlight on Copy"
    author: "trevortylerlee"
    repo:   "trevortylerlee/highlight-on-copy"

    html_url:    "https://community.obsidian.md/plugins/highlight-on-copy"
    github_url:  "https://github.com/trevortylerlee/highlight-on-copy"
    description: "Highlight selected text when copying it. - This plugin has not been manually reviewed by Obsidian staff."
```
