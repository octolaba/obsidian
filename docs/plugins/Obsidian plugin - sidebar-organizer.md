# Sidebar Organizer

Sidebar Organizer groups sidebar icons into hover menus so the sidebar stays uncluttered. Custom groups take optional SVG icons and are reordered by drag-and-drop, hovering reveals a blurred popup menu, and the interface is available in eight languages.

```cue
plugin: {
    id:     "sidebar-organizer"
    name:   "Sidebar Organizer"
    author: "zhywjml"
    repo:   "zhywjml/obsidian-sidebar-organizer"

    html_url:    "https://community.obsidian.md/plugins/sidebar-organizer"
    github_url:  "https://github.com/zhywjml/obsidian-sidebar-organizer"
```
