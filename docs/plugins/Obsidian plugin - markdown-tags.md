# Tags for Markdown

Tags for Markdown styles and highlights inline labels written with a double-parenthesis syntax, using a pipe or slash separator inside the label. Predefined labels or custom hex colors can be applied to the background and foreground, and arrow indicators can be added for left-pointing tags. Built-in presets cover common statuses, so tasks and states can be tracked visually in the text.

plugin: {
    id:     "markdown-tags"
    name:   "Tags for Markdown"
