# GridExplorer

Browses and organizes notes, folders and attachments in a configurable grid layout. Content is selected through several modes, among them folders, bookmarks, search, backlinks, outgoing links, recent files, a random selection and custom Dataview queries. Images, video, audio, PDFs and Canvas files preview directly in the grid, and sorting can be set globally or per folder.
