# Automatic Linker

Automatic Linker converts plain-text file references into wiki links as you write or on save. It processes a selection or the entire vault, handles CJK text and optional case-insensitive matching, and can call on context-aware AI, including a local LLM, to resolve ambiguous or incorrect links.
