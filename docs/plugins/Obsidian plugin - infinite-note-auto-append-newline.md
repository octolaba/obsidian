# Infinite Note

Appends empty lines to the end of a document as it is typed into, producing an editor that keeps scrolling. New lines are generated as the cursor moves while the selection and cursor position are preserved, and the buffer of trailing empty lines is configurable.

    id:     "infinite-note-auto-append-newline"
