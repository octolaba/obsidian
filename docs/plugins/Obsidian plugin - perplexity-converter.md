# Perplexity Converter

Perplexity Converter repairs bracketed citations in text pasted from Perplexity so that inline numeric references become clickable links to their source entries. It works on the current selection only and updates the reference list so the anchors resolve, leaving the rest of the note unchanged.

```cue
plugin: {
    id:     "perplexity-converter"
    name:   "Perplexity Converter"
    author: "heseber"
    repo:   "heseber/perplexity-converter"

    html_url:    "https://community.obsidian.md/plugins/perplexity-converter"
    github_url:  "https://github.com/heseber/perplexity-converter"
    description: "Fix references and their hyperlinks in text pasted from Perplexity."
    about:       "Fix bracketed Perplexity citations in pasted text so inline references like [1][2] become clickable links to their corresponding source entries. Process only the current selection and update the reference list to create working anchors without altering the rest of the note."

    stats: {
        downloads:  5433
        updated_at: 1750714164000
    }
}
```
