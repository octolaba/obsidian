# Copilot auto completion

Copilot auto completion adds fill-in-the-middle suggestions shown as a transparent inline overlay while typing. Suggestions are accepted with Tab or the right arrow and dismissed with Escape, and they are context- and language-aware for prose, code and math. Completions come from the ChatGPT API, Azure, Ollama or other OpenAI-compatible local endpoints, and the plugin is highly configurable.
