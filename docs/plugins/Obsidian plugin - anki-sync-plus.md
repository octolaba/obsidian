# AnkiSync+

Syncs Obsidian notes with Anki, adding, updating or deleting flashcards by scanning folders or working from the current note. The first tag maps to a deck, tags can be excluded, and stale anki-id values are removed automatically. Images and Excalidraw drawings are supported, and a regex can strip unwanted text before the card is built.
