# Proletarian Wizard Task Manager

Tracks tasks across all the notes in the workspace and presents them on a centralized task board that reflects the todos inline in their source files. Tasks are selected and prioritized, status changes are written back to the notes in two-way sync, natural-language dates are expanded automatically, and reports of completed work can be generated.
