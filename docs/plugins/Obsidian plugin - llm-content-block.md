# LLM Content Block

Archives LLM conversations as self-contained scrollable cards whose Markdown renders only inside the card. User and AI turns are kept as bubbles with source tags, headings and code blocks produced by the model cannot alter the surrounding note's structure, and long replies are collapsed by default.

```cue
plugin: {
    id:     "llm-content-block"
    name:   "LLM Content Block"
    author: "Darren Zheng"
    repo:   "slow-coding/obsidian-llm-content-block"

    html_url:    "https://community.obsidian.md/plugins/llm-content-block"
    github_url:  "https://github.com/slow-coding/obsidian-llm-content-block"
    description: "Archive LLM texts as scrollable, format-safe cards. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create self-contained, scrollable cards for AI conversations that render the conversation's Markdown only inside the card. Preserve user/AI turns as bubbles with source tags, prevent AI headings and code blocks from altering your note's structure, and collapse long replies by default."

    stats: {
        downloads:  37
        updated_at: 1783710269000
    }
}
```
