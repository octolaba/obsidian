# Scan to Markdown

Scan to Markdown works from a phone: a scanned code opens the camera, and the photographed book page, formula or table is turned into structured Markdown that is written at the cursor of the current note or saved as a new note. Heading levels, paragraphs, lists, tables and LaTeX formulas, both inline and block, are preserved. Recognition runs through a vision model you configure, with several vendors and OpenAI-compatible interfaces supported.
