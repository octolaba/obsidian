# Natural Language Syntax Highlighting

Natural Language Syntax Highlighting colours adjectives, nouns, verbs, adverbs and conjunctions in the editor so the structure of a sentence becomes visible. The highlight colours can be customized and highlighting toggled on or off from the command palette.

```cue
plugin: {
    id:     "nl-syntax-highlighting"
    name:   "Natural Language Syntax Highlighting"
    author: "artisticat"
    repo:   "artisticat1/nl-syntax-highlighting"

    html_url:    "https://community.obsidian.md/plugins/nl-syntax-highlighting"
    github_url:  "https://github.com/artisticat1/nl-syntax-highlighting"
```
