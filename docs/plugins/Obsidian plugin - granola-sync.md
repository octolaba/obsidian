# Granola Sync

Syncs notes and transcripts from Granola into the vault. Destinations can be daily notes or folders, private notes can be included, and bidirectional links between a note and its transcript are created automatically. Syncs can also run periodically.

```cue
plugin: {
    id:     "granola-sync"
    name:   "Granola Sync"
    author: "tomelliot"
    repo:   "tomelliot/obsidian-granola-sync"

    html_url:    "https://community.obsidian.md/plugins/granola-sync"
    github_url:  "https://github.com/tomelliot/obsidian-granola-sync"
    description: "Sync Granola notes to your vault."
    about:       "The most robust and easiest to use plugin to sync notes and transcripts from Granola into your Obsidian vault. Choose destinations (daily notes, folders), include private notes, create automatic bidirectional links between notes and transcripts, and run periodic syncs."
```
