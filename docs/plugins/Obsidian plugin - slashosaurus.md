# Slashosaurus

Slashosaurus opens a slash menu at the cursor that previews each block before it is inserted, so the syntax does not have to be memorized. Headings, colored callouts, quotes, code and math are previewed in the current theme colors. A selection can be wrapped into a block, and inserted content leaves the cursor placed to continue writing.

plugin: {
    id:     "slashosaurus"
    name:   "Slashosaurus"

    repo:   "polygonhunter/slashosaurus"
