# Spectacles Sync

The vault is exported as a JSON knowledge graph and synced to a Spectacles AR lens, where the notes are explored as a 3D graph. The export is encrypted locally with a password-only key, and the recorded inputs state that the server holds only ciphertext. Full note bodies can be included or omitted, folders and tags excluded, and auto-sync kept on so the lens stays current.
