# Numbered Folder Creator

Maintains sequential numeric prefixes on new folders and Markdown files so a vault keeps an ordered structure. A retroactive command numbers items that already exist, preserving file extensions and skipping names that are already numbered, placeholder names, and the vault root.

```cue
plugin: {
    id:     "numbered-folder-creator"
    name:   "Numbered Folder Creator"
    author: "rajdeep31"
    repo:   "rajdeep31/Numbered-Folder-Creator"

    html_url:    "https://community.obsidian.md/plugins/numbered-folder-creator"
    github_url:  "https://github.com/rajdeep31/Numbered-Folder-Creator"
    description: "Automatically adds sequential numbering to folders and notes to maintain organized structures. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Maintain sequential numeric prefixes for new folders and markdown files to keep your vault organized. Run a retroactive numbering command to number existing items while preserving file extensions and ignoring already-numbered or placeholder names and the vault root."

    stats: {
        downloads:  281
        updated_at: 1772700475000
    }
}
```
