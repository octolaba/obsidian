# Juggl

Adds an interactive, stylable graph view built on Cytoscape.js, where node colors, shapes, sizes, icons and images can be controlled. Node subsets can be expanded, hidden, pinned and saved, graphs can be embedded in notes, edges can be labelled and layouts switched. An open API extends the view, and it runs on desktop and mobile.
