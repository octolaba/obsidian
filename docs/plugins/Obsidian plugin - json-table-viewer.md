# JSON Table Viewer

Renders JSON as recursively nested tables, either inside note code blocks or by opening .json files directly as structured tables. Rows can be sorted, filtered, grouped and collapsed with per-table state. The view adds sticky headers, live reloading, nesting depth indicators, clickable links, formatted numbers and highlights for selection and booleans.
