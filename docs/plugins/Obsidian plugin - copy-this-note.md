# Copy This Note

Copy This Note copies a whole note to the clipboard as Markdown without requiring a selection, optionally including the filename and the YAML frontmatter. It runs from the command palette or from the file-explorer and editor context menus, offers four built-in presets, and works offline on desktop and mobile.

```cue
plugin: {
    id:     "copy-this-note"
    name:   "Copy This Note"
    author: "Musashino Software"
    repo:   "mssoftjp/obsidian-copy-this-note"

    html_url:    "https://community.obsidian.md/plugins/copy-this-note"
    github_url:  "https://github.com/mssoftjp/obsidian-copy-this-note"
    description: "Copy the current note to the clipboard (optionally with filename and frontmatter). - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Copy whole Obsidian notes to the clipboard as Markdown without selecting text; optionally include the filename and YAML frontmatter. Access from the command palette or file-explorer/editor context menus, choose from four built-in presets, and run on desktop or mobile fully offline."
```
