# Lark Wiki

Lark Wiki links local notes to Lark and Feishu cloud documents through lightweight .lark.md proxy files that open the remote document in an Obsidian WebView. Documents can be created or linked from a URL, and remote titles sync back to rename the local file using collision-safe indexed suffixes. A Lark Documents.base index collects the linked notes for browsing.
