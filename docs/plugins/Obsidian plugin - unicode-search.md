# Unicode Search

Searches the Unicode Character Database by name, keyword or codepoint with fuzzy matching and inserts the chosen character into the editor. Favourites are saved and can be given hotkeys, persistent filters narrow the search to planes, categories or custom sets, and usage statistics are shown. Mobile is supported.

    id:     "unicode-search"
    name:   "Unicode Search"
    author: "bambuscontrol"
