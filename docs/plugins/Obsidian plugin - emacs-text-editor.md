# Emacs text editor

Adds Emacs-style keybindings and commands to Obsidian's editor as a partial emulation of Emacs. The covered actions are cursor movement, killing and yanking words and lines, undo and redo, and marking a region.

```cue
plugin: {
    id:     "emacs-text-editor"
    name:   "Emacs text editor"
    author: "klojer"
    repo:   "klojer/obsidian-emacs-text-editor"

    html_url:    "https://community.obsidian.md/plugins/emacs-text-editor"
    github_url:  "https://github.com/klojer/obsidian-emacs-text-editor"
    description: "Partial emulation of Emacs text editor."
    about:       "Add Emacs-style keybindings and commands to Obsidian's editor for familiar navigation and editing. Use common Emacs actions—cursor movement, word/line killing and yanking, undo/redo, and region marking—to edit Markdown with Emacs-like behavior."

    stats: {
        downloads:  8571
        updated_at: 1784221702000
    }
}
```
