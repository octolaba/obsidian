# Galaxy Graph 3D

Renders notes and their resolved links as a translucent three-dimensional galaxy with star cores, halos, depth fog, folder-based colors and node sizes taken from connection count. The view can be orbited, panned and zoomed, labels appear on hover, notes open on click, the active note's neighborhood can be focused, and the graph rebuilds automatically on renames or metadata changes.
