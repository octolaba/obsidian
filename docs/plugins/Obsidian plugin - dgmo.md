# Diagrammo Diagrams

Diagrammo Diagrams renders dgmo code fences as diagrams inline in reading mode and live preview, on desktop and mobile. One plain-text language covers more than 40 chart types across data visualization, software architecture, project planning, hierarchies and specialty diagrams, so the source stays searchable by Obsidian's search and diffable in git or Sync history. Ten palettes including Catppuccin, Dracula, Gruvbox, Nord and Tokyo Night follow light, dark or automatic mode, and a command drops an example note containing every chart type into the vault.

    id:     "dgmo"

One plugin instead of stitching several together. Because diagrams are plain text, they live alongside your notes: searchable by Obsidian's built-in search, diffable in git or Obsidian Sync history, easy to copy between vaults, easy to tweak six months later.
