# Vault OKR Manager

Manages objectives and key results inside the vault through a dashboard with built-in check-ins. Each objective is stored in a single Markdown file with its key results embedded, and progress is calculated automatically across weekly, monthly, quarterly and yearly periods. Score, percentage, number and boolean units are supported, and storage stays local as Markdown and YAML.
