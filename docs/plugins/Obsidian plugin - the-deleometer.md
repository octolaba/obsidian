# The Deleometer

The Deleometer supports self-discovery journaling by generating multi-perspective AI analyses of each journal entry, which requires an OpenAI API key. A live chat continues from any analysis perspective and is saved back into the original note, suggestions convert into editable goals, and progress is tracked on an emotional-intelligence dashboard. Analysis history, export options and optional Full Calendar sync are also recorded.
