# Zettelkasten LLM Tools

Zettelkasten LLM Tools generates embeddings and indexes notes so that a vault can be searched semantically and notes similar to the current file can be found. A Copilot rewrites and splits notes, suggesting clearer titles, more focused ideas, links and tags. Embeddings can be generated in batches selected by filename pattern, which indexes large sets of notes at once.
