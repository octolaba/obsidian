# Spherical Knowledge Graph

The vault is visualized as a rotatable pseudo-3D sphere built from links and metadata and updated automatically without modifying any file. Link direction, type and strength are shown, hovering an edge gives its context, and shortest paths between notes are found. Orphans and weakly connected notes are audited, and a node opens its source note.
