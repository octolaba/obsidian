# TaskTodo

TaskTodo adds a planning view and a Today dashboard on top of TaskLite Core. Built-in in-plan and today views sit beside custom tabs, columns and groups, and filters are set through a graphical interface with a DQL fallback. Groups and tabs are reordered by drag-and-drop, priorities are color-coded, and tasks and subtasks can be created from the view.
