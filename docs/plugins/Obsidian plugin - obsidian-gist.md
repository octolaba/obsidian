# Gist

Renders a GitHub Gist inside a note from a gist fenced code block. The Gist is addressed by its ID or by username and ID, and appending a filename displays only that single file from the Gist.

```cue
plugin: {
    id:     "obsidian-gist"
    name:   "Gist"
    author: "linjunpop"
    repo:   "linjunpop/obsidian-gist"

    html_url:    "https://community.obsidian.md/plugins/obsidian-gist"
    github_url:  "https://github.com/linjunpop/obsidian-gist"
    description: "Display the GitHub Gist."
    about:       "Render GitHub Gists inside Obsidian notes using gist fenced code blocks. Embed by Gist ID, username/Gist ID, or append #filename to show a single file from the Gist."

    stats: {
        downloads:  10403
        updated_at: 1706097350000
    }
}
```
