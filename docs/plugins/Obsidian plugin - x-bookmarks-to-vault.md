# X Bookmarks

Syncs X bookmarks into the vault as one Markdown note per bookmark, capturing full text, media, author information, timestamps and permalinks. Deduplication on the tweet identifier preserves manual edits across runs, and syncing is manual or scheduled with safe pagination and optional local media download. Access is cookie-based and unofficial, described for personal use.
