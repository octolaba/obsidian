# Meridian Clock

Displays analog and digital clocks in the sidebar for local time or other timezones, up to four of them in a 2x2 grid. Timezones are added by IANA name with daylight saving handled automatically. Dial geometry, colors, typography and second-hand movement are customizable and saved as appearance presets.
