# Social Archiver

Posts from social media platforms are archived into the vault as formatted Markdown notes that keep their media, transcripts and metadata for searchable storage. A timeline view browses what has been archived, background processing reports live progress, and public timelines can optionally be published. The recorded inputs state that data stays local by default.
