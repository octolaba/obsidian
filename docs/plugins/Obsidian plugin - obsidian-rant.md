# Rant-Lang

This plugin is a thin wrapper around Rant, a high-level procedural templating language, and executes Rant scripts in code blocks or inline. The generated text covers templates, dialogue, name generators and random data, and is rendered in preview with full Markdown parsing. Block results can be embedded through links, and scripts re-run with new random seeds for varied output.

plugin: {
    id:     "obsidian-rant"
    name:   "Rant-Lang"
    author: "lanice"
    repo:   "lanice/obsidian-rant"
