# Avatar

Avatar renders a compact component showing an image alongside a Markdown description, declared in an avatar codeblock. The image can be edited in live preview, or the block's YAML edited in source to set a path or URL, the side, the size and the object position.

```cue
plugin: {
    id:     "avatar"
    name:   "Avatar"
    author: "maradotwebp"
    repo:   "maradotwebp/obsidian-avatar"

    html_url:    "https://community.obsidian.md/plugins/avatar"
    github_url:  "https://github.com/maradotwebp/obsidian-avatar"
    description: "Display an avatar image in your notes."
    about:       "Display a compact avatar component showing an image alongside a Markdown description via an avatar codeblock. Edit the image in live preview or update the YAML in source to provide a path/URL, side, size, and objectPosition for precise layout."

    stats: {
        downloads:  12306
        updated_at: 1750876951000
    }
}
```
