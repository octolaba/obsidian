# Notes Calendar

Shows a calendar in the side pane and lists the notes grouped by file creation time for the selected day or week. Months and years can be navigated, clicking a day or a week number filters the list, and excerpts, creation times, week numbers, day indicators and sorting are configurable. Trackpad input on iPad is supported.

```cue
plugin: {
    id:     "notes-calendar"
    name:   "Notes Calendar"
    author: "tcatlas"
    repo:   "tcatlas/obsidian-notes-calendar"

    html_url:    "https://community.obsidian.md/plugins/notes-calendar"
    github_url:  "https://github.com/tcatlas/obsidian-notes-calendar"
    description: "Displays a sidebar calendar and notes created on the selected date or week, with iPad trackpad support. - This plugin has not been manually reviewed by Obsidian staff."

Support iPad trackpad input."
