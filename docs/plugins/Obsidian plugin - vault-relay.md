# VaultRelay

Prepares long-form notes for publication without moving them out of the vault. Headings, paragraphs, lists, callouts, code blocks and tables are parsed, local and remote images detected, and a readiness score surfaces the outstanding issues. Rich-text output is previewed inside Obsidian, and article cards are exported in bulk to the vault as PNG images at a fixed size.
