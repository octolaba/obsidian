# mdMenu

Adds a compact WYSIWYG-style formatting toolbar for applying headings, lists, callouts, links, highlights, code blocks, checkboxes and inline formatting while the note stays plain Markdown. The toolbar sits in a fixed position, follows the selection or the cursor, or is dragged and pinned by hand. Buttons and presets are customizable.
