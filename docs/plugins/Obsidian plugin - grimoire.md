# Grimoire

Runs local CLI AI agents inside the vault from one side panel, covering Claude Code, Codex, Grok Build, Mimo Code, Kimi Code, AntiGravity, Qwen Code, Gemini CLI and OpenCode, with a single model picker. Agents can read notes, edit files, run commands, call tools and continue sessions from the vault history. It is desktop-only because it drives local CLIs, and it records having no hosted backend, telemetry, ads or proxy, with data leaving the machine only through a provider or tool the user chooses.
