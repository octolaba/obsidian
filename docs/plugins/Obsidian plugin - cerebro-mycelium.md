# Cerebro Mycelium

Cerebro Mycelium renders the vault as an animated two-dimensional fungal network in which notes become clusters and wikilinks become curved hyphae. Recent notes carry glowing halos, a click on a node sends a cascade, and dragging pans or pins the view. The graph is built locally inside a native Obsidian view and no file is changed.
