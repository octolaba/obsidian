# Advanced Cursors

Advanced Cursors extends multiple-cursor editing with commands that move to or add the next or previous instance of the current selection, looping through the note the way VS Code multi-select does. Lines can be copied up or down, incrementing numbers inserted across cursors, and cursors placed at regex matches for edits in many locations at once.
