# Nous

Captures typed thoughts, voice memos, pasted meeting notes, photos and PDFs and turns them into a tagged, linked knowledge graph in the vault. Each capture is summarized and connected automatically to related notes, and wiki-style topic pages are generated once enough notes have accumulated on a topic. The recorded description names Claude Code or a direct API key from Anthropic, OpenAI or Gemini, or a local model, as the choices behind it.
