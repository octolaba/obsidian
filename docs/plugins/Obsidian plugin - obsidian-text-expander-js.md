# Inline Scripts

Typed shortcuts are replaced with text generated by JavaScript, inserting dates, names, parameterized results and other dynamic values into the note. Shortcut scripts are created and edited in the plugin and run on mobile as well as desktop and on both editor generations. Expansions can be chained and parametrized.

```cue
plugin: {
    id:     "obsidian-text-expander-js"
    name:   "Inline Scripts"
    author: "jon-heard"
    repo:   "jon-heard/obsidian-inline-scripts"

    html_url:    "https://community.obsidian.md/plugins/obsidian-text-expander-js"
    github_url:  "https://github.com/jon-heard/obsidian-inline-scripts"
    description: "Type text shortcuts which are then replaced with JavaScript generated text."
    about:       "Replace typed shortcuts with JavaScript-generated expansions that insert dynamic text (dates, names, parameterized results, and more) directly into notes. Create and edit shortcut scripts, run them on any platform and editor (mobile, CM6/CM5), and chain or parametrize expansions for advanced automation."

    stats: {
        downloads:  15576
        updated_at: 1670908645000
    }
}
```
