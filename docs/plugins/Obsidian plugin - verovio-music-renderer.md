# Verovio Music Renderer

Verovio Music Renderer renders MEI, MusicXML, ABC and PAE scores as SVG from vault files, URLs or code blocks, and the rendered SVG can be downloaded. Score code is edited in a side panel with syntax highlighting, and rendered notes link back to their MEI code blocks. Playback highlights notes in sync with the audio, and page turns can be controlled while it plays.
