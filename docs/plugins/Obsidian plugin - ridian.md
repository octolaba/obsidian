# Ridian

Ridian executes R code blocks inside Obsidian and renders documents with Quarto. Notes are parsed into Quarto code chunks and rendered, with plots and htmlwidgets embedded back into the vault so code examples appear inline and stay reachable through Obsidian search and links.

    id:     "ridian"
    name:   "Ridian"
    author: "michelnivard"
    repo:   "michelnivard/Ridian"

    github_url:  "https://github.com/michelnivard/Ridian"
