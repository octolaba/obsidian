# Gremlins

Reveals invisible and easily confused Unicode characters in the Markdown editor, drawing a red bar over zero-width and bidirectional control characters and highlighting non-breaking spaces, soft hyphens and similar symbols. Curly quotes and en dashes can optionally be marked, and mixed tab and space indentation raises a warning. A bug icon exposes the code point, description and severity on hover, and an Inspect command is provided, in Source mode and Live Preview.
