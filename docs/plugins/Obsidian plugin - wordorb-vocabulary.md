# WordOrb Vocabulary

Looks an English word up through WordOrb.ai and returns definitions, IPA, etymology, audio and translations across 47 languages. A formatted word card can be inserted, or a full vocabulary note generated with frontmatter, lessons and quiz questions. Interactive multiple-choice quizzes and a daily five-phase lesson are included, and inline definitions can be rendered from wikilinks.
