# Bible Verse Tips

Bible Verse Tips previews a verse when a reference is hovered or tapped, shown in a popover without leaving the note. Clicking the reference opens a distraction-free chapter reader with an inline translation switcher and chapter navigation.

```cue
plugin: {
    id:     "bible-verse-tips"
    name:   "Bible Verse Tips"
    author: "Joel Wong"
    repo:   "joelwongjy/obsidian-bible-verse-tips"

    html_url:    "https://community.obsidian.md/plugins/bible-verse-tips"
    github_url:  "https://github.com/joelwongjy/obsidian-bible-verse-tips"
    description: "Hover any Bible reference to preview the verse; click to read the whole chapter, with an inline translation switcher. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Preview Bible verses inline and read full chapters without leaving your notes. Hover or tap any reference to view a clean popover, then click to open a distraction-free chapter reader with translation switching and chapter navigation."

    stats: {
        downloads:  114
        updated_at: 1783843341000
    }
}
```
