# Word Scalpel

Changes Option or Alt plus Backspace so that it deletes one word at a time in Thai and Japanese, using the browser's Intl.Segmenter to find the word boundaries. Space-delimited languages keep the default behaviour, so English still deletes by spaces and punctuation.

```cue
plugin: {
    id:     "word-scalpel"
    name:   "Word Scalpel"
    author: "Grich Hiranyaphinant"
    repo:   "grichshiran/obsidian-word-scalpel"

    html_url:    "https://community.obsidian.md/plugins/word-scalpel"
    github_url:  "https://github.com/grichshiran/obsidian-word-scalpel"
    description: "Precise word deletion for Thai and Japanese — fixes Option+Backspace so it deletes one word at a time instead of the entire sentence. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Fix Option/Alt+Backspace to delete one word at a time in Thai and Japanese by using the browser's Intl.Segmenter to find proper word boundaries. Preserve default deletion for space-delimited languages so English still deletes by spaces and punctuation."

    stats: {
        downloads:  67
        updated_at: 1781852205000
    }
}
```
