# Kcal Calc

Scans the active note for ingredient lines and looks up matching foods in USDA FoodData Central to retrieve kcal and macronutrient values. Per-item kcal and macros are appended, with underlined section totals and an overall kcal line. A match preview with confidence is shown before any change is applied.
