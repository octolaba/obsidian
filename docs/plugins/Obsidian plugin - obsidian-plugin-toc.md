# Table of Contents

This plugin creates a table of contents for a note as a linked list of its headings, either complete or limited to the next heading level. The list style, the title and the header-depth range are configurable to control the scope.

```cue
plugin: {
    id:     "obsidian-plugin-toc"
    name:   "Table of Contents"
    author: "hipstersmoothie"
    repo:   "hipstersmoothie/obsidian-plugin-toc"

    html_url:    "https://community.obsidian.md/plugins/obsidian-plugin-toc"
    github_url:  "https://github.com/hipstersmoothie/obsidian-plugin-toc"
    description: "Create a table of contents for a note."
    about:       "Create a table of contents for a note as a linked list of headings, either full or limited to the next heading level. Choose list style, title and header-depth range to control scope."
```
