# Citation Extended

Searches a Zotero library and other reference sources and inserts the resulting citations automatically. It reads BibTeX, CSL-JSON, Hayagriva YAML or Readwise databases, opens the matching literature notes, and inserts wiki links, markdown links, rendered templates or Pandoc-style citations. Handlebars templates with more than 25 variables and helpers shape the output, and several databases can be loaded at once while duplicate citekeys are preserved.

    name:   "Citation Extended"
