# Tag Links

Tag Links opens tags as URLs from a configurable hotkey. Regular expressions capture values out of nested tags and substitute them into URL templates, so a tag can lead straight to a referenced resource such as a ticket or a pull request.

```cue
plugin: {
    id:     "tag-links"
    name:   "Tag Links"
    author: "zedseven"
    repo:   "zedseven/obsidian-tag-links"

    html_url:    "https://community.obsidian.md/plugins/tag-links"
    github_url:  "https://github.com/zedseven/obsidian-tag-links"
    description: "Open tags as links using a hotkey."
    about:       "Open tags as URLs with a configurable hotkey. Define regular expressions to capture values from nested tags and substitute them into URL templates to quickly jump to referenced resources like tickets or PRs."

    stats: {
        downloads:  1277
        updated_at: 1747019002000
    }
}
```
