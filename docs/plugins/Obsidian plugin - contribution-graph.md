# Contribution Graph

Contribution Graph renders interactive heatmaps in the style of GitHub's contribution chart to track notes, habits, activity and history, with daily counts shown as color-coded cells. Views can be switched between week, month and calendar, and colors or emoji fills, date ranges and cell click and hover behaviour are configurable. Graphs can also be generated dynamically from DataviewJS.

```cue
plugin: {
    id:     "contribution-graph"
    name:   "Contribution Graph"
    author: "vran-dev"
    repo:   "vran-dev/obsidian-contribution-graph"

    html_url:    "https://community.obsidian.md/plugins/contribution-graph"
    github_url:  "https://github.com/vran-dev/obsidian-contribution-graph"
    description: "Generate an interactive heatmap to visualize and track your productivity."
    about:       "Generate interactive heatmap graphs like GitHub to track notes, habits, activity and history with daily counts shown in color-coded cells. Customize views (week, month, calendar), colors or emoji fills, date ranges and interactive cell click/hover behavior, and render graphs dynamically with DataviewJS."

    stats: {
        downloads:  57050

    }
}
```
