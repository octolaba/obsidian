# Drive Embedder

Uploads local files to Google Drive and embeds them directly in a note, with one-click upload and progress reporting. Audio, video, PDF and image formats are supported, with size presets named Compact, Medium, Large and Full Width and an audio-optimized player.

```cue
plugin: {
    id:     "drive-embedder"
    name:   "Drive Embedder"
    author: "reallygood83"
    repo:   "reallygood83/obsidian-embedder"

    html_url:    "https://community.obsidian.md/plugins/drive-embedder"
    github_url:  "https://github.com/reallygood83/obsidian-embedder"
    description: "Upload local files to Google Drive and embed them directly in your notes. Supports audio, video, PDF, and images with intuitive size options. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Upload local files to Google Drive and embed them directly into Obsidian notes with one-click upload and real-time progress. Choose intuitive size presets (Compact, Medium, Large, Full Width) and use audio-optimized players; support video, audio, PDF, and image formats."

    stats: {
        downloads:  8527
        updated_at: 1765243083000
    }
}
```
