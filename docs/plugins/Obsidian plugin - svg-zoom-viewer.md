# SVG Zoom Viewer

Opens SVG and common image embeds, covering svg, png, jpg, jpeg, webp and gif, in a dedicated zoomable leaf when they are double-clicked in reading view. The recorded About text describes zooming with the mouse wheel, dragging to pan, and double-clicking inside the viewer to reset the transform. SVGs are stated to render in an iframe so vector quality is preserved.
