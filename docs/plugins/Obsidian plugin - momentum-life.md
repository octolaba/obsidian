# Momentum Life

Momentum Life is a life dashboard covering habits, tasks, fitness, nutrition and studies, with dashboards, charts, Kanban and calendars rendered from the vault's own Markdown. All data is stored as plain Markdown in a single folder and the plugin works fully offline, with an optional Open Food Facts search described as its only contact with the internet.
