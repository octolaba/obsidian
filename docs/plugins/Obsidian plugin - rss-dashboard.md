# RSS Dashboard

RSS Dashboard gathers RSS, Atom and JSON feeds, podcasts and YouTube channels into a dashboard inside the vault. Curated sources can be discovered, full articles read in a built-in reader with Markdown conversion, and items saved as templated Markdown. Organization uses folders, tags, filters, OPML support and auto-refresh.
