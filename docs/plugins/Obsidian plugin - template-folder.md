# Template Folder

Template Folder replaces the core Templates plugin's Insert Template command. When a template is applied, the note is moved into the folder named by a property in that template's frontmatter.

```cue
plugin: {
    id:     "template-folder"
    name:   "Template Folder"
    author: "LucasOe"
    repo:   "lucasoe/obsidian-template-folder"

    html_url:    "https://community.obsidian.md/plugins/template-folder"
    github_url:  "https://github.com/lucasoe/obsidian-template-folder"
    description: "Moves notes to a folder when applying a template."
    about:       "Replace the core Templates Insert Template command and move notes into the folder specified by a template's frontmatter property."

    stats: {
        downloads:  963
        updated_at: 1783858198000
    }
}
```
