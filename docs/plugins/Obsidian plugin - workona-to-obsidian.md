# Workona Import

Imports a generated Workona JSON export and rebuilds its workspace folder structure in the vault, including resources, tabs, notes and tasks. Each item becomes a Markdown file rendered from a default or custom Handlebars template, keeping metadata, attachments and source URLs.

    id:     "workona-to-obsidian"
    name:   "Workona Import"
