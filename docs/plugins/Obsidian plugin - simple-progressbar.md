# Simple ProgressBar

Simple ProgressBar inserts isolated, customizable and interactive progress bars into notes through Markdown code blocks. Every property of the object can be configured, and progress is advanced with built-in control buttons.

```cue
plugin: {
    id:     "simple-progressbar"
    name:   "Simple ProgressBar"
    author: "isragdd"
    repo:   "isragdd12/simple-progressbar"

    html_url:    "https://community.obsidian.md/plugins/simple-progressbar"
    github_url:  "https://github.com/isragdd12/simple-progressbar"
    description: "Create isolated, highly customizable and interactive progress bars. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert interactive progress bars into notes using simple Markdown code blocks. Customize every property of the object, and control progress with built-in control buttons."

    stats: {
        downloads:  179

}
```
