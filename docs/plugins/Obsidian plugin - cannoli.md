# Cannoli

Cannoli builds and runs no-code LLM scripts inside Obsidian Canvas, where cards and arrows define variables, logic, HTTP actions and data flows. Scripts can read and write the vault, stream formatted output and run chatbots, and are triggered from canvas files, note properties or audio recordings. It connects to OpenAI, Anthropic, Gemini, Groq or a local Ollama model.
