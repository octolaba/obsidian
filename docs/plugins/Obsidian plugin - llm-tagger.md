# LLM Tagger

Tags documents automatically using local Ollama models, generating relevant tags and a brief summary while leaving the original content intact. The tag list is customizable, files and folders can be excluded by pattern, and auto-tagging can be enabled for new, modified, or closed notes while unchanged files are not re-tagged.

plugin: {
    id:     "llm-tagger"
    name:   "LLM Tagger"
    author: "djayatillake"
    repo:   "djayatillake/obsidian-llm-tagger"

    html_url:    "https://community.obsidian.md/plugins/llm-tagger"
