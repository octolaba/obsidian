# Scatter Plot for Bases

Scatter Plot for Bases turns a Bases table into an interactive scatter plot by mapping two numeric properties to the X and Y axes. Points can be colored by category, hovered for a preview and clicked to open the underlying note, while axes scale automatically and missing values are handled without breaking the chart.

```cue
plugin: {
    id:     "scatter-chart-bases"
    name:   "Scatter Plot for Bases"
    author: "martinseeler"
    repo:   "martinseeler/obsidian-scatter"

    html_url:    "https://community.obsidian.md/plugins/scatter-chart-bases"
    github_url:  "https://github.com/martinseeler/obsidian-scatter"
    description: "Visualize notes as points on a 2D chart using any numeric properties. Find patterns, spot outliers, prioritize visually. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Turn Bases tables into interactive scatter plots by mapping two numeric properties to X and Y. Click dots to open notes, hover for previews, color points by category, and rely on auto-scaled axes with graceful handling of missing values."
```
