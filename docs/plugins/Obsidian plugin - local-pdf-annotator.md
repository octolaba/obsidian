# PDF Annotator

Reads PDFs inside Obsidian through an integrated pdf.js viewer, with highlighted passages, page notes and margin annotations. Annotations are stored as a local Markdown sidecar beside each PDF so the original file is left unchanged, and they remain searchable. Page tags can be added and margin cards moved between margins.

    id:     "local-pdf-annotator"
    name:   "PDF Annotator"
    author: "Tianchen Hao"
