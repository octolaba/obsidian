# Handwriting PDF

Converts handwritten PDF notes into formatted Markdown with Gemini document understanding, keeping headings, lists, emphasis, tables and LaTeX equations while correcting spelling, grammar, capitalization and punctuation. Dated notes are created, optionally with a concise summary. The original PDF, or a locally OCR-processed copy made with bundled JavaScript, can be embedded at the end.
