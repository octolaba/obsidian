# Search External Files

Search External Files browses files outside the vault from within Obsidian and searches the vault for matching file or folder paths. Selecting an item previews images and information, or starts a search by name or path. It operates read-only, so vault files are never modified.

```cue
plugin: {
    id:     "search-external-files"
    name:   "Search External Files"
    author: "ttt"
    repo:   "tttt-k/obsidian-search-external-files"

    html_url:    "https://community.obsidian.md/plugins/search-external-files"
    github_url:  "https://github.com/tttt-k/obsidian-search-external-files"
    description: "Browse external files and search for file or folder paths in Obsidian. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Browse external files from within Obsidian and search your vault for matching file or folder paths. Select items to preview images and information or to search by name or path; operate read-only so your vault files are never modified."

    stats: {
        downloads:  117
        updated_at: 1778677653000
    }
}
```
