# Worklog

Tracks monthly work hours as tasks, daily time entries and a calendar of completion status, storing the data in local JSON archived by year. A yearly board reports monthly trends, the share of each task type and per-project totals. New monthly tasks are generated from a template, daily records are edited or deleted, duplicate entries for the same task on one day are refused, and tasks that already carry logged hours are protected. The recorded About text is written in Chinese; this is an English restatement of it.
