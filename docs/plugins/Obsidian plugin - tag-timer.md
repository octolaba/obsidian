# Tag Timer

Tag Timer adds inline stopwatches and goal-oriented countdowns to notes and reports how long is spent on each task. Clickable badges start, pause, reset or delete a timer, one timer per line is enforced, and completion raises a notification. All running timers in the vault can be paused at once, and timers are restored after a crash or a reload.
