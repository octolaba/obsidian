# Annoteca

Adds categorized inline feedback to long-form Markdown documents using plain HTML markers that stay in the file and remain readable without the plugin. Threaded comments anchor to a selection or the cursor and are managed in a right-sidebar hub with Thread, Outline and Starred views. Markers are stripped cleanly at export, and the plugin runs on desktop and mobile.
