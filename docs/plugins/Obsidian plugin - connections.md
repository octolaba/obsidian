# Connections

Connections defines named connections between notes and lists them in a Connections pane, from which one can also be deleted. Frontmatter properties are mapped to connection types so that readable statements are generated automatically, and either side of a connection can be chosen as the subject.

```cue
plugin: {
    id:     "connections"
    name:   "Connections"
    author: "evancleve"
    repo:   "evancleve/obsidian-connections"

    html_url:    "https://community.obsidian.md/plugins/connections"
    github_url:  "https://github.com/evancleve/obsidian-connections"
    description: "Define and view named connections between your notes."
    about:       "Define and view named connections between notes. Display all connections in the Connections pane and delete ones you no longer need. Map frontmatter properties to connection types to auto-generate readable statements and choose which side serves as the subject."
```
