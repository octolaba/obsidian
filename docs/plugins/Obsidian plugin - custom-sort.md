# Custom File Explorer sorting

Reorders files and folders in the File Explorer by drag-and-drop or by config-driven rules. Per-folder or per-group orders are declared in frontmatter and manual and automatic sorting can be mixed. Entries can be ordered by numbers, dates, Roman numerals, wildcards or metadata, with inheritance and grouping.

```cue
plugin: {
    id:     "custom-sort"
    name:   "Custom File Explorer sorting"
    author: "sebastianmc"
    repo:   "sebastianmc/obsidian-custom-sort"

    html_url:    "https://community.obsidian.md/plugins/custom-sort"
    github_url:  "https://github.com/sebastianmc/obsidian-custom-sort"
    description: "Manual or automatic config-driven reordering and sorting of files and folders in File Explorer."
    about:       "Arrange notes and folders in Obsidian's File Explorer by drag-and-drop or detailed config-driven rules. Define per-folder or group orders in frontmatter, mix manual and automatic sorting, and order by numbers, dates, Roman numerals, wildcards, or metadata with inheritance and grouping."
```
