# Full Calendar

Embeds a calendar in the vault so events and schedules are managed alongside other notes. Each event is saved as its own note whose frontmatter carries the details and can link to other notes. Events are read from note frontmatter or from daily notes, and read-only ICS and CalDAV calendars can also be displayed.

```cue
plugin: {
    id:     "obsidian-full-calendar"
    name:   "Full Calendar"
    author: "obsidian-community"
    repo:   "obsidian-community/obsidian-full-calendar"

    html_url:    "https://community.obsidian.md/plugins/obsidian-full-calendar"
    github_url:  "https://github.com/obsidian-community/obsidian-full-calendar"
    description: "Keep events and manage your calendar alongside all your other notes in your vault."
    about:       "Embed a calendar in your vault to manage schedules and events alongside notes. Save each event as its own note with frontmatter to add context and link to other notes. Pull events from note frontmatter or daily notes and display read-only ICS and CalDAV calendars."
```
