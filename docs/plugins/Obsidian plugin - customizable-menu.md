# Customizable Menu

Adds any command, including commands contributed by community plugins, to the right-click context menu of Obsidian, and hides commands there. Icons are chosen from the internal Obsidian set or from Lucide, and hiding applies globally across context menus by exact command name.

```cue
plugin: {
    id:     "customizable-menu"
    name:   "Customizable Menu"
    author: "kzhovn"
    repo:   "kzhovn/obsidian-customizable-menu"

    html_url:    "https://community.obsidian.md/plugins/customizable-menu"
    github_url:  "https://github.com/kzhovn/obsidian-customizable-menu"
    description: "Add any command to Obsidian's right-click menu."
    about:       "Customize the right-click context menu by adding or hiding any command, including community-plugin commands, directly in notes. Assign custom icons from Obsidian's internal set or Lucide, and hide commands globally across context menus by exact name."

    stats: {
        downloads:  29849

    }
}
```
