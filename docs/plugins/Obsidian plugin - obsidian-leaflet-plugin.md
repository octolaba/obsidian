# Leaflet

Embeds interactive maps inside notes from a leaflet code block, built on the Leaflet library. Image files or OpenStreetMap tiles serve as map layers, linked markers open the notes they point at, and zoom, size and overlays are controlled from the block.

```cue
plugin: {
    id:     "obsidian-leaflet-plugin"
    name:   "Leaflet"
    author: "javalent"
    repo:   "javalent/obsidian-leaflet"

    html_url:    "https://community.obsidian.md/plugins/obsidian-leaflet-plugin"
    github_url:  "https://github.com/javalent/obsidian-leaflet"
    description: "Interactive maps inside your notes."
    about:       "Embed interactive maps in notes using Leaflet.js via a leaflet code block. Use image files or OpenStreetMap tiles as layers, place linked markers that open notes, and control zoom, size and overlays."
```
