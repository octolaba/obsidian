# Center on Reveal

Center on Reveal keeps the file explorer on the active file by enabling auto-reveal at startup, centering the revealed row and applying Obsidian's native flash highlight. It leans on built-in explorer behavior and adds no commands, settings, network calls, telemetry or custom CSS.

```cue
plugin: {
    id:     "center-on-reveal"
    name:   "Center on Reveal"
    author: "toadfans"
    repo:   "toadfans/obsidian-center-on-reveal"

    html_url:    "https://community.obsidian.md/plugins/center-on-reveal"
    github_url:  "https://github.com/toadfans/obsidian-center-on-reveal"
    description: "Centers and highlights the active file when it is revealed in the file explorer. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Keep the file explorer focused on the active file by enabling auto-reveal at startup, centering the revealed row, and applying Obsidian's native flash highlight. Rely on built-in explorer behavior without adding commands, settings, network calls, telemetry, or custom CSS."
```
