# GitHub Wiki

Syncs a vault with a GitHub wiki so wiki pages can be edited from Obsidian. Top-level files in a designated wiki folder are mapped to GitHub wiki pages, and changes are pushed to or pulled from the wiki repository.

```cue
plugin: {
    id:     "github-wiki-sync"
    name:   "GitHub Wiki"
    author: "benpm"
    repo:   "benpm/obsidian_github_wiki"

    html_url:    "https://community.obsidian.md/plugins/github-wiki-sync"
    github_url:  "https://github.com/benpm/obsidian_github_wiki"
    description: "Edit GitHub wiki pages with Obsidian! - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync an Obsidian vault with a GitHub Wiki and edit wiki pages directly from Obsidian. Map top-level files in a designated wiki folder to GitHub wiki pages and push or pull changes to the wiki repository."

    stats: {
        downloads:  134
        updated_at: 1778885820000
    }
}
```
