# File Title Updater

File Title Updater keeps the filename, the frontmatter title and the first heading of a note in agreement, with any of the three chosen as the source. Commands run on an individual file, or recursively over a folder and its subfolders. Which of the title locations are updated is selectable.

```cue
plugin: {
    id:     "file-title-updater"
    name:   "File Title Updater"
    author: "wenlzhang"
    repo:   "wenlzhang/obsidian-file-title-updater"

    html_url:    "https://community.obsidian.md/plugins/file-title-updater"
    github_url:  "https://github.com/wenlzhang/obsidian-file-title-updater"
    description: "Synchronize titles between filename, frontmatter, and first heading in notes."
    about:       "Sync titles across filename, frontmatter title, and first-level heading by choosing any of them as the source. Run targeted commands on individual files or apply recursive bulk sync to folders and subfolders and select which title locations to update."

    stats: {
        downloads:  4582
        updated_at: 1774689591000
    }
}
```
