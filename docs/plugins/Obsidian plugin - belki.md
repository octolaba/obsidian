# belki

belki is a Todoist-like task manager that keeps tasks as readable Markdown inside the vault, stored locally with no external connections. Tasks are created, edited, completed, rescheduled and deleted with due dates, deadlines, priorities, labels and attachments across Inbox, Today, Upcoming, Projects and Filters views. Metadata can be changed by dragging, and the views refresh automatically when the files change on disk.
