# Link Preview

Shows a preview of an external link when it is hovered, so a webpage snapshot can be seen without leaving Obsidian. The preview size and the hover delay are configurable, and the recorded inputs describe the preview window as native-looking and matched to the current theme.

```cue
plugin: {
    id:     "link-preview"
    name:   "Link Preview"
    author: "felipetappata"
    repo:   "felipetappata/obsidian-link-preview"

    html_url:    "https://community.obsidian.md/plugins/link-preview"
    github_url:  "https://github.com/felipetappata/obsidian-link-preview"
    description: "Show a preview of external links on hover"
    about:       "Preview external links on hover to view webpage snapshots without leaving Obsidian. Configure preview size and hover delay, and display a clean, native-looking window that matches your theme."

    stats: {
        downloads:  6464

}
```
