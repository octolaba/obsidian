# Claude Sync

Imports Claude chat exports from a watched folder into the vault, preserving the original subfolder structure. The watched and destination folders are configurable, source files can be deleted after import, and a sync can also be triggered by hand from a command or the ribbon.

```cue
plugin: {
    id:     "claude-sync"
    name:   "Claude Sync"
    author: "gbanjos"
    repo:   "gbanjos/claude-sync-obsidian"

    html_url:    "https://community.obsidian.md/plugins/claude-sync"
    github_url:  "https://github.com/gbanjos/claude-sync-obsidian"
    description: "Automatically imports Claude chat exports from a watched folder into your vault. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Import Claude chat Markdown files from a watched folder into your vault and preserve original subfolder structure. Configure watch and destination folders, delete source files after import if desired, and trigger manual syncs via command or ribbon."

    stats: {
        downloads:  317

    }
}
```
