# Close Window When Empty

Closes the Obsidian window once the last note is closed, roughly the way a browser behaves. On macOS the application keeps running after the window closes, while on Windows and Linux it quits.

```cue
plugin: {
    id:     "close-window-when-empty"
    name:   "Close Window When Empty"
    author: "taylorjadin"
    repo:   "taylorjadin/close-window-when-empty"

    html_url:    "https://community.obsidian.md/plugins/close-window-when-empty"
    github_url:  "https://github.com/taylorjadin/close-window-when-empty"
    description: "Close the window when the last note is closed, kind of how browsers work."
    about:       "Close the Obsidian window when the last note is closed to mirror browser tab behavior. Leave the app running on macOS after window close, and quit the app on Windows and Linux."

    stats: {
        downloads:  418
        updated_at: 1763588423000
    }
}
```
