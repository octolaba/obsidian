# 3D Model Viewer

3D Model Viewer previews local STL, OBJ and 3MF files inside notes through an embedded viewer. Models are centered and auto-scaled and drawn without grid, axes or shadows, and inspection uses mouse rotation, wheel zoom, ninety-degree in-plane turns and a view cube.
