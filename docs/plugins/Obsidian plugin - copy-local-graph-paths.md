# Copy Local Graph Paths

Copy Local Graph Paths copies the file paths of the links in the current note to the clipboard, formatted for use outside Obsidian. A custom base path can be prepended, folders excluded by name, and the output separated by newlines or semicolons for documentation, scripts or RAG workflows.
