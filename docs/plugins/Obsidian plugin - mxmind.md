# Mxmind Mindmap

Converts Markdown files into interactive Mxmind mind maps and opens the Mxmind editor in Obsidian's left sidebar for editing in place. Mind map images are copied into notes. The recorded text states that the plugin uses the mxmind.com remote service and that an mxmind account may be required for saving and syncing.
