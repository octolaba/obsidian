# Quran Lookup

This plugin looks up Quran verses and translations from a Surah and Ayah shorthand given by number or by name, replacing the selected text with a formatted callout carrying the ayah number, the Arabic text and a translation. Surah names are matched fuzzily and ranges can be chained. The translation display, the language and the translator are selectable, and Arabic styling or alternate container types can be applied.

```cue
plugin: {
    id:     "obsidian-quran-lookup"
    name:   "Quran Lookup"
    author: "abuibrahim2"
    repo:   "abuibrahim2/quranlookup"

    html_url:    "https://community.obsidian.md/plugins/obsidian-quran-lookup"
    github_url:  "https://github.com/abuibrahim2/quranlookup"
    description: "Easily add Quran verses and translations."
    about:       "Lookup Quran verses by Surah:Ayah shorthand (number or name) and replace the selected text with a formatted Obsidian callout showing ayah number, Arabic text, and translation. Use fuzzy Surah-name matching, chained ranges, toggle translation display, choose language/translator, and apply Arabic styling or alternate container types."

    stats: {

}
```
