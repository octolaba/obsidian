# Zhihu Reader

Zhihu Reader reads Zhihu questions and answers inside Obsidian, rendering the content as native Markdown in a dedicated reader panel that shows one answer at a time. A chosen answer can be saved as a Markdown note with metadata and optional image download. Comments, an author's answers, hot-list search and history are browsable, and voting is available after logging in.

```cue
plugin: {
    id:     "zhihu-reader"
    name:   "Zhihu Reader"
    author: "ZHENG ANYUAN"
    repo:   "iamzay/obsidian-zhihu-reader"

    html_url:    "https://community.obsidian.md/plugins/zhihu-reader"
    github_url:  "https://github.com/iamzay/obsidian-zhihu-reader"
    description: "Read Zhihu questions and answers inside Obsidian. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Read Zhihu questions and answers inside Obsidian and render content as native Markdown in a dedicated reader panel that shows one answer at a time. Save chosen answers as Markdown notes with metadata and optional image download; browse comments, author answers, search hot lists and history, and vote after logging in."

    stats: {
        downloads:  24

    }
}
```
