# mdshare

Shares a Markdown file or a selected passage to mdshare.live without signing in. The upload returns a shareable link and copies the admin URL to the clipboard. The recorded text states that shared documents expire after 90 days.

```cue
plugin: {
    id:     "mdshare"
    name:   "mdshare"
    author: "urbanmorph"
    repo:   "urbanmorph/obsidian-mdshare"

    html_url:    "https://community.obsidian.md/plugins/mdshare"
    github_url:  "https://github.com/urbanmorph/obsidian-mdshare"
    description: "Share markdown files instantly via mdshare.live. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Share Markdown files or selected text to mdshare.live instantly without signing in. Upload content to generate a shareable link with the admin URL copied to your clipboard; shared documents expire after 90 days."

    stats: {
        downloads:  243

}
```
