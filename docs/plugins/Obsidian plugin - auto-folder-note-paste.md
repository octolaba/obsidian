# Auto Folder Note Paste

Auto Folder Note Paste converts a note into a folder note when an attachment is pasted or dragged into it, so the attachment is saved inside that note. Its recorded About states that the default attachment location must be set to the same folder as the current file for this to behave correctly.

```cue
plugin: {
    id:     "auto-folder-note-paste"
    name:   "Auto Folder Note Paste"
    author: "d7sd6u"
    repo:   "d7sd6u/obsidian-auto-folder-note-paste"

    html_url:    "https://community.obsidian.md/plugins/auto-folder-note-paste"
    github_url:  "https://github.com/d7sd6u/obsidian-auto-folder-note-paste"
    description: "Automagically convert the note to a folder note when pasting or drag'n'dropping an attachment."
    about:       "Convert a note into a folder note so pasted or dragged attachments are saved inside that note. Set the default attachment location to \"Same folder as current file\" for correct behavior."

    stats: {
        downloads:  1305
        updated_at: 1741792098000
    }
}
```
