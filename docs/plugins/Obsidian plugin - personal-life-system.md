# Life OS Assistant

Life OS Assistant organises diary entries, tasks, projects, knowledge and long-term memory inside the vault, with local-first daily capture and review workflows. It extracts tasks and tracks project progress through overview cards and lists of unfinished tasks. AI-assisted reviews run over selected vault, task or web context, and daily, weekly and monthly dashboards summarise the result.
