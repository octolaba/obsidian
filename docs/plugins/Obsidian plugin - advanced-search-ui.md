# Advanced Search UI

Advanced Search UI builds search queries through a visual builder of dropdowns and fields covering AND, OR and NOT logic, regex and case-sensitive matching. Conditions and groups are added, removed, reordered by drag-and-drop and copied or pasted, with quick pickers for files, tags and paths. Queries run in a floating search panel or are sent to Graph view for color-grouped inspection.
