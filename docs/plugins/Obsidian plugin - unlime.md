# UnLime

Toggles the visibility of unlinked mentions in the Backlinks and Outgoing Links panels. Each panel is toggled independently, so irrelevant unlinked entries can be hidden to reduce clutter in a large vault.

    id:     "unlime"
    name:   "UnLime"
    author: "shandyba"
    repo:   "shandyba/obsidian-lime"

    html_url:    "https://community.obsidian.md/plugins/unlime"
    github_url:  "https://github.com/shandyba/obsidian-lime"
