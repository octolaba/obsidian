# GitHub Integration

Imports starred GitHub repositories into the vault as individual notes carrying repository metadata and direct links. Tags are created automatically from language and topics, fields such as owner, URL, stars and creation or modification dates are stored, and syncing is incremental so only newly starred repositories are added.

```cue
plugin: {
    id:     "github"
    name:   "GitHub Integration"
    author: "kazhuravlev"
    repo:   "kazhuravlev/obsidian-github"

    html_url:    "https://community.obsidian.md/plugins/github"
    github_url:  "https://github.com/kazhuravlev/obsidian-github"
    description: "Sync your data from GitHub into your Vault."
    about:       "Import starred GitHub repositories into your Obsidian vault as individual notes with rich metadata and direct links. Create automatic tags for language and topics, store repo fields (owner, URL, stars, created/modified), and sync incrementally to update only new stars."
```
