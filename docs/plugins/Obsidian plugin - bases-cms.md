# Bases CMS

Bases CMS turns a base into a card-based content management view with thumbnails, snippets and property-rich grids. It adds bulk actions, including publish and draft toggles, setting or removing tags and properties, and deletion with folder and unique-attachment cleanup. Obsidian commands can be run from a card, and the toolbar and icons are customizable.
