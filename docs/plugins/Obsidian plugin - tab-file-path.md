# Tab File Path

Shows the full vault-relative file path in tab titles, so each note's location is visible from its tab. The recorded About text states that this makes files with identical names easier to tell apart.

```cue
plugin: {
    id:     "tab-file-path"
    name:   "Tab File Path"
    author: "johnburnett"
    repo:   "johnburnett/obsidian-tab-file-path"

    html_url:    "https://community.obsidian.md/plugins/tab-file-path"
    github_url:  "https://github.com/johnburnett/obsidian-tab-file-path"
    description: "Shows file paths in tabs"
    about:       "Display full vault-relative file paths in tab titles to show each note's location at a glance. Make it easy to distinguish files with identical names."
```
