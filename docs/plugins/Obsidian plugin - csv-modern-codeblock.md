# CSV Modern Codeblock

Renders CSV and TSV fenced code blocks as interactive scrollable tables with sticky headers, per-column filters, sorting, layout toggles and automatic link detection. Quoted, escaped and multiline fields are parsed, delimiters detected, and malformed CSV reported with the row and field concerned. Per-cell editing is also supported.
