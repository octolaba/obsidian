# Life Tracker

Life Tracker charts data captured in the vault through twelve chart types, including heatmaps and tag clouds, with animated interactive charts whose tooltips link back to the source notes. Several cards can be added per property, properties overlaid to compare correlations, and views filtered by date range, with presets, colour schemes and reference lines.
