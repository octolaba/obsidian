# Urso

Explores tags and frontmatter properties as navigable trees, so a slash tag such as #world/region/place becomes a collapsible hierarchy. Matching notes are listed beside the current selection, can be sorted and dated, and icons or pins can be assigned to tags, properties and notes. A hotkey creates a new note from the selected tag or property, and the layout switches between a resizable split view on desktop and tablet and single-pane navigation on phones.
