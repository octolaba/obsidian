# Index Notes

Keeps notes indexed by their hierarchical tags, generating index blocks inside notes and updating them automatically when tags change. The nested lists of links are written into the files, so the graph reflects the structure, and new notes can be created with the same metadata and location.

```cue
plugin: {
    id:     "index-notes"
    name:   "Index Notes"
    author: "adanielnoel"
    repo:   "adanielnoel/obsidian-index-notes"

    html_url:    "https://community.obsidian.md/plugins/index-notes"
    github_url:  "https://github.com/adanielnoel/obsidian-index-notes"

    about:       "Generate index blocks inside notes from tag hierarchies and auto-update them when tags change, producing nested lists of links that are written into files so the graph reflects your structure.
```
