# SuperTags

A tagged line is turned into a structured note and the line itself is replaced by a wikilink to it. The new note is pre-filled with the exact frontmatter and body of a template, and several supertags can produce different note types. The recorded inputs describe the plugin as working on desktop, on mobile and with Obsidian Sync, and as showing an undo notice.
