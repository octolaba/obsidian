# Daily Notes Viewer

Daily Notes Viewer gathers recent daily notes onto a single page for quick reference. The viewer file is created automatically and updated whenever a daily note is created or the settings change.

```cue
plugin: {
    id:     "obsidian-daily-notes-viewer"
    name:   "Daily Notes Viewer"
    author: "johnsonhong997"
    repo:   "johnsonhong997/obsidian-daily-notes-viewer"

    html_url:    "https://community.obsidian.md/plugins/obsidian-daily-notes-viewer"
    github_url:  "https://github.com/johnsonhong997/obsidian-daily-notes-viewer"
    description: "Help you to view some recent daily notes on one page."
```
