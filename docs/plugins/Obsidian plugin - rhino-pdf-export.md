# Rhino PDF Export

Rhino PDF Export renders Markdown notes to styled PDFs with configurable themes, a logo, headers and footers, watermarks, pagination, an automatic table of contents and PDF bookmarks. Exports can be previewed, folders batched or merged into a single PDF, and per-note settings overridden from frontmatter. Themes can be created or imported and persist, and Obsidian callouts are rendered in full.
