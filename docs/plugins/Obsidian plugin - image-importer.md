# Image Importer

Imports images into the vault from the device or from the web, with JPEG and PNG named as supported formats. An accompanying Markdown file can be created on import under a custom name, local files can be copied or moved, and image URLs can be pasted automatically from the clipboard. Default behaviours for these choices are configurable.

```cue
plugin: {
    id:     "image-importer"
    name:   "Image Importer"
    author: "ahmed-hegazi0"
    repo:   "ahmed-hegazi0/image-importer"

    html_url:    "https://community.obsidian.md/plugins/image-importer"
    github_url:  "https://github.com/ahmed-hegazi0/image-importer"
    description: "Import images into the vault from the device or the web, with an option to create an accompanying markdown file on import. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Import images from your device or the web into your vault (JPEG, PNG supported). Create an optional accompanying Markdown file with a custom name, choose to copy or move local files, and auto-paste image URLs from the clipboard while setting default behaviors."

    stats: {
        downloads:  151
        updated_at: 1766915341000
    }
}
```
