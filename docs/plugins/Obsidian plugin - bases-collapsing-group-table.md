# Collapsing Group Table

Collapsing Group Table renders grouped Bases Table or Card results as a collapsible tree with foldable group headers and inline row editing, including tag and link autocomplete. It supports nested slash-delimited categories or several groupBy properties, an accordion mode, and expand and collapse-all controls, while preserving the Base view's columns, sorting and filtering as well as badge properties on Card view.
