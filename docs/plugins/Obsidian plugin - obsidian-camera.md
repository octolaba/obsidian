# Camera

Camera creates and saves snaps and video recordings straight into the vault as files. A link to the recording is inserted into the open Markdown note automatically, and saved media is browsed with a file picker. It targets desktop use, and some differences are expected on mobile devices.

```cue
plugin: {
    id:     "obsidian-camera"
    name:   "Camera"
    author: "aldrinjenson"
    repo:   "aldrinjenson/obsidian-camera"

    html_url:    "https://community.obsidian.md/plugins/obsidian-camera"
    github_url:  "https://github.com/aldrinjenson/obsidian-camera"
    description: "Create and save snaps or video recordings."
    about:       "Capture photos and videos directly into your vault and save recordings as files. Insert links to recordings automatically into the open Markdown note and browse saved media with a file picker. Target desktop use; expect some differences on mobile devices."

        downloads:  15652

}
```
