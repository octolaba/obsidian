# RefRaindrop

Imports Raindrop.io bookmarks into the vault as compact Markdown reference notes holding the URL, Raindrop metadata, local notes, and AI frontmatter, without storing the full page content. Several accounts can be kept, and notes are updated by Raindrop ID or by URL. An AI indexing pass writes summaries and retry states into reserved frontmatter.

```cue
plugin: {
    id:     "ref-raindrop"
    name:   "RefRaindrop"
    author: "oikeya"
    repo:   "oikeya/obsidian-ref-raindrop"

    html_url:    "https://community.obsidian.md/plugins/ref-raindrop"
    github_url:  "https://github.com/oikeya/obsidian-ref-raindrop"
    description: "Import Raindrop.io bookmarks as AI-friendly reference notes without storing full page content. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync Raindrop.io bookmarks into your vault as compact Markdown notes with URL, Raindrop metadata, local notes, and AI frontmatter—without saving full page content. Keep multiple accounts, update by Raindrop ID or URL, and run AI indexing to store summaries and retry states in reserved frontmatter."

    }
}
```
