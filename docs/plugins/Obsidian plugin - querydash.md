# QueryDash

Displays Bases and Dataview-powered data as tables, lists, timelines, galleries or Anki-style memory cards. Queries are written in Dataview SQL, and results are searched, filtered, aggregated and paginated, with tasks editable in place. The recorded description names Dataview, Bases and Notion as the reference points for its search, sorting and pagination.
