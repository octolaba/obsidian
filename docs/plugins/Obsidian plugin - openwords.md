# OpenWords

OpenWords memorizes vocabulary for English learning and manages a word bank stored in OpenText format, scheduling review and dictation with the SuperMemo-2 spaced repetition algorithm. It generates an index and a .base view grouped by first letter and adds doubly linked lists between entries. Word file metadata is synchronized with the cache in real time, and modifications are written back to the source file.
