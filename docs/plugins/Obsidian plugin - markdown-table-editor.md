# Markdown Table Editor

Markdown Table Editor edits Markdown tables in a visual, spreadsheet-like editor inside Obsidian. CSV files and data from Microsoft Excel or Google Sheets can be opened and converted into Markdown tables. Rows and columns can be added, deleted and moved, columns sorted and justified, and table content updated in place.
