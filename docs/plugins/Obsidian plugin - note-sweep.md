# Note Sweep

Scores notes by stale, orphan, duplicate and avoidance signals and surfaces the top cards to deal with that day. Timed declutter sessions can start automatically each day, the interface is Korean and English, and the recorded description states that the plugin uses no network, no AI and no telemetry.
