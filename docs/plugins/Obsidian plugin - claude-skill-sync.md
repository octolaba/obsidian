# Claude Skill Sync

Keeps agent skills in one vault folder and symlinks it into the local skill directories of Claude Code, Codex, Cursor, Gemini and other tools, so every tool reads the same files. A sidebar with an eight-cell status grid drives bidirectional install and import, scheduled automatic syncing, and one-click repair or cleanup of links that broke or moved between machines. The recorded inputs count more than fourteen supported tools and more than eighteen presets.
