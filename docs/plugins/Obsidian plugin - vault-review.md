# Vault Review

Takes a snapshot of the vault and walks through its notes one at a time in random order. A file can be marked as reviewed or deleted, progress is tracked with statistics, and status is changed from commands, the ribbon or the status bar. The recorded About states that notes created after a snapshot are not added to it automatically.

```cue
plugin: {
    id:     "vault-review"
    name:   "Vault Review"
    author: "sashakryzh"
    repo:   "sashakryzh/obsidian-vault-review"

    html_url:    "https://community.obsidian.md/plugins/vault-review"
    github_url:  "https://github.com/sashakryzh/obsidian-vault-review"
    description: "Randomly review your vault and track progress."
    about:       "Create a snapshot of your vault and review notes one-by-one in random order. Mark files as reviewed or delete them, track progress with built-in statistics, and update file status via commands, ribbon, or status bar; new notes aren't added to snapshots automatically."

    stats: {
        downloads:  480
        updated_at: 1728972245000
    }
}
```
