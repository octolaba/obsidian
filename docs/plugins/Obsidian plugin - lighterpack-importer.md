# LighterPack importer

This plugin imports a packing list from its public LighterPack share link and converts it into structured Markdown in the vault. It creates category folders and one note per item, plus a summary page with totals, a category breakdown and a weight-distribution pie chart, so that the list can be read and edited offline.

```cue
plugin: {
    id:     "lighterpack-importer"
    name:   "LighterPack importer"
    author: "nsiniscalchi"
    repo:   "nsiniscalchi/LighterPackObsidianImporter"

    html_url:    "https://community.obsidian.md/plugins/lighterpack-importer"
    github_url:  "https://github.com/nsiniscalchi/LighterPackObsidianImporter"
    description: "Import a packing list from https://lighterpack.com."
    about:       "Import shared LighterPack packing lists via their public share link and convert them into structured Markdown stored in your vault. Create category folders, individual item notes, and a summary page showing totals, category breakdowns, and a weight-distribution pie chart for offline viewing and editing."
```
