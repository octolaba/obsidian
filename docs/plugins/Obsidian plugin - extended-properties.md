# Extended Properties

Extended Properties presents note properties in a configurable sidebar whose sections can be arranged, working on desktop and mobile. Value types are rich, layouts are defined per note Type through frontmatter, and dice rolling is available. Feature modules such as a D&D 5e character sheet can be toggled on.

```cue
plugin: {
    id:     "extended-properties"
    name:   "Extended Properties"
    author: "electroluminescent"
    repo:   "electroluminescent/obsidian-extended-properties"

    html_url:    "https://community.obsidian.md/plugins/extended-properties"
    github_url:  "https://github.com/electroluminescent/obsidian-extended-properties"
    description: "A configurable sidebar for note properties: arrangeable sections, rich value types, dice rolling, per-type layouts, and toggleable feature modules such as a D&D 5e character sheet. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Organize and edit note metadata in a fully arrangeable, data-driven sidebar that works on desktop and mobile. Define custom layouts per note Type via frontmatter and build rich, sectioned property panels with extensible modules."
```
