# Notes 2 Tweets

Generates tweets from the notes in the vault and schedules them, starting from a single click. Long-form content is converted into tweet-sized posts and threads, the output can be previewed, and items can be queued for automatic publishing.

    id:     "notes2tweets"
    name:   "Notes 2 Tweets"
    author: "tej-sharma"
    repo:   "tej-sharma/notes2tweets-obsidian"
