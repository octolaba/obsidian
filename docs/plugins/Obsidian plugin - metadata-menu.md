# Metadata Menu

Metadata Menu gives access to note metadata from right-click menus and dataview tables, covering YAML frontmatter and Dataview-style inline fields. Fields can be typed and defined globally or per file through fileClass presets, with autocompletion drawn from preset values. Dates, files, lookups, nested objects and canvas fields are handled as field types.
