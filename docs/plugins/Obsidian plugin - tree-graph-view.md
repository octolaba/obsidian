# Tree

Visualises the vault as a forest of tree graphs, arranging notes hierarchically as a dendrogram and replicating multi-parent notes so branches stay untangled. Parent-child relations are read from frontmatter, tags, outlinks or backlinks, with original links preserved and cycles handled. Layout and themes are adjusted from a floating settings panel.
