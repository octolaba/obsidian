# Vault Brain

Runs multimodal AI locally through a Gemma 4 model on an Ollama endpoint, with the recorded inputs stating that no data leaves the machine and no API key is required. Voice memos are transcribed and summarized, text is extracted from images into Markdown, and semantic search, chat and editing run over the whole vault with cited results and previewable diffs.
