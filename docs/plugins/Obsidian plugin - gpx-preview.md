# GPX Preview

Renders embedded GPX files as rounded map cards showing the drawn route, start and finish markers and an optional title. Workout statistics such as distance, duration and average speed are shown, with optional pace, moving time, maximum speed and elevation, in metric or imperial units. Rendered PNGs are cached for offline previews, and the basemap can be CARTO, OpenStreetMap or Apple Maps, the last requiring a developer key.
