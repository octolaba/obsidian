# Custom Syntax Highlights

Displays files with custom extensions as syntax-highlighted code blocks in reading view, driven by configurable extension-to-language mappings. Configured files can switch to reading view automatically so the file appears as a single clean block.

```cue
plugin: {
    id:     "custom-syntax-highlights"
    name:   "Custom Syntax Highlights"
    author: "outsiders17711"
    repo:   "outsiders17711/Obsidian-Custom-Syntax-Highlights"

    html_url:    "https://community.obsidian.md/plugins/custom-syntax-highlights"
    github_url:  "https://github.com/outsiders17711/Obsidian-Custom-Syntax-Highlights"
    description: "Display files with custom extensions as syntax-highlighted code blocks in reading view with configurable extension-to-language mappings."
    about:       "Render files with custom extensions as syntax-highlighted code blocks in Reading view. Map extensions to any supported language and auto-switch configured files to Reading view for a clean, single-block display."
```
