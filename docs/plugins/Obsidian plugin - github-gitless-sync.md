# GitHub Gitless Sync

Syncs an Obsidian vault with a GitHub repository without requiring a Git installation. It runs on desktop and mobile, can keep several vaults in sync automatically or manually, and provides a conflict resolution view for inspecting differences.

```cue
plugin: {
    id:     "github-gitless-sync"
    name:   "GitHub Gitless Sync"
    author: "silvanocerza"
    repo:   "silvanocerza/github-gitless-sync"

    html_url:    "https://community.obsidian.md/plugins/github-gitless-sync"
    github_url:  "https://github.com/silvanocerza/github-gitless-sync"
```
