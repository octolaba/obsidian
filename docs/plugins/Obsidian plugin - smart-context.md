# Smart Context

Smart Context copies folder contents or open notes to the clipboard as reusable context bundles, with specified headings excluded. Bundles are built, saved and reopened from folders, files or selected blocks using templates, so they can be pasted straight into ChatGPT or another language model. Its recorded About text states that the data stays local and private.

```cue
plugin: {
    id:     "smart-context"
    name:   "Smart Context"
    author: "🌴 Brian"
    repo:   "brianpetro/smart-context-obsidian"

    html_url:    "https://community.obsidian.md/plugins/smart-context"
    github_url:  "https://github.com/brianpetro/smart-context-obsidian"
    description: "Instantly copy folder contents or open notes—excluding specified headings—into your clipboard."
    about:       "Collect and clean the notes you need into reusable context bundles and copy them to the clipboard in one click. Build, save, and reopen templated contexts from folders, files, or selected blocks to paste straight into ChatGPT or other LLMs while keeping your data local and private."

    stats: {
        downloads:  27828
        updated_at: 1780144771000
    }
}
```
