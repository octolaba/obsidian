# MCP Connector

MCP Connector links MCP-compatible clients such as Claude Desktop, Claude Code and Cline to an Obsidian vault, letting an assistant read notes, run templates, execute commands and perform semantic searches. Command execution is gated by confirmation and recorded in an audit log. The recorded description states that a local MCP server mediates all access, enforces allowlists and confirmations, and that the AI is never given direct file access.
