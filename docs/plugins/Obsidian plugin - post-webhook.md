# Post Webhook

Sends notes or selected text to one or more webhook endpoints, carrying YAML frontmatter, inline fields, attachments, and rendered HTML, for integration with services such as n8n, Make.com and Zapier. Webhook responses can be inserted back into notes, additional context notes included, and complex JSON responses with attachments handled.
