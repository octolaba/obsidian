# Calendar List

Calendar List pulls events from macOS Calendar and inserts them into a note as a configurable, formatted list of titles, dates and times. It is triggered inline with a double closing parenthesis or through the Insert Calendar Events command, which offers presets or a custom date range. Slow calendars can be excluded to skip unwanted sources.

```cue
plugin: {
    id:     "calendar-list"
    name:   "Calendar List"
    author: "Sebastien Delisle"
    repo:   "lumargh/obsidian-calendar-list"

    html_url:    "https://community.obsidian.md/plugins/calendar-list"
    github_url:  "https://github.com/lumargh/obsidian-calendar-list"
    description: "Insert a list of macOS Calendar events between two dates. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Pull events from your Calendar and insert them into your notes as a configurable, formatted list of titles, dates, and times. Trigger inline with `))` or run the Insert Calendar Events command to pick presets or a custom range, and exclude slow calendars to skip unwanted sources."
```
