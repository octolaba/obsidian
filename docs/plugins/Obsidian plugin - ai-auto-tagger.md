# AI Auto Tagger

AI Auto Tagger generates tags for the active note with Google's Gemini API and inserts them into the frontmatter. Tags are sanitized to Obsidian format, their number can be limited, and existing vault tags can be reused so labeling stays consistent.

    id:     "ai-auto-tagger"
    name:   "AI Auto Tagger"
    author: "oyuk"
