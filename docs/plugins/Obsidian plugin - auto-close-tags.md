# Auto Close Tags

Closes HTML tags while they are typed or pasted, handling nested tags and self-closing elements. A manual command closes the last unclosed tag, specific tags can be excluded from auto-closing, and fenced code blocks and inline code can be ignored.

```cue
plugin: {
    id:     "auto-close-tags"
    name:   "Auto Close Tags"
    author: "k0src"
    repo:   "k0src/Obsidian-Auto-Close-Tags-Plugin"

    html_url:    "https://community.obsidian.md/plugins/auto-close-tags"
```
