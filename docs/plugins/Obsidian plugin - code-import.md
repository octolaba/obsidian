# Code Import

Pulls external code files into a note with an import directive compatible with Markdown Preview Enhanced. Specific line ranges can be selected and relative paths used, parent directories included, and the imported code is displayed with automatic syntax highlighting in Reading View.

```cue
plugin: {
    id:     "code-import"
    name:   "Code Import"
    author: "yhao3"
    repo:   "yhao3/obsidian-code-import"

    html_url:    "https://community.obsidian.md/plugins/code-import"
    github_url:  "https://github.com/yhao3/obsidian-code-import"
    description: "Import code files with @import syntax. Compatible with Markdown Preview Enhanced. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Import external code files into your notes using @import syntax (compatible with Markdown Preview Enhanced). Select specific line ranges, use relative paths (including ../), and display imported code with automatic syntax highlighting in Reading View."

    stats: {
        downloads:  79
        updated_at: 1782884325000
    }
}
```
