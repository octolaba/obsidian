# Aide

Adds AI writing and editing to notes with streaming responses and inline actions such as improve, shorten, summarize, translate and fix grammar. A floating slash prompt runs custom prompts, web searches and URL fetches, and can generate SVG diagrams saved into assets. Any OpenAI-compatible provider can be connected, with adjustable reasoning effort.
