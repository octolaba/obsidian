# Emacs Keybindings Lite

Adds Emacs-style cursor movement, selection, kill and yank and line-mode editing through a CodeMirror keymap, while common Windows shortcuts are preserved. It can operate on visual (wrapped) or logical lines, enable key repeat when a key is held, and toggle its non-native extensions off.

    id:     "emacs-lite"
    name:   "Emacs Keybindings Lite"
    author: "Ashpega"
    repo:   "ashpega/emacs-lite"

    html_url:    "https://community.obsidian.md/plugins/emacs-lite"
    github_url:  "https://github.com/ashpega/emacs-lite"
    description: "Emacs-like keybindings for Obsidian, designed for Windows users. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Bring Emacs-style cursor movement, selection, kill/yank and line-mode editing to Obsidian on Windows while preserving common Windows shortcuts. Switch between visual (wrapped) and logical lines, enable key-repeat for hold behavior, and toggle non-native extensions via a CodeMirror keymap."
