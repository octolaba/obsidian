# Syncian

The vault is synced and backed up across devices end-to-end encrypted, with file names and contents encrypted on-device using AES-256-GCM and PBKDF2-derived keys. Versioned history and reversible deletes are retained against silent data loss, and vault access is shared or revoked through a companion bot, currently over Telegram only. An account is required, with a free tier and paid plans adding storage and vault limits, and the index records that this plugin has not been manually reviewed by Obsidian staff.
