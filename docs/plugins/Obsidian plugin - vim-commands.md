# Vim Commands

Vim Commands maps Vim-style multi-key sequences to any Obsidian command, including commands contributed by community plugins. Mappings support leaders and modified keys and work across tabs, sidebars and other views, not only the editor. They live in a vault-local vimrc file, and the plugin extends Obsidian's native Vim editing rather than replacing it.

```cue
plugin: {
    id:     "vim-commands"
    name:   "Vim Commands"
    author: "Mateusz Kowalczyk"
    repo:   "mateuszkowalczyk/obsidian-vim-commands"

    html_url:    "https://community.obsidian.md/plugins/vim-commands"
    github_url:  "https://github.com/mateuszkowalczyk/obsidian-vim-commands"
    description: "Map any Obsidian command to Vim-style multi-key sequences that work everywhere, not only in the editor. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Map Vim-style key sequences directly to any Obsidian command, including commands from community plugins. Vim Commands supports multi-key mappings, leaders, and modified keys across tabs, sidebars, and other app views, not only the editor. Mappings live in a vault-local vimrc file. The plugin extends rather than replaces Obsidian's native Vim editing."
```
