# Attachment Renamer

Renames pasted, dragged and existing attachments through a dialog that shows live previews and counters and allows the full path to be edited so subfolders are created. Names come from templates including header, uuid and custom values, with padding and case transforms. Several full-path ignore patterns can be defined, and an attachment can be deleted when the dialog is cancelled.
