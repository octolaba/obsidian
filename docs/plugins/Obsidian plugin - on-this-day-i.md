# On This Day I

On This Day I summarises a calendar date across previous years from daily journals. A customizable placeholder tag inserted at the cursor marks where the generated content goes, and the plugin scans past daily notes for the same date and inserts a Through the Years reflection produced through an OpenAI API key.

```cue
plugin: {
    id:     "on-this-day-i"
    name:   "On This Day I"
    author: "benstuart0"
    repo:   "benstuart0/on-this-day-i-obsidian"

    html_url:    "https://community.obsidian.md/plugins/on-this-day-i"
    github_url:  "https://github.com/benstuart0/on-this-day-i-obsidian"
    description: "Summarize a calendar date in years past with Daily Journals"
    about:       "Insert a customizable placeholder tag at the cursor to mark where AI-generated content should be placed. Generate \"Through the Years\" summaries by scanning past daily notes for the same date and inserting concise reflections generated via your OpenAI API key."

    stats: {
        downloads:  439
        updated_at: 1747331595000
    }
}
```
