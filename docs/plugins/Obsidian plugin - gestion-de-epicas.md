# Gestion de epicas

Manages product epics, stories, sprints, tasks, pending items and a roadmap as Markdown notes organized inside the vault. Each item is stored in a portable file with frontmatter in automatically created folders for traceability. The recorded inputs are written in Spanish and state that the interface is Spanish and that it runs on Obsidian Desktop only.

```cue
plugin: {
    id:     "gestion-de-epicas"
    name:   "Gestion de epicas"
    author: "Leonardo Ruano"
    repo:   "leozymandyas/gestion-de-epicas"

    html_url:    "https://community.obsidian.md/plugins/gestion-de-epicas"
    github_url:  "https://github.com/leozymandyas/gestion-de-epicas"
    description: "Concentra toda la información de una épica de producto en un solo lugar: tareas, pendientes, sprints y roadmap como notas Markdown dentro del vault. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Gestiona épicas, historias, sprints, tareas, pendientes y roadmap como notas Markdown organizadas dentro de tu vault. Almacena cada elemento en archivos .md portables con frontmatter y carpetas automáticas para trazabilidad; interfaz en español (solo Obsidian Desktop)."
```
