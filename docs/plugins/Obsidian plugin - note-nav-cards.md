# Note Nav Cards

Note Nav Cards renders navigation cards from a note-nav code block, showing the previous note, the next one, or both, with keys accepted in English and Spanish. Links are resolved and opened through Obsidian's API, and the cards adapt their styling to light and dark themes. The plugin's own description is written in Spanish.

plugin: {
    id:     "note-nav-cards"
    name:   "Note Nav Cards"
    author: "David Torro"

    html_url:    "https://community.obsidian.md/plugins/note-nav-cards"
