# Highlight Public Notes

Colors the titlebar of a note that is marked public, either through a frontmatter attribute or by sitting in a specified folder. The red warning is meant to prevent confidential or sensitive data from being added to notes intended for publishing.

```cue
plugin: {
    id:     "obsidian-highlightpublicnotes-plugin"
    name:   "Highlight Public Notes"
    author: "dennisseidel"
    repo:   "dennisseidel/highlightpublicnotes-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-highlightpublicnotes-plugin"
    github_url:  "https://github.com/dennisseidel/highlightpublicnotes-obsidian-plugin"
    description: "Warn that a note is public (based on a frontmatter attribute) by coloring the note red."
    about:       "Highlight titlebars of notes marked as public via frontmatter or placed in a specified folder. Show a red visual warning to prevent accidentally adding confidential or sensitive data to notes you plan to publish."

    stats: {
        downloads:  6969
        updated_at: 1659193325000
    }
}
```
