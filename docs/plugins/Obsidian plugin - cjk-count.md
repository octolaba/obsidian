# CJK Count

Counts only Chinese, Japanese and Korean characters and displays the total in the status bar. Text is filtered with cjk-regex so nothing else contributes to the count, and the interface is available in English and Chinese.

```cue
plugin: {
    id:     "cjk-count"
    name:   "CJK Count"
    author: "vrabe"
    repo:   "vrabe/obsidian-cjk-count"

    html_url:    "https://community.obsidian.md/plugins/cjk-count"
    github_url:  "https://github.com/vrabe/obsidian-cjk-count"
    description: "A word counter that only counts Chinese, Japanese and Korean (CJK) characters."
    about:       "Count Chinese, Japanese, and Korean characters and display the total in Obsidian's status bar. Filter text with cjk-regex for accurate CJK-only counts and include UI in English and Chinese."
```
