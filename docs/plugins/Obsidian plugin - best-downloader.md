# Best Downloader

Best Downloader downloads video and audio into the vault using yt-dlp. Audio-only output in MP3, M4A or OPUS and combined video and audio in MP4 or WebM can be selected along with the destination folder. The recorded inputs describe it as desktop software requiring yt-dlp and FFmpeg for muxing, and the index description narrows that further to Windows only; English and Russian interface languages are supported.

```cue
plugin: {
    id:     "best-downloader"
    name:   "Best Downloader"
    author: "trikorka"
    repo:   "trikorka/BestDownloader"

    html_url:    "https://community.obsidian.md/plugins/best-downloader"
    github_url:  "https://github.com/trikorka/BestDownloader"
    description: "Download videos and audio in various formats directly to your vault using yt-dlp. Windows only - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Download videos and audio directly into your vault using yt-dlp. Save audio-only (MP3/M4A/OPUS) or video+audio (MP4/WebM), choose vault folders for downloads, and run on Obsidian desktop (requires yt-dlp and FFmpeg for muxing). Supports English and Russian languages."

    stats: {
        downloads:  203
        updated_at: 1783282384000
    }
}
```
