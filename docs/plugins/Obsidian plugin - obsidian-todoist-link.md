# Todoist Link

A Todoist project is created from the current note, named after the file, and a deep link to it is inserted. A Todoist task is created from the current line, with deep links written in both directions between the note and the task.

```cue
plugin: {
    id:     "obsidian-todoist-link"
    name:   "Todoist Link"
    author: "dennisseidel"
    repo:   "dennisseidel/obsidian-todoist-link"

    html_url:    "https://community.obsidian.md/plugins/obsidian-todoist-link"
    github_url:  "https://github.com/dennisseidel/obsidian-todoist-link"
    description: "Create Todoist tasks and projects including bidirectional links from Obsidian."
    about:       "Create Todoist projects from the current note and insert a deep link to the new project named after the file. Add Todoist tasks from the current line and create deep links between the note and task for quick two-way navigation."

    stats: {
        downloads:  13137
        updated_at: 1670445854000
    }
}
```
