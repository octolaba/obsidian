# Newledge (Xinzhi)

Newledge (Xinzhi) imports data from the Newledge (新枝) service into Obsidian, preserving the related diary property so imported items link into Daily Notes through backlinks. An account is bound by scanning the plugin's QR code in the Newledge app, after which synchronisation runs on a schedule or by hand.
