# Waka time box

The plugin shows daily WakaTime coding activity at the top of the daily note. Stats are fetched hourly by default, and the existing entry is refreshed instead of a duplicate being inserted. An immediate refresh can be triggered from the command palette.

```cue
plugin: {
    id:     "waka_time_box"
    name:   "Waka time box"
    author: "simonla"
    repo:   "simonla/obsidian_waka_box"

    html_url:    "https://community.obsidian.md/plugins/waka_time_box"
    github_url:  "https://github.com/simonla/obsidian_waka_box"
    description: "Show daily coding activity from WakaTime."
    about:       "Display WakaTime coding stats at the top of your daily notes. Fetch stats hourly by default and refresh the existing entry instead of inserting duplicates; force an immediate refresh from the command palette."

    stats: {
        downloads:  4003
        updated_at: 1692207804000
    }
}
```
