# Note Reading Progress

Shows the remaining reading time and the scroll progress of the active note in both edit and preview modes, on desktop and on mobile. Progress percentage, time format and reading speed are configurable, and a status-bar pill sized for mobile carries a stable CSS class for custom styling.

```cue
plugin: {
    id:     "note-reading-progress"
    name:   "Note Reading Progress"
    author: "keithwithAI"
    repo:   "keithwithai/reading-progress"

    html_url:    "https://community.obsidian.md/plugins/note-reading-progress"
    github_url:  "https://github.com/keithwithai/reading-progress"
    description: "Shows remaining reading time and scroll progress for the current note in both edit and reading modes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Show remaining reading time and scroll progress for the active note in both edit and preview modes on desktop and mobile. Display optional progress percentage, multiple time formats, configurable reading speed, and a mobile-friendly status-bar pill with a stable CSS class for custom styling."

    stats: {

    }
}
```
