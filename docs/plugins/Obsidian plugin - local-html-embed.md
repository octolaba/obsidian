# Local HTML Embed

Embeds a vault-local HTML file inside a note through an html-embed code block, so reports, diagrams, dashboards or interactive prototypes render in Markdown. UTF-8 and relative assets are preserved through a generated base URL, paths are vault-relative or automatic, and the iframe height is fixed or automatic. Fallback theme variables are injected, and blocks can be presented collapsibly for section-based layouts.

```cue
plugin: {
    id:     "local-html-embed"
    name:   "Local HTML Embed"
    author: "shygoly"
    repo:   "shygoly/obsidian-local-html-embed"

    html_url:    "https://community.obsidian.md/plugins/local-html-embed"
    github_url:  "https://github.com/shygoly/obsidian-local-html-embed"
    description: "Embed a vault-local HTML file inside notes via an html-embed code block. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed a vault-local HTML file inside a note using an html-embed code block to view reports, diagrams, dashboards, or interactive prototypes directly in Markdown. Preserve UTF-8 and relative assets with a generated base URL, support vault-relative or auto mode, offer fixed or automatic iframe height, and inject fallback theme variables with optional collapsible presentation for section-based layouts."
```
