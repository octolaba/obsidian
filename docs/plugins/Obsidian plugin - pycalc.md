# pycalc

Executes Python code inline in the editor when the Enter key is pressed, so short calculations and simple scripting run in place inside a note. Execution runs on Brython 3.13 rather than an external interpreter.

    id:     "pycalc"
    name:   "pycalc"
    author: "pycalc-plugin"
    repo:   "pycalc-plugin/obsidian"

    html_url:    "https://community.obsidian.md/plugins/pycalc"
