# Bionic Reading

The plugin bolds the leading portion of each word in Reading View, creating fixation points intended to move the eye through text faster. It processes Latin-alphabet text only, skips code, math and SVG elements, and leaves the Markdown files themselves unchanged. Fixation strength is adjustable.

```cue
plugin: {
    id:     "bionic-reading"
    name:   "Bionic Reading"
    author: "omeg-lu"
    repo:   "omeg-lu/obsidian-bionic-reading"

    html_url:    "https://community.obsidian.md/plugins/bionic-reading"
    github_url:  "https://github.com/omeg-lu/obsidian-bionic-reading"
    description: "Applies a bionic reading effect in Reading View by bolding the first portion of each word for faster reading. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Apply a bionic reading effect in Reading View by bolding the initial portion of words to create fixation points and help eyes move through text faster. Process only Latin-alphabet text, skip code/math/SVG elements, keep Markdown files unchanged, and adjust fixation strength."

    stats: {
        downloads:  1260
        updated_at: 1772739565000
    }
}
```
