# HTML Tabs

HTML Tabs renders tabbed panels that group content under labeled tabs. Labels are plain text and the panels accept full Markdown, including transcluded notes and fenced code blocks, and the appearance is adjusted with a CSS snippet.

```cue
plugin: {
    id:     "html-tabs"
    name:   "HTML Tabs"
    author: "ptournet"
    repo:   "ptournet/obsidian-html-tabs"

    html_url:    "https://community.obsidian.md/plugins/html-tabs"
    github_url:  "https://github.com/ptournet/obsidian-html-tabs"
    description: "Create and render Tabs and tab panels in your notes."
    about:       "Insert tabbed panels into notes to group content under labeled tabs. Use plain-text labels and full Markdown inside tabs (including transcluded notes and fenced code blocks), and tweak appearance with a CSS snippet."

    stats: {
        downloads:  8130
        updated_at: 1701624990000
    }
}
```
