# Password Manager

Keeps accounts, passwords and links inside the vault in JSON-based storage presented through a three-column interface. Data is encrypted locally, entries can be searched and grouped, backup and restore and JSON or Markdown import and export are supported together with automatic export to a Markdown file, and deleted items can be recovered from a recycle bin.
