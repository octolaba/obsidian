# Scholar

Scholar manages a local research library: a paper is imported from a web link, its PDF is downloaded and a metadata-rich note is created. The library can be searched or Semantic Scholar queried, abstracts and references are shown inline, and BibTeX can be copied. Syncing with PDF++ supplies in-file citations and automatic note updates.
