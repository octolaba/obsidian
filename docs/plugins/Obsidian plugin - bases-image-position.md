# Bases Image Position

Bases Image Position controls how images are positioned inside Bases card views so the subject is not cropped out. The position is read from note frontmatter and can be set with presets for the center, edges and corners or as precise offsets in common CSS units, and the frontmatter key names can be renamed in settings.

```cue
plugin: {
    id:     "bases-image-position"
    name:   "Bases Image Position"
    author: "Lucas Ostmann"
    repo:   "luceast/obsidian-bases-image-position"

    html_url:    "https://community.obsidian.md/plugins/bases-image-position"
    github_url:  "https://github.com/luceast/obsidian-bases-image-position"
```
