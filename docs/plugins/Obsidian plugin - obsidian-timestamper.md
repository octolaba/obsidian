# TimeStamper

A time- or date-stamp is inserted at the cursor position from two preconfigured templates or from an ad-hoc format dialog. The last custom format is saved for reuse and formats are written with moment.js tokens. Desktop and mobile are both supported.

```cue
plugin: {
    id:     "obsidian-timestamper"
    name:   "TimeStamper"
    author: "gru80"
    repo:   "gru80/obsidian-timestamper"

    html_url:    "https://community.obsidian.md/plugins/obsidian-timestamper"
    github_url:  "https://github.com/gru80/obsidian-timestamper"
    description: "Insert a customized or predefined time- or date-stamp at the current cursor position."
    about:       "Insert time- or date-stamps into notes using two preconfigured templates or an ad-hoc format dialog. Save and reuse the last custom format and use moment.js tokens for flexible formatting. Work on both desktop and mobile Obsidian."
```
