# Explorer Focus

Narrows the file explorer to one file or folder, showing only that item together with its children and its ancestors. The target is the current file, its parent, grandparent or great-grandparent, or a folder chosen explicitly, and focus is toggled from a command, the right-click menu or a toolbar button in the explorer.

    id:     "explorer-focus"
