# Verse of the Day

The plugin inserts YouVersion's Verse of the Day into a note from the Command Palette. Combined with Templater it can be automated, so the verse is added whenever a new file is created.

```cue
plugin: {
    id:     "verse-of-the-day"
    name:   "Verse of the Day"
    author: "janisringli"
    repo:   "janisringli/verse-of-the-day-for-obsidian"

    html_url:    "https://community.obsidian.md/plugins/verse-of-the-day"
    github_url:  "https://github.com/janisringli/verse-of-the-day-for-obsidian"
    description: "Lets you add the verse of the day from YouVersion to your notes"
    about:       "Insert the YouVersion Verse of the Day into any note via the Command Palette. Automate daily insertion with Templater to add the verse when creating new files."

    stats: {
        downloads:  634
        updated_at: 1762175820000
    }
}
```
