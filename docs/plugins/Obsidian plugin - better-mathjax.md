# Better MathJax

Better MathJax adds autocompletion for MathJax with live inline rendering while typing inside math blocks. A helper modal shows the candidates, snippets are inserted as editable templates reachable by hotkey with quick placeholder navigation, and the behavior is customizable in settings.

    id:     "better-mathjax"
    name:   "Better MathJax"
    author: "greasycat"
    repo:   "greasycat/BetterMathjax"
