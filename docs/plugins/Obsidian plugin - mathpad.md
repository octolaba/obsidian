# Mathpad

Mathpad is a computer algebra system and calculator for Obsidian, performing symbolic and numeric calculations and rendering 2D plots in a sidebar built on Nerdamer. Calculations and plots are inserted inline or as code blocks. Results can be exported into notes either as dynamic code or as static LaTeX.
