# Bindery

Bindery formats Markdown book projects by applying typographic substitutions — curly quotes, em-dashes, ellipses and smart apostrophes — and by merging chapters into a clean manuscript. It exports the result to several formats and can connect to an MCP server that offers full-text search and AI assistant integration.
