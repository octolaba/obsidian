# Image Workflow

Opens an image in a fullscreen overlay where it can be zoomed with the mouse wheel, copied, downloaded or dismissed. A Markdown selection can be exported as plain Markdown plus rich HTML with the images embedded as base64, so it pastes inline into Gmail, Google Docs and Slack, and pasting back into Obsidian restores the original embeds without the base64 bulk.

```cue
plugin: {
    id:     "image-workflow"
    name:   "Image Workflow"
    author: "das"
    repo:   "1spread/image-workflow"

    html_url:    "https://community.obsidian.md/plugins/image-workflow"
    github_url:  "https://github.com/1spread/image-workflow"
    description: "Click images to enlarge, zoom, copy, download. Copy markdown selections with images embedded as base64 so they paste inline into Gmail, Google Docs, and Slack. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open images in a fullscreen overlay with mouse-wheel zoom and easy dismiss. Copy or download images, export selections as plain markdown plus rich HTML with images embedded as base64 for inline pasting into Gmail, Google Docs, and Slack, and paste back into Obsidian to restore original embeds without base64 bloat."
```
