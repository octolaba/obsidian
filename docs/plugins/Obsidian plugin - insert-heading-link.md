# Insert Heading Link

Insert Heading Link adds a command that inserts a link to a heading at the cursor position. The generated link is wiki-style and points at a specific section, and it is bound to a single hotkey for quick navigation.

```cue
plugin: {
    id:     "insert-heading-link"
    name:   "Insert Heading Link"
    author: "signynt"
    repo:   "signynt/insert-heading-link"

    html_url:    "https://community.obsidian.md/plugins/insert-heading-link"
    github_url:  "https://github.com/signynt/insert-heading-link"
    description: "Add a command to create a link to a heading."
    about:       "Insert a link to a heading with a single hotkey (Cmd + Shift + L). Generate wiki-style heading links like [[##]] at the cursor for quick navigation to specific sections."

    stats: {
        downloads:  5260
        updated_at: 1779368047000
    }
}
```
