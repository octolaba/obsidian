# Fantasy Map

Fantasy Map displays a campaign map from an image in the vault, switches between maps, and links maps into hierarchies so a reader can drill down and back. Features are markers or drawn polygon and rectangular regions carrying names, descriptions, tags, linked notes and labeled relations to other features. Scale is calibrated from two points, a dynamic scale bar is displayed, and a ruler measures distances.
