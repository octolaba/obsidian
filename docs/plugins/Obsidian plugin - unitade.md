# UNITADE.md

Registers arbitrary file extensions with Obsidian so files open regardless of type, and assigns which view handles them. Registered files can be rendered as editable code with a code-editor interface and syntax highlighting, with modals for creating and renaming files and registries that can be unloaded. Compatibility modules are included for older plugin versions.
