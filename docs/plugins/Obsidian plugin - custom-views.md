# Custom Views

Builds custom HTML views of notes from templates and file-based filter rules. Notes are matched by file properties, frontmatter or tags, with conditions combined by AND, OR and NOR. Field values pass through filter chains and note content can be rendered as Markdown, which the recorded inputs present as a way to build card views and dashboards.

```cue
plugin: {
    id:     "custom-views"
    name:   "Custom Views"
    author: "Anup Chavan"
    repo:   "anupchavan/obsidian-custom-views"

    html_url:    "https://community.obsidian.md/plugins/custom-views"
    github_url:  "https://github.com/anupchavan/obsidian-custom-views"
    description: "Create custom HTML views for your notes based on filter rules. Transform how your notes are displayed. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create custom HTML views for notes using templates and file-based filter rules. Match notes by file properties, frontmatter, or tags and combine conditions with AND/OR/NOR. Transform fields with filter chains and render note content as Markdown to build card views, dashboards, or tailored displays."
```
