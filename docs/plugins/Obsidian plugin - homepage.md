# Homepage

Homepage opens a chosen note, canvas, base or workspace on startup, from the sidebar, or through a command. It controls how previously open tabs are handled, whether the target opens in reading or source view, and can run any Obsidian command when it opens. Integration with plugins such as Daily Notes or Periodic Notes is stated in its recorded inputs.

```cue
plugin: {
    id:     "homepage"
    name:   "Homepage"
    author: "mirnovov"
    repo:   "mirnovov/obsidian-homepage"

    html_url:    "https://community.obsidian.md/plugins/homepage"
    github_url:  "https://github.com/mirnovov/obsidian-homepage"
    description: "Open a note, base, or workspace on startup, or set it for quick access later."
    about:       "Set a specified note, canvas, base, or workspace that can be opened on startup, launched from the sidebar, or used as a command. Control how previous tabs are handled, open in reading or source view, or run any Obsidian command on open. Supports integration with plugins such as Daily or Periodic Notes."

    stats: {

}
```
