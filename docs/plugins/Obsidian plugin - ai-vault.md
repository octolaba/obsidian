# AI-Vault

Chats with GPT and Claude inside notes, drawing context from notes and canvases through local RAG indexing. Models can be switched, conversations organized into projects with separate prompts, and history saved outside the vault. Responses stream, token costs are tracked, and live web results can be fetched.
