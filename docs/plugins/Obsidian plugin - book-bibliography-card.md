# Book Bibliography Card

The plugin displays a book cover and bibliography looked up from an ISBN through OpenBD. An ISBN written inside a code block is rendered as a book card. No About text is recorded for this plugin, so nothing beyond its description is stated here.

```cue
plugin: {
    id:     "book-bibliography-card"
    name:   "Book Bibliography Card"
    author: "the-town"
    repo:   "the-town/book-bibliography-card"

    html_url:    "https://community.obsidian.md/plugins/book-bibliography-card"
    github_url:  "https://github.com/the-town/book-bibliography-card"
    description: "Display book cover and bibliography from ISBN (OpenBD). Write ISBN in a code block to show a book card. - This plugin has not been manually reviewed by Obsidian staff."

    stats: {
        downloads:  127
        updated_at: 1769869101000
    }
}
```
