# LanguageTool Integration

Runs LanguageTool grammar and spelling checks over a whole document or a selected passage inside Obsidian. Findings are underlined in red and a suggestion popover applies a correction or adds the word to a personal dictionary. A self-hosted LanguageTool server can be used instead of the public one for privacy.
