# Cloze

Converts highlighted, underlined, bolded or otherwise selected text into cloze deletions in editing and reading mode, and toggles each one when it is clicked. Hints can be shown, answers revealed on hover or from the context menu, clozes created or removed in batches, and every cloze toggled at once from the ribbon.
