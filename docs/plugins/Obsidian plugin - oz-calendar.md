# OZ Calendar

Shows notes on a calendar using a date taken from any YAML key or from the file name. Custom date formats can be defined so that entries are parsed correctly and notes can be located by date.

```cue
plugin: {
    id:     "oz-calendar"
    name:   "OZ Calendar"
    author: "ozntel"
    repo:   "ozntel/oz-calendar"

    html_url:    "https://community.obsidian.md/plugins/oz-calendar"
    github_url:  "https://github.com/ozntel/oz-calendar"
    description: "View your notes in Calendar using any YAML key with a date."
    about:       "Display notes on a calendar using dates extracted from a YAML key or the file name. Define custom date formats to parse entries and quickly locate notes by date."

    stats: {
        downloads:  21829
        updated_at: 1711887827000
    }
}
```
