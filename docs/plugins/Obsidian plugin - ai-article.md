# AI Article

AI Article extracts article writing styles from one or several reference notes and saves them to a style library. New articles are then generated in a chosen style and written to a generated-drafts folder.

```cue
plugin: {
    id:     "ai-article"
    name:   "AI Article"
    author: "jiang"
    repo:   "javajiang/article_ai"

    html_url:    "https://community.obsidian.md/plugins/ai-article"
    github_url:  "https://github.com/javajiang/article_ai"
    description: "Extract article style from notes and generate articles for your workspace. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Extract article writing styles from single or multiple reference notes and save them to a style library. Generate new articles in a chosen style and save outputs to a generated-drafts folder for consistent, style-matched content."

    stats: {
        downloads:  153

}
```
