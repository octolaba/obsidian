# Note Status

Tracks the lifecycle of vault files through customizable statuses that apply to Markdown and non-Markdown files alike. Statuses can be shown and changed from the status bar, the editor toolbar, the file explorer and commands, and templates, multi-status workflows, explorer icons and dashboards give vault-wide visibility and quick actions.
