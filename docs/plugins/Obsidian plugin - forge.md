# Forge

Checks a vault against the structure it is meant to have: schemas are validated, frontmatter and tags normalized, structural drift repaired, and bulk updates applied to standardize notes. Relationship indexes and exportable views are built so that Dataview, Bases, dashboards and automations keep working as the vault grows.
