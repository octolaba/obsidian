# Slash Inserter

Slash Inserter provides a Notion-style slash menu triggered at the start of a line or after a space, and narrowed by typing. It inserts headings, lists, callouts, fenced code, math, mermaid diagrams, internal links and video embeds. It can also fetch OpenGraph metadata to build a rich preview card, falling back to a plain Markdown link when the metadata is unavailable.

```cue
plugin: {
    id:     "slash-commands"
    name:   "Slash Inserter"
    author: "Jimmy-web169"
    repo:   "jimmy-web169/obsidian-slash-commands"

    html_url:    "https://community.obsidian.md/plugins/slash-commands"
    github_url:  "https://github.com/jimmy-web169/obsidian-slash-commands"
    description: "Notion-style / slash menu to quickly insert headings, lists, callouts, code blocks, link cards and more. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert blocks with a Notion-style slash menu by typing / at the start of a line or after a space. Filter commands by typing and add headings, lists, callouts, fenced code, math, mermaid, internal links, video embeds, or fetch OpenGraph metadata to insert rich preview cards (falls back to a markdown link if metadata is unavailable)."

    stats: {
        downloads:  489

    }
}
```
