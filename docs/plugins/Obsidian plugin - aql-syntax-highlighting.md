# AQL Syntax Highlighting

Adds syntax highlighting for the ANNIS Query Language inside fenced code blocks. It registers a CodeMirror AQL mode with tokens for strings, operators, metadata, node references and node classes, and ships an optional CSS snippet for ANNIS-style node colors.

    id:     "aql-syntax-highlighting"

    author: "Poorvi Acharya"
