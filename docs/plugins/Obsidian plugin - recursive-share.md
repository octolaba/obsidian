# Recursive Share

Creates shareable links for individual notes that also carry embedded images, drawings, and linked attachments. Access is managed through a backend service, which generates public or controlled links for viewing outside the vault.

plugin: {
    id:     "recursive-share"
    name:   "Recursive Share"
    author: "Christian B."
    repo:   "bloeckchengrafik/obsidian-recursive-share"

    html_url:    "https://community.obsidian.md/plugins/recursive-share"
    github_url:  "https://github.com/bloeckchengrafik/obsidian-recursive-share"
    description: "Share notes and resources with others - This plugin has not been manually reviewed by Obsidian staff."
