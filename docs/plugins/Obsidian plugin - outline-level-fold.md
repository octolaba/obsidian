# Outline Level Fold

Folds the active note's outline to a chosen heading depth from one to six, or unfolds it entirely, through hotkey-bindable commands that jump directly between depths. Commands can apply to a selection, folding relative to the shallowest selected line, or to the whole note; space-indented and tab-indented outlines are supported and the current level is shown in the status bar.
