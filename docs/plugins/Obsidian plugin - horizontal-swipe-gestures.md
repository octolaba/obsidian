# Horizontal Swipe Gestures

Horizontal Swipe Gestures maps two-finger horizontal trackpad swipes to any Obsidian command, defaulting to back and forward navigation. Swipe sensitivity and horizontal dominance are adjustable, macOS momentum filtering can be enabled, and a half-circle indicator appears at the note edge when a swipe fires.

    id:     "horizontal-swipe-gestures"
