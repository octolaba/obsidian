# AmpliFlow Page Publisher

Publishes the active note to AmpliFlow as a Markdown page with a single command. Publishing requires authenticating with an AmpliFlow account first.

```cue
plugin: {
    id:     "ampliflow-page"
    name:   "AmpliFlow Page Publisher"
    author: "pbjorklund"
    repo:   "pbjorklund/obsidian-ampliflow-page"

    html_url:    "https://community.obsidian.md/plugins/ampliflow-page"
    github_url:  "https://github.com/pbjorklund/obsidian-ampliflow-page"
    description: "Publish notes easily to AmpliFlow (https://www.ampliflow.se)"
    about:       "Publish notes to AmpliFlow as Markdown pages with a single command. Authenticate with your AmpliFlow account and push the active note directly from Obsidian."

    stats: {
        downloads:  220
        updated_at: 1731069461000
    }
}
```
