# Banners Reloaded

Banners Reloaded adds customizable banners to notes and resolves which banner applies globally, by tag or per note. Five visual styles are offered, among them gradients, blurs and a curved swoosh, focal alignment is set by dragging, a templated header can overlay the banner using the filename or any frontmatter property, and the content margin controls how far the text overlaps.
