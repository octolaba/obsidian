# Enhanced Publisher

Stores pasted images in a per-document assets folder that is hidden from the sidebar, and previews the note as HTML in a choice of themes. The rendered page is copied for use on other platforms or published through a platform API, with the WeChat Official Account supported. The HTML preview renders Mermaid diagrams, LaTeX math and Chinese ruby annotations.

```cue
plugin: {
    id:     "enhanced-publisher"
    name:   "Enhanced Publisher"
    author: "chararch"
    repo:   "chararch/obsidian-enhanced-publisher"

    html_url:    "https://community.obsidian.md/plugins/enhanced-publisher"
    github_url:  "https://github.com/chararch/obsidian-enhanced-publisher"
    description: "Add improved image saving, cleaner HTML preview, and publishing to content platforms such as WeChat."
    about:       "Store pasted images automatically in a [document_name]__assets folder and hide that folder in the sidebar. Preview Markdown as HTML with multiple themes, copy the rendered page for online platforms, or publish directly via platform APIs (WeChat Official Account supported). Render Mermaid diagrams, LaTeX math, and Chinese ruby annotations in the HTML preview."

    stats: {
        downloads:  2478
        updated_at: 1779528889000
    }
}
```
