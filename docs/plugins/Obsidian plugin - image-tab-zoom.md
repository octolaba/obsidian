# Image Tab Zoom

Adds pinch-to-zoom and modifier-scroll zoom to image files opened in their own tab, on desktop and iOS. Dragging pans the image when it is zoomed, the point under the cursor stays anchored while zooming, and a double-click or double-tap resets the view.
