# New Bullet With Time

This plugin automatically inserts the current time into new bullet lines as they are created. The time format is customizable, and a regular expression detects bullets that already start with a time.

```cue
plugin: {
    id:     "obsidian-new-bullet-with-time"
    name:   "New Bullet With Time"
    author: "quorafind"
    repo:   "quorafind/Obsidian-New-Bullet-With-Time"

    html_url:    "https://community.obsidian.md/plugins/obsidian-new-bullet-with-time"
    github_url:  "https://github.com/quorafind/Obsidian-New-Bullet-With-Time"
    description: "Automatically add the current time to new bullet lines."
    about:       "Insert the current time into new bullet lines as you create them. Customize the time format and use a regex to detect bullets that already start with a time."

    stats: {
        downloads:  7212
        updated_at: 1743653796000
    }
}
```
