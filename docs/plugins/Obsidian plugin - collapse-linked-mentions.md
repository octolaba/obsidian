# Collapse Linked Mentions

Collapse Linked Mentions collapses embedded backlink mentions automatically, reducing visual clutter when scanning a note. Links stay visible while the expanded mention content is hidden.

```cue
plugin: {
    id:     "collapse-linked-mentions"
    name:   "Collapse Linked Mentions"
    author: "n810k"
    repo:   "n810k/obsidian-collapse-linked-mentions"

    html_url:    "https://community.obsidian.md/plugins/collapse-linked-mentions"
```
