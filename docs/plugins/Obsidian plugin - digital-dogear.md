# Digital Dogear

Records reading and listening positions by appending a one-line dogear entry to the daily note for any ordered medium — books, shows, podcasts, comics, audiobooks or courses. The next position is suggested automatically, consecutive sittings merge into ranges, and accidental skips are flagged. Each series stays a plain note referenced by wikilink.

```cue
plugin: {
    id:     "digital-dogear"
    name:   "Digital Dogear"
    author: "Dylan Wright"
    repo:   "dyllonwright/Digital-Dogear"

    html_url:    "https://community.obsidian.md/plugins/digital-dogear"
    github_url:  "https://github.com/dyllonwright/Digital-Dogear"
    description: "Track books, shows, podcasts, comics, and more with one-line 'dogear' entries in your notes — ranges, auto-rolling, and sequence-break warnings. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Log where you stopped with one keystroke and append a plain text line to your daily note for any ordered media (books, shows, podcasts, comics, audiobooks, courses). Auto-suggest the next position, merge consecutive sittings into ranges, flag accidental skips, and keep each series as a simple wikilinked note."
```
