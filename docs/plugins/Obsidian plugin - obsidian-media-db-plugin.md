# Media DB

This plugin queries multiple APIs for movies, series, anime, manga, books, comics, games, music releases and wiki articles and imports them into the vault by title or by ID. Template tags shape the content of the created notes, and mappings rename or remove metadata fields. Poster images can be downloaded for offline access, and bulk imports populate many notes at once.
