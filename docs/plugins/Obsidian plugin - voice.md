# Voice

Voice reads notes aloud as text-to-speech on desktop and mobile, with a sidebar player that plays notes and saved audio as chapters and supports skip, rewind, fast-forward, repeat and speed changes. A selection, the current note or a whole folder can be read, MP3 audio can be downloaded and auto-embedded for offline listening, and audio is cached to avoid repeat synthesis costs. The speech engine is chosen among AWS Polly, ElevenLabs, Google Cloud Text-to-Speech, OpenAI and Azure Speech, with credentials kept in your own account.
