# GridSense

Opens a folder as an editable grid in which rows are notes and columns are frontmatter fields. Editing supports multi-cell selection, fill down and right, spreadsheet-style keys and find and replace within a selection. Note body content under a heading can be shown as a column, and changes are written through Obsidian's frontmatter process so they can be undone.
