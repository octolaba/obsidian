# Smart Order List

Smart Order List formats and maintains ordered, nested and parallel lists with prefix styles covering numerals, upper- and lower-case letters, Chinese numbering, bullets and checkboxes. Sequencing stays consistent and nested levels roll back across layers. Continuation and indentation are applied on Enter, Space and Tab, and a backslash silences the automatic prefix.
