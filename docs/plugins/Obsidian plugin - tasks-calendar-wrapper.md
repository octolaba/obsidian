# Tasks Calendar Wrapper

Tasks Calendar Wrapper is a wrapper around Obsidian-Tasks-Calendar and Obsidian-Tasks-Timeline that supplies their settings and update support. Vault tasks are displayed in a timeline view with customizable filters, rendering options, and date parsing aware of daily notes. A quick-entry panel adds new items.

    id:     "tasks-calendar-wrapper"
    name:   "Tasks Calendar Wrapper"
