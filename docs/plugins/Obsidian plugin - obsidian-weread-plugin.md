# Weread

Book metadata, highlights, chapter notes and reviews from Tencent Weread are synced into Markdown files in the vault, keeping covers, authors, ISBN and timestamps. Highlights and reading notes are converted through customizable templates and frontmatter, and the current day's entries can be inserted into daily notes.

```cue
plugin: {
    id:     "obsidian-weread-plugin"
    name:   "Weread"
    author: "zhaohongxuan"
    repo:   "zhaohongxuan/obsidian-weread-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-weread-plugin"
    github_url:  "https://github.com/zhaohongxuan/obsidian-weread-plugin"
```
