# S3agle

S3agle manages vault attachments with S3 providers and Eagle from inside Obsidian. Files dragged or pasted into a note are uploaded to S3, to Eagle, or to both, and preview links are created for them. Files hosted on S3 can be downloaded back into the vault and pushed on to Eagle when wanted.
