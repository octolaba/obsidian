# LinkMagic

Adds links automatically to text that matches user-defined regular expressions, applied as you type in edit mode. URL templates are configured with capture groups, so each match is turned into a clickable link built from the matched text.

```cue
plugin: {
    id:     "link-magic"
    name:   "LinkMagic"
    author: "andyreifman"
    repo:   "andyreifman/LinkMagic"

    html_url:    "https://community.obsidian.md/plugins/link-magic"
    github_url:  "https://github.com/andyreifman/LinkMagic"
    description: "Automatically adds links to defined regex."
    about:       "Define custom regex patterns to detect text and automatically insert links as you type in edit mode. Configure URL templates with capture groups to convert matches into clickable links."

    stats: {
        downloads:  1422
        updated_at: 1756999438000
    }
}
```
