# Share Note

Share Note publishes a note to the web with its full theme and custom CSS, so the shared page matches the appearance it has in Obsidian and renders images, Dataview queries, callouts, code blocks, checkboxes, tags and a table of contents. Note text is encrypted by default, controlled per note or globally, so only the recipient holds the key and the host cannot read the content. Attachments remain unencrypted, and internal links between shared notes keep working.
