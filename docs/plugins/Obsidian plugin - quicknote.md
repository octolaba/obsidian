# Quick note

Creates a quick note in a floating Obsidian window, opened by a command or by right-clicking the Obsidian application icon. Notes are captured without opening the main vault window. The recorded About states that it is macOS only for now, with Windows and Linux support planned.

    id:     "quicknote"
    name:   "Quick note"
    author: "jamesgreenblue"
    repo:   "jamesgreenblue/obsidian-quicknote"
