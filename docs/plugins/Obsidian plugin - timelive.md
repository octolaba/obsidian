# Timelive

Timelive turns a list of dates enclosed in pipe characters into a timeline without requiring a code block, accepting single dates, ranges written as start and end, and dynamic markers such as now, today or present. Events may contain links, images, videos, formatted text and code blocks, date formats are detected automatically, and the timeline renders in Reading view or in embedded live-edit mode.
