# Notes dater

Adds the creation date and the last-updated date of the active file to the status bar. Notes, images and PDFs are all covered.

```cue
plugin: {
    id:     "notes-dater"
    name:   "Notes dater"
    author: "paultreanor"
    repo:   "paultreanor/notes-dater"

    html_url:    "https://community.obsidian.md/plugins/notes-dater"
    github_url:  "https://github.com/paultreanor/notes-dater"
    description: "Add created on and last updated on dates of the active note to the status bar."
    about:       "Display file creation and last-updated dates in the status bar. Support notes, images, and PDFs."

    stats: {
        downloads:  6670
        updated_at: 1690556900000
    }
}
```
