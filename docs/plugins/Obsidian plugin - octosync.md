# Octosync

Octosync synchronises a vault with a GitHub repository through the GitHub API on desktop and mobile, without a local Git installation. Planned changes can be previewed before they are applied, syncs run manually or automatically, and detected conflicts are left for the user to decide. It targets phones, tablets and locked-down machines where a Git client is unavailable.
