# Local GPT

Brings local Ollama and OpenAI-like models to the editor for assistance the recorded inputs describe as private and available offline. Actions such as continue writing, summarize, fix grammar or extract action items run from a context menu on selected text or from an action palette. Linked notes, backlinks, images and PDFs serve as retrieval context, and community actions can be browsed and installed as custom prompts.

```cue
plugin: {
    id:     "local-gpt"
    name:   "Local GPT"
    author: "pfrankov"
    repo:   "pfrankov/obsidian-local-gpt"

    html_url:    "https://community.obsidian.md/plugins/local-gpt"
    github_url:  "https://github.com/pfrankov/obsidian-local-gpt"
    description: "Local Ollama and OpenAI-like GPT's assistance for maximum privacy and offline access."
    about:       "Open a context menu on selected text or the Action Palette to run local AI assistant actions like continue writing, summarize, fix grammar, or extract action items. Use linked notes, backlinks, images and PDFs for contextual retrieval (RAG) and browse/install community actions for custom prompts."

    }
}
```
