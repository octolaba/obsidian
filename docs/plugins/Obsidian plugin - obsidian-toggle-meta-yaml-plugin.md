# Toggle Meta Yaml

A single command hides or reveals the YAML front matter of a Markdown file. Toggling it switches the view quickly between metadata and content.

```cue
plugin: {
    id:     "obsidian-toggle-meta-yaml-plugin"
    name:   "Toggle Meta Yaml"
    author: "hua03"
    repo:   "hua03/obsidian-toggle-meta-yaml-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-toggle-meta-yaml-plugin"
```
