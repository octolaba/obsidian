# Weekly Todo Calendar

Opens a weekly note as an editable Monday to Sunday calendar in which timed tasks are dragged, resized and edited inline. The notes stay portable Markdown, and the view also draws tasks from daily notes, the Tasks plugin and ICS calendars. A week can be synced to an iCloud Apple Calendar on macOS, updating existing events rather than duplicating them.
