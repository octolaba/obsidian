# Custom Comments

Inserts customizable comment templates anywhere in a note, with a cursor placeholder deciding where the caret lands. Several marker sets can be defined, each with a toggleable command, and a word-only mode comments or uncomments the word at the cursor.

```cue
plugin: {
    id:     "custom-comment"
    name:   "Custom Comments"
    author: "jack-chronicle"
    repo:   "jack-chronicle/custom-comment"

    html_url:    "https://community.obsidian.md/plugins/custom-comment"
    github_url:  "https://github.com/jack-chronicle/custom-comment"
    description: "Create custom keyboard shortcuts that enclose comments."
    about:       "Insert customizable comment templates anywhere in notes using {cursor} to set the cursor position. Add multiple marker sets with toggleable commands and a word-only mode to comment or uncomment the word at the cursor."

}
```
