# Better Word Count

Better Word Count replaces the built-in word count with one that counts either the selected text or the entire file. It records vault-wide statistics and can display words, characters, sentences, footnotes, Pandoc citations, file and page totals and today's counts in a customizable status bar.

```cue
plugin: {
    id:     "better-word-count"
    name:   "Better Word Count"
    author: "lukeleppan"
    repo:   "lukeleppan/better-word-count"

    html_url:    "https://community.obsidian.md/plugins/better-word-count"
    github_url:  "https://github.com/lukeleppan/better-word-count"
    description: "Count the words of selected text in the editor."
    about:       "Replace the built-in word count with a counter that counts selected text or the entire file. Record vault-wide statistics and display words, characters, sentences, footnotes, Pandoc citations, file/page totals, and today's counts in a highly customizable status bar."

    stats: {
        downloads:  595551
        updated_at: 1706020459000
    }
}
```
