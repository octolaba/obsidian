# Valeon

Publishes, edits and syncs posts to the Valeon author dashboard from the vault. Notes are linted against the live server schema, tags are kebab-cased, inline images and assets are uploaded, and published or draft content including media can be pulled back. A bulk sync reconciles the vault with remote state and writes automatic conflict backups.
