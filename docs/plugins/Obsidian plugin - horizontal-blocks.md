# Horizontal Blocks

Horizontal Blocks places Markdown blocks side by side in resizable columns with a draggable divider, producing Notion-style multi-column layouts. The blocks accept full Obsidian syntax including images, embeds and internal links; column widths are remembered, images auto-scale, and inline toolbars adjust per-block appearance and colour. The recorded About advises against putting task lists inside horizontal code blocks, because code block content is plain text.
