# Multi-Vault Navigator

Searches and switches between several vaults from one Command Center with fuzzy search, snippet previews and pinned results. Notes from another vault open in a native read-only tab, with a jump to the source vault and copyable cross-vault links. References written as VaultName::NoteTitle navigate across vaults.
