# Rollover Weekly Todo

Rollover Weekly Todo moves incomplete todo items from the previous week's note into the current weekly note. The rollover is triggered from the command palette, a ribbon icon, or automatically when a new weekly note is created, and items are inserted under a chosen template heading or at the end of the note. Originals can optionally be deleted and restored through undo.
