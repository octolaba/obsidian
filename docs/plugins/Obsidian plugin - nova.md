# Nova

Edits text in place with model-driven transformations: a selection can be refined, content inserted at the cursor, sections filled from inline placeholders, or a claim challenged with counter-arguments. A dashboard analyzes writing across the vault, scoring clarity, conciseness, variety and discipline, and English readability and style checks are included. The recorded description states that local models or the user's own API keys can be used, that no conversations are stored, and that there is no telemetry.
