# Textfresser

Textfresser builds a personal German dictionary from the words in open notes, creating a structured entry per word and linking every inflected or related form to its base lemma. Each generated file carries pronunciation, conjugation or declension tables, translations and semantic links, and backlinks are maintained bidirectionally so the vocabulary forms a navigable network.
