# Lecture Lens

Lecture Lens converts lecture PDFs, slides and whiteboard photos into structured Markdown notes using vision-capable language models that extract text, LaTeX and diagrams. Course folders are indexed for RAG-based chat, so questions are answered against the course material. Images are analysed singly or in batch.
