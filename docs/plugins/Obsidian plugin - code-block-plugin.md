# Code Block

Converts selected or pasted text into a fenced code block and detects the programming language automatically. The languages considered for detection are configurable, detection is done with highlight.js, and the recorded inputs note that it can occasionally guess wrong.

```cue

    id:     "code-block-plugin"
    name:   "Code Block"
    author: "paddan"
    repo:   "paddan/code-block-plugin"
```
