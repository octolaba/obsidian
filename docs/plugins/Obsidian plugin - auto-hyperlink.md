# Auto Hyperlink

Auto Hyperlink inserts hyperlinks in reading view from JSON rules that match words or regex patterns and map them onto URL templates, with placeholders for the dynamic part of an address. An experimental editor mode writes the links into the file itself, which its recorded About warns may produce unexpected results.

```cue
plugin: {
    id:     "auto-hyperlink"
    name:   "Auto Hyperlink"
    author: "take6"
    repo:   "take6/obsidian-plugin-auto-hyperlink"

    html_url:    "https://community.obsidian.md/plugins/auto-hyperlink"
    github_url:  "https://github.com/take6/obsidian-plugin-auto-hyperlink"
    description: "Insert hyperlink according to user-defined rule."
    about:       "Insert hyperlinks in reading view using JSON rules that match words or regex patterns and map them to URL templates. Use $ placeholders for dynamic URLs and optionally enable experimental editor mode to write links directly into files (editor edits may produce unexpected results)."

    stats: {
        downloads:  4904
        updated_at: 1712994383000
    }
}
```
