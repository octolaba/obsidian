# Vault Loom

Provides streaming chat with note-aware retrieval and editing commands driven by vault content. The current selection or the active note can serve as context, Markdown chunks are indexed and searched for semantic retrieval, and attached context is previewable. An agent shows its tool activity and asks for confirmation before writing anything.
