# Spreadsheet Table

Markdown tables are edited like a spreadsheet, with editing commands, formula calculation and CSV export. Calculated results are displayed in Live Preview and Reading mode while the formulas remain in the Markdown source as plain text. A right-sidebar toolbar with a mobile-friendly layout inserts, moves, deletes, aligns, sorts and formats rows and columns.
