# Quiz Generator

Generates exam-style questions from selected notes and folders using models from OpenAI, Google, Ollama and other providers, or lets questions be written by hand. Question types cover true or false, multiple choice, select-all, fill-in-the-blank, matching and short or long answer. Answers are given in a quiz interface with real-time feedback, saved as flashcards or markdown, and generated in 22 languages with LaTeX support.
