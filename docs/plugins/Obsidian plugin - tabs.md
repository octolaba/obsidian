# Markdown Tabs

Creates tabbed content blocks in notes from a tabs code block. Tabs can be nested and can contain code blocks. The tab bar is placed at the top, left, right or bottom, and multiple tabs can optionally be selected at once.

```cue
plugin: {
    id:     "tabs"
    name:   "Markdown Tabs"
    author: "xhuajin"
    repo:   "xhuajin/obsidian-tabs"

    html_url:    "https://community.obsidian.md/plugins/tabs"
    github_url:  "https://github.com/xhuajin/obsidian-tabs"
    description: "Create tabs in your notes."
    about:       "Create tabbed content blocks inside notes with a simple tabs code block. Use nested tabs, include code blocks within tabs, and place the tab bar top/left/right/bottom with optional multi-tab selection for flexible layouts."

    stats: {
        downloads:  34010
        updated_at: 1784277354000
    }
}
```
