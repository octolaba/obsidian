# Explorer Colors

Assigns custom colours to files and folders in the explorer. A folder's colour cascades through its tree while the individual settings of the items inside it are preserved, and a default picker colour applies to newly created files and folders.

```cue
plugin: {
    id:     "explorer-colors"
    name:   "Explorer Colors"
    author: "vaguelyelectric"
    repo:   "vaguelyelectric/obsidian-explorer-colors"

    html_url:    "https://community.obsidian.md/plugins/explorer-colors"
    github_url:  "https://github.com/vaguelyelectric/obsidian-explorer-colors"
    description: "Allows for files and folders to be configured with custom colors and other settings."
    about:       "Set custom colors for files and folders in the Explorer to visually organize notes and directories. Toggle cascading colors per folder tree while preserving child items' own color settings. Set a default picker color to apply to new files and folders."

    stats: {
        downloads:  4643
        updated_at: 1765487941000
    }
}
```
