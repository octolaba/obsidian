# MarkPage Sync

MarkPage Sync sends a note, including its embedded images and links, to the MarkPage editor in one step and opens it in the browser for visual editing. A lightweight local server pushes the Markdown and serves vault images to any MarkPage deployment. Built-in themes can be applied, and a first-level heading is extracted automatically as the cover title.
