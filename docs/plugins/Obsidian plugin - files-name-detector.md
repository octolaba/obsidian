# Files Name Detector

Files Name Detector renames files by replacing spaces with dashes, turning my note.md into my-note.md. The vault is scanned when the plugin loads so existing files are renamed, and newly created files are renamed automatically. A notice is shown for each rename.

```cue
plugin: {
    id:     "files-name-detector"
    name:   "Files Name Detector"
    author: "harrishussain24"
    repo:   "harrishussain24/files-name-detector"

    html_url:    "https://community.obsidian.md/plugins/files-name-detector"
    github_url:  "https://github.com/harrishussain24/files-name-detector"
    description: "Automatically renames files by replacing spaces with dashes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Rename files by replacing spaces with dashes (e.g., my note.md → my-note.md). Scan the vault on plugin load to rename existing files, automatically rename newly created files, and show a notice for each rename."

    stats: {
        downloads:  102
        updated_at: 1775850478000
    }
}
```
