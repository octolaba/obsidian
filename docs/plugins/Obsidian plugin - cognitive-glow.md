# Cognitive Glow

Cognitive Glow ranks notes in a sidebar by recency and visit frequency, so the vault is navigated by visual glow rather than by hunting filenames. Luminous bars brighten active notes and fade old ones, a Normal or Focus mode shows either the full list or the top entries, and tracking can be limited by folder or by a minimum open time.
