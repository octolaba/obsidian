# Auto Close Oldest Tabs

Closes the least recently used tabs automatically once the number of open tabs passes a configured limit. Until that limit is reached, internal links and files are forced to open in a new tab, so the active note is not replaced.

```cue
plugin: {
    id:     "auto-close-oldest-tabs"
    name:   "Auto Close Oldest Tabs"
    author: "usero2-endofday"
    repo:   "usero2/obsidian-plugins-auto-close-tabs"

    html_url:    "https://community.obsidian.md/plugins/auto-close-oldest-tabs"
    github_url:  "https://github.com/usero2/obsidian-plugins-auto-close-tabs"
    description: "Automatically close the oldest tab when a maximum tab limit is reached. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Close the least-recently-used tabs automatically when open tabs exceed a configurable limit to keep your workspace tidy. Force internal links and files to open in new tabs until the limit is reached to avoid replacing your active note."

    stats: {
        downloads:  119
        updated_at: 1781606527000
    }
}
```
