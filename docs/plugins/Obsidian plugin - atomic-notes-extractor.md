# Bamboo Darts

Distills long articles, web pages or selected text into short atomic notes using the DeepSeek model. Low-quality or duplicate content is filtered out, facts can be flagged for evidence, and similar notes within one batch are merged. Cleaned single-idea notes are previewed or saved directly into the vault.
