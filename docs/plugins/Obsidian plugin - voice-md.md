# Voice MD

Voice MD records audio and transcribes it inline with OpenAI's GPT-4o audio models, detecting the language automatically and running on mobile. A meeting mode identifies speakers in multi-speaker recordings. Both a raw and a GPT-formatted markdown transcription can be produced, saved and cross-linked in the vault.

```cue
plugin: {
    id:     "voice-md"
    name:   "Voice MD"
    author: "denizokcu"
    repo:   "denizokcu/voice-md"

    html_url:    "https://community.obsidian.md/plugins/voice-md"
    github_url:  "https://github.com/denizokcu/voice-md"
    description: "Record audio and transcribe it to markdown using OpenAI Audio Transcription API. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Record audio and transcribe it inline using OpenAI's GPT‑4o audio models, with auto‑language detection and mobile support. Enable meeting mode for automatic speaker identification in multi‑speaker recordings, or generate both raw and GPT‑formatted markdown transcriptions saved and cross‑linked in your vault."

    stats: {
        downloads:  500
        updated_at: 1779460600000
    }
}
```
