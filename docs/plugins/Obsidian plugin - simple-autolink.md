# Simple Auto-Link

Simple Auto-Link converts plain-text mentions of note titles and aliases into wiki links as you edit, matching case-insensitively, respecting word boundaries and optionally mapping base words to plurals. Code blocks, inline code, frontmatter and math are skipped, and headings and tables can be skipped as well. A masterlist maps several aliases at once and backfills frontmatter, include and exclude folders limit scanning, and it runs on desktop and mobile.

```cue
plugin: {
    id:     "simple-autolink"
    name:   "Simple Auto-Link"
    author: "abgmgp"
    repo:   "abgmgp/obsidian-simple-autolink"

    html_url:    "https://community.obsidian.md/plugins/simple-autolink"
    github_url:  "https://github.com/abgmgp/obsidian-simple-autolink"
    description: "Convert plain-text mentions of note titles and aliases into wiki links. Highly configurable. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert matching words into wiki links as you edit, using smart, case-insensitive matching that respects word boundaries and optional base-word (plural) mapping. Skip code blocks, inline code, frontmatter and math, and optionally skip headings and tables. Map multiple aliases with a masterlist that backfills frontmatter, restrict scanning with include/exclude folders, and run on desktop and mobile."
```
