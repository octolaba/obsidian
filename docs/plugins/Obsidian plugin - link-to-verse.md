# Link to Verse

Turns a selected Bible reference, written in a natural form such as a book name with chapter and verse, into a Markdown link to a configured Bible site. Links are generated from built-in presets or from custom URL templates and a preferred Bible version, replacing the selected reference with a link that opens the passage.

```cue
plugin: {
    id:     "link-to-verse"
    name:   "Link to Verse"
    author: "aygjiay"
    repo:   "aygjiay/obsidian-link-to-verse"

    html_url:    "https://community.obsidian.md/plugins/link-to-verse"
    github_url:  "https://github.com/aygjiay/obsidian-link-to-verse"
    description: "From a bible reference selected creates a markdown link to a configured bible site."
    about:       "Create clickable links to Bible passages from natural references like John 3:16 directly in your notes. Generate links with built-in presets or custom URL templates and preferred Bible versions, replacing selected references with ready-to-open passage links."

    stats: {
        downloads:  1306
        updated_at: 1774707580000
    }
}
```
