# Image Hover Preview

Shows a floating preview of an image when the cursor hovers over it, opening the original at full size. The preview zooms with the mouse wheel, and holding Ctrl temporarily disables the hover behaviour.

```cue
plugin: {
    id:     "image-hover-preview"
    name:   "Image Hover Preview"
    author: "shin2w"
    repo:   "shin2w/obsidian-hover-preview"

    html_url:    "https://community.obsidian.md/plugins/image-hover-preview"
    github_url:  "https://github.com/shin2w/obsidian-hover-preview"
    description: "Hover your cursor over images to display a floating preview with zoom support. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Preview original images by hovering over any image to open a floating full-size preview. Zoom the preview with the mouse wheel and hold Ctrl to temporarily disable the hover preview."

    stats: {
        downloads:  119
        updated_at: 1782790271000
    }
}
```
