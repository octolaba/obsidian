# Better Task

Better Task organizes work into goals and tasks, covering daily routines and one-off quick tasks. A dashboard shows today's tasks, goals, units and upcoming exams with optional reminders, and progress is tracked through analytics, streaks and a 30-day heatmap. A Student Mode adds courses and exams and generates study tasks from them.
