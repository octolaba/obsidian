# Beautiful Mermaid Renderer

Beautiful Mermaid Renderer replaces Mermaid output with SVG produced by beautiful-mermaid and styled from Obsidian's theme variables. Diagrams render in both Reading view and Live Preview, inline diagrams fit the editor width by default, and the aliases mermaid-beautiful and bmmd are accepted as block languages.

```cue
plugin: {
    id:     "beautiful-mermaid-renderer"
    name:   "Beautiful Mermaid Renderer"
    author: "qiaoborui"
    repo:   "qiaoborui/obsidian-beautiful-mermaid"

    html_url:    "https://community.obsidian.md/plugins/beautiful-mermaid-renderer"
    github_url:  "https://github.com/qiaoborui/obsidian-beautiful-mermaid"
    description: "Render Mermaid diagrams with beautiful-mermaid SVG output and theme variables. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render Mermaid diagrams as beautiful SVGs using beautiful-mermaid styles and Obsidian theme variables. View diagrams in Reading and Live Preview with inline diagrams fitting the editor width by default. Support aliases like mermaid-beautiful and bmmd."

    stats: {
        downloads:  1519
        updated_at: 1778835507000
    }
}
```
