# Root Folder Order

Root Folder Order keeps root-level folders in a custom, stable sequence while leaving notes and nested folders to the normal Obsidian sorting. The order is set by drag-and-drop, position numbers, or up and down controls, and missing or future root folders can be added by name. Renames and removals can optionally be tracked automatically.

    id:     "root-folder-order"
