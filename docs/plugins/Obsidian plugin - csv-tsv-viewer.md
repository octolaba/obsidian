# CSV TSV Viewer

Opens .csv and .tsv files as a read-only table with automatic delimiter detection, sticky headers, row numbers and file statistics. A source view shows line numbers and highlights the delimiter, and parsing handles quoted, escaped and multiline fields while reporting warnings. Rows can be filtered by cell content, and the first 10,000 rows are rendered locally.
