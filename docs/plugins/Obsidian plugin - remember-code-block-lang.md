# Remember Code Block Language

Remembers the language of the last code block used and inserts it automatically the next time a code fence is started. A command inserts a code block with the remembered language, and a default language can be set.

```cue
plugin: {
    id:     "remember-code-block-lang"
    name:   "Remember Code Block Language"
    author: "Junyoung Bang"
    repo:   "zzunebye/remember-last-code-block-lang"

    html_url:    "https://community.obsidian.md/plugins/remember-code-block-lang"
    github_url:  "https://github.com/zzunebye/remember-last-code-block-lang"
    description: "Remember the language of the last code block you used and automatically insert it next time. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Remember the last code block language and automatically insert it when you start a code fence, so new code blocks default to your most recent language. Provide a command to insert a code block with the remembered language and allow setting a default language."

    stats: {
        downloads:  78
        updated_at: 1768534394000
    }
}
```
