# Task Companion

Task Companion drives task execution with 25- and 50-minute or free-length timers, pause and resume, focus sessions, and a single level of subtask breakdown, while Markdown Tasks remain the source of truth. Completion retrospectives and reusable experience templates are supported, and dashboard components for current, today, important, daily, pending and review work can be embedded. The recorded text states that all data stays local and offline with no telemetry.
