# YAML Properties

Shows note frontmatter in Live Preview as an editable, syntax-highlighted YAML block that collapses into a compact summary when not needed. Reading view renders the same block read-only, Source mode receives bundled styling, and notes stay plain Markdown with no metadata added.

```cue
plugin: {
    id:     "yaml-properties"
    name:   "YAML Properties"
    author: "Robert Fleming"
    repo:   "haivri/obsidian-yaml-properties"

    html_url:    "https://community.obsidian.md/plugins/yaml-properties"
    github_url:  "https://github.com/haivri/obsidian-yaml-properties"
    description: "Edit properties as readable, syntax-highlighted YAML frontmatter and collapse them when not needed. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Edit YAML frontmatter directly in Live Preview with full syntax highlighting and an editable block that collapses into a compact summary. Display a highlighted read-only block in Reading view, apply bundled Source-mode styling, and keep notes as plain Markdown without adding metadata."

    stats: {
        downloads:  63
        updated_at: 1784168817000
    }
}
```
