# Vault Tasks

Collects Markdown tasks from every note into one grouped view while each task stays in its original note as the source of truth. Tasks are grouped by note or section and filtered by status, notes can be pinned, and frontmatter can defer or hide a note. The same grouped view is exposed to scripts and AI agents through a companion command-line tool.
