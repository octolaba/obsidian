# PO Editor

Edits PO (Gettext) translation files in a dual-mode grid and raw text editor with live syntax highlighting and full plural-form support. Entries are validated, with conflicts and fuzzy or obsolete items flagged, and filtered by status or context. Related PO files are managed together, and content is converted or exported to XLIFF, ARB, JSON, YAML, or ICU.
