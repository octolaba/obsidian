# Redirect

This plugin manages aliases and redirects for any file, including non-Markdown attachments, through redirect or alias entries in a note's YAML front matter. Redirected paths can be inserted, and a suggestion panel triggered while editing searches and links files. Targets, or the origin that redirects to them, can be opened from commands or from the file context menu.

```cue
plugin: {
    id:     "obsidian-redirect"
    name:   "Redirect"
    author: "jglev"
    repo:   "jglev/obsidian-redirect"

    html_url:    "https://community.obsidian.md/plugins/obsidian-redirect"
    github_url:  "https://github.com/jglev/obsidian-redirect"
    description: "Facilitate management of especially non-Markdown files, by allowing aliases to be set on any file."
    about:       "Manage redirects and aliases for any file, including binary attachments, by adding redirect/redirects or alias/aliases entries in a note's YAML front matter. Insert redirected paths, search and link files with a suggestion panel (type r[ while editing), and open targets or their redirect origin from commands or the file context menu."

    stats: {
        downloads:  2117
        updated_at: 1662294302000
    }
}
```
