# Image Hoist

Uploads local vault images to ImgBB and replaces them with remote links, which the recorded description presents as a way to optimize storage. Pasted images can be uploaded automatically, existing uploads are reused so the same file is not sent twice, and a single action hoists every image in a note.

```cue
plugin: {
    id:     "image-hoist"
    name:   "Image Hoist"
    author: "jcmexdev"
    repo:   "jcmexdev/obsidian-image-hoist"

    html_url:    "https://community.obsidian.md/plugins/image-hoist"
    github_url:  "https://github.com/jcmexdev/obsidian-image-hoist"
    description: "Automatically uploads local vault images to ImgBB and replaces them with remote links to optimize storage. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Move local images to ImgBB and replace them with shareable cloud links so notes stay lightweight and images display anywhere. Auto-upload pasted images, reuse existing uploads to avoid duplicates, and hoist all images in a note with a single action."

    stats: {
        downloads:  136
        updated_at: 1779008603000
    }
}
```
