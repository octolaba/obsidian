# Smart Note Agent

Smart Note Agent is a chat-driven agent that reads vault notes and modifies them only with approval, presenting every edit as a diff before it is committed. It runs in Ask, Edit or Scheduled modes, covering research, editing and automated daily summaries or weekly reviews. The agent draws on search, backlinks, folders and the active selection.
