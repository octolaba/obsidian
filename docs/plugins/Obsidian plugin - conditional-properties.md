# Conditional Properties

Conditional Properties automates frontmatter through IF and THEN rules that set, modify or remove properties and update titles. Conditions match on frontmatter or on the title, rules run vault-wide or over a scoped set of notes, scans can be scheduled, and the note body is left untouched while processing happens locally.

    name:   "Conditional Properties"
