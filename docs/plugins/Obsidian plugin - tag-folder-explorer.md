# Tag Folder Explorer

Browses the vault as virtual folders built from Obsidian's nested tags, so a single file can appear in several locations within one vault. A sortable nested tag tree is shown in the sidebar, and untagged notes are gathered under a dedicated Untagged Files folder. The recorded About text also names documenting folder context with associated metadata files.
