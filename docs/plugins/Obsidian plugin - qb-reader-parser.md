# QB Reader Parser

Parses tossups fetched from the QB Reader API into cloze cards in the format the Obsidian_to_Anki plugin reads. A query dialog fetches the tossups, sentences are highlighted to split clues, and clicking a line converts it into Anki-ready cloze format.
