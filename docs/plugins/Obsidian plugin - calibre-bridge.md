# Calibre Bridge

Calibre Bridge connects a Calibre Content Server library and imports selected books as individual notes with cover images, Markdown descriptions and frontmatter covering title, authors, series, rating, tags, ISBN and date added. Repeating an import refreshes the Calibre data without overwriting custom note content or reading status, since an editable area below each description is preserved.

```cue
plugin: {
    id:     "calibre-bridge"
    name:   "Calibre Bridge"
    author: "p24l"
    repo:   "p24l/calibre-bridge"

    html_url:    "https://community.obsidian.md/plugins/calibre-bridge"
    github_url:  "https://github.com/p24l/calibre-bridge"
    description: "Import books from a Calibre (Content Server) as Markdown notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Connect your Calibre library to Obsidian and import selected books as individual notes with cover images, Markdown descriptions, and comprehensive frontmatter (title, authors, series, rating, tags, ISBN, date added). Refresh imports to update Calibre data without overwriting your custom note content or reading status, preserving an editable area below each description."
```
