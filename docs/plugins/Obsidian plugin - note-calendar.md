# Note Calendar

Note Calendar displays a calendar carrying Gregorian and lunar dates, holidays, workday adjustments and solar terms, in month and year views. Notes linked to a date are managed from it with new and update indicators and automatic refresh, and daily, weekly, quarterly or yearly date-based notes can be created straight from a calendar entry.
