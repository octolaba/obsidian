# Arbor Family Tree

Builds a family tree from person notes in the vault and renders it as a navigable SVG diagram that can be rooted on any person. Trees export to interactive HTML or GEDCOM, people import from CSV, and the layout switches between horizontal and vertical with sibling filters. Theme-aware colors and session state are preserved.
