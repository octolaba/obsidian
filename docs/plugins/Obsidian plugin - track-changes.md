# Track Changes

Track Changes reviews CriticMarkup suggestions in a side panel where each one can be accepted, rejected or replied to. All five CriticMarkup forms are handled, with threaded comments, multi-author color coding and deletion per item or per thread. A finalize action resolves the remaining markup, accepted or raw text can be previewed, and markup inside code blocks is left untouched.
