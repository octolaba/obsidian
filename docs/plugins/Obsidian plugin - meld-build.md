# Meld Build

Runs sandboxed JavaScript written inside a note to render templates, query DataView and generate dynamic documents. Code is executed from Reading view or Live Preview through a Run toolbar or a command. The recorded text points to an API and examples covering games, invoices and interactive prompts.
