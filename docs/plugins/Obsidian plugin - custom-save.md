# Custom save

Creates a custom save command to which several callbacks can be attached. Binding that command to the save hotkey runs the added actions alongside the normal save.

```cue
plugin: {
    id:     "custom-save"
    name:   "Custom save"
    author: "hananoshikayomaru"
    repo:   "hananoshikayomaru/obsidian-custom-save"

    html_url:    "https://community.obsidian.md/plugins/custom-save"
    github_url:  "https://github.com/hananoshikayomaru/obsidian-custom-save"
    description: "Add custom save actions."
    about:       "Create a custom save command and attach multiple callbacks to run when saving. Bind the command to your save hotkey to execute added actions alongside the normal save."

    stats: {
        downloads:  3089
        updated_at: 1703137404000
    }
}
```
