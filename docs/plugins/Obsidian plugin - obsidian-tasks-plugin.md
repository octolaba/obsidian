# Tasks

Tasks tracks checklist items across the vault and queries them from search blocks placed in any note. Queries filter by due date, done date, recurrence and partial checklist items, and completing a task from a query view updates the original Markdown file. A create-and-edit command adds or modifies a task without writing the syntax by hand.

```cue
plugin: {
    id:     "obsidian-tasks-plugin"
    name:   "Tasks"
    author: "obsidian-tasks-group"
    repo:   "obsidian-tasks-group/obsidian-tasks"

    html_url:    "https://community.obsidian.md/plugins/obsidian-tasks-plugin"
    github_url:  "https://github.com/obsidian-tasks-group/obsidian-tasks"
    description: "Track tasks across your vault. Supports due dates, recurring tasks, done dates, sub-set of checklist items, and filtering. Maintained by Clare Macrae and Ilyas Landikov, created by Martin Schenck."
    about:       "Track tasks across your vault and query them with flexible search blocks to gather filtered lists anywhere. Mark tasks done from any view and update the original Markdown file; support due dates, recurring tasks, done dates, and partial checklist items. Use the create/edit command to add or modify tasks."
```
