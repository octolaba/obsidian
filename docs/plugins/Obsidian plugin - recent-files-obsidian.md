# Recent Files

Displays a sidebar list of the most recently opened files. Items can be excluded by path, by frontmatter tags, or by bookmarks. Files open on click, can be dragged into editors or folders to create links or move them, and show content previews on hover.

```cue
plugin: {
    id:     "recent-files-obsidian"
    name:   "Recent Files"
    author: "tgrosinger"
    repo:   "tgrosinger/recent-files-obsidian"

    html_url:    "https://community.obsidian.md/plugins/recent-files-obsidian"
    github_url:  "https://github.com/tgrosinger/recent-files-obsidian"
    description: "Display a list of recently opened files."
    about:       "Display a sidebar list of most recently opened files and exclude items by path, frontmatter tags, or bookmarks. Open files by clicking, drag to editors or folders to create links or move files, and hover to view content previews."
```
