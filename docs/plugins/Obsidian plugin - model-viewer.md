# Model Viewer

Model Viewer displays and embeds interactive glTF and GLB 3D models in the vault using Google's model-viewer component. Model files can be browsed and previewed, and placed in notes with the native embed syntax. Common glTF extensions such as Draco and KTX2 are supported for compressed assets and PBR materials.
