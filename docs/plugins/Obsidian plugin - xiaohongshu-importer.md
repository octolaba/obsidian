# Xiaohongshu Importer

Imports Xiaohongshu notes from a pasted share link or text, normalizing explore URLs and extracting title, content, images, videos and tags into Markdown. Imported notes are filed into user-defined categories and folder hierarchies, with media either downloaded locally or embedded from the original URLs.

```cue
plugin: {
    id:     "xiaohongshu-importer"
    name:   "Xiaohongshu Importer"
    author: "bnchiang96"
    repo:   "bnchiang96/xiaohongshu-importer"

    html_url:    "https://community.obsidian.md/plugins/xiaohongshu-importer"
    github_url:  "https://github.com/bnchiang96/xiaohongshu-importer"
    description: "Import Xiaohongshu (RedNote) notes with media and categorization."
    about:       "Import Xiaohongshu notes by pasting share links or text, normalize explore URLs, and extract titles, content, images, videos, and tags into Markdown. Organize notes into user-defined categories and folder hierarchies, and choose to download media locally or embed original URLs."

    stats: {
        downloads:  8272
        updated_at: 1768373738000
    }
}
```
