# Bases Tag Colors

Bases Tag Colors assigns tag colors per base rather than globally, storing each palette in a colors file beside its own .base file so colors never bleed between bases. Palettes are edited through a visual picker, hex input and search, changes appear live, and the active base is detected automatically.

```cue
plugin: {
    id:     "bases-tag-colors"
    name:   "Bases Tag Colors"
    author: "Oleg Brovchenko"
    repo:   "olegbrovchenko/bases-tag-colors"

    html_url:    "https://community.obsidian.md/plugins/bases-tag-colors"
    github_url:  "https://github.com/olegbrovchenko/bases-tag-colors"
    description: "Color your Bases tags per-base. Each .base file owns its palette — no global tag soup. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Color tags per base by storing palettes beside each .base file in a .colors.json so colors stay local and never bleed between bases. Edit palettes with a visual picker, hex input and search, see live updates, and auto-detect the active base for instant changes."

}
```
