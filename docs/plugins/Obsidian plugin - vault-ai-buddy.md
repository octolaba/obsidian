# Vault AI Buddy

Puts an AI assistant in a sidebar that searches the vault for context and answers questions from its content. The assistant can edit the active note, manage files and folders, save remembered items and run several chat tabs at once. It can also connect to MCP servers, GitHub among them, for repository and issue queries.
