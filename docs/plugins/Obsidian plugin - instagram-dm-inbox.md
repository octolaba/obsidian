# Instagram DM Inbox

Instagram DM Inbox mirrors Instagram Business direct messages into the vault as individual notes, creates a profile note per sender, and renders conversations as a color-coded Canvas thread graph for triage. Threads sit in status folders that update automatically, and a status is changed either by an Instagram trigger code or by editing the note. Timestamps, message IDs and wikilinks are kept so messages stay linkable and searchable.
