# Focus Active Sentence

Highlights the sentence the cursor is currently resting on and dims the rest of the document. The focus is removed while scrolling and returns when the cursor moves or typing starts.

```cue
plugin: {
    id:     "focus-active-sentence"
    name:   "Focus Active Sentence"
    author: "artisticat"
    repo:   "artisticat1/focus-active-sentence"

    html_url:    "https://community.obsidian.md/plugins/focus-active-sentence"
    github_url:  "https://github.com/artisticat1/focus-active-sentence"
    description: "Highlight the sentence the cursor is currently resting on."
    about:       "Highlight only the active sentence and dim the rest of the document to reduce visual clutter. Remove focus while scrolling and restore it when you move the cursor or start typing."

    stats: {
        downloads:  7505

}
```
