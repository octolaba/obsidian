# Account Linker

Account Linker describes external service accounts in a note's front matter and generates link buttons from them. Configurable URI templates with name substitution build each address, and the buttons carry service colours and favicons. Custom URI schemes such as mailto: and obsidian:// are supported.

```cue
plugin: {
    id:     "obsidian-account-linker"
    name:   "Account Linker"
    author: "qwegat"
    repo:   "qwegat/Obsidian-Account-Linker"

    html_url:    "https://community.obsidian.md/plugins/obsidian-account-linker"
    github_url:  "https://github.com/qwegat/Obsidian-Account-Linker"
    description: "Describe external service accounts in the frontmatter."
    about:       "Generate link buttons for external accounts from a note's front matter using configurable URI templates and name substitution (e.g., {{NAME}}). Display service colors and favicons and support custom URI schemes like mailto: and obsidian:// for quick access."

    stats: {
        downloads:  4624

    }
}
```
