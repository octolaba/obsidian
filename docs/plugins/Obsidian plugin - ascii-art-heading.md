# ASCII Art Heading

Renders headings as ASCII art from FIGlet fonts, declared in an ascii-art code block. Font, alignment, color and size are selectable, and wide art can be expanded or scrolled horizontally while the font name is displayed.

```cue
plugin: {
    id:     "ascii-art-heading"
    name:   "ASCII Art Heading"
    author: "nbdev99"
    repo:   "nbdev99/ascii-art-heading"

    html_url:    "https://community.obsidian.md/plugins/ascii-art-heading"
    github_url:  "https://github.com/nbdev99/ascii-art-heading"
    description: "Render ASCII art headings from code blocks using FIGlet fonts. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Transform headings into ASCII art using FIGlet fonts. Create an ascii-art code block to render text with selectable fonts, alignment, color and size, and optionally expand or horizontally scroll wide art while showing the font name."

    stats: {
        downloads:  187
        updated_at: 1775554913000
    }
}
```
