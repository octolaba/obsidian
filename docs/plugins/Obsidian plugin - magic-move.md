# Magic Move

Animates the transition between successive code blocks so that changes, refactors or alternative implementations can be shown step by step. Syntax-highlighted fenced code blocks are animated in both reading and editing mode, and the duration, the stagger, line-number animation and the theme are all configurable for timed, staged effects.
