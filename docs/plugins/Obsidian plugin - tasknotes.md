# TaskNotes

TaskNotes stores each task as its own Markdown note with YAML frontmatter and presents them through Bases-powered list, Kanban, calendar and agenda views defined in base files. Dates and tags are parsed from natural language, frontmatter can be extended with custom fields, and calendar, pomodoro and time-tracking integration are part of the plugin. The data stays portable editable plain text with no plugin-specific database.
