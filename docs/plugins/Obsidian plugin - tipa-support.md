# TIPA Support

TIPA Support converts TIPA and TeX phonetic notation into Unicode IPA symbols, handling the textipa, tipa, nt and wt commands. Inline dollar-delimited transcriptions and code blocks are rendered, with code blocks handled automatically in both edit and reading modes. Some constructs such as textschwa have no live inline preview.

    id:     "tipa-support"
    name:   "TIPA Support"
