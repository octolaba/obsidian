# Modal Opener

Modal Opener opens files and links in a modal window so that they can be read or edited without creating duplicate tabs. From the modal it can jump to a Markdown title or a block-link anchor, switch editing modes, and restore the content to a tab. Custom commands and right-click actions insert the edited link at the cursor.
