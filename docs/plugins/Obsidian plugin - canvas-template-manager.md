# Canvas Template Manager

Canvas Template Manager duplicates canvas templates visually so they can be reused across the vault. A rule can add tags automatically, taking a card's level-one title as the tag name.

    id:     "canvas-template-manager"
    name:   "Canvas Template Manager"
    author: "Phillip Wood"
    repo:   "phillip383/obsidian-canvas-template-manager"
