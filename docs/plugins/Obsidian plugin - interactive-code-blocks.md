# Interactive Code Blocks

Interactive Code Blocks previews interactive code blocks in reader mode, so markdown examples can be viewed and tested while drafting. It indicates which blocks are runnable and editable and which are static. The recorded limits are that the preview offers no in-preview editing, no sandbox mode and no syntax highlighting.
