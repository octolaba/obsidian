# textFlow

textFlow compiles several notes into a flow, a dynamic document defined by folders, tags, properties, bookmark groups or Dataview queries. A flow is edited like a normal note and edits sync in both directions with the source files. Embed-based flows avoid duplicating data, and navigation works by keyboard or mouse.
