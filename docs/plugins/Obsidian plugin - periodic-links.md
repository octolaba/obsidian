# Periodic Links

Periodic Links resolves links between periodic notes from natural-language phrases such as tomorrow, next week, in two weeks or last Tuesday. Written numbers and weekday-specific phrases are recognised, and the plugin follows the configured daily, weekly, monthly, quarterly and yearly formats. Linked notes can be created on demand with the right template and folder.

```cue
plugin: {
    id:     "periodic-links"
    name:   "Periodic Links"
    author: "David V. Kimball"
    repo:   "davidvkimball/obsidian-periodic-links"

    html_url:    "https://community.obsidian.md/plugins/periodic-links"
    github_url:  "https://github.com/davidvkimball/obsidian-periodic-links"
    description: "Automatically link between periodic notes with natural language. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Link periodic notes using natural-language phrases like \"tomorrow\", \"next week\", \"in two weeks\", or \"last Tuesday\". Create linked notes with templates and proper folders on demand, support written numbers and weekday-specific phrases, and adapt to your configured daily/weekly/monthly/quarterly/yearly formats."

    stats: {
        downloads:  834
        updated_at: 1780170505000
    }
}
```
