# Awesome Flashcard

This plugin syncs flashcards written in standard Markdown from the vault to Anki in one direction, leaving existing Anki learning progress intact. Images, audio, video, code blocks, LaTeX and tables are supported, with deck and tag assignment per file or per card. Scanning is incremental for speed, and each card can carry a link back to its source note.

plugin: {
    id:     "obsidian-awesome-flashcard"
    name:   "Awesome Flashcard"
    author: "awesomedog"
    repo:   "awesomedog/obsidian-awesome-flashcard"

    html_url:    "https://community.obsidian.md/plugins/obsidian-awesome-flashcard"

Support images, audio, video, code blocks, LaTeX and tables, plus deck and tag assignment per file or per card. Scan incrementally for speed and add quick links back to the source note."
