# Canvas Text Scaler

Canvas Text Scaler scales the text inside a Canvas card to the card's own size as it is resized, rather than only with canvas zoom. An optional safety net can be enabled to avoid conflicts with theme font-size rules.

```cue
plugin: {
    id:     "canvas-text-scaler"
    name:   "Canvas Text Scaler"
    author: "valleytheknight"
    repo:   "valleytheknight/Canvas-Text-Scaler"

    html_url:    "https://community.obsidian.md/plugins/canvas-text-scaler"
    github_url:  "https://github.com/valleytheknight/Canvas-Text-Scaler"
    description: "Scales text inside Canvas cards to the card's own size as you resize it, instead of only scaling with zoom. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Scale text inside Canvas cards to match each card's size as you resize them rather than only with canvas zoom. Enable an optional safety net to avoid conflicts with theme font-size rules."

    stats: {
        downloads:  45
        updated_at: 1784692106000
    }
}
```
