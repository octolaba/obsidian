# Weave Incremental Reading

Creates reading points from documents, selections or external sources and groups them into topic decks for incremental reading. Reading points are scheduled and shown on a calendar, with daily limits and time budgets bounding a session. Progress is tracked, and each point links back to its original source so reading can continue where it stopped.
