# Sync Meter

Shows Obsidian Sync progress as a percentage with a small progress bar in the status bar. The recorded About text names three states: syncing, with an accent-colored icon and an animated bar; synced, with a dimmed full-progress icon; and sync unavailable, greyed out. Status is stated to be polled every two seconds on desktop and mobile.

```cue
plugin: {
    id:     "sync-meter"
    name:   "Sync Meter"
    author: "wolfuardian"
    repo:   "wolfuardian/obsidian-sync-meter"

    html_url:    "https://community.obsidian.md/plugins/sync-meter"
    github_url:  "https://github.com/wolfuardian/obsidian-sync-meter"
    description: "Show real-time sync progress percentage in the status bar. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display real-time Obsidian Sync progress as a percentage with a mini progress bar in the status bar. Provide three visual states—Syncing (accent-colored icon with animated bar and percentage), Synced (dimmed 100% icon), and Sync unavailable (greyed out)—and poll status every 2 seconds on desktop and mobile."

    stats: {
        downloads:  130
        updated_at: 1775573895000
    }
}
```
