# Chat Bubble Theme

Chat Bubble Theme styles Obsidian with four color presets named Lavender, Warm, Ocean and Forest, adding chat-bubble callouts with optional emoji indicators, rounded tables and customizable code blocks and colors. Chat callouts are injected into the Outline, including Quiet Outline, as virtual headings, and the Outline stays sticky when focus moves to a view that is not the editor. Its settings interface is multi-language.
