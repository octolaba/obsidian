# RunJS

RunJS executes JavaScript inside Obsidian from code blocks or from .js and .mjs files, so snippets can run and notes can be manipulated. Scripts are viewed and organized in a codelist or a hierarchical modal, can be autostarted, and can be attached to commands or ribbon icons. Modules are supported for structured code.

    id:     "runjs"
    name:   "RunJS"
