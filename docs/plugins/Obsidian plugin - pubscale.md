# PubScale

Syncs the Markdown content of notes into PlanetScale tables by inserting, updating or deleting rows. Which notes are synced is selectable, and records are mapped by note title so that an edit lands on the matching PlanetScale row. The recorded About states that PlanetScale should not be used as a vault backup.

```cue

    id:     "pubscale"
    name:   "PubScale"
    author: "piriwata"
    repo:   "piriwata/pubScale"

    html_url:    "https://community.obsidian.md/plugins/pubscale"
    github_url:  "https://github.com/piriwata/pubScale"
    description: "Seamlessly sync Markdown notes into PlanetScale tables."
    about:       "Sync Obsidian notes with PlanetScale tables by inserting, updating, or deleting their Markdown content. Select which notes to sync and map records by note title so updates reflect in your PlanetScale rows; do not use PlanetScale as a vault backup."
```
