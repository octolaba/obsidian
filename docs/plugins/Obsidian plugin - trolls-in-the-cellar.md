# Trolls in the Cellar

Builds Perchance-style random generators for tabletop RPG prep directly in Markdown, using troll-food tables and troll-speak blocks. Reading view renders interactive rollers with Roll and Copy actions. The syntax covers named tables, ranges, weights, nested expansions and multi-pass recursion for traps, names, loot, prompts and other structured randomness.

    id:     "trolls-in-the-cellar"
