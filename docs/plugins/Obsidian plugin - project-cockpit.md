# Project Cockpit

Replaces the new tab with a project dashboard showing project cards with status badges, TODO counts, last-modified times, and status filters. Open TODOs are aggregated by project, alongside recent sessions, a 52-week journal heatmap, a link graph, a stats bar, backlinks, and one-click quick actions.

    id:     "project-cockpit"
    name:   "Project Cockpit"
    author: "30jannik06"
    repo:   "30jannik06/Obsidian-Cockpit"

    github_url:  "https://github.com/30jannik06/Obsidian-Cockpit"
