# Focus Time

Tracks how much time is spent on each note and on PDF files. A dashboard analyses focus by day, month, year and total with drill-down bar charts and a top-ten leaderboard of notes by time. The dashboard is responsive on desktop and mobile and follows the light or dark theme.
