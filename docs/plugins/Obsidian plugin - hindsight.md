# Hindsight

Hindsight syncs notes one way into a Hindsight memory bank while Obsidian remains the single source of truth. A side panel chats with an agent that answers from the synced notes and cites the source notes, which open when a citation is clicked. The panel also shows the retrieved notes, the reasoning and a live sync status.
