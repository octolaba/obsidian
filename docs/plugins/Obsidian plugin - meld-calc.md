# Meld Calc

Evaluates math expressions inside notes with the fcal parser, covering arithmetic, units, functions, constants and variables. An expression ending in an equals sign is replaced by its result, while one without it is evaluated and the result copied to the clipboard. Multiline expressions and variable assignment are supported.
