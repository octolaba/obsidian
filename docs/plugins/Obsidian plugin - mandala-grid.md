# Mandala Grid

Organizes Markdown notes in a nine-grid mandala view for breaking themes down, mapping hierarchies and structuring writing, built on Lineage. Cells are edited, swapped, pinned and color-marked, a daily-plan template is provided, and the view switches between the tree and the mandala. The recorded description names both a three-grid and a nine-grid editor.
