# Sounders

A sidebar button plays audio from the vault: a left click starts the next track, a right click opens the player and its settings. Files are added individually or imported by folder into playlists whose track order is set by hand, with shuffle, repeat, seeking and volume controls.

```cue
plugin: {
    id:     "sounders"
    name:   "Sounders"
    author: "Razzdol"
    repo:   "razzdol/obsidian-sounders"

    html_url:    "https://community.obsidian.md/plugins/sounders"
    github_url:  "https://github.com/razzdol/obsidian-sounders"
    description: "Minimalistic audio player in the sidebar: playlists, musics, tracks, sounds, shuffle, repeat, and volume. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Play audio from a sidebar button — left-click to play the next track or right-click to open the player and settings. Add files or import folders into playlists, set custom track order, and control shuffle, repeat, seeking, and volume."

    stats: {
        downloads:  134
        updated_at: 1784297221000
    }
}
```
