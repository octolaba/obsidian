# Pinned Tabs Customizer

Pinned Tabs Customizer resizes pinned tabs and gives them custom icons drawn from emoji, symbols or Obsidian's Lucide set. Icons are assigned by filename, folder, pattern, tag or frontmatter, and folder- and pattern-based rules can be tested live and checked for conflicts. Pinned-tab width is adjustable between compact and standard layouts.

```cue
plugin: {
    id:     "pinned-tabs-customizer"
    name:   "Pinned Tabs Customizer"
    author: "diegomarzaa"
    repo:   "diegomarzaa/obsidian-pinned-tabs-customizer"

    html_url:    "https://community.obsidian.md/plugins/pinned-tabs-customizer"
    github_url:  "https://github.com/diegomarzaa/obsidian-pinned-tabs-customizer"
    description: "Resize pinned tabs and customize their icons with emojis, symbols, or icons based on file names, folders, patterns, or tags. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Resize pinned tabs and assign custom icons (emoji, symbols, or Obsidian Lucide icons) based on filenames, folders, patterns, tags, or frontmatter. Create folder- and pattern-based rules with live testing, detect conflicting rules, and adjust pinned-tab width for compact or standard layouts."
```
