# Style Text

Custom CSS styles are applied to text selected in a note. Several styles are created and managed in the plugin, and each is applied to or removed from a selection through the command palette or the editor context menu.

```cue
plugin: {
    id:     "style-text"
    name:   "Style Text"
    author: "juanjoarranz"
    repo:   "juanjoarranz/style-text-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/style-text"
    github_url:  "https://github.com/juanjoarranz/style-text-obsidian-plugin"
```
