# Direct Git Sync

Syncs the vault with a private GitHub repository on desktop and mobile using web Git operations, so no native Git installation is needed. One command stages, commits, fetches, merges and pushes, while a modal tree shows pending changes and history. Background auto-sync is available, and conflicting remote versions are saved separately so that local edits are kept.
