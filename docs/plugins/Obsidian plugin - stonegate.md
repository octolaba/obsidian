# StoneGate

The vault and individual folders are locked behind per-folder passwords, with automatic idle timeouts and lockouts after repeated attempts. Protected folders can be hidden in a Ghost Mode, a one-time recovery code is available for emergency access, and the lock screen accepts a custom background.
