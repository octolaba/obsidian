# Jenn Bridge

Jenn Bridge receives notes from Jenn Core over a secure WebSocket and creates or appends Markdown files with a title, tags and a target folder. It can also search the vault and browse folders and the vault tree. A color-coded connection status with auto-reconnect reports the state of the link.
