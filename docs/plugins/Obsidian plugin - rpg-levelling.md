# RPG Levelling

RPG Levelling awards one experience point per character typed in the active editor and tracks the resulting level. A compact overlay shows the level label, a progress bar, current XP and a level-up animation, with levels scaling infinitely as XP costs rise. Progress is backed up in app storage, and the corner holding the widget can be chosen.
