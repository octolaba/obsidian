# LeetCode template

This plugin generates a LeetCode note from a problem link or number, filling in frontmatter, the description, similar questions and either the latest or all Accepted solutions. Accepted solutions can also be imported into an existing note through the link in its frontmatter. The filename template and the predefined sections, such as My idea and Optimal solution, are customizable.

```cue
plugin: {
    id:     "leetcode-template"
    name:   "LeetCode template"
    author: "fennr"
    repo:   "fennr/obsidian_leetcode_template"

    html_url:    "https://community.obsidian.md/plugins/leetcode-template"
    github_url:  "https://github.com/fennr/obsidian_leetcode_template"
    description: "Generate LeetCode problem templates in your notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create LeetCode notes from a problem link or number by pulling frontmatter, description, similar questions and inserting the latest or all Accepted solutions. Import Accepted solutions into an existing note via its frontmatter link and apply a customizable filename template and predefined sections like My idea and Optimal solution."

    stats: {
        downloads:  107
        updated_at: 1784605406000
    }
}
```
