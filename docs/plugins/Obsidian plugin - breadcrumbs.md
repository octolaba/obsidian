# Breadcrumbs

Breadcrumbs builds a graph of hierarchies, threads and custom relations from typed links added to notes. That typed graph is visualized and traversed through several views, among them a breadcrumb trail and a matrix view, to explore the structure of the vault.

```cue
plugin: {
    id:     "breadcrumbs"
    name:   "Breadcrumbs"
    author: "Michael Porter"
    repo:   "michaelpporter/breadcrumbs"

    html_url:    "https://community.obsidian.md/plugins/breadcrumbs"
    github_url:  "https://github.com/michaelpporter/breadcrumbs"
    description: "Visualise the hierarchy of your vault using a breadcrumb trail or matrix view."
    about:       "Add typed links to notes to build a graph of hierarchies, threads, and custom relations. Visualize and traverse the typed graph with multiple views to explore and navigate your note structure."
```
