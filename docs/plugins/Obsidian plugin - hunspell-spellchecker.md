# Hunspell Spellchecker

Hunspell Spellchecker checks spelling offline using standard Hunspell dictionary pairs of aff and dic files, with suggestions in real time and a local personal dictionary. Several languages and ignored-word lists are managed and the active language is switched from the status bar. Its recorded inputs state mobile-optimized, low-memory performance with all data kept local.
