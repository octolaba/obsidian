# YT Knowledge Notes

Converts YouTube videos and playlists into vault-native notes whose Markdown leads with the transcript and carries YAML frontmatter. Notes are transcript-only or extended with AI summaries from OpenAI, Anthropic, Gemini or a local OpenAI-compatible model, using built-in templates or custom prompts. Media is embedded or omitted, and a playlist yields either one note per video or a single combined note.
