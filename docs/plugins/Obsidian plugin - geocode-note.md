# Geocode Note

Stores geographic metadata in a note's YAML frontmatter: coordinates, a marker icon, a color and the resolved address. Coordinates are set from device geolocation, an address search, manual entry or a draggable MapLibre marker with live preview. Interactive inline maps are rendered from a geocode-map block, and geocoded notes are exported to GeoJSON, KML, GPX or CSV.

    id:     "geocode-note"
    name:   "Geocode Note"
