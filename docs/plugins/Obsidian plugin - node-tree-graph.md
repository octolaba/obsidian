# Node Tree Graph

Node Tree Graph splits each file into a root node plus one node per heading, so the vault graph traces connections between individual sections rather than whole notes. Heading depth and the rollup of links from hidden sections are configurable, hovering highlights parent and child neighbours, and node and edge visuals and the physics can be customized.
