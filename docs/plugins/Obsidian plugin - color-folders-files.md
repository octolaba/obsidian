# Color Folders and Files

Color Folders and Files customizes how folders and files look in the file explorer through a context-menu color picker and style controls. Background and text colors, font weight and style, and opacity are set per item and can propagate to subfolders and files, presets are saved and applied, and filenames can be styled by extension.
