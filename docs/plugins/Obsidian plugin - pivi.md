# Pivi

Pivi embeds a Pi AI agent in the vault as a sidebar with multi-tab chat, streaming responses and file-aware context. Inline editing rewrites the current selection, and Obsidian-native read, write and search tools understand wikilinks and frontmatter. Vault-local skills and sessions are managed from the plugin, and the recorded inputs state that writes require confirmation.
