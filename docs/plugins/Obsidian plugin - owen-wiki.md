Installs the Owen-WIKI template kit into the active vault, creating an LLM wiki structure of starter pages, ontology and page templates, automation scripts and assets, with an optional GitHub Actions workflow. Presets provision minimal, standard, full or custom setups. The index entry records that the plugin has not been manually reviewed by Obsidian staff.
