# Smart Punctuation on Rendering

Smart Punctuation on Rendering displays ASCII punctuation as typographic characters — curly quotes, en and em dashes and ellipses — when a note is rendered, so those characters need not be entered directly. The transformation applies in reading view only, since live preview is unsupported. Its recorded About text warns of possible element changes, missed backslash escapes and slower rendering on very large notes.
