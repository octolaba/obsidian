# Barcode Generator

Barcode Generator renders customizable barcodes in notes from codeblocks, using JsBarcode. Code 128 in its A, B and C variants, EAN-13, Pharmacode and further formats are supported, appearance is configured through codeblock parameters, and rendering works on desktop and mobile.

```cue
plugin: {
    id:     "barcode-generator"
    name:   "Barcode Generator"
    author: "noxonad"
    repo:   "noxonad/obsidian-barcode-generator"

    html_url:    "https://community.obsidian.md/plugins/barcode-generator"
    github_url:  "https://github.com/noxonad/obsidian-barcode-generator"
    description: "Generate customizable barcodes into your notes."
    about:       "Generate and display barcodes directly in notes using codeblocks powered by JsBarcode. Support multiple formats—Code 128 (A/B/C), EAN‑13, Pharmacode and more—and configure appearance via codeblock parameters; render on desktop and mobile."
```
