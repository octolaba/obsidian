# Sync Folds

Syncs fold states across devices by storing them in the plugin's vault-backed data.json file. Changes are saved automatically as sections are folded and unfolded, and the stored states are restored when a file is opened on another device.

```cue
plugin: {
    id:     "sync-folds"
    name:   "Sync Folds"
    author: "James Alexandre"
    repo:   "itsonlyjames/obsidian-sync-folds"

    html_url:    "https://community.obsidian.md/plugins/sync-folds"
    github_url:  "https://github.com/itsonlyjames/obsidian-sync-folds"
    description: "Enables Syncing of Fold States Across Devices. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync fold states across devices by saving them to your vault-backed plugin data.json. Automatically save changes as you fold/unfold and restore those states when opening files on other devices."

    stats: {
        downloads:  2117
        updated_at: 1778628738000
    }
}
```
