# Iconocolor

Iconocolor customizes folder icons and colors in the file explorer, taking icons from SVG or PNG files, URLs or a Lucide icon search. Palettes auto-color root folders, HSL and lightness transformations are applied, and child folders inherit and interpolate colors as gradients. Profiles and default icon rules keep the scheme consistent.
