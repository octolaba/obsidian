# Fetch Prayer Times

Fetch Prayer Times retrieves the current prayer times from the Aladhan API and saves them to a note, showing local and UTC times with customizable date formatting. The location is chosen as a city or detected automatically, and the prayers that appear are selectable. Update triggers and 12- or 24-hour time formats are configurable.

    id:     "fetch-prayer-times"
    name:   "Fetch Prayer Times"
    author: "eccys"
