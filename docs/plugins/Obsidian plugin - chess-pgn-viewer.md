# Chess PGN Viewer

Chess PGN Viewer renders a chess game from PGN inside a fenced chess code block as a clickable board. Moves can be stepped through and the board reset, while comments, nested variations, board annotations such as square highlights and arrows, and PGN move glyphs are displayed.
