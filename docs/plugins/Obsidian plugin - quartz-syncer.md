# Quartz Syncer

Publishes notes from the vault to a Quartz static site through a Git provider — GitHub, GitLab, Bitbucket, Codeberg, Gitea, Forgejo or a self-hosted instance. Dataview, Datacore and Fantasy Statblocks queries are compiled into static content, with caching and automatic recompilation for data that changes. Exact diffs are previewed in split or unified view before notes are published, updated or removed selectively, and the workflow is automated through the Obsidian CLI.
