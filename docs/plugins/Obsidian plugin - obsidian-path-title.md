# Path Title

This plugin adds the current file's path next to the title of each pane for location context. The path font size is customizable, and ordered replacements, matching an exact path, a folder, plain text or a regular expression, shorten or rewrite path segments.

```cue
plugin: {
    id:     "obsidian-path-title"
    name:   "Path Title"
    author: "jdeal"
    repo:   "jdeal/obsidian-path-title-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-path-title"
    github_url:  "https://github.com/jdeal/obsidian-path-title-plugin"
    description: "Add the path (or optional replacement) to the filename title of each pane."
    about:       "Show the current file's full path next to its title for quick location context. Customize path font size and apply ordered replacements (exact path, folder, text, or regex) to shorten or rewrite path segments."
```
