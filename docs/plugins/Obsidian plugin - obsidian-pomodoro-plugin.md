# Pomodoro Plugin

This plugin adds a simple pomodoro timer to the Obsidian window for focused work intervals and short breaks. Session and break durations are adjusted in settings to follow the Pomodoro Technique, and completed pomodoros are tracked.

```cue
plugin: {
    id:     "obsidian-pomodoro-plugin"
    name:   "Pomodoro Plugin"
    author: "tokuhirom"
    repo:   "tokuhirom/obsidian-pomodoro-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-pomodoro-plugin"
    github_url:  "https://github.com/tokuhirom/obsidian-pomodoro-plugin"
```
