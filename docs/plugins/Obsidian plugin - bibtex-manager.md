# BibTeX Manager

BibTeX Manager creates literature notes from BibTeX entries using customizable templates. It displays formatted reference lists, inserts citations instantly, and fetches BibTeX from remote sources such as arXiv and Google Books in a self-contained workflow that also works on mobile.
