# Conflict Manager

Conflict Manager reviews and resolves sync conflicts coming from any cloud service, without hunting through the file system. A conflicted note is opened, reviewed and then resolved from within Obsidian.

```cue
plugin: {
    id:     "conflict-manager"
    name:   "Conflict Manager"
    author: "Armen Abrahamyan"
    repo:   "demigoddd/obsidian-conflict-manager"

    html_url:    "https://community.obsidian.md/plugins/conflict-manager"
    github_url:  "https://github.com/demigoddd/obsidian-conflict-manager"
```
