# Terminus

Terminus provides a real terminal in Obsidian with full PTY shells, multiple sessions, splits, adjustable font and persistent scrollback. When Claude runs inside it, a failed command gains a one-click badge asking Claude to explain and fix it, and every edit Claude makes lands in a Pending Changes panel carrying per-file line-numbered diffs with Accept, Reject and Edit actions. The recorded description adds word-level diffs, undo and backlink-breakage warnings to that review workflow, and states that the local Claude CLI is used, with no separate account and no stored API keys.
