# AgendaPane

Plans one-off and recurring tasks in a right-sidebar calendar without creating or modifying Markdown notes. A compact monthly calendar sits above a focused daily task list, and tasks carry times, durations, priorities, notes and recurrences and can be reordered, moved, completed or deleted with keyboard navigation. Data is held locally per vault, and the project states that there is no cloud service and no telemetry.
