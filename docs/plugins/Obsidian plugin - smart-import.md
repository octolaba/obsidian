# Smart Import

Smart Import brings files and folders from outside the vault in and converts supported documents into Markdown notes while keeping the original source files. It extracts embedded media from Office documents, generates stub notes for low-quality PDFs, and offers optional cleanup through an OpenAI-compatible service with a local rule-based fallback. Files can be chosen with a picker, dragged and dropped, taken from recent downloads, a Finder selection or the clipboard, or found by natural-language lookup; the plugin is recorded as desktop-only and best tested on macOS.
