# Poke Gateway

Connects the vault to Poke over an outbound WebSocket gateway so that Poke can list, search, and read Markdown notes. Write access is enabled separately and lets Poke create or overwrite Markdown files. The recorded description states that no inbound ports, tunnels, or router changes are required.

    name:   "Poke Gateway"
    author: "Matt"

    github_url:  "https://github.com/mrl-00/poke-obsidian"
