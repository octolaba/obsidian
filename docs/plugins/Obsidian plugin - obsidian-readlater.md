# Read Later

This plugin syncs web pages into Markdown notes and keeps them in step with their online versions. It integrates with the read-it-later services Pocket and Instapaper to fetch unread bookmarks, download or update pages, and map notes to URLs through frontmatter or commands. Items can optionally be archived, and syncs can run periodically.

```cue
plugin: {
    id:     "obsidian-readlater"
    name:   "Read Later"
    author: "canna71"
    repo:   "canna71/obsidian-readlater"

    html_url:    "https://community.obsidian.md/plugins/obsidian-readlater"
    github_url:  "https://github.com/canna71/obsidian-readlater"
    description: "Synch web pages to Markdown and integrate with read-it-later apps (Pocket, Instapaper)."
    about:       "Save web pages as Markdown notes and keep them synced with their online versions. Integrate with Pocket and Instapaper to fetch unread bookmarks, download or update pages, map notes to URLs via frontmatter or commands, and optionally archive items or run periodic syncs."

    stats: {

}
```
