# Sync Vault

Connects cloud drives to Obsidian so cloud files are linked or embedded in notes by file ID or path, with Baidu, Aliyun, Quark, WebDAV and S3 named as supported backends. A built-in MCP SSE server is described as giving LLMs and AI agents real-time access to those files. The recorded inputs also name bidirectional sync and backup across devices, conflict merging, Markdown encryption and collaborative editing.
