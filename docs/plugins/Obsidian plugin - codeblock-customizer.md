# Codeblock Customizer

Codeblock Customizer restyles code blocks with built-in or custom themes, per-language syntax colors, backgrounds, headers carrying filenames and icons, and optional line numbers. Specific lines or text can be highlighted in several colors, the active line can be highlighted, blocks fold from their header and can be grouped into tabs. It also renders terminal prompts and inline syntax, converts comments into annotations, exports code as images, and supports PrismJS in editor mode.
