# Live Life Recording

Records task start and finish times directly in Markdown, with no external database: a single toggle command creates a task, stamps its start, and marks it finished, and estimates, actual times, and finish records all live in the task line itself. Recurring routines are inserted into daily notes automatically and roll over until completed, following flexible repeat rules, while a summary sidebar shows running tasks, remaining estimates, and daily totals. Timestamps edited by hand cause the rest to be recalculated, and because everything stays plain Markdown the records remain readable after the plugin is removed.
