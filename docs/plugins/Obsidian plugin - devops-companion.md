# DevOps Companion

DevOps Companion parses infrastructure files in the vault — Dockerfiles, YAML, Terraform and CI/CD pipeline definitions — and watches selected folders for changes. It generates organized Markdown documentation from what it finds, and can produce explanations or rewrites through OpenAI, Google Gemini, Anthropic or Mistral. Scanning runs manually or as live monitoring.
