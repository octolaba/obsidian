# Excalidraw

The plugin integrates the Excalidraw sketching tool into Obsidian. Drawings are stored as editable files inside the vault, can be embedded into notes, and can be linked to and from documents.

```cue
plugin: {
    id:     "obsidian-excalidraw-plugin"
    name:   "Excalidraw"
    author: "zsviczian"
    repo:   "zsviczian/obsidian-excalidraw-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-excalidraw-plugin"
    github_url:  "https://github.com/zsviczian/obsidian-excalidraw-plugin"
    description: "Visual PKM powerhouse. Create and edit Excalidraw drawings."
    about:       "Create and edit sketches directly in your vault. Embed drawings into notes, link drawings and documents to each other, and store editable Excalidraw files alongside your Markdown."

    stats: {
        downloads:  6816107
        updated_at: 1783619930000
    }
}
```
