# Companion for Claude

Puts a Claude chat in a side panel with streaming Markdown replies, message actions, vault-aware context chips and per-message model and reasoning controls. Output marked as claude-html renders inline or is saved as an interactive note, code sessions are captured into sanitized digests, and chats persist between runs. A local Ollama model serves as the offline fallback.
