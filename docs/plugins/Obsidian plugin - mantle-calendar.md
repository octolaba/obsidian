# Mantle Calendar

Presents a context-aware calendar for events, daily notes and time-sensitive tasks in Obsidian's sidebars or pane layouts, showing them in a monthly or daily grid. Double-clicking a calendar day or an event block generates, opens or links to a Markdown note. The recorded text says the calendar inherits typography, rounded capsule borders and active glows from the Zenith theme.
