# Clean Copy

Copies a selection or a whole note to the clipboard with the metadata left behind. Frontmatter is dropped, wikilinks become plain text, and inline tags, block-id anchors and callout syntax are stripped. An option removes the remaining Markdown formatting as well.

```cue
plugin: {
    id:     "clean-copy"
    name:   "Clean Copy"
    author: "Rafael Mehdiyev"
    repo:   "rafaelmehdiyev/obsidian-clean-copy"

    html_url:    "https://community.obsidian.md/plugins/clean-copy"
    github_url:  "https://github.com/rafaelmehdiyev/obsidian-clean-copy"
    description: "Copy notes to clipboard without YAML, wikilinks, tags, block IDs, and callout syntax. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Copy a selection or whole note to clipboard without frontmatter or other metadata. Strip [[wikilinks]] to plain text, remove inline #tags, ^block-id anchors and callout syntax, with an option to also remove all Markdown formatting."

    stats: {
        downloads:  179
        updated_at: 1779548686000
    }
}
```
