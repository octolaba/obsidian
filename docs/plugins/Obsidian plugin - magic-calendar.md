# MagicCalendar

Finds calendar events in Markdown notes using natural-language processing and synchronizes them with a calendar of choice, either Apple Calendar or Google Calendar. Events are embedded inline with a code-block syntax, incorrect detections can be banned, and custom delimiters catch patterns that are otherwise missed. Two-way sync is available with Apple, while Google uses OAuth and supports push over HTTPS.
