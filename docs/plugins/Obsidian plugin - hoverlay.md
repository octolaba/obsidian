# Hoverlay

Hoverlay previews an external link on hover in a floating window, as a live page, a sanitized reader view without scripts or trackers, or a metadata card with embedded media players. Sites that block framing are still loaded, and the popover can be browsed, pinned and resized, or the page opened in the browser.

```cue
plugin: {
    id:     "hoverlay"
    name:   "Hoverlay"
    author: "zspatter"
    repo:   "zspatter/obsidian-hoverlay"

    html_url:    "https://community.obsidian.md/plugins/hoverlay"
    github_url:  "https://github.com/zspatter/obsidian-hoverlay"
    description: "Preview links on hover in a floating window: live page, reader view, or metadata card, with embedded media players. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Preview external links on hover as a live page, a clean reader view (sanitized with no scripts or trackers), or a metadata card with embedded media players. Load real sites that block framing, browse inside the popover, pin and resize it, or open the page in your browser."

    stats: {
        downloads:  134
        updated_at: 1783634029000
    }
}
```
