# NextDeck

NextDeck stores every Kanban card as a real Markdown note in the vault and presents boards with drag-and-drop lists, inline card creation, coloured labels, start and due dates and checklist progress. Boards sync in both directions with Nextcloud Deck using field-level conflict resolution, attachments can be included, and sync logs are viewable. The recorded description states that credentials are kept encrypted.
