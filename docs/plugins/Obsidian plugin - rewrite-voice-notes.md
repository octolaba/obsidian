# ReWrite (Voice Notes)

ReWrite records audio or takes pasted text, transcribes it with cloud or local engines, then cleans and structures the result with an LLM before inserting Markdown into the vault. The recorded text states it can run fully local with whisper.cpp and a local OpenAI-compatible LLM, and that API keys are kept encrypted. Editable templates, speaker diarization and saved audio embeds are also listed.
