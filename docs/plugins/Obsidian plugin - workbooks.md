# Workbooks

Works with spreadsheets inside notes, either through an embedded sheet code block or by linking an external XLSX, XLS or CSV file. Sheets can be stored in the note itself or kept in sync with the external file. Formatting is preserved when saving to a code block and mostly retained with XLSX, while CSV stores the data alone.

plugin: {
    id:     "workbooks"
    name:   "Workbooks"
    author: "canna71"
    repo:   "canna71/obsidian-sheets"

    html_url:    "https://community.obsidian.md/plugins/workbooks"
    github_url:  "https://github.com/canna71/obsidian-sheets"
    description: "Work with spreadsheets inside your notes."
