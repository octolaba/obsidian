# Review Simple

Review Simple schedules recurring rereads and records the last-review date in each note's frontmatter. Per-note review status and a vault-wide due counter are displayed, and intervals can be set globally, per folder or per note with folder include and exclude filtering. Due notes are opened or marked through commands or by clicking the status bar.
