# Vault Autopilot

Receives screenshots and video frames from the Visual Clipper Chrome extension over a local port and writes them into the vault as structured notes. Images are stored in organized subfolders, clips taken from the same video are merged into one note as added sections, and a link to the created or updated note is returned.

    id:     "vault-autopilot"
    name:   "Vault Autopilot"
    author: "Ava li"
