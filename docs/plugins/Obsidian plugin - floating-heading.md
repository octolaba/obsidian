# Floating Heading

Tracks the heading level of the current viewport, from the first to the sixth level, and updates while a long note is scrolled. The current heading is extracted into a floating window that can be dragged, resized and locked, and clicking it jumps back to that heading. When nothing matches, the window collapses into a small icon, and it hides itself in Canvas, board, database and non-Markdown files.
