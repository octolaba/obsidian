# Right-Click Tools

Right-Click Tools adds file and folder actions to the File Explorer right-click menu, together with a ribbon button. It creates a folder or note named for today's date in YYYY-MM-DD form, incrementing numerically when that name already exists, and moves selected files or folders to a configurable destination folder.

```cue
plugin: {
    id:     "right-click-tools"
    name:   "Right-Click Tools"
    author: "z0lw"
    repo:   "z0lw/obsidian-right-click-tools"

    html_url:    "https://community.obsidian.md/plugins/right-click-tools"
    github_url:  "https://github.com/z0lw/obsidian-right-click-tools"
    description: "Adds Explorer right-click actions and a ribbon button to create today’s date folder or note and move selected items to a configurable folder. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add right-click actions to the file explorer for quick file and folder management. Create today's date folder (YYYY-MM-DD) with automatic numeric increments when a name exists, and move selected files or folders to a configurable destination folder."
```
