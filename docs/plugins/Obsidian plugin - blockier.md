# Blockier

Blockier selects the current block without its bullet, number, heading, quote or checkbox prefix, and works with multiple cursors and inside code blocks. Typing a new prefix at the start of a line overrides an existing list or checkbox marker. It also offers configurable suggestions for custom checkboxes and callouts.
