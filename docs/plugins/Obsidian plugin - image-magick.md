# ImageMagick

Resizes, crops, rotates, flips, compresses and converts images inside the vault without uploading files or leaving Obsidian. Conversion covers JPEG, PNG, WebP, GIF, TIFF, BMP and AVIF, with live preview, an output size estimate, output naming, presets and bulk processing. The recorded description credits Safi-Image as the underlying technology.
