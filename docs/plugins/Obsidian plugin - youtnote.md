# Youtnote

Takes timestamped Markdown notes against several embedded YouTube videos inside a single note, with live preview editing. The player and the notes stay in lockstep, so the note keeps the context of what was being watched, and everything exports back to clean Markdown. It works on desktop and mobile.

```cue
plugin: {
    id:     "youtnote"
    name:   "Youtnote"
    author: "khaldevmedia"
    repo:   "khaldevmedia/obsidian-youtnote"

    html_url:    "https://community.obsidian.md/plugins/youtnote"
    github_url:  "https://github.com/khaldevmedia/obsidian-youtnote"
    description: "Take timestamped Markdown notes across multiple embedded YouTube videos, all inside a single note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Take timestamped Markdown notes with live preview editing across multiple embedded YouTube videos, all inside a single Obsidian note. Then, if you want, export everything back to clean Markdown. Youtnote keeps the video player and your research notes in lockstep so you never lose the context of what you were watching. Works on desktop and mobile."

    stats: {

}
```
