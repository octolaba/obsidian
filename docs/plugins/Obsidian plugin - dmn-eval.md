# DMN Eval

Evaluates DMN decision tables inside notes and renders the decision output inline using the Camunda dmn-engine. Inputs come from DMN file links together with note front-matter or variables, and evaluation runs locally, which requires Java 14 or newer.

    id:     "dmn-eval"
    name:   "DMN Eval"
