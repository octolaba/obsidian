# Table Dashboard

Builds dashboard visualizations from Markdown tables, including progress bars, counters, percentages, streaks and line plots. Table data is aggregated and filtered across the current file, specific files or whole folders using time periods and table-tag markers, and goals are extracted from columns. Widgets are displayed in a grid or a compact list.
