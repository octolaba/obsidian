# Transcriber

Transcribes images into structured Markdown with local Ollama vision models, extracting headings, lists, tables and code blocks. Whole folders can be transcribed in batch with per-file progress, a Markdown file is created beside each image, and models are managed locally so the recorded inputs describe processing as staying on the machine.

    id:     "image-transcriber"
    name:   "Transcriber"
    author: "Sébastien Dubois"
