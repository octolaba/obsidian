# RMarkdown Reader

RMarkdown Reader opens and edits RMarkdown files in the vault while leaving them in the .rmd format. Code chunks get labeled headers showing engine, name and options, inline R expressions are marked with badges, and the styling follows the active theme. The files are indexed so they appear in search and graph views.

```cue
plugin: {
    id:     "rmarkdown-reader"
    name:   "RMarkdown Reader"
    author: "jaskonas"
    repo:   "jaskonas/obsidian-rmarkdown"

    html_url:    "https://community.obsidian.md/plugins/rmarkdown-reader"
    github_url:  "https://github.com/jaskonas/obsidian-rmarkdown"
    description: "Read and display RMarkdown (.rmd/.Rmd) files with R chunk highlighting and RStudio integration. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open and edit RMarkdown (.rmd/.Rmd) files directly in your vault while keeping them as .rmd. Show labeled headers for code chunks (engine, name, options), mark inline R expressions with badges, and index .rmd files for search and graph views with theme-aware styling."

    stats: {
        downloads:  181
        updated_at: 1779813868000
    }
}
```
