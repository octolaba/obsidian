# Block Link Plus

Block Link Plus creates multi-line block references and copies links, embeds or Obsidian URIs to blocks and headings using stable id ranges. It can treat list items as Logseq-style outline blocks with hidden metadata and query or render them through a blp-view backed by Dataview. It also opens a continuous journal feed and allows embedded blocks to be edited inline.
