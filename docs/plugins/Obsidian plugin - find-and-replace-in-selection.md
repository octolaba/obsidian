# Find and replace in selection

Find and replace in selection restricts find and replace to the selected text or the current line, matching with plain text or with regular expressions. All matches inside the selection are replaced at once, which suits updating headings, stripping formatting or transforming embeds in place.

```cue
plugin: {
    id:     "find-and-replace-in-selection"
    name:   "Find and replace in selection"
    author: "dy-sh"
    repo:   "dy-sh/obsidian-find-and-replace-in-selection"

    html_url:    "https://community.obsidian.md/plugins/find-and-replace-in-selection"
    github_url:  "https://github.com/dy-sh/obsidian-find-and-replace-in-selection"
    description: "Find what you are looking for in the selected text and replace it with the specified text."
    about:       "Find and replace text only within a selected region or the current line using plain text or regular expressions. Replace all matches inside the selection to update headings, strip formatting, or transform embeds in-place."
```
