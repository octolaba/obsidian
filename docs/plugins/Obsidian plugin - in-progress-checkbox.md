# In Progress Checkbox

Adds an in-progress checkbox state, written as a slash inside the brackets, to task lists. Shift-clicking marks a task in progress, clicking an unchecked or in-progress box completes it, and clicking a completed box unchecks it, in both Reading and Live Preview.

```cue
plugin: {
    id:     "in-progress-checkbox"
    name:   "In Progress Checkbox"
    author: "jyuukun"
    repo:   "jyuukun/obsidian-in-progress-checkbox"

    html_url:    "https://community.obsidian.md/plugins/in-progress-checkbox"
    github_url:  "https://github.com/jyuukun/obsidian-in-progress-checkbox"
    description: "Shift+Click to set checkbox to in-progress [/] state. Simple click cycles between states. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add an \"in progress\" state ([/]) to task checkboxes in Obsidian. Use Shift+Click to mark in-progress, click unchecked or in-progress to mark complete, and click completed to uncheck; works in both Reading and Live Preview."

    stats: {
        downloads:  124
        updated_at: 1768385014000
    }
}
```
