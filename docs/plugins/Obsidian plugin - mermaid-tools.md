# Mermaid Tools

Opens a Mermaid toolbar that inserts common Mermaid.js building blocks into the editor with one click. Custom elements are created, edited, deleted and reordered to build reusable diagram snippets, and each element is wrapped as a complete diagram so it renders on its own.
