# URL Namer

Converts plain URLs in selected text into Markdown links labelled with the title of each page. Pasted URLs can be named automatically, already-linked URLs are skipped, and titles are read from the HTML title as well as og:title and twitter:title. The recorded About states that it falls back gracefully when offline.

```cue
plugin: {
    id:     "url-namer"
    name:   "URL Namer"
    author: "zfei"
    repo:   "zfei/obsidian-url-namer"

    html_url:    "https://community.obsidian.md/plugins/url-namer"
    github_url:  "https://github.com/zfei/obsidian-url-namer"
    description: "Retrieve the HTML title of web pages to name external links."
    about:       "Convert plain URLs in selected text into Markdown links labeled with each page's title. Auto-name pasted URLs, skip already-linked URLs, extract titles from HTML, og:title and twitter:title, and fall back gracefully when offline."

    stats: {
        downloads:  8395
        updated_at: 1776426023000
    }
}
```
