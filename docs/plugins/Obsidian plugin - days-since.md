# Days Since

Shows how many days have passed since an ISO date written in a note by hovering over it, displaying the day count in a tooltip. It reads dates in the YYYY-MM-DD form, for tracking project timelines, journal entries and other dates. The index description also advertises an interactive milestone timeline with anniversary reminders, which the directory text does not describe.

    id:     "days-since"
    name:   "Days Since"
