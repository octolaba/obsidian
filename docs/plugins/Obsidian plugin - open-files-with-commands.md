# Open files with commands

Open files with commands creates commands that each open exactly one file, invoked from the command palette or through the Commander plugin. A command is created by right-clicking a note, and the created commands are managed, renamed or deleted from the community plugins settings.

```cue
plugin: {
    id:     "open-files-with-commands"
    name:   "Open files with commands"
    author: "lostpaul"
    repo:   "lostpaul/ob-open-files-with-commands"

    html_url:    "https://community.obsidian.md/plugins/open-files-with-commands"
    github_url:  "https://github.com/lostpaul/ob-open-files-with-commands"
    description: "Create commands that only open one file at the time and that can be used with the commander plugin."
    about:       "Create single-file commands by right-clicking notes to open specific files from the command palette or via Commander. Manage, rename, or delete those commands from the Community Plugins settings. Invoke a named command to jump directly to its mapped file."

    stats: {
        downloads:  6098
        updated_at: 1690531401000
    }
}
```
