# Note Reviewer

Filters and fetches notes for review based on the tags recorded in their YAML frontmatter. The Note Reviewer opens from the sidebar, and a review checkbox marks a note as done to record completion.

```cue
plugin: {
    id:     "note-reviewer"
    name:   "Note Reviewer"
    author: "travislinkey"
    repo:   "travislinkey/note-reviewer"

    html_url:    "https://community.obsidian.md/plugins/note-reviewer"
    github_url:  "https://github.com/travislinkey/note-reviewer"
    description: "Plugin to filter and review notes"
    about:       "Review notes by filtering and fetching items based on YAML frontmatter tags. Open the Note Reviewer from the sidebar and mark notes done with the review checkbox to record completion."

    stats: {
        downloads:  589
        updated_at: 1751156717000
    }
}
```
