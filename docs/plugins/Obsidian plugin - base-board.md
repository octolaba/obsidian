# Base Board

Base Board organizes notes into a Kanban board whose columns are generated from any frontmatter property, using Bases as the data source. Cards are dragged between columns to update the frontmatter and write the change back to the Markdown file, and cards and columns can be renamed inline or created directly in a column. Notes open in a floating Obsidian editor, and cards show metadata and color-coded tag chips with hover previews.
