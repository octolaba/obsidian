# VARE

Manages installed plugins and themes by choosing which release to install or to revert to. Unlisted releases can be installed from GitHub, and beta or pre-release builds can be tested and then switched back if necessary.

    id:     "vare"
    name:   "VARE"
    author: "4source"
    repo:   "4source/vare-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/vare"
    github_url:  "https://github.com/4source/vare-obsidian-plugin"
    description: "Now you can easily manage your plugins and themes. Simply select the version you want or install unlisted versions from GitHub. You can also install beta version and switch back if necessary."
