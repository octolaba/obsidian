# Lucanise Vault Assistant

Chats with Claude about a note, a folder or the whole vault by sending the selected local files to Anthropic's API and showing the replies in a built-in chat panel. Edits proposed by the model are applied to the vault only after they are confirmed. The recorded text states that the API key and plugin data stay local, that only Anthropic's API is contacted, and that the plugin works on iOS and iPadOS.
