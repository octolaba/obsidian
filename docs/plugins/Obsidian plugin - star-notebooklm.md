# Star NotebookLM

Obsidian notes are added as sources to Google NotebookLM through a webview embedded in the app. Notes are sent from a ribbon icon, from context menus or from the command palette, and a notebook can be chosen or created for them. The recorded inputs state that direct API calls make source additions faster and more reliable.
