# Personal Development Plan

Personal Development Plan tracks personal and professional development work through a seven-tab interface covering Knowledge Base, Planned, In Progress, Sources, Statistics, History and Examples. Tasks move through that lifecycle from the Knowledge Base to History, with alerts for deadlines and task limits. Periodic tasks can be created with templates applied automatically.
