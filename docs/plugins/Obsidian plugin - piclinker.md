# PicLinker

PicLinker manages image assets across the whole vault, covering scanning, deduplication, comparison and batch operations. An eight-zone view groups local, cloud, unreferenced, broken, duplicate, same-name and empty-folder assets, and SHA-256 duplicates are detected with references updated when deduping. Batch delete, copy and download tasks run alongside WebDAV or cloud-host sync, with credentials kept encrypted and every write requiring manual confirmation.
