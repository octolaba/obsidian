# Quick Switcher++

Extends the quick switcher so that files can be found by heading rather than by filename, and so that symbols, canvas nodes, tags, links, embeddings and related files can be located across the vault. The same switcher navigates open editors, side panels, workspaces and vaults, runs Obsidian commands and searches bookmarks, with quick filters to narrow the result list before jumping to a target.
