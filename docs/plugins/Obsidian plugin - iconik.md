# Iconik

Iconik sets an icon and text or background color for any file or folder from a single right-click in the file explorer. Lucide icons are assigned and colors picked with a live preview, and the choices persist through a single CSS stylesheet, which its recorded inputs describe as carrying no performance overhead.
