# Sidecar Notes

Sidecar Notes pairs a source note with a companion sidecar file in a split view so both stay visible while reading and annotating. Selected text is sent to the sidecar as a blockquote and marked in the source as a highlight, companion files are created automatically under a notes suffix, and duplicate quotes are prevented.

```cue
plugin: {
    id:     "sidecar-notes"
    name:   "Sidecar Notes"
    author: "rosemary1812"
    repo:   "rosemary1812/Sidecar-Notes"

    html_url:    "https://community.obsidian.md/plugins/sidecar-notes"
    github_url:  "https://github.com/rosemary1812/Sidecar-Notes"
    description: "A sidecar note workflow with split view, synced quotes, and companion note files. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open a source note beside a dedicated sidecar to read and annotate with both files visible. Send selected text to the sidecar as blockquotes, mark the source with ==highlight==, auto-create companion files named {basename} notes.md, and prevent duplicate quotes."

    stats: {
        downloads:  517
        updated_at: 1778902715000
    }
}
```
