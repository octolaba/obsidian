# Typing Stats

Compiles typing statistics in the background while notes are written, recording daily figures and a history. The tracked values are active typing time, typing bursts, average net WPM computed as added minus deleted characters, corrections and corrections per minute, and totals for added, deleted and net characters.

```cue
plugin: {
    id:     "typing-stats"
    name:   "Typing Stats"
    author: "Ryan Hardy"
    repo:   "ryyhardy/obsidian-typing-stats"

    html_url:    "https://community.obsidian.md/plugins/typing-stats"
    github_url:  "https://github.com/ryyhardy/obsidian-typing-stats"
    description: "A more productive way to build good typing habits. Compiles advanced typing stats as you take notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Track typing performance and note-taking activity in the background while you write. Record daily stats and view history, including active typing time, typing bursts, average net WPM (added minus deleted chars), corrections and corrections/min, plus total added, deleted and net characters."

    stats: {
        downloads:  12
        updated_at: 1784605767000
    }
}
```
