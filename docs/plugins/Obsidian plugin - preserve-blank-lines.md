# Preserve Blank Lines

Preserves consecutive blank lines in reading mode so that the rendered spacing matches the source exactly. Each preserved blank line is rendered as a stylable element carrying its own class, so the spacing can be adjusted with CSS.

```cue
plugin: {
    id:     "preserve-blank-lines"
    name:   "Preserve Blank Lines"
    author: "Yves Lefebvre"
    repo:   "ivanohe73/obsidian-preserve-blank-lines"

    html_url:    "https://community.obsidian.md/plugins/preserve-blank-lines"
    github_url:  "https://github.com/ivanohe73/obsidian-preserve-blank-lines"
    description: "Preserves consecutive blank lines in reading mode, matching the source 1:1. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Preserve consecutive blank lines in reading mode so visual spacing matches your source exactly. Render each preserved blank line as a stylable div (.preserve-blank-line) so you can adjust spacing with CSS."
```
