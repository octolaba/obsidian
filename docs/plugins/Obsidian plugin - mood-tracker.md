# Mood Tracker

Mood Tracker records moods and emotions with customizable labels, ratings, detailed emotion lists and notes, stored as plain JSON inside the vault. Entries can be added or edited, including for past dates, and attached to journal notes through dynamic paths. Tracked history is shown as interactive graphs, and statistics can be embedded with a mood-tracker-stats code block.

```cue
plugin: {
    id:     "mood-tracker"
    name:   "Mood Tracker"
    author: "Daniel Nikolaev"
    repo:   "dartungar/obsidian-mood-tracker"

    html_url:    "https://community.obsidian.md/plugins/mood-tracker"
    github_url:  "https://github.com/dartungar/obsidian-mood-tracker"
    description: "Track your moods & emotions easily. Visualize tracked history and browse the past entries."
    about:       "Track moods and emotions with customizable labels, ratings, detailed emotion lists, and notes stored as plain JSON in your vault. Add or edit entries (including past dates), attach entries to journal notes via dynamic paths, and view interactive history graphs and embeddable stats with a mood-tracker-stats code block."

    stats: {

}
```
