# PDF2Image

Turns a PDF into a series of images and inserts them into a note for inline viewing and annotation. Page headers can be extracted with duplicate headers prevented, spacing or separators can be added below each image, and image format and quality are configurable.

```cue
plugin: {
    id:     "pdf2img"
    name:   "PDF2Image"
    author: "rasmusachr"
    repo:   "rasmusachr/PDF2Images"

    html_url:    "https://community.obsidian.md/plugins/pdf2img"
    github_url:  "https://github.com/rasmusachr/PDF2Images"
    description: "Turns a PDF into a series of images."
    about:       "Convert PDF pages into images and insert them directly into notes for inline viewing and annotation. Extract page headers, prevent duplicate headers, and add customizable spacing or separators below each image while choosing image formats and quality for optimal size and clarity."
```
