# Operon

Operon is a task and project management system that unifies inline tasks kept inside notes with file-based tasks for larger work. Both kinds move through the same workflows, with tables, filters, calendar planning, kanban boards, recurrence, pinned tasks and time tracking. Stable identity and an agent-friendly structure keep tasks consistent across views, links, metadata and automation.
