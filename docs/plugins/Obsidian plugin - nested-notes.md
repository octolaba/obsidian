# Nested Notes

Nested Notes arranges notes into hierarchies by dragging one note under another, so a vault can express nested tags, indexes or maps of content. Groups collapse and expand, and folders or non-Markdown files can be hidden so only the note structure remains visible.

```cue
plugin: {
    id:     "nested-notes"
    name:   "Nested Notes"
    author: "October"
    repo:   "october-learns/nested-notes"

    html_url:    "https://community.obsidian.md/plugins/nested-notes"
    github_url:  "https://github.com/october-learns/nested-notes"
    description: "Nest notes under other notes with drag-and-drop and collapse/expand. Also hides non-markdown files to focus on notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Organize notes into nested hierarchies with drag-and-drop to build nested tags, indexes, or maps of content. Collapse or expand groups and hide folders or non‑Markdown files to focus on your note structure."

    stats: {
        downloads:  272

    }
}
```
