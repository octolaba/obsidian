# Bulk Image to File Importer

The plugin imports images into the vault in bulk, either as individual files created from a template or appended to an existing note. Duplicate uploads are skipped by referencing an existing file with the same name instead of adding the image again.

```cue
plugin: {
    id:     "bulk-image-to-file-importer"
    name:   "Bulk Image to File Importer"
    author: "John McAnearney"
    repo:   "johnmcanearney/bulk-image-to-file-importer"

    html_url:    "https://community.obsidian.md/plugins/bulk-image-to-file-importer"
    github_url:  "https://github.com/johnmcanearney/bulk-image-to-file-importer"
    description: "Add images to a single file or create a new file for each image in bulk. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Import images in bulk into your vault as individual files, create new image files from a template, or append multiple images to an existing note. This tool skips duplicate uploads by referencing existing files with the same name to avoid re-adding images."

    stats: {
        downloads:  16
        updated_at: 1784664912000
    }
}
```
