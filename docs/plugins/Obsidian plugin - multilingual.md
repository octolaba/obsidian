# Multilingual

Translates note titles into several languages and writes the translations into the note's aliases, so a note can be linked from any of those languages. Translation runs when a note is created or renamed. Because the mechanism is Obsidian's own aliases, the recorded text states that links keep working if the plugin is removed.

```cue
plugin: {
    id:     "multilingual"
    name:   "Multilingual"
    author: "leolazou"
    repo:   "leolazou/obsidian-multilingual"

    html_url:    "https://community.obsidian.md/plugins/multilingual"
    github_url:  "https://github.com/leolazou/obsidian-multilingual"
    description: "Simplify linking notes across multiple languages by automatically adding translations of note names into aliases. Designed for multilingual users."
    about:       "Translate note titles into multiple languages and add translations to aliases for seamless cross-language linking. Auto-translate names on note creation or rename and preserve links by relying on Obsidian aliases so links remain functional if the plugin is removed."

    stats: {
        downloads:  2304
        updated_at: 1710878585000
    }
}
```
