# Context Workspaces

Context Workspaces builds focused working zones for individual tasks and switches between them from a sidebar of space icons. State is saved and restored automatically or through snapshots, each space can carry its own theme and mode, spaces can be reordered by drag-and-drop, and the plugin syncs with Obsidian's Workspace API.
