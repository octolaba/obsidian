# lilbee

lilbee indexes the vault, covering notes, PDFs, ebooks, code and scanned pages across more than 150 file types with OCR, and answers questions from that index with citations that click through to the exact source line, combining semantic and keyword search. It also manages local models itself, so that a catalog is browsed, a model pulled and run on the GPU with no separate app and no account, while existing Ollama or LM Studio installations appear in the same pickers. A built-in web crawler pulls a page or a whole docs site into the vault so that it can be cited offline. Its recorded inputs state that everything stays on the computer and that cloud models from OpenAI, Claude and Gemini are opt-in per role.
