# Korean Book Search

Fills the YAML frontmatter of a book note with Korean book metadata fetched from the Aladin Open API, based on the note title. The fields cover title, subtitle, author, publisher, ISBN, publication date, cover image and page count. Custom frontmatter fields can be added, defaults such as rating and reading status toggled, high-quality covers chosen, and the file renamed to match the book title.

```cue
plugin: {
    id:     "korean-book-search"
    name:   "Korean Book Search"
    author: "lazerfit"
    repo:   "lazerfit/korean-book-search"

    html_url:    "https://community.obsidian.md/plugins/korean-book-search"
    github_url:  "https://github.com/lazerfit/korean-book-search"
    description: "Automatically fills in YAML frontmatter with Korean book information from Aladin API based on the note title."
    about:       "Fill YAML frontmatter for Korean book notes by fetching metadata from the Aladin Open API, including title, subtitle, author, publisher, ISBN, publication date, cover image and page count. Add custom frontmatter fields, toggle defaults like rating and reading status, choose high-quality covers, and rename the file to match the book title."
```
