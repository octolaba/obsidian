# File Preview

File Preview shows preview text and inline images beneath each Markdown filename in the file explorer. Previews are toggled with a button in the explorer, and the view is refreshed to pick up newly created files.

```cue
plugin: {
    id:     "file-preview"
    name:   "File Preview"
    author: "xhuajin"
    repo:   "xhuajin/obsidian-file-preview"

    html_url:    "https://community.obsidian.md/plugins/file-preview"
    github_url:  "https://github.com/xhuajin/obsidian-file-preview"
    description: "Add file preview contents under file in file explorer."
    about:       "Display preview text and inline images beneath markdown filenames in the file explorer for at-a-glance reading. Toggle previews with the explorer button and refresh the view to include newly created files."

    stats: {
        downloads:  5086
        updated_at: 1736432125000
    }
}
```
