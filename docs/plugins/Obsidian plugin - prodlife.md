# ProdLife

Replaces the core Daily Notes workflow with nested date paths, per-weekday templates, and rollover that carries unfinished and nested tasks forward without flattening their structure. The vault is scanned for reminders, recurring tasks are managed, and old days archived. Progress is shown through streaks, achievements, and a 365-day heatmap, and the recorded description states that all data stays local.
