# Extensions-Activity

Extensions-Activity records how third-party community plugins are actually used, tracking commands, views and interactions over time. A searchable, sortable overview shows last-used times, seven-day totals, daily histories and per-plugin details, with automatic cleanup of old records. The recorded inputs state that all of this data stays in the vault.

```cue
plugin: {
    id:     "plugins-activity"
    name:   "Extensions-Activity"
    author: "Yunz93"
    repo:   "yunz93/obsidian-plugins-activity"

    html_url:    "https://community.obsidian.md/plugins/plugins-activity"
    github_url:  "https://github.com/yunz93/obsidian-plugins-activity"
    description: "Extensions-Activity helps you understand how you actually use third-party community extensions. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Track local usage of third-party plugins by recording commands, views, and interactions over time. View a searchable, sortable overview with last-used times, 7-day totals, daily histories, plugin details, and automatic cleanup, keeping all data stored only in your vault."

    stats: {
        downloads:  651
        updated_at: 1779933337000
    }
}
```
