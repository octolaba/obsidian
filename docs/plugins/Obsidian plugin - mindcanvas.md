# MindCanvas

MindCanvas creates zoomable, map-like mindmaps that pan and host linked notes, images and Excalidraw files with embedded previews. Semantic zoom shifts between structure and content, Markdown headings or backlinks can be imported to generate maps, and large graphs are navigated with a minimap, a mixed renderer and preview caching.
