# Book Smith

Book Smith manages book projects inside the vault with custom templates, covers and metadata. Chapters are organized in a draggable tree with live word counts and progress tracking, Pomodoro focus sessions, and citation management with automatic numbering. A finished manuscript can be exported in several formats.
