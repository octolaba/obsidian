# Financial Doc

Reads and edits CSV files inside Obsidian and uses them for financial documentation and tracking. Line, pie and radar charts are generated with Chart.js next to table reports built from the same CSV data. Custom models, splitting data by quarter or week, category and value-range analysis and chart resizing are available on desktop and mobile.
