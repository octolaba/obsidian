# Jira Issue managing

Jira Issue managing creates, updates and imports Jira issues from the command palette. Imported issue data lands in markdown files inside a jira-issues folder, and issues are created or updated from frontmatter fields such as summary, priority and key. Project and issue type are chosen through suggestion modals.

    id:     "jira-issue-managing"
