# Folders to Graph

Adds nodes for the vault's folders to the graph views, so the folder structure is displayed alongside the notes. Folder nodes combined with note links show the hierarchical context of how notes are organized.

```cue
plugin: {
    id:     "folders2graph"
    name:   "Folders to Graph"
    author: "ratibus11"
    repo:   "ratibus11/folders2graph"

    html_url:    "https://community.obsidian.md/plugins/folders2graph"
    github_url:  "https://github.com/ratibus11/folders2graph"
    description: "Display your vault folder structure into your graphs."
    about:       "Display your vault folder structure inside graph views, adding folder nodes to visualize how notes are organized. Combine folder nodes with note links to reveal hierarchical context across your vault."

    stats: {
        downloads:  21864
        updated_at: 1781310506000
    }
}
```
