# Hephaistos Importer

Hephaistos Importer imports Starfinder characters from the Hephaistos website by public identifier and writes one Markdown note per character with populated frontmatter such as name, abilities, race, classes and the Hephaistos link. An existing note has its frontmatter updated without its content being overwritten. Generated notes carry SRD-style hyperlinks and fields stated to be compatible with Javalent's Initiative Tracker and Fantasy Statblocks.

```cue
plugin: {
    id:     "hephaistos-importer"
    name:   "Hephaistos Importer"
    author: "runa-rist"
    repo:   "runa-rist/hephaistos-importer"

    html_url:    "https://community.obsidian.md/plugins/hephaistos-importer"
    github_url:  "https://github.com/runa-rist/hephaistos-importer"
    description: "Imports main stats from the Starfinder RPG character website Hephaistos."
    about:       "Import Starfinder characters from Hephaistos by public ID and generate a Markdown note per character with populated frontmatter (name, abilities, race, classes, hephaistos link, etc.). Update existing notes' frontmatter without overwriting content and create SRD-style hyperlinks plus fields compatible with Javalent's Initiative Tracker and Fantasy Statblocks."

    stats: {
        downloads:  385
        updated_at: 1768981067000
    }
}
```
