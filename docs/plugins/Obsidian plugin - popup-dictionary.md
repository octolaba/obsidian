# Popup Dictionary

Shows word definitions in a compact popup when text is selected or when a modifier key is held while hovering, and moving into the popup allows scrolling and following links. Definitions are fetched from Wiktionary across many languages, word boundaries are detected in scripts without spaces, and each entry links back to its source.

```cue
plugin: {
    id:     "popup-dictionary"
    name:   "Popup Dictionary"
    author: "Nikitas Tsiris"
    repo:   "ntsiris/obsidian-popup-dictionary"

    html_url:    "https://community.obsidian.md/plugins/popup-dictionary"
    github_url:  "https://github.com/ntsiris/obsidian-popup-dictionary"
    description: "Show word definitions in a popup when you select or Ctrl-hover a word, powered by Wiktionary across many languages. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Show word definitions in a compact popup by selecting text or holding a modifier key and hovering; move into the popup to scroll or follow links. Fetch definitions from Wiktionary across many languages, detect word boundaries in scripts without spaces, and link back to the source."

    stats: {
        downloads:  214
        updated_at: 1782074201000
    }
}
```
