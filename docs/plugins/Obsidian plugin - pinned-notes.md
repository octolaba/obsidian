# Pinned Notes

Pinned Notes places frequently used notes on the Obsidian ribbon in the left sidebar for one-click access. Each pin is configured with a display name, a file path and a lucide icon, which defaults to the file icon.

```cue
plugin: {
    id:     "pinned-notes"
    name:   "Pinned Notes"
    author: "vasilcoin002"
    repo:   "vasilcoin002/pinned-notes-plugin-obsidian"

    html_url:    "https://community.obsidian.md/plugins/pinned-notes"
    github_url:  "https://github.com/vasilcoin002/pinned-notes-plugin-obsidian"
    description: "Pin frequently-used notes on Ribbon actions (left sidebar)"
    about:       "Pin frequently used notes to the Obsidian ribbon for one-click access. Configure each pin with a display name, file path, and a lucide icon (defaults to \"file\")."

        downloads:  6463

    }
}
```
