# Character Sheets

Character Sheets creates and manages character sheets inside Obsidian. It generates prefilled templates in a Characters folder, whose fields for background, stats, inventory and notes are then edited into full character profiles.

    id:     "character-sheets"
    name:   "Character Sheets"
