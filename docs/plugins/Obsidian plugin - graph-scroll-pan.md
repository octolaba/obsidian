# Graph Scroll Pan

Makes scrolling, or a two-finger trackpad swipe, pan the graph view instead of zooming, which the description presents as a change aimed at trackpad users. Zoom stays centred on the cursor and is triggered by pinch or by Cmd or Ctrl with scroll, with optional plus and minus buttons. Both the global and local graph views are covered.
