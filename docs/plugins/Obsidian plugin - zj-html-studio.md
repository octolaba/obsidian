# ZJ HTML Studio

ZJ HTML Studio opens local .html and .htm files in native Obsidian tabs without rewriting them, previewing scoped local images, styles, scripts, fonts and media. It offers a safe read-only mode and a trusted compatibility mode, source inspection, zoom, in-page search, reload of affected previews, diagnosis of missing resources, and short-lived browser sessions. HTML can also be embedded in Markdown at a chosen width and height. The plugin is desktop only and states that it carries no telemetry and no developer-operated service.
