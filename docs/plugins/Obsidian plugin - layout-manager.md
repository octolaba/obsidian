# Layout Manager

Layout Manager restores a saved Obsidian layout according to the file being opened, covering splits with their direction and ratios, file groupings, editor mode, tab order and non-file views. A layout is saved from a single file and matched against files by glob pattern, then loaded ad-hoc or automatically on open, and can be restricted to specific platforms.
