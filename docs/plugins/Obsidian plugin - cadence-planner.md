# Cadence

Cadence unifies CRM, PRM, project management, daily planning and reminders in a single Obsidian tab built on plain Markdown. It offers Home, Today, Pipeline, Contacts, Projects, Inbox and Reports views, and keeps tasks, deals and contacts as .md files with frontmatter. Reports and CSV import are included, and the inputs state that no server or sync service is required.
