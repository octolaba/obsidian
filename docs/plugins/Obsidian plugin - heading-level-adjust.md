# Heading Level Adjust

Heading Level Adjust promotes, demotes or shifts Markdown heading levels by a custom delta in a selection, the current line or the whole document, and prevents levels beyond the first and sixth. It also cleans notes by removing horizontal rules and collapsing repeated blank lines. Adjustment and cleaning can be applied together as one command over a selection or a whole file.

```cue
plugin: {
    id:     "heading-level-adjust"
    name:   "Heading Level Adjust"
    author: "obcdian"
    repo:   "obcdian/obsidian-heading-level-adjust"

    html_url:    "https://community.obsidian.md/plugins/heading-level-adjust"
    github_url:  "https://github.com/obcdian/obsidian-heading-level-adjust"
    description: "Adjust Markdown heading levels and clean up dividers/empty lines in selected text or the entire document. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Adjust Markdown heading levels in a selection or current line with promote, demote, or a custom delta while preventing levels below # or above ######. Clean notes by removing horizontal rules and collapsing multiple blank lines, and apply adjustment+clean as a single command to a selection or whole file."

    stats: {
        downloads:  194
        updated_at: 1776656067000
    }
}
```
