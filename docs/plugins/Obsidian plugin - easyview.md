# EasyView

Controls view settings from the status bar, a right-click menu, the ribbon or hotkeys: global font size, the light or dark theme, and switching between Source, Live Preview and Reading view. The same controls are reachable on mobile through a navigation shortcut, and Focus and Zen modes hide sidebars and interface chrome for distraction-free writing.
