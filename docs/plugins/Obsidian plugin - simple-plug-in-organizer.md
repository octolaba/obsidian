# Simple Plug-in Organizer

Simple Plug-in Organizer gathers core and community plug-ins into one unified settings page. Plugins can be grouped and categorized, groups given colors, and the whole set managed from a single consolidated list.

```cue
plugin: {
    id:     "simple-plug-in-organizer"
    name:   "Simple Plug-in Organizer"
    author: "October"
    repo:   "october-learns/obsidian-plug-in-organizer"

    html_url:    "https://community.obsidian.md/plugins/simple-plug-in-organizer"
    github_url:  "https://github.com/october-learns/obsidian-plug-in-organizer"
    description: "Group and organize your core and community plug-ins together in one unified settings page. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Organize core and community plugins from a single settings page. Group and categorize plugins, assign colors to groups, and manage them in one consolidated list."

    stats: {
        downloads:  141
```
