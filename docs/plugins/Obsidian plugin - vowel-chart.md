# Vowel Chart

Vowel Chart generates IPA-style vowel diagrams inline from a code block, showing a language's vowel inventory. Vowels are positioned by coordinates, by IPA brackets or by keywords, and the layout can be a trapezoid or a triangle.

```cue
plugin: {
    id:     "vowel-chart"
    name:   "Vowel Chart"
    author: "maplekarine"
    repo:   "maplekarine/obsidian-vowel-chart"

    html_url:    "https://community.obsidian.md/plugins/vowel-chart"
    github_url:  "https://github.com/maplekarine/obsidian-vowel-chart"
    description: "Generate IPA style vowel diagrams. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Generate a vowel diagram to display a language's vowel inventory inline in notes. Position vowels using a code block. Add vowels by coordinates, IPA brackets, or keywords. Choose trapezoid or triangle layouts."

    stats: {
        downloads:  254
        updated_at: 1778948437000
    }
}
```
