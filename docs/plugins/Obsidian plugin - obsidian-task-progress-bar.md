# Task Genius

The plugin turns the vault into a task manager with list, kanban, calendar and Gantt views. Recurring tasks, multi-stage workflows, habits and priorities are handled through quick capture, advanced filters and saved queries. Progress is followed with progress bars, task status cycling and gamified milestone achievements.
