# Emotion Book

Records emotions inside daily notes through a block that combines an emotion selector, a text field and timestamped entries collected under a collapsible section. The day's average is calculated automatically and written to frontmatter so Dataview can query it, and emotion labels, colours and numeric weights are configurable.
