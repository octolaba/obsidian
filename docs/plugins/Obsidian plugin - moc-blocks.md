# MOC Blocks

MOC Blocks builds interactive Maps of Content by attaching clickable marker and area links to an image. Markers can be added and edited, polylines drawn and marker styles customized. Marker locations and their links are saved in per-MOC files so that the maps stay persistent and editable.

    id:     "moc-blocks"
    name:   "MOC Blocks"
    author: "nebulousnessie"
