# Lemon Comments

Lemon Comments attaches Markdown comments to text selected in Reading view, through a mini toolbar that opens on selection. Commented text is marked with lemon-green rounded highlights that show a popup on hover and open an editor on click. The comments are held in the plugin's own data, so that the notes themselves remain unchanged.

```cue
plugin: {
    id:     "lemon-comments"
    name:   "Lemon Comments"
    author: "blackflag0623"
    repo:   "blackflag0623/obsidian-lemon-comments"

    html_url:    "https://community.obsidian.md/plugins/lemon-comments"
    github_url:  "https://github.com/blackflag0623/obsidian-lemon-comments"
    description: "Add Markdown comments to selected text in Reading view. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add lightweight, non-intrusive Markdown comments to Reading view. Select text to open a mini toolbar, attach Markdown comments, and highlight with lemon-green rounded marks that show popups on hover or open an editor on click. Store comments in plugin data so notes remain unchanged."

    stats: {
        downloads:  54
        updated_at: 1783845741000
    }
}
```
