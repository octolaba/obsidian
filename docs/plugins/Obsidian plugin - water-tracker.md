# Water Tracker

Water Tracker logs drinks from a command or a ribbon icon and totals daily water intake using cup sizes you define. Totals or detailed logs are written to the current file or to the daily file. A DataviewJS snippet summarizes the entries with counts and total millilitres.

```cue
plugin: {
    id:     "water-tracker"
    name:   "Water Tracker"
    author: "luigicerone"
    repo:   "luigicerone/obsidian-water-tracker"

    html_url:    "https://community.obsidian.md/plugins/water-tracker"
    github_url:  "https://github.com/luigicerone/obsidian-water-tracker"
    description: "Keep track of how much water you drunk"
    about:       "Log drinks with a command or ribbon icon and track daily water intake using customizable cup sizes. Save totals or detailed logs to the current or daily file and summarize entries with DataviewJS to show counts and total milliliters."

    stats: {
        downloads:  389
        updated_at: 1746039022000
    }
}
```
