# Mind map editor

Mind map editor presents an outline as a live mind map, converting headings and bullets into nodes and syncing edits back into the original Markdown with no extra markup or file format. Nodes can be renamed, added, deleted and dragged, checkboxes toggled, and checked tasks collapsed into summary pills. Wikilinks can be followed from the map and branches coloured.
