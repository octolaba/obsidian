# CSV Editor

Opens CSV files in a spreadsheet-like table inside Obsidian for viewing and editing. Edits save automatically, headers are set per file, and cells can be edited with a Markdown preview. Columns can be sorted, filtered and frozen, and rows or columns inserted.
