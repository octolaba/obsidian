# Word Count Heatmap

Displays daily writing activity as a GitHub-style heatmap of word or character counts over a chosen date range. A single day can be inspected to see what each file gained. Colour thresholds, folder exclusions and the choice between the word and character metric are configurable, and the interface is available in English and Chinese.

```cue
plugin: {
    id:     "word-count-heatmap"
    name:   "Word Count Heatmap"
    author: "Aluxes"
    repo:   "ashenashes/word-count-heatmap"

    html_url:    "https://community.obsidian.md/plugins/word-count-heatmap"
    github_url:  "https://github.com/ashenashes/word-count-heatmap"
    description: "Visualizes your daily writing productivity with GitHub-style word count heatmaps. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Visualize daily writing activity with a GitHub-style heatmap that displays word or character counts across custom date ranges. Inspect any day to view per-file additions, set color thresholds and folder exclusions, and pick word or character metrics with English/Chinese UI."

    stats: {
        downloads:  9
        updated_at: 1784692991000
    }
}
```
