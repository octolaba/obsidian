# markdown to card

markdown to card renders the active Markdown note into exportable image cards for social platforms, with a live multi-page preview, controlled typography and customizable backgrounds. Pagination follows the real card height so content is not clipped, and images, Mermaid diagrams, code and LaTeX survive the conversion. Tall portrait images are promoted to full cards, and clicking a card scrolls to its place in the source. The recorded description is in Chinese and names Xiaohongshu, Douyin and Bilibili as target platforms, along with AI-assisted rewriting of the text.
