# Desmos

Desmos embeds Desmos graphs into notes through desmos-graph code blocks, with offline support. Several LaTeX equations can be written per block, bounds, dimensions, grid and trig mode set, and per-equation style, colour and restrictions applied.

```cue
plugin: {
    id:     "obsidian-desmos"
    name:   "Desmos"
    author: "nigecat"
    repo:   "nigecat/obsidian-desmos"

    html_url:    "https://community.obsidian.md/plugins/obsidian-desmos"
    github_url:  "https://github.com/nigecat/obsidian-desmos"
```
