# Transcode

Transcode encodes and decodes text inline using the Atbash, Base16, Base64, Base85 and ROT13 algorithms. Conversions are triggered by Markdown keywords, and the code block is replaced by the encoded or decoded result directly in the note.

```cue

    id:     "coder"
    name:   "Transcode"
    author: "rudimuc"
    repo:   "rudimuc/obsidian-coder"
```
