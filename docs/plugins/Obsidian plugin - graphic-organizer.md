# Graphic Organizer

Shows the vault's file hierarchy as an interactive vertical tree, with distinctive icons for folders and files, drag-and-drop reorganization, and right-click menus to open, create or delete items. Large vaults are handled with lazy loading, real-time updates, zoom and pan controls, drop-target feedback and warnings for large folders.
