# Smooth Cursor

Cursor movement is animated, with an optional trail that visualizes the motion. Color and speed of the cursor and its trail are set in the settings or through CSS. The recorded inputs warn that behaviour differs in Vim mode and when editing complex table cells.

plugin: {
    id:     "smooth-cursor"
    name:   "Smooth Cursor"
    author: "busyogg"
    repo:   "busyogg/SmoothCursor"
