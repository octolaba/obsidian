# Todoist Board

Todoist Board manages Todoist tasks inside Obsidian as interactive boards, opened in the sidebar or embedded as filtered task views in a note, with two-way sync. Tasks can be filtered by project, priority, due date or a custom Todoist query, and added, edited, scheduled, moved, completed or deleted from the board. Parent tasks and subtasks are shown with collapse controls.
