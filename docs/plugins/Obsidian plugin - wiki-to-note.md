# Wiki To Note

Fetches a Wikipedia article and generates a Markdown note from it for offline reading, editing and linking. The conversion is deliberately simple and aimed at quick captures rather than at exact replicas of the source page.

```cue
plugin: {
    id:     "wiki-to-note"
    name:   "Wiki To Note"
    author: "Johannes Hans"
    repo:   "commandjoo/WikiToNote"

    html_url:    "https://community.obsidian.md/plugins/wiki-to-note"
    github_url:  "https://github.com/commandjoo/WikiToNote"
    description: "Generate a Note from a Wikipedia article. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Import Wikipedia articles into Obsidian as Markdown notes for offline reading, editing, and linking. Keep conversions simple — ideal for quick captures rather than exact replicas."

    stats: {
        downloads:  252
        updated_at: 1782757281000
    }
}
```
