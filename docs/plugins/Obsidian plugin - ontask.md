# OnTask

OnTask is a bullet journal-inspired task manager that collects tasks from across the vault and filters them by priority, tag or file. A Top Task is set and its appearance personalized to keep attention on one item, and a day plan can be created automatically from the collected tasks. It also syncs with Streams for task flow.
