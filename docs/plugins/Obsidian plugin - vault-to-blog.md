# Vault to blog

Publishes a selected vault folder to a GitHub Pages blog, pushing only that directory's contents to a public GitHub Pages repository. The published site uses an Obsidian-style layout with a left sidebar and file explorer, home routing, a draggable sidebar, keyword and tag search, and a basic Markdown view.

plugin: {
    id:     "vault-to-blog"
    name:   "Vault to blog"
    author: "barkstone2"
    repo:   "barkstone2/vault-to-blog"

    html_url:    "https://community.obsidian.md/plugins/vault-to-blog"
