# Mermaid Canvas

Turns each mermaid code block into an interactive, resizable SVG canvas with zoom, pan, fullscreen, copy-source and delete controls. A built-in split editor edits the diagram source beside a live preview. Invalid or empty blocks are skipped without raising errors.
