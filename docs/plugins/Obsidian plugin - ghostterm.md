# GhostTerm

Opens Ghostty-style terminal surfaces in Obsidian's sidebar or main workspace so a shell runs alongside the notes. Terminal tabs and splits can be created, working-directory context is preserved from the file explorer, and terminal shortcuts are intercepted only while the terminal is focused. Ghostty font, color, cursor and shell settings are read, and terminal title, current working directory and OSC 8 hyperlinks are tracked.
