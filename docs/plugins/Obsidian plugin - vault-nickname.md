# Vault Nickname

Overrides the display name of a vault without renaming its folder, which the recorded description frames as a way to tell apart vaults sharing a folder name across projects. The application title can show the vault name before the document or the document before the vault, and a change-nickname option is added to the vault switcher.

```cue
plugin: {
    id:     "vault-nickname"
    name:   "Vault Nickname"
    author: "rscopic"
    repo:   "rscopic/obsidian-vault-nickname"

    html_url:    "https://community.obsidian.md/plugins/vault-nickname"
    github_url:  "https://github.com/rscopic/obsidian-vault-nickname"
    description: "Override the vault's display name. Intended to disambiguate vaults with the same folder name when adhering to a common folder structure between projects."
    about:       "Set a custom display name for a vault without renaming its folder. Choose whether the app title shows the vault name before the document or the document before the vault. Add a quick change-nickname option to the vault switcher to disambiguate vaults with identical folder names."

    stats: {
        downloads:  2544
        updated_at: 1779340414000
    }
}
```
