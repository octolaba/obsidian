# Tablite

Edits CSV and TSV files in the vault through a table editor with inline cell editing, virtual scrolling for large files, and undo and redo history. Columns are sorted, filtered, hidden, reordered, frozen and resized, and a search runs across all cells. Delimiters, encodings and header rows are detected automatically, and export is Excel-compatible.
