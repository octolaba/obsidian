# Reading progress desktop

Shows reading progress for the current view in the status bar on desktop, as a horizontal progress bar with a view-type indicator and a full-screen button. Markdown, PDF, search, thino, and bases views are supported; for unsupported or infinite-scroll views the bar is drawn inactive in gray.
