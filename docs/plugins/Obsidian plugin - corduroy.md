# Corduroy

Corduroy searches for a place through live Google Places autocomplete and inserts its coordinates and formatted address into the current note's frontmatter. Latitude and longitude are written as a coordinates list compatible with map plugins, so the note appears on a map immediately.

```cue
plugin: {
    id:     "corduroy"
    name:   "Corduroy"
    author: "Gabby Welson"
    repo:   "gabbywelson/obsidian-corduroy"

    html_url:    "https://community.obsidian.md/plugins/corduroy"
    github_url:  "https://github.com/gabbywelson/obsidian-corduroy"
    description: "Search Google Maps and insert place coordinates into note frontmatter. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Search for a place and insert its coordinates and formatted address directly into the current note's frontmatter. Write latitude/longitude as a coordinates list compatible with map plugins so notes appear on maps immediately using live Google Places autocomplete."

    stats: {
        downloads:  109
        updated_at: 1780317470000
    }
}
```
