# NyanBar

Generates an animated Nyan Cat progress bar in a note to show how far a set of tasks has come. The bar is inserted with /nyan or /pusheen, given a value between 0 and 100 or set to auto, and in auto mode it tracks checked checkboxes and updates as they change.

```cue
plugin: {
    id:     "nyanbar"
    name:   "NyanBar"
    author: "xhyabunny"
    repo:   "xhyabunny/nyanbar"

    html_url:    "https://community.obsidian.md/plugins/nyanbar"
    github_url:  "https://github.com/xhyabunny/nyanbar"
    description: "Nyan Cat Progress Bar generator!"
    about:       "Add an animated Nyan Cat progress bar to notes to visualize task completion. Use /nyan or /pusheen with a value 0–100 or set auto to track checked checkboxes, with automatic updates as tasks change."

        updated_at: 1758570937000
    }
}
```
