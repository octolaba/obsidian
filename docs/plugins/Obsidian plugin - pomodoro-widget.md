# Pomodoro Widget

Provides a pomodoro widget modelled on a wind-up kitchen timer, with a constant ticking sound and an alarm sound that can be toggled. The timer is wound manually or set by button and resets itself, a stopwatch is available, and the widget can be dragged and anchored to window corners for resizing. Its toggle sits in the ribbon, in the status bar, or as a command, and its styling follows the active theme.
