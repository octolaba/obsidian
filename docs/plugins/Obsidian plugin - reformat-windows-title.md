# Reformat Windows Title

Customizes the Obsidian window title by reordering the vault name and the file name. The recorded text gives the motivation: with several vaults open, putting the vault name first makes the right window easier to identify on the Windows taskbar.

```cue
plugin: {
    id:     "reformat-windows-title"
    name:   "Reformat Windows Title"
    author: "zhao414"
    repo:   "zhao414/obsidian-reformat-windows-title"

    html_url:    "https://community.obsidian.md/plugins/reformat-windows-title"
    github_url:  "https://github.com/zhao414/obsidian-reformat-windows-title"
    description: "Customize the window title format by reordering vault name and file name. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Reformat Windows Title lets you customize how the Obsidian window title appears on the Windows taskbar. When multiple vaults are open, putting the vault name first makes it easier to identify the right window at a glance."
}
```
