# Linear Year Map

Plots notes on a continuous twelve-month horizontal timeline built from frontmatter dates, so the flow and clustering of notes across a year is visible in one view. Categories can be color-coded and filtered, the map refreshes as notes are edited, and clicking an event opens its note. The recorded inputs attribute the linear calendar concept to Nick Milo.
