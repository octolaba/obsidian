# SQLite Explorer

SQLite databases stored in the vault are browsed in a desktop-only view that opens the file, lists its user tables, shows schemas and previews rows. Read-only SQL queries are run and their results copied as Markdown or exported as CSV. A fenced sqlite-query block embeds a live query in a note as a table, a list or a single value, and a result can be frozen into a static Markdown snapshot.

```cue

    id:     "sqlite-explorer"

    about:       "Browse SQLite databases stored in your vault with a desktop-only browser view. Open .sqlite/.sqlite3/.db files, inspect schemas, run read-only SQL queries, and copy results as Markdown or export CSV. Embed live sqlite-query fenced blocks in notes with table, list, or value displays and freeze results as static Markdown snapshots."
```
