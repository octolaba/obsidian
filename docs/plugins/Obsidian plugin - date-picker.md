# Date Picker

Picks dates from an inline calendar view. A calendar icon next to a date link opens the visual picker, and the plugin states that it is customizable.

```cue
plugin: {
    id:     "date-picker"
    name:   "Date Picker"
    author: "rzbin"
    repo:   "rzbin/date-picker"

    html_url:    "https://community.obsidian.md/plugins/date-picker"
    github_url:  "https://github.com/rzbin/date-picker"
    description: "Pick dates using a calendar view. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Pick dates with an inline calendar view and open a visual date picker from the calendar icon next to date links. Easy to use, with proper customization."

    stats: {
        downloads:  238
        updated_at: 1781588343000
    }
}
```
