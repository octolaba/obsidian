# Canvas Bases

Canvas Bases turns a live Bases view into a spatial Canvas board of draggable, resizable file cards with group frames, relationship edges, assignment zones and inline card editing. Board layout, colors, manual cards and groups and edges are persisted, and .canvas snapshots can be exported or updated. It integrates with TaskNotes when that plugin is available.
