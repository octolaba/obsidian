# VaultAI

Adds a floating chat interface backed by Google's Gemini models for writing assistance, content generation and note enhancement. Vault-wide semantic search grounds answers in the user's own notes and returns citations, a response can be inserted at the cursor, and reusable prompts accept placeholders. The recorded About states that the API key and the chat history stay local.
