# Garmin Health Sync

Syncs Garmin Connect health data such as steps, sleep, heart rate, stress and activities into Daily Notes as frontmatter properties that Dataview can query. Date ranges can be backfilled and recent days synced automatically, human-readable workout summaries and optional machine-readable training fields are added, and note content is left untouched. The recorded text states that it is desktop only.

plugin: {
    id:     "garmin-health-sync"
    name:   "Garmin Health Sync"
    author: "fcandi"

Backfill date ranges, auto-sync recent days, and add human-readable workout summaries plus optional machine-readable training fields while leaving note content untouched (desktop only)."
