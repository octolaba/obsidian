# Sync Graph Settings

Copies the global graph color groups onto the active local graph with a single command. The recorded inputs state that this keeps local graph node colors and groupings identical to the global graph settings.

```cue
plugin: {
    id:     "sync-graph-settings"
    name:   "Sync Graph Settings"
    author: "xallt"
    repo:   "xallt/sync-graph-settings"

    html_url:    "https://community.obsidian.md/plugins/sync-graph-settings"
    github_url:  "https://github.com/xallt/sync-graph-settings"
    description: "Sync global graph settings (like color groups) to local graphs."
    about:       "Sync Global Graph Color Groups to the active Local Graph with a single command. Keep local graph node colors and groupings identical to your Global Graph settings for consistent visualization."
```
