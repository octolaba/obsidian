# Archivist Importer

Imports selected vault files into campaigns on the Archivist service. The API key is kept in Secret Storage, and files are sent from the left-ribbon upload button or the command palette.

```cue
plugin: {
    id:     "archivist-importer"
    name:   "Archivist Importer"
    author: "archivistai"
    repo:   "archivistai/archivist-obsidian-importer"

    html_url:    "https://community.obsidian.md/plugins/archivist-importer"
    github_url:  "https://github.com/archivistai/archivist-obsidian-importer"
    description: "Import selected vault files into Archivist campaigns."
    about:       "Import selected Obsidian vault files directly into Archivist campaigns. Store your Archivist API key in Secret Storage and use the left-ribbon upload button or Command Palette to send selected notes to your campaigns."

    stats: {
        downloads:  1831

    }
}
```
