# Icon Board

Icon Board is a visual workspace holding icon tiles, kanban columns, sticky notes, checklists, images, audio, bookmarks and note links on a freeform canvas, all stored in a single iboard file in the vault. Cards are arranged and connected through drag-and-drop, multi-select, resizing and styled connectors.
