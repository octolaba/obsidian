# Number Headings

Numbers and re-numbers headings in a document with outline-style numbering such as 1.1.2, and can remove the numbering again. The numbering settings are saved into the note's front matter, and front-matter rules also skip particular files and select Roman numerals or alternate separators.

```cue
plugin: {
    id:     "number-headings-obsidian"
    name:   "Number Headings"
    author: "onlyafly"
    repo:   "onlyafly/number-headings-obsidian"

    html_url:    "https://community.obsidian.md/plugins/number-headings-obsidian"
    github_url:  "https://github.com/onlyafly/number-headings-obsidian"
    description: "Automatically number or re-number headings."
    about:       "Number headings with outline-style numbering (e.g., 1.1.2). Add or remove numbering across a document and save numbering settings to a note's front matter. Use front-matter rules to skip files and choose Roman numerals or alternate separators."

    stats: {
        downloads:  87562
        updated_at: 1696337257000
    }
}
```
