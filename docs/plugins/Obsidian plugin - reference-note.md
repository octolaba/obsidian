# Reference Note

Creates a new note by cloning selected frontmatter properties from an existing note, using that note as a template. Which keys are carried over, the target folder, and the name are chosen at creation, and a source link property can optionally be added to point back to the original.

```cue
plugin: {
    id:     "reference-note"
    name:   "Reference Note"
    author: "Rafael Mehdiyev"
    repo:   "rafaelmehdiyev/obsidian-reference-note"

    html_url:    "https://community.obsidian.md/plugins/reference-note"
    github_url:  "https://github.com/rafaelmehdiyev/obsidian-reference-note"
    description: "Create new notes by cloning properties from any existing note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create new notes by cloning selected frontmatter and properties from any existing note to use as a template. Choose which keys to carry, set the target folder and name, and optionally add a source link property to reference the original."

    stats: {
        downloads:  115
        updated_at: 1779735987000
    }
}
```
