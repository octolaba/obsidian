# Review

Review adds a link to the current note into a daily note on a future or past date, scheduling a review on that day. The target day's note gets a Review section created or appended, with the link written as a prefixed line or block. Dates can be given in natural language through the Natural Language Dates plugin.

```cue
plugin: {
    id:     "review-obsidian"
    name:   "Review"
    author: "ryanjamurphy"
    repo:   "ryanjamurphy/review-obsidian"

    html_url:    "https://community.obsidian.md/plugins/review-obsidian"
    github_url:  "https://github.com/ryanjamurphy/review-obsidian"
    description: "Add a link to the current note to a daily note on a future date (or a past date, you time traveller)."
    about:       "Add the current note to a future or past daily note to schedule a review on that date. Create or append a Review section on the target day's note with a prefixed line or block, using natural language dates via the Natural Language Dates plugin."

    stats: {
        downloads:  64083
        updated_at: 1733855965000
    }
}
```
