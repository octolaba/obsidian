# Jisage

Jisage renders jisage indentation, a full-width space at the beginning of a line, so indented Japanese text displays correctly in preview. The plugin records an application limitation: after adding or removing a leading full-width space, the file has to be reopened before the edit appears.

```cue
plugin: {
    id:     "jisage-japanese-indentation"
    name:   "Jisage"
    author: "telehakke"
    repo:   "telehakke/jisage-japanese-indentation"

    html_url:    "https://community.obsidian.md/plugins/jisage-japanese-indentation"
    github_url:  "https://github.com/telehakke/jisage-japanese-indentation"
    description: "Display 'Jisage' (indenting with a full-width space at the beginning of a line) text correctly."
    about:       "Render Japanese jisage indentation created with a full-width leading space so indented lines display properly in preview. Reopen the file after adding or removing leading full-width spaces to make edits appear due to an Obsidian application limitation."

    stats: {
        downloads:  3820
        updated_at: 1779897629000
    }
}
```
