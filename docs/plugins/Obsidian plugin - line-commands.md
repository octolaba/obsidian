# Line Commands

Adds commands that act on whole lines or the current selection: select, copy, cut, duplicate, and paste. Lines can be pasted above or below the cursor and cut without being selected first, which the recorded inputs present as faster line editing on mobile and desktop.

    id:     "line-commands"
    name:   "Line Commands"
    author: "charliecm"
    repo:   "charliecm/obsidian-line-commands"

    github_url:  "https://github.com/charliecm/obsidian-line-commands"
