# Kanban

The plugin renders Markdown files as Kanban boards. Columns and cards are stored as plain Markdown in the vault, so board content stays editable and linkable like any other note.

```cue
plugin: {
    id:     "obsidian-kanban"
    name:   "Kanban"
    author: "obsidian-community"
    repo:   "obsidian-community/obsidian-kanban"

    html_url:    "https://community.obsidian.md/plugins/obsidian-kanban"
    github_url:  "https://github.com/obsidian-community/obsidian-kanban"
    description: "Create Markdown-backed Kanban boards."
    about:       "Create markdown-backed Kanban boards inside Obsidian. Organize notes into draggable columns and cards stored as plain Markdown in your vault, keeping board content editable and linkable like regular notes."

    stats: {
        downloads:  2460199
        updated_at: 1717117708000
    }
}
```
