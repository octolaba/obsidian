# Material Symbols

Material Symbols inserts Google's outlined Material Symbols into notes as inline HTML spans carrying the mso class. Commands insert the span in a double-quoted or single-quoted form, after which the icon name is typed inside it to render the symbol. Weight and grade classes such as weight400 and grade200 adjust its appearance.

```cue
plugin: {
    id:     "material-symbols"
    name:   "Material Symbols"
    author: "cberane"
    repo:   "cberane/obsidian-material-symbols"

    html_url:    "https://community.obsidian.md/plugins/material-symbols"
    github_url:  "https://github.com/cberane/obsidian-material-symbols"
    description: "Add Google's Material Symbols (outlined)."
    about:       "Insert Google's Material Symbols (outlined) as inline HTML spans into notes. Add symbols via commands that insert <span class=\"mso\"></span> or a single-quoted <span class='mso'></span>, then type the icon name to render. Apply weight and grade classes (e.g. weight400, grade200) to adjust appearance."

    stats: {
        downloads:  4771
        updated_at: 1772135829000
    }
}
```
