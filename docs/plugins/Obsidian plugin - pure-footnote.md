# Pure Footnote

Manages Markdown footnotes and custom inline hover notes in a dedicated sidebar outline. Entries are jumped to and highlighted according to cursor position, then edited inline through a draggable popup for renaming and content changes. A cleaner visual style is toggled and entries sorted from the context menu.
