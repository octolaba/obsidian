# QuickClip Capture Manager

Renders the clips saved by the QuickClip Capture browser extension as reading-view cards, covering highlights, full pages, tweets, PDFs, videos with timestamp chips, and images. A Clip Manager browses and filters the clips, edits tags and notes inline, opens the source file at the clip, and deletes entries.
