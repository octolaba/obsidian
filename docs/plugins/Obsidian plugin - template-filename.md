# Template Filename

Template Filename creates notes whose filenames are themselves templated, using date and time tokens, random strings, UUIDs, counters, hashes, Unix timestamps and custom numeral bases. Filenames are previewed live, and global or named counters, system variables and text-formatting utilities support sequential or unique naming.
