# Floating Search

Opens the default Obsidian search view inside a floating modal that searches globally or within the current file. A hotkey opens it, and the search either keeps its last state or clears itself. Results are previewed in a side pane, opened in the background or in a new window, and the input and the preview are moved between without closing the popup.
