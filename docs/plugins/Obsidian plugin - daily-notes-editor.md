# Daily Notes Editor

Edits multiple daily notes inline on a single page, in the manner of the default daily note view of Roam Research. Notes can be filtered by time range covering week, month, quarter, year or a custom span, viewed in Daily, Folder or Tag mode, sorted by creation or modification time, and saved as presets.

    id:     "daily-notes-editor"
    name:   "Daily Notes Editor"
    author: "quorafind"

    github_url:  "https://github.com/quorafind/Obsidian-Daily-Notes-Editor"
