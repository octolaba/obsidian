# Maps

Maps adds a map layout to Obsidian Bases so notes can be displayed as an interactive, browsable map view. Markers are dynamic and follow the active filters, and their icons and colors come from note properties. Custom background tiles can be loaded and default zoom options set.

    id:     "maps"
    name:   "Maps"
    author: "Obsidian"
    repo:   "obsidianmd/obsidian-maps"
