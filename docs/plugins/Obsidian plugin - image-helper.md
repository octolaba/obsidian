# Image Helper

Image Helper adds a context-menu entry on images in reading view that converts the image to JPEG, WebP or PNG. The target format is chosen directly from that preview context menu.

```cue
plugin: {
    id:     "image-helper"
    name:   "Image Helper"
    author: "byfun"
    repo:   "byfun/obsidian-image-helper"

    html_url:    "https://community.obsidian.md/plugins/image-helper"
    github_url:  "https://github.com/byfun/obsidian-image-helper"
    description: "Context menu to convert image format in reading view."
    about:       "Open an image's context menu in reading view to convert it to JPEG, WebP, or PNG. Select a format to convert images directly from the preview context menu."

    stats: {
        downloads:  2342
        updated_at: 1702346844000
    }
}
```
