# Embedded Code Title

Embeds a title into code blocks so that a language name or a filename is displayed above the fenced code. Filenames containing spaces are rendered escaped, and the same titles can be published on Obsidian Publish sites using the supplied publish.js and publish.css.

```cue
plugin: {
    id:     "obsidian-embedded-code-title"
    name:   "Embedded Code Title"
    author: "tadashi-aikawa"
    repo:   "tadashi-aikawa/obsidian-embedded-code-title"

    html_url:    "https://community.obsidian.md/plugins/obsidian-embedded-code-title"
    github_url:  "https://github.com/tadashi-aikawa/obsidian-embedded-code-title"
    description: "Embed a title in code blocks."
    about:       "Embed titles into code blocks to display language names or filenames above fenced code. Render filenames with escaped spaces and publish those titles on Obsidian Publish sites using supplied publish.js and publish.css."

    stats: {
        downloads:  16000
        updated_at: 1666315274000
    }
}
```
