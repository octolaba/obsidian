# WOL Reference Tools

Looks up Bible verses and references from wol.jw.org and inserts them into notes inline, in a modal or popover, or in a sidebar panel. A reference wrapped in double exclamation marks becomes a clickable link, and adding a greater-than sign after them renders the full verse inline. The sidebar lists every reference found in the active note.

    id:     "wol-reference-viewer"
