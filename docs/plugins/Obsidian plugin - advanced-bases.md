# Advanced Bases

Advanced Bases adds three Notion-style views to Obsidian Bases: Cards Compact, Feed and Timeline. Cards Compact shows compact card rows, Feed lazily renders Markdown previews with truncation and expanders, and Timeline plots notes by date on grouped, color-coded lanes with zoom and pan. It is described as a lighter build carrying only these core views.
