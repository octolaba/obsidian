# csvzall

Opens and edits .csv files in an embedded, editable table by connecting to a local csvzall helper, whose binary the plugin installs or updates with verified downloads. New CSV files can be created from folder menus, and charts are regenerated and Markdown tables exported when a CSV changes.

```cue
plugin: {
    id:     "csvzall"
    name:   "csvzall"
    author: "Vincent La"
    repo:   "vincentlaucsb/obsidian-csvzall"

    html_url:    "https://community.obsidian.md/plugins/csvzall"
    github_url:  "https://github.com/vincentlaucsb/obsidian-csvzall"
```
