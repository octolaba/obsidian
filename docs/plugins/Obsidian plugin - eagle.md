# Eagle Integration

Sends images pasted into a note to Eagle and renders them from a local cache, so the image files stay out of the vault. The Eagle library can be searched and images inserted with thumbnails, with deduplication, folder mapping and Canvas support. Cached thumbnails remain usable offline and the cache syncs automatically.

```cue
plugin: {
    id:     "eagle"
    name:   "Eagle Integration"
    author: "goberomsu"
    repo:   "goberomsu/obsidian-eagle-plugin"

    html_url:    "https://community.obsidian.md/plugins/eagle"
    github_url:  "https://github.com/goberomsu/obsidian-eagle-plugin"
    description: "Upload images to Eagle and manage them alongside your vault. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Paste images into notes to auto-upload to Eagle and render via a local cache, keeping your vault lean. Search and insert images from your Eagle library with thumbnails, smart deduplication, folder mapping and Canvas support. Work offline with cached thumbnails and automatic cache sync."

    stats: {
        downloads:  1563

    }
}
```
