# Chatterbox

Chatterbox renders conversations in the style of a messaging app from chatterbox code blocks. Author lines carry a direction marker, with the greater-than sign placing a message on the right, the less-than sign on the left and a caret in the center. Optional subtext such as a timestamp, custom text or a character reference can be attached, and a transcript may involve several authors.
