# Editor.js Rich Text Editor

Integrates Editor.js block-based rich-text editing into Obsidian, with 34 block and inline tools and two-way Markdown conversion the project describes as lossless. Blocks are reordered by drag and drop, and the editor supports undo and redo, autosave, keyboard shortcuts and the active theme.
