# Time Manager

Time Manager draws the tasks in Daily Notes as vertical time-blocks on a timeline. Durations and completion are recorded by category and shown as per-category bar charts with overload warnings, and category tags are suggested and color-highlighted while editing.

    id:     "time-manager"
    name:   "Time Manager"
