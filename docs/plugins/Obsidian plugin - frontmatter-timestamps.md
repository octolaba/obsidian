# Frontmatter Timestamps

Keeps created and updated YAML frontmatter timestamps in sync with file creation and edit events, adds missing created values, and updates modification timestamps after content changes. Timestamp modes, property names and ignored paths are configurable, changes can be previewed or applied per folder or vault-wide, and renames and malformed datetime values are handled.

```cue
plugin: {
    id:     "frontmatter-timestamps"
    name:   "Frontmatter Timestamps"
    author: "Pat"
    repo:   "jqml/frontmatter-timestamps"

    html_url:    "https://community.obsidian.md/plugins/frontmatter-timestamps"
    github_url:  "https://github.com/jqml/frontmatter-timestamps"
    description: "Keeps created and updated frontmatter timestamps in sync with Markdown file events. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Keep created and updated YAML frontmatter timestamps synced with file creation and edits, add missing created values, and update modification timestamps after content changes. Configure timestamp modes and property names, ignore paths, preview or apply changes per-folder or vault-wide, perform safe renames and clean malformed datetime values."

    }
}
```
