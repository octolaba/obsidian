# Claude Code IDE Pro

Connects Claude Code to Obsidian over the full IDE protocol, so the active note, the open tabs and the current selection follow the reader from note to note. Proposed edits arrive as side-by-side diffs applied with one click, and Claude can navigate to a given file and line. Obsidian-native tools expose backlinks, wikilinks, frontmatter, search and daily notes to the CLI.
