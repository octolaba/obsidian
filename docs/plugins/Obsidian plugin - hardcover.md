# Hardcover

Hardcover syncs a Hardcover library into Obsidian, creating one note per book with metadata stored in frontmatter. Note and filename templates are customizable, notes can be grouped by author or series and filtered by status, and updates run incrementally. Personal notes kept below a delimiter are preserved across those updates.

    id:     "hardcover"
    name:   "Hardcover"
