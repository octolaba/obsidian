# Time Machine

Time Machine scrubs through a note's history on an interactive timeline that merges Obsidian File Recovery snapshots with git commits. Colored diffs are previewed while sliding to any moment, and either a whole version or a single paragraph is restored. Git commits appear on desktop, while File Recovery snapshots work everywhere.
