# Claude Sessions

Browses Claude Code sessions as interactive timelines next to the notes, with collapsible labeled turns and timestamped progress. Tool output is rendered as diffs, highlighted code, images, question cards and inline sub-agent logs, and sessions can be searched, analyzed and exported. The JSONL files are read locally, which keeps the conversations private, and the plugin is desktop only.

```cue
plugin: {
    id:     "claude-sessions"
    name:   "Claude Sessions"
    author: "gapmiss"
    repo:   "gapmiss/claude-sessions"

    html_url:    "https://community.obsidian.md/plugins/claude-sessions"
    github_url:  "https://github.com/gapmiss/claude-sessions"
    description: "View Claude Code sessions. Browse, search, analyze, & export your sessions as interactive timelines with live watch & rich tool rendering — right alongside your notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Browse Claude Code sessions as interactive timelines with collapsible labeled turns and timestamped progress. Render tool outputs as diffs, highlighted code, images, question cards, and inline sub-agent logs; read JSONL files locally to keep conversations private (desktop-only)."

    stats: {
        downloads:  702
        updated_at: 1783976900000
    }
}
```
