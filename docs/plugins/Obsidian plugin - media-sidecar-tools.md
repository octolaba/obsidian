# Media Sidecar Tools

Creates a Markdown sidecar note for a media file with Ctrl+Click and can hide the original attachment from the file explorer. Explorer visibility stays synchronized, so renaming, moving, creating or deleting either the note or the attachment updates the view immediately.

```cue
plugin: {
    id:     "media-sidecar-tools"
    name:   "Media Sidecar Tools"
    author: "Gabriel"
    repo:   "turingexmachina/obsidian-media-sidecar-tools"

    html_url:    "https://community.obsidian.md/plugins/media-sidecar-tools"
    github_url:  "https://github.com/turingexmachina/obsidian-media-sidecar-tools"
    description: "Create sidecar notes for media with Ctrl+Click, and hide the original media in file navigation if wanted. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create Markdown sidecar notes for media with Ctrl+Click and hide the original attachment from the file explorer. Keep explorer visibility synced so renaming, moving, creating, or deleting the note or attachment updates instantly."

    stats: {
        downloads:  18
        updated_at: 1783920130000
    }
}
```
