# reMarkable Bridge

Sends notes and PDFs to a reMarkable, where they can be annotated on paper or typed with a Type Folio, and pulls the edits back as Markdown with ink baked into the pages and highlights extracted; footnotes are preserved. It works through the local library of the official reMarkable desktop app, so no Connect subscription is needed. The recorded description states that it is unofficial and not affiliated with reMarkable AS.
