# Media Extended

Plays local files, remote URLs and YouTube or Vimeo video inside notes, with a pinned player and global hotkeys. Clickable timestamps and screenshots jump back to a moment, transcripts are searched, live recording markers are dropped during playback, and timed embeds support looping and autoplay. The recorded description states that the plugin is closed source.
