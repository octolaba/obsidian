# Siteswap

Siteswap juggling notation is rendered as animated GIFs through the Juggling Lab server, so an internet connection is required. A simple pattern can be given inline, or per-animation YAML can set the pattern, hand and body movement, colors and tempo.

```cue
plugin: {
    id:     "obsidian-siteswap"
    name:   "Siteswap"
    author: "tdresser"
    repo:   "tdresser/obsidian-siteswap"

    html_url:    "https://community.obsidian.md/plugins/obsidian-siteswap"
    github_url:  "https://github.com/tdresser/obsidian-siteswap"
    description: "Visualize Juggling Pattern Siteswap via the JugglingLab gif server."
    about:       "Render Siteswap juggling notation as animated GIFs via the Juggling Lab server. Specify simple patterns inline or provide per-animation YAML to set pattern, hand/body movement, colors and tempo for customized visualizations; requires an internet connection."

    stats: {
        downloads:  3686
        updated_at: 1642954346000
    }
}
```
