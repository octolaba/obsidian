# Control Characters

Control Characters shows non-printing characters such as spaces, tabs and newlines directly in edit mode. Highlighting can be limited to the current selection or forced per note through the cc-selection and cc frontmatter properties, including cc-newline and cc-tab. Appearance is adjusted through Style Settings.

    id:     "control-characters"
    name:   "Control Characters"
