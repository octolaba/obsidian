# Pin Enhancer

Pin Enhancer stops pinned tabs from being closed, including by middle-click. It supplies alternative close commands so close hotkeys can be rebound without unbinding the originals, and it leaves the context-menu close buttons working for deliberate manual closing.

    id:     "pin-enhancer"
    name:   "Pin Enhancer"
    author: "sheeplet1"
    repo:   "sheeplet1/obsidian-pin-enhancer"
