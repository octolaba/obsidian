# Card Workspace

Card Workspace browses the notes of a folder as a card stream in the left sidebar or in a main editor leaf, showing each note's title and a Markdown-stripped excerpt. Virtualized scrolling keeps large folders responsive, and notes can be filtered and searched before a click on a card opens the file. Folder clicks in the File Explorer can be linked so the card views stay in sync.

    id:     "card-workspace"
    name:   "Card Workspace"
    author: "kenan"
