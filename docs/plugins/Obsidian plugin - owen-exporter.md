# Owen Exporter

Exports embedded SVG images as PNG or JPEG from a right-click in reading mode, rasterizing for higher-resolution output and handling backgrounds for transparent SVGs. Selected Markdown or rendered text can also be copied or saved as HTML, keeping inline preview styles for tables, code blocks and callouts.
