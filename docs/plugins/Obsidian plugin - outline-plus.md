# Outline++

Renders Markdown inside Obsidian's outline view, so headings, links and inline content appear formatted rather than as raw source. Rendering can be toggled to switch between the raw Markdown source and the rendered outline.

```cue
plugin: {
    id:     "outline-plus"
    name:   "Outline++"
    author: "ryotaushio"
    repo:   "ryotaushio/obsidian-outline-plus"

    html_url:    "https://community.obsidian.md/plugins/outline-plus"
    github_url:  "https://github.com/ryotaushio/obsidian-outline-plus"
    description: "Render Markdown inside the outline view."
    about:       "Render Markdown in the Outline pane to show formatted headings, links, and inline content. Toggle rendering to switch between raw Markdown source and a rendered, easy-to-scan outline."

    stats: {
        downloads:  2516
        updated_at: 1704638591000
    }
}
```
