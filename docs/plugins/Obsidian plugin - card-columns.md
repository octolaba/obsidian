# Card Columns

Card Columns shows notes as kanban-style cards grouped into columns by tags or by any frontmatter property. Clickable tag pills filter across columns in AND or OR mode. Property chips render text, tags, links, booleans and dates with grid or stacked layouts and date formatting.
