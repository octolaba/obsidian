# Tagescape

Tagescape suppresses inline tag recognition so that hash-prefixed words in a note body stay plain text and lose their tag styling and click behavior. Only tags declared in frontmatter properties remain visible to the tag pane, to tag search and to tag styling.

```cue
plugin: {
    id:     "tagescape"
    name:   "Tagescape"
    author: "bkindler"
    repo:   "bkindler/obsidian-tagescape"

    html_url:    "https://community.obsidian.md/plugins/tagescape"
    github_url:  "https://github.com/bkindler/obsidian-tagescape"
    description: "Suppresses inline tag recognition in body text. Only tags in frontmatter properties are kept. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Suppress inline tag recognition so #words in note body remain plain text and lose tag styling and click behavior. Keep only tags defined in frontmatter visible to the tag pane, tag search, and tag styling."
```
