# Note Splitter

Splits one note into several Markdown files at a custom delimiter, creating the new notes without modifying the original. Frontmatter can be ignored, the splits can be written to a chosen output folder, and the first line of each part can be used as its title or the delimiter removed from the split content.

```cue
plugin: {
    id:     "note-splitter"
    name:   "Note Splitter"
    author: "decaf-dev"
    repo:   "decaf-dev/obsidian-note-splitter"

    html_url:    "https://community.obsidian.md/plugins/note-splitter"
    github_url:  "https://github.com/decaf-dev/obsidian-note-splitter"
    description: "Split a note into individual notes based on a delimiter."
    about:       "Split a note into multiple Markdown files using a custom delimiter, creating new notes without modifying the original. Ignore frontmatter, save splits to a chosen output folder, and optionally use the first line as each new note's title or remove the delimiter from the split content."

    stats: {
        downloads:  3318
        updated_at: 1726991005000
    }
}
```
