# Link Tree

Displays the current note's links and backlinks as a recursively expandable, filterable outline that drops circular links, combining the structure of outliners such as Dynalist and WorkFlowy with Obsidian's flexibility. Forward and back lists can be toggled, results searched by pathname, and note lines previewed or edited inline, with Dataview used to extract the links and backlinks.
