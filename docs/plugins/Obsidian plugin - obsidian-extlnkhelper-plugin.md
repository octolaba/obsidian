# External Link Helper

Searches external links across the vault and inserts a previously used URL into the current note through a suggestion modal. A fuzzy-searchable link viewer finds and opens links, jumps to the notes they came from, and filters results by associated tags.

    id:     "obsidian-extlnkhelper-plugin"

    author: "nakalsio"
