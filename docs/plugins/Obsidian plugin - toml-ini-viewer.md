# TOML INI Viewer

TOML INI Viewer opens toml and ini files as a read-only parsed config tree of sections, keys and value types, with filtering and search. The raw source can be viewed with line numbers and lightweight highlighting, parse warnings report TOML errors and duplicate or malformed INI entries, and large files are capped for safety.

```cue
plugin: {
    id:     "toml-ini-viewer"
    name:   "TOML INI Viewer"
    author: "Viggo Meesters"
    repo:   "viggomeesters/obsidian-toml-ini-viewer"

    html_url:    "https://community.obsidian.md/plugins/toml-ini-viewer"
    github_url:  "https://github.com/viggomeesters/obsidian-toml-ini-viewer"
    description: "Open .toml and .ini files as a read-only config tree with search, source view, and parse warnings. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open .toml and .ini files as a read-only parsed config tree with sections, keys, value types, filtering, and search. View the raw source with line numbers and lightweight highlighting while seeing parse warnings (TOML errors, INI duplicates/malformed) and safe large-file caps."
```
