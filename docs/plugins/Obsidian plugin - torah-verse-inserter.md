# Torah Verse Inserter

Torah Verse Inserter inserts Hebrew Bible verses with nikud and cantillation into a note, working fully offline. A verse is found by reference, by Hebrew, or by Latin transliteration, so typing bereshit locates the Hebrew text without switching keyboards. Optional translations and AlHaTorah links can be added, and the verse is inserted as a formatted quote block.

```cue
plugin: {
    id:     "torah-verse-inserter"
    name:   "Torah Verse Inserter"
    author: "spenhos"
    repo:   "spenhos/obsidian-torah-verse-inserter"

    html_url:    "https://community.obsidian.md/plugins/torah-verse-inserter"

Optional translations and AlHaTorah links. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert any Tanakh verse into your notes with full Hebrew text, including nikud and cantillation, available offline. Search by reference, Hebrew, or Latin transliteration (type Hebrew without switching keyboards), add optional translations and AlHaTorah deep-links, and insert as formatted quote blocks."
```
