# Terminal Agent Tabs

Terminal Agent Tabs runs several agent CLI sessions, among them Claude Code, Codex, Gemini and Grok, as tabs inside Obsidian. Sessions are managed from a sidebar and can be resumed or split, titles update automatically, and font size is set per tab. A note selection can be sent to a session, hook notifications arrive with optional sounds, and the terminal clipboard is synced over OSC52.
