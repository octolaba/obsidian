# AI Search for Your Second Brain

The vault is connected to Claude, ChatGPT or Cursor over MCP so that those assistants search it with natural-language queries and find notes by meaning rather than by keyword. Semantic search covers more than a hundred languages and is kept current by incremental background sync with per-user data isolation. The index records that this plugin has not been manually reviewed by Obsidian staff.
