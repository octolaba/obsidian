# FloatMark

Annotates and comments inside notes through a floating toolbar over the selection and a block-level quick menu for formatting, commenting, copying and deleting. Highlights use configurable foreground and background colors stored in a sidecar JSON file, and comment threads are managed in a sidebar. Local comments can be synced to Feishu or Lark when a document link and a sync state are available.
