# Extended Code Highlight

Extended Code Highlight adds configurable syntax highlighting for code block languages across Reading view and the Editor or Live Preview, using Prism-compatible grammars and CodeMirror decorations. It ships built-in support for languages such as WebAssembly, Zig, Nix, HCL and Svelte. Further languages are defined with regex-based token rules in languages.json.
