# Daf Yomi

Daf Yomi prepares a ready-made note for the day's Daf Yomi, with links to the Koren and Steinsaltz Talmud PDF, Sefaria and key commentaries. A page is added by date or by tractate and daf, and the day's PDF is embedded in the note or linked from it.
