# Virtual Autolink

Virtual Autolink creates virtual links for text matching the titles or aliases of other notes, updating live in edit and read modes without changing the note files. The links stay out of the graph and out of reference counts, which gives glossary-like behavior and a view of unlinked mentions. A context-menu action converts a virtual link into a real one.

```cue
plugin: {
    id:     "virtual-autolink"
    name:   "Virtual Autolink"
    author: "imavinash"
    repo:   "avinashkanaujiya/obsidian-autolink"

    html_url:    "https://community.obsidian.md/plugins/virtual-autolink"
    github_url:  "https://github.com/avinashkanaujiya/obsidian-autolink"
    description: "Automatically creates virtual links for text within your notes that match the titles or aliases of other notes in your vault. Create a glossary-like functionality, show unlinked mentions and transform them to real links. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Generate virtual links for any text that matches note titles or aliases, updating live in edit and read modes without altering your note files. Keep links hidden from the graph and reference counts, and convert virtual links to real links via the context menu."

    stats: {
        downloads:  194
        updated_at: 1783597289000
    }
}
```
