# Duplicate Detector

Highlights lines in the active note that duplicate another line, and shows the matching line number on hover. When pasted text contains lines that already exist in the note, a notice is displayed.

```cue
plugin: {
    id:     "duplicate-detector"
    name:   "Duplicate Detector"
    author: "wishmater"
    repo:   "wishmater/obsidian-plugin-duplicate-detector"

    html_url:    "https://community.obsidian.md/plugins/duplicate-detector"
    github_url:  "https://github.com/wishmater/obsidian-plugin-duplicate-detector"
    description: "Highlights duplicate lines in the open note."
    about:       "Highlight duplicate lines in the active note and show the matching line number on hover. Display a notice when pasted text contains lines that already exist so you can avoid accidental duplicates."

    stats: {
        downloads:  1941
```
