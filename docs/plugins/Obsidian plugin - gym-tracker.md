# Gym Tracker

Logs strength workouts and rucks, recording exercises, sets, reps, weight, RPE, RIR, rest timers and notes in a layout that adapts to mobile and desktop. Volume trends, streaks, progression suggestions and personal records are reviewable, GPX routes can be imported, routines saved, and data exported as Dataview-friendly Markdown.
