# Tagline

Tagline creates notes out of a single inline line, choosing the template from the tag on that line. A line carrying a tag and Dataview-style inline fields gets autocomplete suggestions for dates, folders, tags and options, then converts into a linked note with typed frontmatter. Checkbox sync is optional and Templater is supported.
