# Linear Calendar

Displays all 365 days of a year in a single view so notes can be seen chronologically, events tracked, and daily notes managed. Single-day notes are placed into day cells and multi-day events render as horizontal bars, with dates taken from filenames or frontmatter and notes opened or previewed by click or hover. The recorded description notes that the plugin has not been manually reviewed by Obsidian staff.
