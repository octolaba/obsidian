# Folder by tags distributor

Moves notes into existing folders by matching the tags written in the note against folder names. Folder names are searched from the vault root for tag similarity and no new folder is created. A note with no matching directory is placed in the vault root.

```cue
plugin: {
    id:     "folder-by-tags-distributor"
    name:   "Folder by tags distributor"
    author: "revotale"
    repo:   "revotale/obsidian-folder-by-tags-distributor"

    html_url:    "https://community.obsidian.md/plugins/folder-by-tags-distributor"
    github_url:  "https://github.com/revotale/obsidian-folder-by-tags-distributor"
    description: "Automatically move notes into existing folders by tags specified in note."
    about:       "Move notes into existing folders by matching their tags to folder names. Search folder names from the vault root for tag similarity and relocate notes accordingly without creating new folders. Place notes with no matching directory in the vault root."

    stats: {
        downloads:  2278

    }
}
```
