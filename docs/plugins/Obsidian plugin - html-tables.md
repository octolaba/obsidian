# HTML Tables

HTML Tables extends Markdown tables with header rows and columns, horizontal and vertical cell merging, captions, multiline cells and basic formulas. Columns are resized and auto-fitted, horizontal and vertical alignment is set, and tables are edited from a right-click context menu in preview mode.
