# Game Search

Searches games through the RAWG API and creates game notes from a template, filling in metadata such as title, platforms, genres and stores. A Steam library and wishlist can be synced to import games and attach a steamId and optional status metadata to the notes.

    id:     "game-search"
    name:   "Game Search"
    author: "cmorooney"
