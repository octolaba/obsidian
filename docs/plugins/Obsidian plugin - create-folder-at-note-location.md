# Create Folder at Note Location

This plugin creates a folder at the location of the current note with a single command. It can also create a file inside the new folder carrying the same name, so that the folder gets a folder note.

```cue
plugin: {
    id:     "create-folder-at-note-location"
    name:   "Create Folder at Note Location"
    author: "josteniok"
    repo:   "josteniok/create-folder-at-note-location"

    html_url:    "https://community.obsidian.md/plugins/create-folder-at-note-location"
    github_url:  "https://github.com/josteniok/create-folder-at-note-location"
    description: "Creates a folder at the location of the current note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create a folder at the current note's location with a single command. Optionally create a file inside the new folder with the same name to serve as a folder note."

    stats: {
        downloads:  165
        updated_at: 1779724974000
    }
}
```
