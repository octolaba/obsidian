# Freeform

Runs arbitrary JavaScript inside sandboxed iframes in a note. ESM modules can be imported from URLs, styles injected, and a display call used to render values and DOM elements for Observable-style interactive output.

```cue
plugin: {
    id:     "freeform"
    name:   "Freeform"
    author: "tmcw"
    repo:   "tmcw/obsidian-freeform"

    html_url:    "https://community.obsidian.md/plugins/freeform"
    github_url:  "https://github.com/tmcw/obsidian-freeform"
    description: "Create visualizations, run custom JS, and mix live programs with your notes"
    about:       "Run arbitrary JavaScript inside sandboxed iframes in your notes. Import ESM modules from URLs (esm.sh/jsdelivr), inject styles, and use display() to render values and DOM elements for Observable-style interactive outputs."

    stats: {
        downloads:  1071
        updated_at: 1719076617000
    }
}
```
