# Auto Scroll

Auto Scroll scrolls the editor while you type once the cursor reaches a chosen point in the visible pane, keeping the insertion point above the bottom of the pane. The trigger point, scroll step and cooldown are configurable, and the movement can be animated smoothly.

```cue

    id:     "auto-scroll"
    name:   "Auto Scroll"
    author: "femto"
    repo:   "femto-0/auto-scroll"
```
