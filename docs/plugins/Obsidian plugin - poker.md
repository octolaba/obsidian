# Poker

Renders and documents poker hands inline using two-letter card codes, with ranks AKQJT98765432X and suits dhscx, where X marks an unknown rank or suit. Several cards can be written in a single token, and the inline prefix defaults to pkr but is configurable.

```cue
plugin: {
    id:     "poker"
    name:   "Poker"
    author: "maadhattah"
    repo:   "maadhattah/obsidian-poker"

    html_url:    "https://community.obsidian.md/plugins/poker"
    github_url:  "https://github.com/maadhattah/obsidian-poker"
    description: "Easily document and view your poker hands."
    about:       "Render and document poker hands inline using simple two-letter card codes (ranks AKQJT98765432X, suits dhscx) with X for unknown rank or suit. Insert multiple cards in one token and set a custom inline prefix (default pkr) to match your workflow."

    stats: {
        downloads:  4088
        updated_at: 1721000845000
    }
}
```
