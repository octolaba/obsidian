# Property Over File Name

Searches, displays, and inserts notes by a specified note property, such as a title property, instead of by the file name. The property value is shown in the link suggester, quick switcher, graph, tabs, backlinks, bookmarks, window frame, and file explorer, and notes can be created or dragged while keeping their property-based titles.
