# Note Mate

Chats with AI about notes, generates content, searches the web and creates images without leaving the vault. Connects to OpenAI, Azure, Gemini or any OpenAI-compatible API, and lets the model read, search, browse and edit notes with persistent sessions and a reviewable edit history.
