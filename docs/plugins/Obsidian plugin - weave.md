# Weave

Links reading material, FSRS6 spaced-repetition memory cards and test questions into one reviewable loop that stays traceable back to its source. Cards are generated from Markdown excerpts, tests track performance with an EWMA measure, and analytics summarise the result. Cards can also be synced with Anki for study outside Obsidian.
