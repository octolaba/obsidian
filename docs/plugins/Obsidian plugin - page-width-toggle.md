# Page Width Toggle

Toggles a note's page width between the default readable length and a full-window wide mode from the ribbon, the command palette, the editor right-click menu or the note's more-options menu. The change is kept per note and does not alter the vault-wide readable line length, and an optional narrow CSS class can be applied by hand through frontmatter.

```cue
plugin: {
    id:     "page-width-toggle"
    name:   "Page Width Toggle"
    author: "heono3h"
    repo:   "heono3h/page-width-toggle"

    html_url:    "https://community.obsidian.md/plugins/page-width-toggle"
    github_url:  "https://github.com/heono3h/page-width-toggle"
```
