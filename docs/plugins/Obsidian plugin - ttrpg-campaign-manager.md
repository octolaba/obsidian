# TTRPG Campaign Manager

Manages tabletop RPG campaigns in plain Markdown, with entries for NPCs, locations, factions, session logs, quests and loot. A dedicated sidebar browses the NPCs, sessions and quests of each campaign.

```cue
plugin: {
    id:     "ttrpg-campaign-manager"
    name:   "TTRPG Campaign Manager"
    author: "wesswart77"
    repo:   "wesswart77/obsidian-ttrpg"

    html_url:    "https://community.obsidian.md/plugins/ttrpg-campaign-manager"
    github_url:  "https://github.com/wesswart77/obsidian-ttrpg"
    description: "Manage tabletop RPG campaigns: NPCs, locations, factions, session logs, quests, and loot in plain markdown. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Manage TTRPG campaigns in Obsidian. Create NPCs, session logs, quests, locations, factions, and loot entries, then browse NPCs, sessions, and quests per campaign from a dedicated sidebar."

    stats: {
        downloads:  783
        updated_at: 1779653217000
    }
}
```
