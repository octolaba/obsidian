# Indice Nights

Indice Nights indexes the biblical references stored in note properties and presents them in a responsive menu listing all 66 books in biblical order. References, sermon names and subfolders can be searched, and results lead to the related notes through internal links. The index updates automatically, book selection is kept per device, and rendering is progressive for large vaults.

```cue
plugin: {
    id:     "bible-reference-index"
    name:   "Indice Nights"
    author: "the_nights"
    repo:   "thenights20/obsidian-bible-reference-index"

    html_url:    "https://community.obsidian.md/plugins/bible-reference-index"
    github_url:  "https://github.com/thenights20/obsidian-bible-reference-index"
    description: "Creates a lightweight index of Bible references and related notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Index biblical references stored in note properties with a lightweight, responsive menu of all 66 books in biblical order. Search by reference, sermon name or subfolder, jump to related notes via internal links, and get automatic updates, per-device book selection and progressive rendering for large vaults."
}
```
