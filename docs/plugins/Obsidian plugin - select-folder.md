# Select Folder

Select Folder gives the file explorer Finder-like behavior: clicking a folder's name highlights and selects it, while the triangle still expands and collapses it and multi-select and other explorer behaviors remain unchanged. A new note created with the regular shortcut then lands inside the selected folder.

```cue
plugin: {
    id:     "select-folder"
    name:   "Select Folder"
    author: "frog"
    repo:   "frogtempest/select-folder"

    html_url:    "https://community.obsidian.md/plugins/select-folder"
    github_url:  "https://github.com/frogtempest/select-folder"
    description: "Finder-like behavior for the file explorer: click the triangle to expand, click a folder to select it, and create new notes inside the selected folder. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Select folders in the file explorer by clicking their names to highlight them, while the triangle still expands/collapses and multi-select plus other explorer behaviors remain unchanged. Create new notes inside the selected folder using your regular New Note shortcut."

    stats: {
        downloads:  147
        updated_at: 1782724596000
    }
}
```
