# Mermaid GUI Editor

Opens a GUI editor from any mermaid code block for flowchart, sequence, class, Gantt, kanban, quadrant, XY and other diagram types. Editing happens on an interactive drag-and-drop canvas or in a structured form with live preview. The result is saved back as plain Mermaid text, which the recorded text states keeps files portable and free of proprietary metadata.
