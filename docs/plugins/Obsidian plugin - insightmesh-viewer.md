# InsightMesh Viewer

InsightMesh Viewer is a read-only view over InsightMesh provenance for the active page: which conversations and checkpoints produced it, the decisions and rationale behind each edit, and how the page evolved. It shows time-ordered checkpoints, decision details labeled with provider and model, GitHub-style snapshot diffs, drift flags, and structured run-log and cursor views. Everything it displays is local, and it writes nothing back.
