# Checkbox Sounds

Checkbox Sounds plays a completion sound whenever a checkbox is ticked off. The sound itself can be changed in the plugin settings.

```cue
plugin: {
    id:     "checkbox-sounds"
    name:   "Checkbox Sounds"
    author: "yasd251"
    repo:   "yasd251/checkbox-sounds-plugin"

    html_url:    "https://community.obsidian.md/plugins/checkbox-sounds"
    github_url:  "https://github.com/yasd251/checkbox-sounds-plugin"
    description: "Adds a nice completion sound to checkboxes when ticked off"
    about:       "Play a completion sound whenever you check off a checkbox in Obsidian. Change the sound in plugin settings to personalize the feedback."

    stats: {
        downloads:  3653
        updated_at: 1779670985000
    }
}
```
