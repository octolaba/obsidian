# WeChat Multi Publisher

Publishes Markdown notes in bulk to the drafts of several WeChat Official Accounts, with more than one account managed at a time. Thirteen built-in CSS themes or custom ones set the layout, and cover and inline images are uploaded and compressed automatically. Layouts can be previewed or exported as a long PNG, publish history is kept, and network access can go through a SOCKS5 or HTTP proxy.
