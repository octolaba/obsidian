# Hyoka

Hyoka is described as an agentic system for Obsidian with an MCP-style tool loop and multi-profile agents suited to local models. It connects local or remote machine learning models and routes prompts written in notes to them, inserting responses into files or previewing them inline, and model endpoints are managed in its settings.
