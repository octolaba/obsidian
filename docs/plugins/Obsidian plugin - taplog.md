# TapLog

TapLog builds one-tap trackers out of ordinary Markdown notes: in Reading view it renders tappable buttons from the tracker configuration, and a tap writes a timestamped row into a monthly CSV file under its logs folder. Trackers can be created from built-in templates or from settings and edited without touching YAML, with the tracker note remaining the source of truth. It also generates tracker indexes, Markdown dashboards, active-tracker summaries, monthly rollups and snack restock guidance, and is aimed at quick logging on desktop and mobile.
