# Pocketbook Cloud Highlight Importer

Imports notes and highlights from a Pocketbook Cloud account into individual Markdown files carrying YAML frontmatter. Dataview-ready queries are generated to gather comments and metadata for searching and review. The Dataview plugin is required, and login is password-based only.

```cue
plugin: {
    id:     "pocketbook-cloud-highlight-importer"
    name:   "Pocketbook Cloud Highlight Importer"
    author: "lenalebt"
    repo:   "lenalebt/obsidian-pocketbook-cloud-highlight-importer"

    html_url:    "https://community.obsidian.md/plugins/pocketbook-cloud-highlight-importer"
    github_url:  "https://github.com/lenalebt/obsidian-pocketbook-cloud-highlight-importer"
    description: "Import notes and highlights from your Pocketbook Cloud account."
    about:       "Import highlights from your Pocketbook Cloud account into Obsidian as individual Markdown files with YAML frontmatter. Generate Dataview-ready queries to gather comments and metadata for easy searching and review. Require the Dataview plugin and use password-based login only."
```
