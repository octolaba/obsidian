# Paste Mode

This plugin pastes content at the cursor's current indentation and can mark block quotes at any level of it. Eight paste modes are available, among them plain text, blockquote, Markdown-converted text, fenced code block and passthrough. The active mode is shown in the status bar and switched from the status-bar menu or the Command Palette.

```cue
plugin: {
    id:     "obsidian-paste-to-current-indentation"
    name:   "Paste Mode"
    author: "jglev"
    repo:   "jglev/obsidian-paste-mode"

    html_url:    "https://community.obsidian.md/plugins/obsidian-paste-to-current-indentation"
    github_url:  "https://github.com/jglev/obsidian-paste-mode"
    description: "Paste content and mark block quotes at any level of indentation."
```
