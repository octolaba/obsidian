# Graph Label Above

Moves graph node labels above their nodes so an enlarged mouse pointer does not obscure them, in both the built-in 2D graph and the 3D Graph plugin. A slider adjusts the label distance, the 3D hover tooltip is repositioned above the cursor, and the 2D label colour can optionally be overridden.
