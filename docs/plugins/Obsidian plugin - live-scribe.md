# Live Scribe

Transcribes a meeting in real time in a sidebar through ElevenLabs Scribe, buffering the transcript so chosen parts can be inserted into the note. The recorded inputs describe low latency and multi-language detection, insertion of a full session or a single segment, automatic saving of the whole session to a file, and client-side operation with the user's own API key.
