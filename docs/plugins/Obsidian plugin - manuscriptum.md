# Manuscriptum

Manuscriptum exports short stories and novel manuscripts as Microsoft Word .docx files in Shunn format, ready for submission to magazines or agents. A story can live in a single note or be spread across multiple scene notes that are combined with scene breaks. Anonymous manuscripts can be produced and per-story metadata can be overridden.

    id:     "manuscriptum"
    name:   "Manuscriptum"
    author: "sgranade"
