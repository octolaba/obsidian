# Inline Color Swatch

Inline Color Swatch shows a small colour preview next to supported CSS colour values written in inline code spans, matching GitHub-Flavored Markdown behaviour. The recognised formats are hex in the #RGB, #RRGGBB, #RGBA and #RRGGBBAA shapes plus rgb, rgba, hsl and hsla, matched case-insensitively. Fenced code blocks are ignored.
