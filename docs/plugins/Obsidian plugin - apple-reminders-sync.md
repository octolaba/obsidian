# Apple Reminders Sync

Pulls incomplete Apple Reminders due today into the TODO section of the daily note as Markdown checklists. Reminders are appended as unchecked items, reminder notes are preserved as indented text, and priorities are marked with one to three exclamation marks. Entries are deduplicated, excluded lists are skipped, and syncing runs on open or on a set interval.
