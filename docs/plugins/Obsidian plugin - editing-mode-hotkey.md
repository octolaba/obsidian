# Editing Mode Hotkey

Adds a command and a hotkey that toggle the default editing mode between Live Preview and Source. The change is applied to every open editor at once, and the hotkey defaults to Cmd or Ctrl plus Shift plus E.

```cue
plugin: {
    id:     "editing-mode-hotkey"
    name:   "Editing Mode Hotkey"
    author: "signynt"
    repo:   "signynt/obsidian-editing-mode-hotkey"

    html_url:    "https://community.obsidian.md/plugins/editing-mode-hotkey"
    github_url:  "https://github.com/signynt/obsidian-editing-mode-hotkey"
    description: "Adds a command and hotkey to toggle the default editing mode (between Live Preview and Source)"
    about:       "Toggle the editing mode between Source and Live Preview and apply the change to all open editors. Use the command or hotkey to switch instantly (default: Cmd/Ctrl+Shift+E)."

    stats: {
        downloads:  757
        updated_at: 1779366454000
    }
}
```
