# Spotify API

The Spotify SDK is injected into Obsidian so that custom code can call the Spotify Web API through the official TypeScript client. The recorded inputs name searching songs, albums and artists, fetching playlists and track details, controlling playback, and reading user data such as top tracks and recommendations.

```cue
plugin: {
    id:     "spotify-api"
    name:   "Spotify API"
    author: "darren-project"
    repo:   "darren-project/obsidian-spotify"

    html_url:    "https://community.obsidian.md/plugins/spotify-api"
    github_url:  "https://github.com/darren-project/obsidian-spotify"
    description: "Exposes Spotify API"
    about:       "Inject the Spotify SDK into Obsidian and write custom code to call the Spotify Web API using the official TypeScript Spotify API. Search songs, albums, and artists; fetch playlists and track details; control playback and access user-specific data like top tracks and recommendations."
```
