# Personal Assistant

Personal Assistant automates note creation, opens related graph views and quick memos, and updates plugins or themes from a single command. A retrieval-augmented LLM chat assistant searches, reads and writes across the vault, and images can be generated from note content. The recorded description also names records, callouts and frontmatter among the things it helps manage.
