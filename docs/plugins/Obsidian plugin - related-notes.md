# Related Notes

Discovers related notes across the vault using Bloom filter n-gram similarity analysis, and a related note can be linked with one click. All processing runs locally. Multilingual and CJK scripts are handled, with automatic optimization for large vaults.

```cue
plugin: {
    id:     "related-notes"
    name:   "Related Notes"
    author: "mrboxtobox"
    repo:   "mrboxtobox/obsidian-related-notes"

    html_url:    "https://community.obsidian.md/plugins/related-notes"
    github_url:  "https://github.com/mrboxtobox/obsidian-related-notes"
```
