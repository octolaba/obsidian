# Omg.publish

Omg.publish posts selected text from a note to omg.lol services such as the statuslog, authenticated with an omg.lol account token. A default emoji can be set for posts and Mastodon cross-posting can be disabled.

```cue
plugin: {
    id:     "omglol-statuslog-publish"
    name:   "Omg.publish"
    author: "maymeow"
    repo:   "maymeow/obsidian-omglol-statuslog"

    html_url:    "https://community.obsidian.md/plugins/omglol-statuslog-publish"
    github_url:  "https://github.com/maymeow/obsidian-omglol-statuslog"
    description: "Post selected text to OMG.lol statuslog."
    about:       "Post selected notes to omg.lol services like statuslog (weblog planned) using your omg.lol account token. Set a default emoji for posts and optionally disable Mastodon cross-posting."

    stats: {
        downloads:  2168
        updated_at: 1700934255000
    }
}
```
