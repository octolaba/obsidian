# Copy Selected Name

Copy Selected Name copies the names of files and folders selected in the file explorer as editable mentions, or converts them into obsidian:// URLs, for pasting into notes and AI chats. Several selections can be appended into a single paste-ready list, and the plugin keeps an internal clipboard and history, exporting to the system clipboard when required.

```cue
plugin: {
    id:     "copy-selected-name"
    name:   "Copy Selected Name"
    author: "mikeddy"
    repo:   "mikeddy/obsidian-copy-selected-name"

    html_url:    "https://community.obsidian.md/plugins/copy-selected-name"
    github_url:  "https://github.com/mikeddy/obsidian-copy-selected-name"
    description: "Copy selected files or folders as editable @mentions with Alt+C, with append mode, history, and vault URL conversion. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Copy selected file and folder names from Obsidian's file explorer as @filename.md references or convert them to obsidian:// URLs for pasting into AI chats and notes. Append multiple selections into a single paste-ready list, maintain an internal clipboard and history, and export to the system clipboard when required."
```
