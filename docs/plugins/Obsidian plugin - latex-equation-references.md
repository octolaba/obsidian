# Latex Equation References

This plugin numbers LaTeX equations from %\label{...} comments, inserting or updating a \tag{N} on each labelled equation. A \ref{...} is displayed in Live Preview as a readable Equation N, or a custom prefix, and the raw \ref{...} is revealed again while editing.

```cue
plugin: {
    id:     "latex-equation-references"
    name:   "Latex Equation References"
    author: "georgrasumov"
    repo:   "georgrasumov/Obsidian-Latex-Equation-References"

    html_url:    "https://community.obsidian.md/plugins/latex-equation-references"
    github_url:  "https://github.com/georgrasumov/Obsidian-Latex-Equation-References"
    description: "Automatically numerates equations using labels. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Auto-number LaTeX equations based on %\\label{...} comments, inserting or updating \\tag{N} for each labeled equation. Display \\ref{...} as a human-readable \"Equation N\" (or custom prefix) in Live Preview and reveal the raw \\ref{...} when editing."

    stats: {
        downloads:  296
        updated_at: 1771165155000
    }
}
```
