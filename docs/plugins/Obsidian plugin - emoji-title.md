# Emoji Title

Adds an emoji drawn from frontmatter to a note's title in the file explorer and in active tabs, and extends the same treatment to folders. The emoji to display is resolved from frontmatter, from folder inheritance or from the file type, folder notes are created and kept in sync, and injection is suspended during renames to avoid rendering glitches.

```cue
plugin: {
    id:     "emoji-title"
    name:   "Emoji Title"
    author: "arturtupiassu"
    repo:   "arturtupiassu/emoji-title-plugin"

    html_url:    "https://community.obsidian.md/plugins/emoji-title"
    github_url:  "https://github.com/arturtupiassu/emoji-title-plugin"
    description: "Add an emoji from frontmatter to the File Explorer title. Now supports inherit_emoji for folders. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Adicione emojis automaticamente aos títulos de notas e pastas no explorador de arquivos e nas abas ativas. Resolva qual emoji exibir a partir do frontmatter, herança de pastas ou tipo de arquivo; crie e sincronize notas de pasta automaticamente e suspenda a injeção durante renomeações para evitar glitches com renderização otimizada."

    stats: {
        downloads:  188

    }
}
```
