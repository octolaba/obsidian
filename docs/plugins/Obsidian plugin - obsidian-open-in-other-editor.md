# Open in other editor

This plugin opens the currently active file in gVim, VS Code or nvim-qt. The Open in other command is invoked from the palette, and the editor's own CLI command has to be available on the system.

```cue
plugin: {
    id:     "obsidian-open-in-other-editor"
    name:   "Open in other editor"
    author: "yekingyan"
    repo:   "yekingyan/obsidian-open-in-other-editor"

    html_url:    "https://community.obsidian.md/plugins/obsidian-open-in-other-editor"
    github_url:  "https://github.com/yekingyan/obsidian-open-in-other-editor"
    description: "Open current active file in gVim or VS Code."
    about:       "Open the active note in gVim, VS Code, or nvim-qt directly from Obsidian. Invoke the Open in other command from the palette and ensure the editor's CLI command (code, gvim, nvim-qt) is available on your system."

    stats: {
        downloads:  6845
        updated_at: 1686666001000
    }
}
```
