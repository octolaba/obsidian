# GitHub Copilot Integration

Adds a persistent sidebar for chatting about documents, with streaming output and automatic document context, and inserts the generated responses into notes. Content can be generated or rewritten inline, selections sent to the chat, and built-in actions run for summarizing, continuing writing, fixing grammar, extracting tasks, generating code or planning projects.
