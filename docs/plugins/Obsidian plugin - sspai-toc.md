# Sspai Style TOC

A floating table of contents sits at the right side of a note in a minimalist design modeled on Sspai. Headings that are not active collapse into simple lines while the active heading stays fully visible, which keeps the list from competing for attention. The table of contents stays live-synced in both editing and reading modes, updating as the note is typed or scrolled.

```cue
plugin: {
    id:     "sspai-toc"
    name:   "Sspai Style TOC"
    author: "likemuuxi"
    repo:   "likemuuxi/obsidian-sspai-toc"

    html_url:    "https://community.obsidian.md/plugins/sspai-toc"
    github_url:  "https://github.com/likemuuxi/obsidian-sspai-toc"
    description: "A floating table of contents inspired by Sspai. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add a floating Sspai-style table of contents on the right side of your notes with a minimalist design that stays out of the way. Auto-hide non-active headings into simple lines while keeping the active heading fully visible to reduce distraction. Keep the TOC live-synced across edit and reading modes, updating instantly as you type or scroll."

    stats: {
        downloads:  824

    }
}
```
