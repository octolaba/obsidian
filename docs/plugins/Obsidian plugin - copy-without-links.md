# Strip Internal Links

Strip Internal Links removes internal Obsidian links from the current file or from a selection while leaving external links in place. The cleaned Markdown either replaces the content in place or is copied to the clipboard.

```cue
plugin: {
    id:     "copy-without-links"
    name:   "Strip Internal Links"
    author: "adiron"
    repo:   "adiron/obsidian-strip-internal-links"

    html_url:    "https://community.obsidian.md/plugins/copy-without-links"
    github_url:  "https://github.com/adiron/obsidian-strip-internal-links"
    description: "Copy the contents of files or selections within to the clipboard, without internal links."
    about:       "Strip internal Obsidian links from the current file or selection while preserving external links. Replace the content in-place or copy the cleaned Markdown to the clipboard."

    stats: {
        downloads:  2496
        updated_at: 1707127330000
    }
}
```
