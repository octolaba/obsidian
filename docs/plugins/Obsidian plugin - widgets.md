# Widgets

Inserts interactive widgets into a note through a widgets code block. Clocks, quotes, countdowns and counters are available, with formats, labels and increments that can be customised, so live time, timed events, quotes and interactive counts appear inline.

```cue
plugin: {
    id:     "widgets"
    name:   "Widgets"
    author: "rafaelveiga"
    repo:   "rafaelveiga/obsidian-widgets"

    html_url:    "https://community.obsidian.md/plugins/widgets"
    github_url:  "https://github.com/rafaelveiga/obsidian-widgets"
    description: "Add widgets to your notes like clock, countdown, and quotes."
    about:       "Insert interactive widgets into notes using a simple widgets code block. Add clocks, quotes, countdowns and counters with customizable formats, labels and increments to show live time, timed events, quotes and interactive counts inline."

    stats: {
        downloads:  32139
        updated_at: 1743039317000
    }
}
```
