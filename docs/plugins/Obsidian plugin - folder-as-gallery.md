# Folder as Gallery

Opens any folder as a responsive media gallery in a new tab, with image thumbnails and video previews that play on hover. The gallery is opened from an icon beside the folder, and Markdown notes are previewed by their first image or by a text snippet. Breadcrumb titles and a live search handle navigation.

    id:     "folder-as-gallery"
    name:   "Folder as Gallery"
