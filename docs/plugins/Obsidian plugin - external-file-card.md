# External File Card

External File Card displays information cards for files in pre-defined folders, written as ef or extfile code blocks, with efc and extfilec giving a compact view. A card shows the filename, the created and modified times, and the containing folder as clickable links. Inline Obsidian URIs of the form obsidian://ef?file.pdf are also supported, with spaces encoded as colons.

```cue
plugin: {
    id:     "external-file-card"
    name:   "External File Card"
    author: "james-yu"
    repo:   "james-yu/external-file-card"

    html_url:    "https://community.obsidian.md/plugins/external-file-card"
    github_url:  "https://github.com/james-yu/external-file-card"
    description: "Display file cards for external files."
    about:       "Display file info cards for files in pre-defined folders using ef/extfile code blocks, or use efc/extfilec for a compact view. Show filename, created and modified times, and containing folder as clickable links; support inline Obsidian URIs like obsidian://ef?file.pdf (encode spaces with :) for inline links."
```
