# Status Bar Pomodoro Timer

A pomodoro timer runs in the status bar and is driven from its clock icon, the command palette or a hotkey. Work and break durations, auto-start, cycle counts and system notifications are configurable. Completed pomodoros can be logged with timestamps to a file, the daily note or the active note.

```cue
plugin: {
    id:     "obsidian-statusbar-pomo"
    name:   "Status Bar Pomodoro Timer"
    author: "kzhovn"
    repo:   "kzhovn/statusbar-pomo-obsidian"

    html_url:    "https://community.obsidian.md/plugins/obsidian-statusbar-pomo"
    github_url:  "https://github.com/kzhovn/statusbar-pomo-obsidian"
    description: "Add a pomodoro timer to your status bar."
    about:       "Display a Pomodoro timer in the Obsidian status bar and control it from the clock icon, command palette, or a hotkey. Configure work/break durations, auto-start or cycle counts, enable system notifications, and log completed pomodoros to a file, daily note, or the active note with timestamps."
```
