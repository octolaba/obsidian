# Better Links

Better Links opens a compact popover in the Markdown editor for editing a link's display text and URL, invoked with Ctrl or Cmd click. Quick actions open the link, copy it in a preferred format, copy the URL or image filename, or delete it, while vault files and headings autocomplete and display text updates automatically. The popover is also shown for collapsed links on iOS.
