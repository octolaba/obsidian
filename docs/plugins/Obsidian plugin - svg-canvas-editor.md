# SVG Canvas Editor

SVG files are edited inside Obsidian across a visual canvas, a layer tree, an inspector and a live source preview. Elements are selected from the canvas or the layer tree, attributes such as fill, stroke, opacity, size and text are adjusted, items are resized and dragged, layers are reordered, and changes are undone and redone. A one-time backup file is created on the first save.
