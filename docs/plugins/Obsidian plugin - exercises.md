# Exercises

Creates interactive exercises inside a note from a block-based syntax. Match, select, input, line and choice elements build matching, multiple-choice and text-entry questions, with randomized options, more than one correct answer, and solutions that can be revealed.

```cue
plugin: {
    id:     "exercises"
    name:   "Exercises"
    author: "alexccavaco"
    repo:   "alexccavaco/obsidian-exercises"

    html_url:    "https://community.obsidian.md/plugins/exercises"
    github_url:  "https://github.com/alexccavaco/obsidian-exercises"
```
