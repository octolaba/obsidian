# Mandala Chart

Creates interactive nine-by-nine Mandala Charts for structured goal planning, a method the recorded description attributes to Shohei Ohtani. Charts are inserted through code-block embeds, cells are edited inline and accept Markdown, and two view modes switch between the overview and a single theme. Theme labels are drawn as rainbow-colored circles, changes are auto-saved, print-ready A4 landscape pages can be exported, and the recorded description names support for five languages.
