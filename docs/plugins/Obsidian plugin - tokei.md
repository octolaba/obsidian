# Tokei

Tokei displays a movable clock panel showing several timezones and updating live. Zones are added either as numeric UTC offsets or as IANA identifiers, where the IANA entries handle daylight saving time and the search matches partial names. Leaving a name blank falls back to selectable label styles, and the appearance can be adjusted with the provided CSS snippets.
