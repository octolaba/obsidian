# Wysimark Editor

Edits notes through a WYSIWYG rich-text interface while the file itself stays pure Markdown. Headings, lists, code blocks, tables, HTML embeds, links and images are applied as blocks, YAML frontmatter is hidden from the editor and preserved, and changes auto-save with a reload option.

```cue
plugin: {
    id:     "wysimark-editor"
    name:   "Wysimark Editor"
    author: "TAKESHI MORITA"
    repo:   "takeshy/obsidian-wysimark"

    html_url:    "https://community.obsidian.md/plugins/wysimark-editor"
    github_url:  "https://github.com/takeshy/obsidian-wysimark"
    description: "A modern WYSIWYG Markdown editor. Edit your notes with a rich text interface while keeping pure Markdown. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Edit notes with a WYSIWYG rich-text interface while preserving the underlying Markdown source. Apply familiar formatting and block elements (headings, lists, code blocks, tables, HTML embeds), insert links and images, and keep YAML frontmatter hidden and preserved with auto-save and a reload option."

    stats: {
        downloads:  3669
        updated_at: 1784156456000
    }
}
```
