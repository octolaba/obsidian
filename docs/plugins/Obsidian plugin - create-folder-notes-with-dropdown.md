# create folder notes with dropdown

This plugin creates Markdown files in existing or nonexisting folders through a dropdown. A folder path and a filename are picked from the menu, and missing folders are created automatically up to three levels deep.

```cue
plugin: {
    id:     "create-folder-notes-with-dropdown"
    name:   "create folder notes with dropdown"
    author: "sturdyshawn"
    repo:   "sturdyshawn/Create-folder-notes-with-dropdown"

    html_url:    "https://community.obsidian.md/plugins/create-folder-notes-with-dropdown"
    github_url:  "https://github.com/sturdyshawn/Create-folder-notes-with-dropdown"
    description: "create-folder-notes-with-dropdown is a plugin designed to help users quickly create Markdown files in existing or nonexisting folders with dropdown."
    about:       "Create folder notes from a dropdown and auto-create missing folders up to three levels deep. Pick a folder path and filename from the menu to quickly generate and organize new Markdown files in your vault."

    stats: {
        downloads:  785

    }
}
```
