# Markdown Dialect IAL

Markdown Dialect IAL brings Pandoc-style Inline Attribute Lists to Obsidian Markdown, so custom IDs, classes and key-value attributes can be assigned directly in a note. Which IAL token types are accepted is configurable. Filters can be applied automatically on save or run against the active file with an explicit command.

```cue
plugin: {
    id:     "markdown-dialect-ial"
    name:   "Markdown Dialect IAL"
    author: "fangface-hub"
    repo:   "fangface-hub/obsidian_markdown_diarect_ial"

    html_url:    "https://community.obsidian.md/plugins/markdown-dialect-ial"
    github_url:  "https://github.com/fangface-hub/obsidian_markdown_diarect_ial"
    description: "Adds Pandoc-style Inline Attribute Lists to Obsidian Markdown. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add Pandoc-style Inline Attribute Lists (IAL) to Markdown to assign custom IDs, classes, and key/value attributes directly in notes. Configure which IAL token types are accepted, auto-apply filters on save, or run the Apply IAL filters command to process the active file."

    stats: {
        downloads:  97
        updated_at: 1783858449000
    }
}
```
