# Autocomplete

Autocomplete adds inline text completion with automatic and manual triggers to raise typing speed. It provides language-aware tokenizers for Arabic and Japanese beside a default one, session- and file-based suggestions, snippet support, context-aware LaTeX completion and Vim-mode integration.
