# Smart Vault Chat

Runs an AI assistant in a persistent sidebar panel across several providers — Yandex AI Studio, Groq, OpenAI, Anthropic and GigaChat — and pulls vault content in as context for retrieval-based answers. Notes are searched by content or by date, the current note is added to the context in one click, and cited sources open directly. Selected text is edited inline by an AI action and replaced in place.
