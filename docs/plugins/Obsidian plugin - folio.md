# Folio

Creates project-centric workspaces for books, scripts, essays and films, each with self-contained folders, metadata and live word counts. Narrative structure is organized through a hierarchical drag-and-drop outline of chapters and scenes, and Writer Tools add focus mode, drafting helpers, an export assistant and inline references.
