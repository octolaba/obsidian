# Reflection

Shows daily and weekly notes from this day in years past, next to the current periodic note. Daily notes with the same date in previous years and weekly notes sharing the same week number are displayed for retrospective review.

```cue
plugin: {
    id:     "reflection"
    name:   "Reflection"
    author: "brandonkboswell"
    repo:   "brandonkboswell/reflection"

    html_url:    "https://community.obsidian.md/plugins/reflection"
    github_url:  "https://github.com/brandonkboswell/reflection"
    description: "Show daily and weekly notes from this day in years past."
    about:       "Display past daily and weekly notes linked to the current periodic note. Show same-date daily notes from previous years and weekly notes from previous years that share the same week number for quick retrospective review."

    stats: {
        downloads:  4634
        updated_at: 1772168394000
    }
}
```
