# Disciples Journal

Renders Bible verse references and full passages inside notes, with hoverable popups that stay open and links that open or create chapter notes. ESV HTML is rendered with poetry, footnotes, cross-references and Words of Christ. Passages can be downloaded on demand with an ESV API token and stored in an organized local folder for offline reading.

```cue
plugin: {
    id:     "disciples-journal"
    name:   "Disciples Journal"
    author: "Scott Tomaszewski"
    repo:   "scotttomaszewski/obsidian-disciples-journal"

    html_url:    "https://community.obsidian.md/plugins/disciples-journal"
    github_url:  "https://github.com/scotttomaszewski/obsidian-disciples-journal"
    description: "Embed Bible references and passages in your notes and read the Bible."
    about:       "Render Bible verse references and full passages directly in notes. Show hoverable popups that stay open, link to or create chapter notes, and render ESV HTML with poetry, footnotes, cross‑references and Words of Christ. Download passages on demand with an ESV API token and save them in an organized local folder for offline use."

    stats: {

    }
}
```
