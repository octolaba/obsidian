# Protected Note

Puts a password in front of selected notes and hides chosen folders from other people. Files can be encrypted with optional AES, Obsidian auto-locks when idle, and protection is toggled for the chosen content.

    id:     "protected-note"
    name:   "Protected Note"
    author: "mmiksaa"
    repo:   "mmiksaa/obsidian-protected-note"
