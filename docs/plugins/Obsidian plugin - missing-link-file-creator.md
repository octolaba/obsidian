# Missing Link File Creator

Missing Link File Creator creates the Markdown files that links in a note point to but that do not exist yet. It detects standard, aliased, path-specific, embedded and resource-directory links, preserves aliases in frontmatter, and scans in bulk or per folder. Templates and filename rules decide where new files are placed and what they contain.
