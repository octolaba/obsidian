# Interlinear Glossing

Formats the interlinear glosses used in linguistics and conlang texts from gloss-tagged code blocks. Source and metalanguage lines are aligned element by element through the recorded commands, with handling for bracketed multiword elements, escaped brackets, empty elements, comments, and a free translation line at the bottom.

```cue
plugin: {
    id:     "ling-gloss"
    name:   "Interlinear Glossing"
    author: "mijyuoon"
    repo:   "mijyuoon/obsidian-ling-gloss"

    html_url:    "https://community.obsidian.md/plugins/ling-gloss"
    github_url:  "https://github.com/mijyuoon/obsidian-ling-gloss"
    description: "Format interlinear glosses used in linguistics texts."
    about:       "Add interlinear glosses used in linguistics and conlang notes via gloss-tagged code blocks. Align source and metalanguage lines with \\gla, \\glb and optional \\glc element-by-element, handle bracketed multiword elements, escaped brackets, empty elements, comments, and a bottom \\ft free translation."

    stats: {
        downloads:  5979

    }
}
```
