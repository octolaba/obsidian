# Inscribe

Inscribe generates inline autocompletions as you type, each accepted or rejected with the TAB key. It connects to Ollama, Gemini, Grok or OpenAI-compatible providers, and system and user prompts are customizable through context templates such as the text before the cursor. Per-path profiles switch completions to a different configuration or disable them for particular notes.
