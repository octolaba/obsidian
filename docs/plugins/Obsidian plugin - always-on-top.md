# Always On Top

Keeps the Obsidian window above other applications, with the topmost state toggled by a command or hotkey. It runs on desktop only, and the recorded About text notes that the behavior may vary across operating systems.

```cue
plugin: {
    id:     "always-on-top"
    name:   "Always On Top"
    author: "ras0q"
    repo:   "ras0q/obsidian-always-on-top"

    html_url:    "https://community.obsidian.md/plugins/always-on-top"
    github_url:  "https://github.com/ras0q/obsidian-always-on-top"
    description: "Keep the Obsidian window always on top of other applications. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Keep the Obsidian window on top of other applications. Toggle the topmost state via a command or hotkey. Run on desktop only; behavior may vary across operating systems."
```
