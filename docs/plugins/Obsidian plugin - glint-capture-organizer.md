# Glint

Reads capture files left in the Shortcuts iCloud inbox and turns selected text, the current note, the clipboard or a URL into clean Markdown notes with Obsidian-friendly YAML frontmatter. Title, category, tags, summary, key points and entities are generated and notes stored in per-category subfolders. An inbox view lists pending, processed and failed captures with retry and reprocess controls.
