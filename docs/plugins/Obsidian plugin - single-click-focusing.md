# Single Click Focusing

Single Click Focusing lets a single left click focus a file or folder in the file explorer and returns keyboard focus, so Enter renames immediately and the arrow keys navigate. A folder name can be selected without expanding it; the folder arrow expands or collapses it instead.

```cue
plugin: {
    id:     "single-click-focusing"
    name:   "Single Click Focusing"
    author: "thisiselijah"
    repo:   "thisiselijah/obsidian-single-click-focusing-plugin"

    html_url:    "https://community.obsidian.md/plugins/single-click-focusing"
    github_url:  "https://github.com/thisiselijah/obsidian-single-click-focusing-plugin"
    description: "Allows focusing files and folders in the file explorer with a single left click. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Focus files and folders in the file explorer with a single click, returning keyboard focus so you can immediately press Enter to rename or navigate with arrow keys. Select a folder name without expanding it; use the folder arrow to expand or collapse."
```
