# Local Media Embedder

Embeds local videos, images and audio, including MP4 and MP3, directly in notes, with several files shown as a grid or a list and picture-in-picture playback. Files outside the vault can be reached, YouTube links can be played, and clickable timestamps seek the video for synchronized notes.
