# LineRef Copier

Copies the current cursor line or a selected range as a file path plus line number, for example a note path followed by a single line or a line range. Paths can be relative or absolute and a copy notification is optional, and the recorded inputs frame the result as a location index for pasting into AI chats, issues, or tasks.

    id:     "lineref-copier"
    name:   "LineRef Copier"

Choose relative or absolute paths and optionally show a copy notification to paste exact note locations into AI chats, issues, or tasks."
