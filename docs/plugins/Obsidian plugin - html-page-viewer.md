# HTML Page Viewer

HTML Page Viewer opens HTML and HTM files as rendered pages inside Obsidian, in a sandboxed iframe that blocks forms, popups and top-level navigation and never writes to files. A source view with lightweight HTML syntax highlighting and line numbers is available, and a toolbar refreshes the page or toggles scripts per tab, with scripts off by default.

```cue
plugin: {
    id:     "html-page-viewer"
    name:   "HTML Page Viewer"
    author: "Viggo Meesters"
    repo:   "viggomeesters/obsidian-html-page-viewer"

    html_url:    "https://community.obsidian.md/plugins/html-page-viewer"
    github_url:  "https://github.com/viggomeesters/obsidian-html-page-viewer"
    description: "Open .html and .htm files in Obsidian as a sandboxed rendered preview or syntax-highlighted source. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open .html and .htm files as rendered pages inside Obsidian. Switch to a source view with lightweight HTML syntax highlighting and line numbers, and use the toolbar to refresh or toggle scripts per tab (scripts off by default). Render pages in a sandboxed iframe that blocks forms, popups, top-level navigation and never writes to files."
```
