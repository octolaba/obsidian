# Sync Cnblog

Syncs Obsidian Markdown notes to Cnblogs and publishes local images without changing the vault. New posts are uploaded and published posts updated, and the recorded About text states that Cnblogs articles are renamed automatically when the corresponding file is renamed in Obsidian.

```cue
plugin: {
    id:     "sync-cnblog"
    name:   "Sync Cnblog"
    author: "lei-ctyh"
    repo:   "lei-ctyh/obsidian-sync-cnblog"

    html_url:    "https://community.obsidian.md/plugins/sync-cnblog"
    github_url:  "https://github.com/lei-ctyh/obsidian-sync-cnblog"
    description: "Sync notes to Cnblogs."
    about:       "Sync Obsidian Markdown notes to Cnblogs (博客园) and publish local images without changing your vault. Upload new posts, update published posts, and automatically rename Cnblogs articles when files are renamed in Obsidian."

    stats: {
        downloads:  849
        updated_at: 1733539063000
    }
}
```
