# Brickset LEGO

The plugin fetches LEGO set data by set number from the Brickset API and downloads the set images. It creates a formatted Markdown note with frontmatter tags and details such as piece and minifig counts, pricing and ratings, embedding the images directly in the note.

```cue
plugin: {
    id:     "brickset-lego"
    name:   "Brickset LEGO"
    author: "mirkostanic"
    repo:   "mirkostanic/obsidian-lego"

    html_url:    "https://community.obsidian.md/plugins/brickset-lego"
    github_url:  "https://github.com/mirkostanic/obsidian-lego"
    description: "Fetches LEGO set information from Brickset API and creates formatted notes with set details and images. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Fetch LEGO set data by set number from Brickset API and download set images. Create formatted Markdown notes with frontmatter tags and rich details like pieces, minifigs, pricing, ratings, and embed images directly in the note."

    stats: {
        downloads:  145
        updated_at: 1778801179000
    }
}
```
