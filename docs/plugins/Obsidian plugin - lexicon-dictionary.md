# Dictionary Lexicon

Dictionary Lexicon looks up WordNet definitions from a modal or the context menu and inserts them into the note, with the insertion format configurable. Words and their definitions can be saved to a dedicated vocabulary file. Saved words return in flashcard-style popups on a spaced-repetition schedule for periodic practice.

```cue
plugin: {
    id:     "lexicon-dictionary"
    name:   "Dictionary Lexicon"
    author: "st-vin"
    repo:   "st-vin/obsidian-lexicon-dictionary-plugin"

    html_url:    "https://community.obsidian.md/plugins/lexicon-dictionary"
    github_url:  "https://github.com/st-vin/obsidian-lexicon-dictionary-plugin"
    description: "Look up words and improve vocabulary by using flash card style cards."
    about:       "Look up WordNet dictionary definitions and insert them into notes via a lookup modal or context menu. Save words and definitions to a dedicated vocabulary file and customize how definitions are inserted. Review saved words with spaced-repetition flashcard popups for periodic practice."

    stats: {

    }
}
```
