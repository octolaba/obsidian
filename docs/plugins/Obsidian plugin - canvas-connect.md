# Canvas Connect

Canvas Connect updates connection anchors in Canvas as nodes are moved, choosing the side that keeps the lines tidy from top, right, bottom and left. A single command optimizes all connections on the active canvas or on every open canvas, and subtle highlights mark the connections that changed.

```cue

    id:     "canvas-connect"
    name:   "Canvas Connect"
    author: "camadkins"
    repo:   "camadkins/obsidian-canvas-connect"

    github_url:  "https://github.com/camadkins/obsidian-canvas-connect"
```
