# Image Metadata

Annotates photos with Exif and other metadata directly from the image viewer screen. Descriptions are written to Exif ImageDescription and XMP dc:description for JPEG, PNG and WEBP files.

```cue
plugin: {
    id:     "image-metadata"
    name:   "Image Metadata"
    author: "alexeiskachykhin"
    repo:   "alexeiskachykhin/obsidian-image-metadata-plugin"

    html_url:    "https://community.obsidian.md/plugins/image-metadata"
    github_url:  "https://github.com/alexeiskachykhin/obsidian-image-metadata-plugin"
    description: "Annotate photos with Exif and other metadata right from the image viewer screen."
    about:       "Edit image metadata directly from the image viewer. Write Exif and XMP descriptions (Exif:ImageDescription, XMP:dc:description) for JPEG, PNG, and WEBP files."
```
