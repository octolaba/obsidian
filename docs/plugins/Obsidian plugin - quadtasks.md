# QuadTasks

Manages tasks on an interactive Eisenhower Matrix whose quadrants are Do First, Schedule, Delegate and Eliminate. Items are dragged between quadrants, captured first in a toggleable Inbox, and one quadrant is enlarged through Focus Mode. Tasks stay native Markdown, keeping their wikilinks and tags.
