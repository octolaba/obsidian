# Neo4j Graph View

Visualizes the vault's Markdown notes as an interactive Neo4j graph, styling nodes and edges by tags, folders and link types. Cypher queries run against that graph, and nodes are selectively expanded or hidden. Images display inline, and typed links and hierarchical layouts support structured navigation.
