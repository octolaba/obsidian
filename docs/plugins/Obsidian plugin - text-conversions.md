# Text Conversions

Text Conversions runs conversions over the selected text: case changes, ROT13, Base64 and URL encoding and decoding, stripping non-alphanumeric characters except spaces, and adjusting spaces, underscores or dashes. It also generates hashtags, adds spaces between characters, reverses text or word order, and converts between comma-separated items and lists.
