# Canvas Card Merger

Canvas Card Merger merges an open canvas into a single structured Markdown note with one command. Cards become ordered text blocks following arrows or a top-to-bottom, left-to-right order, groups become headings with their cards nested beneath, and files and images are embedded while links are written as URLs. Filenames are auto-incremented so an existing note is not overwritten.

```cue
plugin: {
    id:     "canvas-card-merger"
    name:   "Canvas Card Merger"
    author: "Canvas Card Merger"
    repo:   "teddycatdeath/canvas-card-merger"

    html_url:    "https://community.obsidian.md/plugins/canvas-card-merger"
    github_url:  "https://github.com/teddycatdeath/canvas-card-merger"
    description: "Merge a Canvas into a single structured Markdown note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Merge an open Canvas into a single structured Markdown note with one command. Convert cards into ordered text blocks following arrows or top-to-bottom/left-to-right, turn groups into headings with nested cards, embed files/images and write links as URLs while auto-incrementing filenames to avoid overwriting."
```
