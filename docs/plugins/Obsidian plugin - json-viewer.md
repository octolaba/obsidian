# JSON Viewer

Opens .json, .jsonl and .ndjson files in a dedicated read-only view that shows objects, arrays, strings, numbers, booleans, nulls and per-line parse errors. Content can be filtered by key, value or JSON Pointer, and navigated through a right-side outline with expand and collapse controls. Raw JSON and JSON Pointer paths can be copied, JSONL is parsed record by record, and very large files are previewed rather than loaded whole.
