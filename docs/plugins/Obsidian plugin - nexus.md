# Nexus

Nexus gives built-in chat and external AI agents direct local access to the vault, so notes are read, written, searched, organised and automated in natural language; the recorded description states that all data stays stored locally. It works with Claude, ChatGPT, Gemini and local models, connects external MCP clients, and runs its native chat on desktop and mobile. Local semantic search, ingestion, workspace memory and task management are recorded as desktop-only features.
