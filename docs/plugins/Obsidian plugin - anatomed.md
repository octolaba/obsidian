# Anatomed 3D Anatomy

Embeds interactive, region-isolated 3D anatomy models inline in notes: an anatomed code block names a region and renders a rotatable, zoomable model showing only the requested structures. A legend toggles each structure, and clicking one opens or creates its note. The models come from a validated Z-Anatomy catalogue of roughly 3,500 named structures, shown in isolated, related or regional context.

```cue
plugin: {
    id:     "anatomed"
    name:   "Anatomed 3D Anatomy"
    author: "fabijan"
    repo:   "pitfa19/anatomed-obsidian"

    html_url:    "https://community.obsidian.md/plugins/anatomed"
    github_url:  "https://github.com/pitfa19/anatomed-obsidian"
    description: "Embed interactive, region-isolated 3D anatomy in your notes. Write a region in an anatomed code block to get a rotatable, validated 3D model with a toggleable legend. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed interactive, region-isolated 3D anatomy models inline in notes. Write an anatomed code block to display a rotatable, zoomable model that shows only requested structures with a legend to toggle each; click a structure to open or create its note. Use a validated Z-Anatomy catalogue of ~3,500 named structures with isolated, related, or regional context."
```
