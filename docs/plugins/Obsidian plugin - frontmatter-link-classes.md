# Frontmatter Metadata Link Classes

Adds CSS classes to internal links based on the frontmatter metadata of the note. Boolean, string and array keys produce predictable class names such as link-publish-true or link-type-lorem-ipsum, which can then be styled with custom CSS.

```cue
plugin: {
    id:     "frontmatter-link-classes"
    name:   "Frontmatter Metadata Link Classes"
    author: "zmeeeeeva"
    repo:   "zmeeeeeva/obsidian-plugin-metadata-link-classes"

    html_url:    "https://community.obsidian.md/plugins/frontmatter-link-classes"
    github_url:  "https://github.com/zmeeeeeva/obsidian-plugin-metadata-link-classes"
    description: "Adds classes to internal links based on frontmatter metadata."
    about:       "Add CSS classes to internal links based on a note’s frontmatter metadata. Handle boolean, string, and array keys to create predictable classes (e.g. .link-publish-true, .link-tags-todo, .link-type-lorem-ipsum) for styling via custom CSS."

    stats: {
        downloads:  389

    }
}
```
