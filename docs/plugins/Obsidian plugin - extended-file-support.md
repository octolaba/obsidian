# Extended File Support

Extended File Support lets Obsidian view and embed file types it does not otherwise open, among them Krita .kra, Photoshop .psd, Illustrator .ai, Clip Studio .clip and 3D models in .gltf, .glb, .obj and .stl. The files are displayed inline in notes and in Canvas with adjustable sizing, and 3D models can be viewed interactively. They are viewed and embedded only, not edited.
