# Insert Multiple Attachments

Insert Multiple Attachments extends Obsidian's built-in Insert Attachment command so that several files can be chosen at once. The selected files are added to the current note as links or embeds in a single action.

```cue
plugin: {
    id:     "insert-multiple-attachments"
    name:   "Insert Multiple Attachments"
    author: "Michael Naumov"
    repo:   "mnaoumov/obsidian-insert-multiple-attachments"

    html_url:    "https://community.obsidian.md/plugins/insert-multiple-attachments"
    github_url:  "https://github.com/mnaoumov/obsidian-insert-multiple-attachments"
    description: "Allows to insert multiple attachments at a time."
    about:       "Insert multiple attachments at once by extending Obsidian's built-in Insert Attachment command. Select several files and add them as links or embeds into the current note in one action."
```
