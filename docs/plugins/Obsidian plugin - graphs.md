# Graphs

Creates interactive graphs from YAML written in code blocks, with built-in types including lines, functions, vector fields and 3D plots. Sliders and mathematical functions make the plots interactive, complex expressions are rendered, and a graph can be exported as SVG. Syntax highlighting and Obsidian theme support are included.

    id:     "graphs"
    name:   "Graphs"
