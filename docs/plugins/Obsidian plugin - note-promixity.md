# Lookalike

Finds notes similar to the current one by analyzing word frequencies across the vault, ranking matches by a similarity score that reflects shared terms. Results are listed in a sidebar, and any of them can be opened in the current editor with a click.

```cue
plugin: {
    id:     "note-promixity"
    name:   "Lookalike"
    author: "jlweston"
    repo:   "jlweston/obsidian-note-proximity-plugin"

    html_url:    "https://community.obsidian.md/plugins/note-promixity"
    github_url:  "https://github.com/jlweston/obsidian-note-proximity-plugin"
    description: "Find similar notes based on the frequency of terms within the vault."
    about:       "Find notes similar to the current note by analyzing word frequencies across the vault and rank matches with similarity scores indicating shared terms. Display similar notes in a sidebar and open any result in the current editor with a click."
```
