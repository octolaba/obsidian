# Age Encrypt

Age Encrypt encrypts whole files or selected text with the age encryption library and stores the ciphertext in age code blocks that stay compatible with the age command-line tool. Decrypted content is viewed and edited in memory only, so plaintext is not written to disk, and an optional hint can accompany an encrypted block.
