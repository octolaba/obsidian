# Rollover Daily Todos with Context

Rollover Daily Todos with Context carries unchecked checkbox tasks from the last daily note into today's note, working with the built-in Daily notes plugin or with Periodic Notes. The rollover runs automatically when today's note is opened, or on demand from the command palette, including a pass that gathers open todos from every past daily note at once. Yesterday's tasks can stay put, be removed after copying, or be marked forwarded with backlinks, and rolled items can be placed under a template heading with nested lines brought along. Further commands move completed tasks to the bottom of each section and undo the last rollover within two minutes.
