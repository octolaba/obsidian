# GemmaNotes

Records push-to-talk voice notes and transcribes them locally with Google's Gemma 4 through transformers.js. A placeholder is pinned in the current note and replaced by the transcript when it is ready, and transcriptions are queued so recording can continue while one is processed. The recorded text states that after a one-time model download it works offline, with no server or API key.
