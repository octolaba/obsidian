# Tezcat

Tezcat indexes notes with AI embeddings and surfaces related notes and blocks while you write, acting as a remembrance agent for recall. Matching content or links are inserted and parent pages opened. Search runs as vector or hybrid vector and full-text search, over embeddings from a local Ollama instance or from OpenAI.
