# OpenWhispr Sync

OpenWhispr Sync imports OpenWhispr notes and speaker-labeled meeting transcripts into the vault through the official OpenWhispr CLI. Which sections are imported is selectable, files are organized by date or folder, rich frontmatter is preserved, and notes are deduplicated or updated in place.

```cue
plugin: {
    id:     "openwhispr-sync"
    name:   "OpenWhispr Sync"
    author: "Sam K"
    repo:   "samkawsarani/OpenWhispr-to-Obsidian"

    html_url:    "https://community.obsidian.md/plugins/openwhispr-sync"
    github_url:  "https://github.com/samkawsarani/OpenWhispr-to-Obsidian"
    description: "Sync your OpenWhispr notes and speaker-labeled transcripts into your Obsidian vault using the OpenWhispr CLI. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync OpenWhispr notes, including speaker-labeled meeting transcripts, into an Obsidian vault using the official OpenWhispr CLI. Select which sections to import, organize files by date or folder, preserve rich frontmatter, and deduplicate or update notes in place."

    stats: {
        downloads:  21

    }
}
```
