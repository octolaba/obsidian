# Multi-Column Markdown

Arranges blocks of a note into several columns so a single-column note reads as side-by-side regions. Column count, widths, spacing and alignment are declared with Pandoc-style fenced divs or other supported syntax. The recorded text prefers Reading mode and warns that Live Preview may not render interactive or third-party plugin content.
