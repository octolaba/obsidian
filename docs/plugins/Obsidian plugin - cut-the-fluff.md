# Cut The Fluff

Marks unnecessary words and phrases, among them weak qualifiers, cliches, jargon, wordy constructions and redundancies, to make writing clearer and less cluttered. Built-in rulesets can be enabled and custom phrases and exceptions added, and matches can take different display styles or a fluff CSS class. The plugin states that all checks run locally.

```cue
plugin: {
    id:     "cut-the-fluff"
    name:   "Cut The Fluff"
    author: "adamfletcher"
    repo:   "adamfletcher/obsidian-cut-the-fluff"

    html_url:    "https://community.obsidian.md/plugins/cut-the-fluff"
    github_url:  "https://github.com/adamfletcher/obsidian-cut-the-fluff"
    description: "Make your writing clearer by checking for unnecessary complexity and clutter."
    about:       "Identify and mark unnecessary words and phrases—weak qualifiers, clichés, jargon, wordy constructions and redundancies—to make writing clearer and more concise. Process all checks locally for privacy, enable built-in rulesets or add custom phrases and exceptions, and choose display styles or apply a fluff CSS class for custom formatting."

    stats: {
        downloads:  790
        updated_at: 1778616775000
    }
}
```
