# XU Table Layout Helper

Customizes Markdown table layout, covering column widths, text wrapping, vertical alignment, overflow handling and sticky headers, through visual controls with a live preview instead of hand-written CSS snippets. Zebra stripes, borders and max-height scrolling are applied in both reading and live preview views.
