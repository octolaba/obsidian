# Dropbox Photo Grid

Embeds a responsive grid of photos held in Dropbox into a note, selected by date or by folder and file path. It handles pagination and loading states, offers an On This Day view of past photos, and matches the colours of the active Obsidian theme.

```cue
plugin: {
    id:     "dropbox-photo-grid"
    name:   "Dropbox Photo Grid"
    author: "alimoeeny"
    repo:   "alimoeeny/obsidian-dropbox-photo-grid"

    html_url:    "https://community.obsidian.md/plugins/dropbox-photo-grid"
    github_url:  "https://github.com/alimoeeny/obsidian-dropbox-photo-grid"
```
