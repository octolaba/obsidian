# HangarX

Turns the vault into a knowledge graph of entities, relationships and citations exposed over the Model Context Protocol, so Claude, Cursor and other MCP agents can query it and write findings back. It ships a chat panel that cites the vault notes behind every answer, two-way sync between vault and graph, entity highlighting on Obsidian's native graph view, inline wikilink suggestions from graph matching, and one-click MCP setup for several clients. It runs hosted or fully local with Docker and the user's own keys for providers such as OpenAI, Anthropic, Google, Mistral, Cohere, Groq, Together AI or Ollama.
