# Book Search + Covers

The plugin searches for books as the query is typed, lets a specific edition be chosen, and creates a note from a template filled with title, author, year, description and further fields together with a high-resolution cover. Covers are downloaded into the vault or linked, existing notes can be backfilled, and it runs on desktop and mobile. The recorded search sources are the Google Books API, Open Library and the Apple Store.
