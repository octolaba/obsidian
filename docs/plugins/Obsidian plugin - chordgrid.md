# Chord Grid With Rhythmic Notation

Chord Grid With Rhythmic Notation turns a simple text syntax into scalable SVG chord charts carrying rhythmic notation. Beaming, ties, tuplets, dotted notes, complex time signatures and repeats with voltas are handled automatically. Transpose tools, pick and strum patterns and optional counting are provided for rhythm learning.
