# Backgroundset

Backgroundset sets the workspace background from folders of images that you register, using either a specific image or a random one. Background changes fade in and out rather than switching abruptly.

```cue
plugin: {
    id:     "backgroundset"
    name:   "Backgroundset"
    author: "youngmoss"
    repo:   "youngmoss/obsidian-backgroundset"

    html_url:    "https://community.obsidian.md/plugins/backgroundset"
    github_url:  "https://github.com/youngmoss/obsidian-backgroundset"
    description: "Allow you to set background image set(folder)"
    about:       "Manage workspace backgrounds by adding image folders and setting specific or random images as the background. Apply smooth fade-in and fade-out transitions for seamless background changes."

    stats: {
        downloads:  2003
        updated_at: 1735461576000

}
```
