# Brain Growth

Brain Growth scans the vault's Markdown notes and takes daily local snapshots of note and body counts, tags and internal links. Trends and comparisons are shown in a dashboard and a compact right-side panel with trend cards and charts, and the recorded inputs state that all data stays local.

    id:     "brain-growth"
    name:   "Brain Growth"
    author: "raymondseek"
    repo:   "raymondseek/BrainGrowth"

    github_url:  "https://github.com/raymondseek/BrainGrowth"
