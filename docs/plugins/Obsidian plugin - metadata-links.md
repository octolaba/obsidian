# Metadata Links

Metadata Links adds metadata blocks to notes: selecting a link fetches its metadata and displays it in a structured, readable panel. Deselecting a link removes its entry, and the displayed metadata can be refreshed.

```cue
plugin: {
    id:     "metadata-links"
    name:   "Metadata Links"
    author: "ansango"
    repo:   "ansango/obsidian-metadata-links"

    html_url:    "https://community.obsidian.md/plugins/metadata-links"
    github_url:  "https://github.com/ansango/obsidian-metadata-links"
    description: "Add metadata blocks - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Select links in your notes to fetch and display their metadata in a readable, structured panel. Deselect links to remove entries and refresh the displayed metadata."

    stats: {
        downloads:  44
        updated_at: 1783668751000
    }
}
```
