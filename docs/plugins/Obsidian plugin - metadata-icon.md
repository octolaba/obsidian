# Metadata Icon

Metadata Icon sets custom icons for properties across the vault, giving fields visual cues and faster recognition. Icons are assigned from http or https URLs, from relative or absolute local file paths, or from base64-encoded data images.

    id:     "metadata-icon"
    name:   "Metadata Icon"
