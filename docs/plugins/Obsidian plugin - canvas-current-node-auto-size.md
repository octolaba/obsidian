# Canvas Current Node Auto Size

Canvas Current Node Auto Size resizes the width and height of the Canvas text node currently being edited so it fits its content. Sizing is derived from measuring rendered Markdown, so text, callouts, tables, lists and code blocks are handled, and spacing is CJK-friendly. Neighboring nodes are left untouched.
