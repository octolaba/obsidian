# Enhanced Image

Adds context-menu actions for local and remote images — copy, save as, reveal, rename, delete, move, upload or replace, and format conversion. Commands convert or delete images in batches, unused image files are previewed and removed across the vault, and HEIF and HEIC files get previews.
