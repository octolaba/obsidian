# Misskey Connector

Misskey Connector converts Misskey URLs into quoted embeds in Markdown or HTML so that notes can display them. It also posts the current line, including attached images and videos, to a Misskey account, with options for tagging, file upload limits and anonymized filenames. Misskey authentication is required.

```cue
plugin: {
    id:     "misskey-connector"
    name:   "Misskey Connector"
    author: "minimarimo3"
    repo:   "minimarimo3/Obsidian-plugin-for-Misskey"

    html_url:    "https://community.obsidian.md/plugins/misskey-connector"
    github_url:  "https://github.com/minimarimo3/Obsidian-plugin-for-Misskey"
```
