# FuzzyTag

Suggests frontmatter tags by fuzzy matching, so a close tag name is found and inserted while editing YAML frontmatter. Matches are highlighted in the suggestion list, and the recorded inputs note that tags containing angle-bracket characters may break that highlighting.

```cue
plugin: {
    id:     "obsidian-fuzzytag"
    name:   "FuzzyTag"
    author: "adriandersen"
    repo:   "adriandersen/obsidian-fuzzytag"

    html_url:    "https://community.obsidian.md/plugins/obsidian-fuzzytag"
    github_url:  "https://github.com/adriandersen/obsidian-fuzzytag"
    description: "Fuzzy match autocomplete tags in frontmatter."
    about:       "Suggest frontmatter tags using fuzzy matching to find and insert close tag names while editing YAML frontmatter. Show highlighted matches in suggestions; tags containing < or > may break highlighting."

    stats: {
        downloads:  5898
        updated_at: 1748430850000
    }
}
```
