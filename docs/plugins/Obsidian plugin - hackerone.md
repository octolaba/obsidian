# HackerOne

Fetches HackerOne bug reports into the vault and imports their details as notes. Report summaries and metadata are displayed inside notes, and Dataview can be used to generate summaries across them.

```cue
plugin: {
    id:     "hackerone"
    name:   "HackerOne"
    author: "neolex-security"
    repo:   "neolex-security/obsidian-hackerone"

    html_url:    "https://community.obsidian.md/plugins/hackerone"
    github_url:  "https://github.com/neolex-security/obsidian-hackerone"
    description: "Fetch HackerOne bug reports."
    about:       "Link HackerOne reports into your Obsidian vault and import report details as notes. Display report summaries and metadata inside notes; use Dataview to generate summaries."

    stats: {
        downloads:  3833
        updated_at: 1769626209000
    }
}
```
