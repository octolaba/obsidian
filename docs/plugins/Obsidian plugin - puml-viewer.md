# PUML Viewer

Renders PlantUML diagrams both from .puml files and from fenced markdown code blocks. The view toggles between the rendered diagram and a code editor with line numbers, and offers zoom, drag-to-pan, auto-fit, auto-refresh and reopening the last file on startup. Diagrams export as PNG, SVG or ASCII art, and rendering runs against PlantUML, Kroki or a local server.
