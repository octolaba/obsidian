# Arcadia Toolbar

Adds a word-processor-style tabbed ribbon with ten tabs, from Home, Insert and Format through Tables, Links, Media, Canvas, View and Tools to More, covering formatting, insertion and table controls. A pinned table-of-contents sidebar updates while the note is edited. A premium tier adds a Theology tab with scripture hover popups and commentary lookup, plus an AI prompt row driven by the user's own API key.
