# Link Card Preview

Turns bare URLs into rich link cards with adaptive layouts, dominant-color tinting, and offline image caching. Cards render in Reading view, Live Preview, and Canvas, native link nodes are preserved for portability, and the raw URL is revealed for editing without breaking selection or layout. The recorded description notes that the plugin has not been manually reviewed by Obsidian staff.
