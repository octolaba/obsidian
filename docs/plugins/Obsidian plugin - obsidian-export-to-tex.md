# Export To TeX

Exports vault files to LaTeX in a form meant for pasting into a .tex document, resolving embeds and stripping wiki-links. Headings and blocks receive generated LaTeX labels, internal links become reference-style links, and display math environments are handled. The result is saved to a file or copied to the clipboard.
