# Copy to WeChat

Copy to WeChat copies a note to the clipboard either as chat-friendly plain text or as a rendered PNG image. In text form headings become bracketed titles, lists become indented bullets, links become their text followed by the URL and images become a labelled placeholder, while the image form renders the note with article-style formatting preserved.

```cue
plugin: {
    id:     "copy-to-wechat"
    name:   "Copy to WeChat"
    author: "jerryshi"
    repo:   "syw2014/obsidian-copy-to-wechat"

    html_url:    "https://community.obsidian.md/plugins/copy-to-wechat"
    github_url:  "https://github.com/syw2014/obsidian-copy-to-wechat"
    description: "Copy notes to WeChat as chat-friendly plain text, or as a rendered image. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Copy notes to WeChat as chat-friendly plain text or as a rendered PNG image on the clipboard. Convert Markdown into WeChat-ready text: map headings to bracketed titles, turn lists into indented bullets, convert links to text(url) and images to [图片：alt], or render the note with article-style formatting preserved."

    stats: {
        downloads:  94
        updated_at: 1782193402000
    }
}
```
