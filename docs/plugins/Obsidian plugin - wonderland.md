# Wonderland

The plugin generates linked notes with a language model and expands them further as the reader clicks through. Notes are grouped into per-folder Wonderland collections with unresolved-link indexing and semantic enrichment, and the generation can run against OpenAI, Claude, Ollama or a custom endpoint.

```cue
plugin: {
    id:     "wonderland"
    name:   "Wonderland"
    author: "donjguido"
    repo:   "donjguido/wonderland-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/wonderland"
    github_url:  "https://github.com/donjguido/wonderland-obsidian-plugin"
    description: "Go down the rabbit hole of knowledge. AI generates linked notes that expand on click, letting you explore ideas endlessly. Features auto-organization, knowledge enrichment, and customizable Wonderland folders. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Explore ideas with AI-generated [[wikilinks]] that open interactive rabbit holes and auto-expand notes as you click through. Create multiple Wonderlands per folder, auto-organize notes, index unresolved links, enrich vault content with semantic search, and use OpenAI, Claude, Ollama or custom endpoints."
```
