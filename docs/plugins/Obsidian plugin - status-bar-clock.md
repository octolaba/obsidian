# Status Bar Clock

A live clock is shown in the Obsidian status bar and stays visible in full screen. A setting toggles seconds, switching between an hour and minute display and an hour, minute and second display that updates every second.

```cue
plugin: {
    id:     "status-bar-clock"
    name:   "Status Bar Clock"
    author: "marty331"
    repo:   "marty331/status-bar-clock-obsidian"

    html_url:    "https://community.obsidian.md/plugins/status-bar-clock"
    github_url:  "https://github.com/marty331/status-bar-clock-obsidian"
    description: "Status bar clock."
    about:       "Display a live clock in Obsidian's status bar, visible even in full-screen. Toggle seconds to switch between hour:minute AM/PM and hour:minute:second AM/PM with per-second updates."

    stats: {
        downloads:  1407
        updated_at: 1769570220000
    }
}
```
