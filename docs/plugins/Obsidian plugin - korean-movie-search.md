# Korean Movie Search

Fetches Korean movie metadata from the KOBIS and TMDB APIs using the filename and fills the note's frontmatter with title, cast, crew, genres and release information. High-resolution posters and ratings are included. The interface is available in Korean and English, and metadata fields can be toggled or added.

```cue
plugin: {
    id:     "korean-movie-search"
    name:   "Korean Movie Search"
    author: "shin-young-in"
    repo:   "younginshin115/korean-movie-search"

    html_url:    "https://community.obsidian.md/plugins/korean-movie-search"
    github_url:  "https://github.com/younginshin115/korean-movie-search"
    description: "Automatically fetch Korean movie information from KOBIS and TMDB APIs based on note title. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Fetch Korean movie metadata from KOBIS and TMDB using the filename and auto-fill the note frontmatter with title, cast, crew, genres, release info, and more. Include high-resolution posters and ratings, provide a Korean/English UI, and enable toggling or adding custom metadata fields."

}
```
