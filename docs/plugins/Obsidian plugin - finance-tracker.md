# Finance Tracker

Finance Tracker logs spending as tagged bullets inside daily notes, keeping running totals in plain Markdown rather than in a separate database. Those notes are then turned into pace-aware spending, budget, holiday and savings dashboards. Transactions are captured through Apple Shortcuts, a quick-add modal, or an inbox.
