# Embeds+

Renders and embeds HTML, MHTML, Web Archive and Evernote export files in notes, covering the .html, .mhtml, .mht, .webarchive and .enex extensions. The files are displayed natively with their full styling and support inline previews.

```cue
plugin: {
    id:     "embeds-plus"
    name:   "Embeds+"
    author: "sz-1f"
    repo:   "sz-1f/obsidian-embeds-plus"

    html_url:    "https://community.obsidian.md/plugins/embeds-plus"
    github_url:  "https://github.com/sz-1f/obsidian-embeds-plus"
    description: "Rendering & inline previews for HTML, MHTML, Web Archive & Evernote export (ENEX) files. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "View and embed HTML (`.html`), MHTML (`.mhtml`/`.mht`), Web Archive (`.webarchive`), and Evernote export (`.enex`) files natively with full styling and inline preview support."
```
