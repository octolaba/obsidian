# Snippet Commander

CSS snippets are toggled from the command palette rather than through the Settings window. Several snippets are selected and toggled at once, and the recorded inputs state that changes apply immediately with no reload or restart.

    id:     "snippet-commander"
    name:   "Snippet Commander"
    author: "ImeMine"
    repo:   "memineoff/snippet-commander"
