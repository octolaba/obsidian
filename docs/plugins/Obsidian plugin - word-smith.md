# Word-Smith

Provides a distraction-free writing mode that hides the interface chrome, focuses the active file and enters fullscreen. Typewriter scrolling and adjustable letterbox masks shape the writing area, and a retro status bar shows customisable tokens and word-goal tracking. Per-file and per-heading word counts are shown in the file explorer and the outline.
