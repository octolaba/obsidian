# Advanced new file

Advanced new file lets a target folder be chosen before a note is created, and a full path can be typed to place the file exactly. Files are created with custom extensions, defaulting to md, so canvas, json, js or other files can be made directly in the chosen folder.

```cue
plugin: {
    id:     "obsidian-advanced-new-file"
    name:   "Advanced new file"
    author: "vanadium23"
    repo:   "vanadium23/obsidian-advanced-new-file"

    html_url:    "https://community.obsidian.md/plugins/obsidian-advanced-new-file"
    github_url:  "https://github.com/vanadium23/obsidian-advanced-new-file"
    description: "Create notes in chosen folder."
    about:       "Choose a target folder before creating a new note and optionally type a full path to place the file exactly where you want. Create files with custom extensions (defaults to .md) to make .canvas, .json, .js or any other file directly in the chosen folder."

    stats: {
        downloads:  25220
        updated_at: 1749198034000
    }
}
```
