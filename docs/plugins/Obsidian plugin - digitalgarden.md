# Digital Garden

Publishes notes from the vault to a digital garden website that others can read. Only notes marked with dg-publish: true are published, so the rest stay local, and published pages carry Markdown content, embedded images, PDFs and Excalidraw drawings, backlinks, graphs, live search and themeable styling.
