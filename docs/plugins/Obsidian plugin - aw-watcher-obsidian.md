# ActivityWatch

ActivityWatch records time spent in Obsidian by sending the active vault name and the name of the open Markdown file to a local ActivityWatch server. The resulting per-file and per-vault timelines are inspected in ActivityWatch itself to see how long each note took.

```cue
plugin: {
    id:     "aw-watcher-obsidian"
    name:   "ActivityWatch"
    author: "lordgrimmauld"
    repo:   "lordgrimmauld/aw-watcher-obsidian"

    html_url:    "https://community.obsidian.md/plugins/aw-watcher-obsidian"
    github_url:  "https://github.com/lordgrimmauld/aw-watcher-obsidian"
    description: "Integrate with ActivityWatch to allow detailed tracking of time spent in Obsidian."
    about:       "Record time spent in Obsidian by sending active vault and open Markdown file names to your local ActivityWatch server. Inspect per-file and per-vault timelines in ActivityWatch to see how long you spent on each note."

    stats: {
        downloads:  9434
        updated_at: 1677153939000
    }
}
```
