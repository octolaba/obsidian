# Auto Archive

Archives notes automatically once they reach a configured age. Which notes are archived and where they are moved to are both configurable, so ageing notes leave the working part of the vault without being dragged by hand.

```cue
plugin: {
    id:     "auto-archive"
    name:   "Auto Archive"
    author: "shanedonburke"
    repo:   "shanedonburke/obsidian-auto-archive"

    html_url:    "https://community.obsidian.md/plugins/auto-archive"
    github_url:  "https://github.com/shanedonburke/obsidian-auto-archive"
    description: "Automatically archive notes once they reach a certain age."
    about:       "Archive notes automatically once they reach a specified age. Specify which notes to archive and where to move them to keep your vault organized without manual dragging."

    stats: {
        downloads:  4243
        updated_at: 1693065394000
    }
}
```
