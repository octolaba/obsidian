# Image Paste on GitHub

Uploads pasted or dropped images to a GitHub repository and inserts a raw.githubusercontent.com link instead of saving the file into the vault. The recorded inputs present this as a way to keep the vault small by storing screenshots in a public GitHub repository, and state that pasted images then become publicly accessible.

```cue
plugin: {
    id:     "image-paste-on-github"
    name:   "Image Paste on GitHub"
    author: "HyoYoonNam"
    repo:   "hyoyoonnam/image-paste-on-github"

    html_url:    "https://community.obsidian.md/plugins/image-paste-on-github"
    github_url:  "https://github.com/hyoyoonnam/image-paste-on-github"
    description: "Upload pasted images to your GitHub repository and insert the raw CDN link automatically instead of saving them locally. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Upload pasted or dropped images straight to your GitHub repository and insert raw.githubusercontent.com links instead of saving files into your vault. Keep your vault small by storing screenshots on a public GitHub repo — pasted images become publicly accessible."

    stats: {
        downloads:  74
        updated_at: 1782483854000
    }
}
```
