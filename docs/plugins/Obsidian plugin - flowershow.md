# Publish with Flowershow

Publishes notes from the vault online through Flowershow. Publication status is shown for changed, new, deleted and unchanged files, and either selected notes or the site update as a whole are published. A local custom stylesheet and configuration file are included for styling and configuration.

```cue
plugin: {
    id:     "flowershow"
    name:   "Publish with Flowershow"
    author: "flowershow"
    repo:   "flowershow/obsidian-flowershow"

    html_url:    "https://community.obsidian.md/plugins/flowershow"
    github_url:  "https://github.com/flowershow/obsidian-flowershow"
    description: "Publish notes with Flowershow."
    about:       "Publish your Obsidian vault online directly from Obsidian with Flowershow. View publication status for changed, new, deleted, and unchanged files, publish selected notes or site updates, and include local custom.css and config.json for styling and configuration."

    stats: {
        downloads:  8038
        updated_at: 1783879385000
    }
}
```
