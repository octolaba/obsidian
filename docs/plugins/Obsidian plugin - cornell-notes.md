# Cornell Notes

Cornell Notes renders fenced blocks that use cue and note markers into a responsive two-column Cornell layout in Reading view. Both columns accept full Markdown, including code blocks, callouts, math, mermaid diagrams, images and wikilinks. The source stays plain text and remains editable without the plugin.

```cue
plugin: {
    id:     "cornell-notes"
    name:   "Cornell Notes"
    author: "Sergii Krymets"
    repo:   "bytetiles/obsidian-cornell-notes"

    html_url:    "https://community.obsidian.md/plugins/cornell-notes"
    github_url:  "https://github.com/bytetiles/obsidian-cornell-notes"
    description: "Renders two-column Cornell Notes layouts. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render Cornell Notes from 4-backtick fenced blocks using ::cue and ::note markers into a responsive two-column layout in Reading view. Allow full Markdown in both columns — including code blocks, callouts, math, mermaid diagrams, images, and wikilinks — while keeping the source as plain text editable without the plugin."

    stats: {
        downloads:  1686
        updated_at: 1780718663000
    }
}
```
