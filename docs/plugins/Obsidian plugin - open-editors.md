# Open Editors

Open Editors adds a view listing the open windows, groups, tabs and the editors inside them. Every editor in a window or group can be closed at once, and switching between open editors runs from the same view.

```cue
plugin: {
    id:     "open-editors"
    name:   "Open Editors"
    author: "4source"
    repo:   "4source/open-editors-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/open-editors"
    github_url:  "https://github.com/4source/open-editors-obsidian-plugin"
    description: "Adds a view which shows the opened windows, groups, tabs and editors inside them. Makes managing the open editors easier."
    about:       "Display a hierarchical view of open windows, groups, tabs, and editors to manage open files at a glance. Close all editors in a window or group at once and switch quickly between editors."

    stats: {
        downloads:  951
        updated_at: 1773666978000
    }
}
```
