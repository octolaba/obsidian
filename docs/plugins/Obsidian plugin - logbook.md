# Logbook

Tracks time on tasks with org-mode LOGBOOK-style clock entries written as plain Markdown inline fields that Dataview can query. Clocking in and out happens on a task line, reports are available per file, and open clocks are found across the vault. The recorded text states that all data stays local, with no external services.

    id:     "logbook"
    name:   "Logbook"
    author: "p1tt1"
