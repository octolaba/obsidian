# Tekken Notation

Tekken Notation renders Tekken move notations as diagrams from fenced code blocks written in a tekken language tag. Named combos are supported, along with appended information text such as damage and with custom text tokens. Combo arrows and brackets mark the visual sequence.

```cue
plugin: {
    id:     "tekken-notation"
    name:   "Tekken Notation"
    author: "opti9"
    repo:   "opti9/obsidian-tekken-notation"
```
