# S3 attachments storage

S3 attachments storage keeps media attachments in S3-compatible buckets and serves them to notes through generated links for images, video and audio. Uploads happen on paste, on drag-and-drop, or when an attachment is added. Commands delete unused files, show bucket size, rename links and run parallel retries, and the recorded text mentions static-site hosting and optional local caching.
