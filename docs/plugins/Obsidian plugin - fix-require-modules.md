# CodeScript Toolkit

Runs JavaScript and TypeScript scripts from inside Obsidian across DevTools, CustomJS, dataviewjs, QuickAdd, Templater, JS Engine and module scripts, using modern ESM and modular patterns. Scripts are invoked through commands or hotkeys. The same setup is used to prototype Obsidian plugins and to explore the Obsidian API at runtime.
