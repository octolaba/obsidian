# Simple RSS

Simple RSS collects RSS articles into notes, creating a note per feed item from Mustache templates for the title and the content. Custom feed types and fields can be defined, each feed given its own folder, and pulls scheduled so updates are imported automatically.

```cue
plugin: {
    id:     "simple-rss"
    name:   "Simple RSS"
    author: "monnierant"
    repo:   "monnierant/obsidian-simple-rss"

    html_url:    "https://community.obsidian.md/plugins/simple-rss"
    github_url:  "https://github.com/monnierant/obsidian-simple-rss"
    description: "Collect RSS articles into notes."
    about:       "Pull RSS feeds into your vault and create notes from feed items using Mustache templates for titles and content. Define custom feed types and fields, set per-feed folders, and schedule automatic pulls to import updates."

    }
}
```
