# URL Display

Extracts the external URLs of the active note, Kanban boards included, and lists them in a dedicated pane with favicon and hover-preview support. The list refreshes when the active note changes, or it can be locked in place. A context menu navigates to the location of a link, opens it in a browser tab, copies the URL, or runs a global search for it.
