# Shopping List

Shopping List renders the checkboxes of the current note as an interactive shopping list from its own code block. Items toggle live in the underlying Markdown and a single button clears all completed entries. Theme styling is respected, and different bullet styles and indents work on desktop and mobile.

```cue
plugin: {
    id:     "shopping-list"
    name:   "Shopping List"
    author: "mr-flannery"
    repo:   "mr-flannery/obsidian-shopping-list-plugin"

    html_url:    "https://community.obsidian.md/plugins/shopping-list"
    github_url:  "https://github.com/mr-flannery/obsidian-shopping-list-plugin"
    description: "Renders interactive shopping lists from ```shopping-list code blocks. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render all checkboxes from the current note as an interactive shopping list. Toggle items live in the underlying Markdown and clear all completed entries with a single button. Respect theme styling and support different bullet styles, indents, desktop and mobile."

    stats: {
        downloads:  134
        updated_at: 1775461853000
    }
}
```
