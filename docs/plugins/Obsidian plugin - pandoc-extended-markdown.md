# Pandoc Extended Markdown

Renders Pandoc extended Markdown syntax in Obsidian: superscripts, subscripts and escaped spaces across paragraphs, lists and definition lists. Fancy lists with alphabetic, roman and hash auto-numbering come with autocompletion and auto-renumbering, and example lists support cross-references with live-preview rendering.

```cue
plugin: {
    id:     "pandoc-extended-markdown"
    name:   "Pandoc Extended Markdown"
    author: "errortzy"
    repo:   "errortzy/obsidian-pandoc-extended-markdown"

    html_url:    "https://community.obsidian.md/plugins/pandoc-extended-markdown"
    github_url:  "https://github.com/errortzy/obsidian-pandoc-extended-markdown"
    description: "Render Pandoc extended markdown syntax: fancy lists, definition lists, example lists with cross-references, superscripts, and subscripts."
    about:       "Render Pandoc Extended Markdown in Obsidian, including superscripts (^text^), subscripts (~text~), and escaped spaces across paragraphs, lists, and definition lists. Provide fancy lists (alpha, roman, hash auto-numbering), autocompletion and auto-renumbering, plus example lists with cross-references and live-preview rendering."
```
