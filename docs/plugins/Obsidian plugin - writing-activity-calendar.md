# Writing Activity Calendar

Records net words written across the Markdown files of a vault and renders them as a GitHub-style yearly heatmap with Sunday-first weekday and month alignment. One contribution is counted per 100 net words per day, with writes and deletions balanced against each other. A local contribution log keeps note, heading, preview and timestamp context, and a heatmap code block embeds a given year in a note.

    id:     "writing-activity-calendar"
    name:   "Writing Activity Calendar"
    author: "soul"
    repo:   "mershedsoulaiman/obsidian-heatmap"
