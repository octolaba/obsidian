# Town Forge

Town Forge procedurally generates fantasy landscape and settlement maps for tabletop RPGs from a seed and a few choices, drawing terrain, rivers, coasts, lakes, mountains, forests, roads, landmarks and settlements from hamlet to metropolis. Maps are embedded through a town-forge code block or built in the live preview panel and then inserted as an image, saved as PNG, or exported as interactive pinned maps and notes to TTRPG Tools. The same seed always reproduces the same map.
