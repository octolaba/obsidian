# Auto Move On Property

Auto Move On Property moves notes into folders according to a YAML frontmatter value. Property and value pairs are mapped to destination folders, and the vault root together with chosen folders is watched for matching single or list values.

```cue
plugin: {
    id:     "auto-move-on-property"
    name:   "Auto Move On Property"
    author: "Soul"
    repo:   "soulbits-vibe/Obsidian-Auto-Move-On-Property"

    html_url:    "https://community.obsidian.md/plugins/auto-move-on-property"
```
