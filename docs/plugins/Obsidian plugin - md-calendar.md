# MD Calendar

Embeds a full calendar inside a single Markdown note: an md-calendar code block renders switchable month, week, day and agenda views. Events and tasks carry recurrence, colors, notes, drag-to-reschedule and keyboard control. All data lives inside that one block as JSON, so the calendar stays self-contained in the file.

```cue
plugin: {
    id:     "md-calendar"
    name:   "MD Calendar"
    author: "mrrepac"
    repo:   "mrrepac/obsidian-md-calendar"

    html_url:    "https://community.obsidian.md/plugins/md-calendar"
    github_url:  "https://github.com/mrrepac/obsidian-md-calendar"
    description: "A full calendar in a single Markdown note: month/week/day/agenda views with events, tasks, recurrence, colors, drag-to-reschedule and keyboard control, all stored in one code block. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed a self-contained calendar in a single Markdown file by inserting an md-calendar code block and render switchable Month/Week/Day/Agenda views. Create and manage events and tasks with recurrence, colors, notes, and drag-to-reschedule, storing all data inside the block's JSON."
```
