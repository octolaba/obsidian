# Social Network Analysis

The vault's note network is analysed with centrality measures — degree, betweenness, eigenvector, closeness, PageRank and harmonic — and with clustering coefficients, to surface central notes and communities. Graphs are drawn with force-directed layouts, link direction and weight are inspected, and the analysis results are exported to Markdown automatically.
