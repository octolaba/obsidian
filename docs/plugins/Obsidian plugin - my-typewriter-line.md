# My Typewriter Line

Keeps the active line at a chosen vertical position by setting top and bottom editor scroll padding from a single slider. The bottom padding can be calculated automatically so the two values always add up to 100vh, giving a consistent typewriter effect.

```cue

    id:     "my-typewriter-line"
    name:   "My Typewriter Line"
    author: "dmo-code"
    repo:   "dmo-code/MyTypewriterLine"

    github_url:  "https://github.com/dmo-code/MyTypewriterLine"
```
