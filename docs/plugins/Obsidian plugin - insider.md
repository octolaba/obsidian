# Insider

Insider turns YouTube videos, web pages, PDFs and direct questions into structured research notes carrying summaries, transcripts and source snapshots. Each new note is linked automatically to related vault content, either by keyword overlap or by letting the model explore vault snapshots through DeepSeek over an OpenAI-compatible API.
