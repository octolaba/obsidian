# BibLib

BibLib keeps bibliographic references as Markdown notes whose CSL-JSON metadata lives in YAML frontmatter, so each reference stays a plain-text file that suits version control. Metadata is fetched by DOI, ISBN, PubMed, arXiv or URL, or received from the Zotero browser connector, and bibliographies are exported as CSL-JSON or BibTeX for Pandoc.

```cue
plugin: {
    id:     "biblib"
    name:   "BibLib"
    author: "callumalpass"
    repo:   "callumalpass/obsidian-biblib"

    html_url:    "https://community.obsidian.md/plugins/biblib"
    github_url:  "https://github.com/callumalpass/obsidian-biblib"
    description: "Create literature notes and manage bibliographic references"
    about:       "Manage bibliographic references as Markdown notes with CSL‑JSON metadata in YAML frontmatter, keeping each reference as a plain-text, git-friendly file in your vault. Fetch metadata via DOI, ISBN, PubMed, arXiv or URL, receive references from the Zotero browser connector, and export bibliographies as CSL‑JSON or BibTeX for Pandoc."
```
