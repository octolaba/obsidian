# Miniflux RSS View

Miniflux RSS View reads Miniflux RSS entries inside Obsidian through a dedicated view that browses unread, all or starred entries, with search, refresh and paging. Articles open in Obsidian's Web viewer, and unread entries are marked as read automatically once opened.

```cue
plugin: {
    id:     "miniflux-rss-view"
    name:   "Miniflux RSS View"
    author: "shendongchun"
    repo:   "adoom2017/miniflux-rss-view"

    html_url:    "https://community.obsidian.md/plugins/miniflux-rss-view"
    github_url:  "https://github.com/adoom2017/miniflux-rss-view"
    description: "Read Miniflux RSS entries and open articles in Obsidian Web viewer. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Read Miniflux RSS entries inside Obsidian. Open a dedicated RSS view to browse unread, all, or starred entries, search, refresh, and load more pages. Open articles in Obsidian's Web viewer and auto-mark unread entries as read after opening."

    stats: {
        downloads:  89
        updated_at: 1779181646000
    }
}
```
