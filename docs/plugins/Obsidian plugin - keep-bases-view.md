# Keep Bases View

Displays Bases notes in a Google Keep-style masonry grid, with responsive cards and a column count that adjusts automatically. Notes can be pinned into a separate section at the top, cards color-coded, and cover images and body previews shown. A context menu offers quick actions such as open, pin or unpin, change color and delete.
