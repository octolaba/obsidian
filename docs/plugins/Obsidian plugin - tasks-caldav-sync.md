# Tasks CalDAV Sync

Tasks CalDAV Sync synchronizes obsidian-tasks with CalDAV servers in both directions, converting task status, dates, priorities, recurrence, tags and indented notes into VTODO items. Tags can be mapped to several calendars, and synchronization runs automatically or as a dry-run preview. Conflicts and deletions are detected and duplicates reconciled.
