# Copy Block Link

Copy Block Link gets links to blocks and headings from Obsidian's right-click menu. The copied link is pasted to reference, share or navigate to that exact location within the vault.

    id:     "obsidian-copy-block-link"
    name:   "Copy Block Link"
    author: "mgmeyers"
    repo:   "mgmeyers/obsidian-copy-block-link"

    html_url:    "https://community.obsidian.md/plugins/obsidian-copy-block-link"
