# Cite

Renders LaTeX and Pandoc citations from BibTeX blocks held in dedicated reference notes, turning them into numbered internal links and a lightweight bibliography. Citation keys are completed while typing and resolved from those notes, and the index is rebuilt automatically as the references change. It works in Live Preview and in Reading view.

```cue
plugin: {
    id:     "cite"
    name:   "Cite"
    author: "Pixel"
    repo:   "pmgwork/obsidian-cite"

    html_url:    "https://community.obsidian.md/plugins/cite"
    github_url:  "https://github.com/pmgwork/obsidian-cite"
    description: "Render and link LaTeX or Pandoc citations from BibTeX blocks in your notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render LaTeX (\\cite{key}) and Pandoc ([@key]) citations as numbered internal links and generate a lightweight bibliography from BibTeX blocks in dedicated reference notes. Complete citation keys while typing, resolve entries from notes, and reindex automatically as references change; works in Live Preview and Reading view."
```
