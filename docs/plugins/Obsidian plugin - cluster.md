# Cluster

Organizes notes into parent and child clusters, so hierarchical structures can be built and navigated and relationships found. Clusters are managed from in-note buttons and the ribbon, CLUSTERS and ORPHANS folders are created automatically, and the controls are made for mobile devices while also working on desktop.
