# TaskNotes Agenda Wrapper

TaskNotes Agenda Wrapper shows today's TaskNotes agenda in a sidebar pane or embedded in a note, with collapsible unplanned, overdue and upcoming day groups and stat tiles counting todo, overdue and unplanned items. Tasks can be added quickly in TaskNotes format, and a note opened or its status changed from the widget. It reads TaskNotes data at runtime and therefore requires the TaskNotes plugin.

```cue
plugin: {
    id:     "tasknotes-agenda-wrapper"
    name:   "TaskNotes Agenda Wrapper"
    author: "toyotathief"
    repo:   "toya-co/tasknotes-agenda-wrapper"

    html_url:    "https://community.obsidian.md/plugins/tasknotes-agenda-wrapper"
    github_url:  "https://github.com/toya-co/tasknotes-agenda-wrapper"
    description: "A simple, styled Today's Agenda window for TaskNotes — stats, a date-grouped list, and quick task entry, for a sidebar pane or embedded in a note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display today's TaskNotes agenda in a sidebar pane or embedded block with collapsible Unplanned, Overdue, and upcoming day groups and stat tiles for Todo, Overdue, and Unplanned counts. Add quick TaskNotes-formatted tasks, open notes or change task status from the widget, and read TaskNotes data at runtime (requires TaskNotes plugin)."
```
