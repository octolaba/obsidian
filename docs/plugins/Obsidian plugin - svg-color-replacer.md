# SVG Color Replacer

Replaces black with white in SVG rendered from LaTeX so the output stays readable in dark mode. The recorded About text describes adapting SVG images and mathematical formula colors to the active Obsidian theme, replacing white with the background color and black with white across fill, stroke and color attributes, inline styles, text elements and data-URL SVGs. Processed elements are marked so they are not handled twice.
