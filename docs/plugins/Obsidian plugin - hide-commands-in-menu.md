# Hide Commands in Menu

Hide Commands in Menu removes chosen commands from Obsidian context menus, including commands contributed by community plugins, matching them by plain text or by regex pattern. Redundant separators are removed automatically, and CSS classes are injected so hidden items can be styled or targeted per menu type.

    id:     "hide-commands-in-menu"
    name:   "Hide Commands in Menu"
    author: "bomian98"
