# Vault Clone

Creates a new vault by cloning the theme and configuration of an existing one, then opens it immediately. Appearance, behavior and plugin settings are copied selectively — themes, fonts, hotkeys, editor preferences, core and community plugins and their configs — without editing .obsidian files by hand.
