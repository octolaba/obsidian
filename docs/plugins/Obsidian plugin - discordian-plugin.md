# Discordian Theme

Exposes settings for the Discordian theme in the Obsidian settings panel. Writer Mode and Flat Andy Mode can be toggled, Paragraph Focus enabled with an adjustable fade-out, readable line length and dark note headers set, and font sizes adjusted for notes and the file explorer.

```cue
plugin: {
    id:     "discordian-plugin"
    name:   "Discordian Theme"
    author: "radekkozak"
    repo:   "radekkozak/discordian-plugin"

    html_url:    "https://community.obsidian.md/plugins/discordian-plugin"
    github_url:  "https://github.com/radekkozak/discordian-plugin"
```
