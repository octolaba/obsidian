# Link Maintainer

Maintains note links when notes are split or reorganized, updating block references so they do not break after block IDs move. A single command scans and rewrites those references across Markdown notes and Canvas files to keep link integrity.

```cue
plugin: {
    id:     "link-maintainer"
    name:   "Link Maintainer"
    author: "wenlzhang"
    repo:   "wenlzhang/obsidian-link-maintainer"

    html_url:    "https://community.obsidian.md/plugins/link-maintainer"
    github_url:  "https://github.com/wenlzhang/obsidian-link-maintainer"
    description: "Maintain note links when splitting or reorganizing notes."
    about:       "Update block references when splitting or reorganizing notes to prevent broken links after block IDs move. Scan and rewrite references across Markdown notes and Canvas files with a single command to preserve link integrity."
```
