# Guozha AI Pro

Provides a sidebar chat against OpenAI-compatible models, with streaming replies and image input for multimodal requests. Generated images are saved into the vault, and the assistant can read and edit notes once permission is given. Changes are synced across devices over WebDAV, with two-way sync and conflict handling.
