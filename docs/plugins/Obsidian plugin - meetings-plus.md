# Meetings Plus

Subscribes to ICS calendar feeds and lists the day's meetings in a sidebar sorted by time. A meeting note is created in one click with attendees, time, location and agenda pre-filled, and existing notes are opened from the same list. Optional pre-meeting reminders and daily-note insertion are available and Templater is supported; the recorded text states that ICS feeds are fetched directly over HTTPS and that neither Outlook nor drag-and-drop is required.
