# Task Deck

Task Deck presents a compact kanban board in which every card is a real Markdown note in the vault. Lists and cards are created inline and reordered by drag-and-drop, global colored labels are applied, and checklists with start and due dates are attached. Card details render as Markdown and stay in sync with the underlying note.
