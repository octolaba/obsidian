# Knowlery

Turns the vault into an LLM wiki aimed at Claude Code and OpenCode workflows, built around KNOWLEDGE.md, SCHEMA.md, entity pages and structured layouts. Bundled skills and SCHEMA.md are kept in sync automatically. It can review the current note, generate weekly atlases and run vault health diagnostics.
