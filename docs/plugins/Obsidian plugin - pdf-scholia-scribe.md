# PDF Scholia Scribe

Supports citation-focused PDF annotation and note-linking, keeping exact-selection links to a passage while showing quiet citation labels instead of long file and page links. Passages can be copied as author-date, APA or Harvard, numbered or quoted citations with the PDF link hidden, PDF page labels are preferred, Zotero metadata can be pulled in, and a managed References section is generated.
