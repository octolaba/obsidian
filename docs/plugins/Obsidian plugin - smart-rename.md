# Smart Rename

Smart Rename renames a note and keeps the previous title as an alias on the renamed file. Wiki and Markdown links are updated to point at the new filename while the old display text is preserved, so existing backlinks keep working.

```cue
plugin: {
    id:     "smart-rename"
    name:   "Smart Rename"
    author: "Michael Naumov"
    repo:   "mnaoumov/obsidian-smart-rename"

    html_url:    "https://community.obsidian.md/plugins/smart-rename"
    github_url:  "https://github.com/mnaoumov/obsidian-smart-rename"
    description: "Rename notes keeping previous title in existing links."
    about:       "Rename notes and add the previous title as an alias on the renamed file. Update wiki and Markdown links to point to the new filename while preserving the old display text and keeping backlinks intact."

    stats: {
        downloads:  14294

}
```
