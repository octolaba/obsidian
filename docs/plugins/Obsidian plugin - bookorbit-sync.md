# BookOrbit Sync

BookOrbit Sync pulls highlights and annotations from a self-hosted BookOrbit server into the vault as one note per book, updating incrementally as new highlights arrive. Optional frontmatter and extra metadata such as highlight time, color, chapter and book covers can be included, and syncing runs manually or automatically.
