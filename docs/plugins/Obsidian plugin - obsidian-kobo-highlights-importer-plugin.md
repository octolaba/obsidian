# Kobo Highlights Importer

Imports highlights and notes from a Kobo device by reading its KoboReader.sqlite database into the vault. Eta.js templates customize the output, which can include book metadata, chapters, creation dates and personal notes, and a Markdown file is generated for each book.

    id:     "obsidian-kobo-highlights-importer-plugin"
