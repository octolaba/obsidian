# Recall

This plugin adds spaced repetition review to the vault and is configurable across several algorithms. Notes or whole folders can be tracked and untracked without altering the files, since the review data is kept separately. Each note's review status is shown in the status bar.

```cue
plugin: {
    id:     "obsidian-recall"
    name:   "Recall"
    author: "martin-jw"
    repo:   "martin-jw/obsidian-recall"

    html_url:    "https://community.obsidian.md/plugins/obsidian-recall"
    github_url:  "https://github.com/martin-jw/obsidian-recall"
    description: "A flexible and configurable spaced repetition plugin with multiple algorithms to choose from."
    about:       "Add spaced repetition review to your vault using any SRS algorithm. Track and untrack notes or whole folders without altering files, keep review data separately, and view per-note review status in the status bar."

    stats: {
        downloads:  11351
        updated_at: 1619710422000
    }
}
```
