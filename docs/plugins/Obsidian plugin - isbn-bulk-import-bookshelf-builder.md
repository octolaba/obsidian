# ISBN Bulk Import Bookshelf Builder

ISBN Bulk Import Bookshelf Builder manages a bookshelf from ISBNs, reading them from back-cover photos through barcode detection with a macOS OCR fallback and exporting them to CSV for bulk import. Metadata is fetched from NDL, Google Books and Open Library, and WebP covers are downloaded and cached locally with high-resolution refresh and provider fallback. The resulting book notes are editable and organized into Want to read, Reading and Finished views.
