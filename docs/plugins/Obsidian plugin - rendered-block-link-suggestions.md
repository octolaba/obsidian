# Rendered Block Link Suggestions

Renders Markdown inside Obsidian's built-in block link suggestions, so formatted blocks and embedded content are previewed while typing. The suggestion workflow itself is unchanged; the rendered preview only makes it easier to identify the right block.

```cue
plugin: {
    id:     "rendered-block-link-suggestions"
    name:   "Rendered Block Link Suggestions"
    author: "ryotaushio"
    repo:   "ryotaushio/obsidian-rendered-block-link-suggestions"

    html_url:    "https://community.obsidian.md/plugins/rendered-block-link-suggestions"
    github_url:  "https://github.com/ryotaushio/obsidian-rendered-block-link-suggestions"
    description: "Upgrade Obsidian's built-in link suggestions with block Markdown rendering."
    about:       "Render Markdown in block-link suggestions to preview formatted blocks and embedded content while typing. Maintain Obsidian's suggestion workflow while showing rendered previews to make it easier to identify the right block."

    stats: {
        downloads:  8822
        updated_at: 1702549573000
    }
}
```
