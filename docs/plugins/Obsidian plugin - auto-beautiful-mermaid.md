# Auto Beautiful Mermaid

Routes each Mermaid diagram to one of two renderers: flowchart, sequence, state, class, ER and XY charts are drawn as theme-aware SVG by beautiful-mermaid, while every other diagram type falls back to the built-in Obsidian Mermaid engine so its interactivity survives. A block can be switched between Beautiful, System, Both and Source modes, light and dark themes are followed automatically, and both Reading view and Live Preview are supported.
