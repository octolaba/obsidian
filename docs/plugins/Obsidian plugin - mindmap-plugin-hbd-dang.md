# Mind Map Visual

Mind Map Visual is a brainstorming-focused mind map editor whose maps stay readable as Markdown notes, with automatic layout and keyboard-first editing. Nodes can be added, moved, merged, grouped, connected, collapsed and linked, and the canvas supports pan, zoom, fit, undo and redo. Maps export to PNG, JPEG or PDF and are saved locally as Markdown with YAML frontmatter.
