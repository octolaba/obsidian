# Masking Type

Masking Type hides bold, italic and highlighted text in reading mode to turn a note into memorization material. Masked areas are revealed by clicking or hovering, with optional blur or peek hints. Masks can be converted into cloze tests when exporting to PDF, and masking is configurable per note.
