# Pane Relief

Gives each tab its own browser-style navigation history that survives restarts, with hotkeys and commands to move, switch and rearrange tabs and windows. Tabs can be maximized, sidebar focus locked, and closing a tab activates an adjacent one; a sliding-panes mode stacks tabs.
