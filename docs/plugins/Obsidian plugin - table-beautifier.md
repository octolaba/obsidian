# Table Beautifier

Converts ASCII and Unicode box-drawing tables into Markdown tables. Columns are padded for visual alignment and code-like identifiers in PascalCase, snake_case or dot notation are wrapped in backticks. The recorded About text names terminal output from Docker, psql, MySQL and Claude Code among the sources it handles.
