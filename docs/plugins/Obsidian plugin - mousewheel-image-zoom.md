# Mousewheel Image zoom

Resizes images in preview mode when a modifier key is held and the mouse wheel is scrolled. The modifier defaults to left Alt and is configurable, and the image size changes as the wheel turns.

```cue
plugin: {
    id:     "mousewheel-image-zoom"
    name:   "Mousewheel Image zoom"
    author: "nicojeske"
    repo:   "nicojeske/mousewheel-image-zoom"

    html_url:    "https://community.obsidian.md/plugins/mousewheel-image-zoom"
    github_url:  "https://github.com/nicojeske/mousewheel-image-zoom"
    description: "Increase or decrease the size of an image by scrolling."
    about:       "Zoom images in preview mode by holding a configurable modifier key (default left Alt) and scrolling the mouse wheel. Adjust image size smoothly on the fly and change the modifier key to match your workflow."
```
