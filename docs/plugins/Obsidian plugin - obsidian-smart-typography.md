# Smart Typography

While you type, straight quotes, ellipses, arrows, dashes, common fractions and comparison operators are converted into typographic characters. Backspace undoes a conversion, and the quote and arrow replacements are customizable.

```cue
plugin: {
    id:     "obsidian-smart-typography"
    name:   "Smart Typography"
    author: "mgmeyers"
    repo:   "mgmeyers/obsidian-smart-typography"

    html_url:    "https://community.obsidian.md/plugins/obsidian-smart-typography"
    github_url:  "https://github.com/mgmeyers/obsidian-smart-typography"
    description: "Convert quotes to curly quotes, dashes to em dashes, and periods to ellipses."
    about:       "Convert straight quotes, ellipses, arrows, dashes, common fractions and comparison operators into typographic characters as you type. Allow undo with backspace and provide customizable replacements for quotes and arrow symbols."

    stats: {
        downloads:  161738

}
```
