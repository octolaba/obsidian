# Command Block List

Command Block List hides unwanted commands from the command palette by putting them on a block list. The list is a simple editable set of blocked commands, which is how the palette is kept uncluttered.

```cue
plugin: {
    id:     "command-block-list"
    name:   "Command Block List"
    author: "ryotaushio"
    repo:   "ryotaushio/obsidian-command-block-list"

    html_url:    "https://community.obsidian.md/plugins/command-block-list"
    github_url:  "https://github.com/ryotaushio/obsidian-command-block-list"
    description: "Hide unwanted commands from the command palette."
    about:       "Hide unwanted commands from the command palette by adding them to a block list. Streamline the palette and reduce clutter with a simple, editable list of blocked commands."
```
