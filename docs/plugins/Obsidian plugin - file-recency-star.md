# File Recency Star

File Recency Star marks recently created and recently modified files in the file explorer, by default a green star for files created within one day and a yellow star for files modified within one day. The two thresholds are set independently, and the icon, its color and its position are configurable. Icons can be turned off in favour of title-only labels, and the labels switch between Korean and English automatically.

```cue
plugin: {
    id:     "file-recency-star"
    name:   "File Recency Star"
    author: "Keeho Song"
    repo:   "songkeeh/obsidianstar"

    html_url:    "https://community.obsidian.md/plugins/file-recency-star"
    github_url:  "https://github.com/songkeeh/obsidianstar"
    description: "Adds a green star to files created within 1 day, and a yellow star to files modified within 1 day. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Mark recently created and modified files in the file explorer with configurable markers and title styling. Set independent time thresholds for new vs modified files, pick icon, color and position, toggle icons or use title-only labels, and auto-switch Korean/English labels."

    stats: {
        downloads:  105
        updated_at: 1779533113000
    }
}
```
