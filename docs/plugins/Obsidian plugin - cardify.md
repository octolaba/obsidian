# Cardify

Cardify splits the active note into cards at a chosen separator and writes each chunk to its own Markdown file, preserving frontmatter. Missing internal links are assigned and inserted, pages are named by position or by an extracted comment, and the created files land in a folder so they can be dragged onto Canvas.

```cue
plugin: {
    id:     "cardify"
    name:   "Cardify"
    author: "joshuakto"
    repo:   "joshuakto/obsidian-cardify"

    html_url:    "https://community.obsidian.md/plugins/cardify"
    github_url:  "https://github.com/joshuakto/obsidian-cardify"
    description: "Create links for blocks in a Markdown file and generate Markdown file for each link within a folder. Enabling drag-and-drop of cards onto canvas."
    about:       "Split the active note into separate cards using a chosen separator and create a new Markdown file for each chunk while preserving frontmatter. Assign and insert internal links when missing, name pages by position or extracted comments, and store created files in a folder for easy drag-and-drop onto Canvas."

    stats: {
        downloads:  5604
        updated_at: 1709003803000
    }
}
```
