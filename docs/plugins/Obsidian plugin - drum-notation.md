# Drum Notation

Renders drum kit patterns as SVG percussion staff notation and plays them back with adjustable tempo and a metronome count-in. Patterns are edited in an interactive grid editor, and ready-made notation blocks can be inserted or embedded read-only for setlists, export and tempo training.

    id:     "drum-notation"
    name:   "Drum Notation"
    author: "Viktor Kamolov"

Edit patterns with an interactive grid editor, insert ready-made notation blocks, and embed read-only rendered drums for setlists, export, and tempo training."
