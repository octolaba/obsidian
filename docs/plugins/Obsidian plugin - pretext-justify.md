# Pretext Justify

Justifies reading-view text with Knuth-Plass line breaking to produce typographically balanced paragraphs. Inline formatting is preserved, optional soft-hyphenation is supported, text reflows on resize, and the plugin runs fully offline. It aims to prevent rivers and to avoid overly tight or overly stretched lines.
