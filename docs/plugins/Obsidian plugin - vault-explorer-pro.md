# Vault Explorer Pro

Extends the sidebar with shortcut icons on folders, inline mounting of related files as nested items, and folders that can be locked or hidden. A per-folder display limit auto-collapses the excess when a folder holds many files. Source mode and the collapsing of frontmatter can be switched on automatically while editing.
