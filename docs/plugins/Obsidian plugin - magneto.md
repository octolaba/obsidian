# magneto

Syncs the vault to a GitHub repository from mobile or desktop without Git being installed locally. All files including images and PDFs are pushed and pulled, private repositories are supported, folders or files can be excluded, and syncs can be scheduled at regular intervals.

```cue
plugin: {
    id:     "magneto"
    name:   "magneto"
    author: "vishal-go"
    repo:   "vishal-go/magneto"

    html_url:    "https://community.obsidian.md/plugins/magneto"
    github_url:  "https://github.com/vishal-go/magneto"
    description: "MAGNETO — Markdown And Git Notes Export, Track Origin. Sync your vault to GitHub (mobile + desktop, no Git required). - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync your Obsidian vault to a GitHub repository from mobile or desktop without installing Git locally. Push and pull all files (including images and PDFs), use private repos, exclude folders or files, and schedule automatic syncs at regular intervals."

    stats: {
        downloads:  102

    }
}
```
