# Smart Templates

Markdown templates become reusable AI workflows that pair vault context with a template to build a consistent prompt. A ready-to-run prompt is copied from the active note or from a selection, and generation happens inside Obsidian or by way of the clipboard. The recorded inputs name local models, Anthropic Claude, Gemini and OpenAI as targets and describe the design as local-first.
