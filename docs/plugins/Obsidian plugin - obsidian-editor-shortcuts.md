# Code Editor Shortcuts

Code Editor Shortcuts adds keyboard shortcuts commonly found in code editors such as Visual Studio Code or Sublime Text. The commands insert, duplicate, delete and join lines, edit with multiple cursors and select occurrences, keeping those editing and navigation habits available inside Markdown notes.

```cue
plugin: {
    id:     "obsidian-editor-shortcuts"
    name:   "Code Editor Shortcuts"
    author: "timhor"
    repo:   "timhor/obsidian-editor-shortcuts"

    html_url:    "https://community.obsidian.md/plugins/obsidian-editor-shortcuts"
    github_url:  "https://github.com/timhor/obsidian-editor-shortcuts"
    description: "Add keyboard shortcuts (hotkeys) commonly found in code editors such as Visual Studio Code (VS Code) or Sublime Text."
    about:       "Add common code-editor keyboard shortcuts to Obsidian for inserting, duplicating, deleting and joining lines, multi-cursor editing, and selecting occurrences. Keep familiar code-editor commands available inside Markdown notes to speed up editing and navigation."

}
```
