# Index Cards

Provides a card-based note-taking system for research and study, capturing ideas and reading notes on virtual index cards filed into projects, categories and subcategories. A full-width dashboard previews, searches, moves, exports and compares cards, and Academic Mode adds citation fields and bibliography generation.
