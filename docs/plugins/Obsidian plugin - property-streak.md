# Property Streak

Turns habits recorded in daily-note frontmatter into persisted streaks in the manner of Duolingo, showing icons and motivational comments next to the properties. Streaks can be mono or multi, colors are customisable, a widget displays selected streaks, and optional streak-freezes pause and recover a streak.

```cue
plugin: {
    id:     "property-streak"
    name:   "Property Streak"
    author: "Daniel"
    repo:   "git-hub-dangel/obsidian-property-streaks"

    html_url:    "https://community.obsidian.md/plugins/property-streak"
    github_url:  "https://github.com/git-hub-dangel/obsidian-property-streaks"
    description: "Create and persist Duolingo inspired habit streaks from daily-note frontmatter with widgets, colours, and customisable streak types. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Track daily-note frontmatter habits with Duolingo-like streaks that show icons and motivational comments next to your properties. Configure mono or multi streaks, custom colors, a widget for selected streaks, and optional streak‑freezes to pause and recover streaks."

}
```
