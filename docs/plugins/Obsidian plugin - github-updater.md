# GitHub Updater

Installs, tracks and updates Obsidian plugins directly from GitHub repositories, including unofficial ones. It scans the vault for such plugins, fetches release assets or raw files from a tag when needed, shows release notes, and applies updates individually or in bulk.

```cue
plugin: {
    id:     "github-updater"
    name:   "GitHub Updater"
    author: "Real-Fruit-Snacks"
    repo:   "real-fruit-snacks/obsidian-github-updater"

    html_url:    "https://community.obsidian.md/plugins/github-updater"
    github_url:  "https://github.com/real-fruit-snacks/obsidian-github-updater"
    description: "Download and install unofficial plugins directly from GitHub. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Install, track, and update Obsidian plugins directly from GitHub repositories. Scan the vault for unofficial plugins, fetch release assets or raw tagged files when needed, display release notes, and apply updates individually or in bulk."

    stats: {
        downloads:  119
        updated_at: 1784470034000
    }
}
```
