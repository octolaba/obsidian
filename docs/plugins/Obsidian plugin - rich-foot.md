# Rich Foot

Rich Foot appends a footer to notes carrying backlinks, outlinks and created and modified dates, including links found in frontmatter. The links render as tag-like pills whose opacity, borders and corner radius can be adjusted, and folders can be excluded from displaying the footer.

```cue
plugin: {
    id:     "rich-foot"
    name:   "Rich Foot"
    author: "jparkerweb"
    repo:   "jparkerweb/rich-foot"

    html_url:    "https://community.obsidian.md/plugins/rich-foot"
    github_url:  "https://github.com/jparkerweb/rich-foot"
    description: "Adds backlink tags and created/modified dates to the footer of your notes."
    about:       "Add backlinks, outlinks and created/modified timestamps to the footer of your notes, including links found in frontmatter. Render links as tag-like pills with adjustable opacity, borders and corner radius. Exclude folders from displaying the footer."

    stats: {
        downloads:  12005
        updated_at: 1781535028000
    }
}
```
