# Note to RED

Converts Markdown notes into Xiaohongshu-style images, generating one image per H1 or H2 heading. Several templates are available, and fonts, colors, spacing, avatar, nickname and footer can be customized with a real-time preview. Single or batch export is supported, with an optional lock that prevents the preview from refreshing.
