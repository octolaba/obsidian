# OCR Extractor

Text is extracted from PDFs, documents, images and other embedded attachments. The extracted text is added as an expandable callout after each attachment, so that it is fully searchable. Local and cloud-based OCR options are available, both free and paid.

    id:     "ocr-extractor"
    name:   "OCR Extractor"
    author: "Johnathan Ritzi"
