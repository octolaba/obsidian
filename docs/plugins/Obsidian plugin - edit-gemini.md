# Edit Gemini

Creates and edits .gmi files, the document format of the Gemini protocol, from the side ribbon or the file context menu. The files are treated like regular notes and edited as Markdown in Obsidian's own editor.

```cue
plugin: {
    id:     "edit-gemini"
    name:   "Edit Gemini"
    author: "basil-mori"
    repo:   "basil-mori/obsidian-edit-gemini"

    html_url:    "https://community.obsidian.md/plugins/edit-gemini"
    github_url:  "https://github.com/basil-mori/obsidian-edit-gemini"
    description: "Edit and create .gmi files."
    about:       "Create .gmi files from the side ribbon or file context menu and edit them as Markdown for the Gemini protocol. Treat .gmi documents like regular notes and edit them directly in Obsidian’s editor."

    stats: {
        downloads:  3790
        updated_at: 1666546200000
    }
}
```
