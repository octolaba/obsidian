# The Scripture Injector

The Scripture Injector inserts Bible verses into notes from the command palette, with the ESV and NET translations supported. Passages are formatted as quote callouts with a Bible icon, and single verses, ranges, entire chapters and common book abbreviations are accepted.

```cue
plugin: {
    id:     "the-scripture-injector"
    name:   "The Scripture Injector"
    author: "jarchitect1"
    repo:   "jarchitect1/The-Scripture-Injector"

    html_url:    "https://community.obsidian.md/plugins/the-scripture-injector"
    github_url:  "https://github.com/jarchitect1/The-Scripture-Injector"
    description: "Seamlessly integrate Bible verses into your notes with support for multiple translations. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert Bible verses directly into notes from the command palette with support for ESV and NET translations. Format passages as quote callouts with a Bible icon and accept single verses, ranges, entire chapters, and common book abbreviations."
```
