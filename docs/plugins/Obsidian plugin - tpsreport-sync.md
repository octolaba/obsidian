# TPSReport

TPSReport connects Obsidian to the TPSReport service and publishes or syncs local Markdown folders, nested notes, frontmatter metadata and images. Report updates are pulled back into the vault, reconciliation is driven by a preserved node identifier, conflicting edits produce conflict copies, and destinations or RAG indexing are selected per transfer. A HiFi-WP account is required.
