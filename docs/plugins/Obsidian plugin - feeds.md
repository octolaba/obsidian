# Feeds

Feeds builds topic-specific lists of bullet points from a feed code block added to a topic note. The Dataview plugin has to be installed for feed generation to work.

```cue
plugin: {
    id:     "feeds"
    name:   "Feeds"
    author: "lukemt"
    repo:   "lukemt/obsidian-feeds"

    html_url:    "https://community.obsidian.md/plugins/feeds"
    github_url:  "https://github.com/lukemt/obsidian-feeds"
    description: "Create feeds of topic-specific bullet points."
    about:       "Create feeds of topic-specific bullet points in Obsidian by adding a simple feed code block to a topic note. Install the Dataview plugin to enable feed generation."

    stats: {
        downloads:  3460
        updated_at: 1744546065000
    }
}
```
