# Rainbow Folders Fixer

Stops rainbow folder colors from changing as the File Explorer is scrolled, by adding stable data attributes to folder elements so that each folder keeps its color. Numbering is applied per folder with optional recursive propagation, and a theme or CSS targets folders through that data attribute.

```cue
plugin: {
    id:     "rainbow-folders-fixer"
    name:   "Rainbow Folders Fixer"
    author: "dee158"
    repo:   "dee158/obsidian-rainbow-folders-fixer"

    html_url:    "https://community.obsidian.md/plugins/rainbow-folders-fixer"
    github_url:  "https://github.com/dee158/obsidian-rainbow-folders-fixer"
    description: "Stop rainbow folders from changing colors when you scroll through the File explorer."
    about:       "Fix rainbow folder color flicker in the File Explorer by adding stable data attributes to folder elements so colors remain consistent while scrolling. Apply per-folder numbering with optional recursive propagation and target folders in your theme/CSS via the data attribute (e.g. data-foldernumber) for reliable rainbow styling."
```
