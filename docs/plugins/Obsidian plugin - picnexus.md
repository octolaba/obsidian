# PicNexus

PicNexus uploads images pasted or dropped into Obsidian through the PicNexus desktop application and inserts the returned hosted link into the active note. Image bytes or local paths are sent to the PicNexus app running on the same computer, which uploads them to the chosen hosting service. The recorded inputs state that this communication stays local and that the plugin contains no telemetry.
