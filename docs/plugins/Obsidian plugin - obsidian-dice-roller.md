# Dice Roller

Dice Roller evaluates inline dice expressions written in dice code blocks and shows a clickable result that re-rolls when clicked. A formula may combine arithmetic, parentheses, percentiles, custom face ranges and Fudge or Fate dice, and Dataview inline fields and aliases for common rolls are supported.
