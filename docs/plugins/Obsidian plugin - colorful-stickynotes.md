# Colorful StickyNotes

Colorful StickyNotes creates floating, color-coded sticky-note windows that mirror Markdown files and sit above the main editor. Colors are assigned through frontmatter, notes are browsed and filtered in a grid with sorting and adjustable card sizes, window layouts are saved and restored, windows snap and group by dragging, and sessions resume at startup.
