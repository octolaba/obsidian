# LaTeX Color Sync

LaTeX Color Sync rewrites formulas in source mode as \textcolor{#RRGGBB}{...} so that their colour matches the surrounding Markdown text. The rewrite runs automatically when a newline is inserted, or on demand through commands that update the current line, the selection or the whole document.

```cue
plugin: {
    id:     "latex-color-sync"
    name:   "LaTeX Color Sync"
    author: "lunevoilee"
    repo:   "lunevoilee/obsidian-latex-color-sync"

    html_url:    "https://community.obsidian.md/plugins/latex-color-sync"
    github_url:  "https://github.com/lunevoilee/obsidian-latex-color-sync"
    description: "Sync LaTeX formula color with nearby markdown text color. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync LaTeX formula colors with surrounding text in source mode by rewriting formulas to \\textcolor{#RRGGBB}{...}. Auto-sync on newline insertion or run commands to update the current line, selection, or entire document."

    stats: {

    }
}
```
