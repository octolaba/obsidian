# Document Export

Exports vault notes to PDF, DOCX or LaTeX with control over structure, formatting and content. Notes are selected through an index or reordered by drag and drop, and headings can be mapped to parts, chapters and sections with a cover page and generated table of contents. Embeds, images, PDFs, Mermaid diagrams, KaTeX math, code highlighting, callouts, tasks and footnotes are resolved during export.
