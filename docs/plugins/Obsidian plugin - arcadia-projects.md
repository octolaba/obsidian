# Arcadia Projects

Presents vault notes as a sortable table or a drag-and-drop Kanban board kept in sync with YAML frontmatter in real time. Kanban columns group by a status field, views filter by folder, tag or frontmatter, and any view exports to CSV. Calendar, Gallery, Timeline and Portfolio views are premium additions for date-based and visual layouts.
