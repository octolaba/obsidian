# Thought Synapse (Desktop)

Thought Synapse (Desktop) renders the vault as an interactive 3D semantic network that visualizes how terms relate across notes. Hovering highlights co-occurring words, and clicking a node opens a modal listing the matching notes with extracted sentence snippets for tracing where knowledge came from. It is optimized for desktop devices.
