# Cursor Torch

Turns the text cursor into a flickering torch: a warm glow lights the text around the caret while the rest of the note fades into darkness. The glow is flame-shaped with an ambient halo, a subtle flicker and an optional glowing ember caret. The darkness fades when the editor loses focus and is softened on light themes.
