# AskMate

Opens an AI panel in the right sidebar on desktop that queries the current note or the selected text for question answering, summaries, rewrites, translations, image generation and note-focused workflows. Context is threaded or bounded across several notes or a folder, and responses stream from OpenAI, OpenRouter, Anthropic, Gemini or a local endpoint. Outputs are previewed before they are applied, and custom sidebar workflows can be built from templates.
