# Vim Toggle

Vim Toggle switches Obsidian's Vim editing mode on and off through a command or a configurable hotkey. The toggling behavior is customizable, and an optional notification reports the new state.

```cue
plugin: {
    id:     "vim-toggle"
    name:   "Vim Toggle"
    author: "connerohnesorge"
    repo:   "connerohnesorge/vim-toggle"

    html_url:    "https://community.obsidian.md/plugins/vim-toggle"
    github_url:  "https://github.com/connerohnesorge/vim-toggle"
    description: "Toggle Vim on/off and customize toggling behavior."
    about:       "Toggle Vim editing mode on and off in Obsidian via a command or configurable hotkey. Enable optional notifications to show when Vim mode is switched."

    stats: {
        downloads:  10890
        updated_at: 1755538855000
    }
}
```
