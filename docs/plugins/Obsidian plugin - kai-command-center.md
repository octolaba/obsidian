# KAI Command Center

Parses daily notes stored under 00 Human/10 Daily Notes/YYYY-MM-DD.md and builds a dashboard showing ONE Thing, tasks, schedule, metrics, wins, blockers and an activity heatmap. Quick entries can be captured to an inbox, and a 30-day metrics table and color-coded timeline are available for review. The view refreshes after vault changes.
