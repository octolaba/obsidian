# Runalone Project Manager

Runalone Project Manager keeps projects and tasks locally in Obsidian, combining a Kanban board with an interactive Gantt timeline for solo builders. Tasks are rescheduled or resized by dragging and dependencies are visualized. The recorded text states that everything stays in plain-text files, with no cloud service and no accounts.
