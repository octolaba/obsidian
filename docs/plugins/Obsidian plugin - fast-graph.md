# Fast 3D Graph

Fast 3D Graph explores the vault as a 3D force-directed graph that is intended to stay fluid with tens of thousands of notes. Nodes are GPU-instanced and the physics runs in a Web Worker, and notes can be grouped by folder or tag for cluster-aware layouts. Clicking a node opens the note or focuses a local graph.
