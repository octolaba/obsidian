# Depends

Records cross-file dependencies by id in frontmatter and maintains two managed sections in the note for upstream and downstream links. The ids are written out as real wikilinks, so the relationships show up in the native graph view and survive file renames, and the headings and bullet lists appear or disappear as the relationships change.

```cue
plugin: {
    id:     "depends"
    name:   "Depends"
    author: "Aru Gyani"
    repo:   "arugyani/depends"

    html_url:    "https://community.obsidian.md/plugins/depends"
    github_url:  "https://github.com/arugyani/depends"
    description: "Manage your cross-file dependencies and view them in the native graph view. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Manage file relationships by id in frontmatter and automatically create two managed sections for upstream and downstream links. Write real [[wikilinks]] from ids so the Obsidian graph updates and links survive file renames; headings and bullet lists appear or disappear as relationships change."
```
