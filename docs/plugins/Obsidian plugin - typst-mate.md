# Typst Mate

Renders math expressions with Typst instead of MathJax, covering inline, display and code-block previews with background rendering and mobile support. Preambles, templates, snippets, a linter, bracket jump and symbol completion assist authoring, and fonts and Typst packages can be imported on desktop. Results are exported or copied as SVG, PNG or HTML for PDF and image export compatibility.
