# Limn

Limn opens .limn files as interactive mind map views inside Obsidian, with keyboard-first navigation and pan-and-zoom SVG rendering. Documents are ZIP-backed with embedded assets and stay local, autosaved to IndexedDB offline and synced across tabs, while undo and redo work from diffs.
