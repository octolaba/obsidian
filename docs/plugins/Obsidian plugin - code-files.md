# Code Files

Opens code files beside notes in an embedded Monaco editor with syntax highlighting and theming, and can create files and edit CSS snippets. A single Markdown code block can be opened in a Monaco modal whose changes sync back into the document. Monaco's resources are hosted, so an internet connection is expected.
