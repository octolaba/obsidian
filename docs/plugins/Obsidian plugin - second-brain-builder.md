# Second Brain Builder

Second Brain Builder generates a folder of interlinked, deep-dive study notes from a topic or a selected word or phrase, including an index hub, Mermaid concept maps and wiki-style links that populate the graph view. Selected text can be explained into new linked notes and existing content refined in place, using Claude Code, Gemini, Codex or a local Ollama model as the backend.
