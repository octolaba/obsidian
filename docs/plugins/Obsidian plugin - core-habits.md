# Core Habits

Core Habits is a local-first habit tracker built into Obsidian daily notes, storing habits as properties inside those notes rather than in a central database. Its sidebar layout adapts from a weekly desktop grid to a compact mobile list, and habits are defined with cue, friction, reward and five levels of gradation. It tracks streaks live, shows four-week consistency trends and recovery resilience scores, works with Templater and the native Daily Notes plugin, and records written reflections and audio comments.
