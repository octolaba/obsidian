# Thought Synapse (Mobile)

Thought Synapse (Mobile) embeds a fluid, auto-rotating 3D visual at the bottom of the file explorer, designed exclusively for Obsidian Mobile. Continuous Chinese phrases are extracted from notes while English code, digits and noise are filtered out. Interaction is zero-touch, and rendering persists through a microtask-level observer.
