# Hide Folders

Hide Folders toggles the visibility of configured folders in the file navigator, with attachment folders named as the recorded use. Folders are matched by exact name or by startsWith and endsWith patterns, and visibility is toggled from a sidebar button or from the command palette.

    id:     "hide-folders"
    name:   "Hide Folders"
