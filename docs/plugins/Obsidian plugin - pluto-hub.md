# Pluto Hub

Manages, edits, and runs local code modules inside Obsidian through a visual module grid with drag-and-drop sorting, enable and disable controls, and import/export backups. Multi-file modules are edited with CodeMirror 6 live preview, CSS is auto-injected, JSON and YAML configs are parsed, and outputs are mounted to window.pluto so other plugins can integrate with them.
