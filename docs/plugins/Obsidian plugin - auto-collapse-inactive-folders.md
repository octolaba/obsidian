# Auto Collapse Inactive Folders

Collapses every folder in the file explorer except the one containing the active file. The folder holding the current note stays expanded while the rest fold away, which keeps the file list shorter and easier to navigate.

```cue
plugin: {
    id:     "auto-collapse-inactive-folders"
    name:   "Auto Collapse Inactive Folders"
    author: "somehowitworks"
    repo:   "somehowitworks/auto-collapse-inactive-folders"

    html_url:    "https://community.obsidian.md/plugins/auto-collapse-inactive-folders"
    github_url:  "https://github.com/somehowitworks/auto-collapse-inactive-folders"
    description: "Automatically collapse all folders except the one containing the active file. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Collapse inactive folders to keep the file explorer focused on the current note. Keep the folder containing the active note expanded while folding all others for a cleaner, easier-to-navigate file list."

    stats: {
        downloads:  184
        updated_at: 1773163933000
    }
}
```
