# Quick File Name

Creates a new note whose filename is a randomly generated string. The length of that string and the character sets it draws on — uppercase, lowercase, numbers and symbols — are configurable.

```cue
plugin: {
    id:     "quick-file-name"
    name:   "Quick File Name"
    author: "wapply"
    repo:   "wapply/obsidian-quick-file-name"

    html_url:    "https://community.obsidian.md/plugins/quick-file-name"
    github_url:  "https://github.com/wapply/obsidian-quick-file-name"
    description: "Generates a note with a random string as its name."
    about:       "Generate new notes with randomized filenames. Customize string length and character sets (uppercase, lowercase, numbers, symbols) to control the generated names."

    stats: {
        downloads:  1505
        updated_at: 1710933438000
    }
}
```
