# Dynbedded

Dynbedded embeds notes, templates and snippets, including specific headers, and runs their dynamic content in the context of the current note. Parts of a note name or header can be substituted with Moment.js date formats and shifted by an offset given in ISO8601 or as a number of days, to target a dated note or section.

```cue
plugin: {
    id:     "obsidian-dynbedded"
    name:   "Dynbedded"
    author: "Marcus Breiden"
    repo:   "mmomm-org/obsidian-dynbedded"

    html_url:    "https://community.obsidian.md/plugins/obsidian-dynbedded"
    github_url:  "https://github.com/mmomm-org/obsidian-dynbedded"
    description: "Dynamic embeds."
    about:       "Embed notes, templates and snippets and run their dynamic content in the context of the current note, including specific headers. Substitute parts of note names and headers with Moment.js date formats and apply offsets (ISO8601 or day counts) to target dated notes or sections."
```
