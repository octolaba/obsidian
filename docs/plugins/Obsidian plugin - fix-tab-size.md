# Fix Tab Size

Makes the editor insert the number of spaces configured by the indent visual width setting when the Tab key is pressed, instead of always inserting four. It applies where indentation uses spaces rather than tabs.

```cue
plugin: {
    id:     "fix-tab-size"
    name:   "Fix Tab Size"
    author: "Michael Naumov"
    repo:   "mnaoumov/obsidian-fix-tab-size"

    html_url:    "https://community.obsidian.md/plugins/fix-tab-size"
    github_url:  "https://github.com/mnaoumov/obsidian-fix-tab-size"
    description: "Fixes tab size according to the settings. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Fix editor tab insertion to match the Indent visual width setting. Make the Tab key insert the configured number of spaces when using spaces for indentation instead of always inserting four."

    stats: {
        downloads:  1225
        updated_at: 1784595845000
    }
}
```
