# Copy for Email

Copy for Email copies a selection or a whole note as email-ready rich text, preserving headings, tables, callouts, code blocks and task lists and converting Mermaid diagrams, charts, math and SVGs into embedded images. Styles are inlined and vault images embedded as data URIs with a light palette suited to white email bodies, so the result survives pasting into Gmail, Outlook and Apple Mail. The same copy also carries a chat-styled plain-text flavour in which headings, emphasis, ordered lists and quotes are redrawn with visible markers for WeChat, Slack and iMessage, with every marker configurable and a Minimal style that leaves the text undecorated. A ribbon button copies the selection, or the whole note when nothing is selected.
