# Brainframe

Brainframe saves product, Git and gift-idea bookmarks from the browser into designated vault files as Markdown link entries. The page title and URL are appended to a chosen file, with products.md and gitmarks.md as the defaults, through quick commands for collecting bookmarks centrally.

```cue
plugin: {
    id:     "brainframe"
    name:   "Brainframe"
    author: "pedersen"
    repo:   "pedersen/obsidian-brainframe"

    html_url:    "https://community.obsidian.md/plugins/brainframe"
    github_url:  "https://github.com/pedersen/obsidian-brainframe"
    description: "Tools to make Obsidian more into our second brains."
    about:       "Save product, Git, and gift-idea bookmarks from your browser into designated vault files as Markdown link entries. Append page title and URL to chosen files (defaults: products.md, gitmarks.md) with quick commands for simple centralized bookmark collection."

    stats: {
        downloads:  5216
        updated_at: 1680014017000
    }
}
```
