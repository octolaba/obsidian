# Novel word count

Displays writing statistics beside each file, folder and the vault itself in the File Explorer pane, updating as text is written. Up to three metrics are shown, chosen from word count, page count, reading time, characters, links, embeds, note count, line breaks, percentage of a word goal, and creation or update dates.

```cue
plugin: {
    id:     "novel-word-count"
    name:   "Novel word count"
    author: "isaaclyman"
    repo:   "isaaclyman/novel-word-count-obsidian"

    html_url:    "https://community.obsidian.md/plugins/novel-word-count"
    github_url:  "https://github.com/isaaclyman/novel-word-count-obsidian"
    description: "Display a word count, page count, creation date, or other statistics for each file, folder and vault in the File Explorer pane."
    about:       "Show real-time writing statistics next to files, folders, and the vault in the File Explorer pane. Choose up to three metrics—word/page/reading time/characters/links/embeds/note count/line breaks/% of word goal/created/updated dates—and watch them update as you write."

    stats: {
        downloads:  183255
        updated_at: 1783099645000
    }
}
```
