# Hotkeys Cheatsheet

Hotkeys Cheatsheet opens a searchable reference card listing Obsidian keyboard shortcuts in a newspaper-style multi-column layout, with OS-aware key badges and icons for special keys. Search and filtering are live, sections are categorized and collapsible, and the list can be narrowed to shortcuts using selected modifier combinations.

```cue
plugin: {
    id:     "hotkeys-cheatsheet"
    name:   "Hotkeys Cheatsheet"
    author: "Pierre Awaragi"
    repo:   "awaragi/obsidian-hotkeys-cheatsheet"

    html_url:    "https://community.obsidian.md/plugins/hotkeys-cheatsheet"
    github_url:  "https://github.com/awaragi/obsidian-hotkeys-cheatsheet"
    description: "Display a searchable cheatsheet of all your Obsidian hotkeys. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open a live, searchable reference card for all Obsidian keyboard shortcuts in a newspaper-style multi-column layout with OS-aware key badges and special key icons. Filter and search in real time, browse categorized collapsible sections, and show only shortcuts with selected modifier combos."

    stats: {
        downloads:  797
        updated_at: 1783688375000
    }
}
```
