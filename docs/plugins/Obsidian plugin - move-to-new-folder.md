# Move to New Folder

Moves a file or folder into a newly created subfolder without typing the full destination path: a searchable picker chooses the parent and the child folder is named, created and the item relocated. Obsidian's own link-update behaviour is preserved. The action runs from the file explorer context menu or the command palette.

```cue
plugin: {
    id:     "move-to-new-folder"
    name:   "Move to New Folder"
    author: "d0d1"
    repo:   "d0d1/obsidian-move-to-new-folder"

    html_url:    "https://community.obsidian.md/plugins/move-to-new-folder"
    github_url:  "https://github.com/d0d1/obsidian-move-to-new-folder"
    description: "Move files and folders into newly created folders with a faster workflow. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Move files or folders into a newly created subfolder without typing the full destination path. Pick a parent folder via a searchable picker and name the child folder; the plugin creates it and relocates the item while preserving Obsidian's link-update behavior. Use from the file explorer context menu or the command palette."

    stats: {
        downloads:  436

    }
}
```
