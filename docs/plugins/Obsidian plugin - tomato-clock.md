# Tomato Clock

Tomato Clock runs a Pomodoro timer in a sidebar view with a countdown, a phase indicator and session controls. The remaining minutes appear in the status bar, and the end of a phase raises an OS notification and a browser-synthesized beep. Work sessions are logged to a Markdown file that opens so that notes and links can be added.
