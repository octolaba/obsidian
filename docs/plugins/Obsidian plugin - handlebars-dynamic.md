# Handlebars Dynamic Templating

Renders Handlebars templates inside notes, turning tagged hb code blocks into formatted content. Variables, lists and Handlebars expressions such as each are applied to generate content from inline data. Template files are defined separately and used dynamically, and template recursion is possible.

```cue
plugin: {
    id:     "handlebars-dynamic"
    name:   "Handlebars Dynamic Templating"
    author: "hided62"
    repo:   "hided62/obsidian-handlebars-dynamic"

    html_url:    "https://community.obsidian.md/plugins/handlebars-dynamic"
    github_url:  "https://github.com/hided62/obsidian-handlebars-dynamic"
    description: "Handlebars dynamic templating. Define template files and use them dynamically via hb blocks. Template recursion is also possible."
    about:       "Render Handlebars templates inside Obsidian notes and convert tagged code blocks into formatted content. Apply variables, lists, and Handlebars expressions (including #each) to generate dynamic note content from inline data."
```
