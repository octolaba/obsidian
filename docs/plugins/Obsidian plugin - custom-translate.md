# Custom Translate

Translates selected text through a local LibreTranslate server and returns a bilingual result. It also keeps a personal vocabulary carrying part of speech, definitions, examples, synonyms, antonyms, tags, frequency, CEFR level and UK and US phonetics, with import and export, search and sorting.
