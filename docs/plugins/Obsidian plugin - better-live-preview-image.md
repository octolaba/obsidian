# Better Live Preview Image

Better Live Preview Image keeps an image's Markdown visible and editable in Live Preview so notes stay portable and readable. Images are aligned left, center or right from the context menu or from commands, and resized with a handle at the lower right while the image's Markdown link stays in view.
