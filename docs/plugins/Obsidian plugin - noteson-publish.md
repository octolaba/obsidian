# NotesOn Publish

Exports a selected note as an HTML page to the NotesOn.ru server and copies the resulting public link to the clipboard for sharing. A published note can be removed from that server again through the note's context menu.

```cue
plugin: {
    id:     "noteson-publish"
    name:   "NotesOn Publish"
    author: "shapkinaa"
    repo:   "shapkinaa/noteson-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/noteson-publish"
    github_url:  "https://github.com/shapkinaa/noteson-obsidian-plugin"
    description: "Make single notes instantly available on the web."
    about:       "Export a selected note as an HTML page to the NotesOn.ru server and copy the public link to your clipboard for easy sharing. Remove a published note from the NotesOn server using the note's context menu."

    stats: {
        downloads:  1344
        updated_at: 1763990951000
    }
}
```
