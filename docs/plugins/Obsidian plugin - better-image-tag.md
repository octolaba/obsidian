# Better Image Tag

Better Image Tag tags images by right-clicking them or selecting them in the editor and choosing from existing tags as buttons, so nothing has to be typed. The recorded inputs disagree about storage: the index description says tags are kept in the plugin settings, while the About text says tags, author and dates are stored in frontmatter. A sidebar manages the tag library and can rescan it.

```cue
plugin: {
    id:     "better-image-tag"
    name:   "Better Image Tag"
    author: "ktonel475"
    repo:   "ktonel475/Better-Image-Tag"

    html_url:    "https://community.obsidian.md/plugins/better-image-tag"
    github_url:  "https://github.com/ktonel475/Better-Image-Tag"
    description: "Visual image tagging with sidebar manager. Right-click images or select in-editor to tag with clickable buttons. Stores tags in plugin settings. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Tag images by right-clicking and selecting tags visually from existing tags — no typing required. Store tags, author, and dates in frontmatter and manage or rescan your tag library from a single sidebar."

    stats: {
        downloads:  425
        updated_at: 1780216609000
    }
}
```
