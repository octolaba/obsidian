# KatmerCode

Runs Claude Code inside Obsidian as a sidebar chat, with research-focused slash skills, MCP support and automatic context from the selected text. Manuscripts are edited through inline word-level diffs that can be accepted or undone. It also generates HTML peer-review, citation-verification and gap-analysis reports.
