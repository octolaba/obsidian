# Custom Frames

Custom Frames turns web apps into Obsidian panes using iframes with custom styling, and ships presets for sites such as Google Keep and Todoist. A frame is a standalone pane or is embedded in Markdown through a special code block, style overrides and URL suffixes can be passed, and desktop-only frames are hidden on mobile.

```cue
plugin: {
    id:     "obsidian-custom-frames"
    name:   "Custom Frames"
    author: "Ell"
    repo:   "ellpeck/ObsidianCustomFrames"

    html_url:    "https://community.obsidian.md/plugins/obsidian-custom-frames"
    github_url:  "https://github.com/ellpeck/ObsidianCustomFrames"
    description: "Turn web apps into panes using iframes with custom styling. Also comes with presets for Google Keep, Todoist and more."
    about:       "Turn web apps into Obsidian panes using configurable iframes with custom CSS and presets for sites like Google Keep and Todoist. Embed frames as standalone panes or inside Markdown via a special code block, pass style overrides and URL suffixes, and hide desktop-only frames on mobile."
```
