# storyForge

Obsidian is arranged as a small novel-writing workspace with manuscript formatting and a library offering series or novel views, series and book ordering, and word-count history. Worldbuilding material is kept in a scoped codex, and content is backed up through import and export. The recorded inputs state that the plugin only creates and renames lore files and reads the manuscript, which stays plain Markdown the writer already owns.
