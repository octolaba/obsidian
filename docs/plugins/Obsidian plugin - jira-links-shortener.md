# JIRA links shortener

JIRA links shortener modifies pasted Jira ticket URLs so the link title becomes the issue key. A long Jira link therefore appears in the note as a compact ticket identifier.

```cue
plugin: {
    id:     "jira-links-shortener"
    name:   "JIRA links shortener"
    author: "rplatonovs"
    repo:   "rplatonovs/obsidian-jira-links-shortener"

    html_url:    "https://community.obsidian.md/plugins/jira-links-shortener"
    github_url:  "https://github.com/rplatonovs/obsidian-jira-links-shortener"
    description: "Modifies pasted JIRA links to use JIRA issue number as the link title"
    about:       "Capture pasted Jira ticket URLs and replace them with the issue key (e.g., PRJ-1234). Keep notes concise by converting long Jira links into compact ticket IDs on paste."

    stats: {
        downloads:  705
        updated_at: 1758905988000
    }
}
```
