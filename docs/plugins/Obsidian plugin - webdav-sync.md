# WebDAV Sync

Synchronises a vault in both directions with a WebDAV server, using three-way comparison, automatic sync and conflict resolution. Client-side encryption, parallel processing and rate control are part of the recorded transfer path. Vaults of more than three thousand files are handled with chunking, resumable downloads and detailed logs.
