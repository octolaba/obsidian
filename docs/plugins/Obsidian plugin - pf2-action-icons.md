# Pathfinder 2E Action Icons

Pathfinder 2E Action Icons replaces pf2 code blocks with Pathfinder 2E action icons in preview and reading view. Action, Double Action, Triple Action, Free Action and Reaction icons are rendered inline, including inside Markdown-rendered statblocks.

```cue
plugin: {
    id:     "pf2-action-icons"
    name:   "Pathfinder 2E Action Icons"
    author: "thiagocoutinhor"
    repo:   "thiagocoutinhor/pf2-action-icons"

    html_url:    "https://community.obsidian.md/plugins/pf2-action-icons"
    github_url:  "https://github.com/thiagocoutinhor/pf2-action-icons"
    description: "Display Pathfinder 2E action icons."
    about:       "Replace pf2 code blocks (e.g., pf2:2) with Pathfinder 2E action icons in preview and reading view. Render Action, Double Action, Triple Action, Free Action and Reaction icons inline, including inside Markdown-rendered statblocks."

        downloads:  9943

}
```
