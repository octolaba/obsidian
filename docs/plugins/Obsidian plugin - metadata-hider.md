# Metadata Hider

Metadata Hider suppresses metadata properties that are empty, across the properties table, the file properties panel and the All Properties side panel. Selected properties can be shown even when empty, chosen properties can stay hidden even when populated, and every field is revealed while editing except those set to always hide.

```cue
plugin: {
    id:     "metadata-hider"
    name:   "Metadata Hider"
    author: "benature"
    repo:   "benature/obsidian-metadata-hider"

    html_url:    "https://community.obsidian.md/plugins/metadata-hider"
    github_url:  "https://github.com/benature/obsidian-metadata-hider"
    description: "Hide specific metadata property or if its value is empty."
    about:       "Hide empty metadata properties in the properties table, file properties panel, and All Properties side panel. Show selected properties even when empty or keep chosen properties hidden even when populated, and reveal all fields while editing except those set to always hide."
```
