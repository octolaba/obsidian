# Player Facing Notes

Player Facing Notes flags paragraphs, callouts, code fences, headings or whole notes as player-facing and generates publish-ready copies containing only the flagged content with the markers removed. Those copies are synced into a mirror folder that preserves the folder structure and prunes stale files. Everything left unflagged, including secrets and drafts, stays out of the published copies.

plugin: {
    id:     "player-facing-notes"
    name:   "Player Facing Notes"
    author: "Obsidian TTRPG Community"
    repo:   "obsidian-ttrpg-community/player-facing-notes"

    html_url:    "https://community.obsidian.md/plugins/player-facing-notes"
    github_url:  "https://github.com/obsidian-ttrpg-community/player-facing-notes"
    description: "Selectively publish parts of your notes. Flag blocks as public, then sync them into publish-ready copies, keeping secrets, drafts, and private content out of your published site. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Flag paragraphs, callouts, code fences, headings or whole notes as player-facing and generate publish-ready copies that contain only flagged content with markers removed. Sync those copies into a mirror folder that preserves folder structure and prunes stale files while keeping all unflagged material private."
