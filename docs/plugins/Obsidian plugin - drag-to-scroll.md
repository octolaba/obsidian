# Drag To Scroll

Scrolls the view by holding the mouse button and dragging, the way scrolling works on a touch device. It applies in both Edit and Reading modes and is desktop only.

plugin: {
    id:     "drag-to-scroll"
    name:   "Drag To Scroll"
    author: "constsz"
    repo:   "constsz/obsidian-drag-to-scroll"

    html_url:    "https://community.obsidian.md/plugins/drag-to-scroll"
