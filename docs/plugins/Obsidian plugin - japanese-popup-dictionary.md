# Japanese Popup Dictionary

Japanese Popup Dictionary looks up Japanese words in an offline popup, reading dictionaries in the Yomitan or Yomichan format such as JMdict or Jitendex. Conjugated verbs and adjectives are detected and deinflected automatically. It is desktop-only, because the dictionary imports are large.

```cue
plugin: {
    id:     "japanese-popup-dictionary"
    name:   "Japanese Popup Dictionary"
    author: "atacansuder"
    repo:   "atacansuder/obsidian-japanese-dictionary"

    html_url:    "https://community.obsidian.md/plugins/japanese-popup-dictionary"
    github_url:  "https://github.com/atacansuder/obsidian-japanese-dictionary"
    description: "Fast, offline Japanese popup dictionary using Yomitan dictionaries. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Look up Japanese words instantly with an offline popup using Yomitan/Yomichan-format dictionaries (JMdict, Jitendex, etc.). Detect and deinflect conjugated verbs and adjectives automatically; desktop-only due to large dictionary imports."

    stats: {
        downloads:  558

    }
}
```
