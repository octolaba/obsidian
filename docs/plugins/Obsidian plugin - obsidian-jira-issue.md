# Jira Issue

Tracks the progress of Atlassian Jira issues from notes by embedding issue cards and rendering inline issue links and checklist items. Jira searches and counts are run from within a note, and a connection to a Jira server displays live issue status inside Obsidian.

```cue
plugin: {
    id:     "obsidian-jira-issue"
    name:   "Jira Issue"
    author: "marc0l92"
    repo:   "marc0l92/obsidian-jira-issue"

    html_url:    "https://community.obsidian.md/plugins/obsidian-jira-issue"
    github_url:  "https://github.com/marc0l92/obsidian-jira-issue"
    description: "Track the progress of Atlassian Jira issues from your notes."
    about:       "Track Jira issues from your Obsidian notes. Embed issue cards, run Jira searches and counts, and render inline issue links and checklist items. Connect to your Jira server to display live issue status and progress inside Obsidian."

    stats: {
        downloads:  43567
        updated_at: 1758819736000
    }
}
```
