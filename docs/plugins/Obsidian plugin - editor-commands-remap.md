# Editor Commands Remap

Exposes Obsidian's editor commands - cursor movement, indentation, line swapping, line deletion and folding - so that hotkeys can be mapped to them. These editor-only commands are active whenever an editor is open.

```cue
plugin: {
    id:     "editor-commands-remap"
    name:   "Editor Commands Remap"
    author: "c4ctus5"
    repo:   "c4ctus5/editor-commands-remap"

    html_url:    "https://community.obsidian.md/plugins/editor-commands-remap"
    github_url:  "https://github.com/c4ctus5/editor-commands-remap"
    description: "Map hotkeys to editor commands."
    about:       "Map hotkeys to Obsidian editor commands for cursor movement, indentation, line swapping, line deletion, and folding. Activate these editor-only commands whenever an editor is open to streamline text editing."

    stats: {
        downloads:  4568
        updated_at: 1630137724000
    }
}
```
