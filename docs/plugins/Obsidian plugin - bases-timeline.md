# Bases Timeline

Bases Timeline adds a timeline view to Bases that draws each project note as a horizontal bar between its start and end dates, with colored priority pills and a today indicator. Bars and their edges are dragged to move or resize those dates, which are saved back to the note's frontmatter. Projects can be grouped and sorted by status or priority, dragged between groups to change status, and opened or previewed from the bar.
