# Tag Aliases

Defines groups of tag aliases so tags are normalized as they are typed: typing any alias offers the canonical tag in autocomplete. Existing aliases can optionally be replaced automatically and the whole vault migrated in a batch. Alias lists are imported and exported as files.

```cue
plugin: {
    id:     "tag-aliases"
    name:   "Tag Aliases"
    author: "yingjialong"
    repo:   "yingjialong/obsidian-tag-aliases"

    html_url:    "https://community.obsidian.md/plugins/tag-aliases"
    github_url:  "https://github.com/yingjialong/obsidian-tag-aliases"
    description: "Define tag aliases to normalize tags at input time. When you type an alias, the plugin suggests and inserts the primary tag, keeping your vault's tags clean and consistent. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Define tag alias groups to normalize tags across your vault and keep tag names consistent. Type any alias to get the canonical tag in autocomplete; optionally auto-replace existing aliases, batch-migrate your vault, and import/export alias lists."

    stats: {
        downloads:  272
        updated_at: 1778932208000
    }
}
```
