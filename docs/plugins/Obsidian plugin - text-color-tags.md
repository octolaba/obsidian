# Text Color Tags

Text Color Tags colors inline text through short dollar-prefixed color tags instead of extra markup in the file. Clicking colored text reveals the tag and its swatch, opening the swatch starts a color picker, and colors are given by name or as hex with or without a leading hash. Vault presets and recently used colors are reachable from the context menu.

```cue
plugin: {
    id:     "text-color-tags"
    name:   "Text Color Tags"
    author: "psyda"
    repo:   "psyda/obsidian-text-color-tags"

    html_url:    "https://community.obsidian.md/plugins/text-color-tags"
    github_url:  "https://github.com/psyda/obsidian-text-color-tags"
    description: "Simple and fast inline text coloring that feels native with $red, $#hex syntax. Clickable swatches, color picker, vault presets. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Color inline text using simple $color tags without adding extra markup to your files. Click colored text to reveal the $color tag and swatch, open the swatch to pick a color, use named colors or hex (with or without #), and access vault swatches and recent colors from the context menu."

    stats: {
        downloads:  442
        updated_at: 1768569125000
    }
}
```
