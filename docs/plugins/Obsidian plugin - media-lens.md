# Media Lens

Inspects metadata for image, audio, video and subtitle files in a sidebar, reporting format, codecs, resolution, bitrate and duration. Two files are compared side by side with differences highlighted, playback synchronized and a split A/B view available. Frames are captured and the comparison is saved as a Markdown note.
