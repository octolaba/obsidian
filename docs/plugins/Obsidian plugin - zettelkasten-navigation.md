# zettelkasten navigation

This plugin adds two custom graph views for navigating a Luhmann-style Zettelkasten built on folgezettel note IDs and a keyword index. One view visualizes index-based chains of thought and the other local ID sequences, so starting points, paths and ordered relationships can be traced beyond what a link-only graph shows.
