# Tasks Cleaner

Tasks Cleaner finds and removes outdated completed tasks from Markdown notes, using a customizable regular expression that captures the completion date. Tasks older than a chosen number of days are deleted together with their indented description lines. Filenames can be filtered, and a confirmation modal summarizes the removals first.

```cue
plugin: {
    id:     "tasks-cleaner"
    name:   "Tasks Cleaner"
    author: "lowitea"
    repo:   "lowitea/obsidian-tasks-cleaner"

    html_url:    "https://community.obsidian.md/plugins/tasks-cleaner"
    github_url:  "https://github.com/lowitea/obsidian-tasks-cleaner"
    description: "Find and remove outdated tasks."
    about:       "Remove old completed tasks from your Markdown notes using a customizable regular expression that captures completion dates. Delete tasks older than a set number of days and remove indented description lines, with optional filename filtering and a confirmation modal summarizing removals."
```
