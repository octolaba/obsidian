# Markdown prettifier

Markdown prettifier reformats messy Markdown, normalizing ordered lists and tables and renumbering lists for consistency. It converts inline hashtags and literals into frontmatter entries and links, and updates or inserts frontmatter fields such as modified dates and UUIDs. URLs and email addresses are turned into links automatically.
