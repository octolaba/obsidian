# Custom Slides

Customizes the navigation, styles and behavior of the Slides core plugin, covering transitions, the progress bar, fonts, footer text and slide numbering. Arrow visibility can be toggled, lists left-aligned, auto-fit shrinking enabled and reading mode entered automatically for immediate keyboard control. Touch support is included for mobile.
