# Liquid Templates

Lets templates be written with LiquidJS tags inside Obsidian, including including other template files to compose a note. Liquid filters apply, among them a custom date filter backed by date-fns that understands keywords such as now, today, yesterday, and tomorrow, and autocomplete is available while editing templates.

```cue
plugin: {
    id:     "liquid-templates"
    name:   "Liquid Templates"
    author: "oen"
    repo:   "oen/liquid-template"

    html_url:    "https://community.obsidian.md/plugins/liquid-templates"
    github_url:  "https://github.com/oen/liquid-template"
    description: "Create your templates with LiquidJS tags support."
    about:       "Write templates using LiquidJS tags inside Obsidian and compose notes by including other template files. Apply Liquid filters, including a custom date filter powered by date-fns with keywords like now, today, yesterday, and tomorrow, and enjoy autocomplete while editing templates."

}
```
