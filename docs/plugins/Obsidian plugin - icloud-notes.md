# Apple Notes Sync

Apple Notes Sync keeps a folder of the vault in sync with Apple Notes through the icloud-md command-line tool. Its recorded inputs state that the sync runs in both directions and works from Linux, Windows or macOS.

```cue
plugin: {
    id:     "icloud-notes"
    name:   "Apple Notes Sync"
    author: "Adam Coddington"
    repo:   "coddingtonbear/obsidian-icloud-notes"

    html_url:    "https://community.obsidian.md/plugins/icloud-notes"
    github_url:  "https://github.com/coddingtonbear/obsidian-icloud-notes"
    description: "Sync a vault folder with your Apple Notes via the icloud-md CLI. - This plugin has not been manually reviewed by Obsidian staff."
```
