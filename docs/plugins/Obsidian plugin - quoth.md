# Quoth

Embeds precise excerpts from Markdown files, selecting a single block or several text ranges and joining them into one quote. Embeds are placed inline so that they align with the surrounding content, and the source author and title are added automatically. A reference code block is copied for quick pasting into another note.

```cue
plugin: {
    id:     "quoth"
    name:   "Quoth"
    author: "erykwalder"
    repo:   "erykwalder/quoth"

    html_url:    "https://community.obsidian.md/plugins/quoth"
    github_url:  "https://github.com/erykwalder/quoth"
    description: "More flexible embedding. Embed precise selections, inline embeds, optionally include author and title."
    about:       "Embed precise excerpts from Markdown files by selecting single blocks or multiple text ranges and join them into a single quote. Inline embeds to align with surrounding content and automatically add source author and title. Copy reference code blocks for quick pasting into other notes."

}
```
