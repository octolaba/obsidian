# Force Reading Mode

Keeps reading mode enabled across notes and Obsidian sessions, so files stay in a persistent view-only state. The persistent reading view is toggled from keyboard shortcuts or the ribbon menu item.

```cue
plugin: {
    id:     "force-reading-mode"
    name:   "Force Reading Mode"
    author: "shubhmadhavan"
    repo:   "shubhmadhavan/obsidian-force-reading-mode"

    html_url:    "https://community.obsidian.md/plugins/force-reading-mode"
    github_url:  "https://github.com/shubhmadhavan/obsidian-force-reading-mode"
    description: "A Plugin that forces reading mode, making it persistent. Plugin is controllable using both keyboard shortcuts and the ribbon menu item. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Force reading mode to remain enabled across notes and Obsidian sessions, keeping your files in a persistent, view-only state. Toggle the persistent reading view quickly via keyboard shortcuts or the ribbon menu."

    stats: {
        downloads:  180
        updated_at: 1774051771000
    }
}
```
