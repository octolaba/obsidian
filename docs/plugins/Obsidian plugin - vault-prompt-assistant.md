# Vault Prompt AI-Assistant

Runs an AI assistant in a right-side panel whose responses can be inserted directly into a note. Vault context is retrieved by vector search where one is available and by keyword otherwise, supporting semantic question answering with source references. A prompt library, daily note workflow templates, batch runs, run history and external vector index storage are recorded as part of its prompt workflow automation.
