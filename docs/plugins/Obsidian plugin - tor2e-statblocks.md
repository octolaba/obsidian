# The One Ring 2E Statblocks

The One Ring 2E Statblocks renders NPC and adversary statblocks for The One Ring Second Edition inside a note, showing name, blurb, level, endurance, might, hate, resolve, parry, armour, features and combat proficiencies. A statblock is defined as YAML fields in the note, and Markdown may be included for flavor and special entries, with Obsidian links supported.

```cue
plugin: {
    id:     "tor2e-statblocks"
    name:   "The One Ring 2E Statblocks"
    author: "modality"
    repo:   "modality/obsidian-the-one-ring-2e-statblocks"

    html_url:    "https://community.obsidian.md/plugins/tor2e-statblocks"
    github_url:  "https://github.com/modality/obsidian-the-one-ring-2e-statblocks"
    description: "Render NPC and adversary statblocks for The One Ring 2E roleplaying game."
    about:       "Render adversary statblocks for The One Ring Second Edition directly in notes, showing name, blurb, level, endurance, might/hate/resolve, parry, armour, features and combat proficiencies. Define statblocks as YAML fields in a note and include Markdown for flavor and special entries; Obsidian links are supported."

}
```
