# Advanced Codeblock

Advanced Codeblock adds line numbers and line highlighting to code blocks. Space-separated parameters after the fence language, such as nums or highlight 3 or highlight 2-4, switch the features on, and they apply only when the correct parameters are given. The features work in live-preview mode.

    id:     "obsidian-advanced-codeblock"
    name:   "Advanced Codeblock"
    author: "lijyze"
