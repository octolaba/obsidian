# Attachment Type Icons

Shows configurable file-type icons on internal attachment links in Reading view without changing the underlying Markdown. Link aliases and the original markup are preserved, common types such as images, PDFs, spreadsheets, audio, video and archives are covered, and icons and extensions can be configured per type.

```cue
plugin: {
    id:     "attachment-type-icons"
    name:   "Attachment Type Icons"
    author: "GOODJINC"
    repo:   "goodjinc/obsidian-attachment-type-icons"

    html_url:    "https://community.obsidian.md/plugins/attachment-type-icons"
    github_url:  "https://github.com/goodjinc/obsidian-attachment-type-icons"
    description: "Shows configurable file-type icons for linked attachments without changing Markdown. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add configurable file-type icons to Obsidian internal attachment links in Reading view. Preserve link aliases and original Markdown while showing icons for common types (images, PDFs, spreadsheets, audio, video, archives) and customize icons and extensions per type."

    stats: {
        downloads:  40
        updated_at: 1784530649000
    }
}
```
