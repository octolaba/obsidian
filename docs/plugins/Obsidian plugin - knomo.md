# Knomo

A local memo-first capture plugin for quickly writing down fragmented thoughts. Each memo is written to that day's Daily Note, and monthly Memos Markdown files are created or updated at the same time, so the daily notes keep each day's context while the monthly files give a centralized view for review. The plugin states that memo content, Markdown files and the related data are all stored locally in the vault.

```cue
plugin: {
    id:     "knomo"
    name:   "Knomo"
    author: "BanyanSo"
    repo:   "banyanso/knomo"

    html_url:    "https://community.obsidian.md/plugins/knomo"
    github_url:  "https://github.com/banyanso/knomo"
    description: "A lightweight Memos entry for Obsidian: quick capture, daily context, monthly collection, and local-first control. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Knomo is a local memo-first capture plugin built for Obsidian. It creates a smoother workflow for capturing fragmented thoughts inside your Vault: Each memo is automatically written to the Daily Note of the day; At the same time, Knomo automatically creates or updates monthly Memos Markdown files; Daily Notes preserve the context of each day, while monthly Memos files provide a centralized view for review; Memo content, Markdown files, and necessary related data are all stored locally in your Vault."
```
