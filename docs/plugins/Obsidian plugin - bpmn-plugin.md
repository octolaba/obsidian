# BPMN

The plugin displays BPMN diagrams inside notes from a bpmn code block or a linked .bpmn file, using bpmn-js. Diagrams can be edited with a built-in modeler, driven through token simulation, and exported as SVG.

```cue
plugin: {
    id:     "bpmn-plugin"
    name:   "BPMN"
    author: "joleaf"
    repo:   "joleaf/obsidian-bpmn-plugin"

    html_url:    "https://community.obsidian.md/plugins/bpmn-plugin"
    github_url:  "https://github.com/joleaf/obsidian-bpmn-plugin"
    description: "Enable viewing BPMN diagrams using bpmn-js."
    about:       "View BPMN diagrams interactively inside notes using a bpmn code block or linked .bpmn files. Edit diagrams with a built-in modeler, run token simulations, and export diagrams as SVG."

        downloads:  13260

}
```
