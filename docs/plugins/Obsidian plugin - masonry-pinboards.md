# Masonry Pinboards

Masonry Pinboards shows folder contents in a Pinterest-like waterfall masonry layout, presenting notes and images as draggable tiles. Pin boards can be created and files dragged onto them to pin or move them. Tags can be added, tiles filtered by name or by tag, and images previewed by double-clicking.

    id:     "masonry-pinboards"
    name:   "Masonry Pinboards"
