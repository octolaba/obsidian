# Field Recorder

Field Recorder records audio inside Obsidian with a selectable input device, an output format of M4A, WebM Opus or PCM, and adjustable quality. Waveforms and clipping are visualized, input can be monitored, a capture paused and resumed, and file size and duration displayed. Gain is adjustable and noise suppression and voice isolation can be enabled.

    id:     "field-recorder"
    name:   "Field Recorder"
