# Menu-Bar Time Tracker

Tracks project time from the macOS menu bar with one-click start and stop, and a modal that tags the session when the timer stops. Each session is saved as a Markdown note with frontmatter, and an included Base rolls the totals up per project. Running timers persist across restarts.

    id:     "menubar-time-tracker"
