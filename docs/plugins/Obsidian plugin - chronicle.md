# Chronicle

Chronicle creates or updates notes for films and TV series, filling them with metadata and optionally with locally stored artwork. Details are fetched from OMDB and TMDB, customizable templates shape the note, and entries are saved into a media folder to track what has been watched.

    id:     "chronicle"
    name:   "Chronicle"
