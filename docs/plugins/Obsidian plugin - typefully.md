# Typefully

Publishes a note or a selection to X, LinkedIn, Threads, Bluesky and Mastodon through the Typefully API v2. Drafts, the queue and scheduling are managed from a right-sidebar panel. Vault images are uploaded automatically, posts can be threaded, Markdown is cleaned, and note tags become hashtags.
