# Power Search

This plugin searches notes based on the current line, updating results in real time as you type and covering both Obsidian files and Anki notes. Matching lines and blocks appear in a side pane, so duplicates can be spotted, related ideas linked and notes updated while writing. Results stay updated automatically for immediate context.

```cue
plugin: {
    id:     "obsidian-power-search"
    name:   "Power Search"
    author: "aviral-batra"
    repo:   "aviral-batra/obsidian-power-search"

    html_url:    "https://community.obsidian.md/plugins/obsidian-power-search"
    github_url:  "https://github.com/aviral-batra/obsidian-power-search"
```
