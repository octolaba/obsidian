# CodeBlock Tabs

CodeBlock Tabs groups contiguous code blocks into a tab group, displaying each block as a labeled tab named from its language or title metadata. Switching between tabs is how several language variants or versions of the same example are compared inline.

```cue
plugin: {
    id:     "codeblock-tabs"
    name:   "CodeBlock Tabs"
    author: "jeminmau"
    repo:   "jeminmau/Obsidian-CodeBlock-Tabs"

    html_url:    "https://community.obsidian.md/plugins/codeblock-tabs"
    github_url:  "https://github.com/jeminmau/Obsidian-CodeBlock-Tabs"
```
