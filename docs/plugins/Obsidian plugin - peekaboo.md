# Peekaboo

Peekaboo hides and reveals specific files or entire folders using exact paths, wildcards and per-file exceptions. The hide-list is protected by a password, and visibility is toggled from the ribbon or the command palette. The recorded description frames this as privacy protection, while the About text states that hidden items are visually concealed rather than encrypted.
