# Solo TTRPG Notation

Solo tabletop sessions are recorded in a standardized notation kept inside code blocks, so the narrative text around it stays clean. NPCs, locations and story threads are tagged, oracle questions and dice rolls are logged, and clocks, tracks and timers are followed. Campaigns, tables, random events and meta notes are browsable.
