# isragdd12/simple-progressbar

Repository for Simple Progress Bar, a plugin that renders a progress bar from a code block whose lines carry the bar's options. Its README lists the properties available, among them the displayed name, the maximum and current value, an identifier, a width, a step size, labels for the increment and decrement buttons, a custom format string, and flags controlling whether the name, buttons, identifier, bar and label are shown, together with their defaults.
