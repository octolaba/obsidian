# observerw/obsidian-code-link

Code Link displays code inside Obsidian and limits what is shown to the part being referenced. Code files can be linked and previewed as notes are, and through symbol search, tag search and a code outline a link can point directly at one symbol in a file — a class, a function or a method — so that a note references only the relevant code, which the README suggests matters when taking notes on a complex open-source project. Imported projects are kept in a vault folder, `projects` by default. The README records three prerequisites: the setting that detects all file types must be on, embedded previews render only in reading view, and tag search must be enabled in the plugin's own settings before it is used.
