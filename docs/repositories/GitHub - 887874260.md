# dangehub/obsidian-blur-mode

Obsidian plugin that blurs selected elements of the interface, for privacy or focus and for presentations or screenshots. Elements are picked in a draggable panel opened from a command, where clicking an element adds it to the current preset and clicking again removes it, presets can be created and managed, and objects containing specified keywords can be blurred as well. A ribbon icon toggles the effect for every element in the presets, and the blur amount is set in the plugin settings and applies immediately.
