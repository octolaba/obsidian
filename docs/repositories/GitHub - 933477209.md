# onikun94/line_to_obsidian

The repository records no description; its README presents LINE Notes Sync, a plugin that saves messages sent from the LINE messaging service as Obsidian notes. Messages are organized by date into a configurable folder structure with file names built from templates carrying date, time and message id variables, duplicates are handled, and syncing runs on demand or at intervals, with several vaults distinguished by their own vault ids; only text messages are supported. Setup requires adding a LINE official account as a friend and entering the user id it returns into the plugin settings. The README states that messages are encrypted before transmission, stored encrypted on a Cloudflare server in the Japan region that cannot read them, and deleted after ten days, while advising against sending extremely sensitive information; those are the project's own claims.
