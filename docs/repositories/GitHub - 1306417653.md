# faccuo/voz-notas

VozNotas is a voice-first assistant for Obsidian built on the OpenAI Realtime API: the user speaks, it searches and reads the vault, and it answers aloud rather than through a chat window with a microphone button. It can search and read notes, open one in the foreground or use the note already open, follow links, headings and tags, and write with confirmation by appending to the current note, inserting at the cursor or creating a note in a fixed folder. It can delegate deeper analysis to a stronger reasoning model, and a stated preference is appended to an agent instructions file in the vault that is merged into its instructions next time. Each session is saved incrementally as a plain Markdown note in a sessions subfolder with links to the notes it consulted, so past conversations remain searchable.
