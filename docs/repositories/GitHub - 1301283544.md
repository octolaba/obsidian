# newcodejin/simple-calendar

Simple Calendar renders a minimal calendar with a few decoration options: a marker on days that have a daily note, a choice of dimming, showing or hiding days belonging to the previous or next month, a marker style that can be a dot or any character or emoji, a marker colour that either follows the theme accent or is custom, and a marker size. Changes apply immediately to any open calendar. The date format, folder and template are read from the core Daily notes plugin, or from Periodic Notes when the core plugin is disabled, so the plugin has no settings of its own for those. Daily notes are recognised by filename: a file must carry a readable year, month and day, weekday and time parts do not affect recognition, but reordering the date itself can resolve files to the wrong day and month-name formats stop matching after an Obsidian language change.
