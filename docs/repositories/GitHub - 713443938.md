# timppeters/obsidian-edit-mdx

Obsidian plugin that registers the .mdx file extension as Markdown, so MDX files can be created and edited in the app as if they were ordinary notes; the README states that MDX itself is not previewed. A new untitled MDX file is created from a ribbon button or the file context menu, and selecting an existing one in the file viewer opens it for editing. It is a fork of the obsidian-edit-gemini plugin and records Obsidian 0.11.0 as the minimum version.
