# Kanaries/photes-io-obsidian-plugin

Generates note text from photographs by uploading the image to the Photes.IO service and inserting the result into the notebook. A camera icon in the toolbar starts from a newly chosen photo, and the same icon before an existing image generates notes from that image. The README states that a Photes.IO account and a network connection are required, that free users receive a default amount of credits, and that further use requires purchasing more.
