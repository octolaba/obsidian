# konstantinosGkilas/smart-paste

Repository for Smart Paste, a plugin that intercepts paste events and rewrites the clipboard contents before they reach the note. Its README describes converting HTML into Markdown, covering headings, emphasis, links, images, nested lists, blockquotes, code blocks with language detection, tables and rules, including style-based formatting produced by word processors. It also records replacing a bare URL with a titled link by fetching the page title within five seconds and falling back to the plain URL, stripping a documented list of tracking parameters and configurable additions, removing tracking paths from Amazon product URLs, and collapsing runs of blank lines.
