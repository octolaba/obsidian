# one-wheeled-driver/obsidian-passport

Vault Passport exports an Obsidian document to a self-contained PDF by resolving each wikilink into a real citation. The README explains that every linked note becomes a Pandoc citation, that the plugin collects them into a generated bibliography file and runs Pandoc with citeproc so the output carries a reference list, and that notes absent from the vault are replaced with readable plain text rather than a broken link. A cite key is taken from the linked note's frontmatter when present and otherwise derived from its name, so no note metadata is required to start. Pandoc runs inside a Docker container that ships XeLaTeX, citeproc and a LaTeX template, so Docker is the stated requirement.
