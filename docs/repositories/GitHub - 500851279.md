# SebastianMC/obsidian-custom-sort

Custom File Explorer sorting takes over the order of folders and notes in Obsidian's File Explorer, either by drag and drop through bookmarks integration or by a sorting specification stored in note frontmatter under a sorting-spec key. The configuration language covers fully manual order by explicit names, prefixes, suffixes or wildcards, numbers and dates extracted from titles, compound and Roman numbers, grouping by prefix and suffix with different rules per group, grouping and sorting by note metadata, and mixed manual and automatic rules. Folders without a specification keep Obsidian's standard sorting, and the README points at a much longer advanced document and a wiki for the drag-and-drop workflow.
