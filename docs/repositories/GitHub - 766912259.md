# dream-num/obsidian-univer

This plugin embeds Univer inside Obsidian so that spreadsheets and documents can be created, edited and viewed in the vault. The README records cell styles and formulas as already available in the sheet component, with conditional formatting, data validation and search and replace planned, and ordered and unordered lists, paragraph settings, mixed text and images and multi-column sections in the document component. It reads and saves the xls, xlsm and xlsx formats by default, a behaviour that can be turned off, and its interface is available in English and Chinese.
