# orvpagadua/Code-Azur

This repository holds Code Azur, a dark Obsidian theme whose look is taken from the KodeKloud Notes website and which its own README calls vibe coded. It combines deep slate backgrounds, sky blue accents, Night Owl code blocks and Inter typography. The theme is installed by copying its folder into the vault's themes directory or by using its CSS as a snippet, and it is customized by overriding its CSS variables; aligning Live Preview with Reading view and a possible light variant are listed as open to-do items.
