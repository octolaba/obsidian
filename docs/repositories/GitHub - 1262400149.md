# towishy/owen-exporter

Owen Exporter adds two export workflows to Obsidian: downloading an embedded SVG image as PNG or JPEG from the reading-mode context menu, and copying selected Markdown as rendered HTML or saving it as an HTML file. Its README records the image settings, covering default format, saving directly to a vault folder or asking each time, a filename template with name, note, folder, index, format, scale, date and time tokens, JPEG quality, rasterization scale, background color and optional Markdown reports for batch exports. Commands export every SVG embedded in the current note and diagnose those embeds for external references, oversized output or invalid content, and the plugin falls back to the browser download flow when the native save dialog is unavailable.
