# danrhodes/AutoKeywordLinker

An Obsidian plugin that converts configured keywords into wiki-style links, so recurring names of people, places, concepts or projects need not be bracketed by hand. Keywords and their variations are defined once and then linked as you write or across the entire vault, while existing links, code blocks and other Markdown formatting are respected. The README frames the outcome as graph building through backlinks: every linked mention creates a bidirectional connection that appears in the target note's backlinks.
