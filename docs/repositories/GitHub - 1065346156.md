# sapienskid/pebble-sync

Pebble Sync imports notes from a deployed Pebble backend into an Obsidian vault as atomic notes, on demand or on an interval, with a force mode that overwrites existing files. The README describes deduplication through an on-disk import history, a configurable template, folder and tag-derived naming, and optional embedding of each created note beneath a chosen heading in the matching daily note. It records the prerequisites as Obsidian 1.5.0 or newer, a deployed Pebble API endpoint, and an API key shared between the Pebble app and the plugin.
