# heycalmdown/obsidian-time-inserter

Time Inserter is an Obsidian plugin that inserts the current time at the cursor position, rounded to the nearest five-minute interval and written in 24-hour form with zero-padded hours and minutes. The insertion runs from a command in the palette, which can be bound to a hotkey. The README records that the plugin has no external dependencies and no background processes, running only when its command is invoked; the repository description also mentions an exact format alongside the rounded one.
