# manogna4/obsidian-koncham-workspace

The recorded description calls this an Obsidian workspace enhancement and marks it as not maintained. The README describes a center-panes view in the left sidebar that lists every pane open in the main area, in the manner of vertical tabs in some browsers: it highlights the active note, switches to a pane in one click, and exposes further actions from the tab header's context menu, which the README says helps in modes that hide open panes such as sliding panes or a maximized active pane. A second feature pins or unpins panes, so that pinning all of them forces each new note into its own pane and stops an externally opened note from taking over an existing one.
