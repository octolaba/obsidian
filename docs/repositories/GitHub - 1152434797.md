# kevinyuan/obsidian-chat-bubble-theme

This repository holds Chat Bubble Theme, an Obsidian theme shipped as a plugin because one of its features needs JavaScript: it parses chat-r and chat-l callouts and injects them into the metadata cache as virtual headings so they appear in the Outline pane. It also keeps the Outline pane showing the last active Markdown file when focus moves to a non-editor view, and its settings panel follows Obsidian's language among English, Simplified and Traditional Chinese, and French. All styling is generated from the settings rather than from static CSS, covering four presets named Lavender, Warm, Ocean and Forest, callout emoji indicators, rounded tables with configurable radius, and code blocks with a language label and a copy button.
