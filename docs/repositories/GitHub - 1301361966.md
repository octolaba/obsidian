# yaye-work/note-diary

Note Diary is an Obsidian plugin that places every note on a calendar by its file creation date, so a whole vault can be browsed by day. Days with notes are highlighted in the theme's accent color, more saturated the more notes were created, and clicking a day lists those notes as cards showing title, a short text preview, creation time and tags. Month and year views zoom out and back in, colors follow the Obsidian accent color in light and dark mode, and the README notes that syncing or copying notes to a new machine can reset creation dates so older notes cluster on the setup day.
