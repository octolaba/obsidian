# jamiefdhurst/obsidian-auto-tasks

Obsidian plugin that combines periodic notes with tags and tasks to maintain daily, weekly and project to-do lists. It reads tasks from the previous periodic note and copies incomplete ones into the new note under a header it adds, and it can search the whole note or only specific headers so that a daily list stays separate from other sections. Copied tasks can carry a due date recording when they were originally added, so they can be tracked in the Tasks plugin, and tasks collected from the whole vault can be added to a central Kanban board. The README states the Periodic Notes plugin is required while Tasks and Kanban are optional.
