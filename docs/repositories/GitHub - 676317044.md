# NicoNekoru/obsidan-advanced-table-xt

Obsidian Sheets extends Markdown tables with cell merging, vertical table headings and custom CSS cell styles, including custom row and column styles and inline styles. It is written to work alongside the Advanced Tables plugin, and the README lists automatic formatting in that style, with custom CSS applied to it, among the implemented features. Tables are written as ordinary Markdown tables and the plugin's features are then applied to them, and the README documents both community-plugin installation under the name Sheets Extended and manual installation into the vault's plugins folder.
