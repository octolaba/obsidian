# IKoshelev/Obsidian-Canvas-Filter

Filters what an Obsidian Canvas shows. The README states that selecting one or more nodes and running a filter command hides everything unrelated, with selection by node colour, by arrow connections to and from the selected nodes, or by tags; selected nodes can also simply be hidden. It notes that hidden nodes remain part of the canvas in their original positions and that closing and reopening the canvas restores their visibility.
