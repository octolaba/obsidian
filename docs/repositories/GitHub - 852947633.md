# ckep1/obsidian-autopause

Obsidian plugin that keeps one audio track playing at a time, pausing whatever is already playing when a new clip starts, with an option to reset the earlier clip to its beginning instead of pausing it. Hotkeys play the next or the previous audio file in the current tab and toggle play and pause globally, resuming the last paused audio when it is still available. Another option prevents keyboard focus from landing on audio player elements. The README states it works on desktop and mobile, across tabs and document types.
