# exloseur3d/nier-theme

The Nier theme is an Obsidian theme inspired by the interface of the video game NieR: Automata, and its README states the aim of staying close to the game menus while remaining usable through a warm mono colour scheme. The README records that the author is not a coding expert, made the theme in their free time for personal use first, and then shared it with the community. Documented details include a header font based on the one found in the game, an underline on the first heading level, two close but distinct colours for internal links depending on whether the target note exists, and blue external links carrying a small icon.
