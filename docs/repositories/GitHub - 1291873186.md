# Haniewicz/PrivateSyncPlugin

Private Sync Plugin synchronises an Obsidian vault with a Private Sync Server that the user hosts, whose URL is entered in the plugin settings; the README states that there is no author-hosted default cloud and that no data goes to an external service by default. The plugin keeps a local synchronisation index in its plugin data and detects changes by SHA-256 hash, size and modification time, uploading in batches that send operation metadata before file contents. A device is paired by entering the server URL, a device name and type, and the server pairing password: the first device after server setup pairs automatically, and further devices need approval from an already paired device or a one-time recovery code. Obsidian 1.11.4 or newer and a reachable server are recorded as requirements, with HTTPS recommended from outside the local network.
