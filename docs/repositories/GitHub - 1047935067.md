# Dimagious/snipsidian

Repository for Snipsy, a hotstring expansion plugin whose triggers expand as they are typed, so that a short trigger becomes a longer piece of Markdown such as an empty task checkbox. The README states that expansion is aware of Markdown context and does not fire inside fenced code blocks, inline code or YAML frontmatter, that no scripting or templating language is involved, and that a community catalog of starter packages plus an Espanso import are provided.
