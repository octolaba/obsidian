# anbang278/echo-notes

Echo Notes turns audio into Markdown inside Obsidian: an audio file inserted or linked in a note is transcribed by a command into a companion transcript file, and a view-transcript link is written back into the source note. The README states that configurable AI analysis templates can be chosen from nearby keywords and their structured output written into the matching transcript, and that an experimental Echo Memory workflow turns a transcript and its analyses into meeting pages, candidate memories and long-term profiles. Its privacy notice states that network requests happen only for real-time or file transcription, AI analysis and memory extraction, that real-time mode streams microphone audio to the configured provider, and that content which should not reach external services must not be processed.
