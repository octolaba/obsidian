# MurtazaRaza/prioritymatrix-obsidian

Priority Matrix creates and manages Obsidian notes that arrange tasks in a 2x2 matrix of urgency against importance. It scans the vault for tasks carrying a configurable tag, TODO by default, and also accepts tasks dragged in from the file explorer; tasks can be dragged between quadrants, reordered and marked done. Matrix notes are stored as Markdown files, files whose name contains priority matrix can be opened in matrix view automatically, and scan paths, tags and behaviour are set in the plugin settings.
