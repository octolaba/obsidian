# MSzturc/obsidian-advanced-slides

Obsidian plugin for creating markdown-based reveal.js presentations. Its README lists embedding vault notes into slides, a live preview while editing, themes that change the appearance of a deck, annotations that change the style of slides, export as a PDF document or an HTML presentation, and full support for the Obsidian Markdown syntax. The README points to a demo presentation, documentation and a discussion channel, and records the project as MIT licensed.
