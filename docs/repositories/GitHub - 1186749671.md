# wogong/obsidian-random-plus

Random Note Plus opens a random note in an Obsidian vault, from a ribbon icon or a command, while excluding folders listed one per line in its settings. Excluded paths are given relative to the vault root, leading and trailing slashes are normalised, and matching is prefix-based on the folder path, so a whole subtree is excluded by naming its top folder; a notice appears when no eligible note remains. The README states that the plugin makes no network requests, asks Obsidian only for the list of Markdown file paths to make its choice, and neither reads note contents nor stores or transmits the list.
