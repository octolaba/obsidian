# 7jo-yamato/unfinished-todo-highlighter

This plugin highlights files that contain unfinished Markdown tasks in the File Explorer, and the highlight disappears once every task in the file is completed. The README records configurable highlight colour, background opacity, glow, bold file names and a coloured dot indicator, a choice between highlighting the file name, the background or both, scoping to the whole vault or a single folder, and a status bar count of matching notes. It also maintains a synchronized vault-wide summary note that links each task group to its source note, where completing a task there checks it in the source without removing the completed line, and it warns that the File Color plugin's colour may be overridden on affected files.
