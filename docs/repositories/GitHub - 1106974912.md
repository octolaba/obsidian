# choonkending/obsidian-squire

Repository for Squire, a plugin that surfaces related notes and automates file naming, with each feature usable on its own. The README describes scoring by word overlap, shared tags and outgoing link similarity, a sidebar panel that refreshes as notes are switched, a modal for a one-off lookup, a ribbon toggle, and weights per signal that can be set to zero to disable it. An optional and explicitly experimental mode adds dense-embedding scoring through a selectable transformer model.
