# runnerback/property-icons

Property Icons shows badge icons before file names in Obsidian's file explorer according to rules over note frontmatter, so that a status recorded in a property is visible without opening the note. Rules are organised in groups, each a set of conditions comparing a property to a value by exact equality or by substring, with arrays matching on any element, and each group combining its conditions with either AND or OR. A file matching several groups shows several badges in order, badges update as soon as a note's properties change, and icons come either from a built-in set of platform marks or from an uploaded JPEG, PNG or SVG image. The README is written in English and Chinese.
