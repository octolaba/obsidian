# MeepTech/obsidian-custom-file-extensions-plugin

Obsidian plugin that associates file extensions with Obsidian view types through its settings. The main configuration is a single JSON object given as a parseable string, mapping a view name such as markdown to a list of extensions; a separate mobile configuration can be enabled and falls back to the desktop list when left empty. A toggle allows overriding the default assignment of the markdown view to the md extension, disabled by default to avoid unexpected behaviour, and the README also describes editing a file's extension from the file context menu.
