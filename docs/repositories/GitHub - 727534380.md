# flyer1b/LightRead-master

This plugin synchronises articles from the SyncRead application — described in its README as a read-it-later app comparable to Omnivore — into an Obsidian vault. An API key copied from the SyncRead app is pasted into the plugin's settings page, after which a button in Obsidian's action bar pulls the articles and their annotations across.
