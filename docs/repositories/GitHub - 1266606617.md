# gearheaded/obsidian-github-contributions

Shows a GitHub contribution heatmap in the Obsidian sidebar, in a full-year or single-month view that follows the light or dark theme, alongside a stats bar of total contributions, current and best streak, days since the last commit and the most recent repository. Commits from local Git repositories under a configured root can be counted alongside or instead of GitHub data. Hovering a cell shows the date, total and a per-repository breakdown, and clicking a day opens or creates the matching daily note; five colour palettes, three stats styles and several sizes are offered. Authentication is a GitHub device-flow sign-in or a personal access token limited to the read:user scope, and the README states the token is stored locally and used only against the GitHub GraphQL API, with local Git support disabled on mobile.
