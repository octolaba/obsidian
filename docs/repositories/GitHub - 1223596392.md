# amanxarora/my-todo

This repository holds My Todo, an Obsidian plugin implementing a sorting-based personal todo system with categories, daily and weekly planning, and productivity heatmaps. Tasks carrying bound Obsidian tags are collected automatically into a Kanban-style category board and then promoted into a weekly plan and a daily focus list, with incomplete tasks rolled over or completed ones cleared at a chosen daily threshold time. The README also records event-driven updates when task lists are modified by external tooling, double-clicking a planned task to scroll to and highlight its parent category, and styling that follows the active Obsidian accent colour.
