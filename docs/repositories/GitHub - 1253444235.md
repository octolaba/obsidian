# yetanotherrepo/obsidian-copilot-auto-completion-plus

The repository holds Copilot Auto Completion Plus, an Obsidian plugin that suggests text from a language model based on the characters before and after the cursor and shows it as transparent overlay text. The whole suggestion is accepted with Tab, part of it with the right arrow key, and it is dismissed with Escape or by moving the cursor. The README states that suggestions adapt to the surrounding context, offering prose in paragraphs and code inside code blocks, and lists OpenAI, OpenRouter, DeepSeek, Anthropic, Gemini, Azure OpenAI and Ollama as supported backends.
