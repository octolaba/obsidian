# Ellpeck/ObsidianSimpleTimeTracker

Super Simple Time Tracker inserts a multi-purpose time tracker into a note from a command, and in Live Preview and reading mode that tracker renders with start and end buttons. Each segment can be named or left unnamed, and the time spent is saved and displayed in a table inside the note itself. The plugin also exposes a public JavaScript API through Obsidian's app object, which the README demonstrates from DataviewJS by loading all trackers in a file and printing the total duration of each.
