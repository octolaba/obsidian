# dsarman/better-inline-fields

Better Inline Fields improves working with Dataview-style inline fields such as `Some Field:: value` in Obsidian. It adds a checkbox for toggling inline boolean values and autocompletion of field values from the pages in a configured folder, which takes aliases into account and can be driven by a regular expression when the text is prefixed with a configurable trigger character. The README records the Dataview plugin as needed for the autocompletion, and states the plugin is incompatible with Various Complements when its automatic completion setting is on.
