# 64MM4-KN1F3/regex-line-filter

Regex Line Filter hides every line of the active note that does not match a regular expression supplied by the reader, leaving the matching lines visible and editable; edits are written back to the real note, and toggling the filter off restores the full note with those edits kept. The regular expression is entered in a modal when the filter is activated, JavaScript-compatible and including emoji, and the last five unique expressions are remembered across sessions and offered there for reuse, with entries that can be pinned. Custom filters can be defined and given their own hotkeys, so toggling several of them adds to or subtracts from the visible result incrementally, and the filter itself is toggled from a command or hotkey. Date variables such as a formatted current date, yesterday, tomorrow, last month or next year can be written into an expression.
