# bkis/obsidian-hard-breaks

This plugin adds an editor command that replaces the line breaks of the current document with hard line breaks as specified by CommonMark. The replacement is confined to paragraphs of text and blockquotes; tables, links, lists, code blocks and front matter are left alone. A setting chooses between the two permitted formats, two trailing spaces or a trailing backslash, and the README states that the parsing is delegated to open-source Markdown tools.
