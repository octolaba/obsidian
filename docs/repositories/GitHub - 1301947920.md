# weiya9511/weiya-obsidian-theme

WeiYa is a quiet, restrained Obsidian theme for long reading sessions with a macOS-inspired visual direction, documented in Chinese and English. It supports light and dark appearances, prioritizes Obsidian's official semantic CSS variables, tunes content width, type size and line height for reading, and styles headings, links, lists, callouts, code, tables and sidebars, with translucent desktop sidebars falling back to solid on mobile. The README states that no remote fonts, images, scripts or other external resources are loaded, records a minimum Obsidian version and a desktop version it was verified against, and notes that formal iPhone and iPad testing is still pending.
