# aldrinjenson/obsidian-camera

Camera plugin for Obsidian that takes photos and video recordings and saves them in the vault. When a Markdown file is open it creates and pastes a link to the recording automatically, and it also offers a file picker. The README states that the software is in beta, that it was built primarily with desktop Obsidian in mind, and that the mobile version mostly works but may differ by manufacturer; it is reached from the command palette or a ribbon icon.
