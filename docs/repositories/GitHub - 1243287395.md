# MeMineoff/snippet-commander

Repository for Snippet Commander, a plugin that toggles CSS snippets from the command palette rather than through the appearance settings. Its README describes checking or unchecking several snippets in one dialog, states that no restart or reload is required, and records that the plugin has no dependencies.
