# ruveydayilmaz/obsidian-bento-plugin

Bento Grid creates a customizable bento-style grid inside an Obsidian pane, opened from a pane layout button in the sidebar and filled through an Add Widget button. Widgets can hold rendered Markdown, images, pages and countdowns, and can be dragged, resized with drag handles, duplicated and snapped to the grid, in transparent or standard modes. The README's own notes list improving Markdown rendering, more widget types and mobile responsiveness as outstanding work.
