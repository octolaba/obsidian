# Jyuukun/obsidian-in-progress-checkbox

In Progress Checkbox adds an in-progress task state, written `[/]`, to Obsidian checkboxes. Shift-clicking any checkbox sets it to that state, a plain click on an unchecked or in-progress box marks it completed, and clicking a completed box returns it to unchecked. The README states that this works in both Reading view and Live Preview, and records the plugin as MIT-licensed.
