# KubaMiszcz/MultiStateCheckBoxSwitcher

Multi State CheckBox Switcher is an Obsidian plugin for cycling task checkboxes through several states. It handles the three-state sequence of unchecked, partially done and done, and a customizable set of further single-character states whose defaults the README lists. It toggles on an empty line and works across a multi-line selection, and reverse switching is listed as still to do. The README notes that the states show as icons under themes such as Things.
