# josecoelho/obsidian-tasks-caldav

Tasks CalDAV Sync moves tasks between the Obsidian Tasks plugin and a CalDAV server, mapping them to standard VTODO items so status, dates, priorities, recurrence, tags and notes travel in both directions. Different Obsidian tags can be routed to different calendars and servers, each calendar set to bidirectional, pull-only or push-only, with an auto-sync interval that defaults to five minutes and a dry-run mode that previews changes first. The README records conflict detection with manual or Obsidian-wins resolution, three-way diff delete detection, and reconciliation that matches identical tasks after a calendar switch to avoid duplicates. It states requirements of Obsidian 1.8.7 or later, the Obsidian Tasks plugin and a CalDAV server with VTODO support, and notes a per-device switch on mobile.
