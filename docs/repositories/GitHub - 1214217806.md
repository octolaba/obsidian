# shufflgl/nous-obsidian-theme

Nous is a warm, literary Obsidian theme that combines an editorial aesthetic with LaTeX-style academic typography: a parchment-toned canvas, medium-weight serif headlines, booktabs tables and theorem-like callouts drawn from one palette. Its dark mode keeps the same warm discipline on a near-black surface. The README documents installation from the community store or manually from a release, and notes that the community submission may still be in review.
