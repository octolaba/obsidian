# eust-w/obsidian-image-auto-upload

Uploads images to a remote store and replaces them in the note with the resulting link. Uploads are triggered by pasting an image from the clipboard, by dragging an image file into a note, and from the file context menu for selected image files. The README names GitHub, Qiniu Cloud and Samba as the supported storage services, states that the separate gopic tool must be installed for the uploads, and describes a domain blacklist that prevents uploads from specified sources.
