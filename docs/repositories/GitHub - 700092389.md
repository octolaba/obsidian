# technohiker/obsidian-multi-properties

Multi-Properties is an Obsidian plugin that adds, edits or removes frontmatter properties across many notes at once. The target set can be the active note, a folder from the File Explorer context menu and optionally its sub-folders, a multi-file selection made with Shift or Ctrl/Cmd, the results of a search from the search pane's context menu, or all open tabs in the active tab group. Adding opens a form for property names and values, where an existing property can be overwritten or, for text-based properties, appended to, and editing is done by re-adding a property with the overwrite option; removing lists every unique property found in the selected notes and deletes the chosen ones from all of them.
