# NSDerred/teacher-planner-obsidian

Teacher Planner turns an Obsidian vault into an academic planner built around a school timetable rather than a generic calendar, modelling periods and breaks, class codes, cover and duties, directed time and the difference between a lesson and a meeting. The timetable is laid out once in a visual editor: each class carries a colour, year group, code and default room, and classes are moved, swapped or copied between cells by dragging. For a two-week timetable, an A and B week rotation is tracked automatically, counting teaching weeks and skipping full holiday weeks so it does not drift across a term. The README states that lesson notes are ordinary Markdown files in the vault, that the plugin is free and open source, and that it runs on desktop and mobile with no data leaving the device.
