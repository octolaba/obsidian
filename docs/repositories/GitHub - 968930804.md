# TheJusticeMan/pure-chat-llm

Pure Chat LLM turns an Obsidian note into a conversation with a language model, so the chat lives in the note rather than in a separate window. The README records an agent mode of 13 tools through which the model reads, writes, searches and manages vault content — reading a note down to a heading or block reference, writing in create, append or prepend modes, and searching with boolean logic, regular expressions and context windows — and states that destructive operations require explicit user approval through visual diff modals. It also records real-time voice conversations with tool access through the OpenAI Realtime API, and support for several providers, naming OpenAI, Gemini, xAI, Anthropic, Cohere, Mistral AI and DeepSeek.
