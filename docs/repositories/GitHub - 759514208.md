# OpTi9/obsidian-tekken-notation

Obsidian Tekken Notation renders Tekken move notation as a diagram from a fenced code block whose language is tekken. The README shows the notation written inside the block as comma-separated inputs, where a quoted first element becomes a name, a quoted last element carries trailing information such as damage, unquoted words are kept as custom text, and dash and bracket characters produce combo arrows and brackets. It points to the repository wiki for the list of accepted inputs.
