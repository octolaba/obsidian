# Bin-T/obsidian-simple-wordbook

Repository for Simple Wordbook, a plugin that highlights words from user-maintained wordbooks and tracks learning around them. Its README records several JSON wordbook files that can be added, removed, enabled, reordered by dragging and set read-only, entries carrying phonetics, definitions written in Markdown, aliases and colour tags, and highlighting in reading mode, editing mode and PDFs with alias matching for other forms of a word. It also names a sidebar, a lookup panel, mastery tracking and AI-assisted queries as parts of the learning toolkit, and credits two earlier language-learning plugins as inspiration.
