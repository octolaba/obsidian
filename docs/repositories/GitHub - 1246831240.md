# hunter00zb/pdf-export-compress

This plugin exports a Markdown note to PDF with automatic image compression, using a Python engine built on reportlab and Pillow instead of browser rendering. Its bilingual README records adjustable JPEG quality and maximum width, embedded SVG rasterized through resvg, CJK font registration from macOS system fonts, resolution of both Obsidian embeds and standard Markdown images including a search of the vault root and attachment folders, parsing of tables, code blocks and lists, frontmatter stripping, and a guard that blocks the export when an Excalidraw reference is found. It states the requirements plainly: Python 3 with three packages installed, and macOS only, since the plugin was developed and tested there while other platforms remain unverified. The Python script can also be run on its own from the command line.
