# piglet1236/obsidian-carnelian

Carnelian is an orange theme for Obsidian, described by its README as a modified version of cotemaxine's amethyst theme that works best with the dark base theme. The README records support for the cite element, taken as a snippet from the Palatinate theme. Installation is either through the Custom CSS plugin in the app or manually, by putting an obsidian.css file in the root of the vault, enabling that plugin and refreshing the app. The README heading names the theme Emerald, while the repository and its description call it Carnelian.
