# jacobtread/obsidian-spoilers

Obsidian Spoilers creates hidable blocks of content in a note. A spoiler block shows two buttons, one that shows or hides the content and one that copies the text to the clipboard. Three block languages are recorded: plain hidden text, Markdown content that renders once revealed but does not support nested code blocks, and environment variables, which are parsed with dotenv and displayed as a table whose individual keys and values can be copied.
