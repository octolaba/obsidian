# vpcano/obsidian-smart-link-alias

SmartLinkAlias controls how a note's title is displayed in the internal links pointing at it. The target note declares a full title and a short title as frontmatter properties, and the alias section of a link then selects the display mode: one shows the abbreviation, one the whole title and one both together. The README records base functionality as working in read mode and edit mode, and lists configurable display formats, a tooltip on hovering a shortened link and further ways of selecting the mode as roadmap items.
