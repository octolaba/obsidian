# callumalpass/obsidian-biblib

BibLib manages bibliographic references in Obsidian as ordinary Markdown notes whose YAML frontmatter holds CSL-JSON metadata, so there is no database and every reference is a plain-text file that can be linked, tagged, searched and version-controlled like any other note. Metadata can be fetched automatically from a DOI, ISBN, PubMed ID, arXiv ID or URL through a Create Literature Note command with a lookup field, and the Zotero browser connector can send references straight to Obsidian on desktop. Bibliographies export as CSL-JSON or BibTeX for use with Pandoc, and the README points to a separate command-line project and documentation site.
