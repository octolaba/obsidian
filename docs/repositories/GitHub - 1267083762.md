# viggomeesters/obsidian-newest-files

This repository holds Newest Files, a local Obsidian plugin that lists the newest files added to a vault, including attachments and other non-Markdown files that have never been opened; the repository records no description, so this summary follows the README alone. It registers a sidebar view, reads the vault's whole file list so notes and attachments share one list, maintains its own first-seen index in the plugin's data file, and handles create, delete, rename and modify events while opening files through Obsidian's native behaviour. The README records that only files created while the plugin is active get a reliable first-seen timestamp, that existing files are backfilled from their created or modified time as an approximation, and that editing a file does not change its first-seen value.
