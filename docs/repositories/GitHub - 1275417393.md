# SAN-SchX/scoped-snippets

Scoped Snippets applies CSS snippets to individual Markdown and Base files in Obsidian instead of enabling them across the whole vault, and it includes an editor for writing those snippets inside Obsidian. The README opens with the condition for it to work: a snippet that is to be scoped must be disabled in Obsidian's own appearance settings, because a snippet enabled there is applied globally and cannot be limited to one file. Snippets are kept in the vault's snippets folder and chosen through a picker in the file view header, whose button shows the current selection and offers a clear action. The ribbon icon opens the built-in editor, which lists every file in that folder, opens one for editing or creates a new one, and saves on demand or when a tab is closed.
