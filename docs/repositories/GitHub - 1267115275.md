# laguna821/hanmark

HanMark is a desktop Obsidian plugin that bridges Markdown notes and Korean HWP and HWPX documents, importing HWP, HWPX, PDF, DOCX and XLSX and exporting to HWP, DOCX and HTML. The README records a pinned Kordoc release built in for HWPX generation, import, validation, image embedding, document styles and preview, so producing HWPX, self-contained HTML and an Editorial PDF needs no Python, Pandoc or executable path setup, while DOCX export optionally uses Pandoc. Recorded features include reusable HWPX templates, semantic styles combining body and heading typography, paragraph spacing, page rules and a table profile, styles that stay editable in Hancom Office, and a unified export centre presenting the formats in one grid. Images from HTTP, data URIs or the vault are embedded as document assets, and failures are reported rather than silently replaced.
