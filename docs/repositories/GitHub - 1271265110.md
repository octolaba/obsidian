# 18621063286/xBookmarksObsidian

Copies the user's own X (Twitter) bookmarks into the vault as one Markdown note per bookmark, rendered through a Nunjucks template into its own folder. The README describes an embedded web login on desktop that captures the session cookie, which then calls X's internal GraphQL bookmarks endpoint, with a manual cookie paste as the mobile fallback; the cookie is kept in the plugin's local data file and sent nowhere but x.com. A note holds the full text including long-form posts, author, handle, avatar, timestamp, permalink, images, videos and GIFs, one level of quoted tweet and external-link cards, while threads are deliberately not reconstructed. The README warns that this is unofficial use of a private API at the user's own risk, that it only reads bookmarks and never posts or deletes, and that deduplication by tweet id skips an existing note rather than rewriting it.
