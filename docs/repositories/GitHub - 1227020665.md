# bradbarrish/microblog-publisher

Micro.blog Publisher publishes the active note to Micro.blog over Micropub, covering published posts, drafts, image uploads, categories and updates to a post that already carries a `microblog_url` in its frontmatter. Settings hold an app token, stored in Obsidian's secret storage rather than in the plugin settings file, the blog URL, the Micropub and media endpoints and a Mastodon syndication identifier. Cross-posting is opt-in: publishes send a blank syndication value by default and syndicate only when a note sets the matching frontmatter key. The README discloses that post content, categories, derived publishing metadata and embedded local images are sent to the configured endpoints, and that the plugin carries no telemetry, ads or analytics.
