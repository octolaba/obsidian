# RafaelGB/Obsidian-ZettelFlow

This repository holds ZettelFlow, an Obsidian plugin that builds note-creation and note-editing workflows out of canvas drawings. A flow starts from a root note and continues through steps, which may be notes, groups or canvas cards, connected by arrows that express how one step leads to the next, and each step can carry actions such as a prompt that modify the note being created or edit an existing one. The README notes that the canvas editor flow is configured separately from the canvas creation flow, and points to documentation, a roadmap and community-contributed flows, steps and actions that can be imported into a vault.
