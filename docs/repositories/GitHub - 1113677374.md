# takeshy/obsidian-gemini-helper

Provides chat, workflow automation and retrieval-augmented search over a vault using the Google Gemini API, on desktop and mobile. The chat streams responses, accepts file attachments and slash-command prompt templates, and is extended by reusable agent skills for Markdown, Canvas and Bases plus versioned external skills from a named repository. A visual node editor builds multi-step workflows with MCP tool support, and further features include token and cost tracking, folder-scoped access for the model, encryption of chat history and logs, and an edit history with a diff view. The README states a Google Gemini API key is required and tabulates which capabilities a free key covers.
