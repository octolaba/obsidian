# semisenioritis/Tag-Folder-Explorer

Tag Folder Explorer builds a virtual folder tree out of Obsidian's nested tags, so a file carrying several nested tags appears in several places at once while remaining a single file. A sidebar shows that tree for navigation, files are placed by their metadata tags and untagged files are gathered under their own entry; the README contrasts this with a conventional explorer, where each file is locked into one directory. It also records a metadata file per virtual folder in which that folder's context and purpose can be documented, and colour-coded legends for files and folders where creating a subfolder would be too heavy a separation.
