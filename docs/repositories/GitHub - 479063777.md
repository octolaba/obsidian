# Enveloppe/obsidian-enveloppe

The repository holds Enveloppe, an Obsidian plugin that publishes notes from a vault into a GitHub repository, so any static site generator can build from them. Its README records conversion of wikilinks to Markdown links, link rewriting according to the reader's settings, removal of unpublished and deleted files from the repository, renaming of folder notes to a chosen name, and support for Dataview queries in their several forms as well as other syntax a template understands. It warns clearly that the plugin should not be used to synchronise or back up a vault and that converted files in the repository should not be opened in Obsidian.
