# enhen3/Tidelog

TideLog links Obsidian daily notes into a Plan, Review and Insights loop, and its README is written mainly in Chinese with an English section. Plan lists the day's tasks across daily, weekly and monthly cycles, supports subtasks, dragging and carrying unfinished items forward, and keeps an inbox for undated ideas; Review walks a configurable set of questions for the current or a past day. Insights generates weekly and monthly reports only once enough Plan and Review cycles exist, the README stating at least three for a week and eight for a month, plus a long-term profile it calls the reader as seen by the AI. It records that data stays in the vault, that AI calls happen only on an explicit action, and that the free tier uses the first two enabled review questions while Pro uses the full flow.
