# lynchjames/obsidian-writing-goals

Writing Goals sets word goals on notes and folders, which the README describes as a simplified version of a goals feature in Ulysses. A goal is added from the file explorer context menu or from a command; for a note it is written into the frontmatter under a property name that defaults to word-goal and is configurable, and the same routes can set a daily goal, stored under its own property, that resets each day beside the overall goal. Goals are updated through the command, the context menu, or by editing the frontmatter value directly, and commands show the goal and its progress for the current note or any file or folder, updating as text is typed.
