# bartkessels/daily-note-calendar

Daily note calendar adds a calendar view for navigating and creating periodic notes: clicking a date opens the daily note, the week number the weekly note, the month name the monthly note, the quarter the quarterly note and the year the yearly note. Each kind of note has its own name template and folder, both written with date-fns formatting rules, which the author's README gives as the reason the plugin was written — another calendar plugin could not handle a custom daily-note format. Commands open each periodic note, move to the next or previous week or month, and reveal the current note in the calendar, and notes created on a given day can be listed under its date.
