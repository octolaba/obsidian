# Neurocoda/semantic-linker

The repository holds Semantic Linker, an Obsidian plugin that recommends related notes from local metadata and inserts curated links. Its README states that it indexes note titles, filenames, tags, descriptions, type and kind rather than embedding note bodies, so it works best where front matter and filenames are already consistent. A right-sidebar graph shows the active note with existing links as connected nodes and unlinked but related notes as candidates, placing more relevant candidates closer to the center; clicking a candidate adds it to the configured links section and clicking a connected node removes it.
