# Mikodin/obsidian-scribe

Scribe records voice notes in Obsidian, transcribes them, and then summarises and enriches the resulting note through a language model. Transcription goes through AssemblyAI or OpenAI Whisper and summarisation through OpenAI, recording can be paused and resumed, and the README states that each step is saved progressively so that no single step is a point of failure, a design it attributes to mobile use and marks as work in progress. Asking a question aloud during a recording, prefixed by a wake phrase, has the answer fetched and integrated into the note, and further features are custom prompt templates, a language selection, and automatically generated Mermaid charts. Recording is controlled from a ribbon menu, and further commands are exposed in the command palette.
