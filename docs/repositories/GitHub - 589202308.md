# lnbgc/obsidian-jotter

Jotter is described as a distraction-free custom theme for Obsidian. Its README records Style Settings support and design adjustments for the Canvas core plugin and for the Kanban, Calendar and Dataview community plugins. Through Style Settings the README lists six colour themes, thirteen predefined accent colours, a borderless interface, wrapped file and folder titles in the explorer, a hidden note title in the editor, and colour and style controls for headings, bold and italic text and internal and external links.
