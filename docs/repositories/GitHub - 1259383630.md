# hiforrest/source-mode-inline-images

Repository for Source Mode Image Renderer, a plugin that shows an image preview directly below an image link while editing in Source mode. Its README argues that Source mode keeps the text stable because syntax never appears or disappears under the cursor, but that images are otherwise invisible there, and states that the plugin supports the width suffix after the pipe in an embed, shows a message when the file cannot be found, and leaves Live Preview and Reading view untouched. Its documentation is written in English and Chinese.
