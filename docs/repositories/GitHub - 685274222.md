# drPilman/obsidian-graph-nested-tags

This small plugin links nested tags to their parent tags in Obsidian's graph view, so the structure of a tag hierarchy becomes visible there. The README states that Obsidian offers no API for working with the graph, that the method used was found by reverse engineering, and that the author therefore has no confidence it will keep working on newer versions. It points to the forum feature request behind the plugin and credits code from folders2graph as its inspiration.
