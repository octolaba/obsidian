# liuhaoXD/obsidian-enhanced-search-replace

Enhanced search and replace adds an inline find panel to the Obsidian editor, with a find-and-replace mode and toggles for match case, whole word and regular expressions. The README states that matches are highlighted in the current editor and that Esc closes the panel even when the input is not focused. Two commands, Find and Find and replace, ship without default hotkeys and are bound in Obsidian's Hotkeys settings; the README notes that the panel is implemented as a CodeMirror 6 panel and reaches some editor internals through Obsidian runtime objects.
