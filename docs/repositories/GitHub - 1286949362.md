# liaoqiuyi681-blip/floating-text-overlay

Floating Text Overlay adds movable, resizable Markdown annotation widgets over an Obsidian note, leaving the underlying file untouched. A label is placed anywhere over the note, can be linked to a selected passage of source text and shown or hidden again by holding the platform modifier and clicking that text, and it is dragged by its header and resized from a lower-right handle. Its controls stay hidden until the label is hovered or focused, its background colour and transparency are set from the right-click menu, and its content can be switched to a rendered Markdown preview. The README states that since version 0.7.0 labels use document-space coordinates and scroll with the note content instead of staying fixed in the viewport.
