# DMDerelyn/Obsidian-smart-relations

Repository for Smart Relations, a plugin that builds retrieval indexes over the vault locally, which the recorded description and README both state runs entirely offline with no external API calls. The README enumerates six indexes covering note identifiers, an inverted index of stemmed terms with frequency and position, tag co-occurrence, character trigrams for fuzzy matching, a bidirectional graph built from a frontmatter relation field, and per-document statistics. When a note is opened every other note is scored using several signals, among them BM25 ranking and tag overlap.
