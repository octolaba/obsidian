# zhouhua/obsidian-export-image

The repository holds Export Image, an Obsidian plugin that renders a note as an image, saved to a file or copied to the clipboard. Its README records text and image watermarks, optional author information such as an avatar and a name, output at twice the resolution for high-density screens, an adjustable image width for different destinations, and display of the note's metadata. It also records exporting only a selection, exporting every note in a folder at once, and a preview interface for the configuration.
