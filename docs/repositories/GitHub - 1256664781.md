# liamzy2021/Obsidian--Modular-Theme-Dashboard-Free-Drag-and-Drop

Modular Theme Dashboard builds a dashboard homepage from cards placed freely on an absolutely positioned canvas, with widgets covering weather, calendar, news and other functions, eight themes, and a set of file viewers. The README, written in English and Chinese, records a table viewer with adjustable decimal precision and multi-sheet tab switching, a viewer for `.ppt` and `.pptx` files with text extraction, and a weather module drawing on five providers including Amap, Open-Meteo, wttr.in and OpenWeatherMap or a custom URL template. It also records an interface translation feature that sends the dashboard's interface strings to an OpenAI-compatible endpoint with a key the user supplies, renders them in a chosen language, and saves the result so it can be selected again later.
