# ArhiChief/obsidian-note-from-form

Note From Form is an Obsidian plugin that defines an input form and generates a note from it together with a template. The README positions it beside the Templates core plugin and From Template, extending them with strongly typed fields, initial values and user-defined JavaScript functions for generating values, and templates may be written in YAML, like Obsidian note properties, or in JSON. Templates are registered by pointing the settings at their location, optionally through an Obsidian property naming the template definition; calling a template shows the generated form and writes the resulting Markdown into a new note whose name and folder the template determines. The README warns that version 2.0 introduces breaking changes and that templates written for 1.x may need updating.
