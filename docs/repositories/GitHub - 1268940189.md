# yabswannalearn/html-experience

HTML Experience opens `.html`, `.htm`, `.mht` and `.mhtml` files directly in Obsidian, running their JavaScript inside sandboxed iframes. The view offers zoom by buttons, Ctrl and scroll or commands, in-page search with Enter and Shift-Enter to step through matches, a full-screen toggle, and automatic reloading when the file is edited outside Obsidian. A floating button switches between dark and light presentation, with options to keep the document's original colours or set a custom background, links open in the system browser, and the README states that invalid files produce an explanatory error message. This note is grounded in the README alone, as the repository records no description.
