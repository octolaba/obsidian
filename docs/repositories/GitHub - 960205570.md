# ThePharaohArt/Obsidian-RetroOS98

RetroOS 98 recreates the Windows 95 and 98 style in Obsidian, with support for light and dark mode and for tablet and phone views. Its v0.0.8 changelog records Style Settings options for color schemes based on actual Windows 95 and 98 schemes and Windows Plus, a Style Settings option for scrollbar width, more visible code block colouring, and callouts brought in line with the theme. The README credits Matoseb for the Windows 95/98 scrollbar, SMUsamaShah's Windows 98 Edition theme for the slider and checkbox style, and LennZone's Enhanced File Explorer Tree, and asks that this repository be linked when parts of the theme are reused.
