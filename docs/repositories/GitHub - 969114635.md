# Jatin-Shihora/Obsidian-lofi-plugin

No repository description is recorded, so this body is grounded in the README alone. Lofi Focus plays lofi music inside Obsidian alongside a Pomodoro timer, streaming from pre-configured stations or playing local MP3 files from any vault folder, with play, pause, next and previous controls, volume control and a status bar display. The focus timer has configurable work and rest durations, automatic transitions between them, and start, pause and reset controls in the status bar. The README also records optional ambient particle animations, rendered on a canvas and enabled in the settings.
