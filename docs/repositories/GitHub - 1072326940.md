# Nichtigott/NichNeumor

Nichtigott/NichNeumor holds NichNeumor, a neumorphism-styled Obsidian theme with light and dark modes, a paper-like surface and press feedback on buttons. Its README describes a low-saturation colour scheme, typewriter keypress animations, headings centred through note properties, a syntax for floating and sizing images to allow text wrapping, and printer-style tables. It also records compatibility work for plugins such as Excalidraw and Better Export PDF, and ships both an English and a Chinese README.
