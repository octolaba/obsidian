# THANSHEER/obsidian-mermaid-flow

Mermaid Flow edits Mermaid flowcharts on a drag-and-drop SVG canvas, moving nodes, drawing connections, resizing and multi-selecting while the plugin writes the underlying Mermaid code. It reads existing blocks and writes them back, which the README says preserves custom syntax, and stores manual node positions in hidden Mermaid comments so an arrangement survives reloads while the diagram still renders normally. Node shapes and subgraphs, diagram theme and flow direction, layout presets with a lock, undo and redo, zoom and export are reachable from the toolbar, next to a raw code view that syncs in both directions. An optional AI assist drafts a flowchart from a text prompt through a provider the user configures.
