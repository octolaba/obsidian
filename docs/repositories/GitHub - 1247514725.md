# dashedman/obsidian-nothing-theme

Obsidian Nothing Theme is a theme inspired by the visual identity of the Nothing company, bringing that clean, minimalist design language into Obsidian. The README documents installation by downloading the repository into a folder called Nothing under the vault's themes path, and notes that only manifest.json and theme.css are required.
