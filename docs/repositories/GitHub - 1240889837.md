# grumpydev/vaultbox

The repository carries no description; its README presents Vaultbox as an Obsidian plugin that syncs a vault with a selected Dropbox folder on desktop and mobile. It is aimed at people already keeping a vault in Dropbox on a desktop machine who cannot use that folder from Obsidian mobile, and it talks to the Dropbox API from inside Obsidian so phones and tablets need no Dropbox desktop client. The documented behaviour is deliberately conservative: manual sync that can require confirmation of a prepared plan, automatic sync on startup or on an interval using the same planning engine, a simulation that reports what a sync would do without changing anything, exclusion of the Obsidian configuration folder by default, conflicts that stop for a decision instead of overwriting, and guarded remote writes using Dropbox revision values with backoff on throttling.
