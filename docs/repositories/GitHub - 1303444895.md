# zhengxn1/quick-capture

Quick Capture sends text, links and short notes from an iPhone or Android device to the Obsidian desktop app on macOS or Windows through a Cloudflare Worker and D1 database deployed in the user's own account. The README states that captures arrive from the iOS Shortcuts share sheet or Android automation tools, stay queued while the computer is offline, and are appended to one daily Markdown table once the desktop plugin is available; queued content is encrypted with AES-256-GCM and messages are deleted after the desktop plugin confirms storage. The desktop plugin is required, the phone acts only as a sender and does not need the mobile app, and the recorded text states that no custom domain, server or public relay is needed.
