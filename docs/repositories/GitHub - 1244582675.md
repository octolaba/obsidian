# chefrocker/obsidian-awesome-livedata-plugin

Obsidian plugin that displays live MQTT and REST API data inside notes, so a note can act as a dashboard for values such as sensor readings or a service status. A single code block carries a source discriminator choosing MQTT or REST, the topic or URL, a display variant of number, text, badge or toggle, a label, unit and a path into the payload, with REST polling configurable for interval, caching and retries. MQTT is reached over WebSockets on desktop and mobile or over TCP on desktop only, one subscription per topic is shared across widgets, and each point shows a live, stale or offline status. A wizard composes blocks, a migration command converts the older block syntaxes, and credentials are held in the OS keychain on desktop and only for the session on mobile.
