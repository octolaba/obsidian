# p-acharya/aql-syntax-highlighting

An Obsidian plugin that adds syntax highlighting for the ANNIS Query Language in fenced code blocks tagged aql. It registers an AQL CodeMirror mode with token highlighting for strings, operators, metadata, node references and node classes, and ships the styling in its own stylesheet so highlighting works after installation. The README introduces ANNIS as an open-source search and visualization platform for annotated linguistic corpora and links its project and documentation; the repository carries no description.
