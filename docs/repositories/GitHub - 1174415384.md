# JustWSH/obsidianExportHTML

This repository holds Export to HTML, an Obsidian plugin that exports notes to standalone HTML documents, documented in a bilingual Chinese and English README. The export carries a hierarchical table of contents generated automatically from the note's headings, shown in a sidebar of adjustable width with smooth scrolling, and a classic colour scheme the README describes as clean and professional. Images are converted to Base64 and embedded in the document so a single file can be shared without an extra image folder, with PNG, JPG, GIF, SVG and WebP among the supported formats.
