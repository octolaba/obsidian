# tyler-dot-earth/obsidian-blockreffer

Blockreffer searches a vault for blocks carrying a caret block reference and embeds them. The README describes exactly two features — embedding blocks with block refs and searching the vault for them — and points at the Obsidian documentation for what block references are. It can be installed from the community plugin browser or, for beta versions, through BRAT, and its commands accept hotkeys assigned with the core Hotkeys plugin.
