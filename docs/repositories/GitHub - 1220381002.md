# guykahalani/the-dm-compendium

The DM Compendium searches Dungeons & Dragons 5th Edition monsters, spells and items and inserts formatted entries at the cursor from Obsidian's command palette. Monsters are written as statblock code blocks carrying the YAML fields the Fantasy Statblocks plugin expects, which the README says lets them be rendered, added to a bestiary or an initiative tracker and used for rolls; spell and item entries render as inline cards in reading view. Which sources appear in search results is set in the plugin settings, and selected compendium data is cached locally for faster searching after the first load. The README discloses that the plugin downloads compendium JSON files from a GitHub raw address when the cache is missing or the refresh command is run.
