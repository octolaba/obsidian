# wlunan/vault-cleaner

Finds and removes orphaned files and attachments in a vault through a dashboard opened from a ribbon icon, with scan status and statistics shown as it runs. The README defines a file as orphaned only when nothing links to it, it links to nothing itself, and no Canvas file references it; attachments are recognised by the configured attachment paths. Files are previewed and confirmed before deletion and are moved into a custom trash folder rather than removed outright, while recently modified files are protected for a configurable number of days. Scheduled automatic cleanup, whitelist folders and regular-expression ignore patterns are configurable, and the interface is available in English and Chinese.
