# eatcodeplay/obsidian-simple-banner

Simple Banner adds a header image to a note, controlled through a single frontmatter property whose value is described as always a well-formed url or link so that it can be read by other tools such as Dataview. External and internal images are supported, including image URLs, wikilinks, Markdown links and Obsidian URLs, and a second frontmatter property adds an icon that may be text, an emoji or an image; time and date display is also supported. The property names themselves are customisable, and settings cover image repeat, horizontal and vertical offset, autohiding the frontmatter properties, and a view offset that moves the whole note view to accommodate other plugins, with every setting configurable per device across desktop, tablet and mobile. The README records support for video files as an experimental feature added in version 0.4.0.
