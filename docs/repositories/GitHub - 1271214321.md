# usero2/obsidian-themes-LikeXP

usero2/obsidian-themes-LikeXP holds LikeXP, a retro Obsidian theme that recreates the Windows XP look, with Luna Blue for light mode and Royale Noir for dark mode. The README lists window backgrounds and 3D beveled buttons, a blue titlebar gradient, classic Windows 9x and XP scrollbars, dropdowns and inputs with flat borders and blue focus rings, dialog tabs and modal designs, and folder icons replacing the default collapse arrows in the file explorer.
