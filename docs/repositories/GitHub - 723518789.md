# rudimuc/obsidian-coder

Transcoder encodes and decodes text in Obsidian notes between several formats. The README lists atbash, Base16, Base32, Base64, Base85 and ROT13 as the supported algorithms, while the recorded repository description names base64 and ROT13 only. Each direction is exposed as its own conversion with a Markdown keyword, so text to base64 and base64 back to text are separate operations, and the README tabulates every source, destination and keyword.
