# giuseqpe/vimium-for-obsidian

Vimium Navigation adds modal, keyboard-first navigation to Obsidian in the spirit of Vimium. It starts in Normal mode, where printable keys drive the interface instead of editing the note: j, k, h and l move the editor cursor or scroll other views, gg and G reach top and bottom, d and u move half a page, f shows compact hints over visible links, buttons, tabs, ribbon controls and sidebar items, and slash with n and N finds text in the active note. Pressing i or clicking an editable field enters Insert mode and Escape returns, while question mark opens the complete in-app reference. The README also lists note search and opening, history and tab navigation, copying and opening obsidian note links through the clipboard, and settings for scrolling, hint characters and the mode badge.
