# qawatake/obsidian-binary-file-manager-plugin

Obsidian plugin that detects new binary files in a vault and creates a Markdown file of metadata for each one, so that full text search, tags, aliases and internal links reach material that is otherwise opaque. The README's quick start enables automatic detection in the setting tab and then adds a static file such as a PDF, which produces a metadata file in the root directory. Names and contents of those files come from templates using a documented syntax for creation and current dates, internal or embedded links, and the static file's path.
