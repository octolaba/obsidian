# retypeapp/retype-for-obsidian

A desktop-only plugin for macOS, Windows and Linux that installs and drives the Retype documentation CLI from inside an Obsidian vault. A sidebar panel offers start, stop and build buttons, a scrollable console with color-coded error, warning, success and URL lines, and a server status card showing stopped, starting, running or error state with the server URL as a link; an optional status bar item mirrors that state. The plugin locates the nearest `retype.yml` relative to the active document, detects the CLI on the system PATH including nvm, Homebrew and dotnet tool locations, and when it is missing replaces the controls with a setup guide offering a one-click install through npm, yarn or dotnet.
