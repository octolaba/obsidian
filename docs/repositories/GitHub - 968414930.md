# dubefab/obsidian-TerraFlow

TerraFlow is a nature-inspired Obsidian theme combining warm earthy palettes, glass and depth styling, and flowing animations. It ships ten seasonal palettes, each with light and dark variants except the dark-only Academia, covering headings H1 to H6, callouts, code syntax and highlights, all audited for WCAG contrast. Other options include a low contrast mode, heading intensity and per-level colour pickers, wide-gamut and custom accents, seven heading styles, four link and four callout styles, eighteen alternate checkbox states, table density and striping controls, a deep focus mode with a sepia palette and typewriter dimming, and per-note cssclasses for banners, card grids and widened pages, tables or images. Style Settings unlocks the full option set, while the Melange palette and the card layout are credited to Baseline and to kepano's Cards snippet.
