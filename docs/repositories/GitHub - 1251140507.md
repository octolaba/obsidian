# rafaelmehdiyev/obsidian-vim-cheatsheet

Vim Cheatsheet displays a searchable, categorised vim command reference inside Obsidian, which the README motivates by the app having built-in vim key bindings but no built-in way to look those bindings up. It covers more than 150 commands across motions, operators, text objects, visual mode, search, marks, scrolling and insert shortcuts, filtered by category, navigated with arrow keys, and searched by a query whose words are matched separately so a phrase finds several related commands. It opens either as a floating modal dismissed with Escape or as a docked sidebar that stays open while editing, both following the current Obsidian theme, with per-command examples that can be turned off in settings, and it works on mobile.
