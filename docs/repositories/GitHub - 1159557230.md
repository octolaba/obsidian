# EtsefZale/obsidian_gemini-ai-commander

An assistant for note processing built on the Google Gemini API, offering a quick chat whose answer is inserted into the note, a summarize action that replaces or inserts generated notes, and a custom-instruction action over the current note and its attachments. Responses stream in real time and generation can be cancelled from the command palette or the sidebar ribbon. Embedded notes, images, audio files and PDFs referenced through wiki links, markdown links, aliases or block references are read as input, and Excalidraw drawings are rendered through that plugin's own API rather than read from disk. The README states the original note text is restored if the API call fails or a rate limit is hit, and that a free Google AI Studio key is needed.
