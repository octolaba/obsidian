# Razzdol/obsidian-sounders

Repository for Sounders, a plugin that plays audio tracks and playlists from a sidebar button. Its README records a configurable left-click action on the icon for playing the next track or toggling playback, a right-click that opens the player and settings, adding files one by one or importing a whole folder as a playlist, and an optional right-sidebar player with a compact mode and controls that stay in place while the track list scrolls. It also lists drag-and-drop ordering, renaming by double-click, shuffle and repeat modes, playback speed between half and double with a reset, a seek bar, search within the active playlist, and command palette entries, and states where tracks and their order are stored inside the plugin folder.
