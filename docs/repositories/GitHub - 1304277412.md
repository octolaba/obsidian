# xupisco/obsidian-yabacavi

Yabacavi adds a calendar view to Obsidian Bases, laying notes out as cards on a day, week or month grid placed by any date property, with an option to also show undated notes on the day their file was created. Cards show whichever properties the base makes visible, so a calendar and a table over the same base stay in sync, and dragging a card to another day rewrites its date property while preserving the time of day, the timezone offset and a date-only shape. A property's values can be mapped to accent colours drawn as a bar or a bullet, accent thickness and card font sizes are adjustable, and Todoist tasks can optionally appear on the same grid beside the notes. The README records Obsidian 1.11.4 or later with the Bases core plugin enabled as the requirements.
