# olvidalo/obsidian-chord-sheets

Renders chord sheets in Obsidian, both chords written over lyrics and inline chords in brackets, inside fenced blocks marked as chords. The README lists chord symbol highlighting with automatic detection of chord and lyric lines, and explicit end-of-line markers borrowed from the Chord Lyrics plugin when detection fails; chord diagrams shown on hover or above the block with alternative fingerings, rendered locally without calls to an external service; custom chord shapes written in brackets, including capo and barre forms and higher fret positions; transposition; and autoscroll. Guitar, ukulele and mandolin are supported, the rendering works in editing, live preview and reading mode, and the plugin follows the active theme colours.
