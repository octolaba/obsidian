# RyotaUshio/obsidian-font-size

This repository holds Font Size Adjuster, described upstream as an Obsidian plugin to adjust font size via commands. The README says the plugin adds Increment font size and Decrement font size commands usable from hotkeys or the command palette without opening the appearance settings, and it distinguishes them from Obsidian's built-in zoom commands, which resize every interface element while these affect only the editor font. It suggests a set of macOS hotkeys that keeps the two pairs adjacent.
