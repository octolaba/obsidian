# bytetiles/obsidian-cornell-notes

The repository holds Cornell Notes for Obsidian, a plugin that renders fenced cornell blocks as a two-column Cornell layout in Reading view, with cues on the left and notes on the right at configurable widths. Both columns accept ordinary Markdown, including lists, tables, code blocks, callouts, math, mermaid diagrams, images and wikilinks, and the columns stack vertically on narrow screens. The README states that the content is stored as plain text readable without the plugin, and that headers, borders and column widths are set in the settings or per block through directives.
