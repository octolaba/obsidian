# makediff/obsidian-wucai

This plugin is described by its README as the official integration maintained by the WuCai team for exporting digital highlights into Obsidian notes. After the plugin is enabled and connected to a WuCai account, an initial sync is run and later syncs can be configured to happen automatically or manually. The README records that the plugin requires a subscription to WuCai, a paid service for aggregating and reviewing reading data in one place.
