# cteplovs/obsidian-jupyter-viewer

Jupyter Notebook Viewer opens ipynb files directly in Obsidian, rendering markdown cells through Obsidian's own renderer, code cells with Python syntax highlighting and execution-count badges, and cell outputs inline. Stream output appears as monospace text with stderr in an error colour, HTML results such as pandas and polars tables become scrollable tables, error tracebacks are stripped of ANSI escape codes, and base64 PNG output is shown as an inline image. Colours come from Obsidian CSS variables so the view follows light, dark and community themes, and the plugin is plain JavaScript with no build step. The README states that it needs Obsidian 1.0.0 or newer, is desktop only, and supports notebook format version 4.
