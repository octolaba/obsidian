# PKM-er/obsidian-editing-toolbar

Obsidian plugin that adds a word-processor-style editing toolbar and a compact text editor modal, so common markup and commands can be applied without memorising hotkeys or Markdown syntax. The README records the toolbar as configurable in position, including a top bar and a cursor-following mode, and states that the 3.x version was refactored with further features documented in a repository discussion. It is described as a modification of the unmaintained cMenu plugin and suggests pairing with the Enhanced Editing plugin for more editing commands.
