# tionis/obsidian-hedgesync

The repository holds Hedgesync, an Obsidian plugin that links each note to one HedgeDoc document through a configurable frontmatter property and syncs between them. The README records commands to push the active note, pull the linked document back, open it, create a HedgeDoc document from the active note while writing the link into frontmatter, create a note from a document URL or note ID, pull every linked note while preserving local frontmatter, and toggle live sync for the active note. The frontmatter value may be a full URL, a bare note ID resolved against a default server, or an object carrying a note ID and server URL. Settings record the default server URL, an optional session cookie for private notes, auto-push on save with a debounce and an overwrite warning; the README states that a reachable HedgeDoc 1.x server is required and that mobile is deliberately unsupported.
