# dualyze-ai/obsidian-dualyze-structure

Dualyze Structure splits a long note into separate notes along its headings: each second-level section becomes its own note, while deeper headings stay inside it. The README states that every split note receives a parent property in its frontmatter linking back to the source note, that the original note is rewritten as a structure index of links, and that a Map of Content is generated with a Mermaid flowchart knowledge map. The command runs from the editor context menu, the file explorer context menu or the command palette, and a confirmation dialog lists the detected sections and the number of files before anything is written.
