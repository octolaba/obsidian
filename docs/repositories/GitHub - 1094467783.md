# ThreeM-MMM/note-illustrator

This repository holds Note Illustrator, an Obsidian plugin that reads the text under a user-defined heading in the active note, sends it to an OpenAI-compatible image API, and replaces a specified placeholder image with the generated art. DALL-E 3 is the default target, and the README records a configurable API endpoint and model name, a regenerate path that finds the last generated image when no placeholder is present, a confirmation prompt before overwriting, optional deletion of the replaced file to the system trash, and optional smart sizing that reads the placeholder's dimensions. It was originally built for tabletop game masters creating images of characters and locations.
