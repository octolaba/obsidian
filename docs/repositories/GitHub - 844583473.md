# alberti42/obsidian-bibdesk-integration

BibDesk Integration parses external BibTeX libraries in the background and connects them to the PDF++ plugin so the PDFs attached to bibliography entries can be managed and opened from Obsidian. The README states it works with any standard BibTeX library while some features target libraries maintained with BibDesk on macOS, notably resolving the numbered `bdsk-file` fields, which are macOS bookmarks that keep working when a file is renamed or moved. It is written for libraries of ten thousand papers and more: parsing runs on a dedicated background thread and uses a custom parser built with Peggy, the library file is watched and re-parsed when it changes, and it may live outside the vault; the speed comparisons quoted there are the author's own and were not verified.
