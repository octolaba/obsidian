# al0cam/AutoMover

Obsidian plugin that moves files and notes into designated folders according to rules the user defines. Its README presents it as an alternative to farux's auto-note-mover, motivated by that plugin's lack of regular expressions and capture groups in destination paths; here a destination path can be built from capture groups and is created when it does not already exist. Rules match on filename patterns, on tags, or on project metadata held in frontmatter, exclusion rules protect specific files and folders, and moves can trigger on file open, on manual execution, or on a timer. Settings can be exported and imported, and the linked documentation covers the interface and each kind of rule separately.
