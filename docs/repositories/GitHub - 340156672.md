# Vinzent03/obsidian-hotkeys-for-specific-files

The repository holds Hotkeys for specific files, an Obsidian plugin that opens chosen files by keyboard shortcut. Its README records that the files are listed in the plugin settings, that a command is generated for each one, and that the shortcut itself is then assigned in Obsidian's own hotkeys section. It also records optional support for the Hover Editor plugin, which lets the same command open the file in a hover editor once that setting is enabled.
