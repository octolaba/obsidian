# junghyunbak/graph-depth-gradient

Graph Depth Gradient is an Obsidian plugin that colours graph view nodes by how deep their file sits in the folder tree, as a gradient between a start and an end colour. The README records depth measured as the number of parent folders in a path and the gradient applied independently per top-level section, so each section's shallowest note takes the start colour, its deepest descendant the end colour, and intermediate depths are interpolated; files at the vault root form their own section and nodes that are not vault files keep their colour. Settings record only the two colours, defaulting to an achromatic pair. The README states that because it overrides node colours the plugin is mutually exclusive with other graph colouring, that disabling it restores the original colours, and that it is desktop-only and uses internal renderer APIs.
