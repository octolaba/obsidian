# LightVolk/daily-weight-prompt

Daily Weight Prompt asks for the current body weight and saves it into today's daily note frontmatter, prompting automatically after Obsidian finishes loading and also from a command that opens the prompt manually. It finds or creates today's note through the Daily Notes integration used by Obsidian Daily Notes and Periodic Notes, and cannot resolve or create the note when that integration is unavailable. Integer and decimal input is accepted, skipping for the day stores a null value, and two settings control the frontmatter property name and whether the automatic prompt appears more than once per day.
