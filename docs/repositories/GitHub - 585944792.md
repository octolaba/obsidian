# juergenbr/obsidian-tolino-notes-import

This plugin imports the notes stored on a Tolino e-reader connected over USB, writing all notes for one book into a single Obsidian note. Bookmarks, notes and text markings are supported, imports land in a chosen folder, and a list of tags can be applied to every imported note. Settings record the mounted drive path of the reader and the vault location for the imports; the README states that the plugin was tested on macOS and Windows and that some users report the reader failing to mount automatically on macOS.
