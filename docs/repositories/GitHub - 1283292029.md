# kikocastro/markdown-mindmap

Markdown Mindmap renders configurable mind maps and leveled trees from the links a note already keeps in its frontmatter, with every map written as one fenced code block. A mindmap block gives a leveled left-to-right tree that can be switched between map, gantt and kanban views of the same notes, while a causalmap block draws a causal-loop diagram whose feedback loops are detected automatically. A block is pointed at folders and told which frontmatter field links a note to its parent, and the README states that every map is rebuilt from the notes each time it is opened rather than kept as a second copy of the data.
