# selectstarfromusers/obsidian-task-manager

Minimal Task Board collects checkboxes tagged `#task` from anywhere in the vault onto a board of user-defined buckets, offering a Board mode with buckets as side-by-side columns and a Focus mode showing one full-width bucket at a time. Tasks can be grouped inside a bucket by any frontmatter property, dragged between buckets or reordered, created from the board itself, and checking one on the board or in its source note keeps both in sync. The README records two syntax constraints: the tag must sit at the end of the line or the task is not detected, and where a line carries several links only the first is used for secondary grouping while the rest are stripped from the task text.
