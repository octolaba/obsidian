# OmegaCentauri68/Omega-Theme-for-Obsidian

Omega is a dark-mode-only Obsidian theme whose palette the README traces to nebulae and collapsing stars. It adds gradient accents, an underline form written with combined highlight and strikethrough markers, and highlighting inside a table cell that emphasises the whole cell. The README states that the theme is still in early development and not as feature-rich as older themes.
