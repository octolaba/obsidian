# sankalpsharmaa/obsidian-apple-reminders-sync

An Obsidian plugin for macOS that pulls today's incomplete Apple Reminders into the daily note. Reminders are read through reminders-cli, which uses EventKit rather than AppleScript, and appended as checklist items under the TODO heading, with reminder notes kept as indented text and priority shown as one, two or three exclamation marks. Syncing runs on vault open and on a configurable interval, deduplicates so repeated runs add nothing, and can skip named lists; settings cover the interval, the daily notes folder and the exclusions.
