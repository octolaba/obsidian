# shumadrid/obsidian-copy-path

Copy Path adds context-menu actions that copy the path of a file or folder, either the vault-relative path or the full path on disk. Each of the two actions can be shown or hidden in the plugin settings, and a further setting appends a trailing slash to folder paths so they are distinguishable from files, applying to both kinds of path.
