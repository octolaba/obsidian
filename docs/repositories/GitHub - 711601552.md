# danielegrazzini/adjacency-matrix-exporter

Adjacency Matrix Exporter builds a numerical adjacency matrix of an Obsidian vault and exports it as CSV for processing in other software. Rows and columns are both notes, and a cell carries the weight of the link from the row note to the column note. The plugin's window offers two exports — Absolute, where the weight is the number of links from one note to another, and Normalized, where that number is divided by the total words in the source note — plus a link for changing the CSV separator.
