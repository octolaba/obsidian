# Moonsand79/obsidian-decision-wheel

Adds a decision wheel panel to the Obsidian sidebar: choices are entered as slices and a spin lands on one of them. The wheel is drawn as vector graphics on an HTML5 canvas with friction and inertia physics, and a contrast algorithm keeps identically coloured slices off shared borders unless that is mathematically unavoidable. A theme browser filters style palettes by length, from two to seven colour slots, or by category and accepts custom hex packs, while saved wheel configurations are kept in categories that can be edited, duplicated, re-tagged or deleted. The README states the plugin is in an active build phase and not yet listed on the public marketplace, so it is installed by cloning the source into the vault and building it.
