# zigholding/obsidian-notesync-plugin

Obsidian plugin for copying material out of a vault, documented in Chinese and English. A file or folder can be mirrored to another vault from its context menu: notes, folders and embedded attachments are copied with the same file structure, and an existing file of the same name is overwritten only when the source is newer. A command exports a plugin, optionally including its data file, to a chosen directory, and a further command configures exporting a note as a readMe file, with settings for the export directory, the file name, where attachments are saved, whether metadata is removed, and whether attachment links use a Git-style form.
