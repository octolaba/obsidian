# lilian-pouliquen/obsidian-custom-list-character

Custom list character lets the character used for bullet lists in Obsidian be chosen between the default hyphen, an asterisk and a plus sign. The chosen character is picked in the plugin settings, and a command bound to a hotkey makes or reformats a bullet list with it. The README also describes adding that command to the mobile editing toolbar in place of the built-in toggle bullet list icon.
