# kawecz/folder-auto-properties

Folder Auto Properties applies a defined set of frontmatter properties to new notes according to the folder they are created in, so tags and metadata do not have to be typed each time. Rules are created from a folder's context menu in the file explorer or from the settings tab, and property values may use Obsidian's native types: text, number, checkbox, date, datetime, tags and list, with the settings UI adapting to the chosen type. Sub-folders can carry their own nested rules shown as a collapsible tree, rules follow a folder that is renamed or moved and are removed when it is deleted, and tags or list values are merged with those a note already has rather than overwriting them. The README states that Obsidian 1.1.1 or higher is required.
