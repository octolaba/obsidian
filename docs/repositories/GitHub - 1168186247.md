# p3nguln5/obsidian-claude-code-skills

Obsidian plugin that streams responses from the Claude Code command-line tool into a persistent side panel. The README describes selecting text in a note, right-clicking to pick a skill, following up in the same session with context preserved through the resume flag, freeform chat from the ribbon icon, and export of a whole transcript as a vault note. It states that the plugin is desktop-only because it uses Node child processes, that the CLI must be installed and authenticated, and that on Linux the subprocess is wrapped in systemd-run with network access denied where available.
