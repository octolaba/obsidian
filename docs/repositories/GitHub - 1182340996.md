# yama662607/obsidian-companion-mcp

Obsidian plugin providing a Model Context Protocol server for a vault, combining semantic search with editor context. The README states that multilingual embeddings are computed and indexed locally, and lists a tool surface organised by workflow: listing and searching notes, semantic search and index status, reading a note or the active editor context, one structured edit tool, and lifecycle tools for creating, moving and deleting notes and patching metadata. It states that the read tools return machine-readable edit handoff payloads so an agent can move from reading to editing without reconstructing anchors.
