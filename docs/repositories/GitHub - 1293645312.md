# VladB-evs/obsidian-explorer-sort

Obsidian plugin that lets files and folders be arranged by hand in the file explorer, giving each folder its own order instead of the built-in alphabetical or date sorting. Move up, move down, move to top and move to bottom are added to the explorer context menu, a reorder modal supports drag-and-drop, and the same actions are available as commands that can take hotkeys. Saved orders are updated when items are renamed, moved or deleted, items without a saved position are appended after the ordered ones, and custom sorting can be switched off without losing the stored orders.
