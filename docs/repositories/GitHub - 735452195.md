# pranavmangal/obsidian-single-file-daily-notes

Single File Daily Notes keeps every daily note in a single Markdown file, each day a heading followed by bullet entries. Opening it creates today's entry and selects a placeholder for immediate editing, or positions the cursor for appending when today's entry already exists. A calendar view in the sidebar, shown or hidden from the command palette, jumps to a chosen date and creates its entry when missing, and because days are ordinary headings Obsidian's built-in outline view browses them. The file name, its location, the heading level and the date format are configurable, and the README records that Obsidian's core daily notes plugin should be disabled, since this one does not yet interact with the notes that plugin creates.
