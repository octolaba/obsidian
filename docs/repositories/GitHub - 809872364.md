# pookhaosc1/obsidian-front-matter-timestamps

This repository holds Front Matter Timestamps, described upstream as tracking note created and modified times in front matter and keeping them up to date automatically. The README gives the reason for holding the values in the note rather than reading file attributes: file attributes are prone to accidental change, especially when syncing. It adds that the author built the plugin for personal use some years ago, cannot always attend to every issue, and welcomes pull requests for bug fixes and features alike.
