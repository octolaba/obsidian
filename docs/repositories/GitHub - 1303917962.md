# ygx2378/wetongbu-obsidian-plugin

WeTongbu saves user-selected WeChat articles, Feishu documents and article-style web pages into the current Obsidian vault as Markdown notes with local attachments, by polling WeTongbu tasks and writing the Markdown, images and attachments. Free users connect the Chrome extension with a six-digit binding code and no account login and supply their own Cloudflare R2, Amazon S3, Alibaba Cloud OSS or Tencent Cloud COS bucket, while Pro users authorize the plugin in a browser and can choose local image downloads or hosted image links. The README states that temporary task objects are deleted by the service after completion, failure or expiry while the Markdown and attachments stay in the vault, and that the plugin runs on Obsidian desktop, iOS and Android.
