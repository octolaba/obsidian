# lgreil/obsid-link

This plugin copies or opens a shareable redirect link for the current note. The service it targets wraps Obsidian's own deep-link scheme in a standard web address, which the README presents as keeping links clickable in chat applications, email and anywhere that strips custom URI schemes. Both actions are available from the command palette and from a ribbon icon whose behaviour is chosen in settings, and the README states that the conversion happens in the browser with no data sent to a server.
