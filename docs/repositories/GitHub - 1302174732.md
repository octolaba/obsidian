# Real-Fruit-Snacks/terminal-workbench-cursor

Terminal Workbench Cursor replaces Obsidian's editor caret with a small canvas engine offering box, line and underline carets with smooth gliding motion, a blink or a glow. The README records a torch spotlight carried around the workspace and layered effects including a fading pixel trail, motion smear, a CRT trail and an energy beam, each individually toggleable in settings. Its signature effect is the Ghost Trail, which peels a miniature ghost from the Terminal Workbench Pet plugin off the text as it is typed and, optionally, off the caret as it moves, taking its colours from the Terminal Workbench accent ramp.
