# Abdulkader-Safi/obsidian-safi-theme

Safi is a warm editorial Obsidian theme drawn from its author's brand, with a warm near-black or warm paper canvas, Space Grotesk headings, Inter body text and one clay accent across links, checkboxes, toggles and buttons. Depth comes from hairline borders rather than drop shadows, H2 headings render in clay, a single corner radius is used throughout, and body text is stated to pass WCAG AA contrast. The README records the hex values for both modes and notes that Space Grotesk, Inter and JetBrains Mono are loaded from Google Fonts, so first paint needs an internet connection unless the three fonts are installed on the system.
