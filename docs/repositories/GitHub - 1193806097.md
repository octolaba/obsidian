# xMisio72/obsidian-embed-editor

Embed Editor opens a floating editor panel when a transcluded embed is clicked, so the source content can be changed without leaving the current note; saving updates the source file and every embed of it. The README states that full-note, heading and block-reference transclusions are all supported, that the panel is a source view with line numbers and a monospace font, and that Ctrl/Cmd+Enter saves while Escape cancels, with a dot marking unsaved changes and the header linking to the source file. The repository also ships a CSS snippet that removes the default embed border, title bar and scroll container in Markdown views while leaving Canvas untouched.
