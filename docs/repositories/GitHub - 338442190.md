# jplattel/open-note-to-window-title

Obsidian plugin that adds the currently open note to the Obsidian window title. The README suggests it for application-usage tracking tools that read window titles, and for recognising context when switching between applications. The title is templated in the plugin settings from placeholders for the file name, file path, vault and workspace, and frontmatter keys are supported as well; a key the open file does not carry is dropped from the resulting title.
