# Kevin23-design/obsidian-transfer-latex-from-gpt-fix

This plugin converts LaTeX formulas found in ChatGPT answers into the Markdown math delimiters that Obsidian recognises and renders, and can be run from a command or a left ribbon button. Its author describes the project as a fix for an earlier unmaintained plugin of the same purpose, released while the original is not being maintained and to be retired if the original author resumes work. The README instructs users to turn off automatic HTML conversion in the Obsidian editor settings, or to paste ChatGPT answers as plain text, before using it. Its documentation is provided in English, both Chinese scripts, Japanese and Korean.
