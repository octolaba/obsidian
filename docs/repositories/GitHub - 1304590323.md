# toya-co/tasknotes-agenda-wrapper

TaskNotes Agenda Wrapper shows the tasks of the TaskNotes plugin in a today's agenda pane that can sit in the sidebar or be embedded in a note through a code block. The README records stat tiles counting todo, overdue and unplanned items that filter the list when clicked, a date-grouped collapsible list running from unplanned through overdue to each upcoming day, quick task entry that creates a formatted TaskNotes note, and clicking a task's status ring to change its status. It states that TaskNotes is required, that this plugin reads those tasks and does not manage tasks on its own, and that status and priority colours come from TaskNotes while the widget inherits the theme through Obsidian CSS variables.
