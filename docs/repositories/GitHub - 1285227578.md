# DavidTorro/Obsidian-Note-Nav-Cards-Plugin

This repository holds Note Nav Cards, an Obsidian plugin documented in Spanish that builds navigation cards between notes from a custom Markdown code block. A note-nav block declares the previous note, the next note or both, accepts its keys in Spanish or English, and is rendered as one card per direction using Obsidian's own API to resolve and open the internal links, with styles adapted to light and dark themes. The README records that a card's title must match the real note name in the vault, that the processor resolves navigation relative to the source path, and that an empty-state message is shown when no valid note is found.
