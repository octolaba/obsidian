# chhoumann/quickadd

QuickAdd combines four kinds of choices in Obsidian: templates, captures, macros and multis. The README describes a template as a definition of how to create a new note, with a location, a templatized title and templated content; a capture as a way to add content to predefined files, such as appending a link to a section of the daily note; macros as chains that compound the two behind a single hotkey; and multi choices as purely organisational folders of other choices. Choices use the QuickAdd format syntax, similar to Obsidian's own template syntax, so a date token can be inserted into a filename, and the README points to the project's documentation site for installation and details.
