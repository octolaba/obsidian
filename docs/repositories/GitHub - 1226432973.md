# Akudlay-ru/MailDump

MailDump is a desktop-only Obsidian plugin that exports email from IMAP folders into Markdown, organized into vault folders by ISO week, with presets, weekly digests and optional depersonalization according to its recorded description. The README, part of it in Russian, describes the output as a controlled source package — messages, metadata, threads, contacts, unanswered items and attachments — in a form readable by people, Obsidian, Dataview, scripts or a language model. Its release notes record per-preset schedules with daily, workday, selected-weekday and interval modes, a prompt after startup about missed scheduled exports, two to four independent IMAP accounts each stored in its own child folder under the output root, and a configurable path for the settings JSON.
