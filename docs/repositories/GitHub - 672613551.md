# lucasmelin/red-pen

Red Pen acts as a proofreader for writing in Obsidian, highlighting phrases that could be simplified and identifying weasel words, hedges, filler and further categories of the same kind. The README states that it is implemented as a retext-based plugin, and describes building it from source with either Node.js or Nix and installing the compiled files into the vault's plugin folder.
