# HomefulHobo/linear-calendar-plugin-obsidian

Obsidian plugin that displays a linear year calendar of all 365 days in a single view, with notes placed in their day cells and multi-day events drawn as horizontal bars. Dates are extracted from configurable frontmatter properties or from date patterns in the filename, with a configurable priority between the sources, and periodic notes for weekly through custom periods can be opened or created from the view alongside Periodic Notes plugin compatibility. Notes are clickable, show tooltips and previews on hover, and category visibility can be toggled. The README states that the plugin is in active development, is being developed with the help of AI, and may change significantly while note recognition and date extraction stay stable.
