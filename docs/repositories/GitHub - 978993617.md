# c-degni/text-autocomplete

Text Autocomplete offers a dropdown of suggested words for the word currently being typed in Obsidian. The README records selecting a suggestion with the cursor or with the Enter or Tab keys, moving through the list with the arrow keys, dismissing it with Escape after which every key behaves normally again, and holding Shift with Enter to get the default Enter behaviour. Suggestions come from the plugin's dictionary plus a custom dictionary curated from the settings or from the context menu of selected text, and from imported plain text dictionaries carrying one word per line, while the maximum number of suggestions is configurable.
