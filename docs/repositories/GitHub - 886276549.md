# carlrobert/double-switch

Repository for a plugin that switches Obsidian themes automatically when the dark and light mode setting changes, so a different theme can be used in each mode. The two themes are chosen in the plugin's settings. The README credits the Obsidian sample plugin and an existing theme picker plugin as the sources it is based on, and thanks a user for suggesting an improvement.
