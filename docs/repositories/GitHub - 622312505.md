# mikejongbloet/obsidian-get-stock-information

This repository holds Get Stock Information, whose README describes a single command that inserts information about a stock symbol into the current note using the Yahoo Finance API. The user is prompted for a symbol, and after a pause the plugin adds a callout block holding bid and ask prices, spread, name, currency, volume, market capitalisation, day range, 52-week range and the time of the information. The README credits a separate Yahoo stock API project as the source of the data access code. No upstream repository description is recorded, so this body rests on the README alone.
