# ozdemir08/youtube-video-summarizer

This plugin downloads a YouTube video's information and transcript, breaks the transcript into chunks and sends them to OpenAI's ChatGPT 3.5 to extract key points, writing the result into an Obsidian note as a summary. The README warns that summarizing a long video may take a considerable time. It credits a transcript package for downloading the transcript and another Obsidian plugin for fetching video metadata.
