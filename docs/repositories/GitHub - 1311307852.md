# jmj-eo/obsidian-warmrice

WarmRice is a warm, natural light theme for Obsidian whose palette the README traces to the Earth Online Survival Manual. It sets a soft warm background with sage green accents for interactive elements and terracotta highlights for emphasis, each given as a hex value, and claims full coverage of the Obsidian interface. Typography is described as tuned for both Chinese and English, and installation is documented through community themes or manually from a release.
