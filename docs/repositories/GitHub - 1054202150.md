# ameyxd/obsidian-tiktoker

TikToker saves TikTok videos into an Obsidian vault as Markdown notes, processing URLs from the clipboard and extracting title, author, description and hashtags into the note and its properties. Saved notes embed the video for playback, follow customizable file-naming patterns and templates, and are checked against existing notes for duplicates; batches of URLs can be handled at once. A sidebar review queue filters saved items by watched, starred or review-again state, sorts them by date, author or hashtag, tracks progress, saves filter sessions and can insert Dataview queries for the active filter. The README records local speech-to-text transcription as desktop-only, built on whisper.cpp and requiring Python, yt-dlp and ffmpeg.
