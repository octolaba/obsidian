# Abdulkader-Safi/obsidian-image-magick-plugins

Edits images inside the vault: resize with an aspect-ratio lock, crop by dragging on the preview or by typing coordinates, rotate and flip, compress by quality value, and convert between JPEG, PNG, WebP, GIF, TIFF and BMP. Processing runs offline through a TypeScript image library bundled into the plugin, with only WebP using an inlined WebAssembly codec. Presets and bulk edit apply one pipeline to a multi-selection from the file explorer context menu, and saving defaults to a new path rather than overwriting the source. The README states that EXIF orientation is applied on open, that metadata is never carried into output, and that AVIF, HEIC, progressive JPEG, animated GIF and multi-page TIFF are not decoded.
