# ibrh96-prog/obsidian-meeting-notes-synthesizer

Meeting Notes Synthesizer reads across a folder of meeting notes rather than summarising one, extracting decisions and action items with a single model call per note and caching the result so only changed notes are processed again. A note counts as a meeting when it sits in the configured folder or carries the configured tag, and a separate command builds the synthesis into a note at the vault root: a decision history with dates and links back to sources, open actions grouped by owner with due dates, a rollup of the current week, and the chain showing how a revisited decision evolved. The README records that the user brings their own key for Anthropic, OpenAI, OpenRouter or any OpenAI-compatible endpoint, stored locally, and that notes go only to the provider chosen.
