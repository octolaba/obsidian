# DrBanshan/banshan-skillhub

Desktop plugin for importing, organising and installing AI agent skills from a library kept inside the vault. Skills are imported from a GitHub URL pointing at a directory that contains a skills folder, from a local folder scanned for skills or .agents/skills, or from an npx command whose automatic execution is controlled by a setting. Imported skills are copied into a configurable vault folder, Skill by default, under a collision-safe name rather than overwriting, and the view lists them as blocks that can be renamed, given an emoji and tagged.
