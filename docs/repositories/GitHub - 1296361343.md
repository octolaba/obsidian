# whiletruegeek/status-date-tracker

Status Date Tracker watches a note's status property in frontmatter and, when its value changes, adds or updates a property named after the new status carrying the date of that transition. Dates are the device's local calendar date in a fixed year-month-day form rather than the format configured for Daily Notes or templates, which the README justifies as keeping values unambiguous, sortable and compatible with Obsidian date properties, and earlier status properties stay in the note as a compact transition history. The tracked property name is configurable, and statuses listed as final keep the date of their first transition instead of being overwritten when the note re-enters that status.
