# Marlon154/boardgame-search

This plugin creates Obsidian notes for board games from the BoardGameGeek API. Games are searched and imported with their metadata, categories and mechanics, and cover images are downloaded and stored in thumbnail, medium and full resolutions. The README opens with a notice that BoardGameGeek now requires an API key for all requests, so the plugin will not work until an application is registered, approved and its token entered in the plugin settings. Session tracking is marked as work in progress.
