# tardigrde/obsidian-agentic-chat

Obsidian plugin that puts an agent-led chat in the right sidebar, where the agent acts on the vault through typed tools - reading, searching, writing, editing, renaming, traversing links and reading or writing frontmatter - with every tool call rendered inline in the conversation. It runs inside Obsidian on desktop and mobile, built on the pi agent packages, using hosted models through OpenRouter or a local Ollama server where nothing leaves the machine. OpenRouter requests are restricted by default to endpoints that retain no data and neither log nor train on prompts, and a provider fallback must satisfy the same constraints. The README states the plugin is experimental and under heavy development, ships no analytics endpoint, and sends traces only where observability is explicitly enabled.
