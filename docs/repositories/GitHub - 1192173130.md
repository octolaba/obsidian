# kpulik/VaultChat

The repository carries no description; its README presents VaultChat as a local-first AI chat for Obsidian that can edit the vault. A fresh install points at a local endpoint on 127.0.0.1 and asks for no key, working with Ollama, LM Studio, llama.cpp, vLLM, LocalAI, Jan or any OpenAI-compatible server, while Anthropic, OpenAI, Google Gemini and OpenRouter remain optional. Edits are proposed as reviewable diffs with no accept-everything switch, an edit whose target text appears more than once is refused instead of guessed, and edit or delete blocks pointing outside the vault are rejected, with deletions gated behind a double confirmation. The README adds that code fences claimed by known executor plugins are rewritten before rendering so model output cannot run, and that API keys are held in Obsidian's secret storage.
