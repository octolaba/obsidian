# viggomeesters/obsidian-eml-email-viewer

EML Email Viewer registers .eml files with a dedicated read-only Obsidian view opened from the file explorer. The README states that it parses From, To, Cc, Bcc, Subject, Date, Message-ID, In-Reply-To and References, shows body tabs for plain text, sanitized HTML and raw MIME, lists attachments as metadata only, searches across headers, body and attachment names, and applies render caps to large bodies while surfacing parse warnings. Its stated security model blocks remote images, scripts, external styles, forms and active URL attributes, and excludes mailbox sync, IMAP or SMTP, sending, attachment opening, clipboard access and any write back to the file. The README also positions it against the Email Reader plugin, which renders embedded .eml files in preview mode instead.
