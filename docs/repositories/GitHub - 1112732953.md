# takeshy/obsidian-wysimark

A WYSIWYG editor for Obsidian that presents Markdown files in a rich-text interface and converts between the two representations as the file is edited. The README lists shortcuts for bold, italic, strikethrough, inline code and underline, headings, bullet, numbered and task lists with indentation, block quotes, tables with cell navigation, and links and images inserted from a URL, a local file or a vault picker. Code blocks are syntax-highlighted, callouts render with their icon and colour, Mermaid blocks show as live diagram previews, and HTML blocks are kept as read-only raw HTML. YAML frontmatter is preserved but hidden from the editor, and changes are saved automatically after a one-second debounce.
