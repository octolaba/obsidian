# Vinzent03/find-unlinked-files

Scans the vault for orphaned files that have no backlinks, for links pointing at files that do not exist, for empty files, and for empty folders, writing each result as a note listing them. Files holding only frontmatter count as empty, hidden dot files and folders are ignored, so a folder containing only hidden files counts as empty too. Further commands create the missing files behind broken links, archive orphaned files, or move listed files and empty folders to the system trash after confirmation.
