# haivri/obsidian-fullscreen-image

This repository holds Fullscreen Image, whose README describes clicking an image in a note to open it in a lightbox, with zoom by on-screen buttons, mouse wheel, pinch or double-click and dragging to pan. The README says the viewer can cover the whole window or stay inside the active workspace pane, fits images to the viewport without stretching them, keeps panning inside the image bounds, and restores keyboard focus when it closes. It states that the plugin does not modify notes, collect telemetry or make network requests, and that it works on desktop and mobile. No upstream repository description is recorded, so this body rests on the README alone.
