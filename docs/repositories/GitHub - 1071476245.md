# vinitkumar/monokai-ristretto-obsidian

vinitkumar/monokai-ristretto-obsidian is a warm dark Obsidian theme ported from the Monokai Pro Ristretto vim colorscheme. The README lists the palette it uses, from a #2c2525 background and #e6d9db foreground to separate colours for comments, keywords, functions, strings, numbers, links and tags, and covers installation from the theme browser or by copying theme.css into the vault.
