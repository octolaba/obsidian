# Koishiiko/obsidian-webdav-image-uploader

WebDAV Image Uploader keeps the images used by Obsidian notes on a WebDAV server and references them from the note by link. Pasting or dragging an image is intercepted and the file is uploaded under a configured path format before the link is inserted, and this interception can be turned off in the settings or toggled by command; a local image link can also be uploaded from its context menu, with the local copy optionally kept. The context menu of an uploaded link offers download, delete and rename, the last of which moves the file on the server, and settings buttons batch-upload or batch-download every image across the vault. The file explorer's context menu applies the same batch operations to a single file or a folder.
