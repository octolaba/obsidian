# qqyzk/feishu-obsidian-inbox

Feishu Inbox pulls messages from a Feishu or Lark group chat into an Obsidian inbox note, so the chat can be used from a phone as a capture inbox and emptied into a vault-relative Markdown file on demand. Syncing is manual, from a ribbon button or the Sync Feishu Inbox command, and the plugin keeps bounded local sync state to avoid importing a message twice and filters system messages such as group creation and bot invitation events. Each user supplies their own Feishu custom app: the README walks through creating it, copying the App ID and App Secret into the plugin settings, adding the three message scopes it needs, enabling the bot feature, publishing a new app version and adding the bot to the inbox group. It notes that the App Secret is stored in the vault's plugin data, which should therefore not be published.
