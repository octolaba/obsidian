# BagOfTips/rpg-levelling

Adds an RPG-style levelling display to the focused editor pane, awarding one experience point per character typed and showing a compact level label, a progress bar and the current point count. Levels have no maximum and each one costs more than the last, with a short animation when a new level is reached. Progress is also backed up in Obsidian's app storage so a plugin update can restore it, the widget corner is chosen in settings, and a command toggles the display; the author describes the project as vibe-coded.
