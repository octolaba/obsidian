# Mappedinfo/MarkTex

The recorded description says this project turns Markdown into LaTeX. Its README is written in Chinese and documents a browser-based converter built with React, TypeScript, Vite and CodeMirror, with particular attention to tables: it chooses between the tabular, tabularx and longtable environments by row count and text length, computes column widths from content, wraps long cells and can apply booktabs styling. It also records front-end PDF compilation through a SwiftLaTeX WebAssembly XeTeX engine with Chinese and Unicode support, export of the .tex source or a copy to the clipboard, and settings for document class, font size, page size and the wrapping threshold. The README describes a web application and its own build commands, not an Obsidian plugin interface.
