# fangface-hub/obsidian_table_formatter

This plugin reformats Markdown tables when a file is saved, and while editing in Live Preview or Source mode after a configurable pause in typing, three seconds by default; it never runs in Reading view. Edits are applied through the open editor so the cursor stays in place and Obsidian does not report the file as externally modified, and the table holding the cursor is left alone until the cursor moves out of it, while the manual command always formats everything. A ribbon button, a command and a status-bar switch drive formatting and its auto mode, one command formats every Markdown file in the vault after a confirmation and reports how many changed, and settings choose the cell padding, the number of dashes in the delimiter row and the delay, with the alignment colons preserved.
