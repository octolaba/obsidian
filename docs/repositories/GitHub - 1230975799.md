# danybeam/map-of-content-generator

A utility that generates pre-filtered Obsidian bases over a chosen folder so they can be used as maps of content, automating what the author says they had been doing by hand. Settings cover the map-of-content directory, a ribbon button for manual generation, excluding other bases from the view, deleting empty subfolders after generation, generating on startup, and updating the base queries on generation. The README warns that the empty-folder cleanup can delete the map-of-content folder itself, that startup generation grows slower as folders accumulate, and that updating templates discards customization; the two template text settings are marked temporarily disabled.
