# xiaotianhu/obsidian-messager

Obsidian Messager receives messages sent through a companion service and saves them into the vault. The README states that the author runs that service, which accepts messages by WeChat, an HTTP API or email, and that this plugin is the receiving end inside Obsidian. Using it requires registering an account with the service, with basic use free and advanced functions paid, and the README links the service's privacy policy. The text is given in English and Chinese.
