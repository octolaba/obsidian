# MMoMM-org/obsidian-newtab

This repository holds New Tab, an Obsidian plugin that replaces the empty new-tab view with a customizable dashboard. The README lists a background drawn from seasonal Unsplash themes, local images, a custom URL or transparent modes, a 12- or 24-hour clock, a time-of-day greeting with markdown support in ten languages, a quote from an online source or a custom set, a search button and inline search box wired to a chosen provider, bookmarks from all or one group, and the most recently edited files. It records that this is a personal version derived from the obsidian-beautitab plugin by Andrew McGivery under the MIT licence.
