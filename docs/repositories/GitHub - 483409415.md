# YukiGasai/obsidian-google-calendar

This repository holds Google Calendar, described upstream as adding Google Calendar inside Obsidian. The README lists listing, creating, editing and deleting events, automatically creating notes from events, and inserting links to events into notes, and points to a separate documentation site for getting started. It carries an explicit warning that the plugin is in stale mode, is not being maintained, and could stop working at any time.
