# nhrrs/heboric-obsidian

Heboric is described as a clean theme for Obsidian, built with a pleasant reading experience in mind. Its recorded features are comfortable reading, dark and light themes, and mathematics that is easier to read. The README documents installation from the appearance settings, or manually by downloading or cloning the repository into the vault's themes folder, and asks that missing plugin support be reported through the repository's issues.
