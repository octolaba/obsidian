# cferrugem/obsidian-cfr-find

This repository holds CFR Find, a full-text search plugin for Obsidian that runs indexing and queries in a Web Worker so the interface does not block. The README credits Omnisearch as the direct inspiration, keeps the same core of BM25-ranked search over MiniSearch, and states that CFR Find trades away Omnisearch's HTTP API, public plugin API, embedded results and Chinese word segmentation in exchange for speed. The differences it claims are a single deduplicated tokenisation pass instead of three or four, diacritics normalised once per distinct token, note content not retained in memory, and cache serialisation moved off the main thread. Both plugins are licensed under GPL-3.
