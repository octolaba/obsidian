# code-alchemist-dev/obsidian-crestfall

This repository holds Crestfall, a dark Obsidian theme inspired by the JetBrains Islands aesthetic by way of the Dark Islands theme for VS Code. It sets a near-black canvas with a warm syntax palette of orange keywords, blue functions, green strings, mauve types and cyan numbers, and rounded sidebar leaves and modals carrying directional light borders. It also styles seven task checkbox states, fifteen callout variants, tables and Dataview inline fields, Kanban lanes with per-column accent borders, graph view nodes, and a properties panel colour-coded by type, and loads IBM Plex Mono for all code blocks.
