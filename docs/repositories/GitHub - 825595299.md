# muaz742/obsidian-accointing-viewer

Account Viewer generates accounting tables from Markdown code blocks in Obsidian tagged with the accounting alias. The README's example block records one entry with a debit and a credit line — cash against common stock — which the plugin renders as a table in preview. Installation is documented three ways: following an Obsidian plugin URL, browsing community plugins inside the app, or browsing the plugin directory in a web browser.
