# kouge0510/obsidian-dagens-ord

The repository holds Dagens Ord, an Obsidian plugin that presents a daily Danish word as a card, built on an Anki Danish frequency deck of 4442 words with English and Chinese glosses and example sentences translated into both. The word is chosen deterministically by date, with navigation through the deck, starred and mastered markers, a button back to today's word, Danish audio from the deck and locally generated example audio. The README states that the audio is no longer bundled and is downloaded on first use, that CEFR levels can be filtered individually, that the card sits in the right sidebar or floats over the editor, and that progress is saved locally.
