# yanqingwang/obsidian-joplin-server-sync

The README describes an Obsidian plugin that syncs a vault with a Joplin Server instance, staged as uploading all notes first, then bidirectional sync through the delta API, then attachments as Joplin resources together with tag handling and link conversion between the Obsidian and Joplin formats. Conflicts are resolved as duplicate, local-wins or remote-wins. Setup asks for the server URL, an email and a password and offers a connection test, after which the vault upload is run from the command palette.
