# dylanarmstrong/obsidian-prettier-plugin

This plugin formats Obsidian notes with Prettier using Obsidian's own editor settings, so that it needs no configuration. The README states that only two options are passed to Prettier, tabWidth and useTabs, both taken from the Editor settings, and that nothing beyond them is customizable, which it names as the difference from another Prettier plugin for Obsidian. Format on save is enabled by default and can be changed in the plugin settings, and a Format current file command is also available.
