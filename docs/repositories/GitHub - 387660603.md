# kbravh/obsidian-tweet-to-markdown

Obsidian plugin that saves tweets as Markdown files, built on the second version of the Twitter API. Authentication is a bearer token obtained through the Twitter developer dashboard and entered on the plugin's settings page, or kept in an environment variable instead. The README opens with a notice that the free API key the project used to issue stopped working after the Twitter API changes of April 2023, so a token of one's own is now required.
