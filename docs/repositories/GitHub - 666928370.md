# conorzhong/obsidian-auto-front-matter

Obsidian plugin that automates frontmatter for Markdown notes, documented in both Chinese and English. The README describes version 2 as having removed the modify-while-saving behaviour and the sorting feature and having added custom frontmatter content in their place. The stated reason for dropping modify-while-saving is that editing frontmatter is itself a modification and makes the change listener trigger endlessly, while sorting was dropped in favour of the Linter plugin; the suggested replacement is a Commander macro that saves and runs the plugin under one shortcut. When the action type is Append the new key defaults to an array type, because otherwise Obsidian reports a type mismatch.
