# DiscourseGraphs/discourse-graph-obsidian

Repository for the Discourse Graphs plugin, which adds semantic structure to Obsidian notes by typing pages as nodes and connecting them through typed relations that model scientific discourse. It ships Question, Claim, Evidence and Source node types with complementary relation types, and further node and relation types are defined in its settings menu. The README frames the aim as breaking the research process into atomic units that can be related, resurfaced and reused while building arguments, and states that the Datacore plugin is required and must be installed and enabled first.
