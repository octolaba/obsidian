# dotWee/obsidian-raindropio-plugin

This plugin browses Raindrop.io bookmarks from inside Obsidian through the official Raindrop REST API, using an access token that its README says is stored in plugin data and sent only to that API, with OAuth planned later. A side pane explorer lists the configured collection, runs manual searches with keywords, tag filters, exact phrases and operators such as type, notag and created, and pages through further results. A note-aware filter rebuilds the search term from the active note's tags and external links so the explorer follows what is being read, and fenced raindrop blocks render saved links inline. What a click on a tag does — search the vault, filter the explorer, or nothing — is configurable, and the README states that there is no hidden telemetry.
