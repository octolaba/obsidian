# iiz00/obsidian-daily-note-outline

Obsidian plugin that adds a custom view showing the outlines of several daily notes at once, addressing the difficulty of finding which daily note a thought was written into. The outline displays not only headings but also links, tags and list items. Version 1.5.0 added creation of daily notes for unresolved links, so that where a note links to a date whose daily note does not exist, that file can be created, which the README explains as a way of making backlinks to daily notes appear in the outline. Its documentation is given in English and Japanese on the same page.
