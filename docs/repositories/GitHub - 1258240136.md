# Maicon-Lara/od2-toolkit

Obsidian plugin that brings interactive character sheets and dice rolls for the Old Dragon 2 tabletop system into the vault. A character-sheet code block written in YAML renders a sheet computing attribute modifiers, ascending armour class, melee and ranged attack bonuses and final saving throws, with buttons for roll-under attribute tests and saves, attacks, composite damage, initiative, and a hit-point counter that writes back into the file. Forms add attacks and equipment to the block without hand-editing the YAML, with autocomplete for weapons, armour and general items, and prepared spell slots autocomplete by class. The README states that this is a free, unofficial fan project implementing only the mechanics and numbers adapted from the system's free reference document, not the text of the books.
