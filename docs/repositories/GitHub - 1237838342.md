# hasanyilmaz/hide-sidebars

Hide Sidebars is an Obsidian plugin that adds auto-hide behaviour to the left and right sidebars, controlled separately or together. The README records revealing a hidden sidebar by moving the pointer to the matching screen edge and letting it collapse again when the pointer leaves, plus an overlay mode in which the sidebar floats over the editor instead of resizing the workspace. Three ribbon icons and four commands toggle the left, right and both sidebars and the overlay mode, and settings record sidebar width, trigger zone width, vertical trigger padding, collapse delay and notification behaviour. The README states the plugin is desktop-only, requires Obsidian 1.0.0 or newer, and removes the classes it applies when disabled.
