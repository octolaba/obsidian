# junhewk/simple-graph-builder

Repository for Simple Graph Builder, a plugin that builds a knowledge graph from vault notes using entity extraction by a language model. The README describes a deliberately small ontology of ten fixed entity types, relationships expressed as free-form verbs with a detail field for nuance, and multi-stage entity resolution, and frames the design as a way to avoid schemas with dozens of types. The recorded description adds knowledge extraction, exploration and retrieval-augmented search as the intended uses.
