# Bluemoondragon07/Obsidian-Serenity

Serenity is a theme for Obsidian designed to be simple, minimalistic and focus-promoting. It provides custom checklists using the Minimal theme's syntax plus additional markers such as person, save, link, event and navigation, and speech bubbles in the AnuPpuccin theme's syntax where the first bold text in a bubble becomes its title. The README notes that, since themes are no longer allowed to use assets over the network, the Style Settings entries for additional fonts no longer work out of the box and a supplied snippet is needed to restore them.
