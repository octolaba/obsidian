# Dyse-Sofqi/MDRazor

MDRazor, whose README is written in Chinese, groups five editing modules that are each switched on separately in its settings panel. A hiding module conceals Markdown markers — bold, italic, highlight, strikethrough, inline code, escape characters, heading hashes, internal-link brackets and several HTML tag pairs — showing them again when the cursor moves in, and adds a translucent marker for spaces and a tooltip reporting where the cursor sits relative to a hidden marker. A list module treats a list marker as one atomic unit for cursor movement and deletion, makes Enter insert a soft line break inside an item, and collapses everything outside the focused branch of a list or of the file tree. A further module scans the vault for images that no note references, across three embed syntaxes, and moves them to the system trash with a notice for each file.
