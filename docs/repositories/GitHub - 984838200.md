# masoniis/obsidian-syncable-dictionary

This plugin makes Obsidian's native spellcheck dictionary syncable on desktop by keeping the list of custom words in the plugin's configuration inside the vault's Obsidian folder and applying it to the native spellcheck list. The README is explicit that it does not sync anything itself: it only moves the word list to a syncable location, and a syncing system such as Obsidian Sync still has to be set up. It warns that the plugin calls the internal Electron session dictionary API that Obsidian's own dictionary relies on, so a change in how Obsidian handles this, or a withdrawal of that access from plugins, would break it, and it recommends backing up a large dictionary first.
