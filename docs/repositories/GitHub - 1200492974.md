# czxtm/apathy-obsidian

Apathy is a dark Obsidian theme with deep purple-black backgrounds recorded as #0C0C13 and a soft cyan-mint accent of #D1F1EC used for interactive elements. Its README gives a palette table covering background, editor background, text, accent, muted, error, warning and success colours, and states that every callout type has a distinct colour and that code blocks use syntax-aware colours from the same palette. Tabs, navigation, titlebar and inputs are themed consistently, and the theme is presented as part of an Apathy family that also has VS Code and Zed ports.
