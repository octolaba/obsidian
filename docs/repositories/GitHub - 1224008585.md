# Mukhil-G/obsidian-vision

Vision is an editorial Obsidian theme built around cream paper with a subtle 32px grid, serif headings and crisp ink accents, with a companion dark mode described as ink-on-paper inverted. Typography pairs Cormorant Garamond for the first three heading levels with Inter for body text and JetBrains Mono for code, while the lower heading levels render as uppercase tracked small caps. The README also documents pull-quote blockquotes, structured tables with hairline row borders, horizontal rules carrying a centered section glyph and outlined monospace tag chips.
