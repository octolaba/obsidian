# Brightwav3/Star-Pins

Star Pins pins files as tiles above the file tree in the file explorer. A star button added to every file view's header pins or unpins the current file, tiles are reordered by dragging with a drop into the empty gap sending one to the end, a click opens the file and a modifier click opens it in a new tab, and a right-click offers unpin or open in a new tab. The README states that pins follow files through renames and are cleaned up when a file is deleted, that any file view supporting header actions can be pinned rather than Markdown alone, that a command allows keyboard-only pinning, and that each tile shows the icon assigned by the Iconize plugin, falling back to a monogram.
