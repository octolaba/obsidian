# futureCreator/obsidian-dolch-theme

Obsidian Dolch Theme is a dark theme whose palette is taken from the classic Dolch colour scheme, with blue, red, green, yellow, cyan and purple accents. Its README maps each accent to a role: red for H1 and errors, yellow for H2 and warnings, green for H3, cyan for H4 and code, blue for H5 and links, and purple for H6 and external links. Alongside those heading colours it lists code block styling, a visible split between internal and external links, table styling and custom checkboxes, and it documents installation either through the community themes browser or by copying manifest.json and theme.css into the vault.
