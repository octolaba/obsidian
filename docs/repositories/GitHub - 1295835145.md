# DyllonWright/Eleven-Days

Obsidian plugin that shows a given date in eleven calendar systems at once, adding Hebrew, Islamic, Chinese, Mayan, Discordian, Thelemic and others alongside the Gregorian date. A code fence in a note renders the set of cards, each card opening onto that calendar's background, and the featured card carries a moon-phase glyph that unfolds into illumination and upcoming lunar events plus a zodiac chip covering planetary positions and rare events. The README ties the name to a chapter of Robert Anton Wilson's Cosmic Trigger and adds a Wheel of the Year grid for browsing and adding annual holidays.
