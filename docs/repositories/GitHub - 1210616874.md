# Ashpega/emacs-lite

Emacs Keybindings Lite adds a subset of Emacs editing and navigation keys to Obsidian through a CodeMirror keymap, described by its README as a practical subset rather than full Emacs emulation and as deliberately preserving common Windows shortcuts. Implemented bindings cover cursor and word movement, forward and backward deletion, line kill and yank without a kill-ring, a mark system, region cut and copy, and recentering the view. The README also documents a switch between visual and logical line modes, optional press-and-hold key repeat, and hotkey groups that can be toggled individually, all without reloading.
