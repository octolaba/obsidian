# 3-Elements-Design/hangarx-obsidian

HangarX for Obsidian is a plugin that turns the vault into a queryable knowledge graph of entities, relationships and citations, exposed to agents through the Model Context Protocol. The README records a sidebar chat panel that answers with citations to the source notes, two-way sync that pushes notes to the graph, pulls entities back as Markdown or diffs the two sides, highlighting of cited entities on Obsidian's native graph view, ghost-text wikilink suggestions driven by entity matches, and one-click MCP setup for Claude Desktop, Claude Code, Cursor, Cline and Windsurf. It records two deployment modes: a hosted mode signed into with a HangarX account, and a fully local mode running in Docker with the user's own key for OpenAI, Anthropic, Google, Mistral, Cohere, Groq, Together AI or Ollama.
