# jsmorabito/Obsidian-Command-Shortcuts

Shortcuts lets any Obsidian command, custom action or interface element be triggered by chained keys — a single key, a modifier combination, or a sequence of key presses. The README describes a shortcut mode entered from a status bar icon or a trigger key, which can also be enabled automatically when focus leaves an editor or an input, context-aware shortcuts surfaced for the current place in the app, and helpers, notifications and hints showing what a keystroke will fire. It states that while the mode is active the plugin listens to every key and stops listening as soon as an editor or a standard input takes focus, so ordinary typing is unaffected.
