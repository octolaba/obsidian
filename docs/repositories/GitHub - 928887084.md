# fgubler/obsidian-cursor-position-history

Cursor Position History records where the cursor was, both inside a file and across files. When a file is left and later reopened, the plugin scrolls back to the position where editing stopped, and a separate history of cursor positions across files is walked with two commands that return to the previous position or forward again to the next. The commands carry no fixed bindings, and the README credits two earlier plugins, Navigate Cursor History and Remember Cursor Position, as its inspiration.
