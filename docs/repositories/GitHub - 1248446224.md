# WiseGuru/ReWrite-Voice-Notes

Captures speech, either recorded in Obsidian or pasted as an existing transcript, sends it to a transcription provider, then cleans and structures the text with a language model before inserting it into the vault. Provider keys are supplied by the user across eight transcription and five language-model providers, and the README states that nothing is sent to a server run by the plugin and that pairing its managed whisper.cpp transcription with a local OpenAI-compatible model keeps audio and text on the machine. Ten editable Markdown templates cover cases such as general cleanup, todo, daily note, meeting, lecture and podcast, sharing a baseline edited once. Further features are speaker diarization, embedding the saved audio, spoken ad-hoc instructions, preserved known nouns, per-run destination overrides, real-time dictation at the cursor, and folders that batch-process dropped audio.
