# privet-kitty/obsidian-blogger

This repository holds obsidian-blogger, described upstream as a plugin for publishing Obsidian documents to Blogger. The README marks the plugin as being in a beta stage, notes that it is already released to the community plugins list, and gives instructions for building a development copy from source. It states that the user must create their own OAuth2 client identifier and secret in the Google Cloud Console with the Blogger API enabled, by a procedure that differs between desktop and mobile.
