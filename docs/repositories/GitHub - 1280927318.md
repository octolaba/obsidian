# Blackfish1067750468/Obsidian-DotPass

Repository for Dotpass, a desktop Obsidian plugin that controls which files and folders the file explorer shows, including dot-prefixed items such as `.git` and `.env` that Obsidian hides by default. The README documents a switch for revealing those default-hidden items plus ordered custom rules for folders and files, written either as guided options or as expressions covering path, depth, glob and regular-expression matching. Rules can be duplicated, sorted and reordered with higher rules winning, and the recorded description carries the same summary in Chinese and English.
