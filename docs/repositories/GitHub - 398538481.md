# c4ctus5/editor-commands-remap

Obsidian plugin that exposes the editor commands of the Obsidian API as commands hotkeys can be bound to. The set covers cursor movement by character, line, note start and end, indenting and unindenting lines, inserting a newline with indentation, swapping the current line up or down, deleting a line, and folding or unfolding at the cursor or across the whole note. The README notes that these commands are only available while an editor is open, that some duplicate built-in Obsidian commands, and that the plugin grew from an attempt to approximate the Tabout extension for VSCode, which is not directly possible because Tab cannot be bound as a hotkey in Obsidian.
