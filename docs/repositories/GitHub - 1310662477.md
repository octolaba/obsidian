# decai335335-debug/handwriting-markdown-view

This plugin adds a vector handwriting annotation view layered over rendered Markdown, usable alongside Obsidian's edit and reading views on the same note. The toolkit covers pen, highlighter, stroke eraser, move and undo/redo, collects pressure, tilt and twist, and separates stylus drawing from single-finger scrolling and two-finger pinch zoom, with configurable pen side-button codes. Each note gets a stable handwriting-id in its frontmatter, strokes are stored as a JSON document with a generated SVG preview and metadata, and they are re-anchored to Markdown blocks by exact text match, with unmatched strokes tracked as orphaned IDs. The README marks the current version as a beta and states that reads and writes go only through Obsidian's Vault and FileManager API, so it runs on desktop and mobile.
