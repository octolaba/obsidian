# hungsu/typomagical-obsidian

Typomagical is an Obsidian theme aimed at typographic appreciators, with support for the Style Settings plugin. The README records magazine-style quote callouts, emphasis carried by bold, italic and small caps instead of underlines, text sizing that responds to the settings slider, pinch-to-zoom and the keyboard shortcut, and heading scaling for small and large screens. Style Settings unlocks a high-contrast accessibility mode, additional color schemes and a ligature toggle, and the README states that the CSS avoids important declarations and heavy class use so snippets can override it.
