# notlibrary/obsidian-adamantine-pick

Adamantine Pick renders Pikchr diagrams inside Obsidian notes: a fenced code block marked pikchr is turned into an SVG in the note. The README states that pikchr.c is precompiled with emcc, so diagrams render client-side and offline without installing or compiling Pikchr, and that an adamantine class attribute selector lets the output be manipulated from code. It is installed from the community plugins browser or through the plugin's install URL, and the repository carries sample diagrams, including a recursive one.
