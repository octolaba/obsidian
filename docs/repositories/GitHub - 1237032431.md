# jldiaz/copy-protocol-plugin

The repository holds Copy Text Protocol, an Obsidian plugin that registers a custom copy scheme under the obsidian protocol so that clicking a link copies the text carried in its URL to the clipboard, with a small confirmation notice and no popup or external application. Links are written as ordinary Markdown links whose target uses that scheme and a text parameter, wrapped in angle brackets when the text contains spaces and otherwise percent-encoded. The README names cheat sheets of commands or templates, collections of snippets, boilerplate such as signatures and addresses, and query strings pasted into other applications as its use cases.
