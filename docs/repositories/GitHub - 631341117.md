# screendotgarden/screengarden-obsidian

This repository holds the Obsidian plugin for screen.garden, a service the README describes as offering realtime note collaboration with live cursors, presence showing where others are editing, folder- or vault-level sharing, permissions with private and public collections, file sync for images, videos and other files alongside notes, and read and write access to notes on the web. After installing, the user logs in from the plugin settings, opens the home screen from the status or ribbon icon, and right-clicks a folder to start syncing it. The README's disclosures state that an account is required, that membership on a subscribed team is required after a trial period, that connections are made to screen.garden servers to exchange note and file edits and metadata, and that the code is closed source under a closed license the authors intend to revisit.
