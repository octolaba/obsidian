# banisterious/obsidian-charted-roots

This repository holds Charted Roots, a genealogy plugin for Obsidian that keeps family histories and fictional worlds as linked Markdown notes. The recorded description names interactive family charts, geographic maps, PDF reports, GEDCOM and Gramps import and export, evidence tracking and fictional calendar support. The README adds an interactive family chart with pan and zoom, direct relationship editing, bidirectional sync and export to PNG, SVG, PDF or ODT, plus canvas trees with four layout algorithms. It is addressed to genealogists, historians, writers and worldbuilders.
