# muckmuck96/obsidian-md-to-jira

The repository holds Markdown to Jira, an Obsidian plugin that converts a note or a selection into Jira markup and back again. Its README records that the note has to be in editor view for either direction, and documents a command that converts the whole note and places the result on the clipboard. Installation from the community directory is documented alongside a manual route that copies a release's script and manifest into a plugin folder.
