# calvinwyoung/obsidian-backlink-settings

Obsidian plugin that saves preferred settings for the backlinks or linked mentions pane at the bottom of a note, which Obsidian otherwise does not retain when a new file is opened. Default values can be stored for the sort order, for whether results are collapsed, and for whether more context is shown, and they are applied to the pane every time a file is opened. The values are configured in the plugin's own tab in the Obsidian settings.
