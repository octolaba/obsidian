# BjarneRentz/obsidian-gemini-generator

This repository holds Gemini-Generator, described upstream as a small Obsidian plugin that uses Google Gemini to generate notes. The README says the current release offers a single Generate Note command producing a note from its title, with custom prompt templates and automatic formatting of the response listed as planned rather than present. It states that the user must supply a Gemini API key created in Google AI Studio, possibly with a payment method attached, and warns under a privacy heading that the note title is sent to the API on every generation.
