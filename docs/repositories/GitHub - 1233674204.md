# liominsb/image_zoom

Image Zoom is a lightweight image viewer for Obsidian that the README presents as a drop-in replacement for the unmaintained Image Toolkit. Clicking an image in Reading or Live Preview mode opens it full-screen, the mouse wheel zooms steplessly around the pointer, dragging with the left button pans while zoomed, and Escape or a click on the dark backdrop closes the view. The README describes the implementation as a few hundred lines of vanilla TypeScript with no dependencies, throttled through `requestAnimationFrame`, with all CSS classes carrying a unique prefix so they do not collide with Obsidian's own styles.
