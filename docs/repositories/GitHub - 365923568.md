# ryanpcmcquen/obsidian-org-mode

The repository holds Obsidian Org Mode, a plugin that adds support for the Org Mode format to Obsidian. Its README points at the Org Mode project site for what the format is, and documents manual installation by copying the built script, stylesheet and manifest into a plugin folder inside the vault. It is written in JavaScript under the Mozilla Public License 2.0.
