# ismailivanov/task-deck

Task Deck is a kanban and table view for Obsidian in which every card stays a real Markdown note, so cards remain searchable, linkable and editable outside the board. The README records drag-and-drop ordering of cards and lists, inline card creation, renaming, quick status changes and undo while the view is active, cards carrying coloured labels, start and due dates, Markdown descriptions, images and checklists, and multiple boards with independent folders and lists. It also records automatic discovery of compatible Markdown cards created outside the plugin, and optional cross-device sync, shared boards, member assignment and live presence through the separate Sync Deck project.
