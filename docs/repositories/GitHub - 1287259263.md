# doritosuai/darkrune

Darkrune is a dark neon Obsidian theme built on purple, magenta and violet with lime green on details and pink and cyan on smaller writing details, over a near-black base. Its README lists display headings with a subtle neon glow, syntax highlighting in both reading and editing modes, callouts drawn as frosted cards, an animated graph with drifting particles, and an optional dimmable nebula backdrop behind note text. Customisation is done by editing a control panel of CSS variables at the top of theme.css, which sets the primary and detail colours, the glow strength, CRT scanlines, the nebula strength and its darkening overlay, and prompt prefixes. Both the README and the repository description are written in Portuguese as well as English.
