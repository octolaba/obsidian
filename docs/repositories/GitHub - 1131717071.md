# shichishima/obsidian-universal-cursor-hotkeys

Universal Cursor Hotkeys restores Emacs-style cursor movement, kill and yank editing, and Obsidian's built-in Vim motions inside Markdown tables, which the README says Live Preview otherwise breaks. On macOS it makes the control-key cursor shortcuts and their shift-extended selection variants work inside table cells as they already do elsewhere, and on Windows the same set can be enabled throughout Obsidian. Kill, yank and kill-region are handled inside table cells with newlines and pipe characters taken into account, alongside a recenter command. For Vim mode the README lists the character, word, line and document motions it corrects inside cells, and it states that no hotkeys are assigned by default, with a setup assistant that applies the recommended bindings per command group.
