# lossless-group/image-gin

Image Gin is an Obsidian plugin that generates AI images, searches stock photography and uploads to a CDN from inside a Markdown note. Generation runs through two providers — Recraft with server-side style ids for custom-trained brand styles, and Ideogram v3 with per-call style, rendering-speed and prompt-handling controls plus optional post-processing that strips incidental text — and settings can wrap every per-file prompt in a brand-wide prefix, suffix and negative prompt. Stock search goes through Magnific's API, and local image references in one note or a whole folder can be rewritten to ImageKit URLs with optional WebP conversion. Prompts and generated paths are read from and written back to each note's frontmatter, starting with an `image_prompt` key.
