# towishy/owen-editor

Owen Editor gathers Markdown editing helpers into a single Obsidian toolbar, covering writing, research, report drafting, table conversion and snippets belonging to the author's Owen Graphite theme. Its README states that the interface follows Obsidian's locale, using Korean for Korean and English for every other locale, with an explicit language override in the plugin settings. Most of the README is a long release log recording work on the editor palette, code-block controls and editable titles in Live Preview, a custom scroll area, and icon and tooltip changes.
