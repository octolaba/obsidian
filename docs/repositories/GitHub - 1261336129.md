# kkbin505/tomato-clock-plugin

Tomato Clock is a Pomodoro timer for Obsidian with a sidebar panel showing a countdown, phase indicator dots and start, pause, skip and reset controls, plus a status bar item that shows the remaining minutes and opens the panel when clicked. When a phase ends the plugin raises a system notification and a beep synthesized in the browser, so no audio files are bundled. Completed work sessions are appended to a Markdown log file, which opens automatically after each session so notes and wikilinks can be written on the same line, and the sidebar shows today's sessions with their notes, a weekly bar chart and an all-time total. Work, short break and long break durations, the cycle length, automatic phase start, sound, notification and log path are settings, and the README states that all data stays local with no telemetry.
