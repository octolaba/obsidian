# tmfelwu/obsidian-inbox

This plugin captures a note into an Obsidian vault through a modal opened by a shortcut key. The README describes the modal as holding a note title field, a note body field and a submit button, with a datalist of matching note paths shown as the title is typed: Enter navigates to the first entry, or the arrow keys select another one first, and a new note is created from the submit button or with Ctrl+Enter. The README's checklist marks part of this behaviour as not yet done, including the datalist itself and the handling of a name collision when content is present, and it explains how to bind a global hotkey to the plugin's URI using AutoHotkey on Windows or BetterTouchTool on macOS.
