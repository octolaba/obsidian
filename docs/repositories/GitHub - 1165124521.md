# sec-ml/obsidian-anything-as-md

Obsidian plugin that takes a user-supplied list of file extensions and has Obsidian recognise them as Markdown, covering names such as `.mdx`, `.rmd`, `.qmd`, `.mdown` or `.myst`. An experimental setting goes further and lets Obsidian index those files as though they were `.md`, overriding built-in logic; the README marks that path as still under test with no support offered. It also notes that only Markdown syntax is guaranteed to render, and that the behaviour of other elements such as JSX or R code blocks is unknown.
