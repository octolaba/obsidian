# cpbotha/obsidian-ai-chat-as-md

AI Chat as Markdown carries on a conversation with a model directly inside an Obsidian Markdown note, relying on nested headings so that several conversations, including branching ones, can live in the same note. Images embedded in the note can be discussed with models that accept them. Any OpenAI-compatible API server can be configured in the plugin settings, and a frontmatter key in a file overrides the configured model for that file.
