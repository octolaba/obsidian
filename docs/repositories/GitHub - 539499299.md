# otaviocc/obsidian-microblog

Micro.publish publishes Obsidian notes to a Micro.blog blog as posts with title, tags, visibility and an optional scheduled date, as pages that can be added to the blog's navigation, or, on desktop, as microposts of up to 300 characters of plain text. It finds local images in a note, in both standard Markdown and wiki-style embeds, uploads them and replaces the references with hosted URLs, caching the mapping in note properties for re-publishing. Categories can be synchronized from Micro.blog for tag suggestions, several blogs are supported with a default and a per-publish choice, and frontmatter title and tags are used when present with the URL written back after a successful publish. The README states that the plugin is community-maintained and not affiliated with Micro.blog or Obsidian, and that logging in uses an app token from the Micro.blog account page.
