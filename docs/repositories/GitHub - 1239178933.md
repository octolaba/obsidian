# ShawnSomething/obsidian-gcal

An interactive Google Calendar sidebar covering several accounts in one view, with day, three-day and week layouts and a density toggle. Events are created by clicking or dragging an empty slot, moved by dragging, and edited for title, time, recurrence, guests, location and description; invites can be accepted, declined or marked tentative, and a change to a recurring event applies to one event, this and following, or all. Calendars can be shown or hidden per account, a mini month view navigates, and keyboard shortcuts cover common actions. The README records the plugin as desktop only and requires the user's own Google Cloud project with OAuth credentials, which it says keeps tokens on the local machine and off any third-party server.
