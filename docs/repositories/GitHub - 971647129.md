# eatcodeplay/obsidian-simple-table-math

Simple Table Math performs sums, averages, minima, maxima, subtractions and multiplications over rows or columns of numbers in Markdown tables, calculating and displaying the results as the table is edited. A calculation is triggered by a tag placed in a cell that names the operation as a three-letter code, the direction to read values from, the start and end of the range, and an optional currency. Results can also be copied to the clipboard, either from a keyboard shortcut or from the context menu.
