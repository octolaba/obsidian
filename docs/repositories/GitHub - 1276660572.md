# RanceLee233/Mini-Calendar

Mini Calendar embeds a compact one-week calendar directly below Obsidian's built-in file explorer, so the folder tree and the calendar stay in the same sidebar tab. Clicking a date opens its daily note or creates it, using the folder, filename format and template configured in the core Daily Notes plugin and asking for confirmation before a past or future note is created; a solid dot marks a day that has a note and an outlined dot one whose note still holds unfinished tasks. The README records navigation to the previous or next week and back to today, a choice of locale default, Monday or Sunday as the first day, optional ISO week numbers, rainbow date cards and a red weekday label for today, and states that the plugin needs Obsidian 1.8.7 or later and works on desktop and mobile without network access.
