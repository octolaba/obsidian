# dartungar/obsidian-emotion-picker

The repository holds Obsidian Emotion Picker, a plugin that inserts a feeling from a customizable list at the cursor, with a sensible default list supplied. Its README records four options set in the settings tab: adding a comma after the word for entering several in a row, inserting it as a link, inserting it as a tag, and capitalizing it first. The stated purpose is making entries in a daily journal or a mood tracker quicker to write.
