# blueheron786/obsidian-efficient-word-count

Efficient Word Count calculates and caches word counts for every Markdown file in an Obsidian vault, excluding folders the user configures (Templates and .trash by default). The README states that the cache is updated incrementally from file create, modify, delete and rename events and persisted to disk so startup and vault-wide statistics are faster. Counts are exposed to scripts through a global window.wordCountCache object with get(path) and total() methods.
