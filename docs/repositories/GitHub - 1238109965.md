# joeraad/obsidian-snipdock

Repository for SnipDock, a plugin that manages CSS snippets from a status-bar menu, where they can be toggled, renamed, opened in an editor or created without leaving the current note. Its README presents it as a rewrite of an unmaintained snippet-menu plugin against the current Obsidian API, and records that version 1.1.0 added anchoring the menu above the status-bar icon, a search box that filters the snippet list as it is typed, and a multi-column layout of two to six columns with optional column-first ordering.
