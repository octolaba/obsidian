# tcyeee/obsidian-minimalism-ui

Minimalism UI reworks the Obsidian interface into a Typora-like writing environment: the left sidebar gets a frosted-glass look and merges the Outline panel with the Properties metadata into one view, panel action buttons and search bars are hidden, and the editor and reading view get custom typography, blockquote, table and code-block styling. A home note can open on startup and whenever all tabs are closed, and a single-page mode hides the tab bar, keeps one note visible, caches the ten most recently visited notes in the background and makes back and forward navigate across tabs. The README warns before installation that the plugin is about subtraction and strips away core features including folders, so almost every note lives in the vault root and timestamp-prefixed filenames are advised to keep names unique.
