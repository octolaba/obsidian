# kemayo/obsidian-smart-links

Smart Links turns strings matching user-defined patterns into links while a document is read. Each rule pairs a regular expression with a replacement string, so an identifier such as a ticket number can be rendered as a link to the tracker that issued it. The rules are added and removed in a Smart Links section of Obsidian's settings, and the README frames the plugin as a way to keep habits formed in other writing environments.
