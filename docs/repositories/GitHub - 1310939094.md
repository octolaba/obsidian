# lucytheboss/extended-base

Adds three views to the core Bases plugin: a table, a list and a board, sharing value pills, inline cell editing, a select editor and a page panel for editing a note without leaving the view. The table supports resizable columns whose widths are stored per view, renaming a column's display name without touching the underlying property, a per-column menu for text wrapping and pill colours, property-type icons and nested collapsible groups. The README states that it requires Obsidian 1.10.2 or newer with Bases enabled, and that it is a fork of GoodBases adding the list and board views, nested groups, column resizing and per-column options. No repository description is recorded, so this note is grounded in the README alone.
