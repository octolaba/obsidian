# daledesilva/obsidian_project-browser

Project Browser presents an Obsidian vault as a card interface rather than the hierarchy of the files pane, and lets multiple pages be added to any note, base or canvas. The README's list of implemented features covers folder navigation with back and forward memory, hiding individual folders, a customisable launch folder, folders treated as projects, note states with a state menu and customisable states, prioritisation of notes, right-click actions, file browser integration, and adaptation to light and dark modes. Project excerpts, page versions and drafts, and reordering pages within a project are listed as the current development focus rather than as finished work, and the README asks readers to back up their files because the plugin is provided as is.
