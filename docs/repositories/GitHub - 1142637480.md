# Jareika/TTRPG-Tools-Publish

TTRPG Tools - Publish prepares content from the separate TTRPG Tools maps and timeline plugins so it can be displayed on a site published with Obsidian Publish. Running one of its Prepare commands writes or updates a generated runtime block between named markers inside publish.js and publish.css, leaving the rest of those files untouched, and converts internal data into publishable Markdown notes for the map library, per-file marker sets and timelines, plus asset manifest notes linking every referenced map, image and note. The README states that it is kept separate from the maps and timeline plugins so users who do not publish carry no extra runtime. Requirements it records are Obsidian Publish with a custom domain, and JSON marker storage, since maps using inline note storage cannot be exported yet.
