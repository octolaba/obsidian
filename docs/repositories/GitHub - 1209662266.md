# xeome/obsidian-vesper-sandstorm

Vesper-Sandstorm is a minimal Obsidian theme that combines the structure of the Vesper theme with the warm brown palette of Sandstorm. The README lists dark and light modes, a warm brown accent palette, a monospace-focused design and a clean, minimal aesthetic, and credits both upstream themes by author. It records manual installation by cloning into the vault's themes folder, with the community listing pending approval at the time the text was written.
