# soheidon/Plain-Links-Tools

Plain Links Tools converts Markdown and wiki links in the current note to either their display text or their URLs, so a link becomes plain text or a bare address. It also offers a toggle that renders bare email addresses as plain text instead of clickable mailto links in both Reading View and Live Preview, suppressing the normal click while leaving Ctrl or Cmd click working and preserving explicit mailto links. All commands are reachable from the command palette and the ribbon icon menu.
