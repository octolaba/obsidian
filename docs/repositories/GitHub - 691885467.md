# sunxvming/obsidian-vscode-editor

Obsidian VSCode Editor adds viewing and editing of code files to Obsidian, which does not support them by default. It is built on the Monaco Editor, the editor kernel of VSCode, and handles formats including C, C++, C#, CSS, Go, HTML, Java, JavaScript, JSON, Python, Ruby, Rust, Shell, XML, YAML and ini, so that a code file does not have to be opened in a separate editor. The README states that the plugin depends on no third-party network service and works without an internet connection, and that the editor's light and dark theme colours, font family, ligature support and font size are customizable, with a shortcut for adjusting the size.
