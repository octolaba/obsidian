# TeoEchavarria/karma-notes

Karma Notes adds a Reddit-style voting system to the notes in an Obsidian vault. A new note starts at two karma points and can move at most one point up or down from its daily base score, so repeated clicks on the up or down arrow stay inside that day's range until the base resets tomorrow. Notes that have not been opened for two weeks lose one point automatically. A sidebar view opened from a trophy icon lists all notes with sorting and filters by karma range, tags and other frontmatter properties, and the status bar shows the active note's karma with an emoji.
