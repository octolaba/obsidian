# golddream-y/obsidian-ratel

An AI agent over the vault that chats about and acts on linked notes, answering with numbered citations that open the cited note in one click. Retrieval fuses semantic and keyword recall and pulls in linked related notes, and the agent is extended through built-in skills and subagents plus MCP servers over HTTP or stdio for web search and other external tools. Chat, embedding and rerank models can be swapped and any prompt section overridden; embeddings run locally, network traffic goes only to the configured model API and the added MCP servers, and every vault edit asks for approval first. The README states Obsidian 1.13.0 or later, desktop only, and is also published in Simplified Chinese.
