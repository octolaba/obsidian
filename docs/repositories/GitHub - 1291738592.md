# noriyuki-lim/obsidian-mermaid-gui

Mermaid GUI Editor adds an Edit button to every mermaid code block in Reading view, Live Preview and Source mode, opening a modal with a diagram-specific visual editor so no Mermaid syntax has to be written by hand. Flowchart, Gantt, kanban, quadrant and XY chart types get an interactive canvas that is dragged directly, while sequence, class, pie and the remaining types get a structured form editor beside a live preview. The plugin parses the Mermaid source into an in-memory intermediate representation while editing and writes back only standard Mermaid text on save, so editor-only state such as node positions never reaches the file and the note stays readable by other Mermaid tools.
