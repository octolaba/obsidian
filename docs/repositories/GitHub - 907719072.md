# liqms/obsidian-content-cards

Content Cards renders a set of card layouts from code blocks in a note: timelines in vertical and horizontal form, highlight blocks, target cards, book, music and movie information cards, photo albums, business cards, content subfields, countdowns, and SWOT and BCG matrices. Each entry inside a block starts with a card marker followed by the parameters that card type requires, such as time, title and content for a timeline, and a colour tag after the marker tints the card from a fixed palette of eight colours. The README states support for Obsidian mobile, English and Chinese interfaces, local images and custom code-block languages.
