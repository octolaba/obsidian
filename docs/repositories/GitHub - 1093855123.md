# xiwcx/obsidian-bases-kanban

Kanban Bases View adds a drag-and-drop kanban view to Obsidian Bases, generating columns from any property of the base. Cards move between columns, columns can be reordered by a handle and given colour themes, and column order is saved per property across sessions, while notes with no value for the chosen property collect in an Uncategorized column. A second property can optionally group the board into horizontal swimlanes, and a column's add button creates a card with the column and swimlane values already filled in. Cards can show selected properties, use a frontmatter property as their title instead of the file name, and carry a cover image whose fit and aspect ratio mirror Obsidian's native Cards view.
