# paddan/code-block-plugin

This plugin converts selected or pasted text into a code block with automatic programming language detection. The set of languages that can be detected is chosen in the plugin settings. The README states that detection is provided by highlight.js, is not perfect but works most of the time, and that a wrong guess can be corrected by removing that language from the list and trying again.
