# raito1chi/canvas-task-cards

This repository holds Canvas Task Cards, an Obsidian plugin that turns Canvas cards into task cards. A converted card carries a completion indicator on its left border, one of five types covering task, question, important, idea and info with distinct colours, and a priority shown as a coloured dot; clicking the indicator toggles completion and the state persists across restarts. Type and priority are set from a floating toolbar that appears beside Obsidian's colour picker when a card is clicked, and context menus cover marking a card done, converting it back to a normal card, and adding a task card on empty canvas space. Cards can be filtered by type or priority from the command palette, and a card may show a progress bar over subtasks that auto-completes when every subtask is checked.
