# kevinmcaleer/obsidian-dashboards

Dashboards composes content from across a vault into a layout inside a note, written as YAML in a dashboard code block. The layout is a twelve-column grid of rows and columns that auto-stacks on mobile and holds six widget types: markdown, chart, embed, stat, link and heading, with chart widgets using inline or linked Bases Chart blocks. A reading view renders the dashboard while a pencil icon switches to inline editing, where rows and columns are added, the divider between columns is dragged to resize on the grid, and widgets are configured in a modal instead of by hand.
