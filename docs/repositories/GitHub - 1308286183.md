# AshenAshes/word-count-heatmap

Word Count Heatmap visualizes daily writing in a GitHub-style heatmap of word or character counts over a custom date range, such as the last 30 days, 365 days or a fixed year. Clicking a day opens a details panel breaking the total down by file and by words added to each, and colour shading intervals, tracked metric and excluded folders are set in the plugin settings. The heatmap is rendered from a word-heatmap code block, inserted through a command or written by hand and then configured from the block's own settings button or inline. The README records English and Chinese interfaces following the Obsidian locale, and recommends character counting for Chinese.
