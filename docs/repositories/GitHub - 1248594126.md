# NeuroCloud-Activate/semantic-todoist-sync

Semantic Todoist Sync connects notes written in Obsidian to tasks managed in Todoist, turning a note or a selection into tasks and subtasks, keeping a traceable copy in the vault, flagging duplicates and previewing the day's plan before anything changes in Todoist. The README describes it as local-first in the sense that the AI provider, models and external services are chosen by the user, and lists OpenAI, Gemini, OpenRouter and local Open WebUI or Ollama endpoints with per-workflow selection and optional fallbacks. Its notes on the current 0.8 series record a grounded-search step that filters action-only false matches before model choice, per-model profiles that remember carrier and concurrency behaviour and can be deleted individually, a searchable settings surface, and revised mobile controls with embeddings settings gathered in one place.
