# SyntaxAsSpiral/Semantic-JSON

Semantic JSON recompiles Obsidian Canvas files into deterministic JSON, so meaning that a canvas encodes visually is preserved rather than discarded. The README maps four dimensions onto structure: position becomes a linear reading order, bounding boxes become hierarchy of groups and children, node and edge colours become a taxonomy over the Canvas colour indices, and arrow endpoints become information flow from source to sink. It lists auto-compile on save, import and export with auto-detection, optional LLM-assisted semantic identifier assignment through local or cloud providers, handling of canvas, JSON and JSONL files, and a command-line tool for batch processing or CI, and states the output is a spec-compliant JSON Canvas extension with no custom properties.
