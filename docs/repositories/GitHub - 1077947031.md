# kraasch/true-black

True Black is an Obsidian theme with a pitch-black background and a color scheme based on Atom's dark theme. The README states that it includes no light theme version at all, and records that it was originally borrowed from the obsidian-atom theme. Installation is described through Obsidian's appearance settings by searching for True Black.
