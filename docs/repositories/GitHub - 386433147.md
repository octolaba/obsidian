# NomarCub/obsidian-open-vscode

Obsidian plugin that opens the vault as a Visual Studio Code workspace from a ribbon button, a file explorer context menu entry or either of two commands. One command spawns a child process running the editor's command-line launcher, which can be templated in settings; the other opens the editor through its URL scheme. The README records the prerequisites — the launcher on PATH or its full path configured, and a package manager that still lets Obsidian spawn a child process, or else a system that has registered that URL scheme — and notes that the ribbon button can be disabled and hotkeys assigned instead. It also says the functionality is largely covered by other plugins now, but will go on being maintained.
