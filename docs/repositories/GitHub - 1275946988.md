# Scottnine/obsidian-filamental

3D Filamental Graph renders an Obsidian vault as a three-dimensional force-directed graph in a tab, where each note is a node, each wikilink a connection, and a physics simulation pulls linked notes together and pushes unrelated ones apart. Node size scales with connection count, Filamental entity types colour the nodes, dragged positions are saved to a positions file inside the vault, and a sidebar panel shows the active note's entity type, colour and link count. Navigation uses arrow keys to pan, Ctrl with scroll or a pinch to zoom, and a click to open a note. The same positions file is shared with the separate Filamental desktop application, which the README presents as a paid product with a 30-day trial; the plugin requires Obsidian 1.7.2 or later, is desktop-only and, at the time of writing, supported Windows with macOS announced as coming.
