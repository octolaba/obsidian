# alt-forge/Habit-Heatmap-Calendar

Habit Heatmap Calendar is an Obsidian plugin that tracks daily habits on a heatmap-style year calendar without creating any notes. The README records adding any number of habits and switching between them from a dropdown, and clicking a day to cycle its state through done, missed and not tracked. A statistics bar reports the current streak, the totals done and missed and a success rate, and the view supports browsing past years and returning to today. All habit data is recorded as living in a single JSON file inside the plugin's folder.
