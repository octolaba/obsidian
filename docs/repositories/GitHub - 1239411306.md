# hanzhichao/obdrawio

ObDrawIO opens draw.io diagram files stored in the vault in an embedded editor, so flowcharts, UML, wireframes and entity-relationship diagrams are edited without leaving Obsidian. Diagrams are created from a ribbon icon, the command palette or a folder's context menu, changes are saved to the vault automatically by default, and a searchable picker inserts a diagram link into a note. The editor follows Obsidian's light or dark theme, and the draw.io server address, theme and language are configurable.
