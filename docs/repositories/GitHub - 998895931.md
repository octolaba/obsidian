# digvijay-s-todiwal/phrasesync

PhraseSync suggests internal links as a note is typed, matching note titles, headings and block references without any prefix or special syntax. Matching works mid-sentence, recognizes multi-word phrases, ignores case, and indexes live as the vault evolves, so no manual refresh is required.
