# stracker-phil/obsidian-mention-things

Mention Things lets other notes be mentioned through customizable trigger characters, most commonly an at sign for people; accepting a suggestion inserts a link to the note and leaves the cursor after it. Each mention type pairs a trigger character with a descriptive label shown when creating new entries and a choice between inserting a real link or completing the file name as plain text, the latter intended for use with plugins such as Virtual Linker. General settings control whether matching is anchored to the start of the term, the maximum length typed before suggestions stop, and the characters that immediately close the suggestion box. The README records the plugin as based on saibotsivad's obsidian-at-people.
