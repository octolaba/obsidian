# tiezjin/illuminator

Illuminator removes white backgrounds from images in an Obsidian vault, converts them to WebP, and updates the links to the rewritten files. It runs either automatically on paste or manually through an "illuminate" entry in the file panel's right-click menu, and both paths expose an adjustable white-removal threshold, a choice of PNG or WebP output, and a configurable naming pattern. Removal works by RGB thresholding — pixels brighter than the chosen setting become fully transparent — and the README states that all processing happens locally in a Web Worker. It also warns that the image data is modified permanently, so backups are advised, and that black text may be hard to read against Obsidian's Dark Mode after the background is removed.
