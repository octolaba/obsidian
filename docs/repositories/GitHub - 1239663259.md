# ItsVeyra/glitter-idea-repo

Captures short ideas as lightweight cards — text, links, images and videos — from a global quick-capture entry, so a thought can be kept before deciding whether it stays a card, becomes a Markdown file, or is reused inside a note as a snippet. Saved ideas enter pools and are organized by theme, project, stage or any custom structure, with two home-page views that change only how the pools are presented. A roam board brings saved cards back onto a canvas where they can be dragged, connected, compared and grouped; source blocks show the real content rather than a text description, multi-image ideas stay grouped, board history is kept, and a source block follows edits or deletion of the original idea.
