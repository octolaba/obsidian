# s1m4ne/obsidian-workspace-plus

Saves, switches and organises Obsidian workspace layouts as named sessions. Sessions are switched from the status bar, the quick switcher, the command palette, hotkeys or a session manager, either with save-on-switch or in a manual workflow whose unsaved layout changes raise a status-bar warning. The manager creates, reloads, duplicates, renames, deletes, reorders, bulk-deletes and groups sessions, keeps per-session version history for restoring earlier layouts, and exports, imports and restores backups. A session can also be loaded from a note's `workspace-session` frontmatter, and the README states the interface ships in 21 locales.
