# oscarhenrycollins/obsidianclaw

Obsidian plugin that puts a chat sidebar in the vault for talking to an OpenClaw agent, with streaming replies, natively rendered Markdown and visibility into the files read or written and the commands the agent runs. Chat history and tool calls persist through Obsidian Sync, a command sends the current note as context, and the panel follows the active Obsidian theme. The README records the prerequisites: an OpenClaw gateway reachable over Tailscale, and a one-line patch to the gateway's origin check, because Obsidian's renderer loads from a custom scheme whose origin is null and the handshake is otherwise rejected. That patch has to be reapplied after every gateway update.
