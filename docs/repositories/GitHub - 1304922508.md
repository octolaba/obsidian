# Amato21/Lightweight-Mentions

Lightweight Mentions is described as a plugin for people who mention far more things than they want to turn into full notes. Typing a trigger character, by default an at sign, and a name links to a matching note or alias if one exists; when nothing matches, the plugin appends a heading to a single shared stub file and links to that heading instead of creating a new note. A promote command later extracts a stub heading into its own file, optionally applying a template chosen from a configured folder, and rewrites every existing link across the vault to point at the new note. The README states that the plugin is not yet in the community plugins list and can be installed manually or through BRAT.
