# buwon/naver-sync-plugin

This repository holds NAVER Sync, an Obsidian plugin that synchronizes documents and files by using Naver's memo service as backup storage for cross-device sync. The README records mobile support, periodic syncing and syncing after a period of inactivity following the last edit, with setup through a folder created on the memo service and a login in the plugin settings. It states as the project's own claims that no personal information is collected and the password is not stored, and warns to back up first, that synchronization may fail because of unclear storage policies, that conflicts resolve as last write wins, and that external deletions are synchronized too.
