# artursbridaks/easy-push

Easy Push reviews changed files in a vault that is a Git repository and pushes a selection of them without a terminal: the current file, selected files or all changes, with an editable commit message, a target branch and a command for pushing pending local commits. The README states that the plugin only runs local git commands, uses no account, sync service, telemetry, backend or GitHub-specific API, and initializes a repository if the vault is not one already. File explorer markers colour pushed files green and locally changed or unpushed ones red, while common local files and ignored files are hidden. It is desktop-only, warns before pushing to an existing non-default branch, and does not fetch, merge, delete branches or resolve conflicts.
