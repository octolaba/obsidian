# Ali-Nourix/Agenter

Agenter puts a tool-using AI assistant into Obsidian, reachable from a docked sidebar, a movable floating panel, or a contextual panel beside selected text that shares one conversation history. Its tools read and search notes, inspect links and metadata, list folders, summarize content, search the web, fetch URLs and handle note images when the selected model supports vision, while creating, editing, appending, moving and trashing notes happens only after a configured approval step. Mutations write backups into a plugin folder and deletion uses Obsidian's recoverable trash. The README describes the plugin as desktop-only and requiring the user's own key for OpenAI, Anthropic, Gemini or another compatible endpoint.
