# Flyingmiata-droid/cite-engine

Obsidian plugin that flags quotes which no longer match the source note they were taken from. The README describes three commands: stamping a source note with a citekey derived from author, year and title plus a block id on every passage; citing a passage through a fuzzy picker that inserts a block-reference citation and offers no free-text path, so a non-existent passage cannot be cited; and an integrity check that scans the active note for citations that no longer resolve or whose quoted text has drifted from its source block. It states that no AI touches the citations and that the plugin never rewrites the user's prose.
