# aadityaincode/Deep-Notes

Deep Notes generates study questions from the note open in Obsidian and evaluates the answers in a panel without leaving the app. Four study modes are described: Socratic open-ended questions with detailed feedback, multiple choice questions with a score, Feynman explanations judged on depth and clarity, and flashcards that flip and can be exported to Markdown. The README states one AI provider is required, either Gemini through an API key or Ollama installed locally with a pulled model, and that a session is evaluated, saved and given a scheduled review.
