# szynszyl320/spell-picker-obsidian

SpellPicker lists the spells available to D&D characters in one place so they do not have to be looked up across wiki tabs or book pages. Spells can be filtered by name, by level and by the classes that can pick them, either through a tag system in a single search bar or through three standalone input fields that avoid misspellings. The view opens from a ribbon icon or a command, and the README records the D&D 5e SRD API as the source of all spell data and points to a separate web-based version of the same tool.
