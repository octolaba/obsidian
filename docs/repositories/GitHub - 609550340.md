# bramses/chatgpt-md

Runs a chat with a language model inside an Obsidian note, so the conversation and any notes it references stay in the vault. The README states that an API key for OpenAI, Anthropic or OpenRouter is entered in the plugin settings, and that Ollama and LM Studio can be used instead to run a model locally, selected per note through a model value in the note's properties. It lists tool calling that lets the model search the vault, read notes and browse the web with the user approving each action, agents that apply a named persona to a note, and updated provider integrations covering model selection and streaming.
