# rbrauner/obsidian-header-filename

This plugin renames a note automatically to match the first level-one heading in the document, re-checking on every edit. No repository description is recorded, so this body rests on the README alone. The derived name is converted to kebab-case, diacritics are translated to their ASCII equivalents and duplicate separators are collapsed, while a configurable debounce delay keeps renames from firing too often. A new empty note is given a default untitled heading, and a command palette entry renames all files in one batch.
