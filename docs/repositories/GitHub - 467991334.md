# isaaclyman/novel-word-count-obsidian

Obsidian plugin that displays a word count or another statistic beside every file, folder and vault in the File Explorer pane, updating in real time as text is written. Up to three data types can be shown side by side, chosen from word count, page count and a decimal page count, an estimated reading time, percentage of a word goal, character count and note count. The README documents the defaults behind those figures, among them a word as any sequence of non-whitespace characters, a page as 300 words, and reading speeds of 265 words or 500 characters per minute, each changeable in the advanced settings.
