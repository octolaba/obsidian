# ibatura/obsidian-ask-any-ai

An Obsidian plugin that sends the current selection, or the current line, to a configured LLM and inserts the answer back into the note under an AI Result heading. Wikilinks in the input — to a note, a heading or a block — are expanded to their content before the request is sent, and the list of vault note names can be appended to the system prompt so the model can write resolvable links back. Two commands share that pipeline: one uses an inline system prompt, the other picks a Markdown file from a prompts folder whose body becomes the system prompt and whose frontmatter can override model, provider and insertion position per run. Several named connections across five provider types are supported, and the README records the plugin as desktop-only, requiring Obsidian 1.5.0 or newer.
