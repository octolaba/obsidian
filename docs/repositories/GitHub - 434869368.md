# joethei/obsidian-link-favicon

Link Favicons is described as showing the favicon of a linked website. The README says this happens without custom CSS and works alongside other plugins that render links, and that the icon provider is chosen in the settings from Google, DuckDuckGo, Favicon Grabber, a self-hosted Favicon Finder, Icon Horse and Splitbee. Its table records how the providers differ in maximum icon size, whether a fallback icon is generated, and what request limits they impose, and notes that icons may look different depending on the choice. The README also points to a companion extension for Firefox and Chromium browsers.
