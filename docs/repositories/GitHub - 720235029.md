# gvvim/obsidian-pomodoro-widget

This plugin adds a pomodoro timer widget to Obsidian, modelled in the README on a kitchen timer that is wound to set the time and ticks while it runs; unlike that timer, the widget can be set with a button and resets automatically, and a stopwatch is also provided. Settings choose whether the widget's toggle appears in the ribbon, in the status bar or only as a command, and dragging the widget to a corner anchors it there so the window can be resized. The README states that the widget uses the official style names so it adapts to any theme, that its own class names are prefixed with pomo-, and that the widget functionality is separated from the clock so other plugin developers can reuse the widget class.
