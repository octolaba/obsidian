# ebullient/obsidian-theme-ebullientworks

This repository holds the Ebullientworks theme, described in its README as a dark and light theme for Obsidian and for Obsidian Publish. The README records headers that are styled, sized and responsive with and without stacked tabs, along with styled modals, tables and other panels, and light styling for the Admonition and Calendar community plugins. It states compatibility with custom task snippets from Snippetor, and documents Style Settings options that suppress the theme's own checkbox and tag styles or move view header actions to the left.
