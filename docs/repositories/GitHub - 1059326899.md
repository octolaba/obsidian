# RAIT-09/obsidian-agent-client

Obsidian plugin that connects AI agents to the vault over the Agent Client Protocol (ACP), including Claude Code, Codex and Gemini CLI. Notes are mentioned with `@` so the agent reads and edits them in place, and MCP servers, agent skills, slash commands and permission prompts work as they do outside Obsidian. Several agents can run at once in sidebar tabs, editor tabs or floating windows, each with its own session and model, and a chat can be pointed at any directory rather than the vault.
