# peter-yanase/jadou-obsidian

JADOU is an in-context Japanese language toolbox for Obsidian that looks up readings and meanings, inserts furigana, builds glossaries and selects sentences. A lookup runs on a selected Japanese expression containing kanji from the ribbon icon, the command panel, a keyboard shortcut or the editor context menu, inflected forms are supported, and entries are tagged common, rare, irregular or outdated according to kana usage. Glossary entries are reordered by dragging or sorted into Japanese alphabetical order and removed by right-click, while space or right-click in the dictionary panel inserts furigana instead of adding an entry. The README states that the plugin has zero dependencies, supports mobile and PDFs, and needs a network connection only to download or update its dictionary data, which derives from JMdict and SudachiDict.
