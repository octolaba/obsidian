# katananananna/obsidian-mathify-notes

No repository description is recorded, so this body is grounded in the README alone. Mathify Notes converts raw text into mathematical and chemical notation as it is typed, so LaTeX syntax does not have to be written by hand. The README's conversion tables cover a chemistry engine handling subscripts, polyatomic compounds, ionic charges, hydration states, states of matter and whole reactions with arrows, alongside fractions, derivatives, superscripts, roots, and comparison, logic and operator symbols.
