# ryanjamurphy/workbench-obsidian

Workbench captures material from whatever is currently open into a single Workbench note: pages, headers and blocks can be linked or embedded, and the current line can be copied across. Additions can also be made with alt-click and cmd or windows plus alt-click, and commands exist to insert and to clear the materials collected on the workbench. Settings control the name of the Workbench note, the line prefix given to every added item, and what those two click combinations do.
