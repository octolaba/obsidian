# laximgqozaZZZYT/tag-lens

Tag Lens visualises how a vault's notes are distributed across tags through four view modes: an icon gallery tiling one nested icon per note, a Hasse-style lattice of exact tag intersections ordered by degree, a symmetric tag-by-tag co-occurrence heatmap shaded by Jaccard similarity or raw count, and a BubbleSets containment layout. A floating control panel is shared by every mode and is divided into tabs for filtering the data entering the graph, navigating the surviving notes through folder and tag trees, display, and analysis. The README records saved lenses, following the active note and PNG export, and states that everything runs locally with no network requests. It motivates the four modes by noting that in a vault with deeply overlapping tags a single force-directed graph would collapse into a hairball.
