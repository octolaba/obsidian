# ShermanTsang/obsidian-local-any-files

Local any files extracts external links from an Obsidian note, downloads the referenced files into the vault and replaces the external links with local ones. The README lists preset groups of file types covering images, office files, archives, music, videos and code or configuration files, each with a long list of extensions, and describes configuration options for organizing the resulting attachments.
