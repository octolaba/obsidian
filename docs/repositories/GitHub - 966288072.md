# kargnas/obsidian-create-note-with-date

Create Note with Date adds a command that creates a note named with today's date in year-month-day form inside the directory of the currently open note, and opens it immediately. The README states that the plugin has no external dependencies or database, and that its interface is available in seven languages, chosen automatically from the language configured in Obsidian.
