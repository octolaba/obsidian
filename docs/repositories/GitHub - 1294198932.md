# kebl3541/Obsidian-Umbra

Umbra is a very dark, minimalist Obsidian theme built on near-black surfaces, hairline borders in place of visible chrome, muted grays and a single desaturated violet for links, tags and the caret. The README states that headings differ by weight rather than color, that inactive tabs, the ribbon, the status bar and frontmatter properties stay dim until interacted with, that completed tasks fade and strike through, and that shadows appear only under popovers. Type falls back to faces already present on the system so nothing is downloaded, and the theme is recorded as dark mode only.
