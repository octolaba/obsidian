# ibrh96-prog/obsidian-reading-inbox-synthesizer

Reads a backlog of web clippings in the vault and produces one synthesis note over it: a short summary and the key claims of each synced clipping, themes shared by two or more clippings with an AI-written consensus and the tension between sources, what was saved in the current week counting from Monday, and clippings left unread past a configurable stale threshold, oldest first. A reading inbox lists every clipping with its topics and an estimated reading time. The README frames the problem as clipped articles accumulating unprocessed after readers moved their reading into Obsidian with the Web Clipper.
