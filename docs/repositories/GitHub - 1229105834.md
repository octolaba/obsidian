# uuq007/obsidian-cashlog

This repository holds Cashlog, a personal finance plugin for Obsidian that records income and expenses as plain Markdown list items marked with emoji. Entries are classified with hierarchical tags, then queried, sorted, grouped and summarised inside cashlog code blocks and visualised as bar, line and pie charts or custom tables through cashlog-chart blocks. A side panel shows summary cards, account balances, budgets and goals, and the plugin tracks several accounts along with transfers and balance adjustments. The README also lists receipt photos attached to entries and stored in the vault, natural-language date expressions, and an English and Chinese interface.
