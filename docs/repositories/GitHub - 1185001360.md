# iyioon/obsidian-flash-nav

Flash Nav brings label navigation in the style of folke/flash.nvim to Obsidian, aimed at Vim workflows. The flow is to run the Start jump command, type a search pattern, and press the label character shown next to a match to jump there; backspace edits the pattern, Enter jumps to the current target and Escape cancels. Settings cover the label alphabet, label reuse, whether the current match is labelled, label colours, search direction and scope over the viewport, current line or document, case-sensitive and smart-case matching, auto-jump on a single match, and backdrop dimming. The README documents mapping the command to s in normal and visual mode through obsidian-vimrc-support, naming the command id flash-navigator:flash-nav-start.
