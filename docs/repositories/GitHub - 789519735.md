# lavaforge/obsidian-lava-vtt-uploader

The Lava VTT Uploader is described as uploading images from Obsidian to Lava VTT. Its README explains that Lava VTT is a virtual tabletop meant for in-person play, displaying maps and images to players on a television or projector, and that it is not a publicly hosted service and must be self-hosted. The plugin is therefore configured with the server address of that instance, including a port where needed. An image in a note is then sent by right-clicking it and choosing the display action.
