# Azona77/lite-tabs

Obsidian plugin adding a sidebar panel that lists the tabs currently open in the editor area, as a vertical list, cards or a masonry layout. Tabs can be shown in workspace order, by name or by the modification time of the file, filtered by title through a search control, activated by click, closed by middle-click or a button, and dragged to reorder while workspace order is active. Display options hide file icons or inactive tabs, float, dock or hide the toolbar, and adjust item size, font size, dividers and highlight style, with an optional single-pane mode showing only the active tab group without closing the others. The README states the panel is meant for tabs already open rather than as a replacement for the file explorer, and lists the event-driven, batched update techniques behind its performance claims.
