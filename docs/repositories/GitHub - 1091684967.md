# younginshin115/korean-movie-search

Korean Movie Search fills an Obsidian note's frontmatter with Korean film metadata looked up from the note's filename. The README describes KOBIS, the Korean Film Council database, as the primary source of film data and TMDB as a secondary source for poster images and ratings, with a KOBIS API key required and a TMDB key optional. The lookup runs from a ribbon icon or the command palette and writes fields such as title, English title, director, actors, genre, release date, runtime, nation, company and poster, renaming the file to a safe title when needed. The plugin offers a Korean and English interface with optional and custom metadata fields, and its README credits the Korean Book Search plugin as its inspiration.
