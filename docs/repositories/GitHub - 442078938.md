# manic/obsidian-wrap-with-shortcuts

This plugin wraps the selected text in tags that the user defines, each reachable through its own shortcut. An underline wrapper is supplied by default on control-u or command-u, and a newly created wrapper becomes bindable in Obsidian's hotkey settings after a restart. The README records that the project is a fork of another author's underline plugin.
