# ShotaShirai1719/obsidian-review-comments

Adds review comments to notes by selecting text and clicking a floating button, storing both the highlighted span and the comment inline in the `.md` file as CriticMarkup rather than in a separate store. A comment records its author and date beside its text, so the README's stated purpose is that an external language model can read the file and apply the requested edits with no export step. Installation is manual — build `main.js`, copy it with the manifest and stylesheet into the vault's plugin folder — and the author name used in comments is set in the plugin settings.
