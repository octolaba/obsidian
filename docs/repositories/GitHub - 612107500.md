# M7mdisk/obsidian-gpt

Obsidian-GPT Assistant answers questions from a vault's contents using a GPT-3 based model trained on the notes. An OpenAI API key is pasted into the plugin settings, and loading the data creates the embeddings the search relies on; the README warns that this sends all Markdown files to OpenAI for scanning. Questions are then asked through the `Ask Assistant` command.
