# Trietment/obsidian-kanban

Trietment Kanban collects tasks from every note in the vault onto a board, treating plain Markdown checkboxes carrying a kanban tag as draggable cards. Columns default to a to-do, in-progress, waiting and done set and can be added, renamed, reordered or removed in the settings, with cards dragged between them on desktop and moved through a card menu or edit modal on a phone. On a phone the board shows one full-width column with a row of chips carrying card counts to switch columns, while tablets and desktop keep the multi-column grid. Cards can be grouped by colored project tags with subprojects, by a second client tag dimension, and into swimlanes, and the interface follows Obsidian's language in English or Dutch or can be set manually.
