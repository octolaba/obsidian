# mirnovov/obsidian-homepage

Homepage opens a chosen note, canvas, base or workspace at startup instead of the most recently used file, and the same target can be launched from a ribbon button or the `Open homepage` command. A random file, the graph view or a Daily or Periodic note can be used instead. Settings decide what happens to tabs left open from the previous session, which view the homepage opens in, and which Obsidian command runs when it is opened.
