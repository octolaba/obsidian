# urbanmorph/obsidian-mdshare

mdshare sends a Markdown file or a selected passage to the mdshare.live service and copies the resulting admin URL to the clipboard, invoked from the file explorer context menu, the editor context menu or the command palette. The README records that markdown content is posted to that service to generate a shareable link, that no account is required, and that documents expire after ninety days.
