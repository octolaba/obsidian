# marc-f/obsidian-file-name-styler

Hides, modifies and decorates parts of filenames as they appear in the file explorer, without changing the names on disk. Timestamp-shaped identifiers of eight, twelve or fourteen digits are recognised, or a custom regular expression with three capture groups, and matching names can be given a prefix, a suffix, a colour and a custom icon. Styling can be restricted to particular folders, and several profiles can be combined so that different folders or file types are styled differently. The README states that original names and styles are restored when the plugin is unloaded, and records the plugin's origin as a Zettelkasten identifier hider.
