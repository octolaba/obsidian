# RyotaUshio/obsidian-quick-preview

Quick Preview shows a preview of a suggestion before it is selected, in Obsidian's link suggestions and quick switcher, in Quick Switcher++, and since 0.6.0 in Canvas note and media suggestions. The README states that the preview is triggered by holding Alt or Option by default, and that link suggestions to a file, a heading and a block are all covered. It records that the preview font size can be adjusted through Style Settings, that other plugins can use the quick preview feature through an API, and that beta releases are installable with BRAT.
