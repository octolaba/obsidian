# toki1703/bitwarden

This community plugin shows a read-only view of a Bitwarden vault in an Obsidian side panel. The README states that decryption happens entirely inside the plugin rather than through the official CLI, and that the master password and access token are never sent to the server in plaintext; unlocking uses a personal API key plus the account email. The panel offers folder and type views, favourites, incremental search, TOTP codes with a remaining-time gauge, quick copy buttons and site favicons, and supports the US, EU and self-hosted servers. The README describes the plugin as unofficial, and both it and the repository description are in Japanese.
