# filichev-evgeny/obsidianvkupdatenotifier

This plugin checks a vk.com group for new posts from inside Obsidian. A vk.com account is required and is logged in from the plugin's settings tab, requesting the groups and offline permissions; the README states that authorization is handled by vk.com and that the plugin has no access to the user's login or password. Groups are rendered from a code block naming the group by short name or by numeric id, with the id taking precedence when both are present, and per-block parameters such as a maximum number of days, pinning the last post, a maximum text length and a date format can override the defaults. The README records an Android limitation: the author could not use a webview there, so the authorization link has to be pasted manually, or the login can be done on a PC and the token carried across by synchronization.
