# vforge/obsidian-scanline

Scanline is a terminal and TUI-inspired Obsidian theme its author built for personal daily use across several vaults and then published. Dark mode is near-black with a phosphor glow, monospace-forward typography and barely-there borders, while light mode uses warm paper tones and soft sepia ink. The whole palette, including headings, links, tags, file tree and syntax, derives from the accent color set under Appearance, defaulting to a phosphor green. No fonts are bundled or fetched: the theme takes the first of JetBrains Mono, SF Mono, Fira Code, Cascadia Code and Consolas found on the system.
