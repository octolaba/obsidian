# DuckTapeKiller/etymology-multilingual

Etymology Multilingual looks up word origins in English, Spanish and French from within a note, through the command palette, the editor right-click menu or a ribbon icon after highlighting a word. The README describes it as a fork and extension of clairefro's Etymology Lookup plugin, which covered English only, and lists the online dictionaries it queries for each language, including the Online Etymology Dictionary, the RAE dictionaries, Wiktionnaire and CNRTL; an internet connection is required. Results can be copied, pasted at the cursor or saved into a matching note's frontmatter property inside a configured folder, and repeated lookups are served from an in-memory cache with a configurable expiry.
