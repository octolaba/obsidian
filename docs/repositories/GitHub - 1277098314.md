# johncattrall/obsidian-awareai-theme

AwareAI is a dark-first Obsidian theme from the AwareAI design system, with deep navy surfaces, a red accent and a Signal palette used for callouts, tags and syntax; a light variant keeps the same red over a warm off-white. Its README gives the token mapping, pairing the design system's background, surface, border and foreground tokens and its red with the corresponding Obsidian variables, and mapping Signal green, blue, purple, yellow and red onto Obsidian colour variables. Typography uses Plus Jakarta Sans for text and JetBrains Mono for code when those fonts are installed and falls back to system fonts otherwise, and the README explains how to bundle Plus Jakarta Sans by placing font files beside theme.css and uncommenting a font-face block. Only manual installation is documented.
