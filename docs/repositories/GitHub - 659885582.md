# mProjectsCode/obsidian-js-engine-plugin

The recorded description says the plugin offers multiple ways to run JavaScript from within Obsidian. Per the README a code block whose language is js-engine runs the JavaScript it contains and renders the returned value in place of the block, while a js-engine-debug block behaves identically but adds a small icon in its corner for rerunning the block and viewing statistics about it. Other plugins can reach it through the loaded js-engine plugin instance, and a TypeScript API helper package, attached to each release as a tarball, describes the integration surface: plugin lookup helpers, an internal API, execution context and result types, and the result renderer contract. Separate API documentation is linked, and the README shows a Markdown builder example.
