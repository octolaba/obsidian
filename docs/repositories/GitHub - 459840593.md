# gavinmn/obsidian-things-link

Things Link creates tasks and projects in Things from Obsidian. One command turns the current note into a new Things project and adds deep links in both directions, and another sends the current line to the Things inbox as a task, again linking the two. The README states that the project is currently unsupported and points to a maintained fork.
