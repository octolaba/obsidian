hpdipto/obsidian-ember holds Ember Graphite, an Obsidian theme inspired by the Ember colorscheme and offered in dark and light variants for focused writing and long reading sessions. The README lists a warm colour palette, typography chosen for reading and writing, clean code block styling and consistent callout and markdown rendering, and it attributes the original Ember palette and design to its own creators.
