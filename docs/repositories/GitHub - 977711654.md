# cheuyin/autodater

Obsidian plugin that writes Created and Updated dates into a note's YAML frontmatter, adding Created when a new note carries no value for it, preserving an existing one, and refreshing Updated six seconds after an edit. The property names and the date format are configurable, defaulting to Created, Updated and a year-month-day format, with other date-only orders, a local date and time, and a full ISO 8601 string offered. The README states that only Markdown notes are processed, that changing a property name affects future writes only while existing fields are matched case-insensitively, and that Obsidian 1.13.0 or later is required.
