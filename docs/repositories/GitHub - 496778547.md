# mgmeyers/obsidian-list-callouts

The repository holds Obsidian List Callouts, a plugin that turns a list item into a callout when it begins with a configurable character. Its README records that those characters can be displayed as icons instead, and that the padding of the resulting callouts is adjustable through the Style Settings plugin. It is licensed under the GNU GPL version 3.
