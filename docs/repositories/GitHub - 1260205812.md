# mayeenulislam/obsidian-dbml-visualizer

DBML Visualizer renders DBML fenced code blocks as interactive entity-relationship diagrams inside notes. The diagram is drawn to SVG with automatic layout, link lines and arrowheads, and can be panned, zoomed and rearranged by dragging table nodes. Relations are written in a dotted column style supporting one-to-many, many-to-one and many-to-many markers, processors are registered for both the lower and upper case fence name, and an optional title can be passed in the fence info string. The author records that the plugin was written with the help of free AI models, drawing on the knowledge of building his separate DBML diagram visualizer.
