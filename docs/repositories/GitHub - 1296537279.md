# hata-suriiken/obsidian-popup-dictionary

The README describes an offline Japanese-English and English-Japanese popup dictionary for Obsidian built on JMdict, where selecting a word in the editor or reading view shows its readings and meanings in a popup that can also be triggered from a command or a ribbon icon. Selections inside PDFs opened in Obsidian work too, with line-wrap hyphenation, ligatures and the extra whitespace of PDF text layers normalized and multi-line selections ignored. Lookup is bidirectional and deinflects conjugated Japanese verb and adjective forms back to their dictionary form first. The README states that the dictionary data is downloaded automatically on first load, after which no network connection is required, and that it works on desktop and mobile.
