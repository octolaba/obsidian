# lazyloong/obsidian-fuzzy-chinese

This repository holds Fuzzy Chinese Pinyin, whose Chinese-language README describes adding pinyin search to Obsidian, accepting full spellings or initials in any mixture and supporting traditional characters, double pinyin and fuzzy syllables, the last two being mutually exclusive. The README documents commands that stand in for the quick switcher, the folder-move dialog and the command palette, plus a heading search inside the current document, template insertion, and optional pinyin suggestions for links and for tags. A linkText frontmatter field can add headings or block identifiers to the searchable set. No upstream repository description is recorded, so this body rests on the README alone.
