# chrishoward-projects/related-notes-by-tag

Displays notes that share tags with the currently active note in a sidebar panel, refreshing as the active note changes. Matching can require one, two, or three or more shared tags, results can be sorted by name, modified date or creation date, and the shared tags themselves can be shown. Results can be grouped into collapsible sections by tag, and files in selected folders can be excluded, including their subfolders.
