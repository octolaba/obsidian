# incantatem2/Obsidian-desserts

This repository holds Desserts, an Obsidian theme merging the author's earlier Parfait and Cocoa themes into one light and dark pair, with small style edits and with Parfait's tweaks carried into Cocoa so that the dark mode resembles the light one more closely. The README says the original Parfait and Cocoa themes are to be retired once this one is published. Left-aligned text was removed in this version, and the README gives the CSS rule that restores it, to be added inside the theme's own CSS rather than as a separate snippet.
