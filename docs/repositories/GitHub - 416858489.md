# tomzorz/Sodalite

Sodalite is a relatively opinionated theme for Obsidian, inspired in part by Windows 10 and 11 design ideas such as Fluent and Mica, and as of version 0.1 it supports dark mode only. Two of its deliberate choices are scaling the note title shown in the title bar up to H1 size, and moving the status bar into the right side of the title bar to save vertical space. The README lists the appearance settings the theme is optimised for, ships snippets that cap content width at 1100, 900 or 700 pixels, and records a 0.9.0 entry adding Bases support and reworking the theme around CSS variables.
