# shadielfares/ingester

Ingester watches a folder in an Obsidian vault for new clippings and hands each one to the Claude Code CLI. When a file appears in the watched folder — for example an article saved there by the Obsidian Web Clipper — the plugin opens a new tmux window and runs the CLI's `/ingest` skill against it, so the source is processed into the vault's knowledge graph. The README records the prerequisites as the Claude Code CLI on `PATH`, a running tmux, the zsh shell, and the `/ingest` skill installed in the vault; the repository ships that skill file for copying. Settings hold the watch folder, which defaults to a clippings directory, and a toggle for running the ingest automatically.
