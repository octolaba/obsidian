# jkRaccoon/obsidian-ui-sketch

UI Sketch renders mid-fidelity web interface wireframes inside a note from a YAML description instead of hand-drawn boxes made of pipes and dashes. The README argues that an ASCII sketch loses its structure the moment it is typed, while a YAML screen definition remains addressable data that people can skim, tools can parse and models can mutate, validate or diff, and that the same source renders as a wireframe in reading view following the current Obsidian theme. Forty-five components are available, and the README documents the plugin in English and Korean.
