# nathonius/obsidian-auto-class

Obsidian plugin that applies CSS classes to the Markdown view automatically, as if a cssClasses key had been written into the note, based on the note's path and tags. A folder path or a tag is configured together with the classes to apply, and glob matching is available for advanced cases, so CSS snippets targeting a class can be scoped to parts of a single vault without adding classes by hand. The README states the plugin is in maintenance mode: pull requests and bugs are reviewed, feature requests are not worked on, and the author is looking for someone to take it over.
