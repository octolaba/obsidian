# saberzero1/quartz-syncer

Quartz Syncer manages and publishes Obsidian notes to Quartz, the static-site generator that turns Markdown content into websites. The README records support for GitHub, GitLab, Bitbucket, Codeberg, Gitea and self-hosted Git instances, selective publishing that chooses exactly which notes to publish, update or remove, and a diff viewer showing the changes side by side or unified before publishing. Dataview, Datacore and Fantasy Statblocks queries are compiled into static content, compiled files are cached while dynamic query content is detected and recompiled when needed, and publishing can be automated from the terminal through the Obsidian CLI, which the README records as requiring Obsidian v1.12 or later.
