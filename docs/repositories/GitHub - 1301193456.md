# Louie-vibecoding/time-recorder

Time Recorder is a time-tracking plugin for Obsidian built around a two-click punch-in: the grid opens, a category is tapped or a custom activity typed, and the previous segment closes itself. The README records back-filling on a 24-hour timeline where a gap can be filled and a block edited, deleted or resized by dragging on desktop, live today, week and month summaries by category that can be copied as a Markdown table, a monthly heatmap calendar, a jump to the end of a chosen note, and one-tap undo of the latest punch. It states that all data lives in the user's own Markdown files, that one codebase serves desktop and Android, and that the interface follows Obsidian's language by default with a manual override among English, Simplified Chinese, Japanese and Korean.
