# HuLunTunTao/go-playground-plugin-for-obsidian

Runs, formats and shares Go code snippets through the Go Playground API. A run button on a Go code block executes it and shows the output, an editor context-menu entry imports code from a Go Playground share link or snippet identifier, and the API base address is configurable so a third-party playground can be used instead. The README states that network requests are sent only when the run or insert buttons are used, that code is executed by the configured API and no note content is collected, and that the interface is available in English and in simplified and traditional Chinese.
