# tofrankie/obsidian-plugin-gemoji

Renders GitHub-style emoji shortcodes as Unicode emoji in Obsidian's reading mode while leaving the markdown source unchanged. The README scopes the plugin to reading mode and the rendering contexts served by Obsidian markdown post processors, and states that Live Preview and source mode are not currently covered. Shortcode data comes from the gemoji project and an emoji cheat sheet, both credited in the README, which also points to a matching GitHub-flavored theme.
