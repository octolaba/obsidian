# HananoshikaYomaru/obsidian-tag-generator

This plugin breaks the nested tags in a note's body down into their parent tags and writes the resulting list at the top of the file when the note is saved. A tag several levels deep yields one tag per level, and the tags of unrelated hierarchies are collected in the same generated block. The README records that the block is delimited by a comment which is replaced rather than duplicated on later runs, that tags in the frontmatter are ignored, that generation is skipped for a note carrying an ignore key in its frontmatter, and that the command is meant to be bound to the custom save plugin's save action.
