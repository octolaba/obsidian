# sdkasper/lean-obsidian-terminal

Embedded terminal panel for Obsidian built on xterm.js and node-pty, running interactive shell sessions inside the vault workspace rather than in an external window. It is a full PTY rather than a command runner: the shell is auto-detected per platform, output URLs are clickable, the panel auto-resizes, clipboard copy and paste and readline shortcuts are supported, and a configurable startup command runs in every new tab. Several tabs can be opened, renamed, colour-coded, pinned and dragged to reorder. The README states that the plugin is desktop-only and requires Obsidian 1.5.0 or newer, and that fullscreen mode in detached windows does not reflow terminal content until a command runs.
