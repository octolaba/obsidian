# davidgolding/obsidian-auger

This repository holds Auger, a minimalist Obsidian theme that prioritizes long-form writing and readability. It sets generous line spacing, a legible font stack, font smoothing and antialiasing and a balanced type scale, strips visual noise, redesigns the sidebar, and ships light and dark modes plus styling for the Kanban plugin. With the Style Settings plugin enabled it adds custom colours for bold and italic text, a light canvas in dark mode, a font smoothing toggle, inline title font, size, weight and line height controls, and inactive window blur. The theme is licensed under Creative Commons Attribution 4.0.
