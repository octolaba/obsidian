# pjeurien/obsidian-game-timers

Provides countdown timers in a dedicated sidebar, aimed at running tabletop game sessions. Timers can be created ad hoc with default minutes and seconds or started from reusable presets defined in settings, run once or repeat until cancelled, and be paused, resumed or removed from a pinned footer; active timers survive an Obsidian reload. Presets can carry optional warning times and a colour, a notice fires when a timer finishes with optional desktop notifications, and the status bar summarizes the next timer to expire. A game-timer code block launches a timer from a note, taking a name, a duration or explicit minutes and seconds, a description, a button label and an autostart flag.
