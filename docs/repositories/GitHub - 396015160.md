# Dmytro-Shulha/obsidian-plotly

The repository holds obsidian-plotly, a plugin that embeds Plotly charts in notes. Its README documents a plotly code block carrying the data, layout and configuration objects as JSON or YAML, which are forwarded statically to the library's plot function, and states that this route does not accept the JavaScript examples published by the Plotly project. For those it directs the reader to a second route through a DataviewJS block, which requires the Dataview plugin, and it records command palette entries that insert a template for either form.
