# ELowry/obsidian-replace-commands

Lets search and replace actions be preconfigured as named actions — the README's examples are cleaning OCR text and formatting tables — each holding one or more plain-text or regex rules, then applied to a selection or a whole document in one click. Rules run in sequence and can be reordered, and a live test bench in the settings previews the result of each rule, showing the intermediate output of every step before the final one.
