# especialkim/synaptic-bridge

Synaptic Bridge synchronizes Markdown files, and any other extensions named in its settings, between an Obsidian vault and external folders. The README records multiple folder mappings, one-way synchronization in either direction as well as bidirectional synchronization, real-time file monitoring, and detection of changes made to external folders while Obsidian was closed. Include and exclude rules, the synchronized extensions and the handling of deletions are configurable, and file frontmatter is managed automatically to track sync status, with per-connection control over which side it is written to.
