# tmcw/obsidian-freeform

This repository holds Freeform, described upstream as an Obsidian plugin for freeform visualization and JavaScript code. The README says a fenced freeform code block runs arbitrary JavaScript inside a sandboxed iframe, with a display function for showing values and elements, import statements that pull ESM modules from URLs, and injected styles. It names Observable as the inspiration, and records that export statements are accepted but have no effect while require and JSX are not supported.
