# DvorakDwarf/scrambling-title-animations

Scrambling Title Animations animates the title of a note when it is opened, scrambling and then revealing it in one of several ways. The README states that the default settings are meant to be usable as they are, so enabling the plugin and opening a note is enough to see the effect, and that anything to be changed is found in the community plugin settings. The author records having noticed the effect elsewhere and wanting it in Obsidian as the reason the plugin exists.
