# appendjeff/photo-search-obsidian-plugin

Photo Search jumps from a daily note to a Google Photos or Immich search for that note's date. One command parses the active note's filename with the Daily Notes format or an override set in the plugin settings; a second collects the note's own date together with dates from outgoing links, embeds, frontmatter links and backlinks from daily notes, opening a single match immediately and offering a fuzzy picker when several are found. The README documents the URL shape used for each provider and the settings for the default provider, the Immich base URL and extra date formats to try.
