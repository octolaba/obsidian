# radekkozak/discordian

Discordian is a dark Obsidian theme that carries the Discord application's visual language into Obsidian while aiming to work as a plain dark theme in its own right. Its README recommends a companion Discordian plugin for finer control, listing Writer Mode, Paragraph Focus, Flat Andy's Mode, adjustable line length and font options, and it asks that the provided fonts, chosen to resemble Discord's, be installed in the system first. The disclaimer records that the theme reflects its author's own daily use on macOS, was not tested on other platforms, and may break things because it modifies many parts of the interface. A later note at the top of the README describes small tweaks that keep the original feel and colours while removing parts such as the settings styling, and says that version is used in Obsidian 1.x as a snippet.
