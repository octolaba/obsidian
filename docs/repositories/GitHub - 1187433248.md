# flowing-abyss/obsidian-hybrid-search-plugin

Hybrid Search adds a search modal to Obsidian that combines BM25 full-text with semantic vector search over the vault, showing results with a relevance score as the query is typed, together with a live preview and a local graph. The plugin itself is described as a thin UI layer: indexing and searching run in a separate `obsidian-hybrid-search` CLI installed globally through npm, which the plugin drives as a background process and locates on `PATH` or at a path given in settings. The README marks the plugin as desktop only, and it is distributed both through Community Plugins and as a beta through BRAT.
