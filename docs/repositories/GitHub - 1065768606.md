# incantatem2/Obsidian-antique-flowers

This repository holds Antique Flowers, an Obsidian theme with a dark and a light mode. Its README concentrates on compatibility: the author aimed to make the theme work with the kinds of banners most people use and reports testing with common banner plugins, including Pixel Banner and the older abandoned banners plugin, while warning that the theme's unique layout may still break other styling-changing plugins. Readers who hit such a conflict are asked to post it so that a solution can be sought.
