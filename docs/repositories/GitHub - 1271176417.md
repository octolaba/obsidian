# miaoziguan/obsidian-Bamboo-Darts

An Obsidian plugin that turns long text, a web page, the clipboard or a selection into short atomic notes with the help of the DeepSeek API, then deduplicates them before they are stored. Its Chinese README describes a seven-phase pipeline with a quality gate that filters low-density or noisy input and can be overridden by a forced extraction, and URL content extraction that strips navigation, ads and comments and caches results for an hour. Deduplication runs within a batch and against the existing vault, combining BM25, Chinese segmentation, cosine similarity, edit distance and SimHash fingerprints, with an optional beta stage judging suspicious duplicates through a vector model. It also documents a three-layer fact-checking pass, a second scoring pass that filters weak notes, related-note recommendations, and a cached feature index for the discovery tab.
