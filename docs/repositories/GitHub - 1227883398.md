# sixtarocyan/smart-folder-view

Repository for Smart Folder View, a plugin that presents the notes of a folder as an interactive dashboard. Its README describes saved pages built from any folder, a choice between a timeline and a board layout, multi-select filters over frontmatter fields, card colours derived from a chosen metadata field, drag reordering that can also write a target field value, an undo for the last drag, and exporting a page definition back into the vault. Each saved page records its source folder, an optional template used to infer fields, sort and display fields, layout mode and board grouping field, and filter state and manual ordering are kept locally per page.
