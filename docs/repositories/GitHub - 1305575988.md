# evanlyu/obsidian-crochet-weaver

Crochet Weaver renders crochet stitch charts from text patterns inside Obsidian notes: a `crochet` code block becomes an SVG chart covering flat rows, concentric rounds and continuous spirals, with symbols for chains, single, half double, double and treble stitches, slip stitches, increases, decreases, bobbles, popcorns and post stitches. A `crochet-tool` block renders the same pattern as a row checklist with stitch counts and a per-row counter, and can be embedded beside a chart to highlight the current row and target stitch. The README also records yarn colour-change markers, readable pattern text, panning for oversized charts and a localized interface in English, Chinese and Japanese, with progress stored in the plugin data file and no network requests.
