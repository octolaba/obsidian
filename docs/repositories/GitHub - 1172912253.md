# blamouche/obsidian-any-ai-code

Obsidian plugin that embeds a PTY-backed terminal in the right sidebar so local AI coding tools such as Claude or Codex run inside the vault. Runtimes are declared in settings as a display name plus a launch command, and each session opens in its own tab with its own process, so several runtimes or several instances of one can run in parallel in a single panel. Sessions start in the active vault folder, and the active file or folder can be injected as a mention with one click. Reusable prompts kept as Markdown files in a vault folder are fired into fresh session tabs on an interval or a cron schedule, or run on demand from an Automations panel with an exportable per-run history.
