# LostViking09/obsidian-fastppuccin

FastPpuccin is described as a high-performance clone of the AnuPpuccin theme, streamlined for speed by removing most features and configurations while keeping the look of the original. Its README states that in the author's testing performance is comparable to the default theme, and explains the motivation as AnuPpuccin becoming slow enough on big vaults and complex notes to delay typing. The theme is recorded as supporting the AnuPpuccin Themes Extended colour schemes, mirrored in its own snippets folder, and the author notes that features which add complexity or hinder performance are unlikely to be added.
