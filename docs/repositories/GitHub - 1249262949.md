# nth-chile/obsidian-desktop-sidebar-gestures

Adds directional horizontal swipe gestures on desktop for opening and closing the sidebars: swiping right closes the right sidebar if it is open and otherwise opens the left one if it has content, and swiping left is the mirror image. The README states that empty or unavailable sidebars do not open on a swipe and that there is nothing to configure. It also notes the plugin uses internal wheel heuristics rather than native operating system swipe APIs, so two-finger horizontal swipes are what trigger it.
