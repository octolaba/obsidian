# springrain1/workflowy-style-outline

Presents Markdown notes as a Workflowy-style outline editor with block-level editing. The README describes switching between traditional Markdown editing and the outline mode, hierarchical block operations with atomic undo and redo, a save queue meant to keep synchronisation stable under fast typing, and an isolation architecture intended to leave native Obsidian editing untouched. A separate Daily Notes Plus view, which the README says needs a licence after a seven-day trial, aggregates several daily notes into one editable outline with filtering by source, time range and sort order, collapsible sections, zoom navigation with breadcrumbs, cross-section block dragging and on-demand loading while scrolling. The documentation is written in English and Chinese.
