# vhbelvadi/obsidian-carbon

vhbelvadi/obsidian-carbon holds Carbon, described in both the repository description and the README as a minimal and opinionated Obsidian theme with light and dark schemes, based largely but not entirely on the IBM Carbon design specifications it takes its name from. The README records the theme as being in beta and asks for issue reports or email when it breaks. Its usage notes ask that Obsidian's translucent window option be turned off, recommend a specific accent colour, require a manual clone to be renamed before Obsidian lists it, and suggest restarting the app after applying or updating the theme.
