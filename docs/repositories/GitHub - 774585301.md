# cwfryer/obsidian-callout-suggestions

Offers an autocomplete suggestion modal for callouts, so callout types do not have to be remembered or typed in full. The README states that the suggestion is triggered by typing the opening callout marker, and that the plugin depends on the Callout Manager plugin, whose API it uses to gather the available callouts, including ones the user has defined. It records a known issue that some other plugins interfere with suggestion modals, naming presentation plugins in particular, and gives steps to try when the modal does not appear.
