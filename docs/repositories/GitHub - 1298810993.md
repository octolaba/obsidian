# MarsLuay/handwriting-natively

Handwriting Natively is an Obsidian plugin for handwriting on PDFs with a stylus or mouse, keeping annotations in vault metadata and leaving the original PDF files untouched. It offers pen, graphite pencil, highlighter, laser pointer, circular eraser, lasso and text tools in a Draw toolbar, an opt-in draw mode so ordinary PDF mouse behaviour stays intact until annotating, autosave with recovery, and commands for saving, exporting and selecting ink. Exports can be a flattened copy or a separate editable-PDF annotation copy, and further commands create handwritten PDFs, blank notebooks and pages or export selected ink as SVG.
