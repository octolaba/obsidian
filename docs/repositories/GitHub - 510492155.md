# dominiczaq/obsidian-plugin-time-diff

The repository holds Obsidian TimeDiff, a plugin that computes the difference between times written in a code block. Its README records a timediff block holding one time range per line, rendered in reading mode as readable durations with their sum at the bottom of the block. Three commands are documented: totalling every such block in the current file, inserting a new block at the cursor, and inserting the current time.
