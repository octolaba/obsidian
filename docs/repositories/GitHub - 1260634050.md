# Maniarasan-zuper/slash-cmd

Repository for Slash Cmd, a plugin whose slash menu inserts editor blocks and places the cursor where typing should continue. Its README lists headings, plain text, bullet, numbered and to-do lists, quotes, callouts, code blocks, tables, dividers, internal links, math blocks and today's date, and describes filtering by typing and choosing with the arrow keys. The media entries open the system file browser, copy the chosen files into the configured attachment folder and embed them, which the README explains is necessary because arbitrary external paths cannot be rendered in reading view.
