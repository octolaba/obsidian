# Leike-Dev/Obsidian-Typify

Typify renders values of Obsidian frontmatter properties as styled pills, extending to any property the visual treatment the README says was previously limited to tags. Styles are defined per property with a name, color, shape and an icon drawn from the Lucide library, an emoji, or a user-supplied local image, and colors adapt to light and dark mode. The README also describes scoping a style to particular properties, text-only pills without an icon, hiding the remove button to produce read-only badges, replacing URLs in pills with the style name while keeping link behaviour, favicons cached locally for those links, export and import of configurations, and a color palette with harmony presets. It states that styles also apply in Bases table and card views and in Canvas, and that the interface is translated into five languages.
