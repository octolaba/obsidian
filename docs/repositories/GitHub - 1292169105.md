# Kolpa4/Expansive-local-graph

Obsidian plugin that extends the Local Graph with manual branch expansion past the native depth limit. Expand and reduce actions are added to the graph node context menu, expansion can be nested so an overlay node becomes the root of another branch, and expanded roots are marked with coloured rings. The README states that the extra nodes and edges are drawn in a PIXI overlay layer attached to the Local Graph renderer rather than by mutating Obsidian's own graph dataset, and that relative positions are preserved across rerenders and dragging.
