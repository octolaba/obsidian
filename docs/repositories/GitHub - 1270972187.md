# kathar0s/obsidian-encoding-autofix

Encoding Auto-Fix detects text files added to a vault that are not UTF-8 — the recorded description names UTF-16 and byte-order-mark cases — and rewrites them as UTF-8 before Obsidian or a sync plugin reads them. The README explains the failure it targets: Obsidian handles notes as UTF-8 only, so a UTF-16 or legacy Korean encoded file is mis-decoded on contact, its characters collapse irreversibly into the replacement character, and Self-hosted LiveSync then reports a size mismatch and refuses to write the file. It lists the symptoms it addresses, including mojibake in Korean and other CJK text after import or sync and byte sizes disagreeing between devices.
