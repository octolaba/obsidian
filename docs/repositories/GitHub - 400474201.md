# TfTHacker/obsidian42-text-transporter

Text Transporter is a text-management plugin that can modify the contents of files in the vault even when the file is not currently visible. It adds functions for quickly selecting lines and blocks and for creating block references, and the README aims it at keyboard-driven use. Further documentation is published on the author's own site.
