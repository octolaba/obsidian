# Halftroll0/Sad-Machine-Druid

Sad Machine Druid is an Obsidian theme based on 0xGlitchbyte's Everforest port, with colors shifted away from red and green toward blue and green. The README states that dark mode changes are all that exist for now, and that future plans include updating fonts, updating light mode, and adding formatting support for authors such as highlighting dialogue. Suggestions are welcomed.
