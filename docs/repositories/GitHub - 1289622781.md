# landyking/speak-out-plugin-for-obsidian

Speak Out adds text-to-speech controls to Obsidian's reading view: content marked in source view is given an icon-only speaker button beside it in reading view, which speaks the rendered text with the configured engine and voice. Two marker styles are supported, both enabled by default and either switchable off while at least one remains, one of them a data attribute placed on an HTML element of the author's choosing, with a standard language attribute selecting the language for the system default voice. The README records the plugin as local and note-level, sending no note content to a remote service and using the text-to-speech support exposed by Obsidian's browser environment.
