# DylanTartarini1996/dyresearch-obsidian

DyResearch connects Obsidian to a separate DyResearch Python server that runs a multi-agent AI system for studying and research; the README states the server must be cloned and started before the plugin can be used. Through the plugin, documents are ingested into a vector store and multi-turn chats run against specialized agents — a Coordinator that delegates, a Professor for questions and tutoring, a Librarian that chunks, indexes and cleans up the store, and a Researcher that searches the web for new sources. Chat sessions can be created, renamed, deleted and searched from Obsidian, previous history is retrievable, and answers can be digested into structured notes including Mermaid.js diagrams.
