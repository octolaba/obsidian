# luanalatte/obsidian-sitelen-pona

Repository for a plugin that switches notes written in Toki Pona between a regular font and the Sitelen Pona script. Its README explains that the switch is applied through a command or by adding a CSS class to the note's properties, that the line being edited stays in the regular font to make editing easier, and that prefixing a line with two exclamation marks forces it back to the regular font. The bundled linja-pona font is credited to its authors under a Creative Commons Attribution licence.
