# lucrtrade/lucrjournal-obsidian-plugin

LucrJournal is a trading journal inside Obsidian: positions, playbooks, criteria, symbols, accounts, attachments and market analysis are kept as local Markdown and attachment files under a folder in the vault. Dashboard views cover overview, positions, news, analysis, playbook, accounts and symbols; a position records account, symbol, execution, risk and review context and links to news, key levels, analysis and confluences, screenshots stay attached to the position they explain, and OCR-assisted import extracts candidate fields for review before they are written back. The README states that the plugin requires Obsidian 1.11.4 or later and signing in with a LucrTrade account that includes LucrJournal access, offers English and Simplified Chinese interfaces, and is not a broker, an order-entry tool or an investment advice product.
