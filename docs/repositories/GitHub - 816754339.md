# db-developer/daily-note-structure

Repository for Daily Note Structure, an Obsidian plugin that automates creating a folder and file structure for daily notes, which the README says is unnecessary when daily notes are individual files in a single folder. The structure is configured in settings as an array of entries, each with a type of folder or file, a name pattern, an optional template and optional children, and name patterns use moment.js tokens plus custom tokens for the month of the week's first day, which allows a week's notes to be grouped together. Templater and Folder Notes are recommended alongside it, and the README notes that an invalid pattern may report an error in the developer console or silently return something unexpected.
