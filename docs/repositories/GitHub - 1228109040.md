# KogCat/obsidian-kogcat

KogCat is a local-first calibration layer that reads a selected line, section or whole note against a structured base of cognitive biases, logic fallacies and decision frameworks and returns a few calibration points, leaving the Markdown as written. The review panel opens from the ribbon, the command palette or a right-click; a local engine draws a recall pool from the calibration base, and a connected chat model narrows it to the points that matter, with a built-in fallback when no model is configured. On first launch the engine binary is downloaded from a public release channel, verified against a sha256 manifest, cached outside the vault and run as a local background service, and a user-supplied binary can be used instead. The project states that it runs no server of its own, has no telemetry or account, never uploads the vault, and contacts a model provider only with consent.
