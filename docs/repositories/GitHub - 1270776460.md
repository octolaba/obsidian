# watsonlu/obsidian-showdown-viewer

This plugin renders Pokémon teams built in the Pokémon Showdown team builder inside Obsidian notes. The README states that a team is pasted into a fenced code block marked as showdown, and the plugin displays it in place; the example it gives carries a Pokémon's held item, ability, shiny flag, effort values and its four moves. The README is short and records no settings beyond that usage.
