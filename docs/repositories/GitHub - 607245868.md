# olrenso/obsidian-home-tab

Home tab replaces Obsidian's new empty tab with a browser-like page carrying a search bar and a grid of starred files, searching any local file in the vault including attachments as well as notes. The automatic replacement can be switched off, leaving commands that open a new Home tab or replace the current one. A search can be narrowed by file type or extension through filter keys, and the view can be embedded in a note with a `search-bar` code block that optionally shows only the search bar, the starred files or the recent files. The README opens with a notice that the plugin is not currently maintained.
