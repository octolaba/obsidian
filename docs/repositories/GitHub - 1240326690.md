# MorpheusXu/meridian-clock

Meridian Clock opens analog or digital clocks in an Obsidian pane that can be dragged into either sidebar. Up to four clocks fit a two-by-two world clock grid, drawing either on a built-in list of major cities or on custom cities defined by a standard IANA timezone, which the README records as handling daylight saving changes automatically. Appearance settings cover the analog dial layout, colours for background, hands, ticks and text, typography and layout for the digital face, and whether the second hand sweeps, ticks or is hidden, with built-in presets and user-saved presets for switching between looks.
