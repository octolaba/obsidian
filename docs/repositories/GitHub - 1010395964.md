# Cursivez/journalit

Journalit is a local-first trading journal for Obsidian whose core journaling stays inside the vault and works offline. The README describes a Home View dashboard with draggable widgets and a trading heatmap, trading and account dashboards built around prop firm profit targets and drawdowns, and a review system with daily to yearly templates and a layout builder. Trade Import for CSV, spreadsheets, HTML and broker statements and MetaTrader 4/5 sync over FTP are described as backend-powered features. The project states that it is proprietary software with reviewable source and that an account and a paid subscription are required for those network-backed features, which it describes as opt-in.
