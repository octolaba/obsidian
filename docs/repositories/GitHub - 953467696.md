# CommandJoo/WikiToNote

Wiki2Note converts a Wikipedia entry into an Obsidian note. It is run from the command palette through an Import Wikipedia article command. The README describes the plugin as simple and explicitly not perfect, and records nothing further about how the conversion is performed.
