# cnwenzhihong/Obsidian-auto-paste-link

An Obsidian plugin that reformats a single pasted URL: a plain URL becomes a Markdown link with the cursor left inside the empty label, a URL pasted over a selection uses that selection as the label, an image URL becomes an embed, and a direct video file URL becomes a video element. For a limited list of supported sites, including bilibili, YouTube, Fab and Steam, it fetches and fills the link title after inserting the link. Mixed text is left alone, YAML frontmatter is ignored by default, and the plain-paste shortcut bypasses the plugin entirely. The README is written in English and Chinese.
