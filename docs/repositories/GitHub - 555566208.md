# Basil-Mori/obsidian-edit-gemini

Obsidian plugin that lets .gmi files, the Gemtext format of the Gemini protocol, be created and edited as if they were Markdown files. A new untitled .gmi file is created from the side ribbon or the file context menu, and selecting any such file in the file viewer opens it for editing. The README records Obsidian 0.11.0 as the minimum version, because that is where the required APIs were added.
