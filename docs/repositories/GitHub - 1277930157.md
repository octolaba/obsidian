# aribuga/obsidian-belki-tasks

belki is a Todoist-inspired task manager whose tasks are stored as local Markdown files inside the Obsidian vault; the README states it does not connect to Todoist. It positions itself between checkbox-based task plugins and heavier task-note systems, and ships Inbox, Today, Upcoming, Projects, Filters and Labels, and Activity views covering tasks without a project, overdue and dated tasks, future tasks grouped by date, priority and label browsing with saved smart filters, and completed-task statistics. Calendar subscriptions are optional and read-only: the README states events never become belki tasks and event data is never written into task files.
