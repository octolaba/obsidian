# fantasy-ke/obsidian-cf-imgbed

This repository holds an Obsidian image-upload plugin that sends images to a CloudFlare ImgBed instance. The README lists uploads by drag, paste, context menu and a command-palette batch run, fetching of remote images so external links are re-hosted, and one-command replacement of every image link in the current note. Settings cover the service address with an authentication code or API token, a choice of storage channel among telegram, cfr2, s3, discord, huggingface and webdav, chunk size, file naming, returned link format, an upload directory and a domain exclusion list. Documentation is written in Chinese and English, and support is claimed for desktop and mobile including camera and album capture.
