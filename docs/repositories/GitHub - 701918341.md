# sboesen/remotely-sync

Remotely Sync is a fork of the unofficial sync plugin Remotely Save, created when that project was not actively maintained, and it supports the same kinds of remote: Amazon S3 and S3-compatible services, Dropbox, OneDrive and others. The README lists the security changes it made to the inherited end-to-end encryption — AES-GCM, which authenticates the ciphertext on decryption and so is harder to attack as a padding oracle, a salt raised from 8 to 16 bytes, and an initialisation vector no longer derived from the user's password — while stating plainly that it offers no security guarantees. It also warns that the plugin is not backwards compatible with Remotely Save and needs the documented migration, that it is likely less stable than the upstream project, and that this is not Obsidian's official sync service; it asks the reader to back up the vault first.
