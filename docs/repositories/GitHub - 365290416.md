# Yaozhuwa/easy-typing-obsidian

Obsidian plugin that reshapes text as it is typed, aimed particularly at mixed CJK and Latin writing. Out of the box it inserts spacing between Chinese and Latin letters or digits, switches to full-width punctuation after CJK characters, auto-pairs CJK brackets and quotes, turns two middle dots into inline code, escapes paired symbols with Tab and clears empty list or quote lines on backspace. Further formatting covers sentence capitalisation, configurable spacing around inline code, formulas and links, user-defined regex blocks that protect text from formatting, and a rule engine for custom transformations; every automatic edit can be undone immediately.
