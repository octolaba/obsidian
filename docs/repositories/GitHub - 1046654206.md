# JinmuGo/obsidian-context-workspaces

The repository holds Context Workspaces, an Obsidian plugin that extends the built-in Workspace feature into named spaces for switching between tasks. It offers a live mode that saves and restores state on every switch alongside the default snapshot behaviour, a sidebar of space icons with reordering by drag and drop, and per-space theme and light or dark mode settings. The README states that it synchronizes with Obsidian's Workspace API in both directions and imports existing workspaces as spaces.
