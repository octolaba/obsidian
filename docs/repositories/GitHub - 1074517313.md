# MatheusZarkov/slytherin

Slytherin is an Obsidian theme its author began for late-night writing sessions and D&D campaign planning, aiming for drama with enough contrast to stay comfortable over long stretches. Gradients are applied to headings, bold text, italics and links, and Style Settings can swap them for solid colours while showing live preview chips for each. The README also notes custom graph-view slider colours and adjustments to panes, embeds and metadata, and it is written in both English and Portuguese.
