# jcmexdev/obsidian-mermaid-block-to-image

Mermaid Block to Image replaces a Mermaid code block with a Markdown image link pointing at the Kroki or Mermaid.ink rendering service, and restores it again because the diagram source is encoded in the URL rather than kept in a separate comment. Convert, download and restore appear as hover buttons on a block or a converted image in Live Preview and Reading mode, diagrams can be saved to disk as SVG, PNG or WebP, and rendering follows the active Obsidian light or dark theme. A converted image can be resized by dragging its edge, with the width written into the Markdown link, and diagram metadata controls naming, sizing and alt text.
