# apkcore/apkcore-tts-plugin

This repository holds Apkcore TTS, a text-to-speech plugin for Obsidian that reads the selected text or the whole document aloud. It supports two engines: the browser's native Web Speech API and a WebSocket-based Microsoft Edge TTS whose voice list, including several Chinese voices, is fetched from the Edge TTS API. Playback starts from the ribbon icon, the command palette, the right-click menu or keyboard shortcuts, with a floating stop button during playback, and speech rate, voice and a maximum text length are configurable.
