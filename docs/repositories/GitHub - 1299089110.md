# johannes-kaindl/yijing-oracle

Yijing Oracle casts the I Ching inside Obsidian with a three-coin oracle and the classic Richard Wilhelm hexagram texts, saving every reading as a vault note. A sidebar panel takes an optional question and shows the hexagram figure, the changing lines and the resulting hexagram, two commands cast into a new note or at the cursor, and saved notes carry frontmatter for the hexagram, changing lines, result and question. Texts and interface are offered in German and English and in classic or gender-neutral register, while optional interpretation and meditation-image features stream from a local OpenAI-compatible server and a local A1111-compatible image server and stay off until an endpoint is set. The README describes the plugin as local-first with no cloud and no account, and as a focused re-implementation of the oracle core from the author's separate Yijing project.
