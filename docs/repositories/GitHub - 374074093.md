# SkepticMystic/adjacency-matrix-maker

Adjacency Matrix Maker draws an Obsidian vault's links as an adjacency matrix: a square grid whose rows and columns are both notes, where a filled cell means the row note links to the column note. The Make Adjacency Matrix command opens the image in a modal that pans by dragging and zooms with the mouse wheel, with a control to reset the scale. Hovering a filled cell shows which two notes it connects, holding Ctrl shows the tooltip for any cell, and clicking a cell opens the note.
