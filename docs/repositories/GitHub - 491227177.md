# moolmanruan/obsidian-sequence-hotkeys

Sequence Hotkeys allows a command to be bound to a sequence of chords rather than to a single chord. Hotkeys are managed in the plugin's own options tab, where a search field filters the command list on space-separated terms, and a hotkey is recorded by typing the chords and confirming them. The README states that the author no longer uses Obsidian much and expects to do little further work on the repository.
