# jaliriogbarrios19/ordermanager-plugin

Accounting plugin for Obsidian that manages clients, suppliers, inventory, transactions and debts, with multi-currency support and several separate account books. A dashboard shows indicators, a monthly bar chart, the top five products, stock alerts and upcoming due dates, while transactions offer filters, search, CSV export and recurring entries. Inventory records cost price, sale price and margin with configurable low-stock alerts, debts in both directions can be reconciled quickly, and exchange rates for more than twenty fiat currencies are refreshed from external APIs. The README lists twelve interface languages and states that everything is stored as Markdown notes with YAML frontmatter.
