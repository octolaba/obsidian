# idreamer/markdown-to-slack-message

No repository description is recorded, so this body is grounded in the README alone. The plugin converts a Markdown note into the Slack message blocks needed to send it to Slack. The README describes opening a note and running the conversion command from the command palette, after which the Slack Block Kit builder page opens carrying the converted content, so the message can be sent from the user's own Slack account.
