# rnaidenov/obsidian-ai-nutrition-tracker-plugin

Obsidian plugin that logs nutrition from a natural-language meal description or a meal photo, sending it to an AI model that extracts calories, protein, carbohydrates and fat and writes a food log into the vault. The README names Gemini, Claude 4.5 Sonnet and GPT-5 among the models available for the analysis. Meals that recur can be saved once and added to later logs with a single click.
