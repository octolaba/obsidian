# haivri/obsidian-yaml-properties

YAML Properties replaces Obsidian's in-note Properties editor with an editable, syntax-highlighted YAML block in Live Preview, shows a highlighted read-only block in Reading view, and leaves normal Source mode available. Keys, strings, numbers, booleans, nulls, tags, links, comments and punctuation are highlighted, the block can be collapsed into a compact summary row, and settings control whether notes start collapsed, whether that state is remembered per note, and whether the block is hidden in Reading view. The README states that notes remain plain Markdown, that no proprietary metadata is added, and that the plugin works on desktop and mobile without network access or external services.
