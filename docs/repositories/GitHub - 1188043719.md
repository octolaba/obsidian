# lixingyu41/obsidian-setToRoot

Set to Root opens additional Obsidian file explorer tabs rooted at a chosen folder, leaving the built-in full-vault explorer untouched. The README describes adding a command to the folder context menu of the default explorer, restoring rooted views after a restart, and a searchable icon picker for the tab icon. Settings choose between reusing one rooted view whose root is replaced and opening several at once, and whether new rooted views appear as tabs beside the file explorer or as split sidebar leaves. The README states that the plugin is desktop only.
