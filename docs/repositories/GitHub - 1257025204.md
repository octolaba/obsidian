# kannibalk1w1/jokertype

JokerType is a desktop-first plugin that adds game-like feedback to typing in Obsidian: floating pixel glyphs for typed characters and for space, enter, tab, backspace, delete and paste, plus sampled sounds whose pitch rises during fast typing streaks. It ships Arcade, Neon, Monochrome and Terminal visual themes and Subtle, Classic, Chaotic and sound-only presets, with individual toggles for text glyphs, enter and delete effects, corner brackets, editor shake and a status combo counter. Volume, sound style, effect intensity, glyph lifetime, reduced motion and pitch behaviour are configurable, custom sounds can be uploaded into Obsidian's plugin data, and a command toggles the effects. The README states that the plugin uses no telemetry, advertising, analytics, accounts or network requests, and credits HyperType as its implementation reference and asset source.
