# kubixservice/obsidian-nyan-theme

Nyan is a pixel-retro Obsidian theme inspired by Nyan Cat. It gives each heading level a different pastel colour, turns horizontal rules into rainbow gradients, colours checked boxes as pop-tarts, adds pixel-art file icons for markdown, images, PDFs, audio, video and config files, an animated cat with a rainbow trail in the status bar, a twinkling starfield on the dark background and a rainbow loading bar on the active pane. The interface uses square corners, chunky borders, drop shadow buttons and the Silkscreen pixel font, with warm cream light and deep navy dark modes. Individual effects can be toggled through the Style Settings plugin.
