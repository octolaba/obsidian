# lextoumbourou/obsidian-title-as-link-text

Title As Link Text rewrites links so that they display a note's title rather than its filename, for both wikilinks and Markdown links. A title is inferred first from a configurable frontmatter property, then from the first H1 heading, and finally from the filename, while aliases are respected through substring matching and per-link overrides preserve deliberate custom text through a hidden comment directive or a note property. Links are updated automatically when files are saved or renamed, and the README warns that the plugin can modify multiple files when notes carrying backlinks change and asks for a vault backup first.
