# bomian98/obsidian-hide-commands-in-menu

This plugin hides commands, including those contributed by community plugins, from Obsidian's menus, chosen per menu type. Rules are entered in the settings either as plain text matching a whole command name or part of it, or as regular expressions; dividers left redundant by hidden commands are removed, and CSS classes are injected so hidden items and separators can be styled. The README states that Native menus must be disabled in the Appearance settings first, and that because the plugin modifies menu items after they are displayed, a delay is needed — one millisecond by default — which may have to be raised.
