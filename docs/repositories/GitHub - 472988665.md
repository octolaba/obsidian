# SmortApp/obsidian-smort

The Smort plugin imports Smort.io articles into Obsidian as Markdown: a command asks for a smort.io share link and pastes the Markdown version of the article into the note. The README records two caveats — highlights arrive in a single color, and a highlight covering stylized sections such as bold, italic or blockquote is split into several highlights in the Markdown. The code is credited as adapted from the Pluck plugin.
