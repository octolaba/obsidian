# dbachelor110/flow-tick

FlowTick renders a progress bar in an Obsidian note that shows what percentage of the following checklist items are complete. A flowtick code block marks where the bar appears, and it tracks the checkboxes between that block and the next one or the end of the file, so several bars can live in one note. Nested checklists are averaged, a parent task's completion being the mean of its direct sub-tasks, and the bar is coloured red below 21 percent, green up to 99 percent and blue at completion. Settings cover the re-render interval, which defaults to 1000 milliseconds, the colour mode and debug logging.
