# Real-Fruit-Snacks/obsidian-better-store

Better Store replaces day-to-day use of Obsidian's built-in community plugin browser with a full workspace tab carrying a filter sidebar, a card grid and a detail pane, which can be opened in a tab, a split or its own window. It adds real filters, heuristic categories, rendered README previews, GitHub statistics, a trending view and a dashboard of already-installed plugins, and collapses to a single column with a drawer and full-screen detail sheet in a narrow pane. The README states the plugin deliberately does not install, update or remove plugin files itself — install actions hand off to Obsidian's native Community Plugins dialog — and that the responsive layout is desktop-only for now.
