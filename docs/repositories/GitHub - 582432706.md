# brianpetro/obsidian-smart-connections

Smart Connections surfaces notes and excerpts semantically related to whatever is being written, showing them in a connections list and a graph view so relevant material appears without manual linking, tagging or organizing. The README records it as shipping a local embedding model, so it needs no setup and no API key, stays private and offline by default, runs on mobile, and keeps a small bundle with minimal third-party dependencies. Its recorded framing is a link-building aid for vaults large enough that quickly captured ideas become hard to find and connect again later.
