# EveryDayApps/vesper-golden

Vesper Golden is a warm gold color theme distributed as one palette across several editors and tools, of which Obsidian is one released platform alongside VS Code, while the JetBrains and Zed ports are recorded as buildable locally. The README describes dark and light variants, a build script that produces the artifact for any platform, and installation for Obsidian through the appearance settings theme browser. Further ports are tracked in the repository's own documentation.
