# starhunt/starcloud-studio

StarCloud Studio generates knowledge posters and infographic-style images, HTML and PPTX slide decks, and speech scripts with text-to-speech audio from a vault's notes, and can upload the results into organised Google Drive folders. The README names OpenAI, Gemini, Anthropic, xAI and GLM as usable providers and lists four commands covering poster, slide and speech generation and the Google Drive connection. It states that note content is sent only to the AI and Google services the user configures, that API keys and OAuth settings are stored locally in the plugin settings, that no telemetry is collected, and that the plugin is desktop-only.
