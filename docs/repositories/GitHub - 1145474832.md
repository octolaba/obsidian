# jamesjarvis/obsidian-strava-periodic-sync

This plugin authenticates to Strava over OAuth2 and writes the day's activities into Obsidian daily notes, locating them through the Periodic Notes or Daily Notes plugin. The README records an activities section carrying pace or speed, distance, duration and elevation, frontmatter metrics such as running, cycling and walking distance in metres, automatic sync every 5, 10, 30 or 60 minutes, historical backfill of up to 90 days, and credential storage through Obsidian's SecretStorage API. Setup asks for a Strava API application with localhost as the callback domain, after which the authorization code from the redirect is pasted into the settings; at the time the README was written the plugin was awaiting community-store review and was distributed through BRAT.
