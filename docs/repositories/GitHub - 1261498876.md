# usero2/obsidian-plugins-book-index

This plugin generates an alphabetised, book-style index for an Obsidian vault inside a book-index code block. Terms are extracted automatically from headings, bold and italic text and code blocks across the vault, or listed manually in the block, and files where a term appears in a heading are ranked above files where it appears only in plain text. Clicking an entry opens the file and scrolls the editor to the exact line where the term was found, while a sticky search box filters terms in real time. The generated links can be laid out in one to four columns, with long headings wrapped rather than overflowing.
