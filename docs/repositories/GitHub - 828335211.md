# i-m-mll/obsidian-paste-as-embed

Paste as Embed checks pasted text against regular-expression patterns and, when one matches, creates a new note holding the text and embeds that note into the active note instead of pasting inline. Each rule pairs a regular expression with an optional template the pasted text is inserted into and with settings determining the new note's name and folder; the first rule whose expression tests true is the one engaged, and pasting proceeds as normal when no rule matches. The README records the limitations of this early version, including that only the first matching rule is executed and that an empty expression always matches, and it gives embedding Plotly figures made in Python as the author's own use.
