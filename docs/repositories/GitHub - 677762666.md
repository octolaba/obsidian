# simonla/obsidian_waka_box

Obsidian WakaTime Box shows WakaTime statistics inside Obsidian daily notes. By default the statistics are fetched once an hour, and a refresh can be forced from the command palette. The README states that the block is inserted at the top of the daily note when absent and refreshed in place when already present, and that this behaviour can be used to control where in the note the statistics sit.
