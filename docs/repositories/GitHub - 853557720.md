# MrAnyx/obsidian-ffmpeg-converter

Converts images, video and audio stored in a vault into more compact formats or lower quality, using FFmpeg for the conversion. The supported extensions follow Obsidian's accepted file formats and are listed in the README for each media type. FFmpeg and FFprobe of at least version 0.9 must be installed and reachable through the environment, and a rollback command converts temporary files back to the original after a failed conversion. The README opens with a warning to back up the vault before use and states that most users reduce vault size by seventy percent.
