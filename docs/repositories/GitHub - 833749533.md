# Max-Schulten/truth-table-plus

Truth Table+ generates an autofilled truth table from a logical expression entered in a modal, which is opened from a command in the palette and writes its result into the current editor tab. The README states that the expression uses JavaScript logic operators, gives conjunction and disjunction as its examples, and directs bug reports to GitHub issues and questions to the author's email address.
