# LincZero/obsidian-node-flow

NodeFlow is an Obsidian plugin that renders node graphs of the kind produced by ComfyUI, Unreal Engine, Houdini and Blender, so notes about them can describe the graph as JSON or a lightweight syntax instead of embedding a screenshot, which the README argues is easier to change later. Diagrams are written in code blocks whose type selects the input: a ComfyUI workflow JSON export, the JSON content of an Obsidian canvas file, or a text description in the plugin's own list grammar. The same renderer is usable in VuePress blogs as well as in Obsidian. The README, partly in Chinese, splits the project into purely visual node notes and a newer functional workflow feature whose nodes can be run, and states that a large refactor is under way so the next release will take a while.
