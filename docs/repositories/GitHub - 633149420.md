# lusob/obsidian-brain

This plugin adds a chatbot to Obsidian for question answering over the Markdown notes in a vault. The README states that it runs a brAIn Docker container hosting the brAIn server, which reads the vault's documents and uses the OpenAI GPT-3 API, so Docker and an OpenAI API key entered in the plugin settings are prerequisites. An ingest command feeds the vault's notes to the model and is run again when new notes should be indexed; a ribbon button or an open-chat command then opens the conversation. The repository carries no description, so this summary rests on the README alone.
