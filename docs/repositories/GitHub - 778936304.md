# KraXen72/obsidian-painter

Painter changes the colour of text in a note, extending the highlighting approach of the Highlightr plugin with a text-colour option. The recorded improvements include a minimal menu style showing only icons, a smarter selection that auto-selects the word under the cursor or trims a selection to the nearest word while still allowing part of a word to be painted, a clear command that also removes configurable CSS selectors alongside mark elements and uses a DOM parser instead of a regex-based approach, and a dynamic highlight preview in the settings. The README states that the plugin is looking for maintainers, because its author no longer uses it and has no time for issues or new features.
