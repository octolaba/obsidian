# PandaNocturne/obsidian-password-manager

This plugin manages accounts, passwords and links inside an Obsidian vault, storing them in a JSON structure presented through a three-column interface of groups, entries and details. Its README lists local encryption of the whole store with configurable unlock method and re-verification timing, custom groups, real-time search across title, username, link, note and group name, one-click JSON export and restore, import and export in Markdown or JSON, and a recycle bin from which deleted entries can be restored or removed permanently. It also records automatic export of the complete store to a chosen Markdown file for read-only reference. Those security properties are the project's own claims and were not tested here.
