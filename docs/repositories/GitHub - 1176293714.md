# maxonamission/obsidian-voxtral

Voxtral Transcribe is an Obsidian plugin for dictation with automatic correction on desktop and mobile, adding structure by voice through commands for headings, lists, to-dos and tables localised in 13 languages, and transcribing existing recordings from a vault file. The README says the microphone waits while the user types and resumes afterwards, that transcription runs on Mistral's Voxtral with real-time streaming on desktop and tap-to-send on mobile, and that the user's own Mistral API key is used directly. On privacy it states that audio is processed by Mistral rather than locally, that the plugin stores nothing and sends no telemetry, and that an experimental desktop local server mode can connect realtime dictation to a self-hosted vLLM server instead.
