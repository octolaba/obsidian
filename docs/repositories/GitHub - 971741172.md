# callumalpass/obsidian-template-filename

Template Filename creates Obsidian notes whose filename is generated from a template. The README records a command and a ribbon icon that open a dialog for the filename template and optional note content, with a live preview of the generated name, plus a configurable default template and default content. The placeholders it documents cover date and time components from year down to minute, including full and short month and weekday names, day of year, week number and quarter, and it further lists random strings and unique identifiers, Unix timestamps and seconds since midnight rendered in various bases, counter variables for sequential naming, text formatting utilities and system information variables.
