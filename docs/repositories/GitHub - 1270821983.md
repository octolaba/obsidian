# alas-poor-ophelia/wayfinder

A Pathfinder 1st Edition character sheet that lives in Obsidian's right sidebar, holding abilities, classes, combat, skills, spells and gear and laid out for one-handed use on an iPad. Character data is stored by the plugin itself rather than in note frontmatter, so a sheet is not tied to any one note, while rules text stays as ordinary Markdown notes that the sheet links to. The README states that this is a character sheet and not a builder: it does not enforce prerequisites or cascade rules, beyond filling in racial traits when a race is picked and seeding resource pools and class skills when a class is added, and it computes armor class, saves, attack lines, skill totals and spell DCs from what is entered.
