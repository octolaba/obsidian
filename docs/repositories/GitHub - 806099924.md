# Seniblue/Underwater

Underwater is an Obsidian theme built around switchable color schemes, recorded in its README as a runner up in the Obsidian Gems of the Year 2024 awards. It works best with the Style Settings plugin, which supplies the color schemes, custom colors, further features and a background image, although the README states that the plugin is not required. Beside its own dark and light schemes named Deep, Blue ocean, Seaweed, Sand, Octopus, Coral, Aqua and Oyster it ships widely used palettes including Nord, Catppuccin, Everforest, Biscuit and Gruvbox, and adds custom checkboxes, custom callouts and CSS classes that remove the inline title, blend embeds into the page, add a notebook-like background or hide bold text until hover.
