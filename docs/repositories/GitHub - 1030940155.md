# scross01/obsidian-todoseq

TODOseq is a keyword-based task tracker that scans the vault for lines marked with state keywords such as TODO, DOING, DONE, LATER, NOW and WAIT rather than checkboxes, and collects them into a Task List view. The README describes priority and date markers, natural-language and Org-mode date syntax, filtering by state, priority, date and tags with boolean queries, and clicking a keyword to cycle its state in both editing and reading views. Tasks are also extracted from code comments in more than twenty languages, indented checkbox subtasks are counted as progress, and repeating tasks advance their scheduled and deadline dates on completion. Filtered lists can be rendered inside notes through a todoseq code block.
