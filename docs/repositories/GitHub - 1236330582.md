# CodeWithBehnam/askmate

A desktop-only Obsidian plugin that adds a right-sidebar assistant working on the note being read or edited: asking questions about it, summarizing, rewriting, translating, running reusable workflows, generating images, and writing the output back into the vault through an apply step the README calls safe. Its README documents provider comparison, requirements and setup, example prompts, privacy and network use, a roadmap and troubleshooting, and lists intended users such as students, researchers, writers and product managers.
