# Mara-Li/obsidian-canvas-css-class

Adds a CSS class to canvas files so they can be styled individually. The README states the plugin does two things: it puts the canvas-file class and a data-canvas-path attribute carrying the file path on the DOM of every canvas file, and it lets custom CSS classes be added to or removed from a canvas through a modal, commands or the settings. It notes explicitly that the plugin loads no CSS of its own, so the styling has to be written as a snippet in the vault, and that the recorded path follows a canvas that is moved, renamed or deleted. Further commands switch where the class is appended, between the canvas view content and the body.
