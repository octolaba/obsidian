# carlsverre/obsidian-card-forge

This repository holds Card Forge, an Obsidian plugin that turns notes into printable cards. A Card Forge: Open Preview command opens a preview window in which the current note is rendered at poker-card size, 2.5 by 3.5 inches. Frontmatter properties customise the result: card-forge-type places a string or emoji in the top-right corner, card-forge-title overrides the note title, and cssclasses adds CSS classes to the card. The README states that the plugin is still in development and invites contributions.
