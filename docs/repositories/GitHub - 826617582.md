# kctekn/obsidian-TagsRoutes

TagsRoutes visualizes the files and tags of an Obsidian vault as nodes in a 3D graph. The README is organized as release notes and records a path filter with both positive and negative rules for controlling what the scene shows, and a display control button that opens a scene in the sidebar for use as a navigator. It links wiki pages on organizing tags by timestamp and by hierarchy, and records a fix for mouse drag having no effect, which the author attributes to a change introduced in Obsidian 1.7.
