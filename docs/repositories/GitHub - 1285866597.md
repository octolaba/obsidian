# bwtymdb/scan2md

Scan to Markdown lets a phone photograph book pages, formulas and tables and turns them into structured Markdown written into an Obsidian note, either at the cursor position in the current note or as a new note that can archive the original images. The phone and the computer share one WiFi network: the plugin runs a local HTTP server, by default on port 43112, that serves a capture page reached by scanning a code, and uploads are guarded by a one-time token generated at startup. Images are sent only to the vision model provider configured by the user, with presets for Claude, Gemini, OpenAI, Qwen, GLM, Doubao, Kimi, ERNIE and Hunyuan, and the API key is kept in the plugin's local data file. The README states that the plugin is desktop-only because it needs Node to run the server, that formulas are emitted as LaTeX, and that it collects no telemetry.
