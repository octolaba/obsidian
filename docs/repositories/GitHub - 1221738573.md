# geeknees/obsidian-blockie

The repository carries no description; its README presents Wallet Blockies as an Obsidian plugin that shows deterministic inline blockie identicons beside Ethereum-style wallet addresses. It detects strings of 0x followed by 40 hexadecimal characters in Live Preview and Reading mode and renders the blockie in front of the unchanged address text, so notes stay readable and the address stays copyable. The README states that the blockie algorithm is bundled locally so the plugin does not depend on the archived upstream package at runtime, and lists settings for showing the icon in Live Preview, in Reading mode, its size and which side of the address it sits on.
