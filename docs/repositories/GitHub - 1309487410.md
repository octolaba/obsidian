# LewisStarkov/obsidian-trello-kanban-sync

Trello Kanban Sync mirrors Trello boards into notes for the Obsidian Kanban plugin, which is required to render them, and defaults to one-way synchronization with Trello as the source of truth, so edits made in Obsidian are overwritten on the next pass. Each enabled board is written to a configurable path on an interval or on demand, with due-complete state, labels and a link back to the card rendered by default and members, description and checklists available as toggles. An experimental two-way mode pushes back only a card's name, its lane, whether it exists, and, when checklists are rendered, a checklist item's checked state; everything else remains one-way. The README states that the user creates their own Trello application and supplies its API key and token.
