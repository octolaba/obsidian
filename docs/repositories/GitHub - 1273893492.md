# Real-Fruit-Snacks/obsidian-gym-tracker

Gym Tracker is an Obsidian plugin for logging strength workouts and rucks on desktop and mobile. The README records strength sessions logged with exercises, sets, reps, weight, RPE, RIR, completion state and notes alongside a rest timer, and rucks logged with distance, duration, pack weight, elevation gain, route, RPE, pace and load-distance, with a GPX import filling in date, distance, duration, elevation gain and route name. Routines can be saved, edited and loaded into a new workout, and a built-in exercise library links from a lift to its history. An Insights view reports weekly volume, totals, ruck mileage, streaks, exercise progress, progression suggestions and personal records with a monthly calendar, and sessions export to Dataview-friendly Markdown with frontmatter alongside a full JSON backup command.
