# ShrekBytes/advanced-pdf-export

Desktop-only Obsidian plugin that exports notes to PDF from a full-screen modal with a Markdown editor on the left and a paginated page preview on the right, rendered on demand. Seven customisable style presets are offered along with more than ten code syntax themes applied independently of the Obsidian theme, and Mermaid diagrams are rendered. Page breaks are written as `///` on their own line or inserted automatically before every H1 or H2, and page size covers A4, A3, A5, Letter, Legal or a custom size in millimetres, in portrait or landscape. Margins, fonts, spacing, heading scale, colours, an optional page border, a solid or image background, and header and footer text with page-number placeholders are configurable; export runs through Electron's print pipeline.
