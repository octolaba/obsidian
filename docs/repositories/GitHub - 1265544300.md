# arias007/obsidian-notedraw

NoteDraw is described as a surface layer for drawing and editing rendered note text, with the same logic applied to reading view, source view, embedded note previews and supported webview surfaces. Recorded tools include a default pen and a speed-sensitive fountain pen, watercolour brushes with text-aligned and auto-straight variants, floating text, magnetic rectangles and circles, three-point curved arrows, and selection with movement, resize handles and delete. Elements can be copied and pasted across notes with their styles, assets, layering and bound connectors intact, and the active tool, brush variant, zoom, colour, width and opacity persist across notes and restarts. The description records an open API intended for AI-assisted workflows.
