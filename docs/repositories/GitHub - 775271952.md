# inhumantsar/slurp

Slurp saves web pages into Obsidian as Markdown with the surrounding page furniture stripped off. Pages are slurped from the command palette, through a custom address used by bookmarklets, or by sharing a page to Obsidian from another app on Android and iOS. Frontmatter properties are customizable and can be enriched automatically from metadata sources such as OpenGraph, covering tags built from page keywords, an excerpt, a byline, the site name, published and modified dates, a permalink, the page type, a Twitter handle and onion mirrors. A recorded option slurps only the frontmatter, either permanently or per page, and the plugin is stated to work on desktop and mobile devices.
