# YuChenSSR/buildian

Buildian is an unofficial Obsidian plugin that connects a vault to ACP coding agents, naming the xAI Grok Build CLI, Cursor Agent and Factory Droid; the README states it is based on Claudian and is not affiliated with or endorsed by those vendors. The CLI runs with the vault as its working directory, so it can read, write, edit and search vault files from a chat sidebar, and selected text can be edited inline with a word-level diff preview. Typed sigils in the chat input reach reusable prompt templates and skills, mentions of vault files, subagents, MCP servers or external directories, and refined custom instructions, while a plan mode has the agent explore and present a plan for approval before implementing. Images can be pasted into the chat subject to the selected model's vision support, and conversations run in multiple tabs with history, fork, resume and compact.
