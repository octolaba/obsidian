# gaschengshi/bujuan

Bujuan is a standalone workbench for people who are distracted easily but want steady progress, gathering what to do today, what to do next and what has been finished into one card-based dashboard. Goals carry active, dormant, completed and archived statuses, a dormancy mechanism sleeps a goal until it is selected again, and the day's focus can be re-selected by search and filter or by a random pick from a command or ribbon icon. Current steps are entered manually or adopted from three candidates generated through an OpenAI-compatible API configured with key, base URL, model and prompt template, and finished steps are kept in a timestamped history where recorded idea links become clickable. The README states that the Dataview plugin must be installed first or the plugin will not work, and the repository description is in Chinese.
