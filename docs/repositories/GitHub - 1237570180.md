# AlexanderT142/pdf-font-rewriter

This plugin changes the font of text inside a PDF from Obsidian by redrawing the text that can be replaced safely, aimed at papers, handouts, exported documents and scanned PDFs that still carry a searchable text layer. By default it writes a new PDF next to the original, with an option to replace the current file after a successful rewrite. Its README also describes an experimental live view that opens the PDF in the plugin's own viewer, plans each visible page with a local helper, erases approved original text pixels through a hidden textless render and draws the replacement while the reader scrolls, leaving the original file as the source of truth. It records the deliberate limits: pages that are image-only, rotated, too uncertain or unsafe to redraw cleanly are left unchanged.
