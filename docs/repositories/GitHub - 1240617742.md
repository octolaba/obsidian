# baendlorel/obsidian-liuyao

Obsidian plugin that renders six-line divination diagrams from a fenced liuyao code block. The block takes exactly six digits, each of which names one of the four line types of old and young yin and yang, read from the bottom line upwards, and may optionally carry a date on its first non-empty line with the hexagram on the second; six trigram names are accepted as input as well. The rendered card shows the family and hexagram name, the line relation text, the world and response markers where present, the six gods when a valid date is given, and a version and copyright watermark in its corner.
