# tazihad/obsidian-easy-keep-view

Obsidian plugin that presents the notes of a vault as a card view modelled on the Google Keep interface, each card carrying a title, an excerpt and an optional image thumbnail. The view is opened from the ribbon or the sidebar, clicking a card opens the note in a new tab, and a plus card creates a new note. The theme mode of the view — light, dark or following the system — is set in the plugin settings.
