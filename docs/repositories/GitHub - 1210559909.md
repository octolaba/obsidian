# KXC-Korthcore/obsidian-kxc-cipher

KXC-Korthcore/obsidian-kxc-cipher holds KXC Cipher Dark, a dark Obsidian theme from the Korthcore design system and part of the KXC Themes pack that also covers VSCode, Windows Terminal, oh-my-posh, micro and tmux. The README tabulates the palette by role, with teal for accents, links, H1 and checkboxes, purple, orange, blue and yellow for the lower headings, and a #111921 editor background over deeper sidebar and surface tones.
