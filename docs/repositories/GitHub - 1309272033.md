# AntonAbbac/unsent-letters

Unsent Letters is a dark, icy typewriter theme for Obsidian aimed at long writing sessions rather than screenshots. The README records a monospace editor font chosen for sustained readability, generous line height and paragraph spacing, a maximum content width, a highlighted current line with the rest of the text slightly faded, a visible cursor, and a zen mode that hides the ribbon, tabs and status bar. It also lists an arctic blue-black dark theme beside a warm light one, color-coded root folders in the file explorer, styling for Kanban, QuickAdd, Notebook Navigator, Banner and Dataview, a responsive mobile layout, reduced-motion support, and system fonts only with no network calls.
