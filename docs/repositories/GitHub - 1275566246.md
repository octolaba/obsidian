# johannes-kaindl/vault-rag

Vault Retrieval provides local, offline retrieval over an Obsidian vault — related notes and semantic search — plus grounded chat with a configured LLM endpoint. The README says retrieval always runs on the device using a compact note-level embedding index kept inside the vault, so it syncs with the vault and works offline including on mobile, ranking similar notes by cosine similarity and finding notes by meaning rather than keywords. Chat answers are grounded in retrieved notes and streamed token by token, with an editable live-context panel showing which notes feed the answer and source chips linking back, and reasoning output appearing in a collapsible block that is not fed back into the conversation. Everything lives in one sidebar view whose tabbed panels stay mounted, and the README records that the interface is currently German only.
