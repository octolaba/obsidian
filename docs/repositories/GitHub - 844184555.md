# tu2-atmanand/RoseRed-ObsidianTheme

Rose Red is a red gradient dark theme for Obsidian, stated to be compatible with Obsidian 1.4.13 and above. It is available on the Obsidian theme marketplace, and the README also gives manual steps that place theme.css and manifest.json in a Rose Red folder under .obsidian/themes and then select the theme under Settings, Appearance. The theme is created and maintained by Atmanand Gauns.
