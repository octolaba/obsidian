# AnubisNekhet/AnuPpuccin

AnuPpuccin is a personal Obsidian theme built around the Style Settings plugin, which controls most of its features; the README states that the theme stays usable without that plugin, but with only a fraction of its options. Five palettes ship in the base theme and more come from an extended colorschemes snippet, and they are wired into interface elements rather than into text alone. Its optional pieces include two layout variants, rainbow folder colouring, alternate tabs, custom callout and checkbox styles, speech bubbles, colourful frames adapted from the Minimal theme, and alternate Markdown embed styling. The README records that the theme was voted best theme in the Gems of the Year 2022 awards, that it is on hiatus, and that its GPL-3.0 licence requires preserving the licence notices and crediting reused code.
