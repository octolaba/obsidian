# zcysxy/Obsidian-Terminal-Theme

Obsidian Terminal Theme styles Obsidian so that it emulates a terminal. The editor is built on one colour, customisable through the Style Settings plugin, one font, bold and italic as its two major styles, a uniform font size and line height, a cursor and an active line prompt, and find and replace presented as they would be in a real terminal. Around the editor it adds an Airline-style status bar, treats the open document as the present working directory, opens the command palette and quick switcher as further terminal panes, shows the suggestion container and page preview in a peek window, and replaces interface icons with ASCII characters.
