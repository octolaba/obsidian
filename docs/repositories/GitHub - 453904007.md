# catppuccin/obsidian

Catppuccin for Obsidian brings the Catppuccin pastel palettes to Obsidian, with the Latte, Frappe, Macchiato and Mocha flavours previewed in its README. The full range of palettes and per-colour accents is exposed through the Style Settings plugin, which the README says will carry new options over time, and Latte is selected by setting the base colour scheme to Light. The README records that the default editor text uses a base64-encoded copy of Friedrich Althausen's Vollkorn font, that the theme is a constant work in progress given the pace of Obsidian's own development, and that it was a runner up in Obsidian's 2022 Gems of the Year awards.
