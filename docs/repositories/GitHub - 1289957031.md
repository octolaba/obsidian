# Real-Fruit-Snacks/terminal-workbench

Terminal Workbench is a terminal-inspired Obsidian theme with graphite backgrounds, crisp typography, restrained ANSI-style accents and readable code in dark and light modes, each a deliberate palette rather than an inversion of the other. The README states the goal as a calm, dense, high-contrast working surface rather than retro green-on-black nostalgia. It applies monospace micro-labels to properties, code block headers, tab titles and breadcrumbs, gives code blocks a header band and language label matched between editing and reading views, adds task states for done, cancelled, deferred and important, and styles Mermaid flowchart, state, sequence and class diagrams. Accent color, interface, text and monospace fonts and font size set in Obsidian flow through the theme.
