# Signynt/obsidian-editing-mode-hotkey

Obsidian plugin that adds one command, with a default hotkey, toggling the editing mode between Source and Live Preview. The command changes the default setting and also switches every open editor that is currently in the source editing mode. The README describes installing it from the community plugins browser and rebinding the hotkey in the settings.
