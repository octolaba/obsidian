# michael-uplive021/learning-practice-coevolution

An agent skill, with an accompanying Obsidian plugin, that turns reading into active recall, critique and practice on real tasks. Its loop asks the learner to restate the material in their own words first, then has a mentor role correct the restatement and name the gaps, an apprentice role carry the concept into a real task as a transfer exercise, and an observer role review the result and choose the next step. Each round is meant to leave the learner's own explanation, the corrected gaps, one transfer exercise and a next learning goal. The README is written primarily in Chinese with an English version alongside, and states that the agent skill is the core while the bundled plugin only stores local prompts and study records and does not call the AI itself.
