# Epiphany-Notes/epiphany-obsidian-plugin

Obsidian plugin that receives voice notes dictated in a companion iPhone and Apple Watch app and places them in the vault the next time Obsidian is opened. Recordings are transcribed and queued for sync, and links, screenshots, photos and files shared through the iOS share sheet can travel with them as context. Configurable destinations decide where each capture lands — appended to the daily note, added to an existing note, or saved as a new file — with separate action buttons for separate destinations. The plugin is therefore one half of a service that depends on the separate mobile app.
