# ABHIJEETH-V-N/HYOKA

An agent shell for Obsidian that executes local shell commands with human-in-the-loop authorization and renders HTML files from the vault in a dedicated view with a dropdown for switching between them. A separate mode lets the agent inject interactive dashboard widgets into Markdown files. Configuration covers multiple agent profiles with their own system prompts and API endpoints, a context limit set per model, and a system-execution bypass that the README says should be enabled only in trusted local environments.
