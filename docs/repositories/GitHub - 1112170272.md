# ratokuzmanic/obsidian-kenku-fm-soundboards

This plugin controls playback of sounds from Kenku FM soundboards from inside Obsidian. Commands play a named track from a named soundboard, stop an active track, and reload soundboard data when the plugin's state drifts from Kenku FM, for instance after a sound was played or stopped in the Kenku FM application itself. The remote play address is set in the plugin settings as a base address and port, and defaults to Kenku FM's own local address.
