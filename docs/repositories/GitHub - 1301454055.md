monapdx/Electrocution holds Electrocution, a neo-brutalist Obsidian theme of fluorescent colour, hard black borders, offset shadows and loud typography, built on hot pink, acid lime, ultraviolet purple, cyan and warning yellow. The README lists heavy-bordered headings, high-visibility internal and external links, loud tags with animated hover states, bordered task cards with oversized checkboxes, styled properties and frontmatter panels, colour-coded note, tip, warning and danger callouts, neon syntax highlighting on black code blocks, and matching Reading view and Live Preview styles.
