# atliuhui/obsidian-duckdata

DuckData runs SQL over data reachable from a note and renders the result as a table or an ECharts visualization inside the duckdata code block that declares it. The README states that the source may be CSV written inline, an anchored Markdown table in this or another note, a vault file in CSV, TSV, JSON, NDJSON or Parquet form, or a remote URL, and that the loaded dataset is exposed to the query as a CTE named data, with each block isolated so several can run in parallel. CSV and TSV cells are read as text, so casts are needed for numeric or date comparisons. The plugin is desktop-only and loads the DuckDB-WASM worker and module from a configurable CDN, after which the README states that queries run entirely on the local machine.
