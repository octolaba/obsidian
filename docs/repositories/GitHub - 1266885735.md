# aaronpenne/move-completed-tasks

This repository holds Move Completed Tasks, an Obsidian plugin that moves a completed task to the bottom of its checkbox group when it is checked off, with a highlight flash showing where it went and ordinary undo available. Subtasks travel with their parent, and the README compares the resulting behaviour to Apple Notes, Todoist and Noteplan. Two further commands sort or collect the completed tasks across a whole document for pages that are already messy, both bindable to hotkeys, while the delay, placement, subtask handling and which checkbox characters count as done are configurable.
