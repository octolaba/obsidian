# Artin0r/steam-theme-obsidian

Steam is a flat, zero-radius, dark-only Obsidian theme imitating the retro olive-green Steam interface of the early 2000s, with deep backgrounds, wire greens and sharp yellow highlights. Corners are square across every component, including buttons, checkboxes, tags, canvas nodes and modal windows, and a built-in CRT engine adds active text glow, horizontal scanlines and a screen vignette that can be turned off through the Style Settings plugin. The README notes a pre-configured patch for styling advanced kanban columns, tags and board cards, and recommends installing Liberation Mono Bold and Hack to match the screenshots.
