# Mocca101/obsidian-plugin-groups

The repository holds Plugin Groups, an Obsidian plugin for organising other plugins into groups. Its README records enabling or disabling every plugin in a group with one click or command, loading a group after a configurable delay following startup to shorten the initial load, and nesting groups inside a parent group so several can be delayed together. It also records a limitation: some plugins have to load before the workspace and therefore do not work with delayed loading.
