# meld-cp/obsidian-build

Meld Build lets a note contain sandboxed JavaScript that is executed to render templates, query Dataview and create dynamic notes, turning a note into a small runnable thing. Code goes into a JavaScript code block marked for the plugin, and a toolbar block gives a Run button in Reading and Live Preview modes, while Source mode uses a run command from the palette. The script has access to helpers for asking the user a question and showing a message. The README links a user guide, an API reference and examples including a guessing game and an invoice builder.
