# GixoXYZ/YueObsidian

Yue is an Obsidian theme forked from the Things theme by Colin Eckert, with a color scheme drawn from the author's own Yue theme family. The README records subtle interface colors against vibrant syntax highlighting, light and dark themes, a floating action button for quick preview and edit on mobile, tag pills, checkbox styling and icons, code blocks with line numbers, and the JetBrains Mono font. Colors for bold, italic, highlighters and blockquotes are customizable through Style Settings, and the README lists the supported community plugins along with the inherited alternate checkbox set.
