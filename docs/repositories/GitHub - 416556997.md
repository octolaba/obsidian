# jsartelle/obsidian-auto-split

Obsidian plugin that opens notes with the editor and preview side by side when the workspace is empty. It also adds a command that splits the current pane into two linked panes. The README records that it works only on desktop and tablet devices, because split panes are not supported on phones, and its changelog notes a setting to disable the behaviour on specific platforms.
