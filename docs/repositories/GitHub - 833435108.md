# technerium/obsidian-vault-size-history

Vault Size History draws a graph of how an Obsidian vault has grown, tracking the number of files over time. The graph is opened from a ribbon button, and its legend hides or shows the line for each file category, with the categories themselves configured in settings. Settings also control the display date format, offering several documented patterns, and the order in which legend entries are sorted, either ascending or descending by chart value. The README keeps a separate guide for the 1.0.x versions.
