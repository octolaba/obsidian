# johannes-kaindl/slide-deck

Repository for Slide Deck, a plugin that turns a Markdown note into a slide deck and exports it as a PDF or a series of PNG images, with readability checks shown while editing. Its README states that slides render inside a sandboxed frame so the active Obsidian theme cannot leak into the preview or the exports, and describes five bundled themes selected per deck through a frontmatter key, each carrying matching code-highlighting and diagram themes, with older theme keys resolving to their successors. A toolbar dropdown tries a theme temporarily, labels where the active theme came from and can write the key into the note's frontmatter, which the README names as the source of truth, and further themes can be dropped as CSS files into a configurable folder.
