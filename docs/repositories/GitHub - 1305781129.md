# cwh555/AnimeList

AnimeList tracks anime, manga and novels in ordinary Markdown files inside Obsidian, keeping those notes as the source of truth so uninstalling the plugin leaves records, notes and images behind. It provides a library in card, list and poster views with search, filters and sorting, metadata lookup through Bangumi, AniList and Open Library, local covers, media-specific progress tracking and dated serial entries. A Score Dashboard handles direct and batch rating changes, and a pannable, zoomable timeline shows completions.
