# Lywooye/stratify-mindmap

Stratify Mindmap renders a note as a mind map whose source stays readable Markdown, supporting structures deeper than Markdown's six heading levels and offering Heading, Hybrid and List structure modes with automatic detection of the source format when an existing note is converted. Nodes can be edited directly with the result written back to the Markdown, dragged across parents and sibling positions, selected and restructured from the keyboard, and undone or redone. The README also records Obsidian wikilinks, node collapse, several layouts, PNG export, a theme picker with categorical colour palettes, configurable node font size, automatic wrapping of long labels, and layout recovery after Obsidian reloads or a background tab becomes visible.
