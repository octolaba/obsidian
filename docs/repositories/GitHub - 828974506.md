# itsonlyjames/obsidian-quick-select

Quick Select opens a file, runs a command or picks a suggestion in an Obsidian modal by pressing the modifier key together with a number. The README states that it works in all Obsidian modals, naming the quick switcher, the command palette and the modals it opens, the slash command menu, search, and tag and alias selection, with examples for frontmatter and inline tags, search items, workspaces and slash commands. The modifier is Command on macOS and Ctrl on Windows and Linux, and the project is recorded as MIT licensed.
