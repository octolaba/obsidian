# johnkim05/obsidian-uuugl-plugin

This Obsidian plugin uploads notes to uuu.gl as rendered Markdown documents with images and internal links preserved. The README describes uploading from a ribbon icon, the command palette or a hotkey, choosing a custom or random shortcode so the note is reachable at a short URL, optional password protection, auto-save with version control, and a status bar entry that copies the resulting address. On privacy it states that uploads can be anonymous, that an email is stored only if the user signs in with Google, that notes are stored on Firebase, and that uploads can be deleted from the website.
