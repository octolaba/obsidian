# ofalvai/obsidian-llm-workspace

The repository records no description; its README presents LLM Workspace, a plugin in which a workspace is an ordinary note linking to other notes, and those linked notes are the sources an LLM chat is grounded in. Indexing a workspace builds the usual retrieval-augmented setup by chunking the documents and computing embeddings, after which a conversation can be started or exploratory questions generated, with the retrieval pipeline inspectable while debugging. A single note can also be chatted with directly, gathering more context as the conversation goes on. The README states that manually chosen source sets are cheaper, faster and more accurate than retrieval over a whole vault, that several models and providers can be chosen with customizable prompts, and that the plugin expects the reader's own API key.
