# lanjak/obsidian-qdrant-sync

Qdrant Sync synchronises an Obsidian vault across devices through a self-hosted Qdrant instance instead of Obsidian Sync, iCloud or a CouchDB setup, talking to it directly over HTTP or HTTPS from inside Obsidian on desktop and mobile. Each note is also embedded, so the README states that the same collection doubles as a semantic search index that can be queried from outside Obsidian. Running it requires a reachable Qdrant instance with API key auth, an embedding server speaking the llama.cpp embedding endpoint, and a collection created beforehand at the embedding model's vector size with cosine distance; the settings take those addresses, the API key and the collection name on every synced device.
