# avinashkanaujiya/obsidian-virtual-autolink

Virtual Autolink automatically generates virtual links for text in a note that matches the titles or aliases of other notes, giving glossary-like behaviour without manual linking. The README states that the generated links work in edit and read mode, stay up to date as the vault grows, and are post-processed, so the note text is not changed into bracketed links and the links do not appear in graph view or reference counting; a context-menu action converts one into a real link. Matching can cover the whole vault or be restricted to a folder, and individual files can be included or excluded with a configurable tag. The README records the project as a fork of Obsidian Virtual Linker, now maintained independently.
