# bobostudio/obsidian-imgur-plugin

Uploads images dragged or pasted into a note to Tencent Cloud COS and replaces the local link with the cloud address, configured with a secret id and key, bucket, region and a storage path prefix. Beyond images it can upload other file types including PDF, audio, video, office documents and archives, back up notes locally or online to a configurable path, resize images by dragging on hover, and manage uploaded images from a panel that previews, paginates and deletes them in bulk. Settings also cover the validity period of image links, a connection test and whether the bucket is publicly readable. The README notes that a CORS origin entry is required and that mobile use needs that origin widened.
