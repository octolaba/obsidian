# YouFoundJK/TeXcore

TeXcore assists LaTeX writing in Obsidian by numbering equations automatically, giving them custom identifiers and offering fuzzy autocomplete when a reference command is typed. It renders TikZ code blocks by running a TeX engine compiled to WebAssembly inside a background Web Worker, so no local LaTeX distribution is needed; the format dump, font stylesheet and any packages a diagram requires are downloaded on first use and cached on disk. It also exports a single note or a whole folder to PDF with configurable headers, footers, page sizes and style overrides. The README records that the compilation runs off the main thread specifically to keep the Obsidian interface responsive.
