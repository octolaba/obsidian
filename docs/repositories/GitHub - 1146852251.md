# LunarWatcher/obsidian-utils

A utility plugin for Obsidian bundling several small quality-of-life features into one plugin, the README explaining the bundling as a way to avoid repeating the community review process. The only feature it lists is arbitrary file embedding, including canvases, documented in the repository's own docs folder. The README also declares the plugin no longer maintained, the author citing breaking changes in Obsidian 1.13 and unwillingness to redo the migrations.
