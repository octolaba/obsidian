# saorgage/real-chat

A chat sidebar that talks to any OpenAI-compatible API — the README names DeepSeek directly and OpenRouter for access to many models — with the user supplying the key and choosing a model per session. Five chat sessions each keep their own history, draft, model and settings, persist across restarts, and can be archived, reloaded or exported into a note. The assistant can act on the vault: creating, editing, appending, renaming, deleting and doing find-and-replace on notes, editing frontmatter and tags, finding backlinks, orphans and broken links, and reporting word and vault statistics, with file changes prompting for confirmation unless that prompt is disabled. It also offers ranked vault search from a toolbar button or command, web access and image processing.
