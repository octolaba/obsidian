# emmet24/obsidian-opencode-wsl

Obsidian plugin that embeds the OpenCode web interface in the Obsidian sidebar by running its server inside WSL. A ribbon icon or a command toggles the panel; with auto-start enabled the server launches when the panel opens, otherwise a button in the panel starts it, and the vault project is then chosen inside the web interface. The README records the requirements as Windows 10 or 11 with WSL2, the OpenCode command-line tool installed inside WSL, and a minimum Obsidian version.
