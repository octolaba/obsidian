# Jackywxsz/Jacky-mdflow

Jacky-mdflow turns a Markdown note into publish-ready content for three platforms from a side panel: WeChat Official Accounts, as styled HTML pasteable into the WeChat editor with images converted to Base64; X Articles, as long-form text carrying numbered image placeholders plus a ZIP of the images; and Xiaohongshu, as paginated 3:4 cards downloadable singly or exported together. The README, written mostly in Chinese, records card themes and template, font, size, avatar and cover settings, along with two Xiaohongshu layout modes, one paginating on second-level headings and one flowing the body continuously across cards. It also records that the plugin identifier and install folder remain `mdflow-publisher` for existing users, and states that no account is required, no telemetry is collected, and network requests happen only for external images.
