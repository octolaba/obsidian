# ycnmhd/obsidian-enhanced-annotations

Obsidian plugin that extends Obsidian's comments and highlights. It lists the comments and highlights of the active file in a sidebar view, creates notes from them through the editor context menu, and copies those of selected files through the file explorer context menu. Comments can carry a label written into the comment marker, which both drives custom styling per label and can be inserted through a trigger phrase typed in the editor.
