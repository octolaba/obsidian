# grub-basket/SP

Stashpad is a capture-first notes panel: text typed into a composer at the bottom becomes a note when Enter is pressed, and notes stack newest-first with no filename to invent and no folder to pick. Notes nest under one another into a tree that can be drilled into and stepped back out of, and from there searched, moved or cloned, coloured, pinned, or turned into a task with a due date and a reminder. The README labels the plugin alpha software and asks for backups, requires Obsidian 1.13.0 or later on desktop or mobile, and states that the code is written by an AI assistant under the maintainer's direction rather than hand-authored or human-reviewed.
