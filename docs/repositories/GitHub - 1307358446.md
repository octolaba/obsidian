# RuanPienaarCode/obsidian-bible-search

Bible Search builds a full-text Bible search and reading page inside the vault, described as local and requiring no account. A setup wizard asks where the search page lives — by default a `Bible Search.html` file at the vault root — and which of the public-domain KJV, BSB and WEB translations to include, then builds and opens it, adopting an existing page if one is already present from another device. Commands open the search, rebuild the index after vault edits, and re-run the wizard; the README states network access happens only during setup or rebuild, naming a Bible API host for the translations and raw.githubusercontent.com for the page template, and explains that modern translations are not offered because their licences cover passage quotation rather than whole-Bible storage.
