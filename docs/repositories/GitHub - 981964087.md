# lazerfit/korean-book-search

The recorded Korean description calls this a plugin that fills in book metadata automatically. The README says it completes a note's YAML frontmatter with Korean book information looked up from the note title through the Aladin Open API, covering title, author, publisher, ISBN, publication date, cover image and more. Default fields such as a personal rating, a status and start and finish reading dates can be toggled, custom frontmatter key-value pairs can be added from the settings interface, and an Aladin API key is entered there. Its change list records a high-quality cover option, a pages field, subtitle fields split out separately and Korean localization of the interface.
