# Odaimoko/tag-project

Tag Project manages projects and tracks progress from tasks tagged anywhere in an Obsidian vault, collecting them into a single manage page opened from the command palette or the ribbon bar. The README shows the tagging convention: a checkbox line tagged as a workflow of a given type defines that workflow, and a task tagged with that workflow's name is assigned to it. It states that the plugin extends Dataview and requires it to be installed, while the author records an intention to remove that dependency later, and it points to an external tutorial that is also reachable from a help page inside the plugin.
