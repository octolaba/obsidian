# googlicius/obsidian-steward

Steward is an agent scoped to one Obsidian vault, driven by large language models and equipped with tools and skills, that searches and manages the vault and handles tasks such as creating Bases or Canvas files, with reader-defined commands, skills and workflows. Its recorded pieces are a BM25 search engine with relevance scoring and typo tolerance that the README calls considerably faster than Obsidian's own search, agent capacity through tools, skills, subagents and the Model Context Protocol, guardrails restricting which folders and files it may act on, and a slash-command chat interface built on Obsidian's editor and reading views. The README states that most actions run in the front end through the Obsidian API and local services, so that data beyond the query is not exposed to the model.
