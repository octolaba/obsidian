# mvgrimes/obsidian-todotxt-plugin

This plugin manages todo.txt files inside Obsidian: a file placed in the vault with the .todotxt extension is rendered by the plugin and marked with a badge in the sidebar. The README notes that creating such a file from within Obsidian appends a Markdown extension, so the name has to be corrected outside the app. Beyond the base specification it highlights due dates written in the task text, shifting their colour as the date nears and after it passes, and adds two experimental options: preserving a completed task's priority in a tag, and recurring tasks that create a successor with a new due date.
