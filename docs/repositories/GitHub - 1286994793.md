# istefox/promptbox

Promptbox keeps a library of AI prompts in an Obsidian vault, each prompt a plain Markdown note with YAML frontmatter so the library stays readable and portable without the plugin; its README states that there are no network calls, accounts or telemetry and that it works on desktop and mobile. A full-tab library view ranks fuzzy search results by title, use case and body regardless of word order, filters by type, category, tags, quality, visibility and date, and sorts by title, date, usage recency, relevance or favourites. Cards carry actions to copy with or without variable substitution, edit metadata, open the note, delete and favourite, and a badge opens lint findings for a prompt that has any. Editing happens in a modal whose tag and category fields suggest values already in use and which shows up to five related prompts ranked by shared tags, category and title tokens.
