# Secbone/obsidian-mentat

Mentat is an AI agent that works inside an Obsidian vault through conversation, searching and summarising notes, writing and editing them, running bulk operations such as frontmatter updates and file moves with link fixing, and building research plans that search the web, fetch pages and save findings. The README records two interchangeable chat interfaces, a bubble theme and a terminal-style timeline, together with an extension system, a skill framework and MCP support. Its provider table lists OpenAI and compatible endpoints for chat, tools and embedding, Anthropic Claude for chat and tools, and Ollama locally for embedding only, noting that Ollama offers no tool support.
