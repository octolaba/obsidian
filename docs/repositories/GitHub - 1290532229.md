# EzXabi/svg-suite

SVG Suite opens SVG files from the vault in a dedicated viewer with pan and zoom — two-finger trackpad scrolling pans, pinch or Ctrl and scroll zooms, and the mouse wheel is configurable — beside a live source editor with syntax highlighting, XML formatting and manual or automatic saving. The current view can be exported as a PNG at one to four times resolution, and background presets such as a dot grid, checkerboard or solid dark and light preview an image against different contexts. Hover controls for zoom, reset and expand are added to SVGs embedded in notes, and commands for fitting the view, toggling the code panel and exporting the PNG can be bound to hotkeys.
