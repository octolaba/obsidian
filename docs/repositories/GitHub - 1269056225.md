# meganjjzhang/Promptuary

Promptuary is an annotation plugin for Obsidian that carries reading notes through review comments to a hand-off for an external AI agent. In reading mode, selected text is highlighted in one of four colours and given notes bound to the original text, with the highlights stored in a sidecar JSON file rather than in the note itself. In review mode, text can be struck through to mark a deletion or merge, natural-language revision comments are written without any forced categorisation, and every comment is aggregated in a sidebar list that supports jumping, editing and deleting. The README frames the gap it addresses as existing highlight plugins stopping at recording annotations rather than exporting them for batch execution.
