# ivre/obsidian-ivre-plugin

The repository holds an Obsidian plugin for the IVRE network reconnaissance framework, which pulls data from IVRE into notes. Its README records the IVRE command line tool as a prerequisite and states that only the address data and the view collections are consulted, so scan or passive results have to be turned into a view by IVRE's own command first. The stated purpose is combining that data with Obsidian's organisation for note-taking during penetration tests, incident response and threat intelligence work; the code is licensed under the GNU GPL version 3.
