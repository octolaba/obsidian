# madpin/super-duper-audio-recorder

This plugin extends the audio recorder built into Obsidian with a choice of the folder that recordings are stored in and a picker for the microphone or input device. It adds pausing and resuming without ending the session, multi-track recording for separate speakers or instruments, and a recording duration that can be set or left unlimited. The README, written in a jokey register throughout, also lists a redesigned recording interface.
