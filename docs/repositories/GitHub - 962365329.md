# mattang687/obsidian-checkbox-sort

Moves a completed checkbox to the bottom of its list group as soon as it is toggled, keeping the nested structure intact so child items travel with their parent. The README states that only peers at the same indentation are reordered, that several lists in one file are handled separately, and shows a before and after example of an item sinking below the unchecked ones. Behaviour is resolved through three levels: a global setting, a frontmatter property for a whole file, and a comment marker written before a list that overrides both for that list.
