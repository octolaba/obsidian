# oilandrust/obsidian-github-publish

Publishes a chosen vault folder as a website by generating a repository built with the Quartz site generator and hosted on GitHub Pages, performing the repository and workflow setup itself. After a device-flow sign-in the first publish creates a repository holding the notes under a content folder together with a pinned Quartz toolchain and a deploy workflow; a commit to the main branch triggers GitHub Actions, and later publishes diff the folder against a stored manifest and upload only what changed. Several folders from one vault can be published to separate repositories, progress is tracked until the site is live, and the Quartz configuration file can be edited in settings and republished with the content. The README states the requested permissions are public repository and workflow access, that no other repository data is read, and that the plugin is an early prototype.
