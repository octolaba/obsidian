# vzsky/blindfold-obsidian

Blindfold hides parts of a note inside a normally folded section that a button reveals on click. The README explains the intent as hiding content that takes a lot of space but is not always needed — the author's example is a mathematical proof, and LaTeX is supported inside the folded region. A blindfold is constructed as a code block, and other Obsidian functionality can be used inside it. The README credits AllJavi/spoiler-block-obsidian for a code sample.
