# NabheetCloud/Obsidian-Jira-Sync-Projects-Issues-Dashboard

The recorded description names this an Obsidian Jira Sync Projects Issues Dashboard. Per the README it mirrors one or many Jira projects into the vault as one Markdown note per issue with YAML frontmatter, organized by project, and renders a local, filterable KPI dashboard covering completion, overdue work, workload by assignee, weekly productivity and bug accountability. It connects to Jira Cloud with an email and API token or to Server and Data Center with a personal access token or a username and password, sending traffic straight to the instance over HTTPS through requestUrl with no third-party server or CORS proxy. The README states that the plugin is read-only and desktop-only and therefore unavailable on Obsidian mobile.
