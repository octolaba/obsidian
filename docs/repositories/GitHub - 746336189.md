# MetaCorp/obsidian-augmented-canvas

Obsidian plugin that adds OpenAI-backed actions to Obsidian Canvas. Three actions appear in the menu of a canvas note: sending the note's content as a prompt, asking a question about the note with the question placed on the link between the two notes, and generating questions about the note; the response arrives as a new note underneath, and the links between notes form the chat history sent to the model. Further commands create an image from a note, run a system prompt over the Markdown and canvas files in a folder and its subfolders, insert a system prompt fetched from a public prompt collection or defined in the settings, and create flashcards. The README states an OpenAI API key is required and that the plugin works only with the gpt-4-1106-preview model.
