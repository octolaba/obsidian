# GBAnjos/claude-sync-obsidian

Obsidian plugin that watches a folder for new markdown files and imports them into the vault, aimed at exported Claude chats. The README describes preservation of the subdirectory structure below the watch folder, a configurable destination and check interval, manual import from a command or ribbon icon, and optional deletion of the source files after a successful import. It states that the plugin is designed to work with the author's companion browser extension.
