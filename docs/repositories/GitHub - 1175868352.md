# Adnan-Malik-26/obsidian-ayu-dark

Ayu Dark is an Obsidian port of the Ayu Dark colour scheme, adapted from the Everforest Spruce theme by vupdivup and recorded by its README as dark-mode only. The README describes visual separation through coloured elements, a dimmed background intended to reduce eye strain, mono-colour headings, code blocks following Everforest highlighting rules and simplified tables. Its feature list still names the Everforest colour scheme rather than Ayu, which the attribution section accounts for as the theme that was modified.
