# hammadxp/back-it-up

Obsidian plugin for copying a note before it is modified, or for keeping a history of the changes made to it. Right-clicking a note offers two entries: making a copy placed next to the original, and taking a snapshot copied into a folder the user defines. The README describes no further behaviour.
