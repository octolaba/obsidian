# LeapSurge/Monkey-King

LeapSurge/Monkey-King holds Monkey King, a Chinese-first Obsidian theme whose visual style is taken from Havoc in Heaven, a 1960s cel-animation film from Shanghai Animation Film Studio. The README describes two scene presets combined with four colour sets, a unified vertical rhythm shared by Live Preview and Reading mode, two layout densities, and mixed Chinese and Latin typography across four Chinese and three Latin font families. It requires the Style Settings plugin for its configuration steps and bundles no font files, reading system fonts through local() instead.
