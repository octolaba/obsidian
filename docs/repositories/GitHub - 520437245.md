# k4a-l/obsidian-heading-shifter

The repository holds Heading Shifter, an Obsidian plugin that changes the level of Markdown headings in bulk rather than one hash at a time. Its README motivates it with two ordinary editing situations: splitting part of one note into a new note, where a third-level heading has to become a first-level one, and folding a note into a section of another, where a second-level heading has to become a fourth. Installation from the community directory and manually from a release are both documented.
