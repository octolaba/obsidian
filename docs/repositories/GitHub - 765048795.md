# charliecm/obsidian-line-commands

Line Commands is described as adding commands that select, copy, cut and paste the lines under the selection or cursor. The README lists six: select, copy and cut the lines under the selection or cursor, paste the clipboard into the line above or below the cursor, and duplicate the lines under the selection into the line below. Its author explains the motivation as cutting a line on mobile, where the default cut command does not take the whole line under the cursor when nothing is selected. The README notes that the commands can be added to the mobile toolbar.
