# smartlife-gpt/alfonso-money-manager-obsidian

This repository holds the Obsidian plugin for Alfonso Money Manager, a mobile application for tracking expenses, income and budgeting goals. The application's local database can be synchronized with an Obsidian vault, where the plugin evaluates the Alfonso Query Language to filter, group and report on that financial data. Query results are rendered as charts through ApexCharts inside a note, and the repository keeps separate documentation for the query language and for the settings.
