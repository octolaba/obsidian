# voi-tech/obsidian-primary-simplified

Primary Simplified is a warm, quiet Obsidian theme based on the original Primary theme by Cecilia May, keeping its soft palette, rounded interface details, readable typography, expressive checkboxes and friendly callouts while trimming the theme to what fits a current vault. It ships light and dark palettes, alternative checkbox icons enabled by default, tuned callout colors, folder and bookmark color presets, optional layout density and accent palette choices, and reduced-motion and forced-colors support. It targets Obsidian 1.13+ surfaces including Bases, and adds per-note helper classes compatible with Minimal's cssclasses contract for image grids, block widths, table styling and cards.
