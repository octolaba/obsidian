# matalina/obsidian-tag-and-tally

Tag and Tally adds in-vault tools for running sessions of the rules-light tabletop role-playing system of the same name. The README lists a resolution roller applying the system's mechanics inline, including advantage, disadvantage, tag bonuses and qualifiers, a polyhedral dice roller with quick presets, the complete rulebook bundled with the plugin and searchable from a sidebar, random tables and card decks, and an NPC generator producing appearance, traits and hooks. An optional chat sidebar is described as off by default: the plugin bundles and downloads no model, and it does nothing until the user points it at their own local OpenAI-compatible model server.
