# waheni/obsidian-speaknote

Repository for SpeakNote, a plugin that records audio inside Obsidian and turns it into Markdown through a transcription service. The README names OpenAI Whisper, Deepgram Nova and AssemblyAI as the supported providers, and describes recording from the ribbon or the command palette, an optional mode that transcribes automatically when a recording stops, a floating mini-player for review, a configurable save folder, and interface support for English, French, Spanish and German.
