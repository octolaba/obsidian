# Ragnavig/propsync

Propsync keeps the property structure of Obsidian notes consistent across a group without touching their values. Notes are grouped by the value of a propsync frontmatter property, the shared fields for a group are listed one per line in the plugin's view, and syncing adds any missing property to every note in that group while leaving existing values untouched and writing the added ones empty. The README gives a tabletop role-playing vault as the example, where character sheets share one set of properties and a newly needed field is added to the group instead of to each sheet by hand, and states that the plugin works locally with no telemetry, external servers or network requests.
