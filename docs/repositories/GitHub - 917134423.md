# talau/obsidian-previous-daily-note

This plugin opens the previous daily note in Obsidian. The README states that, unlike the Daily notes command of the same name, it counts back from today rather than from the daily note currently open, and that it provides both a ribbon icon and a command for the action. Installation from the Obsidian community plugins list is recommended, with manual installation recorded as the alternative.
