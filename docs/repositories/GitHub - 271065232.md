# dogwaddle/lizardmen-zettelkasten

dogwaddle/lizardmen-zettelkasten holds Lizardmen Zettelkasten, a light CSS theme for Obsidian geared towards Zettelkasten note-taking and recorded as compatible with version 0.12.10. The repository keeps several variants side by side: the active obsidian.css, an obsidianAlt.css with muted links for easier readability, and an obsidianOriginal.css preserved for anyone who prefers it. A note dated October 2022 states that the theme stopped working after an Obsidian update and that the author had recreated it but had not yet finished updating the page.
