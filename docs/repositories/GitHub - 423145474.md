# claremacrae/reveal-active-file-button-plugin

Reveal Active File Button adds a single-click crosshairs button to the top of Obsidian's File Explorer that makes the explorer show the active file, for example to find neighbouring files. The README presents it as a convenience beside the built-in command and pane-menu option that already do this, and states that the button simply invokes the built-in reveal command. It notes that in large vaults or in folders holding many files the command does not always scroll to the right position on the first attempt, and that clicking the button a second time works reliably.
