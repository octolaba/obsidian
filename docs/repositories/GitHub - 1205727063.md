# Shin2W/obsidian-hover-preview

Image Hover Preview shows a floating preview of an image when the pointer rests over a Markdown image tag or image link in Obsidian. The preview is positioned to stay inside the editor area rather than overflowing into the sidebars, follows the cursor, and can be zoomed by holding a configurable key while scrolling, with enlargement capped at the editor area and the zoom reset to 1:1 when the preview is reopened. Settings cover a hover delay, a modifier key required to trigger the preview, a key that temporarily suppresses it, an optional caption showing the file name or a custom title, a minimum size filter that ignores small icons, and the preview's background, border, radius, shadow and opacity.
