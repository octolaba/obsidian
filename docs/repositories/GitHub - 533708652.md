# czottmann/obsidian-copy-search-url

Obsidian plugin that adds an entry to the context menu of the results count in the search view; clicking it copies the Obsidian URL for the current search to the clipboard, which makes a predefined search easier to bookmark. The README documents installation from the community plugins browser or through BRAT for pre-releases and betas, points bug reports at the repository's issues and discussion at the author's forum, and observes that the plugin adds a button to a core plugin, an idea whose wisdom it leaves open.
