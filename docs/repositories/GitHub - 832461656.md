# barkstone2/vault-to-blog

Vault To Blog publishes an Obsidian vault, or a directory inside it, to a GitHub Pages blog. The README records the prerequisites: a GitHub repository named after the user for GitHub Pages, its build and deployment source set to GitHub Actions, and the repository made public, since private repositories are not supported. It also records the limits — custom domains are not supported, so the default GitHub Pages URL is used — and states that the plugin is in beta with a limited feature set and may not work properly on Windows, having been tested only on a Mac.
