# rgormley/obsidian-github-dark-dimmed

rgormley/obsidian-github-dark-dimmed holds the GitHub Dark Dimmed theme for Obsidian, based on krios2146's Obsidian GitHub theme. It styles Kanban boards to look like GitHub Projects and gives callouts, inline code blocks and interface buttons a GitHub appearance. Header colours and the Kanban and callout styles can be turned on or off through the Style Settings plugin.
