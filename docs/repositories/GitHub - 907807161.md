# Matse2005/Obsidian-Christmas

The repository records no description, so this body rests on the README alone. The README describes a plugin that counts down to Christmas, offering a command that reports the remaining days and a status bar button showing the same count. Its settings toggle the text beside the status bar icon, set how long before the date the button becomes visible, and set the day and month treated as Christmas, which the README ties to the user's location.
