# caezium/obsidian-dayflow-plugin

The repository holds the Dayflow plugin for Obsidian, which reads Dayflow's own SQLite database read-only and writes daily and weekly notes into the vault. Its README describes daily notes carrying a day-at-a-glance callout with tracked hours, top categories, focus and distraction progress and a focus streak, a 24-cell hourly strip, the day's timeline, top apps, and frontmatter fields such as total_minutes and focus_pct that Bases and Dataview can slice. Weekly notes carry inline SVG charts — a donut of the weekly distribution, a bar chart of category totals and a nested treemap — drawn with currentColor so they read in light and dark themes. The README records the plugin as local-first with no network calls beyond an optional ActivityWatch enrichment on localhost.
