# Superschnizel/Obsidian-Moviegrabber

Moviegrabber is an Obsidian plugin that generates notes for movies and series with properties usable in Dataview queries. It retrieves data from the Open Movie Database API and, optionally, embed links for trailers from the YouTube Data API, both requiring keys set in the plugin settings, and the commands Search movie and Search series accept a title or a valid IMDb identifier. How the data lands in the note is defined by a template whose placeholders take the form of double-braced tags, with list-valued tags wrapped in square brackets to form a valid frontmatter list, and a prefix and suffix can be attached to a tag to build values such as internal links.
