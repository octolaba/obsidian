# merijnvervoorn/obsidian-folder-to-tag

Folder to Tag automatically tags notes in Obsidian based on the folder they are stored in, writing the folder tag into the frontmatter tags property and updating it when a note is moved or renamed. Folder depth is configurable: the last folder alone, two levels as separate tags or as one nested tag, or the full path, with an optional prefix and suffix applied to every folder tag. Other frontmatter fields are preserved, notes with or without an existing tags key are handled, and the settings tab offers commands to reapply folder tags across all notes or remove them again.
