# ylgkger/dingtalk-minutes-to-obsidian

Repository for DingTalk Minutes Sync, a desktop Obsidian plugin that imports DingTalk AI Minutes into a vault as Markdown notes through the locally authenticated DingTalk Workspace CLI. The README lists imported summaries, keywords, action items and optional transcripts, notes named by the actual meeting start date rather than the sync date, initial ranges of seven days, thirty days or one year, and manual, startup or scheduled synchronisation. It states that no DingTalk password, cookie or AppSecret is stored, that existing notes are preserved when the transcript API is unavailable, and that the plugin is desktop-only because it invokes a local CLI.
