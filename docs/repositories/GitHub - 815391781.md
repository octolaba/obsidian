# drichardson/obsidian-toggle-readable-line-length

This plugin adds a command, and a default hotkey, that toggles Obsidian's readable line length editor setting. The README records the default binding as Command-Shift-E on macOS and Control-Shift-E on Linux and Windows, and states that it can be replaced by assigning another hotkey to the command.
