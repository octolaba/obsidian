# hoyin258/markdown-password

Markdown Password is an Obsidian plugin that keeps secrets out of the note text, leaving only a vault placeholder in the Markdown so the file stays clean and sync-safe. Typing a secret inside password brackets while the vault is unlocked encrypts it with AES-256-GCM into a local vault.json and replaces the typed text with the placeholder, while a locked vault leaves the text in plain form. Commands unlock the vault with a master key and lock it again, and the README states that the master key and the decrypted vault key live only in RAM, that modifications are tracked in logs, and that there is no recovery if the master key is lost. Its stated aim of keeping secrets away from cloud sync, search indexers and language models is recorded here as the project's own claim.
