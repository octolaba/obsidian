# nekoe/obsidian-tate

TATE renders and edits notes in the traditional Japanese vertical layout, running top to bottom and right to left, and its recorded description claims smooth editing on files of over a million characters. It reads the annotation syntax of Aozora Bunko, so ruby (furigana), upright digits and latin text, emphasis dots, and three heading levels are written inline in the note text. Commands in the palette apply each annotation to the current selection and refuse to nest one inside an existing annotation, and another command strips every Aozora annotation from the selection, keeping the base text and discarding a ruby reading. The README records that removal also works from a collapsed cursor next to an annotation and across a document-wide selection.
