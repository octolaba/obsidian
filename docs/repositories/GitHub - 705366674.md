# pashashocky/obsidian-note-gallery

Note Gallery is an Obsidian plugin that renders notes or images as a masonry gallery defined by a code block inside a note, in the manner of a folder overview. Its block arguments include a single query using Obsidian's native search syntax, including regular expressions, paths and tags, a path for selecting one folder or scanning it recursively, and options for sorting, limiting the number of results and setting custom column breakpoints. Markdown card loading is cached and create, update and delete operations in the vault update the gallery. The README describes the plugin as in early alpha testing, functional but possibly containing bugs, and lists an interactive folder view and a view of open tabs as work in progress.
