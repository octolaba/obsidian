# SalemElatar/salem-obsidian-theme

SALEM is a custom Obsidian theme built around a clean and comfortable user interface with a focus on readability and ease of use. Its listed features include a CENTER callout for centring text without HTML tags or LaTeX, a ListGrid callout that works with Dataview LIST queries and with plain Markdown lists, wider UI spacing, folder icons, differently coloured tags, and border-less transparent cards in canvas. Header callouts inspired by the vicious-theme are available, together with further custom callouts such as moon, author and comment. Installation runs through Settings, Appearance, Themes, Manage, searching for Salem-theme.
