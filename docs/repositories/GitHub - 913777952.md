# LostPaul/obsidian-folder-overview

Renders a dynamic overview of the vault or of a folder from a code block. The README states that this is the same functionality as the folder overview feature of the Folder Notes plugin by the same author, offered as a standalone alternative for users who want only that part, and that it cannot be used while the Folder Notes plugin is also enabled.
