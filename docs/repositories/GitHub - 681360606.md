# Warrobot10/Serika-for-obsidian

Serika for Obsidian brings the default Monkeytype theme to Obsidian, and the README records that a light mode has now been added beside the dark one. The credits point back to Monkeytype, where the theme exists as serika and serika dark. The author asks for issues to be raised on GitHub or through the Obsidian community forums and links a form for feedback and suggested improvements.
