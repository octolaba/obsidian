# yut0takagi/obsidian-deck-dashboard

Repository for Obsidian Deck, a composable dashboard plugin that arranges widgets — tasks, Dataview queries, Bases and calendars — in a draggable grid. The README describes the project as a Phase 1 scaffold that opens `.dashboard` files in a custom view, with no widgets implemented yet. Installation is documented through the BRAT community plugin, and the code is MIT-licensed.
