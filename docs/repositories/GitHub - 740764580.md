# nmcarp99/Obsidian-Auto-Definition-Link

Obsidian plugin that turns block identifiers typed in a note into links to those blocks, where the identifier comes from Obsidian's own block id syntax. In auto link mode the identifier is converted once a space or other interrupter is typed, and holding shift while pressing space skips the conversion; in suggestion mode a list of candidate links is offered and one is chosen or accepted. Matching ignores capitalisation, plurality and dashes versus spaces, while the inserted link keeps the form that was actually typed. The README states that only Markdown files in the same folder as the current document are scanned, and that both modes are enabled or disabled independently in the settings.
