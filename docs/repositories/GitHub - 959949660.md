# adamfletcher/obsidian-cut-the-fluff

Cut The Fluff marks words and phrases in the editor that may be unnecessary, covering four built-in rulesets: weak qualifiers and hedges, clichés, jargon and metaphors, wordy constructions with simpler replacements, and redundancies. Each ruleset can be enabled or disabled, custom words and phrases can be added, and exceptions can be recorded for built-in matches. Matches are shown dimmed, struck through, underlined, or not at all — in which case a class is applied so a user stylesheet can format them; the README states that all processing happens locally and that no text is sent to a remote server.
