# MarckFp/jw-timer-obsidian

JW Meeting Timer is an Obsidian sidebar plugin that provides one stopwatch per part of a JW congregation meeting. It fetches the week's programme from wol.jw.org in a chosen language and caches it locally, re-fetching only when stale, then builds a card per part showing elapsed time, a progress bar and the scheduled end time, above a global bar for the meeting as a whole. A card turns red when a part exceeds its allotted time, with a configurable beep or vibration, an optional one-minute advice sub-timer sits below applicable parts, and pausing a part can start the next one in the same section. Parts can be added, relabelled, retimed, reordered and deleted, past and future weeks can be browsed, a text summary can be exported, and the interface ships in fourteen languages.
