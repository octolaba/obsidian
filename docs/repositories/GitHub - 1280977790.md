# typ127/vault-commander

Vault Commander is a dual-panel, keyboard-driven orthodox file manager for Obsidian modelled on the DOS file commanders of the late 1980s and 1990s, down to the blue screen with double-line borders. Each panel can be set to a brief file list, an info view of file and folder counts, a folder tree that drives the other panel, or a quick view previewing the file under the other panel's cursor, with per-panel sorting by name, extension, time, size or unsorted and either a full or a wide layout. It adds a type-to-jump quick filter, folder bookmarks, and two themes named Commander Blue and Navigator Gray. The README states that it works entirely within the vault through Obsidian's own vault API, without shell commands or Node filesystem access, and runs on desktop and mobile.
