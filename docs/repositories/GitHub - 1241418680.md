# battlecook/omni-viewer-obsidian

Obsidian port of the Omni Viewer editor extension, which opens and in some cases edits a range of file formats inside the vault. It carries over an audio player with waveform and spectrogram analysis and region export, an image viewer with filters and annotation tools that can be saved back into the vault, a PDF editor covering text, stamps, signatures, page reordering and merging, a CSV editor that writes cell edits back to the file, and a partial LaTeX structure and formula preview that is explicitly not a compiler. Files whose content does not match their extension are rerouted to the right viewer, and a share command uploads a copy to an external service under a size limit and a short expiry, then copies the link. Extensions that Obsidian handles itself are reached through the file context menu, while the remaining extensions open with this viewer by default.
