# WinnerWind/gummy-revived

Gummy Revived is described in its README as a revival of the now defunct Gummy theme by Kneecaps, focused on a clean design language and minimalism. The README states that the theme has no style settings yet, and that its interface elements respond to the accent colour currently applied. It names Peace Sans for titles and Space Grotesk for main text, lists plugins it works well with including Make.md, Kanban, Omnisearch, Better Command Palette, Influx, Strange New Worlds, Reminder, Memo and Surfing, and records that the original author is Kneecaps, with this repository maintained because of inactivity upstream.
