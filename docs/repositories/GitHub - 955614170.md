# bwya77/obsidian-quick-peek-sidebar

Quick Peek Sidebar expands and collapses the Obsidian sidebars automatically when the pointer hovers over the left or right edge of the window. The README records settings for enabling hover on each sidebar, the pixel distance from the edge that triggers it, the animation speed, separate delays before expanding and before collapsing, a maximum width per sidebar, an overlay mode in which the sidebars slide over the main content instead of pushing it, a sync option that expands both sidebars together, and a double click that pins a sidebar open until it is double-clicked again.
