# lukeleppan/obsidian-discordrpc

This plugin updates a Discord status through Rich Presence to show that Obsidian is in use, optionally including the vault name and the name of the current file. Settings toggle each of those, allow a custom public vault name, control whether the file extension is shown, choose between the total time in Obsidian and the time spent on a single file, and turn connection notices on or off. It connects only while Discord is running, and a status bar control or a reconnect command retries when it is not.
