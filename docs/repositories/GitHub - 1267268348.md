# andreagrandi/obsidian-meeting-notes-sync

Meeting Notes Sync imports meeting transcripts, notes and AI summaries into a vault from MacParakeet and Fellow, writing one folder per meeting with a folder-note index and each artifact tagged by its source. A meeting captured by both sources merges into a single folder, matched on time-interval overlap with title similarity breaking ties, and an uncertain match is flagged with a low merge-confidence value for review. Syncs are incremental and non-destructive: unchanged meetings are skipped, a late Fellow recap merges into the folder MacParakeet already created, deleting a meeting in a source never touches the vault, and files added by hand are left alone. Each source is toggled independently and a disabled one is inert; the README records MacParakeet as a local macOS command-line tool on desktop and Fellow as a REST API needing a paid plan, an admin-enabled API and a personal key.
