# gibranbadrul/obsidian-confluence-page

Confluence Page Publisher is a one-way publisher for turning Obsidian notes into Confluence pages. Note frontmatter identifies either an existing page or a new child page, and commands trigger publishing; the README documents what is converted and what is not yet, internal macros, attachment publishing and diagram rendering. Authentication covers Atlassian Cloud, Confluence Server or Data Center with a personal access token, and a legacy Server account, and the README carries its own sections on storage preview, privacy and network behavior, settings and limitations.
