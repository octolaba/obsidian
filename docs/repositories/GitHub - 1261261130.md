# nocodeuse-dev/obsidian-quicker-wheel

Quicker Wheel adds a radial command wheel to Obsidian, opened from the command palette or from a floating button, whose slots are bound to Obsidian commands, vault files, URI actions or reusable wheel actions; tapping an empty slot creates an action for that position. The floating button works on desktop and mobile and carries three gestures: a tap opens the wheel, a quick swipe in one of eight directions runs the action bound to that direction, and a long press with a drag moves the button. Wheel size, ring and slot counts, text size, opacity, colours and gesture timing are configurable, and direction actions can reuse actions already defined on the wheel. The README is written in English and Chinese and describes the design as touch-first.
