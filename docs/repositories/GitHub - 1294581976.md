# kuangjiajia/kaitox-obsidian

The recorded description states that this is the distribution repository for the Kaitox Obsidian plugin in the community-plugins directory, generated from the kaitox-toolkit monorepo on each release, where issues and pull requests are to be opened. The README says the plugin previews the active note as an X (Twitter) Article, style-checks and packages it, and then hands the draft to the Kaitox Chrome extension, which picks it up in a logged-in x.com session and creates the Article draft there. According to the README no official API and no keys are involved.
