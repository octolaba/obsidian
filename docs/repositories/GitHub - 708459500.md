# vincenzocaputo/obsidian-metal-archives-plugin

This Obsidian plugin creates notes about metal bands and albums by fetching data from the Metal Archives site, and describes itself as unofficial. It provides two commands, one to search for a band and create a note from it and one to do the same for an album. The README illustrates the result as a graph of bands, albums and tags.
