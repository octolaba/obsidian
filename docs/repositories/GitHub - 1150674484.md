# Altarok/RubikCubeAlgoView

Visualises Rubik's Cube algorithms inside Obsidian notes, rendering a cube that can be rotated with built-in controls or reset to the default view, with the algorithm notation updating to match the current orientation. Commands insert a blank commented code block, a pre-configured example, a stopwatch timer, and a quick start guide, and the integrated speedcubing timer includes scrambled algorithms. Cube size, hex-code colors and directional arrows are configurable, and the plugin states mobile support.
