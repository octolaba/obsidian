# ttusk/leif

Obsidian plugin that organizes exam-preparation study in a single panel, using Brazilian public-examination vocabulary for its entities: contests, subjects, topics, resources and dated study records, plus a today view showing what to study now for the active contest and a Markdown reference wall. Resources carry progress goals in pages, questions, lessons or minutes, and each contest keeps its own cycle and progress. Since version 3.0 all study content lives as readable Markdown files under a vault folder, one small file per entity with independent records collected monthly, so they can be edited in Obsidian, another editor or by an agent while Obsidian is closed. The plugin watches that folder, debounces batches, ignores its staging and backup directories and runs an idempotent sync at startup; the README states this schema is the only writable study authority.
