# vicstu/obsidian_max_sync

MAX Sync bridges the MAX messenger and an Obsidian vault, fetching new messages from a companion sync server, appending them to a target note with an optional template, and downloading media attachments into the vault. The README states that the plugin is desktop only, requires a recent Obsidian version, and needs a running MAX Sync backend and bot that issues a personal user token, which is pasted into the settings and verified with a check button. Settings also cover the template file, the target file and the attachments folder, and messages are pulled by running a fetch command from the command palette.
