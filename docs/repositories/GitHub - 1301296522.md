# algometrix/second_brain_builder

Second Brain Builder generates a folder of interlinked study notes from a topic, including an index hub, mermaid concept maps and wiki-links that appear in the graph view, and it can also explain a selection into linked notes or enhance text in place. Instead of an API key billed per token, it drives an AI command-line tool the user already has, namely Claude Code, the Gemini CLI or the Codex CLI, or a local Ollama model, with all four backends behind a single setting. The README states that it runs in the Obsidian desktop app on Windows, macOS and Linux and is not available on iOS or Android because it needs to run local programs, and it notes that generating notes still consumes the underlying subscription's tokens.
