# rafaelmehdiyev/obsidian-vault-time-tracker

Vault Time Tracker records how long is spent on each note, and the README stresses that the timer is tied to the note that is open rather than to Obsidian being the active window, so it keeps running when the app is minimised or another program is in front. Opening a note starts tracking and switching notes pauses the first and begins the second, Markdown and Canvas files are both tracked, optional idle detection can pause after a period of inactivity, and closing the last tab of a tracked file stops it. A sidebar panel carries daily, weekly and monthly tabs while a full-page dashboard adds a folder column, untruncated names, full-path tooltips and sortable columns, and the status bar shows the tracked note with a running total for the day. Deleted notes stay in the history with a label, renames carry their time along, and data is written to disk every 30 seconds.
