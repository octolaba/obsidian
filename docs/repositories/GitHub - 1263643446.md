# viggomeesters/obsidian-slide-deck-viewer

Repository for Slide Deck Viewer, a plugin that opens PowerPoint files as a read-only inspection view. Its README states that the package is parsed locally with no cloud conversion, and that the view shows slide navigation, extracted text, speaker notes, media references, relationships and package diagnostics, with filtering over them and caps on large render lists. It warns about external relationships, embedded objects, macros, oversized decks and encrypted or malformed packages, and lists as non-goals editing or export, pixel-perfect rendering, legacy binary decks, executing embedded objects, any network access, and launching an external presentation application.
