# StinsonZhao/obsidian-plugin-goban-sgf

This repository holds Goban SGF, described upstream as an Obsidian plugin for recording Go games in the SGF format. The README says most of the functionality and interface were ported from Sabaki, excluding engine and analysis features, giving play with branches and variation trees, edit markers, comments and free navigation, plus SGF import and export. It also lists partial board display for life-and-death study, settings that can be tuned per file through frontmatter, rendering of sgf code blocks as read-only boards inside ordinary notes, and light and dark interfaces.
