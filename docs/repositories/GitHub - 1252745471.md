# Sonophage/Bureau

Bureau is a noir Obsidian theme whose interface is driven by a single chosen accent colour: red for its Control default, green for a Magnus mood and gold for a Deus one. Most of its configuration lives in one Bureau panel in the Style Settings plugin, and the README states that the theme still runs on its built-in defaults without that plugin. It ships both a near-black dark palette and a daylight paper palette, and the editor can be set to the opposite palette from the surrounding chrome, giving a lit page on a dark desk or a dark page in a lit room.
