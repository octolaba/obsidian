# uzusio/obsidian-sr-popup-review

Popup Review shows Spaced Repetition flashcards in a small always-on-top window that appears at a configured interval, by default every two hours, at the bottom right of the primary display and without stealing focus. One due card is shown, the answer revealed by a button or the space bar and rated with four buttons or the number keys; closing the popup without rating writes nothing and leaves the card due. The README records that ratings go through the Spaced Repetition plugin's own review pipeline rather than a re-implementation of SM-2 or FSRS, that desktop Obsidian is required because the popup is an Electron window, and that the pairing was tested against Spaced Repetition 1.15.4.
