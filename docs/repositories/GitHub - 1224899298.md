# i-iooi-i/obsidian-memoria

Memoria is a fleeting-thoughts plugin that keeps every memo as an ordinary Markdown file in yearly files inside the vault instead of a database or proprietary format, so the notes stay readable and searchable without it. It offers a quick-capture box sent with Ctrl or Cmd and Enter, a global capture command, a waterfall timeline grouped by day, tag autocomplete with combined tag and keyword search, images added by paste, drag or file picker, task checkboxes written back to the file, and pinning and starring. A sidebar heatmap and calendar, a statistics report and a year panorama summarise activity, and the README records Chinese and English interfaces together with a mobile-friendly layout and touch interactions.
