# emklasson/obsidian-save-modified-times

This plugin adds commands that save and restore the last modified time of notes in a vault, so frontmatter can be edited — adding tags or changing a property — without moving the note's mtime. The README lists saving and restoring the current note's time either into the plugin settings or into a property inside the note, saving the times of all notes at once, and a restore popup that selects which changed notes to restore or to re-save. Settings cover confirmation prompts, excluded path prefixes that the bulk operations skip while the current-note commands ignore exclusions, and optional automatic updates once a day or when the plugin loads.
