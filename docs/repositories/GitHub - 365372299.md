# rudimuc/obsidian-qrcode

The repository holds a QR Code Generator plugin for Obsidian that renders QR codes inside notes. Its README records that the codes are produced with the node-qrcode library and that the feature is invoked through a qrcode code block. Installation from the community plugin browser is documented alongside a developer route that clones the repository and follows the official sample plugin instructions; the code is licensed under MIT.
