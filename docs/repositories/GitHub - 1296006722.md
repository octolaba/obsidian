# tinkerdragon/ContextOS

The repository holds ContextOS, an Obsidian plugin that builds a structured wiki out of raw source notes so knowledge accumulates instead of being re-derived on every query. It scans a configured source folder for Markdown, plain text, delimited data, code, HTML, PDF, image, Office and RTF files, extracts their text, falls back to vision OCR for scanned PDF pages, image-only slides and images, and detects changes by modification time, size and content hash so unchanged sources are skipped. The README states that OCR of PDF pages runs concurrently with configurable parallelism, that only new or changed files are sent to a chat completions endpoint, that text, chat and vision work can be routed to separate providers including OpenAI, Anthropic, Gemini, DeepSeek, Groq, Ollama and compatible endpoints, and that ingestion can be triggered automatically by file events.
