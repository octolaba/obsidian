# mProjectsCode/obsidian-lemons-search-plugin

Lemons Search is described as a fuzzy-finder quick switcher with preview. Its README says the switcher searches every file in the vault and previews the selected result, and that the matching is written in Rust using the nucleo-matcher crate and run in a web worker so that most of the work happens off the main thread. Three commands are provided: a search over file paths, an alias search over file names and aliases, and a command palette. A query is made of space-separated atoms, escapable with a backslash, and each atom can be marked as substring, prefix, postfix or exact match, with any of those forms negatable.
