# mamadaevv/card-columns

This repository holds Columns, a kanban-style card view for Obsidian that groups notes into columns by tags or by any frontmatter property. It is built on the Obsidian BasesView framework, so the sort, filter, properties and search toolbar are native, and a view is created by opening a base file and selecting Columns in the view switcher. Cards can be arranged in a grid of one to six per column or in a masonry layout, columns can be zebra-striped, and clicking a card opens it in a right or bottom split pane while Ctrl-click opens a new tab. Tags can be clicked to filter across columns with AND or OR semantics, and note properties appear as chips covering text, tags, links, booleans and dates with configurable date formatting.
