# Jefrry/obsidian-typing-cat

Typing Cat places a cat overlay on the Obsidian window that animates while you type and reports your typing speed. The README states that speed can be shown as words per minute, characters per minute or characters per second, that the cat sweats during intense typing and shows a heart when clicked, and that position, size, opacity, mirroring and the speed display are all configurable. It describes the overlay as designed to sit on screen without interfering with editing.
