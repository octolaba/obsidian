# Accsimplify/obsidian-copy-contents

The repository holds Copy Contents, an Obsidian plugin that copies or exports the contents of a file or a folder as Markdown, plain text or JSON. Actions run from the file menu or the command palette, keep nested folder paths when combining files, and filter by extension and maximum file size. The README states that the plugin works locally, makes no network requests, and writes to the clipboard only when a copy action is chosen, offering export actions for cases where clipboard use is unwanted.
