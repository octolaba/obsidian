# qgrail/obsidian-ai-assistant

This plugin lets Obsidian notes interact with AI models: text through OpenAI GPT and Anthropic Claude models, image generation through DALL-E 2 and 3, and speech to text through Whisper. The text assistant has a chat mode, where a single interaction or the whole conversation can be copied to the clipboard, and a prompt mode that feeds a selected piece of the note to the model. The README records image upload in chat mode for vision-capable models and lists Claude 4 and the OpenAI o3 and o4 series as recently added.
