# forever-utf8/obsidian-act-like-vscode

Obsidian plugin that makes the desktop app behave more like VS Code. Tabs follow the VS Code convention in which a single click previews a file and a double click pins it. The file explorer colours entries by an archive tag, showing unarchived notes and folders that still hold them in green and fully archived ones in grey, accepting aliases such as `#done`, and it also shows a note's tags as badges and draws a restrained set of file and folder icons. Settings toggle the icons and give each tag one colour, a personal CSS snippet is included without theme-compatibility testing, and desktop Obsidian 1.8.9 or newer is required.
