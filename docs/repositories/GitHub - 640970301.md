# Neolex-Security/obsidian-hackerone

This unofficial plugin links HackerOne reports into an Obsidian vault. A HackerOne username and API token are set in the plugin settings, after which the fetch HackerOne Reports command retrieves the report data. The README states that the Dataview plugin is needed for the summaries to work.
