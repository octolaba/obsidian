# DylanHojnoski/obsidian-graphs

This plugin renders interactive graphs in Obsidian from a code block whose language is set to graph, with a body giving the bounds and a list of elements. Built-in element types cover lines, circles, function graphs, derivatives, vector fields, sliders, Riemann sums and text, and complex mathematical functions are supported. Graphs are interactable, can be three-dimensional, follow the Obsidian theme, are syntax highlighted, and can be exported as SVG through the Export graphs command in read mode.
