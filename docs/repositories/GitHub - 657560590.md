# Southpaw1496/obsidian-send-to-ghost

Send to Ghost sends an Obsidian note to a Ghost blog as either a published or a draft post, and the README describes it as a maintained fork of an earlier obsidian-ghost-publish plugin. Authentication uses either a Staff Access Token or an Admin API Key, entered along with the site URL in the plugin settings, and a note is then sent from a ribbon icon or a command. The README recommends the Staff Access Token because Obsidian plugins cannot store sensitive information securely and a token's access is limited to its staff member's permissions, while noting that tokens belonging to administrators or owners carry the same access as an Admin API Key.
