# 0xneobyte/VaultAI

VaultAI is a writing assistant for Obsidian built on Google's Gemini API. It offers retrieval-augmented generation over the whole vault through the Gemini File Search API, answering questions from the notes with citations, and inserts responses directly at the cursor with awareness of the surrounding context. Model behaviour is tuned through temperature, top-K, top-P and token limits, reusable custom prompts carry placeholders for repeated workflows, and every feature is reachable by hotkey or from the command palette in a resizable chat interface with a full-page mode. The README states that the API key and the chat history stay local in the vault, and that a Gemini API key from Google AI Studio is needed to start.
