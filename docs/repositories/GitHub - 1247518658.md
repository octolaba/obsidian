# desmondwen/obsidian-antigravity-cli-sidebar

Obsidian plugin that embeds the Antigravity CLI in a sidebar pane as an xterm.js terminal with full typing, scrolling and resizing, and a configurable command and arguments. It is desktop-only because it uses Node's child_process, and it requires the `agy` command on the system PATH plus Python 3 for its pseudo-terminal wrapper. The repository description names Gemini CLI, while the README records that version 2.0 migrated to Antigravity CLI because Google is retiring the older tool, and that existing settings are migrated automatically.
