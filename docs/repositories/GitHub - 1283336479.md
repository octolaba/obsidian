# Rayvven/obsidian-pin-board

Pin Board points at a folder in the vault and shows every image and short video inside it as a vertical, scrollable masonry feed rather than spreading them across a canvas. A note can optionally be attached to any pin, and the folder shown is switched from a dropdown or by clicking a folder in the file explorer. The README recommends pinning the board's own tab, because otherwise clicking a picture replaces the board with that single image, and it records Obsidian 1.4.0 as the minimum version.
