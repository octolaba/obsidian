# hanakin/miami-wind-obsidian-theme

hanakin/miami-wind-obsidian-theme is an Obsidian theme built on the Miami Wind colour scheme, which the README describes as a blend of Tailwind CSS colours with the greyscale ramp of Catppuccin Mocha. It names the Miami Nights theme for Monkeytype as its inspiration, and documents the base, bright, text, overlay, surface and background palettes as swatch links.
