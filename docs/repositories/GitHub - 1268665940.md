# hata-suriiken/obsidian-ctrl-scroll-zoom

The repository holds Ctrl+Scroll Zoom, an Obsidian plugin that zooms the application with the control key and the mouse wheel, upward to zoom in and downward to zoom out, and also responds to trackpad pinch gestures because the platform reports them as the same event. A setting chooses between scaling the whole window through Electron's page zoom, including the interface, and scaling only the note content, which stays anchored to the mouse pointer while the ribbon, sidebars and tab bar keep their size. The README states that each notch scales by a constant ratio so the steps feel even at any level, that pinch deltas scale proportionally, that pop-out windows are covered, and that Canvas and Excalidraw keep their own zoom unless that is turned off.
