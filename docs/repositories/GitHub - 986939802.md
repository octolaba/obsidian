# penyt/replace-pencil

Replace Pencil substitutes custom variables inside a code block. Anything wrapped in the configured placeholder markers — angle brackets by default, with the prefix changeable in the settings — becomes an input slot in reading mode, and typing into it replaces the placeholder in the displayed block; a clear button and an eraser button in the left sidebar reset one block or everything at once. A copy button beside the code block writes the substituted text to the system clipboard. The README states that clipboard access happens only on that button and that the plugin does not read clipboard contents.
