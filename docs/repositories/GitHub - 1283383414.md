# aucontraire/insightmesh-obsidian

InsightMesh Viewer is a read-only plugin that displays the provenance behind wiki pages produced by insightmesh-core, showing which conversations and checkpoints made a page and the decisions behind each edit. For the active page it summarises the latest action, confidence, total edits and contributing exchanges, flags drift when the summary diverges from the latest checkpoint, and lists every checkpoint that touched the page in time order. Checkpoint detail renders each editor decision and its rationale as Markdown beside confidence, action, signals, a provider label and the models used, and a unified diff compares the two most recent recorded versions of a page. The README states that the plugin never writes, makes no network requests, needs Obsidian desktop 1.7.2 or later and a git binary used read-only, and shows nothing without an InsightMesh history in the vault.
