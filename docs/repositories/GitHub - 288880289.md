# liamcain/obsidian-calendar-plugin

A calendar view for visualizing and navigating daily notes, shown in the right sidebar once the plugin is enabled. The README states that it reads the vault's Daily Note settings for the date format, the template and the location of new notes, so it can open an existing daily note or create one for a day that has none, including past and future days. Each day carries a meter of dots approximating how much was written that day, with a configurable words-per-dot value and a maximum of five dots, and weekly notes are supported as a further layer with their own options. Settings cover the first day of the week and whether creating a note asks for confirmation.
