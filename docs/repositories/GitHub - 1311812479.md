# yueyinfeng/filename-checker

Finds duplicate Markdown filenames within configured folders after stripping a filename prefix, which is aimed at vaults whose notes carry IDs or serial numbers but should still be compared by their readable names. Each configured folder pairs a vault-relative path with a wildcard pattern removed before comparison, and only direct Markdown files of the selected folder are compared. Two commands check the active note's folder or a folder picked from the configuration, and the result is written as a Markdown report that is opened automatically. No repository description is recorded, so this note is grounded in the README alone.
