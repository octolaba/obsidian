# UnbrokenHunter/obsidian-text-hider-plugin

Text Hider visually masks the content of an Obsidian note while it is being edited or read, so it can be worked on in public without being legible to bystanders. Privacy mode is toggled from the command palette, a hotkey or a status-bar indicator, and offers three masking styles: hiding the text while keeping the layout, blurring it, or replacing it with password-style bullets. Text around each cursor can be revealed by characters, words, sentences or lines with a configurable amount, the selection can optionally be revealed, and the inline title, headers, callouts and images can each be ignored, masked or hidden. The README states that masking is visual and does not change the underlying Markdown files, and records an optional screen tint.
