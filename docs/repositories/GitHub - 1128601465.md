# pochihh/obsidian-simple-progress-bar

Repository for Simple Progress Bar, a plugin that visualises checkbox completion. The README describes a bar in the note header covering every checkbox in the note and updating as tasks are ticked, and embedded section bars inserted as a code block that count only the checkboxes under the same heading. A command inserts a section bar and uses any selected text as its label, and a setting turns the header bar off.
