# chenzhekl/obsidian_paper_importer

Paper Importer brings papers from arXiv into a vault, with one command importing both the metadata and the PDF and another importing the metadata only. An arXiv identifier or URL is entered in a popup, and the results are saved to the folders configured in the plugin settings. Notes are written from a customisable external template file whose variables cover the paper identifier, title, authors, date, abstract, comments and a link to the downloaded PDF, and the settings can generate a file holding the default template.
