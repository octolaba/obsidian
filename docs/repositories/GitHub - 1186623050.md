# 2brn/Epochgram

Epochgram builds an interactive timeline of a vault's notes in a sidebar, letting them be browsed day by day, filtered, searched and edited directly on the timeline. The README states that clicking a record opens its file and clicking a date opens the daily note, and it documents filters, actions, a review state and custom YAML. A separate Pro tier is described as adding on-device or cloud AI summaries through an AI bridge, zoomable Epochs from daily detail to a year overview, related-note discovery by links, tags, titles and semantic similarity, topic clustering, tracked content edits, calendar sync and recurring events.
