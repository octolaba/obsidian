# gjtorikian/semoi-obsidian

Semoi captures keystroke evidence while a note is written and mints a cryptographic certificate of that writing session through an external service, stamping the proof into the note's frontmatter and returning a public verification address. The README states that the plugin watches the editor's change stream and records each edit as an insert, delete or replace with a character count and a relative timestamp, and that it does not record the characters typed, only the shape of the editing activity. Minting finalises the session, sends the event stream, the current note content and client information to the backend, writes the signed proof reference into frontmatter and opens the verification page. A session is a stretch of editing in one file held in memory until it is minted or reset, tracking both wall-clock bounds and accumulated active typing time, and surviving a rename of the file.
