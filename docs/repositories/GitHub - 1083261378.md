# akhmialeuski/obsidian-citation-extended

Obsidian plugin that connects an academic reference manager to the editor, letting references be searched and literature notes created for papers and books. The README states support for BibTeX and BibLaTeX files, CSL-JSON, Hayagriva YAML, the Readwise API, and a running Zotero through either the Better BibTeX pull-export endpoint or Zotero's own local API. Listed features include opening or creating a literature note, inserting links, rendered template content or Pandoc-style citations, an inline citation autocomplete, and a sidebar listing every reference cited in the active note.
