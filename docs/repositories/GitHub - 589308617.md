# luigman/obsidian-vextab

This plugin renders guitar tablature and music notation in Obsidian using VexTab. The README quotes VexTab's creators describing it as a language for creating, editing and sharing standard notation and guitar tablature that, unlike ASCII tab, is designed for writeability rather than readability. Installation is documented three ways: through the Obsidian community plugins browser, by unzipping a release archive into the plugins directory inside the vault, or by cloning the repository there and running its deploy script.
