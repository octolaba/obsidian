# ivan-lednev/obsidian-automatic-changelog

This plugin renders Git diff output inside Obsidian notes through code blocks tagged with the show-diff language. An empty block shows the diff between today and yesterday, while a dates key limits it to a date range and a commits key to a commit range; a path key points the plugin at any repository on the filesystem instead of the vault, and an exclude key takes one path or a list, with Obsidian's own settings and cache folder excluded by default. A command inserts a block already filled in for today. The README states that the vault must be a Git repository for the default behaviour to work and that the author uses it together with obsidian-git as an automatic changelog.
