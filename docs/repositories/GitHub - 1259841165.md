# noe-av/folder-color

Folder Color colours the Obsidian file explorer without CSS edits: a folder is given a start and an end colour from its right-click Assign color entry, and the gradient between them is applied automatically across subfolders by depth. Files inside a coloured folder take the colour of their direct parent, and a file can also be coloured individually, in which case a single colour is used rather than a gradient. Non-Markdown files such as PDF, Canvas and Excalidraw are drawn as a split pill carrying a file-extension badge. The settings tab exports all folder and file colours and presets to a JSON file, imports one back, and lists saved presets for deletion.
