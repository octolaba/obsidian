# GsLogiMaker/my-bible-obsidian-plugin

My Bible sets up a folder structure in the vault with one note per chapter and fills those chapters with verse text as they are read, so verses can be linked from other notes and the connections show up in the graph view. The chapter notes do not hold the text themselves, which lets a translation be switched without duplicating the Bible or breaking links, and translations can be read from the server or downloaded to the local device. Folders, names, verses and links are all customizable. The README states that the plugin makes requests to the bolls.life API to download the text and metadata for translations, books and chapters.
