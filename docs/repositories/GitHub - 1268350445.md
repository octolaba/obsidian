# Cesditarllas/STS-indentation

STS-indentation indents headings and the blocks below them according to their heading ancestry, treating the first heading in a note as depth zero whatever its level, and covers lists, tasks, code blocks, images, quotes, tables, math, callouts and embeds. It draws one guide line per parent heading, optionally coloured from that heading, and can keep the native fold arrows visible on their guide lines. The README records a master indentation toggle alongside settings for guides, arrows, colour and width, support for Live Preview, Source mode and Reading view, and operation on desktop and mobile including Android touch targets.
