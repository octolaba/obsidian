# RobertttBS/obsidian-enhanced-canvas

Obsidian plugin that links Canvas boards and notes through note properties. Adding a note to a canvas writes a canvas property carrying a link back to the canvas file, drawing an edge writes a link to the target note under a property named after the canvas file, and clicking a canvas link from a note focuses the corresponding node. Further commands split a text node into a hierarchy of nodes by its headings, send the current note to a chosen or previously selected canvas, and auto-resize a node's height to its text after a double-click on its bottom edge.
