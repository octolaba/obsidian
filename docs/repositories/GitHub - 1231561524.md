# nitinvishway/Inline-AI

This repository holds Inline AI, an Obsidian plugin where typing a slash-ai command followed by a prompt and pressing Enter streams a model response directly into the note, replacing the trigger line. The recorded description names a local Ollama model as the responder, while the README's provider table also offers OpenAI, Claude and Gemini, marking Ollama as the local and free option and the others as hosted services with a cost or a free tier. It presents the plugin as a way to generate text, brainstorm, summarize and refactor without leaving the note.
