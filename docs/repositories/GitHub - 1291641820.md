# israerusan/vault-router

Vault Router moves an inbox note to the folder its rules say it belongs in, with three operations: routing the current note, previewing where a note will land before it moves, and sweeping every matching note in the inbox in one pass. Rules match locally on title prefix, path substring, a required tag, and a frontmatter property that either exists or equals a value, with all filled conditions required and the first matching rule deciding the destination. Destination folders are built from the note itself through placeholders for a frontmatter key, the basename, the filename and the extension. The README states there is no AI and no cloud, and splits the feature set between a free tier capped at five active rules and a one-time, offline-verified Pro unlock that lifts the limits and files new notes automatically.
