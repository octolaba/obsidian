# jiang198012/ogenda

Obsidian plugin that adds a calendar and agenda panel, keeping events in local Markdown notes while syncing them both ways with a CalDAV server or iCloud. It offers month and list views, all-day and multi-day events shown on every day they span, and settings for the storage folder, the account credentials and the calendar to write to, including a button that fetches the available iCloud calendars into a dropdown. The changelog records that only real event calendars are offered, because iCloud reports reminder lists as calendars too, that the panel refreshes when a sync finishes so a version the server has replaced cannot be edited, and that a stalled request fails after a timeout instead of hanging the sync. The README requires a minimum Obsidian version, supports desktop and mobile, and needs a reachable CalDAV endpoint.
