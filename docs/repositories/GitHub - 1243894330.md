# DejanDj79/vault-palette

Vault Palette customises folder, file and tag colours in Obsidian through a file-explorer context menu and a settings panel. The README lists optional background, border and text colours, bold, italic and opacity, folder text styling kept separate from the styling applied to files inside that folder, folder styles optionally applied to subfolders, a separate file text style for files inside a folder, and stable rainbow colours for file names within a styled folder. Presets save the whole style package and behave differently when applied to a folder or directly to a file, and a tags tab detects tags from Obsidian's metadata cache and offers one shared text colour with a per-tag background. Settings can be imported and exported, and the README names an earlier colour-folders plugin as the inspiration.
