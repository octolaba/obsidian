# kausthub-kannan/poneglyph

Poneglyph is a research-oriented plugin in which a local research agent expands each Markdown node of an Obsidian graph into a cited artifact, with nodes connected relationally, tagged by lifecycle status and topic, and anchored to a vault-wide citation ledger in SOURCES.md. It needs no external vector database, running the Vectra vector store inside the plugin, and requires only an LLM and an embedding provider. Its README carries an explicit disclaimer that generated nodes may contain hallucinated citations, outdated information or shallow treatment, that human verification is part of the design, and that the tool is meant to accelerate research mapping rather than replace reading primary sources.
