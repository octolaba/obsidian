# mkshp-dev/obsidian-gallery-plugin

Renders image galleries from obs-gallery code blocks written as a sources and view schema, loading images from vault folders, external URLs, Immich shared links or authenticated Immich albums. Views include responsive thumbnail grids with click-to-expand modal viewing, lazy loading for large collections and fallbacks for missing paths. JPEG, PNG, GIF and WebP are the supported formats, the older flat path syntax still parses for compatibility, and a command generates demo notes in the vault that show the configuration syntax.
