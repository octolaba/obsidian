# readwiseio/obsidian-readwise

The official Readwise plugin, maintained by the Readwise team, exports digital highlights into an Obsidian vault from the sources Readwise aggregates, among them Amazon Kindle, Apple Books, Google Play Books, Instapaper, Pocket, Medium, Twitter and PDFs. After the plugin is connected to a Readwise account and the export settings are adjusted, the first sync is initiated and later syncs can run automatically or be triggered manually. The export format is customised with Jinja2 templates and can carry additional metadata such as the cover image, original URL, author name, chapter headings and tags taken while reading. The README states that the plugin requires a subscription to Readwise, which is a paid service.
