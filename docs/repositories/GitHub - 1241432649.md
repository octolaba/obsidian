# sotetsuk/obsidian-marp-inline-preview-plugin

Renders Marp slide decks inside Obsidian: in edit and Live Preview a rendered slide widget appears beneath each slide separator and updates as the text is typed with a configurable debounce, while reading mode replaces the page with the whole rendered deck. Only files whose frontmatter sets marp to true are touched, and everything else renders as ordinary Markdown. The README records Marp Core 4 in pure JavaScript so the plugin also runs on Obsidian for iOS and Android, custom themes declared in a .marprc.yml at the vault root or beside the slide file and read through the Obsidian vault API, bundled KaTeX math that needs no network round-trip, and per-slide CSS mounted in Shadow DOM so it cannot leak into Obsidian's own interface.
