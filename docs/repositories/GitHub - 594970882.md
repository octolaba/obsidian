# HeekangPark/obsidian-hk-code-block

HK Code Block extends how code blocks look in Obsidian's reading view. Options written on the fence give a block a quoted title, a collapsed or explicitly expanded state, line numbers starting from a configured or given value, highlighted lines and ranges, and a language indicator that can be stated independently of the language used for syntax highlighting. The README records that the plugin was inspired by a Prism.js plugin and by the Better Code Block and Code Block Enhancer plugins.
