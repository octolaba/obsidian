# manemajef/obsidian-explorer

Explorer renders a folder as a navigable overview inside Obsidian's main editor pane, so notes and subfolders can be browsed, created, moved, renamed, pinned and searched from the same place they are read. The README describes card and list views with per-block controls, note previews, drag-and-drop moves on desktop, an action bar with a back button and a settings menu for sorting and visibility rules, and folder overviews opened from a homepage or from a folder name in the sidebar. Overviews work either without a file or through Markdown folder notes sharing the folder's name, which can be created from edit mode and optionally hidden from the sidebar file tree.
