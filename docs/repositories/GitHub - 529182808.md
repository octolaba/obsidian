# OlegLustenko/obsidian-bulk-rename

Obsidian plugin for renaming a group of files from a directory at once, with references across the vault updated as well; the README notes that it applies the Obsidian renaming API to many files. Files are selected by folder location, by tags entered with a comma separator, or by a regular expression with flags such as global, ignore case and multiline. In each case an existing-characters pattern and replacement symbols define the new path, so setting a different directory location in the replacement moves the files as well as renaming them.
