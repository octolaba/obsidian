# CMorooney/obsidian-game-search-plugin

Creates game notes from a title search against the RAWG game API, using a configured note location, filename format and template file. An optional Steam sync imports the owned library and wishlist through a Steam API key and user id, injects per-list metadata and adds a steamId property to each synced note, which the README asks users not to remove. The README records the project as a fork of a book search plugin and recommends pairing it with Templater so note content can be generated from the template variables it supplies.
