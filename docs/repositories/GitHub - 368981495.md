# shaggyfeng/obsidian-Golden-Topaz-theme

Golden Topaz is a theme for Obsidian that its README describes as aimed at reading, thinking and writing. The README records that it began as a set of snippets layered on the Blue Topaz theme, and that its colours were collected from photos and websites. Its change log lists syntax highlighting colours for twenty major coding languages, improved tag and table highlight colours, and graph and outline hover effects.
