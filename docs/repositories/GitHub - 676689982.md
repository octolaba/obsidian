# mwoz123/speech-to-text-keyboard-helper

Speech To Text Keyboard Helper adds new-line commands for dictation, because the Google speech-to-text Android keyboard does not handle the spoken new-line command itself. Two commands are recorded: appending a new line and jumping to it, and prepending a new line and jumping to it; both are reachable from the command palette and from there can be added to the mobile buttons toolbar. The README states plainly that this plugin does not provide a speech-to-text service of its own.
