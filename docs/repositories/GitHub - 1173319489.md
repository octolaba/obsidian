# Rajdeep31/Numbered-Folder-Creator

Numbered Folder Creator gives files and folders created inside an existing directory the next available sequential number prefix, leaving file extensions unchanged. A separate command applies the numbering retroactively, scanning subfolders and prefixing items that do not already carry a number. Items already starting with a number, placeholder names such as an untitled file, and anything created in the vault root are left alone.
