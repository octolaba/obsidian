# ibrh96-prog/obsidian-emotional-time-capsule

Obsidian plugin for writing an emotionally charged note and revisiting it after a chosen interval. A capsule is written from one of several prompts, then sealed so that only a title, its dates and a short message are shown until its revisit date, with an explicit option to open it early, and revisit intervals range from seven days to a year or a custom date. A dashboard groups capsules into ready to revisit, sealed, unsealed, undated and archived, and capsules can be postponed, archived or deleted. The README states that it works inside the local vault and is not a therapy, diagnosis or coaching tool.
