# fengshuzi/coin-memo

Obsidian plugin that tracks daily expenses by parsing accounting records out of daily notes. The README lists income and expense summaries, category breakdowns from a custom keyword-to-category mapping, date-range filtering, copying a past record to today, batch reclassification by note keyword, and export to PDF or Markdown. Bills can also be imported from a screenshot, whose OCR text is written to a bill note and parsed into records.
