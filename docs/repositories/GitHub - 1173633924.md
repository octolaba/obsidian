# janacm/cleanshot-embed-obsidian

Obsidian plugin that renders CleanShot share URLs as inline images in reading view. The README explains that such a URL points at a landing page rather than a direct image and that the direct signed URL expires, so the plugin fetches a fresh signed URL at render time through the Obsidian requestUrl API and stores no files in the vault. It describes a markdown post-processor that replaces the links, an in-memory cache cleared on plugin unload, and a fallback that shows the original URL as a clickable link when the fetch fails.
