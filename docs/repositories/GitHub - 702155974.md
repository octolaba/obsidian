# kelvinc6/auto-reading-mode

Obsidian plugin that switches Markdown pages out of Live Preview or source mode into Reading view after a period of time. The timeout in minutes is configured in the plugin settings, and its timer runs while Obsidian is active or minimized. A second setting opens previously opened documents in Reading view when Obsidian starts.
