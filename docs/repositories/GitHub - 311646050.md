# esm7/obsidian-rtl

The repository holds the Obsidian RTL plugin, which extends the right-to-left support built into Obsidian rather than replacing it. Its README states that Obsidian's own RTL support has been reasonable since version 1.6, and lists what the plugin adds: setting an individual note to LTR or RTL instead of the per-line automatic direction, remembering that setting per note, reading it from the note's front matter, and choosing a default direction while leaving individual notes on automatic. A switch text direction command is exposed for a hotkey, and a status bar item toggles the same setting.
