# Nossimonov/obsidian-chartdown

Renders Chartdown map blocks as SVG inside Obsidian notes, so TTRPG battlemaps, hex charts and region maps are written as plain text in a chartdown fence and drawn in place on the local machine. The README describes a GM and player split it calls fail-closed, where hidden tokens, GM notes and triggers render only in GM view, with a per-map toolbar toggle and a default in the settings. It documents exporting a map as SVG beside the note, and exporting UVTT files per map level with walls, doors, windows and lights for VTT import, noting those files are not listed in Obsidian's own file explorer because of their extension. Standalone map files open directly to their rendered map.
