# jsmorabito/obsidian-text-formatting-toolbar

Text Formatting Toolbar shows a floating toolbar above the current selection in the Obsidian editor, giving one-click access to common formatting actions. The README lists setting a heading level from one to six or paragraph, bold, italic, strikethrough and highlight, wrapping the selection in a Markdown link, a wikilink, inline code, a code block, an Obsidian comment or a blockquote, converting it to a bullet, numbered or checkbox list, and copying or cutting it. Individual buttons can be shown or hidden in the plugin settings. On permissions, the README states that copy and cut write the selected editor text to the system clipboard and that the plugin never reads from it.
