# ckelsoe/obsidian-linked-attachments

The repository records no description; its README presents Linked Attachments, an Obsidian plugin that offloads large, cold files such as PDFs, audio, video and archives to an S3-compatible bucket or a local folder and leaves a pointer note in the vault in their place. The pointer note is plain Markdown whose frontmatter records the bucket, key and path, so the README states a file remains recoverable even with the plugin uninstalled, and the original is removed only after the copy is verified byte for byte. From the pointer note a file can be opened, revealed, or pulled back into the vault on demand.
