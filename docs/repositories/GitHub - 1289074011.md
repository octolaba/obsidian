# pilafdob/Nicons

This repository holds Nicons, an Obsidian plugin for customizing icons across the Obsidian interface; the repository records no description, so this summary follows the README alone. It is described as a standalone plugin built on Iconic's icon-management foundation, with Phosphor Icons bundled as the default pack in regular, thin, light, bold, duotone and fill styles, embedded into the build so they work on desktop, Android and iOS, while an SVG pack stored in the vault or an emoji can be chosen instead. Custom icons and colours can be set for files, folders, tabs, ribbon actions, tags, properties and bookmarks through a Change icon entry in the context menu, icon search understands semantic aliases, default icons cover common file types, and tab icons stay matched to the current file's icon.
