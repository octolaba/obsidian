# saibotsivad/obsidian-gtd-no-next-step

This plugin supports a GTD workflow by badging project files that have no defined next step: a project whose tasks include none tagged as the next actionable gets a red badge, one waiting on an external trigger gets a gray badge, and all other files display as normal. The folder holding project files, the next-step tag and the waiting-for tag are configurable and default to `Projects/`, `#next-step` and `#waiting-for`, with sub-folders included. The README sets out the author's own workflow, in which those tags are attached to tasks with the Tasks plugin and queried from various views.
