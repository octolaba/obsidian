# edrickleong/obsidian-calendar-bases

This repository holds Calendar Bases, an Obsidian plugin that adds a calendar layout to Obsidian Bases so notes carrying dates appear in an interactive calendar view, built on FullCalendar. Entries matching the view's filters are placed on their dates from a configured start-date property, an optional end date produces multi-day events, and dragging an event to another day rewrites the note's frontmatter. Months are navigated with on-screen controls and entries can be opened or acted on through a context menu. The README states that the plugin requires Obsidian v1.10.0 or later.
