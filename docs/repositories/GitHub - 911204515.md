# nemariia/task-mover

Task Mover locates unfinished tasks across the notes of an Obsidian vault and consolidates them into a single daily note, grouped by their original file or by topic. The README records settings for the folder to scan, the daily notes folder and whether the originals are deleted after moving, and a command that runs the consolidation. Tasks may be plain checkbox lines or wrapped in a marked task block that carries surrounding context, in which case blocks sharing a heading across notes are combined into one, and the README warns that the delete setting removes the unfinished tasks from their source notes.
