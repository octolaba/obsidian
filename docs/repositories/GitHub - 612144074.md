# waiting0324/obsidian-code-note

Source Code Note helps organize notes about source code by parsing the code blocks in a note, drawing a graph of the method call links between them, and keeping the code blocks themselves on the canvas for reading. The relationships are declared as keywords in the code comments: one naming the class a method belongs to, one naming the method, and one naming the methods it calls, written as a class name and a method name and repeatable for several calls. The graph drawing is credited to the AntV X6 library.
