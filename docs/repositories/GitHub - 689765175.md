# Nexus-JPF/note-companion

An assistant that transcribes audio, video and YouTube material, answers questions with the vault as context using mentions of files, folders and tags, and proposes folders, tags, titles and templates for unsorted notes, with optional automation of an inbox folder. A meeting recorder produces a transcript, discussion points, action items and an embedded recording. The README states that it works against a hosted backend or a self-hosted one where the user configures provider keys, and lists OpenAI, Claude, Gemini, Groq and local models among the providers. It records that the project was formerly called File Organizer 2000.
