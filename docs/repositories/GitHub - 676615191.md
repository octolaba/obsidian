# Pentchaff/obsidian-search-library

This repository holds the Obsidian Search Library plugin, which stores search queries so they can be reused rather than retyped, and shows results in both the search view and the graph view. The README records three modes of use: a free search, a template-enabled search, and graph view integration for visualizing the result. It states that the plugin relies on the QuickAdd plugin being installed and set up beforehand, and names Vantage as a complementary search builder.
