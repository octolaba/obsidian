# Matse2005/obsidian-easy-codeblock

Easy Codeblock inserts fenced code blocks in Obsidian without typing backticks or a language name. The README describes a searchable picker over more than 200 languages that pins the five most recently used ones to the top and matches both names and codes, bound to Alt+L, and a plain block with no language bound to Alt+P. Selected text is wrapped by the inserted block, and the commands are also available from the command palette.
