# Requiae/obsidian-leaflet-bases-plugin

Obsidian plugin that adds an interactive map view to Obsidian bases: a Leaflet Map view type plus a new marker property type. Marker data lives in the note it belongs to rather than in the map, which is one of the stated reasons for the design, alongside leveraging bases and making the maps publishable through a companion Quartz plugin. A map can be configured from the base's view settings or embedded as a base code block whose keys set the map name, background image, height, zoom bounds and default, zoom step, scale and unit.
