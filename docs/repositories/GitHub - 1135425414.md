# devxoul/obsidian-autolinks

An Obsidian plugin that turns text matching user-defined regular expressions into clickable links, described in its README as similar to GitHub's autolink feature but with full regex support. A rule pairs a pattern with a URL template that can reference capture groups $1 to $9, can be enabled or disabled individually, and takes effect without a restart. Rendering covers both Reading View and Live Preview, and the plugin skips code blocks, inline code, existing links, wikilinks and frontmatter, resolving overlaps on a first-match-wins basis.
