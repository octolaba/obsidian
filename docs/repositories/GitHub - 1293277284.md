# MiLin-Jad/Open-Obsidian-Funds

Open Manage is a full-window management suite combining project execution, future planning, personal funds, image workflows and Markdown mind maps in one plugin, with modules for an overview, project progress, planning, finances and settings. Business data is kept in a configurable folder inside the vault as Markdown files holding a readable heading and a fenced JSON payload, so it travels with normal vault sync and backup tools, while the plugin's own data file stores interface and feature settings only. Changing the data folder copies the current database to the new location and switches to it without deleting the old folder, and version 3.1.0 supports migrating data from the earlier Manage plugin.
