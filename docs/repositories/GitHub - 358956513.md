# zsviczian/obsidian-excalidraw-plugin

The repository integrates the Excalidraw sketching tool into Obsidian, storing and editing Excalidraw files inside the vault and embedding drawings into documents. Its README also points at a separate community wiki and at a Simplified Chinese translation.
