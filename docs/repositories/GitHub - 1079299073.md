# edrickleong/obsidian-feed-bases

Feed Bases adds a feed layout to Obsidian Bases, rendering the notes of a base as a scrollable feed that shows each note's content instead of a table row. Notes stay editable inside the feed and edits are saved back to the source file automatically, titles can be clicked to open a note, and context menus offer further options. Sorting is by modified date, created date, or name, which is the default; the README states the plugin requires Obsidian 1.10.0 or later and, at the time of writing, was still under community review and installable through BRAT.
