# wonkwonlee/gotsaeng-os

GotSaeng OS is a local-first Markdown context compiler, distributed as a command-line tool and a desktop-only Obsidian adapter. The README records scanning a Markdown vault recursively, parsing YAML frontmatter, classifying notes into project, decision, research, weekly review, chat export, template and unknown types, and extracting facts, decisions, actions, risks, assumptions, questions, insights and stale context into Markdown and JSON artifacts with coverage statistics. Further recorded capabilities are a deterministic diff between compile manifests, provenance and confidence scores derived from local signals only, and contradiction candidates offered as a review queue rather than a semantic engine. The Obsidian side is recorded as a Report Hub view, a hidden output folder and vault commands calling the same compiler, with no cloud, telemetry or model calls.
