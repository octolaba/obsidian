# abrahambahez/Brutalism

Brutalism is an Obsidian theme following the web brutalist approach, written by its author for personal needs around the idea that the words are the raw material and that less CSS is always better. It deliberately leaves room for Obsidian's own configuration, such as the accent colour and font selection, and adds a gradient and fluid typography treatment for the inline title. The README recommends separate interface, writing and code fonts rather than bundling any, and ships a focus snippet that hides the scrollbar, status bar, sidebar and sidebar toggle icons for keyboard-only use. It also suggests setting source mode as the default editing mode so that the markup itself stays visible.
