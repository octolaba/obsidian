# obsidianmd/obsidian-importer

The repository holds Obsidian Importer, the official plugin for converting notes from other applications and file formats into plain-text Markdown files in a vault. Its README lists guides for importing from Airtable, Apple Notes, Bear, CSV files, Evernote, Google Keep, Microsoft OneNote, Notion and Roam Research among others, all hosted on the official Obsidian help site rather than in the repository. It records installation through the community plugins directory and is licensed under MIT.
