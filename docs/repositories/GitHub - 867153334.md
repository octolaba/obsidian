# NilsLeo/obsidian-youtube-iframe-timestamps

This plugin embeds YouTube videos with clickable timestamps inside a note, so a video can be referenced and annotated without opening a separate browser window; clicking a timestamped link jumps the embedded player to that point. The README records a limitation: the iframes only appear in Reading view when the editing mode is set to Source mode, which can be toggled per session from the command palette or made the default in the editor settings. Usage requires a note carrying timestamped YouTube links together with an empty container element bearing a fixed id, which acts as the host for the embedded player.
