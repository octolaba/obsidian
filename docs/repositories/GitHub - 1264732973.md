# jaewonE/heading-autolink

Heading Autolink is an Obsidian plugin that inserts heading wikilinks and keeps them consistent as headings change. The README records typing a hash sign after a file or heading wikilink to open a picker that inserts a link in the form of a note, heading and alias, optionally with the heading's descendants, and a keystroke that inserts the picker's search text as a file alias when no heading matches. It also records adding aliases to alias-free heading wikilinks once the cursor leaves the line, updating matching heading links across the vault after a heading is renamed, and preserving custom aliases that do not match the old heading text. The README lists which link forms are supported and states that fenced code blocks, inline code, YAML frontmatter and HTML comments are ignored by default.
