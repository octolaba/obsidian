# Abdulkader-Safi/obsidian-crm-plugins

CRM keeps client, deal and project records as plain Markdown notes inside the vault, with no cloud account involved. It provides a dashboard with a deal pipeline funnel, follow-ups due this week, a revenue snapshot and active projects, a board on which deals are dragged between lead, proposal, negotiating, won and lost stages, and filtered lists with a detail page for each client, deal and project. Interactions and tasks are logged inside each note, project progress is calculated from the tasks ticked off, and a won deal can be turned into a linked project in one click. The README states that the interface follows the installed theme and that the plugin works offline, touching only notes in the folder chosen for it.
