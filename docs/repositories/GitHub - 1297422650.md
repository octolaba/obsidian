# yanqingwang/obsidian-html-to-md-effect

Converts HTML files in the vault to Markdown, either the open file alone or every HTML file in the current folder. The conversion covers headings, bold, italic and strikethrough, inline code and fenced code with the language preserved, links, images, nested ordered and unordered lists, pipe tables, blockquotes and horizontal rules. Optional YAML frontmatter carries title and source metadata, and existing Markdown files can be skipped rather than overwritten.
