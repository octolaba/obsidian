# peter70700/vaultguard-obsidian

The repository holds VaultGuard Sync, an Obsidian client for permission-aware encrypted sync, published as a flat release mirror of a plugin whose canonical source sits in a packages directory of the same project. Its README records client-side AES-256-GCM encryption of supported file bodies before upload and local at-rest encryption under a per-device key, while stating that the current service uses server-managed keys backed by a KMS, so the backend is inside the trust boundary and the design is not zero knowledge. AI chat, a permissions graph and external agent access are described as optional modules that stay off until enabled in settings, and the project is distributed under a Sustainable Use License with a paid tier and a trial.
