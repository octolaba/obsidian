# dartungar/obsidian-mermaid

Mermaid Tools adds a toolbar of common Mermaid.js elements to Obsidian, opened from a ribbon icon or a command, so the syntax does not have to be remembered; clicking an element pastes it into the editor. Elements can be created, edited, deleted and reordered in the settings tab. The README is explicit that rendering Mermaid is Obsidian's own feature and that the plugin has no control over it, so rendering bugs belong on the official forums, and it notes that toolbar entries are wrapped as complete diagrams so they can be rendered in the panel.
