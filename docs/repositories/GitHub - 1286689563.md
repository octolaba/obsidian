# q7jxb7yxdk-star/spreadsheet-table

Spreadsheet Table adds spreadsheet-style editing to Markdown tables: navigation between cells with Tab, Shift+Tab and Enter, insertion, deletion, movement, alignment and sorting of rows and columns, table formatting that leaves formula meaning intact, and export of the selected table to CSV. Formula cells stay in the note as formulas while Live Preview and Reading Mode render the calculated results, and Live Preview can optionally show Excel-style column letters and row numbers. Actions run from the command palette, a right sidebar toolbar with a mobile-friendly layout, a ribbon icon or configured hotkeys.
