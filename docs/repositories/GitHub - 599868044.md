# callumhackett/obsidian_polka_theme

Polka is a light and dark theme that adds colourful minimalism to Obsidian, with optional dots in the ribbon. It picks up the accent colour from the main Appearance settings and uses it for links, highlights and much else, and with the Style Settings plugin it exposes a background palette generated from a single base colour through hue, saturation, lightness and contrast. The same menu offers themes that apply only to code blocks, among them Dracula, Gruvbox, Nord, One Dark and Solarized, plus controls for main text colour, highlight colour, circular or square checkboxes, table fonts, roundness of elements and the dots themselves. Default fonts are chosen for Mac and PC but are overridden by the main font settings.
