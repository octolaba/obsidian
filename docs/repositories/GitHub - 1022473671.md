# abduznik/obsidian-steamgriddb

SteamGridDB Image Embedder searches SteamGridDB for game artwork and embeds a chosen image into the active Obsidian note. The README describes an interactive flow: a modal pre-filled with the current note's title searches for a game, a second modal lists the matching games, and a third lists the available grids before the selection is inserted at the cursor. It requires a SteamGridDB API key pasted into the plugin settings, and it can also be triggered from a Templater template by executing the plugin's command id.
