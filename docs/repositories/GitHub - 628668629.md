# Phantom1003/obsidian-slide-note

Slide Note keeps plaintext class notes bound to the slides they belong to, rendering PDF pages together with graphic annotations so the notes stay decoupled from heavier tools. A fenced block of type slide-note names the PDF file, given as a relative path, an absolute desktop path or a wikilink, and the pages to render, with fields for scale, DPI, a text layer, rotation and a rectangular crop, and per-file defaults set in frontmatter. The README records the plugin as inspired by better-pdf but adding graphic annotation, per-file configuration, optimization for documents with many pages and automatic re-rendering when the PDF changes, and warns that it is still under development and follows only the latest non-internal version.
