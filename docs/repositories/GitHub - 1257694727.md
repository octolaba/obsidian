# fnsign/StreamRadio

StreamRadio plays web radio in a right-sidebar player opened from a ribbon icon, with stations searched through the radio-browser.info API by name, country, language and tag, previewed before being saved as favourites, reordered by dragging in the settings, and supplemented by custom stations. The player shows the station logo and name, live track metadata when a desktop stream carries ICY data, playback and previous or next controls, a volume slider and a sleep timer running 5 to 120 minutes or a custom value. A Pomodoro timer sits in the same player, with configurable focus and break durations, interval count, long-break cadence, colours, audio cues including a ten-second countdown at the end of each phase, a reduced-distraction dimming mode, and duration changes applied to a running timer without a reset.
