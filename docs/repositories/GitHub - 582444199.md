# blacksmithgu/datacore

Repository for Datacore, which its README calls a work-in-progress re-imagining of Dataview aimed at two to ten times better query and rendering performance and at fully interactable views. It keeps the same premise — an index over Markdown files supporting live-updating views and metadata — while changing the index substantially and replacing traditional Dataview queries with a new interface. The README names a React-based JavaScript API with internal state and flickerless updates, table views editable through a table editor, working page, image and video embeds, live editing of values and task metadata, and queries at section and block granularity over all indexed files, including attachments, PDFs and images.
