# haradaiko100/obsidian-auto-link-converter

This plugin converts pasted URLs into reference-style Markdown links carrying the page title. Its README describes automatic conversion on paste, which fetches the title of the pasted address, and a command-palette command that converts URLs already selected in a note. Two settings are recorded: a switch for automatic conversion on paste, and the placeholder text used when a title cannot be fetched, which defaults to Untitled.
