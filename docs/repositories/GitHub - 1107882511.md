# ErBlack/obsidian-todoister

Todoister synchronizes the to-do items of the active file with Todoist in both directions. Pasting a Todoist task URL imports an existing task into the note. The README states that the plugin works on desktop and mobile, and keeps its usage, privacy and technical descriptions in separate documents inside the repository.
