# Diexar-Labs/jotdrop

JotDrop shows an Obsidian vault's notes as a Keep-style card grid with titles, colours, tags, pinned cards on top and archived cards, plus filtering, sorting and search. Notes stay plain Markdown files with YAML frontmatter inside the vault, so they can be edited anywhere. The README presents the plugin as one of three parts alongside an Android companion app for share-sheet capture, OCR and voice memos and a Chrome web clipper, kept in step with Syncthing or any folder sync already in use. It states that the project is MIT-licensed and works offline with no server, no account, no advertising and no telemetry.
