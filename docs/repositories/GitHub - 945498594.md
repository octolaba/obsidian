# guicattani/obsidian-countdown-to

CountdownTo renders a progress widget from a code block tagged countdown-to, counting toward a deadline or event. The block carries a title, start and end dates and times, and options for the bar shape — line, circle, semicircle or square, drawn with progressbar.js — its colours, a real-time update interval, and an info line whose placeholders interpolate percentages, remaining duration and formatted dates through Luxon. When no dates are given the countdown assumes the current day and runs daily, progress can be shown counting up or down, and a completion message is configurable.
