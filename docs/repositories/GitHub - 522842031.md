# zfei/obsidian-url-namer

URL Namer converts plain URLs inside selected text into Markdown links whose label is the title of the page each URL points at, run through a single command over the selection. URLs already inside a Markdown link are skipped, and the README advises processing a small batch at a time and not editing or reselecting the text while the command runs. Version 1.1.0 added an option to name URLs automatically on paste, offline detection with a graceful fallback that leaves links unchanged and shows one notice, and title extraction that also reads Open Graph and Twitter title metadata.
