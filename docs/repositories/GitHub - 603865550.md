# SntTGR/obsidian-tw-task-wiki

This plugin queries Taskwarrior reports from a code block in which a report name is followed by optional filters and a template, and renders the result as a task list. Clicking a row modifies a task, holding Alt deletes one, and the template parameter supplies default values for tasks created through that report. The README carries a caution that the plugin runs the configured Taskwarrior binary with arbitrary arguments, so the vault's notes must be trusted.
