# sparkwild/obsidian-tracekeeper

Tracekeeper keeps an agent knowledge system inside one vault, pairing a Memory side that records tasks, sessions, decisions, preferences and project continuity with a Wiki side that organizes reusable topics, hubs and sources, connected by explicit wikilinks so the graph and agent recall share one structure. Every suggestion an assistant produces enters a Review Queue as a candidate proposal that must be edited, approved, rejected or sent back for revision before it becomes durable, and the README states that human decisions outrank machine discovery. While desktop Obsidian is open the plugin exposes a local streamable HTTP MCP runtime bound to loopback by default and reached through a generated local token, which assistants use through its own set of tools. The README states that no external database and no auto-sync platform is required.
