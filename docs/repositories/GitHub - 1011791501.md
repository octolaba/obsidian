# lexafaxine/GoogleCalendarImporter

Imports Google Calendar events and tasks into notes, either injected automatically when a daily note is opened or inserted anywhere through a command, with a date picker for importing another day. Calendar blocks are markdown code blocks that act as configuration and render the events for their date. The README records the plugin as desktop only, requiring Obsidian 0.15.0 or later plus a Google Cloud project with the Calendar and task APIs enabled, authenticated over OAuth 2.0 with the user's own client ID and secret.
