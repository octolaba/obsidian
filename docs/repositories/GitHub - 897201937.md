# JasperSurmont/obsidian-comments

Comments adds basic commenting to Obsidian notes for work shared across a team. A comment is a callout of type `comment` whose title carries a name and a date and whose body carries the comment text, and a ribbon icon opens a view listing every comment in the file with its name, date and content, in the manner of a word processor. A command adds a comment, and in the side view a left click navigates to the comment's place in the note while a right click removes it or adds a subcomment. The README states that comments are hidden in reading mode and when the note is exported, for example to PDF.
