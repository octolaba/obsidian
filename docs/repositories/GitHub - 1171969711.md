# marekpola/obsidian-biblens

BibLens detects Bible references in Obsidian notes, underlines them in the editor, and shows the verse text as a hover preview in both Reading View and the Live Preview editor, reporting when a verse is unavailable in the selected translation. Command-palette commands insert the verse text after the last reference before the cursor, or replace a reference with a blockquote containing the verse or passage. The README separates software from data: translations, language packs of book-name aliases and reference formats are downloaded from a separate resource repository and installed or removed from the settings, which also hold the active translation, language pack, reference format and advanced parsing rules, and it states the plugin works fully offline with no external services required.
