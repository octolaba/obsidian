# Cexyz01/obsidian-basecraft

Basecraft adds a Pivot view to any `.base` file in Obsidian Bases, cross-tabulating notes by a row property, a column property and an aggregation into a spreadsheet-style table. The README states the free tier covers the pivot view, `Count` and `Sum`, and row, column and grand totals, while a one-time paid tier adds further aggregations, date bucketing by month, quarter or year, cell drill-down, heatmap formatting, percentage-of-total views and CSV or Excel export. Licensing terms and the pricing quoted here are the README's own claims and were not verified.
