# Haniewicz/ObsidianGoogleDriveSync

Syncs a vault two ways with Google Drive through the Google OAuth 2.0 device authorization flow, with debounced sync of local changes, a lightweight cloud watch for faster remote detection, a periodic full sync fallback and a manual sync command. Conflict policy options, per-device names and a sync status modal are provided, along with reset actions that replace cloud data from the local vault or local data from the cloud, each preceded by a manifest snapshot. Automatic backups run in safety-only, timed or every-sync modes alongside separately managed named manual backups, and a backup preview offers text diffs with per-file or full restore. The README urges a full backup before use, states that the author accepts no responsibility for data loss or corruption, and notes the plugin is not affiliated with Obsidian.
