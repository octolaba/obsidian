# Arcadia-Studio/obsidian-arcadia-publisher

An Obsidian plugin that exports the active note as a PDF or a single self-contained HTML file, run from an export modal, a ribbon icon or commands. Images from Markdown and wiki-style embeds are embedded in the output, and the export can carry a frontmatter title block with title, author and date, a table of contents with working anchors, a Letter or A4 page size and font options. The README states the plugin is free with no account or license key, that it is desktop-only because PDF rendering uses the desktop app's print engine, and that its community plugin listing was pending review.
