# weblogicjava/swz-quick-memos

Quick Memo captures three kinds of short entry — records, flash thoughts and todos — from an overview panel opened by a ribbon icon or a command. The README states that it uses no database: each entry is written as a Markdown list item under a Quick Memo heading in a dedicated per-day file named after the date, so the ordinary daily note is never touched, and the in-memory index behind search, type and tag filters and a ninety-day activity heatmap can be rebuilt from those files at any time. Todos are ticked in the panel and the change is written back to the Markdown checkbox, and an entry can be edited, deleted, copied as a block link or opened in its source file.
