# wildskyf/obsidian-pin-tab-guard

Pin Tab Guard protects pinned tabs in Obsidian from being closed or unpinned by accident, and its README states that it needs no configuration. It guards three built-in commands: closing the current tab does nothing on a pinned tab, closing all other tabs leaves the pinned ones alone, and closing a tab group closes only the tabs that are not pinned. The README records the limit of that approach explicitly, since only commands run from hotkeys or the command palette are guarded and closing a tab through the right-click context menu bypasses the command system, and it says disabling the plugin restores the original behaviour.
