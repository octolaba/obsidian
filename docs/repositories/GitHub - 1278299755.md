# powderfirm-ship-it/obsidian-menubar-time-tracker

Menu-Bar Time Tracker puts a clock in the macOS menu bar: a left-click starts a timer that shows live elapsed time, a second left-click stops it and opens a modal for picking or naming a project and adding a description, and a right-click offers start and stop, cancelling a running timer, and settings. Each session is written as one note carrying `project`, `start`, `end`, `duration` in minutes and `date` in its frontmatter into a configurable session folder, and a shipped Base groups sessions by project and sums their duration. The README records that a running timer survives an Obsidian restart, that stopping brings the Obsidian window forward so the modal is visible, that a toggle command mirrors the left-click when the icon hides behind the notch, and that only the live menu-bar readout is macOS-only while timing and note writing work elsewhere.
