# Moyf/style-context

Style Context publishes Obsidian's runtime context — the current theme and vault image paths among them — as CSS classes and variables that a user's own snippets can target. The README gives two motivations: vault resource addresses are regenerated across reloads, so a stable variable reference is more reliable than using one directly in a background image; and CSS scoped to a single theme lets theme details be tuned without editing theme files that an update would overwrite. Its theme and note-path modules only publish context and state, while an optional background image module applies a vault image variable as a canvas background, with its visual options configurable in the plugin settings.
