# wesswart77/obsidian-design-portfolio

Design Portfolio manages case studies, inspiration, mood boards and client work logs inside an Obsidian vault. Commands create a case study note structured into Brief, My Role, Process, Outcome, Learnings and Assets sections, capture an inspiration entry with source URL, tags and notes, generate a mood board note from an image grid template, and open a portfolio sidebar that browses case studies by year and inspiration by tag. Settings choose the folders where the case study and inspiration notes are saved.
