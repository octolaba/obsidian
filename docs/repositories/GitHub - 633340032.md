# Yustynn/obsidian-last-modified-timestamp-in-status-bar

The repository records no description; its README presents Last Modified Timestamp in Status Bar, a plugin that shows the current note's last modified time in Obsidian's status bar. Settings enable or disable the created and last modified timestamps independently and control their format, their title in the status bar, and the refresh interval of the modified timestamp. The README's change log records that version 1.3.0 updates the modification time from the vault's modify event instead of polling continuously, and that earlier versions added the created timestamp and the toggles.
