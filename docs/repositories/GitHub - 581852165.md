# AllJavi/material_gruvbox_obsidian

This theme applies the Material version of the Gruvbox palette to Obsidian, and its README records that it is based on the existing obsidian gruvbox theme. Dark and light variants are both shown, and the README states that colours can be adjusted with the Style Settings plugin using the overrides the theme provides. It also notes feedback that the light tones are too yellow, and lists a lighter set of light-mode colour values as an alternative.
