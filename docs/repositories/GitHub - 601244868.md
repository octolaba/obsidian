# LBF38/obsidian-syncthing-integration

This plugin integrates Syncthing with an Obsidian vault, adding tools for managing that synchronisation from inside the app. Its README records four installation routes — the community plugins tab, the project's GitHub releases page, building from source, and the BRAT plugin given the repository address — and points at Syncthing itself, a roadmap and the project's GitHub discussions. It also states that the plugin's initial vision has evolved since it was created.
