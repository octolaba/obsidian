# mattbirchler/claude-code-obsidian

Claude Code Sync mirrors the Claude Code sessions stored on the machine into an Obsidian vault as Markdown notes: the sessions folder is configured once, and past and future sessions then appear as notes. Each session becomes one note named by date and session title, filed under a folder named for its project, with frontmatter recording the session id, project, working directory and dates, and with tool calls and model thinking folded into collapsed callouts so the conversation stays readable. The README states that the notes are a read-only mirror regenerated whenever the source session changes, so edits made directly in a synced note are overwritten on the next sync.
