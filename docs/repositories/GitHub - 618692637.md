# tamiroh/obsidian-interval-timer

The recorded description says the plugin runs focus and break cycles using methods such as the Pomodoro Technique and records completed intervals on Markdown task lines. The README shows the timer sitting in the status bar, where clicking it starts a focus interval and hovering over it reaches the timer controls. A task line carrying completed and estimated interval counts can be started with the cursor on it, after which each completed focus interval updates that count on the line automatically.
