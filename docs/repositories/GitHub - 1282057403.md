# xevrion/obsidian-youtube-links

YouTube Links expands a YouTube URL pasted into an Obsidian note into a Markdown link whose text combines the channel name and the video title. Regular watch links, youtu.be short links and Shorts are listed as supported formats, and the README states that no API key is needed. Settings choose between the channel-and-title format, the video title alone or an inline embed, and can show a placeholder while the title is being fetched.
