# o1xhack/obsidian-chatting

This repository holds Chatting with AI, an agentic assistant plugin for Obsidian offering the same interface on phone, tablet and desktop. It supports the Anthropic API, the OpenAI API and an experimental sign-in with a ChatGPT account, and exposes fourteen vault-native tools for reading, editing, searching, creating and renaming notes and for frontmatter and backlinks, so the agent can change files from within the conversation. Mobile parity is stated as a design constraint, with no streaming, no Node-only modules and no localhost callbacks. Text highlighted in a note can be sent to the chat as a scope the assistant edits only inside, and secrets are kept in the operating system keychain rather than in the plugin data file.
