# toki1703/local-history

A plugin that automatically saves local snapshots of Obsidian notes and shows change history from three sources in one panel: its own snapshots, Obsidian's built-in file recovery data and Obsidian Sync version history; its README is written in Japanese. Snapshots are taken after a two-second debounce for .md, .canvas and .base files, consecutive snapshots from the same source within a merge window are combined, and a per-file cap deletes the oldest entries beyond it. The sidebar panel groups versions by day with source badges and diff statistics and loads lazily, while a modal shows a line-level diff computed with a longest-common-subsequence algorithm, falling back to plain text above 3000 lines, with restore and delete actions. The README requires Obsidian 1.12.0 or later and states that all platforms including mobile are supported.
