# cmdurham/wake_up_samurai

Wake Up Samurai is a dark Obsidian theme styled after Cyberpunk 2077, using an oxblood-to-charcoal gradient, red body text, cyan and green headings, gold tags and angular display type. The README documents bordered, softly glowing panes, six clearly distinct heading levels, blockquotes rendered as bordered panels with a notched corner, callouts grouped into seven accent colors, transclusions shown as bordered panels, and three fonts shipped inside the theme as base64 so nothing has to be installed. It records the project as fan-made and non-commercial, not affiliated with the game's publisher, and documents both community and manual installation.
