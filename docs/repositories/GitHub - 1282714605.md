# JK-cpu-jpg/Graph-Background

The repository holds Graph Background, an Obsidian plugin that sets the background of the global and local graph views from its settings page. The README records a background type of none, a solid colour, a linear or radial gradient or an image, an image taken either from a file in the vault or from an external URL, fit modes of cover, contain, tile or centre, and a choice of applying it to the global graph, the local graph or both. A readability overlay adds dim and blur sliders that affect only the background layer, leaving nodes, links and labels untouched, and changes apply without reopening the graph. The README states the plugin works by making the graph canvas transparent through Obsidian's documented CSS bridge classes and layering the background behind it, that a future markup change could break it, and that it works on desktop and mobile.
