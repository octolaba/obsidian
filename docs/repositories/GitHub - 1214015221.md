# Hucy/split-link-router

Repository holding two related tools for routing a clicked link into the other half of a split view, one an Obsidian plugin and one a Chrome extension, with a README written in Chinese. The Obsidian part opens external links in a Web Viewer pane, reuses the same pane for later links, opens a new Web Viewer tab when Shift is held, and inverts the default target with the Command or Control key. The Chrome part uses the browser's native split view, and the README records the limitation that extension interfaces cannot enter split view or add a new tab to it, so the user must open it manually first.
