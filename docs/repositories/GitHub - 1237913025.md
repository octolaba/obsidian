# mapherez/nox-sync

NoX Sync is a self-hosted vault sync system made of a Go backend with SQLite metadata and local blob storage plus an Obsidian plugin. Syncing is explicitly manual, started from a ribbon button or a command, and the README records that the project uses no external databases, no external sync providers, no vault sharing and no automatic background sync. The backend serves a dashboard behind Google authentication with an admin allowlist, one reusable API key per active user, several remote vaults per user, a backend-enforced per-vault lock with heartbeat and stale-lock recovery, manifest-based planning of uploads, downloads, deletes and conflicts, and checksum validation of transfers.
