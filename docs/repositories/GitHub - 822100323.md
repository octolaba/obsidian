# lc0rp/KeepSydian

The recorded description says the plugin provides two-way sync between Obsidian and Google Keep, which the README frames as an answer to the tedium of Obsidian's one-time Google Takeout import. It downloads Keep notes into a chosen folder with their text and images, preserving checklists and tags, keeps attachments in a local media directory and can optionally display imported images in notes. Syncing runs on demand through a review center where creates, updates, conflicts and skips are approved before anything is written to the vault, or in the background every 24 hours and at shorter intervals for supporters, with each run recorded in a dated activity log. The README links an installation page and a separate subscription page for supporter features.
