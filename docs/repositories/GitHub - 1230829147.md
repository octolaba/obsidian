# jasonsting622-netizen/folder-crypto

Folder Crypto offers two folder-protection modes for an Obsidian vault. Folder lock hides a configured folder's files and subfolders behind a lock badge in the file explorer and asks for the password when the folder or a file inside it is opened, keeping it readable until Obsidian closes or a lock-all command runs; an optional switch also hides the underlying directory in Finder using chflags, which the README states is only a convenience layer and not encryption, bypassable from Terminal, backups, sync history or other apps. Content lock rewrites file contents into an encrypted envelope with AES-256-GCM and a PBKDF2-derived key, and passwords are never saved. Both modes have commands and folder right-click entries, and an option writes plaintext backup files next to encrypted ones, which leaves readable copies in the vault.
