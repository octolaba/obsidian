# LinglingCai0314/obsidian-mood-quarter-calendar

Mood Quarter Calendar renders a full-year mood calendar from a Markdown code block, laid out three months per row, with one custom SVG face drawn for each recorded day. Mood values are read from daily notes through frontmatter, inline fields or tags and stay there rather than in a separate database; clicking an empty day records a mood and creates the daily note when it does not exist, while clicking a recorded face opens a sticky note holding that day's short mood detail. The README lists eight supported mood keys and states that the plugin reads and writes only local files in the vault.
