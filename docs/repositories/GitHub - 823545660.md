# hardingadonis/hash-pasted-image

This plugin renames images pasted into the vault automatically, giving each one the SHA-512 hash of its old name as its new file name. The README describes the whole flow as copying an image to the clipboard and pasting it into the vault. It records that the plugin was inspired by obsidian paste image rename.
