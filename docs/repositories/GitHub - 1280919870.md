# jstoolsspace/json-inspector-obsidian

JSON Inspector renders a fenced json-inspector block as an interactive viewer with tree, raw and query views, and can optionally take over plain json blocks, which is off by default to avoid conflicting with other plugins. The tree view collapses objects and arrays with per-type colouring, item counts, keyboard navigation and lazy rendering; the raw view keeps the original text with beautify, minify, word wrap and copy; and the query view runs JSONPath expressions with a match count and a history of the last ten queries. A find shortcut searches keys and values, and each node offers copying of its value, key, object, JSONPath or JSON Pointer and expanding or collapsing its subtree. The README states that everything runs locally with no network requests, telemetry or accounts, and that numbers are parsed losslessly so large integers and high-precision decimals are unaltered.
