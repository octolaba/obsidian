# nancyel/obsidian-foldercanvas-plugin

Generates a Canvas file from the Markdown files of a folder, invoked from the command palette, a ribbon icon, the file menu or the editor menu. The README records the expected behaviour: only direct first-level files are included and nested folders ignored, the canvas is created in the parent folder of those files, no canvas is created for a folder without Markdown files, and a filename that already exists is incremented. A watch option keeps the latest canvas in step with changes in the folder as long as its filename still matches the configured pattern, and a narrow-to-heading option limits each node to the content under a chosen heading, falling back to the full content for nodes that lack it.
