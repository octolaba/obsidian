# denis2710/simple-kanban

Repository for Simple Kanban, a plugin that shows notes as cards in columns derived from a frontmatter property, by default one named status. Its README records that dragging a card between columns rewrites that property in the file, that columns can be added, removed, reordered and coloured, and that a folder and its subfolders are scanned for Markdown files. Further options cover extra frontmatter fields shown on cards, per-column visibility rules, case-sensitive or case-insensitive matching, and special columns for files with no status or an unrecognised one.
