# jpeacock29/zotero-cite-links

This repository holds Zotero Cite Links, a desktop-only Obsidian plugin that makes a Pandoc-style citekey open the cited PDF in Zotero at the page named by the locator, with annotation-aware page-label offsetting. A citation is opened by Cmd- or Ctrl-click, by a plain click when that modifier is configured, or by a command acting on the citekey nearest the cursor, and a second command re-queries Better BibTeX for the libraries to search. It communicates only with a local Zotero and Better BibTeX over 127.0.0.1 and makes no other network request. The README frames it as closing the last step other citation-aware plugins leave open, whose open action lands in Zotero's collection view rather than on the page.
