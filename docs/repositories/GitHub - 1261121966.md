# abgmgp/obsidian-simple-autolink

Simple Auto-Link converts matching words in Obsidian notes into wiki links as the file is edited, on desktop and on mobile. The README describes word-boundary-aware matching that prefers longer matches over shorter ones, is case-insensitive by default, never links a note to itself and never matches inside another word, with optional base-word matching so a plural links to a singular title and an optional limit of one link per file. Code blocks, inline code, existing links, frontmatter properties, tables and mathematics are always skipped, headings can be skipped by setting, and folders can be included or excluded so that excluded notes are neither scanned nor used as targets. An alias masterlist maps several aliases onto one note and backfills them into each note's frontmatter, and a display link is written when the matched text differs from the note title.
