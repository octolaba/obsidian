# hyungyunlim/obsidian-korean-grammar-assistant

Korean Grammar Assistant checks Korean spelling and grammar from within an Obsidian vault, working on text selected in the editor. The README describes popup and inline review modes, correction states for applying a suggestion, keeping the original, ignoring a term or editing manually, and a keyboard-driven flow for moving between detected issues. Grammar checking defaults to an app proxy that needs no API key, while NaraSpeller and a direct Bareun.ai API server are configurable alternatives that each require their own key. Optional AI-assisted review can be routed to OpenAI, Anthropic Claude, Google Gemini or a local Ollama instance.
