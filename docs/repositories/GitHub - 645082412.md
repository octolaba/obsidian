# thenomadlad/obsidian-note-archiver

Note archiver is a small Obsidian plugin that moves notes into an archive folder to keep a working area clean. Archiving is triggered from a command in the command palette, from a button in the editor menu or from one in the file menu, the destination folder is configurable, and archived files can optionally be grouped into subfolders by the year and month in which they were archived. The README lists per-area settings, archiving by a date in the file name and an unarchive action as not yet built.
