# slavkomelnyk/camera-embed

This repository holds Camera Embed, an Obsidian plugin that captures a photo from the device camera and embeds it in the current note. The README states that it supports Android only, not iOS or desktop; a ribbon button or the Capture photo and embed command opens the camera, and the image is inserted at the cursor position. Photos are saved beside the note or in a configured vault folder and are compressed before saving, with the compression quality configurable and defaulting to 0.8.
