# scbrown/neon-dracula-obsidian

scbrown/neon-dracula-obsidian holds Neon Dracula, a cyberpunk neon dark theme for Obsidian based on Dracula for Obsidian by Chrismettal and Andy Byers. The README maps each element to a colour and an effect, among them golden headers with glow and outline, green inline code and tags, purple borders on tables and code blocks, orange links and bold, and cyan italic comments. It records a font stack of Intel One Mono, Fira Code and JetBrains Mono falling back to monospace.
