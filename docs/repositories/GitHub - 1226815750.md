# an2io/obsidian-canvas-drag-fix

This repository holds Canvas Drag Fix, an Obsidian plugin that repairs Canvas drag-and-drop on Linux when Chromium misclassifies an ordinary mouse as a pen device. The symptoms it addresses are cards that cannot be moved by dragging, side-resizing and marquee selection that do not work, and arrow connections that cannot be drawn, while clicks, double-clicks, keyboard movement and corner resizing keep working. The README names affected setups, among them Linux guests under VMware and VirtualBox, ChromeOS Crostini containers, some Wayland configurations and machines with unusual XInput2 device topology, and states that the bug is not specific to any sandbox or distribution. It also supplies a console snippet logging pointer events so a user can confirm the misclassification first.
