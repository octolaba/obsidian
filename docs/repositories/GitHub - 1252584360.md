# anliberant/hn-obsidian-plugin

HN Reader is an Obsidian plugin for browsing Hacker News inside the vault and saving stories to a reading list note. The README records the Top, New, Best, Ask HN, Show HN and Jobs feeds, opened either in a sidebar panel or a new tab from a ribbon icon or a command, with buttons to switch feed, refresh, and bookmark a story into the reading list. Settings record the display mode, the default feed, 10, 20, 30 or 50 stories per page, optional site favicons, and whether saved stories go into a single file or a dated daily note with frontmatter, plus a configurable set of tags appended to each saved story.
