# stefanimp/context-prism

The repository holds Context Prism, an Obsidian plugin that ranks notes related to the active file and copies a compact Markdown context pack for pasting into an external assistant. It explains why each note was selected, estimates the context avoided, allows include and exclude decisions before the pack is copied, and offers passive suggestions for the active note. The README states that the index is built locally from Markdown files through the Obsidian plugin API and that nothing is sent to external services; that claim is the README's own.
