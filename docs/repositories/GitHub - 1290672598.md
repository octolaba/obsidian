# yangzuo0621/vault-loom

Vault Loom combines streaming chat, note-aware retrieval, editing commands and a confirmation-gated agent mode in Obsidian. The current selection or active note can be attached as structured context, relevant Markdown notes are found by keyword search, Markdown chunks can optionally be indexed for embedding-based semantic retrieval, and the context attached to the latest request can be previewed; chat sessions are created, switched, restored and deleted, and the command palette can explain or rewrite a selection or summarize the current note. Agent mode is bounded, shows tool activity and asks for confirmation per note write. The README records desktop Obsidian 1.12.7 or later and an OpenAI-compatible endpoint as requirements, notes that the first public release is desktop-only, and states that agent mode needs tool-calling support and semantic retrieval an embeddings endpoint.
