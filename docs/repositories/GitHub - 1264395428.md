# callumalpass/canvas-bases

This repository holds Canvas Bases, an Obsidian plugin that adds a canvas-style layout to Obsidian Bases and materialises a view as a JSON Canvas file. The Base still owns the query, so filters, sorting, grouping and visible properties stay in the base file, while the plugin adds spatial layout, draggable and resizable file cards, board frames from Base grouping, relationship edges, assignment zones and export. Board geometry, colours, manual cards, groups and zones are persisted in view config keys the plugin owns, and manual nodes and edges it does not own are preserved when a generated canvas is updated. The README states that Obsidian 1.10.1 or newer and Bases are required, while TaskNotes integration is optional and degrades cleanly when absent.
