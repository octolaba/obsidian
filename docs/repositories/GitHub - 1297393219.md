# jannik-el/survey-log-obsidian-plugin

Survey Log captures timestamped, location-tagged entries into the active note while working through survey tasks, triggered by a keyboard shortcut on desktop or by tapping the command on mobile. The command pre-fills the timestamp for adjustment, offers an autocompleting list of locations read from a locations note in the vault, and can suggest entry text drawn from the author's own past entries before writing a single log line. Locations are inserted as ordinary Obsidian tags by default, so every entry for a location is findable through the tag pane, search or Dataview, or as links if each location should be its own note; a location typed but not yet listed is appended to the locations file.
