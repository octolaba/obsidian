# l10n-dev/obsidian-plugin-ai-translator

This repository holds the L10n.dev AI Translator, an Obsidian plugin that translates notes into any of 165 or more languages through the L10n.dev localization API while preserving Markdown formatting and structure, and also handling json, yaml and other plain-text formats. Translation runs from the command palette, a ribbon icon or the right-click context menu, with a dynamic language search, memory of the last used language, three output modes that create a new note, replace the current one or append, optional preservation of YAML frontmatter, and generated glossaries for consistent terminology. The README records that a free account and API key are required, that the free tier includes 10,000 characters per month, that characters used and the remaining balance are shown after each translation, and that the plugin uses Obsidian's native network layer so it also works on mobile.
