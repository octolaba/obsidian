# TSLST/tokyo-terminal-obsd

Tokyo Terminal is a high-contrast Obsidian theme styled after a retro-futurist 1980s terminal and what its README calls Tokyo's electric nights. It applies crisp cyan on deep purple and near-black backgrounds, with hot pink, sunset orange, gold and deep violet highlights across syntax and interface. The README frames the design as a reworking of vintage CRT glow and synthwave color, and carries its own version, contributor and update metadata in frontmatter.
