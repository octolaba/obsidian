# atait/obsidian-expand-selection

Expand Selection adds a single hotkey that selects the section containing the cursor and, when pressed repeatedly, widens the selection to parent sections and finally to the whole note. The README presents this as a way around imprecise cursor control on mobile, where dragging a selection handle can move it off screen. It registers one command, Expand section, and points at the Code Shortcuts plugin for line-by-line selection.
