# Laplacede/obsidian-canvas-node-autosize

This repository holds Canvas Current Node Auto Size, an Obsidian plugin that resizes only the canvas text node currently being edited so it fits its content. Width is adjusted while typing and the rendered Markdown is then measured for an accurate final width and height, covering text, callouts, tables, lists, code blocks and CJK content without moving neighbouring nodes. Growth can be directed to the right, to the left or from the centre, and settings add CJK-friendly width padding, a temporary anti-wrap width during editing, and fallback line height and vertical padding. The README states that the plugin does not attempt full automatic layout, collision avoidance or graph rearrangement.
