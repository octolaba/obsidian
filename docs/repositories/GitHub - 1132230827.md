# mingmingsoeasy/obsidianSessionWordCounter

Tracks the words added or removed during a writing session, with an optional timer. The status bar shows the difference as a signed number and, when enabled, the elapsed time; a session is started and stopped from the status-bar clock icon or the toggle command. The README states that counting follows Obsidian's built-in counter by filtering Markdown syntax such as links, images and URLs and counting each CJK character as one word. Tracking sleeps when another file is opened and can stop automatically after a period of inactivity.
