# Charette-AI-Group/html-font-toolbar

A floating formatting toolbar that writes every style it applies as one inline HTML span rather than nested Markdown and HTML wrappers. Text color, highlight, bold, italic, underline, strikethrough, font size and font family merge into that single span, and clicking a control again toggles the property off; the plugin finds and edits an existing span in place and repairs pre-existing nested ones. Alignment is context aware, setting paragraph alignment, native column alignment inside a table, fragment alignment for a selection in a cell, or an alias keyword on a lone image embed. A symbol picker inserts characters at the cursor, and indent and outdent adjust paragraph indentation in steps that share a wrapper with alignment.
