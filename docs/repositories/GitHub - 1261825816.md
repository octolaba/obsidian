# toadfans/NameGuard

This repository holds NameGuard, an Obsidian plugin that treats a note name as a vault-wide unique key; the repository records no description, so this summary follows the README alone. The problem it addresses is that with the shortest-path link format, a second note sharing a name anywhere in the vault makes Obsidian rewrite existing links to keep them pointing at the original file, changing notes the user never touched and leaving a noisy diff. NameGuard blocks an operation that would introduce a duplicate name before the file is created, so the rewrite never happens, and the README states that pre-existing duplicates are left untouched and only new collisions are guarded.
