# rkosova/obsidian-markdown-link-space-encoder

This Obsidian plugin encodes the spaces in selected text as percent escapes, which the README describes as useful for Markdown-style links to other notes in a vault. Its usage is to highlight the link markdown in the Markdown view and then run the plugin's encode command from the command palette.
