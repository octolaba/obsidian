# zlovatt/obsidian-trim-whitespace

Trim Whitespace removes unnecessary blank characters from a document, a feature the README compares to code editing software. It works on spaces, tabs and newlines, and each can be trimmed where it is trailing, leading, or repeated in groups of two or more. Commands trim the whole active document or only the selection, a ribbon button does the same, and settings add trimming on manual save, automatic trimming after a delay, and preserving whitespace inside code blocks.
