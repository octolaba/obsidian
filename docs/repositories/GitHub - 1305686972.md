# MasoudMiM/obsidian-dogear

Repository for Dogear, a reading tracker that keeps one Markdown note per book, with metadata in frontmatter and a reading log in the note body. The README describes importing a Goodreads CSV export — shelves becoming statuses, ratings and read dates carried over, reviews kept as prose — with a preview of what will be created and an explicit statement where the export is lossy. Progress can be logged by page, percentage, elapsed time or remaining time and is normalised to a percentage, and the library is shown as a cover grid filtered by shelf and searchable by title, author or series.
