# hasanyilmaz/operon

Obsidian plugin that manages tasks for humans and agents while keeping them in Markdown, adding structured metadata, durable identity, reusable views, planning surfaces, recurrence, reminders and time tracking. It indexes both lightweight inline checkbox tasks and larger file-based tasks under one set of filters, table, calendar, kanban board and task editor, so a single task record moves through many views without becoming duplicated work. Every task is given an identifier and indexed from its source location in the vault, which is what keeps it recognisable across those surfaces. The README records ten interface languages, English built in and the other nine installed as on-demand packs, with natural-language date input available in all of them.
