# dabravin/obsidian-dynamic-embed

Obsidian plugin that embeds snippets, templates and other linkable files by delegating the current scope to the embedded file, so the target is treated as content rather than as a reference, in contrast to the integrated embed syntax. Its README notes that the link syntax it accepts does not support heading or block links, and its example imports the contents of a template note that exists in the active vault.
