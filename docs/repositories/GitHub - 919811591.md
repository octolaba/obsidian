# garethng/obsidian-blog-generator

Blog Generator converts the current Obsidian note into a blog post with OpenAI's language models and saves the result as a new Markdown file. It runs from a pencil icon in the left sidebar or the Generate Blog command, and its settings hold the API key, an optional custom endpoint, the output language and custom prompts. The README lists Chinese, English, Japanese and Korean as the supported languages and mentions automatic processing and conversion of images in the note.
