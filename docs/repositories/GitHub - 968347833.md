# aidanastridge/Publisher

Publisher is an Obsidian theme modelled on the classic books recognisable from their striking black, white and orange colours and their mix of modern and traditional typesetting. Its listed features are minimal borders for simplicity, two fonts — a technical one for the interface and a traditional one for note-taking — and a trichromatic palette. The README lists readability errors under maintenance, references kepano's Minimal theme, and records the MIT license.
