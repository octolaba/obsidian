# pingzi-crypto/note-loom

This repository holds Note Loom, an Obsidian plugin that turns free-form notes into structured notes using the user's own Markdown templates; the repository records no description, so this summary follows the README alone. Templates are imported from a chosen root folder and configured with an output folder, a filename field, field aliases and the sections the plugin should generate. A Generate Structured Note command or a ribbon icon then processes the open note and opens a modal where fields, sections, output path and previewed content can be reviewed and adjusted before the structured note is written; the README is available in English and Simplified Chinese.
