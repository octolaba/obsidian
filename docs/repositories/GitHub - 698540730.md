# chuangcaleb/obsidian-fountain-editor

This repository holds Obsidian Fountain Editor, described upstream as a plugin for Fountain screenplay syntax formatting. The README says a Markdown note is marked for Fountain treatment in one of three ways, by a fountain.md extension, a fountain tag in the properties, or a fountain CSS class, after which the editor applies syntax highlighting and styling according to the Fountain syntax. A video demonstration, community page and a separate documentation wiki are linked from the README.
