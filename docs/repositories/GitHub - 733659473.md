# andrewmcgivery/obsidian-beautitab

Beautitab replaces Obsidian's new tab view with a customizable start page carrying rotating backgrounds, quotes, a clock, a greeting and search entry points. Every element can be shown or hidden in the settings, the clock can use 12-hour or 24-hour format, the greeting text is editable, and both the top-left search icon and the inline search box can be configured to open one of several search providers rather than the built-in one. The README also documents the rotating backgrounds as customizable.
