# alincoop/obsidian-tinychart

TinyChart renders ASCII charts from a codeblock whose lines pair a label with a value. The README marks horizontal bars as supported and vertical bars and line charts as planned, and its settings cover the fill and empty characters, optional prefix and suffix characters, chart length, whether value labels are shown and how they are aligned, and whether the chart renders inside a code block or as a paragraph. It also shows the chart data being generated dynamically from a Dataview script, so a chart can update as the vault changes.
