# mnaoumov/obsidian-smart-rename

Smart Rename renames a note and then repairs what a plain rename would lose. The previous title is added to the renamed note's aliases, and backlinks that used the previous title as display text keep showing it, which the README works through for wikilinks with and without display text and for Markdown links. A demo vault with usage examples ships with every release and can be opened from a command, downloaded from the releases page or browsed in the repository.
