# 4Source/open-editors-obsidian-plugin

This plugin adds a view showing the open windows, groups, tabs and editors of the Obsidian workspace. From that view all editors in a window or group can be closed at once, or another editor can be switched to. Rearranging groups, windows and editors by drag and drop is listed as a planned feature.
