# namelesscorp/tvault-obsidian-plugin

Trust Vault is a desktop-only plugin that wraps the tvault-core command-line tool to encrypt a vault's notes into a container and remove the plaintext, restoring them when unlocked. The README describes a side panel showing the current state and a single primary action, and states that the .obsidian directory is never encrypted or removed: on lock the notes are moved into a temporary staging folder and only that folder is packed, so the plugin, its settings and the bundled binary survive a lock and unlock cycle. Depending on the token type the container is protected either by a passphrase alone or by a generated 256-bit key with Shamir shares and an integrity passphrase, and the panel can gather extra entropy from drawing inside a box.
