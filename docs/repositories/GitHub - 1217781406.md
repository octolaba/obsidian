# boerlabs/obsidian-enhanced-tab-settings

Enhanced Tab Settings is recorded as a fork of jesse-r-s-hines/obsidian-open-tab-settings that adds VS Code-style preview tabs. Its README documents settings for always opening files in a new tab, switching to an existing tab instead of duplicating a file, controlling new tab placement and order, and opening new tabs in the opposite pane of a split. With preview tabs enabled, a single click in the file explorer opens a file in a temporary tab shown in italics, while a double click or an edit promotes it to permanent; the README states that the plugin patches Obsidian internal methods to make this behaviour consistent.
