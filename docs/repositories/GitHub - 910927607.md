# ahmetildirim/obsidian-inscribe

The recorded description says this is an Obsidian plugin for inline autocompletion with AI. Per the README completions are generated as the user types and accepted or rejected with the Tab key, using a configured provider: Ollama running locally, Gemini, Grok, OpenAI or an OpenAI-compatible endpoint. Both system and user prompts are configurable, with mustache template variables supplying context — the text before and after the cursor, the current sentence and the last line of the active note. Several profiles can be assigned to note paths so that opening a matching note activates its profile, which the README also suggests as a way to limit completions to chosen paths, and it recommends a local Ollama model given the frequency of calls.
