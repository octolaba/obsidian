# williansaez/neural-vault

This repository holds Neural Vault, a beta desktop-only Obsidian plugin that animates Obsidian's native graph view while Claude Code reads and edits notes in the vault, flashing the node of each file the agent touches. The README describes the path as a PostToolUse hook configured in the vault posting to a localhost listener the plugin runs, after which the matching node on the built-in graph glows, swells and fades; the plugin drives the built-in graph renderer directly and keeps the force simulation warm instead of adding a view of its own. It states explicitly that this is a visualizer storing nothing of its own, that it is not a note store or memory system, and that Claude Code does not require it.
