# cetrodk/obsidian-inline-annotations

Inline Annotations attaches short notes to selected text in Obsidian and reveals them in a popup, so context can be recorded without creating a separate page. Annotations are written inline with a `{text::note}` syntax; in reading view and Live Preview only the annotated text is visible, and the note appears above it on click or hover. Selecting text and running "Annotate selection" from the command palette or the right-click menu creates one, and right-clicking an existing annotation offers edit and remove actions. A single setting chooses between click and hover as the trigger mode, with click the default.
