# skztr/obsidian-plugin-section-copy

Copy Section adds a copy button to header lines in a document; clicking it copies everything in that section as raw Markdown, up to the next header of the same level. Settings choose which heading levels carry the button, whether sub-sections are included or the copy stops at the next header of any level, and whether comments and lines containing only tags are omitted. The README notes that Obsidian itself is inconsistent about how comments and inline code interleave, and that the plugin treats such mixtures as undefined behaviour rather than deciding between the editor and reader interpretations.
