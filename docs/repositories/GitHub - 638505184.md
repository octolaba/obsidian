# czottmann/obsidian-logstravaganza

Logstravaganza proxies console calls in Obsidian and copies log messages and uncaught exceptions to a note in the vault; the README states that it is aimed mainly at developers and is also useful for asking users to send a log along with a bug report. It intercepts all console output and logs uncaught exceptions, including those raised in async code and promises on the main thread. Output can be written as NDJSON, as a Markdown table or as Markdown code blocks, into a file named after the device name reported by the core Sync plugin and optionally dated.
