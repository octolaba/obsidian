# lojeunhou/zotero-notes-sync-plugin

This repository holds Zotero Notes Sync, a desktop-only Obsidian plugin that reads notes from the Zotero Desktop local API and writes them into the vault as one Markdown file per Zotero note. Each file carries frontmatter with the Zotero key, parent item title, creators, year, tags, dates and zotero:// links, while an index note and a manifest file record what was synced. Sync runs from a ribbon button or the command palette, optionally at startup and on an interval, and the target folder, API URL, page size and index behaviour are configurable. The README states that the plugin only reads from Zotero, never writes back, overwrites previously synced files sharing a note key, and does not sync PDFs or attachments yet.
