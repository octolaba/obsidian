# grub-basket/GridSense

GridSense opens a folder as an editable table over its notes' frontmatter, with rows as notes and columns as the union of frontmatter properties ordered by usage. It offers multi-cell selection, spreadsheet keys for navigation, editing, fill down and fill right, TSV copy and paste and undo, per-column filter dropdowns with value search, sorting and conditions, find and replace, and a read-only column showing each note's body text under a chosen heading. The grid renders from a compiled snapshot of the frontmatter persisted as JSON under the plugin folder and invalidated by metadata-cache events, and the README states that every write goes through Obsidian's processFrontMatter so note bodies are untouched.
