# bruce2431/obsidian-chat-bubble-renderer

This repository holds Chat Bubble Renderer, an Obsidian plugin that renders Markdown chat logs as messaging-app bubble dialogues in the WeChat style. Rendering happens automatically in reading view for a file carrying the plugin's chat-log tag, is dismissed with the escape key, and can also be triggered by a command. Messages from others are drawn on the left and the reader's own on the right, and the README documents quote replies shown with a reference bar above the reply, merge-forward cards opening a navigable overlay with unlimited nesting, centred system messages for events such as recalls and group renames, and rich cards including a location card with a map preview.
