# qustrolabe/zoxide-notes

This repository holds Zoxide Notes, also called Zoxidian, an Obsidian plugin that tracks which notes are visited and ranks them using the frecency algorithm of zoxide. Notes opened often or opened recently rise to the top of a sidebar panel, and a quick search modal reached from the command palette ranks its results by the same score.
