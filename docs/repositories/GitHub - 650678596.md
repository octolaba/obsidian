# epszaw/obsidian-micro-templates

Micro Templates turns templates stored in a folder of the vault into text snippets that can be inserted anywhere from the command palette, with the source folder chosen by a command or set in the plugin settings. Templates are compiled with the ejs engine, so arbitrary JavaScript can be written inside them, and dayjs is provided for date formatting within a template. A cursor marker string in the template marks where the cursor should be placed after insertion.
