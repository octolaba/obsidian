# newcodejin/obsidian-bookmark-list-generator

This plugin generates a Markdown file listing the vault's bookmarks, with statistics per group and per type. The list is produced from a sidebar icon, a Generate Bookmark List command or a button in the plugin settings; each run rewrites the output file and opens it, while auto-update refreshes it in the background at a configurable interval. Settings cover the output filename, whether bookmarks whose note no longer exists are excluded, and whether the sidebar icon is shown. The README warns that the generated file is fully overwritten on every update and should be treated as read-only, and that the Bookmarks core plugin must be enabled.
