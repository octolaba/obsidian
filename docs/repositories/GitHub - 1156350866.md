# Wenzhi-Ding/zotero-direct

This repository holds Zotero Direct, a personalized fork of stefanopagliari/bibnotes that generates literature notes in Obsidian from a Zotero library. It imports metadata such as title, author and abstract only, deliberately dropping the original plugin's import of PDF highlights, annotations, Zotero user notes and extracted images so that the reader organizes material by hand. It reads the Zotero database directly, detecting the default location and falling back to a manually configured path, so neither a Zotero add-on nor a JSON export is needed, and it offers commands to create or update one literature note and to update every note changed in Zotero since the last run.
