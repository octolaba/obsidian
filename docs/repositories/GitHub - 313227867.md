# lukauskas/obsidian-highlighter-theme

lukauskas/obsidian-highlighter-theme is a minimal, clean theme for Obsidian whose stated intention is to make notes look like text printed on paper and annotated with a highlighter pen. The README states that only the light interface is supported, that the theme is based on code from the obsidian_ia theme and inspired by sublime-scheme-alabaster, and that it uses Helvetica for main text and Fira Code for monospaced items. Installation is by placing or symlinking obsidian.css into the vault root and enabling the custom CSS setting.
