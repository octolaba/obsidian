# RyotaUshio/obsidian-outline-plus

Outline++ adds an option to render Markdown inside Obsidian's outline view. The README states that the plugin was originally written to fix a bug of the built-in outline view affecting headings that contain numbers, and that the bug has already been fixed in Obsidian 1.5.4. It also states that the plugin is still awaiting approval and is not in the community plugin browser, so installation goes through BRAT.
