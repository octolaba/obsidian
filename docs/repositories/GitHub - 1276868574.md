# eve1329/issuetracker

IssueTracker syncs issues from Git-compatible hosts into an Obsidian vault, storing each as a normalized note in a configured folder, taken from selected repositories or from every repository under an organization or group. The README states that the implementation is verified against GitCode and GitLab-style issue APIs and that its GitHub and Gitee compatibility paths are not yet fully tested. Authors are marked internal or external from a confirmed member directory, collaborator data, a manual whitelist and workflow markers in issue titles, and issues are classified as bug, requirement or unknown by configurable prefix, keyword and label rules. It also produces daily reports, an XLSX ledger recording first-response timing without storing comment text, reminders when tracked issues close, and optional Feishu webhook notifications logged only once accepted.
