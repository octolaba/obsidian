# Quorafind/Obsidian-Templify

Templify renders an Obsidian note in a different layout chosen from a set of templates, and the README names a Cornell and an Eisenhower template among those it carries. It also documents embedding: the state of any view can be copied from that view's header menu and pasted into a templify-embed code block, or a view opened in another tab can be embedded into the current note through a command or the editor context menu. The README states that the plugin is not open source while adding that the Obsidian team has the authority to review its source code, and it links a video tutorial. The recorded repository description calls this a releases repository for the plugin.
