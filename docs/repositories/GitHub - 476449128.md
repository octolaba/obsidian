# juracy/obsidian-asciidoc-blocks

Obsidian plugin that renders AsciiDoc blocks, initially focused on tables, on the grounds that Markdown tables are limited. The README's examples show a headerless table without grid or frame, a table whose rows are given in CSV form with a header, and cells spanning rows and columns. It states that any AsciiDoc feature might work but comes with no warranty and no support, and that the author may later restrict the table block to tables and add a separate unsupported raw block.
