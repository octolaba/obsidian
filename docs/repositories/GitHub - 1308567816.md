# realhenrylo/obsidian-sidebrace

SideBrace groups a few related lines with a large curly brace and a short side label, reusing the callout syntax: the callout title becomes the label and the body becomes the braced content. A brace callout places the brace to the right of the content with the label beside it, and a left variant mirrors both, while ordinary callout types are left untouched. Without the plugin these blocks render as normal callouts, and in Live Preview clicking into a block shows the raw Markdown until the cursor moves away. Everything is styled through CSS variables for the brace colour, stroke width, column width and label colour, so themes and snippets can override them.
