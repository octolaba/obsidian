# KORThomasJeong/live-scribe

Live Scribe is described as real-time meeting transcription in an Obsidian sidebar powered by ElevenLabs Scribe. Its README says the transcript streams into the sidebar from the microphone through Scribe v2 Realtime, with automatic language detection or a pinned language, and accumulates in a buffer from which everything new or a single segment can be inserted at the cursor, with inserted segments dimmed. The full session is appended live to a file in a chosen folder, and optional timestamps and a configurable line prefix control the written form. The README states that the plugin is client-side only, that the user's own API key fetches a single-use token, and that it is an independent community plugin not affiliated with ElevenLabs.
