# Jareika/ttrpg-tools-time

TTRPG Tools - Time provides fantasy calendars and timelines for campaigns, with week, month and year views built from custom weekdays, months, eras, named years, seasons, leap months, intercalary days outside months, configurable holidays and an optional exact time system. Multiple moons can be defined with their own cycle length, phase count, labels and images, and weather is generated from either calendar-based weather years or fixed climate cycles. Events may span one or several days, carry times, recurrence with end modes, descriptions, linked notes, images, color markers and tags. They appear on a timeline view with vertical, horizontal and stacked layouts, tag include and exclude filtering, and embedded timeline blocks generated through an insert modal; the README states that the plugin is an early release whose interface and data formats may still change.
