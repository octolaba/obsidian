# EzXabi/copy-file-to-clipboard

The repository holds Copy File to Clipboard, an Obsidian plugin that adds a copy entry to the right-click menu of every file in the file explorer. Text files such as Markdown, plain text, JSON, CSV and source files are copied as text; images are converted to PNG and copied as image data; and any other file, such as a PDF or a binary, is placed on the clipboard as a file, in the manner of copying it in a system file manager. The README states that the behaviour is configurable per file type, choosing between the content and the raw file for text and between PNG and the raw file for images.
