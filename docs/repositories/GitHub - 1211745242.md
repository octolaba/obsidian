# GopeshKachhadiya/Cosmic-Events

Cosmic Events is a dark, high-contrast Obsidian theme whose README draws its imagery from space. It uses a true black background, glowing colours for headings, inline code and symbols, and accents in cyan, violet and sky blue. Its manual installation instructions name the stylesheet obsidian-true-black.css and note that the file can be placed in the vault themes folder or enabled as a snippet instead.
