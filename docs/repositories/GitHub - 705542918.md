# Alintor/obsidian-kinopoisk-plugin

This plugin searches films and television series on Kinopoisk through the Kinopoisk.dev API and creates a note from the selected result. The search is started from a ribbon icon or a search command, and the settings hold the API token, the new file name format, which defaults to the title and year, the folder the note is created in, and an optional template file. The README includes an example template and defines the variables used in it, and states that the API token is obtained by choosing a free plan on the provider's site.
