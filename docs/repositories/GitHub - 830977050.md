# shsethi/obsidian-rollover-weekly-todos

Rollover Weekly Todos moves incomplete todo items from the previous weekly note into the current one. The command is run from the command palette or the ribbon icon and works from anywhere in Obsidian, and a setting turns off the automatic rollover that would otherwise happen when a new note is created, leaving it manual. A second setting names the heading, taken from the template configured for new notes, that the incomplete items are placed under, while the items themselves are collected from the whole previous file. The README states that it requires the Periodic Notes plugin with weekly notes enabled, and that it was written after the daily-notes rollover plugin it is based on, in TypeScript rather than plain JavaScript.
