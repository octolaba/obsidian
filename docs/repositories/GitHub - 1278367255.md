# gregbrown1229/obsidian-real-pin

Intercepts the Close current tab command so that a pinned tab is not closed by a stray keystroke: when the active tab is pinned, a confirmation dialog appears instead, and cancelling keeps the tab. Because it hooks the command rather than a key, it applies to whatever hotkey is bound to that command and to running it from the command palette, and a setting can instead block keyboard closing of a pinned tab outright until it is unpinned. A second setting shrinks pinned tabs to their icons, implemented in CSS keyed on Obsidian's own pin indicator with no per-tab JavaScript and no dependency on another plugin.
