# danielnichiata96/obsidian-citeme

Obsidian plugin for searching and inserting formatted academic citations from the CiteMe service. The README describes searching papers or looking up a DOI without leaving Obsidian, inserting in-text citations, full bibliography entries or both, an automatically maintained References section, duplicate detection by DOI and text, citation styles split into free and paid tiers, quota shown in the status bar, and use on both desktop and mobile.
