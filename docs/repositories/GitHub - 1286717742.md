# ondreu/mass-editor

No repository description is recorded, so this body is grounded in the README alone. Mass Editor searches notes across an Obsidian vault through a visual query builder with nested AND and OR groups and negation, then runs bulk edit operations on the result with backups and undo. The README records a two-phase search engine that reads note bodies only where metadata alone cannot decide a match, and fields covering tags, individual frontmatter keys, body, name, path, folder location and created or modified dates. Edit operations include frontmatter set, add, delete and append-to-list, moving a frontmatter key into the body, tag add and remove, body append and prepend, regex find and replace with capture groups, and removal of duplicate blank lines, with per-note placeholders such as title, path and formatted dates.
