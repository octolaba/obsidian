# TheShield2594/clawdia-obsidian-theme

Clawdia is a warm, gothic Obsidian theme with dark and light modes built on deep ink backgrounds, cream text and ember-orange accents. Its README pairs serif body typography with a sans interface font and styles code syntax, callouts, graph view node colours for focused, unresolved and tagged notes, canvas, tables, checkboxes, tags, modals and the command palette, down to slim scrollbars and a paw-print watermark on empty workspace panes. Shades below a middle step are derived at runtime with color-mix() from a single accent, so changing that accent in Style Settings recalculates them, and Style Settings can also hide the watermark and the heading ornament. The README records mobile support for the navbar and drawer and states that body and accent text were checked against WCAG AA contrast ratios in both modes.
