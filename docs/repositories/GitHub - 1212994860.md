# AgileSmagile/obsidian-graph-label-above

Graph Label Above is an Obsidian plugin that moves graph node labels above their nodes instead of below, so that an enlarged mouse pointer does not cover them. The README explains that Obsidian places labels below each node and shifts them a further 21 pixels down on hover, which hides them under a large pointer, and records that the plugin patches the node render method to flip the text anchor and negate the y-offset. It records support for the built-in 2D graph, for persistent labels in the 3D Graph community plugin by scaling the sprite offset, and for that plugin's hover tooltip through a bundled CSS snippet. Settings record a label distance slider from 0 to 200 percent and an optional colour override for 2D labels, applied without restarting Obsidian.
