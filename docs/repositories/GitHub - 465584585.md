# anpigon/obsidian-steemit-plugin

This plugin publishes the current note to Steemit. Credentials are added on the plugin settings page and can be verified there, after which the Publish to Steemit command uploads the page. Front matter carries post metadata such as categories, tags and a chosen permlink, and text surrounded by HTML comment markers is excluded from what is published while staying in the note.
