# codeisconfusing/retro-windows-obsidian

Retro Windows recreates the Windows 3.1 aesthetic in Obsidian, with its classic gray interface, 3D-effect buttons, blue title bars and pixelated charm, in both light and dark variants. It colour-codes folders, uses MS Sans Serif and Courier New for typography, restyles scrollbars, buttons and windows, and adds custom styling for code blocks, headings, lists and other markdown elements. Colours and fonts can be adjusted through variables at the top of the CSS file, and the README says Style Settings support may be added later. Atkinson Hyperlegible, JetBrains Mono and the Iconize plugin are suggested as optional companions.
