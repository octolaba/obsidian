# torusheadstudios/creation-ledger

The repository holds Creation Ledger, an Obsidian plugin for recording what is being worked on and where to resume it, using plain notes. A command palette entry opens a capture form with a title and a status, plus optional project and tags, and saves the entry as a note in a CreationLedger folder. The README addresses people who juggle several projects and stop and restart often, and who want structure without a rigid task system.
