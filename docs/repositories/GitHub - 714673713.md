# noxonad/obsidian-barcode-generator

Obsidian plugin that generates and displays barcodes from code blocks in a note, using the JsBarcode library. A plain barcode block renders with the default settings, a block whose name carries a barcode type such as code128 selects that symbology, and a barcode-custom block accepts options such as line colour, height and format above the content line. The README lists the supported barcode types, states the plugin works on mobile as well as on desktop, and notes that barcodes already on the page are not refreshed after the options change.
