# javierarce/arena-manager

Obsidian plugin that moves content between Obsidian and Are.na in both directions. Six commands cover creating a note for each block in a channel, pulling a specific block into the open note, pushing the open note to a channel or block, creating a note from a single picked block or from a block id or URL, and opening the selected block on the Are.na website. Channels may be the user's own, other people's public channels, or any channel URL. The README states that a personal access token with read and write access is required, since write access is what allows publishing back to Are.na.
