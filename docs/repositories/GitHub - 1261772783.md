# viggomeesters/obsidian-json-viewer

JSON Viewer opens json, jsonl and ndjson files in a dedicated Obsidian view as structured data, aimed at configuration files, logs, exports, API payloads and generated artifacts. It shows objects, arrays, strings, numbers, booleans, nulls and parse errors, parses JSONL and NDJSON record by record with per-line error reporting, filters the tree by key, value or JSON Pointer path, and adds an outline, expand and collapse controls, a raw view with line numbers, and buttons that copy raw JSON or a JSON Pointer. Large JSONL files render only their first 1,000 valid records, with further valid records counted and reported. The plugin is read-only by design so it cannot reformat, reorder or truncate a data file, makes no network requests, and writes to the clipboard only when a copy button is clicked.
