# pb-kh/underpowered-files

Underpowered Files styles files and folders in the Obsidian file explorer with bold, italic and strikethrough effects, toggled from the right-click context menu. A folder can be set to cascade, so its styles apply to every file and subfolder beneath it, while a child may override an inherited style or disable it explicitly. The README states that styles follow a file when it is renamed or moved, and that a single setting clears all styling rules at once.
