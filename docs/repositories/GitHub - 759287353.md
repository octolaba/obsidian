# kingwrcy/obsidian-mblog

No repository description is recorded, so this body is grounded in the README alone, which is written in Chinese. The plugin publishes a single article from Obsidian to the MBlog platform: the API is first enabled in the MBlog backend, which the README states is a paid feature not available to free accounts, an API token is entered in the plugin settings, and a note is published from its context menu. The README requires each article to carry front matter and documents the supported fields — a mandatory title plus optional link, publication date, tags and draft flag — and states that success or failure is reported by a notice.
