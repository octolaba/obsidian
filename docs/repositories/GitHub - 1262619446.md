# viggomeesters/obsidian-plist-viewer

PLIST Viewer opens Apple property list and mobileconfig files in Obsidian as a read-only view offering a typed tree, line-numbered source and a security summary for configuration profiles. Its README records parsing of XML plists into dict, array, string, integer, real, bool, date and data nodes, key paths with type badges, masked secret-like values, search and an outline, warnings for MDM, Wi-Fi credentials, VPN, certificates, restrictions, unknown payload types and profiles that disallow removal, and explicit fallback states for invalid XML, binary plists and large files. The security model is stated as inspect-only: the plugin never installs or activates profiles, performs no enrollment, provisioning, signing or trust decisions, and never writes these files back to disk.
