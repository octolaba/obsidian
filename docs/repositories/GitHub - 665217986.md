# Cutaiar/obsidian-song-links

Song Links connects Spotify to Obsidian for people who are inspired to write by music: an insert-song-link command adds a link to the song currently playing on the connected account at the cursor. Setup is installing the plugin, connecting to Spotify in its settings and then running the command in any note. The README records that Spotify approved a quota extension in June 2024, which made the plugin available to everyone rather than to a limited set of testers.
