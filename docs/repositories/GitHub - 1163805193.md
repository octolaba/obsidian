# nilsandrey/TextToolsPlugin

Local Text Tools adds roughly eighty text-manipulation commands to Obsidian's command palette under a common prefix, each applied to the current selection. The categories recorded in the README are case and format conversions, line operations such as sorting, deduplication, trimming, wrapping and joining, filtering lines by string or regular expression either in place or into a new note, encoding and decoding for URL, HTML entities, Base64, JSON and hexadecimal, incrementing or decrementing integers, generators for identifiers, random values, lorem ipsum, sequences and timestamps, table formatting and regex extraction, five persistent named clipboard slots, and line numbering. Some commands open a small modal to collect extra input, and the README states that everything runs locally in the vault.
