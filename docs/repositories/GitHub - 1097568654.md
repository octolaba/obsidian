# cjonesde/global-week-start

Sets the first day of the week for Moment.js so week calculations stay consistent for plugins that read Moment's locale week settings, such as Periodic Notes and Calendar. The README states the plugin works entirely in memory and modifies no notes, reapplies the chosen week start whenever another plugin calls the locale update function, and restores the original value when disabled. It was written in response to a reported problem where the Calendar plugin's week-start setting intermittently disappeared after a restart, leaving weekly notes on a Sunday layout.
