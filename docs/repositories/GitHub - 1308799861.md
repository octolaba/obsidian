# algiadev8/obsidian-retrieva

Retrieva is a Markdown-native spaced-repetition plugin that schedules reviews with FSRS while keeping card content, identifiers and review history in ordinary files inside the vault, so all card state can be rebuilt from Markdown without an external database. Questions and answers stay in their source notes through embedded headings or block ids, review decks are selected by tag with card counts and nested-tag support, a card can be skipped for the session without touching its history, and long-term suspended cards have their own view. Commands create forward cards or linked front and back pairs, directories can be excluded from indexing, malformed card metadata and JSONL review history can be validated and repaired, and the interface is available in English or Japanese. The README states support for desktop and mobile and requires Obsidian 1.13.0 or later.
