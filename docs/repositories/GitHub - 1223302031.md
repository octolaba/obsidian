# nikoneex/obsidian-kaper

Kaper renders a recipe kept in a Markdown file as a structured recipe inside Obsidian. A recipe note carries kaper: true in its frontmatter and a fenced kaper YAML block in the body; everything outside that block stays ordinary Markdown, the block renders in Live Preview and reading view, and source mode shows the raw YAML. A form editor covers title, servings, prep and cook time, tags, ingredient groups that drag to reorder, and steps with notes, tips, warnings and durations, saving on every change. A cook mode walks through the recipe one step at a time as a full-screen sheet on mobile or a dockable side panel on desktop, and a separate action opens the same recipe in the Kaper web app.
