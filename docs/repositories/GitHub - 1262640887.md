# wenciara/obsidian-pst-importer

PST Import reads Outlook PST mailbox files and converts their mail into Markdown notes in an Obsidian vault, so that archived correspondence becomes searchable and linkable knowledge-base content. The README describes two uses: a one-time import of a historical PST file, and an ongoing flow in which a lightweight staging PST keeps new mail arriving in the vault for further processing by AI plugins, offered as an alternative where Microsoft Copilot is not used. Its documentation is written in Chinese and English and records installation from the community plugin list, through BRAT, or by hand.
