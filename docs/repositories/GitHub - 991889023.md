# godfatherlg/fakelink

Creates links automatically from note titles, aliases and headings without writing them into the Markdown file: the links are rendered in the editor only, so the stored text stays plain. Such virtual links work in editing and reading mode, follow aliases, stay current as the vault grows, are kept out of the graph view and the backlink counts, and can be turned into real links from the context menu. The README records the plugin as a fork of Virtual Linker, continued because the original stopped being maintained and broke after Obsidian API changes in 2025, and lists as its own additions virtual links that point directly at a heading, better input method editor compatibility, improved stability and better behaviour inside tables. No repository description is recorded, so this note is grounded in the README alone.
