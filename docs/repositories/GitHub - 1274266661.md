# avnibilgin/custom-sidebar-width

The repository holds Custom Sidebar Width, an Obsidian plugin that sets the left and right sidebar widths per note from rules defined in its settings. A rule names a frontmatter property, a tag, or both as its trigger and a pixel width for either side, and an empty side is left untouched; when a note is opened the rules are tested from top to bottom and the first match applies. The README stresses that a property rule matches on the presence of the key alone, whatever its value, so the key can be added to a note with no value at all.
