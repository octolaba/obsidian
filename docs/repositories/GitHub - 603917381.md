# lizard-heart/obsidian-to-omnifocus

This repository holds Obsidian to OmniFocus, a plugin that extracts the tasks from the note currently open in Obsidian and creates them in OmniFocus. The README records one command run from the command palette, after which projects and tasks are assigned in an OmniFocus modal, and shows that unchecked checkbox lines are sent while lines already checked are not. It also shows a due date written after a marker at the end of a task line, and records a setting that marks the sent tasks complete in Obsidian.
