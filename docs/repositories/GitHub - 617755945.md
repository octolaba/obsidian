# Zachatoo/obsidian-css-editor

CSS Editor edits the CSS snippet files in the vault's .obsidian/snippets directory inside Obsidian, with syntax highlighting, code completion and basic Vim support, on desktop and mobile. Commands create a snippet, delete the active snippet file, and toggle its enabled state, while a quick switcher modal lists snippets and uses modifier keys to open in a new tab, create, toggle or delete the selected one.
