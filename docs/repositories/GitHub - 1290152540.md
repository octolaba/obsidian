# fcandi/obsidian-immich-journal

Inserts photos from a self-hosted Immich server into Obsidian daily notes. One command opens a picker showing photos taken on the daily note's date, resolved from the note title or a frontmatter field, falling back to the most recent day that has photos; selected images are inserted at the cursor, at the top of the note or at the bottom. Photos are saved as resized local copies with a configurable maximum edge, and embeds use simple presets or a custom template with Immich metadata variables such as description, time, city and camera. The README states an Immich API key with asset read and view permissions is required and that the plugin works on desktop and mobile.
