# a27856704/obsidian-team-plugin

Team Collaboration shares documents from an Obsidian vault to a team drive and allows several people to edit them at once, with the real-time editing built on Yjs. It also synchronises installed plugins and their settings across team members, generates daily and monthly team reports, and can summarise a document through an OpenAI or Claude API key configured in its settings. The README states that the team features require a self-hosted or third-party backend exposing REST and WebSocket endpoints, configured by server URL, optional WebSocket URL and an API token, and it documents the plugin's network usage in a dedicated section.
