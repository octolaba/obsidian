# zigholding/obsidian-notechain-plugin

Note Chain is an Obsidian plugin that gives notes a linear order alongside their existing links: each note names its predecessor and successor through the PrevNote and NextNote metadata fields, and notes sharing that relationship form a chain with a head note and a tail note. The plugin provides commands for creating and editing such chains and orders files in the File Explorer by the chain rather than by name. The README frames the motivation as linear output requiring linear input, since a mesh of dual-linked notes has to be rolled into one line before it becomes an article or a book, and its own description calls the collection highly personal tooling.
