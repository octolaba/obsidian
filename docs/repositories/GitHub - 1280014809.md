# slobbocampbell/obsidian-opml-editor

Obsidian plugin that opens OPML files in a dedicated editor which shows the outline as an interactive, collapsible tree. Nodes expand and collapse on a click, are renamed by double-click, and are added, deleted or reordered through a context menu and drag-and-drop, while a panel below the tree edits the selected node's attributes, including its type, feed and page URLs and any custom ones. A toolbar collapses or expands everything, adds a root-level node and switches to a raw XML view, and the file is auto-saved after a configurable debounce or manually with a keyboard shortcut. The editor is built on Obsidian's CSS variables, so it follows the active theme.
