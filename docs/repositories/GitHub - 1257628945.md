# J3F3H/sillage

Sillage integrates the Mistral Vibe command-line agent into Obsidian by spawning it as a subprocess, which the README says makes the plugin desktop only. It adds a sidebar chat that streams the agent's responses with Markdown rendering, visible tool calls, insert and copy actions and a stop button, plus note commands for summarising, extracting action items in Obsidian Tasks syntax, rewriting a selection and translating between English and French. Skills marked user-invocable under the vault's agent skills folder are registered as commands and rescanned when they change, and chat history and session identifiers survive a reload so later turns resume the same session, falling back to a fresh one when the old session has aged out. The README requires the Vibe CLI installed and authenticated and Obsidian 1.5.0 or later.
