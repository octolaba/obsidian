# 0126-hash/obsidian-smart-import

Repository for Smart Import, a desktop-only plugin that brings files from outside the vault in and converts them to Markdown. Its README lists entry points including a file picker, drag and drop, recent downloads, the current Finder selection, the clipboard and a natural-language lookup, and covers office documents, PDFs, web pages, data files, notebooks, archives, email, plain text and ebooks, with several external converters as fallbacks for ebook formats. It records that the repository was reconstructed from a deployed plugin bundle because the original TypeScript source was unavailable, so two files are the maintained source, and that macOS is the best-tested platform while Windows and Linux are not guaranteed.
