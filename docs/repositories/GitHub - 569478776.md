# dragonwocky/obsidian-tray

Tray runs Obsidian from the system tray or menubar, adding global hotkeys and a tray menu that toggle window visibility and create quick notes from anywhere in the operating system. Its configuration table records options to launch the app whenever the user logs in, minimise or hide it on launch, keep it running in the background instead of quitting when the close button or the focus hotkey is pressed, and hide the window icon from the dock or taskbar, with the note that the last of these may not work on Linux-based systems.
