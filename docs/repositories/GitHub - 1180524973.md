# thiter/obsidian-github-sync-multi-platform

Synchronizes notes across desktop and mobile devices through the GitHub REST API rather than a local Git installation, which the README gives as the reason it runs on iOS and Android without Git binaries. Auto-sync listens for file modifications with a five-second debounce to limit API usage, hash-based change detection is used to reduce conflicts, and binary attachments up to 10 MB per file are handled. Configuration takes a personal access token with repo scope plus the repository owner, name and branch, and the README is written in parallel English and Chinese sections.
