# johncattrall/obsidian-lapfly

johncattrall/obsidian-lapfly holds Lapfly, an Obsidian theme based on the lapfly.com colour scheme: a GitHub-dark foundation with an electric-blue accent and a racing-lime pop, shipping dark and light modes. The lime appears only in small touches, namely the active-tab indicator, checked task boxes, blockquote rules and link-hover underlines, and the README tabulates the palette by role for both modes. It records that theme.css overrides Obsidian's base colour scale, its brand colour hues and the HSL accent per light and dark class before adding component refinements.
