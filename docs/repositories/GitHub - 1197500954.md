# firstsun-dev/git-files-sync

Syncs individual notes or files selected from a folder, rather than a whole vault, with GitHub, GitLab including self-hosted instances, and Gitea behind one interface. Every push, pull and remote deletion shows a plan of additions, changes, moves and deletions before anything is written, renames and folder moves are committed as moves rather than duplicates, and a diff viewer compares local and remote versions with a separate tool for conflicts. A sync status view lists tracked files with live status, filtering and search, an optional folder tree with tri-state selection, and detection of files that exist remotely but were never pulled. The README records mobile support with a touch-friendly dashboard and three interface languages: English, traditional Chinese and simplified Chinese.
