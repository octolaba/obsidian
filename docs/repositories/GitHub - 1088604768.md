# mudnug/note-reader

Note Reader reads notes and clipped articles aloud, with an online voice provider and an on-device one recorded as the two options. An enhanced mode highlights each spoken word in edit and reading views and scrolls to follow it, while a lite mode plays audio only, aimed at mobile use with the screen off. Recorded controls include media keys, a resumed reading position and starting from a hovered line, and the text sent to speech can be filtered to skip frontmatter, code blocks, tables, headers, tags, URLs, images and custom phrases.
