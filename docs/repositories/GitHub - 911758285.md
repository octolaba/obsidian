# mbramani/obsidian-yt-video-summarizer

This plugin extracts the transcript of a YouTube video and generates a structured summary note from it using a large language model. The README records Gemini, OpenAI and Anthropic as supported providers along with any provider offering an OpenAI-compatible or Anthropic-compatible API, with the key entered per provider in the settings and an active model chosen from a dropdown; each provider arrives with preconfigured models that can be added to, edited or removed. The generated note carries key points, identifies and explains technical terms, and is formatted with metadata and tags. Obsidian v0.15.0 or later is recorded as the requirement.
