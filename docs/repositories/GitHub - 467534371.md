# kuchejak/obsidian-bible-linker-plugin

Obsidian plugin for linking several Bible verses at once. Its two commands copy the given verses out of Bible files in the vault and insert Obsidian links to them, or create links alone, from a reference such as a chapter and verse range; the README records that references spanning more than one chapter are not supported. Copied verses are joined into one block of text with invisible links placed after them, visible only in source mode and switchable off in the settings, and the plugin requires a Markdown Bible in the vault structured one file per chapter with each verse marked by a heading.
