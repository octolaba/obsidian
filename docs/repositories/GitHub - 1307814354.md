# rajalokan/obsidian-just-note-plugin

The README describes an Obsidian plugin that opens a note in a focused pop-out window without tabs, sidebars or the ribbon, while the window still holds a normal Obsidian file view so editing, reading mode, links, metadata and vault synchronization stay managed by Obsidian. It is invoked from the command palette, a file's context menu or the editor context menu, and a separate command assigns a colour that lives in the plugin's own data and applies only to these windows, leaving the Markdown file and its frontmatter unmodified. The plugin registers an obsidian URI identifying a vault and a note, which the README uses to build macOS Shortcuts launchers so that individual notes behave like separate applications.
