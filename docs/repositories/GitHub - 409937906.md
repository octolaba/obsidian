# timhor/obsidian-editor-shortcuts

Obsidian plugin adding keyboard shortcuts commonly found in code editors such as Visual Studio Code or Sublime Text. The README lists commands for inserting a line above or below, deleting, duplicating, copying and joining lines, expanding a line selection, adding cursors to selection ends, selecting a word or the next or all occurrences of a selection, and moving the cursor by word, line or line boundary, with several left unbound by default. A note at the top of the README records that the project is in a maintenance state, where only pull requests and critical bugs are addressed.
