# LeonYew-Ley/obsidian-artifact-embed

An Obsidian plugin that renders interactive HTML inside a note as a card, taking its content from a local file path, a remote URL or inline source, all through one artifact code block that detects which of the three the body is. Each artifact runs in an iframe sandboxed to scripts only, with no same-origin access to the vault, cookies or the parent window, and Obsidian's CSS custom properties are injected so the embedded HTML follows the current theme. The card carries a small toolbar to reload it, open it externally or copy its source, and rendering works in both Reading mode and Live Preview. The repository carries no description.
