# lazercaveman/obsidian-firefly-theme

Firefly is an Obsidian theme that its README describes as clean and minimal, with subtle colour accents and support for both dark and light modes. The README records slightly different styles for editing and reading, stated as combining the feel of a code editor while editing with a more blog-like feel while reading. It also documents an experimental feature called code-style tags, content blocks opened like code blocks but labelled with a tag such as _note.
