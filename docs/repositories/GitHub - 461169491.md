# ganesshkumar/obsidian-table-editor

Obsidian Table Editor provides an editor for Markdown tables and can open CSV data or data from Microsoft Excel, Google Sheets, Apple Numbers and LibreOffice Calc as Markdown tables from the Obsidian Markdown editor. The README's usage guide covers creating a new table, editing and formatting an existing Markdown table, converting CSV or spreadsheet data, and cell and header operations. A changelog entry records an update button and support for a popover window when the hover-editor plugin is installed.
