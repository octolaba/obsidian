# johansan/obsidian-featured-image

Writes a frontmatter property pointing at a thumbnail image for each note, taken from the first image, YouTube link or Auto Card Link found in the document. External images are downloaded into the vault and resized thumbnails are created, and complex wiki link syntax with captions and dimensions is handled. The property is updated while notes are edited or on demand from the command palette, and the README gives the main use as supplying an image property that Bases or Dataview can read. The README also records that Notebook Navigator has generated its own thumbnails since version 2.0 and no longer needs this plugin.
