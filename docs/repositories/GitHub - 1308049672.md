# theadamdanielsson/grill

Grill writes recall questions from the notes already in a vault, marks the answers typed back with partial credit, hints and specific feedback, and colors a separate learning graph as notes are proven, green for solid and amber for shaky, distinct from Obsidian's link graph. A session can be focused on a folder or tag from a study dropdown, weighted towards what keeps going wrong and what is due, with FSRS scheduling per concept and a button that opens what is ready for review. It reads the text of embedded PDFs as ordinary note content, asks a question written by hand in a grill callout verbatim, and points out notes that belong together but are not linked. The README states that the questions come from a model reached with the user's own key — Claude, GPT, Gemini, DeepSeek, any OpenAI-compatible endpoint or a local Ollama — or, with no key, from the structure of the notes alone.
