# meetjamie/obsidian-sync

Jamie Sync polls the Jamie public API with an API key and writes each meeting into an Obsidian vault as a Markdown note carrying frontmatter, a short-summary callout and action-item checkboxes, alongside a linked transcript file, the two joined by wikilinks. Three destination modes are offered: a dedicated folder, per-day folders, or appending each meeting as a section of the day's daily note. Syncing runs on a configurable interval, optionally at launch and on demand from a command, and it is idempotent, keyed on the Jamie meeting identifier with daily-note entries deduplicated by their heading; with re-sync of edited notes enabled, meetings changed upstream are detected by content hash and rewritten in place. The README records what is not implemented, including conflict handling for locally edited files and an instant webhook push path, and states that a paid Jamie plan is required.
