# dajhiro/obsidian-simple-homepage

Simple Homepage opens a designated note as a homepage the way a web browser does, treating a new tab and the homepage as separate concerns. The note is set by path in settings, opened by a command whether or not a tab already shows it, optionally opened on startup when Obsidian starts with only an empty tab, and reachable from a ribbon icon whose modifier keys open it in the current tab, a new window, a new tab or a new split. The README names an existing homepage plugin as likely covering what most people need, and records this one as one piece of a larger workflow its author has in mind.
