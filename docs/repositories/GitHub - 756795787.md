# ryanhalliday/obsidian-reverse-prompter

Reverse Prompter generates writing prompts with an AI model so the writer is questioned instead of doing the asking, which the README frames as an interested reader posing questions about the text so far. Running the command or clicking the icon takes either the current selection or the text from the cursor back to the last break — a header or horizontal line — and sends it to ChatGPT to request a prompt. It requires an OpenAI API key to be entered in the settings, and is reached from the command palette or the plugin's sidebar.
