# penyt/obsidian-style-obmd

Style Obmd adds a color key inside Obsidian's built-in highlight and bold Markdown syntax, so that a brace-wrapped letter at the start of a highlight or of bold text renders it in a chosen color in both Live Preview and Reading view. The seven colors — red, orange, yellow, green, blue, purple and gray — are configurable in settings, along with optional horizontal padding and rounded corners on highlights. Commands convert those markers in the current note or across the whole vault into HTML tags carrying inline styles, which the README presents as a way to keep the styling when notes are published as webpages; the underlying text stays valid highlight or bold Markdown if the plugin is removed.
