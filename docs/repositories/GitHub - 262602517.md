# jarodise/Dracula-for-Obsidian.md

Dracula for Obsidian.md is a dark theme for Obsidian, recorded by its README as compatible with Obsidian version 0.11.00. The README notes that the theme was selected as one of the built-in community themes and can also be installed by hand, by downloading an obsidian.css file into the vault root folder with the Custom CSS option enabled. It records jarodise as creator and maintainer and states that the CSS of its newest version is based on the Pisum theme by MooddooM.
