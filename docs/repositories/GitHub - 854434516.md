# amiaslee/obsidian-pintora

Obsidian-Pintora renders diagrams written in the Pintora language directly in the Obsidian editor. The README compares Pintora with Mermaid and PlantUML as a tool that generates diagrams by parsing its own language, and points to the Pintora language reference for the syntax. Recorded features are diagram creation from that syntax, copying a diagram to the clipboard as PNG base64, SVG XML or a PNG blob, and exporting a diagram to file formats including Markdown and PNG, with the rendering described as local.
