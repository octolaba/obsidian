# rmellmer/obsidian-link-range

Link Range is described as adding ranged link support to Obsidian. Its README says a wiki-link may name a range of headings rather than a single one, written as two heading names joined by a separator inside the usual wiki-link syntax, and that native backlink behaviour is retained. It supports the standard wiki-link form or other user-defined patterns, hover preview, and embedded content links. The separator string and the visual style of the heading separators can be changed in the advanced settings.
