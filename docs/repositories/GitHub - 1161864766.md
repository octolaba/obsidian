# ergesmema/obsidian-atline-ai

An Obsidian plugin that answers questions about notes inline: type a trigger such as @claude followed by a question, press the assigned hotkey, and the model's reply is inserted below it as a blockquote, callout, plain text or code block. Providers named in the README include Claude, Google Gemini, Ollama for local models, OpenAI and a dedicated chart agent, reachable either through direct API keys or through an installed CLI tool, with responses streamed as they are generated. Wikilinked notes can be pulled in automatically as context, and multiple agents with their own providers and system prompts can be defined. The README states the plugin is desktop-only because it uses Node.js APIs.
