# magnitus99/Superpower-Inside

Superpower Inside answers a question by searching across the vault's eligible notes instead of a single attached file, verifying the top ranges against the current files and following note links where needed before it answers. The README states that answers can carry checked source cards with line ranges and stated coverage limits alongside a visible work log, and that a result can be opened, copied or inserted back into a note. The model is the user's choice — OpenAI, Claude, Ollama, Ollama Cloud, OpenRouter or a custom OpenAI-compatible endpoint — and the README states that the plugin is desktop-only, free and open source with no paid tier and no feature paywall.
