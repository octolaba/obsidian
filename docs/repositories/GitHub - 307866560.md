# denolehov/obsidian-url-into-selection

Paste URL into selection inserts a URL into selected text with the ordinary paste shortcut, producing a link in the way the README calls notion-style. It also works the other way around, inserting text into a selected URL through a command-palette entry or a hotkey that has to be assigned manually. The README records compatibility with Obsidian v0.9.8 and later, since custom plugins are only available from that version.
