# johansan/pixel-perfect-image

Pixel Perfect Image adds a context menu on images in notes that shows the filename and dimensions and resizes the image to preset percentages of its size or to a custom width in pixels. The same menu copies the image to the clipboard, copies its local file path, shows it in Finder or Explorer, opens it in the default system viewer, and renames the image file. Images can also be resized by holding Alt or Option and scrolling over them, both wikilinks and standard Markdown image links are handled, and a modifier click opens an image in a new tab. The README lists interface translations in six languages.
