# ydd0729/obsidian-better-live-preview-image

Better Live Preview Image improves image editing in Obsidian's Live Preview by editing the image Markdown directly, so the notes remain readable without the plugin. It provides image alignment left, center or right from the context menu, the command palette or default hotkeys; click-to-reveal of an image's Markdown link in Live Preview with a selection frame and a resize handle in the lower-right corner; and application of Obsidian's width and height markers to images inside callouts in both Live Preview and Reading view. The README lists the commands and their default key combinations and points to Obsidian's Hotkeys settings for changing them.
