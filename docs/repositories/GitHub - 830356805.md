# GRA0007/obsidian-css-inlay-colors

CSS Inlay Colors shows a colour swatch beside any valid CSS colour written in an inline code span in Obsidian. A colour picker can be enabled to edit the colour in Live Preview, preserving the written format and any existing opacity while restricted to sRGB without opacity; clicking a colour in reading mode copies it, which can be turned off. Wrapping a colour in square brackets, or a global setting, hides the colour name and leaves only the swatch, and custom palettes are supported by exposing a class for each parenthesised inline code span so that a CSS snippet targeting the plugin's inlay class can define named colours, with six standard palettes downloadable from the settings.
