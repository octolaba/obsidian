# buisson-theme/obsidian

Buisson is an Obsidian theme with dark and light variants that, its README states, works out of the box without the Style Settings plugin. Its palette is six named accents, each with a separate dark and light value: hibiscus for headings and callout titles, sage for checked items and success states, river-moss for tags and links, slate-sky for callout borders and notes, thistle for operators and special syntax, and ochre for inline code and emphasis. The README records accessibility measurements, giving primary text as 11.55:1 in dark mode and 15.15:1 in light mode and placing all six accents at WCAG AA or above. It presents the theme as one part of a wider Buisson ecosystem.
