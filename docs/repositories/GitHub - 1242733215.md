# ksawl/obsidian-smart-tabs

Repository for Smart Tabs, a plugin that opens files in a new tab by default and, when the file is already open, focuses that tab instead of creating a duplicate. Its README states that this applies to the file explorer, the quick switcher, internal links, bookmarks and calls through the API, and to Markdown, canvas, graph, image, video, audio and PDF files. Deduplication and the delay before a tab event is processed are configurable, the plugin is recorded as desktop only and requiring Obsidian 1.8.9 or later, and it is described as a fork of another new-tab plugin.
