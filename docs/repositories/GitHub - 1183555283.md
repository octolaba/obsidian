# nyaaas/visual-flashcards-obsidian

Visual Flashcards reads cards from a note written as question and answer line pairs, ignoring any other content in the file. A panel shows one card at a time with a flip animation, scoring for remembered and missed cards, an end screen with the score percentage and the cards needing practice, an immediate retry of the missed ones, and a shuffle mode. Session history is kept per note for the last ten sessions, and the README records desktop and mobile support with no external dependencies.
