# technohiker/obsidian-multi-tag

Multi-Tag is an Obsidian plugin that adds a tag to every note in a folder: right-clicking a folder offers the action, a prompt asks for the tag, and it is appended to each note inside, and the same works on a multi-file selection made with Shift and the mouse. A setting chooses between writing tags into the YAML frontmatter as a property, which checks for duplicates, and appending them inline at the bottom of each note, which does not. The README states that the plugin remains functional but that its author is focusing on obsidian-multi-properties instead, which covers similar ground, and that Multi Tag stays available for inline tags.
