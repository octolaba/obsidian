# reflector-li/Vocalog

Vocalog is an Obsidian plugin for audio transcription and AI-assisted note generation. The README describes automatic transcription through a Whisper-compatible speech-to-text endpoint, summaries from an OpenAI-compatible chat model with a customisable system prompt, writing into daily notes, batch processing over a date range with a calendar for selecting dates, and commands for today's audio, a date range, selected files or a right-clicked audio file. On data use it states that audio is sent to the configured speech-to-text endpoint and transcripts to the configured summarisation endpoint only when a command runs, that API keys are stored in the plugin's local settings, and that no analytics or telemetry are collected.
