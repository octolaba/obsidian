# sbridel/carnet-du-poete

The repository records no description, so this body rests on the README alone. The README describes a side-panel companion for writing French verse: syllables are counted line by line with a full scansion breakdown following the classic rule for the silent e, the metre and the rhyme's gender are detected, and a word with an ambiguous hiatus is shown both as the default synerese reading and, on a second line, as the dierese split, leaving the choice to the writer. It also documents rhyme-scheme detection over blank-line separated stanzas, labelling end rhymes A, B, C and naming four-line stanzas that match AABB, ABAB or ABBA. Further features are a rhyming dictionary, thematic vocabulary, synonyms and antonyms with optional live lookup from external sources, and a reference on French versification; the README states the core features need no internet connection.
