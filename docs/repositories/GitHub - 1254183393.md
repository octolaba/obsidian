# Xheldon/Obsidian-Better-Calendar

The repository records no description, so this note is grounded in the README alone. Better Calendar is a space-efficient calendar pane for Obsidian that reads the core Daily notes settings — folder, date format and template — marks days that already have a note with a dot, and opens a day's note on click or offers to create it from the template, expanding placeholders such as `{{title}}`, `{{date}}` and `{{time}}`. Its layout renders days by week and wraps weeks left to right so a wider or taller pane shows more months rather than one stretched month, with each day cell held between a minimum and maximum size, and today's week placed on the third row by default so recent weeks stay visible.
