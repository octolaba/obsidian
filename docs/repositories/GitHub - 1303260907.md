# ArshiaEcho/obsidian-granola-api-sync

Granola API Sync imports Granola meeting notes and full transcripts into an Obsidian vault through Granola's official public API, which the README contrasts with earlier integrations that borrowed the desktop app's encrypted local credentials. A key created in the Granola desktop app is pasted into the plugin settings with a notes folder and a sync interval; the README states that API keys require a Granola Business or Enterprise plan and that the key is the only thing stored, locally in the vault. Each meeting yields a note plus a linked transcript note of timestamped, speaker-labeled turns, keyed by granola_id so re-syncs update in place and notes from other Granola sync plugins using the same convention are adopted rather than duplicated.
