# junghyunbak/graph-unread-highlight

Graph Unread Highlight is an Obsidian plugin that draws a ring around notes in the graph view that are new or have been edited since they were last opened, with a command to mark everything as read. The README records the state being kept as a path-to-timestamp map in the plugin's own data file, never in the notes: a note is unread when it has never been seen or its modification time is newer than the recorded time, and it becomes read when opened or when the mark-all command runs. The ring is drawn on the graph canvas itself as a hollow shape sized to the node, so it tracks panning, zooming and simulation movement and leaves node colours and colour groups untouched. Settings record the ring colour, gap, thickness, an optional soft glow and an optional pulse; the README states it works in the global and local graphs and relies on internal renderer APIs.
