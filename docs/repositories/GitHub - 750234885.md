# noradroid/obsidian-git-integration

This repository holds Git Integration, described upstream as an Obsidian plugin that adds git integration. The README says a git menu opened from a ribbon icon offers init, commit and sync, that initializing asks for the remote repository address, that committing takes a message and is equivalent to staging everything and committing, optionally pushing straight afterwards, and that syncing pushes new changes to the remote. It states that the plugin works on Windows 10 and later and requires Git to be installed on the local system.
