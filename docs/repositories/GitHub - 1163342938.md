# Konoyo-014/obsidian-live-preview-bold-fix

Obsidian plugin that stabilizes two rendering behaviours in Live Preview without rewriting note content. It targets inconsistent bold rendering around punctuation and brackets in mixed CJK and English text, and the preview-layer rendering of paren and bracket LaTeX math delimiters. The bold fix works as a deterministic decoration layer for strong text and marker visibility near the cursor, while the math path reuses Obsidian's built-in math widget for visual consistency. Because it operates at the CodeMirror decoration layer, the README notes that compatibility depends on other editor-rendering plugins patching the same ranges.
