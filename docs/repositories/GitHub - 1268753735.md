# istefox/obsidian-bookmarker

Bookmarker saves a web page into an Obsidian vault as a Markdown note carrying a preview image, proposed tags and a proposed destination subfolder. Capture comes from a companion browser extension, from inside Obsidian, or on iOS from the Share Sheet through an Apple Shortcut, and a review window lets the title, tags and destination folder be edited before the note is written. A classifier proposes the tags and folder while reusing those already present in the vault, and the README states an offline heuristic mode works with no API key. Preview images come from the page's Open Graph image and can instead be stored in the vault, and the README states that everything stays inside the vault with no backend of its own.
