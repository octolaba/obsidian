# Telehakke/jisage-japanese-indentation

The recorded description says only that this is an Obsidian plugin. Its bilingual English and Japanese README explains that the plugin makes jisage — indenting with a full-width space at the beginning of a line — display correctly, and that it works as soon as it is enabled. The README records a rename made to comply with the new plugin guidelines, and one known issue: after an edit that only adds or removes a leading full-width space in an existing sentence, the change may not appear when switching to Reading mode, which it attributes to Obsidian itself and works around by reopening the note.
