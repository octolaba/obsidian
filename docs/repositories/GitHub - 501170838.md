# jensmtg/obsidian-diagrams-net

Obsidian plugin for inserting and editing diagrams.net, formerly draw.io, diagrams. The README states that it differs from the drawio-obsidian plugin by embedding the online diagrams.net editor, which requires an active internet connection but enables the full feature set and all the shape libraries. Its caveats record that a diagram is stored as a separate XML file beside its image, that moving or renaming inside Obsidian handles both files while copying does not, because the API exposes no copy event, and that editing a diagram may not update its preview. A warning at the top says the author cannot find the time to maintain the plugin and that issues will not be read.
