# farling42/obsidian-import-json

The repository holds Import JSON/CSV, an Obsidian plugin that creates a set of notes from a table, one note per CSV row or per object in a named array inside a JSON file. Its README records a dialog opened from a ribbon icon that takes a local JSON or CSV file or a URL to fetch JSON from, a Markdown file serving as a Handlebars template, and optionally a JavaScript file supplying extra Handlebars helper functions. It is written in TypeScript under the MIT license.
