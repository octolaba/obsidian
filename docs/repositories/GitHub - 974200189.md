# insile/OpenWords

OpenWords is a plugin for learning and managing English vocabulary in Obsidian, built around the OpenText word library where each word is its own file and its attributes live in the file's properties. Its functions cover generating index files, reviewing words, writing them from memory and adding links between notes, with review scheduling based on the SuperMemo 2 spaced-repetition algorithm. Because no answer history is stored outside the word files, scheduling depends only on the last recorded answer, and the README directs users to Obsidian's built-in search instead of a search feature of its own.
