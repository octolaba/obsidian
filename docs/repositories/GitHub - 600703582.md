# hamsterbase/obsidian-hamsterbase

This plugin exports highlights from HamsterBase into an Obsidian vault, and its README states that it can only be used with a HamsterBase installation to depend on. No repository description is recorded, so this body rests on the README alone. Its settings take the HamsterBase API server entrypoint, an API token and the folder that receives the highlights, after which a command palette entry synchronises them.
