# shaunhurryup/lovely-mindmap

Lovely-Mindmap is an Obsidian canvas plugin for building a knowledge graph, which its own README describes as named after mindmaps but not limited to them. Keyboard shortcuts create a child node, a sibling node or a sibling before the current one and zoom to fit, blur the selected node to start navigating, and move between nodes with a modifier and the arrow keys. The README declares three views — touch with no node selected, navigation with one or more nodes selected, and creation with the cursor inside a node — and states that further multi-node interactions such as layout are expected to follow.
