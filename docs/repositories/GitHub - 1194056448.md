# AbdelrahmanHafez/obsidian-cursor-history

The repository holds Cursor History, an Obsidian plugin that records cursor positions across files and navigates back and forward through them, in the manner of the corresponding editor commands in VS Code. Movements below a ten-line threshold update the current entry while larger jumps create a new one, and the stack behaves like a browser history: moving somewhere new after going back discards the forward entries. The README states that the history is session-based and capped at fifty entries, and that default keybindings are installed on first use.
