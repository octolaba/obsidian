# basham/obsidian-alias-from-heading

Obsidian plugin that implicitly adds an alias matching the first heading of a note, whatever the level of that heading. The heading alias is used wherever YAML aliases are used, such as linking to a note by alias or finding unlinked mentions, and both the Wikilink and Markdown link formats are supported. Updating the first heading changes only those links whose display name matched the heading, so a display name stays in sync by default while remaining customisable for a particular context; aliases defined in YAML keep their standard behaviour and do not affect this plugin.
