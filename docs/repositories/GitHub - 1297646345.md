# 2easy/nudge

Nudge is a task manager backed by a single plain-text todo file, with a custom view offering a Today filter and one list per project tag plus a configurable pinned default list. Items are created and edited through a structured modal covering text, list, due date, priority, link and recurrence rather than hand-typed syntax; completing a recurring item creates its next occurrence anchored on the original due date, and drag and drop reorders items or moves them between lists. Every change is a read-modify-write against the file, so edits made outside Obsidian appear automatically. The README records the plugin as desktop-only on macOS and passive by design, with no operating-system notifications and an optional dock badge counting overdue tasks.
