# jason-lieb/obsidian-browser-interface-plugin

This plugin pairs with a companion Chrome extension to manage browser tabs from inside Obsidian, displaying the tabs saved by the extension and creating buttons to reopen and delete them. The README states that it depends on the Meta Bind plugin, recommends pairing it with the Advanced Tables plugin, and requires three file-system-access flags in Chromium or Brave along with a directory set in both the plugin settings and the extension. Its documented limitations are that opening and deleting a tab work by clicking the row and then the button, and that the buttons do not work in reading mode.
