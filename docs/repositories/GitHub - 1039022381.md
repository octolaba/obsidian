# Hayyan0/Obsidian-Arabic-Poetry-Formatter

An Obsidian plugin that reformats selected Arabic poetry into two classic layouts: a paired format aligning the two hemistiches of a verse on one line with a central gap, and an indented format placing the second hemistich on a new line aligned to the end of the first. Alignment combines character counting with visual width estimation so that proportional Arabic fonts still line up. Gap width is set independently per mode, and the formatters are reachable from the command palette, the right-click context menu, and a ribbon icon whose default action is configurable.
