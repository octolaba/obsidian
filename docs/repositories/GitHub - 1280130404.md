# shabbirpatheria/folder-routines

This plugin renders a checklist in an Obsidian daily note from a folder structure and logs dates into the routine notes behind it; the README presents it as Pixel Habits, a retro 16-bit styled habit tracker. A root folder is pointed at, each subfolder becomes a collapsible section and each note inside becomes a checklist item, and a routines code block in the daily note renders them; ticking an item appends that note's date to the entries frontmatter property of the routine note, and unticking removes it. A routine note may declare subtasks in its frontmatter, which render as nested checkboxes kept in sync with the parent in both directions and recorded per subtask in a plugin-managed property. A separate stats code block draws a character-sheet style board per section over the last 21 days with streaks, a rank badge, completion percentage, a heatmap, weekly milestones and a trend.
