# community-archive/obsidian-zotero-integration

Zotero Integration inserts and imports citations, bibliographies, notes and PDF annotations from Zotero into Obsidian. It requires the Better BibTeX plugin for Zotero, and the troubleshooting notes add that a quick copy style has to be selected in Zotero before citations and bibliographies work. The README describes its own documentation as currently incomplete.
