# aitingtingya/mv-obcc

This repository holds mv-AIDE, a desktop-only Obsidian plugin documented in Chinese that turns the vault into an AI IDE, bridging Claude Code, the Codex CLI and any MCP-capable agent to the local knowledge base. The README records that it supplies those agents with Obsidian context such as the current tab, the selection and open files, exposes eight IDE tools and an editable diff review, and adds selection-triggered streaming model calls into a floating window, ghost-text inline completion, and a full system terminal using PTY on macOS and Linux and ConPTY on Windows. It also records registering non-markdown extensions such as .tex as Markdown views with snippets, source highlighting and lint diagnostics, a default file opener for markdown and source files, multi-provider API management, and a requirement of Obsidian 1.7.2 or newer.
