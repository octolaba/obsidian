# eldritch-theme/obsidian

Eldritch is described as a community-driven dark theme inspired by Lovecraftian horror, with tones from the dark abyss and an emphasis on green and blue. Its README points to a separate main theme repository from which this Obsidian port derives. Installation is documented from the appearance settings, unchecking light themes only and searching for Eldritch.
