# 30jannik06/Obsidian-Presence

Shows Obsidian activity on Discord through Rich Presence: the vault name, the current file, edit or reading mode and an elapsed timer, with canvas files tracked as well and auto-reconnection if Discord restarts. The README describes a pause mode reachable from the status bar, the settings or the command palette, idle detection that shows an away state or clears the presence after a configurable timeout, and an exclusion list of files or folders supporting glob patterns. The status text is composed from placeholders for file, folder, vault, mode, word count and line count, and a custom Discord application client id can supply the images and up to two profile buttons.
