# adamkdean/standard-plus-obsidian-theme

Standard Plus is the stock Obsidian theme with quality of life additions. The README lists custom folder icons with separate closed and open states, folder indent lines removed for a cleaner appearance, a pointer cursor on interactive elements, and support for both light and dark modes.
