# AndyZhengyan/obsidian-dedao-brain-sync

Syncs ideas, excerpts, links, recordings and generated summaries two ways between the Dedao Brain service, formerly Get Notes, and local Markdown files. Downloads can run incrementally, by date range, by selected note, by knowledge base, on a timer or at startup with a resume point, and local Markdown files can be uploaded back to the service. Two authentication modes are offered: an open-platform mode the README states requires a paid membership, and a temporary web-session mode for trying the plugin out. Notes are filed by type with configurable naming and frontmatter, audio and transcripts are stored when the API returns them, a sidebar offers full-text search over remote notes, and a log records each sync's mode, parameters, filters, duration and per-note outcome.
