# mr-asa/obsidian-checkers-hider

This repository holds Checkers Hider, an Obsidian plugin that hides completed and custom-status checklist items from view without altering the notes. It hides checked tasks by default and can be configured with other single-character markers, with the marker list read either as the set to hide or as the set to keep visible, and it can optionally hide bullets nested under a hidden task. Hiding is toggled from a command, a status bar icon or an optional ribbon button, may be suspended while editing while still applying in preview, and can be disabled per page by an inline or frontmatter tag. The README lists the views it was tested in, among them reading view, source mode and Live Preview, hover popovers, Kanban boards, Canvas cards and Dataview task lists.
