# Kevger/obsidian-laws-of-form

The repository records no description; its README presents a plugin that transforms linear Laws of Form bracket expressions into their two-dimensional graphical representation, assuming the reader already knows the formalism. Expressions are written in fenced blocks tagged lof, where a pair of parentheses marks a cross, text inside a space is that space's content, and crosses may be nested. Re-entries are written as a pair of identifiers, one marking the space that enters and one marking its target, with multiple re-entries and a space entering two locations both supported subject to stated limitations. The README notes that plain text or separate expressions on the same line must be explicitly separated, which is also what equations require.
