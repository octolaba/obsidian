# dustinkeeton/obsidian-synapse

Synapse uses AI providers — OpenAI, Anthropic, Google Gemini and local Ollama — to maintain a vault: it finds stub notes and proposes expansions, transcribes embedded audio and linked video, enriches notes with tags, internal links and references, summarises, corrects formatting, reorganises the folder structure and expands topics into interlinked trees. Every change passes through a proposal review in which each suggestion is accepted or rejected, with checkpoints for undo, and the README states that nothing is written to the vault without approval. Audio goes through the OpenAI Whisper API, Deepgram or a local Whisper install; YouTube is transcribed caption-first over plain HTTP and so works on mobile, while captionless videos, TikTok and Instagram fall back to a desktop pipeline built on yt-dlp and ffmpeg.
