# pranjulsingh/obsidian-flat-financing

Flat Financing is a finance tracking plugin for Obsidian that reads and writes plain-text Beancount files kept inside the vault, so the data stays local. It renders dashboards for net worth over time, cumulative expenses, income against expenses and account distribution, and supports monthly expense targets and progress toward savings goals. Accounts and transactions are added, edited and deleted through modals rather than by typing syntax, and results can be filtered by wildcard account patterns, tags and date ranges. A privacy toggle masks balances, tables export to CSV or Markdown, and the layout is built for the mobile app as well as the desktop.
