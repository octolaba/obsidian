# arg1998/obsidian-svg-styler

SVG Styler modifies the style properties of an SVG image embedded in a note — colour, border and opacity among them — from a command run in the palette while the embed is selected. The drawable tags it supports are path, line, rect, circle, ellipse and polygon. Its options are to write the new properties into the original SVG file, to save a duplicate carrying them, or to clear the existing styles.
