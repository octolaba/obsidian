# totocaster/triage-obsidian

Triage collects notes that were never processed into a queue of cards and asks for one quick decision per card, so loose material such as fleeting notes, clippings and untagged captures gets reviewed instead of disappearing into the graph. Each card shows the note's actual content rather than a bare title and expands in place to a rendered body, and the four decisions are keep, which marks the note through frontmatter, a tag or a chosen value without moving the file, snooze, which writes a plain due date so the note returns when it arrives, delete, which hands off to Obsidian's own delete prompt, and open. The README states that the plugin is not a spaced repetition or flashcard tool, having no scheduling algorithm, no ease factors and nothing to memorize. Field names and snooze intervals are configurable, and review is keyboard-first with every action also exposed as a command.
