# stephendolan/obsidian-calendar-event-sync

Replaces the title and the opening content of the current note with data from a calendar event. The README documents two commands: one syncs with the closest event, preferring an event happening now, then an upcoming one, then a recent one, within time windows set in the settings; the other opens a list of past, current and future events to choose from. A calendar ICS URL is required and only a single URL is supported as an event source. Optional settings give the calendar owner's email so that declined events are skipped, a list of event titles to ignore, and the hour and day limits used by the quick sync and the selection modal.
