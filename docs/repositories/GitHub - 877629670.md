# Fleker/trakt-for-obsidian

This plugin syncs Trakt check-ins into a file in Obsidian, writing a bulleted watch history with date-specific backlinks so that films and episodes can be tracked along with when they were seen. The README shows the entries produced by a sync command in a Trakt rating history note, including ratings and finished episodes linked back to their daily notes. Setup requires creating a developer application on Trakt and saving its API keys in the plugin settings, with a redirect URI in Obsidian's own scheme.
