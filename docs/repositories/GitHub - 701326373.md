# mahmudz/obsidian-favorite-plugin

Marks individual notes as favourites directly in the note list, showing a heart icon when a note is hovered. The README contrasts this with the core Bookmarks plugin, which it describes as aimed at general navigation and linking, whereas this plugin is meant for flagging and reaching specific notes.
