# ytahml/obsidian-image-manager

Markdown Image Manager works over a vault's images: a browser covering local and hosted images with reference-status filtering and guarded orphan cleanup, compression through the Canvas API, renaming that updates every reference, and organisation of image files into archive paths built from a template. Uploads target Aliyun OSS, Qiniu, S3 or a custom endpoint, on paste, for one note or across the whole vault, with a custom reference template and card browsing of the remote buckets. The README records that the plugin assumes standard Markdown image references, that it can batch-convert wiki-style embeds into that format but not the other way, and that its interface is available in Chinese and English.
