# seongchan/DailyWorkLog

Repository for Daily Work Log, an Obsidian plugin that reads time blocks and to-do lists out of daily Markdown notes and draws them in a sidebar. Everything is parsed from three plain headings — Event, ToDo and Diary, with Korean spellings and the legacy underscore-prefixed forms still recognised — so the README states that no YAML frontmatter is required. The sidebar carries a ten-minute-cell grid for logging and editing blocks, colour-coded categories written as a bracketed tag in the note body, a collapsible to-do panel, HTML or PDF export, and a vault-wide dashboard of totals, streak and completion rate.
