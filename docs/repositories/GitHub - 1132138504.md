# Marco-Pozzecco/mnemoloop-plugin

Mnemoloop is a spaced repetition system for Obsidian that stores every flashcard as its own Markdown file in a dedicated directory, linked back to its source note through YAML frontmatter instead of markers embedded in the note itself. Scheduling uses FSRS, and a dashboard shows heatmaps, a deck tree, daily goals and retention rates, with swipe-to-rate layouts for use on mobile. The README describes the plugin as local-first, with core features working offline and no telemetry, and records a dual-source design in which a JSON index answers queries while the per-card frontmatter can rebuild that index; those are the project's own statements.
