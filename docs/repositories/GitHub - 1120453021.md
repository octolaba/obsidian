# valenzine/obsidian-url-name-extractor

URL Name Extractor is an Obsidian plugin that retrieves HTML titles in order to name raw URL links; the description presents it as a modernised fork of obsidian-url-namer by zfei. The README says a command names the URL links inside the selected text and warns against changing the selection or the text while the requests are running. Its changes over the original include a more liberal URL-detection regex that is configurable in settings, a request strategy that adds complexity only when needed to avoid anti-bot systems, per-site title regex patterns for pages with non-standard markup, and Archive.org and Microlink fallbacks.
