# seavalanche/vesnea-obsidian-theme

Vesnea Vibe is an Obsidian theme whose color palette follows Seavalanche's Project Sea Web theme colors. The README describes it as simple and light, changing little from the default Obsidian theme while keeping text readable, and adds formatting perks such as italic text colored green. From version 1.2.0 onward it also divides the file tree by what is active or in focus, clarifies properties metadata and workspace tab buttons, and shows heading formatting in edit mode; Josefin Sans and Work Sans are bundled as the text and interface fonts.
