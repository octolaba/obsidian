# finnromaneessen/obsidian-sankey

This plugin renders Sankey diagrams from a code block using the sankey language, in which links and nodes are described in YAML. A link carries a source, a target and a value, and a value written as a question mark is inferred from conservation of flow, resolvable as long as it is the only unknown on one side of a node; chains of such unknowns can resolve one after another, and an error is shown in place of the diagram when a value cannot be resolved. Nodes need only be declared explicitly to give them a colour, since any node not declared is inferred from the sources and targets of the links.
