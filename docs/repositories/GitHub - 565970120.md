# JonasDoesThings/obsidian-hide-folders

This plugin hides configured folders in the Obsidian file navigator and lets their visibility be toggled back on, which the README suggests for attachment folders that are not always wanted. Folders are listed one per line in the settings and matched by exact name, or by prefix and suffix through the `startsWith::` and `endsWith::` forms. The visibility toggle is also available from a sidebar button and from the command palette, without opening the settings.
