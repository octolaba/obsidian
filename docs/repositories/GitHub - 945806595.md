# stefandanzl/webviewer-bookmarks

Web viewer Bookmarks stores website bookmarks for use with Obsidian's built-in web viewer. Bookmarks are added, edited, deleted and given icons in the plugin's settings tab, where each one can also be exposed as a ribbon icon for one-click access or as a command in the palette; icons are named after entries in the Lucide icon set. A bookmark URL may carry a selection placeholder that is replaced by the currently selected text, and the README notes that Obsidian must be reloaded before bookmark changes take effect.
