# Everblush/Obsidian

This repository holds the Everblush theme, described as the Everblush colour scheme for the Obsidian Markdown editor. Its README is a set of preview images plus installation, either by adding obsidian.css to the themes directory or by searching for Everblush under the appearance settings. Mode support, palette values and customization options are not recorded in the description or the README.
