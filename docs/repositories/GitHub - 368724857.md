# caronchen/obsidian-chartsview-plugin

Charts View renders plots and graphs from code blocks in a note, built on a third-party charting library. An insert-template command supplies starting blocks for chart types including pie, word cloud, treemap, dual axes, mixed, bar, organization tree graph, radar and tiny line, along with word-count charts computed over several files, all files or a folder. Data can come from the block itself, from an external or an internal CSV file, or from the Dataview plugin through an allowed set of methods, and search interaction can be enabled on a chart.
