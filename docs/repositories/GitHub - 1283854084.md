# ozephyr-ctrl/csv-quiz-practice

The repository holds a CSV-based quiz practice plugin for Obsidian, which reads a question bank from a CSV file in the vault and opens a practice panel from a ribbon icon or a command. The README specifies the file as UTF-8 with a byte order mark and fifteen columns holding a numeric identifier, the question stem rendered as Markdown, four options, the correct letter, space-separated tags, a three-level category hierarchy for filtering, and flags for favourited, mastered, repeated and previously wrong questions. Its interface and documentation are bilingual Chinese and English, and it tracks the share of correct answers.
