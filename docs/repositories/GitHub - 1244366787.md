# free-solo-lab/obsidian-readwise-tracker

Tracks reading progress and manages a Readwise Reader library from inside Obsidian, syncing documents through the Readwise API into a dashboard with a daily activity heatmap, current and completed books with progress and remaining-time estimates, and reading timelines for regular books, EPUBs and PDFs. Clicking a book on the dashboard filters the heatmap to its activity and opens its highlights in the right sidebar. URLs can be saved and EPUB, PDF, HTML, TXT or Markdown files uploaded to Reader, existing or new Reader tags applied, and books deleted permanently behind an explicit confirmation with local cleanup. It also supports a Zettelkasten-style pass over highlight notes, moving fragments into inbox notes that keep links back to the source book, highlight and reading context.
