# neozhang/you-and-your-research

You and Your Research consolidates research steps that the README says usually span search engines, AI chats and file explorers into Obsidian, so that retrieving and reading long-form material does not require switching contexts. The README records that an OpenAI API key must be supplied in the plugin settings, that a custom endpoint may be given for a self-hosted or compatible API, and that the model can be gpt-3.5-turbo, gpt-4o or a custom model name. It optionally uses Jina AI, with the user's own key, to extract the content of the web pages being read, and it notes that the plugin's name comes from Richard W. Hamming's 1986 talk.
