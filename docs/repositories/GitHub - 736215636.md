# JinmuGo/obsidian-go-up

This repository holds Go Up, described upstream as quickly navigating to a specified parent page. The README says the parent is declared in the note's frontmatter under an up property, as one link or a list of several, and that two commands are provided: one replaces the current note with the parent, keeping the note open when it is pinned and focusing an existing tab rather than duplicating it, and one opens the parent in a new tab beside the current note.
