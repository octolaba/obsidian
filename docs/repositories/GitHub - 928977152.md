# Devon22/obsidian-gridexplorer

GridExplorer browses the notes and folders of a vault in a grid view, opened from a toolbar icon, from a folder's right-click menu or by command. Beyond the folder mode with its subfolders, the grid can show bookmarks, search results, backlinks, outgoing links including media files, all files, the most recently modified files, a random selection, or a custom set described with Dataview query syntax. Sorting works by name, by modification time, randomly or per folder, and grid item width and the default sorting are configurable. The README lists the image, video, audio and document formats that are displayed, describes folder notes created from a folder's right-click menu, and records interface support for English, Traditional and Simplified Chinese and Japanese.
