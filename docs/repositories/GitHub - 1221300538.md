# binhong87/obsidian-note-agent

Repository for Smart Note Agent, an assistant that reads vault notes and, with the user's approval, changes them. Its README describes a multi-turn tool-calling loop with tools for full-text search, reading notes, listing folders, following backlinks and outgoing links and reading the active note or selection, and three modes: a read-only one, an editing one where every create, edit, delete or move is shown as a diff for approval, and a scheduled one with restricted write access for automated daily summaries and weekly reviews. It lists many providers including OpenAI, Anthropic, DeepSeek, Qwen, Kimi, Zhipu, MiniMax, OpenRouter and local Ollama, each with its own saved profile, and records that conversation history is compacted as it approaches the model's context limit.
