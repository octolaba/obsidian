# ScottKirvan/GitHubDHC

GitHubDHC is a theme for Obsidian inspired by the GitHub Dark High Contrast colour scheme. Its README explains that the author writes Markdown mainly for GitHub, was frustrated by formatting that did not map well between the two, and started from krios2146's Obsidian GitHub theme. It records that the result looked different enough from that theme to be published as a separate fork rather than as changes to the original.
