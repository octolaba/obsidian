# usero2/obsidian-plugins-auto-close-oldest-tabs

An Obsidian plugin that caps how many tabs stay open in the main workspace and closes the least recently used one whenever a new tab pushes the count past the configured limit, which the README gives as three by default. An option forces links and files to open in a new tab rather than replacing the active one, so navigation accumulates tabs until the limit takes over.
