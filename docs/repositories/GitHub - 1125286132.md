# Amato21/nldates-revived

This repository holds Natural Language Dates (Revived), an Obsidian plugin for working with dates written in natural language, presented in the README as a revived version of the earlier plugin of that name with a new engine and multilingual parsing. Languages are enabled in the plugin's language settings and several can be active at once, with the autosuggest and the parser understanding all of them simultaneously. The README grades support per language, listing English, French, Spanish, Italian, Russian, Ukrainian and Japanese as full, Chinese, German, Portuguese and Korean as partial, and Dutch as under development, and notes that the partially supported languages have no chrono-node parser to fall back on.
