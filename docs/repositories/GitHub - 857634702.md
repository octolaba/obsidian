# anareaty/html-checkboxes

Inserts HTML checkboxes into a note through a command or the editor menu and makes them clickable, which the README motivates by the fact that they can sit inside Markdown tables and anywhere in a line, and that they stay visible if the plugin is turned off. Each checkbox carries a unique id that clicking depends on, so duplicated ids break it; a setting rewrites ids automatically on pasting and a separate command repairs every checkbox in a file. Right-clicking a checkbox offers a limited set of alternate checkboxes, which need theme or CSS support to look different, and the README notes that this menu hides the default table right-click menu inside a table.
