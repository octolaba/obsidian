# Murchi1k/obsidian-lorebase-plugin

Lorebase turns an Obsidian vault into a media library for tracking games, anime, films, TV shows, books and manga, with card grids, status badges, ratings, progress tracking and collection statistics, all stored as local Markdown files. The README records per-medium progress models — seasons and episodes for anime and shows, pages for books, chapters and volumes for manga — format badges, and an edit modal covering status, rating, tags, progress and metadata fields. Its claim of no accounts, no cloud sync and no telemetry, with data never leaving the vault, is recorded here as the project's own statement.
