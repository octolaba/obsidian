# amatya-aditya/advanced-multi-column

Obsidian plugin for nested multi-column layouts built from comment markers `%% col-start %%`, `%% col-break %%` and `%% col-end %%` rather than a wrapping callout or code block. The README gives that choice as the point: with a block-wrapping approach, editing one column in Live Preview collapses the whole block and the sibling columns are replaced by raw markup, whereas here the other columns stay rendered. Columns nest to any depth, are reordered by a grab handle or Alt+drag, are resized by dragging the divider between them, and are styled from a right-click popover, and rendering is toggled independently for Live Preview and Reading View.
