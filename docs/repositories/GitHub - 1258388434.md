# devxoul/obsidian-ignore

Obsidian Ignore hides files listed in a `.obsidianignore` file at the vault root, written in gitignore syntax. Rather than filtering on its own, the plugin computes entries from that file and drives Obsidian's native excluded-files setting, so the hidden paths disappear everywhere that setting applies: the file explorer, the Quick Switcher, search, the graph and local graph, and backlinks and unlinked mentions. The README states that manually added exclusions are preserved — the plugin manages only the entries it computed — and that the manual list is restored when the plugin is disabled.
