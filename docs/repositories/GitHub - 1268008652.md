# fengshuzi/ai-switch

Obsidian plugin that copies the configuration files of local AI coding tools into Markdown snapshots inside the vault, grouped automatically by machine and by tool. Built-in presets cover Codex, Claude and OpenCode with their default paths, and any other file or folder can be added as a custom source, with `.toml`, `.json`, `.yaml` and `.yml` files imported recursively and missing paths skipped. A sidebar syncs snapshots into notes or applies a snapshot back to the local config file, and syncing also runs when the plugin loads, when settings change and from the ribbon button. The README describes the plugin as read-only towards system config directories and as a starting point intended to grow into a helper for switching AI models.
