# ruveydayilmaz/obsidian-api-designer-plugin

Obsidian plugin for designing and documenting API endpoints inside a note. Endpoints are created with request and response bodies, properties are defined by name and type, and fields can be added or removed in a layout that adapts to the workspace. The resulting schema is saved directly in Markdown, and a JSON color scheme can be supplied in the plugin settings.
