# kinabalu/obsidian-word-sprint

Word Sprint runs timed writing sprints inside Obsidian, twenty-five minutes long by default and configurable in the settings. It can nudge the writer after ten or sixty seconds without typing and reports statistics for each sprint, including total words written, average words per minute, and the longest stretch spent not writing. The README traces the idea to a discussion in a writing-month thread on Discord.
