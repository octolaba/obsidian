# harrishussain24/files-name-detector

Files Name Detector is an Obsidian plugin that renames files by replacing spaces in their names with dashes, turning a name such as "my note.md" into "my-note.md". Newly created files with spaces are renamed automatically, and when the plugin loads it scans the vault and renames existing files whose names contain spaces. A notice is shown for each file that is renamed.
