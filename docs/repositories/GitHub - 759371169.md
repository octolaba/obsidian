# revolter/obsidian-track-a-lot-plugin

This plugin scrapes web pages, builds lists from the items it finds and lets each item's status be tracked individually. The lists are written as Markdown tables whose status column accepts any text, which is preserved when the list is next updated. A tracking recipe is enabled in the plugin's settings, and the corresponding command is then run from the command palette with the note in editing mode to create or refresh the list.
