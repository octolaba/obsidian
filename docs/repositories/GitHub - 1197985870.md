# djinnmind/codex-narrative-engine

Obsidian plugin for tabletop RPG campaign vaults that indexes world-building notes and checks them for narrative problems. The README describes reading a frontmatter type field to build a live entity index, autocomplete filtered by entity type when typing a wikilink, hover previews drawn from frontmatter and opening text, and dead-link detection surfaced in the editor, in the gutter and in a narrative warnings panel. It also states detection of logical contradictions in the story and AI assistance that becomes available once an AI provider is configured.
