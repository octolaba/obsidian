# bgarciamoura/obsidian-notion-bases-plugin

Notion Bases turns a folder into a database whose rows are notes and whose values live in plain Markdown frontmatter. The recorded views are table, board, gallery, list, calendar, timeline and chart; the column types number seventeen in the repository description and eighteen in the README, and include formula, relation, lookup, rollup and media types. Further recorded behaviour covers a spreadsheet-style formula engine, hierarchical subtasks through self-relation columns, rollup aggregation across related databases, type-aware filters with AND/OR logic, column tokens that render live cell values in reading view, and optional filing of rows into nested subfolders driven by property values.
