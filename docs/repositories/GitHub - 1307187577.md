# hankleechn/myspace-tasks

MySpace Tasks is an Obsidian plugin that sends the current line or a text selection to the task list of a linked MySpace account. The README describes it as deliberately action-based: it does not scan notes or the vault, and a task is created only when the command or ribbon icon is used, after which the source line is marked with a sent marker and date and its Markdown checkbox is ticked. It requires a MySpace account and network access to the service, whose default server address is recorded in the README; sign-in sends username and password to that server, the password is not saved, and a revocable vault-specific token is stored in plugin data. Chinese natural-language dates and an optional to-do marker in the line are parsed into the task.
