# PYH1107/obsidian-note-lock

This repository holds Note Lock, an Obsidian plugin that password-protects individual markdown files rather than whole folders; the repository records no description, so this summary follows the README alone. A file is protected or released from the file context menu, and opening a protected file prompts for the password, which the README states is stored only as a SHA-256 hash through the Web Crypto API. Further recorded behaviour includes a configurable idle timeout that re-locks each file on its own timer, optional re-locking when switching away from a file, revoked access when a tab is closed, and operation on desktop and mobile using only Obsidian and web standard APIs.
