# slow-coding/obsidian-llm-content-block

LLM Content Block is described as archiving AI conversations in Obsidian as scrollable cards without disturbing formatting. Its README argues that pasting a reply directly lets the reply's own Markdown become the note's structure — its headings become the note's headings and its fences can cut other blocks — and that long replies stretch the note and lose the turn structure. The plugin puts the conversation in a fenced block with the language tag aicard, where the Markdown renders only inside the card, the card scrolls internally with an expand control, and turns are shown as user and AI bubbles with an optional source tag. The README is written in English and Chinese.
