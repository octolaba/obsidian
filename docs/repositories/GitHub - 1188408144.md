# phongviez/obsidian-index-flow

Index Flow renumbers and removes numeric prefixes on Markdown files and folders in an Obsidian vault, addressing prefixes such as `01.` that become inconsistent as items are inserted or reordered. Renumbering rewrites the `.md` files of a folder into a zero-padded sequence using a two-phase rename that avoids collisions, while removal strips the leading prefix and appends a numeric suffix when the result would collide; folder renumbering covers immediate subfolders only, leaves nested levels alone and keeps folder numbering independent of file numbering. Every operation shows a visual diff preview before it is applied and can be reverted with an undo of the last batch, and the README states that the plugin makes no external network requests.
