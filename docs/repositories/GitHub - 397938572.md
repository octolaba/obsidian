# phibr0/obsidian-relative-find

The repository holds Obsidian Relative Find, a plugin adding a command that searches for occurrences of a word after or before the cursor, or across the whole document. Its README records a second, unrelated command that copies results out of Obsidian's search pane to the clipboard, and states that both were added at the request of other users. It is written in TypeScript under the MIT license.
