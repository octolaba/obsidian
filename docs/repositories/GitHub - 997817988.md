# Josie1902/Simple-Columns

Simple Columns creates resizable columns in a note from a code block using the columns language, in which a generated identifier is followed by column contents separated by a line of three equals signs. A layout is inserted by a right-click submenu entry or by a command palette entry naming the number of columns, and code blocks may be nested inside a column by opening the outer block with four backticks. Column widths are set by ratio keys written inside the block, where columns carrying a declared ratio take precedence and the remaining columns share what is left equally. The README further documents global settings for container borders, the resizer and advanced options, alongside local settings written into an individual block.
