# eharris128/obsidian-bluesky

This plugin posts to Bluesky from Obsidian, either from a dedicated tab opened by a megaphone ribbon icon or by highlighting text. Setup asks for the account handle and an App Password rather than the account password, and posts, threads and uploaded images are published through the AT Protocol. Pasting a post URL into the reply field makes the plugin look that post up, show a preview to confirm the target, and attach the new post or thread as a reply; leaving the field empty posts normally. The README states that credentials are stored locally and sent only to Bluesky, and that network use is limited to actions the user initiates, including link-preview generation for a URL in a post.
