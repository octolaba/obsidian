# Jiashu329/obsidian-getbiji

Syncs notes clipped in the Getbiji applications — the mobile app, the web version and browser extensions — into the vault through that service's official API. Three sync dimensions are offered: personal notes, knowledge bases the user created or joined, and creators they follow, each written into its own folder hierarchy. A full sync overwrites local content while an incremental sync identifies notes by identifier and fetches only what is missing, with quick date filters for the last three days, week or month or a custom range, and a report file recording the written count, titles and mode after each run. The README states that a client identifier and API key from the Getbiji open platform are required, that notes are written straight into the local vault, and that the plugin contacts the official API only during a sync.
