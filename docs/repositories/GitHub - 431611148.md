# parente/obsidian-overdue

The repository holds Obsidian Overdue, a plugin that appends an Overdue wikilink to a checkbox item that was not checked off by its due date. Its README records the due date as either the daily note the item lives in or a date link written on the item's line, and shows the marker being added to the unchecked items alone. The plugin runs automatically just after midnight in local time and can also be triggered from the command palette.
