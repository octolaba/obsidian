# remotely-save/remotely-save

Remotely Save is an unofficial sync plugin that moves notes between a vault and a cloud remote, supporting Amazon S3 and S3-compatible services such as Cloudflare R2, BackBlaze B2 and MinIO, Dropbox, OneDrive for personal, WebDAV servers including NextCloud, InfiniCloud and Synology, Webdis, and — as paid features — Google Drive, Box, pCloud, Yandex Disk, Koofr and Azure Blob Storage. It runs on Obsidian mobile as well as desktop, using the cloud service as the broker between devices, can encrypt files end to end in the openssl or rclone crypt format when a password is set, and syncs on a schedule or on demand from the ribbon, the command palette or a hotkey. Large files and paths matching custom regular expressions can be skipped. The README states plainly that this is not Obsidian's official sync service and asks the reader to back up the vault before use.
