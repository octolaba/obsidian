# joethei/obsidian-key-promoter

The recorded description says the plugin teaches keyboard shortcuts by showing them when the mouse is used. Per the README, using the mouse on a button raises a notification carrying the shortcut assigned to that action, or the name of the command to assign in the settings when the button has none; the README warns that buttons are not directly associated with commands in Obsidian, that a button name may not match the command name, and that one press can therefore produce several different notifications. A separate action, disabled until enabled in the settings, shows a notification whenever a hotkey is pressed with the command it called, which the README suggests is useful for presentations, and a statistics command lists the most used commands. The README names the Key Promoter X and Presentation Assistant plugins for IntelliJ IDEA as its inspiration.
