# zhuSilence/obsidian-mowen-plugin

This plugin publishes Obsidian notes to the Mowen note platform. The README states that a whole note or a selection is published from the right-click menu or the command palette, that Markdown is converted to Mowen's rich text including headings, bold, quotes and links, that embedded images are uploaded and replaced with online links, and that internal note links become embedded Mowen notes; an AI assistant, currently backed by DeepSeek, generates a title, tags and an optional summary that is placed as a quote block under the title. Settings hold the Mowen API key, the frontmatter key storing the note id with a fallback to the older key, an optional title key, default tags and whether a published note is visible or a draft, while a dialog before publishing adjusts title, tags, privacy, sharing and validity.
