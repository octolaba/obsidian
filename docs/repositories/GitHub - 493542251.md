# pulsovi/obsidian-note-aliases

Note aliases is an Obsidian plugin for managing note aliases from the link that uses them. Its one available command, save-alias, takes the wikilink under the cursor, finds or creates the note that link targets, and adds the link's alias to the aliases list in that note's YAML frontmatter. The README states that several further features are planned and that this is the only one implemented so far.
