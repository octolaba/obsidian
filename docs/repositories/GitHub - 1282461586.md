# skyue/obsidian-weixin-mp-publisher

WeiXin MP Publisher is an Obsidian plugin for writing in Obsidian and publishing to a WeChat Official Account, handling the account's formatting without leaving the editor. Its README states that it is derived from RanceLee's WeChat Publisher and points to a usage guide on the author's own site. The recorded material is short and written in Chinese, so nothing beyond that publishing purpose is stated here.
