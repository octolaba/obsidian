# WilliamsJack/pairwise-glicko-ranking

This plugin ranks a cohort of notes by pairwise comparison using the Glicko rating system, so notes can be sorted by a subjective criterion without assigning absolute scores. The README explains the reasoning: choosing which of two notes wins avoids the ambiguity of a fixed star scale, and the ranking adjusts as further comparisons are made. A cohort can be the whole vault, a folder, a set of tags or a Base, and the comparison arena offers several layouts, including a single-note layout for smaller phone screens.
