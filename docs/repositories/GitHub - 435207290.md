# beaurancourt/obsidian-generic-initiative-tracker

This repository holds a TTRPG initiative tracker for Obsidian, described upstream in those terms and presented in its README as a trimmed-down, system-agnostic fork of an existing initiative tracker. The README says it adds a right-pane view where players and creatures are added and their initiatives tracked during combat, and that encounters can be declared in a note through an encounter code block and launched from there, with creature names rendered as internal links. Differences from the project it forks are listed as no experience or level settings, no homebrew creatures, no fifth-edition import, a simplified settings screen, unique indices for repeated creature names, and dice-string initiative modifiers.
