# Dyse-Sofqi/ziping

This repository holds Ziping, an Obsidian plugin that builds Bazi, or Four Pillars, charts from a birth date, time and gender. It calculates the four pillars automatically, calibrates true solar time from a built-in database of more than 400 city coordinates, accepts Gregorian or lunar dates to the minute, and derives Ten Gods relations, luck pillars with their starting date, annual and monthly cycles, nayin, the twelve stages and hidden stems. A chart renders in a sidebar view, inside a code block isolated with Shadow DOM, or as a floating panel pinned to the left of the editor in Live Preview, and selecting a year in any view moves the document cursor to the matching line and back. One click saves a chart as a Markdown case file with YAML frontmatter and tags in a configurable folder.
