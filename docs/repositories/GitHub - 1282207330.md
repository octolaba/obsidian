# qoob23/synapses

Synapses lays out a note's relations as a focused graph with the active note in the center, its parents above, children below, jumps to the left and siblings to the right. A card can be clicked to activate that note, a handle dragged to create a link, and a connector hovered to remove one. Relations are declared as ExcaliBrain-style page properties named parent, child and jump, either as inline fields or in YAML frontmatter, with reciprocal relations and siblings inferred and existing properties edited in place; the README records that the Obsidian side requires the Dataview plugin, that the same plugin also runs in Logseq, and that it was written with LLM assistance.
