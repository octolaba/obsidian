# fenmirs/ob-extends-gwsc

This plugin adds typesetting for classical Chinese poetry and prose to Obsidian, built on the Heti typography project. Each piece is a .sc file holding JSON — title, layout type (poetry, ancient prose or vertical), dynasty, author, font, font size and character spacing — edited through a form view whose per-character cards open a pinyin keyboard for annotation. A preview mode renders the typeset result, including the traditional right-to-left vertical layout, and can export it as a standalone HTML file.
