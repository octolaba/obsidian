# EthanThatOneKid/obsidian-nerv

EthanThatOneKid/obsidian-nerv holds a NERV theme for Obsidian, inspired by the MAGI and EVA-01 displays from Neon Genesis Evangelion. The README states that the theme supports both dark and light modes and, at the time it was written, that inclusion in the official community theme gallery was still under review as a pull request against obsidianmd/obsidian-releases. It also documents local testing by cloning the repository into the vault's themes folder.
