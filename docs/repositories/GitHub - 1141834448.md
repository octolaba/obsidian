# DavidLam-oss/obsidian-wechat-converter

Converts Obsidian Markdown into formatted WeChat Official Account articles and forwards the same note to further publishing targets; the README is written in Chinese. Its publish dialog keeps three routes apart: the WeChat draft box over the official API, with multiple accounts, covers, summaries, draft updates and optional cleanup after syncing; Feishu cloud documents over the Feishu open-platform API, with creation, overwrite, rebinding, image and GIF upload and handling for callouts, task lists, math and Mermaid; and platforms such as Zhihu, Juejin, CSDN and Xiaohongshu, whose drafts are saved through a companion browser extension that reuses the browser's existing login. The README states the project is a rewrite of the open-source ai-writing-plugins.
