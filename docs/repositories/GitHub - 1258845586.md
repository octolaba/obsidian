# doge-liang/obsidian-drawio

Embeds, previews and edits draw.io diagrams in Obsidian across three surfaces: inline code blocks, standalone diagram files whose editor lives in the file's own tab, and embeds, all rendering live SVG previews in editing and reading views. Previews are produced by drawio's own viewer bundled into the plugin, so they work offline with no iframe and no network on desktop and mobile, while the editor defaults to a bundled offline build served from a local server that is installed separately from the settings or switched to the online source. Diagrams are saved as uncompressed, pretty-printed XML rather than a compressed blob, so diffs, sync and version history stay meaningful, and multi-page files get a page switcher under the preview. The README states it requires Obsidian 1.4.0 or later, sanitizes rendered SVG before insertion, and is preview-only on phones and tablets.
