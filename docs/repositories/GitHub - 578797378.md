# ulisesantana/obsidian-pending-notes

The repository holds Pending Notes, an Obsidian plugin that collects the links written while drafting which do not yet point at an existing note. Its README records that the collected links are shown in one place, from the left sidebar or through the command palette, so the missing notes can be created from there. Installation from the community directory is documented alongside a manual route unzipping a release into the vault's plugin folder.
