# elijahchan2019/theme-opendian

Opendian is a monospace-forward developer-documentation theme for Obsidian, taking its visual language from OpenCode and covering light and dark on desktop and mobile with no plugin required. It is designed around IBM Plex Mono with a fallback stack through Berkeley Mono and JetBrains Mono, and the README explains how to install that font. Its layered radius system keeps content sharp at 0px for code blocks, tables and callouts, softens controls to 4 to 8px and modals to 12px, and hard 1px borders are replaced by background-step separation so the tab bar, titlebar and view header read as one surface. A Chinese version of the README is provided.
