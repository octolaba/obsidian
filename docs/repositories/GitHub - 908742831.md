# mnaoumov/obsidian-external-rename-handler

Handles renames performed outside Obsidian while the app is running, which Obsidian otherwise reports as a create event followed by a delete event, and turns them into a single rename event instead. The README records the limits explicitly: the plugin only works while Obsidian runs, only for files and folders that Obsidian tracks, only for renames inside the vault, and not for files or folders whose name starts with a dot. A demo vault ships with every release and can be opened from a command.
