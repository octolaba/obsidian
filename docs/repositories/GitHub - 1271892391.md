# SunnyYYLin/obsidian-html-tables

HTML Tables extends Obsidian's table rendering with features standard Markdown tables lack: header rows and header columns, cells merged horizontally or vertically, captions placed above the table, multiline cell content, horizontal and vertical cell alignment, and basic formulas in cells. Columns can be resized by dragging, auto-fitted or equalised, a right-click context menu carries the table operations, and hovering a table reveals a floating action button. The README states that a standard Markdown table is enhanced automatically and that the features work in Obsidian's preview mode.
