# JakobMick/obsidian-file-indicators

Adds coloured indicators in chosen shapes to files and folders in the file explorer. An indicator is added from a file or folder context menu, from commands covering the active file, or from the settings tab, which is also where a root-level indicator can be set. Custom shapes are supplied as SVG and drawn in the selected colour only, with all colours in the file ignored; the README notes that not every SVG works and that deleting a shape deletes the indicators using it. Because the indicators are drawn with CSS, the README warns of conflicts with snippets or other plugins touching the file explorer and states that stable CSS variables are planned for a later major version.
