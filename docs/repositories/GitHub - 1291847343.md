# NoteNerdOfficial/unhidden

Unhidden makes hidden dot-folders and dotfiles inside a vault visible to Obsidian's file explorer, search, metadata cache and Bases. Vault-root dot-entries are toggled from the settings, and nested hidden paths or individual dotfiles can be revealed as well; the whole tree is registered when a folder is revealed, a recursive watcher keeps it current, and a watcher on the vault root notices newly created hidden paths and prompts to reveal them. Indexing can be limited to an allowlist of extensions, and commands reveal, hide and rescan through fuzzy pickers. The README states that nothing on disk is modified because only what Obsidian indexes changes, and that the plugin is desktop only because it calls and patches undocumented file system adapter methods, which are restored on unload.
