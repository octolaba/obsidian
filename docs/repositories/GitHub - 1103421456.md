# gapmiss/peer-share

Peer Share transfers files between Obsidian vaults over WebRTC peer-to-peer connections, built on PairDrop and described as compatible with its web and mobile apps. The README lists device pairing for cross-network transfers, automatic discovery of peers on the same network, sharing of individual files or whole folders, a searchable sidebar history of sent and received files, and progress reporting during a transfer. It also records eight interface languages, desktop and mobile support, optional operating-system notifications on desktop only, and settings for a custom signaling server, save location and log level.
