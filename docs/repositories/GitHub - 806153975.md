# arumie/obsidian-simple-prompt-plugin

Simple Prompt generates content in notes with large language models through a small set of commands: generating at the cursor, rewriting the selection, rewriting the whole document, and generating from a YouTube video address together with a request, which relies on the video's captions and does not work when the video has none. The model is chosen from a list of providers, with OpenAI and Ollama recorded as supported, prompt templates are customizable, recent prompts can be reviewed and reused, and streaming responses can be toggled. The README lists further model providers, an image-generation command, indexing of all vault documents and encryption of the saved API key as future features.
