# Quorafind/Obsidian-Canvas-MindMap

Makes an Obsidian Canvas behave like a mindmap. The README describes creating a node, then pressing Tab on a selected node to add a child and Enter to add a sibling, with edit mode left first; further keys navigate between nodes with Alt and the arrow keys and create floating or child nodes with the platform modifier. It lists auto layout in a chosen direction, selecting a node's whole subtree, and changing the colour of a node's edges, and the same operations are also available as commands.
