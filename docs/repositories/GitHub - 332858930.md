# Vinzent03/obsidian-shortcuts-for-starred-files

Obsidian plugin that adds nine commands for opening the first nine bookmarks, so each can be bound to a hotkey in Obsidian's own hotkey settings. A second set of nine commands opens those same bookmarks in a new pane. The README notes that files and searches have to be bookmarked with the core Bookmarks plugin first, and records the minimum Obsidian version at which community plugins are available.
