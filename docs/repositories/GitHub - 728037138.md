# luxmargos/obsidian-canvas-card-bg-remover

Makes the background of Canvas cards transparent for particular embed types, the README naming PNG images, embedded canvases and Markdown. It states that after installation an open canvas shows the background removed from embedded cards that themselves have a transparent background, that the effect applies mainly to images and canvases, and that the affected card types are configurable in the settings page. Card label visibility is described as an Obsidian Canvas setting rather than a setting of this plugin.
