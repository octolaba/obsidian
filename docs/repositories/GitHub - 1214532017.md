# loudinthecloud/obsidian-quick-timebox

QuickTimeBox renders an editable time grid inside an Obsidian note from a quicktimebox code block, one row per time slot, with typed tasks written back into the note automatically. The range runs from any start time to any end time, wrapping correctly past midnight, and slots can be 15, 30, 60 or 120 minutes long. A red now-line tracks the current time across the grid and updates every minute, and can be hidden from a button in the header. Right-to-left layouts are mirrored, either from a setting in the block or from the note's own direction.
