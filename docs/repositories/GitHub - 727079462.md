# byfun/obsidian-highlight-helper

This plugin collects and copies all the highlights in the note currently open in Obsidian. Which text counts as a highlight is decided by regular expressions in the settings, whose defaults cover Markdown highlight syntax and the output of the Highlightr plugin. Those defaults can be replaced with the reader's own expressions.
