# Sadsnake1/word-smith

Word-Smith collects several independent writing modes for Obsidian, each of which can be switched off on its own. Zen clears the chrome, ribbon, sidebars and scroll bar until Escape is pressed; Letter box masks the top and bottom of the screen with a resizable band; Typewriter holds the current line in the middle of the screen; and Hemingway blocks the individual keys used to go back, such as backspace, undo, cut, paste, arrows and clicks. It also colours nouns, verbs, adjectives, adverbs and conjunctions, marks seven prose patterns including filler words, passive voice and vague pronouns, and replaces the status bar with rows composed by the user. The README states that the syntax colouring and the prose checks both run entirely on the local machine and are guesswork.
