# community-archive/obsidian-full-calendar

The repository holds the Full Calendar plugin, which brings the FullCalendar library into a vault so a schedule can live beside notes and tasks. Its README records each event as its own note carrying special frontmatter, so notes, links and context can be attached to any event, and it records two local sources — frontmatter on notes and event lists inside daily notes — alongside read-only remote calendars over ICS and CalDAV. The catalog records this repository as archived, and the underlying library is credited to its author under the MIT license.
