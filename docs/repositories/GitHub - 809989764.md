# xainapse/Allium

xainapse/Allium records no repository description; its README presents Allium as a theme inspired by allium flowers, chiefly Allium atropurpureum and its shades of red and purple. The notes for its second version record increased contrast between backgrounds and text for less eye strain, together with changed heading and bold colours and a slightly tweaked italic colour. A light mode exists but the README calls it very much an early work in progress, and the repository also offers the icon shown in its screenshots as an app icon.
