# MamoruDS/obsidian-open-link-with

The repository holds Open Link With, an Obsidian plugin that decides which browser opens an external link. Its README records that the browser is chosen in the plugin's settings menu and that a custom profile can be added there, mapping a name to a list of commands, with a user profile ignored when its name collides with a preset. Installation from a release archive into the vault's plugin folder is documented alongside the community listing.
