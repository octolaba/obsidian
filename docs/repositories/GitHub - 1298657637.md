# carbongo/checkbox-context-menu

Adds a right-click context menu to any task checkbox for switching its state. The README lists unchecked, done, half-done, deferred, scheduled, important and cancelled among the built-in states, plus custom states defined as a single character with a label and icon, and a command that cycles through the enabled states. It states the menu works in editing and Live Preview through the editor menu and in Reading mode through right-click on desktop or long-press on touch, and that the shipped CSS gives each state its own color and glyph using Obsidian's theme variables.
