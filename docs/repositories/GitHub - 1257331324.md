# west-shell/obsidian-chess-tree

This repository holds Chess Tree, an Obsidian plugin for rendering and exploring chess inside notes, built on chess.js for the rules and chessground for the board. It supplies three code block types, namely chess, fen and tree, a variation tree visualisation, and engine analysis from a WebAssembly build of Stockfish 18. It also registers a view for PGN files, so such a file opens on an interactive board where moves, variations, comments and annotations are edited and written back when Save is pressed, with a ribbon button for new files and a context menu switching between the PGN and Markdown views. The README notes that the PGN view handles single games only, and it is written in English and Chinese.
