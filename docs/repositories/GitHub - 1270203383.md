# andsea007/obsidian-audio-inbox

An Obsidian plugin for voice notes that records with one click, transcribes the audio, and has a model write a structured note from the transcript. The README states that transcription runs on SiliconFlow's SenseVoiceSmall and summarization on DeepSeek, chosen so the plugin works in China without a VPN, and describes a memo mode where the model classifies a recording as a reminder or a memo and files memos into a dated note keeping both summary and original transcript. Checklist items are extracted from the summary into a dedicated todo file that can be exported for iOS Shortcuts and Apple Reminders, pre-recorded files in an inbox folder can be processed in batch, and mobile recording uses a draggable floating button.
