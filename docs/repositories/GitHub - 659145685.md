# korbinjoe/obsidian-excalidraw-cn-plugin

Obsidian plugin bringing the excalidraw-cn whiteboard into Obsidian, adding a Chinese handwriting font as the default without requiring it to be installed on the system. It is created from a ribbon icon and, according to the README, carries the current Excalidraw features while also supporting Obsidian's bidirectional links, which are added by pasting an Obsidian URL or typing a file name into a shape's link field. Custom fonts, table, mind-map and Markdown cards, and cloud storage are listed as planned rather than present.
