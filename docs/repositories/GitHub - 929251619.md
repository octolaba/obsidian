# benstuart0/on-this-day-i-obsidian

This plugin adds AI commands for daily journals. One command inserts a placeholder tag at the cursor, marking where generated text should be placed, and the tag can be changed in the settings. The other looks for daily notes from the same date in past years and writes a brief summary of each of them into the current note.
