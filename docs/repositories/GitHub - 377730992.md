# esm7/obsidian-map-view

The repository holds Obsidian Map View, a plugin that searches notes for geolocations and paths and places them on an interactive map. Its README records adding locations from a search, from the map itself, from external mapping services or from the device's GPS, viewing paths in the GeoJSON, GPX, KML and TCX formats, drawing locations and shapes in an edit mode, and calculating driving, cycling or walking routes between points. It also lists display rules for marker icons, badges, colors and path styles, a boolean query language for filtering markers, live maps embedded in notes, saving maps for offline use, and integration with Obsidian Bases.
