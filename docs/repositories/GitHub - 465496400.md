# cfe84/obsidian-pw

Proletarian Wizard manages todos and projects from inside Obsidian notes: tasks are written in the notes themselves and appear on a task board, board changes are written back to the notes, and clicking a task opens it at its source. The README describes panels for tracking the day — selecting the tasks to do, optionally prioritising them, changing their status and marking them done — and panels below for planning, where a scheduled task appears in the Todo column when its date arrives and an uncompleted one collects in a Past panel. It also records an auto-expand command that turns natural language such as tomorrow or next monday into an actual date, and a report of the work done that is meant for status reports and annual reviews.
