# TheseusGrey/edit-in-neovim

Obsidian plugin that mirrors the file open in Obsidian into a listening Neovim instance, opening it as a new buffer or focusing an existing one, which gives the linked-tabs behaviour against an external editor. It can also start Neovim in a new terminal when Obsidian launches, which can be switched off in the settings. The README notes reports that the plugin does not work when Obsidian is installed through flatpak, names the additional plugins needed to make the reverse direction work, and warns of a loop that occurs when files are renamed or deleted in Obsidian while the buffer is open in Neovim.
