# MichelleGDyason/obsidian-dictionary-plus

Dictionary Plus is an AGPL-licensed enhancement of the phibr0 Obsidian dictionary plugin, adding a dictionary view to the right sidebar that is opened from the command palette. It adds desktop right-click lookup, appended to the existing Obsidian and PDF++ context menus so their own link, copy, annotation and editing actions remain available, and a mobile path that remembers the selection before the mobile menu collapses it. Selections are trimmed of surrounding punctuation and phrases containing spaces are rejected, because the configured providers expect a single word. Successful lookups are saved by default to a lookup history note, tagged for flashcards and written in the single-line format used by the Obsidian Spaced Repetition plugin.
