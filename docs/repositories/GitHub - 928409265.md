# iqijun/obsidian-image-share

Renders selected text from a note as images that can then be shared. The version history in this plugin's README records the initial release, then the adoption of markdown-here styling with preview and download-button adjustments, then a revised preview style adding image copying and zoom. Nothing beyond those changes is documented there.
