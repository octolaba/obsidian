# iwa/Sei

Sei is its author's personal Obsidian theme, designed with clarity and simplicity in mind, and the README warns that it might not fit other users' needs. It began as a hard fork of the Cupertino theme and has since been almost completely reworked, with a few elements kept because Cupertino's spirit was closest to what the author wanted. The credits record features adapted from other themes: the Cards layout and custom checkboxes from AnuPpuccin, inline label navigation from Minimal, and settings icons from Border. It is installed from the Community Themes tab and released under the MIT License.
