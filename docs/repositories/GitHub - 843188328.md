# golam71/obsidian-hackthebox

This repository holds an Obsidian theme inspired by Hack The Box Academy, described by its author as an attempt at making an Obsidian theme. Its README documents installation from the appearance settings by searching for Hackthebox, or manually by cloning the repository into the vault's themes directory. It recommends Neue Haas Unica W1G for text and JetBrains Mono for monospace, and credits Hack The Box Academy, an HTB theme for Visual Studio Code and named community members.
