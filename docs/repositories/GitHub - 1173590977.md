# jaidetree/obsidian-base-settings

Base Settings enforces shared base settings across multi-user Obsidian vaults by deep-merging partial JSON templates into the vault's `.obsidian` config files on startup and whenever settings change. Templates live in a folder inside `.obsidian`, are named after the config files they manage, and their values take precedence over the user's on conflicting keys, so a team can commit required plugins or hotkeys to version control while each user keeps their own additions. Merge directives let a template author choose a different strategy for arrays instead of the default replace, and a template whose target config file does not exist yet is skipped until Obsidian creates it.
