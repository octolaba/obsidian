# ted-marozzi/task-list

Task list adds task states to ordinary ordered and unordered Markdown lists in Obsidian. The README records four directives written at the start of a list item, for to-do, doing, paused and done, which render as interactive task state boxes that cycle on click or can be set from a context menu. A sort command, also reachable from the context menu, orders a list by state, putting doing first, then paused, then to-do, with done last. The author records performance and Markdown compatibility as project values, noting that a document still renders readably outside the plugin.
