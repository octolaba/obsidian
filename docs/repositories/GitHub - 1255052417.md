# imed-ghomari/obsidian-bases-buttons

Bases Buttons lets button properties such as `button.run` render as clickable buttons inside core Bases tables in Obsidian. Each button runs a configured Templater template against the note represented by that property or Base row, so a template can update frontmatter or append content to the target note even when it is not open. The README records Obsidian 1.8.0 or later and the Templater community plugin as requirements, and describes global button configuration, template-path suggestions, keyboard activation, and an optional confirmation dialog on mobile.
