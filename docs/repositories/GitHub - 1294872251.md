# Efficient-X/Calendar-Importer

Imports iCal and ICS calendar events from third-party calendars into a dedicated Obsidian note. The README states that the plugin reads Google Calendar, Outlook, iCloud, Zoho and other iCal or ICS feeds in the background and writes their events as Markdown tasks, either as plain text or as wikilinked notes, with dates and a tag. Setup is described as adding a feed link in the plugin settings and running a sync. The README is written as promotional copy; only the mechanism it states is restated here.
