# dpickett/open-related-url

Open Related URL opens addresses recorded in a note's YAML front matter. The command searches the front matter and offers the URLs it finds, which the README illustrates with a tasks key pointing at a task manager and a files key pointing at a cloud folder. The stated motivation is correlating a note with the matching task list and file storage without leaving Obsidian.
