# HananoshikaYomaru/obsidian-3d-graph

This repository holds a 3D graph view for Obsidian, opened as a global graph from a ribbon button or a command and then zoomed by scrolling, rotated by dragging and panned with a modifier key. A local graph showing only the nodes connected to the current note is opened by its own command. The README records a performance problem in the underlying 3d-force-graph library and a maximum node count setting above which the graph is not rendered, and documents installation from the community plugin store, through BRAT, or by cloning and building the repository.
