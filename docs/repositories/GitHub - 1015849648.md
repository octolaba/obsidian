# mbedded/obsidian-paste-file-link

This plugin pastes clipboard text as a link to an existing note in the current vault, using the selected text as the alias. The README states that the resulting link is a wiki link or a Markdown link depending on the vault setting under Files and links, and that a dialog opens when several files share the same name. When the clipboard holds no text or no matching file is found, the ordinary paste happens instead, and the paste shortcut binding can be switched off so that the command palette is used.
