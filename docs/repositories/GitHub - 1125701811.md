# erezak/obsidian-lock-cards

Lock Cards is an Obsidian plugin that locks selected Canvas cards so they cannot be moved or resized. A command toggles the lock on the current selection, locked cards are visually marked, and attempts to move or resize them are reverted. A setting allows locked cards to be moved while a modifier key is held, and the two recorded inputs disagree about which one: the description names Alt and the README names shift. The description also mentions an unlock-all command that the README does not document.
