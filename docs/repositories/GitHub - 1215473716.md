# Aejkatappaja/sora-obsidian

Sora is a dark theme for Obsidian using ethereal cyan, cool silver and deep OLED blacks. The README places it in the Sora colorscheme family and documents manual installation by copying the extras/obsidian folder into the vault's themes directory, with the community themes route marked as coming soon. It is MIT licensed.
