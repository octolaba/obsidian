# aipyer/bitfield

The repository carries no description; its README, written in Chinese, presents Bitfield as an Obsidian plugin that renders bitfield definitions inside a bitfield code block as interactive SVG diagrams and HTML tables, aimed at chip front-end engineers reading register layouts in their notes. Fields are declared by name, width and description with indented sub-fields nested up to five levels, bits are allocated to earlier fields first from the least significant end, and any bits left over are filled as reserved at the most significant end. Diagram boxes carry two indices, the field's own relative range inside the box and the parent range outside it, and one control switches between diagram and table. Definitions in one block can be referenced from another by an at-prefixed name, with click-to-jump and hover preview.
