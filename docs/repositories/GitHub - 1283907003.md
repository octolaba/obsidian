# leweii/read-it-never

Read It Never is a rebranded fork of ReadItLater by Dominik Pieper that saves web content into an Obsidian vault as Markdown for later reading or reference. It handles several content types — website articles, YouTube videos and channels, Twitter, Bilibili and plain text snippets — each with its own template and predefined variables, can download article images into the vault, and processes batches of URLs from the clipboard as well as single notes created from the ribbon icon, the command palette or the share menu. The README states that it works with the iOS and Android apps, that content can also be inserted at the cursor in an existing note, and that the plugin is distributed outside the community store, through BRAT or a manual release download.
