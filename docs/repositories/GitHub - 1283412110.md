# JuanCodeLabs/DarkCatto

DarkCatto is an Obsidian theme based on the Catppuccin colour palette that ships two modes in one theme: DarkCatto, a dark mode inspired by the Catppuccin Mocha palette, and WhiteCatto, a light mode. The README describes WhiteCatto as a later addition that keeps the same palette, fonts and visual identity as the dark mode, adapted to a white background. The two modes are switched from Obsidian's own appearance settings.
