# threeyang3/bangumi-sync

An Obsidian plugin that imports a Bangumi account's collection into vault notes. Its README, written in Chinese, describes syncing ratings, short reviews, tags, collection status and watching progress for anime, games, novels, comics, art books, music and live action, with template-driven custom properties, and sync modes covering manual selection, automatic and incremental import, pausing, background progress and a cancel that rolls back new files and restores renamed paths. A large part of the README documents recovery: a separate journal records original content, subject ids, paths and cover assets before the first vault modification, covers are hashed with SHA-256 and refused beyond 16 MiB, and corrupt or orphaned journals are backed up and block further writes. The repository carries no description.
