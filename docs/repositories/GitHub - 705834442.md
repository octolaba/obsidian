# Floydv149/bibleLinkerPro

The repository records no description, so this note is grounded in the README alone. Bible linker Pro converts Bible references written in an Obsidian note into JW Library links, accepting both shorthand and spelled-out forms such as `ge 1:1` or `genesis 1:1` and rewriting them as a Markdown link to a `jwlibrary:` address. It can also open a Bible text in JW Library without altering the note, picks up the current line automatically, and offers configurable link output formatting, several interface languages and a choice of Bible edition. Conversion is run from the command palette, and the README notes that Restricted mode must be off to use the plugin.
