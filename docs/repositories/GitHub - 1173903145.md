# juanchiparra/obsidian-year-in-pixels

Reads the frontmatter of daily notes and draws the year as a pixel chart, either a horizontal grid or a circular layout. The tracked variables are user-defined frontmatter properties whose values map to hex colours, notes are taken from a configured target folder, and the date comes from the note title or a `date` property in a chosen format. The visualization opens as a workspace tab from a ribbon icon or as a compact sidebar view, and hovering a cell shows the exact date and logged variables while clicking opens the corresponding note.
