# mario-holubar/obsidian-daily-note-creator

Daily note creator fills in daily notes that do not exist yet, acting as an add-on to the core Daily notes plugin and using the settings defined there rather than replacing them. It can create the daily note on startup without opening it, so the vault can open on another note, automatically create notes for days when the vault was not opened — asking for confirmation when the gap is longer than a week — and expose a command that opens a window for filling in any past range. The README records a known issue: daily notes organized in a folder structure or carrying extra text beside the date in the filename misbehave, which it attributes to the underlying daily-notes-interface package.
