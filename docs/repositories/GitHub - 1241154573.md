# 23maverick23/obsidian-convert-case

The repository holds Convert case, a dependency-free Obsidian plugin that converts selected text between cases and handles multiple selections. Commands are run from the command palette or bound to hotkeys, and cover title, upper, lower and swapped case as well as camel, Pascal, snake and kebab case. The README notes that the plugin is deliberately build-free, with Obsidian loading its main script directly.
