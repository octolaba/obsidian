# kiaraorq/heic-viewer

HEIC Viewer is an Obsidian plugin that displays .heic and .heif images inside notes on desktop, tablet and mobile. The README states that Obsidian does not support HEIC because of Chromium licensing restrictions and that the plugin converts such files to PNG on the fly with the libheif-js library through WebAssembly, rendering ordinary embeds like any other image and preserving an alpha channel. Recorded features include a fullscreen viewer with zoom by button, pinch or scroll wheel and drag to pan, a choice of transparent, black, white or custom backdrop behind transparent areas, optional colour inversion, and lazy conversion only when an image scrolls into view. The README states that conversion happens locally in memory with no upload and no cache files, and that large photographs may take a second or two to decode.
