# Highway-wu/obsidian-gothic

Highway-wu/obsidian-gothic holds Gothic, a typography-focused Obsidian theme inspired by Typora's Gothic theme: a neutral page, centered uppercase headings, red links, generous line height and a Century Gothic or TeX Gyre Adventor font stack. The README states that light mode is the primary experience with dark mode supported for low-light work, and that the light screenshot is sized to the 512 by 288 pixels the community theme directory expects.
