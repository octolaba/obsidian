# RuanPienaarCode/budget-vault

Budget Vault keeps every account, budget and transaction as a plain Markdown file inside the user's own vault, under a folder that defaults to Finances/Budget with subfolders for categories, accounts, budgets per period and transactions per account. The README states that the plugin makes zero network requests, requires no account to create and holds no company database, so syncing is left to whatever service already carries the vault. Its screens cover a dashboard of spending trend and budget versus actual, searchable and editable transactions, budgets per category and period with live left-or-over feedback, savings, accounts, owed money, subscriptions and tax. A bank statement can be imported from CSV, reviewed and committed, categorisation rules are learned from corrections, periods can be payday-aligned, and the README claims full iOS and Android support.
