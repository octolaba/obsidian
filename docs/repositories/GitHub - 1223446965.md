# allexcd/obsidian-mcp

MCP Vault Bridge connects an Obsidian vault to MCP clients such as Claude Desktop and LM Studio, and the README describes it as local, token-protected and read-only by default, with exclusions deciding which notes are exposed. An assistant can list notes by folder, tag, path or metadata, search note text, read and summarize notes, show links, backlinks, tags, aliases and related notes, create Obsidian base files, and optionally use semantic search with local embeddings or write tools that create and edit Markdown. Setup installs a SQLite runtime from the plugin settings and copies a generated client configuration carrying the token, bridge URL and local server path, and Obsidian has to stay open while a client is using the vault.
