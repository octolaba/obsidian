# kleokl7/Claude-Code-Obsidian-Theme

Claude Code Orange is an Obsidian theme that recreates the look of Claude Code in the Claude mobile app, with warm cream surfaces in light mode, warm charcoal in dark mode, and a coral accent driving links, the active note marker, tags, checkboxes and highlights. Its typography pairs a grotesque sans for interface and body text with an optional serif reading mode and a monospace face for code, and bold text takes both a heavier weight and the high-contrast heading colour. Beyond the empty and done checkboxes it styles three further task markers, for in progress, forwarded and cancelled, in reading view and Live Preview on desktop and mobile. The README also documents navigation layers for long notes, among them a heading breadcrumb in the title bar that depends on a community plugin.
