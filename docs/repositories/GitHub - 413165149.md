# ryanpcmcquen/obsidian-javascript-init

The repository holds Obsidian JavaScript Init, a plugin that runs custom JavaScript when Obsidian loads or at another moment. Its README documents manual installation by copying the built script, manifest and stylesheet into a plugin folder inside the vault.
