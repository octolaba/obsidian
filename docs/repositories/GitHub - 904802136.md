# Mara-Li/obsidian-my-thesaurus

My Thesaurus is an Obsidian plugin that adds tags to a note based on a thesaurus supplied as a CSV file or a Markdown table in the vault. It searches the note's properties, body and title for each term, matching strictly without truncation, case-insensitively and, configurably, accent-sensitively, so that a term matches its own capitalisations but not its plural or derived forms. The thesaurus needs at least a terms column and a synonyms column with a header row, a term may carry many synonyms by repeating it, a synonym may belong to several terms, and a Markdown thesaurus file must contain nothing but that table apart from optional frontmatter. The path to the thesaurus is set in the settings, with a save action that checks the file exists and is well formed.
