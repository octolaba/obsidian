# sunxiaoqiqi/markdown-image-maker

Markdown Image Maker opens a Markdown file or a selected passage in a dedicated Obsidian view and exports the content as styled images. The file menu opens a whole .md file, the editor context menu opens a selection, paginated images can be previewed before export, and the output goes to the vault root, the current file's folder, the attachment folder or a custom folder, optionally writing image links back into the source note; template, brand text, mode, size, format, quality and output location persist between sessions. The README records the plugin as desktop-only because it uses local Node modules, and states that it needs a local converter backend — by default an HTTP service on localhost exposing two conversion endpoints — to which the Markdown content is sent.
