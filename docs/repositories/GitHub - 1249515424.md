# callumalpass/pickle-obsidian

Pickle turns a folder in an Obsidian vault into a local, file-based inbox for typed agent requests and structured human responses. According to its README, agents write request files under a requests folder, a human reviews them through Obsidian Bases views for pending, answered and conflicting rows, answers through a schema-driven modal built from the requested response type, and response files are written under a responses folder, with both kinds of file staying in the vault as the audit trail. It explains the intent as human checkpoints in local automation, where request state lives in files rather than ephemeral interface state and downstream automation copies the decision into its own workflow while leaving the Pickle files intact. Nested response schemas with object and list fields, and attachments copied into the collection attachments folder, are recorded as well.
