# yuukibarns/obsidian-zotero-completion

This repository holds Zotero Completion, a desktop-only Obsidian plugin that searches Zotero PDF attachments and annotations and inserts a Markdown link at the cursor. Annotations are searched by comment or highlighted text and PDFs by citation and filename, and the inserted links carry annotation page numbers. A normalized cache is persisted in Obsidian's plugin data, with commands to refresh or clear it, and the local API URL and retrieval limit are configurable. It requires Zotero 7 with the local API enabled, sends requests only to loopback addresses and rejects any other API URL, and does not modify the Zotero library.
