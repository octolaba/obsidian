# Ankush-Chander/obsidian-smart-move-text

Smart Text Mover moves a selected line or link elsewhere in the same file by suggesting the headings it could go under. Three modes are recorded: no classification, which lists target sections by their position in the file; classification by a language model, useful when the file holds little data; and a naive Bayes classifier, the recommended mode, which ranks headings by the distribution of words already under them and improves as it is used. The README names sorting bookmarks into categories as an example of the workflow.
