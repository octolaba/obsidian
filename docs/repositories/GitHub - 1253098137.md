# MDerman/context_nine_obsidian_plugin

The repository holds Context Nine, a desktop-only Obsidian plugin bundling TaskNotes capture, context routing, a vault command cockpit and attachment cleanup. It captures selected Markdown into a new TaskNotes task or appends it to an existing one, copies the current note's vault-relative directory, routes attachment links and inbox attachments into destination context folders, moves TaskNotes files when their context fields change, adds delete actions in the file explorer and in Bases kanban cards, and replaces open past periodic-note tabs with the current ones. A right sidebar command centre and a full-screen control room run vault terminal commands for backup, sync, upgrade, logs and setup; the README states that these use local Node process interfaces, which is why the plugin is desktop-only.
