# SeanMcOwen/Quick-Note-Obsidian-Plugin

This plugin, described in its own README as at a very early stage, is meant to speed up note taking and linking in Obsidian. Find Possible Aliases collects every display name used in links pointing at the current note that is not yet listed as an alias and offers to add them to the note's aliases metadata, while Solidify Links rewrites plain links to the note into the piped form, so that renaming the note no longer changes the display names of its links. Further actions work from a selection in the right-click menu: silently creating a note without navigating to it, the same with a different name, and linking a selected display name to a note as an alias.
