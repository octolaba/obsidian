# serafinovsky/bases-heatmap-view

Bases Heatmap View adds a GitHub-contributions-style heatmap for any date-based property in an Obsidian Bases table, drawing color-coded squares to track activity, habits or progress. The README's usage is to filter the records first, create a view of type Heatmap, then pick the property to display and adjust the remaining settings.
