# seongchan/DayTimeTracker

Repository for DayTime Tracker, an Obsidian plugin whose recorded description is in Korean and whose README describes logging daily activities on a 10-minute grid timetable stored in the note. Logs are overlaid on the timeline as colour chips by category, and a collapsible to-do list beneath it can create a linked log when an item is completed or delete that log when the item is unchecked. Settings cover the day's hour range, a Korean or English interface, category editing, and the README also lists a today's-daily-note button and PDF or HTML export.
