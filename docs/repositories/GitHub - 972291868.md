# rodolfo-terriquez/images-to-notes

Transcribes photographs of handwritten or printed notes into Markdown using a hosted model, creating one note per image and adding the image at the bottom of that note. Images dropped into a folder in the file explorer are queued and processed one after another, and jpg, jpeg, png and heic files are accepted. Settings hold the API provider, one of OpenAI, Anthropic, Google, Mistral or GitHub Copilot, with its key or login, the model, the system and user prompts, and the naming convention for new notes. Transcription can be restricted to images added to one chosen folder, and the destination for processed images is configurable.
