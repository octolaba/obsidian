# ricparks/note-maker-ai

This repository holds NoteMakerAI, an Obsidian plugin that turns a photo into a structured note with properties intended for use with Obsidian's Bases feature. Subjects such as Wine, Albums or Recipes are defined in YAML files, and the selected model extracts metadata, writes summaries and gathers further information about the subject in the photo. The README lists batch processing, an iterative redo with custom instructions and image optimization, and records that the user must supply their own API key for a provider such as OpenAI, Gemini, Anthropic or OpenRouter.
