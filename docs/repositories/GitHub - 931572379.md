# michalekmatej/obsidian.md-ascii-tree-generator

Obsidian plugin that renders indented outlines as ASCII tree diagrams inside a note. A code block carrying the tree language identifier accepts either standard Markdown list syntax, with unordered or ordered items and tab indentation, or equals signs where each sign stands for one level of nesting. Nesting levels are unlimited, the output is drawn with box-drawing characters, and the README states that trees are rendered in both preview and editing modes.
