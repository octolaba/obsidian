# kpaede/docxidian

docxidian opens Word documents directly inside Obsidian through a custom file view and saves edits back to the same vault file, either from the editor toolbar's save action or a save command. Documents can also be embedded read-only with the standard embed syntax. The README states the plugin is based on the DOCX EDITOR project and its Vite and React example, that it is not yet part of the community plugins and is installed through BRAT or by hand, and it carries the author's disclaimer that the work exceeds his own programming skills and therefore always carries a residual risk.
