# Artin0r/artinors-kanban

Kanban board for Obsidian backed by plain Markdown, one file per board, with columns, cards and metadata kept as text that can be edited by hand and diffed. Cards carry titles and Markdown descriptions, due dates with shortcuts and overdue highlighting, recurring schedules, tags, arbitrary custom fields, inline checklists with a progress bar and a cover colour, and both cards and column headers move by drag and drop. Columns support renaming, per-column card limits with a warning, sorting, collapsing and accent colours, while an archive column keeps cards instead of deleting them and reschedules recurring ones. The README also lists live search and tag filters, auto-move when a checklist completes, card templates, and CSV and Trello-compatible JSON import and export.
