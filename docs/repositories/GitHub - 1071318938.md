# PixeroJan/obsidian-toword

ToWord exports Obsidian Markdown files to Microsoft Word documents that are written into the vault rather than downloaded through the browser. The README states that headings, lists, tables, code blocks and blockquotes are converted, that bold, italic, strikethrough, highlights and inline code are preserved, and that fonts and sizes follow the current Obsidian appearance, with syntax highlighting applied to code. Page size can be chosen from A4, A5, A3, Letter, Legal or Tabloid, and output can go to the note's own folder, the vault root or a custom folder. Version 1.4.0 is described as a rewrite for mobile compatibility that resolved Buffer API incompatibilities, and export can be triggered from a ribbon icon, the command palette or the file context menu.
