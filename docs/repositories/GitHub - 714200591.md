# amatya-aditya/obsidian-media-slider

Media Slider groups images, videos including YouTube, audio files, PDFs and Markdown files into a slider inside a note, so similar media take less vertical space. It offers a compare mode for before-and-after images, zoom and pan, a range of transition effects, a thumbnail carousel with configurable position, fullscreen viewing and quick copying of a Markdown image link. Notes can be written and saved per slide, drawing annotations can be made directly on images, and audio and video playback can be shown as a waveform visualization.
