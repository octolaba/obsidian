# fontsource/obsidian-fontsource

This repository holds Fontsource for Obsidian, described upstream as a plugin to load custom fonts from Fontsource into Obsidian. The README says imported fonts become available throughout the application including popout windows, that several fonts can be assigned to the interface, text and monospace roles and ordered by precedence to cover more languages, and that this version requires Obsidian 1.12 or newer. On the network it states that the plugin contacts only the Fontsource API for the directory and metadata and a CDN for the selected WOFF2 files, caching them as CSS files under the vault's configured Obsidian folder.
