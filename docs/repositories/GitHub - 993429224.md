# maksim77/obsidian-jira

The recorded description says the plugin creates and syncs Jira issues as Markdown notes in Obsidian, with customizable templates and automatic updates. Per the README an issue key selected in the editor is turned into a note by a command that fetches the issue and renders it through a configurable template, while individual or all tracked issues are updated with a single click, including from a status-bar button on the open issue note. The Jira API URL, username and password, the path where issue notes are saved and the Markdown template are set in the plugin settings, and TLS certificate errors can be ignored for self-signed servers. The README records that the plugin was not yet available in the community plugins list.
