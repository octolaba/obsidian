# alpppine/click-to-edit

Obsidian plugin that opens every note in reader mode and flips it to edit mode when the rendered note is clicked. The README states that the cursor is placed at the end of the note by default, with the top of the note or the click position as alternatives, and that a double-click mode toggling in both directions can be used instead of the single click. It also states that pop-out windows behave the same, that clicks on links, tags, task checkboxes and fold buttons keep their normal behaviour, and that switching is deferred while text is being selected.
