# aviral-batra/obsidian-power-search

The repository holds Obsidian Power Search, a plugin that searches notes while the reader is typing, across Obsidian's own notes and an Anki collection. Its README gives three reasons for it: linking ideas when similar text surfaces, avoiding writing the same thing twice, and updating notes when something worth changing appears. Setup is recorded as choosing debounce refresh timeouts and enabling the indexes to search, with the Anki index additionally requiring the AnkiConnect add-on to allow requests from Obsidian's origin.
