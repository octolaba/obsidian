# AwesomeDog/obsidian-awesome-flashcard

Obsidian plugin that synchronises flashcards written in vault notes to Anki. Its stated design keeps a single source of truth by syncing in one direction only, defines a flashcard in standard Markdown without private syntax, stores no private data in the notes and does not affect Anki learning progress. The README lists support for images, audio, video, code blocks, LaTeX and tables, deck names and tags defined per file or across the vault, incremental scanning, and a link back to the corresponding Obsidian note; the one-time setup requires Anki with AnkiConnect installed.
