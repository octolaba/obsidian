# gtg922r/obsidian-numerals

Obsidian plugin that turns a math code block into a calculator. The README documents inline expressions written as ordinary inline code with a trigger prefix, one form showing only the result and one showing the whole equation, alongside full math blocks. Calculations cover units and conversions, currencies, variables defined for a note, functions, frontmatter and Dataview metadata, and values referenced from other notes, and a result can be written back into the note as an inline field.
