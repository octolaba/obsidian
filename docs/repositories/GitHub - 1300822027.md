# leethobbit/obsidian-strong-start-plugin

Strong Start is a campaign manager for tabletop roleplaying games in Obsidian, built around the eight-step preparation method of Return of the Lazy Dungeon Master. It provides a guided campaign wizard for the pitch, truths and fronts, an eight-step session worksheet covering characters, strong start, scenes, secrets and clues, locations, NPCs, monsters and rewards, a campaign dashboard, a distraction-free run mode with a session timer, built-in and user-authored random tables, and an optional 5e improvisation module. Everything the plugin creates is a plain Markdown note in the vault with its views acting as a lens over those notes, and the README discloses extensive use of an AI coding tool in the project's development.
