# jhofker/obsidian-hoarder

Karakeep Sync creates a Markdown note for each Karakeep bookmark in a designated folder and refreshes them on a configurable interval, hourly by default. Its settings hold the Karakeep API key and endpoint, the sync and attachments folders, whether existing files are updated, and filters for archived bookmarks, favourites only and excluded tags; notes can also be synced back to Karakeep. Bookmarks deleted in Karakeep can be followed locally by deleting the file, moving it to an archive folder or adding a deletion tag. The README notes that the Karakeep CORS policy has to allow requests from the Obsidian instance.
