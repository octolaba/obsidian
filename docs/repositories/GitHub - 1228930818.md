# liwbcraft/custom-translate

The repository holds Custom Translate, an Obsidian plugin that translates selected text and manages a personal vocabulary list. The README states that translation is performed by a self-hosted LibreTranslate service whose endpoint is configured in the plugin settings, and that the vocabulary entries store part of speech, definitions, examples, synonyms, antonyms, tags, frequency, CEFR level and both British and American phonetic transcriptions. Words are queried or added from the context menu, the list is opened from a sidebar icon with sorting, search and paging, and it can be exported and imported; the interface itself switches between Chinese and English.
