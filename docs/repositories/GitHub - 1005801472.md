# BARTlab/obsidian-local-history

Local Version History gives each Obsidian note its own on-disk timeline of earlier versions that survives restarts, and highlights changed, added, removed and whitespace-only lines in the editor gutter as they are typed. The README describes a diff modal with side-by-side, line-by-line, word-level inline and zero-context patch views, restoring a whole file to any version or reverting a single block, retention caps for live files and deleted-file tombstones, and pinned labelled versions. It records the plugin as fully local with no account and no network, and positions it as a complement to Obsidian Sync's server-side version history rather than a replacement.
