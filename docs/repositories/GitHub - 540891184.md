# larsmagnus/obsidian-theme-toggler

Theme Toggler sets the theme for each of Obsidian's panels separately rather than for the whole window. It adds a theme toggle button to every pane in the workspace and three commands that toggle the theme of the active pane, switch it to dark, or switch it to light. The README carries a disclaimer that the plugin is designed for the author's own use of Obsidian on macOS and is not thoroughly tested elsewhere.
