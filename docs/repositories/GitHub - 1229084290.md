# Mahdi-Massahi/obsidian-marvis

Marvis is a project planner and habit tracker for Obsidian in which projects, milestones, tasks, logs, habits and events are ordinary Markdown notes with frontmatter, rendered through Kanban, Timeline, Calendar and Table views that share drag-and-drop, filtering and fuzzy search. The README records a voice or text assistant built on Google Gemini Live that knows the open note and gates every vault write behind a confirmation modal using a user-supplied API key, one-way recurrence-aware import of Apple Calendars on macOS, and a bundled skill that lets coding agents work against the planning notes when a project folder is symlinked into a code repository. Every view is stated to work on Obsidian for iOS and Android with macOS-only features hidden elsewhere, and the README warns that the plugin is new and still rough.
