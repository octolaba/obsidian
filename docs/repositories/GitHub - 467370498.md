# anselmwang/obsidian-vim-multibyte-char-search

This plugin makes searching for multibyte characters easier while Obsidian's Vim mode is on, by matching them through the first letters of their input-method encoding. In the Chinese pinyin method the encoding of a two-character word is a pair of syllables, so typing their initials in the Search Multibytes command finds the word, and n then repeats the search. The README states that Vim mode has to be turned on for the plugin to work.
