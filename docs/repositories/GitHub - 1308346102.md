# licc168/obsidian-htmlto-link

Publishes the current note as a web page through an external sharing service and copies the resulting public link. It offers more than thirty page templates with per-template color themes, a command to delete a previously created share, and optional frontmatter fields recording the share link and its update time. Settings cover an optional API token, which the README says an empty value replaces with a guest share lasting 24 hours, plus default template, theme class, interface language, clipboard and browser behaviour. The README also states that the note content is sent to the configured API service.
