# dsebastien/obsidian-ghost-publish

Publishes vault notes to a Ghost blog through named presets, each capturing a publication target — tags, an optional newsletter, a canonical URL strategy and a status — and appearing as a tab in a side panel with triage, queue and recently-published sub-tabs. Each note's body is hashed so unchanged notes skip the round trip, and Ghost post identifiers are recorded in frontmatter for in-place updates. Image embeds are uploaded and rewritten as Ghost image cards, wikilinks resolve through a known-URL map with fallbacks, video links and link blocks become embed and bookmark cards, and markdown footnotes are rendered as footnote anchors with a footnotes section. The README records the plugin as desktop only, needing a Ghost URL and Admin API key, with configurable frontmatter property names so existing vault conventions can be kept.
