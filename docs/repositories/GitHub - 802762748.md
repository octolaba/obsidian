# Sheeplet1/obsidian-pin-enhancer

Pin Enhancer extends the standard pin behaviour by preventing pinned tabs from being closed. It blocks closing a pinned tab with a middle click and adds alternative close commands that the user can bind in place of the standard close hotkeys, which take priority without the originals having to be unbound. The README also records what the plugin does not do: it does not block the close buttons in the context menu, which it leaves as an easy way to close pinned tabs, and it does not provide alternatives for every close command.
