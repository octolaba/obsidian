# yangcht/obsidian-things-toolkit

Things Toolkit imports completed and cancelled items from the Things 3 Logbook into Obsidian daily notes, creating a missing daily note when synced items exist for that day. A sidebar review calendar shows completed-task counts per day with the current streak and a seven-day total, grouped by month with ISO week numbers, and reports monthly totals, active-day counts and the best day; clicking a day opens or creates its daily note. A day can be marked good, steady or needing improvement with a short reflection, stored in the daily note under a dedicated frontmatter property. The README records two access paths to the Things database, direct SQLite and an AppleScript fallback when macOS privacy blocks it, with an automatic mode that tries SQLite first.
