# GenoZhou/easy-recall

Easy Recall builds spaced-repetition cards from Markdown already written in a note: a highlight marks a cloze and a trailing question mark marks a question, cards are separated by blank lines, and decks come from file-level easy-recall tags. The README states that reviewing uses three ratings — Again, Hard and Good — and that an Again card returns to the tail of the queue within the same session. It describes a Quick Switcher-style deck selector, a choice between reviewing in a modal or an Obsidian tab, mobile support, and an interface that follows Obsidian's English or Chinese language setting.
