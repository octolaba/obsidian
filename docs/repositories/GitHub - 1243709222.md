# CrEagleOne/obsidian-iconik

Iconik assigns icons and colours to individual files and folders in the Obsidian file explorer, all from the explorer's right-click menu. Any Lucide icon can be attached to a file or folder and given its own colour, icons persist across restarts, and they can be removed one at a time or reset in bulk from settings. Separately, a file or folder name can be given a text colour and a background colour, chosen from twelve presets or a full colour picker with a preview before applying. The README states that the colours are applied through a single injected CSS stylesheet.
