# oylbin/obsidian-yuque-publish

Yuque Publish sends an Obsidian note to Yuque, a Chinese knowledge management platform, creating the document there or updating it if it already exists. A note carries frontmatter naming the target document URL and optionally a title and a visibility value covering private, public and space-member access, after which a Publish to Yuque command performs the transfer. Personal and team accounts are both supported, each configured as a group entry holding a URL prefix and an access token, and several such configurations may coexist. The README is written in Chinese and English.
