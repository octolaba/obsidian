# djayatillake/obsidian-llm-tagger

The repository records no description; its README presents LLM Tagger, a plugin that tags notes using large language models run locally through Ollama. It generates tags for a note and can write a brief summary alongside them while keeping the original content, works from a user-supplied tag list, and skips files that have not changed since they were last processed. Auto-tagging can run on new or modified files and on closing a file, while files being edited are skipped and exclusion patterns by filename, folder or wildcard keep parts of the vault out. Configuration covers the Ollama server URL, which may be remote, the model, and the default tags; the README requires Obsidian 1.0.0 or higher and a running Ollama installation.
