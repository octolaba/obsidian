# nickolay-kondratyev/obsidian-plugin-collapsible-details

Repository for Details Markdown, an Obsidian plugin that renders Markdown inside native HTML details and summary blocks, which Obsidian deliberately leaves as literal text. The README limits rendering to Reading view and states that Live Preview is not yet supported, and it describes the supported block shape: an optional single-line summary, a body up to the closing tag, and unsupported, malformed or unclosed blocks left at native behaviour. A single settings toggle disables the plugin and returns Obsidian's own output with nothing left behind.
