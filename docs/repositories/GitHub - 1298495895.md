# 7eahaus/dissociated-identitea

Dissociated IdentiTea is an Obsidian theme built around several subthemes rather than one look, with base light and dark modes and colours customisable through the Style Settings plugin, including the rainbow colours it applies by default. It adds custom callout types, among them a Creative callout for work needing a creative touch, and custom checkboxes for in progress, important, later, more info needed, cancelled, favorite and love. Its README describes the theme as being in its very beginning stages and marks the subthemes as still to come.
