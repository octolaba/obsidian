# kiitosu/yearly-diary-comparator

This plugin adds a yearly calendar view over Obsidian daily notes that places the entries for the same date in different years side by side, so activities or diary entries can be compared across years. A headline keyword, by default a daily-summary marker, tells the plugin which part of a daily note to extract as that day's summary. The keyword and the width of each year column are configurable, and the view is toggled from a ribbon icon.
