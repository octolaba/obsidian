# davidmonnom/obsidian-pr-tracker

Tracks GitHub pull requests in a sidebar panel grouped by status or by repository, each row showing title, repository, number, author, target branch, diff statistics and last update. A bracketed title prefix is pulled out into a coloured badge, the dominant review state appears as a pill beside the full reviewer list and their statuses, and the combined commit status is displayed, which the README says is optimised for custom pipelines reporting through the GitHub commit statuses API. Pull requests are added by pasting a URL that is normalised so the same one is not added twice, rows offer refresh, pin and remove, and sort, group and collapse choices persist between sessions. The README states the personal access token is kept in the system keychain through Obsidian's secret storage and never written to disk, and that closed pull requests stay in the list but are never auto-refreshed.
