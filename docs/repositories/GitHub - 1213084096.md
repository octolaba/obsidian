# nightfall-yl/obsidian-third-party-sync

Obsidian Third-party Sync is an unofficial fork of Remotely Save that synchronises a vault with a third-party storage service. The fork narrows the original's thirteen storage back ends to three, namely S3, WebDAV and OneDrive, and rebuilds the encryption: the README records AES-256-GCM with authentication-tag integrity checking, a randomly generated initialisation vector per file, a sixteen-byte salt and the browser-native crypto API in place of the original's ciphers and dependencies. It states explicitly that the plugin is not the official Obsidian sync service and that it is not backwards compatible with Remotely Save, advising a vault backup before switching. The repository description is written in Chinese and describes the plugin in the same terms, as a slimmed-down Remotely Save keeping only those three services.
