# comwhore/obsidian-comshit

Obsidian desktop plugin bundling Canvas mind-mapping shortcuts, paired Markdown and Canvas files, OSINT command-line integrations and spreadsheet support in one plugin folder. The README lists Canvas keyboard shortcuts, bidirectional debounced sync between a note and its canvas, commands to create, convert and open graph pairs, integration with the Sherlock, Maigret and Social Analyzer tools which are not bundled and must be installed separately, and an embedded spreadsheet runtime for sheet files. It states a minimum Obsidian version of 1.4.16, and asks that the separate Excel community plugin be disabled to avoid duplicate registration.
