# tcyeee/obsidian-image-cluster

Obsidian Image Cluster is a plugin that combines several images in a note into a single group, described by its README as making the note interface more organized. Images are wrapped through a right-click command, and in Reading mode a settings button in the corner of a group opens its style controls. The group's style is stored in the first line of an `imgs` code block, ending in `;;`, where parameters such as size, gap, radius, shadow and border can be edited by hand.
