# visini/obsidian-icons-plugin

The repository holds the Obsidian Icons plugin, which adds icons to notes and is described by its own README as experimental. Recorded icon sets are Remix Icon with 2172 icons and the free FontAwesome set with 1560, and the settings choose which sets appear in the icon picker. The README states that icons are rendered through react-icons from a Markdown postprocessor, and credits the citation plugin as inspiration and the official sample plugin as the base.
