# picassio/central-vault-sync

A revision-safe two-way sync client between an Obsidian vault and a self-hosted WebObsidian server, where the server is authoritative and every accepted mutation receives an identity, revision, content hash and journal sequence. The README lists the safety properties it claims: no silent overwrite of a stale server revision, local operations published before newer remote bytes are pulled, deterministic three-way merge only for independent UTF-8 text edits with overlaps and binary divergence becoming conflict copies, SHA-256 and byte-length verification of every transfer, and credentials kept in Obsidian SecretStorage rather than in data.json. The README marks the current release as a community review release that is not yet listed in Community Plugins.
