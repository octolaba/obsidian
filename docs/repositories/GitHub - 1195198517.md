# PandaNocturne/obsidian-advanced-search-ui

Obsidian plugin that adds a graphical builder on top of Obsidian's native search syntax, so a complex query can be assembled without memorising it. Conditions combine with AND, OR and NOT and target all, file, tag, path, content, line, block, section and task scopes including completed and incomplete tasks, with regular expressions and case-sensitive matching available. A picker inserts existing files, tags or folder paths, rows are added and removed individually, and conditions can be gathered into groups that collapse, reorder by drag and drop, move between panels and be copied from a right-click menu. The panel can also stand alone as a floating window, and conditions can be sent into Graph view with colour group configurations imported back.
