# jordanhandy/obsidian-cloudinary-uploader

Obsidian plugin that uploads media pasted into a note to a Cloudinary account instead of storing it in the vault. The README states that images, video, audio and raw files are supported, that Cloudinary's custom parameters can be used to transform the stored media, and that configuration covers a cloud name, an upload preset and a folder name. It also records that the uploads are unsigned and points to its own separate documentation for the details.
