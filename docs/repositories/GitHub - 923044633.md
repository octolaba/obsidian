# shkarlsson/obsidian-discrete

Repository for Discrete, an Obsidian plugin that filters files in the file explorer by their frontmatter metadata, hiding or showing the ones that match a rule. A rule names a frontmatter key, an operator — exact equality, contains text, field exists, includes a value in a list, greater than or less than — and a typed value; the README's examples hide notes whose status equals completed, show notes whose numeric priority is greater than three, and filter by a tag present in an array. It states that the plugin was developed with aider and is released under the MIT licence.
