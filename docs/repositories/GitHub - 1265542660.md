# arias007/obsidian-pdf-edition

Pdftion annotates and edits PDFs inside Obsidian, adding editable pen and highlighter strokes, text overlays with color, opacity, size and font controls, cover blocks that visually hide original content, and image overlays taken from captured regions or vault files. Its README records selecting, moving, resizing, deleting, undoing and redoing the elements the plugin creates, separate settings per tool, an icon-first toolbar, a quick menu on native PDF text selection for highlighting and for copying a page-aware vault link whose alias carries the selected text and the PDF name, and localization that follows Obsidian with an English fallback. Annotation data is saved automatically as editable data, while the share menu exports a burned-in copy matching the visible annotated view, beside the other export formats the README lists.
