# Shumpei-Tanaka/obsidian-short-tab-name

Short Tab Name hides a leading part of a filename, such as a Zettelkasten identifier, from the name shown on an Obsidian tab. The hidden range is defined by a regular expression in the settings, with a default that strips a run of digits followed by a hyphen, so a file named with a timestamp prefix shows only the remainder in its tab. The README gives further patterns for prefixes ending in an underscore or for any prefix up to a hyphen, and states that the plugin needs no configuration beyond installation when the default pattern fits.
