# mikevetkin/obsidian-tengwar

Tengwar for Obsidian renders text written in the Tengwar script inside a note. The README records that the text goes into a code block whose language keyword is teng, and that a font can be chosen per block by appending its name to that keyword, listing several bundled font names. It states that the keyword itself can be changed in the settings, in which case the font name is appended to the new keyword instead, and that both ways the community uses to represent Tengwar on a computer, ISO 8859-1 and the ConScript Unicode Registry, are supported.
