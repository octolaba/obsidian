# agentage/obsidian-sync

Obsidian plugin that syncs a vault two ways over Git into a hosted memory and exposes the same content over MCP, so clients such as Claude, ChatGPT or Cursor read and write the same notes. Each memory is a bare git repository that can be cloned or exported at any time, and one dialog picks an existing memory or creates a new one. Notes stay plain Markdown, edits made in different places merge automatically and anything unmergeable is flagged rather than dropped silently, while sign-in access is kept in Obsidian's encrypted storage rather than in notes or config. A status-bar dot, the command palette and the ribbon all offer sync, dashboard and settings; the plugin is desktop-only for now and includes up to 100 MB of storage.
