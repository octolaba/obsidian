# Railly/agentfiles

Obsidian plugin for managing AI agent files - skills, commands, rules and agents - across coding tools including Claude Code, Cursor, Codex and Windsurf, read from each tool's own directories. Files are browsed in one place, searched by name or through a deep content search, created with a stepped wizard that asks for tool, type and name, and edited inline with Markdown preview. It also installs skills from a marketplace, browses Claude Code session history for tagging and export into the vault, and shows a usage dashboard that depends on a separate skillkit package. The repository description counts 12 coding tools while the README counts 17.
