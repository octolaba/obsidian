# ohm-en/obsidian-plugin-manager

Plugin Manager provides management for other Obsidian plugins, with two features recorded in its README: a startup delay in seconds set per plugin on the manager's settings page, and quick toggling of a given plugin from the command palette or a configured hotkey. The README is written as a literate Org document that carries the plugin's source alongside its description, and it records that the program depends only on the Obsidian API. Installation instructions cover placing the release files by hand in a folder under the vault's plugins directory.
