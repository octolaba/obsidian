# Synaphi/background-tray

A desktop Obsidian plugin that hides the window to the system tray when it is closed instead of quitting the app. The tray icon toggles the window on left click and offers show or hide, relaunch and quit from its right-click menu, using Obsidian's own icon unless a custom one and tooltip are configured, and an optional single-instance behaviour restores the hidden window when Obsidian is launched again rather than opening the vault switcher. The README states the point of keeping the process alive — background sync continues and reopening is immediate — describes the plugin as deliberately single-purpose and a reimplementation of the unmaintained obsidian-tray, and records Windows and macOS as fully supported with Linux tray behaviour best-effort.
