# 0x-DLN/obsidian-table-checkboxes

This plugin replaces Markdown checkboxes written inside Markdown tables with HTML checkboxes, so they can be ticked in view mode with the resulting state written back into the file. Conversion happens as the closing bracket of a checkbox is typed, and a command converts every checkbox in the current file at once, with a setting that extends the conversion to checkboxes outside tables as well. A further command regenerates all checkbox identifiers, and the README records that the plugin is listed in the community store as Markdown table checkboxes.
