# mnaoumov/obsidian-codescript-toolkit

Runs JavaScript and TypeScript from inside Obsidian, targeting the places where scripts are already written: the DevTools console, dataviewjs, datacore, JS Engine, CustomJS, Modules, QuickAdd and Templater blocks. The README states that it allows modular scripts written in modern JavaScript and TypeScript syntax, and records that the plugin was formerly named Fix Require Modules.
