# dgalichet/obsidian-kb-plugin

Obsidian plugin that wraps a separate local knowledge-base service, giving the vault lexical, semantic and graph-aware search with related-note discovery, and exposing the same retrieval layer over MCP to agents such as Codex, Claude Code and OpenCode. The README calls it a user-interface and lifecycle wrapper rather than a chat plugin or a search engine of its own: the companion command-line tool has to be installed on the same machine, and on desktop the plugin starts it as a local process and talks to it over localhost HTTP. A side panel carries search, related notes and index maintenance, and the README states that the vault is not uploaded to a hosted knowledge service.
