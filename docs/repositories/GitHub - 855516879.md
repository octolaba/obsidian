# crayhuang/Obsidian-Hugo-Sync

Copies selected notes from the vault into a Hugo site's content directory, converting Obsidian-style Markdown and frontmatter into a Hugo-compatible format. Obsidian tags are converted to Hugo tags from either inline or list frontmatter syntax, while pure symbol tags are ignored. Headings listed in the filtered-headers setting are dropped together with everything beneath them up to the next heading of the same or higher level. The Hugo project root and the content subdirectory are set in the plugin settings, and syncing runs from a ribbon icon or a command over the file explorer selection.
