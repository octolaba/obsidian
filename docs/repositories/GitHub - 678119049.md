# buszk/obsidian-ai-editor

The AI Editor plugin sends the content of an Obsidian document to a language model and brings the result back into the app. Commands are user-defined and configurable: each carries its own prompt, the text selection it acts on and what is done with the output, and the plugin ships a text-summarization command as a demonstration. The README states that an OpenAI API key is entered in the plugin's settings tab and that the app must be reloaded before a newly added command is registered.
