# hydescarf/Obsidian-Theme-Mado-11

Mado 11 is an Obsidian theme inspired by Windows 11 interface styling, aiming for a simplified but spacious app feel with bigger buttons in the sidebar. Its README states that the theme is in maintenance mode, with infrequent updates and no feature or pull requests accepted. Style Settings support is recorded as covering theme colours, basic layout changes, hiding and unhiding elements and some markdown styling, and the README documents Mado CSS classes such as a heading class and an explorer class that turns a note into a pseudo file explorer under stated markup rules.
