# asonas/obsidian-akaire

Obsidian plugin that sends a note, or only the paragraphs changed since the last review, to Claude Code and renders the returned comments in a sidebar anchored to the paragraph each one is about. Review sessions are stored in the note's frontmatter, so reopening the file keeps the comments visible, and textlint runs in parallel where it is installed, with its findings listed beside the AI comments. It is Claude-only and desktop-only: the plugin shells out to the `claude` command and reads its streaming JSON output directly, which the README gives as the reason other providers are not planned, and Obsidian 1.7.2 or newer is required. The name comes from the red-pen marks a Japanese editor leaves on a manuscript.
