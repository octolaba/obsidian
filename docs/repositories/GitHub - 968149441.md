# Jacobinwwey/obsidian-NotEMD

Obsidian plugin that integrates with large language models to process notes and build a knowledge base inside the vault. Its recorded output is written back into the vault as files rather than left in a chat session: wiki-links connecting key concepts, concept notes for those terms, research summaries with source citations, translations, and Mermaid diagrams and charts. The README states that it works with more than thirty models and that its documentation is published in many languages.
