# shepherdjerred/cooklang-for-obsidian

The repository holds Cooklang Rich Preview, an Obsidian plugin that previews Cooklang recipe files carrying the cook extension. It renders ingredients, cookware and timers as highlighted elements, reads YAML frontmatter for metadata such as title, servings and preparation time, renders sections as an ingredient list and numbered directions, shows inline quantities, and supports checkboxes in ingredient lists. The README states that it also provides syntax highlighting for the source files and handles plain-text recipes as well as Cooklang markup.
