# sahilium/obsidian-life-log

Life Log is described as logging everyday life events in the manner of commits, with the person as the repository. The README positions it as neither a journal nor a habit tracker but a timeline: each atomic event, trivial or significant, is captured as its own Markdown file with YAML frontmatter, so the record stays portable and version-control friendly. Capture runs from the command palette, and the sidebar groups events by year, month and day with newest first, alongside case-insensitive title search, a today-in-history view, and a fixed set of event types covering health, dreams, travel, career, purchases, food, exercise, books, movies, relationships and other.
