# SirwanAfifi/inkplane

Adds a handwriting and sketching canvas to Obsidian, stored as portable drawing files in the vault that can be opened edge to edge or embedded read-only in a note. Drawing tools include a pressure-aware pen and highlighter, an area eraser that removes only the touched part of a stroke, lasso selection, undo and redo, infinite pan and pinch zoom, and SVG export to a normal vault attachment. Settings cover the folder for new drawings, default embed dimensions, pen and eraser behaviour, palm rejection, optional finger or mouse drawing, and toolbar placement. The README states the plugin makes no network requests and collects no analytics or telemetry.
