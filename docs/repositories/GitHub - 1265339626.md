# rezgi/obsidian-list-fold

Obsidian plugin that folds and unfolds list items only, leaving headings untouched, which the built-in fold-all command does not do. One command toggles folding of root-level list items in the current note and another toggles every nested list level recursively; both inspect the current state, unfolding when most target items are already folded and folding otherwise. The README states that it works alongside the Outliner plugin and requires desktop Obsidian because it uses CodeMirror editor APIs.
