# gorf/obsidian-block-step-reader

Block Step Reader is a maintenance fork of Galacsh/obsidian-reading-view-enhancer that focuses on step reading in Obsidian. It adds keyboard block navigation with J and K or the arrow keys, highlights and auto-centres the current block, and shows a reading progress bar with a remaining-time estimate in both reading and editing views. A reading library sidebar filters notes into to-read, reading, unread and read, sorts by recent update, progress or title, and notes can be marked read or unread. Reading position is remembered per user in note frontmatter for shared vaults, and the interface is offered in English, Simplified Chinese and Traditional Chinese.
