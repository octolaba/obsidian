# cosmicoptima/loom

This repository is an Obsidian implementation of Loom, a recursively branching interface to language models aimed at exploratory and experimental use of base models. From a point in the text a shortcut generates several child nodes of the current node, each holding a different completion of the text up to the cursor, paired with a tree interface and settings panel in the right sidebar and a pane showing the current node and its siblings. The README records completion providers including Cohere, TextSynth, OpenAI and Azure OpenAI Service, together with proxy implementations whose base URL is set in the plugin's settings tab.
