# kanshurichard/obsidian-docx-exporter

DOCX Exporter is an Obsidian plugin for exporting note content to DOCX format. The README states it has zero external dependencies and needs no Pandoc, so it runs on desktop, mobile and iPad, and it exports headings, bold, italics, lists, hyperlinks, code blocks and local or web images. It records a known issue that exported files may render incorrectly in Apple Pages or the system Preview app, with the workaround of opening and re-saving the file in Microsoft Word.
