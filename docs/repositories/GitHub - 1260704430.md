# MichelleGDyason/obsidian-literature-flow

Obsidian plugin for open-access literature discovery, reference management and citation mapping. OpenAlex is its default source and an open-access-only filter is applied to searches, to cited and citing works and to the literature graph. Its sidebar offers static and dynamic reference lists alongside a search view and a graph view, and the README serves as the project's documentation. The README also records that the plugin is a modified version of anoopkcn/obsidian-reference-map, renamed and extended with OpenAlex search in June 2026, with attribution kept in a separate notice file.
