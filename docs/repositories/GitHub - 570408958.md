# d2lang/d2-obsidian

This is the official Obsidian plugin for D2, a diagram scripting language that turns text into diagrams: a fenced code block tagged d2 is rendered as a diagram. The README states that the plugin currently calls a local D2 installation, which must be installed separately, and that a remote API is planned but not available. Settings cover the layout engine, theme id, padding, sketch mode, container height, a debounce interval before refreshing, and an explicit path to the d2 executable when the plugin cannot locate it.
