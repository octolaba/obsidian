# HoBeedzc/obsidian-header-enhancer-plugin

Header Enhancer adds hierarchical numbering to Markdown headers and keeps it updated as the document changes, with a master switch for the vault and per-document control, header level detection, configurable separators, a selectable start level and bulk operations across the vault behind confirmation dialogs. It also updates links of the form file#header when a header changes, in batches and in both directions. Font family and size can be set separately for headers and document titles, and per-file behaviour is configured through YAML frontmatter, which since version 0.5.0 carries defaults so the frontmatter no longer has to be added to every file.
