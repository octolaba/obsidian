# cdloh/obsidian-cron

Obsidian Cron schedules Obsidian commands and user scripts to run automatically. Each job in the settings carries a name, the command to run and a cron expression for its frequency, plus toggles for running on mobile — off by default — for its lock and for a per-job sync check. An exposed JavaScript API registers user functions as jobs, keyed by name across reloads and receiving the app instance as their only parameter; locks recorded at the start of each run prevent concurrent execution of the same job and can be cleared from the settings, and the sync check makes jobs wait for Obsidian Sync to complete before running.
