# TheManuelML/obsidian-tradeview

This plugin adds a stock view inside Obsidian built from TradingView's free embeddable widgets, configured from a settings panel and opened through a ribbon icon or a command. Eight widget types are available, including an advanced chart, stock, crypto and forex heatmaps, a ticker tape, a single quote, symbol information and a symbol summary, and the default widget, symbol and theme are set in the settings while the active widget can be changed from inside the view. The README states that the plugin is desktop only and requires an internet connection because the widgets and their data are loaded from TradingView servers, that the plugin is not affiliated with TradingView, and that no market data is written into notes or stored in the vault beyond the plugin's own preferences.
