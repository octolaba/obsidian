# RieTamura/Post-To-Bluesky

Post To Bluesky posts to Bluesky from inside Obsidian, and its README is published in parallel English and Japanese versions. Recorded features are writing the post in Markdown so that link syntax becomes a real link while other markers are stripped, posting from draft notes in the vault, keeping unsent text as a draft note when the composer is closed, automatic post history notes, linking a post to a chosen note with date variables, an emoji picker and default hashtags. Desktop and mobile are both supported, and up to four images from the vault or the device can be attached and are recorded in the draft and history notes.
