# kalvn/obsidian-export-to-html

Obsidian plugin that exports the content of a note as HTML, either copied to the clipboard or downloaded as an HTML file, through two commands in the command palette. Images are copied into the export in base 64 form, so pasted output keeps its styling in a mail client or a word processor. The README states that the plugin is a work in progress, that some edge cases in inline image export remain to be improved, and that the Obsidian mobile apps are not yet supported.
