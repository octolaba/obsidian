# yipqp/obsidian-scrobble

Scrobble is an Obsidian plugin for logging thoughts about Spotify songs and albums, named after the record of a listened track in Last.fm. The README describes logging the currently playing or a recently played song or searching Spotify, creating song and album notes with populated frontmatter, timestamping the thoughts written on them, and linking related songs with context recorded on each. It records that a Spotify Premium account is required to reach the API after the February 2026 platform changes, and that new notes are named with Spotify identifiers, so it suggests the Front Matter Title plugin to display readable filenames.
