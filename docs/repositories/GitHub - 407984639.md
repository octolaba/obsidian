# tim-hub/obsidian-bible-reference

Source for an Obsidian plugin for Bible study notes, with automatic verse and reference suggestions. Typing a double hyphen followed by a reference such as John1:1 offers a suggestion to insert, a trailing chapter marker inserts all verses of a chapter, and a separate trigger inserts a verse of the day. The README records a link-only setting and an insert-link command that add only a reference and never fetch, Polish translations including UBG and BG, and a known conflict on iOS between smart punctuation and the double-hyphen trigger.
