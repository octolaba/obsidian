# bjsi/incremental-writing

The repository holds the Incremental Writing plugin for Obsidian, which adds notes and blocks from the vault to prioritized queues that are reviewed a little at a time. Its README ties the practice to the SuperMemo notion of incremental writing and points at introductory and getting-started videos and an article by the same author. The code is written in TypeScript under the MIT license.
