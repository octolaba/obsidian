# israerusan/patina

Patina scores how stale each note in a vault is, ranks the results into a review worklist and dims the stale notes in the file explorer. The score combines the file's modification time, when the note was last opened, which Obsidian does not record and the plugin logs itself, and the recency of the newest note still linking to it, weighted 0.5, 0.3 and 0.2 and decayed on a half-life; it runs from 0 to 100 and falls into fresh, aging, stale and decayed bands. The weights are renormalized over the signals that actually exist, so a note with no inbound links is not punished for having none. The README states that Patina never edits notes apart from writing a decay line into frontmatter when that command is run explicitly.
