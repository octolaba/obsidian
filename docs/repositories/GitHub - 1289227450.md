# AkiSantin/VaultPack

VaultPack exports selected Obsidian content, including Bases views, into a self-contained static website that reads offline. Root base pages and base embeds are exported with named views, groups, formula columns, display-name headers, summaries and table, list or card layouts, and note pages keep their properties block, callouts, footnotes, Mermaid, MathJax converted to self-contained SVG, task-list states and code blocks with an offline copy button. Five output modes are documented: a local folder opened through a start page, an AES-256 encrypted ZIP, a public web folder, a link-only folder with an unguessable name and no indexing or referrer leakage, and a password mode that generates a PHP login gate for ordinary Apache hosting. The generated site carries a sidebar with offline full-text search and a collapsible folder tree that becomes a menu button on mobile.
