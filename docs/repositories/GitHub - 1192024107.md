# swekizer/Direct-Git-Sync

Syncs an Obsidian vault with a private GitHub repository on desktop and mobile without a Git installation; the README states it uses isomorphic-git and Obsidian-friendly HTTP requests so the same flow works on both. Setup is a repository URL and a personal access token entered in settings, after which one action stages, commits, fetches, merges and pushes, from a ribbon button or on an interval. The repository and token are verified before a sync starts, a modal shows the last successful sync time and recent history, and a merge conflict keeps the local file while saving the remote version as a separate conflict copy.
