# siosig/obsidian-nextcloudsync

This repository holds Nextcloud Sync, an Obsidian plugin for bidirectional synchronization between a vault and Nextcloud, written for Nextcloud specifically rather than for generic WebDAV. The README records that it talks to Nextcloud's own APIs, naming capabilities, file ids, checksums, versions, locking and Login Flow v2, and degrades to plain WebDAV with reduced features where those APIs are unavailable. It also records an initial vault index on first install, merge logic meant to keep the vault consistent when the same note is edited on several devices at once, and a Japanese translation of the README.
