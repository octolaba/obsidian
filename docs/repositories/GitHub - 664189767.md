# aedans/mtg-card-links

MTG Card Links is an Obsidian plugin that turns a trading card name written in square brackets into a Scryfall link. Card names are fuzzy matched, so a partial or reordered name still resolves to the intended card. A set can be given after the card name separated by a vertical bar, and a collector number can follow the set in the same way.
