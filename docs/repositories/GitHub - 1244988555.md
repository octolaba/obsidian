# johannes-kaindl/json-editor

JSON Editor opens json and jsonc files in a dedicated Obsidian view with a toggle between tree and source modes. Tree mode folds and inline-edits values and restructures a document by adding, renaming, deleting and reordering keys and items and switching a value's type, while source mode is CodeMirror 6 with JSON highlighting, a parse-error banner and find. Comments and formatting in jsonc files survive editing because every tree change is applied as a targeted text edit, and an unedited open and save is byte-identical, though a free-standing comment line keeps its position when rows are reordered. Optional JSON Schema validation flags invalid rows against a companion schema file, json fences inside Markdown notes render as read-only collapsible trees, and the README states the target is Obsidian 1.5.7 or newer on desktop and mobile with no external services or telemetry.
