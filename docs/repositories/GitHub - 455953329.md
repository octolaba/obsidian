# wesmoncrief/obsidian-todoist-text

Todoist Text replaces a configurable keyword in the current file with tasks fetched from Todoist, each keyword carrying its own Todoist filter definition so the set of tasks shown is controlled by that filter. Replacement runs from a command or automatically, and folders can be excluded so that a template file keeps its keyword instead of having it consumed. With the cursor on a line created this way, a toggle command completes or reopens that task in Todoist and checks it off locally; the README asks that its security section be understood before a Todoist API token is entered in the settings.
