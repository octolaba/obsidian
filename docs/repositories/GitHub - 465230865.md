# reorx/obsidian-daily-notes-opener

Obsidian plugin for opening daily and periodic notes in a new pane, so that the action can be bound to a keyboard shortcut. It adds a command and a sidebar button, finds and focuses an already opened note to avoid redundancy unless configured otherwise, uses an end of day time so that the intended date is opened around midnight, can append a line to a chosen section after opening, and colours the daily note pane through Style Settings. The README documents those options, with an end of day default of five in the morning.
