# sn1p4am/TokenBar

TokenBar is a desktop-only Obsidian plugin that shows the active note's local token count in the status bar. Its README records a primary tokenizer setting that defaults to GPT and a hover comparison across GPT, Qwen, DeepSeek, Claude and Gemini, the last two given as local estimates because their provider tokenizers are not bundled. Counting is text-only, with embedded images and attachments excluded, and the README states that all counting happens locally, with no note content sent to remote services, no telemetry and no account required.
