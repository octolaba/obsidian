# saltyfireball/obsidian-banner-images

An Obsidian plugin that displays a banner image at the top of a note from frontmatter fields. Image sources can be vault-relative paths, wikilink-style paths or external URLs, and height, opacity, vertical position and fit mode — cover, fit to height or fit to width — are set globally or per note, with an optional gradient that fades from full opacity at the top. A command palette action inserts the banner fields into a note, adding only the ones missing, and the README states rendering in Reading View as well as Live Preview and Source mode, including full-width banners on mobile.
