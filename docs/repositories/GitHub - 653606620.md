# qing3962/password-protection

Password Protection locks Obsidian behind a password rather than encrypting anything: the README states that it does not encrypt or decrypt and does not modify notes, and only locks the app and asks for a password to unlock it. Settings enable or disable the protection with the password, set an auto-lock interval in minutes since the last correct password was typed, record a prompt to help recall the password, and list the protected folder or file, where a single slash protects the entire vault and up to six further paths can be added. The README reports that the plugin was tested on Windows and on iPhone and iPad.
