# joshua-walls/lockblock

Lockblock keeps fenced lockblock code blocks in Obsidian notes encrypted until they are revealed or edited. A setup command creates a random vault key protected by an unlock password, stores the wrapped key material in Obsidian's secretStorage and shows a recovery key; a sealed block holds one line carrying the key id, the AES-GCM algorithm, the initialization vector and the ciphertext. In reading view sealed blocks render as cards with show, hide, copy and lock actions that reveal plaintext in the interface only, and while the vault is locked edits touching sealed ciphertext are refused with an unlock action offered. Because secretStorage is device-local, a password-wrapped copy of the keyring travels through synced plugin settings, and the README warns to back up the vault first.
