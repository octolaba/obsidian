# Obsidian-TTRPG-Community/dice-roller

Dice Roller replaces an inline code block holding a dice formula with the result of the roll in preview mode, and clicking the result rolls it again. The parser supports addition, subtraction, multiplication, division and exponents over any number of dice or static numbers, with full order of operations and parentheses, faces given as a number or as a minimum and maximum pair, omitted counts and faces that fall back to configurable defaults, and percentile dice. Named formulas can be defined in the settings as aliases for common rolls, and basic Dataview inline fields can be used as numbers, with the README warning that only one field is used when a name repeats. The README also records that its documentation is moving to a separate site.
