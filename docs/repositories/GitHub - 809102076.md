# alberti42/obsidian-plugins-annotations

This plugin adds personal annotations to each installed plugin, displayed in the Community plugins settings pane directly below the plugin's own information; the README frames that as a way to keep track of why a plugin is installed and what it is used for. Annotations are typed into a text area under each plugin, saved persistently, editable at any time, and can be formatted with Markdown and carry Obsidian links. They can also be locked with a button next to the Installed plugins title, which the README pairs with the toggle that hides annotation fields for plugins that have no annotation yet.
