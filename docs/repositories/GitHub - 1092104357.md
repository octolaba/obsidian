# j2masamitu/obsidian-goboard-viewer

Displays SGF game records as interactive Go boards, both from sgf code blocks and from embedded .sgf files, with a move parameter that starts playback at a given move number. Playback controls step through the game, show per-move comments and handle variations, and game information such as players, ranks, event, date, komi, handicap and result is displayed. A separate edit mode adds placing and removing stones, labels, comment and game-info editing, deleting moves from a position onwards and copying the resulting SGF text. The README records support for desktop plus iOS and Android, SGF markup properties for labels, triangles, squares, circles and marks, several board sizes, and configurable colors.
