# AwesomeDog/obsidian-awesome-image

Obsidian plugin that keeps a vault's images in one user-defined folder. Commands copy images into that folder under a uniform name and update the links in notes, download images referenced from the internet, and list images that no note links to so they can be deleted by hand. Pasted images can be processed the moment they are pasted, whether they come from the internet or arrive in a binary format. The README warns that the plugin modifies notes and asks for a backup before first use, and states that only Markdown links are supported rather than wikilinks.
