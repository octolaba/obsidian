# jaysan0/cardinal

Cardinal is an Obsidian theme and, by its author's account in the README, their second attempt at making one. Its listed features are red accent details, subtle grid lines, support for both dark and light modes, and headings styled with more character than the default. The README closes with an invitation for suggestions and edits rather than documenting configuration options.
