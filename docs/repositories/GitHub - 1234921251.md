# 0xkz1/obsidian-asset-weaver

An Obsidian plugin that scans a target folder for images without metadata and writes a Markdown sidecar note for each one, generated by a local vision-language model rather than a cloud API. The documented workflow skips files that already have a sidecar, reports and skips zero-byte files, resizes each image to at most 768 pixels and compresses it to JPEG in a canvas before sending it to the model, scans the vault for links and embeds referencing the image, sanitises and parses the returned JSON, and writes a sidecar file whose frontmatter and body carry the result, pausing about a second between images.
