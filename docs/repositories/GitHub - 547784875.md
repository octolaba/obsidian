# shoedler/crossbow

Crossbow scans the active note for words that could be linked to a heading, a tag or a file elsewhere in the vault, and lists them as suggestions in a sidebar opened from a ribbon icon. Clicking a suggestion lists its occurrences in the note, scrolling to one shows the matched cache items ranked by match quality, and applying a match inserts the link. The README states that Crossbow reads Obsidian's internal cache rather than parsing the vault itself, strips Markdown syntax from the editor content before searching, and lets suggestions be disabled by closing the view from its icon.
