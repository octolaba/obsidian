# philips/supernote-obsidian-plugin

This unofficial plugin brings Supernote e-ink devices into Obsidian: the device's note files can be viewed inside the vault, linked to from Markdown notes, and embedded inline — the whole note with page navigation, or a single page. Notes can be exported as PNG images or Markdown files attached to the vault, every note modified on the device today can be attached to the current note by command, an image can be pulled in over screen mirroring, and files can be downloaded, uploaded or synced through the device's own browse and access feature. The README also records a beta extension point through which a companion plugin can customize how pages are recognised as text during conversion to Markdown, and the repository description names the device models covered.
