# seth10/beautiful-obsidian-contacts

This plugin renders a contact card with tappable links — phone, email, social handles and addresses — either from a note's frontmatter properties or from a `contact` code block. When properties are used the card is drawn at the top of the note in both Reading view and Live Preview on any note carrying at least one recognized field, and the raw Properties panel is hidden by default so the card is the only top panel. The README lists the supported fields as `name`, `birthday`, `phone`, `email`, `insta`, `discord` and `address`, notes that values may be YAML lists so extra names become nicknames, and states that the older code-block form still works anywhere in a note and additionally accepts repeated fields.
