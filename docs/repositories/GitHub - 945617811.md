# scottTomaszewski/obsidian-disciples-journal

Repository for Disciples Journal, an Obsidian plugin that renders Bible verse references and passages directly in notes. A reference inside an inline code block becomes a link that shows the verse text in a hover popup and can open or create the chapter note scrolled to that verse, while a `bible` code block renders a whole passage; single verses, verse ranges, entire chapters, multi-chapter passages and book names containing spaces are the recognised formats. With an ESV API token and download-on-demand enabled, referenced passages are downloaded and stored locally in a configurable folder tree by book and chapter, and the ESV HTML format is supported with poetic typesetting, section headings, footnotes and cross-references.
