# ayoyoqiu/obsidian-sakana-qiuqiu

This plugin puts a Qiuqiu widget in the Obsidian workspace as a companion while notes are written. Four characters are bundled — qiuqiu, taotao, qiuqiu2 and qiuqiu3 — and the widget is dragged to make it swing, while a controller switches character or turns automatic movement on. Custom widgets can be supplied through the plugin settings, and the README documents installation through BRAT or by copying a release into the vault's plugin folder.
