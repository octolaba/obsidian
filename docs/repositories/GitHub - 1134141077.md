# nancyel/obsidian-dynamic-font-size

Dynamic Font Size sets the font size of a note's content from a font-size frontmatter property, accepting either a numeric value or a string with a unit, and applies the change as soon as the property is edited. The README also describes a slider shown in the view header by a toggle command, which writes the chosen value back to the frontmatter, and a status bar indicator showing the current size. Minimum, maximum and default sizes are configurable in the plugin settings.
