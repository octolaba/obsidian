# Wolframscs/obsidian-auto-equation-numbering

Obsidian plugin that numbers display equations automatically and keeps cross-references to them in sync. It parses the block equations delimited by double dollar signs in a note, appends a LaTeX tag command to each, renumbers them when an equation is inserted or deleted, and leaves inline equations and code blocks untouched. The README also describes references that resolve to the current number, handling for the same equation repeated in several places, and the MathJax parsing problems that using label and tag directly in Obsidian causes. Its documentation is bilingual English and Chinese.
