# spreadwell/butter-editor

Butter Editor adds a WYSIWYG editing view to Obsidian that renders supported Markdown in place and sits alongside Source, Live Preview and Reading, leaving notes as ordinary Markdown files with no import step and no proprietary format. It formats headings, lists, tasks, links, tables, code, math and callouts visually, works with wikilinks, embeds, tags, footnotes, block ids, properties and Bases embeds, lets complete blocks be selected, dragged, reordered and transformed, and inserts blocks from a slash menu. The toolbar's position and its separate desktop and mobile button layouts are configurable, and the README states the plugin runs on desktop and mobile. The README also states that Butter Editor is paid software, with a 15-day trial requiring no account and a one-time v1 licence covering up to five active devices.
