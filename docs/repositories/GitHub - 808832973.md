# Lio5n/blue-star

Blue Star generates Anki flashcards from Obsidian notes through AnkiConnect, which the README lists as a requirement. Cards can be created from the current file or from a specified directory, using parsing modes based on headings, sections, custom delimiters or regular expressions. Directory and tag filters narrow which notes are used, and settings control whether existing cards are updated or only new ones added, along with default decks, models and tags. Individual notes can override those defaults with document-level settings.
