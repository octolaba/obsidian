# aleksejs1/obsidian-contact-sync-plugin

This repository holds Google Contacts Sync, described upstream as an Obsidian plugin for syncing Google Contacts with notes. The README says each contact becomes a note with metadata in YAML frontmatter and free text below it from a customizable template, in a configurable folder, with optional filename prefixes and naming strategies and an audit command that finds local notes no longer present in Google Contacts. Contacts can be filtered by Google label, frontmatter keys follow one of three naming strategies, a customizable default, a vCard-compatible layout, or arrays for multi-valued fields, and relations can optionally be written as links.
