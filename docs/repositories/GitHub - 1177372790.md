# zhaohongxuan/journal-partner

Journal Partner highlights the HH:MM timestamps at the start of lines inside a note's Journal section, rendering them as coloured badges in the editor and in reading view. The target heading name and level, the matching regular expression and the text and background colours are configurable, existing timestamps can be made read-only, and pressing Enter inside the section starts the next line with the current time. A quick-capture sidebar writes into today's daily note, accepting multi-line text, pasted or dragged images and microphone recordings saved as attachments, with optional speech-to-text, and shows entries as a bubble timeline scrolling back up to 365 days. A statistics tab counts writing days, entries and recordings, draws a per-year heatmap, and a registered URL protocol writes an entry without opening the main window.
