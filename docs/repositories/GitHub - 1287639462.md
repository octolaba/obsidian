# null-machine/simple-plotlines

Simple Plotlines organizes plotlines across acts by tagging scene notes with the plotlines they progress. Scene notes are recognised by a filename beginning with an act and scene identifier, the tags inside them are treated as plotlines, and a tag-order note anywhere in the vault restricts and orders which tags count. Beside the plotline view an act overview shows scenes as cards, where dragging a card reorders scenes by renaming the underlying files. The README records that everything the plugin needs lives in note titles and tags, so nothing is stored in a form that is awkward to maintain in vanilla Obsidian.
