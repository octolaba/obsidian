# jamesgreenblue/obsidian-quicknote

This plugin creates a new quick note in a floating Obsidian window, either on command or by right-clicking the Obsidian app icon; the README traces it to a feature request on the Obsidian forum. A setting for changing the quick note title is recorded as done, while Windows and Linux support remain to-do items, and the author states that he has no reliable access to a Windows or desktop Linux machine for testing. One known issue is recorded: creating a new note fails when Obsidian is running but minimised, so no window is available.
