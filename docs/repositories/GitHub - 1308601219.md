# AngusK97/obsidian-eisenhower-matrix-blocks

Obsidian plugin that inserts an Eisenhower matrix as an editable block at the cursor inside a Markdown note, with more than one matrix allowed per note. Each matrix owns its own tasks and completed history, and tasks can be added, edited, moved between quadrants, completed, restored, deleted and filtered without leaving the block. The README states that tasks, quadrants, ordering and completion times are stored in the note itself, so they travel with it through Obsidian Sync, Remotely Save or Git.
