# almeidazs/rich-link-obsidian

Turns a pasted or selected URL into a Markdown link that carries the page title and its favicon rendered at 16 by 16 pixels. Conversion happens automatically when the clipboard holds a single URL, or on demand through a command or context menu action against the selection or the URL under the cursor, with an inline loading placeholder shown while metadata is fetched. If no favicon URL can be resolved it falls back to a plain Markdown link; the favicon can sit before or after the title, resolved URLs can instead be rendered as preview cards, and specific domains and exact URLs can be excluded from automatic conversion on paste.
