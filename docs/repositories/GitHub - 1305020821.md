# chuanqq/user-prompt-optimizer

User Prompt Optimizer refines a selected prompt with an LLM inside Obsidian, streaming the rewritten text back into the selection character by character so it can be undone with the usual shortcut. Two modes are offered: a template mode that restructures the prompt against an active optimization standard, shipping one built-in template and accepting further Markdown files in the vault or HTTP links, and a lite mode that applies no structure and only disambiguates, dedupes and sharpens wording, marking missing information in place with a placeholder. It talks to OpenAI-compatible and Anthropic providers with one-click model listing, reasoning-effort and sampling controls and a request timeout. Progress is visible as a selection highlight, a banner with a stop button, a notice, a pulsing ribbon icon and status-bar feedback.
