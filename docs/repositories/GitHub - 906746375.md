# ProfSynapse/nexus

Nexus is an Obsidian plugin that exposes a vault to AI agents so notes can be read, written, searched, organized and automated in natural language while storage stays local to the vault. It works in two ways: a native chat inside Obsidian connected to a chosen provider, with voice, read-aloud and audio or video generation, and access from external agents over MCP, for which the settings generate a connector file, or over a local CLI command for shell agents. The README records that the CLI installation is user-triggered, writes only outside the vault and, on Windows, adds its directory to the current user's PATH without administrator rights, with uninstall removing only what it added. It also records Nexus as the successor to Claudesidian, with legacy installations still working.
