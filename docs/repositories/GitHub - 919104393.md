# dominikmayer/obsidian-note-id

Note ID is an Obsidian plugin that lists notes by the id property in alphanumeric order, so numbered sequences such as a manuscript outline or a Zettelkasten Folgezettel become the organizing structure and clusters of related ideas, gaps and dense areas become visible. New notes can be created from the context menu or a command either continuing a sequence, as 1.2 to 1.3, or branching a subsequence from a note, as 1.2 to 1.2a, and an existing note's ID can be set relative to another note. A separate table of contents view lists top-level notes and notes carrying a toc property, giving a curated index rather than the full list, and search matches fuzzily on note title, note ID or table of contents title.
