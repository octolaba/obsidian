# MrDanRave/auto-linker

An Obsidian plugin that underlines words in a note matching other note titles and offers to turn them into wikilinks, always as a suggestion and never linking on its own. Each candidate gets a confidence score rather than a binary title match, and only candidates above a threshold the reader sets are shown; the score blends lexical closeness including stemming and near-typos, word significance graded by IDF over the vault, capitalization, note importance computed as PageRank over the link graph, an optional on-device embedding model for meaning, and preferences learned from the links actually accepted. The README describes a fixed candidate pipeline in which only some steps can eliminate a note while the rest adjust its score, and states that the software was vibe-coded.
