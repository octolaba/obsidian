# rflpazini/obsidian-authorship

An Obsidian plugin that records whether text in a note was typed, pasted, or marked as AI-generated or reference material, and shows the difference in the editor with a gradient highlight for AI text, a subtle mark for pasted text and italics for reference material. Tracking uses CodeMirror 6 transaction events, and commands mark a selection as AI, self or reference and toggle the highlighting. Authorship is persisted at the end of the Markdown file in the open Markdown Annotations format that iA Writer's Authorship feature uses, with a SHA-256 value detecting edits made outside Obsidian. The README states the plugin is local with no network calls.
