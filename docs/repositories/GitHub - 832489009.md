# dragonish/obsidian-abbreviations

This plugin marks abbreviations and acronyms automatically in Obsidian notes. Abbreviations are defined either in a note's properties — as a list of strings that separate abbreviation from tooltip with a colon, or as key-value pairs — or with Markdown Extra syntax. Rendering works in reading view and Live Preview, and optionally in source mode, and the plugin can list every abbreviation in the current file and offers a context menu on a marked abbreviation.
