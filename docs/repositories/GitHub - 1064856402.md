# ebullient/obsidian-prompt-flow

Prompt Flow generates content in Obsidian from custom prompts using local LLMs through Ollama or any OpenAI-compatible API, with named connections so several providers can be configured and switched between. Generated text is inserted at the cursor, and system prompts, model selection and per-note overrides are configurable. Content filters can exclude chosen callout types or link patterns, wikilink targets can optionally be expanded into the prompt, and further filters can be registered through the plugin's filter API. The README states that the plugin communicates only with the configured LLM providers and works on desktop and mobile.
