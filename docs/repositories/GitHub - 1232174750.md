# sai1047976/obsidian-cjk-cross-search

Obsidian plugin that expands global search queries across Simplified and Traditional Chinese, so typing one script also finds files written in the other. The README states that Obsidian's native global search treats the two as different strings and that the plugin rewrites the query using Obsidian's own OR syntax before it reaches the search engine, also bridging regional term variants through OpenCC mappings. It states that rewriting pauses during input-method composition, that both typed and programmatic searches are covered, and that the quick switcher, tag pane and backlinks pane are not.
