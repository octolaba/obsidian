# coignard/obsidian-typographer

Typographer applies typographic corrections while you type, converting straight quotes into configurable opening and closing quotation marks, running user-defined text replacement rules, and auto-pairing characters such as guillemets so the closing counterpart is inserted with the cursor between them. The README states that the plugin works in the background and ignores code blocks, frontmatter and other regions where such changes are unwanted. All replacement and auto-pairing rules can be added, edited or removed from the settings tab.
