# MediosZ/obsidian-subdivider

Subdivider splits a note into smaller files, converting it into a folder in which each subheading becomes a separate file. Two operations are recorded: a right-click command on a file subdivides that whole file into a folder, and a right-click on a text selection moves the selection into a file of its own. The README states that the plugin expects a well-structured note, because only first-level headings are converted in a single pass, that certain characters in a generated filename are replaced with an underscore — the slash and backslash everywhere, the space and the period on Windows — and that the plugin is still at an early stage.
