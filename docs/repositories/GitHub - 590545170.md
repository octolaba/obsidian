# inouetakuya/obsidian-kill-and-yank

The recorded description says this Obsidian plugin enables kill and yank in the editor. Per the README the behaviour follows Emacs: kill line cuts from the cursor to the end of the line on Control and K, kill region cuts the selection on Control and W, yank pastes the kill ring on Control and Y, and set mark toggles the start position of the selection on Control and Space. The README notes that the commands work in the editor but not in the note title, so anyone who wants kill and yank in the title has to change the default key mappings.
