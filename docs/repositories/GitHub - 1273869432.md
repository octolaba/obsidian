# bryanbans/Notional

Notional synchronizes notes between Obsidian and Notion in both directions, pushing a note as a formatted page and pulling changes back. The README states that wiki links become Notion page mentions, that headings, checklists, tables and callouts survive the conversion, and that push and pull are conflict-safe rather than overwriting silently. It presents Notion as the place where teams and agents can read the material, and records that nothing leaves the device except the notes the user selects.
