# AndyMDH/obsidian-nous

Nous turns captured material, from typed notes and voice memos to calls, photos and PDFs, into summarized notes that are tagged from a controlled vocabulary and linked to related notes while the capture happens rather than on command. Once a topic has accumulated enough notes, it writes a hub page pulling them together. The README records meeting capture as macOS-only and live voice transcription as a desktop-only beta, with mobile supported through a direct API key, and states that the local command-line, transcription and model paths send nothing off the machine while direct API keys are opt-in.
