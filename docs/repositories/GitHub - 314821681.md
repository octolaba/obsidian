# abcjs-music/obsidian-plugin-abcjs

This repository holds an Obsidian plugin that renders ABC music notation from code blocks marked with the abc language specifier, using the abcjs library and supporting the features abcjs provides. Custom options are passed to the renderAbc function by placing a JSON string at the top of the code block followed by a separator line with no surrounding whitespace, and the README shows examples for a simple song, chorus music and adding swing to 4/4 tunes. When the JSON is invalid the block is still rendered but a red error banner is shown above it. The plugin is maintained by the abcjs-music organization of volunteers, including its original author.
