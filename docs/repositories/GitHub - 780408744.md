# sfr0xyz/obsidian-bitcoin-block-stamp

This plugin stamps Obsidian notes with the current Bitcoin block height, Moscow time, or both, and can also stamp historical dates back to the Genesis block. Commands insert a custom or current stamp and replace placeholders such as blockheight and moscowtime in notes as they are created. Settings cover the block explorer used for optional block-height links, the digit grouping of the height, the Moscow time format and the placeholder strings themselves. The README names the mempool.space REST API as the source of block and price data.
