# sandorex/nuke-orphans-plugin

Obsidian plugin that trashes orphaned files and attachments. It provides three commands run from the command palette, and the README states that the plugin always asks before trashing files. Installation is documented from the community plugins browser or by extracting a release archive into the vault's plugin folder, in which case it has to be enabled manually.
