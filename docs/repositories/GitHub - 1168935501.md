# sec-ml/obsidian-auto-file-extension

An Obsidian plugin that renames a file's extension according to a rule set, where a rule matches on directory path, on file content by regular expression, or on both, and the first matching rule wins. Content rules read the file from disk, and an option makes the current extension come from the file path rather than from Obsidian's reported extension, which another plugin may have spoofed. Running on save is off by default to avoid races with other file-processing plugins, so a command fixes the extension of the current file instead. The README warns that Obsidian largely ignores non-Markdown files and that a rename fails when the target filename already exists.
