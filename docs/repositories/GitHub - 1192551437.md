# iaremarkus/wol-reference-viewer

Looks up Bible verses and references from wol.jw.org and adds them to notes inline, in a modal or popover, or in a sidebar panel. A reference wrapped in double exclamation marks becomes a clickable link, a greater-than sign after it renders the verse inline, and the sidebar lists and loads every reference in the active note. The README explains that the wrapped value is sent to a Cloudflare worker, which searches wol.jw.org, parses the returned HTML with cheerio and answers with the reference and verse text, left unchanged apart from light formatting. References collected in a `scriptures` frontmatter property can then be surfaced through a dataviewjs query.
