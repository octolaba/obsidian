# kometenstaub/copy-publish-url

This plugin copies or opens the Obsidian Publish URL of the current note, optionally through a file-menu entry as well as a command, and can open the note's Git commit history on GitHub. Settings must name the Publish index note and the base path of the Publish site, plus a repository URL and branch name for the commit-history feature, which is turned off by default. A note whose publish flag is set to false is skipped, so neither the URL nor the file-menu entry appears.
