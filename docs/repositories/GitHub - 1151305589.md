# yhfs21/diary-linker

Diary Linker adds a diary calendar view for daily notes with month navigation and a Today button, where clicking a day opens or creates the note for that date. It maintains a year, month and day folder hierarchy and keeps the parent links present from the root note down to the day note. New notes come from a template in the Templates folder, which must contain the diary-link placeholder and may also use title, date and time placeholders. The README states the plugin makes no network requests, collects no telemetry or analytics, and only reads and writes inside the vault.
