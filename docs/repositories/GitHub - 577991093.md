# lhansford/obsidian-checklist-reset

Obsidian plugin that adds a command to reset the state of checklists in a document, working on Markdown and Canvas files. Its commands uncheck all checked items, check all unchecked items, and uncheck only the selected items, the last available in editor mode. A setting takes a string or a regular expression whose matches are removed from a checklist item line when it is reset, which the README suggests for stripping metadata such as that generated by the Tasks plugin.
