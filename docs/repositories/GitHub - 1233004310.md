# nnniv/palenight.obsidian

This repository is the Obsidian port of the author's Monokai Palenight theme, recorded in the repository description as a port of their universal theme. Installation is documented through the Appearance settings and the theme browser, or by copying the Palenight folder into the vault's themes directory. The README states that the theme is actively work in progress and that selectors for some CodeMirror6 classes are not yet covered.
