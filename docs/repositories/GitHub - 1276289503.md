# cmdaeo/obsidian-plugin

Yet Another All-In-One is an Obsidian plugin that collects several modules in one place; the only module this README documents is Git Sync. Git Sync performs local-first, cross-platform Git synchronization with isomorphic-git, a pure JavaScript engine, and issues requests through Obsidian's requestUrl rather than raw fetch so that it also works on Android. It offers debounced commit and push on file changes, a pull at startup, and an audit log written into the vault, with the remote configured by URL plus GitHub OAuth or a personal access token.
