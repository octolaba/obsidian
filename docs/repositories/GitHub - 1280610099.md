# tahayigitmelek/mermaid-explorer

Mermaid Explorer is an Obsidian community plugin that indexes the Mermaid code blocks across a vault and gives them a dedicated view with search, sorting and filtering by folder, note, diagram type or tag. Diagrams can be previewed with zoom, fit and fullscreen, edited in a built-in editor with syntax highlighting and error diagnostics that writes changes back into the original Markdown block, and exported as SVG or PNG. A dashboard reports totals for diagrams, folders, types and recently modified items. The README states that the plugin works locally and offline and transmits no note content to external services.
