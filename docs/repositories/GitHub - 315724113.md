# nhaouari/obsidian-youglish-plugin

Obsidian plugin that embeds the YouGlish widget, so a selected word or phrase can be looked up in YouTube recordings and heard as real people pronounce it in context. Selecting the phrase and clicking the plugin icon opens that lookup. The README records a minimum Obsidian version and notes that the bundled widget script was modified to export its main variable and to declare two variables that had been left undeclared.
