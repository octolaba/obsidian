# SmolBlackHole/mermaid-elk-renderer

Mermaid ELK Renderer re-enables the Eclipse Layout Kernel layout engine for Mermaid diagrams in Obsidian, applied to one diagram by placing an `%% elk %%` marker inside its block or to every diagram through a setting. It can optionally load Mermaid 11.16.0 bundled with the plugin instead of Obsidian's older built-in version, which the README records as the switch for newer diagram types such as xychart-beta, cynefin-beta and railroad-beta. Further settings override an existing layout config, escape numbered labels that would otherwise trigger Markdown list rendering, set a default look and theme, and enable debug logging that the README states does not leave the device.
