# Altarok/chemtrails

This repository holds Chemtrails, an Obsidian plugin that renders SMILES chemical notation as SVG diagrams inside notes, using the smilesDrawer library from the reymond-group, which the README credits for the drawing itself. Rendering happens locally with no external image server or API, and a playground draws the molecule as the input is typed. A dynamic viewBox keeps small molecules small while scaling large structures down to the width of the active pane, the diagrams follow Obsidian's light and dark themes with further bundled themes, and the ribbon icon and the command can each be switched off in the settings.
