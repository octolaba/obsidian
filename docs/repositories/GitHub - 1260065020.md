# sunxiaoqiqi/svg-editor

SVG Canvas Editor opens an .svg file from the Obsidian file menu into a workspace of four panes: the raw source with live preview, a layer tree, a canvas and an attribute inspector. Elements are selected on the canvas or in the tree, dragged, resized, selected together, duplicated, deleted, reordered or sent to front or back; text, rectangles and circles can be inserted, text edited inline on a double-click, and fill, stroke, opacity, size, position and text edited in the inspector, with undo, redo and save shortcuts. The README states that a one-time .svg.bak backup is written beside the file before the first save, that the plugin reads and writes only the SVG files the user selects inside the vault, that it makes no network requests, and that the interface switches between Chinese and English.
