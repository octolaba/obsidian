# johansatge/obsidian-automatic-table-of-contents

Obsidian plugin that creates a table of contents in a note and updates it when the note changes. The table is produced by a code block placed in the note rather than by maintaining the list by hand, and the README documents the available options together with a section on limitations and known bugs. It can be installed from the community plugins list, cloned into the vault's plugins directory, or built from source.
