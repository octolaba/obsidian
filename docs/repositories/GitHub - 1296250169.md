# sharfaroz7/themed-journal-capture

Themed Journal Capture opens a quick-capture window from a hotkey anywhere in Obsidian and files what is written into a chosen note as a dated bullet. The README records three routes out of that window, a fuzzy search over every Markdown file in the vault, a direct send to a configured inbox note, and a browsable list of configured categories navigated with the arrow keys, with the back and select steps also exposed as tap buttons because many mobile on-screen keyboards lack a left arrow key. Multi-line entries are supported, and continuation lines are indented so they stay part of the same bullet.
