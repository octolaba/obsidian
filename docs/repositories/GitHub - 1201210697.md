# cjgtsc/obsidian-ai-idea-capture-plugin

Obsidian plugin that connects a Telegram or Discord bot to the vault and turns incoming messages into structured notes. Text, photos, voice messages and URLs sent to the bot are handled by the language, vision, speech-to-text and web-search models configured in settings, and a session is summarised into a Markdown file after a customisable idle period, five minutes by default. Recent context is remembered across sessions, and the interface and prompts follow the Obsidian language setting across twelve languages. The README states there is no central backend: data goes to whichever AI providers the user configures, while API keys and chat history stay inside the vault encrypted with AES-256.
