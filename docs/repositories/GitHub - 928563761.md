# travisvn/obsidian-vision-recall

Vision Recall turns screenshots into searchable Obsidian notes. Screenshots reach it several ways: a monitored intake folder processed periodically or as soon as a file is created, Obsidian deep links, the clipboard, and a file upload modal for files already in the vault. Each screenshot is then analysed — text is extracted with Tesseract OCR and a vision language model such as OpenAI's GPT-4o or an Ollama model interprets the image.
