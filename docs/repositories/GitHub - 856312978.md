# bruce-pain/crackboard-obsidian

This plugin reports Obsidian activity to crackboard.dev, which its README describes as a leaderboard productivity tracker. Setup consists of installing the plugin from the community plugins section and entering a session key in its settings tab; the recorded README says nothing about what is transmitted or how often.
