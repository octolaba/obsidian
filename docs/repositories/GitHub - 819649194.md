# jordanhandy/obsidian-imgbb-uploader

Uploads images pasted or dragged into Obsidian to an ImgBB account instead of storing them locally, replacing the embed with the hosted link. It requires an ImgBB API key taken from the API section of the account; the README states the key is encrypted when saved, so the settings field can look blank on a later visit while the stored value remains in place. Settings cover uploading on copy and paste, uploading on drag and drop, and automatic deletion after a period of at least 60 seconds. The README notes that ImgBB stores images only and points to the author's Cloudinary uploader for other media types.
