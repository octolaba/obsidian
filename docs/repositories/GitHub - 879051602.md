# ElmoNeedsArson/Obsidian-3D-embed

Embed 3D shows 3D models held in an Obsidian vault inside notes, rendering them with the three.js library. The README stresses that models stay local — there is no need to upload a model elsewhere and embed the result — and lists stl, glb, obj with mtl, fbx and 3mf as the supported file types. Scene appearance is adjustable through variables such as background colors, autorotation, lighting and scales, documented further down the README.
