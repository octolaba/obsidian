# PMGWork/obsidian-cite

Obsidian plugin that renders LaTeX- and Pandoc-style citations and links them to reference notes containing BibTeX. The README states that citation commands become numbered internal links in Live Preview and Reading view, that citation keys complete by key or title while typing, that a bibliography is generated at a bibliography marker, and that several BibTeX entries can be resolved from a single reference note. Reindexing happens automatically when reference notes change, a reference folder must be set because the whole vault is not scanned, and the stated minimum Obsidian version is 1.12.7, with desktop, iOS and Android supported.
