# jv209/callout-control-panel

This repository holds Callout Control Panel, an Obsidian plugin that unifies callout insertion, detection and management behind one modal. The modal opens by hotkey, command or ribbon icon and lists every available callout type, whether built-in, theme-defined, snippet-defined or user-created, letting a title, collapse state and content be set before the Markdown is inserted at the cursor. It scans CSS snippet files and the active theme for custom definitions, recognises the fourteen built-in Obsidian types and their aliases, and picks up snippet and theme changes as they happen. Custom types are defined with a name, colour and an icon taken from Obsidian's own set, from other bundled icon libraries, or from an uploaded image, and definitions can be imported or exported as JSON or written out as a CSS snippet.
