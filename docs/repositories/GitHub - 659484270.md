# ms3056/Tenki

Tenki displays weather inside Obsidian, and its README notes that the name is the Japanese word for weather. It records that a free WeatherAPI key and a city are entered in the settings, that the display can be opened from a command, and that the feed is refreshed no more often than a 30-minute minimum interval the plugin enforces by default. Every display element carries a CSS class, so the appearance can be changed through the user's own snippets. Citing the Obsidian developer policy on disclosures, the README states that the plugin retrieves weather data from the WeatherAPI endpoint combined with the user's personal key.
