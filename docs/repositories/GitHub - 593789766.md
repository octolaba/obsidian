# lenalebt/obsidian-pocketbook-cloud-highlight-importer

This plugin imports highlights and notes made on a Pocketbook e-ink reader or in the Pocketbook app into an Obsidian vault through a Pocketbook Cloud account. The README states that it reads all highlights from the account, writes them into small Markdown files with YAML frontmatter, and creates Dataview queries that gather the comments together; the Dataview plugin is required and its presence is not checked, and only password login works. Setup takes a user name and a login that asks for a password which is not saved, though a refresh token is, plus an optional shop name for accounts with several shops and the folder highlights are written to; the README records the AGPL-3.0 licence as inherited from the epub-cfi-resolver library.
