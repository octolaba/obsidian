# jfsicilia/obsidian-file-manager

Adds file management commands to the file explorer so that files and folders can be handled from the keyboard by binding hotkeys. The commands cover opening files or folders with custom commands or URL schemes, creating a sibling folder, a subfolder or an empty note, duplicating, moving, copying, cut and paste with an explicit clipboard clear, toggling and inverting the selection, selecting and deselecting everything, renaming, moving a note and going to a folder. A pathexplorer code block is documented as a separate feature, able to show absolute paths and to expand environment variables in the paths it is given.
