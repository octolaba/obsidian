# Raboro/Obsidian-Birthday-Tracker-Plugin

This Obsidian plugin tracks the birthdays of family and friends from a single Markdown file whose location is set in the plugin settings. Each person is one line pairing a name with a birthday, and triggering the plugin from its ribbon icon or command shows a notice for anyone whose birthday is today plus a separate view listing everyone sorted by their next birthday. A Year View gives an overview of all birthdays and links each name to more information about that person. The date format used to collect and display the dates is configurable and defaults to DD/MM/YYYY.
