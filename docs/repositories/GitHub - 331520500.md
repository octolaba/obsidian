# liamcain/obsidian-things-logbook

Things Logbook periodically syncs the Logbook of the Things task manager into Obsidian daily notes, placing each completed task in the daily note for its completion date. The README records that subtasks, tags and areas attached to a task are shown as well, that tasks are refetched at a configurable interval, and that a setting controls the heading under which they appear. It warns that the initial sync backfills the entire Logbook and may create or modify hundreds of files, and advises testing in a new vault first and keeping a backup.
