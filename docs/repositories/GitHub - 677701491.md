# lucifayr/archwiki-obsidian

Obsidian plugin that downloads ArchWiki pages and opens them as Markdown files in a new tab. A command asks for the name of the page, and after installation a list of all ArchWiki pages grouped into categories is fetched so that names can be suggested while searching. The README states the plugin depends on the external command-line tool archwiki-rs, which has to be installed separately.
