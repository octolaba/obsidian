# sstallion/obsidian-command-line

Command Line copies command lines out of Obsidian notes to the clipboard without selecting text. Prompts and command output are stripped from what is copied so the result can be pasted straight into a terminal session, and a default prompt is supplied for command lines that do not carry one. Command line code blocks are identified by their language — `command-line`, `batch-command`, `powershell-command` or `shell-command` — each with its own prompt pattern, default prompt and line continuation character. Optional syntax highlighting through Prism Command Line and optional removal of unnecessary white space are offered, and the README states that both mobile and desktop are supported.
