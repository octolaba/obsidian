# MM-GO/UseSemaLogic

This plugin makes SemaLogic usable inside Obsidian. The README describes SemaLogic as a symbolic AI that can be adapted to natural language in order to represent logical relationships unambiguously, with three interconvertible forms, namely natural language, technical language and a practical representation. At the recorded version the plugin renders the technical language and graphical pictures in real time and can place part of the generated SVGs directly in PDF output. The README states that the plugin is in development status, that its SemaLogic API is in early alpha and subject to change, and that updates are read straight from GitHub releases because only an initial listing goes through review.
