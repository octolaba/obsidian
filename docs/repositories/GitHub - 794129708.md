# andrewheekin/obsidian-folder-periodic-notes

Creates and opens periodic notes inside a folder hierarchy of year, month and day, where a yearly folder holds monthly folders and a monthly folder holds its daily and weekly notes, each level also carrying its own note. Commands open the daily note, creating the monthly and yearly notes when they are missing, and open a weekly, monthly or yearly note for a period entered by the user. A setting names the folder in which the periodic notes are created. No repository description is recorded, so this note is grounded in the README alone.
