# Mats324/cards4links

This repository holds Cards4Links, an Obsidian plugin that converts a pasted URL into a card-styled link showing title, description, thumbnail, favicon and host. The conversion runs from a command, from the editor context menu, from a selection command with a keyboard shortcut, or automatically once the default paste is enhanced in the settings. Metadata is fetched from the page's Open Graph data, three layouts are offered as card, compact and minimal, and several addresses can be combined into a scrollable carousel. The README also lists watched and read markers for video and article cards, a forced light or dark card theme, and optional caching of images into the vault with a configurable lifetime.
