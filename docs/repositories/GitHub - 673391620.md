# FBarrca/obsidian-handwritten-notes

This plugin integrates stylus-based handwritten notes into an Obsidian vault and stores them as PDFs for long-term compatibility; the README contrasts it with the Excalidraw plugin for long handwritten notes. Notes are created from paper templates, annotated from within the vault, and embedded or referenced in Markdown files. A compatible external PDF editor is mandatory, and the README warns that mobile support is limited because not every mobile app can edit a file directly, and that unsupported editors are the main cause of reported issues. It also records that templates may not sync correctly through Obsidian Sync.
