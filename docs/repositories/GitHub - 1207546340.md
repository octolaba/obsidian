# Narwhai/pinned-tab-utils

This plugin changes how pinned tabs are ordered in Obsidian so that they behave more like tabs in some web browsers. According to its README pinned tabs move automatically to the left end of the tab bar, each further pinned tab takes the next slot to their right, and unpinning a tab moves it to the right of the remaining pinned ones. Installation is documented only through BRAT, by adding this repository as a beta plugin.
