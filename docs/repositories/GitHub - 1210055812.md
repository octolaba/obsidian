# peacewalkerT/obsidian-rodin-export

Sends the Markdown files of a vault to the external Rodin service, which returns what its authors call an intellectual fingerprint: recurring themes, open questions, mental models, influences, blind spots and a single core question. The export runs from a ribbon icon or a command, after which Rodin opens in the browser with the result. An existing profile can be evolved instead of replaced by pasting a connection code from the profile's manage page into the plugin settings, so later exports merge into that fingerprint.
