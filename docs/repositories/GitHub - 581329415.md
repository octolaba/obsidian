# AllJavi/spoiler-block-obsidian

Spoiler Block hides information in a note until the reader chooses to reveal it. With the mouse over a spoiler block a click shows the content and a double click hides it again. The README records this version as basic functionality only: the block renders plain text rather than Markdown, and a command to reveal every spoiler on the current page is named as a possible future addition.
