# tetsuya-dev-jp/igdb-game-search

IGDB Game Search creates game notes in Obsidian from IGDB metadata. A ribbon icon or the "Create new game note" command opens a search by game title, and picking a result builds a note from the selected game's metadata retrieved through the IGDB API. Access requires a Twitch Client ID and Client Secret entered in the plugin settings, and the README walks through registering a Twitch application to obtain them. It states that the plugin is currently installed manually rather than from the community browser, and it is published in English, Japanese and Korean.
