# pyrochlore/obsidian-tracker

Obsidian plugin that collects data recorded across notes — occurrences and numbers — and renders it in a comprehensible form. Values are gathered by search types covering frontmatter keys, including list-valued keys and mere existence of a field, inline Dataview fields with emoji values, and checkboxes in the properties introduced in Obsidian 1.4, over a date range. The changelog names bar charts with full bars at either end, stacked bar charts, pie charts with non-overlapping external labels, and calendars with threshold and streak-based colour intensity. Further parameters cover the first day of the week, graph aspect ratio, expression functions and how streak counting terminates.
