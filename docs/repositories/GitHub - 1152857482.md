# babarot/obsidian-image-uploader-to-api

Image Uploader to API uploads images to an arbitrary HTTP API endpoint when they are dragged into or pasted in the Obsidian editor, then inserts the returned public URL as Markdown. The endpoint, the multipart field name, arbitrary request headers such as API keys, and a dot-notation path for extracting the URL out of the JSON response are all configurable, so the README presents it as working with a custom server or a hosted service. Several images upload in parallel and a placeholder marks each one while its upload is in flight. JPEG, PNG, GIF, WebP, SVG, AVIF and ICO are supported; PDF handling is opt-in and can save locally, always upload, or ask each time, and unsupported types fall back to Obsidian's default behaviour.
