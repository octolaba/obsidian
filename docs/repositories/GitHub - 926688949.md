# brokensandals/obsidian-paste-quote-plugin

Paste Quote helps with formatting and citing quotations pasted from the clipboard. Pasting at the beginning of a line produces a block quote, while pasting in the middle of a line wraps the text in quotation marks and turns any internal double quotes into single ones. Text copied from the Kindle app carries a trailing citation, which the command rewrites: a simple title and page-number format when the note has no references section in its front matter, and a Pandoc-style citation drawn from that section when it does. Further commands paste references from tools such as Zotero into the note's references front matter and insert a Pandoc-style citation for an entry there.
