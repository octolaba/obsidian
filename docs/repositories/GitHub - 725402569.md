# jonzfisher/obsidian-chronostory

The Storyclock plugin draws a note's list of timestamps as a clock-shaped view of a story's structure, based on the Storyclock notebook by Plot Devices and the process explained by its creator, Seth Worley. The input is the story's full runtime on the first line followed by one timestamp per event, all in an hours, minutes and seconds format, typed while watching or listening to the story. The clock appears once focus moves away from the text, as with many Obsidian plugins, and an icon in its top right switches back to editing the source; the README presents the result as a way to spot gaps or symmetries in a time-dependent story.
