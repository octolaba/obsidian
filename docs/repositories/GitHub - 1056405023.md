# IllDepence/obsidian-frontmatter-to-html-attributes

Exposes a note's YAML frontmatter in HTML as data attributes on the note's workspace container, so CSS snippets can style notes by their metadata. Every frontmatter item becomes an equivalent data attribute matched with CSS attribute selectors; lists and objects are serialized as JSON and everything else as a plain string, so tags need a quoted substring match rather than an equality test. The README shows snippets that append an icon after the title of notes tagged travel and underline headings in notes whose boolean property is set.
