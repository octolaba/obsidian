# Abdur-Nur-Porag/CEvent-Planner

This repository holds CEvent Planner, an Obsidian plugin that turns event and task entries written in Markdown notes into a dashboard. The plugin scans the vault, collects the events it finds, and presents them in calendar, list and timeline views with live subtask tracking and alarms that raise system reminders. The README documents event attributes, event statuses and recurring events, and states that the companion plugin CEvent Planner Extra must also be installed in order to create an event visually.
