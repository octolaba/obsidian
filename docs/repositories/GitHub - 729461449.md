# BBazard/obsidian-orgmode-cm6

This plugin brings Orgmode editing to Obsidian, with live preview, syntax highlighting whose CSS classes can be overridden, customizable todo keywords and folding from the gutter. Wiki links open an org file of that name and fall back to a markdown file, image links display the image if it exists in the vault, and ID links are supported. The README notes that org files appear only once Detect all file extensions is enabled, and that a new org file has to be created outside Obsidian.
