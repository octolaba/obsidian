# BCS1037/notion-block

Notion Block adds block handles in the gutter of Live Preview that follow the pointer vertically and align with the line it points at, so a line can be acted on without moving the cursor first. Clicking a handle opens a conversion menu for headings, bullet, numbered and todo lists, code, math, divider and quote blocks and twelve callout types, while a plus button inserts a line below and opens a searchable insert menu for elements such as tables, footnotes and frontmatter. Long-pressing a handle drags blocks to reorder them, with a context menu switching between a single physical line and a logical paragraph. The README states that the plugin avoids inner HTML assignment in its DOM manipulation.
