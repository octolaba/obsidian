# sissilab/obsidian-hexo-toolkit

Hexo Toolkit converts Obsidian notes to Hexo-compatible Markdown so that Hexo posts can be maintained in the vault. The conversion extracts Hexo front-matter according to the plugin settings, rewrites internal title links depending on the Hexo renderer in use, converts image and file link syntax, and turns embedded Excalidraw images into svg; a converted file link resolves through a hexo-path property set on the note. Images are handled by a configured image hosting service: with Local the matched images are copied to Hexo by hand from the conversion result window, and with SM.MS local images are uploaded automatically. The conversion runs from the Hexo Toolkit: Convert command, which reports its progress and its result in the status bar.
