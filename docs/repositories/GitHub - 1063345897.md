# thewheelbarrow/quick-matrix

Quick Matrix is a plugin for Obsidian that adds a command for interacting with matrices written in LaTeX, aimed at faster editing of them. Its README records that the plugin was initially based on obsidian-sample-plugin and uses files and code from it.
