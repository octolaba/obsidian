# jamesmagoo/nostr-writer

Nostr Writer is an Obsidian plugin that publishes notes from a vault to Nostr. A Nostr private key is entered once at setup, after which a note is published in a couple of clicks; images in the Markdown file are uploaded and handled on publish, tags can be added for discoverability, a published view lists everything sent from Obsidian with links, a short-form note writer composes and publishes directly, and relays are configurable. The README states that the plugin is one-directional by design: it does not read Nostr messages or show the public space, only publishing what has been written.
