# casals/obsidian-linear-integration-plugin

Linear Integration is described as syncing Linear issues with Obsidian notes, so issues can be created, updated and tracked from the vault. Its README claims bidirectional synchronization, conversion of a Markdown note into an issue using inline tags for assignee, status, label and priority, autocomplete over users, statuses, labels, projects and teams, colour-coded labels, quick editing, hover previews, conflict detection and resolution, automatic label creation, and API retries with exponential backoff. Further features listed are generated kanban boards and agenda notes, comment mirroring, batch operations across notes, custom status-to-emoji mapping, support for several workspaces, encrypted token storage, per-folder configuration files, conflict analytics and custom GraphQL filters. The README is written in a promotional register and none of these claims was verified here.
