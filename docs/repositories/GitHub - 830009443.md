# DarioCasciato/obsidian-auto-folder-collapse

Obsidian plugin for the file explorer offering two independent features, each with its own toggle and both off by default. Auto-collapse children collapses every sub-folder inside a folder when that folder is collapsed, which the README calls the original behaviour. Exclusive accordion collapses all folders that are neither ancestors nor descendants of a folder when that folder is expanded, keeping the sidebar on the area being worked in. The README states either feature can be enabled or disabled at any time and the change takes effect immediately.
