# Minus1min/obsidian-energy-tracker

30-Day Energy Log records energy levels and activities across six daily time slots for thirty days from a chosen start date. The README states that each cell is set to one of four levels — low, steady, active or peak — and that activities logged inside it are marked energizing, neutral or draining. An export button produces a text file containing the data together with a built-in prompt for pasting into an AI assistant, and a reset clears everything for a new run; slot boundaries and the interface language are configurable. All data is stored in the plugin's data.json inside the vault, and the README states that nothing is sent anywhere.
