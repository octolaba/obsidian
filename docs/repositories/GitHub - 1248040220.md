# wesswart77/obsidian-zettelkasten

This repository holds Zettelkasten Core, an Obsidian plugin implementing a fleeting, literature and permanent note workflow. A quick-capture command writes fleeting notes tagged for the inbox, a sidebar inbox view lists the unprocessed ones, and one action promotes a fleeting note into a permanent note carrying a timestamp-based Zettel ID or into a structured literature summary with author, year and quotes. Folder paths per note type, the Zettel ID format string, the inbox tag and whether new notes open automatically are all settings.
