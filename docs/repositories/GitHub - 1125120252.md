# likemuuxi/obsidian-sspai-toc

Repository for a plugin that adds a floating table of contents styled after the Sspai publication. The README describes a right-side outline in which only the active heading is fully shown while the others fade to short lines, synchronisation in both editing and reading modes, and updates as the note is typed or scrolled. Its documentation is written in English and Chinese.
