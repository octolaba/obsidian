# joshmedeski/obsidian-dynamic-wallpapers

Dynamic Wallpaper sets a background image per note from a wallpaper frontmatter property pointing at an image in the vault, and lets notes without one inherit a wallpaper from linked notes through a chosen property, all frontmatter links, body links or backlinks. The README describes a gallery picker with cached thumbnails, a random pick from the backlink pool or the whole related set, a modal listing every wallpaper that could apply grouped by inheritance tier, a per-theme overlay opacity for text readability, horizontal flipping, saving the displayed wallpaper into the note's frontmatter, and an option to keep the current wallpaper on notes that have none. It states that the plugin is desktop-only because it uses Node.js filesystem APIs.
