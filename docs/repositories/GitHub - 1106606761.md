# DuckTapeKiller/Brutalist

This repository holds Brutalist, an Obsidian theme for heavy readers and writers whose stark, geometric look drops rounded corners in favour of a strictly angular architecture and low-contrast shades of grey. It is compatible with the Style Settings plugin, through which fonts and font colours, internal and external link colours, alignment, note width, line height, inline title size, an auto-hiding side ribbon and mobile settings are configured. Per-note overrides set custom widths and hide interface elements, and the theme also documents a dashboard and masonry layout built on callouts, dashboard banners, CSS-only timelines, image captions and a gallery.
