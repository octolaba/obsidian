# JimCSuen/Enhanced-Canvas-Theme-for-Obsidian

JimCSuen/Enhanced-Canvas-Theme-for-Obsidian transplants the Enhanced Canvas theme from Visual Studio Code to Obsidian, combining that theme's colour template with the interaction interface of the Obsidian Nord theme. The README traces the source back through the enhanced HubSpot theme for Visual Studio Code to its earlier authors, explains that the author wanted its colour style for its vitality and clearness, and records that the transplantation was done with the help of a coding assistant.
