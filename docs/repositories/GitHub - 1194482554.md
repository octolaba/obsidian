# felixleopold/obsidian-code-suite

Obsidian plugin for executing code inside notes, described in its README as a notebook that lives in plain Markdown with no kernel, no notebook file format and no server. It lists Shiki syntax highlighting with over 65 themes and imported editor themes across Reading view, Live Preview and Source mode; execution of Python, JavaScript, TypeScript, Bash, Go, Ruby, PHP and further languages with streaming output, interactive input and cancellation; inline Matplotlib images and interactive Plotly widgets; variables shared across blocks and referenced inline in prose; embedded vault code files as runnable blocks; and notebook import and export.
