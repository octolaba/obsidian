# Real-Fruit-Snacks/Tidemark

Tidemark substitutes variables into the body of an Obsidian note from values defined once in the note's YAML frontmatter, using a double-brace token syntax. Tokens are colored live in the editor by state, one color when the value resolves, another when it falls back to an inline default, and another when the key is missing, so the state of a template is visible while typing. The resolver handles nested dot-notation keys, indexed items and arrays joined by a configurable separator, and defaults can be written inside the token itself. A command copies or replaces a line, the selection or the whole document with the variables expanded, and the README states that frontmatter is only read for substitution and written through Obsidian's own APIs.
