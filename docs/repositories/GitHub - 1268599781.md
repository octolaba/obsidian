# idheitmann/obsidian-yaml-editor

Adds a YAML editing mode that works in three places: a note's frontmatter block, fenced yaml or yml code blocks, and standalone `.yaml` and `.yml` files, which it opens in their own editor. Completions are built by scanning the vault's frontmatter, code blocks and standalone files, so suggestions for a key are path-aware, ranked by how often it occurs there and annotated with the value types and example values observed elsewhere, with keys already present at that level filtered out. Structural indentation, folding and a snippet palette come with it. The README states the guiding principle as round-trip preservation: the plugin does not reorder keys, strip comments or reformat whitespace on its own.
