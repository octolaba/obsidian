# bingryan/obsidian-ibook-plugin

Exports highlights and annotations from Apple Books on macOS into the vault, reading them from the local SQLite database in which the application stores them. Commands export everything, export a single book found by searching name or author, and insert book information looked up on Goodreads at the cursor position. Note output is driven by user-defined Handlebars templates with the documented parameters, bundled helper libraries and grouping support. The README notes that Obsidian has to be allowed access to the machine's data for the export to work.
