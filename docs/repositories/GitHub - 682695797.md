# plasmabit/timethings

Time Things writes the current timestamp into a chosen frontmatter property whenever a note is modified, and separately records how many seconds have been spent editing that note in the frontmatter as well. The active note's total is also shown in the status bar through a customizable template built from duration tokens for days, hours, minutes and seconds. The timestamp format, the timezone, searchable by region or city or set to UTC, and folder or file exclusions are all configurable, and the plugin additionally displays a clock in the status bar for readers whose window hides the system clock.
