# semanticdata/obsidian-pomodoro

PomoBar is a minimalist Pomodoro timer that sits in the Obsidian status bar, with optional audio notifications when a timer completes. The README states that the timer is driven by mouse clicks on the status bar item, with a left click starting or pausing it, that work and break intervals are configurable, and that optional auto-progression starts the next timer in the cycle or pauses after each session for manual control. Completion sounds are chosen from built-in sounds or from custom audio files in the vault, and the status bar item is also available with icons that change while a timer runs.
