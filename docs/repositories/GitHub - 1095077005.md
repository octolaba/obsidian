# qwai-tech/obsidian-plugin-intelligence-assistant

Intelligence Assistant is a desktop-only Obsidian plugin, requiring Obsidian 1.7.2 or newer, that runs an AI agent over the vault's notes, links and canvas. Its README describes a Sense-Plan-Act-Reflect loop: the agent perceives the active note, graph neighbours, directory structure, retrieval snippets and stored memories, plans a multi-step checklist, executes vault, canvas, MCP, web and CLI tools, and presents every vault change as a batch write proposal for approval. It ships preconfigured personas, read and write access to canvas files, a local vector store for long-term memory, and tools for YAML properties and batch file operations. The README lists OpenAI, Anthropic, Gemini, DeepSeek, Ollama, OpenRouter and SAP AI Core as providers and states that notes stay local.
