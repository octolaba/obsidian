# ovitrif/obsidian-url-preview

URL Preview is an Obsidian plugin that shows a preview of external links on hover in Editor, Live Preview and Reader modes, including secondary windows. The README describes holding a configurable modifier key while hovering, a loading spinner during the hover delay, dismissal with ESC, and cancellation when the modifier is released or the mouse leaves the link. Preview size, hover delay, mouse stillness tolerance and resizing behaviour are configurable, with controls placed in a toolbar above the content so they do not cover the page. It notes that sites blocking iframe embedding cannot be previewed.
