# deeplook/obsidian-asciinema-player

An Obsidian plugin that embeds terminal recordings made with Asciinema — asciicasts — inside Markdown notes and renders them with the interactive Asciinema Player interface. The README documents installation from the Obsidian community plugin browser as well as a manual route that unzips a release archive into the vault's plugins folder.
