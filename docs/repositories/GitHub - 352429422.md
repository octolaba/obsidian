# community-archive/obsidian-style-settings

Obsidian plugin that gathers configuration options declared inside CSS files into a single settings pane. Snippets, themes and plugins declare them in comments carrying YAML with a name, an id and a list of settings, and the plugin scans every CSS file Obsidian loads from the snippets, themes and plugins directories of the vault's configuration folder. Seven setting types exist: a heading that groups settings into collapsible nested sections, class toggles and class selects that add or remove classes on the body element, and text, number, slider, select and colour types that set CSS variables. Every definition carries an id, a title, a type and an optional description.
