# Ekrizdis367/obsidian-caissa

This repository holds Caissa, a chess study plugin for Obsidian named after the muse of chess. It embeds positions in notes and bundles a library of openings and variations, canonical endgame techniques such as Lucena, Philidor, Vancura and opposition, and sixty-eight World Championship games from 1886 through 2024. Any position can be played offline against Stockfish at strength levels zero to twenty, a PGN can be pasted from elsewhere or pulled from a Lichess URL without a token, and several boards can sit in one note for comparison. An opt-in Opening Explorer panel powered by Lichess shows win, draw and loss percentages for candidate moves, and the README states that the plugin does not read or write the system clipboard.
