# wenlzhang/obsidian-send-to-canvas

Send to Canvas sends tasks, blocks and notes from a Markdown note into a Canvas file, as plain text, as a block link, as a block embed, as a note link or as a note embed, with one command per format. When no text is selected the current line is used. Settings cover appending custom text to open tasks while preserving their formatting, choosing between date-based and random block identifiers with a format written in MomentJS tokens, appending customisable timestamps to links and embeds, setting node sizes per node type, remembering the last selected canvas file, and a startup delay for large vaults, with a status bar item selecting and showing the target canvas.
