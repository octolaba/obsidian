# johannes-kaindl/neurovim-obsidian

NeuroVim, also called vim-dojo, is an Obsidian plugin that teaches Vim through a cyberpunk spy story in which a handler named CIPHER assigns missions that are really Vim exercises. The README describes 54 playable missions across two story arcs, materialised as throwaway notes edited with Obsidian's own Vim mode rather than a simulator, with a mission HUD showing line progress, elapsed time and keystroke count, on-demand character-precise hints, and XP, levels and best scores per mission. Leaving a mission note pauses the timer and restores Vim mode, and an optional CIPHER uplink sends in-character advice and debriefs through any OpenAI-compatible endpoint, including a fully local one.
