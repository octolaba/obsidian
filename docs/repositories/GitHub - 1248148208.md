# Jimmy-web169/obsidian-slash-commands

Repository for Slash Inserter, a plugin whose slash menu inserts a block chosen from a list. Its README tabulates the commands and their aliases: headings, bullet, numbered and task lists, blockquotes, callouts, fenced code, dividers, a small table, a math block, a Mermaid diagram, internal links and transclusions, video embeds, an inline frame for an embeddable address, a plain external link, and a rich preview card. The card command prompts for a URL and inserts a card built from the page's OpenGraph title, description, image and site name.
