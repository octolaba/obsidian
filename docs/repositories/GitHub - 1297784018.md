# johannes-kaindl/obsidian-paperize

Paperize exports the active note as a text-selectable vector PDF holding only the note's content, with no letterhead added. One command or ribbon icon produces the file without a browser print dialog, and the README states that the plugin writes the PDF bytes itself rather than relying on a print pipeline, so the same code path runs on desktop, iPhone and iPad. Headings, paragraphs, inline formatting, nested lists, blockquotes, rules, links, images, fenced code and simple tables are covered, while elements outside that scope such as callouts, math and embeds are simplified into plain text and counted in a summary notice. Four output destinations are chosen in settings, and the interface follows the Obsidian display language in English or German.
