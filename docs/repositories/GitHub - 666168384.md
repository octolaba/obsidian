# kepano/obsidian-permalink-opener

Permalink Opener opens the URL of the current note on a published site, built from a permalink or slug held in the note properties, for use with static site generators and publishing platforms such as Jekyll, Hugo, Eleventy, Astro and Obsidian Publish. Three settings control it: the name of the frontmatter property carrying the permalink, which defaults to permalink but can be set to slug or something else, a live site base URL, and a development site base URL. The command is run from the command palette or a hotkey, and when no permalink is set the note title is slugified using kebab case.
