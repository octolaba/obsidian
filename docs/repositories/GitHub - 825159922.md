# logonoff/obsidian-inline-spoilers

The recorded description says the plugin adds Discord-like syntax for inline spoilers. Per the README a spoiler is created by wrapping text in a pair of double pipe characters or by running the Create spoiler command, other formatting may be nested around it but must stay outside the spoiler, and clicking a spoiler reveals or hides it unless the Always show spoilers setting is enabled. CSS variables and classes are exposed so that a snippet can restyle spoilers without modifying the plugin. The README states that its author is no longer an active Obsidian user and that a pull request is the most reliable way to get a fix or feature implemented.
