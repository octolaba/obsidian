# yy4382/obsidian-static-site-export

Obsidian plugin that exports notes carrying a published front matter key set to true into plain Markdown for a static site generator such as Hexo, Hugo or Astro. Its main process rewrites wiki links and embeds that point at other published notes into standard Markdown links, handles tags and images, and leaves the links inside the vault untouched. One ribbon button exports every valid file and another only the current note, and the README states that since version 2.0.0 the plugin does not modify files in the vault, only reading them and generating new files to upload.
