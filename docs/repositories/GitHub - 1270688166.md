# ccf/agentcairn-obsidian

Read-only Obsidian plugin that visualises an agentcairn agent-memory vault, in which a coding agent's memory is stored as plain Markdown. A note counts as a memory when its frontmatter carries a memory type; the list view searches by keyword and filters by project, harness, currency and tag, sorted by newest or importance, while a provenance panel shows the active memory's originating project, harness and session with importance and currency badges. Superseded and expired memories are dimmed and badged, matching how agentcairn's recall demotes them. A d3-force graph draws the related edges between memories, colouring nodes by project, sizing them by importance, parking isolated notes aside, and optionally clustering around hub nodes for a project, harness or tag.
