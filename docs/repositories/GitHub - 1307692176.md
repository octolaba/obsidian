# Lizhen0628/obsidian-wechat-sync

WeChat Collector pulls WeChat Official Account articles into an Obsidian vault as Markdown archived by date. Its README describes it as one part of a larger project that requires a separate backend server: a link is submitted from a WeChat mini program, the server fetches the article HTML, parses the body, converts it to Markdown and downloads the images, and this plugin polls the server and incrementally pulls new articles into the vault. Articles are filed into year-month folders, images are downloaded locally because the WeChat CDN copies expire, and sync can run on a configurable polling interval or be triggered from the status bar, the ribbon icon or the command palette. The README records that it works on desktop and mobile because it uses the requestUrl API, and that a server address and API token must be configured.
