# o1xhack/obsidian-sync-trakt

Sync Trakt turns a Trakt.tv watch history into Markdown notes that record which episode was watched at what time, re-watches included, through an incremental sync. Metadata is translated through TMDB into more than fifteen languages with a strict primary locale plus a user-defined fallback, so a missing translation does not silently substitute another locale, and the English originals stay in separate frontmatter fields. The README records poster sources set to automatic, TMDB-only or OMDb-only, with OMDb used by IMDb id as a poster-only fallback; renaming of existing notes and their internal links when the metadata language changes; bundled note templates in eleven languages; tabbed settings; and daily-note injection of watched, watchlist, favourited and rated events inside a marker-bounded region that leaves surrounding content alone.
