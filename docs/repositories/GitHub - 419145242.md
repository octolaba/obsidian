# James-Fallon/obsidian-lineup-builder

The repository holds Obsidian Lineup Builder, a plugin that draws a football lineup from a code block and shows it in preview mode. Its README records a lineup block with two options: a formation chosen from a fixed list including 433, 4231, 442 and its diamond variant, 523, 532, 541, 352 and 343, and a list of eleven players ordered from bottom to top and left to right. It records that the pitch and player images are generated from Wikimedia Commons SVGs whose positions were moved to build the formations.
