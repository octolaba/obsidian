# tnichols217/obsidian-columns

Obsidian plugin for laying out columns in a note, with a column wrapping feature for mobile that is enabled in settings. The README documents three syntaxes: a callout syntax built on the Obsidian callout spec, which uses no JavaScript and therefore works in live preview but cannot limit column height; a code block syntax that supports live preview and all settings; and a list syntax that does not support live preview. In the callout form each item inside the column callout becomes its own column, and a nested variant groups items into one column with a width given in multiples of a half up to ten.
