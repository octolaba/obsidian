# Kianzzz/wechatPB

Formats Obsidian notes for WeChat Official Accounts and sends them to draft boxes without leaving the vault; the README is written in Chinese. It manages several accounts at once, ships 14 built-in themes with a preview of title, body, quotes, code blocks and images, compresses and uploads inline images, keeps a default cover, exports the formatted article as one long PNG beside the note, and reads custom themes from a CSS file or a Markdown file holding a CSS block. AppSecret, access tokens and proxy passwords are held in Obsidian's SecretStorage, HTTP and SOCKS5 proxies are supported with exit-IP and connection checks, and each publish result is recorded locally. The README states the plugin is desktop-only and that the account's exit IP must be added to the WeChat platform's whitelist before publishing.
