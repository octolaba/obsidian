# jlb-jlb/vault-script-runner

The repository carries no description; its README presents Vault Script Runner as a desktop-only Obsidian plugin for running local scripts with prompted parameters. The plugin itself is script-agnostic: scripts are discovered from a catalog JSON file whose URL is configurable, downloaded on demand into a scripts folder inside the plugin directory, tracked by version so a newer catalog entry appears under updates, and executed through the preset the catalog supplies. A catalog entry carries an id, name, version, description, filename, an optional checksum and a preset defining the command, arguments, prompted parameters, virtual environment use and requirements, and presets are written with template variables for the vault path, plugin and scripts directories, the downloads folder, the newest downloaded file and the active file.
