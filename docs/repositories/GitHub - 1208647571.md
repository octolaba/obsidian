# nowszhao/obsidian-alipan-sync

Obsidian plugin that synchronises a vault two ways with Alipan cloud storage, connected through OAuth authorization. Synchronisation is incremental so only changed files are transferred, a loose sync mode is offered for vaults holding thousands of notes, and a size limit skips large files. Conflicts are resolved by character-level comparison that merges changes where it can, with an alternative timestamp rule in which the newest file wins. A remote file browser, sync status indicators and detailed logs for troubleshooting are included.
