# chfourie/obsidian-journal-folder

The README describes an Obsidian plugin that turns any folder in the vault into a journal: a note named for a day, week, month or year, carrying a one-line code block at the top, is rendered with a navigable header, an inline calendar picker and a sidebar. Any number of independent journals can run in one vault, each folder keeping its own settings, its own sequence of notes and its own header. The header offers backward and forward chips, a Today link and a popover for higher-order period jumps, while the calendar picker mirrors the journal with existing, missing, today and current-note states, a fold-out month grid and per-platform defaults. A ribbon icon opens a menu for the sidebars, for switching light and dark mode and for initialising a new journal folder, and new notes can be auto-filled from note-based templates without Templater.
