# fredoliveira/obsidian-lens

Obsidian plugin that reruns a note through different framings: a note or a text selection is sent to a language model with a lens that challenges, steelmans or concretizes the idea, and further lenses can be defined by the user. Results stream into a side panel opened from a ribbon icon or a command, and a result can be saved as its own note named after the lens and source, linked back and tagged. Anthropic is the default provider, with the key held in Obsidian's secret storage and kept out of synced settings, and any OpenAI-compatible endpoint, hosted or local, can be used instead. The README notes that only the Anthropic path streams, because other endpoints are reached through Obsidian's request layer which does not.
