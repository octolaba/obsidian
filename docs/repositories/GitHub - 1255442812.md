# carnalMATRIX/obsidian-mantle-images

Mantle Images provides image editing, resizing and cropping inside an Obsidian vault, so diagrams, photos or screenshots can be cropped and formatted without an external editor. The README records a modal cropping canvas, aspect-ratio presets of 1:1, 16:9, 4:3 or freeform, inline resize handles in the note editor, and either replacing the source file in the vault or saving the edited image as a new asset. It states that the plugin matches the Project Mantle design tokens and is tuned for the Zenith theme while functioning on any theme, and its troubleshooting section notes that SVG and PDF files cannot be cropped.
