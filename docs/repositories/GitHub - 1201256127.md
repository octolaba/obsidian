# wuyifan-code/Obsidian-pretext

The repository holds Pretext Optimizer, an Obsidian plugin that reduces DOM measurement work while notes render. Its README explains that Obsidian measures text to set heights, and that the plugin computes those heights ahead of time and sets min-height directly so the browser can skip the measurement, through a MarkdownPostProcessor in preview mode and a CodeMirror extension on editor lines. Identical text and font results are cached, DOM-mutation triggers are throttled through requestAnimationFrame, and scanning is limited to the visible content area. The README records version 1.2.2 and gives Obsidian 1.10 or newer as the requirement.
