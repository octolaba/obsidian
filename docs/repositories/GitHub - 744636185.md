# yamfeel/coco-askai

CoCo-AskAI adds AI-assisted writing to Obsidian through customizable functions, and its README states that the plugin itself is closed-source. The release notes that make up most of the README describe an AskWin panel with multi-directional resize handles, a customizable right-click menu with toggle switches and item management, model configuration covering OpenRouter and one-click reset buttons for Ollama and LM Studio setups, and model tags that select a model from inside a prompt. Further entries cover menu sorting by usage frequency or last use, listening-tag controls with toggles and quantity limits for filtering, cached emoji resources, and note search handling of the link-opening bracket symbols in both ASCII and full-width form.
