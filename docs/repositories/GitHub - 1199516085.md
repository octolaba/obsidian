# Skyleret/obsidian-ical-task-sync

Obsidian iCal Task Sync fetches events from an iCalendar URL and writes them as checkbox tasks under a `### Tasks` heading, in a fixed line format carrying the task name, an optional link and a dated marker. The README states that the plugin never deletes manually written tasks, keeps indented sub-tasks and notes attached to their parent, and uses a local manifest so a task that has been moved is not added again. The source URL is configured in settings, with the `webcal` scheme replaced by `https`, and a sync runs when the target note is opened, or on a keyboard shortcut or a status-bar icon. Its only network use is retrieving iCalendar data from that user-specified URL, and the README states that the plugin was written with the help of an AI assistant.
