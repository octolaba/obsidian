# danielkhmara/obsidian-lumines

Lumines is described as a minimal Obsidian theme, in development since 2024 and, according to its README, used daily by thousands of people. The README states that it preserves the familiar Obsidian interface while offering an updated colour palette and an expanded set of features, with support for Android, Windows, iOS and macOS. It records that a Catalyst license is used during development, so users often receive updates before new public Obsidian versions are released, and documents situational icons that change with the property type or with listed keywords, drawing on more than 300 icons.
