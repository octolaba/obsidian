# yut0takagi/obsidian-meeting-detector

Meeting Detector polls at a configurable interval for a running meeting application and, when one is found, shows a modal offering to start a recording through the core Audio Recorder plugin, create a meeting note from a template, do both, or dismiss for the session. Zoom and Microsoft Teams are found by process detection and Google Meet by reading browser tab titles from Chrome, Brave, Edge, Arc or Safari, which the README records as making the plugin macOS-only. Notes are generated from a template file supporting date, time and application-name variables, with settings for the notes folder, the filename format and what happens when a meeting ends.
