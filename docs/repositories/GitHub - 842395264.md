# likemuuxi/obsidian-modal-opener

Modal Opener opens files and links in an Obsidian modal window, and can create and edit compatible file types there. It supports Markdown heading and block anchors, switching between editing modes, restoring the modal to a tab by double-clicking its border, hotkeys for opening the current file or link, and custom commands that open a given file or link in one action. A right-click menu creates several file types and edits them in the modal, embedding the link at the cursor position when editing finishes. The README records that creating diagrams from that menu and editing code blocks in the modal each require a modified version of another plugin, and credits obsidian-link-opener as the basis of its structure.
