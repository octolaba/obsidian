# agrison/obsidian-tag-classes

Tag Classes adds every tag on a note to its view container as a CSS class, so that a note tagged recipe carries the class tag-recipe. The README's point is that a snippet in the vault's snippets folder can then target notes by tag alone, without adding a cssclasses property to the frontmatter of each note. No configuration is described: once the plugin is enabled the classes are applied automatically.
