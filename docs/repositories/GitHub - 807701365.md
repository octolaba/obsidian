# Mossy1022/Smart-Connections-Visualizer

Smart Connections Visualizer draws the connections of the note currently open as a force-directed graph, where nodes are notes or excerpts from them and the distance from the central node is proportional to how relevant the connection is. Node size, label size, text fade distance, the minimum and maximum link width and the repel, link and center forces are all adjustable, and hovering a node previews the note behind it. The README records the plugin as integrating with the Smart Connections tool and points at a separate vault visualizer for clusters spanning many notes rather than one.
