# nsyout/obsidian-concordance

Obsidian plugin that generates Markdown indexes of links from folders, tags, frontmatter properties or filename prefixes. The README states that only the content between the plugin's start and end markers is rewritten, so prose, headings and callouts elsewhere in the index note are left alone, and that single and bulk updates are shown in a diff modal before saving, with a read-only check command for previewing pending changes across the vault. Link style and sort order are configurable per index block, and folders and filename substrings can be excluded in every mode.
