# razeghi71/obsidian-image-search

Searches for images through the Brave Search API from inside Obsidian and inserts a chosen result into the current document. A command opens a prompt for the query and displays the returned images for selection. Using it requires a Brave Search API key created on the Brave Search API dashboard and entered in the plugin settings; the README describes the signup steps and the query limits of the free and paid plans.
