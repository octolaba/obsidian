# taskgenius/taskgenius-plugin

Task Genius adds a task-management layer over the plain-text tasks of a vault. Its views show tasks as a list, a kanban board, a calendar or a gantt chart, and further features cover recurring tasks and several date types, priority indicators, multi-stage workflows with automatic timestamping, habit tracking, quick capture, saved queries and filters, and achievement-style rewards. It is installed from the community plugin browser, and guides the user through an onboarding process once enabled.
