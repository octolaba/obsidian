# open-octo/octo-obsidian

Obsidian plugin that embeds the Octo Agent coding assistant in a chat sidebar whose working directory is the vault, so the agent reads, writes, edits and searches files and runs multi-step workflows. Selected text or the cursor position can be edited inline with a word-level diff preview, a slash prefix inserts reusable prompt templates or skills from user and vault scopes, an at-prefix mentions vault files or files in external directories, and a hash prefix adds custom instructions from the chat input. Several chat tabs and a conversation history are kept side by side. The README requires the Octo Agent command-line tool or server reachable at a configurable local address, a minimum Obsidian version and a desktop platform, and records that input, attached files, images and tool-call output go to the configured server.
