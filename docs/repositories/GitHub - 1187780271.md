# oneoffobject/dynalist-mover

Dynalist Mover moves the selected lines of an Obsidian note up or down as a block, keeping the selection after the move so repeated presses continue shifting it. The README states that it is not restricted to bullet lists and works on paragraphs and any other text, that selected lines are highlighted while being moved, and that indented child items travel with their parent unless that setting is turned off. Two commands, Move selected lines up and Move selected lines down, ship without default hotkeys, and the README warns of conflicts if the Outliner plugin is bound to the same keys.
