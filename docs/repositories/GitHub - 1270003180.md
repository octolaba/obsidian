# Longwind1984/galaxy-view

A three-dimensional graph view that renders the vault as a starfield of nodes coloured by graph groups, with thin link filaments, a rotating backdrop and a camera that glides rather than jumps; the force simulation runs in a Web Worker to keep the main thread free. Physics parameters — repulsion, link distance and strength, centre pull and a flatten force that turns the cloud into a disc — are adjustable live, and eight style presets plus colour themes can be previewed, applied and saved. Guided navigation includes a hands-off tour between notable and long-unseen notes and a shortest-path flight between two notes, while a focus mode dims everything outside a selected note's neighbourhood. Canvas files participate in the graph alongside Markdown notes, tags stay off until enabled, and the interface is offered in six languages.
