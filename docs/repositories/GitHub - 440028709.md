# RyzenFromFire/obsidian-phoenix

Phoenix is the author's personal CSS theme for Obsidian, built around a palette of red, orange, yellow, grey and black with a tinge of blue and green. It was originally based on the gruvbox and Atom themes and has been heavily modified since, and the README names Obsidian 1.6.7 as the latest verified compatible version. Because it is meant primarily for Live Preview, the reading side is less polished, and the author states that the light theme receives less attention than the dark one. The README also points to companion snippet repositories for checkboxes, printing, callouts and file outlines.
