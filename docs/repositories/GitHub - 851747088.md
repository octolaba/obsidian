# anareaty/callout-menu

The repository records no description, so this body rests on the README alone. The README addresses users who work with many custom callouts and want to change a callout's type from the context menu, and states that the plugin lets the user choose which callout types appear in that menu. It also adds entries for setting or removing callout metadata and the plus or minus sign that controls folding. The lists of callout types and metadata types shown in the menu are entered in the plugin settings.
