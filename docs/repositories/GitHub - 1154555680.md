# skydiver/obsidian-image-grid

Image Grid renders images in a responsive CSS grid inside an Obsidian note, driven by a fenced block tagged `image-grid` that lists the images in wiki-link syntax. Optional `key: value` lines before the list configure the grid, with `columns` defaulting to three and `gap` to four pixels, and the pipe syntax on an individual embed sets that image's maximum width. Clicking any image in the grid opens a full-screen lightbox, dismissed by clicking the backdrop or pressing Escape.
