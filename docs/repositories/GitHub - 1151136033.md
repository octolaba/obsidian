# HCYT/taskweaver

TaskWeaver gathers the checkbox tasks scattered across an Obsidian vault into a sidebar list and a set of Kanban boards. The list searches and filters tasks, expands sub-tasks with progress, colors them by priority and jumps to the source file and line; the boards hold customizable columns whose type can be manual, completed, dated, overdue, undated or driven by a tag, with per-column work-in-progress limits and drag and drop between them. Individual tasks can be given due dates and tags, pinned, archived, moved to another file from a context menu, and are flagged when a duplicate is detected. Settings hide completed tasks, include or exclude folders, and auto-hide empty columns.
