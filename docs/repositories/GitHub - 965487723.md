# mntno/obsidian-come-through

Come Through creates and reviews flashcards in Obsidian using the FSRS scheduling algorithm. A card side is declared with a code block whose language is `ct` or `comethrough`, and the contents of that side are the heading section in which the block sits, so one note can hold several sides. A front side generates an `id` automatically and a back side is paired to it by repeating that `id` in another heading section; the README warns that changing an id after the card has first been rated makes it a new card, and that for the default card type the id must be unique across the vault, which lets the two sides live in separate notes.
