# Andrewyx/Github-PR-Autocomplete

Adds an autocomplete suggester for open GitHub issues and pull requests: typing a trigger character, by default an at sign, followed by a search term or an issue number lists matches from the configured repository and inserts a markdown link. The trigger character is configurable so it need not collide with other plugins, and private repositories become reachable by adding a personal access token with repo scope. The README states that several named tokens can be managed with a validity indicator in settings, and that tokens are held through Obsidian's secret storage API, hardware-encrypted on desktop through the system keychain and stored locally on mobile.
