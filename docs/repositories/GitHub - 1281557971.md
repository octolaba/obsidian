# pssah4/frontmatter-operator

Bulk-edits YAML frontmatter across a vault: notes are selected by property and value conditions using fourteen operators with AND and OR plus virtual columns for folder, filename and extension, and one action is then applied — set, delete, rename a property, copy or merge properties, or rewrite values with per-value mappings and bulk transforms. Missing fields such as a description, tags or a map of content can be generated from note content with a language model, and cleanup passes strip refusal boilerplate out of frontmatter and collapse duplicate wikilinks. Every write action saves a JSON snapshot, so the last action can be undone or any of the last fifty restored. The plugin offers an interactive table view with inline editing and per-column filters plus a typed programmatic API with twelve commands, and the README presents migration to the Open Knowledge Format as its main use case.
