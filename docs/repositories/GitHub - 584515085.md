# connerohnesorge/vim-toggle

Vim Toggle adds a command that turns Obsidian's Vim editor mode on and off, so it can be switched without going through settings. The command can be bound to a hotkey, and a settings tab holds a toggle for the optional notification shown when the mode changes. The README states that the plugin was written in response to the Canvas core plugin, whose arrival prompted the author to make toggling Vim mode easy.
