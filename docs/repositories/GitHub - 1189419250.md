# chefrocker/awesome-task-manager

An Obsidian plugin for visual task management inside the vault, with no external dependencies according to its README. It provides a dashboard with four tabs — Today, week, Open and All — inline editing in the task table, automatic status transitions and completion dates, recurring tasks, handling of task-related images, and export to Excel with formatting and formulas. The repository ships its documentation in a docs folder, largely written in German, covering requirements, specification, architecture, technical design, test concept, user manual and API.
