# anshusrathe/nexus-lm

This repository holds Nexus-LM, an Obsidian plugin whose recorded description covers concept maps, slideshows, notebooks, vault chat, web search, MCP and a personal feed, all generated inside Obsidian. The README records API keys for providers including Gemini, Groq, OpenRouter, OpenCode, Nvidia, Mistral and Cohere plus Ollama for local models, a hub opened from a ribbon icon or a command, and a vault index built in the settings to enable semantic search. It also records RSS feed management, code execution and custom model endpoints that can be enabled, disabled and configured in the model selector.
