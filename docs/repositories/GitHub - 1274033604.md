# On-DevPlan/ob-ps

Local Runner runs local shell commands from an Obsidian sidebar tab and streams their output live, giving each command a card with a status dot and an expandable log so a dev server or other CLI tool keeps running while notes are written. Output merges stdout and stderr, strips ANSI escapes and is capped at 200,000 characters, and stopping a process kills the whole process tree on Windows while other platforms fall back to a termination signal. The same sidebar lists unresolved wikilinks newest source first, can flatten every unresolved link in the vault after a confirmation, and draws a pannable repair-history tree built by walking a frontmatter backlink chain upward. The README marks the plugin desktop-only because it spawns child processes, and it is written in English and Chinese.
