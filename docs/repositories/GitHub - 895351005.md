# pahkey/obsidian-wikidocs-plugin

This plugin lets WikiDocs books and blogs be written and edited from inside Obsidian rather than in the web interface. Its README states that working locally gives faster response than the web environment and allows offline work, that images and table-of-contents order can be arranged by drag and drop, and that a send-to-WikiDocs action uploads the finished document. Setup requires a WikiDocs API token from the account settings together with the API base URL, entered in the plugin settings, after which book and blog icons appear in the sidebar. The recorded README is written in Korean, so this is an English restatement of it.
