# davidingerslev/outlook-meeting-notes

Outlook Meeting Notes creates a note from a Microsoft Outlook meeting, filling a customisable template with the meeting details such as date and time, subject, recipients and the invite message. It processes .msg files dragged from the Outlook Classic desktop app onto the plugin's ribbon icon, which the README gives as the reason that no code has to run inside Outlook and no administrator has to authorise a Microsoft Graph app. The README records a limitation for recurring appointments: Outlook includes no field identifying which occurrence was dragged, so the start time of the first appointment in the series is used, and it suggests putting the current date and time into the filename template instead.
