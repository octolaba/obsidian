# caulfieldsbrain/shadowdark-statblocks

Shadowdark Statblocks imports, manages and renders monster stat blocks for the Shadowdark role-playing game inside Obsidian notes. The README describes pasting raw stat blocks from PDFs or selected text and parsing them into structured monster notes, a bulk workflow that detects several monsters in one paste and steps through them with import, skip and cancel choices before a summary, suggested tags and a remembered source, and duplicate handling that prompts to overwrite or copy on a single import and creates copies during a bulk one. A browser searches and filters monsters by name, source, tag and maximum level with hover preview, stat blocks render from frontmatter in monster notes, hover previews and embeds, and an optional integration with the Dice Roller plugin turns attack, damage and ability dice into clickable rolls.
