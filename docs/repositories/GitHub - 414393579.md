# deathau/snippet-commands-obsidian

Snippet Commands registers every CSS snippet in the vault as an Obsidian command, so a snippet can be toggled from the command palette or bound to a hotkey. A separate command reloads all snippet commands when the set of snippets changes while Obsidian is running. The README states compatibility from Obsidian 0.9.18, the version that introduced CSS snippets, and describes the plugin as very experimental.
