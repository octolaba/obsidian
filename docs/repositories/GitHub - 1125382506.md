# Vetrenar/Open-PDF-Translate

Obsidian plugin that translates PDF documents inside the vault through a configured provider such as OpenRouter. In overlay mode it extracts text blocks and their positions from the current page, sends each block for translation and renders the result as a positioned overlay above the original PDF, leaving the file itself unchanged and saving the overlays to a companion translations note for later reloads. A separate OCR pipeline handles scanned PDFs that carry no text layer, and the layout engine is either the internal one reading the text layer of Obsidian's own PDF viewer or an external Python engine built on PyMuPDF.
