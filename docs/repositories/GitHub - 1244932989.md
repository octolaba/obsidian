# pangy9/obsidian-note-database

This repository holds Note Database, an Obsidian plugin that presents notes as local-first database views while the notes themselves stay plain Markdown. The recorded description lists table, board, gallery, list, chart, calendar and timeline views together with formulas, filters and inline editing, which the README summarizes as the same notes in seven views. Documentation is provided in English and Simplified Chinese.
