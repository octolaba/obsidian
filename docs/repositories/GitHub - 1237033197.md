# Nymbo/Copy-Highlighter

The repository holds Copy Highlighter, an Obsidian plugin that highlights text as it is copied, as a visual confirmation that the copy happened. The highlight appears when the copy shortcut is pressed and stays while it is held, also covering copied text in reading view and other rendered content, and a configurable fallback duration handles mouse or menu copies where no key release can be observed. Settings cover the highlight colour, editor and rendered-text opacity, corner radius, whether rendered Markdown is highlighted, and the two fallback timings; the README states that the plugin uses no external services, network requests, telemetry or file-system access.
