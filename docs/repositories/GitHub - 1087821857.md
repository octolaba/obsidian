# ly0va/beastvault

BeastVault is an Obsidian plugin for game masters of the Daggerheart tabletop role-playing game, used to search, edit and create adversary and environment stat blocks. Adversaries and environments from the SRD can be inserted through commands, rendered as editable stat blocks that roll attack or damage dice on a click and track marked HP, stress, countdowns and feature uses, with battle points shown in the status bar. The README records customizable colors for any theme, use inside a canvas for encounter building, and a roadmap that includes a local homebrew library, filtering through Bases, summon buttons and condition markers.
