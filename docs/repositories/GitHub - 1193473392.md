# konstantinosGkilas/Obsidian-SVG-Viewer

SVG Viewer renders svg code fences as live graphics in Reading View and Live Preview, so raw SVG markup pasted into a note is displayed without any attached file. All content is sanitized before it reaches the DOM: the README lists removal of script and foreignObject elements and of every on-event handler attribute, plus a setting that strips external http and https URLs from attributes. Clicking a rendered block shows the raw source and clicking outside returns to the graphic, hovering reveals a copy button, a second setting toggles a small badge on rendered blocks, and the README states there are no runtime dependencies.
