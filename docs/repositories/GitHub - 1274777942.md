# Stepheson/s-restore-profile_obsidian-plugin

Exports the community plugins and themes enabled in a vault into a single profile file, then imports that file into another vault to bulk-install and activate all of them at once, instead of searching for each one in the community store. The stated cases are keeping several vaults consistent, moving to a new machine, and restoring after a backup or migration. The interface separates plugins and themes into their own tabs.
