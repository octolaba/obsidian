# reorx/obsidian-telegraph-publish

This plugin publishes the active note to a Telegraph page. It can create a new page, update the page a note was published to before, and clear the published content again. The README notes that Telegraph supports only a restricted set of markup, so very complicated pages are not practical, and that image uploading was still an upcoming item.
