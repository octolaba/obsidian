# encima/obsidian-writeas-plugin

This plugin publishes Obsidian notes to write.as or to a self-hosted WriteFreely instance. Its README discloses that it publishes content over the internet and requires an account on one of those services: a username, a password and optionally an instance URL are set in the plugin settings, and each note must carry a frontmatter key naming a collection or blog the account owns. Running the publish command sends the note and writes the post id and URL back into its frontmatter, so later runs of the command update the same post instead of creating a new one.
