# HobbySoftwareDeveloper/Zen-Forest

Zen Forest is a minimal Obsidian theme derived from the Zen theme by Laughmaker, aiming at a quiet, typography-led writing environment. The README records a unified narrow viewport width that constrains all six heading levels and body text to one layout width, a custom cubic-bezier entrance animation for modals and dialogs, a hardcoded forest color palette and reworked sidebar layouts and active states. It warns that the theme is optimized for desktop and that mobile layout adaptation is still in progress, recommends a specific accent color for the intended look, and notes compatibility with the Style Settings plugin.
