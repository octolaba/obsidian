# buzzguy/friend-tracker

This repository holds Friend Tracker, described upstream as an Obsidian plugin for managing personal connections, keeping track of dates such as birthdays, anniversaries and milestones, and logging interactions with friends, family and colleagues. The README describes contact profiles holding name, birthday, email and phone, custom fields for anything else worth tracking, a notes section per contact, dated interaction entries, a view of upcoming birthdays, and sorting by name, age or next birthday. It credits an article on maintaining friendships as the inspiration for the approach.
