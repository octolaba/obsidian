# callmekeyboardman/text-brush

Text Brush applies text colour and font size in Obsidian through the editor right-click menu, so a selection can be coloured, resized, cleared or made bold from submenus. The README records that re-colouring or re-sizing already-marked text replaces the value in place instead of nesting elements, that the default palette uses Obsidian theme CSS variables, and that both a CSS class and an inline style are written so the formatting survives HTML and PDF export. Colours and sizes are editable in settings, and pasting a bare HTTP or HTTPS URL is converted into a Markdown link.
