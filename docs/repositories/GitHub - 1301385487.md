# cyriusweng/opal-companion

Companion plugin for the Opal Obsidian theme that turns options otherwise typed by hand into a visual picker in which every choice renders a live preview before it is applied. One click writes page state, layout and recolour classes into the note's frontmatter, inserts a callout of any type, wraps a selection in a coloured highlight, sets the checkbox state of the current line, or chooses an image layout such as banner, grid, float or dark-invert through the image alt text. It is reached from a floating toolbar at the bottom of the screen, from the command palette or from the editor right-click menu. The README states that it styles only what the Opal theme understands, so that theme has to be installed and enabled first.
