# abhimangs/obsidian-vortex

Vortex is an Obsidian theme built around the accent color chosen in Obsidian's appearance settings, which the README says everything in the interface then follows. Documented styling includes a distinct color for each heading level with a glow effect and a gradient underline, separate colors for internal and external links with a hover animation that raises a bottom border to fill the background, and a set of custom callouts with their own icons. The README is organized as a walkthrough of those areas, each with a screenshot.
