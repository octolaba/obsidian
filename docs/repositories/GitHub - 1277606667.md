# Initsnow/obsidian-harmony-progression-player

The repository holds Harmony Progression Player, an Obsidian plugin that detects chord progressions written in notes and plays them back. The README records recognition of numeric degrees, Roman numerals and chord symbols with extensions, altered chords, sus and add chords, diminished and half-diminished chords and slash chords, giving examples that range from bare degree sequences to jazz voicings. Progressions written in inline code are detected while fenced code blocks are ignored. Settings record the folders in which the plugin is active, defaulting to the whole vault, a key root that resolves numeric and Roman-numeral progressions, and a choice between a bundled sampled piano and two synth instruments.
