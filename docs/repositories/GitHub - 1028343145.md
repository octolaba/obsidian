# iCodeAlchemy/horizontal-blocks

An Obsidian plugin that renders side-by-side, resizable Markdown blocks from horizontal or hblock code blocks, with columns separated by a rule line and support for images, embeds and internal links inside them. The README records a draggable divider, per-block width controls, persistence of block widths between visits, and a styling settings tab that adjusts divider colour, thickness, opacity and style, block backgrounds, borders, padding and gaps through CSS variables. It warns that content inside the code block is treated as plain text, so tasks written there are not recognised by the Tasks or Dataview plugins.
