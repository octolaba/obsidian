# lunerfox/obsidian-gitea-cards

Renders live Gitea issue cards inline from a gitea-issue code block, showing the linked number, title, truncated body, label chips, comment count, state, author, milestone and last-updated time from a single API call, with a comment thread that expands lazily beneath the card. Visible cards refresh on a configurable interval floored at thirty seconds, a shared cache coalesces duplicate fetches, and unreachable cards render stale rather than erroring. A search block lists issues by repository, state, labels and milestone, a milestone block draws a progress bar, and a graph block renders a milestone's issues as a dependency graph with still-blocked issues dimmed; wizard commands build those blocks from dropdowns with a live preview. Issues can also be created from a modal and inserted as a full card, an inline status chip or nothing at all.
