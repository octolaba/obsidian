# Bluemoondragon07/obsidian-light-and-bright-theme

This repository holds a light and bright Obsidian theme that its README describes as clean and weightless, and records as the author's first theme, inspired by hydescarf's Mado Miniflow and kneecaps' Ultra Lobster. The README states that the accent colour affects the sidebars and the main note pane, that values stay the same whether a dull or intense accent is chosen, and that both light and dark modes are covered. It lists rounded elements, box shadows, header sizes increasing by level with the first two centred, compatibility with Dataview and Style Settings, and built-in support for kepano's Minimal cards class and hydescarf's mado panels code.
