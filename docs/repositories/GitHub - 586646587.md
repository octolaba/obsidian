# BumbrT/obsidian-reading-comments

Reading Comments lets a reader annotate long notes with inline HTML comments while reading, and also recognises Obsidian's native comment syntax. Comments are tagged with hierarchical parent and child tags and grouped by parent in a panel that supports search and click-to-navigate, and commands add a comment for the current selection, open the panel, and remove or toggle a comment between block and inline form. A comment can be hidden until the commented text is hovered, and its colour is chosen in the settings. Once commenting is finished, a command extracts the original note with plain Markdown links into a separate comments note, free of the HTML formatting, so it can be integrated with the rest of the vault.
