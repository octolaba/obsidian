# jedgrant/wh-obsidian

Measures writing output as text is typed in Obsidian, separating typed words from pasted ones, and syncs the totals with the writer's Writing Habit account. On the platform side that covers daily and lifetime word counts across writing apps, sprints with timers and stretch goals, streaks against a daily target and leaderboards, while a sidebar panel inside Obsidian shows session statistics and the day's progress. The README states that a free Writing Habit account is required and that signing in happens in the browser from the plugin's panel.
