# tcyeee/obsidian-bases-lock

Bases Lock hides the Obsidian Bases toolbar and disables header interaction on demand, so an embedded base can be read without accidental changes. A lock button appears when hovering an embedded base in Reading view and toggles the state, which is stored by rewriting how that base is embedded in the note's Markdown, so it survives with the document. The README states that only the `.base` embed in the current document is affected, that other notes are never scanned or modified, and that the plugin works in Reading view only and is desktop-only.
