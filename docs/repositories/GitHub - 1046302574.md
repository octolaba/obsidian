# mbedded/obsidian-web-task-dashboard

Connects Obsidian to third-party task services and lists their tasks in the app, so todos can be handled without switching tools. At the time of the README, Tracks is the only supported service, and an account or an independently set-up instance plus authentication data is required for the plugin to interact with it. The project keeps its documentation on a separate site rather than in the README.
