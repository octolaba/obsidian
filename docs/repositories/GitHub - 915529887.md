# alythobani/obsidian-callout-copy-buttons

Adds copy buttons to callout blocks: one copies the callout's content as Markdown with the callout syntax stripped, the other copies it as plain text taken from the rendered preview. The README states that settings control the appearance and behaviour of the buttons, such as showing or hiding them and their format indicators, and that the interface reflects a setting change immediately. It records a limitation of the Markdown button, which the author attributes to technical constraints: it is available only in Source Mode and in top-level Reading Mode callouts, not in Live Preview callouts or nested Reading Mode ones.
