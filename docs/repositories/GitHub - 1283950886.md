# saintbyte/obsidian_mistal_spell_checker

Mistral Spell Checker is an Obsidian plugin that checks and corrects spelling and grammar in selected text using Mistral AI, invoked from the editor context menu or the command palette. Settings choose the Mistral model, customise the system prompt, validate the API key and switch the interface between Russian and English. The README documents the commands it registers, a manual installation from the releases page, and a source layout whose Mistral client is built on the Mistral AI SDK.
