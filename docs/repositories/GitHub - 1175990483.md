# MMoMM-org/miyo-kado

MiYo Kado runs a Model Context Protocol server inside Obsidian, exposing the vault to AI assistants through eight tools covering read, write, delete, rename, search, opening notes, and graph inspection and audit. Access is default-deny: a global security scope defines what is eligible and a per-key scope what each assistant key may do, across five permission gates and four data types — notes, frontmatter as JSON, binary files as base64, and Dataview inline fields — with allowed and denied requests logged. Notes can be read and written in part, by leading characters or words, by heading section or by line and character range, and written back with append, prepend, insert-under-heading or replace operations. The README states that the server runs locally on 127.0.0.1 by default with no cloud, telemetry or third party, which is the project's own claim.
