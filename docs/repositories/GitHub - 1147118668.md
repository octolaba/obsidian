# meghan-lendhe/md-to-json

Markdown to JSON adds a command that copies the current note as an ordered list of structured JSON blocks. Headings become `h1` through `h6` and carry a level, each non-empty body line becomes its own body block, each bullet becomes its own list block, and every block carries a generated identifier. The README records that the output is meant to be pasted into a companion Figma plugin that turns those blocks into separate text layers for case-study page layout.
