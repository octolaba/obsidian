# kikijiki/obsidian-habit-tracker

The recorded description names this the Kikijiki Habit Tracker plugin for Obsidian, and the README calls it a simple habit tracker. Once installed and enabled from Obsidian's community plugins, habits are configured in the settings, and each habit sets a tag in the current document composed of a prefix and the habit name. An Open Habit Panel command displays the panel, which can then be placed wherever the user prefers.
