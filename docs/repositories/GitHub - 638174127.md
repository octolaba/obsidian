# pacokwon/obsidian-lds-library-plugin

LDS Library Reference is described as linking LDS scriptures and General Conference talks in Obsidian notes. Its README says verses from the standard works — the King James Bible, the Book of Mormon, the Doctrine and Covenants and the Pearl of Great Price — are inserted as callouts by writing a reference between colons that names the book, chapter and verse numbers. It also covers quoting General Conference talks and selecting a language, either as a configured default or through a one-time syntax on a single reference. The README states that Obsidian alone is required, with no external service.
