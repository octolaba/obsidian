# kiril-liu/obsidian-ai-plugin

The repository carries no description; its README presents an Obsidian AI assistant with chat, vault search, retrieval-based question answering, a prompt library, a daily note workflow, batch prompts, conversation history and insertion of responses into notes. Chat lives in a right-side panel with a conversation history list, and when vault search is enabled the plugin tries a vector index first and falls back to keyword search that prefers filename matches, then path, then content, showing each reference as a filename, a relative path and an open button. The prompt library reads text templates from a prompts file or folder, invoked in chat with a slash command, and ships templates for daily-life scenarios such as reviews, planning and summaries. The README states that local embedding works on a computer while phones use an embedding API, and that the same model should be used on both.
