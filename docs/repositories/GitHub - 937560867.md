# slateblua/mathtype

MathType offers autocompletion that turns natural-language words into mathematical expressions while typing in Obsidian. The README describes setting a trigger key in the settings, an exclamation mark by default, and then typing an English word for the mathematical expression after that key to see MathJax autocompletion suggestions. It states that a variety of mathematical symbols and functions are supported.
