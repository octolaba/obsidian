# tjbrennan/obsidian-color-cycler

Color Cycler changes Obsidian's accent color on demand from the ribbon menu or the command palette, for readers who keep the default theme but tire of one accent color. Color is defined in HSL, and cycling behavior is configured as increment through the color wheel by a given angle, random selection, or a list of preset colors, each with its own advanced options. A timer can cycle the color automatically at an interval in seconds, the current HSL value can be shown in the status bar, and the behavior can either be shared across dark and light themes or split into separate settings for each.
