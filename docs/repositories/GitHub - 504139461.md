# dartungar/obsidian-simple-note-review

Simple Note Review resurfaces notes for review at the reader's own pace rather than on a rigid schedule, which its README distinguishes from a spaced repetition plugin. A note set is defined by tags, folders, frontmatter properties, creation date or a dataviewJS query, and a note may belong to any number of sets; starting a review builds a persistent queue that is walked in order or at random, skipping drops a note from the current queue until it is reset, and a note's review frequency can be set to high, normal, low or ignore. The README records Dataview as the search engine this plugin depends on, and warns that the queue does not update by itself, so resetting it is advised when a new review starts.
