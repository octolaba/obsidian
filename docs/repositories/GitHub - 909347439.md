# addozhang/obsidian-confluence-converter

Confluence Toolkit converts between Obsidian Markdown and Confluence markup. Two output formats are offered — the storage format in XHTML, which the README recommends because it can be pasted straight into the Confluence editor, and the legacy wiki markup — and the converted content is copied to the clipboard automatically. Heading structures, lists, code blocks and tables are preserved during conversion, code blocks keep their language for highlighting, and Obsidian-specific syntax such as an embedded image link is handled. Code block themes for wiki markup, line numbers and collapse settings are configurable.
