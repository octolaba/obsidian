# zsviczian/excalibrain

Obsidian plugin that renders a vault as an interactive, structured mind map, presented in its README as inspired by TheBrain and Breadcrumbs. It distinguishes five relationships between notes — children, parents, friends, other friends and siblings — derived either from explicit dataview fields or inferred from links, where a forward link reads as a child, a backlink as a parent, mutual links as friendship and the children of parents as siblings; folders, tags and frontmatter also feed the map. The README records Dataview and the Excalidraw plugin as required prerequisites and Hover Editor as an optimisation.
