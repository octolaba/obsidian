# r3d5/obsidian-spectacles-sync

Repository for Spectacles Sync, a plugin that exports the vault as a JSON knowledge graph and uploads it for viewing as a three-dimensional graph on a Spectacles augmented-reality lens. Its README states that the vault is encrypted on the device with a key derived from a password the user chooses, that the server stores only the ciphertext and a password-derived identifier, that the backend address is configurable and can be self-hosted, and that the same password is the only pairing secret on the lens side. Syncing runs from a command or ribbon icon, and an optional setting re-uploads about thirty seconds after editing stops.
