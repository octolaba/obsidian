# sxxgrc/obsidian-pairwise-ranking

This plugin inserts an item into a ranked list on a note by asking pairwise comparison questions, and works on desktop and mobile through the command palette. Its README states that insertion uses a generic binary insertion algorithm of logarithmic order, and that the focus is inserting new items rather than ranking a list that already exists, although an existing list can serve as the ranking source. Each line of the note is treated as an existing ranking entry: the command asks for the new item, then offers choices between it and existing items until its position is determined.
