# s-blu/obsidian-remember-scrollposition

Remember Scrollposition saves the scroll position of a note and restores it when the note is opened again, instead of returning to the top of a long document. Restoring can be left automatic or, by setting, limited to happening only when the ribbon icon or the command is used. The README describes the plugin as very basic and built around its author's own workflow, and records its limitations plainly: it does not work in reading view, only in live preview and source mode, the saved position is an estimate rather than an exact match, and it is untested on mobile devices where it will probably not work.
