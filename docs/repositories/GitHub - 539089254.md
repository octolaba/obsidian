# czottmann/obsidian-actions-uri

Actions URI adds x-callback-url endpoints to Obsidian on top of the app's built-in URI scheme, covering common actions on daily notes, notes and search results. The README keeps the route list in external documentation rather than in the repository text, directs bug reports to GitHub issues and discussion to a separate plugin forum, and states a project status following Don McCurdy's post on expectations in open source. Installation is through the community plugins browser.
