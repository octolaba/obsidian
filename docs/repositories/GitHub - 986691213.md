# gapmiss/hackernews-comments

This plugin fetches the comments of a Hacker News post and saves them as a Markdown note in the vault. A ribbon icon or the Fetch Hacker News Comments command asks for a Hacker News URL, and the created note carries the post title, the original URL and the comment count, with the threads indented and the HTML converted to Markdown. Settings turn usernames and timestamps into links to Hacker News profiles and single comments, set the timestamp format with moment.js tokens, open a new note automatically, wrap HTML tags in backticks to keep them from rendering, and build the filename from template variables.
