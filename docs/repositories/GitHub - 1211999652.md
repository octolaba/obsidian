# mnaoumov/obsidian-email-to-vault

Email to Vault saves incoming emails into an Obsidian vault as notes, in one of two modes: a disposable Mail.tm mailbox created from the plugin settings, or the user's own IMAP server such as Gmail or Outlook. The README states that new mail is fetched periodically, that From, To, CC, subject, body and attachments are kept, and that messages are flagged as seen on the server unless the option to leave them untouched is enabled. IMAP mode is desktop-only while the Mail.tm mode also works on mobile, and the README states that no backend, paid service or external account is required.
