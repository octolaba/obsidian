# FioPio/ObsidianAlignmentTracker

Alignment Tracker records a tabletop character's alignment in Obsidian from what the player's character actually does, rather than fixing it in advance. An alignmenttracker code block holds four counters — L, C, G and E — which are incremented whenever an action fits one of them and which the plugin renders as tables on the lawful-chaotic and good-evil axes. The README describes the author's practice of reviewing those tables from time to time and sometimes sharing them with players, and suggests creating the block from a Templater template.
