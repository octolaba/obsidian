# nnyj/obsidian-mobile-tab-bar

A browser-style tab bar for Obsidian mobile that replaces the title bar with a scrollable row of tabs for the open notes, leaving desktop unaffected. Tapping a tab switches to it, a long press closes it, and the active tab scrolls itself into centre view. An optional save indicator dot is available but depends on the separate autosave-control plugin, and the README notes it reads that plugin's DOM class and may break if those class names change. Tab appearance can be overridden from a CSS snippet.
