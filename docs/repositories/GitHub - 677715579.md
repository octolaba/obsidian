# Klojer/obsidian-emacs-text-editor

Obsidian plugin that adds commands imitating Emacs editing keys, which can then be bound to hotkeys. The README's table maps commands such as backward and forward character, word and paragraph movement, beginning and end of buffer, delete character, kill line, kill region, kill ring save, kill word and keyboard quit onto the usual Emacs chords. It states explicitly that the plugin is a basic imitation rather than an implementation of GNU Emacs functionality, does not integrate elisp, and does not reproduce Emacs command behaviour exactly.
