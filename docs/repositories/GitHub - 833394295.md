# tyrad/obsidian-vitepress

This plugin previews and compiles Markdown files from an Obsidian vault with VitePress, and can drive other static site generators such as Hugo, Hexo and Docusaurus instead. Its required settings name the top-level directories or files to be previewed or published, the path to VitePress on the local machine, and the location of the VitePress source directory. The development, build and preview commands are configurable, defaulting to the corresponding docs scripts, which is what allows a generator other than VitePress to be used. Installation is documented through the community plugin browser or by placing the three release files into a plugin folder in the vault.
