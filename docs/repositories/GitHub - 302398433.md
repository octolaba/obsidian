# santiyounger/Reverie-Obsidian-Theme

Reverie is an Obsidian theme with both dark mode and light mode functionality. The README explains the name as a state of abstracted musing or daydreaming, and directs installation through Settings, Appearance, Themes, Manage, searching for Reverie and selecting it. It is released under the MIT license and is free to use.
