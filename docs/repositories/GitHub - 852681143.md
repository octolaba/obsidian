# zachmueller/spaced-everything

Spaced Everything applies spaced repetition to writing rather than to flashcards, using the SuperMemo 2.0 algorithm to decide which note to review next in a spaced writing practice. A note can be tagged with several contexts, such as work against personal, so that a session only pulls up notes appropriate for the moment. The README credits the practice to Andy Matuschak's notes on incrementally developing writing, and documents installation, configuration, frontmatter properties, template variables and advanced usage.
