# banisterious/obsidian-draft-bench

Draft Bench is a writing workflow for Obsidian covering projects, scenes, manuscripts and versioned drafts as plain Markdown files carrying dedicated frontmatter properties, with no index files or parallel JSON store and native compatibility with Obsidian Bases. The README names Longform as its inspiration and adds per-scene draft history as first-class files, richer frontmatter metadata and a compile system that requires no JavaScript knowledge. Release 0.6.4 is recorded as current, with a dockable Manuscript Builder, a Manuscript view continuous mode, a Scrivener 3 project importer and a status-based scene-archive workflow among the shipped extensions. Mobile support is stated as Android-verified and iOS or iPadOS untested, and the API and data shape may still adjust between minor versions during the 0.x phase.
