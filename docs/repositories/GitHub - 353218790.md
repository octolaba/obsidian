# matthewhchan/linkify

The repository records no description; its README presents Linkify, a plugin that turns text into links based on configurable regular expressions. Each pattern is paired with a URL that may use replacement references from the matched groups, and an optional CSS class applied to matching text; the README gives social-media handles and a GitHub repository shorthand as examples. Matching text is displayed and behaves as a link in Live Preview and opens in a browser when clicked. The README states that the underlying text is not modified and that no change is written to the Markdown files.
