# danielkremen818/obsidian-graph-project-buttons

Graph Project Buttons is an Obsidian plugin that adds a bar of one-click filter buttons to the graph view, so a path query need not be typed by hand. The README records one button per immediate subfolder of a configurable projects root, auto-discovered from the vault, plus a Curated button applying a configurable reset query and an All projects button, with the button matching the current search highlighted. The bar is collapsible, can carry per-button icons, docks to the top left or right, and re-injects itself when the graph re-renders through a mutation observer rather than polling; the project list is cached and recomputed only when files are created, deleted or renamed. The README states the plugin reads only the vault's file list, never file contents, makes no network requests, and writes nothing beyond its own settings.
