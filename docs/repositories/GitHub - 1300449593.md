# ruisloan/obsidian-color-marker

Color Marker attaches color labels to folders and notes from the file explorer's right-click menu, offering twelve calendar-style colors named Tomato, Cherry, Flamingo, Tangerine, Banana, Sage, Basil, Peacock, Blueberry, Lavender, Grape and Graphite. A marked item's name is tinted and given a colored dot, and the same menu removes the color again; colors persist across restarts and follow an item when it is renamed or moved, including everything inside a renamed folder. The README states that it works on desktop and mobile, with a swatch picker dialog on mobile, and that colors are stored in the plugin's own `data.json` keyed by vault path so note content is never touched.
