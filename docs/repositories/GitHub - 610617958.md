# Bluemoondragon07/obsidian-notation-2

Notation 2 is an Obsidian theme based on deathau's Notation theme and on Notion, the app behind its inspiration; the author combined them because the original Notation remained a bit broken after Obsidian 1.0. Callouts are styled like Notion callouts with a transparent background and faint outline, and any callout can take a colour — red, orange, yellow, green, blue, purple, pink, brown or grey — placed after a pipe inside the callout type brackets. The README also documents callout toggle blocks, heading callouts, and CSS classes for banner images, text styling and other adjustments.
