# DaisukeMiyazaki/katazuke

The README presents Katazuke, an Obsidian plugin named after the Japanese word for tidying up, for revisiting notes that have quietly accumulated too many links. It scores notes by degree, counting backlinks the way Obsidian's backlink pane does plus outgoing links while excluding media attachments and self-links, and weights that by how long the note has been untouched, so a note left for one half-life counts double; notes tagged as intentional hubs are left out. Two command-palette modes show either the single highest-scoring note or the top N for a longer session, and a second view covers the opposite failure of notes connected to nothing.
