# sahilium/expiry-manager

Obsidian plugin for tracking things that expire or need renewal, such as domains, certificates, subscriptions, documents, warranties and licences. Each item is created once and keeps its renewal history, and the plugin offers a dashboard showing progress, days remaining, expiry date, cost, category and auto-renew status, alongside timeline and calendar views and a renewal workflow. The README states that all data is stored as plain Markdown notes with YAML frontmatter.
