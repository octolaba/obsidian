# obsidian-ezs/obsidian-comfort-color-dark

Comfort Color Dark is a dark theme for Obsidian, recorded by its README as compatible with Obsidian version 0.5.0. Installation is documented as downloading an obsidian.css file, turning on the Custom CSS option in the plugin settings, placing the file in the vault root folder and restarting Obsidian. The README notes that the theme uses the Avenir font, which has to be present in the local font library for the full effect.
