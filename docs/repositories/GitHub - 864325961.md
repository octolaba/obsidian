# iparips/open-or-create-file-obsidian-plugin

This plugin registers Obsidian commands that open a file when it exists and create it from a template otherwise, following a predefined path pattern. Paths can use date-based patterns with a time shift towards past or future dates, which the README aims at daily notes, weekly plans and other regularly used documents. Command names are customisable, and the command configuration can be exported and imported as JSON files.
