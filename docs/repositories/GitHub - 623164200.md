# nikdanilov/whisper-obsidian-plugin

Whisper records or uploads audio in Obsidian, transcribes it with Whisper and writes the result at the cursor, on desktop and mobile. Recording is started and stopped from a sidebar microphone icon or a hotkey, audio files in several formats can be uploaded from the command palette or transcribed from a file's context menu, and the same actions are reachable through Obsidian URI commands so external tools such as iOS Shortcuts or Alfred can drive them. The README states that it works with OpenAI, Groq, Azure or any other Whisper-compatible API and that an API key is configured in the plugin settings. Optional post-processing sends the transcription through an LLM to fix grammar, drop filler words, format Markdown or extract action items, and can generate a title, with note filename and content driven by template variables.
