# phibr0/obsidian-dictionary

Obsidian Dictionary adds a dictionary view to the right sidebar, opened from the command palette, with a default language chosen in the plugin options and a per-note override through a language key in the frontmatter. The README lists the supported languages and states that definitions and synonyms come from third-party APIs the user selects and permits, so the plugin makes no request to an API it has not been allowed to use. Experimental offline support for English and Chinese is recorded as downloaded on first use rather than bundled, because the data is roughly thirty-five megabytes.
