# mattcoleanderson/obsidian-dynamic-text-concealer

Obsidian plugin that conceals or replaces text in Live Preview and Reading mode according to user-defined regular expressions, where the capture groups of a pattern are what gets concealed. The README gives its main purpose as hiding verbose metadata that other plugins write into notes, using the curly braces of Obsidian to Anki cloze syntax as the example. It also points at a repository discussion collecting regular expressions contributed by users.
