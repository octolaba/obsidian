# remihoeppe/vault-notatypo

Vault - Not A Typo reads a Markdown word list kept inside the vault and registers every word with the operating system's spellchecker, so proper nouns such as character names, place names and invented words stop being flagged as errors. The README frames this against Obsidian's native fix of adding each word by right-click, which does not travel when the vault is moved or shared; keeping the list as a file in the vault lets it travel with it and be re-registered on any machine where the plugin is installed. Support is stated as desktop only, and the README records an accepted trade-off: because the operating system dictionary is a single per-user store, registered words are system-wide and stay visible to other applications while present.
