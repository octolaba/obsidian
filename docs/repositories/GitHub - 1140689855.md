# michaelAtDisney/ObsidianLinearYearMap

Obsidian plugin drawing a 12-month linear calendar that lays the whole year out horizontally to show note flow and clusters. Notes are plotted onto it from frontmatter dates once they carry a configurable trigger tag, single and multi-day events are supported, events can be colour-coded by category and toggled on or off, and clicking one opens its note. Events are created from a button in the calendar toolbar, a command, or by hand in any note, and the view refreshes automatically when event files change; the README lists drag and drop as planned rather than present.
