# usero2/obsidian-plugins-mememo

MeMemo captures short memos as individual Markdown files in a folder inside the vault, taking the first line as the file name — appending a counter when that name exists — and the remaining lines as the body, saved from a persistent composer by keyboard shortcut or button. Its view is two panels: a sidebar carrying a calendar and a tag filter that includes or excludes tags with a one-click reset, beside a scrollable memo feed. The README records hashtags extracted from the text when a memo is saved, drag and drop of operating-system or vault files into the composer, an image lightbox with keyboard navigation, video thumbnails taken from the first frame, checkboxes that write back to the file, and options to open the view at startup and pin its tab.
