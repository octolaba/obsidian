# denberek/obsidian-agent-fleet

Obsidian plugin for building and running AI agents from inside a vault, where every agent, skill, task and run log is a Markdown file. Each agent runs on either the Claude Code or the OpenAI Codex command-line backend, chosen per agent, and carries its own system prompt, skills, permissions, heartbeat schedule and memory, with chat, tasks and permission rules behaving the same on either backend. A Wiki Keeper mode turns a folder into a self-maintaining wiki: sources from an inbox or watched folders are ingested into an interlinked topics tree with cross-references, citations and a log, each topic page carrying a refreshable summary block, and a weekly lint reports orphans, contradictions and deduplication candidates. Slack, Telegram and Discord channels and MCP services can be attached to an agent.
