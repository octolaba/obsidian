# GitGorman/weekly-goal-tracker

Weekly Goal Tracker adds status-bar buttons that track daily or weekly goals, such as an exercise or reading target. A closed button shows an icon with the current and target values and changes colour once the goal is reached; left click opens it into a progress bar, right click adds one to the count and shift with right click subtracts one. Tasks can be attached to a goal with a command so that completing them adds progress, optionally worth several points. Settings choose per goal whether it resets daily or weekly, which frontmatter value is read and written, the icon and the target, and globally whether numbers are hidden on closed buttons and whether weekly data is stored in the Monday note or the weekly note, while daily goals always use the current daily note.
