# mrcnkobu/tascal

Tascal plans a day inside the daily note: it fetches events from ICS calendar feeds and renders them, together with the free gaps between them inside configured working hours, as a timeline under a managed heading. A second managed section holds date-scoped unscheduled tasks, which can be imported from backlog items in configured project directories. Manual events, recurrence rules defined in settings, optional notes created from templates for an event, and tracking of time spent on a scheduled event are all recorded. The README describes the daily note as rendered output: Tascal owns the content between its markers and preserves checkbox changes when the section is rebuilt.
