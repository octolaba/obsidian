# MrDanRave/Note-Doctor

This repository holds Note Doctor, an Obsidian plugin for managing tags by automatically tagging new notes and then reviewing them by tag. A configurable plaster tag, defaulting to a marker for incomplete notes, is applied to every note the moment it is created, and two commands add or remove that tag on the active note by hand. A review queue presents every note carrying the tag as a stack of cards navigated forward and back with progress shown as position out of total, offering keys to mark a note healed by removing the tag, to skip it, to open it for full review, or to close the queue; the README states that the software was vibe coded.
