# aoout/obsidian-epub-importer

Obsidian plugin that converts EPUB files into Markdown notes in a vault, so ebooks can be read, annotated and linked inside Obsidian. An import is run either by giving the absolute path of an EPUB file or by choosing among the files found in library paths configured in the settings, and the book becomes a folder of notes whose properties and asset paths follow configurable templates. The README records Windows as fully tested, Linux and macOS as lightly tested, and mobile as unsupported because of EPUB file handling, and it names companion plugins for organising the resulting library.
