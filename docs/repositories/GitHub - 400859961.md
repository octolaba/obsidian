# jglev/obsidian-carry-forward

Carry Forward copies text out of a note together with automatically added links back to the lines it was copied from, and can also copy a link or an embed link to the current line on its own. The README describes four primary commands, linking either every copied line or only the first, with variants that take the copied link's text from the current selection or from the clipboard. A regular expression set in the settings controls where the link is placed in each copied line, at its beginning, at its end, or replacing existing text. The README gives moving unfinished tasks forward between days' notes as the motivating use.
