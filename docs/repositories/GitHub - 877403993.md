# allenhutchison/obsidian-gemini

This repository holds Gemini Scribe, described upstream as an Obsidian plugin to interact with Google Gemini. The README describes model-assisted note-taking, writing and knowledge management that uses the user's own notes as context, and offers three provider paths chosen in the settings: Google Gemini in the cloud with an API key, a local Ollama installation needing no key, and OpenAI or an OpenAI-compatible server with the user's own key. A capability matrix in the repository's documentation records what each provider supports, and the release notes in the README describe agent runs, a plan mode and a reworked visual design.
