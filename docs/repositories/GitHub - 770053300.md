# mProjectsCode/obsidian-focus-theme

The Focus theme is described in its README as a dark-only theme for Obsidian, focusing on the important parts of your notes. The README states that JetBrains Mono may have to be added to Obsidian's font settings when custom fonts are used, and documents installation from the appearance settings with light themes only unchecked, or manually by placing manifest.json and theme.css in a Focus folder under the vault's themes directory. It records a GPL-3.0 license, and credits FireIsGood for readme tips and sailKite for CSS help and testing.
