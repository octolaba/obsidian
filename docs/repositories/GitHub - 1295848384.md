# mrrepac/voice-scribe

Voice Scribe records a voice note in Obsidian and transcribes it on the device with Whisper, so that after the one-time downloads it works offline without cloud services, API keys or subscriptions. Recording is started from a ribbon or status-bar microphone and no window opens: the text lands in the last focused input or in a new note depending on a setting, while the status bar shows a blinking microphone, a timer and a level meter. Existing audio files in the vault can be transcribed from their context menu into a transcript note, covering formats such as mp3, m4a, wav, ogg, flac and webm. No default hotkeys are set; the README documents commands for toggling recording, push-to-talk while a key is held, discarding a recording, and stopping then pressing Enter.
