# Lemon695/obsidian-lemon-vault-dashboard

Obsidian plugin that presents a dashboard of a vault's storage composition, file distribution and health, intended to surface large files and orphan attachments. Headline metrics give indexed size, file and folder counts with a breakdown into Markdown, images, attachments and other, and an optional desktop-only recursive disk scan includes unindexed files such as the configuration folder. Space usage is explored through a squarified treemap with drill-down and breadcrumbs, switchable to sunburst, donut or bar views and filterable by file type, with small items in crowded folders merged into an aggregate block. Further panels include a twelve-month cumulative size trend, and the README is also published in Simplified Chinese.
