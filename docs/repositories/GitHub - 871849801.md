# tabibyte/session-notes

Session Notes creates two kinds of throwaway note in Obsidian. A temporary note is deleted once the user switches away from it, while a session note persists for the session and is deleted when the Obsidian app closes. The README states that the hotkeys for creating either kind are customised from the Hotkeys section of the settings, and it documents manual installation from the release assets.
