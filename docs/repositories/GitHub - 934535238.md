# Lutu-gl/Obsidian-Minimal-Quiz

Minimal Quiz turns questions written directly in a Markdown file into a quiz, with no extra setup. The syntax is that a line ending in a question mark is the question and the following line is its answer; the plugin detects those pairs and presents them in quiz form when the ribbon icon or the command is used. The README states it was inspired by Simple Note Quiz and aims at an even more minimalistic design.
