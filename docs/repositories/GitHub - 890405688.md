# Saiki77/easy-tikz

Obsidian plugin providing a visual editor for TikZ and pgfplots charts, with a live preview that renders the chart inside the note and lets a rendered chart be clicked to be edited again. The README states that no TeX installation is needed for use inside the vault, while the same model exports pgfplots source for publication. It records a plugin id change in version 3.0, which requires the plugin folder to be renamed when migrating from 2.x, and describes installation from the community browser, through BRAT, or by hand.
