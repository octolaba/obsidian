# bkindler/papyrus-nox

Papyrus Nox is a dark-only Obsidian theme with an aged paper texture, earthy tones and hinted serifs. The texture is CSS-only, layering SVG noise from feTurbulence and feDiffuseLighting with fiber lines, aging stains and a deep vignette, so no images are required. Headings H1 to H6 take gold, teal, mauve, cyan, rose and taupe with a letterpress text-shadow, body text is DM Sans at 14px with 1.75 line-height inside a 550px page width, and the sidebar stays dark and flat without the paper texture. The README also lists dotted heading underlines, accessible focus indicators and print styles.
