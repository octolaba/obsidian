# ValleytheKnight/TTRPG-Rathgar-Gold-Theme

TTRPG - Rathgar Gold is a gold-and-parchment Obsidian theme built for running a tabletop campaign out of a vault, with dark and light mode both supported. Its stated purpose is turning a note full of Dataview queries into a dashboard: any note whose cssclasses value contains the word dashboard turns each top-level card callout into a uniform grid tile, with a full-width card variant, a content area that scrolls internally, and an optional full-bleed backdrop. Further opt-in cssclasses values switch the accent from gold to crimson with a session backdrop, or stretch the last card of an uneven grid to fill its row. The README states that the uneven option checks only the class name and not the actual card count.
