# n23eos/advanced_graph_view

Advanced Graph View replaces Obsidian's graph view for large vaults — the README names a range of five to fifty thousand notes — and presents the graph as an analysis tool rather than decoration. Any metric can be assigned to node size, color or glow, among them PageRank, open frequency, edit recency, note age, in and out links, file size, folder, tag and cluster; clusters come from Louvain community detection, and a local log of note opens is kept, exportable to CSV or erasable. Rendering runs on WebGL through Pixi.js with the force layout in a Web Worker. The plugin declares itself desktop only, requires Obsidian 1.13.0 or newer, and is installed through BRAT or by hand into a folder named graph-insight, its stable plugin id.
