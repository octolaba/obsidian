# DevM0nk3y/CyberGlow

CyberGlow is a cyberpunk-styled Obsidian theme with dark and light modes built around cyan (#00FFFF) and magenta (#FF00FF) accents. Code blocks use the Xcode Midnight colour scheme for both CodeMirror 6 and Prism.js, and the README states compatibility with the Code Styler plugin through dual selectors. A card layout can be toggled separately for content, the file browser and the actions panel, and three background intensity presets are offered: Abyss, Default and Elevated. The remaining customisation runs through the Style Settings plugin, which the README requires for its fourteen options across colours, editor and workspace.
