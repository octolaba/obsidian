# polyipseity/obsidian-modules

Modules loads JavaScript and related languages such as TypeScript as modules from the vault and from the Internet, on all platforms and without configuration. It resolves relative paths, vault paths, Markdown links, wikilinks and external links, can load Markdown files as code, supports modules used inside other modules, and handles both CommonJS and ES modules, with circular dependencies supported for the CommonJS form. Modules can be loaded at startup, the require name is configurable, source maps are added for debugging, and the README records support for plugins such as Dataview and Templater.
