# kmranrg/obsidian-handwriting-theme

This repository holds a handwriting theme for Obsidian built around the Kalam font, intended for notes that read like ink on paper. Its README records sky blue body text, pen-blue headings, purple bold text, support in both preview and live preview modes, and math and inline code styled to match. Installation is documented from the community themes browser or manually into a handwriting-theme folder, and the README also offers the theme as a CSS snippet applied per note through a cssclass property.
