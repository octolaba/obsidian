# PeanutUp/AgendaPane

Repository for AgendaPane, an Obsidian plugin that puts a compact monthly calendar and the selected day's task list in the sidebar. The README states that it creates no daily notes and modifies no existing Markdown files, keeping tasks in local per-vault storage with no account, telemetry or cloud service. Tasks carry optional start and end times, four priority levels, per-occurrence notes and recurrence — daily, weekdays, weekly, monthly or a custom interval — and are ordered by time and then priority until a day is reordered by hand.
