# waymakerlabs/obsidian-supabase-uploader

This plugin uploads images to a Supabase Storage bucket when they are pasted or dragged into an Obsidian note and replaces them with a Markdown image link to the uploaded file. The README records date-based storage paths built from year, month, day and a generated filename, a context-menu action that deletes an image from the bucket, and settings for the Supabase URL, the anon key and the bucket name, with hosted and self-hosted Supabase both supported. It also documents the bucket setup it expects: a public bucket plus storage policies granting the anonymous role insert, read and optionally delete.
