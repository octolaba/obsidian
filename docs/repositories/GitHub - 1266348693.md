# wanghuan9/obsidian-feishu-lark-cli-sync

Feishu Lark CLI Sync publishes Obsidian Markdown notes to Feishu and Lark cloud documents through the locally installed lark-cli, in one direction only, with the vault as the source and the remote document as the output. A single note is created or updated from a ribbon icon or the file context menu, a folder can be synced with its hierarchy recreated remotely, and links between synced files, including wikilinks, are rewritten into remote document references without changing the local files. Small edits are pushed as incremental block updates so the remote edit history survives, while large or structurally complex changes fall back to a full overwrite, and a note is bound to its document by a URL in frontmatter. Automatic syncing of bound notes can run after a save or from a Git pre-push hook, and the README requires lark-cli 1.0.53 or newer.
