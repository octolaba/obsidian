# SystemSculpt/obsidian-systemsculpt-ai

SystemSculpt AI adds an agent workspace, semantic vault search, transcription and visual workflows to Obsidian, activated with one license rather than provider keys, model catalogs or a local runtime. Its recorded capabilities include chatting with notes, documents, images and built-in vault tools, streamed reasoning, citations, tool activity and approvals, a portable semantic index for finding related notes, transcribing recorded or imported audio to Markdown or subtitle files, turning long audio and videos into structured summaries, and building workflows in a component called Studio. The README records that it runs on desktop and mobile while local command-line, terminal, dataset-adapter and media-processing nodes need the desktop app, and that the work is sent only to the project's own service, with provider credentials and model selection kept there.
