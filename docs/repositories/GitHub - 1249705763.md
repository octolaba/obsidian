# liwbcraft/ai-hub-manager

Obsidian plugin that gathers many web-based AI assistants into a single view, switched from a draggable tab bar along the top. More than twenty services ship by default, among them ChatGPT, DeepSeek, Kimi, Gemini and Grok; sites that can be embedded are shown inline, while those that cannot offer a button that opens them in a separate window. Any entry can be added, edited, deleted or reordered by dragging, each with its own name, icon and URL, and the current view or all views can be refreshed. Settings choose the assistant opened by default, hide the tab bar for more space, and switch the interface between Chinese and English.
