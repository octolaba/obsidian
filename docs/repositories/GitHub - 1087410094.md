# ChasKane/language-recall

Obsidian plugin providing Anki-style spaced repetition for language learning, forked from Obsidian Better Recall. Decks hold basic front and back cards that can be edited mid-review and searched across a deck, reviews are rated Again, Hard, Good or Easy with next-review estimates, and the card editor can translate the front into the back without an API key. An optional AI follow-up screen answers questions about a card through Gemini with Groq or OpenRouter as fallbacks, which does require the user's own key; the interval multiplier, system prompt and chat history length are configurable.
