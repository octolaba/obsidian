# brumik/obsidian-ollama-chat

Ollama Chat answers questions about the notes in a vault with a locally run Ollama model rather than a hosted service. Files are indexed on startup and when they are modified, and the README states that the indexing is done by a lightweight Python server run beside Ollama, with a branch that avoids that server described as slower and less developed. The URL of the model is set in the plugin settings.
