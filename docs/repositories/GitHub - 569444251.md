# Seraphli/obsidian-aggregator

Obsidian plugin that gathers information from files and renders a summary inside a note. Content is collected with a code block whose language is set to aggregator, which finds matches by regular expression and renders them through a template, optionally sorted by named fields and orders. The README acknowledges that writing the regular expression is difficult, points to separate argument and example documentation, and notes that the file indicator is a Handlebars template receiving the file and an index starting at one.
