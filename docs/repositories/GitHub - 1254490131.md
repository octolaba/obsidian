# lumargh/obsidian-date-list

Date List inserts single dates and formatted date lists in Obsidian through inline autocomplete and a live-preview wizard, described in the README as inspired by and much expanded from the original Natural Language Dates plugin. Typing a configurable trigger opens a predictive suggestion popup that resolves presets, weekday and month names, ISO, compact, slash and military date forms, and relative offsets in days, weeks, months or years. A doubled trigger opens a range picker that inserts a whole list of dates, such as this week, next month or the next 14 days, with each row showing the label, the date range and the number of dates. Inserted dates follow the configured format, prefix, postfix, wiki link and alias settings.
