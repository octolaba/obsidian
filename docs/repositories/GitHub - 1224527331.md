# 0xatrilla/AI-Sidebar

Obsidian plugin that adds an assistant panel to the right sidebar, opened from the ribbon, the command palette or an assigned hotkey. It is desktop-only because it can talk to local command-line agents such as Codex, Claude Code and opencode, and it also supports OpenAI-compatible API providers and OAuth-capable providers that publish desktop endpoints. Context is assembled from the active note, the selection, links, backlinks, Bases files and search matches and refreshes as notes are switched, while slash commands expose provider controls and vault-local agent skills. Vault writes follow one of three access modes, where read only blocks proposed writes, confirm actions shows them first, and full access applies valid ones directly; the README states there is no advertising and no telemetry.
