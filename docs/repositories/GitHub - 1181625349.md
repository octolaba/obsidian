# Gilgamesh-Tamarian/obsidian-link-iframe

Obsidian plugin that converts selected URLs into native iframe embeds. It identifies the URL's provider with a per-provider pattern, builds the provider's embed address, opens a preview modal where the live iframe can be inspected and an aspect ratio chosen, and then inserts the embed markup at the cursor, so the embed keeps rendering even if the plugin is disabled or removed. The README lists more than thirty supported sites, options for preloading, dark mode and showing the original link, and side actions that save images, media or exported Google Docs into the vault and export Quizlet flashcard sets to local Markdown notes.
