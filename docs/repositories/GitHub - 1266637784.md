# 5tukgpt/thunderegg

Thunderegg converts attachments in a vault, among them PDF, Word, Excel, PowerPoint, email and image files, into Markdown notes with YAML frontmatter, writing the result beside the source file. Conversion runs from a file or folder context menu, from the command palette for clipboard content, and a status bar indicator reports whether its engine is available; the README states the conversion happens entirely on the local Mac. A separate premium layer called the Refinery adds note maturity grades set in frontmatter, bonds derived from wikilinks, hub notes it calls condensers once their bond count passes a threshold, and folder-level groupings, shown in an info bar at the top of each note. The README records that the bond graph is built from Obsidian's own metadata cache and that macOS is required.
