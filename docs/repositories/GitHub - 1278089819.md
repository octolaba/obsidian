# DXShelley/obsidian-image-manager

This repository holds Note Image Manager, a desktop-only Obsidian plugin that keeps image import, naming, conversion, compression, light editing, gallery browsing and recovery in one controlled workflow. Pasted images are stored in a configurable, optionally note-scoped folder with names generated from variable templates, and sources given as a URL, a file address or a base64 data URI are imported into the vault and rewritten as local links in either wiki or standard Markdown form. External-image import, format conversion, compression, link cleanup and orphan-image cleanup run against the current note, the current folder or the whole vault, while context-menu actions copy, compress, convert, rotate, flip and crop an image and galleries offer filtering, sorting and grid or list views. The README records recovery transactions and a minimum Obsidian version of 1.12.4.
