# dnotes/obsidian-markdown-chords

No repository description is recorded, so this body is grounded in the README alone. This plugin adapts the markdown-it-chords library for Obsidian, and the README describes it as a barebones adaptation that points to the upstream demo for the full chord syntax. At the time of writing it provides only a Markdown code processor for fenced blocks marked as song or lyrics, where chord symbols written in brackets are placed above the words, with an option to apply chord formatting to all text named as a possible later extension. Installation is described through the BRAT community plugin, with submission for community-plugin review planned.
