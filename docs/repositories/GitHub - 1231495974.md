# Amdhj22/rbr.obsidian

This repository is the Obsidian port of the RBR color scheme, a three-accent palette using kerb red for what is active, RB yellow for what needs attention and chequer white for functions and methods, over a deep navy base. The README refers to the upstream style guide for the full design rules and documents manual installation into a vault themes folder or a build from source. It notes explicitly that the scheme is a fan tribute, not affiliated with or endorsed by Red Bull Racing or Red Bull GmbH.
