# tadashi-aikawa/obsidian-another-quick-switcher

TypeScript source for an Obsidian plugin the repository describes as another choice of Quick switcher. The README lists custom search commands with token-order-independent matching, non-fuzzy matching by default with optional fuzzy search, dialogs for header, backlink, link and in-file search, and a ripgrep-powered grep over note contents. It also records previewing notes without closing a dialog, multi-select with batch open or insert, moving a file to another folder, over a hundred dialog commands with customisable hotkeys, and a command palette that ranks results using query history and past selections.
