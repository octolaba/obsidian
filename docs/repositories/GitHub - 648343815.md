# koljapluemer/obsidian-the-queue

The Queue shows random notes from an Obsidian vault one at a time, opening a floating button bar in the corner that reacts to the current note and then draws another. The README records that a note can be configured to behave as a habit, a spaced-repetition flashcard, an iterative reading prompt or a to-do, and lists the uses the author has in mind, among them building a Zettelkasten gradually, low-friction iterative reading, habit tracking and working through to-do lists without being overwhelmed. The documentation covers a second, rewritten version with the older documentation kept in a separate file, and the author records that he is not actively working on the project while the plugin stays available.
