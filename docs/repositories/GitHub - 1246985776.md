# caezium/obsidian-spotify-control

Repository for Spotify Control, a plugin that drives Spotify playback from inside Obsidian. Its README describes a now-playing sidebar with album art, transport controls revealed on hover, a seek bar, volume and a device picker polling the service every few seconds, together with time-synced lyrics, a queue of upcoming tracks, a search palette, transport commands that can be bound to hotkeys, and capture of a track or its lyrics into a note. It states that Spotify's development mode requires the owner of the developer application to hold a Premium subscription, that playback control also requires Premium, and that a free account can use the display and capture features only when allowlisted on someone else's development application, which Spotify limits to five authorised users.
