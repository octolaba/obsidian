# miaoziguan/obsidian-bamboo-immortals

Chinese-themed personal goal management plugin whose README credits the OGAS cybernetics concept of Viktor Glushkov as its starting idea. It tracks multi-level numeric and progress goals with health scores and priorities, breaks them into daily tasks, and logs a nine-period daily timeline beside a structured review of checklists, diagnosis and action plans. Completed goals earn in-plugin bamboo coins that a shop redeems and advance a cultivation progression of ten stages and one hundred levels. The README also lists procedurally generated ambient bamboo sound with a sleep timer, an adjustable animated background, and dashboard panels that can be reordered or hidden.
