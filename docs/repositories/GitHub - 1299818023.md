# JerryWiltz/np-rf-analysis

nPort RF Analysis embeds radio-frequency and microwave network analysis in notes, rendering results as inline SVG line charts, Smith charts or tables. One block type runs verbatim JavaScript against the analysis API on demand, with run, stop and reset controls, each run starting in a fresh isolated worker, while declarative JSON blocks are retained for automatic rendering. The README records the initial public release as supporting the desktop application, and states that mobile support will be declared only after it has been tested there.
