# ASingularPhoton/device-theme-switcher

Device Theme Switcher applies a different Obsidian theme depending on whether the app is running on mobile or on desktop. Each platform is given its own theme and colour mode, either dark, light or matching the device theme, and the correct pair can optionally be applied when the plugin loads. A command to apply the platform-appropriate theme triggers the switch at any time.
