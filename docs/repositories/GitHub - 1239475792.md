# visua1hue/obsidian-markr

Markr adds trigger-based markers to list items and tasks in Obsidian, drawing character or icon badges and tinting the line in Live Preview and Reading View; the README names the List Callouts plugin as its inspiration. One to three characters on a list item act as the trigger, and each marker's label, Lucide icon, line colour and badge colour are configured independently, with priority markers built in and toggleable. Commands apply, remove and cycle markers without touching the trigger text, and the README states that no colours are hardcoded, so any theme works.
