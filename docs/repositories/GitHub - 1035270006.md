# z0lw/obsidian-right-click-tools

Extends the Obsidian file explorer context menu with date-oriented actions: creating a dated folder and note from a configurable Moment date format, auto-incrementing with `_1`, `_2` when the target exists, and creating today's daily note from a template. It can also move selected files and folders into a configured destination folder, and add ribbon buttons that create today's note in several configured folders under custom display names. The README states that AI title and tag generation moved out into a separate plugin, and documents the same feature set in Japanese.
