# jsmorabito/obsidian-workspaces-plus

Workspaces Plus expands Obsidian's core Workspaces plugin, which the README records as a prerequisite for it to work properly. It shows the active workspace in the status bar, where clicking the name opens a picker that can switch, delete, rename and create workspaces, and the same operations are available from a switcher modal opened by an assignable hotkey; further hotkeys open a specific workspace by name. Options cover keyboard shortcuts in the picker, a delete confirmation, and whether switching always saves first. The plugin also sets a data attribute carrying the workspace name on the document body, updated whenever a workspace loads, so that workspace-specific styling can key off it.
