# Lapis0x0/obsidian-yolo

YOLO is an AI assistant for Obsidian that combines chat, writing help, retrieval over the vault and agent orchestration in one plugin. Its recorded features include tool and MCP server use, subagents and background agents, web search, a memory system for long-term context, hybrid retrieval over vault notes, multi-window chat, tab completion, an in-editor quick ask, and a learning mode that turns source material into flashcards reviewed on an FSRS schedule. The README records OpenAI, Claude, Gemini, DeepSeek and other models as selectable, with an API key or OAuth configured in the settings, and warns that YOLO cannot coexist with the Smart Composer plugin, which must be disabled or removed first.
