# ZHOUTianye/obsidian-focus-timer

Focus Timer is a local timer for Obsidian that supports statistical analysis, a card view, and embedding its data in notes. Sessions run as a countdown, 25 minutes by default, or as a stopwatch, are named by an optional task label, and end as either completed or abandoned before being saved; commands start, complete or abandon a session, open the timer view, and launch preset quick timers. Recorded sessions are shown as filterable cards alongside statistics such as today's focus duration, completed task count, seven-day and monthly averages and the yearly total, with charts over 7, 14 or 30 days, the month or the year. A focus code block embeds those statistics and charts in a note, taking date and chart parameters that select a day and a range or metric.
