# QuintSmart/obsidian-course-module-loader

Course Module Loader downloads a zip file from a direct download URL and unzips it into a chosen folder of the vault, aimed at course attendees receiving materials. The target folder is picked from a searchable list in the settings, the command prompts for the URL, and subfolders described by the zip structure are created as needed. Files already present in the target folder are skipped rather than overwritten, and macOS metadata entries are ignored during extraction; the README states the plugin requires Obsidian 1.0.0 or newer.
