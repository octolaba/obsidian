# open-horizon-labs/obsidian-ics

Adds events from calendar or ICS feed URLs into the daily note on demand, taking the target date from the currently open daily note and working alongside the Daily Note or Periodic Notes plugins. Events can also be retrieved from Dataview or Templater through a getEvents method that accepts date strings, moment objects or Date objects. The README states that the output format is tuned for the Day Planner plugin, that local vdir calendar caches are supported as a cache, and that the project deliberately keeps its scope to importing calendar events into notes.
