# diegoeis/ghost-writer-manager-plugin

Synchronizes notes one way from Obsidian to a Ghost publication, converting markdown to Ghost's Lexical format including images. Ghost metadata is controlled through YAML frontmatter, posts can be scheduled with a publish-time property, and a paywall marker sets where the public preview ends. Sync runs debounced on file save and on a configurable interval, a sidebar shows an editorial calendar of the month's scheduled and published posts, and a status bar indicator reports sync state. The README states the Ghost Admin API key is kept in Obsidian's secure keychain and used with JWT authentication against the Admin API.
