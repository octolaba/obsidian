# ecustic/obsidian-file-color

The repository holds Obsidian File Color, a plugin that assigns colors to files and folders in the file explorer. Its README records that a color is set from the file's context menu, which opens a dialog listing the colors defined in a palette, and that the palette is extended in the plugin settings with a color picker and a name for each entry. Two options are recorded: cascading a folder's color to its children, which a child can override, and coloring the background instead of the text.
