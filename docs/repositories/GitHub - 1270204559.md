# skyue/obsidian-typecho-publisher

Typecho Publisher publishes Obsidian notes to a Typecho blog over XML-RPC, creating a new post or updating an existing one from a command or a context menu. Frontmatter keys are mapped to Typecho fields through a configurable mapping with strict property type validation, a creation date field is mandatory, and a slug missing from the frontmatter is generated from the publish date with a configurable format string. Images are uploaded either to Typecho's built-in media library or to Cloudflare R2, with an upload cache that avoids sending the same image twice. The plugin can convert wikilinks pointing at other published notes into blog URLs from a template while turning links to unpublished notes into plain text, can strip sections from named headings onward, and follows the Obsidian language in English or Simplified Chinese.
