# mderazon/obsidian-base-board

Base Board adds an interactive, property-driven Kanban board view for Obsidian Bases, generating columns from any frontmatter property. Cards can be dragged between columns to update their properties, reordered inside a column, renamed inline, and opened into a full Obsidian editor in a floating modal. The README further records metadata chips on cards, color-coded tag chips with a filter bar, hover previews through the Page preview core plugin, per-column work-in-progress limits and collapsible columns.
