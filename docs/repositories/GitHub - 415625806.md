# kometenstaub/linked-data-helper

Linked Data Helper is described as generating the data required by the Linked Data Vocabularies plugin. Its README says the settings carry a step-by-step guide for each implemented dataset, that Library of Congress Subject Headings are currently supported with other linked data planned, and that the plugin has been updated to work with the Library of Congress bulk exports. Generated files go by default into a subfolder of the attachments folder, with an alternative output path entered in the settings when that is not possible. The README notes that the plugin can be disabled after the conversion until the data needs updating or another dataset is added.
