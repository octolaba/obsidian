# Justin-Arnold/Journalyst

The README describes an Obsidian plugin for keeping track of daily journaling: one folder in the vault is designated as the journal folder, and each folder inside it becomes its own journal, so separate journals for personal life, work or sleep tracking can run side by side. Every entry is a Markdown file named by its date in year-month-day form, and the plugin offers an interface for creating entries and for seeing which days of the current month already have one in a given journal. The README calls the plugin early-stage and lists commands for creating the current day's entry, template support and configurable filename formats among its planned features.
