# GOODJINC/obsidian-view-mode-lock

View Mode Lock pins Obsidian notes to Reading, Live Preview or Source mode. Every Markdown note can be locked to Reading view globally, and rules can be defined by folder, tag or property value, with folder rules covering subfolders, the first matching rule winning, and individual notes able to override them. Desktop, tablet and phone are configured independently, each set to follow the rules, always use Reading view, or disable locking. The README states that the plugin reads Obsidian's metadata cache to stay lightweight, and that its interface uses Korean when Obsidian's app language is Korean and English otherwise.
