# aaachen/IMDb-Obsidian

Syncs a public IMDb list, watchlist or ratings export into Obsidian notes by downloading and parsing the list at its URL. Note structure comes entirely from a mustache template the user supplies, with variables including the IMDb id, title, description, rating, runtime, year, release date, genres and vote count. An optional OMDb API key adds posters, writers and plot descriptions to the fetched data; the README recommends it and links basic and Templater-based example templates.
