# helloworldkr/Askify-Obsidian-Sync

Obsidian plugin that syncs between Obsidian and the Askify service, with support the README describes as multi-language, cross-platform, and covering tags and date. Setup copies a sync key from the Askify website into the plugin settings, after which syncing is started from the plugin's entry in the left sidebar. The README states the token is saved locally inside the vault's Obsidian plugins folder and warns against sharing that folder, since doing so would expose the token.
