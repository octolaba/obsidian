# Saiki77/hub-sidebar

Hub Sidebar restyles Obsidian's right sidebar to resemble Obsidian Publish, wrapping the local graph and the backlinks and outgoing-links panes in a rounded borderless card with Publish-style section headings and a plain "On this page" outline whose heading depth is configurable. Its central addition is a switcher on the graph card: buttons change it in place between the local graph, incoming links and outgoing links. Further options remove the sidebar's hairline borders, keep the editor column centred while the sidebar is open, and toggle the right sidebar from a command or a status-bar button. The plugin also puts a fuzzy-search box on the empty new-tab page and can place configurable icon buttons in a note's header that insert a bound Templater template.
