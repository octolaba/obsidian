# viggomeesters/obsidian-xlsx-viewer

Opens `.xlsx` files in a dedicated read-only Obsidian view showing one sheet at a time behind sheet tabs, displaying cell values and cached formatted formula results without evaluating any formula. Rows are filtered by searching across cells, column letters and row numbers stay pinned while scrolling, and the view reports sheet count, active sheet, row and column counts and whether the render cap applied. The README caps rendering at the first 10,000 rows, counts the remainder in a warning area, and gives plain error states for empty sheets and malformed workbooks. It states that this is a viewer rather than a spreadsheet editor, without editing, formatting, charts, merged-cell layout, pivot tables, comments or macros, and that it makes no network requests.
