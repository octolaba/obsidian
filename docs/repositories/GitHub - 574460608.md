# adriandersen/obsidian-fuzzytag

The repository holds Fuzzytag, an Obsidian plugin that suggests frontmatter tags with a fuzzy search. Its README records it as a separate plugin rather than a change to the frontmatter tag suggestion plugin it is based on, precisely because fuzzy matching alters that plugin's behaviour and not everyone would want it. It also records a known issue: the highlighting of suggestions is implemented in a way that can break for tags containing special characters.
