# gaetanmuck/obsidian-flashcard-learning

Builds flashcard reviews out of cards written across a user's own notes. A review is measured by progress rather than by time, so several reviews can be run in one day, and a review that is interrupted resumes where it stopped even after Obsidian is closed. Each card can carry a description of what the answer is expected to be, which the README motivates with a card whose front does not say which of several facts is asked for. Cards that are answered correctly are shown less often, cards that are not are shown every time, and new cards can be added after each review.
