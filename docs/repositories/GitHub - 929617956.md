# luisbs/obsidian-attachments-cache

Obsidian plugin that stores remote attachments locally inside the vault and serves the local copy while the note is rendered. The note is not modified by default, so its remote URLs keep working outside the vault, while an archive option rewrites the link to the local file instead. During rendering the plugin decides whether an image should be cached, downloads it into a vault folder when it is not, and points the element at the cached file; cached files can be deleted at any time to free disk space. Caching is governed by whitelists and blacklists over vault paths and remote URLs with per-note and per-remote overrides, an API is exposed for other plugins, and the README lists the image, audio, video and PDF formats covered.
