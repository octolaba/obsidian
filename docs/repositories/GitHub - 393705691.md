# onlyafly/number-headings-obsidian

Number Headings adds outline-style numbers to the headings of a document, run from the command palette or from hotkeys bound to its commands. Its settings page carries the numbering options, and the README's version history records per-document control through frontmatter, including a setting that skips selected headings and an option that turns automatic numbering off for a specific file. Other recorded options include Roman numerals, a right parenthesis as the separator, and a starting number other than one.
