# Staaaaaaaaaan/obsidian-custom-commands

Custom Commands lets a user define their own commands, which then appear in the command palette and can be bound to hotkeys. Four types are supported: opening an existing note at a path, creating a note at a path with an optional template, inserting a text snippet at the cursor, and running a comma-separated sequence of other commands by name. Paths, templates and snippets accept date and time placeholders, and a command that opens a note can be told to use the current tab, a new tab or a new window.
