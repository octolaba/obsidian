# ErrorTzy/obsidian-pandoc-extended-markdown

This plugin renders Pandoc extended Markdown in Obsidian's Live Preview and Reading mode while leaving the original Markdown source intact. The README lists the supported syntax: superscripts and subscripts, fancy alphabetic, Roman and auto-numbered lists, distinct unordered list markers, definition lists, example lists with local references, fenced divs with titles and numbering, and custom label lists. It also describes list editing helpers bound to Enter and Tab, and a sidebar list panel for navigating labels, examples and footnotes.
