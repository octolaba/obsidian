# djmango/obsidian-transcription

Transcription creates text transcriptions from audio and video files linked in a note, using Whisper speech recognition. The listed features are support for a wide range of formats through ffmpeg, a local transcription engine, start and end timestamps for each line of the transcription, transcribing several files at once, and transcribing in the background.
