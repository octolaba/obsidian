# twofive-labs/target-word-count

Target Word Count disables editing in Obsidian until a target number of new words has been added. The README records three commands: one starts tracking, after which content cannot be deleted until the target is met, one resets progress to zero while keeping the target setting, and one halts the plugin and allows editing again. It states that progress and the editing restriction are shared across all documents.
