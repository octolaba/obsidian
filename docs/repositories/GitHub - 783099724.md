# HaloGamer33/Obsidian-Fuzzy-Note-Creator

This repository holds Fuzzy Note Creator, described upstream as a plugin for quickly creating notes with the help of a fuzzy finder, now with templates. The README says the command palette offers variants that open the new note in a new tab, the current tab, a new window, or a horizontal or vertical split, each with a bulk version that keeps the dialogue open so several notes can be created in one folder. The destination folder is chosen through a fuzzy path input with tab completion over existing folders, after which the note title is entered.
