# Jaycelu/Smart-Review

Repository for Smart Review, a review centre that reads note properties from YAML frontmatter. Its README describes building queues from a next-review property, grouping notes into overdue, today, the next seven days, future and invalid dates, showing today and overdue counts in the status bar, four rating buttons whose calculated interval is previewed on the button itself, and adaptive scheduling whose four rating rules can be tuned. Review metadata is written back into the note's frontmatter and events are appended to a log file, the interface is available in English and Simplified Chinese, and the recorded description adds pausing and resuming notes and optional evidence-grounded exams using models the user configures.
