# HEmile/obsidian-search-on-internet

Search on Internet adds context-menu entries that search selected text, a note's title, an internal link or an external link on external websites, with Google and Wikipedia configured by default. Searches open in an iframe inside Obsidian, or in the default browser when that option is chosen. Each site is defined by a name, a URL in which a title placeholder is replaced by the query, and an optional tag list that limits which notes show the entry, so a site can be offered only on notes carrying particular tags. The README opens with a warning that the right-click menu is broken in the latest Obsidian release at the time of writing, so the plugin will not work as expected.
