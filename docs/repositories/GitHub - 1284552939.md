# Sparky-code/para-tree

PARA-Tree draws a vault organised by the PARA method the way a commit graph draws a repository: areas are long-lived trunks, projects branch off their area and merge back when their status is done, and resources filed under a project ride that branch. Cross-links declared with a contributes-to field appear as dashed merges, colour encodes area identity and work status, and each row shows when it was last edited. The view is read-only and live, with a sidebar navigator, the graph and an inspector; the README states that it is desktop-only for now, with mobile support planned.
