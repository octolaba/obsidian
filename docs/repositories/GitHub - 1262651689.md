# viggomeesters/obsidian-git-viewer

Shows Git status and history for the vault in a sidebar with compact changes and history tabs, grouping files into staged, changed, untracked, deleted, renamed and conflicted, and opening files inside Obsidian when they belong to the vault. The history tab lists the latest fifty commits with short hash, subject, author and timestamp, and read-only commit details with the full hash, message body and changed files. Its single write action is committing explicitly selected files with a required message, performed through a temporary Git index so unrelated staged or unstaged files are not swept in. The README states there is deliberately no pull, push, fetch, merge, rebase, branch management, staging, discard or automatic sync, and that the plugin code makes no network requests.
