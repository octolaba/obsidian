# Qwyntex/doubleshift

Obsidian plugin that runs a command when the Shift key is pressed twice; by default it opens the command palette, and the target command is configurable. Several bindings can be defined at once, and the plugin distinguishes left from right modifiers, so left and right Shift or Alt can trigger different commands. The README states that every available command works, including commands added by other plugins, and that a command missing from its picker is usually fixed by disabling and re-enabling the plugin.
