# remotely-save/crypt-it

Crypt It generates an encrypted copy of a file from the file's context menu, using a password supplied by the user. The recorded README states that the plugin follows the rclone-crypt format and that it does not store the password, so a forgotten password cannot be recovered; both are the project's own statements and neither the format nor the claim was verified here.
