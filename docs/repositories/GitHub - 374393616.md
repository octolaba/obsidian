# ozntel/file-tree-alternative

Replaces the single-pane file explorer with separate views for folders and for files. A combined view shows folders and the file list at the same time, or the two can be kept apart, and the split can be horizontal or vertical. The folder pane can show the number of notes or of all files under each folder, or no count at all, and a folder can be focused and unfocused by double-clicking its name or through its context menu. A ribbon icon rebuilds the view if it was closed.
