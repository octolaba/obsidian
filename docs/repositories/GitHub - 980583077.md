# nitishkhurana/obsidian-move-files-plugin

Move Files Plugin is an Obsidian plugin that gathers the files a note links to into a folder of their own. Running the command Move linked files and update links creates a folder named after the note with a files suffix, moves the linked attachments such as png, pdf and jpg into it, and rewrites the links in the note. Two settings control whether the note itself is moved into that folder as well, and whether the folder is created beside the note, preserving the folder structure, or in the vault root. The README suggests pairing it with a paste-image-rename plugin and credits an image collector plugin as inspiration.
