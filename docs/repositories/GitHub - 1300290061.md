# Kamijoucen/obsidian-openyolo

Desktop-only Obsidian plugin that gives an AI note assistant a sidebar chat while containing no model or agent of its own: it spawns opencode as a subprocess over the Agent Client Protocol and leaves model access, tool execution, session history and memory to it. The chat streams output with collapsible reasoning, tool-call cards carrying diff previews for edits, and a plan panel; the open note is attached automatically, and further vault notes, external text files and images can be added. Tool permission requests appear as cards to allow once, always allow or reject, with an optional mode that approves everything. The README states that file access goes through the vault adapter and rejects paths that are not lexically inside the vault root, calling this a path boundary rather than a sandbox, since symlinks may resolve outside it.
