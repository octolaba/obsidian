# michaeladams/obsidian-text-progress-bar

Text Progress Bars renders text-based and emoji progress bars in Obsidian notes from a dedicated code block. The README shows a minimal bar carrying a label, the amount complete and the total, with everything else taken from the plugin settings, and a fully specified form that adds the fill character, the empty character, a prefix, a suffix and a length. A transition value supplies one or more characters for partial completion, decimal amounts drive that partial state, and several labels in one block produce a group of bars.
