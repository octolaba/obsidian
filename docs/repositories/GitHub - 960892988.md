# ohyoungpark/obsidian-sonkil

Sonkil brings Emacs-style text operations to the Obsidian editor, its name given in the README as a Korean word for a helping hand with care. It keeps a kill ring holding up to 120 entries, syncs cut and copied text with the system clipboard, kills lines from several cursor positions into a single paragraph, yanks at several cursors at once, highlights the region between the mark and the cursor with a background color, and reports the current operation in the status bar. The README records that default hotkeys were removed in line with Obsidian's plugin guidelines, to avoid conflicts with existing configurations and cross-platform problems, and lists the original combinations as suggestions to configure by hand.
