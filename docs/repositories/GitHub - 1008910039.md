# wanglin2/obsidian-simplemindmap

Repository for SimpleMindMap, the Obsidian plugin edition of the SimpleMindMap mind-map project, built on the author's open-source mind-map JavaScript library. The README is written mainly in Chinese, offers the interface in Simplified Chinese, Traditional Chinese, English and Vietnamese, and points to a separately sold professional edition and a standalone desktop client whose licences do not carry over between them. It records that the plugin is desktop-first and much less complete on mobile, and lists editing in a separate window and full theme-colour synchronisation of some interface components as current limitations.
