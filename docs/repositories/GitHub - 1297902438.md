# turingexmachina/obsidian-media-sidecar-tools

Media Sidecar Tools creates a Markdown sidecar note for an attachment when it is control-clicked or command-clicked in the navigation pane, then hides the attachment itself from the file explorer so only the note remains visible. The README explains the reasoning: media files cannot hold Obsidian properties and so are invisible to features that read note metadata, and screenshots, recordings and scans are usually viewed through the note that embeds them rather than opened directly. Any attachment sharing a name with a Markdown note in the same folder is hidden automatically, and renaming, moving, creating or deleting either one updates the navigation immediately.
