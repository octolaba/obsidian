# nagi1999a/obsidian-focus-plugin

The repository holds Focus and Highlight, an Obsidian plugin that narrows attention to one heading and its children in reading mode when they are clicked. Its README records that from version 1.2.0 a single paragraph can be focused instead, by changing a content behaviour setting, and that clicking a child of a heading also focuses it. It also records a focus sensitivity setting that can be lowered so selecting text does not change what is focused.
