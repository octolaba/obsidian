# radiantmatter/remote-vault-sync

Backs up and synchronises an Obsidian vault to an S3 bucket under git version control, driving native `git` through child processes and copying the `.git` directory to and from S3, with git LFS holding large files. Ribbon buttons and commands push, pull and restore, and modals show commit history, a diff of changes, and merge conflict resolution, while a status bar item reports synced, uncommitted, syncing or error state. It requires `git` and `git-lfs` on the system and AWS credentials with read and write access to the bucket, connecting to an existing repository in the bucket or initialising a new one.
