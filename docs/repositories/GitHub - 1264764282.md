# ghh-l-djl/obsidian-habit-dashboard

Habit Dashboard is an Obsidian plugin that gathers daily events, data logs, tasks, check-ins, moments, monthly plans and quick links into one editable page on desktop and mobile. The README records a month mini-calendar selecting the focused date beside an events column with a weekly view and archiving, where each event can be backed by an auto-created Markdown note, marked started, or postponed to the next day. It further records a standalone countdown timer that survives restarting Obsidian, a data log for daily metrics with monthly history and archiving, task boxes whose subtask checklist stays in two-way sync with a linked note, check-in buttons with per-habit cycles and a monthly streak view, timestamped daily moments, a monthly planner with a yearly view, and quick links added by hovering the blank area of a column.
