# Yima-Gu/obsidian-lecture-lens

Obsidian plugin aimed at students that uses multimodal large language models to turn lecture PDFs, slides and whiteboard photos into structured Markdown notes. It converts course PDFs in batches keeping formulas and headings, performs OCR on pasted screenshots, and answers questions in a chat sidebar with optional local retrieval over a course folder and clickable wiki-link citations back to the source. Providers named in the README include DeepSeek, Kimi, OpenAI and Gemini, supplied by the user under a bring-your-own-key model; the document is written in parallel English and Chinese.
