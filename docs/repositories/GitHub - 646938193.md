# afazio1/obsidian-markdown-blogger

Markdown Blogger pushes Markdown notes from Obsidian into a local blog, portfolio or static site project, and works with any framework configured to render Markdown pages, naming Astro and Next as examples. Its commands push the current note into the configured project folder or into a custom path chosen through a folder navigator, and pull content from a project file back into the note. The README states that the local project folder path must be absolute and that a note is not pushed when that path is invalid or does not exist.
