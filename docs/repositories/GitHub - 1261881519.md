# lowshot31/note-pilot

Note Pilot adds a panel that asks a configured model about the active note or the selected text, which the README presents as keeping the prompt to what the user chose instead of sending a whole vault. Write requests come back as structured actions such as creating, appending to or modifying notes, and the README states that they are applied only after the user reviews and confirms them. Recorded connections include a local proxy for a chat subscription and several API-key providers as well as a local runner or any custom OpenAI-compatible endpoint, and the interface labels can be Korean or English.
