# especialkim/obsidian-synaptic-view

Synaptic View adds a configurable dashboard view to Obsidian that opens from the command palette and can optionally replace the new-tab page. Its action bar carries three fixed buttons for creating a file, opening the quick switcher and reaching the plugin settings, alongside user-defined quick-access buttons of four kinds: a note or canvas, a web page opened inside Obsidian, a periodic note for the day, week or month that is created when missing, and, per the recorded description, calendar navigation. The README frames the plugin as configuration in place of a hand-maintained homepage note built from Dataview queries, internal links and CSS snippets.
