# xauravww/obsidian-encrypted-datasafe-notes

Encrypted Datasafe Notes encrypts Markdown, Canvas and Excalidraw files on disk with AES, either across the whole vault or restricted to one folder, and individual files can also be encrypted manually outside that folder. The README describes it as an enhanced fork of obsidian-protected-note and states that a master password is set in the settings, that files can lock automatically when the Obsidian window loses focus, and that the file explorer and status bar mark which files are locked. It also names a panic hotkey that locks the vault and wipes memory at once, a banner on locked notes offering decryption or emergency recovery, and a password prompt that can be dismissed to keep browsing unencrypted notes.
