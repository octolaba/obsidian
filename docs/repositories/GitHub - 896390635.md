# SmallZombie/link-opening-restore

Link Opener is described as restoring Obsidian's link opening behaviour, and its README, offered in English and simplified Chinese, specifies that behaviour as control plus left click in edit mode. It lists three internal-link shortcuts: control and left click opens the link in the current tab, adding shift opens it in a new tab, and adding shift and alt opens it in a new window.
