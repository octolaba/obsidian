# DavidMJChoi/obsidian-meow

obsidian-meow sends selected text or a typed question to an OpenAI-compatible chat completions endpoint, DeepSeek by default and configurable to any other. A polish command returns the rewritten selection in a diff preview modal with word-level highlighting, additions in green and removals struck through in red, to be accepted or rejected with a click; a question command opens a small modal that answers inline, optionally combined with the selected text and optionally in a playful persona. The README states what leaves the vault — the selected or typed text plus a system prompt, sent only to the configured endpoint — records the API key as stored in plain text in the vault's local plugin data, and says there is no telemetry and no request until a command is run.
