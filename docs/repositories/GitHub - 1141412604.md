# philfreo/obsidian-granola-plugin

Granola Meetings Simple Sync is an Obsidian plugin that syncs Granola meeting notes, AI summaries and transcripts into the vault. The README records authentication through Granola's official MCP API using a browser OAuth flow set up once from plugin settings, with more than one Granola account able to sync into the same folder. Recorded behaviour includes automatic syncing at intervals from one minute to twelve hours, a customisable output template, deduplication by meeting ID, an option to skip existing notes so local edits survive, linking attendees to existing notes by email, and optional inclusion of full transcripts. Settings record a time range, a sync frequency and a filter limiting the sync to the user's own meetings.
