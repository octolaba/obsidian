# kdnk/obsidian-hierarchy

This plugin visualizes the folder hierarchy of Markdown files inside the Obsidian editor, showing the subdirectory structure of the current file in a collapsible view. No repository description is recorded, so this body rests on the README alone. Separate settings decide whether that hierarchy appears below the editor, in the tab headers and in the backlinks panel, and whether tab and backlink titles display the full path or only the file name.
