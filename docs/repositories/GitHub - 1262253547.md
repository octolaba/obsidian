# viggomeesters/obsidian-toml-ini-viewer

TOML INI Viewer opens files with the TOML and INI extensions from the Obsidian file explorer as a read-only configuration tree, with sections, keys, values, type labels and filtering, alongside a source view carrying line numbers and light highlighting. TOML parse errors are reported without blocking access to the raw source, and the INI side reports duplicate keys, duplicate sections and malformed lines as warnings rather than hiding them. Rendered nodes are capped so generated or oversized files keep the interface responsive, and the file is refreshed after external changes. The README states that the plugin never writes to disk, arguing that comments, ordering and whitespace matter in these formats, and that TOML parsing uses a small external parser while INI uses a deliberately conservative local one.
