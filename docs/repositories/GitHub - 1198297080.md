# tinswangtao-web/little-milestones

Obsidian plugin for rating daily behaviours and logging life, aimed primarily at helping children build habits. Scoring categories and items are user-defined and can carry positive or negative values, with daily and monthly statistics and progress tracked over time, while a diary module offers several field types, custom placeholders and templates, Markdown and file attachments. Food, meals, activity and exercise are tracked through custom categories, and reports are generated with visualizations and exported to YAML described as structured data for language-model analysis. The README states it works on desktop and mobile with a responsive, touch-friendly interface.
