# malweis/obsidian-discord-export

Discord Export prepares a note for posting on Discord by splitting it at paragraph boundaries into numbered chunks that fit the character limit, each with its own copy button in a modal opened from a command. The limit toggles between the standard 2000 and the Nitro 4000 characters, an indent mode converts line jumps into indentation that Discord handles, and a splitter mode only splits without adding indentation. Content wrapped in curly braces is stripped from the output entirely, and a marker line forces a chunk split at that point regardless of how full the current chunk is. The README states it is mainly a personal tool, written to automate splitting long notes by hand.
