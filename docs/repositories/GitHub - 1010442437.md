# awfrok/obsidian-plugin-last-edit-location

Obsidian plugin that moves the cursor to the last edit location when a note is opened, once per note. It keys each note on a unique identifier that is either a plugin-generated UUID written into the frontmatter, an existing frontmatter field chosen by the user, or the note's path in the vault, and stores the last edited line and character against it. Settings select the folders in which the plugin operates and a delay before the cursor position is restored.
