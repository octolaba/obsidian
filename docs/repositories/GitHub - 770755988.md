# decaf-dev/obsidian-vault-explorer

Vault Explorer uses frontmatter properties to explore and organise the files of an Obsidian vault, opened from a compass button in the sidebar. Its README states three problems it sets out to solve: filtering by groups of frontmatter properties and other file data, displaying those properties in meaningful visual layouts, and creating a social-media-like experience from personal data alone. The screenshots section names grid, list, table and feed views together with custom, sort and search filters. The README describes the plugin as a work in progress, points to a separate documentation website for detail, and carries its own sections on network use, contributing, support and licence.
