# profesr-chaos/obsidian-checklist-progress-bar

This repository holds Checklist Progress Bar, an Obsidian plugin that displays a live progress bar above a checklist. A progress callout placed directly before the list is filled in with a bar, the checked count and a percentage, updating as items are ticked; items are counted from that line down to the next progress bar or the end of the file. The README states that it needs no configuration, updates on every keystroke, supports nested items at any indentation and several bars per note, and styles the callout for both dark and light themes.
