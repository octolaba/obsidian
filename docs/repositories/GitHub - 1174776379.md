# lylo/obsidian-pagecord

This plugin publishes notes from Obsidian to a Pagecord blog. According to its README a command creates or updates a post as published or as a draft, tracking an existing post through frontmatter, uploads embedded images automatically, and reads title, slug, tags and further post metadata from YAML frontmatter. Several Pagecord blogs can be configured, each with its own name and API key, and each configured blog contributes its own pair of publish commands; deleting a connection only removes it from the Obsidian settings and leaves the blog itself alone.
