# mnaoumov/obsidian-advanced-exclude

Advanced Exclude reworks Obsidian's Excluded files setting around gitignore syntax, because excluded files still appear in the Files pane and in backlinks. Ignore patterns can be configured in the plugin, edited by hand in an .obsidianignore file, taken from an existing .gitignore, or reused from the built-in Excluded files setting in string or regexp form. A Hide empty folders setting additionally hides a folder whose files are all excluded, cascading up through parents whose whole subtree became empty while leaving genuinely empty folders visible. The README warns that making Obsidian behave as if ignored files did not exist may affect features such as Obsidian Sync.
