# starhunt/stargate

Star Gate clips web pages from inside Obsidian through an embedded multi-tab browser that holds pinned and temporary tabs. The README lists AI analysis templates for briefings, concept notes, insights, knowledge maps and deep analysis, a quick-save command for raw page content and selected text, YouTube metadata extraction, and settings for providers, models, note templates and pinned sites. It states that analysis uses only the providers the user configures, that no telemetry is collected, and that the plugin is desktop-only because it relies on desktop-only APIs.
