# PKM-er/Obsidian-Surfing

Surfing renders web pages inside Obsidian using the tabs introduced in version 1.0, a web view whose implementation the README credits to Ellpeck's Custom Frames plugin. It intercepts Obsidian's file, http and https protocols so that links — including local HTML and other local resources — open in the app rather than an external browser, and it adds searching selected editor text or text inside an open page with the default search engine. Further recorded features are copying links that point at a highlight, opening a URL in Obsidian from a browser bookmarklet, and an experimental copy of a video timestamp that currently covers one site and is noted as unreliable.
