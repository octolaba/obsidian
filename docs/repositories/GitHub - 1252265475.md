# ABCDLabs/isHistory-CMS

isHistory CMS is a control panel inside Obsidian for blog posts and research notes that are published to an Astro website. It validates each post against the information the site needs and reports what is missing, and it shows a dashboard of all posts with sorting, search and filters, a quick-validate sidebar for the post being edited, a status bar summary and right-click actions on files. A pre-flight action marks a draft as ready for deployment in frontmatter only, one post at a time or in bulk, with the deployment itself left to Git sync. The README also describes a track system grouping posts as articles, profiles or events, a responsive dashboard for Obsidian mobile, ARIA labels and keyboard navigation, and settings that merge on upgrade.
