# justanotherjurastudent/highlight-active-folder-section

This plugin highlights the container of the folder that holds the currently opened note in the file explorer, as a visual aid for seeing which folder the active note is in. The background colour of that container and the colour of the folder title are customizable, with further styles for the title and for the file names inside it including hover and drag effects, and the root folder container can be highlighted with its own colours. An autoscroll option moves the file explorer to the active note when notes are switched or opened, and auto-collapse closes every folder except the direct path to the active file. The README asks that the file explorer's auto-reveal current file button be turned on.
