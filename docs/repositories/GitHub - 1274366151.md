# KKenny0/obsidian-kami

KKenny0/obsidian-kami holds Kami Reader, an unofficial Obsidian adaptation of the typographic system of tw93/kami: a warm parchment surface, an ink-blue accent, a serif-led hierarchy and warm-grey neutrals, applied without changing Obsidian's navigation model. The README states plainly that the project is not affiliated with or endorsed by tw93 and that its visual design tokens trace to the original MIT-licensed kami project. It records the theme as published in the Obsidian theme gallery at release 0.2.0, and notes that dark mode deliberately keeps a heavier bold weight for screen readability as an exception rather than a claim of exact conformance.
