# compadrejunior/attachments-library

An Obsidian plugin that maintains a parallel library of metadata notes for the files in the vault's attachments folder, one sidecar note per attachment, without modifying the attachments themselves. A sidecar is created as soon as a file is dropped in, subfolder structure is mirrored into the library folder, renames and deletions are followed automatically, and a backfill command indexes pre-existing files without overwriting notes that already exist. Metadata is read from PDF files locally — title, author, subject and keywords — and can optionally be enriched by DOI and ISBN lookups against CrossRef and OpenLibrary, which need no API key. The plugin also writes a Bases file so the whole library can be browsed, sorted and filtered in a table-like view.
