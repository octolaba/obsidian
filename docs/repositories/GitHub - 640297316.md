# cadrianxyz/obsidian-auto-anki

Obsidian plugin that generates Anki flashcards from note content using an OpenAI GPT model. Two commands export the current file or the highlighted text, sending it to the model to produce questions and answers, and the number of alternatives generated for each can be specified. It requires an OpenAI account and API key, a local Anki installation and the Anki Connect add-on, whose port is set in the plugin settings. The README states the plugin only works on desktop.
