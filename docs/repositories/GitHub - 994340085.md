# kvh03/obsidian-scratchpad

Scratchpad opens a sidebar pane with two tabs for quick capture while working across notes: a Text tab with an input area for short notes, and a Canvas tab for freehand drawing with an adjustable brush colour and size and a control to clear the canvas. A Copy to Scratchpad entry in the context menu of any Markdown note appends the selected text to the Text tab. A Save button writes the current text and drawing to disk, and the README warns that the content otherwise lives in memory and is lost when the app closes, and that the plugin does not support multiple notes.
