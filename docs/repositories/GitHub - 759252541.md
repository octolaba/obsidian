# decaf-dev/obsidian-view-count

View Count tracks how often each file in an Obsidian vault is opened, on desktop and mobile. On desktop the count for the current file appears in the status bar, and a sidebar view opened from an eye icon or a command lists both the most viewed notes and the notes with the highest trending weight, each in descending order. The README documents two view-count types and a setting that syncs the count into a note's frontmatter, which is what makes the count visible on mobile and queryable from the Dataview plugin. Further sections cover an API, the remaining settings and the licence.
