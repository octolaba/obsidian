# degun-osint/obsidian-rhino-pdf-export

Exports Markdown notes to styled PDFs using configurable themes that carry colors, a logo, header and footer, watermark, PDF bookmarks and a legal notice. Configuration is layered — the theme supplies defaults, note frontmatter overrides them through keys such as `theme:` and `order:`, and the export modal has the last word, with a section for subtitle, cover, table of contents, watermark and classification that can be written back into the note's frontmatter. Themes can point at font files in the vault, which are inlined into the PDF with family, weight and style read from the file, and any theme including the built-ins can be duplicated; exporting makes no network request and a quick export command writes a PDF beside the note without a dialog.
