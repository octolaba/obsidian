# brandonkboswell/weekly-review

Weekly Review opens the files created in the recent past so they can be reviewed together, instead of being opened one by one. The README describes it as coming from the author's own weekly review process, in which every file created that week is revisited, and states that the number of days it reaches back is configurable. It is run from the command palette through a Start Review command.
