# Lemon695/obsidian-recently-added-files

Recently Added Files shows a sidebar list of the files most recently added to or modified in the vault, rather than the ones most recently opened, which the README motivates by importing a batch of images, dropping in reference PDFs or creating several notes at once. Files can be tracked by creation date or by last modification date, filtered by type — Markdown, PDF, images, video, Canvas or other — searched by filename as the query is typed, and sorted newest or oldest first or alphabetically in either direction. A right-click pins a file to the top of the list or renames it with a SHA-256 hash to resolve a filename collision, hovering an image or PDF entry shows a floating preview, and regular expressions over paths and frontmatter tags exclude entries from the list.
