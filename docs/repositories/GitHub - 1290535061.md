# dhwang0803-glitch/Vaultend

Vaultend is an AI-assisted vault maintenance plugin for Obsidian that tags, links and organises notes, with an activity log and undo safety. The provider is chosen in settings — OpenAI, Google Gemini, Ollama or a custom endpoint — and commands cover organising the current note, a folder, or the vault's tags. The README states that every AI feature reports token usage and an estimated cost after each call, and documents privacy protection, internationalisation, compatibility and known limitations as separate sections.
