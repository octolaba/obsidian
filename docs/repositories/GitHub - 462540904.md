# PKM-er/obsidian-floating-toc-plugin

Renders a floating table of contents beside the note in both reading and source mode. The list tracks the current scroll position and highlights the matching entry, can show the current heading together with its parent, collapses and expands a section on ctrl-click, and offers a heading search bound by default to alt+f. Multi-window popouts are supported, and further appearance options are exposed through the Style Settings plugin. The README credits the earlier floating-toc plugin as inspiration and describes this one as a rewrite that reduced size and added features; no repository description is recorded, so this note is grounded in the README alone.
