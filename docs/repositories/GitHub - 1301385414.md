# cyriusweng/opal-theme

Opal is an accessibility-checked Obsidian theme with hand-tuned light and dark flavours and about 82 Style Settings controls in eight groups covering colour, fonts, per-level headings, layout, borders, element toggles, skins and motion, and print; the recorded repository description gives the count as about 83. It descends from the Catppuccin Mocha lineage but retunes every hue into a muted-macaron palette with zero-duplication element roles, and the README states WCAG figures of at least 4.5:1 for body text and 3:1 for decorative elements. Reading view and Live Preview are covered at parity, native surfaces such as Bases, Canvas, Properties and graph view are styled, plugins are adapted through their own CSS variables, Chinese callout aliases map onto the semantic colours, and advanced CSS features carry fallbacks.
