# camadkins/obsidian-canvas-connect

Adjusts where connection lines attach to nodes on an Obsidian Canvas. The README states that the plugin picks the most logical anchor point among top, right, bottom and left from the relative positions of the nodes, and updates the anchors in real time as nodes are moved. A command optimizes all connections at once, and the settings switch the dynamic updating on or off, enable a brief highlight on connections that changed, and choose whether all open canvases are treated or only the active one.
