# splendidissimemendax/Camena

splendidissimemendax/Camena records no repository description; its README presents Camena as a theme built to adjust to the accent colour a user chooses. The author frames it as an experiment in how far Obsidian's CSS variables can be pushed toward that goal, and reports that all colours, including those with defined hues, respond to the accent colour. The name is explained as the Camenae, the Italic goddesses Livius Andronicus used for the Greek Muses in his Latin Odyssey. Supported modes, settings and the installation route are not recorded in the fetched text.
