# llaori1/canvas-cover-overlay

This repository holds Canvas Cover Overlay, an Obsidian plugin that gives each canvas its own thumbnail for embeds and its own canvas-view background. It affects only file nodes pointing at canvas files and reads the cover path from the target canvas file's frontmatter, which is edited through the Properties panel. Rather than replacing native rendering it adds a non-interactive overlay layer, wrapping the internal embedRegistry hook for canvas embed creators, and it stays idle when embedRegistry is unavailable in the running Obsidian build. The README states that the Advanced Canvas plugin is a required dependency and that mobile is not supported.
