# fengshuzi/daily-habit

The repository holds Daily Habit, an Obsidian habit tracker that reads check-ins from daily journal files, where each habit is recorded as a tag such as reading or exercise inside the day's note. A sidebar view lists the configured habits with dots for the last seven days, counts consecutive days, and filters the statistics by this week, last week, this month or last month. The README states that habit keywords and display names are configurable, that only files with date-shaped names are scanned, and that results are cached for thirty seconds and refreshed by file watching.
