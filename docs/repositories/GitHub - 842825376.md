# imfenghuang/obsidian-immersive-translate

Applies the Immersive Translate service to foreign-language Markdown files inside Obsidian. The README states that the plugin works in reading mode and that from version 0.0.2 onward only the Lite variant of Immersive Translate is supported. Settings hold the selectors and exclude selectors that define which parts of the reading view are translated, defaulting to everything in the reading view except inline code, and changes take effect after a relaunch.
