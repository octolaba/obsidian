# CollierKing/saloon-obsidian

The Saloon plugin implements SALOON, described in its README as a framework for turning vault notes into structured AI-enabled wikis, OWL ontologies and Anki flashcards; the acronym names its stack of SQLite, Anki, LangChain, Obsidian, OWL and Next.js. Its listed features are extracting technical terms, definitions and context from Markdown files with a local LLM through Ollama, an approval workflow for reviewing, approving or rejecting extracted terms before they enter the glossary, generating wiki-style term pages with definitions, context and knowledge triples, and storing everything in a local SQLite database. The README states that a locally running Ollama with a pulled model is a prerequisite.
