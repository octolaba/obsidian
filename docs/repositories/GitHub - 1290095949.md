# tikitock/toastmaster

Toastmaster changes how long Obsidian's toast notifications stay on screen, which the README states is otherwise fixed at four seconds with no setting anywhere in the application. It patches the single method the notice class uses to schedule its auto-hide timer, so the change applies to notifications from every plugin and from Obsidian core rather than only its own. Two modes are offered: a minimum duration that raises a floor without ever shortening a toast a plugin deliberately set to last longer, and a persist mode in which toasts stay until clicked. The plugin also keeps a capped, persistent log of recent toasts that can be reviewed from a command or the settings, and the README notes two existing Obsidian behaviours it leaves unchanged, that clicking a toast dismisses it and that hovering pauses its timer.
