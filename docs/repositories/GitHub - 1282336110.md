# bobstanton/extreme-wikilinks

Extreme Wikilinks changes how wikilinks are displayed by rendering them through templates that read the linked file's frontmatter, so a link can be shown with an icon, a property value or a rewritten display text without the underlying Markdown changing. Templates are defined in the plugin settings and can be applied conditionally based on headings or on the target link. Placeholders cover the linked file's title, basename, path, the original link destination and display text, the whole frontmatter object and any property by name, with bracket syntax for names containing spaces, and template expressions may contain JavaScript. Every rendered link is wrapped in a span carrying a data attribute for the template name, so CSS can style each template, and two built-in classes are provided.
