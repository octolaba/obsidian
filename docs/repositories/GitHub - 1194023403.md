# Meibbo/Vaultman

VaultMan is described as a plugin for bulk file operations, filtering elements by different conditions and queueing pending changes. Its README says it aims to expand Obsidian's core plugins by adding functionality to the data and metadata explorers, each showing its data in a node or cell based structure with selectable layouts, optional detail, and sorting and grouping so the same information can be seen from different perspectives. Filters can be applied to files, tags, properties or content, and the selected changes are queued as batch operations and applied together; the README offers stable, beta and alpha release streams, the latter two through BRAT.
