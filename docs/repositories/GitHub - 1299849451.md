# turingexmachina/obsidian-url-file-preview

This plugin registers a dedicated Obsidian view for Windows Internet Shortcut files, the INI-formatted .url files that store a link and an optional icon, rendering each as a small card with an inline-editable URL field and one-click actions. It parses the shortcut section, preserves keys and sections it does not touch including the icon entry, and writes changes back in the same format, which suits vaults that sync in shortcuts created on Windows or dragged in from a browser. The README states that the plugin makes no network request of its own — no favicon lookups and no telemetry — and that the action for opening a link in the web viewer appears only when Obsidian's optional Web viewer core plugin is enabled.
