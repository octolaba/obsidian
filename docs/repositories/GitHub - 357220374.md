# renmu123/obsidian-image-auto-upload-plugin

The repository holds the Image Auto Upload plugin, which uploads images to an image host through PicGo, PicList or PicGo-Core. Its README describes the setup as installing and configuring PicGo, enabling its server service, noting the port and pointing the plugin's setting at that local upload address. With PicList from version 2.5.3 the target host and configuration name can be appended to that address as query parameters, so different vaults can upload to different hosts. The README notes that Obsidian should be restarted after the plugin is updated and that the plugin has not been tested on macOS.
