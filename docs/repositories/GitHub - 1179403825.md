# laofahai/obsidian-tablite

Tablite opens .csv and .tsv files in the vault as an editable table, rendering large files through virtual scrolling and progressive chunked loading. The README records inline editing on double-click, cell selection with row and column cross highlighting, per-column type detection for string, number and date values, multi-column sorting, a global search, and filters that follow the column type: free text, a multi-select dropdown for columns with fewer than twelve distinct values, a numeric range, or a date range. It also lists automatic delimiter and encoding detection covering UTF-8, GBK, Windows-1252 and Shift-JIS, header-row detection, hiding, reordering, freezing and resizing of columns saved per file, row and column insertion and deletion from a context menu, and up to fifty steps of undo.
