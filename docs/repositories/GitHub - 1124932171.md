# JACKERS228/quest-journal-theme

Quest Journal is a lightweight Obsidian theme inspired by quest journals, aimed at Dungeon Masters, players and world-builders recording a campaign or their own adventures. Its light mode uses warm beige parchment tones with rust-red accents and its dark mode deep browns and muted golds, over a customisable paper-grain texture overlay. Headings are set in Cinzel small caps and body text in Crimson Text, content is centred at a book-like reading width, tabs are styled as bookmarks, checkboxes as ink-crossed squares and code blocks as dashed-border scribbles. The theme supports the Style Settings plugin for further tweaking.
