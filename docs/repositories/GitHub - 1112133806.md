# bongho/obsidian-regex-replace

Find-and-replace over note text using JavaScript regular expressions, including capture groups, with a before-and-after preview and match highlighting shown before anything is written. The global, case-insensitive and multiline flags can be toggled, replacement can be limited to the selection, recent patterns are kept as history, and multi-step rulesets can be saved and reused or imported from regex-pipeline rulesets. Its README states that everything runs locally and that note content is not sent to external services.
