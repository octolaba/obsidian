# marcjulianschwarz/obsidian-file-link

The repository holds Better File Link, an Obsidian plugin for inserting links to files outside the vault without dragging them in. Its README records a command that opens a file selection inside Obsidian, custom prefixes when several links are added at once, a toggle for showing file extensions, a choice between linking the file or its containing folder, optional embedding, and a command that checks every note for broken file links. Embedding is documented for Markdown and PDF documents, several image formats, and a list of audio and video formats.
