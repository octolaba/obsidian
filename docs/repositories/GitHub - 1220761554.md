# moranrs/table-master

Table Master gathers table editing features that its README attributes to three existing plugins: shortcuts for inserting, deleting and moving rows and columns and setting alignment, a visual grid editor, and merged cells rendered in Reading view and Live Preview through Table Extended or MultiMarkdown syntax. A floating toolbar appears above a table under the cursor, carrying those operations plus cell merging and splitting, table re-padding and pasting a table copied from a spreadsheet or a web page with HTML or TSV detected automatically; the same operations sit in the editor's right-click menu, and a modal grid editor edits cells inline, selects rectangular ranges and writes back on apply. The README warns that Table Extended hooks the same parser, so running both is not supported and Table Master warns on load.
