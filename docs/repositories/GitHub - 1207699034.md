# bahfahh/engram-quest

EngramQuest builds study material from notes in a vault: interactive courses, quest-style drills, memory maps of how ideas connect, and review decks scheduled by the FSRS spaced repetition algorithm. The README states that cards can be written by hand or generated by an external AI tool the user already runs — it names Claude Desktop, Claude Code, Codex, Antigravity, Gemini CLI and Cursor — so the plugin itself asks for no subscription or per-token fees and AI stays optional. Each module is described as usable on its own or chained into the next, and the plugin is opened from its ribbon icon.
