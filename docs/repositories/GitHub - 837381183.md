# jdrbrn/obsidian-scripture-indexer

Obsidian Scripture Indexer scans notes for scripture references and writes them into an index file. References are recognised in the form of a book with a chapter and verse separated by a configurable delimiter, with hyphens for verse intervals, commas for several verses or intervals in one chapter, and semicolons between different chapters or books. Three commands reset the index, index every Markdown file in the vault, or index the active note, and settings define the index file path, the chapter and verse delimiter, whether indexing runs automatically on change, the delay before a changed file is indexed, and paths excluded from indexing. When indexing runs it removes old or dead entries, and with automatic indexing enabled it also cleans the index on deletion and renaming.
