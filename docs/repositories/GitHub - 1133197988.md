# DuckTapeKiller/obsidian-easyview

Easy View adds status bar buttons for adjusting the global font size, switching between light and dark themes, cycling Source, Live Preview and Reading views, toggling focus and zen modes, and opening a list of recently opened notes. The README states that each button can be enabled or disabled individually, and that on mobile, where there is no status bar, one chosen action and an optional history icon are placed in the navigation bar instead. It also documents deleting a note together with its linked attachments, keyboard shortcuts, a right-click context menu and persistence of the current state.
