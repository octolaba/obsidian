# heeeyMan/ObsSync

Pushes and pulls a whole vault to a Git remote from one button on desktop and mobile, written in pure JavaScript so no system git is required. A sync engine setting chooses between a local git engine with full history and two-parent merges and a GitHub data API engine that transfers files one blob at a time so large repositories sync on a phone, with an automatic mode that picks per platform. A conflict dialog lists each conflicting file and offers keeping the local version, the remote version or editing the merged result, while a commit preview allows deselecting changes that stay on disk and out of the commit. The README records that both engines honour excluded paths and the repository ignore file, that the API engine always skips the configuration folder, and that the plugin's own data file holding the token is always excluded.
