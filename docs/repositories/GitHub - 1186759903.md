# rodolfo-terriquez/workflowy-sync

Connects an Obsidian vault to Workflowy, sending content there, embedding live outlines and keeping mapped notes aligned. The current selection, or the current line when nothing is selected, is sent to a saved default target or to one chosen at the moment, and a `workflowy` code block embeds a live node or subtree inside a note. Mappings pair one Workflowy item with one Obsidian note and sync in either direction, manually or on a schedule, writing into a managed block under a heading instead of replacing the whole note. Setup pastes a Workflowy API key into the settings and tests the connection, and with backlinking enabled the sent item carries an `obsidian://` link back.
