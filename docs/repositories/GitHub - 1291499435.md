# psalkiewicz/obsidian-proxmox-vm-list

Proxmox VM List connects to the Proxmox VE API and writes an inventory of the virtual machines and LXC containers of a host or cluster into a Markdown note. One command, from the palette or a ribbon icon, fetches every QEMU machine and container from all nodes and regenerates a table with the identifier, name, type, host node, running state, CPU count, RAM, each disk with its size, the operating system and the description field, marking templates and showing running or stopped status as icons. Authentication is by API token, which the README recommends, or by username and password including the realm, TLS verification is optional so the default self-signed certificate works, and a test-connection button checks the credentials before anything is fetched. The destination folder and note name are configurable.
