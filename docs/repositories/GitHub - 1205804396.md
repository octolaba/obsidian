# PandoraReads/HiLighter

HiLighter is an Obsidian plugin for managing highlights as note cards. The README records a sidebar that aggregates highlighted content from the current document or the whole vault, filtering by the four highlight colours yellow, pink, blue and green and by a keyword search, and clicking a card to jump back to the highlighted position in the source note. Card handling covers inline editing, custom tags with recommendations and batch tag operations, a batch-selection delete mode, a full-screen card view, and a review mode that shuffles cards and can archive them. AI translation of a highlighted sentence and an AI research action with built-in and custom prompt templates require an LLM API configured in settings, for which the README names DeepSeek, Google Gemini and Volcano Engine as supported providers.
