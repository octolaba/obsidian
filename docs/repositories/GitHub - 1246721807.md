# HornatX/plugin-setting-renamer

This plugin customizes Obsidian's settings sidebar by renaming tabs, swapping their icons and hiding panels. Its bilingual README records that any tab can be renamed, including core settings, core plugins and community plugins, that default icons can be replaced from the Lucide set through a searchable picker with live preview, and that rarely used panels can be hidden, with a built-in guard against locking oneself out. It also describes a responsive grid dashboard with debounced search for jumping straight to a plugin's configuration, and states that changes are applied dynamically through a mutation observer, so removing the plugin restores the settings sidebar to its original state.
