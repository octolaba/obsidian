# AlexanderT142/Alex-annotator

PDF Annotator adds highlighting and margin notes to Obsidian's native PDF viewer, keeping the annotations as local Markdown sidecars according to the recorded description. Selecting text offers highlight, annotate or copy, with plain highlight, underline, dotted or dashed underline, box and strike-through styles in four colours, and notes appear as cards in a margin rail whose height reflects their length, folding when a page carries many long notes and opening on hover, click or pin. A list button searches every mark and note in the document by word, page or text and jumps back to it, and a card's context menu pins it, moves it to either side, returns it to automatic placement or deletes it without altering the marked words. The README records the plugin as desktop-only.
