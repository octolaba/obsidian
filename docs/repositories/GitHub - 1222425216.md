# ikeniborn/obsidian-ai-wiki

Obsidian plugin that builds and maintains a knowledge-base wiki alongside the vault with an AI assistant. Ingest reads an open note, extracts topics such as people, tools, processes and terms, and creates pages or patches existing ones with guarded section edits, chunking oversized Markdown and standardising tags against the domain's existing vocabulary. Query answers a question using the wiki as context, Lint reports gaps, outdated content and broken links, Fix applies corrections from the sidebar chat, Init and Re-init create or rebuild a domain's folders and index files, and Format tidies headings, tables, frontmatter and image captions in notes outside the wiki. Two backends can be switched in settings: a fully local Ollama or OpenAI-compatible server, or the Claude agent in Anthropic's cloud.
