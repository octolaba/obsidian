# snezhig/obsidian-front-matter-title

The repository holds Front Matter Title, an Obsidian plugin that displays a title taken from a note's frontmatter wherever the app would otherwise show the file name. Its README makes the boundary explicit: the plugin never renames or edits a file, so timestamp or identifier filenames stay exactly as they are on disk and only the display changes. Each surface is toggled separately in the settings, among them the file explorer, search, the quick switcher, bookmarks and backlinks, the tabs, note header, inline title and window frame, and the graph and canvas views.
