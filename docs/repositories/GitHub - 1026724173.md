# NicoKNL/tasks-map

Tasks Map renders the tasks in a vault as an interactive graph, drawing each task as a node and each dependency as an edge. It reads two task sources: inline checkbox tasks through Dataview, and file-based note tasks where a whole note becomes a task through frontmatter metadata, with relationships taken from Obsidian Tasks identifier and blocking syntax or from blockedBy and dependsOn frontmatter keys. Multi-select tag filtering narrows the view, tasks can be marked done or undone from the graph, and the interface is translated into English, Dutch and Simplified Chinese. The README records that the plugin requires the Dataview and Tasks plugins and that, before v1.0, the embed format, filter field names and settings may change between releases.
