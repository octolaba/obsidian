# ntsiris/obsidian-popup-dictionary

Popup Dictionary shows a word's definition in a small popup in Obsidian, either from a command run on the selection, optionally automatically on every selection, or by holding a modifier key and hovering the word. Definitions come from Wiktionary through its REST definition endpoint, which the README records as implemented only for the English edition while that edition covers words from thousands of languages, glossed in English. Word boundaries are found with the platform's segmenter, so scripts written without spaces between words are handled, and results are grouped by language. A language allow-list, examples, the number of senses, the hover delay and the modifier key are configurable, and results link back to the Wiktionary page.
