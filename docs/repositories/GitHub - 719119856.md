# Jamalam360/obsidian-automatic-tags

Obsidian plugin that adds tags to new notes according to the path where they are created. Its single configuration option maps paths to tags in a simplified glob format, so a pattern matching everything can tag all new Markdown files while a folder pattern tags only the files created inside that folder. The README states that comments are not allowed in that configuration.
