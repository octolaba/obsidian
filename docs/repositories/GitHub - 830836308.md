# Lord-Turmoil/heading-toggler-obsidian

Heading Toggler changes heading levels by command rather than by typing `#` characters: one command increases the level from normal text up to H1, another decreases it from H1 back down to normal text, and further commands toggle a line between a chosen heading level and normal text. All of them can be bound to hotkeys in the options. The README records a limitation: because Obsidian does not support nested headings, the plugin does not apply them and treats listing and quotes as normal text.
