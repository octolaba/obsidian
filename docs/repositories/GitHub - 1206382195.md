# leozague/obsidian-vscode-dark-plus

VSCode Dark+ is a dark Obsidian theme reproducing the VSCode Dark Modern palette, with the TRAE IDE named as a further influence. The README documents six distinct heading colors, left-border color coding for every standard callout type, custom checkboxes, themed graph view and canvas colors, Calendar plugin styling and a Menlo or SF Mono editor font, and it tabulates the exact hex values for backgrounds, headings, links and text. Its stated aim is low-saturation, non-neon color for long reading and writing sessions.
