# Lina674/Pxld-Obsidian-Theme

Pxld is an Obsidian theme available on desktop and heavily inspired by pixelated games. It features the Pixel Square font and both dark and light modes, and the font and the accent colors can be modified with the Style Settings plugin. The README explains that when the Pixel Square font is not recognized, the Pixel Square 10.ttf file has to be downloaded and installed for all users.
