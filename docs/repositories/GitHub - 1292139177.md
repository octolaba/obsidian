# AedraAelynn/Wikipedia-Importer

Wikipedia Importer fetches a Wikipedia article and writes it into a new or existing Obsidian note as Markdown, converting every Wikipedia link into an internal vault link so the import joins the knowledge graph. Equations are converted to Obsidian LaTeX, content images and animated gifs come through as embeds at original quality rather than being stored locally, sources are preserved as clickable footnotes, and navboxes, maintenance banners, fundraising notices and edit-section markers are stripped. Link style and image handling are described as configurable.
