# wmwby/obsidian-easy-latex

Obsidian Easy LaTeX completes LaTeX inside math contexts — inline math, display math and LaTeX code blocks — offering a searchable list of more than 200 commands after a backslash, filtered by prefix or description. The README states that math terms typed in Chinese, Japanese or Korean are matched to commands without a backslash, and that custom keyword-to-snippet mappings with tabstop placeholders can be defined in the settings for both Latin and CJK triggers. Pressing Tab on a selection inside a math zone asks an AI provider to convert that natural-language description into LaTeX.
