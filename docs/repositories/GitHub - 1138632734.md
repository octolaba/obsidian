# JinmuGo/obsidian-move-active-folder

This repository holds Move Active Folder, an Obsidian plugin that moves the folder containing the currently active file. A command lists the parent folders of the current file so the scope of the move can be chosen, from the direct parent to an ancestor, and then asks for a destination folder. The README records validation that prevents moving a folder into itself or its own subfolders, and a check for duplicate folder names in the destination before the move is carried out.
