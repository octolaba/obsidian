# skylernorgaard/obsidian-bible-journal-plugin

Bible Journal is an Obsidian plugin for personal Bible study that ships offline chapter text of the World English Bible, a one-time setup wizard for a new vault, and a Bible Reader with study notes in the sidebar. The wizard copies WEB chapters into a `~ Bible/` folder and creates starter folders, the reader offers a chapter picker, previous and next navigation and verse selection, and the sidebar groups notes by chapter, section or book with support for a structure file. A single action creates a tagged note in `1. Bible verses/` from the current chapter, and tag search runs AND and OR queries whose results can be saved as snapshots; the README notes the setup wizard downloads a data archive from the release URL on first run because Obsidian's installer fetches only the three plugin files.
