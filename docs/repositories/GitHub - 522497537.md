# linanwx/aosr

Aosr is a spaced-repetition plugin for Obsidian that uses flashcards to help remember knowledge. The README describes it as similar to the obsidian-spaced-repetition plugin with changes made to suit personal habits, and lists an Explore Hard Cards mode for reworking difficult cards, configurable single-line and multiline patterns, a custom database path, folder and file exclusions, and card scanning skipped for files without the Q tag. Cards support rich text formats such as audio, and the card database is serialized with one-space indentation to sit better with the Git plugin.
