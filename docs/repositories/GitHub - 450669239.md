# Sanqui/obsidian-persistent-graph

Persistent Graph adds commands that save and restore the positions of nodes in the global graph view, so a graph arranged by hand survives a restart, with a setting to restore automatically whenever a graph view is opened. A further command runs the graph simulation continuously instead of leaving it to be jiggled by hand. The README states that the plugin uses internal Obsidian APIs, so it may break with updates and is unlikely to be accepted as a community plugin, and it carries a notice that the project is looking for a new maintainer.
