# Narwhai/theme-basics

Theme Basics exposes common Obsidian appearance properties as settings so they can be changed without writing a CSS snippet. It covers four background colors, internal, external and unresolved link colors, bold, italic and highlight colors, body text sizes and spacing, per-heading controls for the six heading levels, list indentation and spacing, divider thickness, blockquotes, code blocks and tags, each with separate light and dark profiles. The README states that the plugin is installed through BRAT, that it is intended mainly for the default theme, and that a community theme or an existing CSS snippet targeting the same properties may interfere with its settings.
