# aoout/obsidian-rss-copyist

RSS Copyist collects articles from RSS feeds into notes. A feed is represented by a note tagged with a feed tag, and the plugin gathers that feed's updated articles into a folder of the same name in the root of the directory holding the feed notes; a template file placed at the same level or higher formats the articles for every feed beneath it. A single command fetches the newest articles from all configured feeds and writes them out through that template. The README notes that parsing works better on desktop than on mobile, so article content may be more complete there.
