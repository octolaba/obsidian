# kometenstaub/obsidian-version-history-diff

Version History Diff shows differences between versions of the active file taken from Obsidian Sync, the File Recovery core plugin, and Git through the Obsidian Git plugin. A selected version can be opened in a modal and rendered as markdown or as plain text before the file is overwritten with it, and the settings add a colour-blind mode and a choice between line-by-line and side-by-side views. The README warns that the plugin uses private APIs and may break at any time.
