# PixeroJan/obsidian-resizer

Resizes embedded images and PDFs by dragging corner handles that appear when the embed is clicked in Live Preview, and writes the resulting dimensions back into the Markdown. Aspect ratio is kept unless proportional scaling is turned off, and PDF scales are stored in the Markdown as comments so they carry across devices. Handle size and color, minimum dimensions and a live dimension readout are configurable, and a command resets an image to its original size.
