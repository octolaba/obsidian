# diegoeis/obsidian-conditional-properties

Obsidian plugin that updates frontmatter properties through conditional rules. The README describes rules combining several conditions with match-any or match-all logic over six operators (exactly, contains, notContains, exists, notExists, isEmpty), checked against frontmatter properties or note titles. Actions add, remove, overwrite or delete a property, or change the title with prefixes, suffixes and placeholders referencing dates, filenames and other properties.
