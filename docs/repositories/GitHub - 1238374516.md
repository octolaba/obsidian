# rahilp/second-brain-obsidian-plugin

Second Brain Sync sends Obsidian notes to a Cloudflare Workers service that the user deploys and runs themselves, and pulls stored memories back into the vault as notes. The README describes syncing the current note from a ribbon icon, a hotkey or a command, bulk-syncing every note carrying a configured tag, auto-syncing tagged notes on save, chunking long notes so their embeddings stay clean, and a status bar showing when the last sync happened. Setup is recorded as pasting the worker address and an auth token into settings and testing the connection; the README states that the companion worker must be running first and that the accompanying semantic search is reachable from Obsidian and from any tool speaking the Model Context Protocol.
