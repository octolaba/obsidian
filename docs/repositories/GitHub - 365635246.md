# steven-kraft/obsidian-markdown-furigana

The repository holds a Markdown Furigana plugin that renders ruby annotations above text, following the markdown-it-ruby syntax. Its README states that rendering happens as post-processing in preview, so the note itself is never modified, and that since version 1.2.0 the plugin is no longer restricted to Japanese, with examples covering kana, bopomofo, pinyin and hangul readings. It records the syntax rule that the base section holds the characters and each furigana section either matches the character count or is left empty.
