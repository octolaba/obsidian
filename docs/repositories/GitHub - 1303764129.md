# polygonhunter/slashosaurus

Slashosaurus is a slash menu that opens at the cursor and previews each block before it is inserted: headings drawn at their real sizes, callouts as colored boxes with their icons, code and math in their own look, all in the theme's own colors. Typing after the trigger filters the list, and Enter inserts the entry, with a code block asking for its language in the same popup. Its author records building it because callout syntax and the set of available callout types were hard to remember, and a menu listing only names would not have fixed that.
