# Aspharmyx/obsidian-password-protect

This plugin sets a password on selected notes and folders, and hidden notes become visible only after the password is entered in a session. Hiding works by changing the file extension, which also keeps the files out of searches and the graph view; the README states that the files are not encrypted and can still be read with a note editor in the system explorer, so the protection holds against casual viewers only. A command turns all hidden files back into Markdown, and the README describes a syncing workaround that ignores Markdown files inside the hidden folders.
