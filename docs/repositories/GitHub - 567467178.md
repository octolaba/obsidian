# Satchelmouth/Obsidian-Theme-WYConsole

WYConsole is an Obsidian theme based on the computer consoles of popular 1980s science-fiction films. Its README is written inside a CSS comment block that carries the version, the author, the MIT license text and a feature list. Those listed features are dark and light mode, styling applied across all panels, menus and buttons, and support for the Advanced Tables, Kanban, Calendar and File Tree Alternative plugins.
