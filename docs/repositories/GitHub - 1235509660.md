# qmkCamel/obsidian-ai-tag-curator

Obsidian plugin for governing an existing tag taxonomy rather than generating tags from nothing. It builds a cached tag index from Obsidian metadata, frontmatter tags and optionally inline tags, summarising tag, usage and file counts, and reuses that index instead of rescanning the vault each time. Recommendations for the current note prefer tags already in the vault, drop tags the note already carries, carry a confidence and the close alternatives not selected, apply only after confirmation, and can be undone for the latest change. A vault-level health report groups issues such as low-frequency tags, near duplicates, hierarchy inconsistencies, over-broad and over-narrow tags and naming drift, keeping rule-based evidence separate from AI-written rationale, priority and risk notes.
