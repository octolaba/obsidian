# tttt-k/obsidian-search-external-files

Search External Files adds a browser for the local file system to Obsidian and searches the vault for the file or folder that is selected in it. The README explains the problem it addresses: material kept outside the vault is linked from notes, and before moving or deleting such a file one wants to know whether any note refers to it. Navigation uses up and refresh buttons and a path bar, a preview sidebar shows an image preview and file information, double-clicking a file searches for its filename while a selected folder is searched by path, and an auto-search option triggers the search on every click. The README states that the plugin is read-only and never modifies vault files, and that its author relied on AI assistance and expects unknown issues.
