# julzerinos/spellcheck-toggler-obsidian-plugin

Spellcheck Toggler gives control over where the red spellcheck underline appears in Obsidian's editing view. Individual toggles cover external links, internal links, HTML comments, block quotes, italic and bold emphasis, and the entire file, each configurable from the plugin's settings tab. Every option's behaviour is chosen from always spellchecking, never spellchecking, or reading a user-defined frontmatter property per file with a fallback for files that lack it. The README records the plugin as originally created to stop links being underlined in the editing view and as open to requests for further block types.
