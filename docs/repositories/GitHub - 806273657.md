# h-sphere/obsidian-canvas-picture-in-picture

The repository records no description, so this body rests on the README alone. The README describes lifting a selected Canvas node above the rest of the content so it floats while being edited, which it calls picture-in-picture. Selecting an element and running the plugin's float command places it in the bottom left corner, where it can be resized by hovering on its top or right corner.
