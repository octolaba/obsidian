# joeutke-dev/skill-harness-manager

Skill and Harness Manager collects the AI skills, slash-commands and agents scattered across tool folders, marketplace bundles and loose notes into one Obsidian side pane. A skill is recognised as a file named SKILL.md carrying name and description frontmatter, or any Markdown file directly inside a skills folder, so the same rule surfaces material from every tool following that convention; results are grouped in a collapsible source-folder tree that can be searched and filtered by agent, harness and tag, with tabs for skills, commands, scripts, sessions, agents and harnesses. Skills stay readable and editable as ordinary notes, and can be launched against a chosen harness from the ribbon, the command palette, a file or folder right-click, or a right-click on highlighted text.
