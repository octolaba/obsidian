# wesswart77/obsidian-travel-planner

Travel Planner creates trip notes in Obsidian together with itinerary, packing list, accommodation and budget sub-notes, from a new trip modal. A command adds an itinerary day, the packing list arrives pre-populated with categorised checkboxes, and a sidebar lists trips sorted by whether they are current, upcoming or past. The trips folder is configurable in the settings.
