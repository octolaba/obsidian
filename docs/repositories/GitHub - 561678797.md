# hua03/obsidian-toggle-meta-yaml-plugin

This plugin toggles the display of a note's YAML metadata block, showing or hiding it. Its single command can be bound to a hotkey for convenient switching. The README notes that the latest version of Obsidian already offers a folding feature for that block.
