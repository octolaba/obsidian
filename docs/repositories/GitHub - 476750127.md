# lijyze/scroll-offset

The repository holds Scroll Offset, an Obsidian plugin that keeps a chosen distance of visible text before and after the cursor, in the manner of Vim's scrolloff option. Its README records that the distance is set in the settings tab either as a fixed pixel value or relative to the height of the content area, and that the plugin checks the boundary case: a distance beyond half the content area is treated as half, in fact slightly less because of the cursor's own height. Manual installation by copying the built files into a plugin folder is also documented.
