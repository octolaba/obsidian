# viscosenpai/obsidian-workout-logger

Logs strength training and cardio sessions and writes each entry as Dataview-compatible inline metadata, so the records can be queried from notes. A logger modal takes multiple sets with weight, reps and an optional RPE from 6 to 10 in half steps, can duplicate the first set, and computes volume and an Epley estimated one-rep max automatically; setting the target muscle to cardio switches the form to speed, incline and duration with calories from a VO2-based walking formula. Exercise names autocomplete from notes in the exercise folder, pre-filling target muscle and equipment from frontmatter and creating the note when it does not exist. A sidebar dashboard charts body metrics, calories burned and per-exercise performance over week, month, year or all-time ranges.
