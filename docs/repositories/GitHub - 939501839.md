# idlgcl/obsidialogs

Connects the vault to the Idealogs platform, where an article's kind is identified by an id prefix marking it as writing, question or insight. Typing a bracketed at-sign opens a live search modal over Idealogs articles and inserts links, writing links receiving an auto-incrementing hex sub-id so that every link in a document is unique, and articles open in a side panel that can overlay both web and local annotations and render citation markers. Annotations are written as comments or notes tied to a target article and text range, stored as JSON under a vault folder in both the source and target article files, and re-validated as those files change. Sending annotations to Idealogs renders them on the site for the sending user alone, held in browser local storage rather than on the servers.
