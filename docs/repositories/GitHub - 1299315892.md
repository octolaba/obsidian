# Dimar4713/vault-storage-map

Vault Storage Map shows where disk space is used inside an Obsidian vault, combining an interactive treemap with folder drill-down, ranked largest-folder and largest-file tables, file-type statistics, search and minimum-size filters, and a collapsible details panel. A scan is cached so it can be compared with the previous one, reports export to Markdown, CSV and JSON, and diagnostic warnings cover large files, the configuration folder, Copilot indexes, attachments and unreadable entries, with the plugin's own cache excluded from the totals. The README states that scanning is read-only over filesystem metadata rather than note contents, that there is no telemetry, account, network request or automatic deletion, and that the interface is available in twelve languages with automatic detection or manual selection.
