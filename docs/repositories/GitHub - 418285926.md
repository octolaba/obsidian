# tomzorz/obsidian-link-archive

The repository holds Obsidian Link Archive, a plugin that keeps external links readable after the pages behind them change or disappear. Its README records the action of a ribbon button: every external link in the current note is collected, submitted to the Internet Archive, and once saved an archived link is embedded in the note beside the original. It notes that already-archived links are skipped, which relies on the formatting of those archive links being left alone.
