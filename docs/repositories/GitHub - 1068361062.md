# mProjectsCode/obsidian-bases-charts-plugin

The repository records no description, so this note is grounded in the README alone. Bases Charts adds three new views to Obsidian Bases — Scatter, Line and Bar charts — where the X axis is a property or formula of type Number, Date or String and the Y axis accepts Number values selected through the Base's Properties menu. The README also documents a multi-chart mode that either separates data by a `Group by` sort or renders one chart per selected Y-axis property, and states that installation is currently only through BRAT.
