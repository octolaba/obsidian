# KrazyManJ/obsidian-keyshots

The recorded description says Keyshots adds classic hotkey and shortcut commands from popular IDEs such as Visual Studio Code and the JetBrains family. The README lists actions including moving lines up or down, adding caret cursors, inserting and duplicating lines, duplicating text or a selection, toggling readable line length and line numbers, encoding and decoding URI text, converting selections to lowercase, uppercase or title case, joining and splitting selections, sorting selected lines alphanumerically and converting to or from snake case. Every command carries hotkey mappings for those IDEs, and where an IDE action has no hotkey the plugin's own mapping is used instead, which a setting can change. Two double-key commands borrowed from JetBrains IDEs, adding caret cursors by holding the last key and opening the built-in Quick Switcher, can be disabled in the settings.
