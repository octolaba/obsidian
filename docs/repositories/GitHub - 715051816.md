# daledesilva/obsidian_ink

Adds handwritten and drawn sections between the paragraphs of a note, aimed at a digital pen, stylus or Apple Pencil, and useful for handwriting, sketches, scribbles and mathematical notation. The drawing surface runs on the tldraw framework and provides an infinite canvas. The README points to a video overview and to the author's development diaries, and describes installation from the plugin directory or, for versions still being tested, through BRAT.
