# RevoTale/obsidian-folder-by-tags-distributor

Moves notes into folders whose names match the tags written in the note, triggered by a ribbon button or a command that redistributes all notes. For each tag the plugin searches from the vault root for a folder with a similar name and skips the tag when none exists. The README states as warnings that the plugin creates no folders, that notes without a matching folder are moved to the vault root, that a templates folder should be added to the excluded folders, and that the vault should be backed up before use.
