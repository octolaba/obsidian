# Sto3IV/obsidian-fancy-a-story-frozen

Sto3IV/obsidian-fancy-a-story-frozen holds Frozen Kingdom, a fork of the Fancy a Story theme that its author rebuilt for performance and a colder look. It applies the Nord palette across a dark and a light mode, adds rounded corners, translucent borders and lift shadow transitions on hover, restores native font inheritance by stripping hardcoded CSS overrides, colours folders recursively so subfolders inherit their parent's colour, and reworks tables with alternating row hovers and crosshair cell highlighting.
