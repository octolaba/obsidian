# usero2/obsidian-plugins-infinite-note-auto-append-newline

Infinite Note appends empty lines to the end of an Obsidian document so the editor never reaches an absolute bottom, whether the user is typing or moving down with the arrow keys. More lines are generated as the cursor approaches the end of the file, including when nothing is being typed, and the README states that the document is modified in the background without moving the cursor or losing the selection. The number of empty lines kept at the end of the document is configurable.
