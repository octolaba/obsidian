# George-debug/obsidian-timeline

Obsidian plugin that renders timelines from code blocks in a note. In the timeline block each event is written as three plus-prefixed lines carrying its time, its title and its content, while a labelled variant starts each line with the field name instead; blank lines between events are allowed in both. An optional bracketed list at the start of the block attaches classes to the wrapper, and pre-written classes vary the line style, the body style and the active colour. Those active colours are Obsidian's own CSS variables, so a timeline follows the theme, and a custom colour can be set through a dedicated variable on the timeline class.
