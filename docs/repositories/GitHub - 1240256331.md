# ydd0729/obsidian-extended-code-highlight

Extended Code Highlight widens syntax highlighting for Obsidian code blocks across Reading view, Source mode and Live Preview, covering every PrismJS language id and alias bundled with the plugin, the bundled CodeMirror parser languages, and regex-based languages loaded from JSON. Highlighting priority depends on the view: Reading view tries the PrismJS grammar first, then a CodeMirror parser translated into Prism-style token spans, then the regex fallback, while the editor views try the CodeMirror parser first and translate PrismJS tokens into cm- classes. Highlighted blocks stay editable in Live Preview and reuse Obsidian's own theme classes rather than shipping colours. A custom language is added as one JSON file in the plugin's languages folder, declaring an id, aliases and regex token rules, and picked up by a reload command.
