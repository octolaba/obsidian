# wangdamon6-hub/obsidian-mini-tray

Mini Tray makes Obsidian's close button hide the window to the system tray instead of quitting: clicking the tray icon toggles the window, and quitting is done from the tray icon's right-click menu. The README states it has no settings panel, no hotkeys and no quick notes, describes it as roughly 5 KB with zero configuration, and records it as desktop-only, single-window only and tested on Windows 10 and 11. It is a fork of dragonwocky/obsidian-tray by way of another fork, written because the author wanted only the close-to-tray behaviour rather than the original's settings interface.
