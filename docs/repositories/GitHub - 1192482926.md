# Qctsu/obsidian-file-shift

FileShift reorders files and folders in Obsidian's File Explorer by drag and drop, without filename prefixes: the order is stored in the plugin's data.json per folder and no file is modified. Dropping on the top or bottom edge of an item reorders it, while dropping on the centre of a folder moves the item into that folder, preserving Obsidian's native behaviour, and the custom ordering can be toggled or reset from a ribbon icon and two commands. The README states that the plugin intercepts drag events in the capture phase and uses Obsidian's internal vChildren and InfinityScroll APIs for rendering, which makes it desktop-only and dependent on Obsidian 1.7.2 or later.
