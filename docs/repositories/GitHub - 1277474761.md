# znorgaard/azer

An Obsidian plugin for running D&D campaigns over plain Markdown notes. Commands create typed notes — NPC, session, adventure log, location, PC and table — each with starter frontmatter carrying an azer-type discriminator and defined in an azer.yaml file at the vault root so further types can be added, and NPC, location and PC notes carry a grouped Bases backlinks table that a command can insert anywhere. Several campaigns can live in one vault through a top-level campaign folder that scopes the commands, and a table authored in an azer-table code block is scaled into die-face ranges and rendered as a roll-to-result table with nested tables written as wikilinks. Two features use an Anthropic API key kept on the device and never synced: generating a table from a prompt and recapping the last few adventure log notes.
