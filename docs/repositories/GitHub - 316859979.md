# tgrosinger/leader-hotkeys-obsidian

Leader Hotkeys is described as using a leader key, in the style of tmux, for hotkeys in Obsidian. The README says the leader is pressed before the assigned key, as in tmux or Vim, that no leader is defined by default and any key can be configured on Obsidian's hotkeys settings page, and that the mechanism works with any command including those added by other plugins. Four pane-focus commands are configured by default, moving focus to the pane below, above, left or right. The README notes that the 0.2.0 release requires hotkeys to be reconfigured and describes the plugin as experimental.
