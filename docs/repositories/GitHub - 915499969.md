# Wishmater/obsidian-plugin-duplicate-detector

Obsidian plugin that highlights lines duplicated within the active note, with a tooltip on a highlighted line giving the line number of its duplicate. A notice is also shown when pasted lines duplicate lines already in the file. The README gives keeping lists of items such as web links as the motivating case, and records detecting duplicate links rather than lines, include and exclude settings, cross-file detection and a jump-to-next-occurrence command as possible future work.
