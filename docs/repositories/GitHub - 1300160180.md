# LinkwiseApp/obsidian-linkwise

Linkwise for Obsidian is described as the official Linkwise plugin, and its README marks the version as beta. It performs a one-way incremental sync of saved links, AI-generated summaries, key questions, highlights and collections into the vault as Markdown notes, tracks each note by a unique identifier so files can be renamed without duplicating, preserves highlight colours through CSS and frontmatter, and gives each collection a map-of-content hub note carrying a link count and a dedicated tag. A command assigns graph colours to those hub notes without changing existing graph settings, and cover images can be shown or switched off. The README states that the plugin requires an active Linkwise Pro subscription and that text written by the user in a synced note is not overwritten.
