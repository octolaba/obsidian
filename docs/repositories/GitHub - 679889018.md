# Canna71/obsidian-sets

Obsidian Sets structures data in Obsidian notes around their properties, an approach the README describes as inspired by Notion and AnyType. It provides types and collections, a query engine that selects items by their properties, editing of that data through Obsidian properties, several layouts for viewing items including grid, board, gallery and list, and creation of new items from the interface. The README states that the plugin is under development and lists aggregations, further layouts, text search within items, integration with other plugins such as Templater, more property types and joins as roadmap items.
