# n21rl/stablock-sidekick

Statblock Sidekick generates D&D 5e sidekicks for use with Fantasy Statblocks, following the Expert, Spellcaster and Warrior rules from Tasha's Cauldron of Everything. It walks interactively through choosing the sidekick's class, level and features. A save mode setting decides whether the generated note is written into the same directory as the original statblock note or into a directory named in the settings, and the README documents installation from the community plugins browser, through BRAT, or by placing release files in the plugin folder by hand.
