# Obsidian-TTRPG-Community/Granite

Granite, the Goal Reinforcing And Note Improving Tiny Entity, is a character that talks to the writer while they work in Obsidian, and the README names Gemmy as its inspiration. Quotes appear on an interval set in Granite's settings and range from encouragement to laughing at writer's block; they can be set per character, with Gemmy available and Granite and Drake listed as coming soon. A writing mode interrupts a session whenever the writer has paused for an extended duration. The README advises against using the plugin in work vaults because of its language.
