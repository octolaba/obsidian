# M-Torrus/obsidian-cosmical-theme

M-Torrus/obsidian-cosmical-theme holds Cosmical, a theme that pairs a neutral background the README attributes to Gnome with accent colours it draws from code editors. It ignores the user accent colour and ships its own schemes, Ocean as the default plus Forest, Twilight, Sunset and Night, so the Style Settings plugin is required to pick a different one. The README also lists toggleable extras such as coloured headings with optional underlines, hidden or customized file titles, sidebar toggle visibility and a reworked multi-select list, and records a Vite and PostCSS build with the theme released under the Apache License 2.0.
