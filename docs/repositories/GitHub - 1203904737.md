# wolfuardian/obsidian-sync-meter

Sync Meter reports the progress of Obsidian Sync as a percentage with a small progress bar in the status bar. The README describes three visual states: syncing, with an accent-coloured icon and an animated bar; synced, dimmed at 100 percent; and greyed out when Obsidian Sync is not enabled. It states that sync status is polled every two seconds, that no configuration is needed, and that the plugin works on desktop and mobile.
