# DawsonBodenhamer/beautiful-graph

Beautiful Graph is an alternative graph view for Obsidian built around folder-driven and Karpathy-style knowledge bases. It keeps graph navigation familiar and concentrates on what the native view does not offer: folder semantics, readable `index.md` hubs as folder indexes, visual Directory Groups, curated color palettes, Folder Lens contours and adjustable ambience. The README frames the design against Andrej Karpathy's LLM wiki pattern, in which a Markdown wiki sits between raw sources and the person exploring them.
