# KStew1017/obsidian-sea-glass-theme

Sea Glass is an Obsidian theme adapted from a VSCode theme its author made, so that both editors keep a consistent look, with colour inspired by the beach. It is solely for dark mode and does not support light mode. The Euclid Circular A font is built in for the interface and editor and CaskaydiaCove Nerd Font Mono for code blocks, both falling back to the default font when not installed, and code block syntax highlighting follows the VSCode version. The author reports no major plans beyond changes made for personal use.
