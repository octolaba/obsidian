# kotborealis/slides-extended-mobile-preview

Repository for a plugin that previews Markdown slide decks on Obsidian Mobile using a bundled Reveal.js runtime and themes. Its README states that the active note is rendered through Obsidian's own Markdown renderer and the result placed into a deck shown inside an Obsidian view, that horizontal and vertical slide breaks use two different separator lines, and that frontmatter selects a bundled theme and may override the speaker-notes separator. It also records slide backgrounds set through a comment, including backgrounds referenced as vault images, touch navigation and previous and next controls, and installation through BRAT or by copying the files by hand.
