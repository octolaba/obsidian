# PeterCarterSr/Obsidian-Theme

This repository holds Arcadia, an Obsidian theme aimed at a calm, book-like writing environment. It ships 34 colour schemes, 16 dark and 18 light, including newspaper, encyclopedia, publishing and genealogy-inspired collections, along with 14 content and 6 code fonts, more than 50 file type icons, 21 alternate checkboxes, paper styles such as lined, grid, graph, legal pad, Cornell and music staff, sticky-note callouts in eight colours, and custom callouts for timelines, profiles, definitions, pro and con lists, recipes and stats. Style Settings unlocks the customization, and without it the theme falls back to its Granite dark and Marble light defaults. Accessibility options include an OpenDyslexic mode, a high contrast mode and reduced motion support, and the README states that the theme is free and always will be.
