# jaidetree/obsidian-random-task

Random Task Selector picks the next task from a Markdown checklist in Obsidian: with the cursor inside a checklist, one command draws uniformly among the unchecked items at that indentation, refusing to run when there is nothing unchecked or one item is already in progress. The chosen task is marked with an active tag, a start glyph and a selected-at timestamp, and a checklist holds at most one active task at a time. Checking off any hyphen task anywhere in the vault appends a completion glyph and a minute-precision local timestamp, which the README states deliberately absorbs and replaces the Tasks plugin's date-only done stamp, while un-checking a completed task refreshes its start timestamp and returns it to the pool. The tag and both glyphs are editable in settings.
