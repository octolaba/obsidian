# DevilRoshan/obsidian-lunar-calendar

A calendar plugin whose recorded description and README are written in Chinese; this body is an English restatement of what they describe. It presents a calendar following Chinese conventions, showing the lunar calendar, festivals, adjusted working days and solar terms, with a month view and a year view that can be switched, and navigation to the previous or next month or year. Clicking a day, week, month, quarter or year creates the corresponding periodic note; the README states that the plugin depends on the Periodic Notes plugin, which holds the filename syntax, template and folder settings, and that note creation can instead go through a QuickAdd template command with documented parameters. The README also carries a to-do list of unimplemented items, including internationalization and mobile support, and a changelog of holiday data updates.
