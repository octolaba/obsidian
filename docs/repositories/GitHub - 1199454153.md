# toniim/obsidian-novel-theme

Novel is an Obsidian theme that brings the aesthetic of printed pages into the app through warm parchment backgrounds, serif typography and generous whitespace. Merriweather is used for headings and body text and JetBrains Mono for code, the layout is max-width constrained and centered, and the dark mode uses a deep background with warm-tinted text rather than harsh contrast. Callouts and blockquotes take a warm left-border accent with a subtle background tint, tables use alternating row shading, and task checkboxes are styled with the accent color.
