# Dyldog/luhman-obsidian-plugin

No repository description is recorded, so this body is grounded in the README alone. Luhmann adds commands for keeping a zettelkasten whose filenames are Luhmann-style identifiers, creating a child note under the current note or a sibling beside it and taking the new title from the selected text or from a prompt. Two further commands search files by the first heading found inside the note, either opening the matching zettel or inserting a link to it instead. The README also lists the project's current maintainers and its contributors.
