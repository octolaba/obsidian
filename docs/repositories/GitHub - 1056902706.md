# mnaoumov/obsidian-embed-html

Embed HTML adds support for embedding HTML files inside Obsidian notes, accepting the htm, html, shtml, xht and xhtml extensions. The README documents per-embed sizing tokens for width and height, a marker that sizes a dimension to the embedded content and updates as that content changes, and a list of CSS declarations for finer control including min and max clamps; unknown properties fall back to the defaults configured in settings. A demo vault with usage examples ships with every release and can be opened from a plugin command.
