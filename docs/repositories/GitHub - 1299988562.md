# JWCzju/scroll-wheel-zoom

Scroll Wheel Zoom zooms the whole Obsidian window in and out when Ctrl or Cmd together with Shift is held while scrolling, and allows zooming out below Obsidian's own lower limit of roughly 63 percent down to about 40 percent, which the README suggests for fitting wide tables, graphs or notes on screen. Three commands are provided, for zooming out one step past the built-in limit, jumping to a configured preferred zoom level, and jumping to the configured minimum, all bindable under Settings and Hotkeys. Both the minimum and the preferred level are set in the plugin settings with a live percentage preview. The README states that the plugin controls the Electron window zoom and therefore does not run on Obsidian mobile.
