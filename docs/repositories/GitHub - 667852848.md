# j0rd1smit/obsidian-copilot-auto-completion

This plugin adds Copilot-style auto-completion to Obsidian, generating text from a large language model based on the characters before and after the cursor and showing the proposal as transparent text beside it. Tab inserts the whole suggestion, the right arrow key inserts part of it, and Escape or moving the cursor dismisses it. The README describes context-aware behaviour — prose in paragraphs, code in code blocks, formulas in math blocks — and language detection that nudges the model toward the surrounding language, with OpenAI, Azure OpenAI, Ollama and any OpenAI-compatible endpoint as providers and configurable triggers, delay and context sizes.
