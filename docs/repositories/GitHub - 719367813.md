# zmister2016/obsidian-mrdoc

This repository holds an Obsidian plugin for MrDoc, a self-hostable knowledge base and online document management system, providing two-way synchronization between local documents and MrDoc. It maps an Obsidian vault to a MrDoc collection, Markdown files to documents, and folders to documents that hold subordinate documents; the target collection is chosen on the settings page, and a new one can be created from there. A toolbar button pulls every document of the chosen collection into the vault, creating files and folders that do not exist locally. The README records the requirements as MrDoc Professional v1.3.6 or later, or Open Source v0.9.2 or later, and Obsidian v1.4.16 or later.
