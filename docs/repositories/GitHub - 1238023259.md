# Nymbo/Markdown-Minimap

A minimap for Markdown notes inside the Obsidian editor pane, giving a scaled-down view of the whole note in the way a code editor does. The README contrasts it with implementations that clone the editor DOM and so only cover the part of a virtualized long note currently on screen: this one renders the entire note independently and lays the panel out at the note's own text width, margins, line height and font, mapping scroll position through anchors shared by both rather than by one scaling ratio. Clicking, dragging or scrolling over the minimap moves the note, Live Preview, Source and Reading modes each get their own map, and settings control default enablement, scale, panel opacity and the viewport marker.
