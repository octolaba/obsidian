# ashishbhateja/obsidian-url-cleaner

URL Cleaner strips tracking parameters from the URLs in the current Obsidian note through a single command. The README lists the parameters it removes, covering the utm family, the click identifiers from Facebook, Google and Instagram, two mailing-list parameters, and several referral parameters, and shows a before and after example on a social network link. Installation is described from the community plugin directory or by copying the release files into the vault.
