# kylemcd/obsidian-document-comments

Document Comments adds inline comments to Obsidian notes, showing each one as a card beside the text on desktop and storing it inside the Markdown file as an HTML comment instead of a separate database, so other editors, version control tools and agents can read it. Comments attach to prose, inline code, tables and selected lines in fenced code blocks, where the comment block also stores the selected line range and exact code text, and a comment can be replied to, resolved, reopened, edited, deleted or reacted to, with Markdown allowed in its body. Cards appear in Live Preview, Source and Reading views, long comments open in the sidebar, and the sidebar filters by open, resolved or all while comments can also be hidden entirely. The README states that Obsidian 1.7.2 or newer is required and that desktop and mobile are supported.
