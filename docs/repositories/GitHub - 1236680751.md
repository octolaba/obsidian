# Yan-Vieira/obsidian-chess-puzzles

This repository holds Chess Puzzles, an Obsidian plugin for creating and reviewing chess puzzles in Markdown notes on a spaced-repetition schedule. A deck is any note carrying the chess-puzzles tag in its frontmatter, and a puzzle is a chess-puzzle code block giving a FEN position and the expected best line. Four review modes cover a single puzzle, a single deck, only pending puzzles, and every puzzle in the vault. Review history and scheduling are stored inside the Markdown block itself, so puzzles move between vaults without losing progress; the README frames the plugin as a way to build a personal collection from one's own games and mistakes.
