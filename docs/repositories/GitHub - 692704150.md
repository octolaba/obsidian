# fnya/merge-notes

Merge Notes merges several notes selected in the Obsidian file explorer into a single note. The notes are selected, Merge notes is chosen from the right-click menu, the order can be rearranged by drag and drop, and a file name is given for the result, with a confirmation popup when the name is long. The merged note is created in the same folder as the first note of the selection. The README credits the dnd-kit library for the reordering.
