# chiahsien/obsidian-kohi

KOHi imports highlights and notes from KOReader into an Obsidian vault. It scans a mounted KOReader device for sdr metadata directories, covering all three KOReader storage modes, parses the Lua-serialized annotations, and writes one Markdown note per book into a configured output folder. Note and filename output is controlled by Nunjucks templates with book-level variables such as title, author, language, pages, keywords, description, series and import date, and highlight-level variables for text, note, chapter, page, timestamp and colour. Books can be imported all at once or picked by fuzzy search, illegal filename characters are sanitized, and re-importing overwrites the existing note by default.
