# twentytwokhz/quote-of-the-day

Quote of the Day inserts a random quote into an Obsidian note as Markdown, drawing it from the Quotable API, which the README credits to its author. Two default hotkeys are recorded, one inserting a random quote of the day and the other a tag-based random quote, and the quote can also be placed through a template token. Settings control the format in which the quote is displayed, the format used for its tags, and whether the tags appear in the quote's footer.
