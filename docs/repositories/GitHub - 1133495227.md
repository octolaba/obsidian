# goryugocast/atomic-insights

An Obsidian plugin that surfaces structurally related notes from the vault's own link graph, scoring pairs with the Adamic Adar index and optional metadata and time signals. The README explains the choice of that index: a link shared through a widely referenced page is weak evidence, while a shared link to a page only a few notes point at indicates a more specific alignment, so small focused notes sharpen the results. It also states that this structural signal is invisible to text-similarity models and exposes the same data through an API intended for AI agents. The repository description is written in Japanese.
