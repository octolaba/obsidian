# FrancescoUmberto/GoodBases

A custom Bases view that renders a base as a table in the style of Notion: hairline borders, a hover wash, a horizontal scroll container, an open button revealed on row hover, and list properties shown as coloured pills. Pill colours are assigned by a deterministic hash so a value keeps its colour, and can be overridden per value from a picker or in bulk through a pinned-colours view option. Cells edit inline — text and numbers in a floating input, checkboxes in place, and pill cells through a searchable select menu that can create new values — while a page panel opens a note centred in the view with an editable title, editable properties and a body that renders as Markdown and switches to source on click. The README requires Obsidian 1.10.2 or later with the Bases core plugin enabled, and records grouping support and per-view options.
