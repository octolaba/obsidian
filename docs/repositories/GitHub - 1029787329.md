# pedroaraujo74/screvi-obsidian-plugin

This repository is the official Obsidian plugin maintained by the Screvi team, and it exports highlights from Screvi into a vault. The README describes syncing automatically at a configurable interval or on demand, with highlights organised by source type such as books, articles and tweets, and an API key from a Screvi account entered in the plugin settings. It records that the plugin contacts a single host for that purpose, polls it every two hours by default while auto sync is on, and states that it sends no analytics, telemetry or other data — claims recorded here as the project's own.
