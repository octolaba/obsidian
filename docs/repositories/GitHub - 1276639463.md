# anandrajbaghel/obsidian-custom-tag-color

The repository holds Custom Tag Color, an Obsidian plugin that colours tags according to regular-expression rules, so names, prefixes, numbering schemes, dates, times and other patterns can each get their own colour. The first matching rule wins, a complementary background colour is derived from the assigned text colour, and rules are added, edited, removed or reset to the default examples from the settings panel. The README gives example patterns for exact names, dates, times, prefixed and purely numeric tags, and states that the plugin works on desktop and mobile.
