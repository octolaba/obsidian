# Nitero/obsidian-mermaid-base-views

Mermaid Base Views adds view types to Obsidian bases that render the base's results as Mermaid diagrams: flowchart, mindmap, timeline, sankey, pie chart, XY chart and quadrant chart. The flowchart view shows notes as labels carrying either clickable links or selected properties, draws links between them as lines labelled with the property name, and boxes each group, while the timeline view orders notes by a chosen time property with a year, month, day or hour cutoff. A Mermaid config can be set globally in the plugin settings as frontmatter config, per view type, or overridden on an individual view using directive syntax.
