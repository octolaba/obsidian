# trikorka/wonderful-cards

Renders item cards for Dungeons & Dragons inside Obsidian notes from an `itemcard` YAML code block. The card fields cover the item name, an optional English title, an image given as a URL or a vault link, type and subtype, rarity, attunement, price, text alignment and a description, and a command inserts a blank card template. Items can be kept in a global catalog, and a card is previewed inline in any note through a short reference syntax or by clicking an internal link. The README's example is written in Russian.
