# mkali-personal/obsidian-comments-with-notifications

Obsidian plugin for leaving structured comments in a shared vault and notifying the people they address. The README states that a comment is an Obsidian callout inserted by a command or from the right-click menu, tagging one or more members through a member tag syntax and carrying a timestamp hidden inside an HTML comment. A ribbon bell shows a badge for unread comments addressed to the current user and a sidebar panel lists them by date with a preview and a click-to-navigate link; the username is set per machine, so one synced vault can serve several people.
