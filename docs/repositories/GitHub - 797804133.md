# jcollingj/caret

Brings language models into an Obsidian vault while keeping the data local: the README states the plugin is local-first, stores everything it creates or consumes as Markdown files in the vault, and calls no external service other than the model provider itself. Its features are an AI canvas for non-linear chat inside the Obsidian Canvas, a chat that can reference other files in the vault with the logs stored as vault files, and support for local or remote models, with Ollama, OpenAI, Anthropic, Groq and OpenRouter built in and further models addable. The README opens with the author's note that the plugin is no longer actively maintained.
