# jcacdc/obsidian-kanban-sync

Kanban Sync keeps a status field in a note's frontmatter in step with the column its card occupies on a Kanban board. It watches a configured comma-separated list of Kanban files and, when a card linked to a note moves between columns, writes the column name in upper case into the configured frontmatter field after a configurable delay in milliseconds. Columns are recognised from headings and cards from checkbox items carrying a link to the note. The README states that Obsidian 0.15.0 or newer and an installed Kanban plugin are required, and recommends the Obsidian Kanban plugin for the board itself.
