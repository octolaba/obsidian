# LarrySAL/pinyin-replacer

Pinyin Replacer allows pinyin notes to be typed without installing another keyboard layout. Four commands replace the vowel behind the cursor with its toned version, one command per tone, and a fifth removes the tone, each bound by default to Alt with a digit or with R. The letter v produces the u-umlaut tones in the same way as the plain vowels, and a status bar item is added to remind the writer of the order of the tones.
