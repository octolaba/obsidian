# addozhang/obsidian-mermaid-exporter

Mermaid Exporter adds a download button beside the native edit control on a rendered Mermaid diagram and saves it as a PNG through the system file dialog, in both Live Preview and Reading mode. The export reproduces the diagram exactly as Obsidian renders it, including the current theme, at a scale factor between one and four times, defaulting to two. The README records the requirements as Obsidian 0.15.0 or later and desktop only.
