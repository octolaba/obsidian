# bkindler/amber-cathode

This repository holds Amber Cathode, a dark Obsidian theme inspired by 80s amber CRT monitors and bulletin board system aesthetics. It combines a monochrome amber phosphor palette with a scanline overlay, a heavy screen vignette, an SVG grain simulating dot pitch, a text-shadow glow, a barely perceptible flicker animation, IBM Plex Mono or JetBrains Mono throughout, and zero border radius for a terminal feel. The repository also ships a BBS-themed showcase file containing ASCII art, BASIC code and other retro content.
