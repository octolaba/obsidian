# Acylation/obsidian-chem

Chemistry support for Obsidian: SMILES strings are rendered as chemical structures. The README states that the strings are written one per line in a code block using smiles as its language, and that the rendering is done by Smiles Drawer and RDKit.js while the data itself stays plain text in the note. An optional inline render recognizes code spans carrying a configurable prefix, structure scale, image size and light or dark theming are set globally in the plugin settings, and open notes are re-rendered when those settings or the Obsidian color scheme change. Images can be copied as png from their right-click menu and pasted back into a note.
