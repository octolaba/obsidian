# aleff-github/vuln-report-kit

Vuln Report Kit turns an Obsidian vault into a structured workspace for vulnerability research documentation — responsible disclosure notes, bug bounty writeups, CVE research notes and sanitized report drafts. Its workflow runs from creating a case and documenting target, reproduction, impact, evidence, remediation and timeline, through a local dashboard and starter or professional templates, to generating a final Markdown report, scanning locally for possible secrets, producing a sanitized public copy, and exporting bundles, shareable folders, indexes and template backups. The README states that the plugin works on Markdown files inside the vault and requires no server, account, cloud database, API key, external AI service or license server.
