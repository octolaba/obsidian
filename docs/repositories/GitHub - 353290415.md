# roovo/obsidian-card-board

Shows the tasks already present in a vault on kanban-style boards. The README states that any task or subtask anywhere in the vault can appear as a card, provided it sits in a Markdown file, is not indented, and uses one of the recognized task formats. Two column types are supported and can be mixed on one board: date-based columns, which work with daily and periodic notes, and tag-based columns defined by tags. Boards are opened from the ribbon icon or the command palette, and columns are added, edited, reordered or deleted in the plugin settings.
