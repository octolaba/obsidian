# iLiftALot/insta-toc

The recorded description says the plugin generates, updates and maintains a table of contents for notes while typing, in real time. The README states that inserting its code block is all that is required, contrasting this with other table-of-contents plugins that regenerate on command activation. Individual headings can be excluded by a marker appended to the heading or through local settings, HTML and special symbols inside headings are handled with a configurable set of characters to escape, and any heading hierarchy is accepted rather than a prescribed structure. Installation is documented through Obsidian, BRAT, npm or manual copying.
