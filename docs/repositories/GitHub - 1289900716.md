# Temsys-Shen/ostracon-ob

Obsidian plugin that connects a vault with MarginNote: it receives Markdown, HTML and Canvas cards sent from MarginNote, browses and filters them in a right-hand panel before importing, and renders Obsidian documents to PDF for import into the current MarginNote study set. Export settings cover paper size, orientation, margins, scaling, background, media height and headers and footers. The two sides talk over a local or LAN WebSocket that the Obsidian user approves on first connection, and the README states that no Ostracon cloud service is involved and that content is read or written only when a send, import or export is run. It requires desktop Obsidian at a stated minimum version, MarginNote on macOS with its companion plugin, and does not support Obsidian mobile.
