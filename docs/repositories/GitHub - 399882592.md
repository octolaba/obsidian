# elias-sundqvist/obsidian-annotator

Annotator opens PDF and EPUB files for reading and annotation inside Obsidian, storing the annotations in a local Markdown file rather than on a remote service. The file to annotate is named in a note's frontmatter property, pointing either at a file in the vault or at an online address, with a second property available when the type cannot be inferred from the path; an annotate entry then appears in the note's options menu. The README records the plugin as based on a modified version of the Hypothesis reader, warns that renaming the original PDF or EPUB breaks the link between the file and its annotations, and lists known issues on newer iOS versions and with annotations changed on another platform.
