# fxal/obsidian-youhavebeenstaring-plugin

YouHaveBeenStaring reports in the Obsidian status bar, in natural language, how long the vault has been open since the plugin was loaded, and optionally how long it has been open in total. The README frames this as a reminder to take a break from the screen. The display text is customizable for both durations, the counter can be started and stopped from a ribbon button, and actual days, hours and minutes can be shown instead of the humanized duration. Accumulated time is saved every ten minutes and on settings changes, plugin unload and ribbon toggles, to limit disk writes.
