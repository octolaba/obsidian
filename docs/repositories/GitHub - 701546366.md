# lucagrippa/obsidian-ai-tagger

AI Tagger analyzes the document currently open in Obsidian, together with the tags used before, and tags it in one click. The README states that it returns up to five relevant tags already in use and generates up to three entirely new ones. It works with models from several providers — OpenAI, Mistral AI, Anthropic, Google and Groq are tabulated with their token limits and whether the model is open source.
