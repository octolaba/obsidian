# natri0/obsidian-bytefield

Renders byte-field diagrams, the tables that show the offsets of fields in structures such as network packets. The README states that a diagram is written in a bytefield code block with one field per line, each line giving a name, a colon and space as the delimiter, and a length in bytes; lines without that delimiter are ignored silently and can serve as comments. A special first entry moves the offset the diagram starts at, omitting the name before the delimiter produces unnamed padding that still takes up space, and fields longer than a row wrap around. The README also notes that the project is built with Bun rather than the usual toolchain.
