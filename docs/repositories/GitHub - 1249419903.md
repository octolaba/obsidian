# rafaelmehdiyev/obsidian-reference-note

Creates a new note by cloning the frontmatter properties of an existing one, so a set of properties does not have to be retyped. It is triggered from a ribbon icon, a command, or the file explorer's right-click menu on any Markdown note. A modal then offers the new note's name, pre-filled from the source, a checklist of which property keys to carry over — all checked except keys named in a default-excluded setting — a searchable target folder defaulting to the source note's folder, and an option to add a `source` property linking back to the original.
