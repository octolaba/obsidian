# akaalias/dangerzone-writing-plugin

Repository for Dangerzone Writing, an Obsidian plugin that starts a timer during which writing has to continue: the recorded description states that pausing for more than five seconds deletes everything written in that note. The README describes starting a session from a stopwatch icon in the left bar, watching the countdown, and writing without stopping until it ends. The author presents it as a way to warm up, to get a first draft down however rough, and to stay focused, and recommends beginners start with the defaults in an empty note.
