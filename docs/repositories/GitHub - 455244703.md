# thisdotrob/obsidian-relativenumber-plugin

The repository holds an Obsidian plugin that enables relative line numbers in the manner of Vim's relativenumber option, working in both Live Preview and the legacy editor mode. Its README records one prerequisite: Obsidian's own show line numbers option has to be turned off first. It credits an earlier relative line numbers plugin for part of the legacy-mode code.
