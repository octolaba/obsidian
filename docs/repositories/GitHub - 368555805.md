# acidghost/obsidian-checklist-progress

Fills in the progress of a checklist as a fraction or a percentage. The README shows a marker written in a list line, an empty fraction or percent sign, being rewritten by the plugin's command into the completed count over the total or the matching percentage for the tasks nested under that line. Besides the command, which can be bound to a shortcut, the README documents optional auto-updating when a checkbox is toggled in Live Preview, and a leading minus that counts unchecked boxes instead. It states the behaviour is meant to mimic a similar feature of Emacs Org Mode.
