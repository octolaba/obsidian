# Canna71/obsidian-sheets

Obsidian Sheets works with tabular data in Obsidian, either storing it inside the note or in an external XLSX, XLS or CSV file. A sheet is created from a code block named sheet, whose properties set the file path, save behaviour, dimensions, font size and cell geometry; when a filename is given the data is loaded from that file and created on save, and otherwise the data lives in the code block itself. The README states that saving to external files is disabled by default because information is generally lost, and records what each format preserves: everything when saving to the code block, most formatting for XLSX, data and cell merges only for XLS, and data alone for CSV.
