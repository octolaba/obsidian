# mdfriday/obsidian-sync

MDFriday Sync synchronises an Obsidian vault across devices through CouchDB with end-to-end AES-256 encryption, on desktop and mobile. The README describes it as building on the Self-hosted LiveSync core and adding a managed open-source backend: with a license key the database, authentication and connection credentials are provisioned automatically, or the hugoverse backend can be self-hosted instead. It records real-time sync, hidden-file sync of the configuration folder, conflict handling and per-file-type selective sync, and compares itself in a table against Obsidian Sync, Self-hosted LiveSync and Remotely Save.
