# Ahmed-Farhat99/core-habits

The repository holds Core Habits, an Obsidian habit tracker whose data lives in daily notes as standard Markdown checkboxes rather than in a separate database. Toggling a habit on its weekly grid finds or creates the daily note and writes the checkbox into a dedicated section, with a compact layout when the view sits in the sidebar or on mobile, and habits can be nested as parent and child. The README describes the plugin as offline and local-first, relying on a local cache and non-blocking file writes; those privacy and performance claims are its own.
