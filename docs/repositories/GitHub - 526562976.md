# jqhoogland/obsidian-squiggle

The Squiggle plugin executes Squiggle code blocks inside a note, adding a run button to blocks in the supported language and showing the result once execution finishes; prefixing the language name with a run marker renders the block in preview so it can be executed there as well. Syntax highlighting is added with Prism. The README records the plugin as forked from the execute-code plugin, states that text cannot be entered into a running program, warns against executing code from unknown sources, and describes a known problem where the run button can disappear after a theme switch.
