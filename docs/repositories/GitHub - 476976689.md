# nekoshita/obsidian-auto-card-link

Obsidian plugin that fetches metadata from a URL and renders it as a card-styled link. The card comes from a cardlink code block written in YAML, with url and title required and description, host, favicon and image optional, so notes keep Markdown instead of HTML tags. Commands enhance a pasted or a selected URL, default paste can be set to enhance automatically, and local images referenced through internal links are supported. Styling comes from the plugin's own stylesheet and can be overridden with CSS snippets.
