# acaprino/obsidian-plugin-homepage

Homepage Blocks is an Obsidian plugin providing a composable, drag-and-drop homepage assembled from blocks. The README records 17 block types — greeting, clock, quotes, quick links, button grid, image gallery, video embed, embedded note, static text, HTML, bookmarks, recent files, pomodoro timer, spacer, random note, voice notes and vault search — arranged in an edit mode entered from the homepage view and reachable from a ribbon icon or a command. Layout is recorded as drag-and-drop with column-span and row-height resizing on GridStack, reflowing in narrow panes through CSS container queries, with per-block styling for title, emoji, divider, padding, elevation, border, opacity, backdrop blur and gradients, accent colours at adjustable intensity, and collapsible block headers.
