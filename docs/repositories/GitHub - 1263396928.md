# LiveAQuietLife/obsidian-index-cards

Index Cards adds a card-based capture workspace to Obsidian for jotting down ideas, reading notes and sources, organised into projects and categories and exported into the vault when a project is finished. The README distinguishes it from card plugins that render existing vault notes in a grid: this is a capture layer beside the vault, modelled on physical research index cards, where cards are created quickly, reorganised and then moved into permanent notes rather than accumulated. An optional Academic Mode, off by default, adds citation fields, a parser for bibliography text copied from tools such as Zotero, Google Scholar and Logos, and bibliography generation in the Chicago, SBL, MLA, APA and Turabian styles. The README marks the plugin as desktop-only.
