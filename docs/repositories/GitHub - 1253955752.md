# aiken884/obsidian-h1aligner

The repository holds H1Aligner, an Obsidian plugin that renames a note's file to match its first H1 heading, in that direction only. The README records five trigger modes — on opening a note, a couple of seconds after typing stops, both, on leaving a note, or manual only through commands — and states that edit-triggered renames respond to local typing rather than sync writes or programmatic updates, and that a hand-renamed file snaps back unless a frontmatter key locks that note. Renames are recorded as going through Obsidian's own rename call so backlinks follow, behind a protection chain of frontmatter locks, daily-note protection, folder allowlists and regex excludes, filename sanitisation and collision detection aware of case-insensitive filesystems. A vault-wide dry-run preview and a 20-step undo are also recorded.
