# agctute/relative-timestamps

Relative Timestamps inserts the current time together with the interval that has passed since a reference timestamp, so entries in a log show the span between them rather than only their clock times. The reference point can be set explicitly and a command resets it to the current time. The README states that the plugin was made for personal use in food logs and diaries, that it is barebones and rigid in its present state, and that contributions, particularly around formatting settings, are welcome.
