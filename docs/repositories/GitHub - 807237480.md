# wwwkieran/obsidian-multiplatform-highlights-import

Multi-Platform Book Highlight Importer is an Obsidian plugin that pulls highlights and annotations from several reading sources into a vault, with Kobo and Apple Books supported at this README. Books are reconciled by ISBN or title, so the same book read on different devices produces a single note carrying all its highlights, and the note format is the same regardless of which platform the annotations came from. Reading services are enabled and configured on the plugin's settings page, some extractors needing extra configuration, and extraction is triggered from an eBook icon in the sidebar or the Import multiplatform highlights command.
