# ShaktiSampadSwain/minidoro

Minidoro is a Pomodoro timer drawn as a circular progress indicator in the header of the active pane, with a hover-activated control panel that can be pinned open. Left-clicking the time display starts, pauses and resumes a session, right-clicking resets it, and clicking the mode name while idle cycles between Work, Short Break and Long Break. Session durations, the number of work sessions before a long break, automatic start of breaks or work, desktop notifications and an end-of-session sound are configurable in the settings.
