# dbrockman/obsidian-change-case

Changes the case of the current editor selection. The README lists one command per target case, among them lower case, upper case, camelCase, Capital Case, CONSTANT_CASE, kebab-case, PascalCase, snake_case, Sentence case and Train-Case, plus a command that offers the same list in a selection modal. It states that multiple selections are handled and committed as a single editor transaction, so one undo reverts them all and changes in string length do not disturb the following selection. Case conversion uses locale-specific mappings taken from the Obsidian settings with the browser language as a fallback, and letters written as multiple Unicode characters are grouped before conversion.
