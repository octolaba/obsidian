# chrisgrieser/shimmering-focus

Shimmering Focus is a minimalistic and opinionated Obsidian theme for the keyboard-centric user, recorded in its README as the winner of Obsidian October 2022. Its stated design philosophy is minimalism applied to the interface rather than to colours: elements not relevant to keyboard users are hidden or shown only when needed, unnecessary padding and white space are removed, and more than a hundred settings are exposed through the Style Settings plugin. Listed features include a tab bar shown only when several tabs are open, image alt-text used as a caption with click-and-hold zoom, heading and table styling options, community-submitted colour schemes, and emphasis of Pandoc citations and footnotes.
