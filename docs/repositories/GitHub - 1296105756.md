# ansango/obsidian-metadata-links

Obsidian Metadata Links fetches the title, description, image and icon for the URLs in a selection and stores them in a metadata-links code block, which is rendered as a card in Reading view and Live Preview. Two templates are provided, a card showing image, title, description and URL and a compact single-line link, chosen per conversion from the editor context menu or set as a default for the command palette. A separate command converts the blocks in a selection back into plain URLs, and editing the block's fields or its template value by hand re-renders it. Settings cover the default template and whether a conversion replaces or appends to the selection.
