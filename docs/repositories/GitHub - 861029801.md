# jackvonhouse/custom-node-size

Custom Node Size lets a note set its own size in Obsidian's graph view through a numeric node_size property in its frontmatter, overriding the weight that Obsidian otherwise derives from the number of references to the note. The README states that the visible effect was found experimentally to span values from 6 to 100, and warns that a property of any type other than numeric causes unexpected behaviour.
