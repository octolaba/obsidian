# sotashimozono/obsidian-remote-ssh

Opens and edits an Obsidian vault that lives on a remote server over an SSH connection, comparable to how VS Code's Remote-SSH works, serving files, attachments, search and live updates from the remote host rather than keeping a full copy locally. Two transports are offered: an RPC transport, for which the plugin fetches a matching helper daemon from its signed GitHub release under a one-time confirmation with sha256 verification and uploads it to the host, and an SFTP transport that needs no remote-side binary. The README states that no cloud or sync service is involved and that only the material being viewed is held locally.
