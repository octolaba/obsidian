# Mijyuoon/obsidian-ling-gloss

Ling Gloss is described as a plugin for the interlinear glosses used in linguistics texts, aimed in particular at constructed-language documentation kept in Obsidian. Glosses are written in a fenced block tagged gloss, where commands mark the source-language line, the metalanguage line and an optional third line such as a transcription; the elements of each line are space-separated and aligned vertically, with the first level italicized by default. Square brackets group an element containing whitespace, a caret escapes a literal bracket, and an empty pair writes a blank element; a further command adds a free translation line at the bottom. Lines beginning with a hash and blank lines are treated as comments and ignored by the parser.
