# EurFelux/obsidian-another-name-plugin

Another Name shows a second name under a note's inline title in Obsidian. The text is read from a note property called another-name by default and changeable in the plugin settings, and the inline title has to be enabled in the appearance options for it to appear. The README gives the motivation: the author writes notes about a concept in Chinese and wants the English name of that concept displayed under the title instead of appended to it.
