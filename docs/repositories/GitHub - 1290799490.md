# Cong-xu/flowboard-pm

FlowBoard PM is a project-management board for Obsidian with Linear-style lanes and cards, storing each board as a local .pmboard file inside the vault and needing no external service. Boards carry backlog, todo, in progress and done lanes, and a card holds a title, context, project, owner, stage, type, priority, due date and tags; cards are created, edited and deleted from the board, searched, and moved between lanes by drag and drop, which updates the status and saves automatically. Board-level project metadata such as project name, colour, owner and description is edited from a configuration button at the top of the board. Commands create either a blank board or a sample one, and the README is partly written in Chinese.
