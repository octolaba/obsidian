# dralkh/spaceforge

Repository for Spaceforge, a study plugin combining spaced repetition with question generation and timed sessions. The recorded description and README name the FSRS and an enhanced SM-2 algorithm for review scheduling, with configurable scheduling parameters, generation of multiple-choice questions from notes through OpenAI, OpenRouter, Ollama, Gemini, Claude or Together, an integrated Pomodoro timer, and a calendar event manager.
