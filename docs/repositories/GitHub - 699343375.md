# your-papa/obsidian-Smart2Brain

Your Smart Second Brain is a free and open-source assistant that reads and processes the vault's own notes: notes are embedded as vectors, retrieved by similarity to a query, and used to generate an answer that references the notes it came from as Obsidian links. Chats can be saved and continued later and shown in a comfy or a compact view, and note-based answering can be switched off so replies rest on the model's training knowledge instead. The README records Ollama as the way to run models locally with quick switching between them, ChatGPT as a supported alternative, and the plugin as able to operate completely offline so that data stays private.
