# arpitbbhayani/obsidian-hackernews

The repository holds Obsidian HackerNews, a plugin that periodically fetches a top story from Hacker News and shows it in an Obsidian pane. Its README records that a displayed story can be saved as a note so it can be revisited, and covers installation from the community plugin browser and opening the pane from the command palette. It is written in TypeScript under the MIT license.
