# diagonalcounty/blinks

Blinks adds phrase-searchable block links to Obsidian. Typing two carets inside a wikilink — open or already closed — opens a picker that ranks the blocks of that note by phrase and inserts a link using a readable slug id rather than a random hex id, writing the slug onto the target line if it is missing. The resulting link is an ordinary Obsidian block link that still works when the plugin is off, and display text is handled by the core alias syntax. Commands cover inserting a block link by picking a note, in the current note, for the wikilink at the cursor, and realigning a slug and its inbound links after the opening words change.
