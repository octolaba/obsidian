# johannes-kaindl/epub-exporter

Obsidian plugin that exports notes as EPUB3, either a single note or a whole book. A book note is the single source of truth: its frontmatter carries the metadata and its ordered embeds form the chapter spine, so the assembled book is visible in reading view without a separate project file. Chapters can be reordered from a sidebar by dragging or with a hotkey, a folder can be exported as a book or imported as a book note, and a book note can be consolidated into a folder of numbered chapter files with an assets directory. Per-chapter frontmatter can override the title in the table of contents or exclude the chapter.
