# kzhovn/copy-command-obsidian

This plugin adds a Copy active note command to the command palette and the file menu that mimics the make a copy behaviour of the file explorer menu, and a Copy folder command that copies a selected folder together with all its contents. The recorded README is a single sentence, and it states nothing further about settings or behaviour.
