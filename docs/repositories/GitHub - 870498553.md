# nyable/obsidian-text-finder

Obsidian Text Finder provides a find and replace window in editing mode resembling the one in VS Code. The README records searching and replacing within the current Markdown file, highlighting of matching text, a count of the matches, regular expression support, case sensitivity and input history. Searching or replacing inside a selection is listed as still to do, and the README notes that the Obsidian API is early and subject to change.
