# Simratt/obsidian-caretsort

This repository holds Caretsort, a table sort for Obsidian named after the caret the user clicks and, as the description puts it, with a nod to quicksort. It adds a small caret beside every column header; clicking it offers A to Z or Z to A for text and ascending or descending for numeric values, and the chosen order is written back into the Markdown file on disk rather than applied only to the view. The last sort can be undone from reading view through an undo command that carries no default binding. The README states that the plugin makes no API calls and uses no external services or configuration files.
