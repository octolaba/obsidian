# lajg-dev/Obsidian-Plugin-GPG-Inline-Encrypt

GPG Encrypt performs inline or full-document encryption of Obsidian notes using the operating system's native GPG tool. In that default mode the full path of the gpg executable is entered in the settings and validated as it is typed, the keys found on the system are listed for information, and flags decide whether stored keys are always trusted and whether encrypted text is also signed with a selected private key. The GPG Library setting can instead select OpenPGP.js, which encrypts in-app from an armored key pasted into the settings and runs on desktop as well as Android and iOS, whereas the CLI mode is desktop only and works with the OS keychain and security keys such as YubiKey.
