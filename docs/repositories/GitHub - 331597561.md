# xpgo/obsidian-folder-note-plugin

Attaches a description note to a folder so that a vault can be read as a hierarchy of notes: ctrl-clicking a folder in the file explorer creates the note, clicking the folder opens it, and deleting the opened file removes it. Three placement methods are offered, inside the folder, outside it, or as an index file, with the inside-folder method as the default, and the note file is hidden by CSS rules. The plugin keeps folder and folder-note names in sync, allows a customised initial note content, and renders folder contents as card or strip views, including a ccard code block.
