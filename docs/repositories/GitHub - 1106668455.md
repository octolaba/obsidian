# li-xiu-qi/obsidian-auto-tags

An Obsidian plugin that generates tags for a note with a large language model. Its recorded inputs, written mainly in Chinese, state that it analyses the open document together with the tags already used in the vault and returns up to five relevant existing tags plus up to three newly suggested ones, written into frontmatter through Obsidian's processFrontMatter API. Tagging runs from a ribbon icon, from the command palette over selected text, or recursively over a file or folder, and settings cover the API key, model, custom OpenAI-compatible or Ollama endpoint, prompt language and lowercase tags. The README records the project as derived from lucagrippa/obsidian-ai-tagger.
