# madebydia/obsidian-retro-terminal-theme

Retro Terminal is an Obsidian theme drawing on amber phosphor terminals and the original Macintosh. Its dark mode puts warm amber text on deep black with cyan links and tags, a scanline overlay, a soft text glow, a prompt prefix on H1 headings and a blinking block cursor, while its light mode reproduces the 1984 Macintosh look with a near-white background, pure black text, one-pixel borders and inverted selection highlighting. Both modes use a monospace stack from Monaco through Courier New, square corners, always-underlined links, minimal scrollbars and a 14px base font size.
