# davidjroos/obsidian-notswift

Notswift is an attempt to style Obsidian so that it looks more at home on macOS, written after the author found the existing options Big Sur Aesthetic and California Coast dead. The design comes from looking at Mail, Finder and Notes rather than Apple's style guides, and it requires the Apple San Francisco Pro and Mono fonts because the CSS names them directly. Mac-oriented changes include light and dark colours, a fat header bar with sidebar toggle buttons repositioned, square file tabs with the close button on the left and the dropdown moved, a fake red close circle in settings and dialogs, resized and recoloured toggles, styled buttons and dropdowns, and checkbox and bullet shapes matching Notes. The author states that parts of the interface, such as the ribbon and the back and forward buttons, still do not work as wanted.
