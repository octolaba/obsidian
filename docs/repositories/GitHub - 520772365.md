# Mara-Li/obsidian-group-snippets

The repository holds Group Snippet, an Obsidian plugin that collects CSS snippets into named groups so a whole group can be enabled at once. Its README records that a group is created and filled in the plugin settings, that activating it enables the snippets it marks as enabled and disables the others, and that groups are reachable both from the settings tab and from command palette entries for reloading groups and activating one by name. A group can also be tied to a theme, so switching theme, including switching between light and dark, switches the snippets with it.
