# tttnny/obsidian-claude-cream

Claude Cream is a minimal Obsidian theme for light and dark modes, documented in English and Chinese, that reproduces the warm, scholarly look of Claude.ai down to its dark palette base of #262624. Its README states that the Anthropic Serif, Anthropic Sans and Anthropic Mono fonts are embedded in the theme as Base64, so no internet connection and no system font installation are required. Editing view and reading view are aligned to the same maximum width of 752px, the same line height of 1.65, and the same spacing and type sizes. Accent elements use the clay-orange #D97757, with hand-drawn checkbox styles and clay-orange wavy underlines for highlights, while cards, sidebars, tables and callouts keep minimal borders.
