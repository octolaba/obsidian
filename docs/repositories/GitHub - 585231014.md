# alangrainger/obsidian-image-captions

Renders the text placed in an image embed's caption position as a visible caption under the image, using either the wiki embed form or the standard Markdown image form. The existing width parameter still resizes, and center, left or right keywords float the image. Captions accept inline Markdown and Markdown links, with angle brackets substituting for square brackets when a wikilink is wanted, and a percent sign expands to the filename with or without its extension. A configurable regex strips data that other themes or plugins place in the description field; the README states that external images do not show captions in editing or live preview mode.
