# bgoosman/obsidian-project-garden

The repository holds Obsidian Project Garden, a plugin that gathers projects into a single view opened from the left ribbon. Its README records the convention it relies on: notes placed under a projects folder appear as cards in that view, and tasks written in a project note show up on its card. The recorded inputs describe no settings beyond that convention.
