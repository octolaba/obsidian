# madx/blueprint-obsidian-plugin

Blueprint is a templating plugin for Obsidian built on the Nunjucks templating engine with additional features. The README describes propagating changes made in a template out to the notes built from it without losing their content, using frontmatter properties in notes, and quickly creating new notes from a template. The author records that the plugin is mostly developed without AI-assisted development tools and that blatantly vibe-coded contributions are not accepted, while Claude Web is occasionally used to improve the documentation's wording.
