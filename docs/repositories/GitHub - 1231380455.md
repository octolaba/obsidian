# henriquemanduca/mysync-plugin

This repository holds MySync, described in the repository as a proto plugin for syncing vault files with a remote CouchDB server. It keeps a local PouchDB index of the vault and then pushes that state to CouchDB or pulls the remote state back, covering the full vault or one folder inside it plus the top-level configuration files, and tracking Markdown files, PDFs and common image formats. The README records a connection test, sync progress and last push time in the status bar, an option to sync when the plugin loads, and requirements of Obsidian 1.12.7 or newer with an existing CouchDB database and a user with access to it. It warns that pulling can restore, overwrite or delete local files according to the remote state, so the vault should be backed up first.
