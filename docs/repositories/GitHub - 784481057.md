# jacoblearned/obsidian-template-by-note-name

Template by Note Name applies a template to a note automatically according to the note's name, at creation time and optionally on rename. The README records rules that match by prefix, suffix or contains against any template in a configured templates folder including its sub-folders, an option for case-sensitive matching, and examples such as notes beginning with a given word taking a particular template file. When a note is renamed into a matching rule, the template content is prepended to the existing note.
