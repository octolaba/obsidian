# deemsd/timeline-calendar

Timeline Calendar presents daily notes and their tasks as a calendar with month, week, day and agenda views, and a timeline layout in which the time labels line up with the grid lines. Time-stamped tasks and list items are read out of daily notes, supporting timed events, all-day tasks, drag and drop and resizing, and selecting an event opens the note it came from. The recognised entries are task or list lines beginning with a time or a time range. Settings choose whether the week starts on Sunday or Monday, which heading receives new events, which section of a daily note is processed, and the visible time range of the week and day views.
