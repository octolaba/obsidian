# Newbrict/obsidian-obligator

Obsidian plugin that replaces and extends the built-in daily notes plugin. When a new daily note is made, unchecked to-do items are copied over together with the headings and formatting structure that organised them, along with any scheduled notes that were set up, which leaves a running history of earlier notes to refer back to. A sidebar icon opens today's note and creates it if it does not exist; the README documents template macros, a date format that may contain directories so notes nest in folders, and the caveat that the archive function will not delete directories when such a nested structure is used.
