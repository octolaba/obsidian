# zsviczian/obsidian-excalidraw-extras

Excalidraw Extras is a companion package for the Obsidian Excalidraw plugin and, by its README's own statement, does nothing on its own: the main plugin hooks into it. It exists to hold the pieces carved out of that plugin — the MathjaxToSVG and MermaidToExcalidraw engines, which are large dependencies, and high-privilege operations such as file system access beyond the vault API, outbound network access, and Electron IPC calls used for PDF printing and export. The README states that the split keeps the core plugin small and fast and compliant with Obsidian's community security policies, and notes that the eval and btoa logic needed for loading the Excalidraw canvas stayed in the core plugin.
