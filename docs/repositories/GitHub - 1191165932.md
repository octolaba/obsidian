# gtritchie/bulk-properties

Bulk Properties edits properties on, or deletes, several notes at once. Notes are marked with a checkbox property — named selected by default — and the command then acts on every note in the vault whose box is checked, which the README warns is not limited to the notes visible in a particular Base. Settings name the selection property, list the properties available for bulk editing with their types (aliases, checkbox, date, date and time, list, number, tags and text) in a draggable order, and set whether the selection is cleared when finished. The README states the plugin is intended for relatively small sets of notes, because a large operation can leave Obsidian's metadata cache re-indexing for minutes while property-driven views show stale information.
