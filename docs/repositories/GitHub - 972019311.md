# kdnk/obsidian-easy-link-to-daily-note

Obsidian plugin that creates a note whose filename is a timestamp and appends a link to it in today's daily note, so a quick capture needs no name but stays connected to the daily log. It is run from a command in the palette that can be given a hotkey, and it can additionally append links for Web Clipper notes carrying a clippings tag. The README records that Obsidian's core Daily notes plugin must be enabled and its folder configured first.
