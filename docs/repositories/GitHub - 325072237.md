# akaalias/obsidian-extract-pdf-highlights

The repository holds a plugin that extracts highlighted and underlined text and annotations from PDF files into a Markdown note in the vault. Its README records the workflow as dropping a highlighted PDF into the vault, opening it in Obsidian and clicking a PDF icon in the left sidebar. Optional settings, all off by default, add the page number, the highlight color and links; the README also carries a backlog of planned work, including grouping highlights by color and a progress indicator for longer documents.
