# OnlyWorlds/obsidian-plugin

This plugin manages OnlyWorlds elements as Obsidian notes, one note per element, in a folder per category inside an OnlyWorlds folder in the vault. Since version 3.0.0 each element's fields live in the note's properties and link fields are clickable internal links, so that relationships between elements appear as ordinary vault links. A world can stay entirely local or be uploaded to the OnlyWorlds site, where a free account hosts it and exposes it through a REST API for other tools.
