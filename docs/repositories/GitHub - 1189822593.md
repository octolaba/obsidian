# Pierry/obsidian-cloud-dancer-theme

Cloud Dancer is an Obsidian theme whose light mode is built around the Pantone shade Cloud Dancer, a warm off-white recorded in its README as #F0EBE3. A dark mode of deep warm charcoal tones accompanies it, and both share warm terracotta accents used for links, highlights and interactive elements. The README lists a heading hierarchy, refined scrollbars and subtle transitions, pill-styled tags with soft backgrounds, and a palette table giving background, surface, accent, text, muted, link and tag colours for each mode.
