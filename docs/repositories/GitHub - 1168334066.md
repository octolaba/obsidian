# eugenesvk/Obsidian-Densy

Densy is a density-oriented Obsidian theme, offered by its README for cases where minimal is not minimal enough, that removes padding and margins to leave more room for content. It restores a full-height target for top tab selection when the window is maximized, removes the window minimise, maximise and close controls and the per-tab close button, shrinks labels to fit their content, and makes label text larger and darker while enlarging icons. The theme is compiled from Sass sources with the sass command. Its README records the theme as work in progress, broken in a few places, currently unconfigurable, light-version only, and with some items too small on a smartphone.
