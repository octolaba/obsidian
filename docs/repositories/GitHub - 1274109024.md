# ONEGAYI/Obsidian-Smart-Tagger

Obsidian plugin that generates tags for a note with an AI backend and writes them into the frontmatter tags field, for the current file or for a whole folder at once. It works with OpenAI-compatible APIs and with local Ollama models, keeps several prompt templates that can be saved, switched and restored, and can be told to prefer tags already present in the vault so the taxonomy stays consistent. A placeholder syntax lets the same run fill other frontmatter fields such as a summary or a title, gitignore-style patterns exclude files, and folder runs have a configurable recursion depth and a right-click entry. The README states that the API key is stored encrypted with AES-GCM and PBKDF2 keyed by the vault path.
