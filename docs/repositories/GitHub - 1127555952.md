# arcticleo/wiki-otd

Inserts Wikipedia's "On this day" material into the active note as Markdown. The plugin fetches the Wikipedia page for the current day, or for a date chosen in a picker, extracts its Events, Births and Deaths sections, filters out page noise and inserts the result at the cursor, rewriting relative Wikipedia links as full URLs. Settings control how links are displayed, inline, grouped or not at all, and whether today is taken from the system timezone or from one selected by hand. Both commands are reachable from the command palette, and today's entry also from a ribbon icon.
