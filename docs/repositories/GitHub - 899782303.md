# CatMuse/HiNote

HiNote extracts highlighted text from a note and shows it as cards in the sidebar, where a comment can be attached to a single highlight or to the whole document, and where an AI can generate comments and hold a dialogue with the highlighted text. Several highlight formats are recognised, including `==` and tag-based markup, and custom formats can be defined with regular expressions. Highlights and comments can be exported as knowledge card images or turned into new notes linked back to the source, and the README states that all of that data is stored in a `.hinote` folder in the vault root. It also states that the plugin was developed with AI assistance and is in beta testing, and that a Pro upgrade unlocks an FSRS-based flashcard system.
