# keithwithAI/reading-progress

Note Reading Progress shows the remaining reading time and the scroll progress of the current note, in reading mode as well as edit mode. The reading speed in words per minute, the time format, an appended text and an optional percentage are configurable, and the status bar item carries a CSS class for further styling. Because Obsidian hides the status bar on mobile, the plugin ships styles that render its own item as a pill near the bottom of the screen and, by default, hides the other status bar items while that pill is visible; both behaviours are settings.
