# Maniarasan-zuper/obsidian-zocean

Zocean is a paper-like Obsidian theme supporting light and dark modes, built on generous whitespace, soft dark grey text, a blue accent and subtle borders. The README lists a 708px centered reading column, an Inter and system font stack with slight letter-spacing, pill-shaped inline code, soft-gray code blocks, colored callout blocks, accent-filled checkboxes and quiet sidebars, tabs and scrollbars. Both manual installation and installation from the community store are documented.
