# SilentVoid13/Chesser

A chess game viewer and editor for Obsidian. The README states that declaring a chess code block renders a board in the starting position, and that settings written inside the block change it, including a FEN string describing a particular position; some of those settings can be fixed once in the plugin's own settings tab. A game can be supplied as PGN, which the README says must be written as a properly formatted multiline YAML string, and it lists PGN file support as a to-do rather than an implemented feature.
