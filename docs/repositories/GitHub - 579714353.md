# jglev/obsidian-boost-link-suggestions

This plugin adds an inline link-suggestion interface that orders files by how often they are linked to rather than by search match alone. Typing an opening square bracket after the letter b brings up the alternative suggester; each file's rank is the number of incoming links in the vault plus a boost score read from a frontmatter key, which defaults to boost. Within a file, suggestions list the aliases in their frontmatter order followed by the filename, and a Show scores setting displays the score calculation in the interface. The README's stated motivation is that Obsidian's built-in suggester can surface a rarely linked file above a frequently linked one when typing quickly.
