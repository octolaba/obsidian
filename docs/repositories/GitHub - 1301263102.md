# Law-Of-Cycles/claude-paper-obsidian

Claude Paper is an unofficial Obsidian theme inspired by Claude and Anthropic's warm visual language, combining clay accents, paper-like surfaces, bilingual serif typography and matched light and dark modes. Its README states that the project is independent and not affiliated with, endorsed by or sponsored by Anthropic, and that no Anthropic artwork or commercial font files are included. Interface, headings and body text are set in one bilingual serif family so type does not visibly change between Chinese and English, code stays in a monospace stack, and the theme assigns Obsidian's own font variables so Appearance settings still take priority. The README also lists six differentiated heading levels, support for keyboard focus, increased contrast, reduced motion, small screens and print, and pure CSS with no telemetry, network requests or scripts.
