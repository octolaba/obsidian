# samprintz/obsidian-issue-augmentation-plugin

This repository holds the GitHub Issue Augmentation plugin, whose README describes replacing bare GitHub issue identifiers written in a note with their titles, each rendered as a link to the repository. Two sources of titles are documented and may be combined: the GitHub API, which needs a repository owner and a personal access token in the settings and can be restricted to selected repositories with a default one for unqualified identifiers, and a CSV file inside the vault mapping identifiers to titles. No upstream repository description is recorded, so this body rests on the README alone.
