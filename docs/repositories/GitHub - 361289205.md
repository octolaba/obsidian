# ozntel/oz-image-in-editor-obsidian

This plugin renders images, transclusions, iframes, PDF files and Excalidraw drawings directly under the editor view, so switching to Preview is not needed to see them. Both Markdown and wikilink formats are recognised, local images and images from the internet are handled, and the scanned image formats are jpg, jpeg, png, gif, svg, bmp and webp. Display size is controlled through alt-text options such as small and extra-small, or by giving an explicit width and height. The README states that from version 2.1.3 the legacy editor is no longer supported and only Source Mode of the new editor is handled, with widgets disabled automatically under Live Preview to avoid duplicated images.
