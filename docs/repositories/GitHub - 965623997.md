# lowitea/obsidian-tasks-cleaner

Tasks Cleaner removes old completed tasks from the Markdown notes of an Obsidian vault. The README records that completed tasks are detected by a customizable regular expression which must carry a capture group for the completion date, that tasks older than a configurable number of days qualify for deletion together with the indented description lines beneath them, and that files can be filtered by filename pattern. A confirmation modal with a summary of the affected tasks appears before deletion, and the README states that the plugin is compatible with the Tasks plugin but also works separately.
