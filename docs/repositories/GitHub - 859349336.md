# alberti42/obsidian-minimize-on-close

Minimize on Close minimizes the Obsidian window to the dock or taskbar when the last open pane is closed, rather than leaving an empty window. The README describes this as standard macOS application behaviour, which the plugin can either restrict to macOS, the default, or apply on Windows and Linux as well through its settings. It also adds two command palette entries, one to minimize the window to an icon and one to exit Obsidian entirely, which can be given their own hotkeys.
