# yaye-work/inline-note

The recorded description says the plugin lets a wikilink be expanded into a real, editable inline note without leaving the page. The README explains that in Live Preview every link gains a control after it, a plus icon while the target does not exist and a chevron once it does, and that pressing Tab with the cursor right after the closing brackets cycles through creating, expanding and collapsing the inline body without affecting indentation elsewhere. Inline bodies are full editors, so a link typed inside one nests the same way up to five levels deep, and each inline note is an ordinary Markdown file, so backlinks, graph view and normal opening behave as usual. A nesting-style setting controls how the bodies are drawn.
