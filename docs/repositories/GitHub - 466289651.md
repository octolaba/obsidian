# SimeonLukas/obsidian-kindle-export

The repository holds an Obsidian plugin that sends notes to a Kindle or PocketBook device as an EPUB file. Its README records an export command that collects the note together with its embedded images and embedded Markdown files and posts them to a PHP backend, which converts the bundle and mails it to the device. The author records that the backend can be self-hosted from a companion project and warns explicitly that using the shared instance sends private data to that server, while stating that the data is neither saved nor read.
