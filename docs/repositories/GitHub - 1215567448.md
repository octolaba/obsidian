# obcdian/obsidian-heading-level-adjust

An Obsidian plugin that adjusts Markdown heading levels and performs small clean-ups on notes. The README records commands that increase or decrease the heading level by one over the selection or current line, a custom-delta prompt for shifting several levels at once, and composite commands that adjust and then clean in one step; adjustments are cancelled outright if any line in the selection would fall below level one or rise past level six. A separate clean command strips horizontal rules such as three hyphens, asterisks or underscores and collapses runs of empty lines into one, operating on the selection or on the whole document when nothing is selected. Default hotkeys are recorded for the two single-step adjustments.
