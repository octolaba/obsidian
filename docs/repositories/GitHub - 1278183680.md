# Raven-Pensieve/obsidian-components-lib-downloader

Obsidian plugin that downloads file assets from Feishu wiki bitable libraries into configured folders of the current vault. The README states that presets cover three libraries, that Obsidian's native request API is used to reach the Feishu endpoints without a custom server, and that the plugin exchanges the user's Feishu Open Platform app credentials for a tenant access token, resolves the wiki links to bitable targets, reads the linked tables and downloads the attachments. It also lists a card-based library view with cover previews, duplicate handling by skip, rename or overwrite, separate download paths per library, and credentials kept in local plugin settings rather than in source.
