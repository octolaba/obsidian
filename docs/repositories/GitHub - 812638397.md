# Quorafind/Obsidian-Search-In-Canvas

Search in Canvas adds a search bar to an Obsidian canvas, opened with Ctrl and F or from the search icon in the toolbar. Typed text is searched across all kinds of nodes and also across edges, matches are highlighted, and pressing Enter moves to the next occurrence. The README documents installation through BRAT by adding the repository as a beta plugin, or manually from a release archive or its individual files.
