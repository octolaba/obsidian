# joeyliu6/picnexus-obsidian

PicNexus uploads images pasted or dropped into Obsidian through the PicNexus desktop app running on the same computer, then inserts the resulting image link into the active note. The plugin connects only to that local app on a configurable port, sending image bytes or local image paths when an upload is explicitly triggered, and the desktop app performs the upload to whichever hosting service the user selected. The README states that the plugin contains no telemetry, advertisements or self-update mechanism, and that it needs Obsidian 1.4.0 or later on desktop.
