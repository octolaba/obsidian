# pieces-app/obsidian-pieces

Pieces for Obsidian brings the Pieces Copilot, the long-term memory engine and Pieces Drive into the Obsidian workspace. The README describes querying cloud and local language models from inside Obsidian, adding files, folders or an entire vault as context for a conversation, saving materials to reference later, and using Pieces Drive to save, edit, search and share saved materials such as reusable code. Copilot is started from the editor by selecting a portion of code and using the Pieces entry in the context menu, and inline quick actions are added to block elements for saving and sharing.
