# eliasfloreteng/obsidian-copy-all

The repository holds Copy All, an Obsidian plugin that copies the whole content of the active file to the clipboard as Markdown from a command palette entry. A setting, on by default, prepends the filename without its extension as a top-level heading. The README also states that the command can be bound to Obsidian's mobile pull-down action.
