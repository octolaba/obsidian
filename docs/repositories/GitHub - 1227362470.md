# GS-AX/docflow-obsidian

DocFlow detects the type of IT project documents in a vault, among them ERD, API specification, WBS, architecture diagram, requirements, manual and meeting notes, and renders each with a purpose-built view. It draws entity-relationship Mermaid blocks as interactive diagrams with a table view carrying primary, foreign and unique key badges and one-click SVG or PNG export, and renders OpenAPI 3.x and Swagger 2.x specifications from YAML or JSON code blocks in an embedded Swagger UI with an optional try-it-out mode. A left-sidebar artifact explorer lists artifact files filtered by type and status and grouped by the project frontmatter field, while a right-sidebar metadata panel shows status, version, author, modification date, tags and related links. A command inserts pre-filled templates for all seven types, and the interface and templates are localized in English and Korean.
