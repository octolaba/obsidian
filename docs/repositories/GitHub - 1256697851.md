# MichelleGDyason/index-note-splitter

Index Note Splitter extracts content out of the active Obsidian note into new linked notes and rewrites the source note as an index. It can extract the current selection or every section at a chosen heading level from H1 to H4, naming each new note after its source heading or the first non-empty line of the selection, preserving heading levels and copying the source note's YAML properties into each extracted note. In the source note the extracted content is replaced by an ordinary link, so page preview or the Hover Editor plugin shows the extracted note on hover; each new note gets a backlink to its source, and heading extracts also get a `Next:` link to the following extracted note. The commands are run from the command palette.
