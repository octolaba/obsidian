# quantavil/Tag-Timer

Tag Timer adds inline stopwatches and countdowns to lines inside Obsidian notes, tracking time spent on a task or a section where it is written. Timers are created and paused from keyboard shortcuts or from a context menu on the badge, a command stops all running timers, and a timer's time can be edited by entering minutes and seconds, hours minutes and seconds, or a plain number of minutes. Each timer is running, paused or stopped, and the README records that resuming a stopped timer restarts elapsed time from zero. An optional analytics panel in the sidebar reports daily and weekly totals, a streak, the ten files with the most tracked time, and a history of recent sessions.
