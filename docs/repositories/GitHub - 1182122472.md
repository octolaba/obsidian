# wasmir/obsidian-continuity-sketch

The repository holds Continuity Sketch, an Obsidian plugin that draws on a nearby iPad through Apple Continuity Sketch and inserts the resulting image at the cursor. A command opens the Continuity menu, the sketch is drawn with Apple Pencil, and the image lands in the note when it is finished. The README states that the plugin is macOS only and needs macOS 12.0 or later plus a separate helper binary, boofa-sketch, whose path is auto-detected or set in the settings.
