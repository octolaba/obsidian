# RichardX366/Obsidian-Google-Drive

This repository holds Google Drive Sync, described upstream as making Obsidian work in Google Drive to enable access from iOS. The README states plainly that this is not the official Obsidian sync service, and that the plugin communicates with the Google Drive API and with a server run by the author. Listed features are two-way sync, cross-device and iOS support, automatic conflict resolution that prioritises the local file, several vaults per Google account, and configuration syncing. The README asks the user to back up the vault first and warns against manually uploading files into the folder it creates in Drive.
