# aaronarcade/Obsidian-Folder-Children

Folder Children syncs each folder's direct children into a collapsible Children section on that folder's folder note. Running the sync command from the palette or the ribbon shows a preview that has to be approved, after which every folder with a folder note gets a callout listing its direct child notes and subfolders alphabetically as wikilinks, with subfolders pointing at their own folder note where one exists. Folders without a folder note are skipped, and hidden files, the Obsidian configuration directory and the folder note itself are never listed. The plugin requires the Folder Notes plugin and resolves parent notes the same way it does.
