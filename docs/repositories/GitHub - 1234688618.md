# merrier/obsidian-blog-bridge

Blog Bridge syncs selected Obsidian notes to GitHub-backed Markdown static-site blogs. It ships configurable path and frontmatter presets for Hexo, Hugo, Jekyll, Astro, VitePress and MkDocs, commits the generated Markdown together with local images in one commit, and can either commit directly to the target branch or open a pull request from a custom branch. Existing frontmatter is preserved with missing title and date filled in, the output filename comes from a slug or urlname property or a slugified title, and Jekyll's dated filename convention is applied automatically. A sync status page filters by title, tag and status and marks locally changed notes as Modified, while tokens are held in Obsidian SecretStorage with only the secret name in plugin data.
