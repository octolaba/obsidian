# WhatsYourWhy/Cognitive-Glow

Obsidian plugin that shows a sidebar panel of notes ranked by a computed glow score blending recency and visit frequency. The README states that row width tracks visit frequency, brightness tracks rank and color temperature tracks recency, that a focus mode narrows the list to the top ranked notes, and that a visit only counts after a configurable minimum open time, 30 seconds by default. Tracking can be restricted to or excluded from chosen folders, and the panel opens from a ribbon icon.
