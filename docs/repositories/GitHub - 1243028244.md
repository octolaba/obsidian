# zhanglongx/deep-research-formatter

Deep Research Formatter cleans Markdown exported from ChatGPT Deep Research, whose inline citation, entity and URL marker tokens are readable inside ChatGPT but noisy in plain Markdown. It removes citation markers and exported citation blocks entirely, replaces entity and URL markers with their readable label, and falls back safely for unknown marker types, while preserving YAML frontmatter, fenced code blocks and inline code and applying only minimal whitespace cleanup afterwards. Two commands are exposed, one cleaning the whole active note and one cleaning only the current editor selection, and the README records requirements of Obsidian 1.5.0 or later with Node.js 20 and npm 10 for building.
