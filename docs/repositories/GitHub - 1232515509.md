# ranjugao/codex-bridge

Desktop-only Obsidian plugin that connects a local vault to Codex. The README states that its primary workflow is a local MCP endpoint bound to localhost, letting Codex search, read and write notes without a hardcoded vault path, alongside file-based bridge commands that export the active note's context, create request files, and append the latest reply into the active note or a new one. It also lists optional summarization of a selection or note into a dated file, deduplicated by a hash marker and auto-tagged, and a switch between Chinese and English interface text.
