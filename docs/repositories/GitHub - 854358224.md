# Ssentiago/obsidian-xmind-viewer

XMind Viewer opens files with the .xmind extension inside Obsidian, creating a viewer for the file, and also renders .xmind files embedded in Markdown notes. Access is view-only, with no editing capabilities. The README states that an internet connection is required for the plugin to function.
