# israerusan/attachment-audit

Obsidian plugin that scans a vault for unused attachments, duplicates, oversized files, junk-named pastes and misplaced files, and reports what each detector found before anything is deleted. It shows reclaimable space, image previews and duplicate grouping, per-detector thresholds and exclusions, Markdown report export, and a cleanup history with restore. The README places bulk cleanup beyond the first one, saved scan profiles, custom rules and severity tuning behind a paid Pro tier, and states the plugin works offline with a one-time payment and no account.
