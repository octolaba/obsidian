# shammond42/definition-list

Repository for the Definition List plugin, which adds HTML definition lists to Obsidian in reading view as well as live preview and source mode. It follows the Extended Syntax markup for terms and definitions and adopts parts of Pandoc's specification — a tilde as a definition marker and definition lines indented by two spaces — while multi-line terms, paragraph definitions, nested definition lists and nested ordered or unordered lists are listed as unsupported. The README notes that a term with several definitions separated by blank lines renders in live preview but not in reading mode, that strict line breaks need a trailing backslash, and that themes do not recognise definition lists, so CSS snippets are usually required.
