# Lenonss/obsidian-tasklist

The repository publishes a plugin named Projex, whose recorded description is written in Chinese and presents it as a centralized task-list component supporting adding, editing, status toggling and removal. The README describes a SQLite task database per project, with directory-scoped isolation and automatic detection of the active project, filtered by status and priority from a sidebar and created through quick-add commands or a selection context menu. Task and OKR code blocks embed tasks by identifier and key-result progress cards into notes, and a workboard file provides a calendar view, a dashboard and an OKR overview. The README also records an MCP server exposing six tools and a Claude Code skill used to generate weekly and monthly reports, and a bilingual Chinese and English interface.
