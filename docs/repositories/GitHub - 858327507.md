# alythobani/obsidian-callout-toggles

Adds, switches and removes callout wrappers around text in a note, with one command per callout type so hotkeys can be assigned to the callouts used most. The README describes inserting a blank callout, turning the current line or several selected lines into a callout, changing the type of an existing callout, and unwrapping one back into ordinary text, plus a fuzzy picker for choosing the type. It states that custom titles are retained when wrapping or removing, that custom callout types are picked up automatically when the Callout Manager plugin is installed, and that settings cover formatting, auto-selection and foldable callouts.
