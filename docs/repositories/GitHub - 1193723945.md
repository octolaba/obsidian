# brianpetro/smart-lookup-obsidian

Repository for Smart Lookup, a plugin that searches the vault by meaning rather than by exact wording. Its README frames it as question-first search for the case where the idea is remembered but not the phrase, file name, heading, tag or folder, and states plainly that a result may be useful without containing the words typed and that the plugin is not a replacement for exact search. Matches can be previewed, opened, linked, copied or packaged as context, and the README separates its role from a sibling plugin that works from the current note and from Obsidian's own search for exact phrases.
