# sylcool/obsidian-codeblock-template

Codeblock Template makes the content of a code block reusable as a template across notes. A template is declared in a `pack-source` block stored under the configured template path and rendered elsewhere with a `pack-view` block that passes values as `key = value` pairs. The README documents interpolation with `$.{}` placeholders, anonymous variables passed as comma-separated values with a configurable prefix, array-valued loop variables that repeat a line, and an input hint that completes the block after typing a trigger. It states that the plugin is not in the Obsidian plugin store and has to be installed by hand from a release.
