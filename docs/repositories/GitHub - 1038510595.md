# j-maas/sync-safe-file-names

Sync-safe file names renames vault files so that they contain only characters which sync across devices, replacing each unsafe character such as a question mark with a hyphen. The README states that automatic renaming of newly created or renamed files is active by default, that the plugin never overwrites an existing file, and that two commands exist: one inserts a report of all unsafe file names and the other renames all files. Its author contrasts this with a filename linter plugin that has to be run manually.
