# Reocin/obsidian-markdown-formatting-assistant-plugin

The repository holds the Obsidian Markdown Formatting Assistant, which provides a side panel of snippets for Markdown, HTML and LaTeX plus a color picker that keeps a history of recently used colors and can store chosen ones. Its README records a ribbon icon that opens the panel on the configured side, sections whose order can be changed and which can be expanded or collapsed, and a command line interface intended for a faster workflow. The README opens by stating that the plugin is no longer maintained and invites a takeover.
