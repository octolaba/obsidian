# dlsdgj/obsidian-regex-css-highlighter

Highlights keywords matched by regular expressions with custom CSS and indexes every match into a searchable highlight database, so clicking a keyword surfaces its occurrences across the vault; floating notes keep chosen questions permanently visible. Styles are organised into groups that can be added, edited and deleted, take effect immediately without a restart, and a style button can be right-clicked to create a draggable floating button. The README, formerly naming the plugin Regex CSS Highlighter, is written in parallel English and Chinese.
