# Roasted-NZ/obsidian-three-d-graph-view

Three D Graph View renders a vault's notes, links, backlinks, folders and tags as a graph in three dimensions that can be rotated, panned, zoomed or left to auto-rotate, laid out core-to-surface in a globe-like volume. Note bubbles are coloured by folder with per-folder controls, and optional tag nodes carry their own colours with muted inheritance for sub-tags. The note currently open is brought into focus and marked with a pulse, hovering a node keeps it and its direct connections clear while the rest fades, and a timelapse mode replays the graph in note creation order. The README records settings for labels, unresolved links, backlinks, tag visibility and the spread of disconnected groups.
