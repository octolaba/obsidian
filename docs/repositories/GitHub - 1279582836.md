# grp06/RephraseThis

Rephrases a selected passage in place: run the command or the inline button, review the suggestion before anything is written back, and cycle through alternatives from the keyboard until one is accepted. Requests go to Ollama, OpenAI, OpenRouter or another OpenAI-compatible chat API at the base URL set in settings, with an optional API key held in Obsidian's secret storage, and the amount of surrounding text sent along for style and context is configurable. The README states that note content is sent only when a rephrase action is explicitly run, and that there is no telemetry, no advertising, no background rephrasing and no access to files outside the vault.
