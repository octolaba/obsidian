# shuuul/obsidian-pivi

Pivi embeds the Pi agent inside Obsidian, so chat, edits and tools run in the vault rather than in a separate app or a terminal. Its README describes working from the note already open and drawing in linked notes, vault tools, reusable skills and commands, delegating larger work to concurrent subagents that each carry their own objective, tools and progress, and a composer catalog opened with a slash that searches commands, installed vault skills, enabled tools and MCP servers. It also records editing a selection inline from a built-in toolbar whose shortcuts, covering Pivi commands, vault skills and Obsidian editor actions, can be enabled and reordered in settings, and it states that an API key is added in the plugin settings before use.
