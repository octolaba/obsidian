# YangsonHung/obsidian-vscode-2026

VSCode 2026 ports the Fluent visual language of Visual Studio 2026 to Obsidian, with light and dark modes that follow the system color scheme. The README lists the Fluent accent and surface tokens by hex value, VSCode Dark+ and Light+ syntax highlighting mapped for both CodeMirror in the editor and Prism in reading view, macOS-style polish including SF Pro and SF Mono, rounded corners and reduced-motion support, backdrop blur when the translucent window option is enabled, and overlay scrollbars. It states a minimum Obsidian version of 1.5.0 because the theme uses color-mix, and exposes every color as a CSS variable that a snippet can override.
