# egradman/obsidian-etherpad-lite

The repository holds an Obsidian plugin that connects a note to an Etherpad-Lite server for collaborative editing. Its README explains the problem it addresses: moving a draft into an external document to work on it with others leaves the work unsearchable, untaggable and unlinkable in the vault. With the plugin a note is uploaded to the server and its address shared, while the note stays in the vault and takes the latest server version each time it is opened; removing the pad identifier from its frontmatter ends the synchronisation.
