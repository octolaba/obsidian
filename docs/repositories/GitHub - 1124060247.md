# starhunt/star-notebooklm

Star NotebookLM opens Google NotebookLM in an embedded side-panel view inside Obsidian and sends the active note or the current selection to it as a source. The README records ribbon icons, context menus and command-palette actions, a choice between an existing notebook and a new one when sending content, and a setting that includes or excludes metadata and frontmatter from what is transferred. It states that a Google account is required, that content leaves only when the user chooses to transfer it, that no telemetry is collected, and that the plugin is desktop-only.
