# muzi-xiaoren/Obsidian--TOC--reader

TOC Reader renders a standalone TOC line as a nested, clickable table of contents built from the note's headings, in both reading view and Live Preview, where the widget turns back into editable source when the cursor is on that line. Jumps use line positions, so duplicate heading names each resolve to their own place, and non-contiguous heading levels fold into relative indentation. Settings cover the minimum and maximum heading levels included and optional numbering, the table updates as headings are added, removed or renamed, and in source mode the line stays plain text by design.
