# sato-note/file-heatmap

File Heatmap overlays coloured indicators beside each file title in Obsidian's file explorer so recently changed files are visible without opening a recent-files view or re-sorting the explorer. The colour of the indicator follows the age of the last modification across a 30-day scale, moving from hot colours in the first days through to inactive ones near the end and disappearing entirely past 30 days, while the bar width narrows week by week and the exact number of days is printed only for files touched within the last 15 days. Every colour, width and threshold is configurable and individually resettable, and a command toggles the whole overlay for a hotkey. The README states it tracks the vault modify and create events plus a MutationObserver on the explorer tree, renders into a single pointer-transparent overlay so clicks pass through, and debounces its updates.
