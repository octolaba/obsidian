# ivan-lednev/obsidian-persistent-links

Persistent Links keeps internal links that point at headings and blocks working when those headings and blocks move. Once enabled it updates such links automatically when headings or blocks are cut and pasted, and a repair command searches the metadata cache for the file that now holds the linked block or heading when a file changed in some other way. The README records the limitations: the plugin partly relies on internal Obsidian APIs, the automatic path covers only cut-and-paste events, and only wiki links are handled.
