# CtrlAltFocus/obsidian-plugin-auto-tag

Obsidian plugin that generates tags for a note through the OpenAI API, working on the whole note or on a selected portion. Tags are inserted into the note's frontmatter, which the plugin creates when it is missing, and they can be previewed and accepted or ignored individually first. The tag format is selectable between kebab-case, snake_case, camelCase, PascalCase and others, tags are returned in the language detected in the note, and a demo mode exercises the settings without an API key. The README describes the plugin as in beta until a larger number of users have tested it.
