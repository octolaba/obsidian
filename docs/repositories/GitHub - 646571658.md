# Nikolai2038/strict-obsidian-theme

Strict Obsidian Theme is a simple, compact dark theme, and its README lists the differences from the default: pointed corners on many elements, animations disabled, reduced indents, a smaller application header and tabs, dark highlighting of input fields and main elements, decorated line numbers, justified text outside code blocks, darker code blocks with colours mimicking VS Code, a maximum height on images, and headings at body text size marked with a border. The image height limit assumes the Image Toolkit plugin is used to view them. Heading colour can be changed by adding a CSS snippet that overrides the default green.
