# ozavodny/obsidian-copy-inline-code-plugin

This plugin adds a customizable icon inside each inline code span in Obsidian; clicking the icon copies the content of that span to the clipboard. The recorded README covers only this behaviour together with installation and development steps, and states nothing about settings beyond the icon being customizable.
