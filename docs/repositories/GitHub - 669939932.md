# ALegendsTale/obsidian-color-palette

Color Palette creates color palettes and inserts them into Obsidian notes as rendered swatches. A `palette` code block holds the colors, in most CSS color formats including hex, RGB and HSL, or a link from coolors.co or colorhunt.co that the plugin converts into a palette. Per-palette options are passed as JSON inside the block and cover height, width, row or column direction, gradient rendering, hover, hidden text, override and aliases, and the README cautions that setting width can make a palette display incorrectly. Commands, bindable to hotkeys, open an advanced palette editor and convert a selected URL or an existing block.
