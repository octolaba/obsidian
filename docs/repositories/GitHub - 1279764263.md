# zoyluoblue/obsidian-note-to-video

This repository holds ZoyClip, an Obsidian plugin that turns a note into a 9:16 vertical short video for TikTok, Instagram Reels, YouTube Shorts and Xiaohongshu. A cloud LLM, OpenAI or DeepSeek or another OpenAI-compatible endpoint configured with the user's own key, rewrites the note into a spoken script, and the README names this as the only step that sends note content off the machine; narration is then synthesized locally with Kokoro TTS through sherpa-onnx, images come from Pexels or from the note with Ken Burns motion and cross-fades, captions follow the speech, optional music ducks under the voice, and ffmpeg composites a 1080x1920 MP4 with a generated cover back into the note. It is desktop-only, downloads its ffmpeg binary and TTS models once from public GitHub releases and then runs them offline, and states that it carries no analytics, telemetry or ads.
