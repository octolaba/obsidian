# rveciana/obsidian-cooklang

This plugin edits and views recipes written in the Cooklang format inside Obsidian. Section titles such as ingredients and cookware are translated into the recipe's language or the one configured in Obsidian, a slider in the ingredients section scales the quantities up or down, and the changelog records an option to show quantities as fractions or decimals. The README notes that Obsidian does not search non-Markdown files, so .cook files are only searchable after adding the cook extension to the Omnisearch plugin's list of additional text files to index.
