# profesr-chaos/obsidian-checklist-sort

This repository holds Checklist Sort, an Obsidian plugin that sorts a checklist so unchecked items appear above checked ones. Nested items stay attached to their parent and are never reordered on their own, relative order within each group is preserved, and content that is not part of the checklist is left untouched. The sort runs from a Sort Checklist command in the palette or from a hotkey the user assigns.
