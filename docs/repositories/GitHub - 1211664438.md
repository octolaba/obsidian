# maropark/obsidian-jump-to-terminal

Jump to Terminal opens a system terminal at the directory of the current note. It runs from the command palette, from the file explorer context menu on any file or folder, or from the context menu inside the note body. Settings choose a terminal per platform, offering Terminal, iTerm2, Warp, Alacritty and kitty on macOS, GNOME Terminal, Konsole, Xfce Terminal, Alacritty, kitty and xterm on Linux, and Windows Terminal, Command Prompt and PowerShell on Windows. A custom option accepts any shell command written with a directory placeholder.
