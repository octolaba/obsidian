# zhou-yusen/Moving-Note

This repository holds Moving Note, a cross-device Obsidian note synchronization plugin that uses the system Git installation on desktop and the GitHub API on Android, so no local Git is needed on mobile. A one-click sync pulls, detects local changes and pushes in a single step, and the README also records scheduled sync and sync on startup. Conflicts produce a report file on desktop while mobile treats the remote as the source of truth, and the repository URL, branch name and commit message template are all configurable.
