# hiroyaiizuka/taskchute-for-obsidian

TaskChute Plus is an execution-first task manager for Obsidian: a dated view lists the day's tasks, each can be started and stopped so actual execution time is logged, and tasks group into configurable time slots plus an untimed section. It also records routines on daily, weekly and monthly patterns, links tasks to projects, exposes history through execution logs and a yearly heatmap, and exports to a Google Calendar URL. The README states that task, log, review and heatmap data is stored as plain Markdown and JSON inside the vault and that no feature sends it anywhere. It records that from version 2.0.0 the plugin is no longer open source: it stays free, its source moved to a private repository, only build artifacts are published here, and the v1 source remains under MIT.
