# arugyani/depends

Depends declares relationships between notes by id in frontmatter and writes real wikilinks into managed sections, so the native Obsidian graph view picks up the edges; because ids are resolved to filenames, renaming a note does not break the graph. It maintains an upstream and an inverse section whose headings appear and disappear with the relationships, and a managed section owns its heading plus the contiguous bullet lines beneath it, so prose written after the bullets is preserved. Settings choose automatic or manual rewriting, the id, dependencies, dependents and optional gate frontmatter keys, whether dependents are declared, inferred or both, the two heading lines, and the included or excluded folders.
