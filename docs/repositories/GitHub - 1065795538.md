# MoshiQAQ/obsidian-lark-countdown-plugin

Obsidian plugin that renders Feishu and Lark style countdown blocks which update live inside a note. A command palette entry inserts a timer whose target date and time, optional label and preset colour are stored in the code block and can be changed from inline buttons, while fallback label, duration and colour are set as global defaults in the settings. The interface is localized to English or Chinese following the app language, and the README states that Obsidian 1.8.0 or newer is required and that no additional service or API key is needed.
