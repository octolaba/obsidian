# Moyf/single-choice-property

Repository for Single Choice Property, a plugin that keeps a chosen list property at a single latest value. Its README explains that adding a value overwrites the previous one instead of requiring it to be deleted first, which suits properties such as status or priority that cannot sensibly hold several values at once. The watched property defaults to status and further names can be added or removed in the settings, and the README notes that the plugin would become unnecessary if Obsidian gained a single-select property type.
