# Torutu/daggerforge

The repository holds DaggerForge, an Obsidian plugin for game masters running the Daggerheart tabletop RPG. It searches, filters and inserts adversaries and environments into notes, lets custom ones be built, and includes a dice roller and a battle calculator following the rulebook's battle guide. The README records that release 3.0.0 added a character system with an interactive sheet, shareable character codes, guided character creation, GM content browser and battle planner, and reference guide pages.
