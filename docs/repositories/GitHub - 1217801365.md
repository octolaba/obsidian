# krannich/obsidian-tree-modal

Tree Modal opens a file clicked in the Obsidian file explorer in a modal preview instead of the editor, with the modal covering most of the viewport and carrying Obsidian's native view header. Holding the command or control key opens the file normally, a file-menu entry provides a second path, and internal links clicked inside the modal open in place in the same modal. The trigger modifier is configurable, and options hide the center workspace area in favour of the sidebars, hide the sidebar toggles and sync status icon, and keep a terminal view mounted after startup. The README explains that the modal embeds a detached workspace leaf in markdown mode so live preview and other editor behaviour keeps working, and it records that the click interception relies on a data attribute that is not part of the official plugin API and could break with an Obsidian update.
