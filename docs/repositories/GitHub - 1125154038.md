# jackcipher/obsidian-lightbox

A lightbox plugin for Obsidian: clicking an image or a Mermaid diagram in Reading view opens it enlarged in an overlay. Zoom can be changed with dedicated buttons or the mouse wheel and reset, and the enlarged content can be dragged to pan once zoomed in. The overlay closes on the Escape key or a click on the background, and the README is also published in Chinese.
