# artemkorsakov/project-euler-stats

This plugin fetches statistics from the Project Euler website and displays them inside Obsidian through a code block. The README records profile information such as username, alias, location, programming language, level and number of problems solved; an overall progress view with the percentage solved and global, regional and language-specific rankings; tasks such as the number of problems remaining to reach the next level; progress toward completed and uncompleted awards; and a comparison with friends. Configuration takes the SessionId and Keep-Alive cookie values, entered in the plugin's settings.
