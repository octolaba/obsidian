# dsebastien/obsidian-dataview-serializer

Repository for Obsidian Dataview Serializer, a plugin that runs Dataview queries and writes their output into the note as Markdown, so the resulting links appear on the graph and the generated content also shows up on Obsidian Publish sites, which the Dataview plugin's own rendering does not. The README states that the Dataview plugin must be installed for it to function and that Obsidian 1.8.7 or later is required. Installation is documented through the community catalogue, through a manual copy of the release files, and through BRAT for the latest commits.
