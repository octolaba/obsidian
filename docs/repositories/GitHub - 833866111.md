# h-sphere/obsidian-mahjong-renderer

No repository description is recorded, so this body is grounded in the README alone. This community plugin renders Mahjong hands written in mahjong notation inside a fenced code block, drawing the tiles once focus leaves the block or the note is read. The notation gives each tile as a number followed by a suit letter, covering the man, pin and sou suits, honour tiles and the red five, with a single quote after a tile marking it as rotated, usually to represent a called tile. The README records dark mode support and lists further tile themes, han and fu computation and Chinese or Singaporean tile variants as future plans.
