# kepano/list-to-table

Obsidian plugin that converts selected lists into Markdown tables. Three commands are offered: flattening the list into a single-column table, turning a nested list into a table whose top-level items are column headers with nested items as rows, and turning a nested list into a table whose top-level items are row labels with nested items filling the cells across each row. Bullet, task and numbered lists are all recognized.
