# shenfan19/smart-fold

Repository for Smart Fold, a plugin that adds folding commands on top of Obsidian's built-in folding. Its README describes shortcuts that raise or lower the folding depth across the active document, toggles for each heading level from one to six, and a command that folds only the headings which have no sub-headings beneath them. It also records an option to apply a fold state automatically when a file is opened, ribbon icons for each command, and the rule that turning an icon off in settings also disables its command and hotkey.
