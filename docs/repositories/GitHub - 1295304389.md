# MapleCheng/obsidian-mirror-archive

Mirror Archive moves files and folders into a configurable archive root while preserving their original vault paths, so a note under a project folder reappears under the same path inside the archive folder. Running the same command, hotkey, toolbar button or file-explorer context action on an archived item restores it to where it came from, and multiple selected items can be archived or restored at once, though mixed selections are ignored. Besides the global archive location it supports archiving into a subfolder beside the original item, routing chosen source folders to custom destinations, automatic creation of intermediate folders and configurable behaviour when a target already exists. The interface is available in English and Traditional Chinese.
