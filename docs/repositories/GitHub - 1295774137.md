# ansango/obsidian-slugify

Obsidian Slugify renames files, and everything that links to them, into slug case: lowercase, without accents, hyphen separated. It acts on a single file, a folder recursively, a multi-selection from the explorer context menu, or the whole vault from a command, and shows a preview modal listing every old and new path, where each proposed name is editable and collisions against existing files or against another rename are recomputed live and flagged rather than silently skipped. Renaming goes through Obsidian's own file manager API so wikilinks are updated automatically, an undo command reverts the most recent batch in memory, and settings cover excluded folders, the separator character and whether non-markdown attachments are renamed too.
