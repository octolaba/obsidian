# mnaoumov/obsidian-nested-properties

This repository holds Nested Properties, an Obsidian plugin that allows nested frontmatter properties to be viewed and edited, rendering nested YAML objects and arrays as a collapsible tree inside the Properties editor. It adds per-property and global collapse and expand, a context menu with cut, copy, paste and remove, adding properties at any nesting level, horizontal scrolling for deeply nested structures, and a toggle for showing full nested keys. The README records that the type of a nested property, whether text, number, checkbox, date, list, object or Tags, which Obsidian's own interface will not assign, is persisted in the vault's types.json under the property's dotted path, so it survives a reload and applies across notes.
