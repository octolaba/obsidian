# luxmargos/obsidian-image-magician-plugin

Adds preview, link, embed and export support for image formats Obsidian does not handle natively, rendering them through magick-wasm and using a dedicated engine for Photoshop PSD files. The formats work in inline wiki embeds and in HTML image tags, where the plugin resolves both vault-based paths and inline links. An export dialog reachable from the context menu or a command writes selected images to PNG, JPG or WebP with an optional resize, and auto-export repeats that conversion when the source file's modified date changes. The README states that the default format list is configurable and that formats outside it are not guaranteed to work.
