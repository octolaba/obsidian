# kzyiym/inbox-curator

Inbox Curator reviews the notes in an Obsidian inbox folder with an LLM and sorts them into Archive, Read Later or Tasks. Note content, and optionally image and PDF context, is sent from the device to a configured OpenAI, Gemini or Anthropic endpoint, which returns structured verdicts carrying scores, summaries, credibility assessments, tags and recommended actions, with files processed in batches under configurable limits. The README states that notes are never deleted automatically, that auto-sort can be disabled or restricted to review only, that recent runs can be undone, and that the Tasks destination demands higher confidence than the others. It also records the limits: reviews may be inaccurate, URL extraction can fail on paywalled or script-heavy pages, PDF extraction is experimental, image review needs a multimodal model, and provider usage may cost money.
