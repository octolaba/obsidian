# Tenor-John/obsidian-scholarium

Scholarium is an Obsidian plugin that assembles a local-first research workspace: an electronic lab notebook, AI-assisted experiment writing, a productivity dashboard, a material library and an academic tool library, all inside the vault. The README describes structured experiment notes as Markdown with status, date, reagents, results, SMILES strings and linked drawing files, searchable and browsable from a dashboard, plus an assistant that turns a natural-language description into such a record using a configurable system prompt and a provider the user selects. It also lists an OCR-assisted image import path for handwritten or screenshot notes and a role-aware planning workspace covering daily overviews, focus sessions, habit logs and submission tracking, and states that notes stay as Markdown in the vault while external AI and cloud services remain optional and user-configured.
