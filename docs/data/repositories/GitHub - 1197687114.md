# sky150/obsidian-boox-sync

Boox Sync copies handwritten notes from an Onyx Boox device into Obsidian over BooxDrop. It scans the device for notes exported as PDF or PNG, lists the new and changed ones in a selection dialog, and downloads only what is selected, optionally preserving the notebook folder structure in the vault. Setup asks for the device's IP address as shown in the BooxDrop app and requires both devices to be on the same WiFi network.
