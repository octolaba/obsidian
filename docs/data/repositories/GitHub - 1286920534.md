# khunpoom/Thai-bracket-remap

Thai Bracket Remap is an Obsidian plugin that remaps two obsolete Thai consonants to the opening and closing square bracket as they are typed in the editor. The README explains that those letters no longer appear in modern Thai spelling, so their keyboard positions are reused as shortcuts for bracket-heavy syntax such as wiki-links, with the substitution happening instantly and needing no extra keystrokes. It documents installation through BRAT or by hand, and states that the character mapping can be changed by editing a map constant in the plugin file.
