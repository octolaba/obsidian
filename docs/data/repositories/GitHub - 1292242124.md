# fyaic/Football-Obsidian-Theme

fyaic/Football-Obsidian-Theme holds Football Notes, an independent football-inspired Obsidian theme whose default palette uses pitch green, chalk white, trophy gold, charcoal and restrained red and orange accents across editor surfaces, sidebars, tabs, links, tags, checkboxes, tables, code blocks and callouts. Team colourways are selected from a Palette dropdown that the Style Settings plugin provides; without that plugin the theme still loads but stays on the default Football Classic palette. The README lists country-inspired palettes including Argentina, Brazil, France, Germany, Japan, Mexico, Netherlands, Portugal, Spain and England among others.
