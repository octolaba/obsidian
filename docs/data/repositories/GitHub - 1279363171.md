# Saiki77/smart-related-notes

Repository for Smart Related Notes, a plugin that shows a left-sidebar stack of cards ranking the vault's notes by how closely they relate to the note being read. Its README states that the ranking runs on a small multilingual embedding model held on the machine itself, needing no cloud service, API key or separate application, and working offline after a one-time model download across many languages so matches can cross language boundaries. It records that version 3.0 also reads the shape of the vault's own link graph and fuses that signal with textual similarity, and points to an architecture document for the measurements behind that change.
