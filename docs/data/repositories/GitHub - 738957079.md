# 4Source/settings-profiles-obsidian-plugin

Settings Profiles stores Obsidian settings as named global profiles that can be synchronised between vaults, so settings do not have to be adjusted by hand for every vault. A profile is created from the plugin's settings tab with a name and a selection of which options it covers, and switching to a profile reloads Obsidian and loads its settings, including themes and plugins. Profiles are written under a save path that must be configured separately for each vault and device, with one folder per profile named after it, and a profile already present at that path is recognised automatically by a newly configured vault. The README states that a significant refactoring of the plugin is being planned and invites feedback in a linked discussion.
