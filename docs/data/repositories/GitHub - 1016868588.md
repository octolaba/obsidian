# mudnug/note-navigator

This repository holds Note Navigator, an Obsidian extension that brings OneNote-like navigation behaviour and keyboard shortcuts to file review. It adds commands to move to the next or previous file in the current folder or the whole vault, following the sort method and direction currently set in the File Explorer, and pairs deletion with automatic navigation to the next logical note. The README frames it as a way to process temporary notes, read-it-later articles and other collections that need cleanup, written after the author migrated from OneNote.
