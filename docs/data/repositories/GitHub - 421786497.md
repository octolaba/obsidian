# piglet1236/obsidian-ruby

Ruby is a red theme for Obsidian.md and a modified version of cotemaxime's Amethyst theme. The README states that it works best with the dark theme and that it supports the cite element through a snippet from the Palatinate theme. It can be installed through the Custom CSS plugin inside the app, or manually by placing obsidian.css in the root of the vault, enabling the custom CSS plugin and refreshing the app.
