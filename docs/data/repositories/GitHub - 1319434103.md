# GitHub-Xzhi/obsidian-remember-settings-window

Remember Settings Window saves the size and position of the standalone settings window introduced in Obsidian 1.13.0 and restores them the next time it opens, instead of the window reverting to its default geometry each time. Remembering size and remembering position are separate toggles, and a configurable default width and height is applied when size is not being remembered. The interface ships in English and Simplified Chinese, loading its locale JSON files from the plugin folder at runtime so a new language file appears in the dropdown without a restart.
