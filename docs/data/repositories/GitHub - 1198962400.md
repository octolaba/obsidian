# goryugocast/llr

Obsidian plugin that records task start and finish times and the day's flow directly in Markdown. A single Toggle Task command creates, starts and finishes a task, with long-press and an adjust-time action covering the rest, and the times, estimates and actuals live in the task line itself so there is no sidecar database and the history can be grepped. Routines are plain notes in a folder, their repeat patterns written in human-readable shorthand and their next due date advanced on completion. The README states that the full specification lives in about twenty Markdown files under a docs folder and that Obsidian 1.7.2 or later is required.
