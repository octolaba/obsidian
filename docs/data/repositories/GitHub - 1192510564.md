# li-zane/obsidian-graph-edge-notes

Graph Edge Notes is an Obsidian plugin that overlays short relationship labels on the edges of Obsidian's graph view. The README records relations read from a note's frontmatter under a configurable property, in either a string form or an object form carrying a target, a label and an optional detail, where the label is drawn on the matching edge and the detail appears in a hover tooltip. A command adds a relation to the current note, a plugin-level default label colour is configurable, and an optional debug panel reports recent actions and the graph binding state while writing a log file that is removed when debug mode is turned off. The README states the plugin only annotates edges that already exist, so the two notes must be linked somewhere for an edge to appear.
