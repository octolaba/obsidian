# randonneurs/daily-saying-kr

Daily Saying KR inserts a random Korean one-line saying into the current note, either through a command palette entry or by replacing a template placeholder automatically when a note containing it is opened. The README states the sayings come from a local dataset with no external API call, so the plugin works fully offline, and that both desktop and mobile Obsidian are supported.
