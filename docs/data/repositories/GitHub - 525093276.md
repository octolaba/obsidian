# Canna71/obsidian-chronology

The repository records no description, so this body rests on the README alone. The README describes a sidebar calendar of the notes in a vault, from which a day, a week, a month or a shift-clicked custom range can be selected; daily and weekly ranges appear on a timeline unless a simple-list setting is enabled, and notes falling in the same time slot can be grouped. Timeline entries carry a coloured marker showing whether the note was created or modified at that moment, clicking a name opens it and a modifier-click opens it in a new pane, and a day tile's background shades according to how many notes it holds relative to the configured average. The README also records a workaround for Obsidian Sync, whose synced files carry the sync time as their creation timestamp: two settings let the plugin read the real creation date from the note's metadata instead.
