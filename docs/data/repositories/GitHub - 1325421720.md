# ihubert555/KnForge

Creates a note together with its folder structure from a template: choosing a template and a name produces a package folder containing a Markdown file of the same name plus any configured subfolders, and opens the new file. Templates are discovered recursively in a configured vault folder, packages can be placed at the vault root, beside the active note or in a fixed folder, and date, title and unique-ID variables are substituted in template text and folder paths. Optional YAML frontmatter is generated and merged with the template's own, with a setting deciding which side wins on a shared key. Creation runs from the ribbon, the command palette or a folder's context menu, the interface follows Obsidian's language in English or Simplified Chinese, and Obsidian 1.13.0 or later is required.
