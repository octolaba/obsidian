# Pierrad/obsidian-github-copilot

This repository holds the GitHub Copilot plugin, described upstream as a bridge between Obsidian and GitHub Copilot. The README says it provides inline suggestions as the user types, accepted with Tab and dismissed with Escape, and a chat surface for asking questions about notes. It records the requirements as a Copilot subscription, a network connection to the Copilot service and, for the inline part, a path to a Node 22 or later binary followed by a sign-in step.
