# aldaw/graph-search-sync

Graph Search Sync applies whatever is typed into the global search to the filter of every open graph view, slightly debounced, so the graph shows the same results as the search list; operators such as tag:, path: and file: behave the same in both. Hovering a search result highlights the corresponding node in the graph, with the same effect as hovering the node itself. A graph opened after a search receives the current query on opening, and both features can optionally be extended to local graph views. Settings toggle the sync, the hover highlighting, whether clearing the search also clears the graph filter, and the debounce delay, and a command pushes the current query to the graph once even while sync is disabled.
