# Eloliuyx/everyday-classical-music-plugin

Obsidian plugin that adds one piece of classical music, with a YouTube link, to each daily note. The pieces are drawn from a randomised list of the first 366 entries of a recommendation document named in the README, selected by date so the same day yields the same suggestion in different years. By default only newly created daily notes are touched; settings can backfill existing notes and remove links added before a given date.
