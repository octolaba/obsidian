# Ivan1248/obsidian-selective-publisher

Selective Publisher publishes a chosen subset of an Obsidian vault to a Git repository. The README describes filtering notes and attachments by tag, frontmatter, folder, title, path or body content — with substring and regex matching and AND, OR and NOT combinations — then reviewing the added, modified and deleted files in a preview modal before committing and pushing to a target branch. It requires Obsidian 0.15.0 or later, a locally installed Git and a local clone of the target repository, and notes that the repository may hold a static site generator such as Quartz when the goal is a published website.
