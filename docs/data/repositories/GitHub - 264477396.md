# harmtemolder/obsidian-solarized

Solarized for Obsidian is a recolor of the app based on Ethan Schoonover's Solarized color scheme, stated to work as of Obsidian v1.0.0. The README quotes the upstream write-up: Solarized reduces brightness contrast while retaining contrasting hues for syntax highlighting readability, keeps the same selective contrast relationships when switching between light and dark backgrounds, and translates its monotones and accents through CIELAB for perceptual uniformity in lightness. The theme respects Obsidian's accent color setting, so that setting can be pointed at any of the Solarized accent colors.
