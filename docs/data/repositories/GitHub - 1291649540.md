# DevilSurvivor2/character-companion

This repository holds Character Companion, an Obsidian plugin that animates character sprites in the right side panel and walking along the bottom edge of the window. A character points at an image or a folder of frames in the vault, and its walking, resting, speaking, idle and click-reaction behaviours are tunable, with quotes spoken when idle or clicked. The side panel adds four feed sources: a stream of reactions to the character, an oracle riffing on what is being typed, timed mail, and ambient microblogs. The README states that the feeds are produced locally by a bundled language engine using RiTa and compromise, without a model or an internet connection, and that they are desktop-only.
