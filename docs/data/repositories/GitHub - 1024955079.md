# wudanyang27/ticktick-today

TickTick Today is an Obsidian plugin that reads today's tasks from the TickTick desktop application through the macOS JXA API and lists them in a sidebar panel, so tasks can be reviewed and marked complete without switching applications. The README states that completion syncs back to TickTick, that refresh runs on a configurable interval, and that pinned tasks are shown first. It positions the plugin as an aid to a GTD practice rather than a replacement for TickTick: creating, editing and organising tasks stays in the app. The README records that it supports macOS only and requires the TickTick application.
