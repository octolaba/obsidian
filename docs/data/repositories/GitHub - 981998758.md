# ratiger/obsidian-banyan

Obsidian plugin that adds a card-based homepage for browsing, organizing and reviewing notes. Notes are shown as cards rather than as titles alone, and tags from both the note body and its properties appear in the card view and take part in search, so notes can be classified in more than one way instead of by a single tree. Search combines keywords, date ranges and tag expressions built with OR, AND and NOT logic, and frequent searches can be kept as saved filters. A random browsing mode walks all notes or only the notes inside one filter scheme.
