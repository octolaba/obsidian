# fengshuzi/lite-reminders

Lite Reminders manages macOS Reminders from inside Obsidian, driving Reminders.app through JXA and osascript rather than switching to the app. A sidebar view opened from a bell icon or the Open reminders command lists the reminders in a chosen list, defaulting to the Inbox, and reminders can be created, edited, completed and deleted from it, with optional due dates and times. Because the data stays in macOS, it syncs through iCloud; the plugin is macOS only and requires Obsidian 1.2.8 or later.
