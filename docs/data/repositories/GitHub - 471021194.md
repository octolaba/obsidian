# twibiral/obsidian-execute-code

Obsidian plugin that runs the code inside a note's code blocks locally. A run button is added to code blocks in supported languages, the result is shown after execution finishes, and an interactive input element appears when the snippet expects user input. The README lists around thirty supported languages including C, C++, Python, Java, JavaScript, TypeScript, Rust, Go, Haskell, SQL and several shells, records embedded plots for Python, R and Octave, and describes special commands that reach vault paths and show images in notes, code blocks that run before or after every block of the same language, global code injection, and optional persistent output stored in the note.
