# keptan/obsidian-anki

Anki Forge finds flashcards written inline in Markdown notes and sends them to Anki through the AnkiConnect add-on, which must be running at its local endpoint. Cards are written with a double colon for one direction, a triple colon for both, highlights or braces for cloze deletions, and a tagged prompt followed by an answer for longer cards; ordinary Obsidian tags on the card are carried into Anki. An anki-deck property in frontmatter picks the deck and opts a note into automatic syncing, and folders can optionally become nested decks. Syncing a note, a folder or all opted-in notes first shows a preview counting creations, updates and deletions and applies nothing until approved, and the first sync writes a block ID under each card that identifies it for later edits.
