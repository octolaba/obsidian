# pengivy1990/md-table-to-latex

Markdown Table to LaTeX converts a selected Markdown table into a LaTeX array environment for MathJax rendering, triggered from a ribbon icon or a command, each opening a dialog for an optional table caption. The conversion reads the Markdown alignment row to build the column specification and removes the dollar signs around inline formulas in cells, since the output already sits inside a display-math block. The README is written in Chinese and documents manual installation from the released files.
