# zuluwi/obsidian-vlc-bridge

VLC Bridge connects Obsidian to VLC Player: it starts VLC with its web interface active, opens video addresses written in Obsidian URI form at a given time, and sends commands to that web interface so the player can be controlled without leaving the editor. It also pastes a timestamped link or a snapshot taken from an existing video into the note, so that notes can be taken from a video without losing focus. The README documents installation from the community plugins browser after restricted mode is turned off, and alternatively through BRAT.
