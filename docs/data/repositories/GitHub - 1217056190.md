# jochenbernard/obsidian-view-mode-rules

The repository carries no description; its README presents View Mode Rules as a plugin that sets a default editing or reading view per note or per folder without using note frontmatter. Rules are attached from the file explorer context menu or from commands, and resolution runs from the rule for that exact note, to the deepest folder rule containing it, to a plugin-level global default, and finally to Obsidian's own default for new tabs. The README adds that rules survive renames and moves and are cleaned up for deleted notes, that reapplying views on navigation into an open tab and on tabs restored at startup are separate options, and that only Markdown notes are affected.
