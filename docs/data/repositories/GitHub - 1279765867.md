# moonweave/obsidian-graph-styler

Graph Styler is an Obsidian plugin that applies curated presets to the graph view in one click, each setting node and group colours, a glow CSS snippet and force and size values. The README lists fourteen presets and records a customise panel whose force and size sliders and colour pickers update the graph live and can be saved as a personal preset. Colour mapping is recorded as adapting to the vault: the palette is assigned to the most-used folders, up to four, falling back to the most-used tags, and to the glow, background and node colours alone in a vault with neither. The README states the plugin writes Obsidian's own graph colour groups and a CSS snippet, backs up the original graph configuration so a restore command can revert it, and is desktop-only with an English or Korean interface.
