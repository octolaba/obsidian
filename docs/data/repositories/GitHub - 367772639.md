# meld-cp/obsidian-calc

Obsidian Calculator evaluates mathematical expressions inside notes using the fcal library, which the README describes as supporting basic arithmetic and precise percentage operations with a large set of built-in units, functions and constants. An expression ending in an equals sign is selected and evaluated from the command palette, and the result is written back into the note; an expression without the trailing equals sign has its result copied to the clipboard instead. Variables and multiline expressions are supported, so several selected lines evaluate together. The README records that the plugin has no settings.
