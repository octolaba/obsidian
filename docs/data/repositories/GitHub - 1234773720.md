# rogerdigital/document-exporter

Document Exporter exports a single note, an entire folder or hand-picked files to PDF, a Word document, a Markdown bundle or a standalone HTML document, preserving the directory structure on batch exports. The Markdown bundle writes one file per source note plus a shared assets directory with attachments copied and links rewritten, while the HTML output carries a table of contents, native rendering and linked assets. Exports start from a sidebar icon, the file or folder context menus, the editor context menu or a command, and a dialog picks the source, format, output folder and name. The README states that PDF is not offered on mobile and that the progress bar can be cancelled while already-exported files are kept.
