# Itzqingyu/todo-calendar

This plugin renders a Markdown task list as a monthly calendar and timeline, highlighting the dates that carry tasks and their completion status. The README describes bi-directional synchronization: creating, modifying, deleting or completing a task in the panel is written back to the Markdown file, and editing the file externally updates the calendar. Tasks are standard Markdown checkboxes with a date tag appended, the plugin binds by default to a file in the vault root and otherwise to any Markdown file chosen through fuzzy search in settings, and it offers English and Traditional Chinese interfaces, filters such as overdue and the next three or seven days, and a separate panel for tasks with no deadline.
