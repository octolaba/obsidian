# IronMind15/spherical-knowledge-graph

Spherical Knowledge Graph builds a rotatable pseudo-3D sphere, or a multi-planet system, from the links already present between the vault's Markdown notes, watching create, modify, rename, delete and metadata events to stay current. Planets are grouped by folder, graph community, custom rules or manual assignment, nodes are colored by folder, tag or property, and edges encode link direction, relation type and repeated-reference strength. It finds a shortest path between two selected notes, derives a learning route from a search topic using starting points taken from the current vault, and audits orphan notes, weak notes, stale hubs, cross-category bridges and unresolved concepts. The README records the plugin as local-first and read-only, scanning notes and metadata but never editing note content.
