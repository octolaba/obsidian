# kyffa/Iridium

kyffa/Iridium hosts Iridium, an Obsidian theme its README describes as pretty, comfortable and customizable, built around the user's accent colour. It defines a large set of alternate checkbox states, among them incomplete, canceled, forwarded, scheduling, question, important and bookmark, and its customization is exposed through the Style Settings community plugin. The README asks macOS users to run Obsidian installer version 1.11.4 or above.
