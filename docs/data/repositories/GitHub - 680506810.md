# shanedonburke/obsidian-auto-archive

Obsidian plugin that archives notes once they reach a certain age. One or more archive configurations are added in the plugin's settings tab, each stating which notes are archived, where they should go and at what age. The README credits code taken from Liam Cain's Periodic Notes plugin.
