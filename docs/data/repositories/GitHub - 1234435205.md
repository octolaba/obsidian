# pasevin/obsidian-slick-mermaid

Repository for Slick Mermaid, described as a minimal, monotone CSS theme for Mermaid diagrams. Its README states that the plugin reads the active Obsidian theme's background, border and text colours, matches diagram surfaces to the surrounding note and adds contrast so nodes and groups stay readable in light and dark mode. It notes that most of the diagram behaviour lives in the plugin's script rather than in CSS alone, so the plugin has to be reloaded after syncing changes.
