# mikealexsoldatkin/obsidian-simple-git

This repository is a compact Git client for Obsidian that puts its actions in the status bar: pull, commit, push, create a branch and a label showing the current branch that opens a searchable list for switching. The README states the plugin is desktop only because it shells out to the local git executable and optionally git-lfs. Creating a branch asks for an issue key and a branch type from a configurable dropdown, names the branch from the two, creates it from the current branch after pulling, and pushes it to the remote with upstream tracking. The commit window, shared by the commit and push actions, remembers the message per branch and either stages everything or lets individual files be picked from a tree of changes with status badges.
