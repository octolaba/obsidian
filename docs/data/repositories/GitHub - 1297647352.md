# ITNQ18/obsidian-audio-timestamp-player

Obsidian plugin that turns timestamp links in a transcript into seek-and-play controls for audio or video embedded in the same note. It accepts MM:SS and HH:MM:SS timestamps, works in Reading view and Live Preview, recognises the links while editing in Source mode, and lets several recordings in one note be addressed separately through an alias declared beside each embed. The README lists MP3, WAV, M4A, OGG and FLAC audio and MP4, WebM, OGV, MOV and M4V video embeds, and a floating player that survives view-mode changes and pane rerenders. It also states the plugin runs entirely locally with no telemetry and no network requests.
