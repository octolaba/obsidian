# Yep49/obsidian-ai-rag-plugin

Obsidian plugin combining retrieval-augmented question answering over a vault with a persistent wiki layer that the language model maintains. The retrieval chain runs query analysis, four-way dense, sparse, feedback and metadata recall, fusion by RRF, weighted or distribution-based methods, model-based reranking, and context compression through parent-child chunks, sentence windows and a token budget. The wiki keeps raw sources read-only while a separate directory holds source summaries, entity and concept pages that merge new material rather than overwrite it, conflict markers when old and new statements disagree, and generated index and log files, with an audit for orphans, missing cross-references and gaps. The README states no API key is bundled, that indexing and asking send text to the user's own OpenAI-compatible endpoint, and that automatic indexing and import are off by default.
