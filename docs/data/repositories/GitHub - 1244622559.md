# Etudes-Informatiques-et-Services35/abal-lang-highlighter

Obsidian plugin that adds syntax highlighting for the ABAL programming language inside fenced code blocks marked `abal`. Highlighting is applied in edit mode through CodeMirror 6 decorations and in reading mode through a Markdown post-processor. Keyword detection is case-insensitive, and the token types coloured are keywords for control flow, data types, object-oriented constructs and built-in instructions, double-quoted strings, comments beginning with a semicolon, decimal and hexadecimal numbers, operators and punctuation. It requires Obsidian 1.8.7 or later and works on desktop and mobile.
