# saltyfireball/obsidian-auto-view-mode

An Obsidian plugin that chooses a note's view mode when it opens — Reading View, Source Mode or Live Preview — from a frontmatter key. The key defaults to auto-view-mode and can be renamed in settings; accepted values are preview or reading, source, and edit or live. The README describes the plugin as lightweight with no external dependencies.
