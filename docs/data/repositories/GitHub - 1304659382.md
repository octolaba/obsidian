# keptan/obsidian-todoist-pomodoro

Todoist Pomodoro Heatmap adds a Pomodoro timer to Obsidian that runs for as long as wanted and then starts a break proportional to the time worked. Todoist tasks can be browsed, created, selected and completed from the timer, grouped by project, shown with subtasks and linked to notes, using an API token entered in settings. Sessions are recorded in year and month heatmaps, time can be added manually, completed-task history can be imported from Todoist, and a mikumodoro-heatmap code block renders a heatmap inside a note. Token, settings, sessions, task links and history are stored in the plugin's local data file, and break sounds and system notifications are optional.
