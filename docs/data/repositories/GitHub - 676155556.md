# CheeseCake87/gnome-terminal-loader

This repository holds Gnome Terminal Loader, whose README describes an Obsidian plugin that loads gnome-terminal and can also run a Python entry point placed at the vault root as a file named main.py. The README states that it is compatible only with Linux systems that have gnome-terminal and python3 installed, and suggests writing the entry point as a small command-line menu, for which it gives an example. No upstream repository description is recorded, so this body rests on the README alone.
