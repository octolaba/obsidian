# Jasper-1024/block-link-plus

Block Link Plus extends Obsidian's block linking with multi-line range references, alongside commands and a context menu for copying links, embeds and URIs to blocks and headings. It adds a Logseq-like outliner workflow that treats list items as blocks in scoped files with stable ids and hidden system metadata, queried and rendered through a blp-view code block that requires Dataview. A journal feed opens a marked anchor note as a continuous view of several daily notes using the core Daily Notes settings. Embedded blocks and headings can be edited inline in Live Preview, and copied links can carry content-based aliases.
