# wiop93256/Simple-Code-Formmater

Simple Code Formatter formats the code block the cursor is inside, run from a command in the command palette. Its README lists the formatter module used per language: js-beautify for C, C++ and C#, prettier for Java, HTML, Vue, CSS, JavaScript, TypeScript, JSON5, SCSS, Less, GraphQL, Markdown and YAML, a dedicated XML formatter, and a SQL formatter. The README states that the Markdown syntax of the code block has to be correct, that prettier checks the code's syntax, and that a language handled by js-beautify can be selected temporarily to bypass that check for code which does not conform.
