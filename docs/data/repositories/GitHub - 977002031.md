# awfrok/obsidian-plugin-bibtex-entry-view

This plugin renders a `bibkey` code block in an Obsidian note as the matching BibTeX entry, loaded from a `.bib` file placed in or imported into the vault; a key that is not found is shown as struck-through red text instead. The rendered entry shows the key in Obsidian's accent color, then the `author` field — or `editor` when there is no author — in a last-name-first format, then the remaining fields ordered by the `fields to display and sort` setting. The README also records suggestions while a key is typed in braces, drawn from partial values of those same configured fields and requiring keywords of at least two letters.
