# nazoadiego/tiny-habits

Tiny-Habits tracks habits from within Obsidian, storing every entry in the frontmatter of the reader's own notes so that the data stays local and inside the Markdown. The README records marking a habit as completed, failed, skipped or not started, and a table of habit entries presented in the format of a heatmap. The plugin is built with Svelte.
