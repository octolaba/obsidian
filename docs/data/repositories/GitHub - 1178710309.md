# tetsuya-dev-jp/igdb-game-search

IGDB Game Search queries the IGDB API by game title and turns selected metadata into a new Obsidian game note. It can also insert rendered metadata into an existing note, use a chosen template and file path, translate long-form fields with DeepL, and configure language and cover-image options.
