# luzcmax/video-learning-notes-plugin

Video Learning Notes links timestamped notes to video files already on the computer and opens the matching video in a single reusable Obsidian pop-out player, reached from the ribbon, the note header or the command palette. A note declares its video through frontmatter recording a SHA-256 asset identity, absolute Windows path, file URI, size, modification time and duration, and timestamp links carry a millisecond start so a click seeks to that moment with configurable pre-roll. From the player it can locate the nearest timestamped evidence line and copy the current playback position back as a timestamp link, and it verifies the local file against the recorded hash. It is a Windows desktop plugin for Obsidian 1.11.7 or later and neither transcribes video nor generates learning notes itself.
