# Gonzalo-D-Sales/obsidian-velocity

Velocity is an Obsidian theme its README presents as futuristic and the product of a year-long design effort, with release 2.2.0 recorded as of June 2026 and adding a stylized light mode color scheme. Customization runs through the Style Settings plugin, which exposes Quick Settings for layout and colors and a deeper Configurator, including a toggle that overrides the typeface the theme bundles. The README also states an issues policy: reports and feature requests are read and worked on during weekends only, with no guarantee of completion in the same week.
