# SATOSprod/programming-mono

Programming Mono is a sharp, monospace Obsidian theme for programmers, using JetBrains Mono for interface, editor text and code with Fira Code and Cascadia Code fallbacks, and zero border radius on buttons, tabs, inputs, modals, panes and scrollbars. Dark and light variants are built from the same warm, low-contrast neutral palette, and a four-color accent system gives H1 to H4 distinct colors reused across links, tags and code syntax. Code variables such as keyword, string, function and comment are mapped so inline code and code blocks read like a real editor, chrome stays flat with no shadows or gradients, and the README records the license as proprietary.
