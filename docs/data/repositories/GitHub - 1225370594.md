# chinoryunqin/ObMeeting

Meeting Scribe AI records a meeting inside the Obsidian desktop app, keeps the original audio in the vault, transcribes it with the Doubao speech recognition model and polishes the transcript with a configured OpenAI-compatible model before writing a structured Markdown meeting note. By default the result is appended to the note that was open when the recording started, and a new note is created under a meeting folder when there is none. The README, written in Chinese and English, records manual notes taken in a tab during the recording, a command that rebuilds an interrupted long recording from the saved audio and segment information, and an attachment upload entry whose contents are not yet analysed. Its privacy section states that audio goes to the configured transcription service and the transcript and manual notes to the configured model service, with no telemetry included.
