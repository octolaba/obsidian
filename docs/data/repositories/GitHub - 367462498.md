# oeN/liquid-template

Liquid Templates is described as letting Obsidian templates be defined with LiquidJS tag support. The README shows templates composed from smaller ones through include tags, with variables such as the note title and date substituted when a note is created from the template, and states that the standard LiquidJS tags and filters are otherwise available. An autocomplete triggered by a configurable sequence, two semicolons by default, offers templates while typing, and the built-in date filter is replaced by one backed by date-fns that also accepts words such as now and today, falling back to the original filter when the format string contains a percent sign. The README describes the plugin as under heavy development with basic features.
