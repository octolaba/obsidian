# banastas/an-old-hope-obsidian-theme

An Old Hope for Obsidian is a dark theme that ports the An Old Hope palette to Obsidian, covering the app shell, Markdown editor, reading view, callouts, graph view, canvas and editor syntax. It keeps the original editor theme's colour assignments: deep charcoal backgrounds, warm off-white text, red keywords and actions, cyan links and strings, yellow headings and functions, green Markdown and code accents, orange accents and purple constants and bold emphasis. The README traces its lineage from Jesse Leite's Atom syntax theme through the VS Code and Sublime ports. It also documents a bundled validation script that checks the manifest shape, the presence of the palette and of key Obsidian selectors and variables, and balanced braces, comments and strings in the CSS.
