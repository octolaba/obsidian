# andrewmcgivery/obsidian-ribbon-divider

Ribbon Divider adds dividers to Obsidian's ribbon so that its icons can be spaced into groups. Dividers are created and removed in the settings screen and then dragged into position in the ribbon like any icon. Their appearance is left to CSS: the README gives selectors for changing the padding, width and colour of all dividers, and notes that each divider also carries a class built from its own unique id, shown in the settings, so a single one can be targeted. It further discusses Obsidian's ribbon icon-order behaviour, where plugin icons do not always keep the arranged order.
