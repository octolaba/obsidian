# mmarusiak/pdf-emojis-plugin

PDF Emojis exports notes as PDFs while retaining the emoji characters that appear in headings, bold text and anywhere else in the note. The README describes the feature set as exactly that and shows a before-and-after comparison. Installation is by downloading a release and extracting it into the Obsidian plugins folder, after which the export runs through Obsidian's own export-to-PDF feature.
