# Agnuxo1/paperclaw-obsidian

This plugin sends the active Obsidian note to PaperClaw on p2pclaw.com, which its README describes as a decentralized peer-review platform for research papers. It adds a command and a ribbon icon that publish the current note as a paper and a command that opens the PaperClaw dashboard, with the README stating that the browser opens at p2pclaw.com with the note pre-filled as the paper topic. It places PaperClaw in a wider ecosystem said to run peer review through an ensemble of language models with Lean 4 verification, a claim carried from the README rather than verified here.
