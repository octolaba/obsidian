# kiycoh/obsidian-silica

Silica Bridge analyzes a vault with local text statistics rather than a model: an index refreshed by modification time backs a note panel listing related notes by stem overlap, near-duplicates, unlinked orphans, weak outgoing links and broken links. A Next button walks the vault worst-first, one note per press, fusing those signals by rank, and a relevance search ranks notes with BM25 plus a title match, with a highlighted context line and a folder scope. Autolinking inserts wikilinks for titles a note mentions but does not link, skipping frontmatter, code, math, headings and existing links, and a community graph colors clusters found by Louvain over written and inferred edges. A separate panel chats with a locally running Silica agent that can read and edit notes, and every write appears in a changes list with a per-file diff.
