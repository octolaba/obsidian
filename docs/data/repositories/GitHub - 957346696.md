# amatya-aditya/obsidian-zen-space

Zen Space provides a separate file explorer view that shows the files of one folder, in a card-based grid layout, for working without the rest of the tree in view. It can create and update an index file for a folder as a map of its content, offers rename, delete and pin actions from hover buttons, keeps pinned files and folders for quick access, and navigates nested folders through breadcrumb trails. The README's installation instructions run through BRAT with the repository URL, rather than through the community plugin browser.
