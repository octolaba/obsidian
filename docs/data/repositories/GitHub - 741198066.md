# mnaoumov/obsidian-codescript-toolkit

CodeScript Toolkit lets Obsidian users run JavaScript or TypeScript from places such as the developer console, CustomJS, Dataview, JS Engine, QuickAdd, and Templater. It also supports modular scripts, plugin prototyping, API exploration, and invoking scripts through commands or hotkeys.
