# NeuroCloud-Activate/Handwriting-PDF

The repository holds Handwriting PDF, an Obsidian plugin that sends a selected PDF of handwritten notes to Google Gemini and writes the transcription into a new Markdown note. The README records invoking it by right-clicking a PDF on desktop or through the file action on mobile, a note name defaulting to a date-and-title pattern that can be changed, a short summary before the transcription, and output using headings, bullets, emphasis, tables and LaTeX-style maths where Gemini identifies them. It records a cleanup pass fixing obvious spelling, punctuation and capitalisation while stating the transcription must not change content, meaning, numbers, dates or conclusions, action items tagged with a configurable tag, a link back to the source PDF rather than an embed, and an OCR-enhanced copy of the PDF produced afterwards. Setup requires a Gemini API key and a model chosen in settings.
