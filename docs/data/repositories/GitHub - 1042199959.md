# konnta0/obsidian-noctis-viola-theme

Noctis Viola Theme for Obsidian is a dark theme ported from the Noctis Viola theme for VS Code by Liviu Schera, which the README credits as the original work. It describes the palette as inspired by the night sky and documents installation through Settings, Appearance, Themes and the community themes browser. The theme is distributed under the MIT License.
