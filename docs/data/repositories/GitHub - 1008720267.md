# gapmiss/custom-theme-studio

The repository holds Custom Theme Studio, an Obsidian plugin for creating and tweaking custom themes without leaving the app. It provides live CSS editing, element styling and instant previews, and exports the result as a theme. The README states that it requires Obsidian v1.13.0 or later and that older Obsidian versions need an earlier release installed manually.
