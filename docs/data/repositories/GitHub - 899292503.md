# yuhanbo758/obsidian-yuhanbo-python

Adds a Run Python button to rendered python code blocks and shows the interpreter's standard output and errors in a modal, with the result copied to the clipboard on request. Each run writes the code to a freshly created temporary directory, launches the configured interpreter without a command shell, and removes that directory afterwards on a best-effort basis; runs longer than 30 seconds are stopped. The interpreter path is configurable and stored in the plugin's local data, and the plugin itself makes no network requests. It requires Obsidian 1.7.2 or later with Python 3 installed, is desktop only because it launches a local process, and does not sandbox the code it runs.
