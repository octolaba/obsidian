# ericmwalk/obsidian-bunny-publisher

Bunny Publisher uploads images and other media from an Obsidian note to a Bunny.net storage zone or a custom CDN hostname. A command scans the active note for local image embeds, uploads them, converts Obsidian-style embeds into Markdown image links pointing at the generated URLs, and can optionally delete the local files afterwards. Upload paths accept date placeholders for the year and month, filenames are sanitised and preserved for consistent URLs, and progress is reported in real time during the upload. The README also offers optional alt-text generation through OpenAI, Google Gemini or Perplexity with an API key.
