# scambier/obsidian-text-extractor

Text Extractor extracts text from images, PDFs and office documents in an Obsidian vault, and is presented as a companion plugin mainly useful alongside others such as Omnisearch. The README lists the supported extensions and records several limits: extraction rests on Tesseract.js and pdf-extract, PDF files often fail to yield text, extraction does not work on mobile, and an internet connection is required because the OCR language files are downloaded on demand even though processing happens locally. Extracted text is cached as small JSON files inside the plugin directory, which can be synced between devices. The README opens by declaring the project unmaintained, with pull requests and forks welcome.
