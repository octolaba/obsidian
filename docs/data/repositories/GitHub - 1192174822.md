# arangutambo/weekly-meal-shopper

Standardises recipe notes, parses ingredient metadata, builds weekly meal-prep canvases and generates categorised shopping lists from them, shipping its own starter templates so the core Templates plugin is not needed. The README states that templates, canvas planning, ingredient parsing and list generation stay offline and never leave the vault. Optional recipe transcription from a URL, from a folder of images, or when reformatting an existing recipe calls the OpenAI API with a key the user supplies, stored in the plugin's data.json and sent only to that API; with no key set, no request is made. Optional macro tracking, off by default and desktop only, fetches the USDA FoodData Central Foundation Foods dataset once and then works from the local copy.
