# nehloo/graphnosis-obsidian-plugin

Graphnosis for Obsidian is a plugin that indexes vault notes into a Graphnosis memory bank and recalls them from within Obsidian. The README records a recall command that searches semantically and inserts a chosen result at the cursor, a command that saves the current note, optional vault sync pushing modified Markdown files on save, and a catch-up sync at launch that picks up notes edited outside Obsidian. Notes can be routed into a specific memory graph, the recall token budget is configurable between 100 and 8,000, and a status bar item reports the bridge state. The README states the plugin talks to a local Graphnosis sidecar that must be running and unlocked, authenticated with a bearer token copied from the desktop application, and warns that enabling vault sync imports every existing Markdown file in one pass.
