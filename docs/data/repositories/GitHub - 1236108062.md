# krcnow/manex-brain

A local question-answering assistant over an Obsidian vault: the plugin indexes the notes and answers from a local MLX model, which the README says requires macOS on Apple Silicon, Python 3 and Obsidian 1.5.0 or later. On first load it creates a Python virtual environment, installs mlx-lm, downloads a roughly 2.3 GB quantized Qwen3 model and indexes the vault in the background, after which the server starts whenever Obsidian opens. Answers draw on retrieval across the whole vault plus the currently open note and its linked, backlinked and shared-tag notes, with clickable source links, chat memory within a session and re-indexing on create, edit, rename or delete. Its privacy section claims no network requests beyond the local server and no collected user data, recorded here as the project's own statement.
