# AndreasStandar/Obsidian-Theme---Purple-Aurora

Purple Aurora is a dark theme for Obsidian and its author's submission to the Obsidian October 2021 event. Its colours are meant to suggest the blue and minty green of an aurora borealis against a dark purple sky, and specific changes were made for the Calendar and Kanban plugins. Smaller touches listed in the README include fold icons that stay faded until hovered, subtle tag pills, a more distinct border around preview windows, lower opacity for smaller headings, a gradient border and large quotation symbol on blockquotes, and gradient vertical lines connecting bullet points.
