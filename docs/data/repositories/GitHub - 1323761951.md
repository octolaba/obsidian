# stagars-m/group-tabs

Group Tabs combines several files into one native Obsidian tab that shows a group name and member count and opens members in place. Groups form by holding one tab over another before dropping, by dragging File Explorer selections or a folder onto a tab, or through an Open as tab group menu action; members can be searched in a popup, reordered by dragging, and expanded back into ordinary tabs. Navigation from search, bookmarks, backlinks, the quick switcher and internal links keeps members inside the group tab, and group names, membership, order and active member persist per saved workspace. A sidebar view lists recent groups with a configurable history limit, and an export command combines a group's Markdown members into one file, preserving order, frontmatter, code blocks and links, with a header listing sources and counts.
