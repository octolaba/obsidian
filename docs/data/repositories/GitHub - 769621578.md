# BungaRazvan/confluence-link

Confluence Link converts an Obsidian Markdown file into a Confluence page so that documentation written in Obsidian can be shared with a team. Its settings take the Confluence domain, the Atlassian account email and an Atlassian API token, with an optional default space in which pages are created, and its commands are run from the command palette or from user-assigned hotkeys. In the spaces modal a space can be starred as a favorite so that it appears first next time, and typing `??` followed by a title runs a fuzzy search across every space the account can reach.
