# gapmiss/inline-callouts

Renders inline code written in a bracketed syntax as a small inline callout badge carrying a Lucide icon, a label and a color. Modals create a new inline callout and modify an existing one, an editor auto-complete suggester proposes icons while typing, and a further modal searches for inline callouts. The README presents the plugin as a successor to the same author's Badges plugin, with simpler syntax and access to all Lucide icons, and states that it requires Obsidian 1.13.0 or later because the settings tab uses the declarative settings API, with 0.1.12 offered to earlier vaults.
