# BlakeC2010/context-titles

The repository holds Context Titles, an Obsidian plugin that prefixes folder context to note labels in Graph View and Local Graph so repeated names can be told apart. By default it changes only labels that are duplicated in the visible graph, so a unique note keeps its plain name while two notes of the same name in different folders each gain their folder. The README states that the plugin changes the displayed label only, renaming no file, altering no note content and requiring no frontmatter title, and that settings cover the label mode, folder include and exclude rules, path mode, custom separators and live preview.
