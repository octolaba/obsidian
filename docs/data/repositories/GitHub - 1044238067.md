# Andy-Stack/vaultkeeper-ai

Vaultkeeper AI is an Obsidian plugin that brings Claude, Gemini, OpenAI, Mistral and self-hosted local models into the vault with note management capabilities. The README describes three chat modes — read-only, edit, and a planning mode whose agent drafts a strategy for approval before execution — with proposed changes shown in a diff viewer and any created, edited or deleted file restorable to a previous version. It also lists tag, file and folder mentions with autocomplete, custom system instructions, persistent conversations, glob-based privacy exclusions, reading of PDF and Office documents, stored vault memory, and optional web search.
