# StephenCarboni/obsidian-unique-tab-labels

Unique Tab Labels prefixes tab labels with parent folder names until the open tabs no longer share a label, adding one further level of folder at a time while duplicates remain. The README states that the plugin needs no configuration and exposes no settings. It also records the limitation that the labels are changed by patching the rendered tab-header DOM, because Obsidian exposes no public API for built-in tab labels, so a future Obsidian update may break it.
