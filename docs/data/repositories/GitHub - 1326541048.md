# Gloumi/obsidian-html-prototype-viewer

Opens .html and .htm files from the vault in a tab, rendering them inside an iframe so the prototype's own CSS and scripts stay out of Obsidian's interface. The file is resolved through Obsidian's resource URL rather than a local web server, which also makes it work on mobile, and the preview reloads when the file changes on disk. Render width switches between full width and desktop, tablet or mobile presets, a code block embeds a preview inside a note with optional height and width, and a strict-isolation setting drops the iframe's same-origin access for HTML from elsewhere. Only one view can own the .html extension, so another HTML-rendering plugin enabled at the same time wins or loses by load order.
