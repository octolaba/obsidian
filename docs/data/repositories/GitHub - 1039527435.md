# Raven-Pensieve/obsidian-next-toc

This repository holds Next TOC, an Obsidian plugin whose recorded description is a floating TOC panel. The README describes that panel as showing the current document's reading progress, its table of contents and navigation aids, and offers installation from the community plugin market or through BRAT for beta users. It is licensed under GPL-3.0 and ships an English and a Chinese README.
