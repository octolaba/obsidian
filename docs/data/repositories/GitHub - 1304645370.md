# ringeringeraja33/FederatedEmoji

Renders Mastodon-style custom emoji shortcodes in Live Preview and reading view while leaving the Markdown source as the plain shortcode. Typing a colon opens a shortcode search for insertion, and a searchable picker is available from the ribbon or the command palette, with emoji grouped by instance and server-provided category. Emoji are imported from one or more Mastodon-compatible instances configured by the user, with a priority order for duplicate shortcodes. The README states that the plugin sends unauthenticated requests to each configured instance's custom emoji endpoint, caches responses locally, and sends no note content.
