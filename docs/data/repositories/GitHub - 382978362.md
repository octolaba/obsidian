# erykwalder/quoth

Quoth embeds content from other Markdown files with more flexibility than Obsidian's standard embed syntax: parts of a single block, several parts joined into one quote, inline embeds that align with surrounding content, and automatic attribution of the source author and title. The README states that the simplest route is a copy-reference command, which turns a selection made in source or preview mode into a quoth block on the clipboard, bound by default to Control or Command with Shift and an apostrophe. Such blocks can also be written by hand: a path field addresses the source like an Obsidian link, optionally down to a heading, block id or list item, a ranges field selects subsections by quoted text or line and column positions, and further fields set the join string, inline display and which source fields are shown.
