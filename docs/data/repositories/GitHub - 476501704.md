# YukiGasai/obsidian-google-tasks

The repository holds Obsidian Google Tasks, a plugin for managing tasks held in the Google Tasks service from inside Obsidian. Its README records listing, creating and editing tasks — an edit being carried out as a new task and a deletion of the old one — marking them done or not done, and deleting completed tasks, while stating that working with a specific time of day is not supported by the upstream API. Setup requires a Google Cloud project with the Tasks API enabled and an OAuth consent screen configured, and the README carries a notice urging an upgrade to at least version 1.5.0 to avoid a possible corruption of attachments.
