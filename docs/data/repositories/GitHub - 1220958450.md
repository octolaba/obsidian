# polleoai/gryphon

Gryphon is an Obsidian plugin providing an AI chat panel that reads and edits vault files through a tool-use loop. The README records six provider options — the Anthropic, OpenAI and Google APIs directly, or their locally installed command-line tools as subprocesses — with the Anthropic API as the default and the CLI modes as an advanced opt-in, and notes that the plugin is not affiliated with those companies. It records a built-in security layer whose curated list of sensitive paths and destructive commands always raises an approval modal, independently of the permission modes Prompt, Safe, YOLO and Plan, alongside an approve-per-call modal with diff preview. The README also records that the plugin was briefly published as Hermes at version 1.0.0 and renamed to Gryphon, with migration steps for settings and the vault folder.
