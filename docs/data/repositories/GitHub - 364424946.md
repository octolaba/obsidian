# ryanpcmcquen/obsidian-focus-mode

The repository holds Obsidian Focus Mode, a plugin that dims everything but the text being worked on. Its README records two commands with default shortcuts, a normal focus mode and a super focus mode that narrows to the active pane alone, the latter also reachable by holding shift while clicking. It documents the classes added to the document body in each state, so a vault can adjust the effect with its own styling, and gives a snippet that removes the dimming of non-active lines.
