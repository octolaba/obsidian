# RyotaUnzai/x-clipper

Saves X (Twitter) posts into the vault together with their images and videos. A post URL is pasted after opening the clipper from its ribbon icon or the Clip Post command; the plugin then fetches the post text and author information, downloads attachments into an attachments folder under the configured posts folder, and writes a Markdown note with frontmatter. Hashtags found in the post text are stored as tags both in frontmatter and inline, tag suggestions come from usage history with the previous selection pre-activated, and the README records Japanese support in filenames and tags plus an automatic fallback from fxtwitter to vxtwitter.
