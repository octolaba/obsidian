# leschuster/obsidian-advanced-copy

Advanced Copy copies Markdown out of Obsidian and transforms it into HTML, an Anki-compatible form, or any other format the user defines. Templates can be written for nearly every Markdown element Obsidian supports and are grouped under a profile, with variables such as heading level, element content, current filename and date; each command run asks which profile to use, and customisable default profiles ship with the plugin. The README's example uses are copying a note as HTML with working links, exporting a selection as Anki-compatible HTML, copying content with a reference back to the original note, and pasting snippets into chat platforms.
