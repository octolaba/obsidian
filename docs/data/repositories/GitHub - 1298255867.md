# fire-university/paperfolio-obsidian

PaperFolio for Kobo imports Kobo highlights as one note per book, sorted by position in the book rather than by when each highlight was made, and grouped under chapter names taken from the book's table of contents, falling back to reading the EPUB when the database carries no entry. Generated content sits inside a sentinel block, so re-syncing rewrites only that block and leaves anything written by hand around it untouched, and imports are incremental and de-duplicated. A connected Kobo reader and the Kobo desktop app are merged in a single sync, an index note lists every book by highlight count, and highlights can be rendered as callouts, blockquotes or bullet lists. The README states that the plugin is desktop-only and involves no accounts, servers or telemetry.
