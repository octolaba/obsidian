# Mara-Li/obsidian-symbol-linking

Symbol Linking allows a note to be linked by typing any trigger symbol, with each trigger limited to a folder or to a single file — in the file case the link resolves to a heading inside it, at a level chosen with a slider. Aliases set in a note's properties or metadata are supported, and the link type follows Obsidian's own wikilinks setting. The plugin's settings add a compatibility mode for use alongside plugins that show their own suggestions, such as the Tasks plugin, an option to keep the trigger symbol in the final link text, and a per-folder list of allowed file extensions; the README warns that linking to an image always embeds it.
