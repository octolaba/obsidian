# joeyyu123/obsidian-anki-cloze-sync

Sends flashcards written inside Markdown notes to Anki through AnkiConnect, covering native cloze deletions, question-and-answer cards, single- and multiple-choice cards, code-practice cards with a scratch editor, and interactive image-occlusion cards. Stable file and card identifiers mean a later sync updates the same Anki notes rather than creating duplicates, so review history survives edits. The current note, the whole vault, or every note on save can be synced, with deck and tag overrides taken from frontmatter, LaTeX and local media carried across, and a preview of what will be added, updated or removed. Cards deleted from the Markdown can be kept, suspended or removed in Anki, and the plugin needs Anki Desktop with the AnkiConnect add-on and Obsidian Desktop 1.5.7 or later.
