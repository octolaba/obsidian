# gibsonchan-5/easy-web-clipper

Easy Web Clipper fetches a web page through Obsidian's own request API and saves it into the vault as a Markdown note, started from a ribbon icon, a command, or a URL already on the clipboard. Extraction uses Mozilla's Readability engine plus extra cleaning rules that drop navigation, advertising, footers, share buttons and comments, and Turndown with its GitHub-flavoured plugin converts the remaining HTML, keeping headings, lists, tables and images. YAML frontmatter with title, source URL, author, date and excerpt is written by default with each field switchable, and the save folder and a filename template built from title, date and time are configurable. Only server-rendered pages can be captured, and images keep their original remote URLs rather than being downloaded.
