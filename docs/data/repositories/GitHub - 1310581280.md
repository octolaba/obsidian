# haivri/obsidian-simple-gallery

Simple Gallery renders a list of image embeds inside a code block as a responsive photo gallery, without frontmatter or per-image HTML, and a command converts images already dropped into a note into such a block, picking up the paragraph around the cursor when nothing is selected. Thumbnails can be dragged to reorder, which rewrites the block's source immediately, and captions and section names can be edited in place by clicking them, with Enter or a click away saving and Escape cancelling. The default masonry layout sizes each thumbnail from its own photo's proportions, and a grid layout in settings produces evenly cropped uniform tiles instead. The README states that the editing controls only rewrite the gallery block acted on, and that the plugin collects no telemetry and makes no network requests.
