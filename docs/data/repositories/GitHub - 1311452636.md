# BrohdeXC/MD2Resume

MD2Resume renders a Markdown note as a formatted resume and exports it to PDF from a preview panel opened by a Preview Resume button, with an Export as PDF button above the preview. Frontmatter properties supply the header block, covering name, email, phone, website, LinkedIn and GitHub plus a short bio, and those contact values become hyperlinks in the exported file. In the body, second-level headings become sections and third-level headings become entries: a vertical bar separates a title from a date range and produces job formatting with a dot leader and an optional italic subtitle, a colon splits a title into a project title and inline subtitle, bullets stay bullets, and other plain text lines become tag-list items. It is installed by cloning into the vault's plugins folder rather than from the community catalog.
