# TylerCarrol/obsidian-sketch-matter

SketchMatter builds SVG drawings out of Obsidian notes: each object is a note whose frontmatter carries a type tag, coordinates, an optional layer override, image identifiers and style overrides such as fill, stroke, stroke width and opacity. Built-in shapes cover polygon, polyline, line, circle, rect, ellipse, text and composite, and type definitions in settings extend those shapes or each other with default layers and styles; a note with several matching type tags emits one object per tag. Objects are ordered by layer and filtered by views, with blend to soften edges, mask to keep items inside bounds and seeded noise for jagged ones. A preview panel offers drag-and-drop editing, a toggleable grid, zoom and pan; renders export as SVG, and an inline code block places a chosen image and view in a note.
