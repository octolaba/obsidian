# London-Chen/gz-sync-obsidian

GZH Sync is a local command-line tool and Obsidian plugin that syncs the current Markdown note to WeChat Official Account drafts and to Feishu documents. The README records the pipeline as parsing the article, generating WeChat-compatible inline HTML, uploading body images and a cover to obtain a thumbnail media id, creating the WeChat draft, and importing the same article as an online Feishu document, with separate commands for the draft, the Feishu document and a local HTML preview. It states plainly that the tool only creates drafts and never publishes automatically, so each draft should be reviewed in the WeChat console first. Credentials for both platforms are recorded as required and entered in the plugin settings page, a local configuration file or environment variables, with an IP allowlist noted for the WeChat interface.
