# THeK3nger/obsidian-chessboard

Chessboard Viewer renders chess positions given in FEN notation as static SVG boards from a code block in preview mode. Board orientation, non-standard positions through a strict flag, and beta annotations for arrows, highlights and icons are recorded as supported, alongside experimental rendering of recorded games and optional navigation controls for those diagrams. The README states that the plugin is deliberately limited to visualization, aimed at diagrams and HTML or PDF export rather than game analysis or editing, and recommends another plugin for interactive play.
