# winters27/obsidian-byoc

BYOC is a self-hosted synchronisation plugin that syncs an Obsidian vault through the user's own cloud storage, and the README describes it as a community-maintained fork of Remotely Save that keeps that project's sync engine. It lists twelve providers, among them S3, WebDAV, Dropbox, OneDrive, Google Drive, Box, pCloud, Yandex Disk, Koofr, Azure Blob Storage and Webdis, connected with credentials the README says persist locally. A three-way merge engine tracks a local baseline to decide push, pull and conflict across sessions, and a conflict produces a timestamped copy instead of a silent overwrite. Optional AES-256 or rclone-crypt encryption is applied before data leaves the device, sync can run on a timer or on save, and an existing Remotely Save configuration is imported on first load.
