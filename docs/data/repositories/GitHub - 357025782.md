# charliecm/obsidian-tidy-footnotes

Obsidian plugin that adds a command tidying the footnotes of a note. It consolidates every footnote definition into one place, sorted by order of appearance, and re-indexes the numbered footnotes so their numbering runs in sequence. The README records the caveats: footnotes inside code blocks are parsed rather than ignored, the original positions of definitions are not preserved because all of them move to where the first one was found, and non-numbered footnotes do not affect the re-indexing.
