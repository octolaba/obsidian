# wesswart77/obsidian-ttrpg

TTRPG Campaign Manager creates and organizes the notes a tabletop campaign accumulates, covering campaigns, non-player characters, locations, factions, session logs, quests and loot. Commands set up a campaign with its system, setting, party size and status, create character notes carrying role, location, secrets and loot, log a session with a summary, cliffhanger, experience, loot and character wikilinks, and track a quest with its giver, status and rewards. A sidebar browses characters, sessions and quests for each campaign, and the campaigns folder is configurable; all commands are reached by searching the command palette.
