# Cogito-Ergo-Video/lcars-inspired-obsidian-theme

Cogito-Ergo-Video/lcars-inspired-obsidian-theme holds a minimalist theme drawn from the LCARS interface design language created by Michael Okuda for Star Trek: The Next Generation, over a true-black canvas with elbow-framed panels and pill geometry. Two working hues carry the load, orange for structural elements such as frames, headings, tags and the active file, and periwinkle for interactivity such as links, bold, selection and scrollbars, with lilac, pale blue and salmon in supporting roles. The Antonio typeface is embedded in the theme and applied only to the note title, H1 and H2, while body text and small interface labels keep the reader's default fonts, and the README describes an LCARS standby console rendered on the New Tab page.
