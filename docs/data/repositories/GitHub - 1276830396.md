# SurprisedDuck/obsidian-orange-book-cloth

Orange Book Cloth is an Obsidian theme with warm paper-like surfaces, a clay and coral accent on links, tags, checkboxes and the active tab, and serif headings set in a bundled Newsreader so nothing is fetched over the network. Dark and light mode are both warm-neutral rather than blue-grey, and coverage extends across the editor, callouts, tables, code and the app chrome. The README states that it is an independent, unofficial theme inspired by the Claude and Anthropic visual aesthetic and is not affiliated with, endorsed by or sponsored by Anthropic.
