# skye1349/contextual-ai-reader

The repository holds Contextual AI Reader, a desktop Obsidian plugin for reading in a foreign language, covering translation, contextual vocabulary explanations, text-to-speech, excerpts, PDFs, Markdown and YouTube transcripts. The reading language can be chosen or auto-detected and the learning language chosen separately, with auto-detection and Simplified Chinese as the defaults. The README states that it can drive local assistant command line tools such as Codex and Claude Code or call OpenAI and Anthropic directly with an API token, and that it requires desktop Obsidian on macOS, Windows or Linux.
