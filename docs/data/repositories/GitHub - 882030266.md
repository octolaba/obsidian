# damonsk/obsidian-wardley-maps

This plugin displays and edits Wardley Maps written in the OnlineWardleyMaps format inside Obsidian. A map is written as a code block in a Markdown file using the wardleymap language, and the README carries a worked example whose syntax covers a title, anchors, components with coordinates and label offsets, evolution steps, dependency links, annotations, notes, a style and a size. Its getting-started section warns that a recent version of the Obsidian installer is required, since an older installer can keep the plugin from loading properly.
