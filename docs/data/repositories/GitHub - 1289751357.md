# THANSHEER/obsidian-noteflare

NoteFlare publishes a vault, a folder or a single note as a static site built by a separate site generator, and can mirror the vault one way into a private GitHub repository as a backup on a schedule or after edits. Publishing pushes the content to a private repository that Cloudflare Pages then builds and deploys, which the README presents as avoiding terminal work and continuous-integration configuration. Several sites can be managed from one vault, each with its own repository, domain and publish scope, and the README states that the GitHub and Cloudflare tokens are held in the operating system's encrypted keychain rather than in plain text. It is recorded as a desktop plugin.
