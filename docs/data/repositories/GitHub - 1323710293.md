# chachagogogo/obsidian-kakao-book-search

Kakao Book Search queries the Kakao Book Search API by title, author or ISBN from the command palette or a ribbon icon, and creates a note from the selected result. Generated notes carry cover image, authors, translators, publisher, ISBN and description, drawn either from a built-in default template or a custom template edited in the settings tab, whose placeholders also cover price, publication date and note creation time. The note folder, filename format, whether the note opens automatically and whether covers appear in the result list are configurable, and results are navigated with the arrow keys and Enter. A Kakao REST API key is required and can be checked with a built-in connection test.
