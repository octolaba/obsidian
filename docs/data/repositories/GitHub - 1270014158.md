# fyaic/Mermaid-Fixer-Plugin

Mermaid Fixer repairs Mermaid diagrams and Markdown tables that fail to render, with one command for the current note and one that scans the whole vault, each showing a diff preview before anything is applied. The current-file command re-validates the repaired note with Obsidian's own Mermaid renderer before reporting it clean, the vault scan shows progress and then a summary, and each fix rule can be enabled or disabled on its own. The README states that the plugin is local-only, with no accounts, API keys, network requests, telemetry or hosted service, and notes that a diagram which is valid in a newer Mermaid version but fails on Obsidian's older bundled renderer is a case for changing the renderer rather than rewriting the diagram.
