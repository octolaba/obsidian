# oirehT/unified-shopping-list-sorter

Unified Shopping List Sorter inserts a managed shopping-list block into an Obsidian note and keeps only that block sorted, leaving ordinary task lists elsewhere in the note untouched. The README states that the block is delimited by markers which the plugin hides in the editor while keeping them in the Markdown source, that sorting runs from a command or automatically after a configurable debounce, and that the ordering is unchecked items first, then checked ones, with untagged items before store-grouped ones and each group sorted alphabetically using German-aware collation. Store grouping is driven by configurable keywords matched case-insensitively at word and punctuation boundaries, and the README lists seven German grocery chains as the defaults while noting that the setting controls which names are recognised rather than a manual priority order.
