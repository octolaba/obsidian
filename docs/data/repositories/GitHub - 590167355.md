# greasycat/BetterMathjax

The repository records no description, so this note is grounded in the README alone. BetterMathjax adds autocompletion to MathJax editing in Obsidian, triggered inside a math block and showing inline rendering of the candidate as it is selected. It also offers a helper modal for reference and fast snippet editing, navigation between placeholders in an inserted snippet, and a configuration the README calls fully customizable. The README stresses that hotkeys must be set by the user and lists an example mapping for confirming an entry, moving through entries and placeholders, showing help and reloading the configuration file.
