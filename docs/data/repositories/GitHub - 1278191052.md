# TMK314/GitProgressTracker

Analyses the Git commits of a writing project to separate new writing, deletions and revisions instead of tracking word count alone. Revisions are detected by comparing word-frequency changes within a commit and measured with a Levenshtein word-level diff, so replacing one word counts as a single change, and results are reported as net word difference, gross work volume and pure revision effort. A scrollable heatmap shows daily progress with hover detail against a configurable daily goal, alongside overview, per-commit and per-day views, and the weights given to new, deleted and revised words are adjustable. The README requires the vault to be a Git repository with git on the path, states the plugin does not manage Git itself, and recommends writing one sentence per line, with glob file filters and an author filter available.
