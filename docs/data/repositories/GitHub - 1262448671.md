# zhaoyaoyuan/obsidian-douyin-capture

Douyin Capture Pro is a fork of an existing Douyin capture plugin that imports Douyin share links or pasted share text into an Obsidian vault, downloading no-watermark videos, carousel images and captions into structured notes with titles, hashtags, a tag callout block and frontmatter metadata. Video posts can be transcribed to Simplified Chinese by a local Whisper backend, with a second import mode that downloads the video and skips transcription. The README states the plugin depends on a separate local Python service that must be installed and run first, requires desktop Obsidian 1.4.0 or later, Python 3.10 or newer and FFmpeg for transcription, and that no Douyin cookie or paid speech API is used while the media stays on the machine.
