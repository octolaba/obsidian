# qian-shen/obsidian-reading-progress-desktop

A desktop-only Obsidian plugin that adds three status bar components: a full-screen button, a reading progress bar, and a view type indicator. The full-screen button and the view type indicator can be disabled in settings. Progress is tracked for markdown, PDF, search, thino and bases views, and the bar turns gray for other view types to show that it is inactive.
