# monapdx/Quizzable

Quizzable turns a quiz defined in a YAML block into an interactive widget inside an Obsidian note, which can be answered, submitted, scored and retried without leaving the note. The README records seven question types — multiple-choice, true/false, multiple-select, reorder, matching, short-text and numeric — two play modes, scoring by points, percentage and a passing score with per-question feedback, partial credit for matching and optionally multiple-select, and optional progress saving that it states is stored by the plugin without modifying notes. It works offline and standalone with an optional API for JS Engine, Dataview and Meta Bind, draws its colours from the Obsidian theme, and shows a clear message instead of breaking the note when a quiz is malformed.
