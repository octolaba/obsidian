# propranolol11/todoist-board

Todoist Board is an Obsidian plugin that displays Todoist tasks as interactive boards, either in the sidebar or inside a note through a fenced todoist-board block that carries a Todoist filter query. The README describes task actions for adding, editing, completing, deleting, scheduling, deferring, moving and changing priority, parent and subtask display with collapse controls, sorting, compact mode, manual order, polling refresh and cached offline display. Setup requires a Todoist personal API token, and the README states that existing plugin-data tokens are migrated to Obsidian Secret Storage where that is available. The plugin states that it avoids desktop-only Electron, Node and filesystem APIs and routes network requests through Obsidian's requestUrl, so it runs on desktop and mobile.
