# qoonmax/memmaster-obsidian-plugin

MemMaster turns notes into flashcards by command, tag or folder, or from selected editor text through the context menu, and schedules them with FSRS through the `ts-fsrs` package as each card is rated Again, Hard, Good or Easy. A review list shows the cards due now, sorted by urgency, and all spaced repetition data can be reset in one action. The README also records AI-generated multiple-choice tests built from flashcards and saved as Markdown files linked to their source cards, AI-assisted revision of a test without resetting its review progress, and support for OpenAI, DeepSeek or an OpenAI-compatible local server such as Ollama, LM Studio, LocalAI or llama.cpp.
