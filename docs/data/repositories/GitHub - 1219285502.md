# Cryptic0011/real-tasks

Deletes completed task lines from a note shortly after their checkbox is ticked, so a file keeps only the tasks still outstanding instead of a history of struck-through ones. A task checked in the editor is removed after 800 ms through the editor API and can be restored with undo; a task completed programmatically — by a Dataview checkbox click in an embedded query or by a sync client — is caught through the `vault.modify` event and stripped 400 ms later by rewriting the file. It recognises the `- [x]`, `- [X]`, `* [x]` and `+ [x]` forms, and a ribbon button and a command insert a fresh empty task line at the cursor.
