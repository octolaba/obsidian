# kkYrusobad/AbsoluteGruv

AbsoluteGruv is an Obsidian theme carrying three Gruvbox palette variants, Original, Hybrid and Strict Material, switched through the Style Settings plugin, with the palettes credited to the gruvbox and gruvbox-material projects. Headings are colour-coded by level, from red at H1 through orange, yellow, green and aqua to purple at H6, and code blocks carry full syntax highlighting. The interface is borderless, sidebar tabs stay visible by default, and lists draw bullet relationship lines. Its remaining Style Settings options mostly restore what the theme removes: auto-hiding sidebar tabs, the window title bar, scrollbars, collapsed pane borders, the status bar border, and left alignment for images and embeds.
