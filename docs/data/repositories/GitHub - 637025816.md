# Redwinam/obsidian-cubox

This plugin sends an Obsidian note to Cubox, a service with separate Chinese and international endpoints, through a Share to Cubox entry added to the editor's right-click menu. A Cubox API key must be entered in the plugin settings, which the README says has to be enabled from the Cubox extensions settings, and default tags and a default folder for new memos can be configured there as well. The README states that the plugin supports English and Simplified Chinese, and that only text content of no more than 3000 words is supported.
