# Charette-AI-Group/html-table-toolbar

Adds a toolbar for real HTML tables in notes, covering structural edits Markdown pipe tables cannot express: merging a selected rectangle of cells or splitting a merged one, inserting and deleting rows and columns, toggling a header row, setting column widths and alignment, and shading cells. Borders are set as a whole-table pattern plus per-row and per-column edges, each with its own thickness, line type and colour, and a table can be aligned, reformatted or deleted. New tables start from a hover grid that picks their size, with an optional header row, and the status bar shows which row and column the cursor is in. Every button is also a command that can be bound to a hotkey, and the toolbar's visibility, dimming and layout are configurable.
