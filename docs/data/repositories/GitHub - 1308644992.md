# IkariKr/obsidian-epub-reader-plus

Obsidian plugin that opens EPUB files stored in the vault in a paginated reading view, with mouse-wheel page turning, a compact table of contents and a theme-aware background that can be overridden with a custom colour. Publisher styles are preserved for headings, emphasis and relative typography, and reading progress is retained per book name while font-size changes anchor the visible text before reflowing. The README states that it replaces the unmaintained ePub Reader plugin, that both register the .epub extension and must not run together, and that it is based on caronchen's obsidian-epub-plugin under the same licence.
