# useroption3/obsidian-embed-eml

Embed EML renders .eml email files inline in a note through the standard embed syntax, in both Reading view and Live Preview, and also opens them in their own tab from the file explorer. The README states that the header block shows subject, From, To and Cc and a localized date, that HTML bodies render inside a sandboxed frame with automatic height fitting and fall back to plain text, and that inline images referenced by content id are resolved from the message's own parts. Remote images and trackers are blocked until a per-embed load button is clicked, attachments are listed with their size and can be opened read-only in the operating system's default application on desktop, and MIME parsing is handled by postal-mime.
