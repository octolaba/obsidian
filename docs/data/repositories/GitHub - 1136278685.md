# weppos/obsidian-mermaid-view

Mermaid View treats Mermaid files as first-class files in Obsidian, opening `.mermaid` and `.mmd` documents in preview, split or source mode with a CodeMirror editor carrying line numbers, syntax highlighting and undo. Diagrams pan by click-drag, zoom with the mouse wheel, reset on double-click, and can be exported as SVG or PNG. The README records that the same rendering applies to mermaid code blocks and to embedded mermaid files, and that a new mermaid file can be created from the file explorer context menu or the command palette.
