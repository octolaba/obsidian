# mvahaste/meridian

Meridian is described as a minimal theme for Obsidian, and its README states that transparency is only supported on macOS. Under a minimal and uncluttered interface it records sidebar toggle buttons, nav headers, tab headers and other chrome hidden unless hovered or focused, a tab bar that hides when only a single tab is open, and a status bar, backlinks and file metadata greyed and semi-transparent until hovered or focused. Installation is documented from the community themes list or by placing theme.css and manifest.json in a Meridian folder, with the Style Settings plugin optional for customization options.
