# sauremilk/obsidian-pwbs-sync

This plugin connects an Obsidian vault to PWBS, a hosted service that returns AI briefings drawn from the synced notes; its README is written in German. Only Markdown files are uploaded, settings and themes staying local, and synchronisation is incremental and can run automatically on an interval between fifteen and 120 minutes. The recorded briefing types are a morning summary, meeting preparation based on a calendar and related notes, and per-project context, all read in the Obsidian sidebar. The README further states that Google Calendar, Notion and Zoom can be connected as additional sources and that every statement carries source references, and that setup begins with creating a free account on the service.
