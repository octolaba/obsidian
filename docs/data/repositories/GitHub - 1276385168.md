# MichelleGDyason/pdf-scholia-scribe

PDF Scholia Scribe is a citation-focused fork of PDF++ for reading PDFs while writing scholarly notes: a copied passage keeps its link back to the exact PDF selection but shows a short citation label instead of a long file, page and color link. Its README records author-date, APA or Harvard page and numbered citation styles, an in-text paste rendering a quoted passage followed by the citation with the link hidden underneath, the retained quote and callout paste formats, and preference for the PDF's own page labels over raw page indexes. It also records a toolbar button opening the native PDF search with occurrence highlighting and result counts, Zotero-backed citation insertion that searches Zotero and vault source notes, and generation of a managed references section from the citations in a note.
