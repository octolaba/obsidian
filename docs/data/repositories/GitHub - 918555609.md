# dominikmayer/obsidian-reader-mode

Reader Mode opens every note that has content in reading mode by default, while leaving the reader free to switch into editing when needed; empty notes are opened in edit mode instead. The README recommends it for notes carrying footnotes, embeds, images or code snippets, and notes that it also avoids the case where a link is unclickable in edit mode because the cursor happened to be inside it when the note opened.
