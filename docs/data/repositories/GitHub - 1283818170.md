# junghyunbak/graph-type-to-search

This plugin brings type-ahead search to Obsidian's graph view: while a graph or local graph pane is active a small bar is pinned to its top-left and kept focused, so typing starts a query without opening a search box first. Nodes whose title contains the query are ringed with a glow drawn into the graph's own renderer, so it tracks pan, zoom and the simulation, optionally pulsing, with matching titles enlarged and non-matching nodes dimmed. By default the whole graph stays on screen for context; turning off the keep-all-nodes-visible setting instead pushes the query into the graph's built-in search and hides non-matching nodes. The README explains that a real, visible, focused input is what lets Hangul and other IME composition work correctly, and that `Esc` clears the query.
