# bobstanton/places-valhalla

A routing provider for the Places plugin backed by Valhalla. It builds routes between the waypoints in a block and isochrones around a center point, reads elevation for the points of a track, snaps a recorded track to the road or path network, and identifies the named ways that track follows. It runs no background tasks and takes its map, overlay and routing code from places-shared.
