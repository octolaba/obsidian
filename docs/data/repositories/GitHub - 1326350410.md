# CosmicSeaFox/Celestial-Abyss

Celestial Abyss is a handcrafted Obsidian theme with a dark mode of near-black backgrounds, nebula blue highlights and a soft violet glow, and a light mode of ivory surfaces and glass panels. Its styling covers reading and source modes, tables, properties, code blocks, callouts, tags and task states, and the graph view is treated as a constellation network. Dark and light modes and mobile layouts are both supported.
