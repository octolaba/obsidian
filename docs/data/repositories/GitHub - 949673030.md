# gasparschott/smooth-navigator

Smooth Navigator provides commands for cycling through tabs, leaves and tab groups that are already open, so they can be bound to keyboard shortcuts. It is explicitly not about searching for and opening files: the README argues that searching and dropdown lists are slower than repeating one keystroke when the file is already open in the workspace. Recorded commands move to the next or previous tab group, either in the workspace root alone or including the sidebars, move between leaves in the active tab group and jump to the first or last leaf, and the next and previous commands wrap from one end of a group to the other.
