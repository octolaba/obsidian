# Slaymish/Synod

Synod gives each of a writer's stated values its own LLM agent, lets every agent read the same period of journal entries in isolation, and then has a compiler look across their reports for the places where those values pull in different directions. The output is a short Markdown bulletin in the vault naming contradictions, what each value would have the writer do, and what is left unresolved; the README says the compiler runs an evidentiary gate, a tension finder and a tension validator before anything reaches disk. Entries are imported from a Rosebud export, a folder of free-form notes, or a daily-notes or Journals setup, and a one-shot extractor proposes values that the user confirms and redefines in their own words. The README states that the default backend is Ollama on the user's own machine, with OpenRouter or any OpenAI-compatible endpoint as alternatives.
