# bwtymdb/scan2md

Scan to Markdown connects a phone camera page to a desktop Obsidian plugin over the same Wi-Fi, then sends selected images to a configured vision model for structured Markdown. Results can be inserted at the current cursor or written to a new note, while an alternate path saves the original image without recognition; the plugin also handles basic image adjustments, formulas, and tables.
