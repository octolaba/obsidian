# lavich/domorium-obsidian

This plugin adds GEDCOM language support to Obsidian, opening .ged and .gedcom files for direct editing with tag autocomplete, real-time validation, semantic highlighting, folding, tooltips, quick fixes, and navigation between XREF declarations and their uses, including an atomic rename. The GEDCOM file stays the source of truth: records are not converted to Markdown and no second genealogy database is created. A note can link to a single record, either as a vault-indexed link that shows up in backlinks and the graph or as an obsidian URL, with completion, hover previews and embeds; fenced gedcom blocks in notes are highlighted and checked too. The parsed document is reachable from dataviewjs through a read and parse API, and the plugin runs on desktop and mobile.
