# pan4ratte/obsidian-classy-pdf-extractor

Classy PDF Extractor reads annotations out of PDFs and writes them into vault notes: highlighted, underlined, struck out and squiggly text, sticky note comments and free text placed on the page. Sources include the PDF currently open, every PDF in its folder, and a file or folder path taken from the clipboard, so documents outside the vault can be processed without copying them in. An advanced menu narrows an extraction to page ranges, to the days annotations were made and to the colors present in that file, while per-type templates control formatting and can move tags from annotations into the note's tags property. Output can go to the current note, a new note or one note per annotation, grouped by folder, file, date and topic, with headings and note names built from templates.
