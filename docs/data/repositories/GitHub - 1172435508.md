# wj0s3ph/obsidian-notion-plugin

Notion Database Sync pushes the active Markdown note to a selected Notion database and pulls the linked page back, storing the linked page identifier in the note's frontmatter. Frontmatter keys are mapped to Notion properties, the property list can be fetched from the target database in one action, and mappings are chosen from dropdowns rather than typed. The README lists the writable property types the serializer handles and states that read-only types such as formula, rollup and last edited time are deliberately not written back. Setup requires a Notion internal integration, and the interface follows Obsidian's language across English and Simplified Chinese.
