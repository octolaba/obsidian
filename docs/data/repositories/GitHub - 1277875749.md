# ghh-l-djl/obsidian-quick-capture-triage

Quick Capture Triage adds a sidebar panel to Obsidian for triaging notes that a separate self-hosted inbox pipeline has synced into the vault. Each untriaged note is listed with two actions: save, which changes its status property from inbox to active and moves it into a configured organized folder, and discard, which sends it to Obsidian's trash. The scanned inbox folder, the organized destination and a legacy inbox tag kept for compatibility with older notes are set in the plugin settings. Its README states that the plugin makes no network calls, never touches git, and only reads and modifies files already present in the vault.
