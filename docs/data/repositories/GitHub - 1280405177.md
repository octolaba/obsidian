# shuuul/obsidian-marp-extended

Marp Extended is an Obsidian plugin for creating, previewing, presenting and exporting Marp slide decks written as Markdown notes. The README records export to HTML, PDF or PPTX through a user-installed Marp CLI, bundled and custom Marp theme CSS, conversion of Obsidian image wiki-links to standard Markdown links, Mermaid diagrams rendered in a zooming and panning frame, and fenced Kami DSL blocks for slide metadata, lead text, callouts, columns and cards. It states that the project originated from Samuele Cozzi's Marp Slides for Obsidian and is now maintained as an independent plugin.
