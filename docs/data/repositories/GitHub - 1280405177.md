# shuuul/obsidian-marp-extended

Marp Extended turns Markdown notes into Marp slide decks that can be previewed, presented, and exported as HTML, PDF, or PPTX through a user-installed Marp CLI. It bundles and manages themes, supports custom CSS, converts Obsidian image embeds for Marp output, and renders Mermaid diagrams with interactive zooming and panning. Presenter notes, fragments, slide metadata, callouts, columns, and card grids extend the deck workflow while preview and managed exports share Marp Core 5.
