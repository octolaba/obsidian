# bobstanton/places-protomaps

A map provider for the Places plugin backed by Protomaps, supplying vector maps and POI discovery. It loads the selected style and its vector tiles from the Protomaps style API, with the label fonts and icons that style names fetched from the Protomaps basemap assets host. Rendering runs on maplibre-gl through the shared Places GL map implementation, and no background tasks run.
