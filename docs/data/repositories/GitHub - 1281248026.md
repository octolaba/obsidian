# laguna821/achmage-slides-ultra

Achmage Slides Ultra renders an Obsidian Markdown note as 1920x1080 slides in a side pane using Marp, without slide-specific syntax: the layout engine reads headings, lists, definition lists and nesting to choose grids and balance columns. A closed-loop measurement pass paginates or shrinks content so nothing is clipped in either the live preview or an export, and body, heading and label sizes scale together from a base font size that can be nudged by hotkey. The README lists built-in light and dark themes and export of a deck to a single HTML file that embeds its fonts.
