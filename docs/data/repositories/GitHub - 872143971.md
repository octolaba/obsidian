# henryco/BlazeJump-Obsidian

BlazeJump is a text-navigation plugin for Obsidian inspired by Emacs-Avy and Vim-EasyMotion. It provides five jump modes — to the beginning or end of a word, to the beginning or end of a line, and to any character — each bindable separately or reachable by cycling through a toggle-and-jump mode. The documented workflow is to activate a mode, type the character to jump to, then type the tag letter shown at the matching position. The README lists support for multiple keyboard layouts, ergonomic indexing and tagging, and full customisation.
