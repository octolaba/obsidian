# GitHub-Xzhi/obsidian-close-and-switch-to-recent-tab

Close and Switch to Recent Tab changes what happens after a tab is closed: instead of moving to the adjacent tab, Obsidian moves to the most recently visited one, the behaviour familiar from web browsers. The plugin tracks the last 30 visited tabs and applies this to any way of closing a tab, and it also registers a dedicated close-and-switch command that can be given a hotkey. There is no settings panel and nothing to configure.
