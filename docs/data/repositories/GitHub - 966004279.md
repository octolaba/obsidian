# forketyfork/obsidian-youtrack-fetcher

YouTrack Fetcher creates an Obsidian note from a YouTrack issue, fetched by issue id or by pasted URL from a ribbon icon, a keyboard shortcut or a command. The instance URL and an API token are configured in the settings, along with the folder for issue notes and a note template; placeholders in the template name the fields to insert, including arbitrarily nested ones, and the set of fields fetched is parsed from the template automatically. A separate command opens a search modal where a YouTrack query returns a paginated list of issues to import.
