# Dyse-Sofqi/Glimpse

Glimpse highlights text dynamically in Obsidian's source and live preview editors; reading mode and the legacy editor are not supported. Selecting text marks every case-insensitive match elsewhere in the document, showing them on the scrollbar and in an optional minimap, with selections above a configurable length skipped. Persistent highlights come from saved keyword or regular-expression queries, each with its own CSS class, colour and custom CSS, marking the whole match, its parent line, zero-width widgets at either end, or capture groups. A sidebar index gathers the note's standard highlights under their headings with cursor linkage and keyboard navigation, and a desktop-only floating teleprompter window shows lines, highlights or the current selection, optionally bound to one document.
