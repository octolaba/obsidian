# eondrcode/obsidian-manager

The repository records no description, so this note is grounded in the README alone. Better Add-on Manager is a manager for Obsidian community plugins aimed at vaults that run many of them, offering more than the built-in enable and disable toggles. The README describes delayed startup to keep launch responsive, batch controls, groups and tags for organising plugins by workflow, installation from GitHub releases, and guided diagnosis to isolate a conflicting plugin, arranged across five tabs on desktop and mobile.
