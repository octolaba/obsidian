# Atelier-Recherche/pandocit

PandoCit shows a formatted reference in Obsidian's sidebar for every Pandoc citation key present in the active note. Its README, written mainly in French, records that bibliography files such as BibTeX are converted to CSL JSON by Pandoc 3.9 compiled to WebAssembly and shipped with the plugin, so no system installation of Pandoc is needed, and that the same plugin runs on desktop Windows, macOS and Linux as well as on Android and iOS. It documents installation through BRAT and warns that the plugin folder must carry the plugin identifier, with settings and bibliography data copied over when migrating from an earlier Pandoc reference-list plugin.
