# hanabi-works/hanabi-theme

hanabi-works/hanabi-theme holds Hanabi, a high-contrast, dark-first theme family generated from a shared palette source and shipped for several tools, of which Obsidian is one. The README lists targets including Ghostty, iTerm2, Terminal.app, tmux and Visual Studio Code, and states that light variants are compatibility aliases unless noted otherwise. It also records that the project is built first for the tools its author uses, with support for other tools handled on a best-effort basis.
