# okawak/discord_message_sender

Repository for discord_message_sender, an Obsidian plugin that fetches messages from Discord channels through a bot and saves them into the vault as Markdown. Regular messages are stored per channel in their own subfolder as individual, daily, weekly or monthly files, a URL command clips a web page into Markdown, and the sync runs at desktop startup or from the command palette, with the notification sent back to Discord afterwards customisable or disabled. Setup requires creating a bot with the message content intent, inviting it to a server and listing the channel ids, and the README states that Obsidian 1.8.10 or later is required, that the plugin is desktop-only, and that confidential information should not be sent because it passes through the Discord API.
