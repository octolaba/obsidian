# DrBanshan/banshan-habits-tracker

An Obsidian plugin for tracking habits, storing its data as YAML frontmatter and Markdown tables in tracker notes so the files stay readable. Habits are toggled by clicking day blocks in a rolling window, scheduled daily, weekly or on chosen weekdays, and counted as streaks in a strict mode or a forgiving one with a one-day grace period, with a choice of keeping or deleting history when a habit is removed. Views include a dashboard with progress rings, completion rates, streak counts and per-habit analytics, a Today view with habit cards, a month calendar grid, a full-year heatmap that wraps to the window width, and per-habit monthly mini heatmaps; several tracker notes can coexist for different areas. The README records the project as based on Nodeencoder's Obsidian-Tracker, and the repository carries no description.
