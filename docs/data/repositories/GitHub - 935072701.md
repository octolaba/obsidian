# Kovah/obsidian-jira-auto-linker

Obsidian plugin that converts Atlassian Jira issue identifiers into clickable links when a note is viewed in view mode. Projects are registered in the plugin settings by entering the project key without an issue number together with the company Jira URL, and only registered projects are linked. The README describes installation from a release download and lists the community plugins entry as still to come.
