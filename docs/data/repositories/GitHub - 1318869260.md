# JeffreyL-3/ObsidianCanvasFixer

Restores clipboard copying of selected text inside Markdown and text cards while a Canvas is in read-only mode, and deliberately does nothing when the Canvas is editable. A setting chooses the copy format: Markdown with its syntax, visible text only, or visible text with rendered formatting attached for applications that accept it. Copying elsewhere, and inside editable controls on a Canvas, keeps Obsidian's native behavior, and canvases opened in separate windows are handled with per-window listeners that are removed when those views close. Cards embedding external web pages are out of reach for browser security reasons, and because Obsidian does not expose the read-only state publicly the plugin reads the Canvas view's internal flag, which an update could change.
