# Justin-J-K/obsidian-vega

This plugin renders Vega and Vega-Lite visualizations inside Obsidian notes. A chart is written as a code block whose language is vega or vega-lite and whose body is the JSON specification, which the README illustrates with a bar chart and a line chart. It refers readers to the Vega project's own documentation for how those specifications are formatted.
