# rca-umb/anchor-link-display-text

Anchor Link Display Text sets the display text of an anchor link — a link to a heading in another note — to the heading's name instead of leaving the raw link text visible. The README explains the saving against doing it by hand, particularly after tab-completing a link, which otherwise means moving back before the closing brackets to add a vertical bar and type the heading. The format of the display text is configurable, including the separator between multiple headings in one link — a single space by default, or something like a comma, colon or arrow — and version 1.4 added using a file property instead of the note name.
