# lifegems/obsidian-related-notes-finder

The repository holds Related Notes Finder, an Obsidian plugin that looks for notes whose title contains any word from the active note. Its README records a show-possible-links command with a default hotkey, a minimum word length defaulting to three characters, an option to skip the dailies path, a configurable stop-word list, and a setting that appends a link to each related note into the active note. A second command toggles that appending behaviour without opening the settings.
