# mmartamg/novadust-obsidian

Novadust for Obsidian is a dark blue colour theme inspired by the stars, designed for high contrast while staying soft enough for long, comfortable work. Its layout separates each section into a round-cornered box, and the colours deliberately give each type of title, list and text formatting element its own colour so that elements can be identified rather than blending together. The code block colours were chosen to match the author's Novadust theme for VSCode. The README calls the theme a work in progress and credits AllJavi for the layout inspiration and final touches.
