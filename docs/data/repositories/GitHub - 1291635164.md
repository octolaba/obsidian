# wanghuan9/obsidian-float-mark

FloatMark brings a Feishu and Lark Docs style annotation workflow to Obsidian notes, combining a floating toolbar over the current selection, inline highlights and a comment sidebar. Selecting text shows quick actions for bold, italic, strikethrough, inline code, highlighting and commenting, while hovering the left edge of a block offers actions to change its format between paragraph, heading, list, task, quote and code, or to comment on, copy or delete it. Highlights take a custom text and background colour and are located in the original text in both editing and reading mode; comments and visual marks are stored in a sidecar directory rather than in the Markdown. Comments can optionally be pushed to an already-published Feishu or Lark document, which requires the companion sync plugin's block mapping, a document URL or token in the note, and a logged-in lark-cli.
