# pedersen/obsidian-testing-vault

This repository holds the Obsidian Testing Vault plugin, which generates random vault content for use during plugin development. The README states that its three commands are deliberately bound to no hotkey and no menu entry because they are dangerous and can destroy an existing vault: one makes a single random note, one opens a dialog and generates a group of interconnected notes limited to 10,000 at a time, and one deletes everything in the vault without asking for confirmation. Generated notes carry Lorem Ipsum text, which the README presents as content the reader is meant not to care about while still exercising work such as an alternate rendering system or statistics.
