# alangrainger/obsidian-lazy-plugins

Lazy Loader is described as loading plugins with a delay at Obsidian startup so that the application's own start time falls below a second. Its README carries two cautions: the full effect may take up to two restarts the first time the plugin is used, and the plugin cannot tell whether another plugin was enabled or disabled by hand. For a disabled plugin to stay disabled across a restart, the README says it must be disabled from Lazy Loader's own settings page rather than from Obsidian's plugin list.
