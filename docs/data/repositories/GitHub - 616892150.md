# manibatra/obsidian-text2anki-openai

This repository holds Text2Anki using OpenAI, an Obsidian plugin that generates flashcards from note content through the OpenAI API and pushes them into a locally running Anki. The README records one command that processes the current file, states that bullet points work best, and shows a deck name set for a single note by a line at the top of that note. Settings cover the OpenAI API key, a default Anki deck name, the model to use and a custom prompt, and the README records a local Anki with AnkiConnect among the dependencies.
