# sergiodlash/goodreadsync

This repository holds GoodReadSync, whose README describes creating a note for each book on a Goodreads shelf by reading that shelf's RSS feed. The settings take a Goodreads user identifier, the shelf name, the target folder in the vault and the path to a template note, and the README requires the template to carry a book identifier property filled from the feed, because that value is what stops a book from being imported twice. Import runs from a command or from a ribbon icon. No upstream repository description is recorded, so this body rests on the README alone.
