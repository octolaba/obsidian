# nadavspi/obsidian-relative-line-numbers

The repository holds an Obsidian plugin that enables relative line numbers in editor mode, in the manner of Vim's relativenumber option. Its README records one prerequisite: Obsidian's own show line number setting must be enabled in the editor options. The recorded inputs describe no further configuration.
