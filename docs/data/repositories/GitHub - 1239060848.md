# Napard-web/liminal-plugin

Obsidian plugin providing an AI note assistant backed by the Anthropic Claude API under a bring-your-own-key model. Its commands generate a structured note from pasted raw text or from a YouTube transcript, propose a few tags for the active note, suggest semantically related notes as links, run a free-form instruction such as translation or rewriting over the note, and search the vault by meaning rather than keywords. Further commands cover note housekeeping: creating folders, deleting, renaming, moving or duplicating the active note, detecting notes sharing significant content with it, and removing broken links that point at non-existent notes. The README states the plugin is desktop-only and requires the user's own Anthropic API key.
