# jasonqg26/Nux-Exporter

Nux Exporter merges a whole vault, or one folder and its subfolders, into a single Markdown file written beside the exported material and named after it. The generated document carries export statistics, a hierarchical index, one section per source note with its original path and a unique document ID, and interpretation rules aimed at AI tools. Along the way it strips YAML frontmatter, turns wikilinks into plain text, replaces embeds with a bracketed filename, and pulls readable text out of Excalidraw notes without their compressed drawing data. Exports run from the command palette or a folder's context menu, skip the Obsidian configuration directory along with .git, .trash, node_modules and ANEXOS, make no network requests, and require Obsidian 1.5.0 or later.
