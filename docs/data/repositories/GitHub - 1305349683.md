# MSH-01/obsidian-youtube-panel

YouTube Panel opens a custom view in Obsidian's right sidebar holding a compact 16:9 player built on the privacy-enhanced youtube-nocookie embed, with a URL bar pinned to the bottom of the panel. It accepts watch links, short links, Shorts, live and embed URLs, playlists, timestamps and bare eleven-character video ids, restores the last video when reopened, and keeps a queue that persists across restarts and advances automatically when a video ends. Queue items show real titles resolved through the oEmbed endpoint, and a built-in search modal reports title, channel and duration, adding a result to the queue or playing it at once. The README states that no API key is used: search fetches the ordinary results page through Obsidian's requestUrl and parses the embedded initial-data JSON generically, looking for video renderer objects so that layout changes are tolerated.
