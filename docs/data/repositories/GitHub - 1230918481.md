# makinda-jackson/makinda-obsidian

makinda-jackson/makinda-obsidian holds Makinda, a single CSS theme that switches with Obsidian's appearance setting rather than shipping separate light and dark files. The README covers manual installation into a Makinda folder under the vault's themes directory, and records that theme.css is generated from a palette JSON file by an npm build script.
