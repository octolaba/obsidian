# mlava/scholar-sidekick-obsidian

Scholar Sidekick turns a scholarly identifier pasted into a note — a DOI, PMID, ISBN, arXiv identifier, ADS bibcode or PMCID — into a formatted citation, without a reference manager. The README lists commands that format a selection, replace the identifier at the caret, or open a modal offering five quick styles and a search across more than 10,000 CSL styles, plus commands that scan the active note and export every identifier it finds as a BibTeX or RIS file beside it, and commands that check the identifier nearest the caret for retraction or for open access. It states that the metadata comes from a public API backed by Crossref, NCBI, arXiv, Open Library, ADS and WHO IRIS, and positions the plugin for the case before a curated library exists, pointing at the Citations plugin for Zotero and BibTeX workflows.
