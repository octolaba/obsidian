# kevinmkchin/Obsidian-GitHub-Sync

This repository holds GitHub Sync, described upstream as syncing an Obsidian vault to a personal GitHub repository. The README says a single ribbon action pulls from the repository and pushes local changes, and that unmerged files are opened for the user to resolve when a conflict occurs. Setup expects the vault to be a Git repository whose remote has already been pushed to successfully, and the settings offer configurable notice levels, a shortened or hidden success notice, and optional automatic sync on startup when the vault is behind the remote.
