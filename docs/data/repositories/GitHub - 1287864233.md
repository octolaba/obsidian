# YzYhhhstudy/paper-deadlines

Repository for DDL Radar, a tracker for computer-science conference submission deadlines. The README covers roughly seventy conferences across sixteen areas plus rolling journals, with live countdowns, area and rank filters, alias-aware search, and a warning when a conference has an earlier abstract deadline than its full-paper date. It also documents an installable offline web app with browser reminders, timeline and board views, shareable filter URLs and a seven-language interface, while the recorded description adds CCF filters and calendar export.
