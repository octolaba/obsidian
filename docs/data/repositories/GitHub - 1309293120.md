# jasonfirkus/obsidian-move-tab

Move Tab is a small Obsidian plugin that moves the active tab left or right within its tab group, and into an adjacent tab group when the tab is already at the edge. It provides two commands bound by default to Mod+Shift+PageUp and Mod+Shift+PageDown, where Mod is Ctrl on Windows and Linux and Cmd on macOS. The README illustrates the behaviour with a three-tab example.
