# MichelleGDyason/vault-reorganizer

The repository holds Vault Reorganizer, an Obsidian plugin that previews and applies bulk vault cleanup plans, aimed at vaults that have grown into hundreds of folders. Its README proposes a target structure of nine folders for notes, images, videos, sound, attachments, templates, canvases, bases and other files, plus an archive folder the plugin leaves alone, and offers a flatter strategy that moves Markdown notes to the vault root. It records that a preview is generated before anything moves, that files are moved through Obsidian's file manager so links can be updated, that filename conflicts take a numeric suffix, and that rename failures reporting an existing folder are retried.
