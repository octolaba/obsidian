# nhaouari/obsidian-textgenerator-plugin

Text Generator produces text in Obsidian notes using AI providers including OpenAI, Anthropic, Google and local models. It is used to generate ideas, titles, summaries, outlines and whole paragraphs out of the context of a knowledge base, with that context assembled from configurable options. Templates make repeated tasks reusable and can be shared with other users, and frontmatter configuration lets a single note select a different service.
