# liyaomingme/Obsidian-Thought-Synapse-Desktop

Thought Synapse (Desktop) renders a vault's high-frequency words as a three-dimensional cloud in the Obsidian sidebar, driven by a physics simulation with damping and collision avoidance so the cloud can be spun with the mouse. Hovering a word highlights the other words that occur with it in the same note, and clicking one opens a context excerpt with a jump to the source note. A time filter restricts the notes considered to a recent window such as the last week, month or half year, and the height the view occupies in the sidebar is configurable. The README is written mainly in Chinese, records a periodic check that keeps the view stable as the sidebar is toggled, and states that the desktop and mobile versions use different architectures and should not be mixed.
