# Z1xus/mylonite

This repository holds Mylonite, a self-hosted sync server for Obsidian together with the plugin that pairs devices and syncs vault data end-to-end encrypted through storage the user runs. The README distributes server binaries for Linux and other platforms alongside a plugin archive, and records that release assets carry GitHub artifact attestations whose provenance can be verified with the GitHub CLI. It states that the project is still in early development and that bugs and breaking changes are expected.
