# stefan-imbesi/obsidian-rollover

One command closes the most recent dated note in a target folder and opens the next one: it finds the note whose name ends with a configured pending marker, replaces that marker with a done marker through Obsidian's rename API so internal links follow, and creates a new note for the next date in the same folder. The new note can be left empty, filled with a copy of the previous note's content, or built from a template with token substitution. The date is normally today's, so skipped days such as weekends are jumped over rather than filled in, and if the note being closed is already dated today or later the next day is used instead. Markers, labels and naming are configurable rather than fixed to one convention.
