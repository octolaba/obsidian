# Arkounay/obsidian-paste-ascii-table

Paste ASCII Table converts box-drawing and ASCII art tables into real Markdown tables at the moment they are pasted, and leaves ordinary prose and existing Markdown tables untouched. It reads light, heavy, double and rounded Unicode borders, plain ASCII borders and border-less psql output, rejoins cells the terminal wrapped over several lines, strips ANSI color codes and leading indentation, infers column alignment from padding, and escapes a pipe found inside a cell. Two commands convert a selection or the table at the cursor and sweep a whole note, and settings control paste conversion, wrapped-cell handling, pipe escaping, alignment detection and pipe padding. Columns are counted per line rather than read from the border, so a border-less two-column table is not detected.
