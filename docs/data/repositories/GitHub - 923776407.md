# bwya77/collapsible-code-blocks

Collapsible Code Blocks makes code blocks collapsible in reading and editing view and can give them horizontal scrolling. A toggle button in the top-left corner of a block collapses or expands it, reachable with Enter or Space when focused, and the collapse and expand icons, the number of lines left visible when collapsed and the default collapse state are configurable. A note can override that default by setting its `code-blocks` frontmatter property to collapsed or expanded.
