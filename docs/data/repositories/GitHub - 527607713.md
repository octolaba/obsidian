# Canna71/obsidian-mathpad

Mathpad is a computer algebra system for Obsidian, built on Nerdamer for symbolic and numeric calculation and on function-plot for 2D plotting. It consists of a sidebar plus code block and inline block support, where the sidebar works as a standalone calculator whose results can be copied into a note either as a dynamic code block or as static LaTeX. Code blocks and inline code carry computations and plots inside notes, and the README points to fuller documentation in the repository.
