# flowing-abyss/obsidian-hybrid-search-plugin

Hybrid Search combines BM25 full-text search with semantic vector search across an Obsidian vault, using a separate CLI for indexing and search. Its desktop modal offers live previews, relevance scores, similar-note results, query syntax, and a workbench with local graph and link-discovery views.
