# iibob/obsidian-app-launcher

An Obsidian plugin that adds a rocket icon to the ribbon which launches a configured application or automation in one click. On desktop the target is an executable or application path, and on mobile it is a URL scheme, including one that runs a named shortcut. The README, written in English and Chinese, gives as its use cases starting a sync tool before or after editing and opening auxiliary tools such as Zotero while working.
