# studiozojer/prose-obsidian

Prose is a typographic Obsidian theme built on IBM Plex, using Sans for body, headings and interface and Mono for code. Its type scale is a minor third made fluid with clamp(), the measure is a 700px readable line width, and the palette is warm neutrals, light #faf9f7 and dark #1a1917. Dark mode additionally uses antialiased rendering, a reduced font weight and letter-spacing compensation, and the theme is MIT licensed.
