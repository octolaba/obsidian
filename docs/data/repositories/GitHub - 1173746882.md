# aicayzer/obsidian-file-metadata

File Metadata adds a sidebar panel to Obsidian showing file information, text statistics and a document outline without writing anything into frontmatter. The file section lists name, path, folder, created and modified dates and size, the details section shows tags, backlink count and frontmatter properties, and the statistics section counts words, characters, sentences, paragraphs, estimated pages, reading time, a readability score, internal and external links and fenced code blocks. Headings appear as a clickable outline indented by level, images report dimensions, colour space and camera data read with exifr, sections collapse for the session, and clicking a row copies its value. Settings toggle individual fields and sections and choose short, long or relative dates, and appearance can be adjusted through the Style Settings plugin.
