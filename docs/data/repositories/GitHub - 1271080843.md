# PerezSJuan/Obsidian-Document-Export

Document Export renders vault notes into PDF, DOCX or LaTeX output in a single run, using pdf-lib for PDF and docx.js for DOCX. Notes are chosen either from an index note of wikilinks or picked and reordered by hand, headings are mapped to structures such as part, chapter, section and subsection or to inline styles, and a cover page, front matter and a table of contents of configurable depth can be added. Obsidian syntax is normalised on the way out: wikilinks, tags, highlights, comments, callouts and embeds become standard Markdown, embedded notes are inlined recursively with circular-reference protection, embedded PDFs are rendered page by page, and Mermaid diagrams and KaTeX formulas become images. Fonts, base size and page number position are configurable, settings can be saved as defaults, and the interface is translated into 24 languages.
