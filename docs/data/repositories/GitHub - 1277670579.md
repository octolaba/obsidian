# jkRaccoon/obsidian-fast-graph

Fast 3D Graph renders a whole Obsidian vault as a real-time 3D force-directed graph aimed at staying smooth on large vaults, drawing nodes as GPU-instanced spheres and links as one line batch with Three.js. The force simulation runs in a Web Worker on a WebAssembly physics core with automatic JavaScript fallback, and the README reports measurements on Apple Silicon of 60 FPS at around 10,000 nodes, 75 FPS at 20,000 and fluid rendering at 50,000. The layout is cluster-aware, grouping notes by folder or tag with cohesion and separation forces so communities stay spatially distinct. Interaction covers hovering for a title with particles flowing along the links, clicking to select and again to open the note, dragging to orbit, a local-graph mode limited to N hops from the active note, optional auto-rotation, and it respects Obsidian's excluded files setting.
