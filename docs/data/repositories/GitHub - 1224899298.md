# i-iooi-i/obsidian-memoria

Memoria is a lightweight flomo-style fleeting-thoughts plugin that captures quick memos, images, tags, and tasks into ordinary yearly Markdown files. A waterfall timeline, tag and keyword search, pinning, starring, heatmaps, calendars, statistics, and a year panorama support browsing and review, with mobile-friendly interactions and bilingual UI. It can also restore task checkbox changes to the Markdown source and soft-delete memos to a trash file.
