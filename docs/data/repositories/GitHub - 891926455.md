# LuigiCerone/obsidian-water-tracker

Water Tracker records how much water, or another drink, is consumed each day in Obsidian. A command or an optional ribbon icon increases the counter, and the size of the glass or cup used is set in the configuration. Where the total is stored is also configurable, as a property holding the running count in the current file or in the daily file, or as a drink event appended to a log in either of those files. The README shows how a log-based total can be summarised for the day with a dataviewjs block that filters the note's list items and renders them as a table.
