# Real-Fruit-Snacks/obsidian-nested-vaults

This repository holds Nested Vaults, an Obsidian plugin that scopes an entire vault down to a single folder treated as a temporary sub-vault, without opening a second vault window or losing plugins, themes and settings. While a sub-vault is active the file explorer shows only that folder plus anything whitelisted, core search and the graph views carry a path filter for it, the tag pane shows only tags used inside it, backlinks from outside are hidden, and opening an outside file is blocked with a notice. The README records that the sub-vault is left from the status bar or ribbon and that nothing about the files themselves is changed to make the scoping happen.
