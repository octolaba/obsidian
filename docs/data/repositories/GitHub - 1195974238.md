# witi42/obsidian-show-hidden-files

Show Hidden Files reveals dot-prefixed files and folders in the Obsidian file explorer and exposes files whose extensions Obsidian does not otherwise display. The README states that both settings are on when the plugin is enabled and are fully reverted when it is disabled, that the file-type setting mirrors Obsidian's own detect-all-file-extensions option, and that the vault configuration folder and the trash folder are always excluded from the hidden-file listing. It carries an explicit warning that enabling the plugin makes sensitive dotfiles such as environment and credential files visible, editable and deletable in the explorer.
