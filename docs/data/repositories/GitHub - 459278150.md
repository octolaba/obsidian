# oleeskild/obsidian-digital-garden

Repository for Obsidian Digital Garden, a plugin that turns selected vault notes into a published website. Only notes explicitly marked with `dg-publish: true` leave the vault and linked notes are never published automatically, which the README presents as the guard against accidental leaks. Published content covers Markdown and internal links, Bases, Dataview queries, Canvas, transcluded notes and drawings, embedded images and PDFs, callouts, MathJax, footnotes and Mermaid or PlantUML diagrams, with search, file tree, backlinks, graphs and hover previews on the site side. Obsidian themes, Style Settings, CSS variables and regex-based filters customise the result, and Vercel, Netlify and a managed service are listed as hosting options.
