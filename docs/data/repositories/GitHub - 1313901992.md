# OmarYazeedi/graphite-sync

Graphite Sync moves data between an Obsidian vault and a self-hosted Graphite server. Pulling a Space writes the server's canonical export of its modules, such as tasks, notes, calendar and expenses, into one Markdown file in a vault chosen at pull time, and a marked freeform region in that file is never regenerated. Pushing sends the edited file through a validating merge: errors come back with line numbers and nothing is written, while a successful push rewrites the file into canonical form. A sidebar panel shows connection status and each tracked file as in sync, locally edited or missing, with per-file actions, optional selective sync of modules and an optional auto-push shortly after typing stops.
