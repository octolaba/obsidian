# yo-goto/obsidian-card-view-mode

Card View Mode renders notes as cards whose vertical size follows how much content they hold, which the README presents as a way to judge at a glance whether a note is still atomic or has grown enough to be split. A second feature, the attention pane, highlights the active pane and greys the others out, with the colour difference configurable and a value of zero disabling it. Card colours, background, corner radius and drop shadow are configurable, the whole plugin can be toggled by command, and the README records Scrapbox and the Zettelkasten method as inspirations and names the plugins it was built to work alongside.
