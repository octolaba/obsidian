# logotipza/obsidian-ya-gpt

An AI chat panel for Obsidian that talks to several providers chosen in settings: Yandex AI Studio, Groq, OpenAI, Anthropic Claude and GigaChat. The panel keeps its history between sessions, searches the vault so answers rest on relevant notes, uses note creation and modification dates for date-based questions, and can add the current note to the context, listing the notes it used as clickable sources. Selected text can be translated, shortened, improved or explained from the context menu, and the answer is offered as a replacement for that text. The README states that the layout adapts to Obsidian Mobile and to the dark or light theme, and that the interface follows the Obsidian language setting in Russian or English.
