# zheng-shugan/obsidian-poster-wall

Poster Wall displays Markdown notes carrying one or more configured tags as a responsive poster grid, without Dataview, Bases or a separate media database, and a parent tag pulls in its child tags. Notes can be searched by title or vault path and sorted by recent modification or name, a click opens the note and a modifier-click opens it in a new tab, and cards take a half-star to five-star rating stored in the plugin's own data. Covers resolve in order from a note property, then the plugin database, then the first Markdown image in the body, then a placeholder, and may come from vault images, wikilinks, HTTPS URLs or images imported through the system file picker. It watches note, attachment and folder changes, never writes to Markdown or properties, and is desktop-only with support tested on macOS and Obsidian 1.12.7 or newer.
