# xgjk/obsidian-xgkb-sync

Obsidian plugin that syncs notes with the XGKB knowledge base. The README states that sync is bidirectional and can cover a single folder or the whole vault, and that a server URL, an app key and the sync folder and direction are configured in plugin settings. It records the plugin id as cms-xgkb-sync and a minimum app version of 1.6.6.
