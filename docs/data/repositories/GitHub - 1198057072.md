# hanamizuki/obsidian-skill-graph

Obsidian plugin that adapts Graph view to show the structure of OpenClaw or Claude Code agent skills. A `SKILL.md` node is labelled with the `name` from its frontmatter instead of the filename, files referenced inside it are parsed and connected with edges, and nodes are coloured by type, separating a skill root from a referenced file. The plugin is read-only: no original file is modified, every change is held in memory and reverts when it is disabled. It is used by opening an agent's skills directory as a vault, and the scanned skill filename and skills folder are settings.
