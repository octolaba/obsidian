# gregeld96/media-atlas

Media Atlas is a React-based media browser for Obsidian that shows the vault's images, including PNG, JPG, WebP, GIF and SVG, in a grid gallery. Images can be dragged from the gallery directly into a note and narrowed with a search filter, and the view updates when images are added, renamed or deleted in the vault. The README records that the community-plugin listing was pending review when it was written, and that a separately sold Pro version adds a cleaner for images not used in any note.
