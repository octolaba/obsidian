# ruisloan/obsidian-copy-note-text

The repository holds Copy Note Text, an Obsidian plugin that adds a copy icon to the action bar in the top right corner of a Markdown note, beside the reading-mode icon and the overflow menu. Clicking it copies the note's entire Markdown content to the clipboard and shows a confirmation notice, and an equivalent command in the palette can be given a keyboard shortcut. The README, written in Portuguese, states that the plugin works on desktop and mobile.
