# Daeik/obsidian-nomnoml-diagram

The repository holds an Obsidian plugin that draws nomnoml diagrams inside notes. Its README records a nomnoml fenced code block as the syntax, a command that inserts a generated block, and support for the format's own directives so a diagram can carry its own styling, with defaults set in the plugin options. It notes that every diagram is produced as SVG and that Obsidian's export to PDF includes the generated diagrams.
