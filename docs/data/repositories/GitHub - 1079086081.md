# mnaoumov/obsidian-edit-link-alias

Edit Link Alias adds an Edit link alias command that changes only the display text of the link under the cursor, and an Edit link command whose two-field pop-up edits the target and the display text together. The README states that both work on internal wikilinks, Markdown links, external links and links stored in a note's properties, and are reachable from the command palette, the editor right-click menu and the Reading-view context menu. Alt-clicking a link opens the same editor at the link with the alias preselected and Tab moving to the URL; the README notes this gesture is used because Obsidian assigns it no meaning on a link, and it can be turned off in settings.
