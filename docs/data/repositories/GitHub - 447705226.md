# jdeal/obsidian-path-title-plugin

The repository holds Obsidian Path Title, a plugin that shows the current file's path beside its name. Its README records a path font size option defaulting to medium, which can be set to match the file name or to be smaller still, and a set of path replacement rules applied in order from first to last. Those rules can replace an exact whole path or a single exact folder within it with alternative text, so a long path can be shortened or rewritten.
