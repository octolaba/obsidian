# joewhitsitt/obsidian-github-assignments

Appends GitHub issues and pull requests assigned to the configured user to the current note as checkbox items, avoiding duplicates already present in the note. Optional verbs distinguish issues from pull requests, a suffix can carry extra Tasks plugin fields or tags, and a created-date inline field can be appended. Tasks are inserted at the cursor position when the file ends with a blank line so ordered lists keep no gaps, and the README states that a personal access token with repo and read:user scopes plus a username must be configured.
