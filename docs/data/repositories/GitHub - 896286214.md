# ProfSynapse/obsidian-revisionist

Revisionist revises selected text with a language model from inside Obsidian. Text is highlighted and the revision is triggered from the ribbon icon, the command palette or the context menu, which opens a modal where instructions such as making the passage more concise or rewriting it for clarity are entered and settings such as the temperature adjusted before the suggestion is produced. The README also records word-count guidance intended to keep the request within workable limits, error notifications when settings or inputs need adjusting, and support for both mobile and desktop.
