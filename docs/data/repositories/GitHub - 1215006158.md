# graceruowenwang/obsidian-second-brain

Second Brain compiles scattered notes in a raw folder into a structured wiki inside the same vault, extracting concepts, entities and sources with a language model and writing linked pages, an index and a mind map. The README states that compilation is incremental, so only changed files are reprocessed and later runs finish in seconds, and that the result can be browsed or queried through a chat that cites the vault's own material. A long guide sets out what belongs in the raw folder: material the reader has already worked through — self-authored notes, or clippings that carry a highlight, a margin note or a line on why the piece matters — rather than unread saved links, which it says should stay in a read-later inbox until they become real input.
