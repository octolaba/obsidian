# pan4ratte/obsidian-advanced-word-count

Obsidian plugin for word-count presets displayed in the status bar or in a right pane tab, cycled by clicking either surface or from the command palette. Each preset carries its own metrics and its own handling of formatting elements, with metrics covering words, pages, characters with and without spaces, lines and paragraphs. Any metric can take a limit warning that colours it orange at 90 percent and red at 100 percent, or a goal that colours it green at 100 percent, can be renamed separately for each surface, and can be reordered by dragging. Community extensions supply further presets, metrics and settings.
