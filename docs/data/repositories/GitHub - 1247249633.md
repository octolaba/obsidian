# KORThomasJeong/Osync-p

Obsidian plugin that synchronises a vault across devices, mobile included, through a server that stores only encrypted blobs. The README states that content is encrypted on the device with AES-256-GCM before anything is transmitted, using a vault key derived from the user's password with Argon2id, and that the password cannot be recovered from the server. Sync runs when Obsidian opens or regains focus, reports its state in the status bar and can be paused and resumed, while each device decides independently whether images, audio, video, PDFs, other attachments and the Obsidian config folder are included and which folders are excluded. Vault management covers creating or connecting to a remote vault, disconnecting without deleting data, restoring deleted files, per-file version history and a conflict resolution pane, and the server is self-hostable.
