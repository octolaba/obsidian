# WalSplitter/vaultforge-obsidian

VaultForge connects Obsidian to Claude two ways: a local Model Context Protocol server bound to the loopback address, giving a client such as Claude Code or Claude Desktop read, write and search access to the vault, and an in-app chat sidebar over the same tools. The chat authenticates through an existing Claude CLI login instead of a separate API key, and the server component stays on the machine with no proxy in between. Managing Claude Skills inside the vault is described as its main focus, alongside chat and file access. It is described as early in development, with the server, vault tools, chat and skills management working and template generation planned; the interface follows Obsidian's display language in English and German, and it is not yet on the community registry.
