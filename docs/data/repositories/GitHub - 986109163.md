# Mara-Li/obsidian-alpha-bullet

AlphaBullet sorts unordered Markdown lists in Obsidian using natural order sorting, so that item2 comes before item10. Sorting runs ascending or descending from the command palette or the editor context menu, and a Create glossary command groups items under a heading taken from their first letter, with several combinations of group and item direction. Per-file automatic sorting is configured through YAML frontmatter on top of plugin-wide defaults, and the interface is available in English and French.
