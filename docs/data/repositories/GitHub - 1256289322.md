# usero2/obsidian-plugins-current-pane-media-gallery-viewer

The repository holds Current Pane Media Gallery Viewer, an Obsidian plugin that collects the images and videos embedded in the active note and shows them in a side pane. The pane and the document stay in sync in both directions: moving the cursor or clicking an image in the note scrolls the gallery to the matching item, and clicking an item in the gallery scrolls the note to its position in Live Preview, Source mode or Reading mode. A double click opens an image full screen, and a context menu on a gallery item offers actions such as copying the image to the system clipboard.
