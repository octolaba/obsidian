# AndyReifman/LinkMagic

The repository records no description; its README presents LinkMagic, a plugin that inserts links as text is typed by matching user-defined regular expressions. Patterns and their replacement URLs are configured on the plugin's settings page, the substitution happens in editing mode when space or enter is pressed, and the README notes that tab support is planned. Regular-expression groups are supported and can be referenced by number or name in the replacement link, and the README works through an example that turns issue keys into tracker URLs.
