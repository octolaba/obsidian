# jaliriogbarrios19/SupSync

SupSync synchronises a vault between several users through Supabase, covering notes, canvases, Excalidraw drawings, images, PDFs and audio, with binary files carried in Supabase Storage. Editing a note acquires a lock so other users see who is editing it, held by a heartbeat and released when the note is closed, after two minutes without typing, or on switching notes; reading never takes a lock, and when the same file changes locally and remotely a side-by-side diff modal resolves the conflict. The README documents a setup wizard carrying the database SQL, the storage bucket and its policies, commands to create a shared vault or join one with a vault id, and an interface in English and Spanish detected from Obsidian's own setting.
