# ransurf/obsidian-intelligence

The README describes an Obsidian plugin that integrates the OpenAI Assistants API, so assistants can be created and personalized inside Obsidian with custom instructions reused across conversations, files uploaded from the user's notes, and a code interpreter tool that writes and runs code. It opens with a disclaimer about model prices, listing the per-session code interpreter, per-gigabyte retrieval and per-token gpt-4-1106-preview charges as they stood when it was written, and noting that GPT-4 API access may depend on purchased credits. The README calls the functionality beta and less capable than the author would like, expects it to improve as OpenAI's assistants do, and directs readers to a published vault where its documentation links resolve.
