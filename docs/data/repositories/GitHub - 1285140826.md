# DFCEO/obsidian-stp-viewer

STP Viewer opens STEP files stored in a vault as an interactive 3D view, parsing their geometry with OpenCascade compiled to WebAssembly and rendering it with Three.js. Orbit controls provide rotation, panning and zooming with the mouse; display modes cover solid shading, wireframe and an edge overlay, and preset ISO, front, right and top views are offered from the toolbar. The README records rendering at actual size based on screen DPI, a scale bar with XYZ axes for reference, and support for the AP203 and AP214 flavours of STEP.
