# PixeroJan/obsidian-synonym

This plugin looks up synonyms for a selected word from inside Obsidian, using dictionary files kept in its own assets folder for offline lookup and optionally complementing them with an online source — Thesaurus.com for English and Synonymer.se for Swedish. A word is looked up from the context menu, the command palette or a ribbon icon, and clicking a result replaces the selected word. Custom synonyms added by the reader take priority over every other source, further language dictionaries placed in the assets folder are detected automatically, and the interface itself switches between English and Swedish.
