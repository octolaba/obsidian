# lolieatapple/obsidian-table-column-resize

Table Column Resize sets the column widths of a Markdown table by dragging the right edge of a header cell, which highlights when the pointer is over it. Widths are stored per note and restored when the document is reopened, and the README states that Reading View, Live Preview and PDF export all respect them. Two settings are recorded: the minimum width a column can be dragged to, 50 pixels by default, and an action that clears every saved width across all notes.
