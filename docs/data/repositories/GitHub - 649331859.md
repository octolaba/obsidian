# Bluemoondragon07/Obsidian-Bolt

Bolt is an Obsidian theme modelled on Android applications and Google's Material Design system. Its README presents the theme as ready to use without the Style Settings plugin, which is needed only to change the colour scheme. The credits record a community snippet used to give Markdown tables rounded corners and name the Obsidian You and Material Flat themes, alongside Material Design itself, as its inspirations.
