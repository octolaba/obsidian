# heidihelena/obsidian-study-familiar

Study Familiar is a study companion that pays XP for the act of reviewing rather than for the rating given: a concept rated 2 pays what a 5 pays, lowering a rating pays more than raising one, and nothing in it claims that a concept is known. It expects a fixed frontmatter schema, concept notes carrying type concept with confidence and last_reviewed, and source notes carrying type source and status; the folders are configurable but the keys are not, so a vault without them gets an empty dashboard. Commands cover a dashboard with level, XP, streak and badges, a five-point rating command, a ranked list of what to study next, a sprint timer ending in a recall prompt, link suggestions for unlinked concept mentions and a Zotero citekey link.
