# AngusK97/obsidian-eisenhower-matrix-blocks

Eisenhower Matrix Blocks embeds independent four-quadrant task boards directly in Obsidian Markdown notes, with each matrix owning its tasks, ordering, and completed history. Users can add, edit, move, complete, restore, delete, and filter tasks in place, keep multiple matrices in one note, and preserve surrounding prose and other blocks; data travels with the note and the plugin makes no network requests.
