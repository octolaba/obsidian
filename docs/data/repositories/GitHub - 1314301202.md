# raaneem/supernote-cloud-sync

Mirrors chosen files and folders from Supernote Cloud into the vault, preserving the Cloud hierarchy, syncing manually or on an interval, skipping unchanged downloads by checksum, and protecting locally edited files from overwrite. Native .note notebooks open in a reader with paging, swipe, zoom, pan, keyboard navigation and a virtualized thumbnail grid, and a whole notebook or one exact page can be embedded or linked, opening the reader at that page. Pages or multi-page selections export as Markdown, PDF, images, formatted transcription or a combination, with handwriting turned into text by the device's own recognition or an optional external transcription service or command. The mirror is one-way and Cloud-owned; files go back only through an explicit action or an optional conflict-aware paired folder, and the project states it is unofficial and unaffiliated with Ratta.
