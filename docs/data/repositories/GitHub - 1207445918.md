# StephQuery/obsidian-media-lens

Media Lens inspects media files from a sidebar panel, parsing an image, video, audio or subtitle file locally and listing format, codec, resolution, bitrate and duration in collapsible General, Video, Audio, Text and Image sections. Two files of the same type can be compared side by side with differences highlighted, two video encodes can be played back in sync from one transport bar, and a split view overlays them behind a draggable divider. Frames can be captured from either player, aligned to the same frame in synced mode or composited across the divider in split view, and any inspection or comparison can be saved as an auto-named Markdown note with embedded media, captured screenshots and metadata tables. The README states that all processing happens locally and no data is sent to any server.
