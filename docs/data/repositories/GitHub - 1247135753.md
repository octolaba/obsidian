# songkeeh/obsidianstar

File Recency Star marks recently created and modified files in Obsidian's file explorer. A marker character, chosen from several shapes and coloured separately for new and for modified files, is placed before or after the filename, and the title itself can be made bold, recoloured or highlighted; the marker icon can also be switched off so only the title styling remains. The thresholds for counting a file as new or as modified are independent and given in hours, defaulting to 24, and a rescan interval in seconds controls refreshing. Labels follow the Obsidian language setting between Korean and English.
