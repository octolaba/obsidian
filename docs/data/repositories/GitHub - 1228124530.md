# iscii/obsidian-better-explorer

Better Explorer adds sticky folder headers, in the style of VS Code, to Obsidian's built-in file explorer: when a large vault is scrolled, expanded parent folders stay pinned at the top and nested folders stack beneath them. The README describes it as a DOM enhancement over the core explorer rather than a replacement view, with no settings, no vault scan at startup, and no desktop-only APIs so it should work on mobile. It also states the plugin makes no network requests and collects no telemetry, and that at the time of writing it was not yet listed in the community plugin directory.
