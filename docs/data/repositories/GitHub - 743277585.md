# pjkaufman/obsidian-mobile-suggester-helper

Mobile Suggestion Helper adds three commands that move the highlighted entry in Obsidian's suggester up or down and select it, because mobile has no arrow keys. The README explains the case it was written for: with links configured as Markdown links, choosing a file from the wiki link suggester on mobile converts it straight to a Markdown link, which makes it impossible to reach a file that is not first in the list when the goal is to link to one of its headings. The author's own use is to put the up, down and select commands on the mobile toolbar, pick the intended file with them, and then continue with a heading or block reference.
