# AArlert/obsidian-auto-headings

Auto Headings recomputes number prefixes for headings from H2 downward when a note is edited, while preserving heading levels and allowing per-folder or per-file templates. It offers debounce timing, whitelists, frontmatter overrides, bilingual settings, and a manual renumber command; when numbered heading text changes, backlink references can be synchronized across the vault.
