# AArlert/obsidian-auto-headings

Obsidian plugin that numbers headings automatically and recomputes the whole file after editing, so inserting or removing a section renumbers everything after it. Its backlink sync rewrites heading references across the vault when a numbered heading is renamed, and numbering templates can be set per folder or per file, with a whitelist for headings that should stay unnumbered. The README states the plugin only adds or removes number prefixes and never rewrites heading levels, and the interface is bilingual English and Chinese.
