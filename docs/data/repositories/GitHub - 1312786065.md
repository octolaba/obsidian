# ArronHC/Text2Math

Converts a Chinese or English description of a formula into LaTeX by sending it to an OpenAI-compatible endpoint that the user configures, then previewing the result before it replaces the text. A selection can be converted from the command palette or the desktop context menu, and with nothing selected a dialog takes the description and inserts the formula at the cursor. Output can be inline, block, or chosen automatically for matrices, piecewise functions and multi-line derivations, and the preview allows editing the Markdown, switching the mode, regenerating or copying. The API base URL, key and model are all user-supplied, the model list can be fetched from the endpoint, only the selected text is sent, and a formula that fails to render leaves the original text in place.
