# Mars-Marcelyn/Shuffle-Lab

Shuffle Lab runs timed, randomised fullscreen image slideshows from a vault folder, aimed by its README at drawing practice and presentations. The duration per image is chosen from presets or a custom value, or set to an infinite mode in which navigation is manual and nothing auto-advances, and a loop toggle decides whether images repeat or the deck ends. A configurable break system inserts breaks at a set frequency with their own duration and a fullscreen countdown overlay, with a warning colour when the session would expire mid-break and breaks disabled when the duration is infinite. The README also lists a session timer with adaptive formatting, an optional intro prompt slide per folder, and session logging that prioritises unseen images next time, and it records the fixes made in version 1.0.4.
