# chrisgrieser/new-tab-default-page

New Tab Default Page is an Obsidian plugin that opens a note of the user's choice, or the Quick Switcher, whenever a new tab is created, in the manner of a web browser. The note and the mode it opens in are set in the plugin settings, closing the last tab also triggers the new tab page, and the README lists a homepage note, a daily note, a scratchpad, an image or a random quote as examples, the last built with a dataviewjs block rendered in reading mode. The README states that the plugin is in maintenance mode because its author no longer uses it, that no new features including support for other plugins will be added, and that it suggests more advanced alternatives such as Obsidian Homepage.
