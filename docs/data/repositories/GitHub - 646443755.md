# onuraycicek/obsidian-movie

This repository holds an Obsidian plugin that fetches movie data from OMDb and trailers from YouTube into notes. It requires an OMDb API key set in the settings and, only for trailers, a YouTube API key, and it writes into a movies folder and an assets folder whose names are configurable as the main path and image path. Searches are started from the command palette, a ribbon icon or a hotkey, and accept a title, a title with a year in parentheses, or an IMDb title identifier.
