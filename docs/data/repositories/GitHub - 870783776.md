# LeslyeCream/Lagom-Obsidian-Theme

Lagom is described as a phone-focused theme for Obsidian, which its README frames as making just the right amount of change for a more conventional and modern look rather than reinventing the wheel. Its stated principles are avoiding extreme minimalism that hides what is in the interface, making subtle but noticeable changes, symmetry and visual consistency, an exclusive focus on phones and tablets, no specific colour palette or typeface, and a complementary and modular design. Recorded features include a file panel occupying the whole screen with an optional pop-up style and file names shown in full across multiple lines, and the README names the fonts used for text, headers, monospace, code and quotes.
