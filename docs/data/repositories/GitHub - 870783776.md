# LeslyeCream/Lagom-Obsidian-Theme

Lagom is an Obsidian theme focused on phones and tablets, with restrained visual changes, symmetry, and consistency. Its options include a full-screen or pop-up file panel, multiline filenames, folder indicators, terminal-like code blocks, redesigned embeds, navigation elements, and optional callout styling.
