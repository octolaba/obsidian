# Azona77/lite-tabs

Lite Tabs displays open editor tabs in an independent Obsidian sidebar with vertical, card, or masonry layouts. It supports workspace, name, or recently modified ordering, title filtering, activation, closing, drag reordering, display controls, and customizable sizing and highlights. The plugin uses event-driven refreshes, avoids internet, clipboard, and vault-file access, and changes only workspace tab state and its own settings.
