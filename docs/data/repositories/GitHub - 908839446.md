# Youngmoss/obsidian-backgroundset

Obsidian plugin that manages the workspace background, compared in the repository description to a background extension for VS Code. A folder of images is registered, one of them is set as the background or a random one is chosen, and background changes can fade in and out. The README states that the current background must be deleted before a specific image can be picked, asks for a relative path from the vault that avoids dot-prefixed folders, and warns against extreme values for the change time, the transition time or the opacity.
