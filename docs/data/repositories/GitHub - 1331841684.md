# kaymade/cosmic

cosmic is a colorful Obsidian theme with coordinated light and dark modes and seven palettes, named Original, Red Dwarf, Blue Blob, Aurora, Eclipse, Stardust and Comet, each with separate light and dark values. Headings and interface accents are colored, code blocks carry colorful syntax highlighting, and tables, properties, callouts, embeds, Canvas, Graph, Bases and PDF views are styled, along with alternate checkbox states and optional per-note layouts. Default typography pairs Yeseva One for prominent headings and Tirra for note text with Inter and IBM Plex Mono. The theme runs without companion plugins, while Style Settings adds control over the palette, accent and heading colors, fonts, note width, spacing density, sidebar treatment, workspace background and callout style.
