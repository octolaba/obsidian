# SpeedaRJ/obsidian_folder_tabulation

Moves between the files of a single folder as if they were browser tabs. Two commands step to the next and the previous file relative to the current one and loop at the end of the folder, and a setting decides whether the file opens in the same tab, a new tab, a new pane or a new window, the last of which the README states is not supported on mobile. A file that is already open is focused instead of opened again. Two buttons for cycling are added to the file bar above the editor and can be disabled in the settings.
