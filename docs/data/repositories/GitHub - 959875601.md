# devonthesofa/obsidian-note-status

Obsidian plugin that assigns and tracks a status for each file, such as active, on hold, completed or dropped, from status sets the user controls. A status is set from a status bar badge, an editor toolbar, explorer context menus or commands, with single-status and multi-status workflows and quick-status commands available for hotkeys. File explorer icons reflect the status with configurable placement and visual treatment, and the README records a status dashboard and a grouped status view opened from the ribbon or a command, and states that the plugin works on Markdown and non-Markdown files alike.
