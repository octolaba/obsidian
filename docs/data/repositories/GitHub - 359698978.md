# tokuhirom/obsidian-2hop-links-plugin

This plugin displays the pages linked two hops ahead of the current note, shown at the bottom of the Markdown editor and, in later versions, in preview and live preview as well. Its commands can be bound to keyboard shortcuts, and an experimental setting moves the two-hop links to the top of the pane instead. The README credits Scrapbox and the originator of the two-hop link idea as its inspiration.
