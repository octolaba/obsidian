# ankitchouhan1020/papertrail

Papertrail adds a sidebar listing every Markdown note in the vault as a compact card with title, excerpt and modified date, plus a footer for filtering and quick creation. Its README, which calls the design Bear-inspired, records a right-click menu aligned with the File Explorer offering open in new tab, rename, delete, reveal in navigation where available, and the other file-menu entries contributed by Obsidian and by plugins. Settings are limited to the sort order, by modified date, title or path, and to hiding excluded paths including those containing a dot segment; Obsidian 1.5.0 or newer is required.
