# taisukemino/inoh-obsidian

Underlines words from an Inoh vocabulary deck as notes are written, matching inflected forms and multi-word idioms against real English forms so related but different words are not marked. Hovering a marked word, or tapping it on mobile, shows its definition, phonetic transcription, example sentence and pronunciation audio, with a link into the Inoh app and an action to drop it from the deck. Words can be added to the deck from inside Obsidian through a button above the selection, a long-press menu or a command, with a chooser when an entry has several meanings. The deck is cached locally so highlighting works offline, and the plugin contacts the Inoh backend only to sign in, download the deck and look up a word being added.
