# fyaic/DIDADI-obsidian-theme

DIDADI is a focused writing theme for Obsidian in which every heading level, H1 through H6, uses the same orange colour by default. Its README describes warm neutral backgrounds, a vivid orange accent and readable contrast in light and dark modes, and states that no extra configuration is required. It also records that the theme includes a 512 by 288 cover screenshot for the community theme gallery.
