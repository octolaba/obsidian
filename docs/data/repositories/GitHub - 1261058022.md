# viggomeesters/obsidian-yaml-viewer

Opens `.yaml` and `.yml` files in a dedicated Obsidian view that presents the document as a structured tree, showing maps, sequences, scalars, aliases, document and node comments, and parse errors. The tree filters by key, value or YAML path, an outline eases navigation through large files, expand and collapse controls sit beside buttons copying the raw YAML or a node's path, and a raw view adds line numbers and light syntax highlighting. The README explains that the viewer is read-only by design, because comments, anchors, ordering and formatting matter in such files and a form editor could reserialize and damage them. It makes no network requests, sends nothing to external services, and writes to the clipboard only when a copy button is clicked.
