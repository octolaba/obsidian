# sharfaroz7/frontmatter-cleaner

This repository holds Frontmatter Cleaner, described upstream as a way to review and remove stray frontmatter properties left behind by templates, one-off experiments, plugin residue or fields no longer in use. The README says the plugin lists every property of the current note with its value in a modal, offers select-all, select-none and an empty-values selector, and deletes the chosen properties in one action from a command or a ribbon icon. It states that deletion goes through Obsidian's own frontmatter processing API so the rest of the block keeps its formatting and order, and that rows use a 44-pixel touch target for mobile use.
