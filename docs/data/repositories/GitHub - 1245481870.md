# jabaho9523/obsidian-meetings-plus

Meetings Plus subscribes to one or more ICS calendar feeds, from Outlook, Google, iCloud, Proton, Fastmail or any standards-compliant source, and lists the day's meetings in a sidebar sorted by time with a marker on those that already have notes. Clicking a meeting opens a pre-filled note in the configured folder carrying attendees, time, location and agenda, or opens the existing note when there is one, and attendees arrive as links so a meeting connects to the people and projects it touches. The README records a multi-day agenda that collapses empty days into a single hint and jumps to a future date, navigation back through up to thirty configurable days for writing meetings up afterwards, and optional pre-meeting notifications with a configurable lead time, and states that there is no telemetry and no third-party service.
