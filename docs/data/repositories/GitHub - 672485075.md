# blorbb/obsidian-blockier

Blockier is a collection of small tools for editing blocks — a paragraph, a bullet point, a checkbox and similar — that the author wrote to fill gaps left by other plugins. Its select-block command, bound to the select-all shortcut by default, selects the block the cursor sits in while excluding prefixes such as bullets, numbers, headings, quotes and checkboxes, with options for multiple cursors, code blocks and selecting all on a second press. Typing a block prefix at the start of a block that already carries one overrides it, for bullets, numbered lists and checkboxes. It also offers suggestions for the custom checkboxes and callouts that some themes define, with configurable lists in settings.
