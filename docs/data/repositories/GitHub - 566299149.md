# ptrsvltns/hidden-folder-obsidian

This Obsidian plugin hides folders selected by regular expression, so patterns rather than exact names decide what disappears from the file navigator. A ribbon icon enables and disables the hiding, and the plugin is translated. The README is short: beyond that list it shows example patterns such as `^folder1` applied to a small folder tree.
