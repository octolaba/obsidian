# liamcain/obsidian-periodic-notes

Periodic Notes extends the daily-note idea with weekly and monthly notes, adding commands that open the current week's note, creating it when none exists, and that move to the next or previous weekly note chronologically while skipping weeks with no file. Those navigation commands are available only when the focused note is itself a weekly note. The README states that weekly notes are moving here from the Calendar plugin, that existing Calendar settings are migrated automatically, and that the Calendar plugin keeps working and uses these settings when week numbers are enabled.
