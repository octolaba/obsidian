# jcmexdev/obsidian-image-hoist

Image Hoist uploads local images out of an Obsidian vault to the ImgBB image host and rewrites the notes to point at the uploaded copies, which the README frames as keeping the vault small and the notes shareable without broken links. A single image is hoisted from the editor's right-click menu or a command on the cursor's line, a whole note's images can be hoisted at once, and pasted or dropped images can be uploaded automatically in the background if that setting is enabled. Duplicate images are recognised so an existing link is reused. Use requires a free ImgBB API key pasted into settings, and the README states that the plugin currently works only while the editor is in Source Mode.
