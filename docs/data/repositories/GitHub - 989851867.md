# Alecell/auto-replacer

Obsidian plugin that replaces text in a note as it is typed, according to rules the user defines. A rule pairs a regular expression pattern with a JavaScript transform function that receives the match, the editor and the file and returns the replacement, so a replacement can depend on context such as the note's own basename. Rules are created and edited in a visual interface and run on editor change with debouncing to limit the performance cost. The example rules in the README format units, convert decimal commas and Fahrenheit values, and emphasise occurrences of the note title.
