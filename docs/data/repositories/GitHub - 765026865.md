# jacobtread/obsidian-timekeep

Timekeep tracks time against tasks in a timekeep codeblock, inserted through a command or written by hand, and exports the tracked time as a Markdown table, CSV, JSON or PDF. Entries can be edited or deleted afterwards when a block was misnamed or a timer started late. The README states that the data is stored as JSON inside the code block, with start and stop times recorded as timestamps so tracking continues after Obsidian is closed and reopened, and that the plugin is inspired by and partly backwards compatible with an existing simple time tracker.
