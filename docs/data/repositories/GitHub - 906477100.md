# jlumpe/obsidian-spacekeys

Spacekeys runs Obsidian commands from short sequences of keypresses instead of from single hotkey combinations, in the manner of the Spacemacs Emacs distribution. One user-assigned leader hotkey opens a menu of the available keys, with related commands grouped under a shared prefix and displayed as submenus, so a command is reached by mnemonic rather than by a memorised chord. The keymap is customizable and can bind any command that accepts a traditional hotkey, including commands defined by other plugins, and the README records that no hotkey is assigned by default, in line with Obsidian's plugin guidelines.
