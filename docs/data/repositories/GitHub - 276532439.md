# mediapathic/obsidian-arsmagna-theme

Ars Magna is an Obsidian theme inspired by the works of Athanasius Kircher, presented by its README as a synthesis of other people's work: it began as deathau's Notation theme and incorporates that author's and cotemaxime's work on Andy Matuschak mode, plus a few additions the author wanted. The README states that it works equally well in the two modes it calls lucis and umbra. Installation is through Obsidian's community themes browser or, manually, by downloading an obsidian.css file into the vault folder and turning on Custom CSS.
