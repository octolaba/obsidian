# uuq007/obsidian-annotation-marker

Obsidian plugin that adds highlights, comments and ruby annotation to notes while keeping the annotation data in separate files, so the original Markdown is not modified. Five customisable highlight colours are available, an annotation can carry a note shown on hover, one click can annotate every occurrence of the selected text, annotations may span paragraphs and blocks, and overlapping regions are rendered automatically. A floating panel lists the current file's annotations for navigation, and a sidebar view browses all annotations by file with search and colour filtering. Reading mode renders annotations as coloured mark elements and live preview editing is handled through a CodeMirror 6 extension.
