# xaya1001/obsidian-Chemical-Structure-Renderer

Renders chemical structures from SMILES strings into PNG or SVG, using Ketcher and Indigo. The README describes writing the SMILES string inside a code block tagged smiles and switching to live preview or reading mode to see the structure, with reaction and polymer examples given. It states that the plugin was inspired by the Obsidian Chem plugin and warns that the two may conflict, because both transform smiles code blocks, so enabling them at the same time is not recommended.
