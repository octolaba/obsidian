# script-repo/Zoom-MyNotes-Obsidian-plugin

This repository holds Zoom MyNotes Sync, a desktop-only Obsidian plugin that deploys and controls a bundled Python and Playwright backend which downloads Zoom AI Companion and My Notes transcripts into the vault. A deploy wizard creates a Python virtual environment, installs dependencies, prepares the transcripts folder and registers a background job every thirty minutes, using Task Scheduler on Windows, a user LaunchAgent on macOS and a crontab entry on Linux. Sync and login commands and a ribbon button drive it, settings cover the backend path, transcripts folder, headless browser mode and interval, and each run sets the transcripts directory and browser channel environment variables. Network access is needed on first deploy to fetch Python and Playwright browser components.
