# shapkinaa/noteson-obsidian-plugin

Obsidian plugin that exports a single selected note as an HTML file to the NotesOn server. Right-clicking a note offers a publish command, which copies the public link of the exported note to the clipboard, and a second command that removes the note from the server. The README suggests it for sharing content such as a portfolio site by exporting a note and sharing that link.
