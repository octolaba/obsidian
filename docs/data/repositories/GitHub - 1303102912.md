# iTiPo/lava-plugin

This repository holds Getlava, whose README describes a chat view inside Obsidian in which models can read the vault notes a user explicitly mentions with an at-sign. The README separates a Chat mode with external tools unavailable from an Agent mode that can call configured Streamable HTTP MCP servers under per-tool controls, describes the vault tools as read-only so the assistant cannot create, edit or delete notes, and says conversations are stored with the plugin data in the vault. It records a closed beta with access by request, sign-in by email when prompted, and requirements of Obsidian 1.11.4 or newer on desktop. No upstream repository description is recorded, so this body rests on the README alone.
