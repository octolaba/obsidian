# wei2912/obsidian-latex

The repository holds Extended MathJax, an Obsidian plugin that extends the built-in MathJax support with a preamble file loaded at startup. Its README states that the preamble lives in a preamble.sty file at the root of the vault, where macros are added, and that additional MathJax extensions are enabled, mhchem and bussproofs among them. Changing the preamble requires running the reload-without-saving command, and the README records that the file has to exist before that reload for it to be read.
