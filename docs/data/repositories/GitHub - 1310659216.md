# decai335335-debug/oppopad-pdf-annotation

Obsidian plugin for stylus-first annotation of rendered Markdown and of Obsidian's own PDF reader on Android tablets and desktop. It offers a fountain pen and a translucent highlighter with adjustable colour, width and opacity, and separates inputs so that the stylus writes or erases while one finger scrolls or long-presses to select text and two fingers pan and zoom. Markdown annotation uses a fixed logical page width so camera zoom never rewrites coordinates, and PDF strokes are stored by file, page number and normalised page coordinate, so they stay aligned at any display size. Annotations live in a JSON file inside the vault, follow renames and load on desktop when the vault is synchronised, and the README states that there is no account, telemetry, advertising or automatic network request and that the project is not affiliated with the manufacturer.
