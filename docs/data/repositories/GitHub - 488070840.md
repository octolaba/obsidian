# danyim/obsidian-zenburn

This repository ports Zenburn, the classic low-contrast Vim color theme, to Obsidian. The README states that the theme is dark mode only and that it is best paired with the Inter UI and Inconsolata fonts. Installation is documented through Obsidian's appearance settings by searching for Zenburn.
