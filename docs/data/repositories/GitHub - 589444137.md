# alangrainger/obsidian-air-quotes

Air Quotes searches a source text and inserts direct quotes into an Obsidian note as you type, aimed at someone reading a paper book or an eReader while taking notes on a laptop or phone. The source has to exist as a Markdown note in the vault: an existing note works as it is, an ePub can be converted by the plugin's Import ePub file command, and other ebook formats need an external converter first. The README frames this against the alternatives of retyping the quote or capturing highlights through a separate sync service.
