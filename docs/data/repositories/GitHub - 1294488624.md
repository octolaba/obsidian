# chrisamber/obsidian-leadsheet

Leadsheet is described as producing performance-ready ChordPro lead sheets in Obsidian, with transpose, capo shapes, chord diagrams, set lists and autoscroll. Its README says chords are rendered over lyrics aligned per syllable so CJK lyrics work without fixed-width fonts, transpose is remembered per file with sharps or flats following the target key signature, and a capo toggle switches between sounding pitch and played shapes. Chord diagrams open on hover, focus or tap and follow the transpose and capo state; autoscroll is paced from the song's duration and has a tap-to-pause performance mode; set lists give one continuous view over several songs. Authoring aids include paste conversion of chords over lyrics, chorus repeat shorthand, invalid-chord underlining, and a CLI that validates, transposes and exports.
