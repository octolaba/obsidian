# Emberleif/Chronoboard

This repository holds Chronoboard, an Obsidian plugin for time tracking that turns Markdown tasks into draggable time blocks on day, week and month boards. A task pool is built from a configured folder and a metadata property such as Status, tasks are dragged onto the board to create time, and blocks are moved or resized in place, with right-click actions for colour, subtitles, block notes, precise edits and dedicated time entry notes. Time entries are written back into task frontmatter, so the source of truth stays in Markdown, and scoped totals are tracked for the day, the week and the month. The README states that it works well with TaskNotes-style task notes without being tied to TaskNotes, Jira or any particular vault structure.
