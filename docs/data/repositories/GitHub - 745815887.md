# simonknittel/obsidian-create-task

Create Task opens a modal that guides the creation of a single task and deliberately stops there, leaving task management to other plugins. Several target notes can be configured so tasks land in different notes rather than one, a configurable tag is appended to each created task, and due dates can be entered in natural language and written out in a configurable format. The modal opens from the command palette, from a ribbon icon, or through the Obsidian URL scheme.
