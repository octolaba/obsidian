# eddie/obsidian-time-log

Timelog supports lab-style note taking in Obsidian, where one Markdown document per project carries a dated heading for each work session and bullet points captured beneath it. The README records a command that inserts a dated heading as a link, automatic insertion of a bold time prefix at the cursor while bullet points are typed, and a command that jumps back to the latest dated log header. It states that the plugin takes its date format from the Daily Note settings when those are enabled and otherwise falls back to the ISO year-month-day form.
