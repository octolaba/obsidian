# joshwithers/wedding-computer-sync

Keeps contacts, weddings and checklists in step between an Obsidian vault and the wedding.computer service in both directions, storing them as plain Markdown files that stay editable on desktop and mobile. Each wedding is a folder holding its details in frontmatter with notes in the body, a checklist file whose boxes can be ticked anywhere, and a read-only change log. The README states that the server is the source of truth, that etags detect changes on both sides, and that local edits push a couple of seconds later. The sync token is generated in Wedding Computer, requires its Pro tier, and is kept in device-local storage rather than in the vault, so vault syncing cannot carry it away.
