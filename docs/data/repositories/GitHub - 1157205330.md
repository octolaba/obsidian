# lucasmantuan/task-states

Task States turns a click on a task checkbox into a cycle through six task states, namely todo, priority, progress, standby, cancelled and done, in Reading view, Live Preview and Source mode, with a seventh note state that stays outside the cycle. Each state has its own Markdown marker, name, checkbox and text color and optional strikethrough, and the four intermediate states can be dragged into a different order in the settings, which changes the click cycle accordingly. Any task can carry a date written as an inline field, set from a calendar button beside the checkbox in Reading view or from a command in the editor, with a configurable format, language and tag colors. The README states that everything is stored as plain Markdown, that no other plugin is required, and that it works with nested tasks and tasks inside blockquotes on desktop and mobile.
