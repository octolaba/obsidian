# alieron/obsidian-sequencer

Sequencer arranges notes into a fixed order by storing that order in two frontmatter properties, prev and next, so the notes stay ordinary Markdown files and the sequence can be inspected or edited by hand. When a note carries either property, previous and next arrow buttons appear in its header, opening the linked note or, with Ctrl or Cmd held, opening it in a new tab. Commands insert a note before or after the current one through a picker that can also create a note by typing a new name, and the plugin writes the matching links on the chosen note, the current note and the affected neighbour so the chain stays connected. The README suggests it for reading lists, lesson notes, project logs, daily workflows and drafts.
