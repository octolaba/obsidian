# oquhe/obsidian-scp

A simple command palette for Obsidian, opened by a command or by typing a trigger character in a note. Palette entries are defined through an alias syntax that separates hidden searchable text in square brackets, the displayed name, and a trailing description in braces, so long command names can be shortened while remaining findable. An entry can also carry a script, parsed as JSON: a string inserts text at the cursor, a number moves the cursor, an array runs several scripts in order, and an object selects a behaviour by tag — running a command by id or name, inserting text including the cursor position or clipboard contents, or moving the cursor. The README is written in Chinese.
