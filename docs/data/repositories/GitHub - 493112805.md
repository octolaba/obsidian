# lucaorio/obsidian-image-gallery

The repository holds Obsidian Image Gallery, a plugin that renders a masonry gallery from a folder of images already in the vault. Its README records a gallery code block whose keys give the folder path and the layout, with horizontal and vertical masonry among the types, and states that no other setup is needed beyond a folder of local images. It records Obsidian 1.1.8 or newer as the requirement and is licensed under MIT.
