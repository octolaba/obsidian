# ckelsoe/obsidian-annoteca

Obsidian plugin for categorised inline feedback comments in long-form Markdown, stored in the file as plain HTML markers so they stay readable without the plugin and can be stripped at export. Each comment carries a category naming the kind of feedback, with seven defaults for general revision work and presets for scholarly writing, fiction, code review and project planning, all editable with their own icon, colour and underline urgency tier. Commenting a selection tints the passage with a category-coloured underline and places a marker at its start, opening a comment highlights the passage it concerns, and replies are threaded inside the same marker with author tags. It works on desktop and mobile and requires Obsidian 1.13.0 or later.
