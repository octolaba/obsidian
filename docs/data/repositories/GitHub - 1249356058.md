# ckelsoe/obsidian-annoteca

Annoteca adds categorized, inline feedback comments to long-form Markdown documents, anchoring notes to selected passages and keeping threaded replies in the file. Its comment hub supports scopes, open or resolved tracking, starred items, and an AI revision flow that lets users accept, revise, reject, or restore changes. The plugin supports desktop and mobile use.
