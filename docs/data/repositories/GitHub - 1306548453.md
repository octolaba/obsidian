# GitHub-Xzhi/obsidian-mood-calendar

Mood Calendar shows daily notes in a sidebar calendar with the mood emoji read from each note's frontmatter displayed beneath the date. Clicking a date without a note opens a mood picker and creates the note with the chosen mood written to frontmatter, and hovering the mood property in the editor offers the same picker for an existing day. Markers distinguish dates with no note, a note without mood or pending tasks, and a note with unfinished tasks; the calendar follows the active file's month and can also be embedded in a note through a mood-calendar code block. It reads the date format, folder and template from the built-in Daily Notes or the Periodic Notes plugin, and its interface can be switched between English and Chinese.
