# denvolok/obsidian-sidebar-keyboard-navigation

This plugin adds keyboard-driven, Vim-like navigation to Obsidian's native File Explorer, which the README presents as filling the gap left by Obsidian supporting Vim mode in the editor but not in other tool windows. Individual keys can be disabled where they interfere with another workflow, and the plugin also changes some native behaviour: opening an already open file focuses its tab instead of creating a duplicate, most file-opening actions have a background variant that keeps focus in the File Explorer, a deselect-all action is added, and focus moves to a neighbouring node after a deletion instead of being lost. The README documents installation through BRAT or manually from the release assets.
