# obsidian-note-publisher/obsidian-plugin-note-publisher

Note publisher commits a single note and its embedded images into a private GitHub repository the user owns, using a fine-grained token scoped to that repository, and writes the resulting public link back into the note's properties and the clipboard. Each note is given a stable identifier in its properties, embeds are rewritten to relative filenames, and the public page is rendered by a worker the user deploys, with a hosted-worker and a self-hosted reference implementation named in the README. The README states that the plugin is a thin client with no vendor backend, so its author has access to neither the notes, the token nor the repository.
