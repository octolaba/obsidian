# highmagician/obsidian-any-task

The repository holds Any Task, an Obsidian plugin that renders arbitrary characters inside task checkboxes as visual, interactive checkbox icons. Its README states that markers such as a slash, a greater-than sign, an exclamation mark or a hyphen are drawn rather than left as plain text, extending Obsidian's default checkbox handling to custom workflows. It records built-in CSS adjustments for the checkbox styles of several community themes so that markers align with the active theme, and states that the plugin requires no configuration and starts working once enabled.
