# wruibin803-jpg/Xboard

A dashboard of configurable cards covering note capture, vault health, tasks, a calendar and a focus timer. Capture cards create diary, project-log and inbox notes from vault templates with custom forms, target folders and filename rules, while the health card counts orphan notes, empty notes, broken links and notes without properties and draws a year-long creation heatmap. Tasks live in a user-chosen Markdown file between a pair of start and end markers, with priority, deadline, sorting and a calendar view, and a focus timer records completed rounds per day. RSS and Atom sources are fetched only on an explicit or scheduled refresh into a visible cache folder, and on desktop a command-line AI such as Codex can be run in a sandboxed data directory with its results held there until confirmed for the vault; the interface is mainly Chinese.
