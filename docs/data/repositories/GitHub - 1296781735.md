# cnwenzhihong/Obsidian-workspace-plus-group

WorkSpace Plus Group extends Obsidian's built-in Workspaces core plugin, which its README records as a prerequisite that must be enabled first. It adds a fuzzy-search switcher opened from the command palette, from the status bar workspace name or by shortcut key, where typing a new name and pressing Enter creates a workspace. Workspaces can be dragged in the settings panel into parent-child hierarchies shown with indentation in the switcher, and renamed, reordered, collapsed and deleted there, while a folder in the file explorer can be focused from its context menu. The README is written in parallel English and Chinese.
