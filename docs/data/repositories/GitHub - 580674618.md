# omnivore-app/obsidian-omnivore

The repository holds an Obsidian plugin that imports saved articles and highlights from the Omnivore read-later service. Its README records a page created for each saved article carrying its metadata and labels, filtering of what is imported through the service's advanced search syntax, custom templates for the imported data, and building graphs from it. Setup is an API key created in the service and entered in the settings, after which a ribbon icon or a palette command triggers a sync, whose frequency is also configurable.
