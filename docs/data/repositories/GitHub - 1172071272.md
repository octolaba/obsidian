# saltyfireball/obsidian-sfb-open-in-new-tab

This plugin forces files to open in a new Obsidian tab instead of replacing the current one, covering the quick switcher, the command palette, bookmarks, search results, backlinks, the graph view, sidebar clicks and Markdown links. Its README explains the mechanism: it patches the workspace leaf lookup so calls that would reuse the current tab are redirected to a new tab, while calls already asking for a split or a window pass through unchanged, and it patches link opening so heading and block links within the same file stay put and an already-open file is focused rather than duplicated. An optional split preview mode pairs an edit pane with a reading pane whose navigation stays in sync, with a configurable direction, and the whole behaviour can be toggled from settings or the command palette.
