# b-yp/obsidian-autocorrect

Obsidian plugin that formats Markdown content with Autocorrect, the external formatter it wraps. The active note is formatted from a default hotkey, a ribbon icon, a right-click entry in the editor menu, or a command in the palette. Bulk formatting is also offered: a right-click entry on a folder formats every note inside it, and a settings button formats every Markdown file in the vault. The README states the plugin is MIT licensed.
