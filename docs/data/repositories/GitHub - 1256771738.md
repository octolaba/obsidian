# lesteraiagent/obsidian-full-vault-mirror-sync

Performs a one-way mirror of a source folder to a target folder on the same Windows machine by invoking robocopy with mirror flags. The README warns in its own words that the target is forced to match the source, that extra files in the target can be deleted and that a file deleted from the source can be deleted from the target on the next run, and states that this is not a backup tool and not a versioned backup system. Recorded safeguards include validation for blank, identical and drive-root paths, a confirmation prompt before the first sync into a non-empty target, post-sync verification of file presence, size, modified time and unexpected extras, and up to three retries after a failed validation. The README also lists what it does not do: no bidirectional or cloud sync, no telemetry, no Git or ZIP backup, and no checksum verification in the current release.
