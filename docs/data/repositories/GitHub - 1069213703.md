# waaraawa/ByteGrid

This repository holds ByteGrid, an Obsidian plugin that turns YAML definitions inside a bytegrid code block into interactive SVG diagrams of binary data and C struct memory layouts. A definition names the structure, its size and its fields by byte offset and type, and the plugin renders a byte-accurate grid with automatically assigned per-field colours. The README lists bit-level as well as byte-level layout modes for bitfields, default, dark and light colour schemes, and a legend whose position and column count are configurable. It names reverse engineering, protocol analysis and file-format documentation as the intended uses.
