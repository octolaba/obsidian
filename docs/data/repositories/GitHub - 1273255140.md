# Sevoni/save-history

Save History saves and restores versions of files in an Obsidian vault. The README lists manual saving, one-click restore with the current state automatically kept as a pre-restore backup, a character-level diff between any two versions or between a version and the current file, a draggable and resizable preview before restoring, grouping of versions by day, week, month or year, custom labels, bulk deletion, and export and import of one version or of a file's whole history. Autosave runs at a configurable interval and optionally when a tab is closed, with a cap on the autosaved versions kept per file and per-file overrides of those settings. It also records which extensions are tracked with Markdown always included, configurable snapshot and export folders, snapshots that follow renames and are removed when a file is deleted, and an English, Russian and Spanish interface.
