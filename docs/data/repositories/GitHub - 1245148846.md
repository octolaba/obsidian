# JamJan05/AI-Vault-for-Obsidian

Obsidian plugin providing a chat view over the vault with OpenAI, Anthropic and local models, switchable from inside the chat. Local models run through LM Studio, Ollama or another OpenAI-compatible server, retrieval searches Markdown and Canvas content in the vault, and specific notes or canvases can be attached to a conversation by hand. Chats are saved as history and can be grouped into projects with their own prompts and shared context, a response can be cancelled while it streams, and Fast, Normal and Think modes sit alongside a study-oriented Learn mode and a code mode. The README states it is desktop-only because history, projects, keys and the index may optionally be stored outside the vault, which needs desktop file-system APIs, and that Obsidian 1.7.2 or newer is required.
