# JamJan05/AI-Vault-for-Obsidian

AI-Vault provides Obsidian chat with OpenAI, Anthropic, and local models, using notes, canvases, selected files, and project history as context. Features include vault retrieval, manual context attachment, project prompts, saved conversation history, cancelable responses, thinking, learn, code, and web-search modes, with English and Polish UI. It is desktop-only and can keep history, projects, keys, and its retrieval index outside the vault; local API mode supports LM Studio, Ollama, and other compatible servers.
