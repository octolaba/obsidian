# sandsaber/Grimoire

Grimoire is an Obsidian plugin that runs command-line AI agents in a side panel against the vault. The README names Claude Code, Codex, Antigravity CLI, the legacy Gemini CLI, OpenCode, MiMoCode, Kimi Code, Grok Build and Qwen Code, sharing one model picker in the composer, and records that they read notes, edit files, run commands, call tools and keep session history against the real vault. A capability table records which providers support a local persistent runtime, history hydration, plan mode, image attachments, instruction mode, reasoning effort controls, rewind, fork, provider slash commands and a managed MCP interface. The README states that notes, folders and MCP tools can be mentioned to ground a turn, that cost and limits are shown beside the model selector, that nothing routes through a Grimoire server and no telemetry is collected, and that the plugin is desktop-only.
