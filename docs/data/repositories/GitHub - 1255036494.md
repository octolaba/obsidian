# sandsaber/Grimoire

Grimoire places local CLI agents such as Claude Code, Codex, OpenCode, and Qwen Code in an Obsidian side panel that can read notes, edit files, run commands, and retain session history. Provider selection, vault context, usage information, and supported agent capabilities are exposed locally, with no Grimoire backend, proxy, or telemetry.
