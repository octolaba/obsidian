# Raven-Pensieve/obsidian-custom-icons

Custom Icons assigns icons to documents and folders in Obsidian. Its README announces that version 1.0 is a rewrite with breaking changes: it aligns with the settings-page icons feature of Obsidian 1.11 and allows icons on the settings page, while the CSS-based configuration used by earlier versions is no longer supported and those features are only planned to return through a different mechanism. The recorded README documents installation and this notice but not the per-item configuration itself.
