# julioagh/english-write-checker

English Write Checker analyses selected English text in a note with a local LLM served by Ollama and marks grammar mistakes with a red underline and style suggestions with a blue one. The README states that each flagged phrase carries an inline suggestion chip that applies the replacement when clicked and an explanation on hover, and that a second command clears all suggestions. It lists Obsidian 0.15.0 or higher, a running Ollama and a pulled gemma3 model as requirements, with the endpoint, model and target level configurable, and states that no data leaves the machine.
