# scambier/obsidian-no-dupe-leaves

No Dupe Leaves is an Obsidian plugin that moves focus to an already open note instead of opening a second copy of it, while still honouring explicit instructions to force a new pane such as a middle click on a link. The README explains that Obsidian's default behaviour replaces the note in the current pane even when the target is already open elsewhere, leaving two instances of it. It warns that the plugin works by overwriting the public openLinkText function, so it also affects other plugins calling that function while leaving core features such as the File Explorer unchanged, and it directs readers to another plugin, obsidian-mononote, and states that no feature requests will be considered.
