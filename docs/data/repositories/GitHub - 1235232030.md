# yuzameOne/Inbox-Zero

Inbox Zero renders dynamic checklists inside an Obsidian note: a configuration block names a tag, the folders to search and whether to descend into subfolders, and the plugin lists every note in those folders carrying that inline tag. The listed files appear as checkboxes, and ticking one deletes the file permanently and removes its row, which the README frames as a way to drive a vault's backlog to zero. Entries can be reordered by drag and drop and the order is stored, so it survives an Obsidian restart. The plugin acts only where such a block has been inserted, and its README is written in Russian while the recorded description is in English.
