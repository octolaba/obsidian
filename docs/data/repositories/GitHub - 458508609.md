# JulesGuesnon/obsidian-markdown-shortcuts

This Obsidian plugin writes Markdown from commands rather than by hand, aimed at people coming from assisted editors and at constructs such as tables that are tedious to type. Typing the trigger character in a file shows the command list to choose from, and the settings change that character or insert commands without their examples. The README states which minimum Obsidian version is required and describes installing the release archive into the vault's plugins folder.
