# o1xhack/obsidian-sync-todoist

Sync Todoist keeps Obsidian checkbox tasks and Todoist tasks in sync both ways: adding a todoist tag to a checkbox creates the task, and completion, title, due date, priority, label and project changes flow in either direction, with indented child tasks becoming subtasks. Existing Todoist tasks and their subtasks can be imported at the cursor, and sync-todoist query blocks render filtered task lists inside a note. Daily-note planning writes the day's tasks into a managed marker region, and backfilling past daily notes offers presets for the recent 7 or 30 days, this month and last month, date-picker inputs, a preview-then-apply step, marker-only writes and no mutation of Todoist. The README states that HTTP calls use Obsidian's requestUrl rather than a Node-only SDK, so the plugin works on desktop and mobile.
