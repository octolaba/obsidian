# lumetrium/obsidian-teleprompter

Obsidian Teleprompter opens a teleprompter window that displays the contents of the focused note in a large, easy-to-read format and scrolls it automatically so a steady reading pace can be kept. The README documents controls for play, a countdown, pinning a note, scroll speed, font size, family, line height and letter spacing, padding, horizontal and vertical flip, text and background colour, view mode, opacity, keeping the screen awake, detaching the window and going full screen. It also documents a control panel, a page minimap and an eyeline indicator, together with hotkeys for the controls.
