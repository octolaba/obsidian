# yvonshong/genwiki

Builds a persistent wiki inside the vault from web clippings using a language model, rather than treating search as ephemeral. An ingest step scans an unprocessed clippings directory, has the model decide whether to merge the new material into existing wiki pages or create new ones, writes internal links between entities, archives the originals and records an audit log. A chat panel answers questions from a local index lookup over the five most relevant pages and cites them with wikilinks, and a synthesis from a chat can be saved back as a permanent wiki note. A linter audits wiki pages in batches for contradictions between pages, orphan files with no inbound links and stale placeholders and writes a report; index metadata is kept as flat files so the wiki syncs across devices.
