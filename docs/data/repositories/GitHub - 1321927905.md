# drbinsaad/obsidian-clinical-workspace

Keeps personal clinical follow-up, episode tasks and a surgical logbook in one vault, each record stored as plain Markdown with YAML properties and internal links. Its views cover a daily list of inpatients with overdue, due and undated work, patient cards showing pathway, priority and next action, task handling with repeats on completion, and a surgery view holding an operating-room booking queue, a procedure logbook and portfolio counts. One search box finds patients, record numbers, cases, tasks and procedures, and the layout follows the width of its own pane down to a single readable column. It is presented as a personal workflow aid rather than an electronic record, prescribing or decision-support system, and it provides no encryption, access control or compliance certification.
