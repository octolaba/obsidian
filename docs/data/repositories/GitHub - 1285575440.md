# akamsheh/sort-checked-tasks

Sort Checked Tasks moves completed checklist items to the bottom of their task group so unfinished items stay at the top. In Reading View the list reorders when a checkbox is clicked, while in Source and Live Preview the reordering runs from a command that sorts the current note. Ordering is stable within the checked and unchecked groups, sub-tasks travel with their parent and are sorted at every level of nesting, and the README records that fenced code blocks are ignored, mixed tab and space indentation is handled and the original line endings are preserved.
