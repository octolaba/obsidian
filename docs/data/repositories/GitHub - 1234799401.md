# Leike-Dev/Obsidian-Running-Head

Adds a customizable metadata header at the top of a note, showing creation and last-update dates, custom frontmatter properties, the folder path, and tab navigation. Dates can be formatted with eighteen bundled locales or with custom Moment.js patterns, and a separate update label appears when a note was modified after it was created. The README is available in English, Portuguese, Spanish, French and Simplified Chinese.
