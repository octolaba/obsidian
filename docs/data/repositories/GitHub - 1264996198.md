# lksrpp/obsidian-book-search-covers

Book Search + Covers searches Google Books or Open Library for book metadata and retrieves high-resolution covers from Google Books or Apple Books. It creates or updates vault notes from customizable templates, can link or download covers, accepts ISBN searches, avoids duplicates, and works with existing library notes on desktop and mobile.
