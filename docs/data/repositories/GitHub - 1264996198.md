# lksrpp/obsidian-book-search-covers

Book Search + Covers searches for books as you type and builds a note from the user's own template, down to the frontmatter properties and the file name. Metadata comes from Google Books or Open Library — the README notes Google Books wants a free API key while Open Library needs none — and cover art is pulled from Apple Books and Google Books side by side so the sharper image can be picked at 800x800 pixels or beyond. Covers can be referenced by URL or downloaded into the vault for an offline library, and an existing book note written by hand or by another plugin can be backfilled with a better cover. Search accepts a title, an author or a pasted ISBN, and the README states the plugin works on desktop and mobile.
