# MrGVSV/obsidian-github-embeds

This repository holds GitHub Embeds, described upstream as embedding GitHub issues, pull requests and code snippets directly in Obsidian. The README says that in reader mode the plugin finds GitHub links and renders a preview under them: issue and pull request addresses become previews, and blob addresses become file snippets that may be narrowed to one line or a line range, though the whole file is still requested. A GitHub personal access token is required, and the README lists the minimum repository permissions needed to reach private repositories.
