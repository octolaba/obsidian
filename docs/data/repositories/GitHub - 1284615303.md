# MasoudMiM/sketch-mechanisms

Sketch Mechanisms renders live, hand-drawn animations of common 2D mechanisms — four-bar linkages, slider-cranks, gear pairs, cams, pendulums and spring-mass systems — from a fenced block whose language names the mechanism type. Strokes are drawn with rough.js, so the drawing looks sketchy and follows the Obsidian theme colours, and the README records the result as a live SVG that plays in reading view and Live Preview, works on mobile and respects the reduced-motion setting. Every block accepts the geometry options of its mechanism plus shimmer, speed, roughness, stroke width, autoplay and caption; a four-bar linkage whose link lengths fail the Grashof condition rocks over the range it can reach and says so in a note under the drawing.
