# mkshp-dev/obsidian-gallery-plugin

Gallery View creates interactive image galleries in Obsidian notes from simple gallery code blocks, with responsive thumbnail grids, carousels, masonry layouts, and click-to-expand viewing. It can load local files, URLs, Immich, or Nextcloud sources, supports common image formats on desktop and mobile, and uses lazy loading with graceful fallbacks.
