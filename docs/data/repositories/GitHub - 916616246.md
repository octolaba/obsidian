# shane-lamb/obsidian-llm-docs

LLM docs is described as chatting with an LLM inside regular Markdown files in Obsidian. Its README says the conversation lives in a plain Markdown file that can be edited freely and kept in the vault alongside other notes, rather than in a separate chat window, and it names an existing plugin that shares that design while listing visual overlays, a completion button, a loading indicator and styled speaker headings as its own additions. It integrates with the OpenAI API and with self-hosted or local models exposing an OpenAI-compatible API, and it can follow links to other documents and include linked or embedded images as context in a prompt. The README records support for further providers and tool use as plans rather than present features.
