# ichaly/cohere

Obsidian plugin that syncs vault files through OSS or S3-compatible object storage, naming Cloudflare R2, Aliyun OSS, Tencent COS, Qiniu Kodo and MinIO as compatible services. The README lists manual and automatic sync, deletion sync with cleanup of removed content, conflict copies, optional syncing of empty directories, and import and export of the connection configuration, optionally including the access key and secret. It states that vaults are isolated by a vault id, devices distinguished by a device id, and that signature version 4 endpoints are used.
