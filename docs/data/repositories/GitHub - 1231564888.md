# polleoai/athena

A knowledge-base system built around an Obsidian vault in which URLs, papers, GitHub repositories, screenshots and videos are ingested and an LLM writes each one up as a structured wiki page cross-referenced with what is already there. The README describes a three-layer architecture — immutable raw sources, an LLM-maintained wiki layer, and a schema file that governs the model's behaviour — with wiki digests following fixed sections for key findings, methods, quotes and relevance, and bidirectional links between pages. A verb-driven kb command set adds, searches, queries, reflects, organises and prunes entries, usable in the terminal or through the bundled Gryphon chat surface with an Anthropic, OpenAI, Google or local CLI provider. The README states that the project is not affiliated with those services or with Obsidian.
