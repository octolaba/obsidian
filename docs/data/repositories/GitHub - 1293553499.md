# n23eos/vault_telegram_bridge

Vault Telegram Bridge delivers messages sent to a Telegram bot into an Obsidian note, without a server, VPS or Docker, on desktop and mobile. Text arrives as Markdown keeping its Telegram formatting, while photos, voice notes and documents are saved to the vault's attachment folder and embedded with their caption, and a hashtag routes an entry to a topic note. Folder, note name and heading are configurable, or one toggle writes into the note owned by the core Daily Notes plugin, and delivered message identifiers are recorded in the note's frontmatter so two devices syncing one vault do not produce duplicates. The README states that delivery happens only while Obsidian is open — the plugin polls Telegram every thirty seconds and there is no background execution on mobile — and that the settings interface is available in English and Russian.
