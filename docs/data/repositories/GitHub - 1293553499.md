# n23eos/vault_telegram_bridge

Vault Telegram Bridge polls a connected Telegram bot and places incoming messages in a configured Obsidian note, including the daily note when selected. Hashtag routes can send messages to different notes or headings, while text formatting remains Markdown and photos, voice notes, and documents are stored as vault attachments; delivery occurs while Obsidian is open, with message IDs recorded to prevent duplicate entries.
