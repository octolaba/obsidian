# norderan/RedShift-obsidian-theme

RedShift is described by the repository as a blue-light-free night theme for better sleep, aimed at OLED screens. It restricts the interface to pure reds, applies a red-scale filter to images, and uses a true black background so that OLED pixels are switched off entirely. The README explains the reasoning: driving only the red sub-pixels emits no blue light, which it says would otherwise delay melatonin production at night.
