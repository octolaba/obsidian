# lukasbach/obsidian-file-order

Defines a custom order for files and folders through number prefixes in their names, edited by drag and drop. A Reorder items entry in the context menu of any folder opens a dialog where items are dragged into place, and per-list options set a minimum prefix length, the delimiter and the starting index. Renaming updates every reference to the affected files, and a custom ordering can be cleared again, which strips the prefixes. The README states the plugin keeps no settings of its own: all ordering information lives in the filenames, so an existing ordering is inferred when the dialog is reopened and survives uninstalling the plugin.
