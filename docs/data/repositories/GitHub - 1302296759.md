# ririririse/obsidian-progress-dock

Progress Dock is a dockable Obsidian side panel for numeric goals, deadlines, countdowns and branching learning roadmaps that keeps its data in the plugin's own data file rather than in notes. The README states that numeric tasks carry a current value, target and unit and render as a bar, ring or number, that deadline dates take categories, notes and colours and appear in a month calendar and a countdown view, and that learning paths can be sequential or parallel with every node marked complete independently. Roadmap stages are written with an arrow between stages and a plus or pipe for parallel branches. The recorded text states that the plugin works with light and dark themes and makes no account, network request or telemetry, and does not modify note files.
