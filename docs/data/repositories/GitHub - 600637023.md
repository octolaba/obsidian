# atfzl/obsidian-apple-books-plugin

Obsidian plugin that syncs highlights from Apple Books into the vault. Syncing runs on Obsidian startup, from a command, or from a book icon in the left ribbon. The README states the plugin was inspired by obsidian-kindle-plugin.
