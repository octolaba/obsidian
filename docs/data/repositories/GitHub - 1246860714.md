# Cosmakes/MapTheMouseMind

This repository holds MapTheMind, an Obsidian plugin for neuroscientists working on the mouse brain, which anchors a vault to the Allen Mouse Brain Atlas. A reader moves from a 3D whole-brain view into a region, then into a 2D Allen reference section and individual cell morphologies, and can create a markdown note at any of those levels; the note captures the visual-anatomical context it was taken in and can link to other regions. The README records that regions and reference sections load from the Allen atlas while neuron morphologies come from NeuroMorpho.org, and that a search bar surfaces notes from every nested context.
