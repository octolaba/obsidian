# studiogamma/orbit-graph-view

Obsidian plugin that draws the vault as an orbital system in which child notes orbit their parent nodes, forming recursive multi-layered planetary systems. Parent-child relationships come from one of four sources chosen in the settings panel: a frontmatter key, a tag turned into a central star with virtual nodes where no note exists, outgoing links, or backlinks; edges that would close a cycle are ignored. Settings cover three themes, sibling sort order, orbital speed following the rule that nodes nearer the centre move faster, orbit radius and node size scaling, rotation of top-level nodes around their centroid, and toggles such as orbit traces. Right-clicking a node focuses the camera on it and dims the unrelated ones.
