# reallygood83/obsidian-embedder

Drive Embedder uploads local files from Obsidian to Google Drive and inserts the embed code for them into a note. The README lists video, audio, PDF and image formats, named size options such as Compact, Medium, Large and Full Width with narrower presets for audio, and a progress indicator during upload. Using it requires a Google Cloud project with the Drive API enabled and OAuth client credentials that the user creates and enters in the plugin settings; installation is documented through BRAT rather than the community plugin list.
