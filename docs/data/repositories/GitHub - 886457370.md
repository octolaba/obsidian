# land0r/obsidian-flowchart-plugin

Renders flowcharts written in flowchart.js syntax from a flowchart code block inside a note. The plugin settings customise the appearance of the rendered diagram, including line width, font size, font and line colours, and the styling of individual element types such as start and end symbols, decision conditions and operations.
