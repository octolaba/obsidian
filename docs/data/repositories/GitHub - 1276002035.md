# johannes-kaindl/image-to-markdown

Image to Markdown transcribes the images and PDFs embedded in an Obsidian note into Markdown through a local OpenAI-compatible vision model, streaming the result into a sidebar as the model produces it. A Describe mode generates a description instead of a transcript for text-sparse images such as photos, diagrams or whiteboards, with an editable category drawn from a configurable taxonomy and free tags, and a transcript and a description can exist for the same image independently. A transcript card can be refined by giving the model prose feedback, keeping a scrollable per-card history of rounds from which a version is chosen, and PDFs can be limited to a page range. The README describes the plugin as fully offline and non-destructive, and is published in English and German with the recorded description in German.
