# johannes-kaindl/image-to-markdown

Image to Markdown transcribes embedded images and PDFs into Markdown with a local, OpenAI-compatible vision model, streaming results in a sidebar. It includes a description mode, feedback-based refinement, PDF page selection, born-digital text handling, prompt presets, endpoint fallback, and visible thinking controls. Results are non-destructive and idempotent, with diff review before an opt-in overwrite; standalone images and PDFs can also be processed.
