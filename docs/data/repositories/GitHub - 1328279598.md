# NameIsKyro/text-alchemy

Text Alchemy is a set of command-palette actions that rewrite messy text into cleaner Markdown, working on the current selection or the whole note. It can remove blank lines, trim leading and trailing whitespace, join lines wrapped when copied out of a PDF, repair hyphenated line breaks, and remove duplicate lines either silently or with a list of what was removed. Other commands turn lines into bullet, numbered or checklist items, strip those markers again, re-number a list, add spacing or Markdown dividers around headings at chosen levels, and sort lines, heading lines or title-style lines alphabetically. Further conversions cover wiki-link lines and turning label-and-URL lines into Markdown links, and the cleaners can skip YAML frontmatter and fenced code blocks.
