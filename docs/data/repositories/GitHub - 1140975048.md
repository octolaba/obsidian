# oyuk/ai-auto-tagger

Obsidian plugin that generates tags for the active note through Google's Gemini API, run from the command palette and written into the note's frontmatter. The API key, the model (default `gemini-2.5-flash`) and the maximum number of tags are configurable. Generated tags are sanitised to Obsidian's rules, for example turning `AI API` into `AI_API`, and an optional setting shows the model the vault's existing tags so that variants are reused instead of duplicated.
