# LBerts/personal-finance

This plugin visualizes monthly personal finances inside Obsidian from a single CSV file kept in the vault. Its README describes summary cards for income, expenses and balance, a cumulative daily balance line chart, a monthly income-against-expense bar chart whose bars navigate to that month, a category breakdown table with proportional bars and percentages, and category and sub-category filters. The CSV contract is recorded there as well: case-insensitive columns with date, category and amount required, dates in year-month-day form, positive amounts read as income and negative amounts as expenses, and rows without a valid date ignored.
