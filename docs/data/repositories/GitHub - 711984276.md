# zhuxining/obsidian-attachment-uploader

Obsidian plugin that uploads local attachments to cloud storage by running a shell command the user configures. The command receives the local file path through a placeholder and the plugin extracts the resulting URL from the command's output with a regular expression; commands for the uPic and Picsee tools are built in. Which attachment formats are uploaded is configurable, the original attachment can be deleted after upload, and pasting or dragging a file in from outside Obsidian can trigger the upload automatically.
