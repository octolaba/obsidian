# johackim/obsidian-writing

This plugin is described by its README as a way to write and format a book directly from Obsidian. The features it marks as implemented are goal tracking and a word counter; export to PDF, EPUB and MOBI, a writing habit tracker, a book previewer for several e-reader and phone screens, and NaNoWriMo integration are listed as unchecked plans rather than existing behaviour. The project is licensed under the GNU GPL v3.0.
