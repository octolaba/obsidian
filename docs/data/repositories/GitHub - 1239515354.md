# nodevcg/nodte-translator

This repository holds Nodte Translator, an Obsidian plugin that translates selected text and replaces it in place, covering more than 100 languages. A sidebar icon opens a window where the languages for translation are defined and saved, after which the editor's right-click menu offers replacing the selection with its translation. The README is written in English and Portuguese and presents the plugin as fast and built for simple everyday use.
