# davidvkimball/obsidian-disable-tabs

Disables having more than one tab open in Obsidian, enforcing a single-tab interface: opening or closing a tab always replaces the current one, even a pinned tab. The README notes this is useful together with the Hider plugin when the tab bar is hidden, and that the tabs button can also be hidden on mobile from settings. The plugin is described as part of the Vault CMS project.
