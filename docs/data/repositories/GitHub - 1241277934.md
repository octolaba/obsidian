# valeon-org/obsidian-plugin

Valeon is an Obsidian plugin that publishes and syncs posts to the Valeon author dashboard from the vault, on desktop and mobile. The README says an API token created in the dashboard is the only setting authors configure, with a test-connection action to verify it, and that a sync-template command downloads the current schema into a cached frontmatter template used when creating posts. Each post lives in its own dated top-level folder holding a fixed note filename and an assets folder, and the README states that files not matching that layout are ignored by sync, publish, lint and reconcile, and that the folder slug must not be renamed after publishing because it matches local notes to remote posts. It also records that Valeon is an invite-only writing platform.
