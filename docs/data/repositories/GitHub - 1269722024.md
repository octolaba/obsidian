# ydhawesome/flash-memo

Flash Memo adds a sidebar panel to Obsidian for capturing fleeting thoughts, saving each memo as a standalone Markdown file rather than appending to a daily note. Typing and pressing Ctrl or Cmd with Enter writes a file into a memos folder in the vault, named from the first line of the content and carrying YAML frontmatter with a date and tags. Tags are taken from inline hash tags or a tag input bar, and the panel shows memos on a timeline grouped by date, with sorting by created or modified time in either direction, a real-time search across memo content, and open and delete actions on hover.
