# AndyM-DC/granola-notes-merger

The repository holds Granola Notes and Transcript Merger, an Obsidian plugin that pairs a Granola meeting note with its transcript and merges them. The README records automatic transcript discovery through frontmatter properties, wikilinks, embedded notes or a vault-wide filename prefix lookup, with a fuzzy picker offered when no match resolves. A dashboard modal shows a live preview of the merged text with actions to copy the combination to the clipboard or write a combined Markdown note that opens in a new tab, and the divider template between the two parts is configurable. The plugin is driven from a ribbon icon, three commands, or a default action set in settings so a single hotkey copies or creates directly.
