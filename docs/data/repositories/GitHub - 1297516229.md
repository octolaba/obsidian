# robertoallende/fancy-kanban

Fancy Kanban stores a Kanban board as a fenced code block containing a config section and a standard Markdown table, so a board can be embedded inline in a note and stays readable as a table without the plugin, and it can also be opened in its own pane. Cards carry custom fields defined per board across text, long text, date, number, select and file types, are edited in a dedicated modal, and are reordered within and across columns by drag and drop with workflow validation. A board setup panel edits fields, columns and workflow without hand-editing the config block, and a lanes entry in the config adds a second grouping dimension so cards sit in a grid of columns by lanes and a drag across a lane row updates both fields. One command imports an existing Obsidian Kanban board into a new file, turning its lanes into columns and stripping inline metadata.
