# heycalmdown/navigate-cursor-history

This plugin remembers the recent fifty cursor positions and adds Go back and Go forward commands for jumping between them, which the README compares to the same navigation in VSCode. No repository description is recorded, so this body rests on the README alone. The README states that the position is sampled once a second, that the history is not saved permanently, and that the forward history is reset when a new move is made while navigating.
