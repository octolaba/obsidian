# kdnk/obsidian-automatic-linker

Obsidian plugin that converts plain text matching file names in the vault into wiki links. Conversion runs when a file is saved, over selected text from the command palette, or as a batch across every file in the vault, with support for CJK text and an optional case-insensitive match. A beta AI link enhancer disambiguates between notes that share a name or alias using context and corrects existing links when a better candidate is found, and it can be pointed at any OpenAI-compatible local model.
