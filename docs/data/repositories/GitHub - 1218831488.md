# 9b9387/obsidian-echo

Echo AI generates and edits text inside an Obsidian note from an input box opened at the cursor by a slash command or the command palette: typing an instruction produces content for it, while an empty input continues the writing from that position. The README states that the request carries context automatically — the current section between headings, the document outline, and adjacent sections as a style reference when the current one is short — and that responses stream token by token in the language and tone of the surrounding text. A translate command, a floating toolbar on selection and user-defined actions with selection and input placeholders are also documented, with OpenAI-compatible providers and Google Gemini supported.
