# younggyolee/obsidian-auto-expand-backlinks

An Obsidian plugin that expands the context shown for each match in the backlinks panel and the standalone backlinks pane, so linked mentions appear with surrounding lines already visible instead of requiring a click per match. It forces the panel's "Show more context" toggle on and then clicks each match's show-more-above and show-more-below chevrons a configurable number of times, with settings for the two depths, a delay after the file opens and a pause between clicks. The README states that Obsidian exposes no documented API for this and that the plugin reaches into the internal backlinks DOM to flip the extra-context flag and press the per-match buttons.
