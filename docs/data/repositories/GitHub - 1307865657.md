# philpalmieri/obsidian-taskgregator

Taskgregator aggregates the plain Markdown checkboxes already written across an Obsidian vault into focused views without a separate database, task file format or extra syntax. The README records that context is taken from where a task already lives, so a task in a project note belongs to that project and a task mentioning a person wikilink is cross-indexed under that person, and that the Markdown line stays the single source of truth with every edit written straight back to it. The recorded description adds bucketing by project, people and area context, smart lists, inline editing and per-task detail notes.
