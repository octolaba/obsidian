# tyronejosee/tyrone-neon

Tyrone Neon is an Obsidian theme whose accent color is taken from Obsidian's own appearance settings, so headers, links, active tabs, code block borders, hover states and graph view highlights all follow the chosen color. It ships dark and light variants, pure black backgrounds with neon accents in dark mode and a white interface with adjusted colors in light mode, plus rounded corners, the Inter font family, reduced borders and optimized line spacing. The README documents installation from the community theme browser and manual installation into the vault's themes folder.
