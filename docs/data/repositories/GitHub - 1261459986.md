# mkali-personal/obsidian-code-block-fold

Obsidian plugin that folds and unfolds code blocks in the editor from a chevron beside the opening fence. The README states that a folded block collapses to a single preview line showing the language and the first line of code together with a copy button that works without unfolding, and that the fold state is written into the file on the opening fence, so it survives sessions and syncs to other devices. Two commands fold or unfold all blocks at once and toggle the block under the cursor.
