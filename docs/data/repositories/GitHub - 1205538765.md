# Narwhai/just-vertical-tabs

Just Vertical Tabs arranges Obsidian's note tabs vertically instead of horizontally. The tab bar can be oriented to the left or the right, tab icons can be turned on or off, and the right-sidebar toggle can sit in its default position, in the note header or at the bottom of the vertical bar. A command and a setting collapse the bar down to icons, or to title initials when icons are hidden, and the collapse and expand button in the bar can itself be hidden. The README describes installation through the BRAT beta plugin tool.
