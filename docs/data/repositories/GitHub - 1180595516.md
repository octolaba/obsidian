# saint0721/saint-red-paper

Saint Red Paper is a light-first Obsidian theme for research notes, lab logs and long-form technical writing, with a matching dark mode so the same note structures stay usable when the workspace switches. The README describes a canvas kept close to white paper, headings, spacing, blockquotes, callouts and inline code tuned for reading-heavy notes, and a restrained red-paper language for sidebars, root tabs, links, tags and notices. Markdown and Dataview tables get a paper-like treatment with optional red dividers driven by a marker row, and a compact optional styling layer covers Agent Client controls when that plugin is installed.
