# Coduhuey/ChatGPT-Prompt-Plugin-For-Obsidian

The repository records no description, so this body rests on the README alone. The README describes sending a templated prompt to ChatGPT when a note is created or opened, so the prompt does not have to be written by hand each time. A template is written as a note and paired with a tag in the settings, where several tag and template pairs can be listed as long as their order matches; the template may use a required placeholder for the note's title and an optional one for its current content, which the README limits to five thousand characters. Opening a file carrying such a tag then returns the model's answer.
