# brtmax/obsidian-warm-springs

Warm Springs is an Obsidian theme inspired by the Sonoma wallpapers of the Warm Springs farm. It uses dark chocolate darks, cream lights, desaturated greens and muted rust and clay accents, and supports both light and dark mode. The README notes that its screenshots use a dusty rose accent color, and names Hamlindigo Blue from Better Call Saul as a further inspiration.
