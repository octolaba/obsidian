# polyipseity/obsidian-terminal

Terminal for Obsidian integrates consoles, shells and terminals into the application and can also start external terminals. The README records an emulated developer console usable on all platforms, support for multiple terminal profiles, built-in keyboard shortcuts, automatic saving and restoring of integrated terminal history, a find function inside the terminal, saving that history to a file, and customizable terminal appearance. It notes that this file is opened automatically on first install and can be reopened from the settings or the command palette, and it documents installation from the community plugin directory, by hand, or by building from a clone with its submodules.
