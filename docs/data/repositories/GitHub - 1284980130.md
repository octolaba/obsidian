# KJH-Portfolio/202606-sidebar-resource-saver

Sidebar Resource Saver suspends webviews and iframes in collapsed Obsidian sidebars, which the README states is done to reduce RAM and CPU use. Webviews such as those from the Surfing plugin are suspended when the sidebar is collapsed and restored when it is expanded again, and the plugin is described as requiring no configuration. The README also states that it prevents error overlays when webviews are restored and that Obsidian v0.15.0 or higher is required.
