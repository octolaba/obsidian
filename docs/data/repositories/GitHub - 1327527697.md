# ilinuxio/obsidian-single-page-pdf

Exports a Markdown note as a PDF that is one continuous page instead of a paginated document: the page height is measured from the rendered content rather than configured. Rendering goes through Obsidian's own Markdown renderer into a hidden view at A4 width, whose scroll height becomes the PDF page size, and the result is shown in a preview before it is saved. The export runs from the command palette or a file's right-click menu, follows the vault's font settings, and the interface is available in English and Simplified Chinese.
