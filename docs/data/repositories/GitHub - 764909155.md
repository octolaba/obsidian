# clairefro/obsidian-plugin-etymology-lookup

Obsidian plugin that looks up the etymology of an English word selected in a note, run from a ribbon icon, the command palette or the right-click menu, with an entry copied to the clipboard when clicked. The README states that results are fetched from Douglas Harper's Online Etymology Dictionary and that the plugin therefore requires an internet connection, and it asks readers to consider donating to that resource.
