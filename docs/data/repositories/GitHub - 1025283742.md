# SSaquif/obsidian-chatty

This repository holds Chatty, an Obsidian plugin that reads notes aloud using the browser's built-in speech synthesis and the system's default voices, with no external API involved. Selected text is spoken through a Speak Selected Text context-menu entry or a hotkey that defaults to Ctrl+Alt+S, and the voice, language and hotkey are configurable in the plugin settings. The README states that adding a language requires installing the operating system's language pack and that the plugin has been tested on Windows only.
