# CarlB01/myBrain

myBrain is a graph view for Obsidian that lays notes out in a fixed matrix around the currently focused note instead of a force-directed cloud. Relationships come from the vault itself: parents and children can be declared in frontmatter properties, children also include ordinary forward links in the body, friends need only one of the two notes to name the other, and siblings are computed from a shared parent. Link direction does not matter, since a parent linking down and a child linking up resolve to the same relationship. The property names are configurable, and the view is rendered with CSS Grid rather than a canvas layer.
