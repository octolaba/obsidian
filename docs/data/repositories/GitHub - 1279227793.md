# Saiki77/easy-links

Easy Links displays an un-aliased internal link that contains a folder path by its file name alone, in reading view and live preview, while leaving the link target unchanged so navigation is unaffected. The README states that aliased links are left alone, that heading and block references are preserved with only the folder slashes collapsed, and that embeds keep their full path so labels stay consistent between the two views. Options add revealing the full path on the cursor's line for editing, colouring internal links like normal text, and an off-by-default link suggester that replaces the plain autocomplete popup and ranks notes from automatically detected priority folders first, matching file names and frontmatter aliases and inserting links through Obsidian's configured link format.
