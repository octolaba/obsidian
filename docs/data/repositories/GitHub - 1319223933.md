# KennyRN/formatForge

formatForge controls editor typography and colour: body and heading colours for H1 through H6, font families, weights and sizes, heading dividers, small caps, emphasis and link colours, highlight colours, and the manuscript editor scrollbar, all edited in a Text Styling modal against a live Lorem Ipsum preview, with custom fonts embedded in the plugin. It runs on its own, and when a Forge host such as storyForge or timelineForge is present it registers as their typography companion and shares fonts, palettes and sizes; hosts are detected at runtime and missing ones are ignored. Settings live in the plugin's own data file when standalone, while some groups move into storyForge's data file when storyForge is installed. Obsidian 1.13.0 or later is required, and the plugin is desktop only.
