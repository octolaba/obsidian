# beaurancourt/obsidian-in-file-nav-history

In-File Navigation History adds back and forward navigation over cursor and scroll positions in Obsidian, including jumps that stay inside one note. The README contrasts it with the built-in back and forward, which step only between files: this plugin restores the exact cursor position and scroll offset that was left behind, whether the jump crossed files or followed a heading or block link within the same note. It records a separate history per pane, persisted across restarts, capturing cross-file jumps from the Quick Switcher, the command palette, links and the graph as well as same-file jumps from internal links and outline or file-tree clicks, and it works in editing and reading modes on desktop and mobile. Two commands perform the back and forward step, with no hotkeys assigned by default.
