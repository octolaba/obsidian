# shakedlokits/obsidian-bellboy

Obsidian plugin described by its author as an opinionated file structure manager for a knowledge base, aimed at removing manual note renaming and organising. It takes the first header in a file, converts it to kebab-case and renames the file to match, adding an icon drawn from frontmatter to the name when one is present. It also implements the Idea Processor method: when a note's metadata status is updated, the file is moved to the folder corresponding to that state, following an ideation process that runs from an inbox through validation to execution or abandonment.
