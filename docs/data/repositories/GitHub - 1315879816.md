# iamtheozzz/lark-knowledge-ai

Lark Knowledge AI answers natural-language questions about a vault using hybrid semantic and keyword retrieval over Markdown notes and PDFs, ending each answer with references that jump to the exact line or PDF page. Questions can be asked from a centered modal, the right sidebar or a center pane, and scoped to the open file, the current PDF page, a modification-time window or files picked by hand. A rewrite command turns a selected passage into a proposed edit shown as a line-level diff before anything is written. Indexing is incremental and can watch the vault; models run locally through Ollama, and the plugin is desktop-only.
