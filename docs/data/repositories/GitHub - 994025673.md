# Jack-Chronicle/custom-comment

Custom Comments inserts a user-defined pair of markers around the cursor or the current word, for wrapping text in comment-like delimiters. The template is written in the settings with a cursor placeholder marking where the caret lands after insertion, a word-only mode comments or uncomments the word at the cursor instead of inserting the template, and additional marker sets can be defined, each with its own start and end markers and a toggle that registers a command for it. A further command reloads the marker commands in place after the sets are changed, without reloading the plugin; the README notes that these markers only behave as real comments when they use a form Obsidian itself supports.
