# moziar/obsidian-external-links-icon

Adds an icon automatically to external and internal links according to what they point at. The README lists the built-in coverage in three groups: URL schemes of other applications such as Zotero, Bear, Things, Craft, Notion and Advanced URI; websites including GitHub, Medium, YouTube, Wikipedia, Archive.org, the Google services and several Chinese platforms; and Obsidian's own addresses together with internal and external vault links.
