# dsebastien/obsidian-time-machine

Time Machine presents the history of an Obsidian note as an interactive timeline built from Obsidian's own File Recovery snapshots and, when the vault is a git repository, from its commits. A slider scrubs through that history and a colored diff shows additions and deletions, from which either the whole version or only selected changes can be restored. Each entry is labelled with its source, snapshots that do not differ from the current content are filtered out along with duplicates, the view refreshes when the active file changes, and a snapshot can be forced without waiting for Obsidian's timer. The README records that the plugin runs on desktop and mobile while the git features are desktop only.
