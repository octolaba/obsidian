# search5/harang-nextcloud

Converts a pasted Nextcloud internal link into a rendered file block showing the file's name, path, size and upload date, together with a button that opens it on the server. Accounts are connected through Nextcloud's Login Flow v2 in the browser, which yields an app password rather than the account password, and any number of profiles can be registered so a pasted link is matched to the right server. Setting an nc-folder frontmatter property on a note allows non-image files dropped into it to be uploaded to that Nextcloud folder, and removing a file block later prompts whether the underlying file should also go to the Nextcloud trash. Only the parts of the WebDAV API this workflow needs are implemented, and Obsidian 1.13.4 or later is required.
