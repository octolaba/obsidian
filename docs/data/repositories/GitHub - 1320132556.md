# mhmzdev/obsidian-graph-chat

Graph Chat draws a vault's notes, tags and links as an interactive canvas, and a chat box can be opened against any note; the plugin spawns the locally installed Claude Code CLI, which reads that note along with its outgoing links and backlinks. Conversations can be branched at any point, and each thread is saved as a Markdown note with a Source link, so it appears in the native graph and can be tagged and searched. Dragging on the canvas creates links or tags, a search bar recentres the view on a match, and zooming out collapses folders into cards. The spawned CLI is limited to read operations, so the only writes are the chat notes and the links dragged deliberately.
