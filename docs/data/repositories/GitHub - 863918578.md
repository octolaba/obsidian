# LuigiCerone/obsidian-whatsapp-backup-importer

WhatsApp Backup Importer brings an exported WhatsApp chat archive, supplied as a .zip file, into an Obsidian vault. It extracts and processes the messages and the photo and video attachments, writes them into a folder chosen by the user, and creates links from the chat file to the imported attachments. The README describes the workflow: export the chat from a phone or computer as a zip containing a text or JSON message file plus its attachments, then run the plugin's command and give it the output folder and the zip file.
