# zengyincen/Obsidian-PastePic

Obsidian plugin that catches an image pasted, dropped or newly inserted as a local vault link, uploads it to GitHub or an image host, and puts a remote Markdown image link back in the same place. Each upload gets a unique placeholder, and a failed upload restores the local image link rather than leaving a broken one. The same workflow is configured once in a synced vault and then used on desktop, tablet and phone with one storage destination and one CDN path. The README names the Obsidian versions the release supports on mobile and desktop, and states that the tablet and phone material describes verified compatibility paths rather than device footage.
