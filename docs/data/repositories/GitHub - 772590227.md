# bobstanton/obsidian-who-is-streaming

Who Is Streaming looks up which streaming services currently carry a film or show and writes the details and streaming status into an Obsidian note as properties, using the Streaming Availability API from Movie of the Night. A note is named after the title, and a ribbon button or the Search command queries the API and offers a list of matches; once a note has been synced, the Refresh command uses the stored identifier and type to sync again without searching. The README states that an API key is required and that the API has free and paid tiers, and it documents the network requests the plugin makes, including calls to a user-configured Jellyfin server to search libraries and read watched status.
