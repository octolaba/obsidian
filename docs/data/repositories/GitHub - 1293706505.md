# VladB-evs/obsidian-folder-backlink

Folder Backlinks lets notes link to folders and shows which notes reference each folder, a backlink direction core Obsidian does not provide. A folder link is a normal wiki link ending in a trailing slash, which marks it as a folder link so it cannot clash with a note of the same name, and such links render as resolved rather than broken in reading mode. A sidebar panel lists every note linking to a folder and jumps to the line containing the link, an insert command offers a fuzzy folder picker, and a folder's right-click menu copies a link to it or opens its backlinks. Clicking a folder link reveals the folder in the file explorer, opens the backlinks panel, or both, as configured, instead of Obsidian treating it as unresolved and offering to create a note.
