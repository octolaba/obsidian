# korioinc/obsidian-timelink

TimeLink combines a calendar, a timeline, kanban boards and a board-level schedule overview in one plugin, built for workflows where notes and cards link to each other. It offers a calendar view for creating and managing event notes by date, a timeline view listing timed and unscheduled work chronologically, kanban board and board-list views that can open Markdown files as boards, and a Gantt view grouping dated kanban-linked events per board by year. Cards can spawn linked notes and events, and the plugin keeps backlinks between a card note and its event note in sync, optionally deleting both when the card is deleted. Per-board colors can be applied and reused in the linked event displays.
