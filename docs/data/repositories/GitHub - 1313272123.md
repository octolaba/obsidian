# kpieper876/Virtual-Note-Alias-Creator

Adds a File Explorer context-menu action that creates a second note containing nothing but an embed of the one it was made from, so the same content appears in another folder without being duplicated. Right-clicking a Markdown note and choosing the action asks for a destination folder and writes a file named after the source with a virtual suffix, adding a numeric suffix if that name is taken. Existing virtual notes cannot be virtualized again, which prevents recursive chains, and the generated file is plain Markdown with no frontmatter. Edits stay in the original note because the copy only embeds it.
