# NebulousNessie/Obsidian-MOCBlocks

MOC Blocks adds a `moc` code block for building simple Maps of Content over a background image, with clickable markers and polylines placed on that image. The README records that marker location and link data is written to a file in a mocdata folder in the vault, while marker style data lives in the plugin's own data and is deleted when the plugin is removed. It also records a known conflict: the image converter plugin breaks MOC Block resizing.
