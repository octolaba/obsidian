# wesswart77/obsidian-code-reference

Obsidian plugin that keeps a personal coding reference library of snippets, patterns, links and notes tagged by language and framework. The README lists commands for capturing a snippet with its language, framework, tags, description and code block, for documenting an architecture or design pattern with categories and examples, and for searching by tag, plus a sidebar with snippet and pattern tabs filterable by language. The folders used for snippets and patterns are set in the plugin's settings.
