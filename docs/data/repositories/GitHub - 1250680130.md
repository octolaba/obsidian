# codaloc/FolderGraph

Folder Graph modifies Obsidian's existing graph view so that the folder structure becomes the graph: named nodes are added for the parent folder of every node, linked into a tree. The README lists the settings the result depends on: "Existing files only" should be on, otherwise broken links attach to the root folder rather than to the file that contains them; orphans must be enabled or only nodes the plain graph would already show appear in the tree; and with attachments enabled, hiding manual links avoids attaching a file both to its folder and to the note linking it, while the hidden-nodes-by-string setting can filter particular extensions. The author credits ratibus11/folders2graph as the starting point.
