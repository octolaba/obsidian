# Unabyss/obsidian-plugin

The Unabyss plugin synchronizes an Obsidian vault with the Unabyss service in both directions, pushing notes as change-aware deltas and pulling exports back into a folder chosen inside the vault. Outbound sync is driven by file changes with a five-second debounce, and a daily timer runs both directions regardless of events. The README describes an OAuth 2.0 flow with PKCE for connecting, a manifest-first delta protocol that uploads only files whose content hash the server does not already have, and a local hash and modification-time cache, with a force-full-resync button that clears the cache and the inbound watermark. Each pulled export is mirrored as a Markdown file named from its slugified title, deletion on the service can leave, delete or move the local file, and notes above one mebibyte and blank notes are skipped.
