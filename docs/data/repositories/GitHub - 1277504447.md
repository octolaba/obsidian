# rcanand/obsidian-pencil

Pencil adds an infinite drawing canvas to Obsidian, saved as pencil files inside the vault so they are versioned and synced with the rest of the notes. Its README presents it as a deliberately narrow take on handwriting: an infinite canvas whose view position is stored with the note, pressure-aware stylus input that can be switched off, mouse and finger drawing at constant pressure, palm rejection that turns finger touches into panning once a pen has been used, and two-finger pinch zoom. Recorded tools are the pencil, a stroke-level eraser dragged over unwanted strokes, box selection and moving of strokes, eight built-in colors plus a custom palette, four stroke widths and full undo and redo, with a toolbar showing icons on desktop and short labels on mobile.
