# Arcadia-Studio/obsidian-arcadia-hub

An Obsidian plugin that puts a GitHub workflow in a sidebar panel: browsing repositories with an active-repo switch, viewing issues with open or closed, label and pagination filters, a pull request dashboard showing state and review status, creating an issue from the current note, and auto-refresh on a configurable interval. The README states the whole GitHub module is free and that premium covers further modules — a Claude Code bridge, audio notebook sync and an AI router — which it describes as still in development. It records the plugin as desktop-only and its community plugin listing as pending review at the time of writing.
