# kowshik24/obsidian-ai-assistant

Obsidian plugin that opens an AI assistant when `/ai` is typed in a note and Enter is pressed. A question is entered in the dialog, other notes can be added as context, and the answer returned through OpenAI can be inserted into the current note with one click. An OpenAI API key is configured in the plugin settings.
