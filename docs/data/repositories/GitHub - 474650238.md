# franciskafieh/obsidian-list-modified

The repository holds Obsidian List Modified, a plugin that links every modified file meeting configured criteria into a daily, weekly or monthly note, producing a log of what changed in each period. Its README records two deliberate choices: the log is written as plain text rather than as a dynamic query so it persists, and the plugin does not rely on filesystem modification times, which it states are unreliable when files are moved or synchronised. Configuration is documented in the project wiki.
