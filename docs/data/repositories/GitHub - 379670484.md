# gregzuro/obsidian-kroki

The repository holds Obsidian Kroki, a plugin that renders Kroki diagrams inside notes, with each supported diagram type reached through its own code block language. Its README states that rendering goes to the public Kroki server by default, encourages configuring an alternate address in the plugin options, and points at instructions for self-hosting a server. It records the plugin as a modified and slightly expanded version of an earlier PlantUML plugin, and is licensed under MIT.
