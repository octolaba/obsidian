# Cordedmink2/obsidian-google-sync

An Obsidian plugin that imports Google Calendar events and Google Tasks into the vault and pushes edits back to the matching Google items. The README states Google remains the source of truth for existence: events land in one folder and tasks in another, edits to an imported note carrying a Google identifier patch the existing item, notes without one are never pushed, and deleting or renaming a note never deletes anything in Google, with items deleted on the Google side moved to an orphaned folder instead. Pushes are diff-based against the last imported state, large batches need an explicit confirm command and a preview command offers a dry run, while a per-note property can restrict a note to pull-only. Setup uses the user's own Google Cloud OAuth client with both APIs enabled, tokens kept in local plugin data, and import bounded by a days-past and days-ahead window.
