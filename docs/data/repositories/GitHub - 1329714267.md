# Santuzius/copy-as-zed-link

Copies a Markdown link to the clipboard whose target is a file URL for the current note, a selected passage or a folder in the vault, in the form Zed's agent panel embeds as attached context. A line span in the URL fragment attaches just those lines, no fragment attaches the whole file, and a trailing slash attaches a folder. The commands sit in the editor context menu, the file explorer context menu and the command palette, and the plugin warns when a copy made without a selection yields a one-line span that Zed may not embed. It is desktop only because the link has to name a real path on disk, and Zed resolves such a mention only within the project folders it has open.
