# demian0311/obsidian-slate

Diagrammo Slate applies the Slate palette from Diagrammo to Obsidian, using a cool-gray ground, a corporate blue, a teal accent and a nine-hue categorical spectrum, with separate values for light and dark rather than one set reused with opacity. Hue is spread across headings, callouts, tags, folders, syntax, task states, graph nodes and canvas: H1 through H6 walk red to purple on washed rounded blocks, callout types map to spectrum hues, tags are colored by first character, and folders tint by nesting depth. Every color is one of the thirty palette values verbatim, so nothing is darkened or shifted; the consequence is that yellow, at 2.4:1 on white, carries no ink in light mode and appears only as a fill such as the highlight background.
