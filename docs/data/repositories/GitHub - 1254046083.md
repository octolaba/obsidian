# andyhtran/GhostTerm

Opens Ghostty-style terminal surfaces in the Obsidian sidebar or main area, with terminal tabs, splitting right or down, closing the focused surface and restarting an exited shell. Terminal keyboard shortcuts are intercepted only while a terminal surface has focus, a subset of Ghostty configuration is read for font, colour, cursor, scrollback, shell and basic keybindings, and a terminal can be opened from the file explorer starting in the selected folder. The plugin prepares a terminal-like path, locale, terminal type and dimensions for a graphically launched Obsidian, and tracks title, working directory and hyperlink metadata emitted by the shell. The README records requirements of Obsidian desktop 1.8 or later on macOS with Apple Silicon, and states that its bundled helper starts a local shell with the same permissions as Obsidian and the user.
