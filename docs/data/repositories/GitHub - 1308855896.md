# AlineFan/linqq-handwritten-annotation-plugin

This plugin adds coloured handwritten-style annotations to Obsidian notes without covering or reflowing the annotated prose. Labels are placed in dedicated layout rails above and below a paragraph and distributed automatically, staying in the same lane while they do not overlap and gaining a lane only on a real collision, with curved arrows that remain connected to the rendered text even when the target wraps across lines. An annotation is added to selected text from the command palette, ribbon or context menu in amber, blue, green, red or purple, and selecting a label reveals its edit and delete actions while the original prose is preserved. The README states that annotations remain in the Markdown file as portable HTML, that Shantell Sans is used for Latin text and LXGW WenKai Lite for Chinese, and that the controls follow Obsidian's interface language in English and Chinese.
