# mister-mcgee/obsidian-fill-in-the-blank

Renders text wrapped in double dashes as blank lines, so a note can be printed as a fill-in-the-blank exercise. The post-processor applies to headings, paragraphs and code blocks inline, and text can be wrapped or unwrapped by selecting it and using the ribbon icon or a toggle command bound to a hotkey. Setting a fitb key to false in a note's frontmatter disables the substitution while the syntax is still consumed; the README notes the preview may need reloading for that change to take effect. No repository description is recorded, so this note is grounded in the README alone.
