# starhunt/star-qmd

Star QMD wraps the qmd command-line tool so that BM25 keyword search, vector similarity and a slower deep mode combining query expansion with reranking can be run over the vault from inside Obsidian. A sidebar and a modal share result cards, history and tips; a search can be scoped to a folder prefix, and an index status card reports document and vector counts, the last update, a stale badge and live progress while the index or the embeddings refresh. The README also records commands to find notes similar to the current one and to search the editor selection, a result context menu, hover previews, per-mode score chips, retry suggestions after an empty result, and Korean and English interface text. It states that the qmd CLI must be installed and the vault registered as a collection, and that the plugin is desktop-only on macOS and Linux.
