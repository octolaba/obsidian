# CitrusRenegade/subscription-calculator-obsidian

Subscription Calculator tracks recurring payments inside Obsidian and reports the total cost per year and the average per month. Subscriptions are added from a panel opened by the ribbon or the command palette, each with a name, price, currency and a weekly, monthly, quarterly, yearly or custom billing period, optionally a start date that drives next-payment tracking and a service URL whose icon is fetched once and cached locally. A subscription can be paused so that it stays on the list but leaves the totals, cards are sorted by name, status or next payment, and the README states that the supported currencies are totalled separately rather than converted, that the data needs no separate service, note-per-subscription, Dataview, Bases or frontmatter, and that the plugin works offline.
