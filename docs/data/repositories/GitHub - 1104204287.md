# CaDuCT-3aTeuHuK/obsidian-yandex-calendar-integration

Inserts events from Yandex Calendar into Obsidian daily notes. The README, written in Russian, says the plugin synchronises with the calendar, formats the current day's events according to a configured pattern and inserts them at the cursor position. Configuration takes the account email and a Yandex application password, which the README says is entered once and kept in Obsidian's own secure storage.
