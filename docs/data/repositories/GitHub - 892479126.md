# tu2-atmanand/obsidian-notes-explorer

Obsidian plugin that displays notes as cards for visual navigation and revision of their content. Two layouts follow from one setting: leaving the fixed card height empty gives a masonry view with variable heights, while setting a pixel value gives a grid or gallery view, and a further setting controls the maximum number of lines read from each note. The README also records sorting by last modified time, creation time or filename in ascending or descending order, and opening the notes of a specific folder by clicking that folder in the file tree.
