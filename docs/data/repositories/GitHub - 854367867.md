# willasm/vc-weather

Visual Crossing Weather pulls weather data into Obsidian from the Visual Crossing API, for which the README links a free API key that requires no credit card. Current weather is shown in a customizable status bar carrying two template strings that alternate every thirty seconds, and clicking it opens a modal with today's detail; weather can also be inserted into a document, previewed first in an insert modal, through eight named templates whose first line supplies the menu name and is left out of the output. The README documents data for up to five locations, fourteen days of forecast, around four thousand macro text replacements, daily-note macros reaching any of fourteen past or future days, and template support for automatic insertion into new documents. It presents the plugin as the replacement for the author's OpenWeather plugin, whose underlying API version was discontinued.
