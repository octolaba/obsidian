# fyaic/Understory-Obsidian-Plugin

Understory proposes related notes and conflicts for review rather than writing them into the vault, keeping what the README calls a knowledge-maintenance loop in which machine discovery is advisory and human decisions have higher authority. Running the suggestion command on a note narrows the eligible vault notes using scoped folders, existing links, backlinks, title and content overlap and recent edits, returning a sidebar queue where each relation can be opened, accepted, ignored or inserted as an ordinary wiki link. Ignoring records a deletion memory so the same suggestion does not reappear immediately, manual links outside generated blocks are preserved, and refreshing suggestions does not rewrite the note body. The README states that the default hosted mode sends only bounded note snippets after consent while an advanced local mode uses a bundled graph engine.
