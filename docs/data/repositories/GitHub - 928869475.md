# noy4/browser-history

This plugin syncs a browser's history into Obsidian notes, read from the browser's local history database. Settings select the browser and database path with a connection check, the folder and filename format for the generated notes, a start date that advances to today after each sync, and whether syncing happens on startup or on a repeating interval. The README cautions against publishing history notes because their URLs may contain authentication information, and states that antivirus warnings are a false positive since the plugin only reads the history database file.
