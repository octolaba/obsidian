# Ebonsignori/obsidian-auto-journal

Obsidian plugin that creates daily and monthly journal notes and backfills the days that were missed while Obsidian was not opened, which the core Daily notes plugin does not do. It imposes a folder structure of root, year, month and day for daily notes and root, year, a custom name and month for monthly notes; the date formats and the root are configurable, but the hierarchy and the filename prefix are not. Backfilling for a month or for a year creates the missing notes before today, and a configurable template token is replaced by the date the file would have been created rather than the date it was actually created, with inline date formats also accepted.
