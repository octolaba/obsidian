# DylanComas/noveler-a-storyline-expansion

Noveler adds a manuscript editor as its own view type, separate from the standard Markdown editor and opened from a ribbon icon or the command palette. It bundles page layout controls, focus writing, a formatting toolbar, live word and character counts, formatted exports, StoryLine scene routing and grammar-checker integration into one plugin instead of separate bridge plugins and editor views. The README records it as a desktop plugin and lists StoryLine and the grammar integration as separate plugins to install for those parts of the workflow.
