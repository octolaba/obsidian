# olivertedwards/rose-pine-obsidian

Rose Pine Minimal is a clean, minimal Obsidian theme that applies the Rose Pine palette to notes. Dark mode uses the main Rose Pine variant and light mode the Dawn variant, which the README calls gentle, warm and readable for daytime use. It states that the theme changes colors only and preserves Obsidian's native feel.
