# snoopyrain/obvec-sync

Obsidian plugin that syncs a vault to the hosted Obvec service so that assistants speaking MCP, such as Claude, ChatGPT and Cursor, can search the notes in natural language. Setup is an account and API key from the service's site, after which the vault syncs in the background and the assistant is pointed at the service's MCP endpoint. The README records matching by meaning rather than by keyword, multilingual embeddings, incremental upload of only the files whose hash changed, and per-user data isolation.
