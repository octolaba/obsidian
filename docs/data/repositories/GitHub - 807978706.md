# maybe-hello-world/midi-logger

MIDI Logger uses the Web MIDI API to listen to a connected MIDI device and insert the notes played into the Obsidian editor. Capture is started and stopped from a ribbon icon or from commands, and a further command inserts an ABC template. The output format is chosen in settings among the raw MIDI code, scientific pitch notation and ABC notation, with a configurable separator for the first two; the ABC output carries only note and octave information, not duration or key signature. The README states it works on Windows, Linux and macOS, does not work on iOS while Safari lacks the Web MIDI API, is untested on Android, and pairs with the ABC Music Notation plugin for rendering.
