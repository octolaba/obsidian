# Akitaroh/obsidian-mermaid-maker

MermaidMaker turns a Mermaid block into a visual canvas where nodes are dragged, added, removed, connected and relabelled by double-click, with dagre auto-layout for new nodes and two-way sync between canvas and Mermaid text. Node labels are rendered through Obsidian's Markdown renderer, so links, tags, math and bold formatting work inside the diagram and links keep their click, hover preview and unresolved styling. The behaviour is opt-in: only `mermaid-maker` blocks are processed, and only when the first line inside them is the editable marker, otherwise the block renders read-only; node positions are saved as a Mermaid comment so the file stays portable Mermaid. The README describes the plugin as beta, installed through BRAT, with the add-node button still labelled in Japanese.
