# Kazi-Aidah/blobob

This repository holds blobob, an animated Obsidian theme written by a self-taught animator around motion in interactions. It carries 73 colour options, 43 dark and 30 light, plus six button styles, and supports the Style Settings plugin for customization. Animated and compact tabs, a focus mode, active line styles with dimmed and floating inactive lines, bouncy and vertical folder styles in the file explorer, checkbox and property styling, settings-tab and right-click-menu tweaks and mobile styles are all documented in the README. The theme is described as still in development, with issues and feature requests invited.
