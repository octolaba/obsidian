# huterguier/obsidian-mehrmaid

Mehrmaid extends Mermaid code blocks in Obsidian so that Obsidian-generated Markdown can be rendered inside node labels. It follows Mermaid's own syntax, with node content wrapped in double quotes rendered as Markdown, which allows images, LaTeX math, tables, tags and internal links inside nodes. The README explains the approach: the Obsidian Markdown renderer draws the node content first to estimate its size, Mermaid then lays out the graph with those sizes, and the placeholder nodes are replaced by the rendered HTML. It notes that this approach still has issues.
