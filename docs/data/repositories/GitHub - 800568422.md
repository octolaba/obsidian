# Rooyca/query-json

Q-JSON reads and queries JSON inside Obsidian notes, whether the data is embedded in the note or stored in an external file. The README states that a qjson block holds the data or a file reference and is given a unique numeric id, after which an inline query written with an at sign and that id walks the structure in dot notation and is replaced by the value when the semicolon is typed. Recorded features include filtering with logical and comparison operators, display as JSON, lists, tables or images with customizable table columns and formatting, property substitution from frontmatter, and query expansion in real time as the query is typed.
