# nikitaclicks/obsidian-openagent

Obsidian plugin that runs an AI agent inside the vault against any OpenAI-compatible endpoint, such as OpenAI, Ollama or LM Studio, with a key the user supplies. The agent carries vault tools for reading, writing, editing, appending, searching and listing notes and for managing frontmatter and links, and every destructive write is put behind a confirmation dialog with a diff preview. A single bundle runs on desktop and on mobile. The README states that network requests go only to the configured endpoint, that note bodies, paths, frontmatter and tags may be transmitted there once vault tools are enabled, and that the API key is stored in the plugin's data file and travels with a synced configuration folder.
