# jdchart/onto-tracker

Onto Tracker manages a project by tracking the contents of a folder on the computer from an Obsidian vault, categorising its files according to an ontology and a set of user-defined rules. A project is given a title, a source folder and an ontology file in the settings, after which the ontology can be unpacked, mapped onto the tracked content, and frozen at a point in time. The README describes the result as content that can then be parsed for tasks such as uploading to a content management system.
