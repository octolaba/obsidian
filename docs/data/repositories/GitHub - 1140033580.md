# Nitero/obsidian-tab-multi-select

Tab Multi Select adds multi-tab selection to Obsidian using the input conventions of a browser, which the README says are drawn from Firefox. Shift-click selects a range of tabs and Control-click toggles individual ones; middle-click closes the selected tabs, right-click opens a context menu for them, and dragging moves them to another tab group or window. The undo-close-tab hotkey brings back closed selections.
