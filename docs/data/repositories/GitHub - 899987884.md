# okikae/obsid-kkh

The recorded description says this is the Obsidian plugin for kkh. Its Japanese README explains that kkh is a tool converting between the historical Japanese orthography of old characters and old kana and the modern one, and that this plugin ports it to Obsidian, applying a chosen conversion to the text selected in the editor. The available conversions cover whole sentences in either direction, kana alone and kanji alone, while further entries for iteration marks, loanword katakana, ligature kana and the ya-row e are struck through in the README. It documents running the conversions from a ribbon icon, the command palette or the editor text menu, describes how that differs per platform, and advises against using the plugin on a phone.
