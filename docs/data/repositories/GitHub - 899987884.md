# okikae/obsid-kkh

The kkh plugin ports a Japanese text conversion tool into Obsidian, where selected text can be converted. It handles prose, kana, and kanji between historical and modern orthographies, with commands exposed through the ribbon, command palette, text menu, and device toolbars.
