# istefox/Postbox

Postbox imports .eml and .msg email files that are already on disk and turns them into Markdown notes in an Obsidian vault, converting the HTML body to Markdown while keeping links, lists and tables. Attachments are extracted to a configurable folder and linked from the note, inline images referenced by content id render in place, and a YAML frontmatter records sender, recipients, subject, date, message identifier, attachments and tags. Import runs from the command palette or the file-explorer context menu, an external folder can be watched so new files are imported automatically, and duplicates are skipped by message identifier. The README states that the plugin is desktop only and connects to no Outlook, IMAP or Exchange server.
