# kwanUm/obsidian-docs-sync

Publishes a single note to Google Docs and keeps the two in two-way sync, so a document can be shared and co-edited while the note stays an ordinary local file. Publishing creates the document and writes its URL into the note's frontmatter; local edits are pushed debounced on save and remote edits are pulled on a poll interval or on demand. When both sides changed in overlapping places the plugin writes inline conflict markers into the note and leaves the Google document untouched until they are resolved, merging non-overlapping changes automatically. The README states that a pre-registered OAuth client with a per-file Drive scope is used so the plugin can only touch the documents it created, that tokens live in local plugin data, and that the plugin is desktop only.
