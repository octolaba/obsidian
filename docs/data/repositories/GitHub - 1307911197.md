# SrPernax/obsidian-easyfilereplace

Obsidian plugin that replaces the contents of a vault attachment while keeping its name and path, so existing internal links are not broken. The replacement is started from the file explorer context menu or from the command palette with the file open, and a native file picker chooses the new file. The README states that the new file must carry exactly the same extension as the one being replaced, and that a mismatched format is blocked to avoid corruption.
