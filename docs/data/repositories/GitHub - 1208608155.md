# homura144/obsidian-insert-block-below

Insert Block Below adds command palette commands that insert a math block or a code fence on the line below the cursor. The inserted block keeps the indentation of its context, covering blockquotes, callouts, unordered lists and ordered lists written with a period or a parenthesis. Typing three dollar signs or a fence marker at the end of a line expands into the corresponding block as well, a trigger that fires only during live typing and never inside an existing fenced block. An optional two-line code block mode places the cursor at the end of the opening fence so a language can be typed immediately.
