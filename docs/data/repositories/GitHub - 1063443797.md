# obsidianmd/obsidian-maps

Adds a map layout to Obsidian Bases so notes can be displayed as an interactive map view. Each note carries a coordinates property, written either as text or as a list, and the view places a marker for every note matching its filters, with marker icons and colours driven by other properties. The README records OpenFreeMap tiles by default, custom background tile or style URLs with a separate dark-mode URL, and settable center coordinates, default zoom and zoom limits.
