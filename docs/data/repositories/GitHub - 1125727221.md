# plattnum/where-did-the-time-go

A visual time-tracking plugin whose entries stay in the vault as plain Markdown tables, offering an infinite-scroll timeline for logging hours, hierarchical reports and one-click invoicing. The README states the design deliberately omits a start/stop timer, since hours are entered after the fact, and that the plugin is not a task manager and integrates with none. It records no account, no cloud sync and no telemetry, and points to a separate experimental command-line companion, o-wdttg-cli, that exposes the plugin through the Obsidian CLI so an agent can read, write and report on time entries.
