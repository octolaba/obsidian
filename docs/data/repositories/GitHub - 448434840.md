# ghedamat/obsidian-save-as-gist

The repository holds Obsidian Save as Gist, a plugin providing two commands: saving the current file as a private gist and saving the current selection as one. Its README records that a GitHub API token with gist creation permission has to be generated and entered in the plugin settings, and that the resulting gist address is copied to the clipboard. It states two limits plainly: a public gist cannot be created and an existing gist cannot be updated.
