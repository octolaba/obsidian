# dlsdgj/promchip

promChip pins prompt buttons on top of the Obsidian window: a draggable floating ball opens the settings panel, and individual prompt chips can be placed and dragged anywhere on screen. Selecting text in the editor and clicking a chip sends the prompt, with the selection substituted into a placeholder, to a configured OpenAI-compatible endpoint; several providers can be stored and switched between. The reply streams into a floating window that renders Markdown and can be collapsed to a mini bar, pinned open, recolored from built-in schemes, copied, edited in place or discarded. Annotated text is marked in the editor with an underline that shows the annotation on hover, and the settings panel is available in Chinese and English.
