# lizard-heart/obsidian-tab-limit

Tab Limiter keeps the number of open Markdown tabs under a configurable maximum, which defaults to five. When opening another Markdown tab would exceed that limit, the plugin closes the least recently used Markdown tab instead of blocking the new one, and switching to a tab marks it as recently used, so older inactive tabs are replaced first. The maximum is a single global value in the plugin's settings tab.
