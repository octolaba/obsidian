# lynxaegon/obsidian-anysocket-sync

AnySocket Sync synchronizes an Obsidian vault against a self-hosted server, with end-to-end encryption on the transport layer and as many connected devices as wanted, mobile included. It keeps version history and recovery of deleted files with configurable retention, works offline, supports syncing on demand, and updates itself when the server is updated. The README is explicit that this is file sync rather than CRDT sync, so editing one file on two devices at once can conflict and resolution is last write wins; loss of history on rename is listed as a known issue.
