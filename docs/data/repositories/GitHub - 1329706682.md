# goffiti/vantell-obsidian

Publishes topic labels and note counts from folders explicitly chosen in settings, so colleagues in the same organization can find who knows about a topic without note contents leaving the vault. A side panel, opened from the ribbon or a command, shows the other connected vaults as topic-tagged cards to knock on, the requests awaiting an answer, the answers received and the status of knocks already sent. Going live sends topic labels, counts, the chosen folder names, up to three sample note titles per folder and a signed timestamp, each shown in a review step first; answering a request sends only the typed text and the titles ticked as sources. Linking a device uses a one-time code from the service's web app, the inbox is polled every two minutes, and an optional drafting path, off by default, sends matching note text to the user's own Anthropic account.
