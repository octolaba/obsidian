# TheBestTvarynka/grafily

Grafily is an Obsidian plugin that renders family graphs, or family trees, for genealogy and family-history research. The README records one page per person: the plugin scans a configurable directory, extracts each person's metadata, builds an internal relationship graph and renders it interactively, letting relationships be collapsed and expanded. Rendering uses the reactflow library with a custom node-placement layout, and two visualization algorithms are recorded — a tree-based Reingold-Tilford mode that shows only direct ancestors or descendants with exact centring, and a graph-based Brandes-Köpf mode that handles arbitrary family graphs at the cost of imprecise centring.
