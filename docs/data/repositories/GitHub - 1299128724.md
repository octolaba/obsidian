# duybaodg/mindmap-plugin-hbd-dang

Mind Map is an Obsidian plugin for creating visual mind maps that remain readable Markdown notes, saved automatically as Markdown with YAML frontmatter. Nodes can be added, renamed, moved, merged, grouped, connected, collapsed and deleted, can carry notes or link to Markdown notes, and the canvas supports panning, zooming, fit-to-view and a minimap; keyboard shortcuts cover child and sibling nodes, renaming, undo and redo. Maps export as PNG, JPEG or PDF. The README states that map data stays in vault Markdown files and that the plugin makes no network requests and uses no external services.
