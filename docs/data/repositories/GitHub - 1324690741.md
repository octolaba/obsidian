# Birchove/heading-level-changer

Heading Level Changer promotes or demotes Markdown heading levels on the selected lines in Obsidian, through hotkeys, the command palette or the editor right-click menu, acting on the line under the cursor when nothing is selected. A line counts as a heading only when one to six hash characters are followed by whitespace, so tags are never touched, and lines inside code fences or comment blocks, indented lines and blockquoted headings are skipped. Levels are clamped at the first and sixth levels, multiple selections are handled at once, each operation is a single undo step, and the selection is restored afterwards. Default bindings combine Obsidian's Mod modifier with Alt and the arrow keys and can be rebound or removed in the hotkey settings; it works in Live Preview and Source mode on desktop and mobile.
