# obsidian-helix/obsidian-helix

This plugin enables Helix keybindings inside Obsidian by adding the Helix CodeMirror 6 extension by jrvidal to the editor; the README credits that extension with the actual implementation and notes that it is at a very early stage of development. Vim keybindings have to be disabled under Options, Editor, Advanced first, after which Helix keybindings are enabled in the plugin settings or toggled by a command. The cursor takes the accent colour by default and can be given another colour through a custom CSS snippet.
