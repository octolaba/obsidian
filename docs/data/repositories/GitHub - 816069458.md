# Rooyca/doing

Repository for Doing, an Obsidian plugin that keeps track of the task currently being worked on for people who switch context often. A task is added from the command palette and then shown in the status bar, and once it is completed it is logged with a timestamp into a `doing.md` file that holds the task history. The README describes the plugin as a quick reminder of the current task rather than a full task manager.
