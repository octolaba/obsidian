# eliascotto/ultrafocus

Ultrafocus hides interface elements such as tabs, the status bar, the ribbon and the sidebars behind a single toggle command, with no buttons of its own. Its settings choose which elements stay visible; by default everything is hidden. The README states that getting the plugin into the Obsidian community repository proved difficult and gives manual clone-and-build installation steps instead, and it names Hider and Focus Mode as alternatives.
