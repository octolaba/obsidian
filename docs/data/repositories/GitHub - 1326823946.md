# yuhang-dong/obsidian-paper-manager

Paper Manager keeps academic PDFs as a library inside the vault, giving each imported paper a folder that holds an index note, the original PDF, an editable annotations file and a generated annotated copy. The library supports search by title, filtering by reading status, author, keyword or year, duplicate detection by the PDF's SHA-256 hash, and a dedicated workspace for highlighting, drawing and commenting. Optional AI actions analyse a paper into structured metadata and an overview, or answer a question asked in a PDF comment; these are paid, send the paper to an external service, and reject PDFs over 30 pages. It needs Obsidian 1.8.7 or later, and multi-paper synthesis, bulk selection and presentation generation are stated as absent from the current release.
