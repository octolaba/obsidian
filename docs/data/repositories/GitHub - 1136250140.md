# Requiae/obsidian-leaflet-bases-plugin

Leaflet Bases adds a Leaflet Map view and marker properties to Obsidian Bases. Maps can be configured with an image, zoom and measurement settings, while markers are stored with notes and can be created, edited, or removed from the map interface.
