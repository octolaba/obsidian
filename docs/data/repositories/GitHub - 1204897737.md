# tttt-k/obsidian-cocoa-nook

Cocoa Nook is a warm-toned Obsidian theme aimed at light mode users, offering a gentle palette meant to reduce visual fatigue while avoiding an outdated look. Its README describes the theme as introducing only light modifications: it requires no setup, does not break note formatting, and can be enabled or disabled at any time. For use in dark mode the README recommends setting the Obsidian accent colour to #7D6043.
