# niffka/notes-merger

Obsidian plugin that merges notes into one file. It builds a content tree by traversing all links and nesting them within notes, shown in an interactive preview that can be updated before the merge; inline links expand the structure in place without creating a nesting level, while links under a configurable keyword form a sublevel of the current note. The README also records generating a template for the Advanced Slides plugin and translating a Markdown file into XeLatex with custom Latex templates.
