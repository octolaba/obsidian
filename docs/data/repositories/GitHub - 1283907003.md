# leweii/read-it-never

Read It Never archives web content, videos, feeds, snippets, and other supported inputs as Markdown notes in Obsidian. Its editable per-content templates use variables and chained filters, can download article images, create one note or batches from clipboard URLs, and insert output at the cursor; it supports desktop and mobile use.
