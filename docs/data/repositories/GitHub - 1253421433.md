# fcj-code/multiview-mindmap

This repository holds Multiview Mindmap, an Obsidian mindmap plugin that keeps the mindmap and its Markdown in two-way sync. Besides the basic mindmap it offers views built from the folder structure, from tags and as a chain-of-thought outline, plus a focus view laying out a selected node's parents, children, links, tags and siblings in fixed regions. The README also records node expansion and decomposition assisted by a model, which it says requires an API key and contacts an OpenAI-compatible endpoint, presentation decks generated from the mindmap structure, export to PNG, JPEG, HTML, Canvas, Excalidraw or Markdown, import of OPML and XMind files, undo and redo, a laser pen for presentations, and a multi-language interface.
