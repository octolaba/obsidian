# dgcreations00/obsidian-banners-reloaded

An Obsidian plugin that adds configurable banner images to notes. The README describes a banner hierarchy in which a per-note frontmatter banner overrides a tag-based banner, which in turn overrides the global one, plus visual style choices, a banner header, additional contexts and maintenance options. Frontmatter properties are documented for per-note overrides, and the repository states its relationship to the original Banners plugin.
