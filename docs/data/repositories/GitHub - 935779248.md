# abcamus/obsidian-sync-vault-ce

Sync Vault links an Obsidian vault to a cloud drive so that images, PDFs, audio and video can be reached and referenced across devices without filling local storage, using its own link and embed forms built from a file identifier and path. The recorded storage providers are Baidu, Aliyun, Quark, WebDAV and S3, and the description also names a virtual filesystem that occupies no local space, streaming playback and peer-to-peer collaboration. A built-in Model Context Protocol server exposes tools to listing, reading, creating, deleting, moving, renaming, downloading and uploading cloud files for clients that support that protocol, with context delivered over server-sent events.
