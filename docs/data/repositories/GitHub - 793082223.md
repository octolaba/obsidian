# Nick-de-Bruin/obsidian-media-companion

Media Companion builds a gallery of the media files in an Obsidian vault and lets them be searched by folder, tag or file type, as well as by colour, which the README states is done without AI. It also creates a sidecar file for each media file so notes, tags and similar metadata can be attached to it. The README opens with a caution to back up the vault before use, because the plugin creates and edits a file for each media file, and a warning that only the file types listed in the default settings are known to work, with other Obsidian-supported formats not officially supported. Audio files and 3D object formats are listed as planned.
