# evanlyu/obsidian-crochet-weaver

Crochet Weaver renders crochet stitch charts from Markdown code blocks as themed SVG diagrams, supporting flat rows, concentric rounds, continuous spirals, common stitches, row markers, anchors, repeats, and written stitch placement. A companion progress checklist or translated pattern-text panel can be embedded beside a chart, with row and stitch highlighting, yarn-colour changes, pan and scroll behavior, local progress storage, and an eight-language interface.
