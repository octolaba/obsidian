# saimdeniz/activity-dashboard

Obsidian plugin that aggregates note metadata into a dashboard of interactive widgets, timelines and statistics cards without requiring Dataview queries or JavaScript. Tracking is split into Collections scoped to folders, such as books, games or projects, and widgets from different collections can be pinned to a global Overview pinboard. Widget types cover distribution pie and doughnut charts, activity timelines as stacked bars grouped by month, week or year, ranking lists ordered by a numeric property, and calculation cards showing a count, sum or average. Every chart supports drilldown into a side panel listing the notes behind a data point, widgets sit on a drag-and-drop grid, and the property schema is kept current by a background scan of vault metadata.
