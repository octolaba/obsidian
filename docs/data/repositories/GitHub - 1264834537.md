# fab34/cloudflare-media-sync

Obsidian plugin that uploads local media assets referenced in notes to Cloudflare R2, rewrites the Markdown links to public URLs and can delete the local files. The README states that it targets workflows where other tools drop image files into the vault, such as PDF-to-Markdown converters, document importers, AI assistants and batch import tools. Its recent-updates section describes a standalone uploader flow for pasted, dropped, selected and existing local images, a command that inserts a chosen file as a Markdown image, a link or a plain URL, and a delayed verification of the link rewrite.
