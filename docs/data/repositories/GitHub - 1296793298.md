# Sadsnake1/cursor-smith

The repository holds Cursor-Smith, an Obsidian plugin that replaces the editor caret with a configurable one, addressed at writers and at users who need a high-visibility cursor. Styles cover a box, a line and an underline shape with their own controls, movement can glide between positions with adjustable easing, catch-up speed and delay, and blinking can be tuned in rate and duty cycle, softened into a breathing pulse, suppressed while typing or switched off. Appearance settings include separate colours for dark and light themes, gradients, thickness, opacity and glow, and the README lists a set of additional effects.
