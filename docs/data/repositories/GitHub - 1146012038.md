# The-town/book-bibliography-card

This Obsidian plugin fetches and displays book covers and bibliography from an ISBN, written into a note as an isbn code block. The README names OpenBD as the only data source and states that the plugin accesses the OpenBD API over the network to retrieve cover images and bibliography — title, author, publisher and publication date — and that no other remote service is used. The repository carries no description and the README says nothing further, so this summary rests on those statements alone.
