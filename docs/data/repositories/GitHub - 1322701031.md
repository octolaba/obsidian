# ashrudral/new-tab-here

New Tab Here makes a newly created tab open directly beside the active tab rather than at the end of the tab strip. It covers both routes into Obsidian's New tab command: the command itself is patched for the command palette and the plus button, and a capture-phase keydown listener handles the hotkey, read from Obsidian's hotkey manager so a rebind keeps working. Placement uses the public createLeafInParent call to insert the leaf at the right index and sets it to the blank tab view, falling back to creating the tab and repositioning it through undocumented internals if that call fails, and leaving alone anything that lands in another tab group, split, sidebar or popout window. A debug logging setting reports which path handled each new tab.
