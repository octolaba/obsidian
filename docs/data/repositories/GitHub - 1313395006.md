# LordNeoZ/obsidian-period-calendar

A calendar panel in which every period is clickable - day, week number, month name, quarter and year - with dots marking the periods that already have a note. It reads the configuration already present in Periodic Notes or core Daily Notes, validates the note-name format as it is typed, and offers a one-click fix for cases such as combining the calendar year with the ISO week number, which writes colliding week filenames at the turn of the year. Weeks can follow ISO or locale rules with a configurable first day, formats may contain subfolders, and notes not named exactly like the format can still be matched by title or by a frontmatter date property. Commands cover the calendar view itself and next or previous for each period, a plugin URI opens a given period's note from outside Obsidian, and the target pane for opening notes is configurable.
