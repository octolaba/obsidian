# nakalsio/obsidian-danpung

The repository holds an Obsidian plugin that searches the external links already used across a vault. Its README records two commands: a suggestion dialog that finds a previously used link and inserts it into the editor, which it presents as the answer to losing track of links gathered over a long period, and a viewer opened from the ribbon or the palette where a link is found by fuzzy search and clicked to open the site. It is licensed under the GNU GPL version 3.
