# PROF0UND/stardew-pet-farm

Stardew Pets Farm adds a sidebar view in which pixel pets wander with pauses and occasional sleep, react to a click with a brief stop and a pixel-heart bubble, and share the space with decorations placed on a 16-pixel grid. Pets are added and named from a plus menu, decorations from a decoration menu, and either is removed through a mode toggled by the minus button; rugs and carpets stay below the pets so they can be walked over. The README states that pets and decorations persist in the plugin's own data and that sprites are bundled into main.js so a store install needs no separate sprites folder, and it credits BOTPanzer's Stardew-Pets as the inspiration.
