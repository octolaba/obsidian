# kenlim/file-chucker-plugin

Adds a command that moves the current file into a folder chosen from a fuzzy-search prompt, aimed at emptying an inbox quickly with a hotkey. The prompt completes an existing folder path with the tab key, or accepts a new folder name that is created on enter before the file is moved. A setting makes the plugin open the next file in the folder automatically instead of staying with the moved note. No repository description is recorded, so this note is grounded in the README alone.
