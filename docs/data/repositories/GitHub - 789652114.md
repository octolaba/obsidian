# srz2/obsidian-azure-devops-linker

Obsidian plugin that replaces a highlighted Azure DevOps issue reference with a link, either a web URL for the issue in an Azure DevOps instance or a local link to a folder of notes about it, creating that path when it does not exist. Three commands cover linking to a chosen instance, to the default instance, and to the local info file, whose name defaults to _Info and can be changed. Settings hold the instance URL including the organization name, a list of projects with abbreviations, and the local root directory for issues; several instances may be configured, and the first listed is used unless one is chosen. The README states the command can also ask for the issue in a modal when nothing is selected.
