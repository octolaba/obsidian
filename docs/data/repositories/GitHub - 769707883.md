# aarongilly/obsidian-semantic-canvas-plugin

Semantic Canvas edits note properties from an Obsidian canvas: the Markdown files placed on a canvas get properties set from their group membership and from their links to files, cards and web embeds, so typed or labelled links between notes can be created and worked with graph-style. Commands appended to the palette and to the note and canvas menus either append note properties from the canvas without removing any, or overwrite them, and another command builds a new canvas out of a note's list-type properties. Since version 1.2 properties can also be pulled into an existing canvas, updated for individual nodes rather than all at once, and a customisable set of property keys can be ignored. The README names knowledge graphs, mass editing of properties, and Venn diagrams and Kanbans as use cases.
