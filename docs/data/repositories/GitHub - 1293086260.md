# GOODJINC/obsidian-quick-tray

Quick Tray is recorded as a system tray and global hotkey plugin for Obsidian. Its README states that it hides Obsidian to the tray instead of quitting, offers open, hide, restart and quit from the tray menu, and binds global shortcuts for creating a quick note or opening Search and the Quick Switcher, with the quick note folder, filename pattern, shortcuts and tray icon all configurable. The README also records limits: the plugin is designed for Windows desktop environments, global shortcuts may fail to register when already in use or restricted, and it works only while Obsidian is running.
