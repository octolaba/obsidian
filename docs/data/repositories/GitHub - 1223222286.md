# Puhhh/clear-unused-images-obsidian

Obsidian plugin that finds and deletes images no longer referenced anywhere in a vault. The README states that it scans markdown notes, supported frontmatter references, canvas files and attachment links before comparing them against the image files present, and that deletions go through the trash Obsidian is configured to use rather than bypassing vault settings. It offers a review and log modal, cleanup once after vault load or on a recurring interval, and optional removal of folders left empty; it is described as a maintained fork of an earlier plugin.
