# Habit-Labs/Pinit

Pinit pins notes to the top of their folder in the Obsidian file explorer, replacing the habit of renaming files so that they sort first. Its README records pinning from the file explorer context menu or the note's own menu, moving a pinned note up or down within the pinned group, unpinning to restore the normal sort position, per-folder scoping so each folder keeps its own pinned group, a pin icon following the theme colors, and four command palette entries. It states that pins survive restarts and note or folder renames, that moving a note to another folder unpins it, and that the plugin reorders items inside the file explorer without touching notes, filenames or frontmatter, keeping pin state in its own data file.
