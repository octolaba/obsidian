# a2Fsa2k/obsidian-ask-my-vault-plugin

RAG Chat answers natural-language questions about an Obsidian vault and shows clickable citations that open the notes an answer was drawn from. Its README records that indexing uses a built-in BM25 full-text search engine rather than embeddings, runs inside Obsidian with no Python backend or external server, and keeps up to date as notes are created, edited, renamed or deleted. At query time the top matching note chunks are sent as context to the chosen model; the listed providers include OpenAI, Anthropic, Google, Mistral, Groq, xAI, DeepSeek, Cohere, Together AI and Perplexity, alongside local runners such as Ollama, llama.cpp, LM Studio and Jan.
