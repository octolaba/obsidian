# KJoner/litesync

LiteSync syncs a vault against a self-hosted LiteSync server, a Docker container the user deploys, and talks to nothing else: no hosted service, no account, no telemetry. Syncing is incremental, using per-file revisions, SHA-256 hashes and a global change sequence; overlapping Markdown edits are merged three ways, escalated to a conflict resolver, or kept as both versions. Every change becomes an immutable server-side version that can be compared or restored, remote deletions go to the trash, and a new device is paired by a single-use encrypted QR package before a wizard asks whether to restore from remote or merge. Optional end-to-end encryption derives a key with PBKDF2 and encrypts with AES-256-GCM before upload, leaving the server only ciphertext; desktop and mobile need Obsidian 1.13 or newer.
