# HarrySuen626/weave-epub-ai-reader

Weave EPUB AI Reader is an independent GPL-3.0-or-later derivative of Weave EPUB Reader 0.6.55 that folds a DeepSeek assistant into the ebook reader itself instead of delegating it to a separate companion plugin. Selecting text in the reader and pressing the AI button in its native floating toolbar offers five preset actions plus a custom assistant, and the response appears in a result window that can be copied from. Requests go to a configured DeepSeek endpoint carrying the selected text, chosen prompt, model name and output limit, and only when an AI action is chosen; reading and bookshelf state stay local and no telemetry is collected. The API key is held in Obsidian SecretStorage rather than plugin data, which sets the minimum version at Obsidian 1.11.4.
