# x-Ai/obsidian-nifty-links

Nifty Links is an Obsidian plugin that renders links as rich cards in the note. The README, written mainly in Chinese, records three properties of those cards: a Notion-like minimal style, adaptation to dark mode, and page information extracted through the Crestify and Microlink services.
