# linye0/knowledge-objects

The README describes an Obsidian plugin that renders semantic objects stored in Markdown as interactive components, with the initial release supporting local music objects. A fenced music block becomes an audio player showing title, artist, cover image, progress and duration, where both the audio file and the cover image must live inside the vault and be addressed by vault-relative rather than absolute paths. The README says it works on desktop and mobile and keeps the Markdown readable when the plugin is unavailable, and names papers, repositories, books, movies and games as possible future object types.
