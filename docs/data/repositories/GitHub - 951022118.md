# mnaoumov/obsidian-advanced-note-composer

Advanced Note Composer extends Obsidian's core Note composer plugin, fixing bugs in it and adding options. When a note holding relative links is merged, or a selection or heading is extracted from it, the core plugin moves those links unchanged and leaves them broken; this plugin rewrites them so they stay valid. It also handles titles containing characters that are invalid in a filename, replacing or removing them and optionally keeping the original as a note alias or in the frontmatter title key, and adds a Treat title as path option.
