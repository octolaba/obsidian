# mnaoumov/obsidian-advanced-note-composer

Advanced Note Composer extends Obsidian's core Note composer with fixes for relative links and additional controls for extracting or merging notes. It can sanitize invalid titles, preserve them as aliases or frontmatter titles, apply configurable name transforms, and optionally treat slash-separated titles as paths.
