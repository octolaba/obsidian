# carvah/markdown-tree-plugin

The Markdown Tree plugin renders directory trees from indented plain text placed in a markdown-tree fenced block. Indentation with spaces or tabs represents nested directories and files are written under their directory, and the rendered output draws the same structure with connecting branch characters. The README credits an existing online directory-tree generator for the output format.
