# WlanKasper/obsidian-opencode-plugin

Obsidian plugin that makes raw OpenCode references show up as edges in Obsidian's native graph. It scans Markdown files for those references, resolves each one to an existing vault file and adds synthetic entries to the resolved-link metadata, so the graph and local graph draw them as if they were ordinary internal links. It does not rewrite files, convert the references, or create missing targets, and the synthetic edges are removed when the plugin unloads. The README records that this rests on an internal metadata cache shape rather than a public API, and that links to headings or block identifiers are unsupported in this first version.
