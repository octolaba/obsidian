# pandaAIGC/obsidian-empty-trash

Obsidian plugin that permanently removes every item inside the vault's hidden .trash folder in one action, run either from the command palette or from a ribbon icon and confirmed once before deleting. It applies only when Obsidian is configured to move deleted files to the Obsidian trash. The README notes that it does not touch the operating system trash and that the deletion cannot be undone from Obsidian, so backups or sync history should be kept.
