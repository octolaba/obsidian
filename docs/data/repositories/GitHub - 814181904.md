# gfxholo/iconic

Replaces the icon on tabs, files and folders, bookmarks and groups, tags, properties, ribbon commands, window buttons, sidebar toggles and the help and settings buttons, choosing from the Lucide icons included in the app or from emojis. Icons are changed by secondary-clicking an item and picking Change icon, with multiple selection in the Files, Bookmarks and Properties lists, and each icon takes one of nine named colors determined by the current theme or an arbitrary RGB value. A rulebook automates file and folder icons from conditions such as name, extension, parent folder, tags, property values, creation or modification date and the time of day, replacing custom icons visually without removing them. The README states that ten interface languages are included and that most of them are machine-translated.
