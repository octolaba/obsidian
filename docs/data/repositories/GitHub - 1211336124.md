# shygoly/obsidian-local-html-embed

Local HTML Embed renders a vault-local HTML file inside a note through an html-embed code block, aimed at standalone reports, diagrams, dashboards or interactive prototypes kept in the vault. The block takes a vault-relative path or the keyword auto, which resolves to the HTML file sharing the current note's path and basename, and an optional second line fixes the iframe height where otherwise it is computed automatically. The README records preserved UTF-8 text, relative assets resolved through a generated base URL, fallback theme variables for tab and card layouts, and optional collapsible presentation for section-based layouts. It warns that scripts are permitted inside the sandboxed iframe, so only trusted local HTML should be embedded.
