# nahime0/obsidian-note-status-plugin

Draws a configurable Lucide icon beside every internal link pointing to a note whose frontmatter matches one of its rules, in both Reading view and Live Preview. A rule names a property, an optional value, case-sensitive or case-insensitive comparison, an icon and a color; rules are evaluated from top to bottom and the first match wins, an empty value acts as a wildcard for any non-empty property, and a YAML list matches when any of its items does. Notes and frontmatter are only read, never modified, and embeds and links inside real Markdown tasks are left alone. It requires Obsidian 1.4.0 or newer, is declared for desktop and mobile, and makes no network requests.
