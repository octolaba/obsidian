# Cold-dragon7/Obsidian-Class-Relation-Visualization

This plugin visualizes classes and the inheritance, composition and aggregation relations between them, read out of class files written in a fixed form. Relations are expressed as links to other class files under Inheritance, Composition and Aggregation categories, and a category marked with a hyphen holds a description of the class. The command Open Class Relation View renders the relations, and hovering a class shows its comment and highlights it. The README states that the plugin is in development, may produce unexpected output, and has a known defect where the rhombus marking a composition or aggregation relation is often not placed on the line.
