# OGKevin/obsidian-kobo-highlights-import

The repository holds Kobo Highlight Importer, an Obsidian plugin that imports highlights from a Kobo e-reader. Its README records the procedure: connect the device over USB, make sure it is mounted, open the plugin's import window and point it at the reader's SQLite database inside a hidden folder on the device. Output is shaped by Eta templates whose variables and syntax the README documents; the catalog records the repository as a fork under the MIT license.
