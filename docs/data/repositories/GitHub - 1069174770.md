# dsokolov/goboard

Renders Go game diagrams, also known as Weiqi or Baduk, from markdown code blocks. A goboard block declares a board size, and stone lines beginning with B or W place black and white stones at a coordinate. The README documents installation from the community plugin browser and points to separate example, installation and build documents; it is offered in English, Russian and Chinese.
