# enygma/vault-ai-buddy

Vault AI Chat is an Obsidian plugin that puts an AI assistant in a sidebar panel with access to the vault. The README says every message automatically searches the notes for relevant content and includes it as context, that mentioning the active note lets the assistant read it and suggest or apply edits, and that it can create notes, update content, move files and create folders, with destructive actions asking for confirmation first. It also documents Model Context Protocol servers as an extension point with GitHub support for querying repositories, issues and pull requests, a remember action that stores facts in the vault, parallel sessions in a tab strip, and a one-time wizard that writes two personalisation files to the vault root which are injected into every request.
