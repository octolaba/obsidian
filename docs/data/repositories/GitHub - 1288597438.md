# YzYhhhstudy/leetlog

LeetLog is described as automatically capturing LeetCode practice into Obsidian, with typing starting a timer and an accepted submission saving code and statistics, leaving the practitioner to write the reflections. The README explains that timing begins at the first keystroke on a problem, submissions are counted, and an accepted result writes the code, runtime statistics and timing into a structured note, with repeat attempts accumulating in the same note. It positions the project against LeetHub-style tools, timer extensions and LeetPlug, and states that the data stays local rather than going to GitHub or a third-party server. The README is bilingual, offering English and simplified Chinese versions.
