# rabirabirara/obsidian-jelly-snippets

The recorded description calls this a simple text snippets plugin for Obsidian and warns that snippets should be backed up before updating. The README repeats that warning for versions 1.5 and below, whose snippets are erased by the update to 1.6, and promises a backup feature later. Snippets are written in a settings text area as a left-hand and a right-hand side separated by a snippet part divider, with entries separated by a snippet divider that must sit on its own line; the left-hand side is exactly the text replaced, while the right-hand side may contain symbols standing for things such as whitespace. With the cursor at the end of a snippet, triggering the conversion replaces that text with its replacement.
