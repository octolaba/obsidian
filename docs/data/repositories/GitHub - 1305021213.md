# 879076256/task-companion

Task Companion is a local-first Obsidian desktop plugin that treats Markdown Tasks as the source of truth while adding timed execution sessions, one-level subtasks, completion reviews, reusable experience templates, and embedded task views. It supports fixed or free-duration timers, stores long-lived data in the vault, keeps extensions disabled by default unless declared in JSON, and operates offline without telemetry or network requests.
