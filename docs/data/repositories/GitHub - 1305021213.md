# 879076256/task-companion

Task Companion is a local-first task execution companion for Obsidian on the desktop. Its README, written in Chinese, records that Markdown tasks remain the source of truth while the plugin adds timing at 25 or 50 minutes or a free duration with pause, resume, end and recovery, execution sessions, one level of subtask breakdown, completion reviews with reusable experience templates, and embeddable components for current, today, important, daily, pending and review views. It states that the plugin is local and offline with no telemetry and no network requests, that a controlled local extension mechanism is disabled by default and accepts declarative JSON only, and that an overwriting upgrade preserves the plugin data file and the long-term data folder in the vault root.
