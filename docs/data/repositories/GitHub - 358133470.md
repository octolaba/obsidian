# zolrath/obsidian-auto-link-title

Auto Link Title fetches the page behind a pasted URL and turns the paste into a Markdown link carrying the page title. A keyboard shortcut converts an existing raw URL under the cursor into a titled link, or replaces the title of an existing Markdown link with the freshly fetched one. The README records that on mobile the URL has to be pasted through the tap-and-hold action, because the clipboard shortcut of one keyboard does not raise the paste event the plugin listens for.
