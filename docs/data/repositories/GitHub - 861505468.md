# isdmg/obsidian-remove-unused-block-ids

Remove Unused Block IDs scans the vault for block identifiers that nothing references and deletes them after a confirmation step, run from a single command in the palette. The README asks the reader to back the vault up first to avoid any risk of data loss. It records two limitations: a block id referenced only from a canvas card counts as unused, because a canvas card is not treated as a Markdown file, and when a page carries duplicate block ids of which one is referenced the plugin cannot tell which block is in use — unreferenced duplicates are all removed correctly, and the README advises against duplicate ids because Obsidian itself handles them poorly.
