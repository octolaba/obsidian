# sean2077/obsidian-bases-paginator

Bases Paginator adds a read-only paginated table view to Obsidian Bases, supplying the first, previous, next and last page navigation that a native result limit does not provide. It offers standard and custom page sizes from 1 to 1,000, group-aware pagination over the native Bases grouping result, native rendering of links, tags, lists, images, formulas, dates, booleans and numbers, a sticky header, configurable pagination placement, keyboard-accessible controls, screen-reader status and mobile-sized touch targets. The README states that search, filters, named views, sorting, property order and width, summaries, export and selection remain owned by native Bases, and that Obsidian 1.12.0 or later with the Bases core plugin is required on desktop and mobile.
