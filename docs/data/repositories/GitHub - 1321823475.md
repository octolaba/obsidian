# sakurastral/calendar-note-view

Calendar Note View adds a note-backed month calendar: a sidebar calendar gathering events from across the vault, and a calendar layout for Bases showing whatever the current Base already filtered. Events are date-only, single-day or inclusive multi-day and draw as continuous bars with stable lanes across weeks; which notes qualify is decided by Source Profiles matching a folder, tag, property-scoped wiki link or start property, with configurable property mapping and per-type style rules. Daily Notes get indicators and confirmed creation, events can be created from the command palette, a date or a context menu, and the grid supports keyboard navigation. Month and weekday labels can follow the system, Obsidian or a chosen language, and the plugin describes itself as beta with settings still liable to change.
