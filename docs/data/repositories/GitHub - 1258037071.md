# bverbeken/jot

Jot lets a PDF opened in Obsidian be annotated by hand with an Apple Pencil, keeping strokes in a small JSON sidecar beside the original so the PDF itself is never modified and the annotations travel with the vault. Pen, highlighter and eraser tools with pressure-sensitive ink, seven configurable colours and four widths are chosen from a radial palette opened by long-press that remembers the last pen and highlighter settings, and touch input is ignored once a pen stroke starts so the palm can rest on the page. Undo and redo work per PDF, one command merges the annotations into a flattened PDF as an overwrite or a copy, and another clears every stroke on the current file. The author records the plugin as early but working, limited to PDFs, and built to mark up musical scores during rehearsals.
