# tmlnv/obsidian-telegram-bridge

Telegram Bridge moves messages sent to a Telegram bot into an Obsidian vault as Markdown notes. The README describes the path: Telegram delivers the message to a Supabase Edge Function, the function stores it in a Postgres table, and the plugin polls that table, or subscribes to Supabase Realtime, and writes new messages into the vault. Attachments, forum topics, message edits and configurable routing rules are recorded as supported. Its prerequisites are a Supabase account, a Telegram account, Node.js 20 or newer, the Supabase CLI and the Obsidian desktop application, and the README notes that the bot token is encrypted with a generated key before it is stored in the database.
