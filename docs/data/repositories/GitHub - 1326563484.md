# summerdawn-ai/obsidian-file-explorer-filter

Adds a filter button to the File explorer toolbar that switches the tree between all folders and a single top-level folder, so one vault can be worked in as separate sections. An independent toggle hides files and folders whose name contains a configurable marker, by default the word DONE in square brackets, matched case-insensitively anywhere in the name. Filtering is applied as a CSS class on explorer rows rather than by changing the sort order or the files themselves, so hidden items stay reachable through search, links, backlinks and the quick switcher. Both actions are also available as commands, and the filters are reapplied when Obsidian rebuilds the explorer or files are created, deleted or renamed.
