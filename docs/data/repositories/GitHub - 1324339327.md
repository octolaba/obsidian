# iyiguncevik/obsidian-withings-sync

Writes Withings scale measurements into the frontmatter of Obsidian's Daily Notes, keeping only the most recent reading for each day. Which measurements are recorded and what the frontmatter properties are called is configurable, as are kilograms or pounds and the decimal separator. Syncing runs on startup and on an interval of at least ten minutes, on demand, or as a backfill over a chosen range of up to 365 days; after the first sync it fetches incrementally, while a manual run overwrites frontmatter for the days in its lookback window. The plugin is desktop only, requires the core Daily Notes plugin, and connects to a Withings account through a browser OAuth flow.
