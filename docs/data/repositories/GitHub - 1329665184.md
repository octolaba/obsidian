# Calmtea5209/Gallery-Excluder

Gallery Excluder writes empty .nomedia files into chosen vault folders so that compatible Android media scanners skip them, keeping vault images out of gallery apps while they stay ordinary files inside Obsidian, in embeds and in sync. Protection covers the whole vault, the configured attachment folder, or a list of custom vault-relative folders, and is applied when the vault opens on Android and when a configured folder appears later. Any .nomedia file that already exists is left alone, and paths the plugin created are tracked so they can be removed when automatic protection is turned off. Settings can be edited on any platform, but files are created or removed only in Obsidian for Android; when attachments are stored beside the current note, a fixed fallback folder is requested instead.
