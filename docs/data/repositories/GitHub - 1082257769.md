# dudaanton/obsidian-strudel-plugin

This plugin embeds the Strudel live-coding music environment in Obsidian, adding a player for Strudel patterns held in notes, syntax highlighting that marks the part currently playing, sample caching for local playback, and a pianoroll widget that adapts to the active theme. The README states that Strudel's source is vendored rather than taken from its npm packages, because those execute network-loaded code and would violate Obsidian's plugin security policy, and that play, stop and reload buttons are drawn above each strudel code block. Two disclaimers are recorded: the author is not affiliated with Strudel and redistributes it under AGPL 3.0, and the plugin executes arbitrary JavaScript from notes, which the README says carries inherent risk.
