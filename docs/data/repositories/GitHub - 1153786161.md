# jetrica/obsidian-word-cloud

Generates an interactive word cloud inside an Obsidian note, drawing the words at randomised sizes, colours and orientations. Clicking a word recentres it and redistributes the others, and the README describes automatic scaling of font size and spacing to the word count together with a spiral placement algorithm meant to keep words from overlapping. Colours, fonts, spacing, separators and text casing are configurable, and the README states that it works on desktop and mobile. Its stated inspiration is Ray Bradbury's practice of writing lists of evocative nouns and following one of them into a story.
