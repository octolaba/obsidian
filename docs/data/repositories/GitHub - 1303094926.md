# damofer/nightly-journal

Nightly Journal is an Obsidian plugin in which a local AI interviews the user at the end of the day with short follow-up questions and then writes the journal. Before anything is saved it presents a writing plan item by item with checkboxes, and only on confirmation does it write a daily note with mood and energy plus person and project notes connected by wikilinks. Input can be typed, dictated with the microphone or hands-free, with pause detection and spoken replies, and a long-term memory answers questions from the user's own notes citing dates and sources. The README states that the model runs on the user's own machine through Ollama with no cloud, accounts or telemetry, and that the interface is available in English and Spanish.
