# BCS1037/wk-image-caption

Shows captions under images in both Live Preview and Reading mode, covering standard Markdown images, wiki embeds and external image hosts. The README states that image-resizing parameters are parsed out so only the caption text remains, and that an alias carrying only a size produces no caption at all. Layout is corrected through a CSS parent selector so an injected caption neither shifts nor overlaps the image, and the plugin works against the active document rather than the global one so pop-out windows behave. Settings cover falling back to the file name when no alt text is set, text alignment, italic or normal styling, and take effect without reloading the plugin.
