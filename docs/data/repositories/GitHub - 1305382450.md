# NoteNerdOfficial/doc-preview

Repository for Doc Preview, a desktop-only Obsidian plugin that opens PowerPoint, Word and Excel files in an Obsidian tab instead of launching the originating application. Rendering runs through a headless local LibreOffice install, which the settings tab can install to a folder of the user's choosing, and the preview refreshes when the file changes on disk — including changes made by an external tool or agent — jumping to the page or slide that actually changed. The README describes a custom PDF viewer with zoom, fit-to-page, rotation, panning, selectable text, a thumbnail rail and keyboard navigation, plus sheet tabs for Excel workbooks taken from the PDF outline.
