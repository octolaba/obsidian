# luolanaaTUD/obsidian-graph-analysis

The README describes an Obsidian plugin that treats the vault as a knowledge graph, computes graph-theory metrics locally — degree, betweenness, closeness and eigenvector centrality — and feeds them to Google Gemini to produce semantic analysis, structural analysis, evolution tracking and one-click suggestions; it is opened from an icon in the left ribbon. Its stated premise is that neither part suffices alone: the algorithms give a reproducible view of which notes are hubs, which are bridges and where the structure is thin, while a model reading note text has no view of the whole network. The README frames the problem it addresses as internalizing a large, fast-growing vault rather than acquiring more notes.
