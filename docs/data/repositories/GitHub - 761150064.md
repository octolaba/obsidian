# kerry/obsidian-confluence-sync

Confluence Sync syncs Obsidian notes to Confluence, and its README states that the plugin is at a very early phase. A note is connected by running a command that creates a new Confluence connection with the note open and entering the numerical Confluence page id, after which a second command syncs the note to that page. The README's caveats explain why identity is handled this way: each note needs a unique id so that its settings and connection survive a path change, and the Confluence page is addressed by id because its title can change.
