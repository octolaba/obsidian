# sangwon-j/obsidian-jump

Cursor Jump moves the cursor between list items and headings in an Obsidian note. Its commands jump to the next or previous item at the same level, or to an item at a lower or upper level. The README frames the behaviour as the note-editing equivalent of moving through a spreadsheet with the control key and the arrow keys.
