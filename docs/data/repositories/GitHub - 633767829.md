# flowershow/obsidian-flowershow

Publishes selected notes from a vault to a Flowershow site. The README describes the sequence: install the plugin, create a Flowershow Cloud account, generate a personal access token there, then enter that token and a site name in the plugin settings and publish through the plugin's commands or its ribbon icon. A publication status panel behind the same icon lists which published files were changed locally, which vault files are new and not yet published, and which were deleted.
