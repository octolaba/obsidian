# jackMort/flamingo-noir

jackMort/flamingo-noir holds Flamingo Noir, a monospaced Obsidian theme pairing a hot pink accent on near-black with a deep rose second accent and a separately art-directed warm-paper light mode. Pink carries H1, primary buttons, the active-tab underline and tags while rose carries H2 to H6, links and the blockquote bar; callouts are square cards with a left accent bar, and syntax highlighting covers both reading view and Live Preview. The README sets a Source Code Pro monospace stack with system fallbacks and documents community, manual and BRAT installation.
