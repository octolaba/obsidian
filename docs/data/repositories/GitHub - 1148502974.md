# vishal-go/magneto

MAGNETO synchronizes an Obsidian vault with a GitHub repository through the GitHub REST API, which the README says makes it work on mobile as well as desktop without Git installed locally. It documents push, pull and full sync, optional automatic sync at intervals of 5 to 120 minutes, configurable exclusion of folders and files, private repositories, and binary files such as images and PDFs. Setup needs a personal access token: the README recommends a fine-grained token restricted to one already existing private repository, and offers a classic token with broad repo scope as the alternative that also lets the plugin create the repository.
