# cyk111/ai-book-manager

AI Knowledge Manager builds one Obsidian knowledge base from three sources: local book files scanned as PDF, EPUB or TXT and de-duplicated by SHA256, imported Chrome bookmarks, and starred GitHub projects synced through the API with their README text. A configured AI model classifies and tags each source into its own ten-category scheme and writes Chinese summaries for bookmarks and GitHub projects. The README also describes archiving entries into category subfolders with generated navigation pages, integrating WeChat Reading and Apple Books highlights, compiling an AI Skill in one step, and a knowledge graph.
