# xiajianduan/obsidian-pluto-hub

Pluto Hub is described as a module hub for Obsidian that runs small local code extensions as decoupled configuration packages instead of JavaScript embedded in notes. Its README names three problems it addresses: writing a community plugin or long dataviewjs and Templater snippets for what is only a small widget, the startup delay of enabling twenty to forty plugins to assemble a dashboard, and conflicts between plugin data files when a vault is synced across devices. The recorded features are a console that activates each component immediately or after a two- or four-second delay, a grid card container with drag ordering and bulk import and export, an interception layer that pools extension configuration so the plugins folder can be excluded from Git, and WebGL 3D positioning.
