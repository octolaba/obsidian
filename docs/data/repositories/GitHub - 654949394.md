# ckt1031/obsidian-tinypng-plugin

This plugin compresses images in a vault through the TinyPNG service, run from a compression command in the command palette and reporting its results in a notification. Its settings hold a Tinify API key and a concurrency level. The README states that this is a community plugin and not an official one from the TinyPNG team, and asks the reader to review TinyPNG's terms of service and API usage limits before using it.
