# jacklitstar/writetex-obsidian

Bridges the WriteTex OCR app to Obsidian so that recognised math and diagrams arrive in a note as LaTeX, TikZ or Markdown. The plugin runs a local proxy server inside Obsidian on port 50905 and advertises it over mDNS so the WriteTex iOS app can discover the computer, then inserts the generated code at the cursor while it streams in. Text surrounding the cursor is sent along as context; the settings hold an API endpoint defaulting to the OpenAI API, an API key, the vision-capable model to use and an optional custom prompt.
