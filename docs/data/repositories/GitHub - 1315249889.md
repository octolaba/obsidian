# hxii/hajime-helper

Hajime Helper is a small Obsidian plugin that assists with syncing, building and pushing Hajime updates from inside the vault. It works only alongside Hajime itself, which is a separate project and is required for the plugin to do anything; a separate guide covers setting Hajime up with Obsidian.
