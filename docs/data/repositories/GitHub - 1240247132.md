# AgileSmagile/obsidian-neighbourhood-graph

This repository holds Neighbourhood Graph, an Obsidian plugin that shows the current note's neighbourhood as an interactive force-directed D3.js graph in a sidebar panel. The graph recentres as the active note changes, showing the focus note as the largest node, neighbour notes connected through shared tags or backlinks and sized by relevance, and diamond-shaped nodes for the tags that connect them; when Excalibrain is installed, typed relationships are drawn with distinct line styles. Hovering a node highlights its direct connections and, at depth 2, its secondary ones, while clicking recentres the graph, double-clicking opens the note in the editor, and nodes can be dragged.
