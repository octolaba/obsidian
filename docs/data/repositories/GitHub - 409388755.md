# bramses/stenography-obsidian

This plugin passes a selected code block to Stenography, which returns a translation of the code into simple English along with a guess at the language it is written in. Its README records that it was made for Obsidian October 2021, that it is installed by searching the community plugin list, and that an API key has to be set in the plugin's settings first. Running it means highlighting an unedited code block and clicking the plugin's ribbon icon.
