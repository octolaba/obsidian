# Romelium/obsidian-easy-timeline

Obsidian plugin that renders a timeline from ordinary note text placed in or around a timeline code block, where sections are separated by blank lines and each section's date is the first valid date it mentions. Dates are parsed with Chrono, so relative expressions such as today, tomorrow or a number of days ago are accepted alongside explicit dates, and references in note properties can be used for relative dates. Block options such as sort order can be given on the fence line. The README names the historica plugin as its inspiration.
