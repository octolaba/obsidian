# evielync/hyo-theme

evielync/hyo-theme holds Hyo, a warm, earthy Obsidian theme built on the Hyo design system, with a white editor, a parchment sidebar and a soft peach accent in both light and dark modes. The README covers installation through the BRAT plugin, which keeps the theme updated automatically, or manually by copying theme.css and manifest.json into the vault, and records the MIT licence.
