# anandrajbaghel/obsidian-gate-manager

This repository holds GATE Manager, whose upstream description concerns keeping a GATE study vault synced with community updates without losing personal notes. The README describes connecting a personal vault to a community-maintained GATE repository, downloading releases from GitHub, showing release notes, previewing every installation action before it is applied, and preserving user-owned files according to repository rules. Compatibility is recorded as Windows, macOS and Linux, with mobile listed as not currently supported.
