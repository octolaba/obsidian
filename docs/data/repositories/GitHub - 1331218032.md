# devsdocs/obsidian_media_embed

Stream Embed turns a link pasted on an empty line into an embed block that renders as a player or preview in Live Preview and Reading view, covering Spotify, YouTube, Google Drive and Workspace files, Vimeo, Loom, Figma, SoundCloud, Twitch and CodePen. Height, aspect ratio and load mode can be set per block inside the block itself, and settings hold default heights for Spotify and Google Drive embeds. A click-to-load mode renders a lightweight card and loads the iframe only when it is clicked, and a hover bar copies the URL, opens it in a browser or expands the embed into a full-window modal. Commands convert a link under the cursor or a selection into an embed block and toggle click-to-load globally; Obsidian 1.13.0 or newer is required.
