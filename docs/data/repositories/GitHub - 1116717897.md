# xRyul/calendar-for-daily-notes

This repository holds Calendar for Daily Notes, an Obsidian plugin that adds a collapsible list view showing daily notes as a hierarchical tree. Six grouping presets are offered over year, month, quarter and week, together with sort order, a minimum word-count filter, optional count badges on group headers, and rows for notes and attachments created on a day even when no daily note exists. A day can carry a custom title suffix stored in plugin data rather than in the file name, and eight colour tags can be assigned to a day or file by right-click. Title generation is optional, runs against a local Ollama server with a gemma3 model, produces three keywords and a one-sentence description, and is cached by file modification time.
