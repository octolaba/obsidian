# eiger3970/obsidian-kanban-archiver

Kanban Archiver moves completed Kanban cards older than a configurable number of days, thirty by default, into a separate archive file named after the board. Every card in the Done column counts as completed whether or not it is ticked, the Done column names are configurable and comma-separated for several columns, and ticking an undated card stamps today's date on it so it becomes archivable. A first-run prompt detects undated completed cards and offers to stamp them in bulk, and undated cards are archived into a separate review section rather than being lost. Commands archive the current board or every Kanban board in the vault, and the settings show where the archive file is written.
