# RasmusAChr/PDF2Images

PDF 2 Images converts the pages of a PDF into images and inserts them into the active note, started either from the command palette or from the ribbon in the left menu. Settings cover image quality from half to double the default scale, the output format as WEBP, JPEG or PNG, whether images are generated and inserted one at a time or all at once, and what separates them: an empty line, a separator line or nothing. An option generates a header for each image from an analysis of the PDF page, with duplicate headers optionally removed; the README describes that header detection as early in development and varying with the PDF layout.
