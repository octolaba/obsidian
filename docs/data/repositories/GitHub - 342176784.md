# chhoumann/notetweet_obsidian

NoteTweet posts to X directly from Obsidian through a composer modal that pre-fills from the current editor selection, treating a marked thread block as a pre-split thread and auto-splitting other text at the platform's character limit. Further commands post the current selection immediately or post the first thread block of the active note, several named accounts can be defined with one default for the quick commands, and a modal after posting can delete what was just sent. Images can be attached from the vault, pasted, or embedded through a wiki link to an image file, with uploads recorded as desktop-only, and the API keys are kept in Obsidian's encrypted secret storage rather than in the plugin's data file. Optional scheduling runs through a self-hosted scheduler.
