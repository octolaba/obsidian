# Aceak/LskyPro-Image-Uploader

An Obsidian plugin that uploads local images to a LskyPro image host and replaces them in the note with the returned external URLs. The README records compatibility with the LskyPro V1 and V2 APIs, uploads from the clipboard, drag-and-drop, the context menu and the command palette, batch upload of every local image in the current note, low, medium or high concurrency, optional handling of pasted network images with a domain blacklist, and optional deletion of the source file after upload. It requires a reachable LskyPro service with API access enabled and an access token, plus a storage ID for V2, and it records clipboard auto-upload as desktop-only and attachment auto-upload as mobile-only. The interface offers Chinese and English.
