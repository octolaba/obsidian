# kevboh/longform

Longform helps write and edit novels, screenplays and other long projects in Obsidian by organizing a series of notes, called scenes, into an ordered manuscript, and it also supports single-note projects for shorter works. The README lists a dedicated sidebar collecting projects from across the vault, a reorderable and nestable scene list, scene, draft and project word counts, daily writing session goals, and a workflow-based compilation tool that builds manuscripts from projects. It points to fuller documentation in the repository's docs directory.
