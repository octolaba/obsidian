# mrrepac/ai-assist

RU AI Assist is built around rewriting the note rather than chatting about it: text is selected, an action is run, and the result replaces the selection, with the ordinary undo still available. Actions include fixing spelling, improving, expanding, shortening and evaluating text, plus custom prompts, each optionally bound to its own model; when nothing is selected, a setting decides whether the action takes the paragraph, the section under the cursor, the whole note or nothing. A right sidebar chat accepts a selected fragment as an attachment, images pasted, dragged or picked from the vault, and PDFs sent as the text layer Obsidian's own viewer extracts. The bundled providers are DeepSeek and the Russian aggregators Polza.ai, ChadGPT and GPTunnel, plus Ollama for a model on the user's own machine.
