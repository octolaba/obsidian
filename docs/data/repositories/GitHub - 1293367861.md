# IamMaxim/obsidian-docgen-theme

Docgen is a warm near-black Obsidian theme with honey-amber accents, modelled on the aesthetic of the docgen documentation generator and set in Geist. Geist and Geist Mono are embedded in theme.css as base64, so they render offline with no external font requests, and dark is the primary mode with a light mode tuned from the same token set. Its main addition is a bullet journal task system of 23 markers: four state markers that keep a checkbox because they answer whether the item is done, and annotation markers that drop the box for a Lucide icon, sized from the core checkbox variable so they scale with the configured text size. The README states that the marker set is compatible with the Things and Minimal themes, so notes written for those render correctly.
