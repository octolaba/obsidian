# seonggoos/obsidian-schedule-calendar

Schedule Calendar turns schedules kept in Obsidian daily notes into a drag-and-drop timeline, offering a 24-hour daily view, a seven-day weekly view and a monthly grid whose day chips jump back to the daily view. The README describes dragging an event to reschedule it in fifteen-minute steps, dragging it horizontally to another day in the weekly view, resizing from either edge, clicking to edit or delete it in a popup, double-clicking an empty slot to create one with a ghost preview, a touch-friendly add button, and an undo stack of up to twenty steps that stops when the underlying note changed elsewhere. It integrates with the core Daily Notes settings for folder, date format and template, creating a missing note through that workflow before adding the schedule section, with a manual folder and date format as a fallback; overlapping events are laid out side by side.
