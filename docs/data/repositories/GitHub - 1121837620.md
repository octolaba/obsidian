# Moyf/obsidian-gumroad-theme

This repository holds the Obsidian Gumroad Theme, a custom theme whose minimalist look is taken from the design of the Gumroad website, with light and dark variants shown in the README's screenshots. It is installed by putting its folder under the vault's themes directory and selecting it in the appearance settings. The README states that the theme is a fan-made project, is not affiliated with or endorsed by Gumroad, and is in very early development.
