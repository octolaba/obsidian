# Moskize91/apple-books-notes-sync

A desktop Obsidian plugin that syncs Apple Books highlights, notes and PDF annotations into Markdown notes in the vault, writing by default into an "Apple Books Notes" folder. Reading the local Apple Books data and the sync work itself run in a companion CLI named absync, installed separately from npm, which the plugin settings can detect and test before Doctor, Plan or Sync are run from the command palette. The README lists the requirements — macOS, Obsidian desktop, a local Apple Books library, Node.js 20.16.0 or newer, sqlite3 on PATH, and an optional PDF renderer such as swift, mutool or pdftocairo — and states that mobile is unsupported. The repository carries no description.
