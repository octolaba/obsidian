# hodie/obsidian-custom-selectors

The repository holds Obsidian Custom Selectors, a plugin that turns configured frontmatter properties into dropdown menus with a fixed list of options. The dropdowns are injected both into the properties view at the top of a note and into table cells in views of the core Bases plugin, and a change in one place updates the other immediately. Properties and their allowed options are configured centrally in the plugin settings, and the first option can optionally become the default for files created from a Bases view.
