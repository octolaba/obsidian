# savicprvoslav/vault-brain

Vault Brain is a multimodal AI plugin for Obsidian running against Gemma models on a local Ollama endpoint, covering voice, vision, whole-vault retrieval chat and AI writing. The voice side turns an audio file or an in-app recording into a verbatim transcript, a short summary and extracted tasks written to a daily note or a new note, with recording controls, microphone selection, a meeting mode producing a diarized transcript with decisions and action items, and a watched folder transcribed automatically. Vision extracts Markdown, tables included, from an embedded image below the cursor, while a sidebar panel chats over the active note and its one-hop links or over the whole vault by semantic search with note citations from a local embedding model. The README states that every AI feature talks only to the configured localhost endpoint from a single call site.
