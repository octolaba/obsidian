# bkindler/obsidian-tagescape

Tagescape stops Obsidian from treating a hash-prefixed word in a note's body as a tag. Such inline tags are rendered as plain text with no tag styling and no click behaviour, and are excluded from the tag pane and from tag search, while tags declared in YAML frontmatter properties keep working normally. The README gives the motivation: for a vault that organises exclusively through frontmatter tags, stray hash symbols in headings, issue numbers or casual prose otherwise pollute the tag list.
