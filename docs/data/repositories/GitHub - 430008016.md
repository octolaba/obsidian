# crashmoney/obsidian-typewriter

Typewriter is an Obsidian theme designed for a focused writing experience, using a monospace font in the editor and a semi-proportional face in preview and the interface. Fonts are base64-encoded into the theme, so the README states that they need no installation and are available on mobile. Markdown formatting symbols are faded and shrunk, embeds render without file titles, long titles soft-wrap in the file explorer, and there are Vim cursor support, a cool dark and warm light mode, and stated compatibility with community plugins. The README notes that accessibility issues and bug fixes are prioritized over new features.
