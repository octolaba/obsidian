# fireshort/obsidian-tab-limit

LRU Tab Limiter keeps the number of open Markdown tabs under a configurable maximum, five by default. When a new tab would exceed the limit, the plugin closes the least recently used Markdown tab rather than refusing the new one, and switching to a tab marks it as recently used so that inactive tabs are replaced first. The README states that the project is based on the original Tab Limiter plugin, that it was changed in May 2026 from rejection to LRU replacement, and that it must not be enabled alongside the original because both manage the same workspace behaviour.
