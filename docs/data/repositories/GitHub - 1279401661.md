# Delino-WKB/PDFversioning

This plugin keeps several chronological versions of an embedded PDF in an Obsidian note and swaps between them. Its README explains the motivation: PDF readers inside Obsidian flatten handwriting and do not make it easy to keep iterations, whereas external editors such as Samsung Notes can export annotated PDFs that this plugin then detects as variants. Recorded features are a button that opens the embedded or currently open PDF in the default external PDF editor, with a warning before an older variant is edited, a layers button listing all variants chronologically for instant swapping, a manual rescan that picks up newly saved versions, and bulk tools for clearing outdated duplicates.
