# huynhtranhoanglong/obsidian-datestamp

Datestamp prefixes the name of every new note with today's date, so a new note is named with the date followed by the default name rather than just Untitled. The date format, the separator and the default name are configurable, with the format given in Moment.js tokens. The README states compatibility with Templater, where a 500 millisecond delay lets templates be processed before the rename, and with QuickAdd note creation.
