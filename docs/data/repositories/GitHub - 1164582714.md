# AntoineArt/obsidian-nav-buttons

This repository holds Nav Arrows, an Obsidian plugin that adds navigation buttons to the tab bar. The arrows sit in the top bar next to the sidebar collapse button, move back and forward through history, and stay visible regardless of sidebar state. The README records that an arrow is disabled when there is no history in that direction, that the icons match Obsidian's native style, and that the plugin is MIT licensed.
