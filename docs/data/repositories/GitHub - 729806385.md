# Trulsaa/obsidian-icloud-contacts

Imports contacts from an iCloud account into a folder in the vault, writing one note per contact with contact details as frontmatter properties. Updates touch only those managed properties, the note title and the top-level heading, so anything else written in a contact note survives a resync, and the set of managed keys is adjustable through an excluded-keys setting. Configuration takes a username and an app-specific password, and the README states that a Nextcloud address book share URL can be used in place of the iCloud server URL. Syncing runs from a command and can be restricted to selected contact groups.
