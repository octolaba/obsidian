# ipshing/obsidian-broken-links

Broken Links locates internal links in an Obsidian vault that connect to no file, including links to headings and blocks, and lists them in a view opened from the ribbon icon or command palette. Clicking a link opens the note containing it, so it can be edited or the missing note created through the built-in commands and context menus. Three presentations are offered: a folder view mirroring the file browser with per-folder counts, a file view without the folder level sortable by name or by number of broken links, and a link view collating links by name with the files they appear in. The README notes that the plugin's styles mirror the core file explorer and ships a CSS override snippet for cases where another plugin alters that layout.
