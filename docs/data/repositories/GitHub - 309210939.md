# ismailgunacar/gitsidian

ismailgunacar/gitsidian is a basic Obsidian theme that changes only the preview mode, to look more like GitHub markdown styles. The README describes installation by dropping obsidian.css into the vault with custom themes turned on, or by appending its contents to an existing theme's CSS, where a few small conflicts may have to be resolved. Planned future work is to split the project into an override usable with any theme and a full theme that responds to dark and light mode.
