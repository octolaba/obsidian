# yanqingwang/obsidian-html-to-md-effect

HTML to MD Effectiveness converts an active HTML file to Markdown or batch-converts all HTML files in the current folder. It preserves headings, emphasis, code, links, images, nested lists, tables, blockquotes, and horizontal rules, with optional title and source frontmatter and configurable protection against overwriting existing Markdown files.
