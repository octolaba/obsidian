# rybaier/obsidian-chat-splitter

This repository holds Chat Splitter, an Obsidian plugin that breaks long AI chat transcripts or documents into one note per topic. It imports pasted text or JSON, ZIP and Markdown files exported from ChatGPT or Claude, and for documents it takes headings as section boundaries with a paragraph-group fallback. Topic boundaries are detected offline by six weighted heuristic signals, and each produced note carries a generated title, domain-aware tags, a summary and key points in callouts, and previous, next and parent wikilinks, with an index note tying the set together. The README states that a local Ollama model can optionally improve segmentation quality.
