# kotserge/obsidian-bases-kanban

Bases Kanban adds a kanban board view for Obsidian Bases that is driven entirely by Bases primitives: the board reads the Filter, Group by, Sort and Properties already configured on the `.base` file through the standard Bases toolbar. Dragging a card between columns updates the group-by property on the note, and clicking a card opens it. The README records Obsidian 1.10 or later for the Bases API and no additional dependencies.
