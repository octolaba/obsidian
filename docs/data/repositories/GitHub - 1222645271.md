# AKin-lvyifang/codex-echoink

Obsidian plugin that puts a Codex-based agent panel and a knowledge-base workflow inside the vault. The README describes a first-run setup guide checking the Codex and OpenCode tooling before use, a process timeline shared by the Codex, OpenCode and Hermes backends that keeps reasoning, commands, file edits and tool calls collapsible under the final answer, a per-session turn queue, and a home dashboard with wiki status, health score, heatmaps and filterable note cards. A persistent knowledge channel is driven by chat commands over a rules file in the vault, with local history, archived background threads and optional weekly reviews.
