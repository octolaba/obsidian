# Sadsnake1/word-smith

Word-Smith is a modular Obsidian writing environment with Zen mode, letterbox masks, typewriter scrolling, a write-forward Hemingway lock, configurable Powerline status rows, syntax colouring, prose checks, smart typography, themes, goals, and writing history. Each feature can be enabled independently, applied to selected folders or notes, and kept off until configured, while local checks are presented as prompts rather than definitive judgments.
