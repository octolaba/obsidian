# wuyifan-code/Claudian-plus

Claudian Plus is a desktop-only Obsidian workspace that combines Codex-first defaults with Claude, OpenCode, Kimi, and Pi providers while keeping conversations, memory, and provider sessions in the Vault. It adds note and folder context, file and image attachments, local history, opt-in memory, and a floating outline; provider tools can update Canvas, Properties, links, and graph neighbors with approval, structured diffs, and session-level undo where supported.
