# wuyifan-code/Claudian-plus

Claudian Plus is a desktop-only AI workspace for Obsidian that combines the Codex, Claude, OpenCode and Pi coding agents in one place while keeping conversations, memory, retrieval indexes and provider sessions local to the vault. The README states that provider-native sessions, model discovery and separate permission flows are preserved rather than unified, with Codex as the default. Vault material is brought into a conversation through `@note` and `@folder` context, drag-and-drop files, images, the editor selection, File Explorer actions, Canvas, Properties and links, and local conversation search is offered for finding an earlier discussion.
