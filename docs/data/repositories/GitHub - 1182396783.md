# wepee/obsidian-folder-sort-rules

Folder Sort Rules defines custom sort orders per folder in an Obsidian vault, overriding the global file explorer sorting, with files and subfolders inside one folder sorted independently. Seven orders are offered: name ascending or descending, modified time and created time in both directions, and manual, where items are reordered by dragging them in the file explorer. A rule can apply recursively to nested subfolders, and resolution takes an exact rule for the folder first, then the nearest recursive parent rule, and otherwise Obsidian's global order, so the most specific rule wins. Rules are created in the plugin's settings tab by picking a folder and choosing the two orders.
