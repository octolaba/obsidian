# danialkalbasi/obsidian-vox

Vox reads Obsidian notes aloud with playback controls for pause, resume and stop, using natural voices from ElevenLabs or OpenAI or the built-in browser voice. The README describes assigning a voice globally, per folder or per note, and a voice browser that loads the full ElevenLabs library including cloned or generated voices, showing gender, age, accent and use case with a preview clip before adding one. It records that ElevenLabs and OpenAI each need an API key pasted into settings, that ElevenLabs applies the 0.7x to 1.2x speed range server-side, and it suggests uses such as reviewing notes hands-free, proofreading by ear and rehearsing a presentation.
