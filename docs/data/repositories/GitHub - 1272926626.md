# tyronewj/Plugin-Share-Linker

Plugin Share Linker copies or symlinks community plugins from the current Obsidian vault into another vault. Its README records listing the plugins of the current vault, selecting several across paginated lists, and then either copying those folders into the target vault or creating symbolic links there that point back to the source vault, with existing target folders and conflicting symlinks skipped rather than overwritten. The interface can be switched between English and Chinese, and the plugin is desktop-only because it uses Node.js filesystem APIs, while symlink mode additionally needs a filesystem that supports symbolic links.
