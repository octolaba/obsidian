# SamZhang02/obsidian-latex-algorithms

LaTeX Algorithms is described as a plugin for writing algorithms and pseudocode in Obsidian. Its README explains the motivation: Obsidian renders LaTeX through MathJax, which does not allow package imports such as algpseudocode, so pseudocode environments are unavailable in notes. The plugin reads what has been typed and converts it into standard LaTeX algorithm formatting when it detects keywords, covering algorithm titles and subtitles, conditionals including switch cases, for and while loops with their terminators, proof keywords such as theorem, lemma and corollary, and indentation with a shift-tab shortcut. The README credits an earlier quick-LaTeX plugin as its inspiration.
