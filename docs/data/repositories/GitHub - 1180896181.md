# chonnz/obsidian-notion-style

Notion Style is a visual overhaul that redesigns Obsidian's typography, sidebar, code blocks, callouts, tables and interactive elements after Notion, with light and dark mode on desktop and mobile. The README records the specifics: a system font stack with Simplified Chinese, Traditional Chinese, Japanese and Korean coverage, six heading levels from 1.875em down to 0.875em, 16px body text at 1.4 line-height, inline code in red on a soft gray background, and a 1080px content width with 96px horizontal padding that collapses on smaller screens. The file tree uses 30px rows with a page icon prefix while keeping Obsidian's own folder chevron, and live-preview headings are matched to reading-view headings.
