# emarpiee/Retroma

Retroma is an Obsidian theme drawing on retro arcade machines, vintage software and the early web, described in its own words as a tribute to a time when buttons looked like you could actually press them. Picking a single accent colour derives the rest of the palette automatically. Through the Style Manager plugin the README documents swappable colour schemes, built-in retro fonts applied globally or to the markdown editor and canvas, heading colours from muted to neon, code-block corner roundness, button styling between skeuomorphism and neubrutalism, a CRT scanline filter, a grayscale toggle and a Zen Mode.
