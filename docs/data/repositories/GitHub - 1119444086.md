# abduznik/obsidian-shell-termux

Termux Bridge runs shell commands on an Android device from inside Obsidian by talking to Termux over a local HTTP bridge on localhost, which the README says avoids Android Intent restrictions. Commands are sent and their output returned without opening a Termux window, and access is guarded by a token generated during setup and pasted into the plugin settings. The README documents an install script that provisions Python and OpenSSL, downloads the bridge server, generates the token and configures Termux to start the server automatically, with the port defaulting to 8085. Its roadmap records a live terminal and snippet execution as done, and a file editor, command templates and a connection indicator as pending.
