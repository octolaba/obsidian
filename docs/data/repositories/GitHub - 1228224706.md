# ShashaNYU/Scholia

Scholia is a desktop Obsidian plugin for importing academic PDFs, preparing them for close reading and serving glossary explanations on hover. The README describes the pipeline: a PDF is imported into a per-paper folder and converted to Markdown with a configurable backend, import diagnostics are written to a source subfolder, key sentences may be highlighted, likely technical terms are discovered and explained in background batches, and the resulting glossary entries are stored as ordinary Markdown files in the vault. It is deliberately cache-first — hovering never calls the model live, and an explicit explain action covers a term that has not been prepared — and the README states that definitions are grounded in the paper's own usage and that scanned, OCR-heavy documents are out of scope for the current version.
