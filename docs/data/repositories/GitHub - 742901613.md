# SvenWerlen/moulinette-obsidian-plugin

This repository holds an Obsidian plugin integrating Moulinette, a content distribution platform for tabletop roleplaying games aimed at game masters. Through Moulinette Cloud it searches for images, sounds and music, downloads them and places them in notes, and it also searches for and downloads Obsidian notes such as rules, snippets and tables, all from the Open Moulinette Browser command. The README records that the content comes from creators and communities as both free and premium material, that payment is required for full access, and that the plugin performs searches on assets.moulinette.cloud and downloads content from cloud storages.
