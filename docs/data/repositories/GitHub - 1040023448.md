# vin-cf/obsidian-checkbox-auto-sort

This repository holds Auto-Sort Completed Checkboxes, an Obsidian plugin that reorders a checkbox list the moment an item is ticked, sinking checked items to the bottom while unchecked ones stay on top. Only the contiguous checkbox block containing the changed item is reordered, indented child items stay attached to their parent, and a divider line separates the two groups. The README states that it works in reading and editing modes, that sorting is triggered by a user edit, and that the implementation registers two CodeMirror 6 extensions. The repository carries no description, so this body rests on the README alone.
