# wenlzhang/obsidian-tag-index

Tag Index maintains a curated list of important tags in Obsidian as entry points into a vault, kept separate from the default tag pane. The README records adding tags from the editor context menu, the default tag pane or the command palette, nested tags held as an automatic tree, drag-and-drop rearrangement in a custom sort mode, and independent sorting of tags by custom order, frequency, name or time added and of the notes under a tag by file name, modified time or created time. It also records showing the actual line on which a tag appears, clicking that line to open the file at exactly that place, an option to open the search pane for all occurrences across the vault, and a configurable cursor position.
