# jo-minjun/petrify

Petrify converts handwritten note files into Excalidraw or Markdown inside an Obsidian vault, with OCR that makes the handwriting searchable. In the Excalidraw output the README says the handwriting is preserved as-is on the canvas, where it can be annotated with text, arrows, highlights and links. The README frames the problem as handwriting exported to PDF becoming a flat image cut off from search, links and the graph view, and records Viwoods as a supported source device.
