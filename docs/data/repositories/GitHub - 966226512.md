# shenoy-anurag/obsidian-image-border-style

Applies a border radius and a border to images in both the editor and reading mode, choosing among nine radius sizes from none to a large rounding and six border widths from zero to five pixels. The border color follows the theme by default, faint grey in dark mode and charcoal in light mode, and a custom color can be set instead. The README states that the default border radius matches the one used in Notion, and notes that setting changes may not take effect until pages are switched.
