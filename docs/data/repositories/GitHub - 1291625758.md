# zimabx/status-words

StatusWords shows customizable word and character statistics in the Obsidian status bar, covering the current note, the current line, the current paragraph and any selected text. It also reports the selected text's line count, the cursor position and the file's name and path, offers several counting modes, and lets the status bar text be assembled from a template with a configurable thousands separator. The README records localized template placeholders that remain compatible with the raw placeholder keys, and interface text that follows Obsidian's own language setting for English and Simplified Chinese.
