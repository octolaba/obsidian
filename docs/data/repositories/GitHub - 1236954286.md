# philphilphil/obsidian-track-changes

Track Changes reviews CriticMarkup suggestions in an Obsidian side panel, writing accepted and rejected results straight back into the Markdown rather than into separate state. All five CriticMarkup forms are styled inline and given a card in the panel, adjacent comment blocks become threads, and author and date prefixes on a mark drive per-author colors. A sixth mark flags text inserted by an assistant with a rainbow highlight that is visual only and produces no review card. Clicking a mark in Live Preview exposes the raw markup for editing in place, a modified click opens the panel instead, a panel card jumps the editor to its mark, and a finalize command resolves all remaining markup in one pass; code blocks are left alone.
