# yyhzz985/xuezha985-wechat-publisher

Kenengba WeChat Publisher formats the current Markdown note as HTML for a WeChat Official Account and copies it for pasting into the account's editor. A live preview panel shows the result for the whole note or a selection, YAML frontmatter is dropped, and headings, emphasis, quotes, lists, images, rules, links, code blocks, tables and footnotes are covered, along with Shiki syntax highlighting, image captions, emoji shortcodes and custom containers such as tips, notes, warnings and dialogue. Theme, font weight, subheading style, code theme and a reading-time block are configurable, and local images are resolved against the current note rather than a fixed attachment folder. Preview, formatting settings and copying are free, while uploading to the drafts box, cover and avatar images and automatic upload of local images are paid, and the manifest declares the plugin desktop only.
