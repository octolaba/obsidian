# CocoaAI-IT/easy-obookshelf

Easy Bookshelf creates and maintains book notes in an Obsidian vault from an ISBN. The README states that metadata is fetched from the National Diet Library of Japan first, then Google Books and Open Library as fallbacks, that cover images are downloaded, converted to WebP and cached locally, and that only the entered ISBN is sent to those services. Books are added or updated from ribbon icons and commands, covers can also be set manually by drag and drop, clipboard or file picker, and shelves for want-to-read, reading and finished are provided as Bases views; the plugin is desktop-only.
