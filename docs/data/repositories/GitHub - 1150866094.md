# zkbkb/obsidian-ClipBook

Obsidian plugin that stores API keys, tokens and reusable text snippets in fenced code blocks marked with the clipbook language identifier. The README states that reading view renders such a block as a structured list with a copy button on each row, collapsible sections, and masked values revealed on click. Entries are written as key and value lines, a leading exclamation mark marks a value as masked, and a quick-add button appends entries without editing the source.
