# jiang198012/workbuddian

Workbuddian turns the local WorkBuddy or CodeBuddy CLI into an AI agent reachable from inside an Obsidian vault, with streaming replies, screenshot pasting for visual analysis, note references and conversation management. Since version 2.0.0 one long-lived codebuddy ACP process hosts every conversation instead of a process being spawned per message, which the README describes as giving resumable multi-turn context and a session that restores itself if the CLI process dies, with write and edit approvals surfaced in the chat bubble. The README records Windows and macOS support with Linux not yet supported, Obsidian 1.7.2 or later as the minimum, and version 2.0.1 as a rewrite that makes the codebase independent of its upstream without behavior change.
