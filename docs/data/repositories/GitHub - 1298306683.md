# jiang198012/workbuddian

Workbuddian connects the local CodeBuddy CLI to an Obsidian chat interface with streaming Markdown replies, image input, and references to agents, MCP servers, notes, and files. It presents approval cards for Write, Edit, Bash, and MCP actions, shows line-level diffs with undo, supports session branching and separate panels, and allows MCP and subagent configuration; it is a desktop plugin for Windows and macOS.
