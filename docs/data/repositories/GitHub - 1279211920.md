# mandolin/obsidian-html-v-editor

HTML V Editor is a desktop-only Obsidian plugin for previewing, visually editing and saving `.html` and `.htm` files inside the vault, switching a file between preview, visual edit and source modes. Visual editing uses a locally bundled HugeRTE editor with no CDN dependency and is offered for Markdown `html-v` fenced code blocks and embedded HTML files too, whose content can also be copied out as Markdown or plain text; previews run under a choice of safe, sandbox or trusted security modes. A built-in side panel collects tasks and links: the Tasks tab aggregates checklists from HTML files, `html-v` blocks and ordinary Markdown tasks with filters by status, source, tag, project and file, while the Links tab discovers internal links inside standalone HTML files and opens the resolved vault targets.
