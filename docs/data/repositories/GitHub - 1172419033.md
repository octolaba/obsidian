# fengshuzi/image-viewer

Image Viewer is an image browser for Obsidian that the README says was inspired by PicView. It browses the images of a vault folder with the keyboard or mouse, with a thumbnail strip, configurable subfolder scanning and a default folder, and claims support for more than sixteen formats including JPG, PNG, GIF, WebP, SVG, AVIF, HEIC, PSD and RAW. Viewing offers zoom by keys or wheel, drag panning, fit, fill and actual-size modes, two scroll behaviours, a grid gallery with configurable thumbnail size and column count, and a slideshow with an interval, loop and random order; it also rotates, flips and crops images, displays EXIF camera, GPS and exposure data alongside file details, and renames or deletes files from the viewer.
