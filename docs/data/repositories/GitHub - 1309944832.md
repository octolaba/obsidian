# wdlin233/obsidian-dida-dashbord

Dida Dashboard embeds a Dida365 task view in Obsidian, opened from the left ribbon and backed only by the Dida365 Open API with a personal access token configured and tested in settings. It offers All, Today, Next 7 Days, Inbox and project list views, grouping active tasks by overdue, today, tomorrow, the next seven days, further ahead and no date, and shows each task's tags, list name and due time. Tasks can be added, completed, rescheduled or deleted from the dashboard, and data is refreshed manually. The plugin has no Markdown synchronization layer and does not read or modify notes in the vault, storing only its own settings.
