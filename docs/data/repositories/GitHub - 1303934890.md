# ZavixAI/ling-sync-obsidian

The repository description is the Chinese phrase for an Obsidian plugin; the README presents Ling Sync, a plugin that sends selected Markdown notes to Ling through a provider-neutral Notes Integration API. It states that it uses only public Obsidian APIs, is not desktop-only, imports no Node, Electron or filesystem modules at runtime, and networks through Obsidian's request helper, storing tokens in SecretStorage and keeping device identity and cursor in vault-local storage. Syncing covers whole-vault or selected-folder manifests with debounced create, modify, rename and delete batches, strict server cursors, idempotent retries, and one connector device per account and vault. In the other direction the plugin leases a durable command issued only by Ling's agent skill and applies it inside the folders approved during pairing; the README requires Obsidian 1.11.4 or newer.
