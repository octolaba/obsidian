# murashit/codex-panel

Codex Panel embeds Codex in an Obsidian sidebar, keeping threads and drafts beside notes while allowing vault context, selections, links, and attachments in prompts. It starts a local codex app-server, supports approvals, file-change review, selected-text rewriting, thread archiving, and separate panel sessions. The plugin requires an installed authenticated Codex CLI and targets Obsidian desktop rather than mobile.
