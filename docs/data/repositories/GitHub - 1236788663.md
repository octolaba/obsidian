# murashit/codex-panel

Obsidian plugin that brings Codex into a sidebar panel, keeping its threads beside the notes they concern. The README states that it starts a local Codex application server, that each open panel keeps its own thread and draft with Codex working from the vault root, and that the plugin stores panel preferences only, not API keys or provider credentials. Its stated requirements are the Obsidian desktop app from version 1.12.0, and a Codex CLI that is installed, authenticated and either on the path or configured by absolute path; mobile is not supported.
