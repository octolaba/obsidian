# SomehowItWorks/auto-collapse-inactive-folders

An Obsidian plugin that automatically collapses the folders in the file list that are not currently in use, leaving the location of the active note visible. Its README, in Chinese and English, states that the code was generated with the assistance of Google Gemini and asks readers uncomfortable with that to reconsider installing it, and it notes the plugin suits people who navigate between notes by other means than the file list.
