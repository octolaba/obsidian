# P24L/calibre-bridge

Calibre Bridge imports one structured Markdown note per book from a configured Calibre Content Server, including cover, bibliographic metadata, descriptions, and available Kobo highlights. Re-imports refresh only Calibre-owned data, while commands can create a Bases library overview or synchronize existing books; the plugin contacts only the configured server and scans the selected book folder.
