# P24L/calibre-bridge

This repository holds Calibre Bridge, an Obsidian plugin that imports book metadata from a Calibre Content Server as structured Markdown notes. Calibre's Content Server is started and pointed at in the settings, and the Import books from Calibre command lists the library so that chosen books arrive as notes with a cover image, a description and frontmatter fields such as title, authors, series, rating and tags. Re-importing refreshes only the Calibre data, leaving the status, date_started and date_finished fields untouched, while the tags field comes from Calibre and is overwritten. A Create library overview command generates a Bases file with five views filtered by reading status.
