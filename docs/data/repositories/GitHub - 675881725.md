# divamgupta/obsidian-spreadsheets

The Spreadsheets plugin puts a spreadsheet tool inside Obsidian, built on FortuneSheet, which is itself based on Luckysheet. Recorded features are rich text formatting for fonts, size, colors, borders, cell color and line wrapping, several built-in formulas, filtering and sorting, and cell operations such as merging, resizing and dragging. A new spreadsheet is created from a ribbon button or by right-clicking a folder in the left sidebar.
