# Xiaoqiang-Huang/obsidian-life-os-community

Life OS Assistant organizes diary entries, tasks, knowledge, memory and AI-assisted reviews inside an Obsidian vault, described in its README as a local-first personal operating system in which the Markdown files and the choice of AI provider stay with the user. Recorded features include quick capture, task extraction and carryover with project-aware views, project cards with progress rings, knowledge-base workflows, memory review in which AI suggestions wait for confirmation, an assistant drawing on selected vault, task, project, knowledge and explicit web context, and review dashboards by day, week, month and growth. The README also states that full access is paid: free local-first features sit alongside Pro features unlocked only by a server-issued entitlement token that the plugin verifies, and local settings alone do not grant that access.
