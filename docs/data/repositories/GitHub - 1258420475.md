# katoiek/task-gantt

Task Gantt renders a configured folder of an Obsidian vault as a Gantt chart combining a table and a timeline, where one Markdown file is one task and each direct subfolder becomes a group. Bars are dragged or resized on the timeline, which writes the new start and end dates back into that file's frontmatter, and dependencies, milestones, sorting, filtering and moving a task to another folder are all done from the same view. Every column the table shows is editable in place by double-clicking: start and due open a calendar, progress takes a percentage, status is a dropdown, assignee suggests names already used on the board, and tags open a chip editor backed by the vault's existing tags. The README records a requirement of Obsidian 1.7.2 or later.
