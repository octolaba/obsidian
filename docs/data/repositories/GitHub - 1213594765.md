# thdngan/permanent-ink

Permanent Ink enforces write-forward editing in Obsidian: instead of erasing text, Backspace and Delete wrap it in strikethrough, so revisions stay visible in the note. Its README describes a restricted mode, shown in the status bar, in which new text always goes to the end of the document, typing mid-document moves the cursor to the last line, undo and cut are blocked, and Enter only works at the very end. The README states that the plugin grew out of personal modifications to another note-annotation plugin and became different enough to live on its own.
