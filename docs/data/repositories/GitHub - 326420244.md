# yeboster/autocomplete-obsidian

This plugin adds text autocomplete to the editor, triggered manually by a shortcut or automatically from a configurable character position, with suggestions navigated by arrow keys or control shortcuts and accepted with enter or tab. Completions come from providers for LaTeX, for words already written in the current session and for the current file, with tokenizers for Arabic, Japanese and a default language and configurable word separators, plus cursor placement inside LaTeX function parameters. The README states that the plugin is no longer maintained because its author stopped using Obsidian, points readers to another completion plugin, and describes the project as still a work in progress.
