# SebastianBrightly/Noesis

This repository holds Noesis, an Obsidian plugin that answers questions from the content of the user's own notes rather than from a model's general knowledge. It is described as local-first and able to run entirely against a local model endpoint such as LM Studio on localhost, with named local models including Qwen3, Gemma, DeepSeek and Mistral, while external providers can be configured instead. The README's network and privacy disclosure states, as the project's own claim, that there is no client-side telemetry, analytics or self-update mechanism, and that when an external endpoint is configured the prompts and selected note context are sent only to that user-managed endpoint.
