# Kigrok/obsidian-library-plugin

Obsidian plugin that organizes movies, series, books and other media as visual cards with automatically fetched metadata. A dedicated Library tab renders the collection as a grid of cover-art cards, titles can be searched and added from within the app through per-medium sources named in the README as OMDb, Open Library, Google Books, RAWG, Deezer, AniList and Comic Vine, and series seasons and episode totals are fetched and kept in sync. Progress bars on cards and note headers show how far a title has been watched or read, and each entry becomes a note that participates in the graph. The README is translated into nine further languages and states a minimum Obsidian version of 1.8.7.
