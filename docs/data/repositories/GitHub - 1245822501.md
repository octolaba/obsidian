# lemondepat/token-count

Token Count reports the token count of the active note in the Obsidian status bar, using the tokenizers of several large language model providers so the number matches what those APIs would charge. The model is chosen in the settings from a list of GPT, Claude and Gemini options, and the model name can optionally be shown after the count. The count covers the entire editor content including YAML frontmatter, updates as you edit, and is empty when no Markdown editor is active. The README states that the plugin is desktop only, that system prompts and chat wrappers are not included in the number, and that the Gemini option may download a vocabulary file once on first use.
