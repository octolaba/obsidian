# laantorchaweb/clone-vault

Clone Vault creates a new Obsidian vault from the current one by copying its settings folder and reproducing its folder structure without note contents. The README states that the settings folder is detected even when it has been renamed from `.obsidian`, so plugins, themes, hotkeys and workspace layout carry over. Selected folders can additionally be copied with their files, which the README suggests for templates, snippets or assets, and a modal prompts for the new vault's name while the default location for new vaults is configurable.
