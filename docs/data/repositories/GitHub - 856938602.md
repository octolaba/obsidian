# Nomekuma/auto-strikethrough-task-obsidian-pluggin

Obsidian plugin that applies strikethrough formatting to the text of a completed task and removes it again when the task is unchecked. It works with standard Markdown task list syntax, wrapping the text of a checked item in double tildes and stripping them when the item returns to unchecked. The README states the plugin listens for changes in the editor and updates task formatting as they happen.
