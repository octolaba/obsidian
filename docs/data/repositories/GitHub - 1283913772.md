# doko89/obsidian-aide

Aide is an AI writing assistant for Obsidian that opens a floating prompt when a slash or backslash is typed in a note. It offers inline actions such as improve, shorten, summarize, translate and fix grammar alongside free-form instructions, and streams the response character by character. The README states it can also search the web through Google, Brave or a custom API, fetch and summarize a URL, and generate SVG diagrams saved to an assets folder, working against any OpenAI-compatible API including a local Ollama.
