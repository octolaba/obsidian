# recklyss/markdown-timeline

This plugin builds a timeline view from notes in Obsidian, written inside a timeline fenced block where each entry carries a date, a title and a description and entries are separated by a rule. The README records support for positive and negative years so that BCE and CE dates can both be used, customizable date formats built from year, month and day tokens with any separator, ascending or descending order, search and filtering of events, and adding new events from the timeline view itself.
