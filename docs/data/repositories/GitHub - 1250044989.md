# Jalad25/theme-padd

Theme PADD gives Obsidian themes a settings page covering palette, animation, decoration and density. A theme whose author opts in gets its own page under the plugin's settings carrying the controls that author exposed; where a theme ships no settings, or omits a particular control, the same mechanism can be used to author controls for it locally. The README records that the same customization mechanism also applies globally across the vault rather than to one theme.
