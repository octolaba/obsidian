# kinabalu/obsidian-crypto-lookup

Obsidian plugin that looks up the current price of a crypto currency in a target currency using publicly available APIs, specifically the Cryptonator API. The README lists two commands, one fetching an exchange rate entered in a modal and one using the default pair configured in settings, each able to insert extra data or the price alone. Its opening line records that the API backing the plugin is gone and that a viable alternative is being sought, and it describes manual installation through the BRAT plugin or by copying release files into the vault.
