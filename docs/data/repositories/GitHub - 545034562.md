# innneang/obsidian-readavocado-sync

Readavocado Sync exports highlights from Readavocado into an Obsidian vault. After the plugin is installed, a token is generated in Readavocado's settings and pasted into the plugin's token field, and the first sync is started from there. The README states that the sync runs each time the app is opened and can also be triggered manually from the plugin's settings.
