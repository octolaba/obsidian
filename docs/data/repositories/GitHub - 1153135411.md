# Leike-Dev/Obsidian-Typify

Typify styles Obsidian metadata properties as configurable pills with colors, shapes, and Lucide, emoji, image, or custom icons. It supports scoped styles, Bases and Canvas rendering, import and export of configurations, associated links, and light or dark theme adaptation.
