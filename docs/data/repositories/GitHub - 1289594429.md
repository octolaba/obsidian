# ismailivanov/sync-deck

Sync Deck keeps an Obsidian vault synchronised across devices and, optionally, with other people, using a Google sign-in and no separate password. It offers background file sync with manual sync and pull controls, recoverable deletes, several synced vaults that stay separate, shared vaults with invite codes, Admin and Worker roles, a member list and live editor presence. The README records end-to-end encryption of file contents, filenames, folder paths and synced board identifiers with keys created and held on member devices, an explicit first sync that uploads nothing until a vault is created or opened, user-held recovery keys and owner-controlled key rotation; it presents the plugin as the cloud companion to Task Deck, whose boards are Markdown files.
