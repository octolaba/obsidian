# Quorafind/Obsidian-Table-Generator

Table Generator creates a Markdown table quickly, in the manner of Typora. It can also generate a card-like table inside a canvas file, and the default number of rows and columns is set in the plugin settings. The README documents installing it from the community plugins list, through BRAT, or by copying the release files into the vault by hand.
