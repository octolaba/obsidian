# JavierRibaldelRio/accounting-journal-ledger

Obsidian plugin for recording simple accounting journal entries in class, based on the Spanish libro diario and libro mayor and following double-entry bookkeeping. Entries are written inside Markdown code blocks tagged `acj-m`, `acj` or `acl` for the modern journal, the traditional Spanish journal and a T-account ledger layout, and they are stored as Markdown. Accounts are recognised manually or from a chart of accounts the user supplies, and a journal or ledger can be converted to HTML from the active note. The README states the plugin is designed for educational use rather than as a full accounting system.
