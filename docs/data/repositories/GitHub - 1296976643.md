# No4Var2Ye/ObsidianEmbeddedTerminal

Obsidian plugin that embeds a system terminal as a workspace view, built on xterm.js with node-pty and, on Windows, ConPTY. The README states that the real PTY architecture supports an interactive shell, ANSI colour output, cursor control, tab completion, interrupts and command-line tools such as Python, Node and Git, and that hiding the terminal does not close the background shell. Windows 10 and 11 are listed as supported and Linux as experimental, while mobile and the web version are recorded as unsupported.
