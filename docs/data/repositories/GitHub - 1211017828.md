# chenxiccc/obsidian-ima.copilot-sync

The repository holds ima.copilot Sync, an Obsidian plugin that copies personal notes and knowledge-base entries from Tencent's IMA service into a vault. Its README records the sync as one-way only, so server content overwrites local files on every run and edits made in Obsidian never travel back, and it covers notes, web pages, WeChat articles and attached files, with images and files downloaded into a local attachment folder. It also documents incremental sync, scheduled background sync, credentials held in the operating system keychain rather than a plain-text config file, three modes for handling entries deleted upstream, and a recommendation to run on desktop where the download-enhancement path exists.
