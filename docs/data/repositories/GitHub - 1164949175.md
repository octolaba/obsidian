# reaLm74/obsidian-telegram-ai

Telegram AI Sync copies messages from a Telegram bot into an Obsidian vault and runs them through OpenAI models, which the README records as GPT-4 for analysing text and images and Whisper for transcribing voice, audio and video. Text is extracted from PDF, DOCX, plain text and code attachments locally first, with the AI used only as a fallback, and messages that contain nothing but a URL skip the AI entirely. Media groups sent as an album are kept together in one note, prompts can differ by content type, and note file names are built from template variables such as an AI-generated title, a category or a date. The README records that a Telegram bot token and an allowed user id are configured in settings, and that API errors such as an exhausted quota or a revoked key are surfaced rather than failing silently.
