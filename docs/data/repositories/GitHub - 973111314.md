# bao-tg/kindle-vocab

The recorded description says the plugin generates a Markdown version of the Kindle Vocabulary Builder and puts it in an Obsidian vault. Per the README one command uploads the vocab.db file found in the Kindle's system vocabulary folder when the device is connected over USB, and another uploads a dictionary as CSV with a word and information structure, since Amazon's own dictionaries are DRM-protected; it points at public alternatives derived from Webster's and Wiktionary. The generated notes let words be marked learned or unlearned with checkboxes, show statistics such as the percentage learned, and sort words by timestamp or with unlearned items first.
