# Watermelon4000/flomo-obsidian-sync

Flomo Sync copies Flomo memos into an Obsidian vault over plain HTTP, without browser automation. Logging in happens from inside Obsidian through a popup that captures the token automatically, and the README notes the token expires periodically and login must then be repeated. A full sync fetches all memos, converts their HTML to Markdown including bold, italic, highlights, blockquotes, lists and images, and writes each one as a file named after its creation timestamp with YAML frontmatter carrying date, slug, source and tags; folders mirror the Flomo tag hierarchy and a memo with several tags is copied into each matching folder. Later syncs are incremental, detecting new, updated and deleted memos, and can run on startup and on a configurable interval.
