# uvesarshad/ostack

Obsidian plugin that runs gstack-style AI skills inside the vault, each skill being a Markdown file with a YAML frontmatter header and a system prompt. Running one from the command palette makes the plugin walk the note graph, score linked notes by relevance and recency, assemble them into a context window and stream the output back into the note. Built-in skills ship with the plugin, custom skills are added by dropping a skill file into the vault or importing one from GitHub or local disk, and the providers listed are Claude, OpenAI, Gemini, Grok and Ollama, plus CLI access through Claude Code, Codex or the Gemini command-line tool. The README's roadmap marks mobile support, voice input and a skill hub as not yet done.
