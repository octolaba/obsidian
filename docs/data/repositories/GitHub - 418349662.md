# kinabalu/obsidian-oura-plugin

The repository holds an Obsidian plugin that writes Oura Ring statistics into a note. Its README records a personal access token, created on the vendor's site and entered in the plugin settings, as the credential used to fetch the data, and states that a note named in the year-month-day form supplies the date while any other note takes today's. It documents the available fields, among them the sleep day and score and the contributing measures such as deep sleep, efficiency, latency, REM sleep and restfulness.
