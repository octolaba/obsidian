# lorens-osman-dev/double-row-toolbar

Repository for Double row toolbar, an Obsidian plugin that adds a second row to the mobile toolbar so that more quick-access buttons fit on it. The README explains how to add the plugin's delete-current-line command through the mobile toolbar configuration, including where to find it under global commands, and documents a bottom offset slider in settings that shifts the toolbar vertically so it does not overlap system gestures such as the home bar, with the change applying immediately in the editor.
