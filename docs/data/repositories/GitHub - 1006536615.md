# LittleHaku/obsidian-smart-export

Repository for Smart Export, a plugin that exports a note together with the notes it links to, following wikilinks to a configurable depth. The recorded description states that it is aimed at human-readable exports and at exports intended for language models, and the README adds traversal over outgoing links, backlinks or both, export of all notes carrying a tag, exclusion by folder, tag or frontmatter property, optional redaction of marked sections, and output as XML, print-oriented Markdown or a Markdown template. Exports can be copied to the clipboard or written as a new note, with links between exported notes rewritten so navigation still works. The README records that releases from 1.16.0 onward require Obsidian 1.13.0 or newer.
