# MichalBures/obsidian-file-path-to-uri

The repository holds File path to URI, an Obsidian plugin that converts a written local path into a file URL so notes can link to files and folders outside the vault. Its README records a toggle command, bound by default to a hotkey, that switches the selected path between the two forms. It also states plainly that the plugin is largely unnecessary now, because dragging a file or folder into a note while holding a modifier key makes Obsidian paste the same kind of link.
