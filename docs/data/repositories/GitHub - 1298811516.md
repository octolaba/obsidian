# turingexmachina/obsidian-note-snooze

Note Snooze hides a note from the file explorer until the date recorded in a frontmatter property, after which it reappears without a reload. The property name is configurable and defaults to a hidden-until key, accepting a plain date as well as a full datetime, while a missing property, an empty value or an unparseable date all mean the note is not hidden. Only the file explorer is affected: the note stays searchable, openable through the quick switcher and links, and fully readable.
