# leozymandyas/gestion-de-epicas

A Spanish-language plugin for product owners, product managers and agile teams that manages product development through epics. It works with a hierarchy of epics stored in dedicated folders, stories inside them, labels that classify stories, user-defined record types such as tasks or pending items attached at epic or story level, sprints linked to the teams working on them, and collaborators assigned to any element. Every element is saved as a Markdown note with frontmatter, filed automatically into folders with slugified names, so the information remains readable without the plugin. The README records the plugin as desktop only with a Spanish interface, and describes an action panel that creates the folder structure and opens kanban and roadmap views.
