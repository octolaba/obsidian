# ZetabS/datetime-language-changer

Repository for Datetime Language Changer, an Obsidian plugin that customises the language used for datetime formatting by changing the locale of moment.js, which affects plugins that rely on it such as Tasks. The locale is chosen in the plugin's own settings tab. The README warns that the plugin should not be deleted or disabled once installed: Obsidian does not otherwise support changing that internal locale, and the author could not make the change revert when the plugin is turned off.
