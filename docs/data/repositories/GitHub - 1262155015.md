# m1llky/obsidian-quick-github-sync

Quick GitHub Sync synchronises an Obsidian vault with a GitHub repository from a ribbon button or a command. Each run pulls remote changes first, then stages every local change, commits it with a timestamped message and pushes, with the current branch detected automatically. The README records the requirements — Git installed, the vault itself a Git repository, a remote repository and a personal access token with repository scope — and states that the token is kept outside the vault through Obsidian's local storage API so that it is never committed.
