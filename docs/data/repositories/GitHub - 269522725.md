# nickmilo/Cybertron

Cybertron is a revised retro Obsidian theme its README describes as drawing on Dynalist, Cyberpunk 2077, Synthwave, The Terminator and Keanu Reeves. It is dark mode only, gives bold and italic text each their own colour, and its author states a preference for using it alongside the Sliding Panes plugin. The README opens with a note that the author has stopped updating the theme and invites pull requests instead, and its Features and Supported Plugins sections are left unwritten.
