# Erallie/colored-candy

Erallie/colored-candy holds Colored Candy, a theme that derives the interface colours from the accent colour chosen in Obsidian's appearance settings. The README states that background colours follow the accent hue and that two further pseudo accent colours are generated by offsetting that hue while computing saturation and lightness from the original. It records the theme as intentionally low-contrast, offers a background-to-text contrast option through the Style Settings plugin for readers who need more, and asks for issue reports where the default is hard to read. Installation is documented three ways: the in-app theme browser, the BRAT plugin for beta themes, and a manual copy of the theme and manifest files.
