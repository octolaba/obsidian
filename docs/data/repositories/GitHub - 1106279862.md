# panAtGitHub/obsidian-mandala-grid

Mandala Grid organizes Markdown content in 3x3 and 9x9 mandala layouts for topic breakdown and structured writing; the recorded description calls it a Gingko-like interface in Obsidian. The view opens from a toolbar button, the file context menu or the command palette, and topics and subtopics are edited in place, swapped, pinned or colour-marked, with the same content viewable in either the tree view or the mandala grid. A day-plan template scene is available from the command palette. The README states the same content twice, in English and in Chinese.
