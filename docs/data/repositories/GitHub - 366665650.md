# mcndt/obsidian-toggl-integration

Obsidian plugin that integrates the Toggl Track API so timers can be managed from inside Obsidian. The current timer and how long it has been running appear in the status bar, a side panel summarises the day, and the command palette creates, starts and stops a timer or restarts a recent one. Code blocks render time tracking reports inside notes, for example a summary over the past seven days. Setup is an API token entered in the settings tab followed by picking a workspace, and the README records that the plugin currently relies on a third-party JavaScript client for that API.
