# smx0/obs-text-wrapper

Obsidian plugin that wraps selected text in the editor with customizable HTML tags. Up to three tags can be configured in the settings and bound to hotkeys, and a further tag can be entered through a modal opened from the command palette. The README states that when no text is selected the tags are set adjacent to each other, and that the plugin is aimed at people who frequently use lesser known HTML tags.
