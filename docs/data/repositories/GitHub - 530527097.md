# thingnotok/obsidian-toggle-list

ToggleList overwrites Obsidian's default checkbox toggling with cycling through a configurable group of list states. Several state groups can be defined for different purposes, for example a task group moving between open, in-progress and done marks, and a highlight group for other kinds of list item. A state may also carry a prefix and a suffix, which can include a timestamp in a chosen format.
