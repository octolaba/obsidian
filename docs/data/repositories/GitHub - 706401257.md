# christianwannerstedt/obsidian-key-value-list

The recorded description says the plugin makes it easy to turn lists into formatted key-value lists. Per the README a list row is recognized whenever it contains the configured delimiter, a colon by default, and needs no other input: the key column is given a fixed width computed per list by the browser layout engine so that values line up, and every other line receives a background colour to make the list easier to read. The formatting applies in Reading view through a Markdown post-processor and in Live Preview through an editor extension, while Source mode shows plain Markdown. Overlong keys or values wrap to the next line, and formats such as bold text, links and tags may be used in either part.
