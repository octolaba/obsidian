# Talal-A/obsidian-paperless

This plugin inserts PDFs held on a self-hosted paperless-ngx instance into Obsidian notes without storing them locally. Documents on the instance are browsed from inside the vault and inserted one or many at a time; each insertion generates a share link from paperless and embeds it as an external PDF file, so the document can be read as though it were loaded natively. The README requires a working paperless-ngx installation, an API authorization token taken from the user profile, the instance URL without a trailing slash, and the PDF++ plugin, whose external-PDF support the embedding relies on.
