# JeminMau/Obsidian-CodeBlock-Tabs

This plugin groups contiguous code blocks in an Obsidian note into a single tab group. Each block carries options after its language in the info string, and the README's usage example gives every block a title that becomes its tab label, mixing dataview, Python, Java, Go, C++, JavaScript, TypeScript, C, Rust, Swift and HTML blocks in one group. The README otherwise covers contributing and support and documents no further behavior.
