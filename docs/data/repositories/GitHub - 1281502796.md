# yanqingwang/obsidian-html-effectiveness

HTML Effectiveness renders spatial HTML content inside Obsidian notes and opens standalone HTML files, following the separately published html-effectiveness methodology. Inside a note an `html-effect` fenced block renders one of several templates — a two-column comparison, a vertical timeline, an ASCII diagram in a monospaced frame, a KPI report of data cards, and paged slides — for layouts the README argues linear Markdown cannot express. A dedicated viewer opens `.html` files from the explorer, the command palette or by association, rewriting relative image paths into resource URLs Obsidian can resolve, refreshing when the file changes, and permitting scripts through the iframe sandbox; a further command exports the current note as a standalone HTML file. This note is grounded in the README alone, as the repository records no description.
