# yanqingwang/obsidian-html-effectiveness

HTML Effectiveness lets Obsidian render spatial HTML code blocks inside notes and view standalone HTML files with images, styles, and interactive elements. It provides templates for comparisons, timelines, diagrams, KPI reports, and slides, rewrites relative image paths for Obsidian, and refreshes the viewer when files change. A command can also export the current note as standalone HTML.
