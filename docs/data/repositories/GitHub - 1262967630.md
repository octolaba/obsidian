# sandsaber/mdMenu

mdMenu adds a formatting toolbar to the Obsidian editor while the notes underneath stay plain Markdown, with a command registry covering bold, italic, strikethrough, underline, highlight, clear formatting, inline code and code blocks, block quotes, callouts, checkboxes, lists, links and headings. Four placement modes keep the toolbar fixed at the bottom of the workspace, near the selection, near the caret, or wherever it was dragged, and the last three stay inside the viewport in small windows. The toolbar is editable from settings: built-in commands or any command from Obsidian's palette can be added, unused buttons removed, separators inserted, buttons reordered by drag or arrow controls, and the default set restored. The README describes it as a clean-room toolbar inspired by cMenu and records community-plugin submission as in progress.
