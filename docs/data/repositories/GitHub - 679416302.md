# tu2-atmanand/EvilRed-ObsidianTheme

Evil Red is described as a red dark theme for Obsidian, stated in its README as compatible with Obsidian version 1.4.13 and above. The README documents installation from the theme marketplace, or manually by downloading a release zip and extracting it into a folder named EvilRed under the vault's themes directory, with a restart if required. It names Atmanand Gauns as the creator and maintainer.
