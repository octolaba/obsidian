# tu2-atmanand/EvilRed-ObsidianTheme

The README documents installation from the theme marketplace, or manually by downloading a release zip and extracting it into a folder named EvilRed under the vault's themes directory, with a restart if required. It names Atmanand Gauns as the creator and maintainer.
