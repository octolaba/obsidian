# GodlyMan-bit/Serif

Serif is its author's personal Obsidian theme, made because they could not find one that combined a serif font with colors easy on the eyes. It uses Libre Baskerville, with primary and secondary dark colours 282c34 and 3b4251 and primary and secondary light colours f5f5f5 and e0dcc8. The README notes that this is the author's first theme and was created for personal use, and that the Editing Toolbar, Iconize, Pro-Zen and Kanban plugins have been tried and work.
