# l-4553/obsidian-simple-checklist

Simple Checklist collects the unchecked task items of every Markdown file in an Obsidian vault into one side panel. The README states that todos are grouped under their source file, that clicking a group title opens that note and clicking a todo jumps to its line, that sub-todos are indented as they are nested, and that an item can be completed or deleted from the panel itself. It also lists pinning a note group above the rest, dragging a todo into another note with its sub-todos, reading todos written inside callouts with their header preserved, rendering links and inline code within todo text, and priority ordering by trailing exclamation marks. Settings cover the group sort order, restricting the panel to daily-note filenames, hiding future-dated notes, excluding todos by keyword, and rolling open todos forward into today's daily note.
