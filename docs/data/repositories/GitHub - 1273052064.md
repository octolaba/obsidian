# AyWutiansui/obsidian-onenote-integration

Obsidian plugin that embeds and edits OneNote pages inside notes by driving the OneNote desktop application over a local COM interface, with no cloud service and no Azure configuration. It embeds the actual OneNote window rather than a screenshot or a frame, offers a sidebar tree of notebooks, sections and pages plus cascading dropdowns for picking one, can detach and reattach an embed, converts OneNote XML to HTML including text, tables, images and ink strokes, and extracts preview images from handwritten pages. It hides the embedded window when modals, the command palette or hover previews cover it, tracks coordinates on high-DPI and multi-monitor setups, and caches the hierarchy briefly. The README requires Windows with a running OneNote desktop install, limits macOS to sidebar browsing, and records that two helper executables are downloaded on first launch.
