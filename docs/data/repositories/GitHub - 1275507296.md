# epicylon/add-to-vault-plugin

Obsidian half of a two-part system for capturing web articles and comments into a vault, where a separately self-hosted backend does the scraping and language-model processing. The plugin pushes an index of the vault's filenames to that server so the model can generate internal links to concepts already present, and it periodically polls the server's inbox for newly generated Markdown files, downloading them into the vault and deleting them from the server. It requires a bearer token from the server dashboard and an API key or local URL for a model provider, with Google Gemini, OpenAI, Anthropic, Mistral AI, Kimi and Ollama named. The README states that the architecture, backend logic and frontend code were primarily written by Google's Gemini Pro under a human project manager's direction.
