# studiowebux/obsidian-findoc

Opens and edits CSV files inside Obsidian and uses them as the data source for charts and table reports. Line, pie and radar charts are drawn with Chart.js, calculations use mathjs, and the charts are resizable. Models describing how a CSV is read can be added, edited, duplicated and deleted in the settings, and the data processing covers splitting by quarter or week, category analysis and value ranges. The README states desktop and mobile are supported and points to a separate documentation site.
