# avlihachev/obsidian-workout-ai-tracker

Records workouts in the vault as Markdown files carrying frontmatter properties, built from five default templates or custom ones and tracking weight, reps, RPE and heart rate for each set alongside warm-up and cool-down cardio. Built-in tools include a rest timer with countdown and notifications, quick addition of an exercise to the day's workout, and volume, set and duration tracking. The README states that the analysis side calls the Claude API with a key taken from the Anthropic console, covering progress across weights, reps and volume, program recommendations, recovery analysis and imbalance detection.
