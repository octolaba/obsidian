# xuxiaominger/obsidian-web-card

Web Card converts a highlight copied from a web page into a formatted card when it is pasted into an Obsidian note with a dedicated shortcut, detecting the source URL automatically. Selected text already in the editor can be turned into the same card through a command that asks for the source address. The settings panel chooses the card format between a callout quote block, a code-block card and an embedded card, toggles the source marker at the foot of the card, and selects a modern, minimal or classic visual style. The README is written in parallel Chinese and English, both in a heavily colloquial register that this description does not reproduce.
