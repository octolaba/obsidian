# kenanlian/obsidian-card-workspace

This repository holds Card Workspace, an Obsidian plugin that shows the notes of a folder as a stream of cards in the sidebar or in a main editor leaf, filtered by tag, searchable, and opened by clicking a card. Its 1.0.0 release adds a dual-pane sidebar with its own navigation column for folders, tags, boxes and favorites, a draggable divider, a toggle that hides the column, and an automatic fallback to a single pane when the sidebar becomes too narrow. A card box is a saved collection listed in that navigation pane, keeping its own membership rules that combine folder scope and tags with OR, its own sort order and pins, and hand-picked inclusions or exclusions. The README is available in English and Simplified Chinese.
