# jaival-11/lastfm-obsidian-plugin

Sync Last.fm fetches scrobbles, artists, albums and cover art from Last.fm and creates notes whose properties are meant to be consumed directly in Base. Syncing is incremental, pulling only the tracks recorded since the previous run, while dedicated folders collect top artists and albums with their playcounts and cover images and scrobbled tracks are linked back into the matching artist and album notes. The README records a manual UTC offset that bypasses the system clock so scrobble dates stay accurate, and a command that recalculates the local timestamps of existing track files without calling the API again; a free Last.fm API key is required.
