# pinei/obsidian-consolas-theme

pinei/obsidian-consolas-theme records no repository description; its README presents the theme as a dark one for Obsidian, built around an embedded TrueType font chosen to evoke the look of Visual Studio Code. The listed characteristics are a monospaced face with ligatures, a yellow and purple colour scheme, gradual header shading, and checkboxes modelled on Minimal that the README marks as deprecated in favour of the List Callout plugin. It also claims compatibility with the Git, Calendar, Quiet Outline and Kanban plugins, and documents manual setup by cloning the repository into a vault's themes folder.
