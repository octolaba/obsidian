# linjunpop/obsidian-gist

The repository holds a plugin that renders GitHub gists inside Obsidian notes. Its README records a gist fenced code block that accepts a bare gist identifier, an owner and identifier pair, or either form followed by a file name to show a single file from the gist. Installation is documented from the community plugin listing in the Obsidian settings and by copying a release into the vault's plugin folder.
