# Heiss/obsidian-linkwarden

Linkwarden for Obsidian is described as showing Linkwarden highlights beside notes, linking and archiving URLs, and inserting highlights as quotes. The README states that the plugin is not part of the Linkwarden project, and that its principle is to read in Linkwarden and write in Obsidian: there is no sync engine, and a note is bound to a saved link by a single Markdown link whose target carries the instance deep URL and entry id. A right-hand panel follows the active note, lists each linked source's highlights with text, comment and colour from a cache that works offline, and offers an insert-as-quote action that writes a callout with a referenceable block id, mapping highlight colours to callout types and tags. Further commands search the library, archive a URL that is not yet saved, and export a note's links.
