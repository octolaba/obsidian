# james-tindal/obsidian-mindmap-nextgen

The repository holds Mindmap NextGen, an Obsidian plugin that views notes as mind maps rendered with Markmap. Its README records a more-options menu carrying pin and unpin, copy screenshot, collapse all and a toolbar toggle, and further behaviour for checkboxes, LaTeX, syntax highlighting and per-node styling and folding. Settings cover colouring approaches, line thickness, highlighting of inline markmaps, using the note title as the root node, and the underlying library's own options, with frontmatter able to override them per note.
