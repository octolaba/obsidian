# 5tukgpt/thunderegg

Thunderegg converts vault attachments such as PDF, Word, Excel, PowerPoint, email, images, and recordings into Markdown with YAML frontmatter on macOS using an on-device engine. Its optional Refinery tracks note grades, wikilink bonds, and hub-note condensers, while recordings become structured meeting summaries and converted files are written beside their sources.
