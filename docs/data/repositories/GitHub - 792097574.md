# ConnorEspino/ObsidianSelectWord

Obsidian Select Word selects the word closest to the text editor's caret. The plugin ships no default hotkey; the README explains that one is assigned from the Hotkeys panel in the settings dialog or from the plus icon beside the plugin's switch in the Community Plugins panel. Its open issues, as recorded in the README, are that the plugin does not work on title text and that an option to select a whole hyperlink rather than a word inside it might be useful.
