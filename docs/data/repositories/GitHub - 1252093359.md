# imhlq/obsidian-runescribe

Counts English and CJK writing units for the active note, a folder chosen from the file menu, or the whole vault, reporting the two scripts separately alongside a combined total. A sidebar dashboard shows the statistics for the active file, active folder or vault, together with frequency tables for English words and CJK terms that can be exported as CSV. Handling of frontmatter, code, tags, numbers, wikilinks, CJK locale and reading speed is configurable, text is cleaned in a Markdown-aware way before counting, and a per-file cache speeds up repeated folder and vault counts.
