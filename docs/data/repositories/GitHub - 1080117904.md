# evancleve/obsidian-connections

Obsidian plugin for defining and viewing named connections between notes. The README describes a command that opens a modal for choosing a connection type and a target note, a Connections pane in the right sidebar listing every connection, and a trash icon for removing one. Mapped connection types reuse existing frontmatter properties, such as a spouse property rendered as the phrase is married to, and a mapped type can take its subject from the target instead of the source.
