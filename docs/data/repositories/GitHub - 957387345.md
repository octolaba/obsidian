# Yeban8090/book-smith

Book Smith is a writing-management plugin for organising book projects inside Obsidian. The README describes managing several book projects with custom templates and covers, a tree view of chapters with drag reordering and status marks, writing statistics covering live word count, daily output and goal completion, a focus mode built on the Pomodoro technique with configurable work and break lengths, citation management with automatic numbering and bibliography generation, and export in several formats. The interface is offered in Simplified Chinese and English, and the README claims desktop and mobile support. The repository description and most of the README are in Chinese; this summary restates what they describe.
