# Zachatoo/obsidian-inbox

Shows an in-app notification on startup when there is content to process in a designated inbox note or folder, which the README frames as the landing place for content written by a third-party tool without opening the vault. Settings choose whether the inbox is a single file or a folder of files, its path, and how long the notice is shown. The comparison is made either against a snapshot taken when Obsidian last closed or against base contents defined by the user, so an unprocessed inbox matching that baseline raises no notice.
