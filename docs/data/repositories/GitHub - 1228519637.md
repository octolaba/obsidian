# spenhos/obsidian-diacritics-free-search

Diacritics-Free Search makes diacritical marks transparent while searching and replacing in Obsidian, so a query typed without marks finds the text that carries them. The README names Hebrew nikud, Arabic tashkil, Latin accents, Greek polytonic and any Unicode combining mark, giving unvocalized Hebrew and an unaccented spelling of a French loanword as its examples. A local search bar opens at the top of the active note with real-time highlighting of every match, navigation by buttons or the Enter key, clickable scrollbar markers, replace one and replace all, a case sensitivity toggle and recall of the last query, and a global search section follows it.
