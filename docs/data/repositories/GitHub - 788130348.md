# zigahertz/obsidian-hash

This repository holds a plugin described upstream as inserting a cryptographically strong pseudorandom hash into Obsidian notes. The README says the value comes from Node's crypto random bytes function and suggests it as a source of unique identifiers, exposed through a single Generate hash command reachable from the command palette or a ribbon button. A hash size setting gives the number of bytes to generate, bounded between one and just under two billion, and defaulting to six.
