# davidvkimball/obsidian-ui-tweaker

UI Tweaker gives Obsidian interface elements three visibility states, always shown, always hidden, or hidden until hover or interaction. The README lists the title bar, navigation headers, tab headers, ribbon, vault switcher, help and settings buttons, tab bar and its per-button controls, tab icons, status bar, scroll bars, sidebar toggles, tooltips, search suggestions and counts, and the properties block in reading view among the elements it governs, together with mobile chevrons, navigation buttons and menu button positions. It can also add custom command buttons to the file explorer, the tab bar and the status bar, each with its own icon, color, name, toggle-icon behaviour and device filter, and it can reorder or restyle the native explorer and status bar items. The plugin describes itself as part of the separate Vault CMS project.
