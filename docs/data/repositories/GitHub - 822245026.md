# jvsteiner/obsidian-latex-render

Latex Render is described as a plugin that renders latex code blocks to SVG for viewing in notes, with the reader expected to supply the command. Its README says the plugin runs a user-configured command that must turn a .tex file into an .svg file, substituting the absolute path of the temporary file into the command string, and it gives worked examples built from latex and dvisvgm, including the font-format option needed because Obsidian does not support the font tags dvisvgm emits by default and an environment variable for machines that cannot find the ghostscript library. The README states that the project is a fork of an earlier latex-render plugin that was never published to the community plugins page, that the author added features and intends to submit it, and that maintenance would be handed back on request.
