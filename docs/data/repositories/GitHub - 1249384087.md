# evolutiontrash/draw_integration

Draw integration drives an external drawing application from Obsidian through shell commands, using an ordinary image embed rather than any new syntax: an embed pointing at an image that does not yet exist is turned into a project file, opened in the configured application and exported, currently to PNG only. Separate create, open and export commands run the steps individually, and a combined command runs all of them one after another with the cursor on the image link line. The README states the image path is relative to the vault and the folder is created automatically, offers Krita and MyPaint as starting examples, and warns that on Linux a Flatpak installation may not work because Flatpak does not allow apps to run code on the host machine. The repository records itself as a mirror of the project's Codeberg home.
