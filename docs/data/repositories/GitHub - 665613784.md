# diegoeis/simple-obsidian

Simple is a theme for Obsidian that prioritizes reading and writing, with minimal customizations and a design meant to avoid distraction and noise while taking notes or writing long-form texts. It offers dark and light versions plus a third option in which only the sidebar is dark, switchable through Style Settings. Typography can be set to Inter, IBM Plex or iA Writer Quattro, and further options are exposed through the Style Settings plugin, among them the editor layout order.
