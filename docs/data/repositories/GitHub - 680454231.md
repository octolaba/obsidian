# Medill-East/obsidian-content-linker

Content Linker searches a vault for text that repeats across notes but is not yet wrapped in double brackets, and offers those repeated strings as candidate bi-directional links. Candidates are listed in the settings panel with their occurrence counts and a configurable result count, selected entries can be rewritten into link form in place, moved to an ignore list, restored from it, or converted back from link form to plain text, and a relative path can be excluded from the search and from any modification. The README states that more than 95% of the code was produced with codeGPT, that the plugin was only self-tested and may not be updated, and it advises backing the vault up first; its documentation is mainly in Chinese.
