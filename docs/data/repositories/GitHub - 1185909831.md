# Lemon695/obsidian-enhancement-suite

Enhancement Suite bundles several independent modules into one plugin, each switched on or off in its settings panel, with the interface following Obsidian's English or Simplified Chinese language setting. The README groups them into table sorting and row filtering; frontmatter work such as live YAML validation, a field summary, a tree viewer for object and array properties and batch property editing across notes; export to clean Markdown, to standalone HTML with optionally Base64-embedded images, or through Obsidian's built-in PDF export; and a find-and-replace dialog with case-sensitive and regex toggles, previewed matches and cross-file replace. It also describes a dual tree and source view for .json files with validation and formatting.
