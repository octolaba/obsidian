# Lavton/obsidian-ignore-filter-shortcut

Edits Obsidian's excluded-files list by clicking a folder instead of opening the settings, adding that folder to the list or removing it. With folder-tree awareness enabled, removing a folder whose parent is excluded rewrites the list by dropping the parent and adding its siblings, and one action excludes everything except a chosen folder. A default ignore list is kept in the plugin settings, with commands to restore it, to add the current exclusions to it, and to apply it to the vault; the README states that the plugin works with folders, not files.
