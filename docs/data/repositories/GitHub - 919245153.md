# laughmaker/Zen

Zen is a modern Obsidian theme written for focused writing, removing elements its bilingual README calls redundant and making heavy use of Gaussian blur, with specific attention to Chinese users. The README records that the blur effect on macOS requires the translucent option in the appearance settings, while on Windows, where the application removed that option, the effect is approximated with an image embedded in the code that can be replaced through Style Settings. Listed characteristics include whitespace instead of dividing lines, colored heading levels with numbering hints, aligned indentation guides for lists, colored tab underlines, adjusted letter and line spacing, and mobile behaviour kept close to desktop, alongside a list of optimized plugins and a recommended font.
