# mattbirchler/ghosty-posty-obsidian

Publishes the current note to a Ghost blog from one command, converting Obsidian markdown to Ghost-compatible HTML, uploading local images and rewriting their references, and converting wiki links to plain text. A confirmation modal allows the title, tags and status to be edited first, with draft, published or scheduled status, a future publish time and a featured toggle; frontmatter keys can set title, slug, tags, status and publish date, and a first-line image becomes the featured image. Notes can optionally be moved to an archive folder after a successful publish, with a timestamp appended on a name collision. The README records support for Obsidian on desktop and mobile and describes unit tests covering the conversion pipeline.
