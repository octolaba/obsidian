# michaelwelch/obsidian-hoist

This plugin lets a list item carry a small template that pulls values out of its own child bullets, so a folded parent line reads as a summary instead of just a name. Placeholders in the parent text are filled from nested key-value bullets beneath it, written as dot-paths that may skip intervening levels or match a bare key anywhere in the subtree, up to fifty levels deep. The resolved summary appears inline in Live Preview, reverting to the raw template on the line holding the cursor, and in Reading view it appears when the item is collapsed and reverts when expanded. Any node with children can carry a template, and the values stay ordinary outline bullets rather than frontmatter or a separate metadata block.
