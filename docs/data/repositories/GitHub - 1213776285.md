# vilstr17/cortex

This repository holds Chronote, an Obsidian plugin that turns existing notes into a spaced-repetition study system. A note is scored from one to five on review and the next review is scheduled automatically, with the review state kept in the note's own frontmatter; related notes can be grouped into a test with preparation progress and per-note exam dates. An assistant generates flashcards or a quiz from a note, indexes the vault locally so it can search it, and suggests study blocks from what is due and what is already scheduled. The README states that Chronote reads and writes Google Calendar from inside Obsidian and that the user picks the model, either a free local one or their own API key.
