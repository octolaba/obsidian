# WallaceWyslas/obsidian-checkbox-progress

Checkbox Progress counts the checkboxes in the active note and reports completion in the status bar beside the word and character counts, as a completed-over-total figure with a percentage. It also puts a progress bar and a reset button in the view header on desktop and mobile, where the reset clears the completed checkboxes in the note. Open, done, cancelled and in-progress checkbox states are recognised, checkboxes inside code blocks and YAML frontmatter are ignored, and the counter hides itself in notes that have none. The count refreshes on file open, tab switching and file modification, the last debounced by 300 milliseconds.
