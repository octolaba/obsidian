# qaptoR/Commando

Commando repeats an Obsidian command for a chosen number of loop iterations, so a command that would otherwise be invoked by hand many times — the README's example is moving a table row up twenty times with the Advanced Tables plugin — is called once with a repeat count. The README positions it beside the Commander plugin, which creates command macros, and states that macros were dropped from Commando's own scope. Its disclaimer says that not every command should be run this way, that the effect of running a command hundreds of times in rapid succession should be thought through first, and that the vault should be under version control before using it for anything that changes or removes files.
