# k0src/Floating-Headings-Obsidian-Plugin

Floating Headings displays a floating, collapsible outline of a note's headings on the side of the Obsidian editor, collapsed to indicator lines that expand on hover and navigate to a heading on click. The README describes a filter search over headings, collapsible heading groups, left or right placement with adjustable vertical position, and level filtering from H1 to H6. Heading text can be cleaned by stripping HTML tags or extracted with a custom regex pattern using a heading_text named capture group, and appearance settings control panel width, height, line thickness and animation duration.
