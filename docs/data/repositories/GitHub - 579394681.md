# Sergei-Korneev/obsidian-local-images-plus

The repository holds Local Images Plus, an Obsidian plugin that brings media referenced by a note into the vault, presented as a successor to an earlier local images plugin. Its README records downloading media from pasted web content and from word processor documents, downloading arbitrary file types and files embedded in Markdown tags, and saving base64 embedded images as files. It also records saving attachments beside their note in a folder named after it, converting PNG images to JPEG at a chosen quality, deduplicating attachments by MD5 hash, and removing orphaned attachments, and it states that the author is not obliged to provide support and assumes no liability.
