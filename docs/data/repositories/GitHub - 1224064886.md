# TaylorChen/obsidian-press

Press PDF Export converts Obsidian Markdown into Pandoc-compatible Markdown and then exports a note to PDF, Word or HTML. PDF can be produced through XeLaTeX, pdfLaTeX, LuaLaTeX, wkhtmltopdf, WeasyPrint or Typst; Mermaid blocks are pre-rendered to SVG through the Mermaid CLI, custom CSS and Pandoc templates control styling, six code-highlighting themes are built in, and Chinese, Japanese and Korean fonts are detected automatically for the LaTeX engines. A batch mode exports the current folder or the whole vault with concurrency control, and images, formulas, tables, callouts, wikilinks, embeds and highlights are carried across. The README states that the plugin is desktop-only because it calls these local command-line tools, and records Pandoc as required for every export format.
