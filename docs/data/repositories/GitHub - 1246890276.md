# rafaelmehdiyev/obsidian-clean-copy

Obsidian plugin that copies a note to the clipboard with vault-specific syntax removed. The README states that it strips the frontmatter block, turns wikilinks into plain text, removes inline tags and block-id anchors, and cleans up callout syntax, with an optional pass, off by default, that also strips Markdown formatting such as bold, italic and headings. A selection is copied when one exists and otherwise the whole note, from a ribbon icon or from the two commands the plugin adds.
