# ibrh96-prog/obsidian-highlights-synthesizer

Highlight Inbox Synthesizer is an Obsidian plugin that reads a folder of saved highlights and writes one synthesis note. The README records a per-source summary with key claims and topics, and cross-source themes covering topics shared by two or more sources together with the consensus and any tension between them, written to a note at the vault root and opened. Sources are identified by a configurable folder or tag, and callout highlights, block-id highlights, bullet lists and plain notes are all parsed; a sync command extracts per-source material incrementally so unchanged sources are skipped, and a second command generates the report. The README records the model provider as configurable between Anthropic, OpenAI, OpenRouter or a custom endpoint with the user's own API key, and a free tier limited to three lifetime syncs with a one-time licence removing the limit.
