# HanTae-ho/obsidian-our-kyobo-book-search

This plugin searches book information from the Kyobo bookstore and generates reading notes in Obsidian from it. Its README, written in Korean, states that it queries the store's JSON data directly for accurate fields, separates authors from translators into distinct note properties, and renders the book introduction and table of contents without the advertising banners. It also records logic that avoids duplicate folder creation when folder names contain spaces, and documents manual installation from the release files as well as installation through BRAT.
