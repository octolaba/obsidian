# hunter-ji/obsidian-easy-tracker

Easy Tracker inserts goal and habit tracking modules into a single Obsidian note and records daily check-ins by clicking a button. The README describes four modules — a daily overview with streak and last missed day, a year calendar heatmap, editable check-in buttons and a goal card — added together by one command or individually, and states that all data is stored as plain text inside the note. Settings cover the week start day, and the interface is available in English and Simplified Chinese.
