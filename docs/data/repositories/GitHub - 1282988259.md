# crufi/obsidian-marco-polo

No repository description is recorded, so this body is grounded in the README alone. Marco Polo validates a filesystem path typed inside backticks as it is written, autocompletes it, and turns a valid path into a clickable link that opens or reveals the target in the file manager. The README records expansion of the home directory and of optional shell variables, a configurable colour for valid paths with bad ones shown in red, an insert command with a drill-down picker, and per-link suffixes that override the default open or reveal action. It states that the plugin is desktop only because it uses Node and Electron APIs, and that it never reads file contents or writes anything.
