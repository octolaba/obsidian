# aidenlx/table-extended

Table Extended brings MultiMarkdown table syntax to Obsidian, which the README motivates by noting that the built-in syntax covers only basic tables and leaves raw HTML as the only way to write column spans or multiple headers. The added syntax supports cells spanning columns, cells spanning rows, block-level content such as lists and code inside cells, multiple table headers, a table caption and an omitted header, while internal links and embeds keep working. Recorded known issues include incompatibility with Advanced Tables, whose auto-formatting breaks the syntax, and an escaping problem in one of the extended forms.
