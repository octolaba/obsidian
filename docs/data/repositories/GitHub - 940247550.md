# lhinxue/obsidian-inline-code-copy-plugin

The README describes an Obsidian plugin that copies the content of an inline code span with a single click in reading view. Its author gives the motivation as keeping credentials and account details in Obsidian, where selecting the text and pressing Ctrl and C is less convenient than one click, and credits an earlier plugin as the inspiration. The rest of the README covers building the plugin from source and copying the built files manually into the vault's plugins folder.
