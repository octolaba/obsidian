# grumpydev/octosync

Obsidian plugin that syncs a vault with a GitHub repository through the GitHub API, so no local Git install is needed: the device needs only Obsidian, the plugin and a token with access to the chosen repository. Sync runs manually from the ribbon icon, the command palette or settings, optionally waiting for approval of the prepared plan, or automatically at startup, on an interval, or both. A simulate command builds the same plan and reports what would happen without touching local files, GitHub or its own metadata, the Obsidian configuration folder is excluded by default, and conflicts stop for a user decision instead of overwriting notes. The toolbar icon can indicate that pending local changes were seen.
