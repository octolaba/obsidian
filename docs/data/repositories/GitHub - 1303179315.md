# kazantsev-v/obsidian-jenn-bridge

The README describes an Obsidian plugin that acts as a WebSocket endpoint for Jenn Core, serving as an output destination in Jenn's data routing system. Over that connection it creates Markdown notes with a title, content, tags and folder, appends content to existing notes under an optional section heading, runs full-text search across the vault, and lists files, folders and the vault tree. A colour-coded dot in the status bar reports whether the connection is established, connecting or down, and the plugin reconnects automatically with exponential backoff; setup asks for the server URL from the Jenn output configuration and an API key copied from the Jenn config. The README is written twice, in English and Russian.
