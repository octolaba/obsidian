# lstrzepek/obsidian-yt-transcript

This plugin pulls the transcript of a YouTube video into Obsidian in two ways. An Insert YouTube transcript command writes the transcript at the cursor with clickable timestamps, taking the video URL from the current selection, the system clipboard or manual input after a confirmation prompt, and the README describes that path as suited to mobile. The classic desktop workflow instead opens the transcript of a selected link in a side panel, where a setting controls how often a timestamp appears, clicking a timestamp opens the video at that point, a context menu copies everything, and lines or timestamp links can be dragged into a note.
