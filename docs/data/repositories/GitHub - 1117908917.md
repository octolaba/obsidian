# poanse/obsidian-taskmap

Obsidian Taskmap plans projects as interactive task trees with an automatic layout, so tasks do not have to be positioned by hand. Nodes are color-coded by status, a parent's status is derived from its children, and branches can be temporarily hidden to navigate a large tree. Tasks can be linked to Obsidian notes for a fuller description, and a blocker system expresses dependencies between tasks that are not in the same branch. The README contrasts this with large Kanban boards, arguing the tree shows blocked areas, progress and dependency flow at a glance.
