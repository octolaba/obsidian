# qkm2000/Scuttlebutt

Scuttlebutt is a meeting companion in the Obsidian sidebar that records microphone audio, optionally mixing in system audio, or imports an existing clip from the vault or from disk, then transcribes it and summarises it against endpoints the user configures. Transcription goes to any OpenAI-compatible speech endpoint such as a vLLM Whisper or whisper.cpp server and can be repeated from the Transcript tab, while summarisation goes to any OpenAI-compatible chat endpoint and can be steered by context files picked from the vault. Summary, Transcript and Memo are reviewed side by side before one note is saved with a generated title and tags, and recording shows a live timer, an in-sidebar player and a status-bar indicator. The README describes the plugin as local-first, running against configured endpoints with no cloud and no accounts.
