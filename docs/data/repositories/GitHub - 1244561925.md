# Obsidian-TTRPG-Community/Randomness

Provides dice rolls, rollable tables and full random generators for Obsidian, aimed at tabletop games and creative writing. Inline `dice:` expressions roll in a sentence, any named Markdown table becomes rollable through an `rdm:` reference, and every result offers a re-roll control and a lock control that writes the chosen result into the note so it survives reloads and sync. Underneath sits a generator engine using the Inspiration Pad Pro format, so existing community tables load unchanged. The README states that this plugin has absorbed the separate Dice Roller plugin and that its dice, table and tag rolls keep working, with a migration guide provided.
