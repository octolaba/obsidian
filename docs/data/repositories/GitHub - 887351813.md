# jamiefdhurst/obsidian-inbox-organiser

Collects new and unorganised notes saved into the root of the vault into an inbox folder and provides an interface for moving them into other folders. A periodic notice reminds the user to clear the inbox. Settings control whether newly created root files are moved automatically, whether the reminder is shown, which folder serves as the inbox, and which folder is watched for new items, defaulting to the vault root.
