# ViscousPot/draggable-list-items

Repository for Draggable List Items, an Obsidian plugin that reorders list items by dragging, in reading view and live preview and on desktop and mobile. Tasks, bullets and ordered lists form separate drag groups so an item cannot cross between them, nested children move with their parent, and ordered lists renumber on drop; a handle appears on hover, a ghost preview follows the cursor, a drop indicator shows where the item lands, and Escape cancels a drag in progress. Settings show or hide the handles and allow dragging between groups at the same indent and between files in different editor panes, the latter in live preview only, while source mode is stated as unsupported.
