# DonnervS/obsidian-todo-done-mover

To-Do to Done Mover moves completed checkbox tasks, together with their indented sub-tasks, into a Done heading in the same note. The actions are available from the editor context menu and as commands, one moving every fully completed task and one moving only the task blocks touched by the current selection, and an optional automatic mode moves a task as soon as it and all of its sub-tasks are checked, staying inactive in configured folders and files. Indentation is preserved, a completion date can be appended to each moved line without duplicating an existing one, and the heading is created at the end of the note when it does not exist. The README states that the plugin works offline, makes no network requests, collects no telemetry, and modifies only the note in which a move runs.
