# LubrieDev/lmath

LMath graphs functions, systems of equations, derivatives and integrals inside Obsidian notes: a block shows the formula rendered with KaTeX beside an interactive Cartesian plane offering pan, zoom, a crosshair reading x and f(x) under the cursor, and a rail mode that walks the curve by arc length. Separate block types cover one explicit, implicit, parametric or polar curve; a system of equations with each curve coloured and the intersections marked; the symbolic derivative of a function; a definite integral with the region shaded and the signed area given; and the unit circle with exact values for the angles entered. The README says the engine traces curves by arc length rather than sampling a pixel-bound grid, so bounded curves neither deform nor vanish when zoomed out.
