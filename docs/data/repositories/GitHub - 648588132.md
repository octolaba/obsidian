# halo-sigs/obsidian-halo

This plugin publishes Obsidian documents to Halo. A site is configured in the plugin settings with a name, a site URL and a personal access token carrying the Post Manage permission, and one site can be marked as the default. Commands publish the current note to a chosen or to the default site, upload local images and replace them with remote URLs, pull posts from Halo into Obsidian, and update the current note's content from Halo. The README credits obsidian-wordpress as the origin of the idea.
