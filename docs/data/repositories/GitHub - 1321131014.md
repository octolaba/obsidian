# vuecwiz/obsidian-border-theme-compacted

Border Theme Compacted is a desktop-only companion for the Border theme that applies a compact workspace layout without a CSS snippet: outer spacing drops from about 16px to 4px, the title bar uses a 36px grid with 32px tabs and buttons, and native window controls are aligned to it on Windows and macOS. A 24px status-bar button opens a scrollable pop-up menu of the currently available ribbon actions on left-click and shows or hides Obsidian's own ribbon on right-click. Every interface override is scoped to a class the plugin adds only while the active theme reports as Border, so selecting another theme removes the class, closes the menu, hides the button and restores that theme's own layout.
