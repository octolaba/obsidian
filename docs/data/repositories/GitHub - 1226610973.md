# JohnMcAnearney/bulk-image-to-file-importer

This plugin imports images into an Obsidian vault in bulk, either as one file per image with or without a template, or appended to an existing file. Images are chosen by dragging them onto a drop area or through a file selector, then reviewed and individually removed before import, with compression among the options. An image whose name already exists in the vault is not uploaded again but referenced as expected. The README's stated use cases are adding trip photos to a trip note and cataloguing clothes as individual notes with their metadata.
