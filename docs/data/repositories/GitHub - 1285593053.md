# WayinVideo/WayinVideo-Obsidian-Plugin

This plugin creates Obsidian notes holding video summaries or speaker-labeled transcripts through the WayinVideo service. A video or audio link is pasted and an output language chosen, and a new note is created and opened carrying the title, the source link, a YouTube embed when available, and either an overview with tags, highlights and clickable timestamps or a colour-coded speaker-labeled transcript. The README records Obsidian 1.5.0 or later and a WayinVideo API key as requirements, and lists YouTube, TikTok, Vimeo, Twitch, Instagram, Facebook, Zoom, Rumble and Google Drive among the supported sources.
