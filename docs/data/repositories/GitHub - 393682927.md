# Chrismettal/Obsidian-Behave-dark

Behave dark is an Obsidian port of Christian Petersen's Behave theme, and as its name says only dark mode is supported. Its README notes that Behave also exists for FreeCAD and KiCAD, so the same colours can be carried across those applications. Installation is documented through Obsidian's community themes browser, while the earlier manual route of renaming obsidian.css into the vault themes folder is struck through in the README as superseded.
