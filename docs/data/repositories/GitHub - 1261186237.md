# realfash/obsidian-shiju

Shiju is a mobile-first quick-capture plugin for Obsidian whose name the README glosses as picking up a line: a thought that appears on a phone is written down first and organised later. It opens a large capture panel suited to a phone screen and appends what is typed to today's daily note, optionally under a named heading such as an inbox section, creating the note from a vault-relative path template and, if configured, from a template note when it does not yet exist. The panel carries a small Markdown toolbar for headings, bold text, bullet and numbered lists and tags. The README is written in parallel Chinese and English, and this body summarises rather than quotes the Chinese half.
