# Psyda/obsidian-text-color-tags

Text Color Tags colors inline text in Obsidian notes with a short dollar-prefixed marker naming either one of eleven named colors or a hex value. Clicking colored text reveals the marker and a swatch for editing, clicking away hides the marker again, and clicking the swatch opens a color picker; a context-menu entry adds a color at the cursor or wraps the current selection. The settings hold eight quick-access vault swatches and eight recently used colors that are tracked automatically.
