# iamjjanga-ouo/obsidian-link

Converts the `obsidian://` URI of the active file into an HTTPS URL that redirects back into the vault, and copies it to the clipboard. The stated reason is that platforms such as Slack, Notion and web forums block or fail to recognise the custom URI scheme. The redirect domain is configurable, URL encoding of vault and file names is handled, and the command works on desktop and mobile with a toast confirming the copy.
