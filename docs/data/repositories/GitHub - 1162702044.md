# dsebastien/obsidian-cli-rest

Obsidian plugin that exposes Obsidian CLI commands as a local HTTP API and an MCP server, so scripts, tools and AI assistants can drive the vault. The README states that it is localhost-only by default, with API key authentication and granular per-command controls, and that it needs the Obsidian desktop app from version 1.4.0, with the command line interface enabled in settings.
