# nickolay-kondratyev/obsidian-foldable-embedded-notes

Makes note embeds foldable in reading mode and Live Preview by giving each embed a clickable title bar with a rotating chevron. A trailing dash immediately after the closing brackets marks an embed as folded by default; in reading mode it counts as a marker only when followed by whitespace or the end of the line, and the marker itself is not rendered. A single setting starts every embed collapsed, applying at the next render rather than to already-open panes. Fold state is kept per mode for the current session and resets when Obsidian restarts.
