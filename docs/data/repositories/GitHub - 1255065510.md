# HolyHooly/routine-streaks

Tracks routine streaks from plain Markdown checkboxes in daily notes, which stay the source of truth, and exports the resulting data in a widget-ready form. It also generates Scriptable code so the streaks can be shown on an iOS or iPadOS home screen.
