# Netajam/header-adjuster

Header Adjuster increases or decreases the levels of headers in a Markdown document by a specified number of levels, either across the whole document or within a range of lines. The increase and decrease commands open a modal asking for the number of levels and, optionally, a start and end line, while separate default commands apply the numbers configured in the settings. A ribbon icon opens a context menu carrying the same increase and decrease options.
