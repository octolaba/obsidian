# udus122/checkbox-time-tracker

Inserts a timestamp into a task line when its checkbox is checked. The README states the default format is hours and minutes, that a start and end range can be recorded by enabling a doing status, and that a date can be included in the format as well. Time tracking is switched on per note: the README says a CSS class, named in the settings, is added to the note's cssclasses property, and from then on checking a box on that page writes the timestamp.
