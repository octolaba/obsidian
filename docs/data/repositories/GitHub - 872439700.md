# Danitiate/check-and-delete

Deletes a completed list item at the press of a button, aimed at checklists whose finished entries would otherwise be removed by hand, which the README notes is particularly tedious on mobile. The README states that the plugin works on list items written in its own completed form, a list marker followed by a lower-case or upper-case x in parentheses, and that pressing the button then removes the item.
