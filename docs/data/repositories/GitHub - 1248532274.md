# wesswart77/obsidian-world-builder

A world-building toolkit for fiction, keeping characters, locations, factions, lore entries and timeline events as notes in a configurable world folder. Characters record role, age, faction, physical description, personality, goals and secrets; locations record type, parent location, inhabitants and secrets; factions record alignment, goals, enemies and allies; lore entries carry a category such as history, religion or culture; and timeline events carry a date or era with linked characters and locations. A tabbed sidebar view spans all five entry types.
