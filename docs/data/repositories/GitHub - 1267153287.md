# aisatsanz/obsidian-pokemon-pet

Pokemon Pet adds a collectible pixel Pokemon companion to the Obsidian workspace. The active Pokemon wanders along the bottom of the window, hops briefly onto text or images and reacts to typing, with canvas-rendered frames for idle, walking, travel and typing; wild Pokemon appear at rates weighted by rarity, are caught with a Pokeball animation, and repeat encounters can evolve one already collected. Pikachu is unlocked by default out of more than seventy forms, and a pet menu covers size, collection, a wiki link and hiding the pet, alongside Pomodoro timer presets whose completion is announced by the pet. The README states that a small bundled roster keeps it working offline, that enabling remote data fetches from PokeAPI with sprites from Pokemon Showdown using only identifiers and sprite URLs, and that the plugin is unofficial and unaffiliated with the Pokemon rights holders.
