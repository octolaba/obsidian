# Demigoddd/obsidian-conflict-manager

Obsidian plugin for resolving sync conflict files without leaving the note. The README describes a banner at the top of a note that carries unresolved conflicts, a split-pane diff viewer for comparing the original note with its conflict files, and a status bar indicator for the vault's conflict state. It also supplies CSS a reader can adapt to recolor the inserted and deleted rows.
