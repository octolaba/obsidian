# orjanhesjedal/cursor-timestamp

The repository holds Cursor Timestamp, an Obsidian plugin that inserts a timezone-aware date and time stamp at the cursor from a hotkey, a command or a ribbon button. The format is assembled from an optional time-zone label, the date, any text between date and time, the time to the second, and leading or trailing text naming who made the entry, with a live preview of the result in the settings. The README presents two design goals: pinning one fixed time zone so collaborators in different places record and read the same instant, and prepending a name so a note shows who wrote what and when.
