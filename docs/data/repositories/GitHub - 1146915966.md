# kquinsland/obsidian-plugin-dictionary-sync

Synchronizes the Obsidian spell check dictionary with a note inside the vault. The README explains the motivation: user dictionary words are stored in the Electron application's data directory rather than in the vault, so tools that sync only vault contents cannot carry them between devices, and the author's earlier external scripts had to be run manually and wrote the custom dictionary file without the framework being aware. This plugin instead uses the APIs Obsidian exposes to plugins to read and write the dictionary natively. The README also states the code was AI-generated and advises making backups before use.
