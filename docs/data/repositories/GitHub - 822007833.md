# ketd/obsidian-sync-DB-OS

This plugin synchronises an Obsidian vault through a database while keeping large files in object storage, a split its Chinese README explains as storing only text in the database and recording a large file there by hash, so that a change to a file of the same name can be detected. Pasting an image into a note uploads it to the configured object storage and rewrites the link, already inserted local image links can be converted to hosted addresses, and files such as PDFs go to the object store instead of the database. The README records MongoDB and CouchDB as the supported databases with only CouchDB covering mobile, two Chinese cloud providers as object storage with differing capabilities, a manual comparison dialog for choosing the correct version when a note was edited on several devices, and installation by cloning and building the repository.
