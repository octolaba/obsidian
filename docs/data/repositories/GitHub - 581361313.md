# artisticat1/nl-syntax-highlighting

Natural Language Syntax Highlighting is an Obsidian plugin that colours adjectives, nouns, adverbs, verbs and conjunctions in the editor, an effect the README credits to iA Writer. The colours are configurable in the plugin settings, and a command toggles the highlighting on or off at any time from the command palette. Parts of speech are detected with the compromise natural language processing library.
