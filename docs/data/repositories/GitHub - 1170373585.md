# TommyRoy776/obsidian-canvas-parent-nodes

This repository holds an Obsidian plugin that lists all parent nodes of the current Canvas node in the right sidebar. Clicking one of the listed titles navigates to that parent node, and the settings control how long a displayed node title may be. The README is brief, adding only a video demonstration and a personal note from the author.
