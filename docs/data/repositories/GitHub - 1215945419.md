# HKohlhoff/canvas-html-exporter

This repository holds Canvas HTML Exporter, an Obsidian plugin that exports the active canvas file as an interactive HTML page. Two output formats are offered: a package folder holding an index page with copied assets and optional subpages, and a single self-contained HTML document with inline assets and virtual subpages. The export preserves canvas layout, node styling, groups, connection labels, line styles and markers, renders text and Markdown file nodes with Markdown formatting, and rewrites internal links, wiki links, heading links, section embeds and block references. The README states that Obsidian 1.13.0 or later is required and points to a demo vault and a large HTML documentation file inside the repository.
