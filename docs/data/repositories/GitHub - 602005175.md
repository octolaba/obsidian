# tadashi-aikawa/shukuchi

Shukuchi moves the cursor to a nearby link and then opens it, so it behaves like the built-in follow-link command except that no link needs to sit under the cursor. Its selection order is to prefer the nearest link on the same line, depending on options, and otherwise the link closest to the cursor. Commands cover opening a link in place, in a new tab, in a new tab group either vertically or horizontally, and in a new window, plus moving to the next or previous link. The README states that the plugin supports both desktop and mobile and explains that its name is a Japanese term for mythical techniques of rapid movement.
