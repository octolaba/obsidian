# veritas1/eleven-labs-obsidian-plugin

Obsidian plugin that generates text-to-speech audio files from note text using the ElevenLabs API, which requires an ElevenLabs account and an API key entered in the plugin settings. Selected text in edit mode is sent from the context menu or the command palette, and a modal chooses a voice from the account, overrides the voice settings and selects a model, including multilingual output. Generation runs in the background and the finished audio is downloaded into the vault, with a notification when it is ready.
