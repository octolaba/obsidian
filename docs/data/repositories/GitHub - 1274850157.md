# toya-co/obsidian-workspace-clock

Workspace Clock places a clock in Obsidian's left-sidebar header and opens a popup holding a stopwatch, a pomodoro countdown and a monthly calendar wired to daily notes. The popup can drop the current time at the cursor and log elapsed time, with an optional session label, into the daily or active note, and it keeps the last four stopwatch runs as chips that can be loaded back into the timer. The README states that it is styled with Obsidian's own CSS variables rather than hardcoded colors, with an optional accent override taking a custom color or one of six gradient colorways.
