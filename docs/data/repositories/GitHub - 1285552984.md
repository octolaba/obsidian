# MasoudMiM/obsidian-uncertainty-calc

The repository holds Uncertainty Calculator, an Obsidian plugin that propagates measurement uncertainty through a note. Its README describes a calc block in which measured quantities are assigned with their uncertainties and referenced by later formulas, with a running scope so a derived value can use earlier ones, and each line is rendered with its result. Recorded capabilities include tracking correlations, significant figures, expanded uncertainty, an uncertainty budget attributing the share each input contributes, and an optional Monte Carlo propagation of distributions. The README lists several input notations, among them a plus-minus form, a relative percentage, a compact parenthesis notation, and a Type A form computing mean and standard error from repeated readings.
