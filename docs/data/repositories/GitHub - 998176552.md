# JabariD/obsidian-radiance

Radiance is an unofficial Obsidian theme inspired by Raycast's calm, keyboard-first interface. It provides distinct light and dark palettes, a focused command palette, compact controls across major Obsidian views, native macOS system fonts, and no remote fonts or assets.
