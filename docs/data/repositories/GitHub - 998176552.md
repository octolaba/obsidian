# JabariD/obsidian-radiance

Radiance is a modern Obsidian theme inspired by the Raycast macOS application, giving a clean, minimalist interface with a signature red accent colour of d04255 applied consistently. It supports dark and light mode with separate palettes, styles the workspace, sidebars, command palette, buttons, modals, tags and metadata, uses Inter for the interface and SFMono for code blocks, and gives tags a pill shape in both editor and preview modes. The README states that the theme is unofficial and is not affiliated with or endorsed by Raycast.
