# HomeroKemmerich/journalistic-importer

The README describes an Obsidian plugin that imports entries from the Journalistic app into Obsidian. After the plugin is installed from the Obsidian plugin store, the importer icon in the left sidebar is clicked and the Journalistic export file is selected. The imported entries are written into a folder named Journalistic inside the vault. The README also links contributing guidelines and asks for donations, stating that this is not a commercial solution.
