# TYBLHQY/auto-sidebar

An Obsidian plugin that hides the left sidebar off screen and slides it back in when the pointer reaches the window edge, a compact mode the README credits to Zen Browser. The sidebar is positioned absolutely and translated off screen with a CSS transform, a pointer within eight pixels of the left edge brings it back, moving away hides it after a short delay, and mouseleave and blur events catch switches to another window or monitor. A command toggles compact mode, and the mode and sidebar width are remembered across restarts. The stated motivation is giving the editor the full window while keeping one-click access to the file tree.
