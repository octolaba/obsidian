# guoxueziliao/side-comments

Side Comments is a desktop Obsidian plugin that stores annotations outside the note body: selected text can be given a highlight, an underline, a strikethrough or a side comment, and the Markdown source is not modified. The README describes creating annotations in source or reading mode from a floating toolbar, a sidebar for the current document that edits, filters, resolves and jumps to annotations, a cross-note overview, anchor relocation after edits, import, export and health-check tools, and an English and Simplified Chinese interface. Annotation data is kept as local JSON files with one sidecar per Markdown file, and the README states that nothing is uploaded, synced or transmitted. Its limitations record desktop-only Markdown support, no PDF or EPUB annotation, no collaboration, and active 0.x development.
