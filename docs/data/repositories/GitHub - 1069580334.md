# yuhanbo758/obsidian-yuhanbo-voice_assistant

Yuhanbo Voice Assistant is a desktop-only plugin for speech recognition, speech synthesis, wake words and dictation, with optional conversations through a large language model. Microphone audio is transcribed by iFlytek online recognition, selected text or the current note is read aloud by iFlytek online synthesis, and recognized text can be sent to Google Gemini, OpenRouter or iFlytek Spark, with results inserted into the active note and audio or conversation notes optionally saved into the vault. It requires Obsidian 1.7.2 or later, microphone permission and credentials for each service used, which are stored unencrypted in the plugin's data file; wake-word and continuous listening keep the microphone active and make background requests until stopped. Commands are run from the palette, and no default hotkeys are assigned.
