# cloudy-liu/Paperglow-Theme

Paperglow is a collection of custom themes for Markdown editors and note applications, covering Obsidian, Typora and VS Code or Cursor from a single repository. The Chinese README describes an unbleached paper background instead of screen white and a dark mode in warm dark brown rather than terminal black, an editing area floating above the window like a sheet of paper, and a fired-clay orange accent on links, tags and the left rule of blockquotes. Typography is Montserrat across all weights, with Noto Sans SC for Chinese and JetBrains Mono for code, and a lightweight install.py script in the repository root installs the variants.
