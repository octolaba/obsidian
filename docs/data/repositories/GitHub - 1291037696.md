# RealSteelDeal/obsidian-jw-congregation

This plugin imports official convention program files of Jehovah's Witnesses into an Obsidian vault as structured, linked Markdown notes. It reads jwpub files, decrypting and parsing them, and falls back to an RTF-ZIP export when no jwpub is available; the program file's language is detected automatically and the generated notes follow it, while the plugin's own interface can be set separately among the seven supported languages. Each convention becomes a folder, with one subfolder per day for regional conventions, one numbered note per program item, and a per-day overview note carrying the cover image and theme, every item linked to its note, and songs as JW Library deep links. Every item note links back to that overview and ends with a hint naming what follows, and scriptures throughout are clickable JW Library deep links with an in-app Bible-verse popup.
