# jjmaldonis/obsidian-audio-notes

Obsidian plugin for taking notes on podcasts and other audio files while listening to them. An audio note is a callout holding a quote from the audio together with an embedded player that replays that quote, created from a callout-like code block whose one required attribute is the audio filename, local or a link to a file online. The README documents optional start and end times and a playback rate appended to that filename, an optional title and transcript, and generating quotes automatically once a transcript exists, produced by the speech-to-text software it describes.
