# AlexBieg/obsidian-better-command-palette

Obsidian plugin providing an alternative command palette. Its README lists closing the palette with backspace when the input is empty, recently used choices moving to the top, commands pinned in the default palette staying pinned, a built-in quick switcher and tag search reached by typing a prefix character or a hotkey, searching files by tag, macro commands, and hiding less useful commands, files and tags while keeping a shortcut that reveals them again. Files can be opened, and created, from the same input without running a separate command first.
