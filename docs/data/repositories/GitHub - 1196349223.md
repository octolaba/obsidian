# StepanKropachev/obsidian-pm

Project Manager keeps projects and tasks as Markdown files with YAML frontmatter inside the vault and presents them through three views: a sortable, filterable table with inline editing, named saved filters and bulk actions; an interactive Gantt timeline with draggable bars, resizable edges, dependency arrows, diamond milestones, a today line and zoom from day to quarter; and a Kanban board grouped by status where cards are dragged between columns. The recorded feature set covers subtasks, dependencies, milestones, recurring tasks, time tracking, smart scheduling and custom fields, statuses and priorities. The README states that the plugin works offline with no cloud, API calls or accounts.
