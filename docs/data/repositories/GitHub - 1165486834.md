# keithwithAI/reading-highlighter

Highlights selected text while a note is open in Obsidian's reading mode, wrapping the selection with `==` in the underlying Markdown source. The highlight is applied from a floating button that appears on selection, from the command palette, or from a ribbon icon on mobile, and multi-paragraph selections, formatted text and links are handled with existing formatting preserved. A floating undo button and a command remove the most recent highlight, and the button stays until it is clicked, the note changes, or the plugin is disabled.
