# j-palindrome/obsidian-link-tree

Link Tree is described as a sidebar foldable list of Obsidian link hierarchies. Its README says the view shows the current note's links and backlinks as a recursively expandable outline in the manner of WorkFlowy or Dynalist, with circular links filtered out of the hierarchy. Bullets expand or collapse a node, arrow buttons toggle forward and backward links, a search box filters by pathname, and a further control shows a single line, the full text, or none of a note's content, with edits saved back to the note. The README states that the Dataview plugin is required because its API supplies the links and backlinks.
