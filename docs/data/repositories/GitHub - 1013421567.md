# constsz/obsidian-drag-to-scroll

Adds drag-to-scroll to Obsidian: holding the mouse button and dragging scrolls the view the way a touch device does. The README states it works in both Edit and Reading modes and was inspired by PDF viewers and similar browser extensions, and that it is desktop-only because dragging to scroll is already basic behaviour on mobile.
