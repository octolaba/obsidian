# phibr0/obsidian-emoji-shortcodes

Obsidian plugin that adds support for emoji shortcodes, so a typed shortcode such as a colon-delimited name is rendered as the corresponding emoji in a note. The README points to Emojipedia as the reference list of shortcodes and shows both immediate replacement and shortcodes kept as written. Installation is described through the community plugin browser.
