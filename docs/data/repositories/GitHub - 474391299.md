# svonjoi/obsidian-heading-level-indent

This plugin indents the content under each heading according to that heading's level, a visual technique the README presents as making a document's structure and organization easier to follow. The indentation applied at each level is configurable in the plugin settings. Indentation can be turned off for an individual note by setting the `heading-indent` frontmatter property to false; omitting the property leaves it enabled.
