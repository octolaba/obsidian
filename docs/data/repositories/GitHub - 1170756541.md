# KeonyRus/obsidian-confluence-sync

Obsidian plugin that performs a read-only sync of Confluence Server pages into a vault as Markdown. The README describes pulling a single page by URL, id or title, pulling a page tree recursively, re-pulling changed pages while version tracking skips unchanged ones, and optional attachment download. Conversion covers code blocks, info and warning macros turned into callouts, page links turned into wikilinks, expand macros and a table of contents; each synced file carries confluence frontmatter fields, and setup asks for a base URL and a personal access token.
