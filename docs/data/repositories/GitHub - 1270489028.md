# PatruusBarba/ObsidianSpoilerPlugin

Repository for a spoiler plugin that hides and reveals text in a note. Its README states that selecting text and pressing a ribbon button wraps the selection in a collapsible spoiler callout, preserving any Markdown inside it, and that pressing the button again on an existing spoiler unwraps it back to plain text. In reading view the callout renders collapsed until it is clicked.
