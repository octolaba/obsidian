# fengshuzi/lite-calendar

Obsidian plugin integrating the macOS system calendar, with a Chinese-language README and interface. It can list events for the coming three days and create, edit and delete them across several calendars, including all-day events and event notes and locations, through a capture-style view opened from a ribbon icon or a command. The README states that it requires macOS, Obsidian 1.2.8 or newer and authorization to access the system calendar, and that it reaches EventKit through JavaScript for Automation scripts run by osascript.
