# SharbelMarshi/obsidian-LuaTikz-plugin

No repository description is recorded, so this body is grounded in the README alone. LuaTikZ renders tikz and luatikz fenced code blocks in Obsidian, using a local LuaLaTeX installation or TikZJax on desktop and TikZJax on mobile, with TikZJax bundled into the released main script. The README also describes a floating live preview with an Edit mode that expands into a visual TikZ editor whose select, pan, line, arrow, path, curve, freehand and shape tools write plain TikZ back into the existing fence, drawing over the compiled output as an aligned background layer, and touch, stylus and Apple Pencil input.
