# akaalias/obsidian-journey-plugin

The repository holds the Obsidian Journey plugin, which searches for a path between notes and builds an outline from it. Its README frames the problem as extracting a story out of a vault of atomic notes, and presents the plugin as automatically creating an outline for an article, a blog post or a book. It links a tutorial video and credits community feedback for the feature set; the repository records no license.
