# Barba828/obsidian-plugin-chord

This plugin enters and displays guitar chords directly in a document rather than inside a code block, and the README states that the chords offered are all valid chords generated from chord theory, with custom chords supported as well. A chord is inserted through an Obsidian command in one of two ways: by name, such as Am7, or by finger position, such as x-3-2-0-1-0 for a C chord. The README suggests combining the plugin with Slash commander or with the editing toolbar.
