# obsidian-full-calendar-remastered/plugin-full-calendar

A remastered edition of the Full Calendar plugin that keeps a calendar in the vault by integrating the FullCalendar library. Calendar sources include events in note frontmatter, event lists in daily notes, read-only local or remote ICS files, two-way CalDAV sync and two-way Google Calendar sync. The README also lists integrations with the Tasks plugin, TaskNotes and ActivityWatch, and records that the premium FullCalendar components are used under the GPLv3 provision of that project.
