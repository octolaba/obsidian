# TakamiChie/Obsidian_CharacterInsertionPlugin

Inserts a preset character at the cursor position; the recorded description is bilingual Japanese and English, and this body restates it in English together with the README. The README explains that a list of characters is configured in the settings and that each run of the command advances the cursor position through that list, one character at a time, with a final run removing the inserted character again. The author states the plugin exists because marking each line of a diary with an emoji by copying and pasting was tedious, and suggests it for marking Markdown documents by fixed rules.
