# ryjjin/Obsidian-shortcuts-extender

Shortcuts extender adds editor commands for inserting special symbols without switching keyboard layout, wrapping selections with common Markdown pairs, toggling blockquotes, bullet lists and code blocks, changing heading depth for the current line or selection, and toggling the case of a selection. Its heading commands move in a fixed cycle where increasing the level removes hash characters down to plain text and decreasing adds them up to six, while lines beginning with list, checkbox, ordered-list or other special markers are left unchanged. Typographic commands cover dashes, French quotes with pair insertion when nothing is selected, bracket helpers and inline or fenced code helpers. The README states that version 3.0.0 deliberately ships almost no default hotkeys, since Obsidian already lets users assign them.
