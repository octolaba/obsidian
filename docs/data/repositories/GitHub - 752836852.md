# jtucker2/obsidian-consecutive-lists

Consecutive Lists makes two adjacent Markdown lists render as separate lists in reading mode by automatically alternating the list marker of the second one, for example switching from a hyphen to a plus sign. The README stresses that nothing about how Obsidian interprets Markdown is changed and that the output is ordinary Markdown compatible with other parsers, so notes stay transferable and do not depend on the plugin. Without it, two hyphen-marked lists separated by a blank line are parsed as one list.
