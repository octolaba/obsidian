# JoshKasap/Obsidian-Faded-Theme

Faded is an Obsidian theme whose README states that it uses modified CSS for sliding panes, and warns that using the Sliding Panes plugin alongside it causes glitches. The README encourages installing the Style Settings plugin to reach the theme's customizable options, and lists styling for tables, headers, bullet and numbered lists, checkboxes, callouts, the file tree, the outliner and popovers. It also records support for efemkay's multi-column CSS snippet and custom HTML snippets such as a page title class.
