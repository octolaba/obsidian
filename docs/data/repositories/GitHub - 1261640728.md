# wilbursalazar/typst-book-preview

Typster compiles a configured Typst entry file to PDF using the local Typst command-line tool, previews the generated PDF in an Obsidian pane, and adds a toolbar above source-mode Typst notes. Recompilation happens automatically when the main file, another Typst file in the same project folder, or a referenced image asset changes, and compiler output and diagnostics are shown inside Obsidian. The toolbar wraps a selection or inserts a snippet for emphasis, strong text, math, highlighting, headings, lists, notes, references, layout, figures, tables and bibliography calls, and can insert starter templates for a book or an article. The README records Obsidian desktop 1.13.0 or newer, a local Typst installation and a file-system vault as requirements, and states that mobile is unsupported because a local command is run.
