# taylorsdugger/obsidian-recipe-vault

A recipe management plugin that keeps recipes as ordinary Markdown notes: they can be imported from a URL by fetching the page's structured JSON-LD data, transcribed from a photograph of a cookbook page through AI vision with a verify-and-edit step, or written from scratch on the same template. A gallery view browses the collection as cards, and search filters as you type across titles, meal types and ingredients. Ingredients checked off in a note go to a single shopping list file with units merged automatically, several recipes can be compared side by side with shared and unique ingredients highlighted, and each recipe tracks when it was last made and how often. Edits such as scaling servings can be requested through OpenRouter with an API key, and note templates use Handlebars.
