# RyoJerryYu/obsidian-jessiecode

Obsidian JessieCode renders interactive mathematical graphs described in JessieCode, the scripting language for JSXGraph. A graph is written in a code block whose language is set to jessiecode, and YAML frontmatter inside that block can set width, height, bounding box or other JSXGraph attributes. The README credits JSXGraph and JessieCode as the libraries used and names the obsidian-graphs plugin as its inspiration.
