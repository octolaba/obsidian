# DuckTapeKiller/obsidian-reader-highlighter-tags

Brings highlighting into Obsidian's Reading View, letting text be highlighted, annotated as footnotes, and tagged inline without switching to Edit mode. A structural filtering engine strips non-visible Markdown syntax — footnotes, task checkboxes, callout headers, internal tags — before matching, so a browser selection maps back to coordinates in the source file, and coordinate mapping is documented as covering transclusions and embedded files. The README states that regex gap patterns preserve literal characters such as brackets, asterisks and dollar signs.
