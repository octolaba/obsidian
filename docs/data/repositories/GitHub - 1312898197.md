# KANYE-Shen/tree-obs

Tree Obs converts one marked Markdown file into a folder of notes, writing a separate note for each marked node and linking parents and children through wikilinks in a footer at the bottom of each note. Markers are comment lines naming a node and, for a child, its parent; the document must contain exactly one root, node names must be unique, and markers inside fenced code stay ordinary content. The input is a Markdown export from Tree Chat, whose Harvest export already carries the markers, or any file marked by hand in the same format; JSON is not read. Conversion is one-way and run from a command or the file context menu, the source file is left in place, and the generated notes land in a folder named after the root node.
