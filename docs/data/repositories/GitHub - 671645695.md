# brandonkboswell/reflection

Reflection shows past periodic notes from the same date in earlier years while a daily or weekly note is open: from a daily note it surfaces the notes for the same day in previous years, and from a weekly note the weekly notes carrying the same week number. The plugin is installed from within Obsidian and needs no further action beyond being enabled. The README states that the Periodic Notes plugin must be installed and configured correctly for it to work.
