# ibatura/obsidian-meeting-transcript-converter

This repository holds Meeting Transcript Converter, a desktop-only Obsidian plugin that converts .txt and .vtt transcript files into Markdown notes entirely offline. Text files are cleaned by trimming lines and dropping empty ones, while WebVTT files are parsed into a bulleted list of cues, each optionally prefixed with a timestamp computed as the file's creation time plus the cue offset. Converted notes open with a title and YAML frontmatter carrying the meeting name and date, plus duration and participants when they can be detected, and a watched folder can convert new files automatically and delete the original. The README records that WebVTT voice tags are not stripped and pass through as raw text.
