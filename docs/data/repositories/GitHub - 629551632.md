# PaulTreanor/notes-dater

Obsidian plugin that adds the dates on which the active file was created and last updated to the status bar. The README states that it works for all files, including notes, images and PDFs, and documents installation from the community plugins browser or by copying the built files into the vault's plugin folder. The author records that pull requests are not accepted because the plugin is considered feature-complete, and invites forks instead.
