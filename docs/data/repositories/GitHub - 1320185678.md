# obsidian-power-plugins/obsidian-power-editor

Power Editor puts a formatting toolbar above the editor, adds a selection bubble and slash commands, and hides syntax markers on screen while leaving them in the file, so notes stay plain Markdown. Every block gains a drag handle for moving a paragraph, list, table or whole heading section, with a menu to turn it into something else, duplicate it, copy a link to it or delete it, and every toolbar action is also a command that can take a shortcut. One button converts the block under the cursor into a titled callout in one of nine types, and further commands upgrade older bold-prefixed lines into real callouts after a preview. Copying puts real HTML on the clipboard so pasted text survives email, incoming text from Word or the web is cleaned into Markdown with tables rebuilt, and attached PDFs land as links stored in the note's own folder.
