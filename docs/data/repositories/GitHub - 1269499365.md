# pdriggett/practice-planner

Weekly Music Practice Planner keeps each week of music practice in a single Markdown note holding the week's goals, a skills-by-days tracking table, and one section per day. Each day section is seeded with a practice session bullet carrying Dataview inline fields for skill, minutes and notes, and can be duplicated to log several sessions, with the date in the day's heading so that a later Dataview query or heat map can read date, skill and minutes without hidden metadata. Settings choose the folder for the weekly notes, the day the practice week starts on, and the default skill rows, which can be renamed, removed, extended or reset to the built-in set. Three commands open this week's, next week's or the previous week's note, creating it from the template when it does not yet exist.
