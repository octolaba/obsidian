# PrEvAl85/obsidian-retro-os

Retro OS is an Obsidian theme that rebuilds a 1990s desktop interface, drawing on Classic Mac OS and Windows 95, in a pastel neo-brutalist style: thick black borders, hard flat shadows and buttons that shift down when pressed. Its palette is vanilla with pink and purple titlebars and lime and peach buttons, and the native titlebar gets flat gray square window buttons with classic minimize, maximize and close glyphs. Light and dark variants are included, the VT323 pixel font is embedded as base64 so it works offline, and Cyrillic text falls back to a monospace stack. Scrollbars, tabs, callouts, tags, tables and DataviewJS dashboards are styled to match.
