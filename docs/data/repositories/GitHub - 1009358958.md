# sawamaru/obsidian-LongtimeDiary

LongtimeDiary is an Obsidian plugin that shows past daily notes for the same day in previous years. Adding a LongtimeDiary code block to a daily note makes the plugin search for and display the daily notes sharing that day of the month; the README states that the block does nothing outside a daily note and suggests putting it in a daily note template. At the time the README was written the plugin was still applying for the community list and was installed through BRAT.
