# ShadiestGoat/obsidian-layout-manager

Layout Manager is described as a plugin that manages the layouts of leaves, where layout means the position, size, grouping and view mode of tabs in the main view. A layout is captured by arranging the workspace around a single open Markdown file and saving it against a glob pattern, after which opening any file matching that pattern applies the layout; a saved layout can also be loaded on demand. It preserves splits with their direction and ratios, file groupings, editor mode, tab order and non-file views such as the graph, and a layout may be restricted to particular platforms. The README records two limits: a layout is tied to exactly one file because the mechanism is file-context based, and mobile turns splits into tabs regardless.
