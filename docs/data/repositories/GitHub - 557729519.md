# cloudhao1999/obsidian-scroll-to-top-plugin

This repository holds an Obsidian plugin that, in the words of its own description, adds a button to scroll to the top of the current note and is not just that. The README documents a status bar button that scrolls the note to its top or its bottom and a ribbon button that scrolls until the selection or the cursor in edit mode. It also states that the plugin should work in an Obsidian browser view together with the Surfing plugin, that the button style can be customized with the Style Settings plugin, and that further button options are available in the plugin settings.
