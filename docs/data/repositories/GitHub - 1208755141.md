# martinlegend/neogdsync

This repository holds NeoGDSync, an Obsidian plugin that syncs a vault with Google Drive. It offers a smart sync that detects conflicts and transfers only changed files plus force push and force pull directions, and the README records that a conflicting Drive copy is saved as a conflict file rather than overwritten silently. Further recorded features are a path-based index that avoids a full crawl after the first sync, optional version history kept on Drive, glob patterns for exclusions, and a URI handler for automation; setup asks for a Google OAuth2 refresh token and the Drive folder id that maps to the vault root.
