# NatiAris/obsidian-random-todo

The repository holds Random To-Do, an Obsidian plugin that jumps to unfinished work at random. Its README defines a todo item as any occurrence of a mark the reader configures as a JavaScript regular expression, defaulting to an ellipsis, and records three additions: a command opening a random file that contains at least one such item, a command opening a random item at its position in its file, and an optional status bar counter. It notes that the first command weights files equally while the second weights items equally, and compares the plugin to the core random note command with the difference that it only lands on unfinished material.
