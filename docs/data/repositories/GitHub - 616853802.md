# WoodenMaiden/obsidian-abbreviations

This plugin expands abbreviations in an Obsidian note as they are typed, which the README suggests for words that are often misspelled or for short forms meant to expand into longer words or sentences. Abbreviations are managed in a dedicated section of the settings, where each can be created, enabled, disabled or deleted. An abbreviation can also be marked case-insensitive, so a form typed in capitals still expands.
