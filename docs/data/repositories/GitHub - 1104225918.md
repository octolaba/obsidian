# roomi-fields/obsidian-content-publisher

The repository holds Obsidian Content Publisher, a plugin that publishes notes from the vault to external platforms. The README lists Substack with draft or immediate publishing, images, audience targeting and multiple publications, WordPress with multiple servers, categories, tags and SEO and translation plugin fields, and LinkedIn text or article posts with draft support and an editable preview. It notes that automatic Substack login is desktop only, and points to separate platform documentation for setup and frontmatter.
