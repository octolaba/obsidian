# LiveAQuietLife/obsidian-verso

Verso is a reading scheduler for Obsidian that tracks books and builds schedules to stay on pace: a book is added with a target finish date and the days of the week it will be read, and the plugin derives daily chunks and reports progress. The README describes a dashboard sorting active books by urgency, from at-risk through behind to on-track by due date and then not yet started, a Today sidebar showing only what is due with a click to mark a chunk complete, and a library with planned, completed and archived tabs where finished books line up on a visual shelf and archived ones remember why they were set aside. Logging what was actually read redistributes the remaining pages across the remaining days rather than keeping the original numbers, so falling behind or catching up resolves against reality, and the label used for collections is configurable.
