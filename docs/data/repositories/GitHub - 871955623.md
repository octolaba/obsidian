# Unearthed-App/unearthed-obsidian

This plugin pulls book highlights and notes from the Unearthed service into an Obsidian vault, covering material Unearthed collects from Kindle, KOReader and its own app. Highlights from the same title in Kindle and KOReader are merged into one book file, and repeated syncs append only the quotes that are not already present. Custom templates control how each book and highlight is written, including whether the source template produces Obsidian properties, and highlight colours are carried across. Tags created in Unearthed arrive too, either as one note per tag under a Tags folder with links back to the sources or as tags in each file's frontmatter, selected by a tag mode setting.
