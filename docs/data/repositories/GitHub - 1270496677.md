# swartzrock/obsidian-settings-float-plugin

Settings Float makes the core Obsidian settings modal and the supported catalog dialogs movable and resizable, so settings, theme browsing or plugin browsing can stay open while the note or workspace behind them remains visible. The README states that it is a desktop plugin aimed at appearance-tuning workflows, and that it is not yet listed in the community catalog, so installation goes through BRAT, a GitHub release or a local build. Its sections cover the workflow, the settings, a recovery path and compatibility notes.
