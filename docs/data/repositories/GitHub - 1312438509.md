# dctanugi/obsidian-flow-writer

Flow Writer adds a full-screen drafting mode that hides the ribbon, side panes, tab bar, status bar, properties panel and note title, dims already committed text to a configurable opacity, and centres the line being typed. Once a space or Enter is pressed the preceding word is sealed: it cannot be edited, deleted, undone or navigated back to until flow mode is left, though backspace still works inside the word being typed. The mode starts at the end of the note with existing content sealed and never modifies it, is toggled by a command that ships without a hotkey, exits on Esc unless that is turned off, and is desktop-only because the full-screen behaviour it relies on does not exist on mobile.
