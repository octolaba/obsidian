# drkpxl/Frost

Frost is described as a clean and uncluttered Obsidian theme inspired by Apple Notes and Tailwind's default theming, with both light and dark modes. Its README records rounded corners for images, carefully chosen typography and customizable accent colours, and lists a default accent colour, an 18px default font size and a font stack of SF Pro Display, Atkinson Hyperlegible and JetBrains Mono. It recommends the Code Block and Iconize plugins for the full experience shown in the screenshots, and records that this is the author's first Obsidian theme.
