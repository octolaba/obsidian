# kbwo/obsidian-click-hint

Click Hint provides keyboard-driven hints for clickable elements in Obsidian, so links, buttons and similar targets can be reached without the mouse. The command Show click hints activates hint mode, and typing the characters shown on a hint activates that element, with visual feedback while a match is still partial. Internal and external links are both supported and the hint characters are configurable, defaulting to a to z. The README names vim-easymotion, Vimium and the Jump to Link plugin as its inspirations.
