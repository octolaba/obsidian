# benjamincassidy/lighthouse

Obsidian plugin offering project-based writing, described by its README as bringing the focus of a dedicated writing application into Obsidian in the manner of Ulysses while keeping plain Markdown files in the vault. One command opens a Library and an Inspector for a project, covering groups, goals, pacing and focus, with live word counts, deadline pacing and a streak shown in the Inspector. Nested groups and tinted icons for research notes are shown in its screenshots, and a compile step exports a project to PDF, DOCX or EPUB with style presets.
