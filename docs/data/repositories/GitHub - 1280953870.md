# willjhliang/obsidian-better-daily-notes

Better Daily Notes creates daily notes and presents them as a single infinite-scrolling page in Obsidian, with a calendar for jumping between dates and seeing which days already have notes. The README states the plugin is standalone and includes the functionality of the core Daily Notes plugin.
