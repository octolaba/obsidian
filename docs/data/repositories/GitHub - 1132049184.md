# fengshuzi/media-journal

Media Journal tracks books, movies, TV shows and variety programmes recorded as tagged lines inside daily notes, each line holding a title and a short comment. A sidebar view opened from the ribbon icon or the command palette browses those records and shows monthly statistics filtered by year and month. The README records that the journal folder and date format can be taken from the core Daily Notes plugin when it is available, and that the app title and the media-type labels are renameable through a `config.json` written on the first save from the settings UI.
