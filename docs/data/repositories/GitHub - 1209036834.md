# Norman-lawyer/obsidian-rainbow-highlight

Rainbow Highlight highlights selected text in Obsidian from a floating colour palette that appears near the selection, in the manner of marking up a printed book. Six colours are offered — yellow, green, blue, pink, purple and orange — each also exposed as a command so it can take a keyboard shortcut, and an existing highlight is removed with one click. The README states that highlighting preserves bold, italic and strikethrough formatting and that the colours adapt to light and dark themes.
