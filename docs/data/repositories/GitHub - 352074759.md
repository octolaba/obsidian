# shabegom/buttons

Buttons renders clickable buttons in Obsidian notes that run commands and open links. The README documents button types for running a command from the command palette, opening a URL or URI, performing a calculation that can reference lines from the note, prepending, appending, inserting or creating a note from a template or from specified text, a swap type that runs a different button on each click, and a chain type that runs several actions in sequence. Buttons are most quickly created through the Button Maker opened from the command palette, and the changelog records arguments for multi-line names with Markdown, width and height in em units, and text alignment.
