# jmilldotdev/obsidian-canvas-randomnote

Adds notes to an Obsidian Canvas as file nodes. The README documents two commands, one selecting from all Markdown files in the vault and one selecting randomly from the active search, with settings for the number of notes and their positions offered when the command runs; the selected notes are placed as a grid on the active canvas. The README carries a warning from the author: because no official Canvas API exists in the developer API, the plugin writes the canvas data directly, so running several commands in quick succession can leave the canvas out of sync with what Obsidian shows.
