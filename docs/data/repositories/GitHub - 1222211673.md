# etaiso/obsidian-tag-fuzzy-find

Tag Fuzzy Find adds a quick-switcher style modal for tags: fuzzy-search every tag in the vault, shown with its usage count, then pick one and choose a note that carries it. The flow is two steps, and pressing backspace on an empty query returns to the tag picker with the earlier query preserved. Nested tags are included, so selecting a parent tag also surfaces notes tagged with its children, and the initial ordering can be recently-picked first, alphabetical or by usage. Typing a configurable prefix character as the first character of Obsidian's built-in quick switcher reroutes into this modal, and the usual shortcuts open the chosen note in the current pane, a new tab or a split.
