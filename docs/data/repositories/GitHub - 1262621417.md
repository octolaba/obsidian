# viggomeesters/obsidian-archive-viewer

An Obsidian plugin that inspects the contents of a .zip file in the vault without extracting anything, reading only the ZIP central-directory metadata through the vault's binary API. It shows the archive as a folder and file tree plus a table of per-entry path, type, size, compressed size, modified date, compression method and warnings, with an archive summary of counts, total sizes, compression ratio and suspicious entries, filtering by path text or extension, and a cap of 2,000 rendered entries. It warns about path traversal, absolute paths, hidden or system-looking paths, encrypted entries, very large uncompressed sizes, suspicious ratios and many-file archives. The README states the scope deliberately: version 0.1 handles .zip only, and the plugin never extracts, opens, renames, deletes or writes archives back.
