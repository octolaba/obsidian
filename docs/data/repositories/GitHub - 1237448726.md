# kuanphough/obsidian-bangumi

An Obsidian plugin that syncs Bangumi collections and episode progress into Markdown notes, documented in a mainly Chinese README. It covers books, anime, music, games and live-action entries, filters by collection status, supports incremental sync that restores accidentally deleted entry notes, and writes ratings, tags, comments, covers and chapter checklists through user-editable note templates and frontmatter fields. Further features are a sync block that confines writes to part of a file, an optional daily-note block for entries added or updated in a run, a generated daily broadcast note, single-entry sync by link, id or title, a board for entries in progress that pushes chapter progress back to Bangumi with re-validation, and an error report note when a sync fails. The README warns that mobile compatibility may be poor.
