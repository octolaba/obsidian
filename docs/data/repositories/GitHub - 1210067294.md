# vesan/obsidian-table-beautifier

Table Beautifier converts ASCII and Unicode box-drawing tables into Markdown tables; the README motivates it with terminal output pasted from command-line tools that draw tables with box characters. The conversion runs over the current selection, either from a context-menu entry that appears only when the selection contains table-like characters or from a command-palette command. Columns are padded for visual alignment, and values shaped like code identifiers in PascalCase, snake_case or dot notation are wrapped in backticks.
