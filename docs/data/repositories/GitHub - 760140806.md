# thewordisbird/VaultSync

VaultSync links an Obsidian vault to a cloud storage provider, with Dropbox the only provider supported so far, on desktop and mobile. The plugin is connected from its settings page by choosing a provider and following its authentication flow, after which a remote vault path is selected from an existing directory or a newly created one. The README discloses that it talks to Dropbox through the Dropbox JavaScript SDK, that files in the selected remote folder are brought into the vault where they can be edited and deleted, and that files from the vault are copied to the remote vault.
