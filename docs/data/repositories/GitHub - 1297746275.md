# mainamirh/obsidian-link-cards

Detects a URL pasted into a note, offers to turn it into an embed, and replaces the URL with an embed block holding the fetched title, description, image, favicon and aspect ratio, which Obsidian then renders as a card. Metadata comes from three providers, the YouTube Data API for videos, OMDb for films and television, and OpenGraph for other websites, each deciding for itself whether it handles a given URL. API keys are entered in the plugin settings and held in Obsidian's Secret Storage, and a card can optionally show a blurred background derived from its own image.
