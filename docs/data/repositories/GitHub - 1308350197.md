# ZHYX91/obsidian-chrono-notes

A calendar workspace for periodic notes in Obsidian. The README lists year, month and week calendar views showing note state, tasks, holidays, local ICS events and time-range notes; daily, weekly, monthly, quarterly and yearly periodic notes created from built-in or Templater templates; and a note navbar for moving between adjacent notes, the parent period and the calendar. Optional extensions add Chinese lunar and Ganzhi calendars with solar terms and festivals, Persian, Ethiopic, Hebrew, Indian national, Islamic civil and Umm al-Qura calendars, and mainland China and Singapore holidays. It also documents statistics and heatmaps, time-range notes created by dragging a date range, read-only local ICS sources, and an Android layout.
