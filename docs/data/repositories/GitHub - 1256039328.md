# gabbywelson/obsidian-corduroy

The repository holds Corduroy, an Obsidian plugin that searches for a place and writes its coordinates into the current note's frontmatter. A command opens a live search whose results stream in from Google Maps as the name is typed; picking a result stores the coordinates and optionally the formatted address, leaving the note's other properties alone. The README frames this as removing the manual step of looking a latitude and longitude up outside Obsidian for notes that map plugins such as Leaflet or Map View render from frontmatter coordinates.
