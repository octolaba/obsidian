# t0masGutierrez/fix-pdf

Fix PDF configures how PDF files open in Obsidian, which by default initializes them at page width. The plugin sets newly opened PDF views to fit height instead, chooses which sidebar panel appears on open among none, thumbnails, table of contents or reveal current page, decides whether that sidebar starts open or closed, and can open a document at a given page or percentage through it. The settings are applied once per opened file so later manual zoom changes are not overridden again, and a per-file menu item allows overrides for an individual PDF.
