# kpieper876/Power-Merge-Notes

Merges Markdown notes into one, appending source content under matching headings, keeping distinct headings, and reconciling frontmatter by retaining the title and date of the preferred note while deduplicating aliases and tags. Merges can be started for two notes from the command palette, for several selected notes from the File Explorer context menu, for duplicates in the active file's folder, or automatically when a same-name duplicate is created or renamed, with common copy suffixes and sync conflict titles normalized. Repeated Dataview blocks are deduplicated and the most recently updated dv.view block is kept. By default the secondary note goes to the system trash after a successful merge, which a setting can disable, and heading comparison is exact and case-sensitive.
