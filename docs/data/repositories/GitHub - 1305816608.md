# anuzdhk/autoicon

Obsidian plugin that assigns icons to files and folders in the file explorer without tagging each item by hand. Icons resolve in a fixed priority order: a per-item icon set from the explorer context menu, an icon property in a note's frontmatter, custom rules matching on path prefix, extension, name substring, tag or regular expression, and finally defaults by file type. Rules can target files, folders or both, may assign a fixed colour, and are checked from the top with the first match winning. The README states the icons also appear in tab headers, beside inline titles and on internal links.
