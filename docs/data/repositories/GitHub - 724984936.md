# windingblack/obsidian-global-proxy

This repository holds Global Proxy, described upstream as an Obsidian plugin that makes it easier to configure web proxies and use them throughout Obsidian. The README lists socks, http and https proxy types, says the socks proxy is tried first with the http or https proxy as fallback and a direct request if both fail, and describes a comma-separated blacklist of rules for addresses that should bypass the proxy. It notes that some plugins keep their own network sessions which are not proxied by default, that a plugin token can be declared to route one such plugin's traffic, and that the plugin may be needed by users in areas with restricted networks.
