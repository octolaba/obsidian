# GeoKhv/obsidian-daily-checkbox-focus

The repository holds Daily Checkbox Focus, a small Obsidian plugin that moves the cursor to a configured empty checkbox when a daily note is opened. Daily notes are recognized by a date-shaped filename in any folder, and the plugin jumps once to the first genuinely empty checkbox line, accepting the three common list markers, and places the cursor after the marker. A setting decides whether the search covers only the capture area before the first heading or the whole note after any frontmatter, one missing empty checkbox can be inserted in that area, and two commands jump to or reveal the configured target manually.
