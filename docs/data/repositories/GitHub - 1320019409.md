# RahelaQ/retro-relay

Retro Relay is a warm analog Obsidian theme, graphite and cream in the dark and ink on paper in the light, with an amber accent running through both. Thirty-four foreground and background pairs are checked against WCAG 2.1 AA by a script in the repository, and meaning is never carried by color alone: callouts have icons, unresolved links get a dotted underline, and heading levels differ in weight and size as well as hue. The graph is styled in both schemes over an optional orbital plate, and a broadcast-style color band along the window edge and a faint cloud wash in dark panes can be switched on. Code blocks, tables, focus rings and all thirteen callout families are covered, seventeen options are exposed through Style Settings, and the theme is a single stylesheet with local fonts and no network access.
