# johannes-kaindl/obsidian-transmute

Transmute turns a plain-language instruction into a search and replace: a local OpenAI-compatible model writes a JavaScript regular expression, a replacement pattern and a one-line explanation of what it matches. Every match is listed before and after with its own checkbox and nothing is written until Apply, which writes through the editor so a single undo reverts it. A follow-up instruction refines the rule, sending the conversation and the matches found so far back to the model, and every round is kept in a history that can be returned to; the regex, replacement and flags can also be edited by hand. Scope runs from the selection to the whole vault filtered by folder, tag and a frontmatter property, and a vault-wide run copies the affected files first so one button restores them, refusing to write at all if that snapshot fails.
