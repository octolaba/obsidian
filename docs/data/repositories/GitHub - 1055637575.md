# xigua222/ObShare

ObShare uploads an Obsidian note to Feishu cloud documents from the right-click menu or the command palette; its description is bilingual and its README is largely Chinese. It converts Obsidian formats including YAML, Mermaid and SVG images, uploads local images and rewrites their links, and keeps an upload history whose permissions can be reset later. The README states that credentials such as the application identifier and secret are stored locally with AES-GCM encryption and that the plugin contacts the Feishu API only when the user acts.
