# zuchka/obsidian-readability

Readability Score analyses all or part of a document with the Flesch Reading Ease formula and shows the resulting score in the status bar, prefixed with a short marker. The README describes it as a small plugin and a fork of better-word-count, rebuilt to be smaller, more opinionated and focused on readability metrics.
