# harehare/obsidian-mq

This repository holds an Obsidian plugin that runs mq, a jq-like query language for Markdown, directly inside the app and fully client-side through WebAssembly, so the README states no network access is required. Live query blocks evaluate a query against a note and render the result, and the editor support inside mq code blocks covers syntax highlighting, parse and type diagnostics as you type, hover signatures and documentation, and autocomplete for functions and variables defined earlier in the block. A query is a selector that picks Markdown nodes such as headings, task items, links, code blocks, list items or paragraphs, optionally piped into functions that transform or filter them.
