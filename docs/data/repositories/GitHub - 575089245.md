# joleaf/obsidian-dmn-eval-plugin

Repository for the DMN Eval Plugin, which evaluates DMN decision models inside Obsidian notes using Camunda's dmn-engine library and requires Java 14 or later to be installed. A `dmn-eval` code block names the `.dmn` file and the decision to evaluate, takes its input from a variables mapping together with all frontmatter data of the note, and prints the decision output into the note when no error occurs. Optional parameters render headings of several levels before that output, and the README points to the companion DMN Plugin for viewing a model instead.
