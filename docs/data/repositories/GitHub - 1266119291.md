# usero2/obsidian-plugins-shiori-bookshelf

Shiori Bookshelf turns an Obsidian vault into a digital library for PDF, EPUB and CBZ files, browsed in a grid gallery of covers inside Obsidian. The README describes grouping manga, comics or light novels into series by subfolder and managing standalone books independently, sorting series by their most recently updated book, and lazy loading that fetches fifty items at a time. It also records a built-in local web server that exposes the same library to a browser on the local network, with a responsive interface, filtering and a remote reader, and built-in readers for the supported formats, the comic reader using infinite scroll with progress tracking. Covers are extracted from the files automatically, and an optional integration with a Google Gemini API key fills in metadata.
