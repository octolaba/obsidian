# shumadrid/obsidian-git-changelog

This repository holds Git Changelog, described upstream as an Obsidian plugin that displays changelogs of the entire vault and of individual files in the sidebar by using Git commit history. The README adds vault and file changelog views, customizable changelog rendering, live statistics in the status bar for the current note, integration with the Git plugin's diff view, comparison of two vault states, and changes since a chosen checkpoint, and presents the result as a data loss monitoring tool. It records a dependency on the separate Git plugin, and a note from the author that active work is paused while breakage will still be fixed.
