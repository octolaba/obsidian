# Xallt/sync-graph-settings

Sync Graph Settings copies the Color Groups configured for Obsidian's global graph onto the active local graph, through a single command that the README names as syncing graph groups settings to the local graph. The README states that this one feature is the whole of the plugin. The repository description additionally mentions search filters, which the README's own account of the command does not cover.
