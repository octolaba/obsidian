# choihc/mybox-sync

MYBOX Sync mirrors one mapped vault folder to NAVER MYBOX cloud storage through the MYBOX Open API. File creations, edits, renames, moves and deletions inside that folder are pushed automatically after a debounce of about five seconds, while remote changes are pulled only on demand from a command or the ribbon; a pull never deletes local files and skips files changed on both sides. Deleting a file moves the remote copy to the trash rather than erasing it, and this release covers a single mapped folder, with two-way sync, scheduled polling and multiple mappings left for later. A NAVER account and a personal access token are required, that token is stored as plain text in the plugin data file, local diagnostic logging is on by default, and no other host is contacted.
