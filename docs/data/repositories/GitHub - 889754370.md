# SturdyShawn/Create-folder-notes-with-dropdown

This plugin creates a Markdown note from a filename and a folder path entered in a dropdown-driven interface, and creates any folder in that path that does not exist yet. The README suggests binding a shortcut to open it and states that it handles a hierarchy up to three levels deep. Its recorded documentation is brief and points at a demonstration video and the author's contact address rather than a settings reference.
