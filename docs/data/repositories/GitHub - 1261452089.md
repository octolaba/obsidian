# dsnbyte/obsidian-supabase-sync

Supabase Vault Sync synchronises vault notes, frontmatter included, into a Supabase PostgreSQL database and binary attachments into Supabase Storage, in both directions. The README describes an offline-first design: file events are queued locally, and a registry of paths, modification times and SHA-256 hashes identifies changes and avoids redundant transfers, so work done offline syncs once a connection returns. It records email and password authentication with persistent sessions, Postgres row-level security so one user cannot reach another's vault data, a private attachment bucket, vault-id namespacing for several vaults, device registration, and a management view of vaults, devices and counts. The README calls this an unofficial solution, points to Obsidian Sync as the supported one, and asks for a backup before setup.
