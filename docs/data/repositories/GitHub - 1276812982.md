# chmac/tasknotes-review-intervals

TaskNotes Review Intervals schedules the next review of a note through frontmatter fields. Running its mark-reviewed command reads an interval in days from the note, adds it to today's date and writes the result back as a review date; if the note has no interval yet, a prompt asks for one and stores it so later reviews are a single command. The names of both fields and the default interval offered by the prompt are configurable in the settings, and the repository description frames the feature as adding snooze dates to the TaskNotes plugin.
