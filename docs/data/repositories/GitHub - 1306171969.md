# joeytoday/obsidian-canvas-enhance

Adds Canvas features on top of the native Obsidian Canvas, with every feature individually switchable in the settings. The README, written mainly in Chinese, documents an overview mode that fills each card with a large title when the canvas is zoomed out and restores the original content past a zoom threshold; a mindmap workflow where Tab creates a child node, Enter a sibling and Alt with the arrow keys navigates, with children inheriting the parent colour; node and edge styling through the right-click menu, including flowchart shapes, border styles, text alignment, arrow and path styles and obstacle-avoiding connections; file-node templates; and a metadata cache that lets canvas files participate in the graph view, backlinks and outgoing links. Custom node and edge style properties can be declared in a CSS snippet through YAML comments.
