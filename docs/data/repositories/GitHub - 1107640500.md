# MartinSeeler/obsidian-scatter

Obsidian Scatter adds a scatter plot view to Obsidian Bases: two numeric properties are chosen as axes and each note becomes a point on the chart, which the recorded description frames as a way to find patterns and spot outliers. The README lists auto-scaling axes, optional colouring by a category property, clicking a point to open its note, hover preview, a layout that works in sidebars and splits, and skipping notes with missing values while reporting how many were skipped. All three settings — X axis, Y axis and the optional colour property — live in the standard Bases configure-view menu.
