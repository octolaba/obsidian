# liuh886/obsidian-ical-plugin-pro

iCal Pro exposes tasks written in Markdown notes as iCalendar feeds that Google Calendar, Apple Calendar and Outlook can subscribe to. It parses Tasks and Day Planner syntax without those plugins being installed, infers dates from daily-note filenames or headings, splits entries into timed `VEVENT` and dated or floating `VTODO` components, and generates stable `UID` values so a task moving between files is not duplicated. The README claims RFC 5545 compliance covering line folding, CRLF and escaping. The feed is written either to a file in the vault or to a private GitHub Gist; the README describes the design as local-first with no usage tracking, and states that the GitHub personal access token is stored unencrypted in the plugin's own data.
