# Edems-DEV/md-discord-syntax

Discord Syntax is a monorepo bringing Discord-style Markdown formatting to Obsidian, to MDX and Next.js, and to platform-independent parsers. Two constructs are supported: spoiler text between double pipes, masked behind a spoiler block, and a subtext prefix at the start of a line, rendered as small muted secondary text. The workspace holds a dependency-free core parser, a remark plugin for MDX, an Obsidian community plugin adapter and a Quartz transformer adapter, and the README notes that the npm packages are still local monorepo packages rather than published ones.
