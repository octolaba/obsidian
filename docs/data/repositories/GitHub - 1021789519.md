# jheddings/obsidian-folderize

Folderize is an Obsidian plugin for managing attachments: it organizes them into a nested folder hierarchy derived from each file's SHA-256 checksum, so identical content always lands on the same path. The README states that the first bytes of the hash build the directory levels, which distributes files evenly and keeps any single attachment folder from growing too large. Settings cover the attachment root path, automatic organization of new attachments, removal of empty folders, path depth from 1 to 8, and log verbosity, and an "Organize all attachments" command runs the pass manually.
