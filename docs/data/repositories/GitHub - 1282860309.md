# HamzaMoiyadi/obsidian-film-artist-search

Film Artist Search looks up actors, directors, producers and other film-adjacent people on TMDb and brings the result into an Obsidian vault. One command opens a search palette that queries TMDb as you type and creates a structured Markdown note for the selected person in a configured folder, skipping creation and notifying when a note of that name already exists; a second inserts a wikilink to the person at the cursor, and a third, pre-populated with the active note's title, fetches full details and replaces the entire note content with a rendered template, falling back to a built-in template when none is configured. The last two commands appear only while the active note is in edit mode. Obsidian 1.4.10 or later and a free TMDb v3 API key are required, and the key is selected from Obsidian's secret storage.
