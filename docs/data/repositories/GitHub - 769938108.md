# chrisgurney/obsidian-note-toolbar

Obsidian plugin that adds context-aware toolbars to notes, which can hold commands, file and folder links, websites or URIs, menus, and scripts run through Dataview, Templater or JavaScript. The README shows toolbars that stick to the top of a note on scroll, appear when text is selected, and offer more options on mobile. Its disclosures section records that the plugin needs to read, write and list files within a vault for its built-in library of tools and its scripting extensibility, that the majority of those features are optional, and that it uses some internal Obsidian APIs newer than its declared minAppVersion.
