# Balibaloo/obsidian-contextual-note-templating

Contextual note templating creates notes by running intents, which are the plugin's unit of configuration and are declared as a list in a note's own frontmatter — for example an intent to create a meeting note. An intent groups templates together and prompts for values when it runs, and commands run either a note intent, selected from a note in the vault, or a global intent held in a global intents note and executed in the context of another note, with relative paths resolved from that context. The README states that the separate Filtered Opener plugin is required to select the note whose intents are run, and that global intents are imported and merged before the resulting intent executes.
