# opa-oz/obsidian-snippets-plugin

Repository for Snippets Catcher, a plugin that downloads CSS snippets into the vault instead of installing them by hand. Its README describes choosing snippets from the plugin's settings tab and then enabling them in Obsidian's appearance settings, and states that the available snippets are pulled from a companion repository which the user may contribute to or replace with their own.
