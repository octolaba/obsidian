# Raushan-kumar-yadav/obsidianDraw

CanvasDraw embeds Excalidraw drawings in Markdown notes by storing each one as JSON inside an excalidraw code block in the note file. A drawing renders as an inline preview in reading view, and clicking it opens the full Excalidraw editor in a modal with shapes, arrows, colours, roughness settings and handwriting fonts. Images pasted or dragged into a drawing are saved as assets in the vault, a library panel browses built-in elements and imported library files, and each block keeps its own canvas height and zoom level so the viewport is preserved. Zoom buttons and a resize handle appear on hover, the drawing follows Obsidian's light and dark themes, a transparent background mode is available, and commands insert, edit, clear and delete drawing blocks.
