# binarynoir/obsidian-markdown-tags

Tags for Markdown styles inline labels inside Markdown documents in Obsidian, using predefined or custom labels, customizable colors and optional arrow indicators to track tasks and statuses. A tag is written in double parentheses with either a pipe or a slash separating its parts, optional further parts set the background and foreground colors as predefined names or hex codes, and a leading marker adds an arrow to the left. The README notes that supporting both separators helps when tags are used inside Markdown tables, and it mentions a companion extension for Visual Studio Code.
