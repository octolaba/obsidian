# d9k/obsidian-path-in-tab-title

This plugin puts a note's path, rather than only its basename, into the Obsidian tab title. Its README is largely an installation note plus a list of known limitations: the title updates only after a delay, titles reset to their defaults when the app restarts, and only focused tabs are changed. It suggests a CSS rule for styling the added path and records an alternative approach that would patch the application's own display-text function, which the author says he does not know how to apply to the Electron app.
