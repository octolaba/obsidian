# ziadkadry99/Qlaude

Qlaude runs the Claude Code CLI from inside Obsidian: a modal opened by a keyboard shortcut takes a natural-language instruction and streams the resulting output while notes are read, edited and created. It offers a one-shot quick action mode and a chat mode whose history persists across modal openings and Obsidian sessions and can be resumed, renders replies as Markdown, and lets any model identifier be typed in. Read, list, edit and create access are controlled independently in settings. The README records a requirement of Obsidian 1.4.0 or later on desktop only, with the Claude Code CLI installed and authenticated.
