# RohitNahar-Offical/colorful-folders-obsidian

Obsidian plugin that color-codes folders, tags and the graph view and assigns folder icons. The README is largely a running changelog and documents per-item custom styling through a Set Custom File Style context menu with a border-radius slider, a setting to show or hide folder collapse indicators, and global defaults for open and closed folder icons that individual folders can override. Its promotional framing is not restated here.
