# beolatn/TokenUsage

Reads Claude Code session files stored locally under the user's home directory and reports token consumption in an Obsidian sidebar panel, without an API key or external dashboard. Input, output, cache-write and cache-read totals are shown separately across five ranges, including a rolling five-hour window matching Claude Code's rate-limit period, with logarithmic bars so the four types stay comparable. A seven-day chart stacks usage by model, an HTML dashboard adds 30-day charts, a model donut, a top-sessions table and cache-efficiency analysis, and a Markdown report can be exported into the vault. A file watcher picks up new activity as it is written, backed by a configurable polling interval, and all aggregation runs locally.
