# doitian/obsidian-min-width

The repository holds Min Width, an Obsidian plugin that sets a minimum width for the active pane, so Obsidian widens that pane and shrinks the others to keep it. Its README records the default as the smaller of forty columns or eighty-eight percent of the editing area, and a settings tab that overrides the minimum per view type, listing known view types such as the Markdown editor and views contributed by other plugins. The plugin is recorded as growing out of a blog post by the same author.
