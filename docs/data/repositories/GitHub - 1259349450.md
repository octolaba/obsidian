# canserhat77/obsidian-web-view

Opens HTTP and HTTPS links in Obsidian tabs through an embedded browser. A URL is entered from the command palette or taken from the clipboard when it holds a valid address, and the view offers back, forward, reload and address-bar controls plus an action that reopens the current page in the default browser. The README states that the plugin is desktop-only because it uses Electron's embedded webview element.
