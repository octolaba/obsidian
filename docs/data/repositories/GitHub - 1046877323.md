# tbergeron/obsidian-human-readable-dates

Human Readable Dates displays dates in an Obsidian note as relative phrases such as "Yesterday", "2 hours ago" or "In 3 days" while leaving the original date strings in the file unchanged. The transformation applies in Live Preview mode only and is cursor-aware while editing. Precision follows how recent the date is, from "Now" within five minutes through minutes, hours, days, weeks and months to years, and the date format the plugin looks for is configured with standard Moment.js format tokens.
