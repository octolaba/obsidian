# Obsidian-TTRPG-Community/Made-Up-Words

A dictionary for invented vocabulary — characters, places, conlangs — stored as a folder of Markdown notes with structured frontmatter and indexed for lookup, with hover tooltips and a side-panel lexicon. The README is explicit that this is a dictionary and lookup tool rather than a translator: it shows every matching sense instead of one best guess, recognises inflected forms where rules are defined, and labels the output of its deterministic cypher engine as a phonological placeholder rather than a translation. It distinguishes a flavour-conlang mode, where sound substitution transliterates prose, from linguistic conlanging, where the dictionary is the only real translation surface, and marks itself as pre-1.0 with breaking changes expected.
