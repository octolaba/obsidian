# zakhij/obsidian-activity-heatmap

This plugin draws a GitHub-style heatmap of note-taking activity across an Obsidian vault. It monitors every vault file and, on each change, logs new values and compares them with the previous checkpoint; the two metrics used as activity proxies are file size and word count. The heatmap updates in the background and opens from a ribbon calendar icon or the command palette, where the metric and the period — the past year or a specific calendar year — can be switched and individual cells hovered for detail.
