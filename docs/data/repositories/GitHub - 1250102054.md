# SunnyYYLin/obsidian-tasktodo

TaskTodo adds a planning view and a today dashboard on top of the TaskLite Core plugin, which the README lists as a requirement alongside Obsidian 1.8.0 or newer. It ships two built-in views, In plan and Today, and allows custom tabs with custom columns and groups whose sort order is set by dragging. Filters are built through a graphical interface with a fallback to DQL for queries it cannot express, priority colours are configurable, and tasks and subtasks can be created from the view itself.
