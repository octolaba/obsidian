# EricRhysTaylor/radial-timeline

Radial Timeline arranges the scenes of a longform writing project in a radial layout by act, subplot and either narrative or chronological order, with each ring representing a subplot and hover interactions surfacing details such as a scene synopsis. The README states that it captures four timelines in one view: narrative time as the order in which events are revealed to readers, chronological time as when they happen in the story's world, author time tracking writing progress against due dates through Todo, Working, Complete and Overdue, and revision stage. It also records that Obsidian flags direct filesystem access and shell execution on install because of the Pandoc manuscript publishing pipeline alone, shell execution running Pandoc and its LaTeX engine at export time and filesystem access writing export files and locating the Pandoc binary and fonts outside the vault.
