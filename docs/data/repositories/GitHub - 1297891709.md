# laughedelic/obsidian-readable-date-links

Readable Date Links renders links whose filename is a date as a human-readable date, so daily notes can keep sortable plain filenames while a link to one displays as a formatted weekday and date. The README describes the change as strictly cosmetic: the plugin never renames files, never writes frontmatter or aliases and never changes note content, and links that already carry an explicit alias or a subpath are left alone because their display text was chosen deliberately. It works in reading view and in live preview, where moving the cursor into a link reveals the raw text, and the filename pattern, display format, optional relative labels such as today and yesterday, a folder restriction and per-context toggles are all settings.
