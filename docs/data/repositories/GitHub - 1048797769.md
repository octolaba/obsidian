# taisukemino/random-note-obsidian

Adds commands that open a random note drawn from a recent window of creation time: the past 24 hours, the past 7 days or the past 30 days. Up to three folders can be configured in settings, each adding its own command named after the folder that picks a random note from inside it. It works on desktop and mobile and requires Obsidian 0.15.0 or later.
