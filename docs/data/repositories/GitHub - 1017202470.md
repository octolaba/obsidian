# kennethac/obsidian-http-links-plugin

The Obsidian HTTP Link Plugin creates links to notes using the `https` scheme instead of the `obsidian://` URL that Obsidian's own copy command produces, because the custom scheme is not recognised or rendered as a clickable link on every platform. By default the generated link points at a publicly hosted instance of the author's Obsidian HTTP Links project, which the README describes as running on Cloudflare with no external analytics, tracking or dependencies. The README states that the link carries no information about the file beyond its title and that a self-hosted instance of the site can be deployed instead.
