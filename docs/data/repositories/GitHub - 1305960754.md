# DyllonWright/Digital-Dogear

Repository for Digital Dogear, an Obsidian plugin that records where reading or watching stopped as one plain line in the daily note, with the work linked and the position written in the notation its medium uses — pages for books, season and episode for shows, chapters for manga, issues for comics. Consecutive sittings within a gap window roll into a range on their own, and a skipped position earns a marker so the break stays visible. Each built-in type's emoji and label are editable in settings and custom types can be added for anything with an order, while the recorded description also names a native heatmap and completion tracking.
