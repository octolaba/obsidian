# jameswolensky/obsidian-blackboard

Blackboard adds a blackboard file type for pressure-sensitive freehand drawing with a stylus or Apple Pencil, and lets drawings be made directly inside Obsidian Canvas nodes and Markdown embeds without opening a separate editor. Palm rejection reserves touch for navigation — one finger pans and two fingers pinch-zoom in the standalone view, while Space and drag pans on desktop — so the stylus keeps drawing throughout. The tool set is pen, highlighter and stroke eraser, with a shared floating toolbar, a configurable board background, per-embed sizing controlled by the host node or embed size, and optional SVG export on save. Files are plain human-readable JSON.
