# 7368697661/Ultra-Lobster

Ultra Lobster is a large Obsidian theme that its author describes as the culmination of the CSS they have written for the application, pushing the interface toward card layouts, glassmorphism and deep customization without losing the utility of a note-taking app. The README documents dozens of subthemes and singles out two: abaddon glass, which applies heavy frosted glass to the reading view and floating headers so custom backgrounds show through, and chameleon, which shifts its whole palette from the chosen accent color. With the glass subtheme, a direct image URL pasted into Style Settings sets a workspace wallpaper displayed behind the notes.
