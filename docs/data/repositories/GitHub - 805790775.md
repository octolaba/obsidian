# namikaze-40p/obsidian-command-tracker

Command Tracker records how many times each Obsidian command is used and when it was last used, and a command opens a view of the recorded information. The README frames this as input for tuning plugins and hotkeys: a frequently used command found in the palette may deserve a hotkey, and a rarely used hotkey may be worth ceding to another command. It states that only commands executed by hotkey or chosen from the command palette are recorded, and not those run from the ribbon or by other interface actions, and it lists known bugs in which hotkeys are missing from the table after a restart with the view open or when no keyboard is connected.
