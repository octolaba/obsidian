# Nimaapr/polyglot-renderer

Polyglot Renderer renders fenced HTML code blocks in Obsidian as live previews inside a sandboxed iframe that allows scripts but not same-origin access, so block scripts and CSS run in an opaque origin without reaching the vault. It also opens .html and .htm files in a dedicated view that re-renders on external edits, remembers scroll position across restarts, offers find-in-document over the rendered text, and keeps application shortcuts working while focus is inside the frame. Embedded HTML files can be rendered inline from an eye toggle. Pasted HTML files are saved to a configurable location and linked as embeds, while pasted HTML content can be rendered as a live block, converted to Markdown or pasted as plain text.
