# Sporarum/every-day-calendar

Obsidian plugin that draws a year-long habit tracker from a dataviewjs code block, so it requires the Dataview plugin. The block calls the plugin's function with a year and a function mapping each date to a number, where the default reading is that one and two mean the task was not done and was done and zero marks a missing or invalid day. Colours are taken from Obsidian itself so the calendar follows the active theme, and CSS snippets can add further values and colours. The README names Simone Giertz's Every Day Calendar as the layout inspiration and Heatmap Calendar as the reason for making a plugin.
