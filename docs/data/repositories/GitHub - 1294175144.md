# vividasasana/freedraw-pdf

This repository holds Freedraw PDF, whose README describes a freehand PDF annotation workspace for Obsidian: drawing over PDF pages, adding text boxes, shapes, highlights and images, inserting blank, ruled, grid or dotted template pages, and embedding an annotated page or a selected region into a note. Annotations are said to be stored in vault-backed sidecar files so the source PDF is left unchanged, and an export flattens source pages, inserted pages and annotations into one PDF. Ink is credited to the perfect-freehand library, and the eraser is documented in object and segment modes. No upstream repository description is recorded, so this body rests on the README alone.
