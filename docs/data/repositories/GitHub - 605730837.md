# ozntel/obsidian-msg-handler

MSG Handler is an Obsidian plugin that displays and searches Outlook .msg and .eml files stored in a vault, which Obsidian otherwise only offers to hand to the operating system's default application. It adds a custom view for those two extensions and a separate search view built with Obsidian's own style classes so it resembles the built-in search. To keep searching fast the plugin watches the vault for changes to .msg and .eml files and indexes them into a database rather than re-reading each file per search, reconciling that database against the files in the vault whenever the vault is opened or the plugin loads. The README motivates the plugin with email retention policies that force important messages to be kept locally.
