# mr-flannery/obsidian-shopping-list-plugin

This plugin renders the checkboxes of the current Obsidian note as an interactive shopping list inside a code block placed anywhere in that note. The README states that the block lists every checkbox in the note, that ticking or unticking an item rewrites the underlying Markdown immediately, and that a clear-completed button removes all checked lines from the file. It records that both dash and asterisk bullets and indented items are read, that the list follows the light or dark theme through CSS variables, and that the plugin runs on desktop and mobile.
