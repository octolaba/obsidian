# MartinDampier/draw-steel-retainer

Repository for Draw Steel Retainer, an Obsidian plugin for the Draw Steel tabletop game by MCDM that manages and tracks combat encounters in an initiative tracker. The tracker opens from a scroll ribbon icon and gives the game master two tables for Draw Steel style initiative, and player characters added in settings are placed automatically into every tracker that is generated. The README lists a negotiation tracker, a montage test tracker, game-master tooltips, class-specific trackers and a monster statblock CSS snippet as features still to come.
