# mrrepac/obsidian-md-calendar

MD Calendar renders a switchable month, week, day and agenda calendar from a single md-calendar code block, whose body is a small JSON document, so all the data lives inside that one note while the rest of it stays ordinary Markdown. It handles events and tasks, recurrence, colours, notes and drag-to-reschedule, and every change made in the interface is written straight back into the block. The header offers period paging, a jump-to-date control, search across titles and descriptions, copying the visible period to the clipboard as a plain Markdown list, and toggles for completed items along with buttons to delete them or archive the past. Records whose date is missing or unreadable are not dropped but flagged for sorting out, and they round-trip into the note untouched until then.
