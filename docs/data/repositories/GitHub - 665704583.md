# YPetremann/obsidian-ruled-template

Ruled Template selects which template a newly created file gets, based on rules checked against its path. Each rule pairs a pattern — a regular expression or a glob — with a template, rules are evaluated from top to bottom and the first match wins, and the settings offer sorting arrows, quick deletion, and a test field that reports which rule a typed path matched and whether a pattern or template is invalid. The README positions it for workflows built on plugins such as Templater, Periodic Notes and Natural Language Dates, where not every journal file creation is caught by those plugins, and gives an example table matching daily, weekly, monthly, quarterly and yearly filename shapes to their templates.
