# LikeSundayLikeRain/obsidian-leetcode

Obsidian plugin for browsing, solving and taking notes on LeetCode problems inside a vault, so that each solved problem becomes a tagged and linked note. The plugin contacts leetcode.com to fetch problems and submit solutions, and the README enumerates the hosts it reaches in a network usage section. In its 1.3 architecture each solve fence renders as a self-contained CodeMirror editor inside the note whose edits are written back to the file through debounced vault writes, replacing the earlier nested-editor design, with the file as the single source of truth and the language recorded in a frontmatter field. Notes written by earlier versions migrate to the new fence tag on first open as one atomic write, after a backup sidecar that is retained for thirty days, and the migration can be turned off and run by command instead.
