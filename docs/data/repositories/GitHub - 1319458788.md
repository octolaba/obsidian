# oxilldat/oxill-forms

Oxill Forms lets a set of fields be described once and then filled in from a modal window. A form is created in the plugin settings with an identifier and a title, its fields are defined on the form's card, and an optional command runs it from the command palette. Each form does one of three things: create a new note, insert the answers as text at the cursor, or edit the properties of the current note, in which case the form opens pre-filled with the existing values. The note's name and folder are configurable, defaulting to the form title with a number appended, and because a form command is an ordinary Obsidian command it can also be triggered by other plugins or from a DataviewJS script; the interface is available in six languages.
