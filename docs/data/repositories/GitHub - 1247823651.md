# olegbrovchenko/bases-tag-colors

Bases Tag Colors gives tag pills a color palette per `.base` file in Obsidian Bases, which the README states has no native pill colors. Each base stores its colors in a sibling `.colors.json` file, so a palette travels with the base and nothing is shared globally; a key of `*` applies to any column while a specific key such as `note.status` applies to that column only and wins over `*`. Colors are edited through a settings interface with a picker, hex input and search, the active base is detected automatically, and edits apply without a restart; the README also describes migrating from the colored-bases-properties plugin.
