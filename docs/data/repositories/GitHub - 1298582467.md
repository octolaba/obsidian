# katrinasenpai/tome-reader

Tome Reader opens EPUB files from the vault in a native Obsidian tab on desktop and mobile, with four themes, typography controls in an in-reader panel, per-book reading position, bookmarks pinned above the contents list, and a table of contents rebuilt from headings when a book ships a broken one. Reading feeds notes: a selected passage plus a comment is saved as a quote with its chapter reference into a per-book note, and a selected word plus its translation is appended to a dictionary file in a line format aimed at spaced repetition. A unique fragment can also be corrected in place, which edits the EPUB file itself. An optional assistant, using a key supplied for Groq, OpenAI, OpenRouter, Anthropic or another compatible endpoint, translates or explains a selection and builds a recap from only the text before the current position.
