# ratibus11/folders2graph

Adds the vault's folder structure, and optionally the headings inside files, as nodes to the graph views. Nodes are folded and unfolded with shift-click, where a left click folds a whole subtree or reveals its direct children and a right click unfolds recursively, and folder and heading nodes can be shown or hidden independently from the command palette. Folders can be listed as included or excluded, with an option to hide excluded files entirely rather than leave them disconnected, and ctrl-clicking a folder node fills the graph search with a path filter that ctrl-clicking the root node clears. The way heading links are drawn is configurable.
