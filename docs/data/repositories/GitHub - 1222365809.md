# Yifu-Tian/obsidian-codex-workflow

Obsidian plugin that launches the Codex command-line tool from the current vault. The README describes a ribbon icon and a command that open a terminal, Windows Terminal by default, in the vault directory and pass a configurable startup prompt supporting vault path and active file path variables, plus a compact launcher panel in the right sidebar. Its stated requirements are Obsidian on desktop, a Codex CLI on the shell path and a terminal application, with both commands configurable in settings.
