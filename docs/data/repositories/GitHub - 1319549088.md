# benhancock/daily-note-icon

Daily Note Icon replaces the document icon on today's daily note tab with a solid yellow star, which stays yellow while the tab is active and darkens slightly on hover. It reads the folder and date format configured in the Daily Notes core plugin, requires that plugin to be enabled and today's note to already exist, and refreshes after file changes and at midnight. Because Obsidian exposes no public API for the icon of a built-in Markdown tab, it reaches the tab header element through a guarded reference and is written to fail quietly if a future update changes that markup. It needs desktop Obsidian 1.4.0 or newer, makes no network requests, and neither reads nor modifies note contents.
