# jkmoona/obsidian-instagram-dm-inbox

The recorded description says the plugin mirrors Instagram Business DMs into an Obsidian vault. Per the README each incoming message becomes a note carrying its timestamp, message id and a link back to the sender, each sender gets a profile note with username, a status field, editable tags and a free-form notes block, and a master canvas at the top of the CRM folder pins one column per sender with that thread's messages chained beneath in colour. Conversations live in status folders, new, pending and done by default, and move between them from a right-click picker, a direct frontmatter edit, or a trigger code appended to a reply sent from any Instagram client.
