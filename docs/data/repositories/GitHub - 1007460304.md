# jheddings/obsidian-chopro

This repository holds an Obsidian plugin that renders ChoPro code blocks, described upstream as rendering ChordPro-format chord sheets with chords positioned above the lyric line. The README lists configurable chord styling, chord normalisation, transposition of a whole file between keys or notations, rendering of chord-sheet metadata from frontmatter, and a chopro callout that transcludes song files with flow control. Commands in the palette transpose the current file and insert flow content from another file.
