# jglev/obsidian-redirect

The repository holds Obsidian Redirect, a plugin that allows aliases to be set on any file, including binary attachments rather than only Markdown notes. Its README gives the motivation as the gap between Obsidian's handling of note metadata and its handling of attachments, and records that the plugin watches Markdown files carrying a redirect entry in their YAML front matter. It notes that the plugin pairs with a binary file manager plugin that creates a Markdown file for each binary file in a vault, and it is licensed under a three-clause BSD license.
