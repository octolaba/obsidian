# bzimor/obsidian_hledger

Hledger Notes creates and manages hledger transactions inside an Obsidian vault, offering regular and exchange entries, fuzzy account-name suggestions read from a configured accounts file, automatic balance calculation, multiple currencies and shortcuts that read k as thousands and m as millions. Transactions are written into a dedicated section of the daily note whose date is detected from its filename, with a configurable date format. Separate commands export transactions from daily notes to hledger journal files and import them back for a selected date range.
