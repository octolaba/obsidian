# Jklein64/obsidian-search-exploder

Obsidian Search Exploder adds a contextual menu item to the search results view that opens each result as its own tab. The README states that it is compatible with the Vertical Tabs plugin and that it was written to separate the Continuous Mode plugin's search expansion feature into a plugin of its own, because that feature is not compatible with Vertical Tabs.
