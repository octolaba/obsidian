# CozeBoy/vault-finder

Vault Finder is a desktop-only full-text search plugin for Obsidian with optional AI-assisted keyword expansion and result handling. The README describes a right-sidebar search panel with keyboard navigation, a local MiniSearch index updated incrementally, n-gram tokenisation for mixed Chinese and English content, a match threshold slider splitting primary from lower-match results, a history tab of past queries and saved summaries, and saving an AI summary as a note. Optional vector search uses a separate embeddings API and key with a configurable cache folder, while AI enhancement over OpenAI, Anthropic or Gemini adds keyword expansion, relevance filtering and article synthesis. It states that the AI step sends the query plus paths and truncated snippets of the top hits rather than full notes, and that without keys the plugin indexes and searches locally only.
