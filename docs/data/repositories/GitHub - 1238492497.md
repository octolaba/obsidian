# TYzzt/select2obsidian

Select to Note clips selected browser content into Obsidian through a local companion pair: a browser extension for Chrome and Edge that captures by shortcut, by clicking a page element or by dragging a rectangle, and an Obsidian plugin that listens on a local port, checks a shared token and appends the captured Markdown to the active note, asking where to save when no Markdown note is open. The README states that a default token is shipped on both sides so a fresh install works without pairing, and that a regenerated token must be pasted into the extension's settings page. Translation is optional and can use the browser's built-in translator or a configured translation or language-model endpoint. The README positions the plugin for repeatedly collecting small web snippets rather than archiving whole pages.
