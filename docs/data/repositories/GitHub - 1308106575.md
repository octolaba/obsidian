# 13Green13/kcal-calc

The README describes an Obsidian plugin that scans the active Markdown note for ingredient lines, looks the foods up through USDA FoodData Central, appends kcal values and adds an underlined total. Ingredients are written one per line with a configurable delimiter and bullet lines are accepted; Markdown headings can produce per-section totals alongside the final one, and running the command again updates the annotations and replaces the previous total. Before anything is applied a preview shows each typed ingredient, the USDA food it matched, its kcal and macros, and a confidence value. The README states that a free USDA API key must be entered in the settings and is sent with each ingredient query, and that the plugin has no telemetry, advertising or automatic updates and does not reach outside the vault.
