# morgen-so/morgen-obsidian

This repository holds the Obsidian plugin for Morgen, a calendar application, connecting a vault so that its tasks can be planned, time-blocked and tracked in a calendar. Tasks are shown beside the calendar with deadlines and priorities, dragged onto it for time blocking, split into several time slots for large items, and filtered by due date and priority, while completion in Morgen writes a done date back into Obsidian and the next instance of a recurring task is scheduled automatically. The plugin side can also hide task identifiers in Obsidian task lists or replace them with an emoji. The README records the Obsidian Tasks plugin and the emoji task format as requirements, a Morgen account and desktop application as prerequisites, and support for multiple calendars including CalDAV on macOS, Windows and Linux.
