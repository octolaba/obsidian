# javalent/settings-search

Settings Search adds a global search bar to Obsidian's settings so a particular setting can be found by name, with keyboard navigation through results using the arrow keys and Enter to jump to the setting. It also exposes an API through which plugin authors can register their own settings dynamically, described in the README as three functions for adding resources, removing resources and removing a tab's resources. The README states that the project is in maintenance mode: pull requests and bugs will be reviewed, but feature requests will not be worked on, and the documentation has moved to a separate site.
