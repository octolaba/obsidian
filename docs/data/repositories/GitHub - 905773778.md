# aaaaalexis/obsidian-cupertino

aaaaalexis/obsidian-cupertino holds Cupertino, a theme that aims at a native look and feel across desktop and mobile, with touch-oriented spacing and one-hand reachability called out for the mobile case. Its stated philosophy is to need few plugins and few customizations and to let low-priority interface elements recede. Optional integrations are the Style Settings plugin, which toggles focus view, hover sidebars, the active line highlight, centred tabs and a compact status bar, and the Pseudo Mica plugin, which adds translucent window effects on Windows and macOS. The README states that Cupertino supports most filter and helper classes from the Minimal theme, including a banner class applied through an image link alias, and records the theme as a winner of Obsidian's Gems of the Year 2024.
