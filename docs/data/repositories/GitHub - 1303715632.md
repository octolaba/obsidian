# pitfa19/anatomed-obsidian

Anatomed renders interactive 3D anatomy inline in Obsidian notes: an anatomed code block produces a rotatable model showing only the structures asked for, with a legend to toggle each one and a click that opens or creates that structure's note. The catalogue is derived from Z-Anatomy and covers roughly 3,500 named structures. Rendering is always a bounded region rather than a whole body system, with graded context levels the README names isolated, related and regional.
