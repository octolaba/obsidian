# davidlandry93/obsidian-desk

Repository for Desk, an Obsidian plugin that gathers chosen notes into one view where each is laid out in the 4x6 aspect ratio typical of analog Zettelkasten systems, emulating picking up the cards for a topic and laying them on a desk. A desk opens from a ribbon icon or the create-new-desk command, and notes are filtered by outgoing links, incoming links, string, tag and directory, with a second click on an added filter turning it into an exclusion. Clicking a card expands it to the full note, and the README states that the plugin requires the Dataview plugin with JavaScript queries enabled.
