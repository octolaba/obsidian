# Ekrizdis367/obsidian-clio

Obsidian plugin that assembles a daily ritual inside the daily note. The README lists a quote of the day taken from dedicated quote blocks in the user's own vault, and optionally from blockquotes and quote callouts, chosen deterministically so it stays the same all day; a word of the day with definition and examples; on-this-day entries; the Wikipedia featured article and picture of the day; a reflection prompt; a one-line journal; daily intentions with streak tracking; and a sky card with the moon phase and sunrise and sunset. It notes that blocks written for the plugin's earlier pre-release names still work.
