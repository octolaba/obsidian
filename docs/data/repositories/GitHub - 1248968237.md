# Creative781/obsimap

Obsidian plugin for building mind maps with keyboard-centric editing: nodes are created, renamed, deleted, collapsed, reordered, multi-selected and undone, in either an outline layout or a radial one balanced around the central topic. Every action can be bound to a customisable shortcut, while drag-and-drop, free resizing and a right-click menu cover mouse use, and long-press stands in for the context menu on tablets. Nodes link to existing notes found by vault search or create new ones, an existing list inside a note can be turned into a map, and a map exports as an outline or compiles with its linked notes into one finished document.
