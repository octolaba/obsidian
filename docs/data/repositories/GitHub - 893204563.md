# gsarig/obsidian-varinote

Varinote lets variables with optional default values be defined inside an Obsidian template and their values set through a modal when a new note is created from that template. Variables are declared in a dedicated code block, one per line, as a name followed by a label and optionally a default value, and referenced in the template body through a placeholder syntax carrying the variable name. When a note is created from the template, a prompt offers each label so its value can be entered or the default kept, and the note is updated on save.
