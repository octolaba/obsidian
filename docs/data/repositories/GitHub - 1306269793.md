# SrPernax/obsidian-storyscore

StoryScore organises soundtracks, tracks and leitmotifs inside an Obsidian vault, addressed by its README to composers, audio directors, writers and creators who would otherwise keep that material in separate applications or spreadsheets. A manager view opened from the ribbon lists, plays and filters soundtracks and tracks; track cards carry an audio player beside their metadata; and a track is defined with attributes such as status, type, lyrics and a selected local audio file. A leitmotif system records musical motifs and connects them to characters, objects or places with musical annotations, and a dedicated code block embeds track cards into any note, which the README suggests for character sheets or scene notes.
