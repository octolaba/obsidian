# Lebenswille/note-copilot

This repository holds Note Copilot, an Obsidian sidebar assistant for chatting with language models about the current note, attached files and PDFs, for question answering, summarization, translation and organization. The README records Markdown, TXT and PDF as attachable context, native PDF input for OpenAI, Anthropic and Gemini, configuration of several models with quick switching and built-in presets, authentication by API key or through a local Codex login, custom shortcut prompts, per-file chat history, saving a response back into a note, and automatic inbox notes for standalone PDFs. It opens by stating that the plugin is vibe coded, and it ships English and Chinese READMEs.
