# lumargh/obsidian-calendar-list

This repository holds Calendar List, an Obsidian plugin that pulls events from the macOS Calendar app and inserts them into a note as plain text. A date range is chosen among today, tomorrow, this week, next week, this month or a custom start and end, and the matching events are inserted as a formatted list of titles, dates and times whose format is configurable. The range picker opens either inline, by typing a configurable trigger sequence in a note, or as a modal from the Insert calendar events command. The README states that the plugin is still under active development.
