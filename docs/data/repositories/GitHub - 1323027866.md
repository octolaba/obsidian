# stagars-m/full-file-extensions

Full File Extensions keeps a file's final extension visible in Obsidian's native File Explorer and hides the separate extension badge; when the row is too narrow, only the name stem is shortened with an ellipsis while the extension stays readable. Six boolean settings, all on by default, control whether the extension is shown and shaded, how extensionless names and dotfiles are treated, whether the inline rename field is left untouched, and whether a hover tooltip carries the complete filename. It changes display markup only, reading the explorer's existing path attributes, and restores the native labels when disabled. Those explorer DOM classes are not part of the public plugin API, so a future interface change may require a selector update; the plugin makes no network requests, reads no file contents and writes nothing to the vault.
