# namikaze-40p/obsidian-cliplet

Cliplet is a clipboard and snippet manager kept inside Obsidian and separate from the operating system clipboard, so several snippets can be held and pasted without overwriting the system clipboard, including on mobile where clipboard managers are limited. It keeps its own history and offers two storage methods for up to 200 items with encryption at rest: IndexedDB, held in Obsidian's internal database per vault and per device so different devices or vaults can carry different data, or a `data.json` file inside the vault, which is easy to locate and travels with vault backups, sync and version control.
