# tofrankie/obsidian-theme-gfm

tofrankie/obsidian-theme-gfm holds a GitHub Flavored Markdown theme for Obsidian, forked from krios2146's obsidian-theme-github with the Kanban styling retained and some custom settings removed. It supports light and dark modes and GFM alerts, and its settings, a Kanban style toggle and colour-blind-friendly scheme variants, are exposed through the Style Settings plugin.
