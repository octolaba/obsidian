# linem-davton/obsidian-better-mindmap

Better Mindmap renders the active Obsidian note as an interactive mind map, generated from the heading structure and bullet points of the Markdown and updated as the note is edited or another note becomes active. The view can switch between vertical top-to-bottom and horizontal left-to-right layouts and refits to the content, with sliders for rank separation between levels and node separation within a level, all reachable from a control panel inside the view. Nodes collapse and expand on a double click, a click highlights a node with its descendants, standard Markdown links inside node text navigate to other notes, and the controls follow Obsidian's theme variables.
