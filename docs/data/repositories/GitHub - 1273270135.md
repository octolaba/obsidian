# myeongsoyi/obsidian-almanac

Obsidian plugin combining a full month and week calendar view, a compact sidebar, and creation of daily notes, meeting minutes and events, which the README positions as a single replacement for using Journals, Full Calendar, QuickAdd and Commander together. In the month view each day cell lists its events by name: clicking an empty cell offers to add an event or a meeting note, clicking the date number opens that day's daily note, and an event bar can be dragged to another day, while the week view uses a time grid with start and end times. Three template files for daily notes, meetings and events ship with the plugin and are copied into the vault's Templates folder, with built-in defaults used when they are absent.
