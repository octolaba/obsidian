# yaleiyale/obsidian-emo-uploader

Obsidian plugin that uploads images and files from the editor to external hosting and inserts the resulting link into the note, triggered by pasting from the clipboard or dragging a file in. The README lists GitHub, Cloudinary, Catbox and AList as file destinations and Imgur, SM.MS, ImgURL, imgbb, chevereto and EasyImages as image hosts, so an account or key with the chosen service is required. Its interface is available in English, Simplified Chinese and Traditional Chinese.
