# tionis/obsidian-seafile-improved

Synchronizes an Obsidian vault with a self-hosted Seafile server on desktop and mobile, using Seafile's internal syncing API for delta transfers and supporting end-to-end encrypted libraries. It is a maintained fork of a community continuation, and against upstream 0.3.22 it adds realtime updates through Seafile's notification server with periodic fallback, API-token login, seafile-ignore rules, and policies deciding which Obsidian settings, plugins and plugin data travel. Conflicts are merged against the last synchronized version for Markdown, settings JSON, Canvas and Bases files, with ambiguous cases preserved as conflict copies, and transfers are verified with crash-recovery journals, mass-deletion confirmation and preflight checks. It also adds version history with per-file diffs, deleted-file recovery, whole-vault snapshots, a sync-issues centre and a sync-index rebuild.
