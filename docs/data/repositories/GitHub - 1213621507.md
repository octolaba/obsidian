# KennKyou/obsidian-kobo-note-sync

Kobo Note Sync imports highlights and annotations from a Kobo e-reader into Obsidian notes. It reads either the SQLite database written by the Kobo Desktop App or a Kobo SQLite file copied from the device to a chosen path, and writes Markdown files into a configured output folder. Note and highlight templates use Eta.js syntax and expose 23 book variables and 5 highlight variables, and syncing is append-only, so highlights already in the vault survive being deleted on the Kobo. The README states that the plugin runs on macOS and Windows, follows Obsidian's language setting for English and Traditional Chinese, and sends no reading data to any external server.
