# GOODJINC/obsidian-attachment-type-icons

Obsidian plugin that adds file-type icons to internal attachment links in the rendered view while leaving the Markdown, the file name and the link alias unchanged. It targets regular internal links and skips embedded files and previews, so a link given a human-readable display name still shows whether it opens an image, a PDF or a spreadsheet. Icon, extension list and icon position are configurable per file type, extension matching is case-insensitive, and the README states that Obsidian 1.8.7 or later is required.
