# zzzzswh/odyssey

Obsidian plugin that keeps life events as plain Markdown files in the vault and presents them in a calendar view, a map view and a replay animation. The calendar is a month grid in which single-day entries become pills and multi-day journeys stretch as bars across weeks, while the map places every entry carrying coordinates on a MapLibre map with three basemaps that need no API key. Replay takes a date range and flies a camera between the stops, tracing the past as a dotted trail; hovering an entry in one view highlights it in the other. The README states that entries stay in the vault as local files, with no accounts, no servers and no telemetry.
