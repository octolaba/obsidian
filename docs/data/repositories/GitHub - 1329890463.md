# huggzer-dev/reelleaf-obsidian

The Obsidian half of the ReelLeaf capture service: the service turns public web pages, images and videos submitted through WeChat into structured Markdown, and this plugin downloads the resulting notes from the account's cloud inbox into the vault. It syncs at startup and every five minutes, retrying with exponential backoff when the network returns, writing notes into date-named folders with attachments beside them, never overwriting an existing note and suffixing a conflict instead. Image attachments are SHA-256 verified before they are written, a repeated sync of the same cloud note is recognized as already delivered, and the access token stays in local plugin data. It is desktop only, requires an account bound with a one-time code obtained in WeChat, talks only to the ReelLeaf backend over HTTPS, and offers a free trial with paid plans.
