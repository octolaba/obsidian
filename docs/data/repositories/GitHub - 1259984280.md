# utleysam/codeblock-crbasic

Obsidian plugin that adds syntax highlighting for CRBasic, the language used by Campbell Scientific dataloggers, inside fenced code blocks carrying that language identifier. The README states that highlighting works both in editing and Live Preview through CodeMirror 6 and in Reading View through PrismJS-compatible classes, that matching is case-insensitive as the language itself is, and that the theme's own token colors are used so any theme works. Keywords, built-in functions, operators, constants, strings, comments, numbers and preprocessor directives are listed as the highlighted token types.
