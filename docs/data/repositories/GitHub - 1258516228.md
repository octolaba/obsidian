# willsho/obsidian-headings-indicator

The repository holds Headings Indicator, an Obsidian plugin that displays a heading level marker in front of each heading. The README records the marker matching the heading depth, so one hash sign precedes an H1, two an H2, three an H3 and so on up to H6. It records the indicator appearing in both Live Preview and Reading view.
