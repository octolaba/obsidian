# leonpawelzik/obsidian-tandem-comments

Tandem Comments stores review threads for a note in a single fenced block at the end of the file, each anchored to a quoted passage, so the prose itself is unchanged until an edit suggestion is accepted. A comment is made on any selection from the command palette, a hotkey or the context menu, and a sidebar lists the threads for replying, resolving, reopening, deleting and re-anchoring. Anchors follow the text as it is edited and a comment whose anchor text disappears is marked orphaned and can be reattached to a new selection. The README records per-author colours, resolving as removal by default with an optional history mode, export of a file's comments to a companion note, and a block format of plain self-describing JSON that an external assistant can read and write with file access alone.
