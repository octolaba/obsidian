# krcaljaroslav/4D-eisenhower-matrix

Collects tasks from every markdown file in the vault and lays them out in a five-quadrant Eisenhower matrix — do, decide, delegate, delete and a catch-all open quadrant — chosen by the first tag after the checkbox. It reads and writes Obsidian Tasks syntax, including tags, due, start and done dates and priority, so the markdown files stay the source of truth and the view is only a layer on top. Any quadrant expands into a kanban board with to-do, in progress, scheduled and done columns, where desktop users drag cards between columns or quadrants while mobile and tablet users change status through a card menu. Six task statuses are recognized, and task titles render internal and external links as clickable without breaking drag-to-move.
