# Jareika/obsidian-ttrpg-soundboard

TTRPG Tools - Soundboard turns a folder-based audio library into a soundboard for tabletop sessions, shown either as thumbnail tiles or a simple list per folder. Each sound can be played, stopped, looped, given its own volume, and optionally set to repeat on a delayed sequence, while overlap and exclusive playback settings decide whether sounds stack or fade out the previous ones. Files in a folder named Ambience are treated as ambience, default to looping and follow a separate ambience volume, and direct subfolders become playlists with sequential playback, next and previous controls, fade, shuffle and loop settings. For long tracks the plugin can switch above a configurable size threshold from decoding into an audio buffer to media-element playback, and thumbnails may be kept in a shared folder matched by base filename.
