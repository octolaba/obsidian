# quan-meng/paperflow

PaperFlow imports papers into Obsidian from arXiv identifiers and URLs or from a local PDF, extracting title, authors, date and abstract the same way in both cases. According to its README it downloads the PDF, creates a Markdown note in a default folder, and can generate concise sections for idea, method, limitations, future work and key sentences, reading the paper through the Claude Code or Codex command-line agents. It also adds exact-match highlights for the PDF++ plugin with configurable concepts and colors, and its import commands report progress, can be cancelled, and open the generated note when the import finishes.
