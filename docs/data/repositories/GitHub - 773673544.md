# sunbooshi/note-to-mp

Obsidian plugin that copies a note into the WeChat public account editor with its styling intact, so that formatting set in Obsidian carries over. Its README records code highlighting, code line numbers and theme background colours, and two ways of handling links, which that editor does not accept: showing the address directly or collecting the links as footnotes at the end. Themes are installed separately as an asset bundle downloaded from the plugin settings or from the release page, and its panel offers copy, refresh, image upload, draft sending, cover selection and switching between several accounts, of which the last three are described as requiring a subscription. The stated aim is faithful transfer of formatting rather than becoming an editor in itself.
