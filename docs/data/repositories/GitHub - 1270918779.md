# syw2014/obsidian-copy-to-wechat

The repository holds Copy to WeChat, an Obsidian plugin offering two copy actions for a selection or the whole note, because the WeChat chat box renders no rich text and pasted Markdown looks disordered there. The text action rewrites the Markdown into plain text tuned for that chat box: headings become bracketed titles, list markers vary by depth and indent with full-width spaces that WeChat preserves, task items become box characters, quotes and rules get their own characters, table separators collapse, emphasis is stripped, links are written as text followed by the URL in brackets, and images become a labelled placeholder. The second action renders the note with an article theme and puts a PNG image of it on the clipboard, keeping line breaks and indentation.
