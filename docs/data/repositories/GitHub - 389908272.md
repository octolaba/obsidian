# ZekunC/Obsidian-Typora-Vue-Theme

This repository holds an Obsidian theme inspired by typora-vue-theme, with Blue Topaz named as a further influence. The README states that the file style is kept as close to typora-vue-theme as possible so the two applications can be used side by side, and that dark mode is supported. Listed features include an optional snippet that replaces the bright light-mode background with a gray one, a deliberately narrow set of modified styles, header hover in both editing and reading views, current-line highlighting, and accent color changes made from Obsidian's appearance settings, with the palette given as explicit color values.
