# RuanPienaarCode/obsidian-bible-search

Bible Search provides full-text Bible search and chapter reading inside an Obsidian pane, with verse links, cross-references, highlights, bookmarks, notes, translation comparison, and optional dictionary, maps, church history, prayers, and timeline material. A setup wizard downloads selected public-domain translations and builds vault notes; network access is limited to setup or rebuild, while the finished search works locally without an account or background telemetry.
