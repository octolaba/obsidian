# Cutuchiqueno/obsidian-folgezettel-navigator

This repository holds Folgezettel Navigator, whose README describes a sidebar that draws the Folgezettel sequence of the current note and lets the reader walk it branch by branch. Continuation links are read from a frontmatter property, named folgezettel by default, in which a note lists the notes that continue it, so the plugin can show where the current note came from, where it leads and where the thread forks. The README states that the plugin was largely generated by an AI model under human review and testing, and comes with no warranty. No upstream repository description is recorded, so this body rests on the README alone.
