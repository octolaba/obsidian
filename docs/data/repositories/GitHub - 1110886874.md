# bwpge/obsidian-attachment-renamer

An Obsidian plugin for renaming attachments, described in its README as a full rewrite of a fork of reorx/obsidian-paste-image-rename. The rename dialog gains reset, skip and "don't ask again" controls, a live preview with a counter, pre-selected text and an editable full path that can create missing directories. Its templates accept single or double braces and variables such as the closest previous header, a uuid, custom values derived from the active note path and conditional separators; further options cover counter padding, space replacement, case transformation and multiple regular expressions for ignoring attachments matched against the full path. The repository has no description recorded.
