# jaewonE/icon-bullet-helper

Renders plain Markdown markers as SVG icon bullets that do not depend on the theme. The README states that a marker written in braces at the start of a list item is drawn as an icon in Live Preview and Reading view while the raw text stays visible in Source view and inside code blocks, and that a marker prefixed with an exclamation mark is drawn as a callout bullet with a solid background tint. A picker is opened by a keyboard shortcut or by typing a configured trigger after a list marker, and it inserts common markers or callout markers depending on the key used, preserving the rest of the list item including wikilinks; a further shortcut toggles a marker between the two forms. Marker labels, names and colors are customizable, and the README notes that a related plugin by the same author now offers a more complete version of this feature.
