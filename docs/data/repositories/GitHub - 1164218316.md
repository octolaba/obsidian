# iArt0s/obsidian-vinyl-catalog-tools

Vinyl Catalog Tools is an Obsidian plugin for managing a vinyl collection: adding record cards with an optional cover download, browsing them in a table view with sorting, search, open and hide actions or in a cards view with cover previews, and importing a Discogs CSV export keyed by release id with upsert and cover backfill. The README also documents exporting the collection to CSV, Markdown or a Bases file and exporting the card grid to PNG or JPEG as a single image or a multi-file grid with configurable columns, rows, aspect ratio and light or dark theme. Commands cover adding records, opening the collection, initialising folders, creating a Bases file and importing Discogs data, with all folder paths configurable and a Russian and English interface.
