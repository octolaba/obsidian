# echo-bravo-yahoo/ego-rock

Obsidian plugin that shows taskwarrior tasks in Obsidian's reading view, and requires an existing external taskwarrior installation. A task-table code block holds YAML with a command key carrying a taskwarrior command whose report name must be the last token; custom reports, filter expressions and command-line overrides are all accepted, and two configuration overrides are forced so the ASCII output can be parsed into an HTML table. A task-count block renders a count of matching tasks instead of a table.
