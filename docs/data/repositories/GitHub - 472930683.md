# der-tobi/obsidian-simple-mention

Simple Mention highlights mentions in a note and suggests existing ones while the user writes, leaving code blocks alone. The mention prefix defaults to the at sign and can be changed, and the settings also hold the colour of mentions, a separate colour and name for the user's own mentions, and a way to delete the cache. Selecting a mention opens a side pane listing every occurrence, from which the corresponding line in the document can be reached.
