# wenlzhang/obsidian-task-marker

Task Marker changes the status of a task and appends text to it, from a hotkey or the right-click context menu. Its stated motivation is that in long notes such as meeting summaries, items of differing status, whether open, completed or transferred, blend into the surrounding text and become hard to find during a review.
