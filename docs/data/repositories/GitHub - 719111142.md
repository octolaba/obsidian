# lucasvanmol/obsidian-latex-ocr

LaTeX OCR is described as generating LaTeX equations from images in the clipboard or the vault. Its README says a command pastes an equation recognized from a clipboard image into the note, and a context-menu entry converts an image already in the vault, with recognition running either through the HuggingFace inference API or locally. Using the API requires a read access token created in a HuggingFace account and entered in the plugin settings, and the README notes that the free service needs time to be provisioned before the first request. It carries a warning that the inference API path is not working because image-to-text models are unsupported there, while running locally remains supported.
