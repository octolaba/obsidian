# vkostyanetsky/ObsidianPropertyOrganizer

Property Organizer rewrites the order of properties in a note's YAML frontmatter to match a template, leaving values, property names, their casing and everything after the frontmatter untouched, and skipping the write when a note is already in order. Templates are comma-separated property lists bound to a folder; a template covers that folder and its subfolders, the first matching template in the list wins, and an empty folder path matches the whole vault as a fallback. Listed properties are written first in template order and unlisted ones follow in their original relative order, with options to create missing properties or to drop unlisted ones. Sorting runs only from two commands or, if enabled, once when the vault opens, never on note creation, edit, rename or move, and the property field suggests names from Obsidian's metadata cache.
