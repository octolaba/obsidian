# AxelReaEklund/csv-flashcard-obsidian-plugin

CSV Flashcards opens a .csv file in the vault as a flashcard deck, taking the first column as the question, the second as the answer and an optional third column as a hint. Cards are flipped by clicking, marked right or wrong with two buttons, shuffled mid-session, and any missed or skipped cards are reviewed again at the end of a session. An editing tab in the same view adds, changes and deletes cards, writing every change straight back to the original file, and a command creates a new correctly formatted CSV anywhere in the vault. Two-column exports from NotebookLM can be dropped into the vault and used as they are, since the file format is plain CSV with no deck metadata or scheduling state.
