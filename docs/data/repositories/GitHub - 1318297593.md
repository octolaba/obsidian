# Shockwave3301/encrypt-selection

Encrypts a selected passage inside a note rather than the whole file: the highlighted text is replaced by an opaque token, and the rest of the note stays plain, searchable and editable. A single-line selection becomes an inline code span and a multi-line one a fenced block, both of which render in reading view as a lock control that reveals the text in that view only, without rewriting the file. Reading a value back normally uses a peek command that decrypts into a modal, while a separate in-place command writes the plaintext back into the note for editing. Encryption is AES-256-GCM through the browser's Web Crypto API, with no external binaries or key files and support for desktop and mobile, and the cached password can be cleared from the status bar.
