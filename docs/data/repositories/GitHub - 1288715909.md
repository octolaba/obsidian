# NabheetCloud/Obsidian-Outlook-Mail-Chats-Calendar-Plugin

This plugin syncs Microsoft 365 mail, calendar events and Teams messages into a vault from a single Azure app registration, writing one note per email, per event and per conversation under a configurable target folder. Mail sync uses Graph delta queries so each run pulls only changes, maintains a thread index per subfolder and can download attachments per folder, while the calendar feature adds a sidebar pane of upcoming meetings over a rolling days-ahead window. The README states that each of the three features can be toggled independently, that authentication uses PKCE with no client secret stored and read-only scopes, and that the plugin is desktop-only because the OAuth loopback needs Node modules absent on mobile.
