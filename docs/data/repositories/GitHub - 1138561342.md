# deeplook/obsidian-sparklines

Repository for a plugin that renders inline sparklines as SVG in Obsidian notes, in paragraphs, tables and other contexts. Its README states that the numeric values may be written literally inside code blocks or pulled from frontmatter properties, with Bases and Dataview as planned sources, and points to an example vault inside the repository that has to be installed into manually.
