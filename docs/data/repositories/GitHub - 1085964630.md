# divyanshu9821/pdf-scroll-lock

This plugin addresses PDFs embedded in Markdown notes, where an embed pinned to a particular page can be scrolled away unintentionally while reading. According to its README it locks an embedded PDF against scrolling by default and adds a toolbar toggle that turns the lock on or off for each embedded PDF. The README documents manual installation only: copying main.js and manifest.json into the vault plugins folder, reloading the app, and enabling the plugin with restricted mode off.
