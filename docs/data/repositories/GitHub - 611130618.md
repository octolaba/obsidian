# Tekknoman/obsidian-prio-plugin

The Prioritize plugin marks notes or tasks in Obsidian with a priority level. The README records four actions — set priority, remove priority, increase priority and decrease priority — applied to selected text and reachable either from the command palette or from a hotkey assigned to each one. The number of priority levels and the name of each level are configured in the settings tab, where presets can be switched between or created, and the configuration is saved with a button.
