# Yiaos/obsidian-paste-image-rename-convert

Paste Image Rename Convert renames images when they are pasted into notes and can compress them to take up less space, currently supporting jpg and webp formats. The README states that it combines code from the obsidian-paste-image-rename and obsidian-paste-png-to-jpeg plugins, because the first covers renaming on paste while the second compresses but only renames automatically, and it refers readers to those projects' own documentation for usage instructions. It also records that the plugin was written with the help of Cursor and Claude and that its code readability and extensibility are limited.
