# iuga/obsidian-porygon

Porygon connects an Obsidian vault to a local Ollama model, giving a chat view with streaming Markdown replies plus agent tools that search, read, create and edit notes. It offers semantic search over the vault by meaning, long-term memory of short facts kept across sessions, reusable procedures written as Markdown skill files in the vault and loaded on demand, and the ability to pause mid-task and ask a focused question before resuming. Destructive vault actions such as creating a folder, writing or editing a note and renaming or moving files ask for approval, which can be denied with a free-form reason, and a setting auto-approves them instead. The README frames the plugin as local, private and free, and states that AI should support the workflow rather than become it.
