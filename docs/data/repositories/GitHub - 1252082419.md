# Radical7VII/obsidian-claude-code-bridge

Obsidian plugin that passes the active note and the current text selection to the Claude Code command-line tool in real time. Its bilingual README states that after enabling the plugin the user opens a terminal in the vault directory, starts the CLI and connects it to Obsidian with the ide command, after which opening a note or selecting text makes the file and selection available as context in the way an editor integration would. It states that the CLI must be started from the vault directory for workspace matching to work.
