# senna-lang/graph-context-for-claude-code

Graph Context for Claude Code is an Obsidian plugin that makes Obsidian appear in Claude Code's IDE picker, using the same lock file, localhost WebSocket and MCP protocol as its editor extensions, so the active note and the current selection are visible to Claude Code. Beyond that, the README records that a selection is shipped with its surrounding knowledge graph already expanded: embeds are inlined as the linked note's content, wikilinks become short summaries built from frontmatter and the first paragraph, and the cursor's heading path, the note's frontmatter and its backlinks travel in the same payload. The README states the expansion happens inside Obsidian using its own metadata cache link resolver rather than being pulled link by link by the model, and that the plugin is desktop-only because it runs a Node WebSocket server.
