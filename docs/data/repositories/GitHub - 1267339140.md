# groundfic/link-card-preview

Obsidian plugin that renders bare URLs as rich link cards in Reading view, Live Preview and Canvas, modelled on the link previews in Apple's own applications. The layout is chosen from the fetched image: a large card with the image on top, a compact card with a square thumbnail on the right, or a text card carrying only favicon, title and domain when there is no image, so no broken-image placeholder appears. On Canvas the native link node is left intact in the file, so disabling the plugin restores the default behaviour, while its rendering becomes a card, with icon-only sites filling the node with the dominant colour and adapting the text colour. The interface follows the Obsidian language setting for English or Traditional Chinese, and images are cached for offline use.
