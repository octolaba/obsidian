# artisticat1/arrows

Obsidian plugin that draws arrows between parts of a note, in the way arrows might be drawn across different parts of a page on paper. A start marker is an arrow identifier with a colour written in braces and the end marker is the same identifier alone, and the arrow is drawn along the margin between them; several end markers can share one start identifier. Appending a diagonal keyword to the start marker draws that arrow diagonally instead. The README states the plugin works in Live Preview mode only.
