# Rosemary1812/Sidecar-Notes

Sidecar Notes is a desktop Obsidian plugin for excerpt-based reading notes: the source note stays on the left while a workbench on the right collects quotes, comments and standalone notes. The README describes the loop it is built around — open a note, open the workbench, select text on the left, and the selection is captured as an excerpt card on the right — with the source text marked as highlight, bold, italic or not at all, according to a setting. Excerpt and note cards carry capture times and can be searched, sorted, annotated and clicked to jump back to the matching source text, long excerpts expand and collapse, and the workbench is synced into a Markdown note automatically or on demand, exporting excerpts as quote blocks or callouts with optional two-way links between the source and the exported note.
