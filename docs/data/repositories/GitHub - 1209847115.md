# PixelAnay/Engram

Engram is a sidebar chat for Obsidian that keeps a Markdown memory file describing the user's projects, habits and preferences, condensing older entries automatically as that file grows. The README states that a /memory command extracts takeaways from the current session for review in a confirmation modal while /forget opens the file for editing, and that vault search uses vector embeddings so conceptually related notes surface without matching keywords. Embeddings can come from Ollama locally, from OpenAI, or from any OpenAI-compatible embeddings endpoint, and the project states that all data stays on the user's machine.
