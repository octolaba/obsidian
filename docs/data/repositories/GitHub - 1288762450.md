# maxonamission/obsidian-parallax

Parallax is a research workbench for Obsidian that structures the thinking around searching: exploring before searching, developing a question through several theoretical lenses, weighing evidence from OpenAlex and Semantic Scholar, and keeping a methodological account of how a conclusion was reached. Every step is recorded as artefacts in the user's own notes, and the README states that a language model proposes while the user decides, with nothing written over the user's own text without asking. Inserting OpenAlex references needs no API key and no account; any OpenAI-compatible model beyond that is opt-in.
