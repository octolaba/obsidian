# wesswart77/obsidian-book-tracker

Book Tracker keeps a reading library in plain Markdown, with each book's data held in note frontmatter. A modal adds a book with title, author, genre, year, pages, status, rating, review, quotes and themes, and a sidebar library view filters by reading status — Want to Read, Reading, Finished or Abandoned — and shows a zero-to-five star rating. Theme notes are created automatically and the books that reference them are linked to them. Two commands are documented: add book and open library.
