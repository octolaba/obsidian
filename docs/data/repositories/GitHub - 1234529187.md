# Sdesuyo/obsidian-tegaki

TEGAKI converts handwritten notes, whiteboard photographs and slide screenshots into text inside an Obsidian note by sending the image to an AI vision API, the README naming Gemini Flash and Claude Haiku as the selectable engines. It extracts printed text while preserving structure and layout, and separately extracts handwritten annotations together with where they sit on the page, so a circled list, an arrow or a margin note is recorded with its position. Two commands are provided: one appends a full OCR result to the current note, the other extracts only the handwritten annotations. The README is bilingual in English and Japanese and warns that images are sent to an external provider, advising against use on confidential material, while stating that the API key is stored locally in the plugin data file.
