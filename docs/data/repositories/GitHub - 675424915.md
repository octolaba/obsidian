# dstack/obsidian-codename

Codename generates random codenames inside Obsidian. It adds a single command, Codename: Insert Codename, which generates a name and inserts it at the cursor position in the editor. The README frames it as a way to avoid getting stuck on naming: a generated name lets material be correlated immediately and renamed later, which it suggests is useful for a project whose subject is not settled yet or one being kept from prying eyes.
