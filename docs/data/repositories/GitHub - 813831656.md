# TaylorJadin/close-window-when-empty

Close Window When Empty closes the Obsidian window when the last note is closed, so that it behaves the way tabs behave in a browser. The README states the platform difference this produces: on macOS the application keeps running after the window closes, while on Windows and Linux it quits. The plugin is used simply by enabling it in the Community Plugins section of the settings.
