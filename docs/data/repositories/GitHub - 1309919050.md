# DXShelley/obsidian-tasks-datetime

Tasks Datetime is a task-management plugin for Obsidian that adds optional date and time support down to seconds, keeping date-only workflows compact while allowing more precise planning when time support is enabled. The README states that the project is independently maintained and is not affiliated with, endorsed by or supported by the upstream Obsidian Tasks project, whose date-only behaviour it treats as its compatibility baseline. It records quiet reminders with a structured reminder snapshot, recurrence presets, four-quadrant importance and urgency editing, a dashboard for filtered progress, risks, plans, saved views and bulk updates, and query support for date and time values. At the time the README was written the plugin was not yet in the community plugin directory and had to be installed by hand.
