# josipmarkus/obsidian-reveal-hidden-files

A desktop plugin that shows dot-prefixed files and folders in the File Explorer, toggled from a ribbon icon or a command, with a deny list of patterns that stay hidden. It ships denying `.git/` and `.venv/` by default, the stated reason being that vaults holding real git repositories or Python virtual environments would otherwise freeze when the toggle is flipped; entries such as `.obsidian/`, `.env/`, `.trash/` and `.DS_Store` appear when it is on. Those defaults can be removed and further patterns added in the plugin's settings.
