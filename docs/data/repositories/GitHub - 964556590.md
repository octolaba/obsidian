# zhuzhige123/obsidian---Weave

Weave builds a study loop inside Obsidian that runs from excerpt to card to review to testing, storing cards separately from the source notes while keeping a route back to the original context in Markdown block references, Canvas nodes or EPUB locations. Review is scheduled with FSRS6 over Again, Hard, Good and Easy ratings, and card types include question-and-answer, cloze, fill-in-the-blank and single or multiple choice, with progressive cloze and image occlusion listed as advanced. Cards arrive through native Obsidian editing, capture from the active document, CSV import, batch parsing or APKG import and export, which the README describes as offline migration rather than live sync. The README records Obsidian 1.7.0 as the minimum, desktop and mobile support, and an optional AI assistant using the user's own API key.
