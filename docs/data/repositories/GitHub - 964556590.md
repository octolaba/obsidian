# zhuzhige123/obsidian---Weave

Weave is an Obsidian learning plugin that connects excerpts, card creation, FSRS6 review, tests, and source tracing in one workflow. It keeps learning cards separate from Markdown, EPUB, or Canvas material while supporting multiple card types, deck views, quizzes, imports, backups, and desktop and mobile use.
