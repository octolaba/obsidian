# joeutke-dev/pin-obsidian

This plugin keeps the Obsidian window on top of all other windows, with adjustable translucency. Always-on-top is toggled from a ribbon icon or a command, and opacity is set from presets or a fine-grained slider. The README states that it is desktop-only because it reaches Electron window APIs through @electron/remote, that opacity applies to the whole Obsidian window and is supported on macOS and Windows while Linux depends on the compositor, and that both settings reset to their defaults when the plugin is disabled.
