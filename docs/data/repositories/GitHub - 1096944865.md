# imaikosuke/obsidian-today-pane

Today Pane keeps today's daily note open in the right sidebar, opening it automatically when Obsidian starts and updating the date without the manual drag-and-drop the README describes as the alternative. The note can also be opened on demand from a ribbon icon or the command palette, is created from the configured template when it does not exist yet, and is not opened twice when it is already showing. The daily notes folder, date format and template can optionally be overridden inside the plugin, and the date field in a template's frontmatter is replaced with the current date. The README states that the core Daily notes plugin must be enabled and that this plugin is designed for desktop use only.
