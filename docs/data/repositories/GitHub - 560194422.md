# valteriomon/obsidian-rapid-notes

The repository holds Rapid Notes, an Obsidian plugin that files a note into a folder at the moment it is created, choosing the folder from a prefix typed in its name. Its README records prefixes defined in the settings, a customizable escape symbol that suppresses the move, an optional separator and an optional real prefix kept in the filename, and a choice between opening an existing file or creating a numbered variant when the name is already taken. From version 1.2 the same behaviour can be triggered from the editor with the cursor inside a wikilink or over selected text, aliases included.
