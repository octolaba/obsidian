# Savar-G/taskline

Taskline is a task dashboard and quick-capture plugin that reads tasks from chosen notes, groups them into Today, Upcoming and All views, and writes changes back to Markdown. Capture parses natural language for dates, priorities, recurrence, tags and owners, while sources, headings, areas and capture routes are configured by the user; tasks can be edited, restatused and completed inline, and optional proposal rows present suggested completions or cancellations for review. The README states that the plugin creates no task notes during setup, leaving every source path, heading, route and display group under the user's control, and that it runs locally with no accounts, telemetry or network requests, with layouts and keyboard navigation for desktop and mobile.
