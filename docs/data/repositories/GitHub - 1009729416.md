# aaronsb/obsidian-mcp-plugin

The repository holds an Obsidian plugin that runs a Model Context Protocol server inside Obsidian itself, so an MCP client can read, write, search and traverse the vault without a separate Node process or a REST bridge. Its README describes eight tools, each covering a family of operations — the vault tool alone handles thirteen, among them list, read, create, search, move, split and combine — together with Dataview and Bases support and graph traversal across links, tags and backlinks. Every operation is bounded by permissions the user sets: a read-only mode, per-operation controls, and path allow and block lists. The recorded description adds that vault access is exposed through semantic operations and HTTP transport.
