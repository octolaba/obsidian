# HxWGuang/obsidian-live-preview

Obsidian plugin providing a live HTML preview, modelled on the equivalent feature in VS Code. It starts a local HTTP server that serves HTML files from their own directory so relative paths, CSS, JS, fonts and images resolve, and pushes reload signals over a WebSocket so the preview refreshes within roughly 300 milliseconds of a save. The rendered page appears in a dedicated Obsidian pane through an iframe pointed at that server, with a header button toggling between preview and the raw source and a command to open the page in the system browser. The server rejects requests that try to escape the chosen directory and moves to the next port when the configured one is busy.
