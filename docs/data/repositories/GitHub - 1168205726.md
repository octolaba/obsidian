# tednaleid/limn

Keyboard-first, offline-capable mind map application built with TypeScript, React and SVG, distributed both as a progressive web app and as an Obsidian plugin. The repository is split into a framework-agnostic core library with no React or browser dependencies, a React web application handling rendering, input and persistence, and the Obsidian package that opens the tool's own map files inside Obsidian. Its build tooling names the Obsidian plugin as the primary artifact and the web application as the one deployed to Pages.
