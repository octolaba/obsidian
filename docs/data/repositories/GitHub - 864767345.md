# jemberton/obsidian-booknav-plugin

BookNav renders book-style navigation links in a note from a code block whose language is booknav, each line parsed as an internal or external link with styling applied to links marked prev, center or next. The README states that there are no dependencies on other plugins and that a note opened in another application shows the block as a plain code block. The author's stated motivation was sharing process documentation as a vault with readers who do not know Markdown, rather than typing raw HTML navigation into every note.
