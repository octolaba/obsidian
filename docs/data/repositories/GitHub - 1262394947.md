# kaymade/alice-velvet

Alice Velvet is an Obsidian theme with dark and light modes drawn from a storybook tea-table palette: deep Onyx backgrounds, muted Wineshade panels, pale Gin Tonic text and Claret and Red Suits accents. The light mode softens the same palette into an aged-paper workspace with Onyx text and Claret details. Its README describes soft contrast, decorative headings, rounded interface details and restrained pink highlights, and names four fonts it expects to be installed locally: Cormorant Garamond for note titles, Yeseva One for headings, Nunito for body and interface text, and Emilys Candy for tags and root folder labels.
