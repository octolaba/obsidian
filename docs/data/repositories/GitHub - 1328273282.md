# NameIsKyro/compact-pinned-tabs

Pinned Tabs builds on Obsidian's own pinned-tab state and redraws pinned tabs as a compact, icon-only group at the left of each desktop tab bar, with an optional group divider and animated movement when tabs shift. Icons come from the view itself where one exists, from daily-note title detection, or from rules matching an exact note title or vault path, and any registered Obsidian or Lucide icon name or a single emoji can be used. Pins can be protected against common accidental closes, including bulk close from the tab menu, Cmd or Ctrl+W, Ctrl+F4 and middle-click, and an optional close button appears only after a configurable hover delay. Tabs are pinned through the native context-menu action, a command or an optional ribbon button, and pop-out windows and reduced-motion preferences are handled.
