# jsjixu/obsidian-inklaw-sync

Inklaw Sync pulls notes from the Inklaw service into an Obsidian vault on desktop and mobile. The README describes Inklaw as a WeChat-based service to which a video, article or link is forwarded and which downloads, transcribes and rewrites it into a note; this plugin fetches those finished notes together with their cover images and media. Its network disclosure names the single fixed backend it contacts, states that authentication uses a personal sync token from the user's own Inklaw account sent as a bearer header alongside a numeric cursor for the last note pulled, and that the inbound data is the user's own forwarded notes. It also states that the plugin only writes into the vault — never reading, scanning or uploading existing content — collects no analytics, and stores notes and media in a folder of the user's choosing.
