# Kamijoucen/obsidian-openyolo

OpenYOLO is a desktop-only Obsidian AI note assistant that connects to opencode through the Agent Client Protocol rather than bundling its own model or agent. Its sidebar supports streaming chat, tool approvals, note and file attachments, plan and build modes, model selection, session history, and optional conversation saves or AGENTS.md guidance; vault file access is validated but the local subprocess remains trusted.
