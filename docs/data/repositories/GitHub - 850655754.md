# jtprogru/obsidian-vault-full-statistics-plugin

Vault Full Statistics shows counts and ratios for notes, links, tags, sources, concepts, orphans, and overall vault quality in a status bar and side view. It also analyzes inbox health, folder and taxonomy patterns, tangles, and 30-day history, and can export history snapshots as CSV; desktop is required and mobile is unsupported.
