# israerusan/effort-index

Obsidian plugin that measures how much editing a note has cost and then surfaces expensive notes that have not been opened recently. It records active editing time, counting the spans of keystroke bursts and never the silence between them, the number of revision sessions separated by more than thirty minutes, dwell time paused when the window loses focus, and days since the note was last opened. Its read surface is a command and sidebar view listing the most expensive notes untouched for ninety days. The README places it in a suite of five plugins sharing one key and states that it works offline.
