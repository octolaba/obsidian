# fDirham/fbd-obsidian-writing-timer

A writing timer for Obsidian that keeps track of how much is written in a session. A button on the status bar opens a timer for a writing session, and when it reaches zero the number of words written is shown. The README notes that only one file is tracked at a time: the word count recorded is that of the file open when the timer starts.
