# lkh-cq/sanyuan-context-router

A desktop client for an independently run Sanyuan retrieval sidecar: it sends an explicit query or the editor selection to a user-configured endpoint, previews the returned read-injection block, and copies or inserts it into the active note. Three commands cover unconditional retrieval, retrieval that runs only when the sidecar recognizes an explicit retrieval intent, and a connectivity check, and a note can declare optional query axes in its frontmatter. The endpoint defaults to loopback and a non-loopback address requires an explicit opt-in; retrieval, embeddings, reranking and database access all run in the separate Python sidecar, which this repository does not contain.
