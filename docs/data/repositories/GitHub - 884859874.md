# Asrieal/HoverReveal

Renders text written as a bracketed pair, visible text followed by tooltip text in braces, so that the visible part appears underlined and bold and the hidden part is shown in a tooltip on hover. Two commands insert the syntax at the cursor, wrapping a selection when one exists, and move the cursor between the visible and tooltip halves of an existing occurrence; both accept custom hotkeys. Settings set the tooltip text, background and border colors and the color of the visible text, each accepting a color picker, a CSS variable or a manual value, with a reset to defaults. The README states that the plugin adapts to the theme and supports live preview.
