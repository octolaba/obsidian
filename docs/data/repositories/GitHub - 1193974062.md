# Arcadia-Studio/obsidian-arcadia-projects

An Obsidian plugin that reads the YAML frontmatter of the notes in a chosen folder and presents them as a project board: a sortable, filterable table with frontmatter columns and a drag-and-drop Kanban grouped by a status field. Moving a card writes the new status back into the note's frontmatter, notes can be created from the board with valid frontmatter, and vault edits update the views live; a text filter searches titles and properties, and cards can also be moved from a right-click or long-press menu on mobile. The README lists calendar, gallery, timeline and portfolio views, saved filter presets and CSV export as premium features still in development.
