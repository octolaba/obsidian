# ZJie-Wang/traverse

Traverse is a keyboard-driven file browser pane with vim-style motions familiar from terminal explorers: j and k move, h and l leave or enter a folder, a slash filters the current folder, and other keys search the vault, jump to the root, walk folder history or return to the note open before. The same pane creates, renames, copies, cuts, pastes and deletes files and folders, acting on a selection or on the item under the cursor, and every operation that changes the vault asks for confirmation. A toggleable preview card renders Markdown, images, audio, video, PDFs, text files, folders and Bases, is resizable within the right half of the view, and can hide itself when the workspace gets crowded. Folder notes are supported by default, with configurable location, name template and extensions, and separate keys for deleting the folder note alone or the whole folder.
