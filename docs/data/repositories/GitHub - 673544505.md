# RochaG07/anki-sync-plus

AnkiSync+ moves flashcards between Obsidian notes and Anki. It scans a selected folder to add new cards or update existing ones, and can add, update or delete individual cards from the currently open note. Decks are named from tags — the first tag found on a note becomes the deck name, with specific tags excludable from deck naming or from file scans — and the README also lists deleting the anki-id property when a card is removed in Anki, plus image and Excalidraw support in cards.
