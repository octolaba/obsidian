# 0png/Floaty-Toolbar

Floaty Toolbar shows a floating toolbar above the selection whenever text is selected in Obsidian, with buttons for bold, italic, strikethrough, inline code, highlight, links, headings from H1 to H4 and callouts; clicking a format button again removes that formatting. A pin button switches between the floating toolbar and a dock pinned to the bottom of the screen, button order can be rearranged by dragging in settings or by long-pressing a button, and the toolbar is reachable by keyboard with Tab, Enter, Space and Escape. The plugin also carries a pomodoro timer shown in the status bar or in the dock, with configurable work and break lengths and session and per-file timers, and link insertion can pick up a URL detected in the clipboard. Styling uses Obsidian CSS variables, and every formatting action is also available as a command.
