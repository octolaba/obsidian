# vkostyanetsky/ObsidianFoodiary

This repository holds Foodiary, described upstream as a food tracker plugin for Obsidian. The README says a configurable products folder holds one note per food, each carrying calories, protein, fat and carbohydrate properties given per 100 grams, with the standard aliases property usable for alternative names. Daily notes then carry a foodiary code block, added by hand or through an insert command, listing what was eaten and in what quantity so its nutritional value can be totalled.
