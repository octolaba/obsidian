# kepano/obsidian-minimal-settings

The repository holds Minimal Theme Settings, an Obsidian plugin that exposes the Minimal theme's options in the settings panel. Its README states that the theme does not require the plugin but recommends it, and that the plugin works alongside Hider for removing interface elements. Recorded settings include a choice of preset color schemes — among them Atom, Ayu, Catppuccin, Dracula, Everforest, Flexoki, Gruvbox, Nord, Solarized and Things — or a custom one built with the Style Settings plugin, plus alternate light and dark background styles that can be toggled by hotkey.
