# pan4ratte/obsidian-regex-quick-actions

Creates regex actions and applies them from the command palette, context menus, or hotkeys, to a single note or to every note in a chosen folder, with a default action available. Actions can be chained into reorderable sequences that may repeat the same action, and each saved sequence also appears in the palette and in note and folder context menus. A setting narrows actions and sequences to the currently selected text, the last executed action can be reverted, and actions and sequences can be exported and imported as a file, with export limited to desktop.
