# ArthurSrz/live-anchoring

Obsidian plugin that converts words and phrases matching existing note titles into wikilinks when typing pauses. It listens for editor changes, waits for a configurable pause of two seconds by default, collects the vault's note titles, matches the longest titles first, and applies every link in one editor transaction so the cursor and scroll position stay put and a single undo removes them all. Frontmatter, code blocks, inline code, existing links, URLs and the word the cursor sits in are never touched. Settings cover automatic or on-demand anchoring, the pause length, a minimum title length, case sensitivity, linking only the first occurrence, excluded folders and notices; the README states that the plugin reads the file names of the vault's Markdown notes to know what can become a link.
