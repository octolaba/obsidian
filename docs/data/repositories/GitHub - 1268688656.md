# aonosota/note-refactor-plus

Note Refactor Plus extracts a selection or the heading section under the cursor into a new note, splits a whole note at every heading of a chosen level, or moves everything from the cursor to the end of the note into a new file. Extraction settings, covering filename rules, destination folder, template file and frontmatter, are grouped into profiles; each profile is registered as its own command so hotkeys can be bound, and profiles are also reachable from the editor context menu. A one-step undo restores the source note and deletes the created file, Templater can be run on the new note right after creation, and existing settings from the original Note Refactor plugin can be imported as a starting profile. English and Japanese interface text follows Obsidian's locale.
