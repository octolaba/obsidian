# taggrobs/obsidian-taggr-sync

Taggr Sync moves posts both ways between an Obsidian vault and Taggr, a publishing platform on the Internet Computer. Posts pulled from a Taggr journal land as Markdown files organised into subfolders per realm, and posts written or edited in Obsidian are pushed back; a frontmatter field publishes or unpublishes a post, where unpublishing deletes it from Taggr but keeps the local file. Comments can optionally be pulled into a separate folder linked to their parent post, images are uploaded and pulled inline, and Obsidian wikilinks are converted to Taggr post links and back. The README records per-post cycle cost in frontmatter, pagination that retries on network errors, login by a seed phrase derived locally and never transmitted, and operation on desktop, iOS and Android.
