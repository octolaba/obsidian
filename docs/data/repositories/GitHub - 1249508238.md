# IvanHanloth/Obsidian-Article-Navigator

An Obsidian plugin that adds previous, next and see-also navigation driven by ordinary frontmatter properties. Links are rendered as an inline bar of cards at the bottom of a note in both Reading and Source view, as circular or full-height floating buttons inside the document area, and as a related-note list at the top or bottom; setting a previous or next property keeps the reciprocal link on the target note in sync. Newly created empty notes are seeded with the three navigation properties, optional edge double-click on desktop and half-screen taps on mobile navigate, and the interface language follows Obsidian's setting. The README states that it has no external dependencies.
