# DarkRabbits/ai-llm-search

An AI sidebar that talks to a user-configured OpenAI-compatible endpoint, including a local one, and answers questions about a selection, the current note, notes retrieved from the vault and optional web results. Vault retrieval uses a locally built BM25 index over Markdown rather than an embedding service, and only the highest-ranked excerpts are sent; the panel lists exactly which selections, notes, vault hits and web candidates went to the model, grouped by context type. Web search runs through DuckDuckGo without a key or through Tavily, a selection in the desktop Web Viewer can be asked about with the page URL as context, and keys are held in Obsidian SecretStorage rather than the plugin data file. The interface is in Simplified Chinese, and the plugin has no telemetry and no developer-operated server.
