# kaurimark/murmur

Reads a note, or just the selected text, aloud through a text-to-speech provider and highlights the spoken words in the editor as playback advances. Markdown markup is stripped and pauses are inserted around headings, paragraphs and list items before the audio is generated; playback supports pausing, skipping between segments, seeking and speeds from 0.75x to 2x. Five providers are supported, each needing its own API key, and only ElevenLabs returns character timestamps, so the others highlight on estimated timing. Generated audio is cached unencrypted inside the plugin folder up to a configurable size limit, keys are held in Obsidian's SecretStorage, and the plugin is desktop only with highlighting confined to Source mode and Live Preview.
