# SAsecurityN/SAzure-Glass

SAzure Glass is a blue-ish Obsidian theme that its README describes as inspired by the Encore, HackTheBox and Willemstadt themes. It uses big, bold headings in the Willemstadt style, green accents and a navy-and-neon note pane taken from the Hack The Box colors, over a blue-ish palette. The README states that the theme is not affiliated with or endorsed by Hack The Box, and it is MIT licensed.
