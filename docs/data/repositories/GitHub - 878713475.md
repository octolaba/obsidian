# Yaob1990/obsidian-history-today

This plugin surfaces the notes recorded on this day in earlier years, which the README presents as a Today in History view. An icon in the left sidebar opens it, and the settings choose the display language and filter which folders are considered, all of them by default. The plugin prioritizes the date created field in a note's metadata and falls back to the ctime field when that is not available.
