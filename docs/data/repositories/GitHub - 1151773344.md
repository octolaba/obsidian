# mrcnkobu/myloc

This repository holds MyLoc, an Obsidian plugin for location-aware note taking that separates presence logging, meaning logging in to and out of saved places, from inserting the current location into a note without changing presence state. Places are ordinary markdown notes under a configured root folder, each defining where the place is, its detection radius, and optional text used for inline logging and insertion. Logging in creates an active session and several places can be active at once, while every login and logout event is written both to the place note and to an automatically maintained monthly timeline; inline insertion into the current note is optional.
