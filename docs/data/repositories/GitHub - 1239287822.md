# fiddlestix27/Obsidian-SNA

Repository for a social network analysis plugin that applies graph metrics to the vault's link graph. Its README lists degree, betweenness, eigenvector, closeness, PageRank and harmonic centrality, clustering coefficients for identifying communities, optional link weighting by mention frequency, analysis of backlink direction, and a panel that shows the results with sortable metrics. It marks automatic export of the results to Markdown files as currently broken, and documents installation by cloning the repository into the vault's plugin folder.
