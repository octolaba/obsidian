# tcyeee/obsidian-day-echo

Day Echo collects the daily notes of a diary folder into one continuous, scrollable two-column timeline, opened from a calendar ribbon icon or a command. Each day is rendered as a preview card carrying a text snippet with frontmatter, code and images stripped out, lazily loaded image thumbnails and the note's tags; clicking a card opens the full note in a modal and clicking the date label opens it in the editor. A floating segmented control switches between month and year aggregation, with the year view showing representative entries plus a show-more card, while a left-hand axis, a sticky section label, running entry counts and a back-to-top button structure the scroll. When the newest entries come first the top of the timeline reflects today, offering a card that creates and opens today's note when it does not exist, and a previous and next bar is injected into date-named daily notes.
