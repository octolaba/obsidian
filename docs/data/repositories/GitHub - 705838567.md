# Superschnizel/obsidian-fast-text-color

Colours text through a custom inline syntax that wraps a section between tilde-equals delimiters and an identifier, where the identifier maps to a format defined by the currently active theme. A format can combine a colour with bold, italics, underline, overline, strikethrough, full caps and small caps, all applied through CSS classes, so changing a format updates every section already marked with that identifier. Formats are bundled into themes selected in the settings, and a note can override the active theme through a frontmatter property. The README states that colouring can be applied and removed from the editor in several ways including keyboard only, that live preview is supported, and that no HTML is exposed in the editing view.
