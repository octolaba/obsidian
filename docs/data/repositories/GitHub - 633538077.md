# kamoshi/obsidian-markdoc

This plugin enables editing mdoc files inside Obsidian and adds basic syntax highlighting for Markdoc tags. The README states that Markdoc files then appear in the Obsidian file explorer and can be edited like any other Markdown file, and it describes manual installation by copying the manifest, the main script and the stylesheet into a subdirectory of the vault's configuration folder.
