# Grayvox/obsidian-character-sheets

Generates character sheet notes for writing, from templates the plugin ships. The README describes pressing a Create new character sheet button on the ribbon, choosing which kind of sheet to generate, and finding the result in a Characters folder that the plugin creates, already filled with the basic fields to edit. It states the plugin has been tested on Windows and Linux and that mobile support is not planned unless many users ask for it; the rest of the README is the author's account of why the plugin exists, written jokingly.
