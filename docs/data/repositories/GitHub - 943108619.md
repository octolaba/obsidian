# danferns/obsidian-wordcraft

WordCraft looks up rhymes, synonyms and describing words from inside Obsidian, aimed at songwriting and poetry. Its four search modes cover words meaning something like the query, words that rhyme with it including near rhymes, nouns described by an adjective, and adjectives that describe a noun; clicking a result repeats the search on it, with the noun and adjective modes swapping. Results can be skewed towards a few themes and filtered by syllabic stress pattern, written with slash and x for stressed and unstressed syllables. The README states that the plugin uses the free Datamuse API and needs an internet connection to work.
