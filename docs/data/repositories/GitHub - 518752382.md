# samuelsong70/obsidian-dynamic-background

Obsidian plugin that adds dynamic effects, static wallpapers, or both to the Obsidian background. It ships five effects for the dark theme, a digital rain, rain, random circles, snow and a star sky, and two for the light theme, random circles and a wave. The README documents opening the plugin's settings from the community plugins group, enabling or disabling the effect at any time, and choosing among the available effects.
