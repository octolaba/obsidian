# sgranade/manuscriptum

Manuscriptum is an Obsidian plugin for short-story writers that exports stories as Microsoft Word .docx files in the Shunn modern manuscript format for submission to magazines or agents. Each story lives in its own folder whose name is the title, written either as one note or as several notes combined as scenes with scene breaks between them, and anonymous manuscripts can be produced automatically. Author name, surname and contact information come from plugin settings and can be overridden per story through note properties such as title, filename, outdir and author. The README warns that a plugin changing the file explorer's manual sort order breaks the scene ordering it relies on.
