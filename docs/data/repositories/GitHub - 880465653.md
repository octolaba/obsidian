# clairefro/obsidian-plugin-chronos

Renders interactive timelines inside Obsidian notes from Markdown written in a chronos code block, where each item carries a single date or a date range and a label. The README states that the rendering comes from a Markdown wrapper around the vis-timeline library, and lists grouping, colours, note linking, an Obsidian Bases view, and the ability to render the same plain-text items outside Obsidian. Blank, basic and advanced templates are inserted from the command palette, a Generate command turns highlighted text or a vague prompt into timeline items through a language model, and a further command combines all timeline items found in a folder into one timeline.
