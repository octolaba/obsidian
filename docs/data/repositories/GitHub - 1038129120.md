# coignard/obsidian-timestamper

Timestamper adds one command that inserts the current time into a note, aimed by its README at logging and journaling in daily notes. The timestamp format is configurable, defaulting to a level-one heading with hours and minutes, and insertion happens either at the end of the document or at the first empty line below the cursor. Options can open today's daily note first when the command is run from another file, and can scroll to the bottom of the note after insertion.
