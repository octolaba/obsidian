# west-shell/obsidian-xiangqi

Renders Chinese chess (xiangqi) positions and games inside Obsidian from FEN and PGN, with move exploration and variation management. The plugin registers a dedicated view for `.pgn` files that shows an interactive board, a clickable variation tree, comments and annotation symbols, and writes changes back to the file when the save button is used. Analysis runs on a bundled Pikafish WASM engine, offering single-position, batch and automatic modes, and voice narration is listed among the features. The README notes that a `.pgn` file may hold only one game, multi-game files being converted into code blocks instead.
