# west-shell/obsidian-xiangqi

Xiangqi is an Obsidian plugin for rendering and exploring Chinese chess games, including PGN files, board positions, variation trees, and engine analysis. It provides interactive boards, editable game annotations, customizable FEN and game code blocks, configurable board presentation, and desktop and mobile-oriented controls.
