# MjavadH/PrayerChime

PrayerChime shows Islamic prayer times for cities in Iran inside Obsidian, calculating them locally from a bundled Iranian city dataset and built-in solar calculations, so no external prayer-time API is required for normal use. The README records a ribbon action that opens a dedicated right-sidebar view carrying today's Persian date, the selected city, the prayer-time list, the next time and a countdown, plus a status bar item that can show the next upcoming prayer time. Its interface is Persian and right-to-left, and the recorded settings cover city search across city, county or province and state names, favourite cities, a calculation method chosen from Tehran, Jafari, ISNA, MWL and Umm al-Qura, and the warning interval before the approaching state.
