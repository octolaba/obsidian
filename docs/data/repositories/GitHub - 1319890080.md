# quiachonj/molren

Molren renders chemical structures from fenced code blocks: a smiles block draws one structure per line with an optional caption, mol and sdf blocks take molfile and multi-record SDF input, rxn draws reaction SMILES as full-width rows, and chem auto-detects which of those the content is. Drawing is done by RDKit.js running locally, with stereo bonds and R/S or E/Z labels added automatically and toggleable in settings, so structures stay as plain searchable text in the note while the picture is generated on the fly. The plugin is desktop-only and requires Obsidian 1.4.0 or later.
