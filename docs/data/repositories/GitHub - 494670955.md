# Wanxp/obsidian-douban

Obsidian plugin that pulls data from Douban into a Markdown file. Its README lists importing films, television series, books, music, games and diary entries, and synchronising a personal record of what has been watched, read or played together with ratings, dates, comments and reading status. Covers can be saved locally or to an image host, templates, import paths and other parameters are configurable, a Douban account is optional and needed only for part of the functionality, and import on mobile is supported. Searching is started from the command palette, and the README is written in Chinese with an English version linked from it.
