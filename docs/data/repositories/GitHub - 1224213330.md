# bobhy/vault-share

Vault Share shares all or part of an Obsidian vault with several devices through a folder in Google Drive. The README says changes on one device are uploaded quickly but propagated to other devices lazily or on demand, so bandwidth is conserved while the latest version of a file is fetched when it is opened, and the Drive copy doubles as a backup. Setup covers the Drive folder path, which the plugin creates on first use, a conflict resolution mode, and an OAuth login to a Google account that persists across sessions. On conflict the plugin can keep the newer file by modification time or keep both, renamed to record the vault each came from.
