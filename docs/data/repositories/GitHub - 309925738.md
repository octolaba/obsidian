# aviskase/obsidian-link-indexer

The repository holds obsidian-link-indexer, a plugin that generates index notes listing links according to configured conditions. Its README describes settings presets, each of which adds its own command to the palette, and a used-links report that counts how many notes link to each target, including targets that do not exist as files. Output options recorded there include counting embeds, and the README carries the author's warning that the plugin is no longer used by its maintainer; the code is released under the Unlicense.
