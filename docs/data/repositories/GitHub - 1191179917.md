# lylaminju/weekly-routine-planner

Plans recurring weekly routines through a timetable-style editor driven by a fenced `weekly-routine` block. The plugin writes only inside the note's marked routine region, storing each routine as a line carrying an event id, day, time range, title and category tag, so the rest of the note stays untouched. Categories are added, renamed, recoloured and deleted from the timetable toolbar and live in the plugin's settings rather than in the note, with renames and deletions propagated to matching tags. Start hour, end hour and hour height are settings, and the README states the plugin is desktop-only and meant for recurring structure rather than dated calendar events.
