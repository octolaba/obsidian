# fengshuzi/quick-page

Quick Page Creator adds a plus button to the Obsidian sidebar that creates a note in the pages folder and opens it, with the same action available from the command palette. The new file is named from a timestamp in yyyymmddhhmm form. Its README states that the pages folder layout is compatible with the one Logseq uses, which suits a vault worked on from both applications.
