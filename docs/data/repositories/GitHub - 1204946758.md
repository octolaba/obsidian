# dandele/obsidian-atom-creator

SuperTags creates a structured note whenever a tagged line appears in a watched folder: after a short pause the line is replaced with a link to the new note, which is written into a configured folder from a template that supplies its frontmatter and body, and an undo notice is offered. The README describes any number of independent supertags, each with its own tag, target folder and template — its examples cover evergreen, project, person and meeting notes — and says every supertag renders as a coloured chip in the editor. The recorded description states that the plugin works on all devices through Obsidian Sync.
