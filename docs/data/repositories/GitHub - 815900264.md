# Quorafind/Obsidian-Node-Auto-Resize

Canvas Node Auto Resize is an Obsidian plugin that resizes a canvas node to fit its content as that content is edited in the canvas view. Its settings enable automatic width resizing and set a maximum width. The README gives BRAT, the Beta Reviewer's Auto-update Tool, as an installation route alongside manual installation from the release archive or its individual files.
