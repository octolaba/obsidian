# 9r0x/obsidian-dashing-cursor

Obsidian plugin that adds a dashing effect between cursor positions. The README records it as initially a fork of ninja-cursor that was mostly rewritten, and names three differences: it animates only between cursor jumps rather than the selection range, it supports scrolling so the cursor follows the page position, and it simplifies the code and the CSS animation logic.
