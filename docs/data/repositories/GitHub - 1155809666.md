# alexh/umi-obsidian-theme

This repository holds Utility Materials, an Obsidian theme modeled on the visual language of a New York clothing brand of the same name and built for dense notes and technical writing. It uses dark greys, high contrast and a restrained industrial orange that the README says appears only where meaning changes, at links, highlights and selection states, with no gradients or glow. The theme expects the Monaspace Krypton Frozen font to be installed locally and falls back to other Monaspace variants or the system monospace, and it credits the Wasp Obsidian theme as a partial basis.
