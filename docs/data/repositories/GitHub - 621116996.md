# ericaxu/gemmy

This repository holds Gemmy, whose README introduces it as an Obsidian assistant deliberately built to be unhelpful. Two behaviours are documented: saying things at random on a configurable interval, and a writing mode in which the character appears once typing has stopped for a configurable length of time. The README lists four commands in the palette and notes that the code is MIT-licensed while the character artwork carries a Creative Commons licence. No upstream repository description is recorded, so this body rests on the README alone.
