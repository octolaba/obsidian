# MartinForReal/okf-enforcer

Obsidian plugin that validates a vault against the Open Knowledge Format, a convention for holding knowledge as Markdown files whose frontmatter parses and carries a non-empty type. Hard rules are reported as errors and the specification's recommended fields as warnings that can be switched off, while its permissive rules are respected, so broken links and missing optional fields never fail a bundle. Opt-in checks cover the provenance, trust and lifecycle families — generation and verification actors, status values, an absolute review-due date and whether it has passed, and source credibility signals — with the derived trust tier shown in the status bar tooltip. A migration command rewrites legacy fields into the newer shape, and a collapsible side panel lists every non-conformant note grouped by its folder, errors first, with a summary of conformant, error and warning counts.
