# mihirpatel1112/better-flashcards

Better Flashcards synchronises Obsidian notes with Anki, generating cards from note syntax: `#card` for simple cards, `#card-reverse` for reversed ones, `#card-spaced` for spaced-only cards, `Question::Answer` and `Question:::Answer` for inline forms, and highlights or curly brackets for cloze deletions. It supports a context-aware mode, global and local tags, LaTeX, images, audio, Obsidian URIs, references back to the note and code syntax highlighting, and covers insertion, update and deletion of cards. The README states the plugin is a fork of reuseman/flashcards-obsidian by Alex Colucci and Noah Rousell, maintained with bug fixes and small tweaks, and points to that project's wiki for the details.
