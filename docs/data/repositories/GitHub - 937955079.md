# d7sd6u/obsidian-crosslink-advanced

Crosslink Advanced adds commands for vaults organized around ftags, the file-tag notes the author's related plugins describe. Its commands remove an inbox tag such as Uncategorized from a file, add an ftag to a note and drop the inbox tag automatically, open a random note still carrying the inbox tag, create a new note whose ftag is the current file — converting that file into a folder note — and rename the current file while keeping its former name as an alias. The recorded README defines no settings and points to the author's other plugins for the surrounding ftag machinery.
