# SoulBits-Vibe/Obsidian-Auto-Move-On-Property

An Obsidian plugin that moves notes into folders according to their YAML frontmatter values. Each move rule pairs a property name and a value with a destination folder, and matching works both for a single-value property and for a value inside a YAML list. It watches the vault root and any additional folders named in settings, which also control move notifications and debug notices while rules are checked.
