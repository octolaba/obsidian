# kuvanov-2/obsidian-docbase

Repository for an unofficial DocBase plugin for Obsidian that pulls notes from a DocBase team and pushes them back. Settings take an API token and the team domain, and a note carrying a `docbase_note_id` property is filled or updated with the title, tags, draft status and content of the matching DocBase note when the pull command runs. The README cautions that pushing works only for notes already posted to DocBase and overwrites the remote title, tags, draft status and content, so pulling first is recommended, and it lists handling of multiple DocBase teams as not yet implemented.
