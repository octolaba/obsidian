# J-Barta/qb-reader-parser

This plugin parses quiz bowl tossups from QB Reader into a format that the Obsidian_to_Anki plugin can read. The README states that a QB Reader command opens a dialog for querying the QB Reader API, that returned sentences are separated by highlights, and that clicking a sentence parses it into a form ready for Anki; the answerline categories selected by default are set in the plugin settings. Its default conversion of clues to cards uses highlighting because that is easiest to read in Obsidian, which the README says requires the Cloze Paragraph styles of Obsidian_to_Anki, alongside Anki with the AnkiConnect add-on and a configured target deck.
