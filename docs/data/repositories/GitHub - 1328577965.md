# Sto3IV/Neon-Night

Neon Night is a dark Obsidian theme that assigns a fixed color to each kind of markup, separating sequential from general lists: cyan for headings and unordered lists, mint green for numbered lists, acid lime for italic text and neon yellow for highlighted text. Tables, inline code and code blocks are styled from the same small palette against a near-black ground. The theme is installed from the community theme browser in Obsidian's appearance settings.
