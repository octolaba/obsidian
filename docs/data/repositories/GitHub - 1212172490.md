# stephanteig/obsidian-color-preview

Obsidian plugin that renders hex color codes as interactive color cards. The README describes a fenced color block in which only the hex value is required, with RGB and CMYK approximated when omitted, palette blocks showing a whole palette as a strip of swatches, and small color dots beside any hex code in a note. Clicking a swatch opens the color picker and updates the hex in place, clicking a value copies it, and the underlying markdown stays readable as plain text when exported.
