# 30jannik06/Obsidian-TreeGen

Builds a text rendering of the vault's folder and file structure and copies it to the clipboard. A right sidebar panel shows the tree interactively with file counts per folder, a search box that filters and highlights matches, expand and collapse controls, and per-folder copy buttons; clicking a file opens it. The output can be produced as an indented tree in one of five line styles, as a flat list of paths, or as nested JSON, and a folder in the file explorer can be copied directly from its context menu. Maximum depth, excluded names, tree style, root label and whether files are listed at all are configurable.
