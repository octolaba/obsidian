# izz4n/obsidian-calendar-clock-plugin

A small plugin that injects a live clock at the top of the panel drawn by Liam Cain's Calendar plugin. The README states that Calendar must be installed and enabled for the clock to appear, since this is a companion UI extension rather than a standalone view, and that it needs no configuration to work. A setting switches the clock between 24-hour and 12-hour display.
