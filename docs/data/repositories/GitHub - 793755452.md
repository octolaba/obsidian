# alberti42/obsidian-import-attachments-plus

Handles files brought into the vault by drag-and-drop or copy-and-paste, moving or copying them in and inserting them as an embed or as a link. Attachment folders are configured with paths relative to the note's location, and imported files are renamed according to a naming convention with date formats. Attachment folders can be renamed and deleted automatically, with an optional confirmation before deletion, and their visibility in the file explorer can be toggled. Opening an attachment in the default external application or revealing it in the system file manager is available as well.
