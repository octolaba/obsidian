# wulflo/obsidian-BlackAndWhite

Black and White is a monochrome Obsidian theme built from whites and deep charcoal shades. Its README documents styled highlights, a flashcard effect in which tagging a line marks it with a distinct treatment for active recall, a collage value in the cssclasses note property that renders Dataview query results as cards, and a grouped-callout pattern using a custom callout type. The author states that the theme was tested for personal use and may not be compatible with certain plugins. The credits record inspiration from the Minimal, Vicious and Prism themes and the inclusion of parts of the Cards and MultiColumn snippets.
