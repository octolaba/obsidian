# lumelab-ai/tnrapp-tnr

TNR - Track n Review searches TMDB for films, series and people and inserts a card at the cursor position. Three commands cover adding a title, adding a title together with a cast carousel, and adding a person; cards carry poster, year, director, genres, running time, country and synopsis, and a query such as Lost s01e03 resolves straight to a season or an episode. It needs Obsidian 1.13.0 or newer and a free TMDB account, and both its interface and the TMDB data are localized in Brazilian Portuguese and English. Pointing it at an exported profile folder from the Track 'n' Review iPhone app, which it only reads, adds memory statistics such as an average rating to person cards.
