# CosmicSeaFox/Forgotten-Golden-Sanctuary

Forgotten Golden Sanctuary is a handcrafted Obsidian theme built on a warm archive palette: deep backgrounds with parchment text and antique gold accents in dark mode, and soft parchment surfaces with golden highlights in light mode. Headings are set in Cinzel, with Cinzel Decorative for titles, Inter for body text and JetBrains Mono for code. Styling covers reading and source modes, properties, tables, code blocks, callouts, tags, checkboxes and the graph view, which is treated as a golden constellation. The layout is responsive and the theme is offered for both desktop and mobile.
