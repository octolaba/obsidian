# TimDommett/Remarkable-Sync---Obsidian-Plugin

Syncs documents from a reMarkable Paper Pro to an Obsidian vault as PDFs, connecting to the reMarkable Cloud API directly. The rendering covers all nine pen types with calibrated colors, widths and opacity, fourteen colors including shader and highlighter, and text with paragraph styles. The README states that the plugin is unofficial and not affiliated with, endorsed by, or supported by reMarkable AS.
