# CuriousAbe/obsidian-vault-encryptor

Vault Encryptor is a manual-first Obsidian plugin that encrypts files into an .enc form using AES-256-GCM with PBKDF2-SHA256 at a fixed 210000 iterations. The README documents a command for encrypting the current file and file-explorer context entries for encrypting or decrypting a single file or a folder recursively, with encrypted files opening in a blocked placeholder view that cannot be edited directly. It states that encryption writes the .enc file and then deletes the plaintext, that decryption reverses this, and that an existing output path causes the operation to fail rather than overwrite, leaving the conflict to be resolved by hand.
