# TsFreddie/obsidian-ugreen-sync

UGREEN NAS Sync synchronizes a vault with a UGREEN network storage device running UGOS Pro, logging in through a direct UGOS address or a UGREENlink identifier. Two-way sync always covers the whole vault and can be started from the status bar, the command palette or the settings tab, with optional automatic runs on an interval between one and sixty minutes. The README states that the first sync never treats missing files as deletions because no prior state exists, that later syncs use local history to detect them, that remote deletions go to the UGOS trash rather than being permanent, and that when both sides changed differently a local conflict copy is kept before the remote file is downloaded. It records that only UGREEN devices are supported and that encryption, multiple providers, OAuth and the common cloud protocols are out of scope.
