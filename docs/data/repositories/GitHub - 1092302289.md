# rzbin/date-picker

Adds a visual date picker to Obsidian: next to a link containing a date, a calendar icon opens a calendar view for modifying that date. Commands insert today's date at the cursor position, insert it as a link, and open the picker when the cursor touches a date link. The format of inserted and detected dates is configured with Moment.js formatting.
