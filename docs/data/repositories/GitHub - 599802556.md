# sergey900553/obsidian_dekurai_theme

Dekurai is an Obsidian theme its author presents as combining clean colours, minimalism and functionality, and describes technically as version 2.0 of the same author's Dark Moss theme. Its stated priority is that editing and reading mode stay consistent, so that switching between them causes no confusion. The README also lists search highlighting drawn as a coloured background rather than Obsidian's frame, with an underscore used in preview mode where that background is not possible, a line counter in code display, and a visible indication of which file holds focus during a multiple selection of files.
