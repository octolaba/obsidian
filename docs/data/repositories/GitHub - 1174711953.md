# petersolopov/obsidian-claude-ide

Obsidian plugin described in its README as a minimal bridge that shares real-time editor context with the Claude Code command-line tool. It states that an MCP server runs over WebSocket inside Obsidian, that Claude Code discovers it and lists Obsidian in the ide selector, and that once connected it can see open files and the current selection, while a Send to Claude command passes selected text explicitly. Edits are made through the filesystem with no diff view, and the server is stated to bind to localhost (127.0.0.1) with a per-session token.
