# RakushkaTOP/obsidian-auto-index

An Obsidian plugin that generates and maintains index notes for chosen folders, listing files and subfolders recursively as a tree. Watched folders are configured one per line, and the index is refreshed on a configurable interval whose default the README gives as three seconds. Formatting options cover an emoji or text prefix before folder names and whether folder names are rendered in bold.
