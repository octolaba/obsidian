# penfieldlabs/obsidian-wikilink-types

Adds typed relationships to Obsidian wikilinks: typing an at sign inside a link alias opens an autocomplete of configured relationship types, and on save every matching type is written into YAML frontmatter as its own entry pointing at the linked note. The README describes the at-sign syntax as the authoring interface and the frontmatter as the storage and compatibility layer, so Dataview, Graph Link Types, Breadcrumbs and similar tools can consume the relationships without changes. The marker must follow a space or come right after the alias separator, several types may appear in one link, and display text that matches no configured type is left alone.
