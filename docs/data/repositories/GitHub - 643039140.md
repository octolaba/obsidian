# xHayden/obsidian-mochi-cards-pro

Mochi Cards Pro creates flashcards on Mochi from Obsidian using the API that Mochi's Pro subscription provides, so the README states it works only with a Mochi Pro account and an API key entered in the plugin settings. Cards are written in the note as a first-level heading for the card name followed by its content, which may include Markdown and LaTeX, and several cards can be exported at once. Exporting means selecting the cards, opening the command picker, choosing the export command and following the prompts; the README stresses that the cards to export must be highlighted. It also records the only Mochi template shape the plugin works with.
