# banisterious/obsidian-custom-selected-word-count

Custom Selected Word Count analyses the selected text across view modes and Canvas cards, reporting word, character and sentence counts. The count is reached from the command palette, an optional ribbon button, or a status-bar item that can also update live as the selection changes, and a modal presents the metrics with per-metric copy buttons and a history of previous counts. Exclusion rules omit code, paths, comments, headings and specific words or phrases, can be overridden per note, and word detection can be redefined with a regular expression; links are counted by their visible text only.
