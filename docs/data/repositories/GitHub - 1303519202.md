# alanqin888/obsidian-pdf-mermaid-fix

MD Export Pro adds an Export to PDF (Mermaid Fix) command that keeps wide Mermaid diagrams, such as sequence diagrams, from being cut off horizontally by Obsidian's native PDF export. Running it temporarily injects a print media CSS rule that scales Mermaid SVG elements to the page width and prevents page breaks inside them, then opens Obsidian's own PDF export dialog. The command is reachable from the file explorer context menu or by right-clicking in the editor.
