# ocuclaw/obsidian-wayfinder

Wayfinder Maps renders wayfinder maps held in a GitHub repository's issues inside Obsidian: each map issue becomes a head card with its tickets arranged in a dependency-layered tree drawn from GitHub's native blocked-by issue dependencies. A tally bar counts open and total tickets per type together with takeable, need-you and agent-ready chips, maps can be filtered by repository and by completion, and tree, list and hybrid display modes are offered with list as the mobile default. Ticket state is shown visually: the frontier of open, verified unblocked and unassigned tickets is flagged, blocked tickets are dashed and name their open blockers, and resolved tickets are dimmed. The README states that the wayfinder methodology itself comes from a separate skills repository and that plugin 1.x is aligned to its v1.1.0 release.
