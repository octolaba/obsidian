# x5gtrn/kindle-bridge

Kindle Bridge fetches Kindle highlights and notes from Amazon's notebook pages and writes one Markdown note per book, confining its output to a delimited plugin-managed section. Sync is differential, re-fetching only books Amazon reports as annotated since the last run, and removals propagate: a highlight deleted at Amazon disappears on the next sync, while a book gone from the library is flagged with a banner rather than deleted. Syncing runs from the command palette or ribbon, and optionally on startup, on an interval, or with a summary line appended to an existing Daily Note. It is desktop-only, needs Obsidian 1.4.4 or later and an installed Chromium-based browser launched as a separate process for sign-in and page fetches, and states that it is not affiliated with Amazon.
