# JunweiHu0/obsidian-google-translate

Translates the current text selection and shows the result in a read-only side panel, with no input box and no button: selecting text in a note triggers a debounced translation and the panel shows only the translation, with detected source and target language in a compact header. Line-break merging repairs the broken wrapping that PDFs and papers leave behind so a paragraph is translated as one block while genuine paragraph breaks are kept. A lock button freezes the current translation, a copy button copies it, and a local cache serves repeated selections and target-language switches instead of spending quota, optionally persisting across restarts. The README states that a Google Cloud Translation API key is required and that a tester in the settings tab verifies connectivity without spending translation quota.
