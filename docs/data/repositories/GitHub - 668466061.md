# maskdotdev/obsidian-harpoon

This plugin manages a short list of favourite files and jumps between them, and the README describes it as a port of the Harpoon plugin for Neovim. No repository description is recorded, so this body rests on the README alone. Its commands open a modal listing the hooked files, add the active file to that list, which holds at most four entries, and go straight to entry one through four. Inside the modal the README documents keys borrowed from vim, where `dd` removes a file, `p` and `Shift + p` re-insert the last removed one and `J` and `K` move the selection, and it notes that the list is kept in a `harpoon-config.json` file in the vault.
