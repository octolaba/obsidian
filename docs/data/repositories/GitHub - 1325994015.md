# ssjy1919/obsidian-tasks-custom-date

Writes created, completion and cancelled timestamps onto task lines as their state changes, using a per-state format template in which a placeholder becomes the current time; a template without that placeholder is written literally. Which tasks are affected is limited by a trigger tag or text, or opened to every task when the field is left empty, and a separate trigger controls which tasks cycle through states. Beyond the standard incomplete and done states, any number of intermediate states can be defined with a name and a marker character, and the order of that list becomes the click cycle. All timestamp fields share one time format, chosen from presets or a custom moment format with a live preview, and commands create or edit a task, toggle it, and insert a created-time field.
