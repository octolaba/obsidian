# Lavton/obsidian-connections-to-tag

Helps collect the notes of one subtopic out of a larger vault, by gathering them in a folder, marking them with a tag, and then viewing only those notes in the graph. Notes are added either globally from a search query, which suits vaults where topics are marked by hashtags or folders, or locally by following links between notes, which the README presents as the plugin's main strength for tree-shaped vaults. The README also points at the author's Ignore Filters Boost plugin for excluding everything outside the focused folder. No repository description is recorded, so this note is grounded in the README alone.
