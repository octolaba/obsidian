# Habit-Labs/Sharetron

Sharetron hands an Obsidian note to the operating system's native share sheet, either as the original Markdown file or as a PDF. The README states that the PDF is rendered with Obsidian's own Markdown renderer and printed to a text-based file with selectable text and embedded images, and that sharing can be triggered from the ribbon, the editor toolbar, the file and editor context menus or the command palette. Its platform table records Markdown and PDF sharing on macOS, Markdown sharing on iOS through the web share API, and no support on Windows, Linux or Android, because the desktop share sheet uses a macOS-only Electron API. The README also records that the plugin makes no network calls, bundles no third-party libraries, does not touch the clipboard, and writes shared PDFs to the temporary directory with owner-only permissions, cleaning up files older than an hour on the next load.
