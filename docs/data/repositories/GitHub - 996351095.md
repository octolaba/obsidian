# trevware/obsidian-sidebar-highlights

Sidebar Highlights collects highlights, comments and tasks from across a vault into a sidebar view. Comments attach to a highlight through Obsidian's own footnote syntax, either as a numbered footnote or as an inline footnote, several comment kinds may be combined on one highlight, and standalone Obsidian comments also appear in the sidebar. Tasks are detected across the vault from checkbox syntax, with natural language due dates, grouping by due date under contextual labels, filtering by completion, flag or due date, indented context shown below a task, and a flag for priority. Highlights can be grouped by colour, date, folder, collection, filename or due date, organised into collections spanning several files, and saved as display modes, and the README records five highlight colours and Simplified Chinese localisation.
