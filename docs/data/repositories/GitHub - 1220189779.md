# Tashihiki/action-deck

Adds a launcher panel to Obsidian's right sidebar whose buttons each run one Obsidian command in a single click, aimed at pointer and touch use rather than the command palette. Buttons are configured in settings with an icon, a tooltip label and a command chosen through an autocomplete over command IDs, and they appear immediately without a reload. Icons may be emoji, Lucide names, images from the vault or a URL, or raw SVG, and buttons can be sorted into named, reorderable groups. Deleted buttons and groups can be restored from a history, icon size is adjustable, and the interface follows Obsidian's language setting for English and Japanese.
