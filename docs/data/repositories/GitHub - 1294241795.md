# fahera-mx/obsidian.alissa.app

Alissa Sync mirrors an Alissa vault into Obsidian, writing projects, tasks, context, deliverables and entities as wikilinked Markdown refreshed from a ribbon button. Setup is an API token pasted into the plugin settings plus a target subfolder, which defaults to Alissa. The README states that the token is stored locally and never logged, that the plugin talks only to the configured Alissa API base over HTTPS, and that the source of truth lives in a private monorepo, so code pull requests cannot be merged here.
