# PleiadesM/Tufte-Sidenote

Tufte Sidenotes renders footnote references and sidenote and marginnote callouts as Tufte-style sidenotes in the margin gutter in Reading view, while the editor stays single-column. It belongs to the Tufte for Obsidian theme and plugin suite, and the margin gutter the sidenotes sit in is supplied by the Tufte theme. This repository exists to distribute the plugin through the community directory; development, documentation and issues are handled in the suite's main repository.
