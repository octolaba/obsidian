# CSLukkun/ob_daily_summary

Repository for the Daily Summary plugin, which collects an Obsidian vault's notes from the current day and has a language model write a concise daily report from them. Settings hold an API key, an API endpoint, an Ollama model name for local models, the report save location and excluded directories, and a generate-daily-report command in the command palette produces the report. The README states that Windows, macOS and Linux are supported and that API call failures, file operation errors and configuration problems are logged to a `debug-errors.md` file in the report location.
