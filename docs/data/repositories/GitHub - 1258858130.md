# HornatX/auto-link-suggester

An Obsidian plugin that completes wikilinks while typing, indexing only the folders configured for it rather than the whole vault, and generating the link through Obsidian's own generateMarkdownLink so the path format follows the user's preferences. Its README, written in Chinese with an English section, describes prefix matching by default and an optional fuzzy mode that matches anywhere in a name, a trigger rule that fires on a single non-ASCII character but requires two ASCII ones, suppression inside an existing wikilink, keyword extraction from the last space or punctuation, and an option that stops clicks on links into designated folders from navigating. Performance measures recorded there are debouncing of file-system and settings changes and a cap of ten rendered suggestions. The repository carries no description.
