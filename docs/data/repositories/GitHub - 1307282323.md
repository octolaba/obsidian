# AlinaWang321/ai-linzi-obsidian

Connects a hosted business-coaching assistant to the vault: a sidebar chat that can include the active note, local search across Markdown, TXT, text-based PDF and DOCX files, and note or folder creation after in-app confirmation. It also generates article illustrations, formats WeChat articles and sends them to a configured draft box, converts one into a Xiaohongshu note with title options and local cards, and tracks a publishing matrix and per-post metrics for four platforms. Only the active note, authorized documents or bounded matched excerpts are sent to the service, and keys are held in Obsidian SecretStorage. Local execution of Node, Python or FFmpeg steps is off by default and confirmed per step; the plugin is desktop-only and needs Obsidian 1.11.4 or later.
