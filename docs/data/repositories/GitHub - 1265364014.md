# ali3ngr2/Giganttix

Scans the vault for notes carrying date frontmatter and draws them as an interactive Gantt chart with one bar per note. Dragging a bar to move or resize it writes the new dates back into the note's frontmatter atomically, a progress handle sets a percentage, clicking opens the note in a tab and right-clicking changes its status. Day, week and month views, a today button, a status filter built from the values actually present, custom status lists and configurable start and end date properties are provided, and the chart can be limited to a folder or to notes carrying a required property. The README records the plugin as originally built as a companion to TaskNotes but usable with any notes that carry date frontmatter.
