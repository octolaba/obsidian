# TYBLHQY/obsidian-pretext

Pretext Justify replaces the browser's word wrapping in Obsidian's reading view with the Knuth-Plass line-breaking algorithm from TeX, choosing breaks by shortest path over the feasible candidates so that accumulated paragraph badness is minimised. Its cost combines the cubic stretch-and-shrink ratio with penalties for spacing wide enough to form rivers of white space, for spacing tighter than a configured threshold, and for hyphenated rather than natural breaks, while the last line is left-aligned and penalised when its natural width would overflow. Optional soft hyphens even the spacing further, paragraphs are re-justified when the width changes with the work throttled to a couple of paragraphs a frame, and inline formatting rendered by the reading view is preserved. The README states that all processing is local with no network requests, telemetry or analytics.
