# hemy301/explorer-property-attributes

Obsidian plugin, named Mark as Read in its README, that styles entries in the file explorer according to each note's frontmatter properties. A checkbox property such as read, done or archived greys the note out and marks it in the explorer, and an optional footer bar pinned to the bottom of the pane toggles that property in one click. Every frontmatter property is also exposed as a data-link attribute on the explorer item, so further styling can be written as a CSS snippet, and settings choose which properties are exposed and which get footer toggles.
