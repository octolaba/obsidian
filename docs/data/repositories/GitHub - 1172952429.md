# HikerScrolls/HikerScrolls

HikerScrolls is an Obsidian plugin that turns trip data into scroll-driven journals paired with a topographic map. The README records a journal layout with the narrative in a left panel of location cards carrying photos and text and a map in the right panel, where scrolling traces a marker along the GPX track and draws the route as the reader moves, animating multi-route trips segment by segment. A five-step wizard covers trip information and GPX upload, placing location pins manually or detecting them from photos, assigning photos to locations, grouping locations into sections, and generating the journal. A personal atlas plots every journal on an interactive world map with trip statistics, a timeline sidebar indexes journals by year with cover thumbnails and search, and the README lists a choice of 14 map styles.
