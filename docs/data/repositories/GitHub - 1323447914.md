# leolaurindo/basify

Basify converts a selected Markdown list, task list or table into an Obsidian base, creating one note per item, checkbox or row with frontmatter properties extracted from the line. A dialog controls where the notes and the base file go, how spaces and case in filenames are normalized, which table column supplies the note names, and whether the base is written as a file, as an inline code block, or not at all. From lists it can pull tags, labelled dates such as a due date, and arbitrary key-value pairs into fields, removing that metadata from the note name, while checkbox state becomes a boolean property the base shows as a checkable column. Tables turn their remaining columns into properties, including tables without a header row, whose columns are named positionally and can be renamed in the dialog.
