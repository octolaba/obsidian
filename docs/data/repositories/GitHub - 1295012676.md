# slow-coding/obsidian-llm-auto-title

LLM Auto Title is described as generating note titles with a local LLM, defaulting to LMStudio but working with any OpenAI-compatible server, either on the current note by hotkey or as a batch rename of timestamp notes. The README says renaming goes through Obsidian's file manager so backlinks update, that there is no automatic trigger, and that the batch command matches filenames against a configurable timestamp pattern within configured scan folders. Reasoning is off by default and the system prompt is customizable, and the interface localizes to English or Chinese following Obsidian's language. The README states that the only network traffic is to the configured local server and that no telemetry is collected; that is recorded as the project's own claim.
