# MaxSRodenkirchen/Title-Case-Converter-Plugin

Title Case Converter converts the selected text in the editor to title case according to a citation style, run from a command in the command palette. The style supplied out of the box is that of the American Medical Association, and the README states that the architecture is meant to make further styles easy to add by implementing a style interface and registering it, after which a command appears for it automatically. Colons separating a title from a subtitle and hyphenated compounds are handled as special cases, an exception list in the settings names words that keep exactly the capitalization they were typed with, and a heuristic that preserves mixed-case words can be disabled. The author notes that the plugin was written with the assistance of a language model.
