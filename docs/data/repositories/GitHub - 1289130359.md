# wk-obsidian/HybridGitSync

Synchronizes an Obsidian vault with Git using a different mechanism per platform: native Git commands on Windows, macOS and Linux, and the GitHub, GitLab or Gitea REST APIs on iOS and Android, where no local Git binary is available. Setup requires the vault to be a Git repository on a hosting platform and a personal access token with repository read and write scopes. The README states that tokens are stored in Obsidian's local configuration storage and that the plugin includes synchronization logic aimed at multi-device editing.
