# MSNP1381/mcp-notes-tools

No repository description is recorded, so this body is grounded in the README alone. MCP Notes Tools is a desktop-only Obsidian plugin exposing local MCP tools for one vault: searching note titles, vault-relative paths and body content, returning the full content of a selected Markdown note, and appending a confirmed change note under a timestamped section. The README states that attachments, binary files and plugin configuration files are out of scope, that every append requires per-write confirmation inside Obsidian, and that no note content, filenames, metadata or user identifiers are sent to external services. The local MCP endpoint is enabled in the plugin settings, which display the loopback address a client should connect to.
