# juracy/obsidian-asciidoc-blocks

AsciiDoc Blocks renders AsciiDoc blocks in Obsidian, with initial support centered on tables. Its table syntax covers headerless and CSV tables as well as cells spanning multiple lines or columns, while other AsciiDoc features are not presented as guaranteed.
