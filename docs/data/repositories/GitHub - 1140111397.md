# davidvkimball/obsidian-periodic-links

Periodic Links creates links between periodic notes from natural-language phrases typed inside a periodic note. The README gives the recognised forms per note type, from yesterday and in three days for daily notes through last and next week, month, quarter or year, to weekday phrases such as next Thursday and written numbers such as in two weeks. It states that the plugin detects the note type from the filename format, adapts to the configured date formats, creates missing notes with their template and folder structure, and works with both the core Daily Notes plugin and the Periodic Notes community plugin.
