# lugglory/obsidian-hy-canvas-minimap

HY Canvas Minimap shows an overview of a whole Obsidian Canvas in one corner of the canvas view, with a viewport box that can be clicked or dragged to move around and a double-click that zooms to the nearest node. Settings show or hide the minimap, place it in the bottom-left or bottom-right corner, and set its size as a percentage of the canvas view. The README states that Obsidian's Canvas has no public API, so the plugin relies on internal canvas objects and a future Obsidian update could break it.
