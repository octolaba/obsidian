# rpggio/obsidian-chat-stream

Runs a conversation with an OpenAI model along a thread of Canvas nodes, where a note's ancestors on the canvas form the context sent with it. The README describes selecting a note and pressing a shortcut to generate a new note from the model, and a second shortcut to create the note to reply in; generated notes are coloured purple and marked with a chat role in the canvas data file. It states that an OpenAI API key is entered in the plugin settings, that the plugin is supported on desktop only, and that its canvas handling code comes from the Canvas MindMap plugin.
