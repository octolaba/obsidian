# laupas/google-drive-mirror

This repository holds Google Drive Mirror, described upstream as syncing several vault folders to several Google Drive folders, including Shared Drives, with each pairing mirroring a subfolder or the whole vault two-way and picking up files created directly in Drive. The README adds manual and automatic sync, recursive mirroring including empty folders, a newer-wins conflict strategy in which an edit beats a deletion, and deletion safety in which only files that provably existed on both sides are removed, locally into the vault trash and remotely into the Drive trash. It also describes viewing and editing Google Workspace documents in an embedded pane without downloading them, and an optional passphrase-encrypted sync of plugin settings across devices.
