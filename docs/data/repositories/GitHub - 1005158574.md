# lawrencefeng17/obsidian-hidden-hyperlinks

The repository holds an Obsidian plugin that hides arbitrary text behind display text and copies the hidden payload to the clipboard when the display text is clicked. Its recorded syntax wraps the payload and the visible label between configurable delimiters, by default a double colon at each end with a vertical bar between the two parts, and the start delimiter, separator, end delimiter and notification text are all settings. The README also records a tooltip that shows the hidden payload on hover and styling that follows the active Obsidian theme.
