# kxwu222/mimocode-obsidian

MiMo for Obsidian embeds Xiaomi MiMo in the vault sidebar as an AI assistant, opened from the ribbon or the command palette as a persistent chat panel. Connected MCP servers let the model read and write vault files, search the web and run multi-step tasks; an inline-edit hotkey rewrites selected text in place behind a word-level diff preview; and a prompt-tuning input turns a plain-language description into a saved system instruction. Conversations are stored locally in the vault and can be resumed, browsed or deleted, several chat tabs can run in parallel, and images can be dropped into messages. The README records desktop Obsidian 1.7.2 or later and a Xiaomi MiMo API key on either billing plan as requirements.
