# BeTheOne314/my-desk-sync

Synchronizes knowledge notes between a My Desk account and the vault over that service's own API, using a plugin token issued in My Desk instead of a GitHub repository and access token. Notes are stored as Markdown under a wiki folder with UUID filenames, and issuing a plugin token pauses the account's older GitHub-based sync route. Reconciliation is a three-way merge over the local files, the server and a remembered baseline: conflicts resolve toward the later edit, a server-side deletion sends the local file to the trash, a file deleted locally is restored on the next run, and frontmatter keys added by hand are preserved. Syncing runs on demand or on an interval of at least five minutes, needs a paid subscription, and contacts only the configured My Desk address.
