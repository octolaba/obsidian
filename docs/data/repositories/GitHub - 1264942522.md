# davadev/obsidian_chinese_comprehensible_input

This repository holds Chinese Comprehensible Input, an Obsidian plugin that turns a Chinese note into a reading environment for language learners. Text is tokenised against a dictionary and each word is coloured by learning status or by HSK level, tapping a word marks it known, unknown or partial, and custom dictionary entries can be built from tapped characters. The plugin tracks exposure, schedules review with a spaced-repetition system, and can generate review stories through an OpenAI-compatible endpoint. The README states that it runs on desktop and mobile with no Node or Electron dependency at runtime.
