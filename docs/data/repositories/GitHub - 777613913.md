# codeonquer/obsidian-sync-config-folder-to-common-folder

This plugin copies the contents of Obsidian's configuration folder into an ordinary folder and can restore it again, through one command for each direction. Its README gives the reason: the configuration folder's name must begin with a dot, and some of the synchronization tools people use will not sync a folder whose name starts with one. The target folder is set in the plugin's settings and may be an absolute path or a path relative to the root of the current vault; the README states the same account in English and in Chinese.
