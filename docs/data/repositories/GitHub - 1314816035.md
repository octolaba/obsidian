# Bahey-shalash/obsidian-text-color

Colors marks up colored text with a syntax that stores a plain hex value in the note, so live preview, reading mode and PDF export render the same color on any machine. A command and a right-click submenu apply a palette color, a custom color or removal to the selection, several selections are colored in one step and undone in one, and a swatch appears when the cursor sits inside a colored section, changing the color in place. The syntax accepts full and short hex, an alpha channel and a palette name rewritten to its hex, sections nest with the innermost color winning, and colors compose with bold, highlight and strikethrough in either order. A display math block cannot take the inline markup, so it is colored by writing a LaTeX color command into the block instead.
