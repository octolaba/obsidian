# iamrecursion/symbat

Symbat embeds the Numbat unit-aware calculator into Obsidian, bringing a statically typed scientific calculator language with real physical dimensions into notes. Expressions run in numbat code blocks, in inline spans that show a result as an inlay hint or write it into the note, in frontmatter properties given the Numbat type, and in a sidebar REPL with history and live highlighting. Plain numbat blocks evaluate in isolation while numbat-shared blocks share state and replay in order, and a numbat-use property imports another note's properties and shared blocks, alongside custom prelude files. The Numbat standard library is compiled into the plugin's WebAssembly binary so evaluation stays local, and no network request is made unless live currency rates are switched on.
