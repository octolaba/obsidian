# taichimaeda/markpilot

Markpilot adds AI-powered inline completions and a sidebar chat view to Obsidian, aiming for an experience comparable to GitHub Copilot. The README records support for models from the OpenAI API, the OpenRouter API and local models through Ollama, with further providers planned, and it names other plugins that offer one of the two features. It describes context-aware completions that detect the surrounding Markdown context, such as a list, heading or code block, and the language used inside a code block, together with context-aware system prompts and few-shot examples marked as beta.
