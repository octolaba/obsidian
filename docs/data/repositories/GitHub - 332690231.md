# philoserf/obsidian-vault-changelog

Obsidian plugin that maintains a note listing recently edited notes. The changelog is refreshed from the command palette or, when enabled in settings, automatically whenever a file is modified, and entries can be written as wiki-links or as plain titles, optionally under a configured heading. The README warns that the changelog note is overwritten in full on each update, so a dedicated note should be used and embedded elsewhere when history matters, and it points to Bases, Recent Files, List Modified and Dataview as alternatives.
