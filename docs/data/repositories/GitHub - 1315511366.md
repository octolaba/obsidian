# TanJiaHui8/workout-tracker-simple

Training Volume Log records workouts as ordinary Markdown tables in dated notes, one per day, named after the muscle groups trained and renamed when another group is added. Muscle groups and exercises are defined in settings with default sets, drop sets and starting weights, and a control block in the note appends a table for an exercise, auto-fills the weight column from the last session and can rewrite every set of an exercise to one value at once. The weight column accepts plain numbers or bodyweight notation with added load or assistance from named resistance bands, drop sets are written inline or as lettered sub-rows, and isometric holds record time converted into rep-equivalents by a configurable ratio. Daily volume, weight multiplied by reps, is drawn as a spiral chart with the oldest day at the centre.
