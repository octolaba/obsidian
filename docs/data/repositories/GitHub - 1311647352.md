# coddingtonbear/obsidian-local-rest-api-periodic-notes

This plugin adds periodic-note endpoints and MCP tooling to the separate Obsidian Local REST API plugin. It exposes periodic routes for daily, weekly, monthly, quarterly and yearly notes over the usual read, create, append, patch and delete methods, with a trailing path segment addressing a heading or block inside the note, and an MCP tool that returns the vault-relative path of the current periodic note for a period, creating it if necessary. The README states that all folder, format, template and creation logic is delegated to the core Daily Notes and community Periodic Notes plugins through a shared interface library, that a period not enabled there is rejected, and that the REST routes redirect to the host plugin's existing vault routes.
