# nicojeske/mousewheel-image-zoom

This repository holds an Obsidian plugin that resizes an image by holding a configurable key, left alt by default, hovering over the image in preview mode and scrolling the mouse wheel. The README gives community plugin browser installation as the route and otherwise documents only the development build.
