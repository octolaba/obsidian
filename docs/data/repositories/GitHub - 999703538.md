# zmeeeeeva/obsidian-plugin-metadata-link-classes

This repository holds Metadata Link Classes, described upstream as enhancing internal links with automatic class names based on frontmatter metadata. The README says every internal link in a note receives classes built from that note's frontmatter keys and values, handling boolean, string and array values, so a publish flag or a tag list becomes a class name. Those class names are then targeted from the user's own CSS snippets.
