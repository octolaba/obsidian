# heidihelena/obsidian-sprint-familiar

Sprint Familiar runs a timed research sprint that starts only once a decision to work on and a finish condition are named, and ends in a review written out as a dated Markdown record in the vault. During a sprint it watches for claims, sources, assumptions, open questions and ruled-out alternatives, and a small companion in the corner reacts to those events. Commands cover starting, pausing, finishing or abandoning a sprint, opening a dashboard, and writing daily and weekly summaries. Sprint length, the folder for records and the companion's placement are configurable; the plugin writes only its own records and makes no network requests.
