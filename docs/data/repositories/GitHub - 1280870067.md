# markcrobbins2112/op-file-tree-alpha-hue

File Tree Alpha Hue colours items in Obsidian's file explorer according to the first alphabetical character of their name. The plugin scans the explorer's navigation items, matches that character with a regular expression and stamps each item with a data attribute, which a generated stylesheet layer then uses to assign folders and Markdown files colours spread across the HSL hue spectrum, with muted resting states. The README states the approach avoids DOM layout reflow, that the plugin targets Obsidian on desktop, and that it hooks the Obsidian plugin API together with a MutationObserver on the explorer.
