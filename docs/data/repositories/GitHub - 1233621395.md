# ViktorUJ/obsidian-cloud-kms

Obsidian plugin providing transparent encryption of secret blocks and binary files using AWS KMS, with the stated property that no plaintext is written to disk. The README's sections cover encrypting text in notes including nested code fences, encrypting binary files, removing encryption, the commands, behaviour and settings involved, the AWS setup and requirements, and the on-disk format. It also links separate documents on security, security testing, reproducible builds and verifying release integrity.
