# NotStudyToday/obsidian-habit-check-in

Tracks habits from a right-sidebar panel, where a habit is checked off in one of three ways: a single daily tick, a running total against a target such as an amount of water, or a timer counting up or down that adds the elapsed time on completion. Progress is drawn as a GitHub-style heatmap with user-defined intensity levels mapping value ranges to colors, viewable across the year, the last three months or the current month, and the same heatmap can be embedded in a note through a block naming a habit id and range. Check-ins can be backfilled by switching the panel to an earlier date, and a completed day is also marked in the Calendar plugin. Habits, settings and timers live in the plugin's data file while check-in records are split into one small JSON file per day, and Obsidian 1.2.0 or later is required.
