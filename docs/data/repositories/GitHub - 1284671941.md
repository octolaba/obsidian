# nnyj/obsidian-indented-table

Indented Table styles pipe tables nested inside list items in Obsidian's Live Preview. The README states the problem it addresses: Obsidian ignores indented tables and renders them as plain text, and the plugin makes them readable without changing the Markdown. It hides the separator row, gives the header a bold weight and a background fill, fades the pipe characters, prevents mid-row line breaks, forces a monospace font over table regions to correct proportional rendering on Android, and scopes row borders to the table's content width. Because Obsidian blocks widget and replace decorations from plugins, the styling is implemented with CodeMirror line and mark decorations plus CSS.
