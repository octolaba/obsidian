# aarol/obsidian-hugo-codeblock-highlight

Highlights individual lines inside a fenced code block using the same hl_lines option Hugo uses, written after the language tag. The value is a single number or an array mixing numbers and ranges, and lines can also be selected in the editor and marked through a Highlight selected lines entry in the right-click menu. The README states that only the hl_lines property is supported and that the plugin works in Live Preview and source mode but not in reader mode, which uses a different syntax highlighter.
