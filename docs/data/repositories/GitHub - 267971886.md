# pgalliford/Obsidian-theme-Incredible-Hulk

pgalliford/Obsidian-theme-Incredible-Hulk is a custom CSS theme for Obsidian inspired by The Incredible Hulk and, according to its README, dark theme only. Installation is described through the Custom CSS plugin and the community themes section of settings. The author records that the theme was modified from the work of other Obsidian members' themes and invites others to modify it further.
