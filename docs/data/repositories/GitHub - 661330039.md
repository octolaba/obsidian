# khuongduy354/obsidian-git-url

This repository holds Git Url, whose README describes copying a link to the current file in its remote Git repository, so the file can be opened and shared in a browser without Obsidian installed. A second command copies file content with resource links rewritten to their remote addresses, so images load when the Markdown is pasted into another renderer. The repository name and user name, or a full custom URL, are configured in the settings, and both commands are reached from the file explorer's context menu. No upstream repository description is recorded, so this body rests on the README alone.
