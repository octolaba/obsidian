# Pr0dt0s/new-note-new-window

The repository holds New Note New Window, an Obsidian plugin that creates a note directly in a floating window. Its README records a single command, which can be given a shortcut, and states that new notes land in the folder configured as Obsidian's default location for new notes. Two settings are documented: whether one floating window is reused or a new one opened each time, and whether the note goes to that default folder or to a folder named in the plugin.
