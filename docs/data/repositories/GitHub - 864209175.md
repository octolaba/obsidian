# chern-kp/JustAnotherHotkeyAddon

The recorded description says the plugin adds new hotkeys for text editing along with several additional features. The README groups its commands into section selection and editing, heading navigation, links, lines and other, and says they began as features the author wanted for daily Obsidian use. The further features it lists are contextual language detection for a Paste As Code Block command that writes the detected language into the opening fence, an option to disable Tab and Shift+Tab indentation, copying the content of inline code on double-click, and bulk copying of content from several files through the context menu or a tag-based selection. Installation is documented through the BRAT beta-plugin route rather than the community directory.
