# JakobLien/writing-regex-replacer

Writing Regex Replacer rewrites text as it is typed, using pairs of source and target regular expressions configured in settings. Matching runs through JavaScript's replace method on the current line only, so nothing already written elsewhere in the note is touched. Each pattern has two toggles: whether the match must be preceded by whitespace, and whether a space must follow it before the replacement fires, which stops a partial match from being expanded too early. Because JavaScript's replace does not accept a reference to the whole match written as a zero-indexed group, the plugin rewrites that form into the one it does support.
