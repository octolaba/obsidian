# Stef4678/knowledge-brain

Knowledge Brain treats every Markdown note as a node in a directed acyclic graph, linked through a parents list in YAML frontmatter, with cycles, self-links and duplicates rejected; optional frontmatter records tags, a status and a question type. A built-in chat streams from DeepSeek, OpenAI, Gemini or Claude and is grounded in that graph: a local BM25 search retrieves the most relevant notes for each message and passes them as numbered context that the answer cites inline. Each answer carries a row of chips for the notes it used, one of which opens the graph view with the traversal path between them highlighted. It can also suggest tags, statuses, links and follow-up questions and turn an answer into a new note; retrieval is on by default with a configurable number of candidates, and the plugin is desktop only.
