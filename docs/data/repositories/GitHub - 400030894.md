# noatpad/obsidian-banners

Banners adds a banner image and an optional emoji icon to a note, through commands that select a local image, paste an image address from the clipboard, add or change the icon, or remove either of them. The banner can be dragged to reposition it and locked in place by command, and the banner data is stored in the note's frontmatter, so it can equally be written by hand or by another plugin. Settings control the banner height, a solid or gradient style, and whether banners appear in internal and preview embeds and how tall they are there.
