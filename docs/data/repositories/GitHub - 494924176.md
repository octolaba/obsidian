# macrojd/tag-summary

Tag Summary gathers blocks of text that share one or more tags from across an Obsidian vault into a summary. The README defines a block as text separated by empty lines, and shows that a summary built for a given tag includes every block carrying any of the tags listed for it. The summary is placed in a note as a code block bearing an add-summary identifier, with the tags named on a tags line inside the block and several tags separated by spaces.
