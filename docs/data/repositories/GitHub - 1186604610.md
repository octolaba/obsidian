# OlofHaglund/Obsidian-Anki-Flashcards-Sync

Obsidian plugin that renders `flashcard` code blocks as card previews in Reading view and Live Preview and syncs them to Anki through AnkiConnect. Note type and card template definitions are read from the frontmatter of Markdown files in an `Anki/` folder, note frontmatter supplies the field values, and one preview card is rendered per card template with a front and back toggle. Syncing creates or updates cards using a deterministic source tag per block, uploads linked vault audio into Anki media, and creates missing decks and note types. The README states this is an early version released to catch problems in the distribution flow, and that desktop Obsidian, desktop Anki and AnkiConnect are required.
