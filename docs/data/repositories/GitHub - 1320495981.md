# PleiadesM/Tufte-Backlinks

Tufte Backlinks renders the linked and unlinked mention snippets in the Backlinks pane and in the in-document backlinks block as formatted Markdown, with headings dropped to body size, the backlink reference itself bold, underlined and accent red, and match highlights preserved. The global Search pane is left untouched. It is part of the Tufte for Obsidian theme and plugin suite, and this repository exists only to distribute the plugin through the community directory, with development, documentation and issues kept in the suite's main repository.
