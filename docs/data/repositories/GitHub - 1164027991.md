# Toru4ka/obsidian-age-crypto

Obsidian plugin that encrypts and decrypts note content in the age file encryption format, operating on the whole current note or on a selection. It generates a local age identity key per device, encrypts to multiple recipients, and stores the result as ASCII-armored text blocks opening with BEGIN AGE ENCRYPTED FILE. The repository description names the external age and age-keygen command-line tools, while the README states that this version uses a bundled TypeScript implementation of age instead, needs no external binaries, and runs on iOS, Android, macOS, Windows and Linux.
