# mulder3062/Myst

Myst is a theme for Obsidian whose README records that its CSS was modified with reference to IntelliJ colour schemes, and that it is confirmed to work on Obsidian version 1.8.9. Recorded changes are a pen icon at the beginning of titles to mark editing in progress with an animated background effect, lines below second-level headings, colour used to emphasize text, a changed default font and folder icons in the file explorer. The README notes that with the inline title setting turned off the animation applies to the first heading level instead.
