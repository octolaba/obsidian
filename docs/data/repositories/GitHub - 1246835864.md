# GS-AX/doc-weaver

Document Weaver converts local Word, PDF, PowerPoint, Excel and HWP files into Markdown notes, started by dragging files onto the window, pointing a watch folder at a directory, or picking files from the command palette, with images extracted and front matter injected. The README's fidelity table records DOCX preserving headings, emphasis, tables and images, PPTX producing either one long note or one note per slide with speaker notes, PDF extracting the text layer with heading detection and rendering scanned pages as images, Excel turning each sheet into a GitHub-flavored table, and the Korean HWP and HWPx formats handled as beta where merged cells and complex formatting may be lost. It states the conversion needs no API keys and runs fully offline.
