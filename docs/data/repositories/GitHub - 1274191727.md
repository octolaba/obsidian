# LeonYew-Ley/obsidian-time-stamp-hider

Time Stamp Hider hides the timestamp prefix of Zettelkasten-style filenames in the display text of internal links, so a note named with a leading ten-digit stamp shows only its title. The default pattern matches ten digits followed by whitespace and can be replaced with a custom regular expression, and the whole plugin can be switched off in its settings. The README is explicit about the boundaries: only rendered link text changes, while filenames, Markdown source, aliases, frontmatter, link targets, backlinks, renaming, search indexing and graph data are all left untouched. In Live Preview the links stay editable, clicking or moving the cursor into one reveals the original source and a modifier-click opens the target, and hiding applies there only where editor rendering is stable.
