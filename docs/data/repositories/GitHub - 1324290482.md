# kazdonkai/unified-outliner

Unified Outliner is a structural editing plugin for a single Markdown note in Obsidian: it moves, re-levels and inspects heading sections together with their bodies and child sections, as well as nested list subtrees, and never moves content between notes. A dedicated Outline Tree View shows headings and, optionally, list items in one tree with synchronized selection, and per-file view folding is kept in sync across open tree views. A Partial Edit Pane edits one selected section or list subtree in isolation, with an explicit apply step and conflict protection. It requires Obsidian 1.8.7 or newer and does not set out to cover search, task management, aggregation or writing assistance.
