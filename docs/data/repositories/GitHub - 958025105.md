# chararch/obsidian-enhanced-publisher

Obsidian plugin for preparing notes for publication on Chinese content platforms, currently the WeChat official account. Images pasted into a note are stored automatically in a folder named after the document and hidden from the sidebar, a command renders the note as an HTML preview whose theme can be switched and whose output can be copied to a publishing platform, and a second command publishes the note through the platform API after a title and target are entered. Mermaid diagrams, LaTeX formulas and Ruby annotations are handled for that target, and publishing requires an AppID and AppSecret plus an IP allowlist entry configured on the account.
