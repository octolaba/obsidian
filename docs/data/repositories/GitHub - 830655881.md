# Rudtrack/structured-tree

Structured Tree is a file explorer for notes whose hierarchy is encoded in their names and separated by a character that defaults to a period and can be changed in the settings. The tree is opened from the ribbon, marks a node with no file of its own with a coloured indicator, and expands a note when that note is opened from it. Recorded features include lookup, automatic frontmatter generation for new files with customizable options, multi-vault support, a custom resolver and renderer for links and embeds, a renaming modal and path exclusion patterns; every file type Obsidian supports is handled, with canvas support marked experimental and enabled in the settings.
