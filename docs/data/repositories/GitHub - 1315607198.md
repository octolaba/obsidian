# haohao1101/english-reading-companion

English Reading Companion collects the highlights in an English article, including Obsidian's own highlight syntax, HTML mark elements and Highlightr spans, and sends each with surrounding context to an OpenAI-compatible chat completions endpoint. The model returns structured JSON, from which the plugin renders one aggregated learning note per source article explaining the words, phrases, collocations, terms and sentence patterns in their original context. Re-running the command updates only the marked automatic section of that note, leaving surrounding hand-written content intact, and a link is kept in both directions between article and note. Network requests happen only on generation or a connection test, to the endpoint configured with a base URL, path, key and model.
