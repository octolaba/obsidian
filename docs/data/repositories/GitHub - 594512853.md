# rafaelveiga/obsidian-widgets

This plugin renders small widgets inside Obsidian notes from a code block whose language is set to widgets, with the widget configured by key-value options in the block body. The documented widgets are a clock in 12-hour or 24-hour format with optional seconds, a quote with an optional author, a countdown taking either an absolute date or a relative expression in seconds, minutes, hours or days and choosing which units to show, and a counter carrying a text label and an optional id so several can share a note.
