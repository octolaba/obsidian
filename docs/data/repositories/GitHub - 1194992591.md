# CamBlackwell/Obsidian_Center_Text_Plugin

This repository holds Center Text, an Obsidian plugin that centres note text and controls how wide the text column is. Centering is toggled from a ribbon icon, the command palette or the settings tab, and a slider sets the maximum text width between 20 and 100 percent. The README states that it works in both reading view and live preview, that settings persist across restarts, and that no default hotkeys are assigned, although commands for toggling and for increasing or decreasing the width can be bound by hand.
