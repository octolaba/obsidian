# Galeas/recording-transcript-player

Opens an audio file together with a sibling subtitle file that shares its basename, showing Obsidian's native audio player above the transcript, highlighting the active subtitle during playback, and seeking when a timestamp is clicked. It reads SRT blocks with an optional `Speaker: text` prefix, WebVTT cues with voice spans, and DOTe JSON exports whose `lines` array carries start and end times, a speaker designation and text. Only sibling files with the same basename are considered, `.srt`, `.vtt` and `.json` are tried in a priority order that can be changed in settings, and the default audio extensions are m4a, mp3, wav, aac, flac, ogg and opus.
