# CVERInc/obsidian-marktile

marktile is an alternative Markdown editor pane for Obsidian with three modes over the same file: one that enlarges headings while leaving the markers visible, one that hides them for a rendered view, and one showing raw text, with the file on disk unchanged by the switch. It adds list continuation on Enter, Tab indentation with a tab-versus-space ruler and a drag-reorderable table of contents, and a header button returns to Obsidian's native editor or, when the author's tugtile plugin is installed, to its card table. The README records a two-row toolbar and a virtual-keyboard-aware layout on iOS and iPad, re-highlighting held back while an IME is composing so CJK input is not interrupted, and states that notes never leave the vault because the plugin makes no network requests and collects no telemetry. It is written in English, Japanese, Korean and Traditional Chinese.
