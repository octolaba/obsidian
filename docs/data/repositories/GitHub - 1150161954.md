# mattmcmanus/obsidian-moments

Moments builds a single timeline over dated content that is scattered across a vault rather than gathered into daily notes. It recognises three kinds of entry: inline moments, dated headings inserted inside any note under a configured section; standalone moments, dedicated dated note files; and implicit moments, files created or modified on a given day, shown as secondary entries for context. The README records commands for inserting an inline moment in the current file and for creating a standalone moment, with settings for the section to insert under, the heading level and whether new entries are prepended or appended, plus a demo folder that can be opened as a vault.
