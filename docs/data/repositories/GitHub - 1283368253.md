# k3-2o/kanagawa-hokusai

k3-2o/kanagawa-hokusai is an Obsidian port of rebelot/kanagawa.nvim, named after the artist of The Great Wave off Kanagawa. It ships three variants with complete palette coverage: Wave, a high-contrast dark default with deep ocean tones; Dragon, a muted warm brown-black low-contrast alternative; and Lotus, a warm parchment-like light mode. The two dark variants are switched through the Style Settings plugin, which also configures fonts.
