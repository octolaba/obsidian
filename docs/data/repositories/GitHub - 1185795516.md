# takeshy/obsidian-llm-hub

Obsidian plugin combining AI chat, workflow automation and semantic search over a vault. Chat can run against Gemini, OpenAI, Anthropic, OpenRouter, Grok, OpenCode, local runtimes such as Ollama, LM Studio and vLLM, or CLI backends, and with function-calling providers the assistant can read, write, search and edit notes, with an edit history offering a diff view and restore. A workflow builder automates multi-step tasks through a visual node editor, and a local vector search provides a dedicated search tab with PDF preview and a path from a result into chat. The plugin also supplies models, chat and workflow execution to the author's separate dashboard and discussion plugins.
