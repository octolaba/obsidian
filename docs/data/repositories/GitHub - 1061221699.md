# account-not-relevant/museifu-basic-theme

account-not-relevant/museifu-basic-theme is a simpler, less modular variant of the Museifu theme with a more fixed appearance. It centres on the accent colour, adds an accented callout that follows that colour, and keeps the pen-colour modifications that let notes be customized individually; the README marks the pen-colour tutorial and the accented-style preview as still to be added.
