# HamzaBenyazid/Live-variables

Live Variables is described as defining variables in a note's properties and reusing them throughout its content. Its README says variables are declared in frontmatter and update wherever they are referenced, that code blocks run queries and transform data through built-in functions or custom JavaScript, and that frequently used scripts can be saved in a function library and called by name. A form interface inserts queries without writing code, and the README also lists sharing variables across notes. The README is promotional in register and the claims here are those it makes for version 2 of the plugin.
