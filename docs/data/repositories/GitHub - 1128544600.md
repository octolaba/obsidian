# LeoWie93/obsidian-dangling-image-manager

Finds and deletes dangling images in a vault through a simple interface opened with the Dangling Image Manager command. The README states that it scans the repository on each startup with the help of Obsidian's API and keeps track of file and image changes while Obsidian is in use.
