# any-block/any-block

AnyBlock parses and renders Markdown extensions that convert one block into another form: a section selected by list, heading, table, quote, code block or markdown-it container can be rendered as a table, tabs, directory, card, column, mindmap, markmap, mermaid or PlantUML diagram, timeline, chart or node tree. The README presents it as a single module shipped for several hosts — Obsidian, CodeMirror, markdown-it for Vuepress and Vitepress, Remark for Quartz and Docusaurus — as well as an online app. Tutorial, demo and contribution material sit behind external links rather than in the repository.
