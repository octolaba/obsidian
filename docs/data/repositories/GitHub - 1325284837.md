# CosmicSeaFox/Volcanic-Vein-Lava

Volcanic Vein Lava Lava is a handcrafted Obsidian theme with a dark mode of deep volcanic stone surfaces and molten accents and a light mode of polished mineral surfaces with warm reflections. Tables use one continuous surface instead of zebra striping, properties are presented as carved panels, callouts are styled as chambers, and tags, checkboxes, the calendar, code blocks and the graph view follow the same lava palette. Body text is set in Inter, headings in Cormorant Garamond and code in JetBrains Mono, and the layout supports mobile as well as desktop.
