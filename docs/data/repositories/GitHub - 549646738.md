# mottox2/obsidian-relation-pane

The repository holds Obsidian Relation Pane, a plugin that summarizes how the current note relates to others in a right sidebar view. Its README records four groups: notes this note links to, notes that link to it, notes linked from those first-degree links, and links to notes that do not exist yet. It credits an earlier two-hop links plugin and the Scrapbox feature behind it as inspiration.
