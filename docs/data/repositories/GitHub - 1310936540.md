# lucytheboss/multi-ai-assistant

Multi-AI Assistant is a sidebar that answers questions from sources gathered in a knowledge base panel: notes, whole folders, PDFs and images, plus the currently open note, with a running token estimate for the context being sent. It has four modes: a chat with streamed Markdown answers that can be copied, saved as a note or appended to one; a quiz whose free-text answers the model grades with feedback; generated flash cards with a self-scored review; and a tab that opens Google NotebookLM. Groq, Gemini, OpenAI and Claude are reached over their HTTP APIs, and the gemini and claude command-line tools on desktop reuse an existing terminal login instead of an API key. Highlighted text anywhere in Obsidian can be sent to the assistant from a small button, and sixteen cosmetic characters are selectable.
