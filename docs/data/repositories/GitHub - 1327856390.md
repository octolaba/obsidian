# TylerCarrol/obsidian-base-form

Adds a Form view to Obsidian Bases in which each matching note appears as a form, its selected properties stacked vertically and edited directly. Text, list, number, checkbox, date and date-and-time properties can be changed, with autocomplete in text and list fields, and values are written back to frontmatter when focus leaves a field; file and formula properties, nested data and non-text lists stay read-only. Property order and display names come from the Bases toolbar, and each view can show or hide file names, restrict the form to empty or existing properties, and adjust item spacing. It requires Obsidian 1.13.0 or later with the Bases core plugin enabled, runs on desktop and mobile, and makes no network requests.
