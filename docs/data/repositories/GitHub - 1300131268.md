# akskokki/obsidian-custom-emojis

The repository holds a plugin that renders a shortcode written between colons as a custom emoji image in Obsidian, in the manner of Discord or Slack, while the file itself keeps the plain shortcode text. Typing the opening colon opens a fuzzy-matched suggestion list using the same matcher as Obsidian's quick switcher, and the swap can be applied in all editing and reading views or configured to stay text in source and live editing. The README states that a rendered emoji behaves as one unit for clicking, arrow keys and backspace, and that animated GIFs work as well as static images.
