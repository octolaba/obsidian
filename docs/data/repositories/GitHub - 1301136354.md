# AidenXu-1/zj-html-studio

This repository holds ZJ HTML Studio, a desktop-only Obsidian plugin that opens local .html and .htm files in native tabs. Each preview computes a minimal resource scope for the images, styles, scripts, modules, fonts and media it needs, stays isolated from other HTML tabs, binds only to 127.0.0.1, and reloads only the pages a file change actually affects. Three modes govern what a page may do, from safe read-only for unfamiliar files through local interactive to trusted compatibility for reviewed pages needing remote resources, and the README is explicit that navigation and WebRTC are not absolutely isolated in the interactive mode. A diagnostics panel explains missing resources and restricted capabilities, and pages can be zoomed, searched, shown as read-only source, opened fullscreen, or embedded in Markdown at a chosen size.
