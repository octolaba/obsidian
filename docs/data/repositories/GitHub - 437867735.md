# CattailNu/obsidian-file-info-panel-plugin

The repository holds a plugin that adds a File Information view to Obsidian, toggled from a button in the left navigation panel. Its README records the created and modified dates, the file size in a human-readable form, and links that open the file in its native application or reveal its folder, with the displayed fields chosen in the plugin's settings. It also records writing statistics — character, word, sentence, paragraph and line counts — a word frequency analysis, image dimensions for image files, and relative wording alongside the dates.
