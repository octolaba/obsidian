# emarpiee/obsidian-style-manager

Style Manager reads the settings comments that snippets, themes and plugin CSS files declare and presents them in one pane as body-class toggles, numeric sliders, text inputs, colour pickers and similar controls. The README states that it adapts parts of the Style Settings codebase by mgmeyers, that both plugins rely on the same settings configuration system, and that Style Settings has to be disabled first because the two otherwise compete over the same CSS variables. Its interface is organised into tabs for styles, snippets, a theme builder, presets, isolation and preferences, with whole configurations saved, imported and applied as presets, a shared or isolated mode for how styles apply, a toolbar carrying status badges, and an integrated CSS code editor.
