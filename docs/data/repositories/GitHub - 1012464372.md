# dragonish/code-blocks-commands

Obsidian plugin providing commands that insert code blocks with a chosen syntax-highlighting markup, and a backtick trigger that opens the markup selection menu. The README states that the markup list is sorted by usage habits and that custom markups can be defined with a required markup string plus an optional language name and title. It credits PrismJS and is MIT licensed.
