# anshuman-ecc-eth/hm-obsidian

Hyvmind Uploader uploads folders from an Obsidian vault to the Hyvmind application. Setup is a one-time binding: a Principal ID copied from Hyvmind's wallet settings is pasted into the plugin options and requested, the pending request is approved in the app, and after a restart a green dot in the corner of Obsidian indicates the binding. Uploads are started by right-clicking a folder and choosing Upload to Hyvmind, and the README prescribes a four-level folder structure — broad category, topic, article or section, then precise wording — because the receiving application maps those levels onto its own Curation, Swarm, Location and Law Entity concepts and treats the files inside as interpretation entities.
