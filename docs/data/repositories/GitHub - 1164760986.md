# LimNiemdung/obsidian-ribbon-folder

Adds custom buttons to Obsidian's left ribbon that run a command, open a vault file or open a web link in one click. Buttons can also be grouped: a group button opens a pop-up menu of items, triggered by click or hover, with the menu showing icons, labels or both. Icons come from Lucide names or from SVG files in the vault, tooltips and display names are editable, and shortcuts are reordered by dragging. A global setting decides whether files open in a new tab, the current tab or a split, and the plugin requires Obsidian 1.13.0 or newer.
