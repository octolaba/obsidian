# wojciechpolak/obsidian-daily-echoes

Daily Echoes resurfaces daily notes from previous years in a sidebar panel, showing what was written on this day, this week, this month, or on this day-of-month across the years. It reads the core Daily notes or Periodic Notes configuration to locate daily notes and parses each note's date from its filename, treating only notes under the configured folder that parse as a valid date as entries. Four modes select the time window, every entry is labelled with how long ago it was, and the panel opens from a ribbon icon or a command.
