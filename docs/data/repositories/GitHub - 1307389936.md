# ffy6511/obsidian-activity-map

Activity Map is a local-first Obsidian plugin that shows how focused time is spent across the files and folders of a vault. It tracks active time, editing time, typed characters and file-open counts for the file currently in focus, excluding idle, sleep and lock-screen gaps, and lets daily and historical activity be inspected by drilling from folders down to individual files. A compact, pinnable chart can be opened from eligible file headers, with its placement around the day navigation and its six action controls configurable in settings.
