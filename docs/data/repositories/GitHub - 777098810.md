# clearlysid/apex

clearlysid/apex holds Apex, which its description calls an opinionated, simple Obsidian theme and its README calls a distraction-free one, written by Sid and Vignesh for people who prefer simpler interfaces, monospaced type and hotkey-driven navigation. The README states that it currently works best on macOS and invites issue reports from other platforms. It is typeset in Geist and Geist Mono, starts from the Obsidian sample theme, and borrows its CSS build process from the Minimal theme; development runs through an npm watch script that compiles the source CSS with hot reload.
