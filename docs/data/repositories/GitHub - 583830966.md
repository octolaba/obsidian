# AndreBaltazar8/obsidian-canvas-conversation

Obsidian plugin for holding a conversation with ChatGPT on the canvas: a canvas node is right-clicked and prompted. It has to be configured with a user agent, a session token and a clearance token from ChatGPT, which the README says may need refreshing every two hours. The author calls the code mostly undocumented and messy and lists intended improvements, among them a streaming mechanism for the conversation, refreshing tokens, cleaning up monkey patches over undocumented APIs, better error messages, and adding edges between nodes.
