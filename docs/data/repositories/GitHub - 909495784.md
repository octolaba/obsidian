# trung-tran-swe/obsidian-current-file-tags

Current File Tags shows the tags of the active Markdown file in a side panel, covering both inline tags and the frontmatter tags property. Clicking a tag lists the files that contain it, and clicking one of those files opens it. The README notes that control-clicking a tag hands it to Obsidian's Search plugin instead, and that this path is not mobile friendly.
