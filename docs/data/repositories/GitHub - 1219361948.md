# jaminbrazil2/phosphor-crt

Phosphor CRT is a vintage monochrome Obsidian theme modelled on the green phosphor monitors of the early 1980s. Its dark mode puts green #33ff66 text on deep near-black with a layered text-shadow glow, while its light mode is a flat paper terminal of dark forest green ink on warm cream with no glow. Type is monospace throughout, falling through Monaco and Menlo with support for the Print Char 21 Apple II font recreation when installed, headings are uppercase with an amber prompt prefix on H1 echoing Applesoft BASIC, and the block cursor blinks at the Apple II's roughly 1.06-second rate.
