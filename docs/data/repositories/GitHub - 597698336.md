# MariosGkMeng/Straightforward-Obsidian2Latex

Converts an Obsidian note into LaTeX, unfolding embedded notes so a paper written across linked notes becomes one document, and can then compile it to PDF. The conversion is performed by a bundled Python script that the plugin runs; commands convert the active note, or the note named by a command note in the vault, each with or without a following latexmk run. It needs Python 3 on the PATH, with a Windows option to download a private self-contained Python and numpy, and latexmk for the compile commands; the README also asks for BRAT and for the QuickAdd plugin with rules created from the settings. Settings name the Python executable, an alternative converter script path, and the required command note holding the conversion target line.
