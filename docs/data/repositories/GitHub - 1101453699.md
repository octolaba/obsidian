# jpcranford/obsidian-theme-StarlitAbyss

Starlit Abyss is an Obsidian theme modelled on the computer consoles depicted in popular 1980s science-fiction films, based on Satchelmouth's WYConsole theme. The README states that the Style Settings plugin is required for most of its options: the colour themes Terminal Green, CyberPink, Rogue AI Red, Ominous Orange, Ypsilon Yellow and Moonbase Blue, an option to take the hue from Obsidian's accent colour, multiple fonts, an OLED pure-black mode and an inverted table style. Advanced Tables, Sheets Extended, Kanban, Calendar, File Tree Alternative and April's Automatic Timelines are listed as supported plugins.
