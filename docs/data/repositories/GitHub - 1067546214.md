# mnaoumov/obsidian-fix-tab-size

Fix Tab Size is an Obsidian plugin that fixes the editor tab size according to the settings. The README states that Obsidian always inserts four spaces when Tab is pressed with "Indent using tabs" disabled, partially ignoring its own setting, and that this plugin makes the inserted indentation match the "Indent visual width" setting instead. A demo vault ships with every release and can be opened with the "Fix Tab Size: Open demo vault" command, downloaded from the releases page, or browsed in the repository; debug messages are hidden until enabled from the DevTools console.
