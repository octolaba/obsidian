# RK-Admin-01/obsidian-icon-board

Icon Board builds visual dashboards inside Obsidian, stored as a single `.iboard` file in the vault. A grid mode holds icon tiles that open folders, notes, canvases, kanban files or nested boards, each with its own Lucide icon or emoji, colour, label and subtitle. A freeform canvas mixes those tiles with sticky notes, checklists, note links carrying a live Markdown preview, images, audio players, bookmarks and kanban columns, connected by straight or elbow-routed lines and edited through multi-select, group drag, alignment, corner resizing and panning; kanban columns support drag between columns, WIP limits, rich-text items with tags and note links, and dropped media.
