# AwkMan00/obsidian-logcollector

Logcollector proxies console calls in Obsidian and writes all console output plus uncaught exceptions, including those from async code and promises on the main thread, to a file that may sit inside or outside the vault. The README presents it as a developer tool and as a way for a plugin's users to produce a log when they report a bug, and identifies it as a fork of the Logstravaganza plugin that adds out-of-vault log files, local or UTC timestamps and plain-text output. Logs can be written as NDJSON, a Markdown table, Markdown code blocks or plain text, and the file is named after the device. Recorded known issues include timings from console.timeLog and console.timeEnd not appearing, a non-functional link for out-of-vault files, and worker messages not being captured.
