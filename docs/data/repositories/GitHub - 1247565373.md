# polygonhunter/linkosaurus

An Obsidian plugin that turns words into wikilinks as they are finished, firing on space, enter or punctuation, so the note's text is linked without typing brackets. An alias can be given inline with a double or triple slash, producing a piped link, and a popup fuzzy-matched against note names, keywords and frontmatter aliases completes the target when the note's exact name is not remembered. The README states that it works on desktop and mobile, runs entirely offline and needs no setup. The repository carries no description.
