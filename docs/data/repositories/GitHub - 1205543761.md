# yinshaohua/obsidian-download-image

Download Image finds remote image URLs in the current note, downloads those files into the vault and rewrites the note to point at the local attachments, which the README frames as keeping notes self-contained, offline-available and less dependent on third-party image hosts. Two commands are provided, one saving the remote files of the current note and one cleaning unused attachments by listing orphans for review before moving them to trash or deleting them permanently. Settings cover the image naming strategy of URL hash, timestamp prefix or content hash, the number of concurrent downloads, the cleanup method and the folders excluded from orphan scans.
