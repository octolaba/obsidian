# yufenng/Export-Image-XHS

Export Image XHS exports an Obsidian note as one or more images and is a modified build of the obsidian-export-image plugin, retargeted at pictures made for sharing. Its README, written in Chinese, states that the changes concentrate on the export panel, which becomes an editable preview whose layout can be adjusted before export without altering the note; on defaults tuned for 3:4 multi-image sets; on a configurable author header covering avatar size, fonts, alignment and spacing; on text and image watermarks that survive multi-page export; and on pagination that matches the preview. It reports that the original plugin's capabilities are retained, including copying to the clipboard, PDF export, multi-image export, metadata export and folder-wide batch export.
