# unxok/obsidian-formula-forge

Renders Bases formulas inside notes, either in inline code introduced by an equals sign or in a base-formula code block that can carry extra CSS classes, re-rendering automatically when metadata changes. Inside a formula both this and file refer to the note it is rendered in. It adds utility functions to the formula language: one returns every file in the vault, one converts a markdown string into rendered HTML, a define and then pair introduces and uses local variables, and a seeded random function returns a value that stays stable for its seed. Global formulas, custom functions in global or type scope, an API and Templater integration are documented in the README.
