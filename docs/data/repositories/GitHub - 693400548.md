# hinterdupfinger/obsidian-ollama

This plugin runs prompts against a local Ollama installation from inside a note. It ships with prepared prompts that summarize, explain, expand, caption or rewrite the selection in a formal, casual, active-voice or bullet-point register, and further prompts can be configured with their own model and temperature. The prompt is sent together with the selected text or the whole note, and the result is inserted at the cursor position.
