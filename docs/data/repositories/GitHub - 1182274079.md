# RUIzg/Ankify-plus

Turns the content of the current note into Anki cards by sending it to a language model, using the DeepSeek API or another provider through a configurable endpoint, driven by an editable prompt. Generated cards are reviewed in a dialog where each card's note type can be set individually, cloze syntax in an answer selects the cloze type, a button wraps selected text as a numbered cloze deletion, and tags can be replaced on one card or on all of them. Answers are edited in a multi-line field, a collapsible panel shows the prompt, the selected content and the raw model response, and a button tests the Anki Connect connection. Note content is sent to the configured API, which needs a key and internet access, and every generated card carries a fixed ankify tag.
