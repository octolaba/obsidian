# pharelljordan/auto-tag-puller-obsidian

An Obsidian plugin that collects the lines carrying a given tag from across the vault and displays them in a note. Typing !# and picking a tag inserts a code block that rescans the vault and re-renders the matching lines each time the note is viewed, while typing $# and picking a tag pulls the matching lines into the editor as raw text, grouped by source file and numbered so they can be edited or deleted freely.
