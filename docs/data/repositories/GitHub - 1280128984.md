# zhouzeqiang/obsidian-vault-viewer

Vault Viewer adds a file-browser view to Obsidian that pairs an expandable folder tree with a file list, deliberately separating documents from other files. The tree supports drag-and-drop moves, per-folder counts, locating the active note, and a context menu for creating, deleting and copying paths; the list shows either every non-Markdown file in the current directory or the forward links and embedded files of a selected note. Office and code files are previewed in place — DOCX through docx-preview, XLSX as an HTML table with sheet switching, PPTX rendered on a canvas through pptxviewjs, and source files highlighted with Prism.js. The README also documents two themes, Simplified Chinese, Traditional Chinese and English interfaces, and a draggable divider between the two panes.
