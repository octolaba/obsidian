# Nexround/obsidian-text-lens

TextLens scans the active note for image references and inserts the text recognised in each image directly beneath it. Recognition runs on the device with PaddleOCR executed through ONNX Runtime, which the README says needs no server, no API key and no internet connection after a one-time runtime download, and offers three model sizes trading speed against accuracy. A single command processes the whole note, images that already carry an OCR block are skipped or replaced on a re-run, the batch counts as one undo step, and soft-wrapped lines are joined back into paragraphs. Output is written as a collapsible callout or a fenced block, both wikilink and Markdown image syntax are handled, and the README records Obsidian 1.7.2 or later on desktop only.
