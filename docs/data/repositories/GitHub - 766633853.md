# trucke/para-workflower

PARA Workflower adds commands for managing a vault with the PARA method: initializing the vault for the method, creating a new project, area or resource, moving the currently open item to the archive, and restoring an archived item directly or through a fuzzy search modal. Archiving an area also moves its companion folder when one exists, and both are placed in a subfolder named after the area, while archiving a project inside a project folder moves the whole folder. The recorded changelog adds input validation in the creation modal and a check for an existing project of the same name in the projects and archive folders, and warns that the version may contain breaking changes.
