# Alexandrovdi/File-Describer

File Describer creates and maintains a description note for every file in a watched folder of an Obsidian vault, so files can be found by searchable descriptions and their changes tracked. When a file appears in the tracked folder, recursively at any depth, a note is written into the configured index folder with frontmatter holding a wikilink to the file, the date added, the file type and the filename, and the user fills in description and tag fields. Moving a file updates the link, deleting one changes the note's status and leaves the choice of keeping the note as history or removing it, and a red badge on the ribbon icon signals that notes need attention. Settings cover the index folder, the tracked file types, date and time formats, and excluded folders with a reminder period.
