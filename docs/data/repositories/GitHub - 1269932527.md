# deemsd/calendar-heatmap

This repository holds Calendar Heatmap, an Obsidian plugin that adds a calendar view in the right sidebar for navigating daily notes and visualising writing activity. Clicking a day opens or creates its daily note, and heatmap intensity is derived either from the number of notes created or from the words added. Weekly notes can optionally be shown and opened, settings from the Daily Notes or Periodic Notes plugins are used where available, and week start, note folder, locale and calendar font size are configurable. The README states that the plugin runs locally with no network requests, telemetry, ads or automatic update mechanism.
