# Obsidian-TTRPG-Community/Relations

Renders the relationships between notes as graphs driven by frontmatter, so that only explicitly named connections are shown rather than every link in the vault as the built-in graph does. Relationship types carry meaning through typed line styles, notes can show portraits, and family material can be laid out as a true family tree or as a graph-style family view. Graphs are embeddable inside notes, including within callouts and infoboxes, with a legend and configurable relationship types; the stated uses are worldbuilding, fiction, tabletop campaigns and genealogies.
