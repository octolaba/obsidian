# jiaoyingxing/square

Repository publishing the installable artifacts of Square, a habit tracker for Obsidian, with a README written in Chinese. It describes a main view of small squares, one per tracked project, where each project is an ordinary Markdown note and a click opens a dialog for a confirmation, a count, free text, a date adjustment or an attachment, written back into that note. Weekly, monthly and ranking views are offered for review, projects can be archived, and the README states that the plugin deliberately omits reminders, points, leaderboards and social features. It records that the plugin is closed source and distributed outside the community directory, that a licence key stored in Obsidian's secret storage unlocks the full project count, and that no client telemetry is collected.
