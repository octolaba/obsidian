# yasd251/checkbox-sounds-plugin

Plays a sound when a checkbox is ticked, with an optional animation at the checkbox position. The README states the sound plays however the box is checked, by mouse, keyboard shortcut or otherwise, and that any mp3, wav, ogg or webm file dropped into the plugin's assets folder appears in the sound dropdown, which can be opened directly from the settings tab. Further settings choose the sound, enable the animation, pick between firework, confetti, hypno or random animation types, and scale the animation.
