# Real-Fruit-Snacks/wayback-linker

Sends the external http and https links in a note to the Internet Archive's Save Page Now service, waits for each capture to finish and rewrites the link in place to the resulting web.archive.org snapshot address, so a cited source stays readable after the original page changes or disappears. Archiving runs at three scopes: the active note from a ribbon button or command, the whole vault behind a confirmation showing link, note and URL counts and archiving each unique URL once, and a single link from the editor's context menu. Long runs show a progress window with per-URL status and a cancel button beside a clickable status-bar counter. The README states that a link is replaced only when its capture actually succeeds, a failed or cancelled URL keeping its original link untouched.
