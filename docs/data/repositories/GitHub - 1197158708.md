# evdboom/Bindery

Bindery is a Markdown book authoring toolkit that the repository describes as a VS Code extension and an Obsidian plugin paired with an MCP server. The extension side handles typography formatting — curly quotes, em-dashes, ellipses and smart apostrophes — and merges chapters for export to Markdown, DOCX, EPUB and PDF through Pandoc and LibreOffice. The MCP server exposes full-text search over the book so an assistant can navigate chapters directly instead of being handed text by hand.
