# DyllonWright/Hemi-Sync-Helper

Hemi-Sync Helper logs a Gateway Experience or Hemi-Sync listening session into the daily note as a small block: session number, start time, the wave and track that were played, and the focus level. It reads the previous session out of the note's own headings and pre-fills the dialog from it, so the session count, the start time, the pre-selected track and its focus level are all filled in, leaving the track as the only choice to make. The block is written through a single minimal editor transaction covering only the changed lines, so one undo restores the note and existing folds are kept, and the cursor is left on a blank line under a fresh notes header. There is no sidecar database; the note itself holds the state that the next session is parsed from.
