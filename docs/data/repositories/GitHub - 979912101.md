# ganesshkumar/obsidian-dayframe

Wraps daily notes in a template shown only while they are being viewed, leaving the note files themselves free of repeated boilerplate. A note counts as a daily note when its filename matches the YYYY-MM-DD pattern, and the configured template is split on a CONTENT placeholder, the part before it rendered as a prefix and the part after as a suffix in Reading view and Live Preview. The frame is rendered as markdown, so it can hold links, embeds and queries, and it stays non-editable in Live Preview so the cursor remains in the note's own content. The template can live in the plugin settings or in a chosen vault file, is not saved unless it contains the placeholder, and open daily notes re-render as soon as it changes.
