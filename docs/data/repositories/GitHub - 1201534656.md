# TekGadgt/Muse

This repository holds Muse, a distraction-free Obsidian writing plugin that generates personalized blog post topics with a language model and then drops straight into writing. Its full-screen mode hides the Obsidian interface, leaving only the prompt and the writing surface, and prompts are built from the writer's own GitHub repositories combined with their profile, with recent prompts remembered so a different one is requested each time. The README records a choice of Anthropic or OpenAI as provider, desktop and mobile support including Android with a physical keyboard, and manual installation from GitHub releases while the plugin is not yet in the community marketplace.
