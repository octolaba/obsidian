# ras0q/obsidian-graph-banner

Graph Banner displays a local graph view in the header of a note, so the note's relations appear as soon as it is opened. According to the README, installing and enabling the plugin is all that is required. It suggests the Style Settings plugin for customizing the banner's appearance and the Sync Graph Settings plugin for saving local graph settings, and warns that graph settings are reflected only the first time a note is opened, so the app has to be reloaded after they change.
