# deyixtan/obsidian-drawio-blocks

draw.io Blocks edits and renders draw.io diagrams inside Markdown code blocks, with SVG previews and modal or tab editing. It can autosave changes, support light and dark themes, and use hosted or downloaded offline editors; settings cover preview grids, borders, and XML compression.
