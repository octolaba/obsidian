# deyixtan/obsidian-drawio-blocks

Repository for draw.io Blocks, an Obsidian plugin that renders `drawio` code blocks as SVG previews and opens the hosted diagrams.net editor when a preview is selected, autosaving changes back into the original Markdown block. The README states that an internet connection is required because the editor and preview renderer are loaded from the diagrams.net embed host, with diagram XML passed to that hosted iframe. An optional setting stores diagrams as compressed XML, which shrinks the block at the cost of readability and Git diffs, and commands insert a diagram, refresh previews and reset editor settings; desktop and mobile are both supported.
