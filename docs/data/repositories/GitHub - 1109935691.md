# ratokuzmanic/obsidian-discord-webhooks

Stores Discord webhooks in Obsidian and uses them to send selected editor or preview text, or preset messages, to a Discord server. Webhooks can be added, edited and deleted, and one is chosen as the default for sending selected text from the editor menu. Preset messages carry a JSON payload following Discord's message specification, including rich embeds, and each becomes its own command in the palette; a toggle sends everything to a specified test webhook URL instead.
