# x-supermeng/noterelay

NoteRelay turns the active note into platform-specific previews and clipboard content for several Chinese and international publishing platforms, with multiple creator profiles per platform used for previews, signatures and variable replacement. The README sets explicit boundaries: no one-click or scheduled publishing, no automated login, no reading or storing of platform passwords, cookies or tokens, no calls to those platforms' publishing APIs, and a final publishing step always completed by the user in the destination editor. Output for one platform is emitted with inline CSS to reduce style loss when pasted, and the plugin is recorded as supporting Obsidian on desktop only.
