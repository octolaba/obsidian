# binnyva/obsidian-slasher

Repository for Slasher, a plugin that turns user-defined templates into editor commands, which then also appear among Obsidian's slash commands when that core plugin is enabled. Its README documents template tokens for dates such as today, tomorrow, yesterday and the file's creation and modification dates with a format filter, clipboard contents with text filters applied, and the output of a shell command. Each command can also be bound to a hotkey.
