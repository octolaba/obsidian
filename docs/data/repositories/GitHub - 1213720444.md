# giacolees/obsidian-math-convert

Math-Convert turns images of mathematical formulas into LaTeX inside Obsidian, running the FormulaNet vision-to-sequence model on the machine through transformers.js over WebAssembly rather than calling a hosted service. An image is dragged in, browsed for or pasted from the clipboard, a rectangle selects the region to convert, and the model — around 20 million parameters, fetched once from Hugging Face and then cached at roughly 100 MB — returns the LaTeX. The README states that the plugin works offline after that first download, needs no API key, subscription or GPU, and keeps images on the device, and it says the small model suits clean isolated formulas better than dense multi-formula pages.
