# notepack-app/notepack-obsidian

NotePack scans the vault's Markdown files for unchecked todos and assigns each one to a person through mention syntax, with any unmentioned todo assigned to the user. Due dates are parsed from the todo text after trigger phrases, and relative expressions are resolved against a date prefix in the filename when the file has one, so an old note's tomorrow is treated as overdue rather than due tomorrow. Sidebar views sort overdue and due-soon items to the top and group the rest, and the README describes the plugin as a port of a command-line tool aimed at managers and project leads.
