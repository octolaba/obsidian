# Akifyss/obsidian-border

Border is a highly customisable Obsidian theme whose features are largely driven by the Style Settings plugin, where auto-hiding interface elements, a card layout and a hover line indicator are enabled. Its README publishes ready-made presets, among them Boundary, Neumorphism, Translucent, Sunset and Borderless, as JSON to be pasted into Style Settings, and notes that the Translucent preset additionally needs the translucent window option and is not supported on Windows or Linux. Further options cover alternate checkboxes, callout styles and code block themes, a padded card layout and a customisable new tab. The credits record components taken from the Maple and Minimal themes, and the repository also carries a Chinese README.
