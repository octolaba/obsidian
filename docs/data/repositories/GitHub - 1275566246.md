# johannes-kaindl/vault-rag

Vault Retrieval provides on-device related-note ranking and semantic search over an embedding index stored in the vault. Its sidebar also offers grounded chat with streamed answers, editable source context, model thinking controls, endpoint prioritization, live indexing, and reformat or Smart Apply workflows. Embedding and chat requests use a configured endpoint, while retrieval remains local and can work offline.
