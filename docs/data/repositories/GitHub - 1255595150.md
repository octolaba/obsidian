# fengxuan/mails-blog-obsidian-plugin

A plugin for publishing notes from Obsidian to the Mails Blog service. It saves the current note as a draft, publishes it, syncs a linked note back from the service, shows the saved version history of a linked note, uploads an image from the vault and inserts the returned Markdown, and writes the blog binding metadata into the note's frontmatter. The README states that it requires a Mails Blog account, an Obsidian plugin token generated in the Mails iOS app and a reachable blog API base URL, and that it publishes only to Mails Blog; the rest of the file documents the project's own release and Obsidian review workflow.
