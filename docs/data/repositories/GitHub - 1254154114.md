# HWY1dot0/calendar-hub

This repository holds Calendar Hub, an Obsidian plugin that surfaces every note belonging to a given day rather than a single configured daily note. A date is matched from a note's frontmatter, from its filename or optionally from its creation date, so clicking a day can reveal several notes living in different folders. The same pane switches to a list view that browses notes by week, month, quarter or year, filtered to chosen folders. The README describes the plugin as a fork of Liam Cain's Calendar that keeps the monthly view, daily and weekly notes, note-count dots and reveal-active-note behaviour.
