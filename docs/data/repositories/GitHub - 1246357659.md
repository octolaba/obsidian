# HornatX/super-zen

Super Zen switches Obsidian into a minimal full-screen writing environment, hiding interface elements and the document's properties area so that only the text remains. The README describes frameless tabs with edge-floating text, a choice between a single-pane layout and a dual-pane comparison layout, and an option to keep tabs fixed on the right or split them left and right for multi-pane workflows. It records one shortcut that toggles the mode and another that switches between the single and dual layouts, states that pressing Escape does not leave the mode, and says each feature can be switched on or off in the settings.
