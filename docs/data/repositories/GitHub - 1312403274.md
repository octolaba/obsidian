# AshenAshes/floor-notes

Floor notes presents a Markdown note as a forum-style thread of numbered floors with replies, kept in the vault as ordinary Markdown rather than in a separate database. Floors can be added, edited, deleted, sorted and favorited, replies can be added, edited and deleted, and a dedicated sidebar lists every favorite floor with a jump back to its source record. Record bodies render as normal Markdown, including headings, lists, tables, code blocks and internal links, and composing switches between a write and a preview pane with drafts saved locally. Four layouts are available, Bubble, Glass, Paper and Timeline, stored per note in a frontmatter property with a default in settings, and colors follow either the Obsidian theme or one of several bundled palettes.
