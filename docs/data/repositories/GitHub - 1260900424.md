# zorvan/simplicial-complex

Repository for Simplicial Complex, a graph plugin that replaces pairwise links with clusters of notes treated as single higher-order units. Its README contrasts the built-in graph's statement that one note links to another with the claim that several notes form a unit only meaningful together, names the simplicial complex as the underlying mathematical object encoding those relations, and describes an interface where clusters appear as soft ambient fields and the mathematics stays hidden until asked for. A table compares simplices with tags, groups and links across one-to-many, pairwise and higher-order coherence and overlapping clusters, and the author links a post on the plugin's motivation.
