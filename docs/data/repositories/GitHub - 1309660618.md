# notesynchelper/save2obsidian

Save2Vault turns posts and threads from X into Markdown notes in an Obsidian vault, working with the Save2Obsidian service: mentioning that account in a reply under a post queues it, and the plugin pulls the prepared post into the vault on the next sync. Syncing runs from a ribbon icon or a command and can also run automatically every 5, 15, 30 or 60 minutes, with an option to delete an item from the service once its note has been written. The destination folder, file name, frontmatter and note templates use Mustache syntax with variables such as title, author, content, originalUrl and savedAt, and an identifier field is always added so repeated syncs do not create duplicates. The README states that the API key and sync requests go only to the service's API host, that no analytics or third-party relays are used, and that remote images are not downloaded.
