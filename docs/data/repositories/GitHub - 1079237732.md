# DenizOkcu/voice-md

Voice MD is an Obsidian plugin that records voice and turns it into Markdown notes using AI, described in the README as mobile-friendly capture for quick ideas, meeting recaps and conversations. Recording starts from the ribbon, the command palette or an iOS Shortcut driven by a registered Obsidian URL action, and the transcript can be inserted at the cursor or appended to the daily note under a time heading. The README states that stopped recordings are saved locally before transcription so network failures can be retried, that speaker identification for conversations is optional, and that audio and optional transcript post-processing use OpenAI with no telemetry.
