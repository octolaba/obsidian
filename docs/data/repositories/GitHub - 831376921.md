# oxdc/obsidian-vertical-tabs

Vertical Tabs lays the open tabs of an Obsidian workspace out as a vertical list and lets them be grouped and organised. The README states the problem it addresses: with many notes open, the default horizontal tab layout makes tabs narrower and their titles harder to read, so locating and switching between them becomes difficult. Documentation is kept on a separate site, with a feature tour and a quick start guide linked from the README. A paid subscription is described as required only to download beta versions, and an installed version may then be used for as long as the user wants.
