# iY0Yi/obsidian_glslviewer

This repository holds GLSL Viewer, described upstream as previewing GLSL shaders on Obsidian. The README says a glsl code block carrying a viewer directive is rendered as a running shader, with directives written in single-line or multi-line comments controlling aspect ratio, autoplay and code visibility. It lists limited Shadertoy syntax compatibility, images from the vault loaded as textures, a texture browser and texture shortcuts, a template system, automatic thumbnails for shaders that do not autoplay, and configurable folders for templates and thumbnails.
