# Vinzent03/obsidian-sort-and-permute-lines

Obsidian plugin that sorts and permutes lines in a whole file or in a selection. Its commands sort alphabetically, sort by the length of the line, reverse the line order, shuffle it, and sort headings while preserving their parents. Calling a command with nothing selected changes the whole file, while selecting text first limits the change to that range.
