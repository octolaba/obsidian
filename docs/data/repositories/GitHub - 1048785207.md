# nickfreedom/obsidian-graphic-organizer

The repository holds Graphic Organizer, an Obsidian plugin that draws the vault's folder and file hierarchy as an interactive vertical tree in a sidebar view. The README records lazy loading of folder children on first expansion, updates that follow changes to the vault, zoom and pan for navigating large vaults, distinctive icons per file type, and rendering through Konva.js with Svelte. Clicking a file opens it in a new tab, clicking a folder expands or collapses it, dragging moves files and folders with valid drop targets highlighted, and right-click menus create, rename and delete notes, folders, canvases and bases. Settings record a large-folder warning threshold and animation options.
