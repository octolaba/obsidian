# reallygood83/reallygood-research

ReallyGood Research is a desktop-only Obsidian and CLI deep-research publisher that drives NotebookLM through a local MCP command and Tavily through its API, and adds ribbon buttons for its research console and for opening the HTML report matching the active generated Markdown note. The README states that the plugin is desktop-only because it writes files directly into the local vault, that it carries no client-side telemetry or ads, and that network requests are made only by the provider being run. It records where credentials and tools live outside the vault: Tavily keys are saved to a file in the home directory rather than in Obsidian settings, NotebookLM runs under the user's own Google login, and optional AI synthesis invokes a local CLI the user selects.
