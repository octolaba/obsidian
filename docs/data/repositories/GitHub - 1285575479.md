# xupisco/obsidian-suble-toc

Subtle TOC places a dashed minimap along the edge of a note, one dash per heading and sized by heading level, which opens a floating popover outline on hover or on click. The outline highlights the heading of the section being read and jumps to any heading when clicked, tracking the active heading in Live Preview, Source and Reading mode; an optional mode previews a heading's section as the pointer moves across rows, returning to the previous position on leaving. A second tab lists the note's unchecked tasks in document order with a live count, an edge badge shows that count even when the note has no headings, and completing a task from the popover is an option.
