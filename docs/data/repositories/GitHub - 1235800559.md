# p1ngul1n0/obsidian-sherlockeye-plugin

This plugin integrates the Sherlockeye OSINT API into Obsidian, searching for emails, phone numbers, domains, usernames and other identifiers and writing the results into the vault as notes. The README states that a search is started by highlighting text and using the context menu, or by right-clicking a file to search by its title, and that results are organised into notes automatically. It also lists CPF and CNPJ searches for Brazil and a deep search mode for expanded results, and records that a valid Sherlockeye API key set in the plugin settings is required.
