# ysf-ad/semantic-auto-linker

Semantic Auto-Linker suggests wiki links between notes and shows how accepting them would reshape the vault graph before anything is written. The README describes analysing the current note or the whole vault, choosing exact matches, AI matches or both for a vault-wide scan, reviewing every suggestion while the graph preview updates, and keeping a sidebar open for contextual suggestions carrying confidence, source type, context and one-click exclusion of a target. It also describes an embedding explorer that projects the vault into a semantic vector space so that similar notes and extracted concepts sit close together even when no link joins them, which the README offers as a view of relationships the existing graph does not show.
