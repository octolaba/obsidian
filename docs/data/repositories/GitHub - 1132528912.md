# shuxueshuxue/obsidian-embedding-plugin

Embedding builds vector embeddings for the notes in a vault and opens a floating panel listing the notes most similar to the current one, navigated with single-letter keys — a reopens the original note, later letters open ranked neighbours, and z recomputes from the note now open. The README states that OpenAI embeddings via an API key are the only supported backend, with the model, dimensions, base URL, input length, similarity limit and batch size configurable, and that vectors are stored in embeddings.json at the vault root. An optional MCP JSON-RPC server can be enabled to expose semantic search and note fetching over a local address.
