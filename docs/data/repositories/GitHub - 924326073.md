# bfloydd/streams

Streams creates and manages several parallel sets of daily notes, which the README positions as a replacement for the Daily Note core plugin and credits to the Periodic Notes and Calendar plugins as inspiration. Each stream has its own calendar, a separate view lists the notes missing from a stream, and a navigation bar selects between streams; a stream is configured in the settings by pointing it at the folder holding its notes. The README suggests splitting a crowded daily note into separate work or school streams and encrypting one of them, and records a public API through which other plugins can reach stream data.
