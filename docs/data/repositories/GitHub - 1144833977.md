# achekulaev/obsidian-qmd

QMD Semantic Search adds vector search over an Obsidian vault by driving QMD, a standalone command-line tool for semantic Markdown search, so that indexing and embedding run on the local machine rather than through an API or remote model. Notes are indexed and embedded in the background as they are created and edited, searches are debounced by one second and cancelled when typing resumes, and results are shown in a search modal or an optional sidebar pane. The README records a fallback to BM25 keyword search when semantic search is unavailable, and states that the plugin is desktop only because it needs filesystem access, with QMD itself requiring Bun and roughly 300MB of disk for its embedding model.
