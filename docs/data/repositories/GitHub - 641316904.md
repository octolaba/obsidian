# NekoTarou/lskypro-auto-upload

The repository description is in Chinese and states that the plugin uploads images directly to an Lsky image host, adapted from the obsidian-image-auto-upload-plugin project. The README records a command that walks every Markdown note in the vault, uploads the local images it finds and replaces the links with the uploaded URLs, reusing the same per-note upload routine. It notes that the upload routine now takes a file argument and runs sequentially, using the editor for the active note and reading and writing the file directly for other notes, and that the handling of network images follows the existing settings and domain filters.
