# XJain03/roim-picx-uploader

Roim PicX Uploader uploads images from Obsidian to a Roim PicX instance and replaces the original addresses in the note with the returned ones. It processes images pasted with the keyboard, dragged in from the file system, or already present as external URLs in a note, including files clipped with Obsidian Web Clipper, whose new Markdown files it detects and rewrites; it recognises the several Markdown, embed and HTML image forms, decodes camo.githubusercontent.com addresses to fetch from the original source, and skips badges, shields and other non-content images. Settings cover the API endpoint and token, an optional folder prefix, copying the returned URL to the clipboard, and deleting the local file after upload, and a command uploads every external image in the active note on demand.
