# kpaede/Verovio-Music-Renderer

Verovio Music Renderer renders, plays and edits musical notation in Obsidian using Verovio, the open-source library that engraves MEI scores and other encodings into SVG. It renders MEI, MusicXML, ABC, PAE, Humdrum, CMME, GABC and Volpiano notation from files in the vault by relative path, from URLs by absolute path, and directly from code blocks, including selections of specific measures. A side panel edits the musical code with XML and MEI syntax highlighting, adjusts per-rendering settings and converts non-MEI sources to MEI; for MEI the score and the editor are linked both ways, so clicking a rendered element jumps to its line and clicking a line selects the matching element. The README also documents a quick sketching editor, conversion to MEI from the command palette, and a download button for the rendered SVG.
