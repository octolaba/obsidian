# GizmoRay/obsidian-goal-tracker

This repository holds Goal Tracker, whose README describes tracking goals through a goal-calendar code block placed in a note and rendered as a daily, weekly or monthly view with a customizable title. Progress is stored as JSON inside the block itself, so the data lives in the note, and a streak option adds a longest-recent-streak display. The README states that no other plugin and no custom coding are required. No upstream repository description is recorded, so this body rests on the README alone.
