# ELowry/obsidian-replace-commands

Replace Commands stores named search-and-replace actions that can use plain text or JavaScript regular expressions. Actions may target a selection or whole document, chain and reorder rules, preview intermediate results, and apply as one undoable transaction from the command palette or editor context menu.
