# esm7/obsidian-vimrc-support

Obsidian plugin that loads a file of Vim commands from the vault root, so settings and key mappings for Obsidian's built-in Vim mode persist between sessions. The README is explicit that this is not Obsidian's Vim support — that is built in and usable without the plugin — and that this plugin only adds the persistent configuration and a few extras. The commands available are whatever the underlying CodeMirror Vim implementation accepts, blank lines and Vimscript comments are skipped, and yanking to the system clipboard is enabled by a setting. Two notices open the README: newer Obsidian versions need an explicit line ending on normal-mode Ex command mappings after a breaking change in that library, and the author is asking for a maintainer.
