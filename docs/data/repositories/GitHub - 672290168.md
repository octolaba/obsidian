# Quorafind/Obsidian-Fold-Anywhere

Folds an arbitrary range of text rather than only structural elements such as headings or lists. A start and an end mark are placed at the cursor, and commands then fold or unfold everything between them, fold the current selection directly, or remove all marks. The same actions are available from the editor context menu, and a click folds the marked range while ctrl-click removes a mark.
