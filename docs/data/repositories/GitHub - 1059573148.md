# bastiangx/poimandres.obsidian

This repository is an extended port of the Poimandres colour scheme to Obsidian. The README quotes the original description of Poimandres as a minimal, frameless dark theme inspired mostly by the blueberry theme for VS Code, focused on semantic meaning rather than colour variety, colouring things like errors, voids and throws. A Storm variant can be switched on through the Style Settings plugin, and the README also shows the typography and checkbox styling.
