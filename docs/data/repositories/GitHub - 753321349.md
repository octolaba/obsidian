# yunidev-uk/obsidian-frontmatter-viewmode

This repository holds a plugin described upstream as using YAML frontmatter to specify a view mode per note. The README says no configuration is needed beyond a single prefer-view property at the top of a note, which accepts the values read, edit, edit-source and edit-preview. The edit value defers to the default editing mode configured in Obsidian's own settings, while the other two select source mode or live preview explicitly.
