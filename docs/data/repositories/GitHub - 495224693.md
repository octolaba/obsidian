# Fevol/obsidian-translate

This plugin adds commands for translating selected text and whole files, together with a customizable translation interface that integrates with ten translation services. A service is chosen and validated in the plugin's settings before use, and the README states that most services require signing up for an account and that the plugin itself provides no API keys. Three options need no sign-up, namely Bergamot, LibreTranslate and Lingva Translate, and all of them can be hosted on the user's own machine, with Bergamot working directly from Obsidian and the other two set up through Docker.
