# daelynum/obsidian-cloudbeaver-plugin

This plugin runs SQL against any database a self-hosted CloudBeaver server is connected to, from inside the vault. Queries are written in a cloudbeaver code block, optionally naming a connection alias, and executed with the cursor inside the block from a results panel that docks in the sidebar or a tab. Connections are read-only until writes are explicitly enabled, refusing anything that is not a SELECT, WITH, SHOW, EXPLAIN or DESCRIBE, and each can override its default database or schema; a row limit and query timeout are configurable, and the last 50 queries can be browsed and copied back. It requires Obsidian 1.7.2 or later on desktop, stores credentials in the plugin's data file inside the vault, and deliberately offers no schema browser, autocomplete or result editing.
