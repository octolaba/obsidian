# take6/obsidian-plugin-auto-hyperlink

Obsidian plugin that inserts hyperlinks into the reading view of a document according to rules the user defines. Rules are written as JSON in the settings pane: the key is a pattern matched against the text and handed to the JavaScript RegExp constructor so regular expressions work, and the value is a URL template that can embed the matched string through placeholders such as the whole-match placeholder. A missing https prefix is added automatically, so a template must start with http explicitly to reach a non-secure site. The README marks the option that inserts links into the editor view as experimental and warns that it edits documents directly and can produce unexpected results.
