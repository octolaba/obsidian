# Padane22-spec/obsidian-export-markdown-zip

Export markdown ZIP packages one note together with the notes it links to, recursively, and the local attachments they embed, writing them as a single zip archive. The README states that wiki links and Markdown links are followed, that images, PDFs, audio and other linked files are included, and that internal links are rewritten to relative Markdown paths so the extracted bundle still resolves. Export runs from the command palette or the file context menu, into a directory chosen each time or configured as a default, and the plugin is described as desktop-only.
