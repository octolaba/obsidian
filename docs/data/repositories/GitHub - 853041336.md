# jparkerweb/rich-foot

Rich Foot appends a footer to notes carrying backlinks, the links from other notes to this one, outlinks, the links from this note to others, and the note's created and modified dates. Links are displayed as tags, links declared in frontmatter are detected as well as those in the body, and outlinks are disabled by default. The settings toggle the visibility of each element and adjust the appearance through opacity and border controls, and folders can be excluded from receiving the footer.
