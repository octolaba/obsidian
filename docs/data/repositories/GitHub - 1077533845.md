# snipd-app/snipd-obsidian

Repository for the Snipd plugin, maintained by the Snipd team. Its README describes syncing podcast highlights, called snips, from the Snipd app into the vault, each carrying transcript, AI summary, the user's own notes, a link back to the snip, and podcast metadata such as image, title and publish date. Formatting is customisable, syncing can be limited to edited snips, and the README records compatibility with Obsidian Bases through metadata properties and two default views.
