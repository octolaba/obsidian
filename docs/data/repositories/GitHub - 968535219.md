# Chen2226/obsidian-typecho

This plugin synchronizes files from Obsidian to a Typecho blog through a Typecho Restful API plugin installed on the blog side. The README records publishing posts with categories and tags, browsing existing posts and saving them locally. Its configuration holds the host address, a token set after the API plugin is installed, and an operating user that is retrieved automatically once the first two are filled in.
