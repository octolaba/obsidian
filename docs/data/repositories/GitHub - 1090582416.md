# Ninjalope/obsidian-sortable-file-explorer

Repository for Sortable File Explorer, an alternative file explorer that runs as its own view beside Obsidian's built-in one rather than replacing it. The README records drag-and-drop reordering for a manual sort order, multi-selection with Shift and Ctrl or Cmd, batch move, duplicate and delete, inline rename, a toggle for showing file extensions, and dragging files in from the operating system. Custom order and folder collapse state are stored in the plugin's data file so they can travel between synced machines.
