# Mvstro/canvas-node-linker

This repository holds Canvas Node Linker, an Obsidian plugin that adds a Copy Node Link entry to the right-click menu of any canvas node or group, copying a ready-to-paste wikilink to the clipboard. For a text node the first heading found in its content becomes the display text, for a group the group label is used, and when neither exists the link is copied bare. The README points readers who do not need the node-level variant to a separate plugin that links to groups only.
