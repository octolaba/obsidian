# Caffa/Obsidian-Current-Folder-Note-Display-Plugin

Current Folder Notes Pane opens a sidebar listing the notes of the folder containing the active file, sorted so that chapter-numbered filenames come out in order, which the README frames around novel and research projects kept in one folder. Filters include or exclude notes by words in their titles, subfolder notes can be included, titles can be reformatted in title case, and the active file is marked in the list. The pane can also show the headings of the current file or of every file in the folder, and clicking a heading jumps to that section.
