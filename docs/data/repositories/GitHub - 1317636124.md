# Luis85/backlog-view

Adds a Product Backlog view type to Obsidian's Bases, rendering a flat folder of notes as a sortable work-item tree of epics, features, PBIs and tasks, with Issue, Bug, Idea, Deliverable and Milestone as additional types. The hierarchy comes from three frontmatter properties rather than subfolders: a link to the parent item, a numeric order among siblings, and a type; notes matching neither a configured level nor a parent are left out of the tree. The view writes those properties itself when items are created or dragged, a drag never reclassifying an item's type, and a toolbar button backfills missing type, order and optional properties without overwriting existing values. Every such write is undoable in one step, and the view needs Obsidian 1.12.0 or newer with the Bases core plugin enabled.
