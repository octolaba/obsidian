# caseybecking/obsidian-linear-plugin

The repository records no description; its README presents a plugin that integrates the Linear issue tracker with Obsidian by embedding and filtering issues inside notes. Issues are pulled into a fenced block tagged linear, naming either a single issue id or a YAML list of ids that are rendered in the order given, with an error shown for an id that cannot be found. Display options in the same block limit the number of issues shown and filter by team, by status with case-insensitive and punctuation-tolerant matching, or by assignee email, and further options sort by due date in either direction and hide descriptions. The README states that the plugin is desktop-only and does not support mobile.
