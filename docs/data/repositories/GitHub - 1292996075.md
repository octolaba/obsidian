# Real-Fruit-Snacks/Graphite

Graphite is a task manager for Obsidian in which every task is a line in a plain Markdown file, organized one file per month, with no account, database or external service; the README states that despite the Todoist-like design it never connects to Todoist. Its views are Inbox, Today with an overdue section, Upcoming, Projects, Filters and Labels, Activity with a 26-week heatmap, Completed and Search. Tasks carry titles, descriptions, projects, P1 to P4 priorities, due dates, deadlines, labels, attachments and nested sub-tasks, and can recur on daily, weekly, weekday, monthly, yearly or custom rules counted from the calendar or from completion. Quick capture adds tasks from the board, a full-screen mobile composer or the command palette with inline label and project tokens, deletions always ask for confirmation, and the README states there is no telemetry and no network call.
