# jstoolsspace/colorpalette-obsidian-plugin

Palette Vault generates color schemes inside Obsidian from a ribbon panel offering four colors, a scheme picker and a reroll, optionally built around a color selected in the note. Every hex code in a note gets an inline color square in editing and reading mode, with RGB, HSL and OKLCH values and contrast against white shown on hover. A fenced palette block renders as a strip of clickable swatches, listing hex codes or generating them from directives for scheme, base color, seed and label. Colors can also be clustered out of an image embedded in a note, an eyedropper command inserts a color picked anywhere on screen, and the plugin runs locally with no account or network.
