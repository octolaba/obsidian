# SATOSprod/Auto-GitKeep

An Obsidian plugin that places a .gitkeep file in every folder of the vault so that Git, which does not track empty directories, keeps them in the repository. It scans the whole vault when it loads, watches for folders created or renamed and adds the placeholder to them, and takes a configurable list of paths to skip such as the Obsidian and trash folders. Settings hold manual actions to add the file everywhere or remove all of them again, plus a status panel counting total folders, excluded folders and placeholders present. The README states that Obsidian 1.7.2 or later is required, that desktop and mobile both work, and that the license is proprietary.
