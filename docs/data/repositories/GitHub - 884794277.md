# linqing24/obsidian-simple-focus

Simple Focus hides the other files in the Obsidian file list so that a single file or folder is in view. A focus entry is added to the right-click menu of a file, and clicking it applies the focus. The README documents installation through BRAT or by copying the built files into the vault's plugin folder, and it is written in both English and Chinese.
