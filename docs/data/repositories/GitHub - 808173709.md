# Papyrus-doc-ai/papyrus-obsidian

Papyrus applies generative AI to the document being edited, improving its grammar or finding flaws in its structure. Commands that would otherwise overwrite the document instead write the proposed version to a temporary file and open it beside the original, with a right sidebar offering to accept or refuse the changes, so the new version can be checked and edited first. The structure command presents the flaws it found, lets the user select which of them to tackle, expands each one and asks for clarification before proposing a new version of the document. The README states that an OpenAI key and a target model are set in the plugin settings.
