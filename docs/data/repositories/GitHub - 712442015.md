# stellacube/formatto

This repository holds Formatto, described upstream as a simple, fast and easy-to-use Obsidian Markdown formatter. The README says the formatter is written in Rust with user-customizable options, and can be run from the editor context menu, from a Format Document command that accepts a keyboard shortcut, or from a ribbon action. It states that the plugin was designed to work best in source mode rather than in the live preview that Obsidian uses by default.
