# FireIsGood/obsidian-everforest-enchanted

Everforest Enchanted is described as an Obsidian port of the Everforest theme family, remade from scratch after the author had issues with the styling of a similarly named project. Its README records light and dark palettes derived from Everforest's Hard and Soft themes, separate colours for internal and external links, image styling by ID with alt text captions and inline grids, embed styling by alt text, custom callouts and code block language labels. Extra options come through the Style Settings plugin, including header underlines, custom line length with a separate wide width, image zoom, full-width tables, custom background images, stacked panes counted rather than measured, and a visual parity option that makes reading mode look like editing mode.
