# millioncheung/obsidian-calendar-ledger

Calendar Ledger generates a continuous calendar covering a chosen range of years and keeps every record in one Markdown file rather than a separate database. A sidebar view offers Content, Upcoming, Stats, Heatmap and Year tabs, while commands jump to a date or add a record to today or a selected day. Entries are date bullets carrying tags, wikilinks and date ranges, with weekday language, week start day and ISO week headings configurable. A migration command normalizes older nested date structures, and the sidebar refreshes when the calendar file changes.
