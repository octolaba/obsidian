# lachsh/obsidian-recipe-view

Recipe View renders an ordinary Obsidian note as an interactive recipe card for use while cooking, so recipes stay plain Markdown notes in whatever format they were written and can be cross-linked, tagged and queried like any other note. The card scales the quantities in a recipe, can split it into two columns or group ingredients by step, makes ingredient lists crossable-out and lets steps be highlighted to mark progress. The README states that it works on phones and tablets and aims for compatibility with custom themes, and that beta versions can be installed through BRAT alongside the community plugin browser.
