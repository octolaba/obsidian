# TiagoJacinto/obsidian-object-oriented-thinking

Obsidian plugin that adds inheritance-like behaviour to notes. A note names its parent through a frontmatter property, by default called extends, holding a link to that parent note. The plugin exposes utility methods that resolve a file by link or by path and return it with a test for whether it descends from another file, and the README shows defining further functions on top of them, either directly or through a JavaScript loader plugin.
