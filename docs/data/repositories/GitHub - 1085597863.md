# volodinroman/obsidian-tech001-theme

Tech001 is a high-contrast Obsidian theme aimed at developers, technical writers and minimalists, taking its design cues from Google AI Studio and Material Design 3. It ships a Deep Dark mode with pastel syntax highlighting and Gemini Blue accents and a Clean Light mode with white surfaces and Google Blue accents. The README describes generic file icons replaced by text badges derived from the file extension, code-block headers in Live Preview, VS Code style syntax colours, and Notion-style centred content with the scrollbar kept at the far right edge.
