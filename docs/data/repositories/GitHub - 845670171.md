# Mara-Li/obsidian-edit-shortcut

Edit mode switch adds a button to the file header while editing that switches between Source mode and Live Preview. Three settings change its behaviour: reversing the icons so the button shows the mode it will switch to rather than the current one, including Reading mode so one button cycles through a configurable order, and an all-button mode that gives each of Source, Live Preview and Reading its own button, highlighting the active one, which is not compatible with the other two options. The plugin exposes CSS classes for the button, for hiding the Reading button and for the default button in the three-mode layout. The README states that it does not work if Live Preview or the file header is disabled.
