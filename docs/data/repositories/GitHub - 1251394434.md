# xuhuaya0/obsidian-plan-panel

Plan Panel turns the Markdown task lists of the active file into a lightweight planning board. Its README records a Today list gathering the tasks marked with a today tag, Eisenhower-style quadrants, drag-and-drop ordering inside both, and recognition of the dash, asterisk and numbered checkbox formats. Completion and start times are tracked through tags the plugin writes directly into the task line, one carrying the completion date and the other the start date and time.
