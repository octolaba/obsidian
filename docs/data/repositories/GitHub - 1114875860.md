# junhewk/simple-graph-builder

Simple Graph Builder creates a lightweight knowledge graph from Obsidian notes using LLM entity extraction, ten fixed entity types, free-form relationship verbs, and relationship details. It combines entity resolution and schema validation with natural-language search, multiple model providers, internal-link processing, an interactive graph view, neighborhood exploration, and manual merging.
