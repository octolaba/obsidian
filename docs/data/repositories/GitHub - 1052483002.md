# davidvkimball/obsidian-property-over-file-name

Property Over File Name lets Obsidian search, display and insert notes by a chosen note property, such as title, instead of by the file name. The README records that the property is shown in the link suggester, quick switcher, graph view, tab titles, backlinks, bookmarks, window frame and file explorer, and that new notes can be created from the suggester and the switcher. Fuzzy search can be configured to include file names and aliases, a simple search toggle is offered for larger vaults, and dragging notes out of the file explorer and folder note file names are supported. It is described as part of the Vault CMS project and as helpful alongside the Astro Composer plugin.
