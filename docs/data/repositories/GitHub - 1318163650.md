# CMSZ001/obsidian-tsconfig-alias

Resolves path-alias image references of the kind used by Astro and Vite projects, reading the alias map from the compilerOptions paths entry of a tsconfig file at the vault root. Rendered image elements and Obsidian embed placeholders are rewritten at display time in both reading view and live preview, through a markdown post-processor and a mutation observer, so the notes on disk are never edited. Relative paths that Obsidian itself fails to resolve are retried as vault-root paths, and the alias map reloads when the tsconfig file changes or on a dedicated command.
