# nextbound/bragi-canvas

Bragi Canvas turns Obsidian Canvas into a node-based generation workspace: selected nodes and their incoming edges become prompts and reference inputs, the chosen model runs, and the output is written back to the canvas as connected nodes. Generation covers images, videos, text, speech, music and sound effects, with batch generation from one prompt, upstream references displayed on the nodes, and tools to arrange nodes, duplicate connected workflows, split images into tiles, pin media and download outputs. Workflows import and export as portable packages, and the active canvas can optionally be exposed through a local MCP server for agent automation. The README states it is desktop only, needs Obsidian 1.8.7 or newer, at least one configured provider key, and an English UI language because its toolbar hooks depend on Obsidian's English canvas labels.
