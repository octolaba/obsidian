# JeffSteinbok/obsidian-onedrive

Obsidian plugin that syncs a vault with a OneDrive personal account, talking to the service itself rather than relying on the OneDrive desktop client. Connecting needs no Azure app registration, and a device code flow makes the same connection work on iOS and Android without redirects. Sync is bidirectional and driven by vault file change events instead of polling, conflicts are settled by a configurable choice of overwrite, duplicate or manual resolution, workspace state files are deliberately excluded, and an experimental pull-only mode covers read-only vaults and backup recovery. Access is either an isolated app folder or full access to a chosen location, and the README states that this is not an official Microsoft plugin.
