# JeffSteinbok/obsidian-onedrive

Obsidian OneDrive Sync provides bidirectional vault synchronization for personal and work or school Microsoft accounts, with device-code authentication available on mobile. It reacts to file changes, supports configurable conflict handling, app-folder or full-access modes, and an experimental pull-only mode while excluding workspace state files.
