# Felvesthe/Note-Locker

Note Locker is an Obsidian plugin that locks a note into preview mode to prevent accidental edits. A note is locked or unlocked from the file explorer's context menu or from the editor's, locks survive restarts and follow a file through a rename, and the plugin shows a notification on each change; it works on desktop and mobile. The README states that the lock is not access control: edit mode can still be entered deliberately, after which the note returns to preview when it is reopened, so the feature is aimed at protecting finalized notes while allowing intentional edits.
