# leotomhal/sector-tasks-obsidian

Sector Tasks is a task dashboard that reads and writes a single Markdown file in Tasks-plugin emoji format and therefore requires the Obsidian Tasks plugin, delegating creation and editing to Tasks' own input modal rather than defining a second task syntax. The board groups tasks by configurable sector tags, defaulting to a set that implements Carl Pullein's Time Sector System, where tasks are organised by when they will be done rather than by project, plus an Inbox for tasks carrying no sector tag. The README states that the plugin does not enforce that system: sectors are only tags, and their names, order and review can be changed.
