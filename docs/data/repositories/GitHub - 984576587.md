# Apoo711/obsidian-3d-graph

3D Graph is an Obsidian plugin that renders a vault as a force-directed graph in three dimensions. Its physics runs in a dedicated Web Worker as a Rust WebAssembly engine using 128-bit SIMD intrinsics and a three-dimensional Barnes-Hut octree, which the README claims handles more than 50,000 nodes and edges at over 60 frames per second, with zero-copy array buffer transfers to avoid garbage collection pauses and kinetic-energy cooling that stops the simulation once the layout settles. Shapes, sizes and colours can be set independently for notes, attachments and tags, and repulsion, attraction, gravity and damping are adjusted with live sliders. Path, tag, file and text queries build colour-coded groups, filter tags, attachments and orphans, and highlight a node's neighbours.
