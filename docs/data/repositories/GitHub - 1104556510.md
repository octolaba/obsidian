# TheJusticeMan/obsidian-mobile-plugin

Mobile UX adds a floating action button and context-aware toolbars to Obsidian on mobile. The button runs one command on tap and another on long-press, anchors itself to the active editor leaf so it does not overlap navigation, and can be dragged to draw a gesture; an unrecognised shape prompts for a command to bind to it, and shapes are then matched at any size or speed. Toolbars are defined in a library and bound to contexts such as selection, list, task, heading, code block, table, blockquote and link with a default fallback, several toolbars on one context being merged, and buttons hide themselves when their command is unavailable.
