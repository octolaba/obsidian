# olillin/obsidian-kale-graph

The recorded description says the plugin renders mathematical graphs in Obsidian, in the graph-theory sense of the word. Per the README a code block with the language kale is parsed line by line, and a line either specifies flags, adds vertices or adds edges but never more than one of those; flags are the letters on a first line that begins with a hyphen. Vertex names may contain any character that is neither a control character nor part of the Kale syntax, definitions after the first for one name are silently ignored, and a name beginning with an underscore makes an invisible vertex that is not rendered but still offsets the others and need not be unique.
