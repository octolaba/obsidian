# elliotxx/obsidian-simple-todo

Simple Todo manages tasks as plain text under date headings, compatible with ordinary Markdown syntax, and cycles a task between todo, in progress and done. Recorded commands toggle a task's status, reschedule unfinished tasks from the most recent day onto today, and archive completed tasks by month into a dedicated directory. A date line must follow the recorded format and a task line must begin with one of the three checkbox markers to be recognised, and the interface is available in English and Chinese.
