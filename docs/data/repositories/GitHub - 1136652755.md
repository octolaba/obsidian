# open-obsidian-i18n/i18n-plus

i18n+ manages translations for Obsidian plugins from a single panel that shows every plugin's translation status and lets each one's language be switched independently. Switching a locale refreshes i18n+'s own interface and restarts the affected third-party plugin so the new locale applies immediately, while an overlay mode corrects individual translations without altering the original plugin. Translation files are imported and exported as JSON for sharing, and community translation packages can be downloaded from the cloud. For plugin developers it describes zero-dependency adapters that work whether or not i18n+ is installed, external dictionaries that override or extend built-in languages, and an automated migration that rewrites hardcoded strings into translation calls.
