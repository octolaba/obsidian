# groldsf/obsidian_check_plugin

Keeps parent and child checkboxes in a hierarchical list in step with each other. The README states that a parent is checked or unchecked automatically according to the state of its children, and that a manual change to a parent can optionally cascade down to its children, with the synchronisation direction configurable upward, downward or both. It lists support for ordered and unordered lists, respect for indentation in nested hierarchies, configurable symbols for what counts as checked, unchecked or ignored, file ignore rules, and an option to switch off the automatic synchronisation that runs when a file is opened.
