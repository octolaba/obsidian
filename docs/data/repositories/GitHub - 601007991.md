# songkg7/o2

Obsidian plugin that converts Obsidian Markdown files for other Markdown platforms, currently Jekyll Chirpy and Docusaurus. It expects a particular vault folder structure, whose folder names can be changed in settings; notes to convert are moved into a ready folder and then converted by running the plugin's grammar transformation command. A warning at the top of the README records that development of new features has been discontinued, because the author is now envisioning a tool not tied to the Obsidian platform.
