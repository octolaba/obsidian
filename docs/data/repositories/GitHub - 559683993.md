# MMoMM-org/obsidian-dynbedded

Obsidian plugin that embeds snippets, templates and other linkable notes by delegating the current scope to the embedded file, so that dynamic content in the embedded note executes in the context of the active note; the README's example is a Dataview script that reports the active note's inline links rather than the embedded note's. A target can be named directly or through a date naming format relative to today, substituting part of a note name or a header with the current date in any format. The README also presents the plugin as a replacement for the deprecated Quoth plugin, rendering existing Quoth code blocks without rewriting them once the corresponding setting is enabled.
