# anareaty/task-count

Task Count writes the number of tasks in the active Obsidian note into frontmatter properties chosen in its settings, counting only when at least one of those properties is present in the note. Separate properties exist for different kinds of counts, and the README records support for regular checkbox tasks as well as tasks created by the TaskNotes plugin and related to the current note. Counting can update automatically on every task change or be triggered by an update command, and the README notes the automatic option can affect performance and produce frequent notifications. The plugin was split out of the author's Pretty Properties plugin, which the README says still carries the same feature, so it warns against enabling task counting in both at once.
