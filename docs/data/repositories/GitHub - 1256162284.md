# santiyounger/obsidian-santi-younger-tools

Santi Younger Tools installs and updates plugins and themes from one vendor's catalog after the user signs in with a one-time email code. The README is explicit that the plugin is not a purchase tool and serves existing buyers only: the catalog is paid, purchases happen on the vendor's platform rather than in Obsidian, and the plugin merely installs and updates products already tied to the account. Its disclosure table records the hosts it contacts for login, entitlements and install files, that install files may come from GitHub releases and preview images from a CDN, that no telemetry is collected, and that session and install metadata are kept in the plugin data file while installs write into the vault's plugins and themes folders. It also notes that the catalog products are largely outside the community directory and carry their own terms.
