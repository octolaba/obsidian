# workingyuanyuan/obsidian-kage-theme

Kage is a dark, editorial Obsidian theme that builds its ground in layers: a black base, a warm light leak composited on top, and a static film grain from a fixed seed that never flickers or shifts when scrolling. The leak is anchored outside the frame, so the centre of the page stays dark and the edges glow, and its strength is graded by page type, leaving the text column of a note clean. A paper mode follows Obsidian's own base color scheme and mirrors the same specification with an aged-paper base and multiply blending. Typography is serif-led with sans reserved for navigation and numerals, decoration is limited to hairline corners and flat shadows, and one orange-brown accent family runs throughout, so Obsidian's accent color picker has no effect.
