# CosmicSeaFox/vault-sweep

Scans a vault for cleanup candidates and reports them by category: files sharing a name across folders, attachments no note references, empty notes, notes still called Untitled, notes with no links in or out, and files above a chosen size. Nothing is deleted automatically; the scan is read-only, and results are reviewed and selected before any action runs. Selected items can be kept, excluded from future scans, moved to the system trash, or deleted permanently behind an extra confirmation, and excluded folders stay out of scope. The scan runs from a command or a ribbon icon, works entirely offline, and sends no vault data anywhere.
