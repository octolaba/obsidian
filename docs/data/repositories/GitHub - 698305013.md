# HananoshikaYomaru/obsidian-run

Obsidian Run generates Markdown inside a note from a Dataview query or JavaScript expression written in a comment block. A run block has a starting tag holding the expression, the generated content, and an ending tag; a multi-line expression is written as a fenced snippet inside the starting tag and must return a value. Generation is triggered on save, which the README wires up by installing the companion custom-save plugin and adding the plugin's run command to its save actions. Because the result is written into the note as plain Markdown, it stays readable in any Markdown editor or renderer, and an option records the block's update time and any error as metadata on the ending tag.
