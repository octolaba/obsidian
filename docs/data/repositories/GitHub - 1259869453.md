# vkamolov/obsidian-drum-notation

Obsidian Drum Notation renders drum-kit patterns written in code blocks as SVG percussion staff notation and plays them back. The README documents a notation format with time signatures and beam grouping inherited at system level, tuplets written as one written beat, as explicit note-value spans or as written-beat spans, repeat bars with a non-destructive conversion back to editable notation, inferred rest symbols with a compact alternative, and optional split hands-and-feet engraving with synchronized up-stem and down-stem voices. It also points at an interactive web playground whose examples include ten rudiment exercises covering rolls, paradiddles, flams, drags and buzz strokes.
