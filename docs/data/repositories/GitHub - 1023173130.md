# memodack/memodack

Memodack is a language-memorisation plugin that marks vocabulary inline with its own `{value|translation}` syntax, allows several translations separated by semicolons, and attaches an image by linking it in the document under exactly the same name as the word. A Practice mode is opened from the ribbon icon and can be restricted to a selection of at least four words. The README records a Translate command that converts a selection into that syntax, and provider settings for translation and voiceover, either Google with an API key or a custom API URL.
