# notmuhammad/obsidian-frontmatter-alias-display

This repository holds Frontmatter Alias Display, described upstream as showing frontmatter aliases as display names in the file menu. The README frames the problem in Zettelkasten terms: notes titled by identifier are hard to navigate, so the plugin shows the alias in the File Explorer while the file keeps its identifier as its real name. It records that only the File Explorer is supported with the graph view planned, and that this was the author's first plugin, advising a test vault first.
