# SATOSprod/html-page-preview

HTML Page Preview renders an embedded HTML file inline inside an Obsidian note instead of the default behaviour of opening the file. Each embed of an `.html` or `.htm` file can be expanded in place and collapsed again, and a button remains for opening the file in its own Obsidian tab. Two display modes are offered: a fixed 16:9 frame in which a large page scrolls, and an infinite-height mode where the iframe grows to the document's full height. The README records Obsidian 1.13.0 or later as the requirement and the licence as proprietary.
