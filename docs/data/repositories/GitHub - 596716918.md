# felixchenier/obsidian-optimize-canvas-connections

This plugin reconnects the notes on an Obsidian canvas through their nearest edges, so that a canvas rearranged during brainstorming becomes readable again. Two commands act on the selected notes: one always takes the shortest path between them, while the other also uses nearest edges but keeps each connection on the axis it originally began and ended on.
