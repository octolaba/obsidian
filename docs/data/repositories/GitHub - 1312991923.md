# rx4747/cti-stix-workbench

CTI STIX Workbench turns linked Markdown notes into valid STIX 2.1 Bundles. It provides catalog-driven editing of standard STIX object properties, imports an existing Bundle as typed linked notes, validates the active note and its connected graph against locally pinned schemas with explicit diagnostics rather than silent correction, and exports collision-safe JSON Bundles into a vault-relative folder. A read-only viewer renders a Bundle, an object, or connected notes as an interactive graph using the official OASIS icons, grouping components around relationship hubs and opening the full properties of any node or edge in a side panel. It runs offline on Obsidian desktop with no runtime network calls or telemetry.
