# lucanise-pro/lucanise-vault-assistant

A plugin for chatting with Anthropic's Claude about the notes in a vault on Mac, iPhone and iPad: asking questions, summarizing, rewriting, translating, researching across notes, and creating or editing notes, with a proposed change written to the file in a single tap. The README says the model receives the message plus a file index for the chosen scope — the active note, a folder or the whole vault — and fetches only the files it needs instead of sending everything at once. Its privacy section states that note content goes to Anthropic's API over HTTPS only when Claude reads it, that the API key is stored locally in the plugin's data.json, and that there is no telemetry and no other third-party service; those statements are recorded here as the project's own.
