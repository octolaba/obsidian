# mikuloverfan/GoodNotes-Max

A handwriting and infinite-canvas view for Obsidian with its own rendering engine. Strokes are captured with high-frequency pointer tracking, optional pressure simulation and anti-jitter smoothing; the eraser works at stroke level with pixel-aware hit testing and an adaptive radius; and the canvas pans and zooms with inertia over a page-based notebook with thumbnail navigation. The README describes a layered architecture separating tool, engine and renderer, in which input is frozen into a deterministic snapshot, a single animation-frame scheduler drives rendering and only the renderer touches the canvas, with cached stroke paths and incremental dirty-region redraw. It records Obsidian 1.4 or later and recommends desktop for canvas performance.
