# ltctceplrm/oldsidian-purple

Oldsidian Purple is a dark theme for Obsidian based on the app's pre-1.0 look, restoring the previous callouts, checkboxes and tags, red for unspecified code, purple highlights and YAML at the regular font and size. Beyond that restoration it sets a minimum tab width of 100 pixels through a variable, and adds CSS classes for aligning tables and for hiding field labels in the Bases card view. The README credits snippets by sailKite and Fevol for the recreated checkboxes and callouts.
