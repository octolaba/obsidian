# Razumihin/obsidian-fullscreen-plugin

The repository holds an Obsidian plugin that adds a fullscreen focus mode for the currently active leaf. Its README records the command as reachable from the command palette or a keyboard shortcut, with the escape key returning Obsidian to the previous layout. It is written in TypeScript under the MIT license and carries the obsidian-md and obsidian-plugin topics.
