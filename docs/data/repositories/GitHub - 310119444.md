# ryanjamurphy/review-obsidian

Review adds the current note to a future daily note so that it comes back on that date; the README suggests it for project review, a tickler file and spaced repetition, and notes that a past date works too. Invoking the Review command asks for a date in natural language, such as tomorrow, in three weeks or a month and day, and the plugin then creates or updates that day's daily note with a review section containing the link. It integrates with and therefore requires the Natural Language Dates plugin, which performs the date translation, and its settings define the review heading, the prefix used for a line or for a block — a prefix that can turn each block into an embed — and a default date so the prompt can be accepted with one keystroke.
