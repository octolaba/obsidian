# KulySocc/obsidian-heading-compass

Heading Compass is an Obsidian plugin offering two ways to navigate a note's headings: a command palette for search-and-jump and a floating outline panel that stays visible. The README records an Open heading palette command backed by Obsidian's fuzzy suggest modal with live filtering and keyboard navigation, and a floating outline for the active note that jumps to a heading on click. Recorded details include working in both source and preview mode, tree-style hierarchy prefixes, per-level visibility toggles from H1 to H6, and parsing that ignores frontmatter and fenced code blocks.
