# shakhbanov/whisperer-obsidian

Whisperer Sync sends notes from an Obsidian vault into a Whisperer knowledge base in one direction only, never writing back into the vault. New and edited Markdown, plain text and canvas files go out after a configurable quiet period, deletions remove the note from the knowledge base, renames are handled as moves, excluded folders are skipped, and a periodic full check catches edits made on another device. Only the note's vault-relative path and its text are transmitted, and the vault token lives in the plugin's data file inside the vault, so it travels with the vault under git or another sync. Server-supplied limits apply per sync, 1 MB per note and 50 notes or 8 MB per request, an interrupted run resumes from the last delivered batch, and a paid Whisperer subscription is required.
