# gmcheck/frontmatter-bootstrap

Frontmatter Bootstrap inserts a YAML frontmatter template into newly created Markdown notes, but only when the file is empty and has no frontmatter of its own, and it never overwrites keys that are already set. The default template carries type, domain, status, created, updated, source and tags fields, can be replaced in settings, and an option refreshes the updated date on save when that field already exists. A read-only Metadata Health Check scans the current note, folder or vault for notes using the convention and reports missing required fields, values outside the configured vocabularies, malformed dates and likely field-name typos. Findings go to a report note at the vault root, which is excluded from later scans, and the plugin makes no network requests.
