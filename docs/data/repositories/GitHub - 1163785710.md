# ebibibi/obsidian-cjk-bold-fix

Obsidian plugin that fixes bold and italic rendering for Chinese, Japanese and Korean text in Live Preview. The README attributes the problem to the CommonMark left-flanking and right-flanking delimiter rules that CodeMirror 6 follows, which break when CJK punctuation sits next to an emphasis marker, and notes that Reading mode already renders such text correctly. The fix is described as a CodeMirror view plugin that reads the parser's emphasis spans, recomputes by regex where CJK emphasis should apply, and overrides the ranges the parser got wrong.
