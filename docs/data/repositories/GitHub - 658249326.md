# Jambo2018/notion-assistant-plugin

Typing Assistant adds a command menu to the editor: typing a slash on an empty line, or at the end of a line, opens a menu for choosing the type of the new line, and selecting text raises a second menu for switching the style of that text or of the whole row. The README records generating a card from an entered link address, custom command combinations with drag-and-drop sorting, quick searching of commands, and a menu that follows the cursor position while writing. The author describes the result as a writing experience similar to Notion's.
