# Rons-29/kotonoha

Kotonoha is a quick-capture plugin that appends short notes and tasks to the day's Daily Note and lets them be reviewed in a timeline. Text is written in an input at the bottom of the panel and saved under a configurable heading, and today's Daily Note is created from the Daily Notes settings and template when it does not yet exist. A task is created by turning on the task control or by starting the text with a checkbox marker, completion can be toggled, and file attachments are added as vault links. Optional search, filters, tags, statistics, a heatmap and reflection tools can be revealed alongside the basic capture, and the interface detects Japanese or English automatically.
