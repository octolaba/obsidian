# Lumyo/obsidian-local-graph-tag-links

An Obsidian plugin that makes the local graph show notes connected through shared tags. The README explains that with Show Tags enabled Obsidian renders tag nodes but stops its traversal at them, so notes sharing a tag never appear regardless of the depth setting; the plugin wraps the internal graph engine prototype and runs its own breadth-first pass seeded from the tag nodes already in the subgraph. It injects notes sharing a tag, the forward and back links of those notes, unresolved links and the tags of injected notes, honouring the existing depth slider and filter toggles.
