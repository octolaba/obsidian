# delonborges/obsidian-hunspell-spellchecker

Hunspell Spellchecker adds offline spell checking to Obsidian using standard Hunspell dictionary files, downloaded and managed per language from the plugin's settings; the README states that all checking happens locally with no data sent to external servers and that it is tuned to avoid typing lag in large documents. Words can be added to a personal dictionary from the right-click menu or ignored temporarily within the vault, with the original capitalisation respected in both lists. A status-bar item shows the active language and the number of misspellings currently on screen, opening settings or a dropdown that jumps to each flagged word. This note is grounded in the README alone, as the repository records no description.
