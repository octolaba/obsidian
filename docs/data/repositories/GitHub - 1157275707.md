# latazadehomero/cornell-marginalia

The repository holds Cornell Marginalia, an Obsidian plugin for students working with the Cornell note-taking system. Cues are written inline as comment-style markers anywhere in the note and rendered in the margin, with a second marker form forcing a note to the opposite margin in Reading view. A leading symbol colour-codes a cue as a question, an important point, a correction or a verified statement, and the README describes the margin notes as interactive for active-recall sessions.
