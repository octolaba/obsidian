# SakuraIsayeki/vanilla-amoled-theme

Vanilla AMOLED is an ultra-dark Obsidian theme that the README says was created out of a need for a darker yet vanilla-like theme, and for one that takes full advantage of AMOLED screens by pitching the background fully black. The README also points to three forks and what each changes: colored headings taken from the Obsidian Nord theme, a rework using softer contrasts and colored headings whose background is not fully black, and a minimal spinoff using the JetBrains Mono font.
