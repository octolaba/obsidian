# dy-sh/obsidian-code-block-from-selection

Code block from selection adds a command to Obsidian that turns the selected text into a code block by placing a fence before and after it. The language written into the fence is configured in the plugin settings, several languages can be added, and each can be given its own hotkey on Obsidian's hotkeys panel. In use, text is selected or the cursor is placed on the desired line and the hotkey is pressed.
