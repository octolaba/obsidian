# jonjampen/obsidian-xournalpp

This plugin integrates Xournal++, an open-source cross-platform application for handwritten notes and PDF annotations, with Obsidian. It exports a Xournal++ note to PDF whenever the source file is modified so the result can be linked, embedded and viewed in a vault, creates new .xopp files from the ribbon, the file explorer or the command palette, and offers an Edit in Xournal++ action from the PDF preview and the file explorer. The README carries a warning that any PDF sharing a name and location with a .xopp file will be overwritten by the exported version, and recommends regular vault backups, and it records that Xournal++ itself must be installed on the device.
