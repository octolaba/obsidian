# apokaliptics/concrete-extension

Obsidian plugin combining a reactive variable system, a spatial overlay workspace and a structural outliner, configured from a variables block inside the note. The README describes custom text wrappers that turn markers such as parentheses or quotes into colors and styles, letter-pair wrappers for highlighting, hiding of wrapper delimiters until the line is edited, nested and combined styles, and a clickable swatch for every hex color in the editor. It also names floating sticky notes, copying styled content to external apps and protecting LaTeX from formatting collisions, and labels the plugin as beta.
