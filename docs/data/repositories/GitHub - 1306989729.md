# RuanPienaarCode/budget-vault

Budget Vault manages accounts, budgets, transactions, debt, savings, subscriptions, and tax records as plain Markdown files in a user-selected vault folder, with no account or company database and no network requests. Its Obsidian interface includes a dashboard, transaction search and editing, budget feedback, CSV statement import with review, rule-based categorization, payday-aligned periods, and iOS and Android support.
