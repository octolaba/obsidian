# viggomeesters/obsidian-diff-patch-viewer

A read-only Obsidian viewer for diff and patch files, which it opens through a custom view showing the file list with per-file statistics, hunk headers and highlighted additions and deletions. When no unified diff hunk is detected it falls back to displaying the raw text read-only. The README states that the plugin only renders these files and does not apply patches, call git, modify files or bundle unrelated Git viewer behaviour.
