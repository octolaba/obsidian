# lynchjames/note-refactor-obsidian

Note Refactor copies a text selection into a new note, or splits the current note into further notes from the current line or at every heading of a chosen level. The new file is created at the vault root with the first line of the selected text as its filename and the remainder as its content, with heading characters and characters illegal in filenames removed. Extraction and splitting can also append to an existing note, and the README records that hotkey defaults are deliberately not set for the splitting commands to avoid accidents.
