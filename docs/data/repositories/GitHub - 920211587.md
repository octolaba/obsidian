# gavvvr/obsidian-timecodes-plugin

This plugin turns raw timecodes written as minutes and seconds, or hours, minutes and seconds, into clickable links in Obsidian's reading mode, provided a video URL was mentioned earlier in the note. The README states that YouTube links are detected as raw text links, as Markdown links, and as videos embedded in a note through an iframe element.
