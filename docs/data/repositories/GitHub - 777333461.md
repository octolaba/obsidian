# mProjectsCode/obsidian-shiki-plugin

Shiki Highlighter integrates Shiki through Expressive Code into Obsidian to provide syntax highlighting for over 100 languages in reading, live preview and edit mode. Code block options are written on the same line as the opening backticks, covering line numbers, a title and line highlighting for single lines or ranges, and inline code can be highlighted by naming its language in braces before the code, which can be turned off in settings. The plugin bundles a range of themes and also loads custom JSON theme files compatible with VS Code from a folder given relative to the vault, which become available in the theme dropdown after restarting Obsidian.
