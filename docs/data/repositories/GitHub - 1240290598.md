# AlcatrazYU/better-footnote

Better Footnote provides a right-sidebar workspace for Markdown footnotes in long-form Obsidian writing. It links in-text markers, definition cards, and cursor locations; supports editing with automatic save, focused search, expansion, counts, rendering options, and cleanup of unreferenced definitions. Standard numbered and named definitions are supported, while inline footnotes are outside the sidebar editor.
