# AlcatrazYU/better-footnote

Better Footnote gathers the footnotes of the current Obsidian note into a right sidebar where they can be edited, searched, expanded and deleted, aimed at academic and long-form writing. Clicking an in-text marker selects the matching sidebar card, clicking a card jumps back to the marker and briefly outlines it, and placing the cursor in a footnote definition selects the same footnote in the sidebar. The README frames the problem it addresses as markers and definitions sitting far apart in long notes, scrolling to the bottom to edit, search results mixing footnotes with body text, deletion needing both marker and definition removed, and numbering needing cleanup after insertion.
