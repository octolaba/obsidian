# alex-yelisieiev/cyber-obsidian

Cyber is a dark-only Obsidian theme modelled on the Cyberpunk brand system, applying near-black chrome across the app shell and editor with a yellow primary accent, a cyan focus color and a red danger state. Switching Obsidian's base color scheme does not produce a light palette. Its geometry is angular: notched corners, hard borders, ghost outline buttons, rectangular tags, yellow-fill checkboxes and per-type callouts with filled icon chips, plus hairlines and corner ticks across chrome and reading surfaces. Interface motion and a few layout options are exposed as Style Settings toggles, Rajdhani is embedded locally for headings and interface so no remote fonts are fetched, and the theme requires Obsidian 1.5.0 or newer.
