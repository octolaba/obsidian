# qingxuanlin-s/obsidian-thought-navigator

Thought Navigator builds navigable thought trees from a vault's notes around dedicated MOC files, aimed at Zettelkasten writing and map-of-content workflows. Nodes are created, edited, dragged, connected, grouped and colored directly on the graph, in a free or an automatic layout, with a local graph view showing a node's parent, siblings, children, inlinks and outlinks and with links crossing between different MOC files. A scratchpad moves nodes between MOCs, a workspace view collects notes, MOCs and maps in one place, the tree can be searched, and pasted images become embedded nodes. The README records styling and layout settings plus Obsidian URI and plugin API entry points, and states the plugin is a reconstruction built on the ideas and source of an earlier Zettelkasten navigation plugin.
