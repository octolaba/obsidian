# mdelobelle/obsidian_supercharged_links

This plugin styles the internal links in a vault according to the metadata of the notes they point to, such as tags or YAML frontmatter properties, so that notes standing for a paper, a location, a person or a day of the week are easier to pick out. Its recorded workflow is to create a selector of type Tag, Attribute or Path in the plugin's settings, then define the appearance for that selector — text colour, background colour or an added emoji — in the Style Settings plugin, which the README requires alongside it. The README states that Live Preview, source view, reading mode and the file browser are fully supported in core Obsidian, and lists further plugins that are supported as well; the repository description adds attributes and context menu options on internal links.
