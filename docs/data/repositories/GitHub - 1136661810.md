# starhunt/star-infolearn

Star InfoLearn turns notes into learning cards with AI assistance and runs the review sessions inside Obsidian. The README lists flashcards, multiple-choice questions, cloze blanks and short answers, an FSRS-style spaced repetition schedule, review sessions filtered by the current note, a folder or a date range, and a local progress dashboard. It states that note content goes only to the AI providers the user configures, that API keys are stored locally in the plugin settings, that no telemetry is collected, and that the plugin runs on desktop and mobile where the host app and the configured providers allow it.
