# AndyZhengyan/obsidian-dedao-brain-sync

Dedao Brain Sync synchronizes inspirations, excerpts, links, recordings, and AI summaries between Get Notes and Obsidian as local Markdown. It supports bidirectional transfer, incremental, date-based, note-based, knowledge-base, scheduled, startup, and resumable synchronization, with filters for time, types, tags, notes, and knowledge bases. OpenAPI and temporary web authentication, search, attachment and transcription handling, categorized files, and detailed per-item logs are included.
