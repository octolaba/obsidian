# samuele-cozzi/obsidian-marp-slides

Marp Slides is a slide-deck extension for Obsidian based on Marp, so decks are written as Markdown. The README points to external documentation for getting started and to the Marpit Markdown and Marp Core references for how slides are written, and it links a demo presentation. Its listed features include previewing slides and exporting a deck as HTML, PDF, PPTX or images.
