# jaanaltosaar/obsidian-microlite

Microlite reads the snapshots that Obsidian's File Recovery core plugin takes as notes are edited, groups them by note, and writes one Markdown review note per day containing a per-day activity table of edit volume, active hours and context switching, bulk-sync detection, and heading-aware diffs of what changed, newest first. Renamed notes appear under their current name, each note's live content is folded in so fresh edits are not hidden, and notes that were only opened are dropped. The README frames the output as context engineering for a large language model: the changes rather than whole files. It states that the plugin runs entirely on the device and makes no network requests, and that by default it adds its output folder to Obsidian's excluded files list.
