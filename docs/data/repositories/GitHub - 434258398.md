# chrisgrieser/obsidian-theme-design-utilities

Theme Design Utilities collects commands aimed at people designing Obsidian themes. They include emulating the mobile appearance, cycling through the light, dark and system modes or through the installed themes, freezing Obsidian, toggling the developer tools, garbling text, adding a test class and red outlines for debugging, showing a permanent test notice, and checking CSS feature compatibility against the Chrome version. The repository also ships cheatsheets and sample notes for working with theme colors.
