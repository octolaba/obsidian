# matthewturk/obsidian-additional-icons

Additional Icons bundles extra icon sets for use anywhere Obsidian would normally take an icon from the Lucide set. At the time of the README those are an RPG icon library, GovIcons and Weather Icons, each shipped with the built plugin under the SIL Open Font License and each toggleable on its own. The README's example uses names such as ra-axe, gi-dna and wi-tornado in a metadata icon field to give files icons by type; the repository source itself is BSD 3-Clause.
