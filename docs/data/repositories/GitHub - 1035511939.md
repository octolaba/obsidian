# alexmensch/obsidian-cloudflare-kv-sync

Obsidian plugin that syncs markdown files to a Cloudflare KV namespace based on frontmatter configuration, with the stated use case of feeding a static site generator such as Eleventy. The README describes automatic upload of files carrying a sync flag, auto-generated document ids, duplicate key detection during a full sync, optional collection prefixes, debounced uploads and an error log written to a file in the vault root.
