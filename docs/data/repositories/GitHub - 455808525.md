# vanakat/zotero-bridge

This repository holds Zotero Bridge, an Obsidian plugin that publishes APIs other plugins use to reach Zotero rather than a user-facing feature of its own. It connects either to the Zotero 7 local API or, for Zotero 6 and older, to the ZotServer add-on, with the connection type, library and server port configurable. Its API opens a search modal and resolves to the selected Zotero item, whose values, among them the item key, library URI, title, short title, a structured date, the authors, the first author and the creator summary, are shaped for use in templates such as Templater user scripts; Zotero Link is named as an example consumer.
