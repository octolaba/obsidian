# nicolasassi/yaaiop

Yaaiop adds a vault-aware AI chat panel, in the sidebar on desktop and full screen on mobile, where the model searches and reads notes on its own and answers with wikilinks. It is read-only and never creates, edits or deletes files. It calls Anthropic, OpenAI, Google or OpenRouter over HTTPS with a model picker and a reasoning effort dial, needs no local runtime or companion app, and asks the Smart Connections plugin for search rankings when it is installed, falling back to keyword search when it is not. Images and PDFs are readable and are matched through the text of the notes that embed them, saved prompts and chat history can be reopened, an opt-in memory suggests facts to carry between chats, and a vault instructions file is picked up if one exists.
