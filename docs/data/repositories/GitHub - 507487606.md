# Narsail/habit-tracker-obsidian

This plugin displays a habit tracker in Obsidian, rendered from a DataviewJS block: habits annotated in daily notes are collected with Dataview and passed to `renderHabitTracker()`. Values can be mapped onto several colours as intensities spread between the minimum and maximum of the data. The README records a known limitation of at most seven habits, and states that the plugin was created on the foundation of the Heatmap Calendar plugin.
