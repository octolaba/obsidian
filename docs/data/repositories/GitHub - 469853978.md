# liamcain/obsidian-lapel

Lapel is described as showing the heading level in the editor gutter. The README says a marker beside each heading distinguishes the levels at a glance and that a menu switches a heading to another level. Each level can be targeted separately in CSS through a data attribute on the heading marker, so the displayed character can be replaced. Settings control whether the markers appear before or after line numbers and whether they are shown in source mode.
