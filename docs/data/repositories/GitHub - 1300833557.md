# jqml/style-controller

Style Controller manages reusable style profiles, path overrides and visual settings through a native settings interface, applying a profile's values as scoped CSS custom properties consumed by its own static stylesheet rather than editing theme files, snippets or notes. A profile covers typography, headings, links, tables, code, blockquotes, callouts, images, file explorer styling and custom CSS, and overrides can be bound to folders, files or a path-contains match. The README records that Obsidian's own Appearance settings own the base text font family and size, which the plugin keeps stored but no longer applies, that most blank controls remove their property so theme behaviour continues, and that profiles should be tested on a small set of notes before broad path overrides are assigned.
