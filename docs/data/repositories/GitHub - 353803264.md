# dennisseidel/highlightpublicnotes-obsidian-plugin

The repository holds an Obsidian plugin that highlights the title bar of notes classified as public, so confidential text is not written into a note that will later be published. Its README records two ways to classify a note: by placing it in a configured folder or by giving it a frontmatter attribute and value, both of which are configurable. It states that the check runs only when a file is loaded, so a note has to be reopened before the highlight appears.
