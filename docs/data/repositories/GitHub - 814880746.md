# patrickchiang/obsidian-dialogue-mode

Repository for Obsidian Dialogue Mode, a plugin that fades out non-dialogue text so the dialogue in a piece of writing stands out. The mode is enabled by default and toggled from the command palette, while settings adjust the fade intensity and the colour of the dialogue text. The README also names the CSS variable that a theme can set to change the faded colour at maximum intensity.
