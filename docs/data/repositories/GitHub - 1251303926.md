# jang-hs/obsidian-narrate

This repository holds Narrate, an Obsidian plugin that reads a markdown note aloud through a local OpenAI-compatible text-to-speech server; the repository records no description, so this summary follows the README alone. It offers gapless chunked playback, per-note resume and a draggable mini-player, with the model, language and voice fetched from the configured server address, which defaults to a local port. The README names OpenVox on macOS and the author's own ttsd server as compatible backends, and states that any other server speaking the same endpoint contract works too.
