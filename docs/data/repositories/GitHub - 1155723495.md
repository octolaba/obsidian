# tuxitop/chessview

This repository holds ChessView, an interactive chess board plugin for Obsidian. It renders games from PGN with a navigable move list, static or interactive positions from FEN, and puzzles with hints and a solution reveal. Move annotation glyphs from NAG symbols, arrows and circles drawn from markers or PGN comments, and inline PGN comments are shown alongside the board. The README lists seven board themes with custom colours, twenty piece sets, keyboard navigation with arrow keys and autoplay, one-click export to Lichess and Chess.com, a responsive mobile layout and dark-mode support.
