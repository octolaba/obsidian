# JackBarker7/obsidian-latexocr

The repository records no description; its README presents a plugin that runs LaTeX-OCR when that program is installed locally, converting an image of a typeset equation into raw LaTeX code for use in a Markdown file. It adds a ribbon button and a command-palette entry that execute the local latexocr binary. Optional status-bar text showing whether LaTeX-OCR is running can be turned on or off in the settings.
