# 5krus/obsidian-seamless-embeds

This plugin restyles embedded notes in Obsidian so that transcluded content reads as part of the surrounding document rather than as a separate block. The README states that it removes the border, padding and margins Obsidian normally draws around an embed, hides the embed title and link icon, and makes horizontal rules inside an embed span the full document width. It works with nested embeds and in both reading mode and live preview, and the README records that the plugin has no settings at all: enabling it applies to every embed.
