# Ivanohe73/obsidian-preserve-blank-lines

Preserve Blank Lines keeps consecutive blank lines visible in Obsidian's reading mode so that the rendered spacing matches the source line for line. Obsidian's renderer normally collapses any run of blank lines into a single paragraph break, and the README explains that the plugin was written while migrating notes from Zim desktop wiki, which preserves them, and rejects the usual workarounds of a slash character, an invisible em space or an HTML entity on the blank line.
