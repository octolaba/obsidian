# jiaoyingxing/a-loader

Obsidian plugin that controls when community plugins load, so a vault carrying many of them starts faster, particularly on mobile. Each plugin is set to load at startup or to load later, or is disabled outright, and the settings page follows the native community-plugins page with search, automatic grouping by state and enable and disable switches in the same place. The README contrasts this with Lazy Loader's several delay stages, states that the timings shown come from A Loader's own measurements of plugins it actually loaded, and records that core plugins, library loading and workspace layout are out of scope. It also states that no note content, plugin list or personal data is collected and that the repository publishes reviewable code and release artefacts rather than a complete buildable source tree, under a licence that is not open source.
