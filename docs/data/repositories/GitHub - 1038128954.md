# coignard/obsidian-scroller

Scroller adds typewriter mode, dimming of unfocused text and scrolling commands to the Obsidian editor. The README describes keeping the current line at a fixed vertical position, dimming text outside the current line, sentence, paragraph or section, commands that jump to the top or bottom of a note, automatic scrolling to the bottom of a daily note when it opens, moving the cursor line by line with the mouse wheel, and an option that hides all scrollbars. It notes that most features start disabled and are turned on in the plugin's own settings panel.
