# brianpetro/obsidian-smart-templates

Smart Templates turns the Markdown templates already in a vault into reusable AI workflows: starting from the current note or selection, the context is refined, one or more templates are chosen, and a ready-to-run prompt is copied out for any AI chat. The README frames the core as prompt building and clipboard workflows, with generation inside Obsidian reserved for a paid tier, and describes the plugin as local-first and privacy-preserving by default. Its recorded description names local models, Anthropic Claude, Gemini and OpenAI among the models it works with.
