# davidlbowman/kavita-to-obsidian

Kavita Sync pulls annotations, highlights and notes from a Kavita reading server into an Obsidian vault. Two export modes are described: a hierarchical layout writing one Markdown file per book under a root folder and a series folder, and a single file grouping all annotations by series and chapter. Generated notes carry frontmatter with tags, Kavita series and chapter identifiers and an updated timestamp, and quote each highlight with its note and page number. Setup requires the Kavita server address and an API key taken from the reader's third-party client settings.
