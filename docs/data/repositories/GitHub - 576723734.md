# modality/obsidian-the-one-ring-2e-statblocks

This plugin renders adversary stat blocks for The One Ring, Second Edition, from a block whose parameters are parsed as YAML. The README lists mostly optional fields including name, a blurb or description rendered as Markdown, distinctive features, level, endurance, might, hate or resolve, parry, armour and combat proficiencies, and warns that a stat block disappearing usually means one field is in the wrong format. It is adapted from a 13th Age stat blocks plugin, and it notes that Obsidian conventions such as double brackets may need quoting because YAML interprets them differently.
