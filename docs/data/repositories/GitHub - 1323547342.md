# Hanser0521/quick-editing

Quick Editing is a desktop plugin that groups Markdown editing commands into four independently switchable sets: smart symbols, format brushes, smart paste, and full-document cleanup. Transformations walk the syntax tree so frontmatter, code, math, HTML, links, images and Obsidian comments are protected, and full-document operations show an estimated change count with an undo notice before applying. Smart paste handles URLs, paths, HTML and tables through clipboard events and DOM conversion, internal links are generated through Obsidian's link API, and image links can be removed without deleting the attachment files. It registers no default hotkeys, commands can be switched on individually from searchable settings, and it makes no network requests.
