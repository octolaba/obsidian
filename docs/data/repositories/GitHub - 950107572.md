# peritus/obsidian-interactive-ratings

The recorded description says the plugin edits symbol ratings in Obsidian notes interactively. Per the README a run of at least three identical symbols becomes an interactive rating in edit mode: hovering over it and clicking one of the symbols updates the rating. A numeric rating written after the symbols as a fraction or a percentage, with or without parentheses, is updated automatically along with the symbols. The set of usable emoji is configurable in the settings and includes compound zero-width-joiner sequences, and the README shows uses such as media reviews, habit tracking and project status.
