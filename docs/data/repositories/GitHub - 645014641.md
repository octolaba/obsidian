# WiseGuru/obsidian-automatic-list-styles

Obsidian plugin that shifts the style of ordered lists with each level of indent in read mode, using decimal, lower-alpha, lower-roman, upper-alpha, upper-roman, decimal-leading-zero, disc, circle and square by default. It does not affect edit mode. The README states the plugin is being deprecated in favour of Lawlist, which supports both edit and read modes as well as custom lists, that only security updates will continue to be published, and that a settings page for choosing CSS list style types was intended but never worked properly.
