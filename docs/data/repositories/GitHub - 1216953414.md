# rowmayne/nixsync

This repository holds nixsync, an Obsidian plugin that exports and imports vault settings and plugins as Nix. Export writes a single .nix file holding the vault's configuration together with plugin manifests and settings, and import reads that file back and applies it to the vault's configuration directory. The README records per-section toggles for app config, appearance, core plugins, graph settings, workspace, hotkeys, community plugin manifests and plugin settings, plus an option that strips machine-specific workspace fields such as the last-open files and the active file.
