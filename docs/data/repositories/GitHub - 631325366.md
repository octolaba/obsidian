# A-F-V/obsidian-arcana

Obsidian plugin bundling several AI tools, each named after a historical figure: conversation with custom agents plus speech transcription and spoken replies, metadata markup, text generation, file moving, flashcard generation, automatic tagging and note naming. It runs on the user's own keys for OpenAI, Anthropic, Google or OpenRouter, and most tools are invoked from the command palette by searching for the plugin or for the figure's name, while some add a view in the sidebar. The README states the author is looking for collaborators.
