# IsaiaScope/smart-html-select-plugin

Smart Select inserts an HTML select element into a note with a configurable set of options, added either from a command palette entry or from a ribbon icon that opens the same configuration modal. The options are generated as a numbered sequence. Alongside the select the plugin writes Markdown that lets it update the file when the selected value changes in view mode, which is what makes a choice made in the rendered note permanent.
