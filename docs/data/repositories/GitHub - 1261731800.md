# sinaaxe/ultra-search-plugin

UltraSearch indexes and searches both file names and individual lines across the Markdown files of a vault, showing matching names and matching lines together in one suggestion list with colored badges distinguishing the two kinds. Its matching accepts space-separated terms in any order, prioritizes exact substrings, tolerates one typo for short query terms and two for longer ones, and ranks results with bonuses for word-boundary starts and for terms appearing in query order, a slight preference for file matches, and a small penalty for long names or lines. Selecting a line result opens the note and scrolls to that line, a file result opens at the top, and a modifier key opens either in a new tab. The plugin also provides a Gemini chat panel in the sidebar that answers questions from the vault, the current folder or the active file.
