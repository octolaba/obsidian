# QuincySx/obsidian-tracetime

TraceTime records and displays the last edited time of every block in a note, covering paragraphs, headings, code blocks, lists and tables, with labels aligned to the right of the document area. The README describes incremental re-parsing through CodeMirror change sets so only blocks near an edit are touched, timestamp restoration on undo through a content-hash session history, and migration by block hash when files are changed by sync tools or other editors. Display follows a configurable ladder of formats from just now through to a full date, and every write keeps a one-generation backup that can be restored from the settings tab. Data lives per file under the plugin folder and records only block hashes, short normalized excerpts and timestamps, never note content.
