# Benature/obsidian-share-my-plugin-list

Share My Plugin List exports the plugins installed in a vault so they can be shared or recommended to others, covering active and inactive plugins separately. The list can be produced as a Markdown bulleted list naming each plugin and its author, or as a Markdown table that also carries the version. From version 0.3.3 the exported entries include an install control that installs a plugin directly, and a command in the palette installs every plugin from a shared list that is not yet present.
