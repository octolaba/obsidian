# obsidian-power-plugins/obsidian-power-desk

Power Desk brings calendars into Obsidian from Microsoft 365, Google Calendar, CalDAV services such as iCloud, Fastmail and Nextcloud, and ICS feeds, shown in month, week, work week, day and agenda views with a note for each event. Microsoft 365 and Google events can be created by dragging across the grid, moved and resized with fifteen-minute snapping, invited to, set to repeat and answered with RSVP, while CalDAV and ICS calendars stay read-only. Alongside the calendar it carries a mail client for mail-enabled Microsoft accounts, with a folder tree and unread counts, an unread search folder, a split inbox, conversation grouping, a reading pane and compose. Two actions join the halves: an email can be turned into a prefilled event with its sender invited, or saved into the vault as Markdown with its inline images written beside the note.
