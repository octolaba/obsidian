# witheredAd/Rin-s-Image-Toolbar

Rin Image Toolbar shows a floating toolbar when the pointer hovers over an image in Obsidian's Live Preview. Its buttons copy the image to the clipboard, open it in a fullscreen overlay, and start an interactive crop dialog with drag handles and precise pixel input; a cropped image is saved beside the original under a `_crop` suffix, numbered upward if that name exists, and the note's reference is updated to the cropped file. In Reading view only the copy and fullscreen actions are shown.
