# lukemt/obsidian-daily-note-pinner

Repository for Obsidian Daily Note Pinner, a plugin that keeps the current day's daily note pinned and automatically unpins the daily notes of past and future days. The README documents installation through the BRAT beta plugin rather than the community catalogue. Its stated limitation is that it works only with the default daily note format `YYYY-MM-DD`.
