# AmadeusWM/Obsidian-Apatheia

Apatheia is an Obsidian theme configured through the Style Settings plugin, which its README names as the way to change the colour scheme, fonts, border radius and similar options. Its credits record contributions from another author together with that author's SCSS-based Style Settings compiler, inspiration taken from the Things theme, and fonts also used by the Ultra Lobster theme. Nothing further about the palette or the supported modes is recorded.
