# Poltavtcev/dream-analyzer

Dream Analyzer processes dream journal entries with an OpenAI model, producing a summary and structured entities: characters, places, objects, emotions, symbols and concepts. Each entity gets its own note that accumulates appearance history, related dreams and recurring contexts, with duplicate detection across categories, and references are updated when dream or entity notes are renamed or moved. Related dreams are found by combining vector cosine similarity with shared-entity overlap in equal parts, and a generated dashboard and index notes cover journal and lucidity statistics, dream signs, emotional trends and recurring concepts. It needs an OpenAI API key, offers dream note templates with Templater and calendar integration, and recommends Dataview for the interactive tables.
