# NchuYJ/obsidian-smart-media-notes

Repository for Smart Media Notes, a plugin for taking notes against video and audio. Its README describes opening media beside the note, binding a note to a source through a frontmatter property, inserting clickable timestamp blocks while studying, importing subtitles and jumping by subtitle line, and a library view for saved media, subtitles, feeds and media folders. It states that the project builds on an earlier timestamp-notes plugin, that this release focuses on making the workflow usable on mobile, and that on desktop an external downloader can optionally resolve a direct stream address for page-based video sources.
