# shuxueshuxue/PackUp4AI

packUp4AI collects the notes related to the currently open note and exports them as a context bundle for external AI chatbots. It follows links out of the starting note, optionally including backlinks, to a configurable depth of one to ten hops, displays the collected notes as an interactive graph whose nodes are sized by word count, and reports how many notes were collected together with total, average and range word counts. The bundle is copied to the clipboard or saved as a new Markdown file in the vault, and settings cover the depth, backlink inclusion, excluded files and folders, and the output filename.
