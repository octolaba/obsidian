# flutterspike/obsidian-copy-linked-file

The repository holds Copy Linked File, an Obsidian plugin that adds a right-click action putting the actual file behind an internal link, embed, local file URL or file-explorer entry onto the Windows clipboard, so it can be pasted into Explorer, mail, chat or a browser upload control. It resolves vault targets through Obsidian's link resolver and local file URLs directly. The README states that the plugin is desktop-only and Windows-only, requiring PowerShell, because it uses Node and Windows clipboard interfaces.
