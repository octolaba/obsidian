# ViaCai/bitiful-helper

Bitiful Helper manages Bitiful cloud storage from inside Obsidian so that images, audio and video held there can be inserted into notes. The README describes a sidebar file browser with folder navigation, drag-and-drop and clipboard upload, image compression and text watermarking on upload, EXIF viewing, capacity statistics against the free 50 GB tier, global search, batch operations and copying between buckets. Links are generated according to file type, and the README notes that PDF embedding is not currently achievable. The repository description and much of the README are in Chinese; this summary restates what they describe.
