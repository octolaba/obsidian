# danigarvire/Folio

A project-centric workspace for long-form writing such as books, screenplays, series and essays. Each project has its own root, metadata and predefined folder structure by project type, a project dashboard shows cover, title, author, description and a live word count, and a tree view represents chapters, scenes or sections as a reorderable hierarchy rather than plain folders. A separate writer tools view holds character, narrative-technique, structural-model and writing-advice reference material alongside a focus mode and an export assistant that consolidates a project into a single document.
