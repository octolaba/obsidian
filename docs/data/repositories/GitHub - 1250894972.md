# x1han/html-canvas

HTML Canvas opens local `.html` and `.htm` files from the Obsidian file explorer as visual notes, aimed at study pages, exported notes, formula-heavy documents and diagram-rich HTML. Its default mode loads trusted vault HTML through Obsidian's native browser iframe path rather than rewriting the document into `srcdoc`, which the README argues preserves CSS layout, MathML formulas, inline SVG, anchors and responsive pages more reliably than sanitiser-heavy rendering. The page stays inside an iframe so its styles do not leak into Obsidian, and that default mode omits `allow-scripts` from the sandbox so scripts do not run; more restricted fallback modes remain available for less trusted HTML. Search and zoom controls are provided for reading long documents.
