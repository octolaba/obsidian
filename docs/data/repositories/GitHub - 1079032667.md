# majid-khonji/obsidian-dropdown-vars

Obsidian Dropdown Vars renders an inline token of the form {Status: A | B | ^C} as a clickable dropdown, where the caret marks the currently selected option. The README states that a selection can optionally be persisted to YAML frontmatter or written after the token as a Dataview inline field such as (Status::C), with only one inline field kept per dropdown. When Dataview sync is enabled the token displays as a compact label in Live Preview, and the value can be read back by Dataview queries.
