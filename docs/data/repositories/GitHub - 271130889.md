# GuangluWu/obsidian-pisum

Obsidian-pisum is an Obsidian theme with a clean line-drawing appearance whose color scheme the README credits to obsidian_gruvbox and the Qiita editor theme. Only dark mode is available; light mode is instead set to an Andy Matuschak mode, credited to death_au's solution. The scrollbar is kept for PC and Linux users and can be removed by reactivating code at the end of the CSS file, and the README notes the file is large but carries detailed comments in the manner of the Hulk theme. Installation is through the Custom CSS plugin and copying obsidian.css into the vault directory.
