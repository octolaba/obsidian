# 0918nobita/obsidian-zhongwen-block

This repository holds Obsidian Zhongwen Block, a plugin providing code blocks with features for learners of Chinese. A sentence inside a zh-cn block is annotated with the corresponding pinyin as ruby text and one inside a zh-hk block with jyutping; the annotation is displayed only while the sentence is hovered, which the README presents as an aid to remembering the pronunciation, and a setting displays it from the beginning instead. The interface is available in English and Japanese, and the conversions come from the pinyin-pro and to-jyutping libraries.
