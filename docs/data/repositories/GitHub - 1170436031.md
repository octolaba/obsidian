# alpinemily/obsidian-mood-atlas

Mood Atlas suggests emotion words while journalling: typing an emotion word and then a trigger key, `^` by default, opens a dropdown of the other feeling words in the same emotional region so a more precise one can be chosen. Three word lists are available and each can be customised in the plugin settings — a combined Hoffman and NVC list used by default, the Hoffman Institute feelings list, and the feelings list from Nonviolent Communication.
