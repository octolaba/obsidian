# jpcranford/obsidian-plugin-dice-table

Dice Table Calculator automatically calculates and fills the first column of a Markdown table with evenly distributed dice ranges. The column's header must be standard dice notation, and two commands fill the dice column of the table at the cursor or of every table in the file, overwriting whatever the column already held. When the number of rows does not divide the rollable range evenly the plugin produces ranges instead of single values and spreads the remainder across the rows so the distribution stays as even as possible. The README notes that only the first column is examined, that tables must be standard pipe tables, and that the optional fill-on-save setting can be disruptive mid-edit.
