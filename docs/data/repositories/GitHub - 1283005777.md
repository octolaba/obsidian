# SATOSprod/Voice-to-Text

Voice to Text is a push-to-talk transcription plugin for Obsidian: holding a hotkey records, releasing it transcribes, and the text is inserted at the cursor. Transcription runs through one of two providers chosen in settings, Deepgram Nova 2 or Groq Whisper, with fixed model and language dropdowns rather than free-text fields, and the hotkey is captured interactively and displayed as icons. Activity can be written to daily log files inside the vault and each recording optionally saved there as a WAV file. The README records the requirements as Obsidian 0.15.0 or later on desktop only plus a Deepgram or Groq API key, and states that the licence is proprietary.
