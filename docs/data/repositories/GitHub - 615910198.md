# longy2k/obsidian-bmo-chatbot

BMO Chatbot brings large language models into Obsidian for generating and brainstorming ideas while writing, connecting to Ollama, LM Studio, Anthropic, Google Gemini, Mistral AI, OpenAI and others. Profiles create chatbots with their own knowledge, personalities and presets, a generate command answers from the editor, and a prompt-select-generate command works within the editor on a selection. Responses render in Obsidian Markdown, including code blocks such as Dataview, and the chatbot can reference the current note or be opened from anywhere in Obsidian. Chat history is saved and loaded with slash commands, and self-hosted models require the REST API of Ollama or LM Studio to be running.
