# guchang/Odaily-Plugin

Obsidian plugin organised around the day, made of a home view that fills a new tab and an overview panel in the sidebar. The home view offers one-click access to today's daily note, creation of a new document, a todo list, a quick switcher, recent files, a light and dark toggle and per-theme backgrounds taken from vault images, external URLs or CSS gradients. The sidebar carries a week and month calendar, timestamped memos captured by tag, the documents modified on the selected day, open and completed tasks with tag filtering and a short undo window, a search across those sections and a command copying the day's summary to the clipboard. Settings choose the backgrounds, the task tags, the file new tasks are written to and whether they land at the top or the bottom of it.
