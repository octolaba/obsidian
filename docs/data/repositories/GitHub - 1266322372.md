# liicos/obsidian-wolai-theme

Wolai is an Obsidian theme porting the look of the Wolai note-taking application, aiming at a clean and modern reading experience. Its bilingual Chinese and English README lists light and dark modes, typography optimized for Chinese fonts such as PingFang SC and Microsoft YaHei, comfortable line spacing for long reading, restyled code blocks, tables and blockquotes, and rounded card-style interface elements. It documents installation from the community theme store or manually from the release files, and describes a release workflow driven by GitHub Actions.
