# jellyns/obsidian-noria

Noria is a configurable workbench for Obsidian that gathers tasks, projects, an inbox, maps of content, habits, countdowns and statistics onto a Home dashboard. Home is a widget grid whose widgets can be enabled, reordered and resized, including Markdown widgets that display existing notes and, after trust is granted, custom JavaScript view widgets from the vault; it reads those files rather than generating them. A Task Board collects tasks scattered across diaries, projects and other notes into month, week, day and matrix views, leaving each task in its original note while new tasks are written back to the matching periodic note. A Task Timeline places tasks by date and time block, and a shared data API backs Home, tasks, timelines, periodic statistics, review evidence, exports and custom views.
