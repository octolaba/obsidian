# piriwata/pubScale

PubScale inserts, updates and deletes Markdown text from an Obsidian vault in PlanetScale tables, so that PlanetScale holds the content while Obsidian edits it. The README states plainly that the plugin is not intended for using PlanetScale to back up a vault. Setup needs a table created in advance — its name free, its columns fixed as title and content — plus PlanetScale credentials, the database and the table in the plugin settings, after which two command palette entries publish the active note and delete it. Because notes are identified by their title, the README records that renaming a note inserts a new row rather than updating the existing one.
