# HongjianTang/obsidian-insighta

The recorded description says InsightA transforms long articles into concise, atomic notes and creates organized Maps of Content with a language model, drawing on the Zettelkasten method. Per the README a model and an API key are configured first, after which opening an article and running the plugin from its toolbar icon or the command palette produces atomic notes that link back to the source note and carry relevant tags, with the number of notes and tags, the language and extra properties such as year or location configurable. A Create MOC command run in a new note embeds the notes of a chosen folder, finds those related to the note title, groups them with the model and shows them, against a similarity threshold set in the settings. The README warns that an extensive article typically takes about thirty seconds or longer to process.
