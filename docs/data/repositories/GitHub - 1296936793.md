# DudeThatsErin/callout-metadata

Adds pipe-separated metadata tokens to Obsidian callouts without changing existing callout syntax. The README states that tokens written after the callout type are order independent: numbers become width percentages, alignment keywords are detected, style tokens toggle effects such as shadow or rounded, a css=name pair injects a custom CSS class, and anything else is treated as a color resolved by the browser, so any CSS color value works. The README also carries the author's own note that the plugin is written with AI assistance.
