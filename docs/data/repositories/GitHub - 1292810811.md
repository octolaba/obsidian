# Ooheroism/obsidian-open-edge-tts

Read in Edge opens the active Markdown file in Microsoft Edge so that Edge's built-in Read Aloud text-to-speech can read it. The plugin adds a ribbon icon and a Read with Edge command, and the README leaves starting the speech to Edge's own keyboard shortcut once the window opens. It records that the plugin is desktop only.
