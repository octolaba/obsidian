# KaicuiChen-git/Obsidian-date-on-open

Obsidian plugin that adds today's date to a note when the note is opened, once per day, for running logs, journals and lab notebooks. By default only notes carrying an auto-date property are touched, and the scope can be widened to chosen folders or to every note. The line template, the date format in Moment.js tokens, a shorter format used to detect a date already recorded, and top or bottom placement are settings, and the line is written below the note's properties rather than above them. A command adds today's date to the current note regardless of scope.
