# ebullient/obsidian-task-collector

Task Collector manages tasks and logs inside an Obsidian note, and includes a modal for choosing how a task is marked. Its settings define groups of task marks, listing the characters used for incomplete tasks and those used for completed ones, and a hot-key bindable command opens the mark selection dialog in edit mode.
