# cyriusweng/opal-theme

Opal is an Obsidian theme with hand-tuned light and dark palettes, WCAG contrast checks, and about 82 Style Settings controls covering colour, typography, layout, elements, motion, and print. It styles Reading view and Live Preview together, adapts to features such as Bases, Canvas, Properties, and graph view, and provides fallbacks for newer CSS features while respecting reduced-motion and reduced-transparency preferences.
