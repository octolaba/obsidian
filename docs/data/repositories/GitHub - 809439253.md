# arumie/obsidian-medium-importer-plugin

Medium Importer imports Medium articles into an Obsidian vault, fetching them through the unofficial Medium API on RapidAPI and saving them as Markdown files in a configurable folder, Medium by default. Commands set the RapidAPI key, import a single article from its URL, add a Medium author together with their articles, and sync previously added authors to pick up new articles. The README warns twice that the API key is stored in the vault's plugin settings and suggests adding the plugin's data file to a gitignore when the vault is under version control, and notes that a free RapidAPI plan with a monthly request allowance existed at the time of writing.
