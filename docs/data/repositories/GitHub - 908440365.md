# benjaminezequiel/keep-the-rhythm

The recorded description says the plugin tracks a daily word count through a heatmap. Per the README it records how many words and characters are written each day, supports daily writing goals with a streak of consecutive days meeting the target, and shows a heatmap of activity over time beside statistic slots such as words written today, this week or averaged over the year, plus a list of the files worked on today. Heatmaps, slots and entry widgets can be embedded in any note through custom code blocks, statistics can be narrowed with a query syntax for particular folders or file patterns, and the README states that statistics sync and merge across devices.
