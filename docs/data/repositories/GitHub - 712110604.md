# mgussekloo/obsidian-editor-autofocus

Obsidian plugin that moves focus into the editor window automatically when a note is opened. After focusing it selects the heading when one sits on the first line, so the title can be typed over directly. The README states that autofocus happens only for notes shorter than three lines, and recommends pairing the plugin with Filename heading sync, which creates such a first-line heading.
