# Yeban8090/note-to-red

Obsidian plugin that converts a note into images for the Xiaohongshu platform in one step. Content is split at first- or second-level headings as chosen in the settings, and each heading produces one image; templates, fonts and font sizes are selectable, and custom themes control colours, spacing, background, header and footer, alongside a custom avatar, nickname and footer text. A preview updates as the document is edited and can be locked so that a refresh does not interrupt writing, and pages are exported one at a time or all at once. The README documents installation from the community plugins list or by copying an unpacked release into the Obsidian plugins directory, and states that the plugin interface is currently available in Simplified Chinese only.
