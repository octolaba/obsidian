# caro401/royal-velvet

Royal Velvet is a theme for Obsidian inspired by the colours of royal velvet obsidian and by the distinct colours used in programming syntax highlighting themes, and it supports both light and dark mode. Emoji used in headings require the Dynamic Highlights plugin, configured with a snippet the README supplies, to display in the right colour in reading mode. Customisation is offered through the Style Settings plugin and is marked experimental; the inline document title colour can follow a specific heading level, be disabled, take a custom colour derived from the accent hue, or be rainbow. The author notes using few plugins or advanced features, so some use cases may not look good.
