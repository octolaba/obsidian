# HWY1dot0/obsidian-copy-for-email

The repository holds Copy for Email and Chat, an Obsidian plugin that copies a selection or a whole note as rich text that survives pasting into a mail client or an editor such as Gmail, Outlook, Apple Mail or Word, keeping headings, tables, callouts, highlighted code and task lists. The README explains its approach: every style is inlined on the element itself because mail clients strip classes and style blocks, Mermaid diagrams, charts, formulas and SVGs are rasterized to embedded images, vault images are embedded as data URIs, and a fixed light palette keeps the text readable in a white mail body. The same copy also carries a plain-text flavour so pasting into a chat application gives structured text rather than raw Markdown.
