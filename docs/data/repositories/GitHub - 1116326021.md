# owo/obsidian-chatterbox-plugin

This repository holds Chatterbox, an Obsidian plugin that renders dialogues and conversations in the style of a messaging app. Conversations are written inside a code block whose language is chatterbox, and each entry declares an author, a timestamp, a direction and the message content. Direction markers place a message on the right, the left or the centre, and the README describes further entry types beside plain messages; a line matching no entry type is ignored.
