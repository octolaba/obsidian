# JayJiangCT/knowlery

Knowlery is a local-first knowledge system that takes plain Markdown as its input and is served by three shells: an MCP server, a CLI, and an Obsidian plugin as its human interface. Free-form notes stay as they are while a reviewed pipeline compiles a structured, retrievable layer of entities, concepts, comparisons and queries for agents to read. The README states that retrieval is deterministic and measured, that answers carry citations, that no confident match is returned as an honest verdict, and that the workspace format, CLI surface and MCP contracts are frozen under semantic versioning and pinned by contract tests. In Obsidian the plugin is installed from the community directory and started through a setup wizard, but the README states that nothing about Knowlery requires Obsidian.
