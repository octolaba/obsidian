# MDerman/context_nine_obsidian_plugin

Context Nine adds TaskNotes capture and context-routing workflows to Obsidian, including creating or appending tasks from selected Markdown and moving attachments into context folders. It also provides file actions, a Vault Command Center, a vault TUI for backup and sync operations, and commands that refresh stale periodic-note tabs without editing workspace state.
