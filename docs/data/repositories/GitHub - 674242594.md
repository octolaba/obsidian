# kelszo/obsidian-file-explorer-plus

Hides and pins files and folders in the file explorer according to filters. Filters match names, paths and tags using wildcards or regular expressions and are defined in the settings tab or by choosing hide or pin in a file's context menu. Commands toggle all pin and hide filters at once or an individual filter, and the settings list which paths a filter currently hides or pins. The README states that the plugin patches the explorer so that it only runs during folder sorting or when a filter changes, and that mobile devices are supported.
