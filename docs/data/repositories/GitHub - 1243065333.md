# leweii/agentic-git-sync

Obsidian plugin for two-way GitHub sync aimed at users who do not know git, with an AI agent driving the git operations. Diverged branches are merged automatically and a three-pane local, remote and suggestion resolver opens only when the model cannot decide, showing a confidence rating and its reasoning; push and merge errors are diagnosed by the agent, an empty repository is initialised on first use, and DeepSeek or Gemini drafts a commit message from the diff for editing before the commit. A background scheduler pulls and pushes on a timer, and the layout keeps private notes separate from team-shared knowledge held in submodules, on a personal-branch and team-main-branch split. Tokens and machine-local state stay in `.obsidian/` and are never committed, while remote URLs and the submodule list travel with the repository in a sync configuration file.
