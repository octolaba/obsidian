# BitComing/quick_review_clean

QuickReview reviews and polishes an Obsidian note through several agent roles, working either on the selected text or on the whole active note. The built-in roles cover factual review, wording, expansion, connection, restructuring and polishing, and can be run one at a time or as a combined review; a one-click polish rewrites the selection conservatively and applies the result back to the editor. Results open in a dedicated view where follow-up questions continue the discussion. Agents are configurable down to their identifier, label, title, system role and focus, two tools are offered for the current date and for web search, the context-menu buttons can be shown, hidden and reordered, and both OpenAI-compatible and Anthropic Messages API styles are supported.
