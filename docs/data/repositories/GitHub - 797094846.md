# Hobeom/obsidian-mouse-navigation

Mouse Navigation is an Obsidian plugin that drives navigation with right-click mouse gestures: left and right gestures move to the previous or next document, and up and down gestures scroll to the top or bottom of the current one. The gesture being drawn is tracked on screen like a pencil stroke and an overlay shows which gesture was detected. The README records the gestures as fixed for now, with customizable gestures planned for a future update.
