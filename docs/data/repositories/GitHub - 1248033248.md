# sourit2001/AskVault

A desktop-only Obsidian plugin that answers questions about the active note or the whole vault by driving the reader's own locally installed OpenAI Codex CLI, which each user logs into themselves. The chat session runs in a read-only sandbox with no approvals, follow-up questions avoid resending the full note, the scope switches between the current note and the whole vault, and a conversation can be saved into a folder in the vault. Settings cover the Codex model and reasoning effort and, when auto-detection of the CLI fails, explicit Codex and Node executable paths and an HTTP proxy; the README's installation and troubleshooting instructions are written in Chinese. The repository carries no description.
