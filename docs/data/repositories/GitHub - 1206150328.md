# 4513ECHO/obsidian-embed-plus

Embed Plus extends the set of external web pages Obsidian can embed, using the same Markdown syntax as an external image and supporting live preview. The README states that Obsidian itself supports only a few kinds of pages and lists Bluesky, GitHub Gist and Niconico as the ones this plugin adds.
