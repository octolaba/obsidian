# yesjinu/brain-dump-mode

Brain Dump Mode disables the Backspace and Delete keys in Obsidian so that a first draft is written without stopping to edit. It is activated from a sidebar icon, and a second feature the README calls Shark Mode shows a shark chasing the writer when typing slows down. The README frames the use cases as first drafts, brainstorming sessions and getting past writer's block.
