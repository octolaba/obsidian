# Keksnet/obsidian-mermaid-elk

Mermaid ELK re-enables the Eclipse Layout Kernel renderer for MermaidJS diagrams in Obsidian. The README records that a diagram opts into it by prepending a config block that sets `layout` to `elk`, and that the plugin depends on the `@mermaid-js/layout-elk` package from the Mermaid project.
