# typhoon-kim/obsidian-svelte-syntax-highlighter

This plugin adds Svelte syntax highlighting to Obsidian, which its README describes as starting from the idea of registering an identifier for the Svelte syntax with Obsidian's Prism object, and it supplies a CodeMirror extension so the highlighting also applies live in edit mode. A code block labelled with the Svelte language identifier is highlighted automatically. The README states that the plugin should not be used once Prism.js supports Svelte and Obsidian adopts that officially, and it documents installation from the community plugin browser or by extracting a release into the vault's plugin folder.
