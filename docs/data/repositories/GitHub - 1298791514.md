# jerry4pan/obsidian-office-viewer-plugin

Obsidian plugin that opens local PowerPoint presentations and Word documents from the vault in desktop Obsidian, without conversion and without uploading them. Presentations are read slide by slide with previous and next buttons, a jump to any slide number and keyboard navigation, and each open file keeps its own reading position, thumbnail scroll state and full-screen state across workspace panels. Word documents open in a continuous, read-only view aimed at reading and searching within the current document, covering headings, paragraphs, lists and tables. The README records that presentations keep their slide-reference and embed workflows and that the source files are left unchanged.
