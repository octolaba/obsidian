# PKM-er/obsidian-zettelkasten-navigation

This repository holds Obsidian Zettelkasten Navigation, a plugin adding two custom views, an index graph view and a local graph view, for navigating a Zettelkasten built on Luhmann-style note IDs, the folgezettel, and a keyword index. Its stated motivation is that a graph based only on links between notes shows the disorder of a Zettelkasten but not its order, leaving a single chain of thought, its starting point, path and end, hard to follow among crossing chains. The graphs are drawn with Mermaid through Obsidian's loadMermaid API and panned and zoomed with svg-pan-zoom.
