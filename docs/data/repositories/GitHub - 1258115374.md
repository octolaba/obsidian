# Murchi1k/obsidian-lorebase-plugin

Lorebase turns an Obsidian vault into a local Markdown media library for games, anime, movies, television shows, books, and manga. Card views, metadata, progress tracking, status fields, ratings, and collection statistics help organize each medium while keeping data portable and without accounts, cloud sync, or telemetry.
