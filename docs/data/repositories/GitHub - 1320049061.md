# lukewowo/obsidian-gcal

Google Calendar Agenda renders upcoming Google Calendar events from a fenced code block, so each note can show a different slice of the calendar through options for the date range, view, visible fields and refresh interval. Ranges accept keywords, relative offsets, absolute dates or a period; events group into agenda, list or table views by date, calendar or account, and can be filtered by calendar, account, all-day or declined status, or hidden by exact title, wildcard or regular expression. Meeting notes can be created from any event, with Templater and QuickAdd support, and stay linked through an event identifier property the plugin indexes across the vault. Access is read-only through the user's own Google Cloud OAuth client with no third-party server or telemetry, credentials sit unencrypted in the plugin's data file, and signing in needs the desktop app.
