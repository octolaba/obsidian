# cloudy9101/obsidian-image-inserter

The recorded description says the plugin helps users search for and insert images from Unsplash into the editor. The README adds Pixabay and Pexels as further sources and describes a command that opens a modal, takes a few words describing the wanted image, shows candidates from those sources and inserts the one that is clicked. An image can be downloaded into the resource folder or inserted only as a remote URL, at a preferred quality, with a default size expressed as width alone or width and height, and with a preferred orientation applied to the search. Images can also be written into frontmatter under a customized key and value format.
