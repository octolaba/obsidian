# overmoro/preach-md

Preach MD turns a Markdown note into a full-screen preach mode for delivering a sermon or another presentation, with the Obsidian sidebars hidden, large serif typography, free vertical scrolling that remembers its position within the session, and a two-step exit. A section outline opened from the top-left button jumps to any heading, a bottom-right button switches to editing at the current position, and a live timer counts elapsed time against configurable amber and red thresholds. Bible references in the text are detected and expanded inline from Bible files kept in the vault, and the mode holds a screen wake lock and suppresses edge swipes that would open a sidebar. The README states that it is aimed at the iPad and was inspired by the preach function in Logos Bible Software.
