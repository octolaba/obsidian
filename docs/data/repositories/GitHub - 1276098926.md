# tahayigitmelek/lapis-lazuli-ai-assistant

Lapis Lazuli is described as an Obsidian plugin that brings context-aware AI chat and git-style edit previews into Markdown notes. The README says it sends the active note plus a chat message to a provider chosen in settings — DeepSeek, OpenAI, Gemini or Claude — answers questions in the chat panel, and previews requested additions, rewrites and removals as green and red changes that can be accepted or rejected in full or hunk by hunk. It also generates temporary inline suggestions accepted with plus or dismissed with minus, and allows optional global extra instructions. The README states that no background AI requests are made and that provider keys are stored through Obsidian's standard plugin data mechanism.
