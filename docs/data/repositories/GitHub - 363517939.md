# ozntel/oz-clear-unused-images-obsidian

This plugin deletes image files that no note in the vault references any more: it collects every image link from the Markdown documents, compares them with the image files available in the vault, and removes the ones with no reference. A setting chooses the destination for removed files, either the vault's own trash folder, the operating system trash, or permanent deletion, and folders can be excluded from the scan by full vault path, optionally including their subfolders. The clean-up is run from a ribbon icon or the command palette, and an optional log reports which images were deleted.
