# jeetsukumaran/obsidian-bearings

Bearings provides dynamically-scoped expanding tree views of the relationships between notes in an Obsidian vault, traversing the notegraph through links while reading their meaning from frontmatter. The vocabulary of relationships is user-controlled: property names carry the semantics and the links listed under them give the structure, so a note can sit in several concurrent hierarchies at once. The README records support for two-way hierarchies through paired superordinate and subordinate properties such as `entry-parents` and `entry-children`, and for coordinate, non-hierarchical relationships such as `entry-references` and `entry-associated`.
