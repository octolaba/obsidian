# MihanEntalpo/obsidian-move-done-down

This repository holds Move Done Down, an Obsidian plugin that moves completed top-level Markdown task blocks down in the current note through a single command. A nested block travels with its parent, and a parent counts as movable only when every nested item inside it is also completed, so a completed parent with an active child is left in place. The README records that newly moved tasks can be inserted before an existing tail of completed tasks at the bottom, that line endings, final newlines, trailing blank lines and non-task text are preserved, that custom completion markers are supported, and that the plugin works on desktop and mobile.
