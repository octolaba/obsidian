# chenjhu/image-glance

Renders only images marked with a glance keyword as compact inline thumbnails, in Reading view and Live Preview, and leaves every other embed at Obsidian's normal rendering. The marker is a pipe argument in a wiki embed or the alt text of a standard Markdown image, with an optional description allowed before it. Marked thumbnails support hover preview on desktop, optional tap preview on mobile, and click isolation so a stray click does not trigger the native resize behavior. The README states the plugin makes no network requests and does not modify Markdown.
