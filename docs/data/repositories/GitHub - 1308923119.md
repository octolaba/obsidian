# bopan3/mubu-obsidian-sync

Mubu Sync is a desktop-only Obsidian plugin that makes a one-way copy of Mubu documents as Markdown files in a vault, never editing the Mubu content itself. It preserves the Mubu folder hierarchy, document identity, remote renames and moves, writes only changed documents, supports sync at startup and on a schedule, and updates only the managed section of a synced file so personal additions survive. Nested outline nodes, notes, tasks, due dates, formulas, tables and remote images are converted, and documents deleted remotely are archived locally rather than removed. The README states that this is an independent community project, not affiliated with or endorsed by Mubu, and that it relies on Mubu web interfaces that may change without notice.
