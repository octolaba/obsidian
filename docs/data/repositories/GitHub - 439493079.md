# curtgrimes/obsidian-metronome-plugin

The repository holds Obsidian Metronome, a plugin that renders an interactive metronome from a code block. Its README documents a metronome block whose keys set the tempo in beats per minute, the meter, the instrument and the size, and records that the metronome can run visually alone or with an audible click or beep. The author explains the origin as needing a tempo reference beside music notation written in Obsidian during live performance and practice.
