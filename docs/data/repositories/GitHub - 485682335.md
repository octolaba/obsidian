# musug/obsidian-paste-png-to-jpeg

The repository holds an Obsidian plugin that converts a pasted image to JPEG and compresses it. Its README records three automatic steps when a PNG or JPEG image is pasted: conversion and compression, storage in an images folder inside the current note's directory, and renaming to the note's own name followed by a number. Compression can be switched off and its quality set, with a lower quality yielding a higher compression rate, and the plugin credits an earlier paste-rename plugin as its inspiration.
