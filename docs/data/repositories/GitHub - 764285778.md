# philips/supernote-obsidian-plugin

The unofficial Supernote plugin imports handwritten Supernote notes into an Obsidian vault and renders them on desktop or mobile devices. It can embed or export note files as Markdown, PNG, SVG, and PDF, import notes edited today, mirror the device screen, and transfer files through the device's access features.
