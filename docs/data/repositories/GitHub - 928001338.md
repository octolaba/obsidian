# zarstensen/obsidian-latex-math

LaTeX Math is described as an integrated computer-algebra plugin for Obsidian built on Sympy, with a LaTeX-focused workflow. Its README says the cursor is placed inside a math block and a command then parses that block, evaluates the expression and inserts the result at the end of the block. Beyond evaluation, the documented features cover solving, symbol and function definitions, units and physical constants, symbol assumptions, logical propositions, and conversion of an expression to Sympy code. The README points to a separate documentation directory that treats those features in more depth than the README itself.
