# formax68/memoChron

MemoChron shows calendar events inside Obsidian and creates a note for an event when it is clicked. Events come from public iCalendar URLs or from ICS files in the vault or on the local file system, and a single-event ICS file dropped onto the agenda creates a note directly. A sidebar calendar marks today separately from the selected day and indicates which events already have a note, with a daily agenda listing the selected day's events; both views can also be embedded in a note through code blocks. Note creation is template-driven with a cursor marker, notes are filed into date-based subfolders, calendars can be given colours, tags and per-calendar overrides, attendees become wiki links and can be filtered by type, and the calendar data refreshes on a configurable interval.
