# GrichSHiran/obsidian-word-scalpel

Word Scalpel is an Obsidian plugin that changes what Option+Backspace deletes when the cursor sits after Thai or Japanese text. Because those scripts do not separate words with spaces, Obsidian's default delete-word behaviour treats a whole sentence up to the previous space as one word; the plugin intercepts Alt-Backspace through a CodeMirror 6 extension and uses the browser's Intl.Segmenter API to find the correct boundary. Thai, Hiragana, Katakana and Kanji are listed as the supported scripts, and behaviour for space-delimited languages such as English is left unchanged.
