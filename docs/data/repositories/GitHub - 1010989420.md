# davidvkimball/obsidian-custom-slides

The repository holds Custom Slides, a plugin that changes the navigation, styling and behaviour of Obsidian's Slides core plugin, which the README says must be enabled for it to work. Settings toggle the four navigation arrows, choose a transition effect, set the progress-bar height, left-align lists in presentation mode, apply the configured text font and show footer text on every slide but the title slide. It also switches to reading mode when Slides mode opens so keyboard input works immediately, then restores the previous mode on exit.
