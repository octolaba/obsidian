# holubj/obsidian-dialogue-plugin

Obsidian plugin for writing dialogues in Markdown. The README documents parameters set inside a dialogue block, namely the left and right participant names, a title mode that renders titles never, only on first occurrence or always, and maximum widths for messages and comments. It states that each message must be exactly one paragraph and is prefixed with a marker that places it on the left or the right side.
