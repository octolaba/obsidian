# saertna/obsidian-gamified-pkm

This repository holds Gamified PKM, an Obsidian plugin that its upstream description and README present as applying game techniques to personal knowledge management. The README documents an initialization command that rates every note not excluded by tag or folder, a rate-note-maturity command run from the palette or a plant icon whenever a note is created or improved, a profile leaf showing the resulting points, level and distribution of ratings, and boosters that unlock as progress accumulates. Tags and folders can be excluded so a shared vault keeps unrelated activity out of the game, and Dataview is named as needed for counting notes by maturity. Much of the README is promotional address to the reader and a funding appeal, which this body does not restate.
