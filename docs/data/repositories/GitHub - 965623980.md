# wth461694678/text-block-timer

This repository holds Text Block Timer, which attaches a count-up stopwatch to any text line in an Obsidian note. The README is published in English and Chinese, and its latest entry records the version 1.0.9 changes: the timer is encapsulated so it no longer exposes internal markup, its updates no longer pollute the undo and redo history, its appearance was redesigned with an option to hide the hours digit, and a scroll-wheel picker was added for adjusting a duration. Those changes are tied to the issues they close, among them a report about the undo shortcut and a request for a way to end a running timer.
