# Arcadia-Studio/obsidian-arcadia-toolbar

An Obsidian plugin that adds a Word-processor-style ribbon of tabbed toolbars above the editor without changing how Markdown files are stored. Free tabs cover formatting and lists, insertion of links, images, embeds, tables, code blocks, callouts, footnotes, symbols and math, table data work including sorting, filtering, transposing and CSV import and export, Turabian, Chicago, APA and MLA citations with bibliography generation, slide breaks and layouts for Advanced Slides, plus view, navigate, templates, canvas and review tabs, a pinnable table-of-contents sidebar and per-tab visibility toggles. The README places a theology tab, scripture hover lookup and an AI tools row behind premium, and records the plugin as desktop-only.
