# hansai-art/obsidian-tw-tts

Hans TW TTS reads notes aloud through the browser's Web Speech API and the voices built into each platform, with a Traditional Chinese interface aimed at readers in Taiwan and no external server involved. The README records reading the current note, a selection, or from the cursor onward, continuous playback across a folder, and a separate reading pane that lists the note sentence by sentence, highlights the sentence being spoken and scrolls it into view. Settings cover the voice, listed in quality order, a speaking rate adjustable during playback, a pronunciation dictionary for homographs and proper nouns, and a list of bullet symbols to strip so they are not read out. It states that macOS, Windows, iPhone and iPad are supported while in-plugin reading is not possible on Android, because Obsidian's Android WebView does not expose the speech interface.
