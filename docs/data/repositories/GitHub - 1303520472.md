# fengmz/ForestRest

ForestRest is an Obsidian theme ported from the Typora theme lightmind, built on an ink-on-paper idea: warm beige page surfaces, restrained forest-green accents and dark ink code blocks. Light mode is the primary design and dark mode is derived from it as a deep green-black night variant. Body text is set in LXGW WenKai and code in JetBrains Mono, with syntax colors drawn from a forest spectrum of moss purple, autumn gold, new moss, ochre, stream cyan and warm clay. Callouts, tables, blockquotes, tags, math and footnotes are themed, and the font fallback chain is local so nothing is fetched from the network.
