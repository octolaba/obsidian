# ZukTol/obsidian-data-files-editor

Repository for the Data Files editor plugin, which adds the ability to create and edit `.txt`, `.json` and `.xml` files inside Obsidian. Editing and creation can be enabled separately for each of the three types in settings, and new files are created from the file tree context menu — inside a folder when a folder is clicked, or at the same level when a file is clicked. The README states that the XML editor has no highlighting yet and that it is planned for a future release.
