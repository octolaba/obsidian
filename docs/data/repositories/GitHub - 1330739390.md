# User-DK/obsidian-horizontal-scroll-view

Horizontal Scroll View opens a note in a separate read-only tab where each H1, H2 or H3 heading becomes its own column, scrolled vertically on its own and laid out along one horizontal track. Columns can be dragged to resize with a double-click reset, collapsed to a sliver that keeps the heading visible, and their widths are remembered per file. A row of chips below the toolbar snap-scrolls to any column, and buttons copy a section as Markdown or return one or all columns to the top. Content before the first heading is gathered into a preamble column, and the view re-renders shortly after editing stops in the standard editor.
