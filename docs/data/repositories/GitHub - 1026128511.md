# Xheldon/git-folder-sync

Synchronizes vault files with a specified directory inside a GitHub repository rather than with the whole repository. The README describes bidirectional sync, single-file and whole-vault batch operations, recursive folder handling, a file status cache that reduces GitHub API calls, and a status bar showing sync state and last modified time. Configuration takes a personal access token with repo permission and a repository path in either full URL or short form. An optional image feature uploads pasted images to Aliyun OSS, Tencent COS, AWS S3 or Cloudflare R2, and the interface is available in Chinese and English.
