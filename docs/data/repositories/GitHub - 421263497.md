# colineckert/obsidian-things

Things is an Obsidian theme modeled on the Things 3 task manager, built to look and feel native on macOS and iOS. The README records a Things-inspired color palette across light and dark themes, a floating action button for quick preview and edit on mobile, tag pills, checkbox styling and icons, Atom syntax highlighting, code blocks with line numbers, and the JetBrains Mono font with ligatures. Colors for bold, italic, highlighters and blockquotes are customizable through the Style Settings plugin, the README lists the community plugins it supports, and it states that version 1 of the theme was built from code in the Minimal theme.
