# Jamailar/QuickLink-Obsidian

QuickLink inserts file links in Obsidian from a trigger character typed in the editor, with the at sign as the default trigger. The README states that typing a trigger and keywords opens a suggestion list, that Enter inserts the link while Shift+Enter adds an alias, and that further trigger rules can be defined, each with its own character, a set of folders it searches, a regular expression filter on file names and a tag filter. Main folders confine suggestions and scanning to given paths while excluded folders are ignored in global suggestions; an Auto Link Scan ribbon button scans the open document and replaces text matching file names under the main folders with links, optionally in the Advanced URI format built from a configurable frontmatter field.
