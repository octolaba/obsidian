# KkEi34/confluence-to-obsidian-plugin

Confluence Import imports a Confluence space that has been exported as HTML into an Obsidian vault, converting it under the hood with the author's separate confluence-to-markdown tool. The README states that the plugin is work in progress and used at the user's own risk, that it works on desktop only, tested on Windows 10, Ubuntu 22 and macOS Sonoma, and that the Pandoc command line tool must be installed, with `/usr/local/bin` assumed as its location on macOS. It documents how to produce the HTML export from both Confluence Server and Confluence Cloud before the import.
