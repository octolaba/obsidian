# DearVikki/obsidian-cloze-plugin

Cloze converts text in an Obsidian note into clozes, taking its inspiration from Anki cards. Special segments such as highlighted, underlined or bolded text can be converted automatically in reading mode by enabling the matching settings, and any selection can be turned into a cloze from the editor menu, optionally with a hint, or have its clozes removed in bulk. In reading mode a cloze is revealed or hidden by clicking it, a ribbon icon toggles every cloze at once, and a hover-to-reveal setting shows the content while the mouse is over it. The README notes that the Spaced Repetition plugin also supports cloze cards, and positions this plugin as a helper for reviewing pages and articles instead.
