# vuecwiz/obsidian-mqtt-sync

Subscribes an Obsidian desktop vault to an MQTT broker and writes incoming messages into Markdown notes. Accepted publications are persisted to a checksum-protected state file before processing, then routed by ordered first-match rules that test delivery metadata, envelope fields and content, with templates deciding the target note, the inserted block and any attachment path, and a forced marker making repeated delivery idempotent. Connectivity covers MQTT 3.1.1 and MQTT 5 over plain, TLS and WebSocket transports, with password authentication, custom trust roots or mutual TLS, wildcard topic filters, all three quality-of-service levels and bounded reconnect backoff. A status indicator, redacted diagnostics, retry commands and an optional result outbox round it out; it is desktop only and needs Obsidian 1.12.7 or newer.
