# loglux/fix-math-for-obsidian

Fix Math for Obsidian converts LaTeX math delimiters in the currently open note to Obsidian's format, turning display math into double-dollar delimiters and inline math into single-dollar ones. It is aimed at text pasted from ChatGPT, OpenWebUI, Windows Copilot and similar assistants, and it also detects mathematical content in plain parentheses and single-line brackets, including quoted block math inside blockquotes. Existing dollar-delimited math and everything inside fenced code blocks are left untouched, and the plugin reports how many inline and block formulas were converted in the status bar; it is reachable from a ribbon button and the "Fix math (current file)" command.
