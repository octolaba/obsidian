# Jimmycarroll2021/obsidian-kg-forge

KG Forge extracts typed subject-predicate-object triples from an Obsidian vault, reading YAML frontmatter, Breadcrumbs-style connection fields and wikilinks without requiring those plugins to be installed. Nodes are typed through folder to fileClass mappings, and every triple carries provenance: source, confidence, timestamp and lineage. It validates the vault schema for missing fileClass, malformed source identifiers, missing provenance and broken source links, tracks competency questions against that schema, and exports the graph as Neo4j Cypher merge statements or as Dataview query templates. A GraphRAG prompt is assembled from a k-hop subgraph serialized as bullet facts with a guard telling the model to say so when the facts do not support an answer, and the README describes the plugin as local-first and offline.
