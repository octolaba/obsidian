# SShah7433/obsidian-jira-tiles

Jira Tiles replaces a fenced jira code block naming an issue key with a tile carrying the issue type icon, summary and subtitle, a field grid of issue type, colour-coded status and priority, due date, fix versions and assignee, any custom fields, and a footer with the last-fetched time, a refresh button and a button that opens the issue in Jira. Authentication uses an Atlassian API token kept in Obsidian's SecretStorage, with only the secret's name stored in the plugin data file. Custom fields render as user, sprint, option, version, date, number or boolean without per-field configuration, and a discovery action picks fields from the live instance instead of typing identifiers. A configurable cache falls back to stale data with an offline indicator, and the README states the target is Atlassian Cloud only, with tiles reflowing for mobile.
