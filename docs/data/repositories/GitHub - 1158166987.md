# landnthrn/Obsidian-GraphForge

GraphForge is an Obsidian plugin that builds and maintains a graph view in which folders act as root nodes, for vaults whose notes are organised into folders. The README records that it creates one note per folder, hidden by default, which serves as that folder's node in the graph view, and adds a link to the folder's hub note at the top of each note inside it so the notes attach to their folder node. Its settings expose a button to build or refresh the hub notes and a second button to build or refresh the hub links inside notes, and the description also records a quick-access hub note display per folder.
