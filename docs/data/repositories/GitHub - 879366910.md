# ddspog/obsidian-ribbons-theme

Ribbons is an Obsidian theme built from modular SCSS sources, and its repository description says it allows separating special callouts into ribbons. The src folder is organised by function: shared variables, mixins and functions; callout styles split into decorative, input, layout and option groups; code block styles with plugin integrations such as dataview and leaflet; reusable components such as exhaustion bars, counters and attribute displays; editor, embed and markdown styles including note types such as item, spell, statblock and player character; and further folders for settings, tags and tasks. The README says the theme is installed and activated from the appearance settings and that the SCSS files can be edited to customise the look further.
