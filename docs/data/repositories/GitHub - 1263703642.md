# kinrochen/obsidian-glint

Reads capture JSON files left in the macOS Shortcuts iCloud inbox and writes them into the vault as Markdown notes carrying a title, category, tags, summary, key points and entities, filed into category subfolders with Obsidian-friendly frontmatter. For captures holding only a URL it can fetch readable page text and extract source title, site name, author and published time, warning when the result looks like a login or anti-bot page or is too short. Duplicates are detected by URL or content fingerprint and can update an existing note, be skipped or be copied. A ribbon inbox view shows pending, processed and failed items with retry and bulk cleanup; the README records the plugin as desktop only, with a provider test for Ollama or OpenAI-compatible models, a local heuristic fallback, and Chinese and English interfaces.
