# magitools/magiedit-obsidian

No repository description is recorded, so this body is grounded in the README alone. This is the official Obsidian plugin for interacting with magiedit, configured with the URL of the magiedit instance to connect to, defaulting to the hosted one, and an API key created in the magiedit web application. It adds a single command, Publish Current File, which retrieves the configured publishers, lets one be chosen, and posts the selected publishers together with the content of the open file to the magiedit API.
