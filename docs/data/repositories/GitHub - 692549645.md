# iOSonntag/obsidian-plugin-treefocus

TreeFocus highlights, dims and styles the files and folders shown in Obsidian's file explorer, either through matching rules or item by item. Its README sets out sections for matching rules, per-item overrides and style presets alongside installation and compatibility, and frames the purpose as turning down template, attachment and archive folders while bringing active project folders forward in a vault where every file otherwise looks equally important.
