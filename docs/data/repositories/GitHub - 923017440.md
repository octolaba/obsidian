# exoticknight/quick-nav

Quick Nav exposes cursor navigation operations in the Obsidian editor without binding any default shortcuts, leaving every binding to the user. The recorded commands move the cursor up, down, left and right, a page up or down, and to the left or right end of a line, with matching commands that extend the selection in each of those directions. The README lists recommended bindings for Windows, Linux and macOS and explains that they are assigned by searching for Quick Nav in Obsidian's Hotkeys settings.
