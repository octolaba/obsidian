# shuuul/obsidian-infographic

Obsidian Infographic renders AntV Infographic visualisations from fenced code blocks inside notes. The README lists more than 200 built-in templates covering process flows, timelines, hierarchies and charts, and accepts either JSON configuration or AntV's declarative DSL as the block's content. Rendering handles resizing automatically, follows the auto-detected theme or a forced light or dark mode, and is stated to work with Obsidian's Export to PDF feature. A command refreshes every infographic in one step, and the plugin is distributed both through Community Plugins and as a beta through BRAT.
