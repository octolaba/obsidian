# DarkSeasonStudios/obsidian-masonry

Obsidian Masonry displays folder contents in a Pinterest-like masonry layout of tiles, with tag management, pin boards and drag-and-drop. A folder is turned into a masonry view from its context menu, while a pin board is created the same way and holds pinned records rather than the files themselves. The README describes tagging items and pins, a search bar filtering by name or tag, multi-select with Ctrl and click, double-click image preview, and context menus on items and pins.
