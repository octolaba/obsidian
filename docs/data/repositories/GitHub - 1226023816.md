# Real-Fruit-Snacks/Cove

The repository holds Cove, a bookmark manager for Obsidian that stores each bookmark as a Markdown file with YAML frontmatter in a folder of the user's choosing, with no proprietary database. Adding a URL fetches the page's Open Graph title, description and image, its favicon, author and an estimated reading time and writes them into the new note's frontmatter, and the plugin keeps only an in-memory index derived from those files. The README states that bookmarks remain plain Markdown notes if the plugin is disabled, and that the plugin offers switchable layouts.
