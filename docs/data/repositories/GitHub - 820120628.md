# Swaggeroo/obsidian-ai-image-analyzer

This plugin analyzes images in Obsidian through the Ollama API and returns a keyword list for the image, so Ollama must be installed and running somewhere reachable. Analysis is started from the image's right-click menu or the command palette and covers jpg, jpeg, png and webp files. The default model is llava-llama3, with other llava variants selectable in the settings, and the README documents integration with the OmniSearch plugin, whose Image AI Indexing option indexes the analysis results.
