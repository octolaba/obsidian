# hanchan78/ObsidianFolderView

FolderView renders a folder of the vault as a tree inside a note, written as a folderview code block whose body is a path relative to the vault root. The tree lists every file, not only Markdown, recursing through subfolders and showing empty ones, hides the .md extension on notes while optionally showing others, and opens a clicked entry as an internal link would, with hover preview when page preview is enabled. Folders collapse and expand by mouse or keyboard, and that state is remembered globally by vault path across notes, reloads and restarts, surviving renames and moves. Sorting, whether files or folders come first, extension display and folder, fallback and per-extension icons are settings; trees update when files change, can be filtered, highlight the active note, and work on desktop and mobile.
