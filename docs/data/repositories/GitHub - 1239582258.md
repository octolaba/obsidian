# MrIwan/obsidian-nope

This repository holds NOPE, an Obsidian plugin that exports notes to publication-ready PDFs through a Docker-based Pandoc and LaTeX pipeline using the Eisvogel template, so no local TeX distribution has to be installed. Its authoring model is atomic: chapters, theorems, tables, glossary entries, diagrams and other reusable blocks live in their own notes and are embedded into a main document, cross-references number themselves, glossaries and bibliographies build themselves, and branding comes from a note. The README states that the plugin is still in early development, not yet stable and subject to breaking changes, and points to a wiki whose feature pages are built by the pipeline itself.
