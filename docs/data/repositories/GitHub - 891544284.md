# wenlzhang/obsidian-link-maintainer

Link Maintainer is described as helping to maintain note links when notes are split or reorganized, with the README narrowing that to block references and stressing safety. It sets out the problem it addresses: when a section carrying a block id is extracted into a new note, the block id moves with the text while references elsewhere still point at the original note, so those references break. Without the plugin, the README says, every referencing note and canvas file would have to be found and updated by hand. The repository also records a documentation homepage for the plugin.
