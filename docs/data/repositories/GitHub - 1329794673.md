# CosmicSeaFox/Circuit

Circuit is a technical Obsidian theme with a dark mode of deep surfaces and controlled cyan and blue signal accents, and a light mode built on bright laboratory-style surfaces with the same restrained accents. Tables are treated as structured data for specifications, measurements and comparisons, properties as technical metadata, callouts as system-style information panels, and the graph view as a network of signal paths. Tags are compact component-style labels, task states read as system status, and both reading and source modes and a responsive mobile layout are covered.
