# AwesomeDog/obsidian-awesome-reader

Obsidian plugin that reads ebooks stored in the vault, currently epub and pdf. It remembers reading progress in the plugin's own folder so a book can be continued on another device when a sync service carries that folder, and it can create a book note alongside the file from the table of contents with organised heading levels. The README says that detecting all file extensions has to be enabled first, that reading progress for pdf is not fully implemented, and that some code comes from caronchen's ePub reader plugin.
