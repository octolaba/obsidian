# ninglg/light-mindmap

Obsidian plugin that renders a note's Markdown heading hierarchy as an interactive mindmap without any custom syntax. Adding a type key to the frontmatter replaces the editor and reading view with a live map built from headings, updated in real time as the source is edited, and a folder context-menu entry creates a new mindmap file. All heading levels are parsed into a tree, inline markup is stripped from node labels, fenced code blocks are skipped, and a virtual root named after the file is added when several top-level headings exist. Five layout modes are switchable from a toolbar dropdown or a command, alongside themes, node shapes, line styles, wikilink support, node collapsing and PNG export.
