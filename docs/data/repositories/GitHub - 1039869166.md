# dbarnett/obsidian-gh-links-shortener

Captures pasted text and, when it detects a GitHub link to a repository, issue or pull request, sets the link title to a shortened GitHub reference. The README gives a pull request URL rewritten to an owner/repo and number form as its example. It names two related projects: GitHub Link, which enriches links by fetching information when a page is viewed, and a JIRA links shortener that inspired this one.
