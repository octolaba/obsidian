# dzplus/obsidian-sync-confluence

Sync Confluence pushes notes to Confluence pages on a schedule, binding a note to its page through a Confluence URL in the note's frontmatter and needing no separate mapping file. The README records basic authentication with an email and API token for Atlassian Cloud and a bearer personal access token for Server 7.9 or later and Data Center, a content hash that skips unchanged notes, upload of local embeds as page attachments displayed at a configurable width, and creation of a child page from a parent URL with the resulting URL written back into the note. Mermaid and PlantUML diagrams are pre-rendered to an image attachment before the push, Mermaid either through a kroki HTTP service producing PNG or through the in-process Obsidian engine producing SVG, and a sync is triggered from a ribbon icon, the command palette, a right-click in the editor or file tree, or the timer.
