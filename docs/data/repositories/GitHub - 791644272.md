# dsebastien/obsidian-update-time

This plugin keeps the created and updated frontmatter properties of a note in sync with the file's own creation and modification timestamps, running in the background rather than through a command. The README states that the created value is never overwritten, that the updated value is debounced to roughly a minute and further delayed by a configurable save delay so it does not disturb active editing, and that the property names and a list of excluded folders are configurable. Excalidraw files, canvas files and non-Markdown files are skipped, a one-shot command backfills the properties across existing notes, and the plugin is described as fully local with no network calls and no telemetry. It is a simplified reimplementation of an earlier update-time-on-edit plugin, written because that plugin did not work well with Obsidian Publish.
