# Masterb1234/obsidian-post-webhook

This plugin sends Obsidian notes or selected text to webhook endpoints, with the recorded description naming n8n, Make.com and Zapier as examples of such services. The README states that several endpoints can be configured, that YAML frontmatter and inline fields are parsed into the payload and attachments are handled automatically, that a webhook can be set to send the note's rendered HTML instead of raw Markdown when the note is in Reading View, and that other notes can be included as context for dynamic workflows. Commands send the whole note or, outside Reading View, the current selection; responses can be appended to the note or inserted after the selection, and complex JSON responses carrying attachments are handled.
