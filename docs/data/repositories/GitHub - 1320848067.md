# sebasalas/obsidian-toon-syntax

TOON Syntax Highlight colours fenced code blocks tagged toon, the Token-Oriented Object Notation format, so tabular dumps stay readable inside a note. Keys, quoted strings, numbers including exponents, the null, true and false keywords, punctuation and hash comments each map to one of Obsidian's own code colour variables, so the result follows the active theme in light and dark mode. Quoted values are parsed properly, so a colon inside a quoted string does not turn the row into a key and value line, and doubled or escaped quotes are respected. It works in Reading view and Live Preview but not in source mode, since it is a rendered-Markdown post processor, and one setting wraps long lines instead of scrolling them horizontally.
