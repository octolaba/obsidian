# patrick-knight/Vestaboardian

Vestaboardian composes a message in an Obsidian note under a Vestaboard heading and sends it to a Vestaboard split-flap display from a command or the ribbon. A sidebar view renders the message as tiles while it is typed, validation reports unsupported characters, over-wide rows and extra rows with precise errors or normalises them automatically, and a modal shows what the board will display before anything is transmitted. Emoji squares become coloured tiles, each send is logged newest-first in a history table inside the note, and two transports are supported: the Vestaboard cloud read/write API and the LAN-only local API, for both the Flagship board of 6 rows by 22 columns and the Note board of 3 by 15. The README marks the plugin as beta and desktop only, covered by 74 unit tests but with limited testing against a running Obsidian instance and physical boards.
