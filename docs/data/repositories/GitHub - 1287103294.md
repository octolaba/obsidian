# mrrepac/obsidian-songwriter-player

Songwriter Player keeps an audio player in its own side panel so playback continues while lyrics are scrolled, and survives closing the panel because the sound lives in the plugin rather than in the interface. It picks up the audio embedded or linked in the note being opened, in a hybrid, always or manual mode, and offers to switch with a banner instead of interrupting what is already playing. The waveform responds to a single click to play from that point, a double click to set the one marker kept per track, and a press and drag to select an A-B loop zone whose start becomes the marker; both marker and zone are remembered per file. A note holding several audio files becomes its playlist.
