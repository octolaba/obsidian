# motherduckdb/obsidian-duckdb-motherduck

DuckDB & MotherDuck runs SQL over external data from inside a note: a duckdb code block is rendered in reading mode as a panel with Run, Freeze and Clear freeze buttons, and freezing writes the result underneath the query as a Markdown table bracketed by sentinel comments that the next refresh replaces. The README states that queries run locally in DuckDB WASM and can read Parquet, CSV, JSON, Excel, Iceberg, Delta and geospatial sources, and that adding a MotherDuck token enables cloud blocks against cloud databases or heavier compute. A per-note daily or weekly cadence re-runs the queries while Obsidian is open, and the README contrasts the plugin with Dataview, which queries the vault itself rather than external data.
