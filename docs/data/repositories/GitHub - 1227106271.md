# MMoMM-org/miyo-hakobi

MiYo Hakobi ferries files on a schedule between an Obsidian vault and local filesystem paths, with import rules bringing files in and export rules writing out a vault folder subtree, a tag selection matched on any or all tags, or a single note. Each rule carries its own interval, creating a rule is the approval moment, and a rule synced to another device stays off there until it is enabled. The README records atomic writes so a destination holds either the old or the new version, filename sanitization that refuses NUL bytes, path traversals and empty names at scan time, and a stability check before an import. It states that the plugin has no network surface, no daemon and no telemetry, and that its NDJSON audit log carries only metadata such as paths, operations, byte counts and timings; those are the project's own claims.
