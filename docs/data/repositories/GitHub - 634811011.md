# levirs565/obsidian-dendron-tree

Repository for Obsidian Dendron Tree, a plugin that adds a tree for exploring Dendron notes inside Obsidian. The tree marks notes that have no corresponding file and offers per-note actions to create that file, open Lookup with the note's path as the initial prompt, or delete the note, while the Lookup command opens, creates and deletes notes by Dendron path. The README also documents automatic frontmatter generation for a new file, multiple vaults added in settings by path and name, and a custom resolver and renderer for Dendron-style links and embeds that is disabled by default.
