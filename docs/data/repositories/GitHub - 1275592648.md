# BenCurrie42/navidrome-player-for-obsidian

This repository holds Navidrome Player, an Obsidian plugin that plays a Navidrome music server's library from the sidebar. Cover art turns like a record while a track plays and stops when it is paused, clicking the cover toggles playback and a square mode is available, while the library can be browsed as an album grid, as artists with expandable albums, or as playlists, with one search bar covering artists, albums and songs. The README also records internet radio stations saved on the server with best-effort now-playing information, queue shuffling and a dice action that clears the queue and draws an endless random mix from the whole library, a short setup of server, username and password with a connection test, and that the plugin is desktop only for now.
