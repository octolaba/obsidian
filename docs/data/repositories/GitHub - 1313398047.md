# nonstopdevelopment/media-fetcher

A desktop-only plugin that saves a video or podcast into the vault by invoking a local yt-dlp installation, with ffmpeg used for merged streams and audio conversion; neither program is bundled or updated by the plugin. Downloads start from a command or ribbon icon and offer video presets at 480p, 720p, 1080p or best available and M4A, MP3 or Opus audio, with progress in the status bar, an activity panel showing diagnostics and errors, and a command to cancel. Files follow Obsidian's configured attachment location by default or a custom media folder, and the attachment plus a source link can be inserted into the active note; raw URLs and Markdown links can be right-clicked to download and replace them. yt-dlp is invoked directly with an argument array rather than through a shell, and downloads are single-item by default so playlists are not imported by accident.
