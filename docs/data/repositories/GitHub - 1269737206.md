# artdeone/art-de-one

An Obsidian plugin bundling three editor features. Selected text can be sent to an assistant through any OpenAI-compatible endpoint from a context-menu action, with streamed responses, model switching from the modal header, retry, copy and cancel, and the whole answer or a chosen part applied back into the note. A hotkey highlights the selection in one of six colours, applied or removed by clicking the same swatch. Tables are inserted from a visual grid picker and edited with a floating toolbar that adds or deletes rows and columns and formats alignment, with undo and redo support.
