# CccJhuan/spatial-task-graph

Repository for Spatial Task Graph, a plugin that lays Markdown tasks out on an infinite canvas instead of a linear list. Its README describes dragging between tasks to create dependency connections and right-clicking to delete them or add sticky notes, box selection for moving several nodes at once, and dragging a connection into empty space to open a creation dialog that appends the new task to the parent file and links it. A sidebar groups tasks into in-progress, pending and backlog columns that can be reordered by dragging to change status, and a layout command arranges the graph and moves completed isolated tasks out of the way.
