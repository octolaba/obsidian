# mnaoumov/obsidian-backlink-full-path

Obsidian plugin that shows a backlink's full path in the backlinks panel, where Obsidian by default shows only the note name. The README presents this as the way to tell backlinks apart when notes with the same name live in different folders. A demo vault with usage examples ships with every release and can be opened from a command, downloaded from the releases page, or browsed in the repository, and the README documents installing beta versions through BRAT alongside the community plugins listing.
