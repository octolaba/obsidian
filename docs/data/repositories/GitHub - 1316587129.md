# musel25/indent-to-headings

Indent to Headings converts indented plain-text outlines into Markdown headings, turning each line that has children into a heading at a depth derived from its indentation and leaving leaf lines as body text or bullets. Conversion can cover a selection, the whole note, the outline block at the cursor, or only regions delimited by marker comments, and a preview command shows the result before it is applied. Existing Markdown headings are preserved so a note can be converted repeatedly, fenced code blocks are skipped, and existing list markers and task checkboxes on leaf lines are kept. Settings control the base heading level, spaces per indent, how many children a line needs to become a heading, and how leaf and blank lines are written.
