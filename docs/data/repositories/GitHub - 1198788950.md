# TGRRRR/heading-outliner

Heading Outliner is an Obsidian plugin that applies outliner-style editing to heading-based Markdown, moving, indenting and unindenting whole sections with the hotkeys used for bullet lists. The README records moving a heading with its body text and sub-headings past sibling sections, and Tab and Shift+Tab changing heading levels only when the cursor is on a heading line, across single headings, range selections or multiple cursors, with fold state preserved and a folded parent unfolding when a heading becomes its child. Fold more and fold less commands expand or collapse the outline one level at a time over the selected visible headings, falling back to the heading under the cursor. Optional per-level visual indentation is styled with CSS, and the README states the hotkeys are CodeMirror 6 keymaps that pass through to the Outliner plugin on list lines.
