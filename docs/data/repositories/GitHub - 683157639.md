# julix14/chatGPT-Obsidian

The repository records no description, so this body rests on the README alone. The README states that the plugin adds a single command that generates a definition for a topic through the OpenAI GPT-3 API, using the file's title and its tags as the prompt and appending the generated text to the end of the file. An API key is entered in the settings, and after generation the note's status is set to a configurable value that defaults to marking the text as written by AI.
