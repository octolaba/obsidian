# touss59/obsidian-code-playground

Code Playground embeds live, editable Sandpack playgrounds inside Obsidian notes, so a fenced block becomes a running sandbox for React, Vue, Vanilla, Svelte or Angular. The README carries a network and privacy warning: playground code is sent to CodeSandbox's hosted bundler service to build the preview, npm imports are resolved from its registry and CDN, an internet connection is required because there is no offline mode, and the Open in CodeSandbox button uploads the block's code. A self-hosted bundler URL can be set in the settings tab so that playground code and dependency resolution go to an endpoint under the user's own control instead.
