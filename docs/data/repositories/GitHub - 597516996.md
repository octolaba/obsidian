# cberane/obsidian-material-symbols

No repository description is recorded, so this body is grounded in the README alone. The Material Symbols plugin adds Google's outlined material symbols to Obsidian through two commands that insert a styled inline element and place the cursor inside it, so the icon name can be typed as listed by Google. The README records default font settings for fill, weight and grade, and additional classes that override those defaults to activate filling or to select another font weight.
