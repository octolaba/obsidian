# Mara-Li/obsidian-create-note-in-folder

Create Note in Folder adds commands that create a new note in a folder configured in the plugin settings, with a command generated per registered path and an optional file-menu entry. Each folder can define its own filename, template applied through Templater, and how the note opens — current tab, new tab, window or split view — and whether it is focused afterwards; a current placeholder in the path targets the folder of the open file, and custom variables can be interpolated into paths. Global settings hold a default template for unregistered folders and can enable a quick-switcher command that lists folders, optionally filtering out the ones already registered.
