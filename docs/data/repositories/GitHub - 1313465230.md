# reticenceji/better-quick-switcher

Opens a fuzzy search over headings, either across every file in the vault or within the current file, and jumps to the selected heading. The switcher is bound to Ctrl+Shift+O, or Cmd+Shift+O on macOS, and a second command can override Obsidian's built-in quick switcher. Settings control which heading levels from H1 to H6 appear, which folders are excluded, and the maximum number of suggestions, from 10 to 200 with a default of 50.
