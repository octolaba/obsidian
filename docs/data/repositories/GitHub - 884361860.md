# bfloydd/coalesce

Coalesce merges the notes that link to the current note into a single view, offered as a replacement for Obsidian's Backlinks in Document with more configuration. The README states the problem it addresses: capturing a quick note without first sorting it into a folder hierarchy, and finding those notes again later in one view. Aliases and filtering narrow what the view shows, and a divider limits how far down a note the view reaches. Roam, Logseq, Influx and OneNote's Quick Notes are named as inspirations.
