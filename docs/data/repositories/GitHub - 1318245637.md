# safasffa111/TreeTalk-Obsidian

An AI research assistant whose conversations form a tree: each follow-up either continues the current node or opens a branch, and text selected in a note or an earlier answer becomes context with a link back to its source. Evidence is pulled on demand from the current note, ancestor nodes and related notes, and answers stream with a stop control and can be retried or continued in place. A single answer or a whole tree can be distilled into ordinary Markdown notes joined by wiki links, and a relationship graph of the distilled tree lets nodes or edges be excluded from the next distillation. Conversation data lives in the plugin's own folder outside the file list and search, the API key is kept in Obsidian's secret storage, and note text and selections are sent to the configured API, DeepSeek by default.
