# nord342/obsidian-claude-citations

Obsidian plugin that answers questions about a vault with citations produced by Anthropic's Citations API. The README states that notes are chunked into paragraph blocks before being sent, so a citation lands on the right passage rather than the whole file, that each inline citation is a link back to the source note at the cited paragraph, and that the cited text is guaranteed to come from the notes rather than from a prompt asking the model to include sources. It also states that prompt caching makes follow-up questions in a session cheaper, that the API key is stored locally in the plugin's vault data, and that only the top-ranked notes for a question are sent.
