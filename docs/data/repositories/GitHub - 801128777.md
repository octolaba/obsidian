# paperbenni/obsidian-zenmode

This repository holds an Obsidian Zen Mode plugin based on the Hider plugin, which hides most of the interface so that only the current text file or document remains, together with a single button that restores all of it. Its stated motivation is that Obsidian suits neither content consumption nor presentation: on mobile a PDF fills less than 40% of the screen, and on desktop there is no quick switch between an editing-friendly and a viewing-friendly layout. Toggling zen mode also collapses and restores the side bars, and recent versions add a draggable top bar, a device-dependent exit button, and full screen, hide properties, hide inline title, padding and focused file options. Themes can adapt to it because the plugin puts a zenmode-active class on the body element.
