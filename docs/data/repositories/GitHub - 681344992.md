# cabra-arretado/mini-vimrc-obsidian

Mini Vim Keymaps is a minimal Obsidian plugin whose single job is to apply basic Vim mappings to Obsidian's Vim mode. It reads a vimrc file from the root of the vault and supports the map, imap, nmap, vmap, noremap, inoremap, nnoremap, vnoremap and unmap commands, with comment lines starting with a double quote. The README explains the motivation: Obsidian's CodeMirror-backed Vim mode accepts keymaps but does not set them at startup, so they otherwise have to be entered by hand each session. The vimrc path is configurable and may point at a Markdown or plain text file, including one inside the Obsidian configuration folder.
