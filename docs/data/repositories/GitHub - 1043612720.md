# raeperd/obsidian-default-template

Applies a chosen template automatically to every newly created note, so no manual insertion step is needed. The README states it works for any creation path, including the new-note shortcut and clicking a link to a note that does not exist, supports per-folder templates with hierarchy fallback and ignore paths, and processes the date, time and title variables with Moment.js format tokens like the official Templates plugin. With no template selected the plugin does nothing.
