# tadashi-aikawa/obsidian-old-note-admonitor

The repository holds Old Note Admonitor, an Obsidian plugin that shows an admonition on a note that has not been updated for a configured number of days. Its README records a message template with placeholders for the number of days and the reference date, and a setting choosing where that date comes from: the file's modified time, a front matter field, or a capture group taken from the note. The default template states that the content below has not been updated in the given number of days.
