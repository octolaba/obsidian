# ChristianLemer/obsidian-nushell

This plugin renders Nushell data files as coloured tables with nested records and lists, and syntax-highlights Nushell scripts using the shell's own highlighter. Both file types open directly in Obsidian, and the corresponding code blocks can be embedded in a note. Settings cover the date and time format, filesize units and the colours used for booleans, datetimes and filesizes, and files fall back to raw text with a warning when Nushell is not installed. It is recorded as desktop-only because it requires shell access to the local installation.
