# zhouhua/obsidian-white-noise

This plugin plays white noise inside Obsidian, with dozens of sounds such as rain and coffee shop ambience, a volume control independent of other audio, and a simple built-in pomodoro timer that works alongside the sound. The README credits the Moodist project for the sound material and records how it was modified for this plugin: some sounds that could induce anxiety, such as thunder, were removed, oversized files were dropped, the audio was compressed to variable bit rate with channels merged into joint stereo and content kept between 40 Hz and 15000 Hz, and base noise files were replaced by dynamically generated noise.
