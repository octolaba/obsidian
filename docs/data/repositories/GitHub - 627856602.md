# dartungar/obsidian-mood-tracker

Mood Tracker records a mood rating with customizable mood labels, optional detailed emotions and free notes, storing its data in the vault as plain JSON. Entries can also be added to notes such as a daily journal, with the note path derived dynamically from the entry date, and past entries can be edited or added for earlier days. A history graph shows average and frequent moods and emotions and opens the details of a day when a point is clicked; the same graph can be embedded in a note through a mood-tracker-stats code block whose options set the end date, the number of days shown, which summary lines appear and the size. The README presents it as an alternative to building and maintaining such a system yourself with Markdown files, metadata and Dataview.
