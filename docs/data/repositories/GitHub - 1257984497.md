# whiteblack1858/smart-link-note

Repository for Smart Link Note, a plugin that adds commands and context-menu entries for linking notes. Its README describes creating a new note from a prompted title, inserting a link to it at the end of the current note and writing a back-reference into the new note so both directions exist, copying the active note's wiki link to the clipboard, and inserting empty brackets that trigger Obsidian's native link autocomplete. The same creation flow is offered from the file explorer's context menu, and every command can be run from the palette or bound to a hotkey.
