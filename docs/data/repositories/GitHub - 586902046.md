# chrisgrieser/grappling-hook

Grappling hook adds file-switching commands to Obsidian for people who find the Quick Switcher too slow. Its bookmark cycler goes to the most recently modified bookmarked note and then cycles onwards through bookmarked files, and with text selected it instead copies that selection to the last modified bookmarked note; bookmarked blocks and headers are ignored. Further commands switch back and forth between a note and its alternate in the manner of vim's buffer switch, cycle through all open tabs including those in other splits, step through the current folder alphabetically, and open the first URL in a file.
