# TonyMio/openloops-hidden-files

Obsidian plugin that reveals a chosen list of dot-folders in the native file explorer, folders Obsidian otherwise filters out at the vault-adapter level. Whitelisted folders are injected into the live vault cache so they show up in the explorer and in search, graph and metadata, and that injection is index-only and never writes to disk. Opt-in is per folder by design, because pointing Obsidian at something large such as a version-control directory would make it scan every object; a rescan command re-applies the list after folders are added on disk. The README records desktop-only support, reliance on undocumented internals that the plugin checks for at load before staying inactive, and the consequence that a revealed folder becomes an ordinary vault tree for everything that reads the vault.
