# ondreu/markdown-spreadsheets

Markdown Spreadsheets opens a Markdown table from a note in its own tab as a spreadsheet grid, reached from the ribbon, a button on the table, the command palette or a context menu. The note stays the source of truth: what is written back is strictly valid GitHub-flavored Markdown, with pipes realigned and alignment markers taken from the column alignment. The grid renders Markdown inside cells, has keyboard navigation, resizing, its own undo history, tab-separated copy and paste, a sum, average and count readout for the selection, and export to CSV and Excel. Cosmetic settings such as column widths live in the plugin's data rather than the note, and a table changed in the note while the grid is open raises a choice instead of a silent overwrite.
