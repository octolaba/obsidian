# BurgerAndreas/latex-delimiter-renderer

LaTeX Delimiter Renderer renders the standard LaTeX paren and bracket math delimiters, inline and display, alongside Obsidian's own dollar-sign syntax, in both Live Preview and Reading view. Rendering uses Obsidian's bundled MathJax, works offline, leaves inline code and fenced code blocks alone, and reveals the original delimiters while the cursor sits inside a formula; the Markdown source is never rewritten. There are no commands and no per-note settings, and multiline inline expressions stay unrendered because inline editor decorations cannot span lines.
