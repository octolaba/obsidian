# mofukuru/auto_file_organizer

Obsidian plugin that moves newly added files into designated folders according to their extension or their tags. Mappings are configured in two settings sections, extension to folder and tag to folder, with extensions written without a leading period and tags with a leading hash, and each mapping can be edited, deleted, or disabled while staying saved. A priority setting decides whether extension mappings or tag mappings take precedence. The README records that updating from 1.0.4 to 1.0.5 could clear the extension mapping list, and points at the plugin's data file inside the vault for recovering it.
