# mircomacrelli/cover-image

The repository holds Cover Image, an Obsidian plugin that places the image linked from a note's cover frontmatter property at the top of the note body. The README states that the image is limited to 256 pixels in width and height by default and that two CSS variables change those limits, while the container's margins and padding are adjusted through its own CSS class.
