# mr-asa/obsidian_weather

Renders a multi-city weather forecast in Obsidian, in a dedicated panel, in Markdown notes and in Canvas nodes. The README says the widget follows the vault's visual style and exposes its gradients, icons and sun overlays for tuning, and that cities declared inline in a code block merge with the global list without duplicates. Preset configurations ship in the repository's presets folder and are applied by copying one into the plugin settings as `data.json`. The README is written in English with a Russian translation.
