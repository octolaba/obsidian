# pathfind1103/groove-kb

Groove KB is an Obsidian plugin that builds a music knowledge base of linked notes for artists, albums, release editions and collections. The README records a fixed hierarchy from the home note through bundles, collections, artists, release groups and concrete releases, with note types music-library, collection, artist, release-group and release plus generated Bases views, and states that links and registry entries are updated together when items are imported, expanded, moved or deleted. Recorded actions include previewing an artist before import, importing metadata, genres, images, Wikipedia summaries and discography views, creating album stubs and expanding them into notes with cover art and tracklists, previewing editions such as CD, vinyl and digital, an artist timeline and an Uncollected inbox. Health checks, registry rebuilds and rate-limited metadata updates are also recorded.
