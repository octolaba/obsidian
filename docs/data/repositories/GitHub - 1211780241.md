# CitrusRenegade/review-simple-obsidian

Schedules notes for rereading, storing the last review date in each note's frontmatter rather than in an external database. A status bar indicator shows a note as reviewed on a date, due, or never reviewed, and a vault-wide counter reports how many notes are currently due; a note is marked reviewed by clicking the status bar or through the command palette, and a random due note can be opened the same way. Review intervals are set at three levels — a global default, per-folder rules, and per-note frontmatter overrides — and the scope of batch review is set by a folder filter that works either as an exclude list or as an include-only list, with both lists kept when switching between modes.
