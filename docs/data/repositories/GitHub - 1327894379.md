# StarlightV-org/obsidian-codetime

This plugin reports Obsidian writing activity to a CodeTime.dev account, sending an event when a file is opened, created, modified or edited in the editor, throttled to one per second for the same file and event type. Today's tracked time for the active project appears in the status bar, with the vault name used as the project unless an override is set, and filenames replaced by generated anonymous names by default. The API token is kept in an Obsidian secret rather than the plugin's settings data, the server URL can be pointed at another compatible server, and a filterable activity log covers connection and request diagnostics. It works on desktop and mobile, requires an active CodeTime.dev account, and describes itself as an independent integration rather than an official one.
