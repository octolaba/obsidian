# jxpeng98/obsidian-to-NotionNext

Obsidian to NotionNext sends Obsidian Markdown files to any Notion database through the Notion API and generates a Notion share link. It supports general Notion databases, the NotionNext blog template and fully custom database schemas, lets any frontmatter key be mapped to any Notion property in a custom database, allows the target database to be chosen at sync time, and uploads local images and PDFs referenced by either wikilinks or Markdown links as attachments. The README states that the plugin is a fork of an earlier obsidian-to-notion project, with added features and support for more flexible database configurations.
