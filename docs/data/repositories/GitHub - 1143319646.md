# FengChendian/obsidian-zotero-cite-pdf

This repository holds the Zotero Cite PDF plugin for Obsidian, which cites Zotero PDF, HTML and other attachments and opens them directly. The Zotero data directory is set in the settings first; a search button or the Search Zotero Literature command then takes keywords, lists matching items, and inserts the selected one into the note. Attachment links can afterwards be opened from Obsidian in a custom application.
