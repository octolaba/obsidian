# asgardehs/nott-dagr-obsidian

Nott and Dagr are paired dark and light Obsidian themes from the Asgard EHS ecosystem, named after the Norse night and her son day. Both share the same role architecture, so a keyword is the same kind of thing in either mode and only the surface-adapted color shifts. The README describes Nott as aurora over a night sky on a cool petrol-slate ground and Dagr as morning light on parchment with deepened, earthier counterparts of the same accent roles, and modes are switched through Obsidian's base color scheme setting.
