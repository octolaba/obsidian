# jirayu3141/handwriting-to-text

An Obsidian plugin that transcribes photographed handwritten pages into text using Google Gemini and inserts the result at the cursor in the active note. The README records images taken from a file, the device camera on mobile, the clipboard, the vault, or a drag and drop on desktop, an editable preview before insertion, automatic conversion of HEIC photographs for desktop preview, and operation on iOS and Android as well as desktop. Settings record a Google Gemini API key, a choice of Gemini model, and a customisable OCR prompt that the README suggests adapting to a handwriting style or language. The README states that images are sent to the Gemini API, that the key is stored locally in the vault's plugin data folder, and that no telemetry is collected.
