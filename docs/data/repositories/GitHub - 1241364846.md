# smirnoffmg/obsidian-timeflow

Timeflow Periodic presents daily, weekly and monthly periodic notes as one continuous vertical feed, newest first, so a journal can be browsed by scrolling instead of opening files one by one. Existing notes appear as cards with a title and a plain-text excerpt, weekly and monthly notes become full cards at period boundaries when those are enabled, and dividers mark weeks and months when period notes are off. Days without a note show a placeholder carrying a button that creates one, older days load automatically as you scroll, vault changes refresh the feed, and a command jumps back to today. The README records Obsidian 1.5.0 or newer and a configured daily or periodic notes setup as requirements, names Dataview as optional for table query summaries on cards, and states that the plugin runs offline without analytics.
