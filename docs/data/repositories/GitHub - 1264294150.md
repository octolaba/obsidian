# jagajaga/obsidian-folder-reader

Folder Reader renders all notes directly inside a folder as one continuous scrolling page in a single tab, reached from the folder's right-click menu or a command that opens the current note's folder. Notes appear in numeric-aware name order, each under its title as a header, and remain interactive: a title opens the original note, and wikilinks, embeds, images and tags render normally. Only Markdown files directly in the folder are included, subfolders are not recursed, frontmatter is hidden and the view is restored after a restart. The README states the notes are rendered with Obsidian's own MarkdownRenderer in batches of 15 behind an IntersectionObserver, with no network access and nothing written.
