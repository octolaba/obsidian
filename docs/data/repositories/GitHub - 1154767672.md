# BuckleyResearchLtd/ObsidianGithubPublisher

Publishes the active note and its embedded images to a GitHub repository over the GitHub API, batching every file into one commit. A note is eligible when its frontmatter sets a publish flag to true and names a content type, which selects the subdirectory under the configured content directory, or the note is written flat when that option is off. Wikilinks are rewritten as ordinary Markdown links or plain paths, images are uploaded to an assets directory with spaces in filenames replaced by hyphens, and unpublishing removes the note plus any image no longer referenced by another published note. Configuration covers repository owner and name, branch, a personal access token with write access, and the content and asset paths.
