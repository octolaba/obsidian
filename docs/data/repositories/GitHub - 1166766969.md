# kntanaka/chronostra

This repository holds Chronostra, a life-goal planning table that lives inside an Obsidian vault; the README gives the name as a compound of Chronos and stratum. Goals are captured quickly and then held inside a category map covering health, family, work, learning, money, travel or whatever categories the user defines, so that no single area silently expands at the cost of the others. A timeline turns that map into milestones placed year by year, so the shape of a plan can be compared against stated priorities. The repository carries no description, and the README presents the plugin through a narrative and a set of example users rather than a feature list.
