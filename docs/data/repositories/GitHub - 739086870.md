# bandantonio/obsidian-apple-books-highlights-plugin

Obsidian plugin that imports Apple Books highlights and notes into the vault. The feature its README puts first is a section that preserves the reader's own thoughts and reflections so that repeated imports do not overwrite them, alongside a user-editable template and selective import or overwrite of a single book. Both the repository description and the README are promotional in register, advertising a seventy-times speed advantage over alternatives, monthly and yearly time savings, complete code coverage and user testimonials; those are recorded here as claims made by the project and were not checked.
