# hipstersmoothie/obsidian-plugin-prettier

The repository holds an Obsidian plugin that formats notes with Prettier. Its README records two commands, one formatting the whole note and one formatting only the selection, both unbound by default, and two settings, format on save and format code blocks, both off by default. A note can opt in individually through a plugin-prettier key in its front matter, and the README covers installation from Obsidian or by unzipping a release into the vault's plugin folder.
