# kazhuravlev/obsidian-github

This repository holds GitHub Integration, described upstream as a plugin that fetches a user's GitHub stars into notes. The README says starred repositories are imported as notes carrying repository metadata in frontmatter, including description, address, owner, language, star count and dates, with automatic tags derived from language and topics, and that later runs fetch only new stars. Settings take the GitHub username, an optional personal access token for a higher rate limit, and a target directory. The README warns that a token kept in the Obsidian configuration is exposed if the vault or its config files are shared.
