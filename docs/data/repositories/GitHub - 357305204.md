# amdecker/obsidian-argdown-plugin

This plugin renders Argdown argument maps written in argdown or argdown-map code blocks, showing them in the preview pane and updating as the block is edited. The README records that version 2.0 bundles the Argdown processor, so no extra program has to be installed, and that the settings page chooses whether source or map is the default view. Syntax highlighting and several Argdown blocks in one file are listed as supported.
