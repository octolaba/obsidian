# DepartingAgain/obsidian-newledge

Newledge, also called Xinzhi, is an Obsidian plugin that imports notes, links, highlights and annotations from the Newledge service into a vault as Markdown files, written into a configurable folder. An account is linked once by scanning a QR code shown in the plugin settings with the Newledge app, after which data can be synced immediately or on a schedule. Imported files carry a daily-note link, so with Obsidian's Daily notes core plugin the synced content is reachable from a day's backlinks. The README records that a Newledge account is required, lists the calls the plugin makes to the xinzhi.zone cloud service, states that settings and the returned token are stored through Obsidian's plugin data API, and states that the plugin carries no client-side analytics, advertising or self-update mechanism.
