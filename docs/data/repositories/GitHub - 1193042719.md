# Resolve-public/writing-assistant-chat

An AI writing assistant that puts chat and editing on one surface and connects to local or cloud model providers: LM Studio over a local OpenAI-compatible API, Anthropic, OpenAI or any compatible endpoint, and Claude Code through the local command-line tool with its existing login. Vault-wide retrieval, a knowledge graph, note context and reusable prompt commands feed the conversation, and providers and model profiles are switched from the chat panel. With agentic tool use enabled, every operation that changes the vault passes through an approval gateway whose per-kind policy defaults to asking for review and can be set to auto-apply or to deny, which removes that tool entirely. The README states the plugin is desktop only.
