# NameIsKyro/linkr

A keyboard-driven builder for internal links: pickers choose a file, then a heading or block inside it, and an optional display text, with a live preview before anything is inserted. Six link types can be enabled or disabled individually, each also available as its own command, and a toggle on the final screen turns any of them into an embed. Text already selected in the editor is prefilled as the display text, up to ten recently used files are offered first, a missing note can be created from the picker, and the file explorer context menu can copy file and heading links. Version 2.0.3 requires Obsidian 1.13.0 or later; the plugin makes no network requests and collects no telemetry.
