# omarrashad/obsidian-vesper

Vesper is a minimal Obsidian theme based on the Vesper theme for VS Code, shipping both dark and light modes. The README records that it began as the author's personal theme before being published, and that it was developed and tested on macOS without community plugins, so its appearance may break with some of them. Screenshots use a JetBrains Mono Nerd Font that has to be set in the appearance settings to match, and installation is documented through the community theme browser.
