# Developer-Mike/obsidian-docxer

Repository for Docxer, an Obsidian plugin that previews Word files inside the app and converts them to Markdown. A `.docx` file added to the vault is opened in Obsidian, and a Convert button in the top right corner of the editor produces the Markdown version. The README names the implementation chain: docx-preview renders the preview, mammoth converts the document to HTML, and turndown converts that HTML to Markdown.
