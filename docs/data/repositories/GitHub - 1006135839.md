# the-c0d3r/obsidian-linked-note-exporter

Obsidian plugin that exports a note together with its attachments and linked notes, so a shared Markdown file does not arrive with broken images, PDFs or note links. A configurable link depth decides whether only the note itself, its directly linked notes, or notes reached through those notes are collected, and the result can be written as a folder or as a single ZIP archive. It follows both wikilinks and standard Markdown links, and can keep the original vault folder structure or regroup the collected files by the document's headers.
