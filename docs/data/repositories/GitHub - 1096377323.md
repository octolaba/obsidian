# tailormade-eu/obsidian-task-export-plugin

This Obsidian plugin collects outstanding tasks from the vault and writes them to a CSV file intended for ManicTime. It watches a configurable customers folder rather than the whole vault, exporting on demand from the command palette or a ribbon icon and automatically when watched files change, with debounced updates, a status bar showing the last export time and notifications on success or failure. The README describes it as a TypeScript port of the author's markdown-task-export console application, adapted for Obsidian, and records at the time of writing that it is not yet published to the community plugin store.
