# akosbalasko/zoottelkeeper-obsidian-plugin

This repository holds Zoottelkeeper, an Obsidian plugin that generates and maintains a folder-level index file for each folder of a vault, following the Linking Your Thinking idea of giving folders structure. Only the marked autogenerated link list inside an index file is rewritten, so the rest of that note's content, including its section rules, survives an update. Folders are included or excluded by absolute path, with a trailing asterisk covering subdirectories recursively, and index files support a template, configurable link sorting, optional tags and per-row emojis, a configurable frontmatter separator, embedded child indexes in preview, and a manual generate-now trigger.
