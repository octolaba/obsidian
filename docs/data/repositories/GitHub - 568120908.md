# nevernotmove/obsidian-chordlyrics

Displays chords above lyrics in Obsidian. The README describes writing a chordlyrics block with the chord line placed above its lyric line, and lists chord highlighting, automatic detection of most chord and lyric lines, section headers written in square brackets, and customizable colors. Where the automatic detection fails, a line can be marked explicitly as chords or as text with a trailing marker, and the README states that chords and lyrics wrap together on smaller screens while keeping their alignment.
