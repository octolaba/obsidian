# kzhovn/obsidian-customizable-menu

This plugin adds any Obsidian command, including commands supplied by community plugins, to the right-click context menu and assigns icons to them from Obsidian's internal and Lucide icon sets. Adding commands works only on the note menu in Source and Live Preview mode, not in Preview mode or the sidebars, while hiding a command by its name removes every instance of that name from all context menus rather than a single one; listed commands can be styled instead of removed through a dedicated CSS class. The README states that the plugin is semi-abandoned, that issues may go unanswered, and that Obsidian Commander offers the same functionality.
