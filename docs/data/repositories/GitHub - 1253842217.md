# samyelkina/Simple-home-Obsidian-Plugin

Repository for Simple Home Page, a plugin that adds a home view for navigating a vault. Its README records searching note and folder names rather than file contents, tabs for recent, pinned and deleted notes, a local trash with restore and permanent delete, recent folders and a simplified vault tree, reopening the last closed note or several recently closed ones in new tabs, creating temporary notes, and styling that follows the appearance settings.
