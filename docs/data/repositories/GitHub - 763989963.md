# kon-foo/Obsidian-Translate-Inline

This plugin translates words or whole sentences written inline in a note: bracketed text prefixed with a chevron is replaced by its translation as soon as the cursor leaves the brackets. A target language, and optionally a source language, can be given inline before the text, otherwise the configured defaults and automatic detection apply. It requires an API key from DeepL or Google Cloud Translation, and the README states that translated text is sent to the chosen provider under that provider's privacy policy, that the plugin itself collects no data, and that the API key is stored in the vault in plain text. The author describes the project as being at an early works-for-me stage.
