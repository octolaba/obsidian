# Dr3pi/obsidian-manuscript-export

Manuscript Export turns a book manuscript written in Obsidian into an EPUB, including a one-command export of Longform projects that uses the Longform scene order and the project's title. Without Longform, a plain folder of chapter notes is exported in natural-sort filename order, and a single-file Longform project is split into chapters on top-level headings. The README records that wikilinks render as plain text, image embeds are placed into the EPUB, scene-break rules render as a centered divider, YAML frontmatter is stripped so metadata does not leak into the book, and callouts are removed.
