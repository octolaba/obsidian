# vrtmrz/diffzip

Repository for Differential ZIP Backup, an Obsidian plugin that stores modified vault files in ZIP archives. A create-differential-backup command compares the vault against a `backupinfo.md` record and writes a dated ZIP holding new files, files whose content digest changed, and records for files that the backup history knows but that are now missing locally; the backup and restore folders are skipped and no ZIP is produced when nothing changed. The README documents splitting output into numbered pieces by batch or configured maximum size, optional encryption that requires OpenSSL before ordinary ZIP tools can read a file, a best-effort screen wake lock held during long operations, and legacy commands for older backup variants.
