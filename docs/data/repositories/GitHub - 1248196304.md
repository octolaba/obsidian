# jepicaju862-lab/Side-Comments-origin

Side-Comments-origin attaches standalone comments to highlighted text in Obsidian notes and manages them from a sidebar. The README describes a floating toolbar appearing after a selection for adding a comment or changing the highlight colour, a hover tooltip previewing the comment with Markdown, links and images rendered, and a dedicated view listing every comment in the document with sorting by timestamp or position, a global search, editing, deletion and one-click jumps to the annotated text. Comments render Markdown and accept pasted or dragged images, which are stored in a configurable attachments folder, and all comments can be exported or backed up as a Markdown file. Comments whose original text has been removed are detected, shown with a red dashed highlight and cleared in one step from settings.
