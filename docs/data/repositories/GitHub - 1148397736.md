# nazdridoy/obsidian-cbt-exam

This repository holds CBT Exam Simulator, an Obsidian plugin that renders timed, interactive exams from notes written in a human-readable syntax. The exam runs as a workspace tab with a timer and a question navigator and supports multiple choice, select-all, true or false, fill in the blank, matching, and short and long answers, with Markdown and LaTeX allowed in questions and options. Time limits and shuffling of questions and options are configured in the note's YAML frontmatter, questions can be flagged for review, and a results dashboard reports accuracy, score and time taken. Past attempts are recorded in a sidecar history note beside the exam, and an adaptive study mode targets identified weak points.
