# Kuioma/obsidian_image_renamer

Obsidian Image Renamer intercepts image pastes and saves the file under a templated name before Obsidian inserts the link, so the README states that the original filename never appears in the note. Images dragged in from the file manager are renamed the same way, and templates are built from variables for date, time, datetime, an auto-incrementing counter, the original filename, the active note's name and any frontmatter key, with the original filename as the default template. The counter is stored per note in an `image-counter` frontmatter key and decrements when an image is deleted, and an `image-folder` key sets a per-note destination folder. Commands organise the images of the current note or of the whole vault and find unreferenced images, and the interface is available in English and Chinese.
