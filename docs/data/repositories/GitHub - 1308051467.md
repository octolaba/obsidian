# Fleker/publish-on-github-for-obsidian

This plugin publishes selected Obsidian notes to a GitHub Pages site built with Jekyll. The README states that it copies only notes carrying a chosen tag such as a public tag in the body or frontmatter, converts wikilinks and embedded images into relative Markdown links and image paths while preserving folder structure, renders frontmatter values as HTML property badges under the title, and reports links from public pages to untagged private files as a non-blocking notice. Git commits and pushes are run automatically, with commit messages built from a porcelain diff of additions, modifications and deletions, and the README records Windows and WSL git handling with path translation as well as an included Jekyll template; it describes the plugin as premium.
