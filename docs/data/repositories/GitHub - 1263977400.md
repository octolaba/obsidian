# perinchiang/obsidian-plugins-attachment-imagebed-manager

An Obsidian plugin that uploads a note's local attachments — images, PDFs, audio, video and further file types — to S3-compatible storage such as Cloudflare R2, AWS S3 or MinIO, rewrites the links in the note to the remote URLs, and can delete the local files afterwards. Attachments are browsed by category in list or gallery views, custom extensions can be added, note writes are atomic with concurrent-edit detection and automatic rollback of failed uploads, and transient failures are retried with exponential backoff. Delete policies, periodic vault-wide scanning with quiet-period and size filters, and a dry-run preview are documented, with some options desktop-only; links inside code blocks are treated separately, mobile supports manual upload, and the interface is bilingual in English and Chinese.
