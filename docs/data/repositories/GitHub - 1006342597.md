# ServerKarma/ObsidianPrivateAI

Private AI Chat is an Obsidian plugin for chatting with vault notes through a local LLM, and its README states that notes stay on the device, that no data is transmitted to external services, and that there is no analytics or tracking. It is described as compatible with LM Studio and with locally run models such as gpt-oss, Qwen3, Gemma4, DeepSeek and Mistral. The recorded features are vault search that supplies context and cites specific notes, an open-tab context mode for focusing a conversation on chosen notes, and settings for models, search parameters and token limits.
