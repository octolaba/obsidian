# Miro0o/miniWorldMap

Mini World Map explores a vault in two complementary render modes: a 2D radial atlas whose concentric rings place parent folders and topics at the centre and child folders and notes further out, and a 3D force graph showing the vault as a spatial link network with camera flight, glow, search and visual presets. The atlas is the hierarchy-first view, any folder can become the root node at the centre, and links appear as roads between topics; the README frames this as combining what Obsidian's Graph View and conventional mind maps each show separately. It records the project as built on Longwind1984/galaxy-view, adding plugin packaging, TypeScript sources, local vault indexing, the radial atlas, bilingual controls and quality tiers.
