# johannes-kaindl/koda-agent

A chat sidebar that works on the vault through a fixed set of tools: searching notes, reading them, writing new ones, listing a folder's notes with selected frontmatter fields, and recording dated lines into a plain Markdown memory note that is fed back into later questions. Answers stream from an OpenAI-compatible endpoint configured by the user, local or hosted, and the model must support tool calling, with a text-based fallback for those that do not. Each tool call appears inline in the chat, a Stop button leaves the partial answer in place, and chat history is logged inside the plugin folder and restored on restart. If a separate retrieval plugin has indexed the vault, semantic matches are added as an extra tool and kept in labelled blocks separate from literal hits; Obsidian 1.8.7 or newer is required, on desktop and mobile.
