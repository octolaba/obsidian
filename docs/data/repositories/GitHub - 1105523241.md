# atacansuder/obsidian-japanese-dictionary

Japanese Popup Dictionary is an offline popup dictionary for Japanese learners working inside Obsidian. Lookups run locally against IndexedDB, dictionaries in the Yomitan or Yomichan format such as JMdict and Jitendex are imported from a zip file placed in the plugin's data folder, and conjugated verbs and adjectives are deinflected before lookup. A definition popup appears when the mouse hovers over a word while a configurable trigger key is held, with Shift, Ctrl, Alt or no key available. The README warns that the plugin depends on Node.js and Electron APIs for large dictionary imports and will not work on Obsidian mobile.
