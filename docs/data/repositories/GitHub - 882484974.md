# vellikhor/mass-create

Mass Create creates large quantities of notes at one time in an Obsidian vault. The README describes right-clicking the folder that should hold the new files, optionally adding further folders as part of the same operation, entering the names of the files to create, and optionally choosing an existing file as a template so its structure and content are replicated. Installation is documented manually into the vault's plugins folder and, when available, from the community plugin browser.
