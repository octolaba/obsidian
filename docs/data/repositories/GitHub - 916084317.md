# alberto98fx/idle-monitor-obsidian

Tracks typing and, optionally, mouse movement, and reports how long the user has been idle in the Obsidian status bar. Hovering the status bar item shows the exact time activity stopped, formatted in 12-hour or 24-hour form according to the setting. Settings cover the idle time threshold, how often the check runs, whether mouse movement counts as activity, the color of the status text, and a glowing rainbow gradient effect for it.
