# Intelskya/obsidian-redact

Adds a configurable command that replaces the selected text with a redaction character, defaulting to a solid block, and ignores control characters such as tabs and newlines. Spaces inside the selection can be kept, redacted, or deleted, and symbols can be kept, redacted, or deleted, with deletion the default for symbols and keeping the default for spaces. The command is run from the palette or a keybinding set in the plugin settings, and the author states it was made primarily for personal use with no promise of consistent updates.
