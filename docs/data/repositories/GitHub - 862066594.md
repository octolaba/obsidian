# juanchiparra/obsidian-borealis

juanchiparra/obsidian-borealis holds Borealis, a minimalist theme the README describes as built on two main colours and inspired by the aurora borealis. It records dark and light modes, styling for checkboxes, buttons, callouts, lists, tables, blockquotes, properties and canvas, seven syntax highlighting options, and its own Dataview styles, with the Style Settings plugin exposing colours, backgrounds, fonts, syntax highlighting, checkboxes and tables. The author marks the theme as building in public and states that what is published is a first version far from the intended result, and the repository ships a sample vault for trying it.
