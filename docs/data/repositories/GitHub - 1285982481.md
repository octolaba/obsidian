# pragatinath/obsidianplugin-daily-notes-compiler

Repository for Daily Notes Compiler, an Obsidian desktop plugin that assembles daily notes or journals from a chosen date range into one compiled note. The README lists a start and end date selection, options for compiling the last week or last months of notes, and settings for both the daily notes folder and the destination folder. Manual installation is described as copying `main.js`, `styles.css` and `manifest.json` into the vault's plugin folder.
