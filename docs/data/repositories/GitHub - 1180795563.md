# alokinkal/AK-Sky-Breeze

AK Sky Breeze is an Obsidian theme its author wrote for personal use and then published, aimed at documents that stay readable over long sessions and are easy to skim. It softens borders, simplifies colours and leaves generous spacing, and its headings are large and widely spaced with the emphasis on H1 through H3. Background warmth is adjustable through the Style Settings plugin, and the theme follows the accent hue and font size configured in Obsidian. At the time the README was written the theme was not yet available in the app, so it documents manual installation into the vault themes folder as the only route.
