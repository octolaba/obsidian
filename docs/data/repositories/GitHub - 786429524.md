# masaki39/simple-citations

Simple Citations imports literature notes from Zotero into Obsidian from a bibliography file exported by Better BibTeX, so items are added in Zotero and the notes follow. An Add literature note command creates and updates the notes in one go, with options to do so automatically when the bibliography file changes or when a note is opened, and the README shows a Dataview query listing the resulting notes by author, journal, year and title with links back to Zotero and to the DOI. A second command runs Pandoc with citeproc to export a note that cites those literature notes as a docx file, taking the citation style from a CSL file whose path or URL is set in a note property. The README states that Better BibTeX for Zotero and Pandoc must be installed, and that the export should be set to a location inside the vault as Better CSL JSON or BetterBibTeX JSON.
