# cannibalox/ono-sendai_obsdn

Ono-Sendai_obsdn is an anti-distraction-free Obsidian theme with a terminal retro look, designed for dark mode though a light mode is also available. The README opens with a warning that the theme is currently unmaintained and will not work properly in newer Obsidian versions, and adds that its interface is user-unfriendly and not recommended for Obsidian beginners. Listed features include inline transclusions, tab icons replaced by text, bigger popover previews, images scaled down with hover zoom, visible margins in edit mode, a file explorer in columns view with wrapped long file names, and aligned footnote superscripts, with line-level edits documented for full dark mode and for disabling the experimental columns view.
