# w8s/obsidian-tarot-practice

Tarot Practice draws tarot and other divination cards inside Obsidian, seeding the randomness with the words of the reader's stated intention and the exact moment of the draw. It supports several divination systems in one plugin, among them tarot, runes, Lenormand, I Ching, playing cards and custom decks, with card images stored in the vault, five built-in spreads plus custom ones, and daily or inline draws of one or more cards. A physical draw mode records cards taken from a real deck through the same spread and template machinery, and draw history is kept with statistics. The recorded inputs also list Handlebars templates for rendering a reading and full mobile support.
