# cygnusyang/obsidian-enhanced-pdf-export

Obsidian plugin that exports the active Markdown file to PDF by first rendering it through the app preview renderer and then printing that rendered result with Electron. It is aimed at notes carrying Mermaid diagrams, inline HTML, SVG, tables, callouts and images, and it waits for fonts, images, SVG and Mermaid to settle before printing. Options include a cover page and a table of contents, and the export is reachable from a ribbon action, the command palette and the file context menu.
