# Mr-1311/obsidian-age-encrypt

This plugin encrypts Obsidian notes using age. Commands encrypt the selected text or the whole file, and the result is stored in a code block whose language is age, so it can also be decrypted outside Obsidian with the age CLI tool; a hint may be attached to encrypted content. Decrypted content is held only in memory and is never written to disk automatically. The README warns that encryption is symmetric — losing the passphrase loses the data permanently — that a vault sync may carry secrets away before they are decrypted, and that the plugin comes with no warranty.
