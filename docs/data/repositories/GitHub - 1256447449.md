# kashicards/unread-plus

Unread+ tracks unread files in Obsidian with colored dots in the file explorer and per-status counts on every parent folder, propagating up the tree so a collapsed vault still shows where unread files sit. Statuses are customizable in name, color and icon, with unread and later provided by default, a status bar item shows the total, and dots fade slightly each day so older material looks the part. Files can be snoozed for one day, three days or a week and return automatically, with all snoozed files listed in the settings with their remaining time. The README also describes detection of files created while Obsidian was closed with a configurable grace period, commands and a shortcut that step forward and back through unread files while showing progress, a colored context menu, and an unread-overview code block that embeds a filterable live list in any note.
