# philpalmieri/obsidian-link-forge

Obsidian plugin that creates the target note of an unresolved wikilink automatically, as soon as the cursor leaves the line carrying it. Detection runs on line change through a CodeMirror update listener rather than on every keystroke, missing parent folders are created along with the file, and the link is then shortened to its basename when that resolves uniquely, preserving any heading and alias part. Auto-creation can be restricted to configured watched folders, empty by default meaning all folders, and the README states the plugin works with Templater's trigger on file creation for automatic folder templates.
