# yy4382/obsidian-image-upload

Uploads the local images used in the currently open note to S3 or an S3-compatible service, replaces the links with the uploaded addresses, and can then remove the image files from the vault when they are used exclusively within that note. Instead of S3, an upload function can be supplied as a class through the Custom JS plugin, receiving the file's binary contents and metadata and returning the resulting URL. Uploading is triggered manually from a ribbon button or the command palette rather than on pasting; the README names the optional local deletion and the custom uploader as the differences from similar plugins.
