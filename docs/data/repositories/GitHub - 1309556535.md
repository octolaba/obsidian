# ivana331100/VPS-R2-Obsidian-sync

Hermes R2 Vault synchronizes a vault to Cloudflare R2 with client-side encryption: notes are encrypted with XChaCha20-Poly1305 and Argon2id before leaving Obsidian, and the Hermes control API that brokers the transfer never receives plaintext. Sync is bidirectional with last-writer-wins conflict resolution, manifests are kept in content-addressable storage, and a Conflict Center handles the cases the resolver cannot decide. Recorded capabilities include file revision history, single-file and point-in-time vault restore, an integrity scanner, a retention planner, safe garbage collection, mass deletion protection and an audit log. Multiple devices enrol through a setup URI, and the interface is localized in Russian and English.
