# studiowebux/obsidian-spotify-link

The Spotify Link plugin inserts the song or podcast episode currently playing on a connected Spotify account at the cursor position, through the official Spotify API, and can fetch the tracks played since the beginning of the current day. A custom template controls how the entry is written into the note. The README records two known issues: Obsidian's Web viewer core plugin breaks the Spotify login when the consent page opens inside Obsidian, which the plugin works around by opening the system browser with a copy-link and paste-redirect fallback, and Spotify's February 2026 restriction on development-mode apps, which requires the created app to be owned by an account holding an active Premium subscription and leaves some template variables no longer returned.
