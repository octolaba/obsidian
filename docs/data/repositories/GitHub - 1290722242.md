# s945134636-spec/auto-ledger

Auto Ledger turns Markdown transaction logs kept in the vault into an offline finance dashboard inside Obsidian. A transaction is a single Markdown line carrying Dataview-style inline fields such as date, direction, amount, currency, account, category, member and confidence, and the dashboard reviews monthly income and expenses, recent records, category rankings, member distribution and records below a configurable confidence threshold. The README states the plugin reads only Markdown inside the vault, makes no network connection, uploads nothing and includes no telemetry.
