# brianstm/obsidian-vault-llm-assistant

Vault LLM Assistant queries the content of an Obsidian vault with a language model and returns answers carrying citations and links back to the original notes. A dropdown switches between a query mode and a create mode that writes a note on a topic, with vault content optionally included in the prompt, and results can be copied as text or Markdown or turned into a new note with a generated title. The README lists OpenAI GPT, Google Gemini and Anthropic Claude models as supported, along with local models served by LM Studio or Ollama, and states that the files and folders included in or excluded from scanning are configurable.
