# heseber/perplexity-converter

Perplexity Converter fixes the sources and their links in text pasted from Perplexity into a note. Perplexity writes citations as numbers in square brackets, which Obsidian reads as external links with no URL attached, so clicking one does nothing and consecutive markers show only the first number; the reference list at the end starts with a line reading Citations, Sources or Quellen and carries the same problem. The plugin runs on the selection and replaces it with the fixed text, which the README explains is deliberate, so that an answer already fixed earlier in the same note is not processed a second time. On iOS and iPadOS a setting selects the whole note automatically when nothing is selected.
