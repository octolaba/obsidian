# cwagner223355/obsidian-foldable-frontmatter-groups

The repository holds Foldable Frontmatter Groups, an Obsidian plugin that adds collapsible group headers to the native Properties panel. Its README states that the panel otherwise renders every frontmatter key as a flat unordered list, and that groups match by an ordered list of literal names and prefix wildcards, or by a regex, with the first match winning in settings order. It also records pinning chosen keys above the groups in a fixed order, per-field Lucide icons, folder-scoped field templates, cleanup tooling for stale or empty fields, and an opt-in YAML reconcile when a file is left.
