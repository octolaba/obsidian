# svew/obsidian-pdf-image-extractor

This plugin extracts the images embedded in the PDF currently open in Obsidian and saves each one into the vault. Its README describes a single command that walks every page of the open PDF and writes the images it finds to the configured attachments folder. By default the saved files are PNG named from the PDF name, the page number and an index, placed in the attachments folder the vault settings specify, and both can be changed in the plugin settings.
