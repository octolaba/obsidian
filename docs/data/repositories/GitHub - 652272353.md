# joshrouwhorst/style-importer

Style Importer loads a CSS file from a URL into the vault's snippets folder, which its README presents as a way to keep one set of styles across several notebooks. The address is set in the plugin's settings, after which the snippet has to be located under the Appearance settings and toggled on, refreshing the snippet list first if it does not appear. The README records that the plugin makes requests only to the addresses it is given, saves the result under a single fixed filename inside the snippets folder, and performs no other file manipulation; it suggests the raw address of a GitHub gist as somewhere to host the stylesheet.
