# Arghyahub/postgres-db

Postgres DB runs PostgreSQL queries from inside notes: fenced SQL blocks get syntax highlighting, a run button, a copy button and a connection picker, and results open in a dedicated side panel whose cells expand into a popup. Several connections can be saved with host, port, database, credentials, SSL mode and timeout, filled in from a pasted connection string and verified before saving, and results can be exported to a timestamped CSV file. Autocomplete suggests tables, columns and SQL keywords from the active database schema. The README records Obsidian 1.7.2 as the minimum version and states that the plugin is desktop-only because it uses the Node client and Electron APIs.
