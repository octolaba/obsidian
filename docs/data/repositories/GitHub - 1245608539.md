# GS-AX/confluence-weaver

Obsidian plugin that syncs Confluence pages into a vault as Markdown, working with Confluence Cloud through basic auth and with Data Center or Server through a bearer token. The README describes query profiles that each target a different vault folder, importing a page by pasting its URL with optional collection of child pages, incremental sync that writes only pages whose version has changed, and conversion of headings, tables, code blocks, task lists and info panels from the storage format. It also lists image download into a per-page attachments folder, a fixed set of frontmatter fields, preservation of user content written below a section marker, optional wiki-link conversion, mirrored folder hierarchy and custom field mappings.
