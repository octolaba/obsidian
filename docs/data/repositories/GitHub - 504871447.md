# mcndt/obsidian-quickshare

The repository holds Obsidian QuickShare, a plugin that publishes a note to the web behind end-to-end encryption, requiring no account and no configuration. Its README records AES-256-CBC encryption with the decryption key never sent to the server, so the server itself cannot read a shared note, and states that by default notes go to the author's companion service, which caches them for thirty-one days and hosts the viewer. Both that service and its front end are recorded as open source, and the author explains the plugin as something built for personal use and then released.
