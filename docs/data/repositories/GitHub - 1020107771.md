# joshavanier/prologue

Prologue is an Obsidian plugin that shows a random note, quote, or reminder each time a new tab is opened. Its items come from a collection file — a sample collection.md is created in the vault — where entries are separated by one or more blank lines, and the file can be changed in the plugin settings. The README records that the plugin was not yet on the community list and describes manual installation from a release archive.
