# zachmueller/notor

Notor adds an AI chat panel that can read, search, create and edit notes, with a recorded set of 32 tools covering frontmatter and tags, backlinks and outlinks, templates, the web viewer, web search, shell commands and filesystem access. Write operations require approval by default, every action is shown inline, and automatic checkpoints allow a change to be rolled back. Local OpenAI-compatible endpoints are supported alongside hosted providers, and messages can carry vault notes with section references, external files, images and PDFs, with automatic summarization when a conversation approaches the model's context limit.
