# ipshing/obsidian-text-transform

This repository holds Text Transform, an Obsidian plugin that converts selected text between letter cases and performs other manipulations such as adding lines above or below it. The README lists lowercase, uppercase, title case, camel case, Pascal case, snake case and kebab case among the supported cases, each applied through one of the plugin's commands in the command palette. For conversion to title case it records overrides that ignore user-defined words and that set word boundary characters other than the space.
