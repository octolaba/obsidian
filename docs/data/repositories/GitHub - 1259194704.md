# lyxdream/obsidian-wechat-capture

Collects a WeChat Official Account article into the vault as a Markdown note, taking its title, author, body text and images; the README is written in Chinese. Extraction starts from a ribbon icon or the command palette and takes a pasted article link, while the settings choose the folder for the resulting notes and the root folder for image attachments. The README records three limits: WeChat may answer with a verification page, so the link has to be opened in a browser first; watermarks already burnt into images on the WeChat CDN cannot be removed; and only the Obsidian desktop app is supported.
