# ValleytheKnight/Canvas-Text-Scaler

Scales the text inside an Obsidian Canvas card to the size of the card itself as it is resized, instead of scaling only with the canvas zoom level. The README records two earlier attempts to do this in CSS from the author's own theme and why both failed: container-type size broke Canvas virtualization, leaving cards showing raw placeholder text instead of their embedded content because it implies size, layout and style containment, and container-type inline-size rendered correctly but still did not scale the text. The README also mentions a toggle described as a safety net for cases where the plugin conflicts with a theme's own font-size rules.
