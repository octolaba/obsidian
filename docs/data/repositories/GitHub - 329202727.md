# blacksmithgu/obsidian-dataview

The repository holds the Dataview plugin, a data index and query language over the Markdown files of an Obsidian vault. It provides a pipeline-based query language and a JavaScript API for filtering, sorting and extracting data from pages, and it is written in TypeScript under the MIT license.
