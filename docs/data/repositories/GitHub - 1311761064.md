# sakurastral/obsidian-property-panels

Property Panels renders frontmatter properties as editable panels placed inside the note's own scrollable content, before or after the Properties block, the note body or Linked mentions. Fields cover text, number, toggle, select, multi-select, date, progress, rating and link values alongside readonly values and dividers, laid out in responsive grids with per-field column spans and four label positions; select options can come from static lists, another note's frontmatter, a Markdown list or the notes in a folder. Folder, tag and wikilink rules decide which panel applies, Style Settings controls the appearance, and configuration is exported, validated and restored through a JSON editor. The plugin is documented as having been generated entirely by AI without a complete line-by-line human review, and requires Obsidian 1.13.0 or newer.
