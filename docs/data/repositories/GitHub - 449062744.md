# ebullient/obsidian-snippetor

Snippetor assists in creating CSS snippets for Obsidian from a settings dialog rather than from hand-written CSS. At the time of the README it produces snippets for custom task checkboxes, with more kinds listed as still to come. It names two complementary plugins, one for viewing and toggling snippets from the status bar and one for marking tasks with a few keystrokes.
