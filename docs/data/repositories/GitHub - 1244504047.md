# elijahchan2019/theme-folio

elijahchan2019/theme-folio holds Folio, an editorial Obsidian theme in warm paper tones for long documents, offered in light and dark modes for desktop and mobile with no plugin required. Its palette assigns four roles: ivory for the reading and writing surface, slate for text and headings, clay for links, focus and active states, and charcoal for the dark surface, which follows the same hierarchy rather than reversing the light palette. The README records a 17px reading size, a compact heading scale, blockquotes marked by a quotation mark and indentation instead of a vertical border, and a shared sans-serif family chosen to keep mixed Latin and CJK text steady.
