# cannibalox/Obsdn-dark-rmx

Obsdn-dark-rmx is a theme for Obsidian.md with a light and a dark version. Its README lists work on transclusions, which display fully without scrollbars while still marked by a thin quote line, with the transclusion icon moved to the top left and smaller titles acting as links to the reference document, and on popover previews, which show more content without the bottom gradient. The interface is flattened with rounded corners removed, tabs and icons aligned, the active pane icon colored with the accent color, faster animations, margins shown in edit view, indentation lines, a dark status bar and an experimental columns mode for the file explorer. Tags are styled as pills with special colors for important, in-progress and complete, and the default fonts are Barlow and Fira Code, which must be installed on the system.
