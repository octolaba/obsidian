# debanjandhar12/Obsidian-Anki-Sync

This plugin creates flashcards in Obsidian notes and syncs them to Anki, using its own markup-based syntax rather than forking the earlier Obsidian_to_Anki project that inspired it. Syncing creates, updates and deletes anki-sync-blocks, backs up Anki decks before every run, and adds cards to a deck specified per file or per block, with template folders ignored. Cards render markdown math, code, images and tables, and cloze deletions can be written with highlights, Anki's own cloze syntax, or replacement blocks inside LaTeX math and code blocks.
