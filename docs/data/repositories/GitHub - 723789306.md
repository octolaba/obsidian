# iRewiewer/obsidian-random-numbers-generator-plugin

This plugin adds a command that generates a random number, run from the command palette or from a hotkey bound to it. The README records settings for a seed, for the lower and upper limits of the random range, and for whether a space character is added after the generated number. Generating several numbers at once, other kinds of random values such as floats, booleans and hexadecimals, and random.org support with the user's own API key are listed as planned rather than implemented.
