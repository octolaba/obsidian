# aulyc/aulycKanban

aulycKanban is a task board that groups tasks by custom task types, each keeping its own collection, over one shared set of quadrants that stays the same across every type. Task types and quadrants can be added, renamed and removed, with tasks migrated automatically when a quadrant goes, and tasks can be searched, edited, sorted, archived, restored and deleted in bulk. Each task type and the archive get an automatically maintained Markdown mirror inside the vault, while board state persists through Obsidian's plugin data API. Commands open the board and switch to the work or personal task type, the interface follows Obsidian's language or is set to Simplified Chinese or English, and the plugin contacts no service at runtime and carries no update checker or telemetry.
