# takmatsukawa/obsidian-hatena

This plugin posts notes from Obsidian directly to a Hatena Blog. No repository description is recorded, so this body rests on the README alone. Setup requires the blog's AtomPub root endpoint and an API key from the Hatena account settings, and the blog's editing mode has to be set to Markdown mode beforehand. Commands publish the active note, post it as a draft, delete its article, and insert a table of contents that renders only on the Hatena Blog side, while text wrapped in `%%` stays a comment visible in Obsidian alone.
