# jsandburg/obsidian-redacted

Replaces a selected passage in a note with a run of block characters, from the command palette, the editor context menu or a ribbon icon. Three styles are available: one block per character, one block per character with spaces preserved, or a fixed run of five blocks per line that hides length as well, and the block character itself is chosen from presets or set to any single character. Redaction can be limited to named folders, with a notice shown when the command runs elsewhere, and multi-line selections keep their line breaks. The rewrite affects only the note text, so the original can still survive in editor undo history, Obsidian's File Recovery snapshots and any sync or backup copies.
