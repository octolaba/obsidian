# paulobsf/obsidian-life-calendar

Obsidian plugin that renders a life-in-weeks calendar from an explicit code block in a note, one row per age-year and 52 squares per row. It distinguishes completed weeks, the current week and the weeks remaining to a configured planning horizon, shows age labels at a configurable interval and optional spacing between decades, and supports planning phases given by age range or date range with categories such as life, work, education and sport, cycled through a twelve-colour palette tuned for light and dark mode with optional overrides. Event markers come from the code block or from vault notes carrying frontmatter, and the linked event notes open from the calendar. The README states that all data stays local to the vault.
