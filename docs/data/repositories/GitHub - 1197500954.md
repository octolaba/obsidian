# firstsun-dev/git-files-sync

Git File Sync synchronizes selected vault files with GitHub, GitLab, or Gitea instead of requiring whole-vault synchronization. Its dashboard supports file status filtering, review plans, visual diffs, renames, conflict resolution, folder selection, and mobile use before changes are applied.
