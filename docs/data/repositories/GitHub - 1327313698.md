# Creative781/beautiful_pdf

Exports a Markdown note to PDF with per-element styling: headings, body text, quotes, lists, tasks, code, tables, callouts, images, links, footnotes and embeds each get their own fonts and spacing, configured in a settings interface. Page setup covers paper size, margins, line height, page numbers, header and footer alignment, and using the filename as the title, while named profiles hold complete style sets that can be switched per export. A preview renders through the same export pipeline, so page breaks in the preview match the saved file, and a marker or a command inserts an explicit page break. It is desktop only because it uses the Electron print-to-PDF call, and fonts installed on the computer can be selected for use in the PDF.
