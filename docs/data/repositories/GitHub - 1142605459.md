# pan4ratte/obsidian-pandoc-gui

Pandoc GUI exposes Pandoc's export and import options through Obsidian's interface instead of the command line, with a template editor covering the table of contents, section numbering, the PDF engine, syntax highlighting, maths rendering, paper and font size, and footnote placement. Targets include Word, PDF, LaTeX, HTML, EPUB, Beamer and reveal.js slides, PowerPoint, several Markdown flavours, Typst, RTF, OPML and a BibTeX bibliography, with embedded notes and sections, highlight marks and display maths preserved. An import command converts an outside file into a note, choosing the Markdown flavour, destination folder and how images and properties are handled. Pandoc is installed separately on desktop, a Pandoc WASM build can be installed into the plugin for mobile, and a built-in store offers more than three dozen lua filters.
