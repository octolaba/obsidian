# engram-app/Engram-obsidian

Engram Vault Sync synchronises an Obsidian vault with the Engram service — either the hosted account or a self-hosted backend — so the same notes are available on other devices. The README describes semantic, keyword and hybrid search modes reached from a search icon, with keyword matching running locally and offline, and a REST and WebSocket API over the notes. It states that the vault can be connected to AI clients over the Model Context Protocol so they read and write notes, that offline edits sync on reconnect, and that notes go only to Engram with no tracking; those are the project's own claims.
