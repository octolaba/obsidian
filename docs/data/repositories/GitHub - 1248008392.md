# TheViviana/Obsidian-Theme-Framer

TheViviana/Obsidian-Theme-Framer holds Framer, an Obsidian theme drawn from Framer's design system: a deep black canvas in dark mode, a warm cream canvas in light mode, and tuned pink and rose-gold accents. The README describes a lightweight interface, minimalist tags and properties, expressive code colours and macOS-like motion gated through a single CSS duration variable. Its notes for version 1.3.4 record CSS compression that reduced theme.css from 77 KB to 61 KB, the removal of 21 unused variable definitions, a losslessly compressed background image, and no remaining use of the important flag.
