# Carbonateb/obsidian-encore-theme

Encore is described as a theme that aims to freshen up the Obsidian interface with a design loosely based on Material 3. Its README states that the initial visual impact is deliberately subtle, focused on cleaning up the interface, refining typography and strengthening visual hierarchy while making no changes to the app's core layout. It records support for the Dataview, Make.md, Calendar, Kanban, Projects and Canvas plugins, and an alternative to translucency in which a background image is set by URL or picked from several subtly animated options.
