# muratagawa/update-time-updater

This plugin updates a modified-date field in a note's frontmatter on demand, from a button in the left ribbon or from a command that updates the modified datetime manually. Its settings record which frontmatter key is updated and the datetime format, expressed in Moment.js format tokens.
