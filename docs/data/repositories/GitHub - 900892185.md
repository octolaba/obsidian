# blotspot/obsidian-wake-lock

Cook Mode uses the Screen Wake Lock API to keep the display awake while Obsidian is in the foreground, which the README suggests for long reading, writing or brainstorming sessions and for using Obsidian as a cook book. Four activation strategies are offered: always on while Obsidian is open, per-file control through frontmatter, activation only while the editor has focus, and activation after a period of inactivity in the editor. The lock can be toggled from a hotkey, from a command, or from a status bar icon that also shows the current state, and settings cover the strategy, the status bar item, notifications for wake lock events and a developer mode. The README states that it works on desktop and mobile, with some limitations on iOS.
