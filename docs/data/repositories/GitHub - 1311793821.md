# FilhoRicardo/vaultquiz

VaultQuiz turns notes from chosen folders into a daily multiple-choice quiz played inside Obsidian, with questions generated through the user's own LLM key for MiniMax, OpenRouter or any OpenAI-compatible API and no server, account or sync. A default of five questions is answered one at a time, each showing the correct answer and an explanation before a final score. A participation streak counts a day on which all of that day's questions are finished on an active day, and a streak freeze is spent automatically for a missed day, one earned every 21 completions up to three. The README also documents a dashboard with streak, freezes, today's score, 30-day rolling accuracy and a 12-week completion heatmap, best-effort generation at a set time that catches up when Obsidian is next opened, an optional Markdown log, and desktop and mobile support.
