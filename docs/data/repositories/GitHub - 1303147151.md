# max-fluff/obsidian-reference-linker

The repository holds Reference Linker, a desktop-only Obsidian plugin that autocompletes links to documents kept outside the vault and inserts a Markdown link opening the file at the right page in its default application. Its README claims eleven formats across fifty-seven extensions, among them PDF, Word, Excel, PowerPoint, OpenDocument, EPUB, HTML, Markdown, CSV, images, audio and video, read by the plugin's own readers with no external converters. Where a format carries an outline, every section is indexed on its page, so a query can find a paper's introduction rather than the paper, and hovering a link renders the page, slide, layout or sheet while a reference-link block embeds the same view inline. Links pinned to a section are checked against the index and marked and updated in place when the document is reissued and the section moves.
