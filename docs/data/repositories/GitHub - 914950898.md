# ashwin271/obsidian-vector-search

This plugin adds semantic search to Obsidian through Ollama's embedding API, finding notes that are similar in content rather than by keyword match. It uses text chunking strategies, detects file changes automatically and updates the index incrementally, and exposes a configurable similarity threshold; once the embeddings exist, the README states that search runs locally and fast. Its prerequisites are an Ollama installation started as a service on macOS, Linux or the beta Windows build, and the nomic-embed-text embedding model pulled beforehand, which the README sizes at roughly 500 MB and notes that the first embedding generation may be slower.
