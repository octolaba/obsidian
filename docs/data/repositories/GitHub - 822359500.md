# zzunebye/obsidian-google-liked-video

This repository holds Geulo, described upstream as an extension for pulling and syncing videos liked on YouTube into an Obsidian vault. The README says the plugin fetches the liked-video collection and YouTube playlists, supports searching, filtering and sorting them, can produce model-generated video summaries through Gemini or OpenRouter, integrates a video into daily notes in one step, and can remove videos from the collection through the sidebar. It states that the mobile version is still experimental.
