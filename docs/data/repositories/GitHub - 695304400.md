# iron-vault-plugin/iron-vault

The recorded description says this is an Obsidian plugin for Ironsworn and Starforged games. The README states that it uses game data in the datasworn format and that it grew out of Eric Bright's Forged in Obsidian template vault, whose functionality was gradually replaced by the plugin. The features it points at are built-in rulesets for Ironsworn Classic, Delve, Starforged and Sundered Isles plus the community expansions Ancient Wonders, Fe-Runners and Starsmith; blocks that render game data with interactive editing widgets; commands bindable to hotkeys for actions such as making moves and creating progress tracks; entity representations for game concepts; and support for more than one campaign. Full documentation lives on the project's own site rather than in the repository.
