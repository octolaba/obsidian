# anstosa/format-hotkeys-obsidian

This repository holds Format Hotkeys, described upstream as Google Docs style formatting hotkeys for Obsidian. The README maps default shortcuts for toggling blockquote, bulleted list, numbered list and checklist, and for applying normal text or headings one through six, and notes that Ctrl and Alt correspond to Cmd and Option on macOS. A further table lists strikethrough and other bindings as coming soon rather than implemented.
