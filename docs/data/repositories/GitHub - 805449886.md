# Lio5n/peekaboo

Peekaboo selectively hides and reveals files and folders, with the configuration protected by a password. Individual files, entire folders or wildcard patterns can be hidden, configured exception files stay visible inside a hidden directory although folder exceptions are not supported, and visibility is toggled from a ribbon menu or from dedicated command-palette commands. The README states that the plugin conceals notes visually and does not encrypt the files, and recommends combining it with Obsidian's excluded-files setting so that hidden items stay out of search results and the graph view.
