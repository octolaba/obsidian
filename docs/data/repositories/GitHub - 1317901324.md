# anandrajbaghel/gate-simulator

Turns a vault of GATE previous-year questions into an examination environment, with a full-screen interface, countdown timer, question palette, mark-for-review controls and automatic submission when time runs out. Tests can be assembled by subject, topic, institute, difficulty and question count, or drawn from a single year, several years, or a subject or topic slice, covering MCQ, MSQ, NAT and marks-to-all questions. Submissions report score, accuracy, attempt rate, correct, wrong and unattempted counts and timing, feeding a dashboard of subject and topic accuracy, and every question can be reviewed against its correct answer. The question and image folders it reads are downloaded by a separate GATE Manager plugin, and all data stays inside the vault.
