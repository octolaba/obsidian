# masaki39/tab-swap

Tab Swap is a micro plugin that moves the active Obsidian tab one position to the left or to the right. It adds two commands, swap-tab-left and swap-tab-right, with no hotkeys bound by default; the README shows the author's own macOS bindings for them beside Obsidian's built-in previous-tab and next-tab commands.
