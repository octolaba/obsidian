# jepicaju862-lab/duowei-table

Stores spreadsheet-style structured data in plain-text JSON files with a .duowei extension inside the vault, so records, fields, views and settings can be read, diffed and backed up with ordinary tools. The Community Edition covers 22 field types, including relation, lookup, rollup, formula and attachment, and seven view types: grid, Kanban, gallery, calendar, timeline, form and dashboard. Editing supports range selection, copy and paste, undo and redo, previewed bulk edits and a migration preview when a field changes type, alongside filters, sorting, grouping, conditional formatting and column summaries. Tables can import and export CSV or TSV, index vault folders, migrate from Obsidian Bases, bind records to notes and synchronize fields with frontmatter, and embed filtered views in notes; the interface itself is in Simplified Chinese.
