# mark-when/obsidian-plugin

This plugin integrates Markwhen into Obsidian, so timelines can be written in Markwhen syntax. The README points to the Markwhen documentation for the syntax itself and records the release and document version at the time of writing. Installation is described from the community plugin browser, through BRAT for releases published before review, or manually by copying the release files into the vault's plugin folder.
