# soundslikeinfo/obsidian-clipper-catalog

Clipper Catalog adds a view listing every clipped web article in an Obsidian vault, so clippings can be searched, sorted and organized in one place. A configured property name identifies clipped content, `source` by default, and every note carrying that property with a URL value appears in the catalog. The view is opened from the command palette or a sidebar icon and offers tag-based filtering, real-time search and sorting, directory filtering, and, according to the README, works on desktop and mobile.
