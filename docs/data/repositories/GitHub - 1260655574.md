# BakedSoups/quick-autocorrect

Quick Autocorrect reviews spelling and grammar in the current Obsidian note and presents the suggestions together in one menu, in the manner of the Google Docs tool, instead of hovering over each typo in turn. Checking is done by LanguageTool: by default the note text is sent to the public LanguageTool API when a check is run, and the endpoint can be switched in settings to a local server or any compatible base URL. The README states that the plugin neither bundles nor manages a LanguageTool server and does not use Electron spellcheck or bundled spellchecker libraries, that it collects no analytics or telemetry and sends nothing in the background, and it documents running LanguageTool locally in a Docker container to keep note text off a public service.
