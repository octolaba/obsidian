# colinlienard/obsidian-more-vim

This repository holds More Vim, an Obsidian plugin that adds Vim features missing from Obsidian's built-in Vim mode, among them surround, multi-cursor motions, scrolloff, gd and gx. The surround commands ys, ds and cs plus visual-mode S add, delete and change surrounding characters, covering brackets, quotes and the usual aliases. When more than one cursor is active in normal mode, the listed motions run per cursor and Escape collapses back to the main cursor.
