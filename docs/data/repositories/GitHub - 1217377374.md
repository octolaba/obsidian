# yoriGo77/obsidian-yori-task

A task manager for Obsidian that combines a task board with backlog, upcoming and later columns plus recent done, a seven-column week plan with week navigation, and a year plan of twelve monthly columns. Tasks are reordered by drag and drop, highlighted, and linked back to the notes they were dragged from, and the current view can be archived into a Markdown note. The README states that the plugin is desktop-only and documents it in English and Chinese.
