# friebetill/obsidian-file-diff

Compares the active file with another file inside Obsidian and shows the differences. Three commands are offered: a plain comparison, a comparison that also allows merging changes, and one that finds Syncthing conflict files and offers the merge view for each in turn. The author states the plugin was written to avoid cleaning up Syncthing merge conflicts by hand, and points to an issue thread for adjusting the diff colours.
