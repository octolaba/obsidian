# aterrylu/obsidian-pitch-black

Pitch Black is a true black theme for Obsidian, inspired by the VSCode Pitch Black theme by Viktor Qvarfordt. It uses pure black backgrounds throughout the interface for high contrast on OLED displays and takes its code-block syntax highlighting from VSCode Dark+. The README records the palette, including #000000 backgrounds, #d4d4d4 primary text, a #007acc accent, #d7ba7d inline code and a #010101 code background.
