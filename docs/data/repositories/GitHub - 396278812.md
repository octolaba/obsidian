# dobrovolsky/obsidian-structure

The Structured plugin builds a hierarchy out of note names separated by dots, in the style of dendron, so that aws, aws.ec2 and aws.ec2.security-groups form a tree. It handles renames across that hierarchy and adds commands to list parent and child notes, open the parent note, and create a new note in the root or beside the current one. The README describes the plugin as being in early alpha.
