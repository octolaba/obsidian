# playmean/obsidian-event-highlight-plugin

Obsidian plugin that renders coloured bars showing dates relative to the present. A note carries an event-highlight code block whose body is a date, given either as a plain date or as a date with a time. The repository README consists of that example alone, so nothing further about the rendering is recorded here.
