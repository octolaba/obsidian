# bueckerlars/obsidian-note-mover-shortcut

Advanced Note Mover is an Obsidian plugin that moves notes into folders according to rules based on tags, frontmatter properties, filenames, dates, links and more, so that an inbox does not have to be emptied by hand. A rule combines a trigger, such as a tag including a given value or a property with a given value, with a destination folder, and rules are evaluated in order with the first match winning and everything unmatched staying put; a filter list blacklists paths such as a Templates folder from ever being moved. Movement runs automatically or on demand, and a preview command shows what would happen to the active note before anything is committed. The README records Obsidian 1.5.0 or newer as the requirement and desktop and mobile as supported.
