# aliceinwaterdeep/obsidian-hardcover

This plugin syncs a Hardcover library into an Obsidian vault, creating one note per book with its metadata in frontmatter properties. Incremental updates touch only the books that changed since the last sync, a status filter can restrict which books are imported, a validated template controls the note's frontmatter and body and can add custom properties, and notes can be grouped into directories by author or series. A delimiter separates plugin-generated content from anything added by hand below it, which the README says is preserved across syncs while still recommending regular backups. Obsidian 1.11.4 or later and a Hardcover API key are required, and the README records that version 2.0.0 introduced customizable templates and split book and edition fields with an automatic settings migration.
