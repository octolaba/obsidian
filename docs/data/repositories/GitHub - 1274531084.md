# ichenh/obsidian-math-chords

Math Chords is a math-writing toolkit for Obsidian: chord-like leader shortcuts, whose defaults follow LyX math-mode bindings, type common LaTeX structures, a searchable sidebar browses and inserts formulas, and titled templates hold reusable equations or any other Markdown, stored in the plugin settings and inserted as source into the active note. It normalizes LaTeX delimiters copied from other tools, papers or TeX sources without touching protected Markdown regions, previews inline math, moves between brace fields and wraps display math in environments. Fenced TikZ is rendered either by a self-contained WASM backend with live preview and image or PDF export, or by a local TeX installation. The README records release 0.5.10, requires Obsidian 1.7.2 or newer, calls the plugin keyboard-heavy and desktop-recommended, and is bilingual.
