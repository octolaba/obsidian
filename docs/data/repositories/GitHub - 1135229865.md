# lfcipriani/obsidian-radar

Obsidian Radar places notes and ideas as blips on a radar divided into concentric priority rings and category segments, which can be dragged, panned and zoomed. A blip either links to a vault note or holds standalone text, and grouping by topic with proximity to the centre standing for priority is offered for prioritising initiatives, running a technology radar of adopt, trial, hold and avoid, tracking research topics, and keeping an overview of a project portfolio. The repository also ships a skill file with a sample prompt for asking an assistant in the vault to build a radar file from existing notes.
