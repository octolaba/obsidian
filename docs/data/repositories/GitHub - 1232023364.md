# Najeong-Kim/time-manager-plugin

Time Manager reads a timeline section of the daily note and renders its tasks as time blocks on a vertical axis in Obsidian's sidebar, with a line marking the current time. A task line carries a start time, a name, an at-prefixed category and a duration; the README notes that when the duration is omitted the gap to the next task is used instead. The view navigates between days, adds tasks through a modal, and shows a bar chart of scheduled against completed time per category, while the editor highlights categories and durations as they are typed and offers autocomplete for categories. The daily note folder and the heading of the managed section are configurable.
