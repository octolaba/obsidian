# hanblade67-cloud/media-layout

Media Layout lets images, video, audio and note boxes be arranged, resized and rotated directly on the page in Live Preview. Files can be edited in the text flow or cloned, and a clone loads from the file on disk, carries its own size and position, and remains after the original element is deleted from the note as long as the file exists in the vault. The README records per-clone styling including global and per-file backgrounds, transparency and text colour, links attached to image clones, presets that save every clone and note box in a note, and multi-select with Ctrl and click.
