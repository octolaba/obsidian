# Poet-Coded/Gamified-Writing-Suite

Gamified Writing Suite tracks writing sessions in Obsidian and turns them into experience points across a 900-level progression split into three tiers. A sidebar tab records daily energy on a one-to-five scale and a hormonal cycle phase, and monitors an active session for words added, net words per minute, character counts and pause intervals. Rewards follow a chosen theme, either Stardew-style crops and barn animals or Dungeons and Dragons-style monsters, and the plugin ships affirmation prompts written for neurodivergent writing habits. Finishing a session exports a detailed Markdown session report into a configured vault folder.
