# Laurent-Ferier/pm-compass

pm-compass adds a task dashboard, inbox, weekly review, and dependency graph on top of obsidian-pm project notes and Obsidian Daily Notes checklists. It edits the existing Markdown directly, supports recurring habits, rescheduling and promotion of checklist items, and carries task dates, tags, priorities, and notes into project files. Project views add dependency editing, inherited urgency, ranked queues, weekly rollups, and quick status changes.
