# Laurent-Ferier/pm-compass

PM Compass adds a task dashboard, an inbox, a weekly review and a dependency graph over two things a vault may already hold: project and task notes from the obsidian-pm plugin and checklist items in Obsidian's core Daily Notes. It reads and edits those files directly, with no separate database, and its checklist lines stay compatible with the emoji date format used by the community Tasks plugin. Recurring habits defined once in settings are inserted into each day's note when it is opened or created, while the inbox holds quick-capture tasks with age tracking and a staleness warning, and checking one off moves it into today's note as done rather than deleting it. Any checklist item can be rescheduled, moved to the inbox, deleted, annotated, or promoted into a project task carrying its dates, tags, priority and indented notes.
