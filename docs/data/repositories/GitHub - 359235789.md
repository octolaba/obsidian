# mkozhukharenko/mdx-as-md-obsidian

This plugin lets Obsidian edit MDX files as if they were Markdown. The README records Obsidian 0.10.12 as the minimum version, because that is when the APIs it needs were added, and gives both community-browser and manual installation steps. It also carries a security note that third-party plugins can reach files, the network and other programs, that the source is available for auditing, and that the author's assurance of collecting nothing is ultimately a matter of trust.
