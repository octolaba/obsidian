# studentepercaso/bridge-control

Bridge Control is the desktop-only Obsidian companion that configures the read and write access used by Obsidian Bridge. The README states that on first run access is bound to the current vault's stable identity and local path, reading stays off until the user selects folders, writing and every management permission are off, and no update silently increases access. Three profiles are described: Protected access confines reading and guarded create or append operations to the selected folders, each write requiring a preview and explicit confirmation; Autonomous access allows read, create and append across the eligible vault without per-change confirmation; Full management is separately confirmed and grants only the capabilities explicitly chosen. The panel offers a searchable folder picker, separate read and write checkboxes, non-executing CLI diagnostics and a recent-problems view.
