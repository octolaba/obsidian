# olivertedwards/native-cursor-obsidian

This repository holds Native Cursor, a minimal Obsidian plugin that makes the editor cursor wider, coloured and with controllable blinking, without movement animation or blur. Its settings cover a cursor width between 1 and 6 pixels, separate accent colours for dark and light mode, a toggle for the standard blink, and a button that restores every setting to its original value. The README records iA Writer and the Animated Cursor plugin as inspirations and states that the cursor snaps instantly to its new position, as a native application would.
