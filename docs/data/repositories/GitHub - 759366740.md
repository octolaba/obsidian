# RyotaUshio/obsidian-command-block-list

Command Block List hides unwanted commands from Obsidian's command palette. Commands to hide are added one at a time from the plugin settings with a plus button. The README documents installation through BRAT, including the browser URL that registers the repository, and recommends enabling BRAT's automatic update at startup.
