# MatheusZarkov/gradient-text

Gradient Text is an Obsidian plugin that paints headings, bold, italic, wikilinks, external links and normal text with colour gradients, from preset palettes or custom colours. The README records independent control per element, with a dropdown offering one of five presets, a custom mode or None, and a custom picker taking HEX, RGB or HSL values across two- or three-stop gradients, where removing the middle colour falls back to two stops. Settings rows also record a reset control and a live preview label, and commands enable, disable or toggle all gradients and the body-text gradient on its own. The README states gradients on normal text are off by default, that the styling works in Reading view and Live Preview, and that disabling returns text to the theme's own colours.
