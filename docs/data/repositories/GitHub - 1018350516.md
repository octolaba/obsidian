# artemkorsakov/personal-development-plan

Personal Development Plan is a plugin for planning and tracking personal and professional development inside an Obsidian vault. Its README describes a seven-tab interface covering in progress, planned, knowledge base, sources, statistics, history and examples, and a task lifecycle that moves items from the knowledge base through planned and in progress into history. It also records task-limit and deadline notifications, and periodic daily, weekly, monthly, quarterly and yearly templates that generate tasks automatically.
