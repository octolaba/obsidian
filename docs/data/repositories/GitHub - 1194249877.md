# resina37451-cell/study-flow-planner

Study Flow Planner is a timeline calendar inside Obsidian, drawn as a scrollable day-by-day grid running from 5:00 to 23:00, with zoom levels covering one day, one week, two weeks, one month and two months. Events are created timed or all-day, coloured from ten presets, tagged freely, linked to a note through an autocomplete search, marked done with strikethrough and explained by tooltips; a live line marks the current time in today's column, and events written in daily notes are picked up automatically. The README records a study mode that highlights study-related events in subject-specific colours, persistent storage of the events, and an interface in Portuguese and English.
