# DNDark12/vault-rooms

Vault Rooms shares selected folders of an Obsidian vault, called rooms, with trusted people on the same local network: one device hosts a small relay server and the others join it from the plugin. Access is deny-by-default and per path pattern, granted to a user or to a named permission group called a team, with identity issued per server as one token per device, so the whole vault is never exposed. Every regular file in a shared folder is synced, text as text and everything else as binary, except dotfiles and dotfolders, while character-level co-editing through CRDTs applies only to Markdown notes and is on by default for new rooms. The README states what it is not: not cloud sync, not NAT traversal, not mobile, and not a sandbox for other Obsidian plugins.
