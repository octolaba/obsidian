# DNDark12/vault-rooms

Vault Rooms shares selected vault folders with trusted devices on the same local network through a host relay and client connections. Rooms define shared boundaries, teams and per-path permissions control access, and Markdown notes can use character-level collaboration; it is desktop-only, deny-by-default, excludes dotfiles and dotfolders, and is not cloud sync or NAT traversal.
