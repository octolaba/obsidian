# deathau/Base2Tone-For-Obsidian.md

Base2Tone for Obsidian is a duotone theme built on the Base2Tone colour system, with its default hues taken from the Duotone Dark Sky syntax scheme. Its README documents installation by downloading an obsidian.css file into the vault folder and enabling the Custom CSS option, and recolouring by editing the two hue values at the top of that file. It records one exception: a further colour value has to be converted to RGB by hand with an external converter. The theme is released under The Unlicense.
