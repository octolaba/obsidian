# nwbort/obsidian-harvest

An Obsidian plugin that integrates Harvest time tracking into the vault. The README records a status bar entry showing the running timer with its project, task and duration, command-palette commands to start, stop and toggle a timer and to refresh the project list, and a start flow that selects a project and then a task through modals. Time reports are rendered inside notes from harvest code blocks written in a small query language, in list or summary form over a chosen period. Configuration requires a Harvest personal access token and account ID entered in the plugin settings.
