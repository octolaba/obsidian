# igor-kupczynski/obsidian-title-sync-plugin

Title Sync renames a Markdown file to match its first level-one heading, run as one explicit command rather than continuously. The heading is taken from after the frontmatter, code blocks are skipped, Markdown formatting such as bold, italic and links is stripped, characters that are illegal in filenames are replaced with dashes, and the result is truncated to two hundred characters for cross-platform compatibility. Success and failure are reported as notifications. The README recommends turning off the inline title setting so the heading remains the single visible title, and it notes that at the time of writing the plugin was still under review for the community directory.
