# mikuloverfan/draft-paper

Draft Paper adds a full-screen hand-drawing layer over Markdown documents in Obsidian for sketches, arrows, boxes and text annotations. The README lists smooth handwriting through perfect-freehand, colour picker, stroke width and opacity controls, a real stroke eraser that removes parts of paths, movement, deletion and scaling of elements, and text annotation on the canvas. Its recorded description states the transparent canvas is presented in reading mode, that strokes are bound to document coordinates so they are unaffected by DOM changes such as a folded callout or a loading image, and that they persist in a separate file in the same directory.
