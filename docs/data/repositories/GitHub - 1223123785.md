# FrankL1u/wechat-article-obsidian

A desktop Obsidian plugin for writers who draft WeChat Official Account articles in Markdown. It reads the current note, renders a preview in WeChat article layouts, generates a cover image and inline illustrations from the article content, each of which can be regenerated or deleted, and creates a draft in the WeChat Official Account backend once account credentials are configured. Compatible language-model and image-generation providers are selected in the plugin settings, and the README leaves the final review and publication to the WeChat backend.
