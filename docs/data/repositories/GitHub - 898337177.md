# leoleelxh/obsidian-memos-ai-sync

Memos AI Sync copies content from a Memos server into Obsidian as Markdown, manually or on a configurable interval, organising files by year and month and skipping entries it has already written by their Memos identifier. It derives file names from a content preview plus a timestamp, converts Memos-style tags to Obsidian tags, downloads images and attachments into a resources directory and rewrites the references as relative links, and stores metadata in a collapsible callout. Optional AI features summarise each memo, suggest tags and generate weekly summary files under a weekly directory, with OpenAI, Gemini and Ollama implemented and Claude listed as untested. Required settings are the Memos API URL, an access token and the sync directory; the README is written in Chinese.
