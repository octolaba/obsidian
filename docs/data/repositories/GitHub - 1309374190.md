# h-jessen/second-brain-tarot-plugin

Second-Brain Tarot draws from a complete 78-card tarot deck and asks an AI provider to interpret the draw against content loaded from the open vault through Obsidian's own vault and metadata APIs, rather than from a fixed lookup table. Six spreads are offered, each laid out in its own geometry, with click-to-reveal cards, upright and reversed orientations that flip the artwork, a synthesis of the whole spread, and multi-turn follow-up chat grounded in the same vault context. A reading and its follow-up can optionally be saved into the vault as a new note or appended to the open one, with wikilinks. The README states that the user supplies their own API key for Anthropic, Google, xAI or OpenAI and that requests go straight from the machine to the chosen provider.
