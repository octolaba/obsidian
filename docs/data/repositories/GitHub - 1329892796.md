# ShakToth/LancerOS-Obsidian-Theme

Lancer-OS is a high-contrast, dark terminal-style Obsidian theme modelled on the UNION_OS interface from the Lancer tabletop game. A deep black and grey ground carries a neon orange primary accent on headings, structural icons and properties, with a bright cyan secondary accent on active states, links and folder prefixes. The file explorer is reformatted in terminal fashion, prefixing directories and files with symbols, and the theme also styles Dataview tables, callouts and internal links.
