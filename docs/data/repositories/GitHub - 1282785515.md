# nakaba-lab/eisenhower-bases-view

Obsidian plugin that renders the notes of a Base as a 2x2 Eisenhower matrix, with urgency and importance taken from two boolean note properties chosen in the view configuration. Dragging a card between quadrants writes the corresponding true or false back to the note's frontmatter through the standard processFrontMatter API, and notes whose axis properties are unset sit in an uncategorized zone. The README records the plugin as desktop-only, because classification is drag-and-drop, and states that it runs locally with no network access.
