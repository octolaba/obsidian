# rklpoi5678/OpDoc-AI-Auto-Organizer

Obsidian plugin that watches an inbox folder, sends each new Markdown file to a configured AI backend — Ollama locally or OpenAI in the cloud — and then writes the returned tags into frontmatter and moves the file to the folder the model chose. Target folders are matched by embedding similarity against existing folder content, and processing runs on file creation, on a scan every few minutes and on a manual command, with catch-up for files left in the inbox after a restart. Failures are retried with exponential backoff and classified into user-facing messages, filename collisions are resolved by numeric suffix and then by timestamp, and every action is appended to an activity log note. The README records a guided onboarding wizard on first launch and states that processing goes only to the configured provider.
