# silvanocerza/github-gitless-sync

This repository holds GitHub Gitless Sync, described upstream as syncing a GitHub repository with vaults on different platforms without requiring a git installation. The README lists desktop and mobile support, several vaults, automatic sync on a fixed interval, manual sync and a conflict resolution view, with filtering by file type marked as unfinished. It requires a fine-grained GitHub token with read and write access to repository contents, along with the owner, repository and branch, and states that the first sync works only when either the repository or the vault is completely empty. The README also advises against combining the plugin with another sync service.
