# deathau/cm-typewriter-scroll-obsidian

Typewriter Scroll enables typewriter-style scrolling in Obsidian, keeping the editing view centered as text is typed. The README states that the plugin is experimental and that parts of it might not work, that custom plugins require Obsidian v0.9.7 or later, and that the repository's API targets Obsidian v0.10.0. Installation is described from within Obsidian's community plugin browser or by extracting a release archive into the vault's plugins folder.
