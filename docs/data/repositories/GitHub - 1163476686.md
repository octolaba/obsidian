# minorchange/obsidian-tasknotes-project-colors

TaskNotes Project Colors tints the task cards rendered by the TaskNotes plugin so that each project gets a distinct background and left border. It watches the DOM for task cards, reads the project name from the project link, hashes that name with DJB2, maps the hash onto a hue and sets it as a CSS custom property on the card, so a new project needs no configuration to receive a color. The README records that the colors appear in every TaskNotes view that renders cards, namely kanban, task list and agenda, that light and dark themes are both handled, and that saturation and lightness can be overridden with a vault CSS snippet.
