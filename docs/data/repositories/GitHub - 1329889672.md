# bobstanton/places-nominatim

A search provider for the Places plugin backed by Nominatim, searching OpenStreetMap data. It resolves a search term to place suggestions with coordinates and a coordinate back to an address, and since it renders no map of its own it pairs with any map provider. All requests go to the public Nominatim service, no background tasks run, and its map, overlay and routing code comes from places-shared.
