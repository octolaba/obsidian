# jabaho9523/obsidian-tasks-plus

Tasks Plus organizes plain Markdown checkboxes into six fixed views, Inbox, Today, Upcoming, Anytime, Someday and Logbook, shown in a sidebar leaf or a full tab with live counts and a tree of areas and projects. Folders under the configured Tasks folder act as areas and notes as projects, and completing a task ticks its box and appends the done date in the source line, so nothing is copied into a database. A capture modal parses natural language such as a name plus tomorrow or next Monday into a dated task, can be triggered from outside Obsidian through a URL, and a second command inserts the same line at the cursor. Dates, deadlines, starred and someday markers use the inline emoji format of the Tasks plugin, and an optional block in the daily note lists what is due today.
