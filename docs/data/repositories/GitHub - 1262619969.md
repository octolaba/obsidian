# viggomeesters/obsidian-alteryx-viewer

Read-only Obsidian viewer for Alteryx `.yxmd` workflows and `.yxzp` packages. A workflow opens in a dedicated view summarising metadata such as version, id, name and run settings, each tool with its ToolID, inferred type, engine entry point, annotation, container, position, configuration summary, paths and formulas, and connections written from origin port to destination port. Warnings are reported for malformed XML, missing or duplicate ToolIDs, unknown tool types, broken connections and package contents, a source view with line numbers and XML highlighting stays available, and the listings can be filtered. The README is explicit that version 0.1 never runs, generates, converts, validates, edits or saves Alteryx files, and reads bytes only through the vault API.
