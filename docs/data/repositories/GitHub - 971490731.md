# orelby/obsidian-rtl-math-text-plugin

RTL Math Text adds basic support for mixing right-to-left and left-to-right text inside MathJax expressions through custom LaTeX commands. One command marks strictly right-to-left text such as Hebrew inside a math expression, a second nests strictly left-to-right text such as English inside it, and ordinary math delimiters nest numbers and expressions inside either; the names of both commands are configurable in the settings. The README states that languages with combining letters, naming Arabic, are not supported, and expects that to be resolved by the release of MathJax 4.0.
