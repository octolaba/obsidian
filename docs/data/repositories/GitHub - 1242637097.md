# kkbin505/pdf-to-md

This plugin converts handwritten PDFs into Markdown inside Obsidian using vision language models, started by right-clicking a PDF and choosing the conversion command. Its README says the author wrote it because native OCR handled mathematical formulas poorly, and it claims recognition of mixed text and formulas with equations emitted as LaTeX that Obsidian renders. It records provider choices including Qwen-VL, GPT and Gemini models as well as a free local option running a GLM OCR model through Ollama, with that model's page timing, memory requirement and setup given in the README, alongside progress reporting and API key handling.
