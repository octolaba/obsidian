# maxcohn/obsidian-simple-table-formulas

Simple Table Formulas adds spreadsheet-style formulas to Markdown tables. A formula written into a cell is evaluated by a command that bakes the computed value into the cell while preserving the original formula in an inline comment, and a second command restores the bare formula in a baked cell so it can be edited again. The stated goal is computed data in Markdown tables where a dedicated spreadsheet is overkill, with both values and formulas kept as plain text in the file for portability. The README also records that the plugin was written with LLM assistance and that its author reviewed and modified the code during that process.
