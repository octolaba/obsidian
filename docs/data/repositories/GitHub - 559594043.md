# k4a-l/obsidian-dirtreeist

Obsidian plugin that renders a directory structure diagram from a Markdown list written inside a code block. Entries are nested list items, each optionally followed by a comment separated from the name by a double hyphen, and the README also shows sequential listings and lists interrupted by another element. It states that the plugin relies on the functionality of the dirtreeist library and that feature requests belong there.
