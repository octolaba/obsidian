# zhuzhige123/obsidian-weave-reader

The repository holds Weave EPUB Reader, an Obsidian plugin that turns the vault into a reading environment for e-books. Its README records EPUB, TXT and FB2 reading on desktop and mobile with a bookshelf carrying covers, progress, search and reading state, paged or continuous scrolling, single or double column layout, bookmarks and remaining-time estimates. Annotation covers five highlight colors alongside underline, strikethrough and wavy styles, and excerpts carry deep links back to their place in the book, echoed into Markdown, Canvas or Weave decks and kept in step when the note changes. Several listed capabilities, among them MOBI, AZW3 and CBZ reading, two-way tracing between note and book, whole-book export and footnote popovers, are marked as advanced, and the repository is licensed under GPL-3.0.
