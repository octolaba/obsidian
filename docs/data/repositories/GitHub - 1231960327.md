# zhuzhige123/obsidian-weave-reader

Weave EPUB Reader is a cross-platform Obsidian reader and bookshelf for EPUB and other supported ebook formats, with persistent progress, bookmarks, search, layout controls, and reading-state management. Users can highlight, annotate, capture screenshots, and send excerpts to Markdown notes, Canvas files, or Weave decks while retaining deep links back to source passages. It also provides excerpt summaries, bidirectional note-to-book tracing, chapter export, and incremental-reading scheduling across multiple books.
