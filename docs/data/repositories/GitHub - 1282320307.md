# Britz/obsidian-teaser-card

This repository holds Obsidian Teaser Card, a plugin that renders a fenced teaser code block into a clickable image teaser card. The README, written in German, documents the block accepting image, link, title and text keys, and a minimal form carrying only a heading line and a description line. It describes itself as an initial implementation that does not yet resolve Obsidian-internal attachment embeds.
