# Narcosia/third-brain-neon

Third Brain Neon is a dark-only Obsidian theme that keeps its night look in both appearance modes, layering tinted glass panes over a wallpaper embedded in the stylesheet as a single WebP data URI, so it works offline. Its palette splits roles: cyan carries structure such as headings, internal links, inline code and tags, magenta carries emphasis on bold text and highlights, and violet supports lower headings and external links. File explorer icons are Lucide glyphs baked into the CSS and colored by state, distinguishing files, closed folders and open folders. Heading and divider spacing in the editor uses padding only, because CodeMirror ignores vertical margins on line elements when mapping clicks to text positions, which otherwise makes a click land on the wrong line.
