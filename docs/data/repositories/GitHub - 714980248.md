# MayMeow/obsidian-omglol-statuslog

This plugin posts text from an Obsidian note to the omg.lol statuslog, with a weblog target listed as planned. A username and API token from the omg.lol account page are entered in the settings, together with a default emoji for posts that do not start with one and an option to skip cross-posting the status to Mastodon. Text is posted by selecting it and running the post command from the command palette.
