# StrangeGirlMurph/obsidian-wikipedia-helper

Wikipedia Helper searches, links, inserts and opens Wikipedia and Wikimedia articles from inside Obsidian, and its README presents it as a successor to an unmaintained Wikipedia plugin. It links articles from Wikipedia, Wiktionary, Wikibooks, Wikiquote, Wikiversity, Wikivoyage, Wikisource and Wikinews in any available language, can hyperlink selected text, quicksearch across languages, create a note for an article, and insert an article's description, introduction and thumbnail through configurable templates; articles can also be opened in Obsidian through the Web viewer plugin. The README records that the plugin was previously named Wikipedia Search and that its internal id was kept unchanged for backwards compatibility, so the old name still appears in the plugin folder and URL.
