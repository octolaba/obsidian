# pilafdob/Pinup

Pinup adds two pinning modes to the File Explorer without changing files, folders, note content or frontmatter. A normal pin moves an item above its unpinned siblings inside the same folder in a deterministic order, while pin up places the item on a compact shelf below the File Explorer toolbar and leaves its original tree entry in place by default. Pinning is reachable from the right-click menu on desktop and the long-press menu on mobile, a pin control is shown only for items that are already pinned, and command-palette actions cover pinning, unpinning and clearing all pins for the active file.
