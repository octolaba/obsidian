# israerusan/flowkit-health-dashboard

FlowKit Health Dashboard scores every installed community plugin on quality, maintenance, performance, popularity and compatibility, and helps trace a misbehaving vault back to the plugin causing it. Its elimination search saves the current setup, switches off half the enabled plugins, asks whether the problem persists and halves again, restoring everything afterwards even if the run is stopped or Obsidian restarts mid-search, and it tests the final suspect rather than assuming it. Other views time each plugin's load and catch timers that block the interface, record installs and updates so a recent change can be correlated with new errors, trace runtime errors back to the plugin that threw them and search that plugin's issue tracker, and find plugins claiming the same hotkey. The README states everything runs locally, that the diagnosis is free, and that a Pro tier covers further work.
