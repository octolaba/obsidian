# mattmaiorana/calendar-plus

This repository holds Calendar Plus, a sidebar calendar for Obsidian with daily, weekly, monthly, quarterly and yearly notes built in, presented as an update to Liam Cain's original Calendar plugin. Periodic notes are configured inside the plugin rather than requiring the separate Periodic Notes plugin, and month, quarter and year labels in the header open or create the corresponding note just as day and week cells do. A dot marks that a note exists by default, with a setting that shows word-count dots and an open-task dot instead. A second daily note can be opened per day by right-click, with its own folder, date format and template, and a note's frontmatter banner or first embedded image can be shown as the calendar cell background.
