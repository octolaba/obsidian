# Obsidian-TTRPG-Community/player-facing-notes

This plugin flags parts of a note as player-facing and syncs only those parts into publish-ready copies for Obsidian Publish, leaving the rest of the note in the vault. Its README, written for game masters who keep campaign notes and player handouts together, records four ways to flag content: a checkbox property for the whole note, an eye control in the left gutter of each block, a right-click action, and a command that can take a hotkey. Flagged regions are wrapped in standalone marker lines, so they can enclose callouts, tables and code blocks and can also sit inside a callout to flag part of it, and in Live Preview the markers render as small labels with a tinted border rather than as visible text.
