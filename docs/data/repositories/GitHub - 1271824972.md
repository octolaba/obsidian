# fovlin/obsidian-acovia-theme

Acovia is a warm-toned Obsidian theme that its README describes as gentle on the eyes, especially in dark mode. The README shows a dark and a light example and documents installation either through the community themes browser or by cloning the repository into the vault themes folder. Beyond that it records no configuration options and no palette values.
