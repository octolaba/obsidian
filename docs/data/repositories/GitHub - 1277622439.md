# zhao414/obsidian-reformat-windows-title

Customizes the Obsidian window title by choosing whether the file name or the vault name comes first, or leaving the default order. The text separating the two is configurable, and the Obsidian version can optionally be appended at the end. The README states a minimum Obsidian version of 1.5.0, desktop-only support because it uses Electron APIs, and no network requests, telemetry or access to files outside the vault.
