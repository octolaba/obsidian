# EddieTheEd/Prussian-Blue

Prussian Blue is an Obsidian theme inspired by the colour of the same name and derived from the ProtocolBlue theme. In compliance with ProtocolBlue's original license, the README states that Cosmodium CyberSecurity and the other contributors to ProtocolBlue do not endorse this theme. Its credits link to the ProtocolBlue repository and to the Wikipedia pages for Prussian blue and ferrocyanide.
