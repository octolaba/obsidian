# calghar/LinkVault

Obsidian plugin that files web-clipped links into a structured knowledge base with the help of a language model. One command reads a clipped note from an inbox folder, extracts a title and summary, chooses a target note and a section within it, inserts a table row and moves the inbox note to trash. Anthropic Claude, local Ollama and OpenRouter are the supported backends, all prompts are customizable through template variables, and transient errors such as rate limits and server errors are retried with exponential backoff. The README states that a link already filed anywhere in the base is skipped with its location reported, that a link is never filed into a note the model did not choose, and that a new note named after the subject area is created when nothing fits.
