# c-miles/orrery

Obsidian plugin that renders the vault's link graph as a slowly rotating three-dimensional orrery, each note a glowing star and each link a thread between them, drifting over a nebula and a field of stars. It opens from a ribbon icon or a command, and while open it can be spun by dragging, zoomed by scrolling, hovered to light up a node's neighbours and dim the rest, and clicked to open the note behind a star. A code block embeds a live instance in a note, taking an optional pixel height and an optional top-level folder to limit it to, and cleaning itself up when the note is closed. Settings control a folder filter bar, whether node colour follows the top-level folder or the subfolder, node labels and node dragging.
