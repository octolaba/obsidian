# zimya/zhihu_obsidian

This repository holds Zhihu on Obsidian, a plugin that publishes a Markdown file directly to Zhihu, a Chinese question-answer platform. It creates and publishes Zhihu articles and answers, submits an article to a Zhihu question, and browses customized recommendations, followings and hot lists. Logging in uses Obsidian's Web Viewer core plugin, which has to be enabled first: the plugin opens a login page to scan from the Zhihu app, then fetches cookies and user data automatically, and the README states that it never uploads the user's information.
