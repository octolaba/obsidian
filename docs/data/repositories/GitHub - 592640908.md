# KarthikRaju391/obsidian-float

Animates marked-up text as it scrolls into the viewport in reading mode, so that the text entering view is emphasised while the rest of the page is dimmed. Highlights, bold and italic can each be animated or not and carry their own scale amount, and global settings cover animation duration, the background opacity applied to unmarked content, whether only the matched word rather than its whole container is animated, and whether bold and italic inside a highlight animate too. The README states that the effect applies in reading mode only, not in Live Preview or source mode, and describes transform-only transitions and shadow suppression while scrolling as performance measures.
