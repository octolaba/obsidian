# cazzek/obsidian-accordion-file-view

Obsidian plugin that lists Markdown and text files in an accordion-style preview panel, opened from a ribbon icon or the command palette. The list covers a chosen folder, or the whole vault when the folder setting is left blank, and can be narrowed further by a filter on file name or path. One item expands at a time, rendering Markdown files as formatted previews and TXT files as plain text, with an edit button that opens the file in the editor.
