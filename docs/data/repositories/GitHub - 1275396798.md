# strangelion/obsidian-formula-library

A LaTeX formula editor with a visual editing mode and a library the recorded inputs describe as more than 2100 formulas across eighteen categories, including Greek letters, structures, analysis, algebra, geometry, topology, probability, physics and chemistry. Search matches pinyin initials, LaTeX command aliases, English words, abbreviations and fuzzy input, results are ordered by how often each formula has been inserted, and starred formulas sort to the top. Formulas are inserted from a modal or a sidebar quick-insert list, an existing formula between dollar delimiters can be reopened for editing, and matrix templates and configurable shortcuts are provided. Custom groups are added by dropping JSON files into a formulas folder, and the interface follows the Obsidian language setting in Chinese or English.
