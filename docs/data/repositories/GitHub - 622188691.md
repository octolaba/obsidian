# kaffarell/obsidian-tesseract-ocr

Runs optical character recognition over pasted images with a local tesseract installation and writes the recognized result into a details box beneath the image, which also makes the image content searchable. The README states that tesseract must be installed and either on the environment path or pointed at through the plugin's Tesseract Path option, and that a plugin such as Local Images Plus should copy pasted images into a local folder first. Recognition is triggered by running the plugin's command.
