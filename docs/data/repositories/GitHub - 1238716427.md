# david46liu/obsidian-knowledge-ai

Knowledge AI answers questions about the vault with inline citations that jump to the source chunk, retrieving through a fusion of keyword search, vector embeddings and document-level summary search. It indexes Markdown, PDF text layers and office documents in a worker so the interface stays responsive, reads images through OCR or optional vision models, and generates summaries, study guides, timelines, briefings, mind maps and slide decks from a folder. Any OpenAI-compatible endpoint can be configured and embeddings can run on-device, with a Chinese and English interface following Obsidian's language. The README records the project as pre-1.0 and expects rough edges.
