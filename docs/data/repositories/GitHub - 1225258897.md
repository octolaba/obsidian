# Textcat/harness-noting

The repository holds Harness Noting, an Obsidian plugin that checks note structure against scoped rules. The README records scopes matching notes by file, folder, tag, filename text and frontmatter property conditions, combined with all or any and narrowed by exclusions, and checks for required frontmatter properties, property values through exists, equals, contains and regex operators, required headings and their order, filename patterns, child folder structures, and a whitelist for entries at the vault root. Checks run from a ribbon button with a results modal whose conclusion can be copied, and from a bundled command-line script that can target one file or print JSON and exits 0, 1 or 2 according to whether notes passed, failed, or the checker itself failed. The README states this command-line path is meant for AI-assisted note maintenance.
