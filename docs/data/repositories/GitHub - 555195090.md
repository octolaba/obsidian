# nqthqn/obsidian-wordy

Wordy looks up words through the Datamuse API from inside a note. Selecting a word and running one of its commands finds synonyms, rhymes, antonyms, or alliterative synonyms, and a later version added a panel for searching synonyms. The README suggests setting a hotkey for the command.
