# bobstanton/places-thunderforest

A map provider for the Places plugin backed by Thunderforest, offering raster and vector maps in outdoor, cycling, transport and atlas styles. Its only network requests load the selected map style with its glyphs, sprites and tiles. Rendering runs on maplibre-gl through the shared Places GL map implementation, and no background tasks run.
