# nicholas-wilcox/pug-templates-obsidian-plugin

This plugin renders Pug templates inside an Obsidian vault. The README states that it registers a Markdown post processor for pug code blocks, feeds the content of each block to Pug's render function, and puts the current note's front matter into Pug's rendering context as the variable fm, so a template can compose its output from the note's own properties. It also records the use of the FileSystemAdapter API to read files in the vault's configuration directory, quotes Pug's documentation on including and extending partial templates, and states that the repository and its author are not affiliated with Pug.
