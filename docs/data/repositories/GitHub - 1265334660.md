# carbon-softlab/CQuiz

The repository holds CQuiz, an Obsidian plugin that turns Markdown notes into interactive quizzes rendered from a fenced cquiz block that names the quiz, the source note holding the questions and a pass mark. The README documents a question format and block interface, scoring formulas, several render styles, a tag system, spaced repetition, an analytics dashboard, export of results to a note, a strict mode and keyboard shortcuts.
