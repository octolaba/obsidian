# keymasterr/obsidian-random-list

Random List Pick renders an inline button in an Obsidian note from a short token and, when clicked, shows a modal with one item drawn at random from the list belonging to that button, with a roll-again action that never repeats the item currently shown. Scope is decided by headings: a token in a heading draws from that heading down to the next of the same or higher level, a token in body text draws from its nearest ancestor heading, and a token with no heading context draws to the end of the note, always downward and never above the token. Two commands pick without a token in the note, one over every list item in the document and one behaving as though the token sat at the cursor's line. The README frames it as choosing from curated lists such as what to cook or which task to take.
