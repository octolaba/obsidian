# halfday-dev/halfday-rune

The repository holds Halfday Rune, an Obsidian plugin that stores notes encrypted at rest with X25519 age encryption. According to the README, opening an .age file decrypts it in memory, mounts a CodeMirror editor on the cleartext with live-preview Markdown rendering, and re-encrypts the buffer on save or after 30 seconds of inactivity, verifying the round trip before overwriting the file and leaving the file untouched if verification fails. Recorded commands test a round trip, seal an existing note into .age and delete the plaintext after verification, create a note that is born encrypted, decrypt an .age back to Markdown in replace or scratch mode, and rotate keys by re-encrypting every .age file to the current recipients. The README records multi-recipient encryption and states that the plugin is pre-release.
