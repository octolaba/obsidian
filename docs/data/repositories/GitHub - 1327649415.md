# ttsstchou/obsidian-vault-mirror

Mirrors the current Obsidian vault one way into another local folder, such as an iCloud Drive vault that a phone opens for reading. The source is always the vault the plugin runs in and the destination is chosen once; every run rescans both folders rather than reusing an earlier plan, and lists changed Markdown notes separately from attachments and configuration before anything is written. Copies are staged and restored if a commit fails, destination-only files are deleted only after all creates and updates succeed, large deletions are flagged, and the plugin waits for the source to settle before planning. Notes, attachments, hidden files and the Obsidian configuration folder are copied by default; it is macOS desktop only, contacts no cloud API, and edits made at the destination can be overwritten.
