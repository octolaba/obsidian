# zaemyung/yunseul

Chats with the contents of an Obsidian vault through either a local OpenAI-compatible model server, named as LM Studio, Ollama, llama.cpp, vLLM or LocalAI, or an existing Claude Code subscription driven as a command-line subprocess. Optional on-device BM25 retrieval pulls the most relevant notes for each question, and a block under every reply lists the sources the model saw with links back to the originals. A session binds to the file that was active when it began, so appending lands where it started, replies stream as they are generated and can be stopped, and multi-turn conversations persist locally per session. The README describes provider-aware connection diagnostics and marks the project as pre-1.0 with breaking changes expected between versions.
