# jon-heard/obsidian-inline-scripts

Inline Scripts replaces a typed shortcut with text generated by a JavaScript expansion, so that a date shortcut can be replaced by the current date. Shortcuts live in shortcut-files that are either added to a vault or written by the user, and the documentation covers helper functions, popup boxes, calling shortcuts from shortcuts, and setup and shutdown scripts. The README states that it works on all platforms including mobile, with both the new and the legacy editors, and that the plugin is in open beta.
