# joepetrakovich/obsidian-request

Adds web requests to notes through a Markdown code block: the block configures a URL and optionally a method, headers and body, and the response is rendered into the note. A JSONPath expression selects the value to take from the response, a Handlebars template below a separator formats the result, and a `then` field chains a further request using data from the previous response. Full documentation is published separately from the README.
