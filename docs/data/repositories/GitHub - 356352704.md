# mgmeyers/obsidian-icon-swapper

The repository holds Icon Swapper, an Obsidian plugin that replaces the icons of the interface. Its README requires the replacement icons to be supplied in SVG format and records that a whole icon configuration can be exported and imported again. An example configuration built on Boxicons ships in the repository for testing, and the code is licensed under the GNU GPL version 3.
