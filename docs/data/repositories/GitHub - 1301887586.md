# somasekimoto/obsidian-clippings-dedupe

Clippings Dedupe merges the duplicate highlights that the official Obsidian Web Clipper appends to an existing note, while protecting the comments written under each quote. The README explains that the clipper cannot append only new highlights and has no knowledge of the vault, so every re-clip appends all highlights on the page and the merge has to happen vault-side. Whenever a note inside the clippings folder changes, the plugin merges blocks quoting the same text, using the quoted text itself as the identity, keeps the copy that carries a comment and keeps both when two copies carry different comments, folds appended sections back into the main highlights section, and saves a snapshot under its own backups folder before rewriting.
