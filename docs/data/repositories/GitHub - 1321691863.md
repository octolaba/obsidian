# fvandillen/obsidian-azure-devops-workitems

Azure DevOps Work Items references work items inline: a configurable trigger, az# by default, followed by an id or part of a title searches the work item tracking API and inserts a plain Markdown link. While the plugin is active that link renders as a chip showing the work item type, id, title and state in the project's own colours, with a hover card carrying assignee, iteration, area, tags and a description snippet; it falls back to the plain link when the plugin is disabled or the item is unreachable. A command palette picker inserts a reference without typing the trigger, and pasting a work item URL converts it. Authentication is by personal access token, an interactive Microsoft Entra sign-in with PKCE, or an existing Azure CLI session on desktop, and both Azure DevOps Services and on-premises Server are supported.
