# yorha2B0826/crosspost-studio

Pairs a desktop Obsidian plugin with a Chromium extension to create or update drafts on a set of Chinese publishing platforms, among them WeChat Official Account, Zhihu, Juejin, CSDN, Baijiahao and Toutiao, from one Markdown note. It saves drafts only and never publishes: WeChat goes through the official material and draft APIs with the AppSecret held in SecretStorage, while other platforms are driven through the editor already open in a logged-in browser tab, without reading cookies. Plugin and extension talk only over the loopback address, with no cloud relay, telemetry or stored article bodies, and a failure on one platform leaves the other drafts alone. Rendering covers GFM, Obsidian embeds, tables, Mermaid and LaTeX with three built-in themes.
