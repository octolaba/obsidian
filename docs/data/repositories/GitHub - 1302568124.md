# kinrochen/Galley-Studio

This repository holds Galley Studio, whose README describes an Obsidian plugin that turns a Markdown article into standalone HTML with the help of an OpenAI-compatible model or a local Codex or Claude command-line tool, aimed at publishing layouts such as WeChat public accounts. It also describes a workbench inside Obsidian offering preview, visual rich-text editing and a source editor for HTML files, plus a console covering generation conversations, articles, built-in and custom themes, and settings. The README records a mobile mode limited to an article list and a sandboxed preview, and interface languages of Chinese, English or following Obsidian. It is written mostly in Chinese, and no upstream repository description is recorded, so this body rests on that README alone.
