# schemen/embed-metadata

Embed Metadata renders frontmatter properties inside the body of an Obsidian note through an inline marker, which the README presents as a lightweight replacement for Dataview's inline metadata rendering. A marker can also target another note's property by putting a link target inside it followed by the property name after an at sign; the older separator still renders but is deprecated because Obsidian indexes the trailing text as a tag. Markers are replaced in reading view and live preview only, are ignored inside code, and are left unchanged when the key, target note or target property is missing; built-in keys such as filename, basename, extension, path and folder are available when enabled.
