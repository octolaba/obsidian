# yuanlin2004/omm

Obsidian plugin that renders a Markdown outline as an interactive mindmap and turns a mindmap back into a bullet list, with the Markdown file staying the source of truth. Every first-level bullet becomes its own tree with its own top-down or left-right layout, stored per tree in the front matter, and a file switches between the mindmap view and the Markdown editor without leaving the pane. Interaction covers panning, zooming, collapsing and expanding branches, node selection, keyboard structure editing, undo, and opening a node's links, where an internal link shows its alias or basename and opens in a new tab while an external one opens in the browser. Layout packs siblings by their actual node size, a node may hold several lines, export writes a PNG or PDF beside the note, and touch plus toolbar buttons cover mobile use.
