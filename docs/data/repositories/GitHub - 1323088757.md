# Storm-131/flashcard-genius-obsidian

Flashcard Genius studies flashcards that stay in the vault as ordinary Markdown tables, a deck being an H1 title, optional topic headings and tables of Question and Answer columns plus an optional difficulty column rated zero to five. A Library view shows a whole deck at once grouped by topic and can jump to a card's source line in the editor, while study mode shows the question first and reveals the answer on click. Decks are loaded by right-clicking a note or a folder in the file menu and several can be appended into the same tab; a folder holding only images becomes an image quiz in which each filename is the card's answer text. It initiates no network requests and keeps cards, ratings and edits in the vault.
