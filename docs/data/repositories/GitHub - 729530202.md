# IagoGrah/obsidian-object-writer

Obsidian plugin for the writing exercise called object writing, in which an object and the experiences around it are described using all the senses. A ribbon button creates and opens a new note containing a random word and a countdown timer, and when the timer reaches zero the note switches to read mode, which can be disabled. The note's name is built from a configurable pattern with date, time and random-word keywords, and the path for the new file can be changed in settings as well.
