# metagov/koi-obsidian-plugin

The README describes an Obsidian plugin that interfaces with the KOI ecosystem and states that at present it works only with the prototype KOI-net node built for the Telescope project, alongside a corresponding Slack Telescope node. Its purpose is to listen for RID events from a remote KOI-net node server and synchronize knowledge objects into the vault, with the supported RIDs generally restricted to one namespace and each object's raw JSON rendered into readable Markdown through a user-modifiable Handlebars template. An API URL and key are set in the settings, after which a status-bar button initializes the local cache, later events update it automatically and a reformat command re-runs the templating. The README states that network use is limited to that one configured endpoint, that no data is sent to the remote server, and that remote servers are not currently for public use.
