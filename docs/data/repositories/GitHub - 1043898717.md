# crishood/nota-limonada-light

Nota Limonada Light is a light-only Obsidian theme built on limonada-ds, CrisHood's Verde de Basilica design system, with a warm paper base, a forest-green primary and a thin gold accent. The README states that there is no dark mode by design, so switching Obsidian to its dark base falls back to the stock dark theme. Libre Franklin, Libre Baskerville and Fira Mono are embedded in theme.css as base64 because theme policies forbid loading remote assets, and Style Settings exposes reading font size, line width, an optional film grain and a hairline grid backdrop.
