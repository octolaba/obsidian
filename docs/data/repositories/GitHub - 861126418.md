# GnoxNahte/obsidian-tab-panels

This plugin renders tab panels from a fenced code block labelled as tabs, with each tab introduced by a separator line carrying its name and a marker on that name making it the one opened first. The README shows the source beside the rendered result in Live Preview and Reading mode, and offers the sample content for copying into a vault. An experimental cache option, off by default like the other additional features, lets Obsidian process the content inside tab panels as it does ordinary Markdown, so links, headings and tags there behave normally — backlinks and outgoing links resolve, renaming a linked file rewrites the link, headings reach the outline, and tags become searchable and visible in the tags view.
