# plasch/obsidian-youtube-search-plugin

Creates an Obsidian note from a YouTube link, filled with metadata fetched for that video. The URL is pasted into a modal opened from the ribbon icon or the add-video command, populated automatically when the clipboard already holds a YouTube link, and a preview of thumbnail, title, channel and metadata is shown before the note is written. Generated notes carry frontmatter for title, URL, video id, channel name and URL, thumbnail URL, publication date, view count and tags, with settings choosing which properties appear, an optional local copy of the thumbnail and a template built from placeholder variables. The README lists standard watch, short, Shorts, embed and mobile URL forms as supported.
