# delfinchiknakite-netizen/excalidraw-stylus-menu

Companion plugin for the Obsidian Excalidraw plugin that targets stylus drawing with a Samsung S Pen. Tapping empty canvas or the pen's side button opens an insert menu at the pen tip for text, boxed-text stickers, shapes and embedded notes or images, and tapping an object offers quick actions such as drawing an arrow to another object, duplicating or deleting. According to the README it does not fork Excalidraw but calls the public ExcalidrawAutomate API, leaves finger touch uninterrupted, and requires the Excalidraw plugin to be installed and enabled.
