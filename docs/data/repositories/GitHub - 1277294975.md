# lumargh/obsidian-budgets

Envelopes turns a vault into an envelope-budgeting ledger: a monthly target is set per spending category, each envelope drains as money is spent, and whatever is left rolls forward to the next month. Expenses are logged from a quick-entry pane and stored as individual notes carrying date, cost, vendor and category frontmatter, while bank and credit-card CSV exports dropped into an import folder are parsed, deduplicated against existing entries and filed automatically. Bills and recurring charges are matched to vendors, paychecks are recorded and split across envelopes, spending can be tagged by payment method, and a pace view compares the month's spending against how far into the month it is. The pane opens from the ribbon or the command palette, folders are configurable, and everything stays in the vault as Markdown.
