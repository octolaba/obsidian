# elijahchan2019/plugin-html_live_editor

Lets text inside HTML blocks be edited directly in Live Preview: clicking a rendered text node opens an editor popover, Enter saves and Escape cancels. The plugin maps DOM node indexes back to source positions so nested and repeated text resolve correctly and writes the edit back as a document change; larger blocks are rendered as an interactive widget with a hover toolbar instead. Rendered HTML passes through Obsidian's built-in sanitizer before insertion. The README states the plugin is desktop only because click-to-edit relies on caretRangeFromPoint, which is unreliable in mobile web views.
