# ttscoff/Marked3-obsidian

Obsidian plugin that opens the current note, or monitors the whole vault, in the macOS preview application Marked 3. It reads the absolute path of the active note or the vault on disk and asks macOS to open Marked through its own URL handler; when the vault is opened this way, the preview follows the most recently modified file, so switching notes needs an edit. The README records the requirements — macOS, desktop Obsidian and a separately paid copy of Marked 3 — and discloses that the plugin reads absolute filesystem paths and uses Node APIs on desktop to run the open command.
