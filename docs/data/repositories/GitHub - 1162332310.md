# studiogamma/tag-toggler

Tag Toggler hides and shows individual tag nodes in Obsidian's graph view while the notes carrying those tags stay on the graph, which the README contrasts with a search filter. It works by rewriting the tag text in the files themselves, prefixing a tag so the graph engine stops recognising it, with the prefix configurable in the settings. Commands hide or unhide all tags across the vault, and the README states that only the tags are altered while content and links are left alone. It carries an explicit warning that these are bulk edits to Markdown files, advising a vault backup, care that the prefix does not collide with existing content, and noting that processing can be slow on very large vaults.
