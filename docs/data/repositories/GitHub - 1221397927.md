# andrewboldi/obsidian-vault-sync

Vault Sync is a streaming Obsidian sync plugin that talks to GitHub over the REST API rather than git's wire protocol, which the README presents as the reason it works on iOS for vaults of any size including images. It attributes the failure of git-based clients on iOS to packfiles being loaded into memory, and states that fetching one file at a time bounds memory by the largest single file rather than the vault. The documented operations are an initial seed from a recursive tree listing followed by per-file content fetches, a pull driven by a compare diff, a push that creates blobs, a tree delta, a commit and a ref update as one atomic commit, and an interval auto-sync that pulls then pushes.
