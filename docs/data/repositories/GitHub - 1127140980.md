# Konfetigr/obsidian-nice-gallery

This repository holds Nice Gallery, an Obsidian plugin for creating image galleries inside notes. Galleries are declared in markdown code blocks and rendered as a responsive grid with adaptive columns and configurable gaps and column limits, alongside an image viewer with zoom and pan and support for mobile. The README states that its distinction from similar plugins is building a gallery from attachments already added to a note rather than from a selected folder, which it presents as useful for a large knowledge base that is not organized by folders, and it ships an English and a Russian version.
