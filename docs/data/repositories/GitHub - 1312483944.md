# Morning-Liu/kimidian

Kimi Assistant puts a chat panel in Obsidian's right sidebar that drives the Kimi Code CLI as a child process over the Agent Client Protocol, a JSON-RPC exchange over standard input and output. Replies stream as Markdown with collapsible thinking sections and tool-call blocks naming the tool, its status and the target file, and every file edit or command run needs inline approval unless an auto-approve mode is switched on. The active note's path is attached to each message by default, an at sign completes note names and injects the chosen note's content up to a length limit, and selected text can be sent from a command or the editor context menu. A History button restores earlier sessions for the vault, a status bar shows the current model and connection state, and generation can be stopped mid-reply.
