# erykjj/traverture

Traverture parses, converts, previews and inserts Bible scripture references inside Obsidian. References are detected automatically in editing and reading modes across many book name variants and abbreviations, and can be forced by wrapping them in double braces; clicking one opens a modal with the full verse text, cross-reference and footnote tooltips, a study-note pane where available, and buttons to copy the text or open it externally. A selection or a whole document can be parsed into a searchable, sortable sidebar table with columns for the original and three name formats plus book, chapter and verse codes, offering accent-insensitive filtering, column toggles, live translation of book names, duplicate filtering and copying to the clipboard. References can also be replaced with the verse text in two citation formats, or reformatted between full, standard and official name styles.
