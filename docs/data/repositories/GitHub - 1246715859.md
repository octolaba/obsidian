# HornatX/simply-scroll

Repository for Simply Scroll, a plugin that restores the scroll position of a file when it is reopened, with a README written in Chinese and English. It describes recording the position as a file is read or edited and returning to it on the next switch, a mask over the transition to avoid the flicker of the native switch, suppression of a second jump caused by editor focus, and automatic clean-up of stored data when files are renamed or deleted. The README states that the plugin works without any configuration.
