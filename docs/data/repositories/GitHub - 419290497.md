# flolu/obsidian-scroll-speed

Obsidian Scroll Speed changes the mouse scroll sensitivity inside files, on a scale where 1 is Obsidian's default speed and higher values scroll faster. A second setting defines a multiplier applied to the scroll speed while the Alt key is held. Both are set from the plugin's options page in the Obsidian settings.
