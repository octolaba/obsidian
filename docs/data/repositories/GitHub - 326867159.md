# ThePharaohArt/Obsidian-CyberGlow

Cyber Glow gives Obsidian a sci-fi and cyberpunk look built on glow effects and the app's own accent colour, which it applies across most of the theme in dark mode, light mode and on mobile. Its README lists styles it introduced: a line separator carrying the Obsidian logo, custom headers that blend with Canvas, a single unified active line highlight in the editor, and upright stacked tabs. No plugin is required for the theme to work, and the README names Kanban, Surfing, File Explorer Note Count and Language Tool Integration among the plugins it supports, while recommending Style Settings for custom checkboxes, custom backgrounds and stacked tab width. Its changelog records continuing fixes, among them toggleable mini headers in reading view and an option to remove the strikeout style.
