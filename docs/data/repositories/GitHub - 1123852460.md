# cat-left-paw/tategaki-plugin-release

Tategaki adds a vertical writing layout to Obsidian, editing and viewing Markdown in columns that run top to bottom. Its writing and reference mode edits the vault's Markdown directly with no conversion or sync step, and supports paragraph-level source editing, keyboard navigation tuned for vertical text, typewriter scrolling, focus options that highlight the active block or line and dim the rest, outline navigation with heading folding, and outliner-style list editing. Japanese typographic needs are covered by ruby (furigana) in the Aozora Bunko notation and by TCY, either marked explicitly or applied automatically within a configurable digit length. The README states that the plugin is desktop only and that mobile is not supported.
