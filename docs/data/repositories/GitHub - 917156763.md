# tine-schreibt/textflow

textFlow compiles the contents of several Obsidian notes into a flow, a dynamic document that can be edited like any other note, with changes registered and synced in both directions between the flow and its sources. The README records that a flow can be defined from a Dataview query, from folders, tags and properties, or from a bookmark group, and that since version 0.4.0 a flow can be built from embeds instead, which duplicates no data and relies on a separate Sync Embeds plugin for editing in place. It states that the plugin is aimed mainly at long-form writers and offers keyboard as well as mouse navigation, and it carries the author's notice that version 0.4.12 corrupted some Obsidian settings files through a MutationObserver since removed.
