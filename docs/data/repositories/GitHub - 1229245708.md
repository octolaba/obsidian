# anotum/obsidian-anotum

Official plugin for the Anotum reading platform that pulls highlights and their notes into an Obsidian vault as Markdown. An Anotum account with an active trial or subscription is required; the connection is made from the plugin settings by way of anotum.com, after which highlights sync automatically or on demand through a manual sync command. Each highlight is rendered through a customisable template with variables for the highlight, colour, id, note, chapter and index plus a date filter, and the README recommends keeping the block reference so Obsidian can link to it. It also states the plugin talks only to the Anotum API, only to pull highlights, and collects no telemetry.
