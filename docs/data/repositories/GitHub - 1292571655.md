# usero2/obsidian-plugins-json-table-viewer

The README describes an Obsidian plugin that renders JSON data as recursively nested tables, both from code blocks inside notes and as a direct viewer for .json files, whose extension it registers in the file explorer. Each table supports sorting a column through ascending, descending and unsorted states, filtering rows from an input below the headers, and collapsible grouping by column value, with every nested table keeping its own sort, filter and group state. Column headers and vertical-table property keys stay stuck in view while scrolling, and the plugin listens for vault file modifications so note tables re-render when the JSON they reference changes.
