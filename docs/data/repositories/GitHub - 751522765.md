# AidanTilgner/AutogenObsidianPlugin

Obsidian plugin that fills parts of a note in place using OpenAI models. A trigger regular expression decides which text is treated as the prompt and replaced by the generated text, the model is chosen in the settings with gpt-3.5-turbo as the default, and a custom URL setting points the plugin at a proxy or at a local OpenAI-compatible server such as LocalAI, Ollama or LM Studio. A window size setting bounds how many characters around the trigger are sent as context, defaulting to about eight thousand, and the README warns that the number of tokens sent influences the price paid for API usage.
