# soAntifragile/obsidian-paper-flow

Paper Flow watches modified Markdown files for paper URLs, resolves their metadata and maintains the results in the note. Its README records metadata resolution through Semantic Scholar, arXiv, Crossref, OpenAlex and citation meta tags, downloading of open-access PDFs into a vault folder, a managed metadata table written between marker comments, periodic refreshing of citation counts, and a generated Mermaid paper map for the current note. It states the network boundary explicitly: paper identifiers, addresses and titles are sent to those public services while full note content is not uploaded, and it names the generated blocks the plugin may insert or replace in a note.
