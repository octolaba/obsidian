# SEVENTEEN-TAN/cloud-webdav-sync

Cloud WebDAV Sync is described by its README as an experimental sync plugin that stores notes and attachments in a WebDAV-backed repository, using content-addressed objects, validated commit snapshots, server capability checks, conflict detection and a conflict resolution workspace to reduce accidental overwrites. Version 0.9.9 still defaults to planning-only mode and real sync must be enabled explicitly; when it is, the plugin writes immutable SHA-256 blobs, verified commits and complete file trees rather than overwriting a remote folder file by file, choosing a remote HEAD update strategy from the server's detected capabilities. A sync center collects overview, pending changes, history, logs and server capability reports, alongside automatic checks on startup, foreground resume, local changes and configurable remote polling.
