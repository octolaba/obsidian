# voi-tech/obsidian-praxis

Praxis is a warm, dark-first Obsidian theme built from Minimal's foundation and shaped around a compact Praxis design system, with a light mode fallback and a true black dark variant. It keeps Minimal-compatible helper classes for tables, images, iframes, maps, charts, cards and page width, and adds card layouts for tables and Dataview-style tables, image grids and filters, custom task icons for extended checkbox states, soft, outlined and minimal callout styles, and a custom author callout with noicon metadata support. Interface spacing follows a Fibonacci scale, Properties styling is quieted, and a lightweight publish.css accompanies the theme for Obsidian Publish. Installation is manual or through BRAT while the theme is in beta.
