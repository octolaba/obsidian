# juliang22/ObsidianTimestampNotes

Timestamp Notes opens a video beside a note so that notes can be taken while watching. Timestamps written into the note point back into the video, control it directly, and record where each note came from. The README carries a note from the original author saying that another contributor has taken over as active maintainer.
