# jmondo/obsidian-task-limiter

Task Limiter caps how many task items a section of a note may contain, reading the cap from a limit tag written in the section's header or on the line right after it. Tasks beyond the cap are not removed or blocked; they are marked with a subtle background so the overflow is visible. A section runs from the header carrying the tag until the next header of the same or higher level, unchecked bullet tasks count by default, and a setting makes completed tasks count as well. The README motivates it with work-in-progress limits in a Personal Kanban system, where a column is capped to keep attention on finishing.
