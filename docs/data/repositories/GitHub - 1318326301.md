# Aejkatappaja/cendre-obsidian

cendre is a dark-only Obsidian theme whose hues are derived rather than picked: Planck's law at 1300 K for the coals and published emission wavelengths for the rest, converted through the CIE 1931 color matching functions into OKLCH. The colorscheme has three grounds under the same pigments, and because Obsidian lists one theme per repository this one ships the deepest, hard, with medium and soft kept beside it in the colorscheme repository. Its stylesheet and manifest are generated from a single palette table in the upstream colorscheme project and pushed here on each release, so fixes belong in that generator rather than in this repository.
