# noxx/vim-wikilink-nav

The repository carries no description; its README states that the plugin makes Ctrl+N and Ctrl+P move the selection in Obsidian's wikilink suggestion popup, with Enter or Ctrl+Enter accepting, mirroring completion scrolling in vim. The scope is deliberately narrow: only that popup is touched, while the Quick Switcher, command palette and tag suggestions are left alone. The README records that the plugin is desktop-only on Windows and Linux, requires Obsidian 1.4.0 or newer, suppresses the global Ctrl+N shortcut while the popup is open, and reads suggestion container and item DOM classes, so an Obsidian change to those classes would break it silently.
