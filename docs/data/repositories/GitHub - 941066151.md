# Sophokles187/data-cards

Repository for DataCards, an Obsidian plugin that transforms Dataview query results into card layouts and kanban boards. A `datacards` code block carries a Dataview query followed by settings such as a preset — grid, portrait, square, compact, dense or kanban — and an image property, and per-block settings override the global defaults under stated priority rules. The README lists interactive kanban boards with inline editing and task creation, images taken from frontmatter properties through wiki links, embedded wiki links or Markdown syntax, dynamic or fixed columns, a manual refresh button for reading and editing modes, dedicated mobile settings and lazy loading of images.
