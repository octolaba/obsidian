# smcllns/obsidian-plugin-html-docs

HTML Docs renders `.html` documents inside Obsidian, in tabs, in embeds and on Canvas. The pages are rendered inside a sandboxed iframe, so JavaScript in the document may run for interactivity while staying isolated from other notes and from Obsidian's own data. The README describes the plugin as deliberately minimal — a small TypeScript surface with no runtime dependencies, a demo fixture page, and a CLI-driven end-to-end test runner that checks features, embeds, Canvas cards and sandboxing. An optional agent skill is published alongside it so an assistant can author HTML that fits the sandbox, theme tokens, assets and embeds.
