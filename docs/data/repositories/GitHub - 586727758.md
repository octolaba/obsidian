# pedersen/obsidian-brainframe

Brainframe adds two commands to Obsidian at this stage: adding a product bookmark and adding a Git bookmark. Each takes a page title and address copied from the browser address bar and appends it as a link to a file at the vault root — products.md and gitmarks.md by default, both changeable in the plugin's settings tab — and the README states that appending that link is all the plugin ever does to those files. The README describes the plugin as extremely incomplete and released at this stage mainly to make the author's own usage easier, and lists Full Calendar, Heatmap Calendar, Dataview, Citations, Pocket, Templater and the Todoist plugin as community plugin dependencies.
