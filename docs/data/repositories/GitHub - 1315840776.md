# Celestial105/dros-doctrinal-copilot

DROS Doctrinal Copilot is a bilingual plugin that anchors selected text or whole notes to a doctrinal context and queries either a local DROS backend or a direct LLM endpoint. Generated summaries can be written back into the vault as pavilion notes, and output switches between Chinese and English. Settings cover the language mode, the engine mode (direct, proxy or custom), prompt injection, a custom prompt path and insertion position, and the model and API fields for direct or custom endpoints. Version 1.0.6 requires Obsidian 1.8.7 or later.
