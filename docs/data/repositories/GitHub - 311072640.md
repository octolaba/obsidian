# akaalias/extract-highlights-plugin

Collects the highlights of the current note into the clipboard as a bullet list, recognising text delimited by double equals signs, double asterisks and mark tags. The list can be configured to carry a heading with or without the note title, a footnote linking each item back to the source file, each highlight turned into an internal link so the result acts as a map of content, and automatic capitalisation of the first letter. A separate hotkey highlights or unhighlights the sentence under the cursor without leaving the keyboard.
