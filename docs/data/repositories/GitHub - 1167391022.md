# GenoZhou/easy-recall

Easy Recall is a spaced-repetition plugin that creates cards from Markdown using cloze highlights or question-and-answer syntax. Decks are selected through file tags, and reviews use Again, Hard, and Good ratings with queue handling, configurable batches, hints, and mobile support.
