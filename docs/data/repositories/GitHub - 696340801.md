# Artel250/Obsidian-Gemini-Assistant

Chats with Google's Gemini models from inside Obsidian. The README describes obtaining a Gemini API key from Google AI Studio and pasting it into the plugin settings, then starting a conversation either with a New Gemini Chat command or from a ribbon icon. Because the API keeps no history, chats are stored locally as files in the vault with their own extension, so a chat is reopened like any other note, and a default folder for new chats can be set. The README also warns that obtaining a key from the EU or UK requires a Google billing account, with a time-limited free trial and no automatic charge afterwards.
