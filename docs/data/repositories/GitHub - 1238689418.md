# zgfdada/lskypro-auto-upload-enhanced

A maintained fork of the Obsidian LskyPro Auto Upload plugin that keeps the original clipboard and drag-and-drop workflow and reimplements handling of local images, remote images, context-menu actions and progress reporting. It supports both the older Lsky Pro upload endpoint, with a token header and an image form field, and the newer versioned endpoint, with a bearer token and a file field, and adds a configurable download folder that falls back to Obsidian's attachment setting when left empty. Commands upload the images of the current note or of every note in the vault, downloading remote images first and rewriting the links to Lsky URLs, while a download command replaces remote links with note-relative local ones; a single floating notice reports progress with success and failure details.
