# necauqua/obsidian-page-properties

Page Properties adds page tags similar to those in Logseq by giving full-line inline Dataview fields a tag-like appearance and turning each field name into an inner link. Dataview is not a hard dependency, but the README states that the fields are not that useful without it. Two features the README describes as missing from Logseq are also present: for configured fields the value is converted into a link by a specified pattern, so only the identifying part such as a username and repository has to be written, and selected fields can be hidden from the reader view.
