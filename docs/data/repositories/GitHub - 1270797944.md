# lugglory/obsidian-pagemode

PageMode steps through the Markdown notes of a vault and gathers their content into a second pane. Its README records wheeling on a left-side file position bar to move between notes, sending the selection or the whole current note to the nearest Markdown tab on the right, and archiving or unarchiving files and folders while preserving their relative path. Commands cover opening the next or previous Markdown file, archiving and unarchiving the current file and sending a selection or file to the right, while the settings are page-unit scrolling, the archive folder and whether that folder is shown; Obsidian 1.6.6 or newer is required.
