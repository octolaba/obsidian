# Dun8/Chess-Vault

This repository holds Chess Vault, an Obsidian plugin that syncs games from Lichess and Chess.com into the vault, saving them as embedded boards that can be viewed and analysed inside notes. Games can be written to a single file or to one file per day, synchronisation is incremental so only new games are fetched, and it can run automatically at a configurable interval. Each game may be prefixed with its date and, for Lichess only, its rating change, and in daily mode the note's frontmatter carries combined statistics such as wins, losses, draws and win rate. Folders and files are created automatically and the settings are arranged in collapsible sections.
