# K0324-j/profile-manager

Profile Manager compares and edits which community plugins are enabled across several Obsidian configuration folders, for vaults that keep separate configurations per device or workflow. Its README records registering multiple configuration folders, showing each plugin as on, off, not installed or blocked by invalid JSON, toggling state by writing each profile's community-plugins file, copying a missing plugin folder from another registered profile, uninstalling from one profile after a backup, protecting itself from accidental removal, and a privacy mode for screenshots and issue reports. It is equally explicit about the boundaries: it does not install from the official browser, does not restore backups automatically yet, does not sync settings between devices and does not support mobile, and saving is blocked when a profile's configuration file is invalid.
