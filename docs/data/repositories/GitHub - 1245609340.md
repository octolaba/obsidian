# THANSHEER/obsidian-omnichat

Desktop-only Obsidian plugin that embeds AI chat websites in a persistent sidebar, with ten built-in services - ChatGPT, Claude, DeepSeek, Perplexity, Gemini, Grok, Copilot, Manus AI, Kimi and Ollama - and further tools addable by URL. Selected editor text is sent into the active chat with one click, reusable context can be built from notes, open tabs or whole folders and injected, and prompt templates cover repeated workflows. A split view keeps two services visible side by side, sessions stay logged in across Obsidian restarts, and copied responses are stored into the vault with a Save action.
