# HPuntu/obsidian-sidekick

Local Sidekick is a sidebar chat for Obsidian that talks to local language models through Ollama and the Pi agent harness; the README says the author had Codex build it under human oversight. It keeps agent profiles, prompt library files and memory files inside the vault, persists chat sessions with a history page, lists discovered models with capability badges, and renders Markdown and math through Obsidian's own renderer. Context is supplied explicitly: file mentions with an at-sign, including best-effort PDF text extraction, plus helpers for vault search, related-note search, a filename and heading index, link suggestions, allowlisted local commands and fetches from allowlisted HTTPS hosts. Markdown edits arrive as proposals with visible diffs that must be approved before a write, and chats export to a vault folder.
