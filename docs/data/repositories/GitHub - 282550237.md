# kepano/obsidian-minimal

kepano/obsidian-minimal holds Minimal, a distraction-free and highly customizable Obsidian theme for desktop, mobile and tablet, documented at minimal.guide and recorded as the winner of Obsidian's Best Theme award for 2020. Colours, fonts and more are configured through the companion Minimal Theme Settings and Hider plugins, and its background styles include low contrast, high contrast and a true black option intended for OLED devices. The README also documents helper classes for tables and card layouts, focus mode combined with image grid and image width options, alternate checkboxes, hotkeys and support for plugins such as Calendar, Dataview and Kanban.
