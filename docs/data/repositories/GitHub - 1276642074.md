# tinswangtao-web/tutu-emoji-toolbar

Tutu Emoji Toolbar opens an emoji picker from a command or hotkey that inserts an emoji into the editor, note titles, file rename fields, context menus and mobile contexts. Typing filters the list, and an emoji is inserted by clicking it or by moving with the arrow keys and pressing enter. The README records skin tone support, fuzzy and semantic matching, a recently used list, and an option to render emoji through Twitter's set in the preview and the insert modal, which can be turned off in the settings. It credits an Obsidian React starter template and the Emoji Mart project as its basis.
