# zhouhua/obsidian-markdown-media-card

No repository description is recorded, so this body is grounded in the README alone. The plugin inserts media information cards into Markdown notes in Obsidian, for example for books, music or films, through a media-card fenced block whose fields carry the type, URL, title, cover image, publication date, author, rating, width and introduction. The README states that the plugin is a wrapper for the Remark Media Card project and that its card design was inspired by hexo-douban-card, but that it does not fetch Douban information itself and leaves the displayed content entirely to the user.
