# augustin7698/note-2-tag-generator

Note to tag generator is an Obsidian plugin that derives tags from the whole content of a note. The command Generate tags for current note produces tags and adds them to the note, with a language setting choosing the language they are generated in, English by default, and no other configuration required. The README records that generation is done by sending the note's content to the languages.cortical.io keywords REST endpoint, that similar tags are detected and removed, and that the plugin itself stores no data or information about the notes.
