# gansxx/task_manager

Stamps checkbox tasks with dates as they are written: creating a task appends a start date and completing one appends a done date, with no configuration needed. A priority of urgent, high, medium or low can be attached from the editor's context menu or from commands. A sidebar lists tasks from monitored notes and filters them by date range, priority and file path, with frequently used paths saved for reuse. Archiving is optional and, when enabled, removes completed tasks from the source note while keeping their details in the plugin's SQLite database.
