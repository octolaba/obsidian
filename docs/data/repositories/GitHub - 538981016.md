# val3344/obsidian-update-relative-links

This plugin repairs relative Markdown links after a file is moved. The README states that Obsidian's own automatic internal-link update fixes the links pointing at a moved file but not the links contained inside it, so the plugin corrects those paths automatically on a move and also offers a command that batch-fixes links to relative paths across all files. It requires the wikilink option to be off, since the point of relative paths is that notes stay readable in other Markdown editors and on the web.
