# bobstanton/places-openrouteservice

A routing provider for the Places plugin backed by openrouteservice. It builds routes between the waypoints in a block and isochrones around a center point, resolves search terms to place suggestions, reads elevation for the points of a track, and snaps a recorded track to the road or path network. All requests go to the openrouteservice API, no background tasks run, and its map, overlay and routing code comes from places-shared.
