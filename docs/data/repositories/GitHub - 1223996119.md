# mathieubonvaletpro-commits/auto-refresh-explorer

An Obsidian plugin that refreshes the file explorer when files arrive from an external sync tool such as Syncthing, Dropbox or rsync, which Obsidian's own file watcher can miss, especially on Windows. It polls a list of watched folders every few seconds with cheap adapter.stat calls, compares what is on disk against Obsidian's internal index, and injects the missing files as TFile objects while firing the vault create event so the explorer and metadata cache pick them up without a reload. The README states there is no settings UI yet and that the watched folders and interval are constants edited in main.js. The repository carries no description.
