# talwrii/obsidian-header-navigation

This plugin adds commands for navigating between headers in the Obsidian markdown editor and for toggling the folding of a header. The README suggests binding those commands to hotkeys and mentions the sequence hotkeys plugin for defining a prefix key for motion commands. It records that the plugin is influenced by the functions of emacs org-mode, that it uses the remark markdown parser whose source is included in the built `main.js`, and that it is a third-party plugin with no affiliation to Obsidian.
