# long2icc/sonicnote-sync

Repository for SonicNote Sync, a plugin that copies recordings from the SonicNote service into the vault as Markdown, one self-contained note per recording. Its README records that a note carries the transcript with speaker identification and timestamps, an AI summary with key points and action items, a study report where available, and notes written in the application itself. It also documents syncing at startup with a periodic resync every one, three, six or twenty-four hours, configurable frontmatter fields including custom ones, and the requirement of a SonicNote account and a desktop Obsidian version.
