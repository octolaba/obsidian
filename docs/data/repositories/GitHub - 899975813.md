# dukex/obsidian-import-todoist

Imports tasks from Todoist into Obsidian at the current cursor position through a single command. A Todoist API key entered in the plugin settings is required, and the README links to the Todoist integrations page where it is obtained. The README also suggests installing the Tasks plugin for a better visualization of the imported tasks.
