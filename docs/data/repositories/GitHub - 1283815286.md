# jagajaga/obsidian-file-media-gallery

File Media Gallery collects every piece of media a note references and shows it as a gallery reached from the note's right-click menu or a command. It covers embeds and vault links as well as external http and https URLs parsed out of the raw Markdown, so media stored outside the vault, such as in object storage, appears alongside attachments. Items are classified by extension, de-duplicated, and split into per-type tabs for images, video, audio, PDFs and other files, each with a count, and clicking a thumbnail opens a fullscreen lightbox with previous and next navigation. The README states the plugin makes no network requests of its own, writes nothing, and is plain JavaScript that runs on desktop and mobile.
