# gabrielrenderos/obsidian-verse-markers

The repository carries no description; its README presents Verse Markers as an Obsidian plugin for inline verse numbering and cross-referencing, in which bracketed numeric tokens become anchorable targets that can be linked from anywhere in the vault as single verses, ranges or heading-split parts. It was built for study notes over scripture but is offered for any document wanting stable per-paragraph anchors that survive edits, such as legal texts and play scripts. A verse may span several lines, include blockquotes, be broken by headings or footnotes, carry a part suffix so one canonical verse is split into scattered pieces, and be grouped under section markers that turn verses into nested addresses; two further marker forms pause citation so editorial prose is excluded from popovers, embeds and extraction. References address ranges, parts, sections and disjoint sets that skip verses.
