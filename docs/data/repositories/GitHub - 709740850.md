# mariomui/obsidian-sort-frontmatter

Sort Frontmatter sorts a note's frontmatter properties into alphabetical order, recursing through objects, arrays and their nested contents up to five levels deep. It runs from a single command in the palette and acts on the file currently on screen. The README records a deliberate trade-off: no settings tab and no ribbon icon, which keeps the plugin simple at the cost of being less apparent to new users.
