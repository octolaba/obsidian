# oscampo/obsidian-neural-composer

This repository holds Neural Composer, an Obsidian plugin whose recorded description is graph memory for a vault. It runs a local LightRAG server, indexes a watched folder into a knowledge graph, and answers questions by combining entity-relationship traversal with vector search, showing each note's indexing state in the file explorer and the graph itself in a 2D or 3D view. The README records that the plugin starts and stops the Python process itself, that a remote server can be used instead, that Python 3.10 or newer and Obsidian 1.7.2 or newer are required, and that the project describes the setup as fully local when paired with Ollama.
