# seeyou2n1ght/obsidian-MoonReaderNoteSync

The repository holds MoonReader Note Sync, an Obsidian plugin that imports Moon+ Reader highlights and annotations into a vault over WebDAV. Its README records incremental sync through PROPFIND metadata comparison, so only modified files are downloaded and parsed, WebDAV passwords kept in the operating system keychain through Obsidian's SecretStorage API, and a local cache used when the network or server is unreachable. Notes can be inserted at the cursor, appended to a chosen file, or written over one while its frontmatter is preserved, and the settings hold a drag-and-drop editor for the output template.
