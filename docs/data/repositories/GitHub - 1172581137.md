# SecondBrainProd/obsidian-improved-random-note

Improved Random Note opens a random note in Obsidian selected through configurable filters rather than from the whole vault. Filters include and exclude folders, and include tags — both frontmatter and inline — and frontmatter properties by key or key and value, combined with either AND or OR matching. Filter sets can be saved as named presets, each of which gets its own command in the palette and can be picked from a fuzzy-search modal, and a configurable history of the last few opened notes avoids repeats until the candidates are exhausted. A sidebar panel previews a random note with its title, folder path, tags and a rendered excerpt, offering refresh and open actions, and notes can be opened in the current tab or always in a new one.
