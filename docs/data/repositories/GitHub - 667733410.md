# chrisurf/obsidian-voice

Obsidian Voice reads notes aloud through a text-to-speech provider the user already has, presenting a dedicated player in which notes appear as chapters that can be played, skipped and repeated like a podcast app. Playback speed can be changed while listening, and audio can be saved for offline use. The README lists AWS Polly, ElevenLabs, OpenAI, Google Cloud, Azure Speech and MiniMax as supported engines under a bring-your-own-provider model, and states that credentials stay in the user's own account. Its remaining sections cover the player, a feature tour, settings, keyboard shortcuts, connecting a provider and troubleshooting.
