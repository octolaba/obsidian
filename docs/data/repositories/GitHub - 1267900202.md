# dlsdgj/Obsidian-SwiftMatch

SwiftMatch highlights and counts text matches across a vault. Selecting text immediately highlights every match on the current page with a live counter, keywords can be pinned so that several terms are tallied at once, and each keyword group can float independently on screen with its own counter. A background search over the whole vault runs from the same selection through Obsidian's search API, with a floating toggle reporting the number of matched documents and the total number of matches. The README is written in English and Chinese and records later additions such as an outline popup shown when hovering the minimap, which can be pinned and whose opacity is adjusted with Control and the mouse wheel.
