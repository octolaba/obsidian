# tadashi-aikawa/obsidian-various-complements-plugin

This plugin gives Obsidian word completion in the manner of an IDE's auto-completion. The repository README is deliberately thin, pointing readers to a separate official documentation site for how the feature works and reserving the rest for contribution and development notes; no feature list is recorded here. What it does record is the project's own process: feature requests and bugs go to issues, questions to discussions, an issue or discussion precedes a pull request, and development expects Node.js v24 with pnpm scripts for building, testing, verifying and releasing.
