# arangutambo/wine-tracker

Wine Tracker keeps a physical cellar in ordinary Markdown notes: each bottle note carries flat frontmatter plus a wine-inventory block, and every purchase is recorded as its own lot with its price, purchase date, shelf and quantity. Drinking windows can be split into phases, so part of a lot is marked for one span of years and the rest held for a later one, and dashboard, monthly and sidebar views report what is ready, overdue or still cellaring. Commands add, consume and edit lots, log a tasting with a score into the daily note, rebuild the index, and optionally write a spending line for a purchase price. It is desktop-only, requires Obsidian 1.2.8 or later, and makes no network requests.
