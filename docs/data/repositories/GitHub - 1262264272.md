# viggomeesters/obsidian-txt-viewer

TXT Viewer opens plain text files in a dedicated read-only view with stable line numbers, optional soft wrap, in-file search that navigates between matching lines, and a filter mode that shows only matching lines while preserving their original numbers. A status area reports line, character and byte counts, the line-ending type, wrap, filter and render-cap state, and warns about mixed line endings or possible binary content. The README states that large files are capped, rendering the first ten thousand lines in normal mode and the first thousand matching lines in filter mode, with the remainder counted and reported, and that the view refreshes after external changes. It also states that the plugin makes no network requests, does not use the system clipboard, and never writes back to text files.
