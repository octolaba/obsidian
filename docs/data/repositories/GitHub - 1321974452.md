# jamalbalya/jemz-vault-assistant

Jemz Vault Assistant is a dashboard with three tabs covering capture, vault health and retrieval. The Inbox tab lists notes marked with an inbox status or sitting unfiled in the inbox folder and offers eight actions per item, including a keyboard-driven triage mode that walks through one item at a time and reports what was done. The Health tab scores the vault out of 100 across eight checks - broken links, orphan notes, empty notes, unused attachments, duplicate titles, tag inconsistencies, missing frontmatter properties and large files - and applies fixes only after a preview modal and a timestamped backup, skipping files that changed in between. Retrieval works through saved views and visual filters rather than a query language, everything runs locally with no network calls, and it needs Obsidian 1.7.2 or newer on desktop or mobile.
