# annagracedev/obsidian-azure

This repository holds Azure, an Obsidian theme its README calls no-frills and designed for long writing sessions. It offers light and dark mode and colours nesting indicators six levels deep, uses the same font size for body text and headings in editing modes, and hides code comments in Live Preview for use with plugins such as Waypoint. The typewriter work is credited to crashmoney, and the README states that the theme is not under active development although breaking visual issues are still accepted.
