# exmemo-ai/obsidian-exmemo-client

Obsidian plugin that is the Obsidian client of the separate ExMemo service. It searches local notes from a sidebar and, when a server address is configured and a user registered on the ExMemo front end, also searches notes, web bookmarks and quick notes held on that server, with a preview of remote files before insertion. It synchronises local notes to the server for consistency across devices, uploading and downloading single files or batches. Search accepts space-separated keywords or a file name, and the README notes that only the local search works without a server.
