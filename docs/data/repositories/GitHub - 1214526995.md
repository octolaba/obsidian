# sachio222/obsidian-goldilocks-essentials

Bundles several small, individually toggleable interface changes into one plugin: renaming and colouring tabs from their context menu, placing new notes in the folder last clicked with a matching folder menu entry, a print entry for markdown files, pressing a key in reading mode to switch to editing and Escape to return, and a ribbon icon that jumps to the community plugins pane. Two styling options are included, a tighter table density in two steps and a note width cycled through six presets from a status bar widget or a hotkey. The README explains the single-plugin packaging as one install, one settings pane and one update for a curated set of features each too small to ship alone.
