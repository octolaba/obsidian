# goopii/heading-handler

Heading Handler adds Obsidian commands that increase and decrease the heading level of the current line, with additional handling for headings inside lists. The README records smart promote and demote commands that clamp the level to the document hierarchy, computed as the greater of indentation depth plus one and the parent heading level plus one, and that remove the heading once it would fall below its minimum valid level. Plain increase, decrease and remove commands are also recorded, along with multi-line selection support and handling of headings inside unordered bullet lists.
