# woodchen-ink/obsidian-publish-to-discourse

This plugin publishes Obsidian notes as posts to a forum built with Discourse. The README states that a forum address and a user API key are configured first, that publishing runs from a menu at the top right of the document or from the command palette after a category is chosen, and that a discourse_post_id property is written into the note so the post can be updated later, which works only for posts published from Obsidian. Recorded options cover several forum presets each carrying a name, address and API key and selected at publish time, forcing the filename as the title, skipping the document's first level-one heading, converting Obsidian highlight syntax to a Discourse-compatible form, ignoring specified headings, and multi-select of tags from Discourse tag groups.
