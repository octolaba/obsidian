# hyungyunlim/obsidian-social-archiver-releases

Release repository for Social Archiver, whose plugin archives social media posts and other web content into a personal library. The README describes archiving posts, web pages, newsletters and podcasts, with clients for the web, mobile, Chrome, Obsidian and macOS, background job processing with live progress, and synchronisation across devices. It states that the archive belongs to the user's account with local copies in the clients they use, and points to a separate pricing page for quotas and paid tiers.
