# jagaldol/obsidian-day-planner-enhanced

Day Planner Enhanced is an independent MIT-licensed fork of Obsidian Day Planner, aligned with upstream 0.35.1, adding editable calendar views, basic time tracking and a timeline built for readable nested schedules. Timed and untimed child items render inside their parent timeline block instead of becoming separate overlapping blocks, and right-clicking a block edits the parent item, reveals it in the source file, manages nested items or deletes the planner item with its whole subtree. A nested item manager adds root and child items, edits text in place, moves siblings, converts bullets into checkbox tasks and toggles completion, saving only the child subtree back and leaving the parent planner line intact. Plans that cross midnight stay anchored to the day they start in while still appearing in the next day's timeline.
