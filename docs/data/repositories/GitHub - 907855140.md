# narthur/research-quest

Research Quest generates research questions from the note currently open and tracks which of them the writing has answered, keeping a list of active and completed questions. The view is opened from a ribbon icon and refreshed on demand to analyse the current document, after which questions are marked complete once the document answers them. The README states that the analysis and question generation run on OpenAI's GPT models and that an OpenAI API key must be entered in the plugin settings.
