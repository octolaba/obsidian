# d-eniz/jupymd

The recorded description says JupyMD allows Obsidian to be used as a Jupyter notebook IDE. Per the README it makes Markdown files behave like notebooks: code blocks are executed with their output captured below them regardless of viewing mode, variables and imports defined in one block are remembered by later ones, and rendered outputs stay visible after a restart. Notes are converted to and from .ipynb files through Jupytext and kept in sync in both directions, with executed blocks updating the output metadata of the linked notebook. It renders matplotlib plots and pandas dataframe output, and lists Python, Jupytext and Matplotlib as prerequisites.
