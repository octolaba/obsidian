# xRyul/ObsidianMD_Dracula_x_LYT

Dracula + LYT is a theme for Obsidian that mixes LYT Mode with the Dracula theme, crediting LYT Mode to nickmilo and ceciliamay and the Dracula project to Zeno Rocha. Its listed features are Dracula-inspired syntax highlighting and Dracula-inspired blog style headings. Rather than being installed as a theme, the README instructs that its CSS file be renamed and dropped into the vault snippets folder, with Obsidian set to the default theme in dark mode and the snippet enabled in the appearance settings.
