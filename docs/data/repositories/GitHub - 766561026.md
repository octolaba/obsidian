# Benature/obsidian-default-query-in-backlink

Repository for Default query in backlinks, an Obsidian plugin that sets the default navigation state of the backlinks panel shown in a document: a search query, collapsed results, more context, sort order and whether unlinked mentions are expanded. The query is triggered automatically after a file is opened, a custom query is preserved within the same leaf, and updating the setting overwrites the old default; the plugin can also remember the panel configuration per file. The README explains the motivation — many daily notes linking to a note crowd its backlinks view, which the author previously handled by typing a path exclusion by hand each time — and recalls that the core Backlinks plugin and its in-document option must be enabled.
