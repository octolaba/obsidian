# magnitus99/Superpower-Inside

Superpower Inside turns Obsidian into a source-grounded AI research workspace that searches, reads, connects, and verifies relevant vault notes before answering. It presents answers alongside a work log and inspectable source cards with paths and line ranges, and can open, copy, insert, save, or branch research results. The desktop-only plugin supports configurable cloud or local model providers and MCP tools, with the README emphasizing bounded coverage and local vault research.
