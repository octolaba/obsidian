# Jalad25/vertical-timeline-list

Vertical Timeline List renders a task list as a vertical timeline in Reading View when the parent task carries a particular status marker. Its settings tab adjusts dot separation, line padding and detail block spacing, and holds independent light- and dark-mode colour values for the line, the dots, the hover state and the detail backgrounds, with the active set switching automatically when Obsidian's theme changes. Timeline entries that carry details can optionally be made collapsible. The README documents installation from the community plugins browser and through BRAT.
