# JonnyDeates/obsidian-pivotal-tracker-integration-plugin

This plugin connects Obsidian to Pivotal Tracker and pulls tracker stories into a folder of the vault. Configuration needs a Tracker API key from the account settings, the Tracker project ID taken from the project's URL, and a folder location for the stories to be pulled to. Once that is set, stories are fetched by clicking the ribbon icon or running the corresponding command. The README states that the project uses TypeScript for type checking and documentation.
