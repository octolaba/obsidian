# gabrielrubens/pensio-obsidian-sync

This plugin syncs journal notes from an Obsidian vault to Pensio, which the README describes as an AI journaling platform that extracts emotions, tracks relationships mentioned in the writing, and produces weekly and monthly insights. Sync is selective, covering only the configured folders, and runs when files change or on a five-minute interval. The README carries the required disclosures: a free Pensio account is needed, journal content from those folders is sent to pensio.app over HTTPS for storage and analysis, and nothing leaves the device until the user connects and configures folders. Those service claims are the project's own and were not verified here.
