# Lemon695/obsidian-plugin-update-locker

Plugin Update Locker freezes selected community plugins on a known-good version by rewriting the target plugin's manifest version with a very large prefix, so Obsidian treats the plugin as already up to date. Locking and unlocking work per plugin or in batch over the currently visible list, a manual scan detects mismatches between the lock records and the plugin files on disk, and a snapshot of a plugin's script, stylesheet and manifest can be taken before locking and restored later. Further recorded features are a release preview that tries to fetch GitHub release notes when the repository can be resolved, a warning when a plugin's minimum app version is newer than the installed Obsidian, export and import of the lock configuration as JSON files inside the vault, and an English and Chinese interface.
