# jiaoyingxing/resojot

A voice-notes plugin that records audio and carries it through an automatic chain of saving, transcription, AI polishing, and title, to-do and summary extraction, holding tasks until a recognition service is configured. Audio, transcript, polished text, to-dos and summary are written into a Markdown note inside callouts whose action menu can re-transcribe, re-polish, extract to-dos, copy or delete; long recordings are processed in segments and resume after an interruption. Local or cloud recognition services can be stored several at a time with fallback, and a workbench lists recent recordings together with failed, note-missing and orphaned-attachment cases. Desktop-only additions include Windows dictation, recording system audio, writing into daily notes created by other plugins, and managing a user-installed FunASR instance, all documented in a Chinese-language README.
