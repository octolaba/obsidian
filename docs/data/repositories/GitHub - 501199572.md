# mProjectsCode/obsidian-meta-bind-plugin

The repository holds Meta Bind, an Obsidian plugin that puts input fields, metadata view fields and buttons inside a note. Its README explains the binding: a field written in an inline code block is tied to a frontmatter property and kept in step with it, so the property can be read and changed from the body of the note. It gives a toggle bound to a done property as the worked example, where clicking the toggle switches that property between true and false, and points at external documentation alongside an offline help page in the plugin.
