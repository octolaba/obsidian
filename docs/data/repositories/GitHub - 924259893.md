# stfrigerio/sqliteDB

The SQLite DB plugin queries SQLite databases from inside an Obsidian vault. SQL written in a code block fetches rows and renders them as natural lists or in a custom format, with several filter conditions and date-range filtering, while a separate chart block draws pie, line or bar charts from the same data; table structures can be inspected and table rows exported as notes. The plugin works against either a local database file, whose absolute path is configured, or a remote API server, and the README records that a WASM file has to be downloaded from the repository into the plugin folder, and that daily-note and Cloudflare Access integration are available.
