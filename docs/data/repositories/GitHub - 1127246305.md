# satojin219/obsidian-image-md-description-plugin

Image Markdown Description is an Obsidian plugin for editing a description of a PNG or JPEG file as Markdown and storing it inside the image file itself. Opening an image in the vault renders a small editor below it; the text is written to a `tEXt` chunk with the `Description` keyword for PNG and to the EXIF `ImageDescription` field for JPEG, so the description travels with the file outside Obsidian. The editor renders Markdown with a switch between edit and preview mode, auto-completes internal note links while typing, opens a linked note when its link is clicked in preview mode, and saves on blur; existing PNG chunks are preserved, a partial JPEG write is rolled back, and unsupported file types are ignored without their bytes being read. This note is grounded in the README alone, as the repository records no description.
