# IdanLib/ObsidianFastForwardLinkPlugin

Turns an alias note into a redirect, so that several note names can point at one canonical note. A note is created under the alternative name and given a redirect line, after which opening it forwards to the target note. The README motivates this with abbreviations, acronyms, nicknames and alternate spellings that would otherwise be written as separate notes and fragment a vault, and gives paired examples such as a short form redirecting to the full note name.
