# obsidian-ezs/obsidian-ursa

Ursa is a light and dark Obsidian theme whose README describes a zen mode with collapsing side panels and improved single-pane viewing, stated as compatible with Obsidian V0.5. Installation is documented for that era of the application: download the stylesheet, turn on Custom CSS in the plugin settings, and place the file in the vault root folder. The README notes that the font used is Avenir and has to be present locally for the full effect.
