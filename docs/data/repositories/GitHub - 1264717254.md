# lucianski/Forest-Syntactic-Trees-in-Obsidian

Renders LaTeX forest-style syntactic trees inline from fenced forest code blocks, emitting SVG whose node labels are typeset through Obsidian's MathJax pipeline so primes, superscripts and subscripts work. It implements the subset of the forest package linguists use for syntax trees: bracket nesting with brace protection, per-node options such as name, tier, roof, draw, circle, phantom, anchors and edge labels, inheritance through the for-tree and for-descendants propagators, and movement arrows drawn between named nodes with faithful outward and inward semantics. Sizing options taking TeX dimensions — sibling and level separation, inner padding and label font size — can sit on any node and apply locally.
