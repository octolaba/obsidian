# winboost/obsidian-qmd-semantic-search

This plugin adds local semantic search to an Obsidian vault by driving the QMD command-line tool, which does the indexing, embedding and searching itself while the plugin supplies the setup flow, the search modal and the file-opening behaviour. Keyword results appear first and are then refined semantically, refreshing is manual so nothing indexes in the background while writing, the QMD database and configuration are kept inside the vault, and clicking a result opens the note near the matching line. The README records that QMD must be installed separately through Bun or npm, and that on Windows the plugin detects a Bun global install and runs QMD's JavaScript entry point directly because the generated shim can fail.
