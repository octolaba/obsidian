# scrunchds/Command-Center

Command Center adds a dashboard gathering today's note, unfiled captures, open tasks and managed workspaces in one view, with a calendar for dated work, a jump-to target for any note, folder, tag or Bases view, and a Command Deck whose buttons come from Markdown workflow files. Behind it sits an agent layer: routing across thirteen model providers, a local ReAct engine, vault retrieval combining BM25 with semantic search, persistent memory, Markdown and Canvas workflows, voice input, MCP and REST connectors, and headless automation. Every file write passes an approval gate showing the target path and a diff and is recorded in an append-only log, with an optional auto-write toggle and folders that stay permanently gated. API keys live in Obsidian's Secret Storage, local model endpoints are supported, and the plugin is desktop only.
