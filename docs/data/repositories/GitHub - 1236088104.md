# core-hn/pseudobsidian-ization

This plugin pseudonymises and corrects interactional transcripts inside Obsidian for researchers in linguistics and conversation analysis, importing from noScribe HTML and VTT files or raw SRT, CHA, Markdown and text transcripts with the audio file alongside. Terms are replaced either manually, by right-clicking a term and choosing a pseudonym so the rule is saved, or automatically by a local named-entity model that highlights candidates for the researcher to accept or reject; a dictionary scan is offered as a third route. Pseudonyms are wrapped in double-brace markers to stay visible against raw data, the correspondence table is kept out of every export, and exports are written as pseudonymised Markdown or VTT beside word timestamps. A setup wizard on first launch covers interface language, vault folders, the optional local model download and dictionaries from an online catalogue.
