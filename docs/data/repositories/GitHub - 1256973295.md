# liuba1223/super-nutrition-calculator

Super Nutrition Calculator looks up nutrition data for foods and ingredients across several sources — Boohee, Boohee restaurant dishes, USDA FoodData Central, Chinese food composition data and embedded local datasets — and totals a meal from ingredient names and gram weights. It compares more than thirty nutrients against dietary reference intakes for groups such as adult men, adult women, pregnant women and older adults, and writes food details, meal summaries and DRI comparison tables into the current note. The README records configurable paths for FoodData Central Foundation, SR Legacy and custom datasets, sorting that favours records with fuller nutrient coverage, manual rematching and source switching per ingredient, and optional use of an OpenAI-compatible endpoint to normalise nutrient fields and standardise Chinese ingredient names.
