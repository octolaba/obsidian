# Real1tyy/Prisma-Calendar

Prisma Calendar turns Obsidian notes that carry a date into draggable events in month, week, day, list and timeline views. The recorded material also describes mapping project notes into timelines, milestones, dependencies and Gantt-style plans, recurring notes and habits with a heatmap and statistics on streaks, skips and intervals, meeting notes with agendas, decisions and follow-ups, and time tracking of planned against actual time with workload and category breakdowns. Its description states that it imposes no rigid schemas or predefined structures, and the README describes the data as plain Markdown kept in the vault with no migration or new app.
