# exmemo-ai/obsidian-exmemo-tools

Obsidian plugin that applies a large language model to document management and content editing, and therefore needs an API key, base URL and model name configured before use. Its features generate and update metadata such as tags, descriptions, titles, categories and dates, recommend a directory for the current file, locate an insertion point for selected text, build directory summaries and content tags, assist editing by rewriting or continuing text, and create Luhmann-style cards from a file or a selected paragraph. The README recommends enabling content truncation for long documents to control API cost.
