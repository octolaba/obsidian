# isitwho/EasyLink

EasyLink searches an Obsidian vault for content similar to a selected phrase and turns a chosen result into a wiki-link. Its README states that results are ranked by a keyword-based similarity score and shown in a modal with previews and highlighted search terms, and that a link can point at a specific heading or block. The command is reachable from the ribbon icon, the editor context menu and the command palette, and settings cover excluded folders, inclusion of the current file, the result limit and a minimum similarity score.
