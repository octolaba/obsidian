# jqml/native-property-operator

Native Property Operator is an Obsidian plugin for previewing and applying YAML frontmatter property operations across many Markdown notes at once. It maintains a catalog of properties with native types, browses uncataloged detected properties with conservative type inference, and supports saved manual actions that add, remove, rename, retype or set values for multiple properties, plus automatic actions on the same typed targets. Targets are exact files and folder trees canonicalized from the vault, and the README warns that the plugin modifies frontmatter and advises backing up the vault and using preview first; it touches only visible Markdown notes, ignoring the configuration folder, hidden folders, excluded folders and attachments.
