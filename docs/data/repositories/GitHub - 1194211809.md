# gthelding/obsidian-citrus-neo

Citrus Neo is an Obsidian theme whose palette is taken from the MacBook Neo Citrus colour scheme, combining citrus yellows and greens with high-contrast typography. Its README describes balanced light and dark palettes with consistent contrast and headings whose hierarchy is marked by citrus accents. Callouts, tags, tasks, tables and code blocks are styled, interface and text fonts adapt to the operating system following Cupertino theme conventions, and code is rendered with a monospace face.
