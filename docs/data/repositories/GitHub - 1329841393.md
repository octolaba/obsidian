# bobstanton/places-openfreemap

A map provider for the Places plugin that renders vector maps from OpenFreeMap and supports point-of-interest discovery. Its only network traffic loads the selected map style together with its glyphs, sprites and tiles, and it runs no background tasks. The map itself is drawn with maplibre-gl on top of shared Places map, overlay and routing code.
