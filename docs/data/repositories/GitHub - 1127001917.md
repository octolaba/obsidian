# masaki39/daily-notes-timeline

Renders Obsidian daily notes as a timeline view aimed at browsing and review, opened with the Open daily notes timeline command. Only the region around the visible portion is rendered so the list scrolls infinitely, and a calendar interface jumps to a date. The view extracts landmarks for filtering, among them tasks, lists, links, images, callouts and headings, and any search term filters entries and displays them with highlights. The README states the plugin inherits its settings from the core Daily Notes plugin through the Obsidian Daily Notes interface.
