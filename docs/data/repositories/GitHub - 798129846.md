# lorens-osman-dev/Lorens-Obsidian-Theme

This repository holds the Lorens theme for Obsidian, described as a neat theme. Its README is largely a rendered example page showing how headers, inline code, code blocks, bullet and checkbox markers, italics, callouts and blockquotes appear under the theme, including alternate list markers for idea, like, dislike, up and down. It credits the Obsidian community for testing and bug reporting and names obsidian-border as an inspiration.
