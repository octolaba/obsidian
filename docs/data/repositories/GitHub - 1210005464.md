# curryhendry/obsidian-cloud-attach

CloudAttach connects Obsidian to WebDAV and S3-compatible object storage so attachments can remain on remote services. Its sidebar supports browsing, insertion, upload, signed links, media and PDF previews, automatic uploads, and switching between multiple accounts.
