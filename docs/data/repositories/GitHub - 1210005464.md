# curryhendry/obsidian-cloud-attach

Obsidian plugin for inserting cloud-hosted files into notes over WebDAV or S3-compatible object storage, with the stated aim of keeping attachments out of the vault. Its Chinese README names OpenList and Cloudflare R2 as the services it is built against and describes browsing remote directories in the sidebar, inserting Markdown links for one or several selected files, uploading local attachments and updating their references, generating signed URLs, previewing images, video, audio and documents with an optional PDF viewer, automatic upload of inserted attachments, and switching between several accounts.
