# 352662115-hub/worklog-obsidian-plugin

Worklog is a local work-hours tracker that keeps monthly tasks, daily hours, a calendar of completion states and a yearly statistics board inside Obsidian; the README is written in Chinese. Monthly data is stored as local JSON archived in per-year folders, and commands open or create the current month's workbench and jump to another month or to the yearly board. The yearly board shows overall totals, a monthly trend, the share of planned hours by task type, recent-month cards and project statistics that can be narrowed to one month. Settings maintain task types and the default task templates applied to a new month, and can switch on monthly and yearly summary reports generated from the previous period's data.
