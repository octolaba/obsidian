# TeddyCatDeath/canvas-card-merger

This repository holds Canvas Card Merger, a local Obsidian plugin that merges a canvas into a single structured Markdown note with one command. Cards become text blocks in reading order, following the arrows topologically when cards are connected and otherwise running top to bottom and then left to right, while groups become second-level headings with their cards nested beneath and headings inside a card pushed down so they never outrank the group heading. File and image nodes become embeds, link nodes become plain URLs, and relative Markdown image references written inside a card are converted to vault embeds while external image addresses are kept as written. The plugin never overwrites an existing note, appending a number to the generated filename instead.
