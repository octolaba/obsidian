# meniam/obsidian-vocabulary-cards

Vocabulary Cards displays words and their meanings in Obsidian from code blocks whose contents must be valid YAML. Two block types are documented: one previews the words as a card, showing one randomly picked word at a time, and the other previews them as a list showing every word. Entries may be written in a simple form of one word per line mapping to an explanation with an optional transcription, or in an extended form listing word, transcription and explanation as separate keys. Statistics about correct answers are kept in a data file in the plugin folder, and deleting that file resets them.
