# jackydangelo/obsidian-property-from-backlink

Property from Backlink adds two commands that keep a frontmatter property in sync with a note's backlinks. Running the first from a source note writes that note's name into the configured property on every note linking to it: the property is created when absent, left alone when the value is already present, turned into a list when it held a different single value, and appended to when it is already a list. The second command reverses this, removing the property entirely when it held only that value, removing just that entry from a list, and collapsing a one-item list back to a plain value. Both commands are idempotent, the property name defaults to moc and is configurable, and Obsidian 1.4.4 or later is required for the frontmatter API used.
