# theanh97/nuance-excalidraw-pen-sound

This plugin plays writing sounds while drawing on an Excalidraw canvas, with pencil, fountain pen and marker profiles to choose from. Volume and tone pitch are adjustable in the plugin settings, where the profiles can also be previewed without a stylus. The README describes it as the free standalone sound module of a larger productivity ecosystem by the same author, installable through the beta-plugin loader or from a release archive.
