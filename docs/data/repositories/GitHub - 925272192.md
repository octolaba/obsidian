# adiguno/hello-nemesis

This plugin sends the note being written to OpenAI and returns a nemesis response that challenges its ideas. No repository description is recorded, so this body rests on the README alone. An OpenAI API key is added to the settings, after which clicking the nemesis icon in the left sidebar requests a response. The README credits a Reddit post as the reason the plugin was created.
