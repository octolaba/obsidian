# iDoRecall/idorecall

A companion plugin for the iDoRecall spaced-repetition service that creates flashcards, called recalls, linked to specific text in vault notes. When a recall is practised in the web application, its source button opens Obsidian at the linked note with the source text highlighted. Using it requires an iDoRecall account and an API key generated on the account's integrations page and pasted into the plugin settings; the README notes that a separate key is needed for each account.
