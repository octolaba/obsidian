# Daniel-Fiuk/simple-map

Repository for Simple Map, a plugin that turns an image in the vault into an interactive map. Its README describes a code block naming the image, panning and zooming with the mouse including maps that pan without bounds, pinning notes to positions, restricting which notes appear on which map through map identifiers, customising pin icons and sizes, previewing a note by hovering its pin, and filtering pins from a search bar. It states that the plugin is designed around SVG images for sharpness at high zoom but also accepts PNG, JPG, JPEG, WEBP and GIF.
