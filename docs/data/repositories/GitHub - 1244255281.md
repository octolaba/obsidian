# toustifer/obsidian-task-project-tree

Task Project Tree treats a folder as a project: right-clicking it in the file explorer marks it, after which the plugin scans every Markdown file inside for checkbox tasks. It generates an overview note named after the folder holding a progress summary between HTML comment markers, and shows a live completion badge next to the folder name in the file explorer. Subfolders can be projects too, forming a tree in which a parent's totals include its children, and the figures refresh automatically and with a debounce when files are created, modified, deleted or renamed. Unsetting a project removes the marker from the overview note's frontmatter without deleting the note, and two commands refresh the current project or every project in the vault.
