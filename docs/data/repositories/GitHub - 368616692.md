# Obsidian-TTRPG-Community/fantasy-statblocks

Fantasy Statblocks creates, manages and displays tabletop role-playing creature statblocks in Obsidian, with the documentation for its layouts moved to a separate site to which the README now points. The README carries community-use disclosures for several game systems, stating that their trademarks and copyrights are used under the relevant open game or community-use licences and that the plugin is not published, endorsed or approved by those publishers. It also warns that the plugin comes with no guarantee of stability, that bugs may delete data, and that automated backups should be in place.
