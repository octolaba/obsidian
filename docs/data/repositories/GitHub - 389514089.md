# lyonsquark/obsidian-daf-yomi

This plugin prepares a note for the day's Daf Yomi, the practice of learning one page of the Talmud a day on a fixed schedule that takes about seven and a half years to complete. It adds two commands: one takes a date and works out the tractate and page from it, the other takes a tractate chosen from a list plus a page number, prefilled with the current day's values. The generated page collects links to and text from external study resources, and the plugin settings choose which of them the note includes.
