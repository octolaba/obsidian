# leonardsellem/plaud-sync-for-obsidian

This plugin syncs voice recordings from Plaud into Markdown notes in an Obsidian vault, rendering title, date, duration, AI summary, highlights and the full transcript with speaker labels. The README states plainly that it is unofficial and built on a reverse-engineered API discovered by inspecting the Plaud web app, so it may break without notice. It also records incremental sync from a checkpoint, idempotent updates keyed on a stable file identifier in frontmatter, session-token storage through Obsidian's Secret Storage API with a local fallback, retry with backoff for transient failures, and skipping of recordings already deleted in Plaud.
