# SharbelMarshi/obsidian-extended-browser

Extended Browser opens web sites inside Obsidian, in a tab, a resizable floating preview with a back button, a full window, or embedded in a note through fenced blocks. Sites are saved as passkey profiles carrying a URL, a display name and optional sign-in credentials, and a one-off temporary site can be opened from the command palette without saving it. The README describes optional automatic sign-in that scans the page DOM for the most likely login form, including three-field sign-ins and the custom login buttons used by modern web apps rather than only native submit buttons, plus generated site icons with several favicon fallbacks and a monogram fallback. In-tab controls sit in a small hidden notch at the top centre of the page that reveals back, home, reload and close on hover.
