# xhuajin/obsidian-file-preview

Shows a preview of a Markdown file's content underneath its title in the file explorer, indented below the filename. A button at the top of the file explorer shows and hides the previews, and the README states that previews are added to existing files only, so a refresh button in the ribbon has to be used after new files are created. The recorded changelog lists a setting for the indentation of the preview text, the quick switching button, and inclusion of an image from the file in the preview.
