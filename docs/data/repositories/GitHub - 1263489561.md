# sunxiaoqiqi/html-visual-editor-obsidian

HTML Visual Editor opens `.html` and `.htm` files from an Obsidian vault in a visual editor and saves the result back to the same file. Elements are dragged, resized, selected, duplicated, deleted and styled from a toolbar, and text, images, tables, page layouts, canvas elements and typography blocks can be inserted. Saving happens from the Obsidian toolbar button, an in-page Save button or the keyboard shortcut, and it overwrites the opened vault file directly with no system file picker or save-as step, so the README advises keeping backups or version control. Relative image and stylesheet links are temporarily remapped for the preview and restored on save, and pasted base64 images can be written into an `assets` folder beside the edited file.
