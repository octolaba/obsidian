# dgudim/obsidian-universal-renderer

Universal renderer renders diagrams and generates dynamic SVGs from code blocks, covering graphviz, latex, ditaa, blockdiag, asciidoc, plantuml and typst, plus its own refgraph and dynamic-svg block types. The README states that rendering is delegated to system packages rather than JavaScript ports, which the author considered too slow, so those packages have to be installed through the system package manager. It carries the author's own warning that the plugin was written for personal use, may not work properly on other systems and lacks a settings interface.
