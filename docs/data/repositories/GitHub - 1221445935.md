# erbanku/obsidian-memos-ai-sync

Memos AI Sync Plus is a fork of leoleelxh/obsidian-memos-ai-sync that reverts the original's newer gRPC-gateway calls to the classic Memos v0.21 REST API, which returns a plain JSON array and resolves resource URLs in the older pattern, so attachments are downloaded and embedded in the vault. Settings cover the Memos base URL, a personal access token, the sync directory, manual or automatic syncing with an interval, a per-sync limit, a cutoff date, attachment downloading, interface language and optional AI summary, tags and weekly digest. The README records that this fork supports Memos v0.21 and earlier only, and directs users of v0.22 and later to the original plugin or another fork.
