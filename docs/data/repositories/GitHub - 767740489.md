# dromse/obsidian-gamified-tasks

Gamified Tasks joins task management in an Obsidian vault to a rewards system: completing tasks earns coins, coins buy rewards, and a history view lists earnings and spending. All tasks in the vault are shown and can be filtered by completion status, by recurrence or by a search within their content, and a recurring task is saved to history and reappears in the list when its time arrives. A task can carry a difficulty that decides the coins it pays and counters that break it into smaller segments. The README names obsidian-tasks, obsidian-pomodoro-timer and Habitica as its inspiration.
