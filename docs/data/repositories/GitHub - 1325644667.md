# johannes-kaindl/paperless-storage

Embeds documents from a paperless-ngx instance directly in notes: a small stub file stands in for the document, and the plugin fetches the PDF with an API token rather than a public share link, rendering it inline through Obsidian's own PDF viewer. An insert command searches the paperless library and drops an embed at the cursor, and clicking a stub in the file explorer opens the document in a full pane. Downloaded PDFs are cached inside the vault, so a document stays readable offline and is re-fetched only when it changes on the server, with one command to clear the cache and another to rename stubs to their current server-side titles. It needs Obsidian 1.8.7 or newer, a reachable paperless-ngx server and an API token for it, and is desktop only.
