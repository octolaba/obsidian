# Aziz-Zahran/obsidian-chroma-key

This repository holds Chroma Key Paste, an Obsidian plugin that removes the background from images pasted into notes. Right-clicking an image embed and choosing Remove background opens a live preview where the colour to remove is auto-detected from the top-left pixel, picked with an eyedropper on the preview, or entered as a hex code, with adjustable tolerance, edge softening and a toggle that inverts the image colours. Processing writes a new transparent PNG into a dedicated folder in the vault and updates the link in the editor. The README warns that the context-menu entry may not appear unless the cursor sits on an image link.
