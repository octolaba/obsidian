# liamzy2021/Obsidian-CAD-DWG-DXF-viewer

Previews and renders DXF and DWG CAD drawings inside Obsidian notes by embedding the mlightcad/cad-viewer viewer, with Three.js WebGL rendering, pan and zoom, and layer-aware output. The README states that opening a supported drawing renders it in place rather than in external CAD software, and that the parser workers, including the LibreDWG WASM build, are inlined into main.js so a plain three-file release needs no extra downloads. It notes the plugin is desktop only because it depends on Electron Web Worker support, and that the LibreDWG dependency puts the whole plugin under GPL-3.0.
