# pedrogdn/obsidian-time-bullet-plugin

This repository holds the Time Bullet plugin, which adds timestamps to list items in Obsidian. The README records that typing a short marker and pressing Space turns the line into a bullet carrying the current time, that pressing Enter at the end of such a line starts a new item stamped with the current time, and that a hotkey toggles a timestamp on any line, adding the bullet as well when the line is plain text. The time format comes from the settings and defaults to hours and minutes, and the README names meeting notes, daily logs and research observations among the intended uses.
