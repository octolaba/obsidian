# ApoclyReol/Academic_RSS_Reader-Obsidian

Academic RSS Reader collects RSS and Atom feeds into a local SQLite database inside the vault, as a triage queue for the first pass of literature screening. Papers are sorted into five baskets, Unread, Interested, Archived, Hidden and Expired, and a local TF-IDF and logistic-regression model trained on those decisions reorders the unread queue, keeping the keyword evidence behind each recommendation. Feeds can be added by hand or imported from OPML, updates use ETag, Last-Modified and HTTP 304 with bounded concurrency, retries and backoff, and titles, authors, years, DOIs, links and abstracts are extracted when the feed supplies them. Title translation and review of pending papers by an OpenAI-compatible service are optional, and the plugin is desktop-only, requiring Obsidian 1.13.0 or later.
