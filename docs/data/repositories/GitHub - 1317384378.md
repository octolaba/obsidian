# vuecwiz/obsidian-ntfy-sync

Ntfy Sync subscribes an Obsidian desktop vault to a configured ntfy server and turns messages published to its topics into Markdown notes. Reception uses an NDJSON stream or periodic polling with replay, reconnect backoff and automatic fallback to polling, and accepted messages land in a durable inbox before processing, with idempotency markers preventing duplicate writes. Ordered first-match rules select a destination by topic, title, content, tags, priority, URL or attachment metadata, and templates decide the target note, the inserted content and the attachment path; same-origin attachments are downloaded under redirect and size limits, while cross-origin ones stay as escaped links. A right-sidebar composer publishes notifications back to a topic, a test dialog checks routing, and processing outcomes can optionally go to a separate result topic.
