# riogesulgon/obsidian-cryptopad

The repository holds CryptoPad, an Obsidian plugin that encrypts and decrypts text inline from a keyboard shortcut, with encrypt and decrypt tabs in one modal and optional passphrase memory in the settings. The README states that it uses AES-256-GCM through the Web Crypto API with PBKDF2-SHA256 key derivation over 200,000 iterations and a random salt and initialization vector per encryption, that everything runs client-side with nothing sent anywhere, and that it works on desktop and mobile.
