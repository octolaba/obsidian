# fjdu/obsidian-latex-unicode

LaTeX to Unicode is described as converting LaTeX commands into Unicode sequences, on the grounds that Obsidian supports LaTeX but Unicode symbols are sometimes enough. The README says a command opens a box in which LaTeX is typed and the converted result can then be inserted, and its examples cover superscripts and subscripts, fractions, arrows, radicals, set membership and blackboard-bold letters. It credits the unicodeit project as the basis of the conversion and states that unicodeit's licenses and source are included in the repository.
