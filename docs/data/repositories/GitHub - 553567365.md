# birneee/obsidian-adwaita-theme

Adwaita is an Obsidian theme in the style of Gnome's Adwaita design language, with the stated goal of making Obsidian look more native on Gnome desktop environments such as Ubuntu and Fedora. It restyles window buttons, tabs, icons, colours and fonts, supports both the dark and the light base colour scheme, and exposes customisation through the Style Settings plugin. Rounded window corners are listed as still to be done, with a Gnome extension named as the workaround. Besides the community theme store, the README documents an install driven by the just task runner and a manual copy of theme.css and manifest.json into the vault, and it records that the CSS is built from Sass.
