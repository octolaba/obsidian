# marty331/status-bar-clock-obsidian

Status Bar Clock adds a clock to Obsidian's status bar; the README says the author wrote it because the time is not visible when working in full-screen mode. One option is offered for now: with seconds turned off the clock shows hours, minutes and AM or PM, and with seconds turned on it updates every second. The README states the plugin is free and points to a donation link.
