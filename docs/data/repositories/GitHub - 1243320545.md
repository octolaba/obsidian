# stephanteig/obsidian-lumen

stephanteig/obsidian-lumen holds Lumen, a set of six colour schemes for Obsidian, switchable from a single setting: Paper and Ink, Lavender Fog and Iron Press in light, and Nordic Slate, Soft Dusk and Tokyo Night in dark. All six share sans-serif typography, gradient underline links revealed on hover, accent-tinted blockquotes with a left border, independently coloured bold and italic text, and a six-level heading hierarchy with explicit size, weight and colour at every step, including H5 styled as a small-caps section label.
