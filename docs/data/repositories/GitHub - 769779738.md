# TarsLab/obsidian-ai-zhipu

AI Zhipu connects Obsidian to the Zhipu API for generating content, generating images from text and answering questions against a knowledge base, driven by prompt templates the user can customise. On first load the plugin creates an Aizhipu folder in the vault holding Chinese and English prompt template files; a Zhipu API key in the settings and a network connection are required, and the README warns that API calls are billed and that image generation consumes considerably more tokens. Generation runs as a command over the selected text, line or block, a multi-turn conversation is delimited by horizontal rules, and a detail view shows the previous exchange's prompt and token usage.
