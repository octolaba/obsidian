# viggomeesters/obsidian-sql-viewer

Repository for SQL Viewer, a read-only plugin for inspecting local SQLite database files in the vault. Its README records that it opens files with the sqlite, sqlite3 and db extensions and also recognises write-ahead log and shared-memory sidecar files, offering to open the base database instead of failing silently. It lists database metadata such as page count and size, encoding, schema and user version and application identifier, listings of tables, views and indexes, schema and stored source SQL, capped and lazily loaded row previews, filtering, and a query runner limited to a single read-only statement. The README states plainly that it is not an editor, migration tool, export tool, charting application or general SQL environment.
