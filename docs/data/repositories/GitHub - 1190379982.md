# search5/pumice

Pumice is the Obsidian client half of a self-hosted sync system whose server, pumice-server, is a separate Python project that the user runs. Files are compared by delta so only changed files move, and transport is gRPC-Web over HTTP/2 with many files multiplexed on one connection, falling back from a direct streaming upload over a single fetch request when the server is not reachable over TLS. The authentication token is a static string kept in Obsidian's own secret storage on desktop and mobile alike. The README also records sync history browsing with file recovery, automatic local snapshots with retention, selective publishing of chosen folders, Korean and English localisation, and a settings tab built entirely through the declarative settings API.
