# OptimumMost001/move-completed-tasks-down

This repository holds Move Completed Tasks Down, an Obsidian plugin that relocates a task to the bottom of its list five seconds after its checkbox is ticked. Any sub-items nested under the completed task move with it as a unit, sorting is confined to the checked task's sibling level so parent and other nested groups are never disturbed, and incomplete tasks keep their original relative order while completed ones accumulate in the order they were completed. The README records that unchecking the task before the delay expires cancels the pending move entirely.
