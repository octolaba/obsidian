# xlrve/ollama-assistant

Obsidian plugin that connects a local Ollama model to the vault through three separate modes: Edit, Discuss and Web. Edit mode takes a piece of text and an instruction, explains the change and then offers to replace the original, keep the original under a spoiler, or feed the result back into context; Discuss mode is a chat that remembers a configurable number of past messages; Web mode looks up specific facts and needs a model configured for tool calling, which the plugin detects for itself. History is switched off in two of the three modes so that small models stay focused on one task, and context can be added from notes through the right-click menu, an add button, drag and drop, or a hotkey.
