# zincplusplus/habit-tracker

Habit Tracker 21 draws a grid of daily habits in Obsidian: a habits folder holds one file per habit, and a `habittracker` code block naming that folder renders the grid, which is clicked to log a day. No repository description is recorded, so this body rests on the README alone. Individual files or whole folders can be tracked, a habit's title can be overridden from frontmatter instead of taken from the filename, streak counting accepts a `maxGap` tolerance that keeps a streak across short breaks while counting only completed days, and clicking a date in the header opens the daily note for that day. The README also lists theme matching through Obsidian CSS variables and a debug mode.
