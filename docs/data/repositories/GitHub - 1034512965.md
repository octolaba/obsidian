# vsme/obsidian-card-viewer

This repository holds an Obsidian plugin that parses and displays card views for movies, television shows, books and music, showing covers alongside metadata. Cards are written as code blocks such as card-movie, card-tv and card-book, carrying fields including id, title, release date, region, rating, genres, overview and a poster path. The README also describes image code blocks previewed in a grid with a lightbox in reading mode, optional rendering of HTML code blocks, and a usage example driven from the Templater plugin.
