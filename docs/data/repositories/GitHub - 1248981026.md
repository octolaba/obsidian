# demartinogiuseppe/antinomia

Obsidian plugin for what its author calls Personal Tension Management, the counterpart to personal knowledge management: instead of organising what is known, it organises what does not fit - contradictions, tradeoffs, anomalies, persistent doubts, weak signals and conflicts between goals. Every note carries an `antinomia_type` frontmatter field placing it in one of six layers, starting with `tension`, a contradiction between two positions carrying a status and links. The README is explicit that this is not a decision-support system: the pairs its Contradiction Hunter proposes are prompts for thinking rather than a basis for real decisions, because models can hallucinate, oversimplify or misinterpret. Version 1.7.8 is on the community store for desktop and mobile.
