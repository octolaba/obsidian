# KFreon/nextcloud-link-fixer

Nextcloud Link Fixer is an Obsidian plugin that repairs wiki-links damaged by Nextcloud Text: opening a Markdown file there escapes the brackets, so a double-bracket link is rewritten with backslashes even though it still renders roughly correctly. The plugin can repair such links automatically when a file is opened, which is off by default and enabled in the settings. A fix-wiki-links command performs the same repair on demand.
