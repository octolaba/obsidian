# ziangchen7/obsidian-everforest-clarity

Everforest Clarity ports the Everforest palette to Obsidian for long-form reading, in particular LaTeX-heavy notes and mixed CJK and Latin text. Its dark background matches the Everforest Dark Hard terminal value exactly, while light mode uses darkened hues because the terminal light palette drops to about 2.2:1 on this ground; every pair is checked against WCAG AA, the lowest being 5.79:1 dark and 4.61:1 light. Inline math containers get a zero line height so formulas stop stretching paragraph spacing, display equations scroll instead of clipping, and Latin fonts sit ahead of CJK fonts in the stack with a taller line height. Bold text is colored, callouts are drawn with a real background, and seven highlight and text colors are available through nested Markdown or CSS classes.
