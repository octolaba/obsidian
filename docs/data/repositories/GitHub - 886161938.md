# wenlzhang/obsidian-uri-converter

URI Converter rewrites Obsidian URIs, and Advanced URIs, as Obsidian internal links. The README states that note links, heading links and block links are all handled, and that both bare URIs and URIs written in the Markdown link form are converted. The author presents it as a response to copying such links out of Obsidian into external tools and later wanting them back as internal links.
