# NoHeartPen/obsidian-monokakido-copilot-plugin

Monokakido Copilot searches the Dictionaries by Monokakido application from Obsidian: the whole interaction is a double press of the Option key. The README documents installation from the community plugins browser or manually from a GitHub release, links a frequently asked questions page, and is offered in English and Japanese. It carries a disclaimer that the plugin is not affiliated with the Japanese company that owns the Monokakido trademark.
