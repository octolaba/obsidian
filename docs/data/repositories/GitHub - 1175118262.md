# dsebastien/obsidian-transcriber

Transcriber converts images in an Obsidian vault into Markdown using Ollama vision models running on the same machine, and writes a `.md` file next to each image with the extracted headings, lists, tables and code blocks. A single image is transcribed from the command palette or the right-click menu, and a whole folder can be batch-transcribed with optional subfolders and per-file progress. Vision models can be installed, selected and removed from the command palette without a terminal, and the transcription prompt is configurable; the README names several recommended models and states that any other Ollama vision model can be used. It records Ollama running locally and desktop Obsidian as prerequisites and states that no data leaves the computer.
