# diagrammo/obsidian-dgmo

Renders Diagrammo diagrams inline from a dgmo code block, in reading mode and live preview on desktop and mobile. The README lists more than fifty chart types from one plain-text language, grouped as data and charts, software and architecture, project and process, business and strategy, and people, places and bodies; the countdown and clock types tick live inside the note. Because the diagrams are plain text they stay searchable in Obsidian and diffable in git or Sync history, and a command creates an example note rendering every chart type with sample data.
