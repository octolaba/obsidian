# dennisseidel/obsidian-todoist-link

Todoist Link creates Todoist projects and tasks from Obsidian. One command makes a new Todoist project named after the current file and inserts a link to it at the cursor, while the other sends the current line to the Todoist inbox as a task; both add deep links so that either side can be reached from the other. A Todoist API key is entered in the plugin settings, and the README credits an equivalent Things plugin for the initial idea and code.
