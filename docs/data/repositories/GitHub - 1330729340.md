# ruzx/ChemEdit-Universal

ChemEdit Universal draws and renders chemical structures inside notes using OpenChemLib, turning smiles and mol code blocks into SVG images and opening a touch-friendly editor from the ribbon or the command palette. A mol block can point at a .mol file stored in the vault, and editing the rendered image writes the change back to that file. A command calculates formula, molecular weight, exact mass, LogP, LogS, polar surface area, hydrogen bond donors and acceptors, rotatable bonds and stereocenters for a selected structure and inserts them as a summary block, with a chemprops block available as a persistent widget. Rendering and calculation run offline on desktop and mobile, and settings control the default image size and whether pasted structures are wrapped in a code block automatically.
