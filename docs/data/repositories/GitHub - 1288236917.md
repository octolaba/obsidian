# pieofmind/pie-task-plugin-obsidian

Pie Tasks manages tasks that live in plain Markdown files, presenting the same file as a Kanban board, a list, a month calendar or a stats dashboard. Ticking a task, moving it between lanes or editing its details writes back into the Markdown, and editing the file by hand updates the board. Several boards can be kept side by side, each pointed at its own Markdown file with its own name, colour and icon, and a quick-setup button creates any missing task, people or dashboard files. The README states that the plugin works on desktop and mobile and uses no Node or Electron APIs.
