# imfenghuang/obsidian-magic-move

This repository is an Obsidian plugin for animating code blocks, based on the shiki project of the same name. The README states that it works in Reading Mode, where several successive code blocks are wrapped in one outer fence — optionally marked as markdown so the inner blocks are highlighted while editing — and the transition between them is animated. Code-block syntax is unchanged and syntax highlighting is supported.
