# dualyze-ai/dualyze-notes

Dualyze Notes scans a folder or a whole vault for notes that overlap in titles, headings, tags, links and content, and lists the results in a side panel. The README states that a pair can be compared side by side with a score broken down across five dimensions and with common and unique keyword chips, that similarity scoring runs locally and notes are not sent to an external AI service, and that the threshold, scan scope and per-dimension weights are configurable. Merge scaffolds are written into a merge-drafts folder and comparison reports into a reports folder, leaving the original notes unmodified.
