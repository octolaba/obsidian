# 0xroko/obsidian-arena-plugin

Unofficial Obsidian plugin that saves Are.na blocks as notes in the vault. A command inserts a block into the current note and stores it locally in an are.na folder, using the block id as the file name so that no database is needed, and a saved block can be opened in the browser. The README states that all block types are supported and that saving private blocks requires a personal access token created through the official Are.na developer application page.
