# bakanovskii/obsidian-sqlite-db-viewer

Repository for an SQLite database viewer and manager that runs a WebAssembly SQLite engine inside Obsidian, so a database file in the vault can be queried, edited, built and visualised without a server or external libraries. Its README frames the design as the plain-file philosophy applied to structured data, one database file rather than many notes, and includes an introduction to tables, primary keys and SQL for readers new to databases. It also shows the same file being opened outside Obsidian with the standard command-line tool, to make the point that nothing is locked in.
