# UnterrainerInformatik/safeLearn-Obsidian-plugin

This plugin provides visual aids in Obsidian for the Markdown tags used by SafeLearn, which the README describes as an open-source Node server that publishes teachers' learning materials behind a login backed by a school directory or Keycloak, rendering them to responsive HTML and Reveal.js. Three tag families are given visual formatting while editing: a fragment marker for content that should appear incrementally in Reveal.js slides, permission blocks delimited by a triple-at marker and a role name to separate pupil-facing from teacher-facing content, and side-by-side markers that create multi-column layouts for wide slides. The README documents manual installation by copying the plugin folder into the vault's plugins directory and records Obsidian v0.15.0 or later as the compatibility floor.
