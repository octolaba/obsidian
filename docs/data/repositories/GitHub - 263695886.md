# dogwaddle/obsidian-gastown-theme.md

dogwaddle/obsidian-gastown-theme.md holds Gastown, a light CSS theme for Obsidian which the README records as compatible with Obsidian v0.6.5 and installed by placing obsidian.css in the vault root with the Custom CSS plugin turned on. A note dated August 2021 states that the theme has effectively been abandoned because the author moved to maintaining Lizardmen Zettelkasten, and invites others to fix it up by pull request. The README recommends installing the free Merriweather and Open Sans fonts for the intended visual effect.
