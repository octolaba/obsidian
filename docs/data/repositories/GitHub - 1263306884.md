# lumargh/better-bujo

Better Bujo renders bullet-journal markers in place of Obsidian's checkboxes, in both Reading mode and Live Preview. A plain dash still starts an ordinary list, a Markdown task becomes a bullet that can be clicked to complete it, a migrated task shows as `>`, a task sent to the future log as `<`, and an event as a small circle that is also clickable. The README records that the plugin does not work with the Border theme and credits the earlier obsidian-bujo-bullets plugin and Ryder Carroll's bullet journal method as inspiration.
