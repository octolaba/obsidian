# DyllonWright/Obsidian-External-Attachments

External Attachments renders attachments stored outside an Obsidian vault, on an external drive, a NAS share or a second cloud account, so wikilinks keep resolving after the heavy files are moved out to reclaim sync quota. The plugin does nothing while Obsidian resolves an embed itself; only a genuinely broken embed is retried against the configured external folders in order, with the first match winning, and optionally against a filename index built by searching subfolders. Matching is by filename, and a found file is read and rendered in place as an image, video, audio or PDF, with an optional dashed outline marking it. An embed whose file is found nowhere is left alone, so a broken link stays visibly broken.
