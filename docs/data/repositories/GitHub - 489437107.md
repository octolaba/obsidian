# artisticat1/obsidian-tikzjax

This plugin renders LaTeX and TikZ written inside tikz code blocks, covering graphs, figures, circuits, chemical diagrams and commutative diagrams. Rendering uses the standalone document class, so a block includes the document environment and loads whichever of the available packages it needs. The README lists chemfig, tikz-cd, circuitikz, pgfplots, array, amsmath, amsfonts, amssymb and tikz-3dplot as the packages available.
