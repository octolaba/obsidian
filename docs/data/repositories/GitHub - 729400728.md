# kursad-k/obsidian-openasmd

This plugin lets files that are not Markdown be opened and edited in Obsidian as if they were markdown files. The extensions to treat this way are listed, separated by commas, in the plugin settings, and the plugin has to be disabled and enabled again after that list changes. The README gives Obsidian 0.10.12 as the minimum version, because the required APIs were added there.
