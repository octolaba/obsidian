# Vinzent03/obsidian-advanced-uri

Advanced URI drives Obsidian through URIs, so a workflow can be automated without keyboard or mouse input. The recorded actions include opening files, workspaces, headings, blocks, lines and settings in tabs, splits, windows, popovers or silently in the background, switching between reading, source and live preview, creating and editing files including appending or prepending to a specific heading, block or line, search and replace with regular expressions, calling Obsidian and plugin commands, reading and editing frontmatter properties, and focusing canvas nodes.
