# Quorafind/Obsidian-Canvas-Presentation

Displays Canvas cards in a chosen sequence, as a slideshow. The README describes marking the first card with a Mark Slide Number command, which creates a further card on the canvas holding the ids of the marked cards, then adding the remaining cards one by one in order. Next Slide and Previous Slide commands move through the sequence. The README states that link labels are not supported yet.
