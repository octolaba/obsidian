# Docli-ru/docli-connect

Repository for Docli Connect, an Obsidian plugin that synchronises a vault two ways with a workspace on a docli.ru server. The README documents pairing through a server URL and a personal access token, an explicit lock step before syncing starts, and a status bar indicator for live, polling, error and paused states. Overlapping edits are kept as separate conflict files rather than overwritten, and the plugin is stated to work on desktop and mobile.
