# coignard/obsidian-daily-notes-tweaks

Adds two daily-note behaviours to Obsidian: a command that opens a random daily note from the vault, and an option that automatically switches past daily notes to reading mode when they are opened. The README states today's daily note stays in the default editing mode, and that the automatic reading mode toggle is enabled by default.
