# timrogers/obsidian-share-as-gist

Share as Gist publishes a note as a GitHub gist, either private or public, and works with GitHub.com and with GitHub Enterprise Server. A gist can be updated when the note changes or deleted again, and a table of contents can optionally be included in it. Authentication uses a personal access token with gist scope, or a fine-grained token with read-write access to gists, pasted into the plugin settings.
