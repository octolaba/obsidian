# mdelobelle/fileclass

Defines reusable note types, called fileClasses, each with a fixed set of typed fields, so that frontmatter follows a schema. Notes of a type get guided input for those fields through dropdowns, date pickers and link autocomplete, and the plugin flags notes whose field is missing or holds the wrong type. Querying and display are left to the core Bases plugin. The README presents it as the successor to Metadata Menu by the same author, frontmatter-only and without a Dataview dependency, and directs users who rely on Dataview inline fields to stay on Metadata Menu.
