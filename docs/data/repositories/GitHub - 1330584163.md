# foxycape/obsidian-pdf

Foxycape PDF is a PDF reader for Obsidian in which each new highlight can create or update a Markdown note of the same name and append the excerpt with a back-link. Text and image citations copy as Markdown carrying deep links built from page, selection and markId anchors, so a pasted quote or an extracted PNG can be reopened at its original region. Embedded images can be previewed, copied or downloaded directly, a dragged region can be captured across a page gap as one stitched image, and copied text has its soft line wraps removed. Highlighter, wavy and straight underline styles feed a filterable highlight list, grayscale page colours can be remapped to the theme, and Obsidian's own page and selection links continue to open.
