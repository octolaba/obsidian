# ahseyg/special-callouts

Repository for Special Callouts, a plugin that extends Obsidian's callouts with additional styling. Its README records customisation of background, text, border, gradient, neon glow and icon written directly in the callout's Markdown, named style presets that can be reused, splitting a list into two to four columns, a visual grid layout builder, typography options, use of the column layouts with Dataview queries, and import and export of styles as JSON. The repository also carries a separate usage guide and a Turkish translation of the README.
