# HEmile/juggl

The recorded description presents Juggl as an interactive, stylable and expandable graph view for Obsidian, designed as an advanced local graph view. The README explains that its workspace mode lets a graph be built from the nodes relevant to the current project, expanding only chosen parts so that the screen never carries too much information, and that nodes can be selectively browsed, hidden and pinned in place. Styling is controlled through CSS, YAML and a style pane built on the Cytoscape.js library, covering node colours, shapes, sizes and icons, and images can be included in the graph.
