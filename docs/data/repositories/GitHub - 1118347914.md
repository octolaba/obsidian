# thenewhobbyist/obsidian-countdown-timer

The repository holds Countdown Timer, an Obsidian plugin that renders a countdown from a fenced block carrying a title, a target date and an optional time. Settings choose the date format, toggle the title and the day, hour, minute and second labels, and decide whether an expired timer counts up or reports completion. The README states that the timers render in reading view only and that consecutive blocks with no blank line between them appear side by side.
