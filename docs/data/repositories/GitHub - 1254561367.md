# kaiso12/todoapp

TodoApp Blocks embeds a task manager inside any note through a todoapp code block carrying an identifier, so several independent task spaces can exist in one vault by changing that identifier. Each space keeps its own projects with task counters, today, tomorrow, week and all views, four priority levels, inline editing, completion with strikethrough, and task notes opened in a popup. Task data is stored as JSON in a dot-prefixed folder inside the vault and task notes as ordinary Markdown files, and the README states that no account, API key, external server or cloud sync is involved and that no telemetry, analytics or external requests are made. It records that recurring tasks, notifications, calendar and Todoist synchronization, natural language date parsing and collaboration are deliberately not included.
