# tzengyuxio/obsidian-english-palette

English Palette appends English keywords to every command name in Obsidian's Command Palette, so commands stay findable when the interface language is not English. The README explains that the keywords are derived from each command's id, which is always English, and shown in brackets after the localized name, and that the original names are restored when the plugin is disabled.
