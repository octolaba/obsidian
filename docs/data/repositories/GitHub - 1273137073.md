# AllenX95/sidebar-mimocode

Sidebar MiMo-Code embeds the MiMo-Code command-line agent in an Obsidian sidebar, making the active vault the agent's working directory so it can read, write, search and run approved commands against vault content. The README lists a sidebar chat with streaming responses, cancellation, resume and reloading of the agent's native history, its build and plan modes with custom permission rules, inline editing with a diff preview, image attachments, an instruction mode, slash commands, skills and custom subagents, and multiple chat tabs with automatic titles. It records what is not supported — forking and in-app MCP management, so MCP server mentions are not exposed — and its requirements: Obsidian Desktop 1.7.2 or newer, a specific MiMo-Code CLI version installed globally, and model provider credentials configured for that CLI.
