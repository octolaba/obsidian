# EZRA-DVLPR/WheelPicker

Renders a spinnable wheel from a list written inside a `wp` code block, so one item can be picked from it at random. A title is given on the first line between single hyphens and each following line becomes a slice of the wheel; clicking the central Spin button turns it and selects an entry. The README states that the plugin is intended for reading view but works in editing view too, and that a title is optional while at least two rows of data are required.
