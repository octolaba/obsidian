# mateusznitka/obsidian-paragraph-break

This plugin changes what the Enter key does in Obsidian's editor. As its README explains, default Markdown behaviour makes a single Enter a soft line break and requires two presses to start a paragraph, while with the plugin a single Enter starts a new paragraph as in an ordinary text editor. The README records the exception that inside a list or a code block the default soft line break is kept.
