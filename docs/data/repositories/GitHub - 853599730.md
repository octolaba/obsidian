# xRyul/link-navigation

Link Navigation is described as navigating between incoming and outgoing links several levels deep, including links from Canvas files. Its README presents the links as a hierarchical view with a configurable traversal depth and a caching mechanism, and it explains that Obsidian does not by default surface links coming from Canvas, so a note embedded or mentioned in a canvas is otherwise hard to trace. The author records the motivation as speed and as a way to move between notes for someone who does not use folders, comparing the plugin's load time with the time earlier DataviewJS queries took; those timings are the README's own measurements, not a result verified here.
