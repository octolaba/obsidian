# somesanity/draw-io-obsidian

Repository for a draw.io plugin that integrates the draw.io editor into Obsidian. Diagrams are stored as ordinary SVG files whose names end in `.drawio.svg`, which is how the plugin recognises them, and the README states that the editor runs offline from a local server on the machine. Shapes can be linked to notes or external addresses and can carry Markdown fragments held as numbered data properties, which Obsidian renders — including output produced by other plugins — though this interactivity is stated to work in reading mode only. Mermaid and LaTeX support come from draw.io itself, and the diagrams can also be used in Canvas.
