# kepano/obsidian-hider

The repository holds Hider, an Obsidian plugin that hides parts of the interface, among them the app ribbon, tab bar, status bar, vault name, scrollbars, search suggestions, search match counts, tooltips, prompt instructions and Reading view metadata. Its README records that several of these can be bound to hotkeys and warns that a CSS theme may override the plugin. For theme authors it documents the classes injected on the body element as each feature is toggled on, so a theme can be made compatible with the plugin.
