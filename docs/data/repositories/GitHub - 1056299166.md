# fikte/calendar-period-week-notes

This repository holds an Obsidian calendar plugin that combines a configurable calendar grid with a tabbed panel for a scratchpad stored in the vault, recent and pinned notes, tasks, assets and a dashboard of widgets. Its distinguishing feature is a period and week numbering scheme for a financial year split into thirteen periods of four weeks, offered alongside standard calendar week numbers. The grid marks created and modified notes with dot indicators and shades dates by task count as a heat map, offers a vertically scrolling variant, and exposes a themes settings tab for light and dark appearances.
