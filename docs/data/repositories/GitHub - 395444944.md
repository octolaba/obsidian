# saml-dev/obsidian-custom-js

CustomJS loads user-written JavaScript from the vault and makes it callable anywhere JavaScript can be written, including dataviewjs blocks and Templater templates, on desktop and mobile. Code is taken from a comma-separated list of files or recursively from a folder, loaded in alphabetical order by file name so classes can depend on each other, and exposed as instances on a global customJS object. The README is explicit that each file must contain exactly one class and nothing else — no bare functions, module exports, imports or constants — and it also documents binding invocable scripts to hotkeys and running startup scripts when the plugin loads.
