# joepetrakovich/obsidian-lmstudio-connect

LM Studio Connect adds a chat interface in Obsidian that talks to a local LM Studio instance, so language models can be used with notes privately and offline. The README requires LM Studio's server to be enabled with the CORS option, and suggests its serve-on-local-network setting for use from a phone. Notes are brought into a chat through a file picker or the wikilink prefix, currently open notes are made known to the model, and a prompt can be embedded in a note in an `lmsc` code block with a required prompt option and an optional flag hiding tool-call details. It states that the plugin is not affiliated with LM Studio's company.
