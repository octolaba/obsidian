# SimplGy/obsidian-emoji-magic

Obsidian plugin that inserts emoji through a keyword search backed by a large dictionary, so broad terms and colours return matches that a plain shortcode list would not. The README records a dictionary of 1,812 emoji with 199,658 searchable keywords and thesaurus entries, two-dimensional arrow-key navigation of the emoji grid, and insertion of real emoji characters rather than images, which means no custom emoji and platform-dependent rendering. It states that the search is local with no internet access, and that the plugin is an Obsidian-compatible fork of a Chrome extension the same author wrote.
