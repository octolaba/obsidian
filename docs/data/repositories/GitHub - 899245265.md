# KarmaToast40340/photopea-editor

Photopea Editor embeds the online image editor Photopea in Obsidian, replacing the default image viewer within the same panel when a PNG, JPG or JPEG file is clicked in the vault. The selected image is passed to the editor as a data URI, and the editor runs in an iframe that adjusts to the dimensions of the Obsidian panel. The README records the known issues: an edited image has to be saved from Photopea and put back into the vault by hand, since automated saving is not yet supported, and performance may vary with large images.
