# jiangzizhao/notebookpoint

NotebookPoint pulls articles and links forwarded through a messaging service into the vault as Markdown notes carrying their full text; its README is in Chinese. This repository holds the open-source client, which authenticates with a licence code entered in the plugin settings, while receiving, parsing and storing the content is done by a hosted paid service. The README states that the plugin itself contains no keys, that the licence code stays on the user's own computer, and that syncing runs when Obsidian opens or on a schedule.
