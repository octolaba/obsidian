# XuQuan-nikkkki/FolderFile-Splitter-Plugin

Splits the file explorer into separate panels for folders and for files, instead of the single combined tree. The layout can be switched between a horizontal and a vertical split, the order of files and folders can be customised, and individual files or folders can be pinned to the top of their list. The README states that the plugin follows the current Obsidian theme and names Apple's design as the inspiration. No repository description is recorded, so this note is grounded in the README alone.
