# evanwong89/footprint-map

This repository holds Footprint Map, described upstream as portable photo footprint maps for Obsidian and Markdown. The README says it builds a time-ordered travel diary from photo locations, keeps the data in portable GeoJSON, links each place to local photos, and draws dashed straight arrows showing visit order rather than the route actually travelled. Consecutive photos within 200 metres of the first are grouped into one place, JPEG, HEIC and PNG metadata is read, and rendering can use OpenStreetMap, an AMap static basemap, custom raster tiles or no basemap at all, with markers, timeline and order lines still available when a basemap fails. The README notes that images downloaded from the internet or taken without location data may not appear.
