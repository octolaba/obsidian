# rordaz/ColorTab

Obsidian plugin that assigns a background color to any open tab so notes can be told apart at a glance. The README motivates it by the difficulty of finding the right tab while several notes are open, and gives example conventions such as red for the note being actively written, green for reference material returned to often, and lavender for meeting notes or daily logs. Installation is documented from the community plugin directory or manually into the plugin folder.
