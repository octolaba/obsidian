# coddingtonbear/obsidian-csv-table

This plugin renders data from a CSV file in the vault as a table in a note's preview, configured through a code block. Recorded options are the source path, options passed to the CSV parser, an explicit list of columns which may be renamed or computed from expressions, filter and sort expressions, a maximum row count, and named variables that map a name to a column for use in filters and columns. Without a column list every column is rendered, and without filters or sorting the rows appear in the order they have in the file.
