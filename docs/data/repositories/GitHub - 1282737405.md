# Othman-Benbrahim/iris-transcript-obsidian

IRIS-Transcript turns a YouTube address into a Markdown note holding a transcript, a mindmap and an optional summary. The transcript comes from YouTube's own subtitles with no API key, and the mindmap is rendered by the plugin itself with zoom, panning and collapsible nodes, so no third-party plugin is needed. Without a language model the transcript is recomposed into readable paragraphs, configurable as paragraphs, none or one per line, and the mindmap is cut at pauses; a mindmap structured by theme and any speaker attribution require the optional LLM step, because the subtitles carry neither structure nor speaker. The configured endpoint accepts any OpenAI-compatible chat completions service, network calls go through Obsidian's requestUrl rather than fetch because the renderer blocks a direct fetch by CORS, and metadata is written to frontmatter for Dataview.
