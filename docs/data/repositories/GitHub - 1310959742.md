# moziar/obsidian-xmind-pal

xmind pal embeds and previews .xmind mind map files inside notes. A file can be referenced from an xmind-pal code block or from a lightweight comment that renders in Reading mode and stays hidden in Live Preview, and either form accepts a frontmatter property name, a wikilink, an embed link or a plain path, so one note can hold several embeds pointing at different files. By default it displays the preview image XMind stores inside every file, which needs no network, while an online mode instead renders through XMind's own embed viewer, with a choice of the global or the China service. A toolbar above the viewer shows the file name and opens the file in its default application, and viewer height, default property name and toolbar behaviour are configurable.
