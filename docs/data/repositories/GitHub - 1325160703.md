# solidens/obsidian-todo-economy

Todo Economy is a to-do list in an Obsidian sidebar panel, drawn as monospace ASCII, where completing tasks earns points and points buy rewards. Tasks are ordinary checkboxes in a single Markdown file, each carrying its estimate, difficulty, priority, due date and id in a trailing code span; since 1.3.0 the balance, rewards, streak, daily cap and purchase history live in a state block in that same file, so syncing one file moves everything between devices. Prices are not set by hand: an onboarding conversation estimates realistic monthly point income and solves a coefficient turning a reward's value and a harm multiplier into a price, recomputable later from real earning history. Harmful rewards cost more and carry a weekly cap instead of being blocked, and the in-app chat and onboarding are currently Russian-only.
