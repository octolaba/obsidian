# willjhliang/obsidian-papers

Papers retrieves research papers from arXiv, imports them into the vault and cites them from other notes. Importing takes either a direct arXiv URL or a paper title, which is fuzzy-searched against arXiv so that one of the results can be chosen, and creates a note holding the paper title, authors, publication year, URL and the downloaded PDF. Citing searches through the vault and creates a link to the imported paper note, optionally with an alias.
