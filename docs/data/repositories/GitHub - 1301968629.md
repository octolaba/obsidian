# max-fluff/obsidian-heading-linker

Heading Linker finds words in notes that match headings inside files nominated as glossaries and turns them into links to those headings, following declensions, plurals and other word forms rather than exact spellings, while keeping the note's own wording as the visible link text. Matching words are underlined in reading view and in the editor, and the plugin covers unlinking, aliases, optional link suggestions while typing and the handling of ambiguous headings. The README states that eight language modules are baked into `main.js`, so morphology works as soon as the plugin is installed, and that it deliberately links headings as terms while its sibling Glossary Linker links whole notes on the same matching engine.
