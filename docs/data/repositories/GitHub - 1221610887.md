# Rumcajsev/obsidian-navigate-headings

This repository holds Navigate Headings, an Obsidian plugin that shows the headings of markdown files inside the default file explorer and jumps between them. Clicking a file title expands its headings down to the level set by the auto-expand setting, clicking the arrow beside a file always toggles the headings panel at either all levels or the top level, and clicking a heading jumps to that section and toggles its children. The README presents the point as navigating a document and seeing the current position without leaving the file explorer.
