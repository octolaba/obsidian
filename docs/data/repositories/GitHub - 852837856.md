# bladeacer/flexcyon

Flexcyon is described as an Obsidian theme combining the colour schemes of Halcyon and Flexoki, which its README explains as joining Halcyon's vibrant colours with Flexoki's inky aesthetic. The README also records a light mode colour scheme combining the Origami theme's palette with Flexoki light. Installation is documented through the community store or through BRAT, and the README states that installing the Style Settings plugin is highly recommended because most customisation and functionality is built around it.
