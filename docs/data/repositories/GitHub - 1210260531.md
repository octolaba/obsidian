# otaviocc/obsidian-pika

Pika.publish publishes notes from an Obsidian vault to a Pika blog through the Micropub API, carrying title, tags, a draft or public visibility and an optional post date. According to its README the plugin finds local images in a note, in both standard Markdown and Obsidian embed form, uploads them to Pika, replaces the references with the hosted addresses and caches that mapping in note properties for faster re-publishing. It reads title and tags from frontmatter, falling back to the filename and to configured defaults, writes the post address back into the note after a successful publish, and needs an app token created in Pika settings. The README states that the plugin is community-maintained and not affiliated with Pika or Obsidian.
