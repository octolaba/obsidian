# NemoAndrea/obsidian-daily-named-folder

This plugin creates each daily note inside its own folder and appends a one-line description to the filename, which the README presents as a way to keep a daily note's attachments in a separate folder. It reproduces most of the core daily-note behaviour and adds navigation that jumps to the nearest existing previous or next note rather than the adjacent day, a command that opens today's note or creates it when it is missing, template selection with date arguments, path checking in the settings, and four functions exposed to other plugins. The README warns that plugins relying on the default daily-notes implementation, naming Calendar as its example, will probably not work with named folders.
