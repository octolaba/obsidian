# less1001/obsync

Syncs WeChat Official Account articles and personal memos from a companion WeChat mini program into an Obsidian vault as Markdown files. Duplicate articles are skipped automatically, and a status-bar indicator reports the last sync time and its status. Setup generates a six-digit binding code in the plugin settings, which is entered in the mini program's settings to connect the two, after which articles and memos saved there arrive in the vault.
