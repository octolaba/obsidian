# inciyang2022-a11y/task-journal-checkbox-sink

Task Journal Checkbox Sink keeps a centralized task page readable by moving a completed task to the end of its own sibling list, never across a heading or a parent task, carrying its child tasks and attached content with it. It records the outcome in the Daily Note as completed or partially completed with an optional summary, tracks native checkbox changes to store the real completion date, and archives completed tasks by that date into a file or a heading, grouped by day, week, month or not at all. The most recent status, checkbox or archive operation can be undone, which the README says survives an Obsidian restart. It records English and Simplified Chinese interfaces, desktop, Android and iOS support, a minimum Obsidian version of 1.6.6, and no account, network requests or telemetry.
