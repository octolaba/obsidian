# lumina-apps/obsidian-lumina

Lumina is an assistant plugin for Obsidian combining a multi-model chat side panel, retrieval over the vault, MCP integration in both directions and an agent mode. The README records local embeddings computed offline and a vault index maintained in real time, discovery of documents related to the note being written with duplicate warnings and suggested tags, inline actions to summarize, translate or proofread highlighted text, and an agent that plans and carries out note search, creation, modification, deletion or movement and runs code in a sandbox through built-in MCP tools. Both hosted and local models are supported, and the interface and documentation are offered in eleven languages.
