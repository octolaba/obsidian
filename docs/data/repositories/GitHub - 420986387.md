# Nilahn/pine_forest_berry

Pine Forest Berry is a dark and light theme for Obsidian with an overall minimal design and a calm colour palette. The author notes that it is largely based on snippets of other themes, mostly Dracula for Obsidian by jarodise and Kepano's Minimal theme, and that a tag-pill CSS snippet used with it stays outside the main CSS file because it is customised to the author's own tags. Version 1.2 cleaned up the CSS and reworked code block views, tag rendering in light mode and menu contrast, while 1.3 fixed adjustable font sizes and added the alternative checkboxes taken from Minimal.
