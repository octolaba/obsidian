# ImCuriosity/third-brain-release

ThirdBrain extracts propositions from text pasted or dropped into its panel, links them with logically typed edges into a knowledge graph, detects contradictions between them, and then works problems on that graph. Its README, written mainly in Korean, describes a brain-state view listing per folder the open missions, unconnected propositions and detected contradictions, a conversational workbench whose answers trace back to individual nodes, a folder analysis producing insights, and a graph visualisation. Four AI backends are recorded, namely Gemini, the Claude API, OpenAI, and the Claude Code command-line tool which the README marks as desktop only, with OpenAI listed as required for transcribing audio. Before any AI work the plugin shows a confirmation window estimating tokens, cost and time, which the README says can be switched off in settings.
