# akhileshu/documentation-command-center

Documentation Command Center adds a dashboard for browsing a documentation vault: a collapsible folder tree with search by note name and path, filters by file type, direct or nested counts, depth-limited expansion and a folder pinnable as a temporary root. Three tabs are offered: the vault tree, bookmarked folders that survive reloads and follow renames, and My lists, which is optional and renders saved Dataview LIST queries through the same tree. Recently updated files, unresolved links and orphan notes are surfaced, files open through native links and hover previews, and images and media preview in a keyboard-navigable gallery. The core dashboard works offline and enumerates files locally; only the My lists tab requires the Dataview plugin.
