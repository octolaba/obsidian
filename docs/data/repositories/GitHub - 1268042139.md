# EventideMiles/eventide-quill

Eventide Quill is a writing assistant for novelists in Obsidian that pairs a deterministic prose linter with AI feedback, a lorebook and co-writer collaboration. The README states that the linter runs without AI cost and flags passive voice, adverb and qualifier clutter, repeated words and sentence starts, telling instead of showing, dialogue-tag overuse and overlong sentences, plus a cluster of rules aimed at AI-prose tells such as clichés, em dashes, hedging and wrap-ups. It also describes selection rewrites, inline directives and a plot map that steer generation, a context engine that extracts characters, locations and plot threads from the open document, and a dashboard of chapter word counts, pacing and writing goals; it requires Obsidian 1.13.0 or later and runs locally by default through Ollama or an OpenAI-compatible local server.
