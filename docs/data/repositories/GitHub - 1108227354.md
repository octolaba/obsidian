# axxshen/obsidian-graph-mind

Graph Mind is an Obsidian plugin that indexes the vault's Markdown notes and answers questions about them in a chat view with citations back to the source notes. The README records a local index, search filters for exact phrases, tags, file extensions and included or excluded paths, and reranking of results with local embeddings before an answer is generated from the top results. It requires a local Ollama server providing one chat model and one embedding model, configured by base URL in settings; without it the interface opens but cannot generate answers or embeddings. The README states that notes stay on the device and that the plugin communicates only with the configured Ollama server.
