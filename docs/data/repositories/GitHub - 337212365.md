# renehernandez/obsidian-readwise

The repository holds an unofficial community plugin that synchronizes Readwise highlights into an Obsidian vault. Its README states that a paid Readwise subscription is required and that an API token is requested on installation or set later in the settings. Listed capabilities are syncing on Obsidian startup, updating existing notes with new highlights, templating for the note header and highlights, and author mappings; the README warns that the token is kept in localStorage, which can conflict when the same vault is used elsewhere.
