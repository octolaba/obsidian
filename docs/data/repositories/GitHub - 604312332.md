# patleeman/obsidian-open-in-new-tab

This plugin makes the file explorer open every document in a new tab, and activates the existing tab when the file is already open there. It works by intercepting clicks in the file explorer, so the README states that it does not cover other parts of Obsidian such as the quick switcher, calls the approach a hack, and suggests requesting the behaviour from Obsidian itself.
