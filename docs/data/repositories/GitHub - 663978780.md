# antoKeinanen/obsidian-finnish-spellcheck

Adds Finnish spelling and grammar checking to the editor using Voikko, which the README describes as a Finnish language tool covering morphological analysis, spelling, grammar checking and hyphenation. Checking runs from a Spellcheck command in the command palette or from a button in the editor. The README states that only the desktop version of Obsidian is supported and that libvoikko may have to be installed separately on Windows, macOS or Linux. No repository description is recorded, so this note is grounded in the README alone.
