# saltyfireball/obsidian-code-editor

Obsidian plugin for editing non-markdown text files, such as code, configuration and data files, inside Obsidian with syntax highlighting, line numbers and word wrap. The README lists more than 50 supported file types, five built-in color themes (Monokai Pro, GitHub Dark, GitHub Light, Dracula and Nord), bracket matching, undo and redo history, tab indentation, custom file extensions, and binary file detection that prevents editing binary files. Supported files open in the code editor automatically once the plugin is enabled.
