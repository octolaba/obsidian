# cubicleWar/obsidian-chronicle

This repository holds Chronicle, an Obsidian plugin for recording the films and television series a person watches. Running the Chronicle: Movie or Chronicle: TV Series command asks for a title, offers the matching results, and then creates or updates a note in a configured media folder from a reference template. Data comes from personal API keys the user supplies for the Open Movie Database and The Movie Database; when both are configured, one serves as the primary source and the other enriches the result.
