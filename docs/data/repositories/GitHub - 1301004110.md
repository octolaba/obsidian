# Jiangnan0522/paper-link

Paper Link replaces a pasted academic paper URL with a titled Markdown link at the moment of pasting, so an arXiv address becomes a link carrying the paper's title, venue and year. Titles come from the arXiv API, ACL Anthology page metadata, the OpenReview API, or Google Scholar citation meta tags for anything else, and a URL with no citation metadata is left exactly as pasted. The paste itself is not delayed: the URL lands immediately and the titled link is swapped in once the metadata arrives. A separate command converts every bare paper URL in an existing note, skipping URLs that are already links, sit in frontmatter, or sit inside code blocks.
