# kev-cao/obsidian-flexical

FlexiCal is a calendar plugin for Obsidian in which the user defines one or more calendars, each with its own filter and colour, and days carrying matching notes are marked with a coloured dot per calendar, up to six. Notes are placed by a frontmatter date field, with an optional ISO week field used as a fallback that puts a note on the Monday of that week, and each note belongs to only the first calendar in settings order whose filter and date field it matches, so ordering decides ownership. Filters are built from nested all, any and none groups over frontmatter properties by type with type-appropriate operators, and over file paths by glob. The calendar lives in the right sidebar, opens from a ribbon icon, updates as notes change, and clicking a day opens its note or offers a picker when several match.
