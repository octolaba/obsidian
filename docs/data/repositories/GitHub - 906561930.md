# webceoboy/moredraw-obsidian

This repository holds an Obsidian plugin that embeds MoreDraw, an infinite-canvas whiteboard with AI assistance for drawing flowcharts, mind maps and other diagrams, using the moredraw.com SDK. It opens standalone from an entry in the left sidebar, or a whiteboard is inserted into a note through the context menu or the moredraw insert command; the README lists AI flowcharts and mind maps, to-do lists, timetables, a chart maker, a QR code maker, free drawing and export to PDF, PNG and PPT among its features. The README records that the plugin uses the remote moredraw.com service, that some features such as saving and syncing files require an account there, and that some functions are paid.
