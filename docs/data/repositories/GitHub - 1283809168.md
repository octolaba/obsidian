# trikorka/BestDownloader

Best Downloader downloads video and audio into an Obsidian vault using `yt-dlp`, covering the sites that tool supports and saving files to a configurable path inside the vault. Audio-only MP3 or M4A and combined video and audio MP4 or WebM outputs are offered. The README states the plugin runs only on the Windows desktop app — not macOS, Linux or mobile — and that `yt-dlp` must be on the system PATH or configured explicitly, with FFmpeg required for muxing streams or converting audio.
