# khaldevmedia/obsidian-youtnote

Keeps timestamped Markdown notes on several embedded YouTube videos inside a single Obsidian note. Videos are added by URL and reordered by drag and drop, and each note card seeks the player to its second, optionally autoplaying, with timestamps editable inline and duplicate timestamps mergeable into one card. The note editor embeds Obsidian's own CM6 Live Preview so hotkeys, themes and other plugins behave as usual, a pin option keeps the player visible while scrolling on phones, and the active video or the whole file exports back to Markdown. The README states that Obsidian 1.10.3 or later is required, because earlier versions show Error 153 for embedded YouTube videos.
