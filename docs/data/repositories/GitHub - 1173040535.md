# SriVadrevu/obsidian-note-open-tracker-plus

This repository holds Note Open Tracker Plus, an Obsidian plugin that records how often notes are opened and generates an analytics report covering all-time opens, opens in the last 30, 90 and 365 days, a trending score over those windows, and the most recently opened notes. Its stats database, the generated report and an optional append-only NDJSON event log are written into a configurable stats folder, and settings expose the report filename, a write debounce, tracking of non-markdown files, the trending weights and the number of rows in the report. The README records that the trend score is the weighted sum of the three window counts, and warns that frequent writes can cause conflicts under Obsidian Sync, iCloud or Dropbox, which a longer debounce mitigates.
