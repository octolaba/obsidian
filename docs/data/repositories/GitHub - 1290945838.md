# Abdulkader-Safi/obsidian-s_calc-plugins

S-Calc evaluates a calculator written inside a note: expressions placed in an s-calc code block are computed line by line and each result appears to the right of its line in the theme's accent colour, updating as the text changes. The README records arithmetic with parentheses, labels and variables reused on later lines, a running sum and a previous-line reference, percentage forms, unit conversion, currency conversion by ISO code or common name, and plain-language dates such as a weekday plus two weeks. Blank lines and comment lines are ignored, currency rates are fetched once per session from a free public endpoint with no API key, and the README notes that inch must be spelled out because the bare word in is reserved for conversions.
