# felipe-ds-lima/obsidian-copy-image-plugin

This plugin adds a Copy Image entry to the context menu of an image in Obsidian, placing the image itself on the clipboard for pasting elsewhere. On the desktop the entry is reached by right-clicking the image, and on mobile by touching and holding it for about a second.
