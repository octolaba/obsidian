# Outsiders17711/Obsidian-Custom-Syntax-Highlights

The repository holds Custom Syntax Highlights, an Obsidian plugin that renders files with unrecognized extensions as syntax-highlighted code blocks in reading view. Settings map any file extension to a supported highlighting language, and configured extensions can be switched to reading view automatically when opened. The README states that a matching file is rendered as a single formatted code block.
