# runa-rist/hephaistos-importer

This unofficial plugin imports Starfinder characters from Hephaistos.online into an Obsidian vault. Given the public IDs taken from character share links, clicking the anvil icon fills a chosen folder with one note per character and writes the Hephaistos data into the frontmatter; an existing note of that name has its frontmatter updated rather than replaced, so unrelated entries survive. Settings enable hyperlinks for fields such as spell names, built against the Community SRD vault's structure with the caveat that the link path may be guessed wrong, and add fields formatted for Javalent's Initiative Tracker and Fantasy Statblocks.
