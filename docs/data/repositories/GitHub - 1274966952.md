# skye1349/epub-reading-importer

EPUB Transfer to Markdown converts an EPUB into a folder of chapter-based Markdown notes with an index note that links them, a media folder holding the book's images and, optionally, a copy of the source EPUB. The README states that the plugin also registers a paginated reader so .epub files in the vault open directly, exports an edited book folder back to EPUB, and sends an existing EPUB to Kindle through the local mail client. It is desktop-only on macOS and Windows and requires pandoc to be installed; the plugin looks in the usual locations and otherwise takes an explicit path from its settings.
