# I-am-Rudi/workout-journal

Tracks workouts inside Obsidian, logging sets, reps, weights, durations and distances, with the stated aim of matching the experience of a dedicated fitness app while the data stays in the vault. Reusable routines, structured plans built from those routines and a personal exercise library with muscle-group targeting are managed from the settings interface. An interactive session window records values, added sets, exercises and notes while a workout runs, a rest timer covers the pauses between sets, and dates and file organisation are handled automatically. The README states that the plugin began as a fork of Obsidian Workout Tracker and that it is mostly self-tested, having been designed for its author's own vault.
