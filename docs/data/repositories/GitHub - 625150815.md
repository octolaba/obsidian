# OlivierPS/Olivier-s-Theme

Olivier's Theme is an advanced interface theme for Obsidian focused on legibility, typography and a calm, paper-like writing environment. Version 3.0 uses a perceptual colour system with improved and new palettes, one of them spanning the full hue range, together with an overall intensity control, and many options cascade so that light mode settings carry into dark mode and reading mode builds on writing mode. Lists, tables, quotes and images are styled with several defaults including multiple table styles and image sizing, and a set of cssclasses adjusts individual notes for things such as Bases headers, table width and image size. Full documentation for version 3.0 is published as a separate user guide.
