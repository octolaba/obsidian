# p-of-g-given-h/mandarin_helper

Mandarin Helper is an Obsidian plugin for reading and looking up Chinese text in notes: it renders pinyin above Hanzi in reading and editing views, colours Hanzi and pinyin by tone with configurable colours, and adjusts their display scale. Dictionary lookup uses CEDICT-compatible dictionaries downloaded from a configurable source, with English-Chinese and German-Chinese URLs preset, and matches against Hanzi, normalized pinyin and normalized translation text. Lookup runs from a command, a hotkey or a ribbon button over the selection, falling back to the current line with headings, list markers, checkboxes and links stripped, and each segment of the result popup is copied to the clipboard with a click.
