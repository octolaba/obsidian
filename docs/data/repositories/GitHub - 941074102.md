# aNNiMON/obsidian-timelive

Timelive turns a list of dates in a note into a timeline without using a code block, so each event can be formatted freely with links, code, images or video. Dates are written enclosed in pipe characters, the format is detected automatically with a preferred format selectable in the settings, and two dates separated by a dash become a time span. The words now, today and present mark the project as live and add a marker for the current day, and the timeline is rendered in Reading view, or in Live Editing when a note carrying one is embedded.
