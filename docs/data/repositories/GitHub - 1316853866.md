# fengshuzi/note-api

Note API runs a local HTTP server inside Obsidian that exposes the vault to other programs on the same machine. It binds to the loopback address only and requires a bearer API key generated on first run, and its endpoints list, read, create, replace and trash Markdown notes through the Vault API, resolve a wiki link to a real path using Obsidian's own shortest-path logic, read and upload binary attachments, and report the daily-notes folder and format together with a list of dated journal entries. Further endpoints, off by default and macOS only, read and write Reminders and Calendar entries through EventKit and JXA. The plugin is desktop only and its port is configurable.
