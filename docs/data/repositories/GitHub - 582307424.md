# daledesilva/obsidian_google-keep-import

This repository holds Google Keep Import, described upstream as importing Google Keep backup files. The README says the plugin imports an exported set of Keep notes and their attachments, obtained through Google Takeout, into an Obsidian vault, and records a minimum Obsidian version of 1.1.10. It also states that the plugin is no longer maintained and points readers to the official Obsidian Importer, whose Keep support the same author helped implement, unless the import customisations offered here are needed.
