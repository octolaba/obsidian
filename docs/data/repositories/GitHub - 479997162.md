# scambier/obsidian-omnisearch

Omnisearch is a search front end for Obsidian that scores documents with the BM25 algorithm over their text, filename and headings, built on the MiniSearch library. Its workflow resembles the core Quick Switcher: it is keyboard driven, tolerates typos, understands quoted expressions, exclusions and file-type filters, and can switch between searching the vault and searching within one note. Documents, images and PDFs are indexed through a companion text extraction plugin, and an opt-in local HTTP server allows queries from outside Obsidian.
