# taskscape/InfostackerPlugin

Publishes notes to the vendor's server from inside Obsidian, returning a generated link that renders the note and its attachments as HTML for whoever holds it, and supports editing and deleting a published note afterwards. The README states that storage of notes and attached files such as PDFs and images is free and that publishing is capped at 100 notes per day. The remainder of the README covers the manual installation path and the steps for submitting the plugin to the Obsidian community directory.
