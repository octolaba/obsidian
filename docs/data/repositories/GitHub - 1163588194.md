# SawyerRensel/Osmosis

Renders a Markdown note as an editable mind map, headings becoming branches and list items nodes, with edits flowing in both directions between the map and the file. A single command gives every heading, bullet and paragraph a block ID, turning those lines into flashcards scheduled by FSRS without duplicating any content. Review runs in three modes that share one schedule: on the map itself, where due nodes are hidden behind placeholders while their surroundings stay visible, inline in the note, and as a classic card sequence. Hand-authored cards in five formats are written in code fences, scheduling data lives in frontmatter and the fences themselves, and a dashboard shows decks, due counts and statistics.
