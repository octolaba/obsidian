# semsevens/obsidian-media-transcript

Media Transcript opens a video or audio file in its own view and shows a transcript beside it, read from a same-named JSON, SRT or VTT file in the same folder; it plays transcripts rather than producing them, and does no speech recognition. Clicking a line seeks to that point, the playing line highlights and scrolls into view, and a right-click menu offers play from here, copy timestamp and copy text. Video uses a side-by-side layout with a draggable divider whose ratio is remembered, audio uses a slim control bar above a full-width transcript, and playback runs between 0.75x and 2x. JSON transcripts in the Whisper verbose_json shape can carry speaker numbers, which are shown as coloured labels, and the transcript can be exported to a Markdown note.
