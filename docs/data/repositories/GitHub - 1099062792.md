# Butterski/obsidian-rpg-dice-roller

Builds RPG dice roll commands in d20 syntax through a visual formula builder in a side panel, opened from a ribbon dice icon, the command palette, or a keyboard shortcut. It covers d20 grammar operations such as keeping the highest die, rerolling and exploding, plus advantage and disadvantage as used in D&D 5e, and emits commands formatted for Discord bots or Roll20. Formulas already present in an open note are detected automatically, `ROLL[formula]` syntax makes rolls clickable, and results can be copied to the clipboard or inserted into a note on desktop and mobile.
