# mrcnkobu/readlog

Readlog tracks books in plain Markdown: one note per book under a configurable root folder, an append-only reading log, a compact session line written into the book note and optionally into the daily note, and four commands for adding a book, editing it, logging a session and adding an entry. Book metadata lives in frontmatter, progress is tracked in pages, locations or percent with a stored computed percentage, and session entries record both the unit range and the percent range. It can also import Kindle highlights and notes from a local clippings file, placing highlights and notes in separate sections, matching conservatively against existing book notes and deduplicating through persistent clipping fingerprints. The README notes that writes preserve manual edits and that deleting a book trashes only its note, leaving historical logs intact.
