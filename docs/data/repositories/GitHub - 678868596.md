# pourmand1376/obsidian-custom-font

Custom Font applies a font stored in the vault to the whole Obsidian interface, which the README motivates by the difficulty of setting custom fonts on Android and iOS. Font files in .woff, .ttf, .woff2 and .otf format are placed in the vault's .obsidian/fonts folder and selected from a dropdown in the plugin settings, and the plugin base64-encodes them so the same font works across Windows, macOS, Linux, Android and iOS without being installed on the operating system. The README also documents applying the font through custom CSS or to specific pages, and a separate web page that performs the base64 conversion without the plugin.
