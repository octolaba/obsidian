# ptspzy/obsidian-new-tab-pins

New Tab Pins replaces an empty Obsidian tab with a home view holding pinned notes, a search box and recently modified files, so no dashboard note has to be maintained. Notes are pinned from the file explorer context menu, by dragging a Markdown file onto the pinned area or with a command, and pinned items can be dragged to reorder, while search matches files by title or path. Commands open the home view or replace the current tab with it, and settings cover the home title and subtitle, layout density, starter pins, and whether newly focused empty tabs are replaced automatically. That automatic behaviour depends on Obsidian exposing blank tabs as an empty view type; the plugin stores only settings and pinned paths and makes no network requests.
