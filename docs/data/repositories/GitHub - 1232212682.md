# mjparker/obsidian-rollover-todos-with-context

Rolls incomplete todo items forward from the previous daily note — whether that is yesterday or a week ago — into today's note, triggered automatically when the Daily notes or Periodic Notes plugin creates a new daily note, or run manually from the command palette. A second command undoes the last rollover within two minutes of it happening. The README warns that both commands are potentially destructive, that Obsidian's ordinary text undo does not cover them, and that automatic rollover can conflict with Templater, in which case it should be disabled and the rollover triggered by hand after note creation.
