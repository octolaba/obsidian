# tilhars/obsidian-text-focus-plugin

Obsidian Text Focus Plugin automatically focuses the text area when a new note is opened in Obsidian. The README states that once the plugin is installed and enabled, typing can begin immediately without clicking into the text area first. It documents no settings and no commands beyond that behaviour.
