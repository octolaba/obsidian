# springrain1/flomo-to-obsidian

Flomo Importer brings Flomo notes into Obsidian and is a fork of jia6y/flomo-to-obsidian, described by its author as the fixed community-marketplace version with added features such as Thino compatibility. Pulling notes works over two channels: browser automation with Playwright or a manual ZIP import as the fallback, and incremental synchronisation through Flomo's private API keyed on slug and updated_at, which deduplicates, pages with a cursor, downloads attachments and trashes remotely deleted notes. Pushing back has two channels as well, a Bearer-token call to the private API for free accounts and the official webhook for Pro members, and imported notes carry YAML frontmatter with slug, created, modified, source and tags. The README is in Chinese and documents a module loader that locates Playwright despite Obsidian's Electron require hijacking.
