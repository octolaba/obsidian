# zinverno/obsidian-ai-hub

Obsidian plugin for auditing, maintaining and transforming a vault with configurable AI providers. Audits analyse vault structure and quality and identify clusters, orphan notes and structural issues, while the writing tools cover plain and vault-aware continuation, processing of selected text, Dataview query generation, flashcard generation, atomisation of a note into separate notes, and batch runs filtered by folder, tag or date. A local vector index backs semantic search, with Markdown-aware chunking that preserves heading context, chunk-level incremental indexing by content and metadata hash, results grouped by note, and detection of a changed embedding provider, model, endpoint or vector dimension. The README states semantic features are opt-in, that indexing in version 1.5.0 is manual with no automatic indexing on file events, and that Obsidian 1.8.7 or later is required.
