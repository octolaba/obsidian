# ArtemisLin/memo-lite

Memo Lite captures short memos as plain Markdown files inside the vault, organised with tags that autocomplete while typing, searched as the query is entered and reviewed through an activity heatmap whose days filter the list. Memos can be pinned, edited in place on double-click, counted by words, created from Obsidian templates, and rendered as image cards from four templates and thirteen backgrounds. A File Flow view registers up to five target folders and writes a standalone Markdown file from a title and body, with drafts surviving a view close or an app restart. The README records that the interface is Chinese-only for now, that the plugin is desktop-only, and that it makes no network requests and collects no telemetry.
