# jrockwar/note-bundler

This repository holds Note Bundler, an Obsidian plugin that exports a filtered subset of notes into consolidated Markdown files, which the README suggests for preparing LLM context, documentation packages or curated collections. Filters combine tag matching by regular expression with recursive, vault-relative directory include and exclude rules, joined by AND or OR logic. Exports run manually or on a schedule at minute, hour or day intervals, write to a vault-relative path or, on desktop only, an absolute one, and settings are kept independently per device.
