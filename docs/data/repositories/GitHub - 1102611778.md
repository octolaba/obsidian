# cjonesde/obsidian-folder-new-note-button

Folder New Note Button adds a subtle plus button to every folder in Obsidian's Files view that creates a new note in that folder. The button appears when a folder title is hovered or focused with the keyboard, and stays visible on mobile positioned clear of the drag handle. The new file is created with a unique name and its title is immediately selected for renaming, matching Obsidian's own new-note behaviour, and the README states the plugin works with several File Explorer panes, uses no desktop-only APIs, and cleans up when disabled.
