# gapmiss/vault-name

Vault Name displays the vault's name as a title in the side navigation file explorer and lets that title be customised, restoring something Obsidian showed before version 1.6.0. The README suggests pairing it with the Legacy vault switcher plugin, and its screenshots show the default styling, a customised styling with a sticky position, and the settings tab. Installation is documented from the community plugins browser or manually, either by moving an uncompressed release folder into the vault's plugins directory or by placing the three build files into a folder created there.
