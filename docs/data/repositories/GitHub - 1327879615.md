# joshsterckx/obsidian-open-to-side

Redirects one modifier-click, by default Cmd or Ctrl plus Alt, so that a link opens in the tab group already to the right instead of creating another split each time; a new split is made only when no group is there. Clicking from inside that side column opens there rather than chaining a third column, pinned tabs are never replaced, and only the trigger click is affected, leaving the Split right command and other split-opens untouched. It works for links in Live Preview and Reading mode and from the file explorer, search results and backlinks, because it patches the single workspace method every split-open passes through. Settings choose the trigger combination, whether focus stays in the current note, and whether the side tab is reused or a new one opened each time.
