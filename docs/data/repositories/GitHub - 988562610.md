# kunalJa/VariantEditor

Variant Editor keeps several alternative wordings of a word, phrase or sentence side by side in an Obsidian note instead of deleting and rewriting the same text. Text is highlighted and turned into variants from the command palette, each variant is viewed in context by clicking it, variants are dragged into a preferred order, and committing replaces them with the chosen one. Two commands are named for hotkeys: creating a variant from the selection, and committing all variants in the selection or the document. The README states that the plugin works across every platform Obsidian supports, on desktop, mobile and tablets.
