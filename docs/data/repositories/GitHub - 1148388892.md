# DuckTapeKiller/obsidian-aubade

This repository holds Aubade, a retro-brutalist Obsidian theme from the author of Brutalist that prioritises strict geometry, high contrast and tactile interactions over soft gradients and rounded corners, for users who want a workspace that feels like a structural tool. Its README documents colour schemes, selectable background patterns, sans serif, monospace and serif typography, alignment, note width and typography settings, and per-note overrides for custom widths and interface hiding. It also covers a dashboard and masonry layout, CSS-only timelines and image captions, and records that at the time of writing the community themes listing was still pending review.
