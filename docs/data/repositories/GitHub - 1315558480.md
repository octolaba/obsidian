# reticenceji/obsidian-image-title

Image Title displays the alt text of an image as a visible caption in Obsidian's reading view, centered under the image by default. A setting moves the caption above the image instead, and images whose alt text is empty are left without one. Obsidian's size parameters, such as a width or a width by height suffix, are stripped from the text before it is shown.
