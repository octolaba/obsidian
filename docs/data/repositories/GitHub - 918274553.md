# bluelephant825/highlightr-plus

Highlightr Plus brings a highlighting and annotating menu into Obsidian, described upstream as a minimal and aesthetically pleasing menu for colour-coded highlighting. The README states that it is based on Chetachi's original Highlightr plugin, with the same functionality behind a slightly different interface. A highlight wraps the selection in mark tags carrying an inline background colour, so exported notes do not rely on external CSS, and further colours are added by name and colour picker in the settings tab. Depending on what is right-clicked, the context menu offers Highlight, Change Highlight Color, Unhighlight, Annotate, Edit annotation and Erase annotation.
