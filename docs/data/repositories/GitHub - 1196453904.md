# yinshaohua/UniCalendar

UniCalendar aggregates events from Google Calendar, CalDAV servers and ICS feeds into a single month view, color-coded by source. Google accounts are connected through an OAuth 2.0 PKCE flow described as needing no server, with system, direct or custom proxy behaviour for reaching Google endpoints, while any public or private ICS address can be subscribed to. Events shared across sources are shown once according to a configurable source priority, and same-source duplicates sharing a start time and overlapping titles collapse to the copy carrying more metadata. Each cell also annotates Chinese lunar dates, traditional festivals and the twenty-four solar terms, with a statutory holiday overlay from an external data project, and the README states that synchronization runs on a configurable interval and that the plugin works on iOS and Android.
