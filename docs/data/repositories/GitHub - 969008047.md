# JinmuGo/obsidian-theme-by-folder

Theme by Folder switches the Obsidian theme and the light or dark mode automatically according to the folder the opened note sits in. The README records per-folder mappings configured in the plugin's own settings tab, a choice of light mode, dark mode or the system default for each folder, and fallback theme and mode settings used when no mapping matches. It describes the matching as simple and path-based, and documents installation by cloning into the vault's plugins folder or through BRAT while the plugin is not yet publicly listed.
