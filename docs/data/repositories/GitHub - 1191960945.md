# MB-YUL/obsidian-inline-tag-plugin

Inline Tag renders a tag reference carrying a display label as a clickable link in Obsidian's reading view. The syntax pairs a tag beginning with a hash and a label separated by a pipe inside wiki-link brackets, and clicking the rendered label opens Obsidian Search preloaded with a tag query, listing every note that carries or references that tag. The tag part must contain no spaces and may use letters, digits, hyphen, underscore, slash and Unicode, the label is required and may contain spaces, and malformed forms are left as raw text. Settings cover live preview decorations, which the README marks as desktop only, a hover tooltip showing the canonical tag, and a style mode drawing the token like a wikilink or as a tag pill.
