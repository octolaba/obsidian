# ocapraro/obsidian-math-plus

The repository holds Obsidian Math+, a plugin for taking mathematical notes in a dedicated block. Its README records a command, with a default shortcut, that inserts a math block in which equations can be written as LaTeX or written out plainly and parsed, and a pen icon that opens an Excalidraw canvas over the block for freehand annotation. It states that the drawing mode works only in Live Preview, that confirming a drawing renders it as SVG, and that a setting controls where drawings and their data are stored.
