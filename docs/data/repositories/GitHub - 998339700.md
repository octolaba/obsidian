# forketyfork/obsidian-food-tracker

This repository holds Food Tracker, described upstream as an Obsidian plugin to track food intake and nutritional information. The README describes a nutrient database kept as notes with YAML frontmatter in a configurable directory, entries created through a modal or imported from OpenFoodFacts by product name or barcode, and tracking of calories, fats, saturated fats, carbohydrates, sugar, fiber, protein and sodium. On the entry side it describes a configurable food tag with autocomplete suggestions, inline nutrition entries as an alternative to the database, and running totals, and states that layouts adapt to mobile as well as desktop.
