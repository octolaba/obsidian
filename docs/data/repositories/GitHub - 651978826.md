# Mitra98t/vault2book-plugin

Obsidian 2 Book follows the links in a vault, or in a chosen part of it, and assembles them into a single file that can then be exported to PDF as a book with a table of contents. Two commands are documented: one generating a book from the entire vault and one from a specified folder, both invoked from the command palette, with the result written to the root of the vault. The README states that the plugin was not yet in the official Obsidian plugin library and describes manual installation by cloning the repository into the vault's plugins folder and building it with Node.js.
