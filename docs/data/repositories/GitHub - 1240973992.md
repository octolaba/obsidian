# jayp89/kai-command-center

KAI Command Center is a dashboard that reads the body of daily notes kept at a fixed vault path, not only their frontmatter. It parses named sections of each daily note, covering today's focus, frogs to eat, task and quick-win checkbox lists, a calendar of time blocks, a metrics snapshot of label and value pairs, an activity log and an end-of-day section with wins, blockers and reflection. Its tabs give an overview, a focus block, a colour-coded schedule timeline, today's metrics with a 30-day history table, an 84-day activity heatmap with statistics, and a capture box that creates a file in an inbox folder and logs it. The view refreshes automatically shortly after any vault file changes, and the README states that the plugin is meant for a vault used with the Gemini CLI.
