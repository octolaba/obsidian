# sbuffkin/hexmaker

The repository holds Hexmap World Creator, an Obsidian plugin for tabletop role-playing hex-map world-building in which each hex on an interactive grid is a Markdown note in the vault. The README records a hex editor reached by right-click for terrain, icon overrides, links to towns, dungeons, features, quests, factions and encounter tables, and freeform sections that a die button can fill from a random table. Other recorded tools are terrain painting with 1x, 3x and 7x brushes and an eyedropper, path drawing with per-type colour, width, line style and routing mode, weighted random tables with chained workflows, translucent faction and region overlays with a legend, submaps opened from a hex, and a spreadsheet view of every hex with in-place editing and filters. A GM layer toggles between player-facing and GM views, expanding hidden and secret sections.
