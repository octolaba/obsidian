# alifa98/obsidian-emoji-picker

Obsidian plugin that adds a button to the editor toolbar opening a modal with a searchable emoji picker, inserting the chosen emoji at the cursor; the same picker can be opened from a hotkey. The README states that it is built on the emoji-mart library, which as of November 2024 put it at emoji version 15, and gives search together with skin-tone and category selection as what distinguishes it from other pickers and from the operating system's own.
