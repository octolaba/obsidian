# JunDamin/obsidian-hwpx-writer

Obsidian HWPX Writer converts Obsidian notes into the HWPX format used by the Hangul word processor, covering headings, body text, lists, GitHub-flavoured tables, block quotes, code blocks and inline formatting, plus Obsidian-specific syntax such as wiki links, embeds, callouts and highlights, and LaTeX blocks. A sidebar panel previews the converted result page by page through a WASM renderer, and export writes the `.hwpx` file next to the note or into a configured output folder. HWPX files refined in the Hangul editor can be registered as templates whose fonts, heading styles and table borders are copied into the plugin's settings, presets can be saved and restored, and per-document keys in a note's YAML frontmatter override those settings; the README is written in Korean.
