# tardigrde/obsidian-agentic-chat

This experimental Obsidian plugin adds a privacy-focused, agent-led chat in the sidebar. A typed tool system lets the agent read, search, write, edit, rename, traverse links, and manage frontmatter, while tool calls, approval prompts, and diffs are shown inline. It supports desktop and mobile, with OpenRouter zero-data-retention routing or local Ollama.
