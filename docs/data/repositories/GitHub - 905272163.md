# hariiy-sys/Obsidian-NetClip

NetClip is an Obsidian plugin that browses the web inside Obsidian and clips pages into the vault. Articles are saved as Markdown with their title, content and metadata such as author, thumbnail, publication date and reading time, organized into folders and categories, and searchable and filterable by category with auto-completing suggestions. Clipped content can additionally be transformed with Google's Gemini AI through custom prompts that support variables, which requires a Gemini API key entered in the plugin settings and AI processing enabled there.
