# xevrion/obsidian-termina

termina is a tui-style Obsidian theme in which every panel, including the editor, sidebars, status bar and command palette, is drawn as a bordered box with a lowercase label. There are no rounded corners anywhere, the palette is a neutral oklch grayscale with a purple accent in dark and light, and type is monospace throughout using DM Mono with JetBrains Mono and Fira Code fallbacks. The README states that every knob, including gap size, border thickness, font and label color, sits at the top of theme.css, and that the community theme browser submission is still pending.
