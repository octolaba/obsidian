# HWY1dot0/obsidian-screenshot-selection

Screenshot Selection captures selected note content in Obsidian as a PNG image. The README states that on desktop the rendered selection goes straight to the system clipboard with no save dialog, while on mobile the selected text or the current Markdown block is copied when possible and otherwise written to a screenshots folder in the vault; it also notes that a capture on mobile can take the current block without a precise touch selection. The image inherits the active theme — fonts, colours, callouts and code highlighting — so it matches how the note looks on screen, the full selection is captured even when it scrolls off screen, and the capture works in reading view and live preview from a ribbon icon or the editor context menu. An optional watermark can be added as a corner label or a diagonal tiled overlay.
