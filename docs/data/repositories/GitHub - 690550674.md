# danferns/digital-paper-obsidian-plugin

Repository for Digital Paper, an Obsidian plugin that disables the delete functions — backspace, the delete key and cut — so that whatever is written stays there, which the README compares to writing with a pen on paper. Paper mode is toggled from the command palette, and the status bar shows the word paper while it is enabled. The README frames the goal as accepting flaws and getting ideas down before editing in a later pass, and describes the plugin as the Obsidian version of a minimal web app doing the same thing.
