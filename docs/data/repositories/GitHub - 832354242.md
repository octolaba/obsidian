# L3-N0X/obsidian-marker

This plugin converts PDFs into Markdown inside Obsidian using different models, with support for OCR, LaTeX formulas, tables and images. The README states that a conversion endpoint is required and lists the alternatives: a self-hosted Marker API, Marker's own Python API, the hosted datalab service with a paid account, or a free Mistral AI OCR key. It records that without such an endpoint nothing can be converted, and it links the related Marker project, container and API repositories.
