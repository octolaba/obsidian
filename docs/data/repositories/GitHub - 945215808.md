# networkmastered/obsidian-compress

File Compressor introduces a `.ctxt` compressed text file type for Obsidian, which the README says also holds Markdown. A Create new ctxt button makes such a file in the vault root, and it is then edited like an ordinary file: the plugin reuses Obsidian's Markdown editor, keeps it from refreshing to the saved data, and compresses the contents after Obsidian saves; seeing the compressed data is described as a state fixed by closing and reopening the tab. The README states that only Markdown files have been tested, that any plain-text file should compress, that a converted file is no longer read by the plugin, and that a file belonging to another plugin's own type is turned into Markdown instead, which it plans to change.
