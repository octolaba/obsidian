# taskrobin/Obsidian-Plugin

This repository holds the TaskRobin Email Sync plugin, which copies emails and their attachments into an Obsidian vault so they can be kept as a searchable archive there. The README records the setup: enter an email address in the plugin settings, create a forwarding alias, choose the storage directory and set attachment preferences, then have the inbox forward the selected mail to that address. Synchronization is triggered on demand from the plugin's icon in the side panel, several inboxes can be integrated, and the README states that setup starts a seven-day free trial after which a paid subscription applies.
