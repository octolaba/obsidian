# kevinkickback/Combo-Colors

Combo Colors applies color automatically to fighting game combo notations in Obsidian notes. A note declares a `cc_profile` frontmatter property naming the notation style — Arc System Works, a modern alternative style, traditional, or a custom profile — and combo notations are wrapped in `=:` and `:=` delimiters to be colored. A `comboButton` marker anywhere in the note, or a command, toggles between text and icon rendering of the notation. Custom profiles are created in the plugin settings with a display name, a unique identifier and a set of edited inputs.
