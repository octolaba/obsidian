# ryan-manor/Obsidian-Seek

Seek is a hybrid search plugin for Obsidian that fuses dense semantic embeddings with a lexical BM25 ranker, embedding notes with a local model so that indexing, embedding and ranking all happen inside Obsidian and notes and queries stay on the machine. The README lists support for 52 languages plus code, inline filtering with autosuggestions, mobile use through a synced cross-device index, and relevance tuning tested on vaults up to tens of thousands of notes. It records one network dependency explicitly: the embedding model weights and the runtime that executes them are downloaded once per device the first time a vault is indexed, from a model host and a CDN it names.
