# HornatX/floating-heading

Floating Heading shows the heading of the current scroll position in a draggable floating window over the Obsidian editor, updating it in real time as the document is scrolled. The window can be dragged anywhere and locked in place, its heading level is switched between H1 and H6 from a right-click menu, and clicking the displayed heading scrolls to that position. Settings adjust font size, window width, corner radius, background and text colour, and whether Markdown formatting such as bold and links inside a heading is kept or stripped. A command toggles the window's visibility and can be given a hotkey; the README is bilingual in Chinese and English.
