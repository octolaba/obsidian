# Naros899/obsidian-paperstudio

This plugin publishes an Obsidian note to the Paper Studio service, which returns a shareable HTML document. According to its README the publish command converts the note's Markdown to HTML using the brand settings configured on paperstudio.ink, uploads local images referenced by wiki-style or standard Markdown embeds in PNG, JPEG, GIF, WebP and SVG, leaves images given as URLs untouched, and copies the resulting link to the clipboard. It records an account and a generated API key as prerequisites, plus an API URL setting that only self-hosted instances need to change.
