# lemannrus/smart-linker

Repository for Smart Linker, a plugin that finds semantically related notes from precomputed embeddings and inserts links to them. The README states that it reads vectors produced by a separate Vector Search plugin backed by a local Ollama embedding model, ranks notes by cosine similarity, and writes results into a dedicated managed block at the end of the note without touching the rest of its content. Link count, similarity threshold, excluded folders and display format are configurable, and duplicate suggestions from chunked embeddings are removed.
