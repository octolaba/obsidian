# goderyu/obsidian-blueprint-renderer

This plugin recognises Unreal Engine blueprint code pasted into a blueprint code block and renders it as an interactive node diagram inside Obsidian notes. It is built on BlueprintUE Self-Hosted Edition and, rather than refactoring that project into TypeScript, loads its original render.js and render.css directly, taking the main class from a window global and wrapping it thinly for Obsidian. The README states that this keeps compatibility with all node types, connections and interactions, and that CSS scoping isolates the rendered styles from Obsidian's own.
