# eugenschmalz/obsidian-rollover-daily-todos-helper

An unofficial companion to the Rollover Daily Todos plugin that opens today's daily note after a configurable startup delay of zero to one hundred and twenty seconds. The stated reason is that on some setups, particularly Android with a synced vault, today's note is created so early during startup that plugins listening for the file-creation event miss it, so delaying the open makes the ordering more reliable. It runs the daily-note open command, resolving a fallback command by prefix, can skip when today's note is already open, can run a second command such as the rollover itself afterwards, and offers a manual run command; it is not desktop-only.
