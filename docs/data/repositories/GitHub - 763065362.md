# leolazou/obsidian-multilingual

Obsidian Multilingual is a plugin that translates note names into other languages and stores the translations as aliases, so that a note can be linked in whichever language is currently being written. Translation runs automatically when a note is created or renamed, and a folder, a regular expression and a date format can be excluded, with YYYY-MM-DD names never translated automatically. Because the translations are ordinary Obsidian aliases, the README states that links keep working if the plugin is uninstalled, and it records as a current limitation that renaming a note adds new translations without removing the old aliases.
