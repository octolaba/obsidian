# RahmaniErfan/abstract-folder

Obsidian plugin that builds a virtual file explorer out of frontmatter links instead of physical folders, with parent and child properties declaring the hierarchy. One file can appear under several parents at once without being duplicated, any file can act as a parent for other files, and reorganising the vault means editing text while the file system stays untouched. A command converts an existing physical folder structure into these properties and can export abstract folders back into physical ones, and the view supports drag and drop as well as custom groups for filtering.
