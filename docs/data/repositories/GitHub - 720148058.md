# shiwer/ear-training-obsidian-plugin

Obsidian plugin for ear training, written by its author to practise recognising intervals and chords. A practice session is started from the ribbon or the command palette, its intervals, practice mode — melodic, harmonic or combined — and number of exercises are chosen in the settings, and answers are entered from the number keys with further keys to move between answers and replay the sound. At the end of a session the failed intervals and chords are listed, and results can optionally be saved as Markdown files.
