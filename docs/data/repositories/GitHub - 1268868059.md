# raniendu/OChat

Obsidian plugin that adds a right-sidebar chat over local models, using Ollama by default and also speaking to OpenAI-compatible local servers such as LM Studio or a llama.cpp server. Context can include the active note, selected text, notes attached explicitly by mention, and ranked Markdown snippets from the vault; replies render through Obsidian's Markdown renderer, thinking blocks are collapsed, and edit proposals go through a review step before Markdown-only writes are made with Obsidian's own APIs. First run checks the default local endpoint and offers a model picker, and the settings panel tests endpoints with visible success, warning and failure states. The README records that public endpoints need an explicit acknowledgement, since note context would leave the machine, and that there is no telemetry, advertising or auto-update mechanism.
