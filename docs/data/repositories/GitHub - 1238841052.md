# Webcreator3478/D-D-Beyond-Character-Importer---Obsidian-Plugin

DnD Beyond Importer pulls a public D&D Beyond character into an Obsidian note, writing ability scores, saving throws, skills, HP, AC, speed and proficiency bonus together with an inventory table showing equipped status and weight, spells grouped by level, racial traits and feats, currency, and the backstory and campaign notes taken from the source. Key statistics are exposed as YAML frontmatter properties so Dataview can query them, and a refresh button re-imports and updates the existing note in place. The README also describes a dice roller from d4 to d100 with toast notifications and roll history, and an interactive character sheet overlay carrying HP tracking, rolling and spell slots.
