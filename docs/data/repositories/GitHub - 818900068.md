# HandcartCactus/obsidian-remove-newlines

Remove Newlines adds four commands that strip line breaks from text: two remove newlines from a selection or from pasted text, turning hard-wrapped text into a single paragraph and optionally also removing word-break hyphenation and collapsing consecutive whitespace, and two remove blank lines from a selection or from a paste. The commands appear in the right-click context menu and can equally be run from the command palette or bound to a shortcut. The README gives the cases they were written for: text copied out of PDFs, which arrives hard-wrapped and hyphenated, text copied from the web, which converts to Markdown with many blank lines, and text copied from chat assistants.
