# nocodeuse-dev/memos-plus

Memos Plus is a local-first Obsidian capture and organization workspace that writes readable yearly Markdown memo files. It can collect links, notes, tasks, callouts, code blocks, and custom formats, then support search, filtering, calendar views, reviews, and inline task updates. Optional Apple Reminders and Calendar synchronization is available on macOS, while accounts, telemetry, and ads are not used.
