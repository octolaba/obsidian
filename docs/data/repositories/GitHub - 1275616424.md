# nocodeuse-dev/memos-plus

Memos Plus is a local-first capture and filing workspace that keeps memos as yearly Markdown files under a configurable folder, with quick capture from the main view, a popup, the sidebar or mobile, timeline cards rendered as Markdown, search, tag filtering and today, week, todo, pinned, starred and archived views. Captured content can be filed straight into a project file, a tag file, a recent file or under a real Markdown heading, as a link, a plain note, an Obsidian Tasks item, a callout or a code block. Its privacy section states that there are no accounts, telemetry or ads, that only URLs explicitly chosen for title analysis are requested, and that the opt-in Apple sync is macOS-desktop-only, exports only tasks carrying the configured tag, stores no credentials and does not propagate deletions.
