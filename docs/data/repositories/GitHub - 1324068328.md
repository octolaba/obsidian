# CosmicSeaFox/Geode-Black-Opal

Geode Black Opal is a handcrafted Obsidian theme with a dark mode of deep near-black surfaces and cyan crystal glow and a light mode of soft mineral surfaces with translucent panels. Beyond the default opal palette it includes further crystal variants named Quartz, Sapphire, Emerald, Amethyst, Citrine and Diamond. Body text uses Inter, headings Cormorant Garamond and code JetBrains Mono, and the styling extends to callouts, tables, code blocks, properties, tags, checkboxes, the calendar and the graph view. The layout is responsive for mobile as well as desktop.
