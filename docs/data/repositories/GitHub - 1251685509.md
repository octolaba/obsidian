# bueckerlars/obsidian-consistent-attachments

Obsidian plugin that moves or copies a note's attachments when the note moves between folders. The README describes handling shared attachments with a skip, copy or ask policy, destination choices of the Obsidian default, a note subfolder, the note's own folder or a fixed vault folder, and numeric suffixes that avoid overwriting. It also lists scans for orphaned attachments with filtering, sorting and trash cleanup, scans for misplaced attachments that are still linked from a wrong path with preview and relocate actions, a recent operation log held in memory, and manual actions from the command palette and the file context menu.
