# nestedshell/runalone-project-manager

A project management plugin for Obsidian aimed at individuals rather than teams, storing all of its data as plain Markdown files in the vault and working fully offline with no accounts or external services. It combines a Kanban board view with an interactive Gantt timeline, switchable in one click, where tasks are rescheduled by dragging and resized to change duration. Tasks group into projects with custom icons, nest as subtasks up to three levels, take dependencies through an `@after` syntax, and carry pending, in-progress, done or cancelled status alongside milestones, a today indicator, day, week and month zoom levels, linked notes, and undo and redo.
