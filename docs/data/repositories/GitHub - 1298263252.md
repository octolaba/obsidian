# maksparker/canvas-toolkit

A toolkit that adds customization controls to Obsidian Canvas. The README lists editable labels on Canvas cards, text cards displayed as sticky notes, groups displayed as solid boards, switching card and group appearance across a whole Canvas, default appearances for newly created cards and groups, adding groups from the Canvas toolbar, and mobile-compatible controls. Appearance options are reached by right-clicking a card or group, with defaults under the plugin settings. The README states the plugin is not yet in the official community directory and documents manual installation.
