# beardicus/obsidian-draft-indicator-plugin

Repository for Draft Indicator, an Obsidian plugin that marks notes carrying `draft: true` in their frontmatter in the file explorer. Such a note is shown with a small pencil icon beside its name, and the name itself is italicised. The README states plainly that the plugin has no settings.
