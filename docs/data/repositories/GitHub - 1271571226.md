# toki1703/publish-status

Publish Status shows the Obsidian Publish state of each file in the file explorer as a single-letter badge beside its name, in the manner of the Git status markers in VSCode. The badges are A in green for a file added but not yet published, M in yellow for a published file with local changes, and D in red for a file deleted locally. Status is fetched at startup and refreshed when the active file changes or a file is edited, and can be refreshed by hand from a ribbon icon or a command. The README, written in Japanese, records that Obsidian 1.12.0 or newer and the enabled core Publish plugin are required.
