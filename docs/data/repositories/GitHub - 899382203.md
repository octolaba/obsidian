# Chrstn67/WonderBox

WonderBox turns fenced text blocks written with a triple-colon marker and a type name into styled callout boxes in an Obsidian note. The README lists note, tip, info, warning and danger among the supported types, along with success, error, critical, debug, update, question, announcement, progress and highlight, and each box may carry a title given in the opening marker. The README is written in French and English.
