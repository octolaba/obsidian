# slonoed/obsidian-future-dates

This repository holds the Obsidian future dates plugin, whose short README says it adds a view in the right panel collecting every link that points at a future date, offered as a way to see upcoming tasks in one place. The README states that the plugin takes its date template from the core Daily notes plugin. No upstream repository description is recorded, so this body rests on the README alone.
