# wanabeunique/obsidian-workout-tracker

Workout Tracker logs workouts inside Obsidian and keeps the resulting fitness data in the vault. Muscle groups are created first in the plugin settings and exercises are defined under each group, with parameters such as weight, sets and repetitions; a workout is then assembled by selecting exercises from that predefined list and adjusting their parameters. A heatmap shows workout consistency and intensity over time, and per-exercise statistics track progress including the custom parameters that were defined.
