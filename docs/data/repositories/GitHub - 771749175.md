# Loac/obsidian-fight-note

Renders Tekken move notation written in a fight code block into a readable form. A full notation uses the keywords input, name, damage and hits; a short form gives only the input line, and the parser also accepts loosely written variants. Any run of characters separated by spaces is treated as notation, while text in quotation marks is treated as a comment. Abbreviations differ in appearance by type, covering stances, special moves and stage-related entries, and further notations can be added or existing ones overridden in the settings with a set of colours and effects.
