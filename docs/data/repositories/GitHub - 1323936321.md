# jdjshhc/cheers

cheers is an Obsidian theme that keeps the default theme's design and adjusts only its typography and colors, with few options and nothing to configure before use. Ten color schemes are included across dark and light modes, and the theme is adapted for the Style Settings plugin. It also points to two recommended font downloads, one from Huawei's design resources and one for LXGW WenKai.
