# HotAndCold245/Deadline-Countdown

Manages deadlines in Obsidian and counts them down in a sidebar view. A deadline carries a title, a date and time, an optional category that otherwise defaults to General, optional recurrence with an interval between one and thirty days, and an optional visual warning from one to twenty-four hours in advance. The README states the sidebar lists deadlines in the order set in the settings and refreshes only when its refresh button is pressed, in order to reduce unnecessary screen updates, shows an approaching deadline inside a red box, and displays a passed message for a non-repeating deadline whose time is over. The plugin is described as entirely compatible with the mobile version of Obsidian.
