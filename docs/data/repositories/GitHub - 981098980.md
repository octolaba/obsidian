# SourTarte/Powered-By-Lancer

Powered By Lancer is a theme for the Obsidian Markdown editor based heavily off the aesthetics of the Lancer tabletop role-playing game and of Santi Younger's Wasp theme. It is available in the Obsidian community themes and is applied from Settings, Appearance, Community Themes, Browse, choosing Overwrite if any options appear. The README also points to a retouched fork by Cloopy, credited with turning the setting-analogous original into something usable as a daily driver.
