# LanternYoru/obsidian-chinese-converter

This repository holds Chinese Converter, an Obsidian plugin that converts text between Simplified and Traditional Chinese. Conversion runs from a ribbon icon whose label toggles between the two directions, or from command palette entries for converting simplified to traditional and traditional to simplified. It acts on the current selection, or on the whole document when nothing is selected. The README states the same content twice, in English and in Chinese.
