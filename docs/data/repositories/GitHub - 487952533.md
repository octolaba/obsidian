# ntawileh/obsidian-google-lookup

The repository holds Obsidian Google Lookup, a plugin that inserts Google Calendar events and Google contact details into a note. Its README records two commands driven by a suggestion dialog, one searching calendar events for readers who take meeting notes and want the meeting's details filled in, and one searching personal contacts as well as a Google Workspace directory for readers keeping notes on the people they work with. It also records support for several accounts at once and customizable templates for the inserted content.
