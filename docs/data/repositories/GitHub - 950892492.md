# mildeveloper/obsidian-date-range-expander

Repository for Date Range Expander, an Obsidian plugin that inserts a sequence of dates into a note. A command opens a modal that takes a start date and either an end date or a duration of up to a hundred days, weeks or months, plus a toggle for wrapping the dates in a callout. Settings define the output date format, a friendly format used in callouts and messages with documented day, month and year tokens, and the separator between dates, and further options turn the dates into wiki links with configurable file creation behaviour.
