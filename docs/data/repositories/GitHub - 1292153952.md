# is-cout/maguilanote-obsidian

This repository holds a Milanote-style visual workspace for Obsidian, where notes, images, links, files, columns, to-do lists, colour swatches, comments, audio recordings, nested boards and arrows sit on an infinite canvas inside the vault. Each board is a single JSON file in the vault, and the README states that there is no account, no server and no real-time collaboration, describing cloud collaboration as out of scope rather than as a missing feature. Recorded features include board templates, broken-link detection, card previews, item locking, freehand drawing and sketch cards, and a record card whose audio can be sent to the OpenAI Whisper API with a user-supplied key so the transcript lands in a connected note card.
