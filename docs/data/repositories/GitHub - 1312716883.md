# search5/harang-contacts

harang-contacts lets a note reference a contact held in a CardDAV address book. Typing a dedicated inline trigger opens a staged autocomplete that first picks a server profile and then a contact, and inserts a reference carrying the profile's internal id and the contact's CardDAV UID, so two people with the same name are never confused and renaming a profile does not break the link. The reference renders in Live Preview and Reading view as a chip with the contact's name and email, and clicking it opens a card with email, phone and organization. Any number of server profiles can be configured and searched together, discovery walks the standard CardDAV path from the principal to the address book collection, contacts are cached with a configurable expiry, and the plugin only reads and never writes.
