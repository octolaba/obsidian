# NiccoloNiccoli/obsidian-document-rating-system

Adds star ratings from 0 to 5 to Markdown notes, entered through a status bar input and stored in the note's frontmatter as a numeric `rating` property, so they work with Obsidian Properties. A rated note shows a star widget at the top of the document. A panel opened from a ribbon icon filters notes in the vault by their rating.
