# SirwanAfifi/content-rtl

Content RTL sets text direction per line rather than for the whole interface: a line containing Persian, Arabic, Kurdish, Urdu or Hebrew script is rendered right-to-left, including mixed lines, while English-only lines stay left-to-right. It works per line in the editor and Live Preview and per block in Reading view, on desktop and mobile, and leaves Properties, the inline title, the note footer, sidebars, the status bar, raw frontmatter, inline code, fenced code and math left-to-right. Separate settings govern editing and reading behaviour, a command toggles the plugin's direction handling temporarily, and Obsidian's own right-to-left editor option is expected to be off because it affects more than note content. Note text is examined locally, with no network requests, telemetry or changes to files.
