# kilrkrow/obsidian-bible-verse

Bible Verse looks up and displays Bible verses in Obsidian notes through the HelloAO Bible API, with no API key needed for the built-in translations and the ESV available through the reader's own free key. An inline reference in braces such as `{John 3:16}` renders a linked verse, autocomplete suggests book names and confirms complete references while typing inside the braces, and a code block accepts several references at once including ranges and lists. Modifiers after the reference override the translation, place two translations side by side for comparison, force a sidebar or callout style, hide verse numbers or put each verse on its own line, and bake commands can turn a reference into a real collapsible Obsidian callout that inherits the theme and fold behaviour.
