# linyp/obsidian-interlinear

Interlinear renders a paragraph-by-paragraph translation beside the original text in Obsidian's reading view, either bilingual or translation-only. Translations are injected as render-layer DOM only, so the file on disk stays byte-for-byte unchanged, and a translation is requested only when the floating button, a status-bar button or the command is used, never on opening or switching notes, scrolling or changing settings. Credentials are supplied by the user, held in vault-local plugin settings files, and the README states they are never logged and go nowhere but the configured translation endpoint. The README marks this state of the plugin as reading view only, with no editing or Live Preview translation.
