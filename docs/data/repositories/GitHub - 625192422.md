# mii-key/obsidian-links

Obsidian Links is described as a plugin for manipulating and managing links. Its README groups the commands it adds: creating a link from the selection or from the clipboard, with an option to select the word under the cursor automatically; converting between wiki links, Markdown links, autolinks and HTML links, singly or in bulk; unlinking, deleting a link, and removing links from headings. Further commands copy or cut a link or its destination to the clipboard, edit or set link text and destination including from the clipboard, and embed or unembed files. Each command is reachable from the command palette or the context menu.
