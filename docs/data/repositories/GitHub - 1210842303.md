# blamouche/obsidian-geocode-note

Writes geographic metadata into a note's YAML frontmatter — coordinates, the resolved address, a marker icon and a colour — for use with map plugins such as Map View. Coordinates can be set from device geolocation, from an OpenStreetMap Nominatim address search, by typing latitude and longitude, or by dragging a marker on an interactive vector map whose address is refreshed by reverse geocoding as it moves. A geocode-map code block renders an interactive map centred on the note's coordinates with the same marker and an optional height, and a bulk export writes every geocoded note to GeoJSON, KML, GPX or CSV. The README states that no API key is needed because every service used is free and open, and describes an update mode that reloads existing values for editing.
