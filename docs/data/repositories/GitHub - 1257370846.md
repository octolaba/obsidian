# gorazenxu/pimate

Pimate embeds the Pi Coding Agent into Obsidian as a chat panel that can read and edit vault files and run commands without leaving the app. Its README describes streaming replies, mentioning any file or folder for context, a toolset covering read, write, edit, grep, find and bash inside the vault, sending an editor selection to the model and previewing the returned diff before applying it, optional reasoning blocks, session statistics for tokens, cost and context, session tabs, reusable prompt snippets with variables, context compaction for long sessions, pasted or dropped images and a bilingual interface. It records the plugin as a hybrid that runs a local Pi process, requiring Node.js 18 or newer, Pi installed globally, and an API key or Pi's own login flow, with several model providers selectable.
