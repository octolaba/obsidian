# Rahuletto/supersync

SuperSync backs up and synchronises an Obsidian vault to a private GitHub repository through GitHub's own APIs rather than a local Git installation, which the README gives as the reason it runs on desktop and on iOS and Android without extra setup. Authentication uses GitHub's device code flow, so no personal access token is pasted into the plugin, and syncing can run at startup, immediately after a change, or on a timer. When the same file is edited on two devices both versions are kept — the local change stays and the remote one is saved beside it under a timestamped conflict suffix — and the plugin can browse and restore earlier versions of a note and skip files through glob ignore rules.
