# anselmwang/obsidian-mark-and-select

The repository holds Mark and Select, an Obsidian plugin providing two commands for selecting a region of text: setting a mark and then selecting from that mark to the cursor. Its README shows the pattern combined with other navigation, such as setting a mark and jumping to the next heading before selecting, so a whole section can be taken without dragging. It records the plugin as especially useful on mobile, where selecting long passages by long tap and scrolling is slow and the selection is easily lost.
