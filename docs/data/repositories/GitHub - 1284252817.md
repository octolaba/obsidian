# max-fluff/obsidian-glossary-linker

Highlights glossary terms in notes even when they are inflected, matching plurals and declensions rather than exact spellings, and lets the highlights be turned into real internal links. The term list is built from each glossary file's name and its aliases, multi-word and hyphenated terms match as a whole with the longest match first, and the morphology engine selects itself by the word's script, with eight language modules built into the bundle and more addable as modules. Highlights behave like internal links in reading view and in the editor, showing the term's page preview on hover and opening the glossary note on a modifier click. The README states that aliases are also collected from links made by hand, and that linking a word to a heading inside a file is deliberately left to a sibling plugin sharing the same matching engine.
