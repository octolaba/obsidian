# gfxholo/calculite

A standard calculator for simple arithmetic inside Obsidian, which the README argues is more convenient than switching to the system calculator, especially on mobile. It opens from a ribbon icon or from commands that show the calculator in a tab, move it between the sidebars, or, on desktop, toggle a floating window that stays available outside Obsidian. The README states that there is no history of previous calculations but that copy and paste work, that the current equation survives closing and relaunching Obsidian as long as the calculator tab stays open, and that most hotkeys of the Windows and macOS calculators are supported. It also records compatibility back to an early Obsidian version.
