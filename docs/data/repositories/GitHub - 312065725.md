# cristianvasquez/obsidian-prettify

This repository holds a Markdown prettifier for Obsidian that reformats untidy Markdown and adds fields such as a modified date, bound to a default hotkey. The README shows a hashtag janitor that collects inline tags into frontmatter, configurable templates for created and updated dates or a generated UUID, autolinking of bare web and email addresses, and normalization of ordered lists. It opens by stating that the plugin is no longer maintained and recommending obsidian-linter for similar functionality.
