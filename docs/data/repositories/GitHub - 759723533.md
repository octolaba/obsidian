# ycnmhd/obsidian-lineage

Lineage is described as giving Obsidian a Gingko-like interface, and its README says it allows Markdown files to be edited in that column-based layout. A file is opened in the view from the ribbon icon, the file context menu, or the command palette. Exporting is offered from the view's own context menu.
