# kpndevroot/obsidian-basalt-causeway

Basalt Causeway publishes an Obsidian vault into a GitHub repository so the Basalt mobile app can read it, and brings edits made there back to the desktop. It writes through GitHub's Git Data trees API rather than through git itself, so one sync is four HTTP requests and produces exactly one commit however many files changed, and because it uses Obsidian's own request helper there is no git binary or Node dependency and it also runs on mobile. It carries no merge machinery: divergence between the two sides is detected and surfaced rather than resolved automatically. Setup needs a fine-grained GitHub token with write access to one repository, stored in plain text in the plugin's data file and sent only to GitHub, with a repository and branch picker and a dry-run command that prints the plan first.
