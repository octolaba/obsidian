# Astraaaa02/Obsidian-Torch-Cursor

The repository holds Cursor Torch, an Obsidian plugin that renders the editor caret as a light source: a flame-shaped glow follows the caret through keystrokes, movement and scrolling while the rest of the note darkens, with the pool of light dimming with distance and a faint halo spilling a few lines above and below. The darkness lifts when the editor loses focus, the caret can optionally be replaced by a glowing gradient bar, and the glow flickers unless the operating system asks for reduced motion. The README states that the effect suits dark themes and falls back to a softer overlay on light ones so the text stays readable.
