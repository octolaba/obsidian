# briancbiggs/biggs-obsidian-theme

Biggs is a square-edged Obsidian theme with bold heading markers, bright accent colours and what its README calls a slightly retro document feel. It ships dark and light palettes, colour-codes heading levels, and applies square geometry to controls, tabs, menus and icons. Links, tags, callouts, blockquotes, tables, inline code and code blocks are styled, the heading scale is adjusted on mobile, and the README notes semantic accent variables intended to improve plugin compatibility.
