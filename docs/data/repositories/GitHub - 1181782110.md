# mikedidomizio/obsidian-divide-and-conquer

Divide and Conquer adds commands for bulk enabling and disabling of plugins and CSS snippets, so a misbehaving plugin can be found by bisecting rather than toggling one at a time. Enable and disable commands come in variants that include or skip a user-defined exclusion list, and bisecting runs in either direction depending on whether the problem is present with everything on or absent with everything off. The README frames the plugin as a debugging aid for vaults carrying dozens of plugins.
