# luke-rmaki/rmaki-obsidian

RMAKI OBSIDIAN is a dark theme for Obsidian that uses the Fira Code typeface. The README reports testing against Obsidian Desktop 0.13.0 and Obsidian Mobile for Android 1.0.5, describes the theme as a work in progress, and keeps a to-do list on which linked mention icon active and graph view remain unchecked. Installation is offered from the community themes browser, by copying Rmaki-Obsidian.css into the themes folder, or by cloning the repository and running a build that writes to a destination named in a .env file.
