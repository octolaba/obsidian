# icarian-systems/kanban-pro-plugin

Kanban for Professionals adds local-first kanban boards to Obsidian and slices the same cards as a board, a table or a list. It reads and writes the same kanban-plugin board Markdown format as the community Kanban plugin so existing boards open without conversion, and it ships a validator that round-trips a file and reports any byte-level difference; the README states that the project is independent of that plugin and not endorsed by it. The free feature set covers drag-and-drop between lanes with undo and redo, inline card editing with a detail panel, embedding a board in another note through a code block, and parsing of due dates, tags, priorities and Dataview fields into chips. A paid tier is described as adding saved views, a dashboard of overdue and due-soon rollups, recurring cards, per-card time tracking, calendar export and GitHub Issues sync.
