# Lemon695/obsidian-hot-reload-picker

The repository holds Hot Reload Picker, an Obsidian plugin that reloads enabled plugins from the command palette during plugin development. The README records a searchable picker, a command that reloads the last plugin again, favourites kept at the top of the list, batch reloading of several plugins, generated per-plugin reload commands configured in settings, an option to hide the plugin from its own reload lists, and an English or Chinese interface following the Obsidian language. It states the plugin is desktop-only, requires Obsidian 1.8.7 or later, works only with plugins that are currently enabled and loaded, and relies on the desktop runtime plugin manager to disable and enable them in place. The README also states that it makes no network requests, carries no telemetry or ads, and stores only its own settings locally.
