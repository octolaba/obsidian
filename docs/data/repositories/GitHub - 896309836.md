# rscopic/obsidian-vault-nickname

Vault Nickname sets a custom display name for an Obsidian vault without renaming the vault's folder. It also chooses the order of the application title, putting either the vault name or the document name first, and adds a context menu item to the vault switcher for changing the nickname quickly. The README gives the motive: vaults that share a folder name are hard to tell apart, which is common for users who keep a standard file structure across projects, such as a docs folder in each one. Its acknowledgements record contributors who reported issues on macOS, Arch Linux and Linux, suggested keeping the nickname file in the plugin's install directory, and added support for reading UTF-8 BOM nickname configuration files.
