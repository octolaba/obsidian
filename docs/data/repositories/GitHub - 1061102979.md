# rockbenben/bring-obsidian-to-front

Bring to Front raises the Obsidian window when a modal or notice appears while the app is in the background, so reminders, sync warnings and plugin notices are not missed while working elsewhere. The README states that it works the moment it is enabled with nothing to configure, that filtering what triggers it is optional, and that it does nothing when the window already has focus, so it never steals focus while the user is typing. It is desktop only on Windows, macOS and Linux because it uses Electron window APIs, and requires Obsidian 1.8.7 or newer.
