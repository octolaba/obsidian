# hitctc/obsidian-images-preview

Images Preview opens a floating preview window when an image in an Obsidian note is clicked, with zooming, dragging, switching between images and a gallery. It offers two modes: a Normal mode that keeps one masked preview at a time, and a Pin mode that keeps several floating windows side by side, capped at one to six images with an option to replace the oldest when the cap is reached. Images are collected from the surrounding context, and when the DOM yields none the plugin parses the current Markdown text instead for Markdown embeds, wiki-link embeds and HTML image tags. Interaction covers drag, wheel zoom, double-click between fit and 1:1, a context menu, a toolbar, keyboard shortcuts and palette commands; the README and settings are written in Chinese with an interface-language setting.
