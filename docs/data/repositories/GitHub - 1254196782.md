# notesynchelper/china-speedup

This repository holds China Speedup, an Obsidian plugin that replaces the community plugin browser with one whose manifests and downloads pass through relay nodes, aimed at users in mainland China for whom the GitHub addresses are slow. The relay proxies the plugin index, statistics and deprecation lists as well as the installation files, probing several relay endpoints concurrently and caching the fastest, and the catalogue offered is the official list minus a server-side blacklist plus specially imported plugins injected from a server configuration. It registers a custom protocol handler so the vendor's own site can open the store and install a plugin, accepting deep links only from that vendor's domains. The update checker never changes the enabled state, installs no downgrade, skips a version whose minAppVersion exceeds the running Obsidian, and reports an unknown version as unknown.
