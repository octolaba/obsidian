# davidvkimball/obsidian-oxygen

Oxygen is a fork of the Minimal theme for Obsidian with its own default colour scheme, animations for workspace panes, modals and menus with customisable speed and motion style, and the ability to save custom colour schemes. The README places it in the Vault CMS project and recommends the companion Oxygen Theme Settings plugin for creating, importing and sharing presets. Everything Minimal exposes through the Style Settings plugin remains supported, and general documentation is left to the Minimal guide.
