# plugins-galore/obsidian-plugins-galore

Plugins Galore sideloads Obsidian plugins that are not in the official plugin directory: the user pastes a repository URL and the plugin installs it, after which it is enabled, disabled or removed like any other entry in the Community Plugins tab. The README states that a repository can come from GitHub or from any GitLab or Gitea instance, that GitLab is untested, and that updates are checked only when asked for, through a button that then lets the user choose which plugins to update. It carries a disclaimer that installing a plugin made by someone the user does not trust is not recommended, and it names Obsidian42 - BRAT as a similar tool aimed more at beta testers.
