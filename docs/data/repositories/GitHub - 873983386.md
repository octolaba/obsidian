# xixia123/obsidian-transfer-latex-from-gpt

This plugin converts LaTeX formulas found in ChatGPT answers into the Markdown form that Obsidian recognises and renders correctly. The README states that it can be installed from the community plugin list or manually from its GitHub repository, and that Obsidian's automatic HTML conversion should be turned off before use, or the answer pasted as plain text instead. Conversion is triggered either from a command or from a button in the left ribbon.
