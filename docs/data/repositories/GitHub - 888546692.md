# vrtmrz/usher

Usher manages customisation files across several Obsidian configuration directories in one vault, scanning hidden folders such as the default configuration folder and per-device variants and grouping the files it finds by role — plugin manifests and main files, styles, themes, snippets and JSON settings. Rather than applying every synced change to the current device, it lets each candidate from another configuration directory be inspected and the wanted version applied selectively. The README is explicit that Usher is not a synchronisation engine and replicates nothing by itself: another transport such as Self-hosted LiveSync hidden file sync, Git or a file sync makes the configuration folders available in the vault, and Usher only compares, chooses and applies what is already there. It is described as a companion tool for Self-hosted LiveSync users.
