# imcauley/todoist-review

This plugin reviews and triages overdue tasks from Todoist inside a note. Its README's usage steps are to install the plugin, enter an API key in the Obsidian settings and add a todoist-review codeblock, and it records as a known issue that refreshing takes some time.
