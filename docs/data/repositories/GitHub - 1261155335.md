# 9963KK/obsidian-pi-ide

This plugin connects Obsidian to the Pi Coding Agent through the pi-ide protocol, so that Pi sees the current file, cursor and selection as ambient editor context and is updated as they change. Its README records handling of diff-opening requests from the Pi-side package, routing of Pi write and edit tool calls through an Obsidian confirmation dialog, and an optional auto-accept mode that is disabled by default. The requirements are Obsidian on desktop and Pi available on the PATH, plus a Pi-side package whose presence the plugin checks at startup and can install on request.
