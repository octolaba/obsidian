# mddevils/floccus-bookmarks-to-markdown

Reads an XBEL bookmark file, as exported by the Floccus browser extension, and converts it into a Markdown file in the vault. The conversion is started from a bookmark icon in the ribbon, and the settings hold the absolute folder path and filename of the XBEL file, the vault folder and filename of the generated note, a backup folder and the number of backups kept. No repository description is recorded, so this note is grounded in the README alone.
