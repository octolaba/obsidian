# codejota/NightlyWolf_ObsidianTheme

codejota/NightlyWolf_ObsidianTheme carries NightlyWolf, a minimalistic Obsidian theme that brings the author's Nightly Wolf theme for Visual Studio Code to a knowledge base. The README describes a dark purple palette chosen to be easy on the eyes during long sessions, a translucent left sidebar that can be disabled through Style Settings, a custom vault cover image in the file explorer, and custom indentation guides.
