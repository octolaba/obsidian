# eudennis/ultimate-todoist-sync-for-obsidian-experiment

This plugin creates, edits and deletes Todoist tasks from inside Obsidian. The README presents it as a beta fork of an earlier Todoist sync plugin, used by its author for some time and open to bug reports. A feature table records which direction each operation works in: adding and deleting a task, labels, priority and duration are supported from Obsidian to Todoist, while content, due date, completion state and reminders work both ways, and items such as description, project, section and moving tasks between files are still marked as planned.
