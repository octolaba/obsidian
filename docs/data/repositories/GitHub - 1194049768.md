# frostmute/Tetromino

Tetromino imports Are.na channels, blocks, metadata and attachments into an Obsidian vault as Markdown notes. The import is one-way and deterministic by design: the same input produces the same output, nothing is pushed back to Are.na, runs are started manually, and a dry-run can preview what a run would write. Optional sync-on-startup and interval settings exist but the README states they stay off until enabled. It records that API compatibility targets the current Are.na REST API version 3 documentation.
