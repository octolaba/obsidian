# johannes-kaindl/health-vitals

Health Vitals reads Apple Health exports into an Obsidian vault and makes the data searchable and visualizable in charts and tables. Its German README explains that there is no HealthKit access, because Obsidian runs in Electron while HealthKit is a native iOS and macOS API, so the plugin works from the export file selected in its dashboard; it parses that XML as a stream in chunks and keeps only compact daily aggregates, citing a 2.6 GB export of 5.7 million records reduced to a cache of about 2.7 MB. The result is a health-cache.json in the plugin directory holding per-metric daily aggregates and a workout list. The plugin is desktop only, and its bilingual interface follows Obsidian's own UI language, German for a German interface and English otherwise.
