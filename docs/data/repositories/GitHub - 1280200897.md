# lkmavi/smart-git-sync

The repository records no description; its README presents Smart Git Sync, an Obsidian plugin that keeps a vault in sync with a Git remote by committing and pushing after every save, debounced, and pulling remote changes on a configurable interval. It runs a rebasing pull before every push, exposes a local HTTP webhook endpoint with an optional bearer secret so an external job can trigger a pull, offers a ribbon action menu, and can pause syncing for a set period without being disabled. The README states the plugin is desktop-only because it invokes the git CLI and the local filesystem, and it documents settings for the commit message, branch, debounce and pull intervals, and whether the Obsidian configuration folder is ignored.
