# fanthus/flomo2obsidian

Synchronises Flomo memos into an Obsidian vault, writing all memos of one month into a single Markdown file and mapping each year to its own vault path. Synchronisation is incremental: new, updated and deleted memos are detected and only the affected months are rebuilt, and a change of output format triggers a full month rebuild. Authentication uses a pasted access token or desktop auto-login. The README records the project as a fork of Watermelon4000/flomo-obsidian-sync.
