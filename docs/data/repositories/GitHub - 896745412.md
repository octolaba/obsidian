# mofukuru/TsumugiMark

TsumugiMark opens a Markdown note in a dedicated vertical-writing pane built on the CSS vertical writing mode, aimed at Japanese texts such as novels and screenplays. Edits made in the vertical pane are saved back to the original file automatically two seconds after typing stops and again when the pane is closed, while changes saved in the standard editor appear in the vertical pane in real time. The README records furigana through a ruby syntax, heading creation by typing hash marks followed by a space, a character count in the status bar that also reports a selection, optional automatic opening of every note in the vertical editor, and settings for font, size, line height, letter spacing, writing direction and column alignment. It states that the plugin is in beta and asks that it be tested on a copy of the vault first.
