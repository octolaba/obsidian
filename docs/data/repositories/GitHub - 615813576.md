# Satchelmouth/Obsidian-Theme-Sanguine

Sanguine is a theme for Obsidian based on classic slasher horror films, created by Satchelmouth and released under the MIT license. Its README is written as the CSS comment header of version 1.0.0 and records dark mode as the supported appearance, stating that all panels, menus and buttons have been looked at. Advanced Tables, Kanban, Calendar and the File Tree Alternative Plugin are named as supported plugins.
