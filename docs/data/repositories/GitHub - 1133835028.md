# selfish/obsidian-task-planner

Task Planner collects the ordinary Markdown checkboxes already spread through a vault and presents them on a drag-and-drop planning board instead of moving them into a separate database. Cards are dragged between Today and future horizons such as backlog, weekdays, weeks, months, quarters, years or custom ones, while overdue tasks stay visible for rescheduling. The Today view splits into Todo, In Progress and Completed columns with an optional work-in-progress limit. Moving a card writes back to the original note, changing the source task's status, due date or optional tag.
