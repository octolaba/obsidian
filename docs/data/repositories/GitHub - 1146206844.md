# Saydullayev017/deadline

Deadline combines a monthly calendar, a Pomodoro timer and a task manager in a single Obsidian workspace view. The calendar highlights today, navigates between months, and opens or creates a daily note in a new tab when a date is clicked. The timer defaults to forty-minute work and five-minute break sessions with customizable durations, a progress bar, status indicators and a sound notification on completion, while the task list adds, checks off and deletes entries. The README states the view uses Obsidian CSS variables and is compatible with light and dark themes.
