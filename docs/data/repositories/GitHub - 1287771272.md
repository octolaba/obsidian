# Perry661/Count-Words-and-Time-ObsidianPlugin

Tracks the current writing session in a sidebar: characters typed, writing time, idle time, total time, average speed and a focus-rate progress bar. Newly typed text is counted while deletions do not reduce the count, and the counting unit can be characters, Chinese characters or English words. Idle time starts after a configurable threshold of 5 to 60 seconds, and average speed is taken from a 60-second sliding window and shown per hour or per minute. Pause, resume and start-new-session controls sit in the panel, which is opened from the ribbon icon or the command palette; the interface follows Obsidian's language or is fixed to Chinese or English.
