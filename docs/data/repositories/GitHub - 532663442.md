# swar8080/obsidian-plugin-update-tracker

The repository holds Plugin Update Tracker, an Obsidian plugin that reports which installed plugins have updates and helps weigh whether to take them. Its README records a list of pending updates with their release notes, installation from that list, and several ways of judging the risk: statistics about a new version's adoption, an option to hold updates back for a few days before showing them, and a view of the code changes between two versions of a plugin. It also records viewing and installing beta versions, ignoring particular updates, customizing the plugin's appearance, and a public API for checking updates from elsewhere.
