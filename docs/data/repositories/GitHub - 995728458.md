# LucasOe/obsidian-template-folder

Template Folder replaces the Insert Template command of the core Templates plugin so that a note can be moved when a template is applied. The README records that the destination is named by a frontmatter property in the template file, that the property name is configurable and defaults to folder, and that the property is removed from the note after the template is applied unless that setting is turned off. It warns that with this plugin enabled the Insert Template command always replaces the entire note with the template instead of appending or merging as the core plugin does, and it records the core Templates plugin as a prerequisite.
