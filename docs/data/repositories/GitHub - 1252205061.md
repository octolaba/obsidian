# liuh886/ownly

Ownly records what a person owns, what it cost, how it was used and what was learned, keeping that data as plain Markdown with YAML frontmatter inside its own data folder. Its README states that Obsidian is a convenient place to store and inspect those files but is not required, since the same runtime is also offered as a hosted web app and an installable progressive web app, and that installing changes the launch experience rather than the data model. On first use, when no folder permission exists yet, it asks either to create new local data under a chosen parent such as Documents, a vault root or an empty folder, or to open an existing folder, and initializes its structure there.
