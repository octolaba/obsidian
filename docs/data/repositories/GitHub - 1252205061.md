# liuh886/ownly

Ownly is a local-first ownership and decision ledger that records items, costs, usage, and lessons as Markdown with YAML frontmatter. Its Obsidian plugin, Web app, PWA, and Agent CLI share an Ownly data-folder layout, while the browser asks for explicit local permissions and does not upload personal Markdown contents.
