# KulySocc/obsidian-folder-base-view

Folder Base View opens a chosen .base file as a folder's table of contents when the folder is clicked in the file explorer, scoped to that folder and needing no companion note. A one-click settings action creates a recommended index base, or any existing base can be set as the default; individual folders can be mapped to their own base by exact match. Settings also choose whether a single click, a double click or a modifier click triggers the view, whether the folder also expands on open, and whether .base files are excluded from the listing, and the chevron keeps its usual expand and collapse behaviour. The README states that Obsidian 1.13 or later on desktop with the core Bases plugin enabled is required.
