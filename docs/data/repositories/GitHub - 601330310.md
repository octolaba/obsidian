# LostPaul/ob-open-files-with-commands

This plugin creates a command for each chosen file, where the command only opens that one file and can therefore be reused by the Commander plugin. Commands are created by right-clicking a file name, from the file menu, or in the plugin settings, and those settings also rename them, delete them, and change the path a command points to.
