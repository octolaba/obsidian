# is-cout/notioneer-obsidian

Notioneer adds three Notion-style editing conveniences to Obsidian: a note header with a cover image, an editable title and property rows; a slash-command menu for inserting blocks; and a toolbar that appears over selected text. The cover comes from a cover frontmatter key, renaming through the header renames the file and updates links, and the property rows read and write ordinary frontmatter. Slash commands are meant to insert plain Markdown rather than a plugin-specific format, and the selection toolbar covers bold, italic, strikethrough, inline code and links. As of version 0.7.0 the plugin is a fork of make.md being trimmed to those three features, with spaces, the navigator and space views switched off by default and the Markdown-native slash commands and selection toolbar still parked outside the build.
