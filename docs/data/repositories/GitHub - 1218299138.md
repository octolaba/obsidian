# davidvkimball/obsidian-yeet

Publishes the current note to yeet.md from a single hotkey and stores the per-snapshot delete token so the note can be unpublished from inside Obsidian. A publish handles three cases: a fresh note is posted and the returned URL copied, an unchanged published note only has its existing URL copied, and an edited one prompts to copy the old link, publish an additional snapshot, or replace the old snapshot with a new one. Each publish creates an immutable snapshot at its own address, so editing the source note does not change what was published. Four commands cover publishing, copying the link, unpublishing the latest snapshot and listing every snapshot from the vault, and a desktop status-bar indicator shows whether the buffer still matches its snapshot.
