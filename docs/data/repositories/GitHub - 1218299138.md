# davidvkimball/obsidian-yeet

The yeet plugin publishes the current Obsidian note as an anonymous snapshot and stores its returned URL and delete token for later management. Commands cover publishing, copying links, unpublishing the latest snapshot, and listing snapshots; unchanged notes reuse an existing URL, while edited notes can remain, create a new snapshot, or replace the prior one. Tokens are kept in Obsidian SecretStorage, and configurable property stripping affects only the upload payload.
