# mugiwara85/CodeblockCustomizer

Codeblock Customizer changes how code blocks are displayed in Obsidian. The README lists built-in themes — Obsidian, Solarized, Dracula, Gruvbox, Nord and Tokyo Night — or custom ones, active line highlighting for the editor and for code blocks, exclusion of specific languages or individual blocks, custom background colors, and highlighting of chosen lines or text segments in several definable colors. A header can show a filename or title with a language name and icon and can fold the block on click, with default fold states and persistence; line numbers with a starting offset, semi-interactive terminal prompts, tabbed groups of consecutive blocks, styled comment annotations, inline code highlighting and hidden fence lines are also offered. The README further records an option to use PrismJS for syntax highlighting in editor mode so that editor and reading mode match.
