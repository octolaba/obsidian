# eddie-d0/last-chess-game

Obsidian plugin that pulls the most recent Chess.com game for a username and inserts it at the cursor, typically in a daily note. Separate commands cover the last blitz, rapid, daily, bullet or any-type game, and a lookup command fetches the latest game of any other Chess.com user. Two templates are configurable, one for the user's own games and one for looked-up players, filled from handlebars for game metadata such as rating status, rules, start and end date and time, move count and duration, with date and time formats set in the settings.
