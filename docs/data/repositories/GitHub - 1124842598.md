# EATMELONSEC/OpsToMP

Obsidian plugin that converts Markdown notes into the HTML a WeChat Official Account accepts and uploads them to its draft box or publishes them directly. It previews the rendered result inside Obsidian, uploads local images to WeChat servers, applies account-style themes, and offers one-click formatting for paragraph spacing, headings, images, quotes, code blocks and lists. The README also records XSS filtering of dangerous tags and attributes, tests for network connectivity and API key validity, and management of existing drafts and published articles.
