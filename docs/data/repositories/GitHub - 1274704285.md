# dsvictor/ink-floating-toc

Ink Floating TOC is a floating table of contents for Obsidian that draws headings as proportional bars rather than a list of text, with each bar's length and thickness indicating its heading level so the document structure can be read at a glance. It detects whether a mouse or a touch screen is in use and adapts its gestures: on desktop a click scrolls to the heading, Ctrl or Cmd click folds it in the editor, and Alt click collapses its sub-headings within the table of contents itself, while on a tablet the same three actions are bound to a single, double and triple tap. The README presents it as covering headings H1 to H6 and as designed to occupy little screen space and to follow the active theme.
