# RobertMeissner/obsidian-long-sentence-highlighter

An Obsidian plugin that highlights sentences longer than a configurable word-count threshold, in both editing and reading modes, to keep prose short. The README records a default threshold of 20 words, a choice between background and underline highlighting with customizable colours, commands to toggle highlighting, highlight the current note or clear highlights, and updates as the text is edited. It states that the highlighting uses CodeMirror 6 decorations so it does not interfere with editing, and that the author wrote it for brief sentences in a novel.
