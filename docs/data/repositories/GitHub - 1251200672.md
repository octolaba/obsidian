# Obsidian-TTRPG-Community/Town-Forge

Town Forge generates fantasy maps for tabletop games from a seed and a few choices, producing terrain, forests, mountains, roads and a settlement in a cartographic style. Terrain covers river, coastal, lake, mountain and inland maps, settlements range from a hamlet through town tiers to city tiers with organic street layouts, districts, walls and bridged rivers, and landmarks include a castle, cathedral, market, barracks, docks, mills, stables and a rare isolated tower. A side panel regenerates the map as terrain, settlement size, approach roads, density and landmarks are adjusted, from which the map can be inserted as a town-forge code block, saved as an image, or exported to the separate TTRPG Tools maps plugin with generated place notes. The README states that generation is deterministic, so the same seed always produces the same map.
