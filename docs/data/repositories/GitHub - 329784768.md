# beet/page-headings-obsidian-plugin

Page Headings inserts a Markdown heading built from the filename whenever a blank note is opened, whether it was just created from a wiki link or already existed and was empty. The heading is derived by removing the file suffix, replacing underscores with spaces and capitalizing the first word, so a file named this_is_my_filename becomes the title This is my filename. The README frames this as support for workflows where the page heading is expected to match the filename.
