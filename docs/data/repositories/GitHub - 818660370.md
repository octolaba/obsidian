# chenshutian9610/obsidian-pagescroll-plugin

Page Scroll adds four buttons that jump to the top of a note, page up, page down and jump to the bottom. The README states that it was originally written for e-ink devices, where normal page turning leaves residual shadows on the screen, and it shows a desktop and a mobile example.
