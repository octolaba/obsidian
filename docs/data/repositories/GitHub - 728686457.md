# RyotaUshio/obsidian-rendered-block-link-suggestions

Rendered Block Link Suggestions renders Markdown inside Obsidian's built-in block link auto-completion — the suggestion list triggered when a link is typed up to the block-reference caret — so that each candidate block is displayed as it would read rather than as raw text. The README shows the suggestion list with and without the plugin, and offers installation from the community plugin browser or, for the latest beta, through BRAT.
