# technerium/obsidian-ukiyo

Ukiyo is an Obsidian theme forked from a theme by Kinmury, whose original account the README records as deleted. Its stated focus is easing the eyes and removing unnecessary empty space from interface elements to leave more room for notes. Style Settings drives its options: two mutually exclusive modes, a smooth mode that creates space between elements and a minimal mode that compacts the interface and hides most of it, plus a color scheme selector with a custom option, a pop-out callout animation that can be switched off, and floating side panels.
