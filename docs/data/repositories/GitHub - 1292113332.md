# SATOSprod/pins-save

Pins Save records which Markdown tabs are pinned and reopens and re-pins them the next time Obsidian starts, which the README presents as filling a gap, since Obsidian does not remember pinned tabs between restarts. The list is saved in the background as tabs are pinned and unpinned, updated when a pinned file is renamed or moved, and pruned when a pinned file is deleted. Three command-palette actions scan, restore or clear the saved list on demand, and a status panel shows every tracked path. The README records Obsidian 1.7.2 as the minimum version and states that the plugin works on desktop and mobile.
