# Jesuspinarte/obsidian-personal-kanban

This plugin adds simple kanban boards inside Obsidian, presented by its author as a local alternative to hosted tools for personal projects. The README describes opening the board view from the command palette, creating boards from an input at the top of the sidebar, switching between them by clicking a title, reordering them by dragging and deleting them from a hover action. Inside a board, columns come from a ghost box, tasks from a per-column input, cards and columns are rearranged by dragging, and a card modal can send a card to another board and column.
