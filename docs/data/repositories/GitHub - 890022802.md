# SteveOverSea/obsidian-folder-links

Makes internal links to folders work: a regular internal link with a trailing slash reveals an existing folder in the navigation, or creates the folder when it does not exist. Folder links carry resolved and unresolved styling, appear in outgoing links and the graph view, and accept display text. The README is inconsistent on renaming: its feature list claims folder links are updated automatically after a folder is renamed or moved, while a warning below states that renaming or moving an already linked folder will not update those links for now.
