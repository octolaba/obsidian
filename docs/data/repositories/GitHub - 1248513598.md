# rajatnai49/obsidian-canvas-bundler

This repository holds Canvas Bundle, an Obsidian plugin that exports a canvas and the files it depends on as a portable zip archive. It includes the Markdown notes used by canvas file nodes, follows note links and embedded files so related notes come along, and collects non-Markdown attachments used by nodes, embeds and group background images, rewriting canvas paths and note links so the bundle stays internally consistent. Duplicate filenames are given unique names inside the archive, which holds the canvas file beside notes and attachments folders. The README records the limits: the archive is always written to the vault root, unresolved files are skipped, and the plugin is desktop-only.
