# entire-vc/evc-team-relay-obsidian-plugin

EVC Team Relay adds shared editing and web publishing to Obsidian through a relay server that the user either self-hosts with Docker Compose or uses in hosted form. The README states that synchronisation is CRDT-based so simultaneous edits to one note merge without conflicts and offline edits sync on reconnect, and that folders can be shared with viewer or editor permissions by inviting people from the folder's context menu. Publishing turns notes into a website in public, protected (link plus token) or private (login required) mode, with custom domains supported.
