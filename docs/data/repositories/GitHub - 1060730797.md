# xscriptor/obsidian

Xscriptor is an Obsidian theme for coders and writers built around EB Garamond typography and 12 color schemes switchable through the Style Settings plugin, each with light and dark palettes. It adds subtle transparency and frosted-glass effects, per-language code block tints, folder color borders and Graph View colors that follow the active scheme. The README states that Style Settings is required to reach the scheme selector and the remaining customization options.
