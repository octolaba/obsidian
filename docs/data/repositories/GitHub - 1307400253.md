# bewater8066/obsidian-theme-perch

Perch is a dual-mode Obsidian theme for long-duration writing sessions, with Dawn Perch in warm cream paper tones for light mode and Dusk Perch on a muted teal-charcoal background rather than pure black for dark mode. The README states that the two share a unified design language rather than being a brightness inversion, that color values are calibrated against WCAG contrast standards with body text at roughly 9:1, and that primary interactive hues avoid the 460nm blue light peak to reduce eye strain. No typefaces are bundled: the theme only defines font stacks, naming HarmonyOS Sans SC as the primary body font with system fallbacks otherwise.
