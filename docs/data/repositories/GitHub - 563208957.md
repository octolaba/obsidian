# widcardw/obsidian-asciimath

Obsidian plugin that adds AsciiMath support, based on asciimath-parser. It integrates with the dollar-sign math blocks Obsidian already has, adds a math code block of its own, and provides commands to search and insert an AsciiMath symbol, insert a math code block, convert AsciiMath to LaTeX, and migrate notes created with older versions. The README presents AsciiMath as simpler in syntax than LaTeX and notes that some of its rules, the matrix especially, are not exactly consistent with the reference asciimath site.
