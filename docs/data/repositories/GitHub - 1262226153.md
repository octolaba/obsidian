# viggomeesters/obsidian-csv-tsv-viewer

The repository holds CSV TSV Viewer, a read-only Obsidian plugin that opens delimited files in a dedicated view. It shows a table with sticky headers and row numbers by default, offers a source view with line numbers and delimiter highlighting, filters rows by searching across cells, and reports row and column counts, the detected delimiter and the render cap; comma and semicolon are detected for CSV files and tab is used for TSV. Parsing is done with Papa Parse and covers quoted fields, escaped quotes and multiline fields, reporting warnings for uneven row lengths and byte order marks, and the README states that the plugin never writes back to the data file and renders the first 10,000 rows of a large one.
