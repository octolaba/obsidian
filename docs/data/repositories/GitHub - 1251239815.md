# sikoso774/Nebulux

sikoso774/Nebulux holds Nebulux, an Obsidian theme inspired by galaxies and nebulae, with a darkened interface, futuristic fonts, neon glow effects and gradient headings from H1 to H6. It adds a custom callout system with icon modifiers and clean and native display modes, transparency and background blur on active tabs and floating menus, and a rainbow folder effect that colorizes the file explorer. The README documents two ways to build dashboards, a flexbox menu that needs no frontmatter and a full-page dashboard grid, and full support for the Style Settings plugin.
