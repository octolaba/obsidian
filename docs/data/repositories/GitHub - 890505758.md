# pfrankov/obsidian-ai-providers

AI Providers is a configuration hub: it stores API keys and settings for AI services in one place and shares them with other Obsidian plugins, so the same settings are not entered again and again. The README is explicit that the plugin performs no AI processing itself and exists so other plugins can reach AI services more easily, naming Local GPT as a plugin that requires it. It lists the supported providers — among them OpenAI, OpenRouter, Anthropic, Google Gemini, Mistral AI, DeepSeek, Groq, LM Studio, Ollama and any OpenAI-compatible API — an encapsulated API for plugin developers, and 11 interface languages.
