# MaverickHQ/obsidian-vault-reader

Vault Reader turns a Markdown note into a speed-reading panel beside the source note rather than replacing it. The README documents playback controls for play, pause, stop and restart with per-note progress that can be resumed, adjustable words per minute from buttons, a number input or arrow keys, a space shortcut while the panel is focused, and controls for text size, panel zoom, accent colour and optimal recognition point focus. The current word can optionally be highlighted in the source note in yellow, orange or blue, and opening a different note keeps the existing session and offers an action to read the new one instead of silently losing the place. It states that the first release is desktop-only, and that the plugin makes no network requests, requires no account or hosted backend, collects no telemetry, and stores settings and progress locally.
