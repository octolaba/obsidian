# isgin01/ultimate-pomodoro-timer

This plugin is a Pomodoro timer for Obsidian offering the standard cycle together with configurable timer modes, their sequence, durations, notification sound and colors. The README states that it can be used as a status bar item, as a panel widget, or from the command palette, and that its settings should be adjusted after installation. A checklist of planned work names separate notification sounds per mode, a tasks view, logging and further shape options as not yet implemented.
