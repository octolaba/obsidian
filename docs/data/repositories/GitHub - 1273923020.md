# Real-Fruit-Snacks/obsidian-github-updater

Installs and tracks Obsidian plugins that exist only as GitHub releases, taking a repository as owner and name or as a full URL in a modal and installing from its latest release. A vault scanner compares installed plugins against the official community list, flags the unofficial ones and guesses their repository so tracking begins with one click. Versions are compared semantically, a raw-repository fallback fetches the files from the tagged source tree when a release has no attached assets, release notes render as Markdown in a modal before updating, a single version can be ignored, and one button installs every available update in sequence. The README records background checks shortly after startup with a manual check button and a last-checked timestamp, and states that no desktop-only APIs are used so it also runs on mobile.
