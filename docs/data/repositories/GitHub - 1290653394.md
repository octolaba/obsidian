# alexxozo/apple-notes-obsidian

Apple Notes is an Obsidian theme that mimics the look and feel of the Apple Notes app on macOS and iOS. It uses warm off-white paper in light mode and charcoal #1C1C1E in dark mode, the SF Pro font stack, and a yellow accent for links, folder icons, the active note and tags, with round checkboxes that fill gold when done and a yellow highlighter for marks and text selection. The editor is full width with no line-number gutter, tags are pill-shaped, and modals are rounded over a translucent backdrop. The README recommends turning Obsidian's line numbers off for the closest match and notes that the theme respects the readable line length setting either way.
