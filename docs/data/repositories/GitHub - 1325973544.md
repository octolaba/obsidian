# bytemindlab/blogizi-obsidian

Publishes the active note to a Blogizi blog over that service's account API. Commands create a new post note in a configured folder with the expected frontmatter, insert that frontmatter template into an existing note, and push the note either as a draft or as a published post, with ribbon icons for creating and uploading. Re-pushing a note whose slug already exists updates that post rather than creating a second one, which is enabled by default. An account API key is entered in the settings, after which the account's projects can be loaded and one picked as the publishing target.
