# romejoe/VaultCrypt

The repository carries no description; its README presents VaultCrypt as inline encryption for notes backed by KeePass-compatible kdbx storage. Secrets are referenced in Markdown by tokens naming a profile, an entry path and a field, and they render as masked chips rather than plaintext, with a click copying the value to a clipboard that is cleared after a configurable timeout. The README lists KeePass v3 and v4 databases kept inside the vault, per-session profile locking with auto-lock timers, an optional master keyring for profile passwords, Argon2id key derivation for KDBX v4, and support on both desktop and mobile.
