# tgrosinger/recent-files-obsidian

Recent Files displays a list of the most recently opened files in the sidebar, with optional exclusion of certain paths, frontmatter tags or bookmarked files. The list behaves like the file explorer view: items are clicked to open, control-clicked to open in a new pane and right-clicked for a menu, dragged into an editor to drop a link, onto a header to open in a specific pane or onto a folder to move the file, and hovered for a content preview as configured by the corresponding Page Preview setting. The README also notes that with the Front Matter Title plugin's explorer module enabled, files in this sidebar are named from the frontmatter title.
