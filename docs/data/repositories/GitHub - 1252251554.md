# Nicholas-Yu/InkPilot

InkPilot is an Obsidian plugin for novelists that applies AI assistance across a project's whole arc: planning, character design, worldbuilding and outline generation, then chapter writing, and finally a consistency review. Its stated philosophy is a division of labour in which the AI expands, polishes and fills scenes while the writer selects, controls pacing, injects emotion and removes AI-flavoured text — the README summarises it as AI being the amplifier rather than the voice. That framing is argued from three problems the README attributes to purely AI-written novels: uniform, recognisable prose, contradictions and out-of-character drift over long books, and uncertain copyright protection in many jurisdictions.
