# natobtw/obsidian-nordic

Nordic for Obsidian is a theme built on the Nord palette with, as the README puts it, a pinch of personal preference. It comes in Default and Uniform flavors, each with light and dark variants. Fantasy Statblocks is the only plugin the README lists as explicitly supported, and the credits name the Manrope and Norwester fonts, the Nord theme, and the Obsidian Nord and Discord Nordic projects as initial inspiration.
