# r3Fuze/obsidian-update-title-on-rename

Update Title on Rename keeps the frontmatter title property in step with the filename when a file is renamed, but only when the existing title matched the previous filename, so a deliberately custom title is left untouched. Settings change which frontmatter key is used, add the title to frontmatter on rename when none exists, and switch to always updating the title, which the README states overwrites custom titles. Installation is described from the community plugin browser, through the BRAT beta installer, or by copying the release files into the vault.
