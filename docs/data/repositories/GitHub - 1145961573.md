# entire-vc/evc-local-sync-plugin

EVC Local Sync mirrors folders of an Obsidian vault against directories on the same machine, such as a code project's docs folder, in both directions. The README states that mappings pair a vault path with a local path, that syncing can be run on demand or automatically with a chosen conflict strategy, and that the intended use is keeping notes and repository documentation aligned while AI coding tools edit the repository side. It describes the plugin as local-first, removing the manual copy-paste step between the two locations.
