# WiNE-iNEFF/colorizelt

Colorizelt colors the selected text in an Obsidian note, or clears the coloring again. Colors are applied from the command palette or by keyboard shortcut — the README lists Shift with Ctrl or Command and the digits 1 to 4 for red, yellow, green and blue — and the same shortcuts remove every color from the selection. On mobile the same actions are reachable through buttons. The README's roadmap records that icons for phone access, a settings tab for editing colors and more colors are done, while other highlight types are not.
