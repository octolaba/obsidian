# wesswart77/obsidian-cadence

This repository holds Cadence, an Obsidian plugin presenting CRM, PRM, project management, daily planning and reminders as one workspace over plain Markdown. Every contact, deal, project and activity is a Markdown file with frontmatter, so the data stays in the vault and remains readable by other plugins, and a left rail switches between Home, Today, Pipeline, Contacts, Projects, Inbox and Reports inside a single tab. The Home dashboard collects today's tasks, weekly progress, upcoming deadlines, partners due for follow-up, active projects with milestone progress, the pipeline and recent activity. Individual modules can be switched off, and an inbox with a capture modal and a ticker produces actual reminder notifications.
