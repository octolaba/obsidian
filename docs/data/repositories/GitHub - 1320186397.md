# obsidian-power-plugins/obsidian-power-explorer

Power Explorer adds manual drag-and-drop ordering to the file explorer, where an item dropped between two others takes that position and one dropped onto a folder moves into it, with cut and paste for longer moves and a per-folder order reset. Instead of manipulating the explorer DOM, it hooks the sort itself and changes only the order returned for each visible folder, which is how it stays fast in vaults of twenty thousand notes. A Desktop layout setting splits the Files pane into folders on the left and pages on the right at one of four depths, with arrow-key navigation, multi-select and bulk open, pin and delete. A folder holding a note of the same name is drawn as a single row with the other notes indented under it, and the pane adds recent pages, folder colours and reveal-active-page.
