# hfknight/x-bookmarks-sync

Copies X (Twitter) bookmarks into the vault as structured Markdown notes with YAML frontmatter and a configurable folder, tags and filename format. The README states that no API key and no OAuth are involved: the plugin runs an embedded Electron webview on the existing X browser session, and it is therefore desktop only. A sync reads the bookmark list directly and confirms that it reached the end, re-scanning in full next time when it cannot; an incremental mode stops at already-imported bookmarks, and a checklist with All, None and First N controls selects from a backlog while filtering out what the vault already holds. Notes carry long-form text, images and video or GIF thumbnails, fold quoted tweets under their own heading, and can be re-imported or copied with replies stripped.
