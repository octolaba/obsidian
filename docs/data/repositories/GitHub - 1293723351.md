# vanerp/obsidian-madr

No repository description is recorded, so this body is grounded in the README alone. MADR Author writes Markdown Architectural Decision Records as ordinary notes in an Obsidian vault, with a live checklist flagging missing sections and leftover template placeholders. Configured vault folders hold the records, defaults for the MADR version, status, decision-makers, consulted and informed prefill each new record, and a record is created from a command or from a configured folder's context menu. The README states that the plugin makes no network calls, and that it was developed with the assistance of agentic AI coding tools, advising a source review before use in sensitive vaults.
