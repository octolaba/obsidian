# aygjiay/obsidian-link-to-verse

The repository records no description; its README presents Link to Verse, a plugin that turns a Bible reference written in a note into a link to that passage on an online Bible site. A reference such as a book, chapter and verse is selected and a command replaces it with the generated link. Settings hold a default Bible version and a link template carrying placeholders for the verse and the version, with a dropdown of built-in presets as an alternative to maintaining a template by hand.
