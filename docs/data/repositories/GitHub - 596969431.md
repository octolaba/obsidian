# Maxymillion/zen

Zen is a focus-mode plugin whose README describes it as inspired by iA Writer and as a way to disable interface elements on a whim. Which items are hidden is chosen from the settings tab, where holding the eye button beside a toggle previews the element it would hide. The plugin also exposes an integration interface so other plugins can run functions when zen mode is entered and left; the README records one such integration written for a typewriter-scroll plugin, which is enabled and disabled along with zen mode.
