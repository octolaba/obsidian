# wolfm/obsidian-multi-state-checkboxes

This repository holds Multi-State Checkboxes, an Obsidian plugin that switches checkboxes between customizable statuses. The list of statuses is defined by the user, for example not started, in progress, complete and cancelled, along with the order in which the editor cycles through them. A left click advances to the next status, a right click picks one from the context menu, and editor commands for cycling forward, cycling back and setting each defined status can be bound to keyboard shortcuts.
