# AntoineArt/obsidian-tab-duplicate

Tab Duplicate adds a Duplicate file entry to a Markdown file's tab header menu and to its file-explorer context menu. The copy is created beside the original with a -copy suffix, collisions are avoided by numbering that suffix, and the new file is opened immediately. The README also documents the project's own release flow, in which a pushed version tag makes GitHub Actions build, attest and publish the release assets.
