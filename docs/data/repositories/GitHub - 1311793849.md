# yueyinfeng/bases-navigator

Bases Navigator moves between the files listed by an Obsidian Bases view using arrow keys, following the result order of the last active Bases view after a file is opened from it. Its settings cover the Left/Right or Up/Down key pair, which view modes are active — Reading mode by default, with Live Preview and Source mode opt-in because they can conflict with cursor movement — wrap-around at the ends of the list, whether files replace the current tab or open another, a navigation notice, a DOM-scan debounce and a debug mode. The README states the plugin does not access the network, collect analytics or write to notes, and that it reads the visible Bases view DOM to learn the file order; that claim is the README's own and was not verified.
