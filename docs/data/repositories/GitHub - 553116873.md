# PipeItToDevNull/PLN

PLN, short for Pipe Loves Nord, is a personal Nord theme for Obsidian that its author started for version 0.16. It relies heavily on the Style Settings plugin to enable selected features and to opt in or out of the interface changes it makes, while its snippets directory holds parts of the theme that can be used on their own. The palette is Nord's, with a separate darker yellow added so that yellow stays readable in light mode. Changes named in the README include smaller fonts, flipped and more compact stacked titles, removal of sidebar, editor, status bar, close and tab file icons, scrollbars hidden until hovered, a coloured file explorer and altered link styling.
