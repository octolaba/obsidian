# paddomanno/obsidian-list-table-converter

Obsidian plugin that adds a command converting selected lines into a Markdown table, one row per line. The selection can be plain text, a bullet list, a numbered list or checkboxes, and it need not be exact, since blank lines may be included. Its settings decide whether an empty header row is generated and how many further columns are appended after the converted content.
