# st-vin/better-task

Better Task organises work in Obsidian around goals, their tasks, and a dashboard that shows today's tasks, quick tasks and goals in one place. A goal can carry daily or one-off tasks, in-app and optional system notifications remind about due and overdue tasks, and an analytics section reports weekly completions, streaks, a 30-day activity heatmap and further insights the README calls consistency, momentum and predictions. An optional Student Mode adds units or courses and exams to the dashboard and generates study tasks automatically before the exam dates.
