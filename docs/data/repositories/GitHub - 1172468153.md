# hesprs/sync-engine

Sync Engine is a modular Obsidian plugin for synchronizing vaults through backends such as WebDAV, S3, and Google Drive. Its core separates sync infrastructure from modules for providers, localization, optimization, and strategy, with documentation covering migration and module development.
