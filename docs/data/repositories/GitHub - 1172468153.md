# hesprs/obsidian-webdav-sync

Synchronises an Obsidian vault with a WebDAV server in both directions; its recorded description presents it as a general-purpose, maintained alternative to Remotely Save. The README positions the plugin against the existing syncing landscape and names what it takes to be each alternative's drawback: Remotely Save unmaintained and buggy, Syncthing Integration requiring both devices to be online, Live Sync requiring a custom server, and Git integration suiting other cases. Its documentation is published in English and Simplified Chinese.
