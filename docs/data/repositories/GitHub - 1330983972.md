# ratatulieoi/obsidian-isomite

Isomite synchronizes an Obsidian vault through a private Cloudflare R2 bucket, talking to the S3 API directly from desktop and mobile with Obsidian's request API, so no VPS, Worker or sync server is involved. Content, path names and hashes are encrypted with separate AES-256-GCM keys derived by PBKDF2-HMAC-SHA256 over 600,000 iterations, and the bucket holds immutable encrypted revisions, deduplicated blobs, deletion history and a journal for resuming an interrupted local write. Each run builds a complete upload, download, delete and merge plan that is presented for review before anything is written on either side, with progress shown from the ribbon. Devices are named, credentials stay in local plugin data, and a further device is joined by one generated pairing code that carries everything needed to connect.
