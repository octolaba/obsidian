# ZephyrHaven/Cockpit-Dashboard

Obsidian plugin providing a local-first dashboard home page that gathers tasks, a calendar, search, statistics, bookmarks and focus tracking into one panel. Its bilingual README lists a greeting area with due-soon reminders, silent partial refresh that tries not to interrupt editing, a floating global search over filenames, paths and note bodies, and an edit mode in which every module can be reordered, hidden or collapsed with the state persisted. It also describes a right-click menu on empty areas of the page, a compact calendar with task markers and RSS sources, an RSS reader, task management with filters and priorities, statistics cards and a focus timer.
