# gvivster/obsidian-copy-indented-code-blocks

The repository holds Copy Indented Code Blocks, an Obsidian plugin that removes a code block's leading indentation when the block is copied. It detects the block's indentation level and strips exactly that amount of leading whitespace from every copied line while preserving the relative indentation inside the code, working with both spaces and tabs. The README explains the motivation: Obsidian's built-in copy keeps the indentation of a code block nested in a list, which has to be deleted by hand after pasting into a terminal.
