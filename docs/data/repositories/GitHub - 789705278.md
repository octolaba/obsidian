# h-sphere/sql-seal

SQLSeal queries the files, tags and tasks of a vault with SQL written in its own code blocks, and can also load a CSV file from the vault as a table to select from. Several tables can be defined in one block and blocks within the same note can refer to each other's tables, though tables stay local to their file. The README carries a disclaimer that the plugin may modify files in the vault: variable values are saved as comments at the end of its own query files, and interacting with the tasks table updates the source Markdown.
