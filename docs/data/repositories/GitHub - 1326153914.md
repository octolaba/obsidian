# stardustdreams/loreweaver

Organizes long-form fiction material in plain Markdown frontmatter: notes typed as characters carry a list of relations, and notes typed as foreshadowing carry a resolved flag. A graph view renders characters as nodes and their relations as edges, draggable and double-clickable to open the note, while a second view lists every foreshadowing entry still marked unresolved. Command-palette commands insert ready-made frontmatter templates for locations, organizations, terms, characters and foreshadowing into new, empty notes. The vault remains the only store, indexed in memory at load, and no network request is made except through an optional, off-by-default assist that talks solely to a local Ollama instance and proposes drafts without writing them back.
