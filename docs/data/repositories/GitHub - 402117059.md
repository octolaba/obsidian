# michaellee/stille

Stille is an Obsidian plugin that helps a writer focus on one section of a note at a time. Once activated it adds a moon-shaped icon to the left ribbon that toggles it on and off, shows whether it is on in the status bar, and provides a hotkey for the same toggle.
