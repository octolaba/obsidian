# jvsteiner/s3-image-uploader

S3 Image Uploader uploads images from Obsidian to an S3 bucket the user owns, rather than to a third-party image host. It is configured with an access key id and secret for a user with write access, a region, an existing bucket name and an optional folder that is created on demand, and the README includes the bucket policy needed to make the objects publicly readable together with a CORS configuration. It states that the plugin is supported by advertisements, that it is still in development and may contain bugs, and names the editor and the earlier community plugins that inspired it.
