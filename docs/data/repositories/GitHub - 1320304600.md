# DevMandalia/Nebula

Nebula is an Obsidian theme with a dark mode of cyan and violet on a blue-black canvas and a light mode of warm turmeric accents on cool paper. Interface and editor text are set in Sora and code in JetBrains Mono, both pulled from Google Fonts through a CSS import, so first load needs a network connection unless the font files are downloaded and the import is replaced with local font-face rules. Palette, fonts and the reading width are exposed as CSS variables at the top of the theme's light and dark blocks, and the theme is also distributed with the Solaris board tool.
