# jorritvanderheide/obsidian-tag-explorer

Tag Explorer, a fork of vorotamoroz's TagFolder, presents a vault as folder trees generated from tags, one tree per tag namespace, so a note carrying tags from two namespaces appears under both at once. The README lists its changes from upstream: prefix matching in the ignore list, namespace-aware deduplication that no longer drops a note from whichever namespace is processed second, namespace-scoped sub-folders, configurable cross-namespace filter folders when isolation is off, per-folder icons, an optional item count, and collapsing of empty intermediate folders. It also records what was removed: the link tree and list views, freshness virtual tags, and the per-tag metadata system, replaced by a pinned-folder list and folder icons.
