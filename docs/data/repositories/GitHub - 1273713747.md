# 4Cjyxbq25Cb/obsidian-open-notes-highlight

Obsidian plugin that highlights the notes currently open in Obsidian inside the graph view. Open notes are drawn in a chosen colour and at a fixed size independent of link count while other nodes are faded out, and optional settings tint directly linked notes in the same colour at reduced opacity and tint the edges that reach an open or pinned note. A scope setting can instead read a layout saved by the core Workspaces plugin and highlight the notes it holds, without loading that workspace or disturbing the current one. Colour, size and opacity are adjustable from a small control panel inside the graph view as well as from the settings tab.
