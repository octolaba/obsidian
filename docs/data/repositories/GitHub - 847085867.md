# josmarcristello/Obsidian-Find-Orphaned-Images

Finds images in the vault that no note links to and helps remove them. A scan can produce a report note listing the orphaned images grouped by folder with per-file and total sizes, either displaying the images or linking to them, or open a review panel showing each image as a thumbnail with its path and size so that a selection can be deleted with a running total of the space reclaimed; a command deletes all orphans at once. The README states that references are detected in note links and embeds, frontmatter links, Canvas files including file nodes, group backgrounds and embeds in text cards, raw HTML image tags, and embeds inside legacy Admonition code blocks.
