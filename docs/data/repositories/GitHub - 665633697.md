# ddalexb/obsidian-simple-canvasearch

Obsidian Simple Canvasearch adds a search modal for navigating within a canvas page, reached through a shortcut the user assigns. It fuzzy-searches note titles and can optionally include note contents in the search. The README states that including contents can slow things down on a very large canvas, because the search is not optimised.
