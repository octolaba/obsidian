# ksemkav/obsidian-segerlab-plugin

The Segerlab plugin renders calculator views inside Obsidian notes from JSON copied out of the Segerlab app, which its README describes as a notebook for ceramists and potters who make their own glazes. Markdown code blocks marked as Segerlab calculations become interactive calculator views, with an optional setting for additional coefficients and an interface in English or Russian that follows the Obsidian language setting. The README also lists a panel showing a Stull chart of every calculator point found in the open note and a configurable search query for finding notes that contain calculators, and notes that the app shows its Obsidian button only once the matching profile setting is enabled.
