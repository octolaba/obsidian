# orenaksakal/valnotecom-obsidian-plugin

The description records this as an Obsidian plugin for valnote.com; the README presents it as Valnote Calculator, a natural language calculator rendered from a valnote or calc code block with results shown inline next to each line. Documented capabilities are basic and advanced math including functions such as square root and logarithms, currency conversion across more than 100 currencies, unit conversions for length, weight, volume and temperature, date and time arithmetic with timezone support, percentages, variables, aggregations such as sum and average, number formatting and comments.
