# sliiu/obsidian-md-beautify-plugin

MD Beautify is the Obsidian integration of the separate md-beautify project, turning a note's Markdown into styled rich text for platforms such as WeChat Official Accounts and other rich-text editors. The README records built-in themes including academic, minimalist and cyberpunk, live preview with synchronized scrolling and light or dark mode, Mermaid diagram support, and export to HTML or to PDF in either a non-selectable image mode or a selectable-text vector mode. It also documents batch upload of local images to Qiniu, Aliyun, Tencent Cloud, S3 and similar storage, a custom CSS editor, and handling of WeChat's CSS restrictions such as converting pseudo-elements.
