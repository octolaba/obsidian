# CyrylSz/obsidian-settings-sidebar-organizer

This plugin reorganises the Obsidian settings sidebar: community plugins can be grouped into custom folders, renamed with aliases, reordered manually or automatically, annotated with notes, and hidden. The README describes keyword matching that sorts plugins into groups, including exact phrases and explicit exclusions, a live badge showing what matched, quick-add of installed plugins, membership in several groups at once, an automatic Ungrouped folder, and a group lock that stops newly installed plugins from joining. It carries a caution that the plugin manipulates the Obsidian interface directly because no official API exists for the settings sidebar, works through proxy buttons that click the real hidden ones, and may break when Obsidian changes its markup.
