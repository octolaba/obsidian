# Djiit/obsidian-tasks-kanban

Tasks Kanban shows the tasks found by the Obsidian Tasks plugin as a board with one column per task status. Several named boards can be saved, each with its own query and columns and opened in its own tab, with a shared base query merged into every board so common filters are written once. Default status columns can be replaced by custom ones that map to chosen status symbols, cards can be grouped into foldable swimlanes by status, priority, tags, path, folder or filename, and sorted by priority or a date field. Dragging a card between columns changes the task's status, a search bar and full Tasks-style query editing narrow the board, clicking a card opens its source file, and the plugin updates by listening to the Tasks plugin's events.
