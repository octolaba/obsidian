# Quietbyday/obsidian-merge-as-alias

Merge as Alias merges one note into another, adds the source note's name as an alias on the target, and rewrites every internal link in the vault to point at the target while still displaying the old name. Both body content and YAML frontmatter are merged, with settings for combining list fields without duplicates, concatenating text fields that share a key, the separator placed between them, and whether a divider precedes the appended content. The merge is started from the note's three-dots menu or the command palette and opens the target note when it finishes; the README documents installation as a beta plugin through BRAT.
