# Yunz93/obsidian-plugins-activity

This plugin records how a vault's third-party plugins are actually used and presents the result as one overview. Its README describes local tracking of command runs, plugin view openings and interactions, a searchable and sortable list of installed community plugins with last-used time and seven-day totals, a summary of Obsidian's own community plugin update check with a jump to the update page, daily history cleaned up automatically on a chosen retention, and each plugin's name, version, author and enabled state. It states that some passive plugins cannot be measured reliably and that the overview says so when it happens, and that statistics stay on the device inside the vault with nothing uploaded, which is a claim recorded from the README rather than verified here.
