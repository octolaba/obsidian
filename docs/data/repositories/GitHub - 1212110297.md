# hzlume/obsidian-note-heatmap

This repository holds Note Heatmap, an Obsidian plugin that displays note editing frequency as a GitHub-style annual activity grid with five levels of colour depth, where clicking a day lists the notes modified on it and clicking a month opens a summary. Activity is read from frontmatter date fields in ISO 8601, YYYY-MM-DD, list format or Obsidian date objects, and the README contrasts it with Contribution Graph by noting that a list of dates makes one note contribute to every day it records rather than only the latest. Dates also jump to daily, monthly and yearly periodic notes with hover preview and customizable folder paths and filename formats, and the README records an incremental cache and an optional git diff view.
