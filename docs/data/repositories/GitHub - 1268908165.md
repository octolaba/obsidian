# jsdosanj/ledger

The repository description records a DosanjhLabs IT documentation hub carrying an Obsidian vault toward corporate use, while the README describes Ledger Governance, an Obsidian community plugin that adds governance metadata to a personal vault without an account. It scaffolds governed documents whose frontmatter carries owner, status and reviewed_on, moves a document through draft, in-review, approved and published, stamps reviews against a cadence that defaults to 90 days, and reports the status mix, review freshness and ungoverned documents in a dashboard and the status bar. Every governance action is appended to an in-vault audit log at _ledger/audit.md. The README states that the plugin is entirely local with no login, tokens, network calls or servers, which is recorded here as the project's own claim.
