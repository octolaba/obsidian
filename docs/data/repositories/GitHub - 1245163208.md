# livan116/github-valut-sync

Syncs a vault across devices through a private GitHub repository created for it, using a pure JavaScript git implementation so no native binary is needed and both desktop and mobile are supported. After a one-time in-browser GitHub authorization the plugin creates a private repository named after the vault, commits and pushes each save in the background after a short debounce, and pulls the latest changes when Obsidian opens. When two devices edit the same file the conflict is surfaced in a side-by-side resolution interface. The README states that files go only into the user's own private repository with no server involved, that offline edits are queued until connectivity returns, and that building from source requires registering a GitHub OAuth application.
