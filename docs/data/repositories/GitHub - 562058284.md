# ttax00/obsidian-s3

S3 attachments storage keeps media attachments on S3-compatible services and links to them from notes, covering the file kinds Obsidian allows to be linked: images in ico, png, jpg and gif, mp4 video, and mp3 and wav audio. Uploading happens on paste and on drag-and-drop, and the plugin generates the links for images, video and audio, returning a download link for a resource type it does not embed. Its feature list also records commands that delete unused resources and show the bucket size, marks renaming links after a port or folder change as not yet done, and lists parallel uploads, retry handling, local caching and uploading existing attachments as unplanned.
