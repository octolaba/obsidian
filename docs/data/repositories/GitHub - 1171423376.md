# KHR0907/obsidian-3d-semantic-graph

Desktop-only Obsidian plugin that renders a vault as an interactive 3D graph, placing notes from OpenAI or local Ollama embeddings projected into three dimensions with UMAP or PCA so that semantically similar notes cluster together. Clusters are grouped by k-means and labelled from note titles and tags, grouping can be switched back to folders, and without embeddings the layout falls back to a folder-based clustered sphere. Semantic search flies the camera to the best match, an insights panel proposes close but unlinked note pairs, potential duplicates, orphans and per-cluster maps of content, and a sidebar ranks the active note's nearest neighbours. The graph exports as a standalone HTML file with deep links back into the vault.
