# KHR0907/obsidian-3d-semantic-graph

Obsidian 3D Semantic Graph visualizes vault notes in an interactive three-dimensional graph using embeddings or uploaded vectors projected with UMAP or PCA. It provides semantic search, similarity-based clusters, link insights, timeline playback, export, caching, and a folder-based fallback when embeddings are unavailable.
