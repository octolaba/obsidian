# alexeiskachykhin/obsidian-image-metadata-plugin

Adds image metadata editing to Obsidian, so a description can be written into an image from the image viewer screen. The README's table maps JPEG files to the Exif ImageDescription tag and PNG and WEBP files to the XMP description tag. The rest of the README covers the development setup and the release procedure.
