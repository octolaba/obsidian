# kylesnav/obsidian-delightful

Delightful is an Obsidian theme built on the Delightful Design System and described by its README as neo-brutalist: bold 2px borders, solid zero-blur offset shadows, generous radii and warm neutrals rather than cold gray. Light and dark modes are both defined through a three-tier OKLCH token architecture of primitive, semantic and component tokens. The README lists styling for eight colour-coded callout types, a distinct H1 to H6 heading scale, syntax highlighting, tables, task checkboxes, canvas node types, graph view controls and scrollbars, plus a motion system of five durations and five easings. Mobile is treated separately, with larger touch targets, reduced shadows and a phone-appropriate heading scale.
