# ZeroDark-0/vIbGyOr

vIbGyOr customises Obsidian notes with per-note colours and background patterns, applied either through a visual interface or through frontmatter properties. The README describes setting background, text, link and accent colours for an individual note, background textures such as grid, blueprint, cosmos, starfield and zen waves, ten built-in presets, saved custom palettes, and instant application of frontmatter changes. Two ribbon entries drive it: one opens a modal that names a new note and picks its initial theme and pattern, the other edits the theme of the note currently open. It also tints transparent-background images to the note's pen colour, with a toggle back to the originals.
