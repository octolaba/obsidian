# odayou/task-processing-extension

This repository holds a task processing extension for Obsidian whose README is written in Chinese, with an English version linked separately. It records that the plugin totals the time spent on each task in the current document from the time ranges written on the task lines, and that running a total time command from the palette or the context menu lists each task's time and the overall total at the cursor. The README also records shortcut commands for inserting a pending or completed item and the current time, all of them reachable from the right-click menu, and its sample output shows nested tasks with hours and minutes beside a decimal hour figure.
