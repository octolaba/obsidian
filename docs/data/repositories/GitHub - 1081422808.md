# chetsCMD/Hover-Tooltips-Obsidian

Hover Tooltips adds interactive popup hints to Obsidian notes, written inline with the syntax `{/{word/description}/}`. A tooltip appears on hover and can be pinned open with a left click, and its text supports Markdown — bold, italic, inline code, highlights, external links and internal wiki links, with line breaks converted to separators. Tooltip entries can also be defined once in a global dictionary and reused across notes, either within a single note or across a folder. Settings assign a hotkey for the tooltip menu and configure those dictionaries, and the README is written in both English and Russian.
