# farlenkov/obsidian-canvas-llm

This repository holds Canvas LLM, an Obsidian plugin offering a canvas-like interface for talking to large language models instead of a linear chat window. Prompts are typed into input cards and answers are produced by generate cards, so one graph can carry several branching conversations at once. The README lists text, file and web input nodes, with file attachments covering Markdown, canvas, docx and fountain files and an embedded browser for web content, plus a generate node whose model is chosen per node. It states that the user supplies their own provider API keys.
