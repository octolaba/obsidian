# kmkkiii/obsidian-kanagawa-theme

kmkkiii/obsidian-kanagawa-theme is an Obsidian theme inspired by the colours of Katsushika Hokusai's The Great Wave off Kanagawa, with a palette based on kanagawa.nvim. It ships three variants: Wave, a dark default with deep ocean tones; Dragon, a muted warm dark alternative that requires the Style Settings plugin; and Lotus, a warm paper-like light mode.
