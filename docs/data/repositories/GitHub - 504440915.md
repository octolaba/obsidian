# edonyzpc/personal-assistant

Personal Assistant automates management tasks inside Obsidian and adds AI features described in its README as note understanding, chat with memory, visual relationships and a review workflow. A beta feature called Pagelet reviews notes quietly and saves structured suggestions as review notes; before memory is prepared, the assistant explains the data flow, the AI provider usage and the possible cost, then asks for approval. The repository ships English and Chinese manuals, a version 2.7 user guide covering AI insights, memory, research and safe save flows, and a documentation index for requirements, decisions and architecture.
