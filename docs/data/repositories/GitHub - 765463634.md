# zedseven/obsidian-tag-links

Obsidian Tag Links opens a tag as a link from a hotkey. The README explains the mechanism: the user defines regular expressions that match certain tags and link substitutions that build a URL from the captured values, and pressing the configured shortcut while the cursor sits on a matching tag opens that URL. It is written around Obsidian's nested tags, with the author's own use being identifiers belonging to one system such as ticketing system entries or pull requests, and it suggests an online tester with the ECMAScript flavour for building the expressions.
