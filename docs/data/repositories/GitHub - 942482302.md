# mntno/obsidian-come-down

Come Down downloads the external images embedded in Obsidian notes and keeps them in a cache, so a note reopened later loads the cached copy rather than the original URL. The README states that cached images therefore load offline and in a synced copy of the vault on another device, and that notes themselves are not modified, so disabling or uninstalling the plugin leaves everything as before. Caches sync with file-based solutions such as Syncthing or iCloud Drive, but the README says the cache is deliberately excluded from a vault versioned in Git, because Git is meant for plain-text versioning rather than binary data.
