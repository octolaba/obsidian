# azulika/obsidian-aa-viewer

AA Code Block renders fenced code blocks tagged aa in MS PGothic at 12pt, the font and size Japanese ASCII art was drawn for. Kerning and ligatures are turned off and long lines scroll horizontally instead of wrapping, so the shape of the art is preserved, and the default line height matches the original line spacing. The same font is applied inside the block in Live Preview as well as in reading view, and a command inserts a new block or wraps the current selection in one. The language tags, font family, size, line height and wrapping are configurable, which matters outside Windows, where an AA font has to be installed and named in settings.
