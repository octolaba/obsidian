# jonashaefele/audiopen-obsidian

Obsidian plugin and companion service that brings transcriptions from AudioPen or VoiceNotes into notes. Setup signs up for the hosted service, generates a login token entered in the plugin settings, and adds the resulting webhook URL to AudioPen as an automatic webhook and optionally as a manual trigger so that notes can be updated later. Custom note templates are supported. The README states the plugin is based on trashhalo's obsidian-webhooks, updated and extended to work with AudioPen and VoiceNotes.
