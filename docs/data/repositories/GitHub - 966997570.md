# anotherlusitano/SpectrumPlus

SpectrumPlus is a fork of the Spectrum theme, maintained independently with bug fixes, new features and improvements since the original author stopped maintaining it. The README points at the original Spectrum wiki for the feature list rather than restating it. Contributors clone the repository, install dependencies with yarn and build with esbuild, which compiles the styles into a minified file; the development build writes to a git-ignored testing CSS file. The theme is MIT licensed and names Wiktoria Mielcarek as the original author.
