# remememe/Live-Wallpaper

Live Wallpaper is described as styling notes with wallpapers — videos, GIFs and images — carrying custom effects, and its README lists the accepted file formats. Settings apply either globally or to an individual wallpaper and cover repositioning, opacity, blur, brightness and contrast, a history of previously used wallpapers, and use of images at their original resolution. Scheduled modes switch between a day and a night wallpaper at configurable times, assign one wallpaper per weekday, or rotate through wallpapers at an interval. Transparency is tuned by naming CSS selectors and overriding theme variables so the wallpaper sits behind the interface without harming legibility, with a chosen blur colour, blur and dim sliders, and modal effects; the README notes that the built-in CSS editor was removed and that this version's folder rename may have deleted unused files.
