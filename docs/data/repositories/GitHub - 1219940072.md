# Lhy723/obsidian-karmind

KarMind builds a personal knowledge wiki with an LLM, following the collect, compile, ask, backfill and improve workflow the README attributes to Andrej Karpathy's LLM Wiki pattern. Raw material goes into a configurable raw folder, a compile command turns changed notes into interlinked wiki pages, a question command answers from relevant wiki context, a backfill command writes useful output back, and a health command checks links, orphan pages, gaps and consistency. Compilation state is tracked by content hash, so unchanged raw files are skipped unless a forced recompile is requested, and suggested actions need confirmation before they run. Settings cover the interface language, an OpenAI-compatible endpoint, model and API key in Obsidian SecretStorage, the raw and wiki folders, and a default permission level.
