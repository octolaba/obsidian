# lpp188408/MDToSM

MDToSM is a desktop-only plugin that formats Markdown notes for WeChat Official Accounts and publishes them through the official WeChat API. A compact right-side workspace previews the active note, offers several article layouts and color themes, switches between mobile and desktop previews, and creates drafts or image cards; local images are preserved and a local cover image can be cropped without altering the note. AppSecret values are kept in the macOS Keychain, read through a fixed system tool rather than user-supplied shell commands, and note content is read through the Obsidian Vault API instead of being sent to an external rendering service.
