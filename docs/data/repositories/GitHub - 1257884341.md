# HornatX/pure-footnote

Pure Footnote adds a sidebar outline that lists both standard Markdown footnotes and a custom inline hover-note syntax written as a marked term followed by its content in braces. The entry matching the cursor is highlighted as the cursor moves, and clicking an entry jumps to that position in the document, while a draggable editing popup changes a footnote's number and text without scrolling to the bottom of the note. An optional styling mode adds an indicator icon to footnotes in Live Preview and Reading mode, hides the hover-window title and adjusts the hover typography, and a context menu switches between numeric and alphabetic ordering and toggles that styling. The README is written in Chinese and English.
