# James-Yu/external-file-card

Renders a card for a file that lives outside the vault, addressed by name or partial path and resolved against root paths given in the plugin settings. The card is produced by an ef or extfile code block, shows the file's name, its created and modified times and its containing folder, and both the name and the folder open in the operating system's default application when clicked; a compact variant uses the efc and extfilec languages. Several files listed on separate lines render in one card, a file that cannot be found renders as a not-found card, and the README states that on mobile the plugin does not attempt to locate the file.
