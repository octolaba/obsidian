# Robin-Haupt-1/Obsidian-Map-of-Content

Map of Content generates and displays a map of an Obsidian vault built from the links between notes, so the position of the current note relative to a chosen central note is visible. It shows the shortest path from that central note to the open note along with the note's descendants, and counts every path of equal length, so one note can have several parents and appear in different contexts. The README states that the view lives in the plugin pane beside the editor, that it updates automatically when notes are switched because it is derived from the links themselves, and that a manual update can also be triggered.
