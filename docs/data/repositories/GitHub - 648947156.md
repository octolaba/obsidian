# dot-asterisk-nl/obsidian-lilypond

Lilypond for Obsidian is described as rendering LilyPond notation inside Obsidian. Its README says LilyPond must be installed separately and its executable path set in the plugin settings, and it gives the default paths on Linux and Windows. Notation is written in a fenced block tagged lily, and the README states that any LilyPond code may be used at this point. The maintainer records being authorized to maintain the project without owning full rights, and warns that the attached license may not be correct.
