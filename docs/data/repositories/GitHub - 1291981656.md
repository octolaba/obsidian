# hygyh/smart-list-input

Rewrites Markdown list markers as they are typed. A Chinese ordinal punctuation mark followed by a space becomes a standard ordered-list number, typing a hyphen on the line after an ordered item turns it into an indented bullet child, and typing an opening bracket there turns it into an unchecked task child. Tab on an ordered line converts it into a child matching the surrounding context, bullet or task, rather than a nested ordered list, while Shift+Tab restores a child to an ordered item at the same level. Backspace at the end of a marker removes the whole marker and keeps the content, and both standard and full-width task markers are recognized.
