# terryli710/Obsidian-TaskCard

Renders any Markdown task carrying an indicator tag as an interactive card, with priority, due and scheduled dates, project, labels, duration and recurrence written as visible Dataview inline fields, real tags and a native block id. Cards have a compact preview and a detailed mode where each attribute is edited in place; indented lines become the description, child checkboxes become subtasks with progress, and an edit patches only that task's own lines. Capture is helped by autosuggest with natural-language dates, a quick-add box that parses shorthand, and Live Preview styling of field syntax into chips; completing a recurring task inserts the next occurrence below it. A taskcard code block renders a filtered live task list, optionally as an Eisenhower matrix, and needs the Dataview plugin enabled, which supplies the task index.
