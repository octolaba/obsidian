# dy-sh/obsidian-remember-cursor-position

Remember Cursor Position stores the cursor position, scroll position and text selection for each note and restores them when the note is opened again, in both editing and reading views. Positions are recorded as the cursor moves or the note is scrolled and written to a JSON file at a configurable path, so they survive restarts of the application. Restoration is suppressed for links that target a specific heading, so opening such a link does not scroll elsewhere, and a setting decides what happens when no position is stored: go to the beginning, the end, before the footnotes, or nothing. Stored entries can be pruned by removing those for deleted files, by age, or by capping their total number.
