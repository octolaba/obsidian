# bobstanton/places

Manages points of interest and GPX or GeoJSON data held in notes and draws them on maps. Rendering a map requires at least one companion provider plugin supplying the map capability, and across the provider set there are also search, directions, isochrones, elevation, track snapping and track matching, with one provider drawing raster tiles and the rest vector tiles. Overlays generate their own network requests: the TileJSON describing a vector tile source, the contents of a GPX, GeoJSON, CSV or polyline overlay, and image overlays, which are fetched and inlined as data URLs.
