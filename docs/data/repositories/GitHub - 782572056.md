# palfrey/obsidian-random-names

This plugin inserts random names into an Obsidian document, drawing on many categories covering both people and items, and the recorded description says it is meant mostly for RPGs. The README states that the names come from the random-names project used internally and points to that project's full list for the complete set. The rest of the recorded text covers building the plugin from source, installing it manually into the vault's plugin folder, and cutting a release.
