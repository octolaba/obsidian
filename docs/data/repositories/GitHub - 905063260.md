# bridger-herman/obsidian-tab-title-plugin

Replaces the text shown on Obsidian's editor tabs with the note's full path, so several files sharing a name in different folders can be told apart without checking the breadcrumbs. Settings control whether file extensions and a leading slash appear, and whether path separators are included in the truncation characters. Its own truncation can be enabled with a maximum character count and a join string, shortening a long title from the middle instead of Obsidian's default trimming at the end.
