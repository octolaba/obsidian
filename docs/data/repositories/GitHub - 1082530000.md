# backmind/obsidian-at-people

An Obsidian plugin that turns `@` into a mention trigger: type `@` followed by part of a name, pick a suggestion, and a wiki-link to that person's file is inserted. Matching is fuzzy and accent-insensitive, tolerates initials and out-of-order words, can optionally read frontmatter aliases, and ranks suggestions by how often a person is referenced with a boost for recently edited notes. It can also convert selected text into a person link from a command, create person files and folders on the fly, keep them flat or per-person or grouped by last name, and it tags rendered links with an at-person CSS class and data attribute for styling.
