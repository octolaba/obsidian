# dy-sh/obsidian-find-and-replace-in-selection

Adds a find and replace command that operates on the selected text rather than the whole note, so putting the cursor on a line and pressing the hotkey replaces within that line. The search term and its replacement are configured in the plugin settings as either plain text or a regular expression with its own flags. The README gives worked examples, among them removing bold markers, shifting every heading one level with a multiline regular expression, and stripping display text from embed links.
