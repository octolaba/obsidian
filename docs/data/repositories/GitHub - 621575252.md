# logancyang/obsidian-copilot

Copilot for Obsidian provides an in-vault AI assistant with chat-based vault search, web and YouTube inputs, and context processing. It can work with compatible or local models, understand multimedia, apply composer changes, organize project context, and offer an agent mode with tool calling.
