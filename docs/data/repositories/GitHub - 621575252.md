# logancyang/obsidian-copilot

Copilot for Obsidian is an in-vault AI assistant offering chat-based vault search, web and YouTube content, context processing and agentic features. The README states that vault search works without setup and that embeddings are optional, that any OpenAI-compatible or local model can be used, and that webpages, YouTube videos, images, PDFs, EPUBs and live web search can be brought into a conversation. Its stated position is that data stays local and under the user's control with no provider lock-in, and that commands and tools are defined as Markdown files; these are the project's own claims and were not verified here.
