# YishenTu/claudian

Embeds AI coding agents — Claude Code, Codex, Grok, Opencode, Pi and others — in an Obsidian vault as a chat sidebar. The vault becomes the agent's working directory, so file reading and writing, search, bash and multi-step workflows operate on vault content directly.
