# YishenTu/claudian

Claudian embeds command-line coding agents such as Claude Code, Codex, Grok, OpenCode, and Pi into an Obsidian vault used as their working directory. It provides chat, inline edits with word-level diffs, reusable commands and Skills, file mentions, plan and instruction modes, MCP connections, and tab or session management on desktop.
