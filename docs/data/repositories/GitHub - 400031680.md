# ShockThunder/RandomStructuralDiary

This plugin inserts randomly chosen structural-diary questions into a note, so the writer answers different prompts each time. The README states that a prepared list of questions is used when the user has none and links to that list, and that a custom question file can be supplied instead: sections are kept as Markdown headings, questions are separated by line breaks with one per line, and the filename is set in the plugin settings. A settings template of section number and question count controls how many questions each section contributes, with omitted sections drawing a random number; the README records that questions are picked from the whole file by default since 1.1.0, that the old per-section behaviour remains available, and that a generated list is inserted at the cursor location.
