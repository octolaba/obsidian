# elliotboyd/obsidian-traffic-lights

This repository holds a dark and light CSS theme for Obsidian. The README documents optional tweaks left commented out in the last section of the stylesheet, among them an adapted Andy Matuschak mode credited to deathau, which is enabled by removing the comment markers. Installation is described for the Custom CSS era: download the stylesheet into the vault folder and turn on Custom CSS under the appearance settings.
