# BGGBTAC/obsidian-remark-bridge

Pushes the active Obsidian note to a reMarkable tablet with one command and shows the bridge's sync status in the status bar. It speaks HTTP to a separately hosted reMark Bridge instance of version 0.6.0 or later, running on the user's own machine, VPS or Docker stack, so the README states that no data leaves that infrastructure. Setup issues a bearer token on the bridge server with a CLI command and pastes it, together with the bridge's URL, into the plugin settings.
