# wesswart77/obsidian-language-learner

Obsidian plugin for learning languages through vocabulary lists, grammar rules and progress tracking by CEFR level. Commands add a vocabulary word carrying its translation, part of speech, level, example sentence and notes, or create a grammar rule note with explanations and examples, each saved into a configurable folder. A quiz command shows ten random words and tracks which are known and which are still being learned, and a progress sidebar reports per language the total word count, the breakdown across the A1 to C2 levels and the number of grammar rules.
