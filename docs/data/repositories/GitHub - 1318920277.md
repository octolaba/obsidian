# romanmurray/obsidian-stereo

Turns an Obsidian sidebar into a music player for a Navidrome or other Subsonic-compatible server, with browsing of albums, artists, playlists and internet radio, as-you-type search, a persistent queue, and stations seeded from a song, album or artist. The Now Playing view offers album art, a spinning record or audio-reactive visualizers, follow-along highlighting for synced lyrics with click-to-seek, media-key and system-overlay control, and a mini player when the view is left. Favorites and play counts are written back to the server, and lyrics missing from it are looked up at the public LRCLIB service. It is desktop only, talks to no host but the configured server, and stores the server URL, username and password in plain text in the plugin's data file inside the vault.
