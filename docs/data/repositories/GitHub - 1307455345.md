# gwmage/obsidian-rootr-sync

Rootr Sync pushes a chosen vault folder, or notes carrying a chosen tag, into a team's Rootr workspace so that teammates and assistants such as Claude or ChatGPT can read them, and leaves every other note in the vault alone. The README states the sync is one-directional in v1 — vault to Rootr, with the local notes as the source of truth and no writes back — and that the folder structure is preserved one to one. Writes are described as conflict-safe: before each write the plugin re-reads the remote document and compares it against what it left there, refusing the push and listing a conflict when it changed, sending an If-Match ETag so a simultaneous edit is rejected server-side, and refusing to overwrite a document that already exists at the target path but was never pushed by the plugin. It requires a Rootr account and a workspace the user can write to.
