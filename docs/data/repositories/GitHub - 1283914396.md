# dimohy/obsidian-slogs-sync

Repository for Slogs Sync, a plugin that synchronises a vault with the remote vault API of the Slogs service. Its README records configuration with a server address and a token carrying a specific sync scope, an optional remote vault name defaulting to the local one, and commands to sync all files, push the current file, pull remote changes and open the mapped post or the vault settings. Markdown outside the configuration folder syncs by default while attachments and configuration files are opt-in, frontmatter-triggered mappings are likewise opt-in, and a conflict opens a dialog for choosing which copy to keep.
