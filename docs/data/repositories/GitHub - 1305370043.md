# DavidKendig/HephaestusObsidianPlugin

Hephaestus adds a chat pane that talks straight to a local model server, either Ollama or any OpenAI-compatible endpoint such as LM Studio or llama.cpp, with streaming replies rendered by Obsidian's own Markdown renderer. Images and text files can be attached from the computer or the vault, a pasted URL is pulled in as context, and an optional web search over DuckDuckGo, a self-hosted SearXNG or the Brave Search API reads top pages and cites sources inline. The open note can be sent as context, a reply inserted at the cursor, or the model allowed to append to the note behind a confirmation, and transcript messages can be edited, regenerated or deleted. Conversation history lives in the plugin's data with images stored alongside, a gauge shows how full the context window is, and the release is labelled beta.
