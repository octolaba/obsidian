# scooper4711/obsidian-syrinscape

This plugin integrates the Syrinscape Web Player into Obsidian for people who run tabletop roleplaying games from their vault, so that soundscapes are started from the notes rather than from a separate application. Sounds can be attached to the notes for a location or a scene and triggered from a play and stop button beside them, layers of sound effects and music loops added to a running scene, and bookmarked entries gathered into a soundboard for quick access. The README addresses game masters preparing audio ahead of a session, and states its case in a promotional register rather than a descriptive one.
