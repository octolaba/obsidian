# ledokter/obsidian-tbdl-theme

tbdl is an editorial, news-magazine Obsidian theme: Merriweather for body text, condensed Oswald for headings and interface, a yellow accent carrying mastheads, rules and dividers, and a fuchsia accent carrying interactive elements such as buttons, toggles, checked tasks, tags and H3 headings. The first paragraph of a note gets a drop cap colored to match the body text, blockquotes take a yellow bar on a cream ground, and tables, code blocks, frontmatter and callouts are themed alongside a dedicated dark palette. The theme also loads the Google Material Icons font for use inside notes, with helper classes for icon size and color.
