# wjzixi/kuaifanyi

The recorded description calls this an Obsidian plugin for instant translation and text-to-speech with a Volcano neural voice. Its bilingual Chinese and English README describes select-to-translate behaviour that combines dictionary lookup, streaming translation and an AI explanation in one popup, with a swap control in the popup that flips the language direction and re-translates immediately. A translation API key is required, while Volcano Engine speech synthesis is optional and configured with an AppID and access token; the README also documents cloning a custom voice from a ten-second recording and selecting it as the reading voice.
