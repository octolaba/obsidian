# rivea0/obsidian-match-syntax

MatchSyntax searches the contents of the active Obsidian note with a regex-like query language and highlights the parts of the text that match. It uses the compromise library's match syntax, so a query can combine part-of-speech tags, regular expressions written between slashes, AND matching and negation, which the README illustrates by excluding plural nouns from a search for nouns following a given word. It warns that regex lookups are slower than the other types and that matching works only with English grammar because it depends on compromise.
