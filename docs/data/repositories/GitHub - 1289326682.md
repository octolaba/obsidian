# dsvictor/Ink-Paper

dsvictor/Ink-Paper holds Ink Paper, an Obsidian theme built around the Flexoki colour palette and a paper texture that flows through panes, sidebars and active tabs. Sidebars, title bars and file explorers are rebuilt as transparent surfaces so the chosen background serves as a single canvas, and the README describes a CSS background engine that composites a base colour with a texture image URL and further layers. It also lists styled blockquotes with interactive borders, callouts and extensive support for alternate checkboxes including progress, info, question and cancellation markers.
