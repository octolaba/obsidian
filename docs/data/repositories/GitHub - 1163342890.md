# Konoyo-014/obsidian-latex-paren-math

Obsidian plugin that rewrites paren and bracket LaTeX delimiters in Markdown into Obsidian's own dollar-sign delimiters, for vaults where formulas are authored in the LaTeX form but rendering expects the Obsidian one. Single-line paren expressions become inline math and bracket expressions become display math, while multi-line paren expressions are deliberately left alone to avoid destructive rewrites, and fenced code blocks and inline code spans are skipped. Conversion runs on the active note from a command or the ribbon icon, or across every note in the vault from a second command. Because it modifies files, the README advises committing or backing up the vault before a bulk conversion.
