# alephpiece/obsidian-slash-commander

Slash Commander provides a customizable slash command list for Obsidian. The trigger character defaults to a slash and can be changed, additional triggers can be defined, trigger modes can be set per command, and triggering can be restricted to the beginning of a line. The command list itself is customizable, with drag-and-drop reordering of the command setting items, while command groups are recorded as not yet implemented.
