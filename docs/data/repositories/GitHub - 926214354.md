# tynanpurdy/musical-text

Musical Text is an Obsidian plugin that colours sentences according to their word count, so that the variation in sentence length across a page becomes visible as the rhythm of the prose. Marking happens in real time as you type, in one of three styles — highlighting, text colour or coloured underline — with automatically contrasting text colours in highlighting mode, and both the sentence-length thresholds and the colours are configurable. Highlighting is toggled per editor from a status bar button, a ribbon icon or the command palette, and either button can be hidden in the settings.
