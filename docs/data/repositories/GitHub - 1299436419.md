# WebInspectInc/obsidian-chorefast

The repository records no description, so this body rests on the README alone. The README describes a simplified checklist plugin that works on one chosen file and can pick the next chore at random, which the author says lowers the barrier to starting. Tasks use standard Markdown task syntax with inline metadata: emoji for difficulty, weekly, monthly or yearly tags for recurrence, and a due date. An optional web sync pushes the tasks to a public URL through a sync ID and pulls completions from the web back into the file.
