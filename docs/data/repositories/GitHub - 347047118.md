# ArianaKhit/text-snippets-obsidian

Text Snippets replaces short text templates with longer snippets in the Obsidian editor, in the manner of a text editor or an IDE. The README records that the cursor must sit on the word to be replaced, or the text selected when it contains spaces, and that expansion is triggered by a default keyboard shortcut, by a command from the palette, or by Tab or Space when those are configured instead. Snippet bodies support markers for the resulting cursor position, for a line break inside a multiline snippet and for a tabstop the cursor jumps to, and triggering the shortcut with no eligible expansion jumps to the next tabstop. Live Preview support is recorded as a toggle in the plugin settings that has to be set before use, after which the plugin is restarted.
