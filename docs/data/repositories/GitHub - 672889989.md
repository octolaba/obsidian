# Carrie999/comfort

Carrie999/comfort holds Comfort, an Obsidian theme the repository presents as a custom theme aiming at a clean and comfortable interface, in a style its README calls sweet and inspired by Japanese design. The listed changes are removed edge lines, the SimSun font size and a minimalistic design meant to improve readability; the README records the theme as light mode only, with a dark mode possibly added later. It also points to a separate dynamic background plugin and a background image kept in the repository for anyone who wants one, and documents installation through the in-app theme browser.
