# Sh3llingFord/visual-explorer

Visual Explorer adds a gallery view of notes to Obsidian, displaying them as cards with image thumbnails, category tags, dates and a text preview, either as a workspace tab or docked in the sidebar like the native file explorer. The README lists three view modes — a list of cards or a compact flat style, an image-first grid, and a widescreen mode with one full-width image per row — cycled from the toolbar and remembered per folder, with the sidebar variant appearing in the slide-in panel on mobile. Folder navigation shows subfolders at the top with a breadcrumb trail and an optional file count, while live search filters notes and folders by title or tag with a toggle between the current folder and the whole vault. Toolbar buttons are configurable and an action menu carries sorting, favourites, recently opened notes, new document and create folder.
