# jayandoh/yacht-habit-tracker

A habit tracker that runs inside Obsidian and keeps habits and their logs in the plugin's own local data, exportable to another vault. The tracker opens as a sidebar or tab from a ribbon icon or command and can also be embedded in a note through a `habit-tracker` code block, each habit showing the number of consecutive completed days counted back from today. Habits are added, renamed, edited and archived, archived ones staying hidden unless settings reveal them, and all habits and logs export to JSON and import back with replace-all or merge behaviour on duplicates. Settings include the number of date columns shown and the format of their headers.
