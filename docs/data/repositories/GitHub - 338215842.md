# trydalch/obsidian-daily-activity

This plugin inserts records of vault activity into a note, aimed at keeping a log of work alongside daily notes. Its commands insert links to, or plain-text lists of, files created or modified between two dates, with dates and filters entered in a modal and natural-language dates supported, while a stats command inserts a table counting files created and modified for a date. The README describes the plugin as young and written quickly and directs bugs, feature requests and feedback to the repository's issue tracker.
