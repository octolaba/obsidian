# jinzcdev/obsidian-markxmind

Renders XMindMark syntax, taken from the same author's MarkXMind project, as XMind mind maps inside xmind or xmindmark code blocks in Obsidian. The README documents the syntax it accepts: the first non-empty line becomes the central topic, lines starting with a dash or an asterisk are topics whose indentation sets the hierarchy, and markers exist for boundaries, summaries, relationships, links, notes and folding. It also records light and dark theme support and points at an online MarkXMind editor for learning and previewing the syntax.
