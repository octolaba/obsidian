# dskarbrevik/table-dashboard

Table Dashboard renders dashboard widgets from data already held in Markdown tables, declared through a table-dashboard code block. The README lists progress bars, counters, percentages, streaks and line plots; sources that read the current file, a named file or a whole folder; table selection through a tag written as an HTML comment; goals taken from a table column; daily, weekly, monthly, yearly and all-time filtering; count, sum, average, min and max aggregation; and grid or compact-list layouts when several widgets share one block. It also records that incorrect configuration produces guidance and examples rather than a silent failure.
