# moonskorch/ReverySky-Plugin

Renders the vault graph as an interactive 3D scene running on a bundled Unity WebGL runtime, with live graph updates and navigation to and from notes. Layouts include a force-directed one for smaller graphs, a panoramic starfield for large dense graphs, and a chronological arrangement by date, with combined filters by path, tag and date, pan, zoom, rotation and timeline navigation, detailed and simplified display modes, and graphs with or without tag nodes. Node size follows note length and more connected nodes glow brighter; clicking a node flies to it and opens the note, and activating a note locates it on the graph. The README states Obsidian 1.12.7 or later, desktop only, WebGL-capable hardware, testing up to 10,000 notes, and a slow download because of the bundled runtime.
