# xhyabunny/nyanbar

Obsidian plugin that renders a Nyan Cat progress bar for task progress in a note. The README states that a nyan or pusheen command followed by a number from 0 to 100 draws the bar at that value, and that the keyword auto derives the progress from the checked checkboxes of the note. It credits a contributor for a fix to automatic updating of the bar.
