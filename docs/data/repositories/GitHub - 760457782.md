# ravenSanstete/Obsidian-MantouAI

Both the repository description and the README are written in Chinese and present MantouAI as an Obsidian plugin that integrates a large language model as a personal assistant. Recorded functions include asking a question about any selected text, built-in academic operations such as translation between Chinese and English, Chinese polishing, summarizing key points and close reading of a paragraph, role play driven by a role key and value in the note's properties, and extraction of a document's viewpoints. The setup steps download a release into the vault's plugin folder and configure an Alibaba Dashscope API key, while the roadmap lists local models, chatting with the current document and with the vault, and connecting other plugins. The README warns that the current version calls a networked model and that overly sensitive data should not be used with it.
