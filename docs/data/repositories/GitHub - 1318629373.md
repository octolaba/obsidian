# jamalbalya/jemzsync

jemzsync checks whether an Obsidian vault sits where the device's cloud can reach it, and reports rather than moves files: it detects the ecosystem and checks against iCloud Drive on Apple devices or Google Drive on Windows and Android. While Obsidian is open it watches the vault and re-checks within seconds of a change, including files arriving from another device, and it can prove both devices hold the same notes, find files the cloud has not downloaded yet, and resolve duplicate copies left by an offline edit. It never asks for an Apple account and contacts no cloud service; the only address it reaches is api.github.com, and only when GitHub storage is switched on, which is off by default. Listed platforms are macOS, iPadOS, iOS, Windows, Android and Linux.
