# mnaoumov/obsidian-insert-multiple-attachments

The recorded description says the plugin allows multiple attachments to be inserted at a time. The README explains that it modifies Obsidian's built-in Insert Attachment command to accept several files, invoked from the command palette, from a paperclip ribbon icon or from the editor's right-click menu, with every chosen file saved as an attachment and embedded at the cursor. Settings control the text inserted before, between and after the generated attachment links, and whether the ribbon icon and the context-menu entry appear. A demo vault of usage examples ships with each release and can be opened from a command, downloaded from the releases page, or browsed in the repository.
