# johannes-kaindl/local-image-generator

Local Image Generator is a front end for image generation inside Obsidian that talks to a local image server the user runs, such as Draw Things, AUTOMATIC1111, Forge or SD.Next, over their shared A1111-compatible HTTP API; it does not generate images itself, and the model is chosen in the server app. A panel opened from the ribbon or the Open generator command takes a prompt, an optional negative prompt, style chips, one of seven aspect ratios, and step, guidance and seed values, with Generate reusing the current seed and Reroll drawing a fresh one. A History tab keeps past generations as recipes that can be reloaded, and a result can be saved as an attachment, embedded at the cursor, or saved together with a note recording its prompt, seed, steps, size and date.
