# yuriy-bak/obsidian-bible-reference-preview

The repository records no description, so this note is grounded in the README alone. Bible Reference Preview finds Bible references in Obsidian notes and shows verse previews from Bible translations the user imports as EPUB files, storing several translations, reordering them so the top one is active, and comparing up to four at once from the preview header. References are highlighted in the editor and turned into clickable preview links in Reading view, with a floating preview or a side panel, opened automatically for the current paragraph or only on a click, plus a command and shortcut for the reference under the cursor. Further recorded behaviour includes copying preview or comparison text, searching where references are used across notes with contextual snippets, collapsing and dragging the panel, and Russian and English localization.
