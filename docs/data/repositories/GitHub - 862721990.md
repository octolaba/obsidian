# kotaindah55/extended-markdown-syntax

Adds inline and block formatting written with delimiters instead of HTML tags. The inline forms cover insertion rendered as an underline, a Discord-style spoiler, Pandoc-style superscript and subscript, custom colour tags for highlights and a custom span into which the user's own classes are inserted; the block form is a modified Pandoc fenced div. The README states that formatted text stays editable with its style intact, that parsing is context-aware and stops at code blocks, code spans and context boundaries, that individual syntaxes can be switched off, that colour tags and span tags are user-defined, and that rendering carries into exported PDF. Formatting is applied through commands and the context menu.
