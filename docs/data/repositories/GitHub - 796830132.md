# RobTheFiveNine/obsidian-gdscript

This repository holds the Obsidian GDScript plugin, described upstream as adding live GDScript syntax highlighting to code blocks in the Obsidian editor. The README says highlighting applies to a code block whose language is set to gdscript, names Godot as the engine the language belongs to, and records that the plugin is part of the verified community plugins and installable from the community browser. Manual installation into a named plugin folder is also documented, and the source is placed under the Mozilla Public License.
