# sonarAIT/cm-japanese-patch

The recorded description, given in English and Japanese, calls this a patch for Obsidian's built-in CodeMirror editor that adds support for Japanese word splitting. The README says the plugin is based on a Chinese word-splitting module by linonetwo and modified into a Japanese version, using the TinySegmenter segmenter created by Taku Kudo for the segmentation itself. It records that the API feature the patch requires is available only in Obsidian v0.13.8 and later, and documents installation from the community plugin browser or from a GitHub release in both languages.
