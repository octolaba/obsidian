# d7sd6u/obsidian-reveal-folded

Reveal Folded adds a command that reveals the current file in the file explorer while collapsing every other item in the tree, so only the path to the active note stays expanded. An auto-reveal option for desktop Obsidian refocuses the explorer on the active file as the vault is navigated. The README's remaining content lists the author's other plugins rather than describing this one further.
