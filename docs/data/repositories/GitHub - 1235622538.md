# xhydros/Cortex-Chat

The repository holds Cortex Chat, an unofficial desktop-only Obsidian plugin that adds an assistant chat sidebar working against the Codex CLI as its backend. Context is assembled from the active note, outgoing links, explicit mentions, folders, a shared memory folder, recent sessions and an optional local related-note index, each source toggled before sending and listed afterwards in a per-response manifest; text-based PDFs can also be read in. Assistant insertions are shown as a diff before they touch a note, with automatic backups and a log of approved changes, and the README distinguishes a read-only planner mode from an executing mode.
