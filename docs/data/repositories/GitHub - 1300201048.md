# xcloud-ai/quick-codeblock

This plugin inserts a fenced Markdown code block with the cursor positioned inside it, and can wrap selected text in a code block with one command. The README records a customizable language list defaulting to python, javascript, bash, shell, sql, json, yaml, go, rust, java, html and css, a language picker modal, hotkey configuration inside the plugin settings, and conflict detection that warns when a chosen hotkey is already bound and links to the relevant settings. Line breaks around the cursor are handled so the inserted block does not run into existing text, and the recorded text presents the plugin as a replacement for Templater code block templates without requiring Templater.
