# curtismchale/obsidian-book-search-plus

This is a personal fork of anpigon's obsidian-book-search-plugin, which the README says has not been updated since October 2024; the fork exists to apply Google Books API retry fixes and ship an unminified build, and the README advises preferring the original if it resumes active development. The plugin creates book notes from a query by title, author, publisher or ISBN-10 or ISBN-13 against the Google Books API. It is not listed in the Obsidian community plugin directory and is installed through BRAT from the repository. The README discloses that some of the work on the fork was written with the assistance of Claude Code.
