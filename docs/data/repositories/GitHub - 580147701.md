# deepfates/silicon

Silicon adds a panel to Obsidian that connects notes to one another using text embeddings from the OpenAI API. An OpenAI API key is entered in the plugin's settings tab, after which the panel on the right side of the window finds related notes and lists them. The README documents manual installation from a release into the vault's plugin directory and notes that the Obsidian API it builds on is still in early alpha and subject to change.
