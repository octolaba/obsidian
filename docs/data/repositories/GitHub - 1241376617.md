# liuboacean/ima-plugin

Ima Vault integrates Tencent's IMA knowledge base and notes into Obsidian. It searches IMA notes by title or content with pagination, browses notebook directories down to individual notes, renders a selected note in an Obsidian sidebar panel using native Markdown rendering, and imports notes into the vault as `.md` files in one step. A navigation stack moves back and forward between pages, and command-palette entries open the panel or start a search. Use requires a Client ID and API key created on the IMA open platform and entered in the plugin's settings; the README is written in English and Chinese.
