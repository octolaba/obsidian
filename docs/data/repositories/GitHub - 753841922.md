# Qbject/obsidian-canvas-link-optimizer

Changes how link nodes on an Obsidian Canvas are displayed: instead of loading the linked web page as the node scrolls into view, the node shows a preview thumbnail, and the full page opens when the thumbnail is clicked. The README states this is meant to reduce the resource cost the author compares to keeping extra browser tabs open. It notes that generating a thumbnail requires one ordinary page load first, so existing and newly created link nodes are not optimized immediately, and that the plugin writes no vault data because thumbnails are cached in its own folder under the plugin directory, which can be deleted safely.
