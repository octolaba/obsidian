# aaaaalexis/obsidian-bamboo

An Obsidian plugin that patches the editor's CodeMirror word segmentation so that selecting and moving by word behaves correctly in Chinese, Japanese and Korean text. Segmentation uses Intl.Segmenter with a regex fallback, covering traditional and simplified Chinese, Japanese and Korean. The README compares it with the older Word Splitting plugin, recording that this one does not support Vim mode or custom word lists.
