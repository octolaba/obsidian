# oin/obsidian-gotoheading

This plugin adds commands for moving between the headings of a document. Next and previous heading move relative to the cursor position, a quick switcher presents the outline of the current document so that a heading can be selected, and a variant of that switcher covers the outlines of every document in the current folder. An option makes the next-heading command continue to the end of the file.
