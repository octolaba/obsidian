# pcrausaz/obsidian-inkedmark

InkedMark makes handwriting a first-class block inside ordinary Markdown notes in Obsidian, so diagrams, mathematics, marginalia and fast capture can be written by hand in the same note as typed text. Handwriting notes are `*.ink.md` files that open in a pen-first canvas view while remaining plain Markdown files that sync, diff and link like any other note, and each carries a typed text layer — transcription, key points, links and tags — which Obsidian's core search, graph, backlinks and Quick Switcher index without extra work; a handwriting note can also be embedded in another note or placed inline as a small `inkedmark` block. The README describes the ink as built for Apple Pencil, with pressure-variable strokes, palm rejection and a wet-and-dry canvas split, working on desktop, iPad and mobile.
