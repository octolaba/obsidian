# tcmmichaelb139/obsidian-tokyonight

This repository holds a Tokyo Night theme for Obsidian, taking its colors from tokyonight.nvim and the Tokyo Night VS Code theme. Night and Light are the defaults, while Storm and Moon ship as configurations imported into Style Settings, and that plugin is required to change colors. The README also documents an extended set of checkbox markers covering incomplete, done, canceled, forwarded, scheduling, question, important and further task states, and credits the Obsidian Border theme for some styles.
