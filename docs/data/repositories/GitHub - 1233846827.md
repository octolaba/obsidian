# zhanpeng329-arch/obsidian-CodeIndentation

ignoreMD adds a hover formatting toolbar to the Obsidian editor. While a Markdown file is being edited it shows a compact Md button near the active line or selection; hovering over the button opens a formatting panel from which a format is applied without typing the Markdown syntax by hand. The panel covers headings, bold, italic, highlight, quote, unordered, ordered and task lists, inline code, code blocks and links, and the README states that the plugin runs locally with no telemetry, network calls or background tasks.
