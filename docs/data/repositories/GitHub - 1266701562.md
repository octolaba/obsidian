# 0Crazy-0/obsidian-void

Void is a minimal dark Obsidian theme built on a black and gray palette with subtle contrast and little visual noise. The README states that it is designed for dark mode only and warns that in light mode it may look bad and become hard to read. Installation is described through the community themes browser.
