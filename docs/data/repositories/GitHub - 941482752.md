# en3sis/vercel-obsidian

This repository holds Vercel-Geist, an Obsidian theme its README describes as clean and modern, inspired by Vercel's Geist design system, with dark and light modes. Installation is documented by cloning the repository into the vault's themes folder and then selecting the theme in settings. The README links the Geist design system as its reference and lists publication to the theme gallery as a remaining step.
