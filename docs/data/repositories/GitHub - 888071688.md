# incantatem2/Obsidian-winter-spices

Winter Spices is a simple, minimalist Obsidian theme that its README calls cozy and good for writing long text and journalling. It uses Georgia and YU Gothic as its fonts, and the README states that it looks the same in light and dark mode while working best in light mode. An update note records work in progress to make code more readable.
