# Reggie86/vaultdex

VaultDex is a full-text search plugin for Obsidian with a deliberately retro presentation, opening as a full workspace tab that indexes the vault on load and returns ranked results. The README says title, tag, header and body matches are weighted into a relevance score, and results carry highlighted snippets, breadcrumb paths and clickable tags that browse every note with that tag. It also documents a PARA category sidebar for filtering, sorting by relevance or newest, a random-note action, folder-scoped queries written as a folder name before the search terms, quoted phrases and multi-word AND queries, styling drawn from Obsidian CSS variables so any theme and colour scheme works, and mobile compatibility.
