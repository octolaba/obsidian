# d-sauer/Obsidian-Min3ditorHotkeys-plugin

The repository holds a minimal Obsidian editor plugin that adds a few hotkeys to the editor. Its README lists three commands with default bindings: insert a new line above the current line, insert a new line after it — both working wherever the cursor sits on the line — and duplicate the current line or the selection. The recorded inputs describe nothing beyond those commands.
