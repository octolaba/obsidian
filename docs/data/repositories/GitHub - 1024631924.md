# EmberSparks/obsidian-github-stars-manager

Lists and manages GitHub starred repositories inside Obsidian, with several accounts synced independently, custom tags and notes per repository, and links from a repository to an existing vault note. Search filters by name, description, language and tags with regular expressions and fuzzy matching, and results sort by star time, name, language or star count. The README states that GitHub tokens, the repository cache, tags and notes are kept in local plugin data, and that the plugin contacts the GitHub API, github.com and GitHub avatar hosts only when configuring an account, validating a token, syncing or opening a link.
