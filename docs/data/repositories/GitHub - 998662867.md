# Marvive/Citation-Callouts

Citation Callouts formats a quote together with its citation as a callout in Obsidian. Content copied to the clipboard that carries a citation with a URL or source reference is pasted through the plugin, which extracts the source name and uses it as the callout title alongside a book icon, and preserves rich text such as bold, italic and hyperlinks. The action is reached from the command palette, from a ribbon book icon, or from a hotkey assigned in the settings.
