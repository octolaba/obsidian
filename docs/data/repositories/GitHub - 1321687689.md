# git-akihakune/obsidian-browser-history-sync

Browser Sync is a desktop-only plugin that imports locally stored browser history into the vault as Markdown, CSV or JSON, writing a separate entry for every visit so repeated visits to one URL stay distinct, across every detected profile of each enabled browser. Safari on macOS, Firefox and Chrome are first-class, while Edge, Brave, Chromium and Vivaldi are read through a Chromium adapter as long as their history schema matches Chrome's; a missing browser is skipped and one failing profile does not stop the others. Imports run only when the import command is invoked, with no startup import, timer, background watcher or ribbon action, a separate command rebuilds an existing output folder, and settings hold per-browser toggles, a vault-relative output folder and the export format.
