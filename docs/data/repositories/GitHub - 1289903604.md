# shuuul/obsidian-sidecard

SideCard adds a card panel to an Obsidian sidebar so several notes, PDFs or images stay visible while another file is being edited in the main editor. Cards can be added through a search box that also lists recent files, dragged in from an editor tab, dragged back out to become a normal tab, reordered by a grip handle, resized from the bottom edge, and pinned to lock their body area and height. Markdown cards render with Obsidian's own renderer while PDF and image cards preview in place, and a card's source file can be inserted into the active editor as a Markdown reference. The README describes the panel as inspired by Heptabase and intended for writing and research sessions.
