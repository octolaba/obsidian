# fanthus/obsidian-auto-spacer

An Obsidian plugin for mixed Chinese-and-Latin typography that inserts spaces at the boundaries between CJK characters — including Japanese kana and kanji — and Latin text, and wraps the Latin segments in inline code. It runs over the selection, or over the current line when nothing is selected, from a command with a default shortcut, and skips existing backticks, links, tags and other Markdown structures. An optional button in the editor header triggers the same formatting. The repository carries no description.
