# lxy3372/obsidian-ai-selection-toolbar

Obsidian plugin that shows a floating toolbar over selected text with AI translation, explanation, summarisation and word recognition, plus text-to-speech in two modes. Speech uses either the browser's built-in engine or an OpenAI-compatible TTS API, with adjustable rate and pitch. Translation, explanation and summary stream their output, take a configurable target or output language and use editable prompt templates, while word recognition applies to single words or short phrases and returns IPA or pinyin with two generated example sentences. The AI endpoint accepts OpenAI or Ollama style URLs and each feature can be switched off on its own.
