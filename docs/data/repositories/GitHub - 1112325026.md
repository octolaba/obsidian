# SiranHQ/obsidian-QuadTasks

QuadTasks renders an Eisenhower matrix inside an Obsidian note from a code block declared with the eisenhower, eisen or todoeh alias. Tasks sit in four quadrants — do first, schedule, delegate and eliminate — and can be dragged between them or reordered, with a toggleable inbox for capturing tasks to sort later and a focus mode that zooms into a single quadrant. Tasks are stored as plain text inside the note, annotated with their quadrant and supporting standard Obsidian syntax such as wikilinks, tags and formatting, and view preferences are remembered per file.
