# firstsun-dev/watermark-bucket-uploader

Intercepts every image paste and drop in Obsidian, stamps a watermark on the image, converts it to WebP and uploads it to the user's own S3-compatible bucket, then writes the resulting link into the note. Text or logo watermarks are configured in font, size, colour, opacity and position, with a preview showing the result before an image is uploaded. The README names Cloudflare R2, AWS S3, MinIO and Backblaze B2 among the supported stores, and describes glob-based ignore patterns that keep chosen notes out of the upload path.
