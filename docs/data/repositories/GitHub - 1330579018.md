# lizijing98/calendar-panel

Calendar Panel puts a month calendar in the right sidebar for opening daily notes, creating a missing one from the configured daily note template, and moving between months or jumping to a date through a month and year picker. A filled dot marks a date that already has a note and a hollow dot marks a note containing outstanding tasks, and the selected day's note, or an entry point to create it, appears below the calendar. Week numbers can be displayed and clicked to open or create a weekly note, and commands open the view, the current weekly note, or reveal the active note in the calendar. Daily note configuration is read from the core Daily Notes plugin when present, weekly note settings come from the plugin itself, and it runs entirely locally on Obsidian 1.13.0 or newer.
