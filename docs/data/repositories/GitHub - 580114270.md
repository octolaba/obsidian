# Bluemoondragon07/Wikipedia-Theme

This repository holds a theme that styles an Obsidian vault after Wikipedia, restyling images, headings and the sidebar in that encyclopedia's classic look. Info blockquotes float to the right as infoboxes, with inline Dataview fields inside them shown on separate lines in infobox style, and a sixth-level heading renders as an infobox heading with a yellow background. The README documents alt values that force a callout or image to float left or right or center, or to opt out of the infobox styling, and records an update in which images gained the encyclopedia's border, the default font became Arial and dark mode was reworked.
