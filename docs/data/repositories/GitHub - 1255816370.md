# Moskize91/obsidian-roam-graph

Keeps a small graph in the right sidebar that follows the note being edited: the active note sits in the centre, backlinks to its left, outgoing links to its right, and neighbouring daily notes above and below when the active note is a daily note. The graph is rendered as a real generated Obsidian Canvas file through the native Canvas renderer rather than a custom interface, which the README gives as the reason it stays close to Obsidian's own editing model. It follows the active note automatically, can be opened or refreshed from the command palette or a ribbon icon, and clicking a note in the graph opens it in the main workspace while the Canvas stays in the sidebar.
