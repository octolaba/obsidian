# greater-than/Obsidian-Tracker-Plus

Tracker+ tracks and visualizes data recorded in notes, rendering tracker code blocks once the document is switched to preview mode. The README describes adding those blocks by hand or through commands, and ships a sample vault carrying the examples and documentation to be opened in Obsidian itself. It is a continuation of the Tracker plugin originally developed by pyrochlore, which had not been updated since February 2022 when this fork was released, and its own releases start at version 1.0.11.
