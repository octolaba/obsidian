# jialingxiao/obsidian-feynman-learning

Feynman Learning guides a four-step Feynman Technique cycle inside Obsidian: select a concept, explain it simply, identify gaps, then simplify and use analogies, with an AI tutor asking follow-up questions and checking gap coverage before advancing. The AI runs against any OpenAI-compatible API and scores an explanation on three dimensions, which decides whether a concept moves through the four mastery levels and how the spaced-repetition interval changes, with configurable default intervals of 1, 7 and 30 days and a targeted drill after a failed or partial review. Further features include extracting concepts from pasted text into a learning queue, quizzes, AI-suggested related concepts and wiki-links, batch review of everything due, and a dashboard with streak, due count, mastery distribution, activity heatmap and an AI-written weekly report. The plugin can also sync to Notion.
