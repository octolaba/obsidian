# Rome-1/obsidian-beads

Beads for Obsidian shows a local Beads tracker's issues in a pane with Ready, In progress, Blocked and Closed tabs, each with a live count, paginated by a load-more button and refreshed when the tracker directory changes. Clicking a row opens the issue in an editor tab as YAML frontmatter for its fields plus a Markdown body for the description; saving writes only the changed fields back, and status is set to closed or open there. Dependencies and the comment thread render below the editor, a capture command creates an issue, and a status bar item shows the ready count while the pane is closed. A fenced beads block embeds a query in a note and renders the same clickable rows inline; the plugin is desktop only because it shells out to the separately installed bd binary.
