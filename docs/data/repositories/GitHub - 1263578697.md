# Maws7140/nn-bridge

This repository holds NN Bridge, a companion Obsidian plugin that layers visual tweaks and toggle options onto the navigation pane of the Notebook Navigator plugin without forking or editing it. The README states that NN Bridge does nothing on its own and that Notebook Navigator must be installed and enabled first. Its options include reversible toggles that hide shortcut labels, section headers, the vault title, count badges, the banner image, separator lines and chevrons, overrides for indent distance and chevron size and colour, recents filtering, custom collapsible sections, and pinning any Obsidian command into the Navigator's shortcut list with its own label and icon.
