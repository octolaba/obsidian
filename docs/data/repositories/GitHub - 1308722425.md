# aitsuki/obsidian-mermaid-lens

Mermaid Lens applies one shared Mermaid theme, colour palette, font, spacing and layout configuration across the vault, and opens diagrams in a dedicated viewer that is not constrained by the note width. In the viewer the diagram is panned by dragging and zoomed with the wheel, toolbar, keyboard or touch gestures, and the activation trigger can be set to a single click, a double click or an expand button, with links and buttons inside a diagram still usable. New configuration is validated before saving and the previous valid configuration is kept if applying or saving fails, while small diagrams keep their natural size and large ones are constrained to the note width. The README records Obsidian 1.12.0 or later as a requirement.
