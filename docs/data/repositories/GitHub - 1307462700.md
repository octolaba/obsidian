# casperkwok/obsidian-loupe

Loupe makes the files that Obsidian's file explorer normally hides visible and previews them inline, covering Office documents, HTML, spreadsheets, delimited data, JSON and more than fifty code and configuration formats. The README's format table records HTML shown in a sandboxed iframe, spreadsheets rendered as multi-sheet tables through SheetJS, quote-aware CSV and TSV tables with row numbers, DOCX converted to sanitized HTML, pretty-printed and highlighted JSON, and code highlighted with Obsidian's own engine. Formats such as PPTX, ODP, EPUB, ZIP and RTF are made visible and handed to the default application instead.
