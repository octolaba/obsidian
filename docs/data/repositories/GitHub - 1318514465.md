# zz41354899/slidex-obsidian

A desktop-only, read-only bridge that exports a scoped selection of vault notes to the SlideX presentation service. After a vault is connected from the ribbon, SlideX receives an index of vault metadata, then the Markdown and referenced images of an import job chosen by folder, tags, dates or files, and afterwards only changes to notes explicitly linked to presentation elements. The plugin never writes to the vault, does not index full note content in SlideX and runs no model itself, and its connection token is scoped to a single vault and can be revoked, which stops further reads without deleting presentations already made.
