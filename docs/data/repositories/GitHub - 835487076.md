# Erallie/css-inserter

CSS Inserter wraps the selected text in a user-defined snippet, where each snippet names an HTML tag and optionally a class and inline style. Snippets are defined in the plugin settings — only a name and a tag are required — and can be reordered or deleted there. The README describes the plugin as a fork of Style Text whose difference is that the tag, class and style are specified per snippet, and it states that basic CSS knowledge is needed to configure them.
