# MichaelNguyen5653/Bullet-Depth-Markers

Bullet Depth Markers rewrites the list marker in the file itself so nesting depth is visible in the text: hyphen at the first level, asterisk at the second, plus at the third, then repeating, and rendered as three bullet shapes in Live Preview and Reading view. It binds no hotkey and corrects the marker right after Obsidian's own indentation, whether from Tab, a drag or a paste, swapping one character for one so the cursor holds its place and a single undo reverses the edit. Numbered lists keep their numbers while still counting as a level, and code blocks, frontmatter and existing notes are untouched until a list is edited; checkbox items change marker but stay checkboxes. The marker sequence is configurable and restricted to the three characters Markdown accepts as list markers.
