# anupchavan/obsidian-custom-views

The repository holds Custom Views, an Obsidian plugin that renders notes through custom HTML templates chosen by matching rules. Rules select notes by file data, tags, folders and frontmatter properties, and templates support placeholders, filters, conditionals, loops and expressions, can render note content and wikilinks through Obsidian's Markdown renderer, and can query Obsidian Bases. Scoped CSS and optional JavaScript are supported for trusted templates, and the README states that the first matching view wins, so narrower views belong above broader ones.
