# cwagner223355/knox-timeline

Knox Timeline shows a Fastmail calendar as a timeline in an Obsidian sidebar leaf and turns any event into a meeting note in one click. Single-day and two-day views are offered, all-day events sit in a strip above the timed grid, individual calendars can be enabled or disabled, and read-only external iCal feeds can be added with a name, address and colour. Noisy events such as recurring blockers and declined invitations can be hidden and unhidden later, the view refreshes at midnight and on stale data, and commands move to the previous or next day, jump to today and refresh. Setup uses a Fastmail app password limited to CalDAV calendar access, stored in Obsidian's SecretStorage.
