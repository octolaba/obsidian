# omni-gh549/obsidian-infobox

Obsidian plugin that renders Wikipedia-style infoboxes from a note's YAML frontmatter, including a floating panel pinned to the top right of the reading pane. An infobox block in the frontmatter supplies title, subtitle, image, caption, tags and a list of key-value fields with named section dividers between them, so the note body needs no special syntax. Text properties and field values may carry internal vault links, images resolve from a plain filename, an internal link or a remote URL, and the README records automatic light and dark theming on both desktop and mobile.
