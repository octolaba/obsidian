# omni-gh549/obsidian-infobox

Omni Infobox reads an infobox block from a note's YAML frontmatter and renders it as a Wikipedia-style card, shown as a floating panel pinned to the top right of the reading pane. The block supports a title, subtitle, tags, a single image with caption or a gallery that becomes tabbed when it holds more than one entry, and a list of label-and-value rows broken up by named section dividers. Images resolve from the vault by plain filename or wikilink, or from a remote URL, and text values may contain internal links. Nothing is added to the note body, tags fall back to the note's own tags, and the card follows the light and dark theme on desktop and mobile.
