# TomHan518/vault-llama

VaultLlama is a desktop-only Obsidian plugin for chatting with a local Ollama model from a side panel. The README describes refreshing and selecting installed models, streaming responses with a stop button, clearing the session, and copying or inserting the latest answer at the cursor, with settings for the base URL, temperature, top-p, repeat penalty, context size, maximum tokens, input sizing, whether conversation history is sent, and whether a remote base URL is allowed. It also states plainly what the version does not do, listing note or selection context injection, editor actions such as explain and summarize, telemetry, account login and cloud sync, and it names an installed and running Ollama as a requirement.
