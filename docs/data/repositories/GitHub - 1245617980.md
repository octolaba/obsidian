# dacrystal/obsidian-mermaid-next-plugin

Mermaid Next registers a `mermaid-next` code block and renders it with a current build of Mermaid loaded independently of the copy bundled with Obsidian, so newer diagram syntax becomes usable without waiting for an app update. The source is either the copy shipped inside the plugin, which works offline at a fixed version, or the jsDelivr CDN, where the version can be left at latest or pinned and a selected version downloaded into a local cache. Further settings decide whether diagrams follow the active Obsidian theme and whether the ELK layout engine is used, and the README records that changes apply on the next render without reloading the plugin.
