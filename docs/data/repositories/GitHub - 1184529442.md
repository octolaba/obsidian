# corecube/obsidian-sheet-music

Sheet Music renders playable music notation inside Obsidian notes from five kinds of code block. The README maps each to a purpose: ABC notation renders staff notation with playback, tempo control and transposition; strumming blocks render rhythm patterns with timing labels and animated playback driven by a JSON object of stroke tokens; chord blocks render lyric-and-chord sheets with diagrams and transposition; progression blocks show chord progressions with Roman numeral analysis; and MIDI blocks play back a captured recording with transport controls and export. It also records live MIDI capture from a connected keyboard directly into a block, and that ABC blocks accept a JSON header of renderer parameters, showing an error banner but still rendering when that JSON is invalid.
