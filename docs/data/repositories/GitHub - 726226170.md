# ebullient/obsidian-show-whitespace-cm6

This plugin enables CodeMirror 6 extensions that highlight whitespace in Obsidian's Source and Live Preview modes. It displays leading and trailing whitespace, highlights the leading caret of a blockquote so blockquotes stand out, and applies a slight background to the whitespace belonging to list markers. Leading space is always shown once the plugin is enabled, while inner and trailing space depend on configuration, and the characters used for line endings and line breaks can be redefined through CSS variables. A setting disables registration of the plugin's own stylesheet so a user can copy it into a snippet and restyle it.
