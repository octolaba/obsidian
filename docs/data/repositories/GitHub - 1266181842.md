# towishy/owen-wiki-plugin

This plugin installs the Owen-WIKI Template Kit into the active Obsidian vault, creating a wiki operating structure together with starter pages, ontology and page templates, automation scripts and assets. Its README lists what a configuration run creates: guidance, changelog, setup, index and log files, dated raw folders for articles, clippings and outputs, wiki folders for entities, concepts, summaries, comparisons, synthesis and ontology, plus templates, scripts, assets, output folders and an optional GitHub Actions lint workflow. It states that the plugin asks before creating vault files on first activation and skips existing files unless overwriting is enabled, and it documents both manual and BRAT installation.
