# exa-labs/obsidian-exa-search

Exa Search queries the Exa web search service from Obsidian and inserts the results into the note at the cursor, or copies them to the clipboard when no editor is open. The README states that a command palette modal takes a typed query and a second command searches the current selection, that results arrive as Markdown with links, dates and highlights, and that the number of results, highlights, full-text extraction and search type are configurable. An Exa API key entered in the settings is required; the plugin uses Obsidian's built-in HTTP client and works on desktop and mobile without external servers.
