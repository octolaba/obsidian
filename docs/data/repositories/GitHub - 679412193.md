# dmitrii-mitrichev/pickly-page-blend

Pickly PageBlend publishes a note from Obsidian and returns a link to the published file, supporting Markdown syntax, publication of linked notes and files, and permanent links to files. Publishing is triggered by a keyboard shortcut, the file context menu or a command, and the preview image of the page is the first image in the note, or an automatically created image carrying the note title when the note has none. Meta tags default to the note title and can be overridden through frontmatter properties, and the README describes an option that builds a video from the note text through the Viqeo article-to-video player.
