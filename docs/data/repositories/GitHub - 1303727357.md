# zhy9495/obsidian-xhs-longform

XHS Longform Exporter lays a Markdown note out as a sequence of 3:4 image cards sized for Xiaohongshu, exporting continuous 1080 by 1440 PNG pages. An export panel adjusts cover image, avatar, title, nickname, fonts, sizes, colour scheme and margins against a live preview, and pagination is computed from real font measurement so text that does not fit moves to the next page, with the nickname and page number fixed on every page. Files are written into the vault under a folder named after the note, or to any folder chosen through the system picker. The README states that parsing, font measurement, pagination and image generation all happen locally with nothing uploaded to the developer's servers, and that on macOS a note embedding MP4, MOV or GIF material is exported into a new Photos album with those pages as Live Photos.
