# ankit-kapur/obsidian-kanban-status-updater-plugin

The recorded description says the plugin automatically updates a note property when a card is moved to a column. Per the README, moving a card between columns of a Kanban board sets a frontmatter property on the note the card links to, named status by default and renameable, so that views can reach across boards; its example is a Dataview query for notes whose status is not Done. It states that only the currently active Kanban board is monitored for performance reasons, that property updates give visual feedback, and that a debug mode is available for troubleshooting. The Kanban plugin must be installed and enabled for any of this to work.
