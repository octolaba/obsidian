# SiavashAmeli/TimelineX

The repository holds TimeLineX, an Obsidian plugin that places notes on timelines instead of in a folder or graph view. Its README records that a note joins a timeline through frontmatter: a required date, which accepts a bare year including negative years for BCE or a full date, a required timeline name that is created the first time it is used, an optional date_end that turns the note into a range, and an optional calendar key. Setting that key to persian or hijri marks the dates as written in the Hijri Shamsi or Hijri Qamari calendar, and values are converted to a shared representation so timelines with mixed calendars still line up. Timelines can be overlaid, filtered, recolored, viewed alone, and dragged on the canvas to retime a note.
