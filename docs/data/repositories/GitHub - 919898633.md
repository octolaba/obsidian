# bgrundmann/obsidian-fountain

This repository holds a Fountain plugin, described upstream as writing screenplays in Fountain format inside Obsidian. The README lists live screenplay formatting as the writer types, a near-print read-only view that can hide notes, synopses and boneyard, PDF export with configurable paper size and scene heading style, an index-card view supporting inline renaming, insertion, section depth changes and drag reordering across files, an outline sidebar doubling as a planning tree with synopses and per-scene todos, and a rehearsal mode that blacks out one character's dialogue. Scene numbers written in the Fountain form are shown in both margins, with commands to renumber them.
