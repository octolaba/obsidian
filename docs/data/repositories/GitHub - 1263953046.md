# DuckTapeKiller/memento

Memento manages events and a timeline alongside the Obsidian Calendar plugin, marking event days on the calendar and creating an event from a right-click on a date or a button in its own view. A sidebar timeline merges its own events with read-only ICS subscriptions from external calendars, cached separately, and filters them by search, source, calendar, date range, completed and archived state. Events can recur daily, weekly, monthly or yearly with custom intervals, optional end dates and occurrence counts, and clicking one creates or opens a dedicated note whose path is remembered per occurrence. The README records edit, duplicate, complete, archive, delete, copy, hide and import workflows, JSON export and import of manual events, and English and Spanish localisation that also translates the frontmatter keys.
