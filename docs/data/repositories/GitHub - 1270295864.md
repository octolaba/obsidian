# WooP18/Zhongwen-Vault

This repository holds Zhongwen Vault, an Obsidian popup dictionary for Chinese text. Hovering a word shows a card with simplified and traditional forms, Hanyu pinyin coloured by tone, optional Zhuyin and English definitions from CC-CEDICT, and the popup can be moved word by word or character by character from the keyboard and switched off at any time. Saved words go to a built-in list that exports to Anki or Skritter, and grammar points link out to the Chinese Grammar Wiki. Its dictionary lookup, binary-search index, greedy segmentation and pinyin conversion are ported from Christian Schiller's Zhongwen browser extension, from which the plugin also inherits GPL-2.0.
