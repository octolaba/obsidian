# callumalpass/tasknotes-workflows

TaskNotes Workflows is a companion plugin for TaskNotes in which each automation is an ordinary Markdown note: its frontmatter defines the rule and its body explains what the rule does. Workflow notes live in a dedicated folder and can be reviewed, edited, dry-run and enabled from a bundled base view, with commands to open, create, reload and migrate them. The README lists the shipped examples, among them time tracking driven by status changes, clearing scheduled dates when work starts, rolling overdue tasks forward, escalating priority as a due date approaches, blocked-task review and inheritance from a parent task to its subtasks, and states they are created disabled so they can be inspected first. Its requirements are Obsidian 1.8.0 or newer and TaskNotes, with a further plugin needed only for cross-application contract events and actions.
