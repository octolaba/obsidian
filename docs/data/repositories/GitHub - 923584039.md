# GanapathyRaman/rsync-plugin

This plugin synchronises vault files between machines by driving the rsync tool. A sync is started from a ribbon icon, which opens a modal for choosing the direction — push from local to remote or pull from remote to local — and shows a progress bar while it runs; a dry-run mode previews the changes without making them, and a schedule interval in minutes triggers the sync automatically. The settings hold the rsync binary path, the local and remote paths, SSH credentials using either a password or a private key, patterns for files and directories to exclude, and a log file where the operation's output is kept.
