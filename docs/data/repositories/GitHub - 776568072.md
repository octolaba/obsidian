# dzruyk/obsidian-asciidoc

Obsidian plugin for editing and viewing documents written in the AsciiDoc language. Both view and edit modes are supported and switched with the standard toggle reading view hotkey. The README states that global file search is not available because of limits in the Obsidian API and suggests the Omnisearch plugin instead, and that this plugin is incompatible with other asciidoctor plugins such as asciidoc-reader and asciidoc-blocks, which must be disabled when loading fails.
