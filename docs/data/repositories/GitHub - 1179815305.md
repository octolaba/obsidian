# TodFrog/obsidian-paper-summary

Paper Summary turns a PDF already stored in an Obsidian vault into a structured note with frontmatter, summary sections and links to related papers, started from the command palette or the PDF file menu. The README records a built-in note template or a custom vault template rendered from placeholders, an output language choice of English, Korean, automatic or custom, related-paper links derived from tags, title similarity, author overlap, venue and year signals and section-keyword overlap, and filenames made safe with numeric suffixes on collision. Supported providers are listed as OpenAI, OpenRouter, Gemini, Claude through its OpenAI compatibility layer, local Ollama and a generic OpenAI-compatible endpoint, all driven by one request pipeline.
