# wholetomy/obsidian-e-daiary

Obsidian plugin that creates journal entries numbered by the day of the year. Clicking its ribbon action creates a folder and note named after the day number and the current date and time, inside a journal folder chosen in the plugin options, ready to be written into. The README documents the installation of a release archive into the vault's plugins folder and the steps for rebuilding the plugin from source.
