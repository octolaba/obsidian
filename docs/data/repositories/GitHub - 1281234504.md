# yaye-work/canvas-kit

This repository holds Canvas Kit, an Obsidian plugin that adds annotation and note-making tools to Canvas. It supplies a marquee select tool, a draw kit with marker, highlighter and washi tape whose designs can be replaced by any uploaded image, a text tool that types anywhere without a card, and a card tool that creates and sizes a card in one drag while quickly adding an existing or new note. Ink is stored as inline SVG inside ordinary canvas text nodes, so there are no separate drawing files and everything stays in the canvas file itself. The README notes the touch gestures used on tablets: two-finger tap undoes, three-finger tap redoes, and two fingers pan and pinch-zoom.
