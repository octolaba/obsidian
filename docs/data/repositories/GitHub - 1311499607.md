# jqml/latex-suite-rev

The repository records no description; its README presents LaTeX Suite Rev as a fork of Obsidian LaTeX Suite by artisticat1, retaining the upstream MIT license and copyright notice, maintained as a distribution carrying compatibility fixes rather than an original reimplementation. The fix it packages recognizes CodeMirror math delimiter nodes semantically when Obsidian inserts Markdown structural components such as list or heading tags into their composite names, where upstream compares those names exactly, so inline-math context and snippet expansion survive inside those structures. The README warns that this plugin and the official LaTeX Suite must not be enabled at the same time because both register the same commands and editor extensions. It records a minimum Obsidian version of 1.4.10, desktop testing on 1.13.3, and a mobile build that has not yet had a device smoke test.
