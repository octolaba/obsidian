# Vinzent03/obsidian-hotkeys-for-templates

The repository holds Hotkeys for templates, an Obsidian plugin that generates a command for each template file so it can be inserted by keyboard shortcut. Its README records that the template files are listed in the plugin's settings pane and enabled individually there, after which the shortcut is assigned in Obsidian's own hotkeys section. It requires the core Templates plugin to have a template folder configured, and it also supports templates belonging to the Templater plugin.
