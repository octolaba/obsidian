# christinate/AcademicExport

Exports a Markdown note as a formatted document in one of several academic styles, among them APA 7, MLA 9, Chicago 18, IEEE Conference, two Harvard variants and AMA 11, to PDF, DOCX or HTML, with more than one output type per run. Document metadata comes from YAML frontmatter, the body is Markdown, and references go under a References, Works Cited or Bibliography heading; every heading after that section starts its own addendum page, which is how tables and figures are authored. Vault embeds and standard Markdown images are resolved and reduced to fit the page without ever being enlarged, and emphasis, strikethrough and inline code carry into the output. Other commands create an export template or replace a note with one after taking a timestamped backup, and output is saved through a desktop dialog where available and to a configured vault folder on mobile.
