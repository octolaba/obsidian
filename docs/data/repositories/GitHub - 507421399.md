# jensmtg/influx

An alternative to Obsidian's core backlinks pane that shows excerpts of the content surrounding each linked mention rather than the link titles alone. Excerpts are selected and grouped by the position of the mention in the note's hierarchical bullet structure, and sorting, layout and filtering are configurable. The pane appears at the bottom of a note once the plugin is enabled; the README names excerpt length, grouping and maximum item count as the settings to adjust first.
