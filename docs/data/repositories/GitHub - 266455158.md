# kartik-karz/moonlight-obsidian

kartik-karz/moonlight-obsidian holds Moonlight, a theme for an Obsidian vault. Its README says the theme can be used by enabling it from the community theme menu or by pasting the provided obsidian.css file into the vault, and it shows how it looks in dark and light theme mode under the names Moonlight Dusk and Moonlight Dawn.
