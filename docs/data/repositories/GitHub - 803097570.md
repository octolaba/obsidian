# Tej-Sharma/notes2tweets-obsidian

Obsidian plugin that generates and schedules tweets from notes, converting what has already been written at the press of one button. Setup means installing the plugin, entering API keys in its settings, and opening its sidebar view to generate posts and schedule the ones worth keeping. Its roadmap records conversion of newly written notes, automatic scheduling, threads and prompt customisation as done, with further customisation parameters and image generation still open, and it offers a paid licence for users who do not want to set up the OpenAI and Twitter APIs themselves.
