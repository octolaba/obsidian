# mrjw717/obsidian-code-graph

Code Graph visualizes how code files connect through imports, calls, inheritance, implements, comment-links, ADRs and tests, rendering them as an interactive force-directed graph beside Obsidian notes. It parses source files with tree-sitter to extract typed edges for TypeScript, TSX, JavaScript and Python, uses regex import extraction for CSS, C, C++, Go, Rust, Java, Lua and PHP, and can turn functions, classes, methods, interfaces and types into symbol-level nodes inside their containing files. Comment tags such as `@see`, `@tested-by`, `@adr` and `@depends-on` become typed edges while `@domain`, `@status` and `@author` become node metadata for coloring, filtering and tooltips, files carrying TODO or FIXME comments are highlighted, and frontmatter `related-code` links a note to code.
