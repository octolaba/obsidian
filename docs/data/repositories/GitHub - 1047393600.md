# atman-33/double-click-image-opener

Opens an image in the system's default application when it is double-clicked inside Obsidian. The README states it works in Reading, Live Preview and Source view modes, supports common image formats such as PNG, JPG, GIF, WebP and SVG, and runs on Windows, macOS and Linux. A setting controls whether a notification is shown when an image opens.
