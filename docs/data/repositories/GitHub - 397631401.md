# phibr0/obsidian-tabout

Tabout is described by its README as a port of VSCode's Tabout: pressing Tab places the cursor next to the markup it currently sits inside instead of inserting indentation. A rule is added from the place it is needed — put the cursor in the environment, run the command that adds a rule for that environment, and enter the characters the cursor should jump to. The plugin is installed from the community plugins browser in Obsidian's settings.
