# taskscape/ObsidianUniqueFileName

This plugin renames the currently selected file to a unique name following a GUID pattern, which the README presents as a way of keeping file names unique and avoiding conflicts. The rename is invoked from a file's right-click menu through a Rename to GUID entry, turning a name such as My Note.md into one like 123e4567-e89b-12d3-a456-426614174000.md. The README states that Obsidian version 1.5.12 or higher is required.
