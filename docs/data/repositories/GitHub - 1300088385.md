# NoteNerdOfficial/cited

Cited answers a question about the vault and traces every claim to the exact file and excerpt that was read, aimed at researchers working from interviews, literature notes or primary sources. It runs the user's own `claude` CLI locally and read-only against the vault, so the README states that no external account is required and no vault content is sent to a third-party API. Citations are derived from the model's actual tool-call transcript, the read and search calls it ran and what they returned, rather than from the model reporting its sources in prose, which the README says makes a fabricated citation structurally impossible. A chat panel and a sources panel work together, folder scoping narrows a question to one project's notes, and an export turns an answer into a footnoted note with a sources section.
