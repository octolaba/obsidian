# xxinjie21/Smart-Quiz-Tutor

Smart Question Tutor generates quiz questions from Markdown notes using a local Ollama model or any OpenAI-compatible endpoint configured by base URL, model, key and temperature. Five question types are recorded — single choice, multiple choice, true or false, fill-in-the-blank and short answer — with per-type counts, batch runs over several files, automatically extracted knowledge tags written as wikilinks so results appear in the graph view, and whole-exam extraction that chunks large files with overlap and keeps existing answers while generating missing ones. Answering mode grades objective questions instantly with the correct answer and an explanation, feeds wrong answers into an SM-2 review loop, and the plugin exports to Markdown, Word or PDF.
