# ravenwits/obsidian-ai-summarize

This plugin summarizes Obsidian notes with OpenAI models, working from a selection or the whole active note and streaming selection summaries into the editor as they are generated. Large selections are chunked and recombined into one summary, long operations report progress and can be cancelled, and the list of available models is refreshed on demand. The README documents one-off presets in the right-click menu — concise or detailed summaries, bullet points, action items, study and meeting notes, review questions, flashcards, and open loops or unresolved decisions — alongside output destinations such as replacing the selection, plus frontmatter summaries, daily-note output, linked-note context and folder-level digests.
