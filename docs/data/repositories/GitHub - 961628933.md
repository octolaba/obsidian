# Maws7140/obsidian-storyteller-suite

Storyteller Suite covers planning stories, worldbuilding, running campaign sessions, managing timelines and compiling manuscripts without leaving an Obsidian vault. Its timeline offers a standard and a Gantt mode, grouping by character, location, group or a custom track, dependency arrows, progress overlays, milestone filtering, event search, tracks, eras, forks and conflict detection, and it can watch ordinary notes through a property or a tag. A campaign view holds session notes, a party tracker with hit point controls and conditions, a shared inventory with ownership and use effects, and branch-aware scene running; compilation ships preset outputs for reader and editor drafts, synopsis, print, plain text and HTML, saved custom workflows, a workflow editor and custom JavaScript steps.
