# clingfei/advanced-search

Obsidian plugin that extends the built-in Search view with VS Code-like controls: a `W` toggle for whole-word matching, a `.*` toggle for regular expressions, and Files to include and Files to exclude inputs under the search box. An include or exclude value without glob characters resolves to an existing file or to every file under an existing folder, a name-only value expands to both, a trailing slash forces folder-only matching and a full path forces file-only matching. The README states the plugin reads only paths and file contents in the active vault through Obsidian's vault APIs, which is what triggers the Vault Enumeration disclosure, and that it makes no network requests.
