# mgcsysinfcat/Ink-Buddy

Ink Buddy is an Obsidian plugin that tracks writing-session statistics and shows a floating emoji mascot in the corner of the editor. The mascot changes state with typing speed and idleness, moving through sleeping, thinking, writing, flowing, burning and exploding. Alongside it the plugin reports words written in the current session, session duration and a real-time words-per-hour figure, and it resets those statistics when the active file changes so each document is tracked on its own.
