# ibrh96-prog/literature-review-synthesizer

Obsidian plugin that synthesizes academic reading notes into literature review outputs with a language model. Sources are selected by folder or tag, and the plugin produces a thematic synthesis across them, with a methodological comparison matrix, a research gap analysis and a draft review section offered as paid features; results are saved as new notes carrying frontmatter, backlinks and timestamps. It works under a bring-your-own-key model against OpenAI, Anthropic or any OpenAI-compatible endpoint including OpenRouter and Ollama. The README states that the key is stored locally, that note content goes directly to the chosen provider, and that nothing is routed through a server belonging to the plugin's developer.
