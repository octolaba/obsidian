# Saktawdi/obsidian-last-position

The repository holds Last Position, an Obsidian plugin that saves and restores the scroll position of a Markdown note per tab, across editing and reading modes, split panes and several tabs on one file. Its README records that heading and block anchors take precedence, so following such a link is not overridden by a stored position, and it documents a command that jumps back to the saved position at any time. Named position bookmarks can be saved, searched and deleted, with a numeric suffix added to a repeated name, and the status bar shows the current height while offering the bookmark list. Further recorded settings cover fixed and adaptive restore delays with retry limits, a table of stored positions with paging, deletion, JSON import and export and automatic cleanup, an interface in Chinese and English, and Obsidian 1.8.0 as the minimum version.
