# yuanzhixiang/obsidian-theme-quietus

Quietus is a minimalist Obsidian theme focused on clean typography and smooth interactions. Its listed features are a minimalist interface with accent color customization, uniform header sizes with H1 to H6 prefix indicators, auto-centered images with hover effects and a maximum height, internal links carrying an arrow prefix and highlighted on hover, custom checkboxes, unobtrusive scrollbars, and support for both dark and light mode. The accent color is changed by modifying a CSS variable in theme.css, and the theme is released under the MIT License.
