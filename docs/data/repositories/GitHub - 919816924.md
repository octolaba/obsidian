# tbergeron/obsidian-nldates-redux

Natural Language Dates Redux is an Obsidian plugin for writing dates and date links in natural language, based on argenos/nldates-obsidian. Typing an at-sign followed by an expression such as today and pressing Enter expands it into the corresponding date link inline in the editor, and holding Shift keeps the typed text as the link's alias; when a date is not recognized no link is created. It also registers an nldates Obsidian URI action that opens a daily note from a natural-language day parameter, with a parameter controlling whether it opens in a new pane, and it adds commands including a date picker, whose hotkeys are unset by default.
