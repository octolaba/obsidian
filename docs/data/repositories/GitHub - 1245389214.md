# ScepticalOrange/homework-for-life

Homework for Life is an Obsidian plugin for capturing the story-worthy moments of a day, following Matthew Dicks' method of the same name, and appending them to a single monthly Markdown file. The README records a ribbon icon, a command and a URI that each open a modal with a multi-line text area taking one moment per line, with several captures on the same day merged into that day's row or heading. Two output formats are recorded — a table close to the original spreadsheet, and headings with bullets — chosen per vault, with existing files keeping the format they were created in; the date is always written as a dated wikilink that resolves to a daily note. Settings record the folder, a filename pattern with year, month and quarter tokens, append position and a multi-moment separator, and the README suggests OS-level reminders that open the capture URI.
