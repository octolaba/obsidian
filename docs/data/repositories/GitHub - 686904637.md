# ptournet/obsidian-html-tabs

Renders a tabs code block as a tab control in a note, where each tab is introduced by a marker line carrying its label and everything below it is that tab's content. Labels are plain text while content accepts full Obsidian Markdown, including embedded notes and fenced code blocks; the README warns that the fence characters used for the tabs block must differ from those used for code blocks inside it. Appearance is changed by overriding the plugin's CSS classes from a snippet, since there are no styling settings.
