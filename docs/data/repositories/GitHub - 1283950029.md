# 0libote/SourceDown

SourceDown imports documents into Obsidian using Microsoft MarkItDown, converting PDFs, Office documents, Outlook messages, images, audio, web pages, YouTube transcripts, archives and text-based formats into Markdown notes. Files are imported from the ribbon, from the right-click menu on a vault attachment, or as a pasted web link, with embedded images saved beside the generated note and the source and conversion time preserved in note properties. Docling and Marker are optional alternative converters chosen per file, and the README records the plugin as desktop-only, requiring Obsidian 1.5 or newer and Python 3.10 or newer.
