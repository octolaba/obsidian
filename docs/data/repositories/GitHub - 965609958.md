# asibilia/obsidian-quick-emoji

Quick Emoji inserts emoji from within the Obsidian editor: typing a colon opens a picker, and emoji are searched by name or description with debounced input. The README records a choice of insertion format between native Unicode characters, visible in every view, and shortcodes, which it says render as emoji only in Live Preview and Reading modes but sync across platforms and suit version control, with shortcodes displayed in Source Mode and emoji elsewhere. A recent-emoji history of configurable length, favourites marked with a star, skin tone selection for emoji that support it, and on-demand loading of the emoji data are also recorded.
