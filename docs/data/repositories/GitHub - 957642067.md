# gasparschott/obsidian-mark-open-files

This plugin adds a marker to every File Explorer item that is currently open in the Obsidian workspace, which the README distinguishes from plugins designed to reveal the current tab in the explorer. One marker is added for each open instance of a file, clicking a marker makes the corresponding leaf active, and the settings position the marker before or after the file name or align it to the left or right side of the file explorer.
