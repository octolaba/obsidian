# yesjinu/StatusBarQuote

StatusBarQuote pins a chosen quote to Obsidian's status bar. Its README contrasts the plugin with a quote-of-the-day one: instead of a random quote it keeps a single quote the reader has picked for themselves, meant to stay relevant on every reading. The text is changed in the plugin's setting tab, and until then the status bar carries the author's own default quote.
