# noonesimg/obsidian-audio-player

Obsidian plugin providing an audio player with bookmarks, added to a note through a code block. One audio instance serves the whole vault and keeps playing after its tab is closed, a wave visualiser is drawn for the file, and two commands from the command menu pause and resume whatever is playing. Bookmarks are added either by double-clicking a bar of the visualiser and typing a label, or as text, and clicking a bookmark's timecode sets the playhead position.
