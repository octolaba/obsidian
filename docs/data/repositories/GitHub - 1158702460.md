# ryanbbrown/obsidian-drift

Drift shows a side-by-side diff inside Obsidian when a Markdown file in the vault is changed by something outside the editor, such as an AI coding agent, a sync service or a script. The README states that detection uses CodeMirror 6 transaction monitoring rather than polling, that each diff chunk carries its own revert button beside bulk accept-all and reject-all actions, and that unchanged regions collapse. Pending diffs survive a restart and stale ones are discarded on reload, and editing a file that still has pending diffs raises a warning modal.
