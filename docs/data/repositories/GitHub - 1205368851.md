# casungo/relation-sync-plugin

Maintains bidirectional relationships between notes in YAML frontmatter: adding a relation in one note writes the inverse relation into the target note. It ships with over fifty preconfigured relation pairs across family, romantic, professional and creative categories, accepts custom pairs, and handles both a single link and an array of links. A bulk tool scans and synchronises the whole vault at once, and the settings interface is grouped, searchable and filterable, with the plugin localized into eight languages.
