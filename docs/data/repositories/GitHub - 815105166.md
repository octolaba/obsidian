# mfarr/obsidian-archive

Simple Archiver moves a file or a whole folder into a configured archive folder, keeping the same relative path there, and can move archived items back out to their original location. Both directions are reachable as commands or as file-menu and multi-file-menu entries. An auto-archive feature defines rules that periodically move matching files into the archive: each rule targets a folder, optionally matched by regex, may apply recursively, and requires at least one condition based on days since last modification or a filename regex, with several conditions combined using AND or OR. Rules run on a schedule that defaults to every 60 minutes, the last run time is saved so a catch-up run can happen at startup after a configurable delay, and files already inside the archive folder are skipped.
