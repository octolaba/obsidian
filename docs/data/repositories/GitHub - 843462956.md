# MikeBirdTech/obsidian-open-interpreter

This plugin integrates Open Interpreter with Obsidian, so that automations described in natural language can be run over the vault. It provides a chat interface, checks whether Open Interpreter is installed and guides the user through installing it, and has read, write and edit access to the vault's Markdown files. The README states that user approval is always required before an action is executed.
