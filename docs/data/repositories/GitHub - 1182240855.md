# tobocop2/obsidian-lilbee

Obsidian plugin that runs the lilbee engine against a vault to give it chat, a web crawler that saves sites into the vault, an auto-generated wiki, click-to-source citations and a model catalog. Its built-in manager downloads and runs the server and the local models itself, with nothing installed separately, and it can instead use an existing Ollama or LM Studio installation or cloud models. The README states that everything runs on the user's own computer and that cloud models are opt-in per role, and its topics present the plugin as a self-hosted alternative to hosted document-chat services.
