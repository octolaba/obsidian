# tobocop2/obsidian-lilbee

lilbee runs a local AI stack inside Obsidian, managing a server and models for vault search and question answering. It provides cited answers from notes, PDFs, and code, a web crawler that saves sites, an autogenerated wiki, and optional Ollama, LM Studio, or cloud-model integrations.
