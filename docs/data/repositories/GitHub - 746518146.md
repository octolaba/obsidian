# hokim-m/click-up-x-obsidian

This plugin connects an Obsidian vault to a ClickUp workspace, synchronizing workspace lists and tasks as notes, viewing tasks inside notes and creating a task from a note. Setup runs through a ClickUp sign-in: the plugin icon redirects to ClickUp, granting permission returns a code that is pasted into the settings, and a sign-in button completes the connection. The settings then select the workspace to synchronize and a default list, and text selected in a note can be turned into a task with a hotkey. The README states that the plugin is in a beta stage and updated regularly.
