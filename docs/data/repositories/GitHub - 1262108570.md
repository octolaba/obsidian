# kuaile1407/html-viewer-plus

HTML Viewer Plus previews and embeds HTML and MHTML files inside an Obsidian vault. An embed renders the file inline, and its target can be narrowed to a single element by id or sized by width or width and height through the embed's pipe syntax; `.mht` and `.mhtml` web archives open directly. The view offers fullscreen, opening in the system browser, zooming with Ctrl and the scroll wheel, in-page text search, a scroll guard that requires a click before scrolling, and automatic reloading when the file changes on disk. It follows Obsidian's dark mode with custom CSS support, and a right-click menu copies the embed or link syntax for an HTML file.
