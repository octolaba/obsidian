# Puhhh/chess-pgn-obsidian

This repository holds Chess PGN Viewer, an Obsidian plugin that renders interactive games and static positions inside a fenced chess code block. It parses PGN with mainline moves and nested variations, renders FEN positions, and displays comments, board annotations from square and arrow markers, and move glyphs derived from PGN NAGs. The board is navigated by previous and next controls, the keyboard, or dragging pieces; circles and arrows can be drawn with the right mouse button and saved back into the PGN, and the notation is laid out in a compact study style with clickable moves. The README also records rendering limits that guard against oversized blocks and very large PGN trees.
