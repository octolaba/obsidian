# flash555588/ai-model-workbench

Obsidian plugin that renders 3D assets in local WebGL viewports, annotates key parts and turns models into linked notes. GLB, GLTF, STL, OBJ and PLY are previewed directly, with Babylon.js as the default compatibility mode and Three.js available as an explicit opt-in, while the `3dgrid` multi-model view and SPLAT stay on the Babylon.js path. CAD, FBX, 3MF and DAE assets are handled by optional conversion rather than direct rendering. The README warns that STEP support is conversion-only, requiring desktop Obsidian plus a locally configured Python with CadQuery or OCCT, that mobile cannot run that conversion, and that large assemblies may be slow on first open or fail when the local CAD environment is missing.
