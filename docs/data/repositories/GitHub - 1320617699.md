# clivoa/esql-syntax

ESQL Syntax registers the ES|QL query language with Obsidian's native code-block highlighter, so a fence tagged esql is coloured in Reading view, Live Preview and source mode on desktop and mobile, using the theme's own code variables. Highlighting covers source and processing commands, functions, fields and quoted identifiers, strings and comments, literals and parameters, and operators. The plugin only registers language definitions: it renders no content itself, makes no network requests, reads no vault files and executes nothing, and the three query files it ships are templates that are highlighted rather than run.
