# LeMathMath/Obsidian_MM-Clean-Links

Changes how links behave in Live Preview so they can be edited without being activated: a single click places the cursor and a double click selects the whole phrase between the brackets, for internal links, external links or raw URLs as configured. A second feature reformats the titles of external links consistently, with an assigned hotkey toggling between sentence case and Associated Press style across the current note or the whole vault. Both behaviours have settings, including a third formatting option that ships with a warning.
