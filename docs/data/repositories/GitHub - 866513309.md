# JeanJean-rxl/random-retrieval-plugin

This plugin opens a random note selected by local language models, combining Obsidian's Random Note idea with a retrieval component from Haystack, which the author describes as working like a fuzzy search or half-random note. The README states that only macOS is supported so far, that a conda environment and the listed Python requirements are installed once, and that a terminal is opened automatically when the plugin is activated and must stay open while it runs, with a ribbon button triggering retrieval. Its version history records a configurable number of new pages, three by default, ranked by the retriever, and added Chinese support, while more platforms, multi-language support and speed are listed as future plans.
