# Benature/obsidian-automation

Obsidian plugin that listens to specific events and triggers commands available in the command palette in response to them. The README notes that using Quick Add commands requires enabling that plugin's own icon setting first. Installation is documented through the BRAT beta-plugin installer or by copying the release files into the vault's plugins folder.
