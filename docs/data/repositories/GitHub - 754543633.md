# webceoboy/mxmind-obsidian

This repository holds an Obsidian plugin that integrates Mxmind, a mind map editor, into the app. A Markdown file can be opened as a mind map from its context menu, the mind map view's image can be copied and inserted back into a note, and the editor is reachable from an entry in the left sidebar. The README states that the plugin uses the remote mxmind.com service and that some features, such as saving and syncing a mind map file, require an account there.
