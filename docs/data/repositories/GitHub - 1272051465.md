# DS-argus/vim-reading-nav

Brings vim-style scrolling to Obsidian's reading mode, where the rendered HTML has no editor and the built-in vim bindings therefore do nothing: j and k scroll one line, Ctrl+D or d half a page down, Ctrl+U or u half a page up, gg and G jump to the ends. Scrolling sets the scroll position directly with no animation so held keys repeat without queuing lag, and switching back to source mode corrects the cursor to match what was on screen. Pressing f enters a link-hint mode that labels every visible link; typing a label focuses that link, showing Obsidian's hover preview for internal ones, Enter follows it and Esc cancels. The keys are active only in reading mode with Obsidian's vim key bindings enabled, and the plugin is presented as a fork of an earlier vim-scrolling plugin published with the original author's approval.
