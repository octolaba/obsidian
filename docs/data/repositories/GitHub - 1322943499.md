# wgg2bhccq2-afk/obsidian-mark-and-link

Mark & Link converts a text selection into an Obsidian internal link, and when nothing is selected it targets the single word under the cursor instead. The command is bound by default to Shift with Ctrl or Cmd and E, and that binding can be changed in Obsidian's hotkey settings. It adds only the link brackets, leaving other markup such as highlight markers untouched, and the current release is installed by copying its files into the vault plugin folder.
