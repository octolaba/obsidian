# viggomeesters/obsidian-xml-viewer

Opens `.xml` files in a dedicated read-only Obsidian view, showing a tree by default and a source view with line numbers and light syntax highlighting. Nodes filter by element name, attribute name or value, text, comments and CDATA, and the tree reports element names, attributes, namespace prefixes, child counts, text previews and node paths, rendering comments, CDATA, processing instructions, document type and text nodes distinctly. Malformed XML is reported without crashing while the source view stays available, and a cap of 10,000 rendered nodes keeps large files responsive, with the remainder counted in a warning area. The README states that the plugin never writes back to XML files, makes no network requests and does not use the system clipboard.
