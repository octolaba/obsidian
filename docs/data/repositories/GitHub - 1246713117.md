# totocaster/kanban-base-view-obsidian

Better Kanban Bases View adds a Kanban view to Obsidian Bases whose columns derive from the active Bases grouping and whose cards show each note's title plus the properties already selected in Bases, including formula values rendered with a formula icon. Sorting, grouping, filtering and property selection stay with the existing Bases controls, while the view adds draggable cards, keyboard reordering, optional plain-text or native page previews, exact or relative dates with overdue, today and tomorrow states, per-column soft work-in-progress limits, per-column accent colors, add-note buttons for writable grouped columns, and drag-and-drop column reordering. The README records Obsidian 1.10.2 or newer and states the plugin is not marked desktop-only.
