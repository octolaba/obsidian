# lukokaravan-cloud/karadigm

lukokaravan-cloud/karadigm holds Karadigm, a nearly monochromatic Obsidian theme whose backgrounds, text and borders sit in shades of grey. Callouts carry a subtle coloured left border, and the theme defines 24 unified task checkboxes together with five circular progress indicators. The accent colour is chosen through the Style Settings plugin, either from the Blue, Green and Red presets or as a custom colour.
