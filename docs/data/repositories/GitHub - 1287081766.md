# raulanatol/obsidian-contact-forge

The repository holds Contact Forge, an Obsidian plugin that treats the vault as the source of truth for contacts and pushes a chosen subset one way into a dedicated macOS Contacts group, alerting when the two sides drift apart. Settings choose the contacts folder, the target Contacts group and which fields are managed; a sync report lists the desync alerts of each run with click-through actions, and a summary modal asks for confirmation before anything is written. The README states that the plugin is macOS desktop only because it drives Contacts through osascript, that nothing leaves the device, and that it deliberately inverts the usual direction of contact plugins, which import into the vault.
