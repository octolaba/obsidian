# Fleker/letterboxd-for-obsidian

Letterboxd for Obsidian is described as syncing a Letterboxd diary into Obsidian. Its README says a command fetches the diary and writes it as a bulleted list into a note called Letterboxd Diary, each entry recording the rating and film as a link and the viewing date as a date-specific backlink. Because Letterboxd's API is restrictive the plugin reads the public RSS feed instead, which the README says limits a fetch to the last fifty films, though later runs keep merging new entries into the existing file.
