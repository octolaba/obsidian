# benjaminezequiel/playground-theme

Playground is a minimalist and slightly modified Obsidian theme focused on visual hierarchy and clean typography. Its key features are gradient-coloured headers running from purple to orange, callouts with custom styling, aligned task lists and bullet points, modern typography and high contrast colors, with support for desktop and mobile alike. The README marks the theme as a work in progress, with further customization planned through cssClasses, including Dataview tables and Tasks plugin styling such as custom task statuses and query visualization.
