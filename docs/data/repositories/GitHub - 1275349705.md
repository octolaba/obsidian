# TzadikimBIU/lotus

lotus executes ordinary fenced Markdown code blocks in Obsidian, adding execution controls to a block and rendering transient output beneath it instead of rewriting the source into a plugin-specific format. A block counts as executable when its fence language resolves to a supported alias, and each block gets an identifier derived from the vault-relative path, its ordinal, the normalized language and a hash of its content, so rerunning updates the existing output panel rather than appending another. The README warns that code runs locally without sandboxing by default, behind a consent modal, and points at execution groups that run code in Docker or Podman containers or over SSH or QEMU. It records the plugin as desktop-only and free of telemetry, ads and a self-updater.
