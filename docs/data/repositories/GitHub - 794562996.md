# levi-ivel/MostUsed

MostUsed is an Obsidian plugin that collects the hundred most common words across all notes in a vault and shows them in a graph view, opened from a ribbon icon or the Show Most Used Words Graph command. Its settings exclude chosen words and limit the scope of the scan. The settings tab also shows the full list of words present in the vault, which can be copied or exported as a .txt or .json file, and the README notes that the graph must be used once before that list becomes available.
