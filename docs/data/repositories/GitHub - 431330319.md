# caronchen/obsidian-calibre-plugin

Obsidian plugin for the calibre Content server that lets a reader open calibre libraries and read books inside Obsidian. Clicking its ribbon icon opens a workspace view containing an iframe connected to the content server, whose address is set in the plugin settings; opening more panes allows several books at once and note-taking while reading. The README walks through starting the Content server from calibre, changing the server port on either side, and installing the plugin manually by copying its release files.
