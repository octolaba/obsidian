# anselmopinheiro/lina

Lina is described as an AI-powered Obsidian plugin for semantic search, note organisation and knowledge workflows, and its README marks the project as alpha and under active development. It builds a local text index under .lina/, splitting notes into overlapping chunks with configurable path exclusions, and the README states that the first index is never built automatically: it must be created from the panel or the rebuild command, with automatic updates running only once a valid index exists. Rebuilds run in background batches with progress and a cancel action, preserving the previous valid index on cancellation or error. The README also records mobile constraints on Android, including a binary shadow copy of the embeddings generated on desktop and a no-safe-source state that falls back to text search.
