# anselmopinheiro/lina

Lina is an alpha Obsidian note assistant centered on local indexing, text and semantic search, and optional AI analysis. It maintains a chunked text index, supports hybrid ranking with text-only fallback, and exposes persistent sidebar results that open notes directly. On Android it can use a validated binary embedding shadow copy and preserves text search when no safe embedding source is available.
