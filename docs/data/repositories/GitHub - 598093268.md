# FrancescoDiCursi/Mermaid.js-Helper-OMH-plugin

Mermaid.js Helper is an Obsidian plugin offering commands for Mermaid graph and flowchart blocks plus a few unrelated extras. Its Mermaid commands clean up a selected graph or flowchart cell by moving variable declarations to the top, and expand a selected style or class row whose id is given as a regular expression pattern. The extra commands create empty files from a selected list of titles, create files from selected sections using their second-level headings as titles, copy the global graph view's colour groups into a local graph, and turn a list separated by line breaks or commas into a list of wikilinks.
