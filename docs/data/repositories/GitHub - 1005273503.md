# blueheron786/obsidian-stats-plugin

This repository holds an Obsidian plugin whose description calls it a plugin with some simple statistics. The README states that it exposes two global functions callable from DataviewJS or other scripts: one returns a Markdown summary of vault note count, word count, links and tags, and the other returns a Markdown list of the most recently modified notes, taking an item count and a folder to exclude.
