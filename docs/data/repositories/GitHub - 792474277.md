# MizarZh/mathlive-in-editor-mode

MathLive in Editor Mode brings MathLive input into Obsidian's editor mode, where an equation is edited in a MathLive block below the LaTeX display block, and the block's display can be toggled globally, per block or inline. The README records macro, shortcut and keybinding support, switching between MathLive and the built-in MathJax, and placing an inline MathLive field before or after the source equation. It states that macros set for MathLive are not available in built-in MathJax blocks, that the right-hand inline position uses an experimental focus-preservation path, that input on tablets and phones is a known issue, and that the plugin relies on non-public APIs.
