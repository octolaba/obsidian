# lizard-heart/obsidian-order-list-plugin

Order List adds an Order selected list command that sorts the selected list by the number written at the end of each item. It works on lists with or without bullet points, moves sub-items along with the top-level item they belong to, and orders correctly when the trailing numbers are not integers. The command is meant to be reached through a hotkey assigned to it.
