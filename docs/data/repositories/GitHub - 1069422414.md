# itsonlyjames/obsidian-sync-folds

Sync Folds stores Obsidian fold states in the plugin's data.json inside the vault instead of localStorage, where Obsidian keeps them and from where they do not travel between devices. The README describes the lifecycle: on load the saved states are imported into localStorage, or the current localStorage state is exported when nothing is saved yet; folding changes are written back with a 150 ms debounce; and settings changed externally are detected and applied. Two commands export and import fold states manually, and the data file travels through whichever mechanism already syncs the vault.
