# Ssentiago/obsidian-openapi-renderer

OpenAPI Renderer brings the management of OpenAPI specifications into Obsidian. Specifications are edited and viewed through Swagger UI without leaving the vault, and the plugin keeps versions that can be created, viewed, restored and deleted, together with a view listing every tracked specification. The author's stated motivation was writing API documentation in Obsidian instead of switching between applications.
