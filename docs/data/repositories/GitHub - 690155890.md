# b-camphart/timeline-view

Timeline View displays notes on a timeline or number line ordered by a numeric property of the reader's choosing, defaulting to the creation time, and several views can be open at once with a different property each. A second property can be read as either a length or an end value, and items can be resized directly in the view. Double-clicking creates a new note whose property value is set from the clicked position, notes can be dragged with multi-select support to change their values, and the view can be narrowed with Obsidian's search syntax and coloured by group query in the manner of the graph view.
