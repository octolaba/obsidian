# MihailGusev/hotkey-capture

The repository holds an Obsidian plugin for capturing key presses and inserting them into a note as text. The README describes assigning a hotkey that enters capture mode, which can also be started from the command palette; the keys pressed are then shown in the status bar, and Esc — reconfigurable in settings — ends capture and inserts the result at the cursor. Recorded support covers the Ctrl, Alt, Shift and Win modifiers, comma-separated key sequences, and readable names for special keys such as Space, Enter and the arrows.
