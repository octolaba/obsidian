# DXShelley/ai-translate

This repository holds a multi-platform dictionary and selected-text translation toolkit whose packages include an Obsidian plugin alongside Chrome, Edge, Firefox and VS Code extensions, all sharing the same vocabulary request behaviour and released under a single version that must match across every platform. In Obsidian the plugin looks up English words, translates selected note text, and can optionally save vocabulary. Word lookup returns phonetics, definitions, examples, synonyms, antonyms and pronunciation, several OpenAI-compatible model profiles can be configured with priority-based fallback, and direction is either detected automatically between Chinese and English or set explicitly.
