# mrowa44/obsidian-ia-writer

This repository holds an Obsidian theme inspired by iA Writer, described as making Obsidian nice to think in. Its README documents installation from the appearance settings and a set of optional settings, namely a specific accent colour, the tab title bar turned off, the translucent window turned on and indentation guides turned off in the editor. It also suggests the Hider plugin for hiding interface elements, and names the Focus Active Sentence and Natural Language Syntax Highlighting plugins as related.
