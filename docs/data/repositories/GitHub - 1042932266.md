# LunarWatcher/obsidian-webdav-sync

Obsidian sync plugin that stores a vault on a WebDAV server the user brings themselves, using only standard WebDAV so it is not tied to one server implementation such as NextCloud. Sync is deliberately manual and there is no content-level merge: conflicts are handled at file level and resolved by hand, and the README states the plugin is a poor fit for anyone who repeatedly edits the same file without pulling first. It can cover the whole vault or selected folders, includes the configuration folder by default with an option to exclude it, and its author supports Android, Windows and Linux only.
