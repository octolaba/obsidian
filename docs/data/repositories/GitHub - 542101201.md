# kaminono/obsidian-to-flomo

Share to Flomo sends content from Obsidian to Flomo, either the whole file or the currently selected text. Later versions added an editor menu entry and commands that send each selected line or each selected paragraph individually. The README states that the Flomo API is a paid membership feature, so an account with that membership is required first.
