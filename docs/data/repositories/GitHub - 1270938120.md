# fab34/GeoCapture

Inserts place information into the note being written — travel journals, check-in logs, restaurant notes and photo-based trip reviews — rather than acting as a full map workspace. Commands insert the current device coordinates, search a place by name through OpenStreetMap Nominatim or Google Places, list nearby candidates, parse coordinates or map links from the clipboard, and read EXIF GPS from a nearby JPEG in the note to suggest places. Photo coordinates are cached locally after a successful lookup, with fallbacks to another plugin's image metadata cache or to manual entry when the image or its metadata is unavailable. Snippets are inserted as compact text, a callout, a table row, a travel or restaurant note, a photo caption or a custom template, with Google, Apple or OpenStreetMap map links, and the interface follows the system language unless overridden.
