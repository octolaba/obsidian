# ozephyr-ctrl/csv-quiz-practice

CSV Quiz Practice reads a BOM-prefixed UTF-8 question bank and provides an Obsidian panel for answering, filtering, tagging, and tracking accuracy. It supports randomized questions and options, random and FSRS memory practice, cascading category filters, editable flags, automatic CSV saving, session-aware statistics, and selective progress resets.
