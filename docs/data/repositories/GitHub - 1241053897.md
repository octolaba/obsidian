# Evgene-Kopylov/linux-image-rendering-fix

Obsidian plugin that works around image loading failures on Linux, in particular on Ubuntu and its derivatives. The README attributes the failures to an upstream Electron and Chromium problem with two parts: the internal protocol Obsidian serves local files through cannot resolve paths containing non-ASCII characters such as emoji, diacritics, Cyrillic or CJK, and some Linux Electron builds lack PNG, JPEG and WebP codecs. The plugin intercepts Markdown rendering, finds the image elements, reads each file directly from disk through the vault adapter and replaces the source with a blob URL, bypassing that protocol. PNG, JPEG, GIF, WebP, SVG and BMP files are handled, automatically when a page is opened.
