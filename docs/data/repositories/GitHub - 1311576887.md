# SETIX-A/obsidian-time-canvas

Time Canvas surfaces notes written on the same month and day in previous years as collapsible cards in an Obsidian sidebar. The README records year groups with the currently open note pinned to the top of its group, a choice between an outline view showing headings only and a snippet view showing a content preview, and a date source chosen from a created field, a date field or a custom frontmatter field with a fallback to the file creation time. It also records following the active note, showing selected frontmatter properties on each card, excluding folders from the history search, appearance settings for font sizes, colours, card backgrounds and hover effects, and a bilingual Chinese and English interface.
