# kimsunin/obsidian-live-pdf-preview

Live PDF Preview is described as a real-time PDF preview and export plugin. Its README says the sidebar renders the edited Markdown continuously as a print-formatted page in sizes such as A4, Letter and A3, scales the preview to the panel width, and scrolls to follow the cursor position in the editor. Content that overflows a page boundary — paragraphs, lists, tables and code blocks — is split onto the next page, with list numbering continued across the break, and layout commands written on their own lines control page breaks and multi-column sections. Export produces a PDF carrying interactive navigation bookmarks.
