# JosefBelzer/Copilot-Personal

The repository holds Copilot Personal, an Obsidian assistant plugin offering streaming multimodal chat, semantic retrieval over the vault, an autonomous agent mode with seventeen tools, PDF processing, web search and fallback across eleven model providers. The README records a free tier limited to basic chat with the user's own API key and three tools, and a paid tier unlocking agent mode, web search, semantic retrieval, PDF image extraction and multi-provider fallback, whose licence key is validated against a hosted worker; it states that no telemetry or analytics are collected. It also lists translations into twelve languages, a test suite of 385 tests and separate store and obfuscated builds.
