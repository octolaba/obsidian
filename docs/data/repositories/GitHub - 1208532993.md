# rekby/obsidian-video-notes

Video Notes is an offline-only Obsidian plugin for taking notes on video files that already live in the vault, with the README stating that every online feature of its inspiration was left out — no YouTube, no streaming and no network calls. It provides a video panel that plays any vault video, insertion of a human-readable timestamp link at the current position, and clicking such a link opens the panel, jumps to that second and pauses so the frame can be inspected. A screenshot of the current frame can be saved as PNG into the configured attachments folder with its timestamp link, a configurable pre-roll offset takes the timestamp a few seconds before the click, and playback commands cover play, pause and stepped seeking.
