# mikeddy/obsidian-copy-selected-name

The repository holds Copy Selected Name, a desktop-only Obsidian plugin that turns files or folders selected in the file explorer into mention-style filename references for pasting into AI chat plugins such as Claudian or Codex. One hotkey writes those references into the plugin's own internal clipboard, which the README says does not overwrite the system clipboard, while a second hotkey copies the real disk path of the selection to the system clipboard and appends to the previous path when pressed twice. It also converts between the plain filename form and the obsidian protocol URL form, and offers panels for clipboard content, overwrite or append prompts, and history editing.
