# phibr0/obsidian-go-to-line

The repository holds Obsidian Go To Line, a plugin adding commands that move the cursor to a given line and character. Its README records a command that opens a text field accepting either a line number or a line and column pair, a command that takes the same information from the clipboard and does nothing when the clipboard does not hold valid position data, and a command that copies the current line number. Multiple cursors are recorded as a comma-separated list of positions, and both separators can be changed in the plugin's settings.
