# ValleytheKnight/Canvas-Positioning-Toolkit

Auto-arranges and repositions cards on an Obsidian Canvas board. The README states the plugin only touches a card's x, y, width and height on the active board and never file content or anything outside a Canvas, working through three calls: reading a position from canvas.nodes, writing a new one with node.setData(), and reporting the move with canvas.markMoved() so undo history and the on-disk save stay consistent. Auto-layout arranges the whole board when nothing is selected and only the selection when two or more cards are chosen. The author states this API was confirmed by reading how the Advanced Canvas plugin uses the same objects, and that this plugin does not depend on it.
