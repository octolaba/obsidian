# frostmute/make-it-rain

Make It Rain pulls Raindrop bookmarks, highlights and attachments into Obsidian as Markdown notes with metadata, folder structures and native file support. The README describes filtering which items are fetched, choosing where they are placed, and a template system with pre-configured templates for different content types and a nesting-aware parser for building custom ones. Its register is promotional, and this body restates only the capabilities that the text names.
