# Mara-Li/obsidian-regex-mark

Regex Mark adds custom CSS classes to text matched by regular expressions defined in its settings, pairing each expression with the class to apply; the matched content is also written into a data-content attribute on the generated span so styling can key off it. It can further define custom Markdown tags through an open and close expression pair, which with the hide option enabled mimics how Obsidian conceals its own markup — the delimiters are hidden until the text is selected, which reveals them again as with other markup. Named capture groups can carry sub-styles inside a mark. The README notes that the double-underscore form for underline works in live preview but not in reading mode.
