# AurelienStebe/Gladdis

This repository holds Gladdis, described upstream as an AI chatbot whose name expands to Generative Language Artificial Dedicated and Diligent Intelligence System. The README says the conversation window is any open Markdown file, with the streaming model response appended to it, and lists automatic transcription of linked audio files, automatic loading of linked text files, PDF and web page loading, images sent to vision-capable models, and named system prompts chosen from frontmatter. A demo vault is offered as a release download, and further capabilities are described as plans rather than current features.
