# jasperdevs/letterboxd-recent-films

Letterboxd Recent Films renders a public Letterboxd user's latest diary entries as one clickable poster collage inside a note, composed as a PNG in memory from the poster URLs in the RSS feed. A letterboxd-recent code block renders in Live Preview and Reading view and takes per-gallery options for username, entry count, gap, width, corner radius, heading, captions, refresh policy and timeout, or can be left empty to use the global settings. The collage picks its own grid, sizes itself automatically unless manual sizing is chosen with a slider or by dragging its corner, inherits the Obsidian theme, and shows title, year, rating and watched date on hover or focus. Usernames are validated against Letterboxd's documented rule, the last successful feed result stays available offline, and posters are not downloaded into the vault.
