# TsuKKi-is-dead/Tome

Tome searches books by ISBN or title across Open Library, Google Books and OpenAlex, downloads their covers into the vault and stores each book as a Markdown note. Metadata such as title, authors, ISBN, publisher, subjects, status, rating and progress is written as YAML properties so the library can be read by Dataview or Obsidian Bases, and the README describes both a built-in card gallery and a Bases Cards view that renders covers from the cover property. Provider order and per-provider toggles are configurable, note templates control which frontmatter fields and body layout are written, and requests retry with backoff, with an optional Google Books API key or OpenAlex contact email to raise the quota ceiling.
