# Telehakke/hanko

Hanko registers arbitrary pieces of text and pastes them back into a note. Text is registered by selecting it in edit mode and choosing Register from the right-click menu, and pasted by choosing Paste and picking one of the registered entries; the same operations are reachable from the command palette, from the ribbon menu and, on mobile, from the toolbar. Registered items are deleted and reordered in the plugin settings, where the cursor position after a paste is also set. The bilingual README warns that the plugin works in edit mode and not in preview mode, and that the cursor-moving paste does not work on mobile because the software keyboard closes when the paste menu opens.
