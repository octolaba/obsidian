# zafrem/obsidian-role-switch

Supports deliberate switching between work roles such as developer, writer, researcher or QA, and tracks the time spent in each. Roles are user-defined with a color and a letter icon, transitions can be delayed with configurable messages about context switching, and a minimum session duration is meant to discourage task-jumping. The active role is signalled through the status bar, workspace borders and colored UI, while a side panel and a dashboard show live timers plus daily, weekly and monthly statistics.
