# mizu1/obsidian-languageLearnCopilot

Obsidian plugin providing AI-assisted language learning: selecting a word or phrase and running an analyze action writes a structured note carrying part of speech and meaning, pronunciation, morphology, derived meanings with their evolution and example sentences in context. Known words are highlighted across all notes, hovering one shows a popup with meaning, etymology and examples, and a reinterpret action compares an existing note with the current context and can update it. A chat panel in the sidebar supports streaming, conversation history saved into its own folder and file browsing, and a relation graph derives synonym, antonym and cognate links between collected words through a per-word flag queue. The user supplies an API key and chooses a model in the settings.
