# bobstanton/places-photon

A search provider for the Places plugin backed by Photon, which searches OpenStreetMap data. It resolves a search term to place suggestions with coordinates, and resolves a coordinate back to the nearest named feature. All requests go to the Photon service, no background tasks run, and its map, overlay and routing code comes from places-shared.
