# speze88/obsidian-caldav-sync

This repository holds an Obsidian plugin that synchronises Markdown tasks bidirectionally with a CalDAV server. Tasks are selected by a configured tag, several CalDAV calendars can be mapped to different tags, and synchronisation happens on file save rather than by background polling. Completions are pushed to the server while remote title and status changes are pulled back, and the task UID is stored in an HTML comment that stays invisible in reading view. The README states that it works with any CalDAV server supporting VTODO and names mailcow, SOGo, Nextcloud and Baikal as examples.
