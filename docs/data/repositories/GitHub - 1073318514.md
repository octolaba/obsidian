# wulflo/obsidian-3Sumaq

This repository holds an Obsidian theme built around the accent color picked in Obsidian's appearance settings, so headings and callouts take that color; the README says the theme colors were softened to reduce glare during long reading sessions. It adds hierarchical nested numbering, colorful highlights, a glow effect on lines carrying a flashcard tag, and a collage value in a note's cssclasses property that turns Dataview queries into a card view. The author records the theme as tested for personal use with possible plugin incompatibility, and credits the Minimal, Vicious and Prism themes together with the Cards and MultiColumn snippets.
