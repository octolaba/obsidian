# wulflo/obsidian-3Sumaq

Universitario is an Obsidian theme for users who want to choose an accent color and brightness while keeping a softened, low-glare interface. It adds colorful headings, callouts, highlights, a flashcard glow based on a tag, hierarchical numbering, and a cards-style option for Dataview queries through a note class.
