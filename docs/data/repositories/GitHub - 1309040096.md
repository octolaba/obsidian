# xooooooooox/obsidian-ribbon-organizer

Ribbon and Status Bar Organizer arranges Obsidian's left ribbon into named groups separated by a thin divider on desktop, tablet and phone, and lets ungrouped icons be tucked into a single overflow menu button. Icons can be hidden through one toggle that writes both Obsidian's native hide setting and Commander's hide list so the interfaces agree, and extra ribbon icons can be added as quick menus, each opening its own command list with editable labels and icons including Iconize packs. For the status bar it offers drag-to-reorder, per-item hiding, compact and icon-only display modes, rewrite rules that shorten noisy items, a live preview strip, and an optional floating pill that shows the status bar on phones and tablets. Configuration lives in the plugin's data.json, and a command copies a JSON diagnostics snapshot for issue reports.
