# subframe7536/obsidian-theme-maple

Maple is described as a theme for Obsidian on desktop and mobile, with components, animation and preferences customizable through the Style Settings plugin. Its README records that the theme embeds the author's own monospace font, Maple Mono, and that the older 0.x version remains available on a separate branch. The README states that backward compatibility is not guaranteed, and documents installation from the community themes store or by extracting the source into a maple folder under the vault's themes directory.
