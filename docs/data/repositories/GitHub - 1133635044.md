# clairefro/obsidian-plugin-napkin-notes

This repository holds Napkin Notes, an Obsidian plugin that groups handwritten notes, sketches and whiteboard photos into inline, PDF-style image carousels inside a note. Images are added through an Insert Napkin Notes command, either from the filesystem or by scanning a QR code to send them from a phone over Wi-Fi, and optional annotations make them searchable. The README records a responsive layout for desktop and mobile, light and dark mode support, and that the Obsidian mobile app offers only the filesystem method.
