# javajiang/image_plugin

An image plugin aimed at ecommerce teams that collects reference product images, distills their visual style, and generates new hero or detail images from a saved style. It works over fixed vault folders holding reference material, the distilled style library and the generated output. The README states that an API key obtained by topping up an account on an external service must be entered in the plugin settings before use.
