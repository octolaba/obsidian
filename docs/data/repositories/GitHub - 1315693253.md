# flowing-abyss/obsidian-local-fonts

Local Fonts loads font files from a folder in the vault and applies the families it finds to text, interface, monospace, heading and emoji roles. It reads TTF, OTF, WOFF and WOFF2 files including subfolders, takes family name, weight, style and script coverage from the file itself rather than the filename, and serves faces through resource URLs so only the weights a note displays are fetched. The emoji family is placed first in each stack but limited to emoji code points, and a hard-override option forces the chosen families on themes that set font-family directly. Diagnostics cards list each family's weights, script coverage, per-face format and size, and which face the plugin selected on the current device; it works on desktop and mobile and makes no network requests.
