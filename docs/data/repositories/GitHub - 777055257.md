# zhouhua/obsidian-popkit

PopKit provides a pop-up toolbar of built-in tools in the Obsidian editor, which the README describes as inspired by the Mac software PopClip. Selecting text in the editor makes the toolbar appear, and a show PopKit command invokes it manually, which can be bound to a shortcut key; the buttons are dynamic, so actions that need a selection are excluded when there is none. The README states that the plugin comes with dozens of tools, that the toolbar can also perform mathematical calculations, display date and time and count words, and that which tools it offers is chosen in the plugin settings.
