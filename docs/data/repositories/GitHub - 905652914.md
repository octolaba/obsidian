# MihailKovachev/shaahmaat-md

ShaahMaat-md renders chess positions inside Obsidian notes from a code block using the shaahmaat language. The block holds a headers section and a position section separated by a single empty line: each header sits on its own line as a name and value pair, the orientation and format headers are always required, and the position section carries either FEN or PGN according to the declared format. The orientation header chooses whether the board is seen from the white or the black player's side. The README further records support for square highlighting, for arrows used to show the main ideas in a position, and for customising the colours of squares, highlights and arrows, adding chess sets and setting each board's size individually.
