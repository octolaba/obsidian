# gnowgi/obsidian-nodebook

Renders nodeBook code blocks as interactive controlled-natural-language knowledge graphs inside a note: draggable concept maps with an inspector and morph switching, inferred relations with proof tooltips, a containment view, and Petri-net process notation whose tokens fire on click. The graph follows Obsidian's light and dark setting, and each block's graph instance is tied to the block's lifetime so re-renders and closed panes clean up. Node, relation and attribute types come from a schema note the plugin seeds with built-in definitions on first run, and can be extended there, by inline schema blocks, or by naming schema pages at the top of one graph, where a later definition of the same name wins. It is licensed AGPL-3.0-only and shares its renderer with a Logseq counterpart.
