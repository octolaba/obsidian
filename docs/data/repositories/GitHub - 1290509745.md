# israerusan/vault-triage

Vault Triage scans an Obsidian vault for the notes it judges worth reviewing and then works through them in a review queue rather than presenting a flat list of flags. It reports stale notes untouched longer than a configured threshold, thin notes with little substance, orphan notes without real connections in or out, notes missing required frontmatter properties, and unfinished drafts carrying markers such as TODO, FIXME, WIP or custom ones. The README describes it as local-first and privacy-friendly, and splits the feature set between a free tier covering scanning and one-note-at-a-time cleanup and a paid Pro tier adding saved audits, custom rules, bulk workflows, severity tuning and Markdown reports.
