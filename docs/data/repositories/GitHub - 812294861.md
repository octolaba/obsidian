# chitwan27/lineArrange

Line Arrange is described as a plugin for arranging lines. Its README divides the commands into line operations, which treat a selection as a flat list and ignore hierarchy, and block operations over paragraphs, lists or sections, which preserve heading and indentation structure. Both groups can sort by rendered visual width, sort lexically, shuffle, or reverse, with block sorting keeping nested items attached to their parent and acting independently at each indentation level. The README notes that blank lines inside a block selection are discarded.
