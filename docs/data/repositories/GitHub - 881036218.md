# friebetill/obsidian-share-as-zip

Share as ZIP collects the current note together with the notes it links to, recursively, and compresses them into a single zip file, prompting with a save dialog for its location. Binary files such as PDFs and images among the linked content are handled as binaries rather than as text. Exclusion rules configured in the plugin settings can skip notes carrying a given frontmatter key set to true, skip the content under specific headers when scanning for links, exclude entire directories and their subdirectories, and exclude individual files with wildcard patterns. The collection is started from a command in the palette.
