# SmetDenis/obsidian-frontmatter-date-manager

Frontmatter Date Manager updates created, updated, and viewed date properties in YAML frontmatter as notes are created, edited, or opened. It supports configurable formats and time zones, content hashing, file filters, change-detection modes, delays, bulk operations, and optional activity counts.
