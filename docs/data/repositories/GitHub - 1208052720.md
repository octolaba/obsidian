# SmetDenis/obsidian-frontmatter-date-manager

Maintains created, updated and viewed dates in YAML frontmatter as notes are edited. The updated field follows file modification and created is set on new files, an optional viewed field is stamped when a note is opened, and an optional counter records how often a note is edited so it can be sorted in Bases or Dataview. The date format uses date-fns syntax with IANA timezone autocomplete and string or number property types, and gitignore-style filter rules with preview and validation choose which files are affected. The README explains the design against sync tools that rewrite files without content changes and against template plugins that modify a file immediately after creating it, which is why content hashing and a configurable delay exist.
