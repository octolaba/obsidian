# codesplash-ai/codesplash-themes

Obsidian plugin for creating, managing and switching between custom color themes through a visual editor. The README describes a two-layer color system in which a palette of color variables is assigned to semantic interface elements, 22 editable built-in themes including Catppuccin, Dracula, Tokyo Night, Nord and Gruvbox, renaming of color variables with automatic reference updates, JSON import and export, live preview, and cycling between themes by command or hotkey.
