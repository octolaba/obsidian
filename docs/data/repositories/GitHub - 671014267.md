# joshua-martius/tagmany

TagMany adds the same tags to many Obsidian notes at once. The README records the flow: right-click the folder, choose the menu entry that tags all notes in it, enter the tags separated by commas, optionally tick a box to include subfolders, and submit. It states that using the plugin on the root directory and tagging canvases are not supported yet.
