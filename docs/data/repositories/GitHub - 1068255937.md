# davidvkimball/obsidian-seo

This repository is an Obsidian plugin that audits notes for search-engine and AI discoverability, described in its README as part of the Vault CMS project. The checks it lists cover content quality — length, reading level, keyword density, duplicate content, titles and descriptions — technical items such as title and meta description validation, keyword placement in title, description and filename, heading hierarchy, media alt text and image naming, and link handling for broken, potentially broken, external and naked links and broken embeds. Audits run over the current note or across configured directories vault-wide, with sorting, one-click navigation to a flagged file, caching and configurable thresholds.
