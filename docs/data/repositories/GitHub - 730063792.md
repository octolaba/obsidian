# cycsd/obsidian-card-note

Extracts a block of text into a new note and drops a link to it onto a canvas. The README describes dragging content from a note onto the Obsidian Canvas or an Excalidraw drawing, where dragging the first line takes the whole block, including foldable blocks and Markdown structures such as headings, paragraphs and bullet lists; a block can be extracted by creating a new note, by referencing it, or by cutting it. Clicking the resulting node can open the file in a split view. Commands cover switching automatic link creation on or off, the arrow style and default label of created links, the visibility of the drag symbol, the folder new files go to, and automatic preview.
