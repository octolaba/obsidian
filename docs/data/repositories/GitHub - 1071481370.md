# churnish/copy-link

The repository holds Copy Link, an Obsidian plugin that adds commands for copying links to files, headings and blocks. File-menu commands copy a note link using the shortest unique path, an embed, or the link wrapped as an inline footnote; editor commands add or find a block identifier and copy a block link, embed, footnote or bare anchor, handling multi-block selections by emitting one link per line. The README also records a command that builds an obsidian protocol URL for a block.
