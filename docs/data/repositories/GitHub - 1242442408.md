# nicolasassi/redline

Adds pull-request-style review comments to a document, anchored to a paragraph, heading, list item, image, code block, callout or table through Obsidian's native block reference markers so they survive edits. The comments themselves live in a sibling `.review.md` sidecar file, leaving the source document unchanged. The README describes the design as protocol-based: the sidecar format is documented plain Markdown and is not bound to any downstream tool, so a person, a script or an assistant can read the comments, edit the source, and flip each comment's status in the sidecar.
