# 397327/replace-memory

Replace Memory stores find-and-replace rules and runs all enabled rules of a page in order with one click, with separate named rule pages for different replacement needs. A context-menu action turns the current paragraph or several selected paragraphs into reusable block references, reusing existing block identifiers, and further actions paste the last copied reference or jump from an inserted reference back to its source. A scan reports the count and total size of images it can confidently classify as unused and moves them to the Obsidian trash after confirmation, keeping uncertain ones. Selected Markdown files can be exported as Markdown with their image attachments or as one continuous long-page PDF per note, and processing is stated to happen entirely locally.
