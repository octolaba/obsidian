# Ordnungen/ord-updater

ORDupdater keeps a note's frontmatter in step with where the note sits in the vault: it adds a tag taken from the parent folder name, wikilinks to every ancestor folder, and a creation date on first update plus a modification date on every change afterwards. It also writes Folder.md index files listing the subfolders and notes of each folder. Updates run automatically on create, edit and rename, or on demand from a ribbon icon, a folder's context menu, or commands for the whole vault or the current file, with files processed in batches and hidden folders and index files skipped. Optional settings lock the property editor, rename files and folders containing spaces, and strip non-standard frontmatter fields, and the interface follows Obsidian's language between English and Russian.
