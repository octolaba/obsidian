# felipefdl/warm-burnout-obsidian

Warm Burnout is a community Obsidian theme with dark and light variants built on a warm-first palette and a single steel-blue accent. Headings follow a gradient from amber through burnt orange, aged brass, terra cotta, steel patina and warm stone, so visual weight drops with each level, and all twelve callout types map to distinct palette entries. The README also documents syntax highlighting covering both Prism in reading view and CodeMirror in editing view, and graph colors built on a copper rust accent. The repository is recorded as a mirror of felipefdl/warm-burnout.
