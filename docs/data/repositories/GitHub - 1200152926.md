# Glaysia/termux-terminal

Termux Terminal renders a native Termux shell in an Obsidian tab on Android, with a local Rust bridge owning the pseudo-terminal, the shell and its process lifecycle. The bridge is installed inside Termux as a runit service and prints a connection token once; the plugin is then pointed at that token and opened from a ribbon icon or the Open terminal command. Each tab starts a fresh interactive Bash session that sources only an obsidianrc file rather than the usual bashrc, and the bridge listens on the loopback address alone, requiring the stored token on every connection and expiring it after six months. It needs native Termux on aarch64 and a hardware keyboard, and it is not an SSH client or a remote shell server.
