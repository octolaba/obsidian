# SunnyYYLin/obsidian-tasklite

TaskLite edits and renders standard Markdown task lines in the emoji metadata format of the Obsidian Tasks plugin, covering priorities, start, scheduled, due, done and cancelled dates, recurrence, dependencies, task identifiers and an assignee. Toggling is tree-aware: finishing or unfinishing a task cascades to its children and bubbles up to its parent, done and cancelled dates are written automatically, and a recurring task creates its next occurrence. It intercepts checkbox clicks in Live Preview, suggests emoji fields while typing, reconciles checkbox changes made by other plugins, and can import custom status settings from the Tasks plugin. A file can be excluded from scanning with an ignore key in its frontmatter, and the README also documents turning a whole file into a task through frontmatter.
