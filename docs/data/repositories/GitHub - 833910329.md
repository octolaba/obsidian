# ytisf/virustotal-enrich

This plugin queries VirusTotal from inside Obsidian and writes the result back into the note, enriching it with properties of files, URLs, IP addresses or domains that can then be used in the note body or as metadata for querying with plugins such as Dataview. Use requires a VirusTotal API key obtained from that service and entered in the plugin settings, after which a command palette entry enriches the open note from the content detected in it. Settings hold the API key, a toggle for including the page type such as indicator, IP or URL as a note property, and a list of custom fields naming which VirusTotal properties to include, for example md5, sha256 or filetype.
