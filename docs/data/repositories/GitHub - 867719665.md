# LorenzoPegorari/SimplyColorful

Simply Colorful is an Obsidian theme for desktop and mobile created by LorenzoPegorari. Its stated goals are to make the most prominent parts of a note stand out so that skimming is faster, to help users quickly distinguish between different elements such as headings and internal or external links, and to provide a simple note-taking experience through prominent use of colors, particularly the personalized accent color. Listed features include support for light and dark mode, for all window frame styles, for both stacked tabs and sliding panes, and colorful headings in live preview and reading mode.
