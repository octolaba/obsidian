# eGellman89/Amber-Glass-Phosphor

Amber Glass Phosphor is a dark, CRT-inspired Obsidian theme with square terminal-style panes and controls and multicolored headings. It ships amber, green and white phosphor palettes, optional scanlines and a vignette, and an optional text glow, all selectable through Style Settings; amber is the default when the plugin is not installed. Reading view, Live Preview, the interface and PDF export share the same styling, and the fonts Share Tech Mono, 3270 Nerd Font and Audiowide are embedded as WOFF2 so nothing is fetched from the network.
