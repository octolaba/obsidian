# mryanb/obsidian-asana

Obsidian plugin that creates tasks in Asana from the current line or the selected text in a note. An Asana access token is created on the Asana apps page and saved in the plugin settings, which is what connects the plugin to the account. The README documents installation from the community plugin browser, from a release archive unzipped into the plugins folder, or through the BRAT plugin for beta testing.
