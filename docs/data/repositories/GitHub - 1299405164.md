# nauppece/timemeter

TimeMeter records the frontmost application into a Markdown table in the vault and presents today, per-day and monthly views in a sidebar with an app-totals bar chart and a zoomable timeline; clicking a bar or a timeline segment prompts a short note about that session. Automatic tracking is macOS-only and works only while Obsidian is open, while on mobile it is disabled and only viewing and manual logs remain. The README states that frontmost-app detection runs the macOS commands osascript and ioreg through child_process, only on desktop, using execFile with static arguments, reading system state and writing everything to Markdown in the vault rather than sending it anywhere. Its interface is available in English and Japanese.
