# ferenk/obsidian-tokenz

Tokenz expands short codes typed in a note into icons, special characters and frequently used snippets. Two code maps are built in, an emoji map with more than 1800 entries and a classic smiley map, and further maps can be defined by the reader in whatever format they prefer, so a code such as a dot- or slash-prefixed word maps to a chosen character. The README documents installing it from Obsidian's community plugin collection or building it from sources.
