# Krontur/obsidian-swaggerjson-to-markdown

This plugin converts Swagger 2.0 and OpenAPI 3.x JSON files in the vault into static Swagger-style Markdown, from a context-menu action on a .json file or a command on the active file, with an options modal before generation. A full mode produces complete documentation and a fragment mode reusable pieces filtered by tag, operationId, HTTP method or path, with operations grouped by tag and sections for API information, servers, endpoints, parameters, request bodies, responses, examples and schemas. The README states that real Markdown headings are used so the Obsidian outline and PDF bookmarks work, that rich markup in description fields is sanitized into styled blocks, that examples are emitted as fenced code blocks, and that internal references are resolved with recursion detected and unresolved ones reported as warnings. Interactive Swagger UI controls are deliberately not reproduced.
