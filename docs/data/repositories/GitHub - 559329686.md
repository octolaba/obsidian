# mvdkwast/obsidian-copy-as-html

Copy Document as HTML copies the current document, or just the selection, to the clipboard as HTML for pasting into HTML-aware applications such as mail clients. It exposes three commands — selection or whole document, whole document, and selection only — bindable to hotkeys and also reachable from the file explorer view. The README lists working support for images, PlantUML, diagrams, Tasks, Dataview, Excalidraw and Mermaid, and settings cover a customizable stylesheet, whether external http links are embedded, converting SVG to bitmap, rendering code and callouts as HTML tables, using the filename as the title, and copying an HTML fragment instead of a full document.
