# thomassnoeck/url-formatter-obsidian

URL Formatter is an Obsidian plugin that, per its description, automatically formats specific URLs pasted into Obsidian into clean Markdown links. The README describes user-defined patterns, each carrying a pattern name, a regular expression and an output format that may reference capture groups, so a pasted address becomes a link labelled by the identifier inside it. Worked examples cover Jira ticket URLs, blog post paths carrying a year and a slug, and documentation pages.
