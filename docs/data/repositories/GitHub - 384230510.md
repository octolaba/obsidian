# chetachiezikeuzor/cMenu-Plugin

cMenu adds a text editor modal to Obsidian that presents editing commands as a menu bar, aimed at note-takers who do not want to configure or memorize a large number of hotkeys. Any command from Obsidian's command library can be added to the bar; by default it carries toggle bold, italics, strikethrough, underline, superscript, subscript, code, code block and blockquote. The README states that the plugin is available in the Obsidian community plugin store.
