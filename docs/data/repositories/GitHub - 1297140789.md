# NoteNerdOfficial/web-embed

Web Embed renders a website as a live, interactive browser view inside an Obsidian note: a fenced code block tagged browser with the URL on its own line loads the site at the configured height, where it can be scrolled and clicked like a normal browser tab. The embed height in pixels is the single setting, defaulting to 300, and a URL must begin with the http or https scheme or an inline error is shown. The README records the plugin as desktop only, because the webview element it relies on is not available on mobile, and notes that some sites block embedding through X-Frame-Options or Content-Security-Policy.
