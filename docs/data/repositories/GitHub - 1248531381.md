# wesswart77/obsidian-daily-journal

The repository holds Daily Journal, an Obsidian plugin that creates a dated journal note pre-filled with reflection prompts and habit checkboxes. It records a mood on a one-to-five scale with an emoji, ticks configurable habits, rotates three prompts covering gratitude, challenge and intention, and counts consecutive days with entries as a streak. A sidebar view shows the current week's entries with their mood and habit completion alongside a recent-entry list, and a modal logs mood and habits without opening the note.
