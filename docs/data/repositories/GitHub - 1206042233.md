# semernyakov/polymind

PolyMind is a chat plugin that talks to AI models through the Groq API from inside Obsidian. Its recorded features are a model list updated at run time with a dialog of per-model details, support for text, vision, coder and audio models, Markdown formatting with code highlighting and a raw-source toggle, context-aware replies, and creating a new note out of an AI message. The interface is localised in English and Russian following the Obsidian language setting, runs on mobile, and can default to either a tab or a side panel.
