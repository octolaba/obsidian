# kuzzh/obsidian-startpage

StartPage replaces Obsidian's new tab with a dashboard homepage, which can also be opened from a toolbar icon or from two commands, one for the current tab and one for a new one. The page carries vault statistics — the total number of notes, the edits made today and the storage used — over a card layout that adapts to the screen size, with pinned notes at the top and recently modified and accessed notes below them, sorted by both times and shown in a configurable number. A built-in search box starts searching as soon as typing begins, and a separate search modal adds fuzzy matching and a case-sensitive option.
