# hokolamp/obsidian-custom-new-file-name

This plugin creates notes whose names follow a user-defined format, including dynamic datetime stamps. A New Note (with Custom Name) entry is added to the context menu of a folder in the file explorer, and the format is entered in the plugin settings — the README's example combines fixed text with a datetime placeholder carrying its own date format.
