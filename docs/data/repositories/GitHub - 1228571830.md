# ChristianLempa/obsidian-pi

Pi Agent runs a chat with the Pi coding agent inside Obsidian, passing context from the current note, its links and backlinks, tags, explicit search results and the selected text. Its README records the plugin as desktop-only and requiring the Pi coding agent 0.80.0 or newer installed separately, with a setting for the executable path when Obsidian cannot find it on the PATH. It describes four tool modes of increasing authority: chat, which attaches context only, review for reading, searching and listing files, edit for writing them, and full agent, which also runs shell commands. The README advises starting in chat or review inside a dedicated test vault before granting the higher modes.
