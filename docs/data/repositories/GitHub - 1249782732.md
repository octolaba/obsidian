# p77-don/novels-note-jp

Novels Note JP configures a novel-oriented editing environment for Markdown files marked with novel mode, including Japanese paragraph indentation, full-width space visualization, and adjustable writing layout. It adds ruby and emphasis-dot insertion, terminology registration and highlighting, vertical-text previews, statistics, and manuscript export, with mobile commands for selection-based actions.
