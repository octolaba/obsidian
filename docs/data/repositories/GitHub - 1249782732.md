# p77-don/novels-note-jp

Novels Note JP provides a writing environment for Japanese fiction, scoped by a novel mode key in a note's frontmatter so that ordinary notes are unaffected. Recorded features include Japanese monospace fonts with adjustable size and line height, full-width space visualization, automatic paragraph indentation, a configurable line-wrap ruler, ruby annotation from the context menu, term highlighting and manuscript export. Plain text files can be opened, edited and shown in the vertical writing preview, but the README states that novel mode itself does not activate for them because Obsidian parses frontmatter only in Markdown files. Desktop and mobile are both recorded as supported.
