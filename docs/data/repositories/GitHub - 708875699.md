# Obsidian-Desci/Obsidian-Desci

Repository for Obsidian-DeSci, a plugin that connects Obsidian canvases to decentralized-science tooling. Its commands act on a selected canvas node: pulling content from IPFS by CID, expanding a CID that references a DAG into child nodes, adding a JSON object, fetching a DeSci node record, and executing jobs such as cowsay or Stable Diffusion by sending a transaction through the Lilypad network. Configuration asks for the private key of an Ethereum address funded on the named testnet and for an IPFS Kubo RPC endpoint, and the documented setup runs the plugin from source alongside a gateway API started with Docker Compose.
