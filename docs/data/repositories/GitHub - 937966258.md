# d7sd6u/obsidian-viewer-ftags

This plugin renders the ftags assigned to a file as tag-styled chips at the top of each file view in the workspace. Immediate parent tags are drawn brightest and carry a button that removes the connection, and if removing one leaves the file with no non-inbox ftag the file is moved to the inbox folder; more distant ancestors are drawn progressively more transparent. Child chips are added below the ftag chips, showing the first five and an ellipsis item that reveals the rest when a file has more. The README notes that a button for adding new tags appears to the left of the chips when the author's crosslink-advanced plugin is enabled, and links to another of the author's repositories for an explanation of what ftags are.
