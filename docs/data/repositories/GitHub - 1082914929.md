# ryohma0510/obsidian-note-progressbar

Note Progressbar shows a progress bar above the current note counting how many Markdown checkboxes are complete. It reads standard task lines through Obsidian's metadata cache and renders the totals, a percentage and a fill bar, updating when a task is toggled or another note is opened. A command toggles the bar per vault, and the README states that notes without tasks keep their layout unchanged because the bar hides itself.
