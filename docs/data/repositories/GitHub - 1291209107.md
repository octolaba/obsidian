# vishae/tasks-backlink-shortener

Tasks Backlink Shortener changes how the Obsidian Tasks plugin renders the backlink shown under each task, replacing the full path, heading and file extension with a shorter form. The README documents four display modes selectable in settings, among them filename plus heading, heading only, and filename only as the default, with the heading-only mode falling back to the filename when a task sits under no heading. Its author records it as a deliberately single-purpose plugin written to scratch a personal itch and released in case someone else wanted the same thing.
