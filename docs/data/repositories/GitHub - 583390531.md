# hush-hush/obsidian_wombat

Wombat is a minimalist Obsidian theme based on the Wombat256 color theme for Vim. The README describes a dark gray background with easy-on-the-eyes desert-like colors and states that it is a dark theme only. Part of its CSS logic is credited as inspired by the Obsidian Nord theme.
