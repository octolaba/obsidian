# mafgin/obsidian-graph-heatmap

Graph Heatmap is an Obsidian plugin that colours graph view nodes by a chosen metric and can narrow the graph to a subset of the vault. The README records seven metrics — last modified, created, total connections, backlinks, outgoing links, word count and file size — and a focus mode that dims or hides everything outside the top or bottom 10 or 25 percent, or shows only orphans, stale notes or stubs, with hidden nodes faded to 12 percent opacity unless set to disappear entirely. Twelve built-in palettes plus a custom three-colour mode are recorded, alongside relative ranking by default and an absolute scale for the time metrics, and a halo colour blended into notes modified within a configurable recent window. All of this is driven from a collapsible panel inside the graph view, and hovering a node shows its path, raw value, modification time, connection count and rank.
