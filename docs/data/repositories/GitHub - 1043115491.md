# moziar/Obsidian-Iconify

Iconify adds custom icons to Obsidian and allows the application's default icons to be swapped out. Icons are exposed through unique `iconId` identifiers, which the README presents as the integration point for other plugins that offer icon pickers, naming Callout Manager, Callout Studio, Commander and Better Properties. An Auto-reload Commander setting disables and re-enables the Commander plugin after icons are added or removed so its picker sees the change without an Obsidian restart, and the README states that no other plugin is touched.
