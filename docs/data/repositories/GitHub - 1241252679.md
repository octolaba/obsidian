# philphilphil/obsidian-agent-file-pane

Obsidian plugin that hides agent instruction files - `AGENTS.md`, `CLAUDE.md`, `GEMINI.md` and any other filenames configured - from the file explorer and lists them in a dedicated right sidebar pane mirroring the folder tree. Hiding works at any depth through a runtime stylesheet and matches filenames exactly and case-sensitively, so a file such as `MY_AGENTS.md` is left alone. The pane opens from the ribbon icon or the command palette, re-renders automatically on file create, delete and rename, and opens a file in a new leaf on Cmd or Ctrl click.
