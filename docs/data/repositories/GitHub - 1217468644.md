# stefan-imbesi/obsidian-slash-blocks

Repository for Slash Blocks, a plugin that opens a block menu when a slash is typed at the start of a line. Its README lists the blocks it inserts: a task checkbox, plain paragraph text, three heading levels, a divider, bullet and numbered list items, a blockquote, and image and attachment syntax with the cursor placed inside the parentheses. Typing filters the menu, the arrow keys move through it, and the README states that it works on desktop and mobile.
