# bongho/obsidian-book-metasearch

Book Metasearch creates book notes from four providers queried together: Aladin and Kakao for Korean results, Google Books and Open Library for foreign ones, run as a sequential fallback or a parallel fan-out deduplicated by ISBN13. Commands search by title, by ISBN or from the current note, update a note's book information, insert a citation at the cursor, and mark a book as wishlist, reading or read with automatic dates. Notes are built from a template file with variable substitution that leaves Templater blocks intact, and frontmatter keys, key casing, cover downloads and a language filter are configurable; the vault is scanned for the same ISBN13 first, so an existing match can be opened instead. Aladin and Kakao need free API keys, Google Books works without one at a lower limit, and Open Library needs none.
