# OperationT00/T-wiki

T-Wiki is a desktop Obsidian plugin that turns imported documents, web pages and clippings into a structured, traceable Markdown wiki. It ingests Markdown, TXT, text-based PDF, local audio and video, public web pages and public Bilibili and Douyin videos, normalizing each into clean raw Markdown, with PDF.js used locally and MinerU available for scanned or complex PDFs. An agent runtime backed by an LLM API the user supplies extracts and merges knowledge into Source, Entity, Concept and Synthesis pages, maintaining wikilinks, indexes and graph relations. Changes are reviewed as a diff before anything is written into the wiki folder, and API tokens are kept in Obsidian secret storage.
