# MKSherbini/obsidian-noor

Noor is an Obsidian plugin that inserts Islamic reference material into notes. Its commands insert a quote block holding a random Quran verse with Arabic recitation, a translation in a chosen language and a link for more information, insert a random hadith quote in the chosen language with a similar link, or create a Dhikr file at a configured location containing both, opened in the current view or in a popup window and refreshable with new quotes. The plugin also exposes a noorJS object whose functions return a Quran quote or a hadith quote for scripting from other plugins.
