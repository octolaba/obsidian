# LeonStaufer/obsidian-beeminder-task-sync

Beeminder Task Sync sends a datapoint to a Beeminder goal when a checklist item marked with a bee emoji is completed, and removes that datapoint when the item is unchecked. The marker carries the goal name and an optional value — `🐝 exercise=5` sends five, and an omitted value defaults to one — with autocomplete from the cached goal list and a command that inserts the marker on the current task. The README states it works with plain Markdown checkboxes and is compatible with the Tasks plugin without requiring it, and that the settings hold only a reference to an Obsidian SecretStorage secret while the auth token itself is read from that store.
