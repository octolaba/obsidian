# TerekhinAO/obsidian-gitlab-sync

GitLab Gitless Sync keeps a vault and a single branch of one GitLab project in step using the GitLab REST API alone, so it runs on Android and iPhone where Git cannot be installed while remaining compatible with an ordinary desktop Git workflow on the same branch. Syncing can be triggered manually from a sidebar icon or command, and automatically at startup, after edits, on a timer, and when a mobile app moves between foreground and background. The default strategy attempts an automatic merge of text files and, where that fails, keeps both versions as separate files rather than overwriting either side; connecting a vault first shows a summary of both sides for confirmation. The access token is held in Obsidian's secret storage, local sync metadata is never committed, and Obsidian 1.11.4 or newer is required.
