# emac/obsidian-minote-plugin

Minote Sync is a community plugin that converts notes from Xiaomi's note service into Markdown and saves them into a chosen Obsidian folder, doing a full first pass and then incremental updates of changed notes only. It keeps the source folder structure along with creation and modification times, downloads images and rewrites their references as Markdown, replaces background tags with span tags so highlighting survives, strips redundant tags, and generates titles for old untitled notes from the first line and the note identifier. A forced sync command overwrites everything, and non-China Xiaomi cloud accounts are supported. The README warns that updates are overwriting, so synced files should not be edited, that deleted notes are not cleaned up automatically, and that the login cookie can expire and must be refreshed; it is written in Chinese and English.
