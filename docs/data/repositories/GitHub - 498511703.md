# danieltomasz/qmd-as-md-obsidian

This plugin lets Obsidian edit Quarto qmd files as if they were Markdown and render or preview them through Quarto. The README states that it shells out to the quarto command-line tool for every preview and render operation, so Quarto must be installed locally and reachable on the shell PATH, with its full path settable when it is not discovered automatically. Recorded features include creating a qmd file from a built-in preset, running Quarto preview inside Obsidian or in a browser, rendering to PDF, a sidebar outline of the active file's headings because Obsidian's core Outline panel cannot read that format, optional preview and render for Markdown files that live inside a Quarto project folder, and optional dedicated editors for YAML and Lua files with syntax highlighting.
