# vincentlaucsb/obsidian-csvzall-mobile

The repository holds csvzall Mobile, the phone and tablet companion to the csvzall Obsidian plugin. It creates CSV files from the command palette, the ribbon or a folder menu, opens them in a mobile pane through a bundled WebAssembly viewer, and supports basic editing and saving back to the vault file, with a mobile toolbar button for navigation. The README states that it needs no desktop helper binary and no local server, and that it stays inert on desktop so it does not compete with the desktop plugin for CSV files, which is where chart generation, SQLite queries and large-file viewing live.
