# greatgc-flow/MarkItDown-Flow

MarkItDown Flow converts documents, images, audio, video and ZIP archives into Markdown, both as an Obsidian plugin and as a standalone Python command-line tool. Its README describes a four-phase pipeline that begins with offline OCR through Tesseract and EasyOCR and falls back in turn to vision models from OpenAI, Anthropic and Google, then to Azure Document Intelligence and Azure Content Understanding. Conversion runs from the ribbon icon, from command-palette commands for a single file or a whole folder, or by dragging a file into the editor, and the plugin settings need a Python path and packages such as markitdown and Pillow. The README also records eight output languages, metadata aligned to a configured timezone offset, extraction of inline base64 images into a separate folder, and API keys passed through environment variables rather than command-line arguments.
