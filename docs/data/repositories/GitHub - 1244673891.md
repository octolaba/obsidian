# Transept-AI/obsidian-claude-code-ide-pro

Obsidian plugin that hosts the Claude Code IDE integration protocol, the same WebSocket and MCP contract used by editors such as VS Code and JetBrains, inside Obsidian. The README states that every standard IDE tool is wired up, so Claude edits the vault through a side-by-side diff approval interface, navigates to specific files and lines, and reasons over the backlink graph, wikilinks, frontmatter and search through eight Obsidian-native MCP tools, connecting when the ide command is run from a session started in the vault. It points readers who want a minimal read-only context bridge to a different plugin instead.
