# nedkelly/obsidian-glink

This repository holds GLink, described upstream as a web-view-based Google Docs link utility that opens Google placeholder files inside Obsidian. The README says it keeps a local mapping from each placeholder's vault path to its Google URL, so it neither reads placeholder contents nor uses the Google Drive API, and it opens Docs, Sheets, Slides, Drawings, Forms and Apps Script projects in embedded views, including through embeds. Registry import, export, update, copy and removal controls are listed, along with an optional dark filter for embedded pages. The README states that only Obsidian desktop on Windows is supported, that automatic linking depends on the Windows Shell and PowerShell, and that macOS, Linux and mobile are untested or unsupported.
