# piyooko/obsidian-syro

Syro adds spaced repetition and incremental reading workflows to Obsidian. Flashcards are written inline in native Markdown, through highlight or double-colon syntax, and a review can jump back to the paragraph a card came from, so the card is recalled in its context; longer material goes into a right-sidebar reading queue that can be filtered by tag, with the FSRS algorithm deciding what is due. The README also describes a timeline that stores the scroll position where reading stopped so a later session resumes there and lets the reader leave a message at that point, which it compares to a commit in version control.
