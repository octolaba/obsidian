# LingXiFox/drag-biolink

Repository for Drag Bi-Link, an Obsidian plugin that turns existing text in split Markdown editors into native block links without appending a duplicate copy of the other block's text. Its default entry mode, Anchor Glow, locks one selection with a command, then a second, and offers a bidirectional or one-way link whose direction can be flipped before it is committed or cancelled. An Option or Alt drag gesture is the alternative entry mode, and the README states that the plugin requires Obsidian 1.8.7 or later.
