# copperbox/obsidian-claude-vault-assistant

Obsidian plugin that defines reusable prompt files and runs them against the vault or the active note through the Claude Code command-line tool in headless mode. The README states that both one-off prompts and an interactive multi-turn chat pane drive that CLI through the Claude Agent SDK, with tool approvals shown in the pane. Its security section states that the CLI runs as a local process able to read, write and edit files in the vault, and that on macOS and Linux the plugin harvests the login-shell environment and passes it to that process.
