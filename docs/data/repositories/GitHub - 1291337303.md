# sajee05/Obsidian-ValidTitle

ValidTitle sanitizes characters that are illegal in Windows filenames inside wikilinks, so that Obsidian's "File name cannot contain..." error does not appear. When a link carrying such a character is typed or clicked, the plugin intercepts its creation and rewrites it: a colon becomes a space and a hyphen, slashes, backslashes and pipes become hyphens, and asterisk, question mark, double quote and angle brackets are removed. The README states that aliases, Markdown tables, code blocks and headings are ignored, and that the plugin has no settings, ribbon items or commands.
