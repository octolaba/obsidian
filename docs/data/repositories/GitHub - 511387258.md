# vrtmrz/ninja-cursor

Ninja cursor is an Obsidian plugin that makes the text cursor easier to follow, which the README describes as enhancing cursor visibility and credits to a similar effect in Neovide. Its recorded installation route is not the community plugin browser but the Beta Reviewers Auto-update Tester, adding this repository's URL as a beta plugin from the command palette. The README states the license as MIT.
