# mrjackphil/obsidian-jump-to-link

Jump to link is an Obsidian plugin for navigating with the keyboard by overlaying letter hints. Its Jump to link command labels every link in the open file so pressing the letter opens it, with Shift opening the note in a new pane, while Jump to Anywhere is a regular-expression based mode, similar to vim-easymotion, that labels any word on the page and jumps or, with Shift, selects to it, in both the regular editor and Vim mode. The regular expression and the characters used for hints are configurable, the README noting that words of three characters or more are labelled by default and that matches beyond the available letters cannot be jumped to; a Lightspeed mode is also included.
