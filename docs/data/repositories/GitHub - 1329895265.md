# bobstanton/places-utilities

A provider for the Places plugin that classifies and names recorded tracks, builds new tracks and plays a route back. Classification reads named OpenStreetMap features along and around a track, and naming identifies the ways it follows; both query an Overpass endpoint with a second Overpass host as fallback, while track matching is left to whichever provider the block selects. The track-building tool draws its map with maplibre-gl, and the plugin runs no background tasks.
