# schrunchee/obsidian-covert-theme

Covert is a dark Obsidian theme whose text sits only slightly lighter than its background, so that a note is hard to read at a distance in a public place such as a coffeehouse or a library. Its README suggests pairing it with a smaller font size and a lowered screen brightness, and points to comments in the theme CSS marking the lines that set colours for hand editing. It states plainly that this does not fully hide the text and provides no encryption or any other mechanism keeping the files secret if someone else has access to the device. The theme is built on Insanum's Obsidian Nord theme.
