# ivaneye/obsidian-files-cooker

The repository holds file-cooker, an Obsidian plugin that acts on many notes at once, taking its worklist from search results, the current file or a Dataview query. Its README lists moving, copying, renaming, deleting and merging several files at a time, adding and removing values in the tags, alias and cssclasses properties, editing other properties without a separate metadata plugin, creating files from unresolved links, and copying Dataview result links to the clipboard. Several operations target a Canvas, adding files, plain text or Dataview tasks to it; the code is licensed under Apache 2.0.
