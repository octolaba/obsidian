# Puhhh/pdf-resize-obsidian

PDF Resize applies the width syntax already used for image embeds to embedded PDFs, so a pixel width written after the filename in a wiki-link sets the rendered width. Whole-number widths from 1 to 4096 are accepted, values below 100 are clamped to a minimum rendered width of 100 pixels, and zero, larger values and malformed widths are ignored so the embed keeps Obsidian's default size. The width applies in Reading view and Live Preview and shrinks to fit a narrower pane, source mode is unaffected, and the plugin makes no network requests and does not modify vault files.
