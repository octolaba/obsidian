# rixct/code-recall

CodeRecall turns code blocks in Obsidian notes into spaced-repetition cards: a cloze marker hides part of the code, and during review the hidden fragment becomes an input box that the reader retypes from memory. Rather than self-grading, the plugin runs the typed code against the test cases declared in the card and counts it as recalled only when the tests pass; cards without tests or without a language are checked by comparing the typed text against the hidden answer. A card is one fenced block with the `coderecall` info string whose body is YAML, carrying fields such as `code`, `lang`, `name` and `tests`.
