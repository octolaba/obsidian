# GS-AX/obsidian-jira-weaver

Jira Weaver syncs Jira issues into an Obsidian vault as Markdown files with structured YAML frontmatter. Any Jira system or custom field can be mapped to a frontmatter key, field values can be wrapped as wiki links so they reach Graph View and Dataview queries, and several JQL profiles sync different queries into different folders. A section marker preserves personal notes kept below the Jira block, a sync log panel records created, updated, skipped and error counts per profile, and field mapping presets can be exported and imported. Authentication is a bearer token for Jira Server or Data Center or email plus API token for Cloud, syncing runs manually, at startup or on an interval, and the interface follows the Obsidian language across English, Korean, Japanese and Simplified Chinese.
