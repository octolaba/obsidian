# Steffo99/obsidian-file-index

Creates and keeps updated a file-index.json file at the vault root, holding the list of all file paths and a map from basename to path. The README describes the purpose as rendering wikilinks outside Obsidian without knowledge of the vault's file structure, naming the Glassflame viewer as an example consumer. Files can be excluded by placing a file-index-ignore.json at the vault root containing regular expressions that matching files are tested against. A recorded known issue is trouble distinguishing files that share a basename in different folders.
