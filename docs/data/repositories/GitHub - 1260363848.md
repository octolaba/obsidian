# VitaliiRomanenko/popcorn-md

Popcorn-MD searches for movies and television shows by title or IMDb identifier through TMDb and creates an Obsidian note for the result from a template. The generated note is pre-filled with metadata such as title, year, genres, poster, synopsis, rating and cast, the layout being defined by a chosen template file with placeholders. Setup requires a TMDb API key or access token, a template and a default folder in the plugin settings, after which the search modal is opened from a command or a ribbon icon.
