# BeatsAD/Vault2Dify

Vault2Dify is a desktop-only Obsidian plugin that syncs selected Markdown notes from the vault to one or more Dify knowledge bases. The README says a mapping can point an Obsidian folder, a single note or the whole vault at knowledge bases, which are loaded by testing the Dify API key against the datasets endpoint, and that one configurable service URL covers local Docker, a NAS or LAN host, Tailscale, a reverse proxy or Dify Cloud. Sync runs manually from the ribbon, command palette or settings, or automatically on Markdown create, modify and rename events with a periodic full check, and records are stored per knowledge base and per file path so same-named files in different folders stay distinct. It states that deleting a local note or a mapping does not delete the remote document, and that new installs upload nothing until a mapping is configured.
