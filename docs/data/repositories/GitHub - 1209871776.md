# kenforthewin/obsidian-atomic

An Obsidian plugin that syncs vault notes to an Atomic server and exposes that server's features inside Obsidian: hybrid keyword and vector search with snippet previews, a sidebar of semantically similar notes, LLM-written wiki articles organised by tag hierarchy with citations back to source notes, an agentic chat that searches the vault mid-conversation, and a force-directed knowledge-graph canvas. Syncing runs in the background while writing and uses content hashing to skip unchanged files. The README states that a reachable Atomic server is required — either the Atomic desktop app running a local server or a self-hosted one — and that the server side needs an LLM provider such as OpenRouter or a local Ollama.
