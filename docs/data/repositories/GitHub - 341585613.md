# kalibetre/mochi-cards-exporter

Mochi Cards Exporter exports Markdown notes from Obsidian as flashcards for the Mochi app. A line marked with a card tag, by default a hash-card tag that can be changed in settings, becomes the front face of a card, and the text between it and the next section divider becomes the back face. Images, videos, sounds and other attachment types Mochi supports are included. The export produces a mochi file, which the README describes as a zip of the exported cards and their attachments, to be imported from the Mochi app.
