# ravimashru/obsidian-show-file-path

Obsidian plugin that shows the full file path of the currently open file in the status bar, following whichever pane has focus when several files are open in panes. Settings control icons for each part of the path, whether the file name is included, and whether the copied path is relative or absolute. Clicking the status bar item copies the path to the clipboard, and a command does the same. The README records that the status bar is not visible in the mobile app, so the path is not displayed there, while the copy command still works on Android.
