# KreNtal/obsidian-modern-outline

Modern Outline draws a note's headings as small markers overlaid on the edge of the note itself rather than in a sidebar panel, revealing the heading labels on hover and jumping to a heading when a marker or label is clicked. The active heading is highlighted while scrolling in both editing and reading mode, spacing compresses in dense notes so it stays in view, and an always-visible mode skips the hover entirely. The README records settings for side and vertical alignment, animations, marker style and size, independent marker, label and highlight colours, label font, hierarchy shown through indent or font size, tree lines connecting a heading to its children, the minimum and maximum heading level displayed, and an option that takes heading colours from the active theme.
