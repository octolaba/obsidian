# CyanVoxel/vauxhall-obsidian

Vauxhall is an Obsidian theme that the README presents as clean and cool without sacrificing personality, customized through the Style Settings plugin. That plugin is required for everything beyond the default dark and light themes, and it exposes base colors including white, teal, blue, indigo as the default, purple, magenta and red, three background intensities named Nebula, Standard and Void, and several header color styles from mono through gradients to rainbow. The README also suggests pairings with the JetBrains Mono font, the Iconize plugin and a colored sidebar snippet.
