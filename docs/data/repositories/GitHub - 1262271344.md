# viggomeesters/obsidian-python-viewer

Python Viewer opens .py files in Obsidian in a dedicated read-only view that pairs the source, with line numbers and lightweight syntax highlighting, with a compact structure outline of imports, decorators, classes, functions, methods and top-level constants. Symbols and source lines can be filtered by name, kind, detail and text, a symbol jumps to its line, and parse diagnostics such as a missing colon on a definition are reported while the source view stays usable when parsing is incomplete. Its parser is a lightweight local symbol scanner rather than a full Python syntax tree, deliberately ignoring matches inside comments and triple-quoted strings, and rendering stops at 10,000 lines with a report of how many remain. The README states that the plugin never writes back to Python files and never runs Python code, leaving editing and execution to a code editor or terminal.
