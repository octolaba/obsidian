# wulflo/obsidian-Amor

wulflo/obsidian-Amor holds Love, an Obsidian theme built on scarlet and crimson shades. Its README documents three usage features: colourful text highlights, a glow effect applied to any line carrying the flashcard tag, and a cssclasses value named collage that turns Dataview query output into a cards view. The author states that the theme was tested for personal use and may not be compatible with certain plugins, and credits the Minimal, Vicious and Prism themes along with the Cards and MultiColumn snippets.
