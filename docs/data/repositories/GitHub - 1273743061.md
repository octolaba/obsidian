# mistudiostudy-sys/mistudio-obsidian-sync

MiStudio Sync, whose README is written in Spanish, pulls folders and notes from the MiStudio service into an Obsidian vault as Markdown files, with an optional two-way mode that sends edits made in Obsidian back. Each synced note carries frontmatter identifiers so it is recognised between runs instead of being duplicated, and an optional setting writes read-only task and calendar files plus a daily note, all rewritten on every sync. The README records that a long-lived API key is generated on a page of the user's own MiStudio instance and pasted into the settings together with the instance URL and a destination folder, and it documents building the plugin from source and copying the result into the vault.
