# karstenpedersen/obsidian-advanced-random-note

Advanced Random Note builds commands that open a random note matching a custom query. Queries are written in the plugin's own language modeled on Obsidian search, in Dataview, or as regular expressions, edited through a modal and optionally registered as commands. Folders can be excluded from the searches and notes can be set to open in new tabs, and the plugin ships commands for the query modal, a random markdown note, and a random file of any type.
