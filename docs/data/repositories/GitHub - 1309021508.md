# hailanbb/s3-image-sync-pro

S3 Image Sync Pro uploads images from Obsidian to S3-compatible storage such as Cloudflare R2, AWS S3, or MinIO while maintaining a local mirror. Its central invariant keeps each object key equal to the mirror-relative path, independent of Cloud or Local link mode; scans, downloads, path resynchronization, ignored paths, optional WebP compression, and retry or rollback handling cover bulk and note-level workflows.
