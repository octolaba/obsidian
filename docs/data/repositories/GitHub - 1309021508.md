# hailanbb/s3-image-sync-pro

S3 Image Sync Pro scans images in notes and uploads them to S3-compatible storage such as Cloudflare R2, AWS S3 or MinIO, keeping each image in both a local mirror directory and the bucket so links can be switched between the local copy and the cloud address. An embedded WebP encoder compiled to WebAssembly compresses images before upload, external web images found in notes are downloaded, compressed and re-uploaded in the background, and a migration command pulls cloud-only images from older notes back into the local mirror. Deleting a note or image in Obsidian removes the corresponding object from the bucket and cleans the local mirror, and moving or renaming a note moves its associated remote images and mirror directories to match the new path. The README states the plugin is mobile-friendly.
