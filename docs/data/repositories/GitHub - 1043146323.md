# vupdivup/obsidian-everforest-spruce

vupdivup/obsidian-everforest-spruce is an Obsidian port of the Everforest colour scheme by Sainnhe Park, presented as a streamlined alternative to existing variations. The README lists a dimmed background, mono-colour headings, colour-coded emphasis and code blocks based on Everforest's highlighting rules, and states that the theme is currently dark-mode only.
