# mlevison/obsidian-review-builder

Consolidates Daily and Weekly notes into single files for quarterly and weekly reviews, writing `quarterly_days.md` and `quarterly_weeks.md` instead of leaving the reader to page through thirteen weekly notes. One command builds a quarterly review over a chosen quarter, another builds a weekly review over a chosen week and puts the previous week's review file at the top. The README states one rule for the plugin, that it may modify only files it created in a configurable temp folder, and discloses that most of its code was generated with an AI coding tool. The repository description is still the community plugin template's placeholder text and does not describe this plugin.
