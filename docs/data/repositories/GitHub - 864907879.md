# patrickchiang/obsidian-replace-all

Replace All adds replace-all functionality to Obsidian's built-in in-file find. The built-in find locates the instances, a replacement string is typed into the added input box, and pressing enter applies it to all of them. A command in the palette undoes every change made by the previous replacement. The plugin is installed from the community plugin browser or by placing its files in the plugins folder manually.
