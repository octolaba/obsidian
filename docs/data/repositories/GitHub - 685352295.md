# loveminimal/obsidian-theme-virgo

This repository holds Virgo, an Obsidian theme its bilingual README describes simply as a pure theme, shown in light and dark previews. It records that the theme has been merged into the official theme repository, so it can be installed by searching for Virgo under the appearance settings, and it gives a manual route that clones the repository into the vault's themes folder. A usage guide on the author's site is linked as further documentation.
