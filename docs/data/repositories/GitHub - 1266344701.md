# electroluminescent/obsidian-extended-properties

Extended Properties adds an arrangeable property panel to Obsidian's right sidebar that activates for any note whose frontmatter Type matches a configured type, and each type carries its own layout built visually inside the panel. A new type starts with an empty layout: in edit mode sections and properties are added, reordered by dragging handles, renamed, and configured for data type, options and styling, and outside edit mode the panel is interactive with checkboxes, number steppers, sliders, inline editing on double click and a right-click menu. The README states the core is domain-agnostic and that domain modules, such as the bundled D&D 5e character sheet, plug into it through registries and can be toggled in settings. It works on desktop and mobile and documents keyboard operation separately.
