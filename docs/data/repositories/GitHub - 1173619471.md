# Oczko24/Enchanted-Animations

Enchanted Animations replaces Obsidian's interface transitions with its own animations across panels, buttons and menus, including animated checkboxes and reworked styling for particular areas. The README states that animation speed and easing are configurable and that animations can be toggled per UI element. Its stated goal is to animate as much of the interface as possible, with hover animations and mobile-specific animations listed as roadmap items, and it credits the Checkbox Sounds plugin by yasd251 for the checkbox confetti animation.
