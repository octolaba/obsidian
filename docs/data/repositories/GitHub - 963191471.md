# manuelcoca/obsidian-mono-high-contrast-theme

Mono High Contrast is described as a light high contrast theme for Obsidian, and its README records it as inspired by the default high contrast theme of VS Code. The stated features are a clean and minimal design and a VSCode look and feel. Installation is documented from the appearance settings by browsing for Mono High Contrast, and the project records an MIT license.
