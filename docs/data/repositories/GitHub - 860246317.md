# Bailey-Moir/latex-callouts

Latex Callouts is described as making callouts look like LaTeX-styled definitions and theorems. Its README says that once the plugin is enabled the callout type is reinterpreted rather than used to pick an icon: icons are removed, the type is titlecased with hyphens turned into spaces, and text inside parentheses is italicized, so a hyphenated type with a parenthesised part renders as a bold heading followed by an italic qualifier. The callout's contents are then indented. Settings offer two modes, bordered and unbordered.
