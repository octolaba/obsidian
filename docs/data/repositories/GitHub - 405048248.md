# fivol/netwik-obsidian

Netwik is an Obsidian plugin that connects a vault to a shared network of notes held in the cloud, where anyone can create, view or edit a note and changes are synchronized between all participants. Its commands create, update, delete and upload remote notes and synchronize the local database with the cloud, and deleting a file locally does not delete it remotely. Typing a trigger character, by default a slash, opens suggestions of remote notes by title, inserting an internal link and downloading the file, and Shift+Enter on a typed title creates a new remote note. An obsidian:// URL for a cloud note can be copied and opened by anyone else running the plugin, even before they hold the note.
