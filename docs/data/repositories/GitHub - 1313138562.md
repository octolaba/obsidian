# benhancock/faster-stacked-tabs

Replaces the native smooth horizontal scroll used when switching between stacked tabs with a shorter ease-out animation, so the sliding effect is kept but runs faster. The animation duration is set in the plugin settings, adjustable from 40 to 400 milliseconds with a default of 120. Regular tabs and scrolling elsewhere are left alone, and native scrolling returns when the plugin is disabled. The only value it stores is the selected duration; it reads no note contents and makes no network requests.
