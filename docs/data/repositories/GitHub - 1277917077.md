# sany2ng0226-boop/quick-zh

Quick Chinese Translate translates the whole of the current Obsidian note into Simplified Chinese and saves the result as a new file, leaving the original untouched because machine translation is lossy and the source stays authoritative. The translated title becomes the new filename, and the title and description values in the frontmatter are translated and quoted while every other property is kept verbatim so the YAML does not break; fenced code blocks are never sent to the translator. Translation runs through Google by default with no configuration, or through DeepL with an API key, or through any OpenAI-compatible endpoint. It is triggered from a ribbon icon or a command, and the Chinese copy opens automatically.
