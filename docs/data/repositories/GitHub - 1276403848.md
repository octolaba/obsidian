# josipmarkus/obsidian-outline-level-fold

This plugin folds and unfolds the active note's outline to a chosen depth, filling the gap between Obsidian's all-or-nothing folding and its per-node toggle. Its README records seven hotkey-bindable commands: fold to level one through six, each keeping the levels up to that depth visible and collapsing everything deeper, plus an unfold-all command. The fold commands are absolute rather than toggles, so one hotkey per level jumps straight between depths, and with text selected the same commands act only on the selected lines, measuring levels relative to the shallowest selected line. The README states that this works on any space- or tab-indented outline but not inside fenced code blocks.
