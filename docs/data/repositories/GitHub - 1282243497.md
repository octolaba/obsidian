# israerusan/time-tracker-invoicing

Time Tracker and Invoicing tracks billable time against the note you are working in and aggregates it by client. Starting the timer on the active note tags the entry with client and project frontmatter, falling back to a default client and the note name, a status bar item shows the running timer and toggles it when clicked, and entries are stored in the plugin's own data file inside the vault. A command summarizes hours by client, and the same aggregation feeds invoice generation, which builds a Markdown invoice with one line item per project, configurable rounding, business details and totals, saved into a configured folder. The README states that the plugin is fully local with no external API and no account, that time tracking is free while invoicing and PDF export are unlocked by a one-time license verified offline, and that PDF export is a stub at the time of writing.
