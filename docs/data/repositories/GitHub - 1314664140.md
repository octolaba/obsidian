# surranov/gantt-tracker

Gantt Tracker renders a gantt chart from a YAML code block, drawing each row's planned range as a pill with the actual dates as a bar inside it. Deviations are colored automatically: work outside the plan is red, late starts and early finishes are hatched, unplanned pauses and planned gaps use different dashes, and a plan with no actuals has its overdue days hatched. Rows group into stages with subtasks and collapsible frames, background events such as vacations or releases appear as tinted full-height columns, and up to three typed comments per day show as colored dots. A today line is positioned within working hours, and the plugin has no dependencies, makes no network requests and takes its colors from Obsidian CSS variables.
