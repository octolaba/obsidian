# M-AbdullahTariq/Cornell-Note-Obsidian-Plugin

The repository holds Cornell Notes Pro, an Obsidian plugin that lays out a note as a Cornell study sheet using plain Obsidian callouts rather than a new syntax. A note marked with the plugin's cssclass is rendered with cues in a left margin, the notes beside them, a summary band across the bottom and a title at the top, in both Reading view and Live Preview, and several Cornell pages can be stacked in one file. A command and a ribbon icon create a ready-made Cornell note, and the README also shows a review mode.
