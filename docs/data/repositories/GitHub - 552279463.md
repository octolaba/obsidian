# dragonwocky/obsidian-material-ocean

Material Ocean is described as an oceanic dark theme for Obsidian that combines navy blue undertones with pastel highlights on both mobile and desktop. Its README recommends two accent colours, names Inter and Fira Code as the fonts used in its screenshots, and records that the same colour scheme exists for other applications. Beyond recolouring the interface, the README lists adjusted element spacing, sizing and positioning, window minimise, maximise and close icons replaced by Lucide icons, and further layout and typography tweaks.
