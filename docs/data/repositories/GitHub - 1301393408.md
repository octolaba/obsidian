# Kageetai/obsidian-daily-from-others-plugin

The repository holds Daily Notes from Others, an Obsidian plugin that creates missing daily notes for dates found in the filenames of other notes, such as voice notes, meeting notes or imported journals. It reads a date anywhere in a Markdown filename inside a configured source folder using the filename part of the existing Daily notes format, then asks Obsidian to create the normal daily note for that date without copying or merging the source note's content. A ribbon action or command creates every missing note or the one for the active file, new source notes can be watched automatically, dates that already have notes are skipped, and the README states that the plugin runs locally with no telemetry or accounts.
