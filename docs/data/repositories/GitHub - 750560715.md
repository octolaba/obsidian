# xRyul/obsidian-arcane-theme

xRyul/obsidian-arcane-theme holds Arcane, described as a lightweight, mobile-friendly dark theme that refreshes the author's earlier Dracula and LYT theme, with syntax highlighting listed beside dark mode. The README explains that it began as a base16 theme whose look could be changed by replacing eight shade and eight accent variables in the CSS file, and that it later moved away from a strict sixteen-colour palette around a muted cyan the author settled on, while keeping the base16 idea. Fonts are not bundled; the README recommends SF Pro Display for headings, SF Pro Text for body text and Monaco for code.
