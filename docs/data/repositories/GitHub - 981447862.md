# lnabc03/1st-Timeline

1st Timeline is an Obsidian plugin that renders timeline views from simple text blocks, with intelligent parsing for multiple date formats and Chinese dates. It supports point events, date ranges, referenced timelines, Markdown content, archiving of past events, note summaries, and configurable visual and sorting options.
