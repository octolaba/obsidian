# lnabc03/1st-Timeline

Renders a timeline code block as a timeline view. Entries are plain text lines pairing a date with its text, separated by two spaces or by a colon in either its Latin or its full-width form, and an entry's text may continue over several lines and contain Markdown such as headings, quotes, callouts, lists and tables. The recorded description and README state that several date formats are accepted with first-class support for Chinese dates, and that dates are parsed rather than required in one fixed shape.
