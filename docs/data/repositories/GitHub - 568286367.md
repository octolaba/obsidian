# connerohnesorge/Text-Dataset-Aid-Plugin

Obsidian plugin meant to help create personal JSONL datasets for text generation models. The README describes assembling a fine-tuning dataset by hand inside a note so that a model's output can be more personalised, detailed or better formatted, and presents this as a way to speed up work it calls tedious and slow. It states that the dataset is currently held in a txt file and that export of that file to JSONL is still to be added.
