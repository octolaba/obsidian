# srg-kostyrko/obsidian-journal

The README describes a journaling plugin for Obsidian that creates, organizes and navigates structured entries across several timeframes. It covers standard daily, weekly, monthly, quarterly and yearly notes as well as custom periods such as sprints or financial quarters, auto-numbered index entries, and multiple independent journals in one vault that can be grouped into shelves. For navigation it offers a calendar view, a timeline view driven by configurable code blocks, navigation blocks linking related entries, and note decorations that highlight notes by contents, dates or status. Consistency is handled through a templating variable system, automatic frontmatter metadata and user-defined commands for common operations.
