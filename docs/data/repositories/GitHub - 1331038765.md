# zinkiv/vault-base-plugin

Vault Base synchronises a vault against a WebDAV server such as a NAS in both directions, comparing three states (local, remote and the last successful sync) to decide what to move and to propagate deletions. Syncing runs manually, at startup, on a schedule or in reaction to changes, with a remote directory picker, status bar progress, and limits on concurrency, request rate and file size. Conflicts default to a merge, and where a merge is impossible the choice is newest version, keep local, keep remote or skip. Configuration folders such as .obsidian, .git and .trash are excluded unless an include rule allows a specific file, credentials are held in Obsidian's secret storage, and content can optionally be encrypted on the client before upload.
