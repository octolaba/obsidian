# scriptnull/rho-reader

An RSS reader plugin for Obsidian supporting RSS, Atom and JSON Feed, built so that every feed and every post is its own file in the vault. Feed URLs added to a note produce their posts alongside it, and a tagging system organises reading lists. OPML can be imported and exported, and clicking a post opens it in the web browser by default while marking it as read.
