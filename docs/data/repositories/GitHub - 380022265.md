# skipadu/obsidian-ghost-fade-focus

This repository holds Ghost Fade Focus, described upstream as a plugin for Obsidian that helps the writer keep focus. The README says it fades, step by step, the five lines above and below the line where the cursor sits, reacting to cursor activity such as moving to another line or moving at least one character. Fading can be toggled with a command, to which a shortcut key may be bound.
