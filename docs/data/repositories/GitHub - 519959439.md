# hydescarf/Obsidian-Theme-Mado-Miniflow

Mado Miniflow is a minimalism Obsidian theme derived from the same author's Mado 11 and inspired by the design of Doctave, letting the reader focus at the centre of the screen rather than spreading out. Its README states that the theme is in maintenance mode, with infrequent updates and no feature or pull requests accepted. Style Settings support is recorded as covering theme colours, basic layout changes, hiding and unhiding elements and some markdown styling, and the README documents Mado CSS classes including a heading class and an explorer class with rules for the markup it accepts.
