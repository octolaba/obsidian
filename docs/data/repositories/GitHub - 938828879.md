# wenlzhang/obsidian-folder-navigator

Navigates to a folder in the vault through a fuzzy search prompt, and expands the target folder once it is reached. Which folders are offered first is configurable between alphabetical order, recently visited folders and frequently visited folders, and the navigation history behind the latter two can be reset. The README explains the motivation as wanting for folders the same quick search that Obsidian offers for files.
