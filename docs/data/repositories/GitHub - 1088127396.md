# DIMFLIX/obsidian-memories

Memories renders images, video and audio from the vault as a gallery inside a note, written as a `memories` code block whose parameters set the source paths, sort order, display type, element size, lazy loading and item limit. The README records a responsive grid with full and compact modes, a lightbox with zoom and panning, interactive thumbnails, keyboard control, an automatic slideshow with a configurable interval, random navigation and thumbnail caching for video files. Sources may be several folders at once, searched recursively or across every media file in the vault, and media can be uploaded and deleted from the gallery itself.
