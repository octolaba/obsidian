# jaskonas/obsidian-rmarkdown

Lets RMarkdown files with `.rmd` or `.Rmd` extensions be browsed, read and edited inside an Obsidian vault without converting them to `.md`. They appear in the file explorer, open in Obsidian's Markdown editor and stay in their own extension, and are indexed so they turn up in search and in the graph view. In reading view each code chunk gets a labeled header bar showing its engine, name and options, and inline R expressions are marked with a badge, with all styling drawn from Obsidian CSS variables so it follows the active theme.
