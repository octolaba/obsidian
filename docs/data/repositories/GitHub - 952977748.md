# Moyf/easy-copy

Obsidian plugin that copies content chosen by where the cursor sits, so placing the cursor inside inline code and running one command copies the text without the surrounding backticks. The same command also handles bold, highlighted and italic text, and it generates and copies a link to a heading or, for a paragraph, creates a block ID and copies the block link. Individual formats can be switched off in the settings, and the README notes that no hotkey is assigned by default and that the interface is available in English, Simplified Chinese and Traditional Chinese.
