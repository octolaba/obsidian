# yllucsyeoj/quackblocks

QuackBlocks makes SQL code blocks in Obsidian executable by running DuckDB compiled to WebAssembly inside the app, with no external server. Tables are loaded from Parquet files declared in a note's frontmatter, and each block's results render inline either as an HTML table or as a chart drawn with Observable Plot in forms such as bar, line, area, dot, heatmap, box and waffle, configured through a compact per-block directive syntax. The README states that charts are emitted as SVG with explicit dimensions so that they survive Obsidian's PDF export, keeping narrative, queries and visualisations in a single document.
