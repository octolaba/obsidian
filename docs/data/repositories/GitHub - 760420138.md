# pj4316/markmap-to-csv-obsidian

This Obsidian plugin converts a markmap into a CSV file. The README states that the outline is read down to heading level two, that lists can be used beneath those headings, and that the conversion is run from the command palette or from a shortcut. It links a video walkthrough and points to another plugin for rendering markmaps themselves.
