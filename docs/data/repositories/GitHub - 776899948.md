# amrojjeh/obsidian-buckwalter

This plugin renders Arabic written in Buckwalter's transliteration scheme. The README gives the syntax as a prefixed inline code span and notes that for internal links the back ticks are dropped, so the prefix is written inside the link itself. It also states that the plugin does not work with live preview, and links qamus.org for more information on Buckwalter's transliteration.
