# Brightwav3/Coding-Agent-Theme

Coding Agent is an Obsidian theme that reskins the whole application chrome — titlebar, tabs, sidebar, file tree, status bar, scrollbars and modals — as one of two identities: a warm near-black Claude Code look with a coral accent, or a cool neutral OpenAI Codex look with a teal-green accent. Every accent-derived token is computed from a single custom property with oklch(), so switching the look or the accent repaints the interface at once, and both looks follow Obsidian's light and dark base colour schemes. The file explorer gets rounded rows with a per-file status dot that fills with the accent on the active note, and h1 to h6 each take their own hue. Its controls live in the Style Settings plugin, and without that plugin the theme falls back to its Claude Code defaults.
