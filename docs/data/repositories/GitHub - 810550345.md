# Windesheim-HBO-ICT/Obsidian-Interactive-Code-Block-Plugin

The Dutch README describes an Obsidian plugin for viewing and testing interactive code blocks by opening a Markdown file in reading mode. It states that the plugin assists in authoring such blocks rather than replacing the actual interactive code block, which Windesheim renders through a separate Quartz plugin; this one exists to write and test the Markdown files during that process. The README cautions that the preview it generates is not identical to the Quartz output, because every code block is made runnable in the preview and blocks cannot be edited there. It then summarizes the shared syntax, where a language followed by a runner or sandbox keyword decides whether a block is runnable, editable, or only rendered as an interactive code block.
