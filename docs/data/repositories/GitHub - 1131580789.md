# maiananthan/tmp-maker

Temp Note Maker creates dated temporary notes in a configurable folder and removes them once they are older than a retention period. Cleanup runs at start-up when the corresponding option is enabled, and can also be triggered from the command palette. A left-side icon creates a new temporary note carrying today's date, and the settings expose the folder name, the retention length in days, and the automatic start-up cleanup toggle.
