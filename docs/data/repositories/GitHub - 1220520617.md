# mashx43/obsidian-tickban

Tickban gathers checkbox tasks from across an Obsidian vault and shows them on a Kanban board without requiring them to be collected into one file. A task's checkbox marker decides its column, an empty box meaning TODO, a slash DOING and an x DONE, and moving a card by drag or through its menu rewrites that marker in the source note. Tags written on a task line appear as badges on its card, and a card's menu jumps to the exact line where the task lives. The scope of collection is set with include and exclude glob patterns, tasks carrying chosen tags can be excluded, and completed tasks can be hidden automatically based on the file's last modified date.
