# wesswart77/obsidian-tasting-notes

Tasting Notes creates structured tasting records in an Obsidian vault, with fields for producer, vintage, nose, palate, finish and a rating. Wine entries add colour and grape varieties, whisky entries add distillery, age statement, ABV and cask type, and the README says beers and other drinks can be logged as well. Any note can be marked as held in the cellar with a quantity and a purchase date, and a sidebar lists all entries under All, Wine and Whisky tabs sorted by rating. The commands are reached from the command palette and the folder holding the notes is set in the plugin settings.
