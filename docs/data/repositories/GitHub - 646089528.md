# sata1000000/NeuBorder

NeuBorder is described as a neumorphic rework of the obsidian-border theme, prioritizing neumorphic design, legibility and keeping distractions away. Its README documents installation from the community themes list, or without it by extracting a release zip into the vault's themes folder. It credits Akifyss for the theme it is based on, and Nichtigott for the neumorphism theme from which code was originally taken.
