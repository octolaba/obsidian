# sbridel/carnet-du-poete

Carnet du Poete is an Obsidian writing companion for French verse with real-time syllable counting, scansion, metre, and rhyme-gender detection. It also offers rhyme suggestions, quality filters, thematic vocabulary, synonyms and antonyms, Markdown export, and an optional alternate view for ambiguous hiatuses.
