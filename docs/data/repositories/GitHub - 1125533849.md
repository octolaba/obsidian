# davidvkimball/obsidian-image-manager

Image Manager inserts, renames and sorts images inside Obsidian notes, and its README describes it as unifying functionality from several separate image plugins into one. Images can be chosen through the operating system's file picker, searched and downloaded from Unsplash, Pexels and Pixabay with filters for orientation and size, or pasted and dragged in, and they can be inserted into note content or directly into properties. On insertion the plugin can prompt to rename the file or to supply a description used both as display text and as a kebab-case filename, handles duplicate filenames by numbering them, and supports template variables such as `{{fileName}}`, `{{dirName}}`, `{{DATE}}` and `{{TIME}}` in names. It is described as part of the author's Vault CMS project.
