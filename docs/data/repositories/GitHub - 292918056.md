# dmytrodubinin/Obuntu-theme-for-Obsidian

Obuntu is an Obsidian theme inspired by and borrowing elements from Ubuntu, aiming for deeper integration with that Linux distribution. It ships light and dark variants, the Roboto and Fira Code typefaces, coloured tags in edit view and in the tag panel, indentation lines, custom checklists, more expressive tables and adjusted vim mode colours. A Clutter Free edit mode hides most inline formatting hashes outside the active line, while code blocks, list markers and HTML tags keep their previous behaviour. The README credits cannibalox's Obsdn-dark-rmx theme for several of the ideas used here.
