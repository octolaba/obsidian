# towishy/Owen-Graphite

Owen Graphite is a liquid-glass Obsidian theme for technical documentation, knowledge bases and report-ready notes, keeping Korean and English typography, long tables, code blocks, workspace chrome, Style Settings controls and PDF export layouts on one graphite surface across Live Preview, Reading View and print. The README states that the Style Settings schema and the English and Korean metadata stay inside the theme, while an optional companion supplies the Style Settings locale fallback and structures title and metadata tooltips, and a separate editor plugin adds persistent code-title editing, code copying and Frosted ScrollArea controls. Report and PDF handoff is covered by header and footer labels, page numbering and page-break guards. The recorded repository description is written in Korean.
