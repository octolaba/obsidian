# renhao-wan/obsidian-dashboard

O-Dashboard gathers several sections onto one page: a memo pad of writable cards, an interactive todo checklist with a progress bar, project cards that link vault documents and show a cover image, a compact list of reference notes, and a month-grid calendar of dated tasks. The README states that the calendar is native, needing no query plugin, that multi-day events span days through start and end fields, and that a full-screen view adds month navigation and inline toggling. Quick actions pin file links and Obsidian commands to the sidebar, and wiki links render as clickable links inside memo cards and todo items.
