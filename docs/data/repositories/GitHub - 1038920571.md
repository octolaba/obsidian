# NellowTCS/Obsidian-IroView

IroView previews HEX, RGB and HSL colour values inline in Obsidian notes, in the manner its description compares to VSCode's colour preview. It recognises three-, four-, six- and eight-digit HEX forms along with rgb, rgba, hsl and hsla notation, and works in both editing and reading views. Settings toggle the colour swatch, colourization of the value text and which formats are recognised, and the README states that text is colourized only when contrast remains readable. It is built with TypeScript and CodeMirror 6 and detects colours with regular expressions.
