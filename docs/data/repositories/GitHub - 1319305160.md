# 0libote/integrated-archive

Integrated Archive moves notes into an archive folder instead of deleting them, from a command or an optional file-menu action, singly or across a multiple selection. Delete can be set to ask each time with an Archive, Delete or Cancel prompt, to archive automatically, or to fall through to Obsidian's normal delete, and files already inside the archive always use the normal delete flow. The archive folder is configurable and can keep the original folder structure, an archive tag and archived, created and last-edited dates can be written to frontmatter, and names collide safely rather than overwriting anything. Restoring returns a file to its recorded original path and reverses the metadata archiving added, an undo command restores the most recent archive, and the plugin works locally and requires Obsidian 1.13 or later.
