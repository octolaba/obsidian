# jeremyoverman/obsidian-slackify-note

Slackify Note converts Obsidian Markdown into the Markdown that Slack accepts. Two commands are recorded: copying the whole note as Slack Markdown, and copying the current selection as Slack Markdown. The README illustrates the conversion with a before-and-after pair of an Obsidian selection and the resulting Slack message.
