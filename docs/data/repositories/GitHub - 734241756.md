# sundevista/youtube-template

YouTube Template creates a note about a YouTube video from a configurable template, through a single command that takes the video URL. The template folder, the template itself and the formats used for chapters and hashtags are chosen in the settings. The README records that a Google Cloud API key with the YouTube Data API v3 enabled must be pasted into the plugin settings for it to work, and lists the URL shapes its regular expression recognises, among them watch links, user and embed paths, timestamped links, youtu.be links and Shorts.
