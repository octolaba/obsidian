# jenningsb2/copy-as-html

Copy as HTML converts the selected Markdown to HTML using showdown and copies it to the clipboard through a single command. The README suggests it for sharing notes on platforms such as Slack and Google Docs, which keep the original formatting when HTML is pasted into their text areas. It opens with a caution from the author that the project is no longer actively worked on and that issues will not be corrected.
