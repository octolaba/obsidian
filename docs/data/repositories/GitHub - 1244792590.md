# rodrigolourencofarinha/obsidian-todoist-bridge

Todoist Bridge links selected Markdown tasks to Todoist through a hash-todoist marker on the task line: adding the marker to an unchecked task creates the Todoist counterpart, and completing, reopening or renaming the task on either side updates the other. The README states that the plugin deliberately avoids destructive deletion, so when one side disappears or loses its marker the surviving task is detached and annotated instead of being completed or deleted. It records Obsidian 1.12.7 or later, a Todoist account and API token, and network access as requirements, and asks that the token be held in an Obsidian SecretStorage entry rather than the plugin's data file. Those entries are device-local so each device must be set up separately, and mobile operating systems may suspend the automatic sync timer.
