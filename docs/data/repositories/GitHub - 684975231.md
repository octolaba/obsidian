# pbrw/obsidian-size-history

Size History draws the growth of a vault as a hand-drawn style chart, opened from a line chart icon in the left panel. The only metric available is the number of files in the vault, tracked by day; the history from before installation is reconstructed from file creation times, so files deleted earlier leave no trace, although deletions are tracked from installation onwards. The chart is drawn with chart.xkcd, and the README states that the plugin sends nothing over the internet.
