# pjeby/hot-reload

Hot-Reload watches the `main.js`, `styles.css` and `manifest.json` files of Obsidian plugins under development and disables and re-enables a plugin once its changes have stopped for about three quarters of a second. A plugin is watched when its directory contains a `.git` subdirectory or a file called `.hotreload`, so no watch list has to be maintained by hand. The README notes that the plugin can enable plugins that are not currently enabled in settings, and that cleaning up in `onunload()` remains the developed plugin's own responsibility.
