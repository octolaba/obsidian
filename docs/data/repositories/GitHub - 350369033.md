# vslinko/obsidian-outliner

The repository holds Obsidian Outliner, a plugin that makes list editing behave in the manner of Workflowy or RoamResearch. Its README records compatibility with the Zoom plugin by the same author and covers installation from the community plugin browser or by placing a release's script, manifest and stylesheet into the vault's plugin folder. It is written in TypeScript under the MIT license.
