# hish-math/obsidian-ai-hub

AI integration Hub sends the text selected in an Obsidian note to an AI service as a prompt and replaces that selection with the generated content. Generation is started from a ribbon button or from the Generate content command in the palette. The README documents entering a Google AI Studio API key and choosing a model, such as gemini-1.5-flash, in the plugin settings.
