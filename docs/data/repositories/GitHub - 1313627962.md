# ChenGou-zheng/obsidian-ridiculous-coding

Adds animated feedback to the editor: colored blips when characters are typed, explosion effects on deletion, screen shake that responds to typing intensity, newline animations, sound effects and fireworks on level-up. Typing earns experience points on a progressive leveling curve, shown in the status bar and in a sidebar control panel that also carries quick toggles for the individual effects. Every effect can be switched off separately in settings, shake amplitude and the base XP curve are adjustable, and a reduced-effects mode disables the visuals and audio while keeping the XP tracking. Its credits name a Godot plugin by John Watson and a VS Code port of it as the origin.
