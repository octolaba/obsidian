# battlecook/omni-viewer-obsidian

Omni Viewer opens and, for some formats, edits archives, audio, video, images, tabular data, documents, source formats, models, and other files directly in Obsidian. It includes waveform and image tools, PDF editing, CSV write-back, LaTeX and model inspection, content-signature routing, and optional expiring file sharing. Core-supported extensions may require an explicit Open with Viewer action, and mobile uses vault APIs with a narrower set of capabilities than desktop.
