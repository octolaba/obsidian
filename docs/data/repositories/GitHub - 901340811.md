# brianpetro/smart-context-obsidian

Smart Context copies the notes, links and source material an AI request needs onto the clipboard, so the context does not have to be reassembled by hand each time. Its recorded guidance is to start from the current note at depth 0 and to add directly linked notes at depth 1 only when they carry details the request needs, while a set that keeps being rebuilt can be saved as a named context. Copied output goes through templates that can include source paths, depth, modified times and a file tree, so the assembled context can be inspected, and the README describes the plugin as clipboard-first and built for local-first Obsidian workflows.
