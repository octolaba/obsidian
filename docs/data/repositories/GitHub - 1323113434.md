# luffysolution-svg/obsidian-knowledge-sync

Markdown Relay publishes Obsidian Markdown one way to Feishu or Lark, Notion and ima, treating the local note as the only content source; remote edits are never merged back. A first publish creates a Docx document in a chosen Feishu target, a page under a chosen Notion parent, or a new ima note; later publishes revalidate the remote state before replacing the body, protect Notion child pages and databases, and always create another ima note. Publishing starts from a ribbon icon, the file context menu, the multi-file menu or a command, can cover several notes and platforms at once, and reports per-item failures with a retry for failed items only. Each platform writes its own URL or note ID back into frontmatter, credentials are kept in Obsidian's secret storage, and no reverse sync, directory mirroring or forced overwrite is offered.
