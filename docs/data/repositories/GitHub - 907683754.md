# Hwenyi/obsidian-type-chinese-like-english

This plugin converts pinyin typed in English input mode into Chinese characters and LaTeX mathematics, so the writer need not switch input methods or work through an input method's candidate list. A single command converts the current line or the selected text and replaces it with the generated result. Conversion relies on a large language model reached through a configurable base URL and model name and requires a valid API key, and the settings control whether the note's context is sent along and whether natural-language descriptions of formulas are turned into LaTeX.
