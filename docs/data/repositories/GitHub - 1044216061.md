# asyouplz/SpeechNote

Repository for a speech-to-text plugin that converts audio recordings into text inside Obsidian. The README records transcription through OpenAI Whisper and Deepgram Nova 3, automatic provider selection per file, speaker diarization that labels separate speakers, and support for M4A, MP3, WAV, MP4, WebM, OGG and FLAC files. It also lists automatic language detection across more than forty languages and insertion of the result at the cursor, at the start or end of a note, or into a new note when no editor is active. The README is written in English and Korean.
