# Canna71/obsidian-janitor

The recorded description says the plugin performs various maintenance tasks on an Obsidian vault. Per the README it targets orphan media and attachments that nothing references, including references made from frontmatter, files that are empty or consist only of whitespace, files above a configurable size limit, and notes whose configurable frontmatter expiration attribute has passed, in the manner of the Obsidian Expiring Notes plugin; a utility command helps set those expiration dates. Exclusions can follow Obsidian's own excluded-files setting or separate criteria such as file extension or path. A scan can run at startup, from a ribbon button or from a command, and with confirmation enabled the user chooses which files to remove and whether to trash them in Obsidian, trash them in the operating system, or delete them permanently.
