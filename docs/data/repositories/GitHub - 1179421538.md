# joeytoday/obsidian-blog-publisher

Blog Publisher publishes Obsidian notes to a blog hosted in a GitHub repository, and the README states that it is a modification of Obsidian Digital Garden. A note is marked with a frontmatter key and published singly, in bulk, or through a publishing centre showing which notes are published, changed or pending; only marked notes are sent and linked notes are not published automatically. The README lists support for wikilinks, embeds, Dataview queries, Canvas, Excalidraw, images uploaded after hash comparison, PDFs up to 20 MB, callouts, MathJax, Mermaid and PlantUML, with frontmatter passed through and permalink and blog-path fields generated. The repository description and the documentation read here are in Chinese; this summary restates what they describe.
