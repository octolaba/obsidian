# kevinlangleyjr/obsidian-slatewave

Slatewave is a dark Obsidian theme on a slate foundation with a teal signature, part of a wider palette family covering editors, terminals, prompts and notes. The README states that it is written from scratch against Obsidian's public CSS variable API with no upstream theme dependencies. It tunes a teal heading cascade, pink bullet markers, accent states for the active file, active tab, cursor, checkboxes and outline selection, link colors that separate resolved, unresolved and external targets, inline and fenced code, callout colors for tip, success, warning, error, example and quote, a teal active-tab indicator and the status bar. Both dark and light modes are included, with dark as the primary target.
