# Quorafind/Obsidian-Big-Calendar

Big Calendar adds month, week, day and agenda calendar views to Obsidian, built on React Big Calendar and driven by the content of daily notes. It parses tasks carrying a time or a time range and plain time blocks such as `- 19:00 Dinner with family`, displays them as events, opens the originating note when an event is clicked, and updates as files are created, modified or deleted. Its settings choose Sunday or Monday as the first day of the week, the heading after which new events are inserted, the section below which entries are processed, and the event display format.
