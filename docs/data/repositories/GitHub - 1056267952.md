# exusiaiwei/yet-another-memos-sync

Synchronises Memos entries into Obsidian daily notes. The README describes incremental sync that updates only changed content, a configurable day limit defaulting to 30 days, detection and removal of deleted memos, and synchronisation on startup or on a timer. Output is formatted either as a list-callout style with an emoji timeline or as card-style callouts, and both modern and legacy Memos API versions are supported. It is presented as a reworking of the earlier obsidian-memos-sync plugin.
