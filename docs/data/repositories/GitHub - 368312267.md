# elias-sundqvist/obsidian-static-file-server

Obsidian plugin that hosts subfolders of the vault as static file servers. A folder name and a port number are entered in the plugin settings, after which the files in that folder can be displayed inside the vault through an iframe. The README gives the reasons as embedding websites that work offline, embedding sites that would otherwise run into CORS problems, and reaching vault files from other applications; its changelog records that ports are validated before the servers start and that the folder path is written without a leading slash.
