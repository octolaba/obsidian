# 0utsights/obsidian-contextual-vocabulary

The repository holds Contextual Vocabulary, an Obsidian plugin that turns a highlighted word into a dictionary entry built from the sentence around it. It generates a contextual definition and a usage review, links the selected text to that entry, and keeps an alphabetical index of the entries. The README states that setup requires an API key, an endpoint, a model and the vault-relative path of the dictionary note.
