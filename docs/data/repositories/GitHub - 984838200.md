# masoniis/obsidian-syncable-dictionary

Obsidian Syncable Dictionary makes the native desktop spellcheck dictionary syncable by keeping a global custom-word list in the vault configuration area. It relies on a separate sync service, checks local and external changes periodically, and uses merge or replace behavior with a safeguard when replacement would remove many local words.
