# antoKeinanen/obsidian-advanced-merger

Obsidian Advanced Merge merges a folder of notes into one file, which the README presents as making export easier. The documented interaction is a single one: right-click a folder and select merge folder. Installation is from the community plugins tab or by copying manifest.json and main.js into the plugin folder by hand, and the contributing section suggests developing against a separate vault and toggling the plugin off and on to refresh it.
