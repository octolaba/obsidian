# st-vin/obsidian-lexicon-dictionary-plugin

Obsidian plugin for looking up words and building vocabulary with flash card style cards. It searches the Wordnet dictionary, inserts definitions through customizable templates, and can save looked-up words either to a dedicated vocabulary file or to a glossary section at the end of the current note, with lookup and save also reachable from the right-click context menu. Saved vocabulary is reviewed through periodic flashcard popups. The README notes that on first initialization the plugin downloads a dictionary JSON file of more than 5MB from an external source and caches it locally, so the initial download requires an internet connection.
