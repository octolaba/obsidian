# senjanson/obsidian-scroll-anchor

Scroll Anchor remembers the scroll and cursor position of every note and restores all open tabs when Obsidian restarts, not only the last active one. The README states that positions are saved for editing and reading modes alike into a JSON file inside the vault, written continuously while reading — every 200 milliseconds for the active tab and flushed to disk every five seconds — as well as on tab switches, when the app goes to the background and on quit. That save strategy is described as deliberately aggressive for iOS and Android, where the system may kill the app, and the save interval, restore delay and maximum number of stored entries are configurable.
