# initialneil/obsidian-neat-file-tree

This repository holds Neat File Tree, an Obsidian plugin that adds VSCode-style sticky folder headers, accented top-level folders and tinted indentation guides to the file explorer. Parent folders pin to the top as the tree scrolls, stacked by depth, while folder names, their bar and the indentation guide lines are coloured by depth from one of six schemes chosen with a live preview in settings, and top-level folders stay bold. Each feature has its own toggle, a row-height field keeps the sticky headers aligned when a larger interface font is used, and the README records the implementation as pure CSS.
