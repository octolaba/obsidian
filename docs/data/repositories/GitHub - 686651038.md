# 1612elphi/autotape-theme

1612elphi/autotape-theme holds Autotape, described as a minimal Obsidian theme meant to invoke old-style terminal interfaces without looking dated. It is designed for dark mode but the README records it as compatible with either mode, and it follows the accent colour chosen in Obsidian's appearance settings. Fonts are not bundled: the README asks users to bring their own typefaces and names the one shown in its screenshots, and it credits the Brutalism theme by abrahambahez as inspiration.
