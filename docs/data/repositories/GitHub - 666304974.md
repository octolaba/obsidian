# MrGVSV/obsidian-better-comment-toggle

The repository records no description, so this note is grounded in the README alone. Better Comment Toggle replaces Obsidian's comment toggling, working line by line or over a selected range, preserving indentation, and handling code and math blocks including custom languages. The comment start and end tokens are configurable — HTML comments by default, with Obsidian's `%% %%` style or a custom pair as alternatives — and the appearance of commented lines can be restyled. The README states the plugin is entirely WYSIWYG: no hidden tags or metadata are written into notes and the styling exists only in the editor.
