# mihakralj/obsidian-textanalysis

Obsidian Text Analytics gives real-time feedback on the readability, structure and style of the text being written, combining several established readability indicators. The README documents each indicator it reports and how to read a value, starting with character count taken after Markdown formatting is removed, letter count over visible glyphs only, Unicode word count, and sentence count. For several of them it records the ranges the author treats as typical or clear, for example 100 to 500 words for a clear text against 300 to 5,000 words for most published writing.
