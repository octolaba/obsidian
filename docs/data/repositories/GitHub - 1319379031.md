# czk200518-hash/Typelog

TypeLog records two figures for every file edited: net output, which grows only when the file actually gains content, and total input, which counts every character typed including those later deleted. It also tracks active time, pausing after a configurable idle period, typing speed as characters per minute over a rolling 60-second window plus the session peak, and daily and weekly word and time goals shown as progress rings. A stats window and status bar surface the numbers, with a calendar heatmap of typing hours, daily bar charts over the last 7 or 30 days, and a ranking of the files with the most time or characters. Data stays on the machine and can be exported as JSON, CSV or a Markdown report, or backed up to a single file and merged back later.
