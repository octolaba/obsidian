# adoveil/obsidian-silence-theme

Silence is a clean, quiet Obsidian theme that takes its colors from the accent color set in Obsidian rather than defining its own palette. The interface is set in Hanken Grotesk and note text in Ibarra Real Nova, with font sizes and line heights derived from a 1.06 minor second scale so type sizes stay in proportion. It exposes no Style Settings options and is installed from the theme browser in Obsidian's appearance settings.
