# robisonweb/phantom-flow

Phantom Flow is a dark Obsidian theme with Roboto typography bundled locally so it works offline, a background in deeper and cooler tones than a standard Nord palette, and gradient-colored top-level folders in the file explorer with a larger title font. Three color palettes, Nord as the default plus Sunset and Forest, are switched live through the Style Settings plugin with no reload required. The README documents copying the Phantom Flow folder into the vault's themes directory, and the theme is GPL-3.0 licensed.
