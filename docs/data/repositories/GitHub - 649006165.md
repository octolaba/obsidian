# saket61195/Dracula_obsidian_theme

Dracula Plus is a dark Obsidian theme based on the Dracula palette, which its README describes as compatible with desktop, tablet and mobile and which follows the accent colour chosen in the appearance settings after a restart. Its main addition is a wide set of alternate checkbox markers covering incomplete, cancelled, rescheduled, scheduled and timed tasks along with a further list of annotation markers, with the checkbox designs credited to the obsidian-things theme and the base credited to jarodise's Dracula for Obsidian. Installation is documented in the older style, by placing an obsidian.css file in the vault root folder with the Custom CSS option turned on. The README states that the theme is provided as is for personal use, has not been tested on all platforms, and that white theme settings will not work, with no current plan to add them.
