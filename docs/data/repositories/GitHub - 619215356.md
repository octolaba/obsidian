# clementpoiret/ai-mentor

Obsidian AI Mentor adds an agent named Alfred that reviews a note's writing and formatting inside Obsidian. The README states that from version 1.1.0 it can call both OpenAI and Perplexity APIs, so models beyond GPT-4 Turbo — Llama2 or Mixtral 8x7b — are usable, and that the online Perplexity models answer from current web sources. It also describes asking for advice in the voice of figures such as Socrates or Steve Jobs, explaining a selected passage, drafting text from a bullet-point list, and correcting written text.
