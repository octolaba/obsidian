# ouou365/Semlink

Semlink indexes Obsidian vault notes for semantic search and provides a sidebar conversational assistant with retrieved context, tool traces, and cited sources. The agent can search, grep, read, inspect the active note, manage indexed content, and expose search and read tools through an HTTP MCP server for external AI clients. Real-time indexing, sliding-window conversation history, and an optional Feishu bot extend the workflow beyond the local chat panel.
