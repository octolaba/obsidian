# ouou365/Semlink

Semlink vectorises the notes of an Obsidian vault and exposes semantic search over them through a Model Context Protocol server, so external AI clients can search and read the vault. The README lists seven MCP tools covering natural-language search, fetching a whole note or the content under one heading, finding notes similar to a given one, listing indexed notes, reporting indexing status and triggering a reindex. Its pipeline is recorded as chunking note text, embedding it through a hosted embedding API, storing the vectors locally in SQLite with a binary sidecar, and serving them over a local HTTP MCP server, with file changes detected and the index updated as they happen.
