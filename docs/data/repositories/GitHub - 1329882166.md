# bobstanton/places-leaflet

A map provider for the Places plugin backed by Leaflet, drawing raster maps with markers, tracks and overlays. Tiles come from the tile server of the selected built-in style, one of OpenStreetMap, OpenTopoMap, CartoDB or Esri, or from a custom XYZ tile URL. Leaflet renders the map surface, map, overlay and routing code comes from places-shared, and no background tasks run.
