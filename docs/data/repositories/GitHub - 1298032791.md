# NoteNerdOfficial/terminus

Terminus embeds a real PTY-backed terminal in Obsidian, supporting multiple concurrent shells, persistent working directories and scrollback, path and URL opening, drag-and-drop path insertion, and wiki-link autocomplete. It integrates with the local Claude CLI by explaining failed commands and collecting immediate file edits in a Pending Changes panel with line-numbered diffs and Accept, Reject, or Open actions; edits are written to disk for review.
