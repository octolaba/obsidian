# NoteNerdOfficial/terminus

Terminus embeds a PTY-backed interactive shell in Obsidian and wraps a review layer around what a coding agent run inside that shell changes. The README records that a failed command gets a badge beside it which asks Claude to explain the failure and propose a fix using the surrounding command history, and that every file an edit touched appears in one Pending Changes panel with a line-numbered per-file diff and Accept, Reject and Open actions. It states that edits land on disk immediately and are reviewed afterwards with the option to revert, and that what the user types is neither wrapped nor intercepted. The recorded description adds that the plugin drives the user's local Claude command-line tool.
