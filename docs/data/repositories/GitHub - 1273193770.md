# tektrg/obsidian-ai

Desktop-only Obsidian plugin that adds an AI chat sidebar with streaming responses, active note context, file mentions and a multi-file diff review interface. Sign-in uses Claude Max OAuth with an Anthropic API key as fallback, or ChatGPT Plus and Codex OAuth, so the account required depends on the provider selected. The README discloses that prompts, note context, selected text, mentions and responses may be sent to Anthropic or OpenAI, that keys, OAuth and refresh tokens, model choice and session identifiers are stored in this vault's plugin data, and that when asked to edit notes the bridge may let the agent modify vault files, so generated diffs should be reviewed. It also states that no client-side telemetry is collected and no advertising is displayed.
