# Jefrry/obsidian-em-dash-replace

Em Dash Replace converts a space followed by two dashes into an em dash as the user types in Obsidian. The README states that the replacement is skipped inside code blocks and inline code so code formatting is preserved, and that the plugin works on both desktop and mobile.
