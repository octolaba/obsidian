# a-nano-dust/dust-obsidian-calendar

Obsidian plugin providing a calendar built around Chinese conventions, showing the Gregorian and lunar dates together with weekdays, solar terms, public holidays and adjusted working days, and switching between a month and a year view. It also creates periodic notes linked to the calendar — daily, weekly, monthly, quarterly and yearly — from a configured path template using luxon format tokens, and can apply a template through either the core Templates plugin or Templater. Font size can follow Obsidian, follow the sidebar width or be fixed, and quarters can be named by number or by season.
