# Binaris00/Theme-Controller

Theme Controller decides when and which Obsidian theme is displayed. It adds a status bar icon that toggles light and dark mode, applies a specific theme and color scheme according to the path of the active note, and can set themes and colors for tags found in that note. A default theme and color can be defined for notes matching no path or tag rule, which the README records as disabled by default.
