# dy-sh/obsidian-unique-attachments

Unique attachments renames attachment files after an MD5 hash of their content, so identical files receive identical names and two files sharing a name can be assumed to be copies. One command renames every attachment in the vault and updates the links in all notes that used them, while another renames only the attachments linked from the active file. The README states that the vault-wide command works only with standard Markdown links and not with wikilinks, whereas the active-file command handles all link kinds, and it records options to restrict renaming to linked attachments and to delete duplicate files that sit in the same folder.
