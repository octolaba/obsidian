# rmccorkl/TubeSage

TubeSage converts YouTube videos into structured notes using large language models: it extracts a transcript, generates a summary and can add timestamped links back to particular moments in the video. The README requires Obsidian 1.11.4 or later, because the plugin stores cloud API keys through the secret storage introduced in that version, and the Templater plugin for template-driven formatting. It also requires an API key for at least one of the listed providers, among them OpenAI, Anthropic, Google, OpenRouter and local models through Ollama, with a YouTube Data API key needed only for channel and playlist processing, and it states that license terms must be accepted in the settings panel.
