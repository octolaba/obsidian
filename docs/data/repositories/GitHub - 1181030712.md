# anupchavan/adaptive-practice

Obsidian plugin that generates practice questions from notes and PDFs with a language model and schedules them by spaced repetition. It keeps a lightweight vault index of frontmatter, tags, links, headings, file stats and embedded media references, and reads selected notes more deeply at generation time, including outline, bounded section excerpts and supported attachments. Review is fluency-aware, using correctness, skips and response time to detect fragile recall, and a dashboard shows streak, due notes, scan status and a one-click daily practice. API keys live in Obsidian secret storage with a separate configurable slot per provider, covering Gemini, Anthropic, OpenAI, DeepSeek, Qwen, OpenRouter, local Ollama and other OpenAI-compatible endpoints.
