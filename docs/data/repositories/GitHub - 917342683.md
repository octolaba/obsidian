# webtechaccess/obsidian-heatmap-calendar

Codeless Heatmap Calendar generates a heatmap calendar in Obsidian from Toggl time tracking data, or from fake data so that it can be tried without a Toggl API key. The README states that DataviewJS is required for its data handling and rendering. Appearance is configurable through predefined or user-defined themes, intensity colors given as named colors, hex codes or gradients, font styling, cell size, padding, border radius and spacing, and tooltip background and text colors.
