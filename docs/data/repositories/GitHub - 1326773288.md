# freewheelerz/obsidian-mathvoice

Opens a right-side panel that embeds the MathVoice Studio, a web application for editing LaTeX by voice or typed commands. Placing the cursor inside inline or display math loads that formula into the panel automatically, and applying the result replaces the original math range in the note as a single undoable edit. Delimiters are stripped before loading and restored on write-back, so only the inner LaTeX is edited, and a setting points the panel at a self-hosted Studio URL.
