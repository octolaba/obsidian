# jensen-zheng-cmd/Recto-plugin

Recto imports papers from a local Zotero library into Obsidian with their collection tree and PDF attachments, then converts the PDFs to Markdown that keeps numbered formulas, tables and figure placement. Translated Chinese text is bound paragraph by paragraph to the English original for synchronized two-column reading, and clicking a translated paragraph moves the PDF pane to the matching page and highlights the region. Conversion can also produce a summary note whose properties record title, authors, year, journal, keywords and category, with the original text and PDF embedded as links. Conversion, summarization and translation run on the Recto cloud service and require a free account; the plugin is desktop-only, its interface is Chinese only, and output is stored per paper in the vault.
