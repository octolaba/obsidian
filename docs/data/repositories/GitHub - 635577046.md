# Rooyca/obsidian-api-request

APIRequest issues API requests from inside an Obsidian note and displays the response in a code block, with request caching, variable support and JSON extraction. The README lists the security measures it applies — input validation for URLs, paths and user data, protection against directory traversal, safe JSONPath evaluation and XSS prevention — and keeps the usage documentation on an external site rather than in the repository. The plugin is installed from the community plugin browser.
