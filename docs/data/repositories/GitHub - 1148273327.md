# akhmialeuski/advanced-audio-recorder

Obsidian plugin for recording, playing back, editing and transcribing audio inside the vault. Recording supports pause and resume, stereo or mono capture, automatic splitting of long sessions, crash recovery and up to eight simultaneous input devices, while playback uses an inline waveform player with bookmarks, chapters and clickable timestamps. Files can be split or converted between WAV, MP3, FLAC, OGG, WebM and MP4, and transcription runs against OpenAI-compatible Whisper hosts, Deepgram, Google Gemini or a local whisper.cpp model, optionally adding speaker labels and an AI summary. The README states that audio stays in the vault, that Obsidian 1.6.6 or newer is required, and that multi-track recording, automatic splitting, local whisper.cpp and input-device selection are desktop-only.
