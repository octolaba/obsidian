# jsun2020/hermes-agent-obsidian-plugin

The repository holds an Obsidian plugin for chatting with a locally installed Hermes Agent from a multi-tab sidebar panel, sending the current note or the selected text as context. The README records that the plugin talks only to the local Hermes gateway over its HTTP API rather than to the desktop application, detecting capabilities first and then using the runs transport, which carries tool, reasoning and usage events, or falling back to an OpenAI-compatible streaming chat completions endpoint. Authentication is a bearer key pasted into the plugin settings and taken from the gateway's own environment file. The README describes two ways to have the gateway running — through Hermes Desktop, or by enabling and starting the API server from the command-line install — and notes that the interactive terminal interface is not the gateway.
