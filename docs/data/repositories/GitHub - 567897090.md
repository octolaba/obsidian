# zorazrr/obsidian-link-opener

The repository holds an Obsidian plugin that decides where an external link opens. Its README records that the method is chosen in the settings and that the width and height of the modal used for in-app opening can be adjusted. Manual installation by copying the built script, stylesheet and manifest into a plugin folder is also documented.
