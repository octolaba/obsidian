# gengyabc/obsidian-pi-plugin

PiChat runs a chat with the Pi coding agent inside Obsidian, rendering the conversation as native Markdown with code highlighting, Mermaid diagrams, callouts and vault links. Its README records the plugin as desktop-only, requiring Pi installed locally, and states that it reads Pi's configuration directory under the user's home folder to discover providers, models and session history. The chat view supports streaming with live rendering, collapsible thinking blocks and tool results, steering messages sent while the agent works, aborting mid-stream, pasted images and file attachment. Session management covers browsing, searching, switching, deleting and exporting Pi's own session files, persistence across restarts, and saving conversations into the vault as notes.
