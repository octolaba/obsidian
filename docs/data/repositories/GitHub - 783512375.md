# Donovan-Ye/obsidian-ai-writer-plugin

This plugin generates articles from the knowledge fragments in Obsidian notes by calling a language model API; the README states that only OpenAI is supported so far, although the settings are shaped for several providers, models and target languages. Generation is triggered from a command or the right-click menu and can follow a custom article template. The generated article can be edited in the editor and, in one action, replace the original note.
