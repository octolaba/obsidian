# Ordeeper/obsidian-journaling-plugin

The recorded description says the plugin displays daily notes in a journal-like format similar to Logseq, consolidating them into a continuous journaling view for easier reflection. Per the README it scans one or more configured directories for Markdown files whose names follow a user-defined date format, so conventions such as year-month-day or month-day-year are both usable, and gathers them into a journaling file whose name the user sets. Entries can be sorted and filtered by date as newest or oldest first, and the interval at which the view updates to reflect file changes is configurable.
