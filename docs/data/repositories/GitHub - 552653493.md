# royxue/obsidian-things3-sync

This plugin creates Things 3 todos from lines in an Obsidian note, on both macOS and iOS. Tags can be typed after the todo text or taken from a default in the settings, and a date found in the note is carried over to the todo. The README is explicit that the sync is one-way: creating a todo and toggling its status are triggered from Obsidian, while completing or editing the task in Things 3 does not update the note.
