# ccmdi/smart-link-formatter

Smart Link Formatter rewrites pasted links into formatted Markdown filled with metadata about the target, with explicit support recorded for YouTube, Twitter or X, Reddit, YouTube Music, GitHub and image links. The format string is customizable for each client and for ordinary links, where the first pair of square brackets becomes the hyperlink and variables such as the page title and address are substituted; a YouTube link additionally exposes channel, uploader, duration, views, upload date, description and timestamp, and a date variable can be given a moment.js format. Domains can be blacklisted, automatic linking can be switched off, and regular-expression replacements can be applied to the formatted text.
