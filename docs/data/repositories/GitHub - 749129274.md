# Developer-Mike/obsidian-advanced-canvas

Advanced Canvas extends the Obsidian canvas along several axes. Its core changes keep compatibility with the JSON Canvas format while introducing an extended variant, wire canvases into the metadata cache so they appear in graph view, outgoing links and backlinks, allow frontmatter properties on canvas files, create edges between file nodes from those properties, and let a single node be linked or embedded in a Markdown file. Further groups cover default node sizes and grid alignment, finer control in readonly mode, PNG and SVG export with transparency, and node templates saved for reuse. The README names flowcharts, presentations and interconnected knowledge as the intended uses.
