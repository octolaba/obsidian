# ggauravr/obsidian-serendipity-plugin

Serendipity displays a random note from the vault in a modal each time Obsidian is opened, which the README presents as a way to revisit past journal entries and older learnings. Settings name a directory to pick random notes from and a directory to exclude, both given as paths relative to the vault root. The modal follows the active Obsidian theme and offers a direct link that opens the source file of the displayed entry in a new tab.
