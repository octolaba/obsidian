# 853014750littleyellow-code/obsidian-picote

Picote is a column-layout plugin for Obsidian built around collecting images by dragging them into columns rather than pasting them. Its Chinese README describes sniffing remote image addresses, downloading them quietly, renaming them and rewriting the reference to a local embed, with a dedicated path for links carrying no extension or blocking hotlinking, and paced write-back to reduce stutter during frequent edits. A later entry records single-click image zoom in both the note body and the columns, with wheel zooming, a finer step while Ctrl is held, and closing by Escape, the corner button or the dark backdrop. Most of the README is a version-by-version changelog with upgrade instructions.
