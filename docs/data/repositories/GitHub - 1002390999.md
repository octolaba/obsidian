# chrishoward-projects/related-notes-by-tag

Related Notes by Tag displays notes that share tags with the active note in an Obsidian sidebar panel and refreshes as the active note changes. Results can be sorted, filtered by the number of matching tags, grouped, shown with titles or excerpts, and narrowed by excluded folders or tags.
