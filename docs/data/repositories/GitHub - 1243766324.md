# ksawl/obsidian-minder-nexus

Minder Nexus records typed relationships between notes, written either through the built-in alias syntax on a link or as a Dataview inline field, and checked against a list of trusted types configured in its settings. Semantic links get type-specific badges in Reading mode, are shown while typing in Live Preview, keep native hover previews, and are marked visually when they lead to a note that does not exist. A Sync Master module writes the reverse relationship into the target note's properties, a dedicated view groups backlinks by their semantic type, and a vault-wide watcher scans for broken semantic links.
