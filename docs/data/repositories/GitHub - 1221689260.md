# green-dalii/obsidian-llm-wiki

Karpathy LLM Wiki turns Obsidian notes and PDFs into a connected, queryable knowledge base inspired by the Karpathy LLM Wiki concept. It uses local-first, zero-embedding graph retrieval to create linked entity and concept pages and support graph-powered questions, with integrations for multiple model providers and languages. The project describes a privacy-oriented design without a backend and a built-in editor workflow.
