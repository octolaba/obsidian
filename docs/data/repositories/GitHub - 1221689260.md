# green-dalii/obsidian-llm-wiki

This plugin implements the Karpathy LLM Wiki idea inside Obsidian, turning notes and PDFs into a linked knowledge base of entity and concept pages that can be questioned. Retrieval runs over the graph of those pages rather than over embeddings, and the README describes the plugin as local-first with no backend of its own. It states that the plugin works with every model provider and ships interface text in ten languages, and it credits the original LLM Wiki description by Andrej Karpathy.
