# sourit2001/Obsidian-dashboard

The repository records no description, so this body rests on the README alone. The README describes a card-based dashboard for Obsidian desktop and mobile whose cards act as configurable navigation targets. It lists a banner with adjustable title, subtitle, typography, colors, size and alignment plus image selection, positioning and crop; calendar and analog or digital clock widgets; and a tomato-shaped Pomodoro timer with focus and rest modes. Widgets can be reordered, resized or hidden, and the README notes a lighter dashboard styling for mobile.
