# Adnan0-IM/Cinderpaper

Cinderpaper is an Obsidian theme curated from the Nord template and visually inspired by the Cinderpaper theme, aiming at a minimalist design that keeps readability and usability. Its README documents light and dark variants and installation by extracting a release archive into the vault themes directory. Customisation is described as editing theme.css directly: the accent variable, the base, heading and small font-size variables, and the heading and interface font families. The attribution section records that the base CSS structure and variables come from the MIT-licensed obsidian_nord project and that the palette, naming and additional styles were changed.
