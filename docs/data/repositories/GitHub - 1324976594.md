# vcarus/obsidian-explorer-order-editor

Gives folders and notes a manual position in the file explorer, stored in a plain-text note inside the vault rather than the configuration folder, so the order syncs with the notes and can be edited by hand. An item can be dragged onto the top or bottom edge of another row to land at that spot, and an edge drop in a different folder moves it there at the same time, while dropping onto the middle of a folder row simply moves it in. A dialog opened from a folder's context menu arranges all its children at once, can sort them by name or by creation or modification date as a starting point, and can walk into subfolders without discarding unsaved changes. The same four moves, up, down, to top and to bottom, exist as commands and as optional context-menu entries, acting on whichever explorer row or open note has focus.
