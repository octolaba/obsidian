# KORThomasJeong/bible-sidecar-KR

Bible Sidecar KR is a Korean-language fork of the Bible Sidecar plugin, reading the Bible in an Obsidian sidebar and copying verses into notes with four versions — Korean Revised, Revised New Korean Standard, NIV and KJV. A search field at the top accepts Korean or English book names and abbreviations such as `히3`, `히브리서 3`, `히3:5` or `Heb 3`, offering completions and jumping to the chapter, or scrolling to and highlighting the verse; browsing by testament, book and chapter stays available below it. Verses are selected by clicking and copied through a toolbar in either callout or plain-text format, with non-contiguous verses compressed into ranges and commas; the README states three versions are fetched live from a public API while the copyrighted Revised New Korean Standard text is not shipped and must be supplied by the user as a local JSON file.
