# javalent/obsidian-leaflet

The repository holds Obsidian Leaflet, a plugin that renders interactive maps inside notes using the Leaflet library. Its README documents a leaflet code block whose keys set the map identifier, a background image or tile source, height, latitude and longitude, zoom bounds and default zoom, unit and scale, markers positioned by coordinates and linked to notes, and a dark mode flag. It describes the plugin as a proof of concept tested on Windows and macOS, and its opening notice records that the project is in maintenance mode, where pull requests and bugs are reviewed but feature requests are not worked on.
