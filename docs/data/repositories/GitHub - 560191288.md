# KosmosisDire/obsidian-webpage-export

Webpage HTML Export exports HTML from a single file, a canvas page or a whole vault, and the README states that direct access to the exported files is what lets the result be published anywhere. The exported site carries full-text search, a file navigation tree, a document outline, a graph view and a theme toggle, is described as optimized for web and mobile, supports most plugins including Dataview and Tasks, and can optionally bundle the HTML and its dependencies into one file. The README notes that although the plugin is functional it is still under development, with frequent large changes between updates and bugs that are not uncommon.
