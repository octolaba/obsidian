# toiq/obsidian-sidebar-expand-on-hover

Obsidian plugin that expands or collapses a sidebar when the mouse hovers over the corresponding ribbon. Double-clicking a ribbon pins or unpins the current expanded or collapsed state, sidebar width is set either by dragging or by entering a value in the plugin settings, and the previous state of both sidebars is restored when Obsidian is relaunched. The README lists an option to toggle sidebar animations and a change of animation style as planned rather than implemented.
