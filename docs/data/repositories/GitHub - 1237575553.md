# SirEdvin/excalidash-obsidian-sync

ExcaliDash sync uploads an Obsidian Excalidraw note to an ExcaliDash instance when the note opts in through frontmatter metadata, supporting several instances, collections and either one-way or bidirectional sync. The README states that access is configured with a username and password or API keys against the server root, that the plugin uses ExcaliDash's fixed /api routes, and that API keys are not yet supported upstream. Conflict handling is spelled out: a remote version that changed since the last sync is reported as a conflict for one-way sync, a bidirectional pull happens only while the local scene hash still matches the recorded one, both sides changing leaves both copies untouched, and pulls into compressed-json Excalidraw notes are unsupported.
