# SoulBits-Vibe/property-values-browser

Property Values Browser adds a right-sidebar view for browsing frontmatter properties by value, modelled on Obsidian's built-in All Properties panel with the addition that a property expands to the distinct values used across the vault. Property names and values are listed with counts, list values are counted separately whether the YAML is inline or multiline, blank values appear as an empty marker, and a filter box narrows both lists. Clicking a property or a value opens Obsidian Search for that property or that exact property and value pair, while right-click menus delete a property or a value from the matching notes. The README records that these deletions have no undo history of their own and that the view reads Obsidian's metadata cache, so very recent changes may need the manual refresh.
