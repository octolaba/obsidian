# jmarasch/glyphit

GlyphIt puts icons on files, folders, tabs, note titles and inline text, carrying over custom rules, frontmatter support and a plugin API from Iconize, the unmaintained project it forks. Its difference is storage: a pack stays zipped or as a folder and is never unpacked, only a small index of its contents is read at startup, and an icon is extracted to a cache directory as an SVG the first time it is used. Packs may nest icons in subfolders and reuse a filename across them, with names staying short unless ambiguous, and a rescan button picks up pack edits without restarting Obsidian. Color is applied when the icon is rendered, so icons that set color on their shapes rather than the root element still recolor correctly and one pack covers every color.
