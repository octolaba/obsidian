# maoruibin/obsidian-inbox-sync

Downloads notes from the inBox service into a vault in one direction only: the plugin reads the cloud copy and never writes back, so editing or deleting a synced file in Obsidian leaves the remote data untouched and new notes must be created in the inBox app. It reads from WebDAV or S3-compatible storage, syncs incrementally using ETag and modification time, and brings across images, video, audio and attachments into a shared assets folder. Notes are filed by their inBox box, one folder per box with unassigned notes at the root, and folders follow box renames and deletions. Each note carries frontmatter with title, identifier, timestamps, box and extracted hierarchical tags, and the sync folder and interval are configurable.
