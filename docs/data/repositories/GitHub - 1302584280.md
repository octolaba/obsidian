# Roasted-NZ/chronicle-lanes

Turns dated Obsidian notes into a visual timeline of colour-coded lanes. The README documents two views, a full Chronicle Lanes explorer with labels, category counts, filtering and a note inspector, and a compact Timeline Overview for a tab or side dock. Entries are added by right-clicking a note and setting a start date, optional end date, in-progress state and category, which the editor writes as doc_start, doc_end and timeline-group properties, with an in-progress note written as doc_end current so its range advances to the present day. Notes can be grouped by category, folder or tag, sorted and filtered, and played back chronologically; the README states the plugin is designed for Obsidian Desktop.
