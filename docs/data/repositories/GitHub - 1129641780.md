# Ktonel475/Better-Image-Tag

Better Image Tagger tags images in an Obsidian vault by right-clicking them or selecting them in the editor and picking from existing tags, instead of typing tag names. Tags, author and dates are written into frontmatter through created metadata notes, and a sidebar tag manager collects the tags in one tab; the recorded description states tags are stored in plugin settings. Its commands are `Tag selected image`, `Rescan vault for existing tags` and `Open tag manager sidebar`, and the README notes the manager tab can be reopened from the plugin settings if it is closed.
