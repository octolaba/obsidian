# yuanzhixiang/obsidian-query-control

Query Control adds a control bar to embedded search queries in Obsidian, in Live Preview and Reading modes, with actions to collapse all, show context, sort, hide the title, hide the results, render Markdown and copy the results. Defaults for each control are set in the plugin settings, so that, for example, every embedded query can render collapsed. An extended query syntax overrides those defaults per block through optional keys for title, collapsed, context, hideTitle, hideResults, renderMarkdown and sort, the last accepting alphabetical, modified-time and created-time orderings in both directions. The README states that the plugin was updated to work with Obsidian 1.7.0 and later.
