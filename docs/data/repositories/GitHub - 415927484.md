# piglet1236/obsidian-emerald

Emerald is a green Obsidian theme that the README records as a modified version of cotemaxine's amethyst theme, working best with the dark scheme. The README states that it supports a cite snippet taken from the Palatinate theme. Installation is either through the custom CSS plugin in the app or manually, by placing obsidian.css in the root of the vault and refreshing.
