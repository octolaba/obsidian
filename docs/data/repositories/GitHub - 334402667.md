# SlRvb/Obsidian--ITS-Theme

SlRvb/Obsidian--ITS-Theme holds ITS Theme, made for the author's story vault and designed around readability and customizability through the Style Settings plugin. Its documentation is published separately as an Obsidian Publish site, and the README lists dark and light mode, a coloured graph, squared edges, heading underlines that span the page, and smaller single-colour headings inside embedded files. Several snippets, among them checkboxes, callouts, image adjustments, aside, embed adjustments, Kanban and the alternate themes, are included with the theme rather than downloaded separately.
