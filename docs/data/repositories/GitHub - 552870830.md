# shadowash8/obsidian-aura

Aura is a minimal but configurable Obsidian theme installed from the community themes list. Its README presents the options as switchable colour schemes, custom workspace background images, an alternative more rounded layout, a configurable frame colour, and restyled callouts and folders. The credits attribute individual pieces to other authors: callouts, a floating status bar and file and folder icons; the card layout and workspace background; and the Origin colour scheme and layout.
