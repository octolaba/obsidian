# Hazelnines/document-merge-dedupe

Merges Markdown files that overlap - clips of one long conversation, article or paginated resource saved as several notes - by aligning repeated paragraphs and keeping an ordered union rather than concatenating them. Files are grouped by frontmatter merge_group or clip_group keys, then by ChatGPT or Gemini conversation identifiers, then by pagination patterns, and finally by the normalized URL; similar titles alone never group documents. Commands scan for mergeable groups without changing files, merge the group containing the active note, or merge notes chosen from a searchable picker, which always preserves the sources. Merged output and a verification report covering coverage, anchors, conflicts and possible gaps go to configurable folders; cleanup of sources is opt-in and verifies SHA-256 hashes first, and processing is local with no network requests.
