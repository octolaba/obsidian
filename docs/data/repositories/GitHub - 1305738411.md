# kellybrendan/obsidian-life-timeline

Life Timeline is described as a JSON-based life timeline that groups events under coloured eras, allows events with date ranges and is edited inline. The README says a note carries a life-timeline code block whose body is the path to a JSON data file relative to the vault root, falling back to a default path from settings, and that the file is created on first save. Eras and events are added, edited and deleted from within the rendered block without editing JSON by hand, eras can be collapsed, reordered and hovered for their description, and the data stays a plain JSON file in the vault. The README credits an earlier timeline plugin as inspiration and states that this one shares no code with it.
