# fcandi/Garmin-Health-Sync

Writes health data from Garmin Connect into daily notes as frontmatter properties that Dataview can query, covering steps, sleep, heart rate, HRV, stress, body battery, blood oxygen, weight and more than twenty metrics, plus one key per workout and an optional machine-readable trainings field. Auto-sync at startup fills gaps over the last seven days, optionally waiting for another tool to create the daily note, while a manual command syncs an open note and a backfill covers a date range. The daily note path and format are detected from Periodic Notes or the core plugin, nested and date-based subfolders are supported, and a property prefix avoids name collisions. The README records the plugin as desktop only because it authenticates through an Electron browser session against Garmin Connect's internal web API, and states that note content is never touched.
