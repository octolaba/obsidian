# quanru/obsidian-lifeos

LifeOS combines the PARA method with periodic notes and usememos, and is the plugin half of the wider LifeOS project. The README recommends downloading the LifeOS example vault to try it out, points to the project site for tutorials, and lists the basic feature set alongside the paid LifeOS Pro and DeepAsk AI offerings. The interface language follows the current Obsidian language by default and can be overridden on the plugin settings page, and the README records a third place in the Best Templates category of the 2024 Obsidian Gems of the Year awards.
