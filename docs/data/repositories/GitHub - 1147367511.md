# 22-2/obsidian-on-demand-plugins

Obsidian plugin that delays plugin activation so other plugins load only when they are actually used, which shortens startup. Each installed plugin is given a loading mode in the settings tab, lazy-on-demand triggers are configurable per file and per view type, and applying the changes restarts Obsidian. It works by registering dummy commands that cache command metadata and loading the real plugin on first use, monkey-patching parts of Obsidian's core; the README warns that Obsidian updates may break this, that plugins using timers or global hooks belong in the lazy-on-layout-ready mode, and that inline embedded views are unsupported.
