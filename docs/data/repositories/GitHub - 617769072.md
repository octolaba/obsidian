# autohub7/obsidian-open-selected-links

This plugin opens all selected links in edit mode at once, instead of opening each one by hand. Its single documented feature is that action, triggered by a hotkey the user sets up. The plugin's settings choose the method used to launch the links — a tab, a window or a split.
