# jffaust/obsidian-canvas-images-as-links

This repository holds an Obsidian plugin that lets an image node in Canvas carry a link, opened by double-clicking the image. Right-clicking an image adds Set link and Open link menu entries, and a Set link of selected canvas node command can be bound to a shortcut. Web addresses, local file addresses and obsidian scheme addresses are supported, and the configured link is displayed underneath the image. The repository carries no description, so this body rests on the README alone.
