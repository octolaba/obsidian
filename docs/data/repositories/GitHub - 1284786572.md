# rixct/config-drift-watcher

Config Drift Watcher detects when a server's actual configuration has diverged from what an Obsidian note documents, reading the remote file over SFTP. A `drift` code block carries a server alias and an absolute remote path on its first line and the documented content below it; the plugin connects over SSH, fetches the current file, and compares it line by line, marking the block in sync or showing which lines exist only in the note and which only on the server. The README states that the plugin never executes commands and never writes to the remote server, and that the note itself is left untouched.
