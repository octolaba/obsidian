# tejado/obsidian-gpgCrypt

gpgCrypt encrypts Obsidian notes with GnuPG, either through OpenPGP.js or through a wrapper around a local GnuPG installation, the latter allowing OpenPGP smartcards such as YubiKey or Nitrokey. Encryption is asymmetric and needs a key pair, generated or supplied through a welcome dialog on first load, with passphrase-protected private keys accepted and a configurable duration for remembering the password. Further settings cover encrypting all notes, compression, how the file recovery core plugin handles encrypted notes and a status bar integration; mobile devices are supported only with OpenPGP.js. The README warns that encrypted notes might still be stored unencrypted on disk because of Obsidian's caching, coredumps or other reasons.
