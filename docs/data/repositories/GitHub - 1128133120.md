# xiaozhuang0433/mermaid-zoom

Mermaid Zoom adds zoom and pan to rendered Mermaid diagrams in Obsidian. Wheel zoom is opt-in per diagram through a toggle so the page still scrolls normally, dragging pans the diagram, pinch and drag work on touch devices, and each diagram carries buttons for zoom in, zoom out, reset to fit and fullscreen beside a live scale indicator. Diagram containers can be resized by dragging an edge or a corner, and the settings include a default zoom level between 50 and 300 percent.
