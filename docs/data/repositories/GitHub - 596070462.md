# danzilberdan/obsidian-mathlive

MathLive helps write math in Obsidian through a visual math editor, so an expression can be built and inserted without typing every LaTeX command. Inline and display math can be inserted, and an existing formula can be edited in a visual math field instead of as raw LaTeX only. The plugin can also turn a copied formula image into LaTeX, either through a hosted OCR service or a local OCR server, which the README suggests for screenshots from PDFs or slides and for formulas that would otherwise be retyped.
