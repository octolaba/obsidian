# chinoryunqin/lumen-ai-assistant

Lumen is a right-sidebar assistant panel for Obsidian which its README describes as inspired by Notion AI: it reads the active note or the current selection, runs an action, and writes the result back to the file. Six built-in actions cover summarizing, translating, deep analysis, extracting tasks, continuing writing and polishing, each opening a conversation that allows follow-ups and retries, with write modes to replace the selection, append to the note or overwrite the file. The user supplies an API key for Anthropic Claude, OpenAI GPT, MiniMax or Kimi and can switch provider, model and system prompt in settings; the README's statement that the key stays in the vault's local configuration and that there is no telemetry is recorded here as the project's own claim. The document is bilingual English and Chinese.
