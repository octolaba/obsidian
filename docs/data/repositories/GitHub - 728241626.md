# hotoo/obsidian-markline

Obsidian Markline shows a timeline view rendered from Markdown inside the Obsidian editor and is a fork of the author's own Markline project. The timeline source lives in a markline fenced block, which a command can insert. The README describes the supported Markdown subset, where a heading gives the document title and optional group names and list items carry a date or date range followed by the event text, with links allowed inside an event and sub-events nested underneath.
