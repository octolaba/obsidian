# jaanonim/obsidian-youversion-linker

YouVersion Linker turns a Bible reference typed in a note into a link to the YouVersion Bible. Typing one of three trigger characters before a reference offers a suggestion that links the verse, quotes it, or quotes it inside a footnote, and verse ranges and lists such as several chapters and verses in one reference are supported. The trigger characters, the Bible version, and the language whose book names are recognised are all set in the settings; the README records Polish book abbreviations as supported alongside the languages listed in its own language file, and credits an existing Bible reference plugin as the inspiration and partial source.
