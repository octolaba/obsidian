# jaanonim/obsidian-youversion-linker

YouVersion Linker turns Bible references in Obsidian notes into links to the YouVersion Bible. Trigger characters can insert a linked verse, a quotation, or a footnote quotation, with support for multiple verses, selectable Bible versions, and book names in different languages.
