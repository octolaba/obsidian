# livetennisapi/obsidian-live-tennis

Live Tennis is described as embedding live tennis scores in notes through code-block scoreboards, match snapshots and player profiles served by the Live Tennis API. The README distinguishes the two uses: a tennis code block re-renders current matches whenever the note is previewed and stores nothing, while a snapshot command resolves the same query once and inserts a static Markdown table of players, event, per-set score, surface and winner with a timestamp caption, and a companion command inserts a one-line player profile. Block options select match status, tour, result limit, a specific match id or a player name filter, with completed matches requiring a paid API tier. The README states that each render fetches once and that the block does not poll in the background, and that an API key is set in the plugin settings.
