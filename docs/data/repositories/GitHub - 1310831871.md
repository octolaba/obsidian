# livetennisapi/obsidian-live-tennis

Live Tennis embeds live tennis scores in Obsidian notes for ATP, WTA, Challenger, ITF, and junior tours. Its tennis blocks query current matches, h2h blocks show player records, and commands can freeze a match query into a static Markdown table or insert a player profile.
