# CmZhangxin/obsidian-ima-sync

IMA Sync connects an Obsidian vault to Tencent's IMA knowledge base through its official OpenAPI. It pushes Markdown notes from the vault into IMA notebooks, pulls notes back as plaintext, and can run both directions in one pass, either automatically on save, on a timer, or on demand from the command palette. Each note is routed to a notebook through a folder-to-notebook mapping table configured once in a built-in wizard. The README records the requirements as Obsidian 1.5.0 or newer, because the plugin uses the vault process and frontmatter-processing APIs, and an IMA account with OpenAPI access supplying a Client ID and API key.
