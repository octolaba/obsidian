# leruetkins/obsidian-empty-files-cleaner-np

Empty Files Cleaner NP scans a vault for Markdown files whose content is empty or only whitespace and lists them in a modal for bulk deletion. The README states that files are selected with checkboxes, with select-all and deselect-all actions, that deletion asks for confirmation and refreshes the list afterwards, and that the modal is opened from a ribbon icon or the find-and-delete-empty-files command. It warns that deletion is permanent: files are removed from the vault rather than moved to trash.
