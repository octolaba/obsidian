# ebullient/obsidian-vault-mcp

Vault as MCP is an Obsidian plugin that runs a Model Context Protocol server so external LLM tools can reach the vault; the description names Open WebUI and Claude Desktop as clients. The README says the server speaks HTTP natively over Fastify, with an optional bridge script providing HTTP-to-stdio for Claude Desktop, and exposes MCP tools for note read and write, search, templates and periodic notes. Settings cover the port, an optional bearer token, auto-start, CORS for remote access and log level, and the README states the plugin is desktop-only, runs the server locally, connects to no external services and collects no telemetry.
