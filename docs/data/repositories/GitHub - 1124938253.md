# Pooyash1998/chartspark

This repository holds ChartSpark, an Obsidian plugin that converts tables, checkbox lists and key-value blocks into interactive Chart.js charts inserted into the note. Six chart types are supported, namely bar, line, pie, doughnut, radar and polar area, with a column picker for choosing the category axis and the value series, an axis swap and a horizontal bar toggle. Each chart tracks its source block by id and refreshes live as the data is edited, and the parser handles booleans, currency, percentages and yes-or-no values. The README also lists a multi-block picker, a vault or folder scan aggregating checkbox data, PNG export, and theme-aware colours taken from CSS variables.
