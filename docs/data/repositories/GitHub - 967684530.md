# Epistemic-Technology/co-intelligence

Co-Intelligence AI adds a chat interface to the main Obsidian window and saves each chat into the vault as a Markdown note. Notes and tags can be added to a chat as context, models from OpenAI, Anthropic, Google and Perplexity can be used and switched during a conversation, chats can be renamed automatically by a chosen model, and custom system prompts can be defined and switched between. The README states that at least one provider API key is required, that most models need a paid account, and that free-tier availability, where it exists, changes frequently. Settings cover the folder chats are saved to, the default model and the model used for renaming.
