# byfun/obsidian-image-helper

Adds context-menu entries in Obsidian's reading view that convert an image to JPEG, WebP or PNG format. The three conversions appear when right-clicking an image in that view. The README credits functions taken from the paste-png-to-jpeg and copy-url-in-preview plugins.
