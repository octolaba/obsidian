# Rockorolla/obsidian-easy-wikilink

Easy Wikilink turns selected text into an internal link: trigger the hotkey, pick a page from the vault, and the plugin inserts a link to that page with the selected text as its display text. Its README compares the flow to the Ctrl+K shortcut for external links, states that no shortcut is bound by default and that one must be assigned in Obsidian's Hotkeys settings, and suggests Ctrl+Shift+K.
