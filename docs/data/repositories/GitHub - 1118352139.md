# derek-larson14/obsidian-claude-sidebar

Obsidian plugin that runs Claude Code and other agent command-line tools in a terminal inside the Obsidian sidebar. The README describes automatic launch of the configured CLI, multiple tabs for parallel agents, file explorer context menu entries that open an agent in a folder or send it a file path, and a provider switch covering Claude Code, Codex, Grok Build, OpenCode, Gemini, Kimi Code, GitHub Copilot, Cursor Agent and Pi. Its stated requirements are macOS, Linux or Windows, Python 3, and an installed agent CLI.
