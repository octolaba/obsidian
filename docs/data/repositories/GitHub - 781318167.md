# zhouhua/obsidian-power-mode

Power Mode adds typing effects to Obsidian: screen shaking, a combo meter, and preset cursor explosion effects listed in the README as particle, flame, rift, firework, pikachu, lightning, shapes, coin, confetti and spark. The README opens by calling the plugin useless and offering it as a little ceremony for writing, which it describes as sometimes a boring task. It records that power mode is not a new concept and exists in various text editors, and that this implementation and its effects are largely inspired by vscode-power-mode and by effects shared in an issue on that project.
