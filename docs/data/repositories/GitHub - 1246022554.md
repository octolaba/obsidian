# erincayaz/obsidian-lens-ocr

Obsidian plugin that captures a region of the screen and runs optical character recognition on it, inserting the extracted text at the cursor in the active note. Recognition uses the operating system's own engine, Apple's Vision framework on macOS and the Windows OCR API on Windows, so the README states that no AI API, cloud subscription or internet connection is involved and that no OCR model or external runtime is bundled. Use requires assigning a hotkey to the capture command first, after which the hotkey starts a region selection. The stated requirements are macOS Catalina or later and Windows 10 or later.
