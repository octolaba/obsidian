# victoriadouglas/Comic-Scripter-Obsidian

Comic Scripter is a comic scripting utility for Obsidian, based on Scrivener templating and comic scripting suites such as Superscript, that styles Pages, Panels and Dialogue with Markdown-adjacent syntax. A line consisting only of the word Page or a capital P marks a page and renumbers every page in the document from 1, while a line starting with Panel or a lowercase p inserts an indented panel heading numbered sequentially until the next page. A line carrying a name followed by a colon is styled as dialogue, with the name bolded and indented and the following text left unstyled, which also covers captions, SFX and other attributed descriptions. Settings toggle a separating line between pages and a handedness suffix appending L or R to each page.
