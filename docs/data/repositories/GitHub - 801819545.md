# nancyel/header-counter

This plugin counts the headers in the current note and displays the count in a notification message. No repository description is recorded, so this body rests on the README alone. Its two command palette entries are Count Headers and Compute Header Summary, the latter producing a summary that is pasted from the clipboard, and the header levels to count are configurable in the settings with a default of four.
