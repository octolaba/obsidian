# jia6y/flomo-to-obsidian

Imports Flomo memos into the vault, either by an automatic sync that signs in to the account or by an ad-hoc import of a zip archive exported from Flomo as HTML. The import location is configurable, highlight marks are preserved, and optional outputs include a Flomo Canvas built from memo content or file links and a Flomo Moments note. The README marks bidirectional links inside memos and merging memos by date as experimental, and states that the Playwright browser package must be installed before first use.
