# houjoe0829/sparkmemo

Spark Memo is a journaling plugin that highlights time stamps inside a designated memo section as pill badges in Source, Live Preview and Reading view, with customizable colors and an optional read-only mode. A quick-capture sidebar appends typed, dictated, pasted or recorded entries to today's daily note, and a pasted or uploaded photo carrying EXIF capture time and location is turned into a memo at that moment and place, stored as a geo link. Tags and geo-tagged memos are rolled up for review, with rename, merge and delete for tags, a yearly heatmap summarises what was written and an offline world map drawn from a vector basemap plots the locations. The README records the plugin as forked from journal-partner, whose timestamp-highlighting core it keeps.
