# houjoe0829/sparkmemo

Spark Memo highlights HH:MM timestamps in a designated Memo section and provides a quick-capture sidebar for text, dictation, images, and audio. Photo metadata can place a memo at its capture time and location, while yearly heatmaps, tag and location roll-ups, an offline map, and random rewind support review; an optional desktop chat uses a locally installed Claude Code CLI.
