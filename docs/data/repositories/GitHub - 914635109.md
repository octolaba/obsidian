# Fleker/feedly-for-obsidian

Copies the annotations and comments a Feedly account holds into a folder in the vault, creating one file per article that carries frontmatter metadata followed by the highlights as quotes and the comments. Setup requires a Feedly developer access token and user id entered in the plugin settings, and the sync is started from a command. The README states that annotating requires a paid Feedly membership, that the access token expires after a month, and that Feedly's daily rate limit can end the first sync with a rate-limit error, after which the plugin resumes at the same point the next day.
