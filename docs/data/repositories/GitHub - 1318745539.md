# fardm/Habit-Tracker-Dashboard

Habit Tracker Dashboard reads habit values from the frontmatter properties of daily notes and renders them as dashboards created from a ribbon icon or a command. A tracker is configured with where the daily notes live, by tag or folder, and where the date comes from, the file name or frontmatter, in ISO form; habits are declared as boolean for checkbox properties, or numeric with a target, unit and a completion condition of at least, at most or exactly. Views include a daily dashboard with donut visualizations reflecting that condition, a yearly contribution-style heatmap, line and bar charts, statistics such as totals, averages and completion rates, and streaks with configurable grace days. Scanned data is cached, so manual edits to daily notes are picked up through a refresh button.
