# ChristianLempa/obsidian-iconic

A fork of gfxholo/iconic that expands icon support beyond Lucide and emojis to Simple Icons brand logos and Devicon technology logos, both compressed and bundled into the plugin's main script. Icons can be swapped on tabs, files and folders, bookmarks, tags, properties, ribbon commands, window buttons and sidebar toggles by secondary-clicking the item and choosing Change icon. The README states the fork reuses an existing community plugin id so Obsidian associates releases with the correct plugin, and that ten interface languages are included, most of them machine-translated.
