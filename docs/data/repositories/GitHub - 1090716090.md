# Kazi-Aidah/sidecards

SideCards creates note cards in the Obsidian sidebar that can be coloured, tagged and dragged into the editor to insert their content. The README describes typing into a sidebar input to create a card, editing card content inline with auto-save, converting a card into a Markdown note, two-way sync between cards and notes, and importing Markdown files from a configured storage folder. Cards carry ten colours, automatic colour rules driven by text or tag matches, three visual styles with adjustable border radius, opacity and thickness, a status system with custom names and colours, expiry times with optional auto-archive, and Today, Tomorrow and Archived categories alongside user-defined ones.
