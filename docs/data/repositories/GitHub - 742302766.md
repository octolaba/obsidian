# joeriddles/extended-task-lists

Extends Markdown task lists with two extra item states, an in-progress item written with a dot and a will-not-do item written with a tilde, each rendered with its own presentation including in live preview. A second feature scans the task lists of the vault and generates a top-level TODO file; the generated filename and which item types it includes are configurable, and done and will-not-do items are excluded by default. A file is kept out of the generated list by an HTML comment inside it, a whole folder by placing an empty marker file in it.
