# noduslabs/infranodus-obsidian-plugin

Visualizes vault content as a knowledge graph based on the InfraNodus text analysis tool, showing connections between the concepts in the text as well as between wiki links mentioned in the same statements, and applying clustering algorithms to surface topical clusters, the most relevant concepts and the gaps between them. The built-in AI generates ideas and research questions from that content to bridge the gaps identified. The README states that the plugin can be used without an account, that an InfraNodus account extends the AI quota and connects graphs to the main application, and it documents the settings that reproduce Obsidian's own graph behaviour.
