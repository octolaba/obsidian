# danarnold/tokyonight-simple

Tokyo Night Simple is an Obsidian theme that applies the Tokyo Night colors used in folke/tokyonight.nvim to the application and text colors. Unlike the tcmmichaelb139 tokyonight theme, it deliberately does not color UI elements beyond the level of the default Obsidian theme, aiming for the simplest possible mapping of the palette. The README records that the theme is dark mode only and credits tokyonight.nvim and the Tokyo Night VS Code theme.
