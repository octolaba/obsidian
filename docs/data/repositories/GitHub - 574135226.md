# fzdwx/hugo-preview-obsidian

Previews a Hugo site from inside Obsidian by starting a hugo server process in the background and opening it in a custom iframe view, reachable from an icon in the status bar. Extra flags for the server are configurable and default to navigateToChanged, and a separate configurable command bound to a shortcut launches an external process such as a terminal. The README records an outstanding problem: the hugo child process is not closed when the launching program exits.
