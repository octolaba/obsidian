# hencter/obsidian-motes

Motes is a quick-capture memo plugin, forked from Memoria, that keeps every entry as ordinary Markdown in the vault. Captures are typed into an embedded Obsidian live-preview editor and stored either in daily or in yearly files, with a command to migrate existing daily files into the yearly form, and they appear as a waterfall of cards rendered with Obsidian's own reading view. Tag autocomplete, combined tag and keyword search, quick filter tabs, pinning, starring, image paste and drag, and task checkbox writeback act on those cards. A separate sidebar view can be docked independently and offers a heatmap, calendar, statistics, tag cloud and a year panorama, and the interface is available in Chinese and English.
