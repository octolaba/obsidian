# gasparschott/obsidian-continuous-mode

Continuous Mode displays all open notes in a tab group as one continuously scrollable document, in the manner of Scrivener's Scrivenings mode, and works in main-workspace splits, the left and right sidebars and floating windows. Notes can be opened into it from the File Explorer, including whole folders, from search results, from document links and from Dataview or query blocks, and arrow keys navigate within and between notes. Further options include a Compact Mode, typewriter scrolling, hiding the tab bar and tab headers, and scaling inline note titles by folder depth; the README notes that the plugin works with the existing file explorer structure and leaves file organization and custom ordering to other tools.
