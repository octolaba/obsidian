# tonylee2016/obsidian-import-fixer

Import Fixer cleans up notes brought into Obsidian by web clippers such as Evernote, targeting the artefacts those imports leave behind: oversized header favicons, site UI icons and tracking pixels scattered through the body, image embeds nested inside link text, leftover resource folders, and embeds pointing at resource folders that have since been renamed. Its commands repair those broken resource links by scanning the `res_*.resources` folders and rewriting each link to the one holding most of the missing files, shrink recognised icon embeds by appending a width of 48 while leaving hash-named content images alone, strip image embeds nested inside links in the current selection, and run the repair and shrink steps together on the current note. This note is grounded in the README alone, as the repository records no description.
