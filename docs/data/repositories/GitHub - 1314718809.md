# BuckleyResearchLtd/obsidian-mobile-toolbar-utilities

Adds three editor commands aimed at Obsidian's mobile toolbar: Delete current line, Send current line to another file, and Toggle current line as a checkbox. Unlike the built-in Delete paragraph command, the delete acts on just the line the cursor sits on, or on every line a selection touches, as a single undoable transaction. Sending a line opens a fuzzy search over the vault's markdown files, appends the line to the file picked and removes it from the source, while the toggle command turns a line into an unchecked task or back to plain text. Because Obsidian exposes no API for the mobile toolbar, the commands have to be added to it by hand, and they are also available from the command palette and hotkeys on desktop.
