# platers/obsidian-linter

The repository holds Obsidian Linter, a plugin that formats and styles notes through rules that are individually toggled and configured in the settings. Its README states that each rule is independent logic meant to run on its own, and warns that enabling rules whose targets overlap can produce unexpected results, giving paragraph blank lines together with two spaces between lines with content as an example. It points at an external wiki as the documentation for the rule set and notes that those documents are updated before a release, so they may run ahead of the plugin.
