# tbergeron/obsidian-fold-properties-by-default

Folds the metadata properties of a note by default. The README describes the mechanism plainly: the plugin checks whether the properties are unfolded and, if so, calls Obsidian's built-in command to toggle them into the folded state, and there are no settings. A recorded known issue is that properties are not folded automatically in a newly created note, which the author presents as deliberate for now.
