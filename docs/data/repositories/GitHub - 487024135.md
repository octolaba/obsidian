# luhaifeng666/obsidian-translator

This plugin translates text from inside Obsidian. A book icon in the side menu or the translate command opens a modal where a phrase and a target language are chosen, and selected text in a note can be sent to that modal instead of being retyped. A hotkey can be assigned to the command from the community plugins section of the preferences.
