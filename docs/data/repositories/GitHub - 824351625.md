# mnaoumov/obsidian-refresh-any-view

Refresh Any View, formerly called Refresh Preview, re-renders a view without the note being reopened. The README explains why this is needed for dynamic content: a code block producing a changing value is rendered once when the preview or live preview opens and re-renders only when the block's content changes or the note is reopened. The plugin adds a Refresh button and a command that refreshes the active view, and can be configured to refresh automatically on file change or on a time interval, which the README notes may cause visible flickering. A demo vault ships with every release and can be opened by a command, downloaded, or browsed in the repository.
