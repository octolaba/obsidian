# obsidian-power-plugins/obsidian-power-connect

Power Connect syncs a vault through storage the user already has - Dropbox, OneDrive or Google Drive, the last of these still in beta - using an application registered under their own account, so no third-party server sits in the middle. Each device keeps its own record of what both sides last agreed on, so only changes move, renames are treated as moves, and an edit on one side restores a file deleted on the other. A wizard registers the storage app, names the vault folder and fixes the privacy level once - everything encrypted end to end, only plugin settings encrypted, or off - then previews the first sync, and further devices join by pasting a setup code, with matching files paired by content instead of transferred again. Syncing runs on start, on focus, after edits settle, on a schedule and on demand, with exclude patterns, per-device excludes and a size cap.
