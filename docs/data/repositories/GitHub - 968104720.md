# band/obsidian-folder-filelist

Generates a note in each configured folder containing wiki-links to the files in that folder, listed by modification time with the newest first. A ribbon icon regenerates every list file. The settings hold the included folder paths, where the vault root produces its own list file, the file extensions and the individual filenames to exclude, the naming pattern of the generated file, and an option, recommended on, that keeps the list file out of its own list.
