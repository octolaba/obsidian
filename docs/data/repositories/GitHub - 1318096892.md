# TYBLHQY/obsidian-siltflow-importer

Siltflow Importer reads a Siltflow language-learning SQLite database and writes it into the vault as Markdown, one note per document, each with an AI summary and a callout card per annotation. A ribbon icon and an import command trigger the sync; incremental runs update only changed annotations, and per-type filters restrict the import to words, phrases or sentences. It requires Obsidian 1.13 or later on desktop and reads the database file directly through Node.js, so nothing is uploaded.
