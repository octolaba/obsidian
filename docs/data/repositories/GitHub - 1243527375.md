# MarckFp/ultra-zen-mode

Ultra Zen Mode hides the parts of the Obsidian interface that are not the note itself, by default the left and right sidebars, the properties block, the tab bar and the status bar, with the inline note title optional. A floating exit button appears in the bottom-right corner, staying very transparent until hovered or tapped, and zen mode is toggled from a ribbon icon, the command palette or a hotkey. Settings choose each hidden element, switch to reading mode on activation and restore the previous mode on exit, lock the note against accidental edits so the floating button becomes the only way out, and set the height of the header bar left behind. The README states that the plugin works on desktop, tablet and mobile and that changes take effect the next time zen mode is entered.
