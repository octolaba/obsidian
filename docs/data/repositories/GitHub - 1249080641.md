# wsqstar/obsidian-note-highlight

This repository holds Note Highlight, an Obsidian plugin that renders square-bracket planning markers such as now, trap and suggestion as readable badges; the repository records no description, so this summary follows the README alone. The badges appear in Reading View and in Live Preview alike, tagged headings, list items, paragraphs and editor lines gain a subtle left accent, and the original Markdown is left unchanged. The README lists sixteen recognized markers, states that they are case-insensitive, and records that native Obsidian callouts are ignored.
