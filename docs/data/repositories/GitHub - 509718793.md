# chhoumann/PodNotes

PodNotes is a podcast player and note-taking plugin for Obsidian whose stated goal is to make writing notes on podcasts easier. The README records a player for audio and video episodes that works on iOS and Android including offline playback, podcasts added by search or by custom feed URL, tracking of played episodes and playback progress with continuous resume, episode downloads, and support for local audio and video files that are not podcasts. Episode notes are created from templates carrying episode metadata, the default notes are shaped for Obsidian Bases, a feed note can collect every episode note of one podcast, timestamps can be captured as links back into the episode, and episodes can be transcribed with optional speaker diarization. An API is recorded for use by plugins such as QuickAdd or Templater.
