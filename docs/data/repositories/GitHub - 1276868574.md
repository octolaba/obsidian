# eve1329/issuetracker

IssueTracker is a local Obsidian workspace for synchronizing issues from Git-compatible hosts into normalized Markdown notes. It classifies issues, tracks internal and external authors, produces daily reports, briefs, closure reminders, an XLSX ledger, and roster-gap reviews, and can notify locally or through an optional Feishu webhook. A configurable delayed reply may be sent only to qualifying open internal issues, while synchronization metadata and collaborator caches remain in the configured meta folder.
