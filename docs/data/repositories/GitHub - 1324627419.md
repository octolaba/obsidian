# PleiadesM/tufte-suite

Tufte Suite is the companion plugin for the Tufte for Obsidian theme and merges four previously separate plugins into modules that can each be switched off. One renders footnotes and sidenote or marginnote callouts in the margin gutter in Reading view, keeping the editor single-column; another composes column, full-width and margin figures from dropped or pasted images, with captions, multi-image rows, a quilt generator and numbered references. A third adds inline shorthands for small-caps openers, italic run-ins and two-line CJK drop caps, and a fourth renders linked and unlinked mention snippets as formatted Markdown. The modules stay dormant unless the Tufte theme is active, import the standalone plugins' settings on first load, keep their old command IDs, and need Obsidian 1.4.0 or newer.
