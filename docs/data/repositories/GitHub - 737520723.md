# Benature/obsidian-metadata-hider

Metadata Hider hides a metadata property when its value is empty. Specific properties can be kept visible even when empty, and others kept hidden even when they carry a value, across the properties table, the file properties side dock and the all-properties side dock. While metadata properties are being entered all of them are shown, except those set to be always hidden. Which properties to hide or always show is configured in the plugin's settings.
