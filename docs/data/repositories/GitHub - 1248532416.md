# wesswart77/obsidian-screenwriter

Screenwriter supports screenplay development in Obsidian through project scaffolding and structured entries. The README states that a new project creates a folder holding five pre-structured files — treatment, outline, characters, beat sheet and notes — with the beat sheet pre-filled with Blake Snyder's fifteen beats. Further commands add a character entry carrying archetype, want, need, flaw and arc to a project's characters file, and a scene card carrying scene number, location, time of day, characters, action and purpose to its outline. A sidebar lists all projects with a format badge, a status badge and a scene count, and one setting names the root folder under which projects are created.
