# zoorpha/rustshare-obsidian-plugin

Synchronises a local Obsidian vault against RustShare, a self-hosted synchronization backend for Markdown vaults, reachable through its Vault Sync API endpoint. A manual sync scans the whole vault detecting changes by SHA-256, while incremental sync uploads and downloads on file creation, modification, deletion and rename; storage is content-addressed and deduplicated by the same hash, preserving bytes exactly. Conflicts are never silently overwritten but written as conflict copies, deletions are tracked with tombstones so files are not resurrected, offline changes are queued until the connection returns, and a status bar shows disconnected, syncing, synced, conflict, error or offline. The README states desktop-only support, that the plugin is not in the community directory, and that RustShare is not affiliated with Obsidian.
