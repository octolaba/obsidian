# namikaze-40p/obsidian-tab-selector

Tab Selector switches between open Obsidian tabs in several ways: commands that step to the previous or next tab, a modal that lists tabs while the hands stay on the keyboard home position, a mode that shows a shortcut key for each tab without a modal, and a search over tab names. The stepping commands are configured in the plugin's settings and then bound to matching hotkeys, and the README warns that shortcuts reserved by the operating system take precedence and will not work. The modal is opened by hotkey, from a ribbon icon, or from the command palette.
