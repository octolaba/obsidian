# krios2146/obsidian-theme-github

This repository holds a theme for Obsidian inspired by the GitHub colour scheme. Its README lists a Kanban board styled to look like GitHub Projects, callouts, inline code blocks and interface buttons in GitHub style, and settings exposed through the Style Settings plugin covering header colours, kanban and callout styles and colourblind colour scheme variants. Installation is from the Obsidian theme store, or manually by copying theme.css and manifest.json from the latest release into a folder under the vault's themes directory.
