# RyotaUshio/obsidian-pdf-plus

PDF++ transforms backlinks to a PDF file into highlight annotations, so a passage is annotated by linking to a text selection, and it can alternatively write annotations into the PDF file itself so that they are visible outside Obsidian, with limitations the README treats separately. It also adds quality-of-life improvements to the built-in PDF viewer and to PDF embeds, and the annotation functionality can be turned off entirely. The README positions PDF++ as a complement to Obsidian's native PDF viewer rather than a replacement, keeping sidenotes as pure Markdown so the annotations survive if the plugin ever stops working. Optional Vim keybindings are recorded in the repository description.
