# stagars-m/folder-info

Folder Info appends a small translucent badge to folder rows in Obsidian's native File Explorer, showing the number of files and the number of subfolders it contains, separated by a vertical bar. Counts can be recursive or limited to direct children, either half can be hidden, zero counts can be suppressed, and the badge has three font sizes and an optional shading. Counters are appended without moving the native folder-name elements, leftovers from earlier versions are cleared to avoid duplicate labels, and rows refresh when the explorer mounts or expands and when a file is created, renamed or deleted. It reads only Obsidian's in-memory file and folder tree, stores six display preferences, and makes no network requests and no writes to the vault.
