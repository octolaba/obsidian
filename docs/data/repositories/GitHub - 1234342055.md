# WdBlink/codein

A desktop-only plugin that drives the local Codex CLI from inside Obsidian, with the vault as the working context. The same conversation can be opened in the right sidebar, a main workspace tab or a pop-out window, with one live run kept in sync across all of them and output streamed in before the final answer renders as Markdown. Typing in the composer offers Codex CLI commands, local Codex skills and vault Markdown files through separate trigger characters, a template library inserts reusable prompts, and the current note can be added as context after a confirmation. Prompts sent while a run is active are queued and can be reordered, and sidebar selectors set the model, the reasoning effort and how much file access the run is given.
