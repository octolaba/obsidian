# CatMuse/HiWords

HiWords is an Obsidian plugin that highlights words drawn from user-maintained vocabulary books as they appear while reading and shows their definitions. The README records vocabulary books kept as Obsidian Canvas files, where node colours carry over into the highlight colours, and highlighting that works in editing mode, Markdown reading mode and PDF files, built on CodeMirror 6 and scoped to all files, selected folders or exclusions. Hovering a highlighted word opens a popup carrying a Markdown-formatted definition, a pronunciation control backed by a configurable text-to-speech service and a control for marking the word as mastered. A configured AI service generates contextual definitions from prompt templates with word and sentence variables, and a sidebar view lists the words present in the current document.
