# kbcmdba/kbcmdba-flexible-obsidian-tasks

Flexible Tasks renders task checkboxes written inside Markdown table cells, which Obsidian normally leaves as dead text, as interactive checkboxes and writes toggles back to the source file. Single-character statuses round-trip faithfully in the source, and a right-click menu sets any of them on table cells and, optionally, on ordinary block-list tasks. Icons are left to the checkbox theme: the plugin inserts a checkbox carrying a data-task attribute with the status character and overrides nothing, so a character it does not plan for shows the Important indicator instead of passing as done. It renders in both Reading view and Live Preview and is developed against the Minimal theme.
