# ebullient/obsidian-admonition

Admonition adds styled callout blocks such as tip, warning, caution and note to notes, written either as a code block or through the callout syntax. Custom types can be created with their own icons and styles, styled further with CSS through the callout and admonition selectors, and imported or exported as JSON files. The README records support for nested blockquotes and code blocks and for combination with the core Templates plugin and Templater, and points to a separate documentation site for the detailed instructions.
