# nothingislost/obsidian-hover-editor

The repository holds Obsidian Hover Editor, a plugin that turns the core page preview popover into a full editor instance. Its README records that the popover becomes draggable, resizable and pinnable, that dragging or resizing pins it automatically, and that pinning allows several popovers to stay open at once, with the popover becoming the active pane when opened. It states its own risk plainly: the plugin uses functionality not exposed in the official API, so an Obsidian update may break it, and the author's stated goal is for the behaviour to move into the core or onto an official popover API.
