# Ezakamak/obsidian-album-gallery

Album Gallery introduces a gallery document type in which photos, animated GIFs and local videos are organized as albums. A gallery file stores its album metadata and media references as readable JSON, while imported media is copied into a managed assets folder inside the vault keyed by stable gallery and album identifiers, with duplicate filenames handled safely and deletions routed through Obsidian's trash. It reads common photo formats including JPEG, PNG, WebP, GIF, HEIC and AVIF plus MP4, MOV and WebM video with generated thumbnails, and presents them in a full-screen lightbox with keyboard and swipe navigation. An optional Ekatech Study integration adds an account-scoped album that uploads selected photos and their lesson metadata; ordinary albums stay local, and no analytics or telemetry are collected.
