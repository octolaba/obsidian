# guopenghui/obsidian-quiet-outline

The repository holds Quiet Outline, an Obsidian plugin that reworks the outline view. Its README records that headings do not expand automatically while editing, and adds search over the outline with regular expressions, hiding of irrelevant results and matching through Markdown or HTML syntax, Markdown rendering of headings, automatic expanding and collapsing, a default level and a level switch bar. It also records dragging to rearrange the note from the outline, navigation inside Canvas and Kanban views, a hover preview of a heading's content, remembered expansion state, a Vim-like keymap and further hotkeys.
