# ragetrip/audio-pluglist

A playlist-based audio player for Obsidian that builds a playlist either from a vault folder, indexed recursively for supported audio files, or from an external link. Playback runs from a tab view listing the current playlist and from a compact footer mini-player carrying seek, volume, shuffle and repeat controls and an optional fade-out on stop. The README also records EQ presets with a bypass option, optional artist and album columns, a filename parser for "Artist - Title", per-playlist play/pause hotkeys, and support for mp3, wav, m4a, flac, ogg and aac.
