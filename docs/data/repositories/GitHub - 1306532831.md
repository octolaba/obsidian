# fyaic/Table-Fields-Plugin

Table Fields gives each column of a Markdown table a field type, so the table can be operated on in place: checkboxes that are ticked directly, dropdowns restricted to a fixed list of values, and money, percentage and date columns rendered in an aligned, local format. A column's type is set by right-clicking it rather than through a settings screen, and the controls appear both while reading and while editing. The README records that the file on disk stays an ordinary Markdown table, with the field types carried in a small comment, so disabling the plugin leaves the note exactly as readable as before, with no database and no hidden file.
