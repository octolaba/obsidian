# code-forge-temple/circuit-sketcher-obsidian-plugin

Draws circuit diagrams on a canvas inside Obsidian, built on the author's separate circuit-sketcher core library. The README lists drawing and editing diagrams in the app, saving and loading designs, a customizable library of circuit elements, and automatic resizing. Diagram files can be referenced from a note, for example by dragging the file into it, and the README states that in reading mode an image of the circuit is then displayed automatically.
