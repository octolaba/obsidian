# elliotxx/obsidian-qmd-preview

QMD Preview edits Quarto Markdown files in Obsidian with a live preview in a side pane, aimed at people who write .qmd but want Obsidian's editing, backlinks and vault navigation. The README states plainly that the live preview never calls Quarto and never executes Python, R, Julia, shell or other document code: it converts supported Quarto and Pandoc syntax — code cells, callouts, Pandoc divs, figure captions, image attributes and cross-reference placeholders — into Markdown or HTML that Obsidian itself renders. CSS referenced by the document's frontmatter or a nearby metadata file is applied to the preview, and an explicit Quarto render can be run from the preview pane when the official output is needed. It is recorded as a desktop plugin.
