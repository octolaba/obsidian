# pssah4/vault-operator

Vault Operator is described as an agentic AI operating layer for an Obsidian vault: the user states a task and the plugin plans, searches, reads, writes and reports back. The README contrasts it with a chatbot by describing a loop that picks an action, executes it against the vault, feeds the result back to the model and continues until the task is done, with every action visible, every write requiring approval and every change undoable in one click. It states that the plugin is free, open source and local-first, works with cloud models, an existing ChatGPT or Copilot subscription, or fully offline with Ollama or LM Studio, and covers inline chat over a selection alongside the sidebar agent, plus MCP, skills and memory.
