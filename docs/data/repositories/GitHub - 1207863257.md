# Atelier-Recherche/einkcursor

Eink Cursor replaces Obsidian's editing cursor with a static, non-animated one intended for e-ink screens. Its README, written in French, states that the plugin has no settings — enabling it is the whole configuration — and that it should not be used alongside another plugin that replaces the cursor, naming Animated Cursor as an example. It records the plugin id eink-cursor, an MIT license, and that the plugin is fully local with no network use, telemetry or auto-update.
