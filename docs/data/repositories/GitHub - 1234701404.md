# hehongxi/obsidian-cold-file-hider

Obsidian plugin that hides files not modified for a configurable number of days from the file explorer, with a default threshold of 60 days. The README states that any file type is covered, that a folder disappears once every file inside it has gone cold, and that opening a file through search, the quick switcher, a link, backlinks or the graph view permanently unhides it and its folder. It also lists a toggle that reveals hidden files at reduced opacity, rename-aware bookkeeping, exclusion of folders or glob patterns, and a bilingual English and Chinese interface.
