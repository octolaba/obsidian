# AbbaraS/custom-badges

Custom Badges renders inline badges inside a note from a short marker written in an inline code span, pairing a key with the text to display. Built-in types such as note, info and success carry their own icon and can be written without a value, any Lucide icon name works as a key, and further styles produce GitHub-style label-and-value badges in a blue or green variant or a plain-text form. An Insert badge command opens a fuzzy-search picker listing every type with its icon and inserts the badge at the cursor, using the current selection as the value when there is one. The plugin is a fork of an earlier badges plugin and is described as independent of it, and a value cannot contain a colon or a pipe, since both are used as delimiters.
