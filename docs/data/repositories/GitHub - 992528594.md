# peabody28/obsidian-extension-custom-file-viewer

Custom File Viewer opens non-Markdown files from the Obsidian file explorer in external applications chosen by file extension. Its settings hold a mapping from extensions to application paths, a default application for extensions that are not mapped, and an ignore list for file types that should keep opening inside Obsidian, such as Markdown, images or video. The recorded README documents installation from a local build rather than from the community catalogue.
