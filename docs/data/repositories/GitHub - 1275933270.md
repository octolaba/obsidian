# pilafdob/folderandgraphs-plus

Folder and Graphs Plus applies folder colour rules to the Folder2Graph-style folder nodes in Obsidian's Graph View, keeping its changes visual: vault files, folders and graph configuration are not renamed, moved, merged or rewritten. Each rule sets a folder colour, decides whether child notes inherit it, whether graph lines touching the folder are coloured, and whether the exact folder label is bolded. A setting prefixes every folder node label with a folder emoji, same-name folders can optionally be combined in the graph, and the plugin adds attachment, folder-node and canvas filters into the native Graph View filter panel, including filtering attachments by extension and showing iWork extensions as file types.
