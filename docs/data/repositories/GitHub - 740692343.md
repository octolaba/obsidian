# bitSchleuder/obsidian-monokai-theme

This repository holds an Obsidian theme that its README describes as inspired by the Monokai Pro editor theme, whose colour palette the author uses in every editor. The README records the two fonts configured in its screenshots, Anonymous Pro for interface and text and Victor Mono for monospace, and lists plugin support for DB Folder and Dataview. Its release notes carry a single entry, the initial 1.0.0 release.
