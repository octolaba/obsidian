# JoelYYoung/memo-ai

Memo AI uses a language model to extract knowledge chunks from notes and then reviews them on the SM2 spaced repetition algorithm. Extraction is guided by custom templates, and re-running it over a modified note keeps, modifies, deletes or creates individual chunks rather than starting again, with chunks rendering full Markdown including code blocks, formulas and tables. A push system scores chunks by importance level, familiarity and due date, schedules the top-scoring ones against a configurable threshold, and clears expired or completed pushes automatically. Review itself is conversational, with template-driven evaluation of how well the reader understands each chunk.
