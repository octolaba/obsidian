# mariomui/scroll-to-nav-top

This plugin scrolls the Obsidian file explorer back to its top, run from a Scroll To Nav Top entry in the command palette. Its README states the problem it addresses: the author does not use folders to organise notes, so scrolling up through a deep vault to reach the folders above is laborious. The rest of the README is developer notes covering an environment variable that points at a test vault, dependency installation, and a dev script.
