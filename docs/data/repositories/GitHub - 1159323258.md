# kavinsood/yaos

A real-time synchronisation engine for Obsidian that runs on a Cloudflare Worker deployed into the user's own account. It uses Yjs CRDTs so that concurrent edits merge into a single live vault state rather than producing conflicted copies or delayed file sync, and the README stresses that setup needs no terminal, no environment files and no database. The project ships in two parts, the Obsidian plugin and the small Worker server, and the README records explicit limits around durability receipts, attachments, empty folders and non-Markdown plugin files.
