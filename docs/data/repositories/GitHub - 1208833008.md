# stevenmichaelthomas/cosmos-obsidian

The repository holds Cosmos, an Obsidian plugin that renders a vault as a solar system in which each file becomes a body such as a planet, moon, asteroid or comet. The README states that each file is run through a one-way cryptographic transform on the device, that the length, density and form of the writing decide the body type and its orbital parameters, and that only those numbers are sent to the Cosmos service while the text, file names and vault structure are not. It attributes irreversibility to a per-system secret held only on the device; that claim is the README's own and is not verified here.
