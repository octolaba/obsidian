# houcheng/obsidian-cycle-in-sidebar-plugin

This plugin adds commands for cycling through the tabs of Obsidian's left and right sidebar panels with a hotkey, in both forward and reverse directions. It sets no bindings itself: the README asks the user to assign shortcuts in the Hotkeys settings, and suggests Alt-based defaults alongside a Vim-style alternative using bracket keys.
