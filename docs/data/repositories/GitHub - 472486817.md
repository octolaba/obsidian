# mnaoumov/obsidian-custom-attachment-location

Obsidian plugin that customises where attachments are stored, using tokens such as a note file name or a formatted date, in the manner of Typora. Its README lists changing the attachment folder location, changing the file name of pasted files, a collect-attachments action that moves attachments out of notes into the configured folders, and a delete-unused action that moves attachments no note references to the trash after a confirmation dialog. A demo vault of usage examples ships with every release and can be opened by a command, downloaded from the releases, or read from the repository. The settings documentation warns that other plugins might intercept attachment insertion.
