# endlessblink/detailed-canvas

Detailed Canvas enriches Obsidian Canvas link cards with generated summaries, extracted metadata and cover images. It scrapes the card's URL for title, description and cover image, extracts tweet content, images and author information for Twitter or X links through the fxtwitter API, and replaces the plain link with a rich card. Enrichment runs from a link card's context menu, from commands covering the selection or every card in the canvas, or automatically when a new link card is pasted. The README lists Ollama as a local provider and OpenAI, Claude, Groq and OpenRouter as cloud providers requiring an API key stored locally in the vault.
