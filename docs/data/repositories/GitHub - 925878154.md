# Cormac-C/obsidian-paste-plugin

PDF Paste cleans up text copied from PDFs and other sources before it lands in a note, removing the unwanted newlines and hyphenated line breaks such copies usually carry. The command is found in the command palette under PDF Paste, and the README recommends binding it to a hotkey set under the Obsidian hotkey settings.
