# hans/obsidian-citation-plugin

This plugin reads an academic bibliography exported in BibTeX or CSL-JSON format and makes those references searchable from inside Obsidian. Its recorded features open or create a literature note for a reference, with the note's title, folder and initial content configurable, and insert citations into the current note. Setup is the path to the exported file, given in the plugin settings; the README describes exporting a collection from Zotero with Better BibTeX, recommends the keep-updated option, and notes that the BibLaTeX export carries more information but loads more slowly than the JSON one.
