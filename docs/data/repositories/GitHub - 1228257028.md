# writerP-777/obsidian-writing-studio

Turns Obsidian into a dedicated environment for long-form nonfiction, bundling a project binder that renders the project's folder tree as a manuscript, writing and focus modes, typography tools, a sprint timer, progress tracking, manuscript export and WordPress publishing into one plugin. A sidebar file explorer browses, previews and pulls content from anywhere in the vault without leaving the current draft. The README records the plugin as desktop only.
