# JhihJian/obsidian-heading-mindmap

The repository holds Heading Mindmap, an Obsidian plugin that opens a note's heading structure as an editable mind map while keeping the Markdown file as the source of truth. The README records the file itself as a document root with every real heading, including several H1 headings, as editable nodes, and a pane below the map that renders the selected heading's body with Obsidian's Markdown renderer and switches in place to a source editor when editing, saving only that body. Keyboard shortcuts are recorded for adding child and sibling nodes, editing a title or a body, promoting, reordering, collapsing and deleting, with arrow keys moving the selection. It also records file nodes that expand another file's outline read-only with a fuzzy search when adding them, optional read-only nodes for list items, toolbar zoom controls, and preservation of collapsed nodes, selection and zoom.
