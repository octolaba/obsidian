# mmargenot/tezcat

Tezcat indexes an Obsidian vault with AI embedding vectors and surfaces related notes and blocks while writing, in the style of a remembrance agent. Results are returned at both note and block level, and can be used to insert a link to the source, insert the content itself, or open the page it came from. Two search implementations are recorded: naive vector search and a hybrid mode that combines vector similarity with full-text search. The README states that embeddings come from a local Ollama provider or from OpenAI embedding models, and warns that frequent embedding calls to a proprietary endpoint may incur costs.
