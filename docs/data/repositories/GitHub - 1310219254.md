# hifengzy/ima-sync

Ima Copilot Sync copies a Tencent IMA knowledge base and its standalone notes one way into an Obsidian vault, mirroring each knowledge base as its own folder and keeping the source directory structure. Notes and web articles become Markdown with the source link kept, inline images are downloaded into an attachment folder and relinked, and PDF, Office and image attachments are stored as they are with a generated stub so they stay searchable. Each document gets title, created, source and tag frontmatter, user-added properties survive updates, and syncing is incremental by document id and can run on a schedule with a five-minute minimum interval. A client id and API key are entered in settings and stored locally, requests go only to the IMA service, and Obsidian 1.13.0 or later is required.
