# normanify/obsync_webdav_gpg

Obsidian plugin for bidirectional, end-to-end encrypted sync with any WebDAV server, Nextcloud among them. The README states that file contents and every file and folder name are encrypted locally, each file's AES-256-GCM key being wrapped in a fresh ML-KEM-768 key encapsulation — the post-quantum standard the project names as the replacement for RSA and elliptic-curve schemes — so the server stores only random binary and the secret key never leaves the device. The implementation is pure JavaScript, with no WebAssembly and no native dependency. A prominent notice records that version 2.0.0 breaks compatibility with the earlier OpenPGP scheme: old keys, passphrase and all previously encrypted remote data are invalidated, a new key pair has to be generated, and the remote directory emptied.
