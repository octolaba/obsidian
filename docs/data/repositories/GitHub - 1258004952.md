# HornatX/vault-explorer-pro

The repository carries no description; its README presents Vault Explorer Pro as an all-in-one sidebar enhancement for Obsidian. The documented functions are folder shortcut icons that open frequently used notes from a collapsed folder with a custom icon and colour, inline file nesting that displays an associated file after the main filename and hides the original, folder locking that blocks accidental expansion, per-folder limits that collapse all but the first or last N files, automatic source mode for named files, automatic collapsing of the properties panel when a Markdown file opens, and fully hidden folders toggled from the command palette.
