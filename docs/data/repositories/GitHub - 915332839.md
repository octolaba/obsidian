# Shanshuimei/obsidian-generate-timeline

This repository holds Generate Timeline, described upstream as an Obsidian plugin that generates timelines from tags, folders, files or metadata automatically. The README documents four sources: a folder, a metadata attribute and value, a tag including its subtags, and the internal links of a chosen file, each available as a command that produces either a timeline view or a Markdown file. It adds milestones marked by a custom frontmatter attribute and given a distinct card style, and customization settings such as timeline line width and colour.
