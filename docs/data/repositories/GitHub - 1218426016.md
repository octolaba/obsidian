# SrWildman/Obsidian-Gitlab-Inbox

Fetches a GitLab review queue, authored merge requests and pending todos on a configurable interval, writes them into a vault note as Tasks-plugin-compatible checkboxes, and shows the same items in a sidebar panel with clickable references, status badges and per-item actions. Items checked off stay checked across refreshes, merged or closed merge requests and resolved todos are removed automatically, and a status bar count opens the panel. Default categories — needs your review, re-review, approved, your merge requests, and mentions and todos — can be renamed, reordered or disabled. A rules system assigns priority labels from conditions such as review age, mentions, a failing pipeline or waiting threads, with the first matching rule winning and every threshold configurable.
