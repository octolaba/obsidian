# gabrielbacha/Obsidian-Section-Variants

Section Variants keeps parallel versions of a Markdown section inside one note instead of splitting them across notes, using a Pandoc fenced div that contains two or more labelled variant divs. Block attributes control the identifier, the box title, whether variants are shown as a toggle or as columns, the default label, column width ratios, and responsive behaviour, and single-token labels may use a shorthand form while labels with spaces or punctuation use the explicit variant form. Hovering or focusing a block reveals its labels together with controls to add a variant and to switch between toggle and column views, Shift-selecting a label applies it to every matching block in the note, and a menu offers adding, renaming and deleting variants as well as deleting the whole box. Every deletion asks for confirmation, and the final variant cannot be deleted on its own.
