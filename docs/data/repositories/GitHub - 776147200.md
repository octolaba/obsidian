# jobedom/obsidian-hemingway-mode

Hemingway mode disables all the keys involved in editing — cursor movement, backspace, the cut shortcut and the like — and only allows text to be added at the end of the current note, which the README offers to those who fight themselves to avoid editing while writing. No repository description is recorded, so this body rests on the README alone. The mode is switched with a `Hemingway Mode: Toggle active` command that can be assigned to a shortcut, put on a button or run from the command palette.
