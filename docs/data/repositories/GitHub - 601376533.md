# yiglas/obsidian-file-publisher

Publishes a note to an HTTP POST endpoint configured in the plugin settings together with an API key and an API secret. The README describes creating a template whose frontmatter carries title, excerpt and timestamp fields, inserting it into a new note, and then sending the note with a Publish file entry in its context menu.
