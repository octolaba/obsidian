# rekby/obsidian-natural-link

This repository holds Natural Link, an Obsidian plugin for linking to notes by typing words in any grammatical form; the repository records no description, so this summary follows the README alone. Its morphological search matches a note titled Wooden box from a query such as wooden boxes or the incomplete prefix wood and ignores word order, with Russian morphology covering consonant alternations and suppletive forms and English handled by Snowball stemming plus a dictionary of irregular forms. The search also covers note titles, frontmatter aliases and the display text of existing links, and the README records an optional setting that replaces Obsidian's standard inline link suggestions with this search.
