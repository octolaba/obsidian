# peter-yanase/obsidian-advanced-ruby

Obsidian plugin that renders and edits ruby annotation, showing Markdown ruby syntax as HTML ruby tags without changing the note on disk. It covers the full range of Unicode, so it serves semantic glosses and layered annotations as well as East Asian phonetic guides, and it leaves code blocks and inline code untouched. Editing commands wrap a selection, insert an empty wrapper and convert a note between Markdown and HTML ruby, with optional smart arrow keys that step over an annotation instead of revealing raw markup. The README states the plugin has zero dependencies, stores and transmits no data, and is considered feature-complete.
