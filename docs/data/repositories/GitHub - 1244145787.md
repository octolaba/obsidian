# realhenrylan/obsidian-with-kilocode

KiloCode for Obsidian bridges an Obsidian vault and the KiloCode CLI, so the AI tool already used for coding can also work on the knowledge base. The README describes the bridge as bidirectional and requiring no configuration, with AI skills kept in a skills folder and conversation history in a sessions folder inside the vault itself. The problems it sets out to address are notes drifting into disconnected silos, tags for one concept diverging, weekly review piling up uncurated, and knowledge accrual staying manual.
