# quangnd159/trailmark

Trailmark draws a stack of thin bars along the left edge of a note that has at least three headings, one bar per section, in Live Preview and Reading view. Hovering or focusing a bar shows a preview card for that section and clicking it jumps there, while neighbouring bars react to pointer proximity; Tab moves between bars and Enter follows one, and a command focuses the first section. Previews render a deliberately narrow subset of Markdown, covering emphasis, inline code, links, lists and blockquotes while leaving out embeds, images, fenced code, tables, HTML and display maths. The heading threshold and whether the rail appears in each view are settings, and the plugin reads only headings and short excerpts and makes no network requests.
