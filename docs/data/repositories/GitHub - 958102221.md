# eoinhurrell/obsidian-inboxer

Adds two commands that write into dedicated sections of the current note: one adds a heading under an INBOX section, the other adds a timestamped heading under a TIMELINE section. The section heading is created when missing and reused afterwards, new entries are added as child headings, and the plugin places the cursor for immediate typing. The heading text searched for is configurable for both sections; the README describes the intended use with daily notes or project notes.
