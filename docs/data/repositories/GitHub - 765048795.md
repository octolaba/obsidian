# charliecm/obsidian-line-commands

Obsidian Line Commands adds commands for selecting, copying, cutting, pasting, inserting, and duplicating lines around the cursor or selection. Separate paste-before and paste-after actions, plus list and checkbox continuation for inserted lines, make the commands usable on mobile toolbars.
