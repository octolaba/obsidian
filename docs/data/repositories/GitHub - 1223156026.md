# andrewkopylev/vaultbridge

Vault Bridge SFTP synchronises an Obsidian vault between desktops through the user's own SSH or SFTP server, with no cloud or proxy service in between. The README describes bidirectional sync built on a three-way diff of the local state, a remote manifest and the last-synced snapshot, conflict resolution that keeps both versions by renaming the losing copy, a server-side lock and a manifest generation counter for multi-device safety, per-file SHA-1 comparison so unchanged files are skipped, and atomic transfers through a temporary file and rename. Protective behaviours include a modal when a sync would delete more than 5% or twenty files, refusal to interpret a wiped remote manifest as a mass local delete, and self-healing of manifest entries missing on the server; it is documented as desktop-only because mobile Obsidian cannot open raw SSH sockets.
