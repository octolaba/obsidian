# vicky469/aside

An Obsidian plugin that adds side comments to notes from a dedicated sidebar, where they can be drafted, edited, resolved, reopened and deleted; resolved comments are archived rather than removed. Page notes work on Markdown, PDF and HTML files while text-anchored notes are Markdown-only, and a side note accepts wikilinks, tag search through #, and @todo markers that collect in a Todo index tab. The plugin maintains a vault-wide comment index note and lets the index sidebar switch between the comment list and a thought-trail graph that follows side-note wikilinks across connected files. On desktop it also offers agent replies through @codex or @claude that can create anchored notes or apply edits, plus experimental Cloudflare Pages publishing.
