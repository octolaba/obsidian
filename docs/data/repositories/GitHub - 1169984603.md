# lavs9/obsidian-ghostty-terminal

Embeds a terminal pane in Obsidian built on the Ghostty terminal parser compiled to WebAssembly rather than on a JavaScript terminal emulator, which the README credits for grapheme clusters and wide characters, 256-colour and truecolor, hyperlinks and the Kitty graphics protocol. A Python helper spawns the shell in a real pseudo-terminal using the standard library, avoiding native Node addons, and a canvas renderer draws with exact character cell metrics so columns stay aligned on resize. The plugin reads the user's own Ghostty configuration for font and palette, supports several independent terminal panes and splits, adds a file-explorer entry that opens a terminal at the selected path, and offers a restart button when a shell exits. The README records it as desktop only for macOS and Linux, needing Obsidian 1.6.0 and Python 3.8 or later, with Windows unsupported.
