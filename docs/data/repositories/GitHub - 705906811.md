# anil-e/obsidian_gchat_plugin

This repository holds Google Chat Reminder, whose README describes marking a task in a note with a dated format so that a reminder is posted to a Google Chat room through a webhook when it falls due. The README says the plugin scans all notes every three minutes, that the webhook address is configured in the plugin settings, and that only the marked reminder text and its due date leave the vault. No upstream repository description is recorded, so this body rests on the README alone.
