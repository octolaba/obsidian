# NoteNerdOfficial/asana-connect

Obsidian plugin that embeds, creates, searches and synchronises Asana tasks inside notes. A fenced asana-task block renders one task from its GID or URL with name, assignee, due date, project, description, custom fields and a checkbox that completes or reopens it, while an asana-tasks block renders a filtered live list scoped to the user's own tasks or to a project. It also adds a My Tasks sidebar grouped by due status and task creation from selected text. The README states the personal access token is kept in Obsidian's encrypted local plugin data store and does not leave the machine.
