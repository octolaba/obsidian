# elijahchan2019/theme-h2os

elijahchan2019/theme-h2os holds H2 OS, a geometric light theme for Obsidian that carries the design discipline of HydrogenOS into a writing environment, on desktop and mobile and with no plugin required. Its mark sets three shapes in a fixed relationship, a square for structure, a circle for daily use and a triangle for inspiration rising where the two overlap, which the README presents as the working diagram of the whole theme. Red is treated as a signal rather than decoration, marking where you are through the active tab title, the open-file dot, the caret and pinned tabs, and marking what just happened through a checked task or a search match.
