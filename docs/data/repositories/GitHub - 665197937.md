# vburzynski/obsidian-task-status

Obsidian Task Status changes the status marker of a checkbox task through a searchable modal. The README records selecting one or more lines and running a command that opens a semantically searchable quick menu of custom status markers, which both swap an existing marker and turn non-task content into a task, with the set of statuses configurable in the plugin settings. It notes that the design is keyboard-driven with a fuzzy finder so no character has to be memorized, and that the plugin assumes task status styling comes either from a theme such as Things or Minimal or from the user's own CSS snippet, with setup for several themes documented in separate files.
