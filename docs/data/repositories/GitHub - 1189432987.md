# rospaans/obsidian-agent-mcp

Obsidian plugin that connects the vault to coding agents such as Claude Code and Codex. It ships a terminal emulator built on xterm.js with a pseudo-terminal bridge running on the system's Python 3 and no bundled native binaries, launching straight into a chosen agent rather than a bare shell; a dropdown switches agents or drops to a plain terminal, restarting the session and remembering the choice. Agents are enabled individually in settings, which reports whether each command-line tool was found on PATH and shows an install hint instead of an error when one is missing. A local WebSocket server bound to 127.0.0.1 on a random port writes a lock file under the Claude IDE directory so Claude Code discovers Obsidian as it would another editor.
