# Bluemoondragon07/obsidian-future

Future is described as a simple theme inspired by the Anytype note-taking software. Its README states that the Style Settings plugin is required, and lists a gradient background for the workspace, an OLED dark mode toggle, heading styles that can be made more or less colourful, and a changeable username and icon shown in the settings and below the file explorer. It credits the creators of Anytype and gavinmn for a Safari tabs CSS snippet.
