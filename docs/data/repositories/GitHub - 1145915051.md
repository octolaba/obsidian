# LarchLiu/obsidian-infographic-plugin

Obsidian plugin that renders AntV Infographic code blocks inside notes. A fenced block with the language `infographic` carries a template name and its data, for example a radial-tree template with a nested children structure. The README points to the AntV Infographic learn pages for the full syntax and further examples.
