# oylbin/obsidian-external-file-embed-and-link

Embeds and links local files that lie outside the vault, covering Markdown, PDF, images, audio and video, and creates links that open such files in the system's default application. Paths are written against virtual directories, an identifier followed by a relative path, where the identifier is mapped to a different local directory per device so the same note resolves on several machines and operating systems. A home and a vault directory are predefined and further ones are defined in the settings, and commands add an embed or a link through a file picker.
