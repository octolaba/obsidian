# takeshy/obsidian-discussion-hub

Repository for Discussion Hub, an Obsidian plugin that provides a shared multi-model discussion interface and its orchestration. AI plugins — the README names LLM Hub, Gemini Helper and Local LLM Hub — connect at runtime and contribute their available text models, so models from different providers join one structured discussion, and the user can be added as a participant or voter. A run consists of parallel turns that build on earlier ones, a conclusion from each participant, a vote by separately configured voters, and an announced winner or draw whose transcript can be saved as a Markdown note. Roles, turn counts and reference attachments up to 20 MB each are configurable.
