# Rohith-AM/Obsidian-Vellum

Vellum is a dual-mode Obsidian theme pairing a warm Vanilla Parchment light palette with a Charcoal Grey dark one, using Playfair Display for headings and Charm for body text. The README documents a sepia toggle that switches the light theme's font from navy blue to warm brown, Style Settings controls for font size, line height, content width and accent colors, and an interface that hides elements until they are needed. It states WCAG AA accessibility with a measured 6.48:1 contrast ratio on dark mode and reports mobile support, and records both fonts as loaded from Google Fonts and working offline once cached.
