# ChristianLempa/obsidian-bases-kanban

This is Christian Lempa's edition of the Kanban Bases View, carrying its own plugin identifier and Bases view type so that it can coexist with other kanban Bases plugins. Like the view it derives from, it generates columns from any property of the base, moves cards by drag and drop, reorders columns by a handle, assigns column colours, saves column order per property, collects notes without a value in an Uncategorized column, and offers swimlanes, quick add buttons, custom card titles and cover images. Its own additions are an image property that accepts a list of images as a gallery, collapsing and expanding individual columns, and a choice of small, medium or large column widths.
