# gloamfox/obsidian-smart-scribe

Repository for SmartScribe, a plugin that generates titles, tags, categories and summaries for notes and rewrites selected text. Its README lists six providers with a default model each, including Claude, OpenAI, DeepSeek, Qwen, Zhipu and Xunfei Spark, each configured independently. Generated tags are drawn preferentially from tags already in the vault, category suggestions follow the folder structure, metadata can be previewed and edited before it is applied, and text optimisation shows the rewritten text beside a list of the changes suggested.
