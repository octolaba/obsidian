# BambusControl/obsidian-unicode-search

Unicode Search indexes the Unicode Character Database and inserts characters into the editor through a search command, on mobile as well as desktop. The README records fuzzy search by name, codepoint or keyword, marking frequently used characters as favourites with their own hotkeys, saved filters over planes, categories and custom sets, and usage statistics that surface often-used symbols. It recommends assigning a hotkey to the search command, and all settings are managed from Obsidian's settings pane.
