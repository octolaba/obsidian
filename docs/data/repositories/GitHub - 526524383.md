# jajaperson/obsidian-literate-haskell

Literate Haskell is described as a plugin for integrating literate Haskell files into a personal knowledge base. Its README explains the background: Haskell's literate programming support lets code inside .lhs files behave like ordinary source, but a block must be surrounded by begin and end code markers that the author would rather not see in a note. The plugin therefore treats .lhs files as Markdown and hides those markers inside Haskell code blocks in such files.
