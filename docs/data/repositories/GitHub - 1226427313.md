# jimmitchell/tasks-to-omnifocus

Obsidian plugin that forwards uncompleted checkbox tasks from the active note to the OmniFocus inbox and then marks them complete in the note. Four commands cover the whole note, the task at the cursor, the tasks inside an editor selection, and completing every task without sending anything. Each forwarded task carries a link back to its source note, and nested checkboxes are folded into the parent task's note body or recreated as real subtasks when the hierarchy setting and a supporting send mode are in use. Inline Dataview-style fields on a task line map to OmniFocus due dates, defer dates, flags and time estimates, tags and the destination project come from settings or per-note frontmatter, and the README names OmniFocus 3 or later on macOS or iOS as the requirement.
