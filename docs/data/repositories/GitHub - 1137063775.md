# davidszp/obsidian-rationale

Rationale is an Obsidian theme for writers, researchers and academics, built on serif body text and monochrome icons to keep attention on the document during long reading and writing. It ships four colour schemes, each in light and dark: Academic in monochrome, Anthropic in warm cream with terracotta accents, Nordic in cool blue-greys, and Old Money in ivory, walnut and bronze, switched through Style Settings. Its default typography pairs Source Serif 4 for body text, Space Grotesk for headings and JetBrains Mono for code, and the README states that all fonts can be replaced through Style Settings.
