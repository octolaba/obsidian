# Netajam/obsidian_note_uid_generator

Obsidian plugin that generates unique identifiers for notes and manages them in frontmatter. Four algorithms are offered: UUID version 4, NanoID with configurable length, alphabet and separator positions, ULID, which is lexicographically sortable and encodes creation time, and Snowflake, a 64-bit time-sortable numeric identifier whose node component is derived from the machine's MAC address on desktop and from a persistent random value on mobile, either being overridable by hand. The README also documents manual and automatic generation, a configurable metadata key and copy formats, bulk operations within folders, and an in-memory cache of existing identifiers used to detect duplicates.
