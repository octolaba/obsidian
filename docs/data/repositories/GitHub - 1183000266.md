# jonmccon/obsidian-time-blocks

Time Blocks is a weekly planner for Obsidian that schedules existing vault tasks onto a calendar grid by dragging them from a backlog. The grid covers seven days hour by hour within configurable workday bounds, snaps a dropped block to fifteen-minute increments, and lets a block be moved, resized from its bottom edge or removed; a day view is available in the right sidebar. The backlog sidebar scans the vault for tasks written in the Obsidian Tasks emoji format, sorts them by priority and due date, offers tag chips and text filters, pins overdue tasks, and hides tasks already scheduled for the current week. The README records two-way Google Calendar synchronisation with conflict resolution and an agent guide describing how external tools can read the backlog and schedule blocks through the plugin's data file.
