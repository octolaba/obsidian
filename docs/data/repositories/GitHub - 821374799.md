# nicosomb/obsidian-shrink-pinned-tabs

This plugin shrinks pinned tabs in the Obsidian interface in order to save screen space, and its settings can additionally show or hide the tab title. The README states that the plugin was inspired by a snippet posted by another user on the Obsidian forum, and it illustrates the default display alongside shrunk tabs with and without titles.
