# rafamss/obsidian-tlp-classification

TLP Classification labels Obsidian documents with a Traffic Light Protocol level, offering a dropdown that replaces the native text input for the property in the Properties panel, a keyboard-navigable modal from the command palette, and a status bar indicator that can also be clicked to change the level. Setting a level writes the property and a matching header template into the frontmatter, which the plugin regenerates when the property is edited by hand, and the template property is hidden from the Properties panel. When a document is exported with the separate Better Export PDF plugin, that template renders the classification badge on every page. The README states that the built-in levels and their colors follow the published TLP 2.0 specification, and that organization-specific levels can be defined in a Markdown file inside the vault.
