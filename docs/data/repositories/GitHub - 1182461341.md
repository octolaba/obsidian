# LykAunn/CalendarPlanner

This repository holds Calendar Planner, described in its README as a modified version of the Obsidian Calendar plugin that reads from a single master planner file instead of individual daily notes. All entries live in one planner file at the vault root or a configured path under date headers written in day-month-year or year-month-day form, and the calendar shows the entry text for each day rather than only a dot. Tasks can be viewed, added and completed from the calendar, checkbox syntax toggles completion, entries can span a date range, and a jump command moves to any date inside the planner file. Installation is described as replacing the existing Calendar plugin's main.js, so it is distributed as a drop-in replacement rather than as a separate plugin folder.
