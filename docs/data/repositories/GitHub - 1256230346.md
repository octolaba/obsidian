# Cheendfdf/marginnote-obsidian-sync

Syncs MarginNote 4 annotations, highlights, notes and mind maps into Obsidian; the README is bilingual, with its detail written in Chinese. It reads the live MarginNote SQLite database directly instead of an export, discovers the Core Data table shape at runtime, syncs only books changed since the last run by timestamp, and presents discovered study sets as a checkable list whose members are written into their own subfolders. Output is one Markdown file per book with frontmatter, annotations grouped by chapter and page in callouts, a generated canvas file for the hierarchical mind map with automatic layout and colour mapping, and a deep link back to each annotation in MarginNote. It requires macOS, MarginNote 4 and desktop Obsidian 1.5.0 or later, and offers manual sync, timed automatic sync, a forced full resync and status-bar feedback.
