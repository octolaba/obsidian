# Sunhaloo/OneNice

OneNice is an Obsidian theme based on Kognise's obsidian-atom, written because moving between an editor coloured by One Dark Pro and Obsidian felt disconnected to its author. Its stated aim is to reproduce that editor's feel inside Obsidian, and its references are obsidian-atom, onedark.nvim, onedarkpro.nvim and OneDark-Pro. The README shows dark and light screenshots, names Iconize, Dataview, Templater, Calendar and Highlightr as notable plugins, and lists JetBrainsMono, Iosevka and VictorMono Nerd Font as the fonts the author uses.
