# dwSun/obs-StripImages

Strip Images removes every image embed from one Markdown note, reached from the note's context menu, and handles the underlying files by reference count. An image referenced only by that note is moved into the vault trash folder with its original folder structure preserved and a numeric suffix added on a name collision, while an image referenced by two or more notes keeps its file and loses only the embed. Both wiki-style and Markdown-style embeds are detected, including network URLs, whose embed text is removed without touching any file. References are counted across Markdown files only, and a confirmation dialog reports the number of embeds and files affected before anything is changed.
