# canartuc/pubcopy

Pubcopy copies an Obsidian note to the clipboard as HTML shaped for Medium or Substack, so that formatting survives a paste into those editors, and also offers a plain Markdown copy with Obsidian-specific syntax stripped. It is triggered from the command palette, the editor context menu, where a selection is copied instead of the whole note, or the note's three-dot menu. The README records that 56 Markdown elements are handled and documents where the two targets differ, for example highlights becoming bold, headings below H4 flattened for Medium, and nested lists limited to two levels there while Substack takes unlimited nesting.
