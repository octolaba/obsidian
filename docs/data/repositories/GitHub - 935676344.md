# InfoFlow/Obsidian-InfoFlow

Syncs saved articles, web pages, notes and highlights from the InfoFlow service into the vault, converting HTML content to Markdown automatically. File names and note bodies come from customizable templates with variables for title, id, item type, source URL, author, tags, creation and update dates, content and the annotations section. Syncing runs manually from a ribbon icon or a command, or automatically at a configured frequency, and can be filtered by date range, tags, folders and last update time. The README states that an API token is required and that an active InfoFlow cloud account is needed, because local variants cannot be synced.
