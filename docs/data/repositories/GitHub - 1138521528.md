# TimoBechtel/obsidian-block-view

Block View is an extension for the Bases core plugin that turns notes into a database of blocks. It divides each file's content into blocks so that one view can list and filter specific sections drawn from many notes at once, while the standard Bases features — file filtering, sorting and grouping — still apply. The README gives examples such as collecting every paragraph tagged log or work from daily notes into a single timeline, and building a vault-wide library of quotes. It is installed from the community plugin store and configured as a base view of type block-view with filters and tag filters.
