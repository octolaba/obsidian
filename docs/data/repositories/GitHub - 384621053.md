# pjeby/quick-explorer

Quick Explorer adds a keyboard-oriented file explorer to Obsidian's title or status bar. It lets users navigate the vault or current folder, search by name, preview notes, inspect folder notes, and use familiar file and folder context actions without opening the sidebar.
