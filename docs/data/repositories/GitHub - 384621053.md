# pjeby/quick-explorer

Quick Explorer performs file explorer operations and shows the current file's path from the Obsidian title bar. The README contrasts it with the built-in file explorer, which it describes as almost entirely mouse-driven and slow when many folders hold many files: Quick Explorer is menu-based and keyboard-friendly, navigates from the vault root or the current folder without opening and closing a sidebar, and searches within a folder by typing. It also records a quick-preview mode for scrolling through the full contents of every note in a folder from the keyboard, Vim-style navigation hotkeys added in 0.2.11, and optional use of tab title bars in Obsidian 0.16.3, with its default breadcrumbs hideable through the Style Settings plugin.
