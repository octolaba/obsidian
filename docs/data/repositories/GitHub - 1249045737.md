# vipsyvipul/QuickClip-Capture-Manager

QuickClip Capture Manager renders and manages the clips that the QuickClip Capture Chrome extension saves into an Obsidian vault, which its README records as a requirement for the plugin to have anything to show. Each clip type gets its own card in Reading view: collapsible highlight cards with quoted text, source link, tags, capture date and a delete action; full-page articles with author, publish date, site, word count and a scroll progress bar; YouTube and Vimeo clips with an embedded player, timestamp chips that seek it and a sortable clip table; native tweet embeds; PDF highlights with a source file link and page number; and inline images with caption and metadata. A separate Clip Manager panel, opened from the ribbon or the command palette, browses everything clipped with filtering, tagging and annotation.
