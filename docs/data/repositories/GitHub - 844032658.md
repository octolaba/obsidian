# dsebastien/obsidian-replicate

This plugin connects Obsidian to Replicate.com so that its image-generation models, such as Stable Diffusion and FLUX.1, can be run from the vault. An image is generated from the current selection or from a prompt typed into a modal, the model is configured by name and optional version, and free-form JSON is passed to it as input, so any model taking a prompt can be used; the resulting URLs can be copied to the clipboard or appended to the note as Markdown image embeds. The README states that it requires a Replicate account, an API token and, for paid models, a billing method, and warns that generated images are kept on Replicate's servers for only one hour, so anything to be kept must be downloaded.
