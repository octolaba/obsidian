# stackBreakerX/obsidian-image-auto-upload-plugin

Image Auto Upload Pro uploads images from an Obsidian vault through PicGo, PicList or PicGo-Core and replaces the links in a note with the image host's URLs. It uploads pasted and dropped files, all local images in the active Markdown file, and files chosen from the native file picker; it also processes network images pasted as Markdown and Web Clipper files created in a configured folder, downloading each remote image to a temporary vault folder, uploading it, rewriting the link and deleting the temporary file afterwards. URLs the plugin has already relayed are skipped to avoid upload loops, and a domain blacklist limits which network images are handled. The README records the requirements as desktop Obsidian and a configured PicGo, PicList or PicGo-Core setup, and notes that the plugin id differs from the original plugin's so both can be installed side by side.
