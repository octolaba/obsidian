# Stianlyng/obsidian-vimium-plus

Vimium+ adds a Vimium-style keyboard layer to Obsidian with two modes. Reading mode is the default and opens notes in Reading view, where j and k scroll, d and u move by half pages, f shows click hints for links, buttons, tabs, the ribbon, the file tree and checkboxes, shift-J and shift-K switch tabs, b and shift-O reach bookmarks and an omnibar, and shift-H and shift-L move through history; pressing i drops into the editor where Obsidian's built-in Vim bindings take over, and a double press of Escape returns. The README states that the plugin is an independent reimplementation of the Vimium idea and is not affiliated with the Vimium browser extension or the existing Vimium community plugin.
