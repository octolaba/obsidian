# RanceLee233/Mini-Calendar

Mini Calendar embeds a compact one-week calendar below Obsidian's built-in file explorer, keeping the folder tree and calendar in one sidebar tab. Dates open or create daily notes using the core Daily Notes folder, filename format, and template, with indicators for existing notes and unfinished tasks. Week-start selection, ISO week numbers, rainbow dates, confirmation for past or future notes, and desktop/mobile offline use are configurable.
