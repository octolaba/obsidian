# tylersuzukinelson/zettelkasten-outliner

This repository holds Zettelkasten Outliner, an Obsidian plugin that generates an outline for the opened note together with all of its children. It assumes that the Zettelkasten structure is dictated by a parent property in the note's frontmatter and that this property is a single link to another note. Running the Create Zettelkasten Outline command from the command palette writes the resulting outline into a new note.
