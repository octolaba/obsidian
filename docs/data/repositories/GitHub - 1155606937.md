# POBSIZ/obsidian-diary

Diary presents ordinary Markdown notes in an Obsidian vault as yearly, monthly, daily and three-day planner views, using a configurable planner folder. The README records the plugin id, a minimum Obsidian version of 1.7.2, desktop and mobile support and a default English interface, and its screenshots cover all-day, timed, range, todo and plan entries rendered as grids, lists and timelines. Version 1.17.0 is described as adding a collapsible all-day section with event counts to the daily and three-day planners and improving events shorter than twenty minutes with compact cards, time tooltips and collision-aware layout.
