# tom-un/obsidian-checkbox-reorder

An Obsidian plugin that moves a checked to-do item to the bottom of its checkbox group, reproducing the automatic sorting of checked items found in Apple Notes. It is nesting-aware, so an item with sub-items moves as a group and indented items reorder within their own level, it animates the move with a ghost of the checked row, and a single undo reverts both the check and the move.
