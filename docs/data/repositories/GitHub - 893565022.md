# elpamplina/mastodon-threading

This Obsidian plugin composes threads and posts them to Mastodon, using Obsidian's editing capabilities to prepare the fragments before they are sent to the server. The README records inserting thread separators manually or automatically, showing the order and size of the fragments as they are typed, adding descriptions to images and other media for accessibility, and submitting individual posts or whole threads while checking the server's size limits and its supported visibility types. It states that the plugin was tested under a specific Obsidian version and may not work with older ones.
