# samwho/obsidian-wikidata-importer

This plugin pulls data from the Wikidata database into Obsidian notes. A note carrying a Wikidata entity id property gains that entity's Wikidata properties as note properties when the import command is run for the active file. A second command imports a new Wikidata entry into the vault.
