# SurprisedDuck/obsidian-pastel-dusk

Pastel Dusk is a dark-only Obsidian theme built on top of insanum/obsidian_nord, using a soft muted pastel turquoise accent over a deep, near-neutral dark background with gently rounded corners. The README lists how it differs from stock Nord: light mode dropped, a low-chroma base with a darker left sidebar, a distinct pastel colour for each heading level, pastel blue links and file names against neutral folders, panes floating as cards, and low-saturation syntax and callout colours. It credits Obsidian Nord by Eric Davis and the Nord palette by Arctic Ice Studio, and is MIT licensed.
