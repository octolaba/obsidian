# fangface-hub/obsidian_markdown_diarect_ial

Markdown Dialect IAL adds Pandoc-style Inline Attribute Lists to Obsidian, so custom IDs, classes and key/value attributes can be written directly in Markdown. The README records a settings screen where each item type can be enabled or disabled individually, an option to apply the IAL filters automatically on save, and a command that applies the filters to the active file.
