# ZHYX91/obsidian-heading-numerals

Separates whether heading numbers are stored in the Markdown file from whether they are visible in Obsidian: numbers can be written into headings, removed, displayed virtually without touching the file, or concealed where they already exist. Display and concealment use editor decorations and a Reading View post-processor, while writing, cleaning and renumbering go through an item-by-item preview and apply as one undoable transaction per note. Only standard ATX headings are touched, ambiguous numeric text such as versions and dates is left alone by default, and the preview warns that changed heading text can break links. Schemes cover hierarchical arabic numerals, Chinese official-document and legal-article styles and custom formats, and each note can override the global settings from its own control panel.
