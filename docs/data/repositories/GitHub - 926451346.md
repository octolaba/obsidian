# vran-dev/obsidian-composer

vran-dev/obsidian-composer holds Composer, described as an out-of-box Obsidian theme designed for comfortable reading and writing, published with an English and a Chinese README. Its three named colour schemes are switched through the Style Settings plugin, and the README shows its text formatting, table and callout styling, crediting the task checkbox to the Minimal theme. Development is split between a settings file holding the Style Settings options and a stylesheet holding the styles, which a build script merges into the distributed theme; the README warns that the settings block inside the built file is generated and must not be edited by hand.
