# tianxiangyu0717-hub/obsidian-aurora-dashboard

Opens a home view summarising the vault: note and word totals, notes without resolved backlinks, notes at or below a configurable length threshold, recently modified notes, and per-folder note and word counts, each drillable to the underlying list. Activity is charted as a 365-day writing heatmap, a cumulative resolved-link line chart and a 30-day added-word trend, alongside an animated 3D knowledge graph rendered with WebGL and a reorderable strip of shortcuts to installed plugins. A todo list is read from one explicitly configured Markdown file and is empty until that path is set. Everything is computed locally with no network calls, history is kept in the plugin's own data file, and dates before installation are estimated from last-modified times and marked as such; the interface text is in Chinese.
