# flyingnobita/obsidian-github-stars

This repository holds GitHub Stars, described upstream as displaying GitHub star counts next to repository links in notes, in Reading View, Live Preview and embedded Markdown. The README says repository addresses are detected automatically, that counts can also be written into the Markdown itself so they stay visible outside Obsidian, and that commands exist to refresh, embed and remove them. Counts are cached with a configurable expiry to limit API requests, numbers can be shown in full or abbreviated form, and an optional GitHub token raises the rate limit.
