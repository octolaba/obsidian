# alex-yelisieiev/macos-tahoe-obsidian

macOS Tahoe is an Obsidian theme that maps macOS system colors, materials and SF Pro chrome onto the app, with light and dark palettes selected by Obsidian's own base color scheme. System Blue drives accents, selection and focus rings, while frosted materials, soft radii and shadows are applied to chrome and overlays. The sidebar, ribbon, titlebar, menus, dialogs and form controls follow macOS patterns, properties fields drop heavy form chrome, and text sizes are left at Obsidian's defaults with no font-size overrides. The theme requires Obsidian 1.5.0 or newer.
