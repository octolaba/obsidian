# kasairo/floating-sticky-notes

Floating Sticky Notes keeps sticky notes as ordinary Markdown files in a configurable vault folder, listing them for editing of both content and filename in place. Each note can be given a colour that is stored in its YAML frontmatter, and a note can be opened in a popout window or in the main Obsidian window. Settings cover the storage folder, file naming, preview, editor height and window sizes. It requires Obsidian 1.7.2 or later on desktop, where the popout and always-on-top behaviour relies on desktop windows, and it makes no network requests.
