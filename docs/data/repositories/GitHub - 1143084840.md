# ZyphrZero/Termy

Termy embeds a terminal in Obsidian, pairing an xterm.js frontend with a native Rust PTY backend and offering search, copy and paste, prompt navigation, split panes and multiple sessions. Reusable workflows, made of terminal commands, Obsidian commands and external links, can be launched from the status bar or the command palette. The terminal is aware of the vault: text, files and folders can be dragged into it, and file references printed in its output can be opened directly. The README records integrations with Claude Code, Codex CLI and OpenCode that can inherit the active note's context, and marks the plugin as desktop only.
