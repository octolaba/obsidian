# kawecz/gallery-view-dashboard

Presents vault folders as a navigable gallery of cards with custom banner images, intended for browsing resources, courses and media. Clicking a folder card enters it and a file card opens the note, while a back button in the gallery toolbar returns to the parent folder. Selected frontmatter keys are displayed on the cards, and checkboxes allow task statuses to be changed from the gallery view. Settings take a library root path, the visible metadata keys, per-folder banner assignments chosen from a live vault tree and manual overrides, with path autocompletion and updates applied without a reload.
