# kilrkrow/flowscript-for-obsidian

FlowScript Diagrams renders fenced flow code blocks as inline SVG flowcharts in Obsidian, in both Live Preview and Reading view, using the FlowScript library by the same author. The syntax is an indentation-driven DSL where plain text is a process rectangle and markers introduce start and end nodes, decision diamonds, subprocess, input-output, data and note shapes, named branches, dashed retry edges, groups and swimlanes, plus per-diagram directives for flow direction and theme. Two settings exist: the diagram theme, clean light or clean dark, and a transparent background so the diagram blends with the vault theme.
