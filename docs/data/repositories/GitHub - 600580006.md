# MahmoudFawzyKhalil/obsidian-global-search-and-replace

This repository holds Global Search and Replace, described upstream as a plugin to do a global search and replace in all Obsidian vault files. The README says it searches every Markdown file for a match with optional regular expressions and case sensitivity, replaces a match on Enter or click, opens the note at a match with a modifier and Enter, and cycles through matches with the arrow keys. It also documents the special patterns a replacement string may use, such as inserting the matched substring or the text preceding it.
