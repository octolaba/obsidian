# ebullient/obsidian-markdownlint

This plugin uses the markdownlint library to lint files in an Obsidian vault. It reads a subset of the configuration files that markdownlint-cli2 supports — the JSONC, JSON, YAML and YML variants — and the README explains that other formats need interpretation or parsers that the author found unsuitable inside an Obsidian plugin. When one of those configuration files is present, Markdown files are linted against its rules and the issues are highlighted in the editor to be fixed as the file is written. Installation is documented through the BRAT beta plugin tester.
