# yoGhastly/poimandres-obsidian

This repository is an unofficial port of the Poimandres code editor theme to Obsidian, marked in its README as a work in progress. It is a dark theme based on the Poimandres colour scheme, with syntax highlighting for various programming languages and code snippets and colour used to differentiate elements in a note. Colours can be adjusted further from Obsidian's own theme settings, and the theme is licensed under the MIT License.
