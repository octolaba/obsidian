# shawnduggan/nova

Obsidian plugin that presents itself as an editor rather than a generator: it refines selected text, writes at the cursor and runs local clarity checks over a document. It can use a local Ollama API, OpenAI-compatible endpoints such as LM Studio, or the user's own keys for Claude, OpenAI and Gemini, and the README states that there is no proxy or telemetry service, so conversations stay in the vault and cloud requests go directly to the configured provider. A writing dashboard scores documents across clarity, conciseness, variety and discipline with a per-document breakdown and trend sparklines, and a prose linter opens in its own review pane to flag long sentences, passive voice, adverbs, weak intensifiers, qualifiers, complex words and repeated words or phrases, offering local replacements only when it can verify the text still matches.
