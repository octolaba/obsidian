# TfTHacker/Obsidian-WordNet

Obsidian plugin that looks words up in WordNet, the large lexical database of English developed by Princeton University whose licence allows use in other applications. The dictionary is opened from the command palette or from a ribbon button; options narrow as the word is typed, and pressing enter inserts the entry into the current document, while in preview mode the definition is shown in a notification window for about ten seconds instead. The README places the plugin in the author's Obsidian42 family and points at the author's site for the documentation.
