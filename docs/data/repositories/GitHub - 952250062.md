# Ai-Jani/about-blank

About Blank customizes Obsidian's empty file view — the new tab — by attaching actions to it: running a command, opening a file, or a grouped action. Each action can be given an icon, made to ask before execution, or registered as a command of its own, and the messages and buttons the view shows by default can be hidden. The README warns that the empty-file-view part relies on undocumented Obsidian behavior and may stop working in a future version, while the command-related features are designed independently; it also notes the view stays a genuinely empty file rather than a custom view.
