# julioagh/english-text-interpreter

English Text Interpreter explains a selected passage of English by sending it to a local LLM through Ollama and opening a panel with four fields: meaning in context, tone, cultural or situational background, and the writer's intent. The README states that the output language is configurable among Spanish, English, Portuguese, French and German, that the default model is gemma3 at a configurable Ollama endpoint, and that the selection must be at least five characters. It states that no data leaves the machine.
