# Devon22/obsidian-mediaviewer

Media Viewer provides a full-screen browser for the media files referenced in an Obsidian note, opened from a command or by clicking an image, with the arrow keys moving between files. It also renders a gallery code block that lays out several images, videos or note links as a grid, into which images can be dragged after creation. Gallery parameters set a title, thumbnail size, an add button, pagination above a given number of images, per-image alternative text, a thumbnail for a note link, and a content filter. Settings cover whether media files may be deleted, whether the first image opens automatically, whether clicking an image opens the browser, and the grid layout width.
