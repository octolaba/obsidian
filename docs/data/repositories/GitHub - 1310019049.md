# polygonhunter/daily-bible-verse

Daily Bible Verse adds a Bible verse to the daily note as a plain-Markdown callout carrying a localized verse reference, an attribution line and an optional emoji. The README records 526 curated verses shipped offline in public-domain translations across German, English, Spanish, French and Italian, a seeded shuffled-deck selection that avoids repeats until the pool is exhausted and gives the same day the same verse on every device, and an optional whole-Bible pool downloaded once per translation. A verse can be inserted automatically when the daily note is created, through a placeholder in the daily-note template, or by command, and the day's verse can be re-rolled once.
