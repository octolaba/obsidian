# daun/obsidian-pretty-urls

Pretty URLs changes how links are displayed in Obsidian's reading view by removing common prefixes, so a pasted address renders without its protocol or its www subdomain. Further rules strip mobile subdomains and the amp subdomain, apply the same formatting to links shown in the properties panel, and let a regular expression rewrite a URL-only link with a custom label. The README states that only the display is affected and that the note content remains unchanged.
