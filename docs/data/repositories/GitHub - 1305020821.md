# chuanqq/user-prompt-optimizer

User Prompt Optimizer refines a selected prompt inside Obsidian and streams the result back into the selection, with undo support and either template-based restructuring or a lighter wording pass that can mark missing information. It supports OpenAI-compatible and Anthropic providers, preserves technical examples and URLs, exposes reasoning and sampling controls plus interruption status, and sends only the selected text and chosen template to configured services.
