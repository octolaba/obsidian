# MichelleGDyason/docx-exporter-plus

DOCX Exporter Plus exports the active Markdown note to a Word document, targeting the common subset that opens cleanly in Microsoft Word, Apple Pages and Google Docs: headings map to standard DOCX heading levels, links stay clickable, embedded images and note embeds are exported, and image captions become plain numbered caption paragraphs. It renders through Obsidian before conversion, rasterizes SVG and WebP images to PNG because that imports more reliably, adjusts overly light text so it stays readable on white paper, and writes the result next to the source note, while PDF, audio and video embeds export as file reference links. Pandoc export commands cover the active note and assembled Longform projects, the latter joining scenes in project order, removing scene frontmatter and turning scene titles into headings.
