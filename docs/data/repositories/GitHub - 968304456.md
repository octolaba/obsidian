# cubexy/obsidian-pdf-printer

PDF Printer converts PDF documents in the vault into WEBP images so that their pages can be embedded and annotated in a note, without external dependencies. Selecting a PDF embed and running the convert command generates the images, saves them in a separate folder and replaces the PDF link with links to the page images, and multi-page documents are converted in a batch. Settings cover image quality from 0 to 1, the folder the printed images are stored in, whether a link to the printed PDF is shown above the pages, and the format used for the embedded image links.
