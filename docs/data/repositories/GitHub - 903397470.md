# MichaelFW-ui/mahgen-renderer

Mahgen Renderer renders mahgen mahjong notation inside Obsidian, both as a block and inline, so a hand written as tile groups is displayed as tiles. The README records that a river of discarded tiles can also be displayed, that inline use has no river mode, and it refers to the upstream mahgen project for the details of the notation. It also documents a nankiru mode whose block holds a question or answer identifier, a round and seat line and the hand, and CSS variables in the stylesheet that set the block, inline and row tile heights.
