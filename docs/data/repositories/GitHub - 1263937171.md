# arias007/obsidian-mobile-pdf-exporter

Mobile PDF Exporter adds one ribbon button, one command and one note menu item that open an options panel before exporting the current note to a phone-width PDF, and it can also produce DOCX, PPTX, PNG and self-contained HTML. The PDF combines a high-resolution visual layer with a real text layer so text stays selectable, embeds script-specific Noto Sans fonts only where required, and writes NoteDraw strokes as standard PDF ink annotations; its options cover page size, orientation, colour or grayscale, per-page margins, content scale, headers and footers. The README records that the active reading or editing surface is the primary layout source with hidden rendering used only as a fallback, that files are saved beside the note unless a custom vault folder is chosen, and that the interface text follows an Auto, Chinese or English setting.
