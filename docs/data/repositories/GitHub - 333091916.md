# dvcrn/obsidian-filename-heading-sync

The repository holds Filename Heading Sync, an Obsidian plugin that keeps a file's name and its first heading in step. Its README records four triggers: renaming a file updates its heading, opening a file without a heading inserts one, opening a file whose heading differs from its name updates the heading, and editing the heading renames the file. It states clearly that the plugin overwrites the first heading the moment a file is opened and can be considered destructive, and that the file save and file open hooks can be disabled in the settings so only the manual sync commands remain.
