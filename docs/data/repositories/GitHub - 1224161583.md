# Thalikbussacro/graph-filter-builder

The repository holds Graph Filter Builder, an Obsidian plugin that adds a panel for composing filters for the graph view. The README records each clause as its own line with an include or exclude toggle, a type of tag, path or file, and a value field with autocomplete for that type; the lines are combined with AND and written live into the native filter input, so bookmarks continue to save the filter normally. It states the plugin generates the filter string rather than replacing the native filter. Recorded limitations are that it is desktop-only, targets the global graph rather than local graphs, does not reconstruct lines from a filter typed by hand, and relies on internal DOM selectors that an Obsidian update could break.
