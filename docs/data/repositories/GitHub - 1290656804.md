# johannes-kaindl/vault-crews

Vault Crews runs teams of local LLM agents over an Obsidian vault against a model served by LM Studio or Ollama. A crew is a deterministic pipeline of exactly three task kinds — a collector that gathers context, one schema-validated chat completion, and an actions step that applies a validated action list — so the orchestrator decides flow, paths and writes while the model only decides content. Every model output is extracted, validated against a versioned built-in schema and bound to the collected material, with one repair retry for malformed JSON, so a path or enum value that did not already exist cannot be invented. Before a run touches a note its prior state is snapshotted copy-on-write through the Obsidian vault adapter, and undoing the last run restores changed notes and moves run-created ones to the trash without needing a git repository.
