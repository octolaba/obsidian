# Ameer-Jamal/obsidian-export-mermaid-diagrams

Export Mermaid Diagrams copies or saves a rendered Mermaid diagram as SVG or PNG, for pasting into places that do not render Mermaid. The actions are reached from an export button on the left of a rendered diagram or from a right-click menu on the diagram or on the Mermaid code block. Export defaults to a high-contrast readable light mode so a dark Obsidian theme does not produce hard-to-read images, with an option to match the theme as shown instead, a configurable PNG scale from 1x to 4x, and a background colour used in the theme-matched mode.
