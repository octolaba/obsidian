# LucasHJin/obsidian-pets

Pixel Pets opens a view in the vault where pixel pets play, modelled on the vscode-pets extension for another editor. The README records 22 different cats with seven or more animations each and individual names, ten backgrounds, and interactions that include throwing a ball for a pet to fetch, petting it, and leading it around with a pet toy. The view can be moved, or expanded so that the whole vault becomes the playground, and a chatbot called Catbot answers questions with context from the vault.
