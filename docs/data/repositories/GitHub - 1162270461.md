# danyim/obsidian-custom-publish

The repository holds Obsidian Custom Publish, a plugin whose command palette actions set frontmatter properties for a publishing workflow. Commands publish, unpublish or toggle a page, flip a visibility property, and copy a page's published URL built from a configured template, adding the target property to the note when it is missing. The README states that the plugin is tied to no hosting provider and assumes an existing system that scans notes and publishes on those properties, and settings name the publish and visibility keys, the URL template and a slug style.
