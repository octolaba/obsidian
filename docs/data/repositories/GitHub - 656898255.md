# mAAdhaTTah/obsidian-poker

Obsidian Poker documents and displays poker hands inside notes. The README states that a card is written as inline code carrying a configurable prefix, defaulting to pkr, then a colon and the card in standard two-letter notation, with the rank drawn from A, K, Q, J, T, the digits and X for any rank, and the suit from d, h, s, c and x for any suit; several cards can be written in one span. Configuration is limited to that prefix, and the roadmap records cards without a suit, unknown suited or offsuit cards, a command generating a random number of cards, and a hand replayer defined in YAML as not yet implemented.
