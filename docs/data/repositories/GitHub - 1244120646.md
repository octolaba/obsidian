# icarian-systems/feynman-research-agent

Feynman is a research agent that runs against a vault from a local Docker container using the user's own Anthropic API key. A chat panel opened from a ribbon icon or command exposes built-in workflows such as deep research, literature review, audit, recipe and review, each with a small argument form, and the agent streams tool calls, intermediate reasoning and citations into the panel while the run can be cancelled; workflows can also be started from the command palette with the active file or selection as context. Every tool call that writes a file or fetches a paper opens an approval modal showing the exact command and target path, with Deny focused by default. Finished artifacts are written as Markdown under folders inside the vault, and the README warns that API keys are stored in plaintext outside the vault in a secrets file that the plugin does not encrypt.
