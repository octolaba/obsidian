# flynt-theme/flynt-obsidian

flynt-theme/flynt-obsidian holds Flynt for Obsidian, described in its README as warm tones with zero visual noise. The theme.css file is generated from a template using the author's strike tool, installable through Homebrew, and the theme itself can be installed from the community browser or by copying theme.css into the vault. It is published under the MIT license.
