# czottmann/obsidian-blockquote-levels

This plugin adds two commands to Obsidian that increase and decrease the blockquote level of the current line or selections. Increase adds a Markdown blockquote prefix and repeated calls add further prefixes; Decrease removes the first prefix from each line, processing lines individually so a selection with mixed quote levels loses one level per line where one is present. No hotkeys are set out of the box, so the commands are run from the command palette or bound by the user. The README points bug reports at the repository's issues and moves discussions to the author's forum.
