# ctxinf/simple-disguise

Simple disguise switches the editing area between a disguised appearance and the normal one, which the README describes as a way to keep content being edited from being read easily by people passing by in a public space. The effect is implemented by changing the styles of the editing area through CSS, and it is toggled from a button in the sidebar. The README lists what is not supported: reading view, control through a command, and defining the styles in the settings, since styles can only be changed by editing the plugin's stylesheet directly.
