# chasebank87/unofficial-fabric-plugin

This plugin integrates Fabric with Obsidian, connecting to external APIs to fetch and manipulate note content according to user-defined patterns and models. The README lists watching a designated folder for custom patterns and syncing them, downloading and sharing community patterns, automatic detection of YouTube links in notes, connections to the Fabric Connector and Tavily APIs, dynamic rendering of returned content, and a debug mode with extra logging. It states that Fabric and Fabric Connector must be installed separately as prerequisites, and it opens by pointing readers to a different plugin by the same author that does not require either of them.
