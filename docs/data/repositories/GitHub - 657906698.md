# ckt1031/obsidian-wordwise-plugin

Wordwise adds AI text commands to Obsidian aimed at modifying and improving writing, using either its built-in prompts or prompts the user defines, including file-based ones documented separately. Its README records support for OpenAI, Google Gemini, DeepSeek, Anthropic and OpenRouter models. It positions itself against other AI plugins as a lightweight tool with a simple interface and states that it is designed to work on all devices including mobile, where the README says some other plugins feel laggy or are unsupported.
