# ShivrajRath/daydeck

Repository for DayDeck, a task dashboard for Obsidian that organises work into draggable, resizable sections such as Today, Next, Waiting, Focus Hub, Learning and Ideas rather than one linear list. The README frames this as a two-hat workflow that separates high-level sections from the Today and Next execution columns, and lists a quick capture bar with inline tag entry and suggestions, custom coloured tags, multi-tag filtering, task reminders and waiting-time counters. Its recorded repository description is the single line 'Your day, compiled.'
