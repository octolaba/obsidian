# NickLennonLiu/obsidian-codex-session-archive

Obsidian plugin that exports local Codex session log files into Markdown notes inside the vault. The README states that it reads archived sessions under a configurable Codex home directory, optionally the active sessions tree as well, and a session index supplying thread titles and update times, grouping the resulting notes by the session's working directory or project name and adding frontmatter with the session id, project, working directory, source path and tags. Embedded base64 images are extracted into a media folder beside the note, and sessions already exported are skipped unless overwriting is enabled.
