# afrangi/Obsidian-Theme-Orange

Subtle Orange is a custom Obsidian theme with an orange and dark-themed aesthetic and minimalistic interface elements, designed for readability. In the sidebar, folder titles are bolded in off-white while file titles take a light font weight and a distinct orange, and files switch to an orange background with white text on hover. Body text is soft grey, header levels H1 to H6 each have their own colour and size, tables use orange headers with bold text, code blocks pair a dark background with a soft green font, and internal and external links are blue. The README invites users to modify the CSS variables to adjust colours, font sizes and other styles.
