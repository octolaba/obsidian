# waynevanson/data-entry-obsidian-plugin

Repository for Data Entry, an Obsidian plugin that turns note metadata into a form, described as the Dataview plugin for data entry. A `data-entry` code block names a datasource, a schema and an optional UI schema — each read from a file's frontmatter or given inline — defaulting to the current file's data, schema and uischema keys, and the form is rendered from JSON Schema and JSON Forms definitions. The README states that the plugin is still a work in progress, that the interface looks rough because Obsidian overrides some styles, and that editing a schema for an already-open note raises an error until the note is closed and reopened.
