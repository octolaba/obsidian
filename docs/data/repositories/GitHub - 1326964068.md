# UNcore-gh/UNmemos

A quick-capture plugin that stores short notes as cards on a chronological timeline, grouped by day and summarised in an activity heatmap. Entries are written to native Obsidian Canvas files under a Memos folder, one per year, so they take part in Obsidian's own linking, hover previews and backlinks; cards are edited inline with Markdown, tags are extracted from the text into a sidebar tree, and memos can be starred, archived or filtered by text, tag and date range with saved presets. A capture box with a keyboard shortcut keeps drafts, a mention picker references or creates linked memos from any editor, and an import path exists for flomo notes. The interface is bilingual in Chinese and English, and the plugin makes no network requests and collects no telemetry.
