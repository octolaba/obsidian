# makary-s/obsidian-metafolders

The repository holds Metafolders, an Obsidian plugin that navigates notes as a hierarchy built from links rather than from folders. Its README records the mechanism: a customizable property on a note holds links to its parents, from which the plugin builds a tree whose parents and children are shown in its panel, so one note can sit in several places at once. Two design goals are stated, interfering minimally with existing habits so the structure remains navigable without the plugin, and presenting an interface that feels like an ordinary file navigator.
