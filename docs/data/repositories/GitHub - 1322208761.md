# JakobLien/date-nullable-time

Date Nullable Time strips the time component from a note's datetime properties whenever that time is exactly 00:00:00, so such a property is stored as a plain date. A consequence stated by the author is that a datetime property can never sit at midnight while the plugin is active. It also carries a Title Date Changer feature, which keeps an ISO date in a file's title following a date property; it is bundled here rather than shipped separately because both features listen for the same date-field changes, and it does nothing until its settings are changed.
