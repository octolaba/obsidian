# vincentlaucsb/obsidian-csvzall

The repository holds csvzall for Obsidian, a plugin that opens CSV files in an editable table view, adds a new-CSV action to folder menus and an open action to CSV file menus, generates bar, line and heatmap charts that can be regenerated when the data changes, runs SQLite queries over CSV files, and can produce Markdown table notes from chart configuration entries. The README states that it requires desktop Obsidian, a vault on the local filesystem and the separate csvzall command line binary, which the plugin can download from GitHub releases. It points phone and tablet users to the companion csvzall Mobile plugin.
