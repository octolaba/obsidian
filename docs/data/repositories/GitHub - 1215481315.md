# punkyard/obsidian-media-embed

Media Embed is an Obsidian plugin that converts a YouTube URL pasted on an empty line into an embed in the chosen format. The README lists three embed styles — plain Markdown at a fixed size, an iframe that fills the pane width, and a div wrapping an iframe — and support for the watch, youtu.be, shorts and embed URL forms on both desktop and mobile. A setting can route embeds through an Invidious instance, with a configurable instance URL, for videos whose uploader has disabled embedding.
