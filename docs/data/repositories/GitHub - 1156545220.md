# nightaqua/TaskLens

TaskLens builds a dashboard from widgets, a timeline, a task list, a Kanban board and statistics, over the checkbox tasks already written in a vault. The timeline spans each task from its start to its due date, with a sticky month header, month dividers, hover tooltips and click-to-open; the Kanban board groups tasks into active, upcoming, urgent, overdue and completed columns and writes a drag back into the source Markdown file. Tasks can be edited or deleted inline, added from a quick-add modal carrying start date, due date and recurrence, and color-coded per project or folder from a custom palette. The README records that it reads standard Markdown checkboxes with inline dates in day-first or year-first form, that the start and due keys are configurable, and that a focus mode hides the widgets and later restores the layout.
