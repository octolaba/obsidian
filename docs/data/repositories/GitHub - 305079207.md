# ryjjin/Obsidian-Dark-Graphite-Pie-theme

Dark Graphite Pie is an Obsidian theme its author assembled from existing themes rather than writing from scratch: Obsidian dark rmx as the starting point, Red Graphite for the left panel styling and colours, Cybertron for the graph colours in dark mode, and the Typora theme Pie for the look of quotes. The README records that from version 0.9.2 onward the author makes independent changes instead of following those upstream themes, and that anything later adopted from elsewhere is noted in the changelog. Installation is documented as turning on the custom CSS option and placing an obsidian.css file in the vault folder, or installing the theme through Obsidian's community themes.
