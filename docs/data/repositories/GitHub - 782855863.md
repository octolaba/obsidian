# rostunic/obsidian-alias-picker

Alias Picker adds two Obsidian commands, Pick alias and Pick block, both executed with the cursor on a link. Pick alias swaps the link's alias for another alias available on the target file, and Pick block changes which block the link references through the block-identifier syntax. Renaming an alias updates every instance of it across the vault, and an Open Alias Overview command lists all aliases with their usages, offering rename, copy to clipboard and move actions from a right-click menu.
