# MeMineoff/note-age-highlighter

This repository holds Note Age Highlighter, an Obsidian plugin that highlights stale notes in the file explorer. A note is marked when its last modified time is older than a configurable threshold in days, defaulting to 30, and the highlight colour accepts any valid CSS colour value. The README records that the plugin uses modification time rather than creation date, that changes to the settings apply instantly, and that it carries no external dependencies.
