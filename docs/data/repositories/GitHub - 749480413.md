# rivea0/obsidian-prime

Prime is a simple, customizable dark and light theme for Obsidian whose author wanted colour tweaks rather than changes that modify the positioning of elements or font styles. Its features include syntax highlighting themes for code blocks in dark and light variations, with Dracula as the dark default and an adaptation of Material Theme Lighter as the light one, emojis used as callout icons, and gradient frames inspired by AnuPpuccin's Colorful Frames. Customisation runs through the Style Settings plugin, and the theme can be installed from the community themes list or by copying theme.css and manifest.json into a Prime folder under .obsidian/themes.
