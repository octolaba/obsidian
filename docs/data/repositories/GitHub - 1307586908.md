# c8vzn4ym5g-ai/jdb-command

The recorded description calls this a one-screen mobile command center for Jason's Digital Brain in Obsidian. The README says a jdb-command code block becomes a single screen where one instruction can be typed, dictated, pasted as a public link or recorded, with a recording indicator, elapsed timer, stop control and playback before submission, and where a source such as a video, document, PDF, presentation, spreadsheet or existing recording is imported separately for content extraction. Photos and reference files are attached below as work attachments rather than instructions, and submitting wakes a Windows backend, returns a persistent receipt and stores the command with its attachments in an inbox commands folder.
