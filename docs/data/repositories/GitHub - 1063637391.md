# vanshkumar/dangerous-obsidian

Recreates the Most Dangerous Writing App inside a single Obsidian note: a timed session wipes the note's body, preserving YAML frontmatter, if text insertion stops for five seconds, with a red-edge warning that intensifies toward the cutoff. During a session, selection, copy, cut, paste, undo, redo and drag-and-drop are blocked, and only real insertions reset the idle timer. The README states that only the note active when the session started can be wiped and calls the behaviour intentionally destructive by design.
