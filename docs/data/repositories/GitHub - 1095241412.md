# Jareika/zoom-map

This repository holds TTRPG Tools - Maps, an Obsidian plugin that embeds an image as an interactive, zoomable map and places markers, stickers, drawings, measurements, HUD pins and editable text layers on top of it. Markers are added by Shift-click or context menu, edited in a modal for icon, link, tooltip and zoom range, and grouped into layers that can be hidden, locked or bound to a specific base image, while multiple base images and toggleable overlays are switched from the context menu. A ruler measures multi-segment distances against a per-image calibrated scale in metric, imperial or custom units with optional travel-time presets, and a Canvas render mode is offered for weaker devices. Marker data is stored by default in a JSON file beside the image, or optionally inline in the note.
