# johannes-kaindl/slide-deck

Slide Deck turns a Markdown note into a slide deck that can be exported to PDF or a PNG image series, with live readability checks. It isolates slide rendering in an iframe, offers five built-in themes plus user CSS themes, and supports per-slide templates, density modifiers, smart layout inference, and theme controls stored in frontmatter. The plugin targets desktop and mobile and keeps previews consistent with exports.
