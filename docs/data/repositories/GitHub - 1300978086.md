# x-o-r-r-o/Kan-Sync

The recorded description says Kan Sync is an Obsidian plugin used to sync Kan.bn with Obsidian through its API. The README describes a sidebar board view for browsing any Kan board inside Obsidian with drag and drop between and within lists and filters by due date, label or member; pushing a note's checklists to Kan so headings become lists and unchecked items become cards; and pulling board state back as a status table that checks completed items off and can enrich lines with due dates, tags and mentions. Hidden comment markers carrying card ids keep the sync stable when a line is reworded, and the README claims coverage of the Kan API v0.7.x including filters, templates, archive, card editing, workspace administration, invites, permissions, webhooks and Trello or GitHub import, without duplicating board data locally.
