# PavelPeng7/omni-drawio-viewer

Omni Drawio Viewer displays Drawio diagrams inside Obsidian offline and read-only, listing every page of a diagram file in a page selector. It handles drawio and dio files directly, and an SVG export that still contains the embedded diagram source shows all its pages while a plain export falls back to a single page; because Obsidian assigns views by the final extension, such an export opens in the usual SVG view until a command switches it to the multi-page preview. A note can embed the first page with an ordinary embed, one named page by appending the page name after a hash, or use a dedicated code block when the page name contains Markdown-sensitive characters. Rendering goes through a built-in SVG renderer that loads no remote code, creates no runtime script elements and does not touch the system clipboard.
