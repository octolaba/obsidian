# chhoumann/MetaEdit

MetaEdit adds and updates YAML properties and Dataview fields in Obsidian notes from a file menu, and can transform properties between the two forms or delete them. Auto Properties offer pre-defined values with optional descriptions in single or multi-select form, with one-off or saved additions; Multi-Value Mode creates arrays from values; and Progress Properties keep total, completed and incomplete task counts up to date as tasks are marked anywhere. Properties can be ignored to hide them from the menu, properties in files linked from Kanban boards can update on lane change, and tags can be edited in both homes, renaming a body tag in place or editing the frontmatter list. It also exposes an API for other plugins and Templater templates.
