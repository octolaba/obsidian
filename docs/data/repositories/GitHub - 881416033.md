# ninetyfive666/Planetary

Planetary is a dual-mode Obsidian theme with an AMOLED-friendly dark palette and an emphasis on warmth and on compatibility with user-defined accent colors. Its listed features are polished dark and light palettes, callout colours that stay legible in light mode, an opt-in rainbow header mode painting H1 to H6 red, orange, green, cyan, blue and purple, and a Style Settings switch between IBM Plex Sans and IBM Plex Serif for the body font. The README cautions that the theme may not be fully tested and asks users to report errors.
