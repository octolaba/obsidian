# zhongwenfu00-alt/clipboard-saver

Clipboard Saver appends copied text to the currently open Markdown note, wrapping each entry in a separator and optionally prefixing it with a timestamp. On desktop it watches the system clipboard through Electron's clipboard module and appends automatically whenever new text is copied, and that monitoring can be switched off or toggled by command. On mobile there is no clipboard monitoring, so a command reads the clipboard through the browser API and writes it into the note, which requires a tap and a permission prompt. The separator, the timestamp and desktop monitoring are configurable in settings.
