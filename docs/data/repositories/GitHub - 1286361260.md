# ondreu/STEP-viewer

STEP Viewer opens CAD files clicked in the file explorer in a three.js-based viewer with orbit, pan and zoom, model colours, edges, measurement, annotations and a navigation cube, and can also embed a model inline in a note. It reads STEP files with their assembly hierarchy and per-face colours, native FreeCAD documents, and OBJ and STL triangle meshes, parsing all of them through occt-import-js, which is OpenCASCADE compiled to WebAssembly. The README records mobile support as beta: the layout adapts to small touchscreens and orbit, pan and pinch-zoom work by touch, but the WASM parser can run out of memory on large models in the mobile webview, so opening a large file first shows a warning that can be dismissed.
