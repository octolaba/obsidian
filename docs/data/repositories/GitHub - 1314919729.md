# IronUnicorn66/reading-progress-bookmarks

This desktop plugin records how far a Markdown note or PDF has been read and returns to that position the next time the file is opened, while heading links, block links and PDF page links keep priority over the saved spot. A status bar item shows the percentage with the current line or page, and each file can carry one quick bookmark that is added, opened, removed or reset from that item or the command palette; the bookmarked paragraph or page is highlighted. Reading state is kept in the plugin's own data file, and note content, frontmatter and PDFs are never modified. Settings cover automatic restore, a completion threshold after which the next open starts at the top, reusing an existing tab for the same file, and optional local debug logging.
