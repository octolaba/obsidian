# MugishoMp/obsidian-editor-width-slider

Obsidian plugin that adds a slider to the status bar for adjusting the editor's line width. The width can also be set per file by adding an editor-width field to the note's YAML frontmatter, whose value is a number between 0 and 100 read as a percentage of the viewport width, so different notes can use different widths. The README documents installation from a release archive and enabling the plugin under community plugins.
