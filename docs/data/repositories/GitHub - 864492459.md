# darthdemono/AMOLED-Serenity

darthdemono/AMOLED-Serenity holds AMOLED Serenity, a low-contrast dark theme built for AMOLED screens, where the deep blacks are recorded as both a battery saving and an eye-comfort measure. The README lists a calm palette intended for prolonged use and integration with the Style Settings plugin for further customization. It credits several existing themes as its basis, among them two vanilla AMOLED themes, an Obsidian Nord theme, an AMOLED black theme for VSCode and the Things theme.
