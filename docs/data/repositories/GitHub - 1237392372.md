# gengyabc/naotu

MindCanvas renders a mind map as a canvas where zooming changes the granularity of what is shown rather than only the size of the text, so zooming out shows structure and zooming in shows content, optionally scoped to the selected subtree. A node can hold plain text, a bound Obsidian note previewed when magnified, or a bound image or Excalidraw file. The README, written in Chinese and English, records generating a map from a Markdown file's heading structure or from the backlinks of the current file, mirror, right-facing and free layouts, a minimap, keyboard navigation, search, undo and redo and autosave, together with performance work such as a hybrid Canvas and SVG renderer, viewport culling and preview caching.
