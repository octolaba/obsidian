# uphy/obsidian-reminder

The repository holds the Obsidian Reminder plugin, which manages Markdown todo items that carry a reminder time. Its README records the syntax as a date, optionally with a time, written in parentheses after an at sign at the end of a task line, and states that a checked task is not notified. It also records a view listing the reminders found across all files, where clicking an entry opens the source file, and an in-app notification at the appointed time with a control for marking the task done.
