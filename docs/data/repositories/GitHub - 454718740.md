# qawatake/obsidian-card-view-switcher-plugin

Obsidian plugin that provides a quick switcher with a card view, opened by its own command. The README documents three search modes: a recent search over the contents and file names of the ten most recently opened files, a normal search over all file names entered by prefixing the term with a quote or a space, and a random search that picks ten of the matching file names.
