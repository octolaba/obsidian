# imed-ghomari/cross-player-obsidian

The repository holds Cross Player, an Obsidian media player plugin that turns a local folder into a playback queue shared between desktop and mobile in the same vault. It plays a range of audio and video formats, shows a placeholder with a music icon for audio files, resumes an in-progress file automatically, can play the next unread queue item, keeps an adjustable playback speed, and reads sidecar subtitle files in VTT and SRT form. The README also lists YouTube downloading and storage management as part of the plugin.
