# kingsleyfong/King-s-CalcLatex

Evaluates LaTeX written inside dollar-sign math when a trigger suffix is appended, printing numeric results, symbolic simplifications, derivatives, integrals, solutions and factorizations inline, with no backend server. Other suffixes draw 2D plots - explicit, implicit, parametric, polar and inequalities, with pan, zoom, image download and sliders generated for free variables - and WebGL 3D surfaces, curves, vectors and points. Further commands cover partial derivatives, gradients with contour overlays, tangent planes, matrix arithmetic, determinants, cross and dot products, direction fields for first-order ODEs, and Laplace transforms. An optional 19 MB Giac WASM engine adds limits, Taylor series, partial fractions and step-by-step solutions, and the plugin also renders Excalidraw canvas text as equation images and runs a LaTeX snippet engine in that modal.
