# IchiroFukuda/spy-terminal-theme

Spy Terminal is a dark, terminal-styled theme for Obsidian and other Markdown editors, presented as the atmosphere of hacker movies. It uses monospace fonts such as SFMono-Regular, Roboto Mono and Ubuntu Mono at 16px, three tiers of dark background, green body text with a darker green for muted text, red for errors and cyan links. Glow and text-shadow effects are applied to links and task blocks, checkboxes are green, and code blocks sit on a very dark background.
