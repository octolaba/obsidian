# kodamaChameleon/Ecdysis

kodamaChameleon/Ecdysis holds Ecdysis, a dark Obsidian theme with a retro-terminal aesthetic built on neon colour over near-black: green headings, cyan body text and magenta accents, bold and links. Headings use the Press Start 2P pixel font and body and interface text use Roboto Mono, both loaded from Google Fonts, which the README says requires an internet connection on first load. Each note is framed by a thin green border whose left and right edges fade to transparent across the middle of the pane.
