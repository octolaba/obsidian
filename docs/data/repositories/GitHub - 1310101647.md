# search5/harang-immich

Harang Immich browses, inserts and stores note images on an Immich server instead of inside the vault. Several profiles can be configured, each with its own name, server address, API key and album, and each device picks its own active profile; the Insert Immich image command opens a gallery of thumbnails, optionally scoped to one album, and inserts the chosen photo at the cursor. Inserted links render as images in Live Preview and in reading view, and pasting an image or dragging one in from outside uploads it to Immich and inserts the resulting link. Deleting or editing away a link, or deleting or renaming the note, prompts to move the now-unreferenced asset to trash, delete it permanently or leave it alone; the requirements are Obsidian 1.13.4 or later, a reachable Immich server and an Immich API key.
