# fabricehong/obsidian-prompt-crafter-plugin

PromptCrafter composes modular, reusable prompts for language models inside Obsidian notes, so that material such as project details or key facts is pulled into several prompts instead of being rewritten each time. The README states that a prompt is written in a pc code block and parameterized with mustache placeholders whose values are defined in the note's frontmatter, either as static values or as Obsidian links, in which case the linked note's content is resolved into the prompt, optionally narrowed to one section by a heading reference. When the resolved content is itself a pc block, it is resolved again using the host note's frontmatter, and the finished text is copied out and pasted into an external model.
