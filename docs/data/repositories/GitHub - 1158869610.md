# nickmilo/soft-paper

Soft Paper is a custom Obsidian theme its author describes as made to feel more reflective, forked from a heavily customised AnuPpuccin setup for performance reasons. The README states that the fork reduces the code by 86% and removes every option of the previous theme, including the CPU-expensive tab switching animation that slowed things down with multiple bases open or in heavily linked notes. Style Settings adds optional toggles, among them rainbow folders, which default to ACE-coloured folders, and condensing settings for Bases tables and the file explorer.
