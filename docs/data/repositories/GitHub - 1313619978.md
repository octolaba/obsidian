# funnyCodezj/obsidian-md-formatter

Reformats the layout of a Markdown note without changing its text: heading spacing and minimum level, unified list markers and indentation, blank lines around code blocks, aligned table columns, merged blockquotes, consistent horizontal rules and paragraph spacing, including automatic spaces between Chinese and English. It runs from an editor context-menu entry or the command palette, on the current file or across every Markdown file in a folder. The rules live in an editable YAML template in the plugin settings that takes effect on save, and frontmatter is left untouched.
