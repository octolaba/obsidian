# slow-coding/obsidian-at-mention-autocomplete

Typing an at sign followed by a keyword opens a suggestion list built from an in-memory full-text index of the vault's Markdown files, with YAML frontmatter stripped, so notes are found by their content rather than only by title. The matching sentence is highlighted in the list and the full note is rendered in a detail panel as the selection moves, and pressing Enter inserts a link whose alias is that matching sentence, bounded by sentence terminators. Navigation is keyboard-first with arrow keys or Ctrl+N and Ctrl+P, Esc dismisses the list, and Chinese pinyin input is handled so that Enter first confirms the composed characters. The index is built at startup and updated incrementally as notes are created, edited, renamed or deleted.
