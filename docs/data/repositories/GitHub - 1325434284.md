# wangeek/obsidian-lottery

Picks one note at random from a range defined by checked folders, subfolders included, optionally narrowed with Obsidian search syntax for tags, paths, keywords and exclusions. The draw plays as a slot-machine wheel with a canvas confetti finish drawn without third-party libraries, and clicking the overlay opens the selected note in a new tab. Drawing runs with or without replacement, the latter resetting automatically once the pool is exhausted, and both the scroll duration and the particle count are adjustable. It starts from a sidebar icon or a command, works on desktop and mobile, and switches its interface between Chinese and English according to Obsidian's language.
