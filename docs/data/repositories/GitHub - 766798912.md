# tomkaygames/Tom-s-Theme

Tom's Theme is a simple Obsidian theme whose stated aim is keeping focus on writing, with hacker films and video games credited as inspiration. The README records a black background with Game Boy green text borrowed from GB Studio, dark and light modes with the author preferring dark, and a file width reduced to 520 pixels so that lines run to an optimal 54 characters, matching a GB Studio dialogue box. The stylesheet is commented so that a reader can build their own theme from it, and the theme is released under the MIT license.
