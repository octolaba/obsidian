# kometenstaub/linked-data-vocabularies

Linked Data Vocabularies is described as adding linked data to the YAML of Obsidian notes, and its README records that Library of Congress Subject Headings are the supported vocabulary. Selecting a heading writes YAML keys for the heading and, optionally, its URL, classification and its broader, narrower and related headings, and it can instead be inserted as inline YAML at the cursor for Dataview. The README states that the data itself is generated by the separate Linked Data Helper plugin, that the folder holding those JSON files must be set in the configuration, and that key names, the query limit and fuzzy-search sensitivity are configurable. An option to load the suggester data at startup is off by default and the README advises against it on mobile.
