# atopos31/OZSync

OZSync syncs an Obsidian vault with ZimaOS storage for backup, file browsing and cross-device access. Its README describes manual sync to a configured ZimaOS directory with optional interval-based automatic sync, a ZimaOS file browser inside Obsidian offering upload, download, preview, folder creation and deletion, conflict resolution by modification time so the newer file wins, a local backup taken before a remote download overwrites a local file, and sync state shown in the status bar and a status view. It records the plugin as desktop-only, needing a reachable ZimaOS server and an account with access to the target path, and lists server URL, port, credentials, sync directory and auto sync as its settings.
