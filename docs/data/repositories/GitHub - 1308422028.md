# jstoolsspace/img-resizer-obsidian

Local Image Resizer resizes, compresses and converts JPEG, PNG and WebP images inside an Obsidian vault while preserving the original files. The README records linked or independent dimensions, conversion between the three formats, compression toward an optional maximum file size, a preview of the selected image, and a resized copy saved beside the source with a suffix and a number when that name already exists. An embedded image can be replaced in the current note from its context menu, the tool opens from the ribbon, the command palette or a file's context menu, and the README states that it works on desktop and mobile without Node or Electron APIs and requires no upload and no account.
