# liuxingyu521/obsidian-plugin-cursor-goaway

This plugin removes the editor focus for about 500 milliseconds when a Markdown file is opened, so that the cursor does not appear on the first line and change how that line is displayed. Pressing the down-arrow key returns focus to the editor immediately and places the cursor at the start of the first line. The README states that this is a one-time trigger per file open or switch, and that a press during the defocus window is ignored.
