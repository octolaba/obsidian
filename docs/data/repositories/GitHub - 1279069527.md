# JessieSun-vibe/weekly-todo-calendar

Weekly Todo Calendar builds an Obsidian calendar and todo workflow around one Markdown note per week, opening a weekly note directly as an editable Monday-to-Sunday calendar in which timed tasks stay ordinary Markdown. Timed tasks can be dragged, resized, created, completed and edited in that view, weekly focus cards sit below it, and the current week stays in the calendar folder while past and future weeks are routed to separate folders. It can display tasks from daily notes, Obsidian Tasks dates and ICS calendars, and on macOS desktop it can sync a weekly note to an existing iCloud-backed Apple Calendar, updating previously synced events instead of creating duplicates. The README states that the project is based on the open-source Obsidian Day Planner.
