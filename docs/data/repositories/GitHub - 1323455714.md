# aura88-tech/task-radar

Task Radar plots tasks from the Tasks plugin as blips on a radar, where distance from the centre is computed from the due date and the angle places a task in a category segment. Rings are date buckets such as critical, this week and this month, so blips drift inward on their own as days pass, and dragging a blip in or out rewrites the due date on the task line while dragging it around changes its category. A context menu postpones a task to the next ring or by a day, week or month, sets an exact date, completes the line with a completion date, or opens the task in its note. Radars are stored as self-contained JSON files holding rings, segments, blips and display settings, each blip bound to a task line by a block identifier; it is a fork of a general-purpose radar and requires the Tasks plugin.
