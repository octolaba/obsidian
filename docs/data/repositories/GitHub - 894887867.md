# haierkeys/obsidian-custom-image-auto-uploader

Custom Image Auto Uploader moves images between notes and remote storage on desktop, iOS and Android. It downloads web images referenced in a note — or in every note of the vault — to local storage, and uploads local images to a remote server, a home NAS, WebDAV or cloud storage such as Alibaba Cloud OSS, Amazon S3, Cloudflare R2 and MinIO, or to the author's separate self-hosted image gateway. The recorded inputs also state image processing in note properties or body, including stretching, cropping, resizing and compression; the storage backends and the companion service were not verified here.
