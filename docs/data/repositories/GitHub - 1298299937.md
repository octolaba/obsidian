# kidd911-cmd/obsidian-looki-sync

Looki Sync is an Obsidian community plugin that syncs Looki Moments and For You entries into date-based daily memory notes, and both its description and most of its README are written in Chinese. Settings hold a Looki API key and base URL with a connection test, the target folder for the daily notes and a media folder, plus independent switches for syncing images and videos. The README records that a day's Moments and For You items are merged into one dated note under two sections, that each note is rewritten from the current API data on every sync so entries do not accumulate, and that a location stored as JSON is parsed into a readable address.
