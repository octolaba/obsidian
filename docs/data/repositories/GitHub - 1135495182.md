# yhao3/obsidian-code-import

Obsidian plugin that embeds external code files into notes with an import syntax compatible with Markdown Preview Enhanced. The README states that imports render in Reading View with syntax highlighting chosen from the file extension, that relative paths including parent-directory segments work, and that a line range can be selected with line_begin and line_end parameters in either a 0-based or a 1-based mode. Screenshots of desktop and iOS use are shown.
