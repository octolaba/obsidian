# filipesilva/obsidian-babashka

Obsidian plugin that evaluates Clojure and ClojureScript code blocks in a note, running them through Babashka and Node Babashka respectively. Those tools are prerequisites installed separately, and absolute paths to the bb, node and nbb executables must be set in the plugin settings before a block can be evaluated. Beyond evaluating a block it can print the value outside the block, start and connect to a Babashka nREPL server, and expose vault bindings such as the vault name and path and the last file path to the running code. The README frames the main use as scripting in the context of the vault's own documents.
