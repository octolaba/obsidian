# jgchristopher/obsidian-clipper

Obsidian plugin that captures highlights from the web as Markdown entries in a daily note, a weekly note, or both. The README states that HTML tables are captured as Markdown tables when the Advanced Tables plugin is installed, and that clipping is driven either by a generated bookmarklet or by a Chromium browser extension. Its network use notice records that generating that extension calls out to an external service, maintained by the same author, which wraps the bookmarklet, and that the extension is the only way to use the plugin in browsers such as Arc that do not support bookmarklets.
