# JoyelleZ/Gongkao-Sprint

Gongkao Sprint is a study layer for civil service exam preparation that keeps all of its data as Markdown files in numbered folders inside the vault. A desktop dashboard collects the day's plan, due reviews, topic and weekly practice, recent reflections, weakness reminders, exam countdowns and an effort heatmap, while a lighter mobile view concentrates on capturing an error card by photo, logging practice and reviewing. Error cards accept text or images, can be bound to a practice collection, and support rectangular masks that cover answers or handwritten explanations until the card is turned over; the due queue is computed from their frontmatter rather than stored separately. Commands create each kind of note in its folder, generate the daily plan from due cards and recent corrections, and can lay down example data, and no AI service, OCR, database or network API is required.
