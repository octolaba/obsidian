# aaronarcade/Obsidian-Daily-Todo

Daily TODO keeps dated TODO files in their own folder, separate from journal or daily notes, and rolls incomplete tasks forward when today's file is created from a ribbon icon or the command palette. The README states it requires neither the Daily Notes nor the Periodic Notes plugin, that rollover is scoped to the TODO section and stops at another heading, that nested content under an incomplete task is preserved while completed checkbox subtrees are skipped, and that the most recent dated file before today is found automatically, including in subfolders. New files carry frontmatter with tags, a date, a daily-todo type and a link back to the source note, and older files using a legacy naming scheme are renamed to the current one. A first-run modal sets up the folder, and the plugin re-prompts if that folder is later deleted or moved.
