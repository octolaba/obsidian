# alex-de-kora/obsidian-trending-digest

Trending Digest scrapes trending pages from more than twenty-five sources, scores each item with a language model, and writes a curated daily digest into the vault as a Markdown file carrying frontmatter, scores, generated summaries and tags. The README names GitHub, Hacker News, Medium, Product Hunt, npm, Hugging Face, arXiv, Reddit and several technology publications among the sources, aggregates accounts from X through Nitter feeds without an API key, and lists Chinese communities as their own category. Items are scored from zero to ten on relevance, usefulness, novelty and popularity, and can be filtered by more than twenty focus areas. The run happens on a daily schedule or on demand, repeat runs on the same day append new items instead of overwriting, and the plugin requires an API key and base URL for an endpoint compatible with the Anthropic messages API.
