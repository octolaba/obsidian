# saltyfireball/obsidian-highlight-non-ascii

An Obsidian plugin that highlights every character outside the ASCII range from 0x00 to 0x7F, in Live Preview editing and optionally in Reading View, which the README presents as a way of catching invisible Unicode characters, accidental special characters and non-standard punctuation. Recorded settings cover an on/off toggle also reachable from the command palette, the reading-view toggle that is off by default, an allowlist of characters to leave unhighlighted, customisable highlight CSS, and per-note control through frontmatter. A status bar counter reports how many non-ASCII characters the current note contains. An auto-replace command rewrites matching characters according to configurable find and replace rules, whose defaults cover curly quotes, en and em dashes, the ellipsis and the non-breaking space.
