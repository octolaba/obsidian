# JWCzju/html-blocks

Renders HTML, CSS and JavaScript written in an html-block code fence directly inside a note, each block isolated in its own Shadow DOM so its styles reach neither the theme nor other blocks. Inline script runs in a per-block scope where document queries resolve against that block, and HTML kept in a separate file can be embedded instead. A toggleable inspect mode links rendered elements back to their source lines on hover and click. The README states that only inline script is executed and that external script sources are never fetched or run.
