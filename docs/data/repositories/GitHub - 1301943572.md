# taihartman/obsidian-atoms

Atoms files past captures from Daily Notes into flat Markdown notes under an Atoms folder, giving each one a title, tags and links while leaving the original capture text verbatim as the body. Classification runs through the Anthropic API, which receives vault note titles, tags, person-hub titles and the capture text, and requires either a user-supplied API key held in SecretStorage or a hosted subscription. A home view resurfaces filed notes, tracks captures still waiting to be filed and reports progress during a run, and commands cover open loops and an atom graph. It requires Obsidian 1.11.4 or later and the core Daily Notes plugin, and never rewrites the capture body itself.
