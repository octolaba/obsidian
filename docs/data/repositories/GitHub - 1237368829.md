# rolecall-games/rolecall-obsidian-sync

RoleCall Sync uploads notes from one folder of an Obsidian vault, Published by default, to a game on the RoleCall campaign site, where wikilinks and frontmatter are parsed and rendered. Notes outside that folder are never sent, and the server rejects paths outside the published root as well; comments and secret callouts inside a published note are not hidden, so private material has to stay out of that folder. A ribbon icon and a command send an incremental batch of changed notes and embedded media, skipping unchanged files and deleting notes that were removed; Markdown becomes pages and media becomes embeddable images. There is no background sync, no pull back into the vault and no diff preview, and a free account plus a per-game API token are required, obtained through a browser approval flow or entered by hand.
