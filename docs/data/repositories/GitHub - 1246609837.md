# vipsyvipul/Quick-Organize

Quick Organize adds a dashboard view to Obsidian for triaging captured notes through their lifecycle: classifying what each note is, connecting it to where it belongs, and tracking what has been dealt with. Any note whose frontmatter carries a non-empty type field appears automatically, alongside fields such as belongs_to, related_to, organized and archived, and the README states that no Dataview query, template or further configuration is needed. The dashboard opens from an inbox ribbon icon, registers as a native Obsidian view that can be docked like Graph view or Backlinks, and splits entries across tabs. It is described as based on Portent and as working with any note, with additional support when the QuickClip Capture browser extension for Chrome is used.
