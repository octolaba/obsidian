# danieldaidai/FormulaR

Validates and completes LaTeX mathematical derivations written inside align blocks. Algebraic equivalence between consecutive steps is checked locally with mathjs, incorrect lines are marked with a red wavy underline and unverifiable ones with an orange dashed underline, and hovering a marked line shows a short explanation. When local checking is inconclusive the step can optionally be sent to a configured Claude or OpenAI-compatible endpoint, and typing a trailing double backslash requests next-step suggestions. The README records Obsidian desktop 0.15.0 or later as the requirement and states that an API key is optional because local validation works without one.
