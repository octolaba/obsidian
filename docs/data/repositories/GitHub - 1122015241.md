# haiqiang-zhang/obsidian-bases-charts

Bases Chart Views adds interactive chart views to Obsidian Bases using Apache ECharts, in two distinct forms. Data Charts are built-in Scatter, Line, Bar and Pie views with purpose-built controls for aggregation, grouping and axis configuration, read directly from the Base's data. AI Chart instead delegates the whole configuration to the Claudian plugin, which the README states must be installed separately and which generates and iterates on the ECharts configuration from a conversation.
