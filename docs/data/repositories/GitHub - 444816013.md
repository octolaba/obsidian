# gOATiful/para-shortcuts

PARA Shortcuts adds command-palette commands for setting up and maintaining a vault organised by the PARA method of projects, areas, resources and archives. One command creates that folder structure at the root of the vault, another creates a new entry from a basic template in the selected folder, and further commands move the currently opened file into its matching archive folder, restore an archived file back to its original PARA folder with its subfolders, and postpone an entry. The archive commands create the matching folders and subfolders when they are missing and are offered only where they apply.
