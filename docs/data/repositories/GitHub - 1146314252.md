# Josteniok/create-folder-at-note-location

The repository holds Create Folder at Note Location, an Obsidian plugin that adds two commands creating a folder beside the currently open note. One command creates the folder alone; the other creates the folder together with a note of the same name inside it and opens that note, which the author added for use with the Waypoint plugin's folder notes. Any file can be set as the template copied into that folder note, and the README records that the plugin was built from Obsidian's sample plugin.
