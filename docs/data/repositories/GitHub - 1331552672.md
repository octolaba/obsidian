# devsdocs/anki_embed

Anki Embed renders a deck from a running Anki instance inside a note, reached through the AnkiConnect add-on on the local loopback port. A code block names a deck, a search query or an interactive picker and can set a card limit, a due filter and randomisation; the rendered player flips cards, rates them Again, Hard, Good or Easy from buttons or number keys, writes the review back to Anki and shows a session summary. Commands insert a deck block, import notes from pasted CSV or TSV data, trigger a collection sync and test the connection, while a pasted Anki URI is converted into an embed block automatically. Anki must be open with the add-on installed; review time is logged as zero through the official add-on, and a setting switches to a modified fork that records it.
