# mdklab/note-favicon

Note Favicon is an Obsidian plugin that reads a URL from a note's frontmatter and shows the matching favicon beside the note's title in the file tree, so notes can be told apart at a glance. A favicon field holding either a standard URL or a base64-encoded image is accepted, and the icons update as that metadata is added, changed or removed. The README records installation from the GitHub releases page and states that installation from within Obsidian is not available yet.
