# vivekgalatage/pdf-toggle-dark-mode

PDF Toggle Dark Mode inverts PDF viewers and their sidebar thumbnails to a dark appearance and back. The toggle is available from the PDF toolbar, a ribbon icon, a status bar item and a command, and sliders for darkness, color correction and brightness sit beside it on the toolbar and in the settings tab, each with its own reset, alongside an option to hide the outline boxes around clickable links. The chosen mode and appearance values persist across restarts, an adapt-to-theme setting makes PDFs follow Obsidian's own light or dark appearance, and the controls are re-applied to PDF views opened later. When the PDF++ plugin is installed, rectangular cropped embeds use the same mode and sliders; without it, that part simply does nothing.
