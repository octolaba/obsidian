# Mouadhbendjedidi/themed-obsidian-discord-rpc

Themed Discord RPC publishes an Obsidian session as Discord Rich Presence, showing the active note title, the vault name and the elapsed session time on the user's Discord profile. The README records customizable status messages, support for themes and icons, and four themes at the time of writing, a default in a new and an old variant, Catppuccin, Tokyo Night and Cyberglow. It flags version 1.3.0 as a breaking change, after which theme images are hosted in the repository instead of Discord's asset system, with earlier versions no longer supported.
