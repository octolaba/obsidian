# jillro/obsidian-cards-view-plugin

Displays the notes of a vault as a card view. The README lists sorting by last modified or created date, pinning notes to the top, quick filtering by tags, and settings that exclude notes from the view. It states that the same search syntax as Obsidian's own search plugin is supported, except for the block, section and task operators, and that beta versions are distributed through BRAT with the warning that they may be unstable.
