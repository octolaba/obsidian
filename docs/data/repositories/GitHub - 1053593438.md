# davidvkimball/obsidian-file-name-history

File Name History stores file name and folder name change history into note properties: after a Markdown file is renamed the old name is appended to a configured list property, aliases by default, once a timeout of one to twenty seconds has passed. Tracking of the old immediate parent folder name is available as an option and is off by default. Regex ignore patterns skip names such as those starting with an underscore or equal to Untitled, folder filters restrict or exclude paths, custom file extensions beyond .md are supported, and the target property can be created automatically when missing.
