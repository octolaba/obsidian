# agentage/obsidian-galaxy

This repository holds Agentage Galaxy, an Obsidian plugin that draws the vault as a rotating 3D force-graph in which notes are nodes and the links between them are edges. Folders, tags and attachments form colored clusters on first open, and the view reuses the node kinds and filters of Obsidian's built-in graph, which the README says leaves nothing new to learn. The README also states that the visualization is entirely local and makes no network calls, and that releases ship weekly.
