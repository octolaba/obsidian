# FHachez/obsidian-convert-url-to-iframe

This plugin converts a URL selected in an Obsidian note into an embedded iframe preview, invoked from the right-click menu on a link or through a Convert to Url Preview command with a default hotkey. Its changelog records a move from a custom YouTube mapping to the OEmbed standard, which preserves a YouTube timestamp and supplies default sizes for many sites, along with a configurable aspect ratio defaulting to 16:9, full-screen iframes and mobile support.
