# MMortise/obsidian-vault-schema-refactor

Schema Refactor renames a top-level frontmatter property across a vault and updates the matching references inside supported Bases structures such as filters, formulas, sorting and grouping. Every affected file, its structural location and a diff are shown before anything is written, references it cannot resolve are reported for review rather than changed, and conflicts between old and new names are settled per file or by exclusion. Writes are preceded by local snapshots and verified afterwards, a failure rolls back, and a history view builds an undo plan that refuses to overwrite files edited since the original transaction. A read-only Doctor reports missing properties and formulas, unused formulas, case and type drift and unsupported Base shapes; the write path is desktop-only, mobile is limited to inspection, and nothing leaves the machine.
