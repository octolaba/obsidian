# Spiderpig86/slash-complete

Repository for SlashComplete, a plugin that adds Notion-style autocompletion triggered by typing a slash in the editor. The README describes a contextual menu for inserting Markdown blocks such as headings, lists, quotes and code blocks, suggestions that can be added or modified, and keyboard navigation of the menu. It positions the plugin as a replacement for an existing Notion-style slash command plugin that focuses only on Markdown support.
