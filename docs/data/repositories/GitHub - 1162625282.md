# thematthiasleitner/hermes-tts

The repository holds hermes-TTS, an Obsidian plugin that converts a Markdown note into speech audio and prepends a timestamped metadata callout embedding the resulting audio link. The README records one model-provider selector in settings with provider-specific fields, voice dropdowns, an optional voice prompt for speaking-style instructions, and output always normalised to MP3; the providers listed are OpenAI, Google Gemini, Google Cloud Text-to-Speech, Azure Speech, ElevenLabs, AWS Polly and OpenAI-compatible endpoints. It states that network access is required, that note text is sent to the selected external provider, that external accounts and API keys are needed, and that the plugin carries no telemetry or ads. The README also records mobile loading and an automatic fallback to Google Cloud when Gemini fails transiently and that provider is configured.
