# munach/obsidian-extract-pdf-annotations

The repository holds a plugin that extracts annotations from PDF files inside and outside the vault, covering highlights, underlines, squiggles, notes and free text. Its README records three commands: one that searches every PDF in the current folder and inserts the annotations at the cursor of the note being edited, one that works on the file open in Obsidian's PDF viewer and writes its annotations to a dedicated note, and one that takes a file path from the clipboard. It is written in TypeScript under the MIT license.
