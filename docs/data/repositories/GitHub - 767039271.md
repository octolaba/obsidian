# janisringli/verse-of-the-day-for-obsidian

This plugin inserts the Verse of the Day published by YouVersion into an Obsidian note. It is used by placing the cursor where the verse should go, opening the command palette and running the plugin's insert command. The README also describes automating it with the Templater plugin: with Templater's trigger on new file creation enabled and its template folder set, the plugin's command is placed inside the template that should carry the daily verse.
