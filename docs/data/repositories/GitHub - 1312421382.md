# anandrajbaghel/gate-study-styles

GATE Study Styles bundles a set of CSS tweaks aimed at engineering and exam study notes into one plugin, with each style switched on or off individually in settings instead of being maintained as separate snippets. It adds study-oriented callout types such as Subject, Topic, Formula, Definition, PYQ, Important, Tip and Warning, centers images and tables automatically, strips borders, backgrounds and extra spacing from embedded notes, and restyles highlighted text, table headers and underlined text. The color used by the supported styles is either Obsidian's current accent color or a custom one chosen in settings, and the plugin works on desktop and mobile.
