# LastRatAlive/Librarian

Obsidian plugin for maintaining notes on books that have been read, presented as a local-first alternative to hosted reading services. Book notes are generated from customizable templates with metadata imported from the Open Library API, including title, author, ISBN, page count and cover URL, with manual entry for titles it does not find and support for user-defined frontmatter properties. Reading state moves through to-read, currently reading, finished and did-not-finish through non-destructive frontmatter updates and controls injected into the note header, and every session's start and end dates are logged so re-reads are kept. Books can be grouped into named shelves, sorted into folders through author, year or subject placeholders, and browsed from dedicated sidebar views.
