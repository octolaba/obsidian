# clockblocker/filler-de

A German language-learning plugin that builds dictionary entries inside the vault. The README states that a Generate command reads the open file's name and either links it to the file holding the word's normal form or, when the file already is that normal form, generates a structured dictionary entry, while a Populate command creates files for all links in the current file and writes an explicit backlink into each of them. Entry templates are per word type and the README lists pronunciation, conjugation or declension tables, synonyms and antonyms, translation and a morphological breakdown; bidirectional links are maintained between base verbs and prefixed forms, between synonyms and antonyms, and between related grammatical forms. The README warns that the plugin changes default Obsidian behaviour substantially and recommends using it in a separate vault.
