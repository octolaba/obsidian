# reorx/obsidian-paste-image-rename

The repository holds Paste image rename, an Obsidian plugin that prompts for a name when an image is pasted and, from version 1.4.0, handles every attachment added to the vault. Its README credits Zettlr's rename prompt as the inspiration and records that the plugin goes further by letting the reader define how a name is generated, so files can be renamed automatically by rule. Documented settings include an image name key read from the note's frontmatter, prefixes or suffixes for duplicate names, and a batch renaming process.
