# sunmagicshow/obsidian-webdav

Browses WebDAV servers from inside Obsidian and manages the files stored on them. The README describes dragging a file into a note to generate a Markdown link, double-clicking a file to open it in Obsidian's built-in browser, downloading supported formats into the vault, and uploading files or folders by right-click or drag and drop, with duplicate detection offering overwrite, rename or cancel. Video preview depends on the Media Extended plugin, and the README recommends a WebDAV server with CORS enabled, falling back to an authorization-plus-blob mode when it is not.
