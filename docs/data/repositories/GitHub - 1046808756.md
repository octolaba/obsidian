# Blackajiro/Resonance

A local-first, desktop-only recorder for Obsidian built on Web Audio capture, Whisper for transcription, and Ollama or an optional cloud provider for summaries. It records one main microphone plus optional additional audio inputs in the same audio graph, writes transcript updates while recording, and builds a summary note after the recording stops. Every session is stored with its audio, transcript, summary and diagnostics in a built-in Library, where those artifacts can be inspected, recovered, cleaned up or bulk-deleted.
