# pc418/cloudflare-r2do-sync

R2DO Sync synchronises a vault through a Cloudflare Worker, R2 bucket and Durable Object deployed to the user's own account, encrypting contents before upload with a key that stays on the devices. Each sync publishes a commit: an encrypted manifest naming every file by its content hash plus the id of the snapshot it grew from, which the Durable Object accepts only when its parent is still the current head. A device pulls and three-way merges against the shared ancestor before publishing, deletions are stated by the snapshot rather than inferred from timestamps, and identical content is stored once. Snapshots can be restored whole or per file, old ones are trimmed by scheduled garbage collection, and setup runs from a script requiring a Cloudflare account and Node.js 20 or newer.
