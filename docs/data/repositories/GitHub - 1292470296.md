# gibranbadrul/obsidian-confluence-page

Confluence Page Publisher converts Obsidian notes to Confluence Storage XHTML and publishes them through a bound page URL. It can upload local attachments, render diagrams, add bound-note links, write publish metadata into frontmatter, and skip unchanged content using hashes; the plugin is a one-way desktop publisher with documented conversion limits.
