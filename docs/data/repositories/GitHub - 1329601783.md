# jiaoxiu20040903-crypto/Agent_Review

Stores reading annotations, including highlights, inline comments, free-form sticky notes and Bezier relation lines between them, as structured records under an agent-review directory in the vault, leaving the Markdown text unmarked. The same review renders in Live Preview, Source and Reading modes and in a review view that lists the current note or the whole vault with filters on status, source, type, tag and color, plus bulk resolve, archive, retag, export and delete. Each review is anchored to its passage and keeps its comments, replies, tags and state when the range is adjusted; an anchor that can no longer be resolved is marked orphaned instead of deleted. Humans and external agents work on one data layer through the editors, a local file-command queue, a CLI and a versioned in-vault API, and the plugin ships no model and makes no network requests.
