# Quorafind/Obsidian-Mini-Toolbar

Obsidian Inline Toolbar, also called Mini Toolbar, shows a small context toolbar in the editor: text is selected in live preview mode and a button in the toolbar is clicked to act on it. The README records the plugin as a fork of aidenlx's original mini toolbar, made with changes after the original author became busy, and credits him accordingly. It documents installation through BRAT as a pre-release or manually from the GitHub releases, and notes that community-plugin installation is not yet available.
