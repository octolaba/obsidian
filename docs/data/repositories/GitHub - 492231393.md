# lijyze/obsidian-state-switcher

Renamed to Yaml Manager, this plugin edits YAML front matter through commands instead of by typing into the front matter directly. Its commands update a key-value field, insert or remove an item of a key-array field, and perform a bulk update, with the field name and the value selected in turn. They are available in edit mode only, and when a note has no front matter the plugin creates one before inserting the pair.
