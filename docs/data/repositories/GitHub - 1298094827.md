# javajiang/article_ai

AI Article is an Obsidian plugin that extracts the writing style of reference notes and generates new articles in the same style. Style can be distilled from a single note or from several at once, and the plugin keeps reference material, distilled style files and generated drafts in three dedicated vault folders. The README addresses newsletter, blog and social-platform writers as well as editors, and requires an API key entered in the plugin settings before use.
