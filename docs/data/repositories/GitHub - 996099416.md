# michaelmassoni/obsidian-soc-toolkit

SOC Toolkit collects tools for security operations analysts inside Obsidian. It scans a note for IPv4 and IPv6 addresses, including defanged forms, checks their reputation through the VirusTotal and AbuseIPDB APIs with a cache of configurable duration to limit API calls, and offers customisable output formats with a preview, a right-click check and a command for a highlighted address. A second tool defangs the IP addresses in the current note, from a command or the right-click menu, either fully or on the last dot only, while keeping the note's formatting. API keys for both services are entered in the plugin settings and can be tested there.
