# SomeNoY/obsidian-word-progress-bar

Shows a miniature progress bar in the status bar that fills as a note's word count approaches a goal and turns green once the goal is reached. A default goal can be applied to every note from the settings, or the bar can be limited to notes that carry their own goal in frontmatter under a `word-goal` property, whose key is configurable.
