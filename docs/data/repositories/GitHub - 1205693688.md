# WorldBrain/memex-obsidian

Memex for Obsidian brings a Memex library into the desktop app so saved web pages, notes, highlights, PDFs, videos and images can be searched and questioned without leaving the vault, with supported results draggable into notes as result cards. Setup signs in to a Memex account through the browser and opens a sidebar, and a callback URL can be pasted manually when the browser does not return to Obsidian. Pull imports are disabled by default and driven by rules that each select content types and a destination folder and are evaluated independently, so overlapping rules create one note per matching rule; annotation imports carry a hidden marker used to find the parent note and append under an Annotations heading, otherwise landing as standalone notes.
