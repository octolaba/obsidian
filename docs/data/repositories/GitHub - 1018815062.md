# SilverEzhik/obsidian-note-codes

This repository holds Note Codes, an Obsidian plugin that assigns a four-character code to every note in the vault so notes can be referenced from elsewhere, such as from hand-written notes. The code appears in the status bar on desktop and in the note metadata sidebar on phones and tablets, and command palette actions search for a code, copy the current note's code, or copy its protocol URL for opening the note. The README records that codes are derived from a note's name and path, so a rename changes the code.
