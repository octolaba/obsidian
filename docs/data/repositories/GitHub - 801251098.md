# stashpad/obsidian-to-stashpad

The Stashpad Docs plugin shares an Obsidian note to Stashpad Docs from inside the app. A command reachable from a ribbon action or from the command palette creates a new Stashpad Doc holding the current note's contents and opens it in the browser. The README frames the plugin as a way to pass a note written in Obsidian on to other people.
