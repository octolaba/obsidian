# nguyenvanduocit/obsidian-open-gate

Open Gate embeds a website inside Obsidian as what the plugin calls a gate. A gate can be opened at the left, centre or right of the interface or placed directly within a note, and its icon is generated from the site's own favicon. The README also claims support for embedding sites that cannot be embedded through an ordinary iframe.
