# rocketBANG/obsidian-image-attachment-upload

Adds commands that open a file picker, upload the chosen image to Cloudflare R2, and either insert an inline embed at the cursor or set the note's image frontmatter property to the public URL. Request signing happens on the device with the Web Crypto API, so the README states that no SDK and no bucket CORS configuration are needed and that the commands work on desktop and mobile. Object keys follow a configurable path template with a short random filename suffix, and the README warns that the access key and secret are stored in plaintext in the plugin's data file inside the vault.
