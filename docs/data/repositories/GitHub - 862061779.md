# sechan100/daily-routine-2

Repository for Daily Routine, an Obsidian plugin for tracking recurring tasks, described as a new version of the daily-routine plugin. Routines are recurring tasks scheduled daily, on particular weekdays or on specific dates, while todos are one-time tasks; both are recorded in routine notes, Markdown files generated each day and stored under the plugin's notes directory so the tasks stay manageable without the plugin. A calendar displays tasks carrying a showOnCalendar attribute on their dates, statistics track overall completion rate and routine consistency over time, and the README states full mobile support.
