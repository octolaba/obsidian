# shimeoki/obsidian-store

Store manages a vault's notes within a single folder, changing the structure of the vault to do so. That change is close to impossible to revert, and the documentation warns that a backup should be taken before the first use; the detailed usage guide lives in a docs directory in the repository rather than in the README. The plugin follows semantic versioning, and while the major version is zero each minor release is a breaking change to the settings format and each patch adds a feature.
