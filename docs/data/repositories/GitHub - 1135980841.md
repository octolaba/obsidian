# dsynkd/obsidian-better-properties-view

Better File Properties View extends Obsidian's core file properties view with a thumbnail drawn from a configurable property name, and an option to hide the metadata container while File Properties is active. The README states that installing and enabling the plugin is all that is required, with its configuration available in Obsidian's settings.
