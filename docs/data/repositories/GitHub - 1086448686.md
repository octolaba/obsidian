# ongaeshi/previous-river

Previous River joins Obsidian notes into sequences through a previous frontmatter property, so each note points at its predecessor and backlinks supply the note that follows. It adds a next button to the previous property row in the Properties view and commands for moving to the previous or the next note. Connected notes can be exported to an Obsidian Canvas as a tree — the branches from the current note, every sequence in the vault, or a filtered set — and loop structures are detected and marked on the origin note.
