# ichris007/Obsidian-Birthday-Reminder

Birthday Reminder manages birthday information for friends, family, colleagues and clients inside Obsidian. It reads a configurable frontmatter property, calculates the next birthday date, the days remaining and the upcoming age, converts Gregorian dates to lunar ones with leap-month support, and displays zodiac and Chinese animal signs. A monthly calendar view highlights birthday dates and statistics cards group entries into today, the next 7 days, the next 30 days and later, with folder filtering to avoid scanning the whole vault. The README states that the plugin is fully AI-generated.
