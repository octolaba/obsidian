# toshs/obsidian-mermaid-icons

Mermaid Icons makes icons usable inside Mermaid diagrams in Obsidian, correcting the rendering of the icon set Mermaid already supports by default and adding further sets bundled with the plugin. Icons are written as a prefix followed by an icon name, with `logos`, `lucide` and `clarity` among the supported prefixes. An Insert Mermaid Icon command opens a fuzzy-search modal, with no hotkey assigned by default, and the settings tab carries a browser for filtering every supported icon.
