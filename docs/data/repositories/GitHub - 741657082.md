# Opisek/obsidian-statusbar-organizer

Status Bar Organizer reorders the elements of Obsidian's status bar and chooses which of them are shown, from a settings page that gives every element a row with a drag handle on the left and an eye toggle on the right. The arrangement persists across restarts, and an element belonging to a deleted plugin keeps its remembered position until its row is dropped with the trash button that replaces the visibility toggle. Several presets can be created, renamed, deleted and switched between, with the status bar and the settings page following the switch, hotkeys assigned from Obsidian's own hotkeys page, and an option to keep the active preset separate for fullscreen and windowed modes.
