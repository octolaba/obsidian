# oikeya/obsidian-ref-raindrop

RefRaindrop syncs Raindrop.io bookmarks into an Obsidian vault as reference notes that keep the URL, the Raindrop metadata, the reader's own notes and compact AI index fields rather than the full page content. It supports multiple Raindrop accounts in separate folders, names every file after the raindrop id, updates existing notes by id or URL instead of recreating them, and preserves AI fields and the local notes section across syncs. The README states that the plugin is an independent community project, unaffiliated with Obsidian or Raindrop.io, and warns that the third-party services it can use — Raindrop, OpenAI, Gemini, Ollama and the bookmarked sites themselves — may incur charges or fail, which its throttling, ignored-host rules, private-network blocking and retry handling cannot guarantee against.
