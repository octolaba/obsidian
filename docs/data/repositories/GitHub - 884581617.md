# kuzzh/obsidian-ai-bot

AI Bot adds an assistant to Obsidian that is reached through a modal interface and integrated with commands and editor menus, and that helps generate, edit and organize note content. The README states that the assistant takes the context of the notes into account when responding. Its base URL, API key and model are configurable, so different services and models can be used.
