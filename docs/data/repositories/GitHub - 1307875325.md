# nickolay-kondratyev/obsidian-vicinity-graph-plugin

Replaces Obsidian's local graph with a view where each neighboring note is a labeled node carrying its title, a thumbnail of its first image, an icon strip for its attachments, its folder and a size reflecting relevance. Notes sharing a folder sit inside labeled group boxes that nest with the folder hierarchy, and links are right-angled connectors routed around the nodes; clicking one previews that relationship and can jump to the exact line. Outgoing links, embeds and incoming links each get their own adjustable depth, nodes can be resized with the size remembered, and clicking a node recenters the graph and opens the note. Notes can be pinned globally or only while a particular note is active, pins survive restarts, and the single view opens in the right sidebar or in a pane below the active note.
