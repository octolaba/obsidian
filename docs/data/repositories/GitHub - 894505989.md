# theopavlove/obsidian-dynamic-outline

Obsidian plugin that displays a floating table of contents for the current note, opened from an icon in the top right or from a command that can take a hotkey. It marks the heading the reader is currently at, searches headings and jumps to the matching section, collapses and expands heading groups, and is navigable from the keyboard. Its behaviour can be set to reveal on file open, toggle on hover or auto-hide, and its colours and layout are customisable through the Style Settings plugin.
