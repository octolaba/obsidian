# threeyang3/bangumi-sync

Bangumi Sync is an Obsidian plugin for importing a user's Bangumi collections into local notes across anime, games, books, music, and other media. It supports manual, automatic, incremental, and forced synchronization, configurable templates, progress and collection fields, cover images, episode comments, and shared item notes. Bidirectional synchronization can reconcile ratings, reviews, tags, collection states, and episode progress with conflict choices.
