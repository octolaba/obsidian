# triangular-sneaky/obsidian-list-outline-helper

The repository description records an Obsidian plugin to select the current outline. Its README says a single command selects the line the cursor is on together with every following line that is indented more deeply, which it compares to pressing the select-all shortcut twice in OneNote. It suggests combining the selection with the move-line commands to relocate an outline, or with tab and shift-tab to change its level. The README records that part of the project's copyright is held by the author of an earlier select-current-line plugin.
