# maitake4211/property-kanban

Property Kanban renders a Kanban board from Obsidian note frontmatter, keeping task notes as the source of truth so creating, moving, deleting, or editing cards updates properties and refreshes the board. Cards can be grouped and sorted by fields, arranged in two-dimensional swimlanes, created with date-aware forms, and moved to the trash with related parent and child links maintained.
