# maitake4211/property-kanban

Property Kanban renders a kanban board from note frontmatter properties, treating the task notes as the single source of truth: cards are grouped by a chosen frontmatter field, dragging a card between columns writes the property back, and edits to the notes refresh the board. The README states that cards can be sorted within a column by any property in either direction, that clicking a card title opens the note or jumps to the tab already showing it, and that file creations, changes and deletions are detected in real time. On the first board open with an empty task folder the plugin creates the folder and seeds four sample tasks in a swimlane view, generated in the language of the Obsidian setting; the README records that this happens only once and that existing notes are never modified.
