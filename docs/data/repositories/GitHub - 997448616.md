# chris-codes1/timeline-canvas-creator

This plugin creates timeline-structured canvases in Obsidian without the reader having to place each card individually. The README's steps are to open the command palette, run the command that creates a timeline canvas, and then enter a start date, an end date and an interval before submitting.
