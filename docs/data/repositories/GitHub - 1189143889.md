# d0uub/obsidian-multisync

Maps folders of a vault onto folders in cloud storage and keeps several such mappings active at once, so different parts of a vault can live on different drives. Dropbox, Google Drive and OneDrive are supported through OAuth, and Notion is offered as an experimental target that may duplicate, overwrite or delete content. Each rule pairs one local folder with one cloud folder, and a dry run previews the changes before a sync is applied; a confirmation step and trash bins on both sides guard against unwanted deletions. Unlimited drives, real-time sync and content merging are listed as paid features.
