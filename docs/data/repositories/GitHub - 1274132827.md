# aaa-mvc/ara

An Obsidian plugin that renames a file inline when its already-active entry in the file explorer is clicked again, in the manner of Windows File Explorer, so no context menu or F2 is involved; Enter confirms and Escape cancels. A cooldown keeps a double-click that opens a file from starting a rename by accident. The README records compatibility with Obsidian 0.15.0 or later, desktop and mobile, and both the legacy and the tree-item file explorer DOM.
