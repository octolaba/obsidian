# alona-iaig/obsidian-overboard

This plugin embeds Overboard Studio whiteboards inside Obsidian notes: a board address placed in an overboard code block, or inserted through a command, renders the board in the note. Its README describes editing the board inline, generating diagrams from a sentence, dragging stickies, real-time collaboration and a template library, all provided by the Overboard service rather than by the plugin. It states that the plugin is deliberately a thin client, loading boards in a sandboxed iframe pointing at the Overboard embed address, with authentication happening inside that iframe so the plugin never sees credentials, tokens or board data. Pricing tiers for the service are stated in the README as well and were not verified here.
