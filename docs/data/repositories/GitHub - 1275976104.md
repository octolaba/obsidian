# ahseyg/Masking-as-MD

Masking as MD opens, views and edits non-Markdown files such as .py, .js, .html, .css and .json inside an Obsidian vault, using a CodeMirror 6 editor with syntax highlighting and line numbers. Configured extensions open like ordinary notes and any file can be opened as text from its context menu, while settings control the handled extension list, syntax highlighting, line numbers, word wrap and font size. The README states that files are opened as plain text with no conversion to Markdown and are never modified unless edited and saved, and lists built-in highlighting for JavaScript, TypeScript, Python, HTML, the CSS family, JSON, YAML and Markdown.
