# muhammedhunaid/markdown-fixer

Markdown Fixer cleans up Markdown that has picked up artifacts from terminals, PDFs, chat apps and AI tools, either automatically on paste or on demand through commands. Its fixers strip zero-width and other invisible Unicode characters, convert Unicode box-drawing tables into standard pipe tables, collapse the excess padding in spaced pipe tables, repair fenced code blocks whose spacing was damaged on copy, and trim trailing whitespace, while a combined command runs them in sequence and reports what it changed.
