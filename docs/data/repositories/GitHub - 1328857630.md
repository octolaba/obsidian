# hellokunzai/obsidian-mindmap-xmind

Opens .xmind files from the vault in a mind-map view and edits them in place: topics are added or removed, branches collapse and expand, double-clicking a node edits its text, and Tab and Enter create child and sibling topics. New maps are created from the command palette or the file-list context menu, and an icon toolbar carries fit-to-view, save, structural edits and SVG or PNG export, folding surplus buttons into a more menu when the window is narrow. Settings cover an auto-save interval of 10 to 300 seconds, the default layout, compact spacing, the branch color palette, the corner mini map and the initial zoom. The plugin declares Obsidian 1.4.0 as its minimum, supports desktop and mobile, and reads and writes the zipped .xmind format with JSZip.
