# rcsaquino/obsidian-auto-filename

Obsidian plugin that renames files from their own content, taking the first characters of the file as the filename. Folder paths where this applies are listed in the settings, case sensitive and one per line, and further options cover how many characters are used, using an H1 header as the filename when the file starts with one, considering only the first line, and hiding the inline title for files in those folders. New files created in a target folder are renamed automatically, and a button in the settings renames every file in the target folder at once.
