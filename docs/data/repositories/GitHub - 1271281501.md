# JongChoiYip/s3-image-sync

S3 Image Sync scans the images referenced by Obsidian notes, uploads them to S3-compatible cloud storage such as Cloudflare R2, AWS S3 or MinIO, and replaces the local Markdown links with the remote public URLs. The README identifies the repository as a redesigned fork of an earlier attachment and image-host manager, narrowed to images alone by removing the original's handling of PDFs, documents and heavy media, and states that its refactoring, interface redesign and documentation rewrite were generated with the help of an AI model. Its other stated changes are presentational: a responsive upload modal whose card grid adapts between desktop and mobile viewports, and custom selection and progress controls in place of the browser defaults. This note is grounded in the README alone, as the repository records no description.
