# Cyfine/EmoTagsTitler

Obsidian plugin that copies the emoji found in a note's tags into the note title, and removes them again. The README documents commands that apply the addition or the removal across every note carrying emoji tags. It warns that Dropbox does not sync files whose names contain emoji.
