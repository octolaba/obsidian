# muckmuck96/obsidian-file-share

Shares individual files directly from one vault to another over a socket server, with the transfer described as end-to-end encrypted. Recipients are added by exchanging a key and saving it in a friend list. The README states that a default server is run by the project and hosted in Germany, and that a self-hosted server can be configured instead, deployed from the project's own socket-server Docker image or run directly on a machine.
