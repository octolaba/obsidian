# HananoshikaYomaru/obsidian-image-caption

Obsidian Markdown Image Caption generates image captions from Markdown alone, so the result stays compatible with Obsidian Publish and other Markdown editors. Comment-style markers written after an image declare a caption or a lightbox, optionally grouped, and a command run on the current file turns them into a figure element containing a figcaption. The plugin checks whether a figure element already sits below the marker and replaces it rather than adding another. The README states in a caution that the plugin works only with external images and that local images are not supported, and suggests pairing it with a custom save plugin so captions are generated on save.
