# mnaoumov/obsidian-embed-html

Embed HTML adds support for embedding HTML-family files in Obsidian notes, including htm, html, shtml, xht, and xhtml files. Embeds can use configurable dimensions, reactive content fitting, CSS size constraints, borders, backgrounds, rounded corners, and an option to open HTML files in a new tab.
