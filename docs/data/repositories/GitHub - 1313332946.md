# PHANTOM-Nw/obsidian-mindmap-mode

Switches a note into an editable radial mind map in the same tab, the way reading mode is toggled, without generating any new file. Headings nest by level and nested bullets hang under their heading, so the existing outline is the structure, and canvas edits - rename, add, delete, indent, reparent, reorder, fold, tick checkboxes - are written back as minimal line edits that leave untouched lines byte-for-byte identical. A map opens folded to the root and its top-level branches, each toggle showing how many nodes it hides, and reopens with the fold state and framing from last time, stored in the plugin's data rather than in the note. Math is typeset with Obsidian's MathJax while dollar amounts are left alone, and the canvas offers keyboard shortcuts, drag-to-reparent, zoom, pan and its own find bar with optional regular expressions.
