# barcantree/Insider

Insider turns YouTube videos, web pages, PDFs and direct questions into structured notes in an Obsidian vault and links them to related ideas already in it. A source address or vault PDF path is pasted into a sidebar with optional instructions and the plugin fetches it and writes a new note: YouTube transcripts come through the InnerTube API, Reddit through its public JSON endpoint, and X or Twitter through API v2 with a bearer token given in settings, while a question with no source produces a standalone research report. Related notes are found either by keyword overlap validated by the model or by scanning the vault into compact semantic snapshots, chosen in the sidebar options. The README states that the plugin runs on DeepSeek's OpenAI-compatible API, with the key and output folder set in its settings.
