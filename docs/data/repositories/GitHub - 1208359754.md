# jabaho9523/obsidian-vault-plus

Vault Plus is a sidebar dashboard that reports vault health problems and offers one-click fixes. The checks listed in the README are orphan notes with a strict or relaxed definition, broken wikilinks and Markdown links, empty notes, notes over a configurable word threshold, fuzzy duplicate titles by edit distance, tags used in only one note, and attachments no note links to, each toggleable in settings. Rows offer opening a note, opening a duplicate pair side by side, and deleting to the system trash with confirmation, and the dashboard refreshes shortly after an edit; the README states that the plugin operates fully offline.
