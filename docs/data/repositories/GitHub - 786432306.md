# kocheck/obsidian-figma-viewer

Turns a pasted Figma link into an inline preview embedded in the note, which the README says is viewed and interacted with in reading mode and updates as the Figma file changes. The plugin embeds the file in an iframe, so the README states as a warning that only publicly shared files whose permissions allow anyone with the link to view will render, while private or restricted files fall back to a card.
