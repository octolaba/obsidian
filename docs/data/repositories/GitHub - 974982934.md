# hydrateagent/hydrate

Adds conversational access to the vault, answering questions from note content, surfacing connections between notes, searching by meaning rather than keywords, and generating outlines, summaries and new content. The README states plainly that full access requires a paid subscription and an account, that the plugin connects to the vendor's backend and to third-party AI APIs, and that anonymous usage analytics are collected. It also states that the plugin is Apache 2 licensed but relies on proprietary server-side code.
