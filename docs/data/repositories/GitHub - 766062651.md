# stroiman/obsidian-title-sync

This plugin keeps a note's inline H1 heading in sync with its file name: when a file is renamed it looks for the first H1 and updates it if the current text matches the old file name. The README states that it works on desktop only, that just the first H1 is replaced, and that its main purpose is template-created notes, where renaming an untitled note would otherwise leave the template's heading behind. It also explains that nothing happening usually means the heading and file name are already in sync, or that Obsidian's metadata cache is stale.
