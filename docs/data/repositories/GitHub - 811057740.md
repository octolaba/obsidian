# No-Instructions/Relay

Relay adds real-time collaborative editing to Obsidian, with live cursors, offline editing that syncs when the connection returns, and shared folders whose access to updates is managed. Its README describes the mechanism in three steps: conflict-free replicated data types track updates to folders designated inside a vault, those updates are sent to the project's servers, and the servers echo them to the other collaborators, whose copies integrate them as they arrive. The plugin is written by System 3, and the README explains what a CRDT is, links introductory material on the subject, and points to a Discord for support.
