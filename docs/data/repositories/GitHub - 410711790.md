# coddingtonbear/obsidian-itinerary

The repository holds Obsidian Itinerary, a plugin that renders a monthly, weekly or daily calendar from event information written in notes. Its README frames the problem with a trip plan whose hotels, parades and flights are buried in prose across several headings, where nothing but careful reading keeps the days straight. The plugin's answer is to read the event details out of those notes and draw them as a calendar; the code is written in TypeScript under the MIT license.
