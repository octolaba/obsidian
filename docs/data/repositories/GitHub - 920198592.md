# bwya77/Inline-Checkbox-Groups

Renders several checkboxes written on one line, separated by a configurable character defaulting to a vertical bar, as a single inline group rather than as separate list items. An option strikes through the text once every checkbox in the group is checked, and the rendering follows in both edit and preview modes while keeping Obsidian's native checkbox styling. The README states that the plugin requires Obsidian 0.15.0 or higher and is desktop only.
