# kangig94/obsidian-para-zk

PARA-ZK scaffolds and maintains a PARA plus Zettelkasten vault in Obsidian whose wiki pages are kept coherent by language-model workflows: the user curates sources and asks questions, and the workflows ingest them into interlinked notes with consistent frontmatter, references and backlinks. Its README records three drivers for one workflow contract: GUI commands and ribbon shortcuts in the plugin, a native command-line interface available while Obsidian runs, and a thin MCP server that discovers that contract and exposes shell-safe replace, set and add edit tools for scripts and models. A setup command creates the PARA and ZK layout, templates and dashboards idempotently, overwrites plugin-owned scaffolding when the generated content differs, and offers to install required community plugins or optional enhancements; Obsidian 1.12.3 or newer is required.
