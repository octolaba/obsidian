# tIsGoud/Obsidian-Omd2Typst

Obsidian plugin that exports a note to a typeset PDF, or to Typst source, using the Typst document compiler. Export runs from the command palette or the file context menu and produces a cover page filled from frontmatter, an auto-numbered table of contents, callout blocks, tables and images, with five languages supported. The README records desktop-only operation on macOS, Windows and Linux, a minimum Obsidian version, and that without Typst installed only the source export works while PDF export shows an install notice; the plugin looks for the compiler in common locations, so a path rarely has to be configured.
