# raineszm/obsidian-export-to-tex

The repository holds obsidian-export-to-tex, a plugin that exports Obsidian notes into a LaTeX form suited to pasting into a TeX file. Its README covers installation from the community plugin browser and manual installation by unzipping a release into the vault's plugin directory. It is written in TypeScript under the MIT license.
