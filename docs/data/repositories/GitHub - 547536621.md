# erykwalder/dayspring-theme

Dayspring is an Obsidian theme inspired by the unmaintained al dente theme, described by its README as mostly a colour theme with rounded edges that leans on Obsidian's own theme variables and keeps custom CSS to a minimum. Its distinctive addition places H6 headings beside paragraphs instead of in the text flow, so items such as verse numbers sit outside the main text, and this works on mobile and in embedded content. Frontmatter is hidden in preview and treated as metadata, and a note can be switched to a serif font on a darker background by setting a CSS class in its frontmatter, with three interchangeable class names accepted. The theme uses Crimson Pro and Figtree, included as variable-weight fonts in the CSS, which the README says may still help to install locally.
