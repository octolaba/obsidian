# BCS1037/side-bookmark

Side Bookmark embeds a web browser in the Obsidian sidebar so that pages can be opened and bookmarks kept without leaving the vault. The README describes navigating any page inside the sidebar, saving sites as bookmarks organised into folders, reordering bookmarks and folders by drag and drop, and storing bookmarks, folders and browser preferences inside the vault. An optional setting intercepts clicks on external links in notes, in reading view and live preview alike, and opens them in the built-in browser instead of the system browser; the Chinese half of the README adds that holding a modifier key while clicking bypasses the interception.
