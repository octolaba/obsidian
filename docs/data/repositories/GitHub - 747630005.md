# Darren-project/obsidian-spotify

This plugin injects the Spotify SDK into Obsidian rather than providing a finished interface: its README states that code has to be written by the user, and names the official Spotify TypeScript API as what it wraps. Configuration is creating a Spotify application, registering the plugin's redirect address on it, and entering the client identifier and secret in the plugin's settings before completing the login flow. Once authenticated, the Spotify API can be used from the vault to reach the account, search songs, albums and artists, and retrieve information about playlists and tracks.
