# sahandps/TaskLoops

TaskLoops collects task-tagged lines from anywhere in an Obsidian vault into a sidebar inbox, walks them through a GTD clarify flow and marks each line as handled once it has been sorted. The README is explicit about what it writes: a handled marker appended to a sorted line, which a setting turns off, the sentence of a task the user explicitly edits, and a new tagged line appended to a capture note that is named in settings and created on first use. It states that nothing else is written, that frontmatter, tags, line order and unsorted lines are never touched, and that the remaining state, including bucket, context, delegate, date, project links and done, lives in the plugin's own data file rather than in the notes.
