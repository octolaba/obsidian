# dexin-qi/obsidian-sync-calendar

This plugin synchronises Google Calendar events into Obsidian and manages them as tasks, with a task format the README says is borrowed from the Tasks plugin. The README records that Dataview must be installed because it is used to list tasks within a date range, that recurring tasks are not supported, and that a task needs a start-time element attached before the sync command will push it to the calendar. Synchronisation is centred on calendar events: once a task has reached the calendar, later edits made in Obsidian are not sent, and changes made in the calendar are synced back into the vault instead; the plugin is described as early alpha and subject to change.
