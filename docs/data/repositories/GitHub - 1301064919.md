# Evgene-Kopylov/obsidian-multistate-checkboxes

Multistate Checkboxes adds twenty extended checkbox states to Obsidian, each with its own SVG icon embedded as a data URI so the states do not depend on the active theme. Colors are taken from Obsidian CSS variables so they adapt to any theme, and each state can be enabled or disabled, recolored, or given a replacement icon in the plugin settings. A command cycles the checkbox under the cursor through the configured order, and the README states that both Reading view and Live Preview are supported.
