# milad-s5/obsidian-shamsi-date-converter

Shamsi Date Converter adds Shamsi — Jalali or Persian — dates to Obsidian notes alongside Gregorian ones held in frontmatter properties. The README describes configurable mappings between date properties, so that adding or changing a Gregorian value automatically writes or updates its Shamsi counterpart, and it works over several date pairs such as a start and an end date at once. Settings cover adding, editing and removing those mappings and choosing the output format, a command palette entry converts the current file on demand, and the README states that files without the relevant properties are skipped early.
