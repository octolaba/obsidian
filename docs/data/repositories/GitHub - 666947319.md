# nirtamir2/obsidian-slidev

Slidev for Obsidian previews a Markdown presentation from the vault by opening the active note in an embedded presentation view and keeping the displayed slide aligned with the cursor. The README records it as desktop-only because it starts a local Node.js process, and lists its requirements: a compatible Node.js that the plugin neither installs nor updates, the Slidev command-line package installed in the project's own node_modules rather than globally, and write access to the Slidev project while a presentation starts, where the plugin creates a hidden temporary entry and bridge configuration so that project's themes, addons and components apply to notes stored elsewhere. A quick setup installs a small version-pinned starter only when that option is selected, and never changes a manually configured project.
