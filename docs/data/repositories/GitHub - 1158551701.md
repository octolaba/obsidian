# TheBestTvarynka/photo-tagging

This plugin tags people on photos inside Obsidian and shows a person's photos on their own page. The README explains that it was written for genealogy data kept in a vault, after its author found no existing plugin for the task. It records libvips as a mandatory dependency that cannot be disabled: the plugin uses it to generate image tiles and a preview when an image is first opened in the tagger, so that large images display and zoom efficiently.
