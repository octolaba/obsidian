# keepwonder/ezimage-obsidian

EzImage intercepts image paste and drag-and-drop events in Obsidian and either uploads the image to Cloudflare R2, inserting a Markdown link, or copies it into the configured attachment folder as a wikilink, with the current mode shown in the status bar and switchable from settings or a command. Uploaded images are converted to WebP and resized first using browser-image-compression, and when compression is off the image is redrawn through a canvas so EXIF data such as GPS location and device information is removed either way. Failed uploads retry twice with back-off and distinguish credential from network errors, and the upload path is built from a template with date, timestamp, random, name and extension variables. The README states that AWS Signature V4 is computed on-device with the Web Crypto API, and the settings interface is available in English and Chinese.
