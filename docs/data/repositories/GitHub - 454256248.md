# ganesshkumar/obsidian-excel-to-markdown-table

The repository holds an Obsidian plugin that converts spreadsheet data on the clipboard into a Markdown table when it is pasted, covering Microsoft Excel, Google Sheets, Apple Numbers and LibreOffice Calc. Its README records three routes with a difference between them: an ordinary paste, which converts only tables of two or more columns, and a dedicated hotkey or a command palette entry, both of which also handle a single-column table. The hotkey can be reassigned from the settings, and the code is licensed under MIT.
