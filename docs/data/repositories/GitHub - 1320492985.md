# PleiadesM/Tufte-Inline

Tufte Inline adds three inline typography shorthands rendered in Reading view and Live Preview: a doubled-caret span becomes a small-caps new-thought opener, a doubled-ampersand span becomes an italic run-in lead-in, and a doubled-at span around a CJK character becomes a two-line drop cap. The styling for all three comes from the Tufte theme rather than from the plugin, which is part of the Tufte for Obsidian suite. This repository only distributes the plugin through the community directory; development, documentation and issues live in the suite's main repository.
