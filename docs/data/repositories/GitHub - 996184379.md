# shandyba/obsidian-lime

UnLime toggles the visibility of the unlinked mentions sections inside Obsidian's standard backlinks and outgoing links panels, with separate switches for each panel in its settings. The README explains that large vaults with diverse notes produce many false positives there, and that the author wrote the plugin to keep those entries out of the way. It also states that the approach is likely fragile, that it was tested on macOS desktop Obsidian 1.8.10, and that the author cannot verify other platforms or guarantee compatibility with future versions.
