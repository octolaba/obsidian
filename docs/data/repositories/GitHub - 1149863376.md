# kqint/obsidian-zone-scroll-zoom

This repository holds Zone Scroll Zoom, an Obsidian plugin whose shortcut-driven zoom, by default Ctrl with the scroll wheel, adapts to where the mouse sits: inside the editor area it changes the editor font size, outside it scales the whole interface including sidebar and menus. An on-screen indicator reports the current scale or font size in real time, the shortcut and zoom precision are configurable, and buttons in the settings restore the default 16px font and 100% interface scale. The interface is available in English, Simplified Chinese and Traditional Chinese, and the README asks that Obsidian's own quick font size adjustment be disabled first.
