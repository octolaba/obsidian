# ibrh96-prog/obsidian-periodic-notes-synthesizer

This plugin rolls accumulated daily and periodic notes up into a synthesis note covering monthly and quarterly summaries, recurring themes, open loops and stated commitments measured against completed ones. Its README frames the problem as a growing backlog whose throughline is hard to see, and states that the plugin rolls up what is already written rather than reflecting, prompting or coaching, working alongside an existing journaling practice instead of replacing it. Recorded sections are an overview of notes synthesized with date range, open-loop count and commitment tally, themes shared by two or more notes with an AI-written consensus and the tension between them, the current week starting Monday, open loops flagged stale past a threshold, said against did, and a short summary and topic list per synced note.
