# gabrielbacha/obsidian-base-visuals

Bases Visuals colors values in Obsidian Base tables as compact pills and adds conditional formatting to them. Colors are assigned automatically and stay stable per property and value, can be set from presets or custom hex values, and are managed from a searchable manager opened by a Format button in the Base table toolbar. Ordered, case-insensitive rules highlight a cell or a whole row for text, list, checkbox and number values, scoped to the current view or every view in the Base, and right-clicking a pill changes its color, manages that column's values or removes the value from the row. A Layout popover sets row heights and reusable column widths as named presets, column appearance can be muted, recolored or bolded per view, and nothing is written to note Markdown or frontmatter.
