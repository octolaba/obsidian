# antoKeinanen/obsidian-sanctum-reborn

Sanctum Reborn is a fork of jdanielmourao/obsidian-sanctum, taken up because the original maintainer went inactive, and it keeps Sanctum's aim of a minimalist, serene space of retreat for thought and uninterrupted work. Its stated design principles are intentional, consistent and clean: the interface is decluttered, the greyscale palette is shared between light and dark, colour marks hovered and activated elements, every element follows a predetermined grid, scale and set of animations based on IBM's Carbon Design System, and IBM Plex is the single font family. The README warns that the theme significantly alters Obsidian's original CSS and so may break on app updates or conflict with custom snippets, and it recommends the Smart Typography, Contextual Typography and Style Settings plugins.
