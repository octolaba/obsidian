# mokeyish/obsidian-code-emitter

Code Emitter lets code blocks in Obsidian be executed interactively in a sandbox, in the manner of Jupyter notebooks, for languages including Rust, Kotlin, Python, JavaScript and TypeScript. The README states that no external environment such as a system compiler installation is required, because execution runs either in local sandboxes built on JavaScript or WebAssembly or through network requests to online playgrounds. As a consequence it lists support for every platform Obsidian runs on: Windows, macOS, Linux, Android and iOS, and the README tabulates which provider backs each language.
