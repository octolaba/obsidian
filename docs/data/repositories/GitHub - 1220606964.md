# xwberry/obsidian-drag-out

Drag Out lets files be dragged from Obsidian's file explorer into other applications as real filesystem files instead of an obsidian URL, which suits browser upload fields, email attachments, chat apps and file managers. The README states it intercepts file-tree drags while a configured modifier key is held, Ctrl on Windows and Linux or Option on macOS by default, and uses Electron's startDrag API to expose the real on-disk path while leaving normal Obsidian drag behaviour untouched otherwise. Multi-select is supported, and the modifier exists because Electron's external drag API takes over the whole drag operation. The plugin is described as experimental and desktop only, tested primarily on Windows.
