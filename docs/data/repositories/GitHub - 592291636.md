# LilaRest/obsidian-custom-classes

Custom Classes lets a note attach its own HTML classes to chosen Markdown blocks and elements from within the note itself. A class directive written as inline code on the line before a block applies the class to the whole block, such as an entire list, while the same directive placed inside an element applies it to that element alone, such as a single list item; both can be combined. The classes appear on the rendered output in Live Preview and Reading view, which is what lets snippet or theme CSS target those blocks.
