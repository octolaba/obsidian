# Jade367/ConceptLens

Obsidian plugin for capturing unfamiliar terms and concepts while reading. The README describes a floating toolbar shown over a text selection in editing and reading views, offering overview, explanation, translation, expansion and saving, with the selected text and its surrounding context used to generate a reading card. It lists one-click concept note creation in a configurable folder, duplicate detection that opens the existing note instead of creating a copy, output in several languages with right-to-left display for Arabic, and presets for OpenAI-compatible providers.
