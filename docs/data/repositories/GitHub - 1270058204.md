# hata-suriiken/obsidian-mobile-pinch-zoom

Mobile Pinch Zoom adds two-finger pinch zooming to notes on Obsidian mobile, anchoring the zoom at the point between the fingers, gliding back to exactly 100% when a gesture ends within a few percent of it, and responding to a trackpad pinch as well. Standalone PDF and image files opened in their own tab zoom too, while Canvas and Excalidraw are left to their own gestures. A floating indicator shows the current level and resets it on tap, configurable to fade automatically, stay visible or be hidden and to sit in any corner, and zoom in, zoom out and reset commands can take hotkeys. Two modes are offered: scaling the whole note through CSS zoom, which the README notes can leave the editor cursor slightly off, or scaling only the font size, which leaves images and diagrams unscaled.
