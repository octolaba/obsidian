# notoriouslab/vault-curate

Vault Curate is described as a local-first plugin for finding, connecting and rediscovering notes. The README describes a closed loop: semantic search that fuses keyword, meaning and fuzzy title matching finds a note, a relation graph and semantic paths surface related notes that were never linked by hand, and Hot and Cold tiering resurfaces forgotten ones. It records strong Chinese and CJK handling, a split where the desktop builds the index while phones and tablets search it, and that no API keys are required.
