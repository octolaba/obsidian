# andrewmarconi/GoogleDriveFolderLink

Attaches a Google Drive folder to a note through a fuzzy-search picker over configured root folders in My Drive and shared drives, caching the folder tree in memory for local search. The association is stored in the note's frontmatter and a clickable link in the properties pane opens the folder in a browser, with attach, open and remove actions in the command palette and the file context menu. The README requires each user to create their own Google Cloud OAuth credentials with the Drive API enabled and the read-only Drive scope, and walks through the consent screen setup for both Workspace and personal accounts.
