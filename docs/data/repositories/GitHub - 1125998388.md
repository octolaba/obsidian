# jawoojo/obsidian-toggle

This plugin renders a pipe-and-angle-bracket marker as a clickable triangle that folds and unfolds the content below it, producing collapsible toggle blocks in the style the README attributes to Notion. A heading may be used as the toggle title, keeping the heading's styling while folding only inside the block, which the README says leaves the global outline hierarchy unbroken. Code blocks can be made collapsible by adding a marker after the opening fence, and hovering the title line reveals a copy button. The README states that the implementation builds on Obsidian's core folding engine.
