# 7368697661/moon

moon places a small oneko-style cat in the Obsidian window that chases the mouse cursor and curls up to sleep after a few seconds without movement, its behaviour and sprite taken from the oneko.js project. The README records the plugin as desktop only because it needs a real cursor, and states that it should respect a reduced-motion preference.
