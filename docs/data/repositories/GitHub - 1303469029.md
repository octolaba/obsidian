# Quincy-Leo/obsidian-export-readview-pdf

Exports the active note's Reading view to PDF by snapshotting the rendered DOM and printing it through Chromium's own print engine, so anything drawn into the preview by other plugins is captured rather than re-rendered. Local images are converted to data URLs, canvas elements are snapshotted as images, open shadow DOM is cloned, and every stylesheet and CSS custom property is captured so the theme survives. Page size, orientation, margins, scale, header and footer and background printing are configurable, and output can go to the vault root, a relative path or an absolute system path with tilde expansion. It is desktop-only because it relies on Electron, needs Obsidian 1.4.0 or newer, refuses to run unless the view is in Reading mode, and strips scripts, inline event attributes and javascript URLs while snapshotting.
