# uglyboy-tl/obsidian-ink-player

Plays interactive fiction written in Inkle's ink scripting language inside Obsidian. An ink script file is opened and started through the Activate Ink Story command or the dedicated ribbon button. The README credits Calico for features including custom tags, mobile compatibility, game saving and advanced parsing, and states that the plugin belongs to the InkWeave monorepo and depends on its core, SolidJS and plugin packages.
