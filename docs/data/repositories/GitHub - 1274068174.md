# vitaly-andr/obsidian-code-workbench

Code Workbench connects Claude Code to an Obsidian vault through approval-gated, link-preserving tools for reading, creating, appending, renaming, and deleting notes. It also provides a desktop code editor for many languages and configuration files, with syntax highlighting, diagnostics, formatting, side-by-side Keep/Reject diffs, Git review, and inline blame. The plugin uses the user's Claude subscription rather than a metered API key.
