# vitaly-andr/obsidian-code-workbench

Obsidian plugin that gives Claude Code tools for maintaining a vault and adds a code editor beside them. The README states that the status bar opens a terminal in the vault with the Claude Code CLI already connected, without further setup, and that it drives the CLI the user already runs, so the work draws on a Claude subscription rather than a metered API key. With the vault tools enabled, Claude reads and edits notes through Obsidian itself, answering from backlinks, wikilinks and frontmatter and making link-preserving create, append, rename and trash changes; the editor side is described as syntax highlighting, diagnostics, formatting, keep-or-reject diffs, git review and inline blame for many languages.
