# virbird/LLM_Private_Teacher

Obsidian plugin providing an AI study assistant in a sidebar or as a full-width tab. The README states that it calls model providers directly, naming Anthropic Claude, OpenAI and OpenAI-compatible endpoints, and can instead drive local command-line tools that need no API key, with automatic detection of those executables in the path, Homebrew, nvm and other common locations. It describes selecting any Markdown note as the current study material, learning roles such as private tutor, Socratic tutor and language partner, a set of learning-method commands, and a bilingual English and Chinese interface.
