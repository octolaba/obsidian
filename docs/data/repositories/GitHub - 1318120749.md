# schemen/beyond-toc

Beyond TOC adds a floating table of contents in the margin beside a note, in both Reading view and Live Preview, tracking the scroll position and highlighting the current heading and the path to it. Branches fold from a chevron and reopen as the scroll enters them, and the card is toggled from a header button, a command or an optional ribbon icon, with per-note frontmatter overriding the global setting. Settings cover visibility, title source, heading depth, side, width, tracking and appearance, and the four colour pickers are empty by default so the card follows the active theme. In a narrow pane the card collapses to a handle that floats the list over the note on click, and the text column never loses width to it.
