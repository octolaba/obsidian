# dmo-code/MyTypewriterLine

This repository holds My Typewriter Line, an Obsidian plugin that sets custom top and bottom scroll padding in the editor so the active line stays in focus while typing; the repository records no description, so this summary follows the README alone. Padding is set in vh through a single horizontal slider, with the bottom value derived automatically as 100 minus the top. The README states that the plugin provides this one function and nothing else.
