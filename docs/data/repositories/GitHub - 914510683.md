# Nick-de-Bruin/obsidian-extended-file-support

Adds viewing and embedding for file types Obsidian does not open on its own, listed in the README as Krita, Photoshop, Illustrator and Clip Studio Paint documents and the glTF, GLB, OBJ and STL three-dimensional formats. The README states that editing these files is deliberately out of scope, and that each type can be switched off in the settings. Embeds accept parameters after the filename, a width or a width and height for every type, and for three-dimensional files a spin override and camera position and target coordinates. Embedding also works in Canvas.
