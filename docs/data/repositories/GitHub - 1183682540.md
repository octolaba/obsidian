# saltyfireball/obsidian-click-image-to-zoom

Click Image to Zoom opens any image in a note in a full-screen modal when it is clicked, in both live preview and reading view, on desktop and on mobile. The README lists scroll-wheel zoom, drag to pan, a two-finger pinch gesture on touch devices, and keyboard controls that zoom, reset and close, with the overlay also dismissed by clicking outside the image or its close button. Zooming can be disabled for a single note through a frontmatter key or globally from settings or the command palette, and the zoom step and the minimum and maximum zoom levels are configurable.
