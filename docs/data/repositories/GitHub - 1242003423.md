# notesynchelper/obsidian-wechat-messenger

Syncs notes and articles into Obsidian from several content sources; its recorded description names WeChat Official Accounts, Xiaohongshu, Dedao, Yuanbao and Zhihu as the sources this variant captures. The README describes configuring the plugin in the Obsidian settings and then triggering a sync from a toolbar icon or the command palette, after which content is written into the vault. Beyond those settings the README is mostly about building the plugin from source, so it states little further about how the capture itself works.
