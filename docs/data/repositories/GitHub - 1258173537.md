# agarcabin/obsidian-lazy-cursor

Removes focus from the editor when a note is opened, so no cursor is placed until the editor is tapped or clicked. It listens for Obsidian's file-open workspace event and calls blur once inside a requestAnimationFrame, which lets the WebView finish painting first and matters most on mobile; after that single call the plugin does nothing until the next file is opened. There are no settings and no file-type filter, and it is a fork of an earlier desktop-only plugin with the desktop-only flag turned off.
