# Gao-Qian-Long/obsidian-markdown-cleaner

An Obsidian plugin that cleans Markdown formatting and converts LaTeX math delimiters; its recorded description is in Chinese and the README is bilingual English and Chinese. Cleaning removes excess asterisk and underscore markers while leaving ordinary bold and italic text intact, and runs either on a configurable hotkey over a selection or automatically on paste. Formula conversion rewrites inline and block LaTeX delimiters into the dollar-sign forms Obsidian renders, and the README lists fractions, roots, Greek letters, operators, matrices and comparison symbols among the supported commands.
