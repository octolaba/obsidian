# catalyys/obsidian-timer

Turns a timer code block into an interval timer with Start, Skip and Reset controls and a beep between steps. Each line of the block is a named step with a duration given in plain seconds or with an s, m or h suffix, and a sets line repeats the indented block beneath it a given number of times, with nesting allowed. An optional title comes first, and step names such as work and pause are labels only.
