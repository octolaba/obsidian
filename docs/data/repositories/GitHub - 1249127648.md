# michael-andreuzza/serendipity-obsidian

Serendipity for Obsidian is the community listing of the Serendipity color palette, which its README calls elegant, minimal and clean. Three variants are listed: Midnight and Sunset as dark and Morning as light, and the community theme ships Morning and Midnight together in theme.css. Sunset is distributed instead as a CSS snippet under the variants directory, and the README says to enable only one dark snippet at a time.
