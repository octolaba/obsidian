# AlessandroRuggiero/script-launcher

Script Launcher runs scripts written in any language from inside Obsidian. Each script is registered in the plugin settings with a display name and an absolute path, which the README says may point at a binary, an executable or a Python, shell or bash script, together with options to show it on the bottom bar, run it when Obsidian starts, show its exit code when it terminates, and choose an icon. A registered script is started by clicking its icon on the bottom bar or through a Run script command that lists the scripts with a search box, and the script's output is shown as Obsidian notices. The README also shows passing an argument to a script, using a vault backup script as its example.
