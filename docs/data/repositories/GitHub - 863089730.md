# justanotherjurastudent/Jura-Links

The recorded German description says the plugin links legal citations in an Obsidian note — statutory provisions, court case numbers and journal references — to legal-database providers. The German README states that it was written for law students and for anyone whose notes deal with statutes, judgments and journal citations, and that it recognizes such references and links them to Dejure, Rewis.io, Buzer, LexMea and Landesrecht.online, the last as a source of state law. It also offers a search and filter window over every statute the plugin knows, which the README recommends for finding the abbreviation of a particular state law. Linking depends on the permitted citation forms: the statute is named last, and refinements such as paragraph, sentence, alternative and variant are written in the abbreviated notation the README specifies.
