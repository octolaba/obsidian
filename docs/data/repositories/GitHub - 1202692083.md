# yut0takagi/obsidian-system-recording

This plugin records macOS system audio from applications such as Zoom, Google Meet or Teams together with microphone input and saves the result into the vault, driven from a ribbon icon or the command palette, with the elapsed time shown in the status bar and a link inserted into the current note when recording stops. Capture uses ScreenCaptureKit and needs no extra driver; the README requires macOS 13.0 or later and Obsidian desktop, and states that on first use a helper binary is downloaded from the GitHub release matching the manifest version and verified against a SHA-256 hash embedded in the plugin, on Apple Silicon only. Settings cover the destination folder and a filename template. The recorded description and the README disagree about the output format: the description says M4A, the README says WAV.
