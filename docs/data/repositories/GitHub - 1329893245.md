# bobstanton/places-radar

A map provider for the Places plugin backed by Radar. It loads the selected map style with its glyphs, sprites and tiles, resolves search terms to places and coordinates, resolves a coordinate back to a place name, and builds routes between two waypoints with one request per leg. Search, reverse geocoding and routing come from the Radar SDK, the GL map is supplied by its maps plugin on top of maplibre-gl and the shared Places implementation, and no background tasks run.
