# m3hransh/glassmind-obsidian-theme

m3hransh/glassmind-obsidian-theme holds Glassmind, a frosted glass theme for Obsidian based on the Catppuccin Mocha dark and Latte light palettes. Its transparent backgrounds are designed for compositor-based blur, and the README gives a Hyprland decoration snippet as an example while noting that without compositor blur the theme still renders as a clean dark or light theme with semi-transparent panels.
