# mwoz123/swiss-army-knife-obsidian

This plugin is a collection of small command palette utilities for Obsidian. The recorded commands replace runs of duplicated empty lines with a single one, remove empty lines entirely, create an expandable and collapsable section, download a tagged plugin version, and scroll the page up or down — the last of these motivated in the README by phones that have additional keys.
