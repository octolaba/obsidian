# afanos/notes-to-html-pages

Notes to HTML Pages exports one note or a whole folder as self-contained HTML built for long-form reading, with styles and local images written into the page so it opens offline. Exported pages carry a clickable table of contents, responsive navigation, readable tables, callouts, code blocks and ASCII diagrams, offer two reading styles, and take a custom font and text size from the settings. Selected text can be underlined and annotated while reading, with annotations synced back to the source Markdown note, and exported files can be opened directly from the Obsidian file explorer. The description and README are bilingual English and Chinese.
