# davidbreece/obsidian-see-also-sidebar

See Also Sidebar reads a see-also property from the frontmatter of the active note and renders the related notes it names in a dedicated sidebar panel. The README states that several formats of that property are accepted, that clicking resolves to an existing file before opening and never creates a note, and that related notes can optionally open in a new tab. An optional automatic-suggestions feature, disabled by default, additionally reads the list of Markdown files in the vault to find notes sharing tags, with an excluded-tags list to keep high-volume tags such as daily notes out and an optional grouped display; the README states that all of this processing is local. The recorded version is 1.4.0 with a minimum Obsidian version of 1.8.0.
