# CodyBontecou/health-md-visualizations

Health.md Visualizations is an Obsidian plugin that renders Apple Health data held in the vault as interactive canvas charts from a fenced health-viz code block placed in any note, including a daily note. The README records supported data formats of JSON, CSV, Markdown frontmatter and Obsidian Bases YAML frontmatter, read from a configurable data folder that defaults to Health. Folder structure settings record a flat default plus year, month, week and day nesting or a custom path template using date variables. An insertion command opens a wizard that picks a visualization category and type and fills in a date range, renderer options and an optional size before inserting the block at the cursor.
