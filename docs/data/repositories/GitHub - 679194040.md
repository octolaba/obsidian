# wudanyang6/obsidian-things3-today

This repository holds the Things3 Today plugin, which shows the Today list of the Things3 application inside an Obsidian pane. The README records a sidebar button that opens the pane, a checkbox that marks a task complete in Things3, a refresh button, and an automatic refresh of the list every 30 seconds. It states that Things3 must be installed and running on a Mac, that a permission prompt may appear which has to be allowed before the plugin can update tasks, and that the current version requires no additional configuration.
