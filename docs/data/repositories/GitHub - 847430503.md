# chasebank87/mesh-ai

Mesh AI emulates the Fabric tool's functionality inside an Obsidian vault, running text-processing patterns over the active note, the clipboard or Tavily search results. Patterns can run sequentially, each one's output feeding the next, or in a stitch mode that outputs the results of every pattern together; YouTube links are detected and their transcripts fetched as input. Patterns can be downloaded from the Fabric repository or kept in a custom folder, and workflows created in the settings become command palette items. The README lists OpenAI, Google, Microsoft, Anthropic, Groq and Ollama as integrations, and records that only Groq, OpenAI and Ollama have been tested so far, with the others under development.
