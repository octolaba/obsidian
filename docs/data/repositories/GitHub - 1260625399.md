# Artieficr/link-link

Obsidian plugin that finds semantically similar notes and lists them in a live side panel that updates as notes are switched. Results are ranked by a similarity score between 0 and 1 and carry a colour-coded marker for the strength of the match; a result can be opened, dragged into the editor to paste a link, or added to or removed from the note's related property from a single control. A graph view shows the same information in Obsidian's own style, clustering connected notes around the current one and leaving semantically similar but unconnected notes at the edges, and one command connects the whole vault in a batch. The README states that no cloud service or subscription is involved and that no data leaves the machine.
