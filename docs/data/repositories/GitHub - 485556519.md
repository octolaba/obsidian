# therden/packrat

Packrat processes the completed instances of recurring tasks that the Obsidian Tasks plugin leaves behind in a note. The README explains that Tasks inserts the next instance of a recurring task above or below the one just completed, so completed instances accumulate in the originating note, and it sorts them into three dispositions: delete them, relocate them to the bottom of the same note, or move them into a separate archival note. A command carries out that processing, and from version 1.1.1 the plugin recognises both the emoji notation of Tasks and Dataview-format inline fields.
