# diego-vicente/obsidian-letterboxd-mirror-plugin

Obsidian plugin that mirrors a Letterboxd diary into a vault, creating one note per viewing and able to batch-import the history from Letterboxd's exported data. An optional TMDB integration adds further notes carrying extended information for each film. Note templates are written with the Eta templating engine, the plugin can auto-sync on Obsidian startup, and a username in the settings plus the ribbon's clapperboard icon are enough to start.
