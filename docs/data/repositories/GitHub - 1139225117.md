# nhiwentwest/live-columns

Obsidian plugin that lets editable multi-column layouts be created directly in notes. Columns are inserted, written into and styled in Live Preview rather than in Source mode or as hand-written code blocks, with commands for two-column, three-column and full-width sections reached from an icon in the left ribbon. Background and border colours can be set per column.
