# kaiiiz/obsidian-raindrop-highlights-plugin

The repository holds an unofficial community plugin that synchronizes Raindrop.io highlights and annotations into an Obsidian vault, annotations being available to subscribers of that service. Its README records nested collections and collection groups, synchronisation of bookmark deletions, a choice of which collections to sync with newly created ones optionally picked up automatically, and support for that service's advanced search operators to narrow what is pulled. Existing files can be updated in two modes, appending new highlights to the end or overwriting the file with the latest highlights and metadata, and the content, front matter and filename are all shaped by Nunjucks templates.
