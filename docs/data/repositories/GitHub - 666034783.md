# seanlowe/obsidian-timelines

Timelines (Revamped) generates a chronological timeline whose events are the notes carrying a specified tag or combination of tags. The README describes both vertical and horizontal timelines, custom date formatting for the vertical one, connections drawn between events through a points-to property, and timeline groups and subgroups, and it points to a hosted documentation site and to a changelog recording breaking changes. It is a continuation of an earlier timelines plugin, whose releases are noted as remaining in the original repository.
