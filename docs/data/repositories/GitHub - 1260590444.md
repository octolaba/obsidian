# nbost130/deepfield

Deepfield is a dark and light sci-fi editorial Obsidian theme named for the Hubble Deep Field, with tracked monospace section headers, square corners throughout and a single blue accent running through links, borders and code. It offers twenty colour palettes switchable live, eight of which the README says are derived from real planetary spectral data, and those accents carry into both modes. Tags render as bracketed hash markers and each task state gets its own glyph and colour. The Style Settings plugin is required for the palette switcher, the custom callout components come from a separate CSS snippet shipped in the repository, and the theme is built on the Minimal theme's variable system while also working standalone.
