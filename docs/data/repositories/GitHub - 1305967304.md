# ninsuhnrey/mac-autocorrect

This repository holds an Obsidian plugin that brings native macOS autocorrect into the editor, together with capitalization, the double-space period and the system's own text replacements. The README states that when a word is finished the plugin asks macOS through a small background helper what it would have autocorrected that word to, then swaps the word in with a brief highlight, answering only when the system is confident and respecting words taught through Learn Spelling. A single undo reverses a correction, a revert command restores the original word and stops correcting it for the session, a permanent ignore list lives in the settings, and code, math, links, tags, URLs, frontmatter and capitalized or camel-case words are skipped.
