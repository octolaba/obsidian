# gvorbeck/Nostromo

Nostromo is an 80s retro-futuristic Obsidian theme with muted amber and green terminal colours, presented as space-age note-taking without the eye strain. It uses the VT323 and Share Tech Mono fonts, scanline and screen-flicker CRT effects, glowing text, cassette-futurism scrollbars and block-character heading prefixes. A persistent status indicator in the bottom-left corner reports system status, a recording marker and terminal version information.
