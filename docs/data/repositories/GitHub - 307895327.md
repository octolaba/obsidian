# mrjackphil/obsidian-text-expand

Text expand is an Obsidian plugin that runs a search through Obsidian's own search functionality and pastes the result back into the note. A search request is wrapped in an expander code block, whose first line is the query, and running the expand command searches, waits a configurable time for the search panel to fill, and writes the results below the block. The output is shaped by a template: the eta engine exposes an object giving access to the current file and to the files found in the search panel and their fields, and an older sequence-based engine is kept as legacy.
