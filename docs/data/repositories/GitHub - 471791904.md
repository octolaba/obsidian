# Ellpeck/ObsidianCustomFrames

Obsidian plugin that turns web apps into panes using iframes with custom styling, shipping presets for Google Keep, Todoist and others. Frames are added in its settings from a preset or as a custom entry, opened as a pane with its own command, and can carry custom CSS, a ribbon icon or a position in the centre of the editor. A code block syntax also renders a frame inside a Markdown document in Live Preview and Reading mode, optionally with style settings such as height and a suffix appended to the frame's regular URL. The README notes that Obsidian Mobile does not run on Electron, which is what makes iframes and webviews available.
