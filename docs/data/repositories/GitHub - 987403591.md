# bellebasso/Minimalists-Paradise

Minimalist's Paradise is described as a minimal but not too simple Obsidian theme whose main attraction is a card layout with features customizable through the Style Settings plugin. Its README records inspiration from AnuPpuccin and Border, safari tabs derived from a named snippet that match the colour accent, and colored headers that can be enabled or disabled with preset options or defined by the user. The README warns that some things are not completely optimized for light mode, naming dataview table styling and custom callouts, while markdown tables, blockquotes and citations work as expected.
