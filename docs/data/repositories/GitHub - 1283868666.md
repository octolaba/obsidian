# jagajaga/obsidian-maps-timeline

Maps Timeline displays Google Maps Timeline location history on an interactive map inside Obsidian, covering visits, movement routes and recorded GPS tracks. The README describes a two-pane view pairing the map with a clickable timeline of the period, day, week, month and custom range pickers, flights drawn as a dashed line, and canvas rendering for dense data. Basemaps come from OpenStreetMap or Esri without a key or from Google with the user's own key, coordinate-only visits can be named through the Places API and cached locally, and the README states that the data never leaves the machine.
