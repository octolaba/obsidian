# bhagyas/obsidian-postfix-plugin

This plugin substitutes a pattern into the current line when a postfix is typed after the text, formatting what was written without going back to the start of the line. The README lists templates for heading levels one to three, unordered list items with either a dash or a plus, a blockquote, and complete or incomplete task list items: the text is typed, then a dot and the corresponding symbol, and pressing space rewrites the line with that Markdown formatting in front.
