# Charette-AI-Group/html-font-toolbar

HTML Font Toolbar applies selected-text formatting as one inline HTML span, combining color, highlight, font size and family, bold, italic, underline, or strikethrough without nested wrappers. Its context-aware controls also handle symbols, paragraph indentation, table alignment, and image aliases, while edits can merge with or repair existing spans and remain ordinary note markup if the plugin is removed.
