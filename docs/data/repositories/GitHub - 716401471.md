# hideakitai/obsidian-vim-im-control

Vim IM Control runs a command to change the system input method whenever Obsidian's Vim mode leaves or enters insert mode, on macOS, Windows and Linux. Four settings are configured per platform: the path to the input-method controller, the command run on leaving insert mode, the command run on entering it, and a command that reports the current input method so the earlier state can be restored — and if either of the last two is left blank, the enter-insert step is skipped. The README gives defaults built on im-select for macOS and Windows and fcitx5-remote for Linux, with fcitx-remote as an alternative, while stating that any input-method controller may be used, and it asks for Obsidian to be restarted after installation.
