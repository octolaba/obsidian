# juppinger0/obsidian-people-tree

People Tree renders the people recorded in a vault's Markdown notes as an interactive family tree, org chart, timeline or searchable list, reading each person from YAML frontmatter. Cards can be dragged and repositioned, notes dropped onto the board become people, and avatars can be uploaded or pointed at a file already in the vault. Editing a field in the view writes back to the note's frontmatter immediately, and renaming a person renames the file. The README states that the plugin requires Obsidian 1.7.0 or later, works on desktop and mobile, and uses no external services.
