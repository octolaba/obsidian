# eth-p/obsidian-callout-manager

Creates and configures Obsidian callouts. The README lists browsing the list of available callouts, changing an existing callout's colors and icon, creating custom callouts, and automatic detection of callouts that snippets and themes introduce. It states that mobile Obsidian is supported and that a plugin API is published for other plugins to integrate with.
