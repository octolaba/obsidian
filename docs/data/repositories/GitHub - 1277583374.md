# sunxuecong/Sunflex

Sunflex adapts the Sunflex color scheme to Obsidian's native CSS variables so it can be used as a standalone theme, building on the Minimal theme's interface layer; the recorded repository description instead calls it a plugin. It supports light and dark modes, includes a true-black dark variant enabled by a minimal-dark-black or black class, and carries a full eight-color semantic palette of red, orange, yellow, green, cyan, blue, purple and pink. The README documents installation from the community themes browser or manually, and states compatibility with the Style Settings plugin for tweaking colors, fonts and features without editing CSS.
