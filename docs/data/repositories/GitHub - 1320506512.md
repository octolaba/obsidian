# ZHYX91/obsidian-link-integrity

A read-only diagnostic sidebar with two tabs: broken internal links, gathered from Markdown, embeds, frontmatter, Canvas and explicit Bases references down to missing headings and block ids, and files with no valid link to or from another existing file. Self-links and external URLs do not count as connections; an isolated file that itself contains broken links is marked lower confidence, and periodic notes, templates and archives can be routed into an expected-isolated projection rather than presented as cleanup candidates. Candidates can be filtered by file kind, from notes to images, audio, video and PDF, and selecting a diagnostic opens it at its source. The index rebuilds a full baseline when needed and then updates incrementally; it requires Obsidian 1.12.7 or later, examines only the current vault, and checks no external websites.
