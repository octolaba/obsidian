# panAtGitHub/anki-helper

Obsidian plugin that supplements obsidian_to_anki for a workflow in which headings are questions and the text below them is the answer. It inserts a target deck into the note body or its YAML, adds heading-level backlinks so review can jump back to the card location, strips configured characters from card titles, and tidies blank lines around lists. Cloze markers such as `==` are converted to and from `{{cN::...}}` numbering, either appearing together or in sequence. Scope is set by include or exclude paths, a timed batch pass can run at fixed intervals, and the settings interface and a regexp helper for obsidian_to_anki are offered in Chinese and English.
