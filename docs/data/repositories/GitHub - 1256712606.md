# London-Chen/no-paste

This repository holds No Paste, a minimal Obsidian plugin that blocks paste actions in Markdown editors while it is enabled; the repository records no description, so this summary follows the README alone. It shows a short notice when pasted text is rejected and adds no commands, ribbon buttons, context-menu items or settings. The README is explicit about the limits: it is not an originality detector, AI detector or anti-cheat system, and it does not claim to block every way of inserting text, such as file imports, sync, drag-and-drop, external automation, plugin APIs or edits made outside Obsidian.
