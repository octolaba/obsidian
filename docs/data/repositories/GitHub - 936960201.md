# codingthings-com/tidit-obsidian

tidit inserts timestamps into an Obsidian document as it is typed. The README records a command reachable from the command menu that inserts a timestamp at the current cursor position, and a customizable datetime format, pointing at the Day.js display format documentation for the valid format options. Beyond installing the plugin and adjusting that format, it documents no further behaviour.
