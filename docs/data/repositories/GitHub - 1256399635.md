# walktalkmeditate/pilgrim-obsidian

Imports a `.pilgrim` export from the Pilgrim walking app and turns each walk into a Markdown note whose body is the transcribed voice reflection, so that text lives in the vault as searchable, linkable prose. Notes are created in a folder of the reader's choice and carry frontmatter for date, distance, duration, pace, steps, intention, reflection word count, celestial keys and provenance, every key namespaced so it cannot collide with the reader's own properties. Sections hold the reflections in order and marked where AI-enhanced, labelled waypoints as wiki links with how far into the walk each was dropped, walk statistics, a timeline of activities and pauses, sky and weather data when the export carries it, and photos. An interactive route map is drawn only when a Mapbox token is supplied, and the README describes the import itself as manual.
