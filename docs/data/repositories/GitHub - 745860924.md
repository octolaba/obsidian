# DonkeyPacific/obsidian-full-screen-cross-platform-plugin

This repository holds Fullscreen Toggle, described upstream as a fullscreen toggle plugin across all platforms for Obsidian. The README says the aim is more display space when reading notes, particularly on mobile devices, and that fullscreen is toggled by a double click or touch, configurable to triple, or by a Full screen command. A setting restricts the toggle to the command and hotkey alone, for users who trigger it accidentally with the mouse.
