# Kageetai/obsidian-voicenote-image-migrator-plugin

Voicenote Image Migrator moves image embeds out of Voicenotes notes and into daily notes that already exist. For each voicenote it reads the recorded date, resolves the matching daily note through Obsidian's Daily Notes configuration, copies the images listed under the note's Attachments heading into an attachments folder beside the daily note, inserts the original embeds just after the daily note frontmatter, and removes the source section only once the migration has succeeded. It never creates daily notes, blocks any voicenote whose date, daily note, source image or destination is unavailable, deduplicates by filename, and verifies copied bytes before changing anything. It runs only from the command palette, with a dry run that reports the plan, a confirmed run, optional backup files and a migration report.
