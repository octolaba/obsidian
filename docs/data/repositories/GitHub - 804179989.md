# patsh90/mpv-obsidian-plugin

This repository holds an Obsidian plugin that creates buttons linking to local video files and opens them in mpv at a saved timestamp, so mpv must already be installed. Links are stored in fenced code blocks tagged mpv_link, holding an identifier, the video keyword, a path relative to the vault root or absolute, and a playback position in hours, minutes and seconds that is updated automatically each time the video is closed, or fixed permanently when marked with a trailing hash. Commands add a link, move to the next or previous one, open the selected one, clean dead links and relocalize links, none of them bound to a hotkey by default.
