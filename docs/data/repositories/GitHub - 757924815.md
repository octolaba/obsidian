# jrabmer/obsidian-to-gitlab-wiki

This repository holds the Obsidian Gitlab Wiki Converter, whose README describes exporting a whole vault as a GitLab wiki. The conversion replaces spaces in file names with hyphens to match GitLab page slugs, renames a chosen file to home so it becomes the starting page, and strips Markdown file endings from links so GitLab treats the targets as wiki pages, writing the result into a configured export folder. The README states that renaming is temporary and no permanent change is made to the vault, and that the vault is expected to use relative paths rather than wikilinks. No upstream repository description is recorded, so this body rests on the README alone.
