# moszinet/mail2note-obsidian-plugin

A plugin that pulls emails forwarded to a personal mail2note address into the vault as Markdown notes, together with their attachments. It is configured with an API key from the mail2note dashboard, a target folder, a poll interval, an attachment folder choice and a filename template accepting date, subject and message-id placeholders, and a sync can also be triggered from the ribbon icon or the command palette. The README's privacy section states that the plugin contacts only mail2note.com, writes only into the configured vault folder, never logs or shares the key or note contents, and collects no telemetry; that is recorded here as the project's own claim.
