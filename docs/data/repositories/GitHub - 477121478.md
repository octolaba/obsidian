# dalcantara7/obsidian-auto-moc

Obsidian plugin that collects links back into a map-of-content note, addressing notes that link to it or share a tag or alias but were never listed there. Three commands import missing linked mentions matching the current file's name, notes carrying a tag chosen from a modal, and notes matching an alias defined in a note's properties, each inserted at the cursor position in the active note. The README states frontmatter tags are supported and that the ribbon button can be disabled while the commands stay available from the command palette or a mapped hotkey.
