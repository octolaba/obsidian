# crishood/pdf-folder-to-markdowns

PDF Folder to Markdowns converts every PDF in a chosen folder into its own Markdown file that embeds the corresponding PDF, started from the right-click menu on a folder. The README gives migrating PDF notes from other apps and organising reference material inside Obsidian as the intended uses. Settings decide whether the input folder is renamed with a configurable suffix after conversion, whether the PDFs are moved according to the vault's attachment preferences with the notes stored beside them, and whether a template is applied to each generated note, preferring the Templater plugin when it is available and falling back to the core Templates plugin.
