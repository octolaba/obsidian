# Talal-A/obsidian-immich

Inserts images from a self-hosted Immich instance into notes, listing the contents of one shared Immich album and adding one or several selected images in a single action. Setup requires the Immich URL, an API key with server and album read permissions, the album UUID and the album's link-share key, all entered in the plugin settings, with a test-connection button to confirm them. The README warns that the album share key should be kept private, since posting it makes that album public wherever the Immich instance itself is publicly accessible.
