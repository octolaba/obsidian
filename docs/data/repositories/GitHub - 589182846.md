# LordGrimmauld/aw-watcher-obsidian

ActivityWatch watcher packaged as an Obsidian plugin, reporting user activity in vaults where it is enabled. It tracks the name of the vault and the name of the currently active Markdown file, which the timeline and activity views of ActivityWatch then use to show how much time was spent on which file. The README states the collected data is sent to the ActivityWatch server running on localhost, so it does not leave the local machine by itself, and that the client code follows the official aw-client-js API.
