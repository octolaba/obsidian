# chrisgrieser/obsidian-proofreader

Proofreader sends text to a language model for proofreading and stylistic improvement and inserts the result as suggestions in the editor, additions as highlights and removals as strikethroughs, which the recorded description likens to suggested changes in word processing apps. The README states that a suggestion is accepted or rejected with a single hotkey and that no complicated plugin settings or AI parameters have to be configured, only an API key obtained. Its comparison table gives the project's own figures for English text of 10,000 words: roughly one to six cents and about five minutes, set against a professional proofreading service.
