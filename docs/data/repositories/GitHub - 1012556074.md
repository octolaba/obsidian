# YairSegel/ObsidianMinimap

Note Minimap adds a minimap panel inside the Obsidian editor pane, giving a scaled-down overview of the whole note and a draggable viewport slider for jumping through it. The README records a per-note toggle button in the pane header, live updates on scroll and content change, and settings for minimap scale, opacity, top offset and rendering method. Its better-rendering mode is documented as working around Obsidian's lazy loading by keeping a semi-hidden note open, which shows up as extra tabs the plugin manages itself.
