# ionmint/get-covers

This repository holds Get Covers, described upstream as a minimal and simple plugin for getting media covers. Its README says the plugin searches for a cover image for the note currently open and writes it into that note's cover frontmatter property, through a modal prefilled with the note title and offering search text, a suffix, a mode, a destination and a result count. Search modes include Google Images and a database mode, the result can be kept as a URL or downloaded, and the README states that one codebase serves desktop, Android and iOS. The README opens by stating that every line of it except that first one was written by an AI.
