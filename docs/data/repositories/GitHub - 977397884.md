# Treadder/move-cursor-on-startup

This repository holds a small Obsidian plugin that moves the cursor one position to the right and back to the left at startup. The README records the reason as a workaround: Dataview expressions embedded in the first note opened, such as a Home note, do not run on that first load, and the brief cursor movement makes them run. It shows the problem and the result as before-and-after examples and points to the Obsidian plugin documentation for modifying it.
