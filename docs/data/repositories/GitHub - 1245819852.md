# AlbertoOS/obsidian-rainbow-header-coloring-plugin

Rainbow Header Coloring colours Markdown headings from H1 to H6 in Obsidian, in Live Preview, Source mode and Reading view. A colormap mode assigns each heading level a distinct colour from a built-in palette — HSV rainbow, cool, warm or greyscale — with a configurable number of shades and separate font and background opacities, while a user-defined mode sets an explicit font colour, background colour and optional bold and italic per level. The README states that colour generation is built in and that the plugin has no external runtime dependencies.
