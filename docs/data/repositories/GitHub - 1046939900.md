# AlexKucera/obsidian-typst-pdf-export

This plugin exports Obsidian notes to PDF through the Typst typesetting system rather than rendering them with the current Obsidian theme. The README describes built-in and custom templates, batch export of whole folders, handling of embedded images and PDFs, embedding arbitrary files as attachments, progress reporting with cancellation, automatic system font discovery with caching, and paper size, margin and typography controls. It also records support for the YAML email block format introduced by a separate Email Block plugin, and path validation and sanitization for its file operations. The author states that the plugin grew out of a need for single-page PDFs whose page grows to fit all content without pagination breaks.
