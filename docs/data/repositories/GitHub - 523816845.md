# samepage-network/obsidian-samepage

This repository is the official Obsidian client for SamePage, described in its README as an inter-tool protocol for thought, used to connect a vault to other notebooks in order to sync changes across them and run cross-notebook queries. The README carries an explicit warning that the SamePage family of extensions is still in beta and is not considered stable for real or sensitive data, that all data shared on SamePage is considered public, and that the probability of data loss is high.
