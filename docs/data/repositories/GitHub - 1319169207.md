# natysh1011/obsidian-todolistsync

Todoist Task Notes creates one Markdown note per Todoist task, subtask and nested subtask, filed into folders that mirror the real Todoist project, and keeps title, description, labels, project, hierarchy, dates, priority, duration, recurrence and completion synchronized in both directions. Tasks can be created from Obsidian, offline creation retries idempotently, conflicting edits produce conflict copies, and user text under the Notes heading is never overwritten. A dashboard code block groups tasks by project with a collapsible tree, and the interface is available in English and Hebrew with a mirrored right-to-left layout. The API token is kept in Obsidian SecretStorage rather than in plugin data, and the first synchronization is pull-only.
