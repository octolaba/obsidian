# fengshuzi/logseq-formater

Logseq Formater converts Logseq syntax to Obsidian Markdown automatically when a Markdown file is opened. The README lists rendering Logseq block references as inline previews of the referenced block, converting `id:: block-id` into Obsidian `^block-id`, summarizing CLOCK durations under `:LOGBOOK:` and appending them to DONE tasks, and three TODO modes: preserve the original text, render it as a task checkbox in reading view without touching the source, or rewrite the markers into Markdown checkboxes, which does modify the note source.
