# code-of-chaos/ColoredTagsWrangler.obmd

Colored Tag Wrangler assigns colors to tags in Obsidian, configured tag by tag in the plugin's settings tab with a color picker, and text and background colors can optionally be decoupled so one tag carries two colors. It integrates with several other surfaces: a canvas card carrying a tag can take that tag's color, and for the Kanban plugin a card can be colored by its tag, a list colored when a tag appears in its title, and the leading `#` omitted in the Kanban view. A folder can be colored when its folder note carries a colored tag in the file's properties; the README records a flaw, that the detect button in the settings has to be pressed by hand after such a property changes, and notes that any file named after its folder works, not one specific folder-note plugin.
