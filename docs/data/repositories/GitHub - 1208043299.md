# adrianofontanari/obsidian-focus-mode-banner

Focus Mode Banner is an Obsidian plugin that helps stay anchored to one note: while focus mode is on, opening any note other than the one the session started from shows a warning banner at the top of the editor. Focus mode is toggled from a ribbon icon, which turns red while active, or from the command palette, and the banner can be dismissed manually or left to disappear after a configurable number of seconds. Settings hold the banner text and the auto-dismiss delay, where zero disables automatic dismissal. The author describes the plugin as vibe coded.
