# iamzay/obsidian-zhihu-reader

This repository holds Zhihu Reader, an unofficial Obsidian plugin that renders Zhihu questions and answers through Obsidian's Markdown renderer in a native reader view. It searches answers, browses personalized recommendations and the daily hot list, keeps a local history of opened questions, reads comments, opens an author's public answers and votes on an answer, with keyboard shortcuts for moving between answers and scrolling. A chosen answer is saved as one Markdown file under a configurable folder and path template, optionally downloading its images, and settings control answers per request, feed order and history size. The README states that the project is not affiliated with Zhihu and that changes to Zhihu's APIs, authentication or risk-control systems may affect features.
