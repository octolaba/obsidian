# davidszp/obsidian-active-note

Obsidian plugin that externalises which note is currently open, writing the vault-relative path and any text selection to a JSON pointer file, by default `.obsidian/active-note.json`. The `path` key is always present, while a `selection` object appears only when text is selected and carries the selected text with 1-indexed start and end lines. The README frames the problem as the active note being UI state that scripts, CLI assistants and other external processes cannot see, and it supplies copy-pasteable instructions and a status-bar snippet for wiring the pointer file into Claude Code.
