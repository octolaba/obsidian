# JamesCliffordSpratt/obsidian-habits

Habits stores each habit as a Markdown note and provides dashboard and sidebar views for logging done, counted, or timed activities. It supports daily and recurring schedules, streaks, heatmaps, charts, weekly or monthly goals, pauses that preserve streaks, comments with tags and links, and printable PDF reports, with optional experimental summaries.
