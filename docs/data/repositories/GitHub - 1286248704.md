# JamesCliffordSpratt/obsidian-habits

Habits tracks daily habits as plain Markdown notes in the vault, logged from a carousel dashboard rendered by a `habits` code block or from a sidebar quick-log panel. A habit is done/not-done, counted or timed, at a daily, weekly or monthly frequency, and the plugin reports current and best streaks, completion rates, perfect days, goals and heatmaps, with 30-day and 12-week charts on each habit page and printable PDF reports over a chosen date range and layout. Days can be paused without breaking a streak or dragging down the statistics, per-day comments can be attached to any card, and a dashboard placed in a daily note shows that day's habits. The README marks bad-habit tracking against a daily limit and AI summaries through the user's own AI service as experimental, and lists seven interface languages.
