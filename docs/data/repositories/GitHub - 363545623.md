# mjessome/obsidian-global-hotkeys

The repository holds Global Hotkeys for Obsidian, a plugin that adds system-wide keyboard shortcuts. Its README records that any Obsidian command can be mapped, that every such command brings Obsidian to the front, and that two extra commands are added for bringing the window forward and for showing or hiding it. Key combinations are entered in the plugin's settings following the Electron accelerator syntax.
