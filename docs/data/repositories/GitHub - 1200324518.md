# MrParalloid/nu-ayu

Nu Ayu is a minimal Obsidian theme built around restraint, with rounded surfaces, transparent dividers, a muted text palette and most borders, hover effects, highlights and box-shadows removed. Light mode follows the Ayu tradition of warm off-whites with purple-grey text, while dark mode is original, using deep violet-tinged backgrounds with a warm orange accent and an optional full-black background for mobile devices. The README describes mobile-specific work such as bigger tap areas, reduced animations, full-size sidebars on phones and padding for Bases embeds, plus custom callout and code-block colours and de-animated Dataview embeds and task lists.
