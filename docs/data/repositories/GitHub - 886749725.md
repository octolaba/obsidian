# sedationh/obsidian-instant-above-divider

The README describes an Obsidian plugin whose command inserts a divider line at the beginning of the current note and moves the cursor there, placing the divider after the frontmatter when one is present and optionally respecting headings. A second command opens a document outline that lists the note's headings in their hierarchy together with its dividers, each divider shown with the first N characters of the content that follows it, configurable and ten by default. Clicking an entry in the outline navigates to that section, and the README suggests binding both commands to hotkeys.
