# alexsussy/obsidian-doodle

Doodle adds a 1024 by 1024 bitmap drawing canvas to Obsidian, created from the command palette; clicking on the canvas starts drawing and clicking outside it stops. Drawings are saved as PNG files in a doodles folder whose name can be changed in settings. The README describes a brush size slider, an undo button and colours from the Flexoki palette.
