# br4in/calloutX

Views, manages and customises the callout icons defined in a vault's own CSS. The README states that the plugin reads custom callout definitions from a named CSS file in the snippets folder, importing it from the plugin folder when it does not exist, and shows every icon it finds with its name in a modal opened from the command palette. Callouts can be added with a name, colour and icon, edited, deleted and searched, either in that modal or in the plugin settings tab. The README says the plugin works on desktop versions of Obsidian.
