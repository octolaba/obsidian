# Micha12323/lifeweeks-obsidian

Renders a Life in Weeks grid over the weekly and daily notes in the vault, where each cell is one week and clicking it opens or creates the matching note. A first-run screen asks for a birth date, a life expectancy in years that sets the number of rows, and a base folder holding the weekly and daily subfolders; tabs are detected from the weekly subfolders, so several timelines can run side by side, each with its own legend. Cells can be given colors and titles, edited in bulk through multi-select or a date range, and long-pressed for a day view, while zoom works through a slider, Ctrl with the wheel, or pinch. Notes stay plain Markdown whose frontmatter is written through processFrontMatter so other keys are untouched, filenames follow a date-and-week pattern, and the same build runs on desktop and mobile.
