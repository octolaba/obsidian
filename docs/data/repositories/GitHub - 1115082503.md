# Eonfuzz/stormlight-actions

Stormlight Action Icons replaces inline code tokens of the form strm: followed by a letter or digit with a styled action-icon widget, both in reading mode and in the live-preview CodeMirror editor. The README lists eight case-insensitive tokens covering reaction, opportunity, complication, one, two and three actions, free and unlimited, and explains that the design keeps the note's text simple and searchable while the glyphs are drawn with CSS. It credits a Pathfinder 2e action-icons plugin as the base for its code.
