# GodlyMan-bit/SoliDeoGloria

Soli Deo Gloria is an Obsidian theme whose Latin name translates as glory to God alone. It takes inspiration from old German bibles and Gothic calligraphy, aiming to bring the detail and flowing script of illuminated manuscripts into a modern format while keeping a clean, uncluttered interface that prioritizes readability. The fonts are Germania-One and Cormorant Garamond, and the README lists primary, secondary and tertiary colours for each of the light and dark themes. Its author notes that this is only their second Obsidian theme and that all code and images are under CC BY-SA 4.0.
