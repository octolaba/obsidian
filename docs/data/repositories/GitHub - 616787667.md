# KeithLerner/ObsidianMDsQdthOne

sQdthOne is an Obsidian MD theme with light and dark modes that its author uses daily and updates as new Obsidian features arrive. It is listed as compatible with the Style Settings and Calendar plugins, and its version history names colourless and solar variants beside the default. That history, which starts at 1.8.0, records a move to HSL colours with modified saturation for longer sessions, special checklist icons, checkboxes reworked to use Style Settings in line with a wider standardisation effort, and adjustments to menu borders and list indentation bars.
