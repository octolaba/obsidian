# jkvetina/obsidian-one-oracle-developer

One Oracle Developer is an Obsidian theme built on top of the Baseline theme, tuned for long-form technical writing, tight note taxonomies and daily use by a developer. The README lists what it changes: Source Serif Pro headings on a fixed H1 to H6 scale at weight 500, the properties block hidden in both Live Preview and Reading view, em-dash list bullets instead of dots, grey strikethrough with struck bold forced back to weight 400, and accent-coloured tag pills that stay legible inside completed tasks. Its author states that Baseline was already close and that the tweaks target lists, checklists, tags, headers, fonts and the file tree.
