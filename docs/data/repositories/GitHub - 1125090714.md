# trinitytime/knox-sync-plugin

Knox Sync synchronizes Obsidian documents and files through the Knox portal, using it as backup storage across devices and allowing documents to be shared with other users through Knox's own sharing feature. Synchronization runs at regular intervals and after a set period without edits, and stored Knox documents are refreshed monthly so that they are not deleted. Setup requires a Knox to-do project whose name begins with a plus sign, auto login in other browsers enabled, and a sync start command from the palette. The README states that the plugin collects and transmits no information, warns that conflicts resolve as last write wins and that oversized files may fail to synchronize, and places responsibility for any problems on the user.
