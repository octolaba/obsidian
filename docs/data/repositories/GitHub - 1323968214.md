# miaoziguan/obsidian-chinese-plugin-market

Chinese Market is a search and translation front end for Obsidian's community plugin directory aimed at Chinese-speaking users. Plugin names, descriptions and feature notes are shown translated into Chinese, and three search modes are offered: keyword search over Chinese name, original name and author, on-device vector search that runs offline without an API key, and an AI mode that ranks results from a natural-language description. Results can be filtered by source, category, author and installation state, and several similar plugins can be placed side by side in a comparison mode with AI analysis. On macOS desktop it can call the system translation service to render a plugin README in Chinese, and plugins can be bookmarked or found through editor picks.
