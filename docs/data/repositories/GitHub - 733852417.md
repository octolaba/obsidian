# MateusMolina/obsidian-git-file-explorer

This repository holds Git File Explorer, whose README describes bringing Git status into Obsidian's file explorer. A widget beside each detected repository shows the number of changed files and, when clicked, asks for a commit message and then stages and commits everything in one commit, optionally with an automatically generated timestamped message; a second widget shows the commits waiting to be pulled and pushed and, when clicked, pulls without rebasing and then pushes, with optional automatic sync on startup or on a configurable interval. The README also lists a context-menu entry that opens the system Git diff tool for a file or folder, and customizable highlighting of changed files. No upstream repository description is recorded, so this body rests on the README alone.
