# Ayano7an/Firthian-Notion-of-Collocation

The recorded description calls this habitual co-occurrence mining. The README describes an interactive linguistic visualization kit for a vault: a draggable 3D sphere of the most frequent collocate words, a hover panel listing a node's collocates within a sliding window of plus or minus N tokens, and a keyword-in-context view opened by clicking a collocate, with the partner word highlighted and note cards jumping to the source text. Analysis can be restricted to notes modified in the last 7 days, 30 days, 6 months or year. The README states that it is not available on mobile, that its stopword lists come from a third party and can be turned off for smaller vaults, and that the program is forked from another project.
