# leonjacobs-collab/obsidian-terminal-theme

Obsiddy-In Terminal is a retrofuturistic Obsidian theme described as amber on dark, IBM Plex Mono, CRT warmth. It offers dark and light modes, a CRT scanline overlay and vignette effect that are disabled on mobile, amber accents across headings, tags, links, buttons and graph view, and custom styling for blockquotes, code blocks, tables, callouts and properties. The README presents it as the companion to Obsiddy In, a browser-based vault homepage sharing the same design language, and licenses it under MIT.
