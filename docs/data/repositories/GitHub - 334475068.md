# MSzturc/obsidian-better-pdf-plugin

Better PDF states its goal as a native PDF handling workflow inside Obsidian, embedding pages of a PDF into a note through a configuration block. A block names the PDF by path or wikilink and can insert a single page, a list of pages or an inclusive range, optionally hyperlinked, with `page = 0` standing for the whole document. Further options scale a page, fit it to the note layout, rotate it by 90, -90 or 180 degrees, and cut out a rectangular region given as pixel offsets and sizes; the README also links a third-party script that generates these blocks from Adobe Acrobat Pro or Skim.
