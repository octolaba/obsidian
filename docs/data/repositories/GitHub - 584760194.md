# hedonihilist/obsidian-habit-calendar

This plugin renders a monthly habit calendar inside a DataviewJS code block, showing the status of each habit across a month. The data can come from a Dataview table whose first column is the file link and whose remaining columns are habits, or from manually collected data handed to `renderHabitCalendar`. A habit label can be set from the part of the column header after the last vertical bar, a daily-note naming pattern other than `YYYY-MM-DD` can be supplied so entries link to the right note, and cells can be filled with HTML. The README states that the plugin is based on the Habit Track plugin by duoani.
