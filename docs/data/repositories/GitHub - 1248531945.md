# wesswart77/obsidian-project-manager

Project Manager tracks projects in Obsidian through status, milestones, tasks and progress, presented in a kanban-style sidebar whose columns are the planning, active, on hold and complete statuses and whose cards show a priority badge, a milestone count and a progress bar. Commands create a project with a name, status, due date, priority and description, attach a milestone with its own due date, log a progress update that sets a completion percentage, and archive a project by moving its note into an archive subfolder. The projects folder is configured in settings, and the panel opens from a ribbon icon.
