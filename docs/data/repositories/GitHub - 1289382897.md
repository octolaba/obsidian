# yun-lun-li/Obsidian-TasksPlugin

TaskManagement stores each task as an ordinary Markdown note with frontmatter and presents those notes as a kanban board and as day, week and month timelines, both built as custom Obsidian Bases views. Dragging a card between status columns rewrites its frontmatter; the built-in backlog, nextup, ongoing and done statuses can be renamed, reordered, added to or removed, and a completion date is set when a task reaches done and cleared when it leaves. Cards show priority, date ranges, project and feature links and checklist progress, and tasks can be sorted, filtered with nested AND/OR groups, and extended with custom text, number, date, select and checkbox fields. Task, project and view files live under a TaskManagement folder, and the plugin requires Obsidian 1.10.0 or later with the Bases core plugin enabled.
