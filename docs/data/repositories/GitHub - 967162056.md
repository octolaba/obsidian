# maigamo/Daily-Task-Auto-Generator

Repository for Daily Task Auto Generator, an Obsidian plugin that creates daily task notes from a customisable template. Generation is set to none, every day, or workdays only, files are organised under a configurable root directory, and template variables cover the date, a date with a calendar icon, the weekday, year and month progress percentages, and the current time. The README also lists statistics reporting the previous day's completion rate, documentation in English, Chinese and Japanese with English and Chinese interfaces, and use on both desktop and mobile Obsidian.
