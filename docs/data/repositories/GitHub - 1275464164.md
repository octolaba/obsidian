# Cosmakes/DnDJay

Repository for DnDJay, a tabletop console that runs in an Obsidian pane with two tabs. The Music tab is described as a four-channel Web Audio mixer with live meters, a twelve-pad sound palette with named loadouts for looping beds and one-shots, and a scene prepare and switch system; the Battlemap tab pairs a media library with a framing stage that the README marks as not yet established. Sounds and maps are read from the vault, and settings persist in the plugin's own data file.
