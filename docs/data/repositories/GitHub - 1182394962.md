# incantatem2/Obsidian-cranky-goblin

cranky goblin is a dark-mode-only Obsidian theme with a muted, low-contrast, moss-grey palette that its README frames through an underground dungeon setting. It applies subtle glows around code and structural elements, pixel-leaning accents, and the fonts Lower Pixel for text and PixelWarden for headings and other elements. The README records its origin as an intended small edit of the same author's deep submerge theme that quickly became separate, drawing on the PixelWarden font, retro roguelike RPGs and the dungeoncore aesthetic.
