# suka233/obsidian-kmind-zen

KMind Zen stores mind maps as kmindz files inside the Obsidian vault, so they sit in the file tree with everything else and are covered by existing sync, backup and version-control habits. Maps are created from the command palette or from the file tree context menu in a chosen folder, reopened by clicking the file, and autosaved back to that same file. Nodes carry rich text and notes, images, TODOs, icons, tags, comments, hyperlinks and relationship lines, and one map can be edited as a spatial canvas or as a continuous outline, with a split mode that drags nodes between the two. A Zen mode quiets the interface for complex maps, the format is shared with other hosts, and the README states that license activation does not upload map contents.
