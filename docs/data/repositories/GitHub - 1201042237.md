# suka233/obsidian-kmind-zen

KMind Zen stores mind maps as local .kmindz files in an Obsidian vault, where they can be created from the command palette or file tree and reopened later. It provides spatial, outline, and split editing, autosave, themes, relationship lines, import and export formats, and Zen mode for focused work.
