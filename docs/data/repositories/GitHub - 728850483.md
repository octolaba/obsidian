# gndclouds/days-since-obsidian

Repository for Days Since Date Tooltip, an Obsidian plugin that shows in a tooltip how many days have passed since a date when that date is hovered over in a note. The README states that the standard ISO format `YYYY-MM-DD` is the one recognised, and suggests the plugin for tracking project timelines, journal entries and other important dates. Installation goes through the community plugins browser, and the project is licensed under MIT.
