# n2osync/n2o-lite

N2O Sync Lite pulls Notion pages and databases into the vault as Markdown, with properties written as frontmatter and images stored on disk, and a later run updates what changed instead of dumping a second copy. The README states that it only reads from Notion, using a token the user supplies, and that it is an independent plugin neither made by nor affiliated with Notion Labs or Obsidian. Callouts, toggles, columns, code blocks, mathematics, tables, synced blocks and nested lists are recorded as converted into the equivalent Obsidian construct, and each database arrives as a folder of rows. This edition is recorded as free and limited to one hundred pages.
