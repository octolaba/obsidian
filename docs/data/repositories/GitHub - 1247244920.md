# satyagalla/Morning-OS-obsidian

This repository holds Morning OS, an Obsidian plugin that generates a daily briefing dashboard from the vault's own goals, tasks and rules. Its panel is divided into an identity strip of self-written rules, a bar of short and long-term goals, urgent and regular task sections that badge how many days each task has been carried, the rules judged most relevant to today's tasks, suggestions drawn from what has been left undone, and separate sections for hobby items and wins. The README frames it as doing the morning re-reading of those files so that the day is already laid out when the panel opens.
