# irisable/wp-publisher-for-obsidian

Publishes Obsidian notes to WordPress and synchronises changes back under review; the README describes the project as an independently maintained fork of devbean/obsidian-wordpress extended from one-way publishing into a guarded editorial workflow. Markdown is emitted as native Gutenberg blocks by default, with classic HTML output still available, and a publish carries title, slug, excerpt, categories, tags, featured image, scheduled date, comment settings and post type. Media that has not changed is reused by content hash instead of re-uploaded, content, metadata and rendered blocks can be previewed first, per-profile defaults and templates are saved, and one frozen note revision can go to several sites or through a reviewed batch. Remote WordPress changes are inspected, pulled, compared and merged explicitly, without background overwrite or last-write-wins behaviour.
