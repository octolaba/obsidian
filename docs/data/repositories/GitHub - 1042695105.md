# YazanAmmar/obsidian-theme-engine

Theme Engine edits Obsidian's appearance through a settings interface instead of hand-written CSS, exposing more than a hundred built-in Obsidian variables plus user-defined ones. Colors, CSS snippets, backgrounds including video backgrounds, and themes are grouped into profiles that can be managed from one place. The README records four built-in interface languages plus support for custom ones, and ships a set of included profiles, commands and hotkeys.
