# ununnamed/book-reader

Book Reader adds reading features to Obsidian: it remembers the scroll position of a note and shows the remaining reading time and reading progress as a percentage in the status bar in real time. A code block renders a progress bar for a book, and adding a reset keyword to that block resets the recorded progress. The README links an animated instruction for turning remaining reading time on in Obsidian mobile.
