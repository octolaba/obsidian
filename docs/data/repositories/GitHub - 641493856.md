# pvojtechovsky/obsidian-link-with-alias

Link with Alias is described as an Obsidian plugin for creating links together with an alias in the front matter of the target document. Its README lists three commands: create a link with alias, which adds the link's display text to the target note's aliases; create a link; and toggle the display text of the link being edited. Both creation commands keep the display text so that Obsidian's link autocompletion does not replace it, and the README walks through selecting existing text, adding an alias to an existing link, and creating a link from scratch. When the target note does not exist it is created, with the display text written into its front matter as an alias.
