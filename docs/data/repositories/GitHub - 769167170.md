# simsapa/simsapa-obsidian

The Simsapa plugin searches Pali dictionaries and suttas from inside Obsidian by making HTTP requests to the Simsapa Dhamma Reader application, which has to be installed and left running in the background. Clicking the plugin's book icon opens a sidebar for searching, and double-clicking a word in a note triggers a dictionary lookup whose results appear in that sidebar, or in a separate word-lookup window when the sidebar is closed. The README records that the system may prevent that window from opening, in which case it should be opened from Simsapa first and placed beside Obsidian. The repository is recorded as a sub-module of a larger extensions-and-plugins project.
