# brianling/obsidian-copy-as-rich-url

The repository holds Copy as Rich URL, an Obsidian plugin that copies the current note as a hyperlink whose anchor text is the note title and whose target is its obsidian protocol URL. It writes both an HTML flavour carrying an anchor element and a plain-text flavour to the clipboard, so rich-text editors such as FuseBase, Notion, Confluence, Slack or Gmail paste a clickable link while plain-text editors receive the title and the URL. The README contrasts this with Obsidian's built-in command, which places only the raw URL on the clipboard, and the action runs from a ribbon icon, the command palette or a hotkey.
