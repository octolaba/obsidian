# tdccccc/arxiv-daily

An Obsidian plugin, also usable as a CLI, that fetches new arXiv listings for chosen categories, uses a language model to keep the papers matching the user's topics, and writes the result as Markdown. Its outputs are a daily report per day grouped by topic with short structured summaries, optional longer per-paper notes addressed by arXiv id, and a dashboard with calendar, search, filters and stars; files live under an arxiv-daily folder alongside optional PDF downloads and a local index. It can run on a schedule while Obsidian is open or from the CLI on a machine that stays online, and the README mentions an optional email digest. The repository carries no description.
