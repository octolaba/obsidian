# al3xw/force-read-mode

This repository holds Force Read Mode, whose README describes always opening Markdown files under configured paths in reading mode, offered as a way to prevent accidental edits. Paths are given as patterns, one per line, in a glob syntax where a double asterisk matches any folder depth, a single asterisk matches within one folder level, and everything else is matched literally without escaping. The README says the check runs every time a file is opened, that files outside the configured folders are unaffected, and that the behaviour can be turned off temporarily from the command palette. No upstream repository description is recorded, so this body rests on the README alone.
