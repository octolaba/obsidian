# bartvw/entity-notes

Entity Notes creates a structured note for a person, project or idea from the line being written: tag a dangling internal link with a trigger tag such as #person, #project or #idea and click the inline button that appears, and the plugin writes a note with pre-filled YAML frontmatter, removes the tag and leaves the link resolving to it. The README states that when no dangling link precedes the tag, the whole line is converted into a link and a note of that name instead. Every link pointing at an entity note is decorated with a colored pill naming its type in Live Preview, Source mode and Reading mode; the pill takes its color and label from the type's settings and is never written into the file.
