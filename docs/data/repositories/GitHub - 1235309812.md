# Lumingtianze/obsidian-phantom-cipher

PhantomCipher encrypts an Obsidian vault transparently, intercepting low-level input and output so files are stored encrypted on disk while the editor behaves normally. Its README describes envelope encryption in which a key-encryption key wraps a data-encryption key, so a password change does not re-encrypt files, plus Deflate compression to offset the growth from Base64 encoding and a binary payload format aimed at media files, with attachments optimized up to two gigabytes. The README carries explicit cautions: the project is early-stage and its encryption architecture may change, it is not meant for high-stakes confidential data, the whole vault should be backed up before encrypting, both keys must be saved and synced across devices by hand, and a forgotten password means permanent data loss.
