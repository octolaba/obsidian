# wenlzhang/obsidian-todoist-context-bridge

Todoist Context Bridge sends selected Obsidian content to Todoist as tasks while keeping a link back to its context, instead of trying to synchronize everything between the two systems. The README describes highlighting important tasks selectively in Todoist, syncing those tasks in both directions, maintaining temporal context, and support for several content formats including lists, tasks, callouts and quotes. It also records integration with the Dataview and Tasks plugins and points to the author's separate hosted interface for chatting with Todoist tasks and calendar events.
