# myluster/Obsidian-LaTeX-Helper

Obsidian plugin that adds a LaTeX symbol panel for mathematical and scientific note-taking. Symbols are grouped into categories such as Greek letters, operators and arrows, chosen from a dropdown and filtered by a search over their LaTeX code; clicking one inserts it into the active note, adds a trailing space and returns focus to the editor. The panel can be docked in the sidebar or popped out into a floating window, its symbol library is editable as JSON in the settings, and its interface follows the Obsidian language setting for English or Chinese.
