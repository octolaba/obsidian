# BrunoJalesSousa/obsidian-tell-a-tale

Inserts five kinds of storytelling block, namely dialogue, monologue, narration, scene direction and cast change, each written into the note as an ordinary Obsidian callout that still reads as plain Markdown without the plugin. Dialogue and monologue are attributed through a fuzzy character picker; characters are discovered from vault notes carrying a configurable tag, with optional frontmatter for the display name and a hex color that tints their blocks, and an embedded image whose filename starts with a fixed prefix becomes the portrait shown beside them. Every block type has a keyboard shortcut and a right-click menu entry, and hovering a block reveals edit and delete actions. The README describes the plugin as a work in progress.
