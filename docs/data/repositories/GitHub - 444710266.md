# qawatake/obsidian-local-file-interface-plugin

The repository holds Local File Interface, an Obsidian plugin providing commands for moving files in and out of the vault. Its README records four entry points: a command importing local files from outside the vault, a command exporting vault files elsewhere on the device, an import entry in the folder menu, and an export entry in the file menu. It is written in TypeScript under the MIT license.
