# kenzan100/beeminder-obsidian-word-count

This plugin sends the word count of the current Obsidian file to a Beeminder goal through a registered command, so writing in the vault contributes to a Beeminder writing goal. The README states the command counts only the actively selected area, which the author explains as a way to avoid over-reporting when the same file is edited across several days. Three settings must be filled in: the Beeminder user name, the goal name receiving the count, and a personal authentication token.
