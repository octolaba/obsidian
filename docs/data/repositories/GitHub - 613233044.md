# ytliu74/obsidian-pseudocode

This plugin renders LaTeX-style pseudocode written inside a code block, and its README states that it is based on the pseudocode.js library, which typesets pseudocode to HTML. The recorded grammar takes LaTeX-style input supporting the algorithmic constructs of LaTeX's algorithm packages, and math formulas are inserted by enclosing an expression in the usual LaTeX math delimiters. Later releases add auto-completion inside the pseudo block, preamble and macro customization through a style file or an in-block preamble, export of a compilable LaTeX file including any required macros, and rendering that follows the Obsidian theme in light and dark modes; syntax highlighting is listed as a future feature.
