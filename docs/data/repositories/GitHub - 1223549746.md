# dsebastien/obsidian-book-exporter

Book Exporter compiles a book written across Obsidian notes into a single manuscript and exports it to EPUB and PDF through Pandoc. One manifest note acts as the table of contents: its H1 or a frontmatter title names the book, headings from H2 down define nested sections, and bullets containing wikilinks inline the linked notes in source order, while other content under a section is kept verbatim. The README states that the plugin is desktop only, requires pandoc on the path, recommends Typst as the PDF engine with LaTeX engines still supported, and refuses to export until an absolute output folder is configured. Temporary files are written to the operating system's temp directory rather than into the vault.
