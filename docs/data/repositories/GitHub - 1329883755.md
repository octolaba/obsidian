# bobstanton/places-maptiler

A map provider for the Places plugin backed by MapTiler. It loads the selected map style with its glyphs, sprites and tiles, resolves search terms to places and coordinates, reads elevation for a coordinate, and loads terrain DEM tiles for 3D relief. Styles, geocoding and the map surface come from the MapTiler SDK, with the GL engine supplied by the maplibre-gl copy that SDK pins on top of the shared Places map implementation, and no background tasks run.
