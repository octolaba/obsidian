# forrest1398/obsidian-easyTest-plugin

Obsidian plugin for self-testing on the contents of a note, which the README frames as retrieval practice. It extracts the bold text of the active editor, turns each bold passage into an input field and shows the result in a modal opened from a ribbon button or a hotkey, where answers are typed and checked as they are entered. A hint button reveals the answer for the focused field, and the settings configure the border and background colours of the input boxes through a live preview.
