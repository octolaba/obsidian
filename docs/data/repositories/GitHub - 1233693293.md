# PandaNocturne/obsidian-colorful-stickynotes

Obsidian plugin that opens draggable, stackable sticky-note windows above the vault interface, each backed by an ordinary Markdown note in a configurable folder. The README describes background color palettes stored in note frontmatter, a sticky list in grid form with filters, sorting, pinning and pagination, saved window layouts, edge snapping and auto-resize, session restore on startup and filename templates. Stickies can be dragged from that list onto Canvas to create nodes, with modifier keys choosing between embedding the content, linking to the file, and embedding while moving the original to trash.
