# wakywayne/obsidian-hotstrings

Expands trigger strings into longer text automatically as they are typed anywhere in Obsidian. Triggers and their expansions are defined in the plugin settings using a delimiter-separated format, and a command reloads them without restarting Obsidian. The README notes that triggers are case-sensitive by default and must be unique, and that the reload command should be run after adding new ones.
