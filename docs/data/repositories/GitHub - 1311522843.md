# Sargon01/Feuillets

Feuillets adds long-form writing tools to Obsidian while leaving the text as ordinary Markdown files in real folders, with no project format, narrative database or imposed method. An existing folder becomes a project of type fiction, non-fiction or free without moving or renaming its files, and the plugin adds an auxiliary directory beside them for research, resources, editing, a journal, snapshots, backups and output. As a text grows it can gain a hierarchical binder, cards and outline, a visual notebook, research and passage-aware context, storyline and timeline views, goals, statistics, a writing journal, snapshots, versions and backups. A single sheet, one folder, a selection or the whole project can be reread, composed and exported.
