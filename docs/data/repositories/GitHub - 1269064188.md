# Yuffiee/obsidian-wandlog

The repository carries no description; its README presents Wandlog as an Obsidian plugin combining a daily writing heatmap, random note discovery and task management in one sidebar view. The heatmap is a contribution-style grid whose cells show the words written that day against a configurable daily target, offered in five colour schemes and clickable to open the matching daily note. A random card shows one list item drawn from the vault at a time, opening its source file on click and offering copy and delete on right-click, while a todo tab scans configured folders for unchecked tasks, writes the completion back to the file when a checkbox is clicked, and refreshes as files change. Settings choose tracked folders, the daily target, the colour scheme, folders the random card skips, the todo folders and where items open.
