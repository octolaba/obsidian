# mesqueeb/obsidian-ai-attachmate

Obsidian plugin that transcribes PDFs, images and Canvas files into Markdown notes as soon as they appear in the vault. PDFs and images are processed by Google Gemini with a configurable prompt and output template, while Canvas files are transcribed locally and need no API key. A glob filter narrows which attachments are handled, the transcripts folder can be absolute or relative to the attachment, a sidebar panel shows what is in progress, and deleting an attachment removes its transcript. Each transcript keeps a user zone at the top that survives re-transcription, and the README notes that the Gemini free tier's daily request cap can make a first run over a large vault take hours or days.
