# Joaquim-Frances/obsidian-notelert-plugin

Notelert turns a line in a note into a reminder delivered through Android push, email, Google Calendar, Telegram, or a combination of those channels. Date and time reminders work without the companion Android application, which the README records as required only for push notifications and location reminders, and setup needs an account-linked token obtained from that application or through an email verification flow. Recurrence and location reminders are recorded as paid-plan features, above a free plan of ten reminders per month, and the settings and picker are available in six languages.
