# Jalad25/contact-note

The repository holds Contact Note, an Obsidian plugin that renders the frontmatter of notes designated as contacts into contact cards. A card is shown in reading mode for any note identified as a contact, and a dedicated sidebar view lists all contact notes with search, an alphabet filter, display options and a filter restricted to entries matching frontmatter conditions. The README states that the same contacts can also be surfaced through an Obsidian Bases view that adds sorting, grouping and wider filtering and search.
