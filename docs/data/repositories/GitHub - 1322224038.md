# tjqscott/obsidian-graph-spawn

Seeds Obsidian's graph view with starting positions so that disconnected clusters do not all begin stacked at the origin. It finds connected components with a union-find over the links the graph is actually drawing, orders them largest first, lays their centres on a ring wide enough for the two biggest to clear each other, and scatters each component's nodes across a disc sized from its node count before handing over to Obsidian's own forces. Force settings are left untouched, nothing is hardcoded about folders or cluster names, and a filtered graph is separated as filtered. Seeding happens when a graph view opens and when the number of clusters changes, and a command re-runs it at any time.
