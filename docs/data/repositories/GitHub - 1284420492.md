# rcanand/obsidian-one-file

Obsidian plugin that edits any Markdown file on the computer from inside a vault, without copying it in. Opening a file creates a link inside a deliberately visible mirror folder in the vault that reproduces the original path from the root of the disk, so edits write through to the real file and reopening is instant. Opening also enters a focus mode that hides the ribbon, sidebars, tabs and status bar until the command toggles it off. The README records desktop-only support, that macOS may need full disk access for protected locations, that links to deleted or moved files are detected at startup and by a cleanup command, and that such links generally do not travel through iCloud, Obsidian Sync or Dropbox.
