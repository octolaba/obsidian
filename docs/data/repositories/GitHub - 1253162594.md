# olliecheng/quizblock

QuizBlock renders interactive multiple-choice quizzes in Obsidian notes from a quiz fenced code block, and adds one command that resets the attempts recorded in a note. A block lists the question, its options with the correct one marked, and an explanation that stays hidden until answered; question order is shuffled, blocks preview in Live Preview and Reading mode, can be answered in Live Preview, and the chosen options persist in the Markdown itself. The README states that the format is meant to be written by hand or by an LLM and includes a prompt for generating quiz documents in it.
