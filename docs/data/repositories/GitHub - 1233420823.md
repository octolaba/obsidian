# Lynn-x/LexVoice

Obsidian desktop plugin for recording audio, transcribing speech and turning meetings into Markdown. Chapters grow into a live outline while recording and link back to positions in the audio afterwards, notes can be typed under the outline during the meeting where a leading character routes the line to the assistant as a term to explain, a question to answer or a point to highlight, and the finished recording is completed into meeting notes carrying todos, learning cards, people records and speech-recognition hotwords. The README states that the plugin is not a hosted service and ships no API keys: the user connects their own speech-to-text service and optionally their own language model, and recordings stay in the vault.
