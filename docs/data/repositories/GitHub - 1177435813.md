# CYZice/Obsidian-DidaSync

DidaSync synchronizes tasks in both directions between Obsidian and Dida365 or TickTick, covering task creation, editing, deletion and completion status, and creating or updating tasks from native checkbox syntax. The README describes sidebar, time block, timeline and Pomodoro views for planning, execution and review, nested subtasks with drag reordering, drag-to-parent nesting and cross-project moves, completed-task review by time range, and note integration through dragging tasks into Markdown and jumping back from a note link to the related task. An account is connected in the plugin settings through official OAuth 2.0 authorization, and a local MCP service can optionally expose tasks so AI tools can read, create, update and schedule them.
