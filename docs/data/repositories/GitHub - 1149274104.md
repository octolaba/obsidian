# jgradim/obsidian-soundboard

Repository for a soundboard plugin that builds soundboards and playlists from audio files stored in the vault. Its README explains that it was written to run an offline tabletop campaign with background music, ambience and sound effects without internet access and with custom tracks, and that a root folder is chosen in settings so only audio below it is available. The supported extensions are flac, mp3, mp4, ogg and wav.
