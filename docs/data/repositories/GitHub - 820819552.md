# ryzencool/dinox-sync

Repository for the Dinox Sync plugin, whose README is written in Chinese and English and describes synchronising notes between the Dinox application and an Obsidian vault. A token from Dinox is entered in settings, and a pull fetches only the notes that changed since the last sync — from a status bar button, from a command, or every thirty minutes when automatic sync is on — while push actions update an existing Dinox note by the id in its frontmatter, create a new one, or send selected text as a new note. Synced notes land in a configurable folder that can be split further by note type, by notebook and by creation date, with filenames generated from the note id, the title, the creation time or a custom template.
