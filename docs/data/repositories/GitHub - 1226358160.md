# Luis85/specorator

Repository for Specorator, described as a spec-driven agent workspace where the plan is written in Markdown and the results are reviewed with evidence. Its README states that it runs provider-native agents, naming Claude Code, Codex, Opencode and Cursor Agent, with the vault as their working directory so file reading and writing, search, shell commands and multi-step workflows are available. It records saving prompts as vault notes and running them from a picker, a board tracking each handoff from inbox to done, and previewing every edit before it lands or disabling that confirmation for a trusted run.
