# Ekrizdis367/obsidian-caissa

Caissa is a chess-study plugin that embeds interactive boards in Obsidian notes for openings, endgames, complete games, and PGN analysis. It supports branching variations, multiple boards, annotations, built-in World Championship games, Lichess imports, and optional Opening Explorer statistics. Positions can be played against an offline Stockfish worker with adjustable strength, while board export supports PNG and SVG.
