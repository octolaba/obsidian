# theamritanair/obsidian-external-links

External Links View collates all external links found in an Obsidian vault into a single view, grouped by the note each link appears in with collapsible sections per note. The view opens from a ribbon icon or the "Show External Links" command, and clicking a link opens it in the default browser. Settings accept regex patterns that exclude specific URLs and a path regex that skips whole files or folders from scanning.
