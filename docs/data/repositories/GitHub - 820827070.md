# chasebank87/import-github-readme

Fetches the README of a GitHub repository named by URL and inserts it into the current note. The content is converted from HTML to Markdown, stripped of unnecessary tags and empty lines, and relative image URLs are rewritten as absolute ones so the images resolve. The import runs from a command in the palette, which prompts for the repository URL.
