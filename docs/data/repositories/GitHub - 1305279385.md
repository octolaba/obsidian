# hyeucong/obsidian-my-spaces

My Spaces is an Obsidian plugin that defines named spaces controlling which files and folders appear in the sidebar file tree. Files and folders are assigned to a space from the right-click context menu, and spaces are switched from an icon bar in the File Explorer header, from the command palette or by hotkey. Settings offer a built-in icon picker with live previews, and the README lists further commands, more sidebar cases and additional settings as planned work.
