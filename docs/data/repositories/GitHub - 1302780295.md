# ibarv/obsidian_line-multi-selector

Line Multi Selector is described as implementing multi-line selection via line-number regions, and its README is written in English and Chinese. Clicking a line number selects the whole line, a modifier click toggles a single line in or out of the selection, a shift click selects the contiguous range between two lines, and dragging with the left button selects a block; appended selections are added to a remembered selection set. The README notes that line numbers must be enabled in the editor settings for the plugin to work and that Obsidian 0.15.0 or later is required.
