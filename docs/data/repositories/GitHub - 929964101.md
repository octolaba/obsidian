# lukas-cap/simple-file-info

Simple File Info adds a file information pane to Obsidian's right sidebar. It is opened from the button strip at the top right of that sidebar, and a Show file info command in the command palette brings it back if it has been dismissed. The README states the project's priorities as filling the gap for basic file metadata without adding bloat and as avoiding custom styling so the pane matches whatever theme is in use, and it attributes basic image information to the ExifReader library.
