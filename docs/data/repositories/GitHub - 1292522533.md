# emklasson/obsidian-checkbox-status

Checkbox Status counts the checked and total checkboxes in the active Markdown file and shows the result in the status bar, in a separate right-sidebar view, or both, with an optional progress bar filled to the checked-over-total ratio. Which characters count as checked or unchecked is configurable, so custom checkbox states supplied by a theme are counted too. It also adds commands that cycle the selected lines through a defined sequence of list and checkbox states, such as bullet, unchecked, checked and canceled, with one command per configured cycle and a setting for whether a multi-line selection advances together or line by line.
