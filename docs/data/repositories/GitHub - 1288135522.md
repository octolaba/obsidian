# cousine/hledger-dashboard

This plugin renders a financial dashboard for an hledger journal inside Obsidian, opened from a ribbon icon or the Open hledger Dashboard command and divided into tabs, with period controls, currency display, budget and transfer setup. The journal file path and the target currency are set in the plugin settings, and a setup card walks through that configuration before the dashboard is refreshed. The README states the requirements plainly: Obsidian desktop, because the plugin needs child_process and shell access, and hledger 1.52 or newer installed on PATH.
