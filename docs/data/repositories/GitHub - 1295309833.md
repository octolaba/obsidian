# VladB-evs/obsidian-clear-checklists

Clear Checklist resets recurring checklists in Obsidian so a daily or weekly list does not have to be recreated each time. Every checklist can carry an automatic Reset checklist button rendered in Live Preview, Source mode and Reading view, which unchecks the items of that checklist and can be switched off in the settings. A `checklist-reset` code block placed under a checklist renders a button with an optional custom label taken from the block body and hides the automatic button for that list, and a command unchecks every checkbox in the active note.
