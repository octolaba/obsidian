# vinitkumar/oscura-obsidian

Oscura is a dark theme for Obsidian, ported from the oscura-vim colorscheme by Vinit Kumar. The README records the palette explicitly, including background #0B0B0F, foreground #E6E6E6 and separate colours for comments, keywords, functions, strings, links and tags, and describes syntax highlighting tuned for code blocks and inline code within a minimal interface. It is dark mode only and released under the MIT License.
