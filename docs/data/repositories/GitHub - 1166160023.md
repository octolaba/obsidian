# SuperSkypper/super-rss

Super RSS fetches RSS feeds and saves each article as a note, with template variables controlling the filename, frontmatter and content and with per-feed overrides for the fetch interval, template and cleanup rules. The README records feeds grouped into collapsible folders and edited in batches, deduplication against a local database of imported entries, automatic deletion of old notes by publication or saved date with an opt-out property, a URI handler that marks an item read and can delete its note, image linking or local download, and YouTube handling that detects channel feeds, picks the largest thumbnail, fetches durations and can skip shorts and live streams. The author states that they are not a programmer and built the plugin over roughly four months using Claude and Codex.
