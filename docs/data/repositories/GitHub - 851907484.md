# jparkerweb/pixel-banner

Pixel Banner puts customizable banner images at the top of notes, with every aspect controlled through Obsidian note properties. A banner can come from an image in the vault, from a file outside it referenced through the file protocol, from any web URL, from the Pexels, Pixabay, Flickr and Unsplash APIs by keyword, from AI generation, or from the Pixel Banner Plus collection, which also supplies MP4 and MOV video banners. Position, transparency, border radius, animation effects, spacing and display mode are adjustable for the banner shown.
