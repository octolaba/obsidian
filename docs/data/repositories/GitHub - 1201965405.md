# yoofloe/yoofloe-obsidian

Brings selected personal Yoofloe context into an Obsidian vault as read-only reports and recaps, and can send approved notes or tasks back to Yoofloe. The README states that note generation runs through the user's own Vertex AI project and model, so Google Cloud usage and billing stay between the user and Google Cloud, and that neither the plugin nor the separate MCP wrapper ships a model or model credits. The wrapper is downloaded separately and configured with node, its server script, a Yoofloe personal access token and a vault path, so a connected agent uses whatever model path that agent is configured with. Both are described as available to Yoofloe Free and Pro users.
