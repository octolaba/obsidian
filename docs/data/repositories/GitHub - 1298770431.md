# WestB-DEV/Solomon-Chat

Solomon Chat turns an ordinary Obsidian note into a private written conversation with a wiser version of the writer, as a purpose-built form of the self-distancing practice its README attributes to Alex Hormozi's use of a plain document. One side of the exchange is the writer today and the other an older self, a wise friend, a mentor or any character whose perspective helps; the README traces the idea to writing a letter to a wiser correspondent and a reply back. The plugin is framed as Markdown-first and built to make self-distanced journaling and clearer thinking easier to practice.
