# MohammadKanaan/enhanced-memos-sync

Enhanced Memos Sync pulls entries from a self-hosted Memos server into an Obsidian vault, saving each memo as its own Markdown file and listing the day's memos under a configured header in the Daily Note. Three sync commands are offered: a smart sync that runs a full pass once then incremental ones, an incremental sync that only adds new notes, and a force sync that reapplies remote edits and deletions. Replies can be folded into their parent memo, attachments are downloaded into a chosen folder, and syncing can run at startup or on a schedule. It requires desktop Obsidian 1.6.6 or later and a Memos server with an API token, stored in Obsidian's Secret Storage on 1.11.4 and newer.
