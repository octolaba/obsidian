# sjwinkler19/obsidian-worktree-viewer

Worktree Viewer shows every git worktree of a repository in an Obsidian panel, refreshed every four seconds while open and idle when closed. Each row lists the files changed against the merge-base plus untracked files, opens a coloured diff or a rendered preview of the worktree's version of a note, and carries a presence dot read from a session's own transcripts that pulses while an agent is writing. A commit-all action commits the uncommitted work, pushes the branch and opens a pull request, and the README states that all polling uses the no-optional-locks flag so the plugin never contends with those agents' git operations.
