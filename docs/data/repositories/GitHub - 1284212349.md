# Viy1204/smart-red-public

Smart RED converts Markdown notes into Xiaohongshu style image cards at 1080 by 1440 pixels. The README describes a pagination engine driven by real template DOM measurements that splits paragraphs line by line to avoid premature page breaks, a CJK typography engine applying prohibited line-start and line-end rules, 19 card templates in Chinese long-form and brand series, image and table rendering, and one-click PNG or ZIP export. Writing happens on the left with the cards previewed on the right, where pages are flipped, the preview locked and templates switched.
