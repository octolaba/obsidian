# ondreu/DXF-Viewer-and-editor

Obsidian plugin that opens DXF CAD drawings inside the app, both as a full file view for any .dxf in the file explorer and as a read-only embed in a note. It provides pan, zoom and selection, an adaptive grid, snapping to endpoints, midpoints, centres, quadrants and intersections, and measurement of distance, radius, angle and area, and it can create a new empty drawing from the file explorer. The README describes this as v1 covering DXF only, states that DWG is out of scope, and warns that editing is limited and round-trip fidelity of saved files is still being hardened.
