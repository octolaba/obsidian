# CodeListening/obsidian-bookxnote

This plugin copies reading notes saved in BookXNote into a chosen folder in an Obsidian vault. The README explains the mechanism: BookXNote stores its notebooks as JSON under a notebooks folder, so the plugin reads those files and reorganises them into Obsidian notes; the settings take the path to that notebooks folder and the destination path in the vault, and notes can be imported all at once or one at a time. BookXNote itself is described as reading-note software supporting PDF, EPUB, MOBI, TXT and DOCX books. The repository description and the README are in Chinese; this summary restates what they describe.
