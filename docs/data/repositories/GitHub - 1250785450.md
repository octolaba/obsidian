# DudeThatsErin/vaultkeeper

Vaultkeeper organises attachments, renames pasted files and extracts text from images and PDFs with OCR. The README describes moving attachments to Obsidian's configured location, the linking note's folder or a named folder, optional subfolders by date, file type or a token pattern, configurable extensions, ignore rules, deletion of folders left empty, and automatic runs at startup or on an interval. Paste renaming offers five modes with tokens for date parts, type, the active note name and the original filename, updating embed links to match, and a cleanup pass finds unlinked attachments and purges the selected ones after confirmation. OCR runs through Google Gemini over images and PDFs with a watch folder, batching with rate-limit backoff and a customisable prompt and output template; the README states that the plugin is being vibe coded.
