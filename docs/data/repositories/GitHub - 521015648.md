# ieviev/obsidian-keyboard-shortcuts

This plugin adds snippet and navigation commands for the keyboard to Obsidian, and its README states that no keybindings are set on install, so each command has to be configured by the user. The recorded commands move to the previous or next heading or empty line in edit mode, select the current heading block up to the next heading or the end of the document, raise or lower heading level, insert a default callout or code block with the cursor placed inside and a configurable default language, and copy a code block either from a searchable list or the one nearest the cursor. Two Quick Switcher extensions perform a two-step search that filters notes by tag first, one of them with unfolding tags and AND queries; the README states that they require a default modal command to be set in the plugin settings.
