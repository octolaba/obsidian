# ggajos/ggajos-tasks-eye

Tasks Eye surfaces the next actionable task from each note rather than listing every task in the vault, treating a note placed in a configured folder as a project or work item. Three views organize the result: Focus shows tasks due today or overdue, Open groups active notes and their next tasks by due date, and Inbox collects notes missing metadata such as a context folder, a due date or any unchecked task. The first unchecked dated task in a note, written in Obsidian Tasks format, is the one shown, and the Markdown notes and checkboxes remain the source of truth. It requires Obsidian 1.13.4 or newer and the Tasks community plugin, and optional public-holiday support fetches country and holiday data from an external API without sending note content.
