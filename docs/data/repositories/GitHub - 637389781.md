# pavloDeshko/obsidian-index-checker

Checks that index or map-of-content files contain all the links they should, while leaving their structure and formatting to the user. Index files are identified by naming patterns, including a placeholder standing for the containing folder name, and the expected link set is one of three scopes: the same folder, that folder plus all subfolders, or that folder plus only those subfolders that have no index of their own. Checks run manually or whenever the vault is opened, missing links are appended or prepended to the index or written to a dedicated file with configurable formatting, and both Markdown and Canvas index files are supported. Files that had missing links are marked in the file explorer until they are modified or cleared.
