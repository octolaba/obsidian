# ArtemisLin/obsidian-wechat-diary

WeChat Diary binds a WeChat bot by QR code and appends the messages sent to it into dated Markdown notes inside the vault, one file per day under a year folder. A diary mode is started and sealed by chat commands, casual messages outside that mode are not recorded, and voice messages arrive as the transcription WeChat itself produces. Writing is append-only with stable frontmatter, and an OpenAI-compatible endpoint can optionally be configured for light polishing and replies; without one the plugin still works and makes no model requests. It is desktop-only and runs only while Obsidian is open, catching up through a server-side cursor after short offline gaps, and its bot token and key are held in Obsidian's secret storage rather than in the vault.
