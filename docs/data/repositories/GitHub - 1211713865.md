# HatanoChihiro/obsidian-webnovel-assistant

A writing workspace for novel and story authors inside Obsidian, documented in English and Chinese. It offers a dashboard with a novel overview and statistics panel, a workbench holding panels for chapters, timeline, foreshadowing, lore, tasks and notes, and a full-screen writing mode with typewriter scrolling and line dimming. Word counting comes in three modes with goal tracking, a strict chapter mode, chapter sorting, real-time reminders and per-folder counts, while focus-time tracking separates focused from idle time and reports it as a yearly heatmap, trend charts and an efficiency card. The README also points to an OBS overlay CSS guide beside the user guide.
