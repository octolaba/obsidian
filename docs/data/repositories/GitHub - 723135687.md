# adrianlyjak/obsidian-aloud-tts

Aloud speaks highlighted text from Obsidian notes by sending it to a text-to-speech provider with the user's own API key. The README lists OpenAI, Google Gemini, Hume AI, ElevenLabs, Fish Audio, Azure Speech Services, MiniMax and AWS Polly as supported, and allows a custom endpoint for any OpenAI-compatible server that exposes an audio speech route. Audio is streamed sentence by sentence, the active sentence is highlighted as playback progresses, and playback can be skipped back and forth.
