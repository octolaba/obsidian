# jingmengzhiyue/obsidian-okr-manager

Vault OKR Manager is an Obsidian plugin for planning, tracking and reviewing objectives and key results inside the vault. The README describes one Markdown file per objective holding objective and key-result state in YAML frontmatter and readable check-in history in a progress section, which it contrasts with one file per key result or per check-in. Documented features are a dashboard that browses objectives by period, weekly, monthly, quarterly and yearly cycles, automatic progress calculation for key results and objectives, multiple updates per day, drag-and-drop ordering, overdue indicators, reminders and due-date postponement, and English with Simplified Chinese. It records the design as local-first with no external database, cloud dependency or telemetry.
