# GoBeromsu/Metadata-Auto-Classifier

Metadata Auto Classifier analyzes a note's content with an AI provider and generates tags and frontmatter values for it. Custom frontmatter fields can be defined and populated automatically, classification rules and tag categories can be set, and per-field context prompts guide the classification; the README states that more context gives a more accurate result. Testing tools with a preview mode allow the suggestions to be assessed before they are applied. Commands fetch tags, fetch all frontmatter fields, or update one field at a time, and settings select the provider and model among OpenAI, Gemini, Ollama or a custom configuration.
