# Kageetai/obsidian-plugin-journal-review

The recorded description says the plugin reviews daily notes on their anniversaries, in the sense of what happened today last year. The README explains that it pulls from all daily notes, using the Periodic Notes plugin's settings when that plugin is present, and shows excerpts from the same day in earlier time spans in an On this day view opened from a ribbon icon or the command palette; the view refreshes when a new daily note is created and around midnight. Time spans are configured as a number, a unit and whether they recur once or repeatedly, and further options cover showing note titles above previews, humanizing the time-span titles through moment.js, and rendering previews as Obsidian callouts or as HTML quote elements.
