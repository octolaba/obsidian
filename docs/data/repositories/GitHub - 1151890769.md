# one-spread/obsidian-folder-focus

Folder Focus adds a Finder-like folder navigation view to the right sidebar of Obsidian, with Finder-compatible keyboard shortcuts, selection history, pinned favourite folders reachable from the header, and live refresh when files change outside the app. Files can be multi-selected with Cmd-click and Shift-click, renamed, deleted, grouped into a new folder, moved by dragging onto a folder row, or imported by dragging in from Finder, and a context menu carries the file operations. Search switches between file names and file names plus Markdown note text, can include subfolders, can be limited to folders, and highlights matches. Single click selects, double click opens a file or enters a folder, and compact badges mark file types from Markdown, Canvas and Base to PDFs, images, code, archives, audio and video.
