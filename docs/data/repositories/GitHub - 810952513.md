# vasilcoin002/pinned-notes-plugin-obsidian

Pinned Notes pins the most frequently used notes to the ribbon actions so they can be opened directly. Each pinned note is a row added on the settings screen holding three fields: the name displayed on hover, the path of the file to be opened, and optionally the name of an icon, which defaults to a file icon. Rows are stored with a save button and can be changed or deleted the same way, and the README notes that icon names come from the Lucide set but that not all of those icons are available in Obsidian.
