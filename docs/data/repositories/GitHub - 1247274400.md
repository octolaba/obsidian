# MowdW/DualLink

DualLink embeds files that live outside the vault, at absolute paths, alongside files inside it, so large media does not have to be copied into the vault. The README describes a sidebar browser that switches between internal vault mode and external path mode, drag and drop of an external file into the editor to produce a local-file link, hover card previews and optional inline rendering for images, and inline playback or opening in a native application for formats such as .mp4, .webm and .mp3. Three link formats are offered: a custom protocol described as sandbox-isolated, a standard file URL, and a raw absolute path.
