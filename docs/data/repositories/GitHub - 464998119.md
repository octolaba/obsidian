# NomarCub/obsidian-hide-sidebars-on-window-resize

The repository holds Hide Sidebars on Window Resize, an Obsidian plugin that hides the sidebars when the window becomes too narrow and shows them again when it widens. Its README records a configurable minimum width for the left and right sidebars separately, and points at three related plugins covering finer sidebar control, easier collapsing and a minimum width for the active pane. The catalog records the repository as a fork licensed under MIT.
