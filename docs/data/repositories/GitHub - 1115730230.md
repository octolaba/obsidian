# sustcsugar/obsidian-gantt-calendar

Presents vault tasks in six switchable views — task list, year, month, week, day and Gantt — with a task heatmap, daily counts and gradient palettes. Day and week views lay tasks on a 24-hour timeline with drag and drop and quick creation, a sidebar combines task search, filtering and sorting with a daily timeline, and daily notes can be edited inline. Both the Tasks plugin emoji format and Dataview inline fields are parsed, covering six date fields, priorities and recurring tasks shown as virtual instances. The README also records solar and lunar festival display with the 24 solar terms, and two-way task sync with Feishu over OAuth 2.0.
