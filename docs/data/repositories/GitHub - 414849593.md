# SuperChamp234/habitica-sync

The repository holds Habitica Sync, an Obsidian plugin that adds a pane for viewing and acting on tasks held in the Habitica service. Its README records that the pane is opened from the ribbon or a default hotkey and that a user identifier and API token are entered in the plugin settings to connect an account. The pane shows health, experience and coins alongside tabs for todos, dailies, habits and rewards, with task titles, descriptions and subtasks rendered with Markdown and emoji, and it allows checking and unchecking tasks and moving habit counters up or down. The README describes the plugin as under development.
