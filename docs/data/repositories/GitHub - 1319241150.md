# OgyanuntiusXIII/vault-aquarium

Vault Aquarium draws a single animated betta fish over the Obsidian workspace and colours its body, fins and pattern from the leading graph colour groups of the vault, interpolating between appearances as notes and links change rather than switching at once. Clicking the fish opens a status and hide menu, it can be dragged anywhere, and monthly growth records with note, link and colour-group statistics are stored locally. Colour groups are read from the graph configuration file because Obsidian exposes no stable public API for them, and manual rules by path or tag are also accepted; a rule can be excluded from the fish while still colouring the graph view. Rendering and periodic saving stop while the fish is hidden, reduced-motion preferences hold it still, and no note content is analysed or sent anywhere.
