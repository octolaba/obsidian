# kevinmcaleer/obsidian-bases-chart

Bases Chart renders data from Obsidian Bases as charts inside notes, driven by a `bases-chart` fenced code block that carries a SQL-style query. The README lists eight chart types — bar, column, pie, doughnut, gauge, line, a calendar heatmap and a single-number stat — plus multi-metric queries, multiple `.base` sources compared side by side or merged, date bucketing and relative-time functions, sorting, and data labels. Charts can also be configured visually through an inline settings panel with dropdowns, a draggable color palette and a live SQL preview, or inserted from the command palette.
