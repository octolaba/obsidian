# hxuanwang/obsidian-cdrawer

The repository records no description, so this body rests on the README alone. The README describes an editor for commutative diagrams on a fixed grid, with the same interaction model as the tikzcd web editor: build the diagram by typing LaTeX labels into cells and dragging arrows, then click away to commit a static inline diagram styled to match Obsidian's native CD math environment, and click it again to reopen the grid pre-filled. Diagrams are stored as a cd fenced code block holding a small JSON model, so they stay plain text in the vault, and they can be exported to tikz-cd or plain AMS CD and imported back. The editor runs either as a floating window or embedded in the page; the README states that rendering works on desktop and mobile while the grid editor is desktop only.
