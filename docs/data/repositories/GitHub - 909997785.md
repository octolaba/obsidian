# sleepingraven/obsidian-chat-clips

Records a chat as an ordinary Markdown list in editing view and renders it as a comment-like layout in reading view. The README defines a chat clips list as a first-level ordered list whose first item marks the block as chat clips and whose following items are read as commands, with second-level unordered list items each rendered as one chat comment. It states that the rendered parts are callouts with their own data-callout values, so the appearance can be changed with CSS snippets, and gives the selectors to target folders and comments either loosely or precisely.
