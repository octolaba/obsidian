# quangnd159/inkflow

Inkflow opens a handwriting canvas for a Markdown note: strokes are saved into a compact sidecar file that keeps every point, and a plain PNG stays embedded in the note, refreshing after short bursts of writing. It targets pen input on iPad, Boox and other stylus devices, with pressure-sensitive strokes, palm rejection, cached completed strokes, capped display pixel density and new segments drawn without repainting the canvas. The tool set is deliberately small: a pen, a whole-stroke eraser and three widths, plus undo, redo and zoom, on dotted full-bleed paper with ink that follows the theme. Deleting the handwriting removes the embed along with its sidecar and image, deleting the parent note cleans them up, and it runs offline with no accounts, analytics or network calls.
