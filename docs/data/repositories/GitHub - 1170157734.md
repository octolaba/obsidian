# ScottKirvan/BojuBot

BojuBot is presented as an agentic assistant that extends an Obsidian vault beyond note-taking, storage and organisation into what the README calls a personal AI platform. Its stated interaction model is conversational: the user asks in regular language and the plugin writes, plans, builds custom commands and even develops Obsidian plugins without leaving Obsidian, the README's worked example being a summary of last week's meeting notes. The recorded inputs are written as a pitch and describe intent more than mechanism; nothing beyond the capabilities named here is stated.
