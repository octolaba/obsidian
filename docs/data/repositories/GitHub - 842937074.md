# situ2001/obsidian-enhanced-image

Obsidian plugin that extends how images behave in Obsidian, starting from a context menu with utility actions for local images, which have none by default, as well as for remote ones. The README names copying, renaming and deleting an image from the working Markdown file, and converting an image between local and remote, as the problems it addresses, and lists batch operations, out-of-the-box handling such as HEIF and HEIC preview, and a settings page as work in progress. It opens with a disclaimer that the plugin is in active development and may have bugs or incomplete features.
