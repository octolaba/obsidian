# b1rdmania/obsidian-geocities-98

b1rdmania/obsidian-geocities-98 holds GeoCities 98, an Obsidian theme that recreates the aesthetic of the late-1990s personal homepage in light and dark modes. Dark mode uses a tiled starfield on a midnight background with glowing Comic Sans headings and neon cyan and magenta links, while light mode uses a pale-yellow confetti wallpaper with navy Comic Sans and a web-safe palette. The README also lists animated GIF dividers in place of horizontal rules, blockquotes permanently under construction, a spinning globe above the file list, and a hit counter in the status bar.
