# Chris8891/wisemind-obsidian

Connects an Obsidian vault to the WiseMindAI desktop application through that application's local API. A panel with home, summary, cards, chat, sync, search, settings and tutorial pages summarises the current note, a selection or several notes, generates knowledge cards, chats against note content, sends Markdown notes across and synchronises content between the two sides. The README states that the plugin is desktop only because it talks to a local service, that the local API has to be enabled in WiseMindAI first, and that the default address is a loopback port verified with a connection test.
