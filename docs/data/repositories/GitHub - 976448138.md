# dainakai/obsidian-yaml-table

YAML Table renders a YAML code block as an HTML table in Reading view and Live Preview, updating as the YAML is edited and returning to the source when the table is clicked. It handles simple key-value pairs, lists of plain values and of objects, and nested objects, and adds horizontal scrolling when a table is wider than the note. A caption may be given after a colon on the language identifier line and is centred above the table, and the identifier that triggers rendering is configurable in the settings.
