# johnsonhong997/obsidian-daily-notes-viewer

Obsidian plugin that gathers recent daily notes onto one page. The README states that the core daily notes plugin must be enabled, that the viewer file is created automatically when the plugin is enabled, and that it is updated automatically when daily notes are created or the settings change. A ribbon icon jumps to the viewer file.
