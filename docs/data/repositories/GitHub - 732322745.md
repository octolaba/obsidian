# lei-ctyh/obsidian-sync-cnblog

This plugin publishes Markdown notes from an Obsidian vault to the cnblogs blogging service, adding a right-click command on a Markdown file that uploads it. Its README, written in Chinese, records that MetaWeblog client access has to be allowed in the blog's own backend and that the blog address, username and password taken from there are entered in the plugin's settings together with the target directory for synchronised articles, with a test button to check the connection. It also records setting up the Custom Attachment Location plugin and Obsidian's file and link options first so that local images are handled, that uploading a note a second time updates the already published article, and that renaming a published note renames the article as well.
