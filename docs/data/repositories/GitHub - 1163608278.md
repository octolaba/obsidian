# pikiby/GraphFrontier

The repository holds GraphFrontier, which its README describes as an independent Obsidian graph plugin with its own physics engine rather than an extension of the built-in Graph View, aimed at large collections of notes. Recorded capabilities include pinning nodes at chosen positions or to a grid, saving and reloading node layouts as files, boosting attraction to a specific node, placing linked nodes on another node's orbit, colouring or hiding links, blacklist and whitelist visibility filtering, multi-selection, hotkeys, and copying linked names and paths. The README also records a find mode and a filter mode giving local-graph behaviour inside the global view, separation of orphan files from primary nodes, and static HTML export producing a file with pan, zoom, hover labels and a file-content side panel.
