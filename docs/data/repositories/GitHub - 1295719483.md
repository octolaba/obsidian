# meljadyn/obsidian-pretty-paragraphs

Pretty Paragraphs restyles notes with traditional first-line paragraph indentation in place of the vertical spacing Markdown uses between paragraphs, which the recorded description frames as manuscript-style typography. The README states that a single Enter produces a line break with no indent, so line breaks stay visibly distinct from paragraph breaks and the underlying Markdown remains valid. Settings choose whether the styling applies in reading view, editing view or both, optionally justify the text, and restrict the styles to a whitelisted folder; the indent size is adjusted through the Style Settings plugin.
