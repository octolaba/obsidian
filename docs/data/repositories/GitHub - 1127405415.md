# brabli/obsidian-weekly-notes

Creates weekly notes in Obsidian on its own; the README presents it as a stand-alone alternative to Periodic Notes that does not require the Calendar plugin. Settings cover the starting weekday, the template file to use and a title format written in moment.js syntax, and template variables are handled in line with the core Templates plugin. Its single command creates the weekly note and opens it, or opens the file when it already exists.
