# Yodavatar/Harmony

Harmony is an Obsidian plugin offering several task modules over the same data, each enabled or disabled in its settings. The README records a dashboard module opening in a new window with urgent and next tasks, a Kanban module with multiple boards and columns that can be moved, recoloured or deleted, task creation with priorities, due dates, links and tags, archiving and sorting, a calendar module with daily, weekly and monthly views and recurring tasks, and a minimalist to-do list organised by priority. The stated goal is to keep this kind of workspace entirely local and open source inside Obsidian.
