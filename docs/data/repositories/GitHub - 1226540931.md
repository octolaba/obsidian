# pumler/plugin-obsidian

Pumler renders PlantUML, Structurizr DSL and Mermaid diagrams from pumler fenced code blocks in Obsidian notes by sending the source to the public Pumler rendering API and inserting the returned SVG. Each block carries a YAML header naming the provider, the diagram type, a title and a light, dark or auto theme, edits are debounced before the API is called, and the thirty most recently used SVGs are cached on disk. Diagrams get a collapsible summary row and a zoomable preview modal. The README states that the plugin handles only pumler fences and does not replace Obsidian's native mermaid renderer or process plantuml and structurizr fences directly.
