# ChasKane/autoscroller

Obsidian plugin that scrolls the active note automatically at a configurable pace, intended for reading long documents hands-free or during presentations. Scrolling is toggled from a command or a ribbon icon, separate commands increase and decrease the speed, right-clicking the ribbon icon cycles through speeds, and the icon can be hidden in the settings. The README records a known issue: scrolling stops if it is started before a note's content has been focused.
