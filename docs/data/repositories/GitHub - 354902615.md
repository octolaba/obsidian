# No3371/obsidian-regex-pipeline

The repository holds Regex Pipeline, an Obsidian plugin that applies user-defined regular expression rules to format notes automatically, which its README presents as useful when clipping web pages from the same sources into a knowledge base. Rulesets live under a regex-rulesets directory inside the vault's configuration folder, and an index file lists which ruleset files may be read, a consequence the README attributes to how Obsidian restricts disk access. Since version 1.0.8 rulesets can also be added from a button in the plugin's menu, though the files themselves are still edited on disk.
