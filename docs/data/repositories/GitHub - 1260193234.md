# yonxao/yonxao-mindmap

Renders `yxmm` code blocks in Markdown notes as interactive SVG mind maps and related structural diagrams. The README counts 20 layouts in 7 categories, among them mind maps in several directions, tree diagrams, organization charts, timelines, radial maps, fishbone diagrams and tree tables, with hierarchy expressed through heading markers and plain lines merging into multi-line topic content. Editing happens in the diagram: double-click to edit, drag to reorder, right-click menus, collapse and expand, keyboard navigation and shortcuts for creating, deleting and copying topics, zooming and going fullscreen, backed by an internal clipboard with undo and redo. Eight colour schemes, switchable curve, straight and elbow connectors, and inline styles including bold, italic, colour, lists, code blocks and equations are documented.
