# mrKazzila/Read-Only-View

Keeps selected Markdown notes in Obsidian's Reading view by matching their vault paths against include rules, with exclude rules carving out exceptions, over a folder, a single file, or a broader pattern set. Protection works in two layers: input blocking in CodeMirror-backed Markdown editors, and an automatic return to Reading view for matched notes as a view-level fallback intended to cover contexts such as hover preview. The README states that the plugin changes only Obsidian's view behaviour and not file-system permissions, that no network requests are made, and that diagnostics and a path tester help when a rule misbehaves.
