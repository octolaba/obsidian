# WithMarcel/alias-management

Alias Management surfaces duplicate notes in Obsidian by comparing aliases and filenames. It expands aliases and filenames at runtime rather than rewriting files, and lists every alias appearing in more than one file, color-coding whether that alias comes from a filename or from the aliases inside a file, with the source shown on hover. Clicking an alias opens its file, the view updates in real time, and in reading and source modes a highlighted or pre-selected alias can be removed in a single action.
