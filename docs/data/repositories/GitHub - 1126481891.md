# yy/obsidian-year-glance

Renders a whole-year calendar in a note, marking events with coloured indicators. Events are declared inside a `year_glance` code block, grouped under category headings and dated as single days or ranges, with options given in the block's YAML frontmatter. The README documents the year to display, a 3x4 or 12-rows layout, a Sunday or Monday week start, a compact or expanded display style, a today indicator and a palette for automatically assigned category colours.
