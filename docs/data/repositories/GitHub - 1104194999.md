# MatoTheTomato/Elysian

MatoTheTomato/Elysian holds Elysian, an Obsidian theme inspired by the interface of Disco Elysium, with film-like markings and a grainy texture that follows the content as it scrolls. It supports light and dark mode, colours bold text and distinguishes internal from external links, and uses a terminal-looking interface font with custom inline titles. The README states that this is the author's first theme, that it works best with readable line width enabled, that mobile is functional but not finalised, and that the scrolling background and inline titles may interact badly with some plugins.
