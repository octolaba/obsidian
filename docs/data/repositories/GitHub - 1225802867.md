# sboulema/mtg-deck

This repository holds MTG Deck, an Obsidian plugin for trading card game players that manages decks and card lists as notes, rendering a decklist pasted into a code block as an interactive deck view. Cards are sorted and grouped by type with a per-type count in the footer, mana symbols and prices in USD, EUR or TIX come from Scryfall, rarity is shown as a coloured dot before each card count, hovering shows a preview image, and double-faced cards flip when that preview is clicked. The README also records a toggle between list view and a visual grid of card images, tracking of how many copies are owned with missing cards highlighted, an automatically generated buylist, and validation of card legality per format.
