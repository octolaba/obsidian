# exmemo-ai/obsidian-exmemo-assistant

Obsidian plugin that uses a large language model to generate and update file metadata, including tags, descriptions, titles and edit times, run from a command in the palette. Before use it needs an API key, base URL and model name configured, and the README recommends pre-filling or extracting a tag list so generated tags match existing ones, adjusting the description prompt to change how descriptions are written, and using content truncation to limit the cost of long articles. It carries a maintainer note that the separate obsidian-exmemo-tools plugin now covers all of these features and that development has moved there.
