# Niv20/obsidian-Plugin-Callout-Studio

This repository holds Callout Studio, an Obsidian plugin for creating, editing and styling callout types from a single settings tab, including overriding the built-in ones. One callout definition can be used in three forms, each with its own vault-wide style controls: the ordinary blockquote callout, a heading callout written after the heading marks that turns the heading into a coloured foldable bar, and an inline callout rendering as a small pill inside a sentence. All three forms render in Live Preview, Reading view and PDF export. Icons come from a single picker spanning seven libraries, among them Lucide, which the README notes is always available offline, and Tabler Icons.
