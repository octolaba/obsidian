# Niv20/obsidian-Plugin-Callout-Studio

Callout Studio lets users create, edit, and style callout definitions for regular blockquotes, heading callouts, and inline pills. It supports light and dark colors, reusable palettes, multiple icon libraries, autocomplete, and rendering in Live Preview, Reading view, and PDF export.
