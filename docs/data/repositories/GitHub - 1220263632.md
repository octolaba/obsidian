# punkyard/obsidian-lindar

Obsidian plugin drawing a yearly linear calendar for long-horizon planning, presented by its README as a response to a request from Nick Milo of Linking Your Thinking whose approach shaped the visual interface. Events are created by clicking a date in the calendar tab and filling in a title, date range, colour and optional type, participants and description; on save each event becomes a Markdown note in a configured events folder that can be opened from the calendar. Tasks written in any note with the plugin's tag, a due date and a hex colour are rendered as bars on the calendar as well. The README states the plugin is under development and points to its own docs folder for options, event format and roadmap.
