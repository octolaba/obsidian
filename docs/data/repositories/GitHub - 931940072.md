# SpaceshipCaptain/CmdSearch

CmdSearch searches the web from Obsidian's command palette through user-defined commands. A command holds a search URL with a `%s` placeholder, so selecting it prompts for a query and opens the URL with the query inserted; the default commands can be modified or removed, new ones added for any site that supports URL-based search, and hotkeys assigned to them. The README recommends enabling the Web Viewer core plugin, since without it the links open outside Obsidian in the system browser, and it links a reference list of common search URLs.
