# gapmiss/substack-clipper

Substack Clipper saves a public Substack post as a Markdown note: a command takes the post URL, fetches the post, and downloads its images, video, audio, podcast episodes, transcripts and PDF attachments into a folder beside the note. Media is embedded so Obsidian plays it natively, Substack footnotes become standard Markdown footnotes, CDN prefixes are stripped from image references, and threaded comments are rendered into a separate note that the main note embeds. The README records frontmatter carrying title, subtitle, type, audience, date, comment count and media links, an obsidian URI that clips a post without the command palette, paywalled posts saved as the available preview, and operation on desktop and mobile.
