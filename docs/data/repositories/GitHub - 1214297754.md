# ryofeeee/obsidian-open-terminal-here

Obsidian plugin that opens a terminal at the directory of the file being edited. The triggers are configurable in settings and cover the editor right-click menu, the file explorer right-click menu, an optional ribbon button and a command palette entry that is always registered and can be given a hotkey. The README records that any terminal named in settings works, among them Terminal, iTerm, Warp, Ghostty, Alacritty, WezTerm, PowerShell and Windows Terminal, and lists desktop Windows or macOS as the requirement.
