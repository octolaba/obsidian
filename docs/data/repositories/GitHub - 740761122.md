# jdholtz/obsidian-image-inserter

Simple Image Inserter inserts images into a note without needing an external file explorer window. An insert-image command opens a built-in file browser where one or more images are selected, and those images are embedded into the note and copied into the vault. The README records the plugin as inspired by Better File Link.
