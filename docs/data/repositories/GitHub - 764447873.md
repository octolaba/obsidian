# vkodocha/NoteCompanionFolder

Note Companion Folder is an Obsidian plugin that associates a folder of attachments with each note, named after the note without its extension, so attachments are kept per note rather than in one vault-wide attachments folder. Two layouts are supported: the companion folder sits beside its note by default, or a base path can be set in the settings so that all companion folders live under one subpath of the vault. A companion folder is revealed from a ribbon icon, a command, a context action or a file action, and it is created on first use if it does not exist yet.
