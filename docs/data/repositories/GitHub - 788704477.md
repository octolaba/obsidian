# MarcDonald/obsidian-day-one-importer

Repository for Obsidian Day One Importer, a plugin that converts Day One journals exported as JSON into Obsidian Markdown. The export is extracted into a folder in the vault, the settings are matched to that setup, and the import creates the entries as notes, writing a `Failed Imports.md` file with the reason whenever one fails — for example a filename collision between two entries sharing a date. The README lists support for text and rich text entries, date-based or UUID filenames, inline images and videos, and frontmatter carrying tags, starred, pinned and all-day flags, location and activity, while weather and metadata formats outside frontmatter are stated as not currently planned.
