# vran-dev/obsidian-contribution-graph

Contribution Graph renders interactive heatmap graphs in a note, in the style of a code-hosting contribution calendar, to track notes, habits, activity or history. A graph is added from a right-click Add Heatmap action and configured through a block of options covering the title and its style, the number of days or a fixed date range, and cell colours or emoji fills. Week-track, month-track and calendar views are available, cells report statistics on hover and can carry a custom click action, and the README documents an API for rendering graphs dynamically from DataviewJS.
