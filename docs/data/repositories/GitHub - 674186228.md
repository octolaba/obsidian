# xRyul/obsidian-image-converter

Converts dropped or pasted images to WEBP, JPG or PNG, compresses them by a quality value between 1 and 100, and resizes them either destructively or through the link's width parameter, with resizing by dragging an edge or by scroll wheel in the editor. It also crops, rotates and flips, aligns images and wraps text around them without custom link syntax, and includes an annotation and markup tool for drawing on top of an image inside Obsidian. Images can be renamed and filed into output folders using variables such as note name and file name, and batch processing applies conversion, compression and resizing across a note or the entire vault. The README states the implementation is pure JavaScript working offline, with no external APIs and no binary dependencies.
