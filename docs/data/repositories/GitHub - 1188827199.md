# hpasic/obsidian-liftoff

Mobile-first gym workout tracker for Obsidian that logs sets, reps and weights, storing all data as Markdown in the vault. Workouts start from templates or are built ad hoc, sets are pre-filled from the previous session, and tapping a set number cycles its type between warmup, working, drop and failure, with warmups and drop sets excluded from volume and record calculations. Personal records are detected automatically for heaviest weight, best estimated one-rep maximum by the Epley formula and best single-set volume, and every note receives a summary of duration, working sets, total volume and records. It also carries a count-up stopwatch for duration exercises, a rest timer with auto-start, an interval timer, per-exercise free-text notes and a searchable exercise library.
