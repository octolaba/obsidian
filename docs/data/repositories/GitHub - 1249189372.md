# MellowMarsh-Git/obsidian-translucent-bg

Translucent BG applies the native Windows 11 background materials Mica, Acrylic and Tabbed to the Obsidian window through the Electron API, so the window picks up the operating system's translucency. Tint and opacity are controlled independently and either can be deferred to the active theme; the README states that with both theme toggles on the plugin produces the same translucent workspace background expression Obsidian themes use natively, and that the tint updates when light and dark mode change. A ribbon icon and a command cycle through the materials without opening settings, and a second command opens the settings tab. The README states that the plugin is Windows only, requires the desktop app on an Electron version exposing the background material API, and reverses all of its CSS changes when disabled.
