# spacegrowth/otoha-tts

Obsidian plugin that reads the current note aloud, highlighting each sentence in place and scrolling smoothly so the spoken line stays in view. It can read the whole note, the current selection or everything from the cursor, and while reading it accepts play, pause and stop as well as a click on any sentence to jump there. Two engines are offered: the device's built-in speech, which is the default and needs no setup and works offline and on mobile, or higher-quality neural voices served by a companion menu-bar application running locally. The README discloses that the plugin talks only to loopback addresses — one port for synthesis and two more for mirroring playback state to that companion application — and that it carries no telemetry or analytics.
