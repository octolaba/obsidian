# jkom4/obsidian-devops-compagnon

Repository for DevOps Companion, an Obsidian plugin in an alpha stage that parses common DevOps configuration files inside a vault. It detects Docker, Terraform and CI/CD pipeline files, with Kubernetes and Helm listed as coming and general configuration or environment files handled only through its AI path, watches a chosen folder and re-parses on change, and offers a manual scan command as well as an import path for file types Obsidian does not open natively. Documentation can be rewritten and explained in Markdown by a configured provider — OpenAI, Google Gemini, Anthropic Claude or Mistral — with several API keys stored and a connection test, while the README warns that the plugin is under active development and not yet production-ready.
