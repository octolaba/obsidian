# hkcanan/katmer-code

KatmerCode puts four AI providers, Claude Code, Gemini, Codex and Antigravity, into one Obsidian sidebar, with each chat tab pinning its own provider and model. A reply can be sent to another model for a second opinion, so the consulted response and the active model's synthesis appear in the same conversation without switching tabs. The README describes inline diff editing, MCP support, seven academic research skills exposed as slash commands across every provider, and an option to mirror a rules file to the other providers. It states that the plugin is desktop only and that each provider needs its own CLI installed and its own login or subscription.
