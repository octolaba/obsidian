# davidvkimball/obsidian-link-as

Obsidian plugin that links selected text to any note while keeping the selection as the display text, which the built-in wrap does not do because it treats the selection as the link target instead. It can also run with nothing selected, prompting for display text or falling back to the note's title, and it never writes to the target note's properties, producing inline links only. It follows the vault's configured link format, wikilink or Markdown and shortest path, and omits an alias that merely repeats the file name. The README notes that its note picker lists notes by their title property when the author's separate Property Over File Name plugin is present.
