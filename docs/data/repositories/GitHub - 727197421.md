# chrisgrieser/obsidian-quadro

Quadro is an Obsidian plugin for social-scientific qualitative data analysis, presented as an open alternative to MAXQDA and atlas.ti that stores data and research codes as Markdown, supporting coding in the Grounded Theory tradition and extraction following Qualitative Content Analysis. Analysis rests on two file types: Data Files holding the empirical material, split into small segments because codes are assigned to whole paragraphs, and Code Files in a configurable folder; assigning a code appends a link and a timestamp id to the paragraph and an embedded block link back to that paragraph in the Code File. The README records the caveat that assignment below paragraph level is limited to highlighting, with codes on individual words and overlapping coded segments unsupported, and that Quadro modifies some core Obsidian behaviour, which is one reason a separate vault is recommended.
