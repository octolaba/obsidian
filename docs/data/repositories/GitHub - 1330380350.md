# jimmieldavisjr/microsoft-todo-obsidian

This plugin adds a sidebar panel that lists Microsoft To Do lists and tasks through Microsoft Graph, so completing, adding, renaming, starring or setting a due date acts on the same account reached from Outlook or a phone. Commands send the current note or a selected passage to a list as a task, with a link back to the note. Sign-in uses a device code pasted into Microsoft's page in a browser, and the resulting token is stored unencrypted in the plugin's folder inside the vault; no other files are written into the vault. My Day is reconstructed locally from everything due today or overdue across all lists, because the real list is not exposed to outside apps, and checkboxes written in notes are left as plain text.
