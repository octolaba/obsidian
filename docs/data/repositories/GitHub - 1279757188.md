# masaki39/obsidian-ai-rewrite

AI Rewrite rewrites the current line or the selection in an Obsidian note on demand, rather than completing the next word as you type. The result appears as a ghost preview below the line, applied with Tab and dismissed with Esc, and the plugin ships Proofread and Translate modes that a user can extend with their own. It talks to any OpenAI-compatible server — Ollama by default, and also LM Studio, OpenAI or OpenRouter — a line-level design the README attributes to keeping work small enough for local models.
