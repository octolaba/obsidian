# jeansordes/dot-navigator

Repository for Dot Navigator, an Obsidian plugin that manages notes in a hierarchical tree in the manner of Dendron, driven by dotted note names. The README states that it caches the tree structure in IndexedDB so the view loads immediately even in large vaults, that it was designed for mobile before desktop with lazy loading of suggestions, and that expanded state persists across sessions, with horizontal scrolling for deeply nested structures. Rule-based suggestions are edited in settings — patterns with children, previewed matches, reordering, and JSON import or export — and dotted children become nested suggestion nodes that a double-click turns into real notes. Compatibility with Dendron-structured notes is described as partial and not guaranteed in future.
