# callumalpass/tasknotes

TaskNotes manages tasks in Obsidian as separate Markdown notes, each carrying YAML frontmatter, and drives every view through an Obsidian Bases query. The README states that the task list, kanban, calendar and agenda views are plain base files that can be edited directly or duplicated into new views, that extra frontmatter fields such as an energy level or a client become immediately available for filtering and grouping, and that no plugin-specific database exists, so the tasks stay readable and transformable by other tools. A create command parses natural language, extracting a due date and a context from a typed sentence, and further commands open the individual views.
