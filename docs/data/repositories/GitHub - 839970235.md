# hjamet/Canvas-Explorer

Explores a vault by walking its links: notes are added to or ignored from an exploration stack, and the preserved notes and their connections are then written out as a canvas. The README describes starting from an open note, using Add Note and Ignore Note commands to move through the suggested linked notes, and naming the canvas when the exploration ends. Settings cover the folder the canvases are saved in, node width and height, a frontmatter property or creation date to sort by, sections to exclude from notes, and options to concatenate note content into a separate summary node and to colour notes by their number of connections.
