# Arcadia-Studio/obsidian-arcadia-connect

An Obsidian plugin that keeps a personal CRM inside the vault: typing @ in any note opens a fuzzy-matched dropdown that links a contact, person notes hold email, phone, organization, role and follow-up dates in frontmatter, and a sidebar panel lists and sorts all contacts. Calls, emails, meetings and notes can be logged into a contact's note, hover cards show a compact profile in reading view, and an hourly check raises notices for overdue and due-today follow-ups. The README places a deal pipeline board, a cross-contact interaction timeline and AI follow-up suggestions behind a premium license key, with the AI features using the reader's own API key, and states that the data stays in the vault.
