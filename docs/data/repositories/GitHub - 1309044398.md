# xmachinesai/mercenai-vault-sync

MERCENAI Vault Sync connects an Obsidian vault to a MERCENAI knowledge base, reading Markdown notes through Obsidian's Vault API and synchronizing them once the connection has been started from the MERCENAI dashboard; afterwards it syncs again whenever a note is created, modified, renamed or deleted. The README records Obsidian 1.11.4 or newer, an active MERCENAI account and an internet connection as requirements. On data handling it states that only non-empty Markdown files are synchronized, that each note's vault-relative path and content are sent to the endpoint the dashboard connection selects, that the connection token is kept in Obsidian SecretStorage rather than the plugin's data file, and that the plugin modifies no vault files, reads no hidden files and collects no telemetry.
