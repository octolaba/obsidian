# reallygood83/teledian

Telegram Sidebar embeds the Telegram Web client in an Obsidian sidebar panel through an Electron webview, keeping the login across restarts. Settings choose the K or A web version, the left or right panel side, whether the panel opens at startup, and a default bot, user or channel to open on launch. Commands open or toggle the panel, reload the webview, and navigate to the configured username. It is desktop-only and not compatible with Obsidian mobile; the session and messages are handled by Telegram's own web client, and the plugin stores only its local settings.
