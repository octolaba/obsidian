# LostPaul/obsidian-folder-notes

Attaches a note to a folder so that clicking the folder name opens that note instead of only expanding the folder. The README distinguishes it from similar folder-note plugins by opening folder notes through the path, creating folder notes for every existing folder, and supporting templates and Templater. Documentation, download link and a beta channel installed through BRAT are listed in the README.
