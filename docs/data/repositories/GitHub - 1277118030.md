# xwang0176/obsidian-agent-context

No repository description is recorded, so this body is grounded in the README alone. The project is an Obsidian plugin, Local Agent Context, that generates a local, agent-readable index of a vault so an AI agent can see what exists, which folders look relevant and which notes to open next. The README states that the index is produced without LLM calls, embeddings or uploads and that the commands live inside the Obsidian interface, and it names a separate Python version for indexing general local folders such as a code repository.
