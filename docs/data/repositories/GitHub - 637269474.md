# trganda/obsidian-attachment-management

Obsidian plugin that controls where attachments are stored and how they are named, through variables such as notepath, notename, date and md5 in the configured location. An override setting changes the global configuration for a single file, a folder or an extension, and the effective setting is resolved as file, then closest parent folder, then global. Pasted or dropped attachments are renamed automatically, and a command rearranges attachments already linked from Markdown or canvas files so they match the configuration. The README marks that rearrange command as experimental and advises backing up files before running it.
