# Prodigist/ReactiveNotes

ReactiveNotes renders React components written directly in notes, so a note can hold interactive elements alongside its prose. A component is placed in a react code block, must be self-contained within that block and export itself, and the plugin then renders it in the note. The README states that it requires Obsidian 1.4.0 or higher and React 18.2.0, and that the plugin is currently aimed at desktop use with mobile support still under development.
