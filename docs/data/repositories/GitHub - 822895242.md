# jeetsukumaran/obsidian-sidebar-resizer

Sidebar Resizer adjusts the widths of Obsidian's left and right sidebars through commands rather than by dragging. Its commands increase or decrease either sidebar by a configured increment, toggle either sidebar between its standard width and zero width, expand both sidebars to their standard widths, collapse both to zero, and distribute the two evenly to specified percentages. Widths may be given in pixels or in percentages, and the README states that no hotkeys are bound by default.
