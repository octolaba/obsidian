# exoascension/vault-chat

Vault Chat uses OpenAI to provide an assistant that works over the notes in a vault. Four commands are documented: asking ChatGPT about the vault, summarizing a note, semantic search, and chatting about the active note. Using it requires an OpenAI account and an API key entered in the plugin settings. The README states that the plugin indexes the existing vault files when first added, at roughly one minute per hundred files, and that it can be used during indexing although the assistant lacks full context until that finishes.
