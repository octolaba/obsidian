# jvsteiner/mermaid-themes

Mermaid Themes lets Mermaid.js diagrams in Obsidian be given other themes and customized. Two mutually exclusive options are offered: supply a whole Mermaid theme object, or supply only the parts to change, which the plugin merges into the base theme before applying the result to the diagrams. Because the mermaid code fence label is reserved, themed blocks are written with a merm label instead. The README states that the plugin is still in development, that bugs may remain, and that it is supported by advertisements.
