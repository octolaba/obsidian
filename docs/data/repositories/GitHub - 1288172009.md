# miaoziguan/obsidian-bamboo-immortals

Bamboo Immortals turns free-form notes into structured goals, derives daily tasks from quantified subitems, and links completed work to a timeline, in-vault currency, and a staged progression system. It includes review and diagnosis views, configurable modules, visual and ambient features, and optional AI planning through a user-supplied API key; the core workflow is described as local and usable without network access.
