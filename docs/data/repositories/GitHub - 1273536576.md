# MMoMM-org/obsidian-orbital

Obsidian plugin that gathers everything connected to the active note into a single tabbed sidebar pane, reading Obsidian's own link graph with nothing to index or import. Its tabs cover backlinks shown with their surrounding text; relations, meaning outgoing links, deduplicated second-hop notes, unlinked mentions convertible inline and unresolved targets; dangling links across the vault or one folder with preview-confirmed rename, merge, alias conversion, note creation and deletion that otherwise only rewrite link text; and a most-recent-first list of opened notes. A status bar item reports backlink and second-hop counts and opens the pane, a code block renders a note's backlinks inline with folder or tag filters, and that same context view can be appended automatically to the end of every note. It works on desktop and mobile.
