# shadowoption/Hunchly-obsidian-plugin

Converts an exported case from Hunchly, a web capture tool for online investigations, into Obsidian notes, covering its notes and captioned images and adding the Hunchly selector as a tag. A ribbon icon opens a dialog asking for the destination path relative to the vault root, whether notes taken on the same URL should be consolidated into one note, and the path to the exported case archive. The README states that the archive comes from the Export Case option in the Hunchly dashboard.
