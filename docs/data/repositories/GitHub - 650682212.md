# monnierant/obsidian-simple-rss

Simple RSS pulls RSS feeds into the vault as notes. A feed is added in settings with a name and a URL, and optionally a target folder, a feed type, a title pattern and a body template, both written in Mustache so feed and item fields can be interpolated; pulling runs from a button in the menu bar. A custom feed type declares the top-level feed and item fields to collect, which makes fields outside the generic format available to the templates.
