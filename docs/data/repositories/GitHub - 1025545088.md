# infinitesum/obsidian-emoji-selector

Emoji Selector inserts custom emojis into Obsidian notes, either by typing a trigger sequence (:: by default) or from a selector panel opened from the toolbar or the command palette. The README states that emoji packs are loaded from remote or local OWO-format JSON files and images configured in settings, and that search supports both fuzzy and regular-expression matching. Insertion templates and CSS styles are customizable, and keyboard shortcuts cover pack switching, multi-select, navigation and selection.
