# MichelleGDyason/The_Obsidian_Deleometer_v2

The Deleometer is a journaling plugin that analyses entries from several perspectives, generates goals and offers a reflective chat over them. Its README states plainly that it is not a medical device, diagnosis or treatment and is no substitute for therapy, crisis support or professional care, and that AI responses should be treated as material to question and revise rather than as truth. Analyses, chats, goals, author memory and settings are stored locally in the vault, while AI features send the relevant context to the provider chosen in settings, either OpenAI or a local Ollama endpoint which the README says never falls back silently to OpenAI. The settings carry privacy controls for redacting sensitive details before a call, keeping author memory local, excluding the personality profile from prompts, and clearing the stored memory or key.
