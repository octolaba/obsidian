# EricRhysTaylor/editorialist

Editorialist imports batches of editorial feedback — from human editors, beta readers or an AI conversation — into the scene notes of a manuscript and walks through each suggestion. The README states that importing a batch appends review blocks to the bottom of the targeted notes and applies nothing to the prose until the reader accepts, rejects, rewrites, defers or archives a suggestion, while a review panel records contributor stats, revision history and per-scene progress. It also describes Editorialisms, separate structural checklist files whose directives can carry verbatim anchors used as jump targets, and states that the plugin ships a text format rather than an AI: it makes no network call and holds no API keys.
