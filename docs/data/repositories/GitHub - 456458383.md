# Signynt/insert-heading-link

The recorded description says the plugin adds a link to a heading. The README explains that it contributes one command which inserts a link to the nearest heading above the cursor, at the cursor position, in Obsidian's heading-link form. The command is run from the command palette or from a hotkey the user assigns, and the plugin is installed from the community plugins browser.
