# Brightwav3/clipping-note

Obsidian plugin that creates a clipping note from a template with one click, modelled on the core daily note and unique note plugins. The README states that a scissors ribbon icon or a command writes a new file into a clippings folder, named by date and time with the colon replaced by a hyphen so the filename stays valid, and fills the body from a template using the same placeholders the core plugins use. It also states that the target folder is created if missing, that a numeric suffix avoids name collisions, and that the interface is English with a Czech localization toggle.
