# gaedol/gtd-flow

The repository holds GTD Flow, an Obsidian plugin for GTD-style project and task management written entirely in plain Markdown, with projects as notes carrying a type property and tasks as ordinary checklist lines that remain readable without the plugin. The README records availability logic in which a task counts as next only when its project is active, its defer date has passed and, in a sequential project, everything before it is done, with indented action groups blocked until their children finish. Dates, times, durations and repeats use the Tasks plugin's emoji syntax so both can share files, and statuses cover to-do, in-progress, done and dropped with closure reasons. Recorded views are Next Actions, Forecast, a Mermaid Gantt timeline, Review and Perspectives, alongside quick capture from a modal, a command or a URL, contexts as hierarchical tags, and per-project review intervals.
