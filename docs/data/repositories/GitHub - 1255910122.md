# Bisiaux-dev/obsidian-lore-graph

Lore Graph hides whole folders from Obsidian's graph view and reveals their notes on demand when a related node is used, aimed at vaults where journal, inbox or archive notes make the graph unreadable. Hidden notes are never removed: their positions and edges are kept and only their transparency and interactivity are toggled, so hovering a visible node fans its hidden neighbours in as a preview, a first click pins the reveal, clicking a revealed node cascades from it, a second click opens the note and clicking empty space resets the session. Settings list the hidden folders, cap how many nodes a click may reveal and toggle the feature globally. The README marks the plugin as early development and states that it hooks undocumented internal APIs of the graph renderer, isolated in a single adapter file, so Obsidian updates may break it.
