# seanrcollings/orion-publish-plugin

Orion Publish publishes a note to the web so that it can be shared with others. Its commands publish the current note, update a note that is already published, unpublish it again, and copy the published note's URL to the clipboard. The site is hosted by the author and its source is available for self-hosting, while a custom domain can be set in the plugin settings.
