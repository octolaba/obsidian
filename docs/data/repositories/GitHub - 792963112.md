# sakurastral/obsidian-march-theme

March is a colorful, accent-aware Obsidian theme with a warm light appearance and an accent-tinted dark one, staying close to Obsidian's native behavior. Headings are color-coded with configurable size, alignment, color and indicators, code blocks carry line numbers, and alternate task states cover in progress, planned, review, done and canceled. Optional Catppuccin and Nord color schemes, a colorful frame layout, compact pinned tabs and file-type icons are available, along with styling for Bases and image helpers that center an embedded image or crop it to a circle. The theme works on its own, while the Style Settings plugin exposes its color scheme, editor and layout controls.
