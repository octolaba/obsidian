# ryanjamurphy/vantage-obsidian

Vantage is an advanced search builder for Obsidian: it helps compose complex queries using Obsidian's own native search tools rather than replacing them. The README's changelog records a NOT query option added in v1.2.0, a ribbon button that opens the Vantage modal added in v1.1.0, and fixes to the order of plugin checks and to the notice reporting that Natural Language Dates is not installed.
