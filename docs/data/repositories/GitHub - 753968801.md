# ifree/Obsidian-canvas-minimap

Adds a minimap to Obsidian Canvas notes, so a large canvas can be surveyed and navigated. The README states that the minimap is enabled from the command palette or the settings, that clicking on it moves to the corresponding position on the canvas, and that the navigation behaviour is configurable. It also records a caveat from the author: Obsidian publishes no public API for plugins to reach the canvas object, so the plugin uses a workaround that may be unstable and may break in future.
