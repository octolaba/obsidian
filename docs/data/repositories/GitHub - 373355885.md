# Benature/obsidian-text-format

Obsidian plugin that reformats selected text. It converts case to lowercase, uppercase, capitalised or title case and removes redundant spaces and newline characters, and it carries further commands grouped in the README under Markdown grammar, lists, links, problems introduced by copying or OCR — such as the hyphens left by a paste out of a PDF — and academic use. Commands run from the command palette or from custom hotkeys, several of them carry their own settings, and formatting on paste is listed as experimental. Custom wrappers, replacements and a Zotero-oriented conversion of a citation index into a paper note's file name are documented there as well.
