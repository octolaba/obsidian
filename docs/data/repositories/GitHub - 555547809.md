# erykwalder/obsidian-list-style

The repository records no description; its README presents Ordered List Style, a plugin that sets the style of an ordered list inline by putting a style name in braces at the start of the first list item. Any CSS list-style-type name may be used in full, and the README documents shorthands for upper and lower alpha, upper and lower roman, decimal and decimal with a leading zero. It states that the style cannot be changed mid-list or set on any item but the first, and records that on mobile sub-lists may inherit their parent's type unless set back explicitly.
