# erykjj/conversum

Detects scripture references in notes in both editing and reading views, handling common book-name variants and abbreviations, and indexes them into a searchable concordance that can be filtered by book, chapter or verse. Right-clicking a reference lists every note mentioning it, including notes whose ranges contain it, and the whole concordance can be exported as a Markdown file. Source and output languages are configured separately across a list of supported languages, with a frontmatter property overriding the source language for a single note, and settings cover the reference format, automatic reindexing and excluded folders. Whole book names are not detected on their own unless wrapped in braces, and the first index build can take several minutes on a large vault.
