# angelperezasenjo/obsidian-to-jira

The recorded description says the plugin creates and updates Jira issues directly from Obsidian. Per the README it adds three commands: importing an issue's information into a Markdown file inside a new jira-issues directory, which a ribbon icon also triggers; updating an issue in Jira from the key, priority and summary held in the note's frontmatter; and creating a new issue from a frontmatter priority and summary, with the project and issue type chosen through suggestion modals. A username, a password and the API URL are required for authentication.
