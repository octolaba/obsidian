# Skilletron/obsidian-automatic-installation-of-plugins

Installs, enables and configures other community plugins from JSON files kept in a vault's .obsidian folder. One file lists plugin IDs to install, a second maps plugin IDs to settings that are written into each plugin's own data file, and both can be applied on startup or from a command. Plugin IDs are resolved against the community plugin registry on GitHub and the release manifests, then handed to Obsidian's own install routine, always taking the latest release of each listed plugin. Anything installed this way can read vault data and, on desktop, the file system, so the plugin is intended for vaults whose plugin list is trusted.
