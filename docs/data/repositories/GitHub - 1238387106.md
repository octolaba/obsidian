# openagentmarket/openagent-obsidian-plugin

Obsidian plugin that runs local agent workflows from the vault and from Canvas. It connects to an OpenAgent daemon on the same machine, so Codex tasks can be started from selected Canvas nodes or notes, active threads tracked, and results written back into Canvas. It is desktop-only because it relies on local filesystem access and on that daemon connection, which the plugin can start itself or read from a configuration file under the home directory. The README states that it reads selected notes and Canvas nodes, writes task results, follow-up nodes and metadata back to the vault, and talks to the local daemon over HTTP with an authentication token.
