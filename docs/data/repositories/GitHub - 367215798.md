# nathonius/obsidian-collapse-all

Collapse All extends Obsidian's own collapse and expand behaviour with commands that can be bound to hotkeys. Each supported view gets a collapse, an expand and a toggle command, and the command sets can be switched on or off in the settings. The recorded views are the file explorer, the tag pane, search, which has expand and collapse but no toggle, bookmarks, which has only the toggle, and a global set covering all of them.
