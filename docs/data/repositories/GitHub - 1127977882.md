# n1az/json-collapsible

JSON Collapsible renders JSON written in standard json code blocks as an interactive tree whose nodes can be expanded and collapsed inside Obsidian notes. Values are colour-coded by type, covering strings, numbers, booleans and null, and a collapsed node shows the count of items it contains. The README states that it works on desktop and mobile and that no syntax beyond an ordinary JSON code block is required.
