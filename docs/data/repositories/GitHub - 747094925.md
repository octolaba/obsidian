# Benature/obsidian-metadata-icon

Metadata Icon customizes the icon shown for a metadata property entry in Obsidian. Icons may be given as online URLs beginning with an HTTP or HTTPS scheme, as local file paths either relative to the vault or absolute from the computer's root directory, or as base64-encoded images beginning with the data prefix. The README documents installation from the community plugins browser, through BRAT, or manually, and links a short Chinese introduction.
