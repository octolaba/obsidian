# cestfredy/obsidian-canvas-node-screenshot

Takes screenshots of individual nodes on an Obsidian Canvas. The README describes clicking a screenshot icon in the canvas menu, choosing where the captured image should be stored, and saving it. It states the plugin is not ready for the community plugin market and documents installation through BRAT or by unpacking a release into the vault's plugin folder.
