# vrtmrz/ring-a-secretary

Ring a Secretary is a ChatGPT-backed assistant inside Obsidian; the README states that an API key for ChatGPT is required to use it. A dialogue is started with a command from the palette, which opens a chat area in the note. The conversation is stored as a code block, so it can be resumed later and is searchable, and the README notes that a long dialogue consumes many tokens and recommends starting a fresh one instead. Installation is through BRAT by adding the repository as a beta plugin.
