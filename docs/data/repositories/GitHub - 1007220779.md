# abduznik/Obsidian-Game-Giveaways

Fetches game giveaways from several platforms and organizes them into notes sorted into categories such as Epic Games, Steam, PlayStation and Xbox, using the GamePower API named in the recorded description. Each entry records the title, value, description and instructions for claiming it. Updates can run on a custom interval in hours or on a weekly schedule aligned with the Epic Games Store, and a command refreshes giveaways by platform on demand.
