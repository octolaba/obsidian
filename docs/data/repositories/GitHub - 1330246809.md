# felixleopold/notecolab

Shares a note as a web page, delivers it into another user's vault, or opens it for real-time joint editing, with stored note content encrypted on the device. Three access modes exist: an expiring view-only link, which also gives direct recipients a locked, updating copy in Obsidian; an editable link for collaboration in the browser or after import; and invitations to named users identified by a Note Colab user ID. It works against the hosted service, where a fresh install creates an anonymous identity with no email address required, or against a compatible self-hosted server, and switching the server URL creates a new identity rather than moving existing shares. A dashboard manages links, collaborators, shared notes and storage, and automatic acceptance of notes sent to a user ID is off by default.
