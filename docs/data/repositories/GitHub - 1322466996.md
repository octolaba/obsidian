# virbird/Alevel-study

An A-Level study coach for Obsidian that opens a per-subject chat session for unclear concepts, problems the student is stuck on, and essay grading, and logs every request so weak points accumulate over time. Sessions start automatically on entering a subject, offer lettered opening modes for concept drills, economics and IELTS, and end with a conclude step producing self-review notes, error-log rows and an archived session. Wrong answers feed a thirteen-column error ledger with recurrence counts and scheduled reviews, shown in a records view beside concept maps, IELTS grades and an expression library. A global model selector applies to every AI call, context usage is displayed with a configurable auto-compression threshold, and an in-session timer blocks sending until a thinking delay has passed.
