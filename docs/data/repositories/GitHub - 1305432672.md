# samkawsarani/OpenWhispr-to-Obsidian

Obsidian plugin that syncs notes from OpenWhispr, meeting notes with speaker-labelled transcripts included, into a vault folder by driving the official command-line tool instead of an API, which makes it desktop-only. Sync runs from the ribbon icon, the command palette or a manual button, on a fixed frequency from one minute to daily, and optionally when Obsidian starts, and the sections written into each note — personal notes, the AI-cleaned version and the full transcript — are selectable. Files stay flat, sit in date-based subfolders or mirror the source folders, are matched by a recorded identifier so an existing note is overwritten, skipped or kept as a timestamped copy, and carry frontmatter with that identifier, title, folder, timestamps and source. The README states that the plugin makes no network calls of its own, leaving all backend communication to the configured tool.
