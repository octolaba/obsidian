# u-ways/obsidian-path-picker

Path Picker fuzzy-finds any file or directory under a root, by default the vault folder, and then inserts its path at the cursor or opens the entry in Obsidian or in the operating system's default application. Its README records two commands, for directory and file paths, with a Tab toggle between the modes inside the picker, live fuzzy matching with highlighted match positions, and a preview pane showing either a directory tree of configurable depth or the head of a file rendered by Obsidian's own renderer so that it matches the theme. The split between results and preview is resizable and remembered across sessions, and a shortcut switches the root to the home folder, the vault root, one of the last five recent roots, or a typed path.
