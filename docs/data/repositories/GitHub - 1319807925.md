# PavelPeng7/omni-reader

Omni Reader is a local-first EPUB 2 and 3 reader offering paginated and scrolled modes, a nested table of contents, full-book search, restored reading position, bookmarks, and annotations in four colours and four styles, each carrying a note and tags. Annotations are mirrored into a generated Markdown pair under the book's own folder, rewritten only between managed-block comments so surrounding text survives, and each exported entry links back to the exact location in the EPUB. A sidebar filters annotations by tag, chapter, colour and note status, chapters export to Markdown with their images, and reading statistics track active time, remaining time and furthest progress, pausing after two minutes idle. Typography follows the vault's configured font and size before applying its own long-form rhythm, and the interface ships light and dark palettes with no downloaded web fonts.
