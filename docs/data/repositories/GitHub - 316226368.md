# radekkozak/discordian-plugin

Repository for Discordian Plugin, which accompanies the Discordian theme and exposes its options in the Obsidian settings panel. The README states that the plugin is not required to use the theme but is recommended, and lists the settings it offers: Writer Mode, Flat Andy Mode, paragraph focus with a customisable fade out, readable line length, dark note headers as an option for defaults, and font sizes for notes and the file explorer. Contributors are asked to file an issue first and not to build or commit `main.js`, which the CI server generates.
