# tavva/flow

Implements the main processes of the Getting Things Done method inside a vault. It captures items through a command, a ribbon icon or external tools into an inbox, then processes each item into a project, an action, reference material or a someday list. Life areas are organised as spheres holding hierarchical projects, a focus view collects next actions from across the vault, a waiting-for list tracks items delegated to others, and a planning mode builds the focus list by picking actions from sphere views. The README states that the methodology need not be followed rigidly.
