# bangca85/obsidian-memorylane-plugin

MemoryLane builds an interactive timeline in Obsidian for documenting and navigating the events and milestones of a life. Its Memories feature is described in the README as reminiscent of the on-this-day reminders of social media, surfacing anniversaries so past moments can be revisited. The README presents the plugin as suited to personal reflection or historical logging as much as to browsing, and records the MIT licence.
