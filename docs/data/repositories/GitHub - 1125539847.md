# davidvkimball/obsidian-home-base

Home Base is an Obsidian plugin that opens a designated home page in the vault and can return to it on demand. The README records several home types — a specific file, a workspace layout, a random file from the vault or a folder, the graph view, today's journal entry through the Journals plugin, a periodic note, or nothing — plus view modes, opening modes that replace all notes, replace the last note or keep them, a command run on open, auto-scroll and view reversion. Tab behaviour covers opening on startup, replacing new empty tabs with the home base or a separate configured file, and a desktop sticky home icon pinned to the left of the tab bar with a choice of Lucide icon. Separate mobile settings record a different home page, a different new-tab file and a home icon in place of the mobile new tab button.
