# RussQuan/slidedope

SlideDope is an editor for single-file HTML presentations kept in the vault, where each deck is one self-contained file that plays in any browser without a runtime or an export step. The editor offers a thumbnail sidebar with drag reordering and multi-select, a slide clipboard for cutting, copying and pasting slides and images, inline text editing with a floating format toolbar, pasted images saved into an images folder and positioned as percentages with snap guides and arrow-key nudging, undo and redo across text, image and structural changes, and section labels previewed as a progress bar. The README records that serialized HTML is normalized on save, with color swatches reading the deck's own CSS variables, relative font sizes, pastes downgraded to plain text and browser-extension markup stripped.
