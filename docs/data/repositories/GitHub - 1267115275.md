# laguna821/hanmark

HanMark is a desktop bridge between Markdown notes and Korean HWP/HWPX documents. It imports HWP, HWPX, PDF, DOCX, and XLSX, and exports HWPX, DOCX, HTML, and PDF through built-in or optional engines. The documented 2.5.6 workflow includes Kordoc-backed HWPX generation, reusable templates and styles, image embedding, and a unified export center.
