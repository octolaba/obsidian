# bfloydd/ontask

Task management plugin for Obsidian that collects standard Markdown checkboxes written anywhere in the vault into a single dashboard view. It offers automatic day planning, sub-tasks, today and week views, quick filters, status tracking with customisable symbols, and a top task shown in the status bar. The README also records an integration with the author's Streams plugin.
