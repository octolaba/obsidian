# jdsimcoe/obsidian-mirror

Mirror turns full-line block embeds into live transclusion: in Live Preview the embed becomes an editable mirrored block, in Reading View a simplified rendering, and editing in either place updates the same underlying content. A copy button added to linked mentions in the backlinks sidebar locates the matching block, creates a block reference identifier when one is missing, and copies an embed-ready reference. An `@mention` search started from the editor finds matching text anywhere in the vault, generates an identifier when needed and inserts the reference. The README states that the plugin runs locally, sends no note contents to external services, and writes to files only when an action requires it.
