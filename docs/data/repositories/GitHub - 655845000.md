# juanjoarranz/style-text-obsidian-plugin

Style Text lets a reader define any number of custom CSS styles and apply them to the selected text in an Obsidian note. Every defined style becomes a command in the command palette that can optionally be assigned to a hotkey, and styles enabled in the plugin's settings also appear in the editor's context menu, ordered as they are ordered in the settings. A further Remove Style command strips unwanted styling from a selection, a paragraph, or the styled text the cursor sits in front of.
