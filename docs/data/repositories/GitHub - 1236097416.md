# Moonjuun/obsidian-voxnote

VoxNote turns meeting recordings into Markdown notes, transcribing through the Deepgram API with per-speaker timestamps and optionally producing a structured summary through Google Gemini that is backlinked to the transcript. Summary templates are ordinary notes in a vault folder, each declaring its own prompt and output skeleton with placeholders, and a folder created at the vault root holds audio, transcripts, templates and summaries with gitignore rules so recordings and keys stay out of vault sync. Generated notes carry hierarchical tags so transcripts and summaries cluster in graph view, the interface is Korean and English, and the plugin works on mobile. The README records zero retention by default for Deepgram, the summary step as optional and gated on a Gemini key, and a relisting from an earlier plugin id whose users must reinstall.
