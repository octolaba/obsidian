# mattmaiorana/pinned-files

This plugin pins files for quick access and lists them in a compact sidebar view styled like Obsidian's own file rows. Its README records pinning from the command palette or the File Explorer context menu, opening with one click or in a new tab with a modifier, unpinning from a context menu, drag-and-drop reordering on desktop, pin indicators shown in the File Explorer, automatic handling of renamed or deleted files, and periodic reloading of its own data for Obsidian Sync. The README is equally explicit about what the plugin does not do: it does not replace the File Explorer, manage sidebar layout, implement search, use bookmarks or frontmatter as its source of truth, or modify file contents.
