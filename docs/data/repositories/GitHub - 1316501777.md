# sbridel/poetry-notebook

Poetry Notebook adds a tabbed sidebar panel for writing and revising English poetry. Its Syllables tab counts syllables per line and names the meter and rhyme scheme as the poem is typed, drawing stress data from CMUdict with a heuristic fallback, a small override list and an optional Datamuse lookup that is off by default. Other tabs search CMUdict for perfect and slant rhymes, look up synonyms and antonyms against a personal dictionary, fetch definitions and etymology from English Wiktionary on demand, suggest rarer vocabulary on ten built-in themes, and draw random literary words that can be tagged, liked or excluded. A Guide tab holds static reference material on meter, rhyme and classic poem forms, and an experimental Sonorities view analyses sound patterns.
