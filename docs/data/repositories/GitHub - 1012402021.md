# Vlad3Design/Mushin

Vlad3Design/Mushin holds Mushin, an Obsidian theme built around the Japanese zen concept of no-mind and aimed at mental clarity and focus. The README pairs it with the same author's MindfulDo and FadeLine plugins and states that the modular CSS layout snippets by efemkay improve the design, in particular the wide-view setting with a 1500px maximum page width.
