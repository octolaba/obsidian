# brianpetro/smart-chatgpt-obsidian

Smart Chat embeds a web chat surface in a note through a code block and writes the resulting thread URL back into that block, so a conversation can be resumed from the note it belongs to. Separate block types target ChatGPT, Claude, Gemini, Grok, Perplexity, DeepSeek, Google AI Studio, Open WebUI and Kimi, with one combined block covering all providers; the web interfaces are used directly, so no API key is required. Threads are recorded as inline fields marking them active or done, which Dataview queries can list across the vault. Signing in to some providers requires Obsidian's Web viewer core plugin.
