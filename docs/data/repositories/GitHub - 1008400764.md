# ivnmansi/juliaplots

JuliaPlots is an Obsidian plugin that generates function graphs inside the app using Julia. Its README describes rendering 2D and 3D functions from a compact code-block syntax, together with scatter points, x and y ranges, a point count, a graph title and axis labels, and per-function colours and labels. Graph appearance and default parameters can be customised, including colours, line width and dark mode. The README states the plugin works only in the desktop app and requires Julia with the Plots package installed, plus a release file placed in the plugin folder.
