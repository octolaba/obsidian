# giselle-tr/Oat-Latte

Oat Latte is a warm Obsidian theme in soft beige, warm brown and muted cream tones, inspired by oat milk lattes, vintage notebooks and quiet cafes. The README describes a lined notebook paper background, serif typography for long writing sessions, Cascadia Code for inline code and code blocks, latte-inspired text highlights and balanced light and dark modes. Its named fonts are Cormorant Garamond, Libre Baskerville and Cascadia Code, and it lists daily journaling, creative writing, personal knowledge management and long study sessions as the intended uses.
