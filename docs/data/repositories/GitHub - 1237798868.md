# kpaede/svgeditor

SVG Editor brings an SVG-edit based vector editor into the vault, so that .svg files can be created, opened, edited and saved without leaving Obsidian. It is reached from the file menu, a ribbon icon, commands, or a pencil button in the corner of a rendered SVG that the settings can hide; the same settings set the default document size for new files. The editor offers selection, rectangles, ellipses, lines, freehand paths, text, connectors, panning and zooming, a categorised shape library, rulers, grid and snapping in several units, layers with visibility and ordering, an overview panel, fill, stroke, opacity, marker and gradient controls, direct XML editing and image export; the README states that changes are buffered as drafts before being written back to the file.
