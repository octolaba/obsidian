# mnaoumov/obsidian-backlink-cache

Obsidian plugin that maintains a backlink cache to speed up the undocumented app.metadataCache.getBacklinksForFile function, and with it the backlinks pane and other plugins that work with backlinks. The README states the difference matters mostly on large vaults and may be unnoticeable on smaller ones, and that plugin developers dealing with backlinks are the most likely audience. The replacement function also accepts a path as well as a file and offers an awaited safe variant that processes recent changes first, and the plugin includes canvas files in the backlinks of referenced notes and exposes a canvas file's links through app.metadataCache.getCache.
