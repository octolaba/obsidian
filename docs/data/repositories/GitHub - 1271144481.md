# RenoirTian/markitdown-obsidian-importer

A desktop-only Obsidian plugin that imports files, folders, archives, images, audio, web pages and YouTube or Bilibili links into the current vault and converts them into Markdown notes; the README is bilingual Chinese and English. Sources include PDF, Word, PowerPoint and Excel documents, images through OCR, audio through transcription, HTML, text, CSV, JSON, XML and RTF, ZIP archives converted recursively, and whole folders; YouTube imports prefer manual or automatic captions plus metadata, and Bilibili imports take title, uploader, description, pages and subtitles. Files, folders or URLs are dropped into an importer view or dragged into the editor, where a wiki link is inserted at the cursor. Conversion runs through a Python bridge script, and the settings page can create a virtual environment in the vault and install markitdown.
