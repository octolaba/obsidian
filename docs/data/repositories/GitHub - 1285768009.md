# thisiselijah/obsidian-single-click-focusing-plugin

Single Click Focusing changes the Obsidian file explorer so that a single left click focuses an item, matching the macOS Finder interaction model its README names as the motivation. Clicking a file opens it but returns keyboard focus and the focus outline to the explorer, so Enter renames it or the arrow keys navigate without clicking back. Clicking a folder name selects and focuses it without expanding or collapsing it, leaving expansion to the arrow icon at its left.
