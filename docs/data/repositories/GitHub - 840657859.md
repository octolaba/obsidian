# ramandv/obsidian-snippets-manager

Snippets Manager stores text snippets in a Markdown file, or a folder of Markdown files including subfolders, and inserts them by fuzzy search either onto the clipboard or directly at the cursor in the active note. Snippets can additionally be written out in the JSON format an Alfred workflow reads, saved inside the plugin folder at a path the settings panel displays for copying, and can contain Templater syntax when that plugin is installed. Against desktop-only text expansion tools the README records this plugin's own argument that it also works on mobile.
