# Fredrix1/synapse-ai-obsidian

Synapse AI adds a chat side panel that answers questions against the vault through a model the user supplies a key for: Gemini, OpenRouter or any OpenAI-compatible endpoint, including a local Ollama or LM Studio, with several configured and switched between. Notes are pulled into the prompt through links, through the active note or by automatic keyword search; replies stream and can be stopped, regenerated or edited, and an answer or a selected fragment can be saved as a linkable note with frontmatter. The README records optional autosaving of conversations as Markdown, proxy support for geo-blocked regions, an English and Russian interface, and the statement that notes and keys go only to the chosen provider or the user's own proxy. It labels the plugin beta, with semantic search, agents and a local privacy layer on the roadmap.
