# chrislicodes/obsidian-chess-study

A chess study helper and PGN viewer and editor for Obsidian. The README states that a game can be imported as PGN or started fresh, and that comments and arrows added to individual moves are persisted in a JSON file inside the vault. The author describes the motivation as replacing screenshots of positions with something updatable, and says the plugin is not a full analysis board but a support for chess notetaking, unlike existing alternatives that focus on single FEN snapshots.
