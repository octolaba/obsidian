# FoxMaySay/obsidian-zen-mode

Focus Zen Mode is an Obsidian plugin for focused Markdown writing that hides the surrounding workspace interface, keeps the line being edited centred and dims the non-active lines so the current one stands out. Zen mode is entered from a ribbon icon and left with the Escape key. While it is active, moving the mouse to the bottom of the screen opens a floating menu that switches between light, dark and green writing themes. The README is bilingual in English and Chinese.
