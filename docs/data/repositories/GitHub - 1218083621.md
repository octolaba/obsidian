# eChorgi/obsidian-visual-ui-editor

Visual UI Editor is an Obsidian plugin for selecting and modifying interface elements visually. Its README describes a selection mode entered from a toolbar icon in which hovering highlights elements of the same type and a left click opens an editing panel. The panel's controls are an override weight that raises the chance a change takes effect, a force switch that overrides styles not marked important, an erase action that removes a specific element's modification history, a reset for the current session, a document preview that applies changes temporarily, and a save that writes the generated style text into a CSS snippet file in the vault's snippet folder.
