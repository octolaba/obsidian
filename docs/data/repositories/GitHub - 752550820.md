# tdaykin/obsidian_image_collector

Exports every image embedded in the current note to a separate location, run from the command palette or from the note's right-click menu. The README gives the author's reasons for it: converting school notes to LaTeX without picking images out of the attachments directory by hand, and gathering all images associated with a post for upload to a GitHub Pages site.
