# Automattic/harper-obsidian-plugin

Harper is a grammar checking plugin whose engine runs inside Obsidian instead of shipping writing to centralized servers, which the README contrasts with LanguageTool and Grammarly; it adds that Harper explicitly ignores the contents of code fences and inline code blocks and that running on-device avoids network latency. No repository description is recorded, so this body rests on the README alone. The README states that this repository exists to satisfy the Obsidian team's submission requirements while all the plugin code lives in the main Harper monorepo, and it warns that an up-to-date Obsidian installer is expected.
