# mmiksaa/obsidian-protected-note

Protected Note sets a password on Obsidian to hide notes from other people, with optional AES file encryption that the README states is not enabled by default and that the plugin can be used without. Its settings enable or disable the password, with disabling requiring the identity to be verified, select a specific protected folder, lock Obsidian automatically after inactivity, turn off animations such as the lock emoji and the blur transition, and switch on file encryption. The README warns that files should be backed up before encryption is enabled and that files are not encrypted when Obsidian closes, because encryption cannot run at shutdown, so a ribbon icon is provided to encrypt everything on exit.
