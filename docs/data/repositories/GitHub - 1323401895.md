# Alecwce/obsidian-git-facil

GitFacil commits and pushes an Obsidian vault to an existing Git repository from a ribbon rocket icon or a command palette entry. A side panel lists modified files with checkboxes so a subset can be committed, and offers a pull action. The commit message follows a configurable template with a date placeholder, an auto-sync option backs the vault up every few minutes, and a guided three-step wizard sets a vault up without using a terminal. Git must be installed and on the PATH and the vault must already be a repository with a remote configured; each of those is reported as a distinct error.
