# fancive/obsidian-parallel-reader

Parallel Reader splits the Obsidian view between the original note on the left and AI-generated summary cards on the right, highlighting the card matching the scrolled position. Its README records adaptive segmentation in which the model chooses topic boundaries rather than following Markdown headings, streaming responses for OpenAI and Anthropic APIs, more than twenty providers including local Ollama and LM Studio plus command-line agent backends, and a cache keyed on a content hash and a settings fingerprint that shows a stale banner after edits. Cards render through Obsidian's own Markdown renderer, can be copied, edited, deleted or traced back to their source from a context menu, and can be exported as a note or to the clipboard, with interface and output languages selectable.
