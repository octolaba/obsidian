# Kazi-Aidah/always-color-text

Obsidian plugin that assigns colors and highlights to chosen words so they appear automatically throughout the vault in both Live Preview and Reading view. Colors, highlight borders, rounded corners and transparency are set from a picker modal, and per-entry or per-group custom CSS can be enabled for further styling. Matching is controlled per entry through contains, exact, starts-with and ends-with modes, and quick colors and quick styles are exposed in the right-click menu.
