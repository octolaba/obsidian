# christian-luger-at/obsidian-focus-first

Focus First sorts Obsidian tasks into an Eisenhower matrix automatically, deriving urgency from the due date and importance from the priority, so no manual placement is needed; a task can still be pinned to a quadrant with one click and reset again. It reads standard checkbox tasks in the Tasks plugin format, including due dates, priorities and tags, and offers a second Value/Effort matrix in the same view, with dragging between quadrants as a way to reclassify. A triage view lists every task no matrix has judged yet, an ordered focus shortlist supports daily planning methods such as Eat the Frog, Ivy Lee and MITs, size tags filter the matrix to short tasks, and hovering or tapping a task explains why it landed where it did and offers actions with an undo. It works on desktop and mobile in English and German.
