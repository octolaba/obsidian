# x0aa7i/obsidian-neo

Neo is a theme for Obsidian whose README states the goal of keeping the simplicity of the default theme while adding more colours and reworking the interface. Recorded features are dark and light support, mobile support, alternate tabs, heading indicators, a pointer cursor on clickable elements and alternate checkboxes. The README lists styling for the Dataview, Tasks, Kanban, Style Settings, Calendar and Hover Editor plugins, documents a long set of alternate checkbox markers including progress states usable with the Tasks plugin, and states that the theme is designed for the author's personal use.
