# velviagris/obsidian-local-backup

Local Backup automatically creates local backups of an Obsidian vault. The README records backups on startup, on quit and at intervals, a lifecycle setting for old backups, an output path configured per platform, archiving by calling 7-Zip, WinRAR or Bandizip, and retries after failures. Included and excluded directories both accept comma-separated wildcard patterns, where an empty include list backs up the whole vault before the exclusions are applied. It warns that interval backups cost processor and disk resources and that backing up too frequently might cause lag.
