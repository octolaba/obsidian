# diegomarzaa/obsidian-pinned-tabs-customizer

This plugin resizes pinned tabs in Obsidian and gives them custom icons chosen from emojis, symbols or the built-in Obsidian icons. Its README describes several rule sources in priority order: a frontmatter property per file, folder rules that also cover subfolders, pattern rules offered in simple, preset and regex modes with a live preview of matching files, and tag rules matching both frontmatter and inline tags. It also records conflict detection that warns when several rules match one file, shows which files are affected and which rule wins, and offers to reorder the rules.
