# opellen/Loft

Loft uploads images from Obsidian to the user's own Google Drive and replaces local embeds with rendering Markdown image links, keeping the vault small. Pasting or dragging an image into a note uploads it and inserts the link, and a command converts the local images already embedded in the current note or only those inside a selection. The README records OAuth 2.0 device-flow sign-in over Obsidian's request helper on desktop and mobile, a least-privilege Drive scope that only sees the files the plugin creates, a plugin-owned destination folder path with an optional parent folder, and a re-resolve command that repairs or switches every link without re-uploading an image.
