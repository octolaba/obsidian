# ziadloo/obsidian-local-rest-api-second-brain-mcp-extension

An extension plugin for Obsidian Local REST API that registers a second-brain route on the parent plugin's server rather than running its own web server or authentication, and the recorded description presents it as an example of adding routes to that plugin. When a language model queries the vault it runs a local embedding model to find the most relevant notes by meaning, then traverses Obsidian's outgoing links and backlinks breadth-first from those entry points to gather surrounding context, which the README argues is more token-efficient than sending the whole vault. It exposes MCP tools for querying the wiki, fetching a note and building a card, and the README notes that every release ships two deliberately separated sets of artifacts.
