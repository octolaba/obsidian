# cha-yh/transcription-audio-obsidian-plugin

This plugin turns audio linked or embedded in the active note into Markdown by sending it to Google Gemini for transcription, transcript generation or summarization and inserting the result back at the position where the command was run. The README describes prompt-only, transcription and transcription-only modes, time-based chunking with chunk retry for long audio, category classification for transcript-based summarization, template prompt controls for a consistent output structure, and reusable transcript files. A sidebar progress panel reports the detected audio file and size, preparation state, request timings, Gemini token usage and a cancel button. A Google AI API key is required, and the README notes that key storage is unavailable on older Obsidian versions.
