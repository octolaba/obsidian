# chloedia/Obsidian_Quiz_Generator

Turns the notes of a vault into question and answer sets generated by a large language model. Either an OpenAI model such as GPT-4o or a locally installed model served by Ollama can be used, selected in the plugin settings together with an API key and an option limiting the result to ten questions. The README states that the generated quizzes are written to integrate with the Spaced Repetition plugin.
