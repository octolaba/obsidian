# bwya77/autofit-tabs

Obsidian plugin that adjusts tab header widths so each one follows the length of its title rather than truncating the text. Settings cover a maximum tab width, an option leaving pinned tabs with Obsidian's default behaviour, hiding tab icons, icon width and left padding, padding before and after the close button, and how long the resize animation lasts. The tab bar can be scrolled left and right when tabs exceed the available space, and clicking a tab that is off-screen scrolls it into view. The README states the plugin uses caching to limit its performance impact.
