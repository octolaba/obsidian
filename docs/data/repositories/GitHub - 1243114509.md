# zzditto/MovieLog

This repository holds MovieLog, an Obsidian plugin for tracking movie and television watching history, fetching media information from the TMDB API and generating structured watch records. Searches run from the command palette and produce templated Markdown files carrying posters, ratings and synopses, with television series tracked by season including episode lists and watch progress. Every record can be browsed in a card wall view, and personal fields hold the viewer's own thoughts, rating, watch platform and watch status; the README is also available in Chinese.
