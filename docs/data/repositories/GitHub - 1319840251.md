# do-md/domd-obsidian

This plugin connects an Obsidian note to a DoMD collaboration session, adding a people icon to the Markdown view header and an Open current note command; the syncing itself is done by DoMD, a separate macOS desktop app the plugin locates automatically. A session can be joined for shared editing, with each participant's cursor visible, or shared as a read-only link that follows the writing live, and it runs peer-to-peer with no account on either end. Because DoMD watches the file on disk rather than hooking the editor, a save from any program is reduced to the smallest set of edits and streamed to the session, and offline edits merge back without conflicts. Merging happens at the span level, finer than a paragraph and coarser than a keystroke, and a note keeps its session identity in a frontmatter key.
