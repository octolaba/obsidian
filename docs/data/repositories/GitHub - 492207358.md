# AlexW00/obsidian-note-linker

Obsidian plugin that creates links between notes automatically. It checks every note in the vault for references to other note names or their aliases, collects the matches into a list, and leaves the user to select which of them to turn into links. The README advises backing up the vault before applying changes, because the plugin has been tested only by its author and a few beta testers, and records that it is written in Rust compiled to WebAssembly together with TypeScript.
