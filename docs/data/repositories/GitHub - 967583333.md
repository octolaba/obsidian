# JamesCliffordSpratt/macros

The Macros plugin tracks nutrition inside an Obsidian vault, searching foods, generating nutrition Markdown files and rendering interactive macro tables and visualizations. The README records searching across FatSecret, USDA FoodData Central and Open Food Facts with a prioritization that puts Foundation Foods and USDA legacy data ahead of the other sources, barcode lookups through Open Food Facts, live search with fuzzy matching, and manual entry for items missing from the databases. Food files carry calories, protein, fat and carbohydrates plus optional micronutrients, with custom serving sizes scaled automatically and energy displayed in either unit.
