# gabrielbacha/Obsidian-Lucy

gabrielbacha/Obsidian-Lucy holds Lucy, a Notion-inspired theme that its README offers for Obsidian, Typora and Zed. Note titles fade to zero opacity and return when focused, and formatting markers such as heading hashes and emphasis characters are drawn in a semi-transparent colour so that only the parsed text stands out. H1 carries top and bottom accent lines that stretch across the viewport in Live Preview, H2 carries an underline border, and headings scale from H1 to H6 with distinct colour weights for dark and light mode.
