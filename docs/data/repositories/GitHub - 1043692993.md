# azyarashi/obsidian-typst-mate

Typst Mate renders math in Obsidian with Typst instead of MathJax, covering inline math, display math and code blocks, and supporting preambles and templates that the plugin calls processors. The README lists a linter, a Typst source view, bracket jumping and highlighting, symbol completion that can search LaTeX command names, snippets and scripts, inline and code block previews, and background rendering. Font size is taken from Obsidian settings and text color is inherited from the theme, with additional styling options such as vertically centering inline math. The README states that the plugin runs on the mobile app, while importing system fonts and local Typst packages is desktop only, and it records integrations with Excalidraw, Equation Citator and several PDF and image export plugins.
