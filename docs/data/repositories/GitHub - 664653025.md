# gapmiss/badges

Obsidian plugin that displays inline badges written as inline code. The default syntax carries a key and a value, where the key names the type and icon and the value is the text shown; for built-in types such as success the value and the colon can be omitted, and any Lucide icon name works as the key. The README states the value may not contain a pipe or a colon, because both are used as delimiters of the custom syntax.
