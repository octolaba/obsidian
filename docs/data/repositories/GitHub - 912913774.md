# jkom4/obsidian-pdf-writer

PDF Writer adds text annotations to a PDF opened in Obsidian, so PDF forms can be filled in from inside the vault. A toolbar above the viewer sets font size, family and colour from a fixed list of fonts, clicking anywhere on the page places an editable text zone, and an existing zone can be selected and restyled, dragged to a new position or deleted. Annotations are saved and reloaded automatically, and the annotated PDF can be exported with the text layers embedded.
