# duoani/obsidian-habit-tracker

The repository holds the Obsidian Habit Tracker plugin, which draws a month view of punch-in records from a code block. Its README documents a habitt block whose entries set the month, the days punched in with an optional tag per day — a check mark being supplied when none is given — and a width constraint for the rendered table. It records that rich text such as links or images requires an enable-HTML setting that is off by default, which the README attributes to security.
