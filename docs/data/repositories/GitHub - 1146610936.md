# kharbacheuski/obsidian-notes-dashboard

Notes Dashboard turns a note carrying its frontmatter marker into a board of columns whose cards point at other notes in the vault. Columns are created from the board itself, notes are added to a column through a search field, and cards can be sorted by name, modification date or creation date while displaying each note's tags. The interface is recorded as available in English and Russian, with the README describing the layout as responsive and matching the current theme.
