# AntigmaLabs/ante-obsidian

Desktop-only Obsidian plugin that connects Markdown workflows to the Ante agentic command-line tool, bridging note editing, diff review, interactive sidebars and chat flows with a local agent. The README describes Ante itself as a local-first AI agent runtime written in Rust, roughly a 15MB binary with no dependencies, supporting more than twelve providers and able to run offline with local GGUF models. The repository is a monorepo holding the plugin package alongside a TypeScript SDK for spawning and driving the Ante CLI programmatically.
