# tdmarchetta/obsidian-ollama-notes-chat

Obsidian plugin that adds a right-sidebar chat panel talking to a remote Ollama server over its native chat API, with streaming responses and replies rendered by Obsidian's own Markdown renderer. Context is chosen per conversation — the current note, a selection, the note plus its one-hop links, the whole folder, passages retrieved from across the vault, or nothing at all — and both the chat model and the retrieval embedder can be switched from the panel. Retrieval builds its index incrementally in the background, re-embeds on edits and renames, and renders its citations as clickable note links. The panel also carries editable slash commands, per-note frontmatter overrides, saving a conversation to a note, inserting a reply at the cursor, regeneration, a token estimate and multi-session history.
