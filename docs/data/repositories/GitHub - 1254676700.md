# jagajaga/private-quartz-publish

Private Quartz Publish marks individual notes or whole folders in an Obsidian vault for publication to a self-hosted Quartz site, writing the choice into frontmatter while the rendering and serving happen on a small docker stack that the README says the user must run themselves. Published items get random unguessable slugs, so a note URL reveals nothing about other notes, a folder URL exposes only the notes bundled with it, filenames and vault structure never appear in URLs or HTML, and guessed paths and a sitemap answer 404. A folder URL renders a landing page with a sidebar of the bundled notes that persists while navigating within the bundle, whereas a direct file URL renders the note alone.
