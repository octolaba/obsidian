# alangrainger/obsidian-frontmatter-modified-date

This repository holds Update modified date, described upstream as automatically updating a frontmatter modified date field. The README stresses that the value does not come from the filesystem modification time: it is written only when the note is actually worked on inside Obsidian. Configurable options include the property name, a MomentJS date format that may embed literal text such as link brackets, excluded folders for scripts and templates, and an option to react to typing events rather than Obsidian editor events, so that other plugins and external tools do not trigger an update.
