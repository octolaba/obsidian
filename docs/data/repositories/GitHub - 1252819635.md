# Andrewkfb/obsidian-mission-control

Mission Control opens a dashboard as a home tab, built by scanning a configured vault folder recursively for Markdown tasks. It shows today's and upcoming tasks with due, scheduled, overdue, priority and in-progress states, project summaries grouped by source note and heading, a recurring-task overview that creates the next occurrence when one is completed, and tabs for an inbox folder, Obsidian bookmarks and recent files. Task lines are read in the syntax used by the Tasks and Dataview plugins, covering open, complete, in-progress and cancelled states and due, scheduled, start, completion and created dates, though neither plugin is required. Search uses Omnisearch for full text when installed and falls back to filenames and aliases otherwise, and the startup behaviour, visible tabs, title, logo, fonts and colours are configurable.
