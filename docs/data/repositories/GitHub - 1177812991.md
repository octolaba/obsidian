# yonge123/obsidian-nodegraph-plugin

An Obsidian plugin that visualizes the links between Markdown files as an interactive force-directed graph; the README calls it a copy of the same author's mkdocs-nodegraph project. Clicking a node opens the file, Ctrl or Cmd click opens it in a new tab, and Alt click opens the URL from an mdfile_site frontmatter key, while frontmatter can also set a node icon and colour. The panel offers filename search with keyboard cycling, physics sliders, saved layouts and preferences, home and reset controls, toggles for physics, nodes and grid, and automatic refresh when Markdown files are created, deleted or modified.
