# Epistemic-Technology/obsidian-github-tasks

Imports GitHub issues and pull requests assigned to or opened by the user into one Obsidian note as tasks, in either the Tasks emoji format or the Dataview format. Labels and repository names can be imported as tags, closed items are marked completed, and a configurable interval refreshes the note. The README states the sync runs only from GitHub, so completing a task in Obsidian does not change its GitHub status, and that edits such as an added due date survive a refresh because only completion status and date are updated.
