# mrrepac/obsidian-md-reader

MD Reader renders an Obsidian note as fixed-size pages that are flipped sideways by swiping, tapping the screen edges, using the keyboard or the mouse wheel, in a single page or a two-page spread, on desktop and mobile. It also imports FB2, EPUB and TXT books into Markdown so a library lives in the vault as ordinary notes. Reading position is remembered as a fraction of the whole book so it survives font, width and theme changes, and the reader adds a table of contents, full-book search, bookmarks, a scrubbable progress bar, chapter-wise stepping and an estimate of time left drawn from measured reading speed. An appearance panel adjusts font size, line height, margins, width, tint, brightness and page mode without leaving the book.
