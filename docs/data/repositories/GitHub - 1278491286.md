# k2ak3n/noesis

noesis is an Obsidian theme for technical notes, research and long-form writing, with coordinated default and Hack The Box presets in light and dark and Pristine light and Neutral Graphite dark surfaces by default. Tabs, ribbon icons, file explorer items and side panes are styled as one system, and Properties, tags, search, backlinks, graph, canvas, dialogs and print output are covered as well. It adds custom callouts for documentation, operations and security assessment work, such as decision, definition, scope, recon, finding, vulnerability, exploit, remediation, timeline and attack chain, plus distinct styling for priority task markers. Syntax palettes and contrast levels are selectable for Codeboxes, further controls come from Style Settings, and the theme works offline with no remote images or fonts.
