# cyne-wulf/obsidian-negative-heading

This repository holds Negative Heading, an Obsidian plugin that renders Discord-style lines beginning with a hyphen and a hash as compact, muted headings in Reading View, Live Preview and Source Mode. Reading View emits a semantic heading element at aria-level 7, Source Mode and Live Preview use CodeMirror decorations, and the marker itself is dimmed using the theme's muted and faint text variables. The README also records a toggle command that adds or removes the token by majority detection, support inside list items, an escape sequence that renders the marker literally, and skipping of fenced code, math blocks and inline code.
