# kpaede/Excerpt-Outline-Mindmap-Editor

Obsidian plugin that works with a Markdown outline as a visual mindmap, aimed at literature excerpting and research notes where a spatial view helps. A node is simply a Markdown list item, and dragging one node onto another inserts it as a sibling before or after, or as first or last child, depending on which of four zones of the target it is dropped on; the node's whole subtree moves with it and the result is written back to the outline. The README states that there is no separate database or proprietary file format, that nodes can be greyed out with checkboxes, and that Obsidian 1.8.7 or newer is required on desktop and mobile.
