# cemtan/all-outline

Obsidian plugin providing one outline panel for both Markdown notes and PDF documents, which follows whichever file is active. A Markdown outline is built from real headings and updates as the note changes, while a PDF outline comes from the document's bookmarks and navigates through Obsidian deep links with page, offset and zoom, falling back gracefully when precise offsets are absent. The panel keeps the selected heading highlighted across file switches, remembers expand and collapse state per file, offers expand-all and collapse-all, searches outline titles, and can show right-aligned page number badges. A setting hides Obsidian's built-in PDF table-of-contents and thumbnail sidebar.
