# chad-bennett/al-dente-obsidian-theme

al dente is a simple, minimal Obsidian theme whose README states plainly that it is no longer maintained and that the author intends to remove it from the community themes hub while leaving the repository in place. The current variation pulls colours from the same author's warmth theme and is installed by placing one CSS file in the vault themes folder and selecting it under Appearance. Its README records that the light version is more complete than the dark one, that the theme started from the BENFW theme and has been tinkered with since, and that fonts can be changed through the variables at the top of the file, with Poppins in use.
