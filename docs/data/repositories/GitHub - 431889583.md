# tth05/obsidian-completr

Auto-completion plugin for the Obsidian editor, whose README states that the legacy editor is not supported. It lists LaTeX completion that does not require a leading backslash and covers MathJax commands, environment completion and snippets with placeholders, YAML front matter completion that learns keys and their values, word lists loaded from files, and scanning the current file or the whole vault for new words. Suggestions can be blacklisted through a file in the plugin folder or with a hotkey.
