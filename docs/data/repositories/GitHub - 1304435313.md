# nicolascereijo/obsidian-vitela

Vitela is a serif Obsidian theme for long-form reading and writing, using Lora for body text, EB Garamond for quotations and IBM Plex Mono for code. The README describes justified paragraphs with automatic hyphenation, a restrained teal accent in place of Obsidian's default purple, rem-based font sizes that follow the reader's preferred text size, bundled rather than remotely loaded fonts, and a matching publish stylesheet. It adds three custom callouts that reuse Obsidian's callout syntax purely for layout: two-column text, a centered epigraph, and a verse block that keeps a poem's own line breaks.
