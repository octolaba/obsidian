# pjeurien/obsidian-audio-sidebar

An Obsidian plugin that plays music, one-shot sound effects and looping ambience during play sessions from a persistent right-sidebar player. Folder-based music playback supports crossfading with a configurable duration or an optional overlap mode, ambience loops fade in and out, effects fade on stop, and a now-playing panel lists everything active with elapsed time and stop controls alongside master, music, SFX and loop volume sliders. Audio can also be triggered from Markdown code blocks embedded in notes — a sidebar loader for a folder, a one-shot effect, a loop — with a file-explorer context menu that copies ready-to-paste blocks, and a scene creator that combines a track and several loops into one note button.
