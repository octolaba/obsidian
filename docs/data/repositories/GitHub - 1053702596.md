# m-kk/toc

Table of Contents Generator builds a table of contents from a note's headings and tracks it through a small YAML frontmatter key rather than through visible HTML markers. The README states that the section is matched only by its heading title, that regenerating an unchanged note produces byte-identical content, and that entries are heading links that work in preview and live preview. Settings cover a depth cap, exclusion of level 1 headings, regular-expression heading exclusion, plain-text instead of clickable entries, a custom title, optional debounced auto-update, and a command that removes the section together with its frontmatter key.
