# Raphlette/obsidian-new-tab-plus

New Tab + is an Obsidian plugin that makes opening in a new tab the default behaviour for Markdown files, graphs, canvases, images, audio, video and PDFs. A toggleable option focuses an already open tab instead of opening a duplicate when the file or canvas is opened again. The README states that this is its author's first Obsidian plugin project and asks for unwanted behaviour to be reported on GitHub.
