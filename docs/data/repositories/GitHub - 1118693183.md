# naoki-mizuno/obsidian-modal-keys

Modal Keys Remapper changes the keys that move the selection in Obsidian's modal dialogs and suggestion lists, defaulting to Ctrl+n for down and Ctrl+p for up while leaving confirm and close unset so Obsidian's own Enter and Escape apply. Up to ten shortcuts can be recorded per action, and target CSS classes decide which elements respond, defaulting to the suggestion and modal containers. The README warns that explicitly binding confirm or close to Obsidian's own keys while targeting the editor makes a single keypress be processed twice, and records that hotkeys take precedence over the plugin's settings.
