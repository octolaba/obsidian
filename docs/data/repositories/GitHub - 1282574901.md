# GuilhermeTagliati/neon-dreams-obsidian-theme

GuilhermeTagliati/neon-dreams-obsidian-theme holds Neon Dreams, a dark Obsidian theme with near-black blue backgrounds, structured panels, thin borders and indigo as the default accent, built for knowledge management, journaling and project tracking. Its entire palette derives from two HSL hues, so changing the background and accent hue variables moves every heading, link, border and interactive element with it, and a light variant is calculated from the same tokens. The README exposes further colours and toggles through the Style Settings plugin and states that the author built the theme mostly for himself, so it may not fit every use case.
