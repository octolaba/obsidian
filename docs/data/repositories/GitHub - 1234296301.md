# Fleker/spotify-organizer-for-obsidian

Repository for Spotify Sorter, a plugin that finds liked songs in a Spotify library which are not in any playlist and writes them into a note. Its README states that the plugin is desktop only, and that it requires a Spotify developer application whose client identifier and secret are entered in the settings and whose redirect address must be registered as an Obsidian URL.
