# luhaifeng666/obsidian-text2audio

Text2Audio converts text from an Obsidian note into audio. The README records Microsoft's Azure text-to-speech service as a prerequisite, and walks through creating a speech service resource in the Azure portal and entering the resulting speech key and region, plus an optional output directory, into the plugin settings. The documentation is published in English, Simplified Chinese and Traditional Chinese versions.
