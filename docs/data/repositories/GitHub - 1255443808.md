# carnalMATRIX/obsidian-mantle-calendar

Mantle Calendar adds a calendar interface inside an Obsidian vault for schedules, milestones and task events. The README records daily and monthly views, double-clicking a day or event to generate, open or link a Markdown file, a layout that scales into sidebars, tabs or split panes, and parallax patterns and card designs it describes as minimal. Its troubleshooting section ties event linking to a configured default folder for daily notes and to filesystem-safe note names, and it states that the plugin follows the Project Mantle design guidelines and pairs with the Zenith theme while running on any Obsidian theme.
