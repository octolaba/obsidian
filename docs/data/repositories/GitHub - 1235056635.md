# xlongfeng/obsidian-vim-scrolling

Vim Scrolling adds vim-style scrolling to Obsidian's reading view, which the README explains renders static HTML with no editor, so the built-in vim key bindings powered by CodeMirror do nothing there. The mapped keys scroll a line with j and k, half a page with Ctrl+d and Ctrl+u, and to the top or bottom with gg and G, active only in reading view and only while vim key bindings are enabled. Scrolling sets the scroll position directly with no animation so held keys repeat without queuing lag, gg is recognised when the second g arrives within 500 ms, and switching back to source mode moves the cursor to the first editable line of the viewport when it would otherwise sit outside the visible content.
