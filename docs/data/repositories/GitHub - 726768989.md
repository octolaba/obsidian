# pfrankov/obsidian-local-gpt

Local GPT provides assistance inside Obsidian from Ollama and OpenAI-like models, which the repository description frames as being for maximum privacy and offline access. A context menu on selected text picks an assistant action, or an action palette runs a one-time action, with default actions covering continuing writing, summarizing, fixing spelling and grammar, finding action items and general help from the selected text as a prompt. The README also records working with images, using context from links, backlinks and PDF files through an embedding model, and community actions that are browsed and installed from the plugin settings and auto-update until their prompt is modified.
