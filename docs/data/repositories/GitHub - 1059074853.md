# uthvah/sync-embeds

Sync Embeds turns standard Obsidian transclusions into editable, two-way synced blocks, so an embed can be edited where it appears and the change is written back to the source note. The README explains the mechanism: the plugin opens a hidden editor pane for the source note and re-parents its visual part into the current document, which is what makes ordinary editor hotkeys work inside an embed. It also lists section embeds addressed by header, enforcement of header hierarchy, custom display names in place of raw file paths, and date-based dynamic patterns for daily notes.
