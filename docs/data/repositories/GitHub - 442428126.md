# Gru80/obsidian-timestamper

Time Stamper inserts date and time stamps into the currently active note. Two format strings are pre-configured in the settings and inserted by command or hotkey, a dialog allows an ad-hoc format that is remembered as the next suggestion, and an option adds a line break after the inserted stamp. The README states that both the desktop and the mobile versions of Obsidian are supported.
