# ArtemisLin/obsidian-milk-tea-theme

ArtemisLin/obsidian-milk-tea-theme holds Milk Tea, a warm Obsidian theme with light and dark modes whose palette the README attributes to Claude's desktop application: a #FAF6F0 creamy beige background with a terracotta #D97757 accent, and a #2A2420 warm brown for dark mode. It is presented as a companion to the same author's Milk Tea theme for Visual Studio Code and shares its syntax colours. The README lists eight Style Settings options covering accent colour, radius, fonts, size, line height and heading and bold weights.
