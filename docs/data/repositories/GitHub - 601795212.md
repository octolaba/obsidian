# Cleoche/obsidian-callout-integrator

Turns a long block of text into a callout by inserting a quote marker at each line break inside the highlighted selection. The README documents two operations, Integrate, which adds the marker at the beginning of each line, and Un-Integrate, which removes it again; both can be bound to hotkeys or run from the command palette. It also describes adding both commands to the mobile editor toolbar through the mobile settings.
