# tzamtzis/obsidian-transcription-plugin

An Obsidian plugin that transcribes audio files such as m4a and mp3 and then analyses the transcript to extract summaries, key points, action items and follow-up questions, saving the result as Markdown in the vault. The README states multilingual transcription with automatic language detection through Whisper, a choice between local processing and cloud APIs, speaker identification, support for recordings over two hours, and custom analysis instructions. First use prompts for a transcription model download, with a medium model of about 1.5 GB recommended.
