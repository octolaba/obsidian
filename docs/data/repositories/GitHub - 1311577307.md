# thenights20/obsidian-bible-reference-index

The repository records no description, so this note is grounded in the README alone, which is written in Brazilian Portuguese. Indice Nights builds an index of Bible references in an Obsidian vault together with a local library of Portuguese transcripts, offering a menu of the 66 books in biblical order, global search by reference, talk title or subfolder, internal links to the related notes, and automatic index updates when notes are created, changed, renamed or deleted. Seven transcript collections are offered, the chosen collections and destination folders are stored per device, and only new transcripts are downloaded because existing notes are recognised by an origin id. The README also records recursive import of TXT, Markdown and Google Docs files from a public Google Drive folder link without an API or login, preserving public subfolders and matching existing notes by a remote id.
