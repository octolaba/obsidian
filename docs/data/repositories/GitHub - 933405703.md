# Abdo-reda/obsidian-sticky-notes-plugin

This plugin adds a popout window styled as a sticky note on top of Obsidian's existing popout functionality, with a cleaner look, a pin action and colour options. A sticky note is opened from a ribbon action, a command or a context menu, and the recorded commands open one, create one, and destroy all of them at once. Settings cover the sticky note path, whether the workspace is saved, taskbar visibility, the default pin mode, default size and resizability, and the background colours including whether recent ones are remembered; the README records a dependency on Electron's remote module, because pinning and resizing need access to the main process, and advises backing up notes as a precaution.
