# ceilaolabs/obsidian-s3-sync-and-backup

Repository for a plugin that synchronises a vault and takes scheduled backups through S3-compatible storage such as AWS S3, Cloudflare R2, Backblaze B2 or RustFS. The README describes three-way reconciliation using per-file SHA-256 baselines held locally rather than timestamps or a cloud manifest, optional end-to-end encryption of both synced files and backup snapshots, full-vault snapshots on a configurable interval with retention by age or copy count, and conflict handling that keeps separate local and remote copies instead of discarding one.
