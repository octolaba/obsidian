# Alt-er/obsidian-sync-share

Obsidian plugin that synchronises notes to a private, self-hosted service and publishes selected notes through it. The README presents the two functions as usable independently, so the share side can be used on its own while synchronisation is left to another plugin, and it stresses that the data is stored in a service the user hosts and controls. Getting started means deploying the back-end service, then configuring the plugin with that service's URL and credentials and choosing the notes to sync or publish.
