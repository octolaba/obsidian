# Eccys/obsidian-prayer-times

Fetches daily prayer times from the Aladhan API and inserts them into a note as a table. The location is either chosen manually as a city or detected automatically, and the prayers to display are selected individually. Updates can be set to happen when the vault starts, when a note is opened, or both, and the date format and the choice between twelve-hour and twenty-four-hour times are configurable.
