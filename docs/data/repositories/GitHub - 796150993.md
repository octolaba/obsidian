# alexkurowski/solo-toolkit

Solo RPG Toolkit adds aids for playing tabletop role-playing games, aimed mainly at solo play with a game-master emulator. It rolls dice from a die icon, with a modifier or long tap for an alternative color, and deals from a standard deck of 52 cards with optional jokers and from an oracle major arcana deck. Custom decks are built from folders of images, or from notes listing image URLs, inside a configured vault folder, with per-deck rotation options set in a note and a right-click to shuffle a card back in. It also provides random word generators and custom random tables written as notes in another configured folder, organised into categories by subfolder.
