# marijnbent/obsidian-print

The Print plugin adds printing tools to the Obsidian workspace: the current note, a selection in the active editor, or every Markdown note in a folder. The README states that printing is triggered from the command palette, the printer ribbon, or the context menu on a note or a folder, and that a shortcut can be bound to the print commands under Hotkeys. Its recorded settings decide whether the note title and the note's properties are included in the printout.
