# Lorite/obsidian-unlink-on-delete

Unlink on Delete rewrites the links that pointed at a note once that note is deleted, covering wiki links, embeds, Markdown links and links held in front-matter properties. It works two ways: after an ordinary delete it finds every reference and offers to unlink or leave them, while its own delete command shows what points at the file first, so dismissing the dialog cancels both. Only links resolving to the deleted file are touched, and only after confirming they resolve to nothing else, so deliberately unresolved placeholder links are left alone. Links can also be repointed at a replacement note, keeping any alias and heading, with candidates ranked by signals such as the old name used as an alias, a same or similar name elsewhere, shared rare tags and outgoing links from the deleted note.
