# dreamscached/obsidian-simple-steam-auth

Repository for Simple Steam Auth, a plugin that renders a live Steam Guard code inside a note. The README explains that a code is produced by writing an inline code block containing a marker and the account's shared secret, which the user is expected to obtain themselves, and that the code can be revealed on hover or shown permanently. It gives managing several Steam accounts from one vault as the motivating case.
