# alimoeeny/obsidian-dropbox-photo-grid

Obsidian plugin that embeds a grid of photos from a Dropbox account into a note, selected by date, for daily photos and date-based collections. It accepts folder paths and direct file paths, shows a loading indicator while fetching, handles pagination for large collections, follows Obsidian's theme colours, and can show photos from the same day in previous years. Setup runs through a connect action in the plugin settings that authorises access to the Dropbox account.
