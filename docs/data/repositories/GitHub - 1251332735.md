# yiiwang118/obsidian-glossa

A sidebar workspace in which an assistant works against the vault's own notes: the active note, selections, attached files, PDFs and images can enter context, and every file-changing action runs through visible tools and approval rules rather than being applied silently. Edits are made as patches to a section or an exact string and coordinated across files, so surrounding Markdown is preserved, and checkpointed files can be restored when a change needs rolling back. It can read documents page by page, search PDF text, render pages, run OCR, search bounded public web sources and save validated downloads with their provenance. Built-in skills cover Markdown, Canvas, Bases, PDFs and images and further vault skills can be created and validated; the README records the assistant as starting read-only until writes are approved.
