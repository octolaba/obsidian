# BenRuns/table-calc-plugin

Table Calc evaluates spreadsheet-style formulas written inside Markdown table cells and renders the results inline in both Live Preview and Reading view. A table opts in through a brace-wrapped marker on the line immediately above it; the plugin hides that marker and labels columns with letters and rows with numbers, so a cell can be referenced individually or as a range. Recorded formulas include arithmetic over cell references and functions such as SUM, AVERAGE, MEDIAN, MIN and MAX, and tables without the opt-in marker are left untouched.
