# zachmueller/commonplace-notes

Commonplace Notes publishes a curated subset of an Obsidian vault as a static site with stacked panes, where following a link opens the target note in a new column beside the current one. Sites are self-hosted on AWS using S3 and CloudFront, and the README states that notes are private by default: nothing publishes until a note is opted in with a publishing-context command, which records the profile in `cpn-publish-contexts` and generates a stable per-note UID that drives the note's URL. The Markdown to HTML pipeline is described as user-extensible, and the plugin is desktop-only, in beta at version 0.2.0, requires Obsidian 1.0.0 or later, and is installed through BRAT.
