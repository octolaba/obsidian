# 2607044640/file-undo

File Undo records recent manual file deletions and moves so they can be reverted from inside Obsidian. Undoing a deletion restores the file from the vault's trash folder to its original path, and undoing a move returns a file to its previous folder or name, while a redo command reverses the last undo. The number of remembered operations is configurable and defaults to 200, and both actions are available as command palette entries.
