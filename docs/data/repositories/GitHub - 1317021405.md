# newcodejin/expanded-bookmarks

Expanded Bookmarks adds a bookmark panel alongside Obsidian's core one, with sorting for the whole panel or one group, multi-select for moving or removing several bookmarks at once, hidden bookmarks, per-group and per-type statistics, and an action that moves the bookmarked files themselves into a vault folder. It also adds toggles to the core Search pane for showing only or hiding bookmarked files, and a marker on bookmarked files in the file explorer, both attached to Obsidian interface internals. Bookmarks can be imported from the core plugin or a JSON file and exported back out, with commands to drop duplicates and bookmarks whose file is gone. Its data is stored separately from the core plugin and is not synchronized automatically, so disabling core Bookmarks is suggested to avoid duplication.
