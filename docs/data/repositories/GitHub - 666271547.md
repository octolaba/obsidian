# Lewuathe/obsidian-mlir-syntax-highlight

This Obsidian plugin adds MLIR syntax highlighting for code blocks in the editor. The README describes it as mostly a fork of cm-editor-syntax-highlight-obsidian, reduced to supporting the MLIR syntax alone for simplicity. It documents installation through the community plugins browser, searching there for Syntax Highlight.
