# tgrosinger/pinball-db-obsidian

This plugin tracks a database of pinball machines inside an Obsidian vault. According to its README it creates notes carrying machine details along with deep links to that machine on popular pinball websites, and it records scores per machine. The remainder of the README is development guidance for building, checking and releasing the plugin rather than a description of its behaviour, so nothing further is recorded here.
