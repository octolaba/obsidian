# liyaomingme/thought-synapse-mobile

Thought Synapse (Mobile) is the mobile-only build of a plugin that displays a vault's high-frequency words as an animated three-dimensional cloud, driven by a physics simulation re-engineered for touch input with its own damping for swipes and gestures. Tapping a floating node reveals the words that co-occur with it and offers a jump to the source notes. The README describes the view as an ambient, decorative layer integrated with Obsidian's mobile interface, is written in English and Chinese, and warns that the mobile and desktop builds use different architectures, directing desktop users to the separate desktop release. Installation is recorded through BRAT or by copying the release files manually.
