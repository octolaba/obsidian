# wrsrsh/warblog

WarBlog is an Obsidian plugin for managing an Astro Markdown blog from the vault. Its README says the settings point at the Astro project root, a content folder path, an optional in-vault folder name for the blog, and a password required for updates. Posts then appear in the configured folder for editing in Obsidian, and a single command commits and pushes the current changes to git after the password is entered.
