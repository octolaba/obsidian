# iamrecursion/obsidian-pkvs

Persistent Key-Value Store exposes a key-value store to code running inside Obsidian, so data survives between runs of Templater templates and Dataview or Datacore queries, and between devices when the plugin's data file is synced. The store is reachable in the window scope under the name pkvs, with asynchronous load and store operations, and the plugin ships a portable web inspector to aid debugging. The README states that the plugin is meant to be used from other plugins that execute JavaScript and is not intended to be user-facing, and it warns that serialization uses eval together with a serialization library, so untrusted data must never be stored or loaded and use is at the reader's own risk.
