# GnoxNahte/obsidian-auto-embed

Obsidian plugin that embeds web pages through Markdown syntax rather than an iframe, reusing the syntax Obsidian documents for embedding web pages. A pasted link is converted through a Create Embed action, and options may be given in the syntax before the link. The README lists the supported websites grouped into categories such as social media, naming services including Imgur, CodePen and Steam.
