# usero2/obsidian-plugins-enhance-navigate-pane

Enhance Navigate Pane adds a search bar to the top of Obsidian's native File Explorer that filters files, folders and, optionally, Markdown headings, with multi-term phrase matching and a pipe operator for alternatives. The README states that matching items keep their surrounding folder and heading hierarchy visible, that matches are highlighted, and that the search covers every file extension in the vault rather than Markdown alone. Headings H1 to H6 can be listed inline beneath their file up to a configurable depth and clicked to open the file at that line; custom icons and appearance customization are also offered.
