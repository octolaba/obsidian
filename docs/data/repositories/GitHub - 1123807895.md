# amilleah/obsidian-kitty-plugin

Kitty adds a small animated desktop pet that roams the Obsidian workspace and settles at the bottom of whatever note is being worked on. It ships a cat sprite by Elthen and a Maneki Neko drawn by the author, and custom pixel-art spritesheets can be imported into a sprite library. Settings control whether the pet persists on the same leaf across sessions, whether horizontal movement is allowed, and which sprite is used, while a sprite editor sets frame dimensions, frame scale and frames per second. The pet is toggled from a command palette command.
