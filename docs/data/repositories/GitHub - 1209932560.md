# stefmf/vault-pulse

Vault Pulse renders a GitHub-style activity heatmap of vault file activity as a 53 by 7 grid of the last 365 days in a sidebar pane, with a click on any day listing the files touched then. The README documents a configurable 90, 180 or 365 day window with today anchored at the bottom right, quantile-based colour buckets that adapt to vault size, five palettes including one following the theme accent and one custom hex, a sparkline over the last 30 days, folder and tag filters, streak milestones with a lifetime best, keyboard navigation across the grid, a jump-to-today command, and Style Settings support for the milestone icon colours.
