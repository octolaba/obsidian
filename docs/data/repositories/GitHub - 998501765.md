# Air-Mark/graph-pro

GraphPro adds layout, selection and position tools to Obsidian's native graph view. Node positions can be saved and restored, with a history of saved positions, optional automatic restore on startup, in-memory undo and redo, alignment of selected nodes, precise moving and scaling, arrangement in a circle, unlocking of fixed positions and snapping to a grid that can also be displayed. Selection tools cover rectangle selection while holding Shift, deselection with Alt and Shift, selection by a regular expression matching node IDs, selecting related nodes to a given depth and expanding a selection along backlinks or outgoing links, with a status bar reporting counts and common frontmatter keys. Display options include labels of neighbouring nodes on hover, whose content can be drawn from a regular expression or a frontmatter field.
