# johnfkoo951/cmds-eagle

Obsidian plugin that connects the Eagle asset library to a vault, with cloud upload support. The README describes searching the Eagle library and embedding images into notes, uploading images to ImgHippo, Cloudflare R2, Amazon S3 or WebDAV, handling pasted and dropped images, batch-converting local images in a note to cloud URLs, converting image paths between Mac and Windows, and an Excalidraw integration. It states that the Eagle app must be running locally and gives a minimum Obsidian version of 1.5.0.
