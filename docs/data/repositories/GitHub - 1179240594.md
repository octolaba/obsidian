# davidvkimball/obsidian-extended-embeds

Extended Embeds renders rich media previews in reading mode from a fenced code block using the embed language identifier, detecting the URL inside it and choosing the matching provider. Supported providers are Vimeo, Spotify tracks, albums, playlists, episodes and shows, Steam apps, bundles and packages, SoundCloud, CodePen, GitHub gists, GitHub repository cards with description, stars, forks and language, GitHub issue and pull request cards with state, labels, author and date, and an Open Graph card as the fallback for any other URL. An optional second line inside the block sets width, or width and height. Settings enable individual providers, accept a GitHub token to raise the API rate limit, force dark or light mode instead of following the theme, and set how long fetched data is cached.
