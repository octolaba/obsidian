# uppinote20/obsidian-auto-note-importer

Obsidian plugin that synchronises notes in both directions between the vault and Airtable, SeaTable or Supabase, built on a provider-agnostic core. Several sync configurations covering different bases, tables and folders run side by side, conflicts are resolved manually or by letting Obsidian or the remote win, and computed values such as formula, rollup and lookup fields are fetched again after a push. Notes are named from fields validated per provider, organised into subfolders by a field value, and filled from templates with field placeholders that reach nested properties. Syncing is run manually, on a scheduled interval, or when a file changes.
