# nhannht/obsidian-historica

Historica renders a timeline from the prose of a note: a historica code block splits the file into sentences, ignoring code blocks, and every sentence holding a parseable date or time becomes an entry. Language detection is automatic by default, with parsers for English, German, French, Japanese, Chinese, Dutch and Vietnamese. Entries expand into cards carrying a significance rating, a free-text note and vault attachments, and context menus sort, fold, re-parse, export to PNG, HTML, Markdown, JSON or text, and dismiss bad extractions. Saved timelines are written as plain Markdown under a historica-data folder and indexed into a vault-wide Global Timeline view; the plugin is desktop only.
