# lai2301/obsidian-secret-placeholders

Secret Placeholders keeps credentials out of Obsidian notes: a note holds only a placeholder naming a path in a password manager, and the plugin resolves it to the live value at render time inside Obsidian. The README states the value is never written to the Markdown file, so an agent reading the vault, and Git history, backups and sync, see only the placeholder, and that rendering is display-only and never writes to the vault. It documents autocomplete when a placeholder is opened, saving a selection as a new secret, and editing a secret's value through the backend without touching the note, and lists four supported backends with their own placeholder prefixes and authentication methods, any subset of which can be enabled.
