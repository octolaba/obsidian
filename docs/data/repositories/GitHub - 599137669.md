# gapmiss/iconoir-icons

Renders Iconoir SVG icons inline in notes from a bracketed component written inside inline code, where the icon name is required and color, width, height and further CSS rules are optional pipe-separated fields. Typing two ampersand characters opens a suggestion interface for searching icon names. The README documents the syntax, its delimiter and the ordering of the optional fields, and reproduces the upstream Iconoir copyright and license notice.
