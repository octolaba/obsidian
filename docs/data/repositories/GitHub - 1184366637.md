# DisparateDan/arbor

An Obsidian plugin that builds, visualises and exports a family tree held as Markdown person notes in the vault. The tree is drawn as a navigable SVG diagram rooted on any person, in horizontal or vertical layout, following the active Obsidian theme, with edges from one parent colour-cycled to trace lines, a toggle between blood-line and all siblings, and toolbar state remembered between sessions. It also provides a modal command for creating a person note with the right frontmatter, bulk CSV import with a dry-run preview, and export of the tree as a self-contained interactive HTML file. The README states it is not meant as a canonically correct genealogical tool but as a practical one for keeping family records in Obsidian.
