# joelam2023/investment-tracker

The recorded description calls this private, local-first portfolio tracking for Obsidian with encrypted investment records stored in the vault. The README says it works at account level rather than per position, keeping immutable event-based records of contributions, withdrawals and valuations across accounts in nine currencies, and computing XIRR, cumulative profit, yearly returns and monthly Modified Dietz returns. It compares the same cash flows against the S&P 500 Price Index using currency-aware FRED benchmark conversion with explicit quote-direction checks, and offers a password lock, a separate recovery key, hidden financial values and configurable automatic locking. The project states that none of this requires an account, telemetry or a developer-operated backend.
