# geeknees/obsidian-ruby-wasm-plugin

This plugin runs Ruby inside Obsidian through ruby.wasm. It executes the selected Ruby code from the editor, or the whole current Ruby code block when nothing is selected, and reports standard output, standard error, the return value and errors separately; rendered ruby code blocks also get a Run button for a lightweight read-eval-print flow. The runtime version is chosen in the plugin's settings, with Ruby HEAD, 4.0, 3.4, 3.3 and 3.2 listed, and the README states that the selected WebAssembly runtime is downloaded from jsDelivr the first time a command is run, so that the shipped main.js stays small enough for Obsidian Sync.
