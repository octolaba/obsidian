# sspaeti/obsidian_kanagawa_paper

This repository ports the Kanagawa Paper colour scheme to Obsidian, and its README states that dark and light modes are both supported while noting that the light mode is not really optimized, having been made mainly for the dark one. Installation is by searching for Kanagawa Paper in the community themes list, or manually by copying obsidian.css into the vault directory and reloading Obsidian. The README also points to the author's other themes, Kanagawa, Rose Pine and Osaka Jade.
