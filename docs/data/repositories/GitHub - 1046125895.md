# marcelflymark/new-line-break-inside-table-cell

This plugin adds an Obsidian command that inserts a line break inside a table cell using the HTML line break element. The README gives the motivation: on a hardware keyboard Shift and Enter wrap a line within the same table cell, but that combination cannot be typed on mobile devices, so the command supplies the same result from the command palette, a ribbon icon or a toolbar button.
