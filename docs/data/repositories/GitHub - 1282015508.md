# Laplacede/Canvas-Layer-Order

This repository holds Canvas Layer Order, an Obsidian plugin adding PowerPoint-style layer controls to Canvas cards. The README explains the mechanism: a canvas file stores cards in a nodes array and later entries render above earlier ones where they overlap, so the plugin changes stacking by moving the selected card inside that array. Commands bring a card to front, send it to back, or move it forward or backward one layer, available from the command palette, from hotkeys, and from the card context menu in supported Obsidian versions. An optional setting preserves the saved layer order when a card is focused, since Obsidian may otherwise lift a focused card above its neighbours.
