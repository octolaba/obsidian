# agarcabin/obsidian-custom-extension-names

Renames the display names of other installed plugins and, optionally, keeps those names after an update overwrites a plugin's manifest. A saved name is stored in this plugin's own settings and applied to Obsidian's in-memory manifest so it shows immediately; when locking is enabled the name is also written into the target plugin's manifest file and reapplied once an update finishes. The settings tab searches and filters by plugin ID, current name, saved name or registry name, looks up official names from the community plugin registry, and supports batch selection, template-based renaming and bulk unlocking, alongside separate actions to restore an original or community name. Only the display name is touched, and automatic restoration relies on an internal Obsidian install hook.
