# jamiebrynes7/obsidian-hover-external-link

Adds tooltips showing the target URL when hovering an external link in rendered Markdown. The README states the tooltip appears only when the link text differs from the URL itself, and only in preview mode. Two CSS variables are exposed so that the tooltip background and text color can be set per theme.
