# joshuawootonn/obsidian-rich-text-editor-shortcuts

Rich Text Editor Shortcuts ports keyboard shortcuts the author favoured in Notion into Obsidian's editor. The recorded bindings create an unchecked or checked checkbox from a bracket pair followed by a space, toggle a checkbox's status, turn a paste into a link when the clipboard holds a URL and a range is selected, create a local link within the vault, and toggle underline.
