# Gorkycreator/obsidian-quick-tagger

Quick Tagger adds commands and a selection interface for writing tags into note metadata in Obsidian. The README records bulk tagging by right-clicking one or more notes or a set of search results, hotkeyable command palette entries that add or remove tags, ribbon icons acting on the current note, and configurable starred tags that can be listed first when selecting, given a context-menu entry, an Obsidian command, or a status bar toggle. It notes that the ribbon icon cannot see which files are selected, so bulk tagging stays in the right-click menu, and it states plainly that the plugin keeps no undo or redo queue and is used at the reader's own risk, particularly when tagging in bulk or removing all tags.
