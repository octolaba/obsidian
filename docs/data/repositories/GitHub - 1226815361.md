# kosperun/obsidian-sansconverter

SansConverter converts text between Sanskrit transliteration encodings inside Obsidian, and its README states it is based on a desktop application of the same name by the same author. The encodings it supports are IAST, the legacy Balaram encoding used in many Vaishnava publications, the ASCII-friendly Harvard-Kyoto and Velthuis schemes, and a Cyrillic-based Ukrainian IAST, and the README tabulates the ten conversions available between them. Conversion runs over the current selection through a command chosen from the palette, replacing the selected text, and the README suggests binding the conversions used most often to hotkeys.
