# mdelobelle/metadatamenu

Metadata Menu manages the metadata of Obsidian notes, covering both frontmatter fields and inline dataview-style fields written with a double-colon in the body. It adds context-menu items for modifying a target note's fields from a link or from within dataview tables, gives each field a type, and offers autocompletion driven by preset values. Types and values can be defined globally in the settings or per file through fileClass definitions. The README opens with a call for contributors, stating that the author can no longer dedicate much time to the plugin, and links full documentation and a series of feature demonstrations.
