# namikaze-40p/obsidian-bookmarks-caller

Bookmarks Caller opens Obsidian bookmarks through two commands: a modal that keeps the hands at the keyboard home position, and a search over the bookmarks. In the modal each item carries a one-letter key, and items can also be reached with the arrow keys or the mouse, while a shortcut or an All button opens every bookmark in the current group. The README states that the Bookmarks core plugin must be enabled and that file, folder, search-term, graph, heading, block and url bookmarks are supported, the last of these on the desktop app only.
