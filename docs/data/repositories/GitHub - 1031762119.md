# tomelliot/obsidian-granola-sync

An Obsidian plugin that pulls Granola meeting notes and transcripts into the vault as plain Markdown. The README records that since version 2.1.0 it authenticates with a personal API key against Granola's official public API instead of decrypting the desktop application's local credential store, so note bodies come from Granola's summary field and only meetings with a finished AI summary and transcript are synced. Recorded options cover syncing into daily-note sections or individual files with configurable folder and filename patterns, transcript placement, automatic bidirectional links between notes and transcripts, periodic syncing, title-based filtering and a sync-history window. The README states the plugin works on desktop only and that it batches requests within the public API's rate limits and retries when it is throttled.
