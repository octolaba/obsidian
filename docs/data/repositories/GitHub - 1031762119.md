# tomelliot/obsidian-granola-sync

Obsidian Granola Sync imports Granola meeting notes and transcripts into a vault as searchable Markdown through Granola's official API. It supports API-key authentication, configurable note and transcript destinations, linking, filters, periodic synchronization, rate-limit retries, and in-place updates, and is intended for desktop use only.
