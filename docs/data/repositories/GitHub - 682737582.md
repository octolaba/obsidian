# Erl-koenig/obsidian-checkboxReorder

The repository records no description, so this body rests on the README alone. The README states that the plugin reorders completed checkboxes to the end of their list through a Reorder Checkboxes in List command, which can be bound to a hotkey. A setting chooses whether completed items move to the top or the bottom, and half-checked items are placed between the unchecked and the completed ones.
