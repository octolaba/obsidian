# danzar/Obsidian-Locker

Lockbox encrypts a note's contents while leaving its title visible, so a locked note stays an ordinary Markdown file in the explorer, the graph and links, with its body sealed in a fenced locker block until it is unlocked with a password. Notes are locked and unlocked from commands, the ribbon icon or the file context menu, against either one vault password cached for the session or a per-note password, and the README records PBKDF2 with SHA-256 deriving an AES-GCM-256 key with a fresh random salt and initialization vector per note. Auto-lock re-encrypts on navigating away, after an inactivity timeout and on quit; a status-bar indicator counts the notes currently holding plaintext and locks them all on click; and before plaintext is overwritten the new ciphertext is decrypted and compared, so a faulty lock aborts instead of destroying content.
