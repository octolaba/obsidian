# nathonius/obsidian-github-link

This repository holds GitHub Link, whose README describes injecting GitHub content into notes: GitHub links are transformed into inline tags showing an issue or pull request title and status, and a github-query code block renders a table of search results that refreshes when the note is opened. The block takes an output type, a query type, a query string and a list of columns such as number, title, author and status. Fuller documentation is kept in the project wiki. No upstream repository description is recorded, so this body rests on the README alone.
