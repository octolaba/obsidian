# sr-campelo/retronotes

RetroNotes is a writing-centered Obsidian theme by Ruben Campelo, built around warm palettes and a calm interface for long-form notes. IBM Plex Mono is embedded in the theme, so no font install is required, and eleven colour schemes — five light and six dark, defaulting to Parchments and Midnight Journal — can be picked independently through the Style Settings plugin. The README calls it a personal theme whose contrast and colour choices may not suit every plugin, records testing with the Calendar plugin, and recommends companions such as Better Word Count, Latex Suite, Quick Switcher++ and Smart Typography.
