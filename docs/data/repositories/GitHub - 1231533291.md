# liyaomingme/obsidian-mobile-dashboard

Mobile Dashboard turns the Obsidian startup page on a phone into a control centre combining quick capture, note statistics and a calendar laid out for portrait screens. The README, written in Chinese and English, records a fluid CSS grid that scales fonts and calendar cells to the screen width, popup spacing calculated to clear the notch and leave room for the keyboard, serif typography with a traditional almanac time axis, and frosted-glass dialogs. It also records a date-detection routine that reads dates from YAML and from filename patterns to work around creation times lost to multi-device iCloud sync, and it directs users of widescreen devices to a separate desktop repository.
