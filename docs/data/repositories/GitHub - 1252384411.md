# miaowuduck/stardew-valley-pals

Stardew Valley Pals places pixel-art pets and characters from Stardew Valley in the workspace, where they idle, walk, sleep and can be dragged into position. The README counts fifteen pet species with more than fifty-five colour variants and more than thirty-five named characters, and describes two display modes: a resizable side panel dockable anywhere, or a transparent overlay across the whole Obsidian window. Clicking a character shows a heart and right-clicking triggers a speech bubble in which an AI model comments on the current note; any OpenAI-compatible API can be configured, each species and character carries its own persona, an auto-rant mode speaks at random intervals, and a Chinese prompt mode is optional. Ten themed backgrounds drawn from the game's seasons and locations are included.
