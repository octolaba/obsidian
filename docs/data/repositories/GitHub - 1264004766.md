# perinchiang/obsidian-plugins-code-block-plus

Gives every code block a header bar carrying a language label and a copy button, styled the same in editing and reading modes. Clicking the label opens a searchable picker with more than forty preset languages, and a typed custom language is remembered for later use, while the fence lines themselves are hidden so only the header and the code remain visible. Typing the plugin's Chinese punctuation trigger, optionally followed by a language name, and pressing Enter creates a block; backspace in an empty block removes it, and a first Ctrl or Cmd plus A selects the block body while a second press selects everything. Background, corner radius and padding are optional overrides, the interface switches between Chinese and English, and controls can be set to appear only on hover.
