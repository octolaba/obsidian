# Femto-0/auto-scroll

An Obsidian plugin that scrolls the active editor automatically while writing and navigating. Scrolling can be triggered when the text cursor passes a configured viewport position while typing, on each press of the Down arrow, or when the mouse pointer enters an edge zone at the top or bottom, with the trigger point given as a viewport percentage that defaults to 80. Further settings cap the pixels moved per trigger and per Down arrow press, set a cooldown between scrolls, require the editor to be near a configured document depth first, and enable smooth animation; a command toggles the whole behaviour.
