# ChasKane/gay-toolbar

A collapsible toolbar that floats above the mobile keyboard and replaces parts of Obsidian's default mobile toolbar and navigation. In edit mode each button takes a primary tap command, an optional long-press command and any number of swipe commands, one per direction, and buttons are dragged between slots by long-pressing them. Colours come from an editable palette or are assigned in bulk, the toolbar background accepts a solid colour or a custom CSS value, row and column counts and sizes are set independently, and a finished layout can be snapshotted to a slot. The plugin sends no telemetry, and snippets saved in its command editor become Obsidian commands that run user-authored JavaScript.
