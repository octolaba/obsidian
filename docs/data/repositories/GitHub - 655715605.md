# nicholas-wilcox/tailwind-snippet-obsidian-plugin

This plugin runs Tailwind CSS as a PostCSS plugin to generate a CSS snippet inside an Obsidian vault, following Tailwind's PostCSS installation guide through the PostCSS JavaScript API. The README states that the generated snippet must be enabled by hand once created, after which it updates as files and settings change, that the plugin reads and writes in the vault's configuration directory through the FileSystemAdapter API, and that a ribbon icon triggers a manual refresh for cases such as Tailwind classes in non-Markdown files. It records that the plugin targets Tailwind version 3 with no plans to support version 4, whose refactored PostCSS method the author finds hard to reconcile with the Electron runtime, and that neither repository nor author is affiliated with Tailwind.
