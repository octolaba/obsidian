# kvasonaft/fb2-reader

FB2 Reader opens FictionBook .fb2 files stored in an Obsidian vault as a formatted book, rendering the cover, title page, authors, annotation, chapters, poems, quotes, footnotes, images and tables, on desktop and mobile. A side panel lists the chapters of the active book and scrolls to one when clicked, and the reading position is remembered per book, for up to 300 books, and restored on reopening. Appearance settings cover the theme as light, dark, sepia or following Obsidian, the font family, size and line height, the text colour and optional drop caps, and legacy encodings such as windows-1251 are detected and decoded. The README states that zipped .fb2.zip books are not supported, because Obsidian identifies files by their final extension and claiming .zip would capture every archive in the vault.
