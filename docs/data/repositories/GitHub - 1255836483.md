# bugrasitemkar/obsidian-eisenhower-tasks

Eisenhower Tasks opens a colour-coded grid of urgency and importance quadrants in a full-width tab, reached from the ribbon or the command palette. The README states that tasks are typed into an input at the bottom of each quadrant and land in a built-in Uncategorized section, that named sections can be added, renamed inline and deleted with their tasks migrating back to Uncategorized, and that drag and drop moves tasks between sections and across quadrants. With subtasks enabled, dropping a task onto another makes it a child up to three levels deep, while drops that would exceed the depth or create a cycle are blocked and marked with a red dashed border.
