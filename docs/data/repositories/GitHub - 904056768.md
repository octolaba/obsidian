# aaaaalexis/obsidian-pseudo-mica

Pseudo Mica applies OS-native window translucency effects to Obsidian through Electron's native window APIs. The README states that on Windows it calls setBackgroundMaterial with a choice of Mica, Mica Alt or Acrylic and adds an is-translucent class to the body, mirroring Obsidian's own behaviour when the translucent window option is enabled on macOS, and that it requires the window frame style to be hidden or the Obsidian frame. On macOS it calls setVibrancy with one of the supported vibrancy types, such as sidebar, window or under-window, and requires the translucent window appearance setting; its settings are opened from a ribbon icon or a command.
