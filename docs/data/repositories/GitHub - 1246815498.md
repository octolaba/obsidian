# redzumi/vault-chat-agent

Vault Chat Agent is an AI assistant plugin for Obsidian offering one agentic chat with Ask and Edit intents over OpenAI-compatible chat completions. The README lists search scopes covering the whole vault, the current note or the current folder, a plan mode allowing read-only investigation before pending edits are prepared, context mentions with inline autocomplete, and provider presets for OpenAI, DeepSeek, OpenRouter, LM Studio, Ollama and custom endpoints with model browsing. Retrieval rests on a local index of text files, Canvas files and metadata-only attachments kept current on create, modify, delete and rename, and is graph-aware through links, backlinks and neighbouring chunks, feeding a related-notes sidebar and read-only agent tools with clickable source references. Edits arrive as proposals with patch previews and apply or reject actions.
