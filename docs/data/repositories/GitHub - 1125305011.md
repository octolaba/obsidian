# canepa/plugin-obsidian-classifier

An Obsidian plugin that suggests and applies tags across several independent note collections, each with its own scope, thresholds, filters and dictionary source. A collection can either learn from the tags already present in the vault or draw on a static JSON dictionary, and suggestions from more than one collection can be merged when a note belongs to several contexts. The README also records basic and advanced classifiers, batch operations and automatic removal of blacklisted tags.
