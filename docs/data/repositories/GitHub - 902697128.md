# ariamckinley/obsidian-image-picker

Browses and searches media in the vault from a picker view, generating thumbnails and indexing images in the background so that searches by name and extension return instantly. Settings choose the root folder to index, which the README recommends narrowing to the attachment folder, whether gifs animate in the preview, a debug logging mode, and a button that resets the image index and reloads Obsidian. The README's roadmap lists renaming, local models for generating searchable descriptions, metadata-based search, and video and audio support as not yet implemented.
