# TlmKira/selection-translator

Selection Translator translates selected text, whole paragraphs, Markdown notes and embedded images from inside an Obsidian vault, and can speak the result aloud. The README lists translating from the command palette, the editor menu or the ribbon, a quick panel for ad hoc text, translating a file into a linked side-by-side note, bilingual display in reading mode, image translation through a configured provider, and speech through the browser speech API or a hosted text-to-speech service. Its privacy section states that no analytics are collected and no vault content is uploaded in the background, that requests leave only when a translation, listing or connection test is actively invoked, and that API keys are stored in plugin data behind hidden inputs without being encrypted; the providers it can be pointed at are enumerated there as well.
