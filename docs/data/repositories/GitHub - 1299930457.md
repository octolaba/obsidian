# studiogamma/tree-graph-view

Tree renders the vault as a dendrogram, arranging notes hierarchically with top-down, bottom-up, left-to-right and right-to-left growing directions. Parent-child relations can be resolved from frontmatter metadata, tags, outlinks or backlinks, and a child with several parents is replicated visually under each of them so edges do not cross, while clicking any duplicate still opens the single underlying note. The README states that cycles and self-references are handled during layout calculation without altering notes, and that a collapsible panel floats over the canvas for spacing, sizing and direction. It is labelled as early access and under active development.
