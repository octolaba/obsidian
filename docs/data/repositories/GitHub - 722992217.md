# TfTHacker/obsidian42-HelpMate

HelpMate adds a side pane to Obsidian for viewing the help sites of the plugins and themes that are installed. The README states plainly that the plugin is an embedded web browser: it connects to the internet to retrieve those help sites, connects for no other reason, and needs a live internet connection to function.
