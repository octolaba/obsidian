# grub-basket/Bases-Toolbox

Bases Toolbox collects quality-of-life tools for Bases and note properties in Obsidian. A find-and-replace command rewrites a property's values across files — one specific value or every value at once, including items inside list properties — and logs every run to a history tab that survives restarts, where an operation or individual files can be reverted, with drifted files flagged and skipped unless a force toggle is enabled. The README also records a number input guard that stops number properties in the frontmatter editor and in Bases views from changing on arrow keys or mouse wheel, with an option to restrict typed characters to digits, `.` and `-`.
