# frankolson/obsidian-bujo-bullets

BuJo Bullets adds alternate checkbox types to Obsidian for Bullet Journal rapid-logging bullets: incomplete and completed tasks plus irrelevant, migrated and scheduled tasks and events, each written as its own character inside the checkbox brackets and displayed with its own icon in reading mode. Signifiers written at the start of a bullet are highlighted to add context, with an exclamation point and a question mark supported by default and the set editable in the plugin settings. The bullet type of a line can be changed from a right-click context menu or through commands with hotkeys.
