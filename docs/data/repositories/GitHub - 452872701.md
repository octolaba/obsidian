# stbowers/obsidian-codeblock-labels

Obsidian plugin that renders labels for fenced code blocks. A label is written in curly braces at the end of a fence's first line, after the language when one is given, and the plugin can optionally fall back to showing the language as the label; a rendered label carries a codeblock-label class that CSS can style. The README documents a known refresh issue: because Obsidian inspects only the first line of a code block up to the first space, edits made after that space may not update the preview until a change is made elsewhere.
