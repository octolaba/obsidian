# IdreesInc/PB-Obsidian-Releases

This repository carries the Obsidian distribution of Pocket Bird; its README states that it exists for that distribution only and that the full source code lives in the IdreesInc/Pocket-Bird repository. Pocket Bird is described as a pixel-art bird that hops around apps and websites, where catching rare falling feathers unlocks over thirty species, more than a dozen hats can be worn, and sticky notes stay on a page after a refresh. The README documents adoption through the Chrome Web Store, Firefox add-ons, the Obsidian community plugin listing, and a Tampermonkey userscript used mainly for beta testing.
