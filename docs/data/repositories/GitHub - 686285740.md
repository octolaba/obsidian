# mjsumpter/obsidian-tag-page

Tag Page creates and manages dedicated Markdown pages for individual tags in Obsidian. The README records that tag content is rendered inline from a tag-page code block naming one or more tags, so generated results and the user's own writing share a note without the surrounding text being touched, and that a command creates such a page with the block already seeded, either for one tag or scoped to the nested tags beneath it. Settings cover the directory created pages go into, whether lines containing the tag and bulleted sub-items are included, sorting, titles and links, and whether a reference link appears at the start or the end of each pulled line.
