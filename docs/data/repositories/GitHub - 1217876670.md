# kechengzhang28/Obsidian-CalendarZ-Plugin

This repository holds CalendarZ, a visual calendar plugin for Obsidian that tracks daily notes with a heatmap or with dots. The heatmap shades days by note count or word count, dot mode draws one dot per configurable number of notes or words, and a third mode drops the indicator entirely. Dates are recognised from YAML frontmatter fields, from filenames, or from both, with configurable field names and date formats. Daily, weekly, monthly and yearly notes can each be enabled and opened or created by clicking the matching cell, header or label, with configurable naming formats; the README presents the plugin as a successor to a calendar plugin last updated four years earlier.
