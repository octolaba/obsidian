# rplatonovs/obsidian-jira-links-shortener

The recorded description names this an Obsidian JIRA links shortener plugin. The README calls it a very simple plugin that captures pasted text and, when it detects that the text is a link to a Jira ticket, sets the issue number as the title. Its example shows a pasted browse URL becoming a Markdown link labelled with the issue key.
