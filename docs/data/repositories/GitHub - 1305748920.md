# chrisurf/obsidian-git-history

Git History for Obsidian provides a visual Git workflow through a source-control panel, commit graph, file history, and diff viewer, so vault changes can be staged, committed, pushed, pulled, fetched, stashed, or organized into branches without a terminal. It can trace a note across renames, compare old and new text, stage or undo individual diff blocks, and includes a desktop-only terminal marked as alpha.
