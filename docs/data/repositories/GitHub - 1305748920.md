# chrisurf/obsidian-git-history

This repository holds Git History, described upstream as Git management inside Obsidian with an interactive commit graph, a source control panel, file history and a diff viewer, and no terminal required. The README is written for readers new to Git, explaining commit, push and pull in vault terms and offering an initialize-repository command for a vault that is not yet a repository. It presents the vault's change history as a visual timeline that can be inspected, reverted and pushed to a backup copy from inside Obsidian.
