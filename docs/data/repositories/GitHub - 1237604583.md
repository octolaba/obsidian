# qiaoborui/obsidian-beautiful-mermaid

The repository records no description, so this note is grounded in the README alone. Beautiful Mermaid Renderer replaces Obsidian's rendering of `mermaid` code blocks with SVG output from the `beautiful-mermaid` library, styled through Obsidian's own theme variables, and it accepts the aliases `mermaid-beautiful`, `beautiful-mermaid` and `bmmd` alongside `mermaid`. The README states that Reading view and Live Preview are both supported, that in Live Preview the diagram renders once the cursor leaves the block and a hover Edit button reveals the source again, and that inline diagrams fit the editor width unless that setting is disabled.
