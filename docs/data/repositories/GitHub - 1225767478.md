# CodyBontecou/isome-maps

iso.me Maps renders interactive Leaflet maps inline in Obsidian notes from iso.me location exports. A fenced iso-me code block points at one or more export files in the vault and draws visit markers sized and shaded by duration, route polylines with start and end markers, optional markers for points flagged as outliers, a stats bar of visit and point counts, distance, average speed, date range and top repeated place, and optional day and time-of-day filters. Accepted inputs are iso.me JSON, CSV and Markdown, OwnTracks JSON, Overland JSON or GeoJSON, and GPX. The README states that the plugin requires Obsidian 1.12.0 or newer, reads only the files a block references, uploads no vault content, and limits network activity to loading map tiles from the selected provider.
