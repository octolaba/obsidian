# zaheralmajed/vicious-theme-obsidian

Vicious is a dark Obsidian theme that the README presents as designed for minimalism, readability and reduced eye strain, while shipping both light and dark variants. Documented features include a modern card style, alternative checkbox designs in place of plain checkboxes, and customization intended to let a user match the theme to their own style. The README is built largely from screenshots and badges arranged around those feature headings.
