# lizard-heart/obsidian-wordnik-definitions

This plugin inserts word definitions fetched from Wordnik. One command searches for a word and pastes the data at the cursor, another uses the title of the active note, and both need a Wordnik API key entered in the settings. The formatting of the pasted data and the maximum number of definitions are configurable, and the README states that the plugin is a modified version of an existing Wikipedia plugin.
