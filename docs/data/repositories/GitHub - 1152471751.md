# khabaroff-studio/obsidian-webhooks-server

A self-hosted server that turns external HTTP events into notes in an Obsidian vault, paired with the plugin that receives them. Webhooks sent from tools such as Zapier, Make, n8n or any HTTP client are delivered over Server-Sent Events with a polling fallback, and the README states that an ACK system gives exactly-once delivery and that event data is encrypted at rest with AES-256-GCM. Sign-in is passwordless, through a link emailed to the address given at registration, deployment is described with Docker Compose against a database URL, a JWT secret and mail credentials, and the plugin is configured with a client key and the server URL. A webhook request carries the target vault path as a query parameter and the note content as JSON.
