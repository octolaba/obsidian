# kamil-rudnicki/obsidian-recent-notes

Recent Notes shows recently edited files in a sidebar as a timeline grouped into periods such as today, yesterday and this week, in the manner of Apple Notes. Each entry displays the note's title — optionally taken from a title property instead of the filename — the first lines of its content with Markdown formatting stripped, the last edit time, the folder it sits in, and a thumbnail for images and media. The list can be filtered by file type across Markdown, images, PDFs, audio, video, Canvas and CSV, limited in length, given custom date and preview formats, navigated by keyboard including a jump to today's section, and narrowed by pinning notes or excluding folders and files. The README also records caching for large vaults, appearance changes through the Style Settings plugin, and translation support.
