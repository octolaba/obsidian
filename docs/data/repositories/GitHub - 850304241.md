# Spekulucius/obsidian-adrenaline

Spekulucius/obsidian-adrenaline holds Adrenaline, a minimal theme that takes its colours from the accent colour set in Obsidian and supports light and dark mode. The README lists the ribbon and the nav bar buttons hidden until hover, a hover line indicator, an active line indicator, new folder icons, and restyled blockquotes, callouts and highlighting, with spacing tightened so more text fits on screen. It also records the current look as a second version: anyone who preferred the first is pointed to the author's separate Marathon theme, which the README calls almost a one-to-one copy of the old Adrenaline. Content taken from other theme authors is attributed where it is used.
