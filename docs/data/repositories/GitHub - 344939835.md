# imdone/imdone-obsidian-plugin

Opens the Imdone kanban card corresponding to a TODO comment under the cursor, building a link from the active file path and line number so Imdone lands at that exact location. It also offers autocomplete suggestions for imdone tags while typing. The README describes the paired setup on the Imdone side: selecting Obsidian as the file opener, enabling opening at the card source line, and opening the Imdone project folder as a vault.
