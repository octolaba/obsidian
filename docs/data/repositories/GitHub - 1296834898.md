# nobodyrightnow/obsidian-random-note-plugin

This plugin picks a random note from a folder the user chooses in an Obsidian vault. Its README states that a dice ribbon icon opens a modal for a folder path relative to the vault root, that the folder and its subfolders are searched recursively for Markdown files, and that one of them is chosen at random and opened in a new tab. Progress and any errors are reported during the run, and the project is described as customized from the Obsidian sample plugin repository.
