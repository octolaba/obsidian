# xhydros/pdf-to-markdown-local

This desktop-only plugin converts text-based PDFs to Markdown locally from the file context menu, adding commands for one PDF, for every PDF under a folder tree and for an optional merged batch, with a mandatory preview before a folder batch creates any file. Its README states that PDFs are read through Obsidian's own APIs and parsed with a bundled pdf.js plus an inline local worker fallback, so no CDN or remote worker is used, that the original PDF is preserved, and that existing Markdown files are never overwritten. It records conservative cleanup for paragraph joins, hyphenated line breaks, simple two-column pages and repeated headers and footers, optional page markers and technical metadata, optional extraction of detected images as local PNG files, local templates with placeholder replacement, and generated previous, next and mention links between the produced notes.
