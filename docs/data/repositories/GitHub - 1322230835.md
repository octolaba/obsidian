# thisisthedave/tasknotes-views

TaskNotes Views embeds a progress chart in notes that TaskNotes recognises as projects, drawn in both Reading view and Live Preview. The chart plots cumulative scope against scheduled, started and completed work over a window taken from the project's start and end frontmatter properties, with an ideal target line that advances on weekdays and stays flat at weekends by default, and a hover popup naming the tasks behind each day. Work is measured from task estimates, either durations or unitless values such as story points; statuses marked as skipped are excluded, and recurring tasks are counted per occurrence. Capacity can optionally be estimated from work completed in the six weeks before the project starts, and both Obsidian 1.13 or newer and the TaskNotes version 1 public API are required.
