# latazadehomero/memory-palace

Memory Palace 3D renders notes as a set of interconnected rooms through Three.js with the CSS3D renderer, navigated with WASD keys, the mouse wheel to zoom, shift with mouse movement to rotate and a key to recentre. A room is declared by a Room heading in a note followed by properties setting the wall colour, the content of each cube face — front, back, up, down, left and right — and a floating object in the middle, and the README records that internal links and embedded images inside a room stay clickable, with Zotflow links and Excalidraw diagrams also supported. Settings control the distance between room levels and whether embedded images stretch to fill a wall face or keep their original aspect ratio.
