# EllisMorrow/obsidian-block-reference-enhancer

This plugin renders and manages Logseq-style UUID block references inside Obsidian while preserving the original Markdown. Bare uuid references are shown as first-line summaries and embed references as complete, foldable outlines, backed by a local index of source blocks and references that does not depend on Obsidian's search index. It adds a hover-only Back button that jumps to the source block, reference-count badges, a popover listing where a block is referenced, block autocomplete while typing, and commands and context-menu actions to copy the current block reference or embed. Logseq-style outline property lines are hidden, and the description also names YAML page-property sync.
