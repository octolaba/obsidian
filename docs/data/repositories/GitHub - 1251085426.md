# AntoineArt/obsidian-daily-day-nav

The repository holds Daily Day Nav, an Obsidian plugin adding two commands that open the previous or next calendar day's daily note. When that day has no note yet, the plugin creates it from the configured daily notes folder, format and template instead of requiring it to be made by hand. The README states that the core Daily notes plugin must be enabled and a daily notes folder configured, and explains the gap it fills: the core feature centres on today, so skipped days have to be created manually.
