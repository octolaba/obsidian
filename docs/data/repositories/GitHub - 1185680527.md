# redsheep913/Canvas-Card-Materializer

This repository holds Canvas Card-Materializer, an Obsidian plugin that converts Canvas text cards into Markdown files while preserving their connections and colour coding. Selected cards become Markdown files that replace the original nodes in place, so the canvas layout is kept, and card colour decides the destination folder. Edges are preserved and each generated file gains a Connected Nodes section listing its linked notes as backlinks, while canvas_id and canvas_color are recorded in the frontmatter. Filenames are stripped of heading marks, backticks and illegal characters, and dragging a materialised file back onto a canvas restores its original card colour.
