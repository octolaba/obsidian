# frieda21/downloadPDF

Repository for downloadPDF, a small Obsidian plugin that downloads the PDF files linked from notes and saves them locally. Its README documents one command palette entry that downloads the PDF files referenced in all documents, placing each file in the parent directory of the document that links to it.
