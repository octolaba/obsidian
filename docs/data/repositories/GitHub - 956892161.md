# dee158/obsidian-rainbow-folders-fixer

This plugin stops rainbow-coloured folders from changing colour as the File Explorer is scrolled and its DOM elements are loaded and unloaded, by putting a stable data attribute on each folder instead. Three settings are recorded: the number of colours to iterate through, the attribute name, which becomes a data attribute on the element, and whether the rainbow iterates recursively through subfolders or keeps child folders the colour of their parent. The README shows how a CSS snippet or theme then selects folders by that attribute value instead of relying on nth-child implementations, and its author states that the plugin was made for personal use.
