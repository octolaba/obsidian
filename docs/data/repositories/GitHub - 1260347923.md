# Luhui-Dev/NotePic-OSS-Obsidian

NotePic OSS scans the current note for image references, compresses and deduplicates them, uploads them to Aliyun object storage and rewrites the links in place; the description and most of the README are Chinese. Images can be uploaded all at once or selected from a side panel that shows thumbnails, sizes, status badges, filters and multi-select, with two image formats compressed through the canvas and one through a library, while animated and vector images are left as they are. Object names come from a content hash and an existence check avoids uploading the same file twice, and references whose surrounding text shifted during the upload are skipped rather than overwritten. The README records that the plugin configuration is stored in plain text in its data file and recommends a scoped sub-account with a narrow permission set.
