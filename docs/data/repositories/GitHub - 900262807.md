# cynicalight/obsidian-image-size

Applies a default size to images pasted into a note, taken from a value set in the plugin settings, and writes a relative path for the image link. The README states that the relative path form suits bloggers publishing through Hugo, and that pasted images are stored in the folder configured in the settings. It also warns that the configured folder has to exist already and recommends placing the attachment folder in the project root directory.
