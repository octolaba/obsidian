# nejmlabs/Things-Pages

Things3 Pages links an ordinary Markdown note to the Things Inbox, a project or an area and synchronises them in both directions, covering task titles, task notes, completion states, headings, checklists, project notes and container names. The note gets things3-id, things3-type and things3-name properties, Markdown outside the managed section is preserved, and simultaneous edits are resolved against the last successful synchronisation as a baseline. Writes are manual by default through a ribbon button or command, with optional automatic synchronisation, and deleting the note removes only the local link rather than the Things project, area or Inbox. It is unofficial and macOS-only, needing Things3, Obsidian desktop 1.5.0 or later, and a companion Apple Shortcut that handles headings, task placement beneath them and checklist content.
