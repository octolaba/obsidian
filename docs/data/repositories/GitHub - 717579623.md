# GabAlpha/obsidian-githobs

This repository holds GitHobs, described upstream as using Obsidian as a GitHub issue editor, creating issues from Obsidian with logic taken from Git. The README presents fetch, pull and push as the working verbs and walks through installation from the community browser or by copying release files into a plugin folder. Configuration requires a GitHub token with the repo scope, plus the owner and repository names entered on the settings page.
