# kiluahh/notebrain

Notebrain runs a chat agent inside the note itself: a keyboard shortcut starts a conversation whose history is kept in the same file inside comment markers, and responses stream in with batched file writes. It calls a hosted reasoning model through a recorded set of 21 tools that search the vault, read, create and edit notes, browse the web, search academic papers and query reference sites. Captured reasoning is shown in collapsible comment blocks and preserved across turns, a marker triggers fill-in-the-middle completion, and a vault-wide instruction file created on first load is injected into the system prompt. Destructive tools are governed by permission settings and an in-memory cache keeps tool and reasoning context between messages.
