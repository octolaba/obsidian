# duluodexiaopiqiu/hide-empty-headings

The repository holds Hide Empty Headings, an Obsidian plugin that hides headings with no content beneath them while a note is in reading mode. The README records that the plugin checks each heading and hides it when nothing — text, images or other elements — stands between it and the next heading. It further records that the check runs again automatically when switching between notes and that the plugin needs no configuration once enabled.
