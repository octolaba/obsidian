# Elevict/Shade-Sanctuary

Shade Sanctuary is a theme for Obsidian MD, originally designed as an environment for writing and working with educational content, blending an academic feel with colorful visuals. The README names Castel's lecture notes and CyanVoxel's Vauxhall theme as its inspirations. With the Style Settings plugin the interface colour scheme can be chosen from red through purple and its intensity set anywhere from brighter to completely dark, though for now those changes affect only the dark theme. The author's separate snippet collection adds mathematics callouts, gradient callouts and headers, and animated elements.
