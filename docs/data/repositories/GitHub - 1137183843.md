# fengshuzi/tick-track

Tick Track is an Obsidian time-tracking plugin whose README is written in Chinese; it advances a list item through TODO, DOING and DONE states with one keyboard shortcut and records how long the task took. Starting a task stamps its start time onto the line and stores the precise timestamp in an HTML comment, and completing it, by the same shortcut or by clicking the checkbox of an in-progress item, appends the elapsed duration in seconds, minutes or hours. Native Markdown checkboxes are supported alongside plain list items, and settings control whether the duration is appended automatically and whether it is placed after the state or at the end of the line. The README traces the design to Alexander Lyubishchev's method of recording actual time spent rather than planning it in advance.
