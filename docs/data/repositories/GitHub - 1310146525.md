# smoosex/ob-everforest

OB Everforest applies the Everforest green palette to Obsidian in both light and dark mode, built on top of the native-style interface of the Baseline theme. Colors are fully replaced while Baseline's platform-adaptive element styling is kept, so controls look native on macOS, Windows, Linux and Android, and the Style Settings plugin can customise it further. The README states that the theme is not published to the community theme store and must be installed manually, and that the committed theme.css is compiled from Sass sources under src.
