# deltaplanoo/git-ribbon-sync

Git Ribbon Sync puts three Git actions in Obsidian's left ribbon: pull, commit and push, and a commit history view. Pull runs a git pull in the vault root and reports the result in a notice, while commit and push stages the vault, commits with a message combining a configurable prefix, a device name and the timestamp, and pushes to the remote. The history action opens a tab that renders the repository's commit log as a table. All three are registered as commands, so they can be run from the command palette or bound to hotkeys, and the prefix and device name are set in the plugin's settings.
