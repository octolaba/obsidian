# abuibrahim2/quranlookup

The repository holds Quran Lookup, an Obsidian plugin that replaces a shorthand reference with the verses it names. Its README records the syntax as a surah number or transliterated surah name followed by a verse number, with the name matched by fuzzy search because transliterations vary, and the workflow as typing the reference, selecting it and running a retrieve command or its hotkey. The selected text is replaced by a callout carrying the verse reference together with the Arabic text and an English rendering.
