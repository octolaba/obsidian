# fangface-hub/obsidian_table_formatter

Table Formatter reformats Markdown tables when files are saved and can auto-format during Live Preview or Source mode after a configurable pause. It preserves cursor position and column alignment, leaves the active table alone while editing, supports manual or vault-wide commands, and offers settings for padding, delimiter dashes, indentation, and empty cells.
