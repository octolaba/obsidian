# RoseyGoblin/busy-goblins

Busy Goblins builds reusable chains of AI operations over Obsidian notes. Each step in a chain reads from a file or folder, runs it through a local Ollama model with a prompt the user provides, and writes the result somewhere, with one step's output able to feed the next; a chain built once is saved as a preset and run again in one click. The README states that Ollama must be installed and running locally with at least one model pulled, and that the plugin is desktop only because it uses Ollama's local API. Settings hold the Ollama URL, the default model and the folder where presets are stored, and the panel opens from a ribbon icon or a command.
