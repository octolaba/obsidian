# ai-chen2050/obsidian-wechat-public-platform

This community plugin publishes articles, videos and other resources from an Obsidian vault to a WeChat Official Account, and its recorded description also names Baidu Baijiahao and other platforms as targets. Its commands cover uploading material to the WeChat public platform as part of that publishing flow. The README is bilingual, pointing to a Chinese counterpart and to video walkthroughs for the WeChat and Baijiahao paths.
