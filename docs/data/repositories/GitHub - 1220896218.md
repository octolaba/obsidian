# amm10090/claude-warm-obsidian-theme

Claude Warm is an Obsidian theme with soft ivory surfaces in light mode and layered charcoal in dark mode, tied together by a restrained warm-gold accent used for links, tags, selections and focused controls. Its README presents the two schemes as a matched pair inspired by the calm, low-contrast Claude interface, with warm backgrounds and restrained contrast for long-form reading and editing. Sidebars, tabs, menus, modals, tables, callouts and code blocks are given softer shapes, and a palette table records the light and dark values for background, text, accent and code accent. The README states that the theme CSS references no remote fonts or external assets and that most of the theme is built from Obsidian CSS variables.
