# n23eos/column_explorer

Column Explorer browses an Obsidian vault in Finder-style Miller columns: clicking a folder opens its contents in a new column to the right, so each level of the hierarchy is visible side by side instead of in one vertical tree. It works as a file manager with create, rename, move, drag and drop, multi-select, context menus and folder colors, and folders can be starred so frequently opened paths stay one click away. The README argues that the built-in explorer stops working on deep structures because expanding one branch pushes the rest off-screen, and states that a flat, small vault is served well enough by the default explorer.
