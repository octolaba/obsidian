# n23eos/column_explorer

Column Explorer presents a Finder-style Miller-column view of an Obsidian vault, opening each folder's contents in a new column with breadcrumbs for navigation. It supports file and folder creation, rename, move, drag and drop, multi-select, context menus, folder colors and icons, favorites, list or image-grid views, and optional Recents, Bookmarks, and Calendar rows.
