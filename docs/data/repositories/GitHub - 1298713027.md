# sajee05/obsidian-star-tags

Star Tags scans an entire vault for the tags configured in its settings and lists every occurrence, with its surrounding block of text, in an interactive right sidebar panel opened from a ribbon icon. Clicking a result jumps to that line in its note and highlights the block that contains the tag. Occurrences of the todo tag are given a checkbox in the panel that can be ticked as a visual working aid, which the README states does not alter or edit the underlying Markdown files.
