# SZ-1F/Obsidian-Embeds-Plus

Embeds+ extends the file types Obsidian can render in-app, adding Apple Web Archives (.webarchive), standard HTML, MIME HTML (.mhtml or .mht) and Evernote export files (.enex). The README states that opening such a file renders it in a new tab and that the native inline-preview syntax produces an inline preview, and it gives browser steps for capturing web archives and MHTML clips. ENEX support is read-only and aimed at referencing archived content with its formatting preserved, covering standard HTML elements and some Evernote-specific ones such as Mermaid diagrams, TeX formulas, tasks, tags and images. The recorded description marks this repository as a mirror.
