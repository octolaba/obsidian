# m0farhan/casefile

Tracks cases and tasks as plain Markdown files with YAML frontmatter, each carrying a stable issue key, and presents them as a kanban board with swimlanes and WIP limits, a sortable table with inline and bulk editing, and Gantt and dashboard views. A query bar with a compact JQL-like grammar filters by severity, SLA state or indicator and can be saved as a view. The security-operations side adds severity and verdict fields, per-severity SLA policies with live countdowns, an indicator table that refangs and deduplicates pasted values, lifecycle timestamps on an append-only timeline, reports on response times, and a shift handover note. Optional reputation lookups against VirusTotal and AbuseIPDB are the only network use and run only when a row's check button is pressed.
