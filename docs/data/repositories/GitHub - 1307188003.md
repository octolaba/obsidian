# MichelleGDyason/theme-school

Theme School is an Obsidian plugin that teaches theme design through visual controls rather than a blank CSS file, showing the CSS variable behind each choice and exporting a standalone theme whose files depend on nothing from the plugin. The README explains that it is a plugin rather than a theme because a theme cannot provide an interactive teaching interface, and that uninstalling Theme School is the intended final step. Its first release covers separate light and dark baselines, surface hierarchy, contrast, accents, borders, selections and highlights, interface, reading and monospace type systems, type scale and rhythm, corner, input, tab and divider systems, navigation density, and the first hand-written CSS selector. It also checks normal body-text contrast against the WCAG AA threshold, applies live preview reversibly, and treats hand-written graduation CSS as export-only.
