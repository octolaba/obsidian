# KennyRN/storyForge

storyForge turns an Obsidian vault into a storytelling workspace, described by its author as a pre-release built after finding existing storytelling apps either unusable or tied to a web browser. Its README records that vault backups are now written into a folder inside the vault rather than to an external location, a change made in response to Obsidian's warning about external filesystem access and one the author says should also allow the plugin to work on mobile devices. Embedded custom fonts and manuscript typography were moved out into a separate companion plugin, formatForge, to keep the storyForge bundle smaller.
