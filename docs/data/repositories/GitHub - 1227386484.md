# GhostDrift/JiraTicketObsidianPlugin

Jira Ticket Data Fetcher reads a Jira issue key from a note's filename and writes that issue's field values into the note's frontmatter. Field mappings choose which Jira fields are stored under which frontmatter keys, whether each is refreshed when the note opens, and whether it contributes to a note alias built from a template of single-brace placeholders. Connection settings are the Jira base address, an Atlassian account email and an API token, without which no issue data can be fetched. Fetches also run for newly created and renamed notes, a minimum interval between fetches limits API usage, and the issue link can be saved to frontmatter or inserted into the note near a configured marker.
