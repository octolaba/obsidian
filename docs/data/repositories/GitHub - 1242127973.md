# Zhao-Jun-Yong/scholar-quest

Scholar Quest adds experience points, levels and milestone tracking to academic work in Obsidian, awarding points in the background for reading papers, creating and developing atomic notes and writing in project files. The README describes an onboarding wizard that estimates a starting level from academic history across six categories and can pre-fill publications, grants, peer reviews, talks and awards from an ORCID identifier, fourteen project types with predefined milestone templates, a sidebar carrying a tier avatar, progress bar, daily word count, streak counter, activity feed and pending milestones, and a catalog of 52 manually loggable activities across ten discipline categories. It records a design philosophy that gamification should accelerate the work rather than become work itself, which is why points are awarded silently.
