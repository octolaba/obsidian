# llimllib/obsidian-guid-plugin

This plugin adds a unique identifier to the front matter of every Markdown file that is edited, and provides an `Add an ID to all notes` command that applies one across the vault. No repository description is recorded, so this body rests on the README alone. The rest of that README covers the release procedure, which expects jq, gh and make to be installed.
