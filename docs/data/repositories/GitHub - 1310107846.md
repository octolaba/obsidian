# JordanNewell/curtis-ai-chat

Curtis AI Chat is a sidebar chat client for Obsidian that its description presents as polyglot, covering more than thirty providers, an agent mode, a multi-model arena, voice input and output and vault awareness under an MIT licence. The README describes an agent that calls nine built-in tools to read, create and edit vault notes, an arena that streams one prompt to two models in parallel side by side, an inline diff rewrite with an accept or reject modal, and mentions of vault notes inside a prompt. It states that provider keys are stored in the operating-system keychain on Obsidian 1.13 and later and that a local Ollama model can be used instead of a hosted provider; both are the project's own statements and were not verified.
