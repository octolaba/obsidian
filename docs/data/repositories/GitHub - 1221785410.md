# Shynkro/watchlog-obsidian-plugin

WatchLog tracks anime, movies, TV shows, books, manga and games inside the vault through a sidebar panel of eight tabs: a dashboard of progress and library statistics, a watchlist with per-episode and season tracking, games with completion and playtime, reading for books and manga, upcoming releases with countdowns and notifications, custom Markdown-backed lists, drafts scanned from a tag in the vault, and a unified activity log. Each entry is stored as a Markdown note with YAML frontmatter, and inline code-block widgets render live progress inside other notes on desktop and mobile. The README describes API configuration as the only real setup step, pairing each library with a service such as OMDb or TMDB, Jikan or AniList, Google Books, and RAWG or IGDB with optional Steam sync, each card carrying a test button.
