# jianzs/obsidian-qiniu-image-uploader

This plugin uploads images from the clipboard to Qiniu Cloud rather than storing them locally in the vault, and embeds the uploaded image in the note. The README states that a bucket must be created on Qiniu Cloud with an external link domain name configured, and that the access key and secret key come from the key management section of the Qiniu personal centre. Every plugin setting is required except an optional name prefix and time format, and the README records that the project was generated from the standard Obsidian sample plugin template.
