# RiccardoSilvestri/obsidian-spartito

Spartito writes and renders music notation on a grand staff, treble and bass, either from fenced code blocks whose lines are field and value pairs or in a dedicated visual editor with live preview. It covers notes, chords, rests, dotted values and accidentals, splits measures from the time signature with notes crossing a bar line split and tied, and handles beaming and key-signature accidentals automatically, with configurable defaults for time signature, key, tempo and save folder. A score can be saved as a Markdown note and reopened in the editor later. The README records VexFlow and its music font as compiled into the plugin, so rendering happens offline with no external requests on desktop and mobile.
