# OmriLeviGit/Auto-List-Management-Obsidian

Obsidian plugin that reorders checklists and renumbers numbered lists as they are edited. Checked items are sorted to the bottom or to the top, hierarchical reordering moves a checkbox together with its indented content as one block, and pasted or dragged content is handled in the same way. Numbered lists are renumbered while typing, pasting preserves list context, and starting numbers can be kept or reset. The README states that deeply nested lists are handled, that manual commands are available, and that the tab size in the plugin settings has to match the editor's indent setting for indented lists to be parsed accurately.
