# LonoxX/obsidian-github-issues

Tracks GitHub and GitLab issues and pull requests inside an Obsidian vault. The README describes syncing from several repositories on startup or on a background interval, filtering by labels, assignees and reviewers, GitHub Projects v2 boards with custom fields and a kanban view, and parent-child sub-issue relationships with progress tracking. Markdown notes can be created per issue with customizable filename and content templates, YAML frontmatter and persist blocks that keep user content. Configuration takes a GitHub token with repo and read:org permissions, or a GitLab token with read_api scope for gitlab.com or self-hosted instances.
