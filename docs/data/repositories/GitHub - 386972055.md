# clbn/dracula-gemini

Dracula Gemini is a dark Obsidian theme that applies the Dracula colour palette and concentrates on the Editing view in Source mode rather than Live Preview. Its stated goal is that the Editing view sits as close as possible to the Reading view, so that switching between the two leaves the pieces mostly in place while every Markdown formatting character stays visible. To that end the README describes tightened spacing between paragraphs, header prefixes moved out into the text margin, lists, code blocks and quotes aligned horizontally and vertically with the Reading view, and formatting syntax rendered less prominently.
