# anareaty/pretty-properties

Pretty properties restyles the metadata block at the top of a note with images and colors. A select cover image command puts an image to the left of the metadata block, taken from a configurable folder in the vault or from an external link, and adds a cover property that has to stay for the image to show; right-clicking the cover changes the image or its shape, which is stored in cssclasses and can be the initial shape at one of three custom widths, vertical, horizontal, square or circle. Separate commands add a banner, whose image and position are changed from its context menu, and an icon, which may be an image link, a built-in Lucide icon or a symbol such as an emoji; the README notes that cover shapes look different on small mobile screens by intention.
