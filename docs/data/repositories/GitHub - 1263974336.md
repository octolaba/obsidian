# vectorize-io/hindsight-obsidian

Hindsight for Obsidian is a plugin that syncs the vault into a Hindsight memory bank and adds a chat panel answering questions over those notes with citations. The README states the sync is one-way from Obsidian, so the vault stays canonical, that answers cite the note they came from, that conversations are not stored by default, and that editing a note reconverges on the next sync. Sync is recorded as incremental — each note becomes a document, edits upsert, deletions remove, and a content hash skips unchanged notes — running on every edit or on demand, with a status bar indicator reporting the synced count, the last run and pending edits. On ingest each note is tagged with its vault, its folder and ancestors and its created and updated dates, so recall can be filtered by any combination of those, and the chat panel exposes vault and folder scoping and debug logging.
