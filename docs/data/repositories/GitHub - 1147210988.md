# nin0-dev/obsidian-periodic-quotes-widget

This plugin renders quotes inside periodic-quote code blocks and refreshes them daily or bidaily depending on its settings. The README states that the quotes are never written into the file and are only rendered dynamically in the code block, which it suggests makes the plugin a fit for home notes. It also records that the quote data comes from the Quotable API but that the API is never contacted at runtime, and that each code block can be configured with YAML keys for the refresh period and for showing or hiding the block background.
