# Synaptic-Labs-AI/NeuroVox

NeuroVox is an Obsidian plugin for voice recording and transcription inside notes. A microphone icon in the note, an optional floating button, a toolbar icon or a command starts a recording, which is transcribed through the OpenAI Whisper API together with Groq, and custom prompts can then be applied to the transcription to summarize it, extract to-dos or perform other actions. The audio file is embedded in the note and the transcription and generated output are inserted as callouts at the cursor. Setup requires OpenAI, Deepgram and/or Groq API keys and a folder in which recordings are saved.
