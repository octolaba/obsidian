# johanmensah/obsidian-ripple

Ripple is a micro-journal inside an Obsidian vault, described as being in the spirit of Pile by Udara Jay and stated to be an independent project that is not affiliated with or endorsed by it. Posts are plain Markdown files in one linked folder, named by timestamp with a small frontmatter block, and shown in a newest-first feed with a pinned composer, day headers, a month scrubber and keyboard navigation for posting, editing, replying, highlighting and naming notes. The README records branch-aware threads that display continuations and side branches as a collapsible tree, reflections scoped to one note, a thread up to a point, a terminal branch or the whole tree using the AI providers plugin, exports that preserve the visible tree as timestamped Markdown rows, and draft retention when a vault write fails.
