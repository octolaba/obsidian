# pieralukasz/true-recall

True Recall is a spaced repetition system that keeps flashcards, reviews and statistics inside the vault, scheduling with the FSRS version 6 algorithm and its trainable parameters. Cards can be generated from selected text through models reached via OpenRouter, in basic, cloze, reversed and image occlusion forms, and a projects system organizes cards across notes with inherited scheduling presets. Data is stored in a portable SQLite database inside the vault, Anki decks can be imported and cards exported to Anki or delimited text, and a card browser, type-in answering with semantic or diff-based grading, dashboards, calendar heatmaps, forecast charts and embeddable widgets are described. The README states that the plugin requires Obsidian 1.7.2 or newer, is marked desktop-only in its manifest, and is local-first without telemetry.
