# ZHYX91/obsidian-property-order

Property Order adds list-value reordering and configurable property-name suggestions to Obsidian Properties on desktop and mobile. The README states that values can be dragged to reorder inside a top-level YAML list property and moved between supported properties in the same note, that cross-property drag is enabled by default and can be disabled, and that each reorder or move commits through one verified editor transaction, preserving the current list format unless bracket or bullet output is chosen. Native property-name suggestions can be pinned, moved to the bottom or hidden, and sorted by mixed-language name, strict recent-use order, or the number of Markdown notes containing each property, with recent history advanced only after the Metadata Cache confirms the commit.
