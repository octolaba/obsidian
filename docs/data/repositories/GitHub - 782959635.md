# ahmed3developer/rapid-ai

Rapid AI is an assistant for generating content and for acting on selected text, reachable from the sidebar, the status bar, the context menu and the command palette, with keyboard shortcuts and quick-action buttons. The README illustrates the quick actions with grammar correction, translation, diagram generation and adjusting Python code. It states that the plugin talks to a third-party service called the Obsidian AI API, which requires a subscription and an API key pasted into the settings, where a test button checks it, and describes that service as a high-availability API offering unlimited request rates.
