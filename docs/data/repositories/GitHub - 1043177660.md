# glebglazov/obsidian-external-codeblock-editor

External Codeblock Editor opens the code block under the cursor in an external editor and syncs the edited text back into the Obsidian note when the editor exits. It detects the code block language and writes a temporary file with the matching extension, covering more than thirty languages, and the terminal or editor command is configured as a JSON array so setups such as a terminal running Neovim or a direct editor invocation both work. The author states the motivation was getting autocompletion, auto-indent and LSP capabilities from a preferred editor for multi-line snippets.
