# 42MilesZ/obsidian-folder-pin

Folder Pin pins a folder as a tab in the Obsidian file explorer so each project has its own focused view rooted at that folder, with everything else hidden, instead of repeatedly expanding, collapsing and scrolling the file tree. A folder becomes a tab from its right-click menu, tabs are switched with one click, and each tab remembers its own expansion state, scroll position and selected file. A command opens additional independent explorer views, and settings control the tab bar layout, offering grid, vertical and horizontal, and an optional button for going up to the parent folder. The README, written in Chinese, states that the plugin needs Obsidian 1.6.2 and is desktop-only because it uses Node APIs.
