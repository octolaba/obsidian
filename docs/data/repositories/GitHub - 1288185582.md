# vinci0007/obsidian-EncryptSecure-GitSync

Secure Git Sync is a desktop plugin that puts a password confirmation in front of Git push, pull and sync operations for an Obsidian vault, and can additionally store remote note snapshots as encrypted objects while local vault files and the local Git working tree stay plain Markdown. It reuses an existing vault repository and imports its configured remotes without rewriting their URLs, supports GitHub, GitLab, Gitee, AtomGit and generic SSH or HTTPS remotes, and allows several remotes in one vault. Beyond Git it offers direct LAN sync between devices on the same network with device discovery and manual target selection, plus optional syncing of Obsidian settings and plugin runtime artifacts, a conflict review and resolution interface, and an incremental change index kept outside the plugin data file.
