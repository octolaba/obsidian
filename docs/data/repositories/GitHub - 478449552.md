# anpigon/obsidian-book-search-plugin

Obsidian plugin that creates notes by searching for books. A query can be a book title, author, publisher or ISBN in ten- or thirteen-digit form, and the book information comes from the Google Books API. The README documents an optional setting that shows cover images beside book suggestions in the search results, disabled by default so that the results stay text-focused.
