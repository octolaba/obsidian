# 4Source/vare-obsidian-plugin

VARE, the Version and Resource Explorer, manages the plugins and themes installed in an Obsidian vault from inside Obsidian. A specific version can be selected and installed, unlisted ones can be installed from GitHub, and a beta of a plugin can be installed and then switched back from if necessary. The README asks for bug reports, ideas and questions as issues and fixes as pull requests, and explains how non-developers can help by testing pre-releases through BRAT's frozen-version beta installation and reporting the version they tested.
