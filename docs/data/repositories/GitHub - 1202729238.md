# mtplr/obsidian-table-checkbox-row-color

Table Checkbox Row Color is a fork of Table Checkbox Renderer that keeps interactive checkboxes in Markdown tables in Reading Mode and adds row highlighting: a row is highlighted once at least one checkbox in it is checked. Settings choose the highlight colour, a light pastel yellow by default, and turn strikethrough for checked rows on or off. The README repeats the properties of the plugin it forks: multiple checkboxes per cell and per row, changes saved to the file immediately, a robust mapping between rendered checkboxes and the source, and text checkboxes still toggled directly in Edit Mode.
