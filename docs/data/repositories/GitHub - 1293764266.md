# maartenpeels/obsidian-schematex

Schematex for Obsidian renders Schematex diagrams written in a fenced code block carrying the schematex language identifier, covering diagram types such as genogram, circuit, ladder and fishbone. Rendered diagrams sit inline in the note with a hover toolbar for zooming, resetting the view, opening a fullscreen window, and exporting the diagram as SVG or PNG. Settings control when the toolbar appears, the maximum inline height in pixels, the initial fit, and the diagram theme, which can follow Obsidian's light and dark mode or be fixed.
