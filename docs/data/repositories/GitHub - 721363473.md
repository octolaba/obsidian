# HananoshikaYomaru/obsidian-custom-save

Custom save adds its own save command to which further callbacks can be attached. The README's usage is to rebind the save hotkey to this plugin's save command and then add the extra callbacks in its settings tab, and it states the plugin is simple enough that it needs no further documentation.
