# ytahml/obsidian-image-manager

Obsidian Markdown Image Manager handles image paste and drag-and-drop workflows, including naming, compression, local organization, reference updates, browsing, and guarded orphan cleanup. It supports Markdown-reference conversion, batch uploads, and hosting providers such as Aliyun OSS, Qiniu, S3, or custom endpoints, while reverse Markdown-to-Wiki conversion and hosting migration are not supported.
