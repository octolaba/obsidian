# 0ximst1ll/markdoist

Markdoist is an Obsidian plugin that manages Todoist tasks written as ordinary Markdown checkboxes and syncs them in both directions. A line carrying the sync tag, `#todoist` by default, is created, updated, completed or reopened on Todoist and receives an appended identifier marker; due dates use a calendar marker with a YYYY-MM-DD date and a project is selected with a spaceless project tag. A markdoist code block renders a task list from a Todoist filter expression with an optional limit. The README describes the strategy as local-first: tasks are cached locally and edits are queued in a persistent offline queue before being synced in the background.
