# saaralaluf-tech/ObsidianCheckboxState

This repository holds Checkbox State Switcher, an Obsidian plugin that adds a command opening a dropdown to change the checkbox state of the task on the current line. The README states that it works only with a theme supporting multi-state checkboxes and names Cupertino as an example. The recorded repository description calls it a way to change or select list state.
