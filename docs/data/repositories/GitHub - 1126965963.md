# WolfExplode/obsidian-excalidraw-pureref

Excalidraw PureRef turns an Excalidraw board into a reference surface: the active board pops out into a chrome-free, always-on-top window that can be dragged with the right button and toggled between an editable mode and a transparent, click-through mode. Keys crop, flip, move, rotate and scale selected images, reset rotation or size, pack the selection toward an edge, arrange it into a compact block, or normalize images to matching height, width, size or scale. Other commands export selected media to a folder as fresh PNGs of the visible crop, select every element matching one by file, link or geometry, and allow drawing in front of video, PDF, Markdown and web embeds. It is desktop-only, requires the Excalidraw community plugin and Obsidian 1.13.4 or newer, and has been tested only on Windows.
