# johannrichard/alias-linker

Alias Linker resolves a bare wikilink written with an alias to the note that defines that alias, so the explicit filename-and-alias form is often unnecessary. Normal Obsidian behaviour is kept when the link already matches a real file name, the nearest matching note is picked when several notes share one alias, and the fallback also applies in graph view, backlinks, embeds and preview link state. The README calls the plugin experimental, says it builds on a prototype from the obsidian-auto-linker repository, and recommends explicit links wherever an alias is reused deliberately and targeting must be deterministic.
