# benjamonnguyen/obsidian-todotxt-codeblocks

This plugin manages Todo.txt tasks inside a codeblock rather than a separate file, and a block can be linked to an existing text file so changes stay synchronized. The README documents sorting by project, context, status, priority, completion date, due date and creation date, collapsible project groups with edit, add and delete buttons in Live Preview, autocompletion for projects and contexts, and archiving completed tasks to an archive file with an auto-archive setting. Due-date and recurrence extensions are supported, with dates accepted as full dates, month-and-day forms, relative offsets in days, weeks, months, years or business days, and day-of-week abbreviations.
