# dubefab/Matrix

dubefab/Matrix carries a neon-green, cyberpunk Matrix-inspired Obsidian theme with Live Preview parity and an always-on animated gradient and glow on h1 and inline titles. Code blocks are styled as a terminal with a mono font, and links, blockquotes, tables, tags, inputs, menus, tabs, Dataview and Mermaid colours are aligned to the theme variables. The README states that the Style Settings plugin enables an optional digital rain overlay.
