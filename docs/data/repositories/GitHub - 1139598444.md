# Joaq33/obsidian-tag-view-untagged

Tag View Untagged adds an untagged-files entry to Obsidian's Tags sidebar, showing how many notes carry no tag. The indicator can be rendered in one of six styles, among them a search-style gauge, an inline header badge, a pill, a technical token and a badge on the tag view's navigation buttons, and the README records the plain list-item style as not fully working yet. Clicking an indicator opens a suggest modal that lists and searches every untagged note and opens one with a click. The count is kept current as files are created, deleted or renamed and as tags are added or removed.
