# jovialio/obsidian-mdx

MDX Preview compiles and renders MDX files inside Obsidian, with support for Code Hike scrollycoding, code annotations, focus lines and compile-time syntax highlighting. The README positions it against edit-only MDX plugins that register the extension as plain text without rendering it, and describes the project as a fork of yulei-chen/obsidian-mdx rewritten for security, mobile and offline use. MDX JavaScript runs in a null-origin sandboxed iframe with no access to the vault or Obsidian APIs behind a once-per-session consent gate, the renderer is bundled at build time so no CDN is called at runtime, and unresolvable custom React components render as a labelled placeholder instead of breaking the preview. Files of that extension open directly in the preview view, which reloads a short delay after typing stops.
