# deathau/csv-obsidian

CSV Editor opens and edits CSV files inside Obsidian in a spreadsheet-like table, with auto-saving and a per-file header setting persisted in local storage. Cells support Markdown editing and preview, and the table can be sorted by clicking a column name, filtered by column values, frozen by column, and extended with new rows and columns. The README warns that the plugin is experimental and that CSV files should be backed up because data loss is a real possibility.
