# obsidian-power-plugins/obsidian-power-assistant

Power Assistant records meetings and voice memos inside Obsidian and turns them into notes carrying a summary, decisions, action items with owners and dates, and the full transcript with the audio embedded, so clicking a timestamp plays that moment. Transcription runs on a chosen backend - an OpenAI-compatible Whisper service, AssemblyAI or Deepgram for speaker labels, or WhisperX on the local machine - while summaries are written by an Anthropic key or a local model server, with transcripts still produced if neither is configured. Recording covers the microphone and, on desktop, system audio, with pause and resume, crash-safe writing to disk and splitting of long sessions, and existing audio files can be dropped in instead. A meeting can be prepared from a pasted invite, an ICS file or a connected Microsoft 365 calendar, and a recurring meeting carries over what is still open.
