# yuhanbo758/obsidian-yuhanbo-task

Yuhanbo Task is a task manager and Pomodoro timer that stores tasks as Markdown files in configurable vault folders, covering one-time and recurring tasks with progress, due dates, execution dates and subtasks, and archiving completed tasks as Markdown. The timer runs from a ribbon icon or a command, with configurable work and break durations, cycle interval and notification sound. Task splitting into subtasks is optional and off by default: when it is requested, the task title, description and an optional prompt file from the vault are sent to the DeepSeek API, whose key is kept in the plugin's local settings. It supports desktop and mobile, requires Obsidian 0.15.0 or later, and includes no telemetry, analytics or background requests.
