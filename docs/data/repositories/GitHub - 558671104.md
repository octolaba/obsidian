# lucas-fern/obsidian-deeper-work-theme

Deeper Work is a dark theme for Obsidian that continues the no-longer-maintained Deep Work theme and keeps its original colour scheme. Its README lists support for stacked panes with shadows, calendar support, and callout formatting with large titles and ruled lines closer to the Obsidian 0.x styling. The theme is designed around JetBrains Mono when that font is installed and works with its ligatures, and the sample screenshots use that font for every font option in the settings.
