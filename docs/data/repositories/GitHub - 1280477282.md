# fntsrlike/obsidian-file-explorer-size

File Explorer Size adds size labels to Obsidian's File Explorer, showing file sizes and recursive folder sizes, highlighting items above configurable thresholds and toggling the labels from the explorer toolbar. A ranking view lists the largest items in three tabs: physical files, note groups, and folders ranked by the files directly inside them, deliberately pointing at the deepest folder holding a large file rather than every ancestor. A note group is a Markdown note plus the non-Markdown files it links directly, counted once each and not followed recursively. Optional size labels appear in the MAKE.md Navigator when that plugin is enabled; the README states the plugin is desktop-only because it depends on the desktop File Explorer DOM, excludes hidden configuration content because it uses the Vault API, and that its code was generated with AI assistance.
