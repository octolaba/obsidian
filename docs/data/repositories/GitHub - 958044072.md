# LennZone/enhanced-file-explorer-tree

Enhanced File Explorer Tree is a theme for Obsidian that reworks the file explorer so the folder structure reads more clearly. Its README records horizontal and vertical lines drawn with before pseudo-elements to connect files and folders in the explorer tree, support for light and dark colour schemes with customizable background colours, and faint lines produced from CSS variables. It states that the rest of Obsidian's design is kept as it is, with the theme focused only on this visual function.
