# Steven-Theuerl/forest-phosphor-obsidian

Steven-Theuerl/forest-phosphor-obsidian holds Forest Phosphor, a CRT phosphor theme for Obsidian built around the P1 green, P3 amber and P11 blue phosphor types layered over a deep forest substrate. The README states that the theme is dark-only by design, arguing that a paper variant would dilute its identity, and that both the light and the dark class resolve to the same palette so a system auto-toggle is a no-op rather than a broken render. It is described as part of a coordinated palette family spanning Obsidian, VSCode and iTerm2.
