# joshuakto/obsidian-cardify

Splits a note into separate pages, one per line-separated element, and links them back. The README states that the content is divided at a chosen separator, currently either a blank line or a horizontal rule, that an internal link is assigned to each part when none exists, and that one Markdown file per part is created in its own folder, keeping the source note's frontmatter, indexing the page by the position of its part and taking a title from a comment in the content. The generated internal link then replaces the selection, which the README describes as making the parts easy to drag onto a canvas; the demos cover desktop, iPadOS and Android. Several further options, including a toggle for automatic link assignment and regex-based titles, are listed as planned rather than implemented.
