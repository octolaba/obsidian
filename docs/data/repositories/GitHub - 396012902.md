# TfTHacker/obsidian42-jump-to-date

The repository holds Jump To Date, an Obsidian plugin for navigating to a daily note. Its README records two routes: a popup calendar opened from the ribbon, and a form that accepts a date written as a natural language expression. Documentation lives on the author's external site, and the plugin is presented as part of a family of plugins by the same author.
