# loftTech/obsidian-oblogger

Obsidian side-panel plugin that treats tags as the primary organisational tool and logs frontmatter. Its tag explorer shows custom tag groups, with nesting, several tags per file and tags taken from the body or the frontmatter, alongside predefined groups that can be hidden: a recent list cycling between five, ten and fifteen entries, a list of non-Markdown files organised regardless of folder, a daily notes section sorting notes under a configurable tag by year, month and day, and a list of untagged notes. Note icons come from frontmatter, bookmarked notes are marked and placed at the top of their group, and a photo can be used as an avatar for the panel; multi-select and expanded frontmatter editing are listed on the roadmap.
