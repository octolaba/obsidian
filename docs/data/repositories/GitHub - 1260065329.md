# Coldhan258/obsidian-local-bg-image-server

A desktop-only plugin that runs a small local HTTP server so Obsidian's wallpaper setting, which accepts online URLs only, can use images from a local folder: the folder is mapped to the server and the generated address is pasted into the wallpaper setting. The README, written in Chinese and English, records the use of Node's built-in http module with no further dependencies, a server started and stopped with the plugin's lifecycle, a paginated preview of the folder's images with one-click URL copying, and automatic port increment when the configured port is occupied. Its disclosure states that the server listens on the loopback address only and contacts no external service, and that although the default folder sits inside the vault an absolute path may be configured, which then reads files outside it.
