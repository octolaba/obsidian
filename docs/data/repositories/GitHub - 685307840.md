# ebullient/obsidian-day-planner-og

Repository for Day Planner (OG), an Obsidian plugin that manages timed blocks and pomodoro-like timers from a Markdown task list, with status bar updates on the current and next task and a vertical timeline view. It is a fork of the early Day Planner plugin written by James Lynch and keeps that original behaviour, with the Mermaid Gantt chart feature disabled in the interest of stability. The README warns that the plugin writes to the associated note when completing past planner items is enabled, that this can conflict across synced devices, and that it should be tried in a test vault with notes backed up.
