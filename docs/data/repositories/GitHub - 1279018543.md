# kathar0s/obsidian-hwp-to-pdf

HWP to PDF converts Korean HWP and HWPX documents into PDF, and optionally into a Markdown note, as soon as such a file lands in the vault or on demand from the command palette. Conversion runs locally through a Rust and WebAssembly renderer, so the README states that no server, upload or API key is involved and the documents never leave the machine. Three output styles are offered: an image-based PDF that reproduces colour and photographs and carries an invisible text layer for search and highlighting, a small black-and-white text-based PDF, and a Markdown note that reconstructs paragraphs and tables with merged cells as HTML tables. Settings choose the mode, whether new files are converted automatically, whether the source is moved to the trash afterwards, and the render scale, and the interface follows the application language in Korean or English.
