# weizwz/obsidian-vitepress

This repository holds a VitePress-style theme plugin for Obsidian that brings that documentation site's syntax and appearance into notes. The README documents rendering of VitePress colon-fenced containers for info, tip, warning and danger as alert cards with optional custom titles, a details container rendered as a native collapsible element, code blocks carrying a language label and a filename, consecutive code blocks grouped into a tabbed switcher, VitePress-style badges and emoji, and typography, link, and table styling. Obsidian's own callouts are restyled to match the VitePress colours, and a compatibility table records which features work in Reading Mode, Live Preview and Source Mode.
