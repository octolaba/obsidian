# PrEvAl85/obsidian-daily-press

Daily Press is a monochrome Obsidian theme styled after newsprint and thermal receipts: off-white paper with black ink in light mode, an inverted receipt palette in dark mode, and square corners throughout. Interface, sidebars, properties and body text are set in a monospace receipt stack while headings use a serif newsprint face, with an all-caps masthead H1 and dashed or dotted rules below it. Dividers, the tab bar, callouts and the properties block are drawn as perforation lines, tags become outlined clippings, embedded images render in high-contrast grayscale until hovered, and a time element is styled as a receipt stamp. The theme is pure CSS and loads no external assets, building its textures from dashed and dotted borders and repeating gradients.
