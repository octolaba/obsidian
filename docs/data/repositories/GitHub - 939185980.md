# Yeban8090/mp-preview

MP Preview is an Obsidian plugin that converts a note into the format used by WeChat official accounts. Its panel opens from a sidebar icon and shows a live preview in which a template, font and font size can be chosen, and a copy button places the converted content on the clipboard for pasting straight into the WeChat editor; code blocks, tables and images are among the supported Markdown elements. A lock button pauses the live preview so that editing a large document is not interrupted by refreshes. The README is written in Chinese, records the interface language as Simplified Chinese only, and states the license as MIT.
