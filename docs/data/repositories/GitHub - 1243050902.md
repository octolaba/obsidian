# bfgpollara/obsidian-google-docs-paste

Detects Google Docs clipboard HTML on paste and rewrites it into semantic HTML before Obsidian converts it to Markdown, so formatting survives instead of collapsing into bold-wrapped plain text. Bold, italic, underline, strikethrough and sub- and superscript are preserved, headings are detected from font size, nested paragraph wrappers are flattened, Google redirect links are unwrapped to their destination, and tables lose their inline styles and gain a real header row. Images are kept as remote URLs by default or optionally downloaded into the attachments folder, while colour and highlight retention is off by default. The README states that pastes which are not from Google Docs are left untouched, and that the plugin is installed manually rather than from the community catalog.
