# SharbelMarshi/obsidian-math-plotter

No repository description is recorded, so this body is grounded in the README alone. Math Plotter inserts mathematical graphs into Obsidian notes through a form that accepts ordinary math input rather than TikZ, PGFPlots or Octave syntax. Each graph is stored as a small JSON block in the note and rendered as an SVG with a transparent background in Reading View. The README also records dragging to rotate 3D surfaces, draggable labeled points, pinch or Ctrl-scroll resizing that does not recompile, and LaTeX expression input.
