# KraXen72/more-excellent-hotkeys

More Excellent Hotkeys adds editor commands for toggling Markdown formatting, with no default bindings, so hotkeys are assigned by the user. Its main behaviour is that a partial selection is expanded to the nearest word boundaries before the markers are applied or removed, and the cursor position is preserved where reasonable. Commands cover bold, highlight, italics, inline code, comment, strikethrough and underscore, removing formatting, and changing the checkbox type through a fuzzy picker that also works from the editor right-click menu and can promote plain bullet lines. Settings choose the italics marker, enable that promotion and manage the picker's rows; the README credits obsidian-smarter-md-hotkeys for the idea and some code, and notes that heading level commands were removed as out of scope.
