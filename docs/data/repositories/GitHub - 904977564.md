# rama1997/Image-Preview-On-Icon-Hover

Shows an image popup when the pointer hovers over interface icons in Obsidian, with a separate image configurable for the vault switcher, the help and settings icons, the left and right sidebar toggles, and individual ribbon bar and status bar icons. Ribbon and status bar entries can be added, chosen from Obsidian's icon set, assigned an image and deleted from the plugin settings. Image paths are given relative to the vault root.
