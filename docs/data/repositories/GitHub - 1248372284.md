# Telehakke/fluorite

Fluorite adds a floating panel to Obsidian that can display image files from the device and Obsidian notes. The panel is opened from the ribbon window icon on desktop or from the navigation bar menu on mobile; a photo button then selects one or more images from the device to show, and a scan button captures the note that is currently open. The README states that the note is shown as a snapshot taken at that moment: it is read-only and later edits to the note are not reflected in it. Its documentation is bilingual in English and Japanese.
