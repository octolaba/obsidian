# fenjalien/obsidian-typst

Typst Renderer turns typst code blocks, and optionally math blocks, into images by running Typst compiled to WebAssembly. The README notes that Typst exports PDF, PNG and SVG rather than HTML, so rendered views can suffer from image scaling, that file paths are taken relative to the vault folder, and that the WebAssembly file is downloaded separately the first time the plugin is enabled and after each update. On desktop it reads packages from the preview and local namespaces, while mobile supports the preview namespace only and always downloads missing packages into the vault, and a table records which plugin version targets which Typst version.
