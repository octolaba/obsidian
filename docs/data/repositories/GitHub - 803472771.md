# bhappen/obsidian-space

Obsidian Space is a space-themed Obsidian theme for desktop, mobile and tablet. Its listed features are deep space backgrounds, glowing elements and futuristic fonts, optimisation for low-light environments to reduce eye strain, space-themed icons for files, folders and common interface elements, and high-contrast text chosen for legibility. It is applied from Settings, Appearance, Themes and Manage, and it is licensed under the MIT License.
