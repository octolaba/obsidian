# mshr-h/obsidian-vault-backup

Vault Backup is an Obsidian plugin that creates local ZIP archives of an entire vault with automatic retention management. The README describes manual backups from a ribbon icon or command, automatic backups on startup or shutdown, atomic ZIP creation through a temporary file and rename, template-based filenames with date and time variables, configurable exclusions, and inclusion of dotfiles. Retention can keep the last N backups, keep those within a number of days, or combine the two conditions with AND or OR, and named profiles selected per device let one synced vault use different settings on each desktop; the plugin is documented as desktop-only.
