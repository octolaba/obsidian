# Maclean-D/obsidian-pocket

Pocket Sync imports conversations and insights from the Pocket service into Markdown notes in an Obsidian vault. A conversation is split into separate transcript, summary, action item and mind map notes under a dated folder, insights tagged as highlights are written to their own folder, and both folders and filename templates are configurable. Pocket metadata is written as ordinary Obsidian properties and the imported text is kept inside a managed block so surrounding notes of one's own survive a re-sync. The README records manual, startup and automatic sync, an API key held in local plugin data, and no telemetry, backend or audio download.
