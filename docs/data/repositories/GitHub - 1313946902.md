# 2D3DTreasures/obsidian-canvas-to-pdf

Canvas to PDF exports an Obsidian canvas as a vector PDF, a standalone HTML file, or both, keeping the text selectable and searchable instead of rasterizing the board. Connector lines, arrows, their colors and labels are preserved, sub-canvases are rendered up to five levels deep, and embedded note cards, images, web link cards, video thumbnails and PDFs are carried over. Export runs from the canvas toolbar, the command palette or the tab context menu, with settings for the output path, nesting depth, node labels and the browser path. Rendering drives a locally installed Chrome or Edge over the DevTools protocol on loopback, so it is desktop only and requires one of those browsers.
