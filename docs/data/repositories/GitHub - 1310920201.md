# lucytheboss/obsidian-ribbon-hider

Obsidian Ribbon Hider removes individual buttons from the left sidebar ribbon: right-clicking a button, or touching and holding it on mobile, offers to hide that button immediately. A settings tab lists the active ribbon buttons so hidden ones can be toggled back, restores all of them at once, and tracks entries left behind by disabled or removed plugins so they can be cleaned up. Visibility is toggled with CSS rather than by removing elements, and the plugin requires Obsidian 1.13.0 or later on desktop or mobile.
