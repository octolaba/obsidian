# Kovah/obsidian-wakatime

This plugin tracks the time spent working on notes in Obsidian by sending heartbeats to the WakaTime API, or to a self-hosted Wakapi instance reached through a custom URL. A default project can be set, or folders and files associated with different projects, and an ignore list keeps specific files or folders from being tracked. PDFs and images are tracked alongside Markdown files, with Markdown reported as the language for the corresponding files. The README states that the author wrote it because the official WakaTime plugin lacks some features, that setting a custom URL is easier here, and that installation is lightweight because it does not use the wakatime-cli client.
