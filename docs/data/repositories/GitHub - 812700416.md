# anareaty/creme-brulee-obsidian-theme

anareaty/creme-brulee-obsidian-theme records no repository description; its README describes the theme as minimalistic but cozy, built from soft colours and many small adjustments. It recolours some standard Markdown formatting so notes can carry colour without raw markup, and warns that those colours appear only inside Obsidian and are not preserved when notes are exported. It also documents three cssclasses values that hide the inline title, the backlinks or the properties per note, a properties heading removed with its fold button revealed on hover, a sidebar button dropped on mobile because a swipe opens the sidebar, and narrower blank lines between paragraphs in Live Preview. The author records the theme as deliberately lightweight, with probably no settings to come.
