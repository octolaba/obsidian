# rocketBANG/obsidian-icon-picker

Icon Picker previews and picks Lucide icons stored in a note's `icon` frontmatter property, which the README identifies as the property the Bases map view reads for marker icons. A note carrying the property shows the rendered icon beside its value in the Properties panel and inline in Source mode, with a dimmed placeholder when the value is not a valid icon name, and the preview doubles as a button that opens the picker. Two commands set the icon through a fuzzy-search modal over the full Lucide set and remove it again, and the property name defaults to `icon` but is configurable; because Obsidian bundles Lucide, the README states that the plugin has no runtime dependencies and works offline. This note is grounded in the README alone, as the repository records no description.
