# Enthusjast/obsidian-punctuation-converter

This repository holds an Obsidian plugin that automatically converts Chinese punctuation to the corresponding English punctuation. Conversion runs in real time on newly typed text, over the whole active file from a ribbon button or a command, or over a selection through a context-menu entry. Individual conversion rules can be enabled, disabled, added or deleted in the settings, which also document the mapping from marks such as the full-width comma, period, colon and bracket pairs to their ASCII equivalents. The interface language follows Obsidian or can be fixed to English or Chinese.
