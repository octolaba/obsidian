# KennyRN/languageForge

The repository records no description; its README presents languageForge as a pre-release name generator for Obsidian built on constructed languages rather than a Markov model. A command or ribbon icon creates a small conlang from a chosen mood and register, and a generate step then produces batches of names by category — people, houses, places, titles — each with a pronunciation guide and a meaning, which can be inserted into the current note. The README also describes building a family tree of languages so that languages evolve across generations, mix, and split into dialects or separate languages. It states that Obsidian 1.13.0 or newer is required and that the plugin is installed manually or through BRAT until it is accepted into the directory.
