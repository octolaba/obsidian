# qf3l3k/obsidian-sqlite-explorer

Repository for SQLite Explorer, a desktop-only plugin that browses SQLite database files stored in the vault. Its README describes opening a database from the file tree into a dedicated view with a table selector, schema inspector, read-only query runner, copy to Markdown and CSV export, and rendering query results inside notes from a fenced block in table, list or value form. It also records converting a live query block into a static Markdown table frozen at one point in time, configurable row limits, and remembering the last selected table per database.
