# gquental/obsidian-window-collapse

Window Collapse collapses Obsidian's sidebars from commands, which the README presents as a way to gain screen real estate without switching to fullscreen. Three commands are provided: toggle the left sidebar, toggle the right sidebar, and toggle both together. No hotkeys are assigned by default, so they are left to be bound in Obsidian's settings panel.
