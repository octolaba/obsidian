# eatgrass/obsidian-pomodoro-timer

This plugin integrates a customizable pomodoro timer into the Obsidian workspace, with work and break intervals set by the user, audible alerts at the end of a session, and progress shown in the status bar. The README records logging of sessions into daily notes and task tracking that refreshes the actual time field of the task in focus: a pomodoro inline field is written after the task's text and updated at the end of each work session, and the README warns that it must be placed before the Tasks plugin's own fields or the task may render incorrectly. A custom notification sound is set by putting an audio file in the vault and giving its path with the file extension relative to the vault root, with a play button beside the setting to verify it.
