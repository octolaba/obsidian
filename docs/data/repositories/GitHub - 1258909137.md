# lumargh/obsidian-file-filter

File Filter offers two filters in Obsidian: a paragraph-level filter for the editor and a live filter for the Files pane, hiding everything that does not match the search term. In the editor a filter field opens from an icon in the note header or a hotkey; non-matching paragraphs are hidden, optionally collapsed into an ellipsis marker, and matching text is highlighted, while an exclude mode inverts the filter so paragraphs containing the word are the ones removed. The queries task, todo and done additionally match unchecked and completed task syntax, and a preserve-structure setting keeps the headers above a matching block visible. The file explorer filter matches any case-insensitive substring of the full path including folder names; the README notes the editor filter is designed for Live Preview and Source mode and is known to be buggy in reading view.
