# papaya2k/obsidian-lectern-theme

papaya2k/obsidian-lectern-theme holds Lectern, an Obsidian theme matching the default light and dark appearance of Lectern, a Qt6 markdown viewer. It pairs near-black or white chrome with a muted rainbow heading palette, running blue H1, purple H2, gold H3, green H4, terracotta H5 and grey H6, and the README tabulates the background, text, link and code colours for both modes. It is published under the MIT license.
