# PaolinPaperin/obsidian-wikiflash

Briefly flashes the brackets of a wikilink, a cue the README compares to Xcode flashing the matching brace when a block is closed. It fires when a link is created, the moment Obsidian adds the closing brackets, and when the cursor moves into an existing link by arrow key or click, leaving the link text untouched; the flash rises to full colour, holds and then fades back. Settings turn the effect on or off and set box and bracket colours separately for light and dark themes, with sample previews, an opacity and a duration, and the README states that the appearance carries over into pop-out windows.
