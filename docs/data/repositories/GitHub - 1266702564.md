# Brightwav3/Paper-Source

Paper Source is a standalone Obsidian theme with a soft mint-paper typewriter look and warm green and orange accents. Source Code Pro is used across editor, interface and code at a 16px base with 1.6 line height, headings step through a green gradient from h1 to h6, bold and italic text is warm orange, backlinks are underlined in tan, and reading view is justified with automatic hyphenation at a 72ch measure. The light mode is mint paper and the dark mode is Monokai-inspired with crisp mint text, and the README records the palette hex values for both.
