# aegerita/journal-recap

The recorded description says Journal Recap is an Obsidian plugin using ChatGPT and based on the Auto Classifier plugin. The README states that it summarizes a daily journal entry through the OpenAI Responses API and writes a one-sentence summary into the note's frontmatter, once an API key, base endpoint and model are configured; a custom prompt and response schema can be enabled in advanced settings. Its privacy section records that running the command sends the note content, excluding frontmatter, to the configured endpoint with that prompt and a structured output schema, that the test button sends a short message to the same endpoint, and that the key, endpoint, model, prompt and schema are stored in the vault's plugin data. It states that requests set store to false and that the plugin carries no telemetry and sends data nowhere but the configured endpoint.
