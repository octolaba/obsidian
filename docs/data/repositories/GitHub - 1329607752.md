# mikagosz/obsidian-diary-stats

Draws a set of charts inside a weekly, monthly or yearly periodic note from a single diary-stats code block, working out the period from the note's own frontmatter keys. The panels cover projects as a donut, sessions over time, the four weeks of a month, task states read from the planned, in-progress, done and dropped checkbox markers, key metrics with a sparkline and the change against the previous bucket, and goals when a goals section exists; a panele line selects a subset. Sessions are links to date-prefixed notes, projects come from each session note's list property or its project tags, and settings cover folder names, the goals heading, project-name folding and how many projects get their own color. The interface, month names and block keywords are Polish, and light and dark use two separately chosen palettes.
