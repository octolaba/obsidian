# huydnd/night-owl-obsidian-theme

huydnd/night-owl-obsidian-theme holds a Night Owl theme for Obsidian inspired by Sarah Drasner's Night Owl theme for Visual Studio Code, with a deep blue #011627 dark mode and a soft high-contrast #f0f4f8 light mode. Through the Style Settings plugin it offers translucent sidebars with background blur, a glowing effect on H1 to H3 headings, high-contrast borders around active panels, separate interface and monospace font controls, and an adjustable readable line width.
