# huangchen-byte/obsdian-fingertip-translation

Fingertip Translation is a selection-translation plugin for Obsidian that looks up the selected text and shows the result in a draggable popover with phonetics, part of speech and definitions. Lookups go to Bing Dictionary, Youdao or MyMemory without an API key, triggered either by holding Ctrl while selecting or by plain selection, and pronunciation can be played from a speaker button or automatically, using Youdao audio or browser text-to-speech in a US or UK accent. Settings control the service, the trigger mode, the accent, whether phonetics and exam categories such as CET-4 and CET-6 are shown. The README also documents an optional integration with the Weave memory plugin and a lookup method other plugins can call for dictionary results without opening the popover.
