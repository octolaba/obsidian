# rouvenjahnke/markwhen-file-sync

Markwhen File Sync synchronizes properties from Obsidian notes with a Markwhen timeline file. The settings hold the path to the timeline file, the folder of notes to synchronize or blank for the whole vault, the name of the tag property in those notes and the tags a note must carry, and bidirectional synchronization can be enabled so that date and end-date values travel in both directions rather than only from the notes to the timeline. The README also records customizable grouping and sorting, filtering options, automatic synchronization and status tag support, and it names goal planning as one use case.
