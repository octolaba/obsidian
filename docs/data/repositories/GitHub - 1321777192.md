# Samuel-YSZ/expandable-folder-bookmarks

Bookmark Folder Expand lets a bookmarked folder expand in place inside Obsidian's Bookmarks pane, showing its contents and subfolders without switching to the file explorer. Inline items behave like explorer items: files open on click or in a new tab with Ctrl, Cmd or a middle click, the active file is highlighted, the native Bookmarks context menu applies, items drag and drop through Obsidian's own drag manager, and ordering follows the File Explorer. Expansion state persists across pane reopens and restarts, and the plugin does not scan the vault at startup, poll the file system, or render a folder's contents before it is expanded. It requires Obsidian 1.13.0 or later, works on desktop and mobile, and makes no network requests.
