# ds-package/Dawn

Dawn is an Obsidian theme built around the quiet of the dawn hours, offering soft dark and light modes, a spacious interface and fine-tuned Markdown writing and preview. Its version 2 adds a paper-notebook feel with ruled lines and an analog texture, a direction the README credits to another author's post on note formats. The README also records a deliberate colour decision: pure white and pure black were excluded from the design tokens, so the theme stays low in contrast, and while readability and accessibility were considered the author does not claim they are perfect and names a high-contrast variant as a possible later addition. The README is written in both English and Korean.
