# mo-seph/obsidian-note-from-template

The repository holds Notes from Template, an Obsidian plugin that creates a note from a template file and fills in its fields. Its README records that every file in a configured templates directory becomes its own command, and that running one opens a dialog asking for a value for each variable written in Mustache syntax. Template frontmatter controls the behaviour: keys record the output folder, the input fields to request, a replacement text to leave behind at the invocation site, and whether the new note should be created in an open pane.
