# KulySocc/obsidian-bumblebee

Bumblebee is a warm, high-contrast Obsidian theme with near-black backgrounds, an amber accent and a separate red for emphasis, so that bold text does not read as clickable. Dark mode is the primary design target, and light mode uses darker accent variants that the README says meet WCAG AA contrast on white. Code syntax highlighting is tuned to the palette, the Kanban plugin is styled, and the Style Settings plugin adds header underlines, per-header colours and Kanban layout options. The README describes the theme as a single-file CSS artefact with no build step.
