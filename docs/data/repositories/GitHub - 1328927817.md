# NoteNerdOfficial/working-tabs

Working tabs treats each pane of tabs in the main workspace as a group, named and listed in a sidebar with no create step, and lets groups be filed into sections standing for a timeframe such as a sprint or deadline. Groups and sections are colour-coded as a stripe down the pane's left edge and a matching bar on the sidebar row, and a filed group takes its section's colour. Hiding a group tucks its pane away without closing it, so anything running inside keeps running, while completing one closes the pane and moves it to a recoverable Completed list; a whole section can be hidden in one click, deleting nothing. Rows reveal or reopen their pane, groups can be opened as a split, new tab or new window, and terminal tabs are tracked only while Obsidian stays open.
