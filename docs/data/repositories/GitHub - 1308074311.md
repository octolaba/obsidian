# PavelPeng7/omni-workbench

Omni Workbench turns task notes and frontmatter already present in a vault into a home dashboard and task workbench, showing the current focus, an idea inbox and recent knowledge notes alongside task filters for today, active, in-progress, overdue and completed items. It creates, edits, completes and deletes task notes, runs a focus timer whose state is stored in each task's frontmatter, and reads tasks from a configured folder through a configurable field mapping that can also be exposed as an Obsidian Bases view. The README states that the plugin is local-first, makes no network requests, collects no telemetry and uploads no vault content, and that a one-click initialization creates the recommended folders and a starter template without overwriting existing files.
