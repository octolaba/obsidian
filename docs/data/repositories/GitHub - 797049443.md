# voicenotes-community/voicenotes-sync

Voicenotes Sync brings notes down from the Voicenotes web and mobile apps into an Obsidian vault, on a configurable interval in minutes. AI-generated summaries and actions become sections in the note text, TODOs are converted into Markdown todos with an optional tag appended to each, the sync directory and frequency are configurable, the source audio file can be downloaded although that is off by default, and the date can be prepended to the title and filename. An optional mode deletes synced notes from the Voicenotes server, which the README marks as a destructive action gated behind two opt-in toggles. Connecting an account requires retrieving an access token from the integration settings of a Voicenotes account.
