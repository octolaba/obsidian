# rwirdemann/obsidian-week-planner

Week Planner organises todos into three documents, an unordered inbox, goals for the current week, and an ordered list for today, each held in its own folder. Commands create or show those notes and move tasks between them, and the tasks follow todo-specific markup rules. The README presents this as the author's personal working process rather than as a general system.
