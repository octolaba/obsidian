# ullmannJan/obsidian-tiff-viewer

Obsidian Tiff Viewer makes TIFF images displayable in Obsidian by creating a PNG copy of every TIFF linked in the current file and rewriting the links to point at that copy. The README explains that browsers, and therefore Obsidian, cannot show the format natively although it stays common in science, and that the converted copy is written beside the source file. Four commands are documented: one converts and renames the links in the editor, one renames the links back and deletes the generated copies, and two debug commands delete every generated file in the vault or rename links back without deleting anything.
