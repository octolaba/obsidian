# tadashi-aikawa/obsidian-embedded-code-title

The repository holds the Embedded Code Title plugin, which shows a title above a fenced code block. Its README documents the syntax as a colon after the block's language, followed by a file name or left empty to display the language name alone, with an escape for spaces in the file name. It warns that the plugin depends on Obsidian's internal DOM structure and may stop working, and it records a route for using the same rendering on an Obsidian Publish site with a custom domain.
