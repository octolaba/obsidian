# philphilphil/obsidian-standardform

StandardForm renders a code block written in its own standard-form syntax as a styled table, which the README offers for the logical reconstructions of philosophy, logic and formal notation. Premises are written one per line, optionally prefixed by an identifier that ends in a colon or a period, and an inference line — a pair of dashes, with or without text between them — draws a rule beneath them, while a doubled form draws a double line for an inductive inference. Identifiers may be omitted, and a colon or period inside the text of a premise or conclusion has to be escaped with a backslash.
