# IdreesInc/Waypoint

Waypoint generates a table of contents inside a folder note, which the README defines as any note carrying the same name as its parent folder. A waypoint is created where the configured trigger word is typed in that note and then links to every note in the folder and its subfolders, so a folder gains a node in the graph view without index files or tag upkeep. Creating, renaming, moving or deleting a file triggers a scan for affected waypoints, which are updated in place. The README states that development is now maintenance rather than new features and points readers wanting more conveniences to a different folder-overview plugin.
