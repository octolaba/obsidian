# CocoaAI-IT/ob-cocoa-marp

A fork of the obsidian-marp-slides plugin that creates and presents Marp Markdown slides inside Obsidian; the recorded description states in Japanese that it brings Marp support to Obsidian. The README documents a live preview pane for the active Marp note, fullscreen and popout presentation, a presenter view with current and next slide, speaker notes and an elapsed timer, a laser pointer toggled with the L key, custom theme CSS and three bundled themes. Export to HTML, PDF, PNG and image-based PPTX is performed by the Marp CLI, which is not bundled and must be installed separately together with Chrome, Chromium or Edge, while the editable PPTX export uses PptxGenJS inside Obsidian and requires neither.
