# sveekey/yoga-workout-importer

This plugin builds a yoga workout note in Obsidian from text copied out of a Telegram message, or from a form filled in by hand, and assembles it entirely from files already stored in the vault. Workout diagrams come from a folder of materials organised by level, where each file must be named exactly after the algorithm it illustrates; anything missing is requested one item at a time through the system image picker and copied into place under a canonical name. Accepted material formats are PNG, JPG, WebP, GIF and PDF up to 25 MB, with one file per workout element. The finished note opens with a summary card carrying date, client, level, estimated time and the numbered list of algorithms, and is filed under the client named in the text or under a default folder; the plugin contacts no external server.
