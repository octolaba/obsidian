# irbull/obsidian-ai-summary

This plugin uses an OpenAI model to summarize the notes referenced from the current Obsidian note. The Summarize referenced notes command finds every link in the note, generates a summary of each linked note and shows the result in a dialog; existing notes are never updated, so the summary is copied out by hand. The prompt may be set in the note's front matter and otherwise falls back to a default prompt in the settings, next to the API key and a maximum token count, and the README suggests weekly and monthly summaries as the main use.
