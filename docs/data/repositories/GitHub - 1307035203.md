# oemer-kara/clang-format-obsidian-code-blocks

Clang-Format Code Blocks formats fenced code blocks in Obsidian notes by piping each block's contents through `clang-format` and replacing the block in place with the result, leaving other languages and nested fences untouched. The README records two requirements: desktop Obsidian only, because it uses Node's `child_process`, and a reachable `clang-format` binary either on PATH or named directly in the settings. Recognized fence tags cover C, C++, Objective-C and Objective-C++, C#, Java, JavaScript, TypeScript, JSON, Protobuf, TableGen, Verilog and SystemVerilog variants. Two commands format every matching block in the note or only the block at the cursor, and format-on-save runs on an explicit save rather than while typing.
