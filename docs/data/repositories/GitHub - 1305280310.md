# SakenW/trans-hub-obsidian-localizer

Trans-Hub Localizer applies published translations to the names, descriptions, settings, commands and interface text of supported community plugins, changing only Obsidian's presentation layer and leaving third-party plugin files and vault notes unchanged. The README states that runtime localization uses exact, version-aware matches and excludes Markdown editors, reading views, code, scripts and editable content, and that disabling localization restores the original text immediately. The reader selects a display language and one, several or all enabled plugins, with source-language detection automatic; the README also records that most translations on the platform are machine-generated and labelled as not human reviewed.
