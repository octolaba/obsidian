# WebInspectInc/obsidian-simple-template-importer

Simple Vault Importer installs template vaults into an existing Obsidian vault from a zip file: a command asks for the archive, imports its Markdown files and places CSS files into the appropriate snippets folder. The README records the motivation as the number of manual steps otherwise involved, since drag-and-drop is not supported on every platform, templates belong in the configured templates folder and snippets in a hidden folder. Name conflicts raise an error by default, which is resolved either by configuring an import folder or by enabling an overwrite setting, and plugins are recorded as ignored for now with basic plugin management named as a later goal.
