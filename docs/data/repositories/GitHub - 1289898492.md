# NabheetCloud/obsidian-gmail

This repository holds Gmail Mailbox, which the upstream description calls an Obsidian Gmail plugin. The README describes syncing Gmail into the vault as one Markdown note per email with YAML frontmatter, plus a regenerated thread index per label, and mirroring Google Calendar into an upcoming-meetings sidebar with one note per event cross-linked to related emails. Sync is incremental through the Gmail history endpoint after a first full enumeration of the label, and attachment download is optional and size-capped. The README states that the user must create their own Google Cloud OAuth client with the Gmail and Calendar APIs enabled.
