# anthonyfitzpatrick/manuscript-compiler

Manuscript Compiler compiles structured Obsidian manuscripts into publication-ready DOCX, ODT, EPUB, HTML, Markdown and XML files for Vellum and other publishing workflows. The README states that the plugin reads a book as parts, chapters, scenes, front matter and back matter rather than as a collection of files, detects that publishing structure, and lets the author review inclusion, roles and order before only the approved manuscript is compiled. It describes the flow through manuscript, contents and file-creation stages, keeping research and development notes out and creating the file locally without rewriting the Markdown source.
