# rogerfan48/better-heading-hierarchy

Better Heading Hierarchy adds guide lines to Markdown headings in Obsidian so the nesting of heading levels is visually clearer. The README states it installs from the community plugins panel and recommends the default theme with the author's additional styling enabled, together with specific CJK and monospace fonts, to reproduce the look shown in its demo image.
