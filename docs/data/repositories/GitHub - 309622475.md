# ivan-lednev/obsidian-day-planner

Day Planner adds editable calendar views and basic time tracking, opened as a sidebar timeline, a multi-day planner, or a mini timeline in the status bar covering the next few hours. Records are drawn from daily notes, from the Tasks community plugin, from online calendars given a shared link, and from Dataview clock properties, with blocks coloured by source. Time tracking works by recording clocks that then appear in the timelines, and the README states that either the core Daily Notes plugin or the Periodic Notes community plugin is required for the daily-note source.
