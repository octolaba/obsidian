# uzusio/obsidian-sr-popup-review

Popup Review for Spaced Repetition periodically checks for due cards and opens an unobtrusive desktop popup that reveals an answer and records Again, Hard, Good, or Easy ratings through the Spaced Repetition plugin. It supports keyboard shortcuts, Markdown and cloze rendering, manual opening, pause and do-not-disturb controls, deck filters, interval settings, and optional fullscreen suppression.
