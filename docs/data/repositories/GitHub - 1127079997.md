# kissyjpf/rtm-sync

Synchronises Obsidian tasks with the Remember The Milk service, importing due dates, priorities and tags, adding a task to the service from the current line, and completing one from inside Obsidian. Tasks are linked back by a stable Markdown link at the start of the line so identifiers survive edits, and the format is documented as compatible with the Obsidian Tasks plugin. Later versions add creating separate notes from tasks in a chosen folder, importing task notes and web links as sub-bullets, writing a link back to the Obsidian note into the remote task, and applying a default due date to newly added tasks.
