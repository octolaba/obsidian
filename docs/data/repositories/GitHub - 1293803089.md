# agarcabin/obsdian-tag-to-page

Tag to Page changes what clicking a tag does in Obsidian, navigating to the note of the same name in reading view and live preview instead of opening a tag search. The README, written in Chinese and English, records that the plugin intercepts clicks on tag elements during the DOM capture phase, resolves the target through the metadata cache and then through frontmatter aliases, and creates an empty Markdown file when nothing matches, including parent folders for nested tags. It also documents opening in a new pane with a modifier key and an optional page completion offered when the hash character is typed, which the README notes replaces the default wiki-link completion provider.
