# Developer-Mike/obsidian-calctex

Calculates the solution of a LaTeX formula automatically, using the CortexJS Compute Engine. The README states that adding an equals sign after a formula displays the computed solution, and that clicking the solution or pressing Tab writes it into the document. Installation is described from the community plugin list or by copying a release into the vault's plugin folder.
