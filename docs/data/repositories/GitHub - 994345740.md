# CubieProg/Obsidian-Yandex-Wiki-Integration

Yandex Wiki Integration connects Obsidian to a Yandex Wiki knowledge base. Its README describes a start-up path in which the path to a browser executable is set in the settings, a sign-in button opens an authorization flow, and the wiki tree then appears inside the plugin panel. A directory in that tree is marked as the working directory from its context menu, after which an export command copies the knowledge base into it, showing progress on a bar beneath the panel buttons. The README is written in Russian and defines slug as the Yandex Wiki term for a path to a directory.
