# xXxGeorge/obsidian-engnese

Engnese lets Chinese text be typed in Obsidian without switching input methods: English letters typed in the editor are treated as pinyin in the background, and accepting a candidate replaces the already-inserted token with Chinese characters in place. The README states that candidates come from local Rime dictionary files including imported tables, that the longest valid prefix is used when the whole token has no match, and that completion is suppressed inside fenced code blocks, inline code and math. Candidate shortcuts, paging and an optional double-space to accept the first candidate are configurable, and the plugin is desktop-only because it reads dictionaries from the local filesystem.
