# fnsign/transvault

Trans Vault copies and moves files, multi-selections and folders from the active vault into other local Obsidian vaults configured as destinations, and the README states that it is desktop only. Selected folders keep their internal structure below the destination path while standalone files are written flat, wiki links and standard Markdown links are rewritten when both ends of a link are transferred, and conflicts are handled by skipping, auto-renaming or overwriting. A review dialog for explicitly selected Markdown files shows direct outgoing and incoming link relationships as a tree. Each destination records a name, vault path, destination path and attachment path, all absolute and constrained to the destination vault root, and a move deletes the source only after the destination write succeeds.
