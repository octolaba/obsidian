# rvzenteno/O-Timebox-Daily

TimeBox Daily builds a daily timeboxing note containing a focus area, morning, afternoon and evening time blocks, tasks, a brain dump and reflection sections, creating or opening it from a configurable folder. Unfinished tasks and brain dump items are carried forward to the next day automatically, without duplicating entries. Projects live in their own notes under a TimeBox projects folder and appear in a sidebar dashboard with progress bars and backlogs, where a backlog task can be pushed into today's note in one click and completed tasks can be hidden. Completion state is synchronized between daily notes, project notes and the dashboard, and tasks written with a project wikilink are linked and updated automatically.
