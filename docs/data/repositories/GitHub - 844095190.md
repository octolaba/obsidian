# Yohh/obsidian-simple-sketch

Simple Sketch creates minimal sketches in a dedicated view, opened from a ribbon icon showing a pencil and ruler or by right-clicking an image file and choosing to open it with the plugin. The view supports freehand drawing, generating lines, rectangles and ellipses, and adding text, and a sketch is either saved into the vault or downloaded as an image. The README describes the interface as minimal and convenient, emphasising productivity over completeness.
