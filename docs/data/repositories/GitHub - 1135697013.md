# imed-ghomari/super-add-obsidian

SuperAdd creates a task file from a single natural-language line, parsing the title, tags, a time estimate, due and scheduled dates and times, and recurrence phrases that it turns into an RRULE. User-defined properties of string, number, boolean, array, date and datetime type are recognised inline by name or value, optionally through a regular expression, and a chosen template supplies the frontmatter: every template key is written, values from the modal or the parsed line override the template, unfilled keys are written as null, and the template's key order is kept with non-template keys appended. The README also records a live preview that shows the properties as pills and a file picker, opened by typing a hyphen, that inserts a link.
