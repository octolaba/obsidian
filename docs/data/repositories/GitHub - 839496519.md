# Erallie/diarian

Repository for Diarian, an Obsidian journaling plugin that the README describes as bringing functionality from the Diarium journal app into Obsidian, and as unofficial to both. It adds a calendar view marking which days have daily notes, opening or creating notes from it, commands for moving between daily notes, and attached images shown on the day tiles. An 'On this day' pane in the sidebar reviews earlier notes at a configured interval and starting distance in the past, with a notification when notes are due, and further features include importing an existing Diarium journal, a per-note rating shown in the status bar with customisable characters, a template inserted into new daily notes, a timestamp command, and support for several notes per day.
