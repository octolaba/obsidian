# MarcosNicolau/obsidian-mathematica-plot

Obsidian Mathematica Plot draws mathematical graphs in notes using Wolfram Mathematica code, covering 2D and 3D graphs, previewing a graph while editing and editing a graph that already exists. The README states that wolframscript must be installed, and that a plot command opens fields which accept Mathematica code. It also records that creating an image file with a wikilink and plotting several graphs in a row were unfinished, and that the plugin was not yet a registered community plugin and had to be cloned into the vault's plugins directory and built.
