# PixeroJan/obsidian-indent

Indent disables Markdown's indented code blocks in Obsidian so that tabs and leading spaces read as ordinary indentation in Live Preview. Rather than changing the parser, the plugin rewrites the start of an affected line right after an edit: a line beginning with a tab or four or more spaces gets a zero-width non-joiner (U+200C) in front of its indentation, which breaks the indented-code-block rule while leaving the indentation visible. Lines inside YAML frontmatter, fenced blocks, lists and blockquotes are left alone, the change is applied in the editor only, and the behaviour can be toggled in settings. The README states that this deliberately deviates from CommonMark.
