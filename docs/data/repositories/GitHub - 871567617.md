# Appleec/e-obsidian-upload-plugin

Obsidian plugin for uploading files from a vault to an external store, offered through a right-click menu entry. The README documents configuration for the Lsky Pro image host, the Halo blog engine and GitHub, in each case as an upload API address, JSON request headers carrying an authorisation token, a JSON request body with a built-in field standing for the binary file, and the path within the JSON response at which the resulting URL is found, optionally prefixed. Each target therefore requires credentials for that service.
