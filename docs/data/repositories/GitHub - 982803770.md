# isax785/Terminal2K

Terminal2K is an Obsidian theme that reproduces a classic command-line look, with crisp white text on a deep black background and green accents marking bold, italic and inline code. The README presents it as a distraction-free writing and organizing environment echoing older terminals, with colours chosen for comfortable reading over extended sessions and ongoing updates driven by community feedback. It is installed from Obsidian Settings, then Appearance and Manage, by searching the community themes for Terminal2K.
