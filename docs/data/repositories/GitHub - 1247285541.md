# xiaoyihuang0503-cyber/obsidian-open-bridge-ai

Obsidian plugin offering a chat workspace whose context is assembled from the vault instead of being pasted in again. Files and folders from the explorer, selected Markdown text together with its file path and nearby lines, and whole or partial AI replies can be attached as context chips, and sessions are saved as Markdown inside the vault for later search and review. It talks to Claude, Codex or a custom command-line tool, and to OpenAI-compatible providers such as OpenAI, OpenRouter, LiteLLM, One API, Ollama and private gateways, with Codex reachable through subscription login or an API key gateway. The interface language switches between Chinese, English and Japanese.
