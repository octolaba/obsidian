# pcoletsos/obsidian-dynamic-wide-content

Dynamic Wide Content lets specific blocks break out of Obsidian's readable line length while leaving normal prose in the usual reading column. The README states that Markdown tables, code blocks, Mermaid and PlantUML diagrams and image embeds are the block types widened, that content still too wide for the pane scrolls horizontally inside its frame, and that this works in Reading view and Live Preview without disabling readable line length globally. Settings control the maximum width, a viewport side margin, which block types widen, whether table cells stay on one line, and which of the two views is affected.
