# Mithadon/obsidian-color-folders-files

Color Folders and Files customizes how folders and files look in Obsidian's file explorer through a context menu with a color picker and style options. Right-clicking an item sets its background and text color, font weight and style, and opacity; style presets can be saved and applied, styles can optionally cascade to subfolders and contained files, and the result works in light and dark themes. The README states that it was tested with Obsidian's default theme on Windows and Android and is compatible with the Iconize plugin, which takes precedence, and that version 1.4.0 added a style snippet colouring filenames by extension for use with the Style Settings plugin, automatic hover styling and a preset selector in the settings.
