# satlxq/obsidian-publish-to-git-repo

Publishes notes flagged with gh-publish in their frontmatter, together with the images they embed, to a GitHub repository as plain Markdown and image files; it syncs files and does not render or host a site. A note with images becomes a folder holding an index file and an images subfolder, while a plain-text note stays a single Markdown file; only new and changed notes are uploaded, and each run lands as one commit so an interrupted run commits nothing partial. A preview of every change is shown before anything is uploaded, and a second command toggles the publishing flag on the active note. Settings cover the token, the target repository and branch, a base path, a default storage path and an optional published base URL written back into each note; the token is stored in plaintext in the plugin's data file.
