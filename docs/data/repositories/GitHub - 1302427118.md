# polygonhunter/searchosaurus

Searchosaurus is a vault search panel opened by a hotkey that ranks results deterministically: an exact title or alias match first, title prefixes second, and everything else by relevance, which the README presents as a fix for built-in search returning notes that merely mention a term ahead of the note named after it. It searches notes, files, images and links saved inside notes, previews results live, and supports filters such as restricting to notes, images or saved links, tag queries and quoted exact phrases. With OCR enabled the text inside screenshots and PDFs becomes searchable as well, and the README states that the plugin works entirely offline. It is described as the third plugin in an -osaurus family alongside Linkosaurus and Scalosaurus.
