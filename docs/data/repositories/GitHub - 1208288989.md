# yashmurty/obsidian-people-graph

This plugin renders a force-directed graph of the people described in an Obsidian vault, drawing each person as a circular node with their photo and a silhouette fallback when none is set. The README records that nodes with a higher closeness score orbit nearer to a central node representing the reader, that people sharing a company are clustered, and that the ring color encodes the closeness band. Person notes are identified by a configurable frontmatter field, with name, photo, company, role, closeness and a list of known people read from frontmatter, and the view supports clicking a node to open its note, hover tooltips, zoom and pan, and refreshes as notes are edited.
