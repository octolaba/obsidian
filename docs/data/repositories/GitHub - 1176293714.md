# maxonamission/obsidian-voxtral

Voxtral Transcribe adds real-time and batch dictation to Obsidian on desktop and mobile, with file transcription for recordings. Voice commands can create headings, lists, to-dos, and tables in 13 languages, while automatic correction and note-level language settings support editing during capture.
