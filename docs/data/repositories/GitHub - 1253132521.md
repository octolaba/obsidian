# fengshuzi/keyword-notes-editor

Keyword Notes Editor adds a sidebar list of configured keyword tags and folder paths and shows every matching note together in one scrollable view instead of separate tabs. Sub-tags nest as a collapsible tree, several tags can be aggregated behind one entry so a note matching any of them is included, and a folder entry lists all Markdown files under that path. Keywords and folders are configured in the settings as tag, alias and icon triples. Notes can be filtered by week, month, quarter or a custom date range, collapsed or expanded all at once, stepped through with the arrow keys, and are lazily loaded as the view scrolls.
