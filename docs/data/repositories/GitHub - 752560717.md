# slavafyi/obsidian-neovim

This theme matches Obsidian's colours to the default Neovim colour scheme, which the README states was announced in Neovim version 0.10. The README calls the theme basic, with only colours modified, and points to a Neovim pull request for more information. Screenshots for a dark and a light variant are recorded, and the README invites problems and suggestions as issues.
