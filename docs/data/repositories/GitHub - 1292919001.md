# dtkav/obsidian-tsdb

TSDB is a local time-series database inside Obsidian that records metrics from the vault and from other plugins and renders live charts from promql code blocks in notes. Its recorded sources are vault metrics such as file operations, note counts, vault size, open notes and note view duration, performance metrics covering browser memory and selected Obsidian API timings, metrics registered by other plugins, and optional external scrape targets. Samples are written into a SQLite database running in a worker and persisted in the browser-managed Origin Private File System, with each scrape batch committed as one transaction and retention pruning to a configurable window that defaults to thirty days. A panel block accepts one or several PromQL expressions with a title, a chart type of time series, stat or table, a range, step, refresh interval, unit and legend template.
