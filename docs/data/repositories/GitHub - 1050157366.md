# DarioArzaba/Obsidian-Theme-Arzaba

This repository holds the Arzaba theme for Obsidian, a high contrast and vibrant theme its README describes as colourful without being distracting and intended for long hours of focused note-taking. With the Style Settings plugin installed it exposes extended designs, among them Wiki, Past, and a black and white variant. The README carries preview images of the base theme and of each extended design.
