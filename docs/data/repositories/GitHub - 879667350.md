# acgabbert/IOC-Lens

The recorded description says IOC Lens is an Obsidian plugin for cyber security note taking. The README describes a dedicated view, opened from a ribbon icon or the command palette, that automatically extracts and organizes the indicators of compromise in the current note: public and private IP addresses, domain names, and SHA256 and MD5 hashes. It defangs domains and addresses from context-menu options or the command palette, recognizes both standard and defanged forms, and offers one-click pivot buttons that search an indicator across security engines. The README states that indicators are shown as plaintext and never as clickable links, that they are refanged only for the sidebar view and the pivot searches, and that no default hotkey is set for any of its commands.
