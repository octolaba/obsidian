# thor314/hackmd-obsidian

HackMD Sync pushes and fetches note contents between Obsidian and HackMD. The push command creates the remote note when it does not yet exist and applies the default sharing settings configured in the plugin, but returns an error if the remote note has been edited since the last push; the pull command likewise errors when the local note has changed since the last pull. Separate force push and force pull commands overwrite the other side outright, and further commands copy the remote URL or delete the remote copy.
