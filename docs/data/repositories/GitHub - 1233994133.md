# LeafChage/swipe-words

Swipe Words presents a folder of notes as a flashcard deck, one card per note, worked through by swiping or tapping with SM-2-style scheduling. Any number of decks can be configured, each with its own folder, schedule and budget of new cards, and each opens in its own tab; a session shows every card in that folder due today or earlier plus up to that budget of cards not yet learned, taking failed cards oldest-first and only then never-seen notes in creation order. A card's question comes from the note's front frontmatter field, which may be written as a list for multi-line questions, and its answer from one row per back-labelled key in the order the keys appear; rating a card Again also returns it to the back of the current stack, and the plugin maintains the scheduling fields itself.
