# czottmann/obsidian-mononote

Mononote ensures that each note occupies only one tab per window pane: if the note is already open, its existing tab is focussed instead of the file being opened again in the current tab. This applies to notes opened through links, menus and hotkeys. The README records a hard prerequisite — the editor setting that always focuses new tabs must be enabled, because the plugin hooks the active-leaf-change event, which does not fire for new files otherwise. It also carries a use-at-your-own-risk disclaimer and points bug reports at the repository's issues while discussions have moved to the author's forum.
