# dsebastien/obsidian-graph-explorer-base-view

Graph Explorer Base View is an Obsidian plugin that adds a Bases view rendering the notes a Base returns as an interactive force-directed graph, so the graph stays scoped to that query rather than the whole vault. The README records an explored flag stored in note frontmatter and maturity levels including graduated notes, encoded visually through node shape, borders, rings and an indicator dot, with per-view settings for the property name, colour mode, size mode, filters and presets. The canvas is recorded as force-graph on a 2D canvas with colouring by explored status, confidence, role, maturity, creation date, tags or any frontmatter property, node pinning, cluster dragging, persisted positions and keyboard navigation. A side panel renders a clicked note with metadata badges and controls, and an overlay adds search, statistics, sliders, filters and batch actions.
