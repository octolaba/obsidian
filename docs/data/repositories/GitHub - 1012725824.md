# Riffaells/Robsi

Robsi is an Obsidian theme built around Material Design 3, blur effects on sidebars and modals, and a purple accent scheme for light and dark modes alongside Rose Pine style accents. The README describes multi-level list markers, a compact interface, a responsive layout for desktop, tablet and mobile, and animations that honour reduced motion. Customisation is exposed through the Style Settings plugin, and the stylesheet is generated from a modular styles tree by a Python build script.
