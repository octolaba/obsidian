# cofuente/obsidian-copy-selection

The repository holds Copy on Selection, an Obsidian plugin that copies highlighted text to the clipboard whenever the selection changes, bringing the primary-selection behaviour familiar from X11 to Obsidian on every platform. It covers mouse drags and keyboard selection with shift and arrow keys, as well as double and triple clicks, and the README states that the copying is debounced so fast keyboard selection does not flood the clipboard.
