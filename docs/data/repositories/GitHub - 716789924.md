# ssjy1919/Obsidian-minitabs

Minitabs is an Obsidian plugin that embeds tab pages and column layouts through a code block: the content written inside the block is turned into tabs or columns and then rendered as ordinary Obsidian content, so normal syntax keeps working inside each pane. The block declares whether the tab buttons sit above or below the panes, lists the button labels, and separates the panes with a marker line; blocks can also be nested inside one another. A four-quadrant mode is documented as a column view built from a two-by-two grid, which can equally be written as two columns by any number of rows. The README is written in Chinese.
