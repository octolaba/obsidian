# greedyhao/obsidian-note-to-public

Note to Public publishes a note to an external platform in one action, and the README records the WeChat Official Account as the platform currently supported. It converts Obsidian syntax including wiki links, highlights, strikethrough and callouts into platform-compatible HTML, renders Mermaid diagrams as images, and uploads local images to the platform's media library. A sidebar preview updates when files are switched, and the README states that the account secret is kept in Obsidian's encrypted secret storage rather than in the plugin's data file.
