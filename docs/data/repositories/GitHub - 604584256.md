# digitalsignalperson/obsidian-rofi-helper

Rofi Helper adds id and filename parameters to Obsidian's URI protocol so that a specific open tab can be switched to from outside the application, and ships a sample Python script that exposes those tabs to Rofi as a mode. The README shows the script used on its own, combined with the desktop window list, or as a separate page switched to with a key, giving a global shortcut for jumping between tabs. It explains that the workspace file holds the nested structure of open windows, tabs and panes and that each leaf carries a unique id, which is what makes the switch unambiguous when the same file is open in several places. It records that the plugin has only been tested on Linux.
