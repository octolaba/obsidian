# adifyr/obsidian-chat-view

Obsidian plugin that renders chat interfaces inside Markdown files from code blocks. In its default chat format each message has three parts separated by a vertical bar, a header that is usually the speaker, the message body, and a subtext that is usually a timestamp, any of which may be left empty; bubbles sit on the left by default, with markers that move a speaker to the right or to the centre. The README records that version 2.0 was a full rewrite understanding multi-line messages, embedded images and automatic speaker colours, that the classic syntax remains available under a separate format name, and that exported WebVTT captions, Zendesk chats and Intercom conversations each have their own format.
