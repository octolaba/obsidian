# Christophy/obsidian-github-review

Reads and reviews GitHub issues and pull requests inside Obsidian, aimed at Markdown specification and design documents that render poorly in the GitHub web interface. Pull request Markdown files and issue and comment bodies render as Markdown rather than diffs, every changed file appears with a viewed checkbox and non-Markdown files as a coloured diff, and comments, closing and native GitHub reviews — comment, approve or request changes — are submitted as the token owner so branch protection recognizes them. A queue scoped to the vault's git remote splits pull requests and issues into tabs, any item can be opened by URL, and refresh is manual with optional cheap polling. A read-only local MCP server registered in the vault lets an external Claude client see the open item; the README states the GitHub token never leaves the plugin and that nothing is stored locally.
