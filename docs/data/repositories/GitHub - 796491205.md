# ljcoder2015/obsidian-sheet-plus

Sheet Plus embeds spreadsheets inside Obsidian notes, built on Univer. Its basic features cover embedding a sheet in a note, embedding a link in a cell that opens another vault file when clicked, charts built from sheet data, data validation with checkboxes, dropdowns and dates, images inside sheets, custom fonts, and number formats with regional decimal display. The README lists further features as requiring a license, namely REST API endpoints for automated processing by external AI clients, xlsx import and export, embedding a chart link that renders sheet data as a chart in a note, dashboards, and Kanban and calendar views over sheet data.
