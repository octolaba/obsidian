# Rayvven/obsidian-pin-board

Pin Board presents images and short videos from a selected vault folder in a vertically scrolling masonry board, including files in subfolders. Users can change folders, view all pins, add media by dragging or pasting, open items full size, and attach caption notes; the board updates when files change.
