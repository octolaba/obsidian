# hrenaud/obsidian-checkbox3states-plugin

Obsidian plugin that adds a third state to the checkboxes of a task list. The state, described as not fully done, is set with Shift and a click on desktop and with a long press on a mobile or touch device. Its settings panel offers two colours for that state, a base colour and a hover colour.
