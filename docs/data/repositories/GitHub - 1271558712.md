# inlinkz/obsidian-rchery

Records archery scores in dedicated `.rchery` notes, where the file itself is the data source. A view mode enters scores through a WA-style target face — arrows placed by dragging, with per-end and per-arrow visibility toggles — or through a score pad with undo, while an edit mode exposes the underlying Markdown tables directly. End and grand totals are calculated automatically and written to the file on every change, notes can be attached to individual ends, a session review recaps scores, placements and notes, and layouts come from Indoor, Outdoor or custom presets with a configurable default folder and a touch offset for mobile scoring. The README lists other community plugins as optional dependencies for statistics, tables and charts across scorecards.
