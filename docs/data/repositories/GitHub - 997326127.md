# dannymcc/Granola-to-Obsidian

Granola Sync Plus syncs Granola AI meeting notes into an Obsidian vault, on an interval configurable from every minute to daily or manually only, reporting its state in the status bar rather than in popups. Settings cover the target directory, filename templates and date formats, a note prefix, an override for the Granola credentials path, and an option to skip existing notes so manual additions are preserved. It can add the day's meetings with their times and links to the daily note, works with the Periodic Notes plugin, extracts attendees as tags such as person/john-smith or as wikilink properties in the frontmatter while filtering out the user's own name, and records a link back to the original Granola note. The README notes that the plugin was renamed from Granola Sync and its id changed, so a manually installed plugin folder has to be renamed.
