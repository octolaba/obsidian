# Rinrinsu/pixel-blue-theme

pixel-blue is a Y2K-styled Obsidian theme built on soft sky-blue panels with pink accents and a pixel-grid background across the workspace and editor. Light and dark modes are coordinated, and the styling covers tabs, navigation, prompts, menus, settings and the status bar, with high-contrast system notices and selections. The theme makes no network requests and loads no external assets.
