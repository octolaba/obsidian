# aawhb/ytkn

Turns YouTube videos, playlists and channels into organized Markdown notes in Obsidian. A source note carries the video details together with a readable or timestamped transcript, while an optional AI-assisted note frames the material for studying, research, implementation or general reference and can add TL;DR callouts, Mermaid mind maps and quotes. Notes are produced one per video, as one combined note for a playlist or channel selection, or from a queued batch of URLs. The README states that the AI side is optional and that transcript and metadata notes need no API key, and that Obsidian 1.11.4 or newer is required.
