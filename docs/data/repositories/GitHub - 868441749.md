# SashaKryzh/obsidian-vault-review

Vault Review takes a snapshot of a vault, marking every existing note as still to be reviewed, and then presents those notes one at a time in random order so each can be marked reviewed or deleted. The snapshot is created from the plugin settings, review status is updated through commands, the ribbon or the status bar on desktop, and the settings also show statistics on review progress. The README states that new notes are not added to a snapshot automatically but can be added manually, and lists support for files other than Markdown as planned rather than present.
