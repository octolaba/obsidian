# hjinco/synch

Synchronises a vault across devices by encrypting file contents and paths on the device before they are uploaded, so the server stores only encrypted blobs and metadata and cannot read note text, file paths or the vault key. It runs against the hosted Synch service or a self-hosted server reached through a custom API URL, on desktop and mobile. Non-overlapping edits to the same Markdown file are merged automatically and overlapping ones are kept as conflict copies, and encrypted version history allows earlier versions and deleted files to be restored. Markdown plus images, audio, video and PDF files are included by default, and further files and folders can be excluded.
