# abhimangs/obsidian-vortex

Vortex is an Obsidian theme with selectable accent colors, colored heading levels, gradient underlines, animated links, and custom callouts with icons. Its styling can distinguish internal and external links and offers numerous callout types for notes, tasks, ideas, code, and other categories.
