# metawops/obsidian-table-to-csv-export

This plugin exports tables from a pane in reading mode into CSV files. The author's motivation was reusing tables built by Dataview queries in external applications, but any table in the pane can be exported, including ones hard-coded in Markdown or produced by another plugin. Settings configure details such as the base filename of the CSV file.
