# Fjx-dylanZ/obsidian-drawer-explorer

Repository for Drawer Explorer, a pop-up file and tag explorer for Obsidian with modal, vim-style navigation and a live preview pane. The README documents `hjkl` movement, file operations, move and copy, individual and visual-range selection, a fuzzy filter, and a tag lens that focuses a hierarchical tag and refines it with co-occurring tags. Previews cover rendered Markdown, images, Canvas minimaps and Bases summaries through a small provider API, and the project describes itself as young and daily-driven, with sharp edges expected.
