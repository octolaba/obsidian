# Jul1en-Lin/obsidian-plugin-csdnsync

The repository holds CSDN Sync, an Obsidian plugin that opens the current note in the CSDN Markdown editor with its title, Markdown body and local images filled in. It works through a local bridge: the plugin reads the active note and starts a task server on localhost, and a companion Chrome extension uses the existing CSDN login session in the browser to open the editor and insert the content, leaving review and publishing to the user. The README states that the plugin is desktop-only because of the local HTTP server and the browser extension, and that Chrome with a signed-in CSDN account is required.
