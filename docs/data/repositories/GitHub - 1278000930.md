# Post-Math/Lookout

Lookout is an Obsidian plugin for reading wide Mermaid diagrams and wide tables without working through a note's horizontal scrollbar. Each rendered Mermaid diagram gains a toolbar offering drag or wheel panning, zoom toward the cursor with Ctrl or Cmd and the wheel, a zoom gauge that snaps back to full size, fit-to-frame scaling and a full-screen canvas. The README records that the inline frame hugs the diagram's natural height so a fully visible diagram has no dead space, while tall diagrams are capped at 70 percent of the window height and pan.
