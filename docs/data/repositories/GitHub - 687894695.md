# kadisonm/obsidian-homework-plugin

Homework Manager keeps track of homework in Obsidian through a to-do list, opened from a ribbon icon or the Homework Manager: Open homework command. Views act as folders that collect subjects and tasks, so separate views can be kept for work and school, while subjects sort the tasks inside a view. Tasks can carry due dates, which appear red once overdue, and can be linked to a note in the vault; the README warns that completing a task cannot be undone, and states that the add-on is not an official Obsidian one.
