# symunona/obsidian-bulk-exporter

Bulk Exporter copies a filtered subset of a vault's notes into a new folder structure derived from their frontmatter metadata, so that notes scattered across project folders land in one output tree. The files to export are selected with the Dataview plugin's query language, and the output is renamed and sorted by metadata, which the README frames as running a static site generator such as 11ty, Hugo or Jekyll over a subset of notes. The stated motivation is keeping one source of truth in the author's existing PARA project folders while producing a folder-independent published structure. The status of the latest exported file is shown in the sidebar.
