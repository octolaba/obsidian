# MidwestGuru/habitica-fullsync

An Obsidian plugin that synchronises Habitica tasks into the vault and writes them to a Markdown file whose folder is configurable. The README records pulling personal and party or guild tasks, tagging dailies, habits and rewards in the output, including task notes and a per-sync summary, and scoring tasks in Habitica that were marked complete in the vault, with support for the last four days. Settings record a Habitica API user ID and token, a group ID, an automatic sync interval, platform binding for sync and auto-sync across desktop and mobile, and switches that disable scoring or the creation of new Habitica tasks. The README states the API token is stored in plain text, that Habitica rate limits are handled with exponential backoff, and that daily and weekly due dates use the local time zone.
