# RyotaUshio/obsidian-dynamic-line-height-cjk

Obsidian plugin that adjusts line height per line in editing view and per paragraph in reading view depending on whether it contains CJK characters, on the ground that Chinese, Japanese and Korean text usually needs more line height than Latin script. The height used for CJK lines and paragraphs is set through the Style Settings plugin, which is therefore required for configuration. The plugin also adds a cjk CSS class to the affected lines and paragraphs, so further styling can be written as a CSS snippet.
