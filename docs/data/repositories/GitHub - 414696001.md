# ozntel/obsidian-link-converter

The repository holds Obsidian Link Converter, a plugin that scans the links in a vault and converts them between wikilink and Markdown form. Its README records that the final path can be converted separately or at the same time, to a relative, absolute or shortest possible form, and that four commands cover the active file and the whole vault. The same conversions appear in the context menu of Markdown files, and those entries can be turned off in the plugin's settings.
