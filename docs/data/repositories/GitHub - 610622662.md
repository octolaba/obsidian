# yzh503/obsidian-aicommander-plugin

AI Commander connects Obsidian notes to the OpenAI APIs and the Bing search engine, generating text or images from a prompt, the selected lines or the current line. It can transcribe the last audio file above the current line, ground generated text in Bing web search results using a separate search API key, or answer in the context of a PDF attachment embedded in the note, in which case search results are not used. Custom prompt commands added in settings appear in the command palette, and the README notes that an OpenAI API key is required and that the plugin must be reloaded and Obsidian restarted before a new command shows up.
