# Acylation/obsidian-click-clack

Click Clack simulates typewriter and mechanical keyboard sounds while typing in Obsidian. A default sound resource ships with the plugin, and further sound schemes are fetched as a resources archive from the release page through a download button in the settings tab, or unpacked into the plugin's resources directory by hand if the automatic download fails. The settings tab adjusts volume for all keys, switches key sounds on and off and selects a sound scheme, and the sounds can also be toggled from the command palette. The README states that the plugin is in early development and is not available from the plugin market, so it is installed manually or through BRAT.
