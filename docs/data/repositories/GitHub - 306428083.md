# santiyounger/Wasp-Obsidian-Theme

Wasp is a dark and light Obsidian theme with yellow and amber accents, pairing dark backgrounds with yellow accents in dark mode and light cream backgrounds with amber accents in light mode. The README documents installation from the community theme browser and states that the theme is free to use, asking in return only for a comment on the author's videos or an email.
