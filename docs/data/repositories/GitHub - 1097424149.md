# davidvkimball/obsidian-bases-cms

Bases CMS gives Obsidian Bases a content-management-style workflow, displaying base entries as cards with thumbnails, snippets and property information in a grid. A bulk-operations toolbar selects several items at once for publish and draft status changes, tag management, setting or removing properties, and deletion, and the toolbar's individual buttons can be shown or hidden. The README also records quick-edit execution of an Obsidian command from a card title and a deletion mode that removes a file's parent folder for names such as `index.md` and optionally drops attachments used only by the deleted note.
