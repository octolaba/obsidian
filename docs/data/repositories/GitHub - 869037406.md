# DKLiberty/Red-Shadow

Red-Shadow is a minimalist theme for Obsidian featuring a black-and-red color scheme, intended to give a comfortable and modern interface for note-taking. The README names that colour scheme, clear and simple navigation, and responsiveness across screen resolutions and devices as its features. Accent colour and other elements can be changed by editing values in the theme.css file in the theme folder, and the project is licensed under the MIT License.
