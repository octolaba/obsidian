# HarmfulBreeze/obsidian-material-3-theme

This repository hosts a Material 3 theme for the Obsidian note-taking tool. Its README states that the theme does not support dynamic colour on Android because of limitations, so its colour schemes were generated from Obsidian's brand colours instead. Manual installation is documented as downloading manifest.json and theme.css from the latest release into a Material 3 directory under the vault's themes folder.
