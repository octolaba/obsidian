# awaragi/obsidian-clipboard-monitor

Clipboard Monitor watches the system clipboard and inserts whatever is copied into a pinned target note at that note's cursor, even while Obsidian is not the focused application. The note active when watch mode starts becomes the target, a session can be scoped to text, images or both, and copied images are saved and linked as a normal paste would do. Text is wrapped by a selected insertion template, with raw, bullet, timestamped and callout formats plus user-defined ones remembered as the last used. Watch mode is started, stopped or toggled by command, shows its state in the status bar, stops on its own if the target note is closed, deleted or moved, and polls at a configurable rate; it is desktop only, relying on Electron clipboard APIs.
