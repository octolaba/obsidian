# urishiraval/obsidian-apple-reminders-plugin

This plugin brings Apple Reminders into notes: a code block naming a list renders that list's uncompleted reminders and creates the list when it does not exist, while named reminders can be pulled individually regardless of their completion state. It reaches Reminders through AppleScript, which the README records as limiting it to Apple devices, and states that the plugin alters reminder properties but never deletes a reminder. The author records indented reminders as unsupported because AppleScript does not expose them, and describes the plugin as somewhat heavy despite efforts to keep it efficient.
