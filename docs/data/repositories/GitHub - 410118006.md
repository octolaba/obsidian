# jmilldotdev/obsidian-wikipedia

This plugin fetches the first section of a Wikipedia article and pastes it into the active note. Two commands are offered, one using the active note's title as the search term and one asking for a term. Settings choose the language prefix of the Wikipedia site, the template used for the pasted extract, and whether the first occurrence of the search term is bolded.
