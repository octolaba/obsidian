# noahzender/draftline

Repository for Draftline, an Obsidian plugin for manual Markdown version snapshots and inline comparison between them. Versions live inside the note itself rather than in a sidecar file or plugin database, stored as native callouts with structured draftline markers, so history travels with the note through sync, git or backups and can be read without a special parser. Its commands create a version, make any snapshot the editable note body, and show changes against a parent or chosen baseline with additions and deletions rendered inline in Live Preview; the README states there is no external database, index or network call.
