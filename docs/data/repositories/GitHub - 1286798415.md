# arumata/obsidian-ai-commit

AI Commit adds a button beside the Commit control in the Obsidian Git source-control view that generates a commit message from the staged changes using the DeepSeek API. The prompt, the request timeout and the automatic retries are configurable, and the README notes that generated messages carry no Conventional Commits prefix unless custom instructions ask for one. It requires the Obsidian Git plugin, a DeepSeek API key and git available on the system.
