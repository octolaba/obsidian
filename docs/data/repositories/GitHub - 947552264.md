# Andrii256/ops_obsidian_smart-day-night-switcher

Smart DayNight Switcher calculates the day's sunrise and sunset times for a location and switches Obsidian into light mode at sunrise and dark mode at sunset, so the theme does not have to be changed by hand. The coordinates are entered manually in the plugin settings, because Obsidian does not let a plugin read the device's geolocation, and London's coordinates are used when none are given. The README records that latitude and longitude go into a formula evaluated locally on the device with no data sent anywhere, and suggests using a nearby city's coordinates for anyone still concerned.
