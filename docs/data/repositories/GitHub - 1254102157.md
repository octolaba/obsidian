# MarsLuay/NativePowerPointDocEditor

Opens Word and PowerPoint files stored in the vault in their own editors, without converting them to Markdown. DOCX text, formatting, tables, images and review markup can be edited and saved, as can PowerPoint text, tables, shapes, slide objects and chart data across the pptx, pptm, ppsx, ppsm, potx and potm extensions; files can be duplicated, exported or saved under a new name, and a save conflict is detected when the file changed on disk while open. Commands search within the open file, search an optional vault-wide DOCX index, and copy a diagnostic log, and DOCX files can be scanned for hidden text that looks like a prompt injection. Handling of each format can be disabled independently so another plugin can claim the extension, and the plugin works offline apart from links and remote images in exports.
