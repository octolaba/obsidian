# TylerCarrol/obsidian-mark-base

MarkBase adds a Freeform layout to Obsidian Bases that renders each query result's selected properties, file properties and formulas as continuous Markdown rather than table cells. Which values appear and in what order comes from the Base properties menu, with configurable Markdown separators between properties inside a result and between results, and a file's name rendered as a link to its note. A Markdown file can be selected as a template override, repeated for every result, using placeholders that name a note property, a built-in file property or a formula defined in the Base; the template then controls layout and the line-separator setting is ignored. Each result renders relative to its source note so relative links resolve there, the view updates automatically, and it needs Obsidian 1.13.0 or later with the Bases core plugin enabled.
