# dsebastien/obsidian-expander

Obsidian Expander substitutes configured key-value pairs into notes wherever HTML comment markers appear, and keeps the substituted text up to date. The README states that values may be static or function expressions producing dynamic content such as a formatted current date, and that four update modes control refreshing: automatic on file change, manual by command or button, once, and once-and-eject which removes the markers after substituting. Folders can be included or excluded from scanning, the editor shows mode badges and refresh buttons, and commands replace values in the current note or across the vault.
