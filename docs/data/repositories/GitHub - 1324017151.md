# ruzx/obsidian-chemedit

ChemEdit renders and edits chemical structures inside Obsidian using Ketcher and SmilesDrawer. SMILES strings in a smiles code block are drawn as structures, and mol and cdxml files embedded in a mol block render as SVG instead of a generic file box; double-clicking a rendered molecule opens the Ketcher editor, and saving overwrites the file and updates the preview. A ribbon icon and a command open a blank canvas whose drawing is inserted at the cursor, reactions are supported alongside single molecules, and structures follow the light or dark theme. A basic electronic lab notebook block reads a YAML description of reactants and products and calculates stoichiometry and theoretical and percentage yield, though complex or proprietary ChemDraw objects may not convert fully.
