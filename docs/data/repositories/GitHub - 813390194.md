# TarsLab/obsidian-tars

Tars generates text in Obsidian from tag suggestions, sending the selected section or the section at the cursor to whichever provider the chosen tag names. The README lists Claude, OpenAI, Gemini, DeepSeek, SiliconFlow, OpenRouter, Ollama, Kimi, Doubao, Qwen, Zhipu and QianFan among the supported services, records that the plugin runs on desktop and mobile, and says the name comes from the robot in the film Interstellar. Version 3.1 adds image generation and editing, image analysis and PDF interpretation through the providers that support them, with only embedded files accepted and external URL links stated not to work. Version 2 added tag commands in the command list, custom prompt templates loaded by a command, and a status bar showing character count, rounds and time spent.
