# MMoMM-org/obsidian-archivist

An Obsidian plugin that takes versioned snapshots of the vault to the user's own Dropbox on a schedule and allows any earlier version of any file to be restored. Storage is content-addressed so identical files deduplicate and a rename costs no new bytes, and retention is hierarchical — frequent snapshots for the last day, daily for a month, monthly for years — with a floor that keeps the most recent snapshots and dry-run and delete commands for the policy. Versions are found through a Backup Browser or a history modal for the current file. The README states the project is pre-1.0 and advises keeping an independent second backup meanwhile.
