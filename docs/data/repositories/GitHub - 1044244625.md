# eniverz/obsidian-better-link-clicker-plugin

Better Link Clicker changes what a click on a bidirectional link does in Obsidian: in Live Preview a plain click edits the link instead of navigating to its target, and clicking a link whose note does not exist shows a confirmation before the note is created. Both behaviours are configurable in the settings panel, and the plugin still respects Obsidian's modifier-click behaviour for opening a link in another tab, split or window. The README notes that the `Jump only with modifier` setting applies to every handled link type, that `Open link at new tab` applies to internal navigation only, and that external URLs always open outside Obsidian.
