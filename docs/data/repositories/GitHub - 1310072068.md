# Pavel-mik/obsidian-spherical-graph

Spherical Graph lays the vault out as a world: each top-level folder becomes a continent, notes become cities, links become roads across the surface and tags orbit overhead as satellites, with linked root notes as islands and orphan notes as cities over open water. Layout is a finite operation — deterministic folder territories are grown on an icosphere raster with area quotas following folder size and a permanent water buffer between owners, cities are seeded with a blue-noise distribution and relaxed without crossing the fixed coast, and one complete snapshot is validated and saved. Reading, search, filtering, selection, rotation, zoom, theme changes and resizing do not move notes afterwards, and a route finder reveals the shortest paths between distant notes.
