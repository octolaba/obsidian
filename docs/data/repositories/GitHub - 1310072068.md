# Pavel-mik/obsidian-spherical-graph

Spherical Graph maps an Obsidian vault onto a stable globe where top-level folders become connected territories, notes become cities, links form roads, and tags appear as satellites; Route Finder exposes shortest paths. Initialize and Renew compute and validate a complete spherical layout, then save it as a snapshot so reading, search, filtering, rotation, zoom, themes, and resizing do not move notes; the renderer is desktop-only and requires no account or internet connection.
