# sspaeti/obsidian_kanagawa

This repository ports the Kanagawa colour scheme to Obsidian, and its README states that both dark and light modes are supported, the light one being Lotus with a paper-white background. Installation is by searching for Kanagawa in the community themes list, or manually by copying obsidian.css into the vault directory and reloading Obsidian. The README also points to the author's other themes, Kanagawa Paper, Rose Pine and Osaka Jade.
