# Zachatoo/obsidian-achievements

Obsidian plugin that adds achievements meant to guide a user toward habits in Obsidian. The README lists them: creating one, ten, one hundred and one thousand notes; deleting ten notes; creating one, ten, one hundred and one thousand internal links; opening the command palette and the quick switcher; creating a callout, a heading and three levels of headings in one note; and creating one, five and ten unique tags. It records known issues on mobile, where some achievements are earned much sooner than expected and others cannot be earned at all.
