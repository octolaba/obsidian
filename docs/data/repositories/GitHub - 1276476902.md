# ChongCyrus/handwriting-latex

Handwriting and Image to LaTeX is an Obsidian plugin that converts a drawn formula or an imported image into LaTeX through optical character recognition. The README records an infinite canvas with pen, eraser and pan modes, zoom, rotation, undo, clear, fit and reset controls, an optional grid, and configurable stroke colour and width, alongside image import from the camera or the file picker and a crop step selecting the region to recognise. Recognition backends are recorded as SimpleTex, recommended and free with its own token, custom JSON or multipart endpoints, and experimental Mathpix and OpenAI vision options. The recognised LaTeX appears in a side panel and is inserted at the cursor as inline maths, display maths or raw code, and the README records the interface as suited to touch devices.
