# lornezhang66/open-reader

Obsidian plugin that reads a selection or a whole note aloud through a speech engine installed on the same machine, so there is no cloud service, no API key and no per-character charge. It is written for Chinese and mixed Chinese-English text, skips links, metadata, code and formatting syntax while reading, and installs its local engine from the settings page on macOS or Windows, with an initial model download of about 130 MB. The engine is located in a fixed per-user application directory instead of by an absolute path stored in the vault, so one vault can be shared between the two systems. The README records desktop-only support and states that note content is not uploaded.
