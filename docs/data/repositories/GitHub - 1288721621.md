# irolyuk/chillight-graph

This repository holds Chillight Graph, an Obsidian plugin that redraws the Graph View as an animated themed graph with glowing nodes and curved garland-style wires. Fourteen visual themes are bundled, named after motifs such as Christmas garland, sakura, snow, stars, mushrooms, planets and butterflies, alongside several animation modes. Settings cover the theme and animation mode, node size, glow and text colour, and wire visibility, colour, thickness, glow and sag. The README states that the plugin is desktop only.
