# trashhalo/obsidian-webhooks

This plugin connects Obsidian to other services through webhooks, so that an external automation can write into a vault. It works with a hosted service: a login token is generated there and installed in the plugin settings, and the resulting webhook URL is handed to an automation tool such as IFTTT. The README lists capturing quick thoughts through a voice assistant, liked songs and chat reactions as example uses.
