# gavinpicard/iconocolor

Iconocolor customises folder icons, icon colours and folder colours in the Obsidian file explorer. Icons come from Obsidian's bundled Lucide set, searched with live previews, or from supplied SVG, PNG or URL sources, and folders are configured either by right-clicking them or through the settings panel. Colours are driven from a base colour per folder: palettes assign colours to root folders automatically, HSL or lightness transformations derive icon, folder and text colours from that base, child folders inherit and transform their parent's colour, and a gradient mode interpolates between sibling folders. Named profiles store alternative colour schemes, and default icon rules apply icons by folder or file name pattern.
