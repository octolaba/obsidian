# CasualBot/obsidian-codeviewer-plugin

Obsidian plugin providing read-only syntax-highlighted viewing of common development file types, which the README states are never executed. Its stated purpose is to make developer files first-class inside a vault, with agent harness files such as prompts, tool configurations, instruction files and memory files given as the motivating use case for browsing, searching and linking them beside notes. The README describes a view extending Obsidian's text file view that renders through Prism tokenization and a DOM walker rather than by assigning HTML.
