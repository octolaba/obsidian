# h-sphere/sql-seal-charts

SQLSeal Charts extends the SQLSeal plugin with charts drawn from query results, and requires SQLSeal to be installed alongside it. A chart specification is written beside the SQL in the same block, and the rows a query returns are exposed automatically as a dataset, with columns addressable by name or index and filterable into separate data sets for different series. Line, bar and pie charts are recorded along with more complex forms such as scatterplots and heatmaps, and the rendering is credited to ECharts, whose documentation the README points to for further options.
