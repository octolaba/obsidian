# mohammadmaso/echowiki

Obsidian plugin described in its README as a local-first knowledge compiler driven by a language model. Notes dropped or voice recorded into a raw folder are turned by the compiler agent into a structured, interlinked wiki under a wiki folder, and both folders are created in the vault automatically. The README states that it bundles the compiler in-process rather than running a separate server, and that LLM and speech-to-text API keys must be entered in the plugin settings.
