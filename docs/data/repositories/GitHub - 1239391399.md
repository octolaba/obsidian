# anatoliykmetyuk/show-all-hidden-files

Show All Hidden Files reveals every dot-prefixed file and folder in an Obsidian vault at any depth, and its README states that it ships with no default exclusions, so paths such as the Obsidian configuration folder, the Git directory, environment files and the trash can all appear. Names listed in its ignored-names setting stay hidden anywhere in the vault, ignored folders and everything inside them are skipped, symlinked directories are not followed, and both the patched internals and the previous unsupported-file setting are restored when the plugin is disabled. It is desktop only, depends on the local filesystem adapter and on undocumented Obsidian internals, and records that it makes no network requests, uses no telemetry, and does not rename, delete or modify vault files.
