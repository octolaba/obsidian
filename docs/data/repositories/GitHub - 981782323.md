# lukmay/simple-anki-sync

Simple Anki Sync pushes flashcards written in Obsidian into Anki through AnkiConnect, using a minimal Markdown table format and supporting only Basic cards. Commands sync the current file, sync the entire vault, or unsync the current file from Anki, and the deck and subdeck are taken from a tag on the note, while the card body is a two-row table whose cells may contain line breaks, math and image embeds. The README records as a prerequisite that Anki must be running with the AnkiConnect extension installed and active, and states that the plugin runs no background daemon.
