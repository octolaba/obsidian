# vofen430/obsidian-chatgpt-math-clipboard

This repository holds ChatGPT Math Clipboard, a desktop Obsidian plugin that rewrites what ChatGPT's own copy button puts on the clipboard when the page is open in Obsidian's Web Viewer. Inline KaTeX becomes single-dollar math and display KaTeX becomes double-dollar math, and the clipboard receives plain text only so that rich HTML paste handling does not interfere. The plugin does not guess which brackets are formulas: it converts only KaTeX nodes exposing a tex annotation, and if strict extraction fails the native copy behaviour is preserved. The README states that it activates only for Web Viewer pages whose host is exactly that of ChatGPT, makes no network requests, and stores or uploads nothing.
