# dyc2424748461/obsidian-display-relative-path-img

Repository for a plugin that displays images referenced by an HTML image tag with a relative path inside Obsidian. The README states that the original file is not affected, and that such images keep rendering while the note is scrolled and after the file has been modified, in both reading view and live preview. It credits an existing local-image plugin and an Obsidian forum discussion as the source of the interface modification it uses.
