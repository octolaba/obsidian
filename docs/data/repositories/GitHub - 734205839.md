# ECuiDev/obsidian-quiz-generator

Quiz Generator produces exam-style questions from notes using AI models, and also allows questions to be written by hand for the same quiz interface. The README records that any combination of notes and folders can serve as quiz content, that the types and number of questions are chosen per generation across true or false, multiple choice, select all that apply, fill in the blank, matching, short answer and long answer, and that generation covers 22 languages and notes containing LaTeX. Answers are given in an interactive interface with real-time feedback, and questions can be saved as inline or multiline flashcards compatible with obsidian-spaced-repetition or as Markdown callouts, then reviewed in the same interface. The recorded description names OpenAI, Google and Ollama local models among the providers.
