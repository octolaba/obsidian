# CinquinAndy/notes-to-strapi-export-article-ai

Obsidian plugin that exports notes to a Strapi CMS through its API. The README lists multiple export routes with their own paths, customisable field mappings per route and support for several languages, automatic frontmatter generation and SEO handling driven by a language model, image upload to Strapi covering single images and galleries with path management, and a JSON schema-based configuration. It records that the plugin was fully refactored at version 3.0.0 and that an existing configuration has to be set up again after that release.
