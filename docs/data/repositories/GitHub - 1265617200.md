# Moshyfawn/obsidian-pds-sync

PDS Sync syncs an Obsidian vault to an atproto Personal Data Server through two backends sharing one engine: a private default in which notes are encrypted on the client with Argon2id and AES-256-GCM and stored as opaque records, and a public mode in which notes marked for publishing become standard document records that compatible readers display. Its README records OAuth or app-password authentication with credentials kept in the operating system keychain, two-way private sync with push, pull and restore, conflict copies, orphan deletion and compare-and-swap writes, and automatic sync on change and on an interval with a status-bar indicator, including on mobile. Nothing syncs unless a note is flagged through a frontmatter property, and after a sync the plugin writes its own index back into that note's frontmatter for change detection.
