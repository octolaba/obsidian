# busyoGG/SmoothCursor

Smooth Cursor animates the Obsidian text cursor so it moves smoothly to its target position instead of jumping there, and can draw a trail showing the path it took. The trail can be switched on or off, and cursor color, blink speed, trail color and trail speed are set in the settings panel or by editing the plugin's stylesheet, which requires restarting Obsidian to take effect. The README records two known issues: in Vim mode a cursor placed on a heading appears as a line rather than a block, because key events cannot be detected reliably under pure keyboard operation, and a table cell holding non-plain text can be read as a multi-cell selection, which hides the cursor.
