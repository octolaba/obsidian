# janispritzkau/obsidian-model-viewer

Model Viewer lets 3D models be viewed and embedded in an Obsidian vault through Google's model-viewer component, which supports glTF and GLB models including Draco compression, KTX2 textures and physically-based materials. Obsidian recognises those files so they can be browsed, opened in a tab, and shown through the page preview plugin on hover. Models are embedded with the native embed syntax, with a fragment setting the height or the aspect ratio and the usual pipe suffix setting the width, so several models can sit side by side on one line. Any attribute the component supports can also be passed in the fragment.
