# october-learns/nested-notes

This repository holds Nested Notes, an Obsidian plugin that organizes notes into a nested structure by drag and drop, which the README suggests for nested tags, indexing topics and maps of content. Its first release adds dragging notes into place, collapsing and expanding them in the view, and hiding folders and non-markdown files, with settings to show or hide the file icon and the folder path. The project is licensed under the GNU General Public License v3.0 and is provided free of charge.
