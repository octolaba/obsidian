# zqDeJob/obsidian-plugin-helper

Plugin Helper lists the third-party community plugins installed in a vault together with their official descriptions and Chinese annotations, so each plugin's purpose can be checked without leaving Obsidian. A sidebar panel pairs the read-only official text with an editable personal note, while a popup mode shows the official text only and opens the plugin's own settings. The README states that the official descriptions are pulled from the community plugin directory and translated into Simplified Chinese, which needs a network connection, and that manually edited personal notes are not overwritten by a refresh.
