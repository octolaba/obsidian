# anoopkcn/obsidian-reference-map

Reference Map builds a map of the references and citations of the current document, showing cited and citing works for a bibliography in a sidebar view. Its recorded features are that sidebar, static and dynamic reference lists, a search for published documents related to a subject, and a graph view, all configurable from the plugin's settings. The README carries only a basic description and points to the project's wiki for the detailed guide; installation is offered from the community plugin browser, manually from a release, or through BRAT.
