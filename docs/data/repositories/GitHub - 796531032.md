# jeetsukumaran/obsidian-focus-tracker

Renders a timeline of activity and engagement across notes over time, so that gaps and periods of attention become visible and future focus can be planned against them. The README describes the intended uses as tracking research threads, monitoring which project workstreams are active or stalled, and visualising consistency in a habit, and the author names an OKR-style prioritisation aid and an ADHD self-management aid among personal uses.
