# rockofox/obsidian-advanced-find-and-replace

Obsidian plugin for finding and replacing text across the whole vault with regular expressions, including capturing groups and flags such as global and case-insensitive. A live preview shows the original text beside its replacement, with surrounding lines for context, before any change is applied. The README documents installation through BRAT by adding the repository as a beta plugin.
