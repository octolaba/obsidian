# HyeonseoNam/auto-classifier

Obsidian plugin that suggests tags for a note using either an OpenAI-compatible API or the Jina AI Classifier. It analyses the note's title, frontmatter, content or a selected area together with the tags already present in the vault, and proposes tags relevant to that input. The OpenAI-compatible path takes a base URL and a model name, so hosted OpenAI or a local server such as Ollama or LocalAI can be used, with the API key left empty for local models. The README names DDC classification for books, keyword recommendation and research paper categorisation as example uses.
