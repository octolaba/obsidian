# Yoav6/Obsidian-SpellFix

Repository for SpellFix, a plugin that accepts suggestions from Obsidian's native spellchecker without opening the context menu. Its README documents commands that fix the most recent misspelled word on the line, cycle through the remaining suggestions, restore the original word, and add a suggestion to an ignore list. It notes that no hotkeys are assigned by the plugin and that the user has to bind them, and describes a setting that filters out single-character suggestions with a list of exceptions.
