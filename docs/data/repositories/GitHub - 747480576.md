# scottTomaszewski/obsidian-inline-admonitions

Restyles inline code blocks that match a configured trigger so they stand out on the page as colored bubbles. Each inline admonition is created in the plugin settings and defines background color and opacity, text color and opacity, font, border style, width and color, corner radius, bold, italic and underline, plus optional prefix and suffix icons. The admonition type determines what triggers the conversion, for example a prefix the inline code block must start with. The README notes that prefix and suffix icons are not supported in Live Preview because they cause cursor navigation issues.
