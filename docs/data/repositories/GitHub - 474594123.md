# joethei/obsidian-control-characters

Control Characters shows control and non-printing characters in Obsidian's edit mode. By default they appear throughout a note, but the plugin can be configured to show them only inside a selection, and per-note properties override the settings — switching the display as a whole or separately for tabs, newlines and spaces. Most of the styling can be customized with the Style Settings plugin.
