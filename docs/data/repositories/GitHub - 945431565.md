# busyoGG/OneStepWikiLink

OneStepWikiLink converts the text of the open document that matches other notes into wiki links in one step. The conversion runs from a button added to the outgoing-links view or from a command, and it can also be performed automatically. Its settings show or hide match details, exclude named files or directories from conversion, define non-boundary characters for languages whose word boundaries are not detected, and bind a shortcut, and the README states that the interface exists in Chinese and English.
