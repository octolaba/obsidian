# jmiba/starred-news-sync

Starred News Sync imports starred or saved items from an RSS reader into the vault as Markdown notes with frontmatter for title, URL, reader, feed, author, published and import dates and tags. A command and a ribbon action run the sync, an optional interval repeats it while Obsidian is open, each item is imported once under a filename built from its title and a short hash, and items whose URL already appears in configured frontmatter fields can be skipped. HTML summaries are converted to Markdown with unsafe elements and event attributes stripped, the original page can optionally be fetched and reduced with Defuddle, fetched images are kept only when remote images are enabled, and notes can be rendered from a Templater-compatible template. The README documents setup for FreshRSS, Tiny Tiny RSS, Inoreader, Feedly and Miniflux.
