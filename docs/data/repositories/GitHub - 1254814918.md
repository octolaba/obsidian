# xinworks/obsidian-simple-image-slider

Repository for Simple Image Slider, a plugin that renders a group of image embeds as one swipeable slider with captions, and can also show captions for ordinary image embeds. Its README documents a code block listing image wikilinks whose text after the pipe becomes the caption, navigation by click, keyboard or drag, a counter that opens a list for jumping to a slide, captions placed below the image, and controls hidden by default. It states plainly what the plugin leaves out, including thumbnails, a fullscreen mode, autoplay, video, audio and PDF support, annotations, compression, a compare mode and a settings panel.
