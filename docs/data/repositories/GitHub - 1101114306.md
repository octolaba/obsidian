# aykutkardas/obsidian-dataloom

DataLoom stores database-like tables in loom files that can be opened on desktop and mobile or embedded in a note. Recorded cell types include text, number, currency, checkbox, embed, file, date, tag and creation or edit times, with column visibility, renaming, retyping, sorting and reordering, row filtering, search and reordering, undo and redo, and folder or frontmatter sources. Import and export cover CSV and Markdown, and the README documents a set of CSS variables as a stable way to adjust table density instead of targeting internal selectors. The README records this repository as a fork continuing development of an original plugin its author no longer maintains.
