# PixeroJan/obsidian-extension-hub

Extension Hub is an Obsidian plugin for browsing GitHub, the official community archive and the Obsidian Forum to find plugins and install them across several vaults at once. It searches the approved community plugin list, GitHub repositories by keyword or author, and forum announcements, and it compares installed plugins against GitHub releases so updates can be selected individually. Plugins can be grouped into named sets that install as a group, and installation targets the active vault, every vault found beneath configured parent folders, or an explicit list of vaults. An optional GitHub API token raises the request quota, and multi-vault deployment is desktop-only while browsing works everywhere.
