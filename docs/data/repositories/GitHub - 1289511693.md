# anthonyfitzpatrick/obsidian-metadata-visuals

Metadata Visuals turns Obsidian frontmatter values into File Explorer colours and icons, smart folders with inherited workflow states, metadata highlighting inside note Properties, and workflow visualisation, without modifying the stored metadata itself. Rules are configured per metadata field in settings, with rule groups, drag-and-drop ordering, live previews, folder inheritance, note and folder targeting, and bulk metadata updates across notes and folders. It also discovers fields and values automatically, normalises legacy values and can import field definitions. The README states that the plugin is standalone and has no runtime dependency on Metadata Menu, Dataview, Templater or Iconize.
