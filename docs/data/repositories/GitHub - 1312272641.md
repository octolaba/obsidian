# decai335335-debug/obsidian-multi-definitions

Multi Definitions keeps a personal dictionary in which one term can hold any number of separate explanations, each with an optional title, plus aliases for the term. Saved terms are recognized automatically in Reading View and Live Preview and can be styled with bold, a highlight color, a text color or an underline; hovering one on desktop previews all its explanations, a click or tablet tap opens the full card, and stylus input is ignored. Matching prefers the longest saved term first and handles Chinese terms as well as English word boundaries, and explanations may contain Markdown. Everything is stored in a definitions.json file inside the vault so it travels with any vault synchronization method, and Obsidian 1.13.0 or later is required.
