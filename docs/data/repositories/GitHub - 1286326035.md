# GitMorRic/towrite-open-questions

ToWrite Open Questions keeps unfinished thinking and unfinished writing attached to the notes, PDF passages and draft fragments where they arose, as an annotation layer of cards in two lanes rather than a general to-do list. Cards are captured from Markdown or PDF selections, from explicit Markdown rules, or from inline trigger suggestions, and the sidebar keeps the current note's cards at the top, allows editing of title, source body, note, status, type, lane, color and tags, and jumps back to the source line or highlight. Selection cards are stored in sidecar JSON so the Markdown is unchanged unless a source anchor is pinned explicitly, and workflow stages group files by folder prefix, frontmatter tags or inline tags. The README states that the plugin is marked desktop only because its optional local HTTP API runs a Node server inside the desktop application.
