# leo-su-zhan/obsidian-vault-lens

The repository carries no description; its README presents Vault Lens as an Obsidian plugin that previews Office and code files directly in the editor. For Office documents it renders headings, tables, images, page-break separators and text alignment from docx, font colour and size, bold, cell fill colours, merged cells and column widths from xlsx with tabs for switching sheets, and a visual layout with backgrounds, shapes and positioned text from pptx. More than sixty code and text formats are previewed with syntax highlighting through highlight.js, line numbers, and inline editing that saves back to the file. Common controls cover zoom between 25% and 200% from toolbar buttons or the scroll wheel with a reset, and dragging to pan while zoomed in.
