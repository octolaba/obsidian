# Solace-Theme/solace-obsidian

Solace is a clean, minimal Obsidian theme built around a soft violet palette, brought over from the Solace theme originally created for Zed. Three variants, Dark, Light and Dusk, are switched from Style Settings, each with its own background and accent color. The README lists a pastel syntax palette, custom checkbox states for done, in-progress, question, halfway and canceled, styled frontmatter properties, themed tables with alternating rows and hover effects, pill-shaped tags in editor and reading view, callouts with type-specific accent colors, custom Lucide icons and filled, outlined and minimal style variants, and a violet-tinted text selection.
