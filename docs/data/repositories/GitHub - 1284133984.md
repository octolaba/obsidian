# chooliu/obsidian-sugar-theme

Sugar is an Obsidian theme set with four pastel palettes: taro, light pastels on dark grey and the dark-mode default; cinnamon, earthy warm browns on cream and the light-mode default; sugarplum, saturated tones on white; and a port of fairyfloss classic. Presets are selected with the Style Settings plugin or by editing theme.css directly. The repository also ships a stand-alone interactive palette editor as an HTML file for picking colors and generating CSS, together with a swatches page previewing the palettes.
