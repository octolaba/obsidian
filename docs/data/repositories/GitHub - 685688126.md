# Raboro/obsidian-timer-plugin

This plugin provides a timer that counts down and raises a notice when it finishes, with a maximum of 99:59:59 and no start while the clock reads zero. Timers are set from commands or from buttons under the clock and can be started, stopped, cancelled, resumed and reset, with the current value also shown in the status bar. A command accepts either a colon-separated or a suffixed notation, favourite timers can be stored and reinserted, and the settings control the increment on each button, whether the buttons are stacked, and an alternative verbose time format.
