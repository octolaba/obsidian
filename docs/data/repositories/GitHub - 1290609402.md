# Erimanga/Latex-assistant

LaTeX Assistant is described as a LaTeX assistant for Obsidian, and its README is written in Chinese and English. It pairs dollar delimiters as they are typed, turning a second press into a display-math block, expands snippets from a trigger word through a completion popup or the Tab key, and offers a slash command inside display math that searches for and inserts a snippet with the cursor placed at the first editable position. Snippets can be added, edited and deleted in the settings tab and imported or exported as JSON, and the README states the features activate only inside inline or display math. The interface language can be set to English or simplified Chinese.
