# Vetrenar/v-library-search

Obsidian plugin that turns a collection of notes into a searchable library: opening a note takes its aliases, or a chosen frontmatter property, as the query and surfaces every place those terms appear, grouped by note type. Matching runs in substring, stemmed word-form or whole-word mode, so an alias also matches inflected forms, and terms and text are normalized so Cyrillic and accented Latin match regardless of how they were typed. Notes are classified into groups by a frontmatter property, each group choosing its own term source and search targets among headings, callout titles and bodies, named frontmatter fields, the body, list items and tasks and the filename, with results shown in a docked inline panel, a pinnable side view or a code block. A separate tool builds one note per PDF with the document's table of contents written in as linked headings.
