# SdKay/obsidian-drawio-view

Draw.io View renders .drawio diagrams stored in the vault inline, from a fenced drawio-view block naming the file, with zoom, pan and multi-page tabs. The README states that the block accepts optional parameters in any order for the starting page, viewer height, initial zoom and pan offset, defaulting to the first page, 400 pixels, auto-fit and centred. When a diagram uses extended shape libraries such as AWS, Azure, GCP or Cisco, the plugin detects this and offers a banner that downloads the missing libraries from draw.io's official repository and stores them locally for reuse; libraries can also be browsed and managed from the plugin settings.
