# mizhidaili/version

Groups several vault files into one topic that the File Explorer shows as a single note, with controls at the right edge of the view switching between its versions. Every version stays an ordinary, editable file: series membership is recorded outside note bodies, nothing is inferred from filenames, and disabling the plugin leaves the files unchanged. Links can point at the whole topic or at one exact version, and backlinks from every resolvable version are aggregated. Markdown, Canvas and Excalidraw files are supported, the interface is available in English, Simplified Chinese, Danish and Japanese, and the plugin makes no network requests.
