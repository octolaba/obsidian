# creesee/obsidian-highlighter-plus

The repository holds Highlighter Plus, an Obsidian plugin that extends Obsidian's highlight syntax with named highlighter profiles. The README records a syntax that names the highlighter inside the usual double equals markers, and a Toggle Highlighter Cycle command that steps a selection through the active highlighters and then removes the highlight. Each profile records separate colours, opacities and text colours for light and dark themes, a background fill or an underline, corner radius, and a scope that limits it to all text, paragraphs only or headings only, so the cycle offers only the styles valid for the current line. Settings record reordering, duplication and a live preview of both themes, and the README states that deleting a highlighter reverts the affected text and that output works with Obsidian's PDF export.
