# dsebastien/obsidian-remarkable-sync

Connects Obsidian to the reMarkable cloud with a one-time code to list notebooks and download their pages, rendering .rm v6 stroke data into PNG or JPEG images; a self-hosted rmfakecloud server can be used instead, and .rmdoc files can be imported locally with no cloud connection at all. A sidebar panel browses notebooks in a foldable folder hierarchy with search, multi-select and per-notebook download, and the reMarkable folder structure is mirrored in the vault. Background sync of notebooks needing updates runs on a configurable interval and is off by default. The README states Obsidian 1.4.0 or later, full desktop support, and experimental mobile support.
