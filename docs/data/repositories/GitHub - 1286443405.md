# Piero24/obsidian-gym-tracker

Gym Workout Tracker logs gym workouts inside Obsidian from a monthly calendar that marks the days already trained, where clicking a date opens that day's log. Exercises are searched with autocomplete from a built-in database of more than 1,300 entries carrying names and tags for equipment and muscle groups, and reusable templates such as a push or leg day can be assembled and reordered by drag and drop. Every new set is pre-filled with the numbers from the previous session, and the data is auto-saved into a single JSON file instead of many Markdown files, with an option to show that file in the graph view. The README states that the plugin is private and offline, with no subscription.
