# msakowski/obsidian-library-linker

The recorded description says the plugin integrates JW Library links and Bible references into Obsidian note-taking. Per the README, typing a Bible reference after a command trigger, or simply typing a recognized reference, raises a suggestion popup that inserts a Markdown link opening directly in JW Library. It can also fetch the Bible text itself and insert it as a quote, for a selection, for the whole note, for the link at the cursor, or from the right-click menu on a link, using built-in templates or a custom one written with variables for the reference, the linked reference and the quote. A further command converts publication links, jwpub links and web links inside a selection into JW Library links, and the README documents localization into many languages.
