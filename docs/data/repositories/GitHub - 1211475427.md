# jackcarey/obsidian-rule-engine

Defines rules that match files and then act on them: running lists of commands automatically against individual files or against each item of a `.base`, and rendering HTML templates on Markdown files, canvas nodes and `.base` items. The README documents its permissions — the plugin enumerates vault files so rules can be matched, and script tags inside templates are opt-in, executed through `new Function()`, with any script carrying a `src` attribute ignored. It states that it expands on the MIT-licensed anuwup/obsidian-custom-views plugin.
