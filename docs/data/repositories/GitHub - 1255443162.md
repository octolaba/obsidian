# carnalMATRIX/obsidian-mantle-docs

Mantle Docs is a read-only viewer for code and raw data files kept in an Obsidian vault — JSON, TypeScript, CSS, CSV, HTML and YAML among them — applying syntax highlighting rather than raw-text editing. The README records read-only protection against accidental keystrokes, virtualization so that large files can be viewed without lag, and code blocks with toggleable line numbers, line wrapping and one-click copying. Files need a recognized code extension to be highlighted, and the plugin is styled to inherit the Project Mantle layout and the Zenith theme while remaining compatible with any theme.
