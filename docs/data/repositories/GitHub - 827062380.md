# tankh99/learnie-plugin

Learnie is described as an Obsidian plugin that supports learning through active recall and spaced repetition. Its README says a command converts any file into a tracked note, writing a unique note id into its frontmatter and linking generated revision and question files. A tracked note carries a diff view showing what changed between the current note and the last modified version, questions can be created from selected text so that the selection becomes the answer, and a daily review lists the notes changed in a day, with reminders offered. The README states that questions can only be created for valid tracked notes.
