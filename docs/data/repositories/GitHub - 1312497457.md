# grafanaKibana/obsidian-tabsdown

Renders tabbed blocks from a fenced tabsdown block, where each tab begins with a column-zero marker naming its label and a block needs at least two unique, non-empty labels. Tab bodies go through Obsidian's own Markdown renderer, so notes, queries, embeds, callouts, math, Mermaid diagrams and compatible plugin blocks keep working, and blocks can be nested as long as the inner fence is shorter than the outer one. An optional config line placed before the first tab sets where the tab list sits - top, left, right or bottom - and whether labels stay on one scrollable line or wrap. Labels accept bold, italic, strikethrough and inline code plus a Lucide icon prefix, other Markdown stays literal, and tabs are interactive in Reading View and in Live Preview while the cursor is outside the block.
