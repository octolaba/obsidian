# amatya-aditya/obsidian-rss-dashboard

RSS Dashboard collects feeds, YouTube subscriptions, podcasts and Twitter or X feeds into one dashboard inside Obsidian, parsing RSS, Atom, XML and JSON feeds with automatic feed discovery and converting YouTube channels into feeds. Items can be tagged, played back in place and saved into the vault as notes, and the README documents a one-click subscribe URI, keyboard shortcuts, syncing across devices, and a storage guide for how the plugin shards its data in the vault. It states that the plugin is free and open source, that data is stored locally, and that it carries no ads, tracking or paywalls.
