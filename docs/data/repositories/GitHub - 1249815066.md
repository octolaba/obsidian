# marcpanu/obsidian-mobile-explorer

Mobile Explorer replaces the default file explorer with a drill-down navigator where tapping a folder pushes into it and a back button or a right swipe returns, showing folders and notes as separate card groups with relative modification dates on notes and item counts in the header and on each folder. A long press on mobile or a right-click on desktop opens the full native Obsidian file menu. The README records a Print note action added to that menu and to the command palette: on desktop it opens the system print dialog, and on mobile it renders the note into a paginated PDF and hands it to the native share sheet, saving the PDF next to the note when the webview cannot share files.
