# opellen/Hilo

Hilo adds multi-color highlights on top of Obsidian's native `==text==` syntax by inserting only a color token, so inline markdown such as bold, italics and links keeps working inside a highlight — which the README contrasts with HTML-based highlight plugins that lose it. The markdown source stores a semantic color name while the hex values live in the plugin settings, and source mode, Live Preview and reading view render highlights identically, with the token hidden in Live Preview until the cursor is placed on it. Highlighting, changing a color and unhighlighting are reachable from the right-click menu and from per-color commands plus a palette command, all assignable to hotkeys. Colors come either from a builtin catalog tied to the theme's color variables or from a custom catalog that starts with a few pastels.
