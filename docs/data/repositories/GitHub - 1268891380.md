# PageDen/pageden-obsidian

Pageden Sync connects an Obsidian vault to Pageden, described in its README as a server-owned Markdown workspace for teams and AI agents. Recorded commands cover validating the connection, browsing and searching remote documents, opening a live document, pushing the active document, syncing on demand, downloading a folder or every document, importing the whole vault into a workspace, resolving a conflict for one note, and logging in with a device code. Settings are the server address defaulting to the hosted instance, a personal access token or device-code login, a workspace identifier, a local folder for downloads and a background sync toggle with an interval; sync metadata is stored beside the plugin files keyed by document identifier, and Obsidian 1.5.0 or newer is required.
