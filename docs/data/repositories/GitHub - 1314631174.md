# obsidian-ynote/obsidian-ynote

YNote Sync is an unofficial, desktop-only two-way client between a Youdao Note workspace and an Obsidian vault. Its main command pulls cloud changes incrementally, reads the locally recorded creates, edits, deletions, renames and moves, presents conflicts and selectable operations, and pushes only what is approved, while a separate full pull with resumable jobs is reserved for first-time setup or recovery. Markdown, several native Youdao formats such as MindMap and LXTable, Draw.io, Excalidraw, Canvas, images and arbitrary binaries are handled, some in dedicated viewers and some view-only. Authentication profiles, synchronization state, reports and caches live under a folder in the configured root, the interface is available in English and Simplified Chinese, and Obsidian 1.8.0 or later is required.
