# S3ga1ov/tiktoken-tokenizer

TikToken Tokenizer shows the token count of the currently active note in the Obsidian status bar, recalculating on open and on edit with a 150 ms debounce. It uses js-tiktoken, a JavaScript port of the OpenAI tokenizer, and the README states that tokenization runs entirely in JavaScript with no WebAssembly and no network calls, so it works on desktop and mobile. Two modes are offered: an exact count using the o200k_base encoding shared by the gpt-4o and gpt-5 families, and an approximate Claude count that applies a fixed 15 percent margin on top of a cl100k_base count, which the README explains as a stand-in because no offline Claude tokenizer is published.
