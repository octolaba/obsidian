# MaleleStudySpace/cursor-navigator

The repository holds Cursor Navigator, an Obsidian plugin that remembers the cursor position and scroll viewport of every note and adds a global back and forward history across notes, bound to the alt key with the arrow keys in the manner of VS Code or a browser. It records the position left behind when a different tab is clicked and the source position when a link opens in a new tab, merges consecutive entries from the same file at similar positions, and filters out invalid entries such as embed references. The README states that the plugin is a fork of dy-sh's remember-cursor-position with substantial additions.
