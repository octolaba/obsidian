# letschips/crisp-annotations

Extends inline Markdown highlights into annotations: a short note is attached to the highlighted text and rendered in reading mode as a handwritten label joined to its target by a drawn connector. The annotation is stored in the note itself as an attribute block after the highlight, carrying its text, a placement among eight directions, a color, and whether the highlight stays visible. Annotations are added or edited by hotkey, context menu or command, and an annotation center lists them for the current document or the whole vault with search, color filters, jump-to-target and clipboard export. Connector style, reading layout and label font are global settings; validating an optional licence for the paid appearance options contacts a remote endpoint for device registration and sends no note content.
