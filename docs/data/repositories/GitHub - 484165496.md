# jsmorabito/obsidian-commander

Commander lets commands be added to different parts of Obsidian's user interface. Commands can be added, removed, edited and reordered from the plugin's settings, commands contributed by Obsidian itself or by other plugins can be hidden, and each command can be limited to chosen devices, which the README notes matters for sync users. The README credits the plugin as designed by one author and developed by another, and says code was reused with permission from the Customizable Page Header and Titlebar and Customizable Menu plugins.
