# astradev123/obsidian-focus-time

Tracks how much time is spent focused on each note, and according to the README also reading time for PDF files. The collected data is presented in a dashboard with day, month, year and total views, interactive bar charts that drill down from total through year and month to day, date navigation across those ranges, headline figures for focused notes, focus time and focus days, and a leaderboard of the ten notes with the most accumulated time. The README states that the interface adapts to desktop and mobile and to light and dark modes.
