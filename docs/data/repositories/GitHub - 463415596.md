# anselmwang/obsidian-key-sequence-shortcut

The repository holds Key Sequence Shortcut, an Obsidian plugin that binds a short sequence of letters to a command, on the argument that a sequence is easier to remember than a modifier combination. Its README gives examples where a leading letter stands for a category, so that one pair toggles preview and another toggles a bullet list, and records a command that opens the sequence menu, after which typing the sequence runs the command without a confirming key press. Bindings live in a configurable Markdown file at the vault root, one per line, giving the sequence, the command identifier and an optional description, with comment lines marked by a double quote.
