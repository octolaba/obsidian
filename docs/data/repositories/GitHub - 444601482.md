# tdresser/obsidian-siteswap

This plugin renders siteswap juggling notation as an animation through the Juggling Lab GIF server, which means it requires an internet connection. A bare pattern can be given on its own, or a YAML form can set per-animation details such as the pattern in generalized siteswap notation and the number of beats per second. Some attributes can also be set globally in the plugin settings, where the values given for a single animation take precedence.
