# Thiews/obsidian-simplicity

Simplicity is a minimal and highly customizable theme for Obsidian, installed through Settings, Appearance, Themes, Manage. Its customisation runs through the Style Settings plugin, which adds a Simplicity panel offering a title style, an accent colour, two menu styles, a separate font for titles, a rounded style, stronger bold and italic with customisable links, and a focus mode for writing. A page can be made full width by adding a full-width cssclass in its frontmatter.
