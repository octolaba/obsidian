# wjgoarxiv/obsidian-supsub

SupSub wraps the selected text in the HTML superscript or subscript element, giving quick superscript and subscript formatting inside a note. Each has its own hotkey, differing between macOS and Windows, and a toolbar button; with nothing selected the hotkey enters a typing mode marked by a status bar indicator, in which everything typed is formatted until Escape is pressed. A remove action strips the existing tags from a selection, and with the hide-tags setting enabled that action becomes available by holding the modifier key over visible superscripted or subscripted text even when the selection does not match the raw tag boundaries.
