# henriquemanduca/myhistory-plugin

MyHistory keeps a local version history for Markdown notes by storing each changed note's full text as an immutable version in a database inside the vault. A sidebar timeline lists the active note's versions with capture time, cause and size, a preview modal renders a version before restoring it, and the content being replaced is stored first. History follows a note across renames and moves, survives deletion, and is bounded by a per-note retention limit defaulting to 50 versions, with pinned versions exempt. Capture happens after a configurable pause in editing, a startup scan picks up changes made while Obsidian was closed, and nothing is sent off the machine.
