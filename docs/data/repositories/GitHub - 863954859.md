# Hosstell/image-tools-obsidian-plugin

Adds direct manipulation of images shown on the page: resizing by dragging with the cursor, adjusting alignment to left, center or right, and opening an image in full screen. The README presents these three capabilities as the whole scope of the plugin, followed by an example image.
