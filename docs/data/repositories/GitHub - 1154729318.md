# mattycm1193-sys/Vaporwave_Void-Dark_Mode-Obsidian_Theme

Vaporwave Void is a dark-mode Obsidian theme built on glass-morphism, with translucent panes over a deep purple-to-black gradient and a six-level neon heading hierarchy running from hot pink through electric cyan, purple, lime, gold and red. The README warns that the theme is designed exclusively for dark mode, because its neon variables are bound to the dark theme class and light mode leaves text invisible. It also records custom neon styling for color inputs, support for file explorer plugins and modal windows, and manual installation into the vault's themes folder.
