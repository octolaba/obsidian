# GurnoorRana/Obsidian-pdf-read-aloud

This plugin reads an open PDF aloud in Obsidian using the device's built-in text-to-speech, which its README says needs no API key, no internet connection and no paid service. Recorded controls are play, pause and stop, skipping forward or back by a configurable number of sentences, a click mode that starts reading from the clicked point in the PDF text layer, reading only a highlighted selection, and a right-click menu offering both of the latter. It also records a progress bar that can be clicked to jump, playback speed between half and double, a voice selector listing the voices installed on the system, a status bar showing the current sentence and page, and command palette entries for every action.
