# marcjulianschwarz/obsidian-podcast-note

Podcast Note adds podcast metadata to Obsidian notes from a single episode URL, retrieving the title, image and description. The README states that one command opens a prompt for the URL, while a second, visible only in editor mode, creates and links a note for every podcast link found in the selected text. Apple Podcast, Spotify Podcast, Google Podcast, Pocket Casts, Airr, Overcast, Castro, Castbox, Podcast Addict and YouTube are listed as supported services, and a template setting composes the note from placeholders for title, image URL, description, show notes, episode date, podcast URL, date and timestamp, with show notes and episode date recorded as available only for some services.
