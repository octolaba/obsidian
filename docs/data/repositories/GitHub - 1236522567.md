# wrongvibe/colours

COLOURS is a minimal Obsidian theme whose whole palette is derived from a single chosen accent colour through the oklch() relative colour syntax, so changing that one colour updates everything instead of switching between fixed light and dark presets. Text contrast flips automatically with the accent's lightness, and dark mode is a dimmed version of the same accent, with an option in Style Settings to keep the chosen colour without that dimming. Style Settings also carries the theme's colour, typography and layout options, and the theme adds alternate task checkboxes for markers such as important, star, bug, key and location. The README states a requirement of Obsidian 1.5.0 or later, notes that the recommended fonts are not bundled, and names a companion plugin, Folder Accents, that changes the accent when a note in a designated folder is opened.
