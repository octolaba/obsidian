# Nigecat/obsidian-desmos

This plugin renders Desmos graphs from a code block whose body holds equations in LaTeX form, one per line, and the README states that it works both online and offline. A separator line divides optional key-and-value settings from the equations, so the bounds, the rendered height and width, the grid and the degree mode of trigonometric functions can be set per graph. For exporting a note containing a graph to PDF, the README records that filesystem caching must be on, the renderer must be disabled, and every target graph must already be in the cache, which is achieved by viewing each of them once.
