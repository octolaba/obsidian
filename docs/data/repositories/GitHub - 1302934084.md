# ishibashi-c/ishibashi-web-clipper-v2

The recorded description calls this a privacy-first Obsidian link saver with no automatic page fetching. The README says it saves web links as local Markdown notes without requesting the source page: no HTML scraping or redirect resolution, no Open Graph or Twitter Card requests, no automatic description, article body or image capture, and no analytics, telemetry, cloud storage or external API. Links arrive from the mobile share menu, the clipboard, an obsidian URI action, or an optional desktop bookmarklet that sends only the current URL, the visible document title and text the user selected; duplicates are blocked, tags can be fixed or derived from the domain or folder, and clips are reviewed in history and library views. The README states that this is an independent plugin that neither replaces nor upgrades installations of the original Ishibashi Web Clipper.
