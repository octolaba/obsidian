# fangface-hub/obsidian_mermaid_integrator

Obsidian Mermaid Integrator is described in its README as a plugin base that helps users edit Mermaid code blocks: it wraps the current selection in a mermaid code block, inserts a flowchart template and lets the default flow direction be configured. It also parses a metadata comment line inside a Mermaid block and applies the declared styles to the rendered diagram. Supported keys cover horizontal alignment, width, outer margin, background colour and zoom scale, plus interactive and theme values that are exposed as HTML data attributes on the rendered container; specifying a width disables the responsive maximum-width behaviour for that diagram.
