# vanakat/zotero-link

This repository holds Zotero Link, an Obsidian plugin that adds one Insert command writing a link to a Zotero item into the note. It requires the companion zotero-bridge plugin and reaches Zotero through the local API on Zotero 7 or later, or through the ZotServer add-on on Zotero 6 and earlier. The text of the inserted link comes from a Nunjucks template in the settings, with keywords for the item key, title, short title, publication year, month and day, and author names, including a loop over all authors.
