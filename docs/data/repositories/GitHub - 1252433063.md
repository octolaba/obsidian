# OHM-Engineering/obsidian-csharp-interactive

The repository holds CSharp Snippet Runner, an Obsidian plugin that adds a run button below code blocks tagged as C# or dotnet and shows the execution output in the note. It executes snippets through CSharpRepl, which the README says is installed automatically as a dotnet tool into the plugin folder, accepts optional script arguments, and stores the output and arguments per snippet so they are restored when the note is rendered again. The README states that Obsidian 1.12.7 or later and a locally installed dotnet SDK are required.
