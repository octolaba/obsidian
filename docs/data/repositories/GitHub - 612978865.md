# L7Cy/obsidian-dynamic-timetable

Obsidian plugin that builds a task timetable from a Markdown file, computing estimated completion times from per-task estimates. Tasks carry an optional start time given either as a time or as a date and time, and commands to complete or interrupt a task check off the topmost unfinished one and overwrite its estimate and scheduled start with the actual time taken; interruption additionally creates a copy carrying the remaining time. Task text is coloured by comparing the start time with the end of the previous task. The README records the plugin as inspired by TaskChute.
