# davfive/obsidian-jtab

The repository holds jTab Guitar Codeblocks, an Obsidian plugin that renders guitar chords and tablature inside notes through the jTab library. Its README records three block languages: one rendering the jTab lines it contains, with chords and tabs detected automatically, one printing the library's example set when left empty, and one printing the available chord names for copying into an ordinary block. It adds several behaviours of its own, among them rendering each line of a block separately while ignoring blank lines, and treating lines that begin with a hash and a space as Markdown inside the rendered block.
