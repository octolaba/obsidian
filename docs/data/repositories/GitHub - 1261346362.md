# usero2/obsidian-plugins-folder-as-gallery

Folder as Gallery opens the contents of any folder as a responsive media gallery in a new tab, reached from a gallery icon added beside each folder in the file explorer. The grid shows thumbnails for images and for videos, which preview on hover, and for Markdown notes it uses the first image inside the note as a cover or falls back to a text preview. An optional click-to-zoom mode opens a fullscreen overlay where arrow keys or the mouse wheel cycle images, further keys and dragging zoom and pan, and a filmstrip keeps the focused thumbnail centred. Tab titles show the full folder path, a search bar filters files by name, and settings set the thumbnail size between 100 and 500 pixels and can force the gallery icon to the far right for compatibility with other explorer plugins.
