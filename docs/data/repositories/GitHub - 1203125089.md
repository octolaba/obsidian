# TheKalpit/tare-money

Tare Money records personal finances as plain-text accounting inside an Obsidian vault, storing each transaction as a Markdown file in a configurable directory rather than in a cloud service or an external app. Transactions are entered through a form instead of by hand, validated as double-entry with a zero-sum requirement, categorised with hashtags, and can carry multiple currencies with an explicit conversion. Two built-in views report balances and income against expenses, filtered by date range or text. The README records localized number formatting for several locales, stale-data detection with a reload for vaults kept in sync, and operation wherever Obsidian runs, on desktop, iOS and Android.
