# Jopp-gh/Obsidian-Dune84

Dune is an Obsidian theme named after Frank Herbert's novel cycle and the 1984 film by David Lynch. Its README describes three palettes: a daylight one of wood, sand and rose tones, a nighttime one of dusk, midnight and near-black, and flat tones resembling Obsidian's default black-and-white theme, with both flat tones customisable. The README states that the theme is not only a colour play but adds further features, and it distinguishes two editions: Dune-Silver, the free version in this repository, and Dune-Gold, a paid version with more options and a manual of about seventy pages. A separate wiki page carries troubleshooting.
