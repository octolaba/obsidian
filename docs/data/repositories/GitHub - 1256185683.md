# lishu2043687491-ux/Obsidian-ZengQiang

ZengQiang Enhanced gathers common office-tool actions into one Obsidian workspace aimed at people coming from Feishu, WeCom, Notion and OneNote, while leaving notes in standard Markdown. It provides a floating toolbar over the text with reorderable buttons for text, paragraph, link, file, image, date, table and template actions, and a settings centre organised by task. A template library kept in a configurable vault folder is shared by the settings page, the toolbar menu and the table dialogs, and the table layer offers three mutually exclusive modes, from an Advanced Tables style editing set to a legacy mode with colours, column widths and OneNote rich-text paste, or none at all. Further features cover localizing pasted remote and OneNote images as attachments, wide pages, copy-as-image and short links.
