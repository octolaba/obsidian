# Pflanzmann/obsidian-summary-plugin

Compiles several Markdown files, a folder or an entire vault into one concatenated text document. The plugin traverses the note graph over outgoing links and backlinks to a configurable depth of one to five, and a modal tree view shows which root and linked files will be included, so individual files or whole folders can be unchecked or added by hand. The README names generating context files for large language models as the primary use case, and also describes a history of recently summarised files, exclusions by folder, file or glob, and a mirror mode that pairs primary notes with their equivalents in another folder and labels their source.
