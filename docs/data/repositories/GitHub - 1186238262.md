# Mindaugas3/list-splitter

A small Obsidian utility plugin for splitting and merging lists in Canvas cards. One command takes a selected text card holding a bulleted or numbered list and turns each item into its own card, stacked vertically from the original card's position with the list markers stripped. The reverse command combines two or more selected text cards into a single bulleted list card at the top-left card's position, ordering them top to bottom and then left to right. Unordered and ordered markers of several forms are recognized, and the commands can be bound to hotkeys.
