# onikun94/obsidian-local-rss

No repository description is recorded, so this body is grounded in the README alone. Local RSS saves articles from RSS feeds as local Markdown files in an Obsidian vault, managing multiple feeds, updating them periodically or on demand, and supporting front matter and tags. A feed is added with a name, a URL and an optional folder under a configurable RSS folder, and commands update all enabled feeds or add a new one. File names and note content come from templates whose variables cover the title, link, author, content, publication and save times, image, description and the article's categories rendered as hashtags.
