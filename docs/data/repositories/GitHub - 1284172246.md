# luffysolution-svg/mineru-to-obsidian

MinerU Parser adds a right-click Parse document action to Obsidian's file explorer that converts PDFs, Office files and images into Markdown, saving the note and any extracted image attachments to configurable folders. It offers seven parsing backends with different trade-offs in quality, cost and privacy: MinerU in the cloud, the local markitdown and docling command-line tools, vision LLM OCR through any OpenAI-compatible model, and the Baidu OCR, TextIn and Doc2X document-parsing services. Other features include batch parsing of a multi-file selection with backend-aware concurrency, save paths built from filename, date and note-name variables, and attachment renaming. The README records the plugin as desktop-only because the local backends spawn processes, and it is written in English and Chinese.
