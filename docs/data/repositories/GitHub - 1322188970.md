# maxkalem/obsidian-native-git-bridge

Native Git Bridge runs real Git commands on Android by handing them to the git binary inside Termux through a companion app; on desktop it loads only to explain itself and disables every operation. It covers status, fetch, pull, push, commit, a combined sync, merge abort, staging and unstaging per file or folder, discarding changes, resetting to HEAD and restoring a file from a commit, with sparse checkout supported. Its main surface is a status panel grouping conflicts, staged changes, changes and untracked files, switchable between list and folder-tree layouts, alongside diff panes rendered by the plugin where a hunk or a set of picked lines can be staged, unstaged or discarded. History panels show a repository's commits and what each did to a single file, and a live output panel streams what Termux is saying and whether the request reached it at all.
