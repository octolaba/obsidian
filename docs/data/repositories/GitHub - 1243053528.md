# AndyM-DC/obsidian-link-extractor

Obsidian plugin that scans the active note for external links and copies them as a list, for uses such as bibliographies, reference lists or sharing resources. It collects HTTP and HTTPS links written as Markdown links, bare URLs or angle-bracket links, and removes duplicates. The result is offered in four shapes, plain URLs one per line, a bullet list, a numbered list or Markdown links, and copied to the clipboard from a command palette entry.
