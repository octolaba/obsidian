# owais-sadiqque-dayderh/tinycal

tinyCal is a calendar for Obsidian built around events that have a start date but no fixed end: the bar for an open event extends to today on every render until it is explicitly ended from the calendar. Each event is plain frontmatter on an ordinary note carrying a generated id, a start date, an optional end date and an optional tag, and a note without that id is invisible to the plugin. Month and week views can be switched, events are created by clicking a day or by turning the open note into an event, and right-clicking a bar ends it today or on a chosen date. Tags can be given colors in settings or left to an automatic stable color, and the plugin is desktop only with no recurrence, reminders or external sync.
