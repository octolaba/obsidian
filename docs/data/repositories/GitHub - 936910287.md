# seantiz/obsidian_egv_plugin

Obsidian plugin that exports a vault's graph view to a file that can be opened without Obsidian. The export is configured by a focus mode — a single parent or the full graph — and a relationship strategy of tags, links or folders, and it writes either Mermaid, which the README recommends for the single-parent focus and smaller graphs, or GraphViz dot, recommended for the full graph and able to carry relationship metadata or cluster notes and tags into subgraphs. The README states that the plugin is only passively maintained and that its author no longer uses it day to day.
