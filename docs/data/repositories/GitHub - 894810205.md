# ruszabarov/obsidian-unit-converter

This plugin converts units inline in a note through a bracketed syntax carrying a value, a source unit and a target unit. The README records unit autosuggestion that can be turned off in the settings, a modal-based conversion command aimed mainly at the mobile experience, and custom units defined in settings as a positive factor of a built-in anchor unit within an existing measure. Its supported measures include length, area, mass, volume, volume flow rate, count, temperature and time.
