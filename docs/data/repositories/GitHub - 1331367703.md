# groundfic/obsidian-gallery-navigator

Gallery Navigator replaces the file list with a folder and nested tag tree beside a masonry wall of cover-image cards, rendered lazily so large folders stay usable on mobile. Covers come from a frontmatter field, the first embedded image, the image file itself, a PDF's first page or a linked page's preview image, and cards can be pinned, coloured, batch moved or deleted in three layouts that place the title over, under or beside the image. A built-in BM25 index searches note text and PDF text, the latter read from the Text Extractor plugin's cache when it is installed, through a popup that shows thumbnails, highlighted matches and context snippets. Optional extras add a quick-look image preview, rich cards for bare URLs, and offline stripping of tracking parameters from links.
