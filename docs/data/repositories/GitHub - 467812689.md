# johnsonhong997/obsidian-file-cleaner

The repository holds File Cleaner, an Obsidian plugin that removes empty files and unused attachments from a vault. Its README defines an empty file as one of zero bytes or holding only spaces and line breaks, restricts attachment cleaning to a listed set of image, vector and PDF extensions, and records three disposal settings: the system trash, Obsidian's own trash folder, or permanent deletion. Cleaning is started from a ribbon icon, and the README records a known limitation, that attachments used inside Admonition code blocks are not recognised as used.
