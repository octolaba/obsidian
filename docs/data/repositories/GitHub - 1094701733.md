# j4ckofalltrades/obsidian-tab-numbers

Tab Numbers draws numbered badges from 1 to 8 on Obsidian tabs while Ctrl or Cmd is held, as hints for the built-in shortcuts that switch tabs by number. The README notes that each split pane keeps its own tab sequence and that the badges are shown only on the currently active split. Badge text and background colours are configurable in the plugin settings, and the README states that manual installation is currently the only supported method.
