# Vaccarini-Lorenzo/MagicCalendar

MagicCalendar uses natural language processing to find potential calendar events in Markdown notes and synchronize them with a calendar, and the README states that the plugin is in beta with Apple Calendar and Google Calendar supported. Patterns that are wrongly recognized as events can be banned, and custom delimiters can mark events the engine does not recognize. An inline event view embeds events in notes with a short syntax and is two-way synchronized, which the README records as supported by Apple Calendar only because Google Calendar push notifications need an HTTPS server.
