# DuckTapeKiller/global-book-search

Aggregates book metadata and covers from several sources when creating book notes: Google Books and Open Library through their REST APIs, and Goodreads and StoryGraph through custom parsing engines. A global search consolidates and deduplicates results across configured services with source badges, a barcode scanner starts the same extraction from a physical book, and individual services including a local Calibre library can be searched on their own. The README describes conflict resolution that merges providers by a prioritized scoring system, translator and edition extraction from StoryGraph with a structured-metadata fallback, and high-resolution cover retrieval from Goodreads.
