# AbdelrahmanHafez/obsidian-scroll-line

Scroll Line moves the Obsidian viewport by a configurable number of visual lines while preserving the cursor and selection. It works in Editing and Reading modes, supports smooth scrolling and key repeat, and exposes hotkeys and line-count settings.
