# AbdelrahmanHafez/obsidian-scroll-line

Scroll Line scrolls the Obsidian editor viewport up or down by a configurable number of lines without moving the cursor, which the README compares to the scroll-line commands of VS Code. It reads the actual line height from CodeMirror so the distance stays correct across themes and font sizes, offers an optional animated scroll with easing, and registers its keybindings at the CodeMirror level so that holding a key repeats the scroll. The README gives that key-repeat behaviour as its reason for existing: Obsidian has no built-in command for scrolling by lines, and its hotkey system fires a command once per press.
