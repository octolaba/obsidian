# ishibashi-c/ishibashi-auto-tagger

Ishibashi Auto Tagger derives Obsidian frontmatter tags from note folder paths and refreshes those tags when notes are created, moved, or renamed. Rules can preserve manual tags, add archive tags, ignore years and excluded folders, remove numeric prefixes, and provide previews, explicit save and undo, cleanup commands, and English or Japanese settings; it only updates the tags field rather than note bodies or unrelated frontmatter.
