# ishibashi-c/ishibashi-auto-tagger

Ishibashi Auto Tagger derives Obsidian frontmatter tags from a note's folder path, for folder-first vaults where moving a note should refresh only the tags its folder implies. New notes are tagged on creation, moved or renamed notes are retagged from the new path with the previous folder's tags removed when replacement is enabled, and manually added tags are preserved. Rules can exclude template or system folders, skip year folders, strip numeric ordering prefixes so differently numbered folders yield one tag, give notes under an archive folder an archive tag instead, and add custom names for exceptions picked from existing folder names. A preview shows the tags a sample path would produce, commands run over the current note, the current folder or the whole vault, and the interface switches between English and Japanese.
