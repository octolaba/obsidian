# duanxianpi/zotflow

This repository holds ZotFlow, an Obsidian community plugin that brings a Zotero library into the vault. Its embedded reader opens PDFs, EPUBs and HTML themed to match Obsidian and supports the annotation types Zotero offers, while items, metadata and annotations sync in both directions with each library configured as bidirectional, read-only or ignored and a field-level diff viewer for conflicts. Every Zotero item gets an auto-generated source note rendered from LiquidJS templates, Zotero child notes are created and edited without leaving Obsidian, and citations are inserted in Pandoc, wikilink, footnote or raw citekey form by drag-and-drop, an autocomplete trigger or hotkeys. Vault PDFs and EPUBs that are not in Zotero can be annotated with the same reader, storing annotations in a co-located sidecar file.
