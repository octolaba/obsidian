# eoureo/obsidian-runjs

RunJS runs JavaScript inside Obsidian without packaging it as a separate plugin, while still giving the code access to manage the application and its notes. Code is written either as code blocks in notes or as separate .js and .mjs files in a scripts folder, and each piece is marked as a script or as a module, so larger work can be split into executable code and modules. It can be run from a list view that shows every registered snippet, from a modal that browses a hierarchy of code groups, automatically when the plugin loads, from a command added to the command palette that can then take a hotkey, or from an added ribbon icon.
