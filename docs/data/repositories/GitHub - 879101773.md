# travisvn/obsidian-edge-tts

Obsidian plugin that reads notes aloud using Microsoft Edge's text-to-speech API, either a selection or the whole note, with a choice among listed voices or a custom voice, adjustable playback speed, optional status notices, and an option to generate an mp3 file and embed it. The README records native support on desktop and on mobile. It also carries a maintainer warning that, since around December 2025, Microsoft's servers have been inconsistent about allowing the work-around the plugin relies on, so the service may be unavailable.
