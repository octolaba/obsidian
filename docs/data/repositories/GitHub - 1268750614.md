# aiday-mar/code-style-keys

Obsidian plugin that wraps the current selection in backticks when the backtick key is pressed. The README states that a single-line selection becomes inline code and a multi-line selection becomes a fenced code block, and that a duplicate trailing backtick left over from the keypress is removed. It describes the mechanism as a listener on the input event that cancels the default insertion, replaces the selection with the chosen syntax, and runs a short cleanup pass.
