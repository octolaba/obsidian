# vrtmrz/obsidian-screwdriver

The repository holds Screwdriver, an Obsidian plugin that exports files from inside a vault into a Markdown note and restores them from that note later. Its README gives the purpose as moving or synchronising files that ordinary Markdown synchronisation handles poorly, such as plugin files, theme files, CSS snippets and hidden files under the configuration folder. Recorded features are exporting from selected folders, fetching remote files into a note, restoring files including those under hidden folders, and filters that skip files while exporting; from version 0.0.7 the plugin can also be driven from note properties. It warns that such a note becomes very large and should be excluded from plugins that scan Markdown heavily.
