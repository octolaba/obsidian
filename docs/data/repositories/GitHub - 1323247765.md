# alex3l3t33/knowledge-heatmap

Knowledge Heatmap is a local-first plugin that scores notes on maintenance signals and presents them in a dashboard of healthy, stale and forgotten categories. The score combines recency worth 60 points, resolved incoming and outgoing links worth 25, and closeness to a configured word-count target worth 15, with a temporary grace allowance for notes under seven days old. Each result shows the factor contributions, a plain-language explanation and one suggested maintenance action, alongside attention-first note and folder lists with search and category filters. Analysis is read-only and local, is debounced after Markdown and link changes, and involves no account, telemetry or network requests.
