# HanochShi/obsidian_md2wechat

Markdown to WeChat MP Sync renders a Markdown note with custom styling and pushes it into a WeChat Official Account draft box in one action. The README, written mainly in Chinese, records automatic upload of the note's local images into the account's material library so they land in place, a side-by-side live preview with synchronised scrolling, a built-in HTML renderer that accepts user-supplied CSS, automatic use of the first image as the article cover, and copying the rendered article to the clipboard as a fallback. It documents the setup at length: an AppID and AppSecret taken from the official account's developer settings and entered in the plugin, plus the machine's public IP added to the platform allowlist, noting that IPv6 addresses are not accepted and that changing a proxy node means adding the new address.
