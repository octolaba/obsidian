# karstenpedersen/obsidian-daily-note-navbar

Repository for Daily Note Navbar, an Obsidian plugin that replaces the view header of a daily note with a bar for moving between sequential daily notes. Other files keep the normal view header, and daily notes can still be renamed from the tab bar and the file explorer. Date formatting is customised in the settings tab, and the README lists the CSS classes exposed for the bar itself and for default, active, current, non-existent and week-changing elements; the author credits a similar navbar in RemNote as the inspiration.
