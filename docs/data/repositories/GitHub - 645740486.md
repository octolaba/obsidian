# crybot/obsidian-flashcards-llm

Generates flashcards from a note using OpenAI models, appending the result to the note inside a blockquote. The API key and the model are set in the plugin settings, and the README lists completion models alongside reasoning models whose reasoning effort can be set to low, medium or high. Generation can run over the whole note or a selection, with a custom prompt, a chosen number of cards, a chosen tag, and configurable separators for inline and multi-line card formats.
