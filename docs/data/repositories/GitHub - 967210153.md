# Enthalpiex/Eccirian-Encrypt

Eccirian Encrypt is an Obsidian plugin for encrypting notes, attachments, folders, and other common file types with AES-256-GCM and ECC-P-256. It provides temporary and permanent encrypted file modes, a read-only view for locked files, configurable key derivation, and password-protected access on desktop and mobile.
