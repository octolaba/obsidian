# Enthalpiex/Eccirian-Encrypt

Obsidian plugin that encrypts files in a vault, including linked attachments alongside the note, and works with file types beyond Markdown. It offers a temporary mode whose files are unlocked once and then edited normally and a permanent mode whose files stay encrypted on disk and ask for a password when opened, each with its own file extension, plus a read-only view for locked files and media preview in the permanent-mode editor. The README states that it uses AES-256-GCM and ECC-P-256 through the Web Crypto API with configurable PBKDF2 and Argon2id parameters, and warns that it is meant for personal use, not for mission-critical information, that vaults should be backed up first, and that losing the password loses the file.
