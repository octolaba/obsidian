# andrewbrereton/obsidian-to-ical-plugin

Scans the vault for checkbox tasks containing a date and generates an iCal calendar file from them, appending an emoji per task status, so the result can be imported into a calendar application. The calendar can be written to the filesystem, stored in a GitHub Gist, or posted to a configured web endpoint, either manually or on an interval between 1 and 1440 minutes. The README states that with disk output alone the plugin makes no network requests, that Gist output sends the file to the GitHub API using the token provided, and that the web destination is additionally polled every five minutes while enabled. It reads Obsidian Tasks emoji and dataview formats and Day Planner format tasks without requiring either.
