# Seraphli/obsidian-link-embed

The repository holds Obsidian Link Embed, a plugin that converts a URL in a note into an embedded preview. Its README records a suggestion popup shown when a link is pasted, offering to create an embed, to create an ordinary Markdown link, or to dismiss the popup, alongside three further ways of handing a URL to the plugin. From version 2.0.0 embeds are rendered through a Markdown code block processor rather than an HTML block, and a conversion button in the settings migrates older embeds; the author asks readers for further free metadata services the plugin could draw on.
