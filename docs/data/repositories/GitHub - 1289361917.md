# sonna-io/obsidian-files-progress

Files Progress draws a slim colour-coded progress bar below each Markdown note in Obsidian's File Explorer, so unfinished drafts and overgrown notes are visible without opening them, and adds a sidebar for reviewing progress across the vault. Progress is derived automatically from note length, and an exact percentage can be set by hand where length is not a meaningful measure. Projects and folders can be given their own targets or colours, progress can be hidden for notes or folders where it is not useful, and one change can be applied to several selected notes or folders at once. The README states that Obsidian 1.5.7 or newer is required.
