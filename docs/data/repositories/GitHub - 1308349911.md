# search5/safe-passage

SafePassage links local KeePass database files to an Obsidian vault so credentials render inside notes without exposing the master password. Inline tokens written in backticks become masked circular chips that copy the secret value on click, with a configurable clipboard auto-clear timeout, and code blocks render a whole credential group as a table with a customisable title and inline lookups. Decryption uses a WebAssembly Argon2 engine, master passwords are cached in protected session memory for automatic background unlocking, and database and key files are read and written through Obsidian's Vault API so the same vault-relative paths work on desktop and on iOS and Android. An Insert Secret command modal writes new secrets into the database and completes the matching tokens.
