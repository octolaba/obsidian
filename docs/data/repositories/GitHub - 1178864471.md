# SomehowItWorks/lazy-album

Obsidian plugin that renders images in a masonry or waterfall layout from a code block that mixes several kinds of source: direct web URLs, individual file paths inside the vault, and vault folder paths whose images are all loaded. Block keys set the column count, the gap between images, an images-per-page limit for pagination and an exclusion list, captions are written after a pipe and shown on hover, and the block is repaired automatically when image files or folders are renamed or moved inside Obsidian. The README states that the plugin has no built-in lightbox, so clicking an image does nothing and a separate viewer plugin is suggested, and that its code was written with the assistance of Google Gemini.
