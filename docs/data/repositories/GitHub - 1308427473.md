# hikosalaidarkcommit/confluence-import

Confluence Page Import imports Confluence pages into local Markdown notes in Obsidian. Each import is manual and one-way, and the README states that the plugin has no write capability and never writes back to Confluence; before a note is touched, a read-only diff preview shows what would change and the choice is Pull and Replace or Cancel and keep local. Conversion from Confluence storage format to Markdown happens inside the plugin, so the README says no external tools such as Pandoc or command-line converters are required. Its stated safety story adds credential host and protocol guards, metadata-only logging, a published security policy and attested release artifacts.
