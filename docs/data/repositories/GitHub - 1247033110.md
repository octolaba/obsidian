# jaliriogbarrios19/Research_Paper

Searches academic databases and drafts APA-style research briefs from inside Obsidian, started from a ribbon icon in an open note. An LLM provider and API key are configured in settings, with the README listing OpenAI, Anthropic, DeepSeek, Google Gemini, OpenRouter, Grok, GLM and a default provider called spob, each with several selectable models. The plugin detects the Obsidian interface language automatically, and parts of the README are written in Spanish.
