# salockhart/obsidian-bbcode

Obsidian plugin that converts Markdown files to BBCode for pasting into forums. Its documented use is to open a file in the editor and run the command that converts it and copies the result to the clipboard. The README credits the marked Markdown parser and a md2bbc.js project, and describes a GitHub Actions workflow that bumps the version, pushes the commit and tag and creates a draft release with the built assets attached.
