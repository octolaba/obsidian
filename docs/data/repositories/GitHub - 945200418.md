# wenlzhang/obsidian-canvas-format-brush

Copies formatting attributes between elements on an Obsidian Canvas, which the README compares to a format painter. The commands copy the size and colour of the selected element, or only its size, or only its colour, and paste the copied formatting onto every currently selected element; they are reachable from the context menu as well as the command palette. A status bar indicator shows when a format has been copied, and the README points to a separate documentation site for the rest.
