# eugeny-dementev/briefmaker

Briefmaker prepares an AI agent brief from the current Obsidian note. The README states that it calls no APIs, runs no AI and modifies no notes automatically: it renders a prompt and copies it to the clipboard, through a copy command or a preview modal. The brief is built from a path-based template chosen by ordered regex rules, first match wins with a default template as fallback, and its variables cover the file path, file name, folder path, vault name, content, current selection, stringified frontmatter, local date, and a bullet list of unchecked tasks extracted from the note with indentation preserved. The repository carries no description, so this summary rests on the README alone.
