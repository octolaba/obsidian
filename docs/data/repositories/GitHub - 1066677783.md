# dpvpro/obsidian-cleaning-service

Obsidian plugin that performs cleanup tasks over a vault. The README lists the resources it can remove: orphan media and attachments that nothing references, frontmatter references included; files that are empty or contain only whitespace; empty directories; files above a configurable size limit; and notes whose frontmatter expiration attribute has passed. Deletion of a big file is confirmed by default even when confirmation is otherwise disabled, and commands are provided for setting an expiration date on a note.
