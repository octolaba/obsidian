# juan-miii/obsidian-notice-plugin

Obsidian plugin that removes notices after a specified delay once the workspace is ready, used primarily to hide the debug startup time notices shown for community plugins. The delay is set in the settings tab the plugin adds and accepts values between zero and sixty seconds, where zero is reserved for keeping the notice persistent. The README records that the project is written in TypeScript against the plugin API typings.
