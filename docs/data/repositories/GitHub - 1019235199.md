# aaaaalexis/obsidian-baseline

This repository holds Baseline, an Obsidian theme by the author of Cupertino built around deep integration with the Style Settings plugin, so that colours, spacing and typography can all be reshaped while the defaults are meant to work untouched. It supports every filter and helper class from the Minimal theme, adds banner classes of its own, and its README describes enhanced navigation, refined menus and comfortable spacing for mobile screens. The project site hosts a migration tool that carries Style Settings over from supported themes and a marketplace of community-made presets.
