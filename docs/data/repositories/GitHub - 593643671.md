# msrch/obsidian-double-colon-conceal

Repository for Double Colon Conceal, an Obsidian plugin that displays the double colon of a Dataview inline field as a single colon for a more natural reading experience. Concealment in the editing view is turned off by default and, once enabled in settings, applies in Live Preview but never on the active line, within a text selection or in Source mode. The concealed colon carries a `cm-double-colon-conceal` CSS class that custom styling can target, and the README recommends restarting Obsidian after installing to avoid render caching issues.
