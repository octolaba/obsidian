# NateScarlet/obsidian-content-addressed-attachments

The repository holds an Obsidian plugin that stores attachments by content address, generating a CID per file and deduplicating identical content. It resolves IPFS-style links with filename and format parameters, can download and checksum external web images so links keep working offline, supports configurable external gateways, and offers AES-256-GCM encryption with keys held in Obsidian SecretStorage and gitignore-style rules for automatic encryption. The README states that the plugin is independent of the official IPFS network, works inside the local vault, and includes bulk migration of existing attachments.
