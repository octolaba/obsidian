# OLCUBO/obsidian-cubox

The official Cubox plugin syncs articles and annotations from a Cubox account into an Obsidian vault, on a schedule or on demand from a ribbon icon or the command palette. The README states that the sync is one-way and create-only: notes are created but never updated, so later changes to a card in Cubox do not reach an existing note, and each card is stored with its Cubox id in frontmatter for deduplication. Configuration selects the server domain and an API key, and requires all four filters — folder, tag, type and status — to have a selection before any sync runs; file names, frontmatter and note body come from customizable templates.
