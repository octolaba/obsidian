# LJrobinson/obsidian-lj-os-plugin

Standalone Obsidian desktop plugin that renders local Git activity snapshots as Git Wall sections in Daily Notes. It discovers repositories under user-configured scan roots, tracks the validated ones, scans them at startup and on an interval, writes a daily JSON snapshot inside the vault, and inserts or replaces the Daily Note section from that cached JSON alone, with an optional activity bar showing three-day or seven-day tables and a dashboard layout that reorders the generated sections. The README states that it needs no login, API key, cloud service, companion application or CLI, contacts no Git hosting API, sends no analytics or paths anywhere, and calls an external weather service only when that option is enabled with coordinates.
