# leonardsellem/hypermnesic-companion

Hypermnesic Companion is a read-only Obsidian plugin that surfaces related notes from a self-hosted hypermnesic recall index while writing. Recall is triggered when typing pauses rather than per keystroke, covering the block around the cursor, and results are shown through a status-bar indicator that expands into a popover, an opt-in sidebar, an optional inline editor marker, and a dockable thinking panel carrying related notes, Socratic questions and tensions with a back trail and selection-based recall. Related notes render as native internal links with hover preview, a right-click menu and drag-to-insert, while a note absent from the vault renders as a muted row with a snippet from the engine rather than a link that would create it. The plugin is desktop-only, licensed GPL-3.0, and the README states that it never writes to the vault.
