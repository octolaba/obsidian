# albibenni/Todoist-Plug

Todoist-Plug creates Todoist tasks from a quick-add modal that prefills the title from the selected text or the active file name, can append a deep link back to the note, and offers searchable pickers for project, label, date and priority, with projects and labels fetched live from the Todoist API. Other commands create a task straight from the current line without the modal, check whether a matching task already exists, open a Todoist sidebar view and verify the stored credentials. Defaults for project, priority, date and labels are set in settings, and a fenced todoist block renders the tasks matching a filter query inside a note. Authentication uses Todoist OAuth with PKCE and stores its tokens in Obsidian's SecretStorage, with a manually supplied personal token as a fallback.
