# tararesearch/Obsidian-MSPeopleSync

This repository holds Microsoft People Sync, an Obsidian plugin that syncs Microsoft Graph contacts into one note per person, written from a customizable template. Its settings cover an access token, the people folder, a file prefix and the template itself, while a command palette entry runs the sync and writes one file per contact into that folder. The README shows a template built from contact fields including display name, job title, email, mobile phone, department, company and office location, and notes that the generated notes can be linked or embedded from other notes.
