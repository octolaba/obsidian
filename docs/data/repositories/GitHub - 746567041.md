# akopdev/obsidian-bibtex-manager

BibTeX Manager creates literature notes in Obsidian from a pasted BibTeX entry using customizable templates, formats BibTeX entries into a reference list inside a note, and inserts citations directly. The README states the source BibTeX file is left unmodified while the formatted list lives in the note, that entries from Zotero, Mendeley or other reference managers are accepted, and that the plugin treats mobile as a first-class platform with no external services or desktop-only dependencies.
