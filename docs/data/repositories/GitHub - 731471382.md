# eatgrass/obsidian-gemini-assistant

This repository holds Gemini Assistant, described upstream as an AI assistant in Obsidian. Its short README lists two features, content generation and a Gemini chat, and two commands, New Gemini Chat and Open Assistant. It states that a Gemini API key must be obtained by the user from Google's developer site.
