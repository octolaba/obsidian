# caesarloo/obsidian-svn

Vault SVN is a desktop-only Obsidian plugin that integrates Subversion version control with a visual client panel inside the vault. The README describes a status tree of added, modified, deleted and conflicted files, staging, commit with a message, updating the working copy, conflict marking as resolved, an auto-refresh interval and an option to open the panel at startup. It discloses that the plugin invokes the system svn command through the Node child process API and reaches SVN working copies on the local filesystem, operating only on configured paths, and that an installed svn CLI and a local working copy are prerequisites.
