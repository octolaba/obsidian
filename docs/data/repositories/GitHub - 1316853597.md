# fengshuzi/browser-note

Browser Note runs an HTTP server inside Obsidian that exposes the vault over localhost, bound to 127.0.0.1 by default with an opt-in setting for LAN access. Endpoints list, read, create, replace and trash Markdown notes, resolve a wiki or Markdown link to a real vault path using Obsidian's own shortest-path resolution, serve and upload binary assets, report the daily-notes folder and format, and list journal entries by parsed date. Every request needs a bearer API key generated on first run, which can be copied or regenerated in settings and also passed as a query parameter on GET requests. A built-in journal-style web UI is served on the same port and can be turned off if only the API is wanted; the plugin is desktop-only.
