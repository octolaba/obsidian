# arrowedisgaming/arroweds-adversary-bank

An Obsidian plugin that embeds Daggerheart adversary and environment stat blocks in campaign notes and runs the encounter from the same note. Every adversary and environment from the Daggerheart SRD, plus a homebrew folder, is insertable from one command-palette picker, and the blocks also work in Obsidian Canvas. HP, stress, conditions, feature uses and countdowns are tracked on the block itself, each instance of a repeated adversary keeping its own name and state, with the eight standard conditions available and custom ones definable. The repository description records it as a fork of BeastVault adding renaming, conditions, summoning and instance tracking.
