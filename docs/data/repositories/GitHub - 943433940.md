# wenlzhang/obsidian-file-title-updater

Keeps the three places a note's title can appear in step: the filename, the title field in the frontmatter, and the first level-one heading. Four commands update the other two locations from a chosen source, the filename, the frontmatter or the first heading, or from the source configured as the default. The same synchronisation runs over a whole folder and its subfolders from the folder's context menu; the README warns that the bulk operation touches many files, cannot be reverted, and should be preceded by a backup.
