# chuyuan-li/note-share-image-exporter

This plugin exports a note, a selection or a whole folder as an image or a PDF, keeping Obsidian's own rendering so Mermaid diagrams, math, code blocks, callouts, metadata and the current styling appear in the result. A preview allows width, padding, format, resolution, watermark and author information to be adjusted before the result is copied or saved. Long notes can be split by fixed height, by horizontal rules or by paragraphs, a hidden mark can be embedded in the exported pixels for later matching, and the interface is available in twenty languages. The plugin also exposes an export function callable from the Obsidian command-line eval command, which skips the preview and writes directly to a path.
