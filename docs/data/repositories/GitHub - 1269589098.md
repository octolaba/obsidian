# Haperone/local-image-compress

Compresses PNG and JPEG images inside an Obsidian vault locally, without cloud services or APIs, through WASM pipelines — imagequant for PNG and mozjpeg for JPEG — while WebP, GIF, BMP, HEIC and AVIF are deliberately skipped for want of encoders. Commands compress the images of the active note, of a selected folder or of the whole vault into a Compressed folder mirroring the original paths, and a move command puts them back over the originals after making backups. Automation can compress new files as they arrive or run in the background once a threshold of uncompressed images is reached and the user has been inactive. The README also records that the plugin temporarily disables a third-party paste-image-rename plugin while working, because matching output to originals depends on new files not being renamed.
