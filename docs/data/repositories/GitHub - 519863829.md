# SimplGy/obsidian-open-file-by-magic-date

The repository holds an Obsidian plugin for opening a file whose name matches a date pattern. Its README records patterns written with a date format in braces inside the filename, so a single keystroke can open a note for today, and an anchoring form that resolves to a particular weekday, which the author uses to open the note for the most recent Monday. Several patterns can be configured at once, for instance a monthly and a yearly note, while opening the first file matching a search query is listed as not yet implemented.
