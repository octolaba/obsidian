# jnagase/obsidian-momentum

Momentum Life is an all-in-one life dashboard for Obsidian covering habits, tasks, fitness, nutrition, studies and finances, rendered from plain Markdown files kept under a single folder in the vault. It reads and writes through the Vault API and Obsidian's metadata cache, draws its visualizations as inline SVG without external libraries or a CDN, and leaves cross-device sync to Obsidian Sync, iCloud or git. The README records one optional network use, the Nutrition food search, and describes two-way Google Tasks sync as a beta feature that is off by default and signs in through a hosted OAuth broker so no credentials ship in the plugin.
