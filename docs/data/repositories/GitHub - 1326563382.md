# summerdawn-ai/obsidian-drag-drop-sort

Gives the File explorer a manual order in which files and folders can be freely interspersed: dragging a row shows a drop indicator and commits the new position on release, and dropping between rows of another folder both moves the item there and places it at that spot. The same moves are available from the context menu and as commands for up, down, top and bottom, and a folder's order, or that of a whole branch, can be reset. Orders are stored per folder in the plugin's data file as arrays of item names, with only folders that were actually reordered recorded. It works by patching the explorer's internal sorted-items call, and excludes hidden rows and unsupported file types from position calculations.
