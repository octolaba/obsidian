# vancoder4-cyber/anycontent-obsidian-importer

Obsidian side of a two-part importer: a pasted Douyin, TikTok, WeChat Official Account or YouTube link is sent over localhost to a separate local Python backend that transcribes, scrapes or OCRs the content and returns a Markdown note into the vault. A video yields a transcript, timestamped for YouTube, together with metadata; an image post yields per-image OCR text with image URLs; and a WeChat article yields its full body with inline image references. Every imported note carries a YAML frontmatter block with title, source, author, platform, post type, creation date and tags, so it can be queried by Dataview or Bases. The README states the plugin itself calls no third-party service, and that the split keeps Python and ffmpeg out of the plugin.
