# shabbirpatheria/folder-routines

Pixel Habits turns a folder of routine notes into a retro 16-bit RPG habit tracker in Obsidian. A routines block renders color-coded checkboxes, checking a habit logs the date in that note's frontmatter, and a day-plan block lets users drag habits into half-hour slots or add one-off tasks. A stats view presents levels, ranks, XP, achievements, streak heatmaps, and completion data.
