# theaayushpatel/quillcode

Quillcode is an Obsidian theme addressed to both writers and coders, and its README recommends JetBrains Mono for the best experience. The light variant is described as matching an aged writing desk under sunlight, suited to adding chapters and extensive reasoning, while the dark variant is framed as a quiet reading and writing space under lamplight with ink-like accents against an aged paper effect. The README's prose is largely atmospheric and records no configuration options or plugin support.
