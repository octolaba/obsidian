# elrindir/obsidian-csv-codeblock

This plugin renders code blocks written in CSV as tables in Obsidian: a block tagged csv is post-processed into a table, one row per line and one cell per comma-separated value. The README credits the implementation to the Markdown code-block post-processing example in Obsidian's developer documentation, and its changelog records tsv blocks being added after the initial release.
