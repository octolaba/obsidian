# CubieProg/Obsidian-Yandex-Tracker-Issue

Displays Yandex Tracker items inside Obsidian notes. The README describes code blocks that render issues supplied by id (`yt-issue`, `yt-gantt`) or by a Yandex Tracker query (`yt-issue-query`, `yt-gantt-query`) as tables or Gantt charts, with boards, projects, queues, sprints and users as its other modelled entities. Setup requires an OAuth 2.0 token and the organisation's Org-Id entered in the plugin settings; the README states that IAM tokens and Cloud-Org-Id are not supported. Its documentation is written in Russian.
