# TimDommett/Obsidian-Git-History-Reviewer

Walks through every commit in the vault's Git repository, showing a per-commit diff with per-file collapsing, line numbers, rename detection and add and remove highlighting, and lets each commit be ticked off as reviewed and approved. Files carry individual review circles with a live counter, reviewed files drop out of the diff by default so the next one moves up, merges expand to show every change they introduce, commits can be bulk-approved up to a chosen date, and the list filters between all, needs review and approved with search by message, hash or author. Approval state is stored by commit hash in the plugin's own data file, which the README states is added to the vault's ignore file on load and removed from the index if already tracked, so recording a review cannot itself produce a commit; a status pill verifies that continuously.
