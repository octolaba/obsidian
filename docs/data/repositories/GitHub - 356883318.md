# HEmile/obsidian-neo4j-graph-view

Neo4j Graph View was an Obsidian plugin that added a graph view backed by a Neo4j database, offering selective styling of nodes and edges by tag, folder and link type, selective expansion and hiding of nodes, images inside the graph, Cypher querying, typed links and a hierarchical layout. Its installation required a system Python 3.6 or later and Neo4j Desktop with a database created and started, and its documentation lived on the juggl.io site. The README opens with an announcement that the plugin has been rewritten under the name Juggl, which no longer needs Neo4j or Python, and that this plugin would be removed from the community plugins list.
