# MehulG/airtable-tabula

Airtable Tabula keeps local, Airtable-like tables inside an Obsidian vault: each table is a .tabula JSON file opened in a spreadsheet-style grid. It can import a CSV or Excel file as a table and offers field types including text, number, currency, percent, duration, rating, checkbox, date and time, URL, email, phone, single and multi select, attachments and auto number, with colored select options managed from searchable dropdowns. Views add search, a filter builder, multi-sort, grouping, hidden fields, column resize and reorder, and a frozen primary column, and a linked base or table can optionally be pulled or pushed with an Airtable personal access token.
