# y-usuzumi/obsidian-desktop-sticky-notes

Opens vault Markdown files in resizable popout windows that behave like sticky notes, each with controls to keep it on top, pick a colour, switch between editing and reading, or hide it. Because a window shows the real file, its edits stay in sync with the vault. Commands create a new sticky note in a configured folder, open or hide one for the current file, and designate a top-level note that a single command, or an optional system-wide shortcut stored separately per operating system, opens, brings forward or hides. It is desktop only, uses Obsidian's Electron APIs for the windows and the shortcut, and makes no network requests.
