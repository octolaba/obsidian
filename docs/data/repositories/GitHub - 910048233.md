# Hangeol-Chang/obsidian-csv-allinone

CSV All-in-One creates .csv files in the vault and modifies, saves and browses their data, on the assumption that DataviewJS is in use. Commands create a CSV table from entered data and open a CSV explorer for moving or deleting files, while the plugin object exposes functions to read a CSV file into headers and rows for rendering as a Dataview table and to open an input modal that appends a row with default values. The README states that a read result is a snapshot, so a real-time view requires re-reading the file after it changes, and that the row-adding example relies on the Buttons plugin.
