# DmitrievDmitriyA/obsidian-file-name-length-limit

Checks vault filenames against the length and character limits of Windows, Linux, Android and iOS, so that names which would break a sync between those systems are caught before they are applied. Opening or renaming a file raises a notice naming the affected platforms and the number of issues, and while a title is being typed or a file renamed in the explorer an incompatible name is underlined in red with the prospective length mirrored in the status bar, so the rename is refused before the typed text is lost. The status bar shows the active file length and becomes a warning that starts a full scan when clicked, and a command scans the whole vault and writes a compatibility report to the vault root. No repository description is recorded, so this note is grounded in the README alone.
