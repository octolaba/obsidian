# InterwebAlchemy/obsidian-ai-research-assistant

Obsidian AI Research Assistant is a research tool for prompt engineering against AI APIs, built initially around the ChatGPT API and run from inside Obsidian. Its README documents naming conventions and a memories concept with memory states, alongside currently supported and upcoming models, a roadmap and an explicit list of things unlikely to be added. The plugin is marked as beta software still in development and not considered fully stable, with installation available through BRAT or manually.
