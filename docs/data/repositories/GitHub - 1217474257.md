# peteszym/obsidian-git-file-colors

Colours rows in the file explorer from Git status: green for new or untracked files, muted orange for modified ones and muted red for deleted paths, with descendant changes rolled up to parent folders under a deleted, modified, new priority. Refreshes are triggered by vault create, modify, rename and delete events, with a polling fallback for changes made outside Obsidian and a manual refresh command for recovery. The README records the plugin as desktop only, requiring git on the system path and a vault that is or sits inside a single Git repository, and states that it only reads status and never stages, commits or otherwise modifies Git state.
