# Shreshth-mehra/Obsidian-TV-Tracker

This plugin tracks films and television shows inside Obsidian, with commands to search for and add a title to the library, add an episode list for the current file including new seasons and episodes, update the current file with new data, and refresh its streaming availability. The README's release notes record filtering by streaming provider, with a search box and an option for titles carrying no provider, a direct command for adding titles that can be bound to a hotkey, and automatic pickup of newly added or edited files without reloading the plugin.
