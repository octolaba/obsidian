# tahayigitmelek/note-radar

Note Radar records a view every time a Markdown note is opened and presents the accumulated statistics in a dedicated dashboard. Summary cards count the vault's notes, the viewed notes, the total views and the most viewed note, while a searchable, sortable and paginated table lists notes with view-count badges and a marker for those never opened. Statistics can be exported as JSON or cleared from the command palette, and the README states that the data is stored locally through Obsidian's plugin data system.
