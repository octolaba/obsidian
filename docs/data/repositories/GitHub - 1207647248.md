# chenyuxiaojin/obsidian-llm-translate

Obsidian plugin that translates a selection or a whole note with a language model, streaming the result into the editor as it arrives. One command translates selected text in place from the palette or the context menu, another translates the body of the note while leaving the YAML frontmatter untouched, and a status-bar spinner turns into a cancel control that restores the original text. Nine built-in providers are named, among them DeepSeek, OpenAI, Gemini, Kimi, Qwen, Zhipu, SiliconFlow and OpenRouter, alongside any OpenAI-compatible endpoint, with a command to switch between them and an editable system prompt carrying a target-language placeholder. The README states the plugin is desktop-only and that notes over twenty thousand characters need a confirmation.
