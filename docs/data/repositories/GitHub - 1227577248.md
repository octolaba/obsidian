# Ekrizdis367/obsidian-coach

Obsidian plugin that acts as a fitness coach inside a vault, storing routines, logged sets, body data and meals as plain markdown. The README describes workout templates with exercises, target sets, reps and weight; automatic detection of bodyweight exercises, rendered without a weight column; supersets grouped by a shared label, where the break timer uses a shorter pause between paired exercises; and drop sets and to-failure sets that are excluded from personal records. An analytics view carries a personal records section and tracks progress over time.
