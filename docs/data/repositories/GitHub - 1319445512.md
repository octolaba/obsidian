# harshitsnghl/obsidian-azure-wiki-preview

Azure Wiki Preview renders an Azure DevOps Wiki clone inside Obsidian the way the wiki will publish it, without changing the source files. Azure's colon-delimited mermaid blocks are drawn through Obsidian's own mermaid pipeline, with the diagram text read from the file rather than from rendered HTML, and an unterminated block is flagged inline; Azure's table-of-contents macros are shown as labelled chips instead of broken links. Two settings are off by default and meant only for a wiki clone: treating a heading whose hashes have no following space as a heading, and decoding percent-encoded page filenames for display in the file explorer, tabs, breadcrumbs, quick switcher and backlinks. Decoding is display only and never renames files, and space-less headings are still recorded as tags in Obsidian's metadata index, which the plugin can read but not change.
