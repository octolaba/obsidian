# Munckenh/obsidian-relative-dates

Turns date references written as `@ YYYY-MM-DD`, optionally with an `HH:MM` time, into color-coded elements that show the date relative to now. Colors distinguish overdue, today, tomorrow, this week and future dates, and both the colors and the `@` prefix are configurable. The transformation applies in Reading mode and in Live Preview.
