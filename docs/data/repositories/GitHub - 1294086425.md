# kebl3541/Obsidian-Pandoc-Export-Buttons

Pandoc Export Buttons adds a sidebar panel of format buttons that export the current note through Pandoc to Word, PDF, HTML, EPUB, LaTeX or any other format Pandoc supports, and every format is also a command that can take a hotkey. Transclusions are expanded before the export: note, heading and block embeds are replaced recursively and cycle-safely by the embedded content, so the exported file reads the way the note reads in preview. The README states that exports otherwise follow preview semantics.
