# farux/obsidian-auto-note-mover

Obsidian plugin that moves the active note into a destination folder according to configured rules. A rule pairs a destination folder with either a tag or a title matched as a JavaScript regular expression, rules are checked from the top and the first match wins, and the move is aborted with a warning when the folder is missing or already holds a note of the same name. It can trigger automatically when a note is created, edited or renamed, or only on command, and it skips notes whose frontmatter disables it. The README notes that attached files are not moved and stay visible in the note.
