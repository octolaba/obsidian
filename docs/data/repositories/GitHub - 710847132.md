# seebin/obsidian-minio-uploader-plugin

Minio Uploader uploads images, videos, audio, PDFs and other files to Minio object storage instead of copying them into the vault, which the README motivates by smaller local disk usage and faster synchronization between devices. Files can be dropped into the editor, pasted into it, or chosen through a command, the last being intended for use alongside the Editing ToolBar plugin. Settings hold the Minio access key, secret key, bucket, endpoint, port and SSL flag, and the README notes that anonymous access must be enabled on the bucket so the uploaded files are reachable by URL.
