# MrParalloid/obsidian-things

This repository holds a Things 3 theme for Obsidian, aimed at visual consistency for people who use both applications, and tested on macOS, iPadOS and iOS only. The README records exact color matching with Things 3 in light and dark on desktop and mobile, together with Things-like animations, sidebar, quick switcher, menus, checkboxes and hidden tag markers, a mobile toolbar, prettified code blocks, full-size video previews and Style Settings support. It also lists integrations tuned for Dataview, calendar plugins, Iconize, Ink, Zen Mode and Iconic, and asks explicitly not to confuse it with Colin Eckert's Things theme.
