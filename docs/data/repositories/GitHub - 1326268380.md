# wxjett/obsidian-smart-done-mover

Moves completed checkbox tasks, together with their indented sub-tasks and their indentation, under a Done heading inside the same note. The move runs from the editor context menu or a command, over every finished task or only over the blocks touched by the current selection, and an optional auto mode moves a task the moment it is checked, including completions written back by the Tasks plugin. A text filter can restrict which tasks are eligible, folders and files can be excluded from auto mode while manual commands still work there, and a completion date can be appended to each moved line. The target heading is configurable: a plain name creates a third-level heading, a full Markdown heading keeps its own level, and an existing heading with that title is reused.
