# elias-sundqvist/obsidian-react-components

The repository holds Obsidian React Components, a plugin for writing and using React components with JSX inside notes. Its README describes defining components in a note marked with a defines-react-components property, optionally scoped by a dotted namespace property, set either in frontmatter or through Dataview inline fields. It recommends installing an editor syntax highlighting plugin alongside it, and the code is licensed under the GNU AGPL version 3.
