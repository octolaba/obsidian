# max-fluff/obsidian-code-linker

Code Linker autocompletes references to source code in Obsidian notes and inserts a Markdown link whose URL opens the file at the right line in an editor such as VS Code or Rider, or as a GitHub or GitLab permalink. Typing a configurable trigger, `@@` by default, followed by a class or file name offers matches, and the inserted link keeps a literal `{root}` placeholder and a relative path so the note stays portable, with `{root}` filled from the configured code root when the link is opened. The plugin scans the configured folders through Node's filesystem API and keeps its index in memory, rebuilt on startup and on demand, so no index file has to be committed or generated. Its recorded description also states that live code snippets can be embedded in notes.
