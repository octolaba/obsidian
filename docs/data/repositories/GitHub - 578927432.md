# wakatime/obsidian-wakatime

The WakaTime plugin records activity in Obsidian and reports it to a WakaTime account, where it appears as metrics, insights and time tracking. After installation an API key is entered, and a command in the palette changes that key later. The README points to the project's debugging guide and plugin status page for checking when activity was last received from the editor.
