# livastar/sacred-geometry-obsidian-theme

Sacred Geometry Systems is a dark and light Obsidian theme aimed at complex knowledge maps, Canvas systems and agent ecosystems, turning the language of sacred geometry into an interface grammar of intersections, origins, ecosystems, architecture, progression and feedback loops. The README states the problem it targets, namely large vaults and Canvas maps going visually flat, with flow hard to trace and the centre of a system disappearing, and answers it with clear focus states, readable cards, meaningful edge colors and repeatable map roles. Besides the theme the repository carries a brand book, Canvas starter material, a map-node template and semantic Canvas snippets, and it states that the use of geometry is functional rather than mystical.
