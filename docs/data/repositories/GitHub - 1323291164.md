# T-NhanNguyen/obsidian-vault-ease-of-maintenance

Vault Ease of Maintenance builds a GraphRAG index of an Obsidian vault and runs LLM agents over it from inside Obsidian, with no Python, server or Docker involved. Indexing splits notes into header sections, extracts entities and creates embeddings, storing the result in a database file under a hidden folder in the vault. Three agents work from that index: one proposes cleanup edits to the open note and shows a diff before writing a backup, one triages an inbox folder into placement decisions that need approval, and one answers questions with cited sources. It calls an OpenAI-compatible API whose key comes from the settings tab, a plugin-local config file or an environment variable, and the settings tab wins over other configuration.
