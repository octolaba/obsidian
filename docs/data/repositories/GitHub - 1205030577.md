# ras0q/obsidian-always-on-top

Small Obsidian plugin that toggles whether the application window stays in the foreground above other applications. The behaviour is exposed as a `Toggle always on top` command, to which a hotkey can be assigned in settings. It is desktop only, works through Electron window APIs, and the README notes that behaviour may differ slightly across operating systems.
