# xsiphr/StoneGate-plugin

StoneGate locks an Obsidian vault, or individual folders inside it, behind password authentication. The README records a master password for the vault plus per-path passwords independent of it, an idle timeout that re-locks a path after a period of inactivity, a cooldown that blocks further attempts after repeated failures, a one-time recovery code described as the only way back in after a forgotten password, and a lock-screen background taken from a URL or a file in the vault. Its ghost mode hides a protected folder from the File Explorer entirely while that folder is locked.
