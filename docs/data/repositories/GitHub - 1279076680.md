# jokerwashere/obsidian-lantern

Lantern is described as a privacy-focused Obsidian search and retrieval plugin with search and AI chat panes. The README qualifies that scope: it is desktop-only and a thin front end over infrastructure the user already runs, driving a locally installed qmd search engine for retrieval and a local OpenAI-compatible server for chat, bundling no models and reimplementing no search. Its search pane offers hybrid, text-only and vector-only modes with optional reranking, saved searches, and scope tokens for tags, folders, date ranges and frontmatter key-value pairs; its chat pane runs an agent that searches the notes and answers with citations. The README states the plugin will not work for someone who does not already run local models and a local search daemon.
