# 0skater0/obsidian-custom-note-width

Custom Note Width sets the line width of a note individually, per note or globally, by driving Obsidian's --file-line-width CSS variable, and it requires the Readable line length setting to be enabled. A width can come from a status-bar control — either a slider or a Pills mode with three preset buttons — from a custom-width key in the note's frontmatter, or from commands bound to hotkeys, and widths can be stored in frontmatter, kept locally on the device, or discarded when the note closes. Widths are expressed in percent, pixels or character units, code blocks can carry their own width, and the interface is available in English, German and Russian.
