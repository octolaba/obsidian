# zwpaper/obsidian-progressbar

This plugin renders a progressbar code block into a progress bar, configured with YAML inside the block. The README records time-based kinds — days passed in the current year, month or week, days between a custom start and end date, and months passed in the year — alongside a manual kind whose value the user specifies. A name is shown in front of the bar and defaults to the kind when it is not set, and it accepts templates substituting the maximum, the value and the percentage; the custom date kind requires a minimum and a maximum in year-month-day format.
