# StevenGann/obsidian-circuitjs

Obsidian plugin that embeds CircuitJS circuit simulations in notes. The README describes keeping circuit designs in version control beside the vault, interacting with a running simulation in Reading view, and opening a circuit in the full CircuitJS editor through a one-click link. It records an offline mode added in version 2.0 that runs simulations from a bundled copy of CircuitJS, LZ-string compression for the encoded circuit, and settings for editability and the CircuitJS address.
