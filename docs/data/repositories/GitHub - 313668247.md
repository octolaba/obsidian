# erichalldev/obsidian-smart-random-note

Smart Random Note extends opening random notes with more control than the core plugin offers: opening a random note from the current search results, inserting a link at the cursor to a random note from those results, opening a random note carrying a selected tag, and opening a random note as the core plugin does. Its README records a deliberate scope limit around that core function, pointing at existing flashcard and spaced-repetition plugins rather than implementing that domain itself. Compatibility is stated from Obsidian 0.9.7 upwards, with the plugin targeting API version 0.9.15.
