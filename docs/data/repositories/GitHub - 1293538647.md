# xooooooooox/obsidian-config-sync

Config Sync selectively captures Obsidian settings, core and community plugin configurations, themes, and snippets into a vault-based store, then applies only the items explicitly selected on another device. Field rules support device scopes and encryption, while a Sync Center shows diffs, pending actions, history, and per-device status; desktop remotes can use Git or another vault, and capture and apply also work on mobile.
