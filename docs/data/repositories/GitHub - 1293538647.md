# xooooooooox/obsidian-config-sync

Config Sync performs selective, on-demand synchronization of Obsidian settings — hotkeys, CSS snippets, themes and plugin configurations — across devices and vaults. The data rides an existing note sync such as remotely-save, Obsidian Sync or iCloud by default, or config-sync's own git or vault remotes. Every synced item is one card holding its rules, and each key carries a scope and encryption pair covering all devices, desktop only, mobile only or this device, with this-device keys never leaving the machine and a per-device passphrase encrypting what travels. Nothing changes on a device until items are ticked and Apply is pressed in the Sync Center, where per-item state badges, normalized JSON diffs and a browsable history record every run.
