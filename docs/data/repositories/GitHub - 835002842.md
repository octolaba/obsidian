# Sskki-exe/vanilla-amoled-theme-color

This repository is a fork of the Vanilla AMOLED theme for Obsidian that adds colorful headings. The README repeats the parent theme's stated purpose, a darker yet vanilla-like theme that takes full advantage of AMOLED screens by pitching the background fully black, and records that the heading colors are the same ones used by the Obsidian Nord theme.
