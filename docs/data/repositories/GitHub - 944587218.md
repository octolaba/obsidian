# Stargazer-cc/obsidian-tag-group-manager

Tag Group Manager organizes tags into groups in Obsidian and speeds up inserting them; its README is written in Chinese with an English version linked. It records creating, editing and deleting tag groups, collections of groups that can be switched between and sorted independently, a draggable and pinnable floating tag picker called from the command palette or a hotkey that dims already-used tags, and an overview view in the right sidebar with sorting and insertion modes. It further records insertion into the YAML area, the properties panel, Canvas, the search box and other plugins' inputs, preset and custom tag colours applied per tag, by pattern or per group, automatic expansion of nested tags into groups, vault-wide renaming that updates notes and Canvas references, and an interface following Obsidian's language.
