# darlal/obsidian-switcher-plus

Repository for Quick Switcher++, an Obsidian plugin that extends the built-in Quick Switcher, which must stay enabled because the two share the same configuration. The README lists finding files by heading instead of filename, navigating to symbols such as Canvas nodes, headings, hashtags, links and embeds, moving between open editors and side panels, switching configured workspaces, searching bookmarks, running commands, navigating to related files and opening vaults. Modes are triggered by command characters typed inside the switcher, quick filters narrow the results, and global commands can be bound to hotkeys.
