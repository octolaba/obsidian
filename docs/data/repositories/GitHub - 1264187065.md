# Anti-Warlock/vault-relay

The description records VaultRelay as a local-first publishing workspace that previews long-form Markdown and exports it as shareable image cards without moving the vault. The README adds that it reads the current article, recognises headings, paragraphs, lists, quotes, code blocks, tables and images, produces a preview and a structural check, and generates drafts for X Article, Zhihu, WeChat Official Accounts and Xiaohongshu. With Creator Pro and a separate browser extension it fills those platform editors with title, body and images, but it stops before publication so the user checks the draft and clicks publish. On privacy it states that the whole vault is not uploaded, that platform accounts, passwords, cookies and verification codes are not stored, and that the local relay listens only on 127.0.0.1.
