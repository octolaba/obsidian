# brunoribeiro2k/obsidian-link-tooltip

Obsidian plugin that shows where a hovered link points, in Live Preview and source mode. A tooltip appears for links whose destination is hidden behind a label, meaning Markdown links and aliased wikilinks, while bare links that already display their destination get none. Reading mode is deliberately out of scope because Obsidian shows native tooltips there; in the editor the plugin registers a CodeMirror extension and recovers the destination from the syntax tree rather than from hidden DOM spans. Settings toggle tooltips for external and for internal links separately and enable debug logging while troubleshooting hover detection.
