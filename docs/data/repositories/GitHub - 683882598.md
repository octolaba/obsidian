# Quorafind/Obsidian-Collapse-Node

Collapse Node collapses and expands nodes in Obsidian Canvas. Four commands fold or expand all nodes or only the selected ones, a canvas context menu acts on a selection or on a single node, and clicking a node header toggles it directly. A collapsed node can display a custom alias and thumbnail, set from the context menu or from node metadata — a `thumbnail` path or URL and an `alias` string, with frontmatter aliases used for file nodes — and both customizations can be removed again. The README states that the plugin is not ready for the community store and is installed through BRAT.
