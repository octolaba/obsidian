# delashum/obsidian-checklist-plugin

This plugin consolidates checklist items from across the vault into a single sidebar view, by default collecting the blocks marked with a configurable tag. Items can be completed in the editor or by clicking them in the sidebar, which updates the underlying file. Settings control the tag, whether completed items are shown, whether every task in a tagged file is collected rather than only the tagged block, grouping by file or by tag name, sort order and glob-based file matching. The README opens with its author asking for another maintainer, describing the plugin as neglected because of other commitments.
