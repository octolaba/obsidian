# springrain1/obsidian-editorjs-plugin

Obsidian EditorJS Plugin embeds the Editor.js rich-text editor into Obsidian as an alternative view over a Markdown file, opened from the editor context menu or the command palette. Its README, written in Chinese, counts 34 editing tools — 20 block tools such as headings, lists, tables, code, callouts, math and columns, 11 inline tools, and four block-adjustment tools — and claims lossless two-way conversion between that content and Markdown. It also lists drag-and-drop block reordering, undo and redo, automatic saving back to the Markdown file, and support for Obsidian syntax including callouts, collapsible blocks, formulas, footnotes and internal links.
