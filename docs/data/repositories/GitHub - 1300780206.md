# jqml/frontmatter-timestamps

This repository holds Frontmatter Timestamps, described upstream as keeping created and updated frontmatter timestamps synchronized in Obsidian. The README says a created value is written when a Markdown note is created or found missing one, an updated value is written after content changes under a configurable debounce and minimum interval, and both properties have independent switches, configurable names, ignored paths and date, date-time or plain-text modes. It also documents preview and update commands for a folder or the whole vault, a guarded property-rename workflow, and a cleanup command for legacy malformed values. The README warns that bulk commands can touch many files and asks for a backup first.
