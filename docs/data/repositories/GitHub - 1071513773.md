# ebullient/obsidian-deck-notes

Defines card decks from Markdown notes, where each H2 heading becomes one card, and displays them embedded in a note or in a modal. Cards are organised by hierarchical flashcard tags, can be filtered by tag hierarchy, and are selected either randomly or by least-recent viewing when optional view tracking is enabled. The README describes cycling through the discovered deck tags from within the modal.
