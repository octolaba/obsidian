# monoooki/obsidian-planetz-roller-theme

Planetz Roller is an Obsidian theme with a flat, painted look across the whole interface, built from muted blues with bold accents. The README says the name comes from the Planetz Big Swig Roller, a roller-type weapon in Splatoon 3, and calls the result colourful and soft-toned. Installation places theme.css and manifest.json in a Planetz Roller folder under the vault's themes directory, and the theme is released under the MIT license.
