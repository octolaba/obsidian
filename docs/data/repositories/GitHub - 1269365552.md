# lcjury/obsidian-drivesync

DriveSync synchronises an Obsidian vault with Google Drive in both directions, including the .obsidian folder but excluding vault-technical files such as the workspace and graph settings. The README states that this is not real-time sync: a full reconciliation runs at startup, edits upload after a short debounce, remote changes are polled while auto-sync is on, and a manual sync is available from the command palette, ribbon or status view. Conflicts are resolved by keeping the newest version and saving the older one under a conflicted name, and setup requires the user's own Google Cloud project and OAuth credentials; the README advises backing up the vault first because the initial sync can overwrite local files.
