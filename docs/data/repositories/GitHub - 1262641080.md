# astroyhs/obsidian-center-on-reveal

This repository holds Center on Reveal, an Obsidian plugin that keeps the file explorer focused on the active file. It enables the built-in auto-reveal behaviour at startup, then scrolls the revealed row to the centre and applies Obsidian's native flash highlight to it. The README states that the plugin adds no commands, settings, network calls, telemetry or custom CSS, and that it requires Obsidian 1.7.2 or newer with the file explorer enabled in the left sidebar.
