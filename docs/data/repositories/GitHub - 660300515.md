# thiagocoutinhor/pf2-action-icons

This plugin renders the Pathfinder 2E action icons for the single action, the double and triple action, the free action and the reaction. A code block whose type names the wanted action is replaced by the icon in reading view and live preview, and the same code works inside Fantasy Statblocks properties configured to be rendered as Markdown. The README credits the Dice Roller plugin and the action-icon documentation of the Obsidian TTRPG Community as its inspiration.
