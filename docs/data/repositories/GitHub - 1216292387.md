# Evgene-Kopylov/fsrs_plugin

Implements the Free Spaced Repetition Scheduler algorithm for flashcards kept in ordinary notes. Review history lives in the note's frontmatter under a reviews field, each entry recording an ISO 8601 date and a rating from again to easy, and the next review date is computed from that history. An fsrs-table code block queries cards with a small SQL-like syntax supporting comparison and regular-expression operators, AND and OR, a date formatting function and a preserved column order, while a review-button block places a review control inside a note. The README states the scheduler is the Rust implementation maintained by the algorithm's authors, that target retention and maximum interval are configurable, and that the seventeen weight parameters cannot yet be retrained on a user's own answers.
