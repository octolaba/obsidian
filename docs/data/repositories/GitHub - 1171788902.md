# takezoh/obsidian-air-sync

Obsidian plugin that synchronises a vault through the user's own cloud storage, supporting Google Drive, OneDrive and Dropbox on desktop and mobile. Sync runs without a button, resumes after an interruption, transfers only what changed, and merges edits made on two devices where it can rather than writing conflicted copies, and large attachments or a private folder can be excluded. The README warns that the local vault must not sit inside a folder another cloud drive already syncs, that the mirror folder Air Sync creates in cloud storage must not be opened as a vault, and that no second sync tool should manage the same files.
