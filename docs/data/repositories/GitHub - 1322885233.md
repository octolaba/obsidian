# Din-es/obsidian-decision-ledger

Renders the code that a recorded design decision governs inside the note explaining it, fetched from a git repository at read time and labelled tracked, drifted with a similarity percentage, or code gone. A decision is identified by an id given in a ledger block or in a frontmatter key, and a sidebar lists every decision in the repository, worst first. Three commands open that sidebar, re-resolve every decision against the current code, and list the ones no longer tracked. It works by shelling out to a separate Go binary, so it is desktop only and needs that binary's path and the repository path set in its settings.
