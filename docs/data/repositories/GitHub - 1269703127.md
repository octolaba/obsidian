# nsyout/obsidian-concordance

Concordance generates Markdown indexes from filename prefixes, folders, tags, or frontmatter properties. It rewrites only the region between its managed markers, preserving surrounding prose, and offers diff-before-write modals plus a read-only check command. Each index can configure link style, sorting, recursion, and exclusions.
