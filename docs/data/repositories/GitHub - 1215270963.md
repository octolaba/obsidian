# JoanGen/Obsidian-Material-3-Expressive

JoanGen/Obsidian-Material-3-Expressive holds Material 3 Expressive, an Obsidian theme based on the Material You and Android 16 guidelines, with rounded shapes, expressive typography and grouped lists. It generates tonal palettes for surfaces, containers and accents from a single base hue, and its dark mode adapts to the chosen accent colour. The README states that work to bring the desktop version up to the same finish as the mobile one is still in progress, and lists native design support for community plugins such as Notebook Navigator.
