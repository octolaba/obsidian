# dario-baumberger/obsidian-json-table

The recorded description says the plugin switches between JSON and tables in Obsidian notes. Per the README its commands generate a table from a JSON string held in a note or from a URL that returns JSON, and generate JSON back from a table in a note. Installation is from the community plugin directory or manually from a release.
