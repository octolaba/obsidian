# benjohnson/obsidian-monthly-notes

Monthly Notes is an Obsidian plugin that creates or opens the current month's note from a ribbon calendar icon or an Open monthly note command, creating the containing folder when needed. It sets out to replicate the core Daily Notes plugin for months without adding further features, which the README frames as a deliberate choice against more complex alternatives. Settings cover the date format as a preset or a custom moment.js format, the folder for new notes and a template file, and templates support title, date and time placeholders with optional format arguments.
