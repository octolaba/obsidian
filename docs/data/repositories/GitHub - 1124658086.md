# cybaea/obsidian-vault-intelligence

Vault Intelligence is an AI plugin for Obsidian that its README positions as a maintenance system rather than a question-and-answer search layer over static notes. It describes agents that identify gaps by cross-referencing writing with live web searches, retrieval that follows the explicit structural links a user has built rather than text matches alone, and tag auditing that connects notes to existing topics and proposes new ones. The README also states that it can connect to external tools such as local scripts or databases under cryptographic controls, and that it can use API models or run fully local and offline.
