# tanoshia/obsidian-today-alias

Changes how filenames that begin with a date are displayed in the file explorer and in editor tab titles, without renaming or modifying any file. The leading date prefix is stripped from ordinary notes, while a note dated today or yesterday is shown with its own configurable label, refreshed when the day rolls over through a focus listener, a periodic check and a midnight timer. Prefixes and labels are described with Moment.js format strings rather than regular expressions, ignore patterns keep chosen filenames untouched, and each field previews its result live. Sorting still follows the real filename, MutationObservers keep the display current across renames and popout windows, and unloading the plugin restores the original text.
