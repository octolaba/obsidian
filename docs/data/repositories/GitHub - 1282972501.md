# CocaPls/obsidian-trellis

Trellis treats a hierarchical location tag in a note's frontmatter as the source of truth and mirrors it into the note's filename prefix, so retagging a note renames it through Obsidian's link-safe rename and wikilinks update by themselves. A filename is read as a tagkey built from the tag, a configurable separator and the title, of which only the tagkey is controlled by the plugin; editing the tagkey by hand is reverted from the tag on the next sync, and a note carrying a second location tag is flagged. Renaming a tag cascades through its whole subtree, and a sidebar shows a collapsible tree built from location tags rather than folders. A bootstrap mode onboards a vault that already has filename prefixes but no tags, with a scope selector, dry run, live progress and one-step undo, splitting a prefix at letter and digit boundaries.
