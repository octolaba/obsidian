# Quorafind/Obsidian-Thino

The repository holds Thino, a quick capture plugin whose data lives in the reader's own notes. Its README states plainly that from version 2.0.0 the project is closed source, distributed under a proprietary license, and that this repository ships only the compiled plugin for the community directory. Capture and list features are recorded as free, while synchronisation with the vendor's web service, canvas, table and moments views, a local HTTP API and AI features require a paid license. The README also records which network endpoints are contacted: license verification, the optional web sync when enabled, and whichever AI provider the reader configures.
