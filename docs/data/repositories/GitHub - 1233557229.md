# bryanmanio/obsidian-lexophile

Obsidian plugin that builds a personal dictionary from words encountered while reading. A saved word is looked up, written as a note in a dictionary folder with its definition, an example sentence and a link back to where it was found, and added to an auto-generated table view of the whole lexicon, with a familiarity score of common, familiar or obscure. Words are added from the command palette one at a time or pasted as a list, imported from a Kobo eReader linked back to the book they came from, or saved from the web through the author's companion Chrome extension. Lookups use a free dictionary API by default or a downloaded local SQLite file in offline mode, and note templates are configurable per entity type.
