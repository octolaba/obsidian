# jethrojones/file-viewer

The repository holds File Viewer, an Obsidian plugin that opens data, transcript and text files in purpose-built views instead of raw text. CSV files are parsed with quoted and escaped fields and mixed line endings and shown as sortable, searchable tables with inline cell editing that saves on blur; JSON files get a monospace editor with live validation, formatting and minifying; log files get line numbers, level colouring and filters; and VTT or SRT files are read as timestamped cue lists. The README describes the CSV parser as RFC-compliant and the column sorting as detecting numeric values.
