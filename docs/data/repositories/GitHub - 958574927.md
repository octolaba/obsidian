# kotaindah55/animated-cursor

Animated Cursor gives the Obsidian cursor a move and blink animation, which the README compares to the smooth cursor in Microsoft Office and VSCode. It works in hovering page previews and on canvas, supports multiple cursors, and exposes cursor speed and blink duration through the Style Settings plugin. The README states that the plugin patches Obsidian's existing cursor instead of creating a second cursor instance and leans on the CodeMirror API, which it credits for consistent behaviour, and it asks readers to check its caveat section before installing.
