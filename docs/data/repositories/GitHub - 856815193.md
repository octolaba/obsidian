# yingjialong/obsidian-CloudStorage

Cloud Storage uploads Obsidian attachments to cloud storage and rewrites the links in the notes to point at the uploaded copies, with the stated aim of freeing local storage and making attachments reachable from other devices. Storage is either provided by the plugin — the only mode for which the README claims resumable uploads — or a user's own S3-compatible service. Which files are uploaded is controlled by an extension whitelist or blacklist and a maximum file size, files can be renamed in the cloud to keep names unique, and local files can be moved or deleted after a successful upload, with an interface for managing the stored files and the remaining space.
