# reit5667/obsidian-flowtaker-inbox

Flowtaker Inbox delivers Telegram messages into an Obsidian vault: the plugin polls the Telegram API every 30 seconds by default and writes each message as a Markdown file named after its timestamp, with YAML frontmatter carrying created, source, type and tags. A hash tag in the message becomes a tags entry and is stripped from the body, a forwarded message records its origin in a frontmatter field, and voice messages are transcribed through Groq Whisper. Messages tagged as todo prompt the bot with inline buttons that route the task to a sprint or backlog file, where it is appended as an unchecked task, and a status command replies with the last saved filename. Setup requires a personal bot token from BotFather and the user's own Telegram id, since the plugin polls directly from the machine running Obsidian.
