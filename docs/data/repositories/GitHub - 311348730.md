# lukeleppan/better-word-count

Better Word Count behaves like Obsidian's built-in Word Count plugin except that it counts the selected text when a selection exists rather than the whole document, and the README recommends disabling the built-in plugin it is meant to replace. It can also store statistics about the vault and display them in a configurable status bar: words, characters, sentences, footnotes and Pandoc citations for the current file, their totals across the vault together with a file count, and the same measures typed today. The README states it works with all languages and credits several contributors for the footnote, citation, page and section counts.
