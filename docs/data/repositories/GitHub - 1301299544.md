# jcig789/ledgr

The repository records no description; its README presents Ledgr, a multi-currency personal finance tracker that runs inside an Obsidian vault, and states that it uses no accounts, cloud or subscriptions. It captures transactions through a modal or the command palette and reports them in a dashboard of monthly cash flow, savings rate, category charts, trends and budget bars, with per-category budgets, a net worth tracker across accounts and liabilities, loan and credit-card tracking with payment logging, and debt cost analysis covering interest, payoff months and avalanche or snowball ordering. It also generates CPA-style income statement, cash flow and balance sheet views, cash flow forecasts with what-if scenarios, savings goals, a daily allowance countdown, recurring templates, a scored financial health index built from six behavioural pillars, and monthly and annual review notes.
