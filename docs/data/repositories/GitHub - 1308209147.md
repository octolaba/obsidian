# Trisko06/auto-tag-graph-colors

Obsidian plugin that builds colour groups for the graph view from the vault's tags instead of requiring each group to be configured by hand. It scans every tag, assigns a stable distinct colour from a chosen palette, and updates the graph as notes and tags change. The README describes three modes: one colour per tag, a heat mode shading nodes from few to many links through a blue to purple to red gradient with percentile ranking, and a monochrome mode deriving shades from one base hue. The repository description records it as a side project by Meetzy Corp FZCO.
