# vkalahas/fast-callout

Fast Callout expands a short trigger into Obsidian callout syntax and places the cursor where the title goes, so a callout can be written without typing the full block. Triggers are nicknames such as a prefixed abbreviation of the callout type, and the prefix character is configurable, for example a semicolon, an at sign or an exclamation mark. Custom callouts and nicknames can be added in the settings, and the expansions are also available as commands that can be bound to hotkeys.
