# jsmorabito/obsidian-note-types

Defines named note types in the vault, each with a template, a save folder and its own frontmatter fields. Every type registers a creation command that fills a modal from those fields and inserts a link to the new note, plus a fuzzy finder scoped by the type's frontmatter filters; selected text can also be turned into a typed note in one step. A configurable trigger character opens a quick picker in the editor, links to typed notes can carry a CSS class and a hover card showing chosen frontmatter values, and further palette commands open pickers filtered by frontmatter with equals, contains and exists operators. A sidebar widget lists files in collapsible, reorderable sections filtered by tag, frontmatter, path or filename.
