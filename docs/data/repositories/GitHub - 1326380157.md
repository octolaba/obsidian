# hellokunzai/obsidian-gitee-sync-plus

Syncs a vault to a private Gitee or GitHub repository by calling the platform's API directly, with no server and no local Git installation, on desktop, iOS and Android. The engine compares Git blob hashes across the local vault, the remote repository and a per-device baseline, so sync is incremental and two-way, deletions propagate in both directions, and the newer modification wins a conflict; a preview shows the plan before anything changes. Configuration covers the backend, owner, repository, branch, token, an automatic interval, sync on startup, excluded paths written as gitignore rules, and an optional diagnostic log. Hidden paths such as the Obsidian configuration folder are skipped, every upload or deletion becomes a commit, and sync aborts if the platform returns a truncated file tree.
