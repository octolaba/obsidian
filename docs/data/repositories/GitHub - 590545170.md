# inouetakuya/obsidian-kill-and-yank

Kill and Yank adds Emacs-style kill and yank operations to the Obsidian editor. It can cut from the cursor to the line end, cut a selection, paste from a kill ring, and toggle a mark for selecting text through configurable commands.
