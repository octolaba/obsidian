# jglev/obsidian-apply-patterns-plugin

Apply Patterns applies collections of regular-expression find-and-replace rules to a selection or to whole lines of a note, chosen from a searchable menu. Each pattern groups one or more rules, and patterns can be exported to and imported from the clipboard in the settings tab. The README records support for search and replace patterns built on natural-language dates including date ranges, and illustrates the idea with one pattern that marks open tasks complete and another that reschedules closed ones.
