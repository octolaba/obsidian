# joshuakto/fit

Synchronises a vault across desktop and mobile devices through a GitHub repository, in one click or automatically. Setup is guided from the plugin settings and requires a personal access token whose only needed permission the README gives as contents read and write on the repository; existing vaults and existing repositories are supported. Conflicting changes coming from the remote are stored in a local folder so they can be resolved after the sync. The README states that the plugin is still in beta and asks users to back up the vault before using it.
