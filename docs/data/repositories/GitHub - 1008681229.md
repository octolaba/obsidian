# BiigFish/new-paragraph-on-enter

This repository holds an Obsidian plugin that creates a new paragraph from a single press of the Enter key, inserting two newlines instead of one. Shift and Enter still insert a single line break, and the README states that lists, tasks, tables and code blocks are left unaffected because the plugin checks for those contexts first. The author records writing it after refusing to give up the habit of hitting Enter once to start a new paragraph.
