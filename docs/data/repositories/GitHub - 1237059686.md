# jheddings/obsidian-ballistics

An Obsidian plugin that embeds ballistic trajectory tables and charts in notes through two code-fence processors, ballistics-table and ballistics-chart, which take the same inputs and render them differently. Inputs describing the load, rifle and conditions — ballistic coefficient, muzzle velocity, sight height, zero range and further optional keys — may sit inline in the fence, in the note's frontmatter, or in a shared note referenced with use:. The table lists range, drop, velocity and energy per step, adds a windage column when a wind speed is given, and marks rows crossing configured energy thresholds; the chart plots elevation against range as an inline SVG scaled to the note width with those thresholds drawn as markers.
