# rustam-aka-rust/obsidian-brutalgarden

BrutalGarden is a neo-brutalist Obsidian theme ported from the author's digital garden, with black three-pixel borders, hard unblurred shadows and a dot grid on the chrome. Light mode is a paper ground with black-cut shadows, dark mode is a warm charcoal called Soft Night whose shadows are tinted lime, and lime, blue and orange accents carry links and attention. Its main addition is a set of fifteen custom callouts, including epigraph, poem, definition, example, dialogue, collage, postscriptum, prompt, gap and annotation, alongside the standard Obsidian types in the same frame; two of them are static because the original relied on JavaScript that a CSS theme cannot supply. The theme asks for the iA Writer families, which are not bundled, and falls back to the system monospace when they are absent.
