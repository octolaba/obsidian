# gooderno1/CipherLink

Creates encrypted Markdown notes in Obsidian while keeping user-selected metadata and relationships visible to native search, tags, backlinks and Graph view. The README describes each secure note as two parts: a public Markdown envelope holding only the metadata the user chooses to expose, and an encrypted body stored as an age object under a hidden folder; Obsidian opens the envelope while the plugin replaces the encrypted-content callout with an in-memory editor, so decrypted text is never written into the outer document. Two modes are documented, a standalone mode keeping encrypted objects in the vault and an optional gateway mode where a server holds the authoritative encrypted versions with conflict control and audit.
