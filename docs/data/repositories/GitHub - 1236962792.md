# lucidalpha/digital-garden-obsidian

Digital Garden Timer is a focus timer that earns ten credits for every completed ten-minute focus block, and the credits are spent on objects for a small digital garden. The current timer can be started, paused and reset while an all-time focus total is kept separately and is not reset with it. The plugin writes a Markdown progress note at a configurable path, recording the current timer, the all-time focus duration, credit totals and the placed garden objects.
