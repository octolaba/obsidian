# xym-py/progress-dashboard

Progress Dashboard shows learning skills as progress bars in an Obsidian view and links notes to them by scanning YAML frontmatter for skill and skill-progress fields. Skills are grouped into user-defined categories that can be pinned to the top, support a parent-child structure written with a slash, and carry optional start and end dates. Progress comes from a manual drag of the bar, which takes precedence, otherwise from a note's skill-progress value, otherwise zero, and each skill lists its associated notes on the right for jumping to them. An association can be removed from the note label on a skill, a reset action clears all data, and the scan covers every vault open in Obsidian.
