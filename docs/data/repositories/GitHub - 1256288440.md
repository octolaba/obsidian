# cavi-ai/companion-for-claude

Obsidian plugin for chatting with Claude inside a vault, with notes as context, interactive HTML artifacts, an agent mode whose writes are reviewable, and a local MCP bridge so Claude Code can work on the same notes. The README states that it talks to the Anthropic Messages API with the user's own credential and offers three authentication modes: an API key, a long-term OAuth token that draws on a subscription, or importing a key from the environment. It states that chat, artifacts and semantic search work on mobile while the MCP bridge and session import are desktop-only.
