# lbb2446/bestmemo

Memo Timeline Feed, whose README is written in Chinese, adds a browsing view for memos, diary notes and images in Obsidian rather than replacing the built-in note list. It offers three modes: a timeline that collects notes carrying a configured tag and lists them newest first with title, time, path, summary, tags and image previews; a diary feed identifying diary notes by tag, folder or filename pattern and showing them as cards; and a photos mode extracting every embedded image into one wall. Settings define the timeline tag, the diary tag, the diary folder, the daily-note filename pattern and the maximum number of cards rendered.
