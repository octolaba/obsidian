# KHR0907/obsidian-mouse-handwriting

This repository holds Mouse Handwriting, an Obsidian plugin for practising handwriting with the mouse by tracing letters, words and famous passages in Korean, English and Japanese. Practice happens on dedicated full-page sheets with their own file extension, opened like an Excalidraw file rather than as a code block, with problem sets grouped by language covering Korean jamo, the alphabet, numbers, hiragana and katakana, word drills, and short or long passages traced one line at a time or all at once. Guides can be the target text as outline or fill, evenly spaced ruled lines, or nothing at all, and finishing a sheet shows a guide-free image of exactly what was written.
