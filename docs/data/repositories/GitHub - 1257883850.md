# jonas-karneboge/wiktionary-sidebar

Looks up a selected word in Wiktionary and shows the result in an Obsidian sidebar. The lookup is started from the right-click menu in either editor or reading view, and the sidebar shows structured entries with part of speech, definitions, etymology and synonyms, together with a direct link to the source page for each language. Seven languages are supported, German, English, French, Italian, Swedish, Dutch and Spanish, each toggled separately in the settings. The README states that the plugin follows Obsidian's light and dark themes through CSS variables and is desktop only.
