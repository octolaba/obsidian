# DeabLabs/cannoli

Builds and runs no-code scripts driven by language models inside the Obsidian Canvas editor. The README describes a cannoli as a canvas whose cards and arrows define variables and logic, with colours or prefixes giving nodes and arrows their types so that variables, fields, loops and branching choices can be expressed; a canvas that is a directed acyclic graph and follows the cannoli schema can be run. Scripts read and write vault content and can take actions over HTTP, and are started from the ribbon button, from a command, from a note carrying a cannoli property, or by a filename ending in the plugin's own extension. The README also mentions chatbots with custom logic, streaming output, and audio recordings transcribed with Whisper on a note that names a cannoli.
