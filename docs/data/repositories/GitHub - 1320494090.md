# PleiadesM/Tufte-Sidenotes

Tufte Figures inserts Tufte-style figures when an image is dropped or pasted into a note: column figures with margin captions, full-width figures and margin figures, with size adjustment, multi-image rows, an image-quilt generator that arranges tiles into one transparent PNG, click-to-enlarge, an edit-at-cursor command and auto-numbered clickable references. Figures render in Reading view, and the margin gutter the captions sit in is supplied by the Tufte theme the plugin belongs to. The repository is named Tufte-Sidenotes after a registration mix-up, and it exists only to distribute the plugin through the community directory, with development, documentation and issues kept in the suite's main repository.
