# DuckTapeKiller/obsidian-bulk-tag-manager

A vault-wide tag and frontmatter utility built around two surfaces: a ribbon modal for single-tag actions such as rename, delete, search and tag-page creation, and a settings dashboard holding the bulk operations and statistics. The dashboard reports counts for case and separator consistency, nested versus flat tags, tags in frontmatter versus the note body, overlong tags, empty tag fields and tags that differ only by case, and each figure opens the tags or files behind it. From there tags can be renamed, merged or deleted across every file, casing and separators standardised, YAML list and inline array formats converted, and malformed YAML tag syntax reviewed and fixed. Every operation is recorded in a history that can be undone.
