# NaleVex/obsidian_property_dashboard

Property Board builds Kanban and table boards from the frontmatter properties of notes. Each board is a JSON file with a board extension stored in the vault, holding its trigger property, its scope and its named views; notes carrying that property appear as cards or rows grouped by the property's values, notes without it are excluded, and empty or unrecognized values collect in an Unknown column. Dragging a Kanban card to another column writes the new value back into the note's frontmatter. Scope can be the whole vault, the board file's sibling notes or one folder, and cards and columns can show properties, file metadata or slices of the note body.
