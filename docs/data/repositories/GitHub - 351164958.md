# javalent/prominent-files

The repository holds a plugin that makes bookmarked files stand out in the Obsidian file explorer, and whose README records that it was formerly named Prominent Starred Files. It requires the core Files and Bookmarks plugins to be enabled, and its appearance can be changed by the reader's own styling. The README states that documentation has moved to an external site and that the plugin is in maintenance mode, where pull requests and bugs are reviewed while feature requests are not worked on.
