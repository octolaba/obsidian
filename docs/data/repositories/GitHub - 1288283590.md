# Brightwav3/advanced-bases

Advanced Bases adds three views to Obsidian Bases: Cards Compact, Feed and Timeline. Cards Compact extends the native Cards view with a compact row showing an optional cover, a file-type icon, the title and property values as inline pills, alongside a normal mode with labeled property rows. Feed scrolls full note previews that render lazily and unmount when scrolled out, truncating long notes behind a Show more expander, while Timeline plots date-bearing notes as bars or single markers on lanes grouped by a chosen property.
