# Zangeti/obsidian-smart-autocorrect

Smart Autocorrect adds phone-style autocorrect, next-word and phrase prediction and contextual suggestions to the editor, with a predicted continuation accepted by the Tab key. It also offers right-click alternatives for a word, capitalisation of sentence starts, names and abbreviations, an undo that both restores the text and stops the plugin correcting that word again, experimental underlining of text matching an existing note for hover preview and linking, and statistics on keystrokes and typing time saved. The README records the language model as running on-device with no telemetry and no account, the only network request being a one-time model download of 86 MB that can be declined, and anything learned being stored in a file inside the plugin folder.
