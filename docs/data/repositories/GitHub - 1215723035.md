# y15865708228-pixel/yang

Pensea organizes ideas, spaced review and journaling in Obsidian around a sidebar dashboard, so a session opens with what is due rather than a blank page. Its Chinese README describes idea cards with a life cycle from waiting to incubating to ready, review scheduled by the SM-2 algorithm, an inbox that a language model classifies and summarizes into a knowledge base, questions answered over that base with detection of contradictions, orphan pages and outdated information, calendar-managed diaries with weekly summaries and monthly archiving, and filenames generated from note content. It states that the dashboard, calendar, review, weekly report and archive all work offline and that the language-model features are an optional addition, and it documents a command that initializes a fixed vault folder structure.
