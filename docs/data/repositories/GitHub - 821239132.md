# chfourie/obsidian-journal-folder

Journal Folder turns any supported vault folder into an independent journal based on dated note names. It renders navigable headers, calendars, sidebars, templates, task views, signifiers, and optional quarterly notes, while allowing separate settings and note sequences for multiple journal folders.
