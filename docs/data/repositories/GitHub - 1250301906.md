# BanyanSo/knomo

Knomo is a memo-first capture layer for Obsidian that writes short fragments into the Daily Note of the day and collects them into monthly Markdown files for browsing and review. The README states that memos remain regular Markdown inside the vault, readable and editable outside the plugin, and that Knomo does not replace Obsidian's files, folders, tags, links, backlinks or Daily Notes but sits on top of them. Captured memos are revisited through cards, filters, search, references, images, tasks and statistics. The plugin describes itself as local-first and non-destructive, with input designed to work on mobile.
