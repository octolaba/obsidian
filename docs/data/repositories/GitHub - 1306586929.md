# jiang198012/ogenda

Ogenda adds a bilingual calendar and agenda panel to Obsidian, storing events in monthly Markdown notes while synchronizing with CalDAV, iCloud, or ICS. It offers list, day, week, month, and statistics views, event metadata and recurrence, fixed 24-hour time entry, responsive desktop and mobile layouts, and controls for storage, credentials, time zone, language, and startup synchronization.
