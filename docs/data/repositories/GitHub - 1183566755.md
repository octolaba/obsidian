# KevMorelli/obsidian-game-backlog

Tracks completed games inside a game-backlog block inserted by command, with an interactive interface for adding entries and a stated focus on yearly completions. Entries support a one-to-five rating, per-platform styling, local or remote covers with an option to download them into the vault, platinum marks, DLC campaigns and SteamGridDB, in either a grid or a table layout. A separate profile block holds an avatar, player name and optional RetroAchievements account and scans the game-backlog blocks across files for statistics; the README notes this card is refreshed manually. Platform images and the platinum badge are downloaded from the settings screen rather than bundled with the plugin.
