# OMEG-Lu/obsidian-bionic-reading

This Obsidian plugin applies a bionic reading effect in Reading View, bolding the first portion of each word to create artificial fixation points. The README states that source and editor mode are untouched, that only Latin-alphabet text is processed, and that code blocks, inline code, math blocks and SVG elements are skipped. Two settings are documented: a toggle for the effect and a fixation-strength slider from 1 to 5 controlling how many letters per word are bolded. Markdown files themselves are not modified.
