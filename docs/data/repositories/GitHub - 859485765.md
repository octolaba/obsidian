# xero/evangelion.obsidian

This repository holds an interface theme and colour scheme for Obsidian inspired by Neon Genesis Evangelion. Its README records explicit restyling for a named list of plugins including Shiki, Iconize, Commander, Beautitab, Git, Omnisearch, Dataview, Trash Explorer and Reading View Enhancer. It also records a snippets library kept on a separate branch, covering tablet sizing fixes, Japanese stylings, icon sizings, element hiding, Amiga fonts and tweaks for ASCII art, which the author removed from the main theme as personal choices.
