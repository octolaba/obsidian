# GOODJINC/obsidian-calendar-of-notes

Calendar of Notes browses existing notes by date from a sidebar calendar with month, week and year views. Dates are taken from filenames, from frontmatter properties, or from both with a configurable order of preference, using four built-in filename formats with position choices or a custom pattern, and multiple date properties are allowed. Selecting a day opens its note directly or lists the matches below the calendar, in a popup or not at all, with up to three activity dots marking days that have notes; folder and tag filters, sort order, week start and where a note opens are configurable. Indexing is incremental and in memory, the interface is available in English and Korean, and the plugin only reads metadata and opens notes rather than creating, renaming or deleting them.
