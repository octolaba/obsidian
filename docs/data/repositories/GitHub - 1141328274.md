# penyt/vim-mode-status

Vim Mode Status is an Obsidian plugin that displays the current Vim mode in the status bar with colours. The README lists Normal, Insert, Visual, Replace and Command modes, each with a configurable background colour and a documented default, and a display format setting that switches between the full mode name and a single-letter abbreviation to save status bar space.
