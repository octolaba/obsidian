# CH-YYK/obsidian-rednote

RedNote for Obsidian converts a shared RedNote or Xiaohongshu link into a formatted note in the vault: a modal takes the pasted share text or URL, fetches and parses the content, and a preview step lets the title, fields, template layout and category be adjusted and local media download toggled before the note is saved and opened. It accepts links from the xiaohongshu.com and rednote.com domains as well as the xhslink.com mobile short links, and can download images into a dedicated media subfolder so they are embedded locally. The README also records a URI protocol handler that triggers an import from outside Obsidian, which it suggests using from iOS Shortcuts or Tasker on Android.
