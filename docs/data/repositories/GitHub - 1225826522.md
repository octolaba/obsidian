# prisant-labs/obsidian-tag-visibility

Tag Visibility controls where tags appear across an Obsidian vault, hiding noisy ones, flagging others and surfacing the rest in the places tags actually show up. Its recorded description and README state that the effect is display-only and vault-wide: no note file is modified and the change is fully reversible. The README's badges record Apache 2.0 licensing and an Obsidian version floor of 1.9.10.
