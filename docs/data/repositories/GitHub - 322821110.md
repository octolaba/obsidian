# cristianvasquez/obsidian-snippets-plugin

Run Snippets executes code snippets, such as Python or JavaScript, from inside a note. In preview mode a run button appears beside a recognised snippet; in edit mode the cursor is placed on a snippet and a hotkey or command runs it, appending the output after the snippet. Each language has a configuration entry giving its command template, whether a modal is shown, whether output is appended and whether the run button appears in preview, and placeholders for the vault path, the folder, the file name and the file path are substituted into the command. The README records the plugin as experimental, tested only on Linux and intended for simple uses such as starting a service, and points at a more actively maintained alternative.
