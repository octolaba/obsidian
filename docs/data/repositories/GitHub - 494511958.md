# lijyze/obsidian-advanced-codeblock

Obsidian plugin that adds line numbers and line highlighting to code blocks. Neither applies universally: each is requested per block through parameters written after the language and separated by spaces, one showing numbers and one taking a braced list of lines and ranges to highlight. The README notes that changing only the parameters does not refresh the preview, because Obsidian ignores everything after the first space when deciding whether a section changed, and records that version 1.1.0 made the features available in live preview.
