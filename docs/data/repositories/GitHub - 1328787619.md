# gibsonchan-5/fleurpilot

FleurPilot adds an AI writing assistant to Obsidian, with a side panel that streams replies and can take the current note, a folder or the whole vault as context, and a toggle between quick chat and a deeper reasoning mode. Selected text can be polished, shortened, expanded, translated or proofread in place, with the change shown as a diff before it is applied, and one-click actions run the same operations over a whole note, detecting the direction between Chinese and English. A writing assistant covers full-note review, structure and tone analysis and summary generation, reachable from commands or the editor's right-click menu. Model providers are pre-filled for DeepSeek, Qwen, GLM and SiliconFlow, any other OpenAI-compatible endpoint can be entered, and the interface is offered in Simplified Chinese, Traditional Chinese, English and Japanese.
