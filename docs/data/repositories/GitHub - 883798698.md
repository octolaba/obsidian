# chaintng/quick-share-note-to-gist

This plugin publishes an Obsidian note to an external provider, copies the published URL to the clipboard and writes it back into the note's frontmatter. The README records two providers, HackMD, which it recommends, and GitHub gist, chosen in the settings together with the token each one needs, an Imgur client ID for image uploads when publishing to a gist, and toggles for including the frontmatter and for adding the filename as a first heading. One command publishes the open note to the selected provider; the README states that HackMD uploads images itself rather than through Imgur and allows images up to 1 MB, and that new HackMD notes are readable by everyone with the link while editing stays owner-only.
