# supatipanno5611/atoz

A collection of writing commands and settings, with Korean interface text when Obsidian is set to Korean. The editing commands copy or cut a whole document or the current line, delete a paragraph and focus the main editor; other commands move a selection into a source-linked Later note, move content into a new note, move the current file, and tidy open tabs. Frontmatter properties such as topics and date can be edited and cleaned up, and typing a trigger character opens suggestions for reusable snippets or symbols, with matching symbol pairs deleted together. Settings cover cursor centering, a reading-speed and target-length estimate, the snippet and symbol lists and their triggers, and the path of a work note, and the plugin runs on desktop and mobile from Obsidian 1.13.0.
