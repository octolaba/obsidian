# fnya/media-sync

Media Sync downloads the media files, such as images and PDFs, that Obsidian documents reference by URL, stores them in the vault and rewrites the Markdown links to the local copies. Files are downloaded into a dedicated resources directory whose path can be changed in the configuration. Running it from the sidebar icon processes documents in bulk and caches which notes have been handled so an already-downloaded file is skipped next time, while running it from a file's right-click menu targets that note alone and always downloads. The README warns to make backups before processing large numbers of files.
