# WesternGua/obsidian-zotero-citations

This repository holds Zotero Citations, a desktop-only Obsidian plugin for managing Zotero citations. Citations are inserted through Zotero's native picker or an in-plugin search modal with page and paragraph locators, and rendered as footnotes, endnotes or in-text author-year text, with footnote markers shown as superscript numbers that preview the full citation and allow inline locator editing on hover. The CSL styles installed in Zotero are read dynamically, a reference list is generated from the citations in the document, and Pandoc converts the note to .docx while preserving note structure. It reaches Zotero and Better BibTeX only over the local loopback address, and the README records that it has been developed and tested primarily on macOS.
