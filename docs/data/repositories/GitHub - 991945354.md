# yuhanbo758/obsidian-yuhanbo-search

Yuhanbo Search adds a weighted search over the vault in which file names, folders, tags, headings, body content and quotes each carry their own configurable weight, alongside a configurable search scope and excluded folders. Results are opened from a command or a ribbon icon once at least two characters are entered, with keyboard navigation through suggestions and results. An optional completion mode inserts a match directly as text, as a link to a matching heading, or as a block link, each triggered by its own prefix. It works on desktop and mobile, builds its index locally from Markdown files and Obsidian metadata, sends nothing over the network and does not modify vault files while searching or indexing.
