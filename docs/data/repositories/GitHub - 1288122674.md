# waldemar-one/obsidian-empty-tab

Obsidian plugin that adds one command to the command palette, replacing the current tab with the empty new-tab screen. The tab itself stays open and nothing is closed or removed from history. The README states that it calls getLeaf and setViewState to switch the active leaf to the built-in empty view, and that it reads, writes and deletes no file and makes no network request.
