# 0melette/copy-local-graph-paths

Copy Local Paths copies the file paths of the notes linked from the current note, formatted for use outside Obsidian. A configurable base path can be prepended, named folders can be excluded from the result, and the paths are emitted either newline-separated or semicolon-separated. The README's worked example feeds the semicolon-separated list into a command-line assistant as the document set for a retrieval-augmented chat.
