# viggomeesters/obsidian-log-viewer

Log Viewer is a read-only viewer for .log files in Obsidian, aimed at agent and model output, build logs and other local automation output. It opens such a file in a dedicated view that shows a structured table by default, detecting common timestamp formats including ISO 8601 and epoch values and severity labels from fatal down to trace, and filters lines by text, severity and timestamp presence; a raw source view with line numbers is kept alongside, and unstructured lines and stack traces fall back to raw rendering. Line, timestamp, structured-line and severity counts are displayed, and a 10,000-line render cap limits the rendered tree with the remainder reported as a warning. The README states that the plugin makes no network requests, does not use the system clipboard, and deliberately never writes back, because logs are evidence.
