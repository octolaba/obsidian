# ryanjamurphy/DEVONlink-obsidian

DEVONlink integrates Obsidian with DEVONthink: its commands open or reveal the active note in DEVONthink, or insert related files found through DEVONthink's AI features. Commands are invoked from a ribbon button, the command palette or assigned hotkeys, and require the notes to be indexed in a DEVONthink database that is open. The plugin matches on the active note's name and takes the first file of that name across the open databases, so duplicates or replicants can produce an unwanted result; the README also points to a companion AppleScript.
