# ohida/medianoche-sync

Medianoche Sync adds article triage actions to the Markdown files that the Medianoche desktop reader exports into an Obsidian vault, so an article can be starred, archived or marked for deletion without leaving the vault. It recognises an exported file by a `medianoche_id` field in the YAML frontmatter and shows the actions only for those files, with commands and hotkeys usable in Reading view, Live Preview and Source mode on desktop and mobile. The README states that the plugin does not fetch feeds or create article notes itself: Medianoche desktop owns feed subscriptions, article extraction, file export and the watcher that imports frontmatter changes back into the app.
