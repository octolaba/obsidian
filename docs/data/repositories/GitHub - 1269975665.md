# stavarengo/folia-kanban

A kanban board in which every card is its own plain Markdown file: the column is a status property, the position within a column a fractional order property, and description, subtasks, subcards, comments and history live in that same file as ordinary Markdown sections. A card is a subcard of another only when the parent's subtasks section links to it, body edits splice only the touched section, and frontmatter is written through Obsidian's own frontmatter processor so unrelated bytes are never rewritten. Dragging by pointer or keyboard rewrites one card's status and order and appends a history line instead of reindexing the whole column. A card detail panel, docked, floating or modal, renders description and comments with Obsidian's Markdown engine and edits status, priority, due date, custom properties, subtasks and comments.
