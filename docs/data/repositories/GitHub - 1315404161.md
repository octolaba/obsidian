# nataka620/GoalToDo

GoalToDo layers hierarchical goals over ordinary Markdown task lists with no separate database: a root task becomes a goal once it has children, a parent's state and progress are derived from its direct children rather than set by hand, and Tab or Shift+Tab moves a whole subtree. Task lines carry inline tokens for due date, completion time, priority and assignee, offered by autocomplete and shown in Live Preview as compact controls while Source mode keeps the raw text. Live Preview marks goals with a flag, shows a parent's percentage and its completed count of direct children, and colors overdue dates red. A separate view for the open file lists its goals and tasks with counts, filters by state, deadline, priority and assignee, sorts columns, edits fields in place and jumps to the source line.
