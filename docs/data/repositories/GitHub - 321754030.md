# mgmeyers/obsidian-contextual-typography

This plugin adds a data attribute naming the source element to every top-level preview container, so that styling can react to the kind of block a piece of content came from. The README states that the plugin itself adds no styles: it only enables the contextual styling that a theme or a snippet then supplies. It records a typographic web project as its specific inspiration.
