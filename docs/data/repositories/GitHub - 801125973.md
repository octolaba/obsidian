# BambusControl/obsidian-substitutions

Substitutions replaces text fragments with symbols or with other text while typing, comparing the end of the text typed so far against its rules. The README records that a substitution is triggered by direct single-character input, so existing note content is never rewritten retroactively and multi-character insertions such as pasted text may not trigger a rule at all. It ships with built-in defaults — among them arrows, a not-equal sign and a one-half fraction — that can be edited, disabled or removed like a user's own rules, and rules are managed in the plugin's settings with search and filtering, per-rule actions to swap source and replacement or to switch the rule to regular expressions, and a command that adds a rule from the current selection. The plugin requires a stated minimum Obsidian version and works on desktop and mobile.
