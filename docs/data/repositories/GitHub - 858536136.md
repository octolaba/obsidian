# stanley-910/obsidian-code-language-completer

Code Language Completer speeds up inserting code blocks in Obsidian by autosuggesting and completing programming language names. Further languages can be added, and the suggestion list is ordered by the most recently used language, which the README notes helps while taking notes about one language. A configurable hotkey places the cursor inside the autosuggest modal, and after a language is inserted the cursor is placed inside the code block.
