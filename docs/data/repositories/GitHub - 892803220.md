# eharris128/obsidian-dream-journal

Obsidian plugin for recording dreams as notes in the vault, capturing a title and a description and letting emotions be selected from an emotion wheel. A dream can optionally be rated on the 28-item LuCiD scale, whose factor scores for insight, control, thought, realism, memory, dissociation and emotion are written to the note as properties for later analysis, and unanswered statements are skipped. Entries are saved as Markdown files and managed from a view opened by a ribbon icon or a command; the README records mobile support and lists score analysis and export as not yet implemented.
