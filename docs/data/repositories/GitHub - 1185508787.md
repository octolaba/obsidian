# Jareika/ttrpg-tools-screen

TTRPG Tools - Player Screen sends vault content to a separate Obsidian popout window intended for a second monitor, television or projector, while the game master keeps control in the main window. Notes, selected text, the current paragraph or heading section, images, videos, PDFs and markdown passed through the plugin API can be sent from the file menu, reading-view context menus, embeds, internal links or a searchable media picker. A controller view inside the main window keeps a tab list of everything sent, switches between items, closes individual tabs or the popout, and drives video playback and PDF navigation. The README states that the popout remembers its position and size, that displayed items refresh when they change in the vault, and that markdown containing only a zoommap code block is given a class so map views can be centered and made non-interactive on the player screen.
