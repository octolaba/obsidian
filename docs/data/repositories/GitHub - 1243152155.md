# adoom2017/miniflux-rss-view

Miniflux RSS View reads entries from a Miniflux server inside Obsidian, opening a dedicated view from the ribbon or the command palette that shows unread entries by default and can filter to all, unread or starred, search, refresh and load further pages. Article URLs open in Obsidian's core Web viewer, and unread entries are marked read automatically once opened. The README discloses that a server URL, an API key and a page size are configured in settings, that the API key is stored in plugin data on the device and sent to that server as an authentication header, that network requests go only to the configured server, and that the plugin contains no ads, telemetry or self-update mechanism.
