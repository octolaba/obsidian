# xinxiangmu/knowledge-graph-ai

Knowledge Graph AI builds a structured graph from documents by using a model to extract entities and the relationships between them. A panel opened from a sidebar icon takes uploaded documents for analysis and presents the result as an interactive graph, alongside a timeline view that orders the extracted nodes chronologically; duplicate entities are merged automatically. A paid tier is offered for unlimited document parsing and advanced graph export.
