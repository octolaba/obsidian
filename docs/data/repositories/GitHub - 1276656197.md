# sajee05/echo-recall

Echo Recall schedules revision of whole notes rather than flashcards: opening a note and clicking its echo control starts a review in place, scheduled by spaced repetition together with a retrospective revision timetable tied to deadlines, an approach the README attributes to Ali Abdaal. The README describes the problem it targets as the loss of context and the broken tables or links that come from cutting long notes into small cards. An experimental export slices a note by headings into Anki cards through the AnkiConnect add-on, giving each card a table-of-contents sidebar, a button that shows the full note as an overlay, and images converted to Base64 into Anki's media store, while Obsidian stays the source of truth.
