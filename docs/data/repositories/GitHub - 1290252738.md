# kepano/aloha

Typing an at sign in the Obsidian editor opens an autocomplete menu offering Today, Tomorrow and Yesterday. Choosing one inserts that calendar date into the note as a link, written in a year-month-day format. Upstream names the unmaintained Natural Language Dates plugin as its inspiration.
