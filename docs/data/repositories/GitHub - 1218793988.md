# 2949984428/claude-skill-sync

Obsidian plugin that treats a vault as the central store for AI agent skills and symlinks them into the skill directories of tools such as Claude Code, Codex and Cursor, leaving cross-machine sync to the vault's own solution. Its Chinese README describes a skill root folder in the vault where each subdirectory holding a skill file counts as one skill, a sidebar status grid distinguishing synced, partly synced, missing, importable, mis-pointed, broken and conflicting links, install and import in both directions, one-click cleanup of dead links and repair of wrong targets, and scheduled automatic sync.
