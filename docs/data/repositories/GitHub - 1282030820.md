# frank-pw/cordyceps

Cordyceps is an Obsidian theme drawn from the visual language of The Last of Us: blackened charcoal panels, olive-green navigation, tarnished-gold accents, faded paper text, worn borders and a subtle CRT grain over everything, with a light mode that carries the same weathered mood onto aged paper. It is written entirely in CSS with no snippets, plugins or external assets, and it sets type in IBM Plex Mono, falling back to a system monospace when that font is absent. The README lists panel frames with thin gold-olive borders, faint olive-amber gradients at panel corners, masked folder icons without arrows, a rule under H1 with uppercase gold H2 and olive H3, blockquotes drawn as bordered cards, custom gold checkboxes, and reskinned callouts, tables and code blocks.
