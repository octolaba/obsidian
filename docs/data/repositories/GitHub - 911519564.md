# glasp-co/obsidian-glasp-plugin

This repository holds Glasp for Obsidian, described upstream as importing highlights and notes from Glasp. The README extends that to summaries and bookmarks, and to Kindle highlights kept in a folder separate from web highlights, with background sync running hourly, daily or weekly. It says imports are incremental and non-destructive, matching existing notes by source address and updating them in place rather than duplicating them, that Markdown layout and frontmatter are template-driven, and that each source also gets a generated Bases view, which requires Obsidian 1.9 or newer.
