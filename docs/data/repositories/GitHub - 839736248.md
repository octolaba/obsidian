# larksq/obsidian-llm-summary

The repository description records the project as work in progress; its README presents LLM Summary as automating summarisation and concept definition in Obsidian, aimed mainly at reading academic papers. It generates summaries for the PDF files in a folder as a batch through OpenAI GPT models, writing them into the vault as Markdown with a default structure, and it creates a new note from selected text with that text as the title, linking to it. The README states the requirements: an OpenAI API key, a working Python environment with the openai, arxiv and pymupdf packages installed, and a recommendation to start a new vault because the plugin depends on a particular folder setup.
