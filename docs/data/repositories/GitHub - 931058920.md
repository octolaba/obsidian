# aldo-g/obsidian-llm-test

The repository records no description; its README presents an LLM testing plugin that generates questions from the reader's own notes and grades the answers. It states that questions and feedback follow the language of the source notes, that difficulty levels can be varied, that scores are tracked, and that all tests are managed from a dashboard opened by a ribbon icon or command. A provider is chosen in the settings from OpenAI, Anthropic, Mistral, Gemini and DeepSeek with an API key entered there, or Ollama run locally without one, and the README says the available models are fetched from the provider with incompatible ones filtered out.
