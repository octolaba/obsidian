# Gregory-Jagermeister/Fantasy-Content-Generator

Generates fantasy content for tabletop use, including names by race, inns and taverns, settlements, loot, drinks, groups, currency and dungeons. Generators are reached through a book icon in the ribbon, configured in their own settings, and the generated text is copied to the clipboard. Words and phrases can be added to several of the generators from the settings, and an inline generator invoked through a callout produces a single result in place. The README credits the fantasy-name-generator and fantasy-content-generator packages and a fantasy-names repository.
