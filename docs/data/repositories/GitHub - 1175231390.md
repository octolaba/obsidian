# d0d1/obsidian-move-to-new-folder

This repository holds Move to New Folder, an Obsidian community plugin that moves a file or folder into a newly created folder without requiring the full destination path to be typed; the repository records no description, so this summary follows the README alone. It adds a command for notes and a file explorer entry for folders, offers a searchable picker for the parent folder, then creates the new child folder and performs the move through Obsidian APIs so normal link updating still applies. A setting starts the picker from the active note's parent instead of the vault root, and the README records testing on Windows, Android and Linux with macOS and iOS not yet fully validated.
