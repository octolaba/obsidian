# trawlhq/obsidian-trawl-intelligence

This plugin pulls intelligence reports from the Trawl service into the vault as Markdown notes. The README states that a report contains generated summaries, Reddit sentiment, insider trading, news, filings with the Securities and Exchange Commission, and congressional trading data. A Trawl API key is entered in the plugin settings, and a report is fetched through a command in the command palette.
