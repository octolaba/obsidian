# TfTHacker/obsidian42-strange-new-worlds

Strange New Worlds surfaces the connections a vault already contains, by showing where links, block references and embeds are associated with other files. The README argues that these relationships otherwise require searching or opening the backlinks pane to notice, and that the plugin tries to resurface them without being too intrusive. Its documentation and videos are hosted on the author's own site.
