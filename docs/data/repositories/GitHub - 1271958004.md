# devkirkir/obsidian-simple-sync-plugin

Repository for Simple Sync Notes, a plugin that synchronises vault notes with a CouchDB database. Its README states that it listens for vault create, modify, rename and delete events and pushes them to CouchDB, and that credentials are held in Obsidian's built-in secret storage while the database address is entered as a setting. It records the project as written out of personal interest rather than to compete with existing sync solutions, marks it as in development and not yet feature-complete or fully stable with a recommendation to keep backups, and notes that it is not in the community plugin directory and requires Obsidian 1.12.0 or later.
