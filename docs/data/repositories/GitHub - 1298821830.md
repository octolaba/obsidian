# echore/vault-autopilot

Vault Autopilot receives clips from its companion Chrome extension, Obsidian Visual Clipper, over localhost and writes them into structured notes and images in the vault without a manual paste-and-format step. Webpage screenshots become a standalone note with images placed in a frames subfolder, while cover, hook and keyframe clips from one video are merged into a single note per video: whichever clip type arrives first creates the note and later clips upsert new sections into it. Every clip response carries an obsidian deep link back to the note that was created or updated, so the extension can jump straight to it. The README states that plugin and extension are a suite of which neither half is useful alone, and that the plugin is desktop-only because it runs a local Node HTTP server.
