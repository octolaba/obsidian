# k0src/Obsidian-Auto-Close-Tags-Plugin

An Obsidian plugin that automatically closes HTML tags as you type, adding the closing tag when you type `>`, and that also works on pasted HTML content. It detects nested tags and self-closing elements, exposes a "Close last unclosed tag" command with a configurable hotkey, and can be told to ignore fenced code blocks and inline code. Settings cover the list of excluded tags and whether the cursor lands between the tags or after the closing tag.
