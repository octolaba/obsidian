# mdfriday/obsidian-friday-plugin

Friday is an Obsidian plugin for syncing notes across devices and publishing them as websites from within Obsidian. The README lists ready-made themes for documentation and knowledge bases, blogs, resumes and portfolios, landing and company pages and slides, with more available inside the plugin itself. It also documents self-hosting an MDFriday instance with Docker behind a domain and open HTTP and HTTPS ports, installed by a single shell command. It acknowledges Hugo, LiveSync and Quartz as inspirations.
