# Tea0S/backdrop-sync

BackDrop Sync keeps wiki and timeline articles from a BackDrop account in step with notes in the vault, authenticated by an API key and scoped by a per-world checklist that can enable wiki, timeline or both. Notes carrying the matching frontmatter type gain a header bar for inserting images, audio, spoilers and wikilinks, editing article properties such as status, category, characters and thumbnail, and resolving sync, plus a status badge reading clean, dirty, conflict or unpublished. Pushing goes through a selective panel listing dirty, unpublished and conflicting notes with per-row status, which uploads only the checked ones. Pulling creates missing notes and updates clean ones that are newer on the server but never overwrites local edits: those are marked as conflicts and resolved by keeping local, taking remote or force-pushing.
