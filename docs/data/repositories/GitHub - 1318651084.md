# thisisthedave/tasknotes-jira

Imports a Jira issue as a TaskNotes task, taking the issue data from the Jira Issue plugin and submitting it through the TaskNotes task-creation API, so both of those plugins must be installed and configured first. A settings screen maps Jira JSON paths, templates or fixed values onto TaskNotes properties and user-defined fields, merges several sources into list-valued properties, and remaps status, priority and context values. A sample issue can be fetched to preview the resolved values and inspect the raw JSON, which is held only in memory. The import is run by command with an issue key, adds a Jira backlink to the created note, and leaves task defaults, templates and filename generation to TaskNotes; no Jira credentials are stored by this plugin.
