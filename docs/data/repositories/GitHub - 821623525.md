# yefengr/obsidian-daily-statistics

Repository for Obsidian Daily Statistics, a plugin whose README is written in Chinese and which counts the words written each day and shows them in a calendar. Its listed features are limiting the count to chosen folders, a weekly goal, Chinese and English interfaces, week-start days that follow the locale or are set by hand, editing a day's count by double-clicking the date, switching between counting characters and words, turning the plan on or off, and mobile support. The README states that many of these features were modelled on the obsidian-word-count and obsidian-daily-stats plugins.
