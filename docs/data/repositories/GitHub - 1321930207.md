# Soren-ac/MindBraid

MindBraid is a desktop-only plugin that renders the active note as an interactive mind map, turning its ATX headings and nested lists into topics that refresh while the note is edited. Topics are created with Tab and Enter, edited in place, and dragged to reorder or reparent, with the destination previewed before any Markdown is written. Layout and appearance are chosen separately: balanced or one-sided layouts in four directions, plus Colorful, Pencil and Cloud styles with independent palettes, fonts and connector settings. It parses only the note being mapped, makes no network requests, and keeps presentation choices such as collapse state and viewport in plugin data rather than in the note.
