# Lauloque/Keyboard-Formatter

The recorded description says the plugin formats keyboard text quickly and consistently in Obsidian notes. Per the README a selection is turned into HTML keyboard tags by a hotkey the user chooses, so that a phrase naming modifiers and a letter becomes a set of separately marked keys. It recognizes modifier keys, the function keys F1 to F12, command keys such as Tab, Delete and Enter, direction words rendered as arrows, numpad keys, and mouse buttons written as lmb, rmb, mmb or wheel, matching names regardless of capitalization and capitalizing single letters. The README states that its styling covers both light and dark themes.
