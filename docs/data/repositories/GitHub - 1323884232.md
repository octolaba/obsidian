# webline/onyx-boox-sync

Booxidian watches a folder outside the vault for Onyx Boox exports and imports them into Obsidian automatically. Reading-note highlight files become highlight notes, one per book or one per book page in a subfolder, covering both firmware layouts; handwriting PDFs are reconstructed into lossless SVG vectors with an optional text transcription; annotated PDFs are copied into the vault beside a companion note quoting each highlight with a page deep-link; plain text notes are imported as they are. Imports are deduplicated by content hash, so rescanning a folder creates no duplicates. It is desktop-only because it uses Node's filesystem to watch folders outside the vault, and its interface and the notes it writes are available in English and German.
