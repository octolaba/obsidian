# ariedotme/urso

Urso is an Obsidian tag and property explorer. The README says it turns slash tags into a navigable hierarchical tree with collapse and expand controls, tracks chosen frontmatter properties as a second primary view with optional value sub-categories, and lists the matching notes beside the current selection with configurable sorting and date display. It also documents per-tag, per-property and per-note icons, pinning, hidden tag management, a resizable split view on desktop and tablet with single-pane navigation on phones, and a hotkey that creates a new note carrying the selected tag or property.
