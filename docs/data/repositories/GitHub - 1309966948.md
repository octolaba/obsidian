# andyguy-dot/obsidian-team-manager

Team Manager turns plain Markdown notes with YAML frontmatter into a management workspace for people, one-to-one meetings, projects and performance observations, with no database behind it. The README records a people dashboard whose cards are grouped by relationship and carry a cadence-health ring, days since the last one-to-one and counters for open items and active projects, an agenda buffer that collects points during the week and is pulled into the next meeting while open action items roll forward, and a Kanban board with statuses as columns and owners as rows. A live side panel mirrors the open meeting, person or project note and can hide performance observations while a screen is being shared, and observations jotted down as they happen accumulate to pre-fill the next review.
