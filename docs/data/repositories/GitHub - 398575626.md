# Taitava/obsidian-shellcommands

Shell commands lets a user define shell or terminal commands in settings and run them from Obsidian's command palette or by hotkey, with some automated events and execution through URI links also supported. Commands can use built-in variables such as the current file's title, name and path, its parent folder, and a date or time stamp in a custom format, and the output can be inserted back into a note. The README warns that only commands the user knows and trusts should be run.
