# L7Cy/obsidian-2hop-links-plus

2Hop Links Plus displays links related to the current Obsidian note up to two hops away as cards, each carrying a preview of the note it points to, so connections between notes can be browsed. The README states that it is a fork of tokuhirom's 2hop-links plugin. Its listed additions are automatic adjustment of box width, improved preview content, support for external link images, exclusion paths, a context menu with actions such as open in new tab, sorting of links, and display in a separate pane.
