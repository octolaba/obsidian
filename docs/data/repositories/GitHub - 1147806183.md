# linyanna/panda-syntax-obsidian

Panda Syntax for Obsidian is a theme based on Panda Syntax for VS Code by Siamak Mokhtari, built around a soft pink, teal and blue palette; the recorded repository description calls it a plugin, while the README describes a theme. It provides dark and light modes, a full heading hierarchy running cyan, pink, orange, blue and purple, and syntax highlighting for code blocks and inline code. Callouts, tables, tags, blockquotes and highlights are styled, and the README notes pink-tinted file explorer hover states and thin custom scrollbars.
