# imshenshen/obsidian-sticky-heading

This plugin keeps the headings above the current position pinned at the top of the editor while a note is scrolled. Its README gives the motivation as writing in fragmented time and losing track of which heading level the cursor is at, or which level the next heading should use. It records two limits: in the mode that pins everything up to the first-level heading the container flickers when the number of pinned headings changes during scrolling, because their position is recalculated; and reading mode is not handled, which the author would consider implementing if the demand were there. The Style Settings plugin is asked for as well, since the top spacing a sticky heading needs differs between themes.
