# pan4ratte/obsidian-publish-to-telegram

Publish to Telegram posts notes from Obsidian to Telegram channels, groups, forum topics and personal messages, either as the user's own account or as a bot, with or without rich-text formatting. Targets are held in presets that can each carry several chats, chosen from the chat list after authorization or entered as a username or id, and publishing runs from a hotkey, the command palette, the file context menu or the advanced publishing settings. Beyond standard Telegram formatting the README records accordions, centred quotes, references, LaTeX formulas, maps, collages and slideshows, photo, video, audio, album and document attachments, and an emoji bar that loads custom packs from the account. Advanced settings cover previewing each message, scheduling it, splitting a note into several posts with markers, and editing what was already published.
