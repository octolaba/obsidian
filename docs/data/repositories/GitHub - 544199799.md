# monesga/obsidian-sigma

Obsidian Sigma turns code blocks marked with the sigma language into calculation sheets: each line is an expression, every expression in a block is evaluated with operator precedence, and the block is totalled. Leaving the block renders it as an HTML table showing each expression and its value together with the block total, with syntax colouring that covers dark themes. The README records variable assignment and evaluation, hierarchy and subtotals, several blocks in one note, built-in scientific functions, control over output number formatting, and support on desktop and mobile, and it names financial planning, expense tracking and conversions as intended uses.
