# samhopwell/obsidian-foldstate

Foldstate persists heading fold state in Obsidian across devices and sessions by writing the marker "%% fold %%" onto folded heading lines instead of relying on localStorage, which the README notes is lost on a device change, reinstall or sync. Because the marker uses Obsidian's native comment syntax it is hidden in Reading view and travels with the file through any sync tool such as iCloud, Git, Dropbox or Obsidian Sync. State is saved on every fold and unfold and restored when a file opens, with no settings and no separate state file; unfolding removes the marker again. The plugin requires Obsidian 1.4.0 or later and tracks fold state in Live Preview or Source mode only.
