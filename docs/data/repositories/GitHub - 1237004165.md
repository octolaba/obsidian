# Tea0S/multimuse-tracker

This repository holds Multimuse Tracker, an Obsidian plugin that connects the MultiMuse Discord bot to a vault for tracking roleplay threads. It tracks Discord threads linked in scene files, posts selected text to a thread as a chosen muse from the right-click menu, detects the Discord user id from the API key, creates scene files with muse selection and folder organization, and imports tracked threads from the bot. The README records polling for new replies at configurable intervals between 5 and 60 minutes, roleplay and activity properties added automatically from the folder structure, and automatic updates to a replied property while the participants property is left for the user to edit.
