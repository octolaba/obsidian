# israerusan/prose-lens

Prose Lens marks readability and style in the Obsidian editor while a draft is revised: passive voice, adverbs, hedges, long sentences and a Flesch reading grade, with live counts and a rhythm map in the free core. The recorded description and README place further tools — de-slop marks, an echo detector, a revision delta and focus mode — in a Pro tier sold as a one-time purchase that activates offline without an account. Before any rule runs the plugin masks code fences, inline code, math, frontmatter, URLs, wikilinks, headings and table rows so that only prose is analysed, and the README states that it only highlights and never writes to a note.
