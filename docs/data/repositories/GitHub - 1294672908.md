# anombyte93/obsidian-unread-changes

Unread Changes marks notes in a shared vault that were changed by another device, collaborator or automation, showing an unread dot on changed notes and dots or optional counts on their folders. Its README describes an unread inbox carrying attribution and a plain-language summary where one exists, a virtual banner above a changed note linking to its changelog and diff, and commands to mark notes or whole folders read or unread from the banner, file menu or command palette. Read state is stored separately and synced across devices, so notes are never modified to display the banner and edits made on the current device raise no alert; sectioned inbox views and urgency colours are recorded as not yet shipped.
