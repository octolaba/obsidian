# Erl-koenig/obsidian-flash-navigation

Jumps to any text visible on screen by typing the characters that begin it. Matching text is highlighted as the query grows, each match is given a short label, and pressing that label key moves the cursor there. The status bar shows the query while it is typed, the colours and styling of highlights and labels are configurable, and the README names flash.nvim and similar tools as the inspiration. No repository description is recorded, so this note is grounded in the README alone.
