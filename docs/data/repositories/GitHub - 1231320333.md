# ryanravn/obsidian-seafile-continued

This repository is a community continuation of an earlier Seafile plugin for Obsidian, synchronising a vault against a self-hosted Seafile server. The README states the fork adds support for encrypted libraries, with the passphrase prompted when a repository is selected and again after a restart and never stored in plain text, and a manual sync reachable from a settings button or a command that can take a hotkey. It describes syncing on desktop and mobile through Seafile's internal delta API with per-file status shown beside filenames in the explorer, and an optional ignore pattern loosely following gitignore syntax, with the plugin folder and the Obsidian configuration always ignored. Two warnings are recorded: the plugin is still under development and carries a risk of data loss, and files beyond roughly 50 MB may be slow or may crash because of Obsidian API limits.
