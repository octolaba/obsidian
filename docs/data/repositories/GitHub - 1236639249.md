# Neves007/line-ref-copier

Local Obsidian plugin that copies a precise Markdown note reference from the cursor line, a selected phrase on one line, or a selection spanning several lines. The three reference levels are a path with a line number, a path with a line and a column range, and a path with start and end line-column positions, and the path may be written relative to the vault or as an absolute local file path. Its stated purpose is giving an AI agent an exact location to inspect instead of a prose description of where the text sits. The command runs from the palette or a shortcut recorded in the settings, and an optional notice reports what was copied.
