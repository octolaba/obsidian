# jamespeachh/Three-Noun-Prompts

Three Noun Prompts generates a three-word creative writing prompt in an Obsidian note, derived from a secret key the user chooses so that several people sharing a key receive the same prompt. The README records settings for that key, for the title of the note the prompts are written into and for the interval in seconds after which the prompt changes, a ribbon button that creates or opens the note, and a list of all previous prompts. It states that the plugin is desktop only and cannot be used on mobile, recommends a key of six to nine letters, and notes that the note may have to be created by hand if it does not appear.
