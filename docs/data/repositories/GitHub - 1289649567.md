# BrandtheBrand/eve-apple-tree

Obsidian plugin that renders notes as a three-dimensional tree of light that can be navigated by flying around it, with notes drawn as dots placed by field and time, links as connections, breakthroughs as flowers and outputs as apples. Only notes carrying the plugin's tree frontmatter are drawn, and one folder makes one tree, so a vault of topics becomes a forest. The README presents it as one half of a wider thinking system whose other half is a separate AI companion kit downloaded from the same repository; the plugin itself ships no AI.
