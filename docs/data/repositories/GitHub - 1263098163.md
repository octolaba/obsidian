# vastea/obsidian-task-manager-bases-view

Task Manager Bases View adds three task views on top of Obsidian Bases: a Kanban board whose columns come from the Bases group-by or from a predefined ordered list, a Gantt-style timeline built from start and end date properties, and a weekly calendar grid rendering log blocks from daily notes. The README describes the plugin as a renderer only, with the data staying in the user's own frontmatter and note bodies, grouping, filtering and sorting done by Bases, and no field name hard-coded. Dragging rewrites the underlying property: a card moved between columns changes its group value and a bar moved on the timeline is rescheduled, while a context menu moves or archives a card. It records a requirement of Obsidian 1.10.2 or later for the Bases view API and states that the plugin is desktop only.
