# yuanzhixiang/obsidian-xmind

Opens local `.xmind` files in a dedicated Obsidian view and embeds them read-only inside Markdown notes with Obsidian's own embed syntax, rendering in both Reading view and Live Preview. A map switches between the sheets of one file, can be searched with jumps between matching topics, read as a hierarchy in a full-page outliner view, and zoomed, fitted to the pane or panned with trackpad gestures, wheel scrolling, modifier-wheel zooming and right-button dragging. Branches expand and collapse while respecting the folded state saved by XMind, and relationships, boundaries, summaries, markers, labels, notes, links, tasks, images, callouts, floating topics and topic shapes are shown. The README states that the interface text follows the Obsidian language where possible, in English or Simplified Chinese.
