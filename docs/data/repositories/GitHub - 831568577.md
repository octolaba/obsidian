# ai-learning-tools/obsidian-spaced-repetition-ai

Spaced Repetition AI generates and reviews flashcards inside Obsidian. Cards are written directly in notes with tracking, reviewed on the FSRS scheduling algorithm, and can be generated from a note's content with OpenAI, with review and generation usable separately or together. The README records that the plugin adds a folder to the vault holding the files that track the cards for each detected note, and credits the open-source FSRS implementation it builds on.
