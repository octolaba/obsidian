# maxonamission/obsidian-readability-compass

Readability Compass measures the readability of the active note and reports whether it sits inside a target band the writer chooses. It uses LIX, a score computed from sentence length and the share of long words, which the README states needs no syllable estimation or word lists and therefore works in any language that separates words with spaces, naming Dutch, English, German and the Scandinavian languages. The target band can be set to approximate CEFR B1, B2 or C1 levels or to a custom ceiling, and the resulting verdict is kept in the status bar while writing, with details available in a side panel.
