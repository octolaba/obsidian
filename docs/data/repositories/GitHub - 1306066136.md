# ValleytheKnight/Kanban-Complete-Mover

The recorded description says the plugin moves a Kanban card to a Complete lane, created automatically when missing, the moment its checkbox is checked, with an optional completion-date stamp on the same move. The README explains that it watches boards belonging to the mgmeyers Kanban plugin and, once enabled, keeps one rule true: a checked card belongs in the Complete lane. Unchecking a card sitting there can send it back where it came from, dragging a checked card out unchecks it rather than snapping it back, and a new lane lands above an Archive section when the board has one. The lane name is set in the settings and can be overridden per board through frontmatter, and nothing happens until automatic moving is switched on.
