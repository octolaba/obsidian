# marcelrsoub/react-kanban

Opens existing Markdown-backed Kanban boards — those carrying the `kanban-plugin: board` frontmatter marker — in a React board interface, without migrating them or changing their structure, so the notes stay ordinary portable Markdown. Cards can be dragged within and between columns, columns reordered from their menu and renamed inline, cards added through a dialog with Markdown rendered inside them, marked complete and grouped at the bottom of a column, or deleted from the right-click menu. Adding a card can optionally create a linked Markdown note whose destination is configurable, and the README states the plugin works locally with no analytics, telemetry or network requests.
