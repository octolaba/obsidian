# vrabe/obsidian-cjk-count

CJK Count is a word count plugin that counts only Chinese, Japanese and Korean characters and shows the result in Obsidian's status bar. The README records a limitation, that its interface is localized to English and Chinese only through a simple framework in its own source. It credits the `cjk-regex` library for filtering CJK characters.
