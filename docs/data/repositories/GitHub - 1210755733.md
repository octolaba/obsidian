# LuneVoilee/obsidian-latex-color-sync

Obsidian plugin that wraps inline LaTeX formulas in a colour command so that math follows the colour of the surrounding text in source mode, keeping formulas consistent with headings, links or quotes coloured by the theme. It can sync automatically whenever an edit inserts a newline, which the settings allow disabling for very large notes, and two commands rewrite formulas either in the selection or current line, or across the whole document. The README recommends running the narrower command first and undoing immediately if the result is unwanted, and further settings cover interface language and whether a summary is shown after a manual run.
