# mgriffen/oterm

Terminal emulator embedded in Obsidian, built on the components behind the terminal of VS Code — xterm.js with WebGL rendering, and node-pty underneath. It docks in the right sidebar and offers multiple renameable tabs, find-in-output, clickable URLs and shells detected per platform, among them PowerShell, WSL, Git Bash, zsh, bash and fish, as well as CLI tools such as Claude Code. On first use it downloads a small platform-specific native binary from GitHub releases and caches it, and the README documents a manual download path for machines behind a proxy or firewall.
