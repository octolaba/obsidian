# gilles6/properties-filename

Properties Filename renames Obsidian notes from their frontmatter properties, using a template of property placeholders, so that editing a property renames the file and Obsidian's own rename API updates the wikilinks pointing at it. Each rule names a folder it applies to including subfolders, the filename template, and optionally a required frontmatter type value. A rename only happens when every referenced property is present and non-empty, the new name differs from the current one, and no other file already occupies the target path. Renaming can be triggered for the active note or as a bulk pass over every matching file, and automatic renaming on property change is off by default and debounced when enabled.
