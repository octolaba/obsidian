# rephila/simple-sticky-notes

Simple Sticky Notes opens vault notes as floating sticky-note windows, launched from the ribbon, the command palette or a file's context menu, with commands to open, create, or destroy all of them. Each window can be pinned above other windows, resized, made transparent and given a background and text color from a shared palette, and the appearance can be written into the note's frontmatter. Settings cover the folder for new sticky notes, taskbar visibility, default pin mode, size and transparency, and restoring open windows with their position, size, colors and transparency. It is desktop only, requires Obsidian 1.13.0 or later, and uses Electron APIs together with Obsidian's popout and header DOM structure.
