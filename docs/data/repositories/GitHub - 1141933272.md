# Ongiei/obsidian-lexibridge

Obsidian plugin providing local-first dictionary tools with offline English-Chinese definitions, vocabulary notes, wordbook synchronization and one-way Anki export. It installs and queries the ECDICT dictionary locally, verifying downloads against the Git blob SHA of the selected upstream commit, generates vocabulary notes from editable Markdown and frontmatter templates while preserving user-written content under configured headings, resolves inflected words to lemma notes, and shows non-destructive virtual links that can be previewed or converted into real short links. Optional integrations enrich a word through Youdao, synchronize Eudic wordbooks and send notes to Anki through AnkiConnect. The README places the project in 0.x development, requires Obsidian 1.8.7 or later, and confines the ECDICT installer and Anki export to desktop.
