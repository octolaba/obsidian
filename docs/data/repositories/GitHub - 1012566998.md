# regawaras/Coffee

This repository holds the Coffee theme for Obsidian, a coffee-inspired palette in a dark Dark Coffee and a light Light Coffee mode, the light one built around warm undertones. Its CSS variables are named after coffee terms such as americano, moccacino, latte, caramel and hazelnut. Beyond colour it highlights the active and hovered line in source view, styles text highlights, the cursor caret and callout blocks, animates collapsed and uncollapsed list items, puts emoji folder and file icons in the file explorer, and carries print styles that set Times New Roman and justified text for PDF output.
