# avr/obsidian-reading-time

The repository holds the Obsidian Reading Time plugin, which adds an estimated reading time for the selected note to the status bar. Its README describes the plugin as simple and covers installation by extracting a released folder into the vault's plugins directory, together with a build and release procedure for contributors. It is written in TypeScript under the MIT license and carries the obsidian-md and obsidian-plugin topics.
