# heliostatic/completed-task-display

Completed Task Display controls the visibility of completed tasks across an Obsidian vault, hiding or showing checked `[x]` items with a single toggle. The toggle is reachable from a ribbon button and from a command, a status bar indicator reports whether completed tasks are hidden or shown, and the chosen state is remembered between sessions. Only `[x]` and `[X]` are hidden, so custom statuses such as `[?]`, `[!]` and `[/]` are preserved, indented sub-bullets beneath a completed task can optionally be hidden in Edit and Live Preview mode, and the README states that it works on desktop and mobile.
