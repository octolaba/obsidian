# BrMacCath/Table-of-Contents

This plugin creates a table of contents that its README describes as compatible with Obsidian Publish, inserted either at the top of the file or at the cursor by two separate commands. The table updates after a heading changes, though the README notes that it does not do so on every keystroke and supplies a command for updating it manually. Its settings choose the marker used for entries — numbering, a greater-than arrow, or a bullet — and the characters to strip from titles; the README warns that most settings do not affect tables of contents that already exist, the character list being the one exception.
