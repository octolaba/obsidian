# iodic/obsidian-ayu-theme

This repository holds Ayu Palette, an Obsidian theme inspired by the ayu theme and largely based on the taronull Obsidian Ayu theme, which its README reports is no longer available. It carries three palettes, Light, Mirage and Dark, and the Style Settings plugin chooses which palette maps to Obsidian's light mode and which to its dark mode. Typography uses the system UI stack for the interface, Sentient for text and Maple Mono for code, with theme fallbacks when those fonts are not installed, and the README notes that the theme folder must be named exactly Ayu Palette or Obsidian will not recognize it.
