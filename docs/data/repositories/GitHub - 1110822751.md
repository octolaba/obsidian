# rhoades-brown/obsidian-github

Syncs a vault with GitHub through the Octokit API instead of a local Git command line, pulling and pushing in one operation with selective staging, auto-sync on save, on an interval or at startup, subfolder mapping and optional configuration-folder sync. Extra repositories can be mapped into specific vault directories, each with its own branch, subfolder, ignore patterns and token, with their configuration stored in a vault file so other devices pick it up. Conflicts are detected and resolved through a side-by-side or inline diff view, and a sync panel groups changed files by status alongside commit history and live logs. The README states that all tokens are held in Obsidian's encrypted secret storage and that plaintext tokens are migrated there on first load after an upgrade.
