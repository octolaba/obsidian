# pistacchio/obsidian-enhanced-tables

Obsidian plugin that adds controls to ordinary Markdown tables in Obsidian: configurable pagination, sorting rows by value, custom filters that can be switched between at read time, automatic formatting of dates and numbers, enum columns with fixed values, and per-column custom formatting. The configuration is written as a YAML code block placed immediately before the table, and the controls appear when the note is viewed. The README names DataLoom as its inspiration and gives keeping the data in plain editable tables rather than JSON files as the reason for the different approach.
