# seiichi1101/obsidian-daily-note-carryover

Creates today's daily note at a configured time by copying yesterday's note verbatim, body and frontmatter alike, without rewriting dates inside it. It never overwrites an existing note for today, creates nothing when yesterday's note is missing, and marks the day as done after a run so a note deleted later is not silently recreated. The folder, the moment-style date format, the creation time and whether the new note is opened are configurable, independently of the core Daily notes plugin, and the settings tab previews the paths the current format resolves to. A command and a ribbon icon run the same copy on demand; a run missed while Obsidian was closed is caught up at startup once that time has passed.
