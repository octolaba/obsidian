# leethobbit/obsidian-inkswell-plugin

Inkswell is a writing suite for longform fiction inside Obsidian, gathering the stages of a novel — planning, writing, revising and preparing to publish, plus a cross-cutting Codex and a Track dashboard — into a single host view. The README describes it as local-first and aimed particularly at large, multi-book series, and states a deliberate restraint about scope: rather than adding every possible feature, optional surfaces such as the board, plot grid, beats or the publishing checklist can be switched off losslessly from settings or the tab's context menu so only the tools in use remain visible.
