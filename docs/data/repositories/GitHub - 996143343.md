# Rerurate514/insert_ArknightsURL_banners

The recorded Japanese description says the plugin selects an image saved by the img_dwnldr_wikigg_ak_kt plugin and sets it in the banners property. The Japanese README explains that a command opens a modal listing Arknights images, and that clicking one inserts the network URL of that image into the banner property of the currently active note. It states plainly that the plugin carries no banner rendering of its own, so another community plugin such as Pixel Banner is needed to display the banner, and warns that image loading is rather slow. The recorded licence is MIT.
