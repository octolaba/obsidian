# marc0l92/obsidian-jira-issue

The repository holds jira-issue, an Obsidian plugin for tracking the progress of Atlassian Jira issues from inside notes. Its README records that the connection is configured in the plugin options with a host, username and password, and that the plugin contributes several Markdown components, among them a jira-issue block. Detailed documentation lives on an external site, and the code is licensed under the GNU AGPL version 3.
