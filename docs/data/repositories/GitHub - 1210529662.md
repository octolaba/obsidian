# haotiencheng/obsidian-floating-notes

Opens a native Obsidian editor in a floating popout window for quick capture, toggling it in and out without losing state, optionally kept above other windows and with the tab bar hidden. The popout can show the currently active note, a fixed note, or a freshly created timestamped note in a chosen folder. Three triggers reach it: an Obsidian command that can be bound to a hotkey, an obsidian://floating-notes URI, and a loopback HTTP endpoint on port 51234, the last two intended for a system launcher or a shell script since plugins cannot register operating-system hotkeys themselves. A bundled script starts Obsidian first if it is not already running.
