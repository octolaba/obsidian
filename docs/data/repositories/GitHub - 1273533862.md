# dlsdgj/Obsidian-SwiftSnippets

SwiftSwitch toggles Obsidian CSS snippets from a popup opened by a status-bar button, where each snippet is a chip that is enabled or disabled on click. Snippets are organised into groups created by right-clicking empty space and filled by dragging chips between groups or back to the ungrouped area, fold state is remembered, and a chip's context menu copies its content, edits it inside or outside Obsidian, deletes it or moves it to a group; new snippets can be created from the popup as well. The README also records a draggable floating button, textured background options, automatic adaptation when dark and light mode change, and a Chinese and English toggle in the popup header. The repository name and the name used throughout the README differ, and the README's download instructions point at a different repository.
