# akopdev/obsidian-textgrams

Textgram stores ASCII graphics inside Obsidian notes and renders them as SVG in preview mode, so diagrams, flowcharts, tables and Gantt charts remain plain text that can be edited and versioned along with the note. The README records that a graphic is written inside a code block whose language is textgram, and that the rendering is based on the typograms library. A built-in editor for creating and modifying the graphics without leaving Obsidian is listed as not yet done.
