# rekby/obsidian-header-backlinks

Header Backlinks is an Obsidian plugin that shows an anchor icon in the editor gutter beside headings that other notes link to. The README records a vault-wide scan of wiki links and embeds carrying a heading fragment, building a map of which headings are linked from where and rebuilding it on a short debounce as metadata changes. Clicking an anchor opens a menu of every source note, and choosing one jumps to the exact link line, with a second chooser when a note links to the heading more than once. Same-file links and embed references are counted, headings are matched by normalised text, and the menu also offers a rename action that uses Obsidian's built-in command to update links pointing at the heading.
