# yaye-work/obsidian-sticky-properties

Sticky Properties adds a configured set of frontmatter properties to every newly created note, so the properties a vault always wants are present from the moment a note exists. A property is made sticky either from the settings tab, where its type and default value are set, or by right-clicking its icon in the Properties panel and choosing to auto-add it to new notes, with the type detected automatically. A date or date-and-time property whose default is the recorded now or today keyword records the note's creation moment, and a note that already carries one of the configured properties keeps its existing value.
