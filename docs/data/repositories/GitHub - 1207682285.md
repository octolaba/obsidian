# istefox/obsidian-mcp-connector

An Obsidian plugin that exposes the vault to MCP clients such as Claude Desktop, Claude Code, Cursor, Cline, Continue, Windsurf and VS Code, running the MCP server in-process inside Obsidian on loopback rather than shipping a separate binary. The README records 52 tools, a prompt renderer and on-device embeddings through Transformers.js for semantic search without an API key or Smart Connections, with vault reads and writes going through Obsidian's own vault and metadata cache APIs. Version 1.0 adds up to ten per-client bearer tokens, each carrying its own tool profile, promoted tools and optional hard allowlist, and rotation that takes effect on the next request without restarting the transport. Its statements that nothing leaves the machine are recorded here as the project's own claims.
