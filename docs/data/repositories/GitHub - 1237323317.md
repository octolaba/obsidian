# fanxiaofang/obsidian-murmur

A journaling view for short inner-monologue entries presented in a retro terminal style. Content is extracted automatically from daily notes and ordered as a timeline by time, with an activity heatmap over recent months and statistics for total recorded days, the longest consecutive streak and the day of highest recording density. Filters combining tags, text and dates are saved as reusable chains the README calls paradigms, and a tag registry lists tags by usage frequency, giving each a visual style derived from its name. The README also records ambient background sounds, a layout that adapts between wide desktop views and mobile sidebars, and support for Obsidian's light and dark themes.
