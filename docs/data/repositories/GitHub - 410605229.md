# kzhovn/uri-commands-obsidian

This plugin adds custom URI commands to the command palette, usable with the Obsidian URI scheme as well as any other URI scheme the computer supports. The README documents placeholders substituted into the URI before it is executed, among them the file's base name, its vault-relative path and its entire contents, and states that these are URL-encoded unless encoding is turned off, so reserved characters in the text need no manual escaping. Commands that carry a placeholder are hidden while no file is active.
