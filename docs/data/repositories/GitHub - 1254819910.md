# hoangminhcv2000/obsidian-calculator-pro

This repository holds Calculator Pro, a scientific calculator for Obsidian with LaTeX support. It covers powers, roots, trigonometry, constants, fractions, complex numbers, statistics and unit helpers, and keeps a history of entered equations. Equations can be copied as LaTeX or inserted into a note as full LaTeX carrying both the expression and the result. Two commands open and reset the calculator, and the appearance settings offer an accent colour, a fixed dark look independent of the Obsidian theme, and a soft rainbow accent.
