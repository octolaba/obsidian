# dannyshmueli/obsidian-hermes-console

Hermes Console is an Obsidian plugin that runs the Hermes agent in terminal tabs inside the vault and can pass selected note text or cursor context to it. The README records a per-tab header toggle that opts a tab into sharing context through a local JSON bridge, so a highlighted paragraph becomes the context of the next prompt, with busy state shown per tab and an optional notification when a background turn finishes. Setup is recorded in two parts: installing this plugin from Community Plugins and downloading its binaries from its settings, and separately installing the Hermes-side bridge plugin, which appears under its own name; the README states the plugin does not install Hermes itself. It also records that the plugin is built on a fork of Lean Terminal.
