# viggomeesters/obsidian-folder-sort-view

Folder Sort View adds a separate read-only sidebar for navigating Obsidian folders and files, with folders sorted Z to A and files sorted A to Z inside each folder. Clicking a folder expands or collapses it, with descendants rendered lazily only once their folder is open, and clicking a file opens it through Obsidian's normal workspace flow. The README states the plugin is deliberately a viewer and not a file manager: it does not rename, move, delete or create files, offers no drag-and-drop or context-menu operations, does not patch the native File Explorer, and does not write vault content, use the network or touch the clipboard.
