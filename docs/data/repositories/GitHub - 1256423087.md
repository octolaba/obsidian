# sajee05/sxjeel-spell-checker

This plugin checks spelling offline in Obsidian using standard Hunspell dictionary files, a .dic paired with an .aff. Any Hunspell-compatible dictionary works, so the README states that spell checking is possible in effectively any language and that specialised dictionaries for fields such as medicine, law, science and engineering can be added the same way; installing one means dropping the two files into the folder the settings open and clicking to reload. The README's stated motivation is that the existing grammar-checking plugins it names consume considerable resources for the simpler job of catching typos while typing.
