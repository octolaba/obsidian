# AdamArcane/obsidian-recipebox

Recipe Box stores recipes, meal plans, and grocery lists as ordinary Markdown files while rendering recipes as interactive cards. It supports scalable ingredients, step timers, configurable frontmatter badges, weekly meal planning, filtered meal suggestions, consolidated grocery lists, cooking history, and URL-based recipe import. The plugin also supports RecipeMD and keeps its data editable or queryable with standard Obsidian tools.
