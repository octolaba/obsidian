# soberhacker/obsidian-telegram-sync

Telegram Sync transfers messages and files from Telegram into an Obsidian vault, saving text, voice transcripts, images and other files for further processing. The README records saving a message as its own note or appending it to an existing one, customizable templates for new notes, configurable folders for notes and files, automatic Markdown formatting of text messages, and deletion of processed messages from Telegram. It states that transcription of voices and video notes is available to Telegram Premium subscribers only, and that the plugin is for desktops and would never be available on mobile platforms.
