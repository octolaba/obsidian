# ApoclyReol/AssetTrack-Obsidian

Asset Track organizes bills exported from payment platforms into a local SQLite record kept in a folder inside the vault, for a monthly rather than continuous bookkeeping routine. It imports CSV, XLSX and XLS files with reusable field mappings, then tracks transactions, accounts, loans, investments and fixed assets month by month, with category and counterparty rules repeating the same cleanup each time. Batch edits are previewed before they are applied, conflicts and missing categories are collected for review, and reconciliation compares transactions against recorded asset changes. Monthly and annual analysis, local backup, restore and data-directory migration are included, and an optional AI classifier is the only feature that contacts a network service.
