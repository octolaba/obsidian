# liufree/obsidian-querydash

QueryDash renders query-driven views inside Obsidian notes, with the stated goal of a plugin similar to a Notion database but not limited to database functionality. Because it uses the Dataview API, the README states that the Dataview plugin must be enabled; queries are written in a querydash block in Dataview's SQL syntax and shown as table, list or timeline views, plus a memory card view modelled on Anki-style flashcards that reads spaced repetition properties such as sr-due, sr-interval and sr-ease. Search, filtering, aggregation, pagination and task management including task editing are recorded as further features, and the README says views powered by the Obsidian Bases plugin are supported through the open API that Bases provides.
