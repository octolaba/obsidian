# ms3056/Tokei

Tokei adds a clock to Obsidian, opened through its own command and then dragged to a chosen location. Timezones are entered either as a numeric UTC offset or as an IANA timezone identifier, where IANA zones handle daylight saving automatically and the field suggests matches from any part of a zone name; the name field is optional, and a label style setting derives the displayed label from the zone. The README also ships an alternative compact style as a snippet and documents the CSS class provided for all visible items so the layout and colours can be changed.
