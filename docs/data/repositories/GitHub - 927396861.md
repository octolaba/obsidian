# Nitero/obsidian-paste-image-into-property

Paste image into property adds images from the clipboard to frontmatter properties in live preview mode, which the README describes as functionality currently missing in Obsidian and documented in an open feature request. An image pasted while the cursor sits in a text property is saved to the vault's attachment path under the default Obsidian setting, and a link to it is written into the property. The README records the limitations: live preview only, text properties only, no lists or other types, the property's existing content is replaced rather than added to, and no mobile support.
