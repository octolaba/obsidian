# ProcC99/dictcc-sidebar

Looks up a selected German or English word on dict.cc and shows the bilingual translation table in an Obsidian sidebar, started by right-clicking the selection or through a command palette entry. Results are grouped into tables with section headers such as verbs and nouns, and misspelling suggestions can be clicked to re-search instantly. Settings choose the translation direction, either both ways or one of the two single directions, and a slider limits how many rows are displayed. The README states it works in editor and reading view, respects the light and dark themes through CSS variables, is desktop only, and is forked from a wiktionary sidebar plugin.
