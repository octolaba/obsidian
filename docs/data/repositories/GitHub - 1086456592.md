# COGQOD/hoverpopup-obsidian-theme

COGQOD/hoverpopup-obsidian-theme holds the author's personal Obsidian theme, published in case others find it useful. Its README states that the theme is dark only, that some effects apply in preview mode alone because the author prefers a cleaner look while editing, and that it was made because the author likes hover pop-ups. Written in both English and Chinese, it invites others to modify and publish their own versions and warns that the author has limited time to check reported bugs.
