# DominikPieper/obsidian-ReadItLater

The repository holds ReadItLater, an Obsidian plugin that saves web content into the vault as Markdown for later reading or reference. Its README records a distinct handling and template for each content type it recognises, among them website articles, YouTube videos and channels, posts from several social networks, Stack Exchange questions, Pinterest, Vimeo, Bilibili, TikTok, and plain text snippets. It presents a template engine with predefined variables per type as the core of the plugin, and documents an API for other tools; the code is licensed under MIT.
