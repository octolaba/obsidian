# javalent/second-window

Opens a note or an image from the vault in a separate pop-up Obsidian window, from the right-click menu on the file or its link, or through a command. Repeated requests reuse the second window that is already open rather than creating another, so it can be left in place on a second screen, and images are stretched to the window size instead of opening at their default size. The README states that the plugin is in maintenance mode, with pull requests and bugs reviewed but feature requests not worked, and that its documentation has moved to an external site.
