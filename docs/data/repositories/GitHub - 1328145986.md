# likaihz/work-ledger-obsidian

Agent Ledger is a desktop, read-only workspace over a Work Ledger vault: it asks the work-ledger CLI for deterministic read projections and renders them, leaving that CLI the only writer of managed Markdown. Its tabs cover today's focus and recent activity, project and task hierarchy, knowledge documents with filters and a read-only inspector, a date-grouped timeline of journal entries, weekly report readiness with evidence and copy actions, and a health view for CLI, schema, vault and doctor findings. The open vault and the configured CLI vault must share a SHA-256 identity, and business state is cleared before the error is shown when they do not. It needs Obsidian desktop 1.12.0 or later, a schema 5 Work Ledger vault and a compatible harness release, and performs no Git mutations.
