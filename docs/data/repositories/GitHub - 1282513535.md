# ondreu/Hearth

Hearth is an Obsidian plugin that provides a home screen combining search, a dashboard and a launcher. The README records a keyboard-first search field with four modes — fuzzy search over file names, tags, properties and optionally note bodies, tag search, frontmatter key and value search, and a command mode — with recent files offered on an empty field, auto-generated file-type filter chips, a new note button, and an option to route plain queries through the Omnisearch plugin instead of the built-in engine. Below it sits an arrangeable grid of live cards including embeds, web pages, tasks, calendars, statistics, clocks and launchpads, edited in place through an Arrange mode, with support for several dashboards. The README records the home screen opening on startup and replacing empty new tabs, both of which can be turned off, and describes mobile and appearance settings.
