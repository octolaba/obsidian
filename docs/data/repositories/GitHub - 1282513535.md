# ondreu/Hearth

Hearth is a customizable Obsidian home screen combining a dashboard, fuzzy search, and command launcher. It offers a freely arranged grid of live widgets for notes, tasks, Kanban boards, calendars, web pages, statistics, clocks, and launchers, with multiple dashboards and per-card visual settings. Search can cover file names, full text, tags, frontmatter, commands, and auto-detected file types; mobile collapses to a search-focused launcher.
