# davidvkimball/obsidian-oxygen-settings

This settings plugin controls the color schemes of the Oxygen theme for Obsidian and is a fork of Minimal Theme Settings. Its README places it in the Vault CMS project and lists the Oxygen theme as a requirement, with the Style Settings plugin as an optional addition for finer adjustments. Credits in the README attribute the animation effects and the auto-hide behaviour of the file explorer icons and navigation bar to ideas taken from the Baseline, Meridian and Maple themes.
