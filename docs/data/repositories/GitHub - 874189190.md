# markusmo3/obsidian-private-mode

Private Mode blurs files, links and search results tagged as private in Obsidian, showing them temporarily on hover or focus or permanently through a reveal-all command. The README records three modes — reveal all, reveal on hover as the default, and reveal never, which shows private content only for the line being edited — together with a choice about blurring links to private files, a private callout that is blurred and collapsible, commands for setting visibility that also work on mobile, and a desktop status bar indicator that cycles visibility and turns red when Obsidian would be visible in a screen share. It states that the plugin requires the community plugin obsidian_supercharged_links to work.
