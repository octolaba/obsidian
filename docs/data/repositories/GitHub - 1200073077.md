# nithinbekal/obsidian-upcoming-birthdays

Upcoming Birthdays scans a folder you choose for notes carrying a date-of-birth frontmatter property and lists the birthdays that fall within a configurable look-ahead period in a sidebar view. Each entry reports how many days remain and the age the person will turn, birthdays occurring today are highlighted, and clicking a name opens the corresponding note. The property name, the scanned folder and the look-ahead period are settings, with an empty folder value disabling scanning and a single slash scanning the whole vault. The README states that any date format JavaScript can parse is accepted and recommends the ISO form.
