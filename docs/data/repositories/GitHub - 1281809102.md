# caesarloo/render-api

Render API is a desktop-only Obsidian plugin that exposes dataview, Tasks and general Markdown rendering results through a local REST API, so external tools and scripts can read a vault's rendered content programmatically. The README records the permissions this needs and why: a local HTTP server bound to 0.0.0.0, optional calls into the dataview JavaScript API, a read of the system network interfaces to detect a WSL gateway address for the MCP URL, a write of an MCP stdio bridge script into the plugin's own folder on first load, and clipboard access behind a copy button in settings. It states that the detection step sends no data anywhere and that the plugin reaches no external network beyond what the user configures.
