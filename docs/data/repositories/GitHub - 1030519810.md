# churnish/adapt-to-current-view

Obsidian plugin that sets a different accent color for Reading view, Live Preview and Source view. The README gives the purpose as gauging which view is active, so that editing is not attempted in Reading view and footnote behaviour in Live Preview is not a surprise. It notes the effect is clearest with a theme that leans on the accent color, naming Minimal as an example.
