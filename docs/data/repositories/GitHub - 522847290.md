# carlonicora/obsidian-rpg-manager

RPG Manager helps a storyteller plot, run and track tabletop role-playing campaigns inside Obsidian, and is system-agnostic rather than tied to one ruleset. It models a campaign as linked elements — adventures, chapters, events, locations, clues, non-player characters, factions, objects, monsters, subplots, player characters, sessions and scenes — created and edited through the plugin's own interface, with relationships between them, custom attributes, tasks, element templates and global assets. The README is written as a manual covering installation, upgrading a vault from version 3, building a world for different kinds of storyteller including plotters and sandboxers, and running and prepping sessions.
