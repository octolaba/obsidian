# PandoraReads/apex-dashboard

Apex Dashboard provides a single Obsidian workspace for memos, interactive todos, project and note cards, aggregate tasks, calendar views, quick actions, and configurable sections. It can search and organize vault documents, update source-note tasks, read due dates and priorities, and display widgets for weather, heatmaps, Pomodoro sessions, reading, and countdowns. Drag-and-drop layout changes, banners, wikilinks, and custom section types support a personalized dashboard.
