# PandoraReads/apex-dashboard

Obsidian plugin that renders a single dashboard page combining several views of the vault. It carries a memo pad of writable cards, an interactive todo checklist with drag-and-drop reordering and a completion progress bar, project cards that link related documents with a cover image and inline document search, and a compact list section for reference files. An All Tasks section aggregates every checkbox task in the vault, filtered by status and grouped by date or priority as either a grouped list or a kanban board, reading due dates and priorities from inline fields and writing a completion back to the source note. A native month-grid calendar shows dated tasks per day without another plugin, and reads multi-day events from start and end fields.
