# nfoav8or/coder-engram

Coder Engram turns a vault into reviewable memory for the Claude Code agent, stored as plain Markdown under a Claude Code folder. It indexes the vault's notes into a rebuildable local JSON cache, chunks them into heading-aware segments, and retrieves them with BM25 lexical search that works offline, while embeddings and attachment indexing are opt-in. Memory an agent proposes is not written directly: each entry lands in a pending inbox as a card that can be applied, edited and applied, or discarded, with repeated proposals suppressed and promotion append-only and available only in the desktop interface. An optional local server, off by default, lets the agent search memory and propose entries over localhost with token authentication.
