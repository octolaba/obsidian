# CodyBontecou/timemd-visualizer

This plugin reads data exported from the separate time.md screen-time analytics application and presents it inside Obsidian, so an export dropped into a vault folder can be browsed without opening that application. Exports are auto-detected in JSON, CSV, YAML, GitHub-flavored Markdown tables and frontmatter-carrying Markdown, whether nested or flat. Views cover an overview with totals, averages, peak hour, longest session and distribution, trends with stacked per-application and hourly charts, a calendar of daily and hourly heatmaps, session details with timelines, lanes and a filterable raw-session table, applications and categories, projects, web history, reports with export, and opt-in input tracking. Each view opens from the command palette or the ribbon icon, and any view value can also be embedded in a note through a timemd code block.
