# rknastenka/obsidian-mini-notes

Mini Notes displays short notes as coloured cards in a Google Keep-style view, where they can be pinned, tagged, recoloured and dragged into a different order. Left-clicking a card opens a hover editing overlay and right-clicking opens the note in a separate full-screen tab. The search bar filters with `folder:`, `tag:`, `color:`, `type:`, `is:` and `has:` prefixes, and the settings control the source folder, the folder new mini notes are created in, the maximum number of cards displayed and theme colour preferences.
