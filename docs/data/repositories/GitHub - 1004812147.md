# circkumflexx/obsidian-ravenloft-theme

Ravenloft is a dual-mode Obsidian theme with matched light (aged parchment) and dark (midnight library) variants, styled after AD&D 2e Ravenloft. It embeds Open Sans, Literata, Vollkorn SC and Ruslan Display, colour-grades six heading levels and uses muted gothic reds as accents. The README states that it requires Obsidian 1.6.0 or later for the unified search-highlight API, that no CSS snippets are needed, and that mobile has not been extensively tested.
