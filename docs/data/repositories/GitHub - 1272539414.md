# yunusey/obsidian-proton-integration

This plugin bridges Obsidian and Proton Drive using the official Proton drive SDK, and its README states plainly that the project is independent and not affiliated with, endorsed by or sponsored by Proton AG. Its recorded status is an early foundation: browser sign-in with optional session persistence, and Proton drive links embedded in reading view as images, videos or documents, the latter covering inline PDF preview, plain text and Markdown. Embeds are preferably written as proton-drive links built on the canonical node identifier rather than a share identifier from a web URL, because that identity is stable and also covers photo library items. The README cautions that the Proton Drive SDK is still evolving and does not yet ship standalone authentication, so the plugin reproduces the wiring used by the official Drive command-line tool.
