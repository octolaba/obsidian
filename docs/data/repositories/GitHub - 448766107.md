# operator-axel/obsdian_theme--Carpe_Noctem

Carpe Noctem is an Obsidian theme its author describes as a first attempt at making a theme and working with CSS. Its README reads as a short list of intentions rather than a feature list: instructions inside the CSS for modifying icons, a light theme to be added, and fuller plugin and mobile support, with the author noting that it already looks good on their phone and that Andy's Sliding Panes is supported. Nothing about the palette or an installation route is recorded, and the author invites suggestions while continuing to improve it.
