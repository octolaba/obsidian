# TrueNine/tnmsop

TNMSOP opens prompt-focused mdx files in Obsidian as native Markdown notes, with file discovery, editing, links and reading view. In reading view it compiles a static subset of MDX without evaluating JavaScript and without writing derived files into the vault: calls, assignments, dynamic imports and other executable expressions are never run. Values for static expressions resolve from a JSON scope defined in settings, overridden by file frontmatter, which is in turn overridden by static exports, and conditional prompt blocks are supported through Md and Md.Line elements. Compiled previews can be toggled from a vault-level setting, a desktop status icon or a command, and unsupported or invalid MDX falls open rather than failing.
