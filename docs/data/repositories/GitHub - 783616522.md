# xhuajin/obsidian-tabs

This plugin renders a tabs component from a fenced code block marked as tabs, in which each tab is introduced by a line naming it and followed by that tab's Markdown content. The README credits the Code Tab plugin as its inspiration and states that it was rewritten because that plugin had gone without updates and did not allow the content to be edited directly. Tab blocks can be nested by giving the outer block a longer fence or a tilde fence, and the README warns against writing tasks inside a tabs block, because Obsidian treats text in a code block as plain text, so neither the Tasks plugin nor Dataview will recognise them.
