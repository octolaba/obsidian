# soakaye/obsidian-marimo-bridge

Opens and edits marimo notebooks, which are plain Python files, inside Obsidian by starting and managing a local marimo server and embedding its web interface in an Electron webview — as a full editor tab and inline through a marimo code block in editable or read-only mode — with edits written back to the .py file. Markdown notebooks can be opened through an added context-menu entry. The README records servers run headless with a token password and bound to the loopback address, which cannot be changed in settings, process trees terminated cleanly on unload, a settings installer that detects marimo and offers to install it, and a configurable Python interpreter. The plugin is desktop-only because it uses Node child processes and the webview tag, and it requires Obsidian 1.5.7 or newer with Python and marimo installed.
