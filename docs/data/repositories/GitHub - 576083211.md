# micahke/obsidian-gpt3-notes

This plugin generates notes in Obsidian from OpenAI's GPT-3 language model, with support for older language models as well. An OpenAI API key has to be set in the plugin settings before it can be used. Generation is started from the ribbon or from the `Create GPT-3 Note` command, and the README notes that the output may need a small amount of reformatting once inserted into the document.
