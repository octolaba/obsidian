# anandrajbaghel/gate-calculator

This repository holds GATE Calculator, described upstream as a scientific calculator. The README presents it as a floating, draggable calculator widget for Obsidian with more than fifty functions: trigonometric and inverse trigonometric, hyperbolic, logarithms including an arbitrary base, powers and roots, factorial, memory keys, and degree or radian modes. It also lists keyboard input, command palette integration, optional ribbon and status-bar icons, light, dark and system themes, and an auto-close-parentheses option, and states that the plugin works offline with no external services and no data collection.
