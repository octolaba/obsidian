# jaliriogbarrios19/Audio_Transcript

An Obsidian plugin that records audio or transcribes audio files through a third-party transcription API with speaker diarization, and then works on the result with a language model. Its dashboard indexes past transcriptions, offers one-click summaries inserted into the note, a chat that uses transcriptions as context, reusable prompt templates and a choice between fast and deeper models, with eight LLM providers configurable by API key. The README lists Gladia among the transcription providers, notes that the interface language follows Obsidian's own setting, and mixes English and Spanish, as does the repository description.
