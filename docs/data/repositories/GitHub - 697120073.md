# HananoshikaYomaru/Obsidian-Frontmatter-Generator

This repository holds Frontmatter Generator, described upstream as a plugin that generates frontmatter for notes. The README says a template is configured in the settings as JSON or a JavaScript expression returning an object, which is evaluated on save and written into the note's frontmatter. The expression can read the file object, its existing properties and its tags, and can call Dataview, and conditional expressions and inline functions are supported. The README notes that running it on save relies on a separate custom-save plugin and its command.
