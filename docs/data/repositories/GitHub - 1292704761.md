# mrrepac/obsidian-zim-reader

This repository holds ZIM Reader, a desktop-only Obsidian plugin for reading ZIM archives, the format Kiwix uses for offline Wikipedia and other wikis, from a local file with no external server or process. It reads on demand straight from disk, touching only the header, the search indexes and one decompressed cluster at a time, so the README reports that a 38 GB Wikipedia archive opens instantly and uses almost no memory. Articles are found by title and rendered in a theme-aware reading layout with working internal links, images, a random article button and back and forward navigation, and an article can be saved into the vault with its images. Zstandard-compressed archives are supported, while full-text Xapian search is not implemented.
