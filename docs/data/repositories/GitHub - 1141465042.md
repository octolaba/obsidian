# incantatem2/Obsidian-jolly-holly

incantatem2/Obsidian-jolly-holly holds Jolly Holly, a festive Obsidian theme its author wrote after noticing that the gallery's older christmas theme was gone, aimed at christmas, yule, solstice or a general winter aesthetic. It is dark mode only except for Snowflake, which is light mode only, and it offers the Holly, Berries, Snowflake, Cinnamon and Winter Night colour schemes, with callouts kept visible through a normal callout blend mode.
