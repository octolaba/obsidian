# yushen110/obsidian-drive-opener

Drive Opener puts a file manager inside Obsidian: it opens on a drive picker, walks the filesystem folder by folder, and offers search filtering plus in-place preview of images, PDFs and text files. Folders can be compressed to ZIP, 7z or RAR and archives extracted, preferring an installed 7-Zip and falling back to PowerShell, while a batch rename tool applies find-and-replace or presets such as numbering, date prefixes and case changes, previewed before it runs. With WPS Office installed it converts Word, Excel and PowerPoint files to PDF, merges and splits PDFs, prints in batches and converts between formats. Files can be created, moved to the recycle bin, dragged between folders or out of Obsidian, and inserted into the current note as a link or a folder index; the plugin is Windows-only.
