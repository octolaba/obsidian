# obsidian-power-plugins/obsidian-power-tables

Power Tables adds spreadsheet behaviour to the Markdown tables already in a note: cell fills, text colors and highlights, conditional rules, color scales, data bars and icon sets, plus 49 Excel functions driven from a formula bar that completes names and takes references by clicking cells. Sorting, an AutoFilter on every column header, number and currency formats, data validation lists, a fill handle, block copy and paste and Excel's own selection keys are all present, along with cleanup tools such as remove duplicates, text to columns, transpose and a grouping Summarize, and import and export for Excel and CSV. Everything is stored in the file itself, with a cell's content wrapped in one inline span and widths, color rules, filters and value lists riding on the column's header cell, so the table stays plain Markdown and degrades to ordinary text if the plugin is removed.
