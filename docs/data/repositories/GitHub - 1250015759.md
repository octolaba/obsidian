# daren-thomas/trolls-in-the-cellar

Trolls in the Cellar renders random generators written as plain Markdown inside Obsidian: named tables are declared in a troll-food block and a troll-speak block configures what gets rolled, producing an interactive roller with roll and copy buttons in reading view. The block options select the table, the number of results from one to a hundred, list or paragraph output, whether results render as Markdown, and additional notes supplying reusable tables. The table syntax supports rolling a named table, integer ranges, weighting an entry by repetition, choosing between literals or table results, repeating a roll several times, and remembering a result under a name so the same value can be reused. A command rolls the first block in the active note, copies the result and shows it in a notice, which the README offers as the way to roll while editing.
