# namikaze-40p/obsidian-date-inserter

Repository for Date Inserter, an Obsidian plugin that inserts a date at the cursor position using a calendar. The calendar opens from an assigned hotkey or a command, and selecting a day inserts the date in a custom format — the README gives month/day/year, weekday with month-day, and a dotted year.month.day with an abbreviated weekday as examples. A second command copies the chosen date to the clipboard instead of inserting it, and the calendar is built on vanillajs-datepicker, whose documentation defines the format tokens.
