# eluisjonathann/obsidian-link-grouper

Link Grouper is described, in English and Spanish, as a plugin that automatically organizes and groups all linked notes and attachments of the active note into a collision-free sibling folder. The README says it detects internal links and embedded media in the active note, creates a folder beside the note named after it, and appends an incremental number when a folder of that name already exists so nothing is overwritten. Files are relocated through Obsidian's own API, which the README states keeps links across the vault updated. The move is run as a single command from the command palette.
