# weph/obsidian-bookshelf

Bookshelf is a personal bookshelf and reading tracker that gathers a vault's book notes in one place, tracks reading progress and reports on reading habits. The README keeps setup and usage instructions in separate documentation rather than in the repository, so that sentence is the whole of what it says the plugin does. The author states that no generative AI or AI coding agent was used to write the code, and that code contributions are not wanted because reviewing them takes more time than a side project allows.
