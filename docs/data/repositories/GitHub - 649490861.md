# j-palindrome/obsidian-time-ruler

Time Ruler combines a nested task list with an event-based calendar view, so tasks can be dragged to time-block, reschedule or change duration and can be shown on top of read-only online calendars. The README records reading and writing tasks in Day Planner, Dataview inline field and Tasks plugin formats as well as Full Calendar task-events, search and filtering of scheduled, unscheduled and due tasks, creation of tasks at a chosen time by dragging, a list of files and headings to drag from, an integrated timer and stopwatch, and a sound when a task is checked. It states that Dataview has to be installed because Time Ruler reads tasks through it, and names Tasks, FullCalendar, Reminder and Day Planner as the plugins it works with.
