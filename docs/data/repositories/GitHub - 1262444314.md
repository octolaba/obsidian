# MRL-00/poke-obsidian

Poke Gateway connects an Obsidian vault to the Poke service so that Poke can list, search and read notes and, when allowed, write Markdown back. The plugin opens an outbound WebSocket connection to a hosted gateway address, so its README states that no inbound ports, tunnels, local web servers or router changes are needed and that the user hosts nothing. Setup is copying the connection token generated in the plugin settings, adding the Poke recipe on the service side, pasting the token there and waiting for the plugin to report itself connected. The repository holds only the plugin source and release assets, the hosted gateway being maintained separately.
