# WhiskeyJack96/obsidian-agent

An Obsidian plugin implementing an Agent Client Protocol client, so agents such as Claude Code, Gemini CLI, OpenCode or Mistral can be used inside the vault. The README describes streaming multi-turn sessions with mode switching, reading and writing vault files with a side-by-side diff shown before edits are approved, shell command execution with output streaming and process management, and a permission system with inline approval and auto-approve options for trusted operations. Metadata-based automation and an MCP server for Obsidian commands are both marked alpha.
