# joelseq/obsidian-linkstowr

LinkStowr is described as a way to save and organize web links in Obsidian, and its README presents the repository as the Obsidian half of a pair that also includes a Chrome extension. Links are captured with the extension, which stores them against an account and access token created on the LinkStowr site, and the plugin then syncs them into a configured vault folder, optionally through a template file, when a sync command or ribbon icon is used. The README states that once links have synced the service no longer stores them, so the vault holds them, and describes the toolset as free, open source and privacy-friendly.
