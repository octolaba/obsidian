# lengff123/cursor-bridge

Cursor Bridge opens Obsidian notes and folders in the Cursor editor. A file or folder is opened from the command palette, from its right-click menu, or from a sidebar icon for the current file, and the settings hold a custom path to the Cursor executable, whether a new window is opened or an existing one reused, and a default project folder. The README states that Cursor must already be installed and reachable through the system PATH, and that Windows and macOS are supported.
