# pfrankov/obsidian-colored-tags

Colored Tags colorizes tags in different colors so that they can be told apart at a glance, mixing the color of a nested tag with that of its root tag. The README states that text color contrast is matched automatically to comply with AA level of WCAG 2.1, that colors are adjusted for the dark theme, and that colors may change with future updates because the aim is visual distinction rather than a fixed assignment. A per-tag color can be picked from the current palette under experimental tag assignments — custom colors are not supported, and changing palettes moves a tag to the nearest color in the new one — and the interface is available in nine languages selected automatically.
