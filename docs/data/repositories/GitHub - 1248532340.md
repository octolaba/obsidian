# wesswart77/obsidian-songwriter

Repository for Songwriter, a plugin that keeps songs as structured notes. Its README describes creating a song with title, status, key, tempo, time signature, genre, themes and influences in frontmatter, followed by sections for lyrics broken into verses, chorus, bridge and outro, chords, notes and recording ideas. It also records a snippets folder for hooks and unfinished lines, a helper that points to a rhyme dictionary, a sidebar listing songs grouped by status, and settings for both folder locations.
