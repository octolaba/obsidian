# forketyfork/obsidian-speech-bubbles

Repository for Speech Bubbles, a plugin that renders transcript notes as chat-style bubbles in Reading view. Its README records lines written as a speaker name followed by the message, a frontmatter tag that enables rendering, colours per speaker, right alignment for the vault owner, and multiple aliases for one speaker. Further options cover per-speaker colours, text and icon sizes set in frontmatter, inline timestamps, date separators between days, speaker groups for roleplay scenarios, and appearance settings such as bubble width and radius.
