# Admiral9k/emrald-obsidian

EMRALD tracks effort rather than task completion inside Obsidian: focused work sessions, short post-session effort receipts, and daily check-ins on energy and readiness. The README states that the plugin surfaces patterns in effort, flow and recovery over time and signals related to burnout risk, and that it is meant to sit alongside an existing vault workflow rather than replace it. Its sidebar carries a timeblock timer, projects and effort tools, and its workspace views are described as an E-Level overview of the day, an effort profile and a burnout monitor.
