# Admiral9k/emrald-obsidian

EMRALD is an effort-management plugin that records focused work sessions, post-session effort receipts, and daily energy or readiness check-ins inside Obsidian. It surfaces patterns in effort, flow, recovery, capacity, endurance, motivation, and burnout risk through workspace views and an effort profile. Project profiles and forecasting compare predicted effort with logged results, while area grouping organizes projects across a workspace.
