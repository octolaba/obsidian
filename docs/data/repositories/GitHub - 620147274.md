# HeroBlackInk/ultimate-todoist-sync-for-obsidian

This plugin creates tasks in Todoist from Obsidian and synchronizes task state between the two. Its feature table records that adding and deleting a task, and modifying its content, due date, labels, priority and completion state, already work from Obsidian to Todoist, while modifying content, due date, labels, priority, completion state and task comments work in the other direction, with the remaining rows marked as planned rather than shipped. The README describes installation through Obsidian's community plugin browser and updating by the same route.
