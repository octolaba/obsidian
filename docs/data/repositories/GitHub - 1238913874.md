# jiaoyingxing/sidet

Sidet is an AI chat plugin whose conversations open in a main center tab, while the right sidebar holds a session list for creating, searching, pinning, grouping, archiving and exporting chats. Its home page replaces a new empty tab and accepts a question directly or through pinned commands, and the current note, a selection, a web page or an image can be added to a conversation. Knowledge base lookup uses local keyword matching rather than the model, web search generates terms and then reads pages and cites sources, and any result is previewed before it becomes a new note, an append, or a rewrite. Model configurations are stored per provider with API keys kept in Obsidian's SecretStorage, and the plugin requires Obsidian 1.11.4 or later and ships without source code.
