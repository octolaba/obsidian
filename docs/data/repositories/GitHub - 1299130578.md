# wzmf399443/github-pages-share

This repository holds GitHub Pages share, whose README describes publishing Markdown notes from Obsidian to a GitHub repository served through GitHub Pages with Jekyll, and copying the resulting link to the clipboard. Listed behaviour includes single-note and folder publishing, conversion of wikilinks to relative links with unpublished targets falling back to plain text, upload of embedded images to an assets folder, callout and mermaid rendering on the published site, a command that bootstraps a fresh repository, an unpublish command, and optional automatic republishing shortly after a save. No upstream repository description is recorded, so this body rests on the README alone.
