# popscallion/obsidian-no-empty-windows

No Empty Windows is an Obsidian plugin that offers an alternative to the built-in close-current-tab command for people who prefer browser-like behaviour, where closing the last tab closes the window but leaves the application running in the background for a faster relaunch. Its command, Close current tab or empty window, closes the focused tab unless that tab is pinned, in which case a setting decides whether the tab is unpinned or closed outright. When tabs are open across several tab groups or popouts it cycles through them until one remains in the main window, and the README suggests mapping it to the existing close-tab hotkey.
