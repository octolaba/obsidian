# r3215407/obsidian-plugin

Fetches WeChat official-account articles through an API and writes them into the vault as Markdown, taking a single API key as its only configuration. Syncing runs from a ribbon icon, from a command in the palette, or automatically once an hour in the background, with progress reported through notices. Articles land in a dedicated synced-data folder under filenames combining the sync date and the article title, with characters that are unsafe in filenames stripped. Existing files are overwritten when the server copy has changed, and new articles create new files.
