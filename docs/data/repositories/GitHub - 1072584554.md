# mattmarotta/obsidian-url-enricher

URL Enricher renders plain URLs in a note as previews carrying the page title, description and favicon without changing the Markdown source. Two presentation styles are offered, an inline form that hides the URL and flows with the text and a card form that also shows the description and site name, and inline previews revert to editing when the cursor enters the link. Global behaviour is set in the plugin settings and can be overridden per note through frontmatter keys for preview style, maximum lengths, favicon display, description inclusion and color mode. The README states that the plugin works only in Live Preview mode, that image embeds, code blocks and non-HTTP protocols are unsupported, and that some domains receive special handling.
