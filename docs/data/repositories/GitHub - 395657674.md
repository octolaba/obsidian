# nathonius/obsidian-trello

This Obsidian plugin connects Trello cards to notes, so that labels, comments and checklists can be seen and updated from inside Obsidian. A note is linked to a card through the Trello pane or the Connect Trello card command, and a different card can be linked later. Setup requires a Trello API token, and a new card can be created while connecting.
