# No-Instructions/Relay-Comments

Relay Comments stores comments and suggested edits inside the note as plain CriticMarkup, so review state travels with the file and stays readable in any editor without a server. A selection can be commented from a hotkey, margin button or context menu, replies stack into a thread anchored to the passage, and additions, deletions and replacements are accepted or rejected from a hover preview or swept in one pass. A sidebar lists every comment, suggestion and highlight in document order, jumps to the passage on click, and resolves a thread by removing its markup while keeping the text; canvas cards also take pinned comments that open a floating thread. Live Preview and Reading mode hide the raw delimiters while Source mode shows them, and the author name comes from settings or from an identity service when one is installed.
