# nhannht/obsidian-smart-gantt

Smart Gantt finds dated checkbox tasks across an Obsidian vault and displays them in an interactive Gantt chart without plugin-specific task syntax. Users can reschedule or resize bars, change the timeline scale, jump to the source note, or embed a scoped chart in a gantt code block on desktop or mobile.
