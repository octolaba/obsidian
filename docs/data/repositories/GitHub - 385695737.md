# NomarCub/obsidian-copy-url-in-preview

Image Context Menus adds context-menu entries for images in Obsidian's reading view and on canvas: copy the image to the clipboard, copy its URL, open it in the default app, show it in the system explorer, reveal the file in navigation or in File Tree Alternative, open it in a new tab, and rename it. Only copying to the clipboard is offered for online image embeds, and the README states that most features work on mobile but were tested only on Android. Earlier link-URL copying and an external-PDF hover menu were removed once Obsidian gained equivalent native functionality.
