# jdanielmourao/obsidian-sanctum

Sanctum is a minimalist theme for Obsidian.md whose stated aim is a serene space of retreat for thought and uninterrupted work. In the 1.0 release for Obsidian 0.16 sidenotes became callouts, so a left-aligned aside is written as an aside callout and can be pushed further into the margin with up to five plus signs, while images follow a similar syntax and add size options and a centring option. Custom checkboxes were expanded to a long list of marker characters, and many Style Settings options were added. The README warns that the theme significantly alters Obsidian's original CSS, so it is prone to breaking on app updates and may be incompatible with custom snippets.
