# zapthedingbat/drawio-obsidian

Obsidian plugin that adds draw.io diagrams to the app, usable both as stand-alone files and inside notes. Diagrams are created as SVG files, and the .drawio extension is also supported. The README covers inserting a new diagram and editing an existing one.
