# bnchiang96/xiaohongshu-importer

Xiaohongshu Importer brings notes from Xiaohongshu into an Obsidian vault from a share link or share text, extracting the title, the content, images, videos and tags into a Markdown file. It accepts several link shapes, including newer explore URLs, which the README says are normalized to the standard item format during import. Notes are filed into user-defined categories such as Travel or Food, or a default Others category, under a configurable folder hierarchy, and media can either be downloaded into the vault or embedded from its original URLs; a modal takes the share text, the category and the media choice, with defaults set in the settings tab.
