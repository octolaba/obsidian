# 0126-hash/obsidian-research-agent

A conversational research plugin that turns a research question into a workflow of chat, task progress, evidence notes and Markdown deliverables. It connects to the Deep Research Cloud service at research.obclaude.com for account authentication, online search, fact checking and long-running research tasks, and completed results can be exported back into the vault as Markdown. The README documents its network behaviour: the current note or a selection is sent only when the corresponding control is used, and it advises against sending sensitive notes to the cloud service.
