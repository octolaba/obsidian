# caro401/obsidian-buttondown

Obsidian plugin that sends a Markdown note to Buttondown, a tool for producing email newsletters that accepts Markdown and offers an API. Once an API token is entered in the settings, one command creates a new Buttondown draft whose subject is the note's filename and whose body is the note's content, ready to be previewed, scheduled or sent there. The README's privacy section states what the command transmits to the Buttondown API: the API key, the note content, the filename, and any images referenced in the note, which are uploaded to Buttondown's image storage.
