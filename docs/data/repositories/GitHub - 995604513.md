# klaasklee/checkbox-autochecker-obsidian

The repository records no description, so this body rests on the README alone. The README describes automatic synchronisation between parent and child checkboxes in Markdown task lists, updating as the file is typed in and supporting nested lists at several indentation levels. Three modes are documented: a loose mode that only propagates from children up to parents, a partial strict mode in which toggling a parent updates only its unchecked children, and a strict mode in which toggling a parent overwrites all of them. The stated limits are that only standard Markdown files are handled and that embedded Canvas nodes are not modified, although Markdown files embedded in a canvas are.
