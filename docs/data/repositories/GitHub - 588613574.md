# gapmiss/blur

Blur creates obfuscated blocks of text in Obsidian notes. It offers two modes — inline and a code fence — and three methods: blur, which preserves the text and reveals it on hover; brick, which redacts by replacing the text and does not reveal it; and bone, which preserves the text for wire-framing and reveals on hover. Inline use wraps the hidden text in an inline code span with a leading tilde, the surrounding bracket style selecting the method.
