# bcardiff/obsidian-paperish-presentation

Paperish Presentation renders the current note as a deck of minimal, typography-driven slides in a new tab, splitting it at headings, at the second level by default, and at horizontal rules. Because the deck is a projection of the note's reading view, whatever renders there, including callouts, LaTeX, embeds and output from other plugins, renders on the slides as well. Within a slide, content is revealed whole, block by block or list item by list item, a context bar shows the ancestor headings, a sidebar panel lists every slide for jumping, and a long slide's heading can pin to the top. Front matter can override the break level and add a cover slide from a title and description; the deck is a snapshot rather than a live view, so edits need a refresh.
