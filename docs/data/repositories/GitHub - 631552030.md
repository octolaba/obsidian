# numeroflip/obsidian-auto-template-trigger

Obsidian plugin that applies a template when a new note is created. With a single template it is applied automatically, with several a template selector appears, and a template assigned to a folder is applied instead for notes created inside it, with the most specific folder path taking precedence and a disable-prompt option suppressing the selector entirely. The README states it depends on the core Templates plugin being enabled with a templates folder assigned, and that it probably does not work well with other plugins such as Templater or daily notes.
