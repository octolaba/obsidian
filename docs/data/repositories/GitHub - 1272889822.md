# Coffeegerm/hemingway-typewriter-obsidian

The repository holds Hemingway Typewriter, an Obsidian plugin that constrains editing so that text can only be written forward. The README records a lock that blocks cursor movement, delete and undo inside the editor while leaving the rest of Obsidian navigable, options to lock the mouse as well or to keep Backspace available, and a caret placed at the end of a note when switching files; the lock is a single switch that can be turned off. Typewriter scrolling keeps the current line vertically centred, including inside soft-wrapped paragraphs. A focus mode collapses the sidebars and hides the ribbon, tab headers and status bar, narrows and centres the text column and dims text outside the current sentence, and a syntax highlight option colours nouns, verbs, adjectives, adverbs and conjunctions in the editor only.
