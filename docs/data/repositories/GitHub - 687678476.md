# thesamim/TickTickSync

TickTickSync creates tasks in TickTick and synchronizes task state in both directions between Obsidian and TickTick. The README records bidirectional synchronization of tasks and notes, date and time compatibility with the Obsidian Tasks plugin, recurrence syncing and mobile compatibility, and states that the plugin works best when Tasks is installed. Under known issues it records that only the Tasks emoji formats are supported, and a disclaimer states that the plugin was built with the author's own use cases in mind and carries no warranty against data loss or other damage.
