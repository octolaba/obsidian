# gustavczar/local-agent-obsidian-plugin

Local Agent Office turns an Obsidian vault into a set of agents where each agent is itself a Markdown note carrying frontmatter, a system prompt and a connections section; agents are written by hand, from a template or generated from a single sentence, and six starter personas ship with the plugin. They are laid out as a spatial office grouped into rooms by tag, with avatars, connection lines drawn from the notes' links and cards that light up while an agent works. Conversation happens in a side pane, or by writing an agent question inside a note and running a command so the answer lands as a callout. Proposed note creations and edits pass through an approval modal with a preview and a diff, agents record learnings into a memory section of their own note, and the README states the plugin is local-first and telemetry-free.
