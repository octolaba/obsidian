# Quincy-Leo/obsidian-resize-pics

Rescales images in a note to match the body text by rewriting only the width value inside the image reference syntax, leaving the image files themselves untouched. It runs Tesseract OCR over each image, takes a trimmed mean of the recognized line heights as the pixel height of the text baked into the picture, and computes a new width from the ratio between the body font size and that height. The roughly 12 MB Tesseract runtime and its English and Chinese language models are not bundled; they are downloaded from the settings page with SHA-256 verification and can be cleared again along with their stored model entries. It is desktop-only, needs Obsidian 1.4.0 or newer, writes through Vault.process and drops the write if the note changed during detection, and its interface is available in Chinese and English.
