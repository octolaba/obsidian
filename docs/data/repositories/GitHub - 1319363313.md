# xiaowuwu0620/vintage-sticky-canvas

Vintage Sticky Canvas restyles Canvas boards with parchment and dark archive backgrounds, handwritten edge labels in a bundled offline Ma Shan Zheng font, ink-like paths, transparent file-node containers, and alpha-contour shadows for sticky-note PNGs. Styling is scoped per Canvas, applying by default only to boards whose filename carries a vintage marker, with commands to enable, disable or reset an individual board. Producing the illustrated sticky notes themselves needs a separate provider-neutral Skill the plugin installs into the current vault, driven by a file-capable agent; the visual layer alone does not turn plain cards into illustrated notes. Generation fails closed when renderer files are missing, the interface is available in English and Simplified Chinese, and nothing outside the vault is scanned.
