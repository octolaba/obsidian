# o02c/obsidian-tab-navigator

Tab Navigator searches the tabs open in an Obsidian workspace and switches to the one chosen, matching against file name, file path and — each toggleable and enabled by default — frontmatter aliases and frontmatter tags. The search is opened from the command palette or from a hotkey bound to its command, and a second command closes duplicate tabs. The README records a limitation that follows from Obsidian's own behaviour: inactive tabs are by default not loaded until they are clicked, which preserves performance and bounds what a search across all tabs can see.
