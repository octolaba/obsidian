# ampdat/reflow

Converts a PDF in the vault into Markdown on the local machine using a vision model, producing a folder named from the document's own title that holds the note, an images folder of extracted figures and cropped display equations, a metadata file and the source PDF. Display equations arrive as tagged blocks wrapped in double-dollar math, while inline maths is written by the model as single-dollar spans in the paragraph text. Any note can also be exported to EPUB with figures embedded and equations as images, and on macOS handed to Amazon's Send to Kindle application, the only step that sends a document off the machine. It is desktop-only, prefers a WebGPU-capable machine and warns when it falls back to the CPU, and downloads about 1 GB of model weights on first conversion, which with two pinned CDN assets is its only network use.
