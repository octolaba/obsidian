# nutstore/obsidian-nutstore-sync

Obsidian plugin that synchronises notes with Nutstore in both directions over the WebDAV protocol. The README lists incremental transfer of only the changed files, a single sign-on authorisation that avoids entering WebDAV credentials by hand, a visual browser for the remote files, and conflict resolution that compares at character level and can otherwise be resolved by timestamp so the newest file wins. It also records a loose sync mode for vaults holding thousands of notes, a size limit that skips large files, sync status indicators and detailed logs for troubleshooting; the README is written in Chinese and English.
