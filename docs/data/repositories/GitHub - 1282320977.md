# kanade2511/clip-link-obsidian

Obsidian plugin that turns Markdown links written with a clip target into one-click clipboard copies. The README shows entries for a phone number, an email address, a shell command and a prompt, and states that clicking such a link copies the text and shows a confirmation, while ordinary links keep navigating normally. Those links are displayed in cyan to distinguish them, the plugin has no settings, and it works in Reading View and Live Preview.
