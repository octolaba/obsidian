# zhouhua/obsidian-waveform-player

This plugin replaces Obsidian's display of audio files with a waveform player interface. The README records support for audio attachments in formats such as MP3 and WAV and for audio recorded inside Obsidian, and states that once installed the plugin enhances the appearance of every audio file in the vault with no further configuration.
