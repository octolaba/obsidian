# ZackaryW/obsidian-image-inline

Converts images into base64 encoded strings embedded in the note itself, so a pasted or dropped screenshot does not become another attachment file. Inline image content is kept visually collapsed to keep the editor readable, and a setting helps move the cursor out of that data section while editing. Commands convert a local embed or an online image link into an inline image, export an inline image back to the vault as a normal file, and run either conversion in batch over the current note, the current folder or the whole vault. Size thresholds, resizing before inlining and keeping a backup of the original are configurable; the README states the plugin works on mobile as well as desktop.
