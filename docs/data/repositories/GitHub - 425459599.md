# dominikmayer/obsidian-yesterday

This plugin lets a Yesterday journal be created and edited inside Obsidian. Yesterday is a Markdown extension for journal entries, and its README records support for dialogs such as chat transcripts, for dreams, and for media content blocks. The example entry shows a journal note carrying date, location and weather properties, dream text delimited by its own markers, prose, and references to dated image files.
