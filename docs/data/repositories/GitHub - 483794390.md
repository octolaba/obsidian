# XSPGMike/braincache_obsidian

This is a companion plugin for the braincache service that creates flashcards from Obsidian notes. Cards are written in any Markdown file inside a deck block that names the deck and pairs question and answer sections, and images included in a card are uploaded to braincache's server. Pressing the ribbon button or running the sync command synchronises the local cards with the account, after logging in with an Obsidian token copied from the braincache settings page. The README states that the plugin is at an extremely early stage of development and that bugs are expected.
