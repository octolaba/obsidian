# randomusername21349/cognia-noir

Cognia Noir is an Obsidian theme with paired dark and light modes modelled on Notion's surface palette, using Inter for interface chrome, SF Pro for note bodies and SF Mono for code. With the Translucent Window option on macOS it paints sidebars and chrome over the system NSVisualEffectView so the desktop wallpaper shows through, and it opts Excalidraw, Smart Connections and Canvas leaves out of that force-paint. The README records WCAG AA contrast on primary text, accent and inline code across its background options, respect for reduced-motion preferences, and 100ms hover and focus feedback. Compatibility is stated as Obsidian 1.5.0 or later, designed and tested on macOS only with Windows and Linux unverified, and mobile supported on both iPad and phone.
