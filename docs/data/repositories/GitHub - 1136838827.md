# mssoftjp/obsidian-copy-this-note

The repository holds Copy This Note, an Obsidian plugin that copies a whole note to the clipboard as Markdown without selecting its text. Four presets decide whether the filename and the frontmatter properties are included or only the body, and they run from the command palette or from the editor and file explorer context menus, which can also copy a note that is not open. The README states that the plugin works on desktop and mobile, requires Obsidian 1.8.0 or later, and is fully offline with no network access and no telemetry.
