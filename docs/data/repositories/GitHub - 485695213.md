# cakechaser/obsidian-release-timeline

The repository holds Release Timeline, an Obsidian plugin that arranges notes on a timeline by a year read from their metadata, taking a Wikipedia release-year template as its model. Its README records that the plugin requires Dataview to be installed and that its query syntax is compatible with Dataview's, so any query written for it must also be a valid Dataview query. Three block types are documented, producing year, month and week timelines, and several date formats are accepted, from a bare year to a full date.
