# donivatamazondotcom/obsidian-agent-console

Obsidian plugin that connects a vault to agents over the Agent Client Protocol, naming Claude Code, Codex, Gemini CLI, Kiro CLI and any custom ACP agent. Notes are supplied as context by pinning them in a context strip or mentioning them with @, and the agent also reads the notes those link to; it can write back into the vault, with the user approving what runs. Agents work asynchronously in separate tabs, each showing whether it is ready, busy or waiting, so several run at once, and the model or mode is switchable per tab mid-chat. Typing a slash runs the agent's own commands.
