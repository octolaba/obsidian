# 2JIHAN/canvas-card-info

Adds a Copy card info entry to the right-click menu of a card on an Obsidian Canvas, putting that card's data on the clipboard. The README states that several cards can be selected and copied at once, and that the settings choose between readable text, raw JSON or both as the copy format and toggle the notice shown after a copy.
