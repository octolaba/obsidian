# JichouP/obsidian-marp-plugin

This plugin brings Marp to Obsidian, opening a preview of the selected Markdown file from the ribbon or a command and reloading it automatically when the file is saved. The README states that exporting to PDF, PPTX or HTML requires Node to be installed because the plugin shells out to npx, and that output always goes to the Downloads directory. On export, images are converted to Base64 and embedded so slides can be shared, both wikilink and CommonMark image syntax are accepted, and settings cover auto reload, opening the preview in a split tab, and the theme folder location.
