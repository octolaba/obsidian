# zhouhua/obsidian-vconsole

This plugin embeds vConsole, Tencent's in-page debugging console, into Obsidian so that mobile plugins can be debugged without the separate Android and iOS tooling that would otherwise be needed. It exposes vConsole's panels: logs from the console methods, network activity covering XMLHttpRequest, Fetch and sendBeacon, an HTML element tree, storage covering cookies, local storage and session storage, and manual execution of JavaScript commands. The README states plainly that anyone who is not a developer and does not need to troubleshoot plugin bugs should not install it, and points to the vConsole project for further information.
