# alethiophile/obsidian-hard-wrap

Hard Line Wrap is an Obsidian plugin that stores Markdown files hard-wrapped on disk at a configurable column, 80 by default, while the editor sees each paragraph as one long line and wraps it visually. The README records a global toggle and column width between 40 and 200, a per-file frontmatter key that sets a different width, enables the default or disables wrapping for that file, and a command that reformats the current file by unwrapping, wrapping and unwrapping again to normalise breaks the plugin did not insert. Implementation is recorded as monkey-patching three MarkdownView methods so that content is joined on load, re-wrapped on every save path and re-unwrapped when switching back to source mode; the README explains that patching the view-data getter keeps Obsidian's three-way merge and change detection consistent.
