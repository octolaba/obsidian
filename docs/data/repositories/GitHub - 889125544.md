# 0xPrashanthSec/password-audit

Password Audit analyses the strength of a password typed into its panel and checks whether that password appears in known data breaches, using the Have I Been Pwned service. It also generates passwords of a customizable length and copies a generated password to the clipboard. The panel is opened from the command palette, and password generation is available as a command of its own.
