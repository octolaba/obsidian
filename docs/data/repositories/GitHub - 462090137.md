# geoffreysflaminglasersword/obsidian-living-graph

The repository holds Living Graph, a plugin the author describes as made for fun, which animates Obsidian's graph view. Its README records twelve presets, chosen in the plugin settings, and a command that toggles the effect on and off. It also states a cost: because the plugin only changes graph parameters and has no control over the graph backend, it is likely to make the machine's fans work.
