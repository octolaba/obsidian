# liuboacean/obsidian-local-sync-plugin

The repository description is written in Chinese and names a local-network bidirectional sync plugin for Obsidian built on Yjs CRDT with PSK authentication and UDP discovery. The README describes peer-to-peer WebSocket or WSS sync between vaults on one network, CRDT merging of concurrent text edits without manual conflict resolution, TLS transport with auto-generated certificates and certificate pin verification, and UDP broadcast discovery so no address has to be typed. It also records PSK challenge-response authentication, path-traversal protection against rogue file writes, selective sync that excludes chosen folders and file types, and separate file-writing behaviour on macOS, Linux and Windows.
