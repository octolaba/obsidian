# dotknewt/bonsai-almanac

Tracks bonsai care windows from species notes kept in a folder of the vault, each note carrying frontmatter for the species and one heading per care task with a category and start and end dates. An Almanac view lists the upcoming windows across all species, grouped into open now, coming up and completed, alongside a per-species care plan whose check-offs are stored in the plugin's own data file rather than written back into the notes. An omitted end date falls back to a typical span for the task's category, and the view refreshes as species notes are created, edited, renamed or deleted. A command copies bundled species templates, ported from the upstream bonsai app this plugin follows, into the configured folder.
