# one-spread/image-workflow

Image Workflow is an image-centred plugin for Obsidian: clicking an image in a note opens it in a dark overlay with mouse-wheel zoom that snaps at 100 percent, and the overlay is dismissed by clicking the background or pressing Escape. From there an image can be copied as PNG, saved to disk, or have its vault path copied. Copying a Markdown selection that contains image embeds writes both plain Markdown and an HTML version with the images inlined as base64 data URLs, so the README states that a paste into Gmail, Google Docs or Slack shows the images; pasting that same clipboard back into Obsidian restores the original embed syntax instead of the base64 text. A separate command renders the selection through Obsidian's Markdown renderer first, keeping headings, lists and callouts in the rich HTML.
