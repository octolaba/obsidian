# trashhalo/obsidian-extract-url

Replaces a URL with the Markdown extracted from the page it points at, when the site allows it. It works on a selected URL in the document, on a document whose frontmatter carries a link key, where everything below the frontmatter is replaced, and in an archive mode that extracts every external Markdown link in the document into files under an archive folder and rewrites the links to internal ones. Commands cover full extraction, a title-only variant that leaves a Markdown anchor, and import from the clipboard at the cursor. The README states that extra details such as channel name are extracted for YouTube URLs when youtube-dl is installed on the system.
