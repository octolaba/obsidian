# sundevista/local-quotes

Local Quotes collects quotes from across an Obsidian vault and embeds them in other locations, renewing them after a chosen interval. The README records quote listings, renewal by minute, day, week or month, custom classes applied to every quote, a configurable quote format, a refresh button that fetches new content immediately, and quotes updating in real time. It states that the plugin is in maintenance mode, with no new features planned but bugs still fixed.
