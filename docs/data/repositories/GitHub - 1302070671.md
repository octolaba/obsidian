# sjhealthadvising-prog/vault-galaxy

Vault Galaxy renders an Obsidian vault as an animated galaxy driven by its real link structure: the most important notes sit at the centre as suns, hub notes orbit them, and every other note orbits whatever it is most linked to, with orbit distance set by how many links a note shares with its parent. Two view modes are documented — a galaxy mode in which unlinked notes fill a rotating spiral disc with Kepler-style differential rotation, and an expand mode in which each folder becomes its own labelled satellite cluster. The camera can be cycled from flat to two tilted pitches while the simulation stays two-dimensional, and suns and hubs can be flared with layered coronas. Dragging a node tugs its linked neighbours in proportion to link weight and second-order neighbours less, while unlinked notes do not move.
