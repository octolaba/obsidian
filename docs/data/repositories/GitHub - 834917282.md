# dldisud/obsidian-korean-spellchecker

The Korean README describes an Obsidian plugin that checks Korean spelling, spacing and grammar in text selected in the editor, using the API of the spellchecker developed jointly by Pusan National University's artificial intelligence laboratory and Nara Info Tech. A modal shows the original text beside a corrected preview, lists each detected error with suggestions as radio buttons or a free-text correction, updates the preview immediately, and on confirmation replaces the selected text; long results are split across pages. A user dictionary of proper nouns such as personal names, places, brands and technical terms is excluded from checking, long text is divided internally so that it can still be checked, and the interface follows Obsidian's light or dark theme. Installation is documented as copying a release's files into a plugin folder and enabling the plugin.
