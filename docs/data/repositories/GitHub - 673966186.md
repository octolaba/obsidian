# AlexCCavaco/obsidian-exercises

Obsidian plugin for writing interactive exercises alongside notes, aimed at exam preparation, language learning and revision. Exercises are written inside a block component mixing ordinary text with exercise elements: a select element offering options in randomised order with one or more marked correct by a leading asterisk, an input element and its wider line variant evaluating one or more accepted answers, and a match element pairing values from two randomised columns. On reveal the first listed correct value is the one shown.
