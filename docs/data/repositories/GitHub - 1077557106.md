# loglux/auto-math-for-obsidian

An Obsidian plugin that expands LaTeX-style math snippets as you type, so triggers such as \frac, \sqrt and \sum become ready-to-edit templates without leaving the editor. Expansions live in a user-editable rules.json inside the plugin folder, reload live when that file changes, and can also be edited from a rules editor in the plugin settings; a built-in pack covers 38 LaTeX commands. Multiline environments such as \align expand across several lines, an optional context-aware mode chooses compact or display integral forms depending on the surrounding math delimiters, and the plugin toggles from the ribbon icon or the command palette.
