# ibrh96-prog/obsidian-watch-later-synthesizer

The repository carries no description; its README presents Watch Later Synthesizer as an Obsidian plugin that triages a YouTube watch-later backlog into per-video watch or skip verdicts, recurring themes across the pile, and a list of what is safe to delete. Videos are expected as notes produced by the official Web Clipper carrying frontmatter with url, title, channel, published and duration plus a description section, with a fallback that scans a running-list note for bare YouTube URLs, and missing fields are filled in through oEmbed using Obsidian's built-in request helper. The README states that no transcripts are fetched because caption requests are blocked, so verdicts rest on metadata alone, and that the safe-to-delete list is conservative and never includes stale but substantive videos. Two commands sync the videos and generate the triage report note.
