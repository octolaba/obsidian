# jwy600/obsidian-coo

The repository holds coo, an Obsidian plugin that puts questions about a passage into the note itself rather than in a separate chat window. Selecting text and opening its composer asks a question about the passage, and the answer is stored as a collapsed callout below the paragraph whose title is the question, with follow-up questions chaining because the plugin keeps the note's earlier exchanges as context. A rewrite action folds the gathered notes back into the paragraph and removes them, and the README states that the step is undoable.
