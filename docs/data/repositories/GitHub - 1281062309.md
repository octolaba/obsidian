# dsebastien/obsidian-kanban-action-planner

Kanban Action Planner adds a Kanban board view to Obsidian Bases, so any set of notes becomes a board whose columns come from a status property the user defines. Cards are dragged, reordered, coloured and filtered as you type, relationships between notes are shown and edited, blocked work is surfaced, and every change is written back to the note's frontmatter. The same board flips into a calendar plotting scheduled dates and deadlines, a timeline placing each card by start date and estimate, or a work-breakdown tree where estimates, progress and dates roll up, and views can be split into swimlanes, sliced by GTD contexts or embedded in a note. Per-note-type automation rules update progress, dates, tags or a note's folder when a card enters a done state, and the README states that the plugin requires Obsidian 1.12 or newer and is desktop only.
