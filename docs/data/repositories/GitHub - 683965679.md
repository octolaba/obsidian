# pulsovi/obsidian_eml_reader

Obsidian plugin that renders the contents of an .eml email file inline in reading view, in the same way an image embed is rendered. The file is embedded like an image, and the frame dimensions can be given after a pipe in the link, where a single number is read as the height and unspecified dimensions are detected automatically. The README contrasts this with plugins that convert an email into Markdown inside the note, noting that the converted text becomes searchable while the embedded email does not.
