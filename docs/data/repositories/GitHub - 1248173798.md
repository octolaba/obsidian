# Abdur-Nur-Porag/CEvent-Planner-Extra

This repository holds CEvent Planner Extra, a helper plugin providing a form for composing an event and copying it as formatted Markdown. The modal opens from the command palette or a ribbon icon and covers title and date, single or multi-day scheduling, time ranges, alarms, icons, tags, notes and recurrence, generating a checkbox entry with indented attribute lines. Nothing is written to a file: the generated text is copied to the clipboard and pasted wherever the user wants. The README states that the main CEvent Planner plugin must be installed for the generated events to be tracked.
