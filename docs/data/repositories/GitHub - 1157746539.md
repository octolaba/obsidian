# kinn00kinn/LatteLogic

kinn00kinn/LatteLogic holds LatteLogic, an Obsidian theme aimed at structured notes such as engineering logs, research notes, project documents and study journals. Its headings step down through decreasing border weight and indentation so that nested structure stays visible in Reading view, Live Preview and Source mode, and it uses Obsidian's own accent colour rather than defining one. The README also describes header shading and alternating rows in tables, squared edges on tabs, tags and quotes, and tighter heading indentation on narrow screens.
