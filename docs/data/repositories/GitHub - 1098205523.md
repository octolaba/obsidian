# alangrainger/obsidian-task-zero

Task Zero is a keyboard-first GTD task management system for Obsidian, whose author states the interface will be familiar to users of MyLifeOrganized. Its stated goals are to reduce friction, to manage everything from a single main task page, to make every action reachable by keyboard shortcut, and to let other plugins and scripts work with the tasks through an API. The README notes that version 2 is a significant upgrade for people using multiple devices, and that at the time of writing the plugin is still in the review process and is installed through BRAT rather than the plugin store.
