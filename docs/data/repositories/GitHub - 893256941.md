# talwrii/plugin-repl

Plugin REPL adds a read evaluate print loop to Obsidian: a JavaScript expression written on a line in a document is executed with a single key press and its result is shown in the document. The executed code can drive Obsidian's plugin API to move the cursor, insert text or open files, and working code can then be defined as a new command directly in JavaScript. The README presents this as a way to automate tasks from within notes and to iterate on plugin code without reloading, and it supplies convenience functions partly inspired by Emacs. It also states that the project is not affiliated with Obsidian.
