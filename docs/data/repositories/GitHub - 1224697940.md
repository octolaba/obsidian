# nejimakibird/model-weave

Model Weave reads design information written in Markdown and presents it as diagrams, previews, diagnostics and source links, treating the Markdown files themselves as the source of truth. From them it generates ER and class diagrams, data flow diagrams and data object definitions, application process business flows, screen definitions and business rules, and detects relationships and dependencies across the design for impact analysis. The README records a vault-wide diagnostics pass that runs a static check after rebuilding the full index without rendering diagrams, qualified rule-condition references resolved through completion and impact analysis, and a preview focus mode that expands a single preview into an overlay.
