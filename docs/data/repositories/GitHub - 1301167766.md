# dandersondev/visual-notes

Visual Notes adds a visual workspace to Obsidian in the form of boards carrying icon tiles, a freeform canvas, kanban, tables, sticky notes, checklists, callouts, maps and colour swatches. Everything is stored in a spec-compliant canvas file in the vault, and boards nest inside each other and inside Obsidian's own native Canvas files. In grid mode a tile opens a folder, note, canvas, kanban file or nested board, and each tile's Lucide icon or emoji, background colour, label and subtitle can be customised or replaced with a cover image from the vault or a URL. The README documents fifteen bundled starter templates, saving any board as a template, and group templates made from a selected cluster of cards and dropped onto any board.
