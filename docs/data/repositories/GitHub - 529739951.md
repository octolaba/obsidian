# prncc/obsidian-repeat-plugin

Repeat brings notes back for review on a schedule recorded in their own frontmatter: a note carrying a repeat property becomes due according to that value and appears in a dedicated Repeat view, opened from a ribbon icon or a command. The property accepts periodic intervals such as daily, weekly, monthly and yearly, every N days or weeks, and named weekdays, or spaced repetition when the value begins with spaced, in which case the next review is chosen during each review. Other recorded options obscure the note body during a review until it is clicked, move a review to the evening, or disable repetition entirely. The quick start asks for Dataview to be installed alongside it, and the README notes that keeping all repetition state in frontmatter makes it readable and editable.
