# Ankush-Chander/obsidian-entity-linker

Obsidian plugin that links terms in notes to entries in standard entity databases. Two commands drive it: one searches using the selected text, the other using the active note's title, and both offer matching entities and create an entity note for the chosen one. The README names Wikidata, Wikipedia and OpenAlex as the targets and records the OpenAlex API as the search backend, so the plugin depends on that external service.
