# lclaboissiere-oss/deep-space-glass

Deep Space Glass is a dark Obsidian theme built on a near-black ground with a cyan, violet and magenta aurora behind a fine technical grid, with callouts, tables, code blocks and properties rendered as translucent glass cards. Its accent runs from cyan through indigo to violet across the active tab, checkboxes, buttons and highlights, bold text glows cyan and italics turn magenta, and contrast is stated as AA or AAA for the main text and background pairs. Headings use Chakra Petch, body text Inter and code JetBrains Mono, all loaded from Google Fonts, so the first load needs a network connection. An optional companion snippet colors top-level folders in the file explorer through a five-color cycle.
