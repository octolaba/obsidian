# junghyunbak/graph-scroll-pan

Graph Scroll Pan is an Obsidian plugin that makes scrolling pan the graph view instead of zooming it, moving zoom onto pinch gestures and Cmd or Ctrl with scroll. The README records the mapping — scroll or two-finger swipe pans, pinch or modifier-scroll zooms — notes that macOS trackpad pinches arrive as modified wheel events so they work automatically, and records optional plus and minus buttons in the corner of the graph that always zoom around the centre. Settings record pan and zoom speed multipliers, whether zoom follows the pointer or the view centre, horizontal and vertical inversion, and whether the zoom buttons are shown. The README states the plugin works in the global and local graph views, is desktop-only, and drives internal renderer APIs that are not part of the public plugin API.
