# bramses/obsidian-stack-overflow

This plugin fetches answers from Stack Overflow and pastes them into a note. The default hotkey for inserting an answer is command-shift-v, and it can be changed in the community plugins section. The README credits another plugin for the URL and cursor replacement code it reuses.
