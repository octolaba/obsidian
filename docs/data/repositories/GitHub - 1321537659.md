# Z-Mackintosh/playdown

Playdown turns a set of notes into an ordered playlist for sequential reading: playlists can be created, renamed and deleted, imported from the wikilinks in the current note, and exported back to Markdown as one link per line. Navigation commands move to the previous or next note or start from the beginning, a reading mark records the current position and can be returned to later, and queue order is changed by drag and drop or with Alt and the arrow keys. A sidebar panel holds the progress bar, the current note, playlist management and the queue, and the panel's interface text is currently Chinese while the command names are English.
