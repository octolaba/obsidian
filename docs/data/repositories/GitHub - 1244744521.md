# Admiral9k/emrald-obsidian-theme

Admiral9k/emrald-obsidian-theme holds Emrald, a theme built around deep emerald and warm gold and offered as a match for the EMRALD Obsidian plugin. Dark mode uses emerald backgrounds with emerald and gold accents while light mode uses warm paper tones with dark emerald text, and both cover CodeMirror 6 syntax highlighting, blockquotes, callouts, tables and emerald-tinted inline code. Customization requires the Style Settings plugin, which exposes dark mode surface contrast, light mode gold intensity, header accent style, link emphasis and dark mode text warmth.
