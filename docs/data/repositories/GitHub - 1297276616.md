# ghh-l-djl/markdown2card

The markdown2card plugin renders the active Markdown note as exportable social-card images inside its own preview view in Obsidian. The README records fixed-ratio cards with live preview, automatic pagination by the actual rendered card height so content is not silently clipped, syntax-highlighted code blocks and LaTeX formulas, and rendering of embedded images and Mermaid diagrams, where a long portrait image is given a dedicated card. A settings sidebar switches themes, background styles and fonts, adjusts footer visibility and offers copy or export actions.
