# shitcoding/obsidian_tabjump

TabJump switches between the two most recently active Obsidian tabs, the behaviour its README compares to Alt-Tab, and also moves the current tab left or right in the tab bar. Its three commands can be given hotkeys directly in the plugin settings instead of through the Hotkeys pane, and the README shows how to bind them from a vimrc file through exmap and obcommand. It records that the plugin uses the current Obsidian API rather than the deprecated activeLeaf, is mobile compatible, and handles closed tabs, split panes and boundary cases.
