# KJH-Portfolio/202604-obsidian-task-manager

This repository holds Life OS Task Manager, an Obsidian task plugin edited through dedicated popup modals for todo items, routines and project execution tasks instead of by hand-editing raw markdown; the repository records no description, so this summary follows the README alone. The README records real-time two-way syncing between the daily schedule or project modals and the original project notes, coloured borders marking deadline urgency from overdue through three days out, and indented child tasks inheriting their parent's deadline. A freely editable plan section holds project roadmaps and analysis, with a button that promotes a plan item into execution, and the interface is available in English and Korean.
