# christian-luger-at/obsidian-clew

Clew adds a second graph view in which every note is a node and every link an edge, and runs analytics over it - betweenness centrality, PageRank, community detection and connected components - whose results drive filtering, node color and node size. A Diagnostics panel lists orphan notes, broken links and clusters cut off from the rest, while community-based criteria compare how recently each group was edited and how well groups line up with the folder layout. Force, Radial and Focus layouts show the vault as a whole, by hop distance from one note, or as a single neighbourhood; a Timeline panel replays notes and links in creation order, and a path finder traces a route between two notes while avoiding large hub notes. It opens from the ribbon or a command, builds itself with no configuration, and never edits notes.
