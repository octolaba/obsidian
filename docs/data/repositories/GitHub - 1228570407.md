# ryukyuhub/obsidian-claude-panel-ryukyuhub

Obsidian plugin that adds a Claude Code chat panel to the right sidebar, provided by Ryukyu HUB. The README states that it spawns the claude command-line tool as a subprocess with the active vault as its working directory, so reading, writing, searching and running commands over the notes happen inside Obsidian, and that it is desktop-only and needs that CLI installed and signed in. Listed behaviour includes streaming replies with tool-use pills and per-turn cost, duration and token usage, automatic mention of the active note or folder, captured editor selections, clickable rendering of choice and yes-or-no questions, and session resumption.
