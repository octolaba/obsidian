# HyoYoonNam/image-paste-on-github

Image Paste on GitHub intercepts images pasted or dropped into an Obsidian note, commits them to a GitHub repository the user controls, and inserts a `raw.githubusercontent.com` link, so nothing is written into the vault. Settings take the repository owner and name first and can create a new repository, then a token scoped to it. The README states the consequences plainly: the target repository must be public because raw links render without a token only for public repositories, so every pasted image becomes publicly accessible and sensitive screenshots should not be pasted. It recommends a fine-grained personal access token limited to that one repository with contents read and write and an expiry date, and warns that the token is stored unencrypted in the plugin's `data.json`, which should not be synced, committed or shared.
