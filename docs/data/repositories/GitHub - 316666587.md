# deathau/maximise-active-pane-obsidian

This Obsidian plugin fills the workspace with the active pane, toggled by a default keyboard shortcut that maximises or restores it. The README states that the repository's API targets an early Obsidian version, that custom plugins need at least that version, and that the plugin is experimental so parts might not work. Installation is documented both from the community plugin browser inside Obsidian and by extracting the release into the vault's plugins folder.
