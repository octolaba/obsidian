# 1095327780/FLOWnote

FLOWnote is an AI note workbench for Obsidian: opening it shows a personal dashboard that gathers quick capture, the daily plan, project progress, knowledge statistics, AI chat and skill workflows in one space. It runs on the desktop and on mobile using an API key the user supplies, with OpenCode kept as an optional desktop bridge, and model providers include OpenRouter and a local Ollama mode whose desktop-only localhost limitation is handled by a separate mobile model configuration. The dashboard reads the real daily note, lets its checkboxes be ticked back into the Markdown, aggregates projects with status, priority, counts and due dates, and draws a yearly heatmap of capture activity. Built-in Skills are updated by the plugin and read-only, while users may add, import and edit their own; the README is written in Chinese with English and Russian versions linked.
