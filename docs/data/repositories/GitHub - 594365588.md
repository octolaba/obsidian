# frank0713/nightingale-obsidian

Nightingale is a theme for Obsidian whose README states that it only works well in the dark colour scheme. The README documents heading hints from H1 to H6 shown when the title is hovered, styling for a fixed list of tag names covering notes, books, ideas, information, work, study and finance, and an extended set of checkbox markers beyond the default todo and completed states. Installation is manual, by copying Nightingale.css into the vault's themes folder and selecting the theme with the dark colour scheme chosen.
