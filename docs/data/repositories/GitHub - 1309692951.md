# luhaifeng666/obsidian-docs-sync

Repository for Docs Sync, an Obsidian plugin that synchronises notes and small attachments through a branch of a private GitHub repository, on desktop and mobile without a Git CLI or Electron dependency. The README lists one verified commit per sync operation, optimistic branch-head checks with no force pushes, three-way change detection from the last successful common commit, conflict copies that keep both versions, remote deletions routed to the Obsidian trash, and exclusion of `.obsidian`, `.trash`, `.git` and oversized files. It states that GitHub tokens are stored with Obsidian Secret Storage rather than plugin data, warns against running it beside another synchronisation tool, and notes that automatic sync is disabled by default.
