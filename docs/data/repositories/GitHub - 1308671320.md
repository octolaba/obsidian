# MrMupfel/FinKey

FinKey renders sankey diagrams from a fenced finkey code block, where each line names a source node, a target node and a value, and lines beginning with a double slash are comments. Nodes can be dragged into place, and the generated positions are written back into the block as a comment line that can be deleted to reset the layout. The automatic relaxation algorithm can be disabled in settings, in which case the diagram keeps the order in which nodes appear in the block. Hovering a link highlights the flow and shows how much remains in each node.
