# addozhang/obsidian-image-upload-toolkit

Uploads the local images embedded in a note to a remote store and rewrites the note's links to the uploaded addresses, so the Markdown can be published to a static site. Ten storage services are supported, among them Imgur, GitHub, Cloudflare R2, AWS S3, Aliyun OSS, TencentCloud COS, Qiniu Kodo, ImageKit, Backblaze B2 and Gyazo. It recognizes both Markdown and wiki link formats, handles PNG, JPG, GIF, SVG, WebP and Excalidraw files, uploads in batches with an optional progress modal, and can re-upload web images or convert mermaid diagrams to PNG during publish. The README states that the plugin is desktop only.
