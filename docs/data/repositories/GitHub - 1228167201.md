# FlatulentFowl/docdrop

DocDrop converts documents, spreadsheets, images and other files in a vault to Markdown by driving Microsoft's MarkItDown command-line tool. The README lists PDF, Word, PowerPoint, Excel, image, HTML, CSV, JSON, XML, EPUB, ZIP and audio inputs, and states that conversion runs entirely on the local machine unless the optional AI features are enabled. It requires Obsidian 1.0.0 or later on desktop only, because the plugin uses the Node.js child process API, plus Python 3.10 or newer with MarkItDown installed and ffmpeg for audio. Conversion starts from the file explorer's right-click menu or a command that converts the active file, and the output is written beside the source file or into a configured folder.
