# bgarciamoura/obsidian-tcg-binder

TCG Binder tracks a Pokemon trading card collection, builds decks and browses cards inside an Obsidian vault, storing every collection, deck and card as an ordinary note with frontmatter. The README records pasting a TCG Live style list to import many cards at once, CSV import from ManaBox, Collectr and TCG Collector, searching the card database by name or by set and number, and set collections that generate a full checklist with a completion bar. It also records variant lines per card for normal, holo, reverse holo and promo with inline editing and automatic merging, a cost-to-complete figure computed from live market prices, and hand-written notes counting as valid cards when they carry the right frontmatter.
