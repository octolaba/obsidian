# watsonbox/obsidian-strava-sync

This plugin brings Strava activities into an Obsidian vault, importing the CSV files of a Strava bulk export for historical activities and fetching recent ones through the Strava API. Imported activities are rendered through Handlebars templates with customizable frontmatter properties, which the README aims at Dataview integration, and per-sport icons are supplied for use with Iconize. The README states that the plugin is neither a data backup nor a replacement for the Strava applications: its purpose is to let activities be referenced, tracked and visualized inside Obsidian, and it documents installation from the community browser and of beta versions through BRAT.
