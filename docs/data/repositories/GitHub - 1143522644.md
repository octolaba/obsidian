# cparsell/sidenotes

Renders notes in the page margin rather than at the foot of the document, in the manner of Tufte-style sidenotes. Numbered sidenotes and un-numbered margin notes can be written either as HTML spans or as Markdown footnotes, are inserted by command, show in both editing and reading modes while source mode keeps the bare markup, and can be edited directly in the margin. Numbering increments automatically and can be shown as Arabic or Roman numerals, letters or badges, hidden, or restarted at each heading, and a single note can be pinned to the margin opposite the global side. The layout is responsive, shrinking type and finally hiding the margin as width drops, avoiding collisions between neighboring notes, and PDF export places notes in the margin too.
