# vbeskrovnov/obsidian-contacts

Obsidian plugin for organising and managing contacts inside a vault: a note holds the contact information, and the plugin searches and sorts across those notes. Its recorded purpose also covers remembering the birthdays of contacts and keeping track of the last time each was met. The README documents installation from the community plugins browser with safe mode disabled, or manually by copying release files into a plugin directory in the vault.
