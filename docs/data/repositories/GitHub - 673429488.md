# red0orange/obsidian-webdav-file-explorer

This plugin browses files held on any WebDAV-accessible network disk or cloud storage from inside Obsidian, for the kind of material the README says is inconvenient to manage in a vault, such as archives, videos and pptx documents. It reads the WebDAV directory and shows it as a file tree, and it creates a fully symmetric tree of Markdown files in a local folder, where each file can carry a description of its remote counterpart for later retrieval. Settings take the WebDAV path, a remote directory acting as the root, and the local root folder under which the symmetric notes are created.
