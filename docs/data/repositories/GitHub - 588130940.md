# jrymk/restore-tab-key

Restore Tab Key makes the tab key insert a tab character, which the README says Obsidian otherwise offers no way to do without cutting and pasting, and aims to give tabs and indentation the behaviour expected from a code editor. A setting confines the change to code blocks, another chooses spaces instead of tabs, and selecting text and pressing tab indents through Obsidian's own native indent command, so the indent size and tab preference remain those of the editor settings. Further recorded behaviour includes automatic indentation after braces and an option to insert hard spaces, which stay visible because repeated ordinary spaces and tabs are rendered as one.
