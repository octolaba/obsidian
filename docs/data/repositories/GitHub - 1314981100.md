# thomas-hochbichler/obsidian-remarkable-tagged-sync

Tagged Sync for reMarkable is an unofficial plugin that pulls items tagged on a reMarkable tablet into a mapped vault folder as Markdown, one way only and never writing back to the device. A synced notebook arrives with its pages embedded as drawn plus a transcript split by page, while a marked-up PDF becomes a digest of highlighted and underlined passages, quoted with surrounding text, grouped by section and each carrying a block id. Handwriting transcription is built in on recent macOS and otherwise comes from a local model server the user runs or an optional managed local model; without one the pages still sync but without a transcript. The free version maps a single tag to a single folder, and it requires Obsidian on desktop with a reMarkable cloud account.
