# flowing-abyss/obsidian-base16-default-dark

This repository holds Base16 Default Dark, a minimalist Obsidian theme built on the Base16 Default Dark colour scheme and described by its README as intended for academic research and deep work with terminal aesthetics. The README recommends pairing it with the IBM Plex family, Plex Sans for text and interface, Plex Serif for headings and Plex Mono for code, together with Noto Color Emoji, loaded from the vault through the author's Local Fonts plugin rather than through a CSS snippet or an important override. The theme is available in Obsidian's community themes and is MIT licensed.
