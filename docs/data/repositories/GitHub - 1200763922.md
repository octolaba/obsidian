# 0xdad0/obsidian-cvss

The repository holds a CVSS 3.1 calculator for Obsidian, opened from a ribbon icon or the command palette as a single modal showing all eight base metrics at once. The score and its severity badge update as options are selected, and the resulting vector string can be copied or inserted at the cursor in the active note. Further commands write the CVSS values into the frontmatter of the current note or of an open finding chosen by fuzzy search.
