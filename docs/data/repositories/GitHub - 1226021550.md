# mkshp-dev/obsidian-MOC-plugin

Generates Maps of Content by extracting elements from the vault's Markdown files that match a filter, through a moc code block whose YAML configuration names a folder, an element type and a filter. Element types cover lists, tasks, headings, paragraphs and blockquotes, and filters combine text containment, regular expressions, tag matching and completed or incomplete task tests with AND, OR, NOT, parentheses and frontmatter property conditions. Results can be grouped, sorted, limited and gathered recursively, a creation wizard builds the query through a visual interface, and a bake command replaces a dynamic block with the rendered static Markdown.
