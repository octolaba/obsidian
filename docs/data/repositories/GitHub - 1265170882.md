# bartekmp/obsidian-image-baker

Image Baker converts images referenced by an Obsidian note into self-contained Base64 embeds inside the note itself, and converts them back into ordinary files again. The README gives the reasons: a note with baked-in images is a single `.md` file that can be mailed, pasted or moved between vaults without its attachment folder; screenshot-heavy workflows stop filling the attachment folder; and a baked image is deleted together with the note that uses it, leaving no orphaned attachment. Conversion works in both directions down to the original file name and folder, can be run on one note or a whole vault, and offers a dry-run preview either way. Pasting and drag-and-drop are supported for getting images in.
