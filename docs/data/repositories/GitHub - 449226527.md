# Edo78/obsidian-koreader-sync

The repository holds the Obsidian KOReader plugin, which imports highlights and notes from a KOReader device into a vault. Its README records that the device has to be mounted on the machine running Obsidian so the plugin can scan its files, and that the mount path is one of four main settings. Each generated note opens with frontmatter that the plugin itself relies on, which the README says can be read by Dataview queries but should be changed only through the plugin's own commands, since editing it directly causes unexpected behaviour.
