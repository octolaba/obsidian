# maxonamission/obsidian-remarkable-round-trip

reMarkable Round-Trip sends a note from Obsidian to a reMarkable tablet as a typeset PDF and imports the marks made on it back into the same note, so struck-out text becomes strikethrough, circled phrases become bold and margin remarks land under their paragraph. Notes go out from the command palette or by right-clicking a note, folder or multi-selection, an optional watch folder sends anything dropped into it, and pairing uses a one-time code or a self-hosted endpoint. On the way out wikilinks become plain text, embeds resolve inline, callouts become titled quotes, frontmatter is dropped or rendered as a title block, task checkboxes become squares to tick with the pen, and empty table rows become fill-in rows. Page breaks can be forced by a marker or decided by a setting that measures each section.
