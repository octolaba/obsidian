# scottwillmoore/obsidian-short-links

Short links shortens the displayed form of internal links to files, notes, headings and blocks, with configuration options for how the shortening is applied. Icons can optionally be shown at the start or the end of a link to indicate which of those types it points at. The behaviour is changed in both editing with Live Preview and reading view. The README describes the plugin as temporary, stating that it would not be needed if the corresponding feature request were implemented.
