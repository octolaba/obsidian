# kurakart/garble-text

This repository holds Garble Text, described upstream as a plugin that exposes Obsidian's garbleText function. The README explains that garbling turns all content in the application, notes and sidebar alike, into unreadable text and blurs images, so screenshots can be taken without exposing sensitive data, with garbled text ungarbled on hover and a Toggle Garble Text command in the palette. The README opens with a statement that the plugin is no longer maintained.
