# Astroneeor/freewrite-ob

A timer-based writing view for freewriting sessions: a full-pane text area with no formatting toolbar and no preview, a default fifteen-minute timer and presets for five, ten and twenty-five minutes. The toolbar fades while the timer runs and reappears on mouse movement, sessions save every thirty seconds and again at the end into a configurable vault folder, and font size and family can be cycled during a session. An optional no-backspace mode blocks the Backspace and Delete keys while the timer runs, and spellcheck can be disabled. Sessions are written as plain markdown files that can be opened, linked and searched like any other note.
