# artorias305/obsidian-shadeflow

Shadeflow is a minimalistic black-and-white theme for Obsidian, aimed at a clean, distraction-free experience with high contrast for users who prefer a monochrome aesthetic. It includes Inter for interface elements, Geist for standard text and Geist Mono for code blocks, so the fonts need no installation by the user, and the README names nexxel's website as its inspiration. The repository description still carries the sample text about a template containing everything needed to create your own Obsidian theme, which does not match the README.
