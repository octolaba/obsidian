# Karl-CN/graph-source-color

The repository holds Graph Source Color, an Obsidian plugin that colours graph nodes according to the source notes they are linked to. The README records notes inside configured source folders being treated as sources, one colour group per folder, with colours cascading from a parent folder to sub-folders that have none set and colours from Obsidian's own graph colour groups read and respected. Association is recorded as breadth-first propagation over outgoing and incoming links, and a note linked to two sources is drawn split left and right while three or more produce a pie-chart split. The README states the plugin does not modify Obsidian's own graph configuration, adds commands to refresh the colours and dump node colour information, and supports desktop and mobile.
