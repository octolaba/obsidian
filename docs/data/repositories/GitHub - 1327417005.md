# windily-cloud/obsidian-LanTai

Moves note images between the vault and S3-compatible object storage: a context-menu action on an image, by right-click or long-press, uploads it, localises a remote one or saves it outside the vault, and batch commands do the same for every image in a note. Storage profiles hold a bucket, public base URL, region or endpoint and keys kept in Obsidian's Secret Storage, covering AWS S3, Cloudflare R2, Alibaba Cloud OSS, Tencent Cloud COS and endpoints such as MinIO. Naming templates control local paths and object keys, the local source can be deleted after a successful upload, and a sidebar gallery browses the images in a profile's bucket. It requires Obsidian 1.13.6 or later, replaces the built-in image context menu in edit mode, and has been tested on Android but not fully on iOS.
