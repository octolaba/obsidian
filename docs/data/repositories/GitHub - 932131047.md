# Agents365-ai/obsidian-ai-tagger-universe

AI Tagger Universe analyzes the content of an Obsidian note and adds relevant tags to its frontmatter, using either a local or a cloud language model. The README lists Ollama, LM Studio, LocalAI and any OpenAI-compatible endpoint as local options, and OpenAI, Claude, Gemini, Groq, Grok, Mistral, DeepSeek, Cohere, GLM, Minimax, SiliconFlow, Bedrock, Vertex AI and OpenRouter among the cloud services. It offers several tagging modes, including generating entirely new tags, and installs from the Community Plugins browser or by unpacking a release into the vault's plugin folder.
