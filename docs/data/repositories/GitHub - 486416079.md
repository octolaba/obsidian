# community-archive/obsidian-pandoc-reference-list

The repository holds Pandoc Reference List, an Obsidian plugin that shows a formatted reference in the sidebar for every Pandoc citation key in the active document. Its README records the prerequisites: Pandoc version 2.11 or newer installed on the machine, a path to a compatible bibliography file, and optionally a path or address for a citation style. The reference tab is opened by a command from the palette; the code is licensed under the GNU GPL version 3.
