# aliir74/copy-image-hotkey

The repository holds Copy Image Hotkey, an Obsidian plugin that puts the image itself on the clipboard when an image embed is selected and the copy shortcut is pressed, instead of the wikilink text. It intercepts the system copy event when the selection is either embed text in source mode or a rendered image element in Live Preview, reads the image bytes from the vault and writes them with the matching MIME type, keeping SVG as text and everything else as a blob. The README lists PNG, JPG, GIF, BMP, TIFF, WebP and SVG as the supported formats.
