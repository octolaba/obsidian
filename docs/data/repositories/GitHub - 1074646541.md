# Howardzhangdqs/Latsidian

Howardzhangdqs/Latsidian holds Latsidian, an academic LaTeX-style Obsidian theme aimed at mathematical writing, technical documentation and Chinese content. It defaults to the Latin Modern typeface with Libertinus, Times New Roman and SimSun as alternatives, uses Computer Modern Typewriter for code blocks with FandolFang for Chinese comments, and embeds every font in CSS so that it works offline. The README also documents LaTeX-style callouts for theorem, lemma, definition and proof.
