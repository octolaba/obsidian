# Barba828/obsidian-plugin-gtp-preview

This plugin renders Guitar Pro files — gtp, gp, gp5 and gpx — inside Obsidian, and the README states that it is based on AlphaTab. Such a file can be opened directly, the track shown can be changed, and multiple tracks are supported. The README also lists downloading a midi file.
