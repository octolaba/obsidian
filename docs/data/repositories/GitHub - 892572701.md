# RavenHogWarts/obsidian-ravenhogwarts-toolkit

A personal toolkit plugin, also referred to as OTK or Obsidian Toolkit, that bundles a collection of small Obsidian utilities into a single plugin aimed at everyday note-taking. It is distributed through the community plugin catalogue and, for beta builds, through BRAT, and is licensed under GPL-3.0.
