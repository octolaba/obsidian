# GoBeromsu/obsidian-eagle-plugin

Eagle Integration uploads images pasted or dragged into Obsidian notes to the Eagle media manager rather than storing them in the vault, and renders them from a local cache. The README describes deduplication of repeated images, folder mapping by note location, a search view over the Eagle library, configurable naming templates, cache sync on startup and tab switch, and eviction of the cache copy when an image is deleted in Eagle. It states requirements of Eagle 3.0 or later with its local API enabled and desktop-only Obsidian, because the plugin uses Electron APIs.
