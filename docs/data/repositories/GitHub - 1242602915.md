# whiteandgrey/obsidian-simpledraw-plugin

SimpleDraw creates and edits flowchart files with its own extension directly inside Obsidian, and its README is written in parallel Chinese and English. It documents the canvas — panning with a middle-click drag and zooming with a modifier and the wheel — text boxes placed and resized on the canvas with a double-click editor and a lock toggle, and arrows whose endpoints either snap to text box anchors and follow them or stay free. Double-clicking an arrow opens a menu for toggling the head and tail markers, switching between solid and dashed, adding an editable Markdown label at the midpoint, and deleting it, with direction also settable from the arrow keys. Selection supports single, modifier-click multiple and rubber-band selection, and copy and paste works across files; the README also announces a standalone desktop application of the same project.
