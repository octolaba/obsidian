# CocoaAI-IT/paste-image-as-webp

This plugin converts images pasted from the clipboard into WebP before inserting them into a note. Its README describes two filename modes, fixed and timestamp, an adjustable WebP quality between 0.1 and 1.0, a save destination of vault root, the current note's folder or a custom path, and automatic embedding at the cursor. Duplicate filenames are resolved with a numeric suffix, and size limits are described as a guard against oversized or malicious images. The recorded repository description is a single Japanese phrase and states nothing further.
