# ahmdmusa/obsidian-toolkit

Obsidian plugin bundling seven modules into one plugin. A searchable formatting palette inserts more than sixty elements across categories for callouts, headings, text styles, lists, code, dividers and right-to-left Islamic templates, while two AI commands supply a one-line continuation from context or a full structured template from a description. Image handling in Reading view covers resizing, alignment, rotation, captions and a lightbox, and the remaining modules add a distraction-free fullscreen mode, a file tree with icons and image thumbnails, a pinned quick-access bar above it, and a folder focus mode that hides everything outside one folder. Any OpenAI-compatible API can be connected, or models can be run locally with Ollama.
