# dsebastien/obsidian-life-tracker-base-view

Obsidian plugin that adds a Life Tracker base view type turning tracked note data into visualizations. Twelve visualization types are offered, among them heatmaps with several colour schemes and value-to-colour mappings for rating scales, line, bar, area, pie, doughnut, radar, polar area, scatter, bubble, tag cloud and timeline charts, driven from frontmatter properties, Bases formulas or file metadata. Several cards can visualize the same property side by side, multiple properties can be overlaid on one chart to compare correlations, and per-view settings cover time granularity, the date anchor property, first day of the week, custom filename date patterns and time frame filters.
