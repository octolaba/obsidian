# lanice/obsidian-rant

The repository holds Obsidian Rant-Lang, a thin wrapper around the Rant procedural templating language for use inside notes. Its README quotes the language's own description as a high-level templating language for dynamic templates, game dialogue, stories, name generators and test data, and records the plugin's usage as a rant code block whose program is compiled, executed and shown in preview mode. Examples cover inline use, styling, links, a dice roller and lists, and installation is documented from the community directory, through a beta installer plugin, or manually.
