# protoavatar/obsidian-newsletters

This repository holds the newslog plugin for Obsidian, which syncs newslog.me daily bundles and highlighted Kindle articles into a vault. The README describes newslog as a service that gathers newsletters, RSS feeds and articles into one daily digest with an index and generated summaries, reachable through a personal address on that domain and deliverable to a Kindle or other e-reader by email. The plugin downloads those digests into the vault as Markdown and syncs Kindle highlights back, saving the full article alongside them to preserve context.
