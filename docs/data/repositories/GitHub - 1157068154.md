# SSShooter/obsidian-mindmap

Mind Elixir Mind Map renders a Markdown document as an interactive mind map using the Mind Elixir library, parsing headings and lists into a hierarchy of nodes. The map opens in a split pane beside the original document from a ribbon icon or a command, refreshes automatically when the source file changes, and can take either the filename or the first H1 heading as its root node. Mind maps can also be embedded inline through `mindelixir` code blocks written in an indented plain-text format, and the README records that the plugin is functional on Obsidian's mobile app.
