# Maclean-D/obsidian-limitless-lifelogs

Limitless Lifelogs is described as syncing Limitless AI lifelog entries into Obsidian Markdown files. Its README says entries are written one file per day, named by date, preserving the original structure with entry titles as first-level headings, sections as second-level headings, and messages carrying timestamps and speaker names. Syncing runs from a ribbon icon or the command palette and is incremental, detecting the last synced date and fetching only new or updated entries. A Limitless AI API key generated in that account's settings, a target folder and an optional start date are entered in the plugin settings.
