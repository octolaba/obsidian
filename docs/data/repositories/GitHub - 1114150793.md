# jarchitect1/The-Scripture-Injector

The Scripture Injector inserts Bible passages into an Obsidian note from the command palette, taking a reference such as a single verse, a verse range, a whole chapter, a chapter range or a book abbreviation. Retrieved text is written into the note as a formatted quote callout, and the default translation, API keys and formatting options are configurable. Two translations are recorded: the English Standard Version, which the README says needs a free Crossway API key, and the New English Translation, whose API it describes as free and without a key. The README presents the plugin as aimed at pastors.
