# UNcore-gh/UNagent

An AI assistant panel for Obsidian that reaches model providers over plain HTTP with no bundled LLM SDK and no local process on mobile; each provider profile holds a protocol, base URL, key and model list, and a chat command switches the model per conversation. Sixteen tools let the assistant search, read, create and edit notes, generate images and keep task lists, with destructive edits confirmed and deletions undoable. Retrieval runs on keywords and metadata, with optional semantic search whose embeddings are computed remotely and cached locally; conversations are stored in the vault with branching, rewind and compaction, and memory lives in three visible Markdown files. On desktop, a locally installed hermes agent can be driven over ACP behind an approval panel.
