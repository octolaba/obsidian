# jemstelos/obsidian-media-notes

Obsidian Media Notes supports taking notes on YouTube videos, podcasts and lectures inside a note. A media note is an ordinary Markdown note carrying a media_link property with a supported URL, created either by adding that property to an existing note or from a browser bookmarklet that makes a note for the video being watched and continues playback from the current position. Hotkeys pause and skip the media without leaving the note, insert a timestamp at the current position, and clicking a timestamp-formatted link jumps the player back to that moment; playback resumes where it was left. Settings cover player orientation and size, progress bar visibility and colour, a timestamp offset and a timestamp template.
