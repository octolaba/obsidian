# jkRaccoon/obsidian-wide-view

Wide View is deliberately not a full Obsidian theme: it changes only the content width and leaves colors, fonts, icons and layout untouched. Reading view and editing view widths are set independently, chosen between full width and 1600, 1400, 1200 or 1000 pixels, with 1400 as the default for both, and the theme works whether Obsidian's readable line length setting is on or off. The bilingual English and Korean README states that the Style Settings plugin is needed to switch widths from a dropdown, and that without it the theme still applies its default width.
