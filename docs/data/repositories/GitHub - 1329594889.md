# cuatrecasespro/cammvas

Adds mind-mapping interactions to Obsidian Canvas while keeping every map a standard .canvas file: Enter creates a sibling, Tab a child, Shift with Enter inserts a line break, and arrow keys move through the tree once Mindmap mode is on. Nodes dropped onto another node reparent their whole branches with cycle prevention, branches fold and restore from their parent, and an automatic contour-based layout places left, right or balanced branches, with re-layout available for one branch alone. A synchronized outline sidebar searches, renames and reorganizes roots, and branch colors propagate along each branch. It requires Obsidian 1.13.4 or newer, makes no network requests and collects no telemetry, and relies in places on undocumented runtime APIs.
