# kuoe0/obsidian-pinbox

Pinbox is an Obsidian plugin that captures text snippets and URLs from a mobile device into pre-configured notes in the vault. Notes designated as pinned become targets in the Android and iOS share menu, and Obsidian file bookmarks can be included there as well. The README describes a global append format with content, timestamp, date and time placeholders, per-note overrides, and pinned paths that update automatically when a file is renamed or moved.
