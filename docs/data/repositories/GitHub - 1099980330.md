# davidgolding/obsidian-colophon

Obsidian plugin providing a dedicated writing canvas for long-form manuscripts and screenplays. The README states that it uses a custom editor engine built on Tiptap and ProseMirror plus its own file format, so formatting, footnotes and script standards are preserved rather than reduced to Markdown. Documents are created from the file explorer context menu, a ribbon icon or a command, and switch between a manuscript mode for prose and a script mode for screenwriting.
