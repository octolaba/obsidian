# hipstersmoothie/obsidian-plugin-toc

The repository holds an Obsidian plugin that creates a table of contents for a note. Its README records two commands, one building the full table and one building it for the next heading level, and settings for list style as bullets or numbers, an optional title, and minimum and maximum header depths defaulting to two and six. It explains that the table is generated for the subheadings of the heading the command is run under, so running it under a level two heading yields only that section's subheadings.
