# wesswart77/obsidian-study-vault

Study Vault organises courses and certifications inside the vault: a course record carries an exam date, a topic count and a subject, and topic notes are created with sections for a summary, key concepts, flashcards, practice questions and related links. A review modal reads question and answer pairs out of those notes, where a question is a Q-prefixed heading and the answer a bold A line, and tracks which cards were known and which were unsure. A progress sidebar shows per-course bars for the share of topics mastered and the days left until the exam, and one setting chooses the folder that course and topic notes are saved in.
