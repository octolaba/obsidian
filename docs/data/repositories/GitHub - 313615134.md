# agathauy/wikilinks-to-mdlinks-obsidian

Wikilinks to MDLinks converts an individually selected wikilink into a Markdown link and back again. The cursor is placed inside the link and a hotkey or the toggle command switches that one link to the other format, depending on which format it already carried. The README lists converting every wikilink or Markdown link in a selection as a future plan rather than a present feature.
