# playerofgames/obsidian-mia-theme

Mia is described in its README as a lightweight Obsidian theme for macOS and iOS that builds on the default theme with an emphasis on a clean, distraction-free experience. Recorded features include light and dark mode, system fonts, monochrome external links, a source mode view using SF Mono with heading characters hanging in the margin and formatting noise muted, embedded Bases tables styled like regular tables, centred images with alt tags controlling float and inversion, images dimmed in dark mode, a checkbox style for cancelled tasks, a reader CSS class in a serif font and PDF export at 12pt. The README states that the theme is fully customisable through the Style Settings plugin.
