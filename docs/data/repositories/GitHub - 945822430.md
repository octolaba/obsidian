# 22-2/wheel-tab-switcher

Wheel Tab Switcher switches between Obsidian tabs with the mouse wheel while the pointer hovers over a tab header: scrolling up moves to the tab on the left and scrolling down to the tab on the right, wrapping around at either end. The README states that it works in all Obsidian windows and that no additional configuration is required.
