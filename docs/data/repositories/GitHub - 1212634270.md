# panAtGitHub/AnkiHeadingSync

Desktop-only Obsidian plugin that builds Anki cards in bulk from note headings, fixing the heading text as the question so that questions show up in the outline sidebar and review can jump back to the exact place in the note. A heading combined with a custom marker, typically a tag, selects among four card types: plain question and answer, a multi-level list question and answer, cloze deletions revealed one at a time, and a cloze that blanks everything at once. It converts the current file or every file in a configured scope of all, include or exclude folders, and routes cards by a default deck, folder mappings or a file-level deck declaration, optionally syncing backlinks and tags. Sync markers and their Anki cards can be cleaned up and empty decks removed; Obsidian 1.8.7 or newer, desktop Anki and AnkiConnect are required.
