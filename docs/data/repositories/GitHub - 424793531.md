# aidenlx/obsidian-icon-shortcodes

The repository holds Icon Shortcodes, an Obsidian plugin that inserts emoji and custom icons by typing a shortcode. Its README records built-in Unicode 13.1 emoji and Lucide support, with two further icon libraries available by download, importing and managing custom icons in several raster and vector formats, rendering of custom icons in the editor, and a fuzzy search where a partial code offers every matching icon. It also records an API for other plugins to build on, and credits four earlier emoji and icon plugins as inspiration.
