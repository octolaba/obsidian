# leoray1990/obsidian-folder-column-navigator

A Finder-style file navigator that keeps root folders in view, either as a left-hand list or as tags across the top, and opens each folder level in its own column so the path stays visible. Navigation is keyboard-driven: arrow keys move within and between columns, Enter opens a folder or note, Space opens the context menu, and typing filters the focused column, matching Latin text, digits, Chinese characters, pinyin initials, full pinyin and mixed pinyin. Sorting, item metadata, icons, font sizes, column widths and hiding rules are configurable, and a collapsible calendar browses by month or year, opening files matched to a date by file timestamps, frontmatter dates or filename patterns. It adds file and folder context menus, exposes Obsidian's file-menu event to other plugins, flags duplicate names, and makes no network requests.
