# bobostudio/obsidian-imgur-plugin

The Tencent Cloud COS image-hosting plugin uploads images from Obsidian notes to COS and replaces local links with cloud links. It supports drag-and-drop or paste uploads, configurable naming and date directories, backups, image management, link expiry, bulk attachment transfer, and Markdown–COS synchronization on desktop and mobile.
