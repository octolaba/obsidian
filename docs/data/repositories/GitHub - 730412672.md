# mnaoumov/obsidian-root-folder-context-menu

Root Folder Context Menu enables a context menu for the vault's root folder and for the empty area of the Files pane, where Obsidian otherwise offers none, and populates it with the same entries any other folder has. The README states that a demo vault with usage examples ships with every release and can be opened by a command, downloaded from the releases, or browsed in the repository. The plugin is available in the community plugins repository, beta releases install through BRAT, and its hidden debug messages are enabled by a one-line console call.
