# paulpaterson/obsidian-project-tasks

This plugin builds linked project tasks in Obsidian by managing task IDs and dependencies, which the README presents as a way around the fiddliness of specifying dependencies by hand. Tasks can be built from scratch or from an existing set, project-specific tags are associated with them, and the README states that existing task functionality such as due dates and recurrence continues to work and that the resulting tasks still work in vaults without the plugin installed. The Tasks plugin is required and Dataview is optional for project-specific views; the commands run from the command palette or from hotkeys, and parallel execution and optional or conditional tasks are listed as future work.
