# marten-ti/obsidian-tagline

Tagline turns a line of text carrying a tag into a separate note with populated frontmatter, leaving a link to it behind in the original line. Each tag is mapped in the settings to a template and an output folder, and the template's frontmatter declares each field's type and source through typed comments. Inline fields are written on the line in the Dataview double-colon form, with autocomplete offering dates, folder contents, notes carrying a given tag and custom options. The README records optional synchronisation of a checkbox's state with a frontmatter status field, and that Templater syntax works inside the templates.
