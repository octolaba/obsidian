# churnish/resize-mobile-split-view

Lets the divider lines between tab groups be dragged to resize split views on mobile: hold on a line until it lights up and then move, or press and move directly with a pointer, as on desktop. The README records that this became native behaviour in Obsidian 1.13, so the plugin is no longer needed, and that it was tested on iPadOS 26.
