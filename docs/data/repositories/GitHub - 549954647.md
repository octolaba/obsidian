# ThisTheThe/MicroMike

Micro Mike is described as a high-density retro-style Obsidian interface focused on mouse and eye ergonomics, and its README states that only dark mode is supported. It is intended to be used with the Style Settings plugin, and individual parts of it are also published separately as snippets. Recorded changes include zoomed-out high-density views for the file browser, outline, tags and backlinks, larger buttons with padding gaps removed, a denser settings and prompt menu with left-aligned controls and a hover preview, a generated toplinks section, a layered file browser background and an optional Windows 7 window frame.
