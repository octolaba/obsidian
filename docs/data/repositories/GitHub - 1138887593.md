# davidaffo/volleyboard_svg_app

The repository carries no description; its README presents VolleyBoard as a tactical volleyball whiteboard for Obsidian. A board lives in a volleyboard code block holding JSON, inserted by hand or through an insert command, and clicking the board opens an editor whose save-and-close action writes the changes back into the same block. The README adds that VolleyBoard is also available as a web app served from the repository's docs folder by any static server.
