# seyf1elislam/obsidian-LocalMediaEmbedder-plugin

Local Media Embedder embeds local video, audio and image files from the device into Obsidian notes. Selecting a file path in a note and choosing the embed command from the context menu generates the media code block, and the README records support for formats such as MP4 and MP3, several videos shown as a grid or a list, several audio files, and picture-in-picture video. Its change log also lists using files located outside the vault without copying them in, an integrated video player, playing YouTube videos, and timestamps added to the note when seeking in a video.
