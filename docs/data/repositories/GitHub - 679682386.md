# RyotaUshio/obsidian-inline-math

The recorded description says the plugin stops the reader from being disturbed by flickering inline math in Obsidian. The README explains both cause and fix: Obsidian does not recognize a dollar-delimited span as math when a space sits directly inside the delimiters, so on finding inline math the plugin inserts empty braces at its beginning and end, hides them from view, and deletes them automatically when the cursor leaves the span, so notes are not left littered with braces. A debug-mode setting disables the decorations to show what happens underneath. The README also records a conflict with the Latex Suite plugin, resolved by removing one token from a default snippet, and lists the author's other math-related plugins.
