# ErikaRS/task-list-kanban

Task List Kanban turns Markdown tasks from an Obsidian vault into a kanban board while the tasks stay in their original files, with board edits written back to Markdown. The README records collecting tasks from one folder, several folders or the whole vault, moving tasks between columns using tags, editing, completing, cancelling, archiving, duplicating and bulk-updating them, and one search query filtering by content, tag, file or date. It also records saved views combining filters, sorting, grouping, layout and width, swimlanes by file or tag, sorting by file order, parsed task properties or a manual pinned order, and a dashboard listing every board in the vault with task counts and timestamps.
