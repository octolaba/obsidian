# kelleyblackmore/obsidian-quizport

QuizPort runs interactive quizzes inside notes from JSON in the QuizPort format, either embedded in a quizport code block or referenced as a separate JSON file whose path resolves like an Obsidian link. A quiz needs only a title and questions; the question type is inferred from the shape of the answer, giving single choice, true or false, and multi-select, with optional hints offered before answering and explanations shown after. Answering happens in reading view with scoring and instant feedback, followed by a review of what was missed and a one-click retry of just those questions, and shuffle mode randomises question and answer order. Attempt history is kept locally and can be exported to a note as a summary table plus raw JSON; the plugin works offline on desktop and mobile and needs Obsidian 1.13.0 or later.
