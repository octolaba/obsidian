# jamiefdhurst/obsidian-auto-periodic-notes

Obsidian plugin that creates periodic notes in the background and can pin them in the open tabs, covering daily, weekly, monthly, quarterly and yearly notes with individual settings for each. It requires the Periodic Notes plugin and respects its templates, format and location, and the README states that both the current release and the newer beta of that plugin are supported through a separate abstract provider package. Each note type can be created silently with a notice or opened and pinned automatically, older notes can be closed automatically, and weekends can be excluded from daily note generation.
