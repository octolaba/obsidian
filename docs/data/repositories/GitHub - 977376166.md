# Raven-Pensieve/obsidian-ace-code-editor

The README lists editing code directly in Obsidian, managing CSS snippets, editing code blocks and previewing code files. Installation is from the community plugin market or through BRAT for beta versions, and the project is licensed under GPL-3.0.
