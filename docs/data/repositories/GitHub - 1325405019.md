# ethanffu/open-powershell-here

Open PowerShell Here starts a locally installed PowerShell 7 or later from Obsidian on Windows, either at the vault root from a ribbon button or in a folder right-clicked in the file explorer. There is no embedded terminal, no command-palette entry, no hotkey and no settings page, and the menu item appears only for a single folder, never for files or multiple selections. It looks for pwsh.exe on the inherited PATH and then in two fixed locations, probes each candidate with a hidden version check that rejects anything below version 7, then starts it with the chosen directory as its working directory. The session is hosted in Windows Terminal when present, falling back to a direct spawn, and the plugin never launches the older PowerShell, cmd, WSL or another shell.
