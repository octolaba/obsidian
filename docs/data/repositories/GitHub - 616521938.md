# Mara-Li/obsidian-open-settings

Open Plugin Settings creates commands that open the settings tab of a chosen plugin. Plugins are registered from the plugin's own settings, after which one command opens the settings of any registered plugin, and a separate command searches for and opens the settings of one that has not been registered. The registered list can be refreshed to remove deleted plugins and to disable the commands of disabled ones.
