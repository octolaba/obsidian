# Superkikim/nexus-ai-chat-importer

Nexus AI Chat Importer is an Obsidian plugin that imports exported chat archives from AI providers into vault notes. The README documents exporting a ZIP from ChatGPT, Claude, Mistral Vibe or Perplexity, then importing conversations either wholesale or selectively, with import reports describing what was brought in, configurable folders and formatting, a documented conversation format, handling of attachments such as images, DALL-E output and artifacts, per-provider differences, and a command-line import path. Its recorded version at this README adds ChatGPT 2026 export support, Claude web search citations and Vibe Canvas rendering, the interface and documentation are available in ten languages, and the license is GPL-3.0.
