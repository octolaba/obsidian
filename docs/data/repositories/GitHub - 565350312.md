# efemkay/obsidian-listive-theme

Listive is described as an Obsidian theme for outliner-focused writing, with differentiated header styles and a subtle interface. Its README states two guiding principles, improving the outlining experience as far as CSS allows, and making insights prominent by styling each header level differently to support lead-in headers, with the original styling revertible. The README notes that the theme complements the Outliner plugin rather than replacing its features, and suggests using it alongside the author's Modular CSS Layout snippets for multi-column, card, gallery and image control layouts.
