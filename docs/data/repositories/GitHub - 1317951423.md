# altokun-number-one/obsidian-open-folder-button

Adds a button to every folder row in Obsidian's file explorer that opens that folder in Windows Explorer, leaving the row's expanded or collapsed state unchanged. The resolved path is passed to the Windows Explorer executable as a direct argument rather than through a constructed command string, and paths resolving outside the vault are rejected; the plugin reads no note content, makes no network requests and collects no telemetry. It targets Windows 11 with Obsidian Desktop 1.12.7 or later and a vault on the local filesystem, and it depends on the internal structure of the file explorer, which an Obsidian update could change.
