# springrain1/obsidian-xmind-plugin

SuperMind is a mind-map plugin for Obsidian that edits maps interactively and converts between the map and Markdown in both directions. The README records four layout directions, thirteen themes, rendering of tables, callouts, block quotes, code blocks and embedded Canvas, PDF++, Eagle and Excalidraw content inside nodes, and export to PNG, JPEG and SVG as well as to templated documents. Its AI features call OpenAI, Anthropic, Gemini, Deepseek or Ollama to generate child nodes, analyse content and produce insights from customisable prompts, and bidirectional conversion with XMind files is listed as desktop-only.
