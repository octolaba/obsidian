# ununnamed/remaining-reading-time

Remaining Reading Time shows in the status bar how much reading time is left in the current note and what percentage of it has been read, updating in real time. The README states that it is based on the Reading Time plugin and shares much of its structure, but is aimed at a different use: where that plugin estimates a note's length to help keep writing concise, this one estimates the time still needed to finish reading an article, note or book and tracks progress through it. It also links an animated instruction for enabling the display on Obsidian mobile.
