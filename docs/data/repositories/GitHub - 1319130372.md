# OtmiVi/aurora_glass

Aurora Glass is a graphite-blue glass theme for Obsidian with dark and light palettes, built as a customization of Oczko24's Obsidian Transparent theme. Backgrounds can be transparent, a gradient, a solid color or a custom image. Styling is tuned for the settings modal, the community theme browser, tabs, the file explorer, graph, canvas, callouts, code blocks, marks and inline code, and the theme carries compatibility fixes for Make.md, MySnippets, Day Planner, Remotely Save, Notebook Navigator and Enchanted Animations.
