# carnalMATRIX/obsidian-mantle-kanban

Mantle Kanban is a Kanban board for Obsidian in which cards are dragged between columns to change task status. Cards render Markdown content, links, images and frontmatter metadata, and show checklist sub-tasks with progress percentages on their covers, while the board carries a dot-pattern background that reacts to pointer movement. The README says a Markdown file is opened as a board from the note's options menu and has to carry the expected Kanban frontmatter keys, and that the plugin integrates with the Project Mantle ecosystem and is tuned for the Zenith theme while running on any theme.
