# tmayoff/obsidian-meals

This plugin manages recipe notes and plans meals for the week. Recipes are read either in RecipeMD format or in a simpler heading-based format with Ingredients and Directions headings, and a recipe-finding dialog searches them by ingredient and collects them into a list that can then be assigned to days in a weekly meal plan note. Ingredients reach a shopping list either individually from a note's context menu or for the whole week from the meal plan, and the shopping list format is a template string over ingredient properties such as quantity and unit of measure. Recipes can also be downloaded from the internet and stored as Markdown.
