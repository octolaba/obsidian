# Nighteye841228/obsidian-corkboard

The repository holds Obsidian Corkboard, a plugin that gives each folder a corkboard file rendering the folder's Markdown notes as index cards in a grid, in the manner of Scrivener. A card carries the file's title, a synopsis stored apart from the note body, a status label and an optional colour; cards can be multi-selected, reordered by dragging, and changed through context menus, and card size is stored per corkboard. The README states that file creation, renaming, deletion and moves are reflected even while the view is closed, that status labels are configurable, that a corrupt corkboard file opens read-only rather than being overwritten, and that the plugin is desktop only.
