# tiancaijb/obsidian-sobriety-tracker

Sobriety Tracker records recovery tracking in a plain Markdown note. An urge timer runs a countdown of configurable length, where completing it is logged as a victory with a particle animation and cancelling early is logged as a relapse; a daily check-in reminder fires at a chosen time and, if Obsidian was closed then, within a configurable grace period on the next launch. A dashboard aggregates the tracker note into the current streak, success rate, weekly and monthly breakdowns and a log of wins against relapses. The interface is available in English, Chinese and Japanese, and the README records that everything stays in the vault with no cloud and no accounts.
