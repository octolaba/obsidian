# Erallie/discord-timestamps

Repository for Discord Timestamps, an Obsidian plugin that displays Discord timestamp markup in reading mode the way it would appear in Discord, throughout the note, with an optional setting that leaves code blocks unconverted. A converted timestamp is given a coloured background and reveals the full date and time when hovered on desktop or selected on mobile. A command and an editor context-menu entry insert a timestamp: a modal takes a date and time, optionally in a time zone other than the local one, generates the available formats, and inserts the chosen one at the cursor, while reading mode still shows every timestamp in local time and recent entries can be reused from a history whose size is configurable.
