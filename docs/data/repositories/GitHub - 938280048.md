# louanfontenele/obsidian-vault-file-renamer

Vault File Renamer standardizes the names of files and folders in an Obsidian vault, lowercasing them, removing accents and then applying configurable replacement rules, while keeping each item in its original folder and its contents unchanged. Renaming can be switched on to run automatically when a file or folder is created or manually renamed, and it goes through Obsidian's own file manager rename flow so that internal links are updated. Scope is controlled by four settings: an allow-list of target extensions, a list of excluded extensions that are never renamed and take priority even over the allow-list, a recursive folder blacklist, and a file blacklist matching exact paths, which the README recommends for extensionless files. Custom regex rules run after the built-in lowercasing and accent removal and can be edited, disabled, removed or reordered.
