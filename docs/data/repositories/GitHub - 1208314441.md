# gghyoo/simple-webdav

Repository for Simple WebDAV Sync, a plugin that synchronises a vault with a WebDAV server. Its README describes a three-way comparison built on entity tags and SHA-256 hashes rather than timestamps, two-way transfer covering new and deleted files, conflict handling that keeps both versions under a dated filename, and deletions that restore from the server locally or move a removed remote file into a local trash folder. It also records file-event monitoring with a configurable debounce, periodic and on-close synchronisation, sync state persisted after each operation, an English and Chinese interface, and no npm dependencies.
