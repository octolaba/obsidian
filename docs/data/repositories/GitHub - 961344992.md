# heavenlygaze/obsidian-todo-highlighter

This plugin highlights every occurrence of the exact string TODO in a note, in a colour chosen in the settings, and updates as soon as that colour is changed. The README states that detection works in both edit and preview modes, through a CodeMirror decoration while editing and a span carrying a dedicated class in preview, and records the default colour as a bright green hex value.
