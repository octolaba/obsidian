# dhamaniasad/obsidian-rich-links

The repository holds the Obsidian Rich Links plugin, which converts a URL in a note into a rich link preview of the sort found in Notion. Its README records the workflow as entering a link, selecting it and running a create rich links command from the palette. The author describes the release as early and mainly a proof of concept, and the repository records no license.
