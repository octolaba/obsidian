# cybertramp/obsidian-task-director

Task Director changes every task in a selected Obsidian page at once. The README records commands and file-menu entries that turn all incomplete checkboxes in a file complete, turn all complete ones back to incomplete, and show a summary count of the page's tasks. An option enabled by default removes the completion date from a completed task when it is toggled back to incomplete. The author explains that the plugin exists because uncompleted tasks carried over from past entries otherwise had to be processed one by one.
