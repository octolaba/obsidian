# onsi/expandomatic

Expandomatic grows the editor selection one syntactic unit at a time, modelled on VS Code's Expand Selection, with a paired command that shrinks it back through the expansion history. The README states that the prose sequence runs word, URL or sentence, sentence, paragraph, innermost section and its parents, then the whole document, and that separate sequences apply inside tables (word, cell, row, table), fenced code blocks (word, line, block) and inline or block math. Moving the cursor or changing the selection by hand resets the history, and both commands ship without keybindings so the user assigns them.
