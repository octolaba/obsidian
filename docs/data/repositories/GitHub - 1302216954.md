# israerusan/standing-questions

Standing Questions treats a note carrying a question type in its frontmatter as a first-class open question with a state — open, partial or answered — that appears on a question board and is matched against notes written later. A question can name a parent, in frontmatter or as an inline field, so that the states of sub-questions propagate upward to the question that contains them. The README records that leads are notify-only by default and that the only thing the plugin writes on its own is a status line in a question's own frontmatter once all of its sub-questions are answered, which is itself a toggle; it presents the plugin as part of a Second Read suite.
