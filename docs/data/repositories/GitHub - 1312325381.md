# jldiaz/pdfplus-exporter

PDF++ Exporter writes annotations kept in Markdown notes back into the PDF itself, as standard highlight and square annotations with pop-up comments, so the document can be read in Acrobat, macOS Preview or any other viewer. It reads the backlinks pointing at a PDF, extracts the quoted context and surrounding comment text using conventions such as callout quotes, and produces a standalone annotated copy without requiring the PDF++ plugin to be enabled during export. An export modal fuzzy-filters the vault's PDFs, and settings control which colors and note types are included, highlight opacity, whether comments sit inside the highlight or as floating sticky notes, how link text is replaced, and whether callouts and bullets are stripped.
