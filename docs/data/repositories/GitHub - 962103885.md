# natipt/obsidian-zhongwen-reader

This repository holds Zhongwen Reader, a lightweight hover dictionary plugin for Obsidian aimed at reading Chinese and building vocabulary. Hovering a word in edit or preview mode shows its simplified and traditional forms, pinyin or bopomofo, and CC-CEDICT definitions; HSK colour highlighting can be toggled, hovered words are saved to a vocabulary list optionally with the sentence they appeared in, a sidebar lists the words of the current note and jumps to them, and saved vocabulary exports as Markdown flashcards for the Spaced Repetition plugin. The dictionary and HSK word lists are downloaded on first activation, after which the plugin works offline, and saved vocabulary lives in a JSON file inside the plugin folder. The README records that captured example sentences are stored but not yet used in the flashcards or the sidebar.
