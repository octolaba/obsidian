# mikagosz/obsidian-color-note

Color Note colours note and folder titles in the Obsidian file explorer from the right-click menu. A state is defined in settings as a name, a value, a colour per theme and a sentence describing what it means; choosing one writes that value into the note's front matter, by default under a status field that can be renamed, so the state remains readable to other tools. Folders, having no front matter, take a colour recorded in the plugin's own data, and a hand-picked custom colour on any item overrides its state. Four states ship as defaults, open, done, done-without-test and archived, and can be renamed, recoloured or deleted; colouring is applied through custom properties on the explorer row and a bundled stylesheet rather than a generated one.
