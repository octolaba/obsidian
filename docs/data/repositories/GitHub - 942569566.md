# kuboon/daily-nav

Daily Nav adds two commands to the command palette, opening yesterday's and tomorrow's daily note. The README states that it depends on the daily-notes-interface package, so it reads the configuration of the core Daily notes plugin and of Periodic Notes when that is in use, and it suggests pairing the commands with a note toolbar.
