# oldleam/obsidian-calendar-task-planner

This repository holds Calendar Task Planner, an Obsidian plugin offering a monthly calendar whose day cards carry tasks with checkboxes. Tasks are added, edited and deleted through a modal, the month reports total, done and percentage statistics, and a day can be exported to a note or added to an Obsidian canvas. The README states that the week starts on Monday, that all data is stored locally in a JSON file inside the vault, and that the plugin makes no network requests and works fully offline.
