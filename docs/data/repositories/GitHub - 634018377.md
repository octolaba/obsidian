# seethroughdev/obsidian-recipe-grabber

Recipe Grabber turns a recipe URL pasted into a note into a concise recipe, with the image and a link back to the original page, rather than the full article around it. It expects the page to carry recipe data in JSON form, and the layout can be replaced by pasting a custom Handlebars template into the settings, with the available fields listed in an example recipe. A setting downloads the recipe image into the vault at a configurable location, in which case the image value becomes a link to that file and the template should embed it; if the setting is off or the download fails, the value stays a direct URL. The README also notes that since Obsidian 1.4.6 frontmatter must start on the first line, so leading newlines have to be removed from the template.
