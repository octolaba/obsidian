# MathieuCGit/ChordGrid_for_Obsidian

This repository holds Chord Grid, an Obsidian plugin that renders chord grids with rhythm patterns from a chordgrid code block. The text notation carries a time signature, bar lines, chord names with bracketed rhythm figures, and repeat symbols, and it is rendered as an SVG chart. The README lists automatic beaming, ties, tuplets and dotted notes, complex time signatures such as 6/8, 5/8, 7/8 and 12/8, repeat signs and volta brackets, and a transposition directive. Documentation is available in English and French.
