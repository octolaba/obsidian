# Obsidian-TTRPG-Community/heraldry-weaver

Heraldry Weaver is an Obsidian plugin that generates or hand-builds coats of arms and embeds them in notes. The README records a panel with a Roll mode that derives arms from a name or seed or rolls random results, and a Build mode covering shield shape, field divisions and variations, metal, colour and fur tinctures, an ordinary, and layered charge groups each with tincture, count, arrangement, position, scale, rotation and mirroring, previewed live with a rule-of-tincture hint. A counterchanged toggle gives an element the field's tinctures in reverse, and a format toggle renders the same arms as a banner, flag, swallowtail, pennon or gonfalon. Saved arms go to an in-plugin library that can be browsed and filtered by whether notes reference them, and arms are placed in notes as a heraldry code block or through an inline syntax sized to the text line, with SVG and PNG export.
