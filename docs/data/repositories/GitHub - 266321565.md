# sainadhx/obsidian-boom

This repository holds the Boom theme for Obsidian, inspired by Roam Research, and its README states that only a light theme is provided. Installation is described in the older form: download the obsidian.css file, turn on the Custom CSS plugin in settings, and place the file in the vault root folder.
