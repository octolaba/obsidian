# Quorafind/obsidian-sakana-widget

The repository holds a plugin that places the Sakana widget inside Obsidian as something to play with while writing. Its README records that a reader's own widget can be added from the settings, and documents installation through a beta installer plugin or by copying a release's three files into a plugin folder, noting that the plugin was not yet in the community directory. It records the code as MIT licensed while stating that the two default images must not be used commercially, and credits both the upstream widget projects and the illustrator.
