# RanceLee233/wechat-publisher

Converts articles written in Obsidian into WeChat Official Account content and submits them to the account's draft box; the README is bilingual and states that reviewing and publishing the draft remain the author's job. A sidebar previews the WeChat layout and can copy the HTML for manual pasting, while a direct route submits to the draft box once an AppID and AppSecret are configured. Handled Markdown includes syntax-highlighted code blocks, inline and block math and Mermaid diagrams rendered as images, tables, local and remote images uploaded to the WeChat CDN, ruby annotations, callouts and horizontal image carousels. The README states that the plugin neither writes articles nor generates images nor broadcasts automatically, and that personal use is free.
