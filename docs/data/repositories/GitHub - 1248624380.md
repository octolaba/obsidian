# Snifer/combat-ledger

Obsidian plugin providing a battle tracker for tabletop role-playing games. The README states that initiative, current and maximum hit points, defense and character type are read from the frontmatter of ordinary vault notes, that combatants are sorted by initiative with the active one highlighted as rounds advance, and that every event, including turn changes, damage, healing, conditions and custom notes, is recorded in a Markdown note, either newly generated with timestamps or appended under a chosen header. The interface is documented in English and Spanish.
