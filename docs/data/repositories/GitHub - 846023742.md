# AndreasThinks/obsidian-to-quarto-exporter

This plugin exports Obsidian notes to Quarto-compatible QMD files. The README records the syntax conversions it performs on the way out: wikilinks with or without display text become Markdown links, embedded notes with heading and block references and sized image embeds become their Markdown equivalents, mermaid diagrams become Quarto executable blocks, block anchors become pandoc-crossref labels and cross-references become pandoc-crossref references, callouts become Quarto callouts, highlight syntax becomes a mark tag, and single-line display math becomes the multi-line Quarto form. Export options add a creation or modification date in a chosen format, include or exclude the note's tags, set the output folder, and decide whether existing files are overwritten or new ones created.
