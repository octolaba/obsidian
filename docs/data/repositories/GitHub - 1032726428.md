# Cloopy/Powered-by-Lancer---Retouched

This repository holds a retouched edit of Dion McMillan's Powered by Lancer theme for Obsidian, based on the aesthetics of the Lancer TTRPG and Santi Younger's Wasp theme. The author states that colours were re-managed to suit their own preferences for the dark theme, choosing tones easier on the eyes while keeping the colour usage ordinarily seen in Lancer.
