# monapdx/obsidian-skeletal

Skeletal is a searchable Markdown pattern library of 47 configurable templates across 12 categories, browsed with category filters, favorites and a recent list, adjusted through form controls and previewed as raw Markdown or as rendered output. A chosen template is inserted at the cursor, replacing the current selection when there is one, copied to the clipboard or turned into a new note. It also manages task progress bars that recalculate from checkboxes without rewriting the rest of the note, and its settings cover Markdown flavor, placeholders, progress defaults and remembered template values.
