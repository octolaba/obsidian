# kognise/obsidian-atom

Obsidian Atom is a theme based on Atom's One Dark and One Light colour schemes, offering a light and a dark variant selected from Obsidian's appearance settings. Its README describes the theme as staying close to Obsidian's default interface while applying several tweaks to it, and as replacing the default syntax highlighting in code blocks with one taken from the One family.
