# macbyclp/obsidian-memorry

This plugin adds a sidebar pane for the Markdown notes that the memorry MCP memory server mirrors into a vault, reading their id, project, created_at and pinned frontmatter straight from Obsidian's metadata cache. The pane offers a search box that filters by title and project as it is typed, a project dropdown, a section that keeps pinned records at the top, and a list that re-scans as notes change, with one click opening the underlying note. It is read-only and works while the server is not running: records cannot be added, deleted or pinned from inside Obsidian, and search is a substring match rather than the server's own ranked full-text search. A setting names the vault-relative folder when the server's sync folder differs from its default.
