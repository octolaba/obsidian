# Sisyphe42/obsidian-logseqer-plugin

The Logseqer plugin aims at a Logseq-native experience in Obsidian and at workflow compatibility between the two applications, with each feature switchable on its own in settings. It validates in real time whether lines follow Logseq's dash-space format and reports that in the status bar, and offers a command that checks date formats, journals and pages settings, namespace consistency and task markers across the vault. It also syncs Logseq favorites into Obsidian bookmarks, handling duplicates and creating missing pages after manual confirmation, and auto-formats new journal files with a customizable default backlinks query. The README marks the vault compatibility check as work in progress and lists page preview and clearing unused journals as to-do items.
