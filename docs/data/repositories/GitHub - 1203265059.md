# totocaster/vault-tasks-obsidian

Vault Tasks collects Markdown tasks from every note into a grouped sidebar view while the original notes remain the source of truth, so checking a task in the view updates the note it came from. The README describes grouping by note and optionally by source heading so the list reads like ordinary Markdown headings, filters by pending, completed or all and by section name across notes, pinned notes at the top, inline and context-menu actions, and note-level frontmatter keys that defer or hide a note. A companion command-line tool reads the same vault and plugin settings and renders the same grouped view for scripts, terminals and agents.
