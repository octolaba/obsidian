# Yorkli1/Unified-Chinese-Characters-Searcher

Repository for a search plugin that expands a global search query to cover both simplified and traditional Chinese forms of the characters typed. Its README states that the query is rewritten as alternatives joined by OR while non-Chinese words are left as they are, so a note is found regardless of which variant it was written in. It records four mapping modes, covering simplified against Hong Kong or Taiwan traditional forms, all regions at once, and the two traditional forms against each other, and settings for a toggle, the mapping region and the delay before expansion.
