# iVariable/Obsidian-Format-Code

The repository holds an Obsidian plugin that adds commands for formatting code, using Prettier underneath. Its README lists JSON, YAML, HTML, GraphQL and TypeScript as the supported languages. It records that the plugin was not published in the community directory at the time of writing, so installation meant cloning the repository into the vault's plugin folder and building it.
