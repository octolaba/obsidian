# Meikul/obsidian-thumbnails

This plugin turns a video link into a thumbnail inside a note, working with YouTube and Vimeo. One command builds the block from a URL on the clipboard, a block naming the video type can also be written by hand, and a further command inserts a link whose text is the video title. Settings decide what is kept for offline use, saving the thumbnail information by default and the images themselves only when asked.
