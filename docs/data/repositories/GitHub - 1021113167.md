# TGRRRR/Canvas-link-to-group

This repository holds an Obsidian plugin for Canvas that creates links pointing at a specific group inside a canvas file and jumps to that group in one click. Links are produced by right-clicking a group and copying its link, or by selecting a single group and running a command that can be bound to a hotkey; the resulting link names the canvas file with the group name after a hash. Left-click opens the canvas in the current tab while Ctrl or Cmd click and middle-click open it in a new one, and the plugin reports when no group is selected or when the target name occurs more than once in the same canvas.
