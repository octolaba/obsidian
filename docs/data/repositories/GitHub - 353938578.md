# aidenlx/cm-chs-patch

This plugin patches Obsidian's built-in CodeMirror editor to support Simplified Chinese word splitting, so that double-clicking selects a Chinese word in edit mode and Vim mode can move the cursor by word. The README states that from version 1.8.0 the default segmentation engine is the system-provided one and the jieba engine is no longer a required component, remaining an option for use with the omnisearch plugin or for more precise segmentation, new-word discovery and a custom dictionary. It also discloses that on desktop the plugin uses Node's `fs` module outside the Obsidian vault API to store the jieba WebAssembly file in Obsidian's shared userData directory, so it is not installed once per vault.
