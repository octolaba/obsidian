# chernodub/obsidian-llm-shortcut

Obsidian plugin that turns Markdown prompt files into command-palette entries: a prompt folder is mapped to commands, including nested folders, and running one sends the active note to an OpenAI-compatible provider. The response is streamed into the editor at the selection or cursor, while a frontmatter option makes a prompt show its result in a popup instead of editing the note, and a separate command covers one-off prompts with no file. The user supplies their own provider, base URL, API key and model name; the prompt files themselves stay in the vault.
