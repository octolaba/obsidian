# hailp-vn38/obsidian-dayline-plugin

Dayline captures short daily check-ins in a right sidebar timeline view, creating daily timeline files automatically and saving each entry as a Markdown block with hidden JSON metadata. Entries hold text, images, files and audio recordings, can be filtered by text, tag, time range and date preset, and can be opened at their source, edited, duplicated or deleted; check-ins are also created from the active note, a selection or the file menu, and a code block embeds a filtered timeline. Storage is local-first and markdown-first, with timeline files and attachments in configurable folders, file metadata in frontmatter and entry metadata in a hidden comment block. The README states source context is additionally written as a normal wikilink so backlinks and graph view see it, and that no note content, attachment, audio or clipboard data leaves the device.
