# lin-stephanie/obsidian-url-display

URL Display extracts the external URLs of the active note, including notes rendered by the Kanban plugin, and lists them in a pane. The README records settings for deduplicating URLs, ignoring the file's properties, using aliases, and showing favicons, an indicator icon and hover previews. The list refreshes when the reader switches notes unless it has been locked, and within the list a left click navigates to the URL's position in the note, a middle click opens it in a browser tab, and a right click copies it or starts a global search.
