# Spekulucius/obsidian-brainhack

Spekulucius/obsidian-brainhack holds Brainhack, a minimal Obsidian theme whose description and README state that it derives its customization from the accent colour alone, in light and dark mode. Every built-in callout type is restyled with a tinted background, a coloured outline and a dashed title separator, and the theme adds callouts of its own: one following the accent colour, one without an icon, one laying its content out in responsive columns, and one drawing an accent-coloured ring. Headings come in three variants switchable in Style Settings, coloured text, badges with a background, or an underline, with a colour picker per heading level. Style Settings also drives folder colouring by nesting depth across four levels, with an option that highlights the currently open folder.
