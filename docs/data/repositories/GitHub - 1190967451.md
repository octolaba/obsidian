# Kpyruy/Arbor

An Obsidian plugin that edits a single Markdown note as a left-to-right tree of small blocks, keeping the note itself an ordinary .md file with no canvas file and no sidecar database. Block markers and an in-note structure footer stay readable in the Markdown body so the arrangement can be recovered, and the editor adds inline editing, a selected-block panel, context-aware dimming, drag-and-drop reorder and reparent, keyboard navigation and a block-level search overlay. The README positions it for drafting, study notes, argument building and rearranging long notes rather than as a canvas or mind map, and records it as desktop-only, requiring Obsidian 1.5.12 or newer and tested on 1.12.4. The repository carries no description.
