# AkiSantin/Nodian

This repository holds Nodian, an Obsidian plugin that keeps bidirectional relations in YAML frontmatter in sync: adding a link to a property in one file writes the matching backlink into the paired property of the target file, and deleting the link removes it. Property pairs are configured explicitly and each pair requires tags, so a sync fires only when both the property and the tag match. The README also records optional use of a title property as backlink display text, tags and backlinks added automatically when a file is created from a link, a full sync from the ribbon icon, settings or command palette, and English, Japanese and Traditional Chinese localization.
