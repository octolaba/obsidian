# Isolyth/implicit-macros

Implicit Macros runs inline AI macros inside an Obsidian note: typing a prompt between the plugin's markers fires a call to an OpenAI-compatible chat endpoint when the closing marker is typed, and the response streams back in place of the source text. While the call is in flight the macro text is replaced by animated braille-dot spinners matched to its width, and arriving tokens replace those spinners with each new chunk briefly highlighted in the accent colour before fading over about one and a half seconds. The endpoint is configured in the plugin's settings after enabling it, and the README documents both a community-plugin install and a build from source in which the Obsidian, CodeMirror, Lezer and Node imports resolve to Obsidian's own runtime copies rather than being bundled. This note is grounded in the README alone, as the repository records no description.
