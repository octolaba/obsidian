# Pug0r/obsidian-fragrantica-plugin

An unofficial plugin that searches the Fragrantica perfume site from inside a vault. Typing two exclamation marks followed by a perfume name opens a dropdown of live results and inserts the chosen one, by default as a markdown link, with per-query flags that insert the image or the site's social card instead. A ribbon icon and a search command open a modal that creates a new note for the selected perfume with its social card at the top, in the vault root or a configured folder; the README states that an existing note of that name is opened without being modified. Default output format, image and card widths and the target folder are set in settings.
