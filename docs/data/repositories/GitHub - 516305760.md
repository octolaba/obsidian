# benr77/obsidian-gitlab-issues

The repository holds Gitlab Issues, an Obsidian plugin that imports issues from GitLab, creating one note per issue in a configured output directory from a customizable template. Its README states that those notes are intended to be read-only, since a note is removed from the vault once its issue is no longer returned. It records the refresh schedule as thirty seconds after Obsidian starts and every fifteen minutes thereafter, and the configuration as a personal access token with API scope entered in the plugin settings.
