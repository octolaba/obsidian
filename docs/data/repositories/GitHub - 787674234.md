# jasonmotylinski/hierarchical-backlinks

This plugin displays the backlinks of the active document as a hierarchy built from the folder structure of the referencing files, rather than as the flat list the core backlinks plugin shows. The tree is collapsable and its entries are clickable links to the references. The README gives the motivation: the author organizes notes into directories and wanted for backlinks the kind of overview the tag hierarchy display already gives for tags.
