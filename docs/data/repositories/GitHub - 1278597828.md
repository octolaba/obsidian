# LiveAQuietLife/obsidian-hold-course

Hold Course is an Obsidian plugin that tracks academic coursework inside the vault, with no account and no external syncing. The README records classes organised into semesters, each class holding its own lectures, assignments, exams and a library of resources, whose items are advanced through their statuses and optionally linked to notes in the vault. It records the plugin opening as a full-width tab from a ribbon icon, a first-run flow that creates a semester, adds classes, then adds lectures, exams and library resources, and further views including a calendar, an assignments view, a today strip and a today sidebar together with command palette shortcuts. The README states the plugin is designed for desktop and that mobile is not supported.
