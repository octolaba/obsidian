# dseaman/Kandyban

Kandyban gives a board view and a list view over Markdown project items that lead with bold-key metadata such as status, priority and milestone, and it was built against the SweetClaude project convention. Cards drag between status columns and enum cells are edited inline through a native Obsidian picker, with writes going back to the same files so that annotations after the value stay byte-identical and the rest of the file is untouched. The list view is a table of identifier, title, status, horizon, milestone and scope, with search by identifier or title and filters populated from the values actually present in the vault. Kandyban reads the project's mode field from its phase file and adapts its views to it, and the README positions it as a visibility layer beside SweetClaude rather than the primary working interface.
