# fnsign/embedded-omnisearch

Embedded-Omnisearch renders a search interface inside a note from a fenced embedded-omnisearch code block, drawing its results from the Omnisearch plugin's API. The README describes paginated results in a compact table of file name, relevance score and excerpt, accent-insensitive matching with a configurable highlight color and opacity, Enter to search and Escape to clear, a debounced input, and the full file path shown as a popover while Alt is held; page size is set globally and can be overridden per block. It states that Obsidian 1.0.0 or later and the Omnisearch community plugin are required, and discloses no telemetry, no network requests and no access to files outside the vault.
