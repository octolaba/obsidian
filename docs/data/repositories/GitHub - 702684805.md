# behrouze/obsidian-theme

Theme Perso is an Obsidian theme its author created for personal use. The motivations recorded in the README are a light theme, a clear separation of headings by distinct size, spacing and colours, and code snippets that stand out from the surrounding text. Screenshots of the overall look, the headings and the code blocks are kept in the repository, and contributions are invited by pull request.
