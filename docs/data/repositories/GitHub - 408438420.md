# aleksey-rezvov/obsidian-local-images

The repository holds Obsidian Local Images, a desktop plugin that finds links to external images in notes, downloads those images into the vault and rewrites the links to point at the local copies. Its README records a media subdirectory as the download target and gives keeping pasted web content usable as the motivation, since an external address can move or expire. Two commands are documented, one processing the active page and one processing every note matching an include pattern set in the plugin's settings, and the README advises keeping backups because the plugin is young.
