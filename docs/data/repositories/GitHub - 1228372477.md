# DuckTapeKiller/horme

Horme is an Obsidian plugin providing a chat assistant over the vault, described upstream as privacy-first and driven by local language models by default. The README records two models being needed — an embedding model that indexes the vault and a chat model that answers questions — recommends managing them in LM Studio, names specific embedding models for single-language and multilingual vaults, and describes enabling local vault memory in settings and waiting for the status bar count to finish before querying. Its recorded retrieval layer is a vault index with character-offset indexing, and the description records privacy firewalls that apply when optional cloud models are enabled. The README states that with local providers no data leaves the machine and no API keys are needed, while a cloud provider means the API key is stored.
