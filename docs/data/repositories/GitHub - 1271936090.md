# fyaic/Docferry-Obsidian-Plugin

DocFerry publishes one selected Markdown note from Obsidian as a read-only web link, optionally carrying a document password or an expiration date, and the link can be copied, opened, updated or stopped later from a shares screen without its URL changing. The README states that only the chosen note or folder is published, that the vault is not turned into a website and unrelated content is not scanned, and that a share renders the note with bounded reading styles and the local assets it explicitly references. The plugin can also import a DocFerry share and its listed assets into the current vault, or save a public web link as a local Markdown note. Publishing a folder as a navigable share and applying a bounded full-theme snapshot are described as Pro capabilities of a connected account, and the plugin stops and explains rather than falling back when they are not authorized.
