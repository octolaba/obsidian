# asinkLuno/bullet-journal

Bullet Journal brings the method's notation into Markdown notes: one command cycles a line through task, completed, migrated, scheduled, note and event symbols, another cycles the priority, inspiration and to-explore signifiers, and both are highlighted in reading view. Commands open or create today's daily note, the current monthly log with a calendar and tasks section, a future log with one section per month for the next six months, and an index note linking every entry, refreshed automatically as entries change. Migration commands move unfinished tasks forward from the previous daily note, from last month's logs or from the future log, marking the source lines as migrated or scheduled. Everything lives in a configurable journal folder, and the repository also ships an agent skill for maintaining the journal in natural language.
