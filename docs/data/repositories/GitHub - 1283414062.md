# Arislan-x/multidim-virtual-folders

This repository holds MultiDim Virtual Folders, an Obsidian plugin that builds any number of virtual folder trees from note frontmatter, so one note can appear under a date, a project, a source and a topic at once while the real Markdown file stays exactly where it is. Each dimension can be shown in the left sidebar, the right sidebar or both and switched from compact sidebar icons, date dimensions can start from year, month or day, and path dimensions build nested virtual folders from frontmatter paths. The README also records temporary virtual paths that create no real folders and dragging a Markdown note into a virtual folder to update its frontmatter; documentation is available in English and Chinese.
