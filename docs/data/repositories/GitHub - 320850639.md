# lumoe/obsidian-rollover-daily-todos

The repository holds Rollover Daily Todos, an Obsidian plugin that carries incomplete todo items from the previous daily note — yesterday's or an older one — into today's. Its README records that the rollover fires automatically when a new daily note is created by the core Daily notes plugin or by Periodic Notes, and that it can also be run as a command from the palette. It warns that the automatic path can conflict with other plugins, Templater in particular, and recommends disabling automatic rollover and triggering it manually in that case.
