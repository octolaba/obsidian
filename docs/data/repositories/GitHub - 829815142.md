# StructByLightning/obsidian-recursive-copy

Recursive Copy adds a context-menu item to the file explorer that, on a folder, copies every Markdown file underneath it, concatenates them and places the result on the clipboard. The same action can be bound to a hotkey, which is unbound by default and operates on the parent folder of the active file. The README states that it is meant for loading vault context into language-model tools quickly.
