# shuuul/obsidian-pivi

Pivi embeds the Pi agent inside Obsidian as a vault-native assistant for chatting with notes, precise edits, links, frontmatter, backlinks, and knowledge-work tools. It can delegate work to concurrent subagents, expose commands, skills, tools, and MCP servers through a slash catalog, and provide inline editing for selected text with a configurable toolbar. The plugin presents recoverable changes through Obsidian mechanisms and is a knowledge-work agent rather than a coding terminal.
