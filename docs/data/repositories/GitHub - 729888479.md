# pixley/pf2e-statblock-for-obsidian

PF2e Statblocks renders Pathfinder Second Edition statblocks from Markdown written inside a code block tagged for its syntax, with a second tag switching to Starfinder 2e theming. Inside the block the name is a first-level heading and the statblock type and level a second-level heading, traits are wrapped in double equals signs with size and rarity coloured automatically, and a third-level heading marks the abbreviated statblocks used for short NPC entries. Horizontal lines break a statblock into sections, two line breaks reset indentation, and inline codes insert the one-action, two-action, three-action, free-action and reaction icons.
