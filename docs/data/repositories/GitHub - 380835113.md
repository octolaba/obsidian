# chetachiezikeuzor/Highlightr-Plugin

Highlightr brings a highlighting menu into Obsidian, described upstream as a minimal and aesthetically pleasing menu for colour-coded highlighting. Highlights are written as inline CSS so exported notes do not depend on external styling, and the supplied colours were chosen to work across themes in both light and dark mode. New highlight colours are defined in the settings tab with a name and a colour picker, and the plugin contributes Highlight and Unhighlight items to the editor context menu.
