# richin13/obsidian-brand-icons

Brand Icons renders company logos and icons inline in Obsidian notes from a colon-delimited token naming a domain, with optional variant and pixel-size overrides separated by a pipe. Variants are icon, logo or symbol depending on the provider, and settings choose the provider, the default size and the default variant; the README notes that Brandfetch, the default provider, requires a client ID from its developer portal. Rendering is handled by a Markdown post-processor in reading mode and by CodeMirror decorations in Live Preview, which reveal the raw syntax when the cursor enters it.
