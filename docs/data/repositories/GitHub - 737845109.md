# alexgavrusev/obsidian-format-with-prettier

This repository holds format-with-prettier, described upstream as formatting files in an Obsidian vault using Prettier. The README says format on save is enabled by default and can be changed in the plugin settings, and that a Format current file command is also available. Configuration is read from a prettierrc.json file at the vault root, deliberately without a leading dot, and the README points to the Prettier command-line tool for formatting an entire vault at once.
