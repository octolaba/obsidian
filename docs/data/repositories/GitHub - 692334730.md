# tech-reclipped/ReClipped-Obsidian-Official

The official ReClipped plugin, maintained by the ReClipped team, exports annotations taken on that platform's supported video sites into Obsidian and lets the videos be played and seeked to an annotated timestamp inside the app. Each video's annotations land in a file linked to its channel note, which is in turn linked to the platform note, and tags are searchable while snapshots render as images. The README states that the plugin requires a paid subscription, and credits the Obsidian Timestamp Notes plugin for the video preview and timestamp seeking and the official Readwise plugin as the model for its own design.
