# windzu/windy

An experimental agent plugin whose unit of work is the open note rather than a chat tab: a floating button in the bottom-right corner opens the conversation most recently used for the current page, and switching notes switches the agent's context with it. Other notes are added as extra context through mentions while the page stays the primary context, and a page may hold several conversations without exposing chat-tab management. The stated goals include keeping background tasks, drafts, streaming state and approvals alive across page switches, supporting Markdown notes first and later Bases, Canvas, PDF and pop-out windows, and staying local-first and provider-neutral. Its first implementation copies a snapshot of Claudian's runtime contracts and Codex adapter rather than depending on it.
