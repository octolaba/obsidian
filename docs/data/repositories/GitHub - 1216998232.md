# LLLin000/PaperForge

PaperForge brings a Zotero library into Obsidian for syncing papers, running OCR, extracting figures and AI-assisted deep reading. Its README stresses that the project has two parts: the Obsidian plugin providing the dashboard, buttons and settings, and a separate Python package installed into the system Python that performs the sync, OCR and repair work, so every button in the plugin runs a Python command behind it. It states that after installing the plugin the user must verify that the Python package is installed and version-matched, and it documents installation from the community browser, through BRAT, or manually from releases.
