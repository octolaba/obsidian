# nmady/obsidian-multi-line-formatting

Multi-line Formatting is an Obsidian plugin that applies paired formatting over an entire selection even when the selection contains paragraph breaks. The command, by default named Format even over multiple lines, applies the configured left and right markers, and with an empty selection it toggles the formatting on for what is typed next or formats the word the cursor touches when that option is enabled. Several formatting styles can be defined in the settings, each with its own left and right strings and its own command nickname, and a Skip Headings toggle leaves headings inside a large selection unformatted. The README warns against starting a selection inside another pair of formatting markers and describes the plugin as new and only lightly tested.
