# Creling/obsidian-image-uploader

The repository holds Obsidian Image Uploader, a plugin that uploads an image from the clipboard to an image host as it is pasted, optionally resizing it first. Its README records the settings as the host's API endpoint, request header and body in JSON, the path at which the image address is found in the response, a resize toggle and a maximum width beyond which an image is scaled at its natural aspect ratio. Its changelog notes a command for uploading every local image in the current page and support for the Live Preview editor.
