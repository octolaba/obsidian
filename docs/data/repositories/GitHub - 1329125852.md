# NameIsKyro/known

A people directory in which every person stays an ordinary Markdown note with readable YAML properties and a free-form body. A workspace tab lists everyone with photos, relationships and last-contact dates, searchable across names, aliases, pronouns, organizations, contact details, tags and locations, sortable by name, modification time, upcoming birthday or favorite, and filterable by relation, company or tag. A profile view shows only the properties that are populated, including user-created ones, renders a birthday as an ordinal date with the age being reached rather than storing a stale field, and renders the note body as normal Markdown. People are created and edited through a guided form that omits blank optional properties and preserves unknown frontmatter; fields can be added, hidden, reordered or relabeled, and relations and locations optionally mirror to tags.
