# mnaoumov/obsidian-frontmatter-markdown-links

This repository holds Frontmatter Markdown Links, described upstream as an Obsidian plugin that adds support for Markdown links in frontmatter. The README contrasts what Obsidian resolves natively in frontmatter, wikilinks and bare external addresses, with what the plugin adds: Markdown-style links to vault files including percent-encoded and angle-bracketed paths containing spaces, external addresses carrying an alias, and embedded forms of both. A demo vault of usage examples ships with every release and can be opened by a command, downloaded from the releases page, or browsed inside this repository.
