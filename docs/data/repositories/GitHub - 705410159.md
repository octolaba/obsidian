# clairefro/obsidian-chat-cbt-plugin

A journaling assistant that prompts the writer to reframe negative thoughts, modelled on cognitive behavioural therapy. The README describes chatting inside a note and then summarizing the reframed thoughts into a table of affirmations, with conversations stored as local files that can be kept as a diary or shared with a therapist. It states that the model connection is configured in the settings and can be a cloud service, naming OpenAI and Deepseek, or a local Ollama service, that the system prompt is editable, and that desktop, mobile and over sixty languages are supported. The README carries its own disclaimer about what the plugin is not.
