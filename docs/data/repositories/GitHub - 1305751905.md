# sidny1988/Glass-Scholar

sidny1988/Glass-Scholar holds Glass Scholar, a frosted-glass Obsidian theme whose transparent interface is built from pure CSS radial-gradient glows and backdrop blur panels, with no hard dividers or card shadows. Its typography targets academic writing through serif body text, justified paragraphs, first-line indentation, drop caps and three-line tables, and the theme follows the system light or dark scheme automatically. The README records mobile spacing and size adjustments, dedicated print rules for PDF export, and eleven configuration options exposed through the Style Settings plugin.
