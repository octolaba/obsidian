# dvrch/mergdown2tex

mergdown2tex converts an Obsidian note into a LaTeX document, expanding embedded notes recursively and translating wikilinks into cross-references, image embeds into includegraphics, citations into citation commands with navigation arrays, inline and display math into equations, Mermaid diagrams into rendered PNGs, and callouts into tcolorbox environments. The Markdown-to-LaTeX step runs in a Rust WASM engine inside Obsidian and needs nothing else installed; producing a PDF additionally requires TeX Live with Podman, and DOCX output goes through Pandoc. The README also lists a .tex file for manual editing and InDesign-compatible output among its output formats.
