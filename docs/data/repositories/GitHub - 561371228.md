# hankjs/obsidian-code-preview

Obsidian plugin that renders a code block from a file path rather than from inline text. The block is configured in YAML with a required path, resolved relative to the note or from the vault folder as root, an optional language that otherwise follows the file extension, and start and end bounds given as line numbers, search text or regular expressions, where an end value such as a plus one is counted from the start. Lines can also be highlighted by number, by range, by search text or by regular expression, with several rules separated by commas or written as a YAML list.
