# tcyeee/obsidian-bases-lock

Bases Lock hides the Bases toolbar and disables header interaction for selected Base embeds in Obsidian Reading view, reducing accidental changes in a clean display. Locking rewrites the embed or inline Base block so its state is saved in the note, affects only the current document, and can be reversed with the unlock control.
