# iiz00/obsidian-multiple-notes-outline

Multiple Notes Outline is an Obsidian plugin that shows the outlines of several files at once through two views. Its File View lists the outline of the active file together with its outgoing link files and its backlink files — the local graph at depth one, with the backlinks of those files, so-called two-hop links, optionally shown as well — and refreshes when another file becomes active. Its Folder View lists the outlines of the files in a chosen folder. The README presents the plugin as an adaptation of the same author's Daily Note Outline plugin to ordinary files, recommends installing Dataview to speed up backlink retrieval, and carries a Japanese version of the documentation in its second half.
