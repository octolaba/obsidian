# aleksey-rowan/obsidian-vim-yank-highlight

This plugin highlights the yanked region in Obsidian's Vim mode with a brief animation. The README explains the reason it exists: the Vim mode in CodeMirror has no native support for highlighting yanked text and is unlikely to gain it, and although another yank-highlighter plugin already exists, it relies on monkey-patching the codemirror-vim code, which this author wanted to avoid. It can be installed from the community plugins browser or manually by extracting a release into the vault's plugins folder, and it is licensed under MIT.
