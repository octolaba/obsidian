# robertoallende/fancy-charts

Fancy Charts renders interactive charts from a fenced fancy-charts block inside a note, keeping the data as a plain Markdown table that stays readable in any editor without the plugin. Eight chart types are supported: bar, line, pie, scatter, area, funnel, heatmap and sankey. A simple mode takes a short YAML config naming the type, title and axis columns followed by the table, while an advanced mode accepts a raw ECharts option object for full control. Charts are inserted and edited through a builder modal with a live preview, reached from a command, a ribbon icon or an edit button on a rendered chart, and rendering follows the active light or dark theme.
