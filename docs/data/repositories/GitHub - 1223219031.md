# karx/kaaroGarden

eBrain Gardener adds a process, triage and publish pipeline for digital-garden vaults to Obsidian. The README states that notes in configured inbox folders are scored, with a maturity tier derived from word count — stub, seed, budding, evergreen — and that notes scoring at or above 0.7 are highlighted in a sidebar queue alongside maturity stats and stage buttons. A process command asks an LLM provider — Gemini, OpenAI, Anthropic or Ollama, configured with a model and API key — for frontmatter and internal-link suggestions shown in a diff modal, while the publish command enriches a note and marks it published behind an approval gate; a triage modal, a status bar maturity icon and a ribbon badge complete the interface.
