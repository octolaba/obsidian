# ramysami/obsidian-quran-plugin

Quran Inserter fetches Quranic verses from the Al Quran Cloud API and inserts them into the current Markdown note in Obsidian. A reference is given in surah:verse form in a modal opened from a ribbon book icon, the command palette or an assigned hotkey, and the fetched text is placed at the cursor position with line breaks handled. The README records the plugin as pending addition to the community plugin list and documents installation through BRAT or by hand.
