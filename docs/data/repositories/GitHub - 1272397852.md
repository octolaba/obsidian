# wrojasa/obsidian-dbml-erd

DBML ER Diagrams renders dbml code blocks as interactive entity-relationship diagrams with automatic elkjs layered layout and orthogonal right-angle routing in the dbdiagram.io style, re-routed live as tables are moved. Cardinality uses one symbol per endpoint, a crow's foot on the many side and either a bar or a circle on the one side depending on whether the foreign key is nullable, alongside primary and foreign key icons and per-table header colours. The canvas pans, zooms and can be resized, and table positions, zoom, pan and canvas size are persisted inside the block and restored when the note is reopened. Renaming, recolouring, changing a column type or cardinality and deleting are done from the diagram and written back into the note's own dbml block, which the README calls the single source of truth.
