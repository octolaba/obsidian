# SVM0N/datadeck

Repository for DataDeck, an Obsidian plugin that opens plain CSV files in editable views — cards, kanban, a table, charts, a habit dashboard, a tasks board, a budget tracker, a one-entry focus reader and a travel map — offered according to the columns the file carries. Edits are made in place and written back to the single canonical CSV file, and when the file changed on disk during editing the other version is stashed to an archive folder instead of being overwritten. The README also documents embed blocks that put live views, charts, cross-file task boards and entry forms inside notes, and states that the views work on mobile.
