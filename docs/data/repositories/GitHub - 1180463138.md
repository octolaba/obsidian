# Riverise/obsidian-paste-polish

PastePolish removes the excess blank lines that appear when rich text from AI assistants is converted to Markdown and pasted into a note. Its README says the cleanup preserves the buffer lines that Markdown block elements need, naming tables, setext headings and horizontal rules as protected structures, so formatting is not broken by over-aggressive whitespace removal. Two modes are recorded: a gradual one that reduces runs of blank lines by a single step at a time, and an aggressive one that collapses every redundant blank line to exactly one in a single command.
