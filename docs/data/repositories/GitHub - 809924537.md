# Mara-Li/obsidian-context-menu-hider

Context Menu Hider hides commands, including those contributed by community plugins, from Obsidian's right-click menus. A command is hidden by entering its name as it appears in the menu, or by a regular expression enclosed in slashes with the usual flags, and changes take effect without reloading Obsidian. The README records two limits: the native menu must be turned off in the Appearance settings, and hiding by name removes every instance of that name across all context menus rather than a single one; a CSS class is exposed for styling the listed commands instead of removing them.
