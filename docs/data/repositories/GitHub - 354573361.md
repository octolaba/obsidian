# aidenlx/media-extended

Media Extended integrates media playback and management into Obsidian: it opens local files, remote URLs and videos from services such as YouTube and Vimeo, controls playback through global hotkeys, and can pin a player to avoid tab clutter. It inserts links to specific moments, captures and crops video screenshots embedded with a timestamp link, links SRT and VTT transcripts for navigation, search and timestamped quotes, and drops markers during Obsidian's audio recording that become clickable once the recording is saved. Link fragments set start and end times, looping and auto-play, and timestamp and screenshot formats are template-driven. The README records that future v4 releases will be closed source, with the codebase up to version 3 staying MIT-licensed on a separate branch.
