# HEONO3H/page-width-toggle

This plugin toggles the width of a single note between the Obsidian default and a wide mode that fills the window. Its README states that the width is set per note through a cssclass and does not touch the vault-wide readable line length option, and that the toggle is reachable from a ribbon icon, the command palette, the editor context menu and the note's more-options menu. The width classes live in a CSS snippet that has to be installed and enabled separately; that snippet also defines a narrow class of 560 pixels which sits outside the toggle cycle and can only be applied by hand in frontmatter.
