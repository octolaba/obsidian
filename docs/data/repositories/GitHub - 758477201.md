# onesvat/obsidian-pomodoro-planner

This plugin generates a daily plan based on the pomodoro technique, which its README describes as compatible with the Obsidian Day Planner plugin. A Pomodoro Planner generate command in the command palette builds the plan from the given input, and the result can be inserted at the cursor or copied to the clipboard. The README records that the Pomodoro Technique is a registered trademark of Francesco Cirillo and that the plugin is neither affiliated with nor endorsed by him.
