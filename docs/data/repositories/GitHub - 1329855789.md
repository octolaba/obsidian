# jhm531/obsidian-voice-notes

Reads the active note aloud, either in full or as a summary produced first by an OpenAI-compatible model at one of five compression levels between one and fifty percent. Speech comes from Microsoft Edge TTS over a WebSocket, which needs no key of its own, and is synthesized in segments of up to 500 characters; a player panel at the bottom offers pause, resume, stop, a progress bar and the text of the current segment. Playback can continue into the next note, stop at the end of the current one or loop it, and tables, images, code blocks, formulas, task lists and links are rewritten into speakable text before synthesis. Settings cover the API base URL, key and model, the summary ratio, playback mode, voice, speed and volume, with more than twenty Chinese neural voices offered.
