# abromberg/obsidian-collaborative-folders-plugin

Read-only release repository for an Obsidian plugin providing real-time shared folders and notes; the README points to a sister monorepo for issues, pull requests and server code. It describes sharing a folder from its context menu, sending an invite URL so the folder appears in another vault, seeing collaborators' cursors and editing together while Obsidian is open, with either self-hosting or a hosted service and notes stated to be encrypted end to end. The README labels the project beta software that may contain bugs, breaking changes, data leakage or data-loss risks.
