# LoyalPotato/potato-indexer

Potato Indexer generates a table of contents for a note from the Obsidian command palette. The README opens by noting that the plugin's own naming says index and indexer where table of contents is meant, and the recorded description keeps that wording, calling it an index generated from the selection. Two commands are recorded, one building a table of contents for the current note and one for selected content, and the README states that the existing table has to be selected when it is being updated.
