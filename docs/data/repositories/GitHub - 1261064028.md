# uataru/obsidian-one-dark-pro

One Dark Pro for Obsidian applies the One Dark Pro family of dark palettes to notes, Markdown previews, code blocks, sidebars, tabs, Canvas, graph view and other editor surfaces. It adapts palette decisions from Binaryify's OneDark-Pro, whose MIT notice the repository preserves, and exposes One Dark Pro, Darker, Mix, Flat and Night Flat as palette classes when the Style Settings plugin is installed. Because the community theme format installs one manifest and one stylesheet per selectable theme, the repository also provides a local build script that creates five separate theme folders.
