# mikagosz/obsidian-find-in-note

Searches the rendered note and highlights every match in place, using the CSS Custom Highlight API so no DOM node is touched and a wide table stays a rendered table instead of collapsing into raw Markdown. A small bar in the top right highlights matches as they are typed, marks the current one more strongly, steps between them with Enter and Shift+Enter or its arrows, scrolls only when the current match is off screen, and clears on Escape; matching is case-insensitive and literal. Opening it while editing switches the note to reading view and switches back when the bar closes. Because reading view renders long notes in pieces, the match total can climb while scrolling, and the built-in search binding must be cleared by hand before the plugin's shortcut can take that key.
