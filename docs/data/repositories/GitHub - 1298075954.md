# Lan-zk/obsidian-reader-margins

Reader Margins adds annotation cards to the margins of Obsidian's built-in PDF reader: selected text is highlighted or underlined in one of several colors, and a card holding the quoted passage and a note is drawn beside it, linked to the mark by a dashed connector. Cards can be dragged to a fixed position or left to lay out automatically, edited in place, and switched between a persistent card and a hover popover, falling back to a popover when the margin is too narrow. Every annotation is stored as a blockquote in a managed Markdown note kept per PDF, so annotations are searchable and syncable like any other note, and a second window editing the same one gets a conflict notice. An index view searches all annotations by PDF, quote or note and jumps back to the exact selection; the plugin is desktop-only and requires Obsidian 1.12.0.
