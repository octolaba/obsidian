# Snifer/lonelog

Lonelog brings the Lonelog notation for solo tabletop RPG journaling into Obsidian and extends it with a Partylog add-on for group sessions. Commands and hotkeys insert its core symbols for actions, oracle questions, dice rolls, results, consequences and entity tags, and the plugin creates campaign and session headers, automatically numbered scene markers and rendered lonelog code blocks. It adds syntax highlighting in Live Preview and Reading mode with per-token colours, dedicated views for progress, threads, scenes, combat, dungeon and resources, add-ons for combat, dungeon crawling, resource tracking, card drawing and dice notation, autocomplete from previously mentioned entities, English and Spanish interfaces, and a public API returning normalized JSON for other plugins.
