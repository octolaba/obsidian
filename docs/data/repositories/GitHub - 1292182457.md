# israerusan/attachment-audit

Attachment Audit scans a vault for unused attachments, duplicates, oversized files, junk names, and misplaced files, presenting evidence before cleanup. The free tier supports review, thresholds, reports, history, restore, and one-file actions, while Pro adds bulk trash, move and deduplication, saved scan profiles, custom rules, and severity tuning.
