# yut0takagi/obsidian-share-hosted

Share Hosted publishes an Obsidian note through a hosted service, offered by its README as an alternative to deploying a backend: the user signs in with a one-time link sent by email and no Cloudflare setup is required. Three commands are documented — sharing the current note after picking an audience and an expiry, copying the share address, and un-publishing it — and three audience modes: anyone signed in with an email in a configured organisation domain, only the addresses listed, or anyone holding the link with no login. The README records where the data goes: note content is stored on Cloudflare R2, reader authentication uses Cloudflare Access with a one-time email PIN, and the companion worker is a separate repository. It describes the service as an early free version without quotas.
