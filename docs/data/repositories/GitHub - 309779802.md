# nhaouari/searchpp

Search++ inserts the results of a text search into the note being worked on. A placeholder written in double braces names the text to search for and the number of characters to extract before and after each match, for example a note name or a tag together with a character count, and running the plugin's command with the cursor on that line writes the found notes below it. Running the command again on the same line updates the results. The README states that the plugin is based on the code of mrj-text-expand and needs Obsidian v0.9.7 or later.
