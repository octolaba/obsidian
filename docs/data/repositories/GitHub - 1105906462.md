# noi8282/obsidian-Pastel-Yumekawa-Theme

Pastel Yumekawa is an Obsidian theme built on pale lavender and pink pastels, and its README is written in Japanese. It describes a dreamy, cute palette kept legible over long note-taking sessions through high brightness, low saturation and soft gradients, and it records the colour codes assigned to backgrounds, accent, text, links, code and cursor. The README recommends selecting the light base theme and a Japanese-capable font such as Noto Sans JP at 16 to 18px.
