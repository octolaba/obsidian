# Kazi-Aidah/emoticon-picker

Emoticon Picker inserts text emoticons into Obsidian notes from the command palette, a hotkey or a ribbon icon. The README states that more than 200 emoticons are built in, and that users can add their own, mark favourites for quick access and hide the ones they do not use.
