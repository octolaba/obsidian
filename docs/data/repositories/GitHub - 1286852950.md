# polygonhunter/scalosaurus

Scalosaurus adds resize handles to embedded images in the editor, so dragging a corner writes the new dimensions back into the wikilink instead of typing a width by hand. A locked aspect ratio writes a plain width and lets Obsidian derive the height, holding Shift sizes freely as width and height, and dragging near the note's text column snaps with a guide line and writes a responsive token that keeps tracking the column. The link is updated once on release as a single undo step, targeting the exact embed that was dragged, and Escape cancels a drag while a double-click on a handle clears the size. It works in Live Preview and Reading Mode, handles embedded Excalidraw drawings, and only touches internal vault embeds rather than remote images.
