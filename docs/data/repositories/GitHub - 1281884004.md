# israerusan/obsidian-invoice-forge

Invoice Forge collects billable-tagged lines from notes across an Obsidian vault and turns them into a client invoice note. Such a line carries a client as a tag or inline field and a duration as a time range or an hours or minutes value, with optional rate and date overrides; without a date token the entry falls back to the note's frontmatter date, then a date in the filename, then the file's modified date. Creating an invoice asks for a client and a date range, gathers every matching entry into a numbered note, and stamps each source line with an invoice marker so the work cannot be billed twice, while lines inside code fences and frontmatter are ignored. Invoices can be marked paid, reopened when a payment falls through, and listed while outstanding; the README places PDF export, tax, reminders and payment tracking in a paid tier.
