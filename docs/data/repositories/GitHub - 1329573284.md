# ShakToth/Lancer-Obsidian-Addon

A companion plugin for running the Lancer tabletop RPG in Obsidian, meant to be used alongside a separate Lancer-OS theme. It highlights official status keywords in Reading View and shows the full rule text on hover, renders inline dice rolls and clock or progress-bar markers whose plus and minus buttons write back to the source file, and turns a lancer-stats code block into a per-tier stat grid. A right-sidebar encounter tracker locks to an encounter file, deploys several instances of one NPC with alphabetic suffixes, applies Grunt, Elite and Ultra templates, rescales a mech between tiers mid-combat, and tracks HP, Structure, Stress and Heat. Importers read LCP files and COMP/CON pilot JSON exports and inject the extracted data into the user's own note templates at a placeholder tag, with English and German localization.
