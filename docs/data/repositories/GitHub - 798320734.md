# jsifalda/obsipulse-plugin

YourPulse tracks the daily word count across the notes of a vault and draws the writing activity as a contribution-style graph, adding a writing streak and habit statistics. It can also upload selected notes to a public profile: a note is marked for publishing through a frontmatter property, changes are detected and the profile updated, embedded note references including section and block references are resolved before upload so published content is complete, Dataview queries are rendered, and HTML comments are stripped so commented-out material stays private. The README records a Private Mode, activated with a license key, which it describes as ensuring that no data leaves the vault.
