# bartekmp/koofr-obsidian-sync

The README describes a plugin that syncs an Obsidian vault with Koofr cloud storage against Koofr's public REST API v2, authenticating with an email and a revocable app-specific password rather than an OAuth flow. Sync is event-driven on vault file changes instead of polling, bidirectional with last-write-wins, create-duplicate or manual diff-based conflict resolution, and has an experimental pull-only mode; workspace UI state files are deliberately excluded, and any mount or shared folder can be targeted. The README states that the plugin is not affiliated with Koofr, that it works on iOS and Android without desktop-only APIs, and that its sync engine, conflict resolution and settings UI are adapted from the obsidian-onedrive plugin.
