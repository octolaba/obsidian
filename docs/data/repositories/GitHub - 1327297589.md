# k2ak3n/noesis-flow

Keeps tasks as ordinary Markdown checkbox lines in notes chosen by the user: one capture note plus any additional notes it indexes in place, with optional metadata carried in HTML comments for status, project, completion time and a stable identity. Projects are simply headings that can be registered to gain status and a due date, without tasks being moved or headings rewritten, and unrelated comments are preserved through edits. Dashboard, Task List and Calendar cover daily work, with a Monthly Planner, Kanban boards, recurring series, a Timeline and a Pomodoro timer as optional modules over a shared cached task index. Source-aware undo refuses to overwrite a task that changed outside the plugin, and nothing is sent over the network.
