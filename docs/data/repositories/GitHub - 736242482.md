# digitorum/obsidian-templayted-daily-notes

This repository holds Templated daily notes, an Obsidian plugin that creates a note from a chosen template through a shortcut in the right panel. The README records that each configured entry carries the icon for that shortcut, a description of the action, the template to apply and the directory the file is created in. The repository name and the recorded description spell the word template differently from the README heading.
