# c-sooyoung/kiwi-mono-obsidian-theme

Kiwi Mono is built around two stated desires, a monospaced font in editing mode with spacings consistent with the character widths and equal font sizes, and one accent colour from which the theme generates shades automatically. Its README records smaller heading margins, blockquotes and callouts styled to look more alike, a flatter interface where the sidebars and tab bar share the editor colour, and minor theming for the Pandoc Reference List plugin. It states that theme.css is generated by concatenating the files in the source folder, with editing and reading scoped separately.
