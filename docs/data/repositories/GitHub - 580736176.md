# slpbx/obsidian-plugin

Hints Flow is the Obsidian plugin of the Hints service: it saves captured data into the vault with a specified template, from sources including Telegram, WhatsApp, Slack, email, SMS and Raycast. Setup runs through the Hints web app, where an account is created, a flow with an Obsidian destination is defined, the capture sources and the tag that marks a capture are chosen, and the vault is connected. The capture template is then configured in the plugin's own settings.
