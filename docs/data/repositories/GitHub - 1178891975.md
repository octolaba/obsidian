# Howe-Ren/smart-order-list

Repository for Smart Order List, a plugin that renumbers and restyles ordered lists so their prefixes stay self-consistent. Its README sets out the rules it applies as a specification: consecution is treated separately for parallel lines within one nesting layer and for nested lines below a higher layer, and it distinguishes proactive triggers such as pressing Enter twice or escaping the prefix separator from passive ones such as a single Enter, a space or a tab. Tables in the README enumerate the prefix elements, their variations and how they may be mixed.
