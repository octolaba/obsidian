# dwbutler/obsidian-pdf-page-numbers

This plugin adds page numbers to PDFs exported from Obsidian, extending the native export dialog with a page-number toggle. The README records the configurable options: six positions across the top and bottom of the page, a format that is a bare number, a page-of-total form or a custom template with page and total placeholders, an option to skip the number on the first page, and settings for font size, font family, color and margins. It states that Obsidian desktop 1.12.4 or newer is required.
