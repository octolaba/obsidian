# gapmiss/livecodes-playground

Livecodes Playground is described as an open-source client-side code editor plugin for Obsidian powered by LiveCodes. Its README says playgrounds are created through a command that asks for a name, a markup language, a style language, CSS processors and a script language, and that the vault holds two configured folders, one for playground configuration files in JSON and one for the accompanying Markdown notes. It points to the LiveCodes documentation for the editor's own features and self-hosting, and records that the LiveCodes codebase can be self-hosted but is not fully offline, so an internet connection is required.
