# dario-baumberger/obsidian-image-to-text-ocr

Recognizes text in an image referenced from a note and writes the result back into the note. Six commands cover replacing the image with the recognized text, appending the text to it, or inserting it as the image's alt text, each in one variant using the language set in the settings and one that takes a custom language selection. Supported image types are jpg, jpeg, png, gif, bmp, pbm and webp; the README notes that inserting alt text overwrites any alt text already present.
