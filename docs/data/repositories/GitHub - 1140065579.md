# hutnerr/obsidian-attachment-placement

An Obsidian plugin that decides where a newly created attachment is stored from rules attached to files and folders, instead of one hardcoded attachment folder. When a resource is created the plugin checks whether the active file has a placement rule, then its parent folder, then that folder's parent, and applies the first rule it finds. The README positions it for people who paste images in often and want the results organised per note or per folder.
