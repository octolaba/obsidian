# UnMarkdown/obsidian-unmarkdown

Unmarkdown copies a note or selection formatted for a chosen destination, offering Google Docs, Microsoft Word, Slack mrkdwn, OneNote, email with inline CSS, and plain text, reached from the file explorer or editor context menu. It can also publish a note as a web page from a set of templates with a chosen URL slug, producing a shareable address. The README's network disclosure states that the plugin calls the Unmarkdown API for conversion, document operations, publishing, template listing, quota checks and OAuth token exchange, that all calls are authenticated with OAuth 2.1 and PKCE, and that nothing is sent without user action and no telemetry is collected. It records that a free account is required for all features, with quotas and additional templates and batch publishing reserved for a paid tier.
