# ruikurenaii/performium

Performium calculates a score for a vault modelled on the performance points ranking metric of the rhythm game osu, as a way of gamifying note-taking. A ribbon icon and a command run the calculation, which the README says is based on readability, complexity and information and shows its result in a modal after a wait that depends on vault size, while a second ribbon icon and command list every value calculated so far. A setting selects the version of the point system in use, and the README states that different versions produce different values and that this is not the official system and is not affiliated with the game.
