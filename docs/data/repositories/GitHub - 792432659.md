# bhavers/obsidian-ca

Downloads architectures from Cognitive Architect, also known as IBM IT Architect Assistant, into an Obsidian vault as notes and images. The README states that a Personal Token obtained from the Cognitive Architect support team, together with a base URL, must be entered in the plugin settings, and describes the workflow through a ribbon icon and a side panel where the architecture list is refreshed and an architecture selected. It argues that once the architectural artifacts are local Markdown notes, Obsidian's linking and other community plugins can combine them with the rest of the vault.
