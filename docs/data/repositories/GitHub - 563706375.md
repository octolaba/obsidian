# Quorafind/Obsidian-Daily-Notes-Editor

Repository for Daily Notes Editor, an Obsidian plugin that edits many daily notes inline on a single page, which its description compares to Roam Research's default daily note view. The view opens from a command or the left ribbon and can be filtered by time range — week, month, quarter, year, their previous counterparts, all notes, or a custom range — and switched between daily note, folder and tag modes. The README also documents sorting by creation or modification time, hiding frontmatter or backlinks, opening the view at startup, saved presets, keyboard navigation between notes, and a folder context-menu entry that opens every note in that folder.
