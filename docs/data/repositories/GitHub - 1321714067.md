# KKenny0/kami-reader-companion

Applies one continuous reading and editing presentation across Obsidian's root views, and gives active Markdown views wide-content handling that spends spare pane width on diagrams, tables, code and embeds, plus current-heading highlighting in the core Outline. Three commands toggle a deeper reading stage, a focus mode that follows the active editor line or the focused block in Reading View, and a transient white-page preview that recolours only the active leaf and keeps PDF export light in dark mode. None of these modes persist, no note content is written, and the previous theme is restored when the plugin is disabled. It is desktop-only, targets Obsidian 1.13 and later, and works with the Default theme without requiring the separate Kami Reader theme.
