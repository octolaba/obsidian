# israerusan/obsidian-task-calendar-bridge

Task Calendar Bridge exports dated Markdown tasks from an Obsidian vault into standards-based ICS calendar files that Google Calendar, Apple Calendar, Outlook and TickTick can read. The README records that it understands Obsidian Tasks and Dataview date syntax, produces timed, multi-day and duration events with stable event identity, and works offline without an account. A one-time paid tier is documented as adding whole-vault export without a cap, repeating events, reminder alarms, auto-export when notes change, folder filters and publishing for calendar subscription, while the free tier exports the current note without a cap and the next 25 upcoming tasks across the vault.
