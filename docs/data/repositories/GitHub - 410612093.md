# ozntel/ozanshare-publish-plugin

OzanShare Publish publishes Markdown notes from a vault with a single click, on desktop and on mobile. Each published file carries a unique code available only to its owner, and republishing after small changes keeps the same code and URL, so a link shared once stays valid. The README states that the project is not open source and that the plugin is available only to users at the author's Exclusive Support Level, who receive a token to enter in the plugin settings, and it describes the plugin as still at an early stage with bugs and missing features expected.
