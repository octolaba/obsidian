# jamiebrynes7/obsidian-todoist-plugin

This is an unofficial plugin that materializes Todoist tasks in Obsidian notes and syncs them bidirectionally between the two. Its README states that it is not created by, affiliated with or supported by Doist, and refers readers to a separate documentation site for installation and usage details.
