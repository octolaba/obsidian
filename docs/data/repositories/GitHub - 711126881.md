# marcel-goldammer/obsidian-keyword-highlighter

The recorded description says the plugin automatically highlights specified keywords within notes for visibility and quick reference. Per the README, typing a configured keyword highlights it, with TODO, ADD and FIXME predefined, and a new keyword is added from a settings button that takes the word together with a font colour and a background colour, while existing entries are edited or deleted in the same place. Matching is case-sensitive by default and can be made case-insensitive from a global settings toggle, and regular-expression patterns can be defined instead of plain keywords for advanced matching.
