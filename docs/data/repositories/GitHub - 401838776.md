# chetachiezikeuzor/MySnippets-Plugin

MySnippets is an Obsidian plugin that adds a status bar menu for managing CSS snippets from the workspace instead of the settings tab. The menu opens from the status bar and lets snippets be toggled on and off in place, which the README presents as a condensed version of the CSS Snippets section of the settings. The README records the plugin as available in the Obsidian plugin store.
