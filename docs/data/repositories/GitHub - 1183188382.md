# Nikolay-Eltsov/obsidian-yadisk-sync

Synchronises an Obsidian vault with Yandex Disk in both directions through a three-way merge, and the README states that it works on mobile, including iPad and iPhone. Sync can run automatically on file creation, editing, deletion and renaming, detects change with a single request per poll, transfers files in a configurable number of parallel streams, resumes an interrupted run where it stopped, and shows cancellable progress on mobile when a run lasts long enough to report. Conflicts are resolved per file by keeping the local copy, keeping the remote copy or skipping, one-directional push and pull modes exist, and glob exclude patterns and a maximum file size leave content out. Setup signs in through the browser, pastes the returned code back into the settings and sets the remote folder path.
