# afforai/obsidian-logically-plugin

This plugin puts the Logically AI research assistant beside the Obsidian editor for citation-backed research over the files in a vault. The README, which marks the plugin as beta, lists Semantic Scholar, Google and document-retrieval search modes, models from OpenAI, Anthropic and Gemini, inline citations with data sources shown in a table, editable custom instructions, and adding a chat answer to the active document in one click. It requires a Logically account and internet access because messages are sent to Logically's API, and the models available depend on whether the account is on the free or the unlimited plan.
