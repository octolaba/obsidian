# smikula/obsidian-limelight

The repository holds Obsidian Limelight, a plugin that spotlights the active pane so it stands out from the others. Its README records that the plugin had not yet been accepted into the community directory at the time of writing, and documents manual installation by extracting a release archive into the vault's plugin folder and enabling it in the settings. It is written in TypeScript under the MIT license.
