# yaye-work/obsidian-never-leave-graph-view

This plugin opens a companion pane in the right sidebar whenever the graph view is open, so notes can be previewed, edited and created without leaving the graph. Hovering a node previews it, clicking an existing node opens it for editing in that pane, and clicking a greyed-out node creates the note at that node's position, quietly deleting it again if nothing is typed. New notes can also be made anywhere on the canvas from a control-bar button or the right-click menu, and while a graph filter is active they are created to match it — in a path folder, or seeded with a tag or search term — with the filter briefly lifted when conforming is not possible. The README states that the plugin drives Obsidian's graph renderer through internals outside the public API, so a future Obsidian update could require adjustments.
