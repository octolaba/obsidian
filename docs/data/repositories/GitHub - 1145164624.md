# gogothegogo/Simple-exporter-for-LLM

Simple Exporter for LLM packages notes and folder structures into a single text output intended as context for a language model, and its README states the plugin itself was generated with an AI command-line tool. It exports a folder or a tag from the context menu, including nested tags, and offers a context builder for hand-picking files, folders and tags with a hybrid search and the ability to drop individual notes or sub-branches. Output can be XML, JSON or a custom template, includes the directory and tag structure, deduplicates notes that appear under several tags, and skips notes carrying tags listed in the exclusion setting; the README also records integration with the Notebook Navigator plugin's context menus.
