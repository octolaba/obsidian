# zhenya-yadlovskij/obsidian-book-highlights-importer

Book Highlights Importer pulls highlights and comments from a Yandex Books account into per-book Markdown notes, one book at a time through a provider, book and destination flow. Generated notes carry provider, book id, title, author and import-time properties, render highlights as blockquotes and comments as note callouts, and wrap imported content in a marker-delimited managed section. Re-importing replaces only that section and drops annotations the provider no longer returns, while content outside it and unrelated properties are preserved, and the plugin refuses to overwrite notes it does not recognise as its own. It needs Obsidian 1.11.4 or newer on desktop or mobile and a Yandex OAuth token held in Secret Storage; there is no background sync, no custom templating and no other provider.
