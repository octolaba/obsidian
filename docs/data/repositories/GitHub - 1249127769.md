# michael-andreuzza/sequoia-obsidian

Sequoia for Obsidian is the community listing of the Sequoia color palette, which its README calls elegant, minimal and clean. Six variants are listed, Moonlight, Monochrome and Retro each in a dark and a light form, of which the community theme ships Moonlight Light and Moonlight Dark in theme.css. The other four are distributed as CSS snippets under the variants directory, and the README says to enable only one dark snippet at a time.
