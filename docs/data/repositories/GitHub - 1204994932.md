# redsmite-com/redsmite-sync

Synchronises Redsmite reports into an Obsidian vault, polling for pending reports on a configurable interval of one to sixty minutes. It suggests a destination folder based on the client name and, after two identical confirmations, places later reports there automatically; a report already present in the vault is not downloaded again. Settings take an API token issued by an administrator and a default folder for reports with no client match, and the README states the plugin is desktop-only. Its README is written in French.
