# lukemt/obsidian-feeds

Builds a feed of bullet points about one topic. A feed code block placed in a topic note collects the bullet points elsewhere in the vault that link to that note. The README states that the Dataview plugin is required, and points to a discussion thread in the Obsidian community server for help.
