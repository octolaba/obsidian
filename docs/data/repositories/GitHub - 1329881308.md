# bobstanton/places-graphhopper

A routing provider for the Places plugin backed by GraphHopper. It builds routes between the waypoints in a block and isochrones around a center point, resolves search terms to place suggestions, reads elevation for the points of a track, snaps a recorded track to the road or path network, and identifies the named ways that track follows. Every request goes to the GraphHopper API, no background tasks run, and its map, overlay and routing code comes from places-shared.
