# farcaller/obsidian-clojure-plugin-host

Clojure Plugin Host lets simple Obsidian plugins be written in Clojure — SCI specifically — from inside Obsidian itself. A plugin is a note tagged `clojure-plugin` containing a single Clojure code block that defines an `on-load` form, which the host calls at plugin initialization and which receives the plugin object so it can add status bar items and ribbon icons. The README states that as of version 0.1 the Dataview plugin must be installed, and that the repository is forked from the Obsidian sample plugin template while the Clojure code in it is distributed under Apache-2.0.
