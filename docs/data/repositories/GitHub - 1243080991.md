# maoqingwei/obsidian-version-view

Version View is a version management plugin for Obsidian that saves, manages and compares versions of a file and restores them. The README lists saved snapshots with an optional name, a side-by-side diff with line numbers marking added and removed content, comparison of any two versions or of a version with the current document, one-click restore, editing of a version's name and description, a fullscreen diff, a filter showing only changed lines, frontmatter distinguished visually in the diff, and settings for the storage folder and the maximum number of versions kept before old ones are deleted. It identifies itself as a community-maintained fork rebuilt because the original repository was missing its built main.js.
