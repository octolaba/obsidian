# Luis8492/ShogiView

ShogiView renders Shogi data embedded in Markdown code blocks, supporting KIF move records and the SFEN, BOD and CSA position formats. The README describes an interactive board that highlights the origin and destination of a move and shows captured pieces, comments, elapsed time and metadata, together with first, back, forward and last controls, keyboard shortcuts, autoplay and jumping to a move number. Variations are drawn as an SVG tree below the board whose nodes can be clicked to move to the matching position. Its installation section builds the plugin and copies the output into a vault folder whose name must match the manifest id.
