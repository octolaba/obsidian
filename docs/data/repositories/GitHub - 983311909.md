# mousebomb/obsidian-diary-ics

Repository for Diary ICS, an Obsidian plugin that publishes diary content as an ICS calendar feed for a system calendar application. It parses date-named diary notes, turns headings of a configured level into events on the date in the filename, reads a time in the heading as the event start and treats a heading without one as an all-day event, and serves the generated file on a local HTTP port that a calendar app — or another device on the same network — can subscribe to. Each event carries the heading as its title, a link that opens the diary file back in Obsidian, and the subheadings beneath that heading as its description, while a day's frontmatter can be emitted as an additional event through a customisable rule.
