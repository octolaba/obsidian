# Novitcz/Bullet-Time

Bullet-time renders a monospace text-art timeline from a bullet list in an Obsidian note. Each item carries a duration in days, weeks or hours, siblings chain automatically so a task starts where the previous one ended and only the dates that matter need pinning, and scheduling runs in calendar days or in a workdays mode that skips weekends. Nesting by list indentation gives lanes, projects and subtasks, per-task colours are supported, and children running past their parent's planned total are flagged in a warning colour. A timeline is written either in a bullet-time fenced block or as a plain bullet list tagged with a hidden comment, and bad input renders an error box under the timeline instead of breaking the note.
