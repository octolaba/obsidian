# bernardonogueira8/search-movies-tv-tmdb

This repository is an Obsidian plugin for looking up films and television series through the TMDB API, and its README is written in Portuguese. It describes searching TMDB from the command palette with metadata fetched automatically, generating Markdown records from templates carrying posters, ratings and synopses, following series by season with episode lists and viewing progress, browsing all viewing records in a card grid, and personal fields for impressions, a personal rating, the viewing platform and the viewing status. A free TMDB API key entered in the plugin settings is required, and the README recommends pairing the plugin with Obsidian Projects.
