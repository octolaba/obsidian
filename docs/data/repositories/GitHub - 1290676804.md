# grub-basket/starter-packs

Starter Packs turns a selection of a vault's community plugins and themes into a named, curated list that can be handed to someone else, which the README compares to Bluesky starter packs or mod packs. A pack is assembled by ticking plugins and themes in the plugin's view, with each plugin's name and description read from its manifest and an optional per-plugin comment and enable flag added by the author. A finished pack can be copied as an Obsidian URI link that opens an import preview for anyone with the plugin installed, as a short code that survives forums which mangle links, or as a readable Markdown list linking every plugin to its community page.
