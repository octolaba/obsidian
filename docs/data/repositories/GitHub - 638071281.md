# Mara-Li/obsidian-enhanced-copy

Obsidian plugin that copies a selection while keeping its Markdown formatting, aimed at reading view and at read-only views such as canvas where the native copy does not preserve markup. Settings choose which view modes are processed — reading, editing, or both — add a separate copy command per mode, and optionally override the default copy so the usual keyboard shortcut and context-menu entry route through the plugin. Reading and editing views are configured independently, so text can be transformed during copy in one view and left alone in the other.
