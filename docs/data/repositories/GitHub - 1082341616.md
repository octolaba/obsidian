# archivistai/archivist-obsidian-importer

An Obsidian plugin that imports selected vault files into Archivist campaigns. The import view is opened from a ribbon icon or the command palette, and the plugin expects an Archivist API key selected or created in Obsidian's secret storage. The rest of the README covers a manual build-and-copy script for development and the repository's stated conformance with Obsidian's plugin submission guidance.
