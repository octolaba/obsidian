# Falcion/Whisperer.md

Whisperer plays ambience music inside an Obsidian vault and can assign particular tracks to particular files. Its README frames this by observing that Obsidian is used not only as a zettelkasten but also for technical documentation and for creative work such as campaigns and world-building wikis, where a person may want musical accompaniment attached to a project or to individual notes.
