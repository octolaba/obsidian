# simonsbookclub/readingrate-obsidian

ReadingRate for Obsidian syncs reading data from the ReadingRate app into the vault as interconnected Markdown notes with YAML frontmatter and wikilinks, covering books, authors, quotes, journal entries, insights, completions, domain mastery, themes and a yearly timeline, plus dashboard pages built on native Bases views and Dataview queries. The sync runs one way, from the app into the vault, and is mirror-complete: notes for items deleted or renamed in the app are trashed on the next sync, while files the user creates anywhere in the vault, including inside those folders, are left untouched. Filenames are plain titles, colons become em dashes, books sharing a title gain the author's last name, and renames go through Obsidian's own rename so existing links follow.
