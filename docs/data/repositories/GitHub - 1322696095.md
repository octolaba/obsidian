# lee259/oh-my-claudian

Oh My Claudian embeds command-line coding agents in an Obsidian sidebar chat, letting them read, write, search and run commands in the vault working directory. It is a fork of the Claudian plugin that adds Oh My Pi and Cursor over ACP, covering seven providers in total - Claude, Codex, Cursor, Grok, Oh My Pi, OpenCode and Pi - each with its own model discovery, readiness diagnostics, permissions and reasoning controls. The chat supports multiple tabs, history, fork, resume and compaction, inline edits shown as word-level diffs, slash commands, skills, at-mentions, a plan mode toggled with Shift+Tab, and files dragged in as context chips. It needs at least one supported agent CLI installed and Obsidian 1.7.2 or newer on macOS, Linux or Windows, and can run beside the original Claudian plugin.
