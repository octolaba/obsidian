# SHU-red/propmove

PropMove moves Obsidian notes between folders according to their frontmatter properties. It watches for creation and frontmatter changes, skips notes in ignored folders, applies the first matching property mapping to determine the target folder, creates missing directories, and appends a numeric suffix when a file of that name already exists. Mappings support match operators such as equals, contains, is-empty and is-not-empty, resolve wikilink values to a plain folder name, offer autocompletion of property names and folder paths from the vault, and follow folder renames. The README states that the plugin is developed and maintained with AI agents.
