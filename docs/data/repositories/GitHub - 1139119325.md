# UniqueClone/bases-style-enhancer

Bases Style Enhancer customises the appearance of Obsidian Bases views, and this first version covers table font size only. It injects a CSS variable and rules so all Bases table cells use a configurable size in `rem` or `px`, with an option to apply the same size to table headers. The README records Obsidian 1.5.0 or higher as the compatibility floor and says further style options for Bases views may follow.
