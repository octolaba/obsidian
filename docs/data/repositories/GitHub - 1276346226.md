# hoxi/tidy-titles

Tidy Titles keeps note filenames as slugs while preserving the readable title in frontmatter: a note named with spaces and capitals gets a lowercase hyphenated filename, and the original text is written into a title field and an alias. It hooks Obsidian's own new-note flow, acting only on new empty notes, and adds commands to create a note from a title in a modal with a live slug preview, to rename a note's title and re-slugify its filename together, to re-slugify a note from its title field, and to slugify a folder name. Renames go through Obsidian's file manager API so links to the note are updated. The README suggests pairing it with the Front Matter Title plugin to display the original title in the explorer, tabs and graph while the files on disk stay slugged.
