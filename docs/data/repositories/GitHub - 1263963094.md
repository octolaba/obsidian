# Brightwav3/semantic-backlinks

Semantic Backlinks suggests notes to link to while text is typed in Obsidian, combining lexical matching with semantic search over embeddings. The README states that exact, prefix, partial and word-boundary matches appear instantly in an inline popup and semantic matches from the embedding model appear beneath them, with an optional snippet preview showing the best-matching sentence from each candidate, and that a sidebar panel lists the notes most similar to the one currently open. Embeddings come from a locally running Ollama or LM Studio model by default, or from the OpenAI API when that provider is selected, and the vault is indexed on startup with live progress and re-indexed after editing stops. Mobile use is recorded as working through Tailscale or local network access to the embedding host.
