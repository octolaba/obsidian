# joeytoday/obsidian-md2flomo

md2flomo sends an Obsidian note to the flomo memo service in one click, from a paper-plane icon in the sidebar or from the command palette. The README, written in Chinese and English, records that a flomo API token is configured in the plugin settings and can be checked with a test send, that frontmatter `tags` become flomo tags, and that the sent content bolds the title and places aliases and tags below the body. A batch-publishing view tracks each note as published or unpublished, and a confirmation dialog appears before sending when a note's `send-flomo` value is false.
