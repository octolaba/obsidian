# ce-omarbadawy/obsidian-my-svgs

This repository holds My SVGs, an Obsidian plugin that registers custom SVG files into Obsidian's global icon library so they can be used wherever Obsidian accepts an icon reference. Icons are loaded from an icons folder inside the plugin directory and become available under a customizable prefix, with a searchable grid preview in settings, live reload from a ribbon button, and one-click copying of icon references. The README notes that black colours are converted to currentColor so icons follow the theme, that loading continues when one file fails, and that the author relied heavily on AI while writing the code.
