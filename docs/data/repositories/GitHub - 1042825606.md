# bueckerlars/obsidian-codeblock-language-detector

Obsidian plugin that detects the programming language of code blocks written without a language tag and adds the tag so syntax highlighting applies. The README describes two detection methods used together: the Highlight.js library and pattern matching over keywords and syntax constructs. It shows a before-and-after example in which an untagged block of Python becomes a tagged one.
