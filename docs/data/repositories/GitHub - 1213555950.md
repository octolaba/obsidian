# sedetweiler/obsidian-alembic

Runs AI writing workflows over Obsidian notes, keeping the workflows themselves in the vault as Markdown files that can be edited, shared and run against any note. Backends are configured in the plugin settings and each workflow can target a different one; the README makes the Claude command-line tool the default, run in print mode and authenticated by the tool itself rather than by an API key held in the plugin, with a Codex command-line provider beside it. A workflow is started from the command palette on the current note or on a selection, and its result is written into the note. The README states the plugin is desktop only, since it shells out to command-line tools and makes direct HTTP calls to local AI servers.
