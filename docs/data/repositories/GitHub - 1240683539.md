# jeantoledo/obsidian-deterministic-graph-view

Renders the vault's link graph with a deterministic layout, producing the same layout on every render for the same notes and links, unlike the force-directed built-in graph view that rearranges itself each time it opens. The README states it is built on Cytoscape.js with a breadthfirst layout and trades some of the organic look for predictable, reproducible node placement that can serve as a stable visual index. A ribbon icon opens the graph in a new tab and clicking a node opens the corresponding note, while the graph rebuilds when files are created, deleted or renamed and when the excluded-files filters it respects are changed. Node and edge colours are customized from an in-graph controls panel.
