# wyc7758775/zettlab-sync

Zettlab Sync synchronizes an Obsidian vault with Zettlab Memo over WebDAV only, storing notes as plaintext Markdown so Memo can index them. It supports Basic or Digest authentication, manual, periodic and after-save synchronization, a connection test that creates and removes a temporary remote file, conflict resolution by keeping the newer or the larger copy, and exclusions by file size or path pattern. Cloud providers, OAuth, QR pairing, a paid tier and end-to-end encryption are deliberately absent, credentials live in the vault's local plugin data, and the code is Apache-2.0, derived from a pre-license-split snapshot of Remotely Save.
