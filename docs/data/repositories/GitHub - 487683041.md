# mokeyish/obsidian-enhancing-export

The repository holds an export plugin for Obsidian built on Pandoc, reached from an entry in the file menu. Its README records Markdown, a Hugo-flavoured Markdown, HTML, Word documents and LaTeX among its targets, and states that the first three carry their media resources along with the document. It notes that those three were tested by the author on macOS, Windows and Linux while the others were not tested as thoroughly, and that Pandoc 3.1.9 or newer must be installed and either on the path or given as an absolute path in the settings.
