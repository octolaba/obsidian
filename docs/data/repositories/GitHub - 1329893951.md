# bobstanton/places-stadia

A map provider for the Places plugin backed by Stadia Maps. It loads the selected map style with its glyphs, sprites and tiles, resolves search terms to places and coordinates, builds routes and isochrones, reads elevation for a coordinate, snaps a recorded track to the road or path network, identifies the named ways it follows, and loads terrain DEM tiles for 3D relief. Geocoding, routing, isochrones and snapping come from the Stadia Maps API client, route polylines are encoded and decoded with a polyline codec, and the map is drawn by maplibre-gl through the shared Places GL implementation.
