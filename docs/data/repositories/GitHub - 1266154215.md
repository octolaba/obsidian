# vnrtmnv/obsidian-inline-secret-block

Inline Secret Block encrypts secrets inside notes with AES-256-GCM and a passphrase, covering both fenced blocks and single-line inline code spans. Writing a secret block opens a passphrase prompt as soon as the cursor moves away and rewrites the block into a secret-lock form whose body is opaque ciphertext; cancelling leaves the plaintext in place, and an untouched block is not prompted for again. In reading view and Live Preview a locked block becomes a card with show, edit and copy actions, where copy puts the plaintext on the clipboard without revealing it and edit unlocks the block in the file and re-locks it with the same key once editing stops. Several passphrases can be in use at once: those entered during the session are remembered, tried automatically when decrypting, and offered as a choice whenever a new secret is encrypted.
