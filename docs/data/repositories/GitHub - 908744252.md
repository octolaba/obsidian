# VaguelyElectric/obsidian-explorer-colors

Obsidian plugin that assigns colours to individual files and folders in the file explorer, set from a context-menu entry on the item. Colours cascade to the contents of a folder, which can be switched on or off per item tree, while a child that carries its own colour always keeps it, and a default colour for the picker can be set. The README gives the limitations of the CSS-snippet approach it replaces — no per-item targeting without nth-child or name selectors, breakage as items are added, and explorer items being unloaded when out of view.
