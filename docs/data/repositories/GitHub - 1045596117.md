# community-archive/obsidian-image-toolkit

The repository holds Image Toolkit, an Obsidian plugin that pops an image up when it is clicked so it can be previewed, zoomed, moved, rotated, flipped, inverted and copied. Its README describes a normal mode that masks the note behind a single image and a pinned mode enabled from the settings page, plus an optional gallery navbar listing thumbs of every image in the current note. The catalog records the repository as a fork written in TypeScript under the MIT license.
