# chujiu-dev/obsidian-code-runner

Code Runner executes code blocks inside Obsidian on desktop, iOS and Android, with stdin input support. Python runs locally through Pyodide compiled to WebAssembly, while seventeen or more other languages, among them C, C++, Java, Go, C#, Swift and R, are executed through public playground APIs, and JavaScript runs in a proxy-sandboxed eval. Input handling depends on the platform: where SharedArrayBuffer is available each input call raises an inline popup during execution, and where it is not, all prompts are parsed and shown as labeled pre-filled fields with a raw textarea for loop-driven programs. A stop button terminates a running program and every prompt-and-response pair stays visible above the output.
