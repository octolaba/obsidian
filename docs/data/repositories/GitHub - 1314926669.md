# vicstu/obsidian_telegram_sync_amvera_r

Telegram Sync Amvera R brings messages sent to a personal Telegram bot into an Obsidian vault. The messages queue on a sync server hosted on Amvera and are pulled into notes by a fetch command, after which the server deletes them. It can run against a shared default bot and server, identified by a Telegram user id, or against a bot created with BotFather and a server instance the user deploys, and voice and audio messages can optionally be transcribed through a configured provider. The plugin is desktop only and requires a recent Obsidian version.
