# dsebastien/obsidian-bookshelf

Bookshelf Base registers a Bookshelf view type in Obsidian Bases alongside Table, Cards and Gallery, laying notes out as covers on shelves. The cover comes from any property holding an image URL, a data URI or a vault-relative path; a note without one gets a coloured spine with a vertical title generated deterministically from that title. The view respects the Base's grouping configuration by giving each group its own shelf with a header and count, shows any property in the Base's display order under each book with rating properties highlighted, and renders wikilinks in those properties through Obsidian's standard link handling. Shelf texture, card size, gap and aspect ratio are view options, and the README states that no desktop-only APIs are used.
