# pjeby/hotkey-helper

Adds icons beside each entry in Obsidian's core and community plugin tabs that open that plugin's options pane or its hotkey assignments directly. Hovering the hotkey icon reports how many commands the plugin defines, how many carry assignments, and how many of those conflict with another assignment; the icon takes the theme's error background color when conflicts exist. The icons appear, disappear and change color as plugins are enabled or disabled, and settings and hotkeys are reachable immediately after enabling a plugin from the community browser. The plugin also registers plugin URLs that open the community plugin browser on a given plugin id.
