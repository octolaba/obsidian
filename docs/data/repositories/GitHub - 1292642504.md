# p4nt1um/canvas-branch-chat

This repository holds Canvas Branch Chat, an Obsidian plugin that builds branching model conversations on Canvas. A branch is forked from any conversation node by dragging a line and labelling its direction, each branch holds its own conversation while inheriting context collected along its chain of ancestors, and several directions can be forked at once in parallel. Models are configured individually with an alias, provider, base URL, colour, icon, system prompt and temperature, a connectivity test fetches the remote model list, and a fork can be made with a chosen model so that different models give different perspectives. User and assistant nodes are coloured differently and branches are colour-coded; the README is written in Chinese and English.
