# pedrofuentes/obsidian-subtitles-md

Subtitles MD reads .srt and .vtt subtitle and transcript files as Markdown, with no media playback involved. A command converts such a file into a transcript note, a transcript code block renders subtitle content inline or references a subtitle file by path, and clicking an .srt or .vtt file in the vault opens it in a read-only transcript view without converting it. Settings control how cues are grouped into paragraphs, how timestamps and speakers are displayed and whether frontmatter metadata is included; the README states that the output is plain Markdown, so the text is searchable, linkable and open to annotation, and contrasts this with plugins that generate transcripts from audio or synchronise with playback.
