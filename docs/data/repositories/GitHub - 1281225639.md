# Arsenije/Uru

Uru makes an Obsidian vault searchable by meaning and lets the user search or chat over it offline, with each answer citing the notes it came from. It runs on the local machine through llama.cpp and is powered by Khora, a local-first search-and-connections library that Uru drives through a small bundled backend because Obsidian cannot run Python. New and edited notes are indexed as they are written, and deletions and renames are handled without a manual re-sync. The README records desktop-only support — macOS on Apple Silicon at 13.3 or newer, Windows or Linux — and states that there is no account, no API key and no network call after the one-time model download, and that Uru never alters the notes.
