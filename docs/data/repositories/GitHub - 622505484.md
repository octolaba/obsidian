# QuincySx/obsidian-markdown-tabs

Tabbed Blocks shows Markdown content as switchable tabs in Obsidian's reading view, written inside a code block whose language marks it as tabs. Tabs are separated by a marker line carrying the tab title, with a starred variant naming the tab that is active by default, and any text before the first marker appears above the tabs as a preamble. A command inserts a complete template, typing the separator inside the block suggests both marker forms, a block with no recognised tab shows a syntax hint below it, tab content is rendered only when its tab is first activated so diagrams and code highlighting are not measured while hidden, and an overflowing tab strip can be dragged sideways without switching tabs.
