# derogab/ai-notes

Records microphone audio into the note being edited, transcribes it, and appends an AI-written summary of the note and its transcriptions. Three commands cover the flow: start or stop a recording, which is saved to a configurable vault folder and embedded in the note; transcribe every embedded audio file in the note into collapsible blocks beneath each recording; and enrich the note with a generated section. Transcription targets a whisper.cpp server or any OpenAI-compatible endpoint, and enrichment targets an OpenAI-compatible chat endpoint, each with its own URL, model, API key and extra headers. No endpoint is contacted until one is configured, so the plugin can run entirely against local services.
