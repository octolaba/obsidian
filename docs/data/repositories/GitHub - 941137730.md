# ChenziqiAdam/Daily-News-Briefing

Daily News Briefing generates a daily news note in the vault by sending the configured topics to a model provider or reading RSS feeds, and writing the summary into a dated note filed in monthly subfolders. The README lists eleven pipelines across several providers plus an RSS retriever, six briefing presets that add use-case context such as why an item matters, risks and follow-up questions, six interface languages, and templates with placeholders. Briefings run at a scheduled time or on demand from a command or a sidebar icon, and the plugin requires an API key for whichever provider is chosen.
