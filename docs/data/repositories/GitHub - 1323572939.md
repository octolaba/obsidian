# SWHL/obsidian-code-fence-completer

Code Fence Completer suggests language identifiers while typing Markdown code fences in Obsidian, ranking exact, prefix, substring and fuzzy matches and giving recently used languages priority. Built-in aliases such as py, js and ts insert the canonical identifier, custom mappings can be added in settings, and identifiers such as c++, c#, foo-bar and foo.bar are supported. Commands insert an empty code block or wrap the current selection, and change or clear the language of the block around the cursor while preserving other info-string attributes such as a title. It avoids opening suggestions on closing fences, warns when another enabled plugin also completes code-block languages, and works on desktop and mobile.
