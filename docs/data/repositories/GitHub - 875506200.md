# konfuzz/arweave-uploader-plugin

Obsidian plugin that converts a note to HTML and uploads it to the Arweave network, which the README describes as decentralized storage paid for once and kept permanently. Embedded images are converted to base64 and included in the HTML, and before uploading the plugin shows the wallet balance and an estimated transaction price in AR tokens and in dollars. The README warns that the private key is stored in plaintext in the plugin settings, so a primary wallet or one holding a large balance should not be used, and that only image attachments are supported in this version.
