# hesprs/obsidian-canvas-svg-export

This repository holds Canvas SVG Export, an Obsidian plugin that exports a canvas to SVG, which the README motivates by noting that stock Obsidian exports canvases only to PNG. The canvas is opened and an Export to SVG command is run from the command palette, bringing up a modal that completes the export. The README states that the output is a rendered SVG rather than one wrapping HTML in a foreignObject, and it lists rounded corners, aspect ratio and light or dark options as planned rather than present.
