# gboyd068/obsidian-swiftlatex-render

This plugin renders LaTeX written in a labelled code block into a PDF, or into SVG when the block carries the SVG variant of that label. Compilation uses the SwiftLaTeX WebAssembly compiler built into the plugin, so it has no other dependencies, and packages requested in the source are fetched on demand from CTAN, which makes a block slower to compile the first time; the poppler PDF-to-Cairo utility, also compiled to WebAssembly, performs the SVG conversion. The README records PdfTeX as the default engine and XeTeX as a setting for Unicode support, warning that XeTeX has not been updated for the on-demand package fetching and will not work unless packages are supplied or already cached.
