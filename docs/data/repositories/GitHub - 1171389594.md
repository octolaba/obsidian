# Abdur-Nur-Porag/CList-Calc

Obsidian plugin that renders plain markdown lists as calculating tables. The README shows a block in which named items carry numbers and a further line sums them, producing a rendered table with the arithmetic already done, and states two ways of working: keeping the list inside the render block, or leaving it as an ordinary markdown list outside while the block only calculates. It documents list item syntax, checkbox and plain items, inline unit suffixes, nested children, variables and references, block and row directives, math and aggregation functions, and path references.
