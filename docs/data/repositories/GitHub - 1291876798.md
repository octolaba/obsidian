# KTGoldwolf/journal-mode

Journal Mode adds analog-journal styling to Obsidian notes through a compact markup that stays readable as plain text. A brace-tagged span animates text with effects such as shiver, shake, rage, shock and wave, colours it from a named palette, or gives it a sparkle effect, and tags can be combined, with the last colour winning when several are given. The palette holds as many colour aliases as wanted, and a reserved rainbow name applies every palette colour in turn. Decorative washi-tape dividers are inserted from a command, the styling renders in both edit and read mode on desktop and mobile, and the README states that it is built from plain CSS and JavaScript with no external assets.
