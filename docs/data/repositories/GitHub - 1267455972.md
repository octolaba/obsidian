# johannes-kaindl/obsidian-letterhead

Obsidian plugin that turns a note into a formatted business letter, in the German DIN 5008 layout or a modern one, and exports it to PDF. The note's frontmatter holds the letter metadata and its Markdown body becomes the letter text, with one command producing the finished letter. On desktop the export goes through the operating system print dialog; on iPhone and iPad the plugin generates a text-selectable vector PDF itself and hands it to the system share sheet. The README states that this built-in PDF engine has no runtime dependencies and works offline, renders tables, embedded images, code blocks and multi-page pagination, reports anything it cannot represent as a notice rather than dropping it, and sets page margins automatically.
