# joethei/obsidian-plantuml

The repository holds PlantUML Support for Obsidian, a plugin that renders PlantUML diagrams from fenced code blocks. Its README records three block languages: plantuml for the default rendering, plantuml-svg for higher resolution and plantuml-ascii for ASCII art. Rendering runs either against the PlantUML online server, a self-hosted server whose address is set in the settings, or a local jar file, and the README states that local rendering performs less well than a server.
