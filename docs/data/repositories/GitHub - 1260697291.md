# Maniarasan-zuper/smart-table

Repository for Smart Table, a plugin that renders a database-style grid inside a note. Its README states that the table is stored as a fenced JSON block, so edits are saved in the note itself and travel with it, and that the block renders as an interactive grid in Reading view and Live Preview. It documents typed columns, sorting and per-column filters, adding, renaming and deleting columns and rows, dragging to reorder both, inserting, duplicating, copying and pasting rows, status pills and CSV export.
