# OneeMe/obsidian-lark-doc

Obsidian plugin that connects local notes with Lark and Feishu cloud documents and Bases. It keeps a small linked file in the vault whose opening loads the remote document or Base in an Obsidian WebView, reusing the existing tab as an ordinary Markdown file would and preserving the selected table and view for a Base URL. Commands create such a linked file from an existing document URL or create a new remote document or Base together with its local note, and the current document's link can be copied from the preview header. Titles are synced from the remote side and can rename the local file, with an indexed suffix appended on a collision, and a generated base view lists the linked documents.
