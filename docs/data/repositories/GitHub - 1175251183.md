# anamaydev/advanced-line-numbers

Obsidian plugin that customises editor line numbers and active-line highlighting. Line numbers can be absolute, relative to the current line for vim-style navigation, or hybrid with an absolute number on the current line and relative numbers elsewhere. The active line can be highlighted in the editor, in the gutter and in its own line number, or the highlight can be turned off when the theme already provides one, and a status bar item reports the cursor position as Ln X, Col Y. Every setting is also reachable as a command palette command.
