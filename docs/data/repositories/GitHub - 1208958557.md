# JCF-402/datacharts

DataCharts creates charts, plots functions and visualizes note data directly in Markdown. The README states line charts are powered by Chart.js while Mathjs parses and plots mathematical equations, that data is supplied manually or read from ordinary Markdown tables, and that datasets, plots and canvas styling are customizable with zoom, pan and value inspection. Its changelog records the code block keyword changing to datachart, a type directive adding bar, scatter, pie, doughnut, polar area and radar charts, and saving a chart to the vault as PNG or, for line charts, SVG.
