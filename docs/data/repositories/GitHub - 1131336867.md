# ppeirce/property-annotations

Property Annotations displays inline, display-only annotations for boolean properties in Obsidian daily notes and does not modify the notes. For each boolean property it finds the most recent earlier daily note in which that property was true and renders a label giving the elapsed number of days, in either a verbose or a compact style. The daily notes folder and filename date format are detected from Obsidian's core Daily Notes settings, with the auto-detection optionally disabled in favour of a custom folder and format, and annotation can cover every boolean key or only a whitelist.
