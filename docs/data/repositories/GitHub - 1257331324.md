# west-shell/obsidian-chess-tree

Chess Tree renders chess games inside Obsidian through PGN views and customizable chess or FEN code blocks. It provides interactive boards, legal move handling, variation trees, annotations, configurable display settings, and Stockfish 18 engine analysis, with mobile-oriented layout options.
