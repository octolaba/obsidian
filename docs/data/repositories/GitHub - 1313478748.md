# conoro/obsidian-zvec-hybrid-search

ZVec Hybrid Search adds a local search sidebar to Obsidian that combines word matching with semantic embeddings, opening each result at the matching section of the note. It searches titles, headings, content, tags and front-matter properties such as author, description, source and date, sorts by relevance, date or title, and can index the whole vault or selected top-level folders while excluding others. The index updates as notes are created, edited, renamed or deleted and is stored outside the vault to avoid conflicts with file-syncing services. On first enable it downloads a local search runtime of roughly 75 to 100 MB and an embedding model, then builds the initial index; notes are not uploaded, and it is desktop-only on Obsidian 1.8.0 or newer.
