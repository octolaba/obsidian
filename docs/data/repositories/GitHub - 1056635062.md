# eoliversec/obsidian-capitalise-plugin

This repository holds Capitaliser, an Obsidian plugin that cycles the capitalisation of text between lowercase, Capitalise Each Word and UPPERCASE, which the README compares to Shift+F3 in Microsoft Word. The command works on a selection, on the word under the cursor, or on a whole line. No hotkey is assigned by default; the user binds one to the Cycle text capitalisation command in Obsidian's hotkey settings.
