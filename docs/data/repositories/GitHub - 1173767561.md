# tahayigitmelek/vault-dictionary

Vault Dictionary is an Obsidian plugin that automatically highlights words held in a personal dictionary and shows their definitions, working in both Live Preview and Reading Mode without manual links. Entries are added from the plugin settings or by selecting text and choosing an add-to-dictionary action from the context menu, and a settings dashboard searches, edits and sorts them. The README states that the dictionary is stored as JSON under the Obsidian configuration folder for manual editing, syncing and backup, and that a refresh command reloads it after an external edit.
