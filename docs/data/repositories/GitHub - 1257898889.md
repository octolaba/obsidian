# HornatX/unique-tab

Unique Tab keeps one tab per file in the Obsidian workspace: when a note, canvas or other file is already open, opening it again from the file explorer, quick switcher, search or an internal link focuses the existing tab instead of creating a second one. Newly spawned empty placeholder tabs are closed immediately, which the README describes as reducing flicker and brief white screens during the switch. The README states that the plugin needs no configuration and that it works with standard Markdown notes, canvases, database files and custom view types contributed by other plugins. Its documentation is written in Chinese and English.
