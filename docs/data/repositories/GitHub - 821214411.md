# joycode-hub/datepicker-plugin

Repository for the Datepicker plugin, which edits and inserts dates and times anywhere in Obsidian notes through a date picker widget. The README lists showing the picker automatically when a date is selected, adding a calendar button beside date and time values in a note that opens the picker, and selecting date or time text automatically for quick formatting. Its commands edit a date and time, insert a new date or a date and time, and step to the previous or next one.
