# pteridin/obsidian_symlink_plugin

Symlink Creator adds commands that create a symbolic link to a file or to a folder, inside or outside the vault. The README records the mechanism per platform: the shell link command on Linux and macOS, and on Windows the directory form of mklink for links across drives, which requires administrator privileges, the junction form which requires none, and the plain form for files. It also states that the plugin is in early development and may not work as expected, that it works in desktop mode only so mobile users are not supported, and that creating symlinks and junctions can be dangerous and may lead to data loss.
