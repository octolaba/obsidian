# miaoche2-cell/obsidian-netease-sync

This repository holds an Obsidian plugin that turns songs listened to on NetEase Cloud Music and physical records held on Discogs into notes, one note per song and one per record, carrying metadata, lyrics and tracklists but never downloading audio. The NetEase side reads the local cache of MusicLyricApp and takes genre and region from Last.fm and translated titles from NetEase, while the Discogs side pulls the collection through the official API with a personal token. Notes are rendered from a swappable Markdown template and deduplicated by netease_id or discogs_release_id, and the README records the plugin as desktop only, with keys kept in local plugin data and network calls limited to Last.fm, NetEase and Discogs. Its documentation is mostly Chinese, and the README states that the plugin was generated by AI.
