# jshph/obsidian-enzyme

Enzyme is a chat agent that builds a conceptual map of a vault's ideas from the existing tags, links, folders and note recency, and uses that map to pull relevant context into a conversation before a follow-up question is asked. Its answers quote from the vault with clickable note links and highlight the graph nodes they drew on. The chat model is configured in the settings with an API key, a base URL and a model name, and the README states that any endpoint speaking the OpenAI chat-completions API works, naming OpenRouter, OpenAI, Anthropic through a proxy, llama-server, Ollama and vLLM, including local models. It claims that keeping the map fresh costs far fewer tokens than having a coding agent explore the vault, because its harness is built for Markdown rather than code.
