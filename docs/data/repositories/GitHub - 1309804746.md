# BCS1037/codian

Codian is an open-source multi-provider agent workspace for local coding agents inside Obsidian, keeping notes, folders, conversations, Skills and local tools around one problem instead of treating the vault as one-off context. Agents are used from a sidebar chat or through inline editing with word-level diff previews, and the README states that each provider's native authentication, session and permission boundaries are preserved and that feature parity between providers is not assumed. Six local CLI providers are named — `claude`, `codex`, `kimi`, `grok`, `opencode` and `pi` — alongside a multi-tab conversation workflow with saved sessions, search, resume, fork and rewind, a CodeMirror 6 composer with `@note` and `@folder` mentions, and shared management of Skills, MCP servers, subagents and commands.
