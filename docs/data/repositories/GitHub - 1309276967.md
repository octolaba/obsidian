# NoteNerdOfficial/browser-bookmark

Browser Bookmark adds an independent bookmarks sidebar to Obsidian that opens saved links in the built-in Web Viewer rather than handing them to the system browser, so the panel stays visible while browsing. Bookmarks live in folders nested to any depth with drag-and-drop reordering and re-filing, a search box narrows the tree by title, URL and description and expands matching folders, and keyboard navigation covers moving, expanding, opening, renaming and deleting. Each bookmark shows a real favicon with a globe fallback, and its icon can be overridden with a Lucide icon name or an image URL; optional descriptions appear under the title, and adding a duplicate URL raises a non-blocking warning. A link dragged from a note into the sidebar becomes a bookmark, filed into the folder it is dropped on or added at the root.
