# patrickchiang/obsidian-headings-in-explorer

This plugin makes headings first class concepts in the file explorer, listing a document's headings beneath it as a clickable hierarchy so navigation is consolidated into a single panel instead of a separate outline pane. Which heading levels are included is configurable, and a Highlight Location button in the explorer navbar reveals and highlights the heading the cursor is under, using the tab whose cursor was last clicked. Non-heading text can also be matched into the explorer by regular expression, with entirely bolded lines treated as a seventh level by default, and the whole display is switched by the Toggle File Explorer Headings command. Because it relies on some existing core plugins, it works only on desktop versions of Obsidian.
