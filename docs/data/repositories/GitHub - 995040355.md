# DudeThatsErin/FileCreator

Creates a new file in a folder chosen from the vault's folder structure, with folders excluded from the list by configuration. The file can be a Markdown note, a PDF made from a template stored in the vault, a Kanban board with configurable headers and completion states, a base file, or an Excalidraw drawing, each with its own templates. The current date can be added to the filename as a prefix or a suffix, and the newly created file can be embedded into an existing note. The README states that the plugin is written with the help of AI and advises users who do not want AI-written code in their vault not to use it.
