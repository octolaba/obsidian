# BWurster/explain-selection-with-ai

Obsidian plugin that adds an editor context-menu entry sending the selected text, with its surrounding context, to a chat-completion endpoint compatible with the OpenAI API and asking the model to elaborate on it. The README describes three setups: OpenAI itself with an API key and a model name, a local Ollama instance pointed at by a base URL, and any other local or remote model configured through the same base URL and endpoint settings. The author records it as their first Obsidian plugin.
