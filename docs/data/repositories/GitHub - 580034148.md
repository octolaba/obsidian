# alangrainger/obsidian-google-photos

This repository holds Google Photos for Obsidian, described upstream as connecting to Google Photos from Obsidian. The README says photos are embedded into notes through the Google Photos Picker, with thumbnails downloaded and saved locally, links back to the original photos, customizable image templates and filenames, and configurable save locations. It records that date filtering, album browsing and automatic photo queries were removed following Google's API changes, and that the author has moved to a different photo service and placed this project in maintenance mode while looking for a new maintainer.
