# blackflag0623/obsidian-lemon-comments

Lemon Comments is described as adding non-intrusive Markdown comments to selected text in Obsidian's Reading view, and its README is written in Chinese and English. Selecting text shows a small toolbar that leaves the native selection intact, the editor opens only when the comment button is chosen, and a saved comment highlights the text with a popup shown on hover and rendered by Obsidian's Markdown renderer. Comments live in the plugin's data file rather than in the note body and are re-anchored by text and context after small edits, being reported as unlocated rather than attached to a wrong repeated phrase. The README limits comments to Reading view, excludes embeds, formulas and note properties, and forbids overlapping selections.
