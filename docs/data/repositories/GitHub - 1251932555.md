# chenxiccc/Obsidian-Share-to-Save

Share to Save downloads web pages into an Obsidian vault as Markdown notes and also captures short text notes. Its README describes a two-device workflow: a link shared or pasted on mobile is written to a queue file in the plugin's folder, synced to the desktop by whatever method the user already uses, and the desktop plugin then fetches the full page content and saves it as a note; a link can equally be entered from the desktop ribbon button. Text can be typed into the plugin input and saved directly, and a home screen shortcut opens that input in one tap. The README names general article pages handled through a built-in fallback extractor, WeChat official-account articles, and Xiaohongshu posts whose text and images are both extracted, and it records that on iOS from Obsidian 1.13.0 the new share sheet is used and the plugin need only be installed on desktop.
