# catthode/obsidian

This repository holds Catthode, a high-contrast, retro-futuristic Obsidian theme its README frames as going from CRT to OLED and designed for prolonged writing sessions. It pairs pure black editor backgrounds and near-black sidebars and panels with a warm glow palette of wheat, tan, gold, amber and clay for types, keywords, headers, functions and operators, over white and grey phosphor text, with red, green, cyan, blue and purple accents for errors, strings, regex, links and constants. It installs from Obsidian's community themes or by copying the theme files into the vault by hand.
