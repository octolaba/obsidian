# Doggy-Footprint/Suggest-Notes

Suggest Notes offers completions for linking notes while writing, so that a link can be started without first typing the opening brackets Obsidian normally requires. Only a user-defined set of keywords is tracked — note names and aliases drawn from configured folders and tags — and the plugin records which note is chosen each time so that frequently connected notes are suggested at the top. Its README opens by redirecting readers to the Various Complements plugin, which the author found afterwards and describes as having exactly the same purpose, says this plugin might not be updated further, and marks it as testing software with a warning about unexpected loss of data.
