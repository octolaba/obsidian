# turuhiro26-hub/postcraft

Postcraft turns selected text in an Obsidian note into ready-to-post drafts for X or LinkedIn, run from the command palette or the editor context menu without writing a prompt. Past posts pasted once into settings serve as voice samples so the drafts follow the author's own style, and tone presets narrow it further. Each draft can be edited in the result window with a live character counter that turns red past the limit, and earlier runs are reopened from a recent-drafts command. The README states that the plugin calls Anthropic directly through Obsidian's own request function and that the API key stays in the vault.
