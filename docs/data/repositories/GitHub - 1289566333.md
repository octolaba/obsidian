# ondreu/YAML-Databases

YAML Databases lets Obsidian view, create and edit YAML files as interactive databases, presented as a spreadsheet, a form or raw source. A database is stored as a Markdown file with a .yaml.md suffix, so its leading block is indexed as ordinary properties and the file stays a note for the file explorer, Sync, mobile and links. The README states that it was built for bills of materials whose changes are tracked with git diff, so its output is deterministic and line-based and one edited cell produces a single-line change.
