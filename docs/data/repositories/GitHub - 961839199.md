# any-block/obsidian-any-block-min

This repository distributes a reduced build of the AnyBlock plugin for Obsidian. The mermaid, PlantUML and markmap dependencies are removed to cut size and load time while the functionality is otherwise kept; the README's reference figures for v3.2.1 are 8.82MB down to 262KB and a startup time of 424ms down to 30ms. It also states that parts of the AnyBlock monorepo not belonging to the Obsidian plugin were removed, that source and compilation stay in the main AnyBlock repository and are synchronized here automatically, and that stars belong on that repository rather than this one.
