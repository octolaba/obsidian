# MlLHoUzE/tabletop-music-player

Tabletop Music Player is an audio controller aimed at game masters running a session from a campaign note: playback continues in the background while notes and sidebar panes are switched or closed. Tracks are chosen from a button grid that filters on biome, tone and intensity properties held in note frontmatter, transitions are crossfaded over an adjustable window defaulting to 2.5 seconds, and a second channel mixes looping weather layers with its own volume slider. The README also records inline links that play a track when clicked in reading or live preview, autocompleting settings for the root and weather folders built on Obsidian's suggester APIs, and global play, pause, skip and panic-stop commands; a track loops until a skip button, an inline link or a hotkey changes it.
