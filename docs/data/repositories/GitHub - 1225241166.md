# hendrikhuwy-lgtm/codex-vault-agent

Obsidian desktop plugin that collects reviewed evidence from a chosen vault scope and optionally asks a local Codex session to synthesize it into a report, dashboard, link audit or metadata audit. The README states that the evidence set is built from a selected folder plus backlinks, outlinks and optional broader scopes, using Dataview when available and Obsidian metadata otherwise. It also states that candidate notes can be included or excluded before any synthesis, that only the reviewed evidence packet is sent rather than the whole vault, and that the final note is created only after explicit approval.
