# bobstanton/vaultquery

The repository carries no description; its README presents VaultQuery as a plugin that executes SELECT, INSERT, UPDATE and DELETE statements across notes, properties, tasks, tables, headings and links. Notes, frontmatter, tables, tasks, headings, links and tags are indexed into SQLite and kept current on file create, modify, rename and delete events, and queries use standard SQLite syntax including joins, aggregations, views and custom functions. Results render through SlickGrid, Markdown tables, Chart.js, FullCalendar or JavaScript, and write statements are shown as a before-and-after preview with database-to-file sync; a family of code block types covers queries, writes, charts, calendars, schema, views, functions and built-in help.
