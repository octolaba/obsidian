# BaksiLi/obsidian-inline-annotation

Inline Ruby Annotation renders an inline annotation syntax in Obsidian as ruby and furigana, glosses above or below the base text, bouten emphasis dots, overlines and underlines. Reading view is fully supported and Live Preview has a prototype widget that reveals the source while the expression is edited; both use the model from the author's separate `markdown-it-inline-annotation` core package. Because Obsidian parses Markdown before Reading-view postprocessors run, the adapter renders only complete expressions inside a plain or consistently formatted run, never joins across emphasis, highlight, link or code boundaries, and skips existing links, code, ruby, scripts and opted-out elements. The README records that it uses no network access and offers no commands or settings yet.
