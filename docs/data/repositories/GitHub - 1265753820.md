# joven-lynn/obsidian-better-mermaid

Better Mermaid changes how Mermaid diagrams are viewed in Obsidian's reading mode: clicking a diagram opens it full size in a modal where scrolling pans, Ctrl with scrolling zooms, dragging moves the diagram, and preset levels of 20%, 50%, 75% and 100% are available. A diagram can be exported as a PNG at twice its resolution, custom CSS can be injected to restyle Mermaid output, and the interface is available in English and Chinese. The README records a minimum Obsidian version of 0.15.0, desktop and mobile support, and reset buttons on each settings slider.
