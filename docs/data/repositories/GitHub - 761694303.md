# Benature/obsidian-plugin-reloader

Plugin Reloader reloads a single plugin manually from the command palette or a hotkey, and the command can be bound to a ribbon button through Commander. The README lists the cases it is written for: reloading a plugin to force an update, plugins whose first initialization requires a reload, and plugins that only pick up a new configuration once they have been reloaded.
