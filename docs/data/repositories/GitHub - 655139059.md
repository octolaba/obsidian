# antoniotejada/obsidian-edit-history

Obsidian plugin that writes every edit of a note into a separate edit history file, from which previous versions can be browsed, diffed and copied back by hand. Edits are chosen from a calendar or a timeline view and compared side by side, top by bottom or inline, and the frequency of saved edits, the number of retained edits and their maximum age are all limited by settings. The history file follows the note when it is renamed or moved and is deleted with it. The README compares the plugin with the File Recovery core plugin, claiming an open history format, per-file history files that can be copied or backed up externally, and compressed diff storage.
