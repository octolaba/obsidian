# noatpad/obsidian-grandfather

The repository holds Grandfather, a plugin that displays the time, and optionally the date, in the Obsidian status bar. Its README offers a list of predefined time formats or a custom format string, and points at the moment formatting documentation for how to write one. The author describes the plugin as something written while getting acquainted with the Obsidian API during a migration of their own notes.
