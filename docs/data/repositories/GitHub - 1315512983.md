# ViaCai/obsidian-bible-search-reader

This plugin searches, reads and projects a Bible held as Markdown documents in the vault. Searches run over themes, outlines or verse text, across the whole Bible or a chosen range of books, and accept verse references, keyword combinations whose separators decide whether terms are combined or alternatives, and mixtures of the two. A reading view browses books and chapters in a grid with quick jumps and adjustable font size, and selected passages can be projected one verse at a time, side by side or mixed, driven by keyboard, scroll wheel or touch. The text is loaded either from a data file downloaded into the plugin folder or from Markdown files placed in the vault in a documented format, and only Chinese Bible documents are supported.
