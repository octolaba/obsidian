# francescobernini0016/arena-channels

An Obsidian plugin that renders an Are.na channel as a responsive masonry grid inside a note from an arena code block, in both Reading view and Live Preview. The block takes the channel as a slug or a full Are.na URL, from which the slug is extracted, and any global setting can be overridden per block: target column width, gap, image variant, caption source, and whether the description, link and full-width layout are shown. The README states that the plugin is unofficial, uses the public Are.na API, and is not affiliated with or endorsed by Are.na.
