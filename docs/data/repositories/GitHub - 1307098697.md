# ValleytheKnight/CSS-Resource-Variables

CSS Resource Variables maps a file already in the vault to a CSS custom property, so that theme or snippet CSS reading that variable name resolves to the user's own file. The README explains the gap it fills: theme and snippet CSS is injected as raw text with no folder context, relative paths cannot resolve and local-file URLs are blocked by the app, so only a plugin calling Obsidian's getResourcePath can produce a loadable URL. Mappings are created in settings by picking a file and naming a variable without the leading dashes; the resolved path is wrapped in a url value, re-resolved on every load, and follows the file when it is renamed or moved.
