# SirHobby/wetstone

Wetstone builds a quiz bank from the notes in folders chosen in settings: an LLM reached through a user-supplied key extracts the concepts worth remembering and writes questions for them, and re-running the update touches only notes that changed. Questions come as multiple choice, true or false, multiple select, typed fill in the blank, ordering and cloze, and the plugin rotates between variants so a concept is tested rather than one phrasing. Reviewing uses FSRS scheduling that runs entirely on the device and offline, with the question bank, scheduling state and daily review logs kept as Markdown and JSON files inside the vault. Note content leaves the vault only when questions are updated, and the API key is stored in plain text in the plugin's data file.
