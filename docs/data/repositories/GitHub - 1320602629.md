# hadimozaffari75-source/canvas-card-linker

Canvas Card Linker turns text cards on an Obsidian Canvas into notes named after the card's first line, and mirrors the label written on an arrow between two cards as a wikilink inside the source note, so an arrow labelled Critique of this claim adds that label followed by a link to the target. Conversion runs on demand from a hotkey, Ctrl+F12 or Cmd+F12 by default, or from a ribbon icon menu, so it never fires while a card or an arrow label is being typed, and background processing is an optional setting. Cards that are still empty are skipped rather than converted under a placeholder title, and a note carrying such a placeholder name is renamed from the card text on a later run.
