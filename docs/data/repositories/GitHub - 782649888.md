# andrewheekin/obsidian-create-note-list

Create Note List inserts a bulleted list of the notes in the current note's parent folder at the cursor, for use as a table of contents or a list of related notes. Three commands list files, list folder notes, or list both, and the README states that there is no option to recurse into subfolders. Settings control the sort order, ascending or descending, and whether only notes whose titles begin with a date in year-month-day form are included.
