# MMoMM-org/obsidian-markdown-mason

Markdown Mason reshapes pasted or whole-note Markdown to fit the target note's structure: it cascades heading levels relative to the cursor, turns inline citations into real footnotes, renumbers and deduplicates them against those already present and files them into a Resources section. The README describes a seven-step cleanup recipe — dewrap, dehyphenate, decompose ligatures and punctuation, tidy whitespace, normalize bullets and ordered lists, normalize headings — applied to just-pasted text as a single undo step, and an eleven-step recipe run over a selection or a whole note. The transforms are scripts managed by the plugin, installed from a curated catalog or imported from the vault, which run with full plugin permissions only after an explicit per-version disclosure and have a per-script kill switch. It is marked early, desktop-only and requiring Obsidian 1.6.6 or newer.
