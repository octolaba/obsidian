# grub-basket/GridSense

GridSense presents a folder-scoped editable grid over Obsidian note frontmatter, with multi-cell selection, spreadsheet-style keyboard navigation, TSV copy and paste, per-column filters, sorting, and find-and-replace. It offers row creation and heading-content columns, compiles a cached JSON snapshot invalidated by metadata events, and sends edits through processFrontMatter so note bodies remain untouched.
