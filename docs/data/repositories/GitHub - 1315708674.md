# kidpeterpan/inkbound

Inkbound exports notes from a vault as EPUB 3 files for reading on e-ink devices. A single note becomes a one-chapter book, a folder becomes a book with chapters in filename order, and a note plus the notes it links to, out to a chosen depth, becomes one book with working links between chapters from the same export. Images carry through, while Mermaid diagrams and LaTeX math are rendered at export time and embedded as images; a cover comes from a frontmatter property or the note's first image, and chapter headings become table-of-contents sub-entries down to a configurable level. Books containing Thai text embed Noto Sans Thai automatically, an optional push-after-export setting delivers the finished book to a Boox reader, and the plugin is desktop-only, requiring Obsidian 1.5.0 or newer.
