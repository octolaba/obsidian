# p1tt1/obsidian-logbook

Logbook brings org-mode LOGBOOK-style time tracking to task items in Obsidian, storing clock entries as inline fields in plain Markdown. Commands clock in on the task line under the cursor, clock out to close the open entry, show a report of closed entries for the current file, and scan the whole vault for forgotten open clocks. The README explains how Dataview reads those entries — the clock field is indexed as a plain string because its separator is not a recognized Dataview construct, so the example queries split it manually — and notes that Dataview is optional since the plugin writes plain Markdown either way. It states that the plugin is entirely local, with no network requests, telemetry or external services.
