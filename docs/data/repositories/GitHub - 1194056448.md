# AbdelrahmanHafez/obsidian-cursor-history

Cursor History records recent cursor and selection positions across Obsidian notes and lets users navigate backward or forward to them. It restores the note and viewport, groups nearby movements, creates stops on file changes, and keeps up to 200 session positions while clearing forward history after a new branch.
