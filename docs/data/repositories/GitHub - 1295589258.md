# kebl3541/obsidian-remarkable-bridge

reMarkable Bridge sends an Obsidian note to a reMarkable tablet as typed text, lets it be edited there with the Type Folio, and pulls the edits back as Markdown including footnotes; PDFs can be sent, annotated with the pen, and returned with the ink baked onto the pages and text highlights extracted. The README states that syncing is done by the official reMarkable desktop app rather than by cloud workarounds, so no Connect subscription is required, and that the project is unofficial and not affiliated with reMarkable AS. It is marked beta, developed and tested on macOS with a reMarkable Paper Pro; the Windows and Linux store paths are described as untested guesses to be set manually, the plugin never deletes device data and refuses to write when the store layout looks unfamiliar, and the README asks the reader to keep vault backups.
