# dscherdi/decks

Decks turns notes into flashcards without a separate deck file: tagging a file with a decks tag makes each heading at the chosen level the front of a card and the text below it the back, and tables, image occlusion and cloze highlights are handled the same way. Scheduling uses FSRS-6 with three profiles, per-tag retention targets and a one-click optimizer that trains the weights on the user's own review history client-side. The README also describes one-click migration from the Spaced Repetition plugin and import of an Anki export carrying decks, cards, media and review history.
