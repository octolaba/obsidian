# dscherdi/decks

Decks turns ordinary Obsidian notes into flashcards without requiring a separate deck or special authoring syntax. A decks tag makes headings and their following text into cards, with support for tables, image occlusion, cloze highlights, FSRS-6 scheduling, Anki imports, migration from another flashcard format, multi-device sync, and mobile review.
