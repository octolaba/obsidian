# kh4f/flexplorer

Changes how the built-in file explorer sorts and shows items. Each folder can use its own sorting mode, a custom order mode arranges items manually by drag and drop, and files and folders can be pinned to the top or hidden. The README states that all features also work on mobile and that on touch devices items are dragged by their right edge.
