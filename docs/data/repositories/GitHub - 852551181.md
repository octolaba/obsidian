# marplek/obsidian-poker-range

This plugin creates and displays interactive poker hand range grids inside Obsidian notes. The README states that a grid is written as a poker-range code block carrying a random alphanumeric string as its identifier and a comma-separated list of hands, or inserted at the cursor with the Insert Range Table command from the command palette. Cells are clicked to select or deselect hands and dragged to change several at once, with the first click deciding whether the drag selects or deselects, and the range information in the note is updated automatically; a default range for new grids is set in the plugin settings.
