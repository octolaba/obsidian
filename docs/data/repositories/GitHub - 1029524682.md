# IvanPeshykov/obsidian-visited-countries

Visited Countries Map is an Obsidian plugin for marking and visualising the countries you have visited on an interactive world map inside the vault. The README lists a built-in stats page with totals and a coverage percentage, optional links from countries to notes or travel logs, support for Obsidian on iOS and Android, and operation that is fully local with no internet connection or external services. The map is launched from the command palette once the plugin is enabled.
