# Maximilianwte/Obsidian_CoNote_Git

Obsidian plugin that shares individual vault folders with collaborators through GitHub repositories. The README states that each shared subfolder maps to its own repository while the rest of the vault stays untouched, that syncing happens automatically without manual commits or servers, and that signing in uses GitHub's OAuth device flow rather than a manually generated token. It presents data ownership as the point: the notes live in a repository the user controls and remain as plain git history if the plugin is removed, a private repository keeps them visible only to collaborators, and the plugin is free and open source.
