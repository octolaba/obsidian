# aegixx/obsidian-contact-cards

Contact Cards renders YAML inside a `contact-card` code block as a formatted contact card showing a name, title, company, email and phone number, visible in preview mode as well. The README states that two third-party services are used: an avatar is fetched from Gravatar based on the email address, and a company logo from Logo.dev based on the email domain when a company name is given. Fields such as phone, email and location are clickable, and the styling can be changed by editing the plugin's CSS or adding a vault CSS snippet.
