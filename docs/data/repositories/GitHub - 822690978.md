# LucJager/giphy-plugin

This repository holds Giphy Plugin, whose French-language README describes an Obsidian extension for inserting animated GIFs into notes through the Giphy API. Two commands are documented, one inserting a random GIF at the cursor and one opening a modal for searching GIFs by keyword with a preview before insertion, and the settings take the user's own Giphy API key. No upstream repository description is recorded, so this body rests on the README alone.
