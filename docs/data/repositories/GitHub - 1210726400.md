# ajsscott/obsidian-apple-tts

An Obsidian plugin for macOS that reads notes aloud through the built-in say command, using the voices already installed on the system. Commands read the whole note, the selection, or from the cursor to the end, and stop playback; speech rate is adjustable between 0.5x and 3.0x. Content filters decide whether code blocks, math, tables, links, images, embeds, callouts, HTML and tags are spoken, and Markdown syntax is stripped before speaking. The README states that no internet connection, API key or subscription is involved and that Windows and Linux are not supported.
