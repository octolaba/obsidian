# ccccarlos0504/auto_navigator_pages

Auto Navigator Pages generates and maintains a same-name overview note for each folder, plus a Home note for top-level folders and notes, listing child folders and direct notes. It must be initialized explicitly before it edits anything, backs up existing same-name notes on that first run, and rewrites only the generated section of a page, leaving text outside the required navigator placeholder untouched. After initialization, creating, deleting or renaming notes and folders updates the affected pages, exclude rules cover folders, names and extensions, orphan managed pages can be cleaned, and new empty notes opened from ordinary wiki links can be routed into a _node subfolder. Pinning navigator pages and sorting underscore-prefixed entries last rely on internal file explorer interfaces.
