# DonnervS/vaultbridge

Vaultbridge synchronises an Obsidian vault across desktop and mobile through a CouchDB server the user controls, encrypting notes on the device so the server only ever holds ciphertext. It builds on the PouchDB to CouchDB replication protocol rather than a custom sync engine, and adds a conflict diff view, file history and cross-device passphrase rotation. The README describes content, file paths and metadata encrypted with AES-256-GCM, keys derived from the passphrase with PBKDF2-HMAC-SHA256 and HKDF, each file addressed by an opaque HMAC identifier with its real path stored separately and encrypted, and file bodies split into content-addressed encrypted chunks. Setup is carried by a single string, scanned or pasted on each device, and the plugin is stated to talk only to the configured endpoint, with no telemetry or accounts.
