# zfmohammed/obsidian-feather

Feather is an Obsidian theme that its README records as built using code from colineckert's Obsidian Things theme and greatly inspired by it. The recorded features are dark and light themes, Things-style checkboxes, code blocks with syntax highlighting, and colour customization for bold, italic, highlighted and blockquote text through the Style Settings plugin. The README credits colineckert for the checkbox styles and base, and names kepano's Minimal theme as a further inspiration.
