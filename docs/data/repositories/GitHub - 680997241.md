# hucorz/obsidian-autoLiterature

Obsidian plugin for literature notes that detects paper identifiers written in a note, fetches the paper's information and can download its PDF. It recognises arXiv identifiers, DOIs and medRxiv or bioRxiv identifiers, found through a customisable regular expression, and replaces the identifier with formatted details such as title, authors, journal and publication date assembled from template variables. Downloaded PDFs are named and stored according to configurable options, and the README states the plugin is adapted from the autoLiterature repository by wilmerwang.
