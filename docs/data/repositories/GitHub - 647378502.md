# uday-samsani/obsidian-cloudinary

This plugin uploads images, video and audio dragged or pasted into the Obsidian editor to a Cloudinary media library instead of the local file system, and inserts the resulting links into the note. Upload behavior and Cloudinary transformation options can be customized per content type and per vault folder. The README states that uploads are unsigned, since a signed upload would require an API key, and describes Cloudinary as a cloud storage platform whose APIs then manipulate the stored media's data properties and metadata.
