# csteamengine/notesmith

NoteSmith sends the current note to an OpenAI-compatible endpoint and writes back a cleaned-up version with adjusted Markdown formatting, grammar, punctuation and heading structure, optionally annotating it with preferred tags. The API key, model, endpoint, tags and extra prompt instructions are configured in the plugin settings, so alternatives such as a local proxy can be used instead. The README states that note content is sent to the configured endpoint only when the refine command is run, and advises against the plugin for anyone unwilling to send notes to an external service.
