# darkkross-tech/Life-RPG-1.5

The description records this plugin as being for habit tracking; the README presents Life RPG as an Obsidian plugin that turns daily habits, water intake, rewards, experience points, inventory and simple wallet tracking into a compact role-playing dashboard. Listed parts are daily habits with experience progress, a hero profile with level, class, avatar and radar statistics, quest and stat cards including custom cards tied to one or more habits, a reward shop with inventory, water goals, wallet records for income and expenses, a home dashboard with calendar month navigation, and a sidebar widget showing daily progress. The README states that data is stored locally in Obsidian plugin data and that the plugin makes no network requests and uses no telemetry, ads, accounts or external services.
