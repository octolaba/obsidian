# writing-editor/margin-notes

Margin Notes puts short annotations beside a paragraph the way a note is scribbled in a book margin: the note shows inline as a small superscript marker, with its full text in a chip out in the margin. It is enabled per file through frontmatter, per folder, or vault-wide, and notes are written with an insert command or by typing the marker syntax directly, optionally tagged with a type that is colour-coded. Wikilinks in an enabled file render as plain clickable text that opens the target in a new tab. An optional agent can read the selection, the current file or the whole vault and suggest notes through Claude, OpenAI, Gemini or a local Ollama instance; suggestions are marked as AI-written, existing prose is never edited, the core feature makes no network calls, and API keys are held in Obsidian's secret storage on 1.11.4 or later.
