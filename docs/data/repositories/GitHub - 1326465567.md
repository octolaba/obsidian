# atopos31/zima-topic-sync

Mirrors a vault one way into the currently selected Zima Topic, so its notes and attachments can be used from Zima. Pairing uses a single-use link that expires after ten minutes and binds one vault to one Zima account and Topic, in either a keep-syncing mode that goes on mirroring creations, edits, renames and deletions, or a sync-once mode that stops after the first full snapshot. Hidden paths and the .obsidian, .trash, .git and node_modules folders are excluded, and what is uploaded carries relative paths, file sizes and modification times, the vault and device names, the plugin version and a random vault identifier. Plain HTTP is accepted only for a server on the same machine, and forgetting a connection clears the local credential without removing anything already mirrored.
