# cheuyin/autodater

AutoDater adds Created and Updated dates to YAML frontmatter in new or edited Markdown notes, preserving existing Created values and waiting six seconds after edits before writing. It supports configurable property names and date formats, folder exclusions, and does not backfill existing notes when enabled.
