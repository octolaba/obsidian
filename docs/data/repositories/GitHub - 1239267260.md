# mykyquan/kindle-local-sync

Kindle Local Sync reads the local My Clippings.txt file from a Kindle connected by USB and writes the highlights that are kept into Markdown notes, one per book, without sending reading data anywhere. It is desktop only; the settings hold the clippings path, which can be selected manually when the Kindle is not detected, and the folder the notes go to. A first sync opens a preview in which each highlight is imported, skipped for this sync or ignored, and later syncs recognise what was already imported and ask only about new or missing items. The README states that the plugin keeps the reader's own writing separate from the section it updates and can reconnect existing notes after an update or after plugin data goes missing.
