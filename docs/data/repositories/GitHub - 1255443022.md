# carnalMATRIX/obsidian-mantle-otto

Otto is a chat interface in Obsidian that wraps the Gemini command-line tool, so an agent can run terminal and folder tasks from the note workspace. The README records automatic injection of the current file's contents, the active selection and vault folders into queries, and a command-auditing step in which agent actions are reviewed and approved before they run. It requires the gemini CLI to be installed and reachable on the system path or configured explicitly in the plugin settings, and it states that the plugin is styled for the Project Mantle ecosystem and the Zenith theme while remaining functional on any theme.
