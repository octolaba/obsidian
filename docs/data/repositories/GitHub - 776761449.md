# minimarimo3/Obsidian-plugin-for-Misskey

Misskey Connector adds two Obsidian commands: one embeds a Misskey note in quote format from a pasted note URL, and one posts the current line to Misskey, attaching any image or video files on that line. A Misskey account is required, and setup enters the account's domain and then generates an access token through Misskey's MiAuth flow, which requests permission to create and delete notes and to operate the drive for media uploads. Options cover switching the embedding format between HTML and Markdown, inserting text before and after the posted content for tagging, replacing displayed file names with the posting time while keeping local names, choosing the visibility among public, home and followers, and restricting which file extensions may be uploaded.
