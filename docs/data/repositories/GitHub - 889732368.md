# Lemon695/obsidian-missing-link-file-creator

Missing Link File Creator detects links in notes that point at files which do not exist and creates those Markdown files. It recognises standard wikilinks, links with aliases, path-specific links, embedded links and links into resource directories, creates many missing files at once behind a confirmation dialog that selects which to create, and can scan every note in a folder rather than only the open one. Aliases from links can be written into the new file's frontmatter, a default folder holds files whose link carried no path, Templater templates can populate new files, and a rule system assigns target folders and templates by filename pattern. A context-menu action limits the work to the links inside a text selection.
