# ckelsoe/obsidian-shell-path-copy

Shell Path Copy adds copy actions for file and folder paths to the Obsidian right-click menu and the command palette, formatted for Linux, macOS and Windows shells. The README lists built-in formats for relative and absolute paths, file and Obsidian URLs, Markdown and wiki links, filenames, and links pointing at a heading or a block; four are enabled out of the box and the rest are toggled in settings. Custom formats can be written as templates whose tokens the plugin fills in when copying, and the README states that the plugin works on desktop and mobile.
