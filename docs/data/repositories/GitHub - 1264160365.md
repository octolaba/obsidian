# october-learns/obsidian-property-explorer

Property Explorer adds an expandable right-pane view to Obsidian for exploring the frontmatter properties used across a vault. It is a three-level tree — property key, then the unique values of that key, then the notes carrying that value — where a note in the list opens on click. Search covers keys, values and note titles at once with a scope filter, entries sort by name or by frequency in either direction, and the index is rebuilt automatically as notes are created, edited, renamed or deleted.
