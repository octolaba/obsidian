# shichishima/obsidian-homekey-plugin

An Obsidian plugin that moves the cursor to the beginning of a line's text rather than its absolute left edge, taking Markdown markers into account, and toggles to the absolute beginning when the command is run a second time. The README records two commands: a Normal one that skips indentation, unordered and ordered list markers, task-list checkboxes and quote markers, and an Advanced one that additionally recognises heading markers and footnote definitions. It is intended to be bound to a hotkey such as Control+A for macOS- or Emacs-style navigation, and the README notes it can also be bound to the physical HOME key.
