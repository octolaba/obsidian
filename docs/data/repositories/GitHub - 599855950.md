# sameersismail/obsidian-perilous-writing

Perilous Writing demands writing output and deletes in-progress work when writing stops, emulating The Most Dangerous Writing App. A session is started from the command palette as a short session, a long session or a custom length, with the default durations changeable in settings, and a light grey progress bar appears at the top of the editor with the session beginning on the next keypress. If typing stops for five seconds the additions made during the session are deleted, with a warning after two seconds, and only new characters reset the timer, so backspace and Vim normal-mode operations do not. Completing a session preserves the work, and a clear-session command removes the progress bar.
