# yaishenka/obsidian-yandex-st

Renders Yandex Tracker issues and queries inside Obsidian notes through three block types: one listing issue keys or URLs, one running a search that returns a table with a configurable column set and limit, and one returning a count for a query. Inline references written as an ST prefix followed by an issue key are also recognized. Settings hold the Tracker API and web URLs, the interface language as Russian or English, and an OAuth token that can instead be kept in a token file. It is an unofficial community plugin, not affiliated with or supported by Yandex, and API calls are made only during rendering once credentials are configured.
