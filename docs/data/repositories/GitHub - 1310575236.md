# Aldorithm392/obsidian-task-tree

Task Tree shows the plain Markdown checklists of an Obsidian note as a collapsible tree and as a Kanban board at the same time, acting as a visualization layer over existing checkbox lists rather than a database or a new format. The README records nesting of task, subtask and sub-subtask to any depth, with roll-up in which a parent's state derives from its children. It also records several lenses over one structure, tree, board, columns and an inverted goal-flow, tasks that can deepen into their own linked notes, and a plain-file layout the author describes as operable by an agent.
