# pbjorklund/obsidian-ampliflow-page

AmpliFlow Publisher publishes an Obsidian note to AmpliFlow as a Markdown page. The one documented command, Publish Note to AmpliFlow, is run from the command palette with the note open. Settings hold the AmpliFlow tenant, email and password, with the password not displayed in plain text, and the README states that development requires a paid AmpliFlow account.
