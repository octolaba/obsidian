# caasion/holos

Holos is an Obsidian plugin offering a three-tier planning system whose data is stored as plain Markdown files in the vault. The README records Tracks as high-level areas of current focus, Projects living inside them with phases, tasks and recurring habits, and three task views: a Planner grid with a column per day and a row per track, a Timeline view, and a list-style Tasks view. Planner cells accept plain-text task entry with time labels and durations, tally the time commitment per cell, support dragging tasks across or within days, and are each backed by a Markdown file. Tasks use a recorded syntax that distinguishes events and open, partially completed, cancelled and completed tasks and carries times and durations.
