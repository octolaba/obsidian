# mayeenulislam/obsidian-simple-mentions

Lets people be referenced anywhere in a vault by typing a trigger character, the at sign by default, which opens an autocomplete over a contact table kept in one plain Markdown file. The table's header row is the schema, so columns can be added or renamed freely; only a mention column is required, and each row's key, limited to letters, digits and underscores, is what gets written into the note. Notes show the contact's name instead of the raw key in Reading view and Live Preview, with a hover card of details, the raw key revealed when the cursor sits on it, and a modifier-click opening the database. Renaming a key in the table can rewrite every matching mention across the vault, always or after confirmation, and commands find references, rebuild the database and validate it for duplicate or invalid keys.
