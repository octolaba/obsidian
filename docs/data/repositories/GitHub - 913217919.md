# makebit/obsidian-readeck-importer

Readeck Importer brings bookmarks saved in a Readeck instance into an Obsidian vault as notes, with their properties and metadata set automatically. The instance is configured by its base API URL, and settings choose the destination folder, whether an existing note is overwritten, and which content is saved: the text alone, or the text together with images, with annotations, or with both.
