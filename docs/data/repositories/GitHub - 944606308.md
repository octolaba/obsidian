# anindyaspaul/obsidian-gitlab-activities-importer

This repository holds the GitLab Activities Importer, described upstream as importing GitLab activities into the active daily note using the GitLab REST API. The README says a command imports the events for the note's day, taken from a date in the note's filename in one of two accepted formats, and rewrites a single dedicated section each run so the operation is idempotent, including push metadata such as branch, commit count and latest commit title where present. It supports GitLab.com and self-managed instances, needs a personal access token, and notes that the events API can omit or truncate push details for some events.
