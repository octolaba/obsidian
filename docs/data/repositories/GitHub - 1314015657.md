# illuwa/illuwa-nas-sync

Two-way synchronization of a vault with a WebDAV server such as a Synology NAS, running on desktop and mobile through Obsidian's requestUrl rather than Node APIs. Conflicts are resolved causally through per-device shard indexes chained by a previous-state hash, so sequential edits merge silently despite clock skew and only concurrent edits become conflicts, with the losing version kept in a conflicts folder. Deletions propagate as tombstones into a local trash folder, a guard blocks any cycle that would delete more than fifty files or five percent of the vault until it is approved, and a canonical path layer normalizes Unicode filenames across platforms. Transfers retry with backoff and checkpoint periodically, desktop syncs on startup and on an interval while mobile syncs only while the app is open, and credentials sit in the plugin's data file inside the vault.
