# jannusgoe/obsidian-ankisync

AI-AnkiSync detects flashcards in Obsidian notes, expands their content with an OpenAI language model, and syncs them to Anki through AnkiConnect. The README describes the detection style as RemNote-like and states that brief keywords can be entered and then expanded and formatted automatically. Decks are assigned from file names, tags follow the note's heading structure hierarchically, and the enhancement prompt is customizable; Anki must be running with AnkiConnect installed and configured to accept connections from Obsidian.
