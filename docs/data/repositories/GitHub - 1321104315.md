# NElscost/meta-quest-sync

Meta Quest Sync connects a desktop vault to the Obsidian AR WebXR experience on a Meta Quest headset: it exports the vault graph, compiles and starts a local Rust bridge and an HTTPS tunnel, and shows a QR code that pairs the headset, with session credentials placed in the URL fragment rather than stored. Commands start and stop the session, show the QR code and refresh the graph snapshot. It needs a local clone of the companion Obsidian-Ar project, which holds the viewer, bridge and orchestration, plus Git, Node.js, Rust and cloudflared on PATH; both the viewer address and the backend can be self-hosted. Note paths and links are read through the Obsidian API, and the bridge serves requested note content and media to the paired headset for as long as the session runs.
