# zhuzhige123/Obsidian-Weave-incremental-reading

A standalone incremental-reading plugin for Obsidian, documented in Chinese with an English translation, which the README states does not depend on the main Weave plugin. Material spread across Markdown, block links, PDFs through PDF++, Canvas, web pages and EPUB is turned into reading points, each keeping its source link so reading resumes at the right place. Reading points live in topics saved in the vault as `.irdeck` files and are scheduled on a calendar showing pending, scheduled and overdue items with monthly heat, priorities, a daily cap and a time budget, an item being scheduled again after each pass. One add-link action takes a pasted source and settles its name, topic and first reading day together, and material can be imported in bulk from Markdown, with folder subscription and PDF or EPUB chapter import marked advanced.
