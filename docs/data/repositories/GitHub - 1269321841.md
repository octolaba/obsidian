# hearth-code/hearthcode-obsidian

hearth-code/hearthcode-obsidian holds HearthCode, an Obsidian theme from the HearthCode colour system whose calm dark and light modes share one semantic colour language. Typed callouts, task states, layered list markers, tag pills, code blocks and quotes are styled to turn colour into reading order, and edit and reading views receive the same treatment so a note does not change character between them. With the optional Style Settings plugin the README exposes typography options, three callout intensities and the Moss, Amber and Slate accents.
