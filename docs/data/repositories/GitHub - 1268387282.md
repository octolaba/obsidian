# eluisjonathann/obsidian-remove-task-format

Adds one command that removes task checkbox formatting from the line holding the cursor, turning `- [ ] My Task` or `- [x] Completed Task` back into a plain bullet item or plain text while keeping the original indentation and bullet. The command carries no default shortcut and is bound by hand under Settings, Hotkeys. The repository description is written in Spanish.
