# thomasblc/obsidian-qvac

This plugin chats with an Obsidian vault using AI that runs on the same machine: the plugin is a thin client and the models run in a separate QVAC companion process that its README says must be installed and that the plugin reaches only over localhost. One panel holds four tabs — chat with answers grounded in the notes and clickable citations, search by meaning rather than keywords, a connect tab that proposes notes belonging together, has a model judge which deserve a link and writes the wikilink per note or over the whole vault, and an optional train tab that fine-tunes a small model on the vault. Inline writing commands to summarise, rewrite, fix grammar and expand show their result for review before it is applied, and OCR over images is opt-in. The README states that nothing leaves the computer and that the notes do not become anyone else's training data.
