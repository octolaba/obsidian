# 50tech50style/pink-muted-rose-obsidian

Pink Muted Rose is an Obsidian theme in rose pink and blush tones with dark and light modes, presented as a theme for creators who embrace the feminine. Its dark mode avoids pure black and its light mode avoids white, six heading colors run from grayish pink to sunflower, code is deep rose on pale backgrounds, tags use green pill styling, and callouts take rose and lemon backgrounds. Style Settings can adjust heading colors, body and monospace fonts, font size and line height, content width, accent colors, tag style and rainbow folder icons, and the README notes styling for Calendar, Kanban and Dataview. It is a fork of Fairyfloss by sailorhg, by way of its VS Code adaptation.
