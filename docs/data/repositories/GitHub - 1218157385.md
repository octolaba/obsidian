# that-yolanda/obsidian-calendar

iCalendar is a calendar plugin for Obsidian that displays and manages tasks from daily notes and from project files in one interactive view. Daily-note tasks are read from a configurable heading and work with the built-in daily notes plugin, project tasks come from any chosen Markdown file and heading, and the two sources are colour-coded separately. The calendar offers month, week and list views with a 12- or 24-hour clock, opens the daily note for a clicked date, reschedules by drag and drop, creates a task by clicking empty space, and edits title, time, status and description in a modal or changes status from a right-click menu. A separate dashboard summarises totals, completion rate and duration with period comparison, a donut chart of status distribution and a bar chart of daily time, and the README states that the layout is optimised for mobile.
