# zpzp13/obsidian-writing-menu

A writing environment for Obsidian aimed at novelists, gathering typography controls, custom dividers, focus mode, smart input, a spell checker, a word counter, daily work-time tracking, a calendar dashboard, version control and a wiki view into one plugin. Typography applies font, size, line height and width per note or per folder and adds focus mode, typewriter scrolling, custom heading rendering and a zen mode that cycles between wide, focus and off. Custom dividers replace Markdown rules with text or a registered SVG graphic, and smart input covers curved quotes, a symbol autocomplete popup, cursor movement out of quote and bracket pairs on Enter, and rule-based text substitution. The README describes spell checking through the Daum web API with a proper-noun dictionary of excluded words.
