# 0x1DA9430/img2html

Saves a pasted image as a file and inserts it as an HTML image tag rather than a wikilink or a Markdown image, which the README motivates by compatibility across platforms and other Markdown editors. The save path is either the current file's directory or a configured relative or absolute path, with the source attribute adjusted to match. Settings set the image width in pixels, as a percentage or automatic, whether an alt attribute is included, and a custom attribute list that replaces the width and alt settings when enabled.
