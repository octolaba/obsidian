# galkatzh/obs-svg

Obsidian SVG Editor renders svg fenced code blocks as inline SVG in reading and live-preview modes, stripping scripts, event handlers and javascript: URLs, and opens them in a visual editor from a hover button or a double-click. Embedded .svg files get the same button and a file-explorer context-menu entry, and a further button converts between the two forms: an inline block can be saved as a .svg file and replaced with an embed, or a file's source inlined back into a block. Visual mode offers select, line, circle, rectangle, freehand and delete tools, marquee selection, resizing, copy and paste, undo and redo, colour and opacity settings, and view-only zoom and pan; code mode edits the raw source and rejects parse errors without losing the drawing.
