# sandrofigo/obsidian-pretty-bibtex

The repository holds Pretty BibTeX, an Obsidian plugin that renders a raw BibTeX bibliography entry in a more readable form. Its README records the trigger as an ordinary code block whose language is set to bibtex, and notes that the header colour follows Obsidian's own accent colour setting. Its FAQ records that after enabling the plugin or changing its settings the affected notes have to be reopened, or Obsidian restarted, before entries render correctly.
