# 1ordinateur/cluddle-callouts

Obsidian plugin that adds a searchable callout picker to the editor right-click menu and to a command. The README states that the picker lists Obsidian's built-in callouts, one bundled callout, and custom callouts defined by enabled CSS snippets, so callout ids need not be remembered. From the picker a callout can be inserted, wrapped around content, replaced or removed, and installation is from GitHub releases until a community store listing exists.
