# Canna71/obsidian-readlater

The repository holds Obsidian Read Later, a plugin that keeps offline copies of web pages in a vault. Its README records three ways to bring a page in as Markdown: a bookmarklet, a command that takes the address from the clipboard, and a command that re-syncs the current note from a URL written in its frontmatter. It also records authorizing the plugin against a read-it-later service, with an optional periodic sync and a folder per service, and commands that force a sync of the unread list, storing each bookmark as a Markdown note.
