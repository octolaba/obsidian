# SharbelMarshi/latex-suite-extension

Extends the Latex Suite plugin with seven behaviours around inline math. While the cursor sits inside inline math it inserts hidden brace guards so the expression never becomes invalid mid-keystroke, and a separate layer renders the candidates Obsidian refuses, such as math padded with spaces or left empty, in Live Preview and Reading view; currency, code, comments and tables are left alone. Two configurable commands wrap right-to-left text inside MathJax expressions, with configurable Hebrew and Arabic fonts, and the system keyboard can follow the cursor between the note language, English inside math, and the right-to-left language inside those commands. It can also render inline math in displaystyle, evaluate an equation chain and append the result, and ships snippets for its own commands.
