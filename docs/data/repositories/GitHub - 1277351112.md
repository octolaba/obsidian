# Yvelious/device-plugin-switcher

Repository for Device Extensions Switcher, an Obsidian plugin that decides which community plugins are enabled on desktop and on mobile while one shared configuration folder is kept. Its settings add a table where each installed plugin is set to both, desktop only, mobile only or disabled, and the recorded state is applied when Obsidian starts and detects the device. The README presents this as an alternative to maintaining separate configuration folders such as `.obsidian` and `.obsidian_mobile`.
