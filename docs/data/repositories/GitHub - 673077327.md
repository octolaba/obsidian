# froq0/Qlean

Qlean is an Obsidian theme offering a clean and clutter-free interface, recommended for use together with the Style Settings plugin. Its file tree and outline carry ancestor and descendant indicators for the active or hovered file, accent colours can be chosen separately for the light and dark schemes through an HSL picker, and header level indicators replace the collapse arrows. Inline elements such as strong, emphasis, highlight, strikethrough and underline are customisable in colour, weight, font style and decoration, buttons and toggles are redesigned, a glassmorphism effect can be applied to modals and popups, and tables gain vertical centring, header alignment options and a full width mode. Contributors are asked to modify theme.scss and regenerate style.css rather than editing the compiled file.
