# tikitock/obsidian-vault-file-refresh

Vault File Refresh polls the vault recursively for files added or changed outside Obsidian and reconciles them, which the README ties to Flatpak installs, network drives and external sync tools where the file explorer does not update and an open tab shows stale content. A background poller scans the whole vault every 8 seconds: files present on disk but unknown to Obsidian become available to the file explorer, search, graph view and Dataview, and files whose content changed are reconciled through Obsidian's own update pipeline so an open note or board picks up the change without being reopened. The README explains the cause as filesystem watcher events blocked, delayed or dropped in those environments, and lists recursive coverage of new folders, no configuration, removal of stale paths on delete, an on-demand refresh command, and retries of failed attempts on the next poll.
