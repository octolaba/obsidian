# LucEast/obsidian-bases-image-position

Bases Image Position controls how cover images are positioned in Obsidian Bases card views, which centre them by default, so an off-centre subject is not cropped out. Position is set per note through frontmatter, either with preset focal-point values or with exact offsets in `%`, `px`, `em`, `rem`, `vh` or `vw`, where bare numbers mean pixels and offsets take priority over a preset. The property keys are renameable in the plugin settings, and the README states the positioning is applied by watching the view with a `MutationObserver`.
