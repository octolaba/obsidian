# AustinSuun/obsidian-AAAA

This repository holds AAAA, an Obsidian theme based on the Minimal theme and optimized for reading Chinese. It uses Source Han Sans CN with an article width, line height and spacing tuned for comfortable long-form reading, gives H1 headings a blue-purple gradient, colours outline levels as a rainbow, and tunes the dark and light colour schemes together. Code blocks use the FiraCode monospace font with a Chinese fallback and tables follow a LaTeX booktabs style without vertical borders; the README asks that Source Han Sans CN and, optionally, FiraCode Nerd Font be installed for the intended result.
