# noname-oni/obsidian-keyboard-analyzer

The recorded description says the plugin displays command hotkeys on a visible keyboard layout. The README describes visualizing, searching and analysing Obsidian hotkeys on that layout to spot duplicates and gaps, filtering by scope, searching by key combination, command name or plugin, and optionally overlaying system and editor defaults so that common shortcuts are not assigned over. It also lists grouping commands with per-group settings and filtration, a quick-view popup that can run commands, a configurable key-listener scope and modifier tracking either on hold or as a toggle, and a status-bar entry that opens the popup. Several of these are marked in the README as refactor, alpha, new or work in progress, hotkey editing among them, and settings migration and layout customization sit on its roadmap.
