# gansxx/auto-folder-tags

An Obsidian plugin that writes configured frontmatter tags into notes according to the folder they live in. It listens for newly created Markdown files and injects the tags for the matching rule, and a command applies the same tags to every Markdown file in the current folder, skipping tags the note already carries. Rules map a vault-relative folder path to a comma-separated tag list, and the longest matching path wins, so a rule for a subfolder overrides a broader one. The README states that the plugin works locally and sends no note content, filenames or telemetry anywhere, and the repository carries no description.
