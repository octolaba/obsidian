# adelaidasofia/obsidian-grounded-tierra

adelaidasofia/obsidian-grounded-tierra holds Grounded Tierra, a warm Obsidian theme for writers, pairing a cream light mode of forest-green text and coral accents with a walnut dark mode of sage headings and coral highlights. The README tabulates the colour roles for both modes and states WCAG AAA compliance with a contrast ratio above 11:1 for body text, a 1.65 line height, generous margins and negative letter spacing on headings.
