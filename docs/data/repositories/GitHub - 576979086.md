# maotong06/obsidian-paste-as-html-plugin

The repository holds an Obsidian plugin that pastes copied web content as HTML rather than as converted Markdown. Its README records the whole procedure as copying in a browser and then running a paste as html command from the palette, which inserts the text while keeping its original styling. The recorded inputs describe no settings, and the code is licensed under MIT.
