# Kodaskills/obsidian-po-editor

PO Editor edits gettext PO translation files inside Obsidian in two modes: an interactive grid table and a raw PO text editor with CodeMirror syntax highlighting. Entries carry singular and plural forms, translator comments, flags, message context and source references, and can be filtered by translation status, format flag, comment or context. Validation covers flag conflicts, plural integrity, empty translations, and fuzzy or obsolete entries, with a strict mode, while commands to create, view, validate and mark entries fuzzy sit in the command palette. The README also records conversion between PO and XLIFF, ARB, JSON, YAML and ICU MessageFormat, a project mode for several related files in one folder, and settings for default language, output directory, keybindings, quick actions and placeholder patterns.
