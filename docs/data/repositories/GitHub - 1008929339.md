# tanaka-mambinge/x-post-saver

Saves the text of X (formerly Twitter) posts into new notes, or into a chosen directory of the vault. The README states that it works on both desktop and mobile Obsidian and that the default save location and note format are configurable in the plugin settings. A post is saved by supplying its URL or text and running the plugin's save command from the command palette.
