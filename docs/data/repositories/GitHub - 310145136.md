# raineszm/obsidian-latex-environments

The repository holds obsidian-latex-environments, a plugin for inserting and changing LaTeX environments inside math blocks. Its README records a rewrite of the internals for version 0.3.0 and covers installation both from the community plugin browser and manually from a release archive unpacked into the vault's plugin directory. It is written in TypeScript under the MIT license.
