# sspaeti/obsidian_osaka_jade

This repository ports the Osaka Jade colour scheme to Obsidian as a theme that supports both dark and light mode. The README directs installation through the Obsidian community themes list, or manually by copying obsidian.css into the vault directory and reloading Obsidian. It also points to the same author's other Obsidian themes, Kanagawa, Kanagawa Paper and Rose Pine.
