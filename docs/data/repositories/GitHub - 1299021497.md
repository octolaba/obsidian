# qanszer/another-obsidian-nord-theme

Another Nord Theme applies the Nord colour scheme to Obsidian, with cool blue-gray tones, gentle contrast, readable syntax highlighting and subtle interface accents across panes. Its README records that the theme is based on Insanum's earlier Nord theme for Obsidian. Light and dark modes are both supported and toggled from Obsidian's appearance settings, and the README recommends the Style Settings plugin for adjusting individual colour palettes, typography and accent choices.
