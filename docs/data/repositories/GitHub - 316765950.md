# reuseman/flashcards-obsidian

Generates Anki cards from notes and keeps them in step, covering insertion, update and deletion of cards. Cards are marked in the note itself: a card tag for simple cards, reverse and spaced variants, an inline question and answer form separated by two or three colons, and cloze deletions written as highlights or curly brackets. The README lists a context-aware mode, global and local tags, and support for LaTeX, images, audio, code syntax highlighting, Obsidian URIs and references back to the note, and points to the project wiki for detailed usage.
