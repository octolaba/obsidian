# jaliriogbarrios19/mi-agrupacion

Mi Agrupación, whose README is written in Spanish, records community activity for Bahá'í local groupings inside Obsidian: visits with their sector, cycle, people visited, teachers, prayer, campaign and photos; community activities such as nineteen-day feasts and holy days with their attendance; and educational activity including children's classes and study circles with lessons and participants. Records are stored as Markdown notes with YAML frontmatter under a configurable base folder, and a dashboard reached from the ribbon or the status bar leads to those records, to a teacher register with autocomplete suggestions, and to report views covering general indicators, an SRP summary, sectors and the teaching campaign. Optional sharing between members runs through a Supabase project the user creates and configures, which others join with a vault identifier generated by the first member.
