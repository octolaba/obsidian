# Xsixteen/obsidian-daily-heatmap

The repository holds Daily Stats, an Obsidian plugin that tracks daily word count across the vault and renders it as a heatmap in the right panel, in the manner of a contribution graph. It shows today's word count in the corner of the screen, a configurable daily goal, and the number of words written in the last year. The README states that it is a fork of dhruvik7's obsidian-daily-stats, updated to modernize its libraries, add features and fix bugs.
