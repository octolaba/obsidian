# Lukather/obsidian-reminder-telegram

Sends Telegram notifications through the Telegram Bot API when Obsidian tasks reach their deadline. Tasks are read both from structured YAML frontmatter and from inline checkbox lists in Obsidian's task format with a due date, over the whole vault or a single folder. The check runs on a configurable interval, thirty minutes by default, and several tasks falling due together are sent as one digest message.
