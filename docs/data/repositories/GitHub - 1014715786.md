# thelivingphilosophy/zettelkasten-branch-tracker

This repository holds Zettelkasten Branch Tracker, an Obsidian plugin that draws Zettelkasten note hierarchies as a branch graph rather than a generic link graph. It parses Zettelkasten ID formats, including basic sequences, dot-notation branching, mixed notation and linear continuations, and lays out four tiers from great-grandparents down to branching children, with a distinct colour per tier and nodes scaled by the number of sub-notes they contain. Depth, branch limit, spacing, sub-note counts and auto-update are adjustable from a collapsible control panel, and the view supports click-drag panning, wheel zoom and click-to-navigate.
