# mProjectsCode/obsidian-safe-js-plugin

Safe JS runs JavaScript from Obsidian notes inside sandboxed Web Workers behind a deliberately small host API. The README states that scripts get no direct access to the DOM, Node, Electron or the Obsidian app object; they declare permissions in leading comments and call documented API functions that the plugin validates, with permission prompts shown before a script runs and approvals remembered per script source hash and calling plugin. Three code block languages are described — a normal one, an expression form with worker-local utilities that cannot declare permissions, and an optional debug form — alongside running configured vault script files from commands, permission-gated storage, generated API documentation, and settings that clear stored approvals. The README labels the plugin highly experimental with no stability guarantees.
