# mayurankv/Obsidian-Code-Styler

Code Styler styles code blocks and inline code in Obsidian in both editing mode and reading mode. Its settings page is split into core, code block and inline code sections chosen from a dropdown, and a single theme holds the styles for code blocks and inline code together. Languages can be excluded from decoration through a comma-separated list that accepts the wildcard operator, and code blocks handled by other plugins' processors are left alone unless their language is added to a whitelist, which accepts wildcards in the same way.
