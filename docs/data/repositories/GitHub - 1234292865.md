# JiaLinZhang24/obsidian-html-viewer

HTML Viewer renders `.html` and `.htm` files stored in an Obsidian vault: clicking such a file in the explorer opens it in the viewer, whose toolbar switches between the raw source and the rendered page, reloads the file from disk and toggles script execution, and the same view can be opened from the command palette. In the default safe mode, script tags are removed, inline event handlers are stripped, `javascript:` pseudo-URLs are neutralised and the iframe sandbox allows same-origin only, which the README recommends for static or untrusted HTML. Turning scripts on enables JavaScript for interactive documents such as canvas games and D3 or ECharts visualisations, still stripping event handlers and `javascript:` links and injecting auto-focus so keyboard input reaches the page.
