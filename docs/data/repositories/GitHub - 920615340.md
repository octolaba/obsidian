# Deedone/obsidian-runsh

Runsh runs shell commands from Obsidian. A command is written in a runsh code block together with the label for the button it produces, separated by a marker line, and the block renders as a button in the note; hovering the button shows the command behind it. The README states that the plugin was written mainly to launch development environments for various projects from one place but takes any shell command, and it warns that no security measures are provided, so care is needed about what is run.
