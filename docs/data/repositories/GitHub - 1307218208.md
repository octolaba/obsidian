# netsvetaev/obsidian-freeform-link-cards

This repository holds Freeform Link Cards, described upstream as Apple Freeform-style local link preview cards for Obsidian Canvas. The README says that pasting one complete URL onto empty canvas space produces a self-contained card: the original link is kept, the largest suitable image is downloaded into the vault, the page title and domain are shown, and the caption colour is derived from the image. The card payload is stored as small JSON inside a Canvas text node, which the README presents as keeping the preview portable and editable without a proprietary database, and a resized card keeps its aspect ratio so the image is never cropped.
