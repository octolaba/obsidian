# isax785/obsidian-sparkling-night

Sparkling Night is a dark theme for Obsidian whose author describes its colours as sparkling in the night. It defines coloured checkbox states so that tasks can be distinguished, with markers for work in progress, pause or stand-by, stop, and to be scheduled. The change log records that version 1.2.0 removed the light theme, widened the line width and changed the highlighted text colour, while 1.2.1 adjusted title padding, underline thickness, table centring in reading mode and code block text.
