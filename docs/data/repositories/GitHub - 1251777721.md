# djolex999/vir-obsidian

Vir is an Obsidian sidebar client for the vir command-line tool, which the README describes as distilling Claude Code sessions into a vault of patterns, gotchas, decisions and tools. The plugin surfaces that material through three places: a status bar dot reporting daemon health as healthy, stale, down or CLI-not-found, a Recent tab that scans the vault for vir-distilled notes including topic syntheses and colour-codes them by category, and a Related tab that queries vir for notes relevant to the note being edited. Commands cover searching the vault, surfacing related notes and opening settings, and setup requires installing and initialising the CLI and then resolving its binary path through the login shell, since Obsidian's own path often misses version-manager installs. The README records the plugin as desktop-only because vir is a CLI bound to a background daemon.
