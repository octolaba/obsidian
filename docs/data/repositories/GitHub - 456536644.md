# tingmelvin/willemstad-x

Willemstad is a full Obsidian theme extending an earlier proof-of-concept variant of Chris Grieser's Shimmering Focus theme, named after the capital of Curacao. The README states that it arrives essentially without color, and that its base and accent color options, set through the Style Settings plugin, yield over a million permutations before cross light and dark modes are counted. Documented features include a focused mode, callout types that turn images into grids or a sliding gallery or build encyclopedia-style infoboxes, CSS classes for LaTeX-like and Cornell note layouts, block widths, and alternative checkboxes, with separate theme documentation hosted outside the repository.
