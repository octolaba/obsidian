# swarogan/obsidian-mcp-rest

An MCP server for Obsidian built as a thin wrapper over the Obsidian REST API, shipped both as a command-line server and as an Obsidian plugin whose settings tab auto-detects the obsidian-api plugin and offers a copyable client configuration. The README lists 18 MCP tools covering vault create, read, update and delete, search, templates and active-file operations, prompt templates discovered from the vault, HTML-to-Markdown web fetch, and PATCH targeting of headings, blocks and frontmatter with search-replace substitution. It requires Node.js 20 or newer, the obsidian-api or local REST API plugin and an API key supplied as an environment variable, names Smart Connections and Templater as optional dependencies, and states that it uses Node built-in modules only.
