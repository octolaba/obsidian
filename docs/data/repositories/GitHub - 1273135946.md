# rxdxxxx/obsidian-auto-beautiful-mermaid

An Obsidian plugin that decides per diagram which engine renders a mermaid fence: the beautiful-mermaid library for the six types it supports — flowchart, sequence, state, class, ER and XY chart — and Obsidian's built-in Mermaid engine for everything else, such as gantt, pie, mindmap, timeline and gitGraph. It takes over all mermaid fences so nothing is rendered twice, covers Reading View and Live Preview through a CodeMirror editor extension, adapts to the dark or light theme, and gives each block a toolbar to switch between beautiful, system, both and source modes.
