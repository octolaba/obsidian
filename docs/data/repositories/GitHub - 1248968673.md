# Frankie18581/obsidian-deepseek-translator

An AI translation plugin for Obsidian offering inline translation of a selection through the right-click menu or a hotkey, a hover popup after a configurable delay, full-document translation that either replaces the original or creates a new file, and a sidebar panel with streaming output, language swap and manual input. Long documents are split automatically for batch translation with the Markdown formatting preserved. The README lists the supported providers as DeepSeek, OpenAI, OpenRouter, Google Gemini, Anthropic Claude, Grok, Kimi, Qwen and any OpenAI-compatible custom endpoint, reached through a multi-provider API abstraction layer.
