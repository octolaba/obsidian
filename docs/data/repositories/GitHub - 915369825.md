# Kay607/obsidian-pathlinker

External File Linker embeds files that live outside the vault, using the usual embed syntax with an external prefix on the path. Paths are relative to the vault folder by default, so a parent-directory prefix reaches outside it, and absolute paths are accepted as well; any file type Obsidian can handle is covered, including md, pdf, png, jpg, mp3 and mp4. Groups address the case of one folder sitting at different paths on different devices: a group holds devices with a name, a uuid used to detect which device is active, and a base path, and a group link resolves against the base path of the device in use. The README records support for Windows, Linux, macOS, Android and iOS.
