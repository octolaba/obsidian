# hailp-vn38/trader-journal-plugin

Trader Journal records trading activity in the vault as Markdown notes of three linked kinds: a reusable setup, a plan applying a setup to a symbol, date range and bias, and a live or backtest trade. A plan keeps a snapshot of the setup it was created from, so later edits do not rewrite historical plans, and a trade stores side, timeframe, prices, result, images and holding time, with risk-reward computed from entry, stop, target or exit prices. Trades are grouped into one daily journal note per symbol whose summaries and statistics are regenerated from the stored blocks, and a review step captures context, entry timing, plan adherence, mistakes and lessons. A dashboard and calendar show performance metrics, closed trades awaiting review, active plans and plans without trades, and everything stays local in the vault.
