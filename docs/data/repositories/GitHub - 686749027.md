# Hugo-Persson/obsidian-ocrlatex

Takes the most recently copied image from the clipboard and converts it to Markdown or to a LaTeX math block through one of three OCR providers. Texify and pix2tex are self-hosted services the plugin is pointed at by URL, while SimpleTex is a hosted service requiring a developer account and an access token entered in the settings. The README documents the token and hosting setup for each provider and notes that the first Texify request is slow because the model has to load.
