# october-learns/obsidian-plug-in-organizer

Repository for Simple Plugin Organizer, a plugin that gathers both core and community plugins onto a single settings page so they can be grouped and categorised. Its README records the first release as offering grouping and listing of all plugins on one page and assigning colours to groups, and states that the project is licensed under the GNU General Public License version 3.
