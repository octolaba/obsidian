# wenlzhang/obsidian-copy-metadata

Copy Metadata copies a note's metadata to the clipboard and inserts it into the active file name. The README gives the motivating case: notes captured quickly on Obsidian Mobile lack a Zettelkasten timestamp in their filename, so the plugin appends the note's creation time to the name rather than requiring a manual rename on the desktop. Detailed usage is kept on an external documentation site rather than in the repository.
