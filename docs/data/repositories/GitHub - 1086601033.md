# samuelbeard/obsidian-repertoire-plugin

Renders chord charts written in Nashville-style Arabic numeral notation inside `repertoire` code blocks, with parsing and transposition provided by the degree-chords package. Charts use numerals such as `1`, `5/7` or `4maj7` instead of letter chords, and support major and minor keys, altered and slash chords, extended qualities, parenthesised passing chords, and bracketed section labels styled as headings. The sounding key and capo fret are set in note frontmatter, shown in a header above each block, and chords are transposed to the fingered shapes played with that capo.
