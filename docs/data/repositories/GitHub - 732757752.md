# rcmdnk/obsidian-evernote-decryptor

Obsidian plugin that decrypts the encrypted blocks that arrive as plain text when notes are imported from Evernote by the Obsidian importer. Commands decrypt selected text after a password prompt and either show or replace the result, reformat it as an Evernote secret button that decrypts on click, or encrypt a selection back into that format. The README states that only the AES-128 method introduced in 2014 is supported and that older RC2 data is not, names the article the decryption is based on, and points at a forked importer that writes the secret format directly.
