# zhaohongxuan/obsidian-weread-plugin

This plugin syncs highlights, annotations, book metadata, chapter comments and reviews from Weread into an Obsidian vault. Its second major version authenticates with an API key obtained by scanning a code and falls back to cookie authentication when that fails, and it adds the community's most-highlighted passages, a book detail view with tabs for highlights, notes, popular highlights and reviews, four built-in themes with a template editor, and reading statistics. Highlights from public-account articles are supported as well, and the day's reading notes can be inserted into a daily note at a chosen position.
