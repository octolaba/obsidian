# jasoncrawford/obsidian-toml

TOML Editor opens .toml files in a native Obsidian pane instead of launching an external editor. Its README records editor behaviour built on CodeMirror 6 with TOML syntax highlighting and line numbers, Obsidian-style debounced autosave, and parse errors reported both inline in the editor and through a status bar above it that shows whether the current document is valid TOML.
