# Koshlensky/asciidoc-live

An Obsidian plugin that renders .adoc, .asciidoc and .asc files with a bundled copy of Asciidoctor.js and keeps the preview updating while you type, on a configurable debounce delay. Re-rendering is triggered by edits in the plugin's own source pane, by edits made in Obsidian's plain-text editor in another pane, and by external modifications the vault detects. The README also documents a source-mode formatting toolbar, clipboard image paste that saves the image into the vault and inserts the matching image macro, and latexmath and asciimath macros rendered through Obsidian's built-in MathJax.
