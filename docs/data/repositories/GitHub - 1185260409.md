# franklin-md/franklin-mono

An agent that reads the vault, helps think through notes and proposes reviewable changes to Markdown files, with additions, modifications and deletions shown for approval before they are applied. It is provider-agnostic and currently supports an OpenAI subscription, OpenCode API keys and OpenRouter keys, with the local experience described as free. The README frames three uses — organizing and rediscovering notes, explaining material grounded in the user's own notes and PDFs, and searching and summarizing across the vault, local files and the web — and records the project as an early release that also demonstrates a broader agent toolkit.
