# laroy-sh/obsidian-ai-link-summarizer

Obsidian plugin that summarises a link from the editor context menu, sending the URL under the cursor or in the selection to Gemini, OpenAI or Claude and inserting the result as a summary callout above the detected link. A batch mode summarises every link-only note in a folder, skips notes already summarised so a re-run resumes, optionally renames each note to a generated title and merges topic tags into frontmatter, and writes per-note failure reasons to a log file in the vault root. An inbox mode applies the same pipeline automatically to link notes dropped into a watched folder, holding them in place rather than moving them. Pages behind a login can be read through a persistent logged-in webview session instead of letting the provider fetch the URL itself.
