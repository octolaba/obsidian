# AppleSpriter/obsidian-daily-notes-prefix-matcher-plugin

This plugin opens today's daily note by matching the date prefix in a filename, so a Markdown file named after the date plus a descriptive title counts as the day's note rather than only the exact date filename. A descriptive note is preferred over an empty exact-date placeholder, several matches raise a picker, and when nothing matches the standard date-named note is created. With the core Daily Notes plugin enabled it reuses that plugin's folder and date format; with it disabled it falls back to a configurable folder and the YYYY-MM-DD format. The command is available from a ribbon calendar icon and the command palette, and its interface text follows Obsidian's language setting between Chinese and English.
