# ringeringeraja33/NarrativeCanvas

This repository holds Narrative Canvas, a node-based writing workspace for planning complex narratives, branching stories and game plots in Obsidian and in the browser. It unifies beats, dialogue, branching choices, conditions, variable updates, routing, cast and notes into a single connected structure that can be previewed and edited directly. The README scopes it to structure planning, branch validation, pitch preparation and narrative explanation, and leaves prose drafting, text polishing and dialogue writing to the writer's preferred tool; the interface supports English and Chinese, with the plugin able to follow Obsidian's language setting.
