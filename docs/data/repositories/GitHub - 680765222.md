# l1xnan/obsidian-better-export-pdf

Better Export PDF extends Obsidian's PDF export with capabilities the built-in function does not offer: an export preview, outline bookmarks, page numbers, custom margins, and PDF metadata taken from frontmatter. It can carry internal links within a file into the PDF, merge several Markdown files — a folder or a chosen set — into a single PDF, batch-export multiple PDFs, and export at any page size including everything on one page. Export is started from the More options menu of a Markdown view or from the command palette, which opens a dialog before the file is written.
