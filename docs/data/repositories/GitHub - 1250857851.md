# chilohwei/obsidian-root-folder-order

Keeps the top-level folders of a vault in a custom order in the file explorer, leaving notes and nested folders to Obsidian's normal sorting. The stated case is a vault with a fixed root structure that should not reshuffle when a folder is renamed. The order is edited by drag and drop, by typing a position number, or with up and down buttons; all current root folders can be added at once, a folder can be registered by name before it exists, configured folders are marked present or missing, and a missing one can be created from the settings page. Auto-adding new root folders, tracking renames and dropping deleted folders are optional, and the settings interface is available in English and Chinese.
