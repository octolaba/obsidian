# didacd/colorez

Obsidian plugin that colors selected text using the active theme's CSS variables instead of hardcoded hex values or raw HTML tags. The README states that a right-click menu offers changing the text color or highlighting it, with small color-circle previews, that highlights use matching translucent backgrounds with rounded corners, and that an eraser option removes the styling without leaving nested span tags behind. Because the wrapping uses theme variables, colored text follows a change of theme or of light and dark mode, and the commands can be given hotkeys.
