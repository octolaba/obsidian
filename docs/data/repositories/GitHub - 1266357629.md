# EZDevEr/obsidian-wechatreading-highlights-sync

Synchronises a WeChat Reading shelf into local Markdown notes: highlights, thoughts, book reviews, reading progress, reading time and reading statistics. It writes a summary note grouping books into reading, not started and finished, one note per book filed into a subfolder by book category, and downloads cover images into a local assets folder for inline preview. Text the reader wrote by hand between the plugin's keep-me markers survives a re-sync, incremental sync, a full re-sync after clearing, sync logs and template validation are supported, and the target folder, summary filename and the book, single-book and excerpt templates are configurable. The README states that the plugin runs locally, keeps the WeChat Reading API key only in local plugin settings, uploads no notes, and is documented mainly in Chinese.
