# eliz-abeth/sandover

Sandover is a literary theme for Obsidian, inspired by the spaces in which great works are written and the tools used to write them; its simple design replicates the typewritten page using the TT2020 font, which is encoded in the theme so no additional download is needed. Its accent colours come from the Stonington home of the poet James Merrill, one of the primary settings of his epic The Changing Light at Sandover, and headings and bold text support character dissimilarity. Blockquote syntax renders as blue comments between the lines, and that colour can be changed with the Style Settings plugin. The README recommends companion plugins for footnotes, word count, Longform, Pandoc and typewriter scrolling.
