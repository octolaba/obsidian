# aidenlx/zotlit

This repository holds ZotLit, an Obsidian plugin paired with a Zotero companion add-on that writes a Zotero library into the vault. One command turns a Zotero item into a Markdown literature note shaped by a template, the library is searched and citations inserted without leaving the editor, and Zotero annotations are read in a sidebar. The README warns that this version needs Obsidian 1.13.4 or newer including the installer version, that an older installer makes the plugin fail to load, and that literature notes and custom templates from version 1 do not carry over unchanged.
