# seventhxiv/obsidian-board-view

Board View adds an interactive board layout to Obsidian Bases that can be used as a Kanban board or a gallery. Cards are grouped by both columns and rows, dragged between groups to update the underlying note properties, and can show property-based images and icons plus colours assigned per group. Properties are rendered natively, groups can be hidden or reordered, and a new-note button creates a note in any group with its properties pre-filled. The README says the author built it because column and row grouping together is what they needed.
