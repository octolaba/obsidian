# Liqiuyue9597/quick-memos

Quick Memos is a lightweight memo plugin for Obsidian in the style of Flomo, storing every memo as a local Markdown file. Capture happens in a dedicated view saved with Ctrl or Cmd and Enter, with tag suggestions ordered by recency and frequency, wikilink insertion, image attachment from the iOS photo library or a desktop file picker, and optional mood and source metadata. Memos are browsed as a card waterfall with heatmap statistics, filtered by tag, date or keyword, and resurfaced through a random review button. The README also records sharing a memo as a PNG card, exporting a filtered set to an Obsidian Canvas, a right-click action that saves selected text as a memo, card rendering for transclusions, an iOS Shortcuts URL, and a one-click import of a Flomo HTML export with its timestamps and tags.
