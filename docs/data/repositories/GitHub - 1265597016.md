# gapmiss/dired

Dired navigates and manages vault files from a keyboard-driven text buffer modelled on the Emacs Dired mode: the directory listing is a real CodeMirror buffer whose first line is the current path and whose folders end with a slash, and every operation is a single key or a two-key chord away. Files can be marked individually, by extension or all at once and then moved or deleted in one batch, and a wdired-style rename mode edits names directly in the buffer, with stacked cursors for editing many names at once. The README states that renames and moves go through Obsidian's file manager so wiki links and embeds are updated automatically, and that deletions use Obsidian's own per-file confirmation and deleted-file preferences. Folder bookmarks with fuzzy jump, a preview mode that opens the file at the cursor in a split, inline key hints and auto-refresh complete the set.
