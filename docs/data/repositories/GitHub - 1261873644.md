# Intagri-Technologies/dainvo-task-manager

Dainvo Task Manager syncs ordinary Obsidian checkbox tasks with the Dainvo service so they can be viewed and updated from Dainvo mobile or desktop without changing how notes are written. It carries priorities, tags, due dates and source-note information, keeps tasks available in Dainvo mobile while offline, allows completing or reopening a task from Dainvo, and applies a confirmed relayed deletion back to the Markdown. Tasks are recognized after a move through a short marker that is hidden on inactive task lines in Live Preview and shown while the line is edited, and existing block ids are respected. The README states only task details are synced, with note bodies, attachments, full filesystem paths, passwords and local bridge secrets never uploaded, that one vault is connected at a time, and that Obsidian must be running for changes to flow.
