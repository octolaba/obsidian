# FRIEDparrot/obsidian-equation-citator

Equation Citator numbers equations, figures and similar labelled content in Obsidian notes and provides LaTeX-style citations and cross-references to them, including across files. Its README states that the plugin is aimed at academic and technical notes and is explicitly not intended for citing content inside PDFs or for managing bibliographic references, for which it points at a dedicated citation plugin. It reports testing on Windows, Linux, macOS and Android, with some functions limited on mobile, and keeps its tutorial in separate web documentation.
