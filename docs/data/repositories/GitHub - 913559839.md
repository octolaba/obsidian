# iamgodot/CAO

Chats with Claude inside an ordinary note, and can also use OpenAI-compatible providers such as OpenAI or OpenRouter for non-Claude models. The README states that chat histories are managed as plain notes with editable content, that chat options are configured in the note's front matter, that wikilinks add other notes as context, and that custom prompts can be inserted from templates with a chosen cursor position. Answers are formatted with headings by default or, optionally, as callouts, which the README describes as foldable and easier to tell apart from the questions. Setup requires either an Anthropic API key with a model chosen from a dropdown, or a base URL and a manually entered model name for a custom provider; image embedding in prompts is listed as not yet implemented.
