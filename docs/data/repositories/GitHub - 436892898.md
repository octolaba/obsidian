# beginner137/Obsidian-simple-note-quiz

Simple Note Quiz turns the current note into a quiz and leaves marks on it the way a school test is marked. The note is parsed into cards: a line carrying the question mark character, configurable in settings and a question mark by default, becomes a question and the content directly below it the answer, with cards separated by a blank line, while a release note records an alternative separator using a new bullet point. A quiz starts from an icon, the questions to review can be chosen or their marks cleared, each answer is revealed and then scored by the reader as correct or wrong, and the resulting marks show which parts of the note are already known.
