# qiuos/linkmind

Obsidian plugin that edits Markdown notes as interactive mind maps: headings and bullet lists become the tree, rendered as SVG and DOM, and every edit is written back as plain Markdown. Editing is keyboard-driven, with keys for adding a child or sibling, renaming, navigating, collapsing and restructuring nodes, alongside drag and drop reordering and reparenting including long-press on touch devices, multi-select, undo and redo and copying a branch as Markdown. Nodes carry emoji icons and tags that the map can be filtered by, heading and note wikilinks are drawn as dashed cross-branch association lines, and an outline panel navigates large maps. Layout can be right-facing or balanced, the map or a branch exports as SVG or PNG, and the interface is bilingual Chinese and English.
