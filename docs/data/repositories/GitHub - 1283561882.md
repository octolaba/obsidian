# manitofigh/obsidian-graph-save

Graph Save saves and restores graph layouts for people who use Obsidian's graph as a spatial map, addressing that Obsidian otherwise re-renders the nodes at random locations. Node positions are autosaved on an interval and the latest autosave is restored as an animation of nodes moving back to where they were; named snapshots of different layouts can be taken, restored, renamed and deleted, and shuffling tries out new layouts until one satisfies. Options that are off by default also save graph filters, groups, display and forces, and keep one layout per Obsidian workspace layout. The README names obsidian-persistent-graph as its inspiration and states that restoring an older snapshot does not lose nodes added since it was taken.
