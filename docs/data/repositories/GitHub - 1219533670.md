# CorrectRoadH/obsidian-task-center

Task Center plans ordinary Markdown checkbox tasks on a full-page board with Today, Week, Month, Completed and Unscheduled sections, keeping the tasks themselves in plain Markdown rather than a database or a private format. Tasks are scheduled, nested and abandoned by dragging, parent and child cards inherit schedule and status, and inline estimate and actual-time fields are summarised. A quick add parses dates in English and Chinese and writes new tasks into the day's Daily Note, and the README also documents command-line commands intended for agents and a mobile layout with long-press menus and swipe actions. It states that at least one of the Obsidian Tasks or Dataview plugins must be enabled and that Obsidian's built-in Daily Notes plugin must be configured.
