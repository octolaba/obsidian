# Jeel-Shah/todo-wrangler

TODO Wrangler scans the current note for lines beginning with TODO, including list and checkbox variants of that line, and moves them together into a TODOs section at the end of the note. It runs from a command in the palette or from a ribbon icon. The README states that the keyword it looks for can be changed in the settings, in which case the alternative keyword is extracted instead.
