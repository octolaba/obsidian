# AndyPandy1189/obsidian-game-search

This repository holds Gamebase, described upstream as a simple game file creator for Obsidian. Its README says the plugin pulls video game metadata from the IGDB API and generates Markdown notes from user-supplied templates, with single and bulk import, conflict resolution when a note for a game already exists, and fields such as release dates, developers, publishers, genres, platforms, ratings and cover images. The README states that the user must supply their own IGDB credentials, a client identifier and secret registered through the Twitch developer console.
