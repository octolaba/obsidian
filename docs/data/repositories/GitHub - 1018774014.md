# KiwiJanus/obsidian-line-ending-copyfix

Obsidian plugin that rewrites the line endings of copied text to suit the platform, currently targeting Windows by replacing Unix line feeds with carriage return plus line feed at the moment of copying. The stored Markdown files are left unchanged; only what reaches the clipboard is converted, which the README explains as a fix for older Windows applications that expect CRLF and otherwise show the text squished onto one line. It covers manual selections, code block copy buttons and pop-out windows, and keeps Obsidian's behaviour of copying the current line when nothing is selected.
