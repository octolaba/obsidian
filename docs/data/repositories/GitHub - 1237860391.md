# gurjar1/auto-heading-obsidian

An Obsidian plugin that numbers headings in real time and writes the numbers into the Markdown file, so they also appear in the sidebar table of contents, in PDF exports and on Obsidian Publish; a visual-only mode overlays the numbers without modifying files instead. Numbering styles per level include Arabic digits, Eastern Arabic numerals, upper and lower case letters and Roman numerals, and may be mixed across levels, with detection of numbers already typed by hand and undo support. Scope is chosen per note through frontmatter or by folder and file selection. The README also lists editor additions: heading indentation, a gutter showing heading levels, a sticky breadcrumb strip with word count and reading time, hover actions to promote, demote or fold a heading, a status bar with section statistics, and an ah-toc code block that renders an updating table of contents.
