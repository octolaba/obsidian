# ckelsoe/obsidian-icon-palette

Sets custom icons and colors on files, folders, tabs, tags, properties, bookmarks and ribbon commands from the Obsidian interface, drawing on Lucide icons, emojis, Simple Icons and Devicon. Each icon takes one of nine theme colors or a custom RGB value, and the picker keeps recently used icon and color combinations with an option to pin them. A rulebook, opened from the ribbon or the settings, applies file and folder icons automatically from conditions such as name, extension, path, tags, property values and dates, combined with All, Any or None logic. The README states the plugin runs locally and makes no network requests.
