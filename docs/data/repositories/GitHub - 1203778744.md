# AndreyKolygin/obsidian-puml-viewer

PUML Viewer renders PlantUML and Mermaid diagrams in Obsidian, both from diagram files with the .puml, .mermaid, .mmd and .marmaid extensions and from fenced plantuml and mermaid code blocks. The file view switches between the rendered diagram and the source with line numbers and offers refresh, zoom in, reset and zoom out, drag-to-pan, auto-fit to the viewer width, automatic refresh when the source changes, reopening of the last diagram after a restart, and export to PNG, SVG or ASCII art. Embedded blocks can toggle between code and diagram, open a zoom overlay, be saved as PNG or SVG, and carry an optional width hint that limits only the diagram area. Rendering can go through a PlantUML server, Kroki or a local server, in SVG or PNG.
