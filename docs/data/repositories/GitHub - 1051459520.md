# sandypockets/stock-blocks

Stock Blocks renders stock prices, changes and sparkline charts in Obsidian notes through two code-block types: a compact table of several stocks with sparklines, and a larger detailed chart for a single stock. The README records currency detection driven by exchange suffixes, covering USD, CAD, EUR, GBP, JPY, AUD and HKD, and cryptocurrency charts drawn from Yahoo Finance data. It also describes the project's release practice: no third-party dependencies, releases built by GitHub Actions, and SHA256 checksums published in the release notes so that downloaded files can be checked.
