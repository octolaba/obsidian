# sandypockets/stock-blocks

Stock Blocks displays stock and cryptocurrency prices, changes, tables, and sparkline charts inside Obsidian notes. It offers a multi-symbol list view and a detailed single-symbol chart, supports several currencies and crypto inputs, and emphasizes a dependency-free, open build with immutable releases and downloadable checksums.
