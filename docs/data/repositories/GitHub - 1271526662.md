# CozeBoy/Image2Local

Image2Local downloads the remote images, base64 data and bare image URLs found in an Obsidian note into local files and rewrites the note to reference them as Markdown embeds. Saving runs automatically when a note containing such sources is pasted or saved, or on demand through a right-click entry that handles a single image or every saveable image in the current note; batch conversion detects Markdown embeds, HTML image tags and bare URLs alike. The destination is configurable as a path relative to the note, relative to the vault root, absolute within the vault, or absolute on the system outside the vault. The plugin ships ten browser user-agent strings with optional random rotation for its downloads, and its settings interface is available in Chinese and English.
