# vkostyanetsky/ObsidianFastimer

Tracks intermittent fasting intervals from inside a note. A fastimer code block holds the date and time a fast started, inserted either by hand or through commands for the tracker block and for the current date and time. When the block is rendered it shows the elapsed and remaining time, a progress bar, and the fasting zones with the one currently reached marked; the figures update when the block is re-rendered, which the README says is triggered by editing the block or reopening the note. A fast is marked finished by adding its end date to the block.
