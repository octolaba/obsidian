# kebl3541/Obsidian-AI-Co-Editor

AI Co-Editor is described as an Obsidian plugin for co-editing notes with an AI collaborator, with tracked changes, approvals, chat and per-word attribution. Its README states that the plugin is the review layer rather than the AI itself: it watches the vault, and when a connected AI edits a note it converts that edit into a proposal shown in the note as struck deletions and inserted text. The reader accepts or refuses those proposals word by word, so the README says nothing enters the text without the author's judgement. The README also carries donation and sponsorship links for the author.
