# BookFusion/obsidian-plugin

This plugin imports highlights — including area or image highlights as well as text — along with notes, reviews and annotations from BookFusion into an Obsidian vault. The README states that BookFusion is a separate, external service handling eBooks and articles in formats including PDF, EPUB, CBZ/CBR and MOBI/AZW, and it names atomic highlights and annotations, syncing different content and templates to different vaults, and article support planned for 2024. The README is written as promotional copy; the capabilities named here are its claims and were not checked.
