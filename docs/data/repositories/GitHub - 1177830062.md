# wepee/obsidian-open-in-claude-code

Obsidian plugin that launches Claude Code in the directory of the current note or at the vault root. A ribbon icon opens the active note's directory, and two command palette entries cover that directory and the vault root separately. Before each launch the plugin makes the target directory inherit the enabled plugins listed in the vault root's Claude settings file, creating that file when the directory has none. The README records macOS as a requirement, because launching goes through AppleScript, and the Claude Code CLI has to be available on PATH.
