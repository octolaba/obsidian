# qwegat/Obsidian-Account-Linker

Obsidian plugin for listing accounts on external sites systematically in a note's front matter. It generates a link button for a configured service from the frontmatter description, with settings for the name of the service, its base colour, and substitution rules for the URI and the account name. The README records that URI schemes such as a mail or an obsidian scheme allow more advanced configuration, and lists reverse generation of account names from URIs and favicons on links as still to do.
