# YangsonHung/obsidian-vscode-light-modern

VSCode Light Modern is a light Obsidian theme adapted from the obsidian-vscode-dark-plus theme and tuned for macOS and Obsidian light mode. Its palette follows VS Code Light Modern with low-saturation syntax colors, and it uses SF Pro for the interface with SF Mono or Menlo for editor text. The README covers light-mode adaptations for headings, links, inline code, callouts, checkboxes, graph view, canvas, Calendar and Dataview blocks, keeps the source theme's compact 13px editor feel, and recommends specific base font size, readable line length and accent color settings.
