# udus122/dataview-publisher

Repository for Dataview Publisher, an Obsidian plugin that writes the output of Dataview queries into the note as Markdown and keeps it up to date so that it can be published. A query is placed between start and end comment markers and its rendered result is written between them; leaving the info string off the query block suppresses Dataview's own rendering of it. The README states that both the Dataview plugin and the core Publish plugin are prerequisites, documents installation through BRAT, and shows Dataview Query Language blocks as well as experimental DataviewJS blocks that emit Markdown through helpers for tables, lists and task lists.
