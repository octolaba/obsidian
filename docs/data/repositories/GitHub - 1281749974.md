# mattmaiorana/sidecar

Sidecar opens a note in a simplified Obsidian popout window built on the app's own popout API, giving that window a narrow, minimal look and a default size and position while the main window is left as it is. It can target the currently active note or a configurable default note, reached from a command, a ribbon icon, a file-tree right-click or a note toolbar button, and opening a note already open in the main window closes the main-window copy first. The note opens as a real MarkdownView, so live preview, themes and other plugins apply, and in the popout only the tab bar, view header, status bar and ribbon are replaced by a minimal top bar with optional back and forward history buttons.
