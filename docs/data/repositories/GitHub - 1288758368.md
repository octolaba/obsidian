# lucasgaldinos/obsidian-gfm-headers

This repository holds GFM Heading Links, described upstream as adding compatible GFM headers for cross-platform usage. The README explains that Obsidian's own heading anchors are case-sensitive and keep spaces while GitHub Flavored Markdown uses kebab-case slugs, and that the plugin resolves GFM-style heading links at runtime for both Markdown links and wikilinks, on click and on hover preview, without modifying any file. It adds that heading autocomplete then inserts a GFM slug together with a readable alias.
