# mss051/obsidian-simple-merge

Repository for SimpleMerge, a plugin that assembles the notes linked from an index note into one Markdown document. Its README records that wikilinks are rewritten as internal anchors so the index becomes a working table of contents, that frontmatter is stripped from the child notes while the index note keeps its own, that a heading is inserted from the file name when a child note does not start with one, and that merging can be limited to the links inside a selected block. The recorded description adds customisable separators and a live sync mode.
