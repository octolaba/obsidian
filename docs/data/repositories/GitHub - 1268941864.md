# yaye-work/obsidian-draw-a-mermaid

Draw a Mermaid builds Mermaid flowcharts visually on a canvas that is the source of truth, with blocks and connectors dragged into place, renamed inline by double-clicking, and the Mermaid code generated from the result alongside a live preview. Blocks are added by clicking a shape and connected by dragging a handle onto another block, where dropping on empty space spawns a new connected block and dropping onto an existing arrow splices a block into that connection, while a rubber-band marquee or shift-click selection supports bulk move, reshape, duplicate and delete. Block positions are stored in a comment inside the block so reopening the note restores the canvas. Editing starts from the ribbon icon, from a pencil button on a rendered mermaid block, or from the commands that edit the diagram at the cursor or insert a new one.
