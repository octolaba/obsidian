# Go2Engle/obsidian-github-copilot-integration

Integrates GitHub Copilot with Obsidian through a sidebar chat that streams responses, includes the active document as context, keeps conversation history and can copy or insert replies into the note. An inline edit command opens a floating input over a selection so Copilot can append or replace content in place, selected text can be sent to the chat as context, and an action palette gives fuzzy access to eight built-in actions such as continue writing, summarize, fix spelling and grammar, extract action items and generate code, all of which are editable. The README requires Obsidian desktop, an active Copilot subscription, and the GitHub Copilot command line tool installed, authenticated and reachable on the system path.
