# kitschpatrol/yanki-obsidian

Yanki syncs one or more folders of vault notes to Anki, mapping one Obsidian note to one Anki note. The structure of the Markdown itself determines which Anki note type a note becomes, so the README states that no Anki-specific markup or extra syntax is needed and the flashcards stay legible as ordinary notes; the parent folder determines the Anki deck name, with intermediate hierarchies created as needed. The README records the Obsidian desktop application as a prerequisite and states that the plugin has been tested with Obsidian 1.9.12 and later.
