# nn-ninja/n-brace

N-brace is an Obsidian plugin that provides an alternative local graph view. Right-clicking a note tab and choosing use N-brace opens the local graph of that note in the right-hand view, intended to sit beside the note itself and show how it connects to others and how it is structured. A G-span setting bounds how much of the graph is shown, hiding the most distant nodes once the number of visible nodes reaches that limit, and the graph can be navigated with the keyboard arrow keys. The README states that the plugin is not yet in the community plugin store and gives BRAT or a manual build as the installation routes.
