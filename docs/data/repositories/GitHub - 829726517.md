# carols12352/Oreo-theme

Oreo is an Obsidian theme that brings the colors of Oreo cookies to the app, with both dark and light modes available. The README says the author created it to memorize the good time back in primary school and the nickname Oreo. Customization is documented as general variables plus separate dark-mode and light-mode variables, and the README is offered in English and simplified Chinese.
