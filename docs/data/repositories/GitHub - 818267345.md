# Quinta0/Aurora-Twilight

Quinta0/Aurora-Twilight holds a colour theme whose README records support for both light and dark schemes, following Obsidian's base colour scheme setting. It sets Quicksand for headings and Cabin for body text, gives headings, bold and italic text their own colours, and rounds the corners of several interface elements. The README documents the light and dark CSS custom properties a user can edit directly, describes installation by placing the theme CSS file in the vault, and records the MIT licence.
