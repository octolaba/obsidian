# vulture039/obsidian-mindmap-editor

Mind map editor opens the active Markdown file as a mind map in a split pane that stays in sync while typing, with no new file format and no markup to add: headings and bullet lists become nodes under the note title as root, and heading depth and list indentation define the hierarchy. Nodes can be renamed, added, deleted and dragged, checkboxes toggle in the file, and collapsing a branch folds the Markdown pane with it in both directions. A header button can draw the lines under a node that are not nodes themselves, another hides checked tasks behind a per-parent done node, and map and editor follow each other's selection and cursor without stealing focus. Clicking a wikilink switches both sides to the linked note.
