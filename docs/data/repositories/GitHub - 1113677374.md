# takeshy/obsidian-gemini-helper

Gemini Helper is a free Obsidian AI assistant powered by Google Gemini, with streaming chat, vault operations, workflow automation, retrieval-augmented search, and reusable skills. It also provides a visual workflow builder, MCP and knowledge-source support, folder access controls, encrypted histories, edit restoration, usage tracking, and integrations with other hub plugins.
