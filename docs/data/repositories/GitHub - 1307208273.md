# 379949990/obsidian-export-img

Obsidian plugin that exports Markdown notes as images approximating the Reading view, covering themes, callouts, code, math, Mermaid, embeds, frontmatter, author and watermark. Its Export Studio renders the note with the app's MarkdownRenderer, loads remote images through requestUrl into a session cache, fits wide blocks to the export width, then captures the result once images, fonts and diagrams have settled. Preview runs at single scale for speed while copy and save use the configured export scale with font embedding, and a note, a selection or a whole folder can be exported.
