# frozenabe/neoloopy-obsidian

This repository holds neoloopy, an Obsidian plugin for systems-thinking causal-loop diagrams. A diagram is built from variables, each of them a Markdown note, connected by causal links that carry a polarity, and the plugin detects the reinforcing and balancing feedback loops that follow from that structure. The README records annotation and export, a diagramming canvas inside Obsidian, companion neoloopy app and CLI tooling, and states that everything is stored as plain Markdown and that the plugin is fully local and offline.
