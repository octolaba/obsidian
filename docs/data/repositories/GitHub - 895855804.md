# yingflower/obsidian-stu-repo-helper

This plugin, whose recorded name translates as Student Repository Helper, is addressed to students and their parents and organises study material — exam papers, notes, key documents and artwork — inside an Obsidian vault, calling on external AI services for periodic study summaries. Its Chinese README records converting photographed pages into Markdown in the order the pictures were taken, extracting text from exam images through a recognition service, and analysing artwork with a multimodal model. For English study it records generating spoken audio for a passage with a choice of British or American pronunciation, machine translation, a vocabulary list linked back to the passage a word came from, and grammar analysis; accounts with the named language model, text recognition and speech providers have to be obtained and configured first.
