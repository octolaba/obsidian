# abcamus/cloudweave

CloudWeave adds cloud-storage file nodes and AI analysis to Obsidian Canvas, so files from Aliyun, Baidu, Quark and OneDrive can be browsed and inserted as canvas nodes that record their cloud source and path. Selected canvas nodes, local notes and cloud files together can be sent to a language model for preset actions such as summarize, explain and find relations, or for custom questions, with OpenAI, Gemini, Claude and Ollama named as the supported providers. Timestamps marked in a note jump to the matching canvas node at the exact second. The README records prerequisites: the Sync Vault plugin as the cloud-storage engine with its AI MCP server enabled, and Obsidian 1.5 or later for Canvas.
