# aniruddh-jammoria/obsidian-agentic-todolist

Obsidian plugin that renders a Markdown todo file as a task board and writes every board edit back into that file, so file and board stay in step. Each heading in the file becomes a column and each task becomes a card showing its urgency, importance and effort scores and its due date, updating as the file changes. The design assumes an agent maintains the file: the repository ships a companion Claude Code skill that scans vault notes for todos, scores them and keeps the file ranked, and any other agent or a person may maintain it as long as the documented format is followed. Editing a score, due date or critical flag on the board stamps that task `UsrEdit:Y`, signalling the agent to leave its values alone on the next run.
