# deanxizian/obsidian-wiki-copilot

Answers questions from a vault by retrieving passages and citing them, using lexical search rather than embeddings, so no indexing service is required. Notes are classified by role, separating curated wiki pages from source material: a fast mode searches only the curated index with link expansion, while a precise mode plans more query variants and scans every eligible Markdown body for the most relevant sections. A configured OpenAI-compatible model plans the search phrases and writes the answer, receiving the question, a few recent turns and only the selected passages, never the index itself; replies stream with citations opening the exact note and heading. It requires Obsidian 1.13.0 or later, stores API keys in Obsidian's Secret Storage, runs on mobile as well as desktop, and treats retrieved note text as data rather than instructions.
