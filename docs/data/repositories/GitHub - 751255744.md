# Darren-project/obsidian-kv

The recorded description says the plugin adds a key-value store to Obsidian for storing and retrieving key-value pairs in the vault. Per the README the store is reached from its own settings page, where a textarea holds the data as JSON: pairs are added, modified or deleted by editing lines of that JSON, changes are saved automatically, and data that is not valid JSON produces an error message. The README also points at JavaScript documentation for the store and records that the plugin is licensed under the Apache License.
