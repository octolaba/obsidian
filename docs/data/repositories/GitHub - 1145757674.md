# fengshuzi/lite-memo

Obsidian plugin for quick capture of ideas, tasks, expenses and journal-style notes, saved as timestamped plain Markdown list items in daily journal files. Capture starts from a ribbon button, a command or a hotkey, and entries are organized by tags, quick tag buttons and automatic keyword-based tagging, with task states for todo, doing, done, waiting and cancelled items. Built-in time tracking and Pomodoro sessions run against those tasks, and the view refreshes automatically when the journal files are changed by external tools. The README is bilingual and names Flomo as the inspiration and the Logseq journal format as compatible.
