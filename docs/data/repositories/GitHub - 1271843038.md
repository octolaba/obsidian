# tyronewj/top-aligned-search

Top Aligned Search searches inside the active Markdown note from a floating window that stays above the editor, highlighting every match, emphasising the current one, and moving to the next or previous match relative to the current document position. When it jumps, the matched line is aligned to the top of the editor viewport, which the README presents as a browser-like find bar with more predictable reading position control in long notes. The window can be dragged, resized from its bottom-right corner, and left open while clicking and editing the document, and because it is not an Obsidian modal it does not darken the document and is closed only through its own close button. The plugin opens from a ribbon icon, the command palette or a keyboard shortcut, searches case-insensitively, and switches its interface between Chinese and English.
