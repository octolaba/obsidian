# MockingJay1710/selection-toolbar

Selection Toolbar shows a compact floating toolbar in the Obsidian editor whenever text is selected. The README lists inline formatting for bold, italic, underline, strikethrough, highlight, inline code and both link syntaxes, block formatting for quotes, bullet, numbered and task lists, fenced code and callouts, case transforms to upper, lower and title case, and an action that moves the selected text into a new note and leaves a link behind in its place. A few actions sit directly on the toolbar and the rest behind an overflow menu, every action is also registered as an Obsidian command so it can be given a keyboard shortcut, and formatting is blank-line aware, treating paragraphs separately while keeping soft line breaks inside a paragraph together.
