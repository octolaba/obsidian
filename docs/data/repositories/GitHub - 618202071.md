# lukasbach/obsidian-proper-dark

Obsidian Proper Dark is a theme for ObsidianMD with darker backgrounds and more colourful features. In dark mode it applies darker colours and brings the primary colour into additional places such as context menus, the actively selected file and active tabs, and it also tweaks the editing toolbar styling. It can be used in light mode as well, where only the additional uses of the primary colour apply, and the README names 5865F2 as the accent colour used in its screenshots.
