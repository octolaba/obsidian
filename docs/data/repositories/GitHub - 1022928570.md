# TKOxff/obsidian-inline-local-graph

Inline Local Graph places a custom local graph for the current Obsidian note at the bottom of the note content. It visualizes outgoing links and backlinks with configurable node styling, label limits, node caps, image exclusion, localized controls, zoom buttons, and clickable navigation without capturing normal note scrolling.
