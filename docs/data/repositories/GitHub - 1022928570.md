# TKOxff/obsidian-inline-local-graph

Inline Local Graph displays a local graph of the current note at the bottom of the note content, in space the README describes as otherwise unused. Once the plugin is enabled the graph appears automatically, showing the note's links and backlinks so they can be navigated. The README states the visualization is focused on clarity rather than visual effects, and that rendering uses the vis-network.js library.
