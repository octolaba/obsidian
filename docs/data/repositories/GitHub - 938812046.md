# ysonC/obsidian-tasks-syncer

Task Syncer connects an Obsidian desktop vault to either Microsoft To Do or TickTick, with its commands and sidebar acting on one selected provider and remote list at a time. The README states that an account with the chosen provider is required together with an OAuth application the user registers themselves, and walks through that registration, the delegated read-write tasks permission, the redirect URL and entering the client id and client secret into the plugin settings. It notes that a client secret embedded in a desktop application cannot be made fully confidential, records Obsidian 1.11.4 or newer and desktop only as the requirements, and discloses that the project is built with help from AI tooling alongside human review.
