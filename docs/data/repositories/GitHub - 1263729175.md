# rhydlewis/obsidian-ember

rhydlewis/obsidian-ember holds Ember, a warm, low-glare Obsidian theme that is charred near-black in dark mode and warm parchment in light mode, with an ember-orange accent and a palette taken from gethaunts.app. The README states that the theme ships no bundled or remotely loaded fonts and defaults to the system font stack, so it works offline with no network calls, and it recommends installing Hanken Grotesk, Bricolage Grotesque and JetBrains Mono locally for the intended look.
