# aidistan/obsidian-just-calendar

Just Calendar adds a calendar view that works with Obsidian's daily notes core plugin. Clicking a date opens that day's daily note and prompts to create it when it does not yet exist, and the calendar and the daily notes stay linked in both directions. Months and years can be changed with the keyboard or the mouse wheel, and the view is opened from a command or an assigned hotkey. The README credits CalendarJS.
