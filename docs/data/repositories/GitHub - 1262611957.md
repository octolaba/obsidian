# viggomeesters/obsidian-ics-calendar-viewer

ICS Calendar Viewer opens local `.ics` files inside Obsidian as a read-only inspection surface. It parses `VCALENDAR`, `VEVENT`, `VTODO` and `VTIMEZONE` data, lists events and tasks grouped by date or component type, shows per-event details including summary, location, organizer, attendees, start and end, timezone, UID, status and recurrence, offers text and date filters, and keeps large files bounded with parse and render caps. The README states the non-goals as explicitly as the scope: it never syncs calendars, fetches remote URLs, imports into daily notes, generates notes, sends RSVPs or writes back to `.ics` files, and its runtime code uses no network, clipboard, `eval` or process APIs. This note is grounded in the README alone, as the repository records no description.
