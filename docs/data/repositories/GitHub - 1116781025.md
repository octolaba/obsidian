# OneAutumnMango/run-script-on-property-edit

Watches YAML frontmatter properties and runs a configured script when one of them is edited. Each rule names the property to watch and the full path to the script, and can show a notification when the script runs. The script is given the edited property's name, its new and previous values, and the file path, file name and vault path as environment variables; the README notes that the previous value stays blank unless the property changed earlier in the same Obsidian session.
