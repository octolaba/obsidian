# jimhooker/jokebakery-obsidian

JokeBakery Sync keeps a JokeBakery account and an Obsidian vault in step in both directions, representing sprints, jokes and lists as Markdown files that can be edited on either side. Sprints become dated notes holding a numbered list of joke lines, jokes become notes with setup, development, punchline, notes and scratchpad sections plus structured properties, and lists become notes whose bullet items are the list contents; identity travels in a frontmatter identifier rather than the filename, so renaming is safe. A joke's attached list labels, its alternative punchlines and its setup versions are read-only in the vault and managed in JokeBakery instead. Setup takes a server address, an access token created in JokeBakery's settings and a vault folder, auto-sync on startup and on a timer is on by default, and a Conflicts folder is created only when a sync conflict happens.
