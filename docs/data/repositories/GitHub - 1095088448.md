# alexesDev/donext

Do Next Task marks the first uncompleted task in the current note and stamps it with the completion time in hours and minutes. The action runs from a check-circle ribbon icon or the Mark Next Task command, preserves cursor position and scroll location, and works with both hyphen and asterisk task formats at any level of indentation.
