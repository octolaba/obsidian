# arenasys/obsidian-ai-chat

Obsidian plugin providing a chat interface for asking an AI model about documents and notes, working with OpenRouter, OpenAI and OpenAI-compatible endpoints. Several documents can be held in one conversation by pinning them from the document name at the top of the chat, and the plugin supports images, Markdown and named API profiles. The README states that API keys are not provided and that chat messages and the content of the chosen documents are shared with whichever provider or endpoint the user specifies. It also records that release 1.0.4 changed the internals substantially and dropped bespoke support for certain providers in favour of OpenRouter.
