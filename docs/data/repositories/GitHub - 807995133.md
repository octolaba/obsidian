# Mara-Li/obsidian-explorer-hider

Obsidian plugin that hides files and folders from the file explorer, replacing hand-written CSS snippets that break when a file is renamed or moved. Items are hidden from their context menu, with folders matched by a starts-with rule and files by exact match, and an option extends hiding to the bookmarks panel. A ribbon button switches between showing everything and restoring the hidden state, and the settings list every rule for editing or deletion, including the attribute selector used for string rules.
