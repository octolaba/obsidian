# liammagee/obsidian-topic-linking

Topic Linking provides commands for finding and linking topics across a vault, aimed at PDF and web content held as reference material. One command extracts the contents of PDFs into Markdown files in a nominated folder so that they become easier to search. The README calls the plugin highly experimental and advises using it on test vaults, because it can have unintended consequences on an existing one.
