# 7596ff/obsidian-hyphenation

The repository holds an Obsidian plugin that enables justified text and hyphenation in preview mode. Its README records that the primary language is taken from the browser locale and can be overridden per file with a lang key in the note's frontmatter. It states that the styling applies to paragraphs and to ordered and unordered lists, deliberately excluding external links, which the author considers to look poor when hyphenated.
