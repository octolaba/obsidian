# eonewg/paper-ember

Paper Ember is a general-purpose Obsidian theme with warm off-white paper surfaces in light mode and layered charcoal surfaces in dark mode, taking its accent from Obsidian's native accent-color setting rather than a fixed palette. Typography, spacing, tags, tables and interaction states are shared between Live Preview and Reading View, with reading-focused CJK and Latin type and syntax colors tuned separately for each mode. Compatibility styles cover Claudian, Notebook Navigator, Dataview, Tasks, Calendar, Kanban, Excalidraw, Obsidian Git, Outliner and Advanced Tables. Style Settings is optional and adds controls for background warmth and brightness, text size, line height, reading width, fonts, sidebar density and table stripes; the theme is pure CSS with no build step and fetches no remote resources.
