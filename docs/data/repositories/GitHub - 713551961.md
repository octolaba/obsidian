# husjon/obsidian-file-cleaner-redux

Removes unused and empty Markdown files and attachments according to user-controlled options. Out of the box it only considers Markdown files of zero bytes that nothing links to; options extend this to user-defined attachment extensions, files holding only certain frontmatter, and recursive removal of empty folders, with folder inclusion and exclusion lists. The deletion target is configurable between the system trash, the vault's own trash folder and permanent deletion, an optional preview lists what would be removed so a subset can be chosen, and cleanup can run on startup. The README lists Admonition and Excalidraw among supported external plugins.
