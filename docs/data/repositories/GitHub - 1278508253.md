# jaliriogbarrios19/mi-agrupacion-plus

Mi Agrupación Plus, whose README is written in Spanish, is a centralised Obsidian plugin for recording Bahá'í community activity, joined through an invitation code instead of a manual backend setup. An administrator names a grouping in the settings tab, creates it and generates a code, while an auxiliary pastes that code, registers or signs in, and is connected. The README records two-way synchronisation with a Supabase backend that is already configured on the project's side, running manually or on an interval of one to ten minutes, and states that each grouping's data stays isolated from every other.
