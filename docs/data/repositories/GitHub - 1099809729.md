# qingruikz/image-previewer

Image Previewer opens images embedded in Obsidian notes in a modal overlay with viewing controls. Clicking an image in Preview or Live Preview mode opens it, and a toolbar offers zoom by mouse wheel, pinch or buttons, panning by drag, rotation through a slider or in 45-degree steps, horizontal and vertical flipping, a grayscale toggle and a reset to the original state. Two-finger rotation is supported on touch devices, and the README is published in English, Chinese and Japanese.
