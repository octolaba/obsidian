# hungsu/obsidian-prompt

Prompt shows a random text prompt drawn from a file in the vault, offered by the recorded description as a quick kick of writing inspiration. The README states that the user creates a file of prompts, each one plain text without Markdown and fitting on a single line, and then selects that file in the plugin's settings. A prompt is displayed by clicking the sidebar button, by running the Show Random Prompt command from the command palette, or by assigning a hotkey to that command.
