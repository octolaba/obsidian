# mrniket/palta-obsidian-plugin

Palta Note renders Kaydas, Gats and Relas written in Bhatkhande notation inside Obsidian notes, using the palta-note web component under the hood. A note declares a palta code block whose first line optionally lists the vibhag positions, separated from the composition lines that follow. Leaving the vibhag structure out is supported for quickly noting things down, and the README shows both forms and records nothing about settings.
