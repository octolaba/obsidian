# Abdulkader-Safi/obsidian-safi-site-audit-plugins

Safi Site Audit runs website audits from inside a vault by wrapping the Safi-Studio-Scanner engine, which crawls a site and scores it across SEO, content, links, images, structured data, security and crawlability using 94 rules in 15 categories. Each run writes three siblings under a configured audit folder, named after the site: a Markdown report that opens in Obsidian, the full report data as JSON that the dashboard reads, and a standalone HTML export. A dashboard opened from a ribbon icon or a command takes a URL and an optional page limit, reports progress while crawling, and shows the overall score, the category breakdown, each issue with its fix and per-page findings, with audit history grouped by site in the sidebar.
