# liamcain/obsidian-creases

Creases provides tools for folding Markdown sections in Obsidian around a crease — a fold comment placed in the note to mark where a fold belongs. Commands toggle a crease on the closest foldable heading or list, fold along all creases, crease the current folds, and iron the creases out again, which the README presents as a way to save a folding state, search freely, and restore it afterwards. Fold levels borrowed from vim raise or lower how deeply headings are unfolded, and creases carried in Templates or Templater templates are folded automatically.
