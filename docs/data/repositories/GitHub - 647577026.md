# Zerokei/Litos

Litos is described as a theme for Obsidian on macOS, and its README presents it as having academic aesthetics, Tufte-style sidenotes and CJK font support. Recorded features are academic typography, sidenotes built with container queries, light and dark modes with an HSL accent colour system, custom callout variants, styled checkboxes, tables and Mermaid diagrams and a minimal interface. The README names a recommended font stack including LXGW Bright, JetBrains Mono and Source Serif 4, and credits Obsidian-Serenity, Gwern.net and a sidenote adjustment module as inspirations.
