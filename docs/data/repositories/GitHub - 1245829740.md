# xRyul/draw-in-canvas

Draw in Canvas adds a freehand drawing layer on top of Obsidian canvas files while keeping the normal JSON Canvas data intact, storing the strokes inside the same file. Mouse, touch and stylus input are supported with stylus pressure used when available, brush colour, size, opacity and hardness are set from controls beside the canvas, and an optional handwriting mode produces smoother tapered strokes. Strokes can be selected by marquee or modifier click to move, resize, recolour, restyle or delete them, and undo and redo work with the standard shortcuts and the canvas buttons. The README states the plugin makes no network requests, that Obsidian still opens the canvas without it although the drawings are then not visible, and that very dense drawings can affect performance.
