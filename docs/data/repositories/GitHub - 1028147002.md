# hikosalaidarkcommit/obsidian-image-link-updater

Image Link Updater rewrites image links across an Obsidian vault when image files are renamed, moved or reorganised, so references are repaired without manual editing. It also intercepts clipboard paste events to save images into the attachment folder as standard Markdown image links rather than Obsidian's default wiki-link format, and adds a right-click Cut & Paste command that moves one or more files and updates every reference in one step. When files are moved outside Obsidian, the plugin detects the delete-and-create event pair and repairs links by filename. The README records the plugin as MIT-licensed, desktop-only, and requiring Obsidian 1.5.7 or later.
