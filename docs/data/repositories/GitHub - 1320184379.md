# obsidian-power-plugins/obsidian-power-bases

Power Bases adds six views to Obsidian's core Bases plugin - a kanban board, a calendar, a Gantt-style timeline, charts, an image gallery and a reworked table - which appear in the view switcher beside the built-in ones. Rows remain ordinary notes with their data in frontmatter: dragging a card between board lanes writes the grouping property, dragging a calendar chip reschedules it, and dragging a timeline bar moves or resizes it. The table gains extra field types, formulas with a live editor, number and date formats, rollups, subtotals and value colors, while boards add manual order, swimlanes, WIP limits and lane rules. It requires Obsidian 1.10.2 or newer with Bases enabled, can create a base from a folder or import one from CSV, and groups each change into a single undoable batch.
