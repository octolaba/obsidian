# shuxueshuxue/superstition

Superstition reworks the suitable and unsuitable pairing of the traditional Chinese calendar into a routine manager. Activities are defined in the plugin's settings together with how often each is permitted — once every seven days, once every fourteen, once a month — and a command shows which of them today recommends and which it forbids. The README's own examples are vault housekeeping habits such as installing plugins, switching themes and reorganising folders, and it presents the plugin as a way of having a reason not to do unnecessary things.
