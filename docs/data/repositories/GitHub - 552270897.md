# proog/obsidian-trash-explorer

Trash Explorer lists the files in the vault's own trash folder and allows them to be restored or deleted, which the README presents as useful where hidden folders are hard to reach, such as on iOS. It works only with Obsidian's trash, so deleted files have to be set to move there in the file and link settings. Items are restored to the vault location matching their location in the trash, and an Empty trash command removes everything at once.
