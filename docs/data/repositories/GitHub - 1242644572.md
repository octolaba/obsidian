# msyaifullah/brunet

Brunet opens Bruno API request files — .bru and runnable .yml — inside Obsidian, renders each request as an editable card and sends it without leaving the notes. A Collections sidebar browses every request in the vault for quick running, while the request view exposes the HTTP method, an inline-editable URL kept in sync with the params tab, a copy action producing the equivalent bru run CLI command, and a Send button whose results appear in a Console tab. An Environment tab or the plugin settings select a Bruno environment so that variables resolve from the collection's environment files. The README describes a collection as a folder in the vault carrying bruno.json or collection.bru at its root.
