# dk949/obsidian-mode-manager

Mode manager adds dedicated commands for switching an Obsidian pane to a specific mode instead of relying on the default toggle: switch to reading, to live preview, to source, to edit while keeping the existing source or preview setting, and one that cycles through reading, source and preview in order. Each command has a stable identifier for use from scripts. A note property, named default-mode by default and configurable in settings, makes a file open in a given mode, accepting the values edit, preview, source and reading, with any other value ignored and a notice shown. The README records that this property is currently broken for daily notes opened at startup.
