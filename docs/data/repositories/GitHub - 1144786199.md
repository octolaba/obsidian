# scottschroeder/obsidian-graph-search

Graph Search is an Obsidian plugin that searches notes and ranks the results by link proximity in the graph combined with title and body relevance, intended for cases where plain search returns too many hits. The README records a Graph query command whose syntax mixes plain terms with near, tag and path filter chips, so a query can require text and a tag while scoring results by graph distance from one or more named notes. Scoring lowers the score as graph distance grows and discounts notes carrying many links, so a hub note does not connect everything; weights, falloff and a debug mode showing per-result score breakdowns are configurable. The README records that the index and graph are rebuilt each time the search modal opens, and that tag collection relies on an internal Obsidian API that may change.
