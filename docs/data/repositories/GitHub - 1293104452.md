# zspatter/obsidian-hoverlay

Previews external links on hover in notes, Canvas text cards and pop-out windows, in three modes: the live page rendered in an Electron webview, a reader view extracted with Mozilla Readability and sanitized, or a metadata card fetched through Obsidian's own request pipeline. The README explains that iframe-based preview plugins fail on sites sending framing headers such as X-Frame-Options, and that the webview path avoids that class of failure. Media links from providers including YouTube, Vimeo, Spotify and SoundCloud load the provider's embed player instead of the full page, and the popover can be browsed, pinned, resized or sent to the browser.
