# curio-heart/obsidian-wyrd

Wyrd is a purple-hued, low-contrast, dual-mode Obsidian theme that its README describes as expressive, colorful and animated rather than minimal. The author states that it is still a work in progress with sections not yet restyled, and that unusual combinations of Markdown can produce styles Markdown does not otherwise offer. Some styles obscure text in preview or Publish, and the README warns explicitly that these are for fun and are not real privacy measures. Fonts are imported from Google Fonts and scale with the editor font size, headings included.
