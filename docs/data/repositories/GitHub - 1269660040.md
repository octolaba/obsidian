# arias007/obsidian-mobile-webviewer

Mobile Webviewer offers two modes for browsing the web inside Obsidian on a phone. Browser View is a plugin pane laid out like a mobile browser, with an address and search field, bottom controls, a tab strip holding per-tab URL and history state, downloads, bookmarks, a reading list, cache controls and link capture; its foreground is an editable reader-style web note with a full Chromium webview kept loaded behind it, switched in through Note, Web and Split controls. Note Browser is the same shell rendered inside a real Markdown note in the vault, enhanced with a lightweight search shell, bookmarks bar, cache, downloads and history. The README records that edited text and doodles auto-save into plugin data and are written out to Markdown on request, and that pages opening in a new window are routed into browser tabs.
