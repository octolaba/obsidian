# Butterski/obsidian-dnd-hp-tracker

DnD HP Tracker is a hit point tracker for characters inside an Obsidian vault, opened from a ribbon heart icon or a command and shown in the right sidebar by default. It renders a colour-coded HP bar, tracks temporary hit points separately and applies them before regular HP, and applies resistance or vulnerability modifiers when damage is entered. Further actions cover healing, a long rest that restores maximum HP and clears temporary HP, concentration saving throws after damage taken while concentrating, and a combat log of the five most recent actions with undo of the latest one. The README states it works on desktop and mobile Obsidian.
