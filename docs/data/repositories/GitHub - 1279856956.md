# p77-don/form-builder

Builds an input form from a formbuilder code block embedded in a template, then creates a new note from that template with the entered values applied, filed into the folder the block's meta section names and opened automatically. A syntax generator assembles the block so its syntax need not be memorized. When several templates exist a template picker opens with folder, favourites and history tabs — the history keeping the last twenty templates used — plus a search box that flattens folder results while filtering. The template folder defaults to a Templates folder, only Markdown files there containing a formbuilder block are recognized as templates, and the whole interface switches between English and Japanese.
