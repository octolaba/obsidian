# wheesys/obsidian-image-enhance-plugin

This Obsidian plugin uploads images to an image host through PicGo, PicList or PicGo-Core. Pasting an image uploads it and replaces the embed with the hosted link, and further commands upload every image in the current file or across the vault, download remote images in the current file to local files, clean up unreferenced images, and delete links pointing at images that no longer exist; uploads can also be started from the context menu or by drag and drop. Setup routes uploads at a local PicGo server endpoint, and with PicList 2.5.3 or later URL parameters select the image host and configuration name, so different vaults can target different hosts. Per-file behaviour is controlled from frontmatter, and the README — written in Chinese — notes that the plugin has not been tested on Mac and that Obsidian should be restarted after an update.
