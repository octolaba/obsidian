# nnshi-s/obsidian-vocabulary-view-plugin

Vocabulary View renders blocks of words and their explanations as a vocabulary test. A block declares its type and can be previewed as a list showing every word, as a single-choice question, or as a card, each with subtypes that hide the word, hide the explanation, or mix the two at random. The update log records a vocabulary books feature and spell checking inside card blocks.
