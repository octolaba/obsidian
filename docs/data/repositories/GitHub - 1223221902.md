# whitte-h/Lyrio

Lyrio keeps song sections in sync within an Obsidian note: a block opened by a double-colon tag such as a chorus marker is mirrored into every other block carrying the same tag when it is edited, after a 300 ms debounce, and a bare tag with no body is filled from the nearest existing instance. Section names are case-sensitive, an optional closing tag delimits sections explicitly instead of relying on blank lines, and a trailing asterisk marks an instance as local so its edits never propagate. Inline bar content appended to a marker, for chords or key, syncs across instances by itself; exception tags, of which the verse tag is the default, sync that bar content and the colour while leaving each instance's lyrics independent.
