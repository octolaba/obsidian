# powderfirm-ship-it/obsidian-headless-mode

Headless Mode is an Obsidian plugin that hides every Obsidian window and removes the application from the macOS Dock, leaving it running behind a menu bar icon. The README records a menu on that icon carrying a Headless checkbox, an Open Obsidian entry that leaves the mode, and a Quit entry, plus command palette entries to toggle or enter the mode. Settings record starting directly in headless mode, whether the Dock icon is hidden while headless, and a white, black or automatic menu bar icon colour. The README states the plugin is desktop-only, that Dock hiding is macOS-specific while the tray toggle still hides windows elsewhere, and that unloading always restores the window and Dock icon.
