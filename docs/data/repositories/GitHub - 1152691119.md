# rapphcd/obsidian-vault-cleaner

Vault Cleaner is an Obsidian plugin that removes unused media, untitled files and duplicated files, run from a trash icon in the ribbon menu. The README states that media files such as images and PDFs are deleted when no Markdown file uses them, that untitled files are removed with an option to exclude non-empty ones, and that among duplicates the most recent version is kept and the older copies deleted. Both the untitled and duplicate passes are toggled off by default in settings.
