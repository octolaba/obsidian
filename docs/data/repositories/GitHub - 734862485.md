# daynedaniell/zettelcasting-plugin

ZettelCasting assembles the current note into one social post and schedules it through the ZettelCasting service, replacing links and embeds that sit on their own line with the content they point to, recursively. Embedded images and videos are uploaded and attached rather than left in the text, and nothing is scheduled if an upload fails; an optional reflow folds the hard line breaks that read badly in a feed, while headings, lists, quotes and code blocks keep their own lines. A dialog sets the date and time, the target platform among those connected to the account, and the filename of the copy written beside the source note. It is desktop-only on Obsidian 1.13.0 or later and needs an account API key, which is stored in the plugin's settings and sent only to that service.
