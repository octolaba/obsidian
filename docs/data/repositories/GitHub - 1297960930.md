# ZJie-Wang/obsidian-composed

Composed is a light mode Obsidian theme for focused reading and writing, giving notes a paper-like surface with a LaTeX-inspired heading hierarchy and a narrow text measure. Reading view and Live Preview share the same heading rhythm, long-form prose is fully justified with automatic hyphenation, and tables, nested lists, blockquotes, callouts, inline code and syntax highlighting are restyled. Print output is tuned for A4 and the repository ships a two-page sample PDF exported from Obsidian, while the README still recommends converting to LaTeX for publication-grade typesetting. The desktop sidebar buttons are hidden and replaced by invisible edge targets below the title bar, with the command palette as the alternative, and the theme uses the fonts configured in Obsidian rather than bundling its own.
