# Mara-Li/obsidian-dataview-properties

Repository for Dataview Properties, an Obsidian plugin that copies Dataview inline fields and their values, including calculated ones, into frontmatter properties and keeps the two synchronised. It converts block and inline queries written in DQL or DataviewJS, evaluates calculated values before writing them, synchronises on a configurable interval or through a command, and can optionally clean a property out of the frontmatter when its Dataview field is removed. Written properties take a configurable prefix that avoids clashes with existing keys and cannot be empty, files are excluded by path, by regular expression or by a frontmatter key, and field matching can ignore case and accents; the README states that the Dataview plugin must be installed and activated.
