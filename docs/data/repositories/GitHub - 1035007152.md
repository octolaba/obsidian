# mssoftjp/obsidian-voice-input

Voice Input is an Obsidian plugin for multilingual voice input using OpenAI speech-to-text, described as using the GPT-4o transcription models with prompts tuned for Japanese, English, Chinese and Korean. The README lists one-click and push-to-talk recording from a microphone ribbon icon, model selection, separate settings for interface language and recognition language, optional dictionary-based post-processing, in-view copy, clear and insert actions, and automatic draft saving. It records the requirements as an OpenAI API key, internet connectivity and desktop Obsidian on Windows or macOS, with local voice activity detection needing a user-supplied WebAssembly file.
