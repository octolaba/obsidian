# louvlwu/obsidian-aindentpaper

AindentPaper adds three independent display options to Obsidian. First-line indentation follows East Asian typesetting conventions in reading view, with adjustable paragraph spacing and line height, and headings, lists, code blocks, quotes and tables are excluded automatically. A paragraph splitter breaks rendered paragraphs containing line breaks into separate paragraphs so the spacing setting applies, using an idle-callback batched traversal that skips code blocks and tables and a mutation observer for new content. Paper textures such as kraft, fine white, aged, rough-grain, blue-gray, frosted glass and a configurable grid can be applied to the editing and reading views and to the Canvas backdrop, with adjustable opacity and dark-mode variants.
