# Instapaper/obsidian-instapaper

The recorded description says this is the official Instapaper plugin for Obsidian. The README states that it integrates with an Instapaper account to save URLs from Obsidian notes to Instapaper and to sync highlights and notes back into the vault, and that it requires Obsidian v1.11.0 or higher. Every synced highlight carries a block identifier formed from a caret, the letter h and the highlight id, so other notes can link to an individual highlight and reference it in queries and searches. Because Obsidian's tag format is more restrictive than Instapaper's, runs of spaces in a tag become a hyphen and an entirely numeric tag gains a trailing underscore, and the settings choose which article properties appear in synced notes.
