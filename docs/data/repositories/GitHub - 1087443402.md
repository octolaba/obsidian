# santiyounger/wpm-reading-time

Calculates reading-time estimates for selected text or a whole note from a reading speed the user records in words per minute. The README describes multiple named speed presets, for silent reading, speaking or presenting, switched from a dropdown, and a result view showing reading time, word count and the current speed. It runs as a command, and the README states that it is desktop only.
