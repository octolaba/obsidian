# heran11011/cola-obsidian

Obsidian plugin for chatting with the Cola assistant in a sidebar, where it sees the file currently open. The README describes quoting a selection as a reference for a question, sending a selection directly, inserting a reply at the cursor position, chat history persisted across sessions, and commands that can be given custom hotkeys. It states that the Cola desktop application must be installed and running with its Obsidian channel plugin enabled.
