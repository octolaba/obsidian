# nuthrash/obsidian-html-plugin

The repository holds an HTML reader plugin for Obsidian, which opens files carrying the html and htm extensions inside the app. Its README describes the workflow as placing such files anywhere in the vault and clicking one to read it, and documents general settings alongside configurable hotkeys and touch gestures. Installation from the community directory and by hand are both covered, together with build instructions and a list of known issues.
