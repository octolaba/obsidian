# d7sd6u/obsidian-hide-index-files

This plugin hides folder notes, the index files of folders, from the file explorer, and the README recommends using it together with the folder-notes plugin. It argues that folder-notes relies on direct DOM patching and vault event listeners that can fall out of sync with the explorer's DOM tree and therefore misses some folder notes, especially alongside lazy-cached-vault-load, whereas this plugin patches tree items directly. The remainder of the README lists the author's other plugins.
