# isaiahsarju/map-note

Creates notes carrying the properties that the Obsidian Bases Map view renders, filling a user-supplied template with values looked up from OpenStreetMap. Template placeholders cover the OSM fields — latitude and longitude, which are required for a point to appear, plus display_name, name, osm_id, class and type — and plugin-generated values such as a lucide icon and a colour. The README requires Obsidian 1.10 and records the plugin as beta, installed through BRAT.
