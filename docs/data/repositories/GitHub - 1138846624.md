# fengshuzi/applenotes-sync

An Obsidian plugin that copies notes from a folder in the macOS Apple Notes app into a target folder in the vault, on manual refresh only. The sync runs from a sidebar refresh button or a "Sync macOS Apple Notes" command, carries images, tables and other rich content, and takes the source and target folder names from settings. The README states that the feature is macOS-only, and the repository carries no description.
