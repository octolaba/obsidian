# fengshuzi/file-commander

File Commander is a batch file management plugin for an Obsidian vault: files are selected in a list view and then deleted, moved, tagged, or have their tags replaced and their frontmatter property names renamed in bulk. It also rewrites embedded images, renaming them after the note with a numeric suffix and updating every reference, and converts image links between relative and shortest-path styles for compatibility with editors such as Typora. Audit commands find broken image links, broken file links in both wiki and Markdown form with a one-click repair, unreferenced images in the configured image folder, untagged notes, orphan notes with no incoming or outgoing links, and empty files. The file list can be filtered by folder or by tag; the README is written in Chinese.
