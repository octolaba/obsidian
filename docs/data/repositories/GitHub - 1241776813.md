# dictava/obsidian-sync

Syncs voice-note artifacts produced by Dictava into an Obsidian vault. The README states Dictava turns voice messages sent to its Telegram bot into structured artifacts such as daily notes, blog drafts and meeting summaries, and that the plugin fetches pending deliveries using an account API key pasted into the settings, either on demand or in the background with auto sync. It lists the HTTPS endpoints called on the Dictava server and states that no vault contents are sent, only the API key in the authorization header and the vault name used to scope deliveries to this vault.
