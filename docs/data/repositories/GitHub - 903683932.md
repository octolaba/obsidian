# gsarig/obsidian-sentinel

Sentinel updates note properties or runs commands in reaction to a document's visibility changing, for example incrementing a views property whenever a note is opened, writing the current datetime into a modified property when a changed note is left, or running a linter on open or on exit. Each action is defined in the plugin settings, beginning with which notes it targets: an empty target matches all notes, a value prefixed with a hash matches notes carrying that tag, a value ending in a slash matches a folder including nested ones, and plain text matches a note title case-insensitively. Any of those conditions can be negated with a leading exclamation mark so that the action runs on every note except the matching ones.
