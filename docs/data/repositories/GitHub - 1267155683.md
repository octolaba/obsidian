# zhenghaoyang24/obsidian-plugin-vaultbuddy

VaultBuddy is an AI chat assistant that lives in the Obsidian sidebar and uses the whole vault as context, so questions are answered from the user's own notes. The README describes automatic two-stage retrieval of relevant note content for each question, inclusion of the note currently being edited in full so it can be summarised or discussed, discovery of related material across separate files, and suggested edits presented as a visual diff reviewed line by line and accepted or rejected. It also documents reusable custom skills that activate from the message, several configurable OpenAI-compatible models switchable on the fly, API keys encrypted and stored locally through the Web Crypto API rather than synced, and chat history, skills and settings kept in the plugin's own data file.
