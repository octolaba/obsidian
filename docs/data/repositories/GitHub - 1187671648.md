# roar-jar/obsidian-voice-workflow

Voice Workflow is an Obsidian plugin that handles voice recording, real-time transcription, template-based summaries and archiving of the original transcript from the right sidebar. Its README, written in Korean, documents recording controls with pause and stop, a live transcript feed, speech-to-text through an automatic mode, macOS local speech, Windows speech or an OpenAI-compatible endpoint, and summarisation or translation through OpenAI, Ollama, Claude or Gemini. Summary templates are read from the vault's template folder, a consent confirmation can be required before recording, participants, agenda, consent, recording time and provider are written to note frontmatter, and the audio file and raw transcript are archived at the foot of the note. The README states that macOS is the most verified platform and that the Windows path has not yet been finally verified on real hardware.
