# the-quotient/obsidian-time-tracker-statistics

This plugin is a statistics companion for the separate Super Simple Time Tracker plugin, reading its data across the whole vault through the Dataview API and rendering daily and monthly summaries. Which data belongs to a period is decided by the file name, a full date for the daily view and a year with a month index for the monthly view, and entries are grouped into categories from file tags configured in the settings. Categories can carry a target time so the breakdown reports remaining time, overtime and deviation, and the monthly view accepts parameters inside the code block for carried-over deviation, vacation days, sick days and other non-working days. The daily view also reports whether a tracker is currently running anywhere in the vault, and both views are available as commands or as code blocks.
