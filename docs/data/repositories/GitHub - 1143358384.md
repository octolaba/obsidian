# mssoftjp/obsidian-audio-recording-timer

An Obsidian plugin that starts the core Audio recorder with an end time and stops it automatically when that time is reached. A modal offers quick end times beginning at the first 15-minute clock boundary at least 15 minutes away and covering about two hours, extendable in settings by 30-minute steps up to five hours thirty minutes; recording can then be stopped early or extended from the same ribbon icon, with remaining time in the desktop status bar. It requires the core Audio recorder plugin, whose start and stop command ids are configurable, and its README discloses no network use, no telemetry and no account.
