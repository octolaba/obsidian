# fanis/obsidian-style-tags-in-search-results

Style Tags in Search Results adds a CSS class, by default search-tag, to tags rendered in Obsidian's search results so that they can be restyled with custom CSS, and it exposes a settings toggle that hides them outright. The README gives the motivation: when tags follow text on a heading line, search results become long, and hiding the tags leaves only the text itself. Its provenance section records that the author wrote the plugin with assistance from large-language-model tooling and reviewed, tested and adapted the code.
