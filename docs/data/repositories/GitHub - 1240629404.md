# TimiKays/markpage-obsidian-plugin

The recorded description says in Chinese that this plugin pushes notes to MarkPage to generate paginated images, and the README is written in Chinese throughout. It sends the current note together with its images to a MarkPage instance — an editor that turns Markdown into images sized for social platforms — from a ribbon icon or the command palette, with a second command that chooses a theme first. The plugin runs a lightweight local HTTP service, by default on port 3001, which the MarkPage page polls for the content, so vault images are read straight from that service rather than uploaded or base64-encoded; settings cover the MarkPage address, a default theme among the ten built in, and whether the browser opens automatically.
