# echo-saurav/slash-snippets-plugin

Slash Snippets inserts reusable pieces of text while writing, triggered by a character that defaults to a slash and reading its snippets from a configured folder. Recorded settings cover the trigger character, the snippet folder path, an option to leave property values out when inserting, and Templater support for snippets written in its syntax. Two text variables are recorded: one that places the cursor at a chosen position after insertion, and one that inserts the most recently selected text into the snippet.
