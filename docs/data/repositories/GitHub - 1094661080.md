# mkshp-dev/obsidian-finance-plugin

Beancount Ledger integrates the Beancount plain-text accounting system with Obsidian, turning a vault into an accounting dashboard with net worth tracking, balance sheets, charts and financial metrics. The recorded description adds inline BQL queries embedded in notes, validated transaction entry with account autocomplete, and automatic commodity price fetching into Beancount files. The README states the plugin builds on an existing local Beancount setup and requires Python 3.8 or newer with Beancount v3, the separate `bean-query` package, and optionally `bean-price` for price fetching, with WSL supported for Windows users; the full guide lives on a separate documentation site.
