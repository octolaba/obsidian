# nikoneex/obsidian-kaper

Kaper for Obsidian turns Markdown files containing a Kaper frontmatter flag and YAML block into structured recipes rendered in Live Preview and Reading view. It provides a form editor for ingredients, steps, servings, timings, tags, notes, and warnings, with auto-save and drag reordering. Cook Mode guides a recipe step by step in an in-app panel, while the same portable file can be used by Kaper's web or desktop apps.
