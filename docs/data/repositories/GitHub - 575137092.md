# willasm/obsidian-open-weather

This plugin reads the OpenWeather API and brings the current weather into Obsidian. It can show weather in the status bar, cycling between two configurable strings, insert the current weather into a document, and fill weather into new documents through template support. The README announces that the plugin is discontinued because the API version it is built on was retired, and that the author has written a replacement against a different weather service.
