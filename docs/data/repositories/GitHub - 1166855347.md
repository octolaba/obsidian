# MBlogs/mermaid-copy

Mermaid Copy adds a copy button beside the existing edit button on Mermaid diagrams rendered in Live Preview mode. A click copies the diagram as either a PNG image or SVG markup, selected in the settings, with PNG the default and a transparent background that preserves theme colours. The README records that the plugin was under review for the community plugin directory when it was written, and documents manual installation from the release files.
