# brainsforai/obsidian-brains-sync

Brains Sync moves pages between an Obsidian vault and a Brains wiki instance in both directions. Pull fetches all wiki pages through the Brains API into a configurable vault subfolder, defaulting to one named brains, and the README records that pull is remote-wins in V1, always overwriting the local copy; push scans that subfolder and syncs each Markdown file back, updating existing pages and creating new ones. Signing in is a one-click OAuth2 flow that returns the access token to Obsidian, with a personal access token as an advanced fallback for self-hosters, and the instance URL is configurable. Every operation is summarised in a notice and logged in more detail to the developer console.
