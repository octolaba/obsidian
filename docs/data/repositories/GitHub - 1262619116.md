# viggomeesters/obsidian-script-viewer

Script Viewer is a read-only Obsidian viewer for script files and a fixed list of dotfiles, opening shell, batch, PowerShell, AutoHotkey and related files as well as environment, ignore and tooling configuration files that it routes by name so they do not fall through to an external viewer. The README describes line-numbered source with a soft-wrap toggle, shebang and interpreter detection, an outline built from shell functions, labels, PowerShell functions, hotkeys, dotenv keys and ignore patterns, search over source lines, outline filtering, highlighting that flags risky command patterns, and a ten-thousand-line render cap. It states its own boundary plainly: the plugin never executes scripts, starts terminals, mutates files, reads the clipboard or makes network requests.
