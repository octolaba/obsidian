# zhoulianglen/obsidian-timestamp-player

Timestamp Player makes the timestamps written next to a transcript clickable, so that in reading view each one becomes a play button that seeks the embedded audio to that position, toggling between play and pause. Two patterns are recognised, a speaker name followed by a minute and second timestamp at the start of a line, and a bare timestamp anywhere inside the text. The current timestamp highlights and advances as playback continues. The README states that the plugin only activates on documents containing at least one embedded audio file, lists the supported audio formats, and explains that a document with several audio files is split into sections where each file controls only the timestamps below it until the next one, pausing the previous audio when sections change.
