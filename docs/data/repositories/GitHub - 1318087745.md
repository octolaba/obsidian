# freestylefly/wesight-obsidian

Runs locally installed agent command-line tools, Claude Code, Codex or OpenCode, as collaborators inside an Obsidian vault, through a sidebar chat with file mentions, slash commands and inline editing. It detects an existing executable from a configured or system path and starts it as a child process, installing nothing itself, so tool access and provider requests follow that tool's own configuration. Pasted images are copied into the vault and passed on as local attachments, and separate workflows publish to Feishu documents and to WeChat Official Account drafts. An opt-in Knowledge Brain workflow, gated behind a membership entitlement fetched from the vendor's API, installs a pinned checksum-verified runtime and edits the vault only after a previewed, confirmed plan.
