# bobstanton/places-environment

An add-on for the Places plugin that renders environmental data as charts, tables, cards and user templates: tide predictions from the nearest station, sunrise, sunset and twilight times for a coordinate, current, hourly and daily weather, and forecasts beyond the sixteen-day window. Requests go to the NOAA tides and currents service, a sunrise and sunset API and the Open-Meteo forecast and seasonal APIs, and responses are cached either in the note's frontmatter or in plugin data for a lifetime set per block. It runs no background tasks, draws its charts with Chart.js, adds a moon phase to the solar output, and renders generated tables through a markdown-table library.
