# choihunchul/lns_directories

An Obsidian plugin that links external files and folders into a vault as symbolic links, so paths outside the vault appear in the file explorer without the data being copied. Links are created from a folder's context menu, a sidebar icon or command-palette commands by choosing an external absolute path and a vault-relative link path, and the settings tab lists the registered links with a health status — working, source missing, link missing or broken — and allows removal. The README is bilingual Korean and English, records the plugin as desktop-only and requiring a local filesystem vault, recommends macOS or Linux because Windows symlink permissions vary, and notes that synced or iCloud folders may behave differently.
