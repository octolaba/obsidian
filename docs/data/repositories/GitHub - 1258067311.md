# younginshin115/obsidian-monthly-tracker

Monthly Tracker renders a month of colour-coded cells from daily note data inside a monthly note, driven by a `monthly-tracker` code block. The monthly note declares its year and month in frontmatter, and the plugin scans the configured daily notes folder — or one detected from the Daily Notes or Periodic Notes plugin — for files whose names begin with a date, reading a chosen frontmatter property from each. A boolean tracker highlights days where that property is truthy, or, when the property is omitted, days that simply have a file in the source folder, using a preset name or a hex colour; clicking a cell opens that day's note.
