# jdluque/next-link

Next Link is an Obsidian plugin that adds commands for moving between the links of a note, so navigation between them stays on the keyboard. The README recommends binding the next and previous link commands to shortcuts, suggests Ctrl+H and Ctrl+L, and notes that obsidian-vimrc-support can bind them to Vim normal-mode chords such as Tab and Shift-Tab. Binding Obsidian's own follow-link-under-cursor command alongside them completes keyboard-only navigation.
