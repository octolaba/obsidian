# FlorianWoelki/obsidian-symbols-prettifier

Symbols Prettifier replaces typed character combinations with the single symbols they stand for, so that a sequence such as a hyphen followed by a greater-than sign becomes an arrow rather than staying as two characters. The README's table of recorded substitutions covers single and double arrows, a bidirectional arrow, a greater-than-or-equal sign, and the plus-minus and minus-plus signs. Substitution happens as the combination is typed in the editor.
