# Clemens-E/obsidian-languagetool-plugin

The repository holds an Obsidian plugin that integrates LanguageTool for grammar and spell checking. Its README records that the plugin is in maintenance mode, with issues and suggestions welcome but no planned development beyond fixes, and that pull requests will be reviewed and released. For privacy it recommends self-hosting LanguageTool locally or on a server and pointing the plugin's configured address at that instance; the code is licensed under the GNU AGPL version 3.
