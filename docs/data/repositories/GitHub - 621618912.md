# ittuann/obsidian-gpt-liteinquirer-plugin

GPT-LiteInquirer integrates OpenAI's ChatGPT API into Obsidian so that ideas can be generated, content drafted or assistance requested without leaving the editor. The README presents it as a lightweight, fast and non-intrusive assistant, and offers the plugin in English and simplified Chinese. It also documents manual installation, in which `main.js`, `styles.css` and `manifest.json` are placed in the vault's `gpt-liteinquirer` plugin folder.
