# Real1tyy/BasesImprovements

Bases Improvements adds dynamic search filtering to Obsidian Bases, letting a base query be filtered as you type rather than only through the Bases controls. The README points to a separate documentation site for installation, quickstart, configuration, features, FAQ and troubleshooting, and to a short video tutorial. It states the plugin is still awaiting approval for the community plugin store and that BRAT is the recommended installation route in the meantime.
