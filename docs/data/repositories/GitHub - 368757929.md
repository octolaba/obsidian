# shaggyfeng/obsidian-Pink-topaz-theme

Pink Topaz is a pink theme for Obsidian intended as an environment for reading, thinking and writing. It began as a set of snippets layered on top of the Blue Topaz theme, and its colours were collected from photos and websites as inspiration. The change log records work on code block backgrounds in dark mode, mermaid chart colours, the thirteen core coding syntax colours and twenty further languages, graph and outline hover effects, and centring of images, tables and videos.
