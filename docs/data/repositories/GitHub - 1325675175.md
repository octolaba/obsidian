# GitHub-Xzhi/obsidian-suble-toc-plus

Adds a floating table of contents to Obsidian: a thin heading minimap along the edge of the note opens a popover listing the note's headings and its open tasks on separate tabs. Headings can be searched, folded branch by branch or expanded and collapsed all at once, and the panel can be pinned, hidden when focus leaves the note, or stripped of its toolbar and tab bar. Panel height, background opacity and heading text opacity are configurable, each heading can carry a level badge with its own colour, and every setting has its own reset button. The interface is available in English and Chinese, and Markdown escape backslashes are hidden from heading text.
