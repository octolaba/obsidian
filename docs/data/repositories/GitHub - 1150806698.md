# pan4ratte/obsidian-tags-color-files

Tags Color Files highlights notes in Obsidian's file explorer according to the tags they contain, using rules that pair a tag with a color in the plugin settings. Rules can be scoped to a single folder, given a priority so that one color wins when a file carries several matching tags, or inverted so that files without the tag are the ones highlighted. Besides coloring the file name's text or background, the plugin can draw up to three colored dots before or after the name at a chosen size. The README records import and export of the settings and localization in English and Russian.
