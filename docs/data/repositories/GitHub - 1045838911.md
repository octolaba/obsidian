# GeorgRasumov/Obsidian-Latex-Equation-References

Obsidian plugin that numbers LaTeX equations automatically and resolves references to them. An equation carrying a label comment is assigned a sequential number and a matching tag is inserted or kept up to date, and in Live Preview a reference is displayed as a configurable prefix followed by that number, falling back to the raw text while the cursor is inside it. The prefix word, for example Equation or Eq., is set in the plugin's settings.
