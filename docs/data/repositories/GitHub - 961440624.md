# tristone13th/obsidian-title-only-tab

This plugin sets a tab's displayed name from the title attribute in a note's YAML frontmatter, which the README frames as being for Jekyll users. Before-and-after screenshots show the change, and the author credits an earlier short-tab-name plugin that this one builds on.
