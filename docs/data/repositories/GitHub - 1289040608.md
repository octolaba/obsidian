# Naggischnulu/obsidian-folder-limit

Folder Limit restricts how many files are visible per folder in Obsidian's file explorer, hiding the rest until they are asked for, which the README aims at folders holding hundreds of daily notes, attachments or Zettelkasten files. The limit is global and set in the plugin settings, defaulting to five files, and changing it updates the file tree immediately. A folder's right-click menu switches between showing all files and showing fewer again. The README states the plugin integrates with Obsidian's virtual list rendering so scrollbars stay accurate, and that it works without DOM mutation observers.
