# pronicx/obsidian-solidtime-integration

The SolidTime integration connects Obsidian to a SolidTime account through an API token and controls time tracking without leaving the vault. A sidebar view shows the running timer's description, its project with a color indicator and the elapsed duration, with icons for billable status and applied tags, and allows editing the description, changing the project through a suggestion modal, toggling billable status and selecting or creating tags. Commands start a timer through a modal for project, optional task, description, tags and billable status, stop the current timer, open the tracker view, show timer details in a notice and refresh projects, tasks, tags and user information, while a status bar item shows the current duration alongside configurable project or description text.
