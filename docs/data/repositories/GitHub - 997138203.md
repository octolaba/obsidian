# rootiest/obsidian-ai-image-ocr

This plugin extracts text from images in Obsidian by sending them to an AI image-recognition model, which the README argues handles text and handwriting far better than traditional tools such as Tesseract. Several models are documented with their access requirements and costs: OpenAI's GPT-4o, GPT-4o Mini and GPT-4.1 need an OpenAI API key, while Google's Gemini Flash family is recommended for a free tier whose daily request limits the README records. Detailed documentation is kept in the repository wiki rather than in the README itself.
