# name/obsidian-rpg

Obsidian RPG is a stat tracker that turns note-taking into a game: it counts the time the vault is open and awards experience points for it, adds further points for the number of notes in the vault, and tracks the total against a level system. Settings control the experience gained per second and per file and can reset the experience and level without touching notes. The README describes the plugin as a work in progress, installed by cloning the repository into the vault's plugins folder, and states an intention to add an upgradeable pet unlocked by levelling.
