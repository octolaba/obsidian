# mofukuru/SideNote

SideNote is an Obsidian plugin for annotating notes: a comment can be attached to selected text or to a whole note, and comments are shown in a dedicated side pane or in a split pane beside the note. The README states that commented text is highlighted in the editor with a configurable style, that comments follow their text through edits by hash-based matching, and that clicking a comment jumps to its place in the editor while clicking a highlight opens the matching comment. It also lists inline editing in the sidebar, a search filter over highlighted text and comment bodies, quoting the current selection into a comment, collapsible comments and clickable internal links inside comment text.
