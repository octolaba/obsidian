# MarkMindCkm/obsidian-markmind

The repository holds Obsidian MarkMind, a mind map and outliner for desktop and mobile that also annotates PDFs. Its README states plainly that the project is not open source, while granting an Obsidian developer permission to inspect the code, and it lays out a free tier covering the basic mind map mode, most of the rich mode and list mode against a paid tier adding the remaining rich-mode features, PDF annotation and export of a mind map as PDF. A thirty-day trial is recorded before a purchase code is required, and the repository declares no license.
