# scottTomaszewski/obsidian-folder-bases

Folder Bases opens the Base file associated with a folder when the folder is clicked in the file explorer, doing for .base files what the Folder Notes plugin does for notes. The base filename is configurable with folder name and folder path tokens and defaults to a same-named .base inside the folder, a plain or modifier click can be chosen as the trigger, and a modifier click can create the base from a template when none exists. Which folders respond is scoped by include and exclude glob filters with optional subfolder matching, the collapse chevron always keeps its normal expand and collapse behaviour, and a right-click menu offers opening and creating the folder base. A known limitation is that clicks in a file explorer moved into a popout window are not intercepted.
