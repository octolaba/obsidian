# k-quels/japanese-novel-ruby

The recorded description says this is an Obsidian plugin for handling Japanese novel ruby. Per the README it displays and inserts ruby, or furigana, in the syntax used by Japanese novel sites such as Aozora Bunko and Shousetsuka ni Narou, so a document can be edited while its ruby is previewed; preview in source mode can be toggled, ruby can be limited to notes carrying an enable_ruby property, and the delimiter marks can be changed for non-novel use. Commands insert ruby through a dialog or directly, add emphasis dots, remove ruby from a selection, and toggle the hide-unless-hover and source-mode preview settings, with the interface available in English, Japanese and Chinese. The README records that a half-width pipe as the ruby delimiter breaks display inside tables, that the full-width pipe should be used there, and that Markdown-style ruby is not supported.
