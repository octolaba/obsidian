# frogtempest/select-folder

Select Folder makes a click on a folder's name select that folder in the file explorer, with the native selection highlight, while the disclosure triangle or a double-click still expands and collapses it. Drag-and-drop, the right-click menu and multi-select with Shift, Cmd, Ctrl or Option are described as unchanged from stock Obsidian, and a settings option switches to a mode where one click both selects and toggles. With a folder selected, the Create new note command places the note inside it instead of the default location, which can be turned off in settings. The README records Obsidian 1.4.0 or later, on desktop and mobile.
