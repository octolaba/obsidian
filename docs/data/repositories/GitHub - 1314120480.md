# comedianhhh/obsidian-smart-cluster-graph

A folder-based graph view that groups vault notes into community clusters drawn with soft convex hulls, showing the strongest cross-cluster bridge links and curving those links around intervening hulls to reduce crossings. A search box filters and highlights matching nodes in real time, and the view tracks whichever note is currently open. Clicking a node selects it, double-clicking opens the note, and a right-click menu offers opening the note, opening it in a new tab and copying a link; the canvas pans by dragging and zooms with the scroll wheel.
