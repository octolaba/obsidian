# barisdincer/VaultPrune

VaultPrune finds attachments that are no longer referenced anywhere inside an Obsidian vault. The README records that the project began as a Python prototype and is being reshaped into a native plugin, because a plugin works directly against the currently opened vault, spares the user from typing a vault path, keeps review and cleanup inside Obsidian, can respect Obsidian's trash behaviour when deleting, and allows a desktop-focused first release. The behaviour it describes as planned is a scan for likely attachment files, detection of references from Markdown notes and from Canvas files including text-card links and group backgrounds, preference for Obsidian's configured attachment folder with manual folders allowed, and a review modal offering search, extension filters, sorting, bulk selection and previews for visual media.
