# sergeybychkovvvpgroup-beep/typing-interface-hider

Typing Interface Hider hides selected parts of the Obsidian interface while you type, and optionally while you scroll, restoring them when typing stops or the mouse moves. The elements it can hide are the sidebars, the left ribbon, tab headers, the note header, the status bar, the window title bar and the scrollbars, and settings control the fade duration, the automatic restore after an idle delay, the idle delay itself, the distance the mouse must move before the interface returns, a mouse-only mode that disables the idle timer, restriction to Markdown notes so search and dialogs are unaffected, and whether navigation keys also hide the interface. When hiding was triggered by scrolling, the README states that the interface stays hidden until deliberate mouse movement, a click, a window blur or an explicit command. Two commands show and hide the interface immediately.
