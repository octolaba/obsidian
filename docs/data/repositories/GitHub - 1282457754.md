# crufi/obsidian-hotlines

Hotlines highlights whole lines of an Obsidian note that match a keyword or a regular expression, so plain-text markers such as TODO, PROBLEM or IMPORTANT stand out without callouts or added Markdown syntax. Each rule carries its own background colour, text colour, bold and italic flags and a free custom CSS field, the first matching rule wins so rule order sets precedence, and the highlight spans the whole row while bullets, list indentation and dashes keep rendering on top; it works in Reading mode and Live Preview on desktop and mobile, including inside callouts, soft-wrapped paragraphs, list items and plain code blocks. The README names the aDHL plugin as a richer alternative and positions Hotlines as simpler but able to style with arbitrary CSS. This note is grounded in the README alone, as the repository records no description.
