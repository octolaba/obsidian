# deadhedd/dynamic-notes

Moves blocks of Markdown through three regions of a note, Later, Now and Done, so that one Advance command completes the current block and promotes the next. A note opts in through frontmatter and delimits its regions and blocks with comment markers, each block carrying a unique lowercase identifier; the structure is validated before any change, and a separate validate command reports mismatched markers, duplicate identifiers, nested blocks or stray content without touching the file. Advance runs from the command palette or the ribbon in both Reading and Edit view, with edit-view changes applied as a single undoable editor update. The plugin keeps no state outside the note, adds no scheduling, recurrence or settings, makes no network requests, and avoids Node and Electron APIs so it can run on mobile.
