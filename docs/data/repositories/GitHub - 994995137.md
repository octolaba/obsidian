# Lapis0x0/obsidian-yolo

YOLO is an agent-native Obsidian assistant combining chat, writing, vault knowledge, and orchestration in one interface. Its agent runtime supports tools, MCP, Skills, desktop shell commands, subagents, web search, and multi-window work, while Learning Mode adds structured study projects, flashcards, knowledge maps, FSRS review, and Anki package import.
