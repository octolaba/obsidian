# Phoelectrix/liefwork-obsidian

Liefwork for Obsidian is described as rendering a vault's folders as living, chronological corals. The README defines its terms: a coral is the vault's files and folders drawn as one structure, a branch is a folder, a lief is a note or file drawn as a node along its branch, and a meristem is a branch's growing tip that organises and summarises it and may carry its own folder note. The view updates live, so creating a folder in the file explorer grows a matching branch, and the README presents the layout as a spatial way to survey a project folder and then zoom into a branch or note. It also describes a memory system layered on the same structure, where folders are seeded with rules for AI agents, prompts and responses are logged as notes, and summaries are rolled up to branch tips.
