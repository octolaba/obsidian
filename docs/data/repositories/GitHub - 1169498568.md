# Woukie/tag-my-notes-ai

Tag My Notes AI applies a user-defined tag list to notes through an AI model, letting the operator choose which notes to process, whether the active note, a folder or the whole vault, and which tags to consider. A panel shows progress as each tag is evaluated for each note, and operations survive closing and reopening Obsidian, so they can be viewed, cancelled or deleted later. Tags are described in the settings alongside the model, its parameters and a configurable chain of reasoning steps. The README records support for the Vercel Gateway, OpenAI, Ollama, OpenRouter and Mistral with custom endpoints, and warns that adding reasoning steps raises token cost and processing time.
