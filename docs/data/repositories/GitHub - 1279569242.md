# MHElnour/daytasks

Repository for DayTasks, a day-first task manager for Obsidian daily notes. Task cards are rendered inside the daily note while the canonical task data stays in local plugin storage, so the README states that no managed tasks section is written into the note body. It also documents a dashboard with completion streak, activity heatmap and Today, Due soon and Overdue lists, a cross-day Task List view, subtasks kept as real records, dependencies with blocked status, and optional detail notes carrying managed frontmatter.
