# kintolayli/simplest-todo

Simplest Todo manages tasks in a single Markdown file with named sections and archives completed ones automatically. A checked task is moved to the archive section with a hidden completion date when the file is saved; at month end the archived tasks are exported into a separate file named for that month and filed by their actual completion date, and unchecking a task in the archive returns it to its original section. Archiving and the monthly rollover also run from a ribbon button or the command palette, a migration command reorganises an existing mixed archive into proper monthly files, and the interface is available in Russian and English.
