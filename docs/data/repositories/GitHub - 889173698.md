# felipetappata/obsidian-link-preview

Link Preview is described as an Obsidian plugin that previews external links on hover. Its README says hovering an external link in a note shows a preview of the page without leaving Obsidian, in an interface meant to match the current theme. Settings control the delay before the preview appears and the maximum height and width of the preview window.
