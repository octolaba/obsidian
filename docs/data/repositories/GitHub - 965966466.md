# artemDvoryadkin/obsidian-vim-marker-sharpener

Vim Marker Sharpener adds text formatting commands to Obsidian that behave correctly while text is selected in Vim's visual and visual line modes, which the README gives as its reason for existing alongside the many plugins that format text. It provides commands for bold, highlight, italic, strikethrough, code and comments, combining several styles, removing formatting from a selected block, and formatting a word in normal mode. Vim users are expected to bind these commands through a vimrc file, for which the README points to the separate Vimrc Support plugin, while other users can bind them to hotkeys instead. A planned-features list records proper support for non-Vim selection, a clear-format command, jumping to the next formatting, and formatting part or all of a sentence as not yet implemented.
