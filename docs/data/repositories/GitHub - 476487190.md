# artisticat1/obsidian-latex-suite

The repository holds Obsidian Latex Suite, a plugin whose stated aim is to make typesetting LaTeX mathematics as quick as handwriting. Its README presents snippets as the main feature, expanding short sequences into mathematical markup — a few characters becoming a square root, a slash becoming a fraction, a word becoming a partial derivative — and records a default snippet set that can be modified, removed or replaced with the reader's own. It credits an earlier UltiSnips-based setup as its inspiration and documents a display math trigger from which the examples follow.
