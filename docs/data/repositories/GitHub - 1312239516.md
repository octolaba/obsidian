# vryTfmcat/four-layer-todo

Four Layer Todo organizes work in four layers: a whiteboard for the one to three tasks in focus, a workbench with an inbox, to-do list and cache list, expandable kanban-style task pools, and long-term objects with their related tasks. Cards can be connected, annotated, moved between layers, completed, archived or deleted, and a board can be imported from or exported to Obsidian's Canvas format. Optional Markdown synchronization stores each task as a file named for its title, with card id, location, priority and whiteboard position in frontmatter, so renaming, moving or deleting a managed note updates the board. It works without a network connection, its AI buttons are interface placeholders, and its English and Chinese interfaces follow Obsidian's language by default.
