# ALONELUR/vim-im-select-obsidian

This plugin automatically switches the system input method while Obsidian's Vim key bindings are in use, so that a non-English input method does not cause keys to stop working in Vim normal mode. It requires Vim key bindings to be turned on in Obsidian, and can be installed from the community browser or manually by copying the build output into the plugin folder in the vault. The settings tab is split into two parts, one for the default platform and one for Windows: on Windows the second set is used and otherwise the first, with options in each naming the input method to switch to for normal mode.
