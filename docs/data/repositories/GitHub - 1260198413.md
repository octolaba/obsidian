# pengGgxp/webdav_sync

Backs an Obsidian vault up to a user-configured WebDAV server as whole-vault zip snapshots, and restores from them. The README states that the design is deliberately simple: no incremental synchronization, no file-level conflict resolution, no automatic merging and no automatic direction, the user choosing to upload, download, restore or do nothing. Before restoring anything the plugin packages the current vault and uploads it as a safety backup, and local files are deleted only after that backup succeeds and the selected remote archive has been downloaded and parsed. Settings hold the server URL, credentials, remote root, device name and a generated device id; large archives are split to avoid upload size limits, and Git data, trash, workspace layout files, the plugin's own directory and files matched by size or extension are ignored.
