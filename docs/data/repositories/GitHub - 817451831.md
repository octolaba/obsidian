# GnRlLeclerc/Vanilla-Theme-Palettes

This repository is a color palette switcher for Obsidian rather than a full theme: it supplies popular palettes without changing the vanilla interface. The README lists Atom One Dark, Catppuccin, Dracula, Gruvbox, Horizon, Kanagawa, Nord, Rose Pine and Tokyo Night, and states that the Style Settings plugin is required in order to switch between them. Sources are written in SCSS and compiled with sass, each theme implementing its own palette plus the generic colors a shared commons file requires.
