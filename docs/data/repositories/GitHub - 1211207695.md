# sparkwild/obsidian-tracekeeper

Tracekeeper builds a local-first AI-assisted wiki and memory system inside Obsidian. A loopback-only MCP Runtime recalls scoped vault context, routes proposed wiki changes through review and confirmation, and stores governed memory as ordinary Markdown files without a hosted backend or external database.
