# solargate/obsidian-inline-encrypter

The recorded description names this the Inline Encrypter plugin for Obsidian. Per the README it encrypts text inline, either a whole note or parts of it such as the contents of lists and tables, saving the encrypted value in the note as a code block that appears as a clickable button in reading mode and in Live Preview; its commands encrypt a selection, encrypt into a common code block, insert pre-encrypted text, and decrypt a selected or cursor-containing block. Clicking the button and entering the password shows a secret without decrypting it in the note text, and holding Ctrl suppresses that display. The README warns that passwords are never stored anywhere, that a forgotten password makes decryption impossible, and that the plugin is used at the reader's own risk, and it names the Obsidian Encrypt plugin as its inspiration.
