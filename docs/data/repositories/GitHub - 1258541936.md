# jmerryman-eng/Eisenhower-Obsidian-PlugIn

TaskMatrix scans every Markdown file in the vault for checkbox lines carrying a task tag and lays them out in a two-by-two Eisenhower grid, with quadrants named Do, Schedule, Delegate and Delete plus a backlog for untagged ones. The README stresses that Markdown is the only interface: a task's quadrant is a tag on its line, its status is the checkbox character, and an optional block identifier is its stable identity. Dragging a card between quadrants rewrites the quadrant tag in the source file, clicking a card's checkbox cycles its status, and the toolbar filters by status or text and can re-index the vault. The README states that writes are atomic and conflict-checked, so an action aborts and rescans rather than overwriting a file that changed underneath it.
