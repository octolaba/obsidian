# notesynchelper/shoujidiannao

Shouji Diannao synchronises notes between a phone and a computer, and its recorded description and README present it as convenient, fast and secure. The README states that a new device is paired once with a dynamic code generated on an already-paired device, after which syncing runs automatically and changes propagate in real time, and that the service uses several data centres inside mainland China so domestic access needs no VPN. Its security claim, recorded here as the project's own, is that notes are protected by elliptic-curve key exchange and AES encryption with keys that never leave the devices, so the server cannot read note content. The README requires Obsidian 1.4.0 or higher and documents manual installation from the release files.
