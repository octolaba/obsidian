# Hanser0521/Wave-TOC

Wave TOC turns the active note's outline into a floating navigation rail of ticks for headings beside the document, so headings can be previewed and jumped to without spending sidebar space. Hovering produces a multi-tick wave animation and a heading bubble while scrolling changes only the active colour, and optional hover cards show the title alone, the first paragraph, or a locally extracted section summary. Side, heading depth, rail height, navigation on pointer or on click, and section tracking by scrolling viewport or by cursor are configurable, the rail updates when headings change, and the settings interface is offered in Chinese and English. The README states that Wave TOC works locally inside Obsidian.
