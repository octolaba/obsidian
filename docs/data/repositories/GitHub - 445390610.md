# nickmilo/LYT-Mode

LYT Mode is a theme whose description and README explain the name as Linking Your Thinking and state that it is meant to encourage sensemaking and lateral thinking. The README argues that visually distinct formatting gives the reader more to latch onto, and instructs that the theme be used in dark mode. Listed features include a palette evolved from Cybertron, the DM Sans and DM Mono fonts, mobile and desktop support, all Obsidian views from legacy to live preview and reading, custom icons, minimal animation, its own syntax highlighting and a tighter sidebar line height.
