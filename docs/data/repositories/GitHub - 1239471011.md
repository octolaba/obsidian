# mateosantosdev/chancli-font-size-resizer

This repository holds Chancli Font Size Resizer, an Obsidian plugin that changes the note editor font size from the status bar. Minus and plus buttons sit beside a size indicator, and commands increase, decrease and reset the size; headers scale proportionally while body text scales on its own. The settings tab exposes step size, minimum and maximum bounds and a live slider, defaulting to 16 px with a 1 px step between bounds of 10 and 32 px. The README states that it works in Live Preview, Reading View and Source Mode and that the size persists across restarts.
