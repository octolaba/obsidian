# mo-seph/obsidian-copy-as-latex

Copy as Latex copies selected Obsidian Markdown to the clipboard as LaTeX, aimed at writing in Obsidian and pasting into a LaTeX document without assuming a whole document or a full converter such as Pandoc. Parsing goes through mdast-util-from-markdown and mdast-util-gfm, and headings, bold, italic, external links, nested lists and code blocks carrying their language into the listings package are mapped, along with LaTeX special characters. Internal links starting with @ become citations, links starting with ^ become cross-references and block ids become labels; the README marks footnotes, highlights and images as not done and bibliography support as experimental.
