# twrusstw/mockup-viewer

Mockup Viewer renders an HTML file kept in the vault inside an isolated iframe with Obsidian's own stylesheet, the active theme and a plugin's CSS injected, so a plugin author can iterate on interface designs without the build and reload loop. The iframe boundary keeps host classes such as the phone and keyboard-open markers from leaking onto Obsidian's own chrome, edits hot-reload after a short debounce, and a theme switch re-renders the preview. The README states the trust model directly: the viewer executes whatever a mockup contains, so only trusted mockups should be opened. It also records the plugin as desktop-only and not yet listed in the community plugin directory.
