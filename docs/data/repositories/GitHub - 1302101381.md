# haivri/obsidian-yaml-properties

YAML Properties replaces Obsidian's in-note Properties editor with an editable, syntax-highlighted YAML frontmatter block in Live Preview, while keeping a read-only view in Reading mode and normal Source mode. It can collapse the block, remember state per note, hide it in Reading view, style Source mode, wrap or compact YAML, and save edits after a pause, blur, or keyboard confirmation; notes stay plain Markdown.
