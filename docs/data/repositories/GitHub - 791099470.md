# manimohans/obsidian-local-llm-helper

Local LLM Helper processes text, chats and searches notes semantically inside Obsidian against any OpenAI-compatible LLM server, naming Ollama, LM Studio and vLLM. Beyond chat, the README describes Vault Radar, which turns recently changed notes into a small cited brief meant to surface a commitment about to slip, a project blocked by an unresolved decision, a connection appearing only across two notes, or a supported next action. It also records note-grounded chat, semantic discovery, approval-gated workflows and a section on what leaves the vault; the README's register is promotional, and this body restates only the capabilities it names.
