# JuracyAmerico/obsidian-teleprompter-plus

Teleprompter Plus renders an Obsidian note as a teleprompter script that scrolls automatically at a variable speed, with a countdown timer, manual scrolling and horizontal or vertical flipping for camera-rig mirrors. Instead of a fixed rate the prompter can follow the reader's voice, using on-device speech recognition to scroll and highlight the current position. Navigation is hierarchical: a collapsible header tree, a minimap scrollbar, click-to-jump and highlighting of the active section. The README also records playback control from the keyboard, from an Elgato Stream Deck through a catalog of actions with bidirectional state sync, and from a phone over a local network web interface, plus optional reading aloud with neural text-to-speech voices.
