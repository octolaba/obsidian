# donmccurdy/obsidian-field-recorder

Field Recorder is an audio recorder for Obsidian with quality settings and waveform visualization. It lets an input device be chosen, displays the incoming signal and clipping, monitors the input, pauses and resumes a recording, and reports file size and duration. Settings choose the output format between M4A, WebM Opus and PCM, the bitrate from 32 to 320 kbps, and gain control, noise suppression and voice isolation, which the README marks as unavailable on iOS.
