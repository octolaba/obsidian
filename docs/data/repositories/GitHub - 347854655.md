# pjeby/pane-relief

Pane Relief adds per-tab navigation history that is kept across restarts for every tab in every window and saved with stored workspaces, together with commands for moving between tabs and windows and for rearranging tabs. It also provides a tab-maximizing command, a focus lock that stops sidebar panes from stealing focus, a browser-style close command that activates an adjacent tab instead of the most recently used one, and a sliding-panes mode that toggles per window and works with stacked tabs. The README states that the goal is a more browser-like experience for people who use many tabs, panes and windows, and warns that the plugin adds many preconfigured hotkeys.
