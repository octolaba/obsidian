# oliviergoulet5/obsidian-gitlab-plugin

Embeds GitLab resources such as issues, merge requests and projects into notes: a supported GitLab URL pasted into a note renders as an embed once the note is switched to preview mode. The README states plainly that the plugin makes network requests to the configured GitLab instances, whether gitlab.com or self-hosted servers, in order to fetch and display those embeds.
