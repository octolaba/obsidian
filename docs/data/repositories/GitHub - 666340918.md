# vzsky/apl-obsidian

This plugin renders APL source inside Obsidian code blocks whose language is set to apl. Text written in tick notation, where a tick follows a character, becomes the corresponding APL Unicode glyphs using the RIDE convention; boxes are not generated and must be drawn or copied from RIDE. The README notes that the APL385 font has to be installed separately for the result to look right, and credits an espanso keyboard mapping for the tick-to-Unicode table.
