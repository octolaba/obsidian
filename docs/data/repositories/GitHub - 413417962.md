# timhor/obsidian-sentence-navigator

Sentence Navigator treats a sentence as a unit of movement, adding commands to select, move and delete by whole sentences. The listed commands cover deleting to the start or end of a sentence, moving to the start of the current or next sentence, and selecting the current sentence or part of it, with only the two delete commands bound by default. The README records that active development was paused because of the author's personal circumstances.
