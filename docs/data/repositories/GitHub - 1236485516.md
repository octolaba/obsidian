# semsevens/obsidian-archive-redirect

Downloads the remote images, video and audio referenced by a note into a local cache and swaps the rendered element's source to that copy, in Reading mode and Live Preview alike. The Markdown is never rewritten, so the original URL stays in the file and still works as a fallback if the plugin is removed. Files are stored under a hash of their URL, either in an archive folder beside each note or in one shared vault folder split into hash buckets for vault-wide deduplication. Downloading happens when a file is modified or when a scan command is run, never at render time, and built-in per-domain rules decide which hosts are archived and which are skipped.
