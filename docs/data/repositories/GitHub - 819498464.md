# nickrallison/obsidian-note-linker-with-previewer

Note Linker is an Obsidian plugin that finds places where one note's text mentions another note and turns them into links. It carries its own Markdown parser so it does not link inside code blocks, LaTeX blocks or other special constructs, and it caches discovered links because searching is the most intensive part of its work, making a second run much faster. Its commands scan the vault without writing files, link the whole vault subject to an include filter, link only the current note while bypassing that filter, list invalid notes that errored and are no longer scanned, and hard reset the cache when linking behaves oddly.
