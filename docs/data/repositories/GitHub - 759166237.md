# jsrozner/obsidian-tab-shifter

Tab Shifter navigates and rearranges Obsidian's tabs the way code editors do. It moves the current tab into the previous or the next tab group, which the README compares to the tab-shifter plugin for WebStorm, and since its second version it also binds keys for moving between open tabs — differing from Obsidian's own next-tab command in that it crosses tab group boundaries. The README records that the plugin uses no official API but reads properties of the leaf and tab-group objects that seem always to be present, so it will break if they go away, that it assumes the order of leaves matches the order of tab groups and may behave oddly with many splits, and that it is marked desktop-only because the author does not know whether the logic works on mobile.
