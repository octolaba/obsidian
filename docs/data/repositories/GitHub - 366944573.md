# tokuhirom/obsidian-pomodoro-plugin

The repository holds a Pomodoro timer plugin for Obsidian that places a timer in the Obsidian window. Its README quotes the description of the Pomodoro technique as a time management method that breaks work into intervals, traditionally twenty-five minutes long, separated by short breaks. The interval duration is changed from the settings form, and the README credits the request that led the author to add the technique to an earlier stopwatch plugin.
