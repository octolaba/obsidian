# k4fn/keep-bases-view

Keep Bases View is a custom Bases view that renders a base file's results as Google Keep-style cards. Notes carrying keep_pinned in frontmatter appear in a separate pinned section, keep_color sets a card's colour, a configured property supplies a cover image, and cards can show body previews with frontmatter removed, frontmatter and inline tags, and previews of embedded base files. View options set the title and cover-image properties, image fit, card widths for desktop, tablet and mobile, preview heights and whether tags and pinning are shown. Clicking a card opens it in a Keep-like popup editor or, with a modifier key, in a normal tab; a context menu opens, pins, recolours or deletes it, and the previous scroll position is restored afterwards.
