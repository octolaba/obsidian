# Showwaiyan/obsidian-scan-sketch

Turns a photo of a handwritten page into a cleaned-up image saved in the vault. A scanner modal takes a file or a camera capture, detects the page corners automatically or lets them be dragged with a magnifying loupe, applies a perspective transform and rotates in ninety-degree steps. Background removal samples a colour by click and uses a tolerance slider to produce real transparency, and brightness, contrast, saturation and black-and-white filters preview as they are adjusted. The result is exported as PNG, JPG or an SVG wrapper into a chosen vault folder with a timestamped or custom filename, and an embed link can be inserted into the active note at the cursor.
