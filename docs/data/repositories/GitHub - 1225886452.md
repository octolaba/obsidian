# Akudlay-ru/structure-commander

Structure Commander treats a Markdown note as a tree that can be worked on rather than only displayed. Its README lists moving a branch up or down together with its nested headings and text, moving selected lines without losing the selection, promoting and demoting a branch while keeping its internal hierarchy, folding and unfolding, showing the document down to a chosen heading level or expanding it in full, renumbering headings and lists, removing numbering or replacing it with emoji digits, repairing skipped levels such as a jump from H1 to H3, and exporting a branch to a separate Markdown note. It also records a structure side panel, a compact toolbar above the editor with the current hotkeys shown in tooltips and assignable from the settings, and vault file operations — reveal in the file manager, copy path, copy file — with a dry-run mode and undo and redo for them.
