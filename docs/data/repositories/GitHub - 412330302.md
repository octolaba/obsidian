# TfTHacker/obsidian42-brat

BRAT, the Beta Reviewers Auto-update Tester, is aimed at developers and beta testers of Obsidian plugins and themes. A GitHub repository path is added to a list of things under test, after which the plugin checks for updates, downloads them and reloads the plugin, instead of the tester creating folders and copying files by hand.
