# hiroshi-watanabe/fretboard-renderer

Fretboard Renderer draws guitar fretboard diagrams as SVG from a YAML description inside a fenced code block, where each note gives a string number and a fret, with open and muted strings expressed in the fret value. Marking one note as the root makes the plugin label intervals relative to it, highlight every note sharing that pitch across octaves, and generate a title naming the chord, in a choice of standard, Berklee or jazz symbols. A diagram is fixed when a starting fret or open string is given and movable otherwise, with the position inferred and the title left generic; a naming mode switch titles it by best-fitting scale instead, marking notes outside that scale as passing tones. Boxes, paths and a multi-diagram block draw scale positions, runs through them, and several charts side by side.
