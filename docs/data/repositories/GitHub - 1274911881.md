# IceKhan13/obsidian-source-observer

Repository for Source Observer, a plugin that browses a codebase on disk from inside Obsidian. Its README describes opening any folder into a file tree with file-type icons, reading files with syntax highlighting that follows the active theme, and a changes panel listing files modified, added or deleted relative to the current git revision, where clicking a file shows its diff or full contents. The two panels collapse independently and each has its own search filter.
