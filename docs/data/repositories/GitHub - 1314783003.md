# jepicaju862-lab/blockspace

Blockspace Workspace adds a block editor to Obsidian in which a page body is stored as a structured JSON block tree in the vault rather than as Markdown text, so nesting, columns, tables, media and rich-text ranges are data rather than formatting conventions. Lists, to-dos, quotes, callouts and toggles are real containers whose hierarchy changes with Tab and Shift+Tab, dragging a block moves its whole sub-tree, and each structural operation is one undo transaction. A column block offers two or three columns with fixed ratio presets and stacks them on narrow screens, alongside editable tables, media and bookmark blocks and an auto-updating table of contents. Pages export to Markdown with a sidecar JSON file, to Word and to PDF, while a generated read-only Bridge keeps them visible to Obsidian's graph, backlinks and search.
