# LiveAQuietLife/obsidian-index-cards

Index Cards is a desktop-only capture workspace where ideas, reading notes, and sources are organized into projects, categories, and cards before export to the vault. Its optional Academic Mode adds citation fields, bibliography parsing, and one-click bibliography generation, while search, previews, comparison, and card movement support research workflows.
