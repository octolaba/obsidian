# Sparky4567/obsidian_ai_plugin

This plugin connects Obsidian to a local or self-hosted Ollama instance so local models can be used inside notes and from a sidebar chat panel. The chat panel streams output and carries status indicators, auto-scroll, a stop-generation button, message history and quick prompt chips, while editor commands ask the model about the selected text, summarize it, continue or turn it into a story, fix grammar, or explain it. The README states that the plugin uses native fetch and standard Obsidian storage APIs with no node file-system dependency, so it runs on desktop and mobile.
