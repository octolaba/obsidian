# Tristan0929/Kindle-Transformation

Kindle Transformation converts a Kindle HTML notes export into a Markdown note inside an Obsidian vault. The file is supplied by clicking or dragging it into a modal opened from a ribbon icon or the command palette, and the result is written to a configured folder that the plugin creates when it is missing. Each Kindle highlight colour, covering yellow, aqua, pink, orange, blue and green, is mapped to an Obsidian callout type of the user's choice, highlights are written as nested blockquotes separating the book's text from personal notes, and the output is organised by chapter with excess line breaks removed. The README credits an earlier Kindle HTML importer by l2xu as the work it builds on.
