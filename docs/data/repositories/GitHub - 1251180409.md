# kja140/incremental-reading

Incremental Reading Toolkit brings incremental reading and spaced repetition into Obsidian, working over Markdown notes, PDFs, clipboard content and images. The workflow has three materials: sources — long articles, books, videos or notes revisited in portions; extracts, which are focused passages linked back to their parent source; and Markdown flashcards under a dedicated tag. Sources and extracts are scheduled in a reading queue by a progress-aware A-Factor computed by this plugin, while flashcard scheduling and grading are delegated to the separate Spaced Repetition community plugin. The README marks the plugin as desktop-only, because its integrated reader uses Electron and Node APIs to open vault and external PDFs that are unavailable on mobile.
