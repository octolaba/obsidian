# kja140/incremental-reading

Incremental Reading Toolkit schedules long-form sources and extracts with a progress-aware A-Factor, then connects selected material to Markdown flashcards reviewed through the Spaced Repetition plugin. It supports PDFs, clipboard content, images, a mixed reading queue, linked knowledge-tree navigation, analytics, and an integrated desktop PDF reader.
