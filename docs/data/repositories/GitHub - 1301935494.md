# kubaxius/obsidian-editor-mode-button

Obsidian plugin that adds a ribbon indicator and a command for switching between editing and reading mode, applying the change to already-open files rather than only to newly opened ones. A custom CSS file whose path is set in the settings can style each mode separately through body classes the plugin adds for source and preview. The README explains that the plugin exists because the built-in default-editing-mode setting applies only to new notes, and that its own switch command avoids the delay of the built-in toggle.
