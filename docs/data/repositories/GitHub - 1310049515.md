# crashdhabal/obsidian-messenger-for-chat-view

Messenger for chat view adds a floating, draggable chatbox over the Obsidian editor that injects messages into the active note in the syntax of the Chat View plugin by adifyr, which it requires and builds on. A role is picked from a dropdown configured in settings, a message is typed and sent, and the plugin writes it into the chat code block with an automatically formatted timestamp. The README describes the interface as mobile-friendly and responsive to the Android virtual keyboard while noting it has not been tested on iPhone, and records that the chatbox can be toggled from the ribbon icon, the command palette or the status bar. It also warns that the cursor must be placed where the conversation should start after a reload.
