# duchangkim/organized-daily-notes

This plugin organised daily notes into a customisable folder structure. Its README now marks it as deprecated, because the author found that the core Daily Notes plugin already creates those folders through its date format string, so a format naming year, month and day produces the same structure. The migration guide asks users to disable and uninstall the plugin and to set the format in the core plugin instead.
