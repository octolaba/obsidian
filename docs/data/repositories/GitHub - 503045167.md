# tansongchen/obsidian-note-synchronizer

Obsidian plugin that synchronises Obsidian notes to Anki. It supports arbitrary Anki note types by importing them as Obsidian note templates, keeps a one-to-one correspondence between Anki notes and Obsidian notes, decks and folders, and tags and tags, and converts wikilinks into Markdown links. It works either in a Markdown mode that imports content without rendering it, which needs an Anki add-on to render it there, or in an HTML mode that imports the rendered HTML. Setup requires the core Templates plugin and a configured Anki Connect installation.
