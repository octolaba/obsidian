# dustinho/obsidian-copy-embed-code

The repository holds Copy Embed Code, an Obsidian plugin that adds a copy option for images to the right-click context menu, producing wikilink syntax for a vault image and Markdown image syntax for an external one. The README explains that Obsidian's editor-menu API depends on cursor position, which clicking an image does not always move, so the plugin listens for context-menu events in the capture phase and walks up the DOM from the click target to find the image element. It states that this makes the option work in Live Preview, Reading mode and inside transclusions at any nesting depth.
