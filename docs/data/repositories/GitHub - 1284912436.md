# leweii/chew-it

This repository holds Chew It, an Obsidian plugin that analyses the note being read with a language model and shows the result in a side panel without modifying the note. Analyses are called perspectives and are selected as checkboxes before running; three are built in and editable, covering an outline of hierarchy and main arguments, an explanation of difficult concepts, and a distilled summary, and each runs in parallel into its own result tab with an optional per-perspective system prompt. Results stream in as Markdown, are saved per note and restored when the note is reopened, and each tab can be regenerated or exported on its own as a Markdown note or a canvas. The README states that it works with Claude and any OpenAI-compatible endpoint, including local Ollama, with the user's own API key.
