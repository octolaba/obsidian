# sorinmircea/obsidian-forms-plugin

This repository holds Forms, whose README describes creating and publishing web forms from Obsidian and receiving the responses back into the vault. A vault folder is linked as the home directory of a form, the questions are edited through the project's web interface after linking an account, and submissions then appear as entries in that folder. The README records a payment plan under which one form is free and further forms cost a yearly or a one-time fee. No upstream repository description is recorded, so this body rests on the README alone.
