# laguna821/Obsidian_NotePack-CODEX

Obsidian plugin providing a bottom-up writing workbench that operates on `.codex` files kept separate from ordinary Markdown notes. AI personas annotate and categorise memos dropped onto a board, a synthesis step proposes connections between categories, and when thinking stalls an idea card draw returns five cards across rarity tiers to force unfamiliar angles. Cards are kept or discarded to derive further memos, and a card judged ready is promoted into a Markdown note in the vault. Version 3 adds multi-seed card packs drawn from several selected notes, an offline capture mode that defers the AI, batch annotation through a retry-aware queue with concurrency three, and OpenAI, Claude and Gemini support with the user's own API keys.
