# DahaWong/obsidian-footlinks

This repository holds Footlinks, described upstream as an Obsidian plugin that extracts URLs from the main text into the footer for a better reading and editing experience. The README says the extraction runs from a side-menu icon or a Footlinks command, and that the settings allow a separator between the main body and the footlinks and control whether the side-menu icon is shown. It records a known limitation that footlinks are not parsed inside block quotes, which the author attributes to the application rather than to the plugin.
