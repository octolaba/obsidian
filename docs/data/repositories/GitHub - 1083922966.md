# chi1180/Obsidian-Kanban

Obsidian Kanban View adds a kanban board for managing tasks as draggable cards in customizable columns. The README describes drag-and-drop for cards and columns with mouse or touch, small, medium and large card layouts, per-column colours, and automatic persistence of board layout and column order into the vault. Boards are opened from the Bases menu, cards are edited in place, and card metadata is synchronized with the note's Markdown frontmatter. The interface is built with TypeScript, React, the dnd-kit library and the Obsidian API.
