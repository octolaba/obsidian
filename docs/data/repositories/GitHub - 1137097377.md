# derek-larson14/obsidian-claude-anywhere

Obsidian plugin that exposes a Mac's Claude Code session to a phone or tablet. The README states that it edits files anywhere on the Mac rather than only in the vault, runs the user's own skills, gives full terminal access, and resumes conversations started on the desktop. Its stated requirements are a Mac with Claude Code installed, Tailscale on both devices under one account, and file sync between the Mac and the mobile device.
