# rizerphe/obsidian-companion

Companion adds AI autocomplete to Obsidian, suggesting completions for words, phrases and whole sentences from the context of the surrounding text through a copilot-like interface. The README names OpenAI's GPT-3 and GPT-3.5 including ChatGPT, and locally hosted Ollama models, among the supported backends, with support for further models planned. Suggestions appear as ghost text that can be accepted or ignored while typing, and the completion mechanism is built on the author's own fork of a CodeMirror inline-suggestion extension.
