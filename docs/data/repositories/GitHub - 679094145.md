# lyricat/obsidian-quail

This plugin publishes Obsidian notes to Quaily, described as a publishing service, as newsletters or blog posts; the recorded description marks this repository as a clone of the quail-ink repository for the same plugin. The README states that the commands are found by searching for Quaily in the command palette and cover publishing and unpublishing posts, delivering published posts to subscribers, generating a summary and tags by AI, and previewing on mobile devices or desktop browsers, with support for multiple languages and multiple channels. It records the AGPL-3.0 licence and points to the service's own documentation for the details.
