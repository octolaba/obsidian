# ivan-lednev/obsidian-task-archiver

Task Archiver moves completed tasks out of the notes they were written in, bringing some of org-mode's handling of finished work to Obsidian. Commands archive the tasks of the current file, and settings control the archive file path, placeholders in it, text replaced or appended before archiving, additional patterns for detecting completed tasks, and how heading and list hierarchies are reproduced.
