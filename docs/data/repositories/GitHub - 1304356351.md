# xRyul/gremlins

Gremlins flags invisible or unusual Unicode characters in Obsidian notes, together with mixed indentation, malformed list structure and spacing, inconsistent list-item punctuation and line endings, and optionally typographic punctuation such as curly quotation marks and dashes. An icon appears in the gutter beside every visible line containing a gremlin, and clicking it replaces every flagged character on that line; the plugin works in source mode and Live Preview. The README describes ten groups of rules with individual defaults — invisible or dangerous Unicode and mixed indentation enabled, list indentation disabled — and sets out how a mixed indent is rounded using Obsidian's current indent visual width.
