# moeyua/obsidian-heti

This plugin applies the Heti typography styling, published by sivan, inside Obsidian. Its README is written in Chinese and describes Heti as a typographic enhancement designed for displaying Chinese content, derived from common Chinese typesetting conventions and meant to give a reader a better reading experience. It states that the plugin brings that styling into Obsidian so Chinese typesetting there looks better, and links an upstream preview of the style.
