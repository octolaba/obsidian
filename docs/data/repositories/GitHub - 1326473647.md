# swayinfo/elton-ai

A voice and text assistant that searches the vault, answers from it, and creates, edits and files notes, driven from a panel with two interchangeable modes: a voice mode built around a dial showing whether it is listening or thinking, and a text mode with markdown replies and a list of the notes each answer was built from. The same engine, tools and permissions back both, and a conversation survives the switch between them. The plugin ships no API key of its own: the note fragments a question needs, plus the recording in voice mode, go to whichever provider is configured, which may be OpenRouter, OpenAI, a local Ollama or LM Studio model, or a paid service run by the plugin's author, and that model has to support tool calling. Questions can also arrive from a Telegram bot of the user's own.
