# mgussekloo/obsidian-completedtasks

Completed Tasks automatically moves checked checkboxes to the bottom of the list they belong to. Reordering runs on a configurable interval, only when the document has changed, keeps the cursor on the appropriate line, and can optionally also run whenever a tab or focus changes; a command sorts on demand. Only root-level tasks are reordered and subtasks move with their parent, the plugin works in reader mode, is compatible with the Tasks plugin without requiring it, and a note can opt out with the frontmatter property `completedTasks: false`. The README states that the plugin is not extensively tested.
