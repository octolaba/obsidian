# awaken233/open-in-cursor

Obsidian plugin that opens the current file in Cursor, VSCode or Kiro and jumps to the cursor position it held in the note. Each editor gets its own command palette entry, its own configurable executable command or path, and its own hotkey, with no default hotkey assigned so that existing user configurations are not disturbed. Settings cover notifications, a debug mode and per-IDE connection tests, and the README states the plugin works on Windows, macOS and Linux.
