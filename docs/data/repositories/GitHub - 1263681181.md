# viggomeesters/obsidian-word-viewer

Opens `.docx` files in a dedicated read-only inspection view, parsing the local OOXML zip package inside the plugin with no cloud conversion. The view shows document metadata, an outline of headings, paragraphs, lists, tables, comments, footnotes, endnotes, media references and package diagnostics, and filters across document text, headings, comments, notes, hyperlinks and media metadata. Warnings flag external relationships, embedded OLE or package content, macro-related content, tracked changes, large documents, encrypted files and malformed packages, and long render lists are capped so big documents stay responsive. The README lists as non-goals legacy and macro-enabled Word formats, any editing, saving, export or write-back, pixel-perfect rendering, execution of macros or embedded objects, and any network call or external viewer.
