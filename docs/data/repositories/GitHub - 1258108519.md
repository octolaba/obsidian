# Ar4l/obsidian-papers

An Obsidian plugin that searches for a research paper and creates a note from its metadata, querying the arXiv API and falling back to OpenAlex when arXiv rate-limits the address, which the README says is common on VPNs. The query is either a direct arXiv URL or a title, in which case matches are offered to choose from, and the resulting note records title, authors, publication year, URL and an alphaxiv.org conversation link, with the PDF optionally downloaded and embedded. The note template is editable in settings, and the README documents the placeholder added for the alphaxiv link and states that the plugin is not in the community catalog and must be built and installed from source. The repository is a fork.
