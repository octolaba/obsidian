# mnaoumov/obsidian-new-note-fixer

New Note Fixer is an Obsidian plugin that unifies where a note is created when a link to a non-existing note is clicked. The README records the behaviour it corrects: a plain link honours the Default location for new notes setting, a link carrying a folder path ignores that setting and creates the note under that path, and a link starting with a parent-directory segment creates a file outside the vault root without opening it, after which a second click reports a misleading Folder already exists error. The plugin makes all these cases respect the Default location for new notes setting. A demo vault with usage examples ships with every release and can be opened from a command.
