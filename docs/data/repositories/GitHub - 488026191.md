# grochowski/obsidian-folder-focus-mode

The repository holds Folder Focus Mode, an Obsidian plugin that narrows the file explorer to one folder with its files and subfolders and hides everything else. Its README records that focus is entered from the folder's context menu and left either by a global command, by an unfocus entry in that same menu, or by an optional icon at the top of the explorer. It notes that a folder note kept as an external file needs an option enabled so the linked folder is focused, and the author describes the plugin as a quick draft and invites collaboration.
