# TracingOrigins/obsidian-fast-copier-plugin

Places a copy button beside formatted text in a note, covering inline code, bold, italic, underline, strikethrough, highlights, headings, tags, and internal and external links. Which of those content types show a button is set from a single checkbox list that applies to both editing and reading modes, and the copied text matches the type, so a tag keeps its hash prefix. A command shows or hides all copy buttons, the button icon is configurable, and a notice after copying can be turned off. The interface is available in English, Chinese and Russian, the plugin uses only Obsidian APIs at runtime, and it requires Obsidian 1.13.0 or later.
