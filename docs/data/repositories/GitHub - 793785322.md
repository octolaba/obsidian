# SandmansDreams/Spectrum-Blue

Spectrum Blue is a redux of the Spectrum theme with a bluer colour palette, based on the Spectrum and Obsidianotion themes. The author states that the script was entirely rewritten but takes inspiration and snippets from both, and that the font is the open-source JetBrains Mono. The README notes that it is mainly a theme for personal use and likely contains bugs or errors.
