# Project-Free-Rangers/obsidian-notetabs

Note Tabs adds tabbed sections inside a note, inserted from the editor's right-click menu either as a new tabbed section or as another tab within an existing one. The recorded Markdown for such a section lives in the note itself, and the README describes the plugin as responsive and compatible with most plugins and themes. Slow loading in Live Preview is listed among its known issues.
