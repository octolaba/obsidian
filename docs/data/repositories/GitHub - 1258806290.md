# HackerHomeLab/AITranscribe

Obsidian plugin that records voice notes and meetings inside the app on macOS and iOS, transcribes them with OpenAI Whisper or Google Gemini, and then cleans up or summarises the text with Claude, GPT or Gemini following custom formatting instructions. Audio is chunked automatically before transcription, at 22MB for Whisper to stay under its 25MB limit and at 10MB for Gemini's inline payload boundary, and the input microphone is selectable in settings. Output either creates a new Markdown file from date, time and title templates or is pasted at the current cursor position. If a network error, an invalid key or a deprecated model breaks transcription or post-processing, the recording is still saved into the vault and a note with a media player link is still created.
