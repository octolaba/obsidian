# dwolfe884/obsidian-x86-flow-graph

This plugin converts a block of x86 assembly into a flow diagram drawn as an Obsidian canvas, through a command run over a highlighted code block. The README fixes the input format the parser expects: instructions are indented, jump target labels start at the beginning of the line, an unconditional jump produces one branch while any other instruction beginning with j is treated as a conditional jump with two, and every jump takes the target label as its single argument. The generated canvas is written beside the current note, and the README states that the blocks arrive mixed up and have to be dragged into place.
