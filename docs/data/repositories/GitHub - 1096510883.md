# justrelaxdc/tracker-habits-metrics

Tracks habits and numeric metrics as ordinary Markdown notes in the vault, with no external database or cloud service. Six tracker types are available: good and bad habits, plain numbers, a counter with plus and minus buttons, free text, and a slider with a configurable range. Trackers are rendered wherever a habit code block is placed, which can point at a folder, a date and a day span and toggle charts and statistics; folders up to three levels deep act as categories, and folders named for archiving are skipped. Statistics cover completion rate, active days, current and best streaks for habits and minimum, maximum, median, sum and average for metrics, alongside calendar heatmaps and line charts with optional limit guides.
