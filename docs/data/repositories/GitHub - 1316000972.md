# felixleopold/lean-search

Lean Search adds a search modal whose ranking multiplies match relevance by bonuses for title, heading and alias hits, by an open-frecency factor built from how often and how recently a note was opened, and by an optional boost for recently modified files. Terms are combined with AND and prefix matching, fuzzy matching is off by default, and the query syntax supports quoted phrases, a tag filter and negation; an empty query lists the most frecent notes. It keeps only lightweight metadata and one inverted index in memory, reads excerpts on demand, and restores a versioned local index cache at startup before refreshing changed notes in the background. Settings expose the recency and edit weights, body-text indexing, index persistence and fuzziness, and a debug mode prints the score breakdown under each result.
