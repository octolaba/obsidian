# gapmiss/claude-sessions

Obsidian plugin for browsing, searching, analyzing and exporting Claude Code sessions as interactive timelines, with live watch and rendering of tool calls. The README states that it reads session files directly from disk with no uploads and no external services, and that the documented release, 0.3.18, is desktop-only. It also states that the plugin reads the HOME environment variable and the user's home directory to locate Claude Code session files and OAuth credentials used for rate-limit display, and transmits nothing.
