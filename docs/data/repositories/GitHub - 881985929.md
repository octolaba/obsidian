# jvsteiner/send-note

Send Note shares a note by uploading it as Markdown to an S3 bucket the user provides and creating a URL for it, which another Obsidian user with the same plugin installed can open to add the note to their own vault. The note is encrypted by default and the key is embedded in the link, the share URL is written into the note's YAML frontmatter, and a Delete Note control in the frontmatter removes the note from the backend from inside Obsidian. The plugin is configured with an access key id and secret access key for an S3 user with write access to the bucket. The README states that the plugin shares code with the author's s3-image-uploader plugin, that it is still in development and may contain bugs, and that it is supported by advertisements.
