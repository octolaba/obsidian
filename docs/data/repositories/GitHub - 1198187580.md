# andreconde21/cockpit-board

Obsidian plugin providing a Kanban board driven by frontmatter properties, where dragging a card writes the change back to the file. The README lists configurable column rules over status, date and label fields, week, month and year calendar views with a heatmap, per-card timers recorded in a time_spent property, cron-based recurring tasks, a checklist editor, archive search over a dated folder structure, and due-soon notifications. It also describes mobile column switching by swipe, a privacy mode that blurs card titles, and a focus mode limited to two columns.
