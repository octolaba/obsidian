# yalvhe2009/obsidian-title-serial-number-plugin

This plugin adds serial numbers to the markdown headings of a note. Seven numbering styles are offered, covering Arabic numerals, Chinese lowercase and uppercase numerals, uppercase and lowercase Roman numerals, and uppercase and lowercase letters. The heading levels that are numbered, the style used at each level and the separator between numbers are all configurable, with a live preview while the settings are edited.
