# eweinhoffer/dxf-viewer

DXF Viewer opens .dxf drawings in a dedicated Obsidian view and renders them inside notes in reading mode through the standard embed syntax. The README describes panning, zooming and a zoom-all reset, plus a measurement mode for distances between vertices or curve centers and for diameters of circles and arcs, shown as a direct distance or as X/Y components. Drawing units are detected from DXF metadata with a manual inch or millimetre override, and the README states that the initial release is desktop-only.
