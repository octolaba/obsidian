# friebetill/obsidian-deepl

Repository for Obsidian DeepL, a plugin that translates selected text through the DeepL service. The README lists commands that translate a selection using the languages configured in settings, that choose a target language — or a source and target pair — from a suggestion modal and replace the selection, and one that appends the translation to the selection instead. It requires a DeepL API key obtained from a DeepL account, states that this is not an official DeepL plugin, and warns that the texts are sent to DeepL under that service's privacy policy.
