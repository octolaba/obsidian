# jzcurious/obsidian-theme-exotic-original

jzcurious/obsidian-theme-exotic-original holds Exotic, a dark-optimized Obsidian theme styled entirely in the Source Code Pro monospace face for both editor and preview. The README lists semi-transparent modals, menus and prompts with blur and brightness effects, alternating table rows with hover effects, distinct inline and block code styling, and smooth hover transitions on interactive elements. Every colour is defined as a CSS variable so that the palette can be personalized.
