# drbinsaad/knowledge-base-command-center

Layers an index, libraries, collections and queues over a vault without moving, renaming or rewriting any note. Membership is explicit: records are notes added by hand, plus notes covered by folders deliberately linked for dynamic membership, and a note's storage folder is otherwise irrelevant to whether it is indexed. All of that structure, including nesting up to five levels and a record appearing in several places at once, lives in the plugin's own data rather than in Markdown, so uninstalling leaves every file where it was. One installation can hold several independent knowledge bases, Obsidian 1.13 or later is required on desktop and mobile, and the plugin makes no network request and needs no account.
