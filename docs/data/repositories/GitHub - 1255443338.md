# carnalMATRIX/obsidian-mantle-icons

Mantle Icons puts icons into Obsidian notes, sidebars and folders as a companion plugin for the Project Mantle ecosystem. The README records Lucide-based icons in headers, note properties and folder lists, an inline shortcode syntax for placing an icon inside note text, attaching icons to files and folders from the sidebar, and SVG definitions bundled inside the code rather than loaded as separate resources. It states that custom CSS targets allow icon categories to be styled globally and that the icons are made to pair with the Zenith theme; its troubleshooting section notes that some themes do not render the dynamic SVGs.
