# hided62/obsidian-handlebars-dynamic

An Obsidian plugin that applies Handlebars templates inside notes: template files are defined in the vault and invoked from hb code blocks, and the upstream description records that template recursion is possible. The README's worked example shows an hb block naming a template plus the values it supplies, which is replaced on render by the template's output, including headings, callouts, inline formatting and a list built from an each loop. A separate document in the repository is cited for how templates themselves are written, and a Korean version of the README is linked.
