# open-horizon-labs/obsidian-am

This repository brings Marvin tasks, categories and projects into Obsidian and also ships an MCP server for agents that need Marvin access without mutating a vault. The README states that Marvin remains the task system of record, that the plugin projects that work into notes for context and execution through imports, managed daily-note regions and source-note associations, and that the MCP server is for Marvin-only work such as discovering a project by stable id, reading its work, and creating or completing a task. The two surfaces share one Marvin client, local-first read behavior, cache rules and error model, but are independent: the server runs without the plugin and without Obsidian, and the README expects it to be spun out into its own repository.
