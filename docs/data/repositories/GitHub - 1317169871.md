# wangruobing-dev/obsidian-anki-card-link

Links Obsidian notes to Anki in both directions: cards written in Markdown are synced to Anki over AnkiConnect on desktop, a generated link opens the matching Anki search, and Anki can navigate back to the source note. Basic, Cloze and dedicated single-choice and multiple-choice card formats are recognized, using separators such as a double colon, a question-mark line, and standard Cloze braces, with a comment marker splitting one note into several Cloze cards. Opening an Anki search works on mobile through AnkiDroid and AnkiMobile deep links, while content sync is desktop only and requires the AnkiConnect add-on on a loopback address. A later version adds an optional reading-mode mask that hides answers in tagged notes without altering the Markdown or the synced Anki fields.
