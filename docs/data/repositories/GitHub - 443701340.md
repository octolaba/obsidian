# aptend/typing-transformer-obsidian

Typing Transformer applies configurable automatic formatting as text is typed, and its README groups the behaviour into input conversion rules, deletion rules and selection rules. An input conversion rule is written as a trigger mapped to a result, covering expanded abbreviations, auto-paired symbols, full-width character transformation and auto-correction, with a marker in the result indicating where the cursor lands. It also inserts spaces between multiple languages and certain symbols, credits Easy Typing as its inspiration, and notes that its implementation depends on CodeMirror 6 and therefore works only in non-legacy mode on Obsidian 0.14.15 or later.
