# tapeau/Desk-Photos

Repository for Desk Photos, a desktop-only Obsidian plugin that places sticky and floating photos on top of the editor, fixed either to the screen or to part of a note. Photos are added from a vault image or a direct web link through a command or the editor context menu, and their positions are stored relative to the editor or note area so they persist across sessions. The README describes dragging, a double-click flip and interface sounds read from the plugin's assets folder, while the recorded description lists frames, tapes, pins, texts and filters as customisation options.
