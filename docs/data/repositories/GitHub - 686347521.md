# motschel123/Mac-Contact-Sync-Obsidian

This plugin synchronises contact data from the Contacts application on macOS into an Obsidian vault, writing a note per contact from a template. The template substitutes placeholder tags — among them name, nickname, first, middle, last and maiden name, title, job title, department, organization, home page, birth date, the phonetic name fields and the contact's own note — and which contacts are included is configured through a named smart list. The README records that re-running the sync overwrites an existing contact note except for whatever follows a delimiter string, and that the plugin drives the Contacts application through an AppleScript, so Obsidian has to be granted that permission when it is asked for.
