# rohrbachd/obsidian-review-critics

Adds tracked-change style review markup to notes while keeping them plain Markdown: commands mark additions, deletions, replacements and highlights, and insert standalone or anchored inline comments. A Track Changes mode produces add, delete and replace markup automatically, an Accepted Text View reads the note as if the edits were accepted while keeping comments visible, and single changes can be accepted or rejected, all changes accepted at once, and comments resolved. A unified Changes pane carries quick action buttons and the Track Changes toggle, a comments pane jumps to comment locations, review tokens are rendered in Reading View and highlighted in Live Preview, and named color theme presets can be saved, activated, overwritten and deleted.
