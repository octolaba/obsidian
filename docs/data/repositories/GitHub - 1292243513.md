# PeoneEr/self-hosted-vault-sync

Self-Hosted Vault Sync synchronises an Obsidian vault through a sync server the user deploys, and pairs with a companion server repository whose startup log prints a one-time bootstrap token used to configure the first device. Edits are pushed after a short debounce, the vault is pulled on startup and polled at a configurable interval, and on desktop Server-Sent Events announce another device's push, with mobile falling back to polling driven by app visibility. Only changed files are transferred, a stale write is saved as a conflict copy instead of overwriting newer content, and a glob exclusion list keeps chosen files local, with workspace files excluded by default. Further devices are added by generating a QR code from an already configured device.
