# kaymade/blue-ribbon

Blue Ribbon is a colourful Obsidian theme whose palette of blues, reds and creams is drawn from the blue notebook, the blue pen and the prize ribbon. It supports light and dark modes with optional dark mode background styles, styles headings in both reading and editing view, and themes tags, metadata properties, task states and callouts, with mobile layout refinement and print-friendly note styling. The Style Settings plugin exposes note width, code block width, table size, decorative heading lines, plain embeds, the dark mode background and the title, heading, body and accent fonts. The README says the theme works without extra fonts but was designed with Abril Fatface, Lora and Courier Prime installed locally.
