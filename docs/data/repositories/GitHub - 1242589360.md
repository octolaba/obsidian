# Saiki77/Easy-Git

Easy Git synchronises individual vault folders with Git repositories rather than the whole vault, mapping a folder to a repository, branch and path with a chosen direction. The README states that GitHub and self-hosted Forgejo or Gitea instances are supported, selected under the plugin's authentication settings, and that connecting takes a pasted token or a sign-in with no CLI, SSH keys or per-repository setup. Beyond mappings and directions it names conflict handling, backups and Markdown transforms as working the same across providers, and points at its contributing guide for the extension points another host would use.
