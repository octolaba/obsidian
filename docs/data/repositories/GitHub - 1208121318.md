# jabaho9523/obsidian-paste-plus

Paste Plus changes what a paste does in Obsidian according to the clipboard content. Its README lists the transforms: a URL becomes a Markdown link carrying the fetched page title, a pasted image is saved into the attachments folder with a clean filename, rich HTML is converted to Markdown rather than raw tags, and a YouTube or Twitter link is replaced by the title of the video or post. Each transform can be switched off on its own, and the settings also cover the image filename template, patterns for stripping fetched titles, and the title fetch timeout. The README frames the plugin as gathering into one place what the ecosystem otherwise offers as separate single-purpose paste plugins.
