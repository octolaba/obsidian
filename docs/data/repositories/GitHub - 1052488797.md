# FindFlowState/obsidian-flow-state

This Obsidian plugin connects a vault to the Flowstate service, which transcribes handwritten pages, photos, PDFs and voice recordings and files the resulting plain-text notes into the vault. The README describes capture by photo, voice memo, file upload, email from e-ink devices such as reMarkable, Boox, Supernote and Daylight, or the iOS and Android share extensions, with user-defined flows deciding the destination folder, title and formatting. Beyond transcription the service can reformat, summarize, translate or extract action items, and custom instructions can add frontmatter or other shaping; it is a paid service starting from 50 free credits, where one page or one minute of audio costs one credit.
