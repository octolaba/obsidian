# DocSanctum/doc-sanctum-obsidian

This plugin is an MCP client that connects Obsidian to a self-hosted DocSanctum backend so its indexed documents can be searched and read without leaving the vault. Keyword search and natural-language semantic search each have a command and a ribbon icon; selecting a result fetches the whole document and renders it in a read-only preview. Settings hold the backend's MCP server URL, an optional restriction to a single source, and a connection test, and backend warnings such as a source falling back to stale cached data appear as notices and as a banner above the preview. It performs no indexing or searching of its own, so a folder must already be registered as a source in DocSanctum and finished indexing before results appear.
