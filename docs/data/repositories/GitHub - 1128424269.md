# nbDev99/obsidian-monday-integration

Monday.com Integration shows Monday.com boards and items inside notes through a `monday` code block taking a board id, a title, an item limit and a list of columns, and in a dedicated sidebar panel. From the sidebar an item can be turned into a linked note carrying its task metadata after a check for an existing note, its status changed, people assigned or reassigned, and comments posted, while a separate team summary panel counts tasks per member with colour-coded status badges. The README records that a Monday.com API token is pasted into the plugin settings and tested before boards are loaded, and that the note folder, naming templates and display options are configurable.
