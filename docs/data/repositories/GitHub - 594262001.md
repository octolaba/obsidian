# threethan/obsidian-material-flat-theme

Material Flat is described as a flat and colourful Obsidian theme for desktop and mobile, and its README states that the Style Settings plugin is required. Just about every colour is derived from the accent colour set in the appearance settings and adapts to light and dark themes, so no preset colour lists are needed. The README records a floating action button in the bottom-right corner whose command is set with the Commander plugin, themed support for Breadcrumbs, Cooklang, Excalidraw and Canvas, and a translucency route that turns Obsidian's own translucent window off in favour of the native window frame.
