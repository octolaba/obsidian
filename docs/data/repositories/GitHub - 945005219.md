# dragonish/obsidian-heading-decorator

Heading Decorator displays specific content around a heading according to its level, and the README states that it modifies no note content and only decorates the heading section. The decoration is enabled separately for reading view, Live Preview, source mode, the Outline plugin, the Quiet Outline plugin and the Headings in Explorer plugin. A metadata keyword, `heading` by default, reads the enabled status of an individual note from its properties, while an effect setting decorates headings in an ordered, independent, splice or unordered mode.
