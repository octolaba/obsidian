# WantChane/key-sequence-obsidian

Key Sequence binds a sequence of key presses, rather than a single chord, to any Obsidian command. Sequences live in a vimrc-style configuration file, by default inside the vault's Obsidian folder and auto-created from a template, written as comment lines, a mapleader definition and gmap entries pairing a sequence with a command identifier; nothing is preconfigured. An embedded mode merges the definitions into another plugin's vimrc file, parsing only lines carrying a configurable prefix marker, and a reload command applies changes without restarting Obsidian. The README notes that the leader is only a placeholder substituted with the mapleader value, and that sequences are disabled while an input, textarea, select or contentEditable element has focus.
