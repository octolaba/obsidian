# manthey/offline-whisper

Obsidian plugin that transcribes speech to text with Whisper models and is designed to run entirely offline after the initial model download. On desktop it downloads and drives a whisper.cpp command-line binary for the operating system, while on mobile it runs a bundled transformers.js build through WebAssembly. Models are fetched from Hugging Face on first use and chosen in the settings, and transcription is toggled from the ribbon icon or the command palette. The README states that all audio is processed locally and that no recordings or transcriptions are sent to external servers.
