# r3quisitevariety/copyparty-obsidian

The repository holds Copyparty Uploader, an Obsidian plugin that sends pasted or dropped media to a self-hosted Copyparty server and inserts only the embed, so the file never enters the vault. Images, video, audio, PDFs and other files each get their own embed form pointing at the uploaded URL, and a migration command uploads existing local attachments note by note and rewrites their links. The README warns that the vault should be backed up first, because by default the plugin follows the current attachment settings and may remove local files without rewriting the links in notes.
