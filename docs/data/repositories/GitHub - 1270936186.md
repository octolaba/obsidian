# maoxiaoke/obsidian-image-actions

Obsidian Image Actions puts a small toolbar in the bottom-right corner of an image when the pointer hovers over it, in both Reading view and Live Preview and for vault embeds as well as external images. Its buttons copy the image to the clipboard, reveal a local image in the system file manager, or open a remote image in the browser. On mobile, touching and holding an image for a second copies it. The README notes that images are copied as PNG, re-encoded through a canvas, so any format the renderer can display can be copied.
