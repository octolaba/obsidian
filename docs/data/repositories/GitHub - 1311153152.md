# abnerzhao/obsidian-link-title-plus

Replaces a pasted HTTP or HTTPS URL in the editor with a Markdown link carrying the page title, taken from Open Graph, Twitter or HTML metadata and falling back to the website name when metadata cannot be fetched. Favicons are inlined as data URLs to avoid hotlink protection and are shown by default, and YouTube links go through oEmbed rather than loading the watch page. The inserted text comes from a configurable template with placeholders for title, URL, hostname, site name, icon and description, and metadata fetching can be routed through an HTTP, HTTPS or SOCKS5 proxy.
