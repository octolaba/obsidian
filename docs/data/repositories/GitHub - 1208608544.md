# jabaho9523/obsidian-link-plus

Obsidian plugin that finds unlinked mentions across a whole vault and converts them into wikilinks, one at a time or in bulk. A vault-wide scan collects text matching a note title or alias that is not yet linked, groups the results by target note with source file and context snippet, and offers one-click conversion, linking all mentions of a note, or linking every mention in the vault. Matching is case-insensitive and whole-word, honours frontmatter aliases, and skips existing links, code blocks, frontmatter and self-references. Aliases can be edited from the dashboard, individual mentions dismissed or a note excluded, and the README positions this as covering what the core backlinks pane shows only per note and cannot act on.
