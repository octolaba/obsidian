# joleaf/obsidian-bpmn-plugin

This plugin renders BPMN diagrams interactively inside Obsidian notes from a bpmn code block, and adds a modeler for editing BPMN files directly in Obsidian. It is based on the bpmn-js library and reads a bpmn file from the vault, referenced in the block's url parameter by relative or absolute path or as a Markdown link. Further block parameters set the canvas height, whether a link to the diagram file and the zoom buttons are shown, whether pan and zoom are enabled, and the zoom level, which defaults to fitting the viewport. The README also announces token simulation as a new feature.
