# Phasip/obsidian-canvas-llm-extender

Lets an OpenAI model add nodes to an Obsidian Canvas. The README states that the API key, or a local service, is configured in the settings, and that right-clicking a node and choosing the extender adds a new outgoing edge to a new node whose text the model generates from the nodes connected nearby. It notes the plugin only works on text nodes and probably breaks on other node types, and the author records its state as alpha, with error handling and other items still on a to-do list.
