# fangface-hub/ObsidianSharedVault

SharedVault is a serverless collaboration layer that stores Yjs-compatible operation files inside the vault itself and applies remote changes later without a dedicated server. Shared state lives in an operation cache, a node registry and snapshots under a shared-vault folder, while each device keeps a non-shared local CRDT cache and processed state under its own vault and node identifier, with the per-device node id persisted in the plugin data. The README records a manual sync command alongside background polling sync, and states that a node joins the registry only after it makes a local change.
