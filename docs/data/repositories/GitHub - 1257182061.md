# javatutor-ru/obsidian-cyrillic-non-latin-tags

The repository holds Cyrillic and Non-Latin Tags, an Obsidian plugin that adds CSS classes to tags containing non-Latin letters in Editing view, so their appearance can be styled directly or through another plugin such as Colored Tags Wrangler. A qualifying tag receives a shared class for all non-Latin tags and a second class derived from the tag's own name, while Latin-only tags keep Obsidian's standard classes. The README states that the plugin needs no configuration beyond a single toggle and processes only tags with at least one non-Latin letter, giving Cyrillic and Korean examples.
