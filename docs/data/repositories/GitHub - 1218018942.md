# jochenbernard/obsidian-image-zoom

Image Tab Zoom adds zooming to image files opened in their own Obsidian tab. Zoom is driven by a macOS trackpad pinch, a two-finger pinch with pan on iPad and iPhone, or a scroll wheel with a configurable modifier, and it is anchored on the cursor so the point under the pointer stays in place; dragging pans within the image's edges and a double-click or double-tap resets. The README limits the scope explicitly: only image files opened directly in Obsidian are affected, and images embedded inside Markdown notes are left untouched. This note is grounded in the README alone, as the repository records no description.
