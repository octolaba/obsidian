# lucidalpha/obsidian-pdf-notes

PDF.notes opens PDFs inside Obsidian and lets them be annotated, writing the drawings back into the PDF file itself. The README lists ink drawing with pen or touch input, a pen with adjustable size, color and opacity, rectangle, ellipse, line and arrow shapes, a stroke or pixel eraser, and page management that inserts blank, lined, grid, dotted or Cornell pages and deletes existing ones. It also records automatic saving, a flattening step that bakes drawings permanently into the PDF so any viewer shows them, and optional backups before structural changes; rendering uses PDF.js and manipulation uses pdf-lib.
