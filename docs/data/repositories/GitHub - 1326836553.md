# PrEvAl85/obsidian-life-calendar

Draws a life as a grid of weeks, one row per year and fifty-two cells per row, colored by whether a week has been lived, is a birthday, carries an event or holds journal entries. It creates its own folders for daily journal files, weekly aggregator notes, an events file and a backup, all at configurable paths, and asks for a date of birth on first run because the grid starts there. Clicking a week opens or rebuilds its weekly note from that week's journal entries while preserving sections added by hand, hovering a cell shows its entries and allows recoloring, and periods of life can be marked as zones tinting the weeks they span. Backup commands export and import a JSON file in the format used by a companion Android app, merging entries, events and zones without creating duplicates.
