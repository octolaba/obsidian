# xavwe/obsidian-nerdfont-icon-picker

NerdFont Icon Picker is an Obsidian plugin that adds a picker for Nerd Font icons, reachable through an assignable hotkey. The README states that the interface font and text font in Obsidian's appearance settings must be changed to a Nerd Font installed on the system, with the Custom Font Loader plugin suggested for mobile. Its troubleshooting section records that only Obsidian 1.0.3 and later are supported and that individual missing icons usually mean the installed Nerd Font version is too old for those symbols.
