# LiamRiddell/obsidian-solve

Solve processes equations and patterns in a note in real time, without relying on a chat model. Recorded examples are arithmetic written inline, including a spelled-out division form, and date expressions such as the number of days since a date or a date shifted forward or backward by an interval. The README describes the plugin as unobtrusive, working quietly while notes are written, and points at the project wiki for the wider list of patterns it recognises.
