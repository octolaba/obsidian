# adanielnoel/obsidian-index-notes

Generates index blocks inside notes from hierarchical tags, so a note tagged with a tag path ending in an index suffix receives a nested list of links to the notes under that branch, updated automatically as tags change. A meta index variant lists the indices themselves, and one note may carry several indices and meta indices. Because the links are written into the file, the README notes that the graph view then reflects the resulting organisation. A separate command and ribbon icon create a new note in the same directory as the focused note and copy its tags.
