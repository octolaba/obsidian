# Gust4v0Di4sC/Material-Icons-Obsidian

Adds Material Theme icons, in the style used by VS Code, to Obsidian's file explorer. The README is written in Portuguese and lists per-extension icons and colours for Markdown, JavaScript, TypeScript, Python, JSON, CSS, HTML, images, PDF, YAML, shell scripts, archives and dotfiles, plus special icons for folders such as src, assets, images, docs, notes, projects, templates, config, archive and scripts. Installation is manual and documented as building the plugin with Node.js and npm and copying main.js, manifest.json and styles.css into the vault's plugin folder; adding further icons means editing an SVG map in the source.
