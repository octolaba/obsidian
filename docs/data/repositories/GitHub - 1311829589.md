# Sjef200/cleanview-obsidian-plugin

Builds dashboards inside a note - task lists, tables, key figures, countdowns and hand-drawn SVG charts - configured through a dialog and stored as block data rather than a query language. It reads Obsidian's metadataCache rather than building a second index, opens only the files the cache reports as containing checkboxes, and compiles filters and sorts to closures once per block. Task metadata is read in both the Tasks plugin's emoji shorthand and Dataview's inline field syntax, and a block re-renders only when a change is relevant to its scope. It makes no network requests, uses no eval, ships no runtime dependencies and no Node APIs, and its only write is toggling a checkbox after checking the target line still matches what was indexed; it requires Obsidian 1.13.0 or later.
