# jabaho9523/obsidian-assist-plus

Assist Plus adds a chat sidebar to Obsidian that talks to Anthropic's API using a key the user supplies, streaming Markdown replies with a model picker and a meter for how many files are in scope. Nothing is visible to the model unless it is attached: notes are added from the active file, a fuzzy picker, a command or a drag, and a panel lists every file in scope with per-file removal. A denylist of folders and tags overrides everything and excludes files at send time, a frontmatter flag can refuse a note as well, and each sent message records the exact list of files it carried. Read-only mode never changes the vault, while suggest mode shows a proposed edit as a callout that opens a line-by-line diff for per-hunk application.
