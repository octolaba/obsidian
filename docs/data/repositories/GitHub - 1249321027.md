# ydd0729/obsidian-better-live-preview-image

Better Live Preview Image adds image alignment controls and callout image-size marker support to Obsidian Live Preview and Reading view. Users can set left, center, or right alignment through context menus, commands, or hotkeys, while width and height markers inside callouts can be applied without changing the Markdown. Alignment is represented in image alt markers and the plugin operates entirely inside the vault without network, telemetry, accounts, or external services.
