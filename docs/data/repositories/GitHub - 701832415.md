# lolipopshock/obsidian-scholar

Obsidian Scholar supports a research paper workflow inside the vault: given a link to a paper on the web it downloads the PDF and creates a paper note carrying the paper's metadata, building a local library. Papers in that library can be searched and retrieved, with a key toggling the abstract while moving between results and another key querying Semantic Scholar for papers not yet in the library. While reading, the details of a referenced paper can be checked without leaving Obsidian, a paper's BibTeX can be copied, and citation information can be displayed in place over a PDF. The README states that the in-PDF behaviour is used together with the PDF++ plugin and that, at the time of writing, the supporting change is offered as a branch of that plugin rather than merged.
