# FlorianWoelki/obsidian-iconize

The repository holds Obsidian Iconize, a plugin that attaches a custom SVG icon, or one drawn from an icon pack, to items throughout the interface. Its README lists icons before a file or folder name, icons inside notes, an icon above a note's title, predefined icon packs and icons in tabs, with the detail kept in an external documentation site. Its opening notice records that the project is deprecated and its maintenance has ended.
