# arun-gajaraj/claude-theme-for-obsidian

Claude is a dark Obsidian theme whose neutral palette is modelled on the Claude AI chat interface, with readability as its stated focus. Its README lists Inter for interface and body text with JetBrains Mono for code, syntax highlighting tuned for dark backgrounds, consistent styling across reading mode and live preview, independent sidebar and editor background colours, and inline code and code blocks coloured distinctly from body text. The README states a requirement of Obsidian 1.12.4 or later.
