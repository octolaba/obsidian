# dsebastien/obsidian-note-village

Note Village renders the vault as a two-dimensional pixel-art village: the most frequent tags become themed zones and the notes carrying those tags become villagers placed in them. The world is generated deterministically from a seed, so the same seed reproduces the same layout, and zones, villager limits and graphics quality are configurable. The village is explored with the keyboard or by clicking, and conversations with a villager are generated by a model, which the README records as requiring an Anthropic API key.
