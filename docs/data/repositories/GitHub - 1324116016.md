# RudeCrab/obsidian-plugin-folder-timeline

Renders notes as bars on a time axis, taking each note's start and end from named frontmatter fields. In folder mode a config note whose frontmatter marks it as a timeline selects the folder, optionally recursive, the field names, a year, month or day scale, and the sort key and direction, and that form can be edited from inside the view. It also registers a timeline view type inside Obsidian Bases, alongside table, board, calendar and gallery, where filtering, sorting and grouping are left to the Base and only the two date properties are configured. A note with a start but no end is drawn as a single point, a start later than its end is reported as invalid, the axis is drawn without third-party charting code, and clicking a bar opens the note.
