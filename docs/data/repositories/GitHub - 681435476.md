# ljcoder2015/obsidian-excel

Obsidian plugin that integrates the x-spreadsheet component into Obsidian so that xlsx files can be stored and edited inside a vault, imported and exported, and embedded into Markdown through a link whose parameters select a rectangular cell range and an optional HTML rendering. Selected cells can also be copied out as HTML. The README opens with the statement that the plugin is no longer maintained or updated and directs users to the author's Obsidian-Sheet-Plus instead.
