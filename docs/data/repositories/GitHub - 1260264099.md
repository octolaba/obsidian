# Ryxwaer/obsidian-latex-symbol-picker

Obsidian side panel for finding a LaTeX symbol and inserting it at the cursor. A symbol can be drawn with a mouse, finger or stylus and matched by shape, in the manner of Detexify, or searched by name through common synonyms so it can be found without knowing the LaTeX command. Clicking a result inserts it at the cursor, wrapped in inline math delimiters when the cursor is not already inside a math context, and recently picked symbols are kept at the bottom of the panel for reuse. The README states that the classifier and its training data ship with the plugin so it works fully offline, and that only symbols Obsidian's MathJax can render are included.
