# reallygood83/note-sweep

Note Sweep scores the notes of a large vault locally and builds a queue of cards to work through in timed sessions, with the README stating that it uses no AI, no network and no telemetry. A session can start automatically at a configured local time while Obsidian is running, with a catch-up prompt when that time was missed, and each card can be opened, archived, postponed or skipped from the sidebar queue. Archiving is recorded as a move rather than a deletion, and snooze and streak data are kept in plugin data instead of being written into the notes. The interface switches between Korean and English, and most of the README is Korean.
