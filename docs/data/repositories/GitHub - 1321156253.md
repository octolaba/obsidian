# obsidian-power-plugins/power-extract

Power Extract reads the text inside images in the vault using the character recognizer already built into Windows, so nothing has to be downloaded and no image leaves the machine. It adds no view of its own: the extracted text is offered to other plugins, and a right-click menu item copies the text of one image to the clipboard. Recognition is reached by starting powershell.exe at a fixed path with fixed arguments and passing image paths over stdin, running a script shipped with the plugin that is checked against the shipped copy before every start, with the process shutting down after thirty seconds of quiet. Results are cached against each file's size and modification time so an image is read once, and it works only on Windows desktop, covering png, jpg, jpeg, bmp, gif and webp where Windows has the codec.
