# NEWO-J/note-decay

This repository holds Note Decay, an Obsidian plugin that visualizes stale concepts and targets review through spaced repetition. A note is graded again, hard, good or easy from a bar at the top of the note whose buttons show the interval each grade will schedule; the SM-2 algorithm then sets the next review date and writes the review fields into the note's frontmatter, with a grading cooldown guarding against repeated grading. The file explorer colours notes green through red by how overdue they are, folders are tinted by the share of their notes that are still fresh, graph nodes can be coloured through a review status property and colour groups, and existing notes are seeded from their file date so the vault is not blank on day one.
