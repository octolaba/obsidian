# OkamiWong/obsidian-custom-state-for-task-list

This plugin lets a task list item carry a custom state written between its square brackets instead of the usual blank or checked marker. A state name placed in the brackets is rendered in reading view as the icon configured for it, and the plugin ships with committed, doing, deferred and removed as defaults, each mapped to an emoji. The default states can be edited and further states added in the settings.
