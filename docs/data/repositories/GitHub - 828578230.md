# Ummler/obsidian-auto-correct-capitals

Obsidian plugin that corrects words whose first two letters are capitalised while the third is lower case, rewriting HAllo as Hallo. An exclusion list holds comma-separated words that are never corrected, and an abbreviation list stops the plugin from capitalising the word that follows a recognised abbreviation. An optional setting capitalises the first letter of list items starting with a dash, an asterisk or a number, including inside sub-lists, and repairs wrongly capitalised ones. Fenced code blocks, inline code, and both inline and block LaTeX math are detected and left unchanged.
