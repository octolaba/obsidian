# yanqingwang/obsidian-joplin-server-sync

Joplin Server Sync provides bidirectional synchronization between Obsidian and a Joplin Server for notes, folders, and attachments. It supports optional end-to-end encryption, conflict strategies, path exclusions, link and tag conversion, sync history, and force push or pull operations that reset one side before re-uploading or downloading data.
