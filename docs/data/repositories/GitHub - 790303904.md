# aaronczichon/obsidian-location-plugin

This Obsidian plugin renders a Mapbox location image from data supplied in a note. A location fenced code block takes a longitude and latitude, or a search term, in which case the plugin fetches the most relevant result and generates a map image for that location. The README points to external pages for the full usage documentation, the data privacy information and the changelog.
