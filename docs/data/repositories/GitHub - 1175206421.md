# ouatis/obsidian-scriptorium

Scriptorium is a warm, paper-inspired Obsidian theme for long-form reading and writing, keeping the writing surface primary through soft paper tones, restrained contrast and quiet workspace chrome. It applies its own IBM Plex font stacks with CJK fallbacks, so the Appearance font settings are not applied, and the README states that supporting the Style Settings plugin is not a goal. The theme ships as a single theme.css with no external dependencies, names Sanctum and Baseline as inspirations, and provides Chinese and Japanese translations of the README.
