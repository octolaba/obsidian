# polybjorn/obsidian-readest-highlights

Imports highlights and annotations from the Readest reader, which stores its library, progress and annotations locally as JSON, and renders them into vault notes. Three commands sync every book into a configured folder as one note per book, sync a single book chosen from a fuzzy picker, or append one book's highlights to the active note. It requires desktop Obsidian with access to a Readest Books folder outside the vault, and the README states that the plugin reads only `library.json` and each book's `config.json` from that folder, never writes to it, and needs the Node `fs` module to read outside the vault.
