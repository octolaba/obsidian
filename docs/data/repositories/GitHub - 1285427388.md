# Git-Hub-Dangel/obsidian-property-streaks

Property Streaks builds habit and goal streaks in the manner of Duolingo out of frontmatter properties in daily notes, displaying icons and remarks beside the properties and offering a widget for selected streaks. Each streak is configured in settings with a name, a type that depends on either one property or several, and toggles for showing it next to the properties and in the widget, alongside custom colours, motivational comments and an occasional streak freeze. The README states that the plugin expects a daily-note template with persistent frontmatter fields reviewed each day, and that it works locally, offline and on mobile.
