# joelwongjy/obsidian-bible-verse-tips

Bible Verse Tips previews Bible verses in a popover when a reference is hovered in Reading view or Live Preview, and opens the whole chapter in a reader with previous and next navigation when the reference is clicked; on mobile a tap shows the preview and a tap on the version code switches translation. Passages are laid out with prose in paragraphs, poetry keeping its line breaks and section headings where the translation supplies them, and each preview and chapter links out to the passage on Bible Gateway. Detection covers full book names and common abbreviations with or without verses and ranges and is case-sensitive so ordinary prose is left alone; the README states no setup or API key is required and that the two settings are the default translation and whether the preview appears on hover or on click.
