# Cheng-Zi-Qing/stepvox

StepVox is a voice-driven assistant for Obsidian: microphone input passes through speech recognition to a language model holding vault tools, and the reply is spoken back, with the whole pipeline streamed. The README lists tools that read, search, create, append to, update, move and open notes and query frontmatter, optional web search through Tavily or Exa, and a choice of StepFun, OpenAI, Anthropic or any OpenAI-compatible endpoint for the model. Two modes are recorded — one question and one answer, or a continuous session that ends on a keyword or on silence — plus barge-in, which stops the assistant as soon as the user speaks, and a configurable assistant persona. Requirements are Obsidian 1.7.0 or later on desktop only, a StepFun key for speech recognition and synthesis, a model key, and microphone permission.
