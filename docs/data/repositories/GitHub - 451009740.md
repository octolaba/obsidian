# ckRobinson/multi-column-markdown

Multi-Column Markdown is an Obsidian plugin that lays blocks of a note out horizontally in columns instead of one linear flow. Column regions are defined in the document, with the number of columns, their widths, spacing, text alignment and further settings configurable, and multiple syntax options exist including Pandoc-compatible fenced divs. Whole documents can also be set to reflow automatically into multiple columns in reading mode. The README states that live preview is supported but that cross-compatibility there is not guaranteed, because of how custom live preview plugins hook into CodeMirror 6, for other plugins, interactive elements and more advanced non-native Markdown features.
