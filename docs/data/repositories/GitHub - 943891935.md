# ardakalayci/ytsummarizer

YTSummarizer fetches the transcript of a YouTube video and can generate a summary of it with OpenAI GPT models. A transcript is requested from a ribbon icon, from a URL selected in a note, or from a command that prompts for the URL, and is then shown in the sidebar or written into a new note; timestamps in the transcript are interactive and open the video at that point. The README records configurable timestamp frequency, language and country codes, and a choice of OpenAI model, with the summary generated from a button in the sidebar view.
