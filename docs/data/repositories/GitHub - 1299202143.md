# DyllonWright/Obsidian-Daily-Note-Lookback-Plugin

Repository for Daily Note Lookback, an Obsidian plugin that turns a small code block in a daily note into collapsible rows showing what chosen sections said on earlier dates. The README argues that native embeds load and render the whole source file at every note open, and that this plugin instead renders rows as a light index and reads section content only when a row is expanded. Anchor dates come from the note title or a date key, and the offset series stops at a configured cutoff or at the earliest daily note found from filenames alone.
