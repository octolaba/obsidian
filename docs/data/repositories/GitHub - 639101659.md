# drbap/magicuser-theme-for-obsidian

MagicUser is a theme for Obsidian with light and dark modes and a set of built-in preset color schemes, including Room Lamp, Purple, Teal, Gray, Camouflage, Moon, Teacher, Creativity, Concentration and Stealth. With the Style Settings community plugin it exposes over 200 options covering colors, fonts, layouts, interface modes and effects, gathered behind a preset themes and quick start menu. Two presets are generated rather than fixed: Chroma Amulet builds a scheme from color and saturation sliders while leaving the accent color alone, and the Accent preset derives headings, icons and borders from the accent color chosen in Obsidian. Background presets add sliders to darken or lighten the image in dark and light mode.
