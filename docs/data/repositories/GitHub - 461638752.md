# Richardsl/heatmap-calendar-obsidian

Heatmap Calendar renders vault data as a calendar similar to the GitHub activity calendar, which the README suggests for tracking exercise, finances, project progression and comparable series. It is driven from a DataviewJS block: data annotated in daily notes is collected with Dataview and passed to `renderHeatmapCalendar()`. Colours default to a green scheme and can be overridden per calendar through `calendarData.colors`, with several named colours shown in one heatmap, or added globally from the settings panel.
