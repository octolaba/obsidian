# daniegee/obsidian-vault-activity

Vault Activity is an Obsidian plugin that tracks note creation and revision activity and presents it as a dashboard of streaks and trends. The README lists current and longest streaks, the most active weekday and a rhythm summary, trend charts over weekly, monthly, yearly and all-time windows with a toggle between new and modified notes, and drill-down lists that show which notes lie behind a chart point. Configuration covers the conditions used for streaks and summary statistics, the frontmatter keys holding created and modified timestamps, and include and exclude folder filters.
