# bwydoogh/obsidian-force-view-mode-of-note

Obsidian plugin that lets a note declare in its front matter which mode it should always open in. One key sets the view mode to source or preview, and another sets the editing mode to live or source, so a note can be fixed to live preview or to reading view however it was last left. The plugin also ensures that a note opens in the configured default mode even when the pane it opens in is currently in a different one.
