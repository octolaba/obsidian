# kevinyuan/marp-tikz-plus

Renders TikZ and LaTeX diagrams inside Obsidian notes and authors Marp slide decks; the README marks the plugin desktop-only and says rendering runs locally through a WebAssembly TeX engine with no internet required. Fenced tikz blocks render as SVG in Reading view, with packages such as chemfig, circuitikz, pgfplots and tikz-cd, colour inversion for dark themes, inclusion of external .tikz files that refresh on save, and a two-level memory and persistent cache. For slides it renders Marp decks through marp-core without other plugins, adds a thumbnail slide navigator and a speaker-notes panel built from Marp HTML comments, and exports PDF or PPTX through marp-cli with native PowerPoint math objects and injected CJK fonts.
