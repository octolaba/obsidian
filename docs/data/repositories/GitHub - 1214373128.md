# Aduneer/gruber-darker-obsidian

Aduneer/gruber-darker-obsidian is an Obsidian port of the Gruber Darker colour theme, which the README traces from John Gruber's original for BBEdit through Emacs adaptations by Jason R. Blevins and Alexey Kutepov. It ships a full dark mode with the canonical palette and a warm light fallback, a distinct colour for each of H1 to H6, syntax highlighting in editor and reading view, and coverage of graph view, callouts, tables, tags, Canvas, Mermaid and PDF embeds. Style Settings support adds a settings panel that includes vim cursor shapes, per-mode colours and a mode indicator in the status bar, and the README states that the theme uses no remote assets.
