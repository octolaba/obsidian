# Otto-J/sync-to-xlog

This plugin publishes Obsidian notes to xlog.app, adding a right-click command on a Markdown file that opens an upload dialog before sending it. A token entered in the settings is checked with a connection test and can carry several accounts, one of which is picked as the publishing target. The README, written mostly in Chinese, records that an already published note is updated rather than duplicated on a second upload, that the resulting information is written back into the note's frontmatter, and that images in the Markdown are converted to IPFS references; installation from the community plugin market, through BRAT, or by hand is documented, and known issues and remaining work are listed.
