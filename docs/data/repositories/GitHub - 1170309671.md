# tarikbc/apple-journal-importer

Converts an Apple Journal export, a folder of HTML entries plus a media archive, into Markdown notes inside the vault. Each entry becomes a dated folder holding a note with YAML frontmatter, the original body text and a media subfolder, with photos, videos, audio, locations, workouts, contacts and state-of-mind items mapped to embeds or labelled lines; several entries on one day are numbered apart. The import runs from a ribbon icon or a command, takes the path to the export folder, verifies it, and reports progress and errors. Target folder, media subfolder name and HEIC-to-JPEG conversion are configurable, and that conversion relies on the macOS sips tool.
