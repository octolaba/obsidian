# ericmwalk/obsidian-omglol-publisher

This plugin publishes to the omg.lol services from inside Obsidian — weblog posts and pages, status updates, pastes and photos — and can keep the profile and now pages in step, having been renamed from a status-only plugin as its coverage grew. For weblogs it records publishing a new post, updating an earlier one through a saved entry identifier, batch publishing several at once, back-dating or future-dating from frontmatter, and reading tags, draft status, a custom slug, the page type and a template field out of frontmatter. Renaming the note file after publishing and filing it into year and month subfolders are both optional behaviours.
