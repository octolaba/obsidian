# jsonMartin/readwise-mirror

Readwise Mirror is an unofficial open-source plugin that mirrors an entire Readwise library into an Obsidian vault, downloading all highlights and notes and syncing later changes. Its output resembles Readwise's own Markdown export, which groups a source's highlights into one file per book or article, with Obsidian-specific additions such as links generated for book titles and author names. The README describes keeping internal links to the synced notes intact across syncs, protecting or updating frontmatter properties, and defining custom filenames from each item's properties. It opens with a warning that version 2.x is a rewrite that changes how filenames are generated and will break internal links unless an existing library is prepared first by adding a uri tracking property to the notes' frontmatter, for which it documents a step-by-step guide.
