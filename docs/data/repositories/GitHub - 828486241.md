# Quinta0/chiaroscuroflow

Quinta0/chiaroscuroflow records no repository description; its README presents Chiaroscuro Flow as a customizable Obsidian theme with gradient backgrounds in both light and dark modes. It requires the Style Settings plugin, through which the background, text, code-block and math-block colours and the named light and dark gradients can be changed. Its defaults are Manrope for body text and Nunito Sans Bold for headings, and the README records text shadows on headings plus contrast adjustments for readability. Gradient backgrounds are deliberately suppressed when a note is exported to PDF.
