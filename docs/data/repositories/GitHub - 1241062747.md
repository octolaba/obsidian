# jordanvasu/link-unlinked-mentions

Obsidian plugin that converts plain-text mentions of other notes in the active note into wikilinks in one pass. It collects the titles and aliases of every other note in the vault, scans the current note for them, shows a preview of every match with its surrounding context, and only rewrites after the matches are confirmed; no other note is edited. Text inside frontmatter, fenced and inline code, math, existing wikilinks and Markdown links, HTML comments and tags is left alone, and a term shared by two notes is skipped rather than guessed, with the reason shown in the preview. The README warns that the edit is not reversible without a vault backup.
