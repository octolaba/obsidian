# grub-basket/SnR

Repository for Slide and Reveal, a plugin for studying labelled images such as diagrams, anatomy plates, annotated screenshots, maps and sheet music. Its README describes importing an image once, drawing rectangular or polygonal covers over the labels, and scrolling inside the image to uncover them a group at a time, in contrast to duplicating a slide per revealed label. Version 0.5 added a second mode that pulls cropped fragments from across one or more folders, shuffles them and asks the reader to identify each out of context.
