# borfirbora/auragraph

AuraGraph Station replaces graph browsing with a keyboard-driven modal built from three panes: a Deck of notes staged during a session, a Dynamic Root tree rooted in the note currently being explored, and a third pane showing that note's incoming or outgoing links. It is aimed at screen-reader users, announcing link summaries, focused items and actions through ARIA live regions, and marking dead ends or confirmations with short Web Audio tones instead of verbose messages. Number keys move focus between the panes, arrow keys walk and expand the tree, and dedicated keys report or open incoming and outgoing links, while commands open the station itself and a view of orphan notes.
