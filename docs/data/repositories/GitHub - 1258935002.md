# lyxdream/obsidian-douyin-capture

Imports Douyin share links or pasted share text into an Obsidian vault, downloading no-watermark videos, carousel images and captions and creating structured notes with titles, hashtags, a tag callout block and frontmatter metadata. Video posts can be transcribed to Simplified Chinese by a local Whisper backend, and two import modes either run the full pipeline or download the video and skip transcription. The README states the plugin depends on a separate local Python service that must be installed and run first, and requires desktop Obsidian 1.4.0 or later, Python 3.10 or newer and FFmpeg for transcription. It states that no Douyin cookie and no paid speech API are needed and that the media stays on the machine, while the internet is still used to download the Douyin assets and the first Whisper model.
