# aplikofi/Obsidian-bckp-Plugin

This repository holds Obsidian Zstd Backup, a plugin that archives a vault with tar and Zstandard compression implemented as in-process JavaScript libraries, so no external tar or zstd binary has to be installed on Windows, macOS or Linux. Every backup gets a sidecar checksum file that is validated before a restore, and restoring never overwrites the live vault: the snapshot is extracted into a timestamped folder inside the configured recovery directory for review. A settings panel carries the vault and backup paths, a numeric limit that prunes older backups, and manual backup and restore buttons, while a ribbon icon opens the snapshot list. The .obsidian and .trash folders are excluded from archives.
