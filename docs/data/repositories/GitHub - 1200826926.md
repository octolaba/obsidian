# clairefro/obsidian-plugin-image-dither

Image Dither intercepts images pasted or dropped into an Obsidian note so they can be dithered to black and white and resized before being stored, which the README presents as a way to reduce storage use. Five conversions are offered — Floyd-Steinberg error diffusion, blue noise, ordered Bayer, a hard threshold, and a plain grayscale conversion without dithering — and the README tabulates the resulting file sizes for one sample photograph against its original. Per-image controls include the black-and-white cut point on a 0 to 255 scale and sharpness, with a live preview before the image is saved.
