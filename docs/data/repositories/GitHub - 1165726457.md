# samaraliwarsi/obsidian-portals

Portals pins any folder or tag in an Obsidian vault as a tab above the file pane, giving a navigable view of the selected folder tree. Tabs take custom names, Phosphor or Lucide icons, background colours and gradients, can be reordered, grouped into collapsible stacks, split by collapsible sections based on a property or extension, and switched by hotkeys numbered one to ten. The README also records file preview snippets under filenames, tag grouping with subtags, multi-select of files, folders and tags with a toolbar of actions, floating buttons and quick-add buttons for creating notes, folders and tag groups, automatic backup of the plugin data file on reload, and a Side Portal view holding bookmarks, recent files, context notes, hidden items, properties and journal.
