# xavdid/obsidian-golinks

The repository holds Obsidian GoLinks, a plugin that renders plain-text go links as clickable elements. Its README records that it works in reading mode, source mode and Live Preview, that it handles the short form as well as one written with a protocol, and that it ignores such text inside code blocks and backticks and links that are already written as Markdown links. It is written in TypeScript under the MIT license.
