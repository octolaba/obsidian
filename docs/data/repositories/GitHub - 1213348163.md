# bkindler/imagefull

ImageFull opens an image embedded in an Obsidian note in a fullscreen viewer, with no settings and no toolbar. A double-click or double-tap opens the overlay, pinch on touch or trackpad zooms up to ten times, a two-finger swipe shifts the visible section, dragging pans while zoomed, and Escape or a double-click on the overlay closes it while `0` resets the zoom; this works in reading view and Live Preview on desktop and mobile. The README explains the plugin's reason for existing as the built-in image preview opening in a side pane rather than offering a fullscreen flow with pinch zoom, and notes that the plugin is a single `main.js` with a stylesheet and no build step.
