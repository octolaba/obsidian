# gris/study-pdf

Study PDF adds text highlighting and note-taking to PDFs opened inside Obsidian, writing everything as standard PDF annotations into the file itself rather than to a side store. Highlights are created by selecting text and picking a colour from a popup or by running a command, with one quad per line and a real appearance stream so that any reader renders them; a note attached to a highlight is kept in the annotation's standard contents field, which the README says makes it show up as the highlight's comment in other PDF applications too. A highlight can be removed from its popup or by command, and an overview command lists every highlight in the document with its colour, recovered quoted text, note and page.
