# miaoziguan/obsidian-bamboo-walking

Obsidian plugin that delivers a personal Chinese-language writing column as plugin content, so installing the plugin is how a reader subscribes to it. Articles are browsed by category in a sidebar and saved into the reader's own vault with one click. The README states that production builds pull articles from the author's separate content repository while development builds read them from a local directory, and that the plugin source is MIT while the article content is licensed CC BY-NC-ND 4.0.
