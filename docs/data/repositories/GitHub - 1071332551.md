# HotAndCold245/Hidden-Grotto

HotAndCold245/Hidden-Grotto holds a theme its author made primarily for personal use, with a base palette inspired by the Pokemon Clobbopus and support for both light and dark mode. It offers 25 colour palettes through Style Settings or the companion Hidden Grotto Controls, a mobile toolbar with vertical scrolling, callouts whose icons are hidden unless re-enabled through a CSS variable, and an option to blur or redact everything when notes are left unattended.
