# Jon-Vii/obsidian-tab-link

Tab Link offers note links as inline ghost text while typing, accepted with Tab and dismissed with Escape, a space or an arrow key. The README states that it does not suggest inside existing links, code blocks or frontmatter, that it matches phrases rather than only prefixes, that it searches frontmatter aliases alongside note titles, and that candidates are ranked by a frecency score combining frequency and recency of use. Settings cover the minimum characters before a suggestion appears, the debounce delay, excluded folders, an automatic space after acceptance and a switch for the ghost text itself; the index is described as trie-based and built in chunks at startup.
