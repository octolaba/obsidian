# alvaromateo/folderer

Folderer runs rules automatically on Markdown files in folders it is told to monitor. Each monitored folder can carry several rules, and a rule combines a trigger, conditions and actions: triggers fire on file creation or on a rename or move inside the folder, conditions test the file name, the file path or a frontmatter property with contains, starts with, ends with, matches regex and exists operators, and condition groups combine them with All, Any or None logic. Actions append or prepend text to the file, several actions can be chained in one rule, and rules are reordered with up and down buttons to control execution order.
