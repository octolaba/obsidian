# n23eos/advanced_graph_view

Advanced Graph View is a desktop-only WebGL replacement for Obsidian's graph view, designed for large vaults and using a Web Worker for force layout while the interface renders thousands of nodes. It encodes metrics such as PageRank, open frequency, edit recency, links, tags, and clusters through size, colour, or glow, and adds Louvain clusters, orphan and broken-link overlays, extended search filters, focus and explore modes, and a local graph pane.
