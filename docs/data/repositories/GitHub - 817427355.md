# Mossy1022/Smart-Memos

Smart Memos transcribes audio into notes. Audio is recorded straight into a note with pause, resume and restart controls, or imported into one, then transcribed with an AI model and turned into generated Markdown notes. The prompt sent to the model ahead of the transcript is customizable, so the analysis, structure or formatting requested is up to the user, including forms Obsidian renders such as Markdown and mermaid charts, and the recorded audio formats are mp3, mp4, mpeg, mpga, wav and webm. The README records the plugin as using online OpenAI models configured with an API key, with local models named as a future addition, and notes the provider's stated retention of text but not audio.
