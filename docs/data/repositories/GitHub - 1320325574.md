# Tacitustus/obsidian-graph-color-propagation

Graph Color Propagation reads the colour groups defined in Obsidian's own Graph view settings and spreads those colours to notes that match no group, blending contributions from linked coloured notes by hop distance and path count. A breadth-first search runs up to a configurable maximum number of hops, weighting each contribution by a decay factor raised to the hop distance and discarding anything below a minimum influence. Colours re-apply automatically when a group is added, edited or removed, and can also be triggered from a ribbon icon, a command or a settings button. The result is applied to open Graph views only and is never written back to graph.json, and the plugin is desktop-only because it relies on the desktop graph renderer.
