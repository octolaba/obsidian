# hyungyunlim/obsidian-naver-blog-importer

This repository holds Naver Blog Importer, an Obsidian plugin that imports Naver Blog and Cafe posts into a vault; the repository records no description, so this summary follows the README alone. It covers bulk import of a blog by ID, single posts by URL, subscriptions with auto-sync, and cafe articles including private cafes reached with cookie authentication. Optional features listed are generated tags and excerpts through OpenAI, Anthropic, Google or Ollama, local image download, YouTube embeds, duplicate detection, and a Korean or English interface.
