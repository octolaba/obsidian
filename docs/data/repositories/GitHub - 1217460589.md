# stefan-imbesi/obsidian-at-link

An Obsidian plugin that opens an internal-link autocomplete when @ is typed at the start of a line or after whitespace, so an @ inside an email address does not fire it. What follows the @ becomes the query, matched against vault file basenames, headings from the metadata cache and blocks that already carry a block id, and choosing a suggestion replaces the query with the corresponding wikilink to the note, the heading or the block. Ranking runs exact prefix, then case-insensitive prefix, then fuzzy subsequence, capped at twenty results, and a space or Escape closes the popup leaving the @ in place. The README presents it as a companion to PhraseSync, which handles mid-sentence linking.
