# mokkiebear/heatmap-tracker

Heatmap Tracker reads dated notes in a vault and turns them into a year-at-a-glance grid of the kind known from GitHub's contribution graph. A frontmatter field such as steps or mood is enough: a three-line codeblock draws the heatmap, every filled square opens the note behind it and every empty square offers to create one. A dataviewjs escape hatch gives complete control over the dataset when the codeblock is not enough, and the README states that the notes stay the database, with no account and no cloud.
