# Feng6611/Obsidian-open-in-Teminal

Obsidian plugin that adds command palette entries for opening the current vault in a configured terminal application. Optional per-tool commands launch Claude Code, Codex cli, Cursor cli, Gemini cli or OpenCode in that same terminal application, and optional Git commands run a commit-and-push or a pull from the vault root. Settings hold the terminal application name per platform, an option to use the active note's folder as the working directory, and macOS app-instance behaviour.
