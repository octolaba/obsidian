# omeyenburg/obsidian-scrolling

Scrolling collects several optional scrolling and navigation behaviours for Obsidian, each configurable in the plugin settings. They include keeping the text cursor near the centre of the view while editing, comparable to a typewriter mode, with a configurable trigger distance and animation smoothness; disabling code wrapping so code blocks scroll horizontally in source and preview; saving the scroll or cursor position when a file is closed and restoring it later for Markdown files, PDFs and canvases; and making long inline MathJax and the file tree scroll horizontally. Further options cover zooming an image by holding Ctrl and scrolling, which the README marks as desktop only and only before Obsidian 1.13, a maximum line width, scrollbar visibility, Vim-like keybinds in reading mode, and mouse and touchpad scroll speed.
