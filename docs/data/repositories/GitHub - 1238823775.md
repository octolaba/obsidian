# wrongvibe/folder-accents

Folder Accents changes Obsidian's accent colour according to the folder of the note being opened, and is presented as a companion plugin for the COLOURS theme, whose whole palette derives from the --color-accent variable. Folders are mapped to colours in the settings tab with a folder search and a colour picker, subfolders inherit from a mapped parent, and where several mappings could apply the longest matching path wins regardless of settings order. The colour changes as soon as the active file changes, and mappings can be exported to and imported from JSON. The README states the plugin works by injecting a CSS override on the body element and might work with any theme that respects --color-accent.
