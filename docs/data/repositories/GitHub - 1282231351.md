# Subhash3/obsidian-plugin-media-grid

Media grid is an Obsidian plugin that wraps embedded media in a grid or flexbox layout from a media-grid code block listing the files. The block accepts a column count, a gap and a container id; when the column count is omitted the plugin falls back to a flexbox layout where a blank line starts a new row. It renders JPG, JPEG, PNG and WEBP images and MP4 video, and anything else produces an error callout. The README warns that the format is derived from the file extension rather than file metadata.
