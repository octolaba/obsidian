# mattmaiorana/daily-checklist

The repository holds Daily Checklist, an Obsidian plugin that keeps a daily routine checklist in the right sidebar so items can be ticked without leaving the active note. An edit mode adds, renames, deletes and reorders items by dragging on desktop, and checked state clears when the local date rolls over. Checked items can optionally be written into today's daily note inside a callout whose type, title and fold state are configurable; the README states that the plugin touches only today's note, only after an explicit checklist change, only inside that exact callout, and only while the sync toggle is on.
