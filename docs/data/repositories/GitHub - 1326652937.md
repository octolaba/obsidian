# kfirgumay2005-hash/Trello-Sync

Keeps a Trello board and a note in step in both directions. A mapping pairs one board with one note, and the pair is reconciled on a configurable interval, thirty seconds by default, or on demand from a ribbon button. Adding a checkbox to the note creates a new card on the board, while the id written beside each existing card is what keeps the two sides matched and has to be left in place. Connecting requires an API key and token from a Trello app created by the user.
