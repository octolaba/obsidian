# chenxiccc/obsidian-auto-download-images-after-web-clipping

An Obsidian plugin that downloads the remote images left behind by the Obsidian Web Clipper and rewrites the note to point at the local copies. It watches for new clipped Markdown files — the Clippings folder by default, plus any folder added in settings — downloads images in the background, and handles both Markdown image syntax and HTML img tags, using the page source URL from frontmatter as a Referer to get past CDN hotlink protection. Save location follows Obsidian's attachment settings or one of three custom modes, and filenames are built from tokens such as the note basename, a zero-padded index and a date. The README states that it is desktop-only because it uses the Node.js https module.
