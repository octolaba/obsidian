# limpido/obsidian-tree-diagram

This plugin converts tab-indented text inside a codeblock into a tree diagram drawn with box-drawing characters. The README shows an indented directory listing as the input and the branching diagram as the output, and gives installation both from Obsidian's community plugin browser and from the repository's latest release.
