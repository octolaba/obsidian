# nightfall-yl/obsidian-imgbox-pro

ImgBox Pro manages images and attachments in an Obsidian vault on both desktop and mobile, combining localization, cleanup and preview interaction in one plugin for notes that accumulate many attachments. Localization downloads web images and handles pasted, dragged and base64 media, while attachment organisation covers several save locations and link styles, a timestamp-and-hash naming pattern, and deduplication configured separately for images and other attachments. Cleanup commands find unused images, unused attachments and unlinked attachments in the current note's folder. Desktop interaction adds a context menu, click-to-preview and navigator highlighting while mobile falls back to Obsidian's own image viewer, a Go to Source Note action jumps from an image back to the note that uses it, and the settings and command names follow Obsidian's display language.
