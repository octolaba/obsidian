# trenta3/obsidian-hotkeys-chords

The repository holds Hotkeys Chords, an Obsidian plugin that binds a sequence of key presses, rather than a single combination, to a command. Its README gives Emacs-style sequences as the motivation and records that any available command can be bound in the plugin's configuration pane, including commands contributed by other plugins. The author states that little time is available for the project; the catalog records the repository as a fork licensed under the GNU GPL version 3.
