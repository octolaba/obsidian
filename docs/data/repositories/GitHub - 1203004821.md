# SDS-Mode/ai-annotate

Obsidian plugin for inline editing with a language model: instructions are written in natural language into the note as inline markers or applied to a selection, and the proposed changes are reviewed, accepted or rejected in a track-changes style interface. It needs no API key, spawning the Claude Code command-line tool as a local process against an existing subscription. The README states the plugin itself makes no network requests and that note content reaches Anthropic's servers only through that CLI, and it requires desktop Obsidian 1.5.0 or later with the CLI installed and authenticated.
