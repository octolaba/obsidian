# aqeja/ClipperMaster-for-Obsidian

This plugin receives structured data extracted by the ClipperMaster Chrome extension and stores it in Obsidian, converting the extracted text and images into Markdown notes. Storage can follow a template so that saved content keeps a fixed structure. The README describes the installation as two steps, the Chrome extension from the Chrome Web Store and this plugin from the community plugins browser, after which a port is obtained or changed in the plugin settings so the two can talk to each other.
