# ShockThunder/improved-random-note

Opens a random note from the vault without requiring an intermediate search term, optionally in a new pane. Folders can be excluded from the selection, which the README suggests for archives, templates and other service folders, and the selection can be restricted to notes carrying a given tag in combination with those exclusions. The README states that the plugin was developed for one specific second-brain project.
