# lynchjames/obsidian-mind-map

The repository holds Obsidian Mind Map, a plugin that displays a Markdown note as a mind map rendered with Markmap. Its README records a command that opens the mind map preview for the current note and a preview pane that follows the pane selection, in the manner of the local graph, outline and backlink panes. The preview's more-options menu carries a pin control that fixes the map to the current note so other notes can be selected without changing it.
