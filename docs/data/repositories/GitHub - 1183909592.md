# oamadorr/eisenhower-matrix-obsidian

Eisenhower Matrix sorts tasks into four quadrants — Do Now, Schedule, Delegate and Eliminate — from the Urgent and Important toggles set when a task is entered. The README states that tasks are stored as a readable Eisenhower Matrix.md file in the vault so they remain visible to search, backlinks and Dataview, and that they can be edited in place, dragged between quadrants and reordered within one. Schedule tasks prompt for a due date with quick options such as Tomorrow, +7 days and +30 days and are flagged when overdue, while Delegate tasks prompt for an assignee with autocompletion from previously used names.
