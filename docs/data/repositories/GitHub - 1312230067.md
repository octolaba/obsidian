# polygonhunter/barosaurus

Barosaurus is a command bar returning notes, commands, open tabs, headings, bookmarks, folders and tags in one grouped list, where each result can be acted on rather than only opened: rename, move, copy a link, bookmark, append to today's note or delete. Multi-step actions stay inside the bar, so moving a note opens a folder picker and setting a property asks for a name and then a value, each with a breadcrumb back to where the flow began. Ranking reacts to context, lifting commands that act on a selection while text is selected, and weighs how often and how recently an entry was used; commands from every installed plugin appear, some with added names, icons and synonyms. It ships with no hotkey assigned and is opened from a ribbon icon, an optional double tap of shift, or a shortcut the user sets.
