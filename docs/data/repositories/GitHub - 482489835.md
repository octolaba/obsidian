# LastKnightCoder/obsidian-notion-video

The repository holds an Obsidian plugin that embeds a video held in Notion by way of the Notion API. Its README records that an integration secret is entered in the plugin settings, after which commands in the palette prompt for a block identifier and insert the content of that block into the note. It states the prerequisite plainly: the page holding the content, or a parent of it, has to be shared with the integration that was created.
