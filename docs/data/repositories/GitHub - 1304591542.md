# SVM0N/obsidian-inline-graph

The recorded description says the plugin renders inline force-directed node graphs from gr code blocks. Per the README a fenced block with the language gr declares edges as pairs of node ids joined by a dash for undirected links or an arrow for directed ones, with optional per-node metadata for name, colour and tooltip text and an optional height directive on the first line; missing parts fall back to defaults. The rendered graph animates and settles on its own, nodes can be dragged to reheat the simulation and hovered to expand and show their text, and colours follow the light or dark Obsidian theme through CSS variables. The README states that it has no dependencies and no build step, works on mobile, and is currently installed manually.
