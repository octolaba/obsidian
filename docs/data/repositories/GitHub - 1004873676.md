# chrishoward-projects/sourcemode-styling

Repository for Source Mode Styling, an Obsidian plugin that applies a monospace, raw-text look to source mode so it is easier to tell apart from Live Preview. The README describes detection of monospace fonts available on the system, styling changes that apply as they are set, an option to keep the active theme's colours, and use on desktop and mobile. Options are configured in the plugin's settings tab.
