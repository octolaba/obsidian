# vkostyanetsky/ObsidianTimesheet

This plugin generates timesheets from tasks logged in daily notes. The README's example assumes lines carrying a time range, a description and an issue key in the style of a JIRA project prefix; the plugin groups those lines by issue, rounds up the time spent and prints a report where a timesheet code block is placed. A sheet type is added in the plugin's settings before use, and a sample vault carries further examples.
