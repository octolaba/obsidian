# vkostyanetsky/ObsidianTimesheet

Obsidian Timesheet generates reports from task time ranges recorded in daily notes, grouping entries by issue numbers such as JIRA keys. A configurable timesheet code block can round and total time for each task, and a query block can report across a date range.
