# Andre-Diamond/note-metrics

Daily Note Dashboard is an Obsidian plugin that parses daily notes and turns their checkboxes and tags into charts. Checkbox completions are read from specified headings, with matching at an exact level or any level and entries ending in a numbered task normalized into one group, while tags are parsed as grouped tags of the form group and item, plain tags and emoji tags, with URL fragments and code skipped as false positives. The dashboard filters by weekly, monthly or yearly periods that auto-populate from the notes, refreshes on demand, limits scanning to selected folders or the whole vault, and exports the selected period's checkbox, tag and daily activity data to a CSV file in the vault.
