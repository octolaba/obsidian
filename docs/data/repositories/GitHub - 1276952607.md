# johncattrall/burnish

Burnish sends the current note or selection to an LLM, applies a cleanup action, and always shows a per-hunk diff that is accepted or rejected before anything is written; applying counts as a single undo step and code, math, embeds and frontmatter are protected from changes. Built-in presets such as Tidy and Restructure share one mechanism with user-written prompts, each able to carry a hotkey, a command and a context-menu entry, and prompts expand variables for title, date, selection, path, frontmatter keys and grit. Grit levels — light, medium and deep — control how aggressively the note is rewritten, and per-folder defaults set a different action or model by path glob. Further actions merge several people's meeting notes into one structured note, flagging conflicts and keeping unmergeable text verbatim in an appendix, and generate Mermaid diagrams and Markdown tables.
