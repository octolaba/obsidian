# TreyMeyers/obsidian-chorded-hotkeys

Obsidian plugin that triggers text insertion, template insertion or command execution when several letters are typed at the same time. A chord is a set of keys pressed simultaneously in any order, presented as a way to reach frequent actions without modifier keys; a chord is created in the settings tab, where the first field holds the trigger keys, best kept to between two and four letters, and the second holds a value interpreted according to the chord type. The README warns that the plugin works through text replacement and advises creating a backup of the vault before installing it.
