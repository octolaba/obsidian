# kometenstaub/metadata-extractor

Metadata Extractor writes Obsidian vault metadata that is otherwise reachable only through a plugin onto disk, so third-party applications such as launchers or graph analysis software can read it. It produces four JSON exports, which can also run on a schedule: one mapping each tag to its count and the file paths carrying it, one holding per-note metadata such as file name, relative path, tags, headings, aliases, links, backlinks and frontmatter, and further exports documented alongside them. The README gives the TypeScript interfaces for the exported shapes and links a guide on controlling Obsidian from a third-party application.
