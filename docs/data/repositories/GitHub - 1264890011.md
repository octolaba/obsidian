# CVERInc/obsidian-tugtile

The repository holds tugtile, an Obsidian plugin that lays a Markdown note out as a table of cards: every task-list item becomes a tile that can be dragged, and every second-level heading becomes the lane the tiles line up in. Its README stresses that the board is a plain Markdown file in both directions, since moving a tile rewrites the file and editing the file updates the board, so nothing is held in a database or a proprietary format. It also records that boards from the unmaintained obsidian-kanban plugin open directly, keeping their frontmatter, task-list cards, settings comment block and archive marker until a board is upgraded, and lists undo and redo, an editor built for phones and tablets, and active maintenance as what it adds.
