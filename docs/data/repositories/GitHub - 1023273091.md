# dannns/obsidian-table-checkbox-renderer

Table Checkbox Renderer makes checkboxes inside Markdown tables interactive in Reading Mode: clicking one updates the underlying Markdown source, so the rendered table and the file stay in sync. The README states that each rendered checkbox is matched to its source counterpart through a global index within the row, so multiple checkboxes per cell and per row are supported and any table layout works. In Edit Mode a CodeMirror extension decorates the checkboxes and allows toggling them directly in the editor.
