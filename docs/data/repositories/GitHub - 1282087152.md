# dark72147/3d-model-viewer

3D Model Viewer previews local 3D model files inside Obsidian notes, supporting STL, OBJ and 3MF with automatic centering and scaling. The README records mouse-drag rotation, wheel zoom, a view cube for switching view direction and in-plane 90 degree rotation controls, plus a command that inserts a viewer code block for a chosen model file. STEP and STP files are documented as CAD solid formats that must be converted first, and an older viewer block name is still accepted.
