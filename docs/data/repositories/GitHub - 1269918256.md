# kefate/obsidian-explorer-stepper

Explorer Stepper adds two commands that open the previous or next file in the folder of the active file. The README states that all direct child files count, including Markdown, images, PDFs and Canvas, that names are sorted with locale-aware natural ordering so file2 precedes file10, that nested folders are not scanned, and that navigation stops at the first and last file rather than wrapping, showing a notice instead. No default hotkeys are provided, deliberately, to avoid conflicts, and the interface uses Chinese when the Obsidian locale starts with zh and English otherwise.
