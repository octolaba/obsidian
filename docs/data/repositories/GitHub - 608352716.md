# snsvrno/snsvrno-short-tags

Tag Formatter changes the way tags are displayed in preview mode. It can hide the leading hash character, hide the parents of nested tags, hide all parent tags, and hide portions of a tag matched by a pattern. It can also add a CSS class for every shortened tag according to its definition, for every tag based on its parents, and for all tags, so the shortened display can be styled further.
