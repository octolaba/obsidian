# guoang/obsidian-vim-keynav

Vim KeyNav brings vim-style keyboard navigation to Obsidian's reading mode and built-in web browser, where the app's own vim key bindings do not apply because they only work in edit mode. The documented keys scroll with j and k, jump to top and bottom with gg and G, move by half pages with Ctrl+d, Ctrl+f, Ctrl+u and Ctrl+b, switch tabs with H and L, move through history with Ctrl+o and Ctrl+i, open in-page search with slash, and show Vimium-style link hints with f or s using home-row labels that grow to two characters past twenty links. For webview tabs the README says keys are intercepted through Electron's before-input-event and scroll actions are translated into native browser scroll events, and that the bindings are disabled while a text field, search box or editor has focus.
