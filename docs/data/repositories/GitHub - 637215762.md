# glovguy/obsidian-gpt-zettelkasten

This repository holds Zettelkasten LLM Tools, an Obsidian plugin applying large language models to Zettelkasten note-taking. It generates embedding vectors for a note and indexes them, then searches semantically for notes similar to the current one; a batch modal indexes many notes at once from comma-separated filename patterns that accept an asterisk as a wildcard, listing the matched paths for review first and skipping notes whose text has not changed since their last embedding. A copilot panel in the right sidebar suggests revisions to the open note, focused on clear titles, a single focused idea, relevant links and connections and appropriate tags, and proposes how to split a note that would be better as several. Embeddings are requested from OpenAI and stored in a local index, so an OpenAI API key is entered in the settings alongside an Anthropic key.
