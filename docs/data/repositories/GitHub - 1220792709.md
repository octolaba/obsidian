# Jareika/ttrpg-tools-time

TTRPG Tools - Time provides fantasy calendars for tabletop campaigns and worldbuilding, with custom weekdays, months, eras, seasons, leap rules, holidays, moons, and optional exact time. It includes day and event views, recurring events, vertical or horizontal timelines, tag filtering, embedded timeline blocks, and a control pane for calendar actions. Weather packs and lightweight per-calendar time controls support generated weather, manual overrides, and automatic day rollover.
