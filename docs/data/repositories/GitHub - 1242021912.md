# zgfdada/created-daily-note-sync

The repository holds Created Daily Note Sync, an Obsidian plugin that creates missing daily notes from the created field in a note's frontmatter. It watches Markdown file changes, reads that date in several accepted formats while skipping invalid ones, and creates the matching daily note when it does not exist; a command palette action and file explorer menu entries run a full vault scan or process the current file. The README states that the plugin reads Obsidian's built-in Daily Notes configuration first and falls back to its own settings, and that its notices, commands and settings interface are in Chinese.
