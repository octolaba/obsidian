# charliecm/obsidian-upcoming

Upcoming opens future, and optionally past, daily notes in their own panes, tabs or windows so that several days can be seen at once. The command for opening them works relative to the daily note in the active pane, or starts from today when no daily note is active, and a second command closes everything the plugin opened. The README recommends reviewing the plugin settings before the commands are used.
