# javalent/markdown-attributes

Markdown Attributes lets Pandoc-style attributes be added to elements in Obsidian by surrounding the attribute name and value in curly braces. The README records support for inline text such as italics, bold and highlights, paragraphs, headers, tables and individual table cells, both wikilinks and Markdown links, lists and list items, code blocks, block quotes and callouts. It describes the plugin as a proof of concept that is stable but may produce rendering errors, states that its documentation has moved to an external site, and records the project as being in maintenance mode where pull requests and bugs are reviewed but feature requests are not worked.
