# o1xhack/obsidian-daily-note-plus

Daily Note Plus creates missing daily notes across a selected date range instead of opening each date by hand, using the folder, format and template configured in Daily Notes or Periodic Notes. It checks existing notes by the full path relative to the daily note folder and parses that path with the full date format, so nested formats are resolved correctly rather than read from the final file name alone. A backfill command opens a modal with quick presets for the last 7 and 30 days and this or last month, live range statistics, clamping of future end dates and a disabled confirmation for invalid or empty work; backfilling more than seven older notes creates today's note first and asks for confirmation. Optional creation at startup and a configurable daily scheduling time on desktop are also described.
