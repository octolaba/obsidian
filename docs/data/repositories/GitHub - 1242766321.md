# joshua-walls/forge

Maintenance tooling for long-lived vaults, aimed at keeping metadata and structure predictable so Dataview queries, Bases, dashboards, templates, exports and automation keep working as the vault grows. The README lists schema validation, vault linting, frontmatter and tag normalization, bulk note update workflows, repair tools, reusable note structure validation, relationship indexes, vault exports and maintenance workflows, plus documentation and copy-ready examples installed into the vault itself. It frames the problem as drift — renamed fields, diverging tags, changed templates, missing or malformed frontmatter — and states the goal is durable consistency rather than a rigid system imposed on the user.
