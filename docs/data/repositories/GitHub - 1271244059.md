# laginae/note-reader-cosyvoice

Note Reader CosyVoice reads the current note, the current selection, or the text from the selection to the end of the note through either a local speech pipeline or an explicitly chosen online voice mode. A side panel reports the synthesis and playback phase, overall progress and a text preview, and offers pause, resume, stop, chunk navigation, five-second seeking, progress dragging and a set of speed presets. Markdown is cleaned before synthesis and mathematical notation is handled through a reading-language setting that can voice short formulas in English or Chinese or skip them entirely. It is recorded as a desktop plugin.
