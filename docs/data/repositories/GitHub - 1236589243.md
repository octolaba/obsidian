# solargate/obsidian-photo-album

This plugin displays folders of photos as grid galleries inside Obsidian notes. Its README describes an albums folder set in the plugin settings, with each subfolder acting as one album, and two commands that insert an album at the cursor either as a plain block or wrapped in a collapsible callout, both choosing the folder from a searchable modal. The inserted photoalbum code block records the album title and folder and renders in reading mode as a grid of square thumbnails sorted by modification time, newest first, where clicking a photo opens it in Obsidian's image viewer; grid columns, thumbnail size and the supported image extensions are recorded as well.
