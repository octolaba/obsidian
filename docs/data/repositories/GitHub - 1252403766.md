# qianwei4712/obsidian-word-reader

The repository holds Office Reader, a desktop-only Obsidian plugin that opens .docx, .pptx and .xlsx files inside Obsidian as read-only documents while leaving the original files unchanged. Its README states that the plugin is not an Office editor, and records local rendering of presentation text, images, common shapes, tables, themes, layouts and masters, and a bounded virtual grid for workbooks with worksheet tabs, frozen panes, merged cells, row and column sizing, number and date formats and cached formula results. Listed workflows include searching a whole workbook, inspecting hidden sheets, exporting selected ranges as TSV or Markdown, slide thumbnails with speaker notes, and workbook summary notes. The README gives Obsidian Desktop 1.12.7 or newer as the requirement.
