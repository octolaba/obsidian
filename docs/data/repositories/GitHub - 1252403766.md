# qianwei4712/obsidian-word-reader

Office Reader is a desktop-only Obsidian plugin for opening DOCX, PPTX, and XLSX files as local, read-only documents while keeping originals unchanged. It renders Word documents, presentations, and virtualized spreadsheets with search, navigation, copying, zoom, summaries, and Markdown export, and provides guidance pages for unsupported legacy formats.
