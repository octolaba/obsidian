# GoodbyeNJN/obsidian-plugin-prettier

This plugin formats Obsidian notes with Prettier, and its README states that it re-implements an earlier plugin that is no longer actively maintained and declares no open source license, adding further features. Markdown and MDX are supported, the whole content or only a selection is formatted through two commands that carry no default hotkey, and embedded code blocks in js(x), ts(x), css, scss, less, html, json and yaml are formatted as well, with the option of remapping a block's language to another. Settings cover formatting on save and on file change, frontmatter keys switch formatting and fast mode on or off for a single file, and trailing spaces removed by formatting can optionally be added back so that live preview renders correctly.
