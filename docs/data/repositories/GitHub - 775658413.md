# gapmiss/notice-logger

Obsidian plugin that logs all notices to the developer console, with an optional prefix and timestamp. The README records that it requires Obsidian 1.13.0 or later and documents installation from the community directory or by copying a release into the vault's plugin folder. Two commands enable and disable logging to the console.
