# joey-kilgore/logos-refs

Logos-refs takes references from Logos Bible Software into Obsidian, creating formatted citations with metadata and generating bibliographies for notes. Pasting a copied passage produces a formatted quote block with attribution, extracts the BibTeX citation data and writes reference notes whose metadata sits in YAML frontmatter, which the README states makes them compatible with Obsidian properties, Dataview queries and the Bases plugin. The README requires Logos to be configured to use the BibTeX citation style first, stating that copied references are otherwise not recognized by the plugin.
