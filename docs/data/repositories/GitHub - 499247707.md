# yeeshue99/SimpleDiceRoller

Simple Dice Roller searches the currently active leaf for dice formulas and either simulates or averages all of them. A formula is a number followed by the letter d, another number and an optional addition, and several dice terms may be combined into one expression that is then calculated as a single formula. The commands are run from the command palette, can be bound to hotkeys under Settings and Hotkeys, and can be exposed as ribbon icons from the plugin options; if the page holds no dice the plugin exits with an alert.
