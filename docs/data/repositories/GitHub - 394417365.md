# SMUsamaShah/Obsidian-Win98-Edition

Obsidian Windows 98 Edition is a theme that gives Obsidian a Windows 98 makeover, written out of nostalgia and, in the author's words, spite for zoomed-in modern interfaces. Its CSS takes everything from the 98.css project and some elements from packard-belle. The README also links to in-browser Windows 98 and Windows 2000 emulators offered as visual reference.
