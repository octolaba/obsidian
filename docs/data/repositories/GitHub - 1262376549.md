# AndrewUsher/obsidian-dynatrace-dql

DQL Syntax adds syntax highlighting for Dynatrace Query Language inside dql fenced code blocks, aimed at engineers and SREs who document their Dynatrace workflows in Obsidian. The README states highlighting works in reading mode with full token highlighting and a copy button, and lists what is highlighted: commands, functions, data types, keywords, named parameters, operators, quoted strings, duration literals, numbers and comments. The repository also ships ready-to-use DQL query templates in a templates directory.
