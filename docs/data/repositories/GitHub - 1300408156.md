# xcloud-ai/file-catalog

Reads the headings of a specified Markdown file and renders them as a clickable, hierarchically indented table of contents. A filecatalog code block renders the target file's contents in reading view, an internal-link reference inside the block triggers Obsidian's file autocomplete, and a command either replaces a selected reference with the generated list or inserts an empty block. Which heading levels appear (H1 to H6, H2 and H3 by default), link and static colours, font size, line height and indentation are configurable, as are hotkeys, whose conflicts are detected as they are set. The README states the plugin replaces DataviewJS filecatalog scripts and needs no Dataview dependency.
