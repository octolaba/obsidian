# wesellis/vignelli-obsidian-theme

Vignelli is a serif, rule-driven theme built on black, bone-white and gold with a teal highlighter; gold and teal stay fixed in both modes while the black and white grounds swap. Headings are set in a Bodoni stack with Georgia for reading and Courier for code, H1 sits on a gold masthead rule, horizontal rules become gold dividers, and tables use gold bars with hairline row rules, no vertical lines and tabular numerals. Callouts are faint panels with a gold left rule and a small-caps label, and syntax colors are desaturated into the same palette across reading, live preview and source mode. Six highlight tones are available by nesting bold, italic or strikethrough inside a highlight, or through the Highlightr plugin using CSS classes.
