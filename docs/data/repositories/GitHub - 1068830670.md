# nathanstorm689/outlook-event-notes

Creates a note from a Microsoft Outlook meeting or appointment when its .msg file is dragged onto the plugin's ribbon icon; if a note for that event already exists it is opened instead. Recurring items are detected and a modal asks which occurrence date to use, defaulting to today. The filename pattern and the note template are Mustache strings with access to the .msg fields plus date-formatting helpers, so slashes in the pattern create subfolders, and characters that are invalid in filenames are replaced by a configurable substitute. Everything is read from the .msg file with no Microsoft 365 or Graph API involved, and values written into YAML frontmatter are sanitised so symbols such as angle brackets and asterisks cannot break properties.
