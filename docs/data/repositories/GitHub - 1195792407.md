# matthttam/ttrpg-maps

TTRPG Maps renders an image as an interactive, pannable and zoomable map from a code block inside a note, with markers, reusable templates and distance measurement. Markers carry colors, icons with rotation, one of four shapes and a linked note whose Obsidian page preview appears on hover, and they can be dragged, edited, copied, resized and assigned to zoom-based visibility layers through a range slider. Distances are measured point to point or freehand after calibrating a scale, with unit conversion, configurable rounding and decimal places. The README states that marker state lives in sidecar files under a dot-prefixed folder so the Markdown stays clean, that maps and template sets can be exported and imported as bundles, and that map data and map identifiers can be inspected, migrated or deleted from the settings.
