# Moyf/style-context

Style Context publishes Obsidian runtime context as CSS classes and variables, including the active theme and selected vault image paths. It lets snippets reference stable image variables, apply theme-specific styles, and optionally configure a vault image as a canvas background with opacity, blend mode, filters, and layout controls.
