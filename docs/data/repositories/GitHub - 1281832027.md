# israerusan/obsidian-vault-spotlight

Vault Spotlight is a keyboard-first command centre for Obsidian covering three jobs: fuzzy search across notes, commands, headings, links, folders and open editors; workflows that restore a saved search in one keystroke; and actions applied to a result without leaving the launcher. Search modes are cycled with Tab or a configurable prefix instead of menus, recent files and open editors are boosted in ranking, and results can be narrowed with tag and property filters. The README divides the feature set between a free tier and a paid Pro tier: the action palette and two saved workflows are free, while content and heading search, links mode, unlimited workflows and batch actions are listed as Pro. Actions include opening a result, copying a Markdown link or path, renaming, batch editing, exporting and previewing.
