# siosig/obsidian-nextcloudsync

Nextcloud Sync provides bidirectional Obsidian vault synchronization using Nextcloud capabilities such as file IDs, checksums, versions, locking, and Login Flow v2, with fallback support for standard WebDAV. It uses differential change detection, recoverable trash handling, resumable chunked uploads, optimistic concurrency, and conflict or history tools to protect edits across devices.
