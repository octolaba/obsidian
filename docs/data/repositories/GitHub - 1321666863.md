# TracingOrigins/obsidian-code-viewer-plugin

Code Viewer opens code files in a dedicated read-only view with syntax highlighting produced by Obsidian's own MarkdownRenderer, so the colours follow the active theme and no external library is bundled. Over fifty extensions are registered by default, among them Python, TypeScript, JavaScript, shell, Rust and Go, and the list is editable in settings, though a change requires reloading Obsidian. An optional line-number gutter can be shown, and an edit button creates a temporary Markdown file for in-place editing, with Save and View controls that sync changes back to the source file. Settings use Obsidian's declarative settings API, the interface is available in English, Chinese and Russian, and Obsidian 1.13.0 or later is required.
