# jimparrillo/obsidian-music-catalog

This repository holds Music Catalog, an Obsidian plugin that queries music databases for CD and LP releases and saves a structured note for each one in the vault. Releases are found by scanning a UPC barcode with a USB or Bluetooth scanner or by searching on title, artist, label, composer and conductor, where composer and conductor run as separate queries whose results are merged, and results can be filtered to CD or LP only before searching. Metadata pulled from Discogs and MusicBrainz includes album title, artists, label, catalog number, release year, genre, format and cover art, and the README records tracking of physical condition on the standard vinyl grading scale and of how many copies of a release are owned.
