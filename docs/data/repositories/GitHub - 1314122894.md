# PMGWork/obsidian-ligature

Replaces a typed character sequence with a Unicode symbol as soon as its final character is entered, rewriting the Markdown source itself so the substituted character remains visible outside Obsidian. Default rules cover arrows and comparison operators, and custom rules can be added, edited, enabled, disabled or deleted, with sources required to be unique and forbidden from being a prefix of another enabled source. Replacement is skipped in frontmatter, fenced and inline code, math, HTML and comments, and link destinations, and only direct single-character typing triggers it - paste, drag and drop, autocomplete, IME composition and programmatic edits do not. A single undo restores the typed source sequence; version 0.1.0 requires Obsidian 1.8.7 or later and supports desktop, iOS and Android.
