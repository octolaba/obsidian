# DyllonWright/Wikipedia-To-Obsidian-Markdown

Advanced Wikipedia Importer turns a Wikipedia article into an Obsidian note: the reader picks the sections to keep, images are downloaded and renamed to a chosen convention, tables are flattened, and references are preserved as real footnotes. The README states that the plugin is self-contained — no server, no account, nothing to install beyond the plugin itself — and that the Gemini API is optional and used for image naming. Its author describes the plugin as having begun as a film diary, with the aim of capturing an article into the vault instead of leaving it in a browser tab.
