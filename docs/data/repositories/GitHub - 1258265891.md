# martinowong/obsidian-section-meter

Section Writing Stats places a continuously updated badge beside the note title and each Markdown heading showing word count, character count, estimated reading time and progress toward a writing target. The README defines how a section is counted: it begins at a heading and ends immediately before the next heading of the same or a higher level, so a parent heading includes its nested subsections while each subsection counts only itself. Targets in words, characters or reading time are set for the whole note or the current section through command palette entries and stored as ordinary target lines in the Markdown, so they stay visible and portable. Which statistics and labels appear, and whether they show beside headings, in the note title or in the status bar, are configurable.
