# martinowong/obsidian-section-meter

Section Writing Stats displays live word counts, character counts, reading-time estimates, and writing-target progress beside note titles or Markdown headings. It understands nested section boundaries, stores targets as ordinary lines, excludes frontmatter, code, embeds, comments, and target lines from counts, and offers configurable badges and units.
