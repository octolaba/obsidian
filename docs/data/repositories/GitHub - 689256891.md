# Yanis-Gerst/latex-autocomplete

The repository records no description; its README presents a LaTeX auto-completion plugin that suggests commands as they are typed. Typing a backslash followed by the start of a command shows the suggestions. The README lists auto-completion as the only implemented feature and records a shortcut expansion, turning a slash-separated pair into a fraction, as work in progress.
