# tcyeee/obsidian-link-trace

Obsidian plugin that exports and shares a note as a standalone web page, either as a local ZIP package or published to a cloud bucket. From a share icon in the status bar a note becomes either a short link served from the user's own Aliyun OSS or Tencent COS bucket, with page-view tracking and the link copied to the clipboard, or a self-contained package of HTML, CSS and images that opens in any browser without a server. Directly linked notes and one further level can be bundled so the reader can navigate between pages. The rendering covers KaTeX math, highlighted code blocks with a copy button, foldable callouts, responsive tables, image galleries with a lightbox, Dataview queries as static tables or lists, and Obsidian Bases as tables or cards, alongside a generated table-of-contents sidebar.
