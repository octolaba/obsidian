# cmoskvitin/obsidian-prozen

The repository holds ProZen, an Obsidian plugin that puts the active tab into a fullscreen mode with the interface removed: panels, icons and even the scrollbar are gone while it is on. Its README also records an optional vignette that dims the sides of the screen for readers who want the text narrowed further. It records that the plugin was not yet in the community gallery at the time of writing, so installation meant copying a release's files into the vault's plugin folder, and it is licensed under the GNU GPL version 3.
