# arturtupiassu/emoji-title-plugin

Obsidian Emoji Title Plugin displays an emoji next to note and folder titles in the File Explorer and in active tabs. The README states that the emoji is resolved in priority order — an emoji or icon field in the note's frontmatter, then inheritance from a folder note configured to apply to its children, then a default per file type such as Markdown, Canvas, image, PDF or spreadsheet. It also describes optional automatic creation of folder notes, suppression of emoji injection while a file is being renamed so the emoji is not captured into the new name, and debounced rendering for large vaults.
