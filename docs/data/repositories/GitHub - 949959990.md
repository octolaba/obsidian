# sapienskid/Lemma

Lemma is described as a flashcard plugin driven by the FSRS spaced repetition algorithm, supporting basic and cloze cards, custom study sessions, review statistics and optional CouchDB sync. Its README says the notes themselves are the decks — a tag on a note makes its content reviewable — so no separate application or data export is involved, and it shows a dashboard of decks with due counts and a review mode carrying LaTeX math support. Screenshots present desktop and mobile layouts, activity charts and a statistics panel. The README is written in a promotional register; what is recorded here is what it states the plugin does.
