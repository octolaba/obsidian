# KjellConnelly/obsidian-jsonifier

The repository holds Obsidian JSONifier, a plugin whose whole function is converting the highlighted text through JSON stringify or JSON parse. Its README records two default hotkeys for the two directions and notes that a selection has to be a valid JSON string, quotes included, for parsing to succeed. Because parsing throws on invalid input, the README suggests the same command as a way to check a JSON code block or JSON-formatted frontmatter.
