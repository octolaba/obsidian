# daniti/obsidian-line-capitalizer

Obsidian plugin that capitalizes the first letter of each line as it is typed. It detects the first letter character on a line, ignoring leading spaces or special characters, converts it to uppercase when lowercase, and preserves the cursor position; Unicode characters are handled. It works in edit mode and needs no configuration or commands beyond being enabled.
