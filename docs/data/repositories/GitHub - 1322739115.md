# binaricat/smooth-window-resize

Smooth Window Resize addresses one performance problem: resizing the Obsidian desktop window while a long note is open in Reading view, where every intermediate size triggers another expensive redraw. It combines those repeated Reading view updates into a single update once a 120 ms settling window has passed, leaving Editing view and non-Markdown views untouched. A measurement recorded upstream on Obsidian 1.13.4 under macOS, with a 150 KB note and 60 rapid size changes, reports the resize sequence falling from about 6.5 seconds to about 1.0 second with no long interface stalls. The plugin has no settings, scans nothing, makes no network requests, and disabling it restores the original behaviour immediately.
