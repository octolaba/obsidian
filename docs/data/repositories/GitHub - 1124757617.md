# ljantzen/obsidian-youtube-transcript

Fetches YouTube video transcripts into Obsidian, either inserted into the current note or written to a new file named after the video. Timestamps are embedded as clickable links back into the video at a configurable frequency, the transcript language is selectable with a fallback, and video metadata such as upload date, view count and duration can be included. Transcripts are saved as Markdown, PDF or SRT, several formats in one request, with generated cover notes for the attachments and an optional check that skips a video already present in the vault. The README describes optional cleanup and summary generation through OpenAI, Google Gemini, Anthropic Claude or a custom provider such as OpenRouter or a local model.
