# zachatrocity/md-cal-gen

This plugin generates Markdown table calendars in Obsidian and is described by its author as intentionally simple. The README shows a month view whose table has one column per weekday and a week view listing each day with its date and a notes column, and it records generation of both views, support for mobile and desktop, and customizable settings.
