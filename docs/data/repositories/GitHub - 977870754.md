# nota/gyazo-obsidian-plugin

This plugin integrates Gyazo with Obsidian so that captures can be viewed and embedded in notes. A dedicated sidebar gallery lists the captures, images can be dragged into a note, markdown for an image can be copied from hover actions, a right-click menu offers further actions, and a detail view shows a capture with its metadata including OCR. It works with free and Pro Gyazo accounts, reaching the latest ten captures on a free account and up to a hundred on Pro, and its interface is available in English and Japanese. Configuration requires an access token generated for an application in the Gyazo API settings.
