# aarongilly/obsidian-auto-properties

An Obsidian plugin that fills frontmatter properties from configurable rules: each rule watches note content and writes a value to a property when its trigger fires, and the README states that note bodies are never modified. Rule types documented include lines matched by prefix, suffix, substring or regex; content between two delimiters; content under a heading targeted by level or text; and callouts. The README lists uses such as collecting in-work tasks, highlighted material, a first image embed, word counts or create and update dates, and points at the repository wiki for full documentation.
