# maal0lan/md2html

md2html adds a command that converts the Markdown note currently open in Obsidian into an HTML file, writing it beside the note or into a configured export folder. Settings choose the export theme from light, dark or blue and the export folder. The README is written as a testing guide rather than a description of a finished plugin: it requires Python on the PATH, records the plugin still identifying itself as the Obsidian sample plugin, and documents error notices for no open Markdown file, a missing Python interpreter and a failed conversion.
