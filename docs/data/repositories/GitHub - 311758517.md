# vanadium23/obsidian-advanced-new-file

Advanced New File adds a command that first asks which folder to create a file in and then takes the rest of the path, instead of creating the note in a fixed location. A filename given with an extension is created with that exact extension, which the README illustrates with canvas, JSON and JavaScript files, while a name without one defaults to Markdown. New files are created with Obsidian's own untitled filename for consistency with the default behaviour, and the README records Note Refactor and a similar editor extension as its inspiration.
