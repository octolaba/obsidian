# sbquinlan/obsidian-handlebars

The repository holds an Obsidian plugin that adds the Handlebars template engine to notes, rendering a handlebars code block against the note's own metadata. Its README shows frontmatter values being iterated inside such a block, and records a block helper that walks the notes of the vault so Markdown can be generated from them. It states that each block is compiled and rendered independently, so a partial defined in one block is not available in another, and that the plugin is small enough to support mobile.
