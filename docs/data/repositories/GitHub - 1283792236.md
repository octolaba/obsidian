# grub-basket/SP-Classic

Stashpad Classic is a fork of the Stashpad plugin pinned to its last version compatible with Obsidian's public release, created after mainline Stashpad shipped a build that required insider-only APIs. The fork removed encryption and had later features hand-ported back so that users on the stable release were not left without the plugin. Its README records that Classic is now retired and frozen at its last release, because those APIs reached the public release, and points to the maintained Stashpad plugin instead; Stashpad itself is described there as a chat-style workspace of nested notes with optional Open Knowledge Format export.
