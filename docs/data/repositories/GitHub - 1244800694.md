# ngchenghow/obsidian-project-view

ProjectView organises Obsidian notes into projects, each with its own member folders and notes, listed as boxes in a pane above the file explorer in the left sidebar. Each project keeps a live tab group, so switching projects hides one pane and shows another rather than closing and reopening notes, preserving scroll position, cursor, undo history and the active tab; on restart only the active project's pane is rebuilt and the others are recreated on first click. A project can hold several named panes with their own remembered tabs, and a right-sidebar contents pane shows the active project's pinned notes, folders and loose notes. The README describes the plugin as desktop-focused, with its Google Drive folder synchronisation available on desktop only.
