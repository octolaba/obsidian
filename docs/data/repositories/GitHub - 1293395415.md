# raito1chi/hover-highlight

Adds a cursor glow to Obsidian Canvas by replacing the default dot background with two overlaid dot grids, a gray base layer and a lit white layer masked by a radial gradient centered on the pointer. The mask follows the cursor through linear interpolation and fades out after the cursor stops moving. Settings cover glow radius, dot brightness, follow smoothness and the fade toggle; the README states the effect activates only in Canvas and relies on requestAnimationFrame and GPU-accelerated CSS transforms.
