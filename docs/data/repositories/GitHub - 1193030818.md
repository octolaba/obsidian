# Lebenswille/zotero-lib-view

This repository holds Zotero Lib View, an enhancement of Stefano Pagliari's bibnotes that adds a library-first workflow for browsing a Zotero library inside Obsidian. Its table-style Library View reads a Better BibTeX JSON export directly, with configurable columns, sortable headers, a search covering the full record including abstract and tags, and automatic refresh when the exported JSON changes. Clicking a citation key opens the matching literature note or creates it from the configured template, and the view opens as a tab, in the right sidebar, or through a custom Obsidian URI. The README states that the plugin is vibe coded.
