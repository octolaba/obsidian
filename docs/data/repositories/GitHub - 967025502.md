# bitsofchris/openaugi-obsidian-plugin

OpenAugi is presented as a context layer between the notes of a vault and AI agents, gathering the context an agent needs and dispatching tasks against it. Context is assembled by traversing links up to three levels deep and by finding the notes that reference a note. The README states that it works with a companion MCP server for semantic search, hub discovery and structured access to vault data, and that the server is not released yet.
