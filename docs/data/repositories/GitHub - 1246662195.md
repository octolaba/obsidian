# HornatX/base-view-switcher

The repository records no description, so this note is grounded in the README alone, which is written in Chinese with an English section. It describes a Base view switcher that adds custom buttons to the toolbar of an Obsidian Base so a chosen view opens on one click instead of being selected manually. The README also documents hiding toolbar elements and counts, a default button plus custom buttons in icon or text mode, drag reordering of the buttons, and a separate button configuration per `.base` file.
