# IvanKalmar/simple-quiz

Simple Quiz runs manually written flashcards from inside a note. Cards are defined in a JSON block or, once enabled in settings, built by JavaScript through an object exposing methods to add a card and to commit the set; each card carries an identifier generated from its question when absent, left and right sides, a pool, tags, a default side and a flag for whether the sides may swap. A quiz is started from a command, a play icon, a start button in the card placeholder or an inline quiz block, and the plugin shows the current streak, the number of repeated cards and quizzes for the day, charts by month, year and card progression, and optional grouping by conditions. Mobile use is recorded as tested on Android.
