# Jareika/Simple-Timeline

Repository for a timeline plugin that renders timelines from note frontmatter. The README records two code-block languages for a calendar-style and a horizontal view, an optional integration that exposes the same views inside Obsidian Bases, and settings for image and box dimensions and other global defaults. It documents installation through BRAT and recommends enabling page preview so hover popovers work.
