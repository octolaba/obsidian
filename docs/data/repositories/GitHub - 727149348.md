# KraXen72/obsidian-emoji-autocomplete

Obsidian plugin that suggests emoji as shortcodes are typed, with optional highlighting of the matched part of a suggestion, weighting by previously used emoji, and search by emoji tag so that a descriptive word finds an emoji whose shortcode does not contain it. Further options hide emoji the operating system cannot render, remove diacritics from the query, replace flag emoji with another font, and decide whether a match is substituted immediately or kept as a shortcode rendered in preview. It is built on the gemoji list and the uFuzzy search library with a custom sorting step, and the README records it as a full replacement for, and incompatible with, the Emoji Shortcodes plugin.
