# starhunt/star-imagemaster

Star ImageMaster manages the images attached to a vault: pasted or dropped images are saved automatically into configurable folders, and a gallery command browses them in grid or list view. The README records duplicate detection through SHA-256 hashes, discovery of orphaned images that no note references any more, and link updates when an image is moved or renamed. It states that the plugin works only on files inside the vault, needs no account, calls no external service and collects no telemetry, and that it is desktop-only.
