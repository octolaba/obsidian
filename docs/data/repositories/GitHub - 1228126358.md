# denmojo/obsidian-unread-dot

Unread Dot marks newly created files with a blue dot in the file explorer and clears it the first time the file is clicked or opened, without writing anything into frontmatter or tags. State persists across restarts in the plugin's own data file and survives renaming and moving, and a folder inherits a dot while any descendant remains unread so a collapsed subtree still signals unread content. The README states that files already present when the plugin is installed are treated as read, so only files created afterwards are tracked. Extensions and path prefixes can be ignored, the context menu marks single files or whole folders read or unread, and commands clear every mark or mark the current note unread.
