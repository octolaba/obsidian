# einfachsj/obsidian-corvidae

The repository holds CORVIDAE, an Obsidian plugin that arranges a vault dashboard as a grid of boxes holding a graph, notes, web pages, terminals and tickets. Alongside the dashboard it adds a sidebar for numbered project tickets with automatic frontmatter, graph node size and colour driven from frontmatter with a custom legend, folder notes kept in sync with their folders, a link property synchronized between sibling notes, default aliases, tags, size and colour for new notes, and explorer sorting and visibility options. The README states that it requires Obsidian 1.12.7 or later, is desktop only because the browser and terminal boxes use Electron interfaces, and needs the core Web Viewer plugin for the browser boxes.
