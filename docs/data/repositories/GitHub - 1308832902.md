# Awesome-Intelligence/Amazing-Life

Organizes goals in four nested levels, from a lifetime goal down through stage, yearly and short-term goals, rolling a child's completion up into its parent's progress automatically. Goals are linked from ordinary diary writing: a line or a Markdown checkbox in a daily note carries a goal tag, which files that line into the goal's mention history, while a task-type tag classifies the task and a noteworthy tag pulls the line into weekly and monthly summaries. Dashboard, list, board, gallery and calendar views show the day's tasks, recent completions and progress per goal. Everything is kept as Markdown files in configurable daily, weekly, monthly, yearly and phase folders plus a plugin data folder, so the data stays queryable with Dataview.
