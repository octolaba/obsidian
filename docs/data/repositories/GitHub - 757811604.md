# corentin-godefroy/Obsidian-BreakPage

This plugin adds shortcuts for inserting page breaks intended for PDF exports from Obsidian. The README says the hotkey is configured in the plugin options and then typed wherever a page break should go, and that the command can also be found by typing a slash trigger. The README carries nothing beyond those instructions and two before-and-after images.
