# nbossard/obsidian-CtrlXA

Ctrl-XA cycles the item under the cursor through a list of related keywords, in the manner of the vim plugin it is modelled on: weekday names, true and false, yes and no, set and unset, yesterday, today and tomorrow, or Roman numerals. It also increases and decreases numbers and dates. The lists are filled in the plugin settings, and the cycle up and cycle down commands carry no default bindings, so hotkeys have to be assigned in the Hotkeys settings.
