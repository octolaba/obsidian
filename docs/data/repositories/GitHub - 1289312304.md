# 0libote/Codex-Usage-for-Obsidian

Codex Usage displays CodexBar-style AI coding usage data inside Obsidian using managed local helpers. The README states that this is an independent project, not an official CodexBar, Obsidian or OpenAI one, and that the MVP is desktop-only on macOS arm64 and x64 and Windows x64 because the managed executables need Node and Electron APIs unavailable on Obsidian Mobile. It shows a dashboard of quotas, credits, cost, token analytics and pace, imports local Codex session logs into a usage ledger with token counts, models, sessions, repositories, providers and daily through lifetime windows, and writes a dashboard note on each refresh that the README says excludes raw output, prompts, logs, credentials and repository paths.
