# Llewellyn500/obsidian-tether

Tether synchronises an Obsidian vault with Google Drive using the operator's own Google Cloud OAuth client and Google account rather than a shared backend. It creates a folder named after the vault inside a chosen Drive folder and keeps notes, attachments, nested folders and the vault's configuration folder there, preserving the folder structure. Pull and push are separate actions with their own commands and sidebar buttons, and the README describes the default rhythm as a push during setup, a pull when Obsidian opens and pushes of local changes on a timer. It records an in-app setup guide, sign-in flow, folder picker and sync status sidebar, and that Google requests go through Obsidian's own request API so the plugin also works on mobile.
