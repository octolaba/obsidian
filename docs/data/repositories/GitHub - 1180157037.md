# baylesj/obsidian-noctis-family

Noctis Family ports the full Noctis colour family by Liviu Schera to Obsidian, with all eleven variants selectable through the Style Settings plugin. Eight variants are dark, namely Noctis, Azureus, Sereno, Obscuro, Minimus, Bordo, Uva and Viola, and three are light, namely Lux, Hibernus and Lilac. Without Style Settings installed the theme defaults to Noctis in dark mode and Noctis Lux in light mode.
