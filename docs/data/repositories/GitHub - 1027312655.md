# rafjaf/obsidian-colored-bases-properties

Obsidian plugin that colors property values in Bases files. The README describes support for list properties rendered as multi-select pills, formula properties and inline markdown tags, across the Bases view, the file properties pane, embedded bases and markdown views. Colors are derived from a hash of each unique value so they stay consistent, and can be overridden per value in hex or HSL through a color picker.
