# Ble4K/obsidian-bookorbit-sync

This plugin performs a one-way sync of book highlights and annotations from a self-hosted BookOrbit instance into Obsidian, writing one note per book. Sync is incremental for new highlights, can be run manually or automatically, and offers custom frontmatter on synced notes plus optional extra metadata such as highlight time, colour and chapter. The README states that a self-hosted BookOrbit instance and an account on it are required, that the plugin is currently desktop only because of Android bugs, and that mobile support and excluding chosen books are the next features. It records the official Readwise plugin as the inspiration for most of its functionality.
