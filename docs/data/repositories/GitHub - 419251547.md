# bicarlsen/obsidian_html_tags_autocomplete

The repository holds an Obsidian plugin that autocompletes HTML formatting tags while typing. Its README records two working behaviours, suggesting the closing tag when an opening one is typed and skipping the cursor across a whole tag, and lists updating the matching tag when one is modified as still to come. Three navigation commands are documented, moving over a tag backward or forward and jumping to the matching tag, each available only when the cursor is inside or beside a tag; the code is licensed under the GNU GPL version 3.
