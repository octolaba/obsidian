# michaelpporter/breadcrumbs

Breadcrumbs adds typed links — up and down, next and previous, or any relationship the user defines — and builds them into a directed graph, so the vault records how notes relate and not only that they link. Relationships are read from frontmatter properties, tags, Markdown lists, naming schemes such as Dendron, Johnny.Decimal, dates and custom regex, folder notes and Dataview queries, and further implied relations are derived automatically. The structure is presented as a trail of ancestors at the top of a note, a Tree side view of everything beneath it, a Matrix view grouping incoming and outgoing relationships by type, and previous and next buttons for reading a chain in sequence. A breadcrumbs code block renders a note's neighbourhood as a tree, a Mermaid diagram or a Markmap mind-map, and the same neighbourhood exports to a native Obsidian Canvas.
