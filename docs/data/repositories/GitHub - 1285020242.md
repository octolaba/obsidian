# secum3r/table-of-content

Table of Content scans the active note for headings and inserts a clickable table of contents at its top, delimited by markers so that re-running the command updates the block in place rather than duplicating it. Two further commands generate index notes: one inside a folder listing its notes and subfolders as links, and one at the vault root listing all folders. Heading depth is configurable for each feature independently, sort order is a setting, and headings inside fenced code blocks are ignored.
