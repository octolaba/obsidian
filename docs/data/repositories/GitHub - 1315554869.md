# ssjy1919/plugins-control

Lists every installed plugin in a sortable table with its enabled state, startup delay, last change time and a note, and lets each one be switched on or off from there. A plugin can be given a delay in seconds before it loads at the next start, and disabled per device type through a deny list covering phone, tablet and desktop, so rules follow the device a vault is opened on. Notes attached to plugins are Markdown and searchable alongside plugin names, and the whole configuration of states, device rules, delays and notes can be saved and restored in one step, which is aimed at bisecting a misbehaving plugin. The interface is available in Chinese and English, and console logging is off unless enabled in the settings.
