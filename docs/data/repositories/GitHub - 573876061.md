# Holmes555/workona-to-obsidian

Workona To Obsidian imports the resources, tabs, notes and tasks held in a JSON file exported from Workona, reproducing the workspace folder structure with its resource, tab, note and task sections. Each item becomes a Markdown file rendered through a Handlebars template, either the default for that section or one supplied by the user. The README documents the default template per section along with the variables available to a custom one, among them the title, the date, the section title tags, the URL and the description.
