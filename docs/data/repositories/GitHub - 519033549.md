# CyberT17/obsidian-day-and-night

Obsidian plugin that switches automatically between a day theme and a night theme on a set time schedule. A day colour scheme and theme are paired with the time at which the light theme is applied, and a night pair with the time for the dark theme. A ribbon icon toggles between the two on the fly, which pauses automatic switching for the rest of the day; the README states that normal behaviour resumes when Obsidian is closed.
