# martinlockett/obsidian_theme

martinlockett/obsidian_theme holds the author's personal Obsidian theme, which the README states was created by Claude Code from his published personal brand guide. It uses a five-colour system of Ink Navy, Brass, Slate Teal, Parchment and Graphite in a stated ratio of roughly 60 percent Parchment, 25 percent Ink Navy, 10 percent Slate Teal and 5 percent Brass, and it sets the Fraunces and Inter fonts, which must be installed locally for the intended design. The README records that Ink Navy and Graphite pass AA contrast on Parchment while Brass is decorative only and should never carry body text.
