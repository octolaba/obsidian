# Eldritch-Oliver/file-hider

File Hider hides specific files and folders from the Obsidian file explorer. An item is hidden from its right-click menu and unhidden the same way while hidden items are visible, and the File Hider: Toggle Visibility command switches the whole hidden set between shown and hidden. A settings tab lists everything currently hidden and removes entries from that list; for a ribbon icon the README suggests binding the toggle command through a separate sidebar plugin.
