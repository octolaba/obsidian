# ozntel/oz-calendar

OZ Calendar displays notes on a calendar using a date taken either from a YAML frontmatter key or from the file name. Both the key and the date format are configurable, defaulting to a created key and a date format carrying year, month, day and time; using the file name as the source requires a format without characters that a filename cannot hold, such as a colon. The README points to the Day.js formatting documentation for the accepted patterns and notes that the plugin has to be reloaded for a settings change to take effect in the vault.
