# zhao414/canvas-smart-paste

Pastes clipboard content into an Obsidian Canvas as nodes rather than as raw text. The README, written in English and Chinese, describes copying Markdown, opening a canvas file and running one of the plugin's commands from the command palette. Settings cover the edge direction (top to bottom or left to right), whether arrow connections are drawn for heading trees, list trees and paragraphs, whether ordered-list numbering is kept, and whether nodes resize automatically to fit their content.
