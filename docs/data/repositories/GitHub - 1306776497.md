# TechR10n/stratus-obsidian-theme

Stratus is a dark-first, content-first Obsidian theme inspired by Cloudflare Docs and Cloudflare's Kumo design system, pairing a near-black canvas with orange accents, sky-blue links, deliberate spacing and restrained borders, plus a matched light appearance for daytime use. It requires no plugins and no remote assets, while an optional Style Settings panel tunes width, text size, density, accent, properties and focus chrome. The default readable column is 1000px with Comfortable, Wide and Full presets, and note helper classes cover wide, max, cards, table-100, image grids and muted or borderless callouts. Reading view, Live Preview and Source mode are styled cohesively, with extra polish for Dataview and Tasks when those plugins are installed.
