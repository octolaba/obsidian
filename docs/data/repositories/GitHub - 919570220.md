# babidisrc/obsidian-sunbather

Sunbather is a minimal pink theme for Obsidian based on the vim-sunbather theme. It can be installed from the Community Themes section under Settings, Appearance, Themes, or manually by cloning the repository into the vault's .obsidian/themes folder and selecting it there. The project is licensed under the MIT License.
