# stephanteig/obsidian-brief

Brief is a client workspace manager for Obsidian, driven from a side panel or the command palette. The active client space is switched from the status bar, the ribbon or a fuzzy switcher, each client carrying an accent colour shown as a status-bar dot and a modal banner, and commands create a client folder with an index note or set that colour. A note creator asks for a note type and metadata and writes the note with the right frontmatter into the right folder, while a dashboard note is generated per client listing all notes in its folder grouped by type. Two repair tools are documented: scanning the current note for missing or malformed frontmatter fields and fixing them, and merging a note-type template into an existing note without touching its content.
