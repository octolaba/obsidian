# bastiaanschonhage/syncist

Syncist keeps Obsidian and Todoist tasks in sync in both directions: tagging a checkbox item with a configurable tag, todoist by default, creates the task in Todoist, and indented children of a tagged task follow as subtasks without tags of their own. The README also records importing a Todoist task and its subtasks through a fuzzy-search modal, per-task project assignment, label sync through hashtags, syncist code blocks that embed live filtered task lists, compatibility with the Obsidian Tasks plugin's emoji, and a conflict setting offering Obsidian wins, Todoist wins or ask. It states that the Todoist API is called directly through Obsidian's requestUrl with no external SDK, and that the plugin was created with the help of AI and then validated and tested by a human.
