# jesterspot1-svg/zotero-highlights-sync

Zotero Highlights Sync creates book notes in Obsidian from a locally running Zotero installation and synchronizes the PDF annotations attached to them. From three user-supplied templates it produces a book note, an annotations note ordered by position in the PDF, and one atomic note per annotation carrying annotation text, Zotero comments, colors, pages and deep links back to the exact annotation. Synchronization is manual, only variables beginning with a zhs prefix are substituted, content outside the managed markers is left alone, and an annotation deleted in Zotero is marked rather than losing its note. The plugin is desktop-only, needs Zotero's local API enabled, and offers a Russian or English interface.
