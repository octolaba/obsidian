# Automatt/obsidian-pinboard-sync

Pinboard Sync fetches links recently saved to a Pinboard account and writes them into the Daily Note for the date each link was stored, along with the tags attached to it, refetching at a configured interval. Settings cover the Pinboard API token, a prefix added to imported tags, whether a newline separates the URL, description and tags, the heading under which the links are added, and whether periodic syncing runs at all. The README warns that the initial sync backfills recent posts and may create or modify up to a hundred files, and recommends testing the plugin in a new vault first.
