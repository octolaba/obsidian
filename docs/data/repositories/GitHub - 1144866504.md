# mr-pounds/code-folding

Obsidian plugin that folds code blocks. The README states that blocks of five lines or fewer are shown in full with a copy button, while longer blocks are folded at a configurable threshold and expand or collapse when the block header is clicked. Its stated principles are to change nothing beyond code block folding and to use Obsidian's native CSS variables so it works with any theme.
