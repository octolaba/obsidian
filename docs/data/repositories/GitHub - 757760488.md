# wrenger/obsidian-languagetool

The LanguageTool plugin is described as integrating LanguageTool into Obsidian for grammar and spell checking. Its README presents the project as a fork of an earlier plugin, adding synonyms and a mother tongue setting, a tooltip button for disabling rules, note-specific settings, and bug fixes. Commands check the whole document or a selection, clear the underlines left behind, and toggle automatic checking while writing; clicking an underlined word opens suggestions and can add the word to a personal dictionary. The README advises anyone concerned about the privacy of their notes to self-host LanguageTool and change the configured link accordingly.
