# usero2/obsidian-plugins-epub-reader-with-tts

Obsidian EPUB Reader with TTS opens .epub files inside Obsidian with a table-of-contents sidebar, in-book search, a choice of continuous scrolling or per-chapter pagination, and a remembered reading position per book. The README states that text-to-speech uses the operating system's own offline voices, highlights the sentence being spoken and scrolls it into view, starts from the sentence clicked, and allows speed changes from 0.5x to 3.0x during playback. While speech is active, the previous and next buttons step the audio by one sentence or paragraph instead of turning pages.
