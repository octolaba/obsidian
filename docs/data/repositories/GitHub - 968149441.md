# Jacobinwwey/obsidian-NotEMD

Notemd is an open-source Obsidian plugin that connects more than 30 large language models to a knowledge-base workflow. It processes notes into internal links, concept notes, research summaries, translations, Mermaid diagrams, and other material written back into the vault for a persistent, searchable knowledge graph.
