# LeMathMath/Obsidian_MM-Clean-Headers

MM Clean Headers rewrites heading text in an Obsidian note so that headings follow one capitalization convention. A hotkey toggles between a sentence style, which capitalizes the first word and lowercases the rest, and an Associated Press style, which capitalizes further words too. Formatting can be applied to header levels individually or as a group, to the current note or across the whole vault, and settings add a third formatting option that the plugin flags with a warning.
