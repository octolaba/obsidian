# st3v3nmw/obsidian-spaced-repetition

Obsidian plugin for reviewing flashcards and whole notes on a spaced repetition schedule, using either the FSRS or the SM-2 algorithm. Cards are written inside ordinary notes in single-line, reversed, multi-line or cloze formats, inherit Obsidian's rich text including images, audio, video, LaTeX, code highlighting and footnotes, and take automatic context titles from the note's headings. Decks are organised through hierarchical tags or the folder structure, notes themselves can be queued and reviewed as well as cards, and a statistics view reports on the result. The README records that the community has translated the plugin into fifteen languages.
