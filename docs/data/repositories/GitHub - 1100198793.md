# yinfi/baizer

Baizer is an AI workbench for Obsidian built around a capture, process, remember and consume loop driven by one model runtime. It saves web pages as Markdown with YAML frontmatter through Readability, turns YouTube and Bilibili URLs into summarized transcripts, and runs a live web search when the vault has no answer. Processing happens in a streaming tool-using chat, an inline ghost-text co-writer, selection actions such as polish, proofread, translate, expand, summarize and explain, and a knowledge wiki compiled from chosen folders. Its memory layer stores world, experience and observation records with positive or negative polarity and recalls them into later chat turns, completions and selection actions, alongside citations to the compiled wiki.
