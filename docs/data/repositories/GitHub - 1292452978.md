# kebl3541/Obsidian-PDF-Highlight-Notes

PDF Highlight Notes lets PDFs be imported, read and highlighted inside the vault, using Obsidian's built-in viewer. Selecting a passage raises a small floating toolbar with two independent actions: a highlight that paints permanent marker ink into the PDF file itself in yellow, green, pink or blue, visible in any other PDF reader, and a save-quote action that copies the passage into a companion highlights note with a deep link reopening the PDF at that passage. The README states that the save-quote path leaves the PDF file unmodified.
