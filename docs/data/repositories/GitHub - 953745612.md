# heymoosh/ticktick-quick-add-obsidian

TickTick Quick Add Task sends the line or paragraph at the cursor to TickTick as a new task, on desktop and on iOS and Android. The README records what the command does: it appends a TickTick tag and a unique block anchor to the text in the note, creates the task with that text as its title, and puts an Advanced URI link in the task body that opens the note at that exact block. It names two prerequisites, the Advanced URI community plugin for the link back to work and a TickTick account with API credentials, and documents installation from the community directory, through BRAT for pre-release versions, or by hand on mobile.
