# chenfeicqq/obsidian-attachment-manager

Obsidian plugin that binds an attachment folder to the note it belongs to and keeps the two in step. It renames pasted images, renames the attachment folder and the attachment files, deletes the attachment folder, can hide or show attachment folders, and downloads remote images from the open Markdown or canvas note into the attachment folder. The README warns that the plugin overwrites two Obsidian settings, the new link format and the default location for new attachments, and restores them when it is disabled.
