# ckep1/obsidian-autopause

AutoPause pauses or resets other playing audio when a new clip starts, keeping one audio stream active at a time. Hotkeys can move to the next or previous audio, toggle playback globally, and resume the last paused clip, with an option to prevent keyboard focus on players across tabs and devices.
