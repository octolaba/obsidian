# amanetoki7/mouse-tooltip-translator

This repository holds Mouse Tooltip Translator, an Obsidian plugin inspired by the Chrome extension of the same name that shows a translation in a tooltip on hover. Translation can be triggered by mouseover, by text selection or both, applied per word or per sentence, or run over a whole page in Reading View with a progress bar and a restore command; nine engines are recorded, among them Google, DeepL, Bing, Yandex, Papago and OpenAI-compatible or local models through Ollama and LM Studio, each assignable per context. The README also records auto-detection of the source language, dictionary entries with parts of speech, transliteration, an in-memory cache, options to hide tooltips when the languages or the texts match, and a sidebar vocabulary book that accumulates every lookup for sorted review.
