# turnercore/s3agle

S3agle manages files attached to notes using S3-compatible storage, the local Eagle file-management application, or both, and is based on the S3 Image Uploader plugin. It is configured with the S3 access key, secret, region, bucket and optional folder, and with the address of a running Eagle instance; a file dragged or pasted into a note is then uploaded and a preview link inserted according to those settings. Commands upload every file in a note without removing it from the vault, and download previously uploaded S3 files back into the vault, adding them to Eagle when it is in use. The README notes that using Eagle alone, without S3, currently breaks most ways of previewing the files, which is why it recommends S3.
