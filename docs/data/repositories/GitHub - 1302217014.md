# israerusan/unwritten

Unwritten reads a vault's link graph and writes one note, a gap report, listing places where notes point at something that was never written; it is described as part of the Second Read suite. The README names three heuristics: unexplained pairs, where two notes are repeatedly linked from the same places and no short note links to both; stub hubs, where eight or more notes point at a note of about a hundred and twenty words or fewer; and decisions marked in frontmatter that state no reason. The report itself opens by saying it is a prompt rather than a task list, because the heuristics are computed from links, word counts and frontmatter alone, and every threshold is a setting.
