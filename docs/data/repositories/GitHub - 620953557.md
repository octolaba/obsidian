# April-Gras/obsidian-auto-timelines

Obsidian plugin that generates timelines from tagged notes, written with story telling in mind and described as theme agnostic. A note opts in through frontmatter keys giving a required start date, an optional end date, a render flag, and the names of the timelines it belongs to; a code block naming one or more timelines then scans the vault and renders a card for each matching note. The README supplies a sample vault of basic examples and links a community tutorial video covering the same ground.
