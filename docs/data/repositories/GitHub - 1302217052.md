# israerusan/prior-art

Prior Art surfaces existing notes that resemble the one being written, so a near-duplicate is noticed before it is written again. The README states that a sidebar panel watches a note being captured — created in the last 30 minutes, still under 400 characters, or sitting in an inbox folder, all configurable — and lists up to five existing notes labelled as probable duplicates or merely similar, querying 400 ms after typing stops and discarding answers overtaken by a newer query. Each card offers opening the existing note side by side, appending the new note's body into it, or redirecting, which adds the new note's name to the existing note's aliases and replaces its body with a pointer. The README records that the plugin never edits a note on its own and that trashing an emptied duplicate is confirmed twice.
