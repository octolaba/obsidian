# Unarray/file-tree-generator

Generates a tree of files and folders and inserts it into a note as nested Obsidian callouts, started from a command or a ribbon icon. Files and folders can be excluded by patterns that follow the gitignore specification and are configured in the settings tab. The README states that the plugin reads the local directory through the file system, so it works on desktop only, and that a desktop button next to the path input imports a folder.
