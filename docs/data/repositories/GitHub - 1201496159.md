# mm0x1/obsidian-autism-task-planner

An Obsidian plugin that reads a Markdown task list from the active note and shows it in a sidebar panel as a sequenced schedule of cards, each with a start time computed from the durations of the tasks before it. Tasks are written as a line with a name, a duration such as 5m, 2h or 1h30m, and an optional trailing category tag, defaulting to zero minutes and the "other" category when those are absent. Cards can be dragged to reorder, durations and categories edited in place, and tasks marked done, with the schedule recalculating each time; the panel takes a custom start time or the current time and shows total duration and estimated finish. The repository carries no description.
