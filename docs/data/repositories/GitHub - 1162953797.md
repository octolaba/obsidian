# jotbirdhq/obsidian-jotbird

JotBird publishes a note from an Obsidian vault as a shareable web page, started from the ribbon icon, the command palette or the file menu. Local images are uploaded and embedded, callouts and Mermaid diagrams render on the published page, and republishing the same note updates the existing page at the same address. Published addresses and expiration dates are written into the note's properties, and further commands list published documents, unpublish a note and copy its link. The README states that links last thirty days without an account, ninety days with a free account and permanently on the paid tier, and that a page's theme, branding and password protection can be changed from Obsidian without the password being stored in the vault.
