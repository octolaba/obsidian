# tanzy226/obsidian-study-time-statistics

Study Time Statistics measures active reading time for Markdown notes and PDFs, counting opens and completed sessions per note and showing an inline strip at the top of the note with opens, total and average time, longest session, active days, current streak and last read time. The strip belongs to the view and scrolls with the note, so nothing is written into the Markdown file itself. A dashboard opened from the ribbon or command palette adds leaderboards and day, week, month, year and all-time views, with a 365-day heatmap, 30-day trends, hourly and weekday patterns, session-length distribution, folder summaries and recent sessions. A strict mode pauses tracking while Obsidian is unfocused, all statistics stay in the plugin's own folder inside the vault with no network use, and it targets Obsidian 1.13.0 or later.
