# bsbbera/atelier-obsidian

Atelier is a documentary-editorial Obsidian theme with two paper modes, a warm aged-parchment light mode and a deep excavation dark mode, sharing one copper accent and a set of antiquarian serif and handwriting fonts. Its README composes hero banners, museum plates, ledger tables, illuminated quotes, infoboxes and margin annotations out of ordinary Obsidian callouts, adds twenty-six semantic callout casts, and provides inline typography classes for magazine-style openers without additional plugins. The Style Settings plugin controls accent, fonts, width, roundness, per-element default styles and entrance animations. The README states a requirement of Obsidian 1.5.0 or later and notes that the bundled Google Fonts need internet access on first load, with a system-fonts option for offline or mobile use.
