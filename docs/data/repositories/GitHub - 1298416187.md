# opus-oss/obsidian-opus

Opus is a cold, monospace-forward Obsidian theme with a small color system: one accent for structure and the active item, teal for good, clay for warning, and little else. Headings are monospace on a fixed type scale and separate by size and weight rather than per-level color, and the same accent marks the active file, the active tab and the active table row. Three palettes named after stages of the alchemical Magnum Opus, Prima Materia, Nigredo and Citrinitas, are switched in Style Settings, each a full light and dark palette that the README states is contrast-checked. Canvas preset colors are remapped, mobile gets larger touch targets and tuned reading width, and Dataview, Kanban, Graph, Properties, tables, embeds and print are styled to match.
