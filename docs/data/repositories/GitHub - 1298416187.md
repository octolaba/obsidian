# opus-oss/obsidian-opus

Opus is a monospace-forward Obsidian theme with light and dark palettes, a restrained accent system, fixed-scale headings, and coordinated styling for code, canvas, Kanban, Dataview, Graph, Properties, tables, embeds, and print. Style Settings can switch the two flavors and configure accent, layout, measure, typography, features, OLED contrast, and mobile behavior; the theme supports Reading and Live Preview on desktop and mobile.
