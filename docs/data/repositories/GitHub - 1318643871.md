# SoulBits-Vibe/obsidian-home-launcher

Replaces Obsidian's new tab with a home page carrying a vault-wide search box, user-defined buttons, recent files and bookmarks. The search matches file names, paths, aliases, headings, tags and note bodies, returning metadata hits immediately while contents are scanned in the background, and each result shows its heading context, an excerpt and the folder. Buttons are configured rather than fixed: each has a label, a Lucide icon and one action, which can create a note, capture a line into the daily note, run any command, open a file or URL, reveal a folder, or run a saved search. Recents are tracked as notes are opened, bookmarks come from the core Bookmarks plugin, and an optional quote of the day is drawn from a note of quotes.
