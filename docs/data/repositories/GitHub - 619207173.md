# White7292/obsidian-hd-unfilled-stats-highlighter

Unfilled Stats Highlighter scans notes for stats that have not been filled in yet and prefixes them with a configurable marker so they are easier to locate. The README states that the marker can be an emoji, a special character or text, that it is removed automatically once the missing information is entered, and that the plugin can be configured to target only the reader's stat files. The remainder of the README is the plugin-template material on building, manually installing and submitting an Obsidian plugin.
