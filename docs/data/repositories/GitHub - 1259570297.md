# oilandrust/obsidian-gdocs

Registers the JSON shortcut files that Google Drive sync tools leave in a vault so they appear in the file explorer and open the linked Google document, covering document, spreadsheet, slides, drawing, form, table, script and whiteboard extensions. Clicking a shortcut shows the document in an embedded browser in the current tab, and a wikilink embed renders it inline in reading mode and Live Preview on desktop. The plugin reads a document identifier, a URL or a resource identifier out of the shortcut JSON and builds the address from that value and the file extension. The README records Obsidian 1.8 or later, states the embedded browser is unavailable on mobile where copy-link and open-in-browser buttons appear instead, and warns against moving shortcut files out of a syncing Drive folder.
