# OverRaddit/ZettelGPT

This repository holds the ZettelGPT plugin for Obsidian, which generates ChatGPT answers into notes that stay linked to the question notes producing them. A question template is inserted into a new note, and generating an answer writes it in real time into a connected answer note; further questions are linked to a chosen answer note so that only the relevant conversation history is sent, which the README presents as a way to save tokens while preserving context. The linked question and answer notes are readable in Obsidian's graph view. Setup requires an OpenAI API key, use of that API may require payment, and the README states that the plugin uploads note content to OpenAI servers.
