# AdityaKhowalGithub/weekly-review-notes-linker

Weekly Review Linker is a fork of the Weekly Review plugin: instead of opening every note created in the past week, it writes a file that links to them. The README states that this helps with periodic notes, whose weekly notes are otherwise not connected in the graph, and that the rest of the plugin is unchanged from the one it forks. It is run from the command palette through the Start Review command.
