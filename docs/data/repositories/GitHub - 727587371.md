# decaf-dev/obsidian-note-splitter

Obsidian plugin that splits one note into many notes at a delimiter, described as desktop only. The note is opened in editing mode and split from a command, and the resulting notes appear in an output folder that defaults to a folder of its own, or the original note's folder when the setting is left empty. The README states that splitting does not modify the original note and that frontmatter is ignored, only the content after the frontmatter block being split.
