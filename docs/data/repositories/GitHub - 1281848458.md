# yanqingwang/obsidian-md-to-html-effect

MD to HTML Effectiveness converts an Obsidian Markdown note into a self-contained HTML file with the same basename and folder. Output includes responsive dark or light themes, inline CSS, headings, tables, code blocks, lists, links, and images, and can be opened directly in a browser; commands cover the current note or a batch folder conversion. The generated page has no external dependencies.
