# yanqingwang/obsidian-md-to-html-effect

MD to HTML Effectiveness is an Obsidian plugin that converts a Markdown note into a standalone HTML file following the html-effectiveness standard, written beside the source with the same name and folder. One command converts the active note and another batch-converts the new Markdown files in the current folder. Output is single-file with inline CSS and no external dependencies, in a dark or light theme selectable in settings, and opens directly over the file protocol. The README is written in Chinese and English.
