# linkongren/obsidian-bible-study

The repository records no description, so this note is grounded in the README alone, which is written in Chinese with an English section. Bible Study references, reads and browses the Chinese Union Version Bible inside Obsidian: an inline reference typed as `-book chapter:verse` expands with Tab or Enter, and a reading panel opened from a ribbon icon selects book and chapter from dropdowns, inserts a verse into the note on a click or copies it when no editor is open, copies the reference on a double click, moves between chapters with the arrow keys and jumps to the verse behind a reference link. Its settings cover the inline expansion toggle and its key, the default version, verse numbering, the citation format and the font size, and the README credits an external Bible dataset and a Chinese script-conversion library.
