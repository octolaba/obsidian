# linkongren/obsidian-bible-study

Bible Study helps users reference, read, and browse the Chinese Union Version Bible in Obsidian. Inline shorthand expands in two steps into linked references and verse text, while plus and minus controls adjust ranges; a sidebar reader provides book and chapter selectors, five themes, multi-reference support, smart search, and mobile-friendly triggers. Settings control expansion, translation, verse numbering, citation format, font size, and theme.
