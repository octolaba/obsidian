# karstenpedersen/obsidian-vimium

Obsidian Vimium provides keyboard shortcuts for clicking buttons in Obsidian, taking its inspiration from the Vimium extension for Chrome. A command shows markers over the clickable elements, and typing the keys of a marker clicks the element it belongs to. The CSS selectors used to find clickable elements can be edited, and the font size of the markers can be changed. The README's version history records the marker command as the content of release 1.0.0.
