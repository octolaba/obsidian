# hardes11/llm-token-count

LLM Token Count is described as showing LLM token counts for the active note in Obsidian's status bar, exact for GLM, GPT, Qwen and DeepSeek and approximate for Claude and Gemini. The README says the count appears beside Obsidian's own word and character counts so a note can be checked against a model's context window before it is sent, and that eleven models are labelled by accuracy rather than silently presented as exact, with the approximate ones derived from a scaled GPT tokenizer. A HuggingFace tokenizer is fetched once and cached locally, after which counting needs no network, while the GPT, Claude and Gemini paths need no fetch at all. The README marks the plugin desktop-only.
