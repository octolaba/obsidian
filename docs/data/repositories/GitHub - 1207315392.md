# brittain9/speech-kit-obsidian-plugin

Speech Kit provides local tools in Obsidian for live dictation, meeting transcription, translation, text-to-speech playback, and optional language refinement. It manages downloadable speech, voice, and translation models, supports multiple languages and operating systems, and lets users preview translated text before replacing or inserting it.
