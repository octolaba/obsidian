# brittain9/speech-kit-obsidian-plugin

Speech Kit, previously named Local Dictation, is a speech and language toolkit for Obsidian covering dictation with live streaming text, higher-accuracy batch transcription of meetings and other audio, reading notes aloud, and translation across eight languages. The README describes a managed catalog of speech, voice and translation models — Moonshine streaming models, Nemotron ASR, Whisper Large V3 Turbo, Pocket TTS, Supertonic and Firefox Translations among them — installed through a setup wizard that also installs a native engine, plus optional LLM text tools. It presents the aim as replacing several separate tools with one model manager, one settings surface and one set of commands inside the editor.
