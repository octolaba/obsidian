# MapleKarine/obsidian-vowel-chart

Vowel Chart is an Obsidian plugin that generates IPA-style vowel diagrams, rendered from a vowel-chart code block. The README shows the simplest form as a list of IPA vowels, and an add command that places a vowel by numerical coordinates, by keywords such as high, low, front, back and central with a near modifier, or by its position in the IPA chart, with left and right variants drawing a dot and placing the label beside it. Settings and in-block commands control whether low vowels are centralised and which of the four chart layouts is used.
