# Binxly/Atomizer

Atomizer is an Obsidian plugin that breaks a long note into smaller atomic notes using the OpenAI API, aimed at turning source material into separate ideas. An OpenAI API key is set in the settings, and the Atomize Selected Note command or a sidebar icon sends the current note for processing; each generated note receives frontmatter carrying the date and any custom tags configured in the settings. The supported models are recorded as gpt-4o-mini and gpt-4o. The README discloses that note content is sent to api.openai.com and points readers to OpenAI's privacy policy, and states that the plugin is in early development with sparse updates.
