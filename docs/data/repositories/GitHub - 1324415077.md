# gabrielbacha/Obsidian-Prose-Toolkit

Prose Toolkit adds sentence-aware editing commands and a Markdown highlight extractor to Obsidian, works locally without network requests, and requires Obsidian 1.13.0 or later. Commands delete or select to the start or end of the current sentence, move to the next sentence, select the sentence or editor line, and toggle highlight, bold or bold-highlight markup on a sentence or line, with a configurable sentence pattern. Extraction recognizes equals-sign highlights, mark tags including attributed ones and optionally bold text, copying the result to the clipboard as paragraphs or bullets, with optional heading, source footnotes, links and capitalization. It can also create a highlights note or one linked note per highlight without ever overwriting, numbering a conflicting highlights note and skipping a conflicting exploded note.
