# mixasite/obsidian-mixa

Mixa is a no-code site builder, and this plugin publishes notes and blog posts to it from Obsidian: a site is created in the Mixa dashboard, a secret token generated from its settings is pasted into the plugin, and changes are published with one click. A Show Changes button in the plugin settings lists which files would be published and which deleted before publishing, and a note can be kept back by setting a draft property in its frontmatter. The README also describes the service around it, including themes, a custom or subdomain address, site search, navigation, a table of contents and analytics, and lists Markdown, MDX and HTML as page formats.
