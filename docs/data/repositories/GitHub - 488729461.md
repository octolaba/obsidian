# mnowotnik/obsidian-user-plugins

User Plugins lets snippets and JavaScript files call the Obsidian plugin API, so that behaviour can be changed without packaging a plugin. The README gives adding custom commands and trying out an idea for a plugin as its use cases, and warns that it is for advanced users only, that a script can delete notes, and that no API function beyond the shown examples should be assumed to work. It also describes the plugin as bleeding edge, with newer versions usually requiring the newest Obsidian.
