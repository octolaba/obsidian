# ostoe/Ob-ImagePastePlugin

Pastes network or local images using standard Markdown link syntax and stores the file in a folder named after the current note, beside it, rather than in the location Obsidian's own settings would choose. A second command rewrites the wiki-style image embeds already present in a note into that Markdown form, creating the note's folder and moving the referenced files into it. The README notes a configurable relative save path with a filepath placeholder, optional link encoding, and that Obsidian does not resolve paths containing spaces the way the editor it imitates does.
