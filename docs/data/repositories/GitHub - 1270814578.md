# alas-poor-ophelia/carrel

This repository holds Carrel, an Obsidian plugin that presents a set of notes as a column-balancing board of typed reference cards. One or several folders become a browsable wall of cards that can be pinned, filtered, searched and expanded to read in place without leaving the board. Carrel runs as a full workspace pane, as an inline embed dropped into any note, and as a custom view for Obsidian Bases. The README records that it began as the References tab of the author's Wayfinder character sheet and now runs on its own, integrating with it when both are installed.
