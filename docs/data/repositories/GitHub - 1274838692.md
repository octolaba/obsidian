# q7jxb7yxdk-star/Note-Calc

This repository holds Note Calc, an Obsidian plugin that brings Apple Notes-style inline calculation into a note; the repository records no description, so this summary follows the README alone. An arithmetic expression ending in an equals sign is evaluated and its result shown in Live Preview and Reading view, while the Markdown source is left unchanged, because the calculation is visual only and the answer is never written into the note. Only lines ending in an equals sign are evaluated and a line that already carries an answer is left alone; the supported syntax covers addition, subtraction, multiplication, division, remainder, exponents, parentheses, decimal numbers and scientific notation, with the number of decimal places configurable from zero to four.
