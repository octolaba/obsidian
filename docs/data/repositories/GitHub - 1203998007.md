# EnakZzz/svg-zoom-viewer

SVG Zoom Viewer opens an embedded image in a dedicated leaf when it is double-clicked in reading view, where the mouse wheel zooms, dragging pans and a further double-click resets the transform. It handles svg, png, jpg, jpeg, webp and gif files, and renders SVG in an iframe, which the README says stays closer to native vector rendering than a plain image tag. The README states that the plugin is desktop-only, makes no network requests, collects no telemetry and needs no external account, and notes that rendering quality still depends on how Obsidian and Electron serve the source URL.
