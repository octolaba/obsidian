# scottgrayart/Frontmatter-input

Renders a frontmatterinput code block as interactive checkbox and radio lists that write tags into the note's frontmatter. Lists nest, so a child list appears only while its parent is selected and unchecking a parent removes its child tags, producing structured slash-separated tags from a selection path. Checkboxes allow multiple selections while radio buttons are exclusive, orientation is chosen per list, only unique tags are written, and the README recommends embedding the block in note templates.
