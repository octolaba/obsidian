# Koishiiko/obsidian-note-type

Note Type adds a dropdown to the Properties editor that writes a configurable frontmatter key and applies the matching template when a type is chosen, filling both properties and body content. Templates use either a built-in formatter with variables for the current date, the note's creation and modification times and its name, or Templater for more complex cases, and a default type can be applied automatically to new files. The README states that no new note syntax is introduced and credits another application for the idea of replacing a run-command-then-pick-template workflow with a dropdown.
