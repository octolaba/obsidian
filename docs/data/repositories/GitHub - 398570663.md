# yajamon/obsidian-command-alias-plugin

This plugin assigns an alias to an existing Obsidian command, so the command can be found in the palette under a name the user chooses. An alias is created by running the plugin's own add-alias command, picking the target command and naming it; aliases are removed again from the settings tab. The repository description is in Japanese, and the README gives the motivation as translated command names being helpful for understanding the intent of a command but tedious to type.
