# easonblackwood/shunn-exporter

Shunn Export writes a note out as a DOCX manuscript formatted to William Shunn's Proper Manuscript Format. The output uses Courier New, Courier or Times New Roman at 12 point, double spacing, a half-inch first-line indent and one-inch margins, with a first-page contact block and rounded word count, a running surname, title and page header from page two, and a title page. Frontmatter is stripped, several scene-break markers become a centered hash, headings become bold centered scene labels, emphasis becomes italic or underline, and a double hyphen becomes an em dash. A sidebar holds the title, author name, font and toggles for the address block, an abbreviated running title, underlined italics and an anonymous manuscript, and the exported file is saved to the downloads folder under the story title.
