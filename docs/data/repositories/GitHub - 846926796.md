# gitcpy/obsidian-remove-html-tag

This plugin removes HTML tags from Markdown files, which the README presents as tedious to delete by hand once they have been added to a note's text. In use, text is selected in editing mode — a tag present in the source is selected along with it — and the remove command is then run from the command palette. Installation is described through BRAT by adding the repository as a beta plugin, with other routes noted as still to come.
