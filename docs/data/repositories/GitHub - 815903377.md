# GustavoSZ124/Obsidian-Theme-Seamless-View

This Obsidian CSS theme aims to reduce the differences between live preview mode and read mode, keeping card sizes consistent when elements are edited inside a canvas. It is minimalist: it removes several unnecessary spaces, hides the mandatory empty line before a table and adjusts the canvas menu, and it offers a low-contrast dark mode with warm colours alongside a light mode inspired by Egyptian papyrus. In read mode a one-em bottom margin between paragraphs, code blocks, lists, blockquotes, callouts and headers emulates the empty lines of live preview. Styles are also adjusted for the Admonition, Dataview, Kanban and List Callouts plugins.
