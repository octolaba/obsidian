# tine-schreibt/aDHL

aDHL is based on the Dynamic Highlights plugin by nothingislost, with a bug fixed in its regular expression and the basic mechanics left untouched; what is added is customisability and usability. The README records hotkeys, sorting, a configurable minimum length for selection highlights that can be set to 1 so Chinese characters work, capture-group support, query duplication, a debug mode and contributed responsiveness and dark-mode fixes. Highlight styles are described as inspired by those in Highlightr, and importing highlighters from the original plugin is explicitly not supported.
