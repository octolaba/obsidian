# jaschaephraim/obsidian-title-generator

Title Generator sets a note's title from its content using OpenAI's GPT-3.5, over one note or several at a time. The README records three entry points: a command palette entry while a note is active, an entry in the editor dropdown menu, and a contextual menu entry when one or more files are right-clicked in the file menu, with repeated runs producing variations. An OpenAI API key must be added in the plugin's settings, where a further option forces generated titles to lower case.
