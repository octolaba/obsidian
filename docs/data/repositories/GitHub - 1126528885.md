# Kiteruunner/obsidian-attachment-organizer

Plans where a vault's attachments should live relative to the notes that reference them, and shows that plan as a tree before anything moves. Files are scanned in configured zones, a workspace folder, a staging folder for unreferenced attachments and optional extra folders, and each item is marked as kept, staged, relocated, missing or conflicting, with filters over those marks. Link detection covers ordinary links, embeds, frontmatter links, Excalidraw and Canvas files, and targets can be beside a note, in a note subfolder, in a named folder or at the vault root. Scanning and preview change nothing; applying the plan asks for confirmation, leaves conflicts and missing entries untouched, and the most recent batch can be undone.
