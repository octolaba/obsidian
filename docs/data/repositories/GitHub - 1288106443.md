# KennyRN/nameForge

This repository holds nameForge, a random name generator plugin for Obsidian that learns the letter patterns of a list of source names supplied by the user and invents new names in that same style. The README records that generation runs locally from a statistical Markov model rebuilt from the list each time, offline and without any AI service or internet connection, so the names never leave the vault. Its pack types cover breakdown, which invents names from the learned patterns, list, which picks names verbatim from the source without repeats, and compound, which joins two or three independently generated parts either fused into one word or kept separate.
