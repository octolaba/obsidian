# qawatake/obsidian-core-search-assistant-plugin

Obsidian plugin that extends the built-in search with a keyboard interface, a card view, a bigger preview and automatic preview. Opening the built-in search panel enters a search mode in which documented hotkeys select an item, preview it, open it in the current or a new pane, set search options, move between sets of cards and copy a wiki link to the selection. The README states that those hotkeys apply only inside the search mode, so existing hotkey settings are not overwritten, that they can be customised in the setting tab, and that automatic preview offers none, single view and card view.
