# ragetrip/scoped-search

Scoped Search adds a search modal or dockable tab that searches only inside the folders the user picks, and it also matches filenames of non-Markdown files such as audio, PDFs and images through a configurable extension list. The README describes a folder picker with list and tree views, per-folder default selection, a select-all chip, alt-click to search one folder alone, an expandable preview pane that scrolls to the matched hit, session restore, keyboard navigation and a result context menu offering open, open in new pane and copy path. It records support for quoted exact phrases and unordered groups, and states version 2.1.1 for Obsidian 1.5.0 and above on desktop, iOS and Android.
