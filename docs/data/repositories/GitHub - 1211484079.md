# zh-xx/rosypilot

An assistant for writing Chinese legal documents in Obsidian, built on the MIT-licensed Markpilot plugin. It offers two capabilities: inline completions that predict the next sentence as ghost text from the Markdown context at the cursor and are accepted with `Tab`, and legal commands that look up statute text and cases, verify legal references, and insert the result at the cursor. The README is bilingual, in Chinese and English.
