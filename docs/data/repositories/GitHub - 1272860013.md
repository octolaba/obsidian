# mymindstorm/obsidian-bases-spotlight-view

Bases Spotlight View adds a dual-pane view to Obsidian Bases: a central pane that renders the file — Markdown notes, images and interactive PDFs — beside a right sidebar dedicated to that file's metadata properties. Properties can be edited inline without a modal and reordered by dragging, and assigning properties to a binary file such as an image or PDF transparently creates a Markdown sidecar to hold the metadata. The README also records a custom content property that renders a chosen text property in the central pane instead of the file contents, parsing Obsidian wikilinks in that property to render the linked files.
