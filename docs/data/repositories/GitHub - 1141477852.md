# joepetrakovich/obsidian-furigana

Creates and displays furigana above Japanese kanji in reading view. A hover-only mode keeps the readings hidden until the text is hovered, aimed at learners, and font size and color are adjustable. The README states that dictionary files of about 20 MB must be downloaded from the plugin settings after installation before the plugin can be used.
