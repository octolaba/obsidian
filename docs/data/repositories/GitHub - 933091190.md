# cailurus/imswitch_mathblock_obsidian

Switches the system input method automatically while mathematical formulas are being written: when the cursor enters a formula area between dollar signs it selects the English input, and when the cursor leaves it restores the previous input method. Three settings hold the English input method identifier, the previous input method identifier and the path to the command-line tool that performs the switch. The README states that the defaults target macOS with the macism tool installed, and that other systems need equivalent command-line tools configured in those same settings.
