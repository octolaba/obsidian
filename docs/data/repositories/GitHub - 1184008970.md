# WanDa1993/obsidian-plugin-web-bookmark

Card Bookmark turns links and vault-relative file paths into card-style bookmarks in Obsidian. Its README, written in Chinese, documents two commands that ask for an optional title plus a URL or a path and insert a link or file bookmark code block which renders as a card, and notes that file bookmarks cover only files inside the vault and report an invalid path otherwise. A third feature intercepts opening events in the file explorer for chosen extensions, given as a comma-separated list, with single-click and double-click interception configured separately.
