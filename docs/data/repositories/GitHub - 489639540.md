# SimonTC/obsidian-note-autocreation

The repository holds Note Auto Creator, an Obsidian plugin that creates a note at the moment a link to it is written. Its README records an alternative link suggestion dropdown triggered by a configurable character, an at sign by default, which behaves like Obsidian's own wikilink suggestions with one difference that gives the plugin its name: where no note exists at the link target, one is created rather than left unresolved. It also records that a Templater template can be applied to the note it creates.
