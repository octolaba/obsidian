# mjsharkey/obsidian_target_pane

Target Pane designates one pane as the destination for note links, so clicking a wikilink, a Markdown link to another note or the link icon on an embedded note opens the target there rather than in the pane it was clicked from. A plain click replaces the target pane's active tab and a modifier-click opens a new tab in it, while split-open and open-in-new-window keep Obsidian's own behaviour. Links that jump within the current note, to a heading or a block, stay where they were clicked, and external web links are left alone entirely. The target is set and cleared by command, shown in the status bar, remembered across restarts, and turned off automatically if the target pane is closed.
