# fennr/obsidian_leetcode_template

Obsidian plugin that generates a structured note from a LeetCode problem link or number, fetching its metadata, description, similar questions and the user's own accepted solutions. A second command reads the link field from the active note's frontmatter and appends newly accepted solutions without duplicating existing ones. Settings cover the target folder, a filename template with number, slug and title placeholders, whether the description and all or only the latest solutions are included, and an English or Russian interface. The README records that it is desktop-only, needs Obsidian 1.5.0 or later, and signs in to LeetCode through an embedded browser window or pasted cookies.
