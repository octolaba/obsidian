# dominiclet/obsidian-note-definitions

Note Definitions is an Obsidian plugin that keeps a personal dictionary inside the vault and looks it up from within notes. A folder is registered as the definition folder from the file explorer, definition files are created inside it, and the Add definition command opens a modal for entering one; defined words and phrases are then underlined in notes and their definition is shown on hover or through the Preview definition command. The editor menu and the command palette offer going to a definition, adding one from highlighted text, editing an underlined one, registering consolidated or atomic definition files and refreshing definitions. The README states that no hidden metadata files are kept, all definitions living in the vault itself.
