# fr4nc0i5/obsidian-inline-properties

Inline Properties substitutes note properties into prose through a double-brace variable token, rendering the value inline in both Live Preview and reading mode. A bare name resolves to the current note's frontmatter, while a path-qualified name reads a property, including a nested one, from another note, and local properties take priority when names collide. Typing the opening braces triggers a fuzzy, name-first autocomplete showing each candidate's name, its originating path and a value preview, and inserting the full reference. Selecting a rendered value reveals the raw token for editing, copying text yields resolved values by default, and settings control that behaviour and an optional highlight that a CSS snippet can restyle.
