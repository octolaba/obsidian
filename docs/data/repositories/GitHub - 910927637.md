# Akaswan/table-list

Table List organises tasks in a grid where every row is a project and every column a date, which its README contrasts with a traditional to-do list. The view is opened from a button in the left side panel, a row is added per project, and clicking a cell assigns a task to that project on that date. Clicking a task cell changes its status between not started, in progress and completed.
