# iamxiaoming-gif/life-journal

Obsidian plugin that turns a vault into a personal journal, writing entries into daily Markdown files. Recording is split into four tabs for mood, what happened, passing thoughts and plans, the last of which extracts a date from natural language such as a phrase naming a weekday, while entries accept pasted or uploaded images, inline tags and Markdown. A review mode browses entries as a card layout filtered by type or by clicking a tag, with two-way syncing of todo checkboxes. Three interface styles and eight colour themes are offered, and the layout adapts to phone screens.
