# joshua-walls/night-ridge-theme

joshua-walls/night-ridge-theme holds Night Ridge, a dark, low-glare Obsidian theme for focused notes, technical writing and vault operations, with dark and light modes tuned as first-class. Its palette gives each colour a job: moonstone and ridge surfaces structure navigation, properties, tables, callouts and panels; pine marks active navigation, links, primary actions and success; copper carries secondary actions and warnings; lichen supports headings; ember is reserved for errors; and seafoam stays rare for info and focus highlights. The README describes the intent as grounded and practical rather than decorative, with a beacon-style H1 treatment and small colour signals for scanning.
