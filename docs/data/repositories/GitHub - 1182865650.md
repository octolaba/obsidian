# junjieim/better-quote

The repository records no description, so this note is grounded in the README alone. Better Quote reuses exact content across an Obsidian vault through native block embeds rather than copies: `mirror-to` adds a block ID to the current line if it lacks one, then appends an embed of it to a target file chosen from a fuzzy list, while `mirror-from` searches blocks across the vault and inserts the selected block's embed at the cursor, adding an ID to the source when needed. Its block search matches on preview text and file path with multiple terms and relevance ranking, and its extraction handles headings, list items, blockquotes and paragraphs while skipping frontmatter and fenced code blocks.
