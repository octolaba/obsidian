# Ledaryy/obsidian-todoist-completed-tasks

This plugin fetches completed tasks from Todoist and writes them into a note between a start and an end segment comment placed by the reader. It can fetch today's completed tasks, those completed in the last N hours, or those bounded by dates read from the segments with Templater support, and each task can be given a configurable prefix and postfix for use with the Tasks plugin. Running it requires a Todoist API token in the plugin settings, and the README links its own documentation on the security risks of storing that token.
