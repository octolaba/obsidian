# autohub7/obsidian-tab-rotator

Tab Rotator moves through the tabs open in an Obsidian workspace automatically, rotating them to the right or to the left instead of requiring each one to be clicked. Rotation to the right is toggled from a ribbon icon, and command palette entries start rotation in either direction or stop it. The interval in seconds is a setting, as is whether rotation covers only the active tab group or all splits in the main window.
