# z-fab/agentmd-obsidian

Obsidian plugin that acts as a front end for a local agentmd backend, the markdown-first agent runtime in which each agent is a single `.md` file with YAML frontmatter and a Markdown body. It talks to agentmd over a Unix domain socket whose path is configurable, never contacts a remote server itself, and starts the backend as a local subprocess only on an explicit action such as the status-bar dot or the start command. One sidebar panel carries Agents, Live and History tabs with drill-down detail screens, an agent runs with one click or against the currently open note, and live updates arrive over a server-sent-events stream with health polling as the fallback. The README requires desktop Obsidian 1.5 or newer and agentmd v0.14.0 or newer.
