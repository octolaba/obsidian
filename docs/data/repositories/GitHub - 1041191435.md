# davidvkimball/obsidian-astro-composer

An Obsidian plugin for turning vault notes into posts and pages for an Astro blog. It can prompt for a title when a new note is created and generate a kebab-case filename with properties, standardize a note's properties against a customizable template while preserving existing values, prefix drafts with an underscore so Astro skips them, and convert wikilinks and internal Markdown links into Astro-friendly paths. MDX files are covered for creation, link conversion and property standardization, and the posts folder, link base path and file-based or folder-based creation mode are settings.
