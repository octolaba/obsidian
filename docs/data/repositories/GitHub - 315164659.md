# dxcore35/Suddha-theme

Suddha, a Pali word meaning clean or pure, is an Obsidian theme with a clean and minimalistic look. Its CSS file exposes a custom accent colour, custom element colours and adjustable background brightness, and a small line height in the file explorer is used so that more information fits into a small area. Extra icons are added, the main buttons are hidden, and UI colours are adjusted for the Calendar Widget and Day planner plugins.
