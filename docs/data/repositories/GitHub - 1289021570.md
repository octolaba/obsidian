# aabulkhairov/obsyncian

Obsidian plugin that syncs and backs up a vault through the Obsyncian service, with no buckets, servers or Git to configure. The README states that when an encryption passphrase is set while linking a vault, file contents and file names are encrypted on the device with AES-256-GCM under a PBKDF2-derived key before upload, so the servers see only ciphertext and random identifiers, while syncing without a passphrase stores the data unencrypted. Every change is version-checked, so two devices cannot overwrite each other: the same note edited in two places yields both versions, the second saved beside the original under a conflict-stamped filename, and deletions become reversible tombstones whose version history is retained for a period. It runs on desktop and mobile, syncs only while the app is open, and offers vault sharing on paid plans beside a free tier.
