# KhiipAI/khiip-obsidian

The Khiip plugin captures URLs into an Obsidian vault and recalls them by meaning, working as a thin client over a locally running Khiip daemon that performs the extraction, embedding and storage. Commands capture a URL and open the resulting note, focus the sidebar recall search and open the settings tab, while the sidebar shows daemon status, recall search and recent captures, with context menus to open, re-capture or copy a capture and to capture a link from the editor. It requires the daemon serving locally, discovers its API key from the daemon's local configuration file, and expects the daemon's vault path to point at the Obsidian vault. The README marks the project as paused because the daemon package is not published, and warns that a non-local daemon address sends captures, queries and the pasted key to that host.
