# lisitan/esther-obsidian-typora-themes

lisitan/esther-obsidian-typora-themes holds unofficial, non-commercial Esther-inspired themes for Obsidian and Typora with light and dark modes. The Obsidian theme follows the app's light or dark mode automatically, and the repository also carries two Typora themes, a warm paper-like Paper and a navy Midnight. Its Chinese README describes blue for structure, yellow for emphasis and red only as a sparing accent, serif headings with a quiet sans-serif body, highlighting that covers only the lower half of the text, and coverage of wikilinks, note properties, search, graph, Canvas and print styles, with no remote fonts or images and therefore no network requests.
