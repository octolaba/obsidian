# monapdx/Neon-Acid

monapdx/Neon-Acid holds Neon Acid, a neo-brutalist Obsidian theme built on chunky borders, high contrast and a neon palette of green, pink and cyan against black and white. It adds animated hover effects, framed images, interactive task lists, metadata styling, code block treatments and polished tables and callouts, and the README describes it as lightweight CSS only. The README also states its tradeoffs openly: the cursor becomes nearly invisible, capitals are used heavily, and the risk of unintended style conflicts is raised.
