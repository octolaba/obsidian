# Signynt/virtual-content

Virtual Content, previously named Virtual Footer, renders Markdown text into notes that match a rule as if it were part of the file, without modifying the files themselves. The content can be typed into the plugin settings or taken from a note in the vault, and it renders live constructs including Dataview, Datacore and native Obsidian Bases blocks. Rules are defined on folders, tags or properties, may include or exclude subfolders and subtags recursively, and may combine several conditions with AND and OR, with Dataview rules available for more complex ones. The rendered content can be placed as a footer at the end of a note, as a header below the properties, or in the sidebar, which the README presents as a way to avoid pasting the same block into many notes and to change it for all of them at once.
