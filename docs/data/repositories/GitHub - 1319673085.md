# NoteNerdOfficial/convert-to-markdown

Convert to Markdown turns PDFs, Office and OpenDocument files, ebooks, saved web pages, email, notebooks, subtitle tracks, spreadsheets and images into Markdown notes with their images extracted. Documents are parsed from their own structure, so conversion is deterministic and runs entirely on the machine with no model, API key, cloud service or external binary; images and scanned PDF pages fall back to local Tesseract OCR, which downloads its engine on first use and reports its confidence. The note is written beside the original without overwriting, its frontmatter links back to the source and records coverage counts such as pages, sheets, chapters or cells converted, and anything dropped is named individually in a collapsed callout at the end. It runs from the file explorer context menu or the command palette, and is desktop only.
