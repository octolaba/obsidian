# colorpulse6/brain-atlas

Brain Atlas renders an Obsidian vault as an animated 3D anatomical brain, with notes as nodes, links as neural pathways and note types grouped into brain regions. Version 0.2.0 replaced the desktop Canvas2D path with a WebGL2 renderer that the README says cuts idle-rotation CPU usage by roughly 70%, keeping Canvas2D as an automatic fallback on mobile, where WebGL2 is unavailable, or after a context loss, selectable through a Renderer setting. Earlier work made it read existing vault taxonomies by mapping custom frontmatter values to categories or regions and folders to regions, instead of requiring notes to be renamed. The README describes it as primarily a desktop plugin with experimental mobile support and a Mobile preset that caps rendering load and label density.
