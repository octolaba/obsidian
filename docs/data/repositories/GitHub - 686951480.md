# danielo515/obsidian-modal-form

Modal Form lets forms be defined in Obsidian and opened from anywhere JavaScript can run, so they can be triggered from Templater templates, QuickAdd captures or DataviewJS queries and return the entered values. Forms are described in a simple JSON format, managed as a named collection, and can be built through a user interface; a form with a template can also be registered as a command and used to create notes directly, with its own template editor. Input types include number, date, time, slider, toggle, free text, text completed from note names or from a dataview query, multiple choice and selection from a fixed list or a folder of notes. The README motivates this by the limits of prompting one value at a time without labels or the ability to skip fields.
