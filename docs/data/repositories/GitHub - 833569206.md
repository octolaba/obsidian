# samuelrawrs/recent-tab-switcher

Recent Tab Switcher toggles between the active tab and the previously active one from a hotkey, bound by default to a two-key combination and changeable in the hotkey settings. The README explains the motivation as bringing a browser tab-manager habit to Obsidian, whose existing tab switchers cycle through panes rather than returning to the last used tab. It lists cycling through more tabs by history and visual cues showing the target tab as possible future additions.
