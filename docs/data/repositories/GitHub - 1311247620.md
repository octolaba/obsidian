# johannes-kaindl/3d-codeblocks

3D Codeblocks renders GLB, glTF and STL models inline in Obsidian notes with orbit, zoom and pan. The README records four ways to show a model: clicking such a file in the file explorer opens it full size in its own pane, the normal wiki-embed syntax embeds it with an optional height, a dedicated code block references a file with an optional title and height so several labelled models fit in one note, and a second block type carries glTF JSON written straight into the note for small hand-written models. It notes that materials and colours come from GLB and glTF files while STL carries none and receives a theme-aware default, that binary GLB does not fit in a text block, and that regenerating a file updates the view without a restart.
