# ghyatt/obsidian-bases-image-gallery

The repository records no description, so this note is grounded in the README alone. Bases Image Gallery is a masonry image gallery for Obsidian that requires no setup, built on the earlier Obsidian Image Gallery by Luca Orio and updated for the Bases plugin. The README states it needs Obsidian 1.10.2 or newer with the Bases core plugin available and images already in the vault, and documents installation from the community plugin browser or through BRAT for beta versions.
