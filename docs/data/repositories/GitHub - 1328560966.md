# mrrepac/chess

This plugin opens a chess board in an Obsidian pane and plays against a bot that runs inside the plugin, with no account or network connection, and the game in progress survives a restart. Ten difficulty levels differ in how deeply and carefully the bot searches, an opening book of 56 lines is used from level five upward, and an optional adaptive mode steps the level after a run of wins or losses. An optional clock offers five minutes to an hour with a Fischer increment, moves can be made by click, drag or keyboard with labelled squares, illegal moves are explained rather than ignored, and results are tallied per level. The engine is an alpha-beta search with a transposition table, iterative deepening and quiescence over chess.js, run in a Web Worker; desktop and mobile are both supported.
