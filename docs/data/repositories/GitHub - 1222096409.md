# Joysimple/shopping-list-automatic-reorder

This plugin reorders a shopping list in an Obsidian note as its items are checked off, moving completed items to the bottom of their section and returning them to the active list when unchecked. The README states that reordering respects Markdown headings, so categories kept in one file are sorted within their own section, that it waits a second of inactivity before acting, and that it defers while the cursor sits on a line that is about to move so typing is not interrupted. It activates only on notes explicitly marked as shopping lists through a frontmatter key or a tag, and a setting chooses whether newly checked items go to the top or the bottom of the checked block.
