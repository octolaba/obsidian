# ai-bytedance/obsidian-cloud-sync

This plugin synchronizes an Obsidian vault to cloud storage services and offers optional content encryption. Its README states that the project is at an alpha stage and that important notes should be backed up first, and that two transports actually work today — WebDAV, for services such as Nextcloud, and GitHub for public and private repositories with connection testing, recursive remote listing, upload, update and delete — while iCloud is a placeholder interface and Google Drive and OneDrive are only planned. Sync direction can be two-way, upload-only or download-only, running automatically, on a timer or by hand, with basic conflict handling, create, modify, delete and rename propagation, Markdown link conversion, and selective sync that ignores chosen files, folders and extensions. Installation is from source only.
