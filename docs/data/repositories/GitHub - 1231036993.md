# foundlegacy/zulu-agent

The repository holds Zulu Agent, an agentic AI assistant that runs entirely inside an Obsidian vault. Through a chat interface it searches, reads and modifies Markdown, base and canvas files, edits CSS snippets, and supports local models served by LM Studio or Ollama.
