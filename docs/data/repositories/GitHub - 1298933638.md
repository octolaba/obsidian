# DaoYoung/obsidian-worktable

Worktable is a dashboard plugin built as a single custom ItemView with no Dataview dependency, in which six widgets render in a grid layout and share state through native IndexedDB. The widgets cover a pomodoro focus timer with session history, a todo board with priority levels, inquiry-based concept lookup, AI-generated recall questions tracking per-knowledge-point mastery, an end-of-day review feed, news aggregation over a folder or a tag, and an encouragement widget archiving learning records. The README states that AI features run either through a bundled local Cloakfetch service or through direct browser calls to Anthropic, OpenAI, Gemini, DeepSeek, Moonshot, Zhipu, Alibaba Bailian, Volcengine and MiniMax endpoints, switchable in settings.
