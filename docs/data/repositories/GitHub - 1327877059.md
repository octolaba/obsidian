# chrisurf/obsidian-couchdb-sync

Keeps a vault in sync across devices through a self-hosted CouchDB server, encrypting note content along with file names, folder structure, sizes and timestamps with AES-256-GCM before anything is uploaded. The passphrase stays on the device and must match on every device, and the server operator sees only opaque blobs; a lost passphrase means the notes cannot be recovered. A status panel compares the device, the on-device cache and the server, reporting the exact delta and a color-coded tree marking each file as in sync, local only, remote only, differing or conflicting, and it says when the server cannot be reached instead of reporting success. Syncing is switched on per vault, and upstream describes the plugin as beta.
