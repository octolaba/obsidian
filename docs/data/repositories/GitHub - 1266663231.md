# stephenkall/obsidian-confluence-vault-uploader

Obsidian plugin that uploads a whole vault to Confluence, mapping the folder structure onto a page hierarchy. The README states that every markdown file becomes a page under the right parent, that each folder becomes a page whose content comes from an underscore-prefixed index file, and that wikilinks in all their forms become working Confluence links, while callouts become info, warning and tip panels and fenced code blocks become code macros with syntax highlighting. Sync runs in two phases, creating the pages first and wiring up cross-page links afterwards, and re-running updates only the changed pages so version history is preserved.
