# 2shortplanks/current-file

Current File lets programs outside Obsidian learn which file the desktop application is currently showing. Whenever the vault switches to another file, the plugin writes a small JSON document — the vault-relative path, the vault directory and the full path — to a file in the user's home or profile directory, whose location can be changed in the settings. The README contrasts this with Obsidian's own x-callback-url scheme, which requires an application registering a custom URL scheme or a local web server to receive the same information.
