# AmadeussSystem/Inkporter

Imports photographs of handwritten notes into the vault by extracting the ink strokes and dissolving grid lines, bleed-through and paper shadows, with a sensitivity slider trading bleed rejection against retention of faint markings. Pasting an image opens an interactive cropper over a checkerboard background so notebook margins can be cut away before saving, and saved files are named from a template with date, timestamp and short-id variables. The extraction runs on a self-hosted PyTorch server that has to be installed separately; its directory is set in the plugin settings and a command starts it from Obsidian. The README states that the processing is local rather than cloud-based.
