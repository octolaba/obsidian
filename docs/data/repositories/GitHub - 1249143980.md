# joe-iq/obsidian-manuscript-outliner

Generates structured outline views from manuscript notes, showing each section's status tag and word count. For every configured source note the plugin writes two files: a nested numbered list of headings, each of them a link into the manuscript, and a Markdown table with hierarchical numbering, status tags and word counts. Status comes from the first tag placed on the first non-blank line below a heading, and the tags are free-form, with draft, review, refine and final offered as examples. Outlines are produced by commands or a ribbon icon and can regenerate automatically on save; the source note names and the two output suffixes are settings.
