# andrewmcgivery/obsidian-canvas-dailynote

Adds a node to an Obsidian Canvas that always shows today's daily note. The README states that a button on the canvas view inserts the node and that the plugin keeps it pointing at the latest daily note whenever the canvas is opened. Two limits are recorded by the author: the node is recognized through special metadata written by the plugin, so existing file nodes cannot be converted, and updating replaces the node instead of editing it, so connections from the daily note node to other nodes are not supported. Settings control whether a missing daily note is created, including per weekday, and CSS classes are documented for styling the button and the node.
