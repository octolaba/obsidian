# packetsherpa/obsidian-tomorrow-night-blue

This repository holds an Obsidian port of the Tomorrow Night Blue theme bundled with Visual Studio Code. The README lists the matched palette by hex value for the editor background, sidebar and widgets, tabs and activity bar, title and status bars, active line, selection, borders and syntax accents, and describes the theme as intentionally compact with customization through CSS variables near the top of the stylesheet. It states that the repository holds a CSS implementation for Obsidian rather than a copy of the VS Code extension.
