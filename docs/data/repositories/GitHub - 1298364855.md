# Dimar4713/aimeton-cloud-bridge

AIMETON Cloud Bridge connects an Obsidian vault to Yandex Disk cloud storage without leaving the app. A dedicated side panel browses cloud folders, uploads local vault files, downloads cloud files back into the vault, previews supported images and reports upload and download progress. The interface is available in Russian and English, and on desktop the plugin can route its traffic through HTTP CONNECT, HTTPS CONNECT or SOCKS5 proxies.
