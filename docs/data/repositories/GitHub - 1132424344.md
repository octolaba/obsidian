# ovitrif/obsidian-url-preview

URL Preview opens external links in an embedded preview from Obsidian Editor, Live Preview, or Reader mode. Configurable modifier keys, sticky or resizable popups, per-domain zoom, and URL-to-Markdown conversion support different browsing workflows, although sites that block iframe embedding cannot be shown.
