# likemuuxi/obsidian-diary-view

Diary View turns daily notes into a notebook-style view opened from a ribbon icon or the Open diary view command, showing the latest seven daily notes as pages with a flip animation and allowing preview or in-place editing without leaving the view. Optional per-note details live in frontmatter: a quote shown in the prompt card on the right page, a weather icon chosen from a built-in picker, and a note-specific image replacing the default artwork, while editing the body preserves the rest of the frontmatter. A daily quote can be fetched from a user-configured API only when a note lacks the configured property, and is then cached in frontmatter. The README states the plugin is fully localized in English and Chinese and lets the calendar week start and the highlighted weekend days be configured.
