# benpm/obsidian_github_wiki

Stores a vault in a GitHub wiki repository, or edits an existing wiki from Obsidian, by cloning, fetching and pushing that wiki repository. The README lists four user-controlled sync triggers — a command, ribbon icon or status bar click; sync on startup; a debounced auto-sync after edits inside the wiki folder; and an optional periodic interval that is disabled by default — and states that no data goes anywhere except the configured wiki repository, with no telemetry, analytics or crash reports. Authentication is either a GitHub OAuth device flow through an app owned by the plugin author requesting the repo scope, or a classic personal access token with the same scope, and signing out removes the token from the device only.
