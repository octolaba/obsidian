# Promptier/disk-usage

Repository for a disk usage plugin that aggregates the sizes of the files in an Obsidian vault, broken down by folders, file types and plugins, and writes the result into a Markdown report. An update note from the author records that the plugin is under a hundred lines, that clicking the button again does not overwrite an existing report — it has to be deleted first — and that overwriting and timestamps are the proposed enhancements. It also records that Obsidian's API exposes only file sizes and not the disk space they occupy, since filesystem metadata differs across operating systems, which is why the author considers renaming the plugin.
