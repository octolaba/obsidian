# ivan-lednev/better-search-views

Better Search Views rewrites how matches are presented in Obsidian's native global search, backlinks view, embedded backlinks and embedded queries, giving each match an outliner-like context. It renders the matched Markdown to HTML and builds a breadcrumb trail by chaining the ancestor headings and list items above the match; a match inside a list item also shows its sub-items, and a match in a heading shows the first section below that heading. The README warns that Obsidian must be reloaded after the plugin is installed, updated, enabled or disabled, and that because the plugin reaches into Obsidian's internals it may break after an app update.
