# osatetsu/tekken-code-image

Tekken Code Image renders Japanese Tekken command notation as SVG images from fenced code blocks tagged tekken. The notation is the numpad style used in Japan: digits for directions plus n for neutral, LP, RP, WP, LK, RK and WK for attack buttons, square brackets for a slide of buttons pressed in quick succession, a plus for simultaneous presses, an angle bracket as a separator and double-quoted text for free annotations, with spaces and commas ignored and commands capped at 200 characters. Shape size, spacing, text styles and attack button colours are configurable in settings, diagonal arrows currently carry more horizontal padding than the others, and icons such as power crush are not supported.
