# skye-z/ons

This plugin synchronises an Obsidian vault with a NAS on the user's own network, and the README sends anyone who only wants to sync between Obsidian clients to the official service instead. It requires the project's server component installed on the NAS, registered with a central server to obtain an identifier, and a connection password enabled there. Both values are entered in the plugin settings, which offer a test button for checking that the connection works.
