# matbo1/llm-auto-tagger

Obsidian plugin that asks a configured language model to add tags to Markdown notes, drawing only on the tags that already exist in the vault. It reads the candidate tags from Obsidian's metadata before each request, lets the model choose from that list alone, and writes the matching tags into the frontmatter while keeping existing tags and other fields, running automatically once a note has been idle. A bulk action scans every note in the vault serially with resumable progress, cancellation, and statistics separating updated notes, notes with no new tags and exceptions. Providers include OpenAI-compatible endpoints, OpenAI, Anthropic Claude, Google Gemini and several China-based services, and a connection test checks the configured URL, key and model.
