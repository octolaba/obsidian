# markcrobbins2112/op-file-tree-selector-hue-rotate

This plugin draws an animated color-rotating border around the item hovered or active in Obsidian's file tree. The border is rendered as a floating overlay box on an independent layout plane rather than on the item itself, which the project describes as avoiding the clipping the file tree's own overflow would cause, and the color cycle is produced by sequential border-color frames driven by CSS keyframe animations.
