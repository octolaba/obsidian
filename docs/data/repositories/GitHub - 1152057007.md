# pedrojreis/Pebble

Pebble adds a small writing window reachable from the system tray or menu bar, so one note can be edited without bringing the full Obsidian window forward. Its README describes a pop-out anchored near the tray icon that closes when focus moves elsewhere, autosaves edits back to disk, and reads and writes exactly one chosen Markdown file from the vault. Settings recorded there cover the tray icon style, in color or monochrome, and a light or dark editor background.
