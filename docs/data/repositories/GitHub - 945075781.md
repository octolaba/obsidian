# MarsBatya/tg-emoji-search

This repository holds TG Emoji Search, a plugin that inserts emoji into Obsidian notes by typing a trigger character followed by a keyword and choosing from a suggestion list. The README records that the keywords come from Telegram's emoji translations, counting roughly 13,000 keywords over about 2,000 emoji across English, Russian and Spanish, and that the search itself is written in Rust compiled to WebAssembly while TypeScript binds it to the Obsidian plugin API. Settings cover the default language, the trigger character and whether keywords appear in the suggestion list, custom keyword mappings can be added, deleted and reset, a command inserts a random emoji, and the plugin tracks the most used ones.
