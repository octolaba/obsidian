# stagars-m/bold-folder-name

Bold Folder Name makes folder names bold in Obsidian's native File Explorer, using the bold weight from the --font-bold CSS variable. An optional setting limits the styling to folders directly beneath the vault root and is off by default. Files, Folder Info counters, collapse icons and inline rename fields are left unchanged, and native styling returns as soon as the plugin is disabled. It performs no network requests, telemetry, vault reads or vault writes, and stores only its local display preference.
