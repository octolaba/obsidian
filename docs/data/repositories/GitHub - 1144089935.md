# nbDev99/ascii-art-heading

An Obsidian plugin that renders a heading as FIGlet ASCII art from an ascii-art code block. The block takes a required title plus optional font, alignment and colour parameters, where colour accepts a hex code or one of the accent, muted, warning, error and success presets, and the README lists seventeen available fonts. Settings cover the default font, font size, default colour, full-width rendering, horizontal scrolling for wide art and whether the font name is shown. The repository carries no description.
