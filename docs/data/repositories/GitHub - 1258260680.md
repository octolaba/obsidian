# sourit2001/obsidian-note-tts

Note TTS converts the current note or a selection into an MP3 file through a speech provider the user configures, saving the audio inside the vault and opening a playback modal with actions to open the file or copy its path. Conversion is offered from the command palette, a ribbon button, the editor context menu and the file menu, and a separate command previews the cleaned text before it is sent. Markdown cleanup can strip frontmatter, tags, links, raw URLs, images, embeds, HTML comments and lines matching custom rules. The recorded providers are a hosted speech API over HTTP, presets and an advanced mode for a model-hosting service, and a custom HTTP endpoint.
