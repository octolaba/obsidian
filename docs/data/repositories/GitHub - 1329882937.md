# bobstanton/places-mapbox

A map provider for the Places plugin backed by Mapbox. It loads the selected map style with its glyphs, sprites and tiles, resolves search terms to places and coordinates, builds routes between waypoints and isochrones around a center point, reads elevation for a coordinate, snaps a recorded track to the road or path network, and loads terrain DEM tiles for 3D relief. The map surface is rendered by mapbox-gl injected into the shared Places GL implementation, address and POI search come from the Mapbox search library, and no background tasks run.
