# kieranmansfield/obsidian-quick-bookmarks

Quick Bookmarks opens the entries of Obsidian's core Bookmarks plugin through a fuzzy search modal, bound by default to Cmd+M on Mac and Ctrl+M elsewhere, covering bookmarked files, folders, searches and groups. Groups can be handled in two modes: separate modals, where selecting a group opens a further focused search, or flattening every bookmark into one list that shows its group path. Individual bookmarks can be hidden from the results, and frequently used groups can each be given their own command in the command palette.
