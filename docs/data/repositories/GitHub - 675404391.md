# possibly-not/obsidian-aura-theme

possibly-not/obsidian-aura-theme is an Obsidian port of the Aura theme by daltonmenezes, generated through the Aura API. It records two dark variants, Aura Dark and Aura Dark Soft, switched with the Style Settings plugin, while a light mode, two further soft text variants and complete theme coverage are listed as not yet done. The README also lists known issues: the search bar, the on and off toggles and the highlighted files, search and bookmarks icons are not themed correctly, and the cyan line highlights do not soften in the Aura Dark Soft variant.
