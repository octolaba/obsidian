# whiteandgrey/obsidian-floating-window-plugin

This plugin displays selected text passages in independent floating windows while keeping the same rendering and theme style as the original document. Text is selected in a Markdown note and opened in a window through the right-click menu or the Alt+w shortcut; the window renders headings, code blocks, lists, tables and MathJax formulas, can be dragged and resized, closed with a button, and jumps back to the source paragraph from a second button. Window size is computed from the content to avoid scrollbars, windows are placed below and right of the selection, and all windows belonging to a document close with it. The README is bilingual in English and Chinese, and the interface supports both languages.
