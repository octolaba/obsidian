# omnbird/syncscroll

SyncScroll ties together the scrolling of two files opened side by side, so that scrolling one pane moves the other by percentage in either direction. Triple-clicking a line jumps the other pane to the same line and aligns it horizontally, after which the resulting offset is kept while scrolling rather than snapping back. The README says the author wrote it while translating English technical documents into Chinese, where source and translation drift apart because they differ in length, and that the plugin is turned on and off through command-palette entries.
