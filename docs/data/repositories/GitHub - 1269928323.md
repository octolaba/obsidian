# SonicKarnati/flux-tts

Flux TTS records audio in Obsidian from a ribbon icon or commands, saves it into the vault, transcribes it with Groq Whisper and creates a note holding the transcript and an audio embed. Either the fast or the accurate Whisper model can be chosen, transcription can instead be inserted inline at the cursor with a footnote linking back to the recording, segments can be timestamped so each line links to its moment in the audio, and an optional Groq LLM pass fixes punctuation and filler words while keeping the original transcript. A live waveform shows the microphone is working and recording auto-stops on a silent or disconnected mic; an opt-in feature adds transcripts for pasted YouTube or public media links as footnotes. The README states the key is kept in Obsidian's secret storage, that audio stays local while transcription is sent to Groq, and that Obsidian 1.12.0 or later is required.
