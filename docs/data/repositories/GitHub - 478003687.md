# kmsk99/kr-book-info-plugin

The bilingual Korean and English README describes an Obsidian plugin that imports book information from the Yes24 bookstore into a note's front matter. Running it from an Add Book Info button on the left changes the document's title and content and inserts the front matter above the existing text, taking roughly five to ten seconds. Default values for tag, status, rate and book note, and whether the title is inserted into the body, are configurable in the settings. The README also reports the project's test coverage, claiming full line and function coverage for its source directory.
