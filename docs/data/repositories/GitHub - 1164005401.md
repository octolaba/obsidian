# PixeroJan/obsidian-storyline

StoryLine turns an Obsidian vault into a book-planning workspace organised around projects, covering scenes, characters, locations, plotlines and progress. The README describes several views: a Kanban board of scene cards grouped by act, chapter or status, colour-coded and edited in bulk through multi-select; a corkboard mode holding freeform sticky notes and pinned reference images, where notes live in a separate folder and move into the scenes folder when converted; and a spreadsheet-like plotgrid mapping scenes against plotlines or themes, with per-cell text and colours, linked scene cards, act and chapter divider bands, and an inspector that edits a linked scene without leaving the grid.
