# moremeyou/Obsidian-Tag-Buddy

Tag Buddy brings tag editing into Obsidian's Reading Mode: a modifier click or triple tap opens a selector that inserts a recent, favourite or newly created tag into a note, into embedded content or into a tag summary, while a click or double tap removes a tag, nested tags being removed from the deepest level first. A modifier click or long press opens a tag action modal that renames a tag, changes its case, converts it to text or creates a tag summary, applied to the clicked tag alone, to every instance in the note, or to every instance across the vault. Which gesture performs which action is configurable, so native tag search can be kept on a plain click, and the README presents tag summaries as a way to round up and process tagged content like an inbox.
