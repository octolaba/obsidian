# masaki39/outline-converter

Outline Converter transforms bullet-point outlines into continuous text, working on the current selection or on the entire active note. The auto-header command promotes outline items that have children into headers and renders items without children as prose, with headings starting at the second level by default and siblings separated by line breaks. The custom converter instead controls the transformation at each indentation level from one to five, adding text before or after the content of that level or ignoring the content entirely.
