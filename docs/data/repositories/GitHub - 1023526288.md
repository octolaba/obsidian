# aiksxd/latex-autocomplete

Obsidian plugin that offers a matching list for completing LaTeX formulas. Inside inline or display math, typing a character triggers a suggestion list that is navigated with the arrow keys and applied with Enter, while Space cancels the current completion and starts a new word. The entries it offers are built by the user in the plugin's settings rather than fixed.
