# Jalad25/Okudagram

Okudagram is an Obsidian theme inspired by the computer display graphics of Star Trek: The Next Generation designed by scenic-art supervisor Michael Okuda, a term the README traces to a set decorator on the series. The README states two limits explicitly: the theme is dark mode only and will not render under the light color scheme, and it is desktop only, neither built nor tested for mobile. Its palette is late-TNG peach, beige, lavender, red, amber and blue on near-black, and its font stacks use fonts already shipped on most systems, from Oswald through Arial Narrow for chrome and headings and JetBrains Mono through Consolas for code, set uppercase with wide tracking.
