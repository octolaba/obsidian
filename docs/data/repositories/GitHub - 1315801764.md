# dsebastien/obsidian-ai-editor

AI Editor reviews the note in the editor itself rather than in a chat sidebar, using configurable personas called Editors, each with its own prompt and colour and with findings anchored to the exact words they concern. Seven editors ship and are editable, groups of them called Panels review together and are summarised in a scorecard with per-member verdicts and ranked fixes, and a freeform question put to one editor or a panel comes back as findings. Verbs such as rephrase, summarize, simplify, humanize, critique or continue writing run on a selection, along with margin comments answered in the background, a history panel, an opt-in daemon mode that refreshes findings after a pause, and opt-in per-editor memory distilled from accepted and rejected findings. It is desktop only, runs against a hosted API or a local agent CLI, and shows every proposed change as a diff to accept or reject.
