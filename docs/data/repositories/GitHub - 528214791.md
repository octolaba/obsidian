# almariah/embed-code-file

Obsidian plugin that embeds the contents of a code file into a note, taking the file either from the vault or from a remote address such as a raw GitHub URL. An embed is written as a code block whose body carries PATH, optional LINES and optional TITLE as YAML key-value pairs, where LINES selects individual lines or ranges and omitted stretches are marked with dots. A default list of languages is configurable as a comma-separated setting, and the README notes that it works better with live preview.
