# eatgrass/obsidian-vocab-highlighter

Vocabulary Highlighter marks English words in Obsidian according to how frequent they are, as an aid to language learning and content review. In the plugin's settings tab a highlight threshold controls the frequency sensitivity, colours are chosen for the different frequency ranges, and individual highlight groups can be disabled. The README states that files are reopened in Reading View for the changes to show, and documents one command that toggles the highlighting on and off.
