# benhughes/obsidian-link-exploder

The repository records no description; its README presents Link Exploder, a plugin that creates an Obsidian canvas from a note by placing the note's incoming backlinks and outgoing links, together with their own linked notes, onto that canvas. The canvas is named after the source note, and its destination folder became configurable in the 0.3 release. The README suggests turning a map of contents into a visual map, seeding a canvas from a note of links, or using it as an interactive version of the local graph, and it runs from a single command in the palette. It describes the release as basic and asks for feedback.
