# Phillip383/obsidian-canvas-template-manager

This repository holds a small Obsidian plugin for duplicating canvas templates from a visual menu opened by a ribbon button. Rules defined in the settings look for a card in the canvas whose level-one heading matches the rule name, and a matching card lets default tags be attached to the generated canvas, which the author recommends for finding notes later. The author records that the feature set is deliberately limited, since generalising it beyond one workflow has proved difficult, and that more is intended. The repository carries no description, so this body rests on the README alone.
