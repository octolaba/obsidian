# michael-uplive021/bp-wiki-starter

BP-Wiki Starter is described as the free Obsidian entry point to Public OS Shell, which its README presents as an operating model for turning a vault into a controlled human-AI work system rather than a template collection. The free plugin generates local-only files under a BP-Wiki Starter folder: a short guide to Public OS Shell, a starter path map, a setup checklist and twelve bilingual starter templates. The wider model is said to define how inputs enter the system, how unfinished material stays in staging, how projects, knowledge, skills and protocols stay separate, how agents load context, and how outputs are reviewed before becoming reusable. The repository carries no description and the README is bilingual English and Chinese; these are its claims, not checked behaviour.
