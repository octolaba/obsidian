# jmilldotdev/obsidian-frontmatter-tag-suggest

The repository holds an Obsidian plugin that autocompletes tags inside YAML frontmatter, offering its menu on a line beginning with the tag or tags key. Its README explains the reason it exists: Obsidian's own tag completion is triggered by a hash character, but a hash written inside the frontmatter tags field stops the file from being counted under that tag. The plugin removes the step of going back to delete that character after an autocompleted tag.
