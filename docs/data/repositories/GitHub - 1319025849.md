# quiachonj/merefolk

Merefolk replaces a mermaid entity-relationship block in reading view and Live Preview with a hand-drawn Excalidraw rendering rather than a rasterized image, using crow's-foot arrowheads for cardinality, ELK orthogonal routing that avoids boxes, edge labels placed clear of the lines, and real table rows. Hovering the diagram gives buttons to copy the SVG or open it in a full Excalidraw canvas; edits are saved to a companion scene file, which the inline render then prefers over the mermaid source until a re-sync command discards it. The scene folder is configurable, the diagram scales to the note and repaints on a theme change, and the editor can also be opened from a command and a ribbon icon. It is desktop only and requires the Excalidraw plugin at version 0.18 or later for the crow's-foot arrowheads.
