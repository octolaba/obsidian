# 111pointer111/spider

Repository for Spider, a plugin that turns chat with a language model into a branching map. Its README describes selecting text inside an answer and pressing the tab key to open a child node that carries the surrounding context, so a term can be explored without losing the original thread and several phrasings of one question can sit side by side under the same parent. It records use of OpenAI-compatible endpoints, personal notes attached to nodes, and export of the map to Obsidian Canvas, Markdown or a Mermaid mind map.
