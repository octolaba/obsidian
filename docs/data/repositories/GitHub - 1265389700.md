# rezgi/obsidian-tiny-timer

Tiny Timer is a floating timer widget anchored in the bottom-right corner of the Obsidian workspace, started by typing a duration in minutes and pressing enter. Decimal input is accepted, so a fractional value gives a sub-minute countdown, several timers can run at once, each one can be dragged elsewhere, minimized or closed, and a status bar clock icon or a command spawns a new one. The alarm is a short ascending melody generated procedurally rather than a bundled audio file, and the clock face shows twelve tick marks below twelve minutes and sixty at or above it. The widget takes its colors from the active Obsidian theme, and each new timer remembers the last duration entered.
