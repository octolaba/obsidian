# zacharyc/purple-owl-theme

Purple Owl is a theme for Obsidian MD based on a combination of the Night Owl theme found on the MonoLisa website and the Minimal theme. It uses MonoLisa together with local Mac fonts as primary and backup typefaces on mobile and desktop, and its colours match Night Owl. The README states that the theme is released under the MIT License.
