# AstonDky/obsidian-local-git-sync

Local Git Sync is an unofficial desktop plugin for committing, pulling, pushing and automatically syncing an Obsidian vault that is already kept in a Git repository. It drives the local Git executable rather than an embedded implementation, works with GitHub, GitLab, Gitee and self-hosted remotes, warns when a pull with rebase reports conflicts, and can write placeholder files so empty folders stay tracked. The README requires Git on the machine, a repository around the vault and a configured remote for pull and push, says that SSH keys or HTTPS tokens must be set up in Git by the user, and states that the plugin does not collect, store, upload or manage credentials. It is bilingual English and Chinese.
