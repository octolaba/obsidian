# wilmtang/obsidian-heading-linker

The repository holds Heading Linker and Refactor, an Obsidian plugin that copies links to headings, finds references to them and renames them across the vault. The README records a heading context menu with three actions: copying a Markdown link, which inserts a stable target — an Obsidian block identifier by default, or an HTML anchor — when the heading text is duplicated in the same file; opening a rename modal that updates matching wiki, Markdown and HTML links plus display aliases in the current file, folder or whole vault; and a find-references view that shows each match in context and jumps to it, with a keystroke that renames from the search results. Settings record relative or full vault link paths and the default rename scope, and the shortcuts run only when the cursor is on a heading line.
