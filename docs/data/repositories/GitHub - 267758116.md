# seanwcom/Red-Graphite-for-Obsidian

Red Graphite is a minimal Obsidian theme with both light and dark variants, based on Bear.app's Red Graphite theme. The README records its history plainly: the original went largely untouched for over a year, and this version was rebuilt for the Obsidian 1.0 release as little more than a color theme over the default one, changing the interface rather than how notes render. With the Style Settings plugin a few things can be adjusted, including the base and accent colors, and the README notes that most colors in the theme derive from the base color.
