# Kilowattrl/rpg-homebrew-importer

Imports creations exported from the RPG Homebrew website into Obsidian as Markdown notes rendered as compact cards, whose scoped CSS grids are described as staying consistent across themes. JSON can be imported from downloaded files, dragged in, or pasted, and the website can send an export directly to the plugin, whose request identifier and payload are validated before the normal import window opens; imports either sort into category folders or drop every note into one chosen folder. Each note keeps Obsidian properties and the original source data in an `rpg-homebrew` code block beside the rendered card. Dice notation such as `d20` or `2d6-1d4+3` is clickable, with totals, individual dice, modifiers, sources and roll history shown in a dockable results view.
