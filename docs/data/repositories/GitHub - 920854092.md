# xthecapx/Thecap-cv-generator

This repository holds the TheCAP CV Generator plugin, part of a larger monorepo, which produces a PDF version of a CV from a Markdown note inside an Obsidian vault. The README records two ways to open the preview, a ribbon icon and a command in the palette, and states that the formatting matches the web version of the same generator. It documents the notation the note must use, where the top-level heading is the name followed by key and value lines for contact details, second-level headings are sections, third and fourth-level headings are items and subtitles with optional right-aligned text, bullets are details, and a break marker forces a page break.
