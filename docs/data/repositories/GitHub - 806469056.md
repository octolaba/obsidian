# NailAhmed/Watched-Metadata

MetadataWatcher monitors changes to the metadata fields of Obsidian notes and acts on them, through two kinds of configuration held in its settings tab. Header groups replace a header in the note with the value of a watched metadata field whenever that field changes; a group names the field to watch and the header text and is switched active. Command groups execute predefined commands when the metadata fields they watch are updated. The README documents installation by extracting a release into the vault's plugins directory and enabling the plugin in Obsidian's settings.
