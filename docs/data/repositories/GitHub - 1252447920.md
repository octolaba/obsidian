# ckelsoe/obsidian-developer-toolbox

Developer Toolbox bundles several developer-focused tools for Obsidian, each with its own enable and disable toggle in the settings tab. Issue capture takes an immediate or delayed screenshot of the window, annotates it with pen, box, arrow, text labels and a blackout tool for redaction, classifies it, and generates a paste-ready Markdown payload carrying the active file, view mode, Obsidian version, operating system and enabled plugins, with paths redacted to vault-relative and the payload reviewed before it is copied. A plugin reloader reloads any installed plugin without restarting Obsidian, optionally watching dev build output, and shows the running version and last reload in the status bar. An icon browser lists the icon ids registered in the running install so one can be copied, and a CSS variable inspector completes the set.
