# klaudyu/CalcCraft

Adds spreadsheet-style formulas to Markdown tables. The README states that formulas stay visible while editing, with computed values shown as overlays, and are replaced by their results in live preview and reading mode, the table being treated as a sheet whose columns are lettered and whose rows are numbered. Cells are referenced either as a letter with a row number or in a column-row notation that also supports relative references, ranges in brackets expand as matrices, and the expanded expressions are evaluated with mathjs, so most of its functions are available. A result that is a vector or a matrix is expanded across several cells and the references for those cells are recomputed.
