# ccmdi/obsidian-map-plus

Map+ is a map layout for Obsidian Bases which its README positions against the official Maps plugin, claiming better behaviour on large vaults plus a tag hierarchy, location thumbnails and more customization. Coordinates come either from global frontmatter latitude and longitude keys set in the plugin settings or from a per-view coordinates property holding a list or a comma-separated string. Tags can be given colours, icons and a precedence order, a timeline view filters markers by a date property with grouping and uniqueness modes, and optional search geocoding accepts place names, decimal degrees, degrees-minutes-seconds and Google Maps links.
