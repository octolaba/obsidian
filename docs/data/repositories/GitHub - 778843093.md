# TfTHacker/obsidian-ai-templater

This plugin extends Templater so a template can call a large language model. It is aimed at the OpenAI models behind ChatGPT but works with any model that supports the OpenAI API, and the README states that an OpenAI API key is required and that using it makes internet requests to the OpenAI API unless a local model is configured. Detailed usage instructions live on the author's own site rather than in the repository.
