# AavaGames/obsidian-rename-file-to-selection

Rename File to Selection renames the active file after the text currently selected in it, sanitising the selection first so it is valid as a filename. The single command is intended to be bound to a hotkey, and the README suggests using the Commander plugin to place a button near the file title for use on mobile. It credits an external library for the filename sanitising and offers installation from a release download or through BRAT.
