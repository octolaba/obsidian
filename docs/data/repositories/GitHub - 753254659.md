# DMeurer/improved-potato

Improved Potato is an Obsidian theme built using code from the Things theme, and its README asks that the original author be supported and notes that the original is likely better. The README states that functionality the author did not use was removed, and that options were added through the Style Settings plugin. The recorded configuration options are toggles for the fancy code block and Mermaid styling, per-level heading font size, colour and underline, divider colour, light and dark base colours, line number colour and a configurable line marker.
