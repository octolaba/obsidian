# caronchen/obsidian-epub-plugin

The repository holds an ePub reader plugin for Obsidian, which opens files carrying the epub extension in their own view. Its README describes the whole workflow as placing books in any folder of the vault and clicking one to open it, with a table of contents available while reading. Manual installation by copying the built script, stylesheet and manifest into a plugin folder is also documented.
