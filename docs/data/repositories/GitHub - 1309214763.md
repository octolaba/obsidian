# vryTfmcat/coupon-scheduler

Coupon Scheduler is an offline calendar workspace for planning coupons, groceries, shopping reminders, red packets and recurring activities inside Obsidian. Cards carry validity dates, usable hours, locations, prices, tags and notes, are grouped into outings, groceries and trash, are planned in day, week and month calendar views, and can be kept as reusable templates for recurring activities. The README states that the interface is currently in Simplified Chinese, that planner data is stored through Obsidian's plugin data API with JSON import and export, and that the plugin makes no network requests and collects no telemetry.
