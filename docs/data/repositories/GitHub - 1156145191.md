# Leoyishou/obsidian-ai-autocomplete

Obsidian plugin that offers inline writing completion as ghost text at the cursor, accepted with Tab and dismissed with Esc. Requests go to an OpenAI-compatible chat completions endpoint, defaulting to OpenRouter routed at the Groq provider with throughput-prioritised sorting and fallbacks disabled. Context is read before and after the cursor, continuation follows the detected language in Chinese or English, and the trigger delay, model, system prompt, reasoning effort and reasoning visibility are all settings.
