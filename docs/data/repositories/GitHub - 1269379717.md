# ckelsoe/obsidian-rss-importer

Imports articles and podcasts from RSS, Atom and Substack feeds into the vault as Markdown notes, organised by source feed and deduplicated by note identity. The README states plainly that this is an importer and not a reader, and that Obsidian 1.13.0 or later is required.
