# ayv4zyan/NotebookLM-Mindmap-To-Obsidian-Canvas

This plugin converts a NotebookLM mindmap, copied as either JSON or Markdown, into an Obsidian canvas file through a single import command. Layouts can grow left to right, right to left or symmetrically, node heights adjust to their text, and arrowheads, path types and line patterns can be preconfigured for the Advanced Canvas plugin when it is installed. The README records that obtaining the mindmap data requires a separate browser extension or a similar tool.
