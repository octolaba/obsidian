# sevryng/calloutcustomizer

Callout Customizer edits a callout from its right-click menu, changing the icon, colour, title and fold state without writing CSS. The choices are stored inline in the note as callout metadata, so each callout can differ from others of the same type and the styling travels with the file. Icons come from the Lucide set shipped with Obsidian, searchable by name and by Lucide tag metadata and grouped into 46 categories, and custom SVG can be pasted or picked from the vault; colours use theme-aware swatches, a picker and a hex field. Looks can be saved as presets or promoted to a real callout type, which is written to a CSS snippet so it keeps working with the plugin disabled.
