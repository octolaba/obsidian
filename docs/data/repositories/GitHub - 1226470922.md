# punkyard/obsidian-theme-air

Air is a flat, ultra-dark Obsidian theme built around the built-in accent colour, which it propagates to headings H1 to H6, bold and italic text, highlights, tags, active states, checkboxes, list bullets and folders. Its README describes one uniform surface without pane borders, zero border-radius throughout, near-white body text with stepped grays for muted and faint text, and a bundled headings font file that can be replaced. The ribbon, the Properties block and the Add property control stay hidden until hover, the active line highlights its line number, and tags are drawn as accent-coloured text with no background or border. Both dark and light modes are supported, and code blocks inside lists are handled.
