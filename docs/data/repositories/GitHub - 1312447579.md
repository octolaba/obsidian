# miaoziguan/obsidian-bamboo-china

Bamboo China is an Obsidian theme with a light, paper-toned editor canvas and tinted sidebars and panels, derived from the Cupertino theme. Ten further colour moods sit beside the default bamboo-green palette and are switched from Style Settings, which also exposes toggles and sliders for sidebar and panel expansion, tab style, image zoom, link styling, animation speed and font size. Typography is ordered for CJK text first, falling back through PingFang SC, Hiragino Sans GB and Microsoft YaHei, and all palettes share one light and dark skeleton. On macOS it adds traffic-light window controls, a tab-bar ornament and a frameless layout, while other platforms fall back to a neutral shape treatment; every palette is checked for WCAG contrast, and reduced-motion and contrast preferences are honoured.
