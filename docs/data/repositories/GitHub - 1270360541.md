# naipi11/onedrive-bidirectional-sync

Obsidian plugin that synchronises vault files across Windows, Linux, macOS, iOS and Android through a private OneDrive application folder, speaking to Microsoft Graph directly and needing no OneDrive desktop client. It asks for only the least-privileged app-folder permission, uploads and downloads changes, propagates deletions in both directions, keeps a local conflict copy when the same file changed on both sides, and can run automatically at a configurable interval. Synchronisation compares a stored local snapshot against local file metadata and remote item tags, and the Obsidian configuration folder is excluded by default along with the plugin's own data file, which holds the authentication tokens. The README calls this an early release, asks for a backup before the first sync, and records that every device has to use the same client registration, account and vault identifier.
