# HyoYoonNam/digital-archive

Repository for Digital Archive, an Obsidian plugin that searches books through the Aladin open API, generates notes carrying cover images and metadata, and renders them in a built-in card gallery view. The README states that the library view is a native Obsidian view, so Dataview, Templater or a theme snippet are not required. Each generated note gets frontmatter with title, author, publisher, publish date, page count, category, ISBN, link and a reading status that drives the library filter, and a personal Aladin key must be entered in settings and is stored in the vault.
