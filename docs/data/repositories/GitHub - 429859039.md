# joethei/obsidian-tts

Text to Speech reads notes aloud, with playback started from the status bar or the ribbon and an option to speak only the selected text in edit mode. Voices can be assigned per language: the plugin tries to identify the language of the text, and a lang key in the frontmatter overrides that guess with a two-letter code. It uses the operating system's own speech API, and the README states that it does not work on Android because of a bug in the Webview.
