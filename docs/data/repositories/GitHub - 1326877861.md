# KornilovIvan/Time-Visualization

Collects task lines from across the vault into a single calendar view with day, week and month zoom levels, switched by click or paged with the arrow keys. Tasks are grouped by the note they came from, and checkboxes, inline edits and moving a task to the next day are written back to the source notes. Dates are read from inline fields, from Obsidian Tasks emoji fields, or from a custom regex, which makes tasks read-only. Parsing can be limited to chosen folders, notes and tags, and the view can open automatically at startup.
