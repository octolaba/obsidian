# gr0grig/obsidian-virt-folder

VirtFolder builds a hierarchical structure over the notes of an Obsidian vault so the knowledge base can be navigated like the table of contents of a book. Notes are added to virtual folders from the file explorer context menu, dragged and dropped into a custom sort order, created and deleted from the right-click menu, and every operation can also be reached by hotkey. The README further lists an emoji icon picker with categorised groups, tag-based note highlighting with configurable colours, frontmatter exposed as HTML data attributes for CSS styling, an optional string format for single-parent folder links, note creation through the Unique note creator, Front Matter Title plugin support, and database optimization. It links to the author's articles on organising a knowledge base by the Luhmann method and to documentation kept in the repository.
