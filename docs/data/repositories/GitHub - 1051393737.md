# jritzi/ocr-extractor

Obsidian plugin that runs OCR over PDFs, documents and images embedded in notes and stores the extracted text as Markdown. The text is written below the embedded attachment as an expandable callout, so it is reachable from Obsidian's own search, from other search plugins and from the operating system's file search. Extraction can be started for the active note, a folder or the whole vault from the ribbon icon, the command palette or a context menu, with progress and cancellation in the status bar. The OCR engine is selectable: Tesseract runs locally at no cost but only on English text in PDFs and images, while options such as Mistral OCR are paid and cloud-based.
