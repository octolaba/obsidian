# coddingtonbear/obsidian-apple-notes

Provides an Obsidian front-end for the icloud-md command-line tool, binding one vault folder to Apple Notes and syncing in both directions from Linux, Windows or macOS. Pull and push are reachable from a ribbon icon, a status-bar item and commands, all serialized through a single queue so runs cannot overlap, with optional scheduled pull-then-push on a configurable interval. It is desktop only and requires Node.js 20 or later with the icloud-md CLI on the path. The README warns that the tool reverse-engineers the private CloudKit service behind the iCloud notes site, that every push writes to the live account, and that data loss is possible.
