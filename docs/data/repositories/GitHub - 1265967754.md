# raymondseek/BrainGrowth

Brain Growth tracks how an Obsidian vault grows over time by scanning its Markdown notes and keeping daily local snapshots. It counts notes, bodies, tags and internal links, shows daily snapshots in a dashboard with trend cards and charts comparing recent ranges, and offers a resident mini panel in the right sidebar opened from a ribbon icon or a command. Statistics refresh when Obsidian starts and when vault changes are detected, snapshots are stored through Obsidian's plugin data API, and historical growth can be initialised from existing file metadata. The README states the plugin works locally, sends no vault data to remote services, includes no telemetry, requires no account and does not access files outside the vault.
