# jiaoyingxing/easy-sync

EasySync is a two-way OneDrive synchronization plugin for Obsidian on Windows, macOS, Linux, iOS, and Android. It previews an initial plan, establishes a shared baseline, handles safe one-sided and non-overlapping changes, and exposes history and conflicts; users can separately choose vault files, settings, themes, core or community plugins, while automatic syncing and selected conflict actions remain configurable.
