# jiaoyingxing/easy-sync

Obsidian plugin providing two-way synchronisation of a vault with OneDrive across Windows, macOS, Linux, iOS and Android. Notes and attachments are synchronised by default, while editor settings, appearance, themes, hotkeys and core or community plugins are separately switchable, and sync status, progress and history are shown in a dedicated sidebar. Conflicts are surfaced for line-by-line comparison and resolved by the user, and vaults are matched across devices by vault name. The README warns against placing a managed vault inside another sync tool's directory and states that Obsidian 1.11.4 or newer is required.
