# obafgkm42/obsidian-knowledge-overview

Knowledge Overview turns a subject name into a structured course inside an Obsidian vault: a textbook-like outline, one Markdown note per chapter with numbered sections, and review questions tied to the material generated. Each chapter carries explanations, examples, formulas and common mistakes, introduces terms with their English equivalents, and ends with a terminology table and a model and token-usage footer, while chapters that fail are listed and can be resumed without regenerating the finished ones. The README states that the plugin needs Obsidian 1.12.7 or later and an API key from an OpenAI-compatible provider, and that it works on desktop and mobile. It warns that a full subject costs one outline request plus one request per chapter, quoting a tested figure of roughly three US dollars as an estimate rather than a spending cap.
