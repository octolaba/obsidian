# jiangzizhao/huanmuyu-plugin

A language self-study plugin providing a daily check-in calendar, new-word cards with ten example sentences each, reading annotations and text-to-speech, spaced-repetition review, graded reading with per-word phonetics or furigana, sentence practice with AI correction, and a vocabulary book. The study languages named in the README are English, Japanese, Korean, French, Chinese, Spanish and Arabic. The README states that learning data stays inside the vault, that card and article content is generated separately by a companion skill, and that the plugin contacts a remote endpoint only to validate a paid license key and to download an English phonetic dictionary.
