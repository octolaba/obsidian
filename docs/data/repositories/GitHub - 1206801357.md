# OHM-Engineering/Obsidian-Consolidate-To-PDF

Obsidian plugin that combines the vault's markdown notes into a single export note and then starts Obsidian's own PDF export flow. The README describes a ribbon button and a consolidate command, an options modal offering a cover page, a table of contents linking to the exported sections and a page break after each note, preservation of the folder hierarchy, and skipping of configuration content. It states that a temporary export note is written and the previous one deleted before a new run, and that PDF behaviour such as link clickability depends on Obsidian, Electron and the viewer.
