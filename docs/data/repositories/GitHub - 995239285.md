# jjwheatley/mini-rag

Mini-RAG allows chatting with a locally running language model in the context of selected Obsidian notes and folders: opening a chat on a note or folder chunks its content into excerpts, generates vector embeddings for each chunk, and includes the most semantically relevant excerpts with each query. It relies on a local Ollama instance for its responses, which the README gives as the reason the plugin is desktop-only, and any locally installed Ollama model can be selected. Settings cover the Ollama URL, the chat model, temperature, how many excerpts are retrieved per query, whether embeddings are cached on disk with the recorded privacy trade-off, whether chats without note context are allowed, and whether a dedicated embedding model is used. Chats open from the context menu or the command palette.
