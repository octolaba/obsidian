# tu2-atmanand/Task-Board

Task Board collects the tasks of a whole Obsidian vault onto a centralized board offering several kinds of view, intended for projects from small to large. The README opens with a warning about the map view feature, whose data is kept in local storage, which the author calls a bad design for storing a user's data and says will be changed in the next major release, asking readers to use the feature cautiously or not at all until then. Its stated aim is to document progress while tasks are being completed.
