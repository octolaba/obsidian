# mali-i/deepseek-ai-assistant

Repository for DeepSeek AI Assistant, an Obsidian plugin documented in Chinese and English for managing prompts and keeping a record of AI conversations. It stores prompts with keyword filtering for retrieval, a sidebar timeline that groups them by date, per-prompt links that can be saved into notes to return to an answer later, and a heatmap of asking frequency. Conversations run against DeepSeek's V3 and R1 models with streaming output and basic Markdown rendering, any OpenAI-compatible provider can be configured with its own base URL and model id, earlier conversations can be referenced as context for a new one, and the README states that the API key and all data are kept in the plugin's local data file.
