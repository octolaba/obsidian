# OliverBalfour/obsidian-pandoc

The repository holds the Obsidian Pandoc plugin, which adds command palette entries for exporting notes through Pandoc. Its README lists Word documents, PDFs, ePub books, HTML sites, presentations and LaTeX among the available targets, and frames the point as drafting books, presentations, web pages and assignments in Markdown and exporting without leaving Obsidian. It states that the plugin is in beta with frequent minor formatting issues and asks the reader to proof-read the output; installation instructions live in the project wiki.
