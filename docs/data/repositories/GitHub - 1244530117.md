# dartungar/obsidian-project-notes

Project Notes treats one note as one project, keeping the Markdown file as the source of truth and holding project metadata in frontmatter. Projects are selected by the project tag by default, or by a note property or a folder, and the plugin adds a note bar for editing project metadata inside the note, link previews that show selected project fields in Reading view and Live Preview, and list, table and board layouts for Obsidian Bases. Commands create projects and child projects from a configurable path template and optional Markdown template, generate a ready-to-edit base file, refresh views and repair duplicate properties. Status, progress and due date are the default properties, status driving the project controls and board columns, and further properties can be added, renamed, retyped and reordered in settings.
