# tiancaijb/obsidian-gtd

The repository holds GTD Workflow, an Obsidian plugin that implements an org-mode-style Getting Things Done system on plain Markdown checkbox tasks. The README records task metadata written beneath the checkbox line — scheduled and deadline dates, clock records with a computed duration, inline priority markers and a repeat key that shifts a task forward when it is marked done — plus commands to capture, toggle, cycle priority, promote or demote and insert tasks. It records an auto-created folder structure with inbox, next actions, waiting, someday or maybe and projects, and three sidebar views: an agenda grouping tasks by today, this week, this month and later, a 24-hour timeline over any day's clock records, and per-task time statistics with a pie chart and CSV export. A task timer and a Pomodoro timer both write clock records, and the interface is available in Chinese and English.
