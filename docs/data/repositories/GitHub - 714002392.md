# wenlzhang/obsidian-timestamp-link

Timestamp Link copies links to blocks, headings and notes with a timestamp attached, so a link records when the connection was made as well as what it points at. The README frames this around the slip-box method and argues that the timing of a link is part of its context, letting the reader follow how ideas changed over time and find when particular connections were made.
