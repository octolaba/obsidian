# dbarenholz/halcyon-obsidian

This repository ports the Halcyon colour scheme to Obsidian, and its README states that the theme is dark-mode only. Installation is from the appearance settings with dark themes visible, or manually by extracting a release into the vault's themes folder, which the README notes will not update automatically. It records that the Highlightr plugin uses Halcyon colours when its CSS classes option is chosen, that basic Style Settings support exists as of version 0.0.4, and lists limitations the author calls outside a theme developer's control, such as a code block inside a quote not being recognized by the parser.
