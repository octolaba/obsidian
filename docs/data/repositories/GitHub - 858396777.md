# JoaoEmanuell/obsidian-whatsapp-export-note

WhatsApp Export Note converts an Obsidian note into the text formatting that WhatsApp supports, so it can be exported to a chat. Bold, italics, blockquotes and strikethrough map across directly, while highlights and headings become bold, equations become code, horizontal lines and images are removed, and a link is reduced to its text. The README states that Obsidian's own internal links are not supported and have to be removed by hand.
