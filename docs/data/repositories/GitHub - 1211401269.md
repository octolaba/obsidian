# rmoff/obsidian-canvas-export

This repository holds Canvas Export, an Obsidian plugin that exports canvas files to HTML in light and dark variants, to Excalidraw, Mermaid and D2, and to PDF. Exports run from one command per format, from a multi-format picker, from a re-export command reusing the last settings, or from the file explorer context menu; an existing output file prompts to overwrite, save under a numbered name, or skip. The README explains what survives each format: text nodes are exported with basic Markdown rendering and groups become labelled containers, and it notes that the four JSON Canvas node types do not translate equally to every target.
