# publora/obsidian-publora

This plugin sends the open note, or just the selected part of it, to the Publora posting service, where it is either scheduled for a chosen time or saved as a draft when the time field is left empty. A dialog lists the social accounts connected in Publora, remembers the last ones used, shows a character count, and by default strips YAML frontmatter from the text. Authentication happens through a browser sign-in that returns to Obsidian, with an API key as an alternative, and the resulting credential is kept in the vault's plugin data and sent only to Publora's own hosts. Posts carry text only in this version, so Instagram, TikTok and YouTube, which reject text-only posts, need their media attached in the Publora dashboard.
