# lorens-osman-dev/Glass-Robo

Glass Robo is described as a modern and sleek interface theme for Obsidian, and its README states plainly that the author made it for themselves and that it may not fit other use cases. The recorded main features are a glassy design, shown in separate sets of desktop and phone screenshots, and six further themes and colour schemes selected through the Style Settings plugin. The body of the README is largely collapsible sections of screenshots per feature.
