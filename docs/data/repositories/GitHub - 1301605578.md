# woodamsclark/no-more-untitled

No More Untitled is an Obsidian plugin for reviewing the Untitled.md, Untitled 1.md and similarly named Markdown notes that accumulate in a vault. Its card preview mode shows one note at a time with its path, modification time and rendered contents and offers delete, rename or keep for now, while a bulk delete list shows full paths and content-size hints with nothing selected by default and a confirmation before deleting. Matching is exact on the Markdown basename, so a name such as Untitled thoughts is not included, deletion follows Obsidian's configured trash behaviour, and renaming preserves the folder and extension. The README describes the scope as deliberately narrow with no runtime dependencies and maintenance as best-effort.
