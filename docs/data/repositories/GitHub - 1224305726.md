# lxl448080113/ob-Plugin

Imports Xiaohongshu notes into an Obsidian vault from share text or a note URL. Default note and image folders are set in the plugin settings, as are the frontmatter fields, their order, whether each is enabled and its default value, with placeholders available for date, title, source and video URL. Images belonging to a note are downloaded into the vault and linked from the Markdown, while videos stay as remote links rather than being downloaded as large media files. The README is written in English and Chinese.
