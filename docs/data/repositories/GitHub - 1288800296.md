# fat-pumpkin/SmarTask

SmartTask manages tasks stored in Markdown across list, kanban, calendar and timeline views, the timeline offering a zigzag card layout and a Gantt chart by day, week or month. Tasks are created from a compact input toolbar with due date and priority as inline chips and saved to a specified inbox file, the current file or today's daily note, with unlimited subtask nesting and subtask progress tracking. Filtering covers status, priority, tags, date range and text search, with sorting on several fields and grouping by file, priority, due date or tag, while wikilinks and tags written inside a task description stay clickable.
