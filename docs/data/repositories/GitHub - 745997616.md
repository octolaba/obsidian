# tomaz1502/lean-syntax-highlight

Lean Syntax Highlight is described as a plugin providing syntax highlighting for the Lean programming language in Obsidian, applied live in the editor. Its README states that it is largely a fork of two earlier editor-highlighting plugins and that it supports only Lean, because the other languages those projects covered are already handled natively by Obsidian. Installation is described through the community plugin browser.
