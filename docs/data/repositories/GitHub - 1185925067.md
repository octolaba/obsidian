# Moyf/better-links

Better Links opens a small popover when a link is clicked in Obsidian's Markdown editor, letting the link text and target be edited in place, while Ctrl or Cmd with the click still opens the link. The popover offers quick actions — open the link, copy it in the preferred format, copy the URL or file name for image links, and delete the link — and covers wikilinks, Markdown links, plain URLs and image links, with suggestions that autocomplete vault files and headings and update the display text. The README states external URLs are always copied as Markdown links while internal and image links follow Obsidian's link-format setting, notes an iOS constraint where scrolling cannot start on a link area, and records that the project was developed with AI assistance and inspired by Octarine.
