# wanguliux/workout-block

Workout Block is an Obsidian workout-tracking plugin whose types, fields, units, derived statistics, training plans, muscle mappings, and heatmap metrics are user-defined. It renders the modules as code blocks while storing logs as plain CSV or JSON text in the vault, keeping presentation separate from data and allowing tools such as Dataview to query the records.
