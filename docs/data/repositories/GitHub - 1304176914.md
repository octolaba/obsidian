# wanguliux/workout-block

Workout Block records workouts in Obsidian without imposing a training system: the workout types, the fields each type logs, their units and the statistics derived from those fields are all defined by the user. Everything is rendered as code blocks with the rendering and data layers decoupled, and the data itself is stored as plain-text CSV or JSON inside the vault, so tools such as Dataview can query it directly. Training plans, muscle management and muscle heatmaps are configurable in the same way, and the README records the plugin id workout-block with Obsidian 1.12.7 as the minimum version.
