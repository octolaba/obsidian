# ahmed-hegazi0/image-importer

Image Importer imports images into an Obsidian vault either from the local device or from a web URL, and can optionally create an accompanying Markdown file for each imported image with a custom name. Import runs through a modal, opened by a hotkey configured under Settings and Hotkeys, where the per-import configuration is set; the plugin's settings hold the defaults for those same options. Remote import takes the image URL, with an optional setting that auto-pastes a valid image URL from the clipboard into the modal's input field. The README states that only JPEG and PNG images are supported at present, with other formats expected later.
