# volodymyrkoval/interactive-hill-chart-obsidian

Interactive Hill Chart renders a hill chart from a fenced code block tagged hill-chart, in which each entry pairs a position from 0 to 100 with a label. Dragging a dot updates its position and the change is written back into the code block, and a label written with Obsidian wiki-link syntax becomes clickable. Colours default to the current text colour so charts follow light and dark themes, and every colour field accepts Obsidian CSS tokens, hex with or without alpha, rgb, hsl, named colours or transparent. Curve, baseline, uphill and downhill labels, divider and dot styling are configurable per chart or per dot, and the README states that the chart lives entirely inside the vault with no external service.
