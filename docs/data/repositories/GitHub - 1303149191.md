# PangTouyu717/obsidian-ai-voice-polish

AI Voice Polish records speech from a floating, draggable panel in Obsidian, transcribes it through a speech-to-text provider such as Volcengine or Qwen DashScope, and polishes the transcript with DeepSeek in one of four styles: formal, concise, casual or correction only. The polished text is inserted wherever the cursor sits, including input fields outside the editor, or written to a date-organized note together with the playable recording. The README states that Chinese and English recognition, including mixed speech, works and that the plugin runs on iOS and Android.
