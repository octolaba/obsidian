# Love-Rox/obsidian-kumihimo

kumihimo renders AV signal flow diagrams written as text in a fenced block, opened by either the kumihimo or khm language tag. Ports are drawn on the face the signal flows through, groups become frames, and each run carries its number, length and jacket colour; the cable, wireless, equipment and parts lists are generated underneath from the same compiler. Connections are checked for whether they can physically work, so a mismatch such as HDBaseT into an Ethernet switch, dmx against xlr, rca against spdif or genlock against sdi is reported as a warning. A theme setting offers light, dark, mono and blueprint, overridden by a theme declared inside the block, and the schedules can be switched off.
