# icarsone/obsidian-SoftView

Repository for SoftView, a plugin that opens the current Markdown note in a separate reading pane with a narrower, warmer layout. Its README states that it renders through Obsidian's own Markdown renderer, generates no external HTML, opens no system browser and does not modify the note, so the file stays the single source of truth. It records opening from a ribbon icon or a command, a refresh button, a toggle that follows the active note, navigation through internal links inside the pane, and a back action that restores the previous article and its scroll position.
