# roberts-code/obsidian-theme-modern-dark

Obsidian Theme Modern Dark is described as a theme for the Markdown editor Obsidian, intended to roughly match the style of Adwaita and VSCode in dark mode. Its README states that only dark mode is supported, and documents manual installation by downloading obsidian.css into the vault's themes folder and restarting Obsidian to select the theme. It records that the icon font used for folder and file icons was copied from the Faded theme, which the README says seems to be based on the ITS theme.
