# kdnk/obsidian-daily-note-template

Daily Note Template expands DNT expressions inside existing Obsidian daily notes, identifying daily-note paths from the core Daily notes settings. Expressions are evaluated relative to the date parsed from the target note's path and cover today, yesterday and tomorrow, adding days, weeks, months or years, and formatting the date with a pattern. The README states the plugin does not create missing daily notes, does not apply the full Daily notes template to empty notes and never waits on Obsidian Sync before expanding visible expressions; creating notes and applying the normal template remain the Daily notes and Templates plugins' responsibility.
