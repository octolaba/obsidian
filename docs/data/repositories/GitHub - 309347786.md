# mrjackphil/obsidian-crosslink-between-notes

Add links to current note is an Obsidian plugin that adds a single command for backlinking in bulk: it reads the wikilinks on the cursor's line or in the selection and appends a link to the currently open note at the bottom of each of those notes. An option instead picks the target files through the quick switcher, and the command can be bound to a hotkey in settings. The README records the plugin as tested on Obsidian 0.9.10 and gives the manual installation directory alongside the community plugins route.
