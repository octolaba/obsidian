# jaidetree/obsidian-kanban-base

Kanban Base adds two kanban views to Obsidian Bases and requires Obsidian 1.10.1 or newer. The property view groups notes into columns by the value of a text field chosen as the base's group-by field, and dragging a card to another column updates that property on the note. The folders view makes each direct subfolder of the base's root folder a column, so moving a card between columns moves the file itself and Obsidian updates the links. The author records that development was done largely with Claude and states that the project was reviewed and tested at every phase.
