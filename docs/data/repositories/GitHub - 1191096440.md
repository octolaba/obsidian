# rwyattwalker/obsidian-activity-graph

Obsidian plugin that renders a GitHub-style activity heatmap from a Dataview query placed inside an `activity-graph` code block; the Dataview plugin must be enabled. The query has to return a `date` column, which may be a Dataview date, `file.day` or an ISO date string, and a numeric `value` column used as intensity. Per-query overrides written as plain key-value lines after a separator set the title, days shown, month and weekday labels, legend, week start, colour gradient, legend labels and a fixed minimum and maximum scale. The graph ends on today's local date and runs backwards over `daysToShow` days, with green, blue, purple, orange and red gradients plus any custom palettes added in settings.
