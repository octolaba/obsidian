# yueyinfeng/auto-seq-filename

Obsidian plugin that creates Markdown notes with sequential filenames such as GS0001.md or RY0001.md. Several target folders can be configured, each with its own filename prefix, starting number and digit count, and a command from the palette creates and opens the next file in a selected folder. It reuses the smallest missing number before allocating a larger one, so a gap left where a note was deleted is filled first. The README states the current release targets desktop Obsidian and that mobile support has not been verified.
