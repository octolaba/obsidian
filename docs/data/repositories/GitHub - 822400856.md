# Ori-Replication/obsidian-math-indicator-changer

No repository description is recorded, so this body is grounded in the README alone. Math Indicator Changer rewrites LaTeX-style math delimiters into the dollar-sign delimiters Markdown uses, which the README motivates as making equations generated by AI display correctly in Obsidian. The change is applied to the whole file, or to a selection made first, from a command, an assigned hotkey or a toolbar icon. The README warns that the conversion is based on regular expressions and replaces every occurrence of those bracket delimiters in the file, so unexpected results are possible.
