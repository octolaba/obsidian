# taihoe/style-html-viewer

Style HTML Viewer opens HTML files stored in the vault inside a dedicated Obsidian workspace tab, with a toggle between a sandboxed rendered preview and the raw source. It parses the document and rewrites relative references to scripts, images, audio and video into vault resource URIs, and it reads local stylesheets and injects them inline — resolving nested asset addresses along the way — because the iframe boundary blocks external stylesheets loaded over Obsidian's own protocol. Links to local Markdown or HTML files are intercepted and opened in native tabs while web links go to the default browser, the page runs under strict sandbox flags and a local-only content security policy, and the preview re-renders when the file or its CSS or JS dependencies change.
