# khoj-ai/khoj

The recorded description presents Khoj as a self-hostable AI second brain that answers from the web or from the user's documents, builds custom agents, schedules automations and performs deep research with online or local language models. The README describes a personal AI app that scales from on-device use to cloud-scale deployment, answers from the internet and from documents including image, PDF, Markdown, org-mode, Word and Notion files, and is reachable from a browser, Obsidian, Emacs, desktop, phone or WhatsApp. It also lists agents with their own knowledge, persona, chat model and tools, repetitive research automated into newsletters and notifications, semantic document search, and image generation and spoken output. The README states that the project is open-source and self-hostable and can be run privately on the user's own computer.
