# xnjiang/speakpen-obsidian

Repository for SpeakPen Sync, a plugin that copies voice summaries from the SpeakPen service into the vault as Markdown notes. Its README states that the plugin is a client and does nothing without a SpeakPen account, that the free plan covers three recordings a month of up to five minutes while the paid plan raises those limits, and that each sync makes read-only requests to one documented endpoint on the service, authenticated with the user's token, for notes changed since the last run. It records that the vault is never uploaded, nothing is written back to the service, no telemetry is collected, that edits made in SpeakPen rewrite the existing note in place while keeping its filename, and that a note the user has written into is not overwritten.
