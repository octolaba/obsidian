# bibleCode21/excavelo

ExcaVelo rewrites a rough memo in an Obsidian note into a structured document — meeting minutes, a summary, a decision record or a user-supplied template — by sending it to Claude with context. The README states that the prompt is assembled from a long-lived default context set in the plugin settings, any note-specific context, the memo body and the chosen template, and that the result can be saved as a new file, appended below or copied after a preview. Three backends are documented: an existing Claude Code CLI login on the desktop, an Anthropic API key which also works on mobile, or an OpenAI-compatible endpoint such as Ollama, LM Studio, Groq, Together or OpenRouter.
