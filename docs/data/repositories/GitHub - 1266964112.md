# usero2/obsidian-plugins-cbz-reader

This repository holds CBZ Reader, an Obsidian plugin that opens comic book archive files directly from the file explorer, reading the ZIP structure in memory without extracting it. Pages are loaded lazily as they approach the viewport and released from memory once scrolled past, which the README presents as how large books are handled without exhausting the app. A minimap on the right renders small canvas thumbnails of the pages, with a translucent slider representing the current viewing area that can be dragged with one-to-one pixel mapping or clicked to jump to a page.
