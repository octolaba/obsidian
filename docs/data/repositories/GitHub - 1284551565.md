# baendlorel/obsidian-secret-notes

Obsidian Secret Notes stores private content in a code block, by default named secret, and renders that block as a clickable card. According to the README the block is encrypted locally with a password that never leaves the device and is never stored, after which only ciphertext JSON remains in the note and the plaintext is shown only temporarily once the correct password has been entered. A plaintext block shows an unlock icon and an encrypted one a lock icon; after decryption the title, password hint and body can be edited and the block re-encrypted in place, and the editor carries its own search. The processed block name is configurable in the plugin settings.
