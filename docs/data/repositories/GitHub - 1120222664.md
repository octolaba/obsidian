# jmiba/zotero-redisearch-rag

This repository holds Zotero Research Assistant, an Obsidian plugin that answers questions across a Zotero library from inside the vault. It imports selected Zotero items, extracts PDF text with Docling and OCR where needed, embeds the resulting chunks in a local Redis Stack index, and returns answers whose citations link back to the exact chunk in the note or in Zotero. Imported notes carry chunk markers that can be edited in place, a save reindexes only the changed chunks, and tracked metadata fields and annotations move in both directions between Zotero and note frontmatter. Chat sessions are saved and exportable to notes, with optional rewriting of follow-up questions into standalone queries and an optional retrieval planner.
