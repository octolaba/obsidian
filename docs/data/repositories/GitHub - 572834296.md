# tjandy98/obsidian-review-notes-plugin

The repository holds Review Notes, an Obsidian plugin that lists newly created and recently updated files. Its README records that new files and modifications are appended to the end of the list, that buttons sort the list by file name in ascending or descending order, and that another button clears the whole list. It states plainly that clearing is irreversible.
