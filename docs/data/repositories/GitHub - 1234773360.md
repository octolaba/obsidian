# rogerdigital/vault-inspector

Vault Inspector scans an Obsidian vault for maintenance problems and is suggested for use before publishing, exporting, migrating or cleaning up a long-lived vault. The checks listed are broken wiki links, Markdown links and embeds pointing at missing notes or headings, orphan attachments no note references, empty notes, optional availability checks of external URLs, duplicates by name, size and optional SHA-256 content hash, frontmatter properties used with inconsistent value types, missing or underused tags from a watchlist, and files above configurable size thresholds, with scan progress reported in the app. The README also documents an npm package carrying a read-only terminal scanner for automation and CI, and a read-only agent skill that teaches agents to run scans and read the output without modifying vault files.
