# Krusty84/obsidian-occura-plugin

Occura highlights every occurrence of the text selected in the open note, a behaviour the author took from double-clicking a word in Notepad++ and similar editors. The release notes describe occurrence matching and navigation across Source Mode, Live Preview and Reading View, counts covering the complete note, Unicode word boundaries, debouncing for short selections, and permanent highlight and tag commands that avoid protected Markdown regions. Shortcuts are configured through Obsidian's hotkey settings, and the README states that the plugin installs no global keyboard handlers.
