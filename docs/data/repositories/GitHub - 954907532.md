# sky150/obsidian-image-embedder

Detects an image URL pasted into a note, downloads the image into the vault and replaces the paste with a Markdown link to the saved file. Settings choose the attachment folder relative to the vault root, whether a confirmation dialog appears before embedding, whether the saved file path is shown in the success notice, and the filename format built from name, timestamp and date placeholders.
