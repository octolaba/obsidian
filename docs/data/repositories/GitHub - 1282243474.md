# israerusan/bases-power-pack

Bases Power Pack adds Kanban, Calendar and Gantt views to Obsidian Bases that write changes back into a note's frontmatter — dragging a card, rescheduling a date or resizing a timeline bar updates the note rather than only redrawing the view. The README describes an open-core split: a free Lite tier providing the Kanban board, and a one-time paid Premium tier adding calendar and Gantt timelines, dashboard and analytics views with KPI cards and distribution charts, unlocked by pasting a key. Tier boundaries, pricing and the offline, account-free operation stated here are the README's own claims and were not verified.
