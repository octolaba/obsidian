# gfontenot/obsidian-music-search

This repository holds Music Search, an Obsidian plugin that searches the MusicBrainz database for music releases and creates a structured note for each one. Albums, EPs, singles and other releases are found by artist, title or both from a command or a ribbon icon, and the created note carries genres, the tracklist, the release date, cover art and links to MusicBrainz, Discogs and Wikipedia. Output is customisable through template variables, custom frontmatter fields or a full template file, and settings cover the destination folder, the filename template, tags added to every note, and a folder for locally downloaded cover images.
