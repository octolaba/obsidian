# theadamdanielsson/grill

Grill quizzes users on their Obsidian notes, grades answers against question-specific rubrics, and colors a learning graph as concepts are demonstrated, separate from Obsidian's link graph. It can detect missing links, read embedded PDF text, accept custom grill callouts, schedule concepts with FSRS, and run through configured model providers or a deterministic offline mode; notes can also supply questions from headings, definitions, formulas, and cloze syntax.
