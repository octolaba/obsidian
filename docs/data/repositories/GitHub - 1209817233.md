# ckelsoe/obsidian-plaud-importer

This plugin imports meeting summaries, transcripts and attachments from Plaud.AI into an Obsidian vault. Its README describes the project as early alpha under active development, talking to an undocumented, reverse-engineered Plaud web API that Plaud can change at any time, offered without warranty and best tried first in a non-critical vault. It asks for breakage to be reported as GitHub issues carrying the Obsidian version, plugin version, operating system, reproduction steps and a debug log, and points to a section stating in plain language what the plugin will and will not touch in a vault.
