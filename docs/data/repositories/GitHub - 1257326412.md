# trikorka/tavernus-plugin

Tavernus generates tabletop role-playing taverns as notes in an Obsidian vault, run from a command that opens the generator with configurable or random parameters. A generated tavern carries a name, size, prestige, prices and current atmosphere, plus food and drink menus and available rooms scaled to its prestige, and patrons and local rumors that serve as plot hooks. The README states it supports English and Russian out of the box and includes a built-in editor for tweaking the dictionaries and generation tables.
