# sourit2001/vault-cast

The repository carries no description; its README presents VaultCast as a private podcast player for local audio files inside an Obsidian vault, aimed at people who generate, download or sync audio into the vault and want one player instead of opening files one by one. It scans a configured vault-relative folder and plays audio inside Obsidian with play, pause, previous and next controls, a full-width seek bar, volume and playback speed, and sequential, playlist loop, single loop and shuffle modes. The playlist is searchable and sortable by name or created or modified time, playback resumes from the last saved position, tracks can be marked completed, and a recent plays list is kept. Supported formats are mp3, m4a, wav, flac and aac, a same-named Markdown note can be opened for a track, and a separate command opens the player in the main area for mobile use.
