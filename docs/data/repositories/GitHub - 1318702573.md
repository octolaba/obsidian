# karfekr/obsidian-auto-remove

Auto Remove gives files an expiry measured from their modified time and never deletes silently: when expired files are found it lists them as a folder tree with everything selected, and removes only what is confirmed. A note opts in through frontmatter, with an auto-remove property and an optional ttl in days falling back to a default of seven, while an explicit refusal exempts it from everything. Folder rules apply a time to live, action, destination and gitignore-style ignore patterns to every file inside a folder at any depth, including attachments, with the deepest rule winning and a note's own opt-in outranking any rule. The trash action hands the file to Obsidian and honours the vault's deleted-files preference, while move relocates it and then strips the expiry properties so it does not expire again from its new home.
