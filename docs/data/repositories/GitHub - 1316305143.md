# poopchen/obsidian-recallflow-ai

RecallFlow AI generates flashcards from a selection or a whole note through an OpenAI-compatible endpoint configured with a base URL, API key and model, producing question-and-answer, cloze and multiple-choice cards that can be previewed, edited and regenerated before saving. Review uses the FSRS spaced-repetition scheduler across new, learning, review and relearning states, with four ratings and configurable daily caps on new and due cards. A cramming mode re-quizzes cards already reviewed today without affecting scheduling, while a card manager and a twelve-month activity heatmap cover searching, editing and daily review counts. The interface is available in English, Chinese, Japanese and Korean, card data stays in local plugin data, and review works offline.
