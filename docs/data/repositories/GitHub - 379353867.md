# Obsidian-TTRPG-Community/initiative-tracker

Tracks initiative and turn order during combat encounters in tabletop role-playing games. Creatures and NPCs are added by name, dice roll or bestiary entry, with health, armor class and status tracked per creature, identical creatures grouped, display names to tell them apart, automatic sorting by initiative, and experience calculated from level or challenge rating. Encounters are declared in an encounter code block, saved and reloaded automatically, and custom or SRD creatures come from the Fantasy Statblocks plugin. The README states that the plugin documentation has moved to an external site.
