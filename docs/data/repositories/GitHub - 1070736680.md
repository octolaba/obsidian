# Querke/obsidian-rich-text-editor

Adds a rich-text editing view for Obsidian notes, built on a customized version of MDXEditor, whose output is plain Markdown. The author's stated reason is editing on a phone: removing a checklist item in raw Markdown means deleting its `- [ ]` syntax, while the rich-text editor does it with one backspace. Switching between this editor and Obsidian's own editor is one click.
