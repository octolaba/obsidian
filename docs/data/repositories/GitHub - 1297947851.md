# laughedelic/obsidian-inline-link-suggestions

The recorded description says the plugin underlines plain-text mentions of existing notes in the editor so that clicking one turns it into a wiki link. The README explains that titles and aliases of all notes are matched while typing and marked with a dotted underline; hovering shows the suggested note, and clicking links it, using the note title alone when the text matched the title and an aliased form when it matched an alias, while clicking the text itself only places the cursor. Reading view support is opt-in, a command toggles the whole feature, individual terms can be ignored, and text inside existing links, tags, code, frontmatter, math and HTML is never underlined. The README reports an Aho-Corasick automaton scanning only the visible editor region, measured at about 27 ms to build the index for 10,000 notes and roughly 0.25 ms per viewport scan.
