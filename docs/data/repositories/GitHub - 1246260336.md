# HornatX/writing-annotations

An annotation plugin for novelists, documented in Chinese and English, which attaches branch annotations to selected text. An annotation may hold several variants, such as alternative plot directions or lines of dialogue, and switching variant replaces the displayed text in the note itself, with colours and built-in Obsidian icons assignable per annotation. A sidebar lists the document's annotations grouped by heading level, jumps to a position when a card is clicked, and highlights whichever annotations are currently in view. The README describes silent background backups with a configurable interval and retention count, atomic writes through the vault API, interception of suspicious data wipes, re-anchoring of annotations after the text shifts, and a recycle bin for deleted ones.
