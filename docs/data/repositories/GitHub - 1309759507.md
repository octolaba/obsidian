# tschoffelen/obsidian-gpx

GPX Preview renders map previews of GPX files embedded in a note, aimed at workout tracks: an embed becomes a rounded map card with the route drawn on it, start and finish markers, an optional title taken from the embed's alt text, and workout stats. Distance, duration and average speed are shown by default, while moving time, average pace, maximum speed and elevation gain can be switched on in the settings, in metric or imperial units. The map is composed into a PNG on first load and cached in the plugin folder, so previews keep working without a network connection; the basemap comes from CARTO by default, from OpenStreetMap, or from Apple's Maps Web Snapshots API, which requires an Apple Developer key that the README says is used to sign requests locally. Registering the .gpx extension also makes such a file open as the same map preview in its own pane.
