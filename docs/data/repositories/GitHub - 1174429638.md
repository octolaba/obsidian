# sotirangelo/obsidian-fantasy-map

Fantasy Map displays a campaign map in Obsidian from any image in the vault, with interactive features linked to notes. Markers, polygon regions and rectangles carry a name, description, colour, a main note whose content is rendered in a sidebar when the feature is selected, additional linked notes, tags that search the vault when clicked, and labelled relations drawn as curved arrows between features. Features are grouped into named layers whose visibility can be toggled, maps can be linked into a hierarchy so a marker or region drills down into a local map, and a scale calibrated from two points enables a scale bar and a ruler for measuring distances. The README states that map configurations, layers and features are kept in the plugin's own data storage inside the vault.
