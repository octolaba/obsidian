# Ekrizdis367/obsidian-pantry

Pantry turns recipe notes in an Obsidian vault into one consolidated grocery list and renders those notes as interactive cards for cooking. Its README records that a recipe joins the week's list through a single boolean frontmatter property, that ingredients shared across recipes are merged into a single quantity, and that items are grouped by store category, with by-recipe and flat views available. One-off items unrelated to a recipe and the checkbox progress are kept in a JSON file inside the vault, so they travel with the notes across devices unlike the device-local plugin settings, and finished sections can collapse automatically while shopping. The recipe view applies to notes carrying a configurable type property, whose value may also be a vault link.
