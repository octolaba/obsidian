# joleaf/obsidian-email-block-plugin

Obsidian plugin that adds an email code block for drafting small emails inside a note. The block carries recipient and subject as keys and takes its body either as plain text, as a referenced note, or as free text written after a separator, and a variables mapping plus frontmatter properties fill placeholders in the subject and body. The README documents each of these block forms with examples.
