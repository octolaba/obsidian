# Leonezz/obsidian-tasks-calendar-wrapper

Tasks Calendar Wrapper provides a timeline view of the tasks in an Obsidian vault with configurable filters and rendering options, opened from a command in the palette and offering a quick entry panel for new items and filters. The README describes the plugin as a wrapper around the Obsidian-Tasks-Calendar and Obsidian-Tasks-Timeline projects of another author, adding settings pages and update support on top of them and pointing at those projects for the meaning of the individual options. It also records an example vault inside the repository and announces a refactor toward a separate new timeline view implementation.
