# jesse-r-s-hines/obsidian-open-tab-settings

Open Tab Settings changes how Obsidian opens tabs and navigates between files. Its options make files open in a new tab by default whether they were reached from a link, the quick switcher or the file explorer, switch to an existing tab instead of opening a duplicate, customize where a new tab is placed in the order, and open new tabs in the opposite pane of a split workspace. The primary settings can also be toggled through commands, and the README compares the result to working in an editor such as VSCode.
