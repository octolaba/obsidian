# oxilldat/obsidian-person-network

Person Network draws the people described in a vault's note frontmatter as an interactive relationship map rendered on a canvas, detecting people by a single configurable tag and needing no separate index or data file. A role maps a relation value to a ring colour, a ring stroke style and a position score from 1 to 10 that sets how closely a person orbits the centre node, which is taken from the note marked as self. Names mentioned in a note but without a note of their own appear as ghost nodes that offer to create one, photos are drawn on nodes with a silhouette as fallback, and an in-graph panel carries search, filters, display options and force sliders. The force simulation has no dependencies and its animation loop stops once the layout settles; the plugin can also run as a native view inside Bases.
