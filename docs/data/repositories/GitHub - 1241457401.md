# kilng235/article-annotator-plugin

An Obsidian plugin for annotating articles: selected text in the editor is highlighted and given a comment card in the style of a word processor. A single click on a card locates the passage, a double click edits in place with save on blur and cancel on Escape, and a sidebar panel lists all annotations with locate, delete and export actions, drag-and-drop ordering and grouping that can be renamed, collapsed or dissolved. The README, written in Chinese with an English summary, records six highlight colours with custom colours, bindable hotkeys, a Chinese and English interface, and annotations stored in a single JSON file so they carry across desktop, iPad and Android.
