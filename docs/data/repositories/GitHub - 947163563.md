# Alamion/obsidian-jira-sync

The recorded description says the plugin syncs tasks between Obsidian and Jira. Per the README the sync runs both ways, with issues fetched from Jira, edited in Obsidian and pushed back, and issue notes structured by custom templates built from section, line and inline markers that stay hidden from view. It maps any Jira field including custom fields from add-ons, with built-in mappings for more than fifteen standard fields and support for JavaScript transform functions, and adds work-log statistics and batch submission in the Timekeep and Super Simple Time Tracker formats, workflow transitions, inline comments, and JQL search with batch fetch. Bearer token, basic authentication and session cookie are all supported, several Jira connections can be used at once, and the README links English and Russian guides.
