# RobCC/obsidian-link-mention-plugin

Obsidian plugin that renders empty Markdown links, those written with no link text, as inline pills carrying the site's favicon and page title, in the manner of Notion's link mentions. The Markdown source is not modified: the pill is purely visual, clickable, and opens the URL in the browser, while an ordinary link with its own text is left alone. Rendering is implemented twice, as a CodeMirror view plugin for Live Preview and as a Markdown post-processor for Reading view, with page titles and favicons fetched through an in-memory cache.
