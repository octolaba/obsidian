# schlundd/obsidian-ocr-plugin

This repository holds the Taskbone plugin for Obsidian, presented in its README as a growing set of productivity tools. Two are documented: a two-way sync between Obsidian notes and Todoist tasks that adds links in both directions and is stated to work with the Tasks plugin, and text recognition in images whose output can be formatted through templates, for example into an annotation file or inserted at the cursor. The README states that a Taskbone account is required for the plugin to work, that one can be created free of charge after enabling it, and that paid plans exist. The recorded repository description names the plugin more narrowly, as an OCR plugin that extracts text from images.
