# sean2077/obsidian-dynamic-theme-background

Dynamic Theme Background sets the Obsidian background from a library of images and rotates it on an interval or within configured time windows. The README lists local folders plus Unsplash, Pixabay, Pexels, Wallhaven and a custom API endpoint as sources, and adjustments for blur, brightness, saturation and hue that follow the dark or light theme; switching, saving and fetching are driven from the status bar or the command palette. It records a requirement of Obsidian 1.11.4 or later and states that local images, colors and gradients need no provider request, while provider keys and custom header values are held in Obsidian SecretStorage.
