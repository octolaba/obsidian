# sean2077/obsidian-dynamic-theme-background

Dynamic Theme Background builds a configurable wallpaper library for Obsidian using local images, remote providers, custom APIs, and gradients. It supports blur and color tuning, dark and light theme awareness, time windows, interval rotation, status-bar controls, asynchronous loading, caching, and secret storage for provider credentials.
