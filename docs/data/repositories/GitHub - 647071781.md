# vincentbavitz/obsidian-vox

VOX transcribes the audio notes held in an Obsidian vault, extracting metadata, categories and tag information and writing the transcribed text into its final directory with frontmatter and tags. An unprocessed directory is watched for new files, and a new file triggers transcription and is then saved into the vault; a status panel shows the state of the transcription queue. The README states that the plugin is fully self-hosted, running transcription on the user's own machine through a local Docker backend with no data leaving it, no account and no cost beyond hardware, and it notes that the transcription model is fine-tuned for English and may struggle with other languages. Its stated motivation is that voice memos are not plaintext and so cannot be indexed, searched, sorted or categorised as a collection grows.
