# HGiorgis/sankryptidian

Sankrypt is an Obsidian plugin that encrypts individual files with AES-256-GCM under one master password, writing them out with its own encrypted extension and marking them with a lock icon in the file explorer. The README lists commands and hotkeys for encrypting and decrypting the current file, browsing encrypted files, changing the master password and clearing passwords from memory, plus settings for an auto-lock timeout, what happens to the original file after encryption, and an optional password hint. It records the cryptographic details it claims — PBKDF2 key derivation with 310,000 iterations, a 16-byte random salt, a 12-byte random IV, a twelve-character password minimum, and the Web Crypto API as its only dependency — as the project's own statements.
