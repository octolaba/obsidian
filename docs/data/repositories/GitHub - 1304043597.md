# vsme/obsidian-footprint-studio

This repository holds Footprint Studio, described upstream and in its README as a plugin for creating and editing travel footprint notes with an interactive map, photos and structured frontmatter. The README lists a combined map of all footprint notes with distinct draft markers, a dedicated form instead of hand-edited frontmatter, multi-photo import with reordering, captions and previews, GPS coordinates and capture times read from photo EXIF metadata, place search with reverse geocoding into structured address fields, links to posts in a configurable folder, and per-footprint attachment folders. It states that the editor works on desktop and mobile and that the interface is currently available in Simplified Chinese.
