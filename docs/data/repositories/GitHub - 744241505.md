# eharris128/Obsidian-LLM-Plugin

The Large Language Models plugin is described as giving Obsidian users access to local and web-based models through several chat interfaces — a modal, a widget, a floating action button window, and commands. Its README names OpenAI, Anthropic, Google and Mistral as the cloud providers, reached by entering an API key in the plugin settings, and GPT4All and Ollama as the local options, the first through its enabled local server and the second through a configured host and a model discovery step. Models can be switched from within each chat view, and chats open in the sidebar, the main window or the floating popup.
