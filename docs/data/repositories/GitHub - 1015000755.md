# Shaharyar-developer/remote-fetch

An Obsidian plugin that downloads files from HTTP or HTTPS URLs into the vault through a command-palette action. It takes the filename from the URL or a custom one, detects the file type to add an extension, and lets the destination folder be picked with type-ahead. Its README records that dangerous file types are blocked and that file size and content-type restrictions are enforced, and that the plugin is not yet listed in the community plugin directory.
