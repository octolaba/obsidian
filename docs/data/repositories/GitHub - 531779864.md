# alangrainger/share-note

Share Note publishes a note to the web with the vault's current theme, its options and custom CSS snippets, so the README states the result should look the same as it does in the vault. Sharing is triggered from a command palette entry or from a note's menu, and the first share uploads the theme styles, which later shares reuse until a command forces a re-upload of all data for the note. The README lists the supported content as images, Dataview queries including inline ones, callouts, code blocks, checkboxes, tags and internal links, with a link between two shared notes continuing to work on the shared pages. It states that note content is encrypted by default so that only the sender and the recipient hold the key.
