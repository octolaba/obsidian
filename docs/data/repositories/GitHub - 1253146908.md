# gurio318/obsidian-mandala-chart

An interactive 9x9 Mandala Chart for Obsidian: a main goal in the centre, eight key themes around it and eight supporting ideas per theme, giving 64 items at a glance. Cells are edited inline and accept Markdown including tags, links and bold text; the chart offers a full overview and a per-theme focus mode, saves changes immediately, opens as a dedicated tab from the ribbon icon, and can be embedded in a note through a mandala code block holding JSON. The README records five interface languages detected from the Obsidian language setting, rainbow pastel colours for the themes, circular theme labels and a print export to A4 landscape, and credits the popularization of the method to the baseball player Shohei Ohtani.
