# liyaomingme/desktop-dashboard

Desktop Dashboard replaces the blank Obsidian startup screen with a dual-column control center built on a CSS grid that separates the interactive calendar from the timeline entries for widescreen displays. It applies serif typography throughout and shows the traditional Chinese calendar with shrunk, subscripted year, month, day and hour indicators, and adds a quick capture panel with a frosted-glass interface. Its date parser extracts dates directly from filenames, including shorthand formats, which the README presents as a fix for cross-device syncing when metadata is lost. The README warns that the repository is optimized strictly for desktop and tablet widescreen layouts and directs phone users to a separate mobile release instead.
