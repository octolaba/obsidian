# Cloudac7/obsidian-github-pager

Publishes selected notes and images from a vault to a GitHub repository for static site generators such as Hugo, Jekyll and Hexo. A mapping table in settings pairs local vault paths with remote paths so a remote filename may differ from the local one, files can be pushed individually or batched into one commit, unchanged content is skipped, and auto-sync can push on save or when a note carries a share property. Wiki links are converted to standard markdown links and embedded images are uploaded to a configured image folder with their references rewritten. Configuration takes a personal access token with repo scope, the repository owner and name, a base path, an image path, a commit message template and a default branch.
