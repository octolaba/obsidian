# keathmilligan/obsidian-paste-reformatter

Paste Reformatter rewrites clipboard content as it is pasted, giving control over how HTML and plain text are transformed. HTML is reformatted first, optionally removing empty elements or hard line breaks and applying regular-expression replacements, and is then converted to Markdown, while plain text is treated as Markdown already. Markdown transformations follow in both cases, adjusting pasted heading levels to match the content, handling line breaks and applying further replacements before the result is inserted at the cursor. A brief notification reports whether HTML or plain text content was reformatted.
