# ezra-y/obsidian-vault-clone

Vault Clone is an Obsidian plugin that creates a new vault by cloning the configuration of an existing one, so a source vault is picked, categories of settings are selected, and the new vault is named and located. The README groups what can be inherited into appearance, covering theme, downloaded themes, fonts, accent colour and CSS snippets, behaviour, covering hotkeys, editor preferences, links, attachments, daily notes, templates and graph settings, and plugins, covering the community plugin list, core plugin toggles and plugin configuration. The plugin creates the target folder, copies the selected configuration, registers the vault with Obsidian and opens it. Stated limitations are that it is desktop-only, must be launched from an already-open vault, does not replace the native create-vault screen, and requires a valid configuration folder in the source.
