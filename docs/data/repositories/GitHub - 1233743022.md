# ialex32x/ai-note-mate

Obsidian plugin that adds a vault-connected sidebar assistant with persistent chat, configurable editor shortcuts and checkpoints for reviewing or rewinding AI edits. Vault tools are permitted individually in settings and let the assistant read notes by path or link, search by text or tags and follow links between them, draft and update notes traceably, transcribe attached audio through DashScope or Tencent Cloud, and add tags that match the vault's conventions. It also reads and drafts Obsidian Bases (`.base`) and Canvas (`.canvas`) files, producing table views and filters or card layouts and connections. Specialised work is handed to sub-agents, among them a read-only Vault Inspector and a Vault Editor that rewrites a whole note body.
