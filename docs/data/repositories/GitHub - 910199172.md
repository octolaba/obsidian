# furst/cooksync-obsidian

This is the official Obsidian plugin for Cooksync, maintained by that team, and it imports recipes from a Cooksync account into the vault, including the recipe data, its source and a cover image, with an option to add tags to the imported notes. Setup connects the account in the plugin settings and runs a first sync, after which importing continues automatically or on demand through a sync command. The recorded inputs state that a Cooksync account is required and that it is a paid service for collecting recipes from recipe websites.
