# j4charlie/material-file-tree-theme

Adds Material Icon Theme file and folder icons to Obsidian's file tree, adapting the icons and mapping from the VS Code material-icon-theme project. Matching runs by filename, compound extension, extension, language-id fallback, folder name and expanded-folder name, driven by the upstream icon mapping file, and settings cover icon size, opacity, grayscale and separate file and folder toggles. The README states that there is no build step and no npm dependency, describes the decoration as stable for large vaults and frequent expanding and collapsing, and offers an action that creates, enables or removes a CSS snippet suppressing a theme's own file-tree colours. It also notes that the community installer may not fetch the large icon resource folders, in which case they are imported from a release zip through the settings page.
