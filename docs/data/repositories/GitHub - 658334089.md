# gerrie-myburgh/source-scanner

Source Scanner extracts marked comment blocks from files into the vault as Markdown, and in version 2 lets the user define the folder hierarchy the extracted documentation lands in, for instance a documentation root holding several EPIC entries, each with ITEM entries and each of those with TEST cases. The README records this as the answer to two problems with version 1: extracted comments arrived in the vault without folder structure, and the objective was to document the application being worked on. Version 2 also generalizes from C, C++, Rust and Java style documentation comments to any text file, and drops the WASM parser of version 1, which proved computationally expensive because of character-encoding differences with JavaScript.
