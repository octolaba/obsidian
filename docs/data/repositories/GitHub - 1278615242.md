# ryyHardy/obsidian-typing-stats

Typing Stats compiles typing statistics in the background while you write in Obsidian and lets you review them by day. The recorded measures are active typing time, the number of typing bursts, where a burst ends after a pause longer than a configurable threshold and bursts shorter than a minimum duration are discarded, average net words per minute computed from added minus deleted characters, an estimate of corrections and corrections per minute, and totals of characters added, deleted and net. The README explains that the plugin does not work like typing test websites because there is no target text: instead of reading keystrokes it examines changes to the note's content, and instead of a dictionary it infers errors from backwards cursor movement and deletions. Its author states that the correction measure is not a perfect measure of error.
