# crossbeat461-a11y/table-csv

Opens .csv files from the vault as a table with a sticky header row, in one of two modes. View mode is the default and never writes: a text filter narrows the rows shown. Edit mode changes cells and inserts or deletes rows and columns before saving back to the same .csv file, and empty rows and columns are left as they were. It makes no network requests, and very large CSV files may take longer to render.
