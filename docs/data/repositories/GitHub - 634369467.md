# iadnanmukhtar/obsidian-hadith-lookup-plugin

This plugin takes selected text as a Hadith Unlocked reference identifier and replaces it with the corresponding Quran or hadith text and translation fetched from the Hadith Unlocked API. References address a single ayah or a range, as in quran:2:255 or quran:3:190-194, or a hadith by book identifier such as bukhari:99, and are resolved through the Fetch Hadith command in the command palette. The replacement uses an Obsidian callout by default, and the templates in the plugin settings can address any value of the API's JSON response.
