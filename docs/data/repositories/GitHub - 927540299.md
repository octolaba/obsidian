# situ2001/obsidian-tab-group-arrangement

This plugin rearranges the sizes of Obsidian's tab groups. Its recorded actions arrange the groups evenly or expand the active group while shrinking the others to their minimum size, which the README compares with what VSCode does, and its two modes are manual, which does nothing on its own, and auto expand, which expands the active group whenever it changes or an editor tab is clicked. Actions and modes are reached from a status bar icon or the command palette; the README records that the plugin is at an early stage, that switching to auto expand may need a change of active group or a click before it takes effect, and that expanding by double-clicking a tab is unsupported because that gesture maximises the Obsidian window.
