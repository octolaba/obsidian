# liu-qilong/bibtex-scholar

BibTeX Scholar keeps a literature library inside an Obsidian vault as Markdown notes rather than a folder-based reference manager, so relationships between papers can be written out with nested bullets, tables or flowcharts in context. BibTeX code blocks can be added in any note, papers are cited from inline formats with autocomplete, and hovering a citation opens a popover with the entry's details. The README frames the design around questions a flat library answers poorly — which paper builds on which, how methods evolve, and finding a paper remembered only by what it mentioned.
