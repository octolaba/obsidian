# THeK3nger/obsidian-goban

This repository holds Goban Viewer, described upstream as a plugin for rendering Go and Baduk position diagrams in Obsidian. The README says a diagram is written inside a fenced goban code block using the Sensei's Library diagram syntax and is rendered as an SVG board in the note, on desktop and on mobile. The README calls the plugin very experimental with limited customization options at present.
