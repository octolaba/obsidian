# caorol/obsidian-plugin-tagser

Tagser displays a note's tags property as badges in Obsidian's right-hand pane and makes them editable there. A badge is removed by clicking its close control, edited by clicking the badge itself, and a new value is added by clicking the row beneath the badges, with each change written back to the note immediately. The README recommends setting Obsidian to hide properties in the document while using the plugin, so the note itself reads more cleanly.
