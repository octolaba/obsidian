# MrElvin/obsidian-image-to-cos

Scans the active note for locally stored images, uploads them to configured cloud storage, and rewrites the links in place to point at the remote copies. Tencent Cloud COS, Alibaba Cloud OSS, Qiniu, SM.MS and GitHub are supported as targets, each with its own credential fields and a connection test in the settings. Remote paths are built from templates with variables for year, month, day, timestamp, original filename, extension and a short or full MD5 hash, so uploads can be grouped by date, by note or purely by hash. Both standard Markdown image syntax and Obsidian wiki-style embeds, aliases included, are recognized, and a content-hash cache skips images that were uploaded before.
