# dmgx0/obsidian-stonks

Stonks resolves stock, ETF and crypto tickers written as inline code with a dollar-and-colon prefix into live prices, rendered in place in both editing and reading views and refreshed automatically. Beyond a bare ticker the inline code accepts a small expression, so quantities and several tickers can be combined into a computed value instead of a fixed dashboard block. The README records that tickers are whatever Yahoo Finance understands, that only ticker symbols leave the device and requests go through Obsidian's own network layer, that the plugin claims only inline code carrying its prefix so it coexists with Dataview and other inline-code plugins, and that it works on mobile.
