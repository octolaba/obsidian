# madforstrength/obsidian-wispr-flow-sync

Wispr Flow Sync turns meeting notes and transcripts the Wispr Flow desktop app has already written locally into vault notes, one per meeting, carrying a wispr_id property in the front matter plus an optional companion transcript file. It opens the Wispr Flow application-support database and meeting files read-only, makes no network requests, and states that it is unaffiliated with Wispr AI. One command syncs meetings created or changed since the last watermark and another re-reads everything, while interval syncing, destination folders, subfolder and filename token patterns, a date cutoff and a title filter are configurable. It is desktop-only and expects macOS with Wispr Flow's Notetaker used at least once; changed folder or filename settings apply only to newly synced meetings.
