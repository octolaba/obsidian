# GenoZhou/canvas-acp

This repository holds Canvas ACP, a desktop-only Obsidian plugin for asking an ACP-compatible agent a question about a canvas node. A note, text or group node is selected and a command opens a modal carrying the question field, an editable prompt preview, a statistics line for upstream context size, and a checkbox controlling whether thinking blocks are kept. On submission the plugin creates a new canvas text node, streams the response into it, and labels the connecting edge with the question; a group node contributes all the nodes it contains, and incoming edges add their nodes as upstream context. The agent command, its arguments, the generated node size and the system prompt are configured in the plugin settings.
