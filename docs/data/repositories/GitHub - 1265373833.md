# CyberKurry/pkv-sync-plugin

PKV Sync synchronizes Obsidian vaults across devices through a server the user hosts, with Git as the source of truth so that every change is a commit. Its README, carried in the plugin's release mirror rather than its development repository, records multi-user and multi-vault sync propagated over server-sent events, per-file diff and restore plus vault-level rollback, three-way automatic merge for concurrent text edits with the remainder surfaced as conflict files and an in-app diff view, read-only Git clone access over HTTPS, a built-in MCP server, an admin web interface, metrics, a backup and restore command-line tool, five interface languages and a one-command migration from Obsidian Sync. It states that a self-hosted server is required and that no third-party service is involved.
