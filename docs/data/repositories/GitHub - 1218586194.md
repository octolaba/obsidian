# Radiant-Maple-Studios/rovenotes-obsidian

Syncs recordings and handwritten notes from the RoveNotes service into a vault as Markdown: one page per recording, carrying frontmatter identifiers, an inline-embedded `.ogg` audio file, a summary and the full transcript, and one page per handwritten note with the recognized Markdown, any summaries and a link back. Each sync pass reconciles rather than appends — renames on the service side propagate to the file, late-arriving transcripts, summaries and recognition update the same file in place, and files deleted from the vault are written again. The README states that the plugin issues read requests only, that nothing in the vault is pushed back, and that a paid RoveNotes account is required for API access.
