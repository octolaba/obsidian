# liaocaoxuezhe/obsidian-extension

Desktop-only Obsidian plugin that adds local semantic search over a vault and exposes the indexed content to MCP clients for retrieval-augmented generation. Markdown notes are indexed into vector chunks held by a ChromaDB process on 127.0.0.1, folders and files can be excluded, search runs from a side pane, and related chunks are explored in a Semantic Walk canvas. Because Obsidian installs only the three plugin assets, a runtime installer in settings downloads the pinned ChromaDB and embedding runtimes, verifies their checksums and signed release metadata, installs them atomically and builds a first index; managed downloads currently cover macOS on Apple Silicon or Intel and Windows on x64. Compatible existing Chroma indexes are migrated without re-embedding, interrupted setup resumes from saved recovery state, and the optional Ollama summary model can be skipped.
