# sidkhuntia/obsdian-headings-helper

Heading Helper marks each heading with an H1 to H6 badge in the editor gutter, colour-coded by level, and clicking a badge opens a menu for changing that heading's level. No repository description is recorded, so this body rests on the README alone. Its commands cycle a heading through the levels down to paragraph, increase or decrease the level, set a specific level, or convert a heading back to normal text. Settings switch the gutter badges off, enable warnings when the heading structure might be confusing, and decide whether such a warning blocks the change or merely reports it.
