# junzh0u/obsidian-ccc-search

Opens a quick-switcher-style modal that searches the vault by meaning rather than keywords, showing each hit's note title, path, relevance score and a snippet, with Enter opening the note at the matching section. Search is performed by cocoindex-code, a separate command-line tool the user installs and points at the vault once to build an index; the plugin only launches it and reads results, so it is desktop only. Settings cover the executable path, result limit, minimum score and whether the index is refreshed on the first search of each session. The plugin itself makes no network requests, though whether the indexer does depends on its embedding model, and the first search after a reboot can take up to a minute while that model loads.
