# hadynz/obsidian-kindle-plugin

The repository holds the Obsidian Kindle plugin, which synchronizes and resynchronizes Kindle notes and highlights into a vault. Its README records two methods: scraping highlights from Amazon's Kindle Reader for books bought from Amazon, which it states will not cover books, articles, PDFs or personal documents obtained elsewhere, and uploading the clippings file copied from a Kindle device over USB, which carries highlights, bookmarks and notes for every book on the device. Continuous automatic syncing from one button press is listed among its features.
