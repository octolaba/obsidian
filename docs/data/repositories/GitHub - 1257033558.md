# jdh847/sealmark

Sealmark creates a private proof of existence for an Obsidian note: it hashes the note locally, submits only that digest to public OpenTimestamps calendars, and stores the returned proof as a sidecar file beside the note. The README states that the content never leaves the machine and only a hash is ever published, which is what lets authorship be dated without publishing the text. Three commands cover the lifecycle — sealing the current note, upgrading pending seals once Bitcoin confirmation has landed, and verifying a seal — and the sidecar is a standard OpenTimestamps proof verifiable with the ordinary command-line tool or against a Bitcoin node, so no trust in the plugin or any server is required. A note edited after sealing is reported as drifted: the old proof stays valid for the bytes it sealed but no longer matches the file.
