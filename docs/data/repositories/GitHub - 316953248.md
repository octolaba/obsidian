# oliveryh/obsidian-emoji-toolbar

The repository holds Emoji Toolbar, an Obsidian plugin that opens a searchable emoji picker and inserts the chosen emoji into the editor. Its README records a hotkey-bound command that opens the picker, filtering by typing a word, and insertion either by clicking an entry or by moving with the arrow keys and pressing enter. Listed features are skin tone support, fuzzy and semantic search matching, a recently used list, and an optional Twitter emoji rendering for the preview and the insert modal.
