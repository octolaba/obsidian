# lachlanharrisdev/obsidian-inline-tikz

Renders TikZ, CircuiTikZ and PGFPlots diagrams written in LaTeX inside a note. Diagram source goes in a tikz code block, including preamble lines such as a circuitikz package declaration, and is compiled by the node-tikzjax rendering library. Compiled output is cached in a tikz-cache folder in the vault, which travels with whatever sync service is in use; compilation happens on desktop only, so a diagram must be opened once on desktop before it will display on mobile from the cache.
