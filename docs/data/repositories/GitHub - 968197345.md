# IshizuEitaro/obsidian-wayback-archiver

Wayback Archiver archives the web links found in notes through the Wayback Machine and then appends the archived version beside the original or replaces it. It can work on the current note or across the whole vault, force a re-archive, retry earlier failures, and export or clear the log of failed attempts, with all of these exposed as commands and some as context-menu actions. Settings are organised into profiles carrying their own include and exclude filtering, URL substitution rules and fallback providers, with API keys held globally, and the README documents provisions for safe long-running archival as well as helper commands for archive.today and Web Gyotaku.
