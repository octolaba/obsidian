# c1921/transcript-refine

Transcript Refine sends speech-to-text content to a language model to fix errors and restructure it, replacing either the selection or the whole document in place. Four preset templates are recorded, covering general voice notes, meeting minutes, interviews and stylistic polish, alongside user-defined templates, reachable from the command palette or the right-click menu. The README states that it targets a DeepSeek-compatible endpoint by default and is also compatible with OpenAI and other compatible APIs, and that the API key is held in Obsidian's SecretStorage rather than written into a plaintext config file.
