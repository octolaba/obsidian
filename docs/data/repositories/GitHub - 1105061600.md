# alas-poor-ophelia/windrose-md

A tabletop role-playing map editor and designer that runs inside Obsidian, covering square grid maps for dungeons, battlemaps and building plans as well as hex maps for regions and worlds with radial or rectangular layouts, named regions and nested sub-maps. Maps are painted with image tiles, stocked with objects and labels, obscured with fog of war and linked back to the vault's notes. The README describes it as a (P)React editor, says touch is treated as first class so the tool is usable on a tablet, and adds keyboard and mouse conveniences on desktop.
