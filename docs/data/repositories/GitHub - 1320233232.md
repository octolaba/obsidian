# soringherghisan/obsidian-scroll-control

Scroll Control binds Ctrl+Up and Ctrl+Down to scroll the editor viewport by a single line without moving the cursor, matching the behaviour of VSCode, Notepad++ and Sublime Text. The bindings are registered inside the editor so the scroll repeats while a key is held, and they can be switched off in settings in favour of hotkeys assigned to the Scroll line up and Scroll line down commands, which are always available from the command palette.
