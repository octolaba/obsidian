# neznayer/obsidian-gene-code

This repository holds gene-code for Obsidian, a plugin whose README describes rendering life-science diagrams inside notes the way Mermaid renders its own: a gene-code fenced block is drawn inline as an SVG figure. The README documents two diagram kinds, a lollipop gene variant diagram declaring a gene, its length, domains and per-position variants, and a pedigree diagram built from nodes and couples. Rendering itself is attributed to a separate gene-code core package, with this repository described as the thin Obsidian integration around it. No upstream repository description is recorded, so this body rests on the README alone.
