# PostPollux/obsidian-video-controls-enhancer

VideoControlsEnhancer adds gesture-driven playback controls to the native HTML5 video player Obsidian uses for local video files. Dragging horizontally scrubs through a clip with an adjustable sensitivity slider, dragging vertically sets the volume, a double tap on the right or left half jumps forward or backward by a configurable one to thirty seconds, and a long press without dragging plays at an increased rate between 1.5 and 4 times; each action draws an on-screen overlay showing what is happening. The README states that it works wherever Obsidian renders a local video — notes, Canvas, embedded previews and fullscreen, on desktop and mobile — and that embedded third-party players such as YouTube and Vimeo are not affected.
