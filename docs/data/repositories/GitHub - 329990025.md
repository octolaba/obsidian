# denisoed/obsidian-orthography

The repository holds Obsidian Orthography, a plugin for finding spelling mistakes in a note and correcting a word in one click. Its README labels the plugin an alpha version, states that it does not work correctly in Live Preview mode, handles English text only, and warns that instability could delete data in the current note, so backups are advised. The recorded todo list keeps Live Preview support and mobile style fixes open, while Grammarly integration and a personal dictionary are marked done.
