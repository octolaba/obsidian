# SpatariuRares/obsidian-workout-plugin

An Obsidian plugin that renders workout data as charts, tables and timers, keeping the logs in a single CSV file. The README lists Chart.js charts for volume, weight, reps, duration, distance, pace and heart rate, sortable log tables with editing and progressive-overload targets, countdown, interval and stopwatch timers, and a dashboard with statistics, a muscle heat map and volume analytics. It also records protocol tracking for training techniques such as drop sets and supersets, duration estimation against actual time, Canvas export, custom muscle tags mapped to canonical muscle groups, and a public API for Dataview and Templater queries.
