# ccmdi/propsec

Propsec enforces schemas over Obsidian properties, validating notes against schemas defined in its settings and reporting violations in the status bar and sidebar while leaving the notes untouched. A schema targets notes with a query over folder paths and tags, optionally narrowed by a file name regex, creation or modification dates, and the presence or values of properties. Fields are declared with a name, a type and whether they are required, drawing on primitives such as string, number, boolean, date, array and object, and reusable custom types group fields for schemas that share a structure or need nested validation.
