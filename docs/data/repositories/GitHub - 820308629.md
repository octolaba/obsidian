# FlorianWoelki/obsidian-better-recall

Better Recall brings Anki-style spaced repetition into Obsidian, where decks and cards are created and reviewed inside the app. It implements two scheduling algorithms — the Anki algorithm and FSRS — and adjusts intervals and multipliers from their parameters during a review session. Decks are opened from a sidebar icon or from the `Better Recall: Recall` command, and a session starts by clicking a deck that has cards in it.
