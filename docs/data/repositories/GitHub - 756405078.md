# huedaya/obsidian-simple-file-push

Obsidian Simple File Push sends the current Markdown file to a POST endpoint, and the README describes it as a fork of an earlier obsidian-file-publisher project. The endpoint has to accept a JSON body carrying the file name and the file content, and it must be protected by bearer authorization; the endpoint URL and the API key are entered in the plugin settings. A file is pushed by selecting a sync entry on the note, and the README suggests opening the developer tools to inspect a failed request.
