# gitcpy/obsidian-diagram-popup

This Obsidian plugin shows diagrams from Mermaid, PlantUML, Graphviz and similar sources in a draggable and zoomable popup. The popup opens with a control-click on a diagram or from a button at the top, and can then be zoomed with the wheel or a two-finger touch and dragged with the mouse or one finger; seven on-screen buttons cover zooming in and out, moving in four directions and closing. Settings let the user name the CSS class of the elements to target, with a container option for cases such as an image whose container sits one level above it. The README documents installation through the BRAT plugin.
