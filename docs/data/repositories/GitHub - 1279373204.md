# acornyio/acorny-obsidian

Acorny Sync pulls highlights from Acorny's read-only export feed into an Obsidian vault, writing one Markdown note per source with frontmatter and a Highlights list. Syncing is append-only and idempotent: every highlight ends with a block id, so re-running adds only highlights the note does not already contain and leaves manual edits in place. Source identity is anchored on an acorny-source-id field rather than the filename, so renaming a note or its source title reuses the same note. Syncs run manually, on startup or on an optional interval, one at a time.
