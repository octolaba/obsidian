# shubhmadhavan/obsidian-force-reading-mode

Forces reading mode and makes it persistent, so notes stay in reading view rather than reverting. The mode is controlled from a ribbon menu item or a keyboard shortcut assigned in the hotkeys settings. The README documents manual installation by extracting the release archive into the vault's plugin folder and restarting Obsidian.
