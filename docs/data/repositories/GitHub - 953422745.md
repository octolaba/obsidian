# LIUBINfighter/csv-lite

CSV Lite views and edits CSV files inside Obsidian in a table, with numbered rows and columns, a search over the whole file, a pinnable column, direct cell editing, and row and column operations from a right-click on a header. New .csv files are created from the command palette or the file explorer with an automatically generated unique name, and the view can be toggled to raw source mode. The delimiter is auto-detected and changing it in the toolbar only re-parses the view rather than rewriting the file, plain and Markdown-style links in cells are rendered clickable, and the README states the plugin deliberately avoids modals, a sidebar and a settings tab, keeping its state under the plugin folder.
