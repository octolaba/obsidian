# yildbs/obsidian-harada-method-plugin

Repository for Draw Harada Method, an Obsidian plugin that draws the Harada Method — also known as the Mandara chart, Mandal-art or open window 64 chart — from a code block. A `harada` block lists one main goal, its key plans and their actions using two-space indentation, and the plugin renders the resulting chart of one goal, eight plans and sixty-four actions. The README describes the method as a way to set goals, break them down and pursue them, and lists handling of text that breaks the rules, other indentation characters and further options as still to do.
