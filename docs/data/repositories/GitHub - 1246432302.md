# kotaindah55/better-embedded-canvas

Better Embedded Canvas changes how a canvas embedded in a note is displayed, giving it the same appearance as the canvas view and allowing panning and zooming to move across it. The embed's height can be adjusted in the note, it works in page preview and inside canvases, it is included in exported PDFs, and the README records support for the Advanced Canvas plugin. Canvases are embedded with an internal link prefixed by an exclamation mark, and the author states he still supports the feature becoming built-in to Obsidian rather than remaining a plugin.
