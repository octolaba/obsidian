# yingjialong/obsidian-tag-aliases

Tag Aliases normalises tags at input time: an alias group maps variants such as js and JS onto a primary tag, and typing an alias makes the plugin intercept Obsidian's tag suggestion and offer the primary tag, so the canonical form is what gets inserted. The stated aim is that native search, Dataview and the tag pane keep working because every note ends up carrying the same tag. Beside group management in the settings panel, the README records an optional auto-replace for alias tags that slip through, a batch migration that rewrites existing alias tags across the vault, and JSON export and import of the configuration.
