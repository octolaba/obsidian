# huangcheng/obsidian-notes-bridge

Desktop-only Obsidian plugin that exports notes as portable Markdown and bridges the vault with Bear, WPS Cloud Note, Youdao Note, Flomo, Yinxiang, WeKnora and IMA. Export rewrites Obsidian-specific syntax with individual options for resolving wikilinks, handling embeds, flattening callouts into blockquotes, dropping frontmatter and rewriting attachment paths, and the result is copied to the clipboard or written to an export directory. Each provider is enabled and configured independently in settings while sharing one selection-to-dispatch pipeline and one right-click menu; the README gives that sharing as the reason for bundling them, and notes that several providers drive command-line subprocesses, which is why the plugin is desktop-only.
