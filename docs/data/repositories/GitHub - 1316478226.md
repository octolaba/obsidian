# 2607044640/fluent-onenote

Fluent OneNote adds a two-pane navigator modeled on OneNote: a left column of section folders under the active notebook, shown as cards with item counters and a notebook selector, and a right column listing the notes and nested sub-pages of the selected section. It opens as a floating popup bound to a hotkey, or optionally also as a sidebar, and is driven by the keyboard: arrow keys move within and between panes, Enter opens a note, and typing any character filters notes across the notebook with badges showing where each match sits. Notebooks, sections and pages can be dragged to reorder, a page can be moved between sections, and a folder and a note sharing a name fuse into a parent page with collapsible sub-pages. Popup width, height and accent color are configurable.
