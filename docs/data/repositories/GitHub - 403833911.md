# luckman212/obsidian-reset-font-size

The repository holds Reset Font Size, an Obsidian plugin that returns the font size to a configurable default after the view has been zoomed by mouse wheel, trackpad or keyboard. Its README notes that neither the usual reset shortcut nor restarting Obsidian undoes such a zoom, and that the same change can be made by hand in the appearance settings, which the plugin only makes faster. The reset is reachable from a ribbon button, from the command palette or from a hotkey, and it can optionally reset the window zoom level in the same step.
