# wesswart77/obsidian-meeting-notes

Meeting Notes opens a modal for a meeting's title, date, attendees, type and agenda and writes a structured note carrying frontmatter and Agenda, Notes, Decisions and Action Items sections. Action items use checkbox syntax with an owner marker, and an Extract Actions command copies the unchecked ones into a master actions note. A meetings sidebar lists recent meetings with title, date, attendee count and action count, and the settings hold the meetings folder and the path of the actions note.
