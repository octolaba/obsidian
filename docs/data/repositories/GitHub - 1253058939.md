# colorpulse6/cerebro-mycelium

This repository holds Cerebro Mycelium, an Obsidian plugin that renders the vault as an animated two-dimensional fungal network in a custom view. Markdown notes become clusters grouped by kind, wikilinks are drawn as curved multi-fibre hyphae, recently edited notes glow as fruiting bodies driven by file modification time, and clicking a node sends a cascade through its neighbourhood. The vault adapter is read-only and built from the metadata cache and the list of Markdown files, with kind classification derived from frontmatter, tags, folders and date-style daily-note names. Notes can be dragged to pin them in place with a command to reset the layout, and settings cover palette, recency window, spore density, cluster haze, decorative details and click behaviour.
