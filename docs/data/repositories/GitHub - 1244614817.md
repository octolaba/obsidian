# LJrobinson/TapLog

TapLog logs recurring events with a single tap and writes them to CSV files inside the vault. A tracker is an ordinary Markdown note whose frontmatter declares an identifier, the output folder and file pattern, the CSV columns, and a set of buttons with the values each one records; a matching code block in the note body renders those buttons in Reading View. Tapping a button appends a timestamped row to a monthly CSV file, and the plugin creates any missing folders, files and headers by itself. Trackers can be edited from the plugin settings instead of by hand, and the README lists snacks, habits, symptoms, supplies, chores and inventory as the kind of events it is meant for.
