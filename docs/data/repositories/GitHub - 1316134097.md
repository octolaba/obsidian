# Rinrinsu/pixel-blue-workspace

pixel-blue Workspace adds a single dashboard view that gathers notes, projects, tasks, daily notes and ideas. It provides expandable multi-level navigation with persistent custom items, project dashboards with progress tracking, task boards and recent schedules, editable database-style tables over note properties, daily notes edited and saved in place, and a full-vault Boolean search with BM25-style weighting. A note juicer turns raw material into a structured review that a person confirms before it enters the knowledge base, and annotations and visual Markdown editing support that review. Optional integrations with OpenAI, Claude, a secure gateway or a local Codex bridge stay off unless configured, keys are kept in Obsidian SecretStorage, and the plugin ships a pixel-blue light and dark skin that pairs with the theme of the same name.
