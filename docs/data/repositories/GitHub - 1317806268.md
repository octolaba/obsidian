# kosperun/obsidian-layout-switcher-uk-en

Converts selected text between the English QWERTY and Ukrainian keyboard layouts, for text typed before the layout was switched. Three commands are registered: convert to Ukrainian, convert to English, and a fix command that picks the direction by whether the selection looks more Cyrillic or more Latin. With nothing selected, the word under the cursor is used instead. The mapping follows physical key positions and covers the standard Ukrainian letters, with the rare one that has no dedicated key placed on the backtick position.
