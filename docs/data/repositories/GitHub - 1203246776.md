# marcomandy/plain-text-kanban

This plugin renders nested Markdown lists as interactive kanban boards while leaving the underlying file plain text. Its README documents the format: a column is a top-level list item carrying a first-level heading, a card is a nested item carrying a second-level heading, text below a card is its body, hashtags in a card title are labels, and colors and swimlane configuration are stored as HTML comments. A board is opened from the file explorer context menu, and the board scrolls horizontally with fixed-width columns that can be added, deleted, archived, renamed inline, reordered by dragging and badged with a card count. The README also states that the plugin was developed entirely with an AI model.
