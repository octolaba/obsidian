# egradman/scales-chords

Scales and Chords captures guitar and piano tabs in a fenced code block using the tab language, marking chord lines by ending them with a percent sign while lines without that marker are rendered unchanged. In preview each chord on a marked line is shown in bold and is clickable, and clicking opens a modal with a chord diagram supplied by the ScalesChords service, while every chord captured from the block is also rendered as a stack below it so a song's chords stay in view. The instrument is chosen in the settings from guitar, piano, ukelele, mandolin and banjo. The README states that the chord images come from a ScalesChords API and that this was the author's first plugin.
