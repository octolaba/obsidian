# towishy/owen-mermaid

Owen Mermaid views and edits Mermaid diagrams rendered as SVG inside Obsidian notes. Its README records an inline toolbar and a right-click menu on rendered diagrams offering zoom, editing and PNG or JPG download, a full-screen pan and zoom viewer, and a flowchart-focused visual editor for creating shapes, dragging nodes, editing text and adding, changing or deleting connectors, which writes the result back into the original Mermaid code block. Download settings cover save location, output folder, filename template, quality, background and scale; one command exports every rendered diagram in the active note to a vault folder with an optional Markdown batch report; and the interface follows Obsidian's locale, using Korean for Korean and English elsewhere, with an override in settings.
