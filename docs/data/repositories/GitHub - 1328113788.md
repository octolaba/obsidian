# FountainChan/obsidian-hexo-send

Hexo Send is a desktop-only plugin that prepares selected notes, folders, or file-tree selections for a local Hexo blog repository. Before writing anything it asks for the category and lets tags, keywords, descriptions and image alt text be edited, then copies local images into an abbrlink-based images folder, runs two Hexo validation passes, stages only the planned post and image paths, and creates exactly one Git commit. It stops at a committed-but-not-pushed state, pushing only after an explicit confirmation, and it never runs a Hexo deploy. It requires desktop Obsidian 1.13.0 or later, Node.js and Git on the system, and a local Hexo repository with its own Hexo CLI and abbrlink package installed.
