# Hajorda/obsidian-mac-now-playing

A macOS-only Obsidian plugin that shows the currently playing Spotify or Apple Music track in the status bar, with a popover carrying album art, a live progress bar and play, next and previous controls. The README states that the player is read through native AppleScript, so no developer API key, OAuth login or internet connection is involved, and which of the two players to follow is chosen in settings. Settings also cover the status-bar icon style and position, the display format string, a maximum title length, sliding text for long titles, a polling interval of one to ten seconds, hiding the item while playback is paused, and turning off the album art or the progress bar.
