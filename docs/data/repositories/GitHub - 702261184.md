# shlemiel/globaloe

This repository holds global-markdown-encrypt, described upstream as a plugin for encrypting Obsidian Markdown in memory from a single password. The README says files carrying an aes256 extension are encrypted and decrypted transparently while editing view is the default, and that images and other non-Markdown files are excluded. It records the cryptographic choices as PBKDF2 with SHA-512 over one million iterations for key derivation and AES-256 in GCM mode for authenticated encryption, and it warns of possible data loss on an unexpected error, asking for periodic backups.
