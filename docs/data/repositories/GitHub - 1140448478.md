# madhusudan-kulkarni/obsidian-speed-reader

Repository for Speed Reader, a plugin that presents a note one word at a time using rapid serial visual presentation. Its README describes highlighting the recognition point inside each word, stripping formatting such as links, bold text, code, frontmatter and comments before reading, and inserting short pauses at punctuation, numbers and longer words. Reading speed can be changed while reading, with skipping and jumps between sections, a focus mode that hides the controls, and the option to read only a selection.
