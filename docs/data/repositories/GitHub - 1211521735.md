# dsebastien/obsidian-hidden-folders-access

Hidden Folders Access is an Obsidian plugin that makes root-level folders whose names begin with a dot visible to Obsidian and indexes the notes inside them. The README records per-folder opt-in from the settings tab, after which the files appear in the file explorer, Quick Switcher, search, graph, metadata cache, Bases, Dataview and any plugin using the standard vault API, with filesystem watchers keeping create, modify, rename and delete events live. It states that nothing on disk is renamed or symlinked — the entries are injected into the live vault cache, and turning a folder off or disabling the plugin removes them again — so external tools that rely on the dot names keep working. The README records the plugin as desktop-only and cross-platform.
