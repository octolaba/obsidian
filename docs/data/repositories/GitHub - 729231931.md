# andredalbosco/obsidian-wypst

Wypst renders Typst math inside Obsidian, overriding the regular inline and display math blocks so their contents are typeset as Typst rather than LaTeX. To stay compatible with existing notes the rendering backend falls back to MathJax when LaTeX-specific structures such as begin and end environments or backslash-prefixed symbols appear, so an expression written with a backslash renders as LaTeX while its Typst spelling renders through Typst. The README adds an experimental setting that falls back to LaTeX on error, and states that equivalent Typst and LaTeX expressions should render to exactly the same output.
