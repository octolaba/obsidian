# Wittionary/mammoth-obsidian-theme

Wittionary/mammoth-obsidian-theme holds Mammoth, a dark theme for Obsidian which its author calls highly experimental and still being figured out. It was designed for and used primarily with three vertical panes while fullscreened, and the README shows examples for headers, blockquotes, codeblocks and the command palette. Support for the Todoist plugin is recorded as broken in v1.0 and marked to be fixed later.
