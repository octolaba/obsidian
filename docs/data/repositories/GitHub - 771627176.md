# icealtria/obsidian-telegram-inbox

Telegram Inbox receives messages from Telegram bots and adds them to Obsidian's daily note. The README records the setup: create a bot, paste its token into the plugin settings, add the allowed username or Telegram id, and press the restart button. It notes that while the plugin is not running Telegram keeps pending messages for at most 24 hours, and it documents building the plugin from a clone and reading the developer console when reporting a bug.
