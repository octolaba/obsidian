# sunzyyu/obsidian-default-view

Sets a default view mode per note through a frontmatter key holding either read or edit; the view switches as soon as the note is opened, and a note without the key keeps Obsidian's default behaviour unchanged. Three commands set the key to read or edit or clear it from the active note, and the README states there is no settings tab because everything is controlled at the note level. Compatibility is recorded as Obsidian 1.12.0 or later on desktop and mobile.
