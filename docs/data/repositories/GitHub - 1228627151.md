# Etudes-Informatiques-et-Services35/gtc-sync

GTC-Sync is an Obsidian plugin that synchronises notes with GTC, an ERP system, over a persistent WebSocket connection to a GTC-Sync server. The README records that only notes carrying an IdNote field in their frontmatter take part, that a modified or renamed active file is pushed after a one-second debounce with its content and its creation and modification dates, and that a rename also re-syncs every note referencing the renamed file. In the other direction the server can send JSON commands to read, create, replace, move, find by property or open a note, each answered by an acknowledgement or an error. The README also records optional token authentication on connect, a ten-second timeout on outgoing requests, session replacement when another instance connects with the same token, and a guard that stops remote writes from triggering an outgoing sync.
