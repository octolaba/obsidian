# blakebratcher/obsidian-cisco-syntax

Syntax highlighting for Cisco IOS, IOS-XE, IOS-XR and NX-OS configuration inside Obsidian code blocks: a fenced block tagged cisco is colorized in both Reading mode and Live Preview. The README states that one grammar drives both views, Reading mode through Obsidian's bundled Prism and Live Preview through a CodeMirror 6 extension, and that it recognizes comments, the no and default negation prefix, command keywords, routing and L2/L3 protocols, interface names, IPv4 and IPv6 addresses with CIDR, MAC addresses, quoted strings and numbers. Values in credential-bearing commands are tokenized as a secret; the README says this recognition is heuristic and colors the value only, without hiding or encrypting it. Colors follow the active theme by default, with an optional Vibrant palette.
