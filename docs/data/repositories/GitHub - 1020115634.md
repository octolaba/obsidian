# desimpson/syncer

Fetches items from external services and writes links to them into a target Markdown file under a configurable heading. The sources are Google Tasks, starred Gmail messages, Microsoft To Do, flagged Outlook mail, Azure DevOps work items assigned to the connected user, Firefox bookmarks on desktop and Todoist, each authenticated on its own, through OAuth for the mail and task services and a personal access token for Azure DevOps. Sync runs in the background on a configurable interval and on demand from the command palette, and only incomplete items are pulled in, so completing one at the source drops its line on the next run. Writing completion back to the connected service is optional and off by default, as is deleting a Google task that was deleted in the note.
