# yaye-work/obsidian-better-tables

Better Tables renders an interactive table editor from a `table` code block in an Obsidian note, also insertable through a command. Cells are selected by clicking and edited on a second click or immediately with a quick-edit setting; arrow keys, Tab and Enter move around; dragging across cells selects a block to copy or clear; dragging the lines between rows and columns resizes them and dragging the edge handles reorders them; hovering between cells offers an insert dot, and `+` buttons add a row or column. Column alignment is set from a right-click menu, `Shift+Enter` inserts a line break in a cell, a trash button deletes the table, wide tables scroll sideways with saved widths and heights, and the README states the table is saved as ordinary Markdown so it still works elsewhere.
