# mscott99/Latex-Exporter

The repository records no description; its README presents Latex Exporter, which turns an Obsidian note into a LaTeX paper by following its embeds so that everything visible in the note is included in the export. It handles embedded content including embeds of individual headers, LaTeX environments such as theorem and lemma with wikilink references to them, citations of several kinds, sections derived from Markdown headings, section and equation references, and title and author taken from the YAML header. Abstract and appendix sections are treated specially, exports may follow a template or send a selection to the clipboard, Markdown quotes become LaTeX comments and Obsidian comments are dropped. The README says the workflow starts from a longform note that structures the content through embeds, and names citation, Breadcrumbs and MathJax companion plugins.
