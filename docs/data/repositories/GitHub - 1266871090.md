# JhihJian/obsidian-hr-timestamp-plugin

HR Timestamp rewrites a divider line typed in the Obsidian editor into a timestamped one: a full line of four or more hyphens followed by Enter becomes a rule carrying the local date and time in a `YYYY-MM-DD HH:mm` italic suffix. In Reading view and Live Preview that line renders as a horizontal divider with the timestamp centred in the rule, while the Markdown source stays a single plain-text line, and Live Preview shows the raw source while the cursor sits on the line so editing and deletion behave predictably. Standard three-hyphen horizontal rules are left unchanged and dashed lines inside fenced code blocks are ignored. The README is written in English and Chinese.
