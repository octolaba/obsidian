# Lyqed/copy-as-note

The repository holds Copy Note Content, an Obsidian plugin that copies the raw Markdown of the active note to the clipboard. It can also copy a single note, a multi-file selection or a folder from the file explorer context menu, prepending each note's title as a heading and joining several notes with a horizontal rule, and a setting decides whether YAML frontmatter is included. The README presents it as built for mobile, where its command can be placed on the toolbar, with a ribbon icon on desktop.
