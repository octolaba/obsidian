# pingo8888/chinese-novel-assistant

This repository holds Chinese Novel Assistant, an Obsidian plugin collecting small conveniences for writing novels in Chinese. It maintains a settings library of ordinary Markdown files with a side view for sorting and categorising, highlights those keywords in the manuscript with hover previews of their content, adds selected text to the library from the context menu, and inserts references to existing entries through a fuzzy-search trigger typed inline. Further features are floating inspiration notes stored as separate files, a word count tuned for novels with per-chapter counts in the file explorer, word-count milestones beside the line numbers, first-line indent and line and paragraph spacing controls, and detection of mistaken English punctuation. The README states that every feature is desktop-only and was tested mainly on Windows 11.
