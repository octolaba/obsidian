# zhengxn1/weread-vault

Synchronizes WeRead book metadata, highlights, thoughts, reviews and popular highlights into the vault, and matches a pasted book list against WeRead editions to add many books at once, including paper books with no electronic highlights. Personal reading notes are kept as separate Markdown files linked to a book by frontmatter identifier fields, so an overwriting sync cannot delete them, and a book's detail page shows WeRead thoughts and local notes together. Notes are created from the shelf or a book card, with books picked from a searchable dropdown by title, author or book id, and outside material imported from Markdown, TXT or DOCX, preserving Word paragraphs, tables and images. It is a fork of an earlier WeRead plugin under a new plugin id, is desktop-only because login uses an Electron window, and needs Obsidian 1.8.7 or later.
