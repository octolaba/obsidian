# psovit/obs-plg-bmc

Strategist Toolkit generates a Business Model Canvas as an Obsidian Canvas file, from a command-palette action or a ribbon button. A modal asks for the business or project name, which goes into the filename, and the canvas is created in the folder of the active file, or the vault root when there is none, and opened straight away. The README records nine cards laid out in the classic grid at non-overlapping coordinates, each with a distinct Canvas colour, an emoji heading, a prompting question and a placeholder to type into.
