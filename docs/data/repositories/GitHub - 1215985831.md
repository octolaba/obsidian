# springrain1/get-to-obsidian

Get Notes Importer synchronizes content from Get Notes into Obsidian through browser export and OpenAPI channels, with incremental and scheduled pulls, ZIP import, attachments, and source-link extraction. Its bidirectional mode writes only supported titles, tags, and marked content back to the service, while derived transcription, attachment, and source material remains local. The plugin also offers quota tracking, conflict safeguards, multiple visualization options, and mobile support.
