# springrain1/get-to-obsidian

Imports content from the Get Notes service into a vault over two channels: a browser-automation route using Playwright with a ZIP export, and a REST OpenAPI route. The OpenAPI channel adds two-way sync, knowledge-base and subscribed-creator sync, transcript sync, semantic retrieval against cloud vectors, image upload with content-hash deduplication, remote-deletion handling, parent-child folder mapping, a three-column conflict merge interface and a quota manager that shows remaining read and write allowances and suspends features when they are exhausted. Incremental sync skips already-imported notes, attachments are imported by type, source links are written into frontmatter, and notes can also be browsed as a timeline or on a canvas. The recorded upstream description states this fork fixes manual and automatic import on Windows and improves conversion to markdown.
