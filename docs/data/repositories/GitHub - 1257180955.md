# Mappedinfo/local-zotero-mirror

Local Zotero Mirror is a desktop Obsidian plugin that mirrors Zotero collection structure, item metadata and Zotero's native notes into local Markdown, designed to work with the author's companion Zotero plugin Local Zotero Bridge. It writes one canonical note per Zotero item, regenerates collection index notes linking to those notes, preserves user-written sections outside the managed blocks, migrates Zotero native notes into a protected block, and writes a local full-text search index for searching from the Zotero side. Zotero tags become Obsidian-safe namespaced tags while the originals are kept in a separate property, commands and context menus open Zotero items and PDF attachments, and reading mode renders Pandoc-style citations as APA parentheticals with a virtual references block built from the citekeys used.
