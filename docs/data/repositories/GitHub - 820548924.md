# connorpark24/refresher-plugin

Obsidian plugin that summarises Markdown notes from a specified folder, including its subfolders, using the GPT-4 model from OpenAI. The summaries are displayed in a modal for review. The folder path, a regular expression for matching, and the OpenAI API key are configured in the plugin settings.
