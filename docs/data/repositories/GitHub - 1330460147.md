# ripple-asuna/agent-dashboard

Agent Dashboard collects vault health, inbox, task-flow and note-creation summaries into a single Obsidian panel, alongside today's tasks with persistent TODO, DOING and DONE states and project tracking filtered by folder and frontmatter status. Once a day at a configured hour it queries GitHub repository search and RSS feeds from Nature, Science, Cell and Physical Review Letters, caches the responses and writes a dated Markdown archive, showing five current signals on the dashboard. On desktop it can also start a separately installed Codex CLI with those signals as a prompt and save the resulting report in the vault. It requires Obsidian 1.8.0 or later and carries no telemetry, advertising or bundled API keys.
