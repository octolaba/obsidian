# zeruhur/obsidian-lonelog

Repository for Solo TTRPG Notation, a plugin for recording solo tabletop roleplaying sessions in a fixed text notation. Its README states that the notation lives in code blocks so narrative text stays readable, and covers actions, oracle questions and dice rolls, tags for non-player characters, locations and threads, and progress clocks, tracks and timers. It lists six views reachable from the ribbon or command palette, commands that insert campaign, session and scene templates, and automatic indexing of campaign files.
