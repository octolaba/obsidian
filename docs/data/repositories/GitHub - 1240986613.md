# clancyj11/simple-flashcards

Simple Flashcards reads flashcards written inline in Obsidian notes and reviews them with optional spaced repetition. The README states that cards are read only inside a block opened by a bullet ending in a triple colon, and only from that block's direct children, so templates, mathematics and ordinary prose are never mistaken for cards. Five delimiters are documented — a basic and a forward form producing front and back, a bidirectional form producing two cards, a cloze form with numbered groups that hide together, and a multiline form whose answer is the bullet's own sub-bullets. Cards are filed into decks by a configurable tag prefix placed on the block header, on a single card line or anywhere in the note, with untagged cards going to a default deck.
