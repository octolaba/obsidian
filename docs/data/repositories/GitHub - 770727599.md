# SaalikLok/lavadocs-obsidian

The Lavadocs plugin is described as pushing documents from Obsidian to Lavadocs. Its README says a Lavadocs account is required: the account's Lava Key is copied from the site's account settings and pasted into the plugin settings, and a self-hosted instance additionally needs its full URL entered there. Once configured, opening a note and clicking the added sidebar icon pushes that document to Lavadocs for sharing. The README also records the service's pricing, with a free allowance of 50 documents in the hosted edition and pay-what-you-want access to the self-hosted repository.
