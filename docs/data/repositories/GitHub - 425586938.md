# ChopTV/Obsidian-Theme-That-Shall-Not-Be-Named

This repository holds an Obsidian theme built on the color palette Matheus Zarkov used in his Slytherin theme, drawing on House Slytherin and other Harry Potter colors. The README lists seven working snippets that form its groundwork: base colors, headings borrowed from the Cybertron theme, fonts, graph view overrides, checkboxes, blockquotes using only side and bottom borders, and tags rendered as rounded buttons in preview mode. The author records the theme as a work in progress and does not promise that it works with every plugin.
