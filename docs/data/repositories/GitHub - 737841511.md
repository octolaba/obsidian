# lorens-osman-dev/cluster

Cluster builds a parent-child hierarchy among Obsidian notes, aimed at making note clustering workable on mobile devices while also working on desktop. The README describes clustering as a way to give notes a structure that makes navigating, searching and understanding the relations between them easier, and illustrates it with a Programming note holding JavaScript and CSS children which hold their own children in turn. The plugin provides commands, in-note buttons and ribbon buttons for that process, and the README states that the plugin is easier to use than the explanation suggests.
