# hirose30/terminal-agent-tabs

Terminal Agent Tabs runs command-line agent sessions, the README naming Claude Code, Codex and Gemini CLI, as ordinary Obsidian tabs, several at a time, each from a configurable CLI profile. A sidebar lists every session with status and notifications, tabs split horizontally or vertically, font size is per tab, titles update from terminal escape sequences, and a terminated session can be resumed. Selected note text can be sent to the active session, hook events read from a JSONL file raise notices and a macOS dock badge, and colour themes can be read from a Ghostty configuration. The README states that the plugin relies on a POSIX pseudo-terminal from a bundled Python helper, that only macOS is actively tested, that Windows is not supported and that Linux is unverified.
