# HEONO3H/simple-folder-note

Simple Folder Note treats a Markdown file whose name matches its folder as that folder's note. The README states the plugin does two things: it stops the folder note from appearing separately in the file explorer, and it makes clicking the folder name open that note in the current tab. Both layouts are recognised — a file inside the folder and a file beside it — with the inner one taking priority. The README is bilingual in English and Korean and records no settings beyond that behaviour.
