# prof18/html-shelf

HTML Shelf lists the HTML files in a vault and renders them inside Obsidian on desktop and mobile, where such files are otherwise missing from the file explorer or open in an external browser. A shelf view opened from the ribbon or the command palette filters pages by title, path and section, relative links between pages stay inside the plugin, and a per-page menu copies the vault-relative path or deletes the file. Settings include or exclude folders and hide .htm files, index pages are treated as navigation targets rather than entries, and a folder may carry an html-shelf.json manifest that titles and groups the pages beneath it without hiding unlisted ones. Vault HTML is treated as untrusted: scripts, event handlers, embedded frames, refresh redirects and remote stylesheets are stripped.
