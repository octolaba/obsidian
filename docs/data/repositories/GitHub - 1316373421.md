# llxzxzxll/particle-spoilers

Particle Spoilers hides passages of a note behind a spoiler revealed by clicking it, in one of three styles: animated particles, a solid color block, or a blur filter. Text is marked by wrapping it in a configurable marker, double vertical bars by default, and a ribbon icon and an Insert spoiler command wrap the current selection. Settings cover particle density and speed, use of the app accent color or a custom color, blur amount and reveal on hover, whether a revealed spoiler closes again when the pointer leaves, and whether the effect applies in Live Preview or only in Reading mode.
