# joleaf/obsidian-dmn-plugin

Repository for the DMN Plugin, which renders DMN decision models interactively inside Obsidian notes using the dmn-js library. A `dmn` code block points at a `.dmn` file in the vault by relative or absolute path or by a Markdown link, and its parameters set which decision table opens, the canvas height, the zoom level and coordinates, whether zoom buttons and a link to the source file are shown, and whether a white background is forced. The README points to the separate DMN Eval Plugin for evaluating a model rather than viewing it.
