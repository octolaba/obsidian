# Quorafind/Obsidian-Float-Search

Opens Obsidian's own search view inside a modal, reachable by hotkey. Three commands search all content, search all content while keeping the entered text for thirty seconds, or search only the current file. Results are driven from the keyboard: arrow keys move between results, shift with the arrow keys expands or collapses the results under a file, and enter opens the file in the background, in a new pane, in a new window, or while closing the popup, depending on the modifier. A result can be previewed beside the list with tab and its content copied to the clipboard.
