# MichaBrugger/obsidian-footnotes

The repository holds the Obsidian Footnotes plugin, which turns footnote handling into a hotkey. Its README records inserting an auto-incremented numbered marker or a named one, adding the matching detail line at the bottom of the note, placing the cursor there to be filled in, and jumping in both directions between a marker and its detail. It stresses that hotkeys are not assigned on installation and have to be set in Obsidian's hotkey settings, and the catalog records the repository as a fork under the MIT license.
