# QoderAI/Qoderian

Qoderian embeds the Qoder CLI in an Obsidian chat sidebar with the vault as the agent's working directory, so file reads, writes, search and shell commands run against vault contents. An at-sign brings notes, the current selection or external directories into context, slash commands and skills come from the same Qoder CLI project files, and a leading exclamation mark runs a shell command while a leading hash writes a refined instruction. A toolbar selector sets the permission mode, from confirming each sensitive operation through read-only planning to skipping confirmations, and model and effort pickers read the catalogue returned by the Qoder Agent SDK. Selected text can be rewritten in place with a diff preview, chat tabs keep separate histories with resume and rewind, and the plugin is desktop-only and needs Obsidian 1.7.2 or newer with qodercli on the PATH.
