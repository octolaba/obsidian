# liolle/Crafty

Crafty attaches tooltips to the nodes of an Obsidian canvas and adds navigation between them. Its sidebar searches node titles and sorts or filters nodes, and commands step to the previous or next node and show or hide the sidebar. The README states that all three commands ship without default bindings, so hotkeys must be assigned before node navigation can be used.
