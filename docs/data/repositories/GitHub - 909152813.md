# BambusControl/obsidian-chronotyper

Tracks how long a note is edited and writes the result into the note itself. The README states that the plugin runs in the background and automatically saves both a modification timestamp and the accumulated edit time as note properties, showing an example with an ISO timestamp and a whole number of seconds. Settings exclude chosen folders from tracking and rename the two properties it writes.
