# davidpedrero/obsidian-daily-notes-automater

Daily Notes Automater creates the day's daily note when Obsidian starts or reloads, if one does not exist yet, filling it from a template file; when no template is configured it does nothing. Settings cover the date format used in the filename, the template path, the root folder, an optional filename suffix, and whether notes are filed into year and month subdirectories beneath that root. The README notes that dynamic date strings are produced through the Moment API and gives a worked example of the resulting name and path.
