# rapphcd/definitions-detector

Definitions detector scans the active leaf and replaces each detected word that has a definition in the configured definitions folder with a link to the note containing that definition. A definition is a note whose title is the word and whose body holds the definition, and the README states the folder can contain up to four subfolders of definitions. The scan is started by clicking the book icon in the ribbon menu after setting the definitions folder.
