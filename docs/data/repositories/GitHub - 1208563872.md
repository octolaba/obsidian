# jiawei-hong/obsidian-linkify

An Obsidian plugin whose README describes converting a pasted URL into a Markdown link: it detects that the pasted text is a URL, fetches the page title, and inserts the link with that title as its text. The repository description instead speaks of converting plain text into Obsidian wikilinks by customizable rules, so the two recorded inputs do not agree on what the plugin produces. The rest of the short README covers installation from the community plugin browser and manually from a release.
