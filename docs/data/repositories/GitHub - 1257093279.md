# shangchengwen/obsidian-morse-translator

This repository holds Morse Translator, an Obsidian plugin that takes Morse code typed into a floating window, translates it in real time and inserts the result into the document being edited. Letters are separated by spaces and words by a slash, the translation preview updates while the code is typed, and the text is inserted either by pressing Enter or automatically after a configurable wait once typing stops. The README, written in Chinese and English, also records upper or lower case output, custom character sets for the dot and dash symbols, a draggable window closed with Escape, a Chinese or English interface, and commands for opening and toggling the translator.
