# lizard-heart/obsidian-note-content-pusher

The repository holds Note Content Pusher, an Obsidian plugin that creates a linked note and fills it with content without leaving the note being written. Its README records the syntax as a wikilink followed by a marker and the intended content in braces, and a single command that replaces the written text with the plain link, creates the file and puts the braced content into it. Where the target file already exists, the content is appended to its end instead.
