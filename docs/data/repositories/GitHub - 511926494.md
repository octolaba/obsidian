# BoxThatBeat/obsidian-agile-task-notes

Obsidian plugin that imports tasks from a team foundation server, currently Jira or Azure DevOps, so that notes and to-do lists can be kept on them. It generates a local Kanban board holding only the tasks assigned to the user, creates a file per task whose starting content is configurable in the settings, and updates on an interval, from a left-hand button or from a command. The README states that the generated sprint board is destroyed and replaced on each update, that there is no interface for the board unless the Kanban plugin by mgmeyers is installed, and warns that the settings, including an API key or personal access token, are stored in plain text rather than encrypted.
