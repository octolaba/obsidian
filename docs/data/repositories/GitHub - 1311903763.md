# herbertjones/obsidian-tab-title-from-file-title

Tab Title from H1 replaces the active tab's title with the note's first top-level heading whenever the note has one, so terse, dated or kebab-cased filenames still show a readable title in the tab header. It listens for workspace and metadata events, layout changes, active leaf changes, file opens, vault renames and metadata cache updates, and on each one looks up the first heading of the active file and sets the tab header text to it. There are no settings; the behavior applies as soon as the plugin is enabled.
