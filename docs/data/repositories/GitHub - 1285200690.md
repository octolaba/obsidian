# gapmiss/cm-code-editor

CM Code Editor is a code file editor for Obsidian with syntax highlighting, code folding and autocompletion, built on CodeMirror 6. The README lists highlighting for more than 25 languages and more than 45 syntax themes, among them Dracula, GitHub, Monokai, Nord, Solarized and VS Code, or inheriting the theme from Obsidian. It records a requirement of Obsidian 1.13.0 or later and ships as `main.js`, `manifest.json` and `styles.css`.
