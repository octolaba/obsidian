# chenbihao/obsidian-theme-dark-clarity

chenbihao/obsidian-theme-dark-clarity holds Dark Clarity, described in a Chinese README and description as a personal Obsidian theme built around high legibility and coloured headings from H1 to H6. It adapts parts of the Dark Moss theme and adds several colour schemes, a light-mode palette, and legibility changes such as heavier bold text, borders around images and quote blocks stripped of italics. Style Settings exposes its options: named heading palettes, secondary palettes derived from Dark Moss and Nord, code-block palettes modelled on JetBrains editors and Blue Topaz, horizontal scrolling with adjustable width in the left sidebar, and four folder-colouring modes. The README also records a Chinese font chosen for its tadpole-shaped comma.
