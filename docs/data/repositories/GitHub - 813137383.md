# jlweston/obsidian-note-proximity-plugin

Obsidian plugin that identifies notes which may be similar to the one currently open, by analysing word frequencies across all notes in the vault and comparing them with the current note. Results appear in a right-hand pane called Similar notes, each with a score where a higher value indicates more shared potentially-relevant terms, and clicking a result opens it in the current editor; a command reopens the pane once it has been closed. Its roadmap lists configuration options such as a minimum similarity threshold and a maximum number of similar notes to display.
