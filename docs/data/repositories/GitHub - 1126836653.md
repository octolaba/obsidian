# parente/obsidian-etch-weather

Etch Weather writes daily weather forecasts into Obsidian notes so they stay available locally and offline. The README explains that a fenced etch-weather code block is filled in when the pen icon in its corner is clicked, taking the date from a block parameter or, when none is given, from the title of a daily note, and that latitude, longitude and timezone can override the default location per block. Location, units and other details are configured in the plugin settings, and the README attributes all weather data to Open-Meteo.com under CC BY 4.0.
