# mnaoumov/obsidian-advanced-debug-mode

Advanced Debug Mode improves the debugging experience inside Obsidian. It adds a quick way to switch Obsidian's debug mode on and off, which stops inline source maps being stripped from loaded plugins, and it preserves longer error stack traces, including frames from callbacks such as setTimeout or addEventListener that are usually missing. The README notes that async long stack traces are added on desktop only, because of current JavaScript engine limitations on mobile, and that they may contain duplicates.
