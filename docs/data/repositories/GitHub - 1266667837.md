# spenhos/obsidian-torah-verse-inserter

Torah Verse Inserter inserts verses of the Hebrew Bible into a note as a Markdown quote with its reference, using a complete Hebrew text bundled with the plugin so no internet connection is needed for that text. The README states that the bundled text is the Miqra according to the Masorah, carrying vowel points and cantillation marks, and covers all thirty-nine books of the Tanakh. A verse can be found by reference in English, Spanish, transliteration or Hebrew book names with verse ranges, by Hebrew typed or pasted directly with or without vowel points, through an on-screen alphabet keyboard, or by Latin transliteration typed on a normal keyboard, which the README describes as matching flexible vowels and ambiguous consonants. Translations are offered as an option alongside the Hebrew text.
