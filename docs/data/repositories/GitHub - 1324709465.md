# wendao10/ai-alias

AI Alias replaces sensitive names in a note with user-defined aliases before the text is handed to an outside AI tool, and restores them from the same mapping afterwards. Two commands, available from the command palette and the editor context menu, convert real names to aliases or back across the selection or the whole note, and a third copies a prompt prefix asking the assistant to leave aliases intact. Mappings pair a real name with an alphanumeric alias, are edited or bulk imported and exported as JSON in the settings tab, and the characters wrapping an alias are configurable. Substitution is deterministic rather than left to the model, the mapping table lives only in the plugin's local data file, and the plugin makes no network requests.
