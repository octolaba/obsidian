# jingmengzhiyue/obsidian-code-snippet-manager

code-snippet-manager collects, organizes, formats, searches and AI-explains code snippets in Markdown inside Obsidian, keeping Markdown files as the source of truth rather than moving them into a private database. One collection file holds snippets for a single language, each snippet being a level-2 heading with optional tags and one fenced code block, and inserting a snippet inserts the code only, not the heading. Snippets can be created from the editor selection, the clipboard or the dashboard, are indexed in memory, are searched by keyword, language and tag, and can be previewed, copied, opened at their original Markdown location or inserted into the active note. The README calls this an early stable release intended for manual installation, testing and community review.
