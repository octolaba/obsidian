# Kovah/obsidian-rainbow-colored-sidebar

This plugin colours the Obsidian sidebar automatically from a selected colour scheme, with no CSS tweaking, no per-folder configuration and no folder prefixes; the scheme repeats indefinitely, so the number of folders is not limited. The README records 18 themes compatible with dark and light mode — general schemes such as Default, A11y, Pastel and Muted, schemes with stronger visual themes such as Blue Wave, Summer Vibes, Pink Blossom, Cyberpunk, Noir Carnival and Mixed, and lighter and darker interface variants — plus colouring of sub-folders and files with an indicator for the active file, an accessibility mode that increases contrast, and an option to restart the colouring for subfolders. It states that colouring follows the folder list sorted A to Z, so the ordering in the file manager cannot be taken into account and some colours may end up mixed.
