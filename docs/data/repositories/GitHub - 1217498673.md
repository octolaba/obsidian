# y15865708228-pixel/pensea-theme

Pensea is an Obsidian theme whose Chinese README presents it as the companion theme to the Pensea plugin, also usable on its own. Its stated design principles are warm grey backgrounds with softened shadows, light font weights with wide letter spacing and loose line height, serif headings in Noto Serif SC or Georgia, and restrained transitions and fade-ins. The feature list covers light and dark modes, a warm palette with an indigo accent, soft callout styling, pill-shaped tags, internal and external link styling, graph view colours and mobile adaptation, and installation is documented both manually and through BRAT.
