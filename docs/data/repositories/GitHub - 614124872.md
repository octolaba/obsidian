# Pr0dt0s/obsidian-html-server

Serves the vault over HTTP so its notes can be opened in a browser with the same theme and with working image and file links. The README describes the server as view-only and intended for sharing within a local network, states that interactivity is not implemented yet, and suggests setting a Markdown file of links as the default index page. Served pages are built from templates whose variables resolve first from a mapping in the file's frontmatter, then from plugin settings, then from internal values such as the rendered file name and the theme mode.
