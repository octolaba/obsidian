# Maws7140/vault-hub-plugin

Vault Hub is an Obsidian companion plugin for publishing snippets, notes and templates to GitHub and installing them back. The README covers three workflows: publishing a CSS snippet, a note or a full vault as a GitHub repository, browsing the live Vault Hub catalog from inside Obsidian, and installing note packs and CSS snippets into the vault. Publishing generates hub.md metadata and a README for the listing, detects the community plugins required by the selected files, attaches CSS snippets, and uploads local or referenced screenshots. The disclosures state that the plugin is desktop-only, requires a GitHub account and a personal access token, calls GitHub APIs and the configured Vault Hub site, and writes into the vault and its configuration directory.
