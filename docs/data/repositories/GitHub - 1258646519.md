# nickolay-kondratyev/obsidian-visit-history-plugin

Visit History is an Obsidian plugin that records visit history for notes, canvases and Excalidraw drawings, measuring how long each file holds focus, and presents the vault as a zoomable treemap heatmap in which every file is a rectangle nested inside its folders and sized by file size. Colour is driven by a chosen timestamp — visited, modified or created — so the same vault tells three different stories, with created and modified working immediately while visit-based colouring accumulates as the plugin is used; files can also be coloured by type instead. The README documents drilling into folders and back, filters on path or text content combined with OR, archive folders hidden by default, opening the heatmap for a folder from the file view, and heatmap options saved automatically. It states that everything runs fully offline and locally, with no network calls, accounts or telemetry.
