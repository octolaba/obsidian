# OverFitted/obsidian-japanese-helper

The README describes an Obsidian plugin for Japanese note-taking that converts selected romaji into kana. Two commands convert the selected Latin text to hiragana or to katakana, reachable from default hotkeys or from the command palette, and the README shows one romaji sentence rendered in both scripts. The conversion handles small letters, particles, long vowels and double consonants. The settings customize those hotkeys and whether a notification is shown after a conversion, and the README records a BSD Zero Clause License.
