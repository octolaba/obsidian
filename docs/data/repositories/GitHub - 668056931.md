# tldraw/obsidian-plugin

This plugin embeds the tldraw drawing app inside Obsidian, storing each drawing as an ordinary Markdown file in the manner of the Excalidraw plugin, so the data stays accessible as plain Markdown. The reader can switch between the tldraw view and the Markdown view of the same file, which allows backlinks, tags and other elements to be added alongside a drawing, and the toggle is available from the command palette, keyboard shortcuts, a status bar item, the file menu and the context menu. The README records the project's stated goals of keeping up with tldraw's latest version, previewing a drawing referenced from Markdown, adding Markdown notes into tldraw, and export and import tools.
