# tinswangtao-web/traystone

Traystone keeps Obsidian running in the system tray or menu bar with its own window management and a global quick note. Closing the window hides the application to the tray instead of quitting, global hotkeys toggle window focus and create a quick note, the tray icon and its tooltip can be replaced, the window icon can be hidden from the taskbar or dock, and the application can be launched at login. On macOS the dock icon toggles the window and a left click opens the tray menu, while on Windows and Linux a left click toggles visibility. The README states that the plugin is desktop only and does nothing on mobile beyond showing an informational message, and that it is based on the earlier obsidian-tray plugin under the MIT license.
