# HornatX/sidebar-timer

This repository holds Capsule Timer, a floating countdown timer for Obsidian, documented in a README written in Chinese and English. It draws a translucent capsule window that follows the dark or light theme, can be dragged anywhere, remembers its position, and is constrained so it cannot be pulled off screen. Two timing modes are recorded: a real-time mode that keeps counting while the application is closed, offered for drinking reminders and pomodoro sessions, and a software-only mode that pauses when Obsidian is closed, offered against eye strain; the real-time mode recalculates against the true elapsed time after a sleep so the countdown does not stall. Settings cover the duration, the expiry message, automatic start on launch, the mode, a status bar readout and the capsule colours, and the README states that the plugin runs entirely offline.
