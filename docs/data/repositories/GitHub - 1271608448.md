# rafamss/obsidian-note-comments

This repository holds Note Comments, an Obsidian plugin documented in Portuguese that anchors comments to any span of text, from a single word to a whole paragraph. The commented span is marked with a themed highlight colour and underline in Live Preview, Source and Reading modes, and a right-hand panel lists every comment in the document, sortable ascending or descending by position or by date. The README records that nothing is inserted into the note's markdown: the anchor is the quoted span plus its context, re-found automatically, and a comment whose span has been rewritten too heavily becomes an orphan shown faded in the panel rather than disappearing silently. Comments are stored one note per document inside a configurable folder mirroring the source path, readable as callouts with a hidden JSON block as the source of truth.
