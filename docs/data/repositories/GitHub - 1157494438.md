# NilsGke/obsidian-better-vim

BetterVim adds features to Obsidian's built-in vim mode: highlighting of yanked text, inserting a bullet point on a new line, synchronising yank and paste with the system clipboard, and optional visual-line motions for `j`, `k`, `0`, `$`, `_`, `A`, `I` and `V`. The README credits an earlier vim-yank-highlight plugin as the inspiration for the yank highlight and names integration of surround-style editing as a plan rather than a present feature.
