# xcloud-ai/table-layout-helper

Table Layout Helper exposes Markdown table layout as visual settings, which its README presents as a replacement for hand-written CSS snippets, with every change applying immediately in both reading view and Live Preview. The recorded controls cover fixed or automatic layout mode, table width as a percentage, a pixel value or automatic, a fixed first column with automatic content columns, text wrapping, vertical alignment, line height, overflow behaviour, a maximum height with scrolling, and a sticky header. Zebra stripes with a custom colour, prevention of separators wrapping alone, and border width, colour and collapse mode are settings as well; the README carries the same feature list in English and in Chinese.
