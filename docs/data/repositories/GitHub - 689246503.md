# Ebonsignori/obsidian-timeline-schedule

This plugin generates inline timelines from human-readable time strings inside a schedule codeblock, so a line ending in a duration sets the time recorded on the following line. Autofill and pretty preview can each be enabled separately: autofill keeps start and finish blocks and prepends a time block to every line between them, while pretty preview renders the block and takes its start from a start line or, when none is given, from the current date and time. The names of the start and finish markers and the date formats are configurable, and the README advises writing a schedule outside a callout and pasting it in afterwards.
