# dzplnk/obsidian-unread-badge

Unread Badge marks notes in the file explorer with a small dot when they have never been opened or were modified after they were last opened, and clears the dot when the note is opened. A folder carries the badge when any note beneath it, at any depth, is still unread. The context menu on a note or folder offers marking as read or unread, applied recursively for folders, and commands mark every note in the vault as read or as unread.
