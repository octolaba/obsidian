# jmxo/obsidian-auto-hide-cursor

Obsidian plugin that hides the mouse cursor after scrolling up or down, or after a delay, and shows it again once the mouse moves. The delays are customised in the plugin's settings tab. The README presents it as complementary to the obsidian-focus-mode plugin and compares it to a Chrome extension that hides the mouse pointer.
