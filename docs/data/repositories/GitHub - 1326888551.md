# timeofmei/html-table-math

Renders LaTeX inside the cells of raw HTML tables, which Obsidian's own math handling leaves untouched, using MathJax in both Reading view and Live Preview. It recognizes the same delimiters as Obsidian, single dollars for inline math, double dollars for display math and an escaped dollar for a literal sign, and leaves everything else in the cell exactly as written. Three settings turn rendering off entirely, restrict it to Reading view, and choose whether a formula that fails falls back to its raw source or to the MathJax error output, with changes applying to open notes immediately. Obsidian 1.13.0 or newer is required.
