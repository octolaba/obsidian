# MoxAlehin/TierList

Tier List renders nested Markdown lists as visual tier lists for ranking and organizing items. The README records that a list is marked for rendering by placing a configurable tag inside it, or created ready-formatted by an insert command, and that a To Rank section holds items not yet placed. Items may carry internal or external images, arbitrary Markdown text, or a cover image named by a key in a linked file's frontmatter. The author contrasts this manual placement with query tools that need numeric values, and notes that using Markdown links keeps the ranked items connected in Obsidian's graph view.
