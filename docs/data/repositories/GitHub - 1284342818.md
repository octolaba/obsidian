# kim-dongryeong/obsidian-drive-attachments

Obsidian plugin that stores vault attachments in the user's own Google Drive instead of the vault. Files dropped, pasted or picked in a note are uploaded to Drive and replaced by a link that points at the file's permanent Drive ID, so it survives a rename or a move, while images, videos and PDFs still preview inline. The README also describes a Drive file browser in the sidebar and content-hash deduplication of uploads.
