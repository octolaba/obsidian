# jukkau/HomePulse

Adds a homepage view that can be pinned as a tab and opened on startup, filled with widgets arranged on a draggable, resizable grid whose named layouts can be saved and switched. The widgets cover a daily goal, projects drawn from configured folders, tags or filename prefixes, tasks aggregated from Markdown checkboxes, a calendar, habits with streaks, recently updated notes, an activity heatmap built from file modification times, and summaries of knowledge and recent execution. A Pomodoro widget records focus time into a local time log, attributed to a project, area, task pool or ad-hoc target, and time can also be entered by hand. All data comes from local Markdown, frontmatter, checkboxes, modification times and the plugin's own data file, and the interface follows the theme in English or Simplified Chinese.
