# snelling-a/obsidian-base16

Base16 for Obsidian is a theme built on the base16 colour system, bundling all of the 200-plus base16 schemes published by tinted-theming in one theme file. It works with the Default Dark and Light scheme without configuration, and installing the Style Settings plugin exposes the full scheme list under its own settings section. Schemes that define both a dark and a light variant follow Obsidian's own dark and light toggle. The README also documents a build step that refetches the schemes from tinted-theming and regenerates theme.css.
