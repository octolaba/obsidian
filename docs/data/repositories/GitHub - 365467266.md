# renmu123/obsidian-auto-pair-chinese-symbol

This plugin adds automatic pairing for Chinese punctuation as it is typed, and its README lists support for corner brackets, lenticular brackets, full-width parentheses and Chinese quotation marks. The recorded features also include deleting both members of a pair together and wrapping selected text in the symbols. An ignore list is recorded as planned rather than implemented, and the README itself is short and largely Chinese.
