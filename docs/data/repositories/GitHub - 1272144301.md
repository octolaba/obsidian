# tndgyq/local-office-preview

Local Office Preview is a desktop-only, read-only viewer for PowerPoint, Excel, Word, TXT and LOG files inside Obsidian that avoids creating duplicate preview files in the vault. Modern .xlsx opens in a fast table preview and .docx in a fast text preview, while PowerPoint and the legacy .xls and .doc formats are shown as a temporary PDF, TXT and LOG open directly as text, and a copy-text action extracts text without editing the original. Conversion tries a local LibreOffice installation first and on Windows falls back to WPS Office or Microsoft Office COM export, and the generated PDFs are cached in the operating system temp directory rather than in the vault. The README states that the plugin makes no network requests, uploads nothing to third-party services and never writes back to Office files.
