# MatthewAlner/obsidian-toggle-case

Toggle Case adds a command that switches the selected text between lowercase, title case and uppercase, and it also works with multiple cursors. No shortcut is set by default, so the key is chosen in Obsidian's hotkey settings. The README states that the repository is no longer maintained and points to an editor-shortcuts plugin that covers the same ground and more.
