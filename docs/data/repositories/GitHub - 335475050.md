# pjeby/note-folder-autorename

Note Folder Autorename is an Obsidian plugin supporting folder-overview notes. Its command, Make this note a folder note, creates a folder beside the note with the same name and moves the note inside it; from then on any rename or move of that note renames or moves its folder too. The README motivates this with a topic note that outgrows itself: once the note and its folder travel together, moving the note under another topic carries the whole folder and the other notes in it, which the ordinary move-file command cannot do.
