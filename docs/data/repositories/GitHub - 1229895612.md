# saralaaga/task-hub

Task Hub is a desktop-only workspace that collects the checkbox tasks written across an Obsidian vault into one queue, alongside external reminder and calendar sources. Its list view narrows by source, tag and saved conditions and offers search, custom filters, a completed-task toggle and a vault rescan; its calendar view lays dated items out on month, week and day timelines and reschedules the supported ones by dragging, while read-only calendars stay visible but unchanged. The README records the external sources as Apple Calendar events, Apple Reminders, public ICS feeds and Dida or TickTick tasks, and states that writeback to them is explicit and opt-in. Planning dates are read from the Tasks emoji markers, from a due inline field or from a bare date, with optional start times.
