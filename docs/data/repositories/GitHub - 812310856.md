# catvatar/Obsidian-NSFW-Plugin

Obsidian plugin that adds a sidebar button toggling the visibility of files marked NSFW. Any note inside a designated folder, by default a hidden NSFW directory, is hidden from view; pressing the toggle button or running its command moves the marked files into that folder and moves them back when used again. The README gives the motivation as hiding personal notes when showing a vault in public, and records as a known issue that each file's old location is saved to the plugin's data file, which may be a concern when outside tools synchronise the vault.
