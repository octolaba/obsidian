# dsebastien/obsidian-typefully

This plugin integrates Typefully so that notes can be published as social media posts to X, LinkedIn, Threads, Bluesky and Mastodon. The README describes a sidebar panel with drafts, queue, posted, schedule and analytics tabs, publishing a note or a selection to several platforms at once, attaching vault images through presigned uploads, browsing, editing and deleting drafts, scheduling immediately, into the next free slot or at a chosen time, thread creation by splitting on consecutive newlines, and tag management. Markdown is cleaned before publishing, with frontmatter, wiki links, blockquotes and image syntax stripped, note tags can be appended as hashtags with an exclusion list, and turning a note or selection into a styled image card is marked as desktop only.
