# Opisek/obsidian-battery-indicator

This plugin displays a battery indicator in Obsidian's status bar. Its settings adjust a few visual aspects, such as showing a textual percentage and splitting the battery level and the charging indicator into separate icons, while the README notes that customisable level thresholds are planned rather than present. It also suggests pairing the indicator with the author's statusbar organizer plugin to reposition it or show it only in full screen.
