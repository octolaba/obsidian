# gapmiss/find-n-replace

Find-n-Replace provides vault-wide search and replace for Obsidian with regex support, multi-selection and file filtering, working across text files such as md, txt, js, css and json. Regex searches support capture groups and multiline patterns, matches can be multi-selected with Ctrl or Cmd click, and results can be filtered by extension, folder or glob pattern and clicked to jump to their location. Settings cover search history size, a result cap, search-as-you-type, a confirmation prompt before Replace All, default filters and logging level, and the README cautions that the plugin modifies vault files directly and that backups should be kept before bulk replacements.
