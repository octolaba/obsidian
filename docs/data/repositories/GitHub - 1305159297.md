# grmartin/obsidian-toc-block-plugin

The repository holds the TOC Block plugin, which renders a Typora-like TOC tag as an inline table of contents built from the headings of a note. Its README describes the plugin as functional and bootstrapped from the official Obsidian sample plugin.
