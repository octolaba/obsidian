# Enoai/obsidian-garden-plugin

Vault Garden renders a vault as a garden where each note is a drawn plant in one of five species, its colour and droop set by how recently the note was edited and its size by how well it is linked. Plants cluster into nested soil beds following the folder tree, hovering one shows its title, a plain-language state and stats such as last edited and link count, and the view pans and zooms. Gardening gestures map onto real operations: dragging a plant to another bed moves the note into that folder, a shed archives it, a compost bin trashes it behind a confirmation, and a watering can refreshes a note's freshness. Three built-in themes can be swapped live and extended by palette or sprite packs, files, folders and an ignore tag can be excluded, and everything runs locally with no telemetry.
