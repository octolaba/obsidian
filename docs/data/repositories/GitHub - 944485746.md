# broekema41/obsidian-vcf-contacts

This plugin manages contacts inside an Obsidian vault, each contact stored as a note that can be searched and sorted, with the plugin also surfacing birthdays and tracking when a contact was last met. Contacts live in a folder the user designates, vCard files can be imported into it and contacts exported back to vCard, avatars can be attached, and quick actions and a fast search operate over the set. The README explains the vCard format the notes follow, shows an example contact note, and enumerates the supported vCard fields by group, beginning with basic contact information and address fields.
