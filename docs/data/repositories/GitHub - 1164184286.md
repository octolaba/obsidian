# johanviberg/obsidian-phosphor

Phosphor is an Obsidian theme for deep-focus writing and reading, named for the lingering glow of phosphorescent ink. Its headings run a spectral arc from warm amber at H1 to cool sage at H6, and the reading surface is tuned for long form with an 18px base, 1.72 line-height and a measure of roughly 68 characters on a perfect fourth type scale. Dark and light modes share the same warm-to-cool palette, more than twenty custom checkbox states are provided, and the theme is pure CSS with no build tools or dependencies. Body text is Source Serif 4, the interface Inter and code JetBrains Mono.
