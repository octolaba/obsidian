# Bloeckchengrafik/obsidian-recursive-share

Recursive Share creates share links for notes together with the resources they embed, so images, drawings and other attachments travel with the shared note. The README describes it as a third-party plugin requiring Obsidian 0.15.0 or later, installed from the community plugin browser or from a release. Sharing depends on a backend the user runs themselves, published as a Docker image and configured through a mounted TOML file that sets the port, the accepted authentication tokens and the storage path, which is also how control over who may share is exercised.
