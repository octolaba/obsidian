# cimu233/obsidian-cimu-print

Cimu Print is a desktop printing plugin that captures a note, a selection, a folder or an active non-Markdown view, paginates a PDF preview, then generates the final PDF and verifies its page count. It reads printer capabilities from the operating system and sends the verified PDF to CUPS through lp on macOS and Linux, streaming the bytes over standard input when in-memory printing is on, rather than using Electron's print path. A loopback CLI script takes authenticated requests so scripts can list printers or print a note with duplex, scale, copies and page-range options, choosing between the current Obsidian theme and a plain stylesheet. On first load it performs a guarded one-time migration of settings and hotkeys from the plugin ID print, backing up hotkeys first and leaving the source folder untouched.
