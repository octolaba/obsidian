# MarkMindCkm/obsidian-enhancing-mindmap

The repository holds an Obsidian plugin that turns a Markdown file into an editable mind map, writing the result back as Markdown headings and list items under a mindmap-plugin frontmatter key. Its README lists keyboard shortcuts for creating a map and for adding child and sibling nodes, deleting, editing, undoing, redoing and expanding, and shows that node text may carry links, inline styles, inline code, multiline text and KaTeX math. It states plainly that only a limited subset of Markdown is supported.
