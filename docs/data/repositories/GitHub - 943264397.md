# 12-VidE/annotate-audio

This plugin plays an audio file inside an Obsidian note from an annotate-audio code block whose options — source file, a time chunk, volume, playback speed, looping, layout, sticky and autoplay — are edited by hand or through a dedicated modal. Comments are attached to timestamps in LRC format with precision down to the millisecond; left-clicking a comment jumps to that timestamp, and right-clicking modifies or deletes it, with a separate button on mobile. The README lists keyboard shortcuts, control through Obsidian commands, mobile compatibility and an interface localized into English, Italian, Chinese, Spanish and Brazilian Portuguese.
