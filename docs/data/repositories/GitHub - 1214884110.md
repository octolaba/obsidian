# sourit2001/obsidian-bilingual-translator

The repository records no description, so this note is grounded in the README alone. Bilingual Translator translates English notes into a paragraph-by-paragraph English-Chinese parallel layout inside Obsidian, run from a right-click menu over the whole note or the current selection. Several translation engines are offered — Google Gemini, MiniMax, DeepSeek and Microsoft Translator — and long articles are split into chunks to avoid API timeouts, with progress reported as the run proceeds. The README states Markdown syntax, LaTeX and code blocks are preserved while YAML frontmatter and internal links are skipped, and that engine keys are configured in the plugin settings.
