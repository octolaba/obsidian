# jady21a/obsidian-learning-system

Obsidian plugin that turns notes into a reviewable learning system through extraction, annotation, review and analytics. Content is extracted from a selection, the current file or the whole vault, in batches and from tables, as text, question-and-answer or cloze cards, and extracted items can carry the reader's own annotations through a keyboard-driven editor. Review follows a spaced-repetition-inspired workflow with reminders triggered by actual learning behaviour, and statistics track review progress and let results be filtered by file, tag or date. The README also describes milestones awarded as usage accumulates, and a Chinese version of the document.
