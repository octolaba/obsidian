# RUverse/journal-view

Journal View shows a vault's daily notes as one scrollable, editable timeline, opened from the sidebar or the Open journal command. It reads the existing daily-note configuration, and its own settings can override the date format, folder and template without changing how the rest of the vault handles daily notes. Days can be reached by scrolling, by a calendar, by a jump back to today or from a daily note's surrounding days, entries are searchable, and typing into an empty day creates that daily note only at that point. Day order, year and month grouping, header format, whether empty days appear, the editor used, the autosave delay and how many days stay loaded are all configurable, and it works locally with no network requests.
