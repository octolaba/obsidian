# christianwannerstedt/obsidian-tags-overview

Tags Overview adds an extended tags panel to Obsidian in which tagged files can be overviewed, filtered and opened. The README records a toggle between list and table view, a filter field, additional sort options, and support for nested tags displayed either as a tree or as a flat list with each level expandable separately. Filtering selects one or more tags from a dropdown and can require all criteria or any of them, a tag can be toggled by clicking it in the results while holding a modifier key, and custom frontmatter properties can also be filtered on. A related-tags option widens which tags appear in the result to those also carried by the matching files, without changing which files are listed.
