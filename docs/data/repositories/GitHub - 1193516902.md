# viszkit/obsidian-writing-streak

Tracks the new words written each day rather than total file length, and shows the history as a compact heatmap in the sidebar alongside a detailed statistics view. Counting grows from each note's daily baseline, which lowers again when older text is deleted, and each Han character counts as one word to match Obsidian's Chinese word count; folders can be excluded or counting limited to selected writing folders. Every day in the heatmap is shaded by progress toward the daily word goal, the active daily note is highlighted, and clicking a day opens its note, while a modal shows yearly history and monthly totals. A webhook is sent when the configured daily goal is reached, and past counts can be imported from existing daily notes.
