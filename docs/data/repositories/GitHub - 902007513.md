# ElsaTam/obsidian-extended-graph

Extends the core graph view. The recorded feature list covers images on nodes, alternative node shapes, filtering by tags and properties, removing links by relationship type, several configurable views to switch between, exporting the graph to SVG, changing the appearance of the active node, focusing on and pinning nodes, reflecting the current search result and the open tabs in the graph, and sizing nodes and links by statistical functions. The README states that the plugin installs like any other on desktop but is not supported on mobile, and that a beta channel is available through BRAT.
