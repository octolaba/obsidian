# Chrstn67/Snippetsaurus

Snippetsaurus stores reusable snippets and inserts them into notes. A snippet is created and edited in a modal and holds either text or code, and a code snippet can name its programming language. Commands insert a snippet into the current note or open the interface for managing them, and the README also describes insertion driven by the last word typed.
