# raunaqgupta/obsidian-cooklang-codeblock-plugin

The repository holds a Cooklang codeblock plugin for Obsidian that embeds recipes written in Cooklang inside a note. In view mode the block renders the recipe with its ingredients, cookware and method. The README states that metadata such as cook time and serving size can optionally be rendered at the top of the block.
