# Sun8854/Obsidian-LaTeX-input

A formula input panel that builds LaTeX from a palette of roughly 250 symbols across ten categories, previews the result live, allows the raw source to be edited directly, and inserts it into the current note. It also converts formulas from images: one command drag-selects a region of the screen and another reads the image currently on the clipboard, both requiring an OCR service configured in the plugin settings. Past formulas are kept in a persisted history and can be reloaded for further editing. The plugin ships no default hotkeys, so its six insert and OCR commands are bound by hand, while a ribbon icon always opens the panel and MathLive is bundled into the build rather than loaded externally.
