# BCS1037/SmartPick

Repository for SmartPick, a toolbar that appears when text is selected in the editor. Its README describes sending the selection to a configured AI model to summarise, translate or explain it, binding Obsidian commands to toolbar buttons, triggering system shortcuts or opening external sites, grouping commands, rearranging items by drag and drop, managing prompt templates, and running URL scheme commands. Responses are rendered as Markdown, and the interface is available in English and Chinese.
