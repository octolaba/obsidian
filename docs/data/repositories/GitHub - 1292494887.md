# mateuszkowalczyk/obsidian-vim-commands

Vim Commands maps Vim-style multi-key sequences, leaders and modified keys to any Obsidian command, including commands added by community plugins, and those mappings work across tabs, sidebars and other app views rather than only in the editor. Mappings live in a vimrc-style file kept inside the vault, whose path is configurable in settings; only normal-mode mappings that invoke an Obsidian command and a leader assignment are handled, with the default leader being space and unrelated lines ignored. The plugin extends Obsidian's built-in Vim mode rather than replacing it, requires the built-in Vim key bindings to be enabled, and stays out of text fields and Vim insert mode. The README notes that a key combination clashing with an Obsidian hotkey must be unassigned first, and that the plugin is reloaded after the config file is edited.
