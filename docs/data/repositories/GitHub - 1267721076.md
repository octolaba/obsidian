# vault-mcp/platform

The repository carries no description; its README presents Vault MCP Connector as a plugin that connects Obsidian to ChatGPT, Claude, Codex and other Model Context Protocol clients. The plugin controls what is indexed, can start a local MCP server, and exposes one access-level selector governing local reads and direct writes, while hosted deployments serve only the derived index the plugin approved and can queue vault-write proposals for review. The disclosures state that local mode binds to 127.0.0.1 and needs no hosted service, that remote sync sends only Markdown and metadata allowed by the indexing policy, that local file access is off by default with scoped modes limited to configured folders, and that a permissive mode grants direct read and write across the local filesystem without creating a proposal. It records the release as a public alpha candidate pending community review.
