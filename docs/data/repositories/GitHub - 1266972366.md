# willmove/obsidian-marknice

MarkNice WeChat converts the current Markdown note into inline-styled HTML for the WeChat Official Account editor; its README is written in Chinese and records version 0.6.6 with a minimum Obsidian version of 1.5.0. A side preview renders the note in the final style at desktop width or a 375-pixel phone width, with sixteen built-in themes and adjustable font size and paragraph spacing that apply to the preview, the copy and the draft alike. Copying writes both HTML and plain text with styles inlined into style attributes, and the plugin can also copy the raw Markdown, upload cover and body images through the WeChat API to create a draft, import .docx files or OCR a PDF through a configured service, and export HTML, Word or PDF. The README notes that drafts need an app ID and secret, an IP allowlist entry and usually a verified account.
