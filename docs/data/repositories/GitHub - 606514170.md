# HyeonseoNam/obsidian-emoji-titler

Obsidian plugin that adds an emoji to the title of the active note from a keyboard shortcut, which the README suggests using to mark depth or reading state. The set of emoji is configured in the settings by increasing or decreasing the number of slots and filling them. Inserting a different emoji into a title that already carries one replaces it, and the same shortcut also removes it.
