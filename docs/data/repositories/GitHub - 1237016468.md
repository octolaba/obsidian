# hayribakici/obsidian-scratchblocks

This plugin renders Scratch block markup inside Obsidian notes, turning fenced blocks written in scratchblocks syntax into rendered block images and accepting both singular and plural fence names. The README also documents an inline form, where a prefixed inline code span renders a single block in the middle of a sentence, and points at the Scratch wiki for the syntax itself. It records a caveat that inline blocks render smaller than the surrounding text because their internal scale differs from the multi-line case, offers a CSS snippet that adjusts height and margins to compensate, and notes that nested blocks stay smaller because of padding the underlying library inserts. Under the hood it uses a TypeScript port of scratchblocks by the same author.
