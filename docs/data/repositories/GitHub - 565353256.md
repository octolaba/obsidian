# bingryan/obsidian-markdown-export-plugin

The repository holds an Obsidian plugin that exports Markdown to a package outside the vault, taking either a single file or a folder. Its README records that image attachments are included, that embedded content is resolved, and that the output can be produced as Markdown or HTML, with an option for GitHub Flavored Markdown. It records that an output location outside the vault has to be given as an absolute operating system path, and that asset paths are relative to the output folder.
