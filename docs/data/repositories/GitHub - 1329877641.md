# bobstanton/places-freeroute

A routing provider for the Places plugin backed by the FreeRoute service. It builds routes between the waypoints in a block and reachability isochrones around a center point, resolves search terms to place suggestions, and snaps a recorded track to the road or path network. All of its requests go to the FreeRoute API, it runs no background tasks, and its map, overlay and routing code comes from the shared places-shared library.
