# kirito41dd/obsidian-hugo-publish

Copies Markdown files and their referenced images from the vault into a Hugo site directory, rewriting Obsidian syntax on the way. Wiki links become Markdown links, image embeds become Markdown images with any size argument carried into width and height attributes, and a YAML header with title, date and lastmod is written automatically. Notes are selected by carrying a configured tag, and the transfer runs from a sync button or the sync command once the site directory is set in the settings.
