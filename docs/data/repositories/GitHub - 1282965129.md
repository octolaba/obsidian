# zoupuyo-obsidian/obsidian-daily-preview-calendar

Repository for Daily Preview Calendar, an Obsidian plugin that browses daily notes in week and month calendar views with Markdown previews rendered inside each day cell. The daily note folder and date format are taken from the core Daily notes plugin, and the README lists section filters by heading, keyword highlights, hover or long-press excerpts, a Japanese or English interface, and mobile support. It also documents a dual release line in which odd and even patch versions target different Obsidian API generations, selected through `versions.json`.
