# Sisyphe42/obsidian-neodb-plugin

This repository holds NeoDB Sync, an Obsidian plugin that syncs data from a NeoDB instance into a vault; the repository records no description, so this summary follows the README alone. It syncs shelf items across the wishlist, progress, complete and dropped states together with collections, notes and reviews, writing them through customizable templates and optionally into per-type folders such as book, movie, music and game. The README also records previewing files before syncing, a progress modal that can be cancelled, incremental sync from per-content last-sync timestamps, a custom domain with an account connection panel, import of exported JSON data, and an English or Simplified Chinese interface.
