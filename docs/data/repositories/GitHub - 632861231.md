# andrewbaxter439/due-when

Obsidian plugin that adds four commands inserting a due date at the cursor in a bracketed due field, together with an optional hashtag. The four are the end of this week and of next week, both set to Friday, the end of this month, and a date one hundred years ahead standing for work that will not be done. Settings hold the tag attached to each of the four commands and a toggle deciding whether end of month means the last weekday or the last calendar day.
