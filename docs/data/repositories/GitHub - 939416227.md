# Yoav6/Obsidian-Copy-Outline

Copy Outline adds a button to Obsidian's outline view that copies the outline of the current note to the clipboard. Right-clicking an outline item copies that item together with its subheadings. A setting switches the copied format between Markdown headings and an indented bullet list, and the number of headings copied is reported.
