# G-Chist/obsidian-graph-untangler-plugin

The repository holds an Obsidian plugin that rearranges the graph view automatically. Its README states that the plugin uses forces to untangle the graph, and records that hotkeys can be assigned for starting and stopping the untangling once the plugin is enabled. Installation is described as copying the repository files into the vault's plugin folder and reloading plugins in the community plugin settings.
