# Gnopps/obsidian-rewarder

The repository holds Obsidian Rewarder, a plugin that hands out a reward when a task is completed, either every time or at random intervals, and can record the reward in the daily note. Its README records that rewards are listed one per line in a separate file, named in the settings and creatable from a sample command, and that a reward line may carry a rarity marker and a remaining inventory count in braces. When a checkbox is ticked the plugin decides whether a reward is due and which one, notifies the reader, and offers to skip it without spending from that reward's inventory.
