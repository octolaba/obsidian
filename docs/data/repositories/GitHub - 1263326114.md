# Levis-Code/markcalc

MarkCalc evaluates spreadsheet-style formulas over Markdown tables and writes the computed values into the cells as plain Markdown, so the numbers survive in the file without the plugin, in Git or in another editor. The formula lives in a comment beside the table, which the README calls the idempotent source of truth, and a note can read a table in another note through cross-note functions; changing the source cascades recalculation to dependent notes through a dependency graph instead of scanning the whole vault. The README also records context-aware autocomplete for functions, table columns, named tables and note names, an English and Spanish interface that can follow Obsidian's language, and evaluation in plain JavaScript with user-defined functions embedded in the note itself.
