# mirkostanic/obsidian-lego

This plugin integrates Obsidian with the Brickset API to fetch LEGO set information by set number and create a formatted note from it. The note carries the set's details — pieces, minifigs, pricing and ratings among them — with frontmatter tags for organisation, and set images are downloaded and embedded in it. Settings choose the folder the set notes are created in and can optionally hold a Brickset username and password for personalised features. The repository carries no description, so this summary rests on the README alone.
