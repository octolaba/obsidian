# CascadeThemes/Duality

CascadeThemes/Duality holds Duality, a theme built as a pair: a dark mode of deep gray-blacks with fiery orange-red accents and medieval-inspired borders, and a light mode of blues and golds with a warm golden accent, soft gradients and rounded corners. The README credits the dark side to the gothic look of Diablo II and the light side to the idea of a divine library. Each heading level gets its own colour per mode, callouts are coloured by type, links and tags shift between celestial blue and fiery orange with hover effects, and tables and checklists use alternating row backgrounds. Installation is either the in-app community theme browser or a manual copy of the theme stylesheet into the vault's themes folder.
