# matthewturk/obsidian-sidecar-panel

Sidecar Panel displays a contextual panel in the right sidebar whose content comes from another note, selected either by a sidecar-panel frontmatter property on the open file or by a mapping from a tag to a panel note configured in the settings. The panel's content is rendered as though it came from the file that references it, so input fields created with a plugin such as Meta Bind bind to the parent note rather than to the panel source. Several panel files can be combined, concatenated in the order of the tag maps followed by the sidecar-panel property; the description calls the plugin an experiment.
