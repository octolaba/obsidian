# FantsGa/attachment-butler

An Obsidian plugin for keeping track of attachments and their references, documented in a bilingual Chinese and English README. It marks attachments that no note references with a red dot so redundant files can be found, adds a right-click action that jumps to all notes referencing an attachment, and prefixes a referenced attachment's name with the referencing note's name, with the full list of sources shown on hover.
