# grhawk/obsidian-2-confluence

Obsidian plugin that syncs the active note to Confluence through the REST API, converting Obsidian-flavored Markdown into Confluence storage format HTML. The README describes updating an existing page found by a frontmatter page id or by title lookup in the configured space, creating a new page under an optional parent otherwise, and writing the resulting page id back into frontmatter. Setup requires building the plugin and configuring a base URL, space key, auth email and API token.
