# tahayigitmelek/status-pilot

Status Pilot reads workflow metadata — status, priority and level — out of the YAML frontmatter of a vault's Markdown notes and gathers it into a dedicated dashboard table. From that table the notes can be filtered by status, priority, level, folder or text search, sorted by those fields or by a custom status order, and edited through dropdowns without opening each note. An optional panel at the top of a rendered note exposes the same fields, command-palette entries set metadata or open filtered dashboard views, and the recorded values, labels, icons, badge colors, display order, defaults and folder rules are configurable.
