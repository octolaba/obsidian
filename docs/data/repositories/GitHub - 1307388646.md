# jesterspot1-svg/obsidian-vk-inbox

VK Inbox imports private messages sent to a VK community into a note chosen by the user, without requiring a personal server, since VK holds incoming messages until the plugin checks manually or on a configured interval. Entries are grouped by day, with the first carrying its date and time and later ones separated by rules, duplicates are prevented, and voice messages are downloaded into a selected attachment folder and embedded for playback. Free local transcription is offered on desktop through whisper.cpp. The README records the limits: automatic synchronization runs only while the app is open, local transcription is desktop-only, voice messages imported on iPhone are marked for transcription during the next desktop sync, and the first synchronization sets a starting point and skips older history.
