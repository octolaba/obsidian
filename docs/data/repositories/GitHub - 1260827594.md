# clivoa/talon-cql

Talon CQL adds syntax highlighting for CrowdStrike's LogScale query language to code blocks in Obsidian notes, aimed at threat hunters who keep playbooks, runbooks and DFIR notes in a vault. A block tagged with the language name, or with a LogScale alias, is colored through Obsidian's own code-block pipeline in reading mode, Live Preview and source mode, taking its colors from the theme's code variables. The README lists the recognised tokens, namely event fields, built-in and namespaced functions, keywords, operators, strings, regular-expression literals, numbers and comments, and ships a directory of ready-made hunting query templates.
