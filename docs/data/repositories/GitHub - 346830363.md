# dy-sh/obsidian-consistent-attachments-and-links

Consistent Attachments and Links reorganizes an Obsidian vault so that links between notes and attachments follow the Markdown format with relative paths, and then maintains that consistency automatically as the vault changes. The stated idea is that a note should remain readable outside the vault — in another program or published on a site that renders Markdown — which means attachments should live in the note's own folder or its subfolders. The README warns that the plugin can change the vault layout and that a backup is essential before any large change, and it ships a demo vault with usage examples, reachable through a command, a release archive, or the repository's demo-vault directory.
