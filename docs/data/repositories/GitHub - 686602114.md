# ziyafenn/obsidian-contentful-publisher

Contentful Publisher connects an Obsidian vault to Contentful, a headless CMS: it pulls content types and turns them into Obsidian templates, and pulls entries into notes organized into folders by content type. Edited notes are pushed back with an Update Contentful Entry command, and when the entry has changed on Contentful in the meantime the plugin warns and creates a copy instead of overwriting. Every field except the title and the body becomes a frontmatter property, while RichText, ResourceLink, Link, Object and Location fields are ignored; the README lists the core Templates plugin, disabled wikilinks and a content model with title and text fields as requirements.
