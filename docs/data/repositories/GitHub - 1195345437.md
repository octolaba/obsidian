# senjanson/lan-vault-sync

LAN Vault Sync synchronizes an Obsidian vault between devices over the local network with no cloud service and no central server, every device acting as both WebSocket server and client. Devices announce themselves by UDP broadcast for automatic discovery, and peers can also be added by address and port or paired by scanning a QR code where broadcast is blocked. Text files are merged at character level with the Yjs CRDT so concurrent edits combine without conflicts, while binary attachments such as images and PDFs are compared by SHA-256 hash and backed up before being overwritten. The README states that edits made offline are merged on reconnect and that traffic never leaves the local network.
