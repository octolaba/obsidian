# AyushParkara/NotePix

NotePix uploads pasted or dragged images to a GitHub repository the user owns, public or private, and replaces the local file with a hosted link so the vault stays small. The README states that images in a private repository are rendered through an authenticated fetch in both Reading View and Live Preview, and that the access token is stored encrypted. Desktop and mobile are both recorded as supported.
