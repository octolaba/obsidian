# bobstanton/places-geoapify

A map provider for the Places plugin backed by Geoapify. It loads the selected map style with its glyphs, sprites and tiles, resolves search terms to places and coordinates, builds routes between waypoints and isochrones around a center point, reads elevation along a track, and snaps a recorded track to the road or path network. Rendering runs on the maplibre-gl engine through the shared Places GL map implementation, and no background tasks are involved.
