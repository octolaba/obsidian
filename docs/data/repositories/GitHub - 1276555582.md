# SunnyYYLin/obsidian-better-figures

The repository records no description, so this note is grounded in the README alone. Better Figures turns an image's alt text into a centered caption below the image using ordinary Markdown syntax, rendering captions through Obsidian's Markdown post-processor in Reading view and through CSS in Live Preview. Images whose alt text is empty are left untouched so existing notes are unaffected, and both external images and internal embeds are handled. The README states the plugin has no runtime dependencies and needs no settings.
