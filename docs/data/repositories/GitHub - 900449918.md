# dnlbauer/obsidian-dataview-autocompletion

Repository for Dataview Autocompletion, an Obsidian plugin that offers autocomplete suggestions for the inline metadata fields used by Dataview while typing in the editor, so existing fields are reused and typing errors are reduced. Fields and files can be excluded from the suggestions in its settings. The README documents installation from the community plugin catalogue or by copying the release files into a plugin folder, and records the MIT licence.
