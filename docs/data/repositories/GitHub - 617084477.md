# lukasbach/obsidian-code-files

Code Files adds a code editor view to Obsidian so that code files can be shown and edited alongside notes, using the Monaco Editor that also powers VS Code. File extensions for which the editor becomes the default are configured in the settings, and new code files can be created from a folder's context menu, the command palette or a ribbon button. Individual code blocks inside a Markdown document can also be opened in an embedded Monaco instance, and themes beyond the VS Code defaults are selectable. The README carries a caveat that the plugin relies on hosted dependencies and therefore needs an internet connection.
