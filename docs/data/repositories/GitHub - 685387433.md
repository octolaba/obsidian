# Mara-Li/obsidian-better-canvas-lock

Better canvas lock is described by its author as an experimental Obsidian plugin that locks the view of a canvas, with zoom, selection, drag-and-drop and scrolling individually disableable. It works by monkey-patching the canvas lock function through `monkey-around` and detecting canvases on the `active-leaf-change` event, so enabling the plugin is enough; console logging can be switched on, with the README warning that it is noisy and repeats errors. Dragging and scrolling are deliberately re-enabled while a canvas card is focused so the view can still be adjusted, and clicking away restores the lock.
