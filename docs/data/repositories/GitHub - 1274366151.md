# KKenny0/obsidian-kami

Kami Reader is an unofficial Obsidian theme inspired by tw93/kami. It applies warm parchment and ivory surfaces, ink-blue accents, serif-led hierarchy, and warm-gray neutrals in light and dark variants while retaining Obsidian's navigation model. A Style Settings schema exposes controls such as body font, line height, note width, and bold weight; an optional companion extends the workspace shell.
