# bassio/obsidian-deepsit

Deep Sit is an Obsidian plugin for citing and referring to literature stored in a Zotero reference manager library while taking notes. The README requires Zotero 7 with the Better BibTeX plugin installed and running while the plugin is used, and describes citing as you write, references, annotations and inserting a references section. It is aimed at a research workflow where Zotero holds a large annotated PDF library and the study or research notes are written in Obsidian.
