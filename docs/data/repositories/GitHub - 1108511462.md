# churnish/colorful-heading-underlines

Obsidian plugin that adds colored underlines to headings so heading levels can be told apart, with appearance options exposed through Style Settings. The README explains why it is a plugin rather than a CSS snippet: CSS alone cannot size the underline to the last line or to the widest line of a multi-line heading, and the plugin offers both. Installation is documented through BRAT or manually from a release archive.
