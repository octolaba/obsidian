# HananoshikaYomaru/obsidian-incomplete-files

Flags files as incomplete according to configurable rules and lists them, with each file's last update time, in a dedicated view that updates as the vault changes. Three rules ship: empty content, which cannot be turned off, a heading with no content beneath it, and an explicit incomplete marker written as a comment that may carry an issue string. The README describes the plugin as non-intrusive, requiring nothing to be done after installation, and documents how to add a rule by registering a new scanner.
