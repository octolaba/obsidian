# agarcabin/obsidian-tag-lock

Gates access to notes carrying a configured tag or sitting in a configured folder, asking for a password or an Android-style pattern before the content is shown. The check covers more than opening a note: search results, page previews, backlink previews and links named after a protected tag are intercepted too, and protected previews get an opaque overlay and blur rather than dimming. Unlock validity, locking on restart or backgrounding, forced verification on every access, and the navigation taken after a failed or cancelled prompt are all configurable, and input is paused for 30 seconds after five failures. It does not encrypt or rewrite Markdown files, stores password and pattern credentials as salted hashes, and requires Obsidian 1.13.0 or later.
