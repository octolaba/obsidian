# bwtymdb/obsidian-md-autofix

Scans the active Markdown note for syntax problems shortly after typing stops, on file open and on load, applying 22 individually toggleable markdownlint-inspired rules. Issues with a single safe repair, such as a heading missing its space, an unclosed emphasis marker or code fence, a table without a separator row, or trailing whitespace, are corrected through an editor transaction that one undo reverses, while the rest are only reported. Findings surface as wavy underlines with tooltips, a status-bar count, and a sidebar panel grouping them by type with per-group and global fix buttons and jumps to each location. Two commands shift every heading in a selection up or down one level, and the cursor's own line and fenced code are never touched.
