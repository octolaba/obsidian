# EnGassa/obsidian-twine

Twine syncs an Obsidian vault directly to an S3-compatible bucket the user owns, such as Cloudflare R2 or Backblaze B2, with no server component of its own. The README states that file contents, paths and folder structure are encrypted client-side with AES-256-GCM under a key derived from a passphrase by PBKDF2, so the bucket holds only ciphertext and opaque object keys. Conflicting edits are both kept rather than overwritten, one staying at the canonical path and the other written beside it as a conflicted copy, and syncing runs on debounced file changes, on a foreground timer and on app open or resume.
