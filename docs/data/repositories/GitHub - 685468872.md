# Tatz884/RescueTime-Obsidian

RescueTime for Obsidian brings activity logs from the RescueTime time-tracking service into Obsidian. It requires a RescueTime account with the service's apps installed on the tracked devices, and an API key created on RescueTime's API management page and pasted into the plugin's settings, where the connection can then be tested. The README states that the plugin works only with the Obsidian desktop client and not on mobile, and requires a client newer than version 0.13.0.
