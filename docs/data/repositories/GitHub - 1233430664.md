# darkings/Obsidian-MonokaiSyntax

darkings/Obsidian-MonokaiSyntax holds Monokai Syntax, a theme that reproduces the Monokai Pro dark and light visual language for code learning notes, long-form technical writing and daily knowledge work. Reading mode, Live Preview, file navigation, code blocks, callouts, Graph view and Canvas share one set of semantic spacing, typography and colour variables, and a Style Settings palette selector offers Follow system, Pro and Light. The README records version 1.1.5, a minimum Obsidian version of 1.0.0, and changes such as an animated accent underline on the active tab, refined Live Preview line-number spacing and restored checkbox interaction in Reading mode.
