# imaikosuke/obsidian-cloudflare-r2-sync

Obsidian plugin that uploads local images referenced by the active note to Cloudflare R2, replaces their links with public URLs and moves the local files to Obsidian's trash. The README lists syncing every local image of a note at once, immediate upload when an image is dropped into the editor, writing a chosen cover image URL into YAML frontmatter, deleting R2 objects together with their note references, and optional WebP re-encoding before upload. Markdown and wikilink image references are recognised, and remote addresses are skipped.
