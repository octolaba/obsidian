# jimparrillo/obsidian-book-catalog

Book Catalog builds a catalogue of books in an Obsidian vault by scanning ISBN barcodes with a USB or Bluetooth scanner, or by searching Open Library and Google Books by title and optional author. Metadata — title, authors, editors, publisher, year, page count, cover image and subjects — is written into the note's frontmatter, alongside condition on standard collector grades, copies owned, an estimated value, an acquisition date and any custom fields added to the capture modal. Scanning a duplicate is detected and offers to update the copy count rather than create a second note. A ribbon icon opens a Bases table view, and the plugin creates and manages a base file with All Books, By Year and Needs Condition views.
