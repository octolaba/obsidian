# eharris128/obsidian-content-os

The repository holds Content OS, an Obsidian plugin that publishes LinkedIn posts from inside the vault. A modal opened from the ribbon icon or the command palette composes the post and counts characters against the LinkedIn limit. Publishing needs a LinkedIn access token, which the README says is generated through a browser login flow and pasted into the plugin settings.
