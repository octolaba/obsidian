# iafisher/obsidian-quick-links

Quick Links creates shortcuts for linking to external sites from Obsidian. The README's example links to a Wikipedia article through a w prefix, and further prefixes are defined in the Manage quick links settings pane, such as a twitter prefix pointing at a profile or a target URL using the obsidian vault scheme to link into another vault. Its FAQ records that quick links written in wiki link syntax show up in graph view, avoided either by turning that syntax off and writing them as Markdown links or by enabling the graph's existing files only option, and that a changed setting takes effect in an open tab only after the file is closed and reopened, because Obsidian re-renders content only when it changes.
