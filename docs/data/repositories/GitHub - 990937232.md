# AlphaHasher/obsidian-remove-links

Strips link markup from either a selection or the whole file, leaving the visible text behind. Markdown hyperlinks reduce to their label, including cases with nested or escaped brackets and with parentheses inside the URL, while image links are removed outright. Wikilinks reduce to the target or, when an alias is present, to the alias or to nothing depending on a setting, and embeds are removed. Citation markup of the bracketed numeric kind common in pasted AI search results or Wikipedia content is removed entirely, and the commands are reachable from the context menu.
