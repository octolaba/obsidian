# zyx-corporation/obsidian-kotonoha-console

Kotonoha Console is the Obsidian front end for Kotonoha workflows: creating MeaningDelta entries, running RDE validation, attaching results and recording review decisions. It talks to one of three backends chosen in settings, a mock backend for smoke tests, a local kotonoha-cli of at least 0.3.1, or a running kotonoha-orchestrator over HTTP for proposal generation. Version 0.5.4 inserts or copies RDE review summary blocks into the current note, produces copy-ready GitHub issue draft text and PR summary text, and parses existing issue and PR references as correlation metadata without posting anything. The plugin reads Git context but never commits, pulls, pushes, stages or synchronizes, and the published build is desktop-only because the CLI and Git-context features need a desktop runtime.
