# KimFischer99/Obsidian-LLM-Translator

Obsidian plugin that translates selected text in PDF and Markdown files with a language model, showing the result in a popup window that appears on selection. Translation can be served by a local Ollama model, by an OpenAI-compatible cloud API such as DeepSeek or OpenRouter, or by Google or Bing Translate, which the README describes as needing no configuration. PDF documents are supported by default while Markdown requires a global mode to be enabled in the settings. The README is published in English and Chinese and describes the plugin as desktop-only.
