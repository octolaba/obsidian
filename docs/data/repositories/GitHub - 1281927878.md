# DevidCode/obsidian-extract-highlights

Extract Highlights to Note creates a new note containing only the highlighted passages, written with double equals signs, of the active note. The README describes it as a way to distil a long note such as a fetched video transcript down to its highlights. It is run from a highlighter icon in the ribbon or a command in the palette, and works on mobile as well as desktop. Settings choose the destination folder for the extracted note, whether timestamps found alongside the highlights are kept, and whether the source note is deleted afterwards.
