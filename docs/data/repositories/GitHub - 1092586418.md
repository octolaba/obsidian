# Reifat/daily-notes-sorter

Sorts daily notes and other files by the date in their filename in Obsidian's file explorer, for the folders the user configures. The README lists the supported formats, among them ISO year-month-day, the European and US numeric orderings and a short two-digit year form, plus a textual fallback for names such as three space-separated tokens, whose month names follow a fixed locale list in the plugin rather than the operating system language. Sort direction is ascending or descending and can be toggled from a button in the file explorer, and files that do not match the configured format are reported and placed at one end of the listing.
