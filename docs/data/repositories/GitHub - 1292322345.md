# affluency-dev/obsidian-moltn-sync

Moltn Sync pulls finished notes from a Moltn install into the vault and can optionally share chosen notes back to Moltn as context. Every few minutes and at startup it requests the pending notes from the Moltn install using a vault token, writes each one into a target folder without ever overwriting an existing file, then acknowledges it so Moltn drops it from its outbox; a separate command pushes a chosen folder to Moltn so its answers can cite it. The README states the plugin uses only Obsidian's cross-platform APIs and works on desktop and mobile, and that notes then spread between devices through the user's own sync. Configuration takes the Moltn install URL, the vault token, a target folder and an optional context folder.
