# hedgehog1833/obsidian-timetracker

This plugin adds a stopwatch whose current value can be inserted into the editor with a hotkey, and a custom start value can be set when the stopwatch was started too late. The README states that the stopwatch is a rewritten clone of an existing stopwatch plugin, and that development has moved to Codeberg, leaving this repository as a mirror of tags and releases for Obsidian with new issues to be filed upstream. Settings cover which of hours, minutes and seconds are printed, trimming leading zeros, a line break instead of a space after the inserted value, a text colour applied through a span, a print format built from hour, minute and second placeholders, and whether the value persists when the app closes.
