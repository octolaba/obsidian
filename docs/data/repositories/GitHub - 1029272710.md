# Pluppen/obsidian-vault-encrypt-plugin

Vault Encrypt is an Obsidian plugin that encrypts and decrypts an entire vault from a lock icon in the ribbon or the command palette, with a password entered in an encrypt or decrypt modal; files stay in that state after Obsidian closes. The README records AES-256-GCM with PBKDF2-SHA256 key derivation at a configurable 50k to 500k iterations, HKDF for file-level keys, and anonymisation of filenames and folder structure. It also warns that the vault should be backed up first, that a lost password makes decryption impossible, that the plugin is in early development, and that it has had no security audit.
