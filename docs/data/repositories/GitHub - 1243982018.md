# Live-Cursor/Live-Cursor

Obsidian plugin providing real-time collaborative editing, collaborator cursor tracking and vault configuration sync. It offers several connection modes: on desktop a one-click local host spins up a Node.js websocket daemon and reports the machine's own network addresses for other devices on a LAN or VPN to join, and a WebRTC peer-to-peer mode connects devices directly through a shared room name and password without a central server. The README states that mobile devices can join a local host but cannot act as one, because mobile operating systems block background TCP port binding.
