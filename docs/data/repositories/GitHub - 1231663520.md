# ile-24556/obsidian-plugin-smart-punctuation-on-rendering

Repository for a plugin that renders ASCII punctuation in typographic form in reading view, turning hyphen pairs into dashes, three dots into an ellipsis and straight quotes into curly ones. Its README is explicit about the limits: Live Preview is not supported, some elements may break, rendering a very large note may slow down, backslash escaping cannot be recognised because the plugin receives already-rendered HTML, and simple regular expressions rather than a syntax tree mean elements containing a callout, a Mermaid diagram or certain link targets are left unchanged. It suggests a replace-on-typing plugin as an alternative that can also be used alongside it.
