# TravisLinkey/note-reviewer

Obsidian plugin for reviewing notes that have already been taken, filtering and fetching them by tag with the aim of retaining their content. Enabling it adds an icon to the sidebar that opens the review view, and a done checkbox on a note marks it as reviewed. Tags are read from YAML frontmatter and drive the filter dropdown of its dashboard.
