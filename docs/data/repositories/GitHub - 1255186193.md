# samgilletgaras/obsidian-alert-banner

Obsidian plugin that pins a banner to the top of any note carrying a chosen tag, shown in both Reading and Editing views and staying in place while scrolling. The tag may be written inline or in frontmatter and is matched case-insensitively, up to five banners can be configured with their own tag, message, colour and Lucide icon, and a note matching several shows them stacked. Banners are not dismissible, so the warning cannot be hidden by accident, and their colours come from Obsidian's palette and follow the theme. The README gives the author's motivation as marking notes drafted with AI through a tag such as `ai-generated`.
