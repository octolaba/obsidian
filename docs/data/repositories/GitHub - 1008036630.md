# filippov112/obsidian-sortable-tables

Repository for Sortable Tables, a plugin that makes Markdown tables sortable in preview mode. Clicking a table header sorts ascending or descending, and Shift-clicking adds further sort keys of lower priority. The README states that sorting does not change the contents of the file.
