# humantorch/glass

Glass runs the Claude Code CLI inside Obsidian in an xterm.js terminal in the sidebar rather than reimplementing it as a chat interface, so slash commands, MCP tools and session continuity carry over. It ships a built-in MCP server giving structured read and write access to the vault with no configuration, authenticated by a bearer token written on each launch so other local processes are denied, and an optional read-only mode that hides the write tools. A quick-ask modal issues one-shot queries through Claude Code's print mode and renders the answer as Markdown, and a file-explorer context menu asks about a specific note. The README notes the plugin was formerly called Blackglass and keeps the blackglass id.
