# humantorch/glass

Glass runs the Claude Code CLI in an xterm.js terminal inside Obsidian and provides a built-in authenticated MCP server for structured vault access. It supports read-only mode, quick asks, file-context queries, model selection, session continuation, theme-adaptive output, and a generated CLAUDE.md vault context with backups on regeneration. The plugin targets desktop Obsidian on macOS, Linux, and Windows, with Windows requiring pywinpty.
