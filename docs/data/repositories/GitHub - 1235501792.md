# andreas13xxx/obsidian-mail-importer

Email Importer copies messages from an IMAP mailbox into an Obsidian vault as Markdown notes. It connects to an IMAP server over SSL/TLS or STARTTLS, fetches unread messages, converts HTML mail to Markdown while preserving tables, headings and lists, writes YAML frontmatter, and saves attachments and inline images locally with links from the note. Synchronisation runs automatically on a configurable interval or on demand from a ribbon icon or the command palette, with progress shown in the status bar and duplicate filenames resolved by numbering.
