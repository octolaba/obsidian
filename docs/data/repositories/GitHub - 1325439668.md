# ledokter/obsidian-mega-sync

Mirrors a vault against a folder on a MEGA.nz account, reconciling local state, remote state and a shared last-sync snapshot kept on MEGA so several devices converge. Direction can be two-way, upload-only or download-only, or a one-way push or pull that never deletes, and runs start at launch, on an interval, after debounced vault changes, or on demand. Files up to 25MB are hashed with BLAKE3 at transfer time and that hash outranks modification time when deciding what changed; text notes under 2MB can be auto-merged on conflict, while anything else keeps dated conflict copies on both sides. Glob and regex filters, a file-type whitelist, a size cap, a dry run, a per-file timeout and a guard that aborts when too much of the vault would change all limit what a run touches.
