# zhangyitong625-zjuchem/Caption-Numbering-Obsidian

This repository holds Caption Numbering, an Obsidian plugin that numbers figure and table captions written as sixth-level headings. Tags such as figure or table are defined in the settings, each keeping its own counter, and a heading beginning with a tag is numbered in sequence; an optional chapter prefix takes the number from the enclosing section heading. Typing the heading marks opens a dropdown suggesting a tag, numbering can be re-run on a timer, per-document settings are read from YAML frontmatter, and one command strips every number again. When a caption is renumbered the plugin updates the wikilinks pointing at it, correcting the target and adding or updating the display text.
