# MayaC5/obsidian-docx-importer

DOCX Importer is a desktop plugin that imports Word documents into the vault as Markdown and exports Markdown notes back to Word. An import can take several files at once, and each gets its own subfolder holding the converted note, a copy of the original document and an attachments folder for extracted images linked with embed syntax, while headings, bold, italic, strikethrough, highlights, text colour, hyperlinks, ordered and nested lists, tables, blockquotes and inline or fenced code are preserved. Export runs from a ribbon icon or a command and asks for a save location through a system dialog. The creator's note records that the plugin grew out of Google Docs exports losing style and format on the way to Markdown.
