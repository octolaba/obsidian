# alex-donnan/SyncFTP

SyncFTP pushes and pulls files between an Obsidian vault and an SFTP host the user supplies, transferring them with ssh2-sftp-client and socks and optionally through a proxy. Its settings tab takes the host address and port, a username and password, the server directory that serves as the base for all vaults, a toggle that suppresses verbose notices and a toggle that downloads on open; a sync runs from up and down arrow icons in the left toolbar or from commands that can be bound to a keyboard shortcut. The README warns that the process is destructive on the SFTP side and moves local files to the trash folder, and states that the author is no longer supporting the plugin.
