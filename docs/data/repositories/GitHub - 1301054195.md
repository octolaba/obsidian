# peterczegledy/Obsidian-markdown-columns

No repository description is recorded, so this body is grounded in the README alone. Markdown Columns adds a columns block to Obsidian so text can be laid out in an unlimited number of columns without rewriting the note in HTML. Each column keeps full Markdown rendering, including code blocks, callouts, tables, lists, images and links, and columns are separated inside the block by a line of three colons. The README recommends opening the block with four backticks so that fenced code can be used inside it, and describes the layout as responsive.
