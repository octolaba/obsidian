# Erl-koenig/obsidian-dailyPrompt

Repository for the Daily Prompt plugin, which defines a set of prompts and fills the answers into an Obsidian daily note. Each prompt is given a field type — text, note, embedded note or file, checkbox, text area or slider — and answers are written under a configurable section heading with a configurable line prefix such as a list or task marker. Running the open-prompt command asks the questions and, on accept, writes them into the daily note, creating that note when it does not already exist.
