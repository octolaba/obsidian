# yu-zou/obsidian-auto-numbered-headings

An Obsidian plugin that numbers Markdown headings as you type, rewriting the document text so the numbering survives in other editors and in exports. Numbering is opt-in per note: writing a number followed by a dot at the start of a heading activates it for that heading level, and typing that dot re-runs numbering over every numbered heading in the note. Numbers are written without a trailing dot afterwards, both forms are recognised, an optional setting keeps the trailing dot at the shallowest level, levels are numbered relative to the shallowest heading with a zero filling a skipped level, and headings without a number are left alone. The repository carries no description.
