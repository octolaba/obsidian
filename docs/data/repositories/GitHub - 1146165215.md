# talhabw/obsidian-thought-completion

Thought Completion suggests what to think or write about next, showing prompts as faded ghost text at the cursor rather than writing content into the note. The README compares it to tab completion in an IDE and gives examples such as asking for an illustrating example, a counterargument or a connection to an earlier topic. Suggestions can be limited to a mode, among them automatic, questions, structural, critical and connector, and are triggered after a pause, punctuation or a newline, or on demand from a command, with a status bar indicator showing whether it is idle, queued, thinking or suggesting. The README records that the plugin requires an OpenAI-compatible API and that trigger delay, context size and model parameters are configurable.
