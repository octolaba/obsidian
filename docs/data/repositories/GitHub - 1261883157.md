# viggomeesters/obsidian-html-page-viewer

HTML Page Viewer opens `.html` and `.htm` files as rendered pages in a dedicated Obsidian view, aimed at local reports, exported dashboards, documentation, prototypes and generated artifacts. A toolbar switches between the rendered page and a source view with syntax highlighting and line numbers, refreshes the file, and toggles script execution, which stays off by default and, when turned on, applies only to the current viewer tab. Rendering happens in a sandboxed iframe that is never granted same-origin access, forms, popups or top-level navigation, and the README states that the plugin itself makes no network requests, does not touch the clipboard, and never writes to vault or HTML files. It also notes that a rendered document may still request external resources such as images, stylesheets, fonts or scripts.
