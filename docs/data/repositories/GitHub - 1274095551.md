# zebo101/ReadAlong

Exports a note, or a whole folder, into self-contained HTML pages laid out for reading — narrow body column, serif type, heading hierarchy, clickable table of contents, tables, code blocks, quotes and callouts — with CSS inlined and images and audio optionally embedded, so a page opens offline in a browser or through a registered reading view inside Obsidian. An optional read-along mode synthesises sentence-by-sentence TTS narration into the exported page and highlights the sentence currently being spoken, with a floating player offering play, pause, speed, previous and next sentence, and a progress bar. Folder structure and links are preserved, and a back-link to the source note can be inserted at the top of that note, resolving correctly even when the export path contains a `#`. The README is written in Chinese with a separate English version.
