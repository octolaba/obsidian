# meld-cp/obsidian-encrypt

Meld Encrypt is an Obsidian community plugin for encrypting and decrypting notes, either a whole note or selected text within one. The README states that encrypted notes are never decrypted to disk, so decrypted contents are not synced or backed up to external systems. It carries an explicit use-at-your-own-risk warning: passwords are never stored, so a forgotten password means the notes cannot be decrypted; the encryption methods have not been independently audited; and the user is responsible for keeping backups.
