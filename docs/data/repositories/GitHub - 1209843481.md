# totocaster/metrics-obsidian

Metrics reads and edits canonical `*.metrics.ndjson` files in the vault, one JSON object per line, with required id, timestamp, key, value and source fields and optional date, unit, origin, note, context and tag fields. Its view gives a timeline with inline validation, record create, edit and delete, cross-file command-palette search that jumps to the matching row, filtering by time range, metric, source, validation status or free text, sorting, grouping by period, metric or source, optional derived summary rows such as average, median and sum, and optional charts over the same visible rows. The README states that the plugin acts as a lens over the file rather than introducing a hidden database or cache layer, and that it targets Obsidian 1.6.0 or later.
