# Jin1c-3/obsidian-advanced-maps

Advanced Maps extends Obsidian's first-party Maps view for Bases rather than replacing it, and needs Obsidian 1.13.1 or later with Bases and the Maps plugin enabled. Track files attached to a note, including GPX, GeoJSON, KML and TCX, are drawn in that note's colour with start and end pins, direction arrows, distance, ascent, moving time, pace and an elevation profile, and a track embed renders as an inline map. Geotagged photos get their own pin and thumbnail from EXIF GPS tags, notes sharing one coordinate fan onto a ring past zoom 15 so each stays clickable, and the view auto-frames markers and tracks. Coordinates can be filled from a pasted map link, a place search, a photo or the device, and mainland basemaps are aligned by converting coordinates in memory rather than on disk.
