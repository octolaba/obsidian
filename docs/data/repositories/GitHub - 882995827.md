# aths7/cypher

Cypher replaces the letters of a note with icon-based symbols, giving each upper- and lowercase letter its own symbol. A ribbon icon toggles cypher mode, converting text as it is typed and reverting to plain text when switched off, and a separate command converts only the selected text while the mode is off. The README describes handling of spaces and backspacing and a setting for choosing between symbol sets; it presents the result as a visual transformation rather than as encryption.
