# ebullient/obsidian-slides-extended

Slides Extended creates reveal.js presentations from Markdown inside Obsidian. It embeds notes into slides, previews the deck live while it is edited, changes appearance through themes and per-slide annotations, exports to PDF or to an HTML presentation, and supports most of Obsidian's Markdown syntax. The README records it as an official community plugin and describes a manual installation in which the release archive is extracted into the plugin folder alongside the usual plugin files.
