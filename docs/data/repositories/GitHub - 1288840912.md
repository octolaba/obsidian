# NabheetCloud/Obsidian-Whatsapp

WhatsApp Local Sync mirrors WhatsApp Desktop chats into an Obsidian vault as one transcript note per conversation, reading the app's local SQLite database through a WebAssembly build of SQLite bundled into the plugin. Each sync appends only rows newer than the highest message row id already written for that chat, grouped under day headers, and a setting bounds how many days back a sync reads. The README describes the plugin as read-only and fully local, copying the database to a temporary file and reading it there with no network, cloud, QR pairing or API keys, and as desktop-only because it reads that file through Node.
