# chetachiezikeuzor/Yin-and-Yang-Theme

Yin and Yang is an Obsidian theme built around a stark contrast between its dark and light modes. The README recommends the Style Settings plugin, which exposes customizable features including base hue and saturation, and the Hider plugin for a more minimal workspace. It documents installation from the community themes browser or by placing the stylesheet in the vault's themes folder, and credits the California Coast theme as inspiration.
