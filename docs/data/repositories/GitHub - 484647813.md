# turulix/obsidian-folder-index

The repository holds Folder Index, an Obsidian plugin that treats a folder as if it were a note. Its README records automatic generation of an index file when a folder is clicked and none exists, renaming of that index when the folder is renamed, automatic linking of the folder's files, alphabetical sorting of both files and headings, and a reworked graph view that shows the folder structure and links folders to their contents. It also records a content block for manual indexing and support for an alternative file tree plugin; the code is licensed under the GNU GPL version 3.
