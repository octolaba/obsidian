# mssoftjp/obsidian-ai-transcriber

Speech-to-text plugin for Obsidian that transcribes existing audio and video files through OpenAI transcription models, including GPT Transcribe, GPT-4o Transcribe, GPT-4o Mini Transcribe and Whisper. It accepts mp3, m4a, wav, flac, ogg and aac audio and mp4, m4v, mov, avi, mkv and webm video, handling video by extracting its audio track. Optional post-processing applies word correction, and several languages are supported with automatic detection. The README records desktop-only operation, Obsidian 1.8.7 or higher, an OpenAI API key, and limits of 500MB for the external file picker and 128MiB or two hours for locally decoded media.
