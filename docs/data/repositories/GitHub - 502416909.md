# victorb/obsidian-wielder

Wielder runs Clojure code blocks inside Obsidian documents: in view mode it evaluates each block marked clojure, working through the document block by block so a pipeline of data can be built up with descriptive text between the steps. React components can be rendered through Reagent, and the Obsidian API is reachable from a block through the application object, so what a plugin can do can also be done from a document. The README carries an explicit warning that, like Templater or Dataview, Wielder executes arbitrary code defined by the document, which can harm the vault, the Obsidian installation or the whole system, and it advises running only code whose behaviour is understood.
