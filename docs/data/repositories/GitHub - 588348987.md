# tazpellegrini/abyssalobsidian

Abyssal is a typography-led Obsidian theme that aims to improve the reading and writing experience without changing the app's interface dramatically, using generous white space and muted colours; the configured accent colour still shows through, but only faintly. It requires no plugins or snippets and works with the default system font on Windows and Mac, in light and dark modes and with or without translucency, while the Style Settings plugin adds colourful headings and a larger line height. The README singles out asymmetrical spacing on an 8px grid, a separate line-height treatment per heading type, contrast built from type size, weight and spacing, and contextual spacing that responds to whether items such as the inline title are shown. Its author records this as a first theme, not yet tested on mobile or on Linux.
