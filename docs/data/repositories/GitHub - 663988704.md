# EnderInvader/battlesnake-viewer

This plugin renders BattleSnake JSON board positions as an SVG board inside Obsidian's preview mode: a board state is pasted into a code block tagged with the `battlesnake` language and drawn from there. The README states the plugin is deliberately visualization-only — it does not offer interactivity or handle whole games — and that it is optimised for viewing and for HTML and PDF export.
