# bije0327/obsidian-stacktube

Repository for StackTube, a plugin that pulls notes about YouTube videos from the StackTube service into the vault as plain Markdown. Its README states that the service monitors chosen channels and runs each new video through its own pipeline, that the plugin is a thin client which only fetches and writes files, and that each note carries frontmatter fields for the video identifier, channel, title, address, publication date, language and tags. It records scheduled or on-demand syncing, deduplication by video identifier, resuming after a restart, a ribbon icon and status bar showing the last sync and progress, an optional sync at startup with a choice of initial range, and a capture action added in version 0.2.0 for notes carrying a timestamped frame slot.
