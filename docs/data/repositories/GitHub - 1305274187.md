# Vegolas/obsidian-rpg-scene-maker

This plugin, named Ambient Director in its README and RPG Scene Maker in the recorded description, fires scenes, events and sounds on a companion server from inline tokens written in Obsidian notes. A token renders as a clickable button that sends a background request through Obsidian's requestUrl, so no browser tab opens, and reports the result in a toast; typing the token prefix triggers autocomplete that offers the kinds and then the scenes actually present on the server, with their names and tile art. Buttons can be shown as compact chips or full-width banners with the entity's uploaded art or leading emoji, carry a pulsing indicator while their scene, event or sound is active — including when it was started elsewhere — and the server's control panel can be opened inside an Obsidian tab; both reading view and live preview are supported.
