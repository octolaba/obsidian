# szuc/obsidian-life-in-weeks-calendar

Obsidian plugin that draws a life as a grid of weeks, colour-coding past, present and future weeks and marking the weeks for which a weekly note exists. Weekly notes are read through the Periodic Notes plugin, through the Journals plugin, or standalone, and their folder may contain date-based subfolder variables. Settings cover birth date, projected lifespan, a standard or decades view mode and the panel the calendar opens in; the README recommends a statically named weekly-note subfolder because dynamic or root-level folders slow scanning.
