# Tboules/supernote-obsidian-digest

Supernote Digests reads a Supernote device backup file and turns each highlighted digest inside it into a note, embedding the extracted image of the original handwritten mark with trailing whitespace trimmed. Two organisation styles are offered: atomic, where each digest becomes its own note linked into an atlas note for its source document, and document, where all digests for one source are collected into a single note. Re-running the generation creates notes only for digests that do not exist yet, so existing notes are never overwritten, while switching the organisation style deletes the previously generated notes and requires generating again. The README documents how the backup is produced on the device, and the digest, image and atlas paths are configurable.
