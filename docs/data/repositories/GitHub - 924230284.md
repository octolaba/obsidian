# iinkov/obsidian-attachments-md-indexer

Obsidian plugin that generates Markdown index files for attachments so canvas files, PDFs and images are treated more like notes. Outgoing links from canvas files then show up in the graph view and in the outgoing and backlink panels, and text extracted from PDFs and images makes those attachments searchable by keyword. Index files are created and updated automatically and are removed when the attachment is deleted, which is why the README says a generated file kept as a text backup should be moved out of the index folder. Because the indexes are Markdown, plugins that only work with Markdown, including AI chat plugins, can reach the attachment content.
