# jsandburg/obsidian-featherlight

Enforces a maximum character count on notes: a CodeMirror transaction filter blocks any edit that would add text once the limit is reached, while deletions and selections keep working. A status bar item shows characters used and remaining, turning orange near the limit and red at it, and the limit is set from presets of 140 or 280 characters or a custom number, with a frontmatter property overriding it for a single note. The limit and the counter can be scoped to named folders, leaving notes elsewhere untouched. Counting is the raw length of the file including spaces, punctuation and frontmatter, notes already over the limit are never truncated, and Obsidian 1.13.0 or later is required.
