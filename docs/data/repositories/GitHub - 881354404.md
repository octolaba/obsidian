# FBarrca/obsidian-inlineAI

The README describes an Obsidian plugin that brings language-model assistance into the editor, where text can be transformed, summarized or rewritten from prompts, and where users can define their own system and transformation prompts as commands. Suggested changes are shown as an inline diff with markers for added and removed text, and each suggestion is accepted or discarded with a single click. The README states that OpenAI, Ollama, Gemini and other APIs are supported, including local models for privacy-first workflows, and that an API key and a model are chosen in the plugin settings before use.
