# Eason38467/Obsidian-Knowledge-Atlas

The recorded description states that Knowledge Atlas turns a vault into an interactive, searchable knowledge map, scanning Markdown files through Obsidian's native API without requiring Dataview or generated index notes. The README adds that it presents the vault as an animated galaxy, a structured tree, and activity and knowledge-health panels, and needs no network service. The galaxy overview deliberately stops at the second folder level so a large vault stays readable, with search or entering a folder needed to go deeper, and the README says note names are never changed to render the atlas. Installation is from the community directory or manually from a packaged release.
