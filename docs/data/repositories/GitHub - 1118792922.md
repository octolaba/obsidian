# lualum/obsidian-better-bullets

The repository records no description, so this note is grounded in the README alone. Better Bullets changes the visual hierarchy of bullet lists in Obsidian by analysing nesting depth and applying different symbols and sizes: leaf items keep the standard dash, parents use `->` and grandparents use `=>`, with higher-level lines scaled up and optionally bolded so they read as section headers.
