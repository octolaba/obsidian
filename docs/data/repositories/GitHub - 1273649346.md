# bulat-beltone/obsidian-islands-theme

bulat-beltone/obsidian-islands-theme holds Islands, a theme inspired by the Islands look announced for JetBrains IDEs. Its README states that it overrides no colours and changes no fonts, that it is desktop only, and that its card layout concept comes from AnubisNekhet's AnuPpuccin.
