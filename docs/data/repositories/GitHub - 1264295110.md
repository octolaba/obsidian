# avinashingit/selection-format-toolbar

Selection Format Toolbar shows a floating formatting toolbar above the selection whenever text is selected in the Obsidian editor, whether by mouse or by shift and the arrow keys. The README lists bold and italic toggles, buttons that set or remove the heading level of the selected lines, and six highlight colours with a button that removes the highlight again. It states that the text stays selected after each action so formats can be chained, that the toolbar is dismissed by the escape key, by scrolling or by clicking elsewhere, and that highlights are written as inline tags so the colours render in live preview and reading mode alike.
