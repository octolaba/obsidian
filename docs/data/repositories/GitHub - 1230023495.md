# rgomezjnr/copy-notes-to-vault

The repository holds Copy Notes to Vault, an Obsidian plugin that copies selected notes from the current vault into another vault together with the attachments they reference, resolving both embeds and links. Notes are picked in a searchable folder-tree dialog, the destination vault is chosen with a native folder picker, the source folder hierarchy can be preserved, and the last destination and preferences are remembered. The README states that the plugin uses the local filesystem, works only on desktop Obsidian, and advises backing up both vaults before use.
