# gaut3/timeflow

Timeflow is a flextime tracking dashboard for Obsidian built around a color-coded flextime balance, with a built-in timer, a calendar and statistics views. Timers can be started and stopped from the dashboard or the command palette, run with a live duration display, are logged automatically into the plugin's data file, and can carry comments that also appear in the history table, the calendar context menu and CSV exports. The README states that structural colors come from Obsidian's own theme variables and that the same dashboard adapts to a narrow sidebar layout. It was originally designed around Norwegian work conventions, and it records that workday hours, work week structure, leave types, colors and labels are all configurable, with the interface available in Norwegian and English.
