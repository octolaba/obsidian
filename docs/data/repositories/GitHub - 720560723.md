# MrAnyx/obsidian-note-batcher

Note Batcher is an Obsidian plugin that creates every unresolved link in a vault in one action, so that link targets which do not yet exist become real notes. It uses the Dataview API to list pages and their outgoing links, which makes Dataview a prerequisite. The README states the license as AGPL v3 and recommends the Hot Reload plugin for local development.
