# fnya/remove-empty-folders

Remove Empty Folders deletes empty folders under a selection made in the file explorer: the folders are selected, and the removal is run from the right-click menu. The README states that the folders are moved to Obsidian's own trash folder rather than physically deleted, so an unexpectedly removed folder can be inspected and recovered there, and it asks the reader to back the vault up first because data may be lost. It also records a limitation: only folders empty at the moment of execution are removed, so a folder left empty by the run itself survives and the command may need to be run several times.
