# TheJusticeMan/obsidian-find-replace-regex

This repository is a find-and-replace plugin for Obsidian with full regular-expression support, offering search by regex, plain text or whole-word matching, case-sensitive matching, and replacement of one match or all matches with capture-group substitution. The README documents a search panel and a search-and-replace panel opened by keyboard, navigation between matches, a counter showing the current match out of the total, search history reachable with the arrow keys or a history button, and persisted default preferences. It lists the full shortcut table, including replace-single and replace-all bindings.
