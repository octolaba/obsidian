# ReticentEclectic/checkbox-style-menu

Offers a menu for changing the style of a checkbox, opened by long-pressing it or by another trigger chosen in the settings. The README states that it covers the twenty-two checkbox styles used by the Minimal and Things themes and lists them, from the basic to-do, incomplete, done, cancelled, forwarded and scheduling states to extra ones such as question, important, star, quote, location, bookmark, information and idea. Which styles appear in the menu is configurable, the styling is described as following the active theme or custom CSS, and the README states that desktop and mobile are both supported, with haptic feedback and touch-tuned interactions on mobile.
