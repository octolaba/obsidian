# davisriedel/obsidian-typewriter-mode

Typewriter Mode keeps the current line at a fixed position on the screen and gathers several writing-focus options around it. The README lists current-line highlighting, a configurable number of lines kept above and below the cursor, dimming of unfocused paragraphs or sentences, a fullscreen writing focus, a line-length limit, restoring the cursor position when a file is reopened, and a Hemingway mode that disables editing previously written text.
