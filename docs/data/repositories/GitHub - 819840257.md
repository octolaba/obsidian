# jpoles1/obsidian-litegal

The repository records no description; its README presents Lite Gallery, a plugin that renders carousel image galleries inside a note. A gallery is written as a fenced block tagged litegal, listing one image per line either as a wikilink or as a path. Image directories are configured as a comma-separated list in the settings and searched in order, so a full path need not be given: the first match found in that list is used. The README notes that Obsidian's file search can be invoked inside the block, which inserts a name rather than an absolute path.
