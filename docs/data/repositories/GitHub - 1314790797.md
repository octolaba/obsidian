# EnyaWu/obsidian-hackmd-push

HackMD Push uploads the current Obsidian note to HackMD from a command or a ribbon icon, creating a remote note on first push and updating the same one afterwards. It records the remote id, URL and push time in the note's frontmatter, takes the HackMD title and tags from frontmatter fields, and strips the frontmatter block from the uploaded content. Further commands copy the link, open the note in a browser or unlink it, and the default read, write and comment permissions can be changed in settings. Sync runs one way only, local attachments and wikilinks are not converted, and the API token is stored in plain text in the plugin's data file.
