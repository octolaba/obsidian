# Ariestar/obsidian-dragger

Dragger adds block-level drag and drop to Obsidian: a handle on the left edge of a block moves paragraphs, headings, lists, tasks, blockquotes, callouts, tables, code blocks and math blocks, with a drop indicator showing where the block will land. Horizontal position during a drag controls the indent level while vertical position controls the insertion row, and a range of blocks can be selected by click or long-press and dragged as a group. The README describes mobile long-press dragging with edge auto-scroll, a block type menu that converts or deletes a block, and customizable handle icon, size, colour and offset. It also publishes a platform-agnostic npm core that imports neither Obsidian, CodeMirror nor DOM event APIs.
