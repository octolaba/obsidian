# topk36/obsidian-jira-confluence-converter

Converts the current selection, or the whole note when nothing is selected, into Atlassian markup and puts the result on the clipboard. Two commands cover the targets: Jira wiki markup for fields that use the wiki renderer, and rich text that pastes into the Confluence editor, written to the clipboard as HTML with a Markdown fallback. Headings, emphasis, links, images, lists, task lists, quotes, fenced code, simple pipe tables and horizontal rules are handled, wikilinks become their display text and YAML frontmatter is dropped, while callouts, footnotes, math, embedded HTML and transclusions are converted only as far as a pragmatic converter reaches. Conversion is entirely local with no network use, and an optional ribbon icon runs whichever of the two commands is set as its default.
