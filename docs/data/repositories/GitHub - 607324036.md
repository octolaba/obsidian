# Victologo/elegance-theme

Elegance is a theme for Obsidian, and this repository's README presents an enhanced second version of it. The README records Style Settings compatibility with more than twenty options covering font sizes, colours and spacing, embedded notes with configurable or automatic height and custom scrollbars, and native zoom by control and scroll or by keyboard shortcut. It also lists snippets built into the theme for Dataview cards, Quiet Outline, MathJax and Kanban, and changes described as font rendering, consistent scrollbars, respect for reduced motion preferences and better accessibility support.
