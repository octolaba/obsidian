# ivan-94/obsidian-plugin-manushelf

Manushelf presents a folder of Markdown manuscripts as a responsive, tactile 3D bookshelf inside Obsidian, where each direct child folder is one book. The plugin prefers that folder's index note and otherwise its first naturally sorted Markdown file, discovers a cover image automatically, and lets the title, description, cover and entry be overridden through a form rather than hand-written JSON. The README records Three.js rendering with authored geometry, materials and lighting, a layout of two to six columns keyed to the current leaf width, light and dark rendering with reduced-motion and quality profiles, and a cover-list fallback when WebGL is unavailable. It states that the plugin is offline and self-contained, with no account, telemetry or runtime network requests.
