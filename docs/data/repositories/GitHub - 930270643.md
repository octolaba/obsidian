# Lemon695/obsidian-note-image-gallery

Note Image Gallery is an Obsidian plugin that collects every image in the current note into a masonry gallery view, opened from the command palette. It handles vault attachments, remote HTTP and HTTPS images and Weibo images, opens any image in a lightbox with arrow-key navigation, mouse-wheel or keyboard zoom and a context menu for copying and downloading, and filters by local or remote origin and sorts by size or document order. For large collections it uses lazy loading, virtual scrolling, a prioritised image queue and configurable concurrency, plus a file-based cache for remote images with a configurable size and expiry and a combined LFU and LRU eviction policy. Its interface follows the Obsidian language setting, with English and Simplified Chinese included, and it runs on desktop and mobile.
