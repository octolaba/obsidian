# mrboxtobox/obsidian-related-notes

Related Notes finds notes similar to the active one using bloom-filter similarity analysis and lists them in a sidebar opened from a ribbon icon or a toggle command, where a button creates a link to any of them. The README states that processing is local and no data is sent externally, that multiple languages including CJK scripts are handled, and that indexing is optimised automatically for large vaults. The index is maintained as notes are modified, and a rebuild button in the settings forces a complete re-index with progress shown in the status bar, which the README suggests after large changes or when the index is suspected to be out of date.
