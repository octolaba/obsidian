# Ahmedexe/obsidian-images-ocr

Multilingual OCR for Obsidian extracts text from images in the vault, applying OCR to the last image in the active note, to an image named by absolute or relative path, or to an image right-clicked in the file explorer. Results are copied to the clipboard or shown in the sidebar for highlighting and copy-pasting, the language can be chosen from the more than 100 that Tesseract.js supports, and Arabic right-to-left text is handled. Only png, jpg and jpeg files are accepted, and the README notes that Tesseract.js is not perfect and may produce unexpected output for some images.
