# Lbstrydom/ai-organiser

Obsidian plugin that gathers several AI features behind a single command picker: summarising URLs, PDFs, YouTube videos, audio recordings and Office documents, web research, presentation building, meeting recording, Kindle highlight sync and automatic tagging. Its chat modal offers six modes, among them semantic search over the vault, web research with source scoring and numbered citations, and slide-deck construction, with conversations persisting across sessions. The README records support for 14 providers running locally or in the cloud, five built-in summary personas, an inline diff preview before any write, and export of decks to PowerPoint and meeting minutes to a Word document.
