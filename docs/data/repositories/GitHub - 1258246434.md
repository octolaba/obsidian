# hansai-art/obsidian-hans-kanban

Hans Kanban is an Obsidian plugin that adds a kanban view for Bases with a Traditional Chinese interface, forked from Kanban Bases View under the MIT licence. The README records grouping notes into columns by a chosen property, dragging a card to change that property, and a dropdown on the card that switches state without dragging. Colour is driven by an emoji at the start of the property value, assigned automatically from ten colours by picking the least used one when a new plain-text state is typed, with a command to rename, recolour or delete states that reports how many cards use each. Further recorded features are swimlane grouping on two axes, a masonry card wall, global and per-column width adjustment, a minimal mode hiding property labels, an option to hide empty columns, card positions preserved across file renames, and a generator for a sample board.
