# Kool-Ankit-Raj/Alignment

Obsidian plugin that aligns selected text to the centre, to the right or justified by wrapping the selection in align tags. Alignment is applied from an Align entry in the right-click context menu or from command palette commands, and a Reset Align option removes the tags again. Justify is optional and is switched on in the settings tab so the menus stay short. The README states the plugin was built with the help of Gemini.
