# eatgrass/obsidian-lyrics

This plugin adds an interactive lyrics display to Obsidian's audio player, so an audio file can be navigated through its lyrics or transcript. The audio source and the subtitle contents are written inside an lrc code block, LRC and SRT subtitle formats are supported, and the source is given either as a file path or as an internal link. The README records a context menu in Reading View covering play and pause, auto-scroll, sentence mode, seeking and editing, and it lists the CSS classes available for styling the rendered lines.
