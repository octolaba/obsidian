# chanhee-lee/obsidian-privacy-screen

Privacy Screen blurs the Obsidian workspace except for a spotlight area around the cursor, which its README frames as privacy when working in public spaces. The spotlight can be a circle or a square with adjustable corner roundness, its width, height and horizontal offset are set separately, and it can follow either the text cursor or the mouse pointer. Blur intensity and edge feathering are configurable, the screen is toggled from a ribbon icon or the command palette, and whether it was active is remembered when Obsidian is closed.
