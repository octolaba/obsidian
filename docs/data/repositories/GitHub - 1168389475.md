# silas-zhen/monolithos-plugin

Monolithos is an AI plugin that connects Obsidian notes to hosted models named in the README as Claude Opus, Grok and Gemini Pro, adds inline AI on a keyboard shortcut, and turns writing into podcasts and presentations. Its Memory Core module crystallizes a note, PDF, document, audio transcription or image into a Crystal file holding a distilled core insight, extracted entities, relationships, timestamps and metadata, and a traceable thread back to the source. The README describes the plugin as privacy-first and local-first, with the vault staying on the user's own machine and retrieval described as deterministic rather than a statistical approximation; those are the project's own statements.
