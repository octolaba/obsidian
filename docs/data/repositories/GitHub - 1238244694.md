# jshuntley/fjord-obsidian

jshuntley/fjord-obsidian holds Fjord, an Obsidian theme with a dusk-blue base, a leaf-green primary accent, cyan selections and a crisp blue and cyan separation. The README tabulates its core and accent colours by name, covers installation from the theme browser or by copying theme.css and manifest.json into the vault, and states that the theme is generated automatically from the fjord-core project.
