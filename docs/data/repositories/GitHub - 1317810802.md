# pan75291386-hue/watermelon-workbench

Opens the current Markdown file in a dedicated long-form writing view, with a chapter list of sibling files on the left, the editor in the center and a tools and statistics panel on the right. Typography controls cover font family, size and line height, a toolbar toggle makes Enter start the next line at a first-line indent that never reaches the saved Markdown, and chapters can be sorted by path, name or modification time. A bundled generator produces Chinese and English personal names and place names locally, with no network request or API key. Snapshots are taken automatically about every hundred new non-space characters into a backup folder beside the chapter, can be diffed against the draft and restored, and a stats panel tracks session words, typing speed, writing and idle time, and folder totals.
