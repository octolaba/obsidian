# vannamhh/progress-tracker

Progress Tracker shows how far the Markdown checkbox tasks in a note have been completed, as a progress bar that updates in real time. The README records automatic status updates as tasks are checked, integration with Kanban boards that moves cards to appropriate columns as tasks complete, custom checkbox states for Kanban columns, customizable colours and thresholds, and a debug mode for troubleshooting. Its notes on the latest update record that only one tracker view is created even after reloads, that the view appears in the right sidebar by default, and that the progress bar view loads and updates reliably when opened.
