# aaaaayushh/ai-latex-generator

The LaTeX Generator plugin converts selected natural-language text in an Obsidian note into a LaTeX equation with a single command. Conversion runs against Ollama serving a model locally, so Ollama has to be installed and running, and the model used is selectable in the settings. The README records a loading indicator during conversion, detailed error messages for troubleshooting, and a minimum Obsidian version of 0.9.7.
