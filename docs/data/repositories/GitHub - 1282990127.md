# guilier/relation-weaver

Tracks characters, factions and the relationships between them for novels, tabletop campaigns and worldbuilding, alongside appearance frequency, changes in closeness over time and a narrative timeline. Data is kept as Markdown files in the vault that can be edited by hand, with relationships and factions written to both Markdown and JSON so each backs up the other and manual edits are read back in. Entries can be pushed to Obsidian's own graph view in one action. Field names, tags, closeness levels and relation types are configurable, and the plugin runs on desktop and mobile.
