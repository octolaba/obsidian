# ChekTek/obsidian-copy-link

The repository holds Copy Link Button, an Obsidian plugin that puts a small copy button beside links and images, in the manner of the copy button on code blocks. It covers Markdown links, bare URLs, wikilinks, internal embeds and Markdown images, with a floating button over rendered images, and works in editing, Live Preview and reading view; clicking copies the URL, wikilink or image target and shows a brief confirmation. The README states that the buttons are visible by default but can be limited to while a modifier key is held, and that they are styled from Obsidian's theme variables.
