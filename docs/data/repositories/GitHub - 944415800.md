# CalfMoon/node-factor

Node Factor is an Obsidian plugin that changes which factors determine node size in the graph view. The size can be driven by the number of letters in a file, by the weight of links leading out of it forward and backward, and by whether every descendant reachable forward is counted or only the direct children, and extra size can be added to chosen files by hand. Its settings expose multipliers for forward and backward link weight and a characters-per-weight value, whose defaults the README records. The README states that the project is new and may still contain bugs and gives its license as MIT.
