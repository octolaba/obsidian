# Karakaz/obsidian-paste-from-history

Paste from History tracks the text copied or cut inside Obsidian and lets an earlier clipboard entry be pasted from a menu of recent items. That menu either floats above the editor or docks to its bottom, with settings for how many entries are tracked, twenty by default, how many are visible before scrolling, and how many lines a multiline preview reserves; a second command clears the history. The README records the limitations: Obsidian has no access to the operating system clipboard, so copies made in other applications are not tracked, pasting works only inside editing view, only text content is supported, and the history is held in memory, so it is lost between sessions and never shared between devices.
