# camelChief/local-bible-ref

Local Bible Ref references Bible passages that are stored locally in an Obsidian vault, fetching a passage from a short prefix typed before the reference. The README states that the plugin is an amalgamation of the Bible Reference and Bible Linker plugins, keeping the prefix syntax of the first and the local storage of the second, and that a locally stored Bible allows referencing while offline as well as reading inside the vault. Getting started requires formatting a Bible for the vault in the plugin's own Markdown format, and the README links an already formatted public-domain translation as a starting point.
