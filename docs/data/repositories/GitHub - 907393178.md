# XZSt4nce/note-placeholder

Obsidian plugin that replaces the text of a note link with a placeholder in view mode. A note declares its placeholder in a property, whose name can be changed in the settings, and a further setting decides whether the link name is used in preference to the placeholder or never used at all. The README also documents a separator, declared through a special header, for headers and a specific block, and the project is documented in English and Russian.
