# chengshans/ob-epub-reader

EPUB Marginalia opens EPUB files from the vault in a reading view with chapter navigation, a saved position and accumulated reading time; the README is largely Chinese. Selected text can be underlined in five colours or annotated with one of five configurable thought types, and the resulting excerpts are written into a Markdown file whose folder and filename follow placeholders, in one of several link formats, with deep links back to the exact position in the book. Recorded settings include font size, side margins, six reading themes, paginated or scrolling modes, toolbar placement, keyboard and wheel navigation, and an interface in English, Simplified and Traditional Chinese and Japanese. Annotation and shelf features can each be switched off to leave a plain reading and copying mode.
