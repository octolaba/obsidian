# sspaeti/obsidian-trouble-tags

Trouble Tags scans the active file for inline tags such as TODO, FIXME, BUG, NOTE and WARN and lists the matches in a sidebar panel, where clicking an entry jumps to that line in the editor. The panel is opened from a ribbon icon or a toggle command, and rescans automatically when the file is edited or another file is opened. The README states that the plugin was inspired by trouble.nvim.
