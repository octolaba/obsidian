# loispsq/reading-time-status

Reading Time Status adds an estimated reading time for the active note to Obsidian's status bar, alongside the built-in word and character count, and updates it as notes are switched or typed in. Counting is CJK-aware — each Chinese, Japanese or Korean character counts as one word — so mixed-language notes are estimated on the same basis. The reading speed used as the divisor is configurable and defaults to 200 words per minute, and an optional setting also shows the word count next to the estimate.
