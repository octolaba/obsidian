# springrain1/workflowy-style-outline

Obsidian Workflowy Plugin turns Markdown notes into a Workflowy-style hierarchical editor with dual-mode Markdown and outline editing. It supports block operations, drag and multi-selection, collapse and zoom navigation, shortcuts, atomic undo and redo, and a save queue designed for high-frequency typing. Its Daily Notes Plus view aggregates notes with filters, sorting, on-demand loading, cross-section block movement, and quick date actions; the feature requires a license.
