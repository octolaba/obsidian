# DavidHurtadoAI/visual-card-writer

A desktop plugin, described upstream as an early beta, that presents a Markdown note as a tree of cards in which ATX headings define the hierarchy and each card edits the matching section of the same source file. Cards drag to reorder, move whole branches or change depth, with heading levels rewritten to match; branches fold, child and sibling cards are created in place, and each card is edited in an embedded CodeMirror 6 editor with Live Preview. The tree draws horizontally or vertically with right-angle connectors, unrelated cards can be dimmed to keep one branch in focus, and columns and cards resize while the view pans and zooms. A note without an H1 gets one inserted from its filename, skipped heading levels raise a local repair menu, and a document that sets marp to true becomes a flat sequence of draggable slide cards.
