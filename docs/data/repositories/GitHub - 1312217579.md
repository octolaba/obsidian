# LeMathMath/Obsidian_MM-Notes-Expand

MM Notes Expand adds mouse controls to Obsidian's canvas. A single click on a text-based node opens an overlay on top of it showing the node's full content, so a card smaller than its text can still be read, and a double click opens the underlying note in a new tab for editing instead of going through the file explorer. Both behaviors can be switched off independently and adjusted with options such as the overlay size and keeping nodes read-only.
