# kzhovn/statusbar-pomo-obsidian

Obsidian plugin that runs a pomodoro timer in the status bar. Clicking the ribbon clock starts it and clicking again pauses it, the same actions are in the command palette with a hotkey available for quitting, and settings cover the length of the pomodoro, the breaks and the interval between long breaks, the end-of-timer sound and white noise, and whether the next interval starts on its own or after a set number of cycles. With logging enabled the plugin appends a line to a chosen log file at the end of each pomodoro, creating that file if it does not exist, with a message in moment display format that can optionally go to the daily note or carry a link to the note active when the timer started. System notifications can be enabled, and the README records that they may not work when Obsidian was installed through Flatpak on Linux.
