# viggomeesters/obsidian-vcf-contacts-viewer

VCF Contacts Viewer is a read-only Obsidian plugin for inspecting vCard files as contact cards, raw source and import-preflight warnings, built for reviewing vCards that arrive in a vault without turning Obsidian into a contact manager. It parses one or more vCard blocks, supports common 3.0 and 4.0 fields, lists contacts with full name, organisation, primary email and primary phone, offers a numbered raw source view, searches across names, organisation, email, phone and raw source, and reports warnings for unsupported fields, malformed cards, folded lines, encoded fields and version mismatches. The README positions it as deliberately narrower than the existing VCF Contacts plugin, and records that it never loads remote photo URLs or renders embedded photo data, makes no network or clipboard calls, and never writes back to the files.
