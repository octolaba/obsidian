# disciple-dev/obsidian-plugin-open-file-explorer

Turns a local Windows filesystem path pasted into the editor into a clickable link. The README shows that pasting a path such as `C:\Users\Public` prompts with a modal dialog and produces a Markdown link pointing at a `file:///` URL, so the target opens in File Explorer or its associated application.
