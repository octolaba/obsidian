# 0xatrilla/obsidian-torch-cursor

Torch Cursor darkens the Obsidian window and draws a warm, flickering glow around the text cursor. The README documents a Toggle torch mode command and settings for whether the light follows the text cursor, the mouse pointer or whichever moved last, together with torch radius, darkness, glow intensity and colour, flicker, how quickly the light chases the cursor, and an option to keep the sidebars lit and darken only the editor area.
