# ozthealem/click-unsupported-twice

Changes how the file explorer reacts to files Obsidian cannot open itself, such as PSD, AI or ZIP: a single click only selects the file, and a double click hands it to the operating system's default application. File types Obsidian handles natively, including Markdown, PDF, images, audio and video, keep their normal behavior. The set of extensions counted as native is edited directly in the plugin's main script, and unsupported files only appear in the explorer when Obsidian's detect-all-file-extensions option is on. It is desktop only, since opening a file goes through the Electron shell.
