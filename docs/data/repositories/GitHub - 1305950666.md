# nyonyataro/obsidian-mood-journal

Mood Journal records a required five-level mood, optional activities and an optional Markdown note into the ordinary Obsidian daily note, on desktop and mobile, storing everything locally. Entries are written as a callout under a journal heading carrying a root journal tag and up to two levels of nested activity tags, with identifier and score kept in HTML comments; an entry without a selected mood cannot be saved, and a past or future date and time can be chosen. It follows the Daily notes settings or its own folder, date-format and template settings, and renders only the core title, date and time template variables rather than executing Templater. The README records that changing the display language affects only later entries, that existing Markdown is never migrated, and that the plugin makes no network requests and carries no telemetry.
