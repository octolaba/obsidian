# carlstedt1/open-in-ide

Obsidian plugin that opens the active file in an IDE, covering every file type in the vault including Markdown, .base and .canvas files. Cursor is the supported editor: the plugin can reuse an existing Cursor window or open a new one, optionally focus a configured .code-workspace first, and jump to the active file and its cursor position. The README records desktop-only operation, a Cursor CLI that must be on PATH or configured by path in settings, and testing on macOS alone.
