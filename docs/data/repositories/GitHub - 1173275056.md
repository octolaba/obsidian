# TracingOrigins/obsidian-music-player-plugin

This repository holds Music Player, an Obsidian sidebar plugin for playing local music files from the vault. The README describes it as combining local library management, lyrics display, playlists and favourites, and playback mode controls, and lists MP3, WAV, OGG, M4A, FLAC and AAC as the supported formats. Playback controls cover play and pause, previous and next track, a progress bar with current and total duration, speed between 0.5x and 2.0x, stepped volume levels, and a queue view for switching tracks quickly.
