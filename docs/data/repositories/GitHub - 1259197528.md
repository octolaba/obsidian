# liicos/obsidian-material-icon

Replaces Obsidian's default file explorer icons with icons from the VS Code Material Icon Theme, matched by file extension and by filename. Extension matching takes the longest suffix, filename rules cover cases such as .gitignore, Makefile and docker-compose.yml, folders get separate closed and open icons, and file and folder icons are toggled independently. Custom rules override the default matching per extension through a searchable picker over more than 500 icons, the settings interface is offered in ten languages, and the icons follow Obsidian's light and dark themes. The README is bilingual English and Chinese and notes that the plugin id changed, so an older install folder should be removed.
