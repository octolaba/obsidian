# Gubchik123/obsidian-movie-search-plugin

Movie Search is an Obsidian plugin for creating movie notes: a ribbon icon or the Create new movie note command opens a keyword search, and choosing a result writes the movie's information into a new note. Settings control the folder the file is created in, its file name format, the template file used, and which search services are queried. The README describes integration with Dataview for rendering the resulting notes and with Templater, and inline scripts inside templates as an advanced option.
