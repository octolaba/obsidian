# enchantedcoloring/obsidian

enchantedcoloring/obsidian holds Enchanted, which its README describes as a colour scheme for note-taking built on pink, marine, mint, yellow, purple and rose. Its stated purpose is to aid remembering and learning by pointing out parts and passages the way one highlights in a book, so that structure can be recovered later when the notes make less sense than when they were written. The README calls the project work in progress, aimed at descriptive note-taking, and argues that notes should look visually distinct from browser and code windows.
