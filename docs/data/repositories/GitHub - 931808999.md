# double-tilde/old-world-obsidian

Old World is an Obsidian theme created by double tilde and based on the Old World theme for Neovim by dgox16, designed as a relaxed color palette that is easy on the eyes. The README shows the palette and names Karla as the main font and Geist Mono as the mono font, noting that both are free and can be found online.
