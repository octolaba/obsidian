# seth10/beautiful-obsidian-contacts

The Contact Cards plugin renders contact cards from note properties or a contact code block in both Reading view and Live Preview. Recognized fields can include names, birthdays, phones, emails, social accounts, addresses, and employment data, with tappable links and support for repeated values.
