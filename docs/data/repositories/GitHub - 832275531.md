# revolter/obsidian-share-via-notepad-tab-plugin

This plugin shares Obsidian notes through the Notepad Tab service. Two commands are provided in the command palette: one shares the current note, and one shares the current selection, for which the note has to be in editing mode. The README's remaining sections cover contributor setup, local development with Node dependencies and a dev script, and the release and submission steps for the plugin itself.
