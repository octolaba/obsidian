# charliecm/obsidian-open-with-nldates

This plugin adds a command that opens a daily note named in natural language, so that a date can be described rather than looked up. It requires the Natural Language Dates plugin to be enabled, and the README credits that plugin as the inspiration for this one. The stated motivation was reaching a past or future daily note without a calendar and without remembering the exact file name.
