# harmtemolder/obsidian-ink

Ink is described as a monochrome colour scheme for Obsidian, optimized for e-ink or e-paper screens. Its README states that no dark theme is included because that would not make sense on e-ink, and documents installation from the community themes browser under the appearance settings. It also records the development route, compiling theme.scss into theme.css with a Sass implementation, and a release workflow that builds when a version tag is pushed.
