# ghyatt/bases-collapsing-group-table

Collapsing Group Table adds Bases Table and Card views to Obsidian that turn grouped results into a collapsible tree, folding and unfolding groups while notes stay editable inline. Groups come from the Bases `Group by` configuration or from additional columns set in the Bases dialog, and an optional nested mode splits a single slash-delimited property into several levels of hierarchy. The README records property badges on cards, an accordion behaviour, and Obsidian 1.10.2 or newer with the Bases core plugin as the requirement; it also states the views only try to be drop-in replacements, since Bases exposes no extendible table object and parts had to be written from scratch.
