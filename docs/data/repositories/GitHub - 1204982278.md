# villyoshioka/Wrot

A micro-journaling plugin whose entries are written straight into the vault's daily notes, so Obsidian's search, linking and review features work over them unchanged. Its name contracts write and jot, and the README frames it as a private space for quick thoughts, vents and memos rather than a social feed with an algorithm. A post editor with a formatting toolbar covers lists, links and quotes, a timeline view shows earlier entries, and memos can be pinned to the top of the timeline regardless of date. Tags typed inside a memo behave like ordinary tags in the graph view and in tag searches.
