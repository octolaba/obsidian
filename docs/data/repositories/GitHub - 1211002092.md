# Snifer/opse-oracle-ttrpg

Obsidian plugin that implements the One Page Solo Engine, a system for playing tabletop roleplaying games without a game master, inside the vault. It automates the yes/no and how-much oracles with their modifiers, the oracle focuses, GM moves and random events, and it generates plot hooks, NPCs, plot twists and weather. A scene engine rolls complications and alterations, while dungeon and hexcrawl trackers hold exploration state across Obsidian sessions. A sidebar control panel carries those tabs beside a filterable, pinnable history whose entries can be re-rolled or withdrawn, and a session can be exported to Markdown or JSON.
