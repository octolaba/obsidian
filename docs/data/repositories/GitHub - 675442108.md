# sneakyfoxes/obsidian-safe-filename-linter

This plugin lints filenames for characters that are invalid or troublesome, such as pipes, colons and brackets, covering both characters that cause problems for Obsidian itself and characters that are invalid in Android filenames. Two commands are added, one linting the current filename and one linting every filename in the vault, and they rename files by replacing the offending characters with replacements chosen in the settings. Renaming goes through Obsidian's own rename calls, so the vault's setting for updating internal links, prompted or automatic, is followed. The README states that automatic invocation is not yet available and warns that a large vault with many renames will take time.
