# thomasbrezinski/obsidian-nested-daily-todos

Nested Daily Todos is an Obsidian plugin that scans previous daily notes for incomplete todos and adds them to today's daily note. The number of previous days to check is configurable, todos can be grouped under their headers, nested todos are carried forward whole with their children, and where a top-level item appears in several notes the version with the more recent children wins. Alternative checkbox styles used by themes such as Things are supported, and which states count as complete is configurable. The carry-forward runs from a ribbon icon or from the command Add previous incomplete todos.
