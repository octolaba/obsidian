# pblazh/tabula-obsidian

This plugin runs Tabula, a spreadsheet-inspired CSV transformation tool, over the active Markdown file: a csv block holds the data, a tabula block holds the script, and saving the file applies the transformation in place. The README states that the Tabula CLI has to be installed separately and that automatic execution on save can be switched off. Three commands are recorded — execute Tabula on the active file, toggle execution on save, and toggle the visibility of column and row names in csv blocks — and the script syntax supports an include directive.
