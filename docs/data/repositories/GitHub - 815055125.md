# AmmarCodes/obsidian-quran-helper-plugin

Quran Helper searches for Quran ayahs and surahs and inserts them into Obsidian notes. The README records fuzzy search by Arabic ayah text, surah name or numeric reference; insertion as a blockquote, a callout or inline text; commands for a single ayah, a full surah or a page by number between 1 and 604; and creation of a standalone note for an ayah linked into the vault. The output format and callout type are configurable, the modifier key with Enter inserts inline without changing the default format, and the README states that the plugin is offline-first and works without an internet connection.
