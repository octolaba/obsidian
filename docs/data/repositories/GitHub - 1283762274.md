# 2JIHAN/bracket-to-checkbox

This plugin turns an opening and closing square bracket followed by a space, typed at the start of a line, into a Markdown checkbox prefix. The README compares it to Notion's shortcut and states that it works inside an existing bullet, keeping the marker, and at any indent level, while the same characters in the middle of a line are left alone. It is plain JavaScript with no build step, and the repository carries no description, so this summary rests on the README alone.
