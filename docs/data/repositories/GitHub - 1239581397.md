# aohan237/obsidian-local-audio-plus

A desktop Obsidian plugin that transcribes local audio files linked from notes and inserts the transcript. Transcription starts from the audio link button, its context menu, the ribbon or the command palette; automatic processing on opening, saving or modifying a note is recorded as off by default. The supported providers are OpenAI audio transcriptions, Tencent Cloud recording-file recognition, whose local base64 upload limits the file to 5 MB, and iFlytek recording-file transcription with its own APPID, key and secret, and a shared speaker-diarization setting is mapped onto each. The README's disclosure states that the selected audio is sent to the configured provider, optionally through an HTTP, HTTPS or SOCKS5 proxy, that credentials live in the plugin's data inside the vault, and that there is no telemetry, advertising or analytics.
