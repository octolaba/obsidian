# Xmoncoco/my_anime_list_text_exporter

My Anime List text exporter is an Obsidian plugin that creates a note for an anime from MyAnimeList data, retrieved through Jikan. The command Create note for anime generates a page carrying tags derived from the data, a synopsis and a link to the anime's page, with settings for the target path, the tags to add, a custom template and a checklist option. It can also create a folder named after the anime holding one page per character, with a modal for selecting which characters to add, and animes can be collected into a checklist.
