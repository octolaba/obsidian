# shmolf/obsidian-editor-background

Obsidian plugin that draws a background image behind the editor view. Only remote assets are supported, so the image has to be hosted by the user, and a second URL can be given for use while the dark theme is active. Settings cover opacity, blur, a translucent contrast backdrop behind the text, image position, scaling between fill, fit, stretch and actual size, whether one image sits behind the entire window instead of a copy per pane, and folders or notes excluded from the background. The README's author describes using animated images as the background.
