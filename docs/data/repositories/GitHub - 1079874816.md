# YoFujii0705/japanese-manuscript-counter

Japanese Manuscript Counter is an Obsidian plugin that counts Japanese characters and converts the total into 400-character manuscript pages in real time. The README describes a status bar readout of the character and page count, a count restricted to the current selection when text is selected, and a command palette entry that shows detailed count information in a modal. Counting follows manuscript paper rules, treating full-width characters as one and half-width characters as one half while accounting for line breaks, paragraphs and Japanese line-breaking rules. The author states that accuracy is used at the reader's own risk and that unusual characters and symbols may be handled differently than expected.
