# kgdrathan/donedrop

DoneDrop moves completed tasks to the bottom of their list at their own indentation level, and handles nested sub-tasks recursively. The README states it works in both Live Preview and Reading Mode, and its architecture diagram describes editor-change, markdown post-process and file-modify events routed through one sorting path that applies changes through the Editor API when the file is open in source mode and through the Vault API otherwise.
