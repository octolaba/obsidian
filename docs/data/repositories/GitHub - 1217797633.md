# taskcore-dev/PrimeTask_For_Obsidian

This plugin connects the PrimeTask desktop app to Obsidian and needs that app running on the same macOS or Windows machine. Its main flow is capture from a note: selected text can be sent to PrimeTask and replaced by a link to a new task note, or sent to the PrimeTask inbox alone leaving the note untouched, and an existing note can be converted into a task or a project with its first heading as the title and its body as the description. Each promoted task is its own Markdown file with status, priority, due date and progress in frontmatter plus a recorded origin pointing back at the note it came from, so tasks can be queried with Bases or Dataview. A sidebar lists tasks and projects with inline edits and filters, and status, priority, due date, progress, description and the done state round-trip between the note and the app.
