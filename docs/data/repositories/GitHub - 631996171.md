# erincayaz/obsidian-colored-text

Colored Text adds colored text to Obsidian notes through a set of color slots shown in the status bar, five by default and adjustable between one and twenty in the settings. Slots are switched by hotkey or by clicking them, and the current slot's color is changed from a color input menu that offers a favorites list, which defaults to the most used colors and is configurable, or an arbitrary color from a palette. The selected text takes the current slot's color, or has its color removed, by hotkey or from the right-click menu, and a highlight mode is toggled from a status bar icon or a hotkey. Five commands are exposed for coloring, uncoloring, cycling slots forward and backward, and opening the input menu.
