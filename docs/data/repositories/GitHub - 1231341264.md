# pochihh/obsidian-better-edit

The repository records no description, so this note is grounded in the README alone. Better Edit adds a visual editing layer to Obsidian's Live Preview for arranging images, moving blocks, inserting reusable structures, styling inline text and adding symbols, while writing everything back as visible Markdown and HTML with inline styles. Image work covers pasting or dropping, resizing, aligning, cropping, captions and alt text, replacing the source and grouping related images into side-by-side rows, and blocks can be reshaped by dragging instead of cutting and pasting source text. The README's stated aim is that notes stay readable in Source mode, Git diffs, exports and in Obsidian without the plugin installed.
