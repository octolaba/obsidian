# chiubaca/obsidian-exif-editor

Obsidian EXIF Editor edits the EXIF metadata of images from inside Obsidian, covering fields such as description, artist, copyright, date taken, software, lens model and user comment. The README also lists a map view for GPS data and a raw JSON editor for the underlying EXIF record, and credits piexifjs for the EXIF handling.
