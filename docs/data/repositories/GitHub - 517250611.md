# vertis/obsidian-image-layouts

The repository holds Obsidian Image Layouts, a plugin for arranging several images together inside a note. Its README records a family of code block languages, one per layout, among them masonry variants, and states that images may be given as wikilink embeds with an optional caption and size. The author describes it as a first attempt aimed at visually telling stories in image-heavy notes, still rough because it is new, and points at external documentation for the layouts not shown in the README.
