# zzigo/obsidian-waveanalyzer

Previews audio files inside notes as interactive waveforms and spectrograms. An audio file is embedded through a `wa` code block and the analyzer renders in reading view, offering play and stop, a draggable playhead, loop-region selection by shift-dragging in waveform mode, six FFT sizes for spectrum resolution and a timeline ruler marked in seconds and ten-second steps. Optional overlays draw the spectral-centroid and harmonicity descriptors, and the README lists further descriptors such as spectral flux, spectral rolloff, zero-crossing rate, RMS energy and spectral flatness as not yet implemented.
