# mgmeyers/obsidian-smart-typography

Obsidian plugin that substitutes typographic characters as text is typed. Straight double and single quotes become curly quotes, three periods become an ellipsis, dash sequences step through en dash, em dash and three dashes, an arrow and a guillemet replace their ASCII spellings, simple fractions become their single-character forms, and two comparison operators become the greater-or-equal and not-equal signs. The quote and arrow substitutions are customisable, and any automatic change can be undone by pressing backspace. The README asks for issues describing the typographic conventions of other languages so that support can be widened.
