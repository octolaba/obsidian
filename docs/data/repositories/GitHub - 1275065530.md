# MrDanRave/Intervaults

Intervaults renders several Obsidian vaults as one interactive graph in which each configured vault folder is a line and every note present in two or more vaults becomes an intersection dot where those lines cross. The layout settles through a force-directed physics simulation, lines sharing many notes braid through one another, and the canvas can be dragged, zoomed and panned; clicking a line opens that vault, and clicking an intersection opens the note or, where versions differ, the diff view. That editor shows the versions side by side with per-line colouring, per-hunk and whole-column copy buttons, editable cells and independent saving of each side. A query language of Meet, Merged and Diff functions decides which intersections are drawn and how they are coloured, and the README states the plugin is desktop only because it reads files directly from disk.
