# johansan/notebook-navigator

Obsidian plugin that replaces the default file explorer with a two-pane interface combining a folder tree, tag browsing, properties, shortcuts and file previews in one view. Its recorded features include full keyboard navigation, drag-and-drop, pinned notes, customisable display options and a mobile-optimised layout, and the README states that it works with vaults of more than 100,000 notes. It notes that the Style Settings plugin can be installed to customise colours and appearance, that switching guides exist for people arriving from other note applications, and that the project is checked with TypeScript, ESLint with the official Obsidian ESLint plugin, and Prettier.
