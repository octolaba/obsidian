# johansan/notebook-navigator

Notebook Navigator replaces Obsidian's default file explorer with a customizable notes browser that combines folder and tag navigation, properties, previews, and shortcuts. It provides a two-pane layout, keyboard navigation, drag-and-drop, pinned notes, mobile optimization, and support for vaults containing more than 100,000 notes.
