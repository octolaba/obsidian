# jiezhengj/NotePipe

NotePipe copies selected text together with its file path and line number, so the result can be pasted straight into a terminal-based agent session. The copied output uses Markdown blockquote formatting, which the README explains keeps the quoted reference distinguishable from the question that follows it, and template variables and a path mode control the exact format. The README gives the motivation as command-line agent tools lacking the side-panel selection flow of desktop ones, and records that no default hotkey is assigned. Its README is bilingual English and Chinese.
