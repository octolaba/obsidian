# ckep1/obsidian-mobile-sidebar-notes

Mobile Sidebar Notes adds commands for opening notes and empty tabs in the left or right sidebar of the Obsidian mobile app, functionality the README notes is already built in on desktop. Configured commands carry a display name, a note path with autocomplete and a chosen side, while further commands move the active tab into a sidebar or back to the main area keeping its scroll position, move core views such as Files or Search between sidebars, open the daily note in a sidebar, and close or deduplicate repeated sidebar tabs. Invalid or missing note paths are flagged and those commands are not registered.
