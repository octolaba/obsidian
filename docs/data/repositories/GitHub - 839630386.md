# abcamus/obsidian-quick-card

This plugin shows the files of a directory as cards, each carrying the note title, its creation date and a brief summary. Clicking a card opens the associated note, a plus button at the bottom of the card view creates a new one, and the view switches directory automatically as different files are opened in the editing area. The card view is opened with the Quick Cards show card view command or by right-clicking a folder and choosing cardify, and the README states that the appearance of the cards is customized by editing the plugin's style sheet.
