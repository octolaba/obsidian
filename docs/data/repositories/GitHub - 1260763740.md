# ibrh96-prog/obsidian-ai-journal-coach

Obsidian plugin that analyses journal notes with a language model and saves the result back into the vault. Four analysis types are offered: a weekly reflection covering key themes, emotional landscape, wins, challenges and a question to sit with; pattern detection over recurring themes and behaviour; a mood tracker of tone, shifts, triggers and energy; and growth insights. The provider is chosen in settings from Anthropic, OpenAI, OpenRouter or any OpenAI-compatible endpoint, and a journal folder can be set or left empty to search the whole vault. The README describes a free tier of ten analyses as a one-time lifetime allowance held per vault in local plugin data, where a failed analysis is refunded rather than consumed.
