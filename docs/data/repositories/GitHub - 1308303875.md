# justinzzc/obsidian-ssh-terminal

Obsidian SSH Terminal renders fenced ssh code blocks as interactive terminals in Reading view and Live Preview, turning a note into a runnable runbook. A block either carries the connection fields inline, host, port, username, password and height, or names a profile defined in settings; the two forms cannot be mixed. Inline passwords sit as plaintext in the Markdown and travel with the note, while profile passwords are encrypted through Electron safeStorage, and the plugin refuses to save one if the operating system offers no encryption. Sessions never start on render and begin only when Connect is clicked, host keys are confirmed on first use and a later mismatch blocks the connection; the first release is desktop-only and password-only, with no SFTP, port forwarding, jump hosts or key support.
