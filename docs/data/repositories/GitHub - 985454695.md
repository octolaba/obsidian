# LucEast/obsidian-current-view

Current View sets the view mode of a note — Reading, Live Preview or Source — automatically when it is opened. Rules match on folder path, on file patterns given as regular expressions, on tags, or on a frontmatter field for a single note, and the README records the order in which they are checked, with frontmatter overriding the pattern rules. A file or folder can also be locked to a mode from its context menu in the File Explorer or in Notebook Navigator, with an icon badge marking which mode is locked.
