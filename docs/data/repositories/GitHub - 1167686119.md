# andrewbowley/interstitial-journal

Interstitial Journal adds commands that insert timestamped entries into daily notes for interstitial journalling. One command inserts a timestamped entry and leaves the cursor ready to type; the other inserts a timestamped entry followed by a wiki link, with the cursor placed inside the brackets for a page name. Both commands read the current line, writing on an empty line, appending after a bare list marker without doubling it, or starting a new line below existing content while preserving indentation. Settings cover the time and date formats as Moment.js strings, normal or bold time styling, the divider character and whether entries are bullet list items or plain text.
