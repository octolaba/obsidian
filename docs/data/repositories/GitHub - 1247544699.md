# ssurfthekaliyuga/obsidian-toggle-excluded-folders

Toggle Excluded Folders switches Obsidian's built-in excluded files list on and off from a ribbon icon or a command, rather than keeping a list of its own. One click stashes the whole native list into plugin storage and clears it so everything becomes visible; clicking again restores it, merging in any entries added while the filters were off. All filter kinds the native setting supports are covered, including folder paths, individual files and regular expressions, and the search and graph views are refreshed after a toggle. The README states that the stash is restored into the native list when the plugin is disabled or uninstalled, and that the plugin reads and writes that list through configuration methods outside the public plugin API, isolated in two files, disabling itself with a notice if those methods disappear.
