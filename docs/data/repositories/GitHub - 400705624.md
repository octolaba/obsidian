# joeyuping/quick_latex_obsidian

Quick Latex shortens LaTeX writing in Obsidian with shorthands and automatic formatting: Greek letters typed without dollar signs are converted into inline math, an expression after a superscript or subscript symbol is enclosed in braces when space is pressed, and align and cases blocks gain continuation and alignment symbols as lines are entered. The README records configurable behaviour for several of these, including whether Enter or Shift-Enter starts the next line inside an align or cases block, whether Tab or space expands a custom shorthand, and which user-defined symbols receive an alignment marker. It opens by stating that the plugin is no longer maintained and recommending Latex Suite instead.
