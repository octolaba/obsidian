# adiron/obsidian-strip-internal-links

Strip Internal Links removes Obsidian's internal links from text, leaving external links intact. Its commands work over the entire file or over the selection, and each has an in-place variant that replaces the content and a to-clipboard variant that copies the stripped result instead. The README gives its motivation: sending the contents of a note to someone for whom the internal links carry no meaning.
