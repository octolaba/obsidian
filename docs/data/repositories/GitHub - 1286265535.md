# williansaez/code-ref-vault

Code File Embed renders the current contents of a vault file as a syntax-highlighted code block instead of code copy-pasted into a fenced block. A `codefile` block points at a path, optionally with a 1-based inclusive line range or a single line, and paths resolve like Obsidian links relative to the current note. Highlighting reuses Obsidian's own renderer together with its theme and copy button, the block re-renders when the target file is saved or renamed, and settings configure the extension-to-language map, a maximum file size and an optional clickable header showing the path.
