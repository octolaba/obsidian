# arangutambo/finance-tracker

Finance Tracker records spending as tags inside daily notes and builds budgets, goals, forecasts and dashboards from them, keeping the Markdown notes as the only source of truth with no database, no sync and no network requests. A checkbox line tagged for spending carries the amount, with nested lines splitting it across category tags such as food or restaurants, and everything else is derived from that format. A setup wizard asks where daily notes live, where finance notes should go, the currency and the recurring payments note name, then creates starter notes for budgets, a dashboard, recurring payments and goals. The README describes further features built on the tag language: trips, splits, runway, net worth, a query block, quarter and year reviews, a daily budget sidebar and a merchant map, on desktop and mobile from Obsidian 1.0.
