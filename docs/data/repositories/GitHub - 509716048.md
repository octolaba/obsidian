# jerrywcy/obsidian-path-finder

The repository holds Obsidian Path Finder, a plugin that finds paths between two notes in a vault. Its README records the shortest-path feature, where a start and an end file are given as full paths from the vault root. Three installation routes are documented — the community directory, a beta installer plugin, and a release archive unpacked into the vault's plugin folder — and the code is licensed under the GNU AGPL version 3.
