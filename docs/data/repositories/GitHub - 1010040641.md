# jdenoy/obsidian-smart-tagger

Repository for Smart Tagger, a plugin that asks an AI provider to generate two to five tags for a note. The README records support for OpenAI and Claude, matching of generated tags against tags already in the vault with the vault's casing kept, batch processing of the whole vault, a preview step for reviewing and selecting tags before they are applied, configurable prompts and tag limits, a requests-per-minute limit, retry with exponential backoff, and an English and French interface.
