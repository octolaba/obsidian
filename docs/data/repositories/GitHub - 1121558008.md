# JamieStudio-lab/obsidian-gentlepomodoro

A Pomodoro timer that shows an ambient gradient or frosted-glass visual instead of a ticking clock, with configurable focus, short break and long break durations, overtime tracking and an estimated finishing time. Tasks are picked from the vault in Tasks plugin format and filtered by overdue, today, tomorrow and a configurable lookahead window; an opt-in beta counter writes a session count onto the task line before its date fields, with check, repair and remove recovery actions that confirm exact counts first. A daily focus target is reported in the status bar and reset at local midnight, and each day gets one markdown log file with an inline-field line per session for Dataview. The README marks the release as beta and notes that animations soften when the system requests reduced motion.
