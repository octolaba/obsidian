# getmatterapp/obsidian-matter

The Matter Obsidian plugin syncs highlights and notes from the Matter application into an Obsidian vault. The README describes connecting the plugin to a Matter account by scanning, from the Matter mobile app's connected-accounts screen, a code shown in the plugin's settings page, after which syncing runs automatically in the background. Addresses for questions and feedback are listed at the end.
