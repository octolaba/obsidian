# Benature/obsidian-underline

Obsidian plugin that wraps the selection in an underline tag from a keyboard shortcut, inserting an empty pair when nothing is selected and removing the tags again when underlined text is selected. Further shortcuts wrap a selection as centred text, as a heading link or as a block link. For other custom prefixes and suffixes the README points at the same author's Text Format plugin and its wrapper feature.
