# BogdanCodreanu/obsidian-moc-link-helper

MOC Link Helper works on the two-way link between a Map of Content note and its child notes, where the MOC includes the children in its content and each child carries an up property naming the MOC. A view opened from a command or ribbon button lists the notes included in the selected MOC and can add the link to this MOC to their up property or remove it from all of them, with a warning for included notes that lack the up-link; filters restrict the operation to all notes, non-MOC notes or MOC notes only, and selecting text in the MOC narrows it to the selected notes. A second view lists notes that have an up-link to this MOC but are not included in it, and can insert them as links at the cursor. The README records that the plugin requires Dataview and is desktop only.
