# AUL-DoX/ok-standby-jukebox

Desktop-only Obsidian plugin that organises music source links, audio, video, image and archive material into song notes. A single import command reads the source folder it creates on first run, takes URLs out of text and shortcut files, extracts supported files from zip archives, moves audio, video and image assets into a songs folder, and writes Markdown song notes carrying title, genre, status, creation date and source links. Existing notes are updated without overwriting unrelated content, common asset suffixes such as preview, cover or thumbnail are grouped, and the import runs from the left ribbon, the command palette or an optional auto-watch mode.
