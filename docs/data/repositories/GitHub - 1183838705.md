# sprice/stratum-obsidian

Stratum creates literature notes in Obsidian from a Zotero library, searching that library from inside the app and generating notes with readable filenames, aliases and frontmatter. The README states that a Stratum account and internet access are required, because sign-in, Zotero authentication, sync and enrichment all run through the project's own service, and that the plugin imports from the desktop Zotero app when it is open and through that service otherwise. It records personal and group library sync, import of notes and annotations with highlights grouped by colour and deep links back to Zotero, rewriting only its own managed section so that writing below the boundary callout survives, marking a note deleted rather than removing the file when the source item disappears, pandoc citation insertion with a managed bib file, and enrichment from OpenAlex.
