# GoBeromsu/open-connections

Obsidian plugin that surfaces semantically related notes using embeddings, computed locally by default or through a configured provider. A connections view updates as files are opened, and a semantic lookup searches the vault by meaning rather than by keyword. Local embedding runs Transformers in the browser with WebGPU acceleration and a WASM fallback, while OpenAI, Gemini, Ollama, LM Studio, Upstage and OpenRouter are the supported alternatives, with embeddings cached in SQLite and recomputed when the model changes. The README records mobile support on iOS and Android and states that notes do not leave the device when local embeddings are used.
