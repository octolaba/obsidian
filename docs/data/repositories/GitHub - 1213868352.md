# tcatlas/obsidian-notes-calendar

Notes Calendar shows a calendar in the side pane and lists the notes associated with the selected date. Clicking a day lists the notes created on it and clicking a week number lists that week's notes, with optional week numbers, a configurable first day, note indicators, creation times and excerpts, and configurable sorting. The README states that notes are grouped by file creation time rather than by filename or frontmatter date, and that double-clicking a date can create a daily note through the core Daily Notes plugin for templating.
