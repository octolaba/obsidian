# ZzPoLariszZ/obsidian-snowflake-method

This plugin turns Randy Ingermanson's Snowflake Method into a fiction planning workspace inside Obsidian, carrying a story from a one-sentence summary through ten revisable steps to a scene-level plan. A guided dashboard navigates the steps without blocking validation, while summaries, characters, scenes, worldbuilding entries and drafts are kept as ordinary notes that stay readable with the plugin disabled. A manuscript stream reads and edits the whole draft as one continuous page while each chapter remains its own note, with typewriter scrolling and a four-level focus mode for writing. Interface and project language can be set to English or Simplified Chinese independently, reminders flag when upstream material changes without blocking, and repair tools restore missing managed files without overwriting prose.
