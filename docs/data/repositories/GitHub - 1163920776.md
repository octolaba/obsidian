# tiemio/Image-Metadata-Stripper

Image Metadata Stripper removes privacy-sensitive metadata from images and PDFs in an Obsidian vault. Stripping runs automatically as files enter the vault, and can also be triggered per file from the right-click context menu or over all existing vault files at once. The README lists what is removed per format: EXIF, IPTC, XMP and comment data from JPEG, text chunks and EXIF from PNG, EXIF and XMP from WebP, and the info dictionary and XMP packets from PDF. Per-format toggles and an option to preserve ICC colour profiles are exposed in settings.
