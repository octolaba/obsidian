# jiahuacaogoodman-art/guozha

The repository holds Guozha AI Pro, an Obsidian plugin combining an AI chat panel with WebDAV synchronisation. The README records a side-panel chat against OpenAI-compatible providers with streaming replies, image attachments for multimodal input, image generation saved into the vault and previewed in the conversation, controls for provider, model, temperature and output length, and a file assistant that reads, creates, edits and organises vault files after permission checks. Synchronisation is recorded as bidirectional WebDAV sync through Nutstore with incremental updates, conflict handling, filters, large-file skipping, logs and cache management. The README states the plugin connects to the network only for the features that need it, includes no analytics or telemetry, is licensed under AGPL-3.0, and derives its sync foundation from an existing Nutstore sync project.
