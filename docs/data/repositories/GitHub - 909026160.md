# MalcolmMielle/Emerald-Echo

Emerald Echo is a green Obsidian theme that its README records as inspired by the Green Nightmare theme and by the author's own OneDarkPro Retro green theme for Visual Studio Code. The repository is stated to be a read-only mirror of a Codeberg repository, where contributions should be submitted instead. Its stated objectives are clear colour differences between bold, italics, highlight and internal and external links, high contrast without neon apart from the first heading level, heading levels distinguishable by colour and underline style, dark and light themes, mobile friendliness and a terminal green look.
