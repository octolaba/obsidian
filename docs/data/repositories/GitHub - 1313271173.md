# kpieper876/Export-Selection-to-Word-RTF

Exports the current Markdown selection, or the whole active note when nothing is selected, to a Rich Text Format file that Word and other RTF editors can open. Headings, bold, italics, underline, strikethrough, inline code, lists and tables are carried over, and Markdown links, wikilinks and visible URLs can optionally be stripped. A dialog collects the export options; the file is written next to the source note by default or into a vault-relative folder, and exporting again overwrites the same path. It is desktop-only because it writes the file through Obsidian's adapter, and complex Markdown extensions and embedded media are not reproduced as native Word objects.
