# Deltekk/Obsidian-Latex-Matrices

Latex Matrices is described as a plugin for creating LaTeX matrices in Obsidian. Its README says a command opens a window in which the width, height and bracket type are entered, generating a grid of input cells that is then written out as a formatted matrix; all bracket types are supported and fractions, subscripts and superscripts can be written inside a cell. The README warns that the output must be placed between dollar signs by hand, because that is not done automatically.
