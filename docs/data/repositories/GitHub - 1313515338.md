# edwardsayer/obsidian-window-spaces

Saves and restores layouts for Obsidian's popout windows, capturing their splits, tabs, active file, view modes and exact window size and position without touching the main window or its sidebars. Restoring a saved space opens it in a new popout window, or into the current one when Shift is held, and focuses the window already showing that space instead of duplicating it. Layouts can be named automatically from pinned and active notes, updated by a per-layout auto-save that debounces for five seconds and snapshots on window close, and managed from a searchable modal that opens as a popup, an editor tab or a sidebar panel with sorting, renaming and hover file lists. Guardrails keep restored windows on screen when the monitor setup changes and block accidental overwrites with an empty layout.
