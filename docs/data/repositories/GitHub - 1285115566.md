# crx2003/PantryFin

PantryFin manages kitchen inventory and nutrition tracking inside Obsidian, built around a normalized base-unit engine and a reactive twelve-column dashboard. The engine converts natural-language quantities such as kilograms, grams, litres and millilitres into base units of grams, millilitres or counts, so stock additions and recipe deductions are computed on raw values rather than on display formatting. The README describes logging groceries, tracking macro goals and asking an AI nutritionist for a meal plan, with stock operations handled in separate modals.
