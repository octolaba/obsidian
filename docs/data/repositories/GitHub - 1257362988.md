# perinchiang/obsidian-misty-theme

perinchiang/obsidian-misty-theme holds Misty, a warm Obsidian theme in ivory and charcoal tones with light and dark modes, whose palette the README attributes to Claude's colour scheme. It sets Charter or Songti SC for body text and JetBrains Mono for code, with distinct colours for keywords, strings, functions and comments. The README tabulates both palettes, including a #FDFDFC light editor background with a #C66344 accent and a #1B1B1A dark background with a #D97757 accent, and states that the theme was submitted for review in the community themes directory.
