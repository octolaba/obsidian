# fanxin199/obsidian_deepl_translate

DeepL Translate Selection translates the selected text in the Obsidian editor from the right-click context menu or a command palette entry. It detects the direction between Chinese and English and can insert the result below the selection, replace the selection, or copy it to the clipboard. The README describes support for DeepL Free and Pro API keys, with keys of a certain suffix routed to the Free endpoint, and an alternative provider setting for DeepSeek or any OpenAI-compatible endpoint driven by a built-in translation prompt.
