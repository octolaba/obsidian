# rodydavis/obsidian-dynamic-color

rodydavis/obsidian-dynamic-color holds Dynamic Color, a Material Design inspired theme that builds its palette from the accent colour selected in Obsidian, in light and dark mode alike. The README opens with a disclaimer that it is not an official Google project. Installation is either a search for the theme in the community theme browser or a manual copy of its CSS file into the vault followed by a reload.
