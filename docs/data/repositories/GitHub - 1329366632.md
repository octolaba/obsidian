# AshenAshes/homepage-studio

Homepage Studio is a desktop-only home view gathering a writing heatmap, a journal, tasks, time plans, curated file groups and a banner into one pane, with six built-in themes in light and dark. The journal is a single Markdown file split by second-level date headings, tasks sit in a Markdown file with a managed active and archive boundary and include one-time plus daily and weekly items that reset on the local calendar, and file groups hold explicit vault paths. The heatmap counts positive net growth in Markdown files edited in the Obsidian editor, ignoring synchronisation, imports and external edits. It requires Obsidian desktop 1.8.7 or later on Windows, macOS or Linux, does not support mobile in 1.0.0, and makes no external request beyond an optional remote banner URL the user configures.
