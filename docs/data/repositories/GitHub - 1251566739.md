# jabaho9523/DarkKnightTheme

Dark Knight is a Gotham-noir Obsidian theme built on deep blacks with a gold accent, a steel-blue secondary accent and a red reserved for errors and unresolved links. Its palette table names each token and its role, and H1 to H3 carry the gold gradient while H4 to H6 fall back to steel blue and fog so the heading hierarchy stays legible. Light mode is driven by the same palette tokens as dark, and the README lists compatibility with Obsidian 1.4 and later, the default core plugins, and the Dataview and Tasks plugins. Its accessibility notes cover tuned contrast for faint and code-comment text, contrast-aware colours on accent buttons and checkbox markers, and a gold focus ring for keyboard navigation.
