# spslater/obsidian-cursor-location-plugin

Cursor Location displays the cursor's character and line position in the status bar, and the README records the plugin as desktop-only because the mobile applications do not support custom status bar items. Settings control how many cursor positions are shown before the display switches to a count, the separator between them, and how a selection is reported, whether by its beginning, its current end, or the full range with its own separator. The position can instead be shown as a percentage through the document, with wordier modes that split the document into fractions rather than printing numbers, and dropdown settings accept a custom pattern where none of the presets fit.
