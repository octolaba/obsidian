# shu307/obsidian-nav-weight

Nav Weight is an Obsidian plugin that sorts files in the navigation pane by a weight key defined in each file's Markdown frontmatter. Sorting a folder requires an index file inside it whose weight becomes the folder's weight, with the index file name and the index's own fixed weight set in the settings. Sorting runs automatically while the plugin's left ribbon icon is lit, so clicking it disables the behaviour temporarily, and a status bar icon with a tooltip reports the result. The README states that it implements the features of mkdocs-nav-weight, for people publishing the same notes with MkDocs.
