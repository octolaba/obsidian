# sunwookwak-polisci/Hop-Link-Viewer

Hop-Link Viewer walks the vault link graph outward from an anchor note and lists, in a sidebar, the notes reached within a configurable number of hops that are not themselves linked to the anchor. Links count in either direction, each suggestion shows the hop number at which it was found, and direct neighbours can optionally be included with a badge instead of a number. The anchor follows the active file, the last edited file or the last viewed file, and the list can be capped, ordered by walk order, modification time, link count, title or at random, with folder prefixes excluded from display while remaining traversable. It refreshes when the active note, its content or link metadata changes, has no query language, and requires Obsidian 1.13.0 or newer.
