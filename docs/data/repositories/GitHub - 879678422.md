# MichelNivard/Ridian

Ridian runs R code inside Obsidian and renders notes with Quarto, so a note can hold R notebook chunks with their output and be turned into a Quarto document from the editor. Chunk processing is described as Quarto-compliant, so the same notes can be moved to other editors, and the plugin is presented as a way to keep coding and statistics notes with working examples and to add plots and widgets to notes from R snippets. The README states what it is not: a replacement for RStudio or Positron, and not a general multi-language runner, for which it points to another plugin. It requires the paths to the R, pandoc and Quarto executables to be set in the settings, notes that its guess at the R installation will probably fail, and discloses that the plugin executes code through an external interpreter.
