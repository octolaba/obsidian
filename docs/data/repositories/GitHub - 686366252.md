# R-Cramer4/Periodic-Table-Obsidian

This plugin shows the periodic table in the Obsidian sidebar, and clicking an element brings up more information about it. The README credits its element data to the Periodic-Table-JSON project and to the PubChem periodic table, and records nothing further about settings or commands.
