# Handwriting-OCR/handwriting-ocr-obsidian-plugin

An Obsidian plugin for Handwriting OCR, described upstream as turning handwritten documents and scanned images into editable text through that service's handwriting-to-text conversion. The README records extraction from JPG, PNG, GIF, BMP, TIFF, HEIC and WEBP images and from PDFs up to 20MB, reached from a right-click menu on supported files or from command-palette commands that replace a selection, append to it, copy to the clipboard or create a new note. Setup requires an API key entered in the plugin settings, which the plugin validates and reports a remaining credit balance for. The README states the service is paid, consuming one credit per page processed, with trial credits granted on account creation.
