# ElsaTam/obsidian-fancy-a-story

Fancy-a-Story is an Obsidian theme with a separate documentation site, and its README warns that a minimum installer version of 1.6.5 is required, with 1.7.0 or later recommended, explaining how to check and how to correct it. Installation is documented from the community themes list or through BRAT, and the Style Settings plugin is recommended for adjusting the theme. Recorded features include dark and light mode, Style Settings options, alternative and handwritten checkboxes and list bullets, and a wide set of callout styles named after things such as an autopsy report, a cards deck, a clue, a comic, a conversation, an email, an infobox, a film strip, a letter and a paper fold.
