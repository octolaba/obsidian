# Ganzosupremo/drum-notation-plugin

This plugin renders drum grooves written in a drums code block as responsive SVG notation, with percussion clef, time signature, upper and lower voices on a shared timeline and beat-aware beams. Grooves are written as positions, one line per instrument with beat numbers, subdivision letters and presets such as eighths or sixteenths, plus compact marks for accents, ghost notes, open hi-hat, flams, drags, rolls and rim techniques, with measures separated by bars. A token grid is the alternative, spelling out every subdivision one token per cell at eight, sixteen or triplet resolution, with repeats written as a percent sign or a count. Directives inside the block set style, count labels, the instrument legend, swing feel, beam grouping and staff positions, and diagnostics appear in the rendered block.
