# LiuYangArt/obsidian-canvas-banana

This repository holds Canvas Banana, an Obsidian plugin formerly named Obsidian Canvas AI that brings model-driven assistance to both Canvas and ordinary notes. On a canvas it uses the selected node as context for chat, generates images at configurable aspect ratios and resolutions, and can answer as generated nodes; several requests may run at once and prompt presets can be saved and recalled. In notes it adds a sidebar assistant for chat, edit suggestions reviewed as a diff before they apply, and in-document image generation, plus a floating editor for polishing, translating or rewriting selected text. The README names Gemini, OpenAI, OpenRouter and Antigravity among the supported providers with a custom base URL, and is written in Chinese and English.
