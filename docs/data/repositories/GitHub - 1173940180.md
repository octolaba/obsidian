# SattaRIP/obsidian-khattat

Annotate embeds handwriting sections between paragraphs of ordinary Markdown notes, drawn with fountain pen, calligraphy nib, marker and pencil tools. Drawing offers draw, erase and pan modes with zoom, adjustable stroke stabilization, colour, size and nib angle controls, optional ruled guide lines, undo and redo, and stylus pressure and twist detection; strokes are saved automatically to JSON data files. Handwriting can be converted to text through MyScript or Google Cloud Vision, each requiring its own API key, with the recognized text reviewed in a modal before being inserted at the cursor position.
