# cwh555/AnimeList

AnimeList is a local-first Obsidian library for anime, manga, and novels that keeps Markdown notes as the source of truth. It provides metadata search, card, list, and poster views, company, quarter, and reusable tag filters, progress and dated serial entries, ratings, local covers, a Score Dashboard, and a pannable completion timeline on desktop and mobile; a legacy cleanup command upgrades recognized metadata without rewriting unrelated content.
