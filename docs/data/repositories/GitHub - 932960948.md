# markahesketh/write-good-obsidian

Write Good integrates the write-good prose linter into Obsidian to mark common writing issues in a note. The checks it lists are passive voice, lexical illusions in the form of repeated words, sentences starting with So or with There is or There are, weasel words such as many, various and very, adverbs ending in -ly, wordy phrases, cliches, and to-be verbs flagged for E-Prime style. Checking can be toggled per note from the command palette or a hotkey, and settings control whether new or opened notes are checked automatically and which individual checks are active.
