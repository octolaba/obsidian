# kwhittle/obsidian-github-tools

Puts a GitHub repository panel in the sidebar for a local clone: the current branch with a switcher, uncommitted changes as an expandable file list, how many commits the clone is behind with a pull button, and a ribbon badge that turns red when it is behind. Clicking a changed file opens it and briefly highlights the changed lines, a dot marks modified files and every parent folder in the file explorer, merge conflicts can be resolved per file or aborted, and stashes can be applied or dropped. Fetch, pull, push and branch creation run from an action bar, a commit modal stages files by checkbox before committing or pushing, and a dashboard separates authored, awaiting-review and all open pull requests with a guided creation workflow. The README records the plugin as desktop only, needing git and a local clone plus a classic token with repo scope.
