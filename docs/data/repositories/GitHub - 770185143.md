# jemstelos/obsidian-ayanite

Ayanite is an AI chat plugin for Obsidian offering a multi-tab chat interface, a copilot chat in the side panel, saved and reusable prompt snippets, clipping of text selections to summarize or explain, diagram generation from concepts, and custom chat profiles. Chats, prompts and profiles are stored as local Markdown files, which the README ties to Obsidian's file-over-app philosophy so they can be searched and organized like any other note. Several providers are supported, including OpenAI and a local Ollama, while the README's roadmap lists Gemini and Anthropic models, text-to-speech input and chatting with notes as not yet present.
