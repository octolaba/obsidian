# campfirium/obsidian-tile-line-base

TileLineBase stores structured records directly inside a Markdown note rather than in frontmatter, presenting them as multidimensional tables. One set of records can be viewed in several ways: a filtered table with saved filter and sort rules and multiline text editing, a kanban board, a gallery and a slides view. The README describes the format as plain text requiring no frontmatter and no code, and the repository description calls it a native plain-text database for Obsidian.
