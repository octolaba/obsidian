# obsidianmd/obsidian-importer

Obsidian Importer converts notes and other supported exports into plain-text Markdown files in a vault. Import guides cover sources such as Apple Notes, Evernote, OneNote, Notion, Google Keep, Airtable, CSV, HTML, and Textbundle, with additional formats available.
