# wesswart77/obsidian-freelance-manager

Manages freelance clients, projects, time logs and invoices as plain markdown inside the vault, with no external services. Commands create a client with contact details and notes, a project with a client, rate type and amount, start date, deadline and status, and a time log entry with hours, date and a description of the work. Generating an invoice sums all un-invoiced time logs and writes an invoice note with an itemised table, a total and a due date. A sidebar dashboard lists active projects with total hours logged and estimated earnings, and the clients, projects and invoices folders are configurable.
