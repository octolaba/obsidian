# likemuuxi/obsidian-memos-view

Memos View presents daily notes, or yearly files organised by date headings, as a chronological memo stream grouped by day, with a composer that appends new memos to today's file as timestamped list items. The sidebar carries a contribution-style heatmap of the past twelve weeks and a collapsible nested tag tree, and memos can be searched full-text, sorted by created or edited time, filtered by status or by view, pinned, archived, soft-deleted and later purged. Editing happens inline on double-click, the composer offers a formatting toolbar, image paste saved as attachments, tag autocomplete and link autocomplete reaching headings and blocks, and a random-walk modal surfaces a forgotten memo. Any memo can also be quoted into the composer as a callout or rendered as a shareable image in one of six card styles.
