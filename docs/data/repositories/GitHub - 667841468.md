# ChrisChinchilla/obsidian-vale

Runs the Vale prose linter over the current note and marks its findings inline in the editor. Errors, warnings and suggestions get distinct underlines whose colours are configurable, hovering one shows the issue description, and the status bar carries a count for the open file. Checking happens as text is typed after a configurable debounce, or on demand through commands that lint the file, toggle automatic checking, or clear the marks. Vale itself must already be installed and configured on the machine; its executable path and config file location are plugin settings.
