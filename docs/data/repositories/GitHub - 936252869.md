# cactuzhead/Advanced-Progress-Bars

Advanced Progress Bars extends Obsidian with custom progress bars written as a Markdown code block. The README documents installation from the Community Plugins browser or by copying main.js, manifest.json and styles.css from a release into a plugin folder, then enabling the APB plugin. Its usage section shows the fenced block that inserts a progress bar into a note.
