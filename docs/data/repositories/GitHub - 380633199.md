# 0xGlitchbyte/obsidian_everforest

This repository ports the Everforest colour scheme to Obsidian, and its README states that both light and dark modes are supported. Everforest is described there as green based but warm toned, designed for soft contrast, with rich support for common file types, semantic highlighting and italics, and the README records that only the Medium Material modes are currently supported. Installation is by copying everforest.css into the vault's themes directory, and the todo list keeps code block syntax highlighting and the Hard Flat and Soft Contrast schemes open.
