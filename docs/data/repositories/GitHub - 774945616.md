# slnsys/obsidian-canvas2document

Converts a whole Obsidian canvas into a linear long-form document, carrying over cards, notes and embedded media. The README states that the plugin reads the JSON Canvas file format and takes each element with its metadata, using that metadata to arrange and navigate the elements in the document, and replicating the canvas connections as metadata headers containing the corresponding links. Supported embeddings are listed as images, audio, video, PDF and nested canvases. The conversion runs in two steps: a first command builds a document in which the elements are embedded rather than written out, so the node-level navigation headings can be reordered or deleted before the content is resolved.
