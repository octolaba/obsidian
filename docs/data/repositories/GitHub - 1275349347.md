# liufree/ai-cloze-review

Obsidian plugin that turns a note into fill-in-the-blank review material. Cloze deletions are produced either by a language model through OpenAI-compatible or Anthropic API formats, rendered as the response streams, or locally by a heuristic engine that picks out bold text, quoted terms, numbers, dates, acronyms, proper nouns, definition subjects and frequent terms without any API. Review hides the answers and reveals one on click while tracking revealed against total, with a bottom toolbar for generating, toggling, revealing, resetting and exiting; the cloze content is cached in memory so the note itself is left unchanged. Cloze density follows note length and a difficulty setting, several configuration profiles can be switched from the toolbar, and the interface detects Chinese or English with a manual override.
