# p0shkar/LibreTranslate-for-Obsidian

LibreTranslate for Obsidian is described as a plugin that uses LibreTranslate to translate text. Its README says it translates a selected fragment or an entire note through any LibreTranslate-compatible server, local or hosted, and either replaces the original text or inserts the result as a callout, while trying to preserve Markdown structure and protect callouts, links and code spans. Source and target languages are chosen in settings, and the available language list can be refreshed from the configured server. The README records known issues: Markdown preservation is best-effort, complex callout and blockquote layouts may need manual cleanup, and output varies with the server and source text.
