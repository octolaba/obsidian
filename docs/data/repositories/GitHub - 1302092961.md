# DECK6/obsidian-galaxy-graph

This repository holds Galaxy Graph 3D, described upstream as a translucent three-dimensional galaxy graph for Obsidian. The README presents a desktop-only plugin with its own workspace view, leaving the core graph untouched, that draws notes and their resolved links as star cores with halos, depth fog and a background star field, coloured by folder and sized by connection count. Listed controls cover orbit, pan, zoom, search, hover labels, click-to-open, local-neighbourhood focus, and an automatic large-vault mode with a configurable link cap. The README states that the plugin reads local file paths and Obsidian's resolved-link metadata only, with no telemetry and no network requests.
