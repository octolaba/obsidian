# Heziode/obsidian-antidote

This plugin is an unofficial Obsidian integration of the Antidote grammar checker, which supports English and French. It adds four status-bar icons — a corrector for the whole document, the corrector itself, the Antidote dictionary and the Antidote guide — each of which can be shown or hidden in settings, along with matching commands. The README states that it works with Antidote 10 and higher through Connectix 11 or higher and with Antidote web, on macOS 11 and higher, Linux and Windows, and that it does not work on smartphones.
