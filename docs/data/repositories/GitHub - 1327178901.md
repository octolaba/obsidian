# mikagosz/obsidian-quick-export

Copies the current note, or just the selected text, to a folder outside the vault as a Markdown or plain-text file. The four export actions appear as commands and in the file explorer, tab and title context menus, with the selection variants shown only while text is selected; an open note is exported from the live editor content rather than the older copy on disk. Exported files are named after the note with a timestamp in local time, illegal characters replaced and the name capped at 80 characters, and the destination folder, timestamp format and an optional clipboard copy are configurable. It is desktop only because it uses Node filesystem APIs, and it reads the vault without modifying it.
