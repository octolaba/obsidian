# sharfaroz7/wikilinkcopy

The repository holds Copy Note Wikilink, an Obsidian plugin whose single command copies the active note as a wikilink to the clipboard, bound by default to a shift-modified copy shortcut. When a search-style modal is open it can instead copy the highlighted result, with explicit support for Omnisearch rows that expose a file path and best-effort support for Quick Switcher and Better Command Palette style results. The README states that this depends on the selected result being exposed in the modal's DOM, so a markup change in a third-party search plugin can break it, and that the plugin exists for pasting into plugins and external applications where typing the opening bracket pair triggers no file search.
