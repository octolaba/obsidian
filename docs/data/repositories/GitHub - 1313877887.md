# jepicaju862-lab/ink-annotation

Draws handwritten ink over Markdown notes and PDFs on an overlay above the rendered content, storing strokes as separate annotation data so the source file is never rewritten. Input is stylus-first, with a pen or mouse writing while a finger scrolls and pans, and a draggable toolbar offering pen, highlighter and eraser, stroke width from 1 to 36 pixels and six preset colors plus a custom picker. On PDFs a text-selection mode adds copy, highlight, underline, strikethrough and note annotations, each with its own color, and a page-aware renderer handles long documents. Strokes save automatically shortly after drawing stops and are flushed when the view closes; the plugin needs Obsidian 1.5.0 or newer, runs on desktop and mobile, and works offline with no account or network access.
