# coddingtonbear/obsidian-local-rest-api

The repository holds Local REST API, a plugin that exposes an authenticated REST interface to a vault so scripts, browser extensions and agents can read and change it, and that also serves as a Model Context Protocol server. Its README documents connecting several MCP clients, the tools and resources exposed over that protocol, and an API surface covering note patching with a raw-content mode, targeting particular sections of a note, and searching. Interactive API documentation is published on an external site, and the code is licensed under MIT.
