# dipendave/priority-matrix-obsidian

Task Priority Matrix arranges tasks in the four quadrants of the Eisenhower method, named Do, Schedule, Delegate and Eliminate, inside Obsidian. Tasks are moved between quadrants by drag and drop on desktop or a long press on mobile, edited in place for title and due date, and completed with one click, which moves them to a collapsible bin with a timestamp from which they can be revived or deleted permanently. Due dates are shown in relative form with overdue highlighting, each quadrant header carries a count badge, quadrants scroll individually when full, and a five-second toast offers an undo after a delete or a completion. The README records a responsive mobile layout, adaptation to the light or dark theme, and that tasks propagate between devices through Obsidian Sync.
