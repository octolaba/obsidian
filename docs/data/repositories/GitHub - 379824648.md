# ikuyarihS/obsidian-amazingmarvin-plugin

This plugin brings tasks from the Marvin task manager into Obsidian and requires an API token issued by that service. When its ribbon icon is enabled, a leaf on the right sidebar carries a list tab driven by the ribbon query settings and a calendar tab with week and month modes, and the tab that opens by default is chosen in the settings. Task queries are written as configuration blocks that must be valid JSON, which the README states are parsed with the standard parser and raise errors when they cannot be read. The README also records the minimum Obsidian version for the current plugin version.
