# gustipardo/simple-tap-timer

Repository for Simple Tap Timer, a plugin that renders interactive timers from code blocks in a note. Its README documents a timer block whose parameters set an identifier, a title, button labels and an error message, and a flag deciding whether a timer runs in parallel or pauses the other timers in the same note when started. A second block type generates a summary table of the note's timers, and further commands reset every timer in the note or write a session log to a chosen path in the vault.
