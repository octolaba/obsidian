# mershedsoulaiman/obsidian-heatmap

Writing Activity Calendar records the net words written across the Markdown files of a vault and draws them as a GitHub-style yearly calendar with correct weekday and month alignment. One contribution is counted for each 100 net words in a local calendar day, writing and deletion balance within that day, negative balances do not carry forward, and four intensity levels scale automatically over a customizable base color. Full-year, current-month and current-week display modes, Sunday-first or Monday-first weeks and a year selection from the release year onward are configurable, and a heatmap code block embeds a chosen year in a note. The README also records a local contribution log carrying note, heading, preview and timestamp context, with record validation and SHA-256 tamper detection.
