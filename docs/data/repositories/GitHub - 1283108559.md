# DevidCode/obsidian-publish-to-wordpress

Publish to WordPress sends the active Obsidian note to WordPress as a draft, from a ribbon icon or a command. The default backend talks to the WordPress REST API using an application password created in the site's user profile, which the README notes requires HTTPS and installs nothing on the WordPress side, and an alternative backend posts to a custom webhook for pipelines such as n8n. The note body is converted to HTML from a marker line onwards, the post title comes from a frontmatter field or else the file name, and the featured image comes from a frontmatter image property or else the first embedded image.
