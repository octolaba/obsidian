# rifts-obsidian-laboratory/cyclearn

The repository holds Cyclearn, an Obsidian plugin that keeps flashcard study inside the vault instead of in a separate application. The README describes building cards through its own interface, organizing them with decks, tags and templates, and reviewing them without leaving Obsidian at a self-chosen pace.
