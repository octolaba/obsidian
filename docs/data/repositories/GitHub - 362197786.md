# martin-jw/obsidian-recall

The repository holds Recall, a spaced repetition system for Obsidian that is written to work with any review algorithm. Its README lays out a four-step path — install the plugin, choose an algorithm, start tracking notes, then review them — and states that the plugin was not yet listed in the community plugin directory, so installation had to be done manually. It is written in TypeScript under the MIT license.
