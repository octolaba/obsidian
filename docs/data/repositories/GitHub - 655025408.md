# frthjf/obsidian-zotero-sync-client

This repository holds Obsidian Zotero Sync Client, a plugin that mirrors a Zotero library as Markdown files in a vault through the Zotero web API with an API key, or through a locally installed Zotero app. Synchronization is read-only by design: edits to the generated Markdown are lost and never pushed back, the stated rationale being that linking and search happen in Obsidian while the literature data stays in Zotero. Data is cached and synced incrementally to limit API use, and the file layout comes from a template that can be previewed and rewritten in the settings, with access to the item data and to global collection, item and library values. The plugin itself is desktop-only, but the files it generates reach mobile clients like any other vault file.
