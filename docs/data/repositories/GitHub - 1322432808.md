# Natthapolmnc/the-librarium

The Librarium is a chat interface for local language models served by Ollama, run entirely against models on the same machine. It keeps topic-separated memory as a fixed stack of layers, from a short overview down to a comprehensive summary and the original conversation, routes each query to the topics that match it, and searches that stack from the least detailed layer, loading more detail only when it is needed. Separate chat, summary and embedding models are configured, the first two needing chat or generate support and the third being an embeddings-only model. Beyond chat it offers per-note memory, a chat history digest, document commands that write, update, delete, move and reorganize notes, an accumulated knowledge base, and optional web crawling that can be switched off for a fully offline setup.
