# dualyze-ai/obsidian-context-pack

The repository holds AI Context Pack, an Obsidian plugin that packages notes for use with external assistants such as NotebookLM, ChatGPT, Claude and Gemini. A workspace view manages the outputs generated per folder — briefs, maps of content, context packs, knowledge books in EPUB form and workspace exports — tracks how complete a workspace is, and refreshes outputs when the underlying notes change. The README records that version 4.0 added the workspace dashboard and 4.1.0 an export producing a Notion-ready archive containing the briefs, maps of content, source notes and images.
