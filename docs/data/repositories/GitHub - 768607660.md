# GengAd/obsidian-personal-os

Personal OS automates the selection of what to work on next in a vault, taking its inspiration from the Getting Things Done methodology without requiring strict adherence to it. An Engage command picks the next file that requires an action and opens the appropriate workspace, a Process command identifies the next file in need of processing or task creation, and further commands snooze a file randomly within a date range or mark uncompleted tasks as failed for the current file or the entire vault. Files are classified through Inbox and Work In Progress folders, whose names are set in the plugin settings, and through two optional properties, an Archived flag and a Handled By link, while a task's start, scheduled and due dates decide when its file surfaces. The README states that the plugin leverages the Dataview and Tasks community plugins.
