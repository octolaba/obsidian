# awaragi/obsidian-hotkeys-cheatsheet

Hotkeys Cheatsheet displays every keyboard shortcut assigned in Obsidian as a searchable reference card, opened from the ribbon or the command palette. It reads the live keymap at runtime — default hotkeys plus custom overrides — and lays the result out in newspaper-style columns with key badges rendered for the current operating system, instead of the flat alphabetical list of the built-in hotkey settings. Core commands are grouped by workflow into editing, navigation, search, files and workspace sections while community-plugin commands are grouped by plugin, and each section can be collapsed or expanded. A search box filters by command name or by key character, expanding collapsed sections while a query is active, and an opt-in local tracker can record how often each shortcut is actually used.
