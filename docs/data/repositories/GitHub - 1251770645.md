# t0masGutierrez/folder-sort

Folder Sort adds A-to-Z and Z-to-A folder ordering to Obsidian's native File explorer while leaving file sorting unchanged. It uses natural, case-insensitive sorting, remembers the direction per vault, lets folders appear first or last, and supports pinning or hiding folders on desktop and mobile.
