# t0masGutierrez/folder-sort

Folder Sort adds two entries, folder name A to Z and Z to A, to Obsidian's native File explorer sort menu, and reorders folders only: file sorting keeps Obsidian's built-in behaviour. Sorting applies at every level of the tree, uses natural case-insensitive comparison so a folder numbered 2 comes before one numbered 10, and the chosen direction is stored per vault; the same directions are also available as commands, together with a toggle. A folder placement setting keeps folders in their existing positions or moves them above or below files. Folders can be pinned above the others with a purple marker or hidden from the explorer through the right-click menu, and hidden folders are brought back by a command.
