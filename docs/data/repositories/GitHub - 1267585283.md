# ginkgobackup/obsidian-ginkgo-backup

Sends vault changes to the separate Ginkgo Backup desktop engine, which the README states must be installed for anything to be backed up: this plugin watches the vault while the engine handles compression, encryption, scheduling and storage. Every save is captured within seconds into a versioned timeline, and any two versions can be compared line by line, previewed and restored from inside Obsidian, with a calendar date picker for navigating history. Setup takes an API token copied from the desktop application's settings and a configured source repository per vault, plus an optional vault identifier that keeps per-device hash caches separate. The README states the engine runs locally with no cloud subscription, keeps backing up when Obsidian is closed or the plugin removed, and can link devices over the local network.
