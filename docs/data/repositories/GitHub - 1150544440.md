# Pardesco/hypernovum

Renders the vault as a 3D city built on Three.js, where notes tagged as projects become buildings whose color reports status, height reports priority and district comes from category, with backlinks drawn as arcs; an untagged vault falls back to districts by folder. A projectDir frontmatter field points a building at a folder on disk, which enables read-only git commands for commit activity, branch and dirty state, dependency detection, and an action that opens a terminal running a chosen agent command-line tool. Detection of which agent binaries are installed happens when the view opens, and active agents orbit their building as colored orbs. It is desktop-only, makes no network requests of any kind, and a vault mode switch turns the whole agent layer off, disabling process execution and reads outside the vault.
