# mnaoumov/obsidian-file-explorer-reload

Adds a command that reloads the file explorer's list of files. The README describes the case it addresses: bulk copies, moves or deletions performed outside Obsidian while it is running are sometimes not reflected in the explorer, which then shows files that no longer exist or omits files that do. Alongside the command it adds Reload Folder and Reload Folder with Subfolders context menu entries, and the reload can also be invoked from JavaScript through the plugin instance. A demo vault ships with every release.
