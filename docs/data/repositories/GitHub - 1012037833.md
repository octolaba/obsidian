# cxj05h/obsidian-avatar

This repository holds the Avatar theme, a dark Obsidian theme built on a palette of aqua, purple, gold and pink accents that its README maps to the four elements of water, spirit, fire and life. It sets a distinct colour per heading level from H1 to H6, adjusts text formatting, code block styling and link colours, and gives tables gradient headers and hover effects. The theme is built from CSS custom properties for customization, and the README supplies a CSS snippet the author says may be needed to keep the tab bar and its divider matched when the window is unfocused.
