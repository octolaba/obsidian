# hankleechn/myspace-tasks

MySpace Tasks sends the current Obsidian line or text selection to a linked MySpace account only when its command or ribbon action is used; it does not scan notes or the vault for tasks. Optional knowledge integration is separately authorized by folders or tags, supports reviewed create, update, move, or archive plans, verifies content hashes, keeps backups, and refuses to overwrite notes changed after review.
