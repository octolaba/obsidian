# t5k6/obsidian-koreader-highlights

The recorded description says the plugin imports highlights and metadata from KOReader into Obsidian notes. Per the README it scans for .sdr directories, parses their Lua metadata files and writes both the highlights and the notes attached to them into Markdown organized by chapter and page number, with duplicate highlights detected and managed. Mount points, excluded folders and allowed file types are configurable, the metadata fields written to frontmatter such as title, author and pages can be chosen, and a template system controls how highlights are rendered. Metadata extraction covers author, title, description, pages and keywords, and KOReader's statistics database can optionally be read for reading statistics.
