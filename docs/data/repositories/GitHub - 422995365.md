# twentytwokhz/language-translator

Language Translator is described as an Obsidian plugin that translates selected text into a chosen language. Its README says the translation is based on a free instance of Azure Translator and asks that it not be abused, and the settings choose a default target language and an API type, with the built-in Azure API carrying a limit. The README describes the release as an initial version whose interface is subject to change.
