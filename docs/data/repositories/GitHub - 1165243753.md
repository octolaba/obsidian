# RogueL90/obsidian-day-planner-analyzer

Reads time-boxed tasks from Day Planner-style daily notes named by year, month and day, and displays statistics about them in an advanced statistics window opened from the command palette. It reports how many days were planned, how long the days run, how much time was left unplanned, and how often tasks are finished, particularly the ones marked as priority, over the past 7 or 30 days or any custom range. Charts show how much time is spent on each task over time, and sortable tables list each day and each task. The README states the plugin works alongside the Day Planner plugin rather than replacing its timeline, and that it includes an AI chat assistant giving personalized advice based on the daily notes.
