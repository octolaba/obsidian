# dogukansahil/Borrax-HTML

Borrax HTML opens .html and .htm files stored inside an Obsidian vault in a dedicated view, loaded from their vault location so that relative stylesheets, images, scripts and links resolve correctly. On desktop the file is loaded in an isolated Electron webview, which the README says renders exactly as opening it in a browser would, including linked and inline CSS, scripts and external web fonts; on mobile it falls back to a sandboxed iframe with an injected base element. Links to other vault files open inside Obsidian in the same tab or a new one, while external links open in the system browser. Zoom level is adjustable, folders containing an index file can carry an optional badge, and the tab context menu offers reload and open in an external browser.
