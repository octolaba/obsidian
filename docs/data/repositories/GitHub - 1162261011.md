# alexjiaguo/obsidian-ai-copilot

Obsidian plugin providing a chat sidebar over the vault, text transformation commands and access to several model providers. Chat is scoped to the current note, a selection or the whole vault, pulls files in through `@` mentions and context menus, and keeps multiple pinned sessions that can be organised into projects with their own folders, tags and system prompts. Selected text can be run through actions such as fixing grammar, reformatting, summarising, simplifying, shortening or lengthening, changing tone and brainstorming ideas. The providers listed are OpenAI, Anthropic, Google Gemini, Groq and Ollama for local offline use, and the plugin is extended with MCP servers and custom skills.
