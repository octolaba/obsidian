# jglev/obsidian-paste-mode

The repository holds Obsidian Paste Mode, a plugin that takes over pasting so that pasted text, block quotes included, honours the indentation the cursor sits at. Its README describes eight paste modes, among them plain text, text as a blockquote with a configurable prefix, HTML converted to Markdown, and that conversion as a blockquote, while a passthrough mode leaves Obsidian's own paste behaviour untouched and is the one mode that ignores indentation. It records that the plugin was formerly named Paste to Current Indentation, and it is aimed at embedding code and quoted material inside lists.
