# solomonarul/soundify

Repository for Soundify, a plugin that plays sounds when particular events occur, with the mapping configured in its settings. Its README notes that the default media pack cannot be distributed through Obsidian's asset channel, so the archive has to be downloaded from the latest release and placed in the plugin folder inside the vault. The author asks for feature requests and bug reports as issues.
