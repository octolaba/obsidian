# chingchen0119/obsidian-vocab-hover

Vocab Hover is an Obsidian plugin that adds hover tooltips to selected words, aimed at vocabulary learning, annotations and quick references. A word or phrase is selected, an add-hover-content action is chosen from the context menu, and the tooltip text is typed; the pair is stored inline in the note as the word and its content inside braces, and the tooltip appears on hover in Reading View. The README also documents a setting for the highlight style of marked words, applied without a reload, and a generated vocabulary list note that tables every marked word with its content and a link back to the source note, refreshed whenever a note is saved.
