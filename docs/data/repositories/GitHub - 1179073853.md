# SattaRIP/obsidian-task-accountability

Task Accountability Tracker scans the daily notes folder and reports which days were engaged and which were not, counting a day as engaged when at least a threshold number of tasks were checked off, three by default and configurable. It reports the engaged and not-engaged days, the current streak and the longest streak over weekly, monthly and yearly views, with a breakdown showing which days were missed and why. The folder is detected automatically from the Daily Notes or Periodic Notes plugin settings. The README records that the plugin was not in the community plugin store at the time of writing, and documents adding its task-state cycling command to the mobile editing toolbar because mobile has no hotkeys.
