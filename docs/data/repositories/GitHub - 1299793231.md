# seongchan/DailyWorkLog

Daily Work Log reads Events and To-Do entries from daily Markdown notes and visualizes them in a sidebar without requiring YAML frontmatter. Its grid timeline uses ten-minute cells for time blocks, while categories, inline task controls, PDF or HTML export, folder autocomplete, language-aware markers, sidebar themes, and Work Insights provide tracking and summaries; legacy heading markers remain supported.
