# ameyxd/obsidian-isinglass

Isinglass is a minimal frosted-glass theme for Obsidian in light and dark, keeping surfaces neutral so luminance carries the design while the accent color drives links, highlights and graph focus. Floating surfaces such as menus, the command palette, modals and popovers use real backdrop blur, and the theme adds styling for Dataview, Tasks, Notebook Navigator, Canvas, Bases and the graph. Its build composites every text token over every surface at each translucency state and fails on any pair below WCAG AA, and the theme honours reduced-transparency and reduced-motion settings. Style Settings adds controls for glass intensity, blur, grain, reading width, density and hiding the tab bar, ribbon or status bar, and an optional companion plugin in the repository enables real window transparency.
