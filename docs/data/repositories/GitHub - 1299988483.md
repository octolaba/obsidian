# JWCzju/sticky-table-headers

Sticky Table Headers keeps a Markdown table's header row visible while a long table is scrolled, rendering a pinned clone of that row at the top of the scroll container once the real header passes out of view. It works in Reading view and Live Preview, handles every table on a page independently, and scrolls the pinned header sideways in step with wide tables so the columns stay aligned. Column widths are measured from the real table, the clone inherits the table's existing styling, and the README describes the plugin as display-only, writing nothing into notes and requiring no configuration.
