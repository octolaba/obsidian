# cwagner223355/obsidian-recent-edits

A sidebar panel listing files modified in the last N days — seven by default, configurable from one to ninety — grouped by calendar day under headers labelled Today, Yesterday or a dated form, most recent first. Files edited from outside Obsidian's editor, such as filesystem writes, sync from another device, or programmatic writes by AI tools and scripts, are flagged with a configurable indicator dot. The stated motivation is that most recent-files plugins list recently opened rather than recently modified files, and noisy folders can be hidden through background-folder and excluded-folder settings.
