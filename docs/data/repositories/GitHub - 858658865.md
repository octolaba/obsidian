# ahts4962/nav-link-header

Nav Link Header is an Obsidian plugin that shows a navigation header at the top of a note. Its content is configurable and can include annotated links, the previous and next daily notes, or the previous and next note within the same folder. An annotated link is one preceded immediately by a chosen annotation string, which may be any text including emoji as long as what follows is recognized as a wikilink or Markdown link; such links found in the current note or in backlink notes are surfaced in the header. The README gives Map of Contents navigation as the motivating case, where marking links in the MOC note makes a link back to it appear at the top of each destination.
