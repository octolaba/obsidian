# 30jannik06/Obsidian-Cockpit

Project Cockpit replaces the Obsidian new tab with a dashboard of active work. Its sections are a stats bar of active projects, open TODOs, journal entries this week and the current streak; project cards with status badges, TODO counts and last-modified times; every unchecked task grouped by project and checkable inline; recently edited files with project labels; pinned notes; the top tags as clickable chips; a 52-week journal heatmap with a streak counter; a force-directed graph of links between project files; the seven most-referenced files; and configurable buttons that create files from templates. Each section can be toggled, reordered and collapsed from settings, and its collapse state is remembered.
