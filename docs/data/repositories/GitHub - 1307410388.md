# Mrjahanbin90/safe-attachment-trash

Safe Attachment Trash finds attachments that appear to be unused, presents them as a review list, and acts only on what the reader explicitly selects. The README states that a scan never moves or deletes anything, because a file may still be referenced from a note property, a Canvas or a Base: each row can be opened and inspected in the workspace, then moved to the app's trash after confirmation or marked so that it is never suggested again. A separate trash tab opens, restores to the original location, or permanently deletes the files chosen there, and scanning can be run automatically or manually.
