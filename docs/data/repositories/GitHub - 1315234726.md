# IngloriousPSTR/stage-binder

Builds chord charts in the plain-text ChordPro format and organizes them into setlists and run sheets, all kept as ordinary Markdown or chordpro files in the vault with no database or account. Because chords are symbolic text, a chart can be transposed to any key on the spot, shown with capo-aware shapes while the sounding key stays correct for the rest of the band, or switched to Nashville numbers. A run sheet gathers what a service or show needs beyond the songs, including the form each song is played in, performance keys, clock times, assignments, readings, PDFs and images, and the same files drive a touch-friendly performance view on a tablet. Song metadata lives in ChordPro directives and Obsidian properties, so a library stays searchable and queryable with Dataview or Bases.
