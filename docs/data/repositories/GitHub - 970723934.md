# OwainWilliams/umbPublisher

umbPublisher pushes Obsidian notes into Umbraco 15 or later as content items, using Umbraco's Management API and requiring an API user to be created there. The settings hold the site URL, a client ID and a client secret, and the content tree is fetched so that a parent node and one of the document types allowed beneath it can be chosen. The README describes mutually exclusive content modes for how the Markdown is stored on the document type, the default writing the title and the content directly to named properties and another wrapping the content in a Block List.
