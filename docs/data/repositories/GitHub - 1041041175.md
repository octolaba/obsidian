# andresgongora/obsidian-colorful-note-background

Colorful Note Background tints Obsidian notes according to their folder location or frontmatter values, providing a visual cue for note types and areas. Rules are evaluated in order so the first match determines the color, with configurable alpha and priority, while settings remain local and the plugin makes no network calls or telemetry collection.
