# andresgongora/obsidian-colorful-note-background

Obsidian plugin that tints a note's background color according to its folder or its frontmatter metadata. The README states that a rule is defined once and every matching note then carries the same color cue, so folders and note types can be told apart without reading the file path. Installation is documented from the community plugin browser, through BRAT, or manually.
