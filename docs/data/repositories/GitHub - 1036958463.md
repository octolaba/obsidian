# 4Source/favorites-obsidian-plugin

Favorites stores and manages a global favorites list of Obsidian plugins and themes, kept on the device rather than in a single vault so the same list is available everywhere. Alongside favorites the plugin maintains an "in use" list of plugins and themes enabled in at least one vault and a "known" list of everything installed at least once, and entries can be marked from the plugin browser, the community plugins tab, the theme browser or through commands that also clear, load, save, export and import the lists. The README opens with a caution that the plugin is not expected to work after the settings UI change in Obsidian 1.13.4 and that most of its code would need rework.
