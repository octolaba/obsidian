# 0qln/obsidian-image-darkmodifier

Image Darkmodifier applies filters, including dark-mode effects with transparency, to Markdown image links in Obsidian. Filters are written into the alias part of the link, so `@darkmode` acts as shorthand for an invert, transparent and boost-lightness chain, and several filters are applied left to right. The README documents the filter parameter syntax and its escaping rules, notes that backslashes are not allowed because of how Obsidian parses the image alt text, and states that filtering a remote image requires a network request to fetch the image data.
