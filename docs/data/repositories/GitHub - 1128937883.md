# community-archive/nldates

Natural Language Dates parses date expressions typed in a note and turns them into dates or links to daily notes. An inline autosuggest, triggered by a configurable phrase that defaults to the at sign, expands entries such as today into the current date, optionally as a wikilink or with the typed text kept as an alias, and unrecognised dates produce no link. The plugin also registers an obsidian://nldates URI that opens a daily note from a natural-language day parameter, plus a date picker and commands that insert the current date or time in the configured format; hotkeys are unset by default.
