# oqipoDev/buena-vista-obsidian

Buena Vista is a configurable Obsidian theme that its README frames as small quality-of-life and aesthetic improvements rather than a full restyling. Its colour modes are selected through the Style Settings plugin, and the theme keeps working with Obsidian's accent colour. The listed tweaks make embedded notes take less space and give them smaller titles, give quotes and callouts a more consistent style with a slight highlight in source mode, remove borders except where something is draggable or a border aids clarity, and enlarge the sidebar tabs. Visual changes also reach the built-in Slides and Outline views and the Style Settings, Kanban and Breadcrumbs plugins.
