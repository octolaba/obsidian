# lossless-group/perplexed-plugin

Perplexed generates source-cited research content inside Obsidian from Perplexity, Anthropic Claude, Google Gemini with Search grounding, self-hosted Perplexica or Vane, and local LM Studio, writing the result into notes. The README also describes directory templates aimed at venture capital, private equity and equity-research deliverables: an empty file dropped into a matching folder and the apply-directory-template command return a long cited draft for curation. Those provider and output claims are the project's own, recorded here from its description and README.
