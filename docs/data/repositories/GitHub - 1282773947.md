# cheney12138/mermaid-canvas-plugin

Mermaid Canvas is an Obsidian plugin that turns every mermaid code block into an interactive canvas: the SVG renders at its natural size, zooms toward the cursor with the modifier key and the scroll wheel, and pans by dragging. A hover control bar offers zoom, fit, fullscreen, copy of the raw source and, in editing mode, deletion of the block, while a separate bar exports the diagram as PNG or SVG. A command inserts a block and opens a split editor with live preview, Obsidian's own edit button on a rendered block is intercepted to open the same editor, and saving refreshes the reading view. Invalid or empty blocks are skipped rather than failing.
