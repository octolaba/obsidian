# adoom2017/memos-obsidian

Memos Card View connects Obsidian to a Memos instance and displays memos as editable cards, supporting refresh, paging, creation, editing, deletion, private or public visibility, live Markdown preview and file uploads as attachments. It can clip a web page by URL through the desktop app's embedded browser, summarise it with a locally configured OpenAI-compatible model and save the summary with its source link to Memos, or receive a clipped page from a companion Chromium extension over a local bridge. The README records the base URL, personal access token, page size and default visibility as settings, and states that the plugin is desktop-only because clipping uses local Node and Electron APIs, and that it writes to the clipboard only on a visible copy action.
