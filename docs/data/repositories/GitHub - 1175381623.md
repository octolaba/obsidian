# nicoletterankin/wordorb-obsidian

Looks up words and generates vocabulary material inside Obsidian against the WordOrb API, recorded as covering 162K words and 47 languages. A lookup modal shows a word's definition, IPA, etymology and translations, while further commands insert a formatted word card as a callout, generate a full vocabulary note with frontmatter, lesson and quiz questions, open the day's five-phase lesson and run a multiple-choice quiz. A wikilink whose target is the word prefixed with wordorb and a colon renders as an inline definition link, the word of the day can be appended to the daily note, and the README states that an API key is entered in the plugin settings.
