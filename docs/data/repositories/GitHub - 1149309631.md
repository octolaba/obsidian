# va9id/obsidian-directory-summary

Generates a summary note for any directory in a vault with the Generate directory summary command, writing a summary file whose headings mirror the folder tree and whose file names appear as backlinks. Settings control the maximum directory search depth and the number of files per directory included, the summary file naming scheme, a file property shown with each file name, a property rendered as a checkbox with a regex deciding whether it is checked, and the files or directories excluded from the summary.
