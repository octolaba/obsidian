# ferusnet/kaos-plugin

Opens one custom view whose tabbed panes render operational dashboards pulled on demand from the Ferusnet tenant tools API, drawing Jira, Freshdesk, CRM and tenant metrics as tables, badges, bar charts and status tiles. It requires a Ferusnet tenant account and an API key issued by that service, stored in the operating system keychain rather than in the plugin's data file, and it contacts that single endpoint only. A vault access setting chooses between none, read and readwrite, controlling whether notes may be read for context or reports written back into a nominated folder, with nothing leaving the vault by default. Obsidian 1.11.4 or later is required.
