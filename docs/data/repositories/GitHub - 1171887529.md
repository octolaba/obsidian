# MVRU/focus-mode-pro

Focus Mode Pro is an Obsidian plugin for deep work that combines a minimalist writing environment with keyboard navigation. Its focus mode hides sidebars, ribbons, tabs and status bars, centres the writing area at a configurable maximum width and adjusts font size, while a typewriter mode keeps the active line vertically centred; a file finder modal searches vault paths and a Windows-style Ctrl+Tab switcher cycles open documents, and optional acoustic ticks accompany typing. The README states that the plugin requires Obsidian 1.7.0 or later and works on desktop, that focus mode injects CSS and toggles body classes, that the file finder uses a SuggestModal and typewriter mode the CodeMirror 6 API. Known limitations are conflicts with plugins that force-hide UI or change editor scrolling, and a tab switcher that depends on the hotkey being free.
