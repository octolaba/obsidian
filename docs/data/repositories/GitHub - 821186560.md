# travismlee/arcane-obfuscate

Obsidian plugin that marks text to be displayed as obfuscated, by default with an animated runic look. The text is wrapped in inline code with tilde delimiters, individual characters can be escaped so they show through the obfuscation, and prefixing a word with an exclamation mark reveals the whole word. The README states the plugin was designed for use alongside Obsidian Webpage Export and that the source text is not exposed in the exported HTML, but warns that the structure of the text remains and leaves it open to dictionary or pattern-matching attacks, so it should not be trusted with anything genuinely private.
