# modigaphemelo/Dedication-2-Obsidian-Theme

This repository holds Dedication 2, a refined version of the same author's Dedication theme for Obsidian, with dark and light modes. It carries seven colour presets, Original Dark, Matrix Green, Blade Runner, Dark Knight, Gotham Noir, Cosmic Blue and Star Trek, each with dark and light variants, and six typography options ranging from Inter and the system fonts to Georgia, Helvetica Neue, Source Sans Pro and Roboto Mono. Interface work includes heading indicators with coloured bars, an animated pendulum startup loader, calendar styling with coloured weekdays, table designs and custom tooltips, and the presets are switched through the Style Settings plugin.
