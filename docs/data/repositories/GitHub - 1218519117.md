# Ekrizdis367/obsidian-mtg-decklist

This repository holds MTG Decklist, an Obsidian plugin that turns fenced decklist code blocks into Moxfield-style trading card game deck panels; the repository records no description, so this summary follows the README alone. Card data and images come from the public Scryfall API, with hover previews on desktop and tap previews on mobile, at-a-glance deck stats, automatic grouping by card type or by the author's own section headers, and sorting by name, by mana value then name, or in the typed order. Inline mana symbols and hoverable card links can also be used in ordinary notes, and the README states that this is unofficial fan content not affiliated with Wizards of the Coast and that it is the author's first Obsidian plugin.
