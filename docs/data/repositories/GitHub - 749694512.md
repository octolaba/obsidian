# l2xu/kindle_html_importer

The README describes an Obsidian plugin that imports a Kindle highlights HTML file and converts it into a Markdown note saved in a folder chosen in the plugin settings. It walks through producing that file in the Kindle app — opening the book, tapping the notebook icon, using Share, choosing Export notebook and the APA citation style, and sending the file to oneself. Back in Obsidian the Kindle Highlights Importer command is run from the command palette, the HTML file is chosen in a file picker, and a notification confirms that the import succeeded.
