# dilantha/link-formatter

Link Formatter is described as formatting a block of links into a clean Markdown list in Obsidian. Its README says the links are selected and a single command, reachable from the command palette or a hotkey, rewrites them as an unordered list, and it gives pasting bookmarks exported from a browser as the example. Installation is offered from the community plugin list or through BRAT as a beta plugin.
