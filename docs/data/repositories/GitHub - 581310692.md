# sblakey/obsidian-quip

This plugin connects Obsidian to Quip, which the README identifies as the lightweight document tool from Salesforce. Three commands are recorded: importing a Quip document into a new Obsidian note, publishing a note as a new Quip document from HTML rendered through Obsidian internals, and updating an existing Quip document by overwriting it with a fresh rendering. Configuration takes a portal API endpoint and a developer key, and the README tabulates how the API hostname and the token page follow from the address a corporate account normally uses, states that the account must meet Quip's license requirements for the Automation API, and notes that only one developer token can exist at a time across all of a user's automation tools.
