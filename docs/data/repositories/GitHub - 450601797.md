# ericbiewener/obsidian-lock-screen-plugin

The repository holds an Obsidian plugin that adds a lock screen, which its README describes plainly as a user-interface feature with no filesystem encryption behind it. Recorded triggers are a configurable delay after the window loses focus on desktop, a configurable delay after interaction stops on mobile, opening the vault, and a command palette entry. The README notes the mobile trigger as a workaround until the Obsidian API can tell a plugin the app was backgrounded, and its opening line records that the project is not under active development.
