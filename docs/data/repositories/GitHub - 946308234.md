# docmarionum1/obsidian-pinned-daily-notes

Pinned Daily Notes keeps today's daily note in a pinned tab. A ribbon icon and a command palette action open today's note, updating and focusing an existing pinned daily-note tab when one exists and creating a new pinned tab otherwise, so the tab can be placed once and then keeps showing the current day. The plugin respects the Daily Notes plugin settings and works with any daily-note folder structure and format, and a setting chooses whether a new pinned tab opens in the editor or in the left or right sidebar.
