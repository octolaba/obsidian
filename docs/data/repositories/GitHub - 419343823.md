# SkepticMystic/advanced-cursors

Advanced Cursors adds commands to Obsidian for working with multiple cursors. They move the cursor to the next or previous instance of the current selection — selecting the word under the cursor when nothing is selected — or add that instance to the existing selections, which the README compares to Ctrl+D in VS Code. When no further instance is found the search loops back to the beginning of the note.
