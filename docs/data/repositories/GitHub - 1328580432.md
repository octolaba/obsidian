# CosmicSeaFox/noir-void

Noir Void is a monochrome Obsidian theme built on layered charcoal surfaces in dark mode and a warm neutral ivory in light mode, keeping contrast restrained and avoiding glow and bright accents. Tables use a continuous surface with subtle borders rather than spreadsheet-style striping, properties sit inside the surrounding interface, and callouts, code blocks and the graph view follow the same quiet treatment. Body text is set in Inter, headings in Cormorant Garamond and code in JetBrains Mono, and the theme lists support for mobile alongside desktop and for Dataview, Tasks, Canvas and Excalidraw.
