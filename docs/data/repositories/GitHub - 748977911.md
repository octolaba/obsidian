# rekby/obsidian-paste-transform

Paste Transform handles the paste event, checks whether simple text was pasted and rewrites it according to user-defined rules, each pairing a regular expression with either a replacement string or a script. The author's recorded use is expanding short issue identifiers into links to an internal tracker, and the plugin ships default rules for GitHub and Wikipedia as examples. Rules are applied sequentially, the output of one passed as the input of the next, and each regex rule carries an optional second replacer used when the editor has text selected at the time of the paste. Automatic transformation can be enabled or disabled globally from the settings or through three command-palette commands.
