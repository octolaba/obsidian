# avnibilgin/BeautyTasks

BeautyTasks is a Todoist-style task and project manager that stores one Markdown note with YAML frontmatter per task, without requiring another plugin or an account. Its native dashboard covers inbox, dates, projects, areas, labels, filters, Kanban or calendar views, quick capture, reminders, recurrence, soft deletion, and optional Google Calendar synchronization.
