# avnibilgin/BeautyTasks

BeautyTasks is a Todoist-style task and project manager rendered inside Obsidian, where each task is one Markdown note with YAML frontmatter rather than a row in a proprietary database. It provides a dashboard with sidebar navigation, a chip-based task editor, quick capture and keyboard-driven flows, works in popout windows, and states it requires no other plugin and no account, with two-way Google Calendar sync as the single optional online feature that stays off until configured. The README also records that the two frontmatter fields it needs, `type` and `title`, are renameable so it never claims a property already in use, that converting an existing note adds frontmatter without rewriting the text, that every color is a CSS variable usable with Style Settings, and that the interface is translated into ten languages.
