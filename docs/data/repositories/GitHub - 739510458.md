# natefrisch01/Graph-Link-Types

Graph Link Types renders the type of a link as text on the matching edge of Obsidian's graph view, so the relationships between notes are readable there. The type is read from Dataview metadata — a field holding an internal link, written in frontmatter or inline — so the Dataview plugin has to be installed. The README states that the rendering and updating are done with PIXI.js.
