# nykkolin/obsidian-convert-base64-to-png

Convert Base64 to PNG replaces base64-encoded images embedded in notes with local PNG files: it scans a note for base64 data, decodes it, writes the bytes into a configured folder and rewrites the links to point at the new files. Commands process the active file or every Markdown file in the vault, and a setting converts pasted base64 images automatically. The output folder is configured relative to the note and the generated filenames follow a format with placeholders for the date, an index and the image type.
