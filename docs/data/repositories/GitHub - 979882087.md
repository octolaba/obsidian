# rioskit/obsidian-todo-txt-mode

Todo.txt Mode adds support for the todo.txt file format in Obsidian. The README records syntax highlighting for completed tasks, project and context tags, priority markers, due dates and recurrence markers, with colours customizable through the Style Settings plugin, and the automatic addition of a completion date when a task is marked done. Recurring tasks are generated from a recurrence attribute supporting daily, business-day, weekly, monthly and yearly intervals, numeric prefixes and a strict mode based on the original due date, and commands move completed tasks to a done file and sort by priority, project, context or due date.
