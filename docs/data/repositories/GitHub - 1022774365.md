# jheddings/obsidian-stomp

STOMP receives system key events so that foot pedals can scroll Obsidian notes hands-free; the README says it was written for a Coda STOMP pedal but should work with any pedal. It offers page, section, quick and auto scroll modes bound to configurable keys that are normally unavailable as Obsidian hotkeys, and section scrolling can stop at heading level 1, heading level 2 or horizontal-rule elements. All of the scroll commands are also exposed in the command palette.
