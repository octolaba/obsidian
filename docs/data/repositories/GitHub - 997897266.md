# ras0q/obsidian-litecite

LiteCite is described as a lightweight Obsidian plugin that creates citation notes from a BibTeX or BibLaTeX file. Its README says it was written because the existing Citations plugin is no longer actively maintained, and aims to be lighter, simpler and faster, using the Eta templating engine and a custom parser for BibTeX entries. In use, the path to the BibTeX file is set in the plugin settings and a single command creates a note from an entry. The README records that the project is built from a Deno-based plugin template.
