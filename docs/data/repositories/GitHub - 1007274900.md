# ayu5h-raj/clipboard-manager

Obsidian clipboard plugin that captures text copied while Obsidian is running and stores it as a searchable history. The README describes a configurable monitoring interval and history limit, real-time search over content and previews, a quick-paste modal reachable from a ribbon icon, the command palette or a hotkey, and export of all or filtered entries to Markdown files.
