# YTolun/obsidian-filename-emoji-remover

The repository holds an Obsidian plugin that renames files to strip emoji from their names. Its README gives the reason: services that import notes from elsewhere sometimes bring emoji into filenames, which other services handle badly. Two modes are recorded, a manual scan of the whole vault run from the settings tab or the command palette, and an automatic removal when a new file is created, which has to be enabled in the settings. The author states that this was their first plugin, is likely to have bugs, and should be used with backups.
