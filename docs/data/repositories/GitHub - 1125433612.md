# garrett-is-a-swann/obsidian-sentence-enhancers

Sentence Enhancers adds contextual CSS classes to the workspace and to a file's Markdown view container so snippets and themes can key styling off them. The README states the classes are prefixed and carry temporal information — month, day of the week, day of the month, hour and minute — and shows snippets that use them to restyle notes on a particular date or flash the workspace ribbon at a chosen time. The plugin itself supplies the classes; the styling is left to the user or theme author.
