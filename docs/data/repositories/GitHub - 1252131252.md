# youzhixiaomutou/auto-llm-wiki

An Obsidian plugin that maintains a structured wiki generated from a folder of raw source files. It scans that folder for Markdown, plain text, CSV or TSV, code, HTML, PDF, image, Office and RTF files, extracts their text — falling back to vision OCR for scanned PDF pages, image-only slides and images — and detects changes by modification time, size and content hash so only new or changed files are sent to an OpenAI-compatible chat completions endpoint, which returns a JSON change plan for the wiki. Ingestion can run on Obsidian file events and on a polling interval that also catches outside edits, with retry and backoff on network, 429 and 5xx errors, a request timeout and an endpoint test in settings. A side panel holds multi-turn chats grounded in the notes through index-first retrieval, with several conversations persisting across restarts, and the repository carries no description.
