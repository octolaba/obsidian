# UNLINEARITY/Obsidian-CodeSpace

Obsidian plugin for viewing, managing and editing code files inside a vault, presented in the README as filling a gap in Obsidian's Markdown-centered workflow. It describes four layers: a management space giving a visual dashboard and index of code files, an editing space that opens them in a dedicated environment, an embedding space for references, embedded previews and PDF export as real code blocks, and a mount space that links external folders into the vault through system symlinks or junctions. The upstream description is recorded in both English and Chinese.
