# H21465/eof-stats

EOF Stats appends a statistics line and an end-of-file marker to the bottom of Markdown files in Obsidian, in both Live Preview and Reading view. The README states that it counts unique URLs and unique internal links in the document, and that each of the two statistics can be shown or hidden individually. Colors for the statistics text, the horizontal lines and the EOF text are configurable in settings.
