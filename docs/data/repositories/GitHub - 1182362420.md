# gabriele-cusato/HandTranscriptMd

HandTranscriptMd is an Obsidian plugin that embeds a handwriting canvas in a Markdown file, drawn on with a stylus or mouse, and converts the writing into Markdown. The README records saving a drawing as an SVG in the vault, embedded with ordinary wiki syntax so it renders without the plugin, and a Convert action that runs Google Gemini OCR and replaces the drawing block with structured text such as headings, lists and tables. The editor opens as a full-screen modal on Windows desktop and as a new tab on Android, with pen and eraser modes, four colours, undo, redo, clear, save and delete. Recorded canvas behaviour includes finger scrolling while the stylus draws, automatic expansion as writing nears the bottom, ruled guide lines kept in the SVG, and stroke colours remapped when the theme switches between light and dark.
