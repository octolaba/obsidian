# Hoshino-Yumetsuki/obsidian-plugin-abbrlink

Abbrlink generates a permanent link for each Markdown file in an Obsidian vault and writes it into the file's frontmatter as an abbrlink field. Generation runs in batch from a sidebar link icon or automatically for newly created files, with a hash length configurable between 4 and 32 digits and an option to skip files that already carry an abbrlink. The README also documents a random mode that uses a randomly generated SHA256 hash instead of a filename-based one, and collision detection that avoids conflicting hash values.
