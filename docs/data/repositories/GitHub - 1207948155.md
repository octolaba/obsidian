# hwangso595/eink-sync

Pulls documents, notebooks and annotations off a reMarkable tablet over direct SFTP or Syncthing, without the reMarkable cloud. Text highlights are extracted from PDFs into Markdown notes that link back to the source, pen strokes are rendered as PNG images embedded in those notes, and a sidebar browses, searches, archives and deletes items in the tablet library. Both reMarkable 1 and 2 are supported, with current firmware annotation files and the older formats handled alike. Parsing runs in a local Python process that a setup wizard provisions in a private environment with tested rmscene and PyMuPDF versions; SSH access on the tablet is needed for direct sync and library management, and handwriting search additionally requires Tesseract.
