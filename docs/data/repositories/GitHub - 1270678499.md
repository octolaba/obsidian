# awaragi/obsidian-meeting-note-importer

Meeting Note Importer builds a structured meeting note from a calendar invite, accepting an ICS file by drag and drop or through a file picker, a meeting dragged straight out of Outlook for Mac, or details typed on a quick-entry tab where the date defaults to today. Title, date, attendees, organizer, location, meeting URL and description are filled in automatically, an existing note for the same meeting is returned rather than overwritten, and both the note body and the file name can follow templates with placeholders. Settings cover the target folder, the heading names for the attendee and notes sections, and an option to write into the currently open file instead of creating a new one. The README records the plugin as designed for desktop with mobile behaviour untested, and its interface localised in English, French and Spanish.
