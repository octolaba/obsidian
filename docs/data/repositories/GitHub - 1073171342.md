# modigaphemelo/Dedication-obsidian-theme

This repository holds Dedication, an Obsidian theme with dark and light modes and extensive colour customization. It ships six presets, Dark Modern, Dracula, Nord, Gruvbox, Monokai and a custom one, with separate control over the dark and light colours, an accent that adjusts itself for contrast, and individual colours for headings H1 through H6. Typography options cover font family, base font size and line height, and layout options cover sidebar width, content width, folder indentation and item padding. Its design features include centered headings with coloured underlines, rainbow folders, styled blockquotes and tables, round checkboxes and a colourful calendar view, and full customization runs through the Style Settings plugin.
