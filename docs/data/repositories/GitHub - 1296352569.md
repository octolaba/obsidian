# windzu/windpost

Publishes the active Markdown note to a GitHub-backed blog, where publishing creates a commit through the GitHub API, or to a WeChat Official Account, where images and a cover are uploaded and a draft is created, leaving the final send a manual step in WeChat. Each publish converts the note for the chosen channel, shows a preview and asks for confirmation before any call is made, and each channel has a connection test. Initialization creates a content folder and two example articles without overwriting existing files, and credentials are kept in Obsidian's secret storage. It runs on macOS with Obsidian desktop 1.12.0 or later, reads only the active note and its attachments, and uses no relay, telemetry or browser automation.
