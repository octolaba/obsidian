# Vinzent03/tab-switcher

Tab Switcher, previously called Cycle Through Panes, adds commands for moving between Obsidian tabs. One group navigates in the order of the tabs from left to right and, unlike the native Obsidian commands, ignores panes and tab groups while working per window; the other navigates in the order tabs were last used and supports holding a modifier key between presses to keep iterating. The plugin sets no default hotkeys, leaving every binding to the user.
