# liuba1223/obsidian-english-assistant

English Learning Assistant combines grammar feedback, dictionary lookup and practice tools for English inside Obsidian. Its bilingual README describes AI-driven checking of grammar, spelling and punctuation with explanations and rewrite suggestions through providers such as OpenAI, DeepSeek, Moonshot or Ollama, optional offline lookup from an ECDICT or compatible CSV dictionary, a shadowing mode with real-time typing alignment and grammar highlighting, and Mermaid syntax trees for sentence structure. It also states that vocabulary, grammar notes and mistake logs can be saved into the vault, and that writing volume, mistake categories and practice activity are tracked for review.
