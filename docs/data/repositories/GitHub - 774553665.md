# wish5115/obsidian-ii-quicker

Inserts common Markdown and HTML constructs from slash commands, the command palette or the context menu, covering superscript and subscript, audio, video and iframe embeds, left, center and right alignment, variables, footnotes, callouts, anchor points and HTML comments. Dialog boxes collect the details for image, link and multimedia insertions, and a color panel offers a fixed set of highly distinguishable colors alongside arbitrary color codes. Each command can be switched off or hidden from the context menu, and custom commands can be defined to insert user-supplied code. The README states that time and date formatting uses the same format strings as the official formatting.
