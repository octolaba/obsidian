# FinickySpider/Obsidian-Copy-as-Plaintext

The repository holds Copy As PlainText, an Obsidian plugin that strips Markdown so a note can be copied to the clipboard as plain text. It adds a command to the editor context menu and the command palette and offers two stripping modes: a regex-based simple mode and an AST-based mode built on Unified and Remark with GFM support for tables, task lists, footnotes, math and frontmatter. The README notes that the advanced settings are ignored while Simple Mode is enabled.
