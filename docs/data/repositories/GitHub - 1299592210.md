# tristanvangarsse/relational-graph

Relational Graph visualises connections between notes based on shared context and on direct links, building its picture from an incremental index of the vault. The graph can be opened from the command palette and navigated interactively — nodes are dragged to rearrange the layout and clicked to open their note — while a toolbar filters which relationship kinds are shown. The README also records recency weighting, node styling and a project focus, with projects declared through a frontmatter property.
