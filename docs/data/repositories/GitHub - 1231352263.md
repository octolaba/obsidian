# hauntedhost/obsidian-open-zed

Obsidian plugin that opens the vault, a folder or a note in the Zed editor. A ribbon button and a command palette entry open the vault root, while the file and folder menu opens the selected item and, for the active note, jumps to the cursor's line and column. The README requires the Zed command-line tool to be installed and its absolute path confirmed in the plugin settings, and lists the usual binary locations for macOS, Homebrew and Linux.
