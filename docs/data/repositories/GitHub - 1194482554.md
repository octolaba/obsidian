# felixleopold/obsidian-code-suite

CodeSuite executes code blocks inside Markdown notes with streaming output, shared variables, inline Matplotlib or Plotly graphs, and support for multiple languages. It uses Shiki highlighting across Reading, Live Preview, and Source modes, embeds vault files, and exports rendered notes to HTML or PDF.
