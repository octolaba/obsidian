# rzrabbi/obsidian-johnny-decimal-manager

Johnny.Decimal Manager applies the Johnny.Decimal classification system inside an Obsidian vault, where areas numbered in tens contain numbered categories and categories contain numbered items, giving every note a permanent numeric address in the folder tree. Because the scheme lives in folder and file names rather than in metadata, the README argues the ordering also holds outside Obsidian, in other file explorers, in GitHub and cloud backups, and for agents reading the vault. Typing a target item identifier creates any missing area or category in the same step, and right-clicking a folder scans it and pre-fills the next available number for a new item. The author states that they did not create the Johnny.Decimal system and credits its official site for the concept.
