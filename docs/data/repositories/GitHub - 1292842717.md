# PhononX/cv-obsidian-sync

This repository holds Carbon Voice Sync, an Obsidian plugin that syncs Carbon Voice conversations and voice memos into a vault as Markdown notes. An account is connected with a personal access token stored locally in the vault and sent only to the Carbon Voice API, and the user chooses whether to sync all conversations, only those in selected workspaces, or a hand-picked set, with the same choice offered for voice memos. Import history is bounded by a configurable window of the last 7, 30, 90 or 365 days or all time, background sync runs on a configurable interval with an optional sync at startup, and transcripts are optional. The README states that the plugin talks to the API over the network and runs on both Obsidian desktop and mobile.
