# KreNtal/obsidian-auto-card-link

An Obsidian plugin that converts a URL into a card-styled link rendered from a code block rather than from HTML tags, showing metadata, a thumbnail and a favicon, with handling tailored to sites such as YouTube, Twitch, Reddit, GitHub, Wikipedia and Spotify. Cards can be created by pasting or from a selected URL, with hotkeys and a right-click menu to refresh, delete or add a line after one, and settings cover the card style, thumbnail side and quality, saving images and favicons into configured folders, and internal links for local images. The README describes its network use: metadata is fetched directly from the linked site, and only if that fails and the option is enabled is the URL sent to the third-party microlink.io service. The repository is a fork, and its description records the intent of fixing the older plugin.
