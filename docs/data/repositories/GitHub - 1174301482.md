# takeshy/obsidian-local-llm-hub

A local-only AI workspace for Obsidian: chat, retrieval over the vault, MCP servers and workflow automation all run against a model served on localhost by Ollama, LM Studio, vLLM or AnythingLLM. Chat history is stored as Markdown in the vault, the retrieval index as local embeddings in a workspace folder, MCP servers as local child processes over stdio, and edit history only in memory until restart. Workflows and agent skills can be described in plain language and generated by the model through a plan, generate and review cycle, with invalid YAML retried automatically and an option to copy the prompt to an external model and paste the result back. A visual node editor covers 23 node types across 12 categories, including variables, control flow, HTTP and JSON, note reading and searching, and file operations.
