# estrenuo/vault-companion-for-claude

Vault Companion for Claude runs a Claude chat inside Obsidian on iPhone, iPad, Android and desktop, with agentic access to the vault — reading, searching, creating and updating notes — and an approval card shown for every write. The open note is part of the context automatically and follows tab switches, while a context bar above the input pins or removes further notes. Two backends are documented: a direct call to the Anthropic Messages API with the tools implemented on Obsidian's own vault API, or a small Node relay running on a Mac with Claude Code installed that wraps the Claude Agent SDK behind a token-protected endpoint. The README states that the plugin is independent and not affiliated with or endorsed by Anthropic, and that it avoids the desktop-only child-process approach because mobile Obsidian has no Node runtime.
