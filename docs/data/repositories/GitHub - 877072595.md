# lizard-heart/obsidian-bottom-to-top-text

While this plugin is turned on, pressing enter adds a new line above the current one instead of below it. A command reverses all lines of text in the current note, and a further pair of commands turns reverse mode on or off note by note. The repository carries no description and the README says nothing else, so this summary rests on those three statements.
