# TracingOrigins/obsidian-buttons-panel-plugin

Buttons Panel adds a customisable panel of buttons to Obsidian for opening files, executing commands, visiting links or running scripts with a single click. Buttons carry icons searched from the Lucide library or supplied as custom SVG, are organised into categories, and are shown in a list, tabbed or folder view, the last an Android-style grid with drag-and-drop, auto-expand on hover, pinning and editable folder names. Three interaction modes separate viewing, drag reordering and editing, required fields are highlighted when empty, and changes take effect immediately without a restart. The README states that the panel adapts to Obsidian's light and dark themes and works on every platform Obsidian supports, and its documentation is offered in Chinese, English and Russian.
