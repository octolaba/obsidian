# graydon/obsidian-dangling-links

This plugin lists a vault's dangling links, meaning links written in a note that currently point at nothing, in a side panel opened by a command or a ribbon icon. The list can be grouped by the file or folder the links occur in, or shown as links with their references, each occurrence clickable to navigate to it, with items collapsible and folders ignorable from the settings page. The README frames dangling links as typos or notes not yet written, states that the plugin is only lightly maintained and points at an alternative, and notes that its stated minimum Obsidian version merely reflects the author's own.
