# mnaoumov/obsidian-better-markdown-links

Better Markdown Links makes Obsidian generate the angle-bracket form of Markdown link, which the Markdown specification allows and Obsidian understands but does not produce, so a path containing spaces stays readable instead of being percent-encoded. The plugin also manages relative links, which the README ties to a reported Obsidian problem with link resolution mode. A demo vault with usage examples ships with every release and can be opened from a plugin command, downloaded from the releases page, or browsed in the repository.
