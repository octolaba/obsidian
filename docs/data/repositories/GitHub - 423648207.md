# cooklang/cooklang-obsidian

Cooklang Editor adds Cooklang support to Obsidian: opening a .cook file and toggling Preview shows a recipe page with the title, description, a sibling title image and meta pills for total time, servings, difficulty, source and tags. A servings scaler rescales every ingredient quantity in real time, a two-column layout puts a sticky ingredient checklist beside the steps and stacks on narrow panes, sections group ingredients and steps, notes render as callouts, per-step images follow the Cooklang naming convention, and step tracking dims completed steps — each toggleable in settings. Recipe references written in ingredient syntax resolve relative to the containing recipe, opening a matching .cook file first and falling back to a same-path Markdown file only when its frontmatter carries a recipe flag.
