# adziok/obsidian-incremental-id

Generates sequential identifiers of the form prefix and number, such as DN-1 and DN-2, from prefixes declared in the plugin settings. An identifier is inserted through a command per declared prefix or from a Templater template by calling the plugin's insert function, with a second function that repeats the identifier already generated within the same template. The README states that the author built it to reference a specific note from commits while using the Kanban plugin.
