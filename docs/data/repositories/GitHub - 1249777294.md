# stefan-imbesi/obsidian-macos-theme

stefan-imbesi/obsidian-macos-theme holds macOS Tahoe, an Obsidian theme that applies Apple's design language to the app: translucent sidebars, modals, menus and command palette built from a backdrop blur and saturation filter over semi-transparent backgrounds, with an SVG noise texture and a top-edge gradient layered on to suggest frosted glass. Headings follow Apple's text style scale, the editor sits at 16px for reading and writing while the surrounding interface stays at the native 13px, and the README states that panel opacity drops further when Obsidian's translucent window mode is enabled.
