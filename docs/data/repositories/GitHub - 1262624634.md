# viggomeesters/obsidian-minimal-hidden-files

Minimal Hidden Files reveals a set of allowed dotfiles and dotfolders in Obsidian's native File Explorer without adding a sidebar, tree browser, preview panel or file manager of its own. It enables Obsidian's unsupported-file visibility setting while active and restores the previous value when disabled, while a hardcoded denylist keeps the vault configuration directory, the trash folder and the git directory hidden, along with SQLite write-ahead and shared-memory sidecars unless a diagnostic setting reveals them. The README records the plugin as desktop-only because it uses the desktop file-system adapter, states that it makes no network requests, uses no telemetry and reads or writes nothing outside the vault, and notes that a revealed file behaves like any other since no read-only mode is enforced.
