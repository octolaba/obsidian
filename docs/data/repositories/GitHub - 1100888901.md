# davidvkimball/obsidian-explorer-focus

Explorer Focus limits the Obsidian file explorer to one file or folder, showing only the focused item together with its children and ancestors. The README describes focus levels for the current file, its parent, grandparent or great-grandparent folder, or a fixed custom folder path, plus an option to hide ancestor folders so the focused folder appears at root level. Focus can be toggled from a command, a file explorer navigation-bar button or the right-click menu on any file or folder, and the plugin is described as a fork of the Simple Focus plugin and part of the Vault CMS project.
