# Quietbyday/obsidian-yt-links

YT links cleans up YouTube links pasted into notes through four functions, each available as a command and, for three of them, on paste. It strips a leading notification count such as (62) from a link title, turns a YouTube URL carrying a t or start parameter into a Markdown link showing the time, converts bare time notations like 2:34 into links into the note's source video, and removes or rewrites hashtags in a video title. The source video is read from a frontmatter property, defaulting to source, and nothing inside frontmatter, code, existing links or URLs is touched. Each function can be toggled off.
