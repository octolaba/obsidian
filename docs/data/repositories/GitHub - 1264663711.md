# wonkwonlee/gotsaeng-os

GotSaeng OS scans a local Markdown vault, classifies notes, and compiles auditable Markdown and JSON context packs without cloud services, telemetry, or LLM calls. It extracts facts, decisions, actions, risks, assumptions, questions, and insights, then reports provenance, confidence, memory differences, stale context, and contradiction candidates for human review.
