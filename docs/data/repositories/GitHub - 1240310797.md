# kriss-spy/obsidian-opencode

Obsidian plugin that embeds the OpenCode command-line tool in an integrated terminal inside the vault. The agent is spawned in the vault root, and files dragged in from the file explorer are inserted as path mentions for it. A session manager lists past sessions with their timestamps and working directories, previews message history, token usage, model and cost before resuming, restores a session in one click, and exports a conversation thread as a note. The README records Linux as the author's tested platform, Windows support as beta through ConPTY with Node available on PATH, and macOS as experimental.
