# RobertoJarquinRR/Media-Gallery-view

Media Gallery renders a gallery of video and image files inside an Obsidian note from a MediaGallery code block that names a folder path and an optional type, defaulting to video. Every matching file in the folder is laid out as a grid of cards: hovering a video card reveals playback controls, clicking an image card opens a fullscreen lightbox, and double-clicking any card opens the underlying file in a new tab. The README lists audio and PDF support as unfinished roadmap items and notes that the gallery uses the default HTML5 player for performance.
