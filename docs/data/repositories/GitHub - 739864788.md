# gapmiss/copy-as-source

Copy as Source copies the underlying HTML of a selection made in Obsidian's reading view. The selected elements' source HTML is formatted with prettier and placed on the clipboard by the Copy selection source command, which the README asks the user to bind to a hotkey because the selection is made in reading view.
