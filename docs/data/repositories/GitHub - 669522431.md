# Emile-Durkheim/obsidian_discord_formatter

Repository for Discord Message Formatter, an Obsidian plugin that converts Discord conversations copied or dragged from the desktop client into Obsidian Markdown on paste. It carries over usernames, message times and message text for whole conversations rather than single messages, converts Discord markup such as underline, bold, quotes and strikethrough, embeds attachments, custom emojis and websites, and offers settings for the datetime format and for whether replies, edit markers and system messages are included. The README states that the plugin depends on the HTML Discord usually puts on the clipboard: in about ten percent of cases only raw text arrives and cannot be parsed, and a right-click copy never works.
