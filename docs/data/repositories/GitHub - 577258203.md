# darrenkuro/obsidian-basetag

Obsidian plugin that renders only the basename of a tag in preview mode while the nested structure is kept elsewhere. It appends a basename-tag class so that the rendered tag can be styled with custom CSS, and its version notes record support added for editor mode including tags in the frontmatter, and later for tags in properties. The README states that the plugin is not actively maintained, that issues are not guaranteed to be resolved promptly, and invites pull requests.
