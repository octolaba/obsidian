# Veltrix42/vault-timeline

Vault Timeline builds a global chronological timeline of a vault by scanning every Markdown file and indexing it from frontmatter dates, presented as an interactive zoomable axis. The README documents day, week, month, year and decade zoom levels, colour groups assigned to tags with an event taking the colour of its first matching tag, duration bars for notes carrying both a start and an end date, full-text and tag filtering, a minimap of all events with a draggable viewport indicator, hover tooltips showing title, date, excerpt and tags, click-through to the note, a right-click menu, and automatic refresh when notes change. It lists the accepted date formats, names the configurable frontmatter field, and states that a note without a date field falls back to its file creation time.
