# Dyse-Sofqi/MDRazor

MDRazor enhances Obsidian's Markdown editing experience through independently configurable modules. It can hide Markdown and selected HTML markers until the cursor enters them, visualize spaces, show marker-boundary tooltips, focus nested lists and folders, improve list and tab behavior, display folder counts, and clean up unreferenced images with confirmation. The README describes separate settings for hidden styles, list enhancements, tab enhancements, status-bar enhancements, and orphaned-image cleanup.
