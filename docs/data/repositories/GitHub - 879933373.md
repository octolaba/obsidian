# D4rkP1xel/daily-random-note

Repository for Daily Random Note, an Obsidian plugin that reopens earlier notes at random so that past writing resurfaces. Random instances are configured with the folders to query and optional tag filters, and each instance opens a random matching file at a time of day chosen by the user, with all of them opening in new tabs at that reset time. A ribbon icon opens a random note on demand for anyone who does not want the daily behaviour, and the author states that the plugin was built around their own needs and invites bug reports and contributions.
