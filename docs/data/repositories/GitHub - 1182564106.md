# saltyfireball/obsidian-save-as-local-images

Save as Local Images downloads the remote images referenced by a note into the vault and rewrites every occurrence of the remote address to point at the local copy. The README states it runs over a single note from the command palette or recursively over a folder from the file explorer, saves into the configured attachment folder nested by the note's path, and handles Markdown, HTML and wiki embed syntaxes as well as bare image addresses in frontmatter properties. It also records that each download gets a twelve-character random filename, that the file extension is taken from the content type header with the address as a fallback, that local paths containing spaces or brackets are wrapped so the link resolver handles them, and that a failed download is reported individually without stopping the rest.
