# lanjak/obsidian-postgres-sync

Postgres Sync synchronises an Obsidian vault across devices through a self-hosted Postgres database instead of Obsidian Sync, iCloud or a CouchDB setup, and embeds every note so the same table doubles as a semantic search index that can be queried from outside Obsidian. Because Obsidian mobile cannot open a raw database connection, the README states that the plugin speaks HTTP or HTTPS to PostgREST in front of Postgres, which needs the pgvector extension and the repository's SQL schema applied with a real bearer token replacing the seeded default. An embedding server speaking the llama.cpp embedding endpoint must also be reachable from every device; the schema assumes 768-dimension vectors, and the README says the column dimension is changed before first use to match another model.
