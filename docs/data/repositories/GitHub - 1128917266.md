# Suika556/inline-color-swatch

Inline Color Swatches shows a small colour preview beside supported CSS colour values written in inline code spans. Following GitHub Flavored Markdown behaviour, inline code spans are handled and fenced code blocks are deliberately excluded. Supported formats are hex in three-, four-, six- and eight-digit forms plus rgb, rgba, hsl and hsla notation, matched without distinguishing letter case; the README notes that a value may not carry leading or trailing whitespace inside its backquotes. Previews are shown for the default appearance and for the Minimal and Things themes in both light and dark mode.
