# tillahoffmann/obsidian-file-include

Inserts the contents of another file into a note through an include code block holding a path. Adding a language name after the word include applies syntax highlighting to the included text. Paths resolve relative to the Markdown file, and a path prefixed with the at-sign and a slash resolves from the vault root instead. No repository description is recorded, so this note is grounded in the README alone.
