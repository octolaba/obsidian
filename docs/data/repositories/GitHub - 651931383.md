# SalokinGreen/NAI4Obsidian

NAI4Obsidian is an Obsidian plugin that generates text with NovelAI while writing in a note. Two commands drive it, generate and retry, each needing a hotkey assigned in settings, and almost all of NovelAI's own generation settings are exposed, with biases, bans, EOS and a custom whitelist named as missing but planned; a simplified lorebook is included. It needs a NovelAI subscription and an API key, entered manually or produced by a get-key command from an email and password, and the README notes NovelAI's persistent API token as a longer-lived alternative. The README states that the author is not affiliated with NovelAI.
