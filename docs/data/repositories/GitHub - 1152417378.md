# Marvive/scripture-linker

Scripture Linker scans Obsidian notes for Bible references and rewrites them as links to Logos Bible Software and Bolls Bible. The README describes detecting references in several written forms, resolving shorthand such as a bare chapter-and-verse after a book has been named, recognising over 500 book-name variations, and leaving references that already sit inside a Markdown link untouched. Commands scan the whole file or only the selection, a ribbon icon triggers a file scan, and settings choose the default translation among the eight listed, the link service, and whether the ribbon icon is shown.
