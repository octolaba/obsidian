# Leonezz/tasks-timeline-obsidian

Tasks Timeline displays and manages the task items of an Obsidian vault, and the README presents it as a continuation of the author's earlier tasks-calendar-wrapper plugin built on a separate components library. It also embeds a Model Context Protocol server, disabled until switched on in settings, which listens on a configurable local port and lets an external client read and write the vault's tasks. The README lists tools for querying, creating, updating, deleting, completing, cancelling and batch-updating tasks as well as aggregate statistics and a today plan, alongside read-only resources for all, overdue, today's and upcoming tasks. Bearer-token authentication is recorded as enabled by default, with the token shown in the plugin's settings.
