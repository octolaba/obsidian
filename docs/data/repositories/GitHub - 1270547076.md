# Sonophage/stardust-importer

Stardust Importer pulls watched films from Trakt and full-album listens from Last.fm into notes rendered by the user's own Templater templates. Films come from Trakt's movie history endpoint, so television never enters, and a re-watch updates the existing note's fields instead of creating a duplicate; album listens are reconstructed from Last.fm scrobbles by a session detector that counts a gap-bounded sitting as an album listen when one album dominates it and a coverage threshold of its tracklist was played. Rather than owning the note schema, the plugin hands a payload to the template through a filename-keyed handshake that the template's opening block reads, so the same template still serves manual note creation; the album template picks the closest MusicBrainz release group and, on a low-confidence match, flags the note for review.
