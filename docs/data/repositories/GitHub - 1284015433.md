# ElmoNeedsArson/space-news

Space Launches tracks upcoming rocket launches and space events from inside Obsidian. A sidebar panel, opened from the rocket icon or the command palette, lists countdowns, providers, locations and status, with filters for launch providers, locations and event types and an optional notice 15 minutes before a tracked launch. The README records launch and event data as supplied by The Space Devs through Launch Library 2, and states that the plugin is not affiliated with them.
