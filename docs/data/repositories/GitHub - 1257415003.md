# sertacyildiz/obsidian-google-sync

Google Sync synchronizes a vault with a Google backend the user owns, either a personal Google Drive or a Google Cloud Storage bucket, with no intermediate service. Synchronization runs both ways, deletions propagate, and a conflict keeps both copies; sync state is tracked outside the notes, so Markdown files are not rewritten with plugin metadata, and content encryption is optional. The plugin ships with no OAuth credentials of its own: a Google OAuth desktop client is created by the user and pasted into settings, where it stays in the vault's plugin data, and sign-in uses a loopback flow with PKCE. It is desktop-only and requires Obsidian 1.13.0 or newer, and sign-ins made with the shared client bundled in versions up to 0.6.x can no longer be refreshed.
