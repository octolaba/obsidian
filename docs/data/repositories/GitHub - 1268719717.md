# Thive-N/Orion

Obsidian plugin for vault upkeep whose current function is stale note detection: a command scans the vault and opens a modal listing every note not modified within a configurable window, seven days by default. The README states that the plugin changes no content and is strictly read-only in this version. It also lists checks that are planned rather than built — orphaned notes without backlinks, empty or incomplete notes, TODO aging, unprocessed inbox notes, and a vault health dashboard.
