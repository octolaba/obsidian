# ITNQ18/obsidian-task-manager

Task Manager organizes daily work reports and the tasks inside them from a compact right-sidebar view in Obsidian. The README records creating or opening today's report without overwriting an existing note, a configurable report folder, filename pattern, template and title, and recognition of renamed reports whose filename still carries the matching year, month and day. It collects standard Markdown checkbox tasks from those reports, separates recent unfinished, long-unfinished and explicitly overdue items, treats yesterday's tasks as today's planned work, keeps future tasks in one configurable file using date and time markers, and writes a completion timestamp back to the source note when a task is ticked. The plugin is recorded as following Obsidian's language with manual overrides and working entirely in the local vault without telemetry or network requests.
