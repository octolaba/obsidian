# GammaFunds/german-law-lookup

Looks up legal references for Germany, Austria, Switzerland and a multilingual data-protection pilot, previews the retrieved text and inserts it into the active note only after an explicit action. The German scope covers selected federal laws retrieved through the Gesetze im Internet provider, the Austrian scope exactly twenty-four federal laws through RIS, and the Swiss scope article references for twenty-three federal laws through Fedlex, with identically abbreviated German and Austrian laws kept apart by jurisdiction. Source, citation, retrieval date, jurisdiction, language and cache metadata can be included, and successful lookups are cached locally. The README states that only explicitly mapped laws and reference forms are supported, that published English text is used only where configured, and that the plugin never generates translations.
