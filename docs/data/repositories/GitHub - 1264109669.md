# lugji-app/obsidian-lugji

An optional companion plugin for Lugji, an iPhone app that records meetings, transcribes them on the device and writes a Markdown note straight into a chosen vault folder; the README stresses that the notes arrive without this plugin and that it only adds convenience on top. It contributes a side-pane panel showing a meeting's date, language and duration, a four-tier linking cascade that turns topics and attendees into links, adds the day's daily note and surfaces links already present in the transcript, a meetings dashboard rendered from a code block without Dataview, and a banner when a note's schema version does not match the plugin's. A command and ribbon icon open the iOS app at a new recording, and the README lists Obsidian 1.4.0 or newer, the Lugji app and iCloud Drive as requirements.
