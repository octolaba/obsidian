# Txoldi/obsidian-lastfm-plugin

Obsidian plugin that pulls data from the Last.fm API and creates notes from it. Through a tabbed modal opened from a ribbon icon it fetches recent scrobbles with a selectable track count, top tracks, artists and albums over a chosen period, and weekly charts based on Last.fm's own weekly ranges, including album artwork for recent plays and top albums. The fetched data is written as Markdown notes into a folder chosen in the settings, which also hold the user's Last.fm API key and username.
