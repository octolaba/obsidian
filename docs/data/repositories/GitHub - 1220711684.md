# yan-istart/IStart-Note-AI-Plugin

IStart-Note-AI organises an Obsidian vault through three modules the README names Knowledge, Execution and Auxiliary, reached from one AI entry point. The knowledge module writes question-and-answer notes with concept extraction, classifies questions as new, refinement or expansion, maintains concept pages and domain indexes, builds reading projects with chapter questions and summaries, searches the vault through a metadata index rather than embeddings, and reports gaps such as empty concepts and orphan questions. The execution module models multi-operation vault changes as plans, stores drafts for review, logs applied plans, and by default never executes automatically. The README marks version 2.0.0 as beta with an unstable frontmatter schema, advises a backup before upgrading, and describes an OpenAI-compatible provider defaulting to DeepSeek.
