# okkio-31mon/epub-reader-highlighter

EPUB Reader and Highlighter opens .epub files in the vault for reading inside Obsidian, in scrolling or paginated mode, and remembers the reading position between sessions. The README states that the book is pre-paginated in the background for the current window size and font so the page count stays fixed and each turn advances by one, with the result cached until the window or font changes. Text can be highlighted in several colours from a popup or a default-colour hotkey, annotated with notes, listed in a highlights panel with page numbers for jumping back, editing or deleting, copied as quote blocks, and undone; five reading themes plus a custom colour picker and adjustable fonts are provided.
