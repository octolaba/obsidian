# Creling/obsidian-activity-logger

Activity Logger writes a log of vault activity, covering notes created, modified and deleted, into the current note. The log is inserted between a configured start line and end line, and re-running the command updates the existing entries instead of adding duplicates. A template with three variables for created, deleted and modified files controls the output, and any other characters on a variable's line are kept, so a list marker or a link wrapper is applied to every entry. The README suggests placing the start and end markers on existing headings so the markers themselves stay out of sight.
