# Kigrok/api-key-checker

AI API Key Checker validates API keys for 21 AI providers from inside Obsidian by calling each provider's real API rather than matching a pattern. It distinguishes an invalid key from a valid key that has exhausted its quota, reports when a rate limit resets, and can check dozens of pasted keys in one pass. Results sort broken keys first, show a masked key that can be clicked to copy or hovered to reveal, and carry a per-provider last-check time next to a summary count.
