# podviaznikov/notes-exporter-obsidian

This plugin connects a vault to the separate Notes Exporter application, which writes Apple Notes, Bear and Logseq notes out as Markdown that the vault then contains. It reads the source address written into frontmatter by that export and adds native application integration: icons on the corresponding links in reading view, live preview and the properties panel, open-in-application entries in the file and editor menus, a tab header button and a status bar entry. A sidebar panel reads the run report each export folder carries and shows, per source, how many notes were exported, when, in which format, and which files or attachments failed.
