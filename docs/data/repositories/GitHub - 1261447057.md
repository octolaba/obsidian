# Radegast546/links-with-icons

Obsidian community plugin that displays native operating system file icons beside local file links and website favicons beside web links, in both Live Preview and Reading view. Internal wikilinks, external file paths and folders receive application or folder icons, external web links receive the site's favicon, and clicking the icon navigates to the target or opens the file or URL. Icons are sized in relative units so they scale with font size and zoom, and are adjusted automatically depending on whether the link sits in body text or in a heading. The README states that Obsidian's own Lucide icons serve as a cross-platform fallback on non-Windows platforms or when favicon extraction fails, that background work is capped at five concurrent runs and that cache writes are debounced.
