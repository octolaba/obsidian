# GoSlowPoke168/obsidian-clean-ai-paste

Obsidian plugin that reformats text pasted from AI chat interfaces such as ChatGPT, Claude and Gemini. The README states that it intercepts the paste event, converts the clipboard HTML to Markdown, and applies a configurable set of formatting rules before insertion, addressing excessive blank lines, malformed code blocks, over-bolded headers, broken LaTeX math and emojis. A before-and-after table shows headers stripped of bold, blank lines collapsed and code fences given their language.
