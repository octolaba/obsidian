# Raboro/obsidian-expiration-date-tracker-plugin

Obsidian plugin that tracks expiration dates of items such as groceries. Items are written as rows of a Markdown table carrying a name, a date and a number of elements, in a file whose location is set in the settings; running the ribbon action or the tracking command collects that data into a separate view grouped into expiration categories with expandable item lists, shows the days left per item and gives notice of the ones already expired. Commands also search for a single item or category and show the result in a modal, and the date format used for parsing and display is configurable.
