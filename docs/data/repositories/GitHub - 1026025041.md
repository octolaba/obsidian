# beimohai/Easy-Bookkeeping-Obsidian

A local bookkeeping plugin that stores every transaction as Markdown inside the vault and depends on no third-party service. Desktop entry runs as a single-input keyboard workflow over date, account, type, necessity, category, attachment, description, amount and notes, while mobile uses a touch form, with the device detected automatically or chosen by hand. Amount fields accept arithmetic expressions such as 11.4+5.1-4 and reject input with invalid characters or more than two decimal places. A dashboard reports monthly income, expenses, net balance and transaction count beside trend, calendar and pie charts, tag summaries, budgets and account balances, with CSV transfer between devices and an interface in twelve languages.
