# tgrosinger/advanced-tables-obsidian

Advanced Tables adds navigation, formatting and manipulation to Markdown tables in Obsidian, auto-formatting a table as it is typed and moving between cells and rows with Tab and Enter the way a spreadsheet does. Columns and rows can be added, removed and moved, column alignment set to left, center or right, rows sorted by a chosen column, and the table exported to CSV. The README also records spreadsheet formulas, documented in the project's own help docs, a table controls sidebar, many further commands in the command palette, and that the plugin works on Obsidian Mobile.
