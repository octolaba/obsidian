# bucknatt/mitsu-plugin

Miku Hybrid bundles Hatsune Miku-inspired styling into an Obsidian plugin, so no separate Appearance theme is needed: releases fold the palette CSS into the plugin's own stylesheet. It provides four theme modes named MinimalMiku, Concert, NightNeon and SnowMiku, cycled from a ribbon icon or a command, optional status bar, banner, quote and profile widgets, a dashboard view with original ASCII decoration presets, and settings for reduced motion and glow intensity. The README records that the plugin ships no audio assets, APIs or dependencies, and that its visuals are fan-inspired rather than official Crypton Future Media artwork.
