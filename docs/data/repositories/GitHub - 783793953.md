# OneCalmCloud/obsidian-mindmap

Obsidian Mindmap is a plugin for creating mind maps in Obsidian, based on the vue3-mindmap library. A map file is created by right-clicking in Obsidian's file list on the left and choosing the command for a new mindmap. The README is short and offers an English and a Chinese version.
