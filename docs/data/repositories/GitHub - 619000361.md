# rusi/obsidian-colorful-note-borders

Colorful Note Borders draws a colored border around a note so that notes can be told apart and grouped by rule. Two rule types are supported: folder-based rules, which color notes by their location — the README's example is a green border for notes in an Inbox folder — and frontmatter metadata rules, which color notes carrying a given property, such as a red border where the frontmatter says private is true. Rules are added, edited, removed and re-ordered on the settings page.
