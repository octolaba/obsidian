# ericquan8/obsidian-gitee-sync

This repository holds Gitee Sync, whose README describes storing an Obsidian vault as ordinary files in a private Gitee or GitHub repository by calling the platform API directly, with no server and no local Git installation, on desktop, iOS and Android. The sync engine is described as comparing Git blob hashes across the local vault, the remote repository and the last successful device-local baseline, giving incremental two-way sync, deletion propagation, conflict resolution, dry-run previews and diagnostic logs, with the newer modification winning when both sides change one file. The README requires a personal access token on either backend, and records an interface in English and Chinese that follows Obsidian's language. No upstream repository description is recorded, so this body rests on the README alone.
