# cybrcore/cybr-obsidian

cybr is an Obsidian theme configured almost entirely through the Style Settings plugin, which its README lists as a prerequisite alongside the Geist Mono Nerd Font. Colour is organised into three assignable roles: primary drives text, headings, tags and active states, secondary drives interactive elements, navigation and buttons, and tertiary drives external links, with separate control over H1 to H6, blockquotes, properties, the status bar and the colours of eight top-level folders in the file explorer. The background is either one of eleven bundled wallpapers or a solid palette colour. Built-in focus and hider modes collapse the sidebars and hide chrome such as the ribbon, sidebar toggles, status bar, scrollbars and tooltips, while link underlining, image grids and card column count are toggled separately.
