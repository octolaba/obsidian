# AriaYD/obsidian-image-markdown-link

Image Markdown Link rewrites image links that Obsidian generates on paste into standard Markdown image syntax, so the note renders in Markdown tools outside Obsidian. Depending on vault settings Obsidian inserts a wiki-style embed or a bare link, and the plugin intercepts the paste and converts each of those forms to the standard form, leaving an already-correct link unchanged. It handles attachment folders at any depth, covers the PNG, JPG, JPEG, GIF, WebP, BMP, SVG and AVIF extensions, and the README states that non-image wiki links are never modified. The README is published in English and Chinese.
