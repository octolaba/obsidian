# community-archive/obsidian-easy-bake

Obsidian plugin that compiles several notes into one document, run through a bake command in the command palette. Links and embeds that stand on their own line are replaced by the contents of the target note, inline links are replaced by their link text, and the process recurses into the notes it pulls in. The README states that the plugin is deliberately focused on simplicity and points at the longform plugin for more complex compilation scenarios.
