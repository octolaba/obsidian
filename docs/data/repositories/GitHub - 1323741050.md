# brianpenghe/canvas-project-autofit

Canvas Project Autofit zooms an Obsidian canvas when it opens so the board fills the viewport width, pinned to the top, leaving lower rows off-screen instead of shrinking everything to fit. Auto-fitting is limited by default to canvases whose path starts with a configurable prefix, and the framing can be reapplied to the active canvas with a Fit canvas to width command. Settings cover the path prefix, the fraction of board width to frame and the padding above the content, plus an option to open external links from text cards with a single click. The plugin overrides the canvas zoom-to-fit behaviour while it is active and is written in plain JavaScript with no build step.
