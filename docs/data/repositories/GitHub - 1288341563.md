# myeongsoyi/obsidian-docket

Repository for Docket, an Obsidian project-management plugin that organises work as projects, tasks and subtasks, each identified by a frontmatter type and linked to its parent. The recorded description names status, deadlines and Gantt, WBS and board views; the mostly Korean README adds that a task's status is rolled up from its subtasks instead of being set directly, and that Gantt bars are derived from backlinks to a task in daily notes. It ships project, task and subtask templates and states loose interoperation with the Almanac plugin through frontmatter conventions while also working alone.
