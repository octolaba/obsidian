# MartinoPolo/obsidian-auto-reveal-in-explorer

An Obsidian plugin that reveals the active file in the File Explorer when tabs are switched or files opened, without moving keyboard focus out of the editor. The README explains the motivation: the built-in file-explorer:reveal-active-file command hands focus to the explorer, so a Delete pressed right after a file switch can hit the revealed file; this plugin instead manipulates the explorer view's tree directly. It offers a configurable debounce delay and a manual reveal command, and states that it works on desktop and mobile while noting it is not yet published in the community plugin browser.
