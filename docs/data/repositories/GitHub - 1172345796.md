# tsubasaogawa/obsidian-plugin-flexible-title-text

Flexible Title Text is an Obsidian plugin that customizes the window title bar text from a template set in its settings tab. The template supports a vaultName variable that expands to the name of the current vault, so a title such as the vault name followed by a suffix can be composed. The README also documents that each release build of main.js carries a GitHub artifact attestation, which can be verified with the gh command to confirm the file came from the official release workflow.
