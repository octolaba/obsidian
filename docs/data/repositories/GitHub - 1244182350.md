# mingjuner123-spec/wechat-inbox-sync

Pulls content collected in a WeChat mini program into a local Obsidian vault as Markdown notes and attachments, serving what the README calls a send now, organize later workflow. Text snippets and raw links go into dated inbox notes, supported webpage links become Markdown snapshots, and Feishu documents, WeChat public-account articles and Xiaohongshu notes are saved when their public page content is available. Audio attachments are stored and optionally transcribed through a provider the user configures, transcripts are extracted from some video links when subtitles or a transcribable media URL exist, and uploaded files are kept as attachments with Markdown extracted from txt, md, docx and text-based pdf. The README states that the plugin is desktop-only because it writes local binary attachments, and that it requires the mini program's CloudBase sync API and a bind code.
