# p1tt1/obsidian-dataview-toggle

Dataview Toggle pauses and resumes Dataview's automatic refresh from a status bar item, a command palette entry or an assigned hotkey. The README explains the motivation: with Dataview queries in a note, every keystroke re-renders the blocks, so the refresh is paused while writing and resumed afterwards, at which point all views refresh immediately. A frontmatter property overrides the global setting for an individual note while it is open, and the override is dropped again when navigating away. Dataview itself must be installed and enabled.
