# kelen-argosi/progressive

Progressive displays a progress bar in the Obsidian file explorer sidebar showing what percentage of tasks across notes is complete. It supports daily, weekly, monthly and custom note types and can track the latest note, today's note, a chosen custom note, or every note in a folder, updating automatically when notes are modified. The bar's colour moves through twelve levels with completion and also offers black-and-white and theme-based visuals. The README contrasts it with progress-tracker, which is embedded inside individual notes, whereas this plugin is a passive sidebar overview needing no embedding or commands.
