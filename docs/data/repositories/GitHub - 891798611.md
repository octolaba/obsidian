# Fleker/setlist-for-obsidian

Setlist for Obsidian uses the setlist.fm API to sync the concerts a user has marked as attended into a note in the vault. Running a command to sync attended concerts fetches the data and writes it as a bulleted list into a file named for the concerts attended, with each line naming the artist and venue and carrying backlinks for the city and for the date. The README states that the user has to supply their own API key.
