# Unpreditable/GettingThingsDone

GTD Tasks organizes Markdown tasks into configurable time-horizon buckets such as Today, This Week, Next Week, and Someday. A sidebar panel supports search, checkbox completion, drag-and-drop or quick moves, subtask tracking, overdue flags, and optional integration with the Tasks plugin.
