# Unpreditable/GettingThingsDone

The repository holds GTD Tasks, an Obsidian plugin that groups Markdown tasks into Getting Things Done time-horizon buckets shown in a sidebar panel. The README records default buckets — To Review, Today, This Week, Next Week, This Month and Someday or Maybe — each with a date rule, moves between them by quick-move buttons, drag and drop or a context menu, and buckets customisable in name, emoji, date rule and quick-move targets. Bucket assignment is stored as an inline tag or an inline field, scanning is scoped to the vault, chosen folders or chosen files, and due dates read from the Tasks plugin assign a task automatically. Also recorded: separate tracking of indented subtasks, a search filter, a stale indicator, a status bar count and localisation into 13 languages.
