# qf3l3k/obsidian-data-fetcher

Repository for Data Fetcher, an Obsidian plugin that queries external endpoints from `data-query` code blocks and renders the result inside the note. REST, GraphQL, JSON-RPC and gRPC-style HTTP proxy endpoints are addressed either by a direct JSON request or by a reusable alias configured in settings, with custom headers for authenticated APIs and a test action before saving. Output is shaped by dot-path selection and rendered as JSON, a table or a Markdown template, and it can be copied, saved as static Markdown in the note, or written into the note's frontmatter. Responses are cached with a configurable expiration and the cache can be browsed, filtered or cleared, while endpoint aliases can be exported and imported with headers excluded by default.
