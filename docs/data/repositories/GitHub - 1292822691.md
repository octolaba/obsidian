# kebl3541/Obsidian-Google-Drive-Merge-Sync

This repository holds Google Drive Merge Sync, described upstream as a Google Drive vault sync that runs on the user's own credentials, resolves text conflicts by a word-level three-way merge, and sends deletions to the trash on both sides. The README contrasts that with sync tools which either produce a conflicted copy or silently pick a winner: here the two versions are merged word by word, and only where both sides changed the same words is the local text kept and the fact reported. The remainder of the README is installation detail and donation links.
