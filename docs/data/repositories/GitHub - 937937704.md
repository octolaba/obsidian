# d7sd6u/obsidian-auto-folder-note-paste

Obsidian plugin that converts a note into a folder note when an attachment is pasted or dragged into it, so the attachment is placed inside the note. The README states that it requires the Obsidian option for the default location for new attachments to be set to the same folder as the current file. It also lists the author's other plugins, which share the same notion of folder or index notes.
