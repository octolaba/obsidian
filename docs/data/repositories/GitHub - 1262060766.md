# wikty/obsidian-table-exporter

Table Exporter exports a rendered Markdown table or a Bases view from the active note to PNG, CSV, Excel or PDF, working from what is rendered rather than from the source and preferring the table that was last hovered or clicked when a note holds several. The README describes scroll-stitching for the virtualised Bases Cards and List views: the container is scroll-walked, each viewport is captured, and the chunks are stitched using geometry and pixel overlap detection, so a fifty-card Base exports in full instead of only its visible area. It records a progress notice during the walk, an abort when scroll-position drift is detected, a truncation marker at the safety cap, and Bases Map export deferred because its MapLibre WebGL layer cannot yet be captured reliably.
