# chalas-ch/obsidian-contextual-guides

The repository holds Contextual Guides, an Obsidian plugin that displays a chosen guide note in the right sidebar when the active note matches a configured rule. A rule combines required tags, folders, properties and property values with the path of the guide note, and the sidebar renders that note together with its frontmatter above the content. Clicking a guide property name adds the missing property to the current note and clicking a value adds it or, after confirmation, replaces a single-value property, and a button opens the guide in a foreground tab.
