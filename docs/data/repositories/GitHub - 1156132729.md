# jash101/calsync

CalSync reads to-do items from Obsidian notes and creates matching Google Calendar events whose duration comes from a parenthesised estimate on the task line, with an optional second parenthesis recording the actual time. Running the sync command for one file or for all files creates events for incomplete tasks stacked one after another from a fixed start time, updates the event when a task's text or duration changes, removes the event when the task is deleted, and rewrites the description of completed tasks with the estimated time, the required time and their ratio. The README states that a Google account and a Google Cloud project with the Calendar API enabled and OAuth credentials are required, and that the plugin is desktop only because it runs a local HTTP server for the OAuth flow. Its network disclosure names Google OAuth and the Calendar API as the only remote services contacted.
