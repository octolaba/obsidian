# robertobissanti/obsidian-synthwave-pro

Synthwave Pro is an Obsidian theme with a vaporwave and retrowave palette, built for people who spend long hours at the screen. Its stated rules are never pure black and never pure white, a deep indigo background with warm off-white text, neon reserved for headings, links, focus and syntax highlighting, and WCAG AA contrast on body copy. Retro effects such as glow, a perspective grid and CRT scanlines are off by default and toggled from Style Settings, which also exposes the Synthwave, Outrun, Miami, Tokyo Night and Soft Reading palettes, three background depths, typography controls and accent overrides. Headings default to monospace with hash prefixes, and code blocks take a neon left border.
