# Real-Fruit-Snacks/terminal-workbench-pet

Terminal Workbench Pet adds a small floating ghost to the Obsidian workspace that drifts around on its own, peeks at headings and code blocks, moves away from the cursor, naps in a corner when the user is idle and recolours itself when clicked. The README records three modes, floating freely, following the cursor at a short distance, and off, each settable in the plugin settings or bound to a command, and says the ghost can be picked up and flung anywhere. It is presented as the companion to the Terminal Workbench theme, matching that theme's palette by default while working with any theme.
