# AlcatrazYU/obsidian-cjk-academic-count

Obsidian plugin that counts academic characters in Chinese, Japanese and Korean writing as a supplement to Obsidian's built-in word and character count. The README defines its main metric as Han characters plus Hiragana, Katakana and Hangul, excluding punctuation, numbers, Latin letters and whitespace, and states that YAML frontmatter and common Markdown markup are ignored by default. The count is shown in the status bar for the note or for a selection, with further reference metrics in the tooltip, and the interface follows Obsidian's language setting in English, Chinese, Japanese and Korean.
