# xuxiaominger/obsidian-skim-highlights

Skim Highlights polls the Skim PDF reader every 1.5 seconds from inside the note-taking app and, on each new highlight, copies a Markdown quote callout to the clipboard carrying the page number and a link back to that page. The card is pasted into any note, and clicking its page link jumps back to the exact PDF page. Listening is toggled from a status-bar indicator, a ribbon icon or a command, and the README records the plugin as requiring macOS, because it talks to Skim through AppleScript, plus an installed Skim and the desktop app rather than mobile.
