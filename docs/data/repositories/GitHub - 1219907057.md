# fszlnwr/obsidian-lark-wiki-sync

Obsidian plugin that syncs one or more Lark Wiki spaces into a vault, delegating authentication, scopes and API coverage to the lark-cli tool and adding the Obsidian-side interface: a ribbon button, a setup wizard, link pasting, conflict-aware sync and image download. Each configured space lives in its own subfolder under a single local root, a pull walks the whole node tree with pagination, Lark-flavoured markup is converted into GFM tables and clean Markdown, and inline images are downloaded into an attachments folder and embedded. Per-file hashes drive a three-way diff that classifies each file as skip, pull, push, conflict or reconcile, and every sync pauses on a plan modal grouped by space. The README records the version as 0.0.10, with push unverified end to end and the conflict modal still falling back to a sidecar file.
