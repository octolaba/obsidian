# CosmicSeaFox/Aether-Core

Aether Core is a handcrafted Obsidian theme with a dark mode of deep layered surfaces and soft accent lighting and a light mode of warm panels with mineral borders. Tables share one background with soft borders and hover feedback instead of zebra striping, properties are drawn as part of the same surface system rather than as separate interface, and callouts are structured panels with restrained emphasis. Code blocks, the graph view and reading and source modes follow the same low-glare treatment, with a balanced content width for long-form reading.
