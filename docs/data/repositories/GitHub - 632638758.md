# FabianUntermoser/obsidian-neighbouring-files-plugin

Navigate to Neighbouring Files is an Obsidian plugin adding commands that move to the next or previous file in the current directory, for cases such as stepping from one weekly or daily note to the next or through sequentially numbered notes. Beyond the default next and previous commands it offers alphabetical, creation-timestamp and modification-timestamp variants, plus folder up, folder down, next folder and previous folder. The default command follows the File explorer's sort order with a configurable fallback, navigation is restricted to Markdown files unless other file types or extra extensions are enabled in the settings, and looping within a folder is configurable.
