# search5/harang-calendar

Displays events from CalDAV calendars inside Obsidian and never creates, edits or deletes anything on the server. A staged autocomplete walks through account, calendar and then a date or an event, inserting a reference that renders as a widget listing that day's events as cards or as an inline chip, each opening a detail popup. A sidebar agenda and a full month grid in a workspace tab are built with Vue 3, and any number of server accounts can be configured, each tested and its calendars discovered, enabled and colored individually. Recurring events are expanded from their rules and exceptions for the range in view, each account carries an IANA time zone or manual UTC offset, and the interface follows Obsidian's language in Korean or English.
