# mapherez/nox-sync

NoX Sync is a private, self-hosted synchronization system composed of an Obsidian plugin and a Go backend with SQLite metadata, filesystem blob storage, a dashboard, and Docker support. Synchronization is explicitly user-triggered and includes remote vault management, access control, manifest planning, locks, staged commits, SHA-256 validation, versions, tombstones, and explicit Markdown or binary conflict handling. Local replacements and deletes use a trash area, while plugin settings, credentials, state, and trash remain outside the synchronized vault.
