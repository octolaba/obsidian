# erulmu/freecolors

erulmu/freecolors holds FreeColors, a modular Obsidian theme framework paired with a standalone HTML colour engine. The workflow its README describes is to design a palette in the simulator, export it as a JSON profile, import that profile into the Style Settings plugin, and let the theme render from the resulting variables. The README states that Style Settings is a prerequisite and that custom colour profiles and built-in features cannot be applied without it.
