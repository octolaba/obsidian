# LeCheenaX/WordFlow-Tracker

Wordflow Tracker records the focused time, the number of edits and the words edited per note, and writes those statistics into a daily or periodic note automatically when a note is closed, or for every note on command. The recorded data is shown through a file list view, a tag list view with collapsible groups and dual progress bars, and a heatmap with custom colour gradients and note navigation, alongside a sidebar widget, a customizable status bar and a bar showing the proportion of original, deleted and added content. Which values are recorded and how they are written are configured through string interpolation variables, and totals can be written into the daily note's frontmatter so other plugins can read them. The README also records an optional LLM integration that turns a note's changes into a readable summary through a diff variable, with configurable prompts.
