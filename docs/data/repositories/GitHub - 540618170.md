# marcoluzi/obsidian-synthwave

Obsidian SynthWave is a theme inspired by robb0wen's SynthWave '84 theme for VS Code, which its author names as an all-time favourite. It is available in the Obsidian theme library, and the README also gives manual steps that paste obsidian.css into the CSS snippets folder and activate it from the Appearance settings.
