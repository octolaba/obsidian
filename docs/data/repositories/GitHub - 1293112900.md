# tallvincent/obsidian-random-writing-prompt

Random Writing Prompt keeps a single prompts file — one idea per line under a Prompts heading — and opens a random one to write against. Commands pick a random unstarted prompt and create its note automatically, reopen a random prompt already begun, browse every prompt in a fuzzy-search modal, open the prompts file, and add a new prompt from the command palette. When a new prompt is opened the plugin creates a note named after it and converts the line in the list into a link to that note; a prompt counts as started once its note holds content beyond the frontmatter. The storage folder and an optional template file for new prompt notes are configurable.
