# lossless-group/metafetch

Metafetch fetches Open Graph metadata for a URL and writes it into a note's YAML frontmatter, including title, image, description and publisher, using OpenGraph.io or Microlink. A modal configures whether existing Open Graph data is overwritten, whether missing data is created, whether errors are written to frontmatter, and whether the fetch date is updated for processed files. The README records that an API key for at least one of the two providers is required and that only the commands for a configured provider work; batch fetching across several files is listed as not yet available.
