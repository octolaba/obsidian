# druxorey/minimal-dracula-for-obsidian

Minimal Dracula is described as an Obsidian theme inspired by the Dracula colour palette and compatible with computers, tablets and mobile devices. Its README states that it provides a carefully organized editing experience for those who prefer raw editing mode over live preview, and describes an aesthetic built from grey and blue tones. Installation is documented from the appearance settings by searching for Minimal Dracula, and the project records a GPL-3.0 license and a contribution flow that starts by opening an issue.
