# ferusnet/obsidian-ferus-plugin-auditor

Audits the community plugins already installed in a vault by reading each one's bundled main.js and scanning it for around fifteen risky patterns such as eval, child_process, remote script loading and obfuscated payloads. It also downloads the official GitHub release asset for the installed version and compares its SHA-256 with the copy on disk, so a bundle altered after installation shows up as a mismatch. Static findings, GitHub and registry signals and author history are combined into a risk score from 0 to 100 across four tiers, shown in a sortable in-vault report whose rows expand to the underlying findings. It is desktop only, never disables a plugin itself, and makes outbound requests only to the GitHub API, which is rate limited without a personal access token.
