# xuxinxi14/science-input-helper

Science Input Helper converts common but awkward science notation into LaTeX that Obsidian can render, and its README is written in Chinese and English for Chinese-language science notes. Its tables map short typed prefixes onto output: a chemistry prefix turns formulas, stoichiometric coefficients, ions, organic condensed formulas and hydrates into subscripted and superscripted markup; unit and scientific-notation prefixes format quantities without converting them; reversible and product arrow forms place conditions above and below the arrow; and further prefixes insert Greek letters, Roman numerals, roots, fractions and stock physics and biochemistry formulas looked up by Chinese keyword. The README is explicit about the limits it sets for itself: it does not judge whether the science is correct, does not solve problems and does not balance equations, it only produces the notation.
