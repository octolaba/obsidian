# fangface-hub/obsidian_plantuml_integrator

This plugin renders PlantUML diagrams in Obsidian, covering plantuml and puml code blocks in preview as well as embedded puml files. The README describes caching of include dependency trees with automatic re-rendering when an included file changes, a right-click action that clears the cache for a single diagram, and left, center or right alignment with per-diagram overrides. Two render modes are recorded: a default server mode pointing at a remote PlantUML-compatible HTTP endpoint, and a local mode that talks over HTTP to a PlantUML PicoWeb server the user starts, because Obsidian plugins cannot spawn external processes.
