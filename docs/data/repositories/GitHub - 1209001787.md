# lyxTsinghua/obsidian-theme-quick-switch

Theme Quick Switch moves Obsidian's light, dark and follow-system appearance choices out of the settings dialog and onto a ribbon icon, status bar buttons and command palette entries. It adds a fourth choice the README calls eye-care mode, which softens the overall palette for long reading sessions. When eye-care mode is active in the light theme, PDF page backgrounds are tinted a soft green rather than left pure white, which the README presents as the plugin's particular concern with daytime PDF reading.
