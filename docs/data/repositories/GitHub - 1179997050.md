# zhywjml/obsidian-sidebar-organizer

This plugin groups Obsidian ribbon icons into hover menus, and its README opens by correcting its own name: it modifies the ribbon, the icon strip at the side of the window, rather than the sidebar itself. Groups can be created by hand from selected icons, plugins contributing several ribbon actions are merged automatically, and each group takes a name and an optional custom SVG icon from a set of presets. The README also lists a spring animation and a blurred background for the popup menus, an interface in eight languages, and support on desktop and on mobile in tablet layout.
