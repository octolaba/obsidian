# stroiman/obsidian-dev-publish

This plugin publishes an Obsidian note as an article on DEV, created in a draft state so it can be reviewed before being made public. The README states that the article's title is the note's first H1 heading and its body everything after that heading, that a later run updates the article created earlier, that a link is added to the note's frontmatter after creation, and that tags are read from a dev-tags frontmatter value, with a non-array value ignored, non-string elements removed and at most four tags used. It carries a caution that the DEV api key is stored unencrypted in the plugin configuration file inside the vault, and says not to use the plugin without fully understanding the implications; images have to be uploaded manually because the DEV API exposes no upload capability.
