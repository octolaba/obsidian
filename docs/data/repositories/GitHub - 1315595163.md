# gyroid-eth/obsidian-native-search

Native Search queries the macOS Spotlight index with mdfind instead of building its own, so PDFs, the text Live Text has recognized inside images, Office documents and notes are searchable with no plugin-side index, cache file or startup delay. Queries combine words with AND and are case- and diacritic-insensitive, and support quoted phrases, exclusions, a vault-relative path prefix and an extension filter. Results are grouped by type with badges and optional excerpts, filename matches first; opening a note jumps to and highlights the matches, opening a PDF drives the built-in viewer's search bar, and other file types open in their default application. There is no relevance ranking and no fuzzy matching, and settings cover result limits, filename search, excerpts, query memory and excluded folders.
