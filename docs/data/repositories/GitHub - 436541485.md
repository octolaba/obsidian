# vrtmrz/obsidian-tagfolder

TagFolder presents a vault's tags as a folder tree, building a hierarchy out of permutations of the tags on each note when the Show Tag Folder command runs. Nested tags are respected and get their own dedicated hierarchy rather than leaking out over the parent, and tags can be filtered by a search expression so only the matching notes remain. Settings include opening the view at every Obsidian launch and pinning tags, with the pin information saved.
