# 318182456/ProjectVerse

ProjectVerse builds virtual project spaces in Obsidian: each space is created, edited and deleted on its own, carries a theme colour and icon, and associates existing files and folders scattered across the vault without moving them. A dedicated sidebar explorer shows only the active space and its associated directory tree, with collapse-all and a jump to the file being edited, while a generated dashboard gives the space a banner header, counts of associated files, tasks and rules, a scanner that lists Markdown tasks from those files and writes a tick back to the source, a memo area with Markdown rendering and image attachments, and a virtual file tree with one-click note creation. Switching spaces saves and restores the tabs that were open, and clicking a note in the tree opens it in a new tab rather than replacing a non-empty one.
