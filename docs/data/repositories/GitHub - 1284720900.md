# ALLONE5/Pomodoro-calendar

Pomodoro Calendar is a pomodoro timer for Obsidian whose panel opens from a sidebar icon, with the time display starting and pausing the timer and buttons to complete, skip or cancel it; the same actions are available as commands. An animated progress bar advances a cartoon character collecting coins, leaves, tomatoes, stars or hearts in either direction, and completing a session plays a particle effect. Session, short-break and long-break durations, the long-break interval and automatic starting of breaks and sessions are configurable, as are system notifications and sound. The README also records two-way CalDAV integration with servers such as iCloud, Google Calendar and Fastmail, creating a calendar event when a session completes and deleting it when one is cancelled, and state shared between devices through whatever mechanism already synchronises the vault.
