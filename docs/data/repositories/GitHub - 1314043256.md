# giuseqpe/siden

Adds annotations to Markdown notes and PDFs: select a passage, write a Markdown comment in a sidebar, and return to it later, with annotated passages highlighted and comments optionally shown as margin cards in Live Preview and Reading View. The sidebar lists annotations for the current file or the whole vault and supports search, status filters, editing, resolving, reopening, deleting and navigation back to the source passage. Annotations are stored as individual Markdown files inside the vault, deletions move to a trash subfolder, and source notes and PDFs are never modified; an export command writes a readable copy. It makes no network requests and collects no telemetry, but its PDF selection and highlight positioning depend on Obsidian's internal PDF viewer DOM, so an Obsidian update can require a compatibility update.
