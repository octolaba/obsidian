# slexkit/obsidian-slexkit

Repository for SlexKit, a plugin that renders explicit slex fenced blocks in reading mode using the SlexKit runtime. Its README states that such a fence contains a JavaScript object literal in which one field holds state and logic and another describes the component tree, and that only fences whose language is exactly slex are processed while ordinary JavaScript, JSON and unlabelled blocks stay inert. It gives interactive calculators, engineering worksheets, parameter panels, forms, small dashboards, generated interface blocks and reusable status cards as intended uses.
