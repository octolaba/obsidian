# RieTamura/Post-To-Bluesky

Post To Bluesky lets users compose and publish Bluesky posts from Obsidian, including Markdown link conversion, draft notes, post-history notes, hashtags, emoji, and up to four images from a vault or device. It supports desktop and mobile use and stores the app password in Obsidian's encrypted keychain rather than the plugin data file.
