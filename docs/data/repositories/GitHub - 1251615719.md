# AnonymisedFellow/dev-loader-updater

Dev Loader Updater installs and updates private Obsidian plugins from user-defined sources rather than through the standard public plugin installation flow. The README states that it installs plugins from configured remote sources, supports falling back to another endpoint when the primary source is unavailable, and checks for and applies updates through the same source chain.
