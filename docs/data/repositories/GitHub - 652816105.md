# uthvah/vaultguard

VaultGuard is a customizable lockscreen for Obsidian that keeps a vault from being opened without the password. Its security section documents AES-GCM, an authenticated encryption standard providing confidentiality and integrity, key derivation through PBKDF2 with 250,000 iterations and a secure random salt, and a password strength meter using zxcvbn to give feedback while a password is chosen. The personalization section covers a lockscreen background set to a video, image or solid colour from the defaults, a web URL or an uploaded file, a greeting with a custom username in a chosen font, weight and style, and scaling of the lockscreen elements and the password field.
