# Kunal1522/obsidian-focus-tracker

This repository holds Calm Focus Log, an Obsidian plugin that records focus sessions and shows them as a heatmap of the last ninety days. A session is logged from a ribbon icon or the Open calm focus log command with a date, a label, a duration and a completion percentage, and clicking a heatmap day lists that day's sessions. Data is kept in a JSON file at the vault root, keyed by date. The README states that the tracker deliberately has no goals, no streak pressure and no timers.
