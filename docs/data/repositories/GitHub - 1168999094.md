# Is-Ming/obsidian-note-calendar

This repository holds Note Calendar, an Obsidian calendar plugin whose description and primary README are written in Chinese. The README records a month view showing week numbers alongside Gregorian dates, lunar dates, festivals, solar terms and adjusted working days, marks notes on the calendar by their creation or modification date in distinct colours, and creates daily, weekly, monthly, quarterly and yearly notes from the calendar. Its changelog records per-type title formats and default paths, a folder picker for the note-creation dialog and a theme mode setting, while its TODO list records week and year views, template support, task integration, internationalisation and mobile support as not yet implemented.
