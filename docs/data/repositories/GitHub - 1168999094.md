# Is-Ming/obsidian-note-calendar

Note Calendar is an Obsidian calendar plugin that displays solar and lunar dates, holidays, festivals, and seasonal markers in a month view. It links note creation and modification dates to the calendar and can create daily, weekly, monthly, quarterly, and yearly notes with configurable titles and folders.
