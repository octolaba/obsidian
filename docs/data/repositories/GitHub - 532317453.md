# yekingyan/obsidian-open-in-other-editor

The repository holds an Obsidian plugin that opens the active file in an external editor, offering gVim, Visual Studio Code and nvim-qt. Its README records the prerequisite that the corresponding terminal command must already work, and that the plugin is invoked from the command palette. For macOS it records that the absolute path to the editor's command has to be entered in the settings tab, and it marks the gVim path and non-macOS behaviour as work in progress.
