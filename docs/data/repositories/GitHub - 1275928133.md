# arias007/obsidian-ntfy

Obsidian plugin that sends reminders to an ntfy topic so the Android ntfy app shows them in the system notification shade, which the README gives as a way around Obsidian mobile plugins being unable to create Android notifications directly. It requires the ntfy Android app subscribed to the same topic, and advises a long random topic name when the public ntfy.sh server is used. Reminders are read from unchecked tasks and standalone lines in several syntaxes, including emoji plus a timestamp, an at-remind form, a remind tag and notify or ntfy key-value lines, and it also reads the Obsidian Tasks emoji format preferring scheduled, then due, then start. The interface language can follow Obsidian or the system or be set manually among twelve languages, with any missing string falling back to English.
