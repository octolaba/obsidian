# arias007/obsidian-ntfy

Ntfy Notifications sends Obsidian reminders to an ntfy topic so the Android ntfy app can display them as system notifications. The plugin includes a multilingual interface, cached manager tabs, optional AI webhooks, and automatic nearby vault synchronization over private networks. Synchronization supports bidirectional or incremental modes, durable change journals, encrypted same-vault peer checks, and exclusions for workspace state and caches.
