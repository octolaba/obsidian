# saltyfireball/obsidian-better-search-and-replace

Better Search and Replace adds a floating search bar docked to the top of the Obsidian editor rather than a modal or a sidebar, and it works on desktop and mobile. The README describes highlighting matches as the query is typed and a live diff preview in which matched text is struck through and the replacement is shown inline as ghost text before anything is committed, together with full JavaScript regular expressions and capture groups, case-sensitive and whole-word toggles, a match counter, step-by-step navigation, replace-current and replace-all, and immediate inline reporting of an invalid pattern. Highlight and preview colours, keyboard shortcuts and a hotkey that replaces the built-in search are configurable, and the plugin can also be reached from the Note Toolbar helpers modal.
