# ZhihaoNan/open-in-new-tab-and-preserve-tabs

Obsidian plugin that changes file-opening behaviour so that opening a different file creates a new tab instead of replacing the current one. If that file is already open in another tab Obsidian switches to it rather than duplicating it, an empty tab is reused instead, and reopening the file that is already active keeps the current tab. The change applies to opens that go through Obsidian's normal file-opening path, including the file explorer, search results, recent files and calendar daily notes. The README records that the plugin wraps the workspace leaf's open method and restores the original one when it unloads.
