# Slaymish/Lumen

Runs a local research assistant over an Obsidian vault, with the stated property that vault contents never leave the machine. As a note is opened or edited it pushes related notes and older threads into a side panel, and on demand it answers a complex question by retrieving vault content, synthesising a long-form report, and verifying every citation against a real `^id` block so references cannot be invented, with progress streamed live while the local model works. It also keeps memory across sessions, using earlier research to focus later plans. At runtime it is three processes: the TypeScript Obsidian plugin as the only HTTP client, a Python FastAPI orchestrator, and a local Ollama instance.
