# hoomersinpsom/simple-tab-indent

Simple Tab Indent replaces Obsidian's default Tab handler so that pressing Tab inserts a zero-width space followed by a real tab. Because the first character is not whitespace, Markdown no longer turns the line into an indented code block, while the editor keeps a true tab whose rendered width is configurable in the plugin's settings. It works in Source Mode and Live Preview with no build step and no runtime dependencies, and the README carries an explicit limitation: lines indented this way are not recognised by Obsidian's built-in task features, by task plugins, or by search when looking for tasks.
