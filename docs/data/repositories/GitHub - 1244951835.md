# beauty-diagram/obsidian-beauty-diagram

Beauty Diagram re-renders Mermaid and PlantUML blocks in Obsidian's Reading View through a hosted rendering service, applying one of nine themes — Classic, Modern, Slate, Atlas, Obsidian, Brutalist, Atelier, Blueprint and Memphis — with dark-mode contrast in mind. A one-line directive overrides the theme for a single block so several themes can coexist in a note, a command bakes share-URL references into the Markdown so readers outside the vault see the same output, and PlantUML is handled by the same pipeline without a local Java installation. The README states that the free tier needs no API key and watermarks anonymous renders, and that when the service is unreachable the error interface offers to disable the plugin for Mermaid blocks and fall back to Obsidian's built-in renderer.
