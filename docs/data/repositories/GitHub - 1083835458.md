# Mahiron47/svg-color-replacer

SVG Color Replacer rewrites the colours of SVG images and mathematical formulas so that they stay readable under dark theme styling. The README describes the rule applied to every SVG found when a note loads: white is replaced with Obsidian's current background colour and black is replaced with white, after which the element is marked so that later updates do not process it again. Fill, stroke and colour attributes, inline styles, text and tspan elements, and SVGs encoded in data URLs are all covered.
