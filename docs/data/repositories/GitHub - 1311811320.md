# johannes-kaindl/kuro-gamification

The recorded description calls this neurodivergence-friendly gamification for Obsidian, with XP, levels, streaks carrying freeze tokens, deterministic loot and gothic-cyberpunk lore, off by default. The README says it reads daily notes and awards 2 XP per ticked checkbox plus completion bonuses, XP for user-defined frontmatter habit toggles, and a weekly review or planning bonus, while streaks survive missed days through a configurable monthly allowance of freeze tokens with bonus tiers at 3, 7, 14 and 30 days. Ten editable levels drive deterministic loot drops across five tiers from a default or custom reward pool and reveal one narrative fragment each, shipping with plain-language lore alongside gothic-cyberpunk and cozy packs in the repository. It states that everything runs inside the vault with no account, server or network access.
