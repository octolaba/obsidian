# bubba8587/dmatrix-bases-view

Builds decision matrices inside Obsidian Bases, combining raw scores for options across criteria with how much each criterion is weighted. Two views are provided, a scoring table with weighted totals and rankings and a rankings view with a podium and card list, and clicking a score edits it straight into the note's frontmatter. Numeric properties on the source notes become the criteria, an optional shared prefix is stripped from the column headers, negative weights penalize criteria where a higher value is worse, and a rank option converts a column to competition ranks when scales are incompatible. The README states it requires Obsidian 1.9.10 or newer with Bases enabled, and that weights persist only when weight properties are added to the note embedding the base file.
