# joybro/obsidian-similar-notes

Similar Notes finds semantically similar notes through embeddings, listing them at the bottom of the note being written and offering a semantic search over the vault from a keyboard shortcut. Embeddings can come from a built-in model that runs locally, from OpenAI or any OpenAI-compatible API, or from Ollama, which the README marks as desktop only; the default model downloads once at about 30MB and notes are then indexed in the background with progress shown in the status bar. Built-in models cover any Sentence Transformer model from Hugging Face that ships ONNX weights, since the plugin uses Transformers.js, so repositories publishing only PyTorch or safetensors weights will fail to load. The README warns that large models may crash on mobile because of memory limits.
