# grover572/obsidian-Dictionary-translator

Repository for Obsidian-Dictionary-translator, a plugin whose recorded description and README are written in Chinese. It translates unfamiliar words or sentences from a right-click selection, inserts the result into the note as a word card, and can store the translation engine's pronunciation audio in the vault or a recording of the user's own voice, linked from the note. Youdao and Baidu cloud translation are marked as supported while Google and Microsoft are not, and the README describes adding an engine by implementing a translation strategy class, registering it, and giving it settings entries; it also records that a Youdao interface change left part of its dictionary data missing.
