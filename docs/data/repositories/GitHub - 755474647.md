# isax785/obsidian-sparkling-day

Sparkling Day is the light theme derived from the same author's Sparkling Night. Like it, it uses coloured checkboxes to distinguish task states, with markers for working progress, pause or stand-by, stop, and to be scheduled. Installation runs through Obsidian's Settings, then Appearance and Manage, searching the community themes list.
