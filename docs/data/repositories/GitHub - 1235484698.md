# TheRofli/Mindo

Mindo is an AI companion for Obsidian that chats about the active note with vault and web context, routes tools for opening and creating notes, replacing text, undoing changes and running research workflows, and cites the vault notes and web results it used. It maintains a Mindo Wiki memory layer of Raw, Wiki, Schema and Inbox folders plus a prompt library, created or repaired from a command or the settings tab. The README records attachments for images, PDF and text files and dragged files, local speech-to-text and text-to-speech helpers, and an optional Rust sidecar for faster vault search, resolver scoring and indexing, and states that the plugin is desktop-only because it can start local helper processes.
