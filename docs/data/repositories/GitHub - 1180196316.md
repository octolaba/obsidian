# ForeverWeLearn/obsidian-superflat

Superflat is an Obsidian theme its README calls a theme of nothingness, removing everything that distracts from the thought. There are no borders, no scrollbars and zero depth; many elements are removed completely, and status bars, sidebars and tab headers fade in only when hovered.
