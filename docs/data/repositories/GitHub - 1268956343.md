# ben4202121/buddybridge

BuddyBridge is an unofficial Obsidian plugin that bridges a vault with the local WorkBuddy or CodeBuddy CLI for AI chat. It opens a chat panel in the right sidebar from a ribbon icon or a command, streams responses, displays thinking steps and tool calls, keeps conversation history across sessions, and holds several conversations in tabs. The README states that it is Windows only for now, requires Obsidian 1.7.2 or later on desktop, and needs the WorkBuddy desktop app with CodeBuddy CLI installed or a custom CodeBuddy path configured in settings. The repository carries no description, so this summary rests on the README alone.
