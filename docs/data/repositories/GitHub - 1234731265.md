# avinashkanaujiya/obsidian-agentic-note-references

Obsidian plugin that copies a formatted reference to the current note, file link plus line numbers, to the clipboard for pasting into a chat with an AI agent. With the cursor on a line or a range selected, a hotkey or command opens a picker offering a built-in default mode, any custom modes defined in settings in their configured order, and a reading-mode preset; the chosen template is rendered and copied. Templates expand the filename and the from and to line numbers, and a setting decides whether the filename resolves to the file name alone, a vault-relative path or an absolute filesystem path.
