# akdemirdeniz/obsidian-tipa

This plugin implements TIPA, the TeX notation for International Phonetic Alphabet symbols, inside Obsidian by converting TIPA notation into Unicode phonetic characters. The README states that the textipa, tipa, nt and wt commands are supported, along with inline notation between dollar signs and notation inside code blocks, and that rendering happens in both editing and reading modes for code blocks. It records one restriction: live preview support does not exist for the inline syntax. The repository is mirrored on Codeberg as well as GitHub.
