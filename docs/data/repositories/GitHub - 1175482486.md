# Lumyo/obsidian-base-backlinks-viewer

An Obsidian plugin that adds a "Show backlinks" entry to the context menu of any link, opening a Bases view filtered to the notes that link to that target. It reuses a single _backlinks.base file, changing only the file.hasLink filter and the view name on each invocation, so view type, sorting, visible columns, widths and grouping configured once are kept. The README records the supported contexts: the native context menu in Source mode and Live Preview, an injected item in the properties panel, and a custom menu in Reading mode; the base opens in the current leaf so navigating back works normally.
