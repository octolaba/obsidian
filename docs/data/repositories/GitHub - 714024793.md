# HananoshikaYomaru/obsidian-publish-url

This plugin copies the publish URL of the current view to the clipboard, or opens it. The README records a setup that requires only the domain name, that the permalink is respected, and that a further command copies a theog.io link, for which a template number is taken from that service. Installation through the Obsidian community plugin browser is recorded as awaiting approval at the time of writing, with BRAT and manual installation described as the alternatives.
