# SpencerF718/obsidian-random-wikipedia

An Obsidian plugin that fetches a random Wikipedia article and creates a formatted note for it in the vault, triggered from a dice ribbon icon. Article selection is configurable through a minimum header count for treating an article as suitable, a maximum number of retries when looking for a suitable article, and a list of disallowed headers to exclude. The save location and whether the generated note opens automatically are settings as well.
