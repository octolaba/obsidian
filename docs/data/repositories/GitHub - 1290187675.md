# diegomarzaa/obsidian-extensions-sync-manager

Extensions Sync Manager manages two Obsidian configuration profiles inside one vault, by default a desktop profile in the .obsidian folder and a mobile one in .obsidian_mobile. It compares the extension folders of both profiles by content hash and shows extensions and base JSON configuration files side by side, so an extension can be marked as belonging to both devices, to one of them only, frozen, ignored or removed, and its enabled state set independently per profile. Configuration differences are reviewed by value and a single changed JSON property can be copied from one profile to the other, baseline hashes can be refreshed, and target files are backed up before any overwrite or removal. The README states the plugin is desktop-only because it uses Node file-system APIs on hidden configuration folders, and that it uses no network, telemetry or accounts.
