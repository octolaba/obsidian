# bbawj/obsidian-semantic-search

Semantic Search is a file switcher for Obsidian that searches notes by meaning rather than by literal text, built with Rust compiled to WebAssembly. Its workflow is three commands: `Generate Input` splits notes into sections between headings and writes `input.csv` to the vault root, `Generate Embedding` requests embeddings from a configured API URL and saves `embedding.csv`, and `Open Query Modal` searches over those embeddings. The README states the API URL is arbitrary as long as the response shape matches a supported type, naming OpenAI and Ollama endpoints as examples, with an optional key sent as a bearer token, and it also records a command that recommends links from the current editor selection.
