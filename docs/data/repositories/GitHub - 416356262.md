# vrtmrz/obsidian-livesync

The repository holds Self-hosted LiveSync, a community synchronisation plugin available on every platform Obsidian runs on. Its README records CouchDB and object storage systems such as MinIO, S3 and R2 as server options, and a peer-to-peer mode over WebRTC in which devices exchange notes without a central store, though a signalling relay is still needed for discovery. Listed properties include efficient synchronisation with little traffic, handling of conflicting modifications with automatic merging of simple cases, and end-to-end encryption. The README states clearly that the plugin is not compatible with the official Obsidian Sync service and cannot synchronise with it.
