# mamadaevv/card-columns

Columns presents Obsidian notes as a Kanban-style card view grouped by tags or frontmatter properties. It supports configurable card covers, grid or masonry layouts, zebra striping, property chips, date formatting, tag filters with AND/OR modes, and split-pane previews. The view integrates with Obsidian Bases controls for sorting, filtering, properties, and search.
