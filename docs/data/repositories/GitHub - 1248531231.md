# wesswart77/obsidian-research-hub

Sets up a research workspace in the vault: a modal creates a project with a topic, research question and hypothesis, and generates `Sources/`, `Claims/` and `Synthesis/` subfolders beneath a project index note. Commands add a source note carrying a URL, book or paper reference with its key finding and a high, medium or low credibility tag; a claim note stating a position with links to supporting sources and a confidence level; and a synthesis note recording conclusions. A sidebar lists all projects with their source, claim and synthesis counts, and the vault path holding the projects is configurable.
