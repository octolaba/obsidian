# rifts-obsidian-laboratory/anki-integration

Anki Integration creates and manages Anki flashcards from inside Obsidian, reducing the switching between the two applications when a card relates to the note being written or reviewed. Version 1.0.0 provides synchronization of data from Anki into Obsidian and two pop-up interfaces for working with the Anki collection, where the deck and the note template are chosen as the card is created. Synchronization runs through AnkiConnect from a single button, and cards are structured with metadata.
