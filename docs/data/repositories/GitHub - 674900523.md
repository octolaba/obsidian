# Falcion/UNITADE.md

UNITADE lets Obsidian treat files with extensions other than Markdown as note files: extensions entered in its settings, separated by a greater-than sign, become editable inside the vault. The README states that plain text files are editable by default, that registered extensions can also be force-opened and rendered as code in the manner of a code editor, and that the plugin carries compatibility modules for its own older versions. Its wiki is named as the place where the settings and modes are documented in full.
