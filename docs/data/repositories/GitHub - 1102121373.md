# gustjose/obsidian-syncthing-manager

Syncthing Manager talks to a local Syncthing API and reports vault status, synced, syncing or disconnected, in the status bar and in a side panel, with per-tab icons while files are transferring. The README lists a conflict resolver that detects sync-conflict files and compares them side by side in a CodeMirror diff view, versioning strategies with in-app restore of earlier file versions, pause and resume for folders, context-menu actions to force a sync or to add a file to the ignore list, and an editor for that ignore file. It records that API keys are stored in Obsidian's native keychain, that a long-polling architecture and a debug console were added, and that the interface is localised into more than twenty languages.
