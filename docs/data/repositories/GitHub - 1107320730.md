# ba2slk/obsidian-contexts

The repository holds Contexts, an Obsidian plugin that saves a set of open tabs as a named context and reloads it later. It covers Markdown notes, PDFs, canvases and images, and stores only vault-relative file paths so a context saved on one device loads on another, though the README says layout arrangement is not preserved. A management interface lists and deletes saved contexts, builds them manually with a file picker, and guards against overwriting one by accident.
