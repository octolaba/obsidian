# devbean/obsidian-wordpress

This plugin publishes Obsidian documents to a WordPress site whose URL is set in the plugin settings. Publishing runs from the command palette or an optional side button, and YAML front matter supplies metadata such as an overriding title and tags; on success the post identifier and categories are written back into that front matter so the note can be edited later. The README notes that publishing goes over the XML-RPC or REST protocol.
