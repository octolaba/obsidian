# do0ori/obsidian-full-width-toggle

Full Width Toggle adds a switch to Obsidian's status bar that flips the active note between full width and the default readable width; both the label and the switch itself are clickable. The state is stored per note in the note's cssclasses property, where turning it on adds a full-width class and turning it off removes only that class, leaving other values untouched. The same action is available from the ribbon, the command palette, and the editor and file context menus, and it works in editing and reading view. Styling ships with the plugin, so no separate CSS snippet is required.
