# choisungwook/obsidian-plugins

Akbun Notion Sync is a desktop-only Obsidian plugin that syncs every Markdown note in a vault to Notion as child pages of one parent page. It walks the vault, hashes each note with sha256 and compares the result against a stored sync state, so new notes become Notion pages, changed notes are updated in place and notes deleted from the vault are archived, with Notion API calls throttled to three requests per second. Authentication is either an internal integration token or an OAuth flow that receives its code on a temporary localhost server, and credentials are stored outside the vault with 0600 permissions so syncing the vault cannot leak them.
