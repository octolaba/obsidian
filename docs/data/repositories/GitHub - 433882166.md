# Thiews/Obsidian-Harmonic

Harmonic is described by its repository as a minimal and highly customizable theme for Obsidian, changed through the Style Settings plugin panel. The README lists adjustments or custom design for the Kanban, Calendar, Sliding Panes, Checklist and File Explorer Note Count plugins, and records preset files such as a Bear light preset and a Cobalt dark preset. Customization is documented as covering a logo or title, an accent colour, four menu styles for the sidebars, a focus mode, emphasis colours for bold and italic text, and page settings including line width, paragraph offset and a fullwidth mode.
