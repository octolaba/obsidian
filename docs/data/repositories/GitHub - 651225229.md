# nwindian/Memorization-Plugin

This is an index-card and memorization plugin for Obsidian that implements a spaced repetition algorithm based on SuperMemo-2. Studying is organised by tag: the plugin icon in the left pane or the command palette opens it, a tag is searched for, and study notes are generated from it. Two settings are documented — whether the created memorization notes are deleted after creation, since by default they are kept, and whether moving to the next note in the sequence opens a new tab, which is off by default.
