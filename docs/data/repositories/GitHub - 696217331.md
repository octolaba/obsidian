# Dzoukr/MoonServerObsidianPlugin

Moon server publisher publishes Obsidian notes to a Moon server instance. It is configured with the base URL of the instance and, optionally, an API key and secret. A publish command sends the open note to the server and writes the resulting identifier back into the note as a property, while an unpublish command removes the note from the server and deletes that property; both are available from the command palette or the note's context menu.
