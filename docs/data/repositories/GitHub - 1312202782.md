# giacolees/obsidian-local-voiceover

Local Voiceover speaks selected text on the machine itself, running the Inflect Micro v2 English text-to-speech model through ONNX Runtime Web with WebGPU and a WebAssembly fallback, so no API key, account or upload is involved. A floating Play button above the selection or a command starts synthesis and reports Ready, Loading, Generating or Speaking, and a Stop button ends it. Text is split into chunks, phonemized by an eSpeak-compatible WebAssembly frontend and turned into a 24 kHz mono waveform in a worker, with finished chunks queued through Web Audio so playback starts before a long selection is complete. The first run downloads about 38 MB of model graphs and runtime assets, which are cached and checksum-verified for offline reuse; speed, variation and seed are adjustable, and the model provides one fixed English male voice.
