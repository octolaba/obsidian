# hskwak82/nanalstamp-obsidian

Watches selected notes and, whenever one settles, computes a SHA-256 hash on the device and sends only that hash to the nanalStamp server, which chains and signs the entries and periodically anchors the chain head into Bitcoin through OpenTimestamps. Note content stays local unless the optional paid original-file storage or the optional GitHub offsite archive is switched on, in which case files are encrypted on the device before upload. A ribbon menu gathers sealing, certificates, stored notes, a dashboard and the account, while the status bar and a per-note proof dialog show sealed state, sequence, anchor status and earlier sealed versions with restore. It is presented as a proof of existence with tamper evidence rather than a government-accredited or qualified timestamping service.
