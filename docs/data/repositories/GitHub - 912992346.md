# scottTomaszewski/obsidian-tag-tactician

Tag Tactician manages frontmatter tags in Obsidian in bulk, surfaces related notes and offers a hierarchical tag browser. The README records adding or removing frontmatter tags across many notes or whole folders in one pass with a live preview before applying, a sidebar scoring notes similar to the current one by tag overlap, title, path and links, and a sidebar organizing notes into a collapsible hierarchy from nested tags so one note can sit in several places at once. It records Obsidian 1.7.2 or newer as the requirement, and warns that the plugin is early in development with no undo for bulk edits, advising a backup first.
