# keqing996/ob-plugin-document-bundle

Documents Bundle keeps a note together with its attachments as a small self-contained folder holding the Markdown file and an assets directory beside it, rather than a vault-wide attachments folder. It creates bundle documents from the native file menu, converts existing Markdown files into bundles, saves pasted and dropped files into the active bundle's assets folder, inserts portable relative links, migrates old local attachment links and rewrites the note, keeps a bundle folder rename in sync with its main file, and marks bundle folders in the Files pane. The README stresses that there is no database and no custom archive format: with the plugin disabled the folder is still just a folder, and a folder holding only its Markdown file already counts as a bundle.
