# fardm/obsidian-book-clipper

Book Clipper imports book information from a link into an Obsidian note, supporting goodreads.com, amazon.com, taaghche.com and fidibo.com. The user creates a template note using variables such as title, author, translator, pages, cover, publisher, publication date, ISBN, url and language, points the plugin settings at that template and a save folder, then runs the add-book-from-link command and enters a book link. The README notes that on Goodreads the translator variable is not returned because authors and translators are not properly separated in the JSON-LD it scrapes, so both end up in the author field. It also states that the plugin is designed solely for personal, non-commercial use.
