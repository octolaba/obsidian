# augmentableai/tpsreport-obsidian-sync

This plugin synchronizes vault folders with the TPSReport service, publishing them as collections in that service's knowledge base and metadata contract and pulling edits back into the vault. The README describes the service as a workflow for publishing knowledge bases and using them for retrieval with agent-oriented metadata, with two layers, one for publishing linked reports and collections with visibility and gating and one for scoped hybrid graph and vector retrieval. It positions this plugin as the second of three pieces alongside a set of authoring skills and a separate MCP server, and states that Obsidian is optional because the same knowledge base can be built entirely online.
