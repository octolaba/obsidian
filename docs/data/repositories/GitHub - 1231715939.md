# creesee/obsidian-days-left

Days Left renders countdown and count-up timers in notes: a target date counts down to a future date or up from a past one, a start and end date together give the duration between them, and a start date alone tracks an ongoing streak until today. Counters appear either as centered code blocks for major events or as inline tags embedded in a sentence, and can be inserted manually or through built-in commands. A spotlight threshold changes the counter's colour and font weight when an event comes within range, and can raise either a notice or a full-screen modal even while the note is closed. The README lists output text in English, Polish, Spanish, French, German, Japanese, Ukrainian and Chinese, and per-note overrides of the global colour, format and visibility settings.
