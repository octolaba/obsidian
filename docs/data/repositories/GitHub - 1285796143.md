# Young-caveman/wisdio-companion

Wisdio Companion is the Obsidian side of Wisdio, a browser extension for writing timestamped notes beside a video without leaving the browser. The plugin saves those notes into a chosen vault folder as ordinary Markdown files and keeps content and filenames synchronized in both directions, linking each note through a managed identifier so renames stay attached. The README also demonstrates subtitle capture, Bilibili support and mobile note-taking, which belong to the browser extension rather than to the plugin.
