# dhennessy/MarkdownVaultObsidianPlugin

A plugin that publishes an Obsidian vault to the Markdown Vault service, which makes the notes available in an iOS app of the same name and gives the published vault a sharing link to hand to readers. Publishing runs from a sidebar icon or a publish command, and the plugin is configured with the vault UUID and API key taken from a Markdown Vault account. The README states that the account is free and that optional features such as password protection require a paid subscription; the remainder of the file is the Obsidian sample-plugin developer and release guidance.
