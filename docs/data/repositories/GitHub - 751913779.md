# karfekr/obsidian-persian-calendar

Persian Calendar adds the Solar Hijri, or Jalali, calendar alongside the Gregorian and Lunar Hijri calendars, aimed at making journaling more pleasant for Iranian users. Paths and filenames of calendar notes are built from dynamic placeholders covering the Jalali and Gregorian year in two or four digits, the quarter and further units, so periodic notes can be filed and named dynamically. The README also documents quick reference to calendar notes and a dedicated API, and describes installation either by searching the community plugins browser or by copying the release files into a plugin folder of the vault.
