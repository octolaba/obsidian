# pjeby/tag-wrangler

The repository holds Tag Wrangler, which adds a context menu for tags in the tag pane and in note bodies. From it tags are renamed or reorganized by menu or by drag and drop, tag pages are opened or created, and tags are dragged into an editor as text.
