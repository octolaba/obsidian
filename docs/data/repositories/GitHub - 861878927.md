# mihasm/obsidian-autosave-control

Obsidian plugin that overrides how often Obsidian writes notes to disk, which by default happens about every two seconds while typing. In delayed autosave mode a per-file timer resets on every edit and the note is saved once after editing stops for the configured delay, ten seconds by default; in the disabled mode saving happens only through the Save File command, quitting with unsaved changes shows a warning listing the affected notes, and unsaved changes survive switching or closing a tab in memory. The plugin can also delay the writes Obsidian makes to its workspace layout file, and a status bar indicator shows whether changes are pending or saved, with customisable colours and icon size. The README names sync conflicts with cloud storage, performance on large files, network drives and battery usage as the reasons for changing the default.
