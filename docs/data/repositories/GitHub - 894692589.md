# Mara-Li/obsidian-simple-colored-folder

Simple Colored Folder applies CSS variables and colours to the root-level folders of a vault, with the colour of each root folder then customised through the Style Settings plugin. Colours update in real time, work with light and dark themes, and survive a folder being renamed. Settings cover exporting to a CSS snippet instead of injecting into the DOM, default colours for newly created folders, the prefix used for the generated CSS variable names, and custom CSS and Style Settings templates. The README warns that the Style Settings plugin is required to customise folder colours and that a warning is shown when it is not installed.
