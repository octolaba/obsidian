# aitingtingya/mv-obcc

mv-AIDE is a desktop Obsidian AI IDE that connects Claude Code, Codex CLI, and MCP-compatible agents to a local vault. It exposes tab, selection, file, and web context with IDE tools and editable diff review, and also provides inline completion, selection-based LLM calls, an embedded system terminal, source editing support, and a default file opener. The recorded README lists Obsidian 1.7.2 or later and desktop-only support.
