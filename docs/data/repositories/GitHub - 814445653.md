# zhouhua/obsidian-sticky-headings

Obsidian Sticky Headings keeps the headings above the reading position pinned as a note is scrolled, an idea the README credits to the Sticky Scroll feature in the VS Code editor. Its author records that a plugin with similar functionality already existed at release, states that the two implementations are entirely different, and compares them: the concise mode here corresponds to the other plugin's default of showing only the current heading. The README claims support for both editing and reading views.
