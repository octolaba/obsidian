# ludovicchabant/obsidian-remember-file-state

The repository holds Remember File State, an Obsidian plugin that restores the cursor and scroll position of a file when it is reopened. Its README records that those states are kept across sessions by default by saving them to disk, and that the plugin registers no timers and does no polling, doing its work only when a file is opened or closed so the editing experience is not slowed. It also documents the author's own development loop, building in watch mode into a test vault and reloading the app.
