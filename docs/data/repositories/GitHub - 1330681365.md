# jackydangelo/obsidian-csv-to-table

This plugin converts a selection of comma-separated lines into a Markdown table. The selected text is read line by line, the first line becomes the header row followed by a separator, and the remaining lines become table rows. It is run from the command palette as a single conversion command and adds nothing else.
