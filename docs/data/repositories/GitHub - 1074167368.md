# tavva/obsidian-plugin-hide-traffic-lights

The repository holds Hide Traffic Lights, an Obsidian plugin that hides the red, yellow and green macOS window control buttons. According to the README it moves them off-screen through Electron's traffic-light position API, re-applying the setting on window focus changes, workspace layout changes such as pane splits and tab changes, and new window creation. The README records that it hides them on load, restores them to their default position when the plugin is disabled, requires no configuration, and does nothing on platforms other than macOS.
