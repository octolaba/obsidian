# soykindabored/srcery-obsidian

This repository ports the Srcery colour scheme to Obsidian, described upstream as a colour scheme with clearly defined contrasting colors and a slightly earthy tone. The README requires Obsidian v1.1.9 or above and documents manual installation by copying or symlinking manifest.json and theme.css into the vault's theme directory, as well as the community listing. It also reproduces the canonical Srcery palette, built on the sixteen terminal colours.
