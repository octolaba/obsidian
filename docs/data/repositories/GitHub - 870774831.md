# Oczko24/Obsidian-transparent

Obsidian transparent is a minimalistic theme that its README describes as light, simple and aesthetic, offering an unobtrusive interface with support for both light and dark modes and stated mobile support. The background image can be replaced with any custom URL through the Style Settings plugin or left at its default, and that plugin also drives the rest of the theme's customization. The README further records built-in snippets that can be enabled the same way, and notes that some plugins are accounted for directly in the theme's code.
