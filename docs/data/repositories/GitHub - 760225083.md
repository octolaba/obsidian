# Aetherinox/obsidian-gistr

This repository holds Gistr, described upstream as a plugin that lets notes embed, create and update gists for GitHub and Opengist, with light and dark theme support and manual or autosaved updates to public and private gists. The README describes two ways of showing a gist, a code block and an integrated browser, and a command that converts an existing note into a gist. The supported services are listed as GitHub Gists and a self-hosted Opengist server.
