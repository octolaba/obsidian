# Heiss/obsidian-vikunja-plugin

This unofficial plugin synchronises tasks between Obsidian and a Vikunja instance in both directions, with settings to fit the sync to a workflow. The README states that it is designed for a single user on one platform at a time and should not be used for team work, because Obsidian always wins when both ends change; that it runs on a manual trigger by default, with automatic sync and its interval available in settings; and that all tasks are pushed to Vikunja on the first sync. It depends on the Dataview plugin and the Daily notes core plugin, and its status section records known issues with syncing changes coming from Vikunja.
