# takitsuba/obsidian-auto-bullet

Obsidian plugin that inserts a bullet marker automatically when a space or a tab is typed at the beginning of a line. Half-width spaces, full-width spaces and tabs are each controlled by their own setting and all are enabled by default, and the whole behaviour can be toggled from the settings tab. The README states the plugin is inspired by the automatic bullet point feature in Cosense.
