# TitanicEclair/chatobby-obsidian

A connector that runs the local Chatobby agent runtime inside an Obsidian vault. The README describes an agent workspace that reads notes, calls tools, works across projects, recalls memory and past sessions, and coordinates subagents, with conversations, permissions, context and scheduled or delegated work kept visible in Obsidian. It states that only model calls leave the machine, to a provider chosen by the user, and names OpenAI, Anthropic, Deepseek, Google Gemini, Z.AI, Xiaomi, OpenRouter and Hugging Face among the supported ones, with local models listed as a roadmap item. The README marks the plugin as alpha and points to a separate maintained guide for provider and model details.
