# TitanicEclair/chatobby-obsidian

Chatobby is a desktop Obsidian agent workspace that keeps conversations, memory, provider sessions, permissions, scheduled work, and delegated tasks visible in the Vault. It can read notes, use tools, work across projects, and coordinate subagents, while only model calls are sent to configured providers or compatible local servers; the README identifies the release as a public alpha whose interfaces and storage contracts may change.
