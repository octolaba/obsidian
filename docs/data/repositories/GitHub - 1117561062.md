# dsebastien/obsidian-journal-base

Journal Bases adds two Base view types for daily, weekly, monthly, quarterly, and yearly notes. Its Periodic Notes view supports chronological navigation, inline editing, future-note creation, and missing-period placeholders, while Periodic Review presents multiple periods for review work.
