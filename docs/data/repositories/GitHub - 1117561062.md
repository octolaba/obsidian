# dsebastien/obsidian-journal-base

Journal Bases adds two custom Base view types to Obsidian for daily, weekly, monthly, quarterly and yearly notes. The Periodic Notes view lists notes of one selected period type newest first, folds and expands individual notes, supports inline editing, highlights the current period, and shows placeholders with one-click creation for missing notes in the sequence. The Periodic Review view places the period types side by side for the review workflow the README describes, in which daily notes are reviewed weekly, weekly notes monthly, monthly notes quarterly and quarterly notes yearly.
