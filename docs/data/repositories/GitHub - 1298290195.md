# DevidCode/obsidian-tasks-cockpit

Tasks Cockpit gathers every open task carrying a chosen tag from across an Obsidian vault into one list, groups it by due-date horizon and lets the order be set by hand with drag-and-drop. The README records three horizons, in progress covering today, overdue and undated items, upcoming within a configurable number of days, and later, and states that the manual order persists across refreshes, which it contrasts with the read-only ordering of query views. Ticking an entry completes the task in its source note, recurring tasks roll over to their next occurrence through the Tasks plugin, a link jumps to the task's note at the right line, and a command-palette entry opens the configured cockpit note. The README is bilingual, English first and French below it.
