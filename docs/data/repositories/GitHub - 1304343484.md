# SVM0N/obsidian-rollup-to-pdf

Rollup to PDF compiles a tree of wiki-linked notes into a single PDF through Pandoc. Pointed at an index note, it follows every line-leading arrow-and-link expansion it finds, pulls that note in nested one heading level below where it was linked, and recurses until the outline is flattened into one document with a title page, table of contents, numbered sections and callouts rendered as styled boxes. The README contrasts this with Obsidian's built-in export, which handles a single note as-is, and says the plugin is not the right tool when exporting one note unchanged is all that is wanted.
