# CosmicSeaFox/foundation

Foundation is an architectural Obsidian theme with a dark mode of deep concrete and steel surfaces under blueprint-blue accents and a light mode modelled on drafting paper in daylight. Amber is held back for warnings and secondary emphasis, tables follow engineering schedules and specifications, properties are laid out as technical specification blocks, and callouts are engineering-style information panels. Tags act as compact classification labels, task states read as work orders, the canvas takes a drafting-board treatment, and the graph view is presented as a structural network. Reading and source modes and a responsive mobile layout are included.
