# joeytoday/obsidian-mp-publisher

This repository holds MP Publisher, an Obsidian plugin whose recorded description and primary README are in Chinese; it previews a note under a custom theme and publishes it to a WeChat official account draft box. The README records a CSS theme system with eight built-in themes plus local ones loaded from a custom folder, a separate management view for browsing, switching, creating, editing, renaming and deleting themes, and automatic conversion of CSS pseudo-elements and counters into real elements when copying or publishing. It also records management of several accounts, publishing through the platform API, and states that the plugin is listed in the Obsidian community plugin market and free of charge.
