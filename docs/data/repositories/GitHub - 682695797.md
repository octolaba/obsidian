# plasmabit/timethings

Time Things records when notes were last updated, how long they were edited, and a clock in the Obsidian status bar. It writes configurable timestamps and edit durations to frontmatter, can exclude paths, offers timezone and format settings, and states that vault data is not sent over the network.
