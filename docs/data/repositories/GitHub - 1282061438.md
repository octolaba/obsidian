# mircomacrelli/simple-folder-icon

Simple Folder Icon adds an icon before the name of configured folders in the Obsidian file explorer. Folders are added to or removed from the list, along with their icons, in the plugin's settings tab. The README states that the SVG files can be kept in any folder of the vault.
