# strombraaten/dim-lights

Repository for Dim Lights, an Obsidian plugin that fades every pane except the one being worked in, so a split workspace keeps focus on the active editor. A single open pane looks unchanged, dimming follows focus as panes are switched, and only splits in the main editor area dim — sidebars such as the file explorer, backlinks and outline stay fully lit. Settings expose an enable toggle and a light level between 0 and 100, and a command palette entry flips the same toggle.
