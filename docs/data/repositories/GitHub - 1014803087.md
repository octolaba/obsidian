# lossless-group/cite-wide

Vault-wide citation management for Obsidian: it converts numeric footnotes into stable hex identifiers that survive reordering, logs each citation into a per-citation file for Bases or Dataview queries, and dedupes citations pointing at the same URL. The README also describes parsing research output pasted from Perplexity, Google AI or Claude into the same canonical reference format, and presents the plugin as one of a suite maintained by the same group.
