# TheManuelML/obsidian-agent

Obsidian Agent lends the vault to an AI agent that can read, write and search notes and create notes and folders. A provider is selected in the plugin settings — Google Gemini, Anthropic Claude, OpenAI, or a local Ollama model — with an API key for the hosted providers, a running local server and a pulled model for Ollama, and an optional custom base URL for a different endpoint. Chats are opened from a brain icon in either sidebar or through a hotkey, and are managed as Obsidian notes.
