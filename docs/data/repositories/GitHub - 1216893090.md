# Tuguberk/Thought-Agent-Obsidian

Thought Agent treats a vault's notes, links and diagrams as one knowledge graph and works over it as an agent rather than a chat window. The README describes it searching semantically, following graph links between notes, proposing edits and generating diagrams, and states that no file is written until the change is approved. It records installation from the community plugin directory or through BRAT for pre-release builds, and an Obsidian version floor of 1.7.2.
