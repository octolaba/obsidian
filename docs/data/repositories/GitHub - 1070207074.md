# nsiniscalchi/LighterPackObsidianImporter

Obsidian plugin that imports a public packing list from lighterpack.com into a vault from its share link. Categories, items, weights and the chart become a folder of Markdown notes, one per item and grouped by category, alongside a summary note reproducing the LighterPack overview with totals, category breakdowns and a weight distribution pie chart. Imported lists are stored locally as Markdown, so they can be linked, searched and edited offline; an import starts from a ribbon icon or the command palette and needs no external API key.
