# LeonLuttenberger/obsidian-kindle-highlight-import

The recorded description says the plugin allows users to import Kindle highlights into their Obsidian vault. Per the README it imports the highlights and formats them for readability, through one command that picks the exported file from the device and another that selects a file already in the vault. The export procedure it documents is to open the highlights in the Kindle app, choose Share, select None as the citation style and email the file to oneself; PDF exports made directly on a Kindle device are also supported but carry no chapter titles, so the README recommends exporting from the iOS or Android app.
