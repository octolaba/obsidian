# tsilva/obsidian-agents-plugin

macOS-only Obsidian plugin that adds an Open with agent action to the file explorer context menu, launching a configured AI command-line tool in Terminal.app or iTerm2 already pointed at the right vault location. Right-clicking a file starts the agent in the parent folder with a short file-context prompt, while right-clicking a folder starts it in that folder. The default command is `claude` and settings can change it to another tool such as `codex`; the plugin drives the terminal through AppleScript and `osascript` with no backend service, exits early on non-Darwin platforms, and may need macOS Automation permission on first launch.
