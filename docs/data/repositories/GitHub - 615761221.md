# maradotwebp/obsidian-avatar

Obsidian plugin that renders a small image with accompanying text from an avatar code block. The block takes YAML options: an image given as a vault path or a URL, a description that supports Obsidian's Markdown, the side the avatar is displayed on, a size of small, medium, large or a custom width in pixels, and an object position controlling how the picture sits inside its square container. In Live Preview the image and the description are edited by clicking them and in source mode the code block is edited directly, and when no image is given a picture of the file path initials is used instead.
