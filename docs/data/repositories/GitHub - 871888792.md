# ofalvai/flexoki-warm

Flexoki Warm is described as a slightly modified version of the Flexoki theme for Obsidian. Its README records the changes as follows: in light mode the backgrounds are not tinted yellow and revert to Obsidian's default colours, except for the sidebar and context menu backgrounds, which take a slightly warmer tint. It also records Style Settings options for overriding the accent colour with one from the Flexoki palette.
