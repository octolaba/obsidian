# chenxuan520/obsidian-voice2text

Voice2Text records speech in Obsidian on desktop and inserts the transcript at the editor cursor, with one rebindable hotkey starting and stopping the recording. Two providers are supported: Volcengine big-model ASR streams stable transcript segments into the note while the user speaks, and Xiaomi MiMo ASR uploads a WAV recording once capture stops and inserts the final transcript. The README states that the plugin connects only when recording starts, that both providers require the user's own account and credentials and may charge for them, that credentials are stored only in the current vault's plugin data, and that there is no telemetry, advertising or self-update. It is desktop-only because authenticated Volcengine WebSocket connections need Node.js networking support.
