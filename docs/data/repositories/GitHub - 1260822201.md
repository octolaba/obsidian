# Finarfin12/Multi-Vault-Plugin-Obsidian

This repository holds Multi-Vault Navigator, a local-first Obsidian plugin that lets several vaults be searched, viewed and switched between as though they were one unified workspace. Under the Obsidian developer policies the README discloses that the plugin accesses files outside the active vault, using Node's fs module to read the markdown of vaults configured by the user or detected from the operating system's global Obsidian configuration file, and states as the project's own claim that all operations are local with no files, metadata or telemetry sent anywhere. The README is also available in Indonesian.
