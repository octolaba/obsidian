# argenos/hotkeysplus-obsidian

Adds editor shortcuts for a set of list and block operations: toggling between checkmark states, switching between ordered and unordered lists, toggling blockquotes, and toggling embeds for internal links. Further commands contributed by other authors copy lines up or down, insert a line above or below the current one, and clear the current line; these ship without default bindings. The README lists the default hotkey for each bound action and credits the contributor behind each added command.
