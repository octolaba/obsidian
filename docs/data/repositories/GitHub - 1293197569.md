# onlymykazari/obsidian-nextcloud-deck

This repository holds NextDeck, an Obsidian Kanban plugin that stores every card as a real Markdown note in the vault and syncs two ways against the Nextcloud Deck REST API, forked from Task Deck and refocused on Nextcloud as the sync backend. Boards are unlimited and each keeps its cards in its own folder, with drag-and-drop list ordering, inline card creation and renaming, global coloured labels, start and due dates with a compact date picker, card details rendered as Markdown with checklist progress, and pick-up of Markdown cards created outside the board. The README records field-level conflict resolution during sync, opt-in experimental attachment sync keeping files inside Nextcloud, a sync log viewer with copyable diagnostics, and an app password stored encrypted so plaintext never touches disk.
