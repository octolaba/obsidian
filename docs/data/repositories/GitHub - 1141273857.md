# mattbirchler/quick-reads-obsidian

Quick Reads sync imports highlights from a Quick Reads account into Obsidian notes, grouping them by article so that each article gets one note and later highlights are appended to it. Synced highlight identifiers are tracked to avoid duplicate imports, and when no new highlights are available the plugin records the sync time and stops. Sync runs on demand from a command, a ribbon icon or the settings button, and optionally at startup and on a configurable interval. The README records a requirement of Obsidian 1.6.6 or newer plus an API key, and a note template with placeholders for the article id, title, author, site name, url and highlights.
