# UniRate-API/obsidian-currency

UniRate Currency renders exchange rates inline where an inline code span names a currency pair, replacing it with the current rate and returning a converted amount when an amount is included. Several separators and orderings are accepted, currency codes of three to five characters are matched case-insensitively, and decimal places, thousand grouping and the appended code are configurable. Commands insert a rate through a modal asking for currencies, amount and date, convert a selection written in plain language, and clear the in-memory cache, which the README says holds rates for sixty minutes by default. Rates come from the UniRateAPI service, whose free tier covers live rates while daily history back to 1999 and commodities require a paid plan.
