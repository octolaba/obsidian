# pejakovic/obsidian-convert-katex-to-mathjax

Convert KaTeX to MathJax rewrites KaTeX mathematical notation into the MathJax notation Obsidian renders, aimed at content copied from tools that emit KaTeX. Conversion can run automatically on paste, or through commands that paste with conversion, convert the current note, or batch-convert every Markdown file in the vault. Settings control the conversion heuristics: wrapping matrix and align environments as display math, treating plain parentheses or square brackets as inline math when their contents look like LaTeX, and wrapping bare inline LaTeX tokens in dollar signs.
