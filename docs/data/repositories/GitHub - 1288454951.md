# sphragis-oss/pinax

Pinax renders a dashboard over notes that already exist in a vault from a single profile.json file, stored under the plugin's own folder and hot-reloading when it is edited. Eleven widget types are recorded, among them folder listings, Markdown embeds, frontmatter-backed tables, forms that create a note or append to one, command buttons, an iframe, an activity heatmap, a board grouping records by a frontmatter field, and a single aggregated stat with an optional sparkline. The same codebase ships three profiles with no code difference, which the README gives as its reason for calling pinax a framework rather than an app.
