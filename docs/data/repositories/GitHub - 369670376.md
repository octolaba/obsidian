# ryanpcmcquen/obsidian-dropbox-backups

This plugin uploads the whole vault to Dropbox every twenty minutes after an initial ten-minute delay, with a ribbon icon that starts the authentication flow and also triggers a backup on demand. Backups are written into the application's own Dropbox folder under timestamped names that include fractional seconds to avoid collisions, and the icon's shape reports the current state from unauthenticated through upload progress to completion. A setting excludes binary files by keeping only Markdown, org and plain-text extensions, and the README records that anything outside that list is uploaded as binary. The README also lists the requested Dropbox permissions and states that the application only writes files, scoped to its own folder.
