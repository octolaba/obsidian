# yulei-chen/obsidian-mdx

Obsidian MDX previews MDX files in Obsidian, with support for Code Hike. MDX syntax is written in a note and a preview command is run from the command palette to render it. The README recommends turning on source mode while writing, points at a Code Hike example that can be copied into Obsidian to try that support, and records the project as MIT-licensed.
