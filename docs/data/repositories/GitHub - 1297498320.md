# 5ha99y0/obsidian-bionic-reader

BioRead is described as an ADHD accessibility plugin that applies Bionic Reading formatting to notes in Obsidian's Reading and Preview mode. It hooks into Obsidian's Markdown post-processor pipeline and bolds the first portion of every word to create visual fixation anchors, skipping code blocks, inline code, scripts and other non-prose elements. The README records a minimum Obsidian version of 1.0.0 and support for both desktop and mobile. The repository carries no description, so this summary rests on the README alone.
