# xhuajin/obsidian-settings-management

This plugin adds a menu in the bottom right corner of the Obsidian settings tab. From it a user can show all enabled or disabled plugins and CSS snippets, switch the list to a grid layout, and save the current plugin and snippet enablement as a named configuration that can later be applied in one step, with a right-click menu on a saved configuration to delete or rename it and an option to use a Lucide icon as its icon. The README states that styling issues can occur below Obsidian 1.11.7 and points to plugin version 1.0.6 for those cases.
