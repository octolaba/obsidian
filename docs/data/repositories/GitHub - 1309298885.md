# thequietmind/obsidian-github-linker

This repository is described upstream as the Obsidian GitHub Linker plugin, and its README names the plugin GitHub PR Linker. The README says a selected pull request reference is turned into a Markdown link by a command, accepting short forms with or without an owner, pull paths, and full URLs that may carry extra path segments, query strings or fragments, which are dropped from the generated link. A default owner setting fills in the owner for short forms, and a separate setting controls whether rewritten link labels include the owner.
