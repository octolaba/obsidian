# MkAuto/obsidian-simple-timestamp

Repository for Simple Timestamp, a plugin that writes the current date and time into a frontmatter property whenever a note is modified, with no command to run. Its README records a configurable property name and date format with a live preview in settings, and a default in which only notes that already carry the property are stamped unless creation of the missing property is enabled. Further options cover excluding whole folders with an autocomplete picker, filling that exclusion list from the configured folders of the core Templates and the Templater plugin, and a minimum interval between stamps. It states that the plugin never opens dialogs while editing, never moves the cursor and does not retrigger itself.
