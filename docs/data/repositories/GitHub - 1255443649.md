# carnalMATRIX/obsidian-mantle-zenith

Zenith is a desktop-only Obsidian theme and the stated aesthetic anchor of the Project Mantle ecosystem, using depth, subtle glows and backdrop blur. Its README describes floating capsule tabs in place of the standard header tabs, a color spectrum across heading levels, sidebars that expand on focus or hover, and dual palettes: a parchment light mode and a deep blue dark mode. It also records CSS hooks meant to pair with the Mantle plugins, and states that mobile support is not currently planned. Installation is documented through community themes, through BRAT for beta updates, or manually from a release.
