# 1yx/obsidian-plugin-say

Say reads the H1 heading of a linked note aloud when the cursor hovers over an internal link, falling back to the filename when the note has no H1. The README states that it drives the operating system's own speech tools — the macOS say command, spd-say or espeak on Linux, and the PowerShell speech synthesizer on Windows — and that the command, voice, speech rate and hover delay are all configurable. An optional arguments template with voice, rate and text placeholders overrides the voice and rate settings when it is filled in.
