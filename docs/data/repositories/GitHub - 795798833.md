# nicoletanyt/obsidian-plugin-graphs

This plugin plots graphs and vectors from LaTeX equations using FunctionPlot, aimed at visualising concepts in maths and physics. Selecting an equation and running the generate-graph command opens a new page holding the function, its plot, a helper that computes the value of y for a given x, and colour coding of the graphs; selecting a vector equation written with the vec command and running the draw-vector command opens the equivalent page with a helper that adds two vectors into a resultant one. Several graphs or vectors are drawn at once by separating the functions with a newline command inside the equation, and the settings cover axis labels, title, width, height, grid visibility and zooming.
