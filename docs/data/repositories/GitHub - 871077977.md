# glowingjade/obsidian-smart-composer

Smart Composer is a chat assistant inside Obsidian with vault context: conversations aware of the notes at hand, semantic search, one-click edits and support for local models. Recorded release notes add connecting a Claude, OpenAI or Gemini account directly without an API key, and connecting external tools and data sources over the Model Context Protocol. The README carries a maintenance notice stating that the plugin is kept by a single developer and is not under active development, with community forks collected in a discussion thread, and a warning that third-party subscription OAuth has been reported to get Claude accounts banned or restricted, so that flow is used at the reader's own risk.
