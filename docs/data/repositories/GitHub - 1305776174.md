# Jackyun6/knowstruct

The recorded description lists structured Markdown flashcards, reviews, document conversion and Canvas mind maps for Obsidian. The README calls it a local-first plugin that organizes each knowledge project through switchable Documents, Cards and Whiteboards tabs with rename, move and trash actions, cover grid or list layouts, batch selection and file import. Standalone .sccard cards open in Obsidian's native Markdown editor with Live Preview inside a KnowStruct card shell, cards can be imported into native Canvas nodes that stay connectable and collapsible, and large maps split into a main whiteboard with nested child boards, a hierarchy panel and per-board viewport restoration. It also covers native mark-syntax highlighting, text selection in PDFs and rectangular highlights over scanned pages, kept in five colours without modifying the PDF binary.
