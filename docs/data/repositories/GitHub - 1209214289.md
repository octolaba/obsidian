# theaspect/obsidian-toggl-import

Toggl Import inserts Toggl Track time entries into a daily note with one command, taking the date from the active note's filename and writing the formatted entries at the cursor. Output can be a Markdown table, plain text with a configurable delimiter, or a custom template with placeholders for description, start time, duration, tags and project, and the visible columns and the sort order by start time are configurable. The README states that the API token is stored device-locally rather than through Obsidian Sync, that a test button verifies the token against the Toggl profile endpoint before importing, and that running the command again appends new entries instead of replacing existing ones.
