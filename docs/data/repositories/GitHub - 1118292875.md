# marr00n/email2obsidian-plugin-releases

This repository publishes the official Obsidian plugin for the email2obsidian service, which turns email into notes: an email sent to a private ingestion address becomes a note carrying its subject, body and attachments. The README describes desktop and mobile support, syncing manually, on a schedule of one to twelve hours or daily, or when the vault opens, configurable note and attachment folders, and new notes that never overwrite existing files. It states that emails are deleted after 72 hours and are not sold, shared or used for AI training, and that there is no vault telemetry; it also records that the service is a paid one with a free trial and that the plugin authenticates with an API key.
