# jsifalda/obsidian-todos-sort

Todos Sort orders the todos in a note by completion status when a file is opened, rather than on every edit. The README records a four-tier priority running from incomplete through in-progress and completed to cancelled, read from the character inside the checkbox, where in-progress covers any character other than a space, an x or a hyphen. A setting chooses whether completed tasks are collected at the top or the bottom of the list, and the author states that the implementation is intended to handle large notes with little performance impact.
