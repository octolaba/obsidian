# ShadiestGoat/obsidian-simple-password

Simple Password puts a lock on selected paths in a vault without ever modifying a file. The vault is locked on load and unlocked by entering the configured password; while locked, opening or previewing a file under a protected path prompts for the password, and the chosen privacy mode decides whether protected tabs are closed and reopened afterwards or the modal background is merely blurred. Protection extends to page previews, embeds and search, optionally to graph view, cancelling is allowed so unprotected parts stay readable, and locking runs from a command, a hotkey, the ribbon or a custom address. The README warns explicitly that the plugin does not encrypt files and names other plugins for anyone needing real security.
