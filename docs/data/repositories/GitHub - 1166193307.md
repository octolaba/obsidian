# Niko-Drossos/bookmarks-API

Bookmark API exposes global functions for managing Obsidian bookmarks programmatically from Templater, Dataview or any script running inside Obsidian. The functions are registered on the window object when the plugin loads: one adds a file to a group and creates the group if needed, two more remove a file from a group or move it between groups, and a fourth deletes a group and can optionally trash its files. The file path parameter is optional and defaults to the active file, paths without a Markdown extension are normalised, duplicates are skipped, and a bookmark can carry a custom display title. The README states that Obsidian's built-in Bookmarks core plugin must be enabled.
