# mProjectsCode/obsidian-media-db-plugin

The repository holds Media DB, an Obsidian plugin that queries several external APIs for films, series, anime, manga, books, comics, games, music and wiki articles and imports the results into a vault as notes. Its README records searching either by title across those APIs or by an identifier whose form depends on the API, and a template note appended to anything the plugin creates, with simple template tags such as a title placeholder substituted on import. It warns readers to consult the README on the release branch rather than the development one, and the code is licensed under the GNU GPL version 3.
