# gibsonchan-5/PaperCraft

PaperCraft styles the note surface as manuscript paper through a settings panel rather than CSS snippets, with a preview area that updates as parameters change and an apply step that pushes the result to notes. Sixteen templates cover ruled, vertical, grid and dot-grid layouts, and the underlying parameters are exposed individually: four paper textures with adjustable opacity and scale, line patterns with spacing, thickness and colour, paper and text colours, and page margins on all four sides. Typography settings target Chinese text, offering more than thirty-five font presets, letter spacing up to 0.5em and line height between 1.0 and 3.0. An existing CSS file can be imported and parsed into those visual parameters, and an SVG layer allows drawn annotations.
