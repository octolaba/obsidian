# SdKay/obsidian-rich-table

Rich Table renders an interactive table from a rich-table fenced code block, adding what the README contrasts against native Markdown tables: merged cells, click-to-edit cells, wikilink autocomplete, KaTeX formulas, lists and images inside cells, multi-line content, typed columns such as status and priority, per-cell styling, column alignment, a table title and footer, drag-to-reorder and drag-to-resize, row filtering and a per-table lock. Empty blocks offer built-in templates or a blank table, and the README records a migration from the v0 format with an upgrade banner that converts old tables in one click or keeps them read-only. It also states that the plugin is Obsidian-only, because the code block is not rendered by standard Markdown editors or GitHub previews.
