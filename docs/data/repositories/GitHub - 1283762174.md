# SdKay/obsidian-rich-table

Rich Table renders an Obsidian-specific table block with inline cell editing, merged cells, typed columns, wikilink completion, formulas, lists, images, and per-cell styling. It also supports titles and footers, filtering, row or column insertion and deletion, drag reordering, resizing, and per-table locking, with a migration path for older table formats.
