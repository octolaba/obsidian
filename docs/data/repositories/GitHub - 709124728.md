# srz2/obsidian-jira-linker

The recorded description says the plugin adds a quick amendment to a note, linking references to a configured Jira instance and to internal info pages. The README explains that it inserts either a web URL for a Jira issue or a local URI for that issue's folder, and that any number of Jira instances can be configured, the first listed one acting as the default unless another is selected in the settings. Its three commands link an issue to a chosen instance, to the default instance, or to a local file whose path is created when it does not exist, which requires the local issue path to be set and uses a main file name defaulting to _Info. The issue key comes from the editor selection, or from a modal when nothing is selected, and the text is replaced with the link.
