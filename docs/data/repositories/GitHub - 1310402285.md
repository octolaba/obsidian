# takeshy/obsidian-dashboard-hub

Repository for Dashboard Hub, an Obsidian plugin that gathers Bases, files, Kanban boards, calendars, timelines, web pages, reading memos and encrypted secrets into one responsive dashboard. Actions such as moving a Kanban card, rescheduling a calendar event or saving a reading memo can be recorded as callouts in dated Markdown timeline files, one per day, beside posts written by hand with tags, links and attachments. Reading memos are taken from selected text in a PDF, EPUB or Markdown document together with quote context, and the secret manager keeps values as encrypted files, using a public key to encrypt and a password-protected private key to decrypt. The README states that it works without an AI account, API key or external database.
