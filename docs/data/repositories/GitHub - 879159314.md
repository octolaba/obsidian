# Telehakke/masking-type

The recorded repository description says only that this is an Obsidian plugin, so the detail here comes from the README, which is written in English and Japanese. Masking Type hides text that is bold, italic or highlighted in order to support memorization, filling in the item types enabled in the settings, and a filled area is revealed by clicking it. Masking can also be set per note by pasting a property copied from the settings at the beginning of the note and checking the items to hide, while a hint type of blur or peek shows a hint before the whole text is displayed. The README records a desktop-only option that converts filled areas into cloze questions when exporting to PDF.
