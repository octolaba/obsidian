# adamfletcher/obsidian-sentence-rhythm

Sentence Rhythm applies a coloured highlight to each sentence according to its length, so the variety of sentence lengths in a piece of writing can be seen at a glance; the README attributes the idea to Gary Provost's advice on varying sentence length. The highlighting is toggled on and off from the command palette or from the plugin settings. Those settings also carry the size thresholds for the five categories, from extra short to extra long, and the colour used for each, and the plugin applies a CSS class per category that a user stylesheet can restyle.
