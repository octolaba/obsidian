# hosikiti/obsidian-reorderable-lists

Adds a drag handle that appears on hover beside any list item in the Live Preview editor, letting the item be dragged to a new position with a line marking where it will drop. It works with unordered, ordered and task lists, moves an item's nested children along with it, and keeps the scroll position after the reorder. Settings control the semi-transparent ghost image shown while dragging, whether the handle sits at the far left of the line or just left of the bullet marker, and the gap between handle and marker; the README states Live Preview on desktop only.
