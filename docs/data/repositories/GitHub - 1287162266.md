# justinrosales/obsidian-swipe-gestures

This plugin maps two-finger horizontal trackpad swipes to any Obsidian command, with back and forward navigation as the default. The README states that it listens to the browser WheelEvent API rather than a proprietary Apple gesture API, detects horizontal-enough movement and then fires the configured command. Sensitivity and the required horizontal dominance are configurable, a half-circle indicator appears when a gesture triggers, macOS momentum scrolling is filtered so the command fires after the finger lifts rather than during the inertia tail, and the plugin is desktop only.
