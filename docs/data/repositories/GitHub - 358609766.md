# beaussan/update-time-on-edit-obsidian

This plugin writes the file's modification time, and its creation time when none is recorded yet, into frontmatter properties on save, defaulting to keys named updated and created. The date format is configurable, string and number property types are both supported so Unix timestamps can be stored, and folders can be excluded from all updates or from the creation property alone. Values are read from Obsidian and therefore from the file system, so a change made by an external source also updates the keys, and the README asks that the vault be backed up because the plugin modifies files.
