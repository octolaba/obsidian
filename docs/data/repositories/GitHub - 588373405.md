# ImaginaryProgramming/obsidian-vault-transfer

Vault Transfer copies the contents of a note into another Obsidian vault and then links to it from the original. The output vault and optional output folder are set in settings, together with whether a link back is created — and, when it is not, whether the original note may be deleted — and whether an existing file in the target vault is overwritten. Several notes can be transferred at once, in which case a folder of the same name is created in the target and the notes are moved inside it, and the file menu can send a note or folder to a chosen or newly created target folder. Other commands insert a link to the current note in the other vault without transferring it, and pick the target from a list when a root directory of vaults is configured.
