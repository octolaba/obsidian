# bkyle/obsidian-vault-statistics-plugin

Obsidian plugin that adds a status bar item carrying vault statistics such as the number of notes, files, attachments and links. Clicking the item cycles through the available statistics and hovering shows all of them, while a CSS snippet can display them all, or a chosen subset, at once. Its changelog records later additions including a settings pane, a word count and a vault size metric, and fixes covering admonitions, comment sections and renamed or deleted files.
