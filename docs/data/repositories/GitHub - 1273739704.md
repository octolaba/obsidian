# joshua-walls/trailmark-theme

Trailmark is an Obsidian theme for focused notes and technical writing, using a restrained outdoor-industrial palette of deep moonstone, harvest orange, seafoam, fog and cloud surfaces. Moonstone carries navigation, table headers and page framing, harvest orange marks emphasis, and seafoam keeps dark-mode links crisp, while dark surfaces are layered so notes, callouts, code and metadata stay distinct. The README also records a winding-trail identity layer with route gradients, waypoint dots, dashed folder trails, a callout hierarchy, Dataview state styling and tuned graph colors, and states that the theme is tuned for both Live Preview and Reading View.
