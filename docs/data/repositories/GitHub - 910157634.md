# blotspot/obsidian-markdown2html

This plugin copies a note from Obsidian to the clipboard as HTML. The README states that the conversion runs Obsidian's own Markdown renderer over the selection or the whole document, so content added by other plugins is included, then cleans the result by removing tag attributes and classes except those listed in the settings, converting internal images below a size limit into base64 strings, and removing empty paragraphs. A second command copies the full note as text without its frontmatter, and the README states that generating a complete HTML page is deliberately out of scope.
