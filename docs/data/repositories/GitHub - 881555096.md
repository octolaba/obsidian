# JoramMillenaar/obsidian-similarity

Similarity searches an Obsidian vault by meaning rather than by keyword, offering a semantic search over the vault and a view that lists notes related to the current one. The README states that all processing happens on the device, that no external APIs are called and no data leaves the machine, that no internet connection is required after installation, and that there is no tracking or telemetry. It positions the plugin against others in the same space by its priorities: local by design, low overhead as a vault grows, and semantic discovery rather than language-model agents.
