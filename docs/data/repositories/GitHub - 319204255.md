# DahaWong/obsidian-completed-area

Completed Area moves completed to-do items in the active note into a separate completed area, toggling the item as it goes. It is triggered by clicking the sidebar icon or by a shortcut, Control plus Enter by default, and the sidebar icon can be turned off so that only the command remains. Settings choose the heading level of the completed area, from 1 to 6 with 2 as the default, and its heading name, which defaults to Completed. The README warns that the plugin may contain bugs and that more features are still being developed.
