# NetEase + Discogs Sync

NetEase + Discogs Sync writes NetEase Cloud Music plays and Discogs collections into the vault as one Markdown note per song and one per record, carrying metadata, timestamped lyrics and tracklists without downloading audio. Metadata is drawn from the local NetEase cache, Last.fm and the Discogs API, rendered through a swappable template and deduplicated by service ID. The recorded description states that tokens stay local, that nothing is uploaded, and that the plugin is desktop only.
