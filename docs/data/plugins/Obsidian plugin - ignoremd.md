# ignoreMD

ignoreMD adds a compact hover button that opens a formatting panel for headings, bold, italic, highlight, quotes, unordered, ordered and task lists, inline code, code blocks and links. Common Markdown formats are applied without typing the syntax, and its recorded inputs state that everything stays local, with no telemetry, network calls or background tasks.
