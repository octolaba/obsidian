# Todos sort

Todos sort orders the checkboxes of the current note by completion status when the note is opened. Tasks are grouped into four tiers, namely incomplete, in-progress, completed and canceled, and completed items can be placed either at the top or at the bottom. The sort is intended to stay fast on large notes.
