# Arabic Poetry Formatter

Formats selected Arabic poetry into paired or indented hemistich layouts that align the hemistiches of each verse. Spacing is configurable, and the alignment combines character counts with visual-width estimation for proportional Arabic fonts. The formats are reachable from the command palette, the context menu and the ribbon.
