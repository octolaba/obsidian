# Kuaifanyi

Translates a selection as soon as it is made, using dictionary lookups for short words and streaming translation for longer text. AI explanations render in parallel, language direction is detected automatically, and neural text-to-speech from Volcano Engine reads the result aloud with optional voice cloning. The popup is draggable and resizable, and OpenAI-format APIs such as DeepSeek are supported.
