# Simple Colored Folder

Simple Colored Folder colors root-level folders automatically, each in its own color, updating in real time and following light and dark themes. Each root folder's color and style is customized through Style Settings, which the plugin requires, and the styling is preserved when a folder is renamed.

    id:     "simple-colored-folder"
    name:   "Simple Colored Folder"
    author: "Mara"
