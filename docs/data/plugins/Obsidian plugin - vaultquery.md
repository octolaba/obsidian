# VaultQuery

VaultQuery indexes notes, frontmatter, tables, tasks, headings, links and tags into a SQLite database and runs SELECT, INSERT, UPDATE and DELETE statements against them. Results render as SlickGrid, Markdown tables, Chart.js charts or custom HTML. SQL views and JavaScript scalar functions can be defined for reusable logic.
