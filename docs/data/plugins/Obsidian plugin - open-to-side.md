# Open to Side

Opens links in the existing tab group to the right instead of creating a new split each time, triggered by Cmd+Alt+click on macOS, Ctrl+Alt+click on Windows and Linux, or another chosen modifier. A single side preview is reused across Live Preview, Reading view, the file explorer, search and backlinks. Pinned tabs and the current focus are preserved.
