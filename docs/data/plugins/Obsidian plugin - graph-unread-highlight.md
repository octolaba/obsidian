# Graph Unread Highlight

Highlights new or recently edited notes in the global and local graph views with a coloured ring that follows nodes as they pan, zoom or move. One command marks everything as read, and opening a note clears its own ring. Detection compares each file's last-modified time with when it was last viewed.

    id:     "graph-unread-highlight"
    name:   "Graph Unread Highlight"
