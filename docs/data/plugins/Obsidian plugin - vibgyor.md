# vibgyor

vibgyor sets per-note page, text, link and accent colors and adds selectable background patterns, configured through a visual editor or through frontmatter. Built-in presets can be applied or reusable palettes created, transparent images are optionally tinted to match the pen color, and changes update in real time.
