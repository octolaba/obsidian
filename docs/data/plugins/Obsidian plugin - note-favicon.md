# Note Favicon

Note Favicon shows a favicon beside a note's title in the file tree, taken from a URL in that note's frontmatter. Base64-encoded images are accepted as well as standard URLs, and the icon updates in real time as the frontmatter is added, modified or removed.

```cue
plugin: {
    id:     "note-favicon"
    name:   "Note Favicon"
    author: "mdklab"
    repo:   "mdklab/note-favicon"

    html_url:    "https://community.obsidian.md/plugins/note-favicon"
    github_url:  "https://github.com/mdklab/note-favicon"
    description: "Extracts a URL from the frontmatter of notes and displays an associated favicon image next to the note title in the file tree. Supports standard URLs and base64-encoded images."
    about:       "Display favicons next to note titles in the file explorer using a URL or base64 image specified in a note's frontmatter. Update icons in real time as frontmatter metadata is added, modified, or removed."

    stats: {
        downloads:  1141
        updated_at: 1743766970000
    }
}
```
