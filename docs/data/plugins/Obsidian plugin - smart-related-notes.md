# Smart Related Notes

Smart Related Notes lists the notes most semantically similar to the one being read in a left-sidebar panel, so the vault can be browsed by meaning instead of by folders. A compact multilingual embedding model is downloaded once, cached and run locally, so ranking happens offline. Matches appear as clickable cards carrying a snippet and a similarity score.
