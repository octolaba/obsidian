# svgeditor

Edits and creates .svg files inside the vault using an integrated SVG-edit vector editor. The recorded About text lists opening SVGs from the file menu, the ribbon or an inline pencil, and drawing tools, layers, rulers and grids, styling, source editing and export. Edits are buffered as a draft before being saved back to the vault.
