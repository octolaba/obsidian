# Canvas to PDF

Exports an Obsidian canvas to a vector PDF or a standalone HTML file in which the text stays selectable and searchable. Connectors, arrows, labels, embedded images, web previews, embedded PDFs and nested canvases up to five levels deep are preserved. The export runs locally on the machine, with no cloud service and no tracking.

    id:     "canvas-to-pdf"
    name:   "Canvas to PDF"

    html_url:    "https://community.obsidian.md/plugins/canvas-to-pdf"
