# Topic Linking

PDF content is extracted and web links are converted into Markdown notes, so that the documents become searchable inside the vault. Bibliographies are generated in readable form from Zotero exports, and topic notes are created from topics found across PDFs and bookmarks, linking back to the source documents.

```cue
plugin: {
    id:     "obsidian-topic-linking"
    name:   "Topic Linking"
    author: "liammagee"
    repo:   "liammagee/obsidian-topic-linking"

    html_url:    "https://community.obsidian.md/plugins/obsidian-topic-linking"
```
