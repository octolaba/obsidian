# Fit

Syncs vault files across mobile and desktop through GitHub, either on one click or automatically. Conflicting remote changes are written into a local _fit folder for manual comparison and merging instead of failing the sync. Markdown files and attachments are included while the .obsidian settings and hidden files are excluded.
