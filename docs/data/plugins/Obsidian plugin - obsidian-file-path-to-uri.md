# File path to URI

Converts local file and folder paths into URIs or Markdown links so that items outside the vault can be linked. A selected path is toggled between plain path and URI form, converted URIs are pasted from the clipboard, and Markdown links use either the full path or just the name as link text.

```cue
plugin: {
    id:     "obsidian-file-path-to-uri"
    name:   "File path to URI"
    author: "michalbures"
    repo:   "michalbures/obsidian-file-path-to-uri"

    html_url:    "https://community.obsidian.md/plugins/obsidian-file-path-to-uri"
    github_url:  "https://github.com/michalbures/obsidian-file-path-to-uri"
    description: "Convert file path to URI for easier use of links to local files outside of Obsidian."
    about:       "Convert local file and folder paths into file:// URIs or Markdown links so you can link to items outside your vault. Toggle selected paths between plain path and URI, paste converted URIs from the clipboard, or insert Markdown links using the full path or just the name as link text."

    stats: {
        downloads:  23580
        updated_at: 1662293177000
    }
}
```
