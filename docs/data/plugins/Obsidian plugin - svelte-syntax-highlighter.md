# Svelte Syntax Highlighter

Svelte code blocks are given syntax highlighting in Obsidian. Highlighting also runs live in the editor through a CodeMirror extension integrated with Prism.

    id:     "svelte-syntax-highlighter"
    name:   "Svelte Syntax Highlighter"
    author: "typhoon-kim"
    repo:   "typhoon-kim/obsidian-svelte-syntax-highlighter"

    html_url:    "https://community.obsidian.md/plugins/svelte-syntax-highlighter"
