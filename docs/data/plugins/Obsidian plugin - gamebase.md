# Gamebase

Searches video games through the IGDB API and generates notes from custom markdown templates, so release dates, developers and genres do not have to be typed by hand. A game is looked up from the command palette or a ribbon icon, and a bulk import staging interface queues several games and imports them in one click. The recorded About text is promotional and its claims are not repeated here.
