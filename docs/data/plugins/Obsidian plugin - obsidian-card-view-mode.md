# Card View Mode

Card View Mode displays notes as adjustable cards that scale with their content, so note maturity is visible and atomic writing encouraged. An Attention Pane highlights the active pane and dims the others to keep focus on a single note, and card colours, shapes and sizing are configurable.

```cue
plugin: {
    id:     "obsidian-card-view-mode"
    name:   "Card View Mode"
    author: "yo-goto"
    repo:   "yo-goto/obsidian-card-view-mode"

    html_url:    "https://community.obsidian.md/plugins/obsidian-card-view-mode"
    github_url:  "https://github.com/yo-goto/obsidian-card-view-mode"
```
