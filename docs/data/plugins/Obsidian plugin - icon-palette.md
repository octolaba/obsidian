# Icon Palette

Icon Palette assigns custom icons and colors to files, folders, tabs, tags, properties, bookmarks and commands, drawing on Lucide icons, emojis, Simple Icons and Devicon. Nine theme colors or any RGB value are applied, recent and pinned combinations are reused, and a rulebook assigns icons automatically by name, path, tags, properties or dates.
