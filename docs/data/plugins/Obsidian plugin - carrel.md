# Carrel

Carrel turns one or more vault folders into a column-balanced board of typed reference cards for browsing, sorting and studying notes. Cards can be pinned, filtered, searched and expanded to read their content in place, with favorites kept on a rail. Boards embed inline or open as a full workspace pane, and the plugin states that it integrates with the Wayfinder character sheet.
