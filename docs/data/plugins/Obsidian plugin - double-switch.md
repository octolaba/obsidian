# Auto switch themes between dark and light mode

Switches the Obsidian theme automatically when the app toggles between light and dark mode. One theme is chosen for each mode and applied as soon as the mode changes.

```cue
plugin: {
    id:     "double-switch"
    name:   "Auto switch themes between dark and light mode"
    author: "carlrobert"
    repo:   "carlrobert/double-switch"

    html_url:    "https://community.obsidian.md/plugins/double-switch"
    github_url:  "https://github.com/carlrobert/double-switch"
    description: "Toggling dark/light mode switches themes automatically"
```
