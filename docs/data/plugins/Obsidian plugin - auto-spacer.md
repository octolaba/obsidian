# Auto Spacer

Auto Spacer tidies mixed CJK and Latin typography by inserting spaces at the boundaries and wrapping English segments in inline code. It detects Chinese, including Japanese kana and kanji, next to Latin text, skips existing backticks, links, tags and other markdown, and formats either the selection or the current line.

plugin: {
    id:     "auto-spacer"
    name:   "Auto Spacer"
    author: "fanthus"
    repo:   "fanthus/obsidian-auto-spacer"

    html_url:    "https://community.obsidian.md/plugins/auto-spacer"
    github_url:  "https://github.com/fanthus/obsidian-auto-spacer"
    description: "Wrap mixed English segments with inline code and insert CJK-adjacent spaces. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert spaces at CJK–Latin boundaries and wrap English segments in inline code to tidy mixed CJK–English typography. Detect Chinese (including Japanese kana/kanji) mixed with Latin, skip existing backticks, links, tags and other Markdown, and format the selection or current line."
