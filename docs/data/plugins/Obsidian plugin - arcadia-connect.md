# Arcadia Connect

Runs a personal CRM inside the vault, linking contacts through at-mentions and exposing them in a searchable people panel and hover profile cards. Calls, emails, meetings and notes are logged into a timeline, and deals are tracked on a Kanban pipeline with value totals and reminders. Follow-up suggestions come from AI, using the user's own OpenAI or Anthropic key.
