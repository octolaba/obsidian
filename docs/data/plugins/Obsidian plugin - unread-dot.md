# Unread Dot

Marks a newly created file in the file explorer with a blue dot that clears the first time the note is opened. The unread state survives a restart and follows a file that is renamed or moved, and a file is marked read or unread from the right-click menu or a command.

```cue
plugin: {
    id:     "unread-dot"
    name:   "Unread Dot"
    author: "denmojo"
    repo:   "denmojo/obsidian-unread-dot"

    html_url:    "https://community.obsidian.md/plugins/unread-dot"
    github_url:  "https://github.com/denmojo/obsidian-unread-dot"
    description: "Marks unopened notes with a blue dot in the file explorer. Auto-clears the moment the note is opened. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Mark newly created files in the file explorer with a blue dot that clears the first time you open them, making unread notes easy to spot. Persist unread state across restarts, preserve it when renaming/moving files, and mark files read/unread via right-click or commands."

    stats: {
        downloads:  509
        updated_at: 1782393716000
    }
}
```
