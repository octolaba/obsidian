# TTRPG Maps

Renders interactive tabletop RPG maps from code blocks as pannable, zoomable images with smooth viewport rendering. Markers are customisable, link to notes and show hover previews, marker templates can be reused, and zoom-based visibility layers control what appears at each level. Scales are calibrated so distances can be measured with unit conversion.
