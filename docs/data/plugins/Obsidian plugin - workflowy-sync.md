# Workflowy Sync

Sends the current line, selected text, or a Markdown outline from a note to Workflowy, targeting either a saved destination or one picked on demand. A workflowy code block embeds live Workflowy nodes inside a note, and one-to-one sync mappings move items in either direction, manually or on a schedule, into a managed heading block.

```cue
plugin: {
    id:     "workflowy-sync"
    name:   "Workflowy Sync"
    author: "rodolfo-terriquez"
    repo:   "rodolfo-terriquez/workflowy-sync"

    html_url:    "https://community.obsidian.md/plugins/workflowy-sync"
    github_url:  "https://github.com/rodolfo-terriquez/workflowy-sync"
    description: "Quickly send content to Workflowy, embed live outlines, and sync Workflowy items with notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Connect Obsidian to Workflowy to send selected text or the current line, push Markdown outlines, and pick a saved or on-demand target. Embed live Workflowy nodes with a workflowy code block and create one-to-one sync mappings to sync either direction manually or on a schedule into a managed heading block."
```
