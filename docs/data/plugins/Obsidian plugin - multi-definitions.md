# Multi Definitions

Keeps a personal dictionary in which a term carries several explanations plus optional aliases, with Markdown allowed inside an entry. Recognized terms are marked in Reading view and Live Preview, showing a quick preview on desktop hover and a full definition card on click or tap, while stylus input is ignored to avoid accidental popups. Definitions live in Multi Definitions/definitions.json so they travel with the vault, and the longest matching term wins over shorter ones.

```cue
plugin: {
    id:     "multi-definitions"
    name:   "Multi Definitions"
    author: "Daniel Xu"
    repo:   "decai335335-debug/obsidian-multi-definitions"

    html_url:    "https://community.obsidian.md/plugins/multi-definitions"
    github_url:  "https://github.com/decai335335-debug/obsidian-multi-definitions"
    description: "Save multiple explanations for terms and preview them by hover or tap across your notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create a personal dictionary that saves multiple explanations per term, supports optional aliases, and accepts Markdown in entries. Display recognized terms in Reading View and Live Preview, show quick previews on desktop hover, open full definition cards on click or tap, and ignore stylus input to prevent accidental popups. Store definitions in Multi Definitions/definitions.json for vault-wide sync and match longest terms first to avoid shorter-term collisions."
```
