# Heading Handler

Heading Handler applies heading commands that follow indentation and the level of the parent heading, so hierarchy is kept in plain text and in unordered lists. Promote and demote work on a single line or a multi-line selection, and clamp or remove a heading when the change would break the structure. A heading can also be removed while its text is kept.
