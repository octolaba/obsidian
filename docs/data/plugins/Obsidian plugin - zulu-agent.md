# Zulu Agent

Zulu Agent runs an agentic AI assistant inside the vault. From a chat interface it searches, reads and modifies Markdown, base and canvas files and folders, edits CSS snippets through natural language, and stores prompts with vault or open-file context. Local models served by LM Studio and Ollama are supported.

plugin: {
    id:     "zulu-agent"
    name:   "Zulu Agent"
    author: "foundlegacy"
    repo:   "foundlegacy/zulu-agent"

    html_url:    "https://community.obsidian.md/plugins/zulu-agent"
    github_url:  "https://github.com/foundlegacy/zulu-agent"
    description: "Fully native Agentic AI for Obsidian.md, no terminal/external tools required. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Chat with your notes using native agentic AI that can search, read, and modify files and folders from a conversational interface. Create, edit, rename and delete .md, .base and .canvas files and folders; edit CSS snippets through natural language; save prompts and use vault and open-file context. Supports local models (LM Studio & Ollama)."
