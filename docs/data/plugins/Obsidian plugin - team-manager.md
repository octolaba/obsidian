# Team Manager

Team Manager keeps people, one-to-ones, projects and action items in the vault as plain Markdown with YAML frontmatter. A dashboard reports cadence health, an agenda buffer preserves the notes captured between meetings, and a Kanban board and performance observations sit beside the project logs. A universal quick capture feeds all of them.

```cue
plugin: {
    id:     "team-manager"
    name:   "Team Manager"
    author: "Andre Guy Carvalho"
    repo:   "andyguy-dot/obsidian-team-manager"

    html_url:    "https://community.obsidian.md/plugins/team-manager"
    github_url:  "https://github.com/andyguy-dot/obsidian-team-manager"
```
