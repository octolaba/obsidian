# Image Zoom

Opens an image fullscreen when it is clicked in reading or live preview mode. The mouse wheel zooms around the cursor and dragging pans the image, while Esc or a click on the dark background closes the view. The recorded inputs describe the implementation as dependency-free, driven by requestAnimationFrame and with isolated CSS.
