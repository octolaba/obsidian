# Webpage HTML Export

Exports single notes, canvas pages or an entire vault to HTML files that can be published anywhere. The exported output can include full-text search, a file navigation tree, a document outline, a graph view and a theme toggle, and it supports a number of popular plugins. HTML and its dependencies can also be bundled into a single file.

```cue
plugin: {
    id:     "webpage-html-export"
    name:   "Webpage HTML Export"
    author: "kosmosisdire"
    repo:   "kosmosisdire/obsidian-webpage-export"

    html_url:    "https://community.obsidian.md/plugins/webpage-html-export"
    github_url:  "https://github.com/kosmosisdire/obsidian-webpage-export"
    description: "Export html from single files, canvas pages, or whole vaults. Direct access to the exported HTML files allows you to publish your digital garden anywhere. Focuses on flexibility, features, and style parity."
    about:       "Export HTML from single notes, canvas pages, or entire vaults for direct publishing. Include full-text search, file navigation tree, document outline, graph view, theme toggle, and support for popular plugins, with an option to bundle HTML and dependencies into a single file."

    stats: {
        downloads:  145445

}
```
