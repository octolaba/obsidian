# Mode manager

Mode manager provides dedicated commands to switch the editor to a specific mode, reading, source or live preview, instead of relying on the default toggle. A file-level property named default-mode opens a file in a chosen mode, and modes can also be cycled through sequentially.

    id:     "mode-manager"
    name:   "Mode manager"
    author: "dk949"
    repo:   "dk949/obsidian-mode-manager"
