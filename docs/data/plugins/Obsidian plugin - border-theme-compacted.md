# Border Theme Compacted

Produces a denser desktop layout for the Border theme: outer spacing is reduced, editor and sidebar tabs are aligned with the title-bar controls, and the original Ribbon is compacted. A status-bar button opens the available Ribbon actions in a scrollable pop-up menu, and right-clicking that button shows or hides the original Ribbon. The layout applies only while Border is selected and other themes are restored automatically, with no separate CSS snippet or build step involved.
