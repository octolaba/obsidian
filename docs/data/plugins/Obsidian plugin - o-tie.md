# O-Tie

Builds and edits risk bowtie diagrams in a visual editor inside the vault, modelling hazards, threats, prevention and mitigation barriers, top events and consequences. The editor supports pan and zoom, barrier stacks, escalation factors, per-barrier analysis, undo and redo, and PNG export, and changes are saved automatically to .bowtie files.
