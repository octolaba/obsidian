# Frontmatter Input

Manages frontmatter tags through interactive nested checkbox and radio lists that can be embedded in templates or notes. Hierarchical tags are defined as parent, child and grandchild entries; selecting a parent updates the frontmatter and reveals its child list, duplicate tags are prevented, and child tags are removed when the parent is unchecked. Lists can be laid out vertically or horizontally.

Prevent duplicate tags and auto-remove child tags when parents are unchecked, with optional vertical or horizontal layouts."
