# TreeTalk

Organizes AI conversations as a tree, where any node can be continued or branched, and selected notes or earlier dialogue can be attached as context. Replies stream in with evidence pulled on demand from notes or the web, and failed runs can be resumed. A single answer or a whole tree can be exported as plain Markdown with source-linked excerpts.

```cue
plugin: {
    id:     "treetalk"
    name:   "TreeTalk"
    author: "Len_San"
    repo:   "safasffa111/TreeTalk-Obsidian"

    html_url:    "https://community.obsidian.md/plugins/treetalk"
    github_url:  "https://github.com/safasffa111/TreeTalk-Obsidian"
    description: "Asking your vault is cheaper.Native Markdown tree conversations with deliberate knowledge capture. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Organize AI conversations into a tree structure, continue or branch any node, and attach selected notes or dialogue as context. Stream replies with on-demand evidence from notes or the web, resume failed runs, and export single answers or whole trees as pure Markdown with source-linked excerpts."

    stats: {
        downloads:  23
        updated_at: 1786353359000
    }
}
```
