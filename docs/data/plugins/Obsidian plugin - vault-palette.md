# Vault Palette

Assigns colors to folders, files and tags: a background, border and text color per item, together with bold, italic and opacity. Appearance is set by right-clicking an item in the file explorer, a folder style can be applied to subfolders or files, presets can be saved, and stable rainbow filenames and per-tag backgrounds with a shared tag text color are available.
