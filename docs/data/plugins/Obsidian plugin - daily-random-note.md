# Daily Random Note

Opens random notes drawn from selected folders and tags at a time of day that you choose. A single random note can also be opened on demand from the ribbon icon.

```cue
plugin: {
    id:     "daily-random-note"
    name:   "Daily Random Note"
    author: "d4rkp1xel"
    repo:   "d4rkp1xel/daily-random-note"

    html_url:    "https://community.obsidian.md/plugins/daily-random-note"
    github_url:  "https://github.com/d4rkp1xel/daily-random-note"
    description: "Automatically open daily random notes based on your preferences."
    about:       "Schedule daily random notes from selected folders and tags to open at a time you choose, refreshing your memory with past notes. Open a single random note on demand using the ribbon icon."
```
