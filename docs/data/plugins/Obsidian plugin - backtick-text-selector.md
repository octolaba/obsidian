# Backtick text selector

Backtick text selector selects text wrapped in backticks from the keyboard. Alt with an apostrophe selects the next backtick-enclosed text, and adding Shift selects the previous one.

```cue
plugin: {
    id:     "backtick-text-selector"
    name:   "Backtick text selector"
    author: "cool-rr"
    repo:   "cool-rr/backtick-text-selector"

    html_url:    "https://community.obsidian.md/plugins/backtick-text-selector"
    github_url:  "https://github.com/cool-rr/backtick-text-selector"
    description: "Easily select text in backticks."
    about:       "Select text wrapped in backticks quickly with keyboard shortcuts. Use Alt+' to select the next backtick-enclosed text and Alt+Shift+' to select the previous."
```
