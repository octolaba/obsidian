# 3D Codeblocks

3D Codeblocks renders GLB, glTF and STL models inline in a note and lets them be orbited, zoomed and panned without leaving Obsidian. Models are embedded by opening a file, by wiki-embed, from a 3D code block or from inline glTF JSON, with optional captions and fixed heights. Views stay live-updated when the source file changes, and unsupported compressed files produce a clear message.
