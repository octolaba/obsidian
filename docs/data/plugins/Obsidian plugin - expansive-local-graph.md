# Expansive Local Graph

Patches the local graph so individual nodes can be expanded past Obsidian's native depth limit on demand. The newly linked notes are drawn as overlay nodes that stay attached through redraws and dragging, expansions can be nested, and expanded roots are marked with coloured rings and branch colours. Its recorded description calls the patch experimental.
