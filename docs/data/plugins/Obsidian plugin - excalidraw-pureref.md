# Excalidraw PureRef

Opens an Excalidraw board as a chrome-free, always-on-top popout for use as a PureRef-style reference surface, with opacity and transparency controls. Elements on the board can be arranged and packed, and media imported or exported. It also allows drawing and placing elements in front of video, PDF, Markdown and web embeds, which default Excalidraw does not.
