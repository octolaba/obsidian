# ChatGPT Definition

ChatGPT Definition asks OpenAI GPT-3 for a concise definition, building the prompt from the note's title and its tags. The generated definition is appended to the end of the file and the note's status is updated to record that it was written by the AI.

```cue
plugin: {
    id:     "chatgpt-definitions"
    name:   "ChatGPT Definition"
    author: "julix14"
    repo:   "julix14/chatGPT-Obsidian"

    html_url:    "https://community.obsidian.md/plugins/chatgpt-definitions"
    github_url:  "https://github.com/julix14/chatGPT-Obsidian"
    description: "Let your AI assistant ChatGPT define words and concepts for you."
    about:       "Generate concise definitions with OpenAI GPT-3 using the note's title and tags as the prompt. Append the AI-written definition to the end of the file and update the note's status (e.g., \"Definition by AI\")."

    stats: {
        downloads:  4437
        updated_at: 1693410111000
    }
}
```
