# Chinese Converter

Chinese Converter converts a selection or a whole document between Simplified and Traditional Chinese. The conversion runs from buttons in the left toolbar or from the command panel, and the button label switches between Traditional and Simplified to show the direction of the conversion.

```cue
plugin: {
    id:     "chinese-converter"
    name:   "Chinese Converter"
    author: "lanternyoru"
    repo:   "lanternyoru/obsidian-chinese-converter"

    html_url:    "https://community.obsidian.md/plugins/chinese-converter"
    github_url:  "https://github.com/lanternyoru/obsidian-chinese-converter"
    description: "Convert between Simplified and Traditional Chinese. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert selected content or the entire document to Simplified Chinese or Traditional Chinese. Use the buttons in the left toolbar or command panel to convert with a single click; the buttons automatically switch between \"Traditional/Simplified\" to indicate the conversion direction."

    stats: {
        downloads:  477
        updated_at: 1757607028000
    }
}
```
