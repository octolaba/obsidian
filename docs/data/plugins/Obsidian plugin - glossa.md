# Glossa

Adds an AI sidebar with multi-provider chat, at-mention context, semantic search over the vault and an agent that acts on files with per-action approval and audit logging. The agent works through sandboxed tools for reading, editing, searching and retrieval and applies multi-file patches. Local embeddings, an MCP bridge, vault-native skills, encrypted keys and Codex CLI integration are also part of the recorded feature set.
