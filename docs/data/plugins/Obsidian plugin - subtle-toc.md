# Subtle TOC

A floating table of contents sits at the edge of a note as a discreet dashed minimap. Hovering or clicking opens a popover outline that marks the active heading and scrolls to a section when clicked. Headings are tracked in both editing and reading modes, and options cover smooth scrolling, which side the control sits on and which heading levels appear, alongside document statistics.
