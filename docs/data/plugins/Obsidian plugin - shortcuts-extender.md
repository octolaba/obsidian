# Shortcuts extender

Shortcuts extender assigns shortcuts for entering special symbols without switching keyboard layout, which serves non-English layouts. It also changes heading levels with the Ctrl and digit combinations, toggles code blocks, and clears Markdown markup from a line or a selection.

```cue
plugin: {
    id:     "shortcuts-extender"
    name:   "Shortcuts extender"
    author: "ryjjin"
    repo:   "ryjjin/Obsidian-shortcuts-extender"

    html_url:    "https://community.obsidian.md/plugins/shortcuts-extender"
    github_url:  "https://github.com/ryjjin/Obsidian-shortcuts-extender"
    description: "Use shortcuts for input special symbols without language switching."
    about:       "Change heading levels with shortcuts (Ctrl+1–Ctrl+6) and toggle code blocks with Ctrl+`. Clear Markdown markup from a line or selection with Ctrl+0. Assign shortcuts to enter special characters for non‑English keyboard layouts."

    stats: {
        downloads:  28619
        updated_at: 1785589253000
    }
}
```
