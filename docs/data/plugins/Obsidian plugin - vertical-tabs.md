# Vertical Tabs

Vertical Tabs shows open notes as a vertical list so many tabs stay navigable, and lets them be grouped and organized. Per-tab zoom, a zen mode, tab history and an extended keyboard tab switcher are included. An IDE mode adds VSCode-like ephemeral tabs and automatic deduplication.
