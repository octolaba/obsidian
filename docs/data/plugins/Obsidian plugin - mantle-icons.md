# Mantle Icons

Attaches vector icons to folders and notes in the Obsidian sidebar and inserts icons inside note text through an inline shortcode. Lightweight SVG vectors are packaged in the plugin code itself, which the recorded text describes as avoiding loading lag. Its colour accents, borders and shadows are inherited from the Zenith theme.

```cue
plugin: {
    id:     "mantle-icons"
    name:   "Mantle Icons"
    author: "Ryan Bakker"
    repo:   "carnalmatrix/obsidian-mantle-icons"

    html_url:    "https://community.obsidian.md/plugins/mantle-icons"
    github_url:  "https://github.com/carnalmatrix/obsidian-mantle-icons"
    description: "Integrate visual iconography into your notes, folder directories, and sidebars. Pairs perfectly with the Zenith theme and features zero-bloat inline shortcodes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Mantle Icons is a companion design plugin that brings modern, vector iconography to your note layouts and directories. It allows you to select and attach custom icons to folders and notes in your Obsidian sidebar to navigate your vault visually. Additionally, you can insert icons directly within note body text using a simple inline shortcode syntax. The plugin is built with performance in mind, packaging lightweight SVG vectors directly in the code to ensure zero loading lag. Designed to inherit the colour accents, borders, and shadows of the Zenith theme to keep your vault aesthetics unified."

    stats: {
        downloads:  156

    }
}
```
