# Tekken Code Image

Renders Tekken fighting-game notation written in a tekken code block as inline SVG images. The numeric-keypad syntax covers directions 1-9 and neutral, the attack buttons LP, RP, LK, RK, WP and WK, slides written in square brackets, simultaneous presses joined with a plus sign, and quoted text annotations.
