# Mobile Explorer

Mobile Explorer replaces the default file explorer with an Apple Notes-style drill-down navigator that pushes into folders and returns by tap or swipe. Folders and notes appear in grouped cards with relative modification dates and item counts, alongside native context menus, swipe-back gestures and touch-optimized animations.
