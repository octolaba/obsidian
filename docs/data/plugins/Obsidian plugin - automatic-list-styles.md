# Automatic List Styles

Automatic List Styles shifts the numbering and bullet type of a list by indent level in read mode. The default sequence runs decimal, lower-alpha, lower-roman, upper-alpha, upper-roman, decimal-leading-zero, disc, circle and square, and edit mode is left unaffected.

```cue
plugin: {
    id:     "automatic-list-styles"
    name:   "Automatic List Styles"
    author: "wiseguru"
    repo:   "wiseguru/obsidian-automatic-list-styles"

    html_url:    "https://community.obsidian.md/plugins/automatic-list-styles"
    github_url:  "https://github.com/wiseguru/obsidian-automatic-list-styles"
    description: "Automatically formats the styles of ordered lists, incrementing the list style for each layer."
    about:       "Apply hierarchical list styles to lists in read mode, automatically shifting numbering and bullet types by indent level. Use a default sequence (decimal, lower-alpha, lower-roman, upper-alpha, upper-roman, decimal-leading-zero, disc, circle, square); does not affect edit mode."
```
