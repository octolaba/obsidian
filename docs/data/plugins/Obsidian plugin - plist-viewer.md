# PLIST Viewer

PLIST Viewer opens .plist and .mobileconfig files as typed trees, as source, and as security summaries. The tree shows key paths, type badges and masked secrets, the source view is line-numbered XML, and MDM, Wi-Fi, VPN and certificate payloads are flagged. The recorded inputs state that the viewer is read-only and never installs or modifies profiles.

```cue
plugin: {
    id:     "plist-viewer"
    name:   "PLIST Viewer"
    author: "Viggo Meesters"
    repo:   "viggomeesters/obsidian-plist-viewer"

    html_url:    "https://community.obsidian.md/plugins/plist-viewer"
    github_url:  "https://github.com/viggomeesters/obsidian-plist-viewer"
    description: "Open .plist and .mobileconfig files as read-only trees with search, source view, and profile security warnings. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Inspect .plist and .mobileconfig files as typed trees, source, and security summaries. Show a tree with key paths, type badges and masked secrets; display line-numbered XML; flag MDM, Wi‑Fi, VPN and certificate payloads; remain read-only and never install or modify profiles."
```
