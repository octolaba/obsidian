# About Blank

About Blank customizes the empty file shown in a new tab by adding actions that open files or run commands, and by hiding the default messages and buttons. Actions can be grouped, including nested groups, given icons, made to ask for confirmation before execution, and registered as commands.

```cue
plugin: {
    id:     "about-blank"
    name:   "About Blank"
    author: "ai-jani"
    repo:   "ai-jani/about-blank"

    html_url:    "https://community.obsidian.md/plugins/about-blank"
    github_url:  "https://github.com/ai-jani/about-blank"
    description: "Customize the empty file (New tab) itself a little bit by adding \"Commands\" or \"Open files\". And edit these: Grouping, Set icon, Ask before execution, Register as a new command."
    about:       "Customize the empty file view by adding actions to open files or run commands and hide default messages and buttons. Group actions (including nested groups), set icons, require confirmation before execution, and register actions as commands for quick access."

    stats: {
        downloads:  1063
        updated_at: 1752592539000
    }
}
```
