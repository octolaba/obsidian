# Syncist (Todoist Sync)

Syncs Obsidian tasks with Todoist in both directions, driven by tagging items or by creating tasks in notes. Tasks and subtasks are imported, projects and labels mapped, and live Todoist lists embedded through syncist code blocks. Conflicts are resolved by configurable rules, and the recorded inputs state compatibility with the Tasks plugin and that the plugin was created with AI help and validated by a human.
