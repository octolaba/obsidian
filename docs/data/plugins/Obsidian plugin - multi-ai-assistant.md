# Multi-AI Assistant

Indexes vault notes and uploaded files and queries Google Gemini, OpenAI or Groq models from inside Obsidian. A persistent sidebar chat holds the conversation, and preconfigured AI characters can be switched between, each with its own system prompt. The Gemini CLI can be enabled for local Gemini workflows.

    id:     "multi-ai-assistant"
    name:   "Multi-AI Assistant"
