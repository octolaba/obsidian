# Simple exporter for LLM

Simple exporter for LLM copies the contents of folders, tags or a multi-file selection to the clipboard, formatted as LLM context. Markdown and Canvas files export as JSON, XML or a custom template, and a visual file and tag tree with hybrid search, deduplication and selective removal builds the context while keeping duplicates and unwanted notes out.
