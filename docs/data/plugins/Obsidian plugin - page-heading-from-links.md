# Page Heading From Links

Populates blank notes with a Markdown heading derived from the file name. The conversion strips the .md suffix, replaces underscores with spaces and capitalizes the first word to form the H1 title.

```cue
plugin: {
    id:     "page-heading-from-links"
    name:   "Page Heading From Links"
    author: "beet"
    repo:   "beet/page-headings-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/page-heading-from-links"
    github_url:  "https://github.com/beet/page-headings-obsidian-plugin"
    description: "Populate page headings from the file name."
    about:       "Populate blank notes with a Markdown heading derived from the filename. Convert the filename by stripping the .md suffix, replacing underscores with spaces, and capitalizing the first word to create the H1 title."

    stats: {
        downloads:  6994
        updated_at: 1651467040000
    }
}
```
