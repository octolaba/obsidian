# Sector Tasks

Sector Tasks displays tasks in a dashboard that groups them into configurable time-based categories, called Time Sectors and defaulting to Carl Pullein's Time Sector System, with an Inbox for untagged tasks. It requires the Obsidian Tasks plugin, which it uses for editing, and single-file task storage. Daily, weekly and monthly processing and review features are included.

    id:     "sektor-tasks"

    about:       "Displays tasks in a pretty and easy-to-approach dashboard. \"Time Sectors\" can be used to categorise tasks into different groups (default: Carl Pullein's Time Sector System). Includes an Inbox for untagged tasks. Uses and requires the Obsidian Tasks plugin for editing. Includes processing and review features (daily, weekly and monthly) for convenient use."
