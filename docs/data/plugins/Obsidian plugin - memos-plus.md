# Memos Plus

Captures memos and archives them into project files, tag pages, recent notes or a specific Markdown heading. Timeline cards, calendar-style activity, search and tag filters review them, with views for today, the week, todo, pinned, starred, archived, random review and on this day. Memos are stored as local yearly Markdown files, and the recorded text states that there are no accounts, no telemetry and no network requests.
