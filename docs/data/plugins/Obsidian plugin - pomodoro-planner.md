# Pomodoro Planner

Generates a daily schedule based on the Pomodoro Technique from your input, formatted for compatibility with the Day Planner plugin. The generated plan is inserted at the cursor or copied to the clipboard.

```cue
plugin: {
    id:     "pomodoro-planner"
    name:   "Pomodoro Planner"
    author: "onesvat"
    repo:   "onesvat/obsidian-pomodoro-planner"

    html_url:    "https://community.obsidian.md/plugins/pomodoro-planner"
    github_url:  "https://github.com/onesvat/obsidian-pomodoro-planner"
    description: "Generates a pomodoro schedule plan."
    about:       "Generate a daily plan using the Pomodoro Technique based on your input and formatted for Obsidian Day Planner compatibility. Insert the generated plan at the cursor or copy it to the clipboard for quick use."

    stats: {
        downloads:  3144
        updated_at: 1709217994000
    }
}
```
