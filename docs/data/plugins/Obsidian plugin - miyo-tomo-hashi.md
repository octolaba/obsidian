# MiYo Tomo Hashi

MiYo Tomo Hashi attaches a live Tomo terminal to Obsidian for interacting with the Claude Code agent, working in the terminal directly and injecting file references from the file menu. Tomo instruction.json batches are executed to preview and apply idempotent vault edits, with run logs, background and auto-run modes, and re-runs that resume safely after an interruption. The recorded text states that Tomo itself is in heavy development and not yet feature complete.
