# tugtile

Lays out a Markdown note as a card table in which task-list items become draggable tiles and headings become lanes. The board stays a plain Markdown file with live updates, undo and redo, and board and table views, and it reads existing Kanban boards. Input and sorting are CJK-aware, editing works on mobile, and no network telemetry is recorded.
