# Vault Router

Moves new notes out of an inbox using local routing rules that match title, path, tags and frontmatter. Destinations can be previewed before a move, routing runs on demand or automatically, and an inbox can be swept to file notes in bulk. The recorded About states that unlimited rules, unlimited sweeps and hands-off auto-routing require an upgrade.
