# Share to Cubox

Share to Cubox sends notes from the editor to Cubox. A Cubox API key is configured in the settings, together with default tags and a target folder, and the plugin is available in English and Simplified Chinese.

```cue
plugin: {
    id:     "share-to-cubox"
    name:   "Share to Cubox"
    author: "redwinam"
    repo:   "redwinam/obsidian-cubox"

    html_url:    "https://community.obsidian.md/plugins/share-to-cubox"
    github_url:  "https://github.com/redwinam/obsidian-cubox"
    description: "Share notes to Cubox."
    about:       "Save and share Obsidian notes to Cubox directly from the editor. Configure your Cubox API key and set default tags and target folder; supports English and Simplified Chinese."

    stats: {
        downloads:  3839
        updated_at: 1686310157000
    }
}
```
