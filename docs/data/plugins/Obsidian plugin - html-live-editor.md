# HTML Live Editor

HTML Live Editor lets text inside HTML blocks be edited in Live Preview by clicking it, opening a popover or inline editor. Edits are saved with Enter or cancelled with Esc and mapped back to the Markdown source through DOM-to-source mapping, and rendering returns when focus leaves. Nested and repeated text is handled and the editor matches Obsidian's dark mode.

```cue
plugin: {
    id:     "html-live-editor"
    name:   "HTML Live Editor"
    author: "elijahchan2019"
    repo:   "elijahchan2019/plugin-html_live_editor"

    html_url:    "https://community.obsidian.md/plugins/html-live-editor"
    github_url:  "https://github.com/elijahchan2019/plugin-html_live_editor"
    description: "Click to edit text in HTML blocks directly within Live Preview mode. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Edit HTML blocks directly in Live Preview by clicking any text to open a popover or inline editor. Save edits with Enter or cancel with Esc while changes map back to the Markdown source via DOM-to-source mapping and auto-revert rendering when focus leaves. Support nested and repeated text and match Obsidian's dark mode."
}
```
