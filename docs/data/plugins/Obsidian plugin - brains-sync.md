# Brains Sync

Brains Sync connects the vault to Brains, a store of interlinked Markdown pages kept outside any single AI app so the same knowledge is available to different assistants. The plugin pulls that knowledge base in with its links intact, allows editing in Obsidian and pushes changes back, with background auto-sync, incremental pull that fetches only what changed, OAuth instead of copied keys, and desktop and mobile support. The recorded inputs also mention a community library of filing systems, note templates and agents.
