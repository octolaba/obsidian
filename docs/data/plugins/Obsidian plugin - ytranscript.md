# YTranscript

Inserts the transcript of a YouTube video into a note with clickable timestamps, taking the URL from selected text, the clipboard or manual input. The command is mobile-friendly, while a desktop side panel displays transcripts, allows dragging lines or timestamp links into a note, and copies an entire transcript at once.
