# HelpMate

HelpMate adds a sidebar view showing the help sites of the plugins and themes installed in the vault. The pages load in an embedded web browser, so a live internet connection is needed to retrieve them.

```cue
plugin: {
    id:     "helpmate"
    name:   "HelpMate"
    author: "tfthacker"
    repo:   "tfthacker/obsidian42-HelpMate"

    html_url:    "https://community.obsidian.md/plugins/helpmate"
    github_url:  "https://github.com/tfthacker/obsidian42-HelpMate"
    description: "Add a sidebar view to see help sites for the plugins and themes you have installed."
    about:       "View help pages for installed plugins and themes in a dedicated side pane within Obsidian. Load help sites with an embedded web browser and keep a live internet connection to retrieve content."

    stats: {
        downloads:  18094
        updated_at: 1776534048000
    }
}
```
