# Quick Autocorrect

Scans the current note for spelling and grammar issues and lists every suggestion in a Google Docs-style menu for one-click correction. Note text is sent to a LanguageTool endpoint of your choosing — public, local or custom — so where the text is processed stays under your control.

```cue
plugin: {
    id:     "quick-autocorrect"
    name:   "Quick Autocorrect"
    author: "Alex Peczon"
    repo:   "bakedsoups/quick-autocorrect"

    html_url:    "https://community.obsidian.md/plugins/quick-autocorrect"
    github_url:  "https://github.com/bakedsoups/quick-autocorrect"
    description: "Review spelling and grammar issues in the current note from a Google Docs-style suggestion menu. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Scan the current note for spelling and grammar and display all auto correct suggestions in a Google Docs-style list for quick, one-click corrections. Send note text to a LanguageTool endpoint you choose (public, local, or custom) to get suggestions while keeping control over where your data is processed."

    stats: {

}
```
