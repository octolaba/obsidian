# TODOseq

TODOseq is a keyword-based task tracker in which Logseq-style keywords such as TODO, DOING, DONE, LATER, NOW and WAIT are written directly in a note instead of checkboxes and collected into a searchable Task List. Tasks can be filtered and sorted by state, priority, date or tag, dynamic task lists rendered inside notes, and TODOs extracted from code comments, with subtasks and repeating schedules tracked.
