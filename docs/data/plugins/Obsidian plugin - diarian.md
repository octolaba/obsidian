# Diarian

Diarian manages daily notes through an interactive calendar that marks which days have notes, shows attached images on day tiles, and creates or opens a note for any date. An on-this-day pane and notifications resurface past entries, and entries can be rated from the status bar. It also inserts timestamps, imports Diarium journals, and supports templates, nested folders and multiple notes per day.
