# PDF Highlight Notes

Imports PDFs into the vault and opens them in Obsidian's built-in viewer. Selected text can become a permanent highlight visible in other PDF readers, or be saved as a Markdown quote in a companion highlights note with a deep link back to the exact page and selection.

```cue
plugin: {
    id:     "pdf-highlight-notes"
    name:   "PDF Highlight Notes"
    author: "kebl3541"
    repo:   "kebl3541/Obsidian-PDF-Highlight-Notes"

    html_url:    "https://community.obsidian.md/plugins/pdf-highlight-notes"
    github_url:  "https://github.com/kebl3541/Obsidian-PDF-Highlight-Notes"
    description: "Import PDFs into your vault and save text selections as highlight notes with deep links that reopen the PDF at the highlighted passage. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Import PDFs into your vault and open them in Obsidian's built-in viewer. Highlight text to add permanent highlights visible in other PDF readers, or save selections as Markdown quotes in a companion highlights note with deep links to the exact page and selection."

    stats: {
        downloads:  184
        updated_at: 1783444971000
    }
}
```
