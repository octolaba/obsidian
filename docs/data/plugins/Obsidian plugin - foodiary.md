# Foodiary

Logs foods in a foodiary code block inside daily notes, parsing quantities, accepting comments, and aggregating calories, protein, fat and carbs per item and in total. A products catalog holds per-100g nutrition entries that items reference by name or alias, and the totals are compared against a daily calorie goal.

    id:     "foodiary"
    name:   "Foodiary"
    author: "vkostyanetsky"
