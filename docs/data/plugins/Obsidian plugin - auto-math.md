# Auto Math

Auto Math expands LaTeX snippets as you type, inserting ready-to-edit templates for commands such as frac, sqrt and sum and for multiline environments. Expansion rules live in external files with live reload and a custom rules editor, a default math pack is included, and context-aware integral limits can be enabled for inline or display math.
