# Format Automatically with Prettier

Formats Markdown with Prettier using Obsidian's own editor tab and spacing settings rather than a separate configuration file. Formatting can be enabled on save or invoked through the Format current file command.

```cue
plugin: {
    id:     "prettier-format"
    name:   "Format Automatically with Prettier"
    author: "dylanarmstrong"
    repo:   "dylanarmstrong/obsidian-prettier-plugin"

    html_url:    "https://community.obsidian.md/plugins/prettier-format"
    github_url:  "https://github.com/dylanarmstrong/obsidian-prettier-plugin"
    description: "Format files with Prettier using built-in settings for configuration."
    about:       "Format Markdown with Prettier using Obsidian's editor tab and spacing settings. Enable format-on-save or run the Format current file command to tidy up files with no extra configuration."

    stats: {
        downloads:  878
        updated_at: 1748285964000
    }
}
```
