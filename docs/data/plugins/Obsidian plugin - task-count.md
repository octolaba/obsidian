# Task Count

Task Count counts the tasks in a note and writes the totals into specified note properties, so the counts travel with the file. Both ordinary Markdown checkboxes and tasks from TaskNotes are counted, and the counts refresh automatically or on demand.

```cue
plugin: {
    id:     "task-count"
    name:   "Task Count"
    author: "Reaty"
    repo:   "anareaty/task-count"

    html_url:    "https://community.obsidian.md/plugins/task-count"
    github_url:  "https://github.com/anareaty/task-count"
    description: "Count tasks in notes and save result to properties. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Count tasks in a note and save totals to specified note properties so counts stay with your file. Include regular Markdown checkboxes and tasks from TaskNotes, and refresh counts automatically or on demand."
```
