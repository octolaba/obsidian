# Grappling Hook

Speeds up switching to bookmarked files for people for whom the Quick Switcher still takes too long, with commands to cycle bookmarked files by last modification, toggle the alternate note, and cycle across all tabs and splits. Files in the current folder can be cycled alphabetically, and the first external URL found in a note can be opened. Selected text can be copied into the last-modified bookmark while using the bookmark cycler.
