# Concrete

Concrete styles text and applies inline color highlights through readable wrappers and a collapsible vars block, without settings menus. CSS variables are defined there and colors edited from clickable swatches, wrappers nest for combined effects, and dash-based indented outlines are built with hidden dashes and bullets and a live preview.
