# Furigana

Wraps selected text in ruby markup so that furigana readings are displayed above it. Editable reading slots are inserted for quick manual entry of pronunciations.

```cue
plugin: {
    id:     "obsidian-furigana"
    name:   "Furigana"
    author: "uonr"
    repo:   "uonr/obsidian-furigana"

    html_url:    "https://community.obsidian.md/plugins/obsidian-furigana"
    github_url:  "https://github.com/uonr/obsidian-furigana"
    description: "Display furigana using <ruby> syntax."
    about:       "Wrap selected text in <ruby>…<rt>…</rt></ruby> tags to add furigana (ruby) readings. Insert editable <rt> slots for quick manual entry of pronunciations."

    stats: {
        downloads:  7238

    }
}
```
