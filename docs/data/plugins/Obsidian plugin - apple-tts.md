# Apple TTS

Reads notes aloud through the built-in macOS say text-to-speech, without internet access, keys or subscriptions. A whole note, a selection, or the text from the cursor onwards can be spoken, with a choice among the installed voices, adjustable speed and an immediate stop. Markdown can be stripped and content types filtered before playback.

```cue
plugin: {
    id:     "apple-tts"
    name:   "Apple TTS"
    author: "ajsscott"
    repo:   "ajsscott/obsidian-apple-tts"

    html_url:    "https://community.obsidian.md/plugins/apple-tts"
    github_url:  "https://github.com/ajsscott/obsidian-apple-tts"
    description: "Read notes aloud using macOS native text-to-speech. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Read Obsidian notes aloud using macOS' built‑in say text-to-speech with no internet, keys, or subscriptions. Speak entire notes, selected text, or from the cursor; pick from 180+ installed voices, adjust speed, stop instantly, and strip markdown or filter content types for clean playback."
```
