# Chess Study

Chess Study inserts a PGN viewer and editor into a note for reading and editing chess games in place. Games are imported from PGN or started fresh, comments and arrows are attached per move, and those annotations are persisted as JSON files inside the vault.

```cue
plugin: {
    id:     "chess-study"
    name:   "Chess Study"
    author: "chrislicodes"
    repo:   "chrislicodes/obsidian-chess-study"

    html_url:    "https://community.obsidian.md/plugins/chess-study"
    github_url:  "https://github.com/chrislicodes/obsidian-chess-study"
    description: "A chess study helper and PGN viewer/editor."
    about:       "Insert a PGN viewer/editor into notes to view and edit chess games inline. Import PGNs or start a new game, add per-move comments and arrows, and persist annotations as JSON files in your vault for organized chess note-taking."

    stats: {
        downloads:  7406
        updated_at: 1707661863000
    }
}
```
