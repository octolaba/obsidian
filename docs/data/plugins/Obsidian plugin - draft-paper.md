# Draft Paper

Adds a full-screen transparent canvas over a Markdown file in reading mode for freehand annotation, with smooth strokes, arrows, rectangles, text and a local partial eraser. Marks are stored as per-file JSON bound to document coordinates, so annotations persist and are unaffected by layout changes.
