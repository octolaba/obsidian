# DMN

Views DMN decision models inside notes through a viewer built on dmn-js. A dmn code block embeds a DMN file to open its DRD or a specific decision table, with zoom and canvas size controlled and a link shown to the source file.

```cue
plugin: {
    id:     "dmn-plugin"
    name:   "DMN"
    author: "joleaf"
    repo:   "joleaf/obsidian-dmn-plugin"

    html_url:    "https://community.obsidian.md/plugins/dmn-plugin"
    github_url:  "https://github.com/joleaf/obsidian-dmn-plugin"
    description: "Enable viewing DMNs using dmn-js."
    about:       "View DMN decision models interactively inside notes using a dmn-js–based viewer. Embed DMN files with a dmn code block to open DRDs or specific decision tables, control zoom and canvas size, and show a link to the source file."

    stats: {
        downloads:  3940
        updated_at: 1714383724000
    }
}
```
