# Checklist Sort

Checklist Sort moves unchecked items to the top of a checklist and checked items to the bottom, run through a custom keybind. Nested items keep their original order and stay attached to their parent.

```cue
plugin: {
    id:     "checklist-sort"
    name:   "Checklist Sort"
    author: "Adam Tweedie"
    repo:   "profesr-chaos/obsidian-checklist-sort"

    html_url:    "https://community.obsidian.md/plugins/checklist-sort"
    github_url:  "https://github.com/profesr-chaos/obsidian-checklist-sort"
    description: "Sort your Todo (checklist) items by undone via custom keybind! - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sort checklists by moving unchecked items to the top and checked items to the bottom. Preserve nested item order so subtasks stay attached to their parent and keep their original sequence."

    stats: {
        downloads:  200
        updated_at: 1780566793000
    }
}
```
