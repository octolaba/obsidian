# Admonition

Admonition adds block-styled content such as callouts, tips, warnings and notes to Markdown notes. Built-in types and icons can be used directly or custom styles defined with CSS, and blockquotes and nested code blocks are supported inside a block. Custom admonition presets are imported and exported as JSON.

```cue
plugin: {
    id:     "obsidian-admonition"
    name:   "Admonition"
    author: "ebullient"
    repo:   "ebullient/obsidian-admonition"

    html_url:    "https://community.obsidian.md/plugins/obsidian-admonition"
    github_url:  "https://github.com/ebullient/obsidian-admonition"
    description: "Admonition block-styled content."
    about:       "Create attention-grabbing callouts, tips, warnings, notes and other informative blocks directly in your Markdown notes. Pick from built-in types and icons or define custom styles with CSS, nest blockquotes and code blocks, and import/export custom admonition presets via JSON."

}
```
