# Folder Base View

Opens a chosen base file as a folder-scoped table of contents when its folder is clicked in the file explorer, with no companion note required. A default base, or an exact-match base per folder, decides which layout renders the folder contents. Tree expand and collapse behaviour is preserved and base files are excluded from the listing.

    id:     "folder-base-view"
    name:   "Folder Base View"
    author: "KulySocc"
    repo:   "kulysocc/obsidian-folder-base-view"

    html_url:    "https://community.obsidian.md/plugins/folder-base-view"
    github_url:  "https://github.com/kulysocc/obsidian-folder-base-view"
    description: "Open a folder in the file explorer to view its contents as a Bases-powered table of contents, with no companion note required. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open a chosen .base as a folder-scoped table of contents by clicking its folder in the file explorer, with no companion note required. Map a default base or exact-match per-folder bases to render folder contents with your base layout while preserving tree expand/collapse and excluding .base files."
