# Banyan

Banyan presents a homepage of notes as cards showing title, content preview and tags. Notes are filtered by several tags at once, by time range or by content, filter sets can be saved, a random review resurfaces old notes, and a heat map shows writing activity.

```cue
plugin: {
    id:     "banyan"
    name:   "Banyan"
    author: "ratiger"
    repo:   "ratiger/obsidian-banyan"

    html_url:    "https://community.obsidian.md/plugins/banyan"
    github_url:  "https://github.com/ratiger/obsidian-banyan"
    description: "A homepage to browse, organize, and access notes in card form easily with multi-tag filtering."
    about:       "Organize and browse notes with a card-based homepage that displays clear titles, content previews, and tags. Filter by multiple tags, time ranges, or content; save filter sets, run random reviews to rediscover old notes, and view a heat map of your writing activity."

    stats: {
        downloads:  8529
        updated_at: 1784728443000
    }
}
```
