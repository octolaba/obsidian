# Mindmap Mode

Switches a note into an editable radial mind map in the same tab, built from its headings and indented lists. Nodes are edited directly on the canvas and every change is written back to the original note as a minimal line edit, so no new files are created. Frontmatter, code fences, tables and exact line formatting are left as they were.
