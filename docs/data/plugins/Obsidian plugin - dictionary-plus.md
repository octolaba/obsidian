# Dictionary Plus

Adds a dictionary view to Obsidian, with right-click lookup on desktop and selection recovery on mobile. Lookups can be saved to a history note shaped for flashcards and compatible with the Spaced Repetition plugin. Selections made in PDF++ and in reading view are supported as well.

```cue
plugin: {
    id:     "dictionary-plus"
    name:   "Dictionary Plus"
    author: "michellegdyason"
    repo:   "michellegdyason/obsidian-dictionary-plus"

    html_url:    "https://community.obsidian.md/plugins/dictionary-plus"
    github_url:  "https://github.com/michellegdyason/obsidian-dictionary-plus"
    description: "Dictionary lookup with mobile selection, right-click support, and flashcard-ready lookup history. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add an integrated dictionary view to Obsidian and enable right-click lookup on desktop while recovering selections on mobile. Save lookups to a flashcard-ready history note compatible with Obsidian Spaced Repetition and support PDF++ and reading-view selections."

    stats: {
        downloads:  356
        updated_at: 1783540295000
    }
}
```
