# Vault LLM Assistant

Answers questions about the vault with AI and returns citations linking back to the source notes. A response can become a new note with a generated title or be copied as text or Markdown, and vault context can be toggled off. The providers named are OpenAI, Google Gemini, Anthropic Claude and local models through LM Studio or Ollama.
