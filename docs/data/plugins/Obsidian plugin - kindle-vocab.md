# Kindle Vocab

Imports Kindle Vocabulary Builder lookups from vocab.db and converts them into structured, interactive Markdown notes for review. CSV dictionaries can be attached, words marked as learned with checkboxes, and learning statistics such as percent learned tracked. Unlearned items can be sorted or prioritized for focused study.

```cue
plugin: {
    id:     "kindle-vocab"
    name:   "Kindle Vocab"
    author: "bao-tg"
    repo:   "bao-tg/kindle-vocab"

    html_url:    "https://community.obsidian.md/plugins/kindle-vocab"
    github_url:  "https://github.com/bao-tg/kindle-vocab"
    description: "Create the Markdown file from your Kindle Vocab Builder in your vault."
    about:       "Import Kindle vocabulary lookups (vocab.db) and convert them into structured, interactive Markdown notes for review in Obsidian. Attach CSV dictionaries, mark words learned with checkboxes, track learning statistics like percent learned, and sort or prioritize unlearned items for focused study."

    stats: {
        downloads:  353

    }
}
```
