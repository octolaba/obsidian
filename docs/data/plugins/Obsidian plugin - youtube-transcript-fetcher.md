# YouTube transcript fetcher

Fetches YouTube transcripts into notes with clickable timestamps and the extracted video metadata alongside them. Transcripts are cleaned and summarized through OpenAI, Gemini, Claude or a custom LLM, and the results are saved as Markdown, PDF or SRT files.

```cue
plugin: {
    id:     "youtube-transcript-fetcher"
    name:   "YouTube transcript fetcher"
    author: "Leif Jantzen"
    repo:   "ljantzen/obsidian-youtube-transcript"

    html_url:    "https://community.obsidian.md/plugins/youtube-transcript-fetcher"
    github_url:  "https://github.com/ljantzen/obsidian-youtube-transcript"
    description: "Fetch, clean and embed YouTube video transcripts in your notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Fetch and embed YouTube video transcripts into notes with clickable timestamps and extracted video metadata. Generate AI-cleaned transcripts and concise summaries via OpenAI, Gemini, Claude or custom LLMs, and save outputs as Markdown, PDF, or SRT files."

    stats: {
        downloads:  5173

    }
}
```
