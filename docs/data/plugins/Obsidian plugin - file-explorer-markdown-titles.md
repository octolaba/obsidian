# File Explorer Markdown Titles

File Explorer Markdown Titles shows the first Markdown header of a note beside its filename in the File Explorer sidebar. The same Markdown title also replaces the node titles in the graph view.

```cue
plugin: {
    id:     "file-explorer-markdown-titles"
    name:   "File Explorer Markdown Titles"
    author: "dyldog"
    repo:   "dyldog/file-explorer-markdown-titles"

    html_url:    "https://community.obsidian.md/plugins/file-explorer-markdown-titles"
    github_url:  "https://github.com/dyldog/file-explorer-markdown-titles"
    description: "Show the first Markdown header of a note in the file explorer."
    about:       "Display the first Markdown header alongside filenames in the File Explorer sidebar. Replace graph view node titles with each note's Markdown title for clearer navigation."

    stats: {
        downloads:  6817
        updated_at: 1631447722000
    }
}
```
