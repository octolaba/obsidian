# Google Calendar and Tasks Sync

Pulls Google Calendar events into an events folder and Google Tasks into a tasks folder, and sends updates made in Obsidian back to Google. Events and tasks past their event date or due date are archived automatically, and tasks can be linked to events. Setup instructions are kept in the project's GitHub documentation rather than in the plugin.

```cue
plugin: {
    id:     "google-sync"
    name:   "Google Calendar and Tasks Sync"
    author: "Connor"
    repo:   "cordedmink2/obsidian-google-sync"

    html_url:    "https://community.obsidian.md/plugins/google-sync"
    github_url:  "https://github.com/cordedmink2/obsidian-google-sync"
    description: "Pulls Google Calendar and Google Tasks into your vault as notes and allows you to update them. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Pulls Google Calendar events into a folder, \"events\", and Google Tasks tasks into a folder, 'tasks'. Updates in obsidian get synced into google. Events/tasks past event date/due dates will get automatically archived. Tasks can be linked to events. Please read the github docs for setup Instructions."

    stats: {
        downloads:  868
        updated_at: 1781588627000
    }
}
```
