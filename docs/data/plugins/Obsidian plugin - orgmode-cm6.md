# Orgmode (cm6)

Orgmode (cm6) edits and previews Org-mode files in Obsidian with a syntax-aware CodeMirror 6 editor and live preview. It supports folding, customizable todo keywords, wiki and ID links, inline images, property drawers and source-block highlighting, with optional Vim support.
