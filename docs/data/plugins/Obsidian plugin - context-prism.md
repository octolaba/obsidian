# Context Prism

Context Prism builds token-aware, multilingual context packs from the vault so an AI assistant receives focused, compact evidence. It ranks notes related to the active file, explains why each was chosen, estimates the context avoided, and copies a compact Markdown pack for pasting into any assistant. Indexing and processing stay local, with no external calls.
