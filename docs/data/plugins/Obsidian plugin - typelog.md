# TypeLog

Tracks typing activity per file, recording net word count alongside cumulative input so that deletions and rewrites still register as editing effort. Typing speed is measured over a 60-second window with a session peak, and the timer pauses automatically when input stops. Progress is shown as daily rings, monthly heatmaps and minute-level growth curves, and the local history can be exported as JSON or CSV, or cleared.

    id:     "typelog"
    name:   "TypeLog"
    author: "8&6"
    repo:   "czk200518-hash/Typelog"

    github_url:  "https://github.com/czk200518-hash/Typelog"
    description: "Track typing activity in Obsidian: net vs total input, active editing time, typing speed, calendar heatmap, and daily goals. - This plugin has not been manually reviewed by Obsidian staff."

Monitor 60-second typing speed and session peak with auto-pause on idle; view daily progress rings, monthly heatmaps and minute-level growth curves, and export or clear local JSON/CSV history."
