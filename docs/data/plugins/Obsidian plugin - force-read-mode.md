# Force Read Mode

Forces Markdown files in specified paths to open in read or preview mode so they are not edited by accident. Files are matched with several micromatch glob patterns, and the behaviour can be toggled on or off from the command palette.

```cue
plugin: {
    id:     "force-read-mode"
    name:   "Force Read Mode"
    author: "al3xw"
    repo:   "al3xw/force-read-mode"

    html_url:    "https://community.obsidian.md/plugins/force-read-mode"
    github_url:  "https://github.com/al3xw/force-read-mode"
    description: "Forces Markdown files in specified folders to open in read-only mode."
    about:       "Force Markdown files in specified paths to open in read (preview) mode to prevent accidental edits. Match files with multiple micromatch glob patterns and toggle the behavior on or off from the Command Palette."

    stats: {
        downloads:  5312
        updated_at: 1784987035000
    }
}
```
