# Consistent Attachments and Links

Consistent Attachments and Links reorganizes the vault so that attachments sit beside the notes that use them, and rewrites links into strict Markdown relative paths that other editors and GitHub understand. Attachments are moved or removed together with the notes they belong to, keeping the file layout consistent and portable.
