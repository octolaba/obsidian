# Type Chinese Like English

Converts pinyin typed in English mode into Chinese characters in place. The same conversion turns a natural-language description of mathematics into LaTeX through an AI language model, replacing the current line with the generated result.

    id:     "type-chinese-like-english"

    author: "hwenyi"
