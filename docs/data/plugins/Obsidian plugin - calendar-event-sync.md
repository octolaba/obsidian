# Calendar Event Sync

Calendar Event Sync replaces the current note's title and initial content with data taken from a calendar event. It can sync with the closest current, upcoming or recent event, or let any past or future event be picked. Events are fetched from a single ICS calendar, optionally excluding declined or ignored entries.

```cue
plugin: {
    id:     "calendar-event-sync"
    name:   "Calendar Event Sync"
    author: "stephendolan"
    repo:   "stephendolan/obsidian-calendar-event-sync"

    html_url:    "https://community.obsidian.md/plugins/calendar-event-sync"
    github_url:  "https://github.com/stephendolan/obsidian-calendar-event-sync"
```
