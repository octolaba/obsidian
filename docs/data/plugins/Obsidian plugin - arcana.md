# Arcana

Provides AI agents modelled on historical figures that chat in context, generate text, transcribe speech and synthesize text-to-speech. Custom agents can be defined, and the plugin also generates flashcards, moves files, auto-tags and renames notes and applies metadata. OpenAI, Anthropic, Google and OpenRouter are supported as providers.
