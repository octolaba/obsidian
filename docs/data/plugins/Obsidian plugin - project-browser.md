# Project Browser

Replaces the new tab window with a card interface over the files and folders of the vault. Multiple pages can be added to any note, base, or canvas for multi-page projects, folders hidden to reduce clutter, and priorities and states set to stay focused.

```cue
plugin: {
    id:     "project-browser"
    name:   "Project Browser"
    author: "Dale de Silva"
    repo:   "daledesilva/obsidian_project-browser"

    html_url:    "https://community.obsidian.md/plugins/project-browser"
    github_url:  "https://github.com/daledesilva/obsidian_project-browser"
    description: "Replaces your new tab window with cards of the files and folders in your vault. Also adds support for multi-page projects."
    about:       "Browse your vault through a user-friendly card interface. With multi-page support, add multiple pages to any note, base, or canvas. Hide folders to declutter, and set priorities and states to remain focused."
```
