# Shrink pinned tabs

Shrink pinned tabs makes pinned tabs smaller so the tab bar takes less screen space. Tab titles can be toggled, switching between compact icon-only pins and labeled tabs.

```cue
plugin: {
    id:     "shrink-pinned-tabs"
    name:   "Shrink pinned tabs"
    author: "nicosomb"
    repo:   "nicosomb/obsidian-shrink-pinned-tabs"

    html_url:    "https://community.obsidian.md/plugins/shrink-pinned-tabs"
    github_url:  "https://github.com/nicosomb/obsidian-shrink-pinned-tabs"
    description: "Shrinks pinned tabs to save screen space."
    about:       "Shrink pinned tabs to save space and declutter the Obsidian tab bar. Toggle tab titles to switch between compact icon-only pins and labeled tabs."

    stats: {
        downloads:  4097
```
