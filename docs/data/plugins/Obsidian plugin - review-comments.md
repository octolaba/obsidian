# Review Comments

Review Comments inserts inline CriticMarkup annotations when text is selected and a floating button is clicked, in the style of Notion comments. Because the annotations live in the Markdown itself, the recorded text presents the format as readable by LLMs for assisted editing. A side panel browses the comments, jumps to them and resolves them.

```cue
plugin: {
    id:     "review-comments"
    name:   "Review Comments"
    author: "Shota Shirai"
    repo:   "shotashirai1719/obsidian-review-comments"

    html_url:    "https://community.obsidian.md/plugins/review-comments"
    github_url:  "https://github.com/shotashirai1719/obsidian-review-comments"
    description: "Notion-style review comments stored as CriticMarkup. AI-friendly format for LLM-assisted editing. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add Notion-style review comments by selecting text and clicking a floating button to insert inline CriticMarkup annotations. Store comments directly in Markdown so LLMs can read and apply edits, and use the side panel to browse, jump to, and resolve comments."

    stats: {
        downloads:  385
        updated_at: 1779089774000
    }
}
```
