# Template by Note Name

Template by Note Name applies templates to new or renamed notes based on filename patterns, matching by prefix, by suffix or by containment. Templates are selected from the templates folder including its subfolders, template content can be prepended when a note is renamed, and matching is either case-sensitive or case-insensitive.

    id:     "template-by-note-name"
    name:   "Template by Note Name"
