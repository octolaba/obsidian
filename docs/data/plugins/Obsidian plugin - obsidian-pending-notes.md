# Pending notes

This plugin searches for links that have no note behind them, collecting every link pointing at a non-existent note into a single panel. The missing notes can then be created directly from the sidebar or from the command palette.

```cue
plugin: {
    id:     "obsidian-pending-notes"
    name:   "Pending notes"
    author: "ulisesantana"
    repo:   "ulisesantana/obsidian-pending-notes"

    html_url:    "https://community.obsidian.md/plugins/obsidian-pending-notes"
    github_url:  "https://github.com/ulisesantana/obsidian-pending-notes"
    description: "Search links without notes in your vault."
```
