# Annotator

Annotator opens PDF and EPUB files inside Obsidian for reading and annotation. Selecting text creates highlights and notes, and annotations are saved to a local Markdown file instead of the web while staying linked to vault or external documents.

```cue
plugin: {
    id:     "obsidian-annotator"
    name:   "Annotator"
    author: "elias-sundqvist"
    repo:   "elias-sundqvist/obsidian-annotator"

    html_url:    "https://community.obsidian.md/plugins/obsidian-annotator"
    github_url:  "https://github.com/elias-sundqvist/obsidian-annotator"
```
