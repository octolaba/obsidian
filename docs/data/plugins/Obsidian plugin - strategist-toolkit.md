# Strategist Toolkit

A Business Model Canvas is generated as an Obsidian Canvas file from one click or from the command palette. Nine emoji-labeled cards in distinct colors are laid out in the classic grid, each carrying guiding questions and a placeholder for text. The file is named from the project and the date and created in the current folder.

```cue
plugin: {
    id:     "strategist-toolkit"
    name:   "Strategist Toolkit"
    author: "psovit"
    repo:   "psovit/obs-plg-bmc"

    html_url:    "https://community.obsidian.md/plugins/strategist-toolkit"
    github_url:  "https://github.com/psovit/obs-plg-bmc"
    description: "Generate a Business Model Canvas layout inside a new Canvas file. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Generate a color-coded Business Model Canvas as an Obsidian Canvas file with one click or via the command palette. Create nine emoji-labeled, color-distinct cards laid out in the classic BMC grid with guiding questions and \"[Type here…]\" placeholders, and name the file by project and date in the current folder."
```
