# MM Clean Headers

Formats Markdown headers consistently across the current note or the whole vault. An assigned hotkey cycles between a Sentence style, with only the first word capitalized, and an Associated Press style, and header levels can be changed individually or as a group. Settings adjust the behavior and can enable a third formatting option, which comes with a warning.

```cue
plugin: {
    id:     "mm-clean-headers"
    name:   "MM Clean Headers"
    author: "Math Math"
    repo:   "lemathmath/Obsidian_MM-Clean-Headers"

    html_url:    "https://community.obsidian.md/plugins/mm-clean-headers"
    github_url:  "https://github.com/lemathmath/Obsidian_MM-Clean-Headers"
    description: "Streamlines editing various levels of headers, as well as automating consistent formatting. #cleaner #headings #capitalize #lowercase #uppercase - This plugin has not been manually reviewed by Obsidian staff."
    about:       "• Headers formatting: Allows to make headers formatted consistently in the current note or throughout the whole vault. With the assigned hotkey, toggle once for the \"Sentence\" style (Upper, then all lower) and again for the \"Associated Press\" style (Upper, Then Upper and Upper Again). • Header levels can be modified individually or in group • Enhancement can be customized via a few handy settings, as well as adding a third formatting option (comes with a warning)"
```
