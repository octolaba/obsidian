# Circuit Sketcher

Circuit Sketcher draws and edits circuit diagrams on a canvas inside Obsidian, building on circuit-sketcher-core and saving or loading designs as .circuit-sketcher files. The component library is customizable and nodes can carry images and ports. An embedded sketch renders in a note as a responsive image.
