# Open Notes Graph Highlight

Open Notes Graph Highlight marks the notes that are currently open in the graph view with a custom colour and a fixed enlarged node size. Other nodes are dimmed, and colour, size and opacity are adjusted from a compact control panel inside the graph itself.

    id:     "open-notes-graph-highlight"

    html_url:    "https://community.obsidian.md/plugins/open-notes-graph-highlight"
