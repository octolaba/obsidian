# Symbols Prettifier

Replaces common ASCII symbol sequences with Unicode glyphs as they are typed, so arrows and operators read as symbols in the editor. The recorded About text lists the substitutions -> to →, <- to ←, <-> to ↔, <=> to ⇔, => to ⇒, <= to ⇐, >= to ≥, +- to ±, and -+ to ∓.
