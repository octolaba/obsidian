# Freeform Link Cards

Turns a URL pasted onto a Canvas into an Apple Freeform-style preview card that keeps the original link and downloads the best large image into the vault. The card shows the page title and domain, derives its caption color from the image, keeps a portable JSON preview inside a text node, and opens the source page when clicked.
