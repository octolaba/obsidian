# Drag Bi-Link

Creates native block links between selected text in two split Markdown editors by dragging, replacing each selection in place with a wikilink whose alias matches the original text. Because the links are native, block IDs, backlinks, graph view and normal navigation keep working, and links can be bidirectional or forward-only. The drag uses Option or Alt together with a configurable selection key.
