# StreamRadio

Web radio stations are searched by name, country, language or tag and previewed before being saved as favorites. Favorites are managed and reordered and played from a right sidebar player showing station logos, volume, skip and a sleep timer. A built-in Pomodoro timer runs alongside playback.
