# Atlassian Jira Auto-Linker

Turns Atlassian Jira issue identifiers such as APP-1426 into clickable links while a note is being viewed. Registered project keys and the Jira site URL decide which references are linked and where they point.

```cue
plugin: {
    id:     "atlassian-jira-auto-linker"
    name:   "Atlassian Jira Auto-Linker"
    author: "kovah"
    repo:   "kovah/obsidian-jira-auto-linker"

    html_url:    "https://community.obsidian.md/plugins/atlassian-jira-auto-linker"
    github_url:  "https://github.com/kovah/obsidian-jira-auto-linker"
    description: "Automatically create links to Jira from issue IDs like APP-1426. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert Atlassian Jira issue IDs into clickable links when viewing notes. Register project keys and your Jira site URL to automatically link issue references to their Jira pages."

    stats: {
        downloads:  187
        updated_at: 1778709047000
    }
}
```
