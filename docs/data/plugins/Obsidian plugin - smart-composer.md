# Smart Composer

Smart Composer is an AI chat that uses notes from the vault as context to generate, edit and expand content in place, with one-click edits. It connects to models from OpenAI, Google Gemini and Anthropic Claude among others, and links external tools and data through the Model Context Protocol.
