# Contextual Guides

Contextual Guides shows a guide note in the right sidebar, chosen by the tags, location or properties of the active note. Several rules can be defined, and a guide renders only when all of its required rules match. When nothing matches or the guide note is missing, the panel shows an empty state or a configuration warning.

```cue
plugin: {
    id:     "contextual-guides"
    name:   "Contextual Guides"
    author: "Charles Chalas"
    repo:   "chalas-ch/obsidian-contextual-guides"

    html_url:    "https://community.obsidian.md/plugins/contextual-guides"
    github_url:  "https://github.com/chalas-ch/obsidian-contextual-guides"
    description: "Show tag-based contextual note in a sidebar for the active note - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display a contextual guide in a right sidebar by matching tags, location, or properties in the active note. Define multiple rules that render a chosen guide note when all required rules are met, and show an empty state or configuration warning if no match or guide is found."

    stats: {

}
```
