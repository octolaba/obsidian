# Date Range Expander

Inserts a sequence of day references from a start date plus either an end date or a duration. The output format is configurable, dates can be written as wiki links and wrapped in a callout, and a file can be generated for each date in the range.

```cue
plugin: {
    id:     "date-range-expander"
    name:   "Date Range Expander"
    author: "mildeveloper"
    repo:   "mildeveloper/obsidian-date-range-expander"

    html_url:    "https://community.obsidian.md/plugins/date-range-expander"
    github_url:  "https://github.com/mildeveloper/obsidian-date-range-expander"
    description: "Quickly add a range of day references given a date duration."
    about:       "Insert a sequence of dates by providing a start date and either an end date or a duration. Format outputs to your preferred date style, create wiki-linked dates with optional callout wrapping, and generate files for each date."

    stats: {
        downloads:  269
        updated_at: 1744149410000
    }
}
```
