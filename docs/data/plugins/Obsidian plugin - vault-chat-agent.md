# Vault Chat Agent

Chats with the vault through Ask and Edit intents over OpenAI-compatible chat completions, with provider presets for local and remote models. Notes, Canvas files and metadata attachments are indexed with graph-aware retrieval across links, backlinks and neighboring chunks, and edits arrive as patches that are previewed and then applied or rejected. Read-only tools search and inspect notes, and the index is refreshed in realtime.
