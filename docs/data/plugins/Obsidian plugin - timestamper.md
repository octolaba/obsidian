# Timestamper

Timestamper inserts the current time into a note using a customizable timestamp format. Today's daily note is opened automatically when needed, and the timestamp is placed either at the end of the document or at the next empty line, optionally scrolling to the bottom.

```cue
plugin: {
    id:     "timestamper"
    name:   "Timestamper"
    author: "coignard"
    repo:   "coignard/obsidian-timestamper"

    html_url:    "https://community.obsidian.md/plugins/timestamper"
    github_url:  "https://github.com/coignard/obsidian-timestamper"
    description: "Insert the current timestamp into your notes."
    about:       "Insert the current time into notes with a customizable timestamp format. Open today's daily note automatically when needed. Place timestamps at the document end or at the next empty line and optionally auto-scroll to the bottom."
```
