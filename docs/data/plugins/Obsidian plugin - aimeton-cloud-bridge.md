# AIMETON Cloud Bridge

Connects the vault to Yandex Disk and manages cloud files from a side panel, browsing folders, uploading and downloading files, previewing images and tracking transfer progress. Desktop proxy modes are supported, covering HTTP CONNECT, HTTPS CONNECT and SOCKS5, and the interface is available in English and Russian.
