# Rewarder

This plugin grants rewards for completing tasks and todos, either immediately or at random, and is described as highly configurable. Rewards are listed in a plain file and can carry an optional rarity, an inventory count or an image. Awarded rewards are logged to the daily note.

```cue
plugin: {
    id:     "obsidian-rewarder"
    name:   "Rewarder"
    author: "gnopps"
    repo:   "gnopps/obsidian-rewarder"

    html_url:    "https://community.obsidian.md/plugins/obsidian-rewarder"
    github_url:  "https://github.com/gnopps/obsidian-rewarder"
    description: "Reward yourself for completing tasks/todos, highly configurable."
    about:       "Reward yourself when you complete tasks by granting immediate or randomized rewards. List rewards in a plain file and assign optional rarity, inventory counts, or images. Log awarded rewards to your daily note."
```
