# Image in Editor

Displays images, PDFs, iframes, Excalidraw drawings and transclusions inside the editor, so switching to preview is not needed to see them. Local and remote files are supported through Markdown links or wikilinks, and size is controlled by alt-text presets or width-by-height values. The recorded description states that it runs in the editor's Source Mode and that Live Preview is not supported.
