# SlashComplete

SlashComplete adds Notion-style slash command autocompletion to the editor for fast insertion of Markdown blocks, formatting and commands. Headings, lists, quotes, code blocks and commands are reachable from a single slash, suggestions are navigated with the keyboard, and the command list is customizable.
