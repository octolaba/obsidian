# ReallyGood Research

Runs deep-research jobs from Obsidian against Tavily or a NotebookLM MCP endpoint and saves the results into the vault. A deep-research console produces Markdown notes, optional HTML reports, and JSON history. Local AI command-line tools or provider APIs can be called, with keys and tools kept on the user's own machine.

    id:     "reallygood-research"

Open the deep-research console to generate Markdown notes, optional HTML reports and JSON history, and call local AI CLIs or provider APIs while keeping keys and tools on your machine."
