# Resizer

Resizer adds corner handles that resize and scale embedded images and PDFs in Live Preview. The Markdown is updated with the exact dimensions, and PDF scale is stored as HTML comments so the sizing persists and syncs across devices.

```cue
plugin: {
    id:     "resizer"
    name:   "Resizer"
    author: "Jan Sandström"
    repo:   "pixerojan/obsidian-resizer"

    html_url:    "https://community.obsidian.md/plugins/resizer"
    github_url:  "https://github.com/pixerojan/obsidian-resizer"
    description: "Resize embedded images and PDFs by dragging corners. Automatically updates markdown with correct dimensions. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Drag corner handles to resize and scale embedded images and PDFs in Live Preview. Automatically update markdown with exact dimensions and store PDF scale as HTML comments for persistent, cross-device sync."
```
