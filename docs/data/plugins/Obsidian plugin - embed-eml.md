# Embed EML

Embeds .eml email files inline in a note, or opens them full width in their own tab. The rendered message shows subject, sender and recipients, date, formatted body and attachments, with HTML displayed in a sandboxed iframe and cid images resolved. Remote images are blocked by default until a load button is pressed.

    id:     "embed-eml"
    name:   "Embed EML"
