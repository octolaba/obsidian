# Click to Edit

Opens notes in reader mode and switches to edit mode when the rendered note is clicked, placing the cursor at the end, at the top, or as close to the click as it can get. Ordinary interactions with links, tags and checkboxes keep working, and a text selection is retained while selecting.

```cue
plugin: {
    id:     "click-to-edit"
    name:   "Click to Edit"
    author: "alpppine"
    repo:   "alpppine/click-to-edit"

    html_url:    "https://community.obsidian.md/plugins/click-to-edit"
    github_url:  "https://github.com/alpppine/click-to-edit"
    description: "Open notes in reader mode and click anywhere to switch to edit mode with the cursor placed at the end of the note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open notes in reader mode by default. Click anywhere in the rendered note to flip to edit mode with the cursor at the end, top, or as close to your click as possible. Preserve normal interactions like links, tags, checkboxes, and retain text selection while selecting."

    stats: {
        downloads:  182
        updated_at: 1779472110000
    }
}
```
