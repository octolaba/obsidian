# Callout Metadata

Callout Metadata reads pipe-separated metadata tokens on existing callouts, so the callout syntax already in use does not have to change. Tokens set width, color, alignment, visual effects and custom CSS classes directly in Markdown: numeric tokens give percentage widths, alignment keywords place the callout, and any CSS color value sets its color. Style tokens include shadow, rounded, outline, glass, gradient, hover and sticky.
