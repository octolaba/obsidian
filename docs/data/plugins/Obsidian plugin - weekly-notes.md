# Weekly notes

Creates weekly notes whose week starts on a weekday of your choice, with titles formatted through moment.js. A template can be applied with full template-variable support, honouring the core Templates settings, and one command either creates the week's note or opens the existing one.

```cue
plugin: {
    id:     "weekly-notes"
    name:   "Weekly notes"
    author: "brabli"
    repo:   "brabli/obsidian-weekly-notes"

    html_url:    "https://community.obsidian.md/plugins/weekly-notes"
    github_url:  "https://github.com/brabli/obsidian-weekly-notes"
    description: "Create notes on a weekly basis, starting on a weekday of your choice. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create weekly notes with a configurable starting weekday and moment.js title formats. Apply a template with full template-variable support and respect core Templates settings, then run a command to create a new weekly note or open an existing one."

    stats: {
        downloads:  135
        updated_at: 1783817486000
    }
}
```
