# Notebook Navigator

Replaces the default file explorer with a two-pane browser: a navigation pane holding folders, tags, properties, shortcuts and recent files, and a list pane showing notes with previews, thumbnails and date grouping. Notes can be searched by name, tags, properties, dates, folders, extensions and tasks, with optional Omnisearch integration, and a calendar sidebar opens daily, weekly, monthly, quarterly and yearly notes. Tags can be renamed, deleted and assigned by dragging, and folders, tags, properties and files carry colors and icons alongside folder notes, pinned notes and per-folder sort. Single-pane and dual-pane layouts, custom hotkeys, vault profiles, mobile support and 21 languages with right-to-left text are included.
