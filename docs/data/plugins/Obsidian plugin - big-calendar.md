# Big Calendar

Big Calendar displays notes and scheduled tasks in month, week, day and agenda views built from daily notes. Time-stamped tasks and time blocks written in the Tasks, Dataview or Kanban formats are parsed, the views update in real time, and an event links back to the note it came from.

    id:     "big-calendar"
    name:   "Big Calendar"
    author: "Boninall"
