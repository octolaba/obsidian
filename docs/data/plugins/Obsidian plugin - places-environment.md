# Places - Environment

Supplies environment data to the Places plugin, which it requires, presenting tidal predictions, solar events, lunar phases and weather forecasts as charts, tables, cards or user-defined templates. Data is drawn from the nearest tide station together with sunrise and sunset times and current, hourly, daily and seasonal forecasts. Responses are cached in note frontmatter or in plugin data.
