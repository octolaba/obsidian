# GCal Sidebar

Shows an interactive Google Calendar sidebar inside Obsidian with support for multiple accounts, day, three-day and week views, a density toggle and mini-month navigation. Events are created, edited and dragged with bi-directional sync, recurring events are managed, and invites can be accepted, declined or marked tentative. The recorded text states that it is desktop-only.
