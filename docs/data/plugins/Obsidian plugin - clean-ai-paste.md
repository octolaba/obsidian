# Clean AI Paste

Cleans text pasted from AI chat tools such as ChatGPT, Claude and Gemini as it lands in a note. Excessive blank lines and emojis are removed and code blocks and headers repaired, so the pasted output becomes ordinary Obsidian Markdown.

```cue
plugin: {
    id:     "clean-ai-paste"
    name:   "Clean AI Paste"
    author: "Jeremy Hou"
    repo:   "goslowpoke168/obsidian-clean-ai-paste"

    html_url:    "https://community.obsidian.md/plugins/clean-ai-paste"
    github_url:  "https://github.com/goslowpoke168/obsidian-clean-ai-paste"
    description: "Instantly turns messy AI output into clean Obsidian notes on paste. Removes excessive blank lines, fixes code blocks, headers, removes emojis, and more. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Instantly turns messy text pasted from AI chatbots like ChatGPT, Claude, and Gemini into clean, formatted, Markdown notes. Removes excessive blank lines and emojis, fixes code blocks, headers, and more."

    stats: {

}
```
