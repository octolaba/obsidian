# Meow

Polishes selected text with an LLM and previews the change as a diff, through a command the recorded text names Meow: Polish selected text. A second command opens a lightweight modal for quick questions. Any OpenAI-compatible endpoint is used, and the recorded text states that the selected text or prompt is sent to the configured model.

```cue
plugin: {
    id:     "meow"
    name:   "Meow"
    author: "dmc"
    repo:   "davidmjchoi/obsidian-meow"

    html_url:    "https://community.obsidian.md/plugins/meow"
    github_url:  "https://github.com/davidmjchoi/obsidian-meow"
    description: "LLM-powered text polishing and quick Q&A without leaving your editor. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "- Polish selected text with an LLM and preview diffs. Command Meow: Polish selected text - Ask quick questions in a lightweight Q&A modal. Command Meow: Aska a quick question - Cat girl mode for otakus. Use any OpenAI-compatible endpoint; selected text or prompts are sent to the configured LLM."

    stats: {
        downloads:  49
        updated_at: 1782874739000
    }
}
```
