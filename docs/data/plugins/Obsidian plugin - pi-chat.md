# PiChat

PiChat runs the Pi coding agent inside Obsidian on desktop against a locally installed Pi binary. Conversations render as native Markdown with code highlighting, Mermaid, callouts, wiki links and live streaming, plus expandable thinking blocks, collapsible tool outputs, image paste and file attachments. Sessions are managed from a sidebar and header, chats are auto-saved as Markdown notes, and Pi sessions can be browsed, exported and switched between models and commands.
