# Replace All

Replace All adds replace-all support to Obsidian's core file search, so a batch replacement can be run across files through the built-in find. The last batch operation can be reverted with an Undo replace all command.

```cue
plugin: {
    id:     "replace-all"
    name:   "Replace All"
    author: "patrickchiang"
    repo:   "patrickchiang/obsidian-replace-all"

    html_url:    "https://community.obsidian.md/plugins/replace-all"
    github_url:  "https://github.com/patrickchiang/obsidian-replace-all"
    description: "Adds replace all functionality into search."
```
