# Things Toolkit

Things Toolkit syncs completed and canceled Things 3 Logbook items into daily notes and creates any missing note. Access falls back from SQLite to AppleScript when macOS privacy settings block it. A sidebar review calendar shows daily counts, streaks and monthly totals, and the matching daily note is opened or created from any day.
