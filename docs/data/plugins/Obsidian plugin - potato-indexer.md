# Potato Indexer

Generates a content index for the whole file or for the current selection. An existing index is rebuilt by selecting it first and running the command again.

```cue
plugin: {
    id:     "potato-indexer"
    name:   "Potato Indexer"
    author: "loyalpotato"
    repo:   "loyalpotato/potato-indexer"

    html_url:    "https://community.obsidian.md/plugins/potato-indexer"
    github_url:  "https://github.com/loyalpotato/potato-indexer"
    description: "Generate a content index based on your selection or the whole file."
    about:       "Generate a table of contents for the whole note or for a selected section. Rebuild an existing TOC by selecting it first and running the command."

    stats: {
        downloads:  3965
        updated_at: 1758912453000
    }
}
```
