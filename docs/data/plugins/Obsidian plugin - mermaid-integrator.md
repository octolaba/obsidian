# Mermaid Integrator

Assists editing Mermaid code blocks: a selection is wrapped in a mermaid block, a flowchart template is inserted, and a default flow direction of TD or LR is set. Meta comments inside a block are parsed and applied to the rendered diagram, covering alignment, width, margin, background, zoom, interactivity and theme.
