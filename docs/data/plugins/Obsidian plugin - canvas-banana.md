# Canvas Banana

Canvas Banana brings context-aware AI into Canvas and notes with interactive chat, inline node editing and multi-turn conversations that use selected nodes or text as context. It generates images from prompts and node-based mindmap responses. Concurrent streaming tasks run across multiple AI providers, with Gemini named in the recorded inputs.
