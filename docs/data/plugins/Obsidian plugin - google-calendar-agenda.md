# Google Calendar Agenda

Renders upcoming Google Calendar events inline from a fenced code block, so different notes can show different slices of the calendar as an agenda, a list or a table. Several Google accounts can be connected, and events are shown with their attendees. Authentication is desktop-only OAuth over a local loopback with read-only calendar access, and meeting notes can be saved into the vault.
