# Resojot

Resojot records voice notes into the vault, keeping both the original audio and the transcript. Transcription runs through local or cloud ASR, and the result can be sent to an LLM to polish, summarize or convert it into structured Markdown. The recorded description states that the plugin is closed source, and that audio, transcripts and organized notes are archived together.
