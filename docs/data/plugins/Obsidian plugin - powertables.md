# Power Tables

Turns Markdown tables into spreadsheet-style sheets with a formula bar, live calculations covering sum, average, minimum, maximum, count and 41 functions, AutoSum, and cell references that survive edits and sorting. Cell fills, text colors, conditional rules, number, currency and date formats and smart sorting are applied in place, and tables can be imported from or exported to CSV and Excel. Everything remains stored as plain Markdown.
