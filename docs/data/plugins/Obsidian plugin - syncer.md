# Syncer

Pulls references and links to tasks, bookmarks and emails from external services into a Markdown note under a configurable heading. Sources include Google Tasks, Gmail starred mail, Microsoft To Do, Outlook flagged mail, Azure DevOps work items, Firefox Bookmarks and Todoist. Syncs run on a background schedule or on demand, and completion status can optionally be pushed back to the connected services.

    id:     "syncer"
    name:   "Syncer"

    repo:   "desimpson/syncer"

    html_url:    "https://community.obsidian.md/plugins/syncer"
    github_url:  "https://github.com/desimpson/syncer"
    description: "Sync references/links to Google Tasks, Gmail Starred, Microsoft To Do, Outlook flagged mail, Azure DevOps work items, and Firefox Bookmarks into your vault. - This plugin has not been manually reviewed by Obsidian staff."
