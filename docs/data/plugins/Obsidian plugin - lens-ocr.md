# Lens OCR

Lens OCR captures a screen region and digitises handwritten notes and on-screen text through the operating system's own OCR, macOS Vision or Windows Media.Ocr. Recognition runs locally and offline, with no cloud service, external server or bundled OCR model, and the extracted text is pasted at the cursor in the active note.

```cue
plugin: {
    id:     "lens-ocr"
    name:   "Lens OCR"
    author: "erincayaz"
    repo:   "erincayaz/obsidian-lens-ocr"

    html_url:    "https://community.obsidian.md/plugins/lens-ocr"
    github_url:  "https://github.com/erincayaz/obsidian-lens-ocr"
    description: "Capture screen regions and digitize handwritten notes via native macOS and Windows OCR. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Digitize handwritten notes and on-screen text with your operating system's native OCR (macOS Vision, Windows Media.Ocr) entirely offline. Process everything locally with no cloud, external servers, or bundled OCR models. Paste extracted text directly at the cursor in your active note."
```
