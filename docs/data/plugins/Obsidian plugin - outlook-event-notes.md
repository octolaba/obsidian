# Outlook Event Notes

Creates notes from Microsoft Outlook meetings and appointments when .msg files are dragged onto the ribbon icon. Recurring events are detected and prompt for the occurrence date, and an existing note is opened rather than recreated. Filename patterns and Mustache templates are customizable and YAML frontmatter is sanitized, with no Microsoft 365 or Graph dependency.

```cue
plugin: {
    id:     "outlook-event-notes"
    name:   "Outlook Event Notes"
    author: "nathanstorm689"
    repo:   "nathanstorm689/outlook-event-notes"

    html_url:    "https://community.obsidian.md/plugins/outlook-event-notes"
    github_url:  "https://github.com/nathanstorm689/outlook-event-notes"
    description: "Create notes from Outlook .msg files — supports meetings, appointments, and recurring events. - This plugin has not been manually reviewed by Obsidian staff."
```
