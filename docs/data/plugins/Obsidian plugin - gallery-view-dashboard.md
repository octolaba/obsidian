# Gallery View Dashboard

Turns the vault's directory structure into a grid of cards with custom banners, fallback banners and hierarchical navigation. File metadata is shown on the cards, task checkboxes can be toggled from the gallery, and files and subfolders are browsed with live updates and folder suggestions.
