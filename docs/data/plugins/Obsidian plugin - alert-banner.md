# Alert Banner

Pins a banner to the top of any note carrying a chosen tag, shown in both reading and editing views. Up to five stacked banners can be configured with their own message, color and Lucide icon, triggered case-insensitively by inline tags or frontmatter. The banners cannot be dismissed.

```cue
plugin: {
    id:     "alert-banner"
    name:   "Alert Banner"
    author: "samgg"
    repo:   "samgilletgaras/obsidian-alert-banner"

    html_url:    "https://community.obsidian.md/plugins/alert-banner"
    github_url:  "https://github.com/samgilletgaras/obsidian-alert-banner"
    description: "Display a configurable warning banner at the top of notes with a specific tag. - This plugin has not been manually reviewed by Obsidian staff."

Configure up to five stacked banners with custom messages, colors, and Lucide icons that trigger by inline tags or frontmatter (case-insensitive) and cannot be dismissed."
