# Wikilinks to MDLinks

Converts wikilinks into Markdown links and back again. The cursor is placed inside a link and a command converts that link in place, leaving the surrounding text unchanged, and a selection can be toggled the same way.

```cue
plugin: {
    id:     "wikilinks-to-mdlinks-obsidian"
    name:   "Wikilinks to MDLinks"
    author: "agathauy"
    repo:   "agathauy/wikilinks-to-mdlinks-obsidian"

    html_url:    "https://community.obsidian.md/plugins/wikilinks-to-mdlinks-obsidian"
    github_url:  "https://github.com/agathauy/wikilinks-to-mdlinks-obsidian"
    description: "Convert wikilinks to Markdown links and vice versa."
    about:       "Toggle selected wikilinks to Markdown links and back. Place the cursor inside a link and run the command to convert individual links in-place without altering surrounding text."

    stats: {
        downloads:  21582
        updated_at: 1605733486000
    }
}
```
