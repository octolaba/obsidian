# Schedule Calendar

Schedule Calendar reads schedule entries from daily notes and displays them as a draggable, resizable timeline with daily, weekly and monthly views. Events can be created, edited, moved, resized and deleted directly on the timeline, and the changes are written back into the note file automatically.
