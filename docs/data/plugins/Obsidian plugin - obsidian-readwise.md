# Readwise Community

This plugin syncs Readwise highlights into notes, pulling new highlights on startup and updating existing notes. Note headers and highlight content are customized with Nunjucks templates, and authors can be mapped for organized imports. The recorded text states that a Readwise subscription is required.

```cue
plugin: {
    id:     "obsidian-readwise"
    name:   "Readwise Community"
    author: "renehernandez"
    repo:   "renehernandez/obsidian-readwise"

    html_url:    "https://community.obsidian.md/plugins/obsidian-readwise"
    github_url:  "https://github.com/renehernandez/obsidian-readwise"
```
