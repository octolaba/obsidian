# Crochet Weaver

Renders crochet stitch charts as themed SVG images from text patterns written in code blocks, covering flat rows, concentric rounds and spirals. An interactive progress tool or a read-only pattern list can be embedded, with row checklists, stitch counters and current-row highlighting. Progress is stored locally and offline.

```cue
plugin: {
    id:     "crochet-weaver"
    name:   "Crochet Weaver"
    author: "EvanLyu"
    repo:   "evanlyu/obsidian-crochet-weaver"

    html_url:    "https://community.obsidian.md/plugins/crochet-weaver"
    github_url:  "https://github.com/evanlyu/obsidian-crochet-weaver"
    description: "Render crochet stitch charts and progress tools from text patterns in Obsidian code blocks. - This plugin has not been manually reviewed by Obsidian staff."

Embed an interactive progress tool or read-only pattern list with row checklists, stitch counters, current-row highlighting, and local offline progress storage."
