# Gemoji

Renders emoji shortcodes such as smile, rocket and white_check_mark as Unicode emoji. The recorded text names reading mode as the place where this substitution happens.

```cue
plugin: {
    id:     "gemoji"
    name:   "Gemoji"
    author: "Frankie"
    repo:   "tofrankie/obsidian-plugin-gemoji"

    html_url:    "https://community.obsidian.md/plugins/gemoji"
    github_url:  "https://github.com/tofrankie/obsidian-plugin-gemoji"
    description: "Render emoji shortcodes in reading mode. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render emoji shortcodes like :smile:, :rocket:, :+1: and :white_check_mark: as Unicode emoji in Obsidian Reading mode."

    stats: {
        downloads:  105
        updated_at: 1780757088000
    }
}
```
