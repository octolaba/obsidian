# Bulk Exporter

Bulk Exporter selects and categorizes notes using Dataview queries and metadata and exports them into a restructured output folder. The recorded inputs name static site generators such as 11ty, Hugo and Jekyll as the destination, and the latest export status is displayed in the sidebar.

```cue
plugin: {
    id:     "bulk-exporter"
    name:   "Bulk Exporter"
    author: "symunona"
    repo:   "symunona/obsidian-bulk-exporter"

    html_url:    "https://community.obsidian.md/plugins/bulk-exporter"
    github_url:  "https://github.com/symunona/obsidian-bulk-exporter"
    description: "Filter, export notes from your vault using metadata into a customizable new structure."
    about:       "Export and restructure notes into an organized output folder using Dataview queries and metadata to select and categorize files. Prepare content for static site generators like 11ty, Hugo, or Jekyll and display the latest export status in the sidebar."
```
