# Open with

Open with adds commands that open notes in other installed programs. A single command launches the chosen program on the selected notes or folders, for viewing or editing outside Obsidian.

```cue
plugin: {
    id:     "open-with"
    name:   "Open with"
    author: "phibr0"
    repo:   "phibr0/obsidian-open-with"

    html_url:    "https://community.obsidian.md/plugins/open-with"
    github_url:  "https://github.com/phibr0/obsidian-open-with"
    description: "Add multiple other programs to open notes with."
    about:       "Open notes in other apps directly from Obsidian via commands. Launch any installed program to view or edit selected notes or folders with a single command."

        downloads:  10845

}
```
