# WeSight

Runs locally installed Claude Code, Codex or OpenCode agents as collaborators inside the vault, with a sidebar chat and inline edits in the note. Files can be mentioned and models switched through slash commands. Notes can also be shared to the internet or published as snapshots into Feishu and WeChat Official Account drafts.
