# Text Extractor

Text Extractor is a companion plugin that extracts text from images, PDFs and Office files, covering png, jpg, webp, gif, bmp, pdf, docx and xlsx through local OCR and PDF parsing. Extracted text is cached as local JSON so it can be synced and used as a mobile fallback, and language packs are downloaded on demand.
