# Chorded Hotkeys

Chorded Hotkeys triggers text insertion, pastes file or template content, or executes a command when several letters are typed at the same time. A chord is two to four keys whose order does not matter, Templater is supported, and each chord is assigned to a text, file, template or command action.

```cue
plugin: {
    id:     "obsidian-chorded-hotkeys"
    name:   "Chorded Hotkeys"
    author: "treymeyers"
    repo:   "treymeyers/obsidian-chorded-hotkeys"

    html_url:    "https://community.obsidian.md/plugins/obsidian-chorded-hotkeys"
    github_url:  "https://github.com/treymeyers/obsidian-chorded-hotkeys"
    description: "Type multiple letters at the same time to trigger text insertion, template insertion, or command execution."
    about:       "Trigger text insertion, paste file or template content (Templater supported), or execute commands using simultaneous key chords. Create chords of 2–4 keys whose order doesn't matter and assign each chord to a text, file, template, or command action."

    stats: {
        downloads:  4995
        updated_at: 1698630782000
    }
}
```
