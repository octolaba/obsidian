# Dynamic Background

Dynamic Background adds animated effects and static wallpapers behind the editor. Dark effects include Matrix digital rain, rain, random circle, snow and star sky, light effects include random circle and wave, and a wallpaper can be layered with an animation. The recorded description notes that effects work best when matched to the base theme.
