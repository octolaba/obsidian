# QR Code Generator

This plugin generates QR codes in notes from a qrcode block, with a qrcode-complex block for fully customizable codes. The text, size, margin, colors and error-correction level can all be set.

```cue
plugin: {
    id:     "obsidian-qrcode-plugin"
    name:   "QR Code Generator"
    author: "rudimuc"
    repo:   "rudimuc/obsidian-qrcode"

    html_url:    "https://community.obsidian.md/plugins/obsidian-qrcode-plugin"
    github_url:  "https://github.com/rudimuc/obsidian-qrcode"
    description: "QR code generator."
    about:       "Generate QR codes directly in your notes with a simple qrcode block or use qrcode-complex for fully customizable codes. Customize text, size, margin, colors, and error-correction level to create tailored QR images."

    stats: {
        downloads:  12574
        updated_at: 1707684343000
    }
}
```
