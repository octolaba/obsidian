# Simple Archiver

Simple Archiver moves old notes and folders into a configurable archive folder while preserving their relative paths, and restores archived items to where they came from. Scheduled auto-archive rules target folders, optionally with a regex and recursion, and move files that match conditions such as file age or a filename pattern.

    id:     "simple-archiver"
    name:   "Simple Archiver"
    author: "mfarr"
