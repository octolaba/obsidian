# Awesome Reader

This plugin reads EPUB and PDF ebooks inside the vault and resumes reading position across devices through synced progress. Book notes are created from a table of contents, with organized headings, and saved alongside the source file.

```cue
plugin: {
    id:     "awesome-reader"
    name:   "Awesome Reader"
    author: "awesomedog"
    repo:   "awesomedog/obsidian-awesome-reader"

    html_url:    "https://community.obsidian.md/plugins/awesome-reader"
    github_url:  "https://github.com/awesomedog/obsidian-awesome-reader"
    description: "Add support for multiple ebook formats. Remember reading progress and create notes from the table of contents."
    about:       "Read EPUB and PDF ebooks inside your vault and resume reading across devices with synced progress. Create book notes from a table of contents with clean, organized headings and save them alongside the source file."
```
