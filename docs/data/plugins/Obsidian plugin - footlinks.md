# Footlinks

Extracts the URLs of a note into a list of footlinks separated from the main body by a configurable divider. The footlinks are viewed and managed from a left-side panel or through the Footlinks command.

```cue
plugin: {
    id:     "footlinks"
    name:   "Footlinks"
    author: "dahawong"
    repo:   "dahawong/obsidian-footlinks"

    html_url:    "https://community.obsidian.md/plugins/footlinks"
    github_url:  "https://github.com/dahawong/obsidian-footlinks"
    description: "Extract URLs from main text to footer."
    about:       "Extract and list a note's links as footlinks separated from the main body by a configurable divider. Open the left-side Footlinks panel or run the Footlinks command to view and manage your note's footlinks."

    stats: {
        downloads:  12575
        updated_at: 1607234058000
    }
}
```
