# Our Kyobo Book Search

Searches the Kyobo Book Centre for book information over its JSON database and generates reading notes from the metadata it returns. The recorded description states that it extracts authors and translators into separate properties, renders book descriptions and tables of contents without ads, and prevents duplicate folder spacing. The index entry records that the plugin has not been manually reviewed by Obsidian staff.
