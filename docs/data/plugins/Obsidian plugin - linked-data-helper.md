# Linked Data Helper

Prepares the data used by the Linked Data Vocabularies plugin by generating linked-data files from Library of Congress bulk exports, with LCSH supported at the time of the recorded description. Output is written to an attachments path for linked data vocabularies or to an alternate path, and the recorded inputs suggest disabling the plugin until datasets need updating or adding.

```cue
plugin: {
    id:     "linked-data-helper"
    name:   "Linked Data Helper"
    author: "kometenstaub"
    repo:   "kometenstaub/linked-data-helper"

    html_url:    "https://community.obsidian.md/plugins/linked-data-helper"
    github_url:  "https://github.com/kometenstaub/linked-data-helper"
    description: "Prepare data needed by Linked Data Vocabularies."
    about:       "Generate linked-data files from Library of Congress bulk exports for use with the Linked Data Vocabularies plugin, with current support for LCSH. Save outputs to attachments/linked-data-vocabularies or choose an alternate path, then disable it until you need to update or add datasets."

    stats: {
        downloads:  4316
        updated_at: 1682248642000
    }
}
```
