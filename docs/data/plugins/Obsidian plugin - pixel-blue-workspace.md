# pixel-blue Workspace

Gathers notes, projects and tasks into a single visual workspace with hierarchical navigation and a pixel-blue appearance. Dashboards and task boards can be built, table-style notes edited in a visual Markdown editor, selections annotated, and the whole vault searched with BM25 ranking. Assistance from OpenAI, Claude or a local Codex can optionally be enabled.
