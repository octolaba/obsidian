# Steward

An AI agent runs inside Obsidian to search and manage the vault, generate Bases or Canvas files, and automate repeated workflows. It combines a fast BM25 search with user-defined commands and skills, model fallback and guardrails. The recorded inputs state that execution is mostly local, which they present as keeping responses fast, transparent and privacy-conscious.
