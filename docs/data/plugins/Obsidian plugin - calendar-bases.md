# Calendar Bases

Calendar Bases adds a calendar layout to Obsidian Bases so notes carrying date properties appear in an interactive calendar view. Events can be dragged and dropped to reschedule them, which updates the note frontmatter, and both single- and multi-day events are shown. Clicking an entry opens the note, and context menus expose further options.
