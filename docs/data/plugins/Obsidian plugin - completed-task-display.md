# Completed Task Display

Completed Task Display toggles the visibility of completed tasks across the vault from a ribbon button, the command palette or a status-bar indicator. Indented sub-bullets can optionally be hidden as well, custom task statuses are preserved, and the chosen setting persists across sessions.

```cue
plugin: {
    id:     "completed-task-display"
    name:   "Completed Task Display"
    author: "heliostatic"
    repo:   "heliostatic/completed-task-display"

    html_url:    "https://community.obsidian.md/plugins/completed-task-display"
    github_url:  "https://github.com/heliostatic/completed-task-display"
    description: "Controls for displaying or hiding completed tasks."
    about:       "Toggle visibility of completed tasks across your vault with a single click or command. Use a ribbon button, command palette, and status-bar indicator; optionally hide indented sub-bullets, preserve custom task statuses like [?] or [!], and keep your preference persistent across sessions."
```
