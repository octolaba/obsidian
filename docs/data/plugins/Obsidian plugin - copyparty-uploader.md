# Copyparty Uploader

Copyparty Uploader sends pasted or dropped media and other files to a self-hosted Copyparty server and inserts a remote embed or link, so the files never enter the vault. Local attachments in the current note can be migrated to the server and their links rewritten, and images, video, audio, PDFs and other file types each receive an appropriate embed.

```cue
plugin: {
    id:     "copyparty-uploader"
    name:   "Copyparty Uploader"
    author: "requisite"
    repo:   "r3quisitevariety/copyparty-obsidian"

    html_url:    "https://community.obsidian.md/plugins/copyparty-uploader"
    github_url:  "https://github.com/r3quisitevariety/copyparty-obsidian"
    description: "Paste or drop media files and have them automatically uploaded to your self-hosted Copyparty server and embedded in your note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Upload pasted or dropped media and files to your self-hosted Copyparty server, inserting remote embeds or links so files never enter your vault. Migrate local attachments in the current note and rewrite links, handling images, video, audio, PDFs and other file types with appropriate embeds."

    stats: {
        downloads:  89

    }
}
```
