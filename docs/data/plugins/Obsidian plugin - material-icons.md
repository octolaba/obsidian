# Material Icons

Material Icons adds Material Theme icons, in the style used by VS Code, to files and folders in the Obsidian file explorer. Distinct icons are shown for common file types including Markdown, JavaScript, TypeScript and Python code, images, JSON, CSS and HTML, PDF, ZIP, env and .git files. Special folders such as src, assets, images, docs and templates also receive their own icons.
