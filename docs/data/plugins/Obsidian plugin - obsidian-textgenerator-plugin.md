# Text Generator

Content is generated from the notes themselves, whether ideas, titles, summaries, outlines or full paragraphs, using AI models inside Obsidian. Templates and flexible prompt context drive the requests and community templates can be reused. The provider is switched through frontmatter between OpenAI, Google Gemini and Hugging Face.
