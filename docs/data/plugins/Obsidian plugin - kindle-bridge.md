# Kindle Bridge

Syncs Kindle highlights and notes from Amazon into per-book Markdown files in the vault. Each book keeps its highlights and attached notes in a plugin-managed section, maintained by differential and deletion sync, with optional cover links. Summaries can be written into the Daily Note, and syncing runs manually or on a schedule.
