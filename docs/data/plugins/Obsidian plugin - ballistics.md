# Ballistics

Ballistics embeds ballistics tables in notes through a ballistics-table code block. A range-by-range trajectory is generated from inputs such as ballistic coefficient, muzzle velocity, sight height, zero range, wind and bullet weight, in imperial or metric units.

```cue
plugin: {
    id:     "ballistics"
    name:   "Ballistics"
    author: "Jason Heddings"
    repo:   "jheddings/obsidian-ballistics"

    html_url:    "https://community.obsidian.md/plugins/ballistics"
    github_url:  "https://github.com/jheddings/obsidian-ballistics"
    description: "Embed ballistics data in Obsidian notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed ballistics tables directly in notes using a ballistics-table code block. Generate range-by-range trajectories from inputs like ballistic coefficient, muzzle/muzzle velocity, sight height, zero range, wind and bullet weight, and switch between imperial or metric units."

    stats: {
        downloads:  123
        updated_at: 1780513783000
    }
}
```
