# Family Bank

Manages recurring savings for children, with an account per child, monthly and annual fixed deposits, and automatic interest settlement that can be withdrawn or rolled into a new deposit. Goals are tracked with progress bars, alongside asset trend charts, deposit breakdowns and a leaderboard comparing children. Data is stored in the vault as JSON so it travels with ordinary vault syncing.
