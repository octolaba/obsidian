# Upcoming Birthdays

Reads a date-of-birth attribute from note frontmatter and lists the birthdays that are coming up. Each entry shows the days to go and the age being reached, today's and imminent birthdays are highlighted, and clicking a name opens that note. The property name and the look-ahead period are configurable.

```cue
plugin: {
    id:     "upcoming-birthdays"
    name:   "Upcoming Birthdays"
    author: "nithinbekal"
    repo:   "nithinbekal/obsidian-upcoming-birthdays"

    html_url:    "https://community.obsidian.md/plugins/upcoming-birthdays"
    github_url:  "https://github.com/nithinbekal/obsidian-upcoming-birthdays"
    description: "Show upcoming birthdays from notes with date-of-birth attributes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Track and display upcoming birthdays by reading a date-of-birth field in note frontmatter. Show upcoming dates with days-to-go and calculated ages, highlight today's and imminent birthdays, and open the corresponding note by clicking a name. Configure the frontmatter property name and look‑ahead period."

    stats: {
        downloads:  138
        updated_at: 1779934811000
    }
}
```
