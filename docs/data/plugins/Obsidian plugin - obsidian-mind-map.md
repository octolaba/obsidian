# Mind Map

This plugin displays Markdown notes as mind maps rendered with Markmap. The mind map pane can be pinned, so one map stays in place while other notes are browsed. The map can also be copied to the clipboard as an SVG screenshot.

```cue
plugin: {
    id:     "obsidian-mind-map"
    name:   "Mind Map"
    author: "lynchjames"
    repo:   "lynchjames/obsidian-mind-map"

    html_url:    "https://community.obsidian.md/plugins/obsidian-mind-map"
    github_url:  "https://github.com/lynchjames/obsidian-mind-map"
    description: "Display Markdown notes as mind maps using Markmap."
    about:       "View Markdown notes as interactive mind maps rendered with Markmap. Pin the mind map pane to keep a map in place while browsing other notes, and copy the map as an SVG screenshot to your clipboard."

}
```
