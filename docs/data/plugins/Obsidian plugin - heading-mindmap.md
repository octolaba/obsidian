# Heading Mindmap

Heading Mindmap opens the headings of a Markdown note as an editable mind map, building a node tree from the heading hierarchy. The content of the current node is viewed or edited in a single-column bottom pane, in rendered or source mode, and changes are written back to the original Markdown file. File nodes expand on double click, list items appear as read-only virtual child nodes, and basic keyboard interaction is supported.
