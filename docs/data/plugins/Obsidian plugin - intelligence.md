# Intelligence

Intelligence integrates OpenAI Assistants into Obsidian, so GPT assistants can be created with custom instructions and reused across conversations. Notes can be uploaded for retrieval, and the code interpreter processes data and generates files or visualizations. Conversations are threaded and cite their sources as clickable footnotes.
