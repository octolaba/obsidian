# Visual UI Editor

Visual UI Editor selects any Obsidian UI element on screen, highlighting similar elements on hover and opening an editor on click. Override strength and forced rules are adjustable, edits can be erased or reset, and changes are previewed in the document. The result is saved as a reusable CSS snippet.
