# Librarian

Librarian tracks reading inside the vault by importing book metadata from Open Library and generating standardized book notes with YAML frontmatter. Reading states and session logs are recorded, books are organised into shelves, quotes are captured with page references, and reading statistics are reported.

```cue
plugin: {
    id:     "librarian"
    name:   "Librarian"
    author: "lastratalive"
    repo:   "lastratalive/Librarian"
```
