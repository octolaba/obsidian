# Suggest Notes

Relevant notes are suggested while writing, drawn from note names, aliases, folders or tags the user has selected. Connections chosen often are prioritized, so common links surface first and a link is made without typing the opening brackets.

```cue
plugin: {
    id:     "suggest-notes"
    name:   "Suggest Notes"
    author: "doggy-footprint"
    repo:   "doggy-footprint/Suggest-Notes"

    html_url:    "https://community.obsidian.md/plugins/suggest-notes"
    github_url:  "https://github.com/doggy-footprint/Suggest-Notes"
    description: "Suggest notes as selected by user."
    about:       "Suggest relevant notes as you write by tracking note names, aliases, folders, or tags you define. Prioritize frequently chosen connections to surface common links and speed linking without typing [[."

    stats: {
        downloads:  334
        updated_at: 1725953805000
    }
}
```
