# Copy document as HTML

Copy document as HTML copies the current document or a selection to the clipboard as HTML for pasting into HTML-aware applications such as Gmail. Images are preserved along with PlantUML, Diagrams, Excalidraw, Mermaid and Dataview content, and the styling applied is customizable. External assets can optionally be embedded and SVGs converted to bitmaps for compatibility.
