# Github Issues

Tracks issues, pull requests and GitHub Projects v2 from GitHub and GitLab, including self-hosted instances, inside the vault with Kanban project views and custom fields. It syncs in the background, follows sub-issues, filters items and generates Markdown notes carrying YAML metadata.

```cue

    id:     "github-issues"
    name:   "Github Issues"
    author: "lonoxx"
    repo:   "lonoxx/obsidian-github-issues"

    html_url:    "https://community.obsidian.md/plugins/github-issues"
    github_url:  "https://github.com/lonoxx/obsidian-github-issues"
```
