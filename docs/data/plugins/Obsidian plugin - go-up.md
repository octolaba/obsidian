# Go Up

Navigates from a note to a designated parent note recorded in an up frontmatter property, which may link to one or several parents. The name of that property can be changed in the settings.

```cue
plugin: {
    id:     "go-up"
    name:   "Go Up"
    author: "jinmugo"
    repo:   "jinmugo/obsidian-go-up"

    html_url:    "https://community.obsidian.md/plugins/go-up"
    github_url:  "https://github.com/jinmugo/obsidian-go-up"
    description: "Quickly navigate to a specified \"parent\" page"
    about:       "Jump to a designated parent note by adding an \"up\" front-matter property that links to one or multiple parent pages. Rename the parent property in settings and navigate instantly from child notes to their parent(s)."

    stats: {
        downloads:  1792
        updated_at: 1782707761000
    }
}
```
