# MtG Decklist

Renders fenced decklist code blocks as Moxfield-style deck panels built on Scryfall card data, with image previews on hover or tap. Inline mana symbols and hoverable card links appear in prose, sections group and sort automatically, and the panel shows mana curve, colour-pie and type breakdowns. Colour-identity and legality problems are flagged.
