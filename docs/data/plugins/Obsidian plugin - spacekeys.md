# Spacekeys

Obsidian commands are executed through mnemonic sequences of keypresses started by a single leader key. A popup menu shows the available keys grouped into submenus for discovery, and the keymap is large and customizable, able to include commands contributed by other plugins.

```cue
plugin: {
    id:     "spacekeys"
    name:   "Spacekeys"
    author: "jlumpe"
    repo:   "jlumpe/obsidian-spacekeys"

    html_url:    "https://community.obsidian.md/plugins/spacekeys"
    github_url:  "https://github.com/jlumpe/obsidian-spacekeys"
    description: "Define hotkeys based on sequences of keypresses."
    about:       "Execute Obsidian commands via mnemonic key sequences triggered by a single leader key. Display a popup menu with grouped submenus for quick discovery and assign a large, customizable keymap that can include commands from other plugins."
```
