# Copy Search URL

Copy Search URL adds a copy command to the search view and its results context menu. It puts the Obsidian URL of the current search on the clipboard, so a predefined search can be bookmarked or shared.

```cue
plugin: {
    id:     "obsidian-copy-search-url"
    name:   "Copy Search URL"
    author: "Carlo Zottmann"
    repo:   "czottmann/obsidian-copy-search-url"

    html_url:    "https://community.obsidian.md/plugins/obsidian-copy-search-url"
    github_url:  "https://github.com/czottmann/obsidian-copy-search-url"
    description: "Add a button to the search view to copy the search URL."
    about:       "Add a \"Copy Search URL\" command to the search results context menu. Copy the Obsidian URL for the current search to the clipboard for easy bookmarking or sharing of predefined searches."

    stats: {
        downloads:  5631
        updated_at: 1683051115000
    }
}
```
