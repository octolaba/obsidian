# Trouble Tags

Scans the active file for inline TODO, FIXME, BUG, NOTE and WARN tags and lists them in a sidebar panel. Clicking an entry jumps to its line in the editor, and the scan repeats automatically when the file is edited or the active file changes.

```cue
plugin: {
    id:     "trouble-tags"
    name:   "Trouble Tags"
    author: "Simon Späti"
    repo:   "sspaeti/obsidian-trouble-tags"

    html_url:    "https://community.obsidian.md/plugins/trouble-tags"
    github_url:  "https://github.com/sspaeti/obsidian-trouble-tags"
    description: "Scans the active file for TODO, FIXME, BUG, NOTE, and WARN tags and lists them in a sidebar panel. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Scan active note for inline tags (#TODO, #FIXME, #BUG, #NOTE, #WARN) and list them in a sidebar panel. Click an entry to jump to its line in the editor. Rescan automatically when you edit or switch files."

    stats: {
        downloads:  136
        updated_at: 1770372199000
    }
}
```
