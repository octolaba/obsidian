# Minidoro

Minidoro puts a minimal Pomodoro timer in the header with a circular progress indicator and hover-activated controls to start, pause, resume and reset. Work, short break and long break durations, auto-start and the session count are configurable, desktop and sound notifications are available, and the control panel can be pinned so that it stays reachable.
