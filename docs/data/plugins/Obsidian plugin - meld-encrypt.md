# Meld Encrypt

Encrypts and decrypts whole notes or a selected passage inside the vault. Decrypted content is held in memory only, so it is not written to disk or synced. The recorded text states that passwords are not stored and cannot be recovered once forgotten.

```cue
plugin: {
    id:     "meld-encrypt"
    name:   "Meld Encrypt"
    author: "meld-cp"
    repo:   "meld-cp/obsidian-encrypt"

    html_url:    "https://community.obsidian.md/plugins/meld-encrypt"
    github_url:  "https://github.com/meld-cp/obsidian-encrypt"
    description: "Hide secrets in your notes."
    about:       "Encrypt and decrypt entire notes or selected text directly in your Obsidian vault. Keep decrypted content in memory only so nothing is written to disk or synced. Note that passwords are not stored and cannot be recovered if forgotten."
```
