# YouTube Video Summarizer

Summarizes YouTube videos inside Obsidian using Google Gemini, OpenAI, Anthropic or other compatible models. Transcripts are extracted and turned into structured notes with key points and explanations of technical terms, plus metadata and tags for organized review.

    id:     "yt-video-summarizer"
    name:   "YouTube Video Summarizer"
    author: "mbramani"
    repo:   "mbramani/obsidian-yt-video-summarizer"

    html_url:    "https://community.obsidian.md/plugins/yt-video-summarizer"
    github_url:  "https://github.com/mbramani/obsidian-yt-video-summarizer"
    description: "Summarize YouTube videos using Gemini AI. Extract transcripts, generate summaries, and create structured notes."
