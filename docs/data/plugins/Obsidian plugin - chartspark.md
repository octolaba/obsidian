# ChartSpark

ChartSpark turns Obsidian tables, checkbox lists and key-value blocks into charts that refresh themselves. Bar, Line, Pie, Doughnut, Radar and Polar Area types are available, axes can be swapped, checkbox data aggregated across a vault or a folder, and a chart exported to PNG while following the current theme.
