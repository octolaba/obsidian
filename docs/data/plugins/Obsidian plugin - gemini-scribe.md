# Gemini Scribe

Brings Google Gemini into Obsidian to generate, edit and manage notes with the vault as context. An agent with tool-calling and skills can read, create, move or edit files, and a unified context shelf holds binary attachments and side-by-side diffs. A Google Gemini API key is required.
