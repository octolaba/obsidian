# Telegram Sync

Telegram Sync transfers messages and files from Telegram into a vault on desktop. Chats can be saved as individual notes or appended to existing ones, images and files are imported, and voice or video notes can be transcribed with Telegram Premium. Templates and target folders are applied as messages arrive, Markdown is auto-formatted, and processed messages can optionally be deleted.
