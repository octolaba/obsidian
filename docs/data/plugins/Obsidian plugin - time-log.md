# Timelog

Timelog keeps a running project log in a single Markdown note under dated headings that follow the Daily Note format, falling back to an ISO year-month-day heading. Entries are inserted as bold, time-prefixed bullets, a command jumps to the latest dated section, and a context-aware status bar reports logging activity.

```cue
plugin: {
    id:     "time-log"
    name:   "Timelog"
    author: "eddie"
    repo:   "eddie/obsidian-time-log"

    html_url:    "https://community.obsidian.md/plugins/time-log"
    github_url:  "https://github.com/eddie/obsidian-time-log"
    description: "Add timestamps to entries under dated headers for lab notebook style logging."
    about:       "Keep a running project log in a single Markdown note with dated headings that match your Daily Note format (falls back to ISO YYYY-MM-DD). Insert bold, time-prefixed bullet entries automatically, jump to the latest dated section, and view a context-aware status bar showing logging activity."

    stats: {
        downloads:  768
        updated_at: 1783073527000
    }
}
```
