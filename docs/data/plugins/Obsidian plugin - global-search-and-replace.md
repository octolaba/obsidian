# Global Search and Replace

Searches and replaces across every file in the vault, using plain text or regular expressions with optional case sensitivity. Matches can be previewed and cycled through and the matching notes opened, and replacements accept standard patterns including the whole match, numbered groups and named groups.

    id:     "global-search-and-replace"
