# Teleprompter

Teleprompter opens a window that shows the current note in a large, readable format and scrolls it automatically for live presentations and video production. Speed, font, spacing, colors and orientation flip are adjustable, and the window can be detached or made full-screen. Reading is controlled from panels, hotkeys and an API.
