# Shuffle Lab

Shuffle Lab runs timed, randomized fullscreen image slideshows from any vault folder, for drawing practice, presentations, games and reference. Per-image durations and looping are configurable, an optional intro markdown slide can open the session, a live session timer is shown, and sessions are logged so unseen images are prioritized next time.
