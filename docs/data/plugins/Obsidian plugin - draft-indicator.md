# Draft Indicator

Marks notes whose frontmatter carries draft: true by showing a pencil icon and italicising the title in the file explorer. The styling is applied automatically from the frontmatter value.

```cue
plugin: {
    id:     "draft-indicator"
    name:   "Draft Indicator"
    author: "beardicus"
    repo:   "beardicus/obsidian-draft-indicator-plugin"

    html_url:    "https://community.obsidian.md/plugins/draft-indicator"
    github_url:  "https://github.com/beardicus/obsidian-draft-indicator-plugin"
    description: "Show draft status in the file explorer."
    about:       "Display a pencil icon and italicize note titles in the file explorer for files with draft: true in their frontmatter. Apply styling automatically based on frontmatter."

    stats: {
        downloads:  957
        updated_at: 1714067434000
    }
}
```
