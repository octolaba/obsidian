# Custom Timer

Turns timer code blocks into an interval timer with Start, Skip and Reset controls and a beep between steps. Indented blocks repeat as sets and can be nested, steps take labels such as work and pause, and durations accept flexible forms like 30, 30s, 2m or 1h.

    id:     "custom-timer"
    name:   "Custom Timer"
    author: "catalyys"
    repo:   "catalyys/obsidian-timer"

    html_url:    "https://community.obsidian.md/plugins/custom-timer"
    github_url:  "https://github.com/catalyys/obsidian-timer"
    description: "Run interval timers from timer code blocks with sets, work and pause durations for workout or other stuff. - This plugin has not been manually reviewed by Obsidian staff."
