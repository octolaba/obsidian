# Selection Toolbar

Selection Toolbar shows a compact floating toolbar when text is selected in the Markdown editor. It applies inline styles such as bold, italic, underline, strikethrough, highlight, inline code and links, applies block formats such as quotes, lists, code blocks and callouts, converts case, or extracts the selection into a new note that is left behind as a wikilink.
