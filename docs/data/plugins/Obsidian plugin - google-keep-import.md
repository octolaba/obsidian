# Google Keep Import

Imports notes and attachments from Google Keep backup JSON files into the vault, including standalone binary files that have no matching note. A real-time error log lists files that failed or are unsupported, so an import can be cancelled, edited or retried.

```cue
plugin: {
    id:     "google-keep-import"
    name:   "Google Keep Import"
    author: "Dale de Silva"
    repo:   "daledesilva/obsidian_google-keep-import"

    html_url:    "https://community.obsidian.md/plugins/google-keep-import"
    github_url:  "https://github.com/daledesilva/obsidian_google-keep-import"
    description: "Import Google Keep backup json files and their attachments. Can also be used to import other files."
    about:       "Import exported Google Keep notes and attachments into Obsidian, including standalone binary files even without matching notes. Display a real-time error log for failed or unsupported files so you can cancel, edit, or retry imports."
```
