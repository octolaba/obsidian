# Tasks Timeline

Tasks Timeline displays and manages the task items of a vault on timeline views, with filters, tags, priorities and recurrence handling. It also runs a built-in MCP server so that AI agents can read and write tasks, exposing tools to query, create, update, delete, complete and batch-update items, fetch statistics, and generate daily or weekly plans.
