# Atomizer

Atomizer splits a large note into concise atomic notes, using the OpenAI API to extract its key insights and ideas. Each generated note receives frontmatter with a date and custom tags. Note content is sent to OpenAI for processing, so an OpenAI API key is required.

    id:     "note-atomizer"
    name:   "Atomizer"
    author: "binxly"
    repo:   "binxly/Atomizer"
