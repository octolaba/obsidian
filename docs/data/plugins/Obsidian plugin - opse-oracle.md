# OPSE Oracle

OPSE Oracle plays solo tabletop RPGs in the vault using the One Page Solo Engine v1.6, automating rolls, oracle queries, scene mechanics and session tracking. It generates yes/no and magnitude oracles, plot hooks, NPCs and random events, and supports graph-based dungeon and hex exploration. History is persistent and exportable as Markdown or JSON.
