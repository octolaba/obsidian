# TCG Binder

TCG Binder tracks a Pokemon TCG collection, builds decks and browses cards inside the vault, keeping everything as plain Markdown notes with frontmatter so the data stays readable, syncable, linkable and portable. Decklists and collections can be imported from TCG Live or CSV, variants and set progress managed, and cost-to-complete shown against market prices. Collections and decks export back to TCG Live.
