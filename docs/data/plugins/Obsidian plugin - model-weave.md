# Model Weave

Model Weave manages text-first models, relationships and diagrams with Markdown as the single source of truth. It generates Mermaid overview graphs or custom detailed renderers, shows previews and diagnostics, and exports PNGs, all derived from the Markdown without ever changing it.

plugin: {
    id:     "model-weave"
    name:   "Model Weave"
    author: "nejimakibird"
    repo:   "nejimakibird/model-weave"

    html_url:    "https://community.obsidian.md/plugins/model-weave"
    github_url:  "https://github.com/nejimakibird/model-weave"
