# Nope

Nope exports notes to publication-ready PDFs through Pandoc and the Eisvogel LaTeX template, running the toolchain in Docker so no local LaTeX installation is required. It supports custom branding, transclusions and cross-references, so a document can be assembled from modular notes with embedded chapters, theorems, tables, diagrams and glossary entries while numbering, cross-references and citation handling are preserved.

    id:     "nope"
