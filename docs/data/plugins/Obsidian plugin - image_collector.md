# Image Collector

Collects every image referenced in the current note and saves it into a new folder. The recorded inputs give uploading to a website and converting notes to LaTeX as the reasons for gathering the Markdown-linked images in one place.

plugin: {
    id:     "image_collector"
    name:   "Image Collector"
    author: "tdaykin"
    repo:   "tdaykin/obsidian_image_collector"

    html_url:    "https://community.obsidian.md/plugins/image_collector"
    github_url:  "https://github.com/tdaykin/obsidian_image_collector"
    description: "Collects all images from current note and saves them to a new folder"
    about:       "Collect all images referenced in the current note into a single folder for quick export. Export Markdown-linked images for easy uploading to websites or converting notes to LaTeX without manually hunting files."
