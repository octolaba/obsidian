# Explorer

A file explorer view that shows the contents of a folder as cards or as a list inside the editor pane, so folders are browsed from any note. Entries sort by name, creation date or modification date, a scoped search covers the current folder, and large folders are paginated. Folder notes, mobile and right-to-left layouts are supported.
