# Markwhen

Markwhen creates timelines, gantt charts, calendars and similar views from markwhen's timeline syntax written inside Obsidian notes. The timelines are embedded and rendered inline, so the chronological view can be read and edited beside the Markdown that defines it.

```cue
plugin: {
    id:     "markwhen"
    name:   "Markwhen"
    author: "mark-when"
    repo:   "mark-when/obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/markwhen"
    github_url:  "https://github.com/mark-when/obsidian-plugin"
    description: "Create timelines, gantt charts, calendars, and more using markwhen."
    about:       "Create timelines using Markwhen's timeline syntax inside Obsidian notes. Embed and render those timelines inline to view and edit chronological visualizations alongside your Markdown."

    stats: {
        downloads:  43456
        updated_at: 1752515119000
    }
}
```
