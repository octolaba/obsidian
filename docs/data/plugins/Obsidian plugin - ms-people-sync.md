# Microsoft People Sync

Syncs Microsoft 365 contacts from Microsoft Graph into individual notes, one Markdown file per person in a designated People folder, using a customizable template the recorded description calls minimal. The generated contacts are then referenced or embedded from other notes through @-style links.
