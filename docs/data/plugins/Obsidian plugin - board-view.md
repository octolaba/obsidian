# Board View

Board View adds an interactive board to Bases with grouping by both column and row, so it can serve as a Kanban board or a gallery. Dragging a card updates the underlying note property, and groups can be color-coded, hidden or reordered. Cards can show images and icons, and new notes are created with properties already filled in.
