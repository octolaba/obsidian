# Asciidoctor editor

Views and modifies Asciidoc pages in Obsidian through native edit and read modes. The recorded inputs warn that global file search does not cover these pages because the Obsidian API does not support it, and that the plugin should not be used alongside the asciidoc-reader or asciidoc-blocks plugins.
