# Embed Editor

Makes transclusions editable in place: clicking an embed opens a floating editor on its source, and saving updates the source file and every other embed of it. Full-note, heading and block transclusions are covered, the editor shows line numbers and follows the theme, and a CSS snippet is included to make embeds look native.

```cue
plugin: {
    id:     "embed-editor"
    name:   "Embed Editor"
    author: "xmisio72"
    repo:   "xmisio72/obsidian-embed-editor"

    html_url:    "https://community.obsidian.md/plugins/embed-editor"
    github_url:  "https://github.com/xmisio72/obsidian-embed-editor"
    description: "Notion-style synced blocks. Click any transclusion (![[note]]) to edit its source in a floating panel — edit embeds in place. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Click any transcluded embed to open a floating editor and edit its source inline; saving updates the source file and all embeds instantly. Work with full-note, heading and block transclusions, show a source-style editor with line numbers and theme-aware styling, and include a CSS snippet for seamless, native-looking embeds."
```
