# HTML Blocks

HTML Blocks renders HTML, CSS and JavaScript written in html-block fenced code blocks directly inside a note. Each block is isolated in its own Shadow DOM so styles and top-level variables do not collide, external HTML files can be embedded, and an Inspect Mode jumps from a rendered element to its source.
