# URL Formatter

Formats specific URLs into Markdown links as they are pasted into a note. Customizable regex patterns and output formats extract identifiers such as Jira tickets, blog posts or documentation pages, producing readable link text while the original URL is preserved.

```cue
plugin: {
    id:     "url-formatter"
    name:   "URL Formatter"
    author: "thomassnoeck"
    repo:   "thomassnoeck/url-formatter-obsidian"

    html_url:    "https://community.obsidian.md/plugins/url-formatter"
    github_url:  "https://github.com/thomassnoeck/url-formatter-obsidian"
    description: "Automatically formats specific URLs pasted into your notes into clean Markdown links."
    about:       "Convert messy URLs into concise Markdown links when pasted into notes. Define customizable regex patterns and output formats to extract identifiers (Jira tickets, blog posts, docs) and produce readable link text while preserving the original URL."
```
