# Marp

Marp builds slide decks written in Markdown and previews them with automatic reload on save. Decks export to PDF, PPTX or HTML, which requires Node.js. Local images are embedded as Base64, wiki and Markdown image links are both accepted, and HTML transitions are used where available.
