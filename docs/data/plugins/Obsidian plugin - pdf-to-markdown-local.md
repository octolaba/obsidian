# PDF to Markdown Local

Converts text-based PDFs to traceable Markdown locally from the file or folder context menu, writing side-by-side Markdown files and never overwriting the PDF. Images can be embedded, hyphenation, headers, footers and two-column layouts receive conservative cleanup, built-in templates apply, and local previous and next links connect the output. Batch conversion with an optional merged result and a preview is available.
