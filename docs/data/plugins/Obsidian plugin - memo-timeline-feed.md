# Memo Timeline Feed

Displays notes, diaries and images as a timeline, a diary-style feed or a photo wall. Content is gathered from notes tagged for the timeline and from diary notes, then shown in a card-based gallery with titles, dates, paths, summaries, tags and image previews.
