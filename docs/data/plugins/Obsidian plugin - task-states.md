# Task States

Task States cycles a task through TODO, STANDBY, DONE, CANCELLED, PRIORITY and PROGRESS with a single click on its checkbox. It operates in Reading view, Live Preview and Source mode while preserving Markdown task syntax. Dash, asterisk and plus bullets, nested tasks and task lines inside blockquotes are all handled.

    id:     "task-states"
    name:   "Task States"
    author: "lucasmantuan"
