# Fluent OneNote

Adds a two-pane navigation view in the style of Microsoft OneNote, presenting the vault as Notebooks, Sections and Pages. Typing searches immediately, a global hotkey jumps between panes, and sections and pages are reordered by drag-and-drop with the change saved right away. It runs either as a floating popup or as a sidebar view, and its modal size and accent colors are configurable.

```cue
plugin: {
    id:     "fluent-onenote"
    name:   "Fluent OneNote"
    author: "Jeff1024"
    repo:   "2607044640/fluent-onenote"

    html_url:    "https://community.obsidian.md/plugins/fluent-onenote"

    description: "A beautiful, 2-pane navigation plugin for Obsidian notes, inspired by Microsoft OneNote. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Navigate notes with a two-pane OneNote-style interface across Notebooks, Sections, and Pages. Search instantly by typing, jump across panes with a global hotkey, and reorder sections and pages via drag-and-drop with real-time saving. Switch between a floating popup and sidebar view and adjust modal size and accent colors to match your workflow."
```
