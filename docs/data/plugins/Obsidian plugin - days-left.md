# Days Left

Counts the days remaining until a future event or elapsed since a past date, embedding countdown and count-up timers in notes. Urgent events can be highlighted with a spotlight and with notifications, counters render as centered blocks or as inline tags, and appearance, language and per-event settings are configurable with live updates.

plugin: {
    id:     "days-left"
    name:   "Days Left"
    author: "creesee"
    repo:   "creesee/obsidian-days-left"

    html_url:    "https://community.obsidian.md/plugins/days-left"
    github_url:  "https://github.com/creesee/obsidian-days-left"
