# Enhanced Canvas

Keeps Canvas node connections in step with properties in the underlying notes. A note is split by headings into a hierarchical Canvas tree, notes sent to a Canvas gain a canvas property against a selected Canvas for batch adds, nodes resize as they are edited, and edges carry properties named after the canvas file. Clicking a canvas link focuses and zooms the linked node.
