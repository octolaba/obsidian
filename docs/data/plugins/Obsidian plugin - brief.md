# Brief

Brief manages client workspaces: the active client is switched at any time from a side panel or the command palette, is shown in the status bar and ribbon, and carries a color used as an accent. It creates notes with consistent frontmatter from a set of note types including meeting, project, brief, research, reference and quick note, and applies templates to existing notes without overwriting their content. It also generates a dashboard for the active client that groups notes by type with relevant columns, and regenerating it replaces only the generated section.
