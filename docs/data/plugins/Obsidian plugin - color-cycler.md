# Color cycler

Color cycler changes the theme's accent color dynamically from a ribbon icon or the command palette, working in HSL values. It runs in increment, random or preset mode, can cycle automatically at a set interval or on load, shows the current HSL in the status bar, and applies separate behaviours for light and dark.
