# Day Planner Analyzer

Reads Day Planner-style daily notes and derives statistics on time-boxed tasks, planned against unplanned time, day length and task completion, updating as the notes are edited. A week, a month or a custom range can be selected and viewed as charts and sortable tables, with priority tasks highlighted. A built-in AI chat answers questions about the resulting habits and productivity.
