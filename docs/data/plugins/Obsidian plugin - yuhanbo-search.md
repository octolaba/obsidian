# Yuhanbo Search

Searches the vault with weighted scoring across filenames, folders, tags, headings, content and quotes, with per-field weights, search scope and exclusions all configurable. Typing @@ inserts matching text, @@# creates a heading link and @@@ creates a block link, and results are navigable from the keyboard.

```cue
plugin: {
    id:     "yuhanbo-search"
    name:   "Yuhanbo Search"
    author: "yuhanbo"
    repo:   "yuhanbo758/obsidian-yuhanbo-search"

    html_url:    "https://community.obsidian.md/plugins/yuhanbo-search"
    github_url:  "https://github.com/yuhanbo758/obsidian-yuhanbo-search"
    description: "Search your vault with customizable weights and insert matching text, headings, or block links. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Search your vault with weighted scoring across filenames, folders, tags, headings, content, and quotes. Insert matching text with @@, create heading links with @@#, and create block links with @@@; adjust per-field weights, search scope, and exclusions, and navigate results via keyboard."

    stats: {
        downloads:  22
        updated_at: 1785766839000
    }
}
```
