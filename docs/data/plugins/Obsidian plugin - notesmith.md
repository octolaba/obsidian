# NoteSmith

Refines messy Markdown notes through an OpenAI-compatible model, cleaning up formatting, correcting grammar and punctuation, and applying a sensible heading structure. Bullet lists can be converted into tasks and tag annotations added, and the polished output overwrites the file when run from a single command or the right-click menu. Summaries and new content can also be generated from existing notes.
