# Nutstore Sync

Synchronizes a vault with Nutstore (Jianguoyun) over WebDAV in both directions to keep files consistent across devices. Transfers are incremental, and the plugin adds single sign-on, a visual WebDAV browser, character-level conflict merging or resolution by timestamp, a loose-sync mode for large vaults, progress indicators and detailed logs.
