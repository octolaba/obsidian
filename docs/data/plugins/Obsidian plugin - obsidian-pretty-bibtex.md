# Pretty BibTeX

This plugin shows raw BibTeX bibliography entries in a prettier form, turning standard bibtex code blocks into styled entries whose fields and values are easy to scan. The entry header color is matched to Obsidian's accent color.

```cue
plugin: {
    id:     "obsidian-pretty-bibtex"
    name:   "Pretty BibTeX"
    author: "sandrofigo"
    repo:   "sandrofigo/obsidian-pretty-bibtex"

    html_url:    "https://community.obsidian.md/plugins/obsidian-pretty-bibtex"
    github_url:  "https://github.com/sandrofigo/obsidian-pretty-bibtex"
    description: "Show raw BibTeX bibliography entries in a prettier way."
    about:       "Transform standard bibtex code blocks into styled, easy-to-scan bibliography entries that present fields and values clearly. Match header color to Obsidian's Accent color for consistent visuals."

    stats: {
        downloads:  10425
        updated_at: 1708717010000
    }
}
```
