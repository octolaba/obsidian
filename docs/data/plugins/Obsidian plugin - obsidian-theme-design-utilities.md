# Theme Design Utilities

The plugin collects quality-of-life commands for theme designers: mobile emulation, cycling Source, Live Preview and Reading modes, and switching through installed themes. Further commands toggle light and dark, open devtools, freeze the interface to capture transient elements, garble text for private screenshots, and open color cheatsheets and debugging overlays.
