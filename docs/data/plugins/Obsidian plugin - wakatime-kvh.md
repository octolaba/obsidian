# Time tracker for Wakatime or Wakapi

The plugin tracks time spent browsing and writing notes by sending heartbeats to WakaTime or to a custom Wakapi instance. Projects are assigned per file or per folder with a default project, and paths can be excluded from tracking. Activity is recorded for Markdown, PDFs and images without requiring wakatime-cli.

    id:     "wakatime-kvh"
