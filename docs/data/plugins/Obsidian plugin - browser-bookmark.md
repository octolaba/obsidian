# Browser Bookmark

Browser Bookmark keeps a persistent bookmarks sidebar whose saved links open in Obsidian's built-in Web Viewer rather than an external browser. Bookmarks are organized in nested folders with drag-and-drop and search, links can be dragged in from notes, favorites can be pinned to an icon row, and the system browser is used if Web Viewer is unavailable.
