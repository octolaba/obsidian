# Cornell Marginalia

Cornell Marginalia renders Cornell-style margin cues written with a comment-based marker syntax, keeping the main text clean while side notes appear alongside it for active recall. Semantic prefixes are color-coded, aligned blocks can be grouped into callouts or block marginalia, and the margin notes are interactive in Reading view.

```cue
plugin: {
    id:     "cornell-marginalia"
    name:   "Cornell Marginalia"
    author: "Latazadehomero"
    repo:   "latazadehomero/cornell-marginalia"

    html_url:    "https://community.obsidian.md/plugins/cornell-marginalia"
    github_url:  "https://github.com/latazadehomero/cornell-marginalia"
    description: "Renders Cornell-style marginal notes using the %%> ... %% syntax. Keeps your notes clean for flashcards and export. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render Cornell-style margin cues using %%> and %%< syntax to keep main text clean and present side-notes for active recall. Color-code semantic prefixes, group aligned blocks into callouts or block marginalia, and interact with margin notes in Reading View."

    stats: {

    }
}
```
