# Image Size

Sets a default size for images pasted into notes so that embeds stay consistent. Pasted images can be saved to a chosen folder and inserted with relative paths suited to Hugo-style blogs.

```cue
plugin: {
    id:     "image-size"
    name:   "Image Size"
    author: "cynicalight"
    repo:   "cynicalight/obsidian-image-size"

    html_url:    "https://community.obsidian.md/plugins/image-size"
    github_url:  "https://github.com/cynicalight/obsidian-image-size"
    description: "Set the default size for pasted images."
```
