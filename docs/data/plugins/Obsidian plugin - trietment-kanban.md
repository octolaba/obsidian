# Trietment Kanban

Collects the Markdown checkbox tasks from across the vault onto a Kanban board of draggable cards. Tasks group by a project tag and carry due dates, recurrence, priorities and subtasks with a progress badge. A card can link to or create a note, and today's and overdue tasks move automatically.
