# AI Co-Editor

Co-edits a note with an AI collaborator that proposes changes shown inline as tracked changes, with struck deletions and green insertions. Edits are reviewed and accepted or rejected word by word from a side-panel chat or a per-change dialog, and the recorded description also lists chat, comments, per-word attribution, and snapshots.
