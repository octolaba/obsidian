# WikiFlash

Flashes the brackets of a wikilink briefly when a link is created or the cursor moves inside one, in the manner of an editor's brace-match cue. The flash is a momentary colour pop that leaves the note content untouched, and its colour, opacity, duration and corner radius are adjustable. It respects the system reduce-motion setting, offers a test flash, and works in Live Preview, Source mode and pop-out windows.
