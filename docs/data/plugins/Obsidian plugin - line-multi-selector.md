# line-multi-selector

Implements multi-line selection through the line-number gutter: click, drag, Shift-click for contiguous ranges, and Ctrl or Cmd click to toggle individual lines. Selection sets can be appended and remembered, which is how non-contiguous multi-line selections are built and preserved. The recorded description notes that the plugin has not been manually reviewed by Obsidian staff.
