# Raindrop Highlights

This plugin syncs Raindrop.io highlights and annotations into the vault, preserving nested collections and bookmark deletions. Notes are updated by appending or overwriting highlights, and file content, frontmatter and filenames are shaped with Nunjucks templates. Syncs can also run automatically at a scheduled interval.

```cue
plugin: {
    id:     "obsidian-raindrop-highlights"
    name:   "Raindrop Highlights"
    author: "kaiiiz"
    repo:   "kaiiiz/obsidian-raindrop-highlights-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-raindrop-highlights"
```
