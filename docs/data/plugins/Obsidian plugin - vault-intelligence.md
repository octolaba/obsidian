# Vault Intelligence

Runs AI agents that look for gaps in the vault, audit and unify tags, and retrieve context from similarity and from explicit links through Graph RAG. Outdated notes can be refreshed with live web searches. The recorded About states that the agents run locally, with optional offline models, so that data does not leave the device.
