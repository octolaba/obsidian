# Codeian

Opens a Codex panel in the right sidebar that runs prompts against a local Codex CLI and streams the responses into a compact conversation view. The model and reasoning effort are selectable, and the characters slash, dollar and at sign invoke local CLI commands, skills and vault files from within a prompt. Answers render as Markdown or are written back into the vault.
