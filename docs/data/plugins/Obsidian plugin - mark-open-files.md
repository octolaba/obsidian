# Mark Open Files

Mark Open Files extends the File Explorer by adding a marker to every item that is currently open in the workspace, with one marker per open instance. Clicking a marker activates the corresponding tab. Markers can be placed before or after the filename, or aligned to the left or right of the explorer.
