# Repeat

Repeat schedules note reviews inside Obsidian using periodic or spaced repetition. A note joins the rotation by carrying a repeat frontmatter property, due items appear in the Repeat view, and the next review is scheduled by an interval or spaced algorithm. The recorded text also lists hidden content, evening reviews and tag or Dataview filtering, with all repetition state kept in each note's frontmatter.
