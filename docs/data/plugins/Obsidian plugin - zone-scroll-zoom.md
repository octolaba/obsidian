# Zone Scroll Zoom

Zone Scroll Zoom scales Obsidian by mouse zone through keyboard shortcuts: the editor font is zoomed when the cursor sits in the editor area, and the entire interface is zoomed when the cursor sits outside it. A live on-screen indicator reports the current scale, and font and interface zoom can be reset to their defaults from the settings.

```cue
plugin: {
    id:     "zone-scroll-zoom"
    name:   "Zone Scroll Zoom"
    author: "kqint"
    repo:   "kqint/obsidian-zone-scroll-zoom"

    html_url:    "https://community.obsidian.md/plugins/zone-scroll-zoom"
    github_url:  "https://github.com/kqint/obsidian-zone-scroll-zoom"
    description: "Zoom where your mouse is — font in editor, interface elsewhere. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Scale Obsidian by mouse zone using keyboard shortcuts: zoom editor font when the cursor is in the editor area and zoom the entire interface when the cursor is outside. Display a live on-screen indicator of the current scale and reset font/interface zoom back to defaults from settings."
```
