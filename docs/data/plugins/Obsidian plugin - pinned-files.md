# Pinned Files

Pinned Files collects pinned files in a compact sidebar view for one-click access, with drag-and-drop reordering. Pinned items are marked by subtle indicators in the File Explorer and can be opened in a new tab with a modifier click. The recorded inputs state that renamed or deleted files and Sync updates are handled by the plugin.

```cue
plugin: {
    id:     "pinned-files"
    name:   "Pinned Files"
    author: "Matt Maiorana"
    repo:   "mattmaiorana/pinned-files"

    html_url:    "https://community.obsidian.md/plugins/pinned-files"
    github_url:  "https://github.com/mattmaiorana/pinned-files"
    description: "Pin files for quick access in a simple sidebar view. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Pin files to a compact Pinned Files sidebar for one-click access and drag-and-drop reordering. See subtle pin indicators in the File Explorer, open pins in new tabs with Cmd/Ctrl-click, and let the plugin handle renamed/deleted files and Sync updates."
```
