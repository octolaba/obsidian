# GitHobs

Uses Obsidian as an editor for GitHub issues, with a sidebar and a note-based workflow that tracks each issue by its number. Issue edits are submitted and the repository updated through Git operations such as fetch, pull and push.

```cue
plugin: {
    id:     "githobs"
    name:   "GitHobs"
    author: "gabalpha"
    repo:   "gabalpha/obsidian-githobs"

    html_url:    "https://community.obsidian.md/plugins/githobs"
    github_url:  "https://github.com/gabalpha/obsidian-githobs"
    description: "Use Obsidian as Github issue editor with logic taken from Git"
    about:       "Edit and create GitHub issues directly from Obsidian using a dedicated sidebar and note-based workflow, tracking issues by number. Sync changes with Git operations like fetch, pull and push to update the repository and submit issue edits."
```
