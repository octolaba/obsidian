# Codex Usage

Codex Usage displays CodexBar-style AI coding usage and cost in a compact status-bar item and an expandable dashboard covering session and weekly usage, account and cost data, cache age, helper information, warnings and raw output. The last snapshot is stored locally for an instant start, and the managed helpers run on demand behind an explicit install step and SHA-256 checks.
