# Table Extended

Renders tables in MultiMarkdown 6 syntax, adding colspan and rowspan, multiple headers, captions, omitted headers and block-level cell content while internal links and embeds keep working. The recorded About text states that an extended table is marked with a -tx- prefix to enable the syntax.

plugin: {
    id:     "table-extended"
    name:   "Table Extended"
    author: "Aiden Liu"
    repo:   "aidenlx/table-extended"

    html_url:    "https://community.obsidian.md/plugins/table-extended"
    github_url:  "https://github.com/aidenlx/table-extended"
