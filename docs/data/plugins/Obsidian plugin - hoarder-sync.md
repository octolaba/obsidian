# Karakeep Sync

Karakeep Sync imports Karakeep bookmarks into Obsidian as Markdown notes, including their metadata and bookmark images, which are saved into an attachments folder. Changed bookmarks create or update their notes automatically and deletions are mirrored. Notes can optionally be synced back to Karakeep.

    id:     "hoarder-sync"
    name:   "Karakeep Sync"
