# Global Book Search

Searches Google Books, OpenLibrary, Goodreads, StoryGraph and local Calibre libraries and merges the results into a single deduplicated book note. Results are combined with prioritized scoring and resilient scraping that captures translators, editions, JSON-LD data and information read from QR or barcodes.
