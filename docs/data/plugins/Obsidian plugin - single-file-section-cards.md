# Single File Section Cards

Displays the subsections of a note as a wall of cards, one card per heading, each editable in place with changes written back to the source Markdown file. Sections can be added, deleted and reordered graphically, and cards can be viewed by heading level under several sort orders. Custom layouts are supported, and any file using standard Markdown headings works.

```cue
plugin: {
    id:     "single-file-section-cards"
    name:   "Single File Section Cards"
    author: "JORDAN LONG"
    repo:   "jordanlong121/singlefilesectioncards"

    github_url:  "https://github.com/jordanlong121/singlefilesectioncards"
    description: "View any note's subsections as a set of cards. Edit, reorder, add and delete document sections graphically. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display a note's subsections as a wall of editable cards — one card per heading — and edit any section in-place with changes written back to the source Markdown file. Edit, reorder, add delete sections from your document graphically. View cards by heading level and various sort orderings. Create custom layouts. Works for any file that uses standard markdown headings. Ideal for daily notes, meeting notes, task management, sticky notes, and brain-storming."
```
