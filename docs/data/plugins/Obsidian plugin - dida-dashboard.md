# Dida Dashboard

Embeds a Dida365 task dashboard in Obsidian using a Dida365 Open API token, so tasks are shown without being synced into Markdown. All, Today, Next 7 Days, Inbox and project views group active tasks by overdue, today, tomorrow, next seven days, future and no date, with tags, project name and due time. Tasks are added, completed, rescheduled or deleted, and the view is refreshed manually.

```cue

    id:     "dida-dashboard"
    name:   "Dida Dashboard"
    author: "Ayanami"
    repo:   "wdlin233/obsidian-dida-dashbord"

    html_url:    "https://community.obsidian.md/plugins/dida-dashboard"
    github_url:  "https://github.com/wdlin233/obsidian-dida-dashbord"
    description: "Show Dida365/TickTick tasks inside Obsidian without syncing them into Markdown. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed a Dida365 task dashboard in Obsidian and connect using your Dida365 Open API token. Open All, Today, Next 7 Days, Inbox and project views to see active tasks grouped by overdue, today, tomorrow, next 7 days, future and no date with tags, project name and due time; add, complete, change dates or delete tasks and refresh manually."
```
