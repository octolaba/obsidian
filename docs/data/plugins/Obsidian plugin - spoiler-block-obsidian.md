# Spoiler Block

Text placed inside a spoiler block stays hidden until the reader chooses to see it. Content is revealed by hovering or clicking and hidden again with a double click, and it is displayed as plain text.

```cue
plugin: {
    id:     "spoiler-block-obsidian"
    name:   "Spoiler Block"
    author: "alljavi"
    repo:   "alljavi/spoiler-block-obsidian"

    html_url:    "https://community.obsidian.md/plugins/spoiler-block-obsidian"
    github_url:  "https://github.com/alljavi/spoiler-block-obsidian"
    description: "Hide information until you want to reveal it."
    about:       "Hide spoiler or sensitive text inside blocks until you're ready to reveal it. Reveal content by hovering or clicking, and hide it again with a double-click; content displays as plain text."
```
