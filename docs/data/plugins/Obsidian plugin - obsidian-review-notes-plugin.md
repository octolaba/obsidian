# Review Notes Plugin

This plugin shows recently modified and newly created files together in a single review list. Entries can be sorted by file name in either direction, and the whole list can be cleared. The recorded text notes that clearing is irreversible.

```cue
plugin: {
    id:     "obsidian-review-notes-plugin"
    name:   "Review Notes Plugin"
    author: "tjandy98"
    repo:   "tjandy98/obsidian-review-notes-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-review-notes-plugin"
    github_url:  "https://github.com/tjandy98/obsidian-review-notes-plugin"
    description: "Show recently modified and newly created files."
    about:       "Show newly created and recently updated files in a single review list. Sort entries by file name (A–Z or Z–A) and clear the entire list when needed — clearing is irreversible."

    stats: {
        downloads:  6271
        updated_at: 1707392382000
    }
}
```
