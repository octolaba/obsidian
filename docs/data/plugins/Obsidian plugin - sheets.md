# Sheets Extended

Sheets Extended extends Markdown tables with merged cells, vertical headers and custom CSS-driven styles. Cells merge leftward and upward through single-character markers, a column of dashes turns a table into one with vertical headers, and classes assigned through sheet metadata style individual cells, rows or headers. It is compatible with Advanced Tables.
