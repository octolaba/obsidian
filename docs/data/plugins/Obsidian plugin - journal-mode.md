# Journal Mode

Journal Mode styles notes with animated text, color accents and washi-tape-like dividers, written as minimal inline markup that stays readable in raw Markdown. The effects apply in edit and preview, on desktop and on mobile, and tags such as rainbow and sparkle can be combined. The styles are adjustable with plain CSS.

    id:     "journal-mode"
