# Mathematica Plot

Mathematica Plot renders 2D and 3D graphs from Wolfram Mathematica code written in a note. Graphs can be previewed and edited while writing, several plots can be rendered in sequence, and image files with wikilinks are created through wolframscript.

```cue
plugin: {
    id:     "mathematica-plot"
    name:   "Mathematica Plot"
    author: "marcosnicolau"
    repo:   "marcosnicolau/obsidian-mathematica-plot"

    html_url:    "https://community.obsidian.md/plugins/mathematica-plot"
    github_url:  "https://github.com/marcosnicolau/obsidian-mathematica-plot"
    description: "Render graphs using Wolfram Mathematica code."
    about:       "Plot 2D and 3D mathematical graphs using Wolfram Mathematica code directly in Obsidian. Preview and edit graphs while writing, render multiple plots in sequence, and create image files with wikilinks via wolframscript."

    stats: {
        downloads:  3058
        updated_at: 1702841713000
    }
}
```
