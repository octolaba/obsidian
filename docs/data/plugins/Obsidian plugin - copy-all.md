# Copy All

Copy All copies the entire contents of the active note to the clipboard as Markdown. The filename, without its .md extension, can be prepended as a top-level heading, and the command can be assigned to the mobile pull-down for one-tap access.

```cue
plugin: {
    id:     "copy-all"
    name:   "Copy All"
    author: "eliasfloreteng"
    repo:   "eliasfloreteng/obsidian-copy-all"

    html_url:    "https://community.obsidian.md/plugins/copy-all"
    github_url:  "https://github.com/eliasfloreteng/obsidian-copy-all"
    description: "Copy all the text in the current file as Markdown. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Copy the entire contents of the active note to the clipboard as Markdown. Prepend the filename (without .md) as a top-level # heading when needed and assign the command to the mobile pull-down for one-tap access."

    stats: {
        downloads:  115
        updated_at: 1774517031000
    }
}
```
