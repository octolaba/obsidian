# Cluddle Callouts

Opens a searchable picker of built-in and CSS-defined custom callouts from the editor's right-click menu or from a command, with the callout options colored. From the picker a callout is previewed and inserted, a selection wrapped, an existing callout's type changed or the callout removed in place, so callout ids need not be remembered and block syntax need not be rewritten.

plugin: {
    id:     "cluddle-callouts"
