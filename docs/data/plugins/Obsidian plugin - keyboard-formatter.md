# Keyboard Formatter

Formats selected text into semantic kbd tags that represent keyboard and mouse input. A shortcut converts modifiers such as Ctrl, Shift, Alt, Cmd and Win, together with function keys, arrows, numpad keys and mouse buttons, into consistent symbols. Names are recognized case-insensitively, single-letter keys are capitalized, and light and dark display styles are included.
