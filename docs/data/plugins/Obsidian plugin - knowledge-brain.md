# Knowledge Brain

Turns Markdown notes into a directed acyclic graph expressed in YAML frontmatter, leaving the notes themselves plain and portable. Connections can be inspected and edited in an interactive graph. A streaming chat suggests tags, statuses, links and follow-up questions, or creates new notes from its answers, and vault search runs on local BM25 without embeddings. DeepSeek, OpenAI, Gemini and Claude are the named model providers.

}
