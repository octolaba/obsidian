# Checklist Reset

Checklist Reset adds commands that reset the state of every checklist in the current Markdown or Canvas file, unchecking or checking all items. Selected checklist items can be reset in editor mode, and matching text can optionally be stripped from checklist lines during a reset to remove item metadata.

```cue
plugin: {
    id:     "obsidian-checklist-reset"
    name:   "Checklist Reset"
    author: "lhansford"
    repo:   "lhansford/obsidian-checklist-reset"

    html_url:    "https://community.obsidian.md/plugins/obsidian-checklist-reset"
    github_url:  "https://github.com/lhansford/obsidian-checklist-reset"
```
