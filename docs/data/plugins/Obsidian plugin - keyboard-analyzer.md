# Keyboard Analyzer

Visualizes and searches Obsidian hotkeys on an interactive keyboard layout, making duplicates, conflicts and unassigned keys visible. Bindings can be filtered by scope, and system or editor defaults can be overlaid to avoid clashing with common shortcuts. A quick commands popup lists bindings and runs them.

plugin: {
    id:     "keyboard-analyzer"
    name:   "Keyboard Analyzer"
    author: "noname-oni"
    repo:   "noname-oni/obsidian-keyboard-analyzer"

    html_url:    "https://community.obsidian.md/plugins/keyboard-analyzer"

    about:       "Visualize and search Obsidian hotkeys on an interactive keyboard layout to spot duplicates, conflicts, and unassigned keys. Filter by scope and optionally overlay system/editor defaults to avoid common shortcuts. Open a quick commands popup to view and run bindings."
