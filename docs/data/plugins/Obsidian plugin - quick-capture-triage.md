# Quick Capture Triage

Adds a sidebar panel for triaging the notes that the Obsidian Inbox server has synced into the vault's inbox folder. Saving strips the inbox tag and moves the note to the organized folder, while discarding sends it to Obsidian's trash. The recorded About states that it works only on local files, with no network and no git access.

plugin: {
    id:     "quick-capture-triage"
    name:   "Quick Capture Triage"
    author: "hazel"
    repo:   "ghh-l-djl/obsidian-quick-capture-triage"

    html_url:    "https://community.obsidian.md/plugins/quick-capture-triage"
    github_url:  "https://github.com/ghh-l-djl/obsidian-quick-capture-triage"
    description: "Clear out notes captured by the obsidian-inbox self-hosted pipeline: keep or discard each pending inbox note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add a sidebar panel to triage notes synced into your vault's inbox folder by the Obsidian Inbox server. Save (保存) to strip the inbox tag and move notes to your organized folder, or Discard (丢弃) to send notes to Obsidian's trash; work only on local files with no network or git access."
