# Fold Properties

Adds a fold and unfold properties action to the file and folder context menu. The action collapses or expands a file's properties, applied to the current file or to every file in a selected folder.

```cue
plugin: {
    id:     "fold-properties"
    name:   "Fold Properties"
    author: "James Alexandre"
    repo:   "itsonlyjames/obsidian-fold-properties"

    html_url:    "https://community.obsidian.md/plugins/fold-properties"
    github_url:  "https://github.com/itsonlyjames/obsidian-fold-properties"
    description: "Adds fold/unfold properties function to folder and file context menu."
    about:       "Add a Fold/Unfold Properties button to the file context menu to quickly collapse or expand a file's properties. Apply the action to the current file or to all files in a selected folder for fast, batch folding."

    stats: {
        downloads:  4714
        updated_at: 1778627404000
    }
}
```
