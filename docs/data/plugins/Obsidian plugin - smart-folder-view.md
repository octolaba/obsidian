# Smart Folder View

Smart Folder View turns a folder of notes into an interactive dashboard with timeline and board layouts, draggable cards and filters based on note metadata. Pages and presets can be saved and reused, stable colors mapped from a chosen field, manual ordering and page state persisted, and the last drag undone. Page definitions can be exported back into the vault.
