# Skim Highlights

Skim Highlights polls Skim for new highlights and copies them automatically to the clipboard for pasting into any note. Pasted highlights become formatted quote cards carrying a page reference and a clickable link that jumps back to the original spot in the PDF in Skim.

```cue
plugin: {
    id:     "skim-highlights"
    name:   "Skim Highlights"
    author: "xuxiaominger2024"
    repo:   "xuxiaominger/obsidian-skim-highlights"

    html_url:    "https://community.obsidian.md/plugins/skim-highlights"
    github_url:  "https://github.com/xuxiaominger/obsidian-skim-highlights"
    description: "Skim高亮自动复制到剪贴板，粘贴到Obsidian任意笔记，点击链接跳回PDF原文 - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Poll Skim for new highlights and automatically copy them to the clipboard for instant pasting into any Obsidian note. Create formatted quote cards with page references and clickable links that jump back to the original spot in Skim."

    stats: {
        downloads:  34
        updated_at: 1784979329000
    }
}
```
