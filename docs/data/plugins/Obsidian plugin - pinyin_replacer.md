# Pinyin Replacer

Pinyin Replacer writes pinyin tone marks without installing an extra keyboard layout. Commands replace the vowel under the cursor with its tone-marked form or strip the tone again, the letter v stands in for the u-umlaut variants, and a status-bar reminder shows the tone order.

```cue
plugin: {
    id:     "pinyin_replacer"
    name:   "Pinyin Replacer"
    author: "larrysal"
    repo:   "larrysal/pinyin-replacer"

    html_url:    "https://community.obsidian.md/plugins/pinyin_replacer"
    github_url:  "https://github.com/larrysal/pinyin-replacer"
    description: "Use the Pinyin tones without having to install extra keyboard layouts."
    about:       "Replace the vowel under the cursor with its pinyin tone mark or strip tones via quick commands. Use v for ǖ/ǘ/ǚ/ǜ variants and read the status-bar reminder for tone order."

    stats: {
        downloads:  1850
        updated_at: 1712082172000
    }
}
```
