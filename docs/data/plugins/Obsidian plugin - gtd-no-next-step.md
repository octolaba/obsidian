# GTD No Next Step

Marks Getting Things Done project files that have no defined next step with a red badge, and projects waiting on an external trigger with a gray badge. Project folders and their subfolders are scanned for task lines tagged as next-step or waiting-for, and the badges show which projects need attention.

```cue
plugin: {
    id:     "gtd-no-next-step"
    name:   "GTD No Next Step"
    author: "saibotsivad"
    repo:   "saibotsivad/obsidian-gtd-no-next-step"

    html_url:    "https://community.obsidian.md/plugins/gtd-no-next-step"
    github_url:  "https://github.com/saibotsivad/obsidian-gtd-no-next-step"
    description: "Add a badge to Getting Things Done (GTD) \"project\" files with no defined next step."
    about:       "Mark project files that lack a defined next actionable step with a red badge, and mark projects waiting on external triggers with a gray badge. Scan project folders and subfolders for task lines tagged #next-step or #waiting-for and display badges to highlight projects needing attention."

    stats: {
        downloads:  4652
        updated_at: 1703020257000
    }
}
```
