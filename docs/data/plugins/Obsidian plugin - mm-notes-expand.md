# MM Notes Expand

Adds click behavior to text-based nodes on a canvas: a single click opens an overlay showing the node's full content regardless of the size of the node itself, and a double click opens the note in a new tab for editing. Each behavior can be turned on or off independently and adjusted, for instance by resizing the overlay or keeping nodes read-only.
