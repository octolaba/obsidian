# Markdown to WeChat MP Sync

Syncs a Markdown note to WeChat Official Account drafts in one click, converting it to inline-styled HTML and uploading local images to the WeChat CDN. A sidebar previews the mobile layout, the first image is extracted as the cover, and built-in or custom CSS themes are applied. Styled rich text is copied out, and Markdown footnotes are converted into WeChat-friendly references.
