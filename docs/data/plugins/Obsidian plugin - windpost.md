# WindPost

Publishes the current note from a local vault to a blog or as a WeChat Official Account draft, converting one Markdown file into channel-specific content. Channel output can be previewed, and pre-publish checks and confirmations run before anything leaves the vault. Publishing then runs as a Git push or a platform API call and the result is recorded, with Obsidian remaining the single source of truth.
