# Todoist Review

Todoist Review provides a pane for reviewing overdue tasks from Todoist without leaving Obsidian. The overdue tasks are displayed in a code block so they can be triaged and decided on quickly.

```cue
plugin: {
    id:     "todoist-review"
    name:   "Todoist Review"
    author: "imcauley"
    repo:   "imcauley/todoist-review"

    html_url:    "https://community.obsidian.md/plugins/todoist-review"
    github_url:  "https://github.com/imcauley/todoist-review"
    description: "A pane for reviewing overdue tasks from todoist"
    about:       "Review and triage overdue Todoist tasks from within Obsidian. Display overdue tasks in a code block for quick processing and decision-making."

    stats: {
        downloads:  1461
        updated_at: 1709087446000
    }
}
```
