# Git Url

Creates a URL pointing at the current file in its Git remote so the note can be opened in a browser. Note content can also be copied with embedded image and attachment links rewritten to public remote addresses, so the Markdown renders on external sites. GitLab is supported and a custom remote base URL can be supplied.

```cue
plugin: {
    id:     "git-url"
    name:   "Git Url"
    author: "khuongduy354"
    repo:   "khuongduy354/obsidian-git-url"

    html_url:    "https://community.obsidian.md/plugins/git-url"
    github_url:  "https://github.com/khuongduy354/obsidian-git-url"
    description: "Create a url to your file on your git remote repo."
    about:       "Copy file URLs that point to your repository or custom cloud storage to open notes directly in a browser. Copy note content with embedded image and attachment links rewritten to public remote URLs so markdown renders on external sites. Use GitLab or provide a custom remote base URL."

    stats: {
        downloads:  3932
        updated_at: 1712550256000
    }
}
```
