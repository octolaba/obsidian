# Bible linker Pro

Bible linker Pro converts Bible references written in short or long form into JW Library links that open directly from a note. The link output format is configurable, the current verse can be captured automatically, a preferred Bible edition and language chosen, and links opened automatically, while the note text itself is left unaltered.

```cue
plugin: {
    id:     "bible-linker-pro"
    name:   "Bible linker Pro"
    author: "floydv149"
    repo:   "floydv149/bibleLinkerPro"

    html_url:    "https://community.obsidian.md/plugins/bible-linker-pro"
    github_url:  "https://github.com/floydv149/bibleLinkerPro"
    description: "Converts Bible texts to JW Library links"
    about:       "Convert short or long Bible references (e.g., \"ge 1:1\" or \"Genesis 1:1\") into JW Library links that open directly from your notes without altering them. Format link output, auto-capture the current verse, choose preferred Bible edition and language, and open links automatically."

    stats: {
        downloads:  2933
        updated_at: 1743768242000
    }
}
```
