# Typing speed

Shows the current typing speed in the status bar as feedback while writing. The unit switches between characters per second, characters per minute and words per minute.

```cue
plugin: {
    id:     "typing-speed"
    name:   "Typing speed"
    author: "supercip971"
    repo:   "supercip971/obsidian-typing-speed"

    html_url:    "https://community.obsidian.md/plugins/typing-speed"
    github_url:  "https://github.com/supercip971/obsidian-typing-speed"
    description: "Show the current typing speed in the status bar."
    about:       "Display current typing speed in the status bar. Switch the display between cps (characters/sec), cpm (characters/min) or wpm (words/min) for real-time feedback while you type."

        downloads:  13280
```
