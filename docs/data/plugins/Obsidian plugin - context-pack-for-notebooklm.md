# AI Context Pack

AI Context Pack generates AI Briefs, AI MOCs, Context Packs, Knowledge Books and Notion Workspaces from the notes in a vault. The generated material is intended to prepare vault knowledge for assistants such as ChatGPT, Claude, Gemini, NotebookLM and Claude Code.
