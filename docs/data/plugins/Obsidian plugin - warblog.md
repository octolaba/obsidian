# WarBlog

WarBlog edits Astro blog content as .mdx files inside a designated vault folder. A single command publishes the changes by committing and pushing them to the site's git repository, guarded by a password.

```cue
plugin: {
    id:     "warblog"
    name:   "WarBlog"
    author: "wrsrsh"
    repo:   "wrsrsh/warblog"

    html_url:    "https://community.obsidian.md/plugins/warblog"
    github_url:  "https://github.com/wrsrsh/warblog"
    description: "A simple plugin to manage your Astro blog content files. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Edit Astro blog posts as .mdx files directly in Obsidian within a designated vault folder. Publish changes with a single command that commits and pushes updates to your site's git repository, protected by a password."

    stats: {
        downloads:  83
        updated_at: 1771301247000
    }
}
```
