# Four Layer Todo

Lays out a four-layer task workflow in a full-page workspace built around a whiteboard, a cache workbench, an inbox, todo and cache lists, and a Kanban-style task reservoir. Task pools are added and cards moved with a jump-then-choose flow, alongside a view of long-term objects. An optional two-way Markdown sync stores cards as editable files with frontmatter.
