# Neighbourhood Graph

Draws the active note's neighbourhood as an interactive force-directed graph in the right sidebar, built with D3.js according to the recorded description. The focus note is highlighted alongside related notes, shared tags shown as diamond nodes, and backlinks. Hovering highlights direct and depth-2 connections, clicking recenters the graph and double-clicking opens a note.

```cue
plugin: {
    id:     "neighbourhood-graph"
    name:   "Neighbourhood Graph"
    author: "agilesmagile"
    repo:   "agilesmagile/obsidian-neighbourhood-graph"

    html_url:    "https://community.obsidian.md/plugins/neighbourhood-graph"
    github_url:  "https://github.com/agilesmagile/obsidian-neighbourhood-graph"
    description: "Interactive D3.js force-directed graph showing the current note's neighbourhood in a sidebar panel. Nodes connected by shared tags and backlinks. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Visualize the active note's neighbourhood as an interactive force-directed graph in the right sidebar, highlighting the focus note and showing related notes, shared tags (diamond nodes), and backlinks. Hover to highlight direct and depth‑2 connections; click to recenter and double‑click to open a note."
```
