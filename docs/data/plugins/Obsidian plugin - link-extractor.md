# Link Extractor

Scans the current note for external http and https links and copies them as a deduplicated list. Markdown links, bare URLs, and angle-bracket links are all detected, and the list can be exported as plain text, bullets, numbers, or Markdown links with one-click copying to the clipboard. The recorded description notes that the plugin has not been manually reviewed by Obsidian staff.
