# Incremental Reading Toolkit

Processes long-form reading into scheduled topics, extracts and Spaced Repetition flashcards. Readings are queued and prioritized with A-Factor topic spacing and PDF navigation, passages from PDFs, notes or images become linked extracts, and flashcards are exported as markdown. Sioyek integration is desktop-only, and the recorded inputs name the Spaced Repetition plugin as a dependency.

    id:     "incremental-reading-toolkit"
