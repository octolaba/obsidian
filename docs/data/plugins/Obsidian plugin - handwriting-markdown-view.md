# Handwriting Markdown View

Adds a vector handwriting annotation layer over rendered Markdown, separating pen from touch input and capturing pressure, tilt and smoothed strokes, with pen, highlighter, move and erase tools. Strokes are auto-saved per note as JSON with a generated SVG preview. Ink is re-anchored to Markdown blocks when the text changes.
