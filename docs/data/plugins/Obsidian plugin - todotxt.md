# TodoTxt

TodoTxt manages todotxt files inside Obsidian with native todo.txt parsing and a TODOTXT badge that identifies them. Due dates are highlighted with color alerts and threshold dates respected, while experimental options preserve priorities on completion and create recurring tasks from recurrence tags.

```cue
plugin: {
    id:     "todotxt"
    name:   "TodoTxt"
    author: "mvgrimes"
    repo:   "mvgrimes/obsidian-todotxt-plugin"

    html_url:    "https://community.obsidian.md/plugins/todotxt"
    github_url:  "https://github.com/mvgrimes/obsidian-todotxt-plugin"
    description: "Manage Todo.txt files."
    about:       "Manage .todotxt files inside Obsidian with native todo.txt parsing and a TODOTXT badge for quick identification. Highlight due:yyyy-mm-dd dates with color alerts, respect t:YYYY-MM-DD thresholds, preserve priorities on completion (experimental), and create recurring tasks from rec: tags (experimental)."
```
