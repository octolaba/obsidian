# Canvas Toolkit

Canvas Toolkit adds customization controls to Obsidian Canvas: editable labels for cards, text cards turned into sticky notes, and groups displayed as solid boards. Appearances can be switched across an entire Canvas, default styles set for new cards and groups, and groups added from the Canvas toolbar. The same controls are available on desktop and mobile.
