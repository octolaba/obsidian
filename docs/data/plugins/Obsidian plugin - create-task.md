# Create Task

Create Task opens a guided modal that walks through a task's description, details, due date and target note. Tasks can be saved into several target notes at once and carry appended tags for board-based workflows. The modal opens from the command palette, the ribbon or an Obsidian URI, and due dates accept natural language with configurable output formats.
