# Line Ending Controller

Controls the line ending format, LF or CRLF, per file or per folder, and can fix endings on save or open so Obsidian does not silently convert CRLF to LF and produce unexpected Git diffs. The current file's ending is shown in the status bar, conversions can be run manually on demand, and per-file or per-folder rules apply different strategies across the vault. The recorded description notes that the plugin has not been manually reviewed by Obsidian staff.
