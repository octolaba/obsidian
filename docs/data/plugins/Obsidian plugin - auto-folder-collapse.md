# Auto Folder Collapse

Auto Folder Collapse collapses child folders whenever their parent is collapsed in the file explorer. It can also collapse unrelated folders when one is expanded, producing an accordion-style sidebar focused on the active branch.

```cue
plugin: {
    id:     "auto-folder-collapse"
    name:   "Auto Folder Collapse"
    author: "dariocasciato"
    repo:   "dariocasciato/obsidian-auto-folder-collapse"

    html_url:    "https://community.obsidian.md/plugins/auto-folder-collapse"
    github_url:  "https://github.com/dariocasciato/obsidian-auto-folder-collapse"
    description: "Automatically collapses subfolders when a parent folder is collapsed"
    about:       "Collapse child folders automatically when you collapse a parent to keep the file explorer organized and clutter-free. Create an accordion-style sidebar by collapsing unrelated folders on expand to keep focus on the active branch."

    stats: {
        downloads:  7078

}
```
