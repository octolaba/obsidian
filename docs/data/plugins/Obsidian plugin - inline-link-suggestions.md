# Inline Link Suggestions

Inline Link Suggestions underlines plain-text mentions of existing notes, aliases included, with a subtle dotted line while you write in the editor. Clicking or tapping a suggestion converts it into a wiki link to the title or the alias, and hovering previews the target. Matching runs locally at vault scale, so a link is made without leaving the editor.

    id:     "inline-link-suggestions"
    name:   "Inline Link Suggestions"
