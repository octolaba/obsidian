# Focus Mode Pro

Hides sidebars, ribbons, tabs and status bars, centres the content at an adjustable width and adjusts the font size for reading. A file finder and a Windows-style tab switcher handle navigation while the mode is on. Typewriter mode keeps the cursor centred, and optional acoustic typing ticks give feedback.
