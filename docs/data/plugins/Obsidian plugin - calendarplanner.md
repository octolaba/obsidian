# CalendarPlanner

CalendarPlanner manages tasks and events from a single master planner.md file instead of individual daily notes. Its calendar shows per-day entry previews and lets entries be opened, added, completed or checked off, and multi-day events are created with date ranges. It accepts DD/MM/YYYY or YYYY-MM-DD date formats and can jump directly to any date.
