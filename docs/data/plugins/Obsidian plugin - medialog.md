# MediaLog

Keeps a personal library of movies, TV shows, anime, games and books as local Markdown or JSON files in the vault. A unified card wall with Media, Games and Books tabs holds the entries, and movies are searched and added through TMDB. Status, dates, ratings, platforms and reviews are edited on the cards, while game and book entries are displayed from structured JSON files.
