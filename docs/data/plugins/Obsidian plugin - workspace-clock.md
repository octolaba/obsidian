# Workspace Clock

Places a clock in the left-sidebar header that opens into a pomodoro timer, a stopwatch, or a monthly calendar wired to the daily notes. Timestamps and labeled, time-tracked sessions are dropped into a note in one click. The widget follows the active theme in light or dark, sharp or rounded, and an optional accent override takes a custom color or one of six gradient colorways.

Adopts whatever theme you're using (light or dark, sharp or rounded) Optional accent override in settings takes a custom color or one of six gradient colorways.
