# Tag Lock

Adds a password gate that blocks casual viewing of notes matched by configured privacy tags or folders, without encrypting the Markdown files on disk. Search results, page previews, backlinks and tag-named pages are guarded alongside the notes themselves. The interface is available in Chinese and English, and the unlock behavior is adjustable.
