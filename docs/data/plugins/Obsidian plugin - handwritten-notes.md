# Handwritten Notes

Creates stylus-based handwritten notes saved as PDFs, a format chosen for long-term compatibility and for handling large notebooks smoothly. Those PDFs can be annotated and edited inside the vault and embedded or referenced from Markdown. Editing on mobile requires a compatible external PDF editor.

```cue
plugin: {
    id:     "handwritten-notes"
    name:   "Handwritten Notes"
    author: "fbarrca"
    repo:   "fbarrca/obsidian-handwritten-notes"
```
