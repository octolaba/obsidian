# Timeflow Periodic

Timeflow Periodic presents daily Periodic Notes as an infinite vertical temporal feed ordered newest first, with weekly and monthly cards and period markers. Note cards show the title and a plain-text excerpt, interactive gap cards offer to create the missing days, and older entries load automatically. Changes in the vault are reflected while the feed is open.
