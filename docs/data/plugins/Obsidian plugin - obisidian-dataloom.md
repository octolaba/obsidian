# DataLoom

Creates and manages databases inside the vault with customizable columns, cell types, filters, sorting and several views, drawing on Excel spreadsheets and Notion for its model. Data can be woven together from folders and frontmatter, imported and exported as CSV, Markdown or PDF, and records embedded into notes; it runs on desktop and mobile.
