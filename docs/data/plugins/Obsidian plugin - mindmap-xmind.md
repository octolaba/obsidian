# Mindmap Xmind

Opens .xmind mindmaps inside Obsidian in an interactive mindmap view. Nodes can be added, deleted, collapsed or expanded, and renamed by double-clicking, and new maps are created from the command palette or the file-list context menu. An icon toolbar with a responsive More menu, a minimap, auto-save and export to SVG or PNG are included.
