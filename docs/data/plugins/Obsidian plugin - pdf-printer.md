# PDF Printer

Converts PDF documents in the vault into WEBP images that can be embedded and annotated directly in notes, without external dependencies. Multi-page PDFs are converted in batch, PDF links can be replaced by the page images, and image quality and output folder are configurable.

```cue
plugin: {
    id:     "pdf-printer"
    name:   "PDF Printer"
    author: "cubexy"
    repo:   "cubexy/obsidian-pdf-printer"

    html_url:    "https://community.obsidian.md/plugins/pdf-printer"
    github_url:  "https://github.com/cubexy/obsidian-pdf-printer"
```
