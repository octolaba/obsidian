# Narrative Canvas

Provides a node-based canvas for nonlinear writing, breaking a narrative into scenes, choices, conditions, variables, event frames and character references and connecting them into playable flows. Nodes are dragged, resized, zoomed, searched and navigated with a minimap, and choices, variable writes and simple conditions are previewed at runtime. Character sheets, events and variables have dedicated editors, and projects edit and export in Ink, Yarn and Twee as well as JSON, CSV and Markdown.
