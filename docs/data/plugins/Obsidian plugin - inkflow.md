# Inkflow

Adds a pen-first sidecar canvas beside a Markdown note, capturing pressure-sensitive strokes with coalesced pointer samples, palm rejection and rendering tuned for iPad, Boox and other pen devices. Editable ink is stored in a compact .ink.json sidecar file while a refreshable PNG is embedded in the note itself. Handwriting can be removed in a single action, with cleanup handled automatically.
