# Open in New Tab and Preserve Tabs

Open in New Tab and Preserve Tabs opens files in new tabs while preserving the existing file tabs. An already-open file switches to its tab instead of creating a duplicate, empty tabs are reused, and the active tab is kept when the same file is reopened. The behaviour applies to opens from the explorer, search, recent files and daily notes.
