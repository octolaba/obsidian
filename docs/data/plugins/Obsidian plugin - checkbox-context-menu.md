# Checkbox Context Menu

Checkbox Context Menu adds a right-click menu to task checkboxes for switching between states such as unchecked, done, half-done, deferred, scheduled, important and cancelled, alongside any custom states that are defined. A command cycles through the states, and theme-adaptive colors and glyphs show the current one in the editor, Live Preview and Reading mode. On mobile the menu opens with a long press.
