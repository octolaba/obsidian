# Unhidden

Reveals hidden dot-folders and dotfiles so they appear in the file explorer, in search, in the metadata cache and in Bases. Revealed folders stay current through eager indexing and recursive watchers without modifying any file on disk, new hidden paths are detected, and indexing can be restricted by file type. Reveals and rescans are driven from the command palette, and the plugin is desktop only.
