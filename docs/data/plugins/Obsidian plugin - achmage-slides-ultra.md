# Achmage Slides Ultra 1920 v5

Achmage Slides Ultra renders Markdown notes as layout-aware slide decks at 1920 by 1080 through Marp, with a live preview in a side pane. Grids and balanced columns are selected automatically from headings and lists, and automatic pagination or shrinking keeps slides from overflowing. Decks export as self-contained HTML with bundled fonts for offline playback.
