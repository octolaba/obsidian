# Read Along

Exports Markdown notes or whole folders as self-contained offline HTML pages with clean typography, a clickable table of contents, preserved folder structure, and converted wikilinks, readable in a browser or inside Obsidian. An optional Read Along mode narrates the page sentence by sentence and highlights the sentence being spoken, with a floating player offering play and pause, speed, previous and next sentence, and a progress bar. Read Along uses the reader's own Volcengine TTS API key, while the HTML export works without one.
