# Note Share Image Exporter

Exports notes, selections, or entire folders as PNG, JPG, WebP or PDF while keeping Obsidian's own rendering of Mermaid diagrams, math, code blocks, callouts, metadata and theme styling. Layout, resolution and pagination can be previewed and adjusted, visible or invisible watermarks and author information can be added, and the result is copied or saved.
