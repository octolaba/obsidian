# Click Image to Zoom

Click Image to Zoom opens any image in a note in a full-size zoomable modal. Scrolling zooms, dragging pans, pinch works on mobile, and keyboard controls zoom and close it; the modal works in live preview and in reading view. Zoom can be disabled per note through frontmatter or turned off globally.
