# Icon picker

Icon picker previews the Lucide icon named in a note's icon frontmatter property, in the Properties panel and inline in Source mode, dimming a placeholder when the name is invalid. Clicking the preview or running a command opens a fuzzy-search picker that writes or removes a plain Lucide name, the form the Bases map view reads. It works fully offline.

    id:     "icon-picker"
