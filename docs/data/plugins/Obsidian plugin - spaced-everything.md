# Spaced everything

The SuperMemo 2.0 algorithm is applied across the vault to run a spaced writing practice rather than a flashcard drill. Notes are tagged with contexts that filter the review queue, outcomes are logged as fruitful, unfruitful or ignore, and a command opens the next scheduled item for review.

```cue
plugin: {
    id:     "spaced-everything"
    name:   "Spaced everything"
    author: "zachmueller"
    repo:   "zachmueller/spaced-everything"

    html_url:    "https://community.obsidian.md/plugins/spaced-everything"
    github_url:  "https://github.com/zachmueller/spaced-everything"
    description: "Apply spaced repetition algorithms to everything in your vault."
    about:       "Apply the SuperMemo 2.0 (SM-2) spaced-repetition algorithm to every note to run a Spaced Writing Practice across your vault. Tag notes with contexts to filter review queues, log outcomes (fruitful, unfruitful, ignore) to rate progress, and open the next scheduled item for focused review."

    stats: {

    }
}
```
