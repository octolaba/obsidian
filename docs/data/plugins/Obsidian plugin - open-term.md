# OpenTerm

OpenTerm adds context menu entries that open the right-clicked file or folder in the operating system's terminal. The executables and application names used for each entry are configurable, and entries that are not needed can be disabled.

```cue
plugin: {
    id:     "open-term"
    name:   "OpenTerm"
    author: "daolyap"
    repo:   "daolyap/openterm"

    html_url:    "https://community.obsidian.md/plugins/open-term"
    github_url:  "https://github.com/daolyap/openterm"
    description: "Adds context menu options to open files and folders in a terminal, with configurable executables/apps for each option. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open the currently right-clicked file or folder in your operating system's terminal. Configure terminal executables and application names, and disable options you don't need."

    stats: {
        downloads:  122
        updated_at: 1772715705000
    }
}
```
