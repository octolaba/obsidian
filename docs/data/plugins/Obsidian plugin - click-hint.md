# Click Hint

Labels clickable elements such as links and buttons with keyboard-driven hints, so any of them can be reached without the mouse. The hint characters are configurable, internal and external links are both targets, and partial matches produce visual feedback.

```cue

    id:     "click-hint"
    name:   "Click Hint"
    author: "kbwo"
    repo:   "kbwo/obsidian-click-hint"

    html_url:    "https://community.obsidian.md/plugins/click-hint"
```
