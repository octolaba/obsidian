# Tolino notes Importer

Tolino notes Importer imports notes, bookmarks and text highlights from a Tolino e-reader connected over USB. The annotations of each book are grouped into a single Markdown note, saved into a chosen folder, and tagged.

```cue
plugin: {
    id:     "tolino-notes-import"
    name:   "Tolino notes Importer"
    author: "juergenbr"
    repo:   "juergenbr/obsidian-tolino-notes-import"

    html_url:    "https://community.obsidian.md/plugins/tolino-notes-import"
    github_url:  "https://github.com/juergenbr/obsidian-tolino-notes-import"
    description: "Import notes from a Tolino E-Reader."
    about:       "Import all notes, bookmarks, and text highlights from a Tolino e‑reader over USB into your vault. Group annotations from each book into a single Markdown note, save them to a chosen folder, and apply tags to imported notes."

    stats: {
        downloads:  3556
        updated_at: 1704300165000
    }
}
```
