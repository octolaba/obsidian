# Vault Statistics

A status bar item reports vault statistics: counts of notes, files, attachments, links and words. Clicking the item cycles through the metrics and hovering previews all of them at once.

```cue
plugin: {
    id:     "obsidian-vault-statistics-plugin"
    name:   "Vault Statistics"
    author: "bkyle"
    repo:   "bkyle/obsidian-vault-statistics-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-vault-statistics-plugin"
    github_url:  "https://github.com/bkyle/obsidian-vault-statistics-plugin"
    description: "Status bar item with vault statistics such as number of notes, files, attachments, and links."
    about:       "Display vault statistics in the status bar, showing counts for notes, files, attachments, links, and words. Click the status item to cycle metrics and hover to preview all available statistics."

    stats: {
        downloads:  47684
        updated_at: 1666760473000
    }
}
```
