# Peer Share

Peer Share moves files and folders between Obsidian vaults over WebRTC using PairDrop-compatible peer-to-peer connections. Devices are paired and peers auto-discovered on the same network, with real-time transfer progress, searchable history and optional desktop notifications. The recorded inputs state support for both desktop and mobile.
