# Folder Backlinks

Lets notes link to folders with wiki links ending in a slash and collects every note referencing a folder in a dedicated backlinks sidebar. Folder links are inserted from a fuzzy picker or from file-explorer actions, and clicking one reveals the folder or opens its backlinks. In reading mode these folder links display as resolved.

```cue
plugin: {
    id:     "folder-backlinks"
    name:   "Folder Backlinks"
    author: "Vlad"
    repo:   "vladb-evs/obsidian-folder-backlink"

    html_url:    "https://community.obsidian.md/plugins/folder-backlinks"
    github_url:  "https://github.com/vladb-evs/obsidian-folder-backlink"
    description: "Link to folders from your notes and see which notes reference each folder, just like backlinks for files. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Link to folders with wiki links ending in a slash and view every note that references a folder in a dedicated backlinks sidebar. Insert folder links via a fuzzy picker or file-explorer actions, click links to reveal folders or open their backlinks, and display folder links as resolved in reading mode."

    stats: {
        downloads:  66
        updated_at: 1783569362000
    }
}
```
