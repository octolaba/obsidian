# Mermaid Next

Renders diagrams written in mermaid-next code blocks with the latest Mermaid release rather than the copy bundled with Obsidian. The library is loaded from the jsDelivr CDN with a bundled offline fallback. Diagrams are themed to Obsidian's light or dark color scheme, and any valid Mermaid syntax is supported.

```cue
plugin: {
    id:     "mermaid-next"
    name:   "Mermaid Next"
    author: "Nasser Alansari"
    repo:   "dacrystal/obsidian-mermaid-next-plugin"

    html_url:    "https://community.obsidian.md/plugins/mermaid-next"
    github_url:  "https://github.com/dacrystal/obsidian-mermaid-next-plugin"
    description: "Renders Mermaid diagrams using the latest version, independent of the built-in bundled version. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render Mermaid diagrams using the latest Mermaid release independent of Obsidian's bundled copy. Use mermaid-next code blocks; load from jsDelivr CDN with a bundled offline fallback, auto-theme diagrams to Obsidian's light/dark color scheme, and support all valid Mermaid syntax."

    stats: {
        downloads:  803
        updated_at: 1779487136000
    }
}
```
