# Calculator Pro

Calculator Pro provides a scientific calculator inside Obsidian with LaTeX formatting support and a clean button design. It keeps recent calculations and can copy an equation to the clipboard or insert it into a note as LaTeX.

```cue
plugin: {
    id:     "calculator-pro"
    name:   "Calculator Pro"
    author: "Minh Hoang"
    repo:   "hoangminhcv2000/obsidian-calculator-pro"

    html_url:    "https://community.obsidian.md/plugins/calculator-pro"
    github_url:  "https://github.com/hoangminhcv2000/obsidian-calculator-pro"
    description: "A clean design scientific calculator with LaTeX formatting support. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Calculator Pro lets you do quick calculations directly inside Obsidian. It supports scientific calculations, saves your recent calculations, and lets you copy or insert equations into notes as LaTeX."
```
