# External Link Opener

Chooses how an external link is opened, either through a preferred opener method or through a modal that offers the options for that link. The width and height of the link-opener modal are adjustable.

```cue
plugin: {
    id:     "obsidian-link-opener"
    name:   "External Link Opener"
    author: "zorazrr"
    repo:   "zorazrr/obsidian-link-opener"

    html_url:    "https://community.obsidian.md/plugins/obsidian-link-opener"
    github_url:  "https://github.com/zorazrr/obsidian-link-opener"
    description: "Open external links using a modal or a tab."
    about:       "Choose how to open external links by selecting a preferred opener method or using a modal to pick per-link options. Adjust the link-opener modal's width and height to fit your workspace."

    stats: {
        downloads:  5253
        updated_at: 1669480667000
    }
}
```
