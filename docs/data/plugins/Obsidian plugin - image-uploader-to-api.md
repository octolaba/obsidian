# Image Uploader to API

Uploads images to any API endpoint when they are dragged, dropped or pasted into the editor, then inserts the returned public URL as Markdown. Custom headers and a JSON response path can be configured, several files upload in parallel behind an uploading placeholder, and the handling of PDFs is a setting.

```cue
plugin: {
    id:     "image-uploader-to-api"
    name:   "Image Uploader to API"
    author: "babarot"
    repo:   "babarot/obsidian-image-uploader-to-api"

    html_url:    "https://community.obsidian.md/plugins/image-uploader-to-api"
    github_url:  "https://github.com/babarot/obsidian-image-uploader-to-api"
    description: "Upload images to any API endpoint on drag & drop or paste, and insert the public URL as Markdown. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Upload images to any API endpoint by dragging, dropping, or pasting them into the editor and insert the returned public URLs as Markdown. Add custom headers and JSON response paths, upload multiple files in parallel, show an uploading placeholder, and choose how PDFs are handled."

    stats: {
        downloads:  129
        updated_at: 1770637177000
    }
}
```
