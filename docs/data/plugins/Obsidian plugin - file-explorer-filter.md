# File Explorer Filter

Adds a filter button to the File explorer that switches the view between all folders and one specific top-level folder. Files and folders matching configurable text can also be hidden. The stated purpose is switching context inside a single vault instead of maintaining several notebooks, in the manner of OneNote sections.

```cue
plugin: {
    id:     "file-explorer-filter"
    name:   "File Explorer Filter"
    author: "singularitopian"
    repo:   "summerdawn-ai/obsidian-file-explorer-filter"

    html_url:    "https://community.obsidian.md/plugins/file-explorer-filter"
    github_url:  "https://github.com/summerdawn-ai/obsidian-file-explorer-filter"
```
