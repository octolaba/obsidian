# Dynamic Font Size

Sets the font size of a note's content from a font-size frontmatter property or from an interactive slider. Changes apply in real time with a transition, the current size is shown in the status bar, and the minimum, maximum and default values are configurable.

    id:     "dynamic-font-size"
    name:   "Dynamic Font Size"
    author: "nancyel"
    repo:   "nancyel/obsidian-dynamic-font-size"
