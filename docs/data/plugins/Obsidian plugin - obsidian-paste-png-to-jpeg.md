# Paste image Png to Jpeg

This plugin converts pasted PNG and JPEG images into compressed JPEGs and saves them in an images folder next to the current note. The files are renamed after the current note with a sequence number appended. Compression quality is configurable to control the resulting file size.

```cue
plugin: {
    id:     "obsidian-paste-png-to-jpeg"
    name:   "Paste image Png to Jpeg"
    author: "musug"
    repo:   "musug/obsidian-paste-png-to-jpeg"

    html_url:    "https://community.obsidian.md/plugins/obsidian-paste-png-to-jpeg"
    github_url:  "https://github.com/musug/obsidian-paste-png-to-jpeg"
    description: "Screenshot png to jpeg and compress and rename."
    about:       "Convert pasted PNG and JPEG images to compressed JPEGs and save them in an images folder next to the current note. Rename files to the current note's name with a sequence number (e.g., hello-1.jpeg). Control compression quality to reduce file size."

    stats: {
        downloads:  12358
        updated_at: 1677589928000
    }
}
```
