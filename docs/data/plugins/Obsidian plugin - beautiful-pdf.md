# Beautiful PDF

Exports Markdown notes to styled PDFs with element-level style profiles and page setup. Headings, body text, tables, callouts, embeds and images can each be mapped to fonts, spacing and box presets, and named profiles can be saved and reused. The real PDF can be previewed before export, page breaks inserted and page numbers added; desktop only.
