# HTML V Editor

HTML V Editor edits and previews HTML and HTM files, html-v code blocks and embedded HTML inside the vault. It offers Preview, a visual Edit mode built on HugeRTE, Source editing and Save, alongside Safe, Sandbox and Trusted preview modes. Checklist editing, character insertion and an HTML V Tasks panel collect and update HTML checklist items.
