# StarCloud Studio

Markdown notes are turned into knowledge posters, infographics, interactive HTML or PPTX slides and speech audio using several AI providers and image styles. Outputs are uploaded to Google Drive into organized folders, and HTML slides can be published to GitHub Pages for embedding.
