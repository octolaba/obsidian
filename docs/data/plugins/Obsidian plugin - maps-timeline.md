# Maps Timeline

Maps Timeline displays Google Maps Timeline location history in a dedicated Obsidian pane, combining an interactive map with a clickable timeline of visits, precise GPS tracks, routes and flights. Day, week, month or custom date ranges can be selected, and unlabeled places are resolved through the Places API with local caching. Basemaps come from OpenStreetMap or Google, and the recorded description states that the data stays on the user's machine.
