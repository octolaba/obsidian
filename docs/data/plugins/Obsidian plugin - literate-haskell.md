# Literate Haskell

Integrates literate Haskell files into the vault by treating them like Markdown, so prose and code sit in the same file. The begin and end code markers are hidden inside haskell blocks, which the recorded inputs describe as making Haskell code in a literate file behave like ordinary Haskell source.

```cue
plugin: {
    id:     "literate-haskell"
    name:   "Literate Haskell"
    author: "jajaperson"
    repo:   "jajaperson/obsidian-literate-haskell"

    html_url:    "https://community.obsidian.md/plugins/literate-haskell"
    github_url:  "https://github.com/jajaperson/obsidian-literate-haskell"
    description: "Integrate .lhs files into your PKM."
    about:       "Treat .lhs files like Markdown so prose and code coexist naturally. Hide \\begin{code} and \\end{code} in .haskell blocks so Haskell code in .lhs files behaves like ordinary .hs files."

    stats: {
        downloads:  3597
        updated_at: 1660987230000
    }
}
```
