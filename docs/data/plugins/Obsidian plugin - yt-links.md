# YT links

Cleans YouTube links in notes by removing the leading notification count from the title and stripping or defusing hashtags in it. Timestamped YouTube URLs are rewritten as readable time links. Bare time notations written in a note are turned into links pointing at that note's source video.

```cue
plugin: {
    id:     "yt-links"
    name:   "YT links"
    author: "quietbyday"
    repo:   "quietbyday/obsidian-yt-links"

    html_url:    "https://community.obsidian.md/plugins/yt-links"
    github_url:  "https://github.com/quietbyday/obsidian-yt-links"
    description: "Clean YouTube links and timestamps: strip notification counts, make timestamp URLs readable, and link bare time notations to a note's source video. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Clean YouTube Markdown links by removing leading notification counts and stripping or defusing hashtags from titles. Convert timestamped YouTube URLs into readable time links and turn bare time notations in notes into links to the note's source video."

    stats: {
        downloads:  75
        updated_at: 1785345446000
    }
}
```
