# DocSanctum

Connects Obsidian to a self-hosted DocSanctum backend over MCP to search and read documents that DocSanctum has indexed. Both keyword and natural-language semantic searches are supported, and opening a result fetches the full document into a read-only preview. The backend connection can be tested and the indexed sources queried from the plugin.

```cue
plugin: {
    id:     "doc-sanctum"
    name:   "DocSanctum"
    author: "Sangchul Lee"
    repo:   "docsanctum/doc-sanctum-obsidian"

    html_url:    "https://community.obsidian.md/plugins/doc-sanctum"
    github_url:  "https://github.com/docsanctum/doc-sanctum-obsidian"
    description: "Search and browse your DocSanctum knowledge base from Obsidian via MCP. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Connect Obsidian to a self-hosted DocSanctum backend over MCP to search and read DocSanctum-indexed documents. Perform keyword and natural-language semantic searches, open results to fetch full documents, and view them in a read-only preview. Test the backend connection and query indexed sources."

    stats: {
        downloads:  24
        updated_at: 1785773993000
    }
}
```
