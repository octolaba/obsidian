# Mermaid ELK Renderer

Re-enables the ELK (Eclipse Layout Kernel) layout engine for Mermaid diagrams and applies it per diagram when the code block carries an elk marker comment. Other diagrams keep Mermaid's default rendering, custom classDef styling is preserved, and Obsidian's light and dark color scheme is respected.

```cue
plugin: {
    id:     "mermaid-elk-renderer"
    name:   "Mermaid ELK Renderer"
    author: "smolblackhole"
    repo:   "smolblackhole/mermaid-elk-renderer"

    html_url:    "https://community.obsidian.md/plugins/mermaid-elk-renderer"
    github_url:  "https://github.com/smolblackhole/mermaid-elk-renderer"
    description: "Re-enables the ELK (Eclipse Layout Kernel) renderer for Mermaid diagrams. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Re-enable the ELK layout engine for Mermaid diagrams and apply ELK layouts on a per-diagram basis by adding %% elk %% to the code block. Keep default Mermaid rendering for other diagrams, preserve custom classDef styling, and respect Obsidian's light/dark color scheme."

    stats: {
        downloads:  481
        updated_at: 1783615819000
    }
}
```
