# Smart DayNight switcher

Smart DayNight switcher determines local sunrise and sunset times and switches the Obsidian color scheme between light and dark accordingly. Latitude and longitude are entered in settings and default to London when omitted. Its recorded About text states that the calculation runs locally and no location data is sent.

```cue
plugin: {
    id:     "smart-day-night-switcher"
    name:   "Smart DayNight switcher"
    author: "andrii256"
    repo:   "andrii256/ops_obsidian_smart-day-night-switcher"

    html_url:    "https://community.obsidian.md/plugins/smart-day-night-switcher"
    github_url:  "https://github.com/andrii256/ops_obsidian_smart-day-night-switcher"
    description: "Intelligently determines sunrise and sunset times and automatically switches the color scheme to light or dark mode."
    about:       "Switch Obsidian between light and dark themes automatically based on calculated local sunrise and sunset times. Enter your latitude/longitude (defaults to London if omitted); calculations run locally and no location data is sent."

    stats: {
        downloads:  1096
        updated_at: 1743107558000
    }
}
```
