# Auto-Sort Completed Checkboxes

Auto-Sort Completed Checkboxes moves an item to the bottom of its checkbox list as soon as it is checked, drawing a divider between the unchecked and checked groups. Indented child items travel with their parent, and only the contiguous checkbox block containing the changed item is reordered. It works in Editor and in Reading mode.
