# Calendar for Daily Notes

Calendar for Daily Notes shows daily notes in a calendar beside a collapsible grouped list with six year, month, quarter and week grouping presets, sorting, created-on-day notes and attachments, count badges and a minimum-word filter. Days can carry color tags and per-day custom titles, and zoom and view state are retained. Titles can optionally be generated locally through a gemma3 model on an Ollama server and cached.
