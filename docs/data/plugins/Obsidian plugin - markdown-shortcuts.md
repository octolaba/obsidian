# Markdown shortcuts

Markdown shortcuts inserts common Markdown elements and templates from a command menu opened by a single trigger character. Tables, blocks and formatting snippets can be created this way without recalling the underlying Markdown syntax.

```cue
plugin: {
    id:     "markdown-shortcuts"
    name:   "Markdown shortcuts"
    author: "julesguesnon"
    repo:   "julesguesnon/obsidian-markdown-shortcuts"

    html_url:    "https://community.obsidian.md/plugins/markdown-shortcuts"
    github_url:  "https://github.com/julesguesnon/obsidian-markdown-shortcuts"
    description: "Write Markdown from shortcuts."
    about:       "Insert common Markdown elements and templates using a single trigger character to open a command menu. Create tables, blocks, and formatting snippets without memorizing Markdown syntax."

    stats: {
        downloads:  8529
        updated_at: 1663101115000
    }
}
```
