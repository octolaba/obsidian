# Boardgame Search

The plugin searches BoardGameGeek and imports games into the vault as entries carrying metadata, categories, mechanics and cover images in several resolutions. Play sessions are recorded with players, winners, playtime and notes, and file and image settings are configurable. A BoardGameGeek API key is required to enable the plugin.
