# RChery

Records archery sessions in dedicated .rchery scorecard files laid out as end-by-arrow grids. In View mode arrows are entered with 1-10 buttons and Undo or by drag-and-drop on a target, while Edit mode exposes the underlying Markdown tables. End and grand totals are calculated and every change is persisted to the file, and session stats and charts can optionally be aggregated with Dataview and Charts.
