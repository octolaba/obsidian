# NotePix

Uploads images, screenshots and attachments to a chosen GitHub repository when they are pasted or dragged into a note, replacing the local link with the remote URL. An Auto, Public or Private mode decides between a GitHub-hosted link and a secure private one, the GitHub token is kept encrypted, local files can optionally be removed after upload, and the plugin works on mobile.

    id:     "notepix"
    name:   "NotePix"
    author: "ayushparkara"
    repo:   "ayushparkara/NotePix"

    html_url:    "https://community.obsidian.md/plugins/notepix"
    github_url:  "https://github.com/ayushparkara/NotePix"
    description: "Automatically uploads images to your public or private GitHub repository, replacing local links with the corresponding remote URLs"
    about:       "Upload images, screenshots, and attachments from your vault to a chosen GitHub repository automatically when pasted or dragged into notes. Replace local links with GitHub-hosted or secure private links via Auto/Public/Private mode, keep your GitHub token encrypted, and optionally remove local files after upload; mobile-compatible."
