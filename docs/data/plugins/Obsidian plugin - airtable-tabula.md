# Airtable Tabula

Provides Airtable-style tables inside the vault, with typed columns, colored single and multi selects, search, filters, sorting, grouping and a compact query bar. A table can be created from scratch or built in one step from a CSV or Excel import, and everything stays local as plain JSON in .tabula files, so it works offline and behaves well under git. Linking a table to Airtable and pulling or pushing with a personal access token is optional.
