# Liefwork

Liefwork renders a folder as a coral, in which every subfolder becomes a branch and every file a lief, so that a project's size, substructure and active tips are visible in one navigable shape. The shape is panned, zoomed and clicked into to read a file in place or grow new branches, with nothing overlapping. Its memory system attaches a colour-coded agent terminal to a branch, which its recorded inputs describe as needing the Terminal plugin and the user's own Claude Code subscription rather than an API key, so that agent work takes root as shared notes. Nothing is copied or converted, because the coral is the data itself.
