# Note Linker with Previewer

Note Linker with Previewer looks across the vault for links between notes, using its own Markdown parser to skip code blocks, LaTeX and other non-Markdown sections. Scan results are cached so repeat runs are faster, linking can cover the whole vault or only the current note, invalid or unparsed notes are reported, and the cache can be reset for troubleshooting.

```cue
plugin: {
    id:     "note-linker-with-previewer"
    name:   "Note Linker with Previewer"
    author: "nickrallison"
    repo:   "nickrallison/obsidian-note-linker-with-previewer"

    html_url:    "https://community.obsidian.md/plugins/note-linker-with-previewer"
    github_url:  "https://github.com/nickrallison/obsidian-note-linker-with-previewer"
    description: "Link your notes together."
    about:       "Find links between notes across your vault while skipping code blocks, LaTeX, and other non-markdown sections using a built-in Markdown parser. Cache scan results for faster re-runs, run full-vault or current-note linking, report invalid/unparsed notes, and reset the cache to troubleshoot."

    stats: {
        downloads:  1525
        updated_at: 1724648886000
    }
}
```
