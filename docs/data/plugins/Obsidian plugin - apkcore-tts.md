# Apkcore TTS

Reads a selection or a whole document aloud using either the browser-native Web Speech API or Microsoft Edge TTS. Several Chinese voices are available, speech rate and maximum length are configurable, and playback is controlled by a floating stop button, pause and resume commands, and keyboard shortcuts.
