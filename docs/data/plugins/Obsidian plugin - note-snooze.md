# Note Snooze

Hides notes from the file explorer until a date given in a frontmatter property. Hidden notes stay searchable and can still be opened through the Quick Switcher and through links, and they reappear automatically on the specified date without a reload.

```cue
plugin: {
    id:     "note-snooze"
    name:   "Note Snooze"
    author: "Gabriel"
    repo:   "turingexmachina/obsidian-note-snooze"

    html_url:    "https://community.obsidian.md/plugins/note-snooze"
    github_url:  "https://github.com/turingexmachina/obsidian-note-snooze"
    description: "Hide notes from the file explorer until a date specified in a frontmatter property. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Hide notes from the file explorer until a date specified in a frontmatter property. Keep hidden notes searchable and openable via Quick Switcher and links, and have them automatically reappear at the specified date without reload."

    stats: {
        downloads:  13
        updated_at: 1783921472000
    }
}
```
