# TaskLens

TaskLens is a widget-based dashboard that combines a timeline, a task list, a Kanban board and statistics for tracking tasks and goals. Multi-day deadlines are visualized, cards are dragged to reschedule with the change saved back into the Markdown, and tasks are edited inline. Projects can be colored, and a focus mode hides widgets.
