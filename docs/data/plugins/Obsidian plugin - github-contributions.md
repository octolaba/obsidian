# GitHub Contributions

Displays GitHub and local Git contribution graphs in the sidebar as a year or month heatmap, with streak tracking, per-repository tooltips and several color palettes. Clicking a day opens or creates the matching daily note, years and months can be browsed, and totals such as contributions and streaks are shown.

```cue
plugin: {
    id:     "github-contributions"
    name:   "GitHub Contributions"
    author: "gearheaded"
    repo:   "gearheaded/obsidian-github-contributions"

    html_url:    "https://community.obsidian.md/plugins/github-contributions"
    github_url:  "https://github.com/gearheaded/obsidian-github-contributions"
    description: "Display GitHub and local Git contribution graphs in the Obsidian sidebar with streak tracking, repository insights, and daily note integration. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "View GitHub and local Git contributions in the Obsidian sidebar with a year or month heatmap, streak tracking, per-repo tooltips, and multiple color palettes. Click any day to open or create the matching daily note, browse years/months, and see stats like total contributions and streaks."
```
