# Digital Garden Timer

A focus timer that can be started, paused and reset, granting ten credits for every completed ten-minute block and tracking an all-time focus total. Credits are spent to place objects in a small digital garden, and progress — the current timer, all-time duration, credit totals and placed objects — is recorded in a Markdown note in the vault.
