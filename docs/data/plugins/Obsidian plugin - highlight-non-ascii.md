# Highlight Non-ASCII

Highlight Non-ASCII gives characters outside the ASCII range a red background in Edit mode under Live Preview, and optionally in Reading view, which reveals invisible or unusual Unicode. Configurable find and replace rules substitute common non-ASCII characters automatically, an allowlist and per-note control limit the scope, and a status bar counter reports the matches.
