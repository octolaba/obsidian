# Metafetch

Metafetch pulls Open Graph data for a URL, including title, image, description and publisher, into a note's YAML frontmatter using the OpenGraph.io or Microlink APIs. A modal runs the fetches and reports progress and errors, with control over overwriting, creating missing metadata and updating fetch dates.
