# Chinese Chess

Renders Chinese chess boards in a note and replays games from FEN or PGN, with a dedicated view for .pgn files and interactive move playback. Moves and branches are edited and auto-saved back into the PGN, positions open in the web PikaFish engine for analysis, and xiangqi or xq code blocks embed a board or generate a FEN.

```cue
plugin: {
    id:     "xiangqi"
    name:   "Chinese Chess"
    author: "weshell"
    repo:   "west-shell/obsidian-xiangqi"

    html_url:    "https://community.obsidian.md/plugins/xiangqi"
    github_url:  "https://github.com/west-shell/obsidian-xiangqi"
    description: "Chinese chess variation tree."
    about:       "Render Chinese chess boards and replay games from FEN/PGN inside Obsidian with a dedicated .pgn view and interactive move playback. Edit moves and branches, auto-save changes back to PGN, jump to web PikaFish for analysis, and insert xiangqi/xq code blocks to embed or generate FEN."

    stats: {

}
```
