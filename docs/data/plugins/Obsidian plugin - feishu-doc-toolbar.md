# ZengQiang Enhanced

ZengQiang Enhanced adds a floating toolbar for formatting, inserts, tables and templates, together with a template library. It applies native table colors and sizing, offers short links with safer anchors, localizes remote images, switches to a wide-page layout, copies a selection or a page as PNG, and archives Claudian chats. It requires the markdown-table-enhancer plugin from the same repository, and its enhanced table support is available in the background only while the experimental high-fidelity OneNote paste is enabled.
