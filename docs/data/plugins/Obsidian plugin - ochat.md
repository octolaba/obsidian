# OChat

Local models are used from a right sidebar chat with the active note, selected text, attached notes and ranked vault snippets as context. Ollama or OpenAI-compatible local servers are connected, models are chosen, replies render as Markdown, and proposed Markdown edits pass through a review mode. Endpoints can be tested with visible success, warning and failure states.
