# Beautiful Graph

Beautiful Graph renders the vault as a GPU-drawn knowledge graph aimed at folder-driven knowledge bases. It shows folder-aware index labels, color-coded directory groups, readable index hubs, Folder Lens contours and adjustable ambience, together with search, focus and live controls.
