# Zettelkasten Outliner

Zettelkasten Outliner creates a hierarchical outline for the open note and its Zettelkasten children, following the parent link recorded in each note's frontmatter. The outline is generated into a new note, giving a navigable overview of the related notes.

```cue

    id:     "zettelkasten-outliner"
    name:   "Zettelkasten Outliner"
    author: "tylersuzukinelson"
    repo:   "tylersuzukinelson/zettelkasten-outliner"

    html_url:    "https://community.obsidian.md/plugins/zettelkasten-outliner"
```
