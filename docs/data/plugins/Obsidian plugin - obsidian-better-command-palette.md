# Better Command Palette

Better Command Palette searches commands, files and tags from a single input and moves recent or pinned choices to the top of the list. A slash quick-switches files and a hash filters by tag, files are opened or created, macros run, and less-useful commands, files or tags hidden for a shorter list.

```cue
plugin: {
    id:     "obsidian-better-command-palette"
    name:   "Better Command Palette"
    author: "alexbieg"
    repo:   "alexbieg/obsidian-better-command-palette"

    html_url:    "https://community.obsidian.md/plugins/obsidian-better-command-palette"
    github_url:  "https://github.com/alexbieg/obsidian-better-command-palette"
    description: "A command palette that does all of the things you want it to do."
    about:       "Open a more user-friendly command palette that searches commands, files, and tags from a single input and bubbles recent or pinned choices to the top. Type / to quick-switch files or # to filter by tags, open or create files, run macros, and hide less-useful commands, files, or tags for a cleaner list."

    stats: {
        downloads:  39669

    }
}
```
