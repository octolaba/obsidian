# Kan Sync

Syncs vault checklists with Kan.bn kanban boards and shows live boards in a sidebar. Headings and checkboxes are pushed as lists and cards, and card status is pulled back into notes using rename-safe identifiers. Due dates, tags mapped to labels, sub-item checklists, attachments and mentions treated as assignees are all carried across.
