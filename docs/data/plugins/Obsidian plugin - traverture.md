# traVERture

traVERture detects scripture references in a note and converts them into interactive links carrying verse previews, study notes and copy or export actions. Citations from the NWT Bible are inserted and reformatted between Full, Standard and Official styles, with multi-language support, and a reference can be launched in JW Library and on JW.ORG. A searchable sidebar table lists references with several name formats and BCV codes and exports them as TSV.
