# Task Marker

Tasks are marked with custom statuses from hotkeys or the right-click menu, and text or a timestamp can be appended automatically. Cycling through the configured statuses flags action items, questions, completed and cancelled or transferred tasks, and records when each task changed.

```cue
plugin: {
    id:     "obsidian-task-marker"
    name:   "Task Marker"
    author: "wenlzhang"
    repo:   "wenlzhang/obsidian-task-marker"

    html_url:    "https://community.obsidian.md/plugins/obsidian-task-marker"
    github_url:  "https://github.com/wenlzhang/obsidian-task-marker"
    description: "Change task status and append text with hotkeys and context menu. Create, complete, cancel and mark tasks, cycle among configured task statuses, and append text (automatically)."
    about:       "Mark tasks with custom statuses, append text or timestamps, and change states via hotkeys or the right-click menu. Cycle statuses to flag action items, questions, completed or transferred tasks and track when each task changed."

    stats: {
        downloads:  14976
        updated_at: 1732729790000
    }
}
```
