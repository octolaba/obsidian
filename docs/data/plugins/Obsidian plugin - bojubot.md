# BojuBot

BojuBot connects the vault to Claude Code so that work is directed in ordinary conversational language rather than through a fixed interface. Its recorded inputs describe writing, planning, building custom commands and even developing Obsidian plugins without leaving the app, and state that the user stays in control. They describe intent rather than a list of concrete features, and nothing further is recorded here.
