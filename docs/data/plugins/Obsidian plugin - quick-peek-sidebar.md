# Quick Peek Sidebar

Opens the left, right or both side panels by hovering over the window edge, and collapses them again. Hover trigger areas, expand and collapse timing, animation speed, maximum widths, overlay mode and sync behavior are configurable. A double-click pins a sidebar so that it stays open.

```cue
plugin: {
    id:     "quick-peek-sidebar"
    name:   "Quick Peek Sidebar"
    author: "bwya77"
    repo:   "bwya77/obsidian-quick-peek-sidebar"

    html_url:    "https://community.obsidian.md/plugins/quick-peek-sidebar"
    github_url:  "https://github.com/bwya77/obsidian-quick-peek-sidebar"
```
