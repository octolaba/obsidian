# SmartPick

Selecting text summons a floating toolbar that runs AI actions such as summarize, translate and explain, invokes Obsidian commands, triggers system shortcuts, or opens external links. Commands are grouped and reordered by drag and drop, URL-scheme actions and reusable AI prompt templates are added by the user, and AI replies are shown as rendered Markdown. The recorded inputs state English and Chinese support.
