# Daily Checklist

Keeps a minimal checklist of daily routines in the right sidebar, so items are checked and edited without leaving the active note. Items can be reordered, and their checked state resets automatically each day. When sync is enabled, today's checklist is written into a configurable callout inside today's daily note only.

```cue
plugin: {
    id:     "daily-checklist"
    name:   "Daily Checklist"
    author: "Matt Maiorana"
    repo:   "mattmaiorana/daily-checklist"

    html_url:    "https://community.obsidian.md/plugins/daily-checklist"
    github_url:  "https://github.com/mattmaiorana/daily-checklist"
    description: "A minimal sidebar checklist for daily routines, with optional sync to your daily note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Manage a lightweight daily checklist in the right sidebar. Sync today's checklist into a configurable callout inside today's daily note only when sync is enabled."
```
