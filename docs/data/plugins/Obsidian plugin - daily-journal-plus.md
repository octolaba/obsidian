# Daily Journal Plus

Creates daily journal entries pre-filled with reflection prompts, habit checkboxes and a mood tracker on a one to five scale. Moods and habits can also be logged from a quick-entry modal. A sidebar shows weekly mood and habit completion, and streaks are counted with rotating prompts.

```cue
plugin: {
    id:     "daily-journal-plus"
    name:   "Daily Journal Plus"
    author: "wesswart77"
    repo:   "wesswart77/obsidian-daily-journal"

    html_url:    "https://community.obsidian.md/plugins/daily-journal-plus"
    github_url:  "https://github.com/wesswart77/obsidian-daily-journal"
    description: "A daily journaling system with mood tracking, habit logging, streak counters, and rotating reflection prompts. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create daily journal entries with pre-filled prompts, habit checkboxes, and a 1–5 mood tracker. View weekly mood and habit completion in a sidebar, log moods and habits via a quick-entry modal, and track streaks with rotating reflection prompts."

    stats: {
        downloads:  230
        updated_at: 1779653126000
    }
}
```
