# Search Exploder

Search Exploder opens each search result in its own note tab, invoked from the contextual menu of the search results. It offers that expansion independently of Continuous Mode, which preserves compatibility with Vertical Tabs.

```cue
plugin: {
    id:     "search-exploder"
    name:   "Search Exploder"
    author: "Jason Klein"
    repo:   "jklein64/obsidian-search-exploder"

    html_url:    "https://community.obsidian.md/plugins/search-exploder"
    github_url:  "https://github.com/jklein64/obsidian-search-exploder"
    description: "Opens each search result in its own tab. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open each search result as its own note tab from the search results contextual menu. Preserve compatibility with Vertical Tabs by offering search-result expansion independently of Continuous Mode."
```
