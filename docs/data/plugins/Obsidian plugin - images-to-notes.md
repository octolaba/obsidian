# Images to Notes

Turns photos of handwritten or printed notes into Markdown using AI transcription. Each image becomes a new note with the image appended at the bottom, and dropping several images into a folder queues them for processing. JPG, JPEG, PNG and HEIC are the listed formats.

```cue
plugin: {
    id:     "images-to-notes"
    name:   "Images to Notes"
    author: "rodolfo-terriquez"
    repo:   "rodolfo-terriquez/images-to-notes"

    html_url:    "https://community.obsidian.md/plugins/images-to-notes"
    github_url:  "https://github.com/rodolfo-terriquez/images-to-notes"
    description: "Turn photos of handwritten or printed notes into Markdown using AI."
    about:       "Transcribe photos of handwritten or printed notes into Markdown using AI. Create a new note for each image, append the image at the bottom, and process multiple files queued when you drag and drop images into a folder (JPG, JPEG, PNG, HEIC)."

    stats: {
        downloads:  2647
        updated_at: 1786403149000
    }
}
```
