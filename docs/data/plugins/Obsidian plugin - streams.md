# Streams

Multiple daily note streams are created and managed in place of the core Daily Notes plugin. Each stream has its own full calendar, missing notes are surfaced in a dedicated view, and notes are moved between streams. A public API is exposed for other plugins.

```cue
plugin: {
    id:     "streams"
    name:   "Streams"
    author: "bfloydd"
    repo:   "bfloydd/streams"

    html_url:    "https://community.obsidian.md/plugins/streams"
    github_url:  "https://github.com/bfloydd/streams"
    description: "Create and manage multiple Daily Note streams"
    about:       "Create and manage multiple daily note streams and replace the Daily Note core plugin. Display a full calendar per stream, surface missing notes in a dedicated view, move notes between streams, and expose a public API for other plugins."
```
