# Quick Links

Creates shortcut links to external sites through short prefixes, so a wiki prefix followed by a page name resolves to Wikipedia. Custom prefixes map to any URL or to obsidian://vault targets, and quick links are written either in wiki-link or in Markdown link syntax.

```cue
plugin: {
    id:     "quick-links"
    name:   "Quick Links"
    author: "iafisher"
    repo:   "iafisher/obsidian-quick-links"

    html_url:    "https://community.obsidian.md/plugins/quick-links"
    github_url:  "https://github.com/iafisher/obsidian-quick-links"
    description: "Create quick link shortcuts to Wikipedia and other sites"
    about:       "Create shortcuts to link to external sites with simple prefixes like [[w:New York City]]. Define custom prefixes to map to any URL or obsidian://vault targets. Choose wiki-link or markdown link syntax for how quick links are written."

    stats: {
        downloads:  5841
        updated_at: 1749322665000
    }
}
```
