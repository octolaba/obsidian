# Mark e Link

Converts the selected text, or the word under the cursor, into an Obsidian internal link with a single shortcut. The result is plain wiki-link markup, which suits keyboard-driven editing.

```cue
plugin: {
    id:     "mark-and-link"
    name:   "Mark e Link"
    author: "wgg2bhccq2-afk"
    repo:   "wgg2bhccq2-afk/obsidian-mark-and-link"

    html_url:    "https://community.obsidian.md/plugins/mark-and-link"
    github_url:  "https://github.com/wgg2bhccq2-afk/obsidian-mark-and-link"
    description: "Visually highlights selected text and converts it into a clickable internal link. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert selected text or the word under the cursor into a clean Obsidian internal link [[text]] with a single shortcut. Keep notes tidy with minimal markup and speed up keyboard-driven workflows."
```
