# Timestamp Player

Timestamp Player embeds an audio player in a note and turns speaker-line or inline MM:SS timestamps in a transcription document into clickable seek buttons. Clicking one seeks the embedded audio and plays it, playback can be toggled, and the current timestamp is highlighted as the audio advances. Several recordings in one note are partitioned so each file controls the timestamps in its own section.
