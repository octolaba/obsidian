# Canvas Explorer

Canvas Explorer walks the vault by iteratively adding or ignoring linked notes and then generates a canvas from the notes that were kept. The saved canvas preserves connections, color-codes nodes by link count, sorts notes by frontmatter or date and can exclude sections. An optional concatenated summary node can be added.
