# D2

Renders D2 fenced code blocks as inline diagrams using a local d2 installation, turning the diagram scripting language into pictures inside a note. Several layout engines and themes are supported, along with sketch mode, padding and a maximum height, and renders refresh automatically as a diagram changes.

    id:     "d2-obsidian"
    name:   "D2"
    author: "terrastruct"
