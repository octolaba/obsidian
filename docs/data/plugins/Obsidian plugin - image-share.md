# Image Share

Shares selected text as a styled image rendered from the note. The image can be copied to the clipboard or downloaded, and the preview can be zoomed to adjust its appearance before saving.

```cue
plugin: {
    id:     "image-share"
    name:   "Image Share"
    author: "iqijun"
    repo:   "iqijun/obsidian-image-share"

    html_url:    "https://community.obsidian.md/plugins/image-share"
    github_url:  "https://github.com/iqijun/obsidian-image-share"
    description: "Share selected text as beautiful images."
    about:       "Share selected text as styled images directly from your notes. Copy images to clipboard, download them, and zoom previews to adjust appearance before saving."

    stats: {
        downloads:  566
        updated_at: 1746114654000
    }
}
```
