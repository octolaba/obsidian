# Lightweight Mentions

Lightweight Mentions inserts mentions from a trigger character that link to an existing note or, when no note exists yet, create and link to a heading inside a shared stub file. A stub heading can later be promoted into a full note, and every mention across the vault is rewritten to point at the new file.

```cue
plugin: {
    id:     "lightweight-mentions"
    name:   "Lightweight Mentions"
    author: "amato21"
    repo:   "amato21/Lightweight-Mentions"

    html_url:    "https://community.obsidian.md/plugins/lightweight-mentions"
    github_url:  "https://github.com/amato21/Lightweight-Mentions"
    description: "Type a trigger character to mention anything: links to an existing note, or to a lightweight heading inside a shared stub file if no real note exists yet. Promote a mention to a full note whenever it deserves one. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert @-style mentions that link to existing notes or create and link to headings in a shared stub file when no note exists. Promote a stub heading into a full note and rewrite every mention across the vault to point to the new file."

    stats: {
        downloads:  76
        updated_at: 1786484294000
    }
}
```
