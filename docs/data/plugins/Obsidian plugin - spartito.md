# Spartito

Music notation is written and rendered on a grand staff of treble and bass clefs, either from a fenced code block or from a dedicated visual editor. Live preview covers chords, rests, automatic bar splitting, beaming, ties and key-signature accidentals. Scores are saved as Markdown and rendered offline by a bundled copy of VexFlow.
