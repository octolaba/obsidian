# Audio Inbox

Records voice with one click, transcribes it through SiliconFlow and generates a structured AI summary with extracted to-dos using DeepSeek. To-dos can be pushed to Apple Reminders, audio can be processed in batches, and the plugin runs on desktop and mobile with a draggable floating button. The recorded inputs describe the chosen services as reachable from China without a VPN.
