# Recipe view

Displays notes written as ordinary Markdown in an interactive recipe card to cook from. Ingredient quantities can be scaled, the card split into two columns or grouped by step, items crossed out, and steps highlighted. It works on phones and tablets as well.

```cue
plugin: {
    id:     "recipe-view"
    name:   "Recipe view"
    author: "lachsh"
    repo:   "lachsh/obsidian-recipe-view"

    html_url:    "https://community.obsidian.md/plugins/recipe-view"
    github_url:  "https://github.com/lachsh/obsidian-recipe-view"
    description: "View your notes as interactive recipe cards while you cook."
    about:       "Display recipes written as regular Markdown notes in a clean, interactive recipe card for cooking. Scale ingredient quantities, split into two columns or group ingredients by step, cross out items, highlight steps, and use on phones and tablets."

}
```
