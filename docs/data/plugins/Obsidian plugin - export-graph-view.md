# Export Graph View

Exports a snapshot of the graph view as a Mermaid or GraphViz file. The export focuses on a single parent or takes the whole graph, and relationships are mapped by tags, links or folders, so the result opens in any Mermaid or GraphViz tool for sharing and analysis.
