# Better Tables

Better Tables provides an interactive table editor summoned through a Table block. Cells are edited by clicking, with Tab and Enter moving between them; dividers drag to resize columns and rows, edge handles reorder them, hover dots insert a column or row between two others, and pills at the right and bottom edges append new ones. Rows and columns are removed by selecting a handle and pressing Delete, wide tables scroll horizontally, and column widths and row heights are remembered.

```cue
plugin: {
    id:     "better-tables"
    name:   "Better Tables"
    author: "yaye.work"
    repo:   "yaye-work/obsidian-better-tables"

    html_url:    "https://community.obsidian.md/plugins/better-tables"
    github_url:  "https://github.com/yaye-work/obsidian-better-tables"
    description: "If you are frustrated with making tables in your notes, install this. Summon the interactive table via the ```Table``` block. Just drag to resize and reorder, hover to insert, click to edit. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Click to edit any cell, with Tab / Enter to move between cells Drag dividers to resize columns and rows Drag the edge handles to reorder columns and rows Hover insert dots to add a column or row between any two Select + delete a row or column (click its handle, then Delete) Add columns and rows from the + pills on the right and bottom edges Horizontal scrolling for wide tables Column widths and row heights are remembered --- The same table tool is now included in my CanvasKit Plugin!"
```
