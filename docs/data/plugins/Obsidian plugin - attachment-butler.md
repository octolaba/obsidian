# Attachment Butler

Marks unreferenced attachments with a red dot in the file explorer, so redundant files are visible at a glance. A right-click jumps to every note that references an attachment, and note-name prefixes with hover details show where those references come from.

```cue
plugin: {
    id:     "attachment-butler"
    name:   "Attachment Butler"
    author: "fantsga"
    repo:   "fantsga/attachment-butler"

    html_url:    "https://community.obsidian.md/plugins/attachment-butler"
    github_url:  "https://github.com/fantsga/attachment-butler"
    description: "高效管理附件，告别文件混乱与引用追踪难题. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Identify unreferenced attachments with a red-dot indicator in the file explorer to spot redundant files quickly. Jump to all notes that reference an attachment via right-click and display note-name prefixes with hover details to view reference sources at a glance."

    stats: {
        downloads:  143

    }
}
```
