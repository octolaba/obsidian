# Auto Card Link Enhanced

Converts URLs into card-styled links by fetching their metadata, thumbnails and favicons and writing them into a cardlink YAML code block, which keeps the Markdown clean. YouTube, Twitch, Reddit, GitHub, Wikipedia and Spotify receive tailored handling, and thumbnail quality, local image saving and card style are configurable.

    id:     "auto-card-link-enhanced"
    name:   "Auto Card Link Enhanced"
    author: "KreNtal"

    github_url:  "https://github.com/krental/obsidian-auto-card-link"
    description: "Automatically convert URLs into beautiful card-styled links with metadata, thumbnails and favicons. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Automatically generate beautiful card-styled links from URLs by fetching their metadata, thumbnails and favicons and converting them into a YAML `cardlink` code block that keeps your Markdown clean. It includes tailored handling for YouTube, Twitch, Reddit, GitHub, Wikipedia, Spotify and more, plus options for thumbnail quality, local image saving and multiple card styles."
