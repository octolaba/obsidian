# Google Drive Sync

Syncs vaults with Google Drive in both directions so they can be used across platforms, including from the iOS app. Conflicts are resolved automatically by prioritizing local files, several vaults can live under one Google account, and vault configuration is synced across devices. The recorded inputs advise backing up the vault before use.
