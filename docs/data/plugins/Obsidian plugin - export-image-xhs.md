# Export Image XHS

Exports a note as share-ready image cards, either several images or one long image, with a live preview and editable pagination for adjusting the layout before export. An author header and watermarks are configurable, the previewed appearance is preserved across pages, and presets produce cards in the 3:4 Xiaohongshu format.
