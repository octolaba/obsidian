# Tag Group Manager

Tag Group Manager organizes tags into custom groups and switches between group-sets, inserting and reordering tags from a draggable floating selector or a right-hand overview. Tags can be renamed across the whole vault, including YAML frontmatter and Canvas, and given custom colors. Multi-level tag trees are supported, and tags can be cleared or batch-edited.
