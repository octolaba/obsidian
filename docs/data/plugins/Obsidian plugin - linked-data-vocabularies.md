# Linked Data Vocabularies

Adds Library of Congress Subject Headings to notes as linked-data YAML fields, covering the heading itself, its URL, broader, narrower and related terms, and the LC classification. A search command inserts results either by appending to frontmatter or as inline YAML for Dataview, and the underlying data is generated with the Linked Data Helper plugin.

```cue
plugin: {
    id:     "linked-data-vocabularies"
    name:   "Linked Data Vocabularies"
    author: "kometenstaub"
    repo:   "kometenstaub/linked-data-vocabularies"

    html_url:    "https://community.obsidian.md/plugins/linked-data-vocabularies"
    github_url:  "https://github.com/kometenstaub/linked-data-vocabularies"
    description: "Add Library of Congress Subject Headings (LCSH) as metadata to your notes."
    about:       "Add Library of Congress Subject Headings as linked-data YAML fields to notes, including heading, URL, broader/narrower/related terms and LC classification. Search and insert results with the LCSH command, appending to frontmatter or inserting inline YAML for Dataview; generate data with the Linked Data Helper plugin."

    stats: {
        downloads:  5832

    }
}
```
