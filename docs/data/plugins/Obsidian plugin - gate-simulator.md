# GATE Simulator

Generates mock GATE tests from previous-year question papers, selected by subject, topic, institute or difficulty, or as mixed sets, covering Core, General Aptitude, Subject-wise and Random modes. The exam runs full-screen with a countdown timer, a navigation palette, mark-for-review and auto-submit, and answers are entered interactively. Completed tests feed detailed analytics and an answer review pass for spotting weak areas.
