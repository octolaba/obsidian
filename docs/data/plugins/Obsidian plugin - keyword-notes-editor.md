# Keyword Notes Editor

Organizes the sidebar by keyword tags and folder paths, similar to a Logseq tag view, and shows every matching note in a single scrollable editor. Multi-level sub-tag trees can be expanded, several tags or folders aggregated, and time filters applied. Everything can be collapsed or expanded at once, and notes are browsed in batches with infinite scroll.
