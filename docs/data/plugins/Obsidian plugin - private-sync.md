# Private Sync

Synchronizes the vault with a self-hosted Private Sync Server over HTTP or HTTPS, so that data stays off external clouds. Per-device tokens and a local sync index drive incremental two-way sync with SHA-256 change detection and batched uploads, and devices are paired to control access.
