# Schematex

Schematex renders Schematex diagrams inline in notes, covering genogram, circuit, ladder, fishbone and other diagram types. Diagrams can be panned, zoomed and viewed fullscreen, exported as SVG or PNG, and they adjust to Obsidian's light and dark themes.
