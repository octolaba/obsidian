# Hybrid Git Sync

Syncs a vault across devices using native Git on desktop and the GitHub API on mobile, with bidirectional incremental transfers, parallel uploads, auto-sync and conflict detection. Commit history, diffs, changed files and sync status are shown in the interface, and .gitignore rules are respected.
