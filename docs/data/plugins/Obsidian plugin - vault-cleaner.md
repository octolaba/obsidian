# Vault Cleaner

Removes unused media such as images and PDFs, untitled notes and duplicated files in a single action. The most recent copy of a duplicate is kept, and files that are not empty are excluded from deletion.

```cue
plugin: {
    id:     "vault-cleaner"
    name:   "Vault Cleaner"
    author: "rapphcd"
    repo:   "rapphcd/obsidian-vault-cleaner"

    html_url:    "https://community.obsidian.md/plugins/vault-cleaner"
    github_url:  "https://github.com/rapphcd/obsidian-vault-cleaner"
    description: "Clean unused medias, untitled and duplicated leafs. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Clean your vault with a single click and remove unused media (images, PDFs), untitled notes, and duplicate files. Keep the most recent duplicate and exclude non-empty files from deletion for safe cleanup."
```
