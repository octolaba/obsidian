# Wine Tracker

Tracks a physical wine cellar in plain Markdown notes, recording per-lot inventory, price, purchase date, shelf and quantity. Lots can be split across phased drinking windows, and dashboard, monthly and sidebar views show which bottles are ready or overdue. Tastings and optional spending lines are logged into daily notes.
