# Toggle Case

A command or an assigned shortcut cycles the case of the selection between lowercase, Title Case and UPPERCASE. The change is applied across multiple cursors at once.

```cue
plugin: {
    id:     "obsidian-toggle-case"
    name:   "Toggle Case"
    author: "matthewalner"
    repo:   "matthewalner/obsidian-toggle-case"

    html_url:    "https://community.obsidian.md/plugins/obsidian-toggle-case"
    github_url:  "https://github.com/matthewalner/obsidian-toggle-case"
    description: "Set a hotkey to toggle between `lowercase` `UPPERCASE` and `Title Case`."
    about:       "Toggle selected text case, cycling between lowercase → Title Case → UPPERCASE. Apply changes across multiple cursors and invoke via the Toggle Case command or an assigned shortcut."

    stats: {
        downloads:  6933
        updated_at: 1670788522000
    }
}
```
