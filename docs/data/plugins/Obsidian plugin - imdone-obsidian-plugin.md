# Open cards in imdone

Opens Imdone kanban cards from their source in Obsidian, jumping from a TODO comment or a note to the exact file and line in Imdone. Autocomplete suggestions for imdone tags are offered while typing.

```cue
plugin: {
    id:     "imdone-obsidian-plugin"
    name:   "Open cards in imdone"
    author: "imdone"
    repo:   "imdone/imdone-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/imdone-obsidian-plugin"
    github_url:  "https://github.com/imdone/imdone-obsidian-plugin"
    description: "Open cards in imdone kanban from their source in Obsidian."
    about:       "Open Imdone cards from TODO comments or notes and jump directly to the exact file and line in Imdone. Get autocomplete suggestions for #imdone tags as you type to speed up task tagging."

    stats: {
        downloads:  6223
        updated_at: 1737433060000
    }
}
```
