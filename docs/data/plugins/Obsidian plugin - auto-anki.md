# Auto Anki

Generates Anki flashcards from notes with OpenAI models and sends them to a local Anki instance through AnkiConnect. Whole files or highlighted text can be exported, and generated question-and-answer alternatives are reviewed or chosen before the import. It operates on desktop only.

```cue
plugin: {
    id:     "auto-anki"
    name:   "Auto Anki"
    author: "cadrianxyz"
    repo:   "cadrianxyz/obsidian-auto-anki"

    html_url:    "https://community.obsidian.md/plugins/auto-anki"
    github_url:  "https://github.com/cadrianxyz/obsidian-auto-anki"
```
