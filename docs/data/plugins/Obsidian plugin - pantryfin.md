# PantryFin

Tracks pantry inventory through a normalized base-unit engine that converts weights, volumes and counts so that stock additions and subtractions stay consistent. An AI nutrition assistant generates meal plans, recipes and macro targets from the available ingredients, and a live dashboard shows the current state. The recorded description also names mobile optimization, Chinese ingredient recognition and calorie tracking.
