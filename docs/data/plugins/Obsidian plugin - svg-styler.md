# SVG Style Editor

Changes the color and other style properties of an embedded SVG file from inside the editor. The recorded About text names color, border and opacity among those properties and applies them to path, line, rect, circle, ellipse and polygon elements. Changes can be saved in place, written to a styled duplicate, or cleared.
