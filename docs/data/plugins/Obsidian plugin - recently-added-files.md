# Recently Added Files

Lists files by when they were added, in a sidebar covering notes as well as images, PDFs, videos, and other file types. Entries can be filtered by type and paths excluded. Newly added images can be renamed with MD5 hashes to avoid name collisions.

```cue
plugin: {
    id:     "recently-added-files"
    name:   "Recently Added Files"
    author: "lemon695"
    repo:   "lemon695/obsidian-recently-added-files"

    html_url:    "https://community.obsidian.md/plugins/recently-added-files"
    github_url:  "https://github.com/lemon695/obsidian-recently-added-files"
    description: "List files by last added, including pictures, MP4s, PDFs etc."
    about:       "Display a sidebar of recently added files to quickly find new notes, images, PDFs and more. Filter by type (Markdown, PDF, Image, Video, Other), exclude paths, and rename newly added images with MD5 hashes to avoid name collisions."

    stats: {
        downloads:  3519
        updated_at: 1780909465000
    }
}
```
