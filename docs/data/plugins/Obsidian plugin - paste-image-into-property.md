# Paste Image Into Property

Pastes clipboard images into YAML frontmatter properties while Live Preview is active. The image is saved to the vault using Obsidian's attachment path and a link is inserted into the property, replacing that property's previous content. The recorded description limits this to text properties in Live Preview and states that there is no mobile support.

```cue
plugin: {
    id:     "paste-image-into-property"
    name:   "Paste Image Into Property"

    html_url:    "https://community.obsidian.md/plugins/paste-image-into-property"
```
