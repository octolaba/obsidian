# Theme by Folder

Theme by Folder switches the theme and the light or dark mode automatically when a note in a configured folder is opened. Each folder is assigned a theme and a mode, either Light, Dark or System Default, and a default fallback covers notes that match nothing. Matching is done on the path.

```cue
plugin: {
    id:     "theme-by-folder"
    name:   "Theme by Folder"
    author: "jinmugo"
    repo:   "jinmugo/obsidian-theme-by-folder"

    html_url:    "https://community.obsidian.md/plugins/theme-by-folder"
    github_url:  "https://github.com/jinmugo/obsidian-theme-by-folder"
    description: "Automatically switch themes based on the folder of the opened note"
    about:       "Switch Obsidian theme and light/dark mode automatically when opening notes in specified folders. Assign themes and modes per folder (Light, Dark, or System Default), set a default fallback for unmatched notes, and keep behavior fast with simple path-based matching."

    stats: {
        downloads:  2930

    }
}
```
