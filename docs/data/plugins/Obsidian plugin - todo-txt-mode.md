# Todo.txt Mode

Todo.txt Mode adds support for the todo.txt file format with syntax highlighting for priorities, projects, contexts, due dates, completion marks and recurrence markers. It adds completion dates, generates recurring tasks from recurrence intervals, moves completed tasks into a done file, and sorts by priority, project, context or due date.

```cue

    id:     "todo-txt-mode"
    name:   "Todo.txt Mode"
    author: "rioskit"

    html_url:    "https://community.obsidian.md/plugins/todo-txt-mode"
    github_url:  "https://github.com/rioskit/obsidian-todo-txt-mode"

    about:       "Highlight todo.txt elements: priorities, projects (+project), contexts (@context), due: dates, completion marks and rec: markers. Add completion dates, generate recurring tasks from rec: intervals, move completed tasks to a done file, and sort by priority, project, context or due date."
```
