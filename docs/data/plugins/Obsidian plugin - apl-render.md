# APL Render

Renders APL tick notation into APL Unicode following the RIDE convention, inside code blocks tagged apl. Common APL symbols such as averages, variance and box are displayed as Unicode, and the APL385 font gives the best appearance.

```cue
plugin: {
    id:     "apl-render"
    name:   "APL Render"
    author: "vzsky"
    repo:   "vzsky/apl-obsidian"

    html_url:    "https://community.obsidian.md/plugins/apl-render"
    github_url:  "https://github.com/vzsky/apl-obsidian"
    description: "Render APL syntax."
    about:       "Render APL tick notation into proper APL Unicode using the RIDE convention inside code blocks tagged apl. Display common APL symbols (averages, variance, box) as Unicode and use an APL385 font for best appearance."

    stats: {
        downloads:  3325
        updated_at: 1689838664000
    }
}
```
