# Simple Sticky Notes

Opens notes as floating sticky-note windows that stay above other applications and are restored with the workspace, including position, size, colors and opacity. Notes can be pinned, and background color, text color and transparency are configurable. Windows open from the ribbon, the command palette or the file context menu, and the plugin is desktop only because it relies on Electron APIs.
