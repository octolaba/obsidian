# Note Progressbar

Displays a progress bar above the current note summarizing Markdown checkbox completion: how many are checked, the total, the percentage, and a theme-aware fill. It updates as tasks are checked or unchecked and as notes are switched, hides itself when a note has no tasks, and can be shown or hidden per vault through a toggle command.

```cue
plugin: {
    id:     "note-progressbar"
    name:   "Note Progressbar"
    author: "ryohma0510"
    repo:   "ryohma0510/obsidian-note-progressbar"

    html_url:    "https://community.obsidian.md/plugins/note-progressbar"
    github_url:  "https://github.com/ryohma0510/obsidian-note-progressbar"
    description: "Displays a live progress bar summarizing checkbox completion in the active note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display a lightweight progress bar above the current note showing completed Markdown checkboxes, totals, percentage, and a theme-aware fill. Update live as you check/uncheck tasks or switch notes, auto-hide when no tasks exist, and use the Toggle todo progress bar command to show or hide it per vault."
```
