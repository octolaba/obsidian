# BackItUp

BackItUp makes a copy or a snapshot of a note before it is edited, keeping a history of changes. From the note's context menu a copy is created beside the original, or a snapshot is written into a folder you define.

```cue
plugin: {
    id:     "back-it-up"
    name:   "BackItUp"
    author: "hammadxp"
    repo:   "hammadxp/back-it-up"

    html_url:    "https://community.obsidian.md/plugins/back-it-up"
    github_url:  "https://github.com/hammadxp/back-it-up"
    description: "Quickly make a copy or snapshot of a note."
    about:       "Backup important notes before editing and keep a history of changes. Right-click a note to create a copy beside the original or take a snapshot to a user-defined folder."

    stats: {
        downloads:  1271
        updated_at: 1707930444000
    }
}
```
