# Link Archive

Submits the external URLs found in the current note to archive.org and embeds an archived link beside each original once the snapshot is saved. Existing archive links are not recreated, and progress and errors are reported while the archiving runs.

```cue
plugin: {
    id:     "obsidian-link-archive"
    name:   "Link Archive"
    author: "tomzorz"
    repo:   "tomzorz/obsidian-link-archive"

    html_url:    "https://community.obsidian.md/plugins/obsidian-link-archive"
    github_url:  "https://github.com/tomzorz/obsidian-link-archive"
    description: "Archive links in your note so they're available to you even if the original site goes down or gets removed."
    about:       "Archive links in the current note by submitting external URLs to archive.org. Embed (Archived) links next to the originals as soon as snapshots are saved and avoid recreating existing archive links. Show progress and handle errors during the archiving process."

    stats: {
        downloads:  7005
        updated_at: 1635128156000
    }
}
```
