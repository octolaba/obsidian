# Tasks Plus

Organizes to-dos into six fixed views, Inbox, Today, Upcoming, Anytime, Someday and Logbook, alongside an Areas and Projects tree with live counts. Capture happens from a floating modal or an obsidian:// URL and accepts natural-language dates. Tasks remain ordinary Markdown checkboxes in their notes, with completion dates appended in place.
