# Gallery Navigator

Browses the vault through a folder and tag tree beside a masonry wall of cover cards. Covers are sourced lazily from frontmatter, embedded images and PDFs, and full-text search reaches into PDFs as well. Images get a quick-look view and links get preview cards. Files can be pinned and multi-selected for batch actions, layouts can be switched, and folders reordered by dragging, with nested tags supported.
