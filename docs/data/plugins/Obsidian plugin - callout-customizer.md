# Callout Customizer

Changes a callout's icon, color, title and fold state from its right-click menu, without writing CSS. The settings are stored inline in the note, so customizations travel with the file through sync, export and Git. Icons come from the Lucide set or from custom SVGs, and a look can be saved as a preset or promoted into a reusable callout type.
