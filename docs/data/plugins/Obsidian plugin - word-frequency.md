# Word Frequency

Counts the words of the current note and lists them in the sidebar, ordered from most to least frequent. The list can be filtered or searched, and words placed on a blacklist are left out of the counts, which helps identify keywords for writing.

```cue
plugin: {
    id:     "word-frequency"
    name:   "Word Frequency"
    author: "mts7"
    repo:   "mts7/obsidian-word-frequency"

    html_url:    "https://community.obsidian.md/plugins/word-frequency"
    github_url:  "https://github.com/mts7/obsidian-word-frequency"
    description: "Counts the most frequently used words in a note and displays them in the sidebar."
    about:       "Count words in the current note and display frequency counts in a sidebar sorted from most to least common. Filter or search the list and blacklist words to exclude them from counts to identify keywords for SEO, résumés, or general writing."

    stats: {
        downloads:  2499
        updated_at: 1772416233000
    }
}
```
