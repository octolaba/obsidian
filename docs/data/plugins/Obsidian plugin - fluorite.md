# Fluorite

Displays local image files in a floating panel, with several images selectable at once. The panel can instead show a read-only snapshot of the current note; that snapshot is static and does not follow later edits.

```cue
plugin: {
    id:     "fluorite"
    name:   "Fluorite"
    author: "telehakke"
    repo:   "telehakke/fluorite"

    html_url:    "https://community.obsidian.md/plugins/fluorite"
    github_url:  "https://github.com/telehakke/fluorite"
    description: "Display images or note on floating panel. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display local image files in a floating panel with multi-image selection. Show a read-only snapshot of the current Obsidian note in the floating panel; snapshots are static and won’t reflect later edits."

    stats: {
        downloads:  104
        updated_at: 1779635455000
    }
}
```
