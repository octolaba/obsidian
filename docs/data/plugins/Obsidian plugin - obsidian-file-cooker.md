# File Cooker

Batch-edits notes gathered from search results, the current file, clipboard links, Dataview or DataviewJS queries, or Bases query results. Tag, alias and CSS class values are added or removed, and files are moved, copied, renamed, merged or deleted. It also creates files from unresolved links, syncs to flomo, and adds files, text or tasks to Canvas.
