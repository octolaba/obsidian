# YouTube Panel

Plays YouTube videos in the right sidebar with a compact, privacy-friendly player and a persistent queue that advances on its own. Videos are queued or played by adding a link or searching YouTube from a native modal, real titles are resolved through oEmbed without an API key, and reopening the panel restores the last video.
