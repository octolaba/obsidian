# List to table converter

Converts a list or a block of multi-line text into a Markdown table, giving each selected line its own row. Plain lines, bullets, numbers, and checkboxes are all accepted as input, and an empty header row and extra columns can be added to shape the resulting table.

    id:     "list-table-converter"
    name:   "List to table converter"
    author: "paddomanno"
