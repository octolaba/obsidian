# Trello Kanban Sync

Mirrors Trello boards into native Kanban-plugin boards as file-backed copies, refreshed on an interval. One-way sync keeps Trello as the source of truth by default; an experimental two-way mode pushes card names, lane moves, creation and archival back to Trello while leaving Trello-only fields untouched.
