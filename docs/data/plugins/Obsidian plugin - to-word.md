# ToWord

ToWord exports Markdown notes to Microsoft Word DOCX files, preserving headings, lists, tables, images, hyperlinks and text styling, with code rendered using syntax highlighting in the style of VS Code. The DOCX file is written into the vault itself, so it stays reachable on desktop, iPhone and Android, and several page sizes are offered.
