# Copy Inline Code

Copy Inline Code adds a clickable copy icon inside inline code spans that copies their content to the clipboard. The icon is customizable, and clicking it avoids selecting the text by hand.

```cue
plugin: {
    id:     "copy-inline-code"
    name:   "Copy Inline Code"
    author: "ozavodny"
    repo:   "ozavodny/obsidian-copy-inline-code-plugin"

    html_url:    "https://community.obsidian.md/plugins/copy-inline-code"
    github_url:  "https://github.com/ozavodny/obsidian-copy-inline-code-plugin"
    description: "Easily copy the contents of an inline code element with a single click."
    about:       "Add a clickable, customizable copy icon inside inline code spans to copy their content to the clipboard. Click the icon to copy inline code quickly without selecting text."
```
