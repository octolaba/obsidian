# Vault Transfer

Transfers a note, several notes or whole folders from one vault to another and inserts a link back into the original file. Folder structure is preserved when several files are moved, items can be sent to a specific or newly created folder, and a link to an existing note can be inserted without copying anything. The recorded About states that it runs on desktop only.

    id:     "vault-transfer"
    name:   "Vault Transfer"
    author: "imaginaryprogramming"
    repo:   "imaginaryprogramming/obsidian-vault-transfer"

    html_url:    "https://community.obsidian.md/plugins/vault-transfer"
    github_url:  "https://github.com/imaginaryprogramming/obsidian-vault-transfer"

    about:       "Transfer selected Markdown notes or entire folders to another vault and insert a link back in the original file.
