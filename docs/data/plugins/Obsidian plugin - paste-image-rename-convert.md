# Paste Image Rename and Convert

Renames images as they are pasted into a note and allows naming them manually. Images can be compressed and converted to reduce file size, with JPG and WebP as output formats, and external upload plugins can send the renamed images to cloud storage.

```cue
plugin: {
    id:     "paste-image-rename-convert"
    name:   "Paste Image Rename and Convert"
    author: "yiaos"
    repo:   "yiaos/obsidian-paste-image-rename-convert"

    html_url:    "https://community.obsidian.md/plugins/paste-image-rename-convert"
    github_url:  "https://github.com/yiaos/obsidian-paste-image-rename-convert"
    description: "Renames pasted images and covert the formats"
    about:       "Rename images when pasting into notes and allow manual naming. Compress and convert images to reduce file size, supporting JPG and WebP output. Work with external upload plugins to send renamed images to cloud storage."

    stats: {
        downloads:  2020

}
```
