# Notioneer

Adds a Notion-style header to notes carrying a cover image, a title that renames the file, and frontmatter properties that can be read and written. A slash-command menu inserts real Markdown blocks such as tables, headings, lists, callouts and code. Selecting text brings up a toolbar for bold, italic, strikethrough, inline code and links.
