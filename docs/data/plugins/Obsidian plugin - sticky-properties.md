# Sticky Properties

Configured properties are added to every new note and stamped on creation. Any property can be marked sticky from the Properties panel so that later notes receive it as well, with the property type detected automatically and date and time values stamped in.

```cue
plugin: {
    id:     "sticky-properties"
    name:   "Sticky Properties"
    author: "yaye.work"
    repo:   "yaye-work/obsidian-sticky-properties"

    html_url:    "https://community.obsidian.md/plugins/sticky-properties"
    github_url:  "https://github.com/yaye-work/obsidian-sticky-properties"
    description: "Get auto-added properties on your new notes. Assign/remove a property to be \"sitcky\" anytime. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add configurable properties to every new note and auto-stamp them on creation. Mark any property as sticky from the Properties panel to auto-add it to future notes, with automatic type detection and smart date/time stamping."

    stats: {
        downloads:  195
        updated_at: 1782693766000
    }
}
```
