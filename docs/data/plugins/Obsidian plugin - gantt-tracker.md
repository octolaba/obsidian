# Gantt Tracker

Renders Gantt charts from a YAML code block and tracks the plan against actual progress day by day. Delays, early finishes and pauses are colored automatically, and the chart carries vacation and day-off columns, background events, per-day comments and sticky headers. A touch-friendly sidebar provides compact navigation on mobile.
