# File Tree Alpha Hue

File Tree Alpha Hue colors file explorer items by the first alphabetical character of their name, exposed as a data-alpha-char attribute. Hues are assigned across a 360 degree HSL spectrum, so folders and Markdown files show muted resting colors. Styles are updated in a way that avoids forcing DOM layout reflows.
