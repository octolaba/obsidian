# Kindle Highlights Import

Imports a Kindle highlights export file and saves it as a note in the vault, converted into readable Markdown book notes. Highlights are formatted automatically, and both HTML and PDF Kindle exports are accepted.

```cue
plugin: {
    id:     "kindle-highlights-import"
    name:   "Kindle Highlights Import"
    author: "leonluttenberger"
    repo:   "leonluttenberger/obsidian-kindle-highlight-import"

    html_url:    "https://community.obsidian.md/plugins/kindle-highlights-import"
    github_url:  "https://github.com/leonluttenberger/obsidian-kindle-highlight-import"
    description: "Imports the Kindle highlights HTML file and saves it as a note in your vault."
    about:       "Import Kindle highlights into your Obsidian vault and convert them into readable Markdown book notes. Format highlights automatically for easy reading and accept HTML or PDF Kindle exports for quick, organized import."

    stats: {
        downloads:  1713

}
```
