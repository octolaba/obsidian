# Smooth Window Resize

Keeps the desktop window responsive while a long note is resized in Reading view, by batching the intermediate renders and applying the final update once resizing settles. It runs automatically on desktop with no settings, leaves note content and files untouched, and does not change Editing view or non-Markdown views. No telemetry is collected.

    id:     "smooth-window-resize"
