# Syncthing Manager

A control panel for Syncthing showing real-time file status, sync progress, connected devices and sync icons on tabs, on desktop and mobile. Conflict files are resolved through a side-by-side diff. The recorded About text also names managing the ignore list, pausing or resuming folders, forcing synchronization, and restoring previous file versions.

```cue
plugin: {
    id:     "syncthing-manager"
    name:   "Syncthing Manager"
    author: "Gustavo Carreiro"
    repo:   "gustjose/obsidian-syncthing-manager"

    html_url:    "https://community.obsidian.md/plugins/syncthing-manager"
    github_url:  "https://github.com/gustjose/obsidian-syncthing-manager"
    description: "Control panel for Syncthing. Monitor status, resolve conflicts, and force synchronization on Desktop and Mobile. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Control and monitor Syncthing from inside Obsidian with real-time file status, sync progress, connected device views, and visual sync icons on tabs. Resolve .sync-conflict files with a side-by-side diff, manage .stignore, pause or resume folders, and restore previous file versions."
```
