# Canvas Kit

Canvas Kit reworks the Obsidian canvas experience for a canvas-first, non-linear notetaking workflow. It supports drawing, quickly adding new or existing notes, dragging to make sections, and interactive tables. A local search tool inside the canvas helps navigate between the notes it holds.
