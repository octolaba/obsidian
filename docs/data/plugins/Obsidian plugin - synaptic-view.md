# Synaptic View

Provides a configurable dashboard that unifies hubs, notes, tasks, periodic notes and web resources behind buttons, and can replace the static homepage or the new tab. The recorded About text describes customizable smart buttons, one-click access to files, searches, commands and embedded views, and live task updates shown without opening the underlying notes.
