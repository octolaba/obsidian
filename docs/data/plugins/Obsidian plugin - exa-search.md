# Exa Search

Searches the web through Exa from inside Obsidian and inserts the results as formatted Markdown with links, dates and highlighted snippets. A search starts from the command palette or a hotkey, and the results are placed at the cursor or copied to the clipboard, on desktop and on mobile.

```cue
plugin: {
    id:     "exa-search"
    name:   "Exa Search"
    author: "10ishq"
    repo:   "exa-labs/obsidian-exa-search"

    html_url:    "https://community.obsidian.md/plugins/exa-search"
    github_url:  "https://github.com/exa-labs/obsidian-exa-search"
    description: "Search the web with Exa AI-native search and insert results directly into your notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Search the web from Obsidian with Exa and insert results as formatted Markdown, including links, dates, and highlighted snippets. Trigger searches from the command palette or a hotkey; results insert at the cursor or copy to clipboard and work on desktop and mobile."

    stats: {
        downloads:  94
        updated_at: 1782298976000
    }
}
```
