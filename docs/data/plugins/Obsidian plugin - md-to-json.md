# Markdown to JSON

Exports the current note as structured JSON blocks and copies them to the clipboard. Headings become h1 to h6 blocks, non-empty lines become body blocks and bullets become list blocks. The recorded text states that the output is shaped for a companion Figma plugin.

```cue
plugin: {
    id:     "md-to-json"
    name:   "Markdown to JSON"
    author: "Meghan Lendhe"
    repo:   "meghan-lendhe/md-to-json"

    html_url:    "https://community.obsidian.md/plugins/md-to-json"
    github_url:  "https://github.com/meghan-lendhe/md-to-json"
    description: "Copy a Markdown note as structured JSON blocks to the clipboard. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Export the current Obsidian note as structured JSON blocks optimized for the companion Figma plugin. Convert headings into h1–h6 blocks, split non-empty lines into body blocks, turn bullets into list blocks, and copy the JSON to the clipboard."

    stats: {
        downloads:  137
        updated_at: 1770467638000
    }
}
```
