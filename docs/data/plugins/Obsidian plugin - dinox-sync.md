# Dinox Sync

Syncs notes from Dinox into the vault and pushes Obsidian notes back, with incremental pulls that fetch only changed items. Synced files are organized into adjustable folder hierarchies and filename templates, and pulls can run periodically. The current note or a selected passage can be pushed as a new Dinox note.
