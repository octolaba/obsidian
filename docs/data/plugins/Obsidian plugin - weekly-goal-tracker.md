# Weekly Goal Tracker

Tracks daily and weekly goals from buttons in the status bar that show the current and target value and open into a coloured progress bar. Clicking a button raises or lowers the value directly, and tasks attached to a goal award points when they are completed. Progress is saved into the frontmatter of the daily or weekly note.

    id:     "weekly-goal-tracker"
    name:   "Weekly Goal Tracker"
