# Radar

Visualizes notes and ideas as blips on an interactive radar, grouped into category segments and prioritized by concentric rings, so several areas stay in view at once. Blips link to vault notes or exist as standalone text, the view is dragged, panned and zoomed freely, and a text blip is promoted to a note.
