# Hans TW TTS

Reads notes aloud with built-in system or browser voices for Traditional Chinese, working offline and without an external server. A dedicated reading pane highlights each sentence as it is spoken and auto-scrolls, with play, pause and skip controls. Whole folders can be queued for continuous reading, and a custom pronunciation dictionary covers names and ambiguous characters.
