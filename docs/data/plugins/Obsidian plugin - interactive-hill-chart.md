# Interactive Hill Chart

Interactive Hill Chart draws work progress as a hill chart with positions from 0 to 100, the peak marking the shift from uncertainty to execution. Dots are linked to notes and dragged to a new position, and each change is written back into the fenced hill-chart code block as plain YAML. Everything stays local inside the vault.
