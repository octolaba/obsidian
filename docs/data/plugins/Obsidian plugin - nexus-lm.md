# Nexus-LM

Nexus-LM turns the vault into a conversational AI workspace backed by more than 100 local or cloud models, so notes can be chatted with directly. From its Hub it also generates interactive study tools such as concept maps, slideshows and notebooks, runs code, manages RSS feeds as a personal feed, performs fast semantic search, and reaches outward through MCP and web search.
