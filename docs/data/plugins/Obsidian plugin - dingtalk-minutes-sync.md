# DingTalk Minutes Sync

Syncs DingTalk AI meeting records into the vault as Markdown, including AI summaries, keywords, todos and optionally the verbatim transcript. Files are named by the actual meeting start time, and an initial sync can cover 7, 30 or 365 days. Access goes through the locally logged-in DingTalk Workspace CLI, so no password, cookie or AppSecret is stored, and the plugin is desktop only.

    id:     "dingtalk-minutes-sync"
