# InkedMark

Adds handwriting inside markdown notes with pressure-aware ink, saved as plain files that the recorded inputs say sync, diff and link like any other note. Handwriting is recognized into a searchable text layer so that search, the graph, backlinks and the Quick Switcher index the ink content, and sketches can be embedded inline or linked as separate notes. The recorded inputs state that version 1.1.0 offers recognition either through a one-click cloud setup or a self-hosted model.
