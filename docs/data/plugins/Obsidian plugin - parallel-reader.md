# Parallel Reader

Presents a split view with the source note on the left and LLM-generated summary cards on the right, synced to the scroll position and highlighted while navigating. Summaries are adaptive and topic-aware with streaming output from more than twenty LLM providers, and the cached cards can be edited, exported, or used to jump back to the source.
