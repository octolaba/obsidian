# Outline to task list

Converts a note's outline into a Markdown task list. Its commands insert the resulting task list at the cursor or create a new note that holds it.

```cue
plugin: {
    id:     "outline-task-list"
    name:   "Outline to task list"
    author: "alexandrerbb"
    repo:   "alexandrerbb/obsidian-outline-tasklist-plugin"

    html_url:    "https://community.obsidian.md/plugins/outline-task-list"
    github_url:  "https://github.com/alexandrerbb/obsidian-outline-tasklist-plugin"
```
