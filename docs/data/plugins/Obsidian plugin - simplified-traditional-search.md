# Unified Chinese-characters Searcher (UCCS)

Unified Chinese-characters Searcher expands Chinese search terms in Obsidian global search so that a query matches Simplified, Traditional and the regional Hong Kong and Taiwan variants. It converts search operators and adds phrase-level supplements, so entering any Chinese character or term retrieves all the corresponding results.
