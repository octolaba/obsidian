# FolderFile Splitter

Splits folder lists and file lists into separate panels so that browsing and navigation stay clear. Items are pinned, lists are sorted, and the layout switches between horizontal and vertical. The panels follow the active Obsidian theme.

```cue
plugin: {
    id:     "folder-file-splitter"
    name:   "FolderFile Splitter"
    author: "xuquan-nikkkki"
    repo:   "xuquan-nikkkki/FolderFile-Splitter-Plugin"

    html_url:    "https://community.obsidian.md/plugins/folder-file-splitter"
    github_url:  "https://github.com/xuquan-nikkkki/FolderFile-Splitter-Plugin"
```
