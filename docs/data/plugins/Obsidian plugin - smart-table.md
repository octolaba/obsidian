# Smart Table

Tables are stored as fenced smart-table JSON blocks that render as editable grids in Reading view and Live Preview, so edits stay inside the note and sync with it. Columns are typed and can be sorted and filtered per column, headers are renamed inline, and columns and rows are added or removed. Status values are drawn as colored pills.
