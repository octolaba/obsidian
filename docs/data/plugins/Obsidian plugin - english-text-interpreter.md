# English Text Interpreter

Interprets a selected English passage with a local LLM served by Ollama, so the text stays on the machine. A panel breaks the result into meaning, tone, context and intent, and the language of the interpretation is configurable to Spanish, French, German or Portuguese.

    id:     "english-text-interpreter"
    name:   "English Text Interpreter"
    author: "julioagh"
    repo:   "julioagh/english-text-interpreter"

    html_url:    "https://community.obsidian.md/plugins/english-text-interpreter"
    github_url:  "https://github.com/julioagh/english-text-interpreter"
    description: "Contextual interpretation of selected English text powered by a local LLM (Ollama). Explains meaning, tone, cultural context and intent. - This plugin has not been manually reviewed by Obsidian staff."
