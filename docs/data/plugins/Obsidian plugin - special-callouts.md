# Special Callouts

Callouts are styled beyond the built-in set with grid layouts, custom colors, gradients, neon-style glows and multi-column lists, all through inline syntax. Callouts are arranged side by side with a chosen column count, and a named style is saved for reuse.

```cue
plugin: {
    id:     "special-callouts"
    name:   "Special Callouts"
    author: "ahseyg"
    repo:   "ahseyg/special-callouts"

    html_url:    "https://community.obsidian.md/plugins/special-callouts"
    github_url:  "https://github.com/ahseyg/special-callouts"
    description: "Advanced callout styling with grid layouts, custom colors, gradients, glow effects, and multi-column support. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create advanced callouts with grid layouts, custom colors, gradients, neon-style glows and multi-column lists using simple inline syntax. Arrange callouts side-by-side, control column counts, and save named styles for reuse."
```
