# Media Journal

Tracks books, movies, TV shows and variety programs from daily notes, using tags together with one-line title and short-review entries. Records are browsable and monthly statistics are filtered by year and month. The application title and the media type labels are customizable.

```cue
plugin: {
    id:     "media-journal"
    name:   "Media Journal"
    author: "fengshuzi"
    repo:   "fengshuzi/media-journal"

    html_url:    "https://community.obsidian.md/plugins/media-journal"
    github_url:  "https://github.com/fengshuzi/media-journal"
    description: "Track books, movies, TV, and shows from daily notes with tags, comments, and monthly stats. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Track books, movies, TV shows, and variety programs from daily notes using flexible tags and one-line title plus short-review entries. View browsable records and monthly stats with year/month filters and customize the app title and media type labels."

    stats: {
        downloads:  260
        updated_at: 1785815236000
    }
}
```
