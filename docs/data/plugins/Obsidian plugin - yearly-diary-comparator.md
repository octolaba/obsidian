# Yearly Diary Comparator

Places daily notes for the same calendar date in different years side by side in a calendar view. The diary summary filling each column is extracted from a configured headline in the daily note, so entries can be compared year over year.

```cue
plugin: {
    id:     "yearly-diary-comparator"
    name:   "Yearly Diary Comparator"
    author: "kiitosu"
    repo:   "kiitosu/yearly-diary-comparator"

    html_url:    "https://community.obsidian.md/plugins/yearly-diary-comparator"
    github_url:  "https://github.com/kiitosu/yearly-diary-comparator"
    description: "Show a side-by-side yearly comparison of diary in daily notes."
    about:       "Compare daily notes across years in a calendar view by displaying entries for the same date side by side. Extract diary summaries from a headline in each daily note to populate columns and spot changes, trends, and personal growth year over year."

    stats: {
        downloads:  305
        updated_at: 1747731813000
    }
}
```
