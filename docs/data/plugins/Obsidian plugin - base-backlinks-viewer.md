# Base Backlinks Viewer

Base Backlinks Viewer adds a Show backlinks entry to the right-click menu of any internal link, opening a reusable live Bases view filtered to every note that links to that page instead of the standard backlinks pane. Sorting, columns and layouts are customizable and persist between searches. It also works for unresolved links, so a category-style link can act as a topic hub without a dedicated note or a separate base file.
