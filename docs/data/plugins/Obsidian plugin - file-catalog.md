# XU File Catalog

XU File Catalog generates a clickable, hierarchical table of contents from the headings of any Markdown file, written as a filecatalog code block or inserted by command. Obsidian file links are rendered, and heading levels, styling and hotkeys are configurable, with conflict detection for the hotkeys. It is offered as a drop-in replacement for a DataviewJS filecatalog and does not need Dataview.

```cue
plugin: {
    id:     "file-catalog"
    name:   "XU File Catalog"
    author: "xcloud-ai"
    repo:   "xcloud-ai/file-catalog"

    html_url:    "https://community.obsidian.md/plugins/file-catalog"
    github_url:  "https://github.com/xcloud-ai/file-catalog"
    description: "Generate clickable table of contents from any Markdown file headings. Supports dynamic code block rendering, command insertion, custom heading levels, styling, and hotkey configuration with conflict detection. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Generate a clickable, hierarchical table of contents from any Markdown file's headings using filecatalog code blocks or the insert command. Render Obsidian [[file]] links, choose which heading levels and styling appear, and use as a drop-in DataviewJS filecatalog replacement without needing Dataview."
```
