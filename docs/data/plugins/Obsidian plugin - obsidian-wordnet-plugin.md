# WordNet Dictionary

English words are looked up in Princeton's WordNet lexical database and matching senses are browsed while typing. A chosen word or its definition is inserted into the current note, or shown in a brief notification when the note is in preview mode.

```cue
plugin: {
    id:     "obsidian-wordnet-plugin"
    name:   "WordNet Dictionary"
    author: "tfthacker"
    repo:   "tfthacker/Obsidian-WordNet"

    html_url:    "https://community.obsidian.md/plugins/obsidian-wordnet-plugin"
    github_url:  "https://github.com/tfthacker/Obsidian-WordNet"
    description: "A large lexical database of English developed by Princeton University."
    about:       "Look up English words from Princeton's WordNet and browse matching senses as you type. Insert chosen words or their definitions into the current note, or display definitions in a brief notification when the note is in preview mode."
```
