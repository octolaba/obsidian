# TaskNotes Project Colors

TaskNotes Project Colors colors TaskNotes task cards by project, deriving each hue from a hash of the project name so the assignment is deterministic. Every project gets a distinct background tint and a colored left border, applied across the kanban, task list and agenda views, with light and dark theme support.
