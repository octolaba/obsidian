# Natural link

Creates links by typing a word in its natural form, matching notes regardless of inflection, word order or incomplete words. Titles, aliases, headings and blocks are searched using Russian and English morphology, with live prefix results. Accepting a completion preserves the displayed wording while writing a clean wikilink.
