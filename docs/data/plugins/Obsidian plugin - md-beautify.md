# MD Beautify

MD Beautify converts Markdown into styled rich text with themes aimed at WeChat and other rich-text editors. A live preview scrolls in sync with the note, and the result exports to HTML or PDF. Mermaid diagrams are rendered, local images can be batch-uploaded to cloud storage, and the styles can be adjusted in a built-in CSS editor.
