# QuickShare

This plugin shares notes in one click, described as end-to-end encrypted with AES-256-CBC and single-use keys and requiring no API keys or configuration. Encrypted notes are sent to Noteshare.space or to storage you host yourself, so sharing works without accounts while the decryption key stays local. Those encryption and locality statements are the project's own, recorded here as stated.
