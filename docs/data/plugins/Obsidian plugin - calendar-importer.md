# Calendar Importer

Calendar Importer converts iCal and ICS calendar feeds, including Google Calendar, Outlook, iCloud and Zoho, into Markdown tasks. The recorded inputs present it as a way to bring dates from a calendar shared with someone who does not use Obsidian into the vault without retyping them.

```cue
plugin: {
    id:     "calendar-importer"
    name:   "Calendar Importer"
    author: "Efficient X Group"
    repo:   "efficient-x/Calendar-Importer"

    html_url:    "https://community.obsidian.md/plugins/calendar-importer"
    github_url:  "https://github.com/efficient-x/Calendar-Importer"
    description: "Bring external calendar events into your task notes without retyping them. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Calendar Importer turns Google Calendar, Outlook, iCloud, Zoho, and other iCal/ICS calendar feeds into clean markdown tasks. Using a shared calendar with someone who has not yet found the warm glow of Obsidian? Let them keep adding events in their calendar app while Calendar Importer quietly brings those dates into your vault. Boom! Less double entry, and more obsidian time for you. How good!"

    stats: {
        downloads:  382

    }
}
```
