# Auto Sidebar

Auto Sidebar hides the left sidebar offscreen and reveals it when the pointer reaches the left edge, giving a compact overlay with CSS animations. The compact-mode state and the sidebar width are remembered across restarts, the sidebar can hide on window blur or mouse leave, and the mode toggles from the command palette. Its recorded About states that the plugin is desktop only and makes no external network requests.
