# Image Captions

Image Captions renders a caption beneath an image from text placed in the wiki-style or Markdown image syntax, in a format the plugin states is compatible with the CommonMark spec and other Markdown applications. Width and alignment parameters resize and place the image, captions accept inline Markdown and links, a percent sign inserts the filename, and a regular expression can clean the caption text.

```cue
plugin: {
    id:     "image-captions"
    name:   "Image Captions"
    author: "Alan Grainger"
    repo:   "alangrainger/obsidian-image-captions"

    html_url:    "https://community.obsidian.md/plugins/image-captions"
    github_url:  "https://github.com/alangrainger/obsidian-image-captions"
    description: "Add captions to images with inline Markdown and link support. The caption format is compatible with the Commonmark spec and other Markdown applications."
    about:       "Add captions to images by placing text in wiki-style or Markdown image syntax and render it beneath the image. Resize and align images with width and alignment parameters, include inline Markdown or links in captions, use % to insert the filename, and apply a regex to clean caption text."

    stats: {
        downloads:  60547
        updated_at: 1763303084000
    }
}
```
