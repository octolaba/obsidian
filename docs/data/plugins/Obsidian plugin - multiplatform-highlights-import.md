# Multiplatform Highlights Importer

Imports highlights and annotations from Kobo and Apple Books into the vault. Books are reconciled across those reading sources by ISBN or title, so all highlights for one book consolidate into a single standardized note.

```cue
plugin: {
    id:     "multiplatform-highlights-import"
    name:   "Multiplatform Highlights Importer"
    author: "wwwkieran"
    repo:   "wwwkieran/obsidian-multiplatform-highlights-import"

    html_url:    "https://community.obsidian.md/plugins/multiplatform-highlights-import"
    github_url:  "https://github.com/wwwkieran/obsidian-multiplatform-highlights-import"
    description: "Import and consolidate highlights from different reading sources. Supports reconciling books across reading sources."
```
