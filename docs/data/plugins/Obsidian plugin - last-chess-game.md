# Last Chess Game

Last Chess Game fetches the most recent Chess.com game and inserts it into a note, selected by time control such as bullet, blitz, rapid or daily, or taken as any type. The inserted output is driven by templates with handlebars, so game metadata, times, moves and information about the other player can be laid out as wanted.

```cue
plugin: {
    id:     "last-chess-game"
    name:   "Last Chess Game"
    author: "eddie-d0"
    repo:   "eddie-d0/last-chess-game"

    html_url:    "https://community.obsidian.md/plugins/last-chess-game"
    github_url:  "https://github.com/eddie-d0/last-chess-game"
    description: "Quickly pull your latest game from Chess.com and insert it directly into your daily note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Pull and insert your latest Chess.com game into any note, choosing by time control (bullet, blitz, rapid, daily) or any type. Customize the output with flexible templates and handlebars to display game metadata, times, moves and other players' info."

    stats: {
        downloads:  90
        updated_at: 1763321382000
    }
}
```
