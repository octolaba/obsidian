# Rule Engine

Rule Engine defines rules that run commands and render custom HTML views for the notes they match. Files are matched with filters over frontmatter, tags and file properties, and the commands run in order when a note is opened or on demand. Markdown can be rendered inside HTML templates to produce cards, dashboards or other custom presentations.
