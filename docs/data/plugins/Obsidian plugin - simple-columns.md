# Simple Columns

Simple Columns creates and manages column layouts in notes through a short markdown syntax or a command. Up to four columns are inserted, each with a unique ID, they can hold code blocks, and their widths are set as YAML ratios. Columns are resizable and can carry borders for clearer structure.
