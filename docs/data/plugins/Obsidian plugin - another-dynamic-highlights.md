# aDHL

Creates persistent static highlighters from a search string or a regular expression, with capture-group support for precise matching. Highlighters carry colors, styles and tags, can be toggled by command, and can be imported and exported as sets. A minimum selection length is configurable, down to single Chinese characters. It is based on Dynamic Highlights and works alongside Highlightr.
