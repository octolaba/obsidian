# Qlaude

Runs Claude Code CLI commands against the vault from a modal, so notes are read, edited and created with the streamed Markdown rendered live. Quick-action one-shot prompts and a chat mode with resumable multi-turn history are both offered, and any Claude model can be chosen. The recorded inputs state that Obsidian conventions such as wikilinks and YAML frontmatter are recognized.

    id:     "qlaude"
    name:   "Qlaude"

    github_url:  "https://github.com/ziadkadry99/Qlaude"

Use quick-action one-shot prompts or chat mode with resumable multi-turn history, choose any Claude model, and stream edits in real time. Recognize [[wikilinks]], YAML frontmatter, and Obsidian conventions."
