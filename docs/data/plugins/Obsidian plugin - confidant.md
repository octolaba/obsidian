# Confidant

Generates weekly, biweekly, monthly and yearly reflective summaries of a daily journal, surfacing shifts, repetitions and underlying themes across entries. Thirteen frameworks are offered, among them CBT, ACT, narrative, Stoic and IFS. Models run locally through an OpenAI-compatible server by default, with OpenRouter available as a cloud mode, and a three-tier memory system carries context between summaries.
