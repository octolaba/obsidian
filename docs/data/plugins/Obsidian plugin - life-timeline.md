# Life Timeline

Life Timeline keeps a timeline in a single JSON file inside the vault, grouping events into coloured eras that carry their own descriptions. Events have a start date and an optional end date, and both eras and events are edited inline from a note, reordered and collapsed.

```cue
plugin: {
    id:     "life-timeline"
    name:   "Life Timeline"
    author: "kellybrendan"
    repo:   "kellybrendan/obsidian-life-timeline"

    html_url:    "https://community.obsidian.md/plugins/life-timeline"
    github_url:  "https://github.com/kellybrendan/obsidian-life-timeline"
    description: "A JSON-based life timeline. Group events under colored eras, add events with date ranges, and edit everything inline. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create a JSON-based life timeline inside your vault and group events into colored eras with descriptions. Add events with start and optional end dates, edit eras and events inline from notes, reorder and collapse eras while keeping all data in a portable JSON file."

    stats: {
        downloads:  37
        updated_at: 1784468940000
    }
}
```
