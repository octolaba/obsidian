# Icon Shortcodes

Inserts emoji and custom icons through shortcodes with fuzzy search, rendering them inline in the editor. Custom icon packs in bmp, png, jpg, jpeg, gif, svg and webp formats are imported and managed, alongside built-in Unicode emoji, Lucide, and downloadable FontAwesome and Remixicon packs.

    id:     "obsidian-icon-shortcodes"
    name:   "Icon Shortcodes"
    author: "Aiden Liu"
    repo:   "aidenlx/obsidian-icon-shortcodes"

    html_url:    "https://community.obsidian.md/plugins/obsidian-icon-shortcodes"
    github_url:  "https://github.com/aidenlx/obsidian-icon-shortcodes"
    description: "Insert emoji and custom icons with shortcodes."
    about:       "Insert emoji and custom icons with GitHub-style shortcodes and fuzzy search, rendering them inline in the editor. Import and manage custom icon packs (bmp, png, jpg, jpeg, gif, svg, webp) and use built-in Unicode emoji, Lucide, or downloadable Font Awesome and Remixicon packs."
