# Pocket Bird

Adds a pixel-art bird that flutters around the screen while you write, presented as a desktop pet for the vault. Feathers can be caught to unlock further birds, hats collected across webpages, and sticky notes used to keep track of thoughts. The recorded description states that the plugin is open source.
