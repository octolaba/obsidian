# Pinned Daily Notes

Pinned Daily Notes opens today's daily note in a pinned tab from a ribbon icon or a command. If no pinned tab exists one is created, and otherwise the existing pinned daily note is updated and focused so it shows today's note. Any daily-note folder and format is supported, and the configured Daily Notes settings are respected.

```cue
plugin: {
    id:     "pinned-daily-notes"
    name:   "Pinned Daily Notes"
    author: "docmarionum1"
    repo:   "docmarionum1/obsidian-pinned-daily-notes"

    html_url:    "https://community.obsidian.md/plugins/pinned-daily-notes"
    github_url:  "https://github.com/docmarionum1/obsidian-pinned-daily-notes"
    description: "Dynamically update a pinned tab with today's daily note"
    about:       "Open today's daily note in a pinned tab via the ribbon icon or command. Create a pinned tab if none exists, or update and focus the existing pinned daily note to show today's note. Support any daily-note folder/format and respect your Daily Notes settings."

    stats: {
        downloads:  1344
        updated_at: 1749603099000
    }
}
```
