# Notes Bridge

Notes Bridge exports notes as portable Markdown and bridges the vault with Bear, WPS Cloud Note, Youdao Note and Flomo through their official clients. Obsidian-specific syntax such as wikilinks, embeds, callouts, frontmatter and attachment paths is converted to standard Markdown, then copied to the clipboard or written to a folder. Notes can be sent and imported, degrading gracefully on mobile.
