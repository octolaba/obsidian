# Color Preview

Color Preview renders hex codes as interactive color cards showing hex, RGB, CMYK and PMS values with click-to-copy. Palette blocks display as horizontal strips, inline dot previews sit beside any hex code, and a color picker edits a swatch and updates the hex in place.
