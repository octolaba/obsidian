# Draw in Canvas

Adds freehand drawing, sketching and handwriting on Obsidian JSON Canvas files with mouse, touch or stylus input and pressure sensitivity. Color, size, opacity and hardness are adjustable, strokes can be edited or multi-selected, and actions undone or redone. Drawings are saved inside the .canvas file locally and are visible only when the feature is enabled.
