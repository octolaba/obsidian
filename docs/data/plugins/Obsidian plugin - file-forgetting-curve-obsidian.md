# File Forgetting Curve

File Forgetting Curve tracks files on a forgetting schedule by grouping them under labels and giving each a custom name and remark. Expiration reminders are scheduled and review dates are picked with a date selector. A dedicated forgetting-curve view collects the items and carries translation support.
