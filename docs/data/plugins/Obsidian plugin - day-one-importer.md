# Day One Importer

Converts a Day One journal exported as JSON into Obsidian Markdown, bringing images and videos inline and writing metadata into frontmatter. Tags, the starred, pinned and all-day flags, location and activity are preserved, files are named by date or by UUID, and entries that fail to import are logged to a Failed Imports note.

```cue
plugin: {
    id:     "day-one-importer"
    name:   "Day One Importer"
    author: "marcdonald"
    repo:   "marcdonald/obsidian-day-one-importer"

    html_url:    "https://community.obsidian.md/plugins/day-one-importer"
    github_url:  "https://github.com/marcdonald/obsidian-day-one-importer"
    description: "Import Day One journals."
    about:       "Convert Day One journals exported as JSON into Obsidian Markdown with inline images and videos and frontmatter metadata. Preserve tags, starred/pinned/all-day flags, location and activity, create date- or UUID-named files, and log any failed imports to Failed Imports.md."

    stats: {
        downloads:  3237
        updated_at: 1774268118000
    }
}
```
