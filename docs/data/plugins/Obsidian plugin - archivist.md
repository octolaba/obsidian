# Archivist

Backs up the vault to Dropbox on a schedule, using versioned content-addressed storage that deduplicates identical files. Per-file history can be browsed and any version restored to its original location or to a new one. A bundled command-line tool performs offline recovery directly from the Dropbox folder.
