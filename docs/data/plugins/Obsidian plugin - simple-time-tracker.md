# Super Simple Time Tracker

Super Simple Time Tracker inserts a time tracker into any note, where named segments are started and ended to record durations. Trackers render in live preview and reading mode, and their entries are saved and summarized in a table. A public API lets Dataview and DataviewJS load trackers and compute totals across the vault.
