# Simple Command Panel

Simple Command Panel opens a searchable command panel from a trigger character or from a command. Entries take custom display names with hidden search text and optional descriptions, so labels stay short while remaining findable. An entry can insert text or execute JSON-formatted scripts covering insert, command, move, delete, select and data actions, and query parameters can be passed to them.
