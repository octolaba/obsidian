# Markdownlint

Markdownlint runs markdownlint over the vault's Markdown files and highlights the issues it finds directly in the editor, so file contents stay consistent. Rules are read from a .markdownlint.json, .markdownlint.jsonc, .markdownlint.yaml or .markdownlint.yml configuration file, and problems can be fixed while editing.

```cue
plugin: {
    id:     "markdownlint"
    name:   "Markdownlint"
    author: "ebullient"
    repo:   "ebullient/obsidian-markdownlint"

    html_url:    "https://community.obsidian.md/plugins/markdownlint"
    github_url:  "https://github.com/ebullient/obsidian-markdownlint"
    description: "Use markdownlint to make the contents of your files more consistent. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Lint Markdown files in your vault with markdownlint and highlight issues directly in the editor. Apply rules from .markdownlint.json, .markdownlint.jsonc, .markdownlint.yaml, or .markdownlint.yml configuration files and fix problems as you edit."

    stats: {
        downloads:  4409
        updated_at: 1780503469000
    }
}
```
