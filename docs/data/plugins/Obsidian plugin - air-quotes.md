# Air Quotes

Inserts direct quotes from a linked source text into the current note as you type, matching near-instantly with an adjustable quote length. ePub files can be imported into Markdown source notes so passages can be searched and pulled quickly while reading.

```cue
plugin: {
    id:     "air-quotes"
    name:   "Air Quotes"
    author: "Alan Grainger"
    repo:   "alangrainger/obsidian-air-quotes"

    html_url:    "https://community.obsidian.md/plugins/air-quotes"
    github_url:  "https://github.com/alangrainger/obsidian-air-quotes"
    description: "Search and insert quotes from a source text as you type."
    about:       "Insert direct quotes from a linked source text into the current note with near-instant matching and adjustable quote length. Import ePub files into Markdown source notes to search and pull passages quickly while reading."

}
```
