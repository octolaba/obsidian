# Download Image

Downloads the remote images linked from the active note into the vault and rewrites the note to reference the local attachment paths, so the note works offline. It can also scan for orphaned attachments, show the results for review, and move them to .trash or delete them permanently.

```cue
plugin: {
    id:     "download-image"
    name:   "Download Image"
    author: "yinshaohua"
    repo:   "yinshaohua/obsidian-download-image"

    html_url:    "https://community.obsidian.md/plugins/download-image"
    github_url:  "https://github.com/yinshaohua/obsidian-download-image"
    description: "Download remote images in the current note to local vault storage. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Save remote image links from the active note into your vault and rewrite the note to reference local attachment paths for offline, self-contained notes. Clean unused attachments by scanning for orphaned files, reviewing results, and moving them to .trash or deleting them permanently."

    stats: {
        downloads:  135
        updated_at: 1779083117000
    }
}
```
