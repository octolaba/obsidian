# Long sentence highlighter

Highlights sentences longer than a configurable word-count threshold, which the recorded description frames as an aid to writing clarity and readability. Marks are drawn as a background or an underline in custom colors, checks run automatically or manually, and the highlights update in real time in both editing and reading mode.

```cue
plugin: {
    id:     "long-sentence-highlighter"
    name:   "Long sentence highlighter"
    author: "robertmeissner"
    repo:   "robertmeissner/obsidian-long-sentence-highlighter"

    html_url:    "https://community.obsidian.md/plugins/long-sentence-highlighter"
    github_url:  "https://github.com/robertmeissner/obsidian-long-sentence-highlighter"
    description: "Highlights sentences that exceed a configurable word count threshold to help improve writing clarity and readability."
    about:       "Highlight sentences that exceed a configurable word-count threshold to keep prose concise. Use background or underline marks with custom colors and toggle automatic or manual checks; highlights update in real time in both edit and reading modes."

    stats: {
        downloads:  577
        updated_at: 1758787482000
    }
}
```
