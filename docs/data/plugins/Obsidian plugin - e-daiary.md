# e-Daiary

Creates daily journal entries organized by year and by day of the year, in timestamped folders. Each session produces a Markdown file named after the day number and its date and time, which keeps the journal chronological.

```cue
plugin: {
    id:     "e-daiary"
    name:   "e-Daiary"
    author: "wholetomy"
    repo:   "wholetomy/obsidian-e-daiary"

    html_url:    "https://community.obsidian.md/plugins/e-daiary"
    github_url:  "https://github.com/wholetomy/obsidian-e-daiary"
    description: "Creates directories and notes based on the day of the year."
    about:       "Create daily journal entries organized by year and day-of-year in timestamped folders and Markdown files. Generate a Day X (DD-MM-YYYY HH-mm).md entry for each session to keep a consistent, chronological journal."

    stats: {
        downloads:  392
        updated_at: 1735909545000
    }
}
```
