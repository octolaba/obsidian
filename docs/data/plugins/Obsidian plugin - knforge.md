# KnForge

Generates self-contained Markdown packages from selectable templates inside the vault. Choosing a template and a name produces a predictable package folder and Markdown file, optionally with subfolders and YAML frontmatter. Date, title and unique-identifier substitutions are applied, and the generated note opens immediately.
