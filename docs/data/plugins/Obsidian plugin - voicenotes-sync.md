# Voicenotes Sync

Voicenotes Sync pulls Voicenotes.com web and mobile entries into the vault as Markdown notes, embedding the service's AI-generated summaries and actions as note sections. Detected TODOs become Markdown todos, and the associated audio files are downloaded. The target directory, the sync frequency and optional deletion on the server are configurable.

```cue
plugin: {
    id:     "voicenotes-sync"
    name:   "Voicenotes Sync"
    author: "voicenotes-community"
    repo:   "voicenotes-community/voicenotes-sync"

    html_url:    "https://community.obsidian.md/plugins/voicenotes-sync"
    github_url:  "https://github.com/voicenotes-community/voicenotes-sync"

Convert detected TODOs into Markdown todos and download associated audio files. Save to a custom directory with configurable sync frequency and optional server deletion."
