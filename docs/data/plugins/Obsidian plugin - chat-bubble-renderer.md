# Chat Bubble Renderer

Chat Bubble Renderer draws Markdown chat logs carrying a chat tag as bubble dialogs in the style of WeChat. It parses standard message headers, quoted replies, merge-forward cards and internal links, placing other participants on the left and the note's owner on the right, with inline media previews. Colors follow the theme and the conversation is shown in a fullscreen overlay.
