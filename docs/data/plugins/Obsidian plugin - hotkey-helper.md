# Hotkey Helper

Hotkey Helper adds icons beside each entry in the Core and Community plugin lists that open that plugin's settings or its hotkey assignments. Hovering an icon shows the plugin's command count, assigned hotkeys and conflicts, and the icons update automatically and highlight conflicts.

```cue
plugin: {
    id:     "hotkey-helper"
    name:   "Hotkey Helper"
    author: "pjeby"
    repo:   "pjeby/hotkey-helper"

    html_url:    "https://community.obsidian.md/plugins/hotkey-helper"
    github_url:  "https://github.com/pjeby/hotkey-helper"
    description: "Easily see and access any plugin's settings or hotkey assignments (and conflicts) from the Community Plugins tab."
    about:       "Manage plugins' hotkeys and settings from the Core and Community plugin lists using icons beside each plugin to open its options or hotkey assignments. Hover icons to see command counts, assigned hotkeys and conflicts; icons update automatically and highlight conflicts."

    stats: {
        downloads:  86215

    }
}
```
