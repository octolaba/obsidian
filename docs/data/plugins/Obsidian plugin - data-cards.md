# DataCards

Turns Dataview query results into card layouts or interactive kanban boards. Presets and per-block overrides control the rendering, images can come from frontmatter, wikilinks or Markdown, and the columns are responsive or fixed. Items are edited inline, created from the view, and refreshed manually, with layouts adapted to mobile.
