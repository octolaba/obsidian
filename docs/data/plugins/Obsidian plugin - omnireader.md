# Omni Reader

Reads EPUB 2 and EPUB 3 files locally, with paginated or scrolled views, nested tables of contents, full-book search, bookmarks and restored reading position. Highlights, underlines, strikethroughs and squiggles can be applied in several colors, and notes attached to a highlight. Annotations are exported and synced as one Markdown file per book with Obsidian CFI links, and can be filtered and exported from the sidebar. A bookshelf, focus mode and reading statistics round out the workbench.
