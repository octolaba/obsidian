# Three D Graph View

Three D Graph View presents the vault as a graph that rotates in 3D space, revealing notes, links, backlinks, tags and how the vault grew over time. Its spherical core-to-surface layout is rotated, panned and zoomed, tags carry their own colors, hovering highlights connections, and a timelapse replays note creation.
