# Vault Changelog

A dedicated note is maintained as a changelog of recently edited files. It is updated on command or automatically, in which case the note is overwritten, and its entries use wiki-links, a configurable date format and a capped number of recent files.

```cue
plugin: {
    id:     "obsidian-vault-changelog"
    name:   "Vault Changelog"
    author: "Mark Ayers"
    repo:   "philoserf/obsidian-vault-changelog"

    html_url:    "https://community.obsidian.md/plugins/obsidian-vault-changelog"
    github_url:  "https://github.com/philoserf/obsidian-vault-changelog"
    description: "Maintain a changelog of recently edited notes."
    about:       "Maintain a changelog of recently edited notes in your vault. Update it manually or enable auto-update to overwrite a dedicated note with the latest edits, using wiki-links, configurable date format, and a capped number of recent files."

    stats: {
        downloads:  22325
        updated_at: 1782929491000
    }
}
```
