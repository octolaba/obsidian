# Go to Line

Adds a Go to Line command that jumps to a specific line and character in the active note from the command palette. Clipboard line and column data can be applied to position cursors, and the primary cursor position or all cursor positions can be copied back to the clipboard.

```cue
plugin: {
    id:     "obsidian-go-to-line"
    name:   "Go to Line"
    author: "phibr0"
    repo:   "phibr0/obsidian-go-to-line"

    html_url:    "https://community.obsidian.md/plugins/obsidian-go-to-line"
    github_url:  "https://github.com/phibr0/obsidian-go-to-line"
```
