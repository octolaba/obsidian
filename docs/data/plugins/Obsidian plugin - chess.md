# Chess

Plays chess against a built-in offline engine in a workspace pane, with games persisting between sessions. Ten measured difficulty levels can be selected, with optional auto-adjust, an opening book and a clock. Moves can be made by mouse or keyboard, illegal moves produce a clear message, and an arrow marks the engine's last move.
