# Amazing Marvin

This plugin gets data from the Marvin task service and shows its tasks in Obsidian's right sidebar as a list or as a week or month calendar. The connection uses an API token from that service, and task queries are written as JSON blocks that render due items, scheduled tasks, notes and coloured labels.

    id:     "obsidian-amazingmarvin-plugin"
    name:   "Amazing Marvin"
