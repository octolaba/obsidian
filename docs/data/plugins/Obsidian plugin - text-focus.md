# Text Focus

Text Focus moves focus into the editor text area when a new note is opened, so typing starts immediately. It removes the click that would otherwise be needed before writing, which speeds up quick capture.

```cue
plugin: {
    id:     "text-focus"
    name:   "Text Focus"
    author: "usysrc"
    repo:   "usysrc/obsidian-text-focus-plugin"

    html_url:    "https://community.obsidian.md/plugins/text-focus"
```
