# HamsterBase Official

Exports highlights from HamsterBase into the vault as Markdown files. A single command syncs them through the HamsterBase API into a chosen folder.

```cue
plugin: {
    id:     "hamsterbase"
    name:   "HamsterBase Official"
    author: "hamsterbase"
    repo:   "hamsterbase/obsidian-hamsterbase"

    html_url:    "https://community.obsidian.md/plugins/hamsterbase"
    github_url:  "https://github.com/hamsterbase/obsidian-hamsterbase"
    description: "Export highlights from HamsterBase into your vault."
    about:       "Export highlights from HamsterBase into your Obsidian vault as Markdown files. Sync highlights via the HamsterBase API to save them into a chosen folder with a single command."

    stats: {
        downloads:  3685
        updated_at: 1689684517000
    }
}
```
