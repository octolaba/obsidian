# Claude Anywhere

Reaches a Mac's Claude Code session from a phone or tablet through a remote relay server, so files on that machine can be edited from another device, including notes, code repositories and configuration files. Claude skills and full terminal commands such as Git, npm and scripts run over the same connection, and a conversation is picked up again with the resume command.

```cue
plugin: {
    id:     "claude-anywhere"
    name:   "Claude Anywhere"
    author: "derek-larson14"
    repo:   "derek-larson14/obsidian-claude-anywhere"

    html_url:    "https://community.obsidian.md/plugins/claude-anywhere"
    github_url:  "https://github.com/derek-larson14/obsidian-claude-anywhere"
    description: "Run Claude Code from any device via remote relay server. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Access your Mac's Claude Code from phone or tablet and edit files across your Mac — notes, code repos, and config files. Run your Claude skills and full terminal commands (Git, npm, scripts), and resume conversations with /resume to pick up where you left off."

    stats: {
        downloads:  1772
        updated_at: 1778983060000
    }
}
```
