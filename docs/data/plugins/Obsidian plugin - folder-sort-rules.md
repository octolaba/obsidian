# Folder Sort Rules

Defines a custom sort order per folder that overrides the global file explorer sorting. Files and subfolders take independent orders, rules can apply recursively, and seven orders cover name, modified, created and manual. The manual order is arranged by drag-and-drop.

```cue
plugin: {
    id:     "folder-sort-rules"
    name:   "Folder Sort Rules"
    author: "wepee"
    repo:   "wepee/obsidian-folder-sort-rules"

    html_url:    "https://community.obsidian.md/plugins/folder-sort-rules"
    github_url:  "https://github.com/wepee/obsidian-folder-sort-rules"
    description: "Define custom sort orders per folder, overriding the global file explorer sorting with independent rules for files and subfolders. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Define custom sort orders per folder in your vault and override the global file explorer sorting. Set independent sort orders for files and subfolders, apply rules recursively, choose from seven orders (name, modified, created, or manual), and reorder items via drag-and-drop."

    stats: {
        downloads:  1228
        updated_at: 1773583090000
    }
}
```
