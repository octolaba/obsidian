# Personal OS

Personal OS selects and processes the next file that needs attention, opens the appropriate workspace and directs focus using GTD-inspired inbox and work-in-progress rules. Items can be snoozed randomly within a date range, and overdue or recurring tasks can be marked as failed across the current file or the whole vault. The recorded description frames this as task management with a gamification element.
