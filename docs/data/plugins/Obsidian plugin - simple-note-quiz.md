# Simple Note Quiz

Simple Note Quiz turns the current note into a quiz built from its question-and-answer lines. Lines ending with a question mark are parsed into question and answer cards, with bullet points available as separators instead. Answered cards are marked correct or wrong on the note itself, which is how progress and scores are tracked.

```cue
plugin: {
    id:     "simple-note-quiz"
    name:   "Simple Note Quiz"
    author: "beginner137"
    repo:   "beginner137/Obsidian-simple-note-quiz"

    html_url:    "https://community.obsidian.md/plugins/simple-note-quiz"
    github_url:  "https://github.com/beginner137/Obsidian-simple-note-quiz"
    description: "Start a simple quiz on your current note."
    about:       "Create a simple quiz from the current note's Q&A lines. Parse lines ending with a question mark (or use bullet points as separators) into question/answer cards, present cards to answer, and mark items Correct or Wrong directly on the note to track progress and scores."

    stats: {
        downloads:  5591

}
```
