# Commander

Places Obsidian commands in parts of the interface beyond the command palette, with custom placement and, for Sync users, device-specific visibility. Commands added by Obsidian itself or by other plugins can be edited, reordered, hidden or removed. Macros and mobile toolbar customization belong to the same set of controls.
