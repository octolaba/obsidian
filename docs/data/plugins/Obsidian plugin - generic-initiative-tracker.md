# Generic Initiative Tracker

Tracks initiative for tabletop role-playing encounters in a right-pane view that lists and orders players and creatures. Encounters are launched from encounter code blocks in a note, names render as internal links, duplicate names are indexed automatically, and initiative modifiers accept dice strings.
