# Daily Stats

Daily Stats tracks the day's word count and shows it in the bottom-right corner of Obsidian. A right-side panel presents the historical log as a contribution-style heatmap, so writing streaks and trends can be followed.

```cue
plugin: {
    id:     "obsidian-daily-stats"
    name:   "Daily Stats"
    author: "dhruvik7"
    repo:   "dhruvik7/obsidian-daily-stats"

    html_url:    "https://community.obsidian.md/plugins/obsidian-daily-stats"
    github_url:  "https://github.com/dhruvik7/obsidian-daily-stats"
    description: "Track your daily word count."
    about:       "Track today's word count in the bottom-right corner of Obsidian. View historical logs in a right-side panel presented as a contribution-style heatmap to monitor writing streaks and trends."
```
