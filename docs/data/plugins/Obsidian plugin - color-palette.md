# Color Palette

Color Palette creates and manages color palettes inside notes, accepting Hex, RGB, HSL and other CSS color formats. Palettes can be imported from Coolors or Colorhunt links, gradients generated, and color codes copied by selecting them, while commands open an advanced editor, convert links, or generate a random palette.
