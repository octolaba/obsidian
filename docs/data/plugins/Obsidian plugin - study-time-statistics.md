# Study Time Statistics

Measures active reading time for Markdown notes and PDFs, counts opens and completed sessions, and shows an inline statistics strip at the top of each note without altering the source file. A local dashboard presents heatmaps, trends, session distributions, folder summaries and leaderboards. All collected data stays inside the vault.

plugin: {
    id:     "study-time-statistics"
    name:   "Study Time Statistics"
    author: "miss"
    repo:   "tanzy226/obsidian-study-time-statistics"

    html_url:    "https://community.obsidian.md/plugins/study-time-statistics"
    github_url:  "https://github.com/tanzy226/obsidian-study-time-statistics"
    description: "Private, local-first study analytics for notes and PDFs: sessions, streaks, heatmaps, trends, and rankings. - This plugin has not been manually reviewed by Obsidian staff."

Analyze study habits with a local dashboard offering heatmaps, trends, session distributions, folder summaries, and leaderboards while keeping all data inside your vault."
