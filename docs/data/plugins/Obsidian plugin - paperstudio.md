# Paper Studio

Publishes notes to Paper Studio as shareable HTML documents carrying the account's branding. Local PNG, JPEG, GIF, WebP and SVG images are uploaded automatically, Markdown is converted to styled HTML, and the shareable link is copied to the clipboard.

```cue
plugin: {
    id:     "paperstudio"
    name:   "Paper Studio"
    author: "naros899"
    repo:   "naros899/obsidian-paperstudio"

    html_url:    "https://community.obsidian.md/plugins/paperstudio"
    github_url:  "https://github.com/naros899/obsidian-paperstudio"
    description: "Publish your notes to Paper Studio and get beautiful shareable HTML documents. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Publish Obsidian notes to Paper Studio as shareable, branded HTML documents. Upload local images (PNG/JPEG/GIF/WebP/SVG) automatically, convert Markdown to styled HTML using your Paper Studio brand, and copy the shareable link to your clipboard."

    stats: {
        downloads:  327
        updated_at: 1772422793000
    }
}
```
