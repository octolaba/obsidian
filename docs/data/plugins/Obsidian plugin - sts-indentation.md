# STS-indentation

Content is indented according to its heading ancestry, with the first heading treated as depth zero, and lists, tasks, code blocks, images, quotes, tables, math, callouts and embeds follow the same indentation. One guide line is drawn per parent heading, colored from its parent, and native fold arrows stay usable on the guide lines. Guides are toggled and restyled across Live Preview, Source and Reading views on desktop and on mobile.
