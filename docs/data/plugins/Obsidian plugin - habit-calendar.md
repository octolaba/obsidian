# Habit Calendar

Renders a monthly habit calendar inside a DataviewJS code block, showing habit status across a month. The data comes either from Dataview tables or from manual entries, notes are matched with custom date patterns, and habit labels are set with header pipe notation.

```cue
plugin: {
    id:     "habit-calendar"
    name:   "Habit Calendar"
    author: "hedonihilist"
    repo:   "hedonihilist/obsidian-habit-calendar"

    html_url:    "https://community.obsidian.md/plugins/habit-calendar"
    github_url:  "https://github.com/hedonihilist/obsidian-habit-calendar"
    description: "Monthly Habit Calendar for DataviewJS. Render a calendar inside DataviewJS code block, showing your habit status within a month."
    about:       "Render a monthly habit calendar inside a DataviewJS code block to visualize daily habit status for any month. Use Dataview tables or manual data entries as sources, map notes with custom date patterns, and set habit labels via header pipe notation."

    stats: {
        downloads:  11464
        updated_at: 1679207691000
    }
}
```
