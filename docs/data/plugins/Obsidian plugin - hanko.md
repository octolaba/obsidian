# Hanko

Registers text snippets and pastes them into notes from the right-click menu, the command palette or the ribbon. Saved snippets can be managed, reordered and deleted, and the cursor position after pasting can be set. It works in edit mode only, as preview is not supported.

    id:     "hanko"
    name:   "Hanko"
    author: "telehakke"
    repo:   "telehakke/hanko"
