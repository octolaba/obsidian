# Copy Linked File

Copy Linked File copies the actual file behind an internal link, an embed or a local file URL to the Windows clipboard as a file drop list. Vault links and file URLs are resolved so the linked files can be pasted into File Explorer, email, chat or a browser upload control on Windows desktop.

```cue
plugin: {
    id:     "copy-linked-file"
    name:   "Copy Linked File"
    author: "flutterspike"
    repo:   "flutterspike/obsidian-copy-linked-file"

    html_url:    "https://community.obsidian.md/plugins/copy-linked-file"
    github_url:  "https://github.com/flutterspike/obsidian-copy-linked-file"
    description: "Copy the vault file or local file URL behind a link or file menu item to the Windows clipboard. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Copy the real file behind an internal link, embed, or local file:/// URL to the Windows clipboard as a file drop list. Resolve vault links and file URLs so you can paste linked files into File Explorer, email, chat, or browser upload controls on Windows desktop."
```
