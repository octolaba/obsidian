# Monokakido Copilot

Monokakido Copilot searches the Dictionaries by Monokakido during editing, triggered by double-pressing the option key. Its recorded text adds that the plugin is not affiliated with the Japanese company MONOKAKIDO, which owns the Monokakido trademark.
