# HTML to MD Effectiveness

HTML to MD Effectiveness converts HTML files to Markdown, keeping headings, bold, italic and strikethrough, inline and fenced code with language tags, links, images, nested lists, pipe-format tables, blockquotes and horizontal rules, with optional YAML frontmatter. Every HTML file in a folder can be converted in one batch, and existing Markdown files are skipped rather than overwritten.

```cue
plugin: {
    id:     "html-to-md-effect"
    name:   "HTML to MD Effectiveness"
    author: "rosswang"
    repo:   "yanqingwang/obsidian-html-to-md-effect"

    html_url:    "https://community.obsidian.md/plugins/html-to-md-effect"
    github_url:  "https://github.com/yanqingwang/obsidian-html-to-md-effect"
    description: "Convert HTML files to clean Markdown — headings, lists, code blocks, tables, links, images, and more. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert any .html file to clean Markdown in Obsidian, preserving headings, bold/italic/strikethrough, inline and fenced code (with language tags), links, images, nested lists, pipe-format tables, blockquotes, horizontal rules, and optional YAML frontmatter. Batch convert all .html files in a folder and protect existing .md files by skipping overwrites."

}
```
