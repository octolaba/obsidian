# Bases Toolbox

Bases Toolbox collects property utilities for Bases and the vault at large: find and replace of property values with per-file previews, a persistent history log and revert. It also bulk-edits base results by setting, backfilling, appending, removing or deleting values, computes rollups into real properties, offers a searchable index of every property, and stops number inputs from changing on arrow keys or the scroll wheel.
