# Ribbon Divider

Ribbon Divider adds draggable dividers to the Obsidian ribbon so icons can be spaced out and grouped. Divider appearance is customized with CSS, and each divider carries a unique class ID that can be targeted individually.

```cue
plugin: {
    id:     "ribbon-divider"
    name:   "Ribbon Divider"
    author: "andrewmcgivery"
    repo:   "andrewmcgivery/obsidian-ribbon-divider"

    html_url:    "https://community.obsidian.md/plugins/ribbon-divider"
    github_url:  "https://github.com/andrewmcgivery/obsidian-ribbon-divider"
    description: "Add dividers to the ribbon to space out your icons."
    about:       "Add draggable dividers to the Obsidian ribbon to space and group icons. Customize divider appearance with CSS and target individual dividers using their unique class IDs."
```
