# Omni Viewer

Omni Viewer opens and edits dozens of file types inside Obsidian, including archives, audio, video, images, spreadsheets, PDFs, GIS data, automotive logs and many other data formats. It provides a waveform and spectrogram audio player, an image editor with filters and annotations, a PDF editor that annotates, merges and saves, and a CSV editor that writes changes back. Content-signature rerouting and file sharing are also included.
