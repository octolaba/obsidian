# Canvas Node Linker

Canvas Node Linker adds a right-click menu entry on Canvas nodes and groups that copies a ready-to-paste wikilink onto the clipboard. Text nodes use their first heading as display text and groups use the group label; where neither exists, a bare link is copied.

```cue
plugin: {
    id:     "canvas-node-linker"
    name:   "Canvas Node Linker"
    author: "Giuseppe Mastrodomenico"
    repo:   "mvstro/canvas-node-linker"

    html_url:    "https://community.obsidian.md/plugins/canvas-node-linker"
    github_url:  "https://github.com/mvstro/canvas-node-linker"
    description: "A simple plugin that adds a right-click menu on Canvas nodes to instantly copy a wikilink of the node. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Copy ready-to-paste canvas wikilinks from any node or group via a right-click menu entry and place the link on your clipboard in one click. Use the node's first heading as display text for text nodes, the group label for groups, or copy a bare link if none exists."

    stats: {
        downloads:  368
        updated_at: 1778885236000
    }
}
```
