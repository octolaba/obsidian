# Daily notes sorter

Sorts daily notes and files by date in the file explorer, recognizing formats including YYYY-MM-DD, DD.MM.YYYY, DD.MM.YY and MM/DD/YYYY. The folders it covers are configurable, the order can be ascending or descending, and files that do not match the chosen date format raise a notification.

```cue
plugin: {
    id:     "daily-notes-sorter"
    name:   "Daily notes sorter"
    author: "Nikolai"
    repo:   "reifat/daily-notes-sorter"

    html_url:    "https://community.obsidian.md/plugins/daily-notes-sorter"
    github_url:  "https://github.com/reifat/daily-notes-sorter"
    description: "Automatically sort daily notes and files by date in the file explorer. Supports multiple date formats (YYYY-MM-DD, DD.MM.YYYY, DD.MM.YY, MM/DD/YYYY) and flexible folder configuration. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sort daily notes automatically in the file explorer by recognized date formats (ISO, DD.MM.YYYY, MM/DD/YYYY and common numeric variants) to keep entries chronological. Configure folders, toggle ascending or descending order, and receive notifications for files that don't match the chosen date format."
```
