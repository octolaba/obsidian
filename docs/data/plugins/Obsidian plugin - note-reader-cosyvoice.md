# Note Reader CosyVoice

Reads the current note or a selection through a local CosyVoice text-to-speech pipeline, so the text stays on the machine running it. A reader panel opens on the right with progress, pause, resume and stop controls, speed presets, and handling for cleaned Markdown and common LaTeX.
