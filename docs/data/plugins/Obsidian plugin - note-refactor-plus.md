# Note Refactor Plus

Extracts a selection or a whole heading section into a new note using configurable profiles that set the filename rule, destination folder, template and frontmatter. Notes can be split by heading level or from the cursor, Templater can be run on the new file, the last extract can be undone, and the operations are reachable from the command palette, hotkeys, or the editor context menu.
