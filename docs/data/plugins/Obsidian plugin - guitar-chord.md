# Guitar Chord

Enters and displays guitar chords inline in a document, written either as a chord name such as Am7 or as finger positions such as x-3-2-0-1-0, with no code block required. Chord diagrams are generated from music theory so the offered shapes are valid, custom chords can be added, and chords can be edited in place.

```cue
plugin: {
    id:     "guitar-chord"
    name:   "Guitar Chord"
    author: "barba828"
    repo:   "barba828/obsidian-plugin-chord"

    html_url:    "https://community.obsidian.md/plugins/guitar-chord"
    github_url:  "https://github.com/barba828/obsidian-plugin-chord"
    description: "Quickly enter and display guitar chords, with optional chords based on music theory. No need to write in code blocks, they can be inserted and edited directly in the document."
    about:       "Enter and display guitar chords directly in your document using chord names or finger positions (e.g., Am7 or x-3-2-0-1-0). Generate valid, theory-based chord diagrams, add custom chords, and edit them inline without code blocks."

    stats: {
        downloads:  2235
        updated_at: 1728635109000
    }
}
```
