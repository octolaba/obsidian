# Private Mode

Blurs files, links, and search results tagged with #private so that sensitive content stays hidden until you hover, focus, or reveal everything. The behaviour can be set to reveal all, reveal on hover, or reveal never, which is aimed at protecting content during a screenshare, and visibility is controlled from the status bar.

    id:     "private-mode"
    name:   "Private Mode"
    author: "markusmo3"
