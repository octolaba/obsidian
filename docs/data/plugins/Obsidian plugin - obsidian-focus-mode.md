# Focus Mode

Dims panes and lines that are not active so that attention stays on the note being edited. A Super Focus Mode isolates only the active pane and hides other content for distraction-free editing.

```cue

    id:     "obsidian-focus-mode"
    name:   "Focus Mode"

    repo:   "ryanpcmcquen/obsidian-focus-mode"
```
