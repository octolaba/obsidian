# Audio PlugList

Builds playlists from vault folders or from external links and indexes the supported audio files automatically. Playback is driven from a tab view or a compact footer mini-player with shuffle, repeat, fade-out stop, equalizer presets and hotkeys. The supported formats are mp3, wav, m4a, flac, ogg and aac.
