# Reading Highlighter

Highlights selected text in reading mode by wrapping it in the Markdown highlight syntax. A floating highlight button, a command palette action, and a mobile ribbon icon all apply it, including to multi-paragraph selections, formatted spans, and links, while preserving existing Markdown formatting. An undo button removes the last highlight.
