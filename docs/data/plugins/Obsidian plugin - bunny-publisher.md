# Bunny Publisher

Bunny Publisher uploads images, video and other files from the vault to Bunny.net storage zones or a custom CDN hostname, converting local embeds into Markdown links that point at the generated CDN URLs. Upload paths can be built from the date, filenames are sanitized, progress is reported in real time, local files can be deleted after upload, and alt text can be generated by AI.

```cue
plugin: {
    id:     "bunny-publisher"
    name:   "Bunny Publisher"
    author: "ericmwalk"
    repo:   "ericmwalk/obsidian-bunny-publisher"

    html_url:    "https://community.obsidian.md/plugins/bunny-publisher"
    github_url:  "https://github.com/ericmwalk/obsidian-bunny-publisher"
    description: "Upload images, videos, and files to Bunny.net storage. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Upload images and media from Obsidian to Bunny.net Storage Zones or a custom CDN hostname, automatically converting local embeds into Markdown image links with generated CDN URLs. Use dynamic date-based upload paths, sanitized filenames, real-time progress, optional local-file deletion, and optional AI-generated alt text."

    stats: {
        downloads:  80
        updated_at: 1779218491000
    }
}
```
