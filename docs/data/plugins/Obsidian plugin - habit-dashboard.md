# Habit Dashboard

Collects events, data logs, tasks, check-ins, moments, monthly plans and quick links into one editable daily dashboard with a mini-calendar, a weekly archive and per-item note links. Habit streaks are tracked, a countdown timer persists, daily metrics and timestamped moments are recorded, and tasks are grouped into linked category boxes. It is built for both desktop and mobile.
