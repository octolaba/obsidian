# TideLog

TideLog turns daily notes into a Plan, Review and Insights loop. Plan manages day, week and month tasks alongside an idea inbox, Review completes today's loop or catches up on a past date, and Insights unlocks weekly reports, monthly reports and an AI view of you, previewed in the plugin and updated as new records arrive. AI features run against your own provider and API key, and notes stay Markdown-first in the vault.
