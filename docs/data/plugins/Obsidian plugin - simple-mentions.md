# Simple Mentions

References people anywhere in notes through plain @mentions resolved against a single contact database, kept as one Markdown table file with customizable columns. Each row needs a Mention key made only of letters, digits and underscores, and matching is case-insensitive. Rows with a missing or invalid key are skipped.

```cue
plugin: {
    id:     "simple-mentions"
    name:   "Simple Mentions"
    author: "Mayeenul Islam"
    repo:   "mayeenulislam/obsidian-simple-mentions"

    html_url:    "https://community.obsidian.md/plugins/simple-mentions"
    github_url:  "https://github.com/mayeenulislam/obsidian-simple-mentions"
    description: "Maintain a single contact database and reference people anywhere in your notes using plain @mentions. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Reference people anywhere in your notes with @mentions backed by a single plain-Markdown contact database. Store contacts in one Markdown table file with customizable columns; require a Mention key per row (letters, digits, underscores only), use case-insensitive matching, and skip rows with missing or invalid keys."
```
