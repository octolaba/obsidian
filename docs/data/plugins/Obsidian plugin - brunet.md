# Brunet

Brunet opens Bruno .bru files as a formatted card showing the request method, URL, headers, params, body and docs, and can run the request and inspect the response with JSON pretty-printing. A Collections sidebar lists every .bru file in the vault with run buttons, .bru, .yml and .yaml files get syntax highlighting, and the equivalent bru run CLI command can be copied in one click.

```cue
plugin: {
    id:     "brunet"
    name:   "Brunet"
    author: "masykurisyaifullah"
    repo:   "msyaifullah/brunet"

    html_url:    "https://community.obsidian.md/plugins/brunet"
    github_url:  "https://github.com/msyaifullah/brunet"
    description: "Bruno API format support  view, edit, and run .bru HTTP requests in your vault. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "View and Run Bruno API requests directly from Obsidian. Open any .bru file to see a formatted card with the method, URL, headers, params, body, and docs — then run it and inspect the response with JSON pretty-printing. A Collections sidebar lists all your .bru files with run buttons, .bru/.yml/.yaml files get syntax highlighting, and you can copy the bru run CLI command in one click."

    stats: {
```
