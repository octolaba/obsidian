# Show All Hidden Files

Show All Hidden Files reveals every dot-prefixed hidden file and folder in the Obsidian file explorer at any depth, including the git, obsidian, env and DS_Store entries. While it is active it also enables Obsidian's unsupported-file visibility so non-Markdown hidden files appear, and specific names can be kept hidden through an ignored-names list. It does not modify files.

    id:     "show-all-hidden-files"

Enable Obsidian's unsupported-file visibility while active to show non‑Markdown hidden files, and keep exact names hidden via ignored names; does not modify files."
