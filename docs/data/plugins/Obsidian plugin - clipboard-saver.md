# Clipboard Saver

Appends the system clipboard's contents to the end of the current Markdown note, optionally with a timestamp and wrapped in configurable separators. On desktop the append happens automatically whenever something is copied; on mobile the clipboard is saved by running a command.

```cue
plugin: {
    id:     "clipboard-saver"
    name:   "Clipboard Saver"
    author: "钟文富"
    repo:   "zhongwenfu00-alt/clipboard-saver"

    html_url:    "https://community.obsidian.md/plugins/clipboard-saver"
    github_url:  "https://github.com/zhongwenfu00-alt/clipboard-saver"
    description: "Save the system clipboard content (including a timestamp) to the current note: on desktop, it is automatically appended upon copying, while on mobile, it is saved manually via a command. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Append system clipboard contents (optionally with a timestamp) to the end of the current Markdown note, wrapped in configurable separators. Auto-append copied text on desktop or run the command on mobile to manually save the clipboard into the open note."

    stats: {
        downloads:  122
        updated_at: 1785296442000
    }
}
```
