# LaTeX to Unicode converter

This converter turns simple LaTeX math and symbols into Unicode sequences for use in ordinary note text. LaTeX is entered in a pop-up, and the converted superscripts, subscripts, fractions, arrows, set symbols and common operators are inserted into the note.
