# Get Covers

Searches for a cover image for the current note in Google Images or in structured databases such as Google Books, TMDb, AniList and SteamGridDB. A result is picked from a touch-friendly gallery and either downloaded into the vault or written as a URL into the note's frontmatter, with automatic fallbacks and an adjustable number of results.
