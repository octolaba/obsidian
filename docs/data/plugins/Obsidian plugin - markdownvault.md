# MarkdownVault

MarkdownVault publishes an Obsidian vault to the Markdown Vault service and produces a shareable link, so the notes can be downloaded and read in the Markdown Vault iOS app. Access can optionally be restricted with a password. The recorded description states that a free account at markdownvault.com is required.

```cue
plugin: {
    id:     "markdownvault"
    name:   "MarkdownVault"
    author: "dhennessy"
    repo:   "dhennessy/MarkdownVaultObsidianPlugin"

    html_url:    "https://community.obsidian.md/plugins/markdownvault"
    github_url:  "https://github.com/dhennessy/MarkdownVaultObsidianPlugin"
    description: "Publish your notes directly to an app on your user's phones. Requires a free account at https://markdownvault.com. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Publish your Obsidian vault to Markdown Vault and generate a shareable link so others can download and view your notes in the Markdown Vault iOS app. Add optional password protection for restricted access."

    stats: {
        downloads:  81
        updated_at: 1778273363000
    }
}
```
