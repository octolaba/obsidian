# Shiki Highlighter

Shiki Highlighter applies Shiki syntax highlighting to code blocks across reading, live preview and edit modes, covering more than a hundred languages. Rendered blocks carry line numbers, titles, inline highlighting and line and diff highlighting, and styling comes from bundled themes or from VS Code-compatible JSON themes.
