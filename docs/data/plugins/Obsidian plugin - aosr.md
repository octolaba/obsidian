# Aosr

Another spaced repetition implementation, building flashcards in single-line, multi-line and cloze forms with support for rich media such as audio. Review intervals go down to minutes, and an Explore Hard Cards mode targets the difficult ones. Reviewing happens in a dedicated window or a mobile-optimized interface, notes are scanned selectively with folder and file exclusions, and the database path is configurable.
