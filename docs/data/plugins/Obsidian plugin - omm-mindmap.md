# OMM MindMap

OMM MindMap renders a Markdown outline as an interactive mindmap and converts a mindmap back into a clean bullet list. Nodes are panned, zoomed, collapsed, expanded and edited, links are followed, and each tree uses a top-down or left-right layout kept in two-way sync with its Markdown source. Maps export to PNG or PDF.
