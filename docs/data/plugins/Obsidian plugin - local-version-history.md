# Local Version History

Gives each note an on-disk version history: changed lines are highlighted live and marked in the gutter, the file tree and the tabs. Any point in the timeline can be browsed, diffed, pinned, restored or reverted, and deleted or moved files can be recovered. The recorded text states that this is fully local, with no account and no network.

plugin: {
    id:     "local-version-history"
    name:   "Local Version History"
    author: "B@RT"

    github_url:  "https://github.com/bartlab/obsidian-local-history"
    description: "On-disk version history for your notes: highlight changed lines, capture a timeline, and diff or restore any earlier version, fully local. - This plugin has not been manually reviewed by Obsidian staff."

Browse, diff, pin, restore, or revert any point and recover deleted or moved files — all fully local with no account or network."
