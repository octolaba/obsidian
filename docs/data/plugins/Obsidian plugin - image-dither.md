# Image Dither

Image Dither intercepts pasted or dropped images and dithers or resizes them to black and white to reduce file size while preserving transparency. Floyd-Steinberg, blue noise, ordered, threshold and grayscale algorithms are available, the compression saving is previewed live, and the result is saved under a templated, deduplicated filename.
