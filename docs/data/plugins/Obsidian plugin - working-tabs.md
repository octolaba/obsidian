# Working tabs

Groups the open tabs of each pane into named work groups organised by task and timeframe rather than by folder or layout. Groups are formed automatically from panes and tracked as in-progress work, and a whole section can be hidden or marked complete when its timeframe ends. Completed groups can be recovered afterwards.

```cue
plugin: {
    id:     "working-tabs"
    name:   "Working tabs"
    author: "notenerd"
    repo:   "notenerdofficial/working-tabs"

    html_url:    "https://community.obsidian.md/plugins/working-tabs"
    github_url:  "https://github.com/notenerdofficial/working-tabs"
    description: "Group open tabs into named, switchable spaces you can tuck away and complete when the work is done. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Organize open tabs by task and timeframe instead of by folder or layout, turning each pane's tabs into tracked in-progress work groups. Hide or complete entire sections when a timeframe ends and recover completed groups later, with groups formed automatically from panes."

    stats: {
        downloads:  65
        updated_at: 1786380460000
    }
}
```
