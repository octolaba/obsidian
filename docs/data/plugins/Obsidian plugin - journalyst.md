# Journalyst

Journalyst manages topic-specific journals by designating a vault folder whose subfolders each become a journal of dated notes. Entries are created quickly for categories such as sleep, routines or work, daily or recurring. A monthly completion overview per journal shows which days were written.

```cue
plugin: {
    id:     "journalyst"
    name:   "Journalyst"
    author: "justin-arnold"
    repo:   "justin-arnold/Journalyst"

    html_url:    "https://community.obsidian.md/plugins/journalyst"
    github_url:  "https://github.com/justin-arnold/Journalyst"
    description: "Journalyst enables easy creation of topic-specific journals. Organize your life into categories like sleep, routines, or work, with daily or recurring entries for effortless tracking and reflection."
    about:       "Track daily journaling and manage multiple journals by designating a vault folder whose subfolders become individual journals using YYYY-MM-DD.md files. Create new entries quickly and view a monthly completion overview for each journal to see which days you wrote."

    stats: {
        downloads:  4453
        updated_at: 1721971037000
    }
}
```
