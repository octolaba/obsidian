# Folder Filelist

Creates and maintains index files listing wikilinks to the files in specified folders, newest first. The list for the vault root is written to a file such as ndx-root.md, generated automatically or regenerated from a ribbon icon. Specific files or extensions are excluded and the listfile pattern is configurable.

```cue
plugin: {
    id:     "folder-filelist"
    name:   "Folder Filelist"
    author: "band"
    repo:   "band/obsidian-folder-filelist"

    html_url:    "https://community.obsidian.md/plugins/folder-filelist"
    github_url:  "https://github.com/band/obsidian-folder-filelist"
    description: "Create and maintain a list of wikilinks to files in specified folders."
    about:       "Generate folder filelists of wiki-links for specified folders, producing an index file (e.g., ndx-root.md for /) with newest files listed first. Auto-generate and manually regenerate via a ribbon icon; exclude specific files or extensions and customize the listfile pattern."
```
