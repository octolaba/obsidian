# Vuln Report Kit

Vuln Report Kit builds structured vulnerability cases in a local vault, documenting target, reproduction, impact, evidence, remediation and timeline. Templates and a dashboard support scanning for secrets and producing sanitized public copies. Final Markdown reports, bundles and shareable archives can be exported.
