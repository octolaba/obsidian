# Folder Column Navigator

Browses folders in a Finder-style multi-column navigator, keeping the path context visible and opening notes without leaving the navigator. The root can sit on the left or across the top, columns can be traversed from the keyboard, and filtering accepts English, numbers, Chinese characters or pinyin. Context menus add file sorting and duplicate-name checks.
