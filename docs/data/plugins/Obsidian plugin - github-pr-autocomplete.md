# GitHub PR Autocomplete

Suggests GitHub issues and pull requests through an inline autocompleter triggered by a character, by default the at sign, and inserts a link to the chosen item. Open issues and pull requests can be found by number or by fuzzy search on the title.

```cue
plugin: {
    id:     "github-pr-autocomplete"
    name:   "GitHub PR Autocomplete"
    author: "Andrew Mao"
    repo:   "andrewyx/Github-PR-Autocomplete"

    html_url:    "https://community.obsidian.md/plugins/github-pr-autocomplete"
    github_url:  "https://github.com/andrewyx/Github-PR-Autocomplete"
    description: "Suggests and Autocompletes GitHub Issues and Pull Requests - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert links to GitHub issues and pull requests with an inline autocomplete suggester triggered by a character (default @), letting you search open issues/PRs or jump to a number. Suggestions work with both issue number or fuzzy search by title."

    stats: {
        downloads:  95
        updated_at: 1779484410000
    }
}
```
