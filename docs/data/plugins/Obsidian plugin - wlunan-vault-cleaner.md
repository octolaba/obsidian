# Vault Cleanup Dashboard

Scans the vault for orphaned notes, attachments and other files and presents them in a dashboard with live scan status and statistics. Items are previewed and deleted selectively, and removed files go to a configurable vault trash so that they can be recovered. Attachment cleanups can be scheduled, and recently modified files are protected from deletion.

```cue
plugin: {
    id:     "wlunan-vault-cleaner"
    name:   "Vault Cleanup Dashboard"
    author: "lunan"
    repo:   "wlunan/vault-cleaner"

    html_url:    "https://community.obsidian.md/plugins/wlunan-vault-cleaner"
    github_url:  "https://github.com/wlunan/vault-cleaner"
    description: "Visual dashboard for intelligently cleaning orphaned files and attachments with scheduled auto-cleanup and file protection. - This plugin has not been manually reviewed by Obsidian staff."

Preview and selectively delete items, move removed files to a customizable vault trash for recovery, schedule automatic attachment cleanups, and protect recently modified files from deletion."
