# Crypto Lookup

Crypto Lookup pulls prices for crypto in a target currency through the Cryptonator API, which the recorded description marks as currently unavailable while a replacement is sought. Commands fetch the rate of a specified or default coin and return either the bare price or extended data for reference in a note.

plugin: {
    id:     "obsidian-crypto-lookup"
    name:   "Crypto Lookup"
    author: "kinabalu"
