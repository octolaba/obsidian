# No Paste

No Paste blocks paste actions in Obsidian's Markdown editors for as long as it is enabled, showing a short notice when pasted text is rejected. It runs silently, with no commands, buttons, context-menu items or settings. The recorded description warns that it is not an originality, AI or anti-cheat detector: it does not block imports, sync, drag-and-drop, external automation, plugin APIs, or edits made outside Obsidian.
