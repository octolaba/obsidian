# Timecodes

Timecodes converts raw text timecodes in the MM:SS and HH:MM:SS forms into clickable links in reading mode when the note contains a link to a video. Timecodes are detected in raw YouTube URLs, markdown links and embedded iframes, and following one opens the video at the corresponding timestamp.

```cue
plugin: {
    id:     "timecodes"
    name:   "Timecodes"
    author: "gavvvr"
    repo:   "gavvvr/obsidian-timecodes-plugin"
```
