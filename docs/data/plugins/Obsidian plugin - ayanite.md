# Ayanite

Ayanite adds an AI chat interface to Obsidian with multi-tab chats and a sidepanel copilot, backed by OpenAI or by local Ollama models. Chats, prompts and profiles are stored as local, searchable Markdown files, clipped text can be summarized or explained, diagrams generated and custom chat profiles created. Its recorded description states that the plugin is closed source.
