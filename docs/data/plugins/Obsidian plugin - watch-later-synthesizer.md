# Watch Later Synthesizer

Watch Later Synthesizer triages a YouTube watch-later backlog into per-video watch or skip verdicts, recurring themes across the pile and a conservative safe-to-delete list. Only metadata is analyzed, namely title, channel, description and duration, which is used to flag time-sensitive items and surface patterns across videos. Per-video summaries are deliberately not produced.
