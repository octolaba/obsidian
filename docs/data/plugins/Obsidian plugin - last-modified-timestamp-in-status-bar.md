# File Creation and Last Modified Timestamps in Status Bar

This plugin shows the creation and last modified timestamps of the current file in the status bar, updating frequently and when another note is opened. Each timestamp can be shown or hidden, the format chosen, and the refresh interval adjusted.

```cue
plugin: {
    id:     "last-modified-timestamp-in-status-bar"
    name:   "File Creation and Last Modified Timestamps in Status Bar"
    author: "yustynn"
    repo:   "yustynn/obsidian-last-modified-timestamp-in-status-bar"

    html_url:    "https://community.obsidian.md/plugins/last-modified-timestamp-in-status-bar"
    github_url:  "https://github.com/yustynn/obsidian-last-modified-timestamp-in-status-bar"
    description: "Dynamic display of file modification timestamp in the status bar."
    about:       "Display the last modified timestamp of the current note in the status bar, updating frequently and when switching notes. Show or hide created and modified timestamps, choose timestamp formats, and adjust the refresh interval for real-time accuracy."

    stats: {
        downloads:  10562
        updated_at: 1729448319000
    }
}
```
