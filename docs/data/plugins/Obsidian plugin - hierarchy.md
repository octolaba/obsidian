# Hierarchy

Hierarchy displays the folder hierarchy of the current note in a collapsible view below the editor and in the backlinks panel. Tab and backlink titles can be set to show the full path or only the file name, and the titles are kept updated automatically.

```cue
plugin: {
    id:     "hierarchy"
    name:   "Hierarchy"
    author: "kdnk"
    repo:   "kdnk/obsidian-hierarchy"

    html_url:    "https://community.obsidian.md/plugins/hierarchy"
    github_url:  "https://github.com/kdnk/obsidian-hierarchy"
    description: "Visualize the hierarchy of your link."
    about:       "Visualize the folder hierarchy of the current note in a collapsible view below the editor and in the backlinks panel. Customize tab and backlink titles to show full paths or just file names and keep titles updated automatically."
```
