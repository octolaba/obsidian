# Agile Task Notes

Agile Task Notes imports tasks from Jira or Azure DevOps into Obsidian so notes and todo lists can be kept on them. It generates a local Kanban board showing only the user's own tasks and creates an individual file per task with customizable starter content.

```cue
plugin: {
    id:     "obsidian-agile-task-notes"
    name:   "Agile Task Notes"
    author: "boxthatbeat"
    repo:   "boxthatbeat/obsidian-agile-task-notes"

    html_url:    "https://community.obsidian.md/plugins/obsidian-agile-task-notes"
    github_url:  "https://github.com/boxthatbeat/obsidian-agile-task-notes"
    description: "Import your tasks from your TFS (Azure or Jira) to take notes on them and make todo-lists!"
    about:       "Import tasks from Jira or Azure DevOps into Obsidian. Generate a local Kanban board showing only your tasks and create individual task files to add notes and todo lists with customizable starter content."

    stats: {
        downloads:  11573
        updated_at: 1775833020000
    }
}
```
