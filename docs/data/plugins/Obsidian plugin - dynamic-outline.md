# Dynamic Outline

Adds a floating table of contents for navigating inside a note, with the active heading highlighted. Headings can be searched, jumped to, collapsed and traversed by keyboard, and the outline can appear on file open or on hover, auto-hide, and have its appearance customized.

```cue
plugin: {
    id:     "dynamic-outline"
    name:   "Dynamic Outline"
    author: "theopavlove"
    repo:   "theopavlove/obsidian-dynamic-outline"

    html_url:    "https://community.obsidian.md/plugins/dynamic-outline"
    github_url:  "https://github.com/theopavlove/obsidian-dynamic-outline"
    description: "Adds a customizable GitHub-like floating table of contents."
    about:       "Show a floating table of contents for quick navigation within notes. Highlight the active heading, search and jump to sections, collapse headings, navigate by keyboard, reveal on file open or hover, auto-hide, and personalize the outline's appearance."

}
```
