# Gamer Giveaways Fetcher

Fetches current game giveaways from Epic, Steam, PlayStation, Xbox and other platforms and saves them as organized notes in the vault. The lists are refreshed automatically or on a schedule, sorted by platform, and each entry records title, value, description and claim instructions.

```cue
plugin: {
    id:     "gamer-giveaways"
    name:   "Gamer Giveaways Fetcher"
    author: "abduznik"
    repo:   "abduznik/Obsidian-Game-Giveaways"

    html_url:    "https://community.obsidian.md/plugins/gamer-giveaways"
    github_url:  "https://github.com/abduznik/Obsidian-Game-Giveaways"
    description: "Fetches gaming giveaways and organizes them by platform in a collapsible format. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Fetch latest game giveaways from Epic, Steam, PlayStation, Xbox and more and save them as organized notes in your vault. Keep lists fresh with automatic or scheduled updates, sort by platform, and include title, value, description, and claim instructions for each entry."

    stats: {
        downloads:  111

    }
}
```
