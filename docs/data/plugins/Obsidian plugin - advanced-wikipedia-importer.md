# Advanced Wikipedia Importer

Advanced Wikipedia Importer imports Wikipedia articles as structured notes with selectable sections, images downloaded and renamed to a chosen convention, flattened tables and preserved footnotes. Film pages are detected so the note is named with title and year and posters are labeled. The import runs locally inside Obsidian, without a server or an account.

```cue
plugin: {
    id:     "advanced-wikipedia-importer"
    name:   "Advanced Wikipedia Importer"
    author: "Dylan Wright"
    repo:   "dyllonwright/Wikipedia-To-Obsidian-Markdown"

    html_url:    "https://community.obsidian.md/plugins/advanced-wikipedia-importer"
    github_url:  "https://github.com/dyllonwright/Wikipedia-To-Obsidian-Markdown"
    description: "Import Wikipedia articles as clean notes — pick sections, download and rename images, flatten complex tables, and auto-detect film articles. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Import Wikipedia articles as clean, structured notes with selectable sections, downloaded images renamed to your convention, flattened tables, and preserved footnotes. Detect film pages to name notes Title (Year) and label posters, all running locally inside Obsidian with no server or account."

    stats: {
        downloads:  82
        updated_at: 1784865314000
    }
}
```
