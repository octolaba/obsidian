# Tars

Tars generates text and images inside a note from tag-triggered AI assistants, with the tags offered as suggestions. Claude, OpenAI, Gemini, Ollama, DeepSeek, Kimi, Doubao, Qwen, Zhipu, QianFan, SiliconFlow, OpenRouter and further providers are named as supported. Embedded images and PDFs can be analyzed, responses inserted from a selection or at the cursor, conversations exported to JSONL, and status shown in real time.
