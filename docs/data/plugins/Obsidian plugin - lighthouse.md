# Lighthouse

Lighthouse organises writing across many files into projects, with project-scoped dashboards, a filtered file explorer, fuzzy project switching and a single command that opens a dedicated workspace. Hierarchical word counts and goals update in real time, and pacing is monitored against deadlines with adaptive daily targets. Progress is reported through heatmaps, streaks and progress rings.
