# Note Tabs

Creates tabbed sections inside a note so that content can be grouped and switched between without leaving the note. Tabbed sections are inserted, and tabs added, through the editor context menu or Markdown blocks, and headers adapt with vertical, compact and rounded-edge layouts that the recorded description says stay compatible with most themes and plugins.

    id:     "notetabs"
    name:   "Note Tabs"

    github_url:  "https://github.com/project-free-rangers/obsidian-notetabs"
