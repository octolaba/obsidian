# Netwik

Netwik connects a vault to a global network of shared Markdown notes and synchronises edits between all participants, so anyone can create, view or edit them. Remote notes are searched and opened with auto-suggestions, cloud notes created or edited, shareable obsidian:// links copied, and remote files downloaded into the local vault on demand.
