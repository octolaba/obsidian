# Vault Viewer

Browses every file type in the vault through an expandable folder tree and file list, with drag-and-drop moving, search, sorting and context menus for copying paths, opening a parent folder or deleting. Office documents in DOCX, XLSX and PPTX form and SQL files are previewed inline, Markdown backlinks and embeds are shown in a reference mode, and files can be opened in the system application. The recorded About stresses that documents and other files are kept apart, so the files related to a folder are listed when that folder is clicked.
