# linqq-handwritten annotation

The plugin adds colorful handwritten-style annotations to selected Markdown without altering or reflowing the prose. Labels sit above or below a paragraph with curved arrows that stay attached when the text wraps, and lanes are allocated automatically so annotations do not collide. Annotations are stored as portable HTML and remain editable.
