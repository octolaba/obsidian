# Tag Index

Tag Index keeps a curated list of important tags separate from the default tag pane, so a knowledge base gains deliberate entry points. Nested tags are shown as a tree, reordered by drag-and-drop, and sorted independently from the notes below them. Clicking a tag lists the notes and the exact lines where the tag appears, with jump and hover preview.
