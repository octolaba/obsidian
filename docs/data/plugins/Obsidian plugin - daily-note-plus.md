# Daily Note Plus

Creates missing daily notes across a selected date range without opening each day. It reads the configured Daily Notes or Periodic Notes folder, format and template, detects nested paths such as YYYY/MM/DD, and backfills only the dates that are actually missing. The backfill can also be run automatically at startup.

```cue
plugin: {
    id:     "daily-note-plus"
    name:   "Daily Note Plus"
    author: "o1xhack"
    repo:   "o1xhack/obsidian-daily-note-plus"

    html_url:    "https://community.obsidian.md/plugins/daily-note-plus"
    github_url:  "https://github.com/o1xhack/obsidian-daily-note-plus"
    description: "Automatically creates missing daily notes - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create missing daily notes across a selected date range without opening each day. Use your configured Daily Notes/Periodic Notes folder, format, and template and detect nested paths (e.g. YYYY/MM/DD or YYYY/YYYY.MM.DD) to backfill only truly missing dates with optional startup automation."

    stats: {
        downloads:  217

    }
}
```
