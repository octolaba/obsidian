# Fast Image Auto Uploader

Fast Image Auto Uploader uploads images from the clipboard, from drag-and-drop, or from the file context menu, and replaces them in the note with online links. GitHub, Qiniu Cloud and Samba are supported as upload targets. Uploads from blacklisted domains are blocked.

    id:     "fast-image-upload"
    name:   "Fast Image Auto Uploader"
