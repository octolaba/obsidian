# Theme Quick Switch

Theme Quick Switch toggles between light, dark and follow-system modes and switches themes from Obsidian's ribbon and status bar in one click. An eye-care mode softens the interface palette and applies gentle background tones to PDF pages for less harsh reading.

```cue
plugin: {
    id:     "theme-quick-switch"
    name:   "Theme Quick Switch"
    author: "lyxtsinghua"
    repo:   "lyxtsinghua/obsidian-theme-quick-switch"

    html_url:    "https://community.obsidian.md/plugins/theme-quick-switch"
    github_url:  "https://github.com/lyxtsinghua/obsidian-theme-quick-switch"
    description: "Quickly switch between light, dark, follow-system, and eye-care themes, with gentler PDF reading. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Switch themes with one click and toggle light, dark, or follow-system modes from Obsidian's ribbon and status bar. Enable an eye-care mode that softens the UI palette and applies gentle background tones to PDF pages for easier, less harsh reading."

    stats: {
        downloads:  438

    }
}
```
