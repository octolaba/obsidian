# MailDump

Exports selected IMAP folders into a single analysis-ready Markdown digest that preserves messages, metadata, subject-based threads, contacts and optional attachments, alongside optional mail notes with adjacent attachments. Unanswered items are identified, reply chains and signatures are stripped, and presets can be saved for repeat exports.
