# Media Layout

Drags, resizes and arranges images, videos, audio and note boxes on the page to build visual compositions while the underlying notes stay portable. Independent clones are moved, rotated, sized and linked, with floating notes placed alongside them. Layouts are saved as presets and reused across pages.
