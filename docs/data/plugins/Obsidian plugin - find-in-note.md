# Find in Note

Searches the rendered note and highlights every match in place, without unrendering tables, callouts or other blocks and without reflowing the layout. Highlighting uses the CSS Custom Highlight API, and searches are case-insensitive and literal. Results are navigated live with stronger emphasis on the current match and automatic scrolling, and closing the search clears the highlights and restores edit mode.
