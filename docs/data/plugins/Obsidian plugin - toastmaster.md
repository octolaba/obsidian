# Toastmaster

Toastmaster gives toast notifications a configurable duration and dismiss controls so they do not disappear before they have been read. It patches Obsidian's Notice timer to enforce a minimum display duration or to disable auto-hide entirely, and the change applies to core and plugin-generated toasts alike.

```cue
plugin: {
    id:     "toastmaster"
    name:   "Toastmaster"
    author: "Labtopia"
    repo:   "tikitock/toastmaster"

    html_url:    "https://community.obsidian.md/plugins/toastmaster"
    github_url:  "https://github.com/tikitock/toastmaster"
    description: "Configurable duration and dismiss controls for toast notifications, so they don't disappear before you finish reading them. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Extend toast notifications to last longer or persist until dismissed. Patch Obsidian's Notice timer to enforce a minimum display duration or disable auto-hide for all core and plugin-generated toasts."

    stats: {
        downloads:  94
        updated_at: 1783274286000
    }
}
```
