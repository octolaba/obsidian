# Ultimate LaTeX Converter

Converts notes to LaTeX and can optionally compile them to PDF using a bundled Python converter script. Embedded notes are unfolded into the output and Dataview tables are converted along with the prose, so a scientific paper can be assembled from several notes. Equation, table and figure references are carried across into proper LaTeX referencing.
