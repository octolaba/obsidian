# Git Sync

Syncs a vault across desktop and mobile devices through a private GitHub repository owned by the user. It commits silently and pushes in the background on every save, pulls the latest changes when the vault is opened, and offers a side-by-side interface for resolving conflicts.

```cue
plugin: {
    id:     "git-obsi-sync"
    name:   "Git Sync"
    author: "Livan Kumar"
    repo:   "livan116/github-valut-sync"

    html_url:    "https://community.obsidian.md/plugins/git-obsi-sync"
    github_url:  "https://github.com/livan116/github-valut-sync"
    description: "Sync your vault across all devices using your own GitHub account. Free forever. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync your Obsidian vault across desktop and mobile using a private GitHub repo, with silent auto-commits and background pushes on every save. Pull the latest changes on open and resolve conflicts with a side-by-side UI, keeping all files in your own GitHub account."

}
```
