# Tab Title from H1 File Title

Shows the first H1 heading of a note as its tab title instead of the filename. Tabs stay readable when filenames are terse, dated or kebab-cased, because the heading is displayed automatically.

```cue
plugin: {
    id:     "tab-title-from-file-title"
    name:   "Tab Title from H1 File Title"
    author: "Herbert Jones"
    repo:   "herbertjones/obsidian-tab-title-from-file-title"

    html_url:    "https://community.obsidian.md/plugins/tab-title-from-file-title"
    github_url:  "https://github.com/herbertjones/obsidian-tab-title-from-file-title"
    description: "Show a note's first H1 heading as its tab title. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Show a note's first-level heading (H1) as the active tab title instead of the filename. Keep tabs readable when filenames are terse, dated, or kebab-cased by displaying the note's human-friendly H1 automatically."

    stats: {
        downloads:  46

    }
}
```
