# Canvas Card Linker

Converts Canvas text cards into notes named after the card's first line. Labeled arrow connections between cards are mirrored inside the source note as wikilinks carrying the arrow's label. Processing runs on demand from a hotkey or ribbon icon, with optional background automation.

    id:     "canvas-card-linker"
    name:   "Canvas Card Linker"
    author: "hadi mozaffari "
