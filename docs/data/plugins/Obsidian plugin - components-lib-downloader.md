# Components Library Downloader

Components Library Downloader downloads file assets from Feishu wiki bitable libraries into configured folders inside the vault. The built-in components, xdbjs and forms libraries are browsed in a tabbed card view with cover previews, an image carousel and lightbox, download progress, and skip, rename or overwrite handling for duplicates. Records and attachments are fetched with Feishu Open Platform app credentials through Obsidian's requestUrl.
