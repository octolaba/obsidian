# LLM Test Generator

Generates test questions from notes with an LLM to support learning and retention, producing quizzes in any language with instant feedback tied to the source content. Several providers are recorded, among them OpenAI, Claude, Mistral, Gemini, and DeepSeek, with dynamically updated model lists, varied difficulty levels, score tracking, and a unified dashboard for managing tests.
