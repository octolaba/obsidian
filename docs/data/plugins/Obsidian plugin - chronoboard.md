# Chronoboard

Chronoboard is a Gantt-style timeboard for project-based time tracking that records its entries into the frontmatter of each note. Blocks are created, resized, moved, recolored and edited on a draggable day, week or month board, with scoped totals and statistics. Static notes such as meetings can be pinned for continuous tracking.
