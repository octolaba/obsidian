# Document Comments

Stores margin comments inside the Markdown file as HTML comments and renders them as floating cards aligned to the highlighted text in Live Preview, Source and Reading views. Threads can be resolved and reopened, carry reactions and are composed inline as ordinary edits, so other tools, git diffs and agents read the original file unchanged. An All discussions sidebar lists every comment in the note.

```cue
plugin: {
    id:     "document-comments"
    name:   "Document Comments"
    author: "Kyle McDonald"
    repo:   "kylemcd/obsidian-document-comments"

    html_url:    "https://community.obsidian.md/plugins/document-comments"
    github_url:  "https://github.com/kylemcd/obsidian-document-comments"
    description: "Notion-style margin comments stored inline in your markdown, so agents and other tools can read them too. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed Notion/Linear-style margin comments in Markdown as HTML comments and render floating cards aligned to highlighted text in Live Preview, Source, and Reading views. Keep threads, resolve/reopen, reactions and inline composing as plain edits so other tools, git diffs and agents read the original file unchanged; browse all comments in an All discussions sidebar."

    stats: {
        downloads:  2010
        updated_at: 1785516879000
    }
}
```
