# Side-Notes

Adds numbered sidenotes and un-numbered margin notes anchored to lines, displaying the reference in the page margin instead of at the bottom of the note. Sidenotes can be edited directly in the margin, are visible in both Reading and Editing modes, and can be stored either as HTML spans or as Markdown footnotes, carrying links and basic formatting. Numbering increments automatically and stays responsive to the pane width. Because the layout uses the extra margin space, sidenotes added to a document remain in the file on mobile but are not displayed in the margin there.
