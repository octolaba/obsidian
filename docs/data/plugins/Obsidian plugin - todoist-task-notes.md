# Todoist Task Notes

Creates one Markdown note per Todoist task, nested subtasks included, and synchronizes title, description, labels, project, dates, priority, recurrence, duration and completion in both directions. Notes are organized by their real Todoist project, and a Hebrew right-to-left dashboard shows project statistics and a collapsible task tree. Content under the Notes heading is preserved, tasks can be created offline, and clashing edits produce conflict copies.

```cue
plugin: {
    id:     "todoist-task-notes"
    name:   "Todoist Task Notes"
    author: "Nataniel shulkin"
    repo:   "natysh1011/obsidian-todolistsync"

    html_url:    "https://community.obsidian.md/plugins/todoist-task-notes"
    github_url:  "https://github.com/natysh1011/obsidian-todolistsync"
    description: "Creates one hierarchical Obsidian note per Todoist task with two-way synchronization. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create one Markdown note per Todoist task (including nested subtasks) and synchronize key fields (title, description, labels, project, dates, priority, recurrence, duration, completion) bidirectionally with Todoist. Organize notes by real Todoist project, show a Hebrew RTL dashboard with project stats and a collapsible task tree, preserve ## Notes content, support offline creation and generate conflict copies."
```
