# Word Viewer

Opens .docx files in a read-only view by parsing the OOXML package locally, with no cloud conversion involved. Metadata, headings, text, tables, comments, notes and media can be inspected, with filters over what is shown. Package diagnostics warn about external relationships, macros, tracked changes, and encrypted or malformed files.
