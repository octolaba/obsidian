# Lineage

Provides a writing interface that edits Markdown files in a Gingko-style tree of cards, combining structure and content for hierarchical outlining. The recorded inputs credit Gingko Writer as the inspiration. Files open from the ribbon, the file context menu, or the command palette, and outlines can be exported from the view context menu.
