# Audio Player

Audio Player replaces the default HTML5 audio element with a single audio instance shared across the vault and a persistent wave visualiser that keeps playing after the note is closed. Bookmarks are added by double-clicking the waveform or by listing timestamped chapters inside an audio-player block, and pause and resume commands control playback.
