# TileLineBase

TileLineBase builds multidimensional, text-based databases inside Markdown notes with no frontmatter and no code. One set of records is viewed and managed as a Table, a Kanban board, a Gallery or Slides, with inline formulas, smart date and time parsing, automatic note linking and built-in GTD task statuses.
