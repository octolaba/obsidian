# TsumugiMark

Replaces the standard Markdown editor with a vertical writing view aimed at Japanese text, novels and screenplays. Editing happens in the vertical pane with live preview, ruby annotation for furigana, and a character counter for the document or the selection. Fonts, sizes and spacing are configurable.

```cue
plugin: {
    id:     "tsumugi-mark"
    name:   "TsumugiMark"
    author: "mofukuru"
    repo:   "mofukuru/TsumugiMark"

    html_url:    "https://community.obsidian.md/plugins/tsumugi-mark"
    github_url:  "https://github.com/mofukuru/TsumugiMark"
```
