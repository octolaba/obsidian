# Transfer LaTeX from GPT Fix

Transfer LaTeX from GPT Fix translates LaTeX formulas generated by OpenAI GPT into MathJax format, producing inline and display math that renders in Obsidian. It processes pasted ChatGPT answers and exists to fix the bug that stopped the original Transfer LaTeX from GPT plugin working.

    id:     "transfer-latex-from-gpt-fix"
    name:   "Transfer LaTeX from GPT Fix"
