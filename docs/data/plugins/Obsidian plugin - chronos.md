# Chronos Timeline

Chronos Timeline renders interactive timelines from a chronos Markdown block or an inline block, covering date ranges, single-point events, grouping, colors and links to notes. A timeline can be generated from highlighted text with AI, and Chronos items across a folder combined into one merged, linkable overview.

```cue

    id:     "chronos"
    name:   "Chronos Timeline"
    author: "Claire Froelich"
```
