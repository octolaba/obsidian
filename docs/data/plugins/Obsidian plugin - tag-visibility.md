# Tag Visibility

Tag Visibility controls which tags appear across Obsidian's interface, hiding, flagging or always showing a tag without modifying the notes, so every change is display-only and reversible. A dockable panel lists every tag, applies rules and per-tag overrides, and shows live diagnostics beside the native tag pane.

    id:     "tag-visibility"
    name:   "Tag Visibility"
    author: "Prisant Labs"
