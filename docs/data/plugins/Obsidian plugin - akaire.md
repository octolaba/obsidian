# Akaire

Sends a note, or only its changed paragraphs, to the Claude Code CLI and displays the returned review inline next to the paragraphs it refers to. Comments also appear in a sidebar anchored to each paragraph, textlint can optionally run for grammar and style checks, and review sessions are saved into the note frontmatter.

    id:     "akaire"
    name:   "Akaire"
