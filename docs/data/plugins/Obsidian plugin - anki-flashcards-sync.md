# Anki Flashcards Sync

Renders flashcard code blocks as preview cards in Reading view and Live Preview, one preview per template, with a front and back toggle and a playable audio button. Cards are pushed to Anki through AnkiConnect, Anki notes are created or updated from frontmatter using note-type templates, and missing decks and note types are created automatically.
