# Voice Workflow

Voice Workflow records audio in a right-hand sidebar, transcribes it live and writes a template-based summary to the top of the note. The audio and the full transcript are archived at the bottom, and meeting metadata goes into the frontmatter. Transcription, translation and summarization can each use a local or a cloud provider.

```cue
plugin: {
    id:     "voice-summary-workflow"
    name:   "Voice Workflow"
    author: "roar-jar"
    repo:   "roar-jar/obsidian-voice-workflow"

    html_url:    "https://community.obsidian.md/plugins/voice-summary-workflow"
    github_url:  "https://github.com/roar-jar/obsidian-voice-workflow"
    description: "Capture, transcribe, summarize, and archive voice meeting notes with local or cloud AI providers. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Record audio in a right-hand sidebar, transcribe live, and save template-based summaries to the top of your note. Archive audio and full transcripts at the note bottom, add meeting metadata to frontmatter, and use multiple STT and LLM providers for transcription, translation, and summarization."

    stats: {
        downloads:  81
        updated_at: 1782449672000
    }
}
```
