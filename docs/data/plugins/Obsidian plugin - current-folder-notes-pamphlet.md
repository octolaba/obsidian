# Current Folder Notes

Shows the notes of the current folder in a dedicated pane, sorted by chapter numbers with the active file highlighted. Which titles appear can be filtered, titles can be formatted to Title Case, subfolders can be included, and file headings are shown inline to jump to.

```cue
plugin: {
    id:     "current-folder-notes-pamphlet"
    name:   "Current Folder Notes"
    author: "caffa"
    repo:   "caffa/Obsidian-Current-Folder-Note-Display-Plugin"

    html_url:    "https://community.obsidian.md/plugins/current-folder-notes-pamphlet"
    github_url:  "https://github.com/caffa/Obsidian-Current-Folder-Note-Display-Plugin"
    description: "Shows a list of notes in the current folder, and allows you to filter the titles to include or exclude notes."
    about:       "Show notes from the current folder in a dedicated pane, automatically sorting them by chapter numbers and highlighting the active file. Filter which notes appear, format titles to Title Case, include subfolders, and view or jump to file headings inline for fast navigation."

    stats: {
        downloads:  2176
        updated_at: 1749743665000
    }
}
```
