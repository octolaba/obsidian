# File Info Panel

Adds a File Info view showing the active file's creation and modification dates, human-readable size, image dimensions, and links that open the file in its native application or open its folder. The same panel reports writing statistics such as characters, words, sentences and paragraphs, selected-text counts, estimated pages and word frequency analysis.

```cue

    id:     "obsidian-file-info-plugin"
    name:   "File Info Panel"
    author: "cattailnu"
    repo:   "cattailnu/obsidian-file-info-panel-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-file-info-plugin"
    github_url:  "https://github.com/cattailnu/obsidian-file-info-panel-plugin"
    description: "Create a File Info view that displays the active file's date created, date modified, file size, and links to open the file in its native application and to open the file's folder."
    about:       "Display file metadata including creation and modification dates, human-readable size, image dimensions, and links to open the file or its folder. Show writing statistics (characters, words, sentences, paragraphs), selected-text counts, estimated pages, and word frequency analysis."
```
