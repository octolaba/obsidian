# Link Trace

Publishes notes as short shareable links and tracks who has viewed them, or exports standalone HTML folders for local and offline use. Linked notes are included with working navigation, math renders through KaTeX, code is highlighted with one-click copying, and the recorded inputs also list image galleries, an auto-generated table of contents, and a status-bar publish indicator.
