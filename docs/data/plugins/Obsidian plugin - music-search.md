# Music Search

Searches the MusicBrainz database for albums, EPs, singles and other releases and fetches genres, tracklist, release date, cover art and links to MusicBrainz, Discogs and Wikipedia. A structured note is generated from template variables or a full template file. Cover art can optionally be downloaded into the vault.

```cue
plugin: {
    id:     "music-search"
    name:   "Music Search"
    author: "gfontenot"
    repo:   "gfontenot/obsidian-music-search"

    html_url:    "https://community.obsidian.md/plugins/music-search"
    github_url:  "https://github.com/gfontenot/obsidian-music-search"
    description: "Search for music releases and generate notes for them that include release metadata and links to MusicBrainz, Discogs, and Wikipedia. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Search the MusicBrainz database for albums, EPs, singles, or releases and fetch rich metadata — genres, tracklist, release date, cover art, and MusicBrainz/Discogs/Wikipedia links. Create structured notes with template variables or a full template file and optionally download cover art into your vault."

    stats: {
        downloads:  339
        updated_at: 1780688245000
    }
}
```
