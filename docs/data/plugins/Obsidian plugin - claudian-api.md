# AI Study Buddy

Embeds an AI study assistant in the sidebar that chats with Anthropic, OpenAI or OpenAI-compatible models through direct API calls with the keys kept local, and adds a local CLI path on desktop. Any Markdown note can be selected as study material, tutoring roles and guided commands shape the session, and vault files can be quoted into the chat. Conversations are saved, and spaced-repetition flashcards with an error notebook support review; the plugin runs on desktop and iPad.
