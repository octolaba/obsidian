# Bring to Front

The plugin raises the Obsidian window to the foreground when a modal or notice appears while the app is in the background. Triggers are filtered by keyword or DOM scope and a cooldown limits repeated focus events. The recorded inputs state that it works on Windows, macOS and Linux.
