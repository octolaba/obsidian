# Better Figures

Better Figures turns an image's Markdown alt text into a centered caption. Captions render in both Reading view and Live Preview through pure CSS, images with empty alt text are left unchanged, and both external URLs and internal image embeds are supported without runtime dependencies or settings.

```cue
plugin: {
    id:     "better-figures"
    name:   "Better Figures"
    author: "SunnyYYLin"
    repo:   "sunnyyylin/obsidian-better-figures"

    html_url:    "https://community.obsidian.md/plugins/better-figures"
    github_url:  "https://github.com/sunnyyylin/obsidian-better-figures"
    description: "Add captions to images using native Markdown syntax even in LIVE PREVIEW. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add centered captions to images by using the Markdown alt text as the caption. Render captions in Reading view and Live Preview with pure CSS, leave images with empty alt text unchanged, and support external URLs and internal ![[image]] embeds without runtime dependencies or settings."

    stats: {
        downloads:  179
        updated_at: 1783147311000
    }
}
```
