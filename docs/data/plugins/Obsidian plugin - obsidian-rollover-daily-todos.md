# Rollover Daily Todos

This plugin rolls unchecked checkboxes over from the most recent past daily note into today's note. The rollover runs automatically when a new daily note is created through Daily Notes or Periodic Notes, and can also be run manually from the Command Palette. The last rollover can be undone within two minutes.

```cue
plugin: {
    id:     "obsidian-rollover-daily-todos"
    name:   "Rollover Daily Todos"
    author: "lumoe"
    repo:   "lumoe/obsidian-rollover-daily-todos"

    html_url:    "https://community.obsidian.md/plugins/obsidian-rollover-daily-todos"
    github_url:  "https://github.com/lumoe/obsidian-rollover-daily-todos"
    description: "Rollover any unchecked checkboxes from your last daily note into today's note."
    about:       "Roll over incomplete todos from the most recent past daily note into today's note automatically when a new daily note is created via Daily Notes or Periodic Notes, or run the command manually from the Command Palette. Undo the last rollover within two minutes if needed."

    stats: {
        downloads:  144931
        updated_at: 1748365005000
    }
}
```
