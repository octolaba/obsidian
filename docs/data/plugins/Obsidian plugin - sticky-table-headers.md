# Sticky Table Headers

Table headers stay visible while a long table is scrolled, by pinning a lightweight cloned header to the top of the viewport. Several tables are handled independently and the pinned header follows horizontal scrolling in wide tables. The recorded inputs state that the effect is display-only, preserving table styling and changing nothing in the note.

    id:     "sticky-table-headers"
    name:   "Sticky Table Headers"
