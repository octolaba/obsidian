# Weekly Review

Opens every note created in the past week at once, so they can be reviewed in a single session. The lookback period is adjustable, so files from any recent number of days can be loaded together.

```cue
plugin: {
    id:     "weekly-review"
    name:   "Weekly Review"
    author: "brandonkboswell"
    repo:   "brandonkboswell/weekly-review"

    html_url:    "https://community.obsidian.md/plugins/weekly-review"
    github_url:  "https://github.com/brandonkboswell/weekly-review"
    description: "Open all the files you have created in the last week."
    about:       "Open all notes created in the past week for a focused review session. Adjust the lookback period to load files from any recent number of days and review them together."

    stats: {
        downloads:  7873
        updated_at: 1714959607000
    }
}
```
