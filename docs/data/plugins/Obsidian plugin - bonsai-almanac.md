# Bonsai Almanac

Tracks bonsai care windows such as repotting, feeding, pruning and wiring from species notes written as plain Markdown with frontmatter and a heading per task. An Almanac view lists every upcoming care window grouped into Open now, Coming up and Completed. Per-species care plans keep persistent check-offs, and the view refreshes when the notes change.

```cue
plugin: {
    id:     "bonsai-almanac"
    name:   "Bonsai Almanac"
    author: "Knut Hagane-Lunden"
    repo:   "dotknewt/bonsai-almanac"

    html_url:    "https://community.obsidian.md/plugins/bonsai-almanac"
    github_url:  "https://github.com/dotknewt/bonsai-almanac"
    description: "Track bonsai care windows (repotting, feeding, pruning, wiring, and more) from species notes written in Markdown with frontmatter, right inside your vault. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Track species care windows as plain Markdown notes with frontmatter and a heading per task. View an Almanac listing every upcoming care window grouped into Open now, Coming up, and Completed, and manage per-species care plans with persistent check-offs. Refresh on note changes."
```
