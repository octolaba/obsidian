# Remove Newlines

Removes hard line breaks and blank lines from a selection in the editor, or from text as it is pasted from the clipboard. Hyphenated word breaks are stripped and excessive whitespace collapsed, which turns text copied out of a PDF or a web page into clean paragraphs.

```cue

    id:     "remove-newlines"
    name:   "Remove Newlines"
    author: "handcartcactus"
    repo:   "handcartcactus/obsidian-remove-newlines"

    github_url:  "https://github.com/handcartcactus/obsidian-remove-newlines"
```
