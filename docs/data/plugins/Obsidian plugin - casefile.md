# Casefile

Tracks SOC incidents inside the vault as Markdown notes with YAML frontmatter and Jira-style issue keys, so cases stay portable, offline and version-controllable. Work is viewed through Kanban, table and Gantt views with a JQL-lite query bar, epics, swimlanes and per-severity SLA timers. Indicators of compromise can be defanged, refanged and deduplicated, and append-only timelines feed reports and shift-handover output.
