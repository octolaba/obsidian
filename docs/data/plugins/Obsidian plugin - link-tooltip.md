# Link Tooltip

Shows where a hovered link points in Live Preview and source mode, covering Markdown links, aliased wikilinks, external URLs, and internal note targets. A small floating tooltip appears near the cursor, with the target extracted from the CodeMirror syntax tree so destinations that are otherwise hidden become visible.
