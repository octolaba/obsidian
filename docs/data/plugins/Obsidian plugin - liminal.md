# Liminal

Liminal generates structured notes from raw text or a YouTube transcript, using an Anthropic Claude API key supplied by the user. It suggests relevant tags and up to three semantically related wikilinks, runs free-form instructions against a note, and searches the vault by meaning rather than by keyword.
