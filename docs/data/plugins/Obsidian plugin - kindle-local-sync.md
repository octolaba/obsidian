# Kindle Local Sync

Imports Kindle highlights and notes from a local My Clippings.txt file, typically read from a USB-connected device, into Markdown. Clippings are grouped by book into one note per title, bookmarks are skipped and duplicate entries avoided. Content you wrote outside the sync region is preserved, and the plugin states that everything stays local with no cloud service involved.

```cue
plugin: {
    id:     "kindle-local-sync"
    name:   "Kindle Local Sync"
    author: "My Ky Quan"
    repo:   "mykyquan/kindle-local-sync"

    html_url:    "https://community.obsidian.md/plugins/kindle-local-sync"
    github_url:  "https://github.com/mykyquan/kindle-local-sync"
    description: "Import Kindle highlights and notes from a local My Clippings.txt file into Markdown notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync Kindle highlights and notes from a USB-connected My Clippings.txt into your Obsidian vault as Markdown. Group clippings by book into one note per title, skip bookmarks, avoid duplicate entries, preserve user content outside the sync region, and keep everything local without cloud services."

    }
}
```
