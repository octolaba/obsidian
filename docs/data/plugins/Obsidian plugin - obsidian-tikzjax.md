# TikZJax

LaTeX and TikZ diagrams are rendered in notes from tikz code blocks. Graphs, figures, circuits, chemical diagrams, commutative diagrams and 3D or pgfplots plots are produced through packages such as chemfig, tikz-cd, circuitikz, pgfplots and amsmath.
