# YouTube downloader

Downloads YouTube videos into the vault as local files for offline viewing. The download-youtube-video command fetches a video and stores it alongside related notes, where it can be linked and referenced.

```cue
plugin: {
    id:     "youtube-downloader"
    name:   "YouTube downloader"
    author: "ai-chen2050"
    repo:   "ai-chen2050/obsidian-youtube-downloader"

    html_url:    "https://community.obsidian.md/plugins/youtube-downloader"
    github_url:  "https://github.com/ai-chen2050/obsidian-youtube-downloader"
    description: "Download videos from YouTube"
    about:       "Download YouTube videos directly into your vault as local files for offline viewing. Use the download-youtube-video command to fetch videos and store them alongside related notes for easy linking and reference."

    stats: {
        downloads:  2680
        updated_at: 1734763190000
    }
}
```
