# CmdSearch

Turns web searches into command-palette commands whose URLs are supplied by the user. Commands are added, edited or removed with a query placeholder in the URL, they can open a search or an instant link, hotkeys can be assigned, and results open in Obsidian's Web Viewer when that is enabled.

```cue
plugin: {
    id:     "cmd-search"
    name:   "CmdSearch"
    author: "spaceshipcaptain"
    repo:   "spaceshipcaptain/CmdSearch"

    html_url:    "https://community.obsidian.md/plugins/cmd-search"
    github_url:  "https://github.com/spaceshipcaptain/CmdSearch"
    description: "Use the command pallete to search web. Add your own URLs."
    about:       "Search the web from within Obsidian using custom command-palette commands. Add, edit, or remove commands using %s as a query placeholder to open search URLs or instant links, assign hotkeys for quick access, and open results in Obsidian's Web Viewer when enabled."

    stats: {
        downloads:  997
        updated_at: 1745083754000
    }
}
```
