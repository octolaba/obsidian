# Due When

Inserts a due-date marker at the cursor from four presets: the end of this week, the end of next week, the end of this month, and a never date set a hundred years ahead. The month preset resolves to the last day or the last weekday, and each preset can carry optional hashtags.

```cue
plugin: {
    id:     "due-when"
    name:   "Due When"
    author: "andrewbaxter439"
    repo:   "andrewbaxter439/due-when"

    html_url:    "https://community.obsidian.md/plugins/due-when"
    github_url:  "https://github.com/andrewbaxter439/due-when"
    description: "Add shortcuts to insert due dates for end of this week or end of next week."
    about:       "Insert [due:: YY-MM-DD] markers at the cursor with four smart presets: end of this week (Friday), end of next week (next Friday), end of this month (last day or last weekday), and \"never\" set 100 years ahead. Attach optional hashtags to each preset."

    stats: {
        downloads:  3855
        updated_at: 1687469543000
    }
}
```
