# Plugin REPL

Plugin REPL evaluates JavaScript written inside notes, running a line or a selection with a single key press in an Emacs-inspired read-eval-print loop. Scripts reach Obsidian's plugin API to move the cursor, insert text, open files and define commands. The recorded description frames this as lightweight automation and rapid iteration for plugin development, and convenience helpers are built in.
