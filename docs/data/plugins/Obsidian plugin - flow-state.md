# Flowstate

Turns handwriting and voice memos into text in the vault: handwritten notes and audio are transcribed, then formatted, named and saved. Material reaches it by photographing a notebook, recording in the mobile app, uploading from the web, sharing from another app, or emailing files to an address issued to the account. Configurable Flows decide, per kind of note, whether the transcription is appended to an existing file or creates a new one, how the title is generated and what custom instructions apply.
