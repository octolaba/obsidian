# Attachment Organizer

Sorts attachments into Workspace, Staging and Extra Scan zones, placing each file beside its note, in a subfolder, or in a specified location. Planned moves are previewed, and orphaned or missing files and filename conflicts are detected before anything is written. Moves run as batch operations and the last one can be undone.
