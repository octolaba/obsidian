# Tufte Suite

Bundles four Tufte modules in one plugin, each toggled independently: sidenotes, margin figures with captions and image quilts, inline typographic shorthands such as small caps, italic run-ins and CJK drop caps, and rendered backlink snippets. The editor stays single-column while the marginalia are shown beside it, with tap-to-reveal on narrow panes. It activates only with the Tufte theme and replaces the four standalone plugins, which are meant to be disabled while it is in use.

    id:     "tufte-suite"
    name:   "Tufte Suite"

    about:       "Render Tufte-style sidenotes, margin figures with captions and image quilts, inline typographic shorthands (small-caps, italic run-ins, CJK drop caps), and rendered backlink snippets from a single plugin. Toggle each module independently, keep the editor single-column while showing marginalia (tap-to-reveal on narrow panes), and activate only with the Tufte theme."
