# Inline Graph

Inline Graph renders force-directed node graphs from a fenced gr code block inside the note. The nodes are animated, draggable, labeled and colored, with hover tooltips and support for directed or undirected edges. Styling follows the active theme, and the plugin reports working on mobile with zero dependencies.
