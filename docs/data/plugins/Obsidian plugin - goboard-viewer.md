# Go Board Viewer

Displays SGF files and SGF code blocks as interactive Go boards with playback controls, move navigation, variation selection and game metadata, on desktop and mobile. SGF can also be edited in place by placing stones on the board and setting labels, comments and game information, after which the updated SGF can be viewed and copied.
