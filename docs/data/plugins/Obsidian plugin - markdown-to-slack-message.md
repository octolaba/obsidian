# Markdown to Slack Message

Markdown to Slack Message converts a Markdown note into Slack Block Kit message blocks. The converted content is opened in the Slack Block Kit builder, where the message can be previewed and then sent from the user's own Slack account.

```cue
plugin: {
    id:     "markdown-to-slack-message"
    name:   "Markdown to Slack Message"
    author: "idreamer"
    repo:   "idreamer/markdown-to-slack-message"

    html_url:    "https://community.obsidian.md/plugins/markdown-to-slack-message"
    github_url:  "https://github.com/idreamer/markdown-to-slack-message"
    description: "Convert a Markdown note to the Slack message blocks that enable you to send to Slack."
    about:       "Convert a Markdown note into Slack Block Kit message blocks. Open the Slack Block Kit builder with your content to preview and send the message from your Slack account."

    stats: {
        downloads:  4936

}
```
