# Mobile UX

Mobile UX adds a floating action button whose tap, long-press and draw gestures can each be bound to any Obsidian command. It also shows context-aware toolbars that adapt to the cursor or the selection, auto-merge, display icons with horizontal scrolling, and preserve editor focus.

```cue
plugin: {
    id:     "mobile"
    name:   "Mobile UX"
    author: "Justice Vellacott"
    repo:   "thejusticeman/obsidian-mobile-plugin"

    html_url:    "https://community.obsidian.md/plugins/mobile"
    github_url:  "https://github.com/thejusticeman/obsidian-mobile-plugin"
    description: "Mobile-optimized UX enhancements with floating action button, context-aware toolbars, and gestures. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add a floating action button (FAB) with tap, long-press and draw-to-trigger custom gestures to run any Obsidian command. Display context-aware toolbars that adapt to cursor or selection, auto-merge toolbars, show icons with horizontal scrolling, and preserve editor focus."

    stats: {
        downloads:  4689
        updated_at: 1780566564000
    }
}
```
