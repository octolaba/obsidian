# Export Mermaid Diagrams

Exports rendered Mermaid diagrams as SVG or PNG, either copied to the clipboard or saved to disk. Export runs from a button on the left side of the diagram or from the right-click menu, the appearance is either readable-light or matched to the theme, and PNG output can be scaled up to four times.

```cue
plugin: {
    id:     "export-mermaid-diagrams"
    name:   "Export Mermaid Diagrams"
    author: "Ameer Jamal"
    repo:   "ameer-jamal/obsidian-export-mermaid-diagrams"

    html_url:    "https://community.obsidian.md/plugins/export-mermaid-diagrams"
    github_url:  "https://github.com/ameer-jamal/obsidian-export-mermaid-diagrams"
    description: "Export rendered Mermaid diagrams as SVG or PNG — copy to clipboard or save to disk. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Export rendered Mermaid diagrams as SVG or PNG for pasting or saving outside Obsidian. Use the left-side export button or right-click menu to copy or save, choose readable-light or theme-matched appearance, and scale PNG exports up to 4×."

    stats: {
        downloads:  67
        updated_at: 1785752184000
    }
}
```
