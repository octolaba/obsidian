# TimeLineX

TimeLineX adds a timeline view to Obsidian for organizing and visualizing notes chronologically. Several timelines can be maintained at once.

    id:     "timelinex"
    name:   "TimeLineX"
    author: "Siavash Ameli"
    repo:   "siavashameli/TimelineX"
