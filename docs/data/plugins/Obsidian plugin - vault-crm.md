# Vault CRM

Keeps clients, deals and projects as plain Markdown notes in the vault, following the active theme. Interactions and to-dos are logged without leaving Obsidian or using a cloud account, deals move through a drag-and-drop pipeline with dashboard metrics and per-deal timelines, and a won deal converts into a project in one click. The recorded About states that all data stays local.
