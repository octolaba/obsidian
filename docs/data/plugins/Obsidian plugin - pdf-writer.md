# PDF Writer

Writes and fills a PDF from inside the vault by clicking anywhere on a page to add a text annotation. Font, size and color are selectable, text zones can be moved and edited, annotations are auto-saved and reloaded, and a new PDF can be exported with the text layers embedded.
