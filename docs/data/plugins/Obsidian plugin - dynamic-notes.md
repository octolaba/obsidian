# Dynamic Notes

Moves whole Markdown blocks between Now, Later and Done regions of a note as a local workflow. Plain Markdown remains the source of truth, with no hidden per-note state and no network dependency. An Advance action moves the current Now block to Done and promotes the next Later block into its place.
