# Feuillets

Turns Obsidian into a writing and editorial workspace for Markdown texts, from a single article or essay to a structured project for fiction, nonfiction, collections and books. A visual Binder, card and outline views organize the material, with research, notes and a writing journal kept beside the text, repetition review, optional linguistic feedback, and snapshots and backups. A file, folder, selection or the whole project is compiled and exported to Markdown, DOCX, EPUB, ODT or PDF, and an existing folder becomes a project without files being moved or renamed. Everything stays local in standard Markdown and needs no account, telemetry or online service.
