# Tab Navigator

Searches the open tabs with fuzzy matching over file names, paths, frontmatter aliases and tags, then switches to the chosen tab. The recorded About text also names closing duplicate tabs in bulk.

```cue
plugin: {
    id:     "tab-navigator"
    name:   "Tab Navigator"
    author: "o02c"
    repo:   "o02c/obsidian-tab-navigator"

    html_url:    "https://community.obsidian.md/plugins/tab-navigator"
    github_url:  "https://github.com/o02c/obsidian-tab-navigator"
    description: "Simple Tab Switcher, search open tabs."
    about:       "Search open tabs with fuzzy matching across file names, paths, frontmatter aliases and tags, then jump to the chosen tab instantly. Close duplicate tabs in bulk to tidy your workspace."

    stats: {
        downloads:  6998
        updated_at: 1766931996000
    }
}
```
