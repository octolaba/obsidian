# Quick Tray

Keeps Obsidian running in the Windows system tray and drives it from the tray menu or from global shortcuts. Quick notes are created and Search or the Quick Switcher opened from there, and Obsidian is hidden, restarted, opened or quit with a click. What a left-click on the tray icon does is configurable.

```cue
plugin: {
    id:     "quick-tray"
    name:   "Quick Tray"
    author: "GOODJINC"
    repo:   "goodjinc/obsidian-quick-tray"

    html_url:    "https://community.obsidian.md/plugins/quick-tray"
    github_url:  "https://github.com/goodjinc/obsidian-quick-tray"
    description: "Keep Obsidian running in the Windows tray and provide quick note/search actions. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Keep Obsidian available in the system tray and control it from the tray menu or global shortcuts. Create quick notes or open Search and Quick Switcher from the tray or via shortcuts, and hide, restart, open, or quit Obsidian with a click. Choose what the tray left-click does."

    stats: {
        downloads:  93
        updated_at: 1783497429000
    }
}
```
