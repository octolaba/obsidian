# Sidebar MiMo-Code

Sidebar MiMo-Code embeds the MiMo-Code CLI agent in the vault, which becomes its working directory, so it can read and write files, search, run bash commands and carry out multi-step workflows. Inline edits are shown as word-level diff previews, slash commands, Skills and mentions address files or subagents, Plan and Instruction modes can be toggled, and external MCP servers can be connected.
