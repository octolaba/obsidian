# Rubik Cube algorithms

Rubik Cube algorithms adds a speedcubing timer that generates a random scramble for each use, and visualizes cube algorithms on an interactive 2D cube. Colors can be customized, arrows defined, and the cube rotated while the algorithm display updates as it turns. The recorded text also points to ready-to-use OLL and PLL algorithm lists in the repository's examples.
