# Extreme Wikilinks

Extreme Wikilinks customizes how a wikilink is displayed by reading the linked file's frontmatter and applying a template, rendering icons, addresses or custom labels inline. A template can reference built-in values such as title, basename, path, wikilink, linkDestination and frontmatter, and frontmatter properties are reached with bracket syntax when their names contain spaces. JavaScript expressions are supported for conditional output.

```cue
plugin: {
    id:     "extreme-wikilinks"
    name:   "Extreme Wikilinks"
    author: "bobstanton"
    repo:   "bobstanton/extreme-wikilinks"

    html_url:    "https://community.obsidian.md/plugins/extreme-wikilinks"
    github_url:  "https://github.com/bobstanton/extreme-wikilinks"
    description: "Take your Wikilinks to the eXtreme! by using frontmatter to customize their appearance. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Customize Wikilink display using linked file frontmatter and templates to render icons, addresses, or custom labels inline. Reference built-in values (title, basename, path, wikilink, linkDestination, frontmatter), access frontmatter properties (use bracket syntax for names with spaces), and use JavaScript expressions for conditional output."

    stats: {
        downloads:  101
        updated_at: 1783513729000
    }
}
```
