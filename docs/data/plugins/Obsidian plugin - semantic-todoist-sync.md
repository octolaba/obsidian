# Semantic Todoist Sync

Builds a local semantic index of the vault for search, question answering and summarizing meeting notes, using either private or cloud AI providers. Actionable tasks are generated from notes or forwarded emails with current and past notes as context, inserted back into notes for tracking, and synchronized with Todoist in both directions. Most of the processing stays local.
