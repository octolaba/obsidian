# Semantic Todoist Sync

Semantic Todoist Sync builds a local semantic index of the vault to search it, answer questions and summarize meeting notes, using private or cloud AI with your own key. Actionable tasks are generated from notes or forwarded emails, taking current and past notes into account, inserted back into notes for tracking, and synchronized with Todoist. The sync is two-way, and the majority of processing stays local to keep it fast.
