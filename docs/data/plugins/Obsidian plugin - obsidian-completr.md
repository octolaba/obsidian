# Completr

Completr provides auto-completion for LaTeX, front matter and ordinary writing. MathJax and LaTeX commands are completed, including environment completions and commands that need not start with a backslash, and snippets are inserted with placeholders. YAML front-matter keys and learned key-value pairs are completed, large word lists loaded for suggestions, and the current file or the whole vault scanned for new words while suggestions stay responsive on very large lists.
