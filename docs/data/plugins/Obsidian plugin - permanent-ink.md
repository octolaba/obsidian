# Permanent Ink

Permanent Ink turns Backspace and Delete into strikethrough, so deleted words stay visible as crossed-out text and the thought process remains in the note. A write-forward restricted mode forces new text to the end and blocks undo and cut. The recorded inputs also list inline highlights and annotation-aware cursor navigation, with an annotation sidebar.
