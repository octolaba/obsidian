# Manuscript Export

Exports a book manuscript kept as one note per chapter to a valid EPUB without leaving the vault, including a one-command export of Longform projects. Wikilinks are rendered as plain text, image files are embedded in the EPUB, scene breaks become centered dividers, and author callouts are stripped while blockquotes and bold and italic formatting are preserved.
