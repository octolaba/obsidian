# Manuscript Export

Manuscript Export turns a book manuscript written in Obsidian, one note per chapter, into a clean and valid EPUB without leaving the vault. Wikilinks are rendered as plain text, image files are embedded into the EPUB, and scene breaks become centered dividers. Author callouts are stripped while blockquotes and bold or italic formatting are preserved.
