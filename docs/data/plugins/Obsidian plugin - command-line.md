# Command Line

Command Line copies command-line code blocks to the clipboard without selecting text, stripping prompts and command output so what is pasted is ready for a terminal. Line continuations and whitespace are preserved, Prism-based syntax highlighting and prompt defaults are provided, and both desktop and mobile are supported.
