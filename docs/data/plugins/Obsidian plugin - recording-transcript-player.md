# Recording Transcript Player

Opens a recording together with its sibling transcript in SRT, VTT, or DOTe JSON format, showing the native audio player above a clickable transcript. The active subtitle is highlighted during playback and clicking a timestamp seeks to it. The transcript can be searched with inline highlights and match navigation, and playback resumes from a saved position.
