# Quizzable

Defines, renders and plays quizzes inside Markdown notes from a simple YAML block. Seven question types and two play modes are offered, with instant scoring including partial credit, per-question feedback, retries at any time and optional progress saving. The recorded inputs state that it works fully offline, stays self-contained, and exposes an optional public API for Meta Bind and JS Engine.
