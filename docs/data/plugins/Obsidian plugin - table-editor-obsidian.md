# Advanced Tables

Improves navigation, formatting and manipulation of Markdown tables, moving between cells and rows with Tab and Enter. Columns and rows are added, removed and moved, and column alignment set. The recorded About text also names spreadsheet formulas, sorting rows by any column, CSV export and mobile support.
