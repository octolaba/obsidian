# Real Tasks

Deletes task lines shortly after their checkbox is marked done, so a note keeps only open work. Undo is preserved, so an accidentally removed line comes back with the usual undo shortcut, and completions are caught both from the editor and from external writes such as Dataview or sync. A ribbon button and commands insert a new task or sweep completed tasks on demand, on desktop and mobile.
