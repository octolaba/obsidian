# Seek

Seek searches the vault by combining semantic embeddings with keyword ranking and fusing them into a single, relevance-ranked result list, across more than 52 languages. A note can be found from its wording or from its idea, without complex configuration or setup. Everything runs locally inside Obsidian, with no external APIs and no local servers.
