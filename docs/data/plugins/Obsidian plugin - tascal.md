# Tascal

Tascal syncs ICS calendars into daily notes and renders a managed timeline showing scheduled events, free-time gaps and time-tracking statistics. Date-scoped unscheduled tasks are managed beside it, manual events can be added and linked to notes, and backlog items imported into the unscheduled list. Checkbox completion is preserved when the timeline is rebuilt.
