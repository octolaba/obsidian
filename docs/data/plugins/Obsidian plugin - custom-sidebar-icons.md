# Custom Icons

Customizes the icons of documents, folders and the Settings page to give the vault clearer visual organization. Icons are applied per file or per folder. The recorded inputs state that the remastered version is aligned with Obsidian 1.11, that CSS-based configurations were removed, and that breaking changes may require migration.
