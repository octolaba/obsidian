# Smart RED

Smart RED converts Obsidian notes into Xiaohongshu-style image cards of 1080 by 1440 pixels, with a real-time side-by-side preview and pagination driven by measurement. Markdown text, images and tables are rendered with CJK-aware line breaking and Kinsoku handling, and several templates are available. Output is a single PNG, a copied image, or a batch exported as a ZIP archive.
