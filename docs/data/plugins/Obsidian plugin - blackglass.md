# Glass

Glass runs the Claude Code CLI inside a terminal embedded in Obsidian on macOS, Linux and Windows, keeping slash commands, MCP tools and session continuity intact. It also hosts an authenticated MCP server over the vault so the assistant can read, search and optionally write notes, and adds a quick-ask modal, file-explorer queries, per-query model selection and automatic session resume.
