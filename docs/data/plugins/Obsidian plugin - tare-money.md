# Tare Money

Tare Money tracks money as plain Markdown files stored inside the vault, keeping the data local and requiring no cloud account or subscription. Transactions are added through a user interface, and balances alongside income and expenses are shown back. Multi-currency conversion, hashtag tagging, and filters by date or text are included.
