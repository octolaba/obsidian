# Order Manager

Order Manager keeps accounts for small businesses, tracking clients, suppliers, inventory, transactions and debts with multi-currency support, real-time exchange rates and several accounting books. A dashboard shows KPIs, monthly charts and top products, while stock and due alerts, recurring transactions and payment reconciliation cover day-to-day bookkeeping. Records are stored as native Markdown notes with YAML frontmatter and can be exported as CSV.
