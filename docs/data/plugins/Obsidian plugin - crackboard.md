# Crackboard

Crackboard syncs Obsidian session activity with the Crackboard.dev service to record productivity and take part in leaderboard-based tracking. Session summaries and comparative statistics are available for monitoring progress over time.

```cue
plugin: {
    id:     "crackboard"
    name:   "Crackboard"
    author: "bruce-pain"
    repo:   "bruce-pain/crackboard-obsidian"

    html_url:    "https://community.obsidian.md/plugins/crackboard"
    github_url:  "https://github.com/bruce-pain/crackboard-obsidian"
    description: "tpot leaderboard productivity tracker"
    about:       "Sync Obsidian session activity with Crackboard.dev to record productivity and join leaderboard-based tracking. View session summaries and comparative stats to monitor progress and compare performance over time."

    stats: {
        downloads:  256
        updated_at: 1727368820000
    }
}
```
