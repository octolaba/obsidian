# Document Weaver

Converts Word, PDF, PowerPoint, Excel and Korean HWP or HWPx files into Markdown notes in the vault. Files are supplied by dragging them onto the window, through a watch folder such as Downloads, or from the command palette, with images extracted and front matter injected. DOCX keeps headings, emphasis, tables and images, PDF text layers get automatic heading detection, PPTX becomes one long note or one note per slide with speaker notes, spreadsheets become GitHub-flavored tables, and TXT or CSV is kept verbatim or formatted as a table. The project states that conversion runs offline with no API keys.
