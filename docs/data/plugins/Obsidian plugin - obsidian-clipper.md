# Clipper

Clipper captures highlights and web content into the vault as Markdown notes. Clips go to daily or weekly notes, or to both, HTML tables are converted to Markdown through Advanced Tables, and clipping is done from the browser with a bookmarklet or an optional Chromium extension.

    id:     "obsidian-clipper"
