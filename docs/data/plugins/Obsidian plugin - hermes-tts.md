# Hermes TTS

Hermes TTS converts a Markdown note into lightweight MP3 speech and prepends a timestamped metadata callout containing an embedded audio link. Several text-to-speech providers can be chosen, with dropdown voice choices and optional speaking-style prompts. Output is normalized to MP3 and is stated to be built for mobile-compatible runtimes.

```cue
plugin: {
    id:     "hermes-tts"
    name:   "Hermes TTS"
    author: "thematthiasleitner"
    repo:   "thematthiasleitner/hermes-tts"

    html_url:    "https://community.obsidian.md/plugins/hermes-tts"
    github_url:  "https://github.com/thematthiasleitner/hermes-tts"

Select from multiple TTS providers with dropdown voice choices and optional speaking-style prompts; output is normalized to MP3 and built for mobile-compatible runtimes."
