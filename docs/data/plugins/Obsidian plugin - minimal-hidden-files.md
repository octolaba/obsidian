# Minimal Hidden Files

Minimal Hidden Files reveals safe dotfiles and dotfolders, such as .gitignore, .env and .claude/, in Obsidian's native File Explorer without adding an extra sidebar or a custom file manager. It enables Obsidian's unsupported-file visibility while active and opens the revealed files in the normal workspace. The .obsidian, .trash and .git directories and the vault config directory stay hidden by default.

    id:     "minimal-hidden-files"
    name:   "Minimal Hidden Files"
    author: "Viggo Meesters"

    about:       "Reveal safe dotfiles and dotfolders (e.g., .gitignore, .env, .claude/) in Obsidian's native File Explorer without adding extra sidebars or a custom file manager.
