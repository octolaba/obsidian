# More Excellent Hotkeys

More Excellent Hotkeys provides commands that toggle common Markdown formatting, covering bold, italics, highlight, inline code, comment, strikethrough and underscore, by expanding or contracting the selection to the nearest word while preserving the cursor position. It also manages task checkboxes through a fuzzy picker, changes checkbox types, and promotes bullet lines to tasks. The commands are reachable from the editor context menu.

    id:     "more-excellent-hotkeys"
