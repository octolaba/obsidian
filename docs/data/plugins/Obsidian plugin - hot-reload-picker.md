# Hot Reload Picker

Hot Reload Picker reloads enabled plugins from the command palette through a searchable picker, for manual reloads during plugin development. Plugins can be favourited, several can be reloaded in one batch, and the last reload can be repeated with a single command. Dedicated quick-reload commands can be created, and the reloader itself can be hidden from lists.

```cue
plugin: {
    id:     "hot-reload-picker"
    name:   "Hot Reload Picker"
    author: "lemon695"
    repo:   "lemon695/obsidian-hot-reload-picker"

    html_url:    "https://community.obsidian.md/plugins/hot-reload-picker"
    github_url:  "https://github.com/lemon695/obsidian-hot-reload-picker"
    description: "Reload enabled plugins from the command palette for faster Obsidian plugin development. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Reload enabled plugins from the command palette using a searchable picker for fast, manual development reloads. Favorite plugins, reload multiple plugins in one batch or repeat the last reload with a single command, create dedicated quick-reload commands, and optionally hide the reloader from lists."

    stats: {
        downloads:  245
        updated_at: 1780925893000
    }
}
```
