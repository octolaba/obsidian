# ConceptLens

ConceptLens captures unfamiliar terms and technical vocabulary while reading: selecting text opens a floating toolbar offering an AI-generated overview, explanation, translation and expansion. A reusable concept note is created in one click, duplicates are detected, and output is available in several languages including right-to-left ones.
