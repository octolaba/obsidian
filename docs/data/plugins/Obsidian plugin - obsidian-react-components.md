# React Components

This plugin lets React components written in JSX be defined and rendered inside notes. Components come from JSX code blocks or from whole-note component files and can be given an optional namespace. They are then embedded inline or by invocation to display dynamic content.

```cue
plugin: {
    id:     "obsidian-react-components"
    name:   "React Components"
    author: "elias-sundqvist"
    repo:   "elias-sundqvist/obsidian-react-components"

    html_url:    "https://community.obsidian.md/plugins/obsidian-react-components"
    github_url:  "https://github.com/elias-sundqvist/obsidian-react-components"

    about:       "Create and render React components with JSX directly inside Obsidian notes. Define components via JSX code blocks or whole-note component files, assign optional namespaces, and embed components inline or by invocation to display dynamic content."
```
