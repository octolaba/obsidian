# aulycKanban

A lightweight Kanban board for tasks, with multiple task types, shared quadrants, filtering, search and archiving. Task types and quadrants can be created, renamed or removed, and tasks moved, edited, archived and restored. Per-type notes are generated automatically and kept in sync with the board as Markdown.
