# Brand icons

Brand icons renders brand logos and icons inline from a colon-delimited brand and domain syntax, with optional variant and size overrides. Icons appear next to text in both Reading view and Live Preview and are fetched from configurable icon providers.

```cue
plugin: {
    id:     "brand-icons"
    name:   "Brand icons"
    author: "richin13"
    repo:   "richin13/obsidian-brand-icons"

    html_url:    "https://community.obsidian.md/plugins/brand-icons"
    github_url:  "https://github.com/richin13/obsidian-brand-icons"
    description: "Add brand icons/logos to your notes, inline. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render brand logos and icons inline using :brand:domain: syntax, with optional |variant and |size overrides to control appearance. Show icons next to text in reading view and live preview, fetching images from configurable icon providers."

    stats: {
        downloads:  136
        updated_at: 1776999240000
    }
}
```
