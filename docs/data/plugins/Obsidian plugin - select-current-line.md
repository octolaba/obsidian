# Select current line

Select current line selects the line where the cursor is placed, highlighting it from start to end, and is bound to the Esc key by default. The hotkey can be changed to another key combination, and the same command can be invoked on mobile.

```cue
plugin: {
    id:     "select-current-line"
    name:   "Select current line"
    author: "gokulk16"
    repo:   "gokulk16/select-current-line-plugin"

    html_url:    "https://community.obsidian.md/plugins/select-current-line"
    github_url:  "https://github.com/gokulk16/select-current-line-plugin"
    description: "Select the current line where the cursor is placed. Press 'ESC' key to select."
    about:       "Select the current line by pressing Esc, highlighting from the start to the end of the line. Change the hotkey to a different key combination or invoke the same command on mobile."

    stats: {
        downloads:  4634
        updated_at: 1681232184000
    }
}
```
