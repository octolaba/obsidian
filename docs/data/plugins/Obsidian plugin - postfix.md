# Postfix

Formats the current line by typing a dot-suffix postfix and pressing space. Templates cover headings, unordered lists, blockquotes, and task items, so a plain line is turned into the corresponding Markdown without typing the markup by hand.

```cue
plugin: {
    id:     "postfix"
    name:   "Postfix"
    author: "bhagyas"
    repo:   "bhagyas/obsidian-postfix-plugin"

    html_url:    "https://community.obsidian.md/plugins/postfix"
    github_url:  "https://github.com/bhagyas/obsidian-postfix-plugin"
    description: "Use postfix completions to automatically format text."
    about:       "Convert the current line into Markdown by typing a dot-suffix postfix and pressing space. Use templates like .#, .##, .### for headings, .-, .+ for unordered lists, .> for blockquotes, and .[ ]/. [x] for task items to quickly format text."

}
```
