# OmniChat

Embeds AI chat services in a persistent Obsidian sidebar, among them ChatGPT, Claude, DeepSeek, Perplexity, Gemini and Grok. Selected text, individual notes or whole folders can be sent straight into the chat input, and services are switched from the same pane. It is desktop only, on macOS, Windows and Linux.

    id:     "aibrowser-chat"
