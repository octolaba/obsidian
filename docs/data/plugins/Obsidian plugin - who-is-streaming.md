# Who Is Streaming

Looks up which streaming services currently carry a film or television show and writes the provider, the availability status and related metadata into the note's properties. The search starts from the note title, a match is chosen by hand, and the stored tmdb_id is then used to update the note directly. The country and the set of services considered are chosen in the settings.

```cue
plugin: {
    id:     "who-is-streaming"
    name:   "Who Is Streaming"
    author: "bobstanton"
    repo:   "bobstanton/obsidian-who-is-streaming"

    html_url:    "https://community.obsidian.md/plugins/who-is-streaming"
    github_url:  "https://github.com/bobstanton/obsidian-who-is-streaming"
    description: "Discover and document which streaming services a movie is currently available to be streamed on. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Discover which streaming services carry a movie or TV show and add provider, availability status, and metadata as properties to your Obsidian note. Search by note title, pick a match, and sync using the stored tmdb_id for direct updates across your chosen country and services."

    stats: {
        downloads:  127
        updated_at: 1778762705000
    }
}
```
