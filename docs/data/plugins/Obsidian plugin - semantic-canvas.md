# Semantic Canvas

Semantic Canvas edits file properties visually on a canvas, applying changes to many Markdown notes at once based on group membership, links to files, or embeds. Typed semantic links can be created and managed, and notes can be converted into canvases and back, so that a knowledge graph is built and updated from a graph view.
