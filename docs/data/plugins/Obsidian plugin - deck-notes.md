# Deck Notes

Defines card decks from H2 headings in Markdown, then embeds individual cards in notes or browses them in a modal. Decks are filtered by hierarchical flashcards tag paths, and cards are drawn at random or by least-recent view, with optional tracking so that unseen cards come up first.

```cue
plugin: {
    id:     "deck-notes"
    name:   "Deck Notes"
    author: "ebullient"
    repo:   "ebullient/obsidian-deck-notes"

    html_url:    "https://community.obsidian.md/plugins/deck-notes"
    github_url:  "https://github.com/ebullient/obsidian-deck-notes"
    description: "Define card decks for activities, strategies, or any content you want to rotate through. Embed cards in your notes or browse them in a modal. Filter by tag hierarchies to narrow your selection. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Define card decks using H2 headings in Markdown and embed cards directly in notes or browse them in a modal. Filter decks by hierarchical #flashcards/* tags and select cards randomly or by least-recent view with optional tracking to prioritize unseen items."

    stats: {
        downloads:  144
        updated_at: 1780496186000
    }
}
```
