# Open Bridge AI

Open Bridge AI builds contextual AI conversations in the vault by attaching files, folders, selected Markdown text and specific AI replies as context before a question is asked, so short prompts such as summarize this or compare these files act on the right surrounding material. It talks to Claude, Codex, custom CLI backends and OpenAI-compatible model gateways, using either a subscription CLI login or a gateway configured with base URL, model name and optional API key. Active context chips, quoted AI replies, live CLI execution progress and Markdown session saving are included, with Chinese, English and Japanese interfaces.
