# OPML Editor

OPML Editor views and edits OPML files as interactive, collapsible outline trees inside Obsidian. Nodes expand and collapse, labels are edited by double-clicking, nodes are reordered by drag and drop, and the context menu adds or deletes them. Node attributes are inspected and edited, and the file can be toggled to raw XML with auto-save.
