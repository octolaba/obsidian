# Voz-notas

Voz-notas is a hands-free voice assistant that searches and reads the vault, answers aloud, and opens or edits notes by voice. It follows links, headings, tags and filenames, and appends to or creates notes after confirmation. Session transcripts are saved as searchable Markdown, and audio runs through OpenAI Realtime for low latency while the notes stay local.

```cue

    id:     "voz-notas"
    name:   "Voz-notas"
    author: "Fernando Abellan"
    repo:   "faccuo/voz-notas"

    about:       "Talk to your notes by voice: search and read your vault, get spoken answers, and open or edit notes hands-free. Follow links, headings, tags, and filenames; append or create notes with confirmation; save searchable session transcripts as Markdown while keeping your notes local via low-latency OpenAI Realtime audio."
}
```
