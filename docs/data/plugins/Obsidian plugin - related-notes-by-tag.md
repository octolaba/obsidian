# Related Notes by Tag

Lists notes that share tags with the currently active note in a right-sidebar panel that updates in real time. The list can be filtered by tag, made to require a minimum number of matching tags, sorted, shown with the matched tags, grouped collapsibly, and restricted by folder exclusions.

```cue
plugin: {
    id:     "related-notes-by-tag"
    name:   "Related Notes by Tag"
    author: "chrishoward-projects"
    repo:   "chrishoward-projects/related-notes-by-tag"

    html_url:    "https://community.obsidian.md/plugins/related-notes-by-tag"
    github_url:  "https://github.com/chrishoward-projects/related-notes-by-tag"
    description: "Displays list of notes in the sidebar that share tags with the currently active note."
    about:       "Discover notes that share tags with the active note to surface related content and strengthen knowledge links. Open a right‑sidebar panel that updates in real time and offers tag filters, minimum-match requirements, sorting, matched-tag display, collapsible groups, and folder exclusions."

    stats: {
        downloads:  4948
        updated_at: 1786259847000
    }
}
```
