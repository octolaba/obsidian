# syncread-assistant

Syncs articles and annotations from SyncRead into Obsidian. Authentication uses a Syncread API key, and the sync is triggered from the Obsidian action bar, importing articles and highlights as Markdown files.

```cue
plugin: {
    id:     "syncread"
    name:   "syncread-assistant"
    author: "flyer1b"
    repo:   "flyer1b/LightRead-master"

    html_url:    "https://community.obsidian.md/plugins/syncread"
    github_url:  "https://github.com/flyer1b/LightRead-master"
    description: "Sync articles from SyncRead."
    about:       "Sync articles and annotations from Syncread into Obsidian. Authenticate with your Syncread API key and trigger sync from the Obsidian action bar to import articles and highlights as Markdown files."

    stats: {
        downloads:  2104
        updated_at: 1722502323000
    }
}
```
