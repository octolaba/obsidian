# Plugin Reloader

Plugin Reloader reloads installed plugins on demand from the command palette, a hotkey or a ribbon button. That is used to force a plugin update, finish first-time initialization or apply new configuration without restarting Obsidian.

```cue
plugin: {
    id:     "plugin-reloader"
    name:   "Plugin Reloader"
    author: "benature"
    repo:   "benature/obsidian-plugin-reloader"

    html_url:    "https://community.obsidian.md/plugins/plugin-reloader"
    github_url:  "https://github.com/benature/obsidian-plugin-reloader"
    description: "Manually reload plugins."
    about:       "Reload installed plugins on demand from the command palette, a hotkey, or a ribbon button. Force plugin updates, finish first-time initialization, or apply new configurations without restarting Obsidian."

    stats: {
        downloads:  5136
        updated_at: 1711904914000
    }
}
```
