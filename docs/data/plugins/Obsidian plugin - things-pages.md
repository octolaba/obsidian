# Things3 Pages

Mirrors the Things3 Inbox, projects and areas as editable Markdown notes and synchronises task titles, notes, headings, checklists and completion states in both directions. Markdown outside the managed sections is preserved, simultaneous edits are resolved deterministically, and deletions stay local so Things items are not removed. Things 3 on macOS is required.
