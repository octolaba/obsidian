# Link Mention

Renders empty Markdown links, those written with no link text, as inline pills showing the page title and the site favicon. The underlying Markdown is left unchanged, the pill is clickable and opens the URL, and both Live Preview and Reading View are supported with fetching done by Obsidian and an in-memory cache for speed.

```cue
plugin: {
    id:     "link-mention"
    name:   "Link Mention"
    author: "robcc"
    repo:   "robcc/obsidian-link-mention-plugin"

    html_url:    "https://community.obsidian.md/plugins/link-mention"
    github_url:  "https://github.com/robcc/obsidian-link-mention-plugin"
    description: "Render empty markdown links as rich inline pills with favicon and page title. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render empty Markdown links (e.g., [](https://example.com)) as inline pills that display the page title and site favicon. Keep your Markdown unchanged, make pills clickable to open the URL, and provide Live Preview and Reading View support with Obsidian-side fetching and an in-memory cache for speed."

    stats: {
        downloads:  715
        updated_at: 1772386365000
    }
}
```
