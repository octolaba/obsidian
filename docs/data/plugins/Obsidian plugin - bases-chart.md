# Bases Chart

Bases Chart visualizes Bases data as charts rendered inside notes, built either from SQL queries or through an inline visual editor. Chart types include bar, column, pie, doughnut, gauge, line, a GitHub-style calendar heatmap and stat KPI tiles, with multi-metric queries, multi-source comparison and UNION, date bucketing, custom colors and data labels.
