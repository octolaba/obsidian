# English Reading Companion

Turns highlights made in English clippings into one aggregated learning note per source, linked in both directions with the original note. The highlighted words, phrases and sentence patterns are explained in context by an OpenAI-compatible model, which returns structured JSON. The learning note is written or updated from that data, leaving hand-written sections intact.

```cue
plugin: {
    id:     "english-reading-companion"
    name:   "English Reading Companion"
    author: "fish bird"
    repo:   "haohao1101/english-reading-companion"

    html_url:    "https://community.obsidian.md/plugins/english-reading-companion"
    github_url:  "https://github.com/haohao1101/english-reading-companion"
    description: "Analyze highlighted English text and generate structured, updateable learning notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Read and highlight English clippings in Obsidian and generate or update one aggregated learning note per source, creating a bidirectional link back to the original. Analyze highlights with an OpenAI-compatible model to explain words, phrases and sentence patterns using context, output structured JSON and write/update Markdown while preserving handwritten sections."
```
