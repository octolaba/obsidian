# Home Launcher

Replaces new tabs with a configurable home page carrying vault search, recent files, bookmarks and user-defined action buttons. Search covers names, paths, aliases, headings, tags and note contents, and results show contextual previews with the H1, section, excerpt, folder and hit count. Buttons can open files, run commands, create notes, append to the daily note, reveal folders, run saved searches or open URLs.
