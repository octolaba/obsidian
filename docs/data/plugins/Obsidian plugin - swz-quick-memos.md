# Quick Memo

Records quick notes, ideas and todos as plain Markdown in a per-day file named yyyy-MM-dd-quick-memos.md under a Quick Memo section. An overview panel adds, edits, deletes and copies block links to memos and toggles todo checkboxes that are written back to Markdown. The recorded About text also describes searching and filtering by type, tag or keyword, a three-month activity heatmap, and rebuilding the index from the Markdown.

Search and filter by type, tag or keyword, view a three-month activity heatmap, and rebuild the index from Markdown."
