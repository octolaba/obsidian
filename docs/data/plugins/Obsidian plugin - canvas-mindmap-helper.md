# Canvas Mindmap Helper

Canvas Mindmap Helper adds cards quickly and navigates between them with keyboard commands so that a canvas works like a mindmap. Automatic layouts are applied on demand or run whenever cards change, which keeps the arrangement tidy and organized.

```cue
plugin: {
    id:     "canvas-mindmap-helper"
    name:   "Canvas Mindmap Helper"
    author: "tim-smart"
    repo:   "tim-smart/obsidian-canvas-mindmap"

    html_url:    "https://community.obsidian.md/plugins/canvas-mindmap-helper"
    github_url:  "https://github.com/tim-smart/obsidian-canvas-mindmap"
    description: "Make the Canvas work like a mindmap."
    about:       "Add new cards quickly and navigate Canvas cards with keyboard commands. Apply automatic layouts manually or run auto-layout on card changes to keep mind maps tidy and organized."
```
