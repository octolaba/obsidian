# Today Alias

Shows configurable aliases such as Today or Yesterday for daily notes in the file explorer and in tab names, and hides leading date prefixes from other filenames. The change is visual only, so no files are renamed or modified and the filename sort order is preserved. Patterns are matched with Obsidian-style Moment format strings, and labels update as the day rolls over.

```cue
plugin: {
    id:     "today-alias"
    name:   "Today Alias"
    author: "tanoshia"
    repo:   "tanoshia/obsidian-today-alias"

    html_url:    "https://community.obsidian.md/plugins/today-alias"
    github_url:  "https://github.com/tanoshia/obsidian-today-alias"
    description: "Shows configurable aliases (e.g. \"Today\" / \"Yesterday\") for notes with date prefix in the file explorer. Hides date prefixes from all other notes. Sort order is preserved. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display configurable aliases (e.g., Today, Yesterday) for daily notes in the file explorer and tab name while hiding leading date prefixes from other filenames. Preserve filename sort order and make only visual changes—no files are renamed or modified. Use Obsidian-style Moment format strings for pattern matching and update labels automatically as the day rolls over."
```
