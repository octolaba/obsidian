# Dataview Autocompletion

Suggests completions for inline Dataview metadata fields while a Markdown note is being edited. The suggestions reuse field values that already exist, which reduces typing errors, and individual fields or files can be excluded from them.

```cue
plugin: {
    id:     "dataview-autocompletion"
    name:   "Dataview Autocompletion"
    author: "dnlbauer"
    repo:   "dnlbauer/obsidian-dataview-autocompletion"

    html_url:    "https://community.obsidian.md/plugins/dataview-autocompletion"
    github_url:  "https://github.com/dnlbauer/obsidian-dataview-autocompletion"
    description: "Adds autocompletion to Dataview metadata fields"
    about:       "Add autocomplete suggestions for inline Dataview metadata fields while editing Markdown notes. Reuse existing field values to reduce typing errors and exclude specific fields or files from suggestions."

    stats: {
        downloads:  2702
        updated_at: 1739615419000
    }
}
```
