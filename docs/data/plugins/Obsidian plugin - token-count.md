# Token Count

Token Count shows the token count of the active Markdown note in the status bar next to the word count, using the same tokenizers as GPT, Claude and Gemini. The count covers the entire editor content including YAML frontmatter and updates in real time while editing, the selected model name can optionally be displayed, and the feature is desktop-only.

```cue
plugin: {
    id:     "token-count"
    name:   "Token Count"
    author: "Pat"
    repo:   "lemondepat/token-count"

    html_url:    "https://community.obsidian.md/plugins/token-count"
    github_url:  "https://github.com/lemondepat/token-count"
    description: "Count tokens for the active note in the status bar next to word count (GPT, Claude, Gemini). - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display token counts for the active Markdown note in the status bar on desktop using the same tokenizers as GPT, Claude, and Gemini. Update counts in real time as you edit, count the entire editor content (including YAML frontmatter), and optionally show the selected model name."

    stats: {
        downloads:  219
        updated_at: 1779515335000
    }
}
```
