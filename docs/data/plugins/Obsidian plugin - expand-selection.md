# Expand Selection

Selects the current section with one hotkey and expands the selection again to parent sections and finally the whole note. It targets mobile, where controlling the cursor is awkward, and its recorded About suggests pairing it with Code Shortcuts for line-by-line selection.

```cue

    id:     "expand-selection"
    name:   "Expand Selection"
    author: "atait"
    repo:   "atait/obsidian-expand-selection"

    html_url:    "https://community.obsidian.md/plugins/expand-selection"
    github_url:  "https://github.com/atait/obsidian-expand-selection"
    description: "Expands the editor selection to lines, sections, or the entire note for convenience on mobile. - This plugin has not been manually reviewed by Obsidian staff."
```
