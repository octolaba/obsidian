# Continuity Sketch

Continuity Sketch uses Apple Continuity to draw on a nearby iPad with Apple Pencil and inserts the resulting image at the cursor in the current note. It captures the sketch from the iPad directly into the note inline and requires macOS 12 or later.

```cue
plugin: {
    id:     "continuity-sketch"
    name:   "Continuity Sketch"
    author: "wasmir"
    repo:   "wasmir/obsidian-continuity-sketch"

    html_url:    "https://community.obsidian.md/plugins/continuity-sketch"
    github_url:  "https://github.com/wasmir/obsidian-continuity-sketch"
    description: "Draw on a nearby iPad with Apple Pencil via Continuity Sketch and insert the image into your note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Draw on a nearby iPad with Apple Pencil via Apple Continuity Sketch and insert the resulting image at the cursor in your note. Connect via macOS Continuity to capture sketches from your iPad and add them inline (requires macOS 12+)."

    stats: {
        downloads:  359

    }
}
```
