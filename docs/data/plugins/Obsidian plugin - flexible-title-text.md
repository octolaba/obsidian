# Flexible Title Text

Changes the text that Obsidian shows in its window title bar. The format is built from a template mixing static text with variables such as the vault name.

```cue
plugin: {
    id:     "flexible-title-text"
    name:   "Flexible Title Text"
    author: "tsubasaogawa"
    repo:   "tsubasaogawa/obsidian-plugin-flexible-title-text"

    html_url:    "https://community.obsidian.md/plugins/flexible-title-text"
    github_url:  "https://github.com/tsubasaogawa/obsidian-plugin-flexible-title-text"
    description: "Change the title text. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Customize the Obsidian window title with flexible templates. Use variables like {vaultName} plus static text to build custom title formats that appear in the app's title bar."

    stats: {
        downloads:  92
        updated_at: 1779598333000
    }
}
```
