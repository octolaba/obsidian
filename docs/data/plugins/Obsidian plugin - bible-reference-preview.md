# Bible Reference Preview

Bible Reference Preview recognizes Bible references in notes and shows verse previews taken from EPUB translations that you import. Several translations can be stored and up to four compared side by side, with previews shown as floating popups or in a side panel. References are highlighted in both the editor and Reading view, and verse or comparison text can be copied to the clipboard.
