# Birthday-Tracker

Birthday-Tracker reads the birthdays of family and friends from a Markdown file of name and birthday entries. It notifies about birthdays falling today, lists people sorted by next occurrence, and opens a Year View calendar in which clicking a name shows further details.

```cue
plugin: {
    id:     "birthday-tracker"
    name:   "Birthday-Tracker"
    author: "raboro"
    repo:   "raboro/Obsidian-Birthday-Tracker-Plugin"

    html_url:    "https://community.obsidian.md/plugins/birthday-tracker"
    github_url:  "https://github.com/raboro/Obsidian-Birthday-Tracker-Plugin"
    description: "Keep track of all birthdays of your family and friends."
    about:       "Track birthdays of friends and family from a Markdown file of name=...; birthday=... entries. Receive notifications for today's birthdays, view a list sorted by next occurrence, open a Year View calendar, and click names for more details."

    stats: {
        downloads:  8702

}
```
