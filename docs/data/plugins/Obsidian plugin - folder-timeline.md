# Folder Timeline

Turns any folder into a timeline or Gantt view, plotting its notes from start and end fields in their frontmatter. A timeline view can be opened or created for a folder, showing notes as spans or as single-point events. Common frontmatter date formats are accepted, and scale, recursion into subfolders and sort order are configurable.

    id:     "folder-timeline"
    name:   "Folder Timeline"
