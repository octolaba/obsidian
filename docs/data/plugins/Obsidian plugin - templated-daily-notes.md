# Templated daily notes

Templated daily notes creates daily notes from defined templates in a single click. Shortcuts added to the right panel each carry an icon, a description, a template and a target folder for the notes they create.

```cue
plugin: {
    id:     "templated-daily-notes"
    name:   "Templated daily notes"
    author: "digitorum"
    repo:   "digitorum/obsidian-templayted-daily-notes"

    html_url:    "https://community.obsidian.md/plugins/templated-daily-notes"
    github_url:  "https://github.com/digitorum/obsidian-templayted-daily-notes"
    description: "Create daily notes with a specified template according to the described settings."
    about:       "Create daily notes from defined templates with a single click. Add right-panel shortcuts that set the icon, description, template and target folder for each new note."

    stats: {
        downloads:  2427
        updated_at: 1708172034000
    }
}
```
