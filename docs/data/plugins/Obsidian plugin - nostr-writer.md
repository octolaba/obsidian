# Nostr Writer

Nostr Writer publishes notes and short-form posts from Obsidian directly to Nostr. Images are uploaded automatically, tags can be added, and multiple Nostr profiles and relays are managed from the plugin. It also imports Nostr bookmarks as Markdown and lifts frontmatter into article metadata before publishing.

```cue
plugin: {
    id:     "nostr-writer"
    name:   "Nostr Writer"
    author: "jamesmagoo"
    repo:   "jamesmagoo/nostr-writer"

    html_url:    "https://community.obsidian.md/plugins/nostr-writer"
    github_url:  "https://github.com/jamesmagoo/nostr-writer"
    description: "Publish your writing directly to Nostr."
    about:       "Publish notes and short-form posts from Obsidian directly to Nostr. Upload images automatically, add tags, manage multiple Nostr profiles and relays, import Nostr bookmarks as Markdown, and extract frontmatter into article metadata before publishing."
```
