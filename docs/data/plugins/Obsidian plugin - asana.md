# Asana

Creates Asana tasks from the current line or from highlighted text. An Asana access token connects the plugin to a workspace, so tasks are sent there directly.

```cue
plugin: {
    id:     "asana"
    name:   "Asana"
    author: "mryanb"
    repo:   "mryanb/obsidian-asana"

    html_url:    "https://community.obsidian.md/plugins/asana"
    github_url:  "https://github.com/mryanb/obsidian-asana"
    description: "Create Asana tasks from highlighted text or the current line."
    about:       "Create Asana tasks from the current line or selected text in Obsidian. Connect with an Asana access token to send tasks directly to your Asana workspace."

    stats: {
        downloads:  1295
        updated_at: 1743907772000
    }
}
```
