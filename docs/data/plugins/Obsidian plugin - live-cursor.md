# Live-Cursor

Enables real-time collaborative editing, showing other editors' cursors and text selections inside a note. It also syncs the Obsidian configuration folder and runs a built-in background server for local vault synchronization, whose health can be monitored through admin diagnostics. The recorded description presents the plugin as free, open-source, and privacy-first.
