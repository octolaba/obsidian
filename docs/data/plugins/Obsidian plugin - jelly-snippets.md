# Jelly Snippets

Jelly Snippets inserts text snippets defined as left-hand and right-hand mappings in the settings editor. On command the typed trigger text is replaced with its mapped replacement, and multiple snippets are kept organized by divider lines.

```cue
plugin: {
    id:     "jelly-snippets"
    name:   "Jelly Snippets"
    author: "rabirabirara"
    repo:   "rabirabirara/obsidian-jelly-snippets"

    html_url:    "https://community.obsidian.md/plugins/jelly-snippets"
    github_url:  "https://github.com/rabirabirara/obsidian-jelly-snippets"
    description: "A simple text snippets plugin."
    about:       "Insert text snippets from simple lhs|+|rhs mappings defined in the settings editor. Replace typed trigger text with its mapped replacement on command and keep multiple snippets organized by divider lines."

    stats: {
        downloads:  6147
        updated_at: 1696811442000
    }
}
```
