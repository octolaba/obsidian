# YOLO

Turns the vault into an AI workspace for chat, writing, knowledge-base questions and task orchestration. An agent mode lets the assistant call tools, edit files and run reusable skills, and several chat windows can run at once. An inline quick ask and retrieval over vault content supply the context behind the answers.
