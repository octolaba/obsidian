# MTG Deck

Renders a decklist pasted into a code block as an interactive MTG deck view with card previews, official mana symbols, prices, rarity dots and automatic grouping by type. Cards preview on hover and double-faced cards flip on click, and the view toggles between a list and a visual grid. Collection tracking, format legality validation and buylist generation are included.
