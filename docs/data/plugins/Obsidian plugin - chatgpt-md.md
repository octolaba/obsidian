# ChatGPT MD

ChatGPT MD holds a conversation from any note with ChatGPT, OpenRouter or a local LLM served by Ollama or LM Studio, for drafting, editing, summarizing and discussion. Agent personas are written as Markdown files or generated by its AI Wizard. Tool calling is gated so the model asks before it reaches the vault or the web.
