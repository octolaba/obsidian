# PM Compass

Adds a task dashboard, inbox, weekly review, and interactive dependency graph on top of existing project notes and Daily Notes checklists, without a separate database. Recurring habits are inserted into daily notes, tasks are captured to an aged inbox with staleness warnings, checklist items support one-tap actions, and dependencies and priorities are managed through an inline draggable graph.
