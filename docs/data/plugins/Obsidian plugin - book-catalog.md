# Book Catalog

Book Catalog creates catalogued book notes by scanning an ISBN barcode or by searching titles and authors, pulling metadata from Open Library and Google Books. Notes are saved with automatic frontmatter for title, authors, publisher, year, pages, cover and subjects, and can also record condition, copies, valuation and custom fields. It detects duplicates, opens a Catalog base table and can reorganize book notes across the vault.
