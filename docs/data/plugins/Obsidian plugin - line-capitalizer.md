# Line Capitalizer

Capitalizes the first letter of each line automatically in edit mode as you type. Detection skips leading spaces and special characters, preserves the cursor position, and covers Unicode characters in real time. The recorded description notes that the plugin has not been manually reviewed by Obsidian staff.
