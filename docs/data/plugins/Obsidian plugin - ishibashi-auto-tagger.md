# Ishibashi Auto Tagger

Ishibashi Auto Tagger derives frontmatter tags from a note's folder path and refreshes them when notes are created, moved or renamed, while preserving manually added tags. Templates and year folders can be excluded, numeric ordering prefixes are stripped, and configured folders contribute an archive tag. Changes can be previewed, duplicate tags repaired, and tagging or cleanup run for one note, a folder or the whole vault.

Exclude templates and year folders, strip numeric ordering prefixes, add archive tags for configured folders, preview changes, repair duplicate tags, and run tagging or cleanup for a note, folder, or entire vault."
