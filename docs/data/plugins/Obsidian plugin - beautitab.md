# Beautitab

Beautitab replaces the new tab with a customizable view carrying rotating backgrounds, a greeting, the current time, random quotes and a search field placed inline or in the top-left corner. Recent files and bookmarks can be listed on the welcome screen, and every element can be toggled on or off.

    id:     "beautitab"
