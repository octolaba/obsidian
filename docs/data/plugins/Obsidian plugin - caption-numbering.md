# Caption Numbering

Caption Numbering numbers figure, table and algorithm captions written as sixth-level headings, using customizable tag-based counters and optional chapter-prefix numbering. Renumbered headings are kept in sync with the caption wikilinks that reference them, tags are suggested while typing, and per-document front-matter is supported. Numbering can also run on a timer and be removed again with one click.

plugin: {
    id:     "caption-numbering"
    name:   "Caption Numbering"
    author: "Caption Numbering Plugin"
    repo:   "zhangyitong625-zjuchem/Caption-Numbering-Obsidian"
