# Pintora

Pintora renders diagrams written in Pintora syntax inside Obsidian, with responsive output, lightbox viewing, custom themes, edge styles, titles and error reporting. Diagrams are exported or copied as PNG, SVG, WebP, Markdown or Base64. Pintora code blocks can also be converted into attachment links for embedding.

    id:     "pintora"
    name:   "Pintora"
    author: "amiaslee"
