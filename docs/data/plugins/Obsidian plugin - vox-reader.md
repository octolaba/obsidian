# Vox Reader

Vox Reader reads notes aloud using ElevenLabs, OpenAI or the built-in browser voice, with pause, resume and stop controls. A voice can be assigned globally, per folder or per note, which suits proofreading, hands-free review of meeting notes and rehearsing presentations.
