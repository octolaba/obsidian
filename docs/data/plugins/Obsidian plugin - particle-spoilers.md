# Particle Spoilers

Hides text wrapped in double vertical bars behind a shimmering particle animation, revealed by a click or a keyboard activation. The markup stays standard Markdown, and the mechanism is aimed at concealing answers, plot details or personal data.

```cue
plugin: {
    id:     "particle-spoilers"
    name:   "Particle Spoilers"
    author: "LXXVII"
    repo:   "llxzxzxll/particle-spoilers"

    html_url:    "https://community.obsidian.md/plugins/particle-spoilers"
    github_url:  "https://github.com/llxzxzxll/particle-spoilers"
    description: "Hides text between ||double vertical bars|| under a particle animation. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Hide sensitive text behind a shimmering particle \"dust\" animation and reveal it with a click or keyboard activation. Create spoilers using standard Markdown by wrapping text in double vertical bars ||like this|| to conceal answers, plot details, or personal data."

    stats: {
        downloads:  94
        updated_at: 1785920971000
    }
}
```
