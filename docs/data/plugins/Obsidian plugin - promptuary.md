# Promptuary

Highlights text in four colors and attaches bound reading notes, saved in a non-destructive sidecar JSON file rather than in the note itself. Deletions are marked and natural-language revision comments written, then aggregated in a sidebar. Selected comments can then be exported for an external AI or agent to perform the revisions in batch.
