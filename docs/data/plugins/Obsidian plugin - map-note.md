# Map Note

Map Note creates location notes that Obsidian's Bases Map view can render. Templates are populated from OpenStreetMap with coordinates, address, a lucide icon, a color and OSM metadata such as latitude, longitude, name and osm_id, so the resulting notes appear as map points.
