# Dashboard

A Chinese-language home dashboard for the vault, showing clickable note and word statistics, recent notes and folder totals. One Markdown file can be configured as an editable Todo list, installed plugins can be launched from a reorderable shortcut strip, and the note graph is drawn as an animated 3D galaxy. A continuous 365-day writing activity matrix is included, and all analysis stays local in Obsidian.
