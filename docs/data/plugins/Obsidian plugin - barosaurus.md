# Barosaurus

Puts commands, files, headings, open tabs, bookmarks, folders and tags into one searchable bar, ranked together in a single list. Results are acted on inline through an action panel, so commands run, files move through an embedded folder picker, headings are jumped to and selected text is modified without leaving the bar.

```cue
plugin: {
    id:     "barosaurus"
    name:   "Barosaurus"
    author: "polygonhunter"
    repo:   "polygonhunter/barosaurus"

    html_url:    "https://community.obsidian.md/plugins/barosaurus"
    github_url:  "https://github.com/polygonhunter/barosaurus"
    description: "One bar for everything — select text and type b for bold, jump to any note, move it to a folder, run any command. Notes, commands and open tabs in one list, ranked by what you are doing right now. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Unify commands, files, headings, open tabs, bookmarks, folders and tags into a single searchable bar. Act on results inline with an action panel — run commands, move files with an embedded folder picker, jump to headings or modify selected text without leaving the bar."

    stats: {
        downloads:  635
        updated_at: 1785837846000
    }
}
```
