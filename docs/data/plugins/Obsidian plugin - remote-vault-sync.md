# Remote Vault Sync

Backs up and syncs the vault to S3 using native git and Git LFS, so the stored copies carry version history. Commit history, file diffs, file badges, and a status-bar sync state are surfaced in the vault, and push, pull, and restore controls plus merge-conflict resolution are built in.
