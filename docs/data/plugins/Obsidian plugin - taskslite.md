# TaskLite

TaskLite manages tree-aware Markdown tasks with metadata compatible with the Tasks plugin's emoji fields for dates, recurrence, priority, assignee and identifiers. Toggling a task can cascade to its children or bubble up to its parents, recurring occurrences are created automatically with done and cancel dates, and Live Preview checkboxes are intercepted. External checkbox changes are detected, an entire file can be treated as a frontmatter task, and files can opt out through an ignore key.
