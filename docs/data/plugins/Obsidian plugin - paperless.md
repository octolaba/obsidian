# Paperless

Inserts PDFs from a paperless-ngx instance into notes and displays them in Obsidian without storing the files locally. Remote PDF references are embedded through generated share links, with one-click insertion of single or multiple documents, which keeps vault size down.

```cue
plugin: {
    id:     "paperless"
    name:   "Paperless"
    author: "talal-a"
    repo:   "talal-a/obsidian-paperless"

    html_url:    "https://community.obsidian.md/plugins/paperless"
    github_url:  "https://github.com/talal-a/obsidian-paperless"
    description: "Link your paperless-ngx documents within your vault."
```
