# Alteryx Viewer

Opens .yxmd workflows and browses .yxzp packages as read-only summaries showing metadata, tools, connections, paths, formulas and the source XML, with search. Malformed XML, duplicate or missing ToolIDs, unknown tool types and broken connections are flagged as warnings. Nothing is executed and no file is modified.

    id:     "alteryx-viewer"
    name:   "Alteryx Viewer"
