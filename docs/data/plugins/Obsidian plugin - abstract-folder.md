# Abstract Folder

Abstract Folder organizes files into dynamic virtual folders without moving them on disk. Folder relationships are declared as frontmatter links, and a virtual file explorer shows notes that have several parents. Notes can be rearranged by drag-and-drop and converted between physical and abstract folder layouts.
