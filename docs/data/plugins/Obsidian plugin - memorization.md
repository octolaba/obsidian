# Memorization

Generates study index notes from tagged notes and schedules them with the SuperMemo-2 spaced-repetition algorithm. Flashcards are generated from a tag and reviewed in sequence, and memorization notes are created or removed as the review proceeds.

    id:     "memorization"
    name:   "Memorization"
    author: "nwindian"
    repo:   "nwindian/Memorization-Plugin"

    github_url:  "https://github.com/nwindian/Memorization-Plugin"
