# Text Block Timer

Text Block Timer attaches a count-up stopwatch to a line of text so the time a task consumes is tracked. Several timers run at once with start, pause, resume and delete controls, timing data is stored persistently, and cumulative time is shown in real time. Durations are adjusted with a scroll picker, and timer changes are kept out of the undo history.
