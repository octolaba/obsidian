# Table to CSV Exporter

Tables in a reading-mode pane are exported to CSV files for use in external applications such as Power BI. Standard Markdown tables and tables produced by Dataview are both handled, and filenames are auto-incremented with a warning when they would conflict.

```cue
plugin: {
    id:     "obsidian-table-to-csv-exporter"
    name:   "Table to CSV Exporter"
    author: "metawops"
    repo:   "metawops/obsidian-table-to-csv-export"

    html_url:    "https://community.obsidian.md/plugins/obsidian-table-to-csv-exporter"
    github_url:  "https://github.com/metawops/obsidian-table-to-csv-export"
    description: "Export tables from a pane in reading mode into CSV files."
    about:       "Export table data from any reading-mode pane to a CSV file for use in external apps like Power BI. Handle tables created by Dataview or standard Markdown, auto-increment filenames to avoid overwrites, and warn on conflicts."

    stats: {
        downloads:  17558
        updated_at: 1654960322000
    }
}
```
