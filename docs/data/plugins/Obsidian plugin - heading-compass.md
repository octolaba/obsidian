# Heading Compass

Heading Compass navigates the headings of the active note through a fuzzy-search palette and a floating outline panel that stays visible. Headings are reached by click in source or preview, the outline shows tree-style hierarchy prefixes, and visibility of levels H1 through H6 is configurable. Frontmatter and fenced code blocks are ignored when headings are parsed.

    id:     "heading-compass"
