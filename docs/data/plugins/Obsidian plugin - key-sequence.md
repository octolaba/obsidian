# Key Sequence

Assigns multi-key sequences to any command, including commands contributed by other plugins, so pressing a series such as Ctrl+b followed by h triggers an action. Sequences can be restricted to Vim normal mode so they do not interfere with typing. While a prefix is in progress, sequences can be given priority to resolve clashes with ordinary hotkeys.

```cue
plugin: {
    id:     "key-sequence"
    name:   "Key Sequence"
    author: "wantchane"
    repo:   "wantchane/key-sequence-obsidian"

    html_url:    "https://community.obsidian.md/plugins/key-sequence"
    github_url:  "https://github.com/wantchane/key-sequence-obsidian"
    description: "Assign multi-key sequences to any command. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Assign multi-key sequences to any Obsidian command, including commands from other plugins, letting you press a series (e.g., Ctrl+b then h) to trigger actions. Restrict sequences to Vim normal mode to avoid interfering with typing. Give sequences priority while a prefix is in progress to resolve hotkey clashes."

    stats: {
        downloads:  54
        updated_at: 1783480459000
    }
}
```
