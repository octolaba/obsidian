# AI Notes

Records audio directly into a note and keeps the files in a folder per note. Recordings are transcribed with whisper.cpp or an OpenAI-compatible endpoint, and the transcription is merged with the written text. Summaries and structured insights are generated from the combined note and transcription using a local or cloud LLM.
