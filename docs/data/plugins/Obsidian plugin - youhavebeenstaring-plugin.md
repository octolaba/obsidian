# YouHaveBeenStaring

Adds a status-bar indicator reporting how long the vault has been open, in natural-language durations, optionally beside an accumulated total. The counter is toggled from a ribbon button, its display text is customizable, and durations are saved periodically so the totals survive.

```cue
plugin: {
    id:     "youhavebeenstaring-plugin"
    name:   "YouHaveBeenStaring"
    author: "fxal"
    repo:   "fxal/obsidian-youhavebeenstaring-plugin"

    html_url:    "https://community.obsidian.md/plugins/youhavebeenstaring-plugin"
    github_url:  "https://github.com/fxal/obsidian-youhavebeenstaring-plugin"
    description: "Add a status bar indicator showing how long your vault has been open."
    about:       "Display how long you've been staring at your vault in the status bar using natural-language durations for current and optional total time. Track accumulated staring time, toggle the counter with a ribbon button, customize the display text, and auto-save durations periodically to preserve totals."

    stats: {
        downloads:  5922
        updated_at: 1621760660000
    }
}
```
