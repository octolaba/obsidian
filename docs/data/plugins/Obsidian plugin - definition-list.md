# Definition List

Adds HTML definition lists to Obsidian and renders them in reading view as well as in live preview and source mode. Extended Syntax and Pandoc conventions are supported, including tilde definition markers and definition lines indented by two spaces. Styling is minimal and left open to further CSS customization.
