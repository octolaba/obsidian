# Find-n-Replace

Find-n-Replace provides a vault-wide search and replace sidebar view in the style of VSCode, matching with JavaScript regular expressions including capture groups. Matches are previewed in a navigable list where individual hits or whole files are selected, and results are filtered by folder or file type. Any match can be jumped to and reviewed before the replacement is applied.
