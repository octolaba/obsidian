# Import Attachments+

Imports attachments by moving or copying files into the vault on drag-and-drop or paste, then embedding or linking them. Folder locations and naming conventions are configurable, and attachment folders can be renamed, deleted and hidden. Files can also be opened externally or revealed in the system file manager.
