# New 3D Graph

New 3D Graph draws the vault as a force-directed graph in three dimensions on a canvas that pans, zooms and rotates. Node shape, size and colour are customisable, physics can be adjusted while the graph runs, and nodes are filtered or colour-coded with path:, tag: and file: queries. Clicking a node focuses it or opens the file behind it.
