# DOCX Exporter Plus

Exports the active note to docx with Markdown heading levels mapped onto Word heading levels, clickable links preserved and images and notes embedded, rendering through Obsidian so that inline styling carries over. Text colors can be adjusted for readability on white paper, image captions become numbered Word figure captions, and the file is saved beside the source note.
