# Calendar Ledger

Generates a continuous multi-year calendar inside a single Markdown file and stores records, tags, links and date ranges inline, without a separate database. A sidebar offers content, upcoming, stats, heatmap and year views for jumping to a date, adding entries, and reading heatmaps, timelines and yearly summaries. The views refresh automatically, and legacy date structures are migrated.

```cue
plugin: {
    id:     "calendar-ledger"
    name:   "Calendar Ledger"
    author: "Million"
    repo:   "millioncheung/obsidian-calendar-ledger"

    html_url:    "https://community.obsidian.md/plugins/calendar-ledger"
    github_url:  "https://github.com/millioncheung/obsidian-calendar-ledger"
    description: "Manage dates, records, ranges, tags, and statistics in one Markdown file. - This plugin has not been manually reviewed by Obsidian staff."

Open a sidebar with content, upcoming, stats, heatmap and year views to jump to dates, add inline entries, view heatmaps, timelines and yearly summaries, auto-refreshing and migrating legacy date structures."
