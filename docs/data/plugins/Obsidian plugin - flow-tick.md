# FlowTick

Renders auto-updating progress bars from the checkboxes in a note, using flowtick code blocks and the ratio of completed items. Several bars can appear in one file, and a parent task averages the progress of its direct subtasks. The bar colour changes with completion between red, green and blue.

```cue

    id:     "flow-tick"
    name:   "FlowTick"
    author: "dbachelor110"
    repo:   "dbachelor110/flow-tick"

    html_url:    "https://community.obsidian.md/plugins/flow-tick"
    github_url:  "https://github.com/dbachelor110/flow-tick"
    description: "Auto-updating progress bar based on checkbox ratio using flowtick code blocks. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Generate and auto-update visual progress bars from checklists in your notes, tracking completion across items and nested subtasks. Display multiple bars per file, average parent-task progress from direct subtasks, and change bar color to reflect completion (red, green, blue)."
```
