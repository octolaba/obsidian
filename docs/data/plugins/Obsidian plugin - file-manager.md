# File Manager

File Manager adds missing file and folder operations to the file explorer - create, duplicate, move, copy, rename, select and clipboard commands, each with a hotkey. Items are opened with a custom command or URL, and pathexplorer codeblocks list paths, including absolute paths and environment variables. On a conflict the operation can overwrite, skip or keep the existing file.
