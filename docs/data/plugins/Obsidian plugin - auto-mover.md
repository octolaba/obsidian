# AutoMover

AutoMover moves files into designated folders from rules matching filename patterns, tags or frontmatter project metadata. Full regex with capture groups builds dynamic destination paths, exclusion rules protect files, and moves run on file open, manually or on a schedule. Rules can be imported and exported and are managed through a collapsible interface.
