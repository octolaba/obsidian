# JessieCode

JessieCode renders interactive mathematical images described in JessieCode, the script language of JSXGraph, directly in Obsidian. The script is placed inside a fenced code block labeled jessiecode, and YAML frontmatter can optionally set graph attributes such as size and bounding box.

```cue
plugin: {
    id:     "jessiecode"
    name:   "JessieCode"
    author: "ryojerryyu"
    repo:   "ryojerryyu/obsidian-jessiecode"

    html_url:    "https://community.obsidian.md/plugins/jessiecode"
    github_url:  "https://github.com/ryojerryyu/obsidian-jessiecode"
    description: "Plugin for displaying interactive mathematical images described by JessieCode. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render interactive graphs defined in JessieCode (a JSXGraph script language) directly in Obsidian. Place JessieCode inside fenced code blocks labeled jessiecode and optionally use YAML frontmatter to set graph attributes like size and bounding box."

    stats: {
        downloads:  106
        updated_at: 1760075972000
    }
}
```
