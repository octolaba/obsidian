# Superstition

Routines are managed through a suitable and unsuitable system modelled on the traditional Chinese calendar. Activities are defined together with how often they are permitted, and each day lists which are recommended and which are to be avoided, which the recorded inputs present as a way to curb unnecessary tasks.
