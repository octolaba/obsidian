# Code Fence Completer

Suggests language identifiers while an opening backtick or tilde code fence is being typed, ordering recently used languages first and accepting custom identifiers such as c++, c#, foo-bar and foo.bar. Accepting a suggestion inserts an empty code block or wraps the current selection, moves the cursor inside it, and adds the closing fence when it is missing. Suggestions are suppressed on closing fences, and it works on desktop and mobile.
