# Pure Chat LLM

Turns a note into an interactive chat with an LLM that can read, search, write and manage the vault through agent tools, with destructive changes requiring explicit approval. Several LLM providers and real-time voice are supported, and the recorded inputs describe deep Obsidian integration.
