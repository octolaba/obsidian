# iso.me Maps

iso.me Maps renders Leaflet maps inline in a note from iso.me exports and compatible location formats, including JSON, CSV, Markdown, OwnTracks, Overland, GPX and GeoJSON. Visits are drawn as markers sized by duration, alongside route polylines, heatmaps, outlier markers and a stats bar. Optional day and time filters narrow what the map shows.
