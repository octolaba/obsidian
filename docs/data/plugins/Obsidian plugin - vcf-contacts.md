# VCF Contacts

VCF Contacts stores contacts as Markdown notes whose frontmatter follows the vCard standard, with avatars and birthday tracking. vCard 4.0 files can be imported and exported, and contacts are searched and linked across the vault. Phone numbers and emails support click-to-call and quick-copy actions.

```cue
plugin: {
    id:     "vcf-contacts"
    name:   "VCF Contacts"
    author: "broekema41"
    repo:   "broekema41/obsidian-vcf-contacts"

    html_url:    "https://community.obsidian.md/plugins/vcf-contacts"
    github_url:  "https://github.com/broekema41/obsidian-vcf-contacts"
    description: "manage, organize, link and interact with your contacts. structured md files according vCard (VCF) standards"
```
