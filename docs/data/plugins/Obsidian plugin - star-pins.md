# Star Pins

A file is starred from its header to pin it as an Arc-style tile at the top of the file explorer. Pinned notes, files and searches form a central list for returning to key content.

```cue
plugin: {
    id:     "star-pins"
    name:   "Star Pins"
    author: "Brightwav3"
    repo:   "brightwav3/Star-Pins"

    html_url:    "https://community.obsidian.md/plugins/star-pins"
    github_url:  "https://github.com/brightwav3/Star-Pins"
    description: "Star a file from its header to pin it as an Arc-style tile at the top of the file explorer. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Pin important notes, files, or searches for quick access. Create a central list of starred items and jump back to key content instantly."
```
