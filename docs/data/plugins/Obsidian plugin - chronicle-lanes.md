# Chronicle Lanes

Chronicle Lanes lays dated notes out as an interactive timeline of colour-coded lanes that tolerate overlapping ranges, shown either as a compact dockable overview or as a full explorer with a collapsible note inspector. Dates and categories are set from the note context menu, which writes the start, end and timeline-group fields. Lanes can be merged or filtered, a timelapse played, and the active note located chronologically.
