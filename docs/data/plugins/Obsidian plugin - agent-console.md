# Agent Console

Agent Console connects the vault to agents such as Claude Code, Codex, Gemini CLI, Kiro CLI or any custom ACP-compatible agent, which follow the links between notes and produce docs, slides, projects or code that is saved back into the notes. Several agents run at once in a tabbed sidebar, each tab keeping its own session and a status icon for busy, waiting or done. Every command an agent runs is visible and anything touching the system needs approval, and pinned notes are referenced rather than re-pasted so long chats stay token-efficient.
