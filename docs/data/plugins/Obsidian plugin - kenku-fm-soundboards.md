# Kenku FM Soundboards

Controls playback of sounds from Kenku FM soundboards. Tracks are played and stopped through commands, the Kenku FM remote play URL is configurable, and soundboard data can be reloaded when the plugin falls out of sync.

```cue
plugin: {
    id:     "kenku-fm-soundboards"
    name:   "Kenku FM Soundboards"
    author: "Rato Kuzmanić"
    repo:   "ratokuzmanic/obsidian-kenku-fm-soundboards"

    html_url:    "https://community.obsidian.md/plugins/kenku-fm-soundboards"
    github_url:  "https://github.com/ratokuzmanic/obsidian-kenku-fm-soundboards"
    description: "Control playback of sounds from Kenku FM soundboards. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Control playback of Kenku FM soundboards from Obsidian. Play and stop tracks via commands, set the Kenku FM remote play URL, and reload soundboard data when the plugin goes out of sync."
```
