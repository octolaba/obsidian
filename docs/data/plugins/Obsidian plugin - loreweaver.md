# Loreweaver

Tracks character relationships, foreshadowing and worldbuilding for novelists using only Markdown frontmatter, gathered into one dashboard. Character graphs are drawn interactively, unresolved foreshadowing is listed in a warning panel, and templates for locations, organizations and terms can be inserted. Data stays in the vault with no external network calls, and an optional local Ollama model can draft relation and foreshadowing suggestions.
