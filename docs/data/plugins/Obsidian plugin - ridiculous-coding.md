# Ridiculous Coding

Reacts to keystrokes and deletions with animated blips, booms, screen shake, newline animations, fireworks and sound effects. Characters typed earn XP and levels, with progress shown in a control panel and sidebar. Individual effects can be toggled or reduced for accessibility.

```cue
plugin: {
    id:     "ridiculous-coding"
    name:   "Ridiculous Coding"
    author: "Jacob"
    repo:   "chengou-zheng/obsidian-ridiculous-coding"

    html_url:    "https://community.obsidian.md/plugins/ridiculous-coding"
    github_url:  "https://github.com/chengou-zheng/obsidian-ridiculous-coding"
    description: "Blips, booms, fireworks, XP and levels — make your editing experience ridiculous! - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Turn typing into a gamified experience with animated blips, booms, screen shake, newline animations, fireworks and sound effects that react to keystrokes and deletions. Earn XP and level up for characters typed, view progress in a control panel/sidebar, and toggle or reduce effects for accessibility."
```
