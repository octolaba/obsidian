# Flomo Sync

Syncs Flomo memos into the vault, converting their rich HTML into Markdown files with YAML frontmatter for date, slug, source and tags. Notes are placed into folders mirroring the Flomo tags, and a memo carrying several tags is duplicated into each of them. Incremental updates, optional auto-sync and one-click login keep the content current.
