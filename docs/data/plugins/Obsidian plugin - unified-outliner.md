# Unified Outliner

Reorganizes heading sections and nested list subtrees within a single Markdown note, without moving content between files. Sections are moved, re-leveled, inspected and focused through an Outline Tree View and a Partial Edit Pane, with the selection synchronized between them and folding preserved.
