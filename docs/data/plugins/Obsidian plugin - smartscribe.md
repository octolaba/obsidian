# SmartScribe

Titles, tags, categories and summaries are generated for a note by several AI platforms, reusing tags the vault already carries and suggesting categories from the folder structure. Selected text or a whole note is rewritten, with a dual-panel preview showing the edits and suggestions before they are applied from the editor or the context menu.
