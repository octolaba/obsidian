# Limitless Lifelogs

This plugin syncs Limitless AI lifelog entries into the vault as dated Markdown files, preserving the original headings, sections, timestamps and Markdown structure. Entries are filed by date as YYYY-MM-DD.md, and a single click fetches only new or updated entries for incremental syncing.

```cue
plugin: {
    id:     "limitless-lifelogs"
    name:   "Limitless Lifelogs"
    author: "Maclean (Silk Ribbon)"
    repo:   "maclean-d/obsidian-limitless-lifelogs"

    html_url:    "https://community.obsidian.md/plugins/limitless-lifelogs"
    github_url:  "https://github.com/maclean-d/obsidian-limitless-lifelogs"
    description: "Sync your Limitless AI lifelog entries"
    about:       "Sync Limitless AI lifelog entries into Obsidian as dated Markdown files, preserving original headings, sections, timestamps, and markdown structure. Organize entries by YYYY-MM-DD.md and fetch only new or updated entries with a single click for incremental syncing."

    stats: {
        downloads:  1328
        updated_at: 1752372979000
    }
}
```
