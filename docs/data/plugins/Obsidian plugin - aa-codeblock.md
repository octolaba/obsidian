# AA Code Block

Renders fenced code blocks tagged aa in MS PGothic at 12pt so Japanese ASCII art keeps its original shape. Kerning and ligatures are disabled to hold character alignment, and the same styling is applied in Live Preview.

```cue
plugin: {
    id:     "aa-codeblock"
    name:   "AA Code Block"
    author: "azulika"
    repo:   "azulika/obsidian-aa-viewer"

    html_url:    "https://community.obsidian.md/plugins/aa-codeblock"
    github_url:  "https://github.com/azulika/obsidian-aa-viewer"
    description: "Renders aa code blocks in MS PGothic 12pt so Japanese ASCII art keeps its original shape. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render fenced code blocks tagged aa using MS PGothic at 12pt to preserve Japanese ASCII art (AA) layout. Disable kerning and ligatures to keep character alignment and apply the same styling in Live Preview so AA displays exactly as intended."

    stats: {
        downloads:  19
        updated_at: 1785288445000
    }
}
```
