# Coalesce

Merges backlinked notes into a single view instead of reading them one by one. The view is configurable and can filter by aliases and other criteria, and the recorded inputs position it as a replacement for Obsidian's option to show backlinks at the bottom of a note.

```cue
plugin: {
    id:     "coalesce"
    name:   "Coalesce"
    author: "bfloydd"
    repo:   "bfloydd/coalesce"

    html_url:    "https://community.obsidian.md/plugins/coalesce"
    github_url:  "https://github.com/bfloydd/coalesce"
```
