# Life Journal

Life Journal is a sidebar journal whose four tabs capture mood as an emotion with a note, a record of what happened, fleeting thoughts, and plans as tasks with dates extracted from natural language. Entries are timestamped automatically and written into the day's Markdown file, so all data stays as plain Markdown in the vault with no cloud storage. A review mode shows waterfall cards filtered by type, with clickable inline tags and task checkboxes that sync back to the file, and three interface styles with eight colour themes are offered. Its recorded inputs state Obsidian 0.15.0 or later and describe the layout as mobile responsive.
