# Memory Palace 3D

Turns Markdown notes into a navigable 3D memory palace of interconnected rooms. Each room section of a note is mapped into walls, faces and central floating content. The space is explored with FPS-style controls, and internal wikilinks and embedded images stay clickable inside it.
