# Better Explorer

Better Explorer adds sticky folder headers to the file explorer in the style of VS Code. Expanded parent folders pin to the top while scrolling and nested child folders stack beneath them, keeping the current context visible. The change is described as a DOM-only enhancement that preserves Obsidian's native explorer.
