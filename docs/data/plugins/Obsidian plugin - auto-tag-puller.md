# Auto Tag Puller

Auto Tag Puller aggregates lines carrying a tag from across the vault when that tag is typed. The result is either a live block that refreshes whenever the note is viewed, or a static list grouped by source file and numbered, which stays editable as ordinary text.

```cue
plugin: {
    id:     "auto-tag-puller"
    name:   "Auto Tag Puller"
    author: "pharelljordan"
    repo:   "pharelljordan/auto-tag-puller-obsidian"

    html_url:    "https://community.obsidian.md/plugins/auto-tag-puller"
    github_url:  "https://github.com/pharelljordan/auto-tag-puller-obsidian"
    description: "Automatically pulls lines containing a tag when typing it. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Aggregate tagged lines across your vault into live-updating blocks or static, editable lists. Insert live dynamic blocks that auto-refresh when viewing notes, or pull static lists grouped by source file as numbered, editable text you can modify directly."

    stats: {
        downloads:  145
        updated_at: 1781592055000
    }
}
```
