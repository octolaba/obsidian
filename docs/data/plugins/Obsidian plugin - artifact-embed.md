# Artifact Embed

Embeds interactive HTML cards in notes from a local file, a remote URL or inline source, declared in a single artifact code block. Each artifact runs in a sandboxed iframe that inherits Obsidian theme variables and carries a compact toolbar to reload it, open it externally or copy its source. Rendering works in Reading mode and in Live Preview.

```cue
plugin: {
    id:     "artifact-embed"
    name:   "Artifact Embed"
    author: "LeonYew-Ley"
    repo:   "leonyew-ley/obsidian-artifact-embed"

    html_url:    "https://community.obsidian.md/plugins/artifact-embed"
    github_url:  "https://github.com/leonyew-ley/obsidian-artifact-embed"
    description: "Embed interactive HTML files, URLs, or inline HTML as Claude-style sandboxed artifact cards inside notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed interactive HTML cards into notes from local files, remote URLs, or inline source using a single artifact code block. Run each artifact in a sandboxed iframe that inherits Obsidian theme variables and provides a compact toolbar to reload, open externally, or copy the source; works in Reading mode and Live Preview."

    }
}
```
