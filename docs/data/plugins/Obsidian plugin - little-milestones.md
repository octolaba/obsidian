# Little Milestones

Records a child's day: behavior scoring with customizable categories, diary fields, diet and activity tracking, templates, and file attachments. Reports are generated automatically and progress can be visualized over time, and the recorded inputs describe exporting structured YAML intended for AI or LLM analysis, on desktop and mobile.
