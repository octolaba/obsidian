# Insta TOC

Insta TOC generates a table of contents from an insta-toc code block and keeps it updated as the note changes. Headings can be excluded with an omit comment, HTML and special characters are preserved, and any heading hierarchy is handled along with markdown and wiki links. Bullet style, update delay, exclusions and indentation are configurable.

```cue
plugin: {
    id:     "insta-toc"
    name:   "Insta TOC"
    author: "iliftalot"
    repo:   "iliftalot/insta-toc"

    html_url:    "https://community.obsidian.md/plugins/insta-toc"
    github_url:  "https://github.com/iliftalot/insta-toc"
    description: "Simultaneously generate, update, and maintain a table of contents for your notes."
    about:       "Insert an insta-toc code block to generate a live, auto-updating table of contents. Exclude headings with <!-- omit -->, preserve HTML and special characters, and handle any heading hierarchy plus markdown and wiki-links. Set bullet style, update delay, exclusions, and indentation."

    stats: {
        downloads:  10236
        updated_at: 1774453311000
    }
}
```
