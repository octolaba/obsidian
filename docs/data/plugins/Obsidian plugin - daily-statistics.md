# Daily Statistics

Counts the characters or words written each day and displays the totals on a calendar, optionally scoped to a folder. Weekly goals can be set, a day's count edited by double-clicking its date, the character or word mode toggled, and the start of the week chosen manually. It runs on mobile and carries multiple interface languages.
