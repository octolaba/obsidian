# Markdown Image Caption

Generates Markdown-based image captions by wrapping external image links in figure and figcaption elements through simple inline commands. Figure elements are inserted or replaced, and optional lightbox grouping is added for Obsidian Publish and other Markdown editors. The recorded text states that only external image URLs are supported.
