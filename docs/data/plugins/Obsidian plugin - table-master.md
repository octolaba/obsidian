# Table Master

Combines several Markdown table editing surfaces in one interface: a floating toolbar, a visual grid editor and a right-click menu for row and column operations. Merged cells written in MultiMarkdown caret and pipe syntax are rendered in Reading view and Live Preview. Tables can also be pasted in from Excel, HTML or TSV.
