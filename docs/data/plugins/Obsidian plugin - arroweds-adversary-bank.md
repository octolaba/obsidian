# Arroweds Adversary Bank

Manages Daggerheart adversary and environment stat blocks, which are searched, created and edited as rollable renders. Encounters are run with auto-suffixed duplicate names, clickable instance naming, per-instance condition tracking, summon buttons, interactive stress and HP controls and one-click rolls.
