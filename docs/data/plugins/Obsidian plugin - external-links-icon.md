# External Links Icon

External Links Icon adds icons to external and internal links so link types are visually distinguishable and supported sites and URL schemes are highlighted. Icons for many services are built in, custom SVG icons are accepted, and the colors adapt to the active theme. The bundled assets are described as optimized for performance.

plugin: {
    id:     "external-links-icon"
    name:   "External Links Icon"
    author: "Moz"
    repo:   "moziar/obsidian-external-links-icon"

    html_url:    "https://community.obsidian.md/plugins/external-links-icon"
    github_url:  "https://github.com/moziar/obsidian-external-links-icon"
