# Space Launches

Upcoming rocket launches and space events are tracked in a sidebar panel that shows countdowns, providers, locations and status. The list is filtered by provider, location and event type, and an optional notice fires fifteen minutes before a tracked launch.

```cue
plugin: {
    id:     "space-launches"
    name:   "Space Launches"
    author: "elmoneedsarson"
    repo:   "elmoneedsarson/space-news"

    html_url:    "https://community.obsidian.md/plugins/space-launches"
    github_url:  "https://github.com/elmoneedsarson/space-news"
    description: "Track upcoming rocket launches and space events in Obsidian. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Track upcoming rocket launches and space events in Obsidian via a sidebar panel showing countdowns, providers, locations, and status. Filter by provider, location, and event type, and receive an optional 15-minute notice before tracked launches."

    stats: {
        downloads:  85
        updated_at: 1782916236000
    }
}
```
