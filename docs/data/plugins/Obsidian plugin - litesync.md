# LiteSync

Synchronizes vaults across desktop and mobile through a self-hosted server, so the notes do not pass through a third-party cloud. Per-file revisions are incremental, Markdown files are merged three ways automatically, and version history is immutable. Content is end-to-end encrypted with device-trusted keys, and encrypted sharing can be revoked.
