# Xournalpp

Exports Xournal++ notes to PDF whenever the source changes, so handwritten pages can be linked, embedded and previewed in Obsidian. New .xopp files are created from the ribbon, the file explorer or the command palette, and existing ones open in Xournal++ from a PDF preview or the explorer. The recorded About text advises backing up the vault, since a PDF sharing a name and location with a .xopp file can be overwritten.

    id:     "xournalpp"
    name:   "Xournalpp"
    author: "Jon Jampen"
    repo:   "jonjampen/obsidian-xournalpp"

    github_url:  "https://github.com/jonjampen/obsidian-xournalpp"
    description: "Integration with Xournal++ for handwritten notes and annotations."
    about:       "Export Xournal++ notes to PDF automatically whenever they change, enabling links, embeds, and in-Obsidian previewing. Create .xopp files from the ribbon, file explorer, or command palette and open files directly in Xournal++ from PDF preview or file explorer. Back up your vault to avoid overwriting PDFs that share names and locations with .xopp files."
