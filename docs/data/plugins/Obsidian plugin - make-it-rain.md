# Make It Rain

Pulls Raindrop.io bookmarks, highlights and attachments into Markdown notes with rich metadata, smart folder structures and native file support. Imports use flexible filters and selective sync, or run as a bulk import or a quick import by URL or ID. Note output is customized with Handlebars templates and smart variables, and content is organized by group, collection, tag or type.
