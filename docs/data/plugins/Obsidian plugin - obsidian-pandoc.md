# Pandoc Plugin

This plugin adds commands that export notes through Pandoc to Word, PDF, ePub, HTML, PowerPoint, LaTeX and many other formats. Presentations, books, webpages or assignments can be written in Markdown and produced as ready-to-use output. The recorded text advises proofreading exported files for minor formatting issues.

```cue
plugin: {
    id:     "obsidian-pandoc"
    name:   "Pandoc Plugin"
    author: "oliverbalfour"
    repo:   "oliverbalfour/obsidian-pandoc"

    html_url:    "https://community.obsidian.md/plugins/obsidian-pandoc"
    github_url:  "https://github.com/oliverbalfour/obsidian-pandoc"
    description: "Commands to export to Pandoc-supported formats like DOCX, ePub and PDF."
    about:       "Export notes to Word, PDF, ePub, HTML, PowerPoint, LaTeX and many other formats using Pandoc directly from Obsidian. Write presentations, books, webpages or assignments in Markdown and produce ready-to-use outputs; proofread exported files for minor formatting issues."

    stats: {
        downloads:  542765
        updated_at: 1664139062000
    }
}
```
