# Raindrop.io

Browses saved Raindrop.io bookmarks in an explorer side pane that is aware of the active note. The explorer filters by the tags and external links of that note, and manual searches support tags, phrases and operators. Saved Raindrop.io links also render inline from a fenced raindrop code block.

```cue
plugin: {
    id:     "raindrop-io"
    name:   "Raindrop.io"
    author: "Lukas Wolfsteiner"
    repo:   "dotwee/obsidian-raindropio-plugin"

    html_url:    "https://community.obsidian.md/plugins/raindrop-io"
    github_url:  "https://github.com/dotwee/obsidian-raindropio-plugin"
    description: "Browse Raindrop.io links with note-aware search filters. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Browse saved Raindrop.io bookmarks in a note-aware explorer side pane inside Obsidian. Filter the explorer by active note tags and external links, run manual searches with tag/phrase/operator support, and render saved Raindrop.io links inline from fenced raindrop code blocks."

    stats: {
        downloads:  218
        updated_at: 1783333837000
    }
}
```
