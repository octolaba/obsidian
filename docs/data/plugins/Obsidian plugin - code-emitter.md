# Code Emitter

Executes code blocks interactively inside a note, in the manner of a notebook. Python, TypeScript and JavaScript run locally in JavaScript and WebAssembly sandboxes, while many other languages are evaluated through online playgrounds, on desktop and mobile alike. The recorded inputs warn against sending sensitive source code to those remote services.
