# Note Illustrator

Note Illustrator generates an image from a chosen description heading and replaces a placeholder image in the note with it, calling an OpenAI-compatible API that defaults to DALL-E 3. Regenerating a past image asks for confirmation, the embed matches the placeholder's dimensions, and the plugin can optionally update frontmatter image keys or move the replaced file to trash.
