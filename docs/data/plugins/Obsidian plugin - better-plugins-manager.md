# Better Manager

Better Manager extends plugin management with delayed start, batch operations, groups and tags, custom names and notes, and installation from a GitHub repository. A binary-search wizard helps isolate conflicting plugins and can export a Markdown report, while ribbon icons are customizable and the layout adapts to mobile.
