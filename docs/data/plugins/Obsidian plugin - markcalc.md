# MarkCalc

MarkCalc evaluates spreadsheet-style formulas inside Markdown tables and writes the results back as plain Markdown, so the values remain readable, versionable and usable outside Obsidian rather than living in a rendered view. It covers aggregates, lookups, dates and custom functions, and tables can be referenced across notes with automatic recalculation. In-note functions can be embedded and formula entry has context-aware autocomplete.
