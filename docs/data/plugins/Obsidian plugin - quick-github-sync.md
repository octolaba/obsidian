# Quick GitHub Sync

Synchronizes the vault with a GitHub repository from the ribbon or the Command Palette in one click. Remote changes are pulled before local commits are pushed, the current branch is detected automatically, and the GitHub personal access token is kept in Obsidian's local storage so that it is not committed.

```cue
plugin: {
    id:     "quick-github-sync"
    name:   "Quick GitHub Sync"
    author: "M1LLKY"
    repo:   "m1llky/obsidian-github-vault-sync"

    html_url:    "https://community.obsidian.md/plugins/quick-github-sync"
    github_url:  "https://github.com/m1llky/obsidian-github-vault-sync"
    description: "Sync your vault with a GitHub repository in one click. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync your vault with a GitHub repository in one click from the ribbon or Command Palette. Pull remote changes before pushing local commits, auto-detect the current branch, and keep your GitHub PAT stored securely in Obsidian's local storage so it won't be committed."

    stats: {
        downloads:  80
        updated_at: 1780854484000
    }
}
```
