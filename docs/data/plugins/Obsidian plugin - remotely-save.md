# Remotely Save

Syncs notes between the vault and a cloud provider, covering Amazon S3 and R2, Dropbox, OneDrive, WebDAV, Google Drive, Box, pCloud, Yandex Disk, Koofr, and Azure Blob Storage, on desktop and mobile. End-to-end encryption, scheduled auto-sync, conflict handling, and regex filters that skip large files or given paths are included.
