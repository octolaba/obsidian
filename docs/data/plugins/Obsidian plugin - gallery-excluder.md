# Gallery Excluder

Creates .nomedia files in selected vault folders so Android gallery and media apps stop indexing images, while the files stay accessible and syncable in Obsidian. The whole vault, the attachment folder, or specific folders can be protected. Pre-existing .nomedia files are left untouched, created paths are tracked so they can be removed again, and protection is applied when the vault opens or a folder is added.
