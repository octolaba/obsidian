# Canvas2Document

Canvas2Document converts a complete Canvas into a single linear Markdown document containing its cards, notes and embedded media, namely images, audio, video and PDF, along with their metadata. Canvas links are recreated as metadata headers, so the resulting document can be navigated, reordered, cleaned up and edited further.
