# Default New Tab Page

Default New Tab Page opens a note of your choice, or the Quick Switcher, whenever a new tab is created, in the manner of a browser's new-tab page. Any note can serve — a homepage, the daily note, a scratchpad — as can a dataview-driven random quote. The recorded description states that the plugin is in maintenance mode and will receive no new features.
