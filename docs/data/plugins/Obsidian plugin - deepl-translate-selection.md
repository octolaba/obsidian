# DeepL Translate Selection

Translates the current selection through the DeepL API using its quality_optimized engine, from the editor right-click menu or from the command palette. The Chinese and English direction is detected automatically, and the result is inserted below the selection, replaces it, or is copied to the clipboard. Free and Pro API keys are both supported.
