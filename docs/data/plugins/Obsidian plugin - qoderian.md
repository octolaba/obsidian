# Qoderian

Embeds the Qoder CLI in the vault and makes the vault the agent's working directory for file reads and writes, search, shell commands and multi-step workflows. A chat sidebar streams qodercli responses, notes and files are brought into context with @mentions, and inline edits are shown with diff previews. Bash and instruction modes, permission and model controls, and multi-tab conversations are available.
