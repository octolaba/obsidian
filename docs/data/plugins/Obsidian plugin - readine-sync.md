# Readine Sync

Performs a one-way sync of Readine articles into the vault as Markdown or HTML files, preserving local edits so synced notes are never overwritten silently. Path and article templates are customizable, syncs run manually or on a schedule, and attachments can be fetched. Deletion and network policies are configurable, and progress is shown live with crash recovery.

```cue
plugin: {
    id:     "readine-sync"
    name:   "Readine Sync"
    author: "Readine"
    repo:   "readineapp/readine-obsidian"

    html_url:    "https://community.obsidian.md/plugins/readine-sync"
    github_url:  "https://github.com/readineapp/readine-obsidian"
    description: "One-way sync of Readine articles into Obsidian vault as Markdown ot Html files; auto-sync, local-edit protection. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync Readine articles into your vault in one direction, preserving local edits so synced notes are never overwritten silently. Choose Markdown or HTML output, customize path and article templates, run manual or scheduled syncs, fetch attachments, control deletion and network policies, and monitor live progress with crash recovery."

    }
```
