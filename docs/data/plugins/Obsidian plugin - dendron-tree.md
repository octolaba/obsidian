# Dendron Tree

Adds a collapsible tree view for exploring Dendron notes, opening and expanding them from the tree. Missing notes can be looked up and created with autogenerated frontmatter, files deleted, and multiple vaults managed. Custom resolvers and renderers for Dendron links and embeds can be enabled optionally.

```cue
plugin: {
    id:     "dendron-tree"
    name:   "Dendron Tree"
    author: "levirs565"
    repo:   "levirs565/obsidian-dendron-tree"

    html_url:    "https://community.obsidian.md/plugins/dendron-tree"
    github_url:  "https://github.com/levirs565/obsidian-dendron-tree"
    description: "Add tree for exploring Dendron note."
    about:       "Browse Dendron notes in a collapsible tree view and open or expand notes directly. Lookup and create missing notes with autogenerated frontmatter, delete files, manage multiple vaults, and optionally enable custom resolvers/renderers for Dendron links and embeds."

    stats: {
        downloads:  5015
        updated_at: 1695652407000
    }
}
```
