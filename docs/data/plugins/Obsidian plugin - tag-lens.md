# Tag Lens

Tag Lens visualizes tag-note relationships in a vault of Bases files through four interactive view modes. A co-occurrence heatmap grids tag against tag and shades each cell by the notes two tags share, drilling down to that intersection; an intersection lattice tiers exact intersections by degree with subset links, switching between overview, density and card rendering by note count and zoom. BubbleSets draws containment as rectangular iso-contour bubbles, and an Icon Gallery tiles one zoomable icon per note showing its tag-intersection groups and its link and backlink relations.
