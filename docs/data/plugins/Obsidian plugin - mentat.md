# Mentat

Organizes notes, classifies and tags content with AI, and suggests links between related notes. A retrieval-augmented chat answers questions against the knowledge base, an interactive 3D graph visualizes the notes, and spaced-repetition reviews run over them. Tasks are routed across OpenAI-compatible, Anthropic or local Ollama models; the recorded description also names local command operations and mathematical reasoning.
