# Withings Sync

Writes Withings scale measurements into the frontmatter of core Daily Notes automatically in the background, keeping only the latest reading for each day. The metrics to track can be selected and their field names renamed. Up to a year of history can be backfilled, and values are stored in the chosen units and decimal locale; desktop only.

```cue
plugin: {
    id:     "withings-sync"
    name:   "Withings Sync"
    author: "Iyigun Cevik"
    repo:   "iyiguncevik/obsidian-withings-sync"

    html_url:    "https://community.obsidian.md/plugins/withings-sync"
    github_url:  "https://github.com/iyiguncevik/obsidian-withings-sync"
    description: "Sync Withings scale measurements into core Daily Notes frontmatter (desktop only). - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync Withings scale measurements into Daily Notes frontmatter automatically and in the background, keeping only the latest reading per day. Select which metrics to track and rename fields, backfill up to one year of history, and store values in your preferred units and decimal locale."

    stats: {
        downloads:  16

    }
}
```
