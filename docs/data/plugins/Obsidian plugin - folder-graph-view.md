# Folder Graph View

Replaces the link-formed graph view with one that follows the folder structure. Named nodes are added for the parent folders of every node, and links between them turn the graph into a tree.

```cue
plugin: {
    id:     "folder-graph-view"
    name:   "Folder Graph View"
    author: "Co"
    repo:   "codaloc/FolderGraph"

    html_url:    "https://community.obsidian.md/plugins/folder-graph-view"
    github_url:  "https://github.com/codaloc/FolderGraph"
    description: "Replaces the link-formed graph view by a graph following the folder structure. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "This plugin will modify your existing obsidian graph view to add named nodes for the parent folders of every node and links between them creating a tree structure."
```
