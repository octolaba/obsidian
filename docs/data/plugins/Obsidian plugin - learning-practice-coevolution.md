# Learning Practice Coevolution

This plugin structures reading of books, articles, PDFs, courses and concepts into a repeatable loop: the idea is reconstructed in the reader's own words, taken to an AI agent for critique and concept repair, and then applied in one real task. Observer notes capture what changed and choose the next practice or reading target. Its recorded inputs state that prompts and session records are stored locally and that the plugin itself calls no AI API, collects no telemetry and makes no network requests.
