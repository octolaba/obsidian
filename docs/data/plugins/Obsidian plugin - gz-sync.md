# GZH Sync

Syncs the current Obsidian Markdown note to a WeChat Official Account draft and to Feishu cloud documents through a local gz CLI. The Markdown is converted to WeChat-compatible HTML, and images and the cover are uploaded before drafts are created on both services. Drafts are left for manual checking before publishing.

    id:     "gz-sync"
    name:   "GZH Sync"
    author: "观自"
