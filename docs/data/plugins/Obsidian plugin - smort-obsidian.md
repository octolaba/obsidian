# Smort

Articles from Smort.io are imported as Markdown and pasted into the vault, where they can be edited, annotated and shared. Highlights inside an article are converted to Markdown in a single color, and the recorded inputs note that a highlight spanning bold, italic or blockquote sections may be split into several entries.

```cue
plugin: {
    id:     "smort-obsidian"
    name:   "Smort"
    author: "smortapp"
    repo:   "smortapp/obsidian-smort"

    html_url:    "https://community.obsidian.md/plugins/smort-obsidian"
    github_url:  "https://github.com/smortapp/obsidian-smort"
    description: "Add Smort.io articles to your vault, and easily edit, annotate and share articles."
    about:       "Import Smort.io articles as Markdown and paste them directly into your vault. Convert article highlights to Markdown in a single color; highlights spanning bold/italic/blockquote sections may be split into multiple entries."

    stats: {
        downloads:  3854
        updated_at: 1649218729000
    }
}
```
