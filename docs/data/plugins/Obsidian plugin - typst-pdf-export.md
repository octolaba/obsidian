# Typst PDF Export

Exports a note or a collection of notes to PDF through the Typst typesetting system. Built-in or custom templates are selected per export, folders can be exported in batch, images, PDFs and attachments are embedded, and the layout is single-page or paginated. Progress is shown live and fonts are discovered automatically.
