# Co-Intelligence AI

Provides chat, search and research inside Obsidian's main window, backed by models from OpenAI, Anthropic, Google and Perplexity. Conversations are saved as Markdown notes, notes and tags are added as contextual input, the model can be switched mid-chat, custom system prompts defined, and chats renamed automatically.
