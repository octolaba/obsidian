# Better Recall

Better Recall adds Anki-style decks and cards to the vault and runs spaced-repetition review sessions inside Obsidian. Scheduling uses either the Anki algorithm or FSRS, with timings and multipliers adjustable per deck.

```cue
plugin: {
    id:     "better-recall"
    name:   "Better Recall"
    author: "florianwoelki"
    repo:   "florianwoelki/obsidian-better-recall"

    html_url:    "https://community.obsidian.md/plugins/better-recall"
    github_url:  "https://github.com/florianwoelki/obsidian-better-recall"
    description: "Add anki-like spaced repetition and recall to your vault."
    about:       "Create Anki-style decks and cards inside Obsidian and run spaced-repetition review sessions directly in your vault. Use Anki or FSRS algorithms to schedule reviews and adjust timings and multipliers per deck."
```
