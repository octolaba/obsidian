# Alt-Click to Copy

Copies a codeblock to the clipboard when it is Alt-clicked in reading view. No selecting or highlighting is needed to grab the code or text.

plugin: {
    id:     "alt-click-to-copy"
    name:   "Alt-Click to Copy"
    author: "veersheth"
    repo:   "veersheth/obsidian-alt-click-to-copy"

    html_url:    "https://community.obsidian.md/plugins/alt-click-to-copy"
