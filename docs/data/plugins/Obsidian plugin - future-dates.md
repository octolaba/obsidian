# Future Dates

Collects links carrying future dates into a right panel so upcoming tasks and notes can be tracked in one place. The date information is taken from Daily Notes templates.

```cue
plugin: {
    id:     "future-dates"
    name:   "Future Dates"
    author: "slonoed"
    repo:   "slonoed/obsidian-future-dates"

    html_url:    "https://community.obsidian.md/plugins/future-dates"
    github_url:  "https://github.com/slonoed/obsidian-future-dates"
    description: "Show list of future dates in vault"
    about:       "Collect all links with future dates into a right panel for easy tracking of upcoming tasks and notes. Pull date information from Daily Notes templates to surface upcoming entries in one place."
```
