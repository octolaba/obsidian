# Zotero Direct

Zotero Direct generates literature notes from a Zotero library by importing metadata such as title, authors and abstract, while excluding PDF highlights, annotations and images. It reads the Zotero database directly, so no extra plugin or export step is needed, and it keeps note creation manual in order to encourage active organization.
