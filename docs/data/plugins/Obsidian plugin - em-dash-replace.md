# Em Dash Replace

Replaces two consecutive dashes with an em dash in real time as they are typed. Replacement is skipped inside code blocks and inline code so code formatting is preserved, and the plugin runs on desktop and mobile.

```cue
plugin: {
    id:     "em-dash-replace"
    name:   "Em Dash Replace"
    author: "jefrry"
    repo:   "jefrry/obsidian-em-dash-replace"

    html_url:    "https://community.obsidian.md/plugins/em-dash-replace"
    github_url:  "https://github.com/jefrry/obsidian-em-dash-replace"
    description: "Replaces double dashes with em dashes in real time. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Replace consecutive double dashes (--) with an em dash (—) automatically as you type. Preserve code formatting by skipping replacements inside code blocks and inline code, and run on desktop and mobile."

    stats: {
        downloads:  360
        updated_at: 1769089685000
    }
}
```
