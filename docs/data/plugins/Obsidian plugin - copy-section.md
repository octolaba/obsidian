# Copy Section

Copy Section adds a copy button to heading lines that copies the whole section as raw Markdown up to the next header of the same level. Comment lines and tag-only lines can be omitted, sub-sections either included or cut off at the next header, and the header levels that show the button are configurable.

```cue
plugin: {
    id:     "copy-section"
    name:   "Copy Section"
    author: "skztr"
    repo:   "skztr/obsidian-plugin-section-copy"

    html_url:    "https://community.obsidian.md/plugins/copy-section"
    github_url:  "https://github.com/skztr/obsidian-plugin-section-copy"
    description: "Adds a Copy button to the top of Headed sections."
    about:       "Add a copy button to header lines to copy the entire section as raw Markdown up to the next header of the same level. Omit %%comments%% or tag-only lines, include all sub-sections or stop at the next header, and pick which header levels show the button."

    stats: {
        downloads:  2701
        updated_at: 1767923278000
    }
}
```
