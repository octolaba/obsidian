# Copy Image

Copy Image copies an image to the clipboard from its right-click menu in Obsidian. On mobile the same is done by long-pressing an image, so it can be pasted into other applications.

    id:     "copy-image"
    name:   "Copy Image"
    author: "felipe-ds-lima"
    repo:   "felipe-ds-lima/obsidian-copy-image-plugin"

    github_url:  "https://github.com/felipe-ds-lima/obsidian-copy-image-plugin"
