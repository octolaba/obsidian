# File Share

File Share transfers files directly between vaults over a socket server, end-to-end encrypted. Friends are added to a friendlist by exchanging a key, after which files are sent to them directly. The default hosted server can be used, or a socket server can be run by the user.

plugin: {
    id:     "file-share"
    name:   "File Share"
    author: "muckmuck96"
    repo:   "muckmuck96/obsidian-file-share"
