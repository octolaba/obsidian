# Tiny Habits

Tiny Habits tracks habits inside Markdown notes and stores every entry in the note's own frontmatter. Entries are marked completed, failed, skipped or not started, and a calendar table renders them as a heatmap with keyboard navigation and browsing of past and future entries.

```cue

    id:     "tiny-habits"
    name:   "Tiny Habits"
    author: "nazoadiego"
    repo:   "nazoadiego/tiny-habits"
```
