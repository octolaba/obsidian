# Harang Contacts

References contacts from a CardDAV address book inside notes. An inline autocomplete trigger searches cached address books and inserts a pinned, unambiguous reference to one contact. References render as rounded chips showing name and email in Live Preview and Reading view, and clicking a chip opens a read-only detail card with email, phone and organization.
