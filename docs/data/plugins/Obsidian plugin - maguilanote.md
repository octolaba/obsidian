# Maguilanote

Creates Milanote-style visual workspace boards in the vault on an infinite canvas holding notes, images, links, files, to-do lists, columns and nested boards. Cards are connected with arrows or smart-routed lines, sketches can be drawn, and audio can be recorded and transcribed with OpenAI Whisper. Each board is saved as a local .board file.
