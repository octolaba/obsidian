# Synapse AI

Chats with the vault in a side panel, streaming replies that can be stopped or regenerated, and pulls linked or searched notes into the context. The user supplies their own API key and model, with Gemini, OpenRouter and any OpenAI-compatible or local endpoint named. Answers are saved as plain-text notes, and the recorded inputs state that data is routed only to the chosen provider.
