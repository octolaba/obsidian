# Folder Auto Properties

Applies folder-specific rules so that new notes inherit predefined YAML properties. Paths are mapped through an integrated folder search and properties are injected without overwriting existing frontmatter. Properties whose value is empty are skipped.

```cue
plugin: {
    id:     "folder-auto-properties"
    name:   "Folder Auto Properties"
    author: "Kawê Cezar"
    repo:   "kawecz/folder-auto-properties"

    html_url:    "https://community.obsidian.md/plugins/folder-auto-properties"
    github_url:  "https://github.com/kawecz/folder-auto-properties"
    description: "Automatically apply specific properties to new notes based on their folder with a simple key-value UI. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Automate frontmatter metadata by applying folder-specific rules so new notes inherit predefined YAML properties. Use integrated folder search to map paths and inject properties safely without overwriting existing frontmatter. Skip properties with empty values to keep files clean."

    stats: {

    }
}
```
