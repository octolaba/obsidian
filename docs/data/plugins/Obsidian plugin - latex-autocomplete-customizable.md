# Customizable LaTeX Autocomplete

Customizable LaTeX Autocomplete builds a personal library of LaTeX formula completions rather than offering a fixed list. Suggestions are triggered while editing inline or display math, and the chosen custom entry is inserted to speed up equation entry.

```cue
plugin: {
    id:     "latex-autocomplete-customizable"
    name:   "Customizable LaTeX Autocomplete"
    author: "aiksxd"
    repo:   "aiksxd/latex-autocomplete"

    html_url:    "https://community.obsidian.md/plugins/latex-autocomplete-customizable"
    github_url:  "https://github.com/aiksxd/latex-autocomplete"

    about:       "Build a personalized autocomplete library for LaTeX formulas. Trigger suggestions while editing inline ($...$) or display ($$...$$) math and insert custom completions to speed up equation entry."
```
