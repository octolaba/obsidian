# Daily Notes Tweaks

Opens a random daily note on command so that past entries and ideas resurface. Past daily notes are switched to reading mode automatically when they open, while today's note stays in editing mode.

```cue
plugin: {
    id:     "daily-notes-tweaks"
    name:   "Daily Notes Tweaks"
    author: "coignard"
    repo:   "coignard/obsidian-daily-notes-tweaks"

    html_url:    "https://community.obsidian.md/plugins/daily-notes-tweaks"
    github_url:  "https://github.com/coignard/obsidian-daily-notes-tweaks"
    description: "Open a random daily note and automatically switch past daily notes to reading mode."
    about:       "Open a random daily note to rediscover past entries and ideas. Switch past daily notes automatically to reading mode on open while keeping today's note in editing mode."

    stats: {
        downloads:  98
        updated_at: 1762619224000
    }
}
```
