# Local LLM Hub

Runs chat, retrieval-augmented generation and workflow automation against local model servers, including Ollama, LM Studio, vLLM and AnythingLLM. Chat history, embeddings, indexes and requests stay on the machine, so no data or API keys leave the vault. Workflows and agent skills are described in plain language, and MCP integration, file encryption, edit history and slash commands are included.
