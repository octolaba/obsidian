# Taskgregator

Taskgregator reads the plain Markdown checkboxes already written in the vault, so no separate database, special task file or syntax has to be adopted, and every edit is written straight back to the original line. A task takes its context from where it lives, so one in a project note belongs to that project and one linking a person's note belongs to that person as well, appearing under project, people and date-based smart lists at once with no copies to sync. Three surfaces share one index: a navigator with smart lists and a context tree, a sortable task list, and a right sidebar that follows the note being edited by page, section or reference. A task line can be edited inline from its right-click menu, on desktop and on mobile.
