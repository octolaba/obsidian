# Easy Wikilink

Turns selected text into an internal wikilink with a single hotkey: the selection is kept as the display text and the target page is chosen from a picker. The generated link is piped, so the visible phrase stays as written while the link points at the chosen page.

```cue
plugin: {
    id:     "easy-wikilink"
    name:   "Easy Wikilink"
    author: "Rockorolla"
    repo:   "rockorolla/obsidian-easy-wikilink"

    html_url:    "https://community.obsidian.md/plugins/easy-wikilink"
    github_url:  "https://github.com/rockorolla/obsidian-easy-wikilink"
    description: "Works like Ctrl+K but for internal wikilinks. Select text, pick a page, generates [[page|selected text]]. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Generate internal wikilinks from selected text with a single hotkey. Select a word or phrase, trigger the hotkey, pick a page and insert a [[Page|selected text]] wikilink automatically."

    stats: {
        downloads:  184
        updated_at: 1779445218000
    }
}
```
