# Carry-Forward

Carry-Forward copies text from a note while linking back to the source it was copied from, or copies a link to a note block. A selection can be carried forward as individually linked lines, and plain or embed links created to reference an exact block.

```cue
plugin: {
    id:     "obsidian-carry-forward"
    name:   "Carry-Forward"
    author: "jglev"
    repo:   "jglev/obsidian-carry-forward"

    html_url:    "https://community.obsidian.md/plugins/obsidian-carry-forward"
    github_url:  "https://github.com/jglev/obsidian-carry-forward"
    description: "Copy text from a note, linking back to its copied source, or copy a link to a note block."
    about:       "Copy text or a link to a specific line and automatically add backlinks to the original note or block. Carry forward selections as individually linked lines or create plain or embed links to reference exact blocks."

    stats: {
        downloads:  8231
        updated_at: 1673526019000
    }
}
```
