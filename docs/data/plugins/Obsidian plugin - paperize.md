# Paperize

Exports the active note as a text-selectable vector PDF through an on-device PDF writer, without a browser print dialog, screenshots or network calls. Standard Markdown such as headings, lists, code blocks, links and images is preserved, while Obsidian-specific elements are simplified to plain text and counted in a summary. The result can be saved or shared to the vault, the attachment folder, a custom folder or external apps, on desktop, iPhone and iPad.
