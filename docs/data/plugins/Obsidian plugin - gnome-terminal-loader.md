# Gnome Terminal Loader

Adds sidebar action icons that launch GNOME Terminal from Obsidian to open a shell or run terminal commands on Linux. A Python entry script named main.py at the vault root can be run in that terminal to present CLI menus and interactive programs. It requires gnome-terminal and python3.

```cue
plugin: {
    id:     "gnome-terminal-loader"
    name:   "Gnome Terminal Loader"
    author: "cheesecake87"
    repo:   "cheesecake87/gnome-terminal-loader"

    html_url:    "https://community.obsidian.md/plugins/gnome-terminal-loader"
    github_url:  "https://github.com/cheesecake87/gnome-terminal-loader"
    description: "Sidebar action icons to quickly open the Gnome Terminal or to have the Gnome Terminal run a Python module."
    about:       "Launch GNOME Terminal from Obsidian to open shells and run terminal commands on Linux. Run a Python entry script named main.py placed at the vault root to present CLI menus and execute interactive Python programs (requires gnome-terminal and python3)."

    stats: {
        downloads:  5568
        updated_at: 1693341268000
    }
}
```
