# Zoom

A heading or a list is zoomed into by hiding everything except that section and its content. Leaving the zoom restores the full document view.

```cue
plugin: {
    id:     "obsidian-zoom"
    name:   "Zoom"
    author: "vslinko"
    repo:   "vslinko/obsidian-zoom"

    html_url:    "https://community.obsidian.md/plugins/obsidian-zoom"
    github_url:  "https://github.com/vslinko/obsidian-zoom"
    description: "Zoom into heading and lists."
    about:       "Focus on a heading or list by hiding everything except that section and its content. Exit the zoom to restore the full document view."

    stats: {
        downloads:  111220

}
```
