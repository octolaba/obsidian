# Vault Plus

Reports vault health from a single sidebar dashboard: orphan notes, broken links, empty and oversized files, fuzzy title duplicates, unused tags and unreferenced attachments. Items found can be opened, compared or deleted directly from the dashboard with one click, and the recorded About states that no setup is needed before the first scan.
