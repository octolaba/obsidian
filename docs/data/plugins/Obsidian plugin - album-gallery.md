# Album Gallery

Organizes photos, animated GIFs and local videos into Apple Photos-style albums, described by a .gallery file with plugin-managed storage inside the vault. Images are previewed and MP4, MOV and WebM videos play with thumbnails in a full-screen lightbox. Filenames are handled safely and deletions go through Obsidian's trash.

    id:     "album-gallery"
    name:   "Album Gallery"
