# Kenengba WeChat Publisher

Converts the current note or selection into WeChat Official Account HTML, with a live right-side preview and one-click copy for pasting into the WeChat editor. Headings, lists, images, tables, code with Shiki highlighting, footnotes and custom containers are preserved, while YAML frontmatter is stripped. A Pro tier adds draft, cover and avatar upload and automatic upload of local images.
