# Vault Explorer

Explores the vault through frontmatter properties and file data rather than through the folder tree. Notes are filtered and sorted into grid, list, table or social-feed views, and cover images are taken from frontmatter, links, embeds or URLs.

```cue
plugin: {
    id:     "vault-explorer"
    name:   "Vault Explorer"
    author: "decaf-dev"
    repo:   "decaf-dev/obsidian-vault-explorer"

    html_url:    "https://community.obsidian.md/plugins/vault-explorer"
    github_url:  "https://github.com/decaf-dev/obsidian-vault-explorer"
    description: "Explore your vault in visual format"
    about:       "Explore and organize your vault using frontmatter properties and file data. Filter and sort notes into grid, list, table, or social-style feed views and show cover images extracted from frontmatter, links, embeds, or URLs."
```
