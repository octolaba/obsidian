# Xboard

A resizable dashboard that gathers capture entry points, knowledge-base health, tasks, a calendar, a focus timer and RSS feeds in one place. Diary, project and inbox notes can be created and opened from it, daily and weekly tasks persist, and the calendar shows how urgent each deadline is. Local AI workflows and ad-hoc conversations run from the dashboard, with results held in a staging area before any of them reach the main knowledge base, and quick-note templates and cached external feeds are configurable.
