# Prompt

Shows a random single-line text prompt taken from a plain-text file in the vault. The prompt file is chosen in the settings, and a new random prompt is revealed on demand.

```cue
plugin: {
    id:     "prompt"
    name:   "Prompt"
    author: "hungsu"
    repo:   "hungsu/obsidian-prompt"

    html_url:    "https://community.obsidian.md/plugins/prompt"
    github_url:  "https://github.com/hungsu/obsidian-prompt"
    description: "Show inspirational prompts, from a prompt file in your vault."
    about:       "Show a random single-line text prompt from a file in your vault. Choose a plain-text prompt file and reveal a new random prompt on demand."

    stats: {
        downloads:  5650
        updated_at: 1681016717000
    }
}
```
