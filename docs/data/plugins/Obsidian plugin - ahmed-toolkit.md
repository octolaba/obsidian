# My Toolkit

My Toolkit bundles seven modules: a searchable formatting palette, AI smart suggestions with a template generator, and image controls for resizing, alignment, rotation and a lightbox. It also adds a fullscreen reading view, pinned quick-access buttons, a file tree with SF Symbols-style icons, and a folder focus mode that makes one folder the visual vault root.
