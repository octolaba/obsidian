# Meeting Note Importer

Imports calendar invites as structured meeting notes by dropping an .ics file into Obsidian or dragging a meeting out of Outlook for Mac. Title, date, attendees, organizer, location, meeting URL and description are filled in, duplicates are skipped, and custom date and title templates are applied. Notes are saved to a configured folder and the interface is localized.

```cue
plugin: {
    id:     "meeting-note-importer"
    name:   "Meeting Note Importer"
    author: "Pierre Awaragi"
    repo:   "awaragi/obsidian-meeting-note-importer"

    html_url:    "https://community.obsidian.md/plugins/meeting-note-importer"
    github_url:  "https://github.com/awaragi/obsidian-meeting-note-importer"
    description: "Import meeting notes from calendar invites — drop a .ics file or drag a meeting directly from Outlook. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Import calendar invites as structured meeting notes by dropping .ics files or dragging meetings from Outlook for Mac into Obsidian. Populate title, date, attendees, organizer, location, meeting URL and description, skip duplicates, apply custom {{date}}/{{title}} templates, and save to a configured folder with localized UI."
```
