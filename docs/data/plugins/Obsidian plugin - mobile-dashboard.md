# Mobile Dashboard

Mobile Dashboard turns the startup page into a mobile-first dashboard with fluid typography, safe-area support for notches and the Dynamic Island, and traditional typographic styling. It offers quick capture and note statistics drawn as charts. Dates are parsed from frontmatter, filenames and folder context so that they survive across devices.
