# Knowledge Graph AI

Extracts entities from Markdown notes, covering people, places, organizations, concepts and events, and maps the relationships between notes into an interactive knowledge graph. The graph is visualized, searched, filtered and explored, and duplicate entities are merged automatically. Parsing runs against either a local or an external AI model.
