# Global Hotkeys

Maps any Obsidian command to a configurable system-wide hotkey. Those shortcuts can bring Obsidian to the front, toggle its visibility, or show and hide the Settings window.

```cue
plugin: {
    id:     "obsidian-global-hotkeys"
    name:   "Global Hotkeys"
    author: "mjessome"
    repo:   "mjessome/obsidian-global-hotkeys"

    html_url:    "https://community.obsidian.md/plugins/obsidian-global-hotkeys"
    github_url:  "https://github.com/mjessome/obsidian-global-hotkeys"
    description: "Configurable system-wide hotkeys for running commands."
    about:       "Map any Obsidian command to a system-wide hotkey. Bring Obsidian to the front, toggle visibility, or show/hide Settings using global shortcuts."
```
