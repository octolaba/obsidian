# Auto Linker

Auto Linker underlines text in the editor that matches an existing note title and offers one-click insertion of a wiki-link for it. Its recorded description calls this semantic auto-linking.

```cue
plugin: {
    id:     "auto-linker"
    name:   "Auto Linker"
    author: "MrDanRave"
    repo:   "mrdanrave/auto-linker"

    html_url:    "https://community.obsidian.md/plugins/auto-linker"
    github_url:  "https://github.com/mrdanrave/auto-linker"
    description: "Semantic auto-linking: underlines text that matches a note title and offers one-click wiki-link insertion. - This plugin has not been manually reviewed by Obsidian staff."

    stats: {
        downloads:  369
        updated_at: 1782828722000

}
```
