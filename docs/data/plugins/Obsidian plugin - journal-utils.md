# Journal Utils

Journal Utils provides mobile pickers that insert wikilinks for people, groups and locations, with create-new, group conversion and ghost handling. Frontmatter lists of people and locations are maintained automatically, and groups are expanded into their members. Unresolved ghost links are surfaced for review or for creating a profile.

```cue
plugin: {
    id:     "journal-utils"
    name:   "Journal Utils"
    author: "sagersmith8"
    repo:   "sagersmith8/obsidian-journal-utils"

    html_url:    "https://community.obsidian.md/plugins/journal-utils"
    github_url:  "https://github.com/sagersmith8/obsidian-journal-utils"
    description: "Mobile wikilink pickers for people, groups, and locations with automatic mention tracking in frontmatter. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert person and location wikilinks quickly from a mobile picker with create-new, group conversion, and ghost handling. Auto-maintain people: and locations: frontmatter lists, expand groups into their members, and surface unresolved ghost links for review or profile creation."

    stats: {
        downloads:  81
        updated_at: 1784072301000
    }
}
```
