# Task Accountability Tracker

Task Accountability Tracker scans the daily notes folder and flags the days on which no note was created or too few tasks were checked. Weekly, monthly and yearly summaries report the current and longest streaks together with a breakdown of the missed days. The threshold that counts as engagement is configurable.

```cue
plugin: {
    id:     "task-accountability"
    name:   "Task Accountability Tracker"
    author: "sattarip"
    repo:   "sattarip/obsidian-task-accountability"

    html_url:    "https://community.obsidian.md/plugins/task-accountability"
    github_url:  "https://github.com/sattarip/obsidian-task-accountability"
    description: "Track your daily note engagement with statistics showing which days you didn't engage with your tasks. Includes streak tracking and customizable thresholds. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Track engagement by scanning your daily notes folder and flagging days you didn't create a note or checked too few tasks. View weekly, monthly, and yearly summaries with current and longest streaks, a detailed breakdown of missed days, and a customizable engagement threshold."

    stats: {
        downloads:  139
        updated_at: 1784770993000
    }
}
```
