# Markdoist

Markdoist manages Todoist tasks from plain-text Markdown checkboxes and synchronizes changes in both directions. Edits stay local through a persistent offline queue with background sync, and a line is bound to a task by a sync tag that then receives a todoist_id marker. Todoist filters can be rendered as task lists in code blocks, and due dates or projects are set with inline markers.
