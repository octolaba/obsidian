# Quick Share Note to gist

Publishes a note to GitHub as a secret, shareable Gist and uploads its embedded images to Imgur, replacing the image links in the published copy. The gist URL is copied to the clipboard for sharing, and frontmatter is optionally included in the published file.

```cue
plugin: {
    id:     "quick-share-note-to-gist"
    name:   "Quick Share Note to gist"
    author: "chaintng"
    repo:   "chaintng/quick-share-note-to-gist"

    html_url:    "https://community.obsidian.md/plugins/quick-share-note-to-gist"
    github_url:  "https://github.com/chaintng/quick-share-note-to-gist"
    description: "Quick publish and share notes to GitHub Gist and its image by upload images to Imgur."
    about:       "Publish notes to secret, shareable GitHub Gists and upload embedded images to Imgur, automatically replacing image links in the published note. Copy the gist URL to your clipboard for fast sharing and optionally include frontmatter in the published file."

    stats: {
        downloads:  482
        updated_at: 1783162438000
    }
}
```
