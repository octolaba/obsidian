# Task Planner

Task Planner manages tasks from any Markdown file with a Kanban-style planning board, a Today view, and configurable day, week, month, quarter and year horizons. Tasks are tracked through Dataview-compatible inline fields, dragged between periods, and given priorities, due dates and subtasks. Work-in-progress limits, backlog and overdue tracking, and pinning of important items are part of it.
