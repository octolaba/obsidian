# Soundify

Sounds are played in response to specific Obsidian events, giving audio feedback as the app is used. Which events trigger a sound, and which audio file each one plays, are chosen from the settings menu.

```cue
plugin: {
    id:     "soundify"
    name:   "Soundify"
    author: "solomonarul"
    repo:   "solomonarul/soundify"

    html_url:    "https://community.obsidian.md/plugins/soundify"
    github_url:  "https://github.com/solomonarul/soundify"
    description: "Allows for sounds to play on specific events. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Play sounds on specific Obsidian events to get instant audio feedback. Configure which events trigger sounds and choose audio files from the settings menu."

    stats: {
        downloads:  192
        updated_at: 1778949097000
    }
}
```
