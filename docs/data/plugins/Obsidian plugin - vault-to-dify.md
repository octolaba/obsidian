# Vault2Dify

Synchronizes selected Markdown notes to one or more Dify knowledge bases, mapping folders, individual files or the whole vault. Syncing runs manually or automatically on create, modify and rename events, the Dify service URL is configurable, and separate records are kept per knowledge base and file path. The recorded About states that remote documents are not deleted.

```cue
plugin: {
    id:     "vault-to-dify"
    name:   "Vault2Dify"
    author: "wenbin"
    repo:   "beatsad/Vault2Dify"

    github_url:  "https://github.com/beatsad/Vault2Dify"
    description: "Sync selected Markdown notes to a Dify Knowledge Base. - This plugin has not been manually reviewed by Obsidian staff."

Support manual or automatic sync on create, modify, and rename events, point to any Dify service URL, keep separate records per KB and file path, and avoid deleting remote documents."
