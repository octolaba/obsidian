# Modular Theme Dashboard

Modular Theme Dashboard provides dashboard modules that can be dragged, resized and cloned freely on a canvas, with layouts saved automatically and kept stable after a restart. Twenty-five built-in modules cover weather, calendar, note statistics, to-do lists, recent files, news, directory listings, AI insight, web and media viewers, code and table editors, document preview, XHS import and Excel-Markdown conversion. A multi-format viewer previews Excel, Word, PPT, code, image and video files, and the recorded text also lists eight themes with customizable background colour and transparency, plus an AI custom-language feature that works with OpenAI-compatible APIs.
