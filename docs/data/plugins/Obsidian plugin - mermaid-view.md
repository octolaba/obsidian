# Mermaid View

Opens .mermaid and .mmd files directly in Obsidian and renders them as interactive diagrams, in preview, split editor-and-preview, or source mode. Diagrams are panned and zoomed, edited in a CodeMirror editor and exported as SVG or PNG. Files handled this way are also embedded into notes.

```cue
plugin: {
    id:     "mermaid-view"
    name:   "Mermaid View"
    author: "weppos"
    repo:   "weppos/obsidian-mermaid-view"

    html_url:    "https://community.obsidian.md/plugins/mermaid-view"
    github_url:  "https://github.com/weppos/obsidian-mermaid-view"
    description: "Handle Mermaid files as first-class citizens, rendering them fullscreen when opened. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open .mermaid and .mmd files directly in Obsidian and render them as interactive diagrams with preview, split (editor + live preview), or source modes. Pan and zoom diagrams, edit with a CodeMirror editor, export as SVG/PNG, and embed diagrams into notes."

    stats: {
        downloads:  14212
        updated_at: 1778927039000
    }
}
```
