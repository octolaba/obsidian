# oblogger

Adds a side-panel tag explorer with custom groups and pre-defined lists for dailies, recents, files and untagged notes, pins bookmarked notes to the top of their group, and flags files that carry no tags. A modal logger writes entries into the frontmatter of new notes, frontmatter can set a custom note icon, an avatar can be shown in the panel, and daily notes can be sorted by year, month and day.
