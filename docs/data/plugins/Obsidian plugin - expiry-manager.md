# Expiry Manager

Tracks things that expire or renew — subscriptions, licenses, domains, certificates and warranties — as plain Markdown notes with YAML frontmatter, which its recorded About presents as avoiding lock-in. A dashboard shows them as compact cards, progress bars, a timeline and a calendar, with Obsidian-native notifications, templates, search and filters, and automatic creation of the next renewal cycle.
