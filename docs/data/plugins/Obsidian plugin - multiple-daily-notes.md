# Multiple Daily Notes

Creates more than one daily note for the same date, keeping logs, projects or contexts apart. Each note has its own template, filename and target folder. The recorded description also names time offsets for notes created past midnight and a choice of ribbon icon.

```cue
plugin: {
    id:     "multiple-daily-notes"
    name:   "Multiple Daily Notes"
    author: "vaibzzz123"
    repo:   "vaibzzz123/multiple-daily-notes"

    html_url:    "https://community.obsidian.md/plugins/multiple-daily-notes"
    github_url:  "https://github.com/vaibzzz123/multiple-daily-notes"
    description: "Create multiple daily notes in one vault, with additional configuration options including time offsets for creating notes past midnight, choosing the ribbon icon to use for the note, and more."
    about:       "Create multiple daily notes for the same date to separate logs, projects, or contexts. Set templates, filenames, and target folders to keep each daily note organized and easy to find."

    stats: {
        downloads:  745
        updated_at: 1742429424000
    }
}
```
