# Fill in the Blank (FITB)

Fill in the Blank renders text wrapped in double dashes as blank lines in preview, covering headings, paragraphs and inline code. The markup is applied to a selection from the ribbon icon or from the toggle command.

```cue
plugin: {
    id:     "fill-in-the-blank"
    name:   "Fill in the Blank (FITB)"
    author: "mister-mcgee"
    repo:   "mister-mcgee/obsidian-fill-in-the-blank"

    html_url:    "https://community.obsidian.md/plugins/fill-in-the-blank"
    github_url:  "https://github.com/mister-mcgee/obsidian-fill-in-the-blank"
    description: "Use --magic-- to render inline text as blank line(s) instead."
    about:       "Convert text wrapped in double dashes into blank lines in preview, including headings, paragraphs, and inline code. Toggle fill-in-the-blank on selected text via the ribbon icon or the toggle command."
```
