# Hash Pasted Image

Hash Pasted Image renames pasted images to a content-based hash, using SHA-512 by default. It also renames image files copied into the vault, supports selectable hash algorithms and encodings, and can show a notification when a rename happens.

```cue
plugin: {
    id:     "hash-pasted-image"
    name:   "Hash Pasted Image"
    author: "hardingadonis"
    repo:   "hardingadonis/hash-pasted-image"

    html_url:    "https://community.obsidian.md/plugins/hash-pasted-image"
    github_url:  "https://github.com/hardingadonis/hash-pasted-image"
    description: "Auto rename pasted images added to the vault via hash algorithm SHA-512"
    about:       "Rename pasted images to a content-based SHA-512 hash. Rename image files copied into the vault, support selectable hash algorithms and encodings, and show optional notifications."
```
