# Intervaults

Intervaults renders several Obsidian vaults as one interactive force-directed graph, with intersection dots marking notes shared between them, and the canvas can be dragged, panned and zoomed. Notes that differ are compared and merged in a side-by-side diff editor with editable panes, per-line highlighting and one-click acceptance of a hunk. Intersections can be narrowed with a compact query language.
