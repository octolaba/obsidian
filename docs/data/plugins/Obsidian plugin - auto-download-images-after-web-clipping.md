# Auto Download Images After Web Clipping

Auto Download Images After Web Clipping converts external image links into local attachments after a page is clipped with Web Clipper. It monitors chosen folders for new clippings and saves the downloaded images to Obsidian's attachment location, a per-file folder, or a specified subfolder.

```cue
plugin: {
    id:     "auto-download-images-after-web-clipping"
    name:   "Auto Download Images After Web Clipping"
    author: "chenxiccc"
    repo:   "chenxiccc/obsidian-auto-download-images-after-web-clipping"

    html_url:    "https://community.obsidian.md/plugins/auto-download-images-after-web-clipping"
    github_url:  "https://github.com/chenxiccc/obsidian-auto-download-images-after-web-clipping"
    description: "Automatically download remote images to local vault after web clipping. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Download images automatically when clipping webpages with Web Clipper, converting external image links into local attachments in the background. Monitor chosen folders for new clippings and save images to Obsidian's attachment location, a per-file folder, or a specified subfolder."

    stats: {
        downloads:  1398
        updated_at: 1784709067000
    }
}
```
