# Power Bases

Adds six views to Bases: a Kanban board, month and week calendars, a Gantt timeline, bar, line and donut charts, an image gallery, and an advanced table with summaries, colors, rollups and inline editing. Notes stay ordinary files on Obsidian's data model, so the views sync and work on mobile, and rendering happens in chunks to stay responsive in very large vaults.
