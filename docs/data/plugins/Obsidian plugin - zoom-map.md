# TTRPG Tools - Maps

This plugin embeds zoomable, interactive images as maps inside notes and places markers, stickers, drawings, measurements, HUD pins and editable text layers on top of them. Marker layers are edited with icons, links and tooltips, base images and overlays can be switched, shapes can be drawn, and calibrated distances are measured with units and travel-time presets.
