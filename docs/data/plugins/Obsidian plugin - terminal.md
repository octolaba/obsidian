# Terminal

Terminal embeds consoles and shells inside Obsidian and starts external terminals from notes. Multiple terminal profiles are managed, an emulated developer console is available on all platforms, terminal history is searched and saved, sessions are restored automatically, and terminal appearance is customizable.

```cue
plugin: {
    id:     "terminal"
    name:   "Terminal"
    author: "polyipseity"
    repo:   "polyipseity/obsidian-terminal"

    html_url:    "https://community.obsidian.md/plugins/terminal"
    github_url:  "https://github.com/polyipseity/obsidian-terminal"
```
