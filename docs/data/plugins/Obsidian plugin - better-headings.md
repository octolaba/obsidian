# Better Headings

Better Headings prefixes headings automatically with decimal-style numbering. Sections are numbered in order, which keeps navigation and document structure consistent without maintaining the numbers by hand.

```cue
plugin: {
    id:     "better-headings"
    name:   "Better Headings"
    author: "zachbugay"
    repo:   "zachbugay/obsidian-plugin-better-headers"

    html_url:    "https://community.obsidian.md/plugins/better-headings"
    github_url:  "https://github.com/zachbugay/obsidian-plugin-better-headers"
    description: "Automatically prefix headings with a decimal system. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Prefix headings automatically with decimal-style numbered prefixes to create clear, ordered sections. Simplify numbering in your notes for easier navigation and consistent document structure."

    stats: {
        downloads:  246
        updated_at: 1782824805000
    }
}
```
