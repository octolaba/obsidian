# Chronostra

Chronostra renders a hierarchical life-planning table from a single future-data code block, zoomable and laid out along a timeline. Rows are structured by scope as Vision, Goal or Step, commitment is tagged as Must or Wish, and Future, Now and Gap metrics are tracked. Decades can be viewed at once and virtual scrolling keeps the table usable while the data stays plain Markdown.
