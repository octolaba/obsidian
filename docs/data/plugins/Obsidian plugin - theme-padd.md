# Theme PADD

Theme PADD modifies a theme's palette, animation, decoration and density from per-theme settings panels built out of color, text, number, toggle and select controls. Changes are previewed live and persist across theme updates, theme specs are discovered automatically from theme releases, and errors are reported readably.
