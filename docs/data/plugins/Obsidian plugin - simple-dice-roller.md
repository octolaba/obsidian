# Simple Dice Roller

Simple Dice Roller scans the active note for dice formulas such as 1d10+2d6+4 and either simulates a randomized roll or computes the average. Results are displayed in place, and an alert appears when the note contains no dice.

    id:     "simple-dice-roller"
    name:   "Simple Dice Roller"
    author: "yeeshue99"
    repo:   "yeeshue99/SimpleDiceRoller"

    html_url:    "https://community.obsidian.md/plugins/simple-dice-roller"
