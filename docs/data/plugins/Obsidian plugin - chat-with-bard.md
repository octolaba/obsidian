# Gemini AI Assistant

Gemini AI Assistant chats with Google's Gemini model from inside Obsidian using the reader's own API key. Each chat is stored as a local .gemini file in a configurable folder, opens like a note and can be moved into the sidebar. Responses can be copied as Markdown for pasting into other notes.

```cue
plugin: {
    id:     "chat-with-bard"
    name:   "Gemini AI Assistant"
    author: "artel250"
    repo:   "artel250/Obsidian-Gemini-Assistant"

    html_url:    "https://community.obsidian.md/plugins/chat-with-bard"
    github_url:  "https://github.com/artel250/Obsidian-Gemini-Assistant"
    description: "A Google Gemini integration, completely for free."
    about:       "Chat with Google's Gemini AI directly in Obsidian using your API key. Store chats as local .gemini files in a configurable folder, open them like notes, move chats into the sidebar, and copy responses as Markdown to paste into other notes."

    stats: {

    }
}
```
