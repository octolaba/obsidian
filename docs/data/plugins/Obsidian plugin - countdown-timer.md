# Countdown Timer

Countdown Timer embeds countdown blocks carrying a title and a target date and time into notes and dashboards. Each timer shows days, hours, minutes and seconds and handles expiry by counting up or showing a completion message, and consecutive blocks are placed side by side in Reading view.

```cue
plugin: {
    id:     "countdown-timer"
    name:   "Countdown Timer"
    author: "thenewhobbyist"
    repo:   "thenewhobbyist/obsidian-countdown-timer"

    html_url:    "https://community.obsidian.md/plugins/countdown-timer"
    github_url:  "https://github.com/thenewhobbyist/obsidian-countdown-timer"
    description: "Embed countdown timers for tracking vacations, deadlines, and due dates. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add living countdown timers to notes and dashboards using simple countdown blocks with a title and date/time. Show days/hours/minutes/seconds, auto-handle expiration (count up or show Complete!), and place consecutive blocks side-by-side in Reading view."

    stats: {
        downloads:  207
        updated_at: 1765988414000
    }
}
```
