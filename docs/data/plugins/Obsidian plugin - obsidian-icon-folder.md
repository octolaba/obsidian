# Iconize

Adds icons to files, folders, notes, tabs and titles across the vault, from custom SVG files or from icon packs. Predefined packs, frontmatter and custom rules decide which icon applies, and colors can be set per icon. Icons are placed before a name or above a title.

```cue
plugin: {
    id:     "obsidian-icon-folder"
    name:   "Iconize"
    author: "florianwoelki"
    repo:   "florianwoelki/obsidian-iconize"

    html_url:    "https://community.obsidian.md/plugins/obsidian-icon-folder"
    github_url:  "https://github.com/florianwoelki/obsidian-iconize"
    description: "Add icons to anything in Obsidian, including files, folders, and text."
    about:       "Add custom SVGs or icon packs to files, folders, notes, tabs, and titles across your vault. Apply predefined packs, frontmatter and custom rules, and set per-icon colors to place icons before names or above titles for clearer visual organization."

}
```
