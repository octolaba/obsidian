# Natural Language Dates

Creates links to daily notes from natural-language date phrases, expanding inline dates through an autosuggest as they are typed. A date picker inserts dates and timestamps, selected text can be parsed as a date, and notes can be opened through obsidian://nldates URIs. Phrases that are not recognized as dates produce no link.

```cue
plugin: {
    id:     "nldates-obsidian"
    name:   "Natural Language Dates"
    author: "obsidian-community"
    repo:   "obsidian-community/nldates"

    html_url:    "https://community.obsidian.md/plugins/nldates-obsidian"
    github_url:  "https://github.com/obsidian-community/nldates"
    description: "Create date-links based on natural language."
    about:       "Insert timestamps and create wikilinks to daily notes using natural-language phrases. Expand inline dates with autosuggest (e.g., @today → [[2021-12-27|today]]), pick dates with a date picker, parse selected text as dates, and open notes via obsidian://nldates URIs. Prevent link creation for unrecognized dates."

    stats: {
        downloads:  503809
        updated_at: 1785096954000
    }
}
```
