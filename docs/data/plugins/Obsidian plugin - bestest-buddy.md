# Bestest Buddy

Bestest Buddy hatches an ASCII pet for each vault that lives in a sidebar panel and reacts to writing with short quips. Each buddy is seeded from its vault and carries its own species, rarity, hat, stats and personality, responding to writing bursts, pauses, revisions and direct questions without editing the notes themselves.
