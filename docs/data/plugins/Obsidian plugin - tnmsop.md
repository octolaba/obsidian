# TNMSOP

Previews .mdx files as native Markdown notes with a statically compiled reading view that never runs JavaScript and writes no derived files into the vault. Static expressions are resolved from frontmatter, plugin scope and static exports, and .mdx files can be edited, linked and navigated natively. Previewing is toggled vault-wide from a status icon or a command, and unsupported MDX falls back to a safe rendering.
