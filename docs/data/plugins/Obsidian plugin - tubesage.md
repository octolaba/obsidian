# TubeSage

Turns YouTube videos into structured notes by extracting the transcript, generating an LLM summary and adding timestamped headings that link back to exact moments in the video. Channels and playlists can be processed in batch, and the model can be OpenAI, Anthropic, Google Gemini or Ollama across desktop and mobile.
