# Magiedit

Publishes notes to Magiedit for simultaneous publishing, choosing among the configured publishers. The open file's content is sent to the Magiedit API as a POST request for immediate publication.

```cue
plugin: {
    id:     "magiedit"
    name:   "Magiedit"
    author: "magitools"
    repo:   "magitools/magiedit-obsidian"

    html_url:    "https://community.obsidian.md/plugins/magiedit"
    github_url:  "https://github.com/magitools/magiedit-obsidian"
    description: "Publish notes to Magiedit for simultaneous publishing."
    about:       "Publish the current file to Magiedit by choosing from your configured publishers. Send the open file's content to Magiedit's API as a POST request for immediate publication."

    stats: {
        downloads:  172
        updated_at: 1733040869000
    }
}
```
