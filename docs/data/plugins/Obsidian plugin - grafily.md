# Grafily

Renders interactive family graphs, or family trees, from person files stored as Markdown. A vault directory is scanned for person metadata, and ancestors and descendants are explored through a Reingold-Tilford tree layout or a Brandes-Koepf graph layout. Family branches can be collapsed and expanded for clearer navigation.
