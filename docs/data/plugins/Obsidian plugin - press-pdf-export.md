# Press PDF Export

Exports notes to PDF, Word (DOCX), or HTML through Pandoc and local PDF engines such as XeLaTeX, wkhtmltopdf, and WeasyPrint. Folders or whole vaults can be batch-exported, Mermaid diagrams are pre-rendered, and custom CSS or Pandoc templates applied, while images, math, tables, wikilinks, embeds, and code highlighting are preserved. The plugin is desktop-only.

```cue
plugin: {
    id:     "press-pdf-export"
    name:   "Press PDF Export"
    author: "taylorchen"
    repo:   "taylorchen/obsidian-press"

    html_url:    "https://community.obsidian.md/plugins/press-pdf-export"
    github_url:  "https://github.com/taylorchen/obsidian-press"
    description: "High-fidelity PDF export powered by Pandoc. Supports multiple engines (XeLaTeX, wkhtmltopdf, WeasyPrint), Mermaid diagrams, custom CSS/templates, and batch export. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Export notes to high-fidelity PDF, Word (DOCX), or HTML via Pandoc and local PDF engines. Batch-export folders or vaults, pre-render Mermaid diagrams, apply custom CSS or Pandoc templates, and preserve images, math, tables, wikilinks, embeds, and code highlighting; desktop-only."
```
