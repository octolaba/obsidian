# TickTick Today

TickTick Today lists today's TickTick tasks in a sidebar panel with project names, pinned tasks on top and human-readable time labels. Tasks are marked complete in place and sync in real time, while full edits open in TickTick itself. It requires macOS and the TickTick app.

```cue
plugin: {
    id:     "ticktick-today"
    name:   "TickTick Today"
    author: "wudanyang27"
    repo:   "wudanyang27/ticktick-today"

    html_url:    "https://community.obsidian.md/plugins/ticktick-today"
    github_url:  "https://github.com/wudanyang27/ticktick-today"
    description: "Display TickTick today's tasks in a sidebar panel. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display today's TickTick tasks in Obsidian's sidebar with project names, pinned tasks on top, and human-readable time labels. Mark tasks complete with real-time macOS sync and jump to TickTick for full edits — requires macOS and the TickTick app."

    stats: {
        downloads:  785
        updated_at: 1764927042000
    }
}
```
