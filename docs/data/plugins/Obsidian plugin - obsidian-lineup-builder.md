# Lineup Builder

Builds football lineups from a lineup codeblock that names a formation and lists the players in order. In Preview mode the lineup is drawn as an SVG pitch from Wikimedia-sourced images, repositioned per formation and labeled with the player names.

    id:     "obsidian-lineup-builder"
    name:   "Lineup Builder"
    author: "james-fallon"
