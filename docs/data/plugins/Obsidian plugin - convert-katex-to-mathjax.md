# KaTeX to MathJax

KaTeX to MathJax converts KaTeX notation into MathJax format so pasted mathematical expressions keep rendering. It can convert automatically on paste, paste with conversion through a command, convert the current file, or batch-convert every file in the vault.

```cue
plugin: {
    id:     "convert-katex-to-mathjax"
    name:   "KaTeX to MathJax"
    author: "pejakovic"
    repo:   "pejakovic/obsidian-convert-katex-to-mathjax"

    html_url:    "https://community.obsidian.md/plugins/convert-katex-to-mathjax"
    github_url:  "https://github.com/pejakovic/obsidian-convert-katex-to-mathjax"
    description: "Converts KaTeX format to MathJax format"
    about:       "Convert KaTeX notation to MathJax in your vault to preserve pasted mathematical expressions. Apply automatic paste conversion, use commands to paste with conversion, convert the current file, or batch-convert all files to fix KaTeX-to-MathJax formatting."

    stats: {
        downloads:  7201
        updated_at: 1759498405000
    }
}
```
