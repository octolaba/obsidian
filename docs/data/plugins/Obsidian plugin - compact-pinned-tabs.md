# Pinned Tabs

Renders pinned tabs as compact, icon-only fixed-width tabs grouped at the left of each desktop tab bar. Pins are protected against accidental closing, and icons can be set per file or derived automatically for daily notes. Hovering expands a tab, the active tab is highlighted, and movement is animated with theme-aware visuals.
