# Hyphenation

Enables justified text and automatic hyphenation in the Obsidian preview. The language defaults to the browser locale and is overridden per file through a lang key in frontmatter. Hyphenation applies to paragraphs and to ordered and unordered lists, while external links are skipped.

```cue
plugin: {
    id:     "obsidian-hyphenation"
    name:   "Hyphenation"
    author: "7596ff"
    repo:   "7596ff/obsidian-hyphenation"

    html_url:    "https://community.obsidian.md/plugins/obsidian-hyphenation"
    github_url:  "https://github.com/7596ff/obsidian-hyphenation"
    description: "Enable justified text and hyphenation."
    about:       "Enable justified text and automatic hyphenation in Obsidian preview. Use navigator.language as the default and override per-file via a frontmatter lang key; apply hyphenation to paragraphs, ordered and unordered lists while skipping external links."

}
```
