# Markdown Cleaner

Markdown Cleaner strips excessive Markdown formatting, removing stray asterisks, underscores and other redundant markers while leaving valid bold and italic in place. It also converts LaTeX math delimiters, turning parenthesis and bracket forms into single and double dollar delimiters for expressions such as fractions, roots, sums and matrices. Cleaning runs automatically on paste or from a hotkey.

```cue
plugin: {
    id:     "markdown-cleaner"
    name:   "Markdown Cleaner"
    author: "gao-qian-long"
    repo:   "gao-qian-long/obsidian-markdown-cleaner"

    html_url:    "https://community.obsidian.md/plugins/markdown-cleaner"
    github_url:  "https://github.com/gao-qian-long/obsidian-markdown-cleaner"
    description: "Clean Markdown syntax and automatically convert LaTeX to a compatible format. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Clean excessive Markdown formatting while preserving valid bold and italic, removing stray *, _, and other redundant markers. Convert LaTeX math delimiters \\(...\\) to $...$ and \\[...\\] to $$...$$ for complex formulas (fractions, roots, sums, matrices), with paste auto-clean and hotkey-triggered cleaning."

    stats: {
```
