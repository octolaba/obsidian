# Note Status Checkbox

Shows Lucide icons next to internal links based on the frontmatter of the target note, in both Reading view and Live Preview. Ordered rules decide which icon and color to use, matching values exactly, case-sensitively or insensitively, inside arrays or by wildcard. Metadata is only read, so the notes themselves are left unchanged.

    id:     "note-status-checkbox"

Define ordered, rule-based matches (exact, case-sensitive/insensitive, arrays, wildcards) to assign icon and color, while reading metadata without changing notes."
