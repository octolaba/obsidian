# Link Opening Restore

Restores the link-opening method in edit mode to Ctrl and left click. According to the recorded inputs, Ctrl with left click opens the link in the current tab, adding Shift opens it in a new tab, and adding Shift and Alt opens it in a new window.

```cue
plugin: {
    id:     "link-opening-restore"
    name:   "Link Opening Restore"
    author: "smallzombie"
    repo:   "smallzombie/link-opening-restore"

    html_url:    "https://community.obsidian.md/plugins/link-opening-restore"
    github_url:  "https://github.com/smallzombie/link-opening-restore"
    description: "Restore the link opening method to Ctrl + Left Click."
    about:       "Restore link-opening behavior to Ctrl+Left Click in edit mode. Use Ctrl+Left Click to open in the current tab, Ctrl+Shift+Left Click to open in a new tab, and Ctrl+Shift+Alt+Left Click to open in a new window."

    stats: {
        downloads:  699
        updated_at: 1772937451000
    }
}
```
