# Search Templates Library

Search Templates Library saves complex Obsidian search queries as templates so they can be recalled later. Free-form searches can be run or a saved template applied, results can be visualized in the graph view, and QuickAdd can trigger saved or template-enabled searches.

```cue
plugin: {
    id:     "template-search-library"
    name:   "Search Templates Library"
    author: "pentchaff"
    repo:   "pentchaff/obsidian-search-library"

    html_url:    "https://community.obsidian.md/plugins/template-search-library"
    github_url:  "https://github.com/pentchaff/obsidian-search-library"
```
