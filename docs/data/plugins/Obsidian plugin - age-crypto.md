# AGE Crypto

AGE Crypto encrypts and decrypts whole notes or selected text with the age file encryption format, using a bundled TypeScript implementation that runs on desktop and mobile without external binaries. Identity keys are generated and recipient public keys derived from them, and the output is stored as ASCII-armored age blocks.
