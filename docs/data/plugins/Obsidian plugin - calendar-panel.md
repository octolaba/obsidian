# Calendar Panel

Adds a sidebar calendar panel for browsing, creating and managing daily and weekly notes. Month and year jumps, a daily note template setting, week-number navigation, task status indicators and opening a note in a new split are supported. The interface comes in Chinese and English with independently configurable date locales, and the plugin runs entirely locally, collecting no data and making no external network requests.
