# Segerlab

Segerlab renders segerlab-calculation code blocks as interactive glaze calculators built from JSON data copied out of the Segerlab app. Extended coefficients are optional and the interface switches automatically between English and Russian. A Stull chart panel plots all calculator points from the open note, and a configurable query searches notes for calculators.
