# OPPO Pad Markdown Annotation

OPPO Pad Markdown Annotation annotates PDFs on Android tablets with stylus-first input and palm rejection, so one finger scrolls and a pinch zooms while the stylus writes. Strokes respond to pressure and tilt, the stylus button toggles pen and eraser, and annotations are saved automatically. Annotated PDFs export with the ink burned in, or as Markdown or DOCX.
