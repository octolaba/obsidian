# Version View

Version View saves file snapshots with optional names and descriptions and restores any of them in one click. Versions are compared side by side with line-numbered diffs that highlight additions and deletions, either against each other or against the current note. The comparison view has a fullscreen toggle and a filter that shows only changed lines.

    name:   "Version View"
