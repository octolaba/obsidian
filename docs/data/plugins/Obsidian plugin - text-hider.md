# Text Hider

Text Hider visually hides note text while editing so it cannot be read over your shoulder, without modifying files on disk and without encrypting notes. Several masking styles are offered, among them invisible, blur and bullet-password, and the current word or letter, or a selection, can be revealed. Markdown headers are kept visible as needed.

    id:     "text-hider"
    name:   "Text Hider"
