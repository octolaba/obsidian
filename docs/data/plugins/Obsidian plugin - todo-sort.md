# Todo sort

Todo sort orders the todos of a note by completion status. Incomplete tasks are kept at the top and completed items placed below, which makes a task list clearer to read.

```cue
plugin: {
    id:     "todo-sort"
    name:   "Todo sort"
    author: "ryangomba"
    repo:   "ryangomba/obsidian-todo-sort"

    html_url:    "https://community.obsidian.md/plugins/todo-sort"
    github_url:  "https://github.com/ryangomba/obsidian-todo-sort"
    description: "Sort todos by completion status."
    about:       "Sort todos by completion status within a note. Keep incomplete tasks at the top and place completed items below for clearer task lists."

    stats: {
        downloads:  7947
        updated_at: 1672365874000

}
```
