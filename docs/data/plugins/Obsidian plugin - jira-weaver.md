# Jira Weaver

Jira Weaver syncs Jira issues into the vault as Markdown files with structured YAML frontmatter, driven per profile by JQL queries run on click or on a schedule, each with its own target folder. Any Jira field can be mapped to a frontmatter key, and values can be wrapped as wiki links so they reach Graph View and Dataview. A memo marker preserves hand-written notes across syncs, and each profile keeps its own sync log.

    name:   "Jira Weaver"
