# Card Dashboard

Card Dashboard builds a responsive, card-based dashboard for the vault on desktop and mobile, with a customizable banner, image, typography, colors, size and alignment. Its widgets include a calendar, an analog or digital clock and a tomato-shaped Pomodoro timer with focus and rest modes. Widgets can be reordered, resized and hidden.
