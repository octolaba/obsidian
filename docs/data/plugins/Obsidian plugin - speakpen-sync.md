# SpeakPen Sync

Voice summaries from SpeakPen are synced into the vault as Markdown notes carrying YAML frontmatter. Syncing runs on a configurable interval or on demand, only new ideas are pulled so that entries are not duplicated, and the status bar shows the time of the last sync.

```cue
plugin: {
    id:     "speakpen-sync"
    name:   "SpeakPen Sync"
    author: "xnjiang"
    repo:   "xnjiang/speakpen-obsidian"

    html_url:    "https://community.obsidian.md/plugins/speakpen-sync"
    github_url:  "https://github.com/xnjiang/speakpen-obsidian"
    description: "Sync your SpeakPen voice summaries into your vault as Markdown notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync SpeakPen voice summaries into your vault as Markdown notes with YAML frontmatter. Auto-sync at a configurable interval or trigger manual sync on demand. Only sync new ideas to avoid duplicates and show the last sync time in the status bar."

    stats: {
        downloads:  42
        updated_at: 1785771755000
    }
}
```
