# Gemini Assistant

Generates content and runs interactive chats with Google Gemini inside Obsidian. A new Gemini chat or the assistant itself is opened through commands, and the connection uses a Gemini API key.

```cue
plugin: {
    id:     "gemini-assistant"
    name:   "Gemini Assistant"
    author: "eatgrass"
    repo:   "eatgrass/obsidian-gemini-assistant"

    html_url:    "https://community.obsidian.md/plugins/gemini-assistant"
    github_url:  "https://github.com/eatgrass/obsidian-gemini-assistant"
    description: "Your Gemini AI assistant"
    about:       "Generate content and run interactive chats with Google Gemini directly inside Obsidian. Start new Gemini chats or open the assistant via commands, and connect using your Gemini API key."

    stats: {
        downloads:  19332
        updated_at: 1709617868000
    }
}
```
