# Typify

Renders plain metadata values as colour-coded pills with icons, in properties, in Bases tables and on cards. A chosen base colour generates a light and dark palette in either a translucent or a solid mode, and icons come from the Lucide set or from imported SVG files. Any YAML property can be styled globally or per field in pill, rectangle or flat shape, and a configuration exports and imports as JSON.
