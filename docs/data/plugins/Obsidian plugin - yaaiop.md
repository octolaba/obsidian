# Yaaiop

An API-only chat that answers from the vault on desktop and mobile, and works read-only. It can search and open notes, images and PDFs for context, and returns tappable wikilinks in its replies. Conversation history and saved prompts are kept, and Smart Connections can optionally be used for semantic search.
