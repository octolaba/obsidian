# Flux TTS

Records audio from the ribbon or the command palette, saves the file in the vault, and creates a note with an embedded audio player and a Groq Whisper transcription. Timestamped segments linked to the audio are optional, and an AI cleanup pass can run while the original transcript is kept. Note templates, an automatic stop and a warning on microphone silence work on desktop and mobile.
