# Local History

Saves automatic local snapshots of notes and consolidates version history from those snapshots, Obsidian File Recovery and Obsidian Sync into one place. A chronological sidebar lists the versions, an LCS-based diff viewer compares them, and content can be copied or restored. Close snapshots are merged to keep the history from bloating.
