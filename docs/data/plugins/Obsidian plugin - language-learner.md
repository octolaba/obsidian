# Language Learner

Language Learner stores vocabulary entries and grammar-rule notes tagged by CEFR level from A1 to C2, each carrying a translation, part of speech, example sentences and notes. A ten-word vocabulary quiz exercises the collected entries, and a sidebar reports progress per language broken down by CEFR level with totals.

```cue
plugin: {
    id:     "language-learner"
    name:   "Language Learner"
    author: "wesswart77"
    repo:   "wesswart77/obsidian-language-learner"

    html_url:    "https://community.obsidian.md/plugins/language-learner"
    github_url:  "https://github.com/wesswart77/obsidian-language-learner"
    description: "Learn languages with vocabulary lists, grammar rules, vocabulary quiz, and progress tracking by CEFR level. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create vocabulary entries and grammar-rule notes with CEFR tags (A1–C2), translations, part of speech, example sentences, and notes. Run a 10-word vocabulary quiz and view per-language progress with CEFR-level breakdowns and totals in a sidebar."
```
