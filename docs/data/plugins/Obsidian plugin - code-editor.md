# Code Editor

Edits non-markdown text files such as code, configuration and data inside Obsidian, with syntax highlighting for more than fifty languages, line numbers with active-line highlighting, bracket matching, word wrap, tab indentation and undo history. Five built-in color themes are available, binary files are detected so they are not edited by accident, and further extensions can be registered.
