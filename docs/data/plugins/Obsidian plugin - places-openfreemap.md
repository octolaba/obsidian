# Places - OpenFreeMap

Supplies a map provider for the Places plugin, drawing free vector maps from OpenFreeMap and adding point-of-interest discovery. The Places plugin is required.

```cue
plugin: {
    id:     "places-openfreemap"
    name:   "Places - OpenFreeMap"
    author: "bobstanton"
    repo:   "bobstanton/places-openfreemap"

    html_url:    "https://community.obsidian.md/plugins/places-openfreemap"
    github_url:  "https://github.com/bobstanton/places-openfreemap"
    description: "Map provider for Places using OpenFreeMap, with free vector maps and POI discovery. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Requires the Places plugin: https://community.obsidian.md/plugins/places"
```
