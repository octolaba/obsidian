# Writing Habit

Tracks word counts, timed writing sprints, streaks and leaderboards from a persistent sidebar panel. Sprints run solo or with friends, daily and lifetime word counts are shown, and statistics are synced to WritingHabit leaderboards.

```cue
plugin: {
    id:     "writing-habit"
    name:   "Writing Habit"
    author: "Writing Habit"
    repo:   "jedgrant/wh-obsidian"

    html_url:    "https://community.obsidian.md/plugins/writing-habit"
    github_url:  "https://github.com/jedgrant/wh-obsidian"
    description: "Track words, sprints w friends, writing streaks, and leaderboards and more. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Details writing stats, sprints (solo or with friends), writing streaks, and leaderboards while you write in Obsidian, with stats synced to WritingHabit Leaderboards. View daily and lifetime word counts, run timed sprints, and build streaks from a persistent sidebar panel."

    stats: {
        downloads:  98

    }
}
```
