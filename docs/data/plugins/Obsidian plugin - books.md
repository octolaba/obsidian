# Books

Books provides a workspace for writing long-form manuscripts in the vault, with a left-side navigator, a spine view of sections and chapters, drag-and-drop reordering and readable manuscript tabs. Snippets are saved to a per-book scratchpad, research is pulled from other notes and canvases can be included, with writerly styling applied. The ordered spine exports to a single Markdown file stored locally under a Books folder.
