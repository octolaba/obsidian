# Any Task

Any Task renders task markers written with any character as theme-aware interactive checkboxes, so markers such as a slash, an angle bracket, an exclamation mark or a hyphen appear as clickable icons. Built-in CSS fixes are included for broad theme compatibility, and the recorded inputs state that it runs out of the box and stays light on large task lists.
