# Sanyuan Context Router

Sends an explicit query or the current editor selection to a configured Sanyuan sidecar and previews the read-injection block it returns. Retrieved context can be copied or inserted into the active note, and sidecar connectivity can be checked separately. An external Sanyuan sidecar is required, and smart retrieval handles explicit intent.
