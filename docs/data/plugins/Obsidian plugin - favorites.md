# Favorites

Favorites keeps a global list of favorite plugins and themes so the same selection is available in every vault. Items are favorited from the plugin or theme browser, and auto-updated In Use and Known histories are available beside the list. The lists are stored globally on the device and can be imported and exported.

```cue
plugin: {
    id:     "favorites"
    name:   "Favorites"
    author: "4source"
    repo:   "4source/favorites-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/favorites"
    github_url:  "https://github.com/4source/favorites-obsidian-plugin"
    description: "Store and manage a global favorites list of plugins and themes, keeping them accessible across all your vaults. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Manage a global favorites list for plugins and themes and make your go-to tools and styles available in every vault. Access auto-updated \"In Use\" and \"Known\" histories, favorite items directly from the plugin or theme browser, and import/export lists stored globally on your device."

    stats: {
        downloads:  828
        updated_at: 1785671946000
    }
}
```
