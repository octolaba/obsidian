# Github PR Tracker

Tracks GitHub pull requests in a sidebar panel showing title, repository, number, author, last update and review status for each one. Inline review counts and the combined CI commit status are displayed, pull requests can be refreshed or removed individually or in bulk, and closed ones can be kept for reference. The GitHub token is stored in the system keychain.

```cue
plugin: {
    id:     "github-pr-tracker"
    name:   "Github PR Tracker"
    author: "David Monnom"
    repo:   "davidmonnom/obsidian-pr-tracker"

    html_url:    "https://community.obsidian.md/plugins/github-pr-tracker"
    github_url:  "https://github.com/davidmonnom/obsidian-pr-tracker"
    description: "Track and manage GitHub pull request reviews directly from Obsidian. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Track GitHub pull requests in a sidebar panel and view per-PR details like title, repo, number, author, last updated, and review status. See inline review counts and combined CI commit status, refresh or remove PRs individually or in bulk, and keep closed PRs for reference. Store your GitHub token securely in the system keychain."

    stats: {
        downloads:  115
        updated_at: 1783881826000
    }
}
```
