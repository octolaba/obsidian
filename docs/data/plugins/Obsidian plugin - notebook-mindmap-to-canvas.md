# NotebookLM Mindmap to Canvas

Converts a NotebookLM mindmap into a native .canvas file from a single paste, parsing either JSON or Markdown. Layouts can be left-to-right, right-to-left or symmetric, node sizing stays dynamic, and Advanced Canvas styling such as arrowheads, path types and line patterns is applied. The recorded description states that the NotebookLM Ultra Exporter Chrome extension is required.
