# Text Progress Bar

Text Progress Bar renders low-fi text and emoji progress bars from a text-progress-bar block in a note. Fill and empty characters and their transitions are customizable, decimal partial progress can be shown, and several labeled bars are grouped in one block.

```cue
plugin: {
    id:     "text-progress-bar"
    name:   "Text Progress Bar"
    author: "michaeladams"
    repo:   "michaeladams/obsidian-text-progress-bar"

    html_url:    "https://community.obsidian.md/plugins/text-progress-bar"
    github_url:  "https://github.com/michaeladams/obsidian-text-progress-bar"
    description: "Display low-fi text progress bars in your notes."
    about:       "Insert text-based and emoji progress bars into notes using a text-progress-bar code block. Customize fill/empty characters and transitions, show decimal partial progress, and group multiple labeled bars in one block."
```
