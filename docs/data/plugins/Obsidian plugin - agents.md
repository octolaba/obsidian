# Agents

Agents launches AI command-line tools from the vault: right-clicking a file or folder opens a terminal preloaded with that path. On macOS the terminal is Terminal.app or iTerm2, and the agent command to execute in that directory is configurable.

```cue
plugin: {
    id:     "agents"
    name:   "Agents"
    author: "tsilva"
    repo:   "tsilva/obsidian-agents"

    html_url:    "https://community.obsidian.md/plugins/agents"
    github_url:  "https://github.com/tsilva/obsidian-agents"
    description: "Launch AI agents from your vault — right-click any file or folder to open a terminal with context. Supports Claude, Codex, and other AI CLI tools. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Launch AI agents from your vault with a right-click on any file or folder to open a terminal preloaded with the file or folder path. Run agents in Terminal.app or iTerm2 on macOS and configure the agent command to execute instantly in the correct directory."

    stats: {
        downloads:  282
        updated_at: 1772557408000
    }
}
```
