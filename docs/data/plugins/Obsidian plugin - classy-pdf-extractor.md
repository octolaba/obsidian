# Classy PDF Extractor

Extracts annotations from PDFs inside and outside the vault and writes them into notes with automated formatting. The import can be restricted by annotation type, page range and the day a comment was created, and a separate template controls the formatting of each annotation type. Annotations can be grouped by topic, date, folder and file, then sent to the current note, to a new note, or each into a note of its own.
