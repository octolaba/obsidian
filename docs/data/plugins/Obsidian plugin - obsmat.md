# MathMacro

Inserts a centered display math block and places the cursor inside it with Alt+M. Inside a math field, WordMat-style shortcuts expand to LaTeX when Space is pressed, covering fractions, superscripts and subscripts, dot products, Greek letters, roots, integrals, sums, vectors and hats. It works on both desktop and mobile.

```cue
plugin: {
    id:     "obsmat"
    name:   "MathMacro"
    author: "Mehdi Khaksar"
    repo:   "minomaster/ObsMat"

    html_url:    "https://community.obsidian.md/plugins/obsmat"
    github_url:  "https://github.com/minomaster/ObsMat"
    description: "A plugin simulating the WordMat experience. Write Math/Physics/Chemistry notation comfortably like in WordMat, rather than spending more time writing LaTeX. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert a centered display math block and place the cursor inside with Alt+M. Type WordMat-style shortcuts in math fields and press Space to expand common notation into LaTeX—fractions, superscripts/subscripts, \\cdot, Greek letters, \\sqrt, \\int, \\sum, \\vec, \\hat—compatible with desktop and mobile."

    stats: {
        downloads:  38
        updated_at: 1786045569000
    }
}
```
