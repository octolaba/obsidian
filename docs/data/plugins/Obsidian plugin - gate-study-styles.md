# GATE Study Styles

Applies modular CSS enhancements aimed at engineering and GATE study notes, each toggled on its own. Custom callouts, centered images and tables, cleaned-up embedded notes and restyled highlights, table headers and underlines are included. A custom accent color is applied across the supported elements.

    id:     "gate-study-styles"
    name:   "GATE Study Styles"
