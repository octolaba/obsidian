# Paste Reformatter

Reformats pasted HTML and plain text under regular-expression rules, converting HTML to clean Markdown and stripping empty elements or hard line breaks. Heading levels can be adjusted and blank lines removed so that the result matches the note structure. The transformed content is inserted at the cursor and a brief notification reports the paste type.

    id:     "paste-reformatter"
    name:   "Paste Reformatter"
    author: "keathmilligan"
