# Merge Notes

Merges notes selected in the file explorer into a single Markdown file. The selection is reordered by drag-and-drop and the merged note's title is entered before it is written. The new note is saved in the same folder as the first selected file.

```cue
plugin: {
    id:     "merge-notes"
    name:   "Merge Notes"
    author: "fnya"
    repo:   "fnya/merge-notes"

    html_url:    "https://community.obsidian.md/plugins/merge-notes"
    github_url:  "https://github.com/fnya/merge-notes"
    description: "Merge the selected notes."
    about:       "Merge selected notes from the file explorer into a single Markdown file. Rearrange the selection by drag-and-drop, specify the merged note's title, and save the new note in the same folder as the first selected file."

    stats: {

    }
}
```
