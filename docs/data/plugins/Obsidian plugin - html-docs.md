# HTML Docs

HTML Docs renders HTML in a sandboxed iframe, working across tabs, embeds and canvas. JavaScript may run inside that HTML for interactivity, but the iframe is isolated from other notes and from Obsidian's own data. The plugin describes itself as zero-dependency and minimal, doing one job and nothing else.

```cue
plugin: {
    id:     "html-docs"
    name:   "HTML Docs"
    author: "Sam"
    repo:   "smcllns/obsidian-plugin-html-docs"

    html_url:    "https://community.obsidian.md/plugins/html-docs"
    github_url:  "https://github.com/smcllns/obsidian-plugin-html-docs"
    description: "A zero-dependency minimal plugin to enable html docs in Obsidian - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Bringing the unreasonable effectiveness of HTML to Obsidian. HTML is rendered in a sandboxed iframe and works across tabs, embeds, and canvas. JS can run inside the HTML for interactivity but the iframe is isolated from your other notes and Obsidian's own data. No other bells and whistles. Minimal, simple, one job."

    stats: {
        downloads:  1357
        updated_at: 1781729025000
    }
}
```
