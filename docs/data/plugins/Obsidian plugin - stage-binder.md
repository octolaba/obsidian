# Stage Binder

Builds ChordPro charts and organizes them into setlists and run sheets, tracking performance details such as keys, timings, assignments, PDFs, images and notes. Charts are transposed on the fly, with capo-aware handling and Nashville number support. Songs remain in the vault as ordinary Markdown or .chordpro files, and a touch-friendly view supports performing from a tablet or a desktop.
