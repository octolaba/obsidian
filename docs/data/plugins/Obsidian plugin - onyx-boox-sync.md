# Booxidian

Watches a folder for Onyx Boox annotation exports and imports highlights, handwriting PDFs, annotated PDFs and plain text into the vault. Handwriting is converted to lossless SVG, with optional AI transcription, and companion notes quote the highlights with page-anchored deep links back into the PDF. Imports are deduplicated by content hash, and it runs on desktop only.
