# Project Euler Stats

Displays a Project Euler profile inside Obsidian, including solved counts, progress percentage, leaderboard rankings, tasks, and award status. Problem-solving progress can be tracked and compared with friends to see relative standings.

```cue
plugin: {
    id:     "project-euler-stats"
    name:   "Project Euler Stats"
    author: "artemkorsakov"
    repo:   "artemkorsakov/project-euler-stats"

    html_url:    "https://community.obsidian.md/plugins/project-euler-stats"
    github_url:  "https://github.com/artemkorsakov/project-euler-stats"
    description: "Get statistics from Project Euler."
    about:       "Display your Project Euler profile, solved counts, progress percentage, leaderboard rankings, tasks, and award status directly inside Obsidian. Track your problem-solving progress and compare results with friends to view relative standings."

    stats: {
        downloads:  279
        updated_at: 1743659384000
    }
}
```
