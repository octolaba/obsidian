# RosyPilot

RosyPilot offers context-aware inline AI completions for Chinese legal documents in Obsidian. It detects the surrounding Markdown context, whether heading, paragraph, list, block-quote, code or math, to tailor its prompt, and shows suggestions as ghost text. Providers and models can be switched, with DeepSeek and Volcengine named in the recorded text.
