# Cohere

Cohere syncs vault files to OSS and S3-compatible object storage, either manually or automatically, propagating deletions and isolating vaults and devices from one another. Conflict copies are preserved, empty directories can optionally be synced, and S3 connection configurations import and export with Signature V4 support.
