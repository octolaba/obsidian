# Colored Bases Properties

Colored Bases Properties colors property values in Bases files, embedded bases and markdown views, covering multi-select pills, formula-rendered values and inline tags. Colors are generated consistently from a hash of the value, coloring can be toggled per property type, individual colors are customized through visual previews or hex and HSL entry, and updates apply in real time.
