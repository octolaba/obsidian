# Folia Kanban

Provides a Kanban board whose cards are plain Markdown files, one note per card. Cards can be dragged to reorder or change status, nested as subcards, and carry comments and automatic history, with position and metadata persisted without a database or hidden state.

```cue
plugin: {
    id:     "folia-kanban"
    name:   "Folia Kanban"
    author: "Rafael Stavarengo"
    repo:   "stavarengo/folia-kanban"

    html_url:    "https://community.obsidian.md/plugins/folia-kanban"
    github_url:  "https://github.com/stavarengo/folia-kanban"
    description: "A real Kanban board with drag-and-drop, nested subcards, comments, and history — every card is a plain Markdown file. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Organize Kanban boards using plain Markdown files, with each card stored as a regular .md note. Drag cards to reorder or change status, create nested subcards, add comments and automatic history, and persist position and metadata without any database or hidden state."

    stats: {
        downloads:  261
```
