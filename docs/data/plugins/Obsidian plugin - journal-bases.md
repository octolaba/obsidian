# Journal Bases

Journal Bases adds two Base views for journaling and periodic review over daily, weekly, monthly, quarterly and yearly notes. A Periodic Notes view lists, folds and edits notes by period, while a Periodic Review view compares periods side by side and extracts insights for weekly, monthly, quarterly and yearly summaries.
