# Image Title

Renders the alt text of an image as a visible caption in reading view, centered above or below the image according to a setting. Obsidian's size parameters are stripped out of the caption text, and images with empty alt text are left without a caption.

```cue
plugin: {
    id:     "image-title"
    name:   "Image Title"
    author: "Ji"
    repo:   "reticenceji/obsidian-image-title"

    html_url:    "https://community.obsidian.md/plugins/image-title"
    github_url:  "https://github.com/reticenceji/obsidian-image-title"
    description: "Render image alt text as visible captions in reading view. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render image alt text as visible, centered captions in reading view and display the text from [] above or below images. Strip Obsidian size parameters from captions and skip images with empty alt text; set caption position to above or below images."

    stats: {
        downloads:  31
        updated_at: 1785293150000
    }
}
```
