# Property Values Browser

Lists frontmatter property names with their counts in a right-sidebar view. A property expands to its distinct values with counts, clicking a value opens an exact property and value search, and right-clicking a row deletes that property or value from the matching notes. The list is filtered from the top input and refreshed on demand.
