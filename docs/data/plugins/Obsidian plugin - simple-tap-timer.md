# Simple Tap Timer

Simple Tap Timer runs timers directly in notes from tap-timer code blocks, each started or stopped with a single tap. Timers marked independent run in parallel, while the rest keep a single active timer per note. It can generate an updatable summary table, reset every timer in a note, and save session logs to any file path in the vault.
