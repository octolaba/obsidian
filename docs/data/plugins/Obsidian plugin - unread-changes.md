# Unread Changes

Tracks unread edits across a vault that people and AI agents edit together, showing dots and folder rollups and listing every unread note in an inbox pane with who changed it and a plain-English summary. A virtual banner above a changed note offers Changelog, Diff and Mark Read actions, read state is synced, and diffs and author attribution are kept per device. Stamped changelogs are appended as browsable Markdown.

    id:     "unread-changes"
    name:   "Unread Changes"
    author: "Hayden / Atlas-AI"

Display a virtual banner above changed notes with Changelog, Diff and Mark Read actions, provide per‑device diffs and author attribution, and append stamped changelogs as browsable Markdown."
