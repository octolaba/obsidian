# Federated Emoji

Federated Emoji renders and inserts custom emoji from Mastodon and compatible federated instances while the Markdown source keeps the plain shortcode form. Emoji are searched by typing a colon and inserted with the keyboard or mouse, or picked from a searchable picker opened from the ribbon or the command palette. Emoji can be browsed and imported from several instances, with a priority order for duplicates.

```cue
plugin: {
    id:     "federated-emoji"
    name:   "Federated Emoji"
    author: "ringeringeraja33"
    repo:   "ringeringeraja33/FederatedEmoji"

    html_url:    "https://community.obsidian.md/plugins/federated-emoji"
    github_url:  "https://github.com/ringeringeraja33/FederatedEmoji"
    description: "Render and insert custom emoji from Mastodon and compatible federated instances. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render and insert Mastodon-style custom emoji while keeping Markdown source unchanged as :shortcode:. Search emoji by typing : and insert results via keyboard or mouse, or open a searchable picker from the ribbon or command palette. Browse and import emoji from multiple instances and set priority for duplicates."

    stats: {
        downloads:  39
        updated_at: 1784374432000
    }
}
```
