# Fountain Editor

Renders Fountain screenplay syntax in the Obsidian editor with automatic highlighting and screenplay-style styling. Fountain elements such as scene headings, action, dialogue and synopsis can be mixed with regular Markdown in the same note.

```cue
plugin: {
    id:     "fountain-editor"
    name:   "Fountain Editor"
    author: "Chuang Caleb"
    repo:   "chuangcaleb/obsidian-fountain-editor"

    html_url:    "https://community.obsidian.md/plugins/fountain-editor"
    github_url:  "https://github.com/chuangcaleb/obsidian-fountain-editor"
    description: "Fountain (screenplay) syntax highlighting in the editor."
    about:       "Render Fountain screenplay syntax directly in the Obsidian editor with automatic highlighting and screenplay-style styling. Mix Fountain elements (scene headings, action, dialogue, synopsis) with regular Markdown to write screenplays seamlessly inside your notes."
```
