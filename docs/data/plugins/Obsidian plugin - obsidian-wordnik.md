# Wordnik Definitions

Definitions, examples and related words are fetched from Wordnik and pasted at the cursor location. The lookup uses a searched word or the active note title, and the inserted output is shaped by a customizable template and a maximum-definition limit.

```cue
plugin: {
    id:     "obsidian-wordnik"
    name:   "Wordnik Definitions"
    author: "lizard-heart"
    repo:   "lizard-heart/obsidian-wordnik-definitions"

    html_url:    "https://community.obsidian.md/plugins/obsidian-wordnik"
    github_url:  "https://github.com/lizard-heart/obsidian-wordnik-definitions"
    description: "Grab information from Wordnik for a topic and bring it into your notes."
    about:       "Fetch definitions, examples, and related words from Wordnik and paste the results at your cursor location. Search a word or use the active note title to insert formatted Wordnik data, and control output with a customizable template and a maximum-definition limit."

    stats: {
        downloads:  4424
        updated_at: 1650164598000
    }
}
```
