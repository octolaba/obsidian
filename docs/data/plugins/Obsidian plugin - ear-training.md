# Ear Training

Provides interval and chord ear-training exercises inside Obsidian, covering melodic and harmonic patterns. Mistakes are reported immediately, and results can be saved to Markdown files to track progress over time.

```cue
plugin: {
    id:     "ear-training"
    name:   "Ear Training"
    author: "shiwer"
    repo:   "shiwer/ear-training-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/ear-training"
    github_url:  "https://github.com/shiwer/ear-training-obsidian-plugin"
    description: "Get ear training exercises inside your vault."
    about:       "Train your musical ear with interactive interval and chord exercises inside Obsidian. Practice melodic and harmonic patterns, receive immediate feedback on mistakes, and save results to Markdown files to track your progress."

    stats: {
        downloads:  1458
        updated_at: 1716720903000
    }
}
```
