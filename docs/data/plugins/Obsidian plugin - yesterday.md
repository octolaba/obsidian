# Yesterday

Creates and edits a journal in the Yesterday format inside Obsidian. Its extended Markdown adds dated entries, chat-style dialogs, dream passages, media content blocks and metadata such as location and weather.

    id:     "yesterday"
    name:   "Yesterday"
    author: "dominikmayer"
    repo:   "dominikmayer/obsidian-yesterday"

    html_url:    "https://community.obsidian.md/plugins/yesterday"
    github_url:  "https://github.com/dominikmayer/obsidian-yesterday"
