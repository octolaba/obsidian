# Dragger

Drags any block — paragraph, heading, list, task, table, code or math block — to a new place in the note, in the manner of Notion. Horizontal movement while dragging controls the nested indent and vertical movement sets the insertion position, a glowing drop indicator shows where the block will land, and multi-line ranges can be selected and moved as a group. It also works on mobile.
