# Timeline

Chronological timelines are built from Markdown inside timeline and timeline-labeled blocks. An event is written either as three lines prefixed with a plus sign for time, title and content, or as labeled lines using date, title and content keys, with blank lines separating events.

```cue
plugin: {
    id:     "obsidian-timeline"
    name:   "Timeline"
    author: "george-debug"
    repo:   "george-debug/obsidian-timeline"

    html_url:    "https://community.obsidian.md/plugins/obsidian-timeline"
    github_url:  "https://github.com/george-debug/obsidian-timeline"
    description: "Build great timelines."
    about:       "Create chronological timelines from simple Markdown by using timeline or timeline-labeled blocks. Define events with three +‑prefixed lines (time, title, content) or with labeled lines (date:, title:, content:), and separate events with blank lines for readability."

    stats: {
        downloads:  90510
        updated_at: 1658512472000
    }
}
```
