# Header Counter

Header Counter counts the headers in the current note and reports the total in a notification. It can also compute a header summary for pasting elsewhere, and which header levels are included is configurable.

```cue
plugin: {
    id:     "header-counter"
    name:   "Header Counter"
    author: "nancyel"
    repo:   "nancyel/header-counter"

    html_url:    "https://community.obsidian.md/plugins/header-counter"
    github_url:  "https://github.com/nancyel/header-counter"
    description: "Count the number of headers in the current note."
    about:       "Count headers in the current note and display the total in a notification. Compute a header summary to copy and paste elsewhere, and set which header levels to include."

    stats: {
        downloads:  520
        updated_at: 1716946227000
    }
}
```
