# VSCode Editor

VSCode Editor edits and views code files inside Obsidian with the Monaco editor, covering languages including C, C++, C#, Python, JavaScript, Rust and Go. It works offline, with customizable themes, fonts and code wrapping and with toggles for line numbers, indent guides and the minimap. Individual code blocks in Markdown can be opened for editing, and internal links are previewed.
