# Enveloppe

This plugin publishes notes to a preconfigured GitHub repository using custom templates for Jekyll, MkDocs, Hugo or a layout of your own, and can open pull requests that auto-merge. Wikilinks are converted to Markdown, internal links updated and folder notes renamed. Dataview queries, Mermaid and LaTeX are supported, and deleted or depublished files are removed.

```cue
plugin: {
    id:     "obsidian-mkdocs-publisher"
    name:   "Enveloppe"
    author: "enveloppe"
    repo:   "enveloppe/obsidian-enveloppe"

    html_url:    "https://community.obsidian.md/plugins/obsidian-mkdocs-publisher"
    github_url:  "https://github.com/enveloppe/obsidian-enveloppe"
    description: "Publish your notes to a preconfigured GitHub repository."
    about:       "Publish Obsidian notes to a GitHub repository using custom templates (Jekyll, MkDocs, Hugo or your own) and create pull requests that can auto-merge. Convert wikilinks to Markdown, update internal links, rename folder notes, support Dataview queries, Mermaid and LaTeX, and remove deleted or depublished files."

    stats: {
        downloads:  61388
        updated_at: 1775575121000
    }
}
```
