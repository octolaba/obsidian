# Hard Breaks

Turns soft line breaks in the open note into hard line breaks, in paragraphs and blockquotes, while leaving tables, lists, links, code blocks and front matter untouched. An editor command performs the replacement, and the hard break is written either as two trailing spaces or as a backslash, both CommonMark-compliant.

```cue
plugin: {
    id:     "hard-breaks"
    name:   "Hard Breaks"
    author: "bkis"
    repo:   "bkis/obsidian-hard-breaks"

    html_url:    "https://community.obsidian.md/plugins/hard-breaks"
    github_url:  "https://github.com/bkis/obsidian-hard-breaks"
```
