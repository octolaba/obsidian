# md2html

Converts the open Markdown note to HTML through a Python renderer and writes the result into the note's folder or a configured export folder. A light, dark or blue theme is applied, and the built-in CSS is meant to make the file easy to host. Success and error notices are shown after each conversion.

```cue
plugin: {
    id:     "mdtohtml"
    name:   "md2html"
    author: "maalolan"
    repo:   "maal0lan/md2html"

    html_url:    "https://community.obsidian.md/plugins/mdtohtml"
    github_url:  "https://github.com/maal0lan/md2html"
    description: "converts markdown file to html files with builtin css for easy hosting - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert the open Markdown note to HTML via a Python renderer and save the output to the note's folder or a configured export folder. Apply a chosen light/dark/blue theme to the HTML and show clear success or error notices."

    stats: {
        downloads:  32
        updated_at: 1783764151000
    }
}
```
