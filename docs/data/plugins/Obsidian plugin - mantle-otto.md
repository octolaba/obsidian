# Mantle Otto

Wraps the native Gemini CLI in a visual chat interface inside the vault, so context-aware agent workflows, note summarization, file edits and database searches run from a chat window. Active note files, text selections and workspace folder structure are fed to the local agent for contextual responses. Shell commands the agent proposes are audited and approved before they are executed, and the recorded text says the design matches the Zenith theme.

Otto automatically feeds active note files, text selections, and workspace folder structures to your local agent, ensuring contextual responses.
