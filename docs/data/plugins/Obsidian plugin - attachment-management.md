# Attachment Management

Customizes where attachments are stored through path variables for the note path, note name, date, MD5 hash and original file name. Pasted or dropped files are renamed and relocated automatically, path rules can be overridden per folder, file or extension, and a rearrange command renames and moves already linked attachments across the vault.

```cue
plugin: {
    id:     "attachment-management"
    name:   "Attachment Management"
    author: "trganda"
    repo:   "trganda/obsidian-attachment-management"

    html_url:    "https://community.obsidian.md/plugins/attachment-management"
    github_url:  "https://github.com/trganda/obsidian-attachment-management"
    description: "Customize attachment path, auto-rename attachments, etc."
    about:       "Set flexible attachment paths using variables like ${notepath}, ${notename}, ${date}, ${md5}, and ${originalname}. Auto-rename and relocate pasted or dropped files, override path rules per folder, file, or extension, and run a rearrange command to rename/move linked attachments across your vault."
```
