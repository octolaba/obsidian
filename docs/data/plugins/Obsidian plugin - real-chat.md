# Real Chat

Adds a chat sidebar backed by any OpenAI-compatible API, with the user supplying their own key, for providers such as DeepSeek and OpenRouter. The assistant can read and edit notes, run ranked vault search, browse the web, and process images. Five persistent chats run alongside each other with a per-chat model choice, vision input, memory notes, streamed responses, and chat export.
