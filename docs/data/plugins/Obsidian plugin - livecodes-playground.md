# Livecodes Playground

Creates client-side code playgrounds inside the vault with live previews and configurable markup, style, and script languages, powered by LiveCodes. Starter templates or quick prompts open a new playground, playgrounds and their notes are stored as files in the vault, and the recorded inputs describe examples across many languages and frameworks.
