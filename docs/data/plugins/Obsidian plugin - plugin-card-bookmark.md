# Card Bookmark

Card Bookmark turns URLs and vault-relative file paths written in code blocks into card-style bookmarks for links and notes. It also intercepts file-pane open events by extension, so single or double clicks on the chosen file types do not open them.

```cue
plugin: {
    id:     "plugin-card-bookmark"
    name:   "Card Bookmark"
    author: "wanda1993"
    repo:   "wanda1993/obsidian-plugin-web-bookmark"

    html_url:    "https://community.obsidian.md/plugins/plugin-card-bookmark"
    github_url:  "https://github.com/wanda1993/obsidian-plugin-web-bookmark"
    description: "Create rich card-style bookmarks for links and files. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert URL or vault-relative file paths as code blocks that render into card-style bookmarks for links and notes. Intercept file-pane open events by extension to block single- or double-click opens and prevent unwanted file opening."

    stats: {
        downloads:  617
        updated_at: 1775308072000
    }
}
```
