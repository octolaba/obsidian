# Letterboxd Recent Films

Shows a Letterboxd user's latest public diary entries as a poster collage inside a note. The posters are composed into one clickable PNG that inherits the current theme, with optional headings and tooltips, and clicking opens the entry in a new tab. The last successful feed is kept so the collage still renders offline.
