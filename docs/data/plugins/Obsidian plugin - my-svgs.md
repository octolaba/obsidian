# My SVGs

Registers custom SVG icons from the vault into Obsidian's global icon library so they can be used wherever an icon reference is accepted. A searchable visual grid previews the icons, reloads them on demand and copies a reference with one click. Black fills are converted to currentColor for theme compatibility.

```cue
plugin: {
    id:     "my-svgs"
    name:   "My SVGs"
    author: "ce-omarbadawy"
    repo:   "ce-omarbadawy/obsidian-my-svgs"

    html_url:    "https://community.obsidian.md/plugins/my-svgs"
    github_url:  "https://github.com/ce-omarbadawy/obsidian-my-svgs"
    description: "Registers your own SVGs into the global icon library for use with other plugins or however you want."
    about:       "Load custom SVG icons into your vault and use them anywhere Obsidian accepts icon references. Browse a searchable visual grid with live previews, reload icons on demand, and copy icon references with one click while black fills convert to currentColor for theme compatibility."

    stats: {
        downloads:  867
        updated_at: 1768974025000
    }
}
```
