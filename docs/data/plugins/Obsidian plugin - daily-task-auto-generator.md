# Daily Task Auto Generator

Generates daily task notes on a schedule from customizable templates, with variables for date, time and progress and a choice between every day and workdays only. Completion rates for the previous day are tracked, and the notes are filed into year and month folders. It runs on desktop and on mobile.

    name:   "Daily Task Auto Generator"
    author: "maigamo"
