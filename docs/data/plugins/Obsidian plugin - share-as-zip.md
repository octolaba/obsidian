# Share as ZIP

Share as ZIP exports the current note together with all the notes it links to as a ZIP archive, including binary files such as PDFs and images. Frontmatter, headers, folders and files can be excluded to keep private content out, and the compressed archive is offered through a Save As dialog for sharing or backup.

```cue
plugin: {
    id:     "share-as-zip"
    name:   "Share as ZIP"
    author: "friebetill"
    repo:   "friebetill/obsidian-share-as-zip"

    html_url:    "https://community.obsidian.md/plugins/share-as-zip"
    github_url:  "https://github.com/friebetill/obsidian-share-as-zip"
    description: "Share notes and their links as a zip folder."
    about:       "Export the current note and all linked notes as a ZIP archive, including binary files like PDFs and images. Configure frontmatter, header, folder, and file exclusions to skip private or unwanted content. Compress and prompt a Save As dialog for easy sharing or backup."
```
