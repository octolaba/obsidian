# Text to Speech

A whole note is spoken from the status bar or the ribbon, and a selection can be spoken while editing. The language is detected automatically and can be overridden from frontmatter, native operating-system voices are used, and other plugins can drive it through an exposed API. Android is recorded as unsupported.

```cue
plugin: {
    id:     "obsidian-tts"
    name:   "Text to Speech"
    author: "Johannes Theiner"
    repo:   "joethei/obsidian-tts"

    html_url:    "https://community.obsidian.md/plugins/obsidian-tts"
    github_url:  "https://github.com/joethei/obsidian-tts"
    description: "Hear your notes."
    about:       "Play entire notes from the status bar or ribbon, or speak only selected text while editing. Detect language automatically and override it with lang: {languageCode} in frontmatter; use native OS voices (Android not supported) and expose a plugin API for other plugins."

    stats: {

}
```
