# Zotero Cite PDF

Zotero Cite PDF searches Zotero literature and inserts the selected item, its citation, or a link to its PDF, HTML or other attachment into a note. Once the Zotero data directory is set, an attached asset can be opened from within Obsidian in a custom application.

```cue
plugin: {
    id:     "zotero-cite-pdf"
    name:   "Zotero Cite PDF"
    author: "fengchendian"
    repo:   "fengchendian/obsidian-zotero-cite-pdf"

    html_url:    "https://community.obsidian.md/plugins/zotero-cite-pdf"
    github_url:  "https://github.com/fengchendian/obsidian-zotero-cite-pdf"
    description: "Cite zotero-pdf and directly open zotero-pdf. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Search Zotero literature and insert selected items, citations, or links (PDF/HTML/other) directly into Obsidian notes. Open Zotero-attached assets in a custom app from within Obsidian after setting your Zotero data directory."

    stats: {
        downloads:  197
        updated_at: 1778910696000
    }
}
```
