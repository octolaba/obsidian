# XLSX Viewer

Opens .xlsx workbooks inside Obsidian as read-only value tables with a tab per sheet and sticky column letters and row numbers. Cell values are shown, including cached or formatted formula results, and cells are searchable across the workbook. Sheet, row and column counts are reported, and rendering is capped at 10,000 rows.
