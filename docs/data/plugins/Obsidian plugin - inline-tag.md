# Inline Tag

Inline Tag writes a tag reference with a human-readable label rather than the raw tag text. The labels render as clickable tokens with Live Preview decorations, and clicking one opens Obsidian Search preloaded with a tag query that lists every note carrying that tag. Hovering displays the canonical tag behind the label.

```cue
plugin: {
    id:     "inline-tag"
    name:   "Inline Tag"
    author: "mb-yul"
    repo:   "mb-yul/obsidian-inline-tag-plugin"

    html_url:    "https://community.obsidian.md/plugins/inline-tag"
    github_url:  "https://github.com/mb-yul/obsidian-inline-tag-plugin"
    description: "Reference tags with readable labels that open native tag search on click. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Write tag references with human-readable labels using the [[#tag|Label]] syntax. Render labels as clickable tokens that open Obsidian Search preloaded with tag:#tag to list all notes with that tag, with Live Preview decorations and hover display of the canonical tag."

}
```
