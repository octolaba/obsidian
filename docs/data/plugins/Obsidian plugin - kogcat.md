# KogCat

Checks a selection, a paragraph or a whole note against a local knowledge base of cognitive biases, logical fallacies and decision frameworks. It returns concise calibration points intended to sharpen a judgment, and leaves the original Markdown unchanged. An optional local-model distillation step narrows the advice.

```cue
plugin: {
    id:     "kogcat"
    name:   "KogCat"
    author: "uv"
    repo:   "kogcat/obsidian-kogcat"

    html_url:    "https://community.obsidian.md/plugins/kogcat"
    github_url:  "https://github.com/kogcat/obsidian-kogcat"
    description: "Calibrate your thinking against a knowledge base of cognitive biases, anti-patterns, and contradictions with your past notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Calibrate reasoning on any selection, paragraph, or whole note against a local knowledge base of cognitive biases, logical fallacies, and decision frameworks. Receive concise calibration points that sharpen judgments and preserve your original Markdown, with optional local-model distillation for focused advice."

    stats: {
        downloads:  123
        updated_at: 1781834323000
    }
}
```
