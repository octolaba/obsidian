# deepseek-ai-assistant

Manages prompts and turns AI conversations into searchable, linkable notes in the vault. Prompts are shown on a sidebar timeline, past exchanges are retrieved by keyword search and deep links, and asking frequency is displayed as a heatmap. Models using the OpenAI request format are supported, with streaming and Markdown output.
