# Search on Internet

Search on Internet adds context-menu items that search external sites such as Google or Wikipedia from a selection, a note title or a link. Results open either in an iframe inside Obsidian or in the default browser, and custom sites can be added. The recorded description notes that the right-click entry may be broken in recent Obsidian releases.

```cue
plugin: {
    id:     "search-on-internet"
    name:   "Search on Internet"
    author: "hemile"
    repo:   "hemile/obsidian-search-on-internet"

    html_url:    "https://community.obsidian.md/plugins/search-on-internet"
    github_url:  "https://github.com/hemile/obsidian-search-on-internet"
    description: "Add context menu items to search the internet based on the title of your note."
    about:       "Search selected text on external websites like Google or Wikipedia inside Obsidian using an iframe, or open results in your default browser. Add custom sites and trigger searches from selections, note titles, or links via context menus (right-click may be broken in recent Obsidian releases)."

    stats: {
        downloads:  30676
        updated_at: 1624466128000
    }
}
```
