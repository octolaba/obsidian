# Timestamp Link

Timestamp Link copies timestamped links to notes, headings and blocks so the moment a connection was made is recorded. Block links carry dual timestamps for creation and insertion time, which exposes the chronological context of the note network.

```cue
plugin: {
    id:     "timestamp-link"
    name:   "Timestamp Link"
    author: "wenlzhang"
    repo:   "wenlzhang/obsidian-timestamp-link"

    html_url:    "https://community.obsidian.md/plugins/timestamp-link"
    github_url:  "https://github.com/wenlzhang/obsidian-timestamp-link"
    description: "Copy timestamped links to blocks, headings and notes."
    about:       "Copy timestamped links to notes, headings, and blocks to record when connections were made and inserted. Add dual timestamps to block links to track creation and insertion times and reveal the chronological context of your note network."
```
