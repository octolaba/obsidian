# Config Sync

Config Sync distributes vault configuration — CSS snippets, hotkeys and plugin settings — selectively across devices and vaults, with an explicit Apply on each device. Configurations are captured into a versioned store that travels either through your notes or through a git or local transport, credentials are sanitized, and a single backup allows the last apply to be reverted.
