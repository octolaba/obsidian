# Ring a secretary

Ring a secretary holds ChatGPT conversations inside Obsidian and saves them as code-block dialogues that stay searchable and resumable. New dialogues start from the command palette, and fresh threads can be created to limit token usage during long consultations. The recorded text states that a ChatGPT API key is required.
