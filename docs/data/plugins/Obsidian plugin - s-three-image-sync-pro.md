# S3 Image Sync Pro

S3 Image Sync Pro scans local images referenced by notes, uploads them to S3-compatible cloud storage such as Cloudflare R2, AWS S3 or MinIO, and replaces the local Markdown image links with public remote URLs. Uploads are browsed and managed in a responsive image grid with adaptive card sizing that the recorded text describes as mobile-friendly. The description also names note-path matching, WebP compression through WASM, and auto-delete sync.
