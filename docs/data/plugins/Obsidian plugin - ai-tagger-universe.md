# AI Tagger Universe

Generates tags for notes with local or cloud AI and writes them into frontmatter. Tags can be matched against existing vault tags or predefined lists, nested hierarchical tags are supported, and batch tagging runs across many notes. An interactive network view visualizes the tag relationships.
