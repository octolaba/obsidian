# To-Do to Done Mover

To-Do to Done Mover moves completed checkbox tasks together with their indented sub-tasks into a Done section of the same note, preserving indentation and task hierarchy. It runs from the right-click menu or the command palette, an automatic mode moves tasks once they are fully checked, and a completion date can be appended to each moved line.

```cue
plugin: {
    id:     "todo-done-mover"
    name:   "To-Do to Done Mover"
    author: "wenzel1983"
    repo:   "donnervs/obsidian-todo-done-mover"

    html_url:    "https://community.obsidian.md/plugins/todo-done-mover"
    github_url:  "https://github.com/donnervs/obsidian-todo-done-mover"
    description: "Move completed checkbox tasks (with their sub-tasks) into a Done section — via right-click, command, or automatically. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Move completed checkbox tasks and their indented sub-tasks into a Done section in the same note, preserving indentation and task hierarchy. Run via right-click or command palette, enable auto mode to move tasks when fully checked, and optionally append a completion date to moved lines."
```
