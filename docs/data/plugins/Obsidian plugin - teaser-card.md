# Teaser Card

Teaser Card renders a clickable image teaser card from a fenced code block tagged teaser, showing a background image, a centred title and text, and a link, with a portrait tile, a gradient overlay and a hover-lift effect. The recorded About text, which is written in German rather than English, notes that Obsidian-internal attachment links are not yet resolved.
