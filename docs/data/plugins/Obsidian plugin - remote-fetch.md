# Remote Fetch

Downloads files from any HTTP or HTTPS URL directly into the vault, extracting the filename automatically or accepting a custom one. The destination folder is chosen with type-ahead, file extensions are detected and applied, and dangerous or oversized files are blocked with explicit error messages.
