# Arcane Obfuscate

Obfuscates text into animated runic characters in the editor and in exported HTML, leaving whitespace and escaped characters as plain text. Marked text can be revealed letter by letter with backslashes, or whole words by prefixing them with an exclamation mark. The recorded inputs state that this is not strong secrecy, because the structure of the text stays exposed.
