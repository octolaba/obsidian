# Weekly Review notes linker

Builds a weekly index note that links every note created during the past week. Linking them keeps periodic notes connected in the graph and makes the week's activity navigable without opening each file separately.

```cue
plugin: {
    id:     "weekly-review-linker"
    name:   "Weekly Review notes linker"
    author: "adityakhowalgithub"
    repo:   "adityakhowalgithub/weekly-review-notes-linker"

    html_url:    "https://community.obsidian.md/plugins/weekly-review-linker"
    github_url:  "https://github.com/adityakhowalgithub/weekly-review-notes-linker"
    description: "This links all of the files you have created in the last week into a Weekly Review note."
    about:       "Create a weekly index file that links every note created during the past week. Keep periodic notes connected in your graph without opening each file, enabling quick navigation and review of your weekly activity."

    stats: {
        downloads:  905
        updated_at: 1715011456000
    }
}
```
