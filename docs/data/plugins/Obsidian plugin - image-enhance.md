# image enhance

image enhance uploads images to a remote host through PicGo, PicList or PicGo-Core, turning pasted images into hosted links. Images in one file or across the vault are uploaded in batches, web images are downloaded to local files, and unused image files and broken image links are cleaned up. Drag-and-drop and right-click uploading are supported.
