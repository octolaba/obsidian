# Ratel

An AI assistant for the vault: it answers questions with numbered citations that open in one click, and carries out multi-step jobs by searching, reading, synthesizing, and writing, asking before it changes anything. Indexing and embeddings run locally by default, network traffic goes only to the configured AI provider, keys live in the system keychain, and the recorded text states there is no telemetry. DeepSeek, Claude, or a fully offline Ollama setup can be used, with per-tool permissions and confirmation before edits.
