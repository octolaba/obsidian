# Mood Atlas

Mood Atlas suggests emotion words inline while writing. Typing an emotion word followed by a trigger key lists the other feeling words in the same emotional region, which is meant to help find a more precise word than happy or sad for what is being experienced.

```cue
plugin: {
    id:     "mood-atlas"
    name:   "Mood Atlas"
    author: "alpinemily"
    repo:   "alpinemily/obsidian-mood-atlas"

    html_url:    "https://community.obsidian.md/plugins/mood-atlas"
    github_url:  "https://github.com/alpinemily/obsidian-mood-atlas"
    description: "Expand your emotional vocabulary beyond 'happy' and 'sad' with inline emotion suggestions - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Inline emotion word suggestions. Type any emotion word followed by a trigger key to pull up all the feeling words in the same emotional region, helping you find the most precise word for what you're experiencing."

    stats: {
        downloads:  1623
        updated_at: 1780610219000
    }
}
```
