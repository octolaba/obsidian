# Open Related Url

Open Related Url opens URLs recorded in a note's YAML frontmatter. Keys ending in Url are scanned and offered as options to open in the browser, common frontmatter keys are defined as quick URLs, and keybindings jump straight to a linked task, file or web resource.

```cue
plugin: {
    id:     "open-related-url"
    name:   "Open Related Url"
    author: "dpickett"
    repo:   "dpickett/open-related-url"

    html_url:    "https://community.obsidian.md/plugins/open-related-url"
    github_url:  "https://github.com/dpickett/open-related-url"
    description: "Open URLs found in a note's YAML frontmatter."
    about:       "Open URLs listed in a note's YAML front matter by scanning for keys ending with \"Url\" and present matching options to open in your browser. Define common frontmatter keys as quick URLs and assign keybindings to jump directly to linked tasks, files, or web resources."

    stats: {
        downloads:  4335
        updated_at: 1661009456000
    }
}
```
