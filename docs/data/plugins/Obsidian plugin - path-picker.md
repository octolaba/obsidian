# Path Picker

Fuzzy-finds files and directories under a chosen root from inside Obsidian, then inserts the selected path at the cursor or opens the entry in Obsidian or the operating system's default application. Results can be previewed as a directory tree or a file head with syntax highlighting, and the split can be adjusted. The recorded description states that it operates entirely inside Obsidian with no external binaries.
