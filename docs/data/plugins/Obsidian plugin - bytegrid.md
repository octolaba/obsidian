# ByteGrid

ByteGrid visualizes binary data and C struct memory layouts from YAML definitions as interactive, byte-accurate SVG diagrams. It shows bitfield-level detail with automatic color-coded fields and offers byte- or bit-layout modes. Flexible legends support documenting protocols, file formats and reverse-engineering tasks.
