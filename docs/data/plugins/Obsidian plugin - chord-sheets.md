# Chord Sheets

Chord Sheets works with chord sheets written as chords over lyrics or as inline bracketed chords, keeping symbol highlighting and diagram rendering active in edit, live preview and reading modes. Chord diagrams for guitar, ukulele and mandolin are drawn locally and custom chord shapes can be defined. Songs can be transposed and scrolled automatically while playing.
