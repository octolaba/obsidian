# Pivotal Tracker Integration

Pivotal Tracker Integration imports stories, bugs and chores from Pivotal Tracker into the vault as Markdown files in a chosen folder. Stories are pulled on demand from a specified project using a Tracker API key, and their titles, descriptions, labels and other details are stored for offline access.
