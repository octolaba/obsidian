# Health Vitals

Health Vitals imports an Apple Health export as ZIP or XML and stream-parses large files without loading them into memory, producing a compact cache file of daily aggregates and workouts. The metrics are then browsed in a dashboard of tiles, sparklines and favourites. The original export is stated to stay read-only and outside the vault.
