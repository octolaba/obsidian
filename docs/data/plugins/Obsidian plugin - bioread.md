# BioRead

BioRead applies Bionic Reading anchors in Reading and Preview mode, bolding the leading portion of words to create visual fixation points. It skips code blocks, inline code, scripts and other non-prose elements and runs on both desktop and mobile Obsidian. Its recorded description presents it as an ADHD accessibility plugin.
