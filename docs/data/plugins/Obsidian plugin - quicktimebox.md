# QuickTimeBox

Renders an interactive time grid in a note from a quicktimebox code block, so a day is planned inside the note itself. Slots are edited in place and the changes are saved back to the note automatically. A live now indicator, configurable slot granularity, midnight-wrap and RTL layouts are handled.

```cue
plugin: {
    id:     "quicktimebox"
    name:   "QuickTimeBox"
    author: "loudinthecloud"
    repo:   "loudinthecloud/obsidian-quick-timebox"

    html_url:    "https://community.obsidian.md/plugins/quicktimebox"
    github_url:  "https://github.com/loudinthecloud/obsidian-quick-timebox"
    description: "Embed interactive timeboxing in any note (quickly). - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Plan your day inside notes by dropping a quicktimebox code block to render an interactive time grid. Edit slots inline and save changes back to the note automatically. Show a live now indicator, choose slot granularity, and handle midnight-wrap and RTL layouts."

    stats: {
        downloads:  120
        updated_at: 1776551022000
    }
}
```
