# Eisenhower Matrix

Organizes tasks by urgency and importance in an interactive Eisenhower matrix, where toggling the two flags routes a task into its quadrant. Tasks are edited inline, reordered or moved by drag and drop, scheduled with dates and assigned to people. Everything is persisted to a readable Markdown file, with overdue alerts and per-quadrant counters.
