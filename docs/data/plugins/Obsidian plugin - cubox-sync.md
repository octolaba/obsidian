# Cubox

Syncs articles and highlighted annotations from Cubox into the vault as Markdown notes. Syncs run manually or periodically and can be filtered by folder, type, tags and status. Filenames, front matter and note content are shaped with templates.

```cue
plugin: {
    id:     "cubox-sync"
    name:   "Cubox"
    author: "olcubo"
    repo:   "olcubo/obsidian-cubox"

    html_url:    "https://community.obsidian.md/plugins/cubox-sync"
    github_url:  "https://github.com/olcubo/obsidian-cubox"
    description: "Sync your Cubox articles & annotations"
    about:       "Sync articles and highlighted annotations from Cubox into Obsidian as Markdown notes. Filter by folder, type, tags and status, run manual or periodic syncs, and customize filenames, front matter and note content with templates."
```
