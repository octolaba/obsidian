# X Clipper

Saves X posts as notes together with their images, videos, author information and hashtags. Media is downloaded into the attachments folder of the vault, hashtags become frontmatter and inline tags, tag choices are suggested and remembered, and vxtwitter serves as a fallback source.

```cue
plugin: {
    id:     "x-clipper"
    name:   "X Clipper"
    author: "ryotaunzai"
    repo:   "ryotaunzai/x-clipper"

    html_url:    "https://community.obsidian.md/plugins/x-clipper"
    github_url:  "https://github.com/ryotaunzai/x-clipper"
    description: "Save X (Twitter) posts as notes with images and videos included. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Save X (Twitter) posts to Obsidian as Markdown notes with images, videos, author info, and hashtags automatically included. Download media into your vault's attachments folder, extract hashtags as frontmatter and inline tags, suggest and remember tag selections, and fall back to vxtwitter when needed."

    stats: {
        downloads:  531
        updated_at: 1778882812000
    }
}
```
