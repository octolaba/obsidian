# Folder Limit

Limits how many files a folder shows in the file explorer through a global maximum and adds a show more control. A folder's context menu toggles between showing all files and showing fewer. It integrates with the native virtual list rather than using DOM mutation observers, so scrollbars stay accurate.

```cue
plugin: {
    id:     "folder-limit"
    name:   "Folder Limit"
    author: "Naggischnulu"
    repo:   "naggischnulu/obsidian-folder-limit"

    html_url:    "https://community.obsidian.md/plugins/folder-limit"
    github_url:  "https://github.com/naggischnulu/obsidian-folder-limit"
    description: "Limits the number of visible files in folders and provides a show more button. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Limit how many files appear in large folders to declutter the file explorer by setting a global maximum. Toggle showing all or fewer files from a folder's context menu. Keep accurate scrollbars and fast performance via native virtual-list integration without DOM mutation observers."

    stats: {
        downloads:  97
        updated_at: 1783238380000
    }
}
```
