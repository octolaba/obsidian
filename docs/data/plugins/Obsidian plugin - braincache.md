# braincache

The plugin creates braincache flashcards directly from Markdown using a deck, question and answer syntax, and embedded images are uploaded to braincache. Local cards are synced with a braincache account from the ribbon button or the sync command.

```cue
plugin: {
    id:     "braincache"
    name:   "braincache"
    author: "xspgmike"
    repo:   "xspgmike/braincache_obsidian"

    html_url:    "https://community.obsidian.md/plugins/braincache"
    github_url:  "https://github.com/xspgmike/braincache_obsidian"
    description: "Create braincache flashcards."
    about:       "Create braincache flashcards directly from Markdown using a simple #deck, q:, a: syntax and include embedded images that upload to braincache. Sync local cards with your braincache account using the ribbon button or the sync command."

}
```
