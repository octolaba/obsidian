# Home Base

Home Base designates one destination as the vault's home, opened at startup, in place of new tabs, or on demand. The target can be a file with an md, mdx, canvas or base extension, a workspace, a random file or folder, the graph, or a journal or periodic note. View and opening modes, new-tab behaviour and a sticky home icon are configurable.

```cue
plugin: {
    id:     "home-base"
    name:   "Home Base"
    author: "David V. Kimball"
    repo:   "davidvkimball/obsidian-home-base"

    html_url:    "https://community.obsidian.md/plugins/home-base"
    github_url:  "https://github.com/davidvkimball/obsidian-home-base"
    description: "Your dedicated home in your vault. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Set a dedicated home base for your vault and open it at startup, replace new tabs, or open on demand. Choose from file (.md/.mdx/.canvas/.base), workspace, random file/folder, graph, journal or periodic notes; configure view and opening modes, new-tab behavior, and enable a sticky home icon."

    stats: {
        downloads:  4208
        updated_at: 1780170357000
    }
}
```
