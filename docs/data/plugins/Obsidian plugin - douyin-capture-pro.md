# Douyin Capture Pro

A fork of obsidian-douyin-capture that imports Douyin share links into Obsidian, extracting video, images and text locally and generating structured notes. The recorded description states that it depends on a local Python backend, obsidian-content-capture-backend, which must be installed and started first, and that links and media are not processed in the cloud.
