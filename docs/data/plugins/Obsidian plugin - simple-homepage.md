# Simple Homepage

Simple Homepage designates an index note as a homepage that behaves like a web browser home page. A command opens it whether or not a homepage tab already exists, and the homepage can launch automatically when Obsidian starts with only an empty tab.

```cue
plugin: {
    id:     "simple-homepage"
    name:   "Simple Homepage"
    author: "Dajhiro"
    repo:   "dajhiro/obsidian-simple-homepage"

    html_url:    "https://community.obsidian.md/plugins/simple-homepage"
    github_url:  "https://github.com/dajhiro/obsidian-simple-homepage"
    description: "Set a note as your homepage that behaves just like a web browser. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open your index note as a browser-like homepage with a command that opens it regardless of whether a homepage tab already exists. Launch the homepage automatically at startup when Obsidian opens with only an empty tab."

    stats: {
        downloads:  107
        updated_at: 1784789357000
    }
}
```
