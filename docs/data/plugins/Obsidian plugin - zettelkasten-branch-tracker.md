# Zettelkasten Branch Tracker

Zettelkasten Branch Tracker draws note hierarchies as a branch-style graph that recognizes complex Zettelkasten ID formats. Tiers are colour-coded and nodes are scaled by the number of sub-notes they hold, and pan, zoom and hover feedback are used to explore a note's ancestors, siblings, continuations and branching children.
