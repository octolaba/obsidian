# Canvas Project Autofit

Zooms a canvas on open so it fills the viewport width and pins it to the top, which leaves lower rows off-screen on tall project boards. Auto-fitting can be limited to canvases under a given path prefix, and a Fit canvas to width command reframes on demand. External links in text cards open with a single click.

```cue
plugin: {
    id:     "canvas-project-autofit"
    name:   "Canvas Project Autofit"
    author: "Peng He"
    repo:   "brianpenghe/canvas-project-autofit"

    html_url:    "https://community.obsidian.md/plugins/canvas-project-autofit"
    github_url:  "https://github.com/brianpenghe/canvas-project-autofit"
    description: "Zoom canvases on open to fill the viewport width, pinned to the top. Ideal for project boards with many cards. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Auto-fit canvases on open to frame the board width and pin the canvas top so lower rows can stay off-screen for tall project boards. Limit auto-fit by path prefix, run the Fit canvas to width command to reframe, and open external links in text cards with a single click."

    stats: {
        downloads:  32
        updated_at: 1785913496000
    }
}
```
