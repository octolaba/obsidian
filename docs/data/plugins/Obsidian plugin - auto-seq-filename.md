# Auto Sequential Filename

Auto Sequential Filename creates Markdown files whose names combine a custom prefix with a zero-padded number, such as GS0001 or RY0001. Several target folders can be configured, the smallest missing number is reused so gaps are filled, and the new file is created and opened from the command palette.

```cue
plugin: {
    id:     "auto-seq-filename"
    name:   "Auto Sequential Filename"
    author: "yueyinfeng"
    repo:   "yueyinfeng/auto-seq-filename"

    html_url:    "https://community.obsidian.md/plugins/auto-seq-filename"
    github_url:  "https://github.com/yueyinfeng/auto-seq-filename"
    description: "Create Markdown files with sequential filenames such as GS0001 and RY0001. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create sequentially numbered Markdown files with custom prefixes and zero-padded numbers. Configure multiple target folders and reuse the smallest missing number to fill gaps, then create and open the new file from the command palette."
}
```
