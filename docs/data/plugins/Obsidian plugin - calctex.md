# Calctex

Calctex evaluates LaTeX formulas inline using the CortexJS Compute Engine. Adding an equals sign after a formula displays its solution, and clicking that result inserts it into the note.

```cue
plugin: {
    id:     "calctex"
    name:   "Calctex"
    author: "mika-dev"
    repo:   "developer-mike/obsidian-calctex"

    html_url:    "https://community.obsidian.md/plugins/calctex"
    github_url:  "https://github.com/developer-mike/obsidian-calctex"
    description: "Calculate LaTeX formulas."
```
