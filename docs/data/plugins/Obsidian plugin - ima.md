# Ima Vault

Ima Vault brings an IMA knowledge base into Obsidian, reachable from a sidebar panel or the command palette. Notes are searched by title or body with pagination, notebook folders are browsed, and a note is rendered as native Markdown, imported into the vault as a Markdown file, or navigated with a multi-level back and forward stack.
