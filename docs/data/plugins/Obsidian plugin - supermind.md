# SuperMind

XMind files are viewed inside Obsidian and mind maps are edited on a canvas with drag-and-drop layout, several themes and rich content including tables, callouts and code blocks. Maps sync in both directions with Markdown, nodes are expanded with AI through multiple providers, and maps export to PNG, JPEG, SVG or XMind.
