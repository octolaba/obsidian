# Daily Notes Automater

Creates a daily note automatically when the vault is launched, using configurable date formats, template content, filename suffixes and optional year and month subdirectories. Notes are stored in a chosen root folder, and creation is skipped when no template is specified.

    id:     "daily-note-automater"
    name:   "Daily Notes Automater"
    author: "davidpedrero"
