# RedNote

Converts RedNote, also known as Xiaohongshu, posts into templated Markdown notes, parsing out title, tags, content, and categories. The xiaohongshu, rednote, and xhslink domains are handled.

```cue
plugin: {
    id:     "rednote"
    name:   "RedNote"
    author: "kylemumu"
    repo:   "ch-yyk/obsidian-rednote"

    html_url:    "https://community.obsidian.md/plugins/rednote"
    github_url:  "https://github.com/ch-yyk/obsidian-rednote"
    description: "Connect RedNote/Xiaohongshu (小红书) with Obsidian - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert RedNote (Xiaohongshu小红书) notes into templated Markdown notes with parsed title, tags, content, and categories. Handle xiaohongshu/rednote/xhslink domains."

    stats: {
        downloads:  177
        updated_at: 1783825676000
    }
}
```
