# koncham workspace

Adds a Center-panes sidebar that lists every open main-area pane as a vertical tab. Any pane can be switched to with one click, the active note is highlighted, and panes can be pinned so new notes open in their own pane. Right-clicking a tab header opens further pane actions.

```cue
plugin: {
    id:     "koncham-workspace"
    name:   "koncham workspace"
    author: "manogna4"
    repo:   "manogna4/obsidian-koncham-workspace"

    html_url:    "https://community.obsidian.md/plugins/koncham-workspace"
    github_url:  "https://github.com/manogna4/obsidian-koncham-workspace"
```
