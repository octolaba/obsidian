# Settings Management

Settings Management adds a menu at the bottom right of the Settings tab that lists every enabled and disabled plugin and CSS snippet in a grid layout. Current plugin and CSS enable states can be saved as named configs, renamed or deleted by right-click, and applied again instantly, with optional Lucide icons.
