# Timeline Calendar

Timeline Calendar renders month, week, day and agenda views with time labels aligned to the grid lines. Time-stamped tasks and list items from daily notes appear as timed or all-day events, which can be moved by drag-and-drop and resized. Selecting an event opens the note it came from.
