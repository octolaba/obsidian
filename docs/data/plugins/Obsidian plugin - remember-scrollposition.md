# Remember Scrollposition

Saves the scroll position of each note and returns to it when the note is reopened. Restoring happens automatically or on demand from a ribbon icon or a command. It works in Live Preview and Source; read view and mobile are not supported.

    id:     "remember-scrollposition"

    author: "s-blu"
