# Heading Helper

Heading Helper draws heading indicators in the editor gutter, and clicking a marker changes that heading's level. Commands cycle, increase, decrease or set a heading level, and optional hierarchy warnings point out structural issues.

```cue

    id:     "heading-helper"
    name:   "Heading Helper"
    author: "sidkhuntia"
    repo:   "sidkhuntia/obsdian-headings-helper"
```
