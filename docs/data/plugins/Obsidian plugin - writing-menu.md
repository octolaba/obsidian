# Writing Menu

Bundles a writing environment aimed at novelists: typography controls for font, size, line height and line width per note or folder, a focus mode with typewriter scroll, and smart input covering auto quotes, symbol triggers, text substitution and smart enter. It counts characters in Munpia and Novelpia formats with daily-note integration, tracks work time per draft, writing and editing mode into frontmatter, and shows a calendar dashboard with a date strip, monthly view and hover previews of tasks, character count and time. Version control provides snapshots, side-by-side diffs and partial revert; a wiki view shows characters and settings as cards with custom groups and relations; export writes TXT or HWP with heading and footnote exclusion; and an in-vault music player is included.
