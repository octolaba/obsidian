# Lemons Search

Lemons Search is a fuzzy quick switcher that previews the file while results are browsed. Queries match file path, filename or aliases and accept search atoms for substring, prefix, postfix, exact and negated matching, with the matching itself performed by a Rust matcher running in a web worker.
