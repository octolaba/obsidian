# Copy Note Text

Copy Note Text adds a copy button to the note action bar, next to the reading view and more-options controls, which copies the note's entire Markdown content to the clipboard. The same action is available as a command that can be bound to a hotkey, and it works on desktop and mobile.

```cue
plugin: {
    id:     "copy-note-text"
    name:   "Copy Note Text"
    author: "Central Brain Trust"
    repo:   "ruisloan/obsidian-copy-note-text"

    html_url:    "https://community.obsidian.md/plugins/copy-note-text"
    github_url:  "https://github.com/ruisloan/obsidian-copy-note-text"
    description: "Adds a copy icon to the note's action bar that instantly copies the note's entire text to the clipboard. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Copy Note Text adds a copy button to the note action bar (top-right, next to the reading view and the more-options menu). Clicking it instantly copies the note's entire Markdown content to your clipboard. A command is also available, so you can assign it a hotkey. Works on desktop and mobile."
```
