# Read Only View

Keeps selected Markdown notes in Reading view by forcing matching files to stay in preview mode. Which files are affected is decided by include and exclude path rules, matched locally. It runs on desktop and mobile and, per the recorded text, makes no network requests.

```cue
plugin: {
    id:     "read-only-view"
    name:   "Read Only View"
    author: "mrkazzila"
    repo:   "mrkazzila/Read-Only-View"

    html_url:    "https://community.obsidian.md/plugins/read-only-view"
    github_url:  "https://github.com/mrkazzila/Read-Only-View"
```
