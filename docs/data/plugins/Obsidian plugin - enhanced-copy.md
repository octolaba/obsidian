# Enhanced Copy

Overrides the native copy so a selection keeps its original Markdown when copied from reading view, and so wikilinks can be dropped when copying while editing. Separate modes exist for reading, editing and all views, with per-view commands and profiles, and custom copy behaviour can be defined for non-Markdown content and for mobile. Copying from a locked canvas is supported.

```cue
plugin: {
    id:     "enhanced-copy"
    name:   "Enhanced Copy"
    author: "Mara"
    repo:   "mara-li/obsidian-enhanced-copy"

    html_url:    "https://community.obsidian.md/plugins/enhanced-copy"
    github_url:  "https://github.com/mara-li/obsidian-enhanced-copy"
    description: "Copy your selection and add it some edit to paste in other markdown software. Allows to keep markdown in reading view, removing wikilinks in editing, copy from locked canvas, and more!"
    about:       "Copy selections in reading view while preserving original Markdown formatting. Override the native copy across views, define separate modes for reading/editing/all, add per-view commands and profiles, and create custom copy behavior for non-markdown and mobile use."

    }
```
