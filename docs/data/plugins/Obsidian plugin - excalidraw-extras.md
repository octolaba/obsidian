# Excalidraw Extras

A companion plugin that hosts the heavy libraries and high-privilege operations of Excalidraw, including MathJax and Mermaid rendering as well as file system, network and IPC capabilities. Keeping those dependencies and that privileged code out of the main Excalidraw plugin is meant to leave it lightweight, fast and compliant.
