# My Bible

Builds a customizable Markdown Bible inside the vault, with one note per chapter and verse text fetched on demand. Verses are read and populated as you go, several translations can be downloaded and switched between without breaking links, and any verse can be linked to and explored in the graph view.

```cue
plugin: {
    id:     "gslogimaker-my-bible"
    name:   "My Bible"
    author: "gslogimaker"
    repo:   "gslogimaker/my-bible-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/gslogimaker-my-bible"
    github_url:  "https://github.com/gslogimaker/my-bible-obsidian-plugin"
    description: "Your own customizable markdown bible for your personal vault!"
    about:       "Create a customizable Markdown Bible inside your vault with one note per chapter and on-demand verse text. Read and populate verses as you go, access or download multiple translations and switch between them without breaking links, while linking to any verse and exploring connections in the Graph View."

    stats: {
        downloads:  9983
        updated_at: 1774798093000
    }
}
```
