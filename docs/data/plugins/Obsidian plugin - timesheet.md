# Timesheet

Timesheet generates a timesheet from tasks in daily notes, grouping the time by issue identifiers in the JIRA-style ABC-123 form. Inserting a timesheet code block produces grouped and rounded totals together with the task descriptions, for reporting or logging.

```cue
plugin: {
    id:     "timesheet"
    name:   "Timesheet"
    author: "vkostyanetsky"
    repo:   "vkostyanetsky/ObsidianTimesheet"

    html_url:    "https://community.obsidian.md/plugins/timesheet"
    github_url:  "https://github.com/vkostyanetsky/ObsidianTimesheet"
    description: "Timesheet generator for tasks in daily notes."
    about:       "Generate timesheets from tasks in daily notes and group time by issue identifiers (e.g., JIRA-style ABC-123). Insert a timesheet code block to produce grouped, rounded totals and list task descriptions for quick reporting or logging."
```
