# Vestaboardian

Vestaboardian composes a message in a note and sends it to a Vestaboard display through the Cloud or Local API, targeting Flagship 6x22 or Note 3x15 devices. Tile output is previewed, and unsupported characters or over-wide rows are validated and auto-fixed. Every send is logged in a Vestaboard History table.
