# Smart Gantt

Smart Gantt renders tasks collected across the vault as an interactive Gantt chart. It parses plain-language dates, Tasks-style emoji dates and Dataview due fields without extra syntax, and dragging or resizing a bar writes the new dates back into the note. The chart zooms by day, week, month or quarter and jumps to the task it was built from.
