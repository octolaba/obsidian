# Simplicial Complex

Simplicial Complex represents clusters of notes as simplices — triangles, tetrahedra and beyond — so that sets of notes form coherent units rather than only pairwise links. The view switches between an organic blob rendering and a formal geometric one, with live layout and inference suggestions. Topological metrics such as Betti numbers are reported for the resulting structure.
