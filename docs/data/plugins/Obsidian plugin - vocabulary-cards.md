# Vocabulary Cards

Vocabulary Cards displays vocabulary from simple YAML-compatible blocks as flashcards or as a list table. A voca-card block previews one random word at a time, while a voca-table block shows every entry. Correct-answer statistics are tracked locally in a data.json file.

```cue
plugin: {
    id:     "vocabulary-cards"
    name:   "Vocabulary Cards"
    author: "meniam"
    repo:   "meniam/obsidian-vocabulary-cards"

    html_url:    "https://community.obsidian.md/plugins/vocabulary-cards"
    github_url:  "https://github.com/meniam/obsidian-vocabulary-cards"
    description: "An easy way to display vocabulary words as flashcards and as a list."
    about:       "Study vocabulary with flashcard-style cards or list tables directly in notes using simple YAML-compatible blocks. Preview one random word at a time with voca-card or view all entries in a voca-table. Track correct-answer statistics locally in a data.json file."

    stats: {
        downloads:  6937
        updated_at: 1696021999000
    }
}
```
