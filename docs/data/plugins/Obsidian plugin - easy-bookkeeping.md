# Easy Bookkeeping

Records income and expenses locally through minimalist entry modes built for desktop and mobile. Finances can be analyzed with trend, calendar and pie charts, budgets, multidimensional tables and flexible filters, and data moves in and out through CSV transfer. All records are kept as local Markdown files in the vault, and the interface is available in 12 languages.
