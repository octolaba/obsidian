# Vimium+

Vimium+ adds a Vimium-FF-style keyboard layer over Obsidian. In Reading mode j and k scroll, d and u move by larger steps, J and K switch tabs, and f shows click-hints for opening elements. Pressing i drops into the editor's native Vim keybindings, and Esc returns to Reading mode.

```cue
plugin: {
    id:     "vimium-plus"
    name:   "Vimium+"
    author: "Stian Lyng"
    repo:   "stianlyng/obsidian-vimium-plus"

    html_url:    "https://community.obsidian.md/plugins/vimium-plus"
    github_url:  "https://github.com/stianlyng/obsidian-vimium-plus"
    description: "Navigate with Vimium-style keys: f for click hints, j/k/d/u scrolling, J/K tab switching, and i to drop into the editor's native Vim mode. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Navigate Obsidian with a Vimium-FF–style keyboard layer. Use Reading mode to scroll with j/k and open elements via f click-hints, then press i to edit with Obsidian's Vim keybindings and press Esc to return to Reading mode."
```
