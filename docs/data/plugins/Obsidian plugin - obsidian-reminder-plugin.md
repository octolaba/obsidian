# Reminder

This plugin manages Markdown TODO items with reminders, scheduled by writing a date, and optionally a time, after an at-sign on the item. A cross-file reminder list shows what is due and opens the source note, and Obsidian notifications offer marking the item done or snoozing it. The date formats of the Obsidian Tasks and Kanban plugins are also supported.

```cue
plugin: {
    id:     "obsidian-reminder-plugin"
    name:   "Reminder"
    author: "uphy"
    repo:   "uphy/obsidian-reminder"

    html_url:    "https://community.obsidian.md/plugins/obsidian-reminder-plugin"
    github_url:  "https://github.com/uphy/obsidian-reminder"
    description: "Manage Markdown TODOs with reminder."
    about:       "Set reminders on Markdown TODO items using @YYYY-MM-DD or @YYYY-MM-DD HH:MM to schedule alerts. View a cross-file reminder list, open source notes from items, and receive Obsidian notifications with options to mark done or snooze. Support Obsidian Tasks and Kanban date formats."

    stats: {
        downloads:  315441
        updated_at: 1786374479000
    }
}
```
