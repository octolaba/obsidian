# ProjectVerse

Creates virtual project spaces that link files and folders across the vault and auto-generates customizable dashboards showing project statistics. Projects are browsed in a dedicated sidebar explorer, Markdown tasks are scanned and toggled from the dashboards, memos are stored, and open tabs are restored when switching spaces.
