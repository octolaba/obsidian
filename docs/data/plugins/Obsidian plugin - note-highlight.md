# Note Highlight

Note Highlight renders square-bracket planning tags such as [fact], [trap] and [next] as readable badges in Reading View and Live Preview while the Markdown source stays unchanged. Tagged headings, list items, paragraphs and editor lines gain a subtle left accent, and Obsidian callouts such as [!note] are ignored.

```cue
plugin: {
    id:     "note-highlight"
    name:   "Note Highlight"
    author: "wsqstar"
    repo:   "wsqstar/obsidian-note-highlight"

    html_url:    "https://community.obsidian.md/plugins/note-highlight"
    github_url:  "https://github.com/wsqstar/obsidian-note-highlight"
    description: "Render square-bracket planning tags such as [fact], [trap], and [next] as readable badges. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render square-bracket planning tags (e.g., [now], [plan], [suggestion]) as readable badges in Reading View and Live Preview while keeping the original Markdown unchanged. Add a subtle left accent to tagged headings, list items, paragraphs, and editor lines, and ignore Obsidian callouts like [!note]."

    }
```
