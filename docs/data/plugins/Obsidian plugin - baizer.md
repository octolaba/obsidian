# Baizer

Captures web pages and video transcripts, converts them into Markdown with metadata, and compiles the result into a searchable knowledge base with facts kept as durable memory. An agent-driven loop processes, summarizes and recalls that material. Writing support arrives as chat over the vault, actions on a selection, and an inline co-writer that supplies AI completions.
