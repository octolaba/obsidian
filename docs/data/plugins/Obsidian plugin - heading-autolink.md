# Heading Autolink

Heading Autolink inserts heading links through a picker that opens when # is typed after a file link, offering a single heading or a heading together with its descendant sections. Missing heading aliases can be added, and matching heading links across the vault are updated when a heading is renamed. Text and list formatting is preserved, and code blocks, YAML frontmatter and HTML comments are ignored.

```cue
plugin: {
    id:     "heading-autolink"
    name:   "Heading Autolink"
    author: "jaewone"
    repo:   "jaewone/heading-autolink"

    html_url:    "https://community.obsidian.md/plugins/heading-autolink"
    github_url:  "https://github.com/jaewone/heading-autolink"
    description: "Link to headings, update aliases, and insert content from linked sections. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert heading wikilinks with a picker by typing # after a file wikilink and choose single headings or insert a heading plus its descendant sections. Add missing heading aliases and update matching heading links across the vault when headings are renamed. Preserve text and list formatting and ignore code blocks, YAML frontmatter, and HTML comments."

    stats: {
        downloads:  270
        updated_at: 1783503630000
    }
}
```
