# Canvas Card Background Remover

Canvas Card Background Remover makes card backgrounds transparent in canvas files for particular embed types, such as PNG images, canvas embeds and Markdown. Which embed types are rendered transparently is chosen in the plugin settings.

```cue
plugin: {
    id:     "canvas-card-bg-remover"
    name:   "Canvas Card Background Remover"
    author: "luxmargos"
    repo:   "luxmargos/obsidian-canvas-card-bg-remover"

    html_url:    "https://community.obsidian.md/plugins/canvas-card-bg-remover"
    github_url:  "https://github.com/luxmargos/obsidian-canvas-card-bg-remover"
    description: "Make the background of cards transparent in canvas files."
    about:       "Remove card backgrounds in Canvas for specific embed types such as PNG images, Canvas embeds, and Markdown to create transparent cards. Customize which embed types use transparency from the plugin settings."
```
