# Photo-tagging

Photo-tagging tags people in photos and links each tag to the note that represents that person, connecting images to people in the vault. A tagged-photos code block displays a person's photos inside their own note. The recorded inputs state that all tags are saved to a JSON file in the vault.

```cue
plugin: {
    id:     "photo-tagging"
    name:   "Photo-tagging"
    author: "Pavlo Myroniuk"
    repo:   "thebesttvarynka/photo-tagging"

    html_url:    "https://community.obsidian.md/plugins/photo-tagging"
    github_url:  "https://github.com/thebesttvarynka/photo-tagging"
    description: "Plugin for tagging people on photos and rendering interactive galleries. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Tag people in photos and link each tag to a note representing that person, letting you connect images to people in your vault. Display a person's photos inside their note with a simple tagged-photos code block; all tags are saved to a JSON file in the vault."

    stats: {
        downloads:  35
        updated_at: 1784384078000
    }
}
```
