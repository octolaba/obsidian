# Evernote Decryptor

Decrypts Evernote-encrypted data that was imported into the vault as text once the password is entered, either showing the plaintext inline or replacing the selection. Encrypted blocks are formatted as Evernote secret inline buttons so they decrypt on click in preview, and selected text is encrypted back into the Evernote secret format.
