# Math Plotter

Math Plotter inserts math graphs through a form-based GUI instead of hand-written plot code, covering interactive 2D and 3D function, parametric, PDE and ODE solution and data plots, and a quick inline graph block. A built-in JavaScript sampler renders transparent SVG previews immediately, and higher-quality TikZJax or LuaLaTeX output can be exported on demand. Labeled points, meshes and annotations are supported.

    id:     "math-plotter"
    name:   "Math Plotter"
    author: "Sharbel Marshi"
    repo:   "sharbelmarshi/obsidian-math-plotter"
