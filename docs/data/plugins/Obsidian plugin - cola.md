# Cola

Cola chats with the Cola AI in the Obsidian sidebar while automatically reading the open file for context. Selected text can be sent as a quoted reference, replies are inserted into the editor with one click, and chat history persists over a local-only connection.

```cue
plugin: {
    id:     "cola"
    name:   "Cola"
    author: "Heran"
    repo:   "heran11011/cola-obsidian"

    html_url:    "https://community.obsidian.md/plugins/cola"
    github_url:  "https://github.com/heran11011/cola-obsidian"
    description: "Chat with Cola AI directly in your notes with full file context awareness. - This plugin has not been manually reviewed by Obsidian staff."
```
