# Dictionary

Dictionary is a multilingual dictionary that shows word definitions in the sidebar and synonyms in a popover for inline lookups. Many languages are covered and experimental offline dictionaries exist for English and Chinese, and the lookup APIs that may be used are selectable to keep lookups private.
