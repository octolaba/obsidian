# ImgBB Uploader

Uploads images pasted or dragged into Obsidian to an ImgBB account so that they are not stored in the vault. The ImgBB API key is stored encrypted, automatic upload on paste and drag-drop can be enabled, and hosted images can be given a deletion time.

```cue
plugin: {
    id:     "imgbb-uploader"
    name:   "ImgBB Uploader"
    author: "jordanhandy"
    repo:   "jordanhandy/obsidian-imgbb-uploader"

    html_url:    "https://community.obsidian.md/plugins/imgbb-uploader"
    github_url:  "https://github.com/jordanhandy/obsidian-imgbb-uploader"
    description: "Upload images from your clipboard to ImgBB."
    about:       "Upload images pasted or dragged into Obsidian directly to your ImgBB account to keep them out of your vault. Store your ImgBB API key encrypted and enable auto-upload on paste/drag-drop with optional timed deletion of hosted images."

    stats: {
        downloads:  470
        updated_at: 1725802262000
    }
}
```
