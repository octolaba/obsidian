# Nudge

Manages tasks in a single plain-text todo.txt file, with lists, due dates, priorities and recurrence, plus a Today view that surfaces items when they come due. Tasks are created and edited in a modal covering text, list, due date, priority, link and recurrence, dragged between lists, and advanced automatically when recurring, and edits made to the file outside Obsidian are reflected immediately. The recorded description states that the Today view is macOS only.
