# Bible Journal

Bible Journal provides a Scripture journaling interface around an offline World English Bible reader with a chapter picker, previous and next navigation, and verse selection. Study notes are organized in a sidebar by book, chapter or section, notes are created in one tap with tags attached, and AND/OR tag searches can be saved as snapshots.

    id:     "bible-journal"
    name:   "Bible Journal"
    author: "Skyler Norgaard"
