# Repertoire

Repertoire is described as helping musicians manage their music with chord sheets and automatic transposing. Chord charts are written in scale-degree notation such as 1, 2 or 5/7 and rendered as chords in any key, including altered chords, slash chords and optional or passing chords in parentheses. Key and capo are set in frontmatter, which transposes the displayed chords.

plugin: {
    id:     "repertoire"
    name:   "Repertoire"
    author: "samuelbeard"
    repo:   "samuelbeard/obsidian-repertoire-plugin"

    html_url:    "https://community.obsidian.md/plugins/repertoire"
