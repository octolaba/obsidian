# Key Sequence Shortcut

Binds short key sequences to any Obsidian command and executes them as they are typed, without pressing Enter. Sequences such as one for Toggle Preview and another for Toggle Sidebar are meant to be easier to remember than modifier chords. Mappings are managed in a workspace config file and reloaded to apply new or updated shortcuts.

```cue
plugin: {
    id:     "obsidian-key-sequence-shortcut"
    name:   "Key Sequence Shortcut"
    author: "anselmwang"
    repo:   "anselmwang/obsidian-key-sequence-shortcut"

    html_url:    "https://community.obsidian.md/plugins/obsidian-key-sequence-shortcut"
    github_url:  "https://github.com/anselmwang/obsidian-key-sequence-shortcut"
    description: "Execute commands with short key sequences. For example, 'tp' for 'Toggle Preview' and 'tb' for 'Toggle Sidebar'. Easier to remember."
    about:       "Bind memorable key sequences (like \"tl\" or \"xl\") to any Obsidian command and execute them immediately as you type, without pressing Enter. Manage mappings in a workspace config file and reload changes to apply new or updated shortcuts."

    stats: {
        downloads:  5140
        updated_at: 1647311834000
    }
}
```
