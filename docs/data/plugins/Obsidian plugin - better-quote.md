# Better Quote

Better Quote mirrors a line or block from one note into another using Obsidian's native block embeds, so a single source stays editable. Block identifiers are assigned automatically, blocks are searched vault-wide with fuzzy relevance, and the embed is inserted or appended into the target file.

```cue
plugin: {
    id:     "better-quote"
    name:   "Better Quote"
    author: "junjieim"
    repo:   "junjieim/better-quote"

    html_url:    "https://community.obsidian.md/plugins/better-quote"
    github_url:  "https://github.com/junjieim/better-quote"
    description: "Mirror blocks between notes with mirror-to and mirror-from commands. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Mirror any line or block across notes using native Obsidian block embeds to keep one editable source of truth. Assign block IDs automatically, search blocks vault-wide with fuzzy relevance, and insert or append embeds into target files for consistent, synced reuse."

}
```
