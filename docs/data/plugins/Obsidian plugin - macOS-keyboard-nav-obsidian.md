# macOS Keyboard Navigation

The plugin restores macOS keyboard navigation inside Obsidian. It re-enables alt with the up and down arrows, and the same combinations with shift, so cursor movement and selection behave as they do elsewhere on the platform.

```cue
plugin: {
    id:     "macOS-keyboard-nav-obsidian"
    name:   "macOS Keyboard Navigation"
    author: "ryanjamurphy"
    repo:   "ryanjamurphy/macOS-keyboard-nav-obsidian"

    html_url:    "https://community.obsidian.md/plugins/macOS-keyboard-nav-obsidian"
    github_url:  "https://github.com/ryanjamurphy/macOS-keyboard-nav-obsidian"
    description: "Enable alt+↑ and alt+↓ keyboard navigation."
    about:       "Restore macOS keyboard navigation by re-enabling alt+↑ / alt+↓ and alt+shift+↑ / alt+shift+↓ in Obsidian. Preserve familiar macOS cursor and selection movement for smoother text editing across notes."

    stats: {
        downloads:  8030
        updated_at: 1605840001000
    }
}
```
