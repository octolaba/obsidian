# TagFolder

Tags are shown as a collapsible folder tree generated from tag combinations, respecting nested tags and grouping notes by the tags they share. Tag expressions drive the search, and tags can be pinned or redirected to reshape the tree.

```cue
plugin: {
    id:     "obsidian-tagfolder"
    name:   "TagFolder"
    author: "vrtmrz"
    repo:   "vrtmrz/obsidian-tagfolder"

    html_url:    "https://community.obsidian.md/plugins/obsidian-tagfolder"
    github_url:  "https://github.com/vrtmrz/obsidian-tagfolder"
    description: "Show tags as folder."
    about:       "Display tags as a collapsible folder tree generated from tag combinations, respecting nested tags and grouping notes by shared tags. Search with tag expressions and pin or redirect tags to customize the tree for faster navigation."
```
