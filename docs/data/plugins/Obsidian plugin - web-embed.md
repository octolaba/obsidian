# Web Embed

Embeds a website as a live, interactive browser view inside a note when its URL is placed on its own line in a fenced code block tagged browser. The embedded page can be scrolled and clicked at a configurable height, and the feature is desktop only. Sites that send X-Frame-Options or Content-Security-Policy headers may refuse to be embedded.

```cue
plugin: {
    id:     "web-embed"
    name:   "Web Embed"
    author: "notenerd"
    repo:   "notenerdofficial/web-embed"

    html_url:    "https://community.obsidian.md/plugins/web-embed"
    github_url:  "https://github.com/notenerdofficial/web-embed"
    description: "Embed any website as an interactive browser view inside a note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed any website as a live, interactive browser view inside a note by placing its URL on its own line in a fenced code block tagged browser. Scroll, click, and interact at a configurable height (desktop only); note that some sites may block embedding via X-Frame-Options or Content-Security-Policy."

    stats: {
        downloads:  70
        updated_at: 1783749446000
    }
}
```
