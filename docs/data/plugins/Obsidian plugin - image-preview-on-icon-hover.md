# Image Preview on Icon Hover

Adds image popups to Obsidian interface icons on hover, covering the vault switcher, the help and settings icons, sidebar toggles, ribbon icons and status bar icons. Custom images are assigned and managed per icon, and ribbon or status icons can be added and removed.
