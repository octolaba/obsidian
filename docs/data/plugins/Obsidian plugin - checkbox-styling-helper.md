# Icon Bullet Helper

Icon Bullet Helper converts plain Markdown markers, written as a short word in braces, into theme-independent SVG icon bullets in Live Preview and Reading view, leaving the underlying notes as portable Markdown. It adds an icon picker, callout-style bullets and customizable labels, colors, SVG markup and layout options. The recorded description states that it works locally, with no telemetry and no external data transfer.
