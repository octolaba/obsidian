# Mermaid Fixer

Repairs Mermaid diagram and Markdown table syntax in the active note or across the whole vault, so preview, export and publishing do not fail on them. Files are scanned, the resulting diffs are previewed, and fixes are applied conservatively. The recorded text states that the plugin works locally and makes no network requests.
