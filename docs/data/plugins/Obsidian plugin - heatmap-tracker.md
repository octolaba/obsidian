# Heatmap Tracker

Heatmap Tracker builds interactive yearly heatmaps from numeric or boolean frontmatter values across daily notes. Dataview can pull and aggregate several properties at once, the display is customizable, and a heatmap is inserted through an interactive modal. The recorded uses are habit tracking, project progress and trend analysis.
