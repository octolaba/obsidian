# KarMind

Compiles raw notes into a persistent, interlinked wiki using an LLM. Questions can be asked against the relevant wiki context, and useful answers and analysis backfilled into the pages. Health checks report broken links, orphan pages and missing concepts, and long-running task progress is tracked in the chat.
