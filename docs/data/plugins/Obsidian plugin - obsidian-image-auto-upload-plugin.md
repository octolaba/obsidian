# Image auto upload

Uploads pasted or dragged images to remote image beds through PicGo, PicList or PicGo-Core, handling PNG, JPG, GIF, SVG, WebP, TIFF, BMP and AVIF. Commands bulk-upload local images or download online images into local files, and uploading is also available from the edit-mode context menu or in server mode.
