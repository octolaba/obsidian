# Prompt Flow

Generates content with local LLMs such as Ollama or with any OpenAI-compatible API, using named connections, model selection, and per-note prompt overrides. Generated text is inserted at the cursor on desktop and mobile, prompts may include wikilinks whose targets are expanded, and content filters are applied from the built-in set or added through a filter API.
