# VaultDex

Searches the vault full-text with relevance scoring, indexing on load and opening as a workspace tab in a retro style. Ranked results carry highlighted snippets and clickable tags, and can be filtered by PARA category or folder and sorted by relevance or date. Phrase and AND operators are supported, and a lucky option opens a random note.
