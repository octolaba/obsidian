# HR Timestamp

HR Timestamp turns a line of four or more hyphens into a single-line divider carrying a local timestamp in YYYY-MM-DD HH:mm form. The timestamp is rendered centered in Reading view and Live Preview while the source stays one editable plain line, and the original source reappears while the Live Preview cursor sits on that line. Standard three-hyphen rules and fenced code blocks are left alone.

```cue
plugin: {
    id:     "hr-timestamp"
    name:   "HR Timestamp"
    author: "JhihJian"
    repo:   "jhihjian/obsidian-hr-timestamp-plugin"

    html_url:    "https://community.obsidian.md/plugins/hr-timestamp"
    github_url:  "https://github.com/jhihjian/obsidian-hr-timestamp-plugin"
    description: "Converts long dashed divider input into timestamped dividers in Reading view and Live Preview. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert lines of four or more hyphens into a single-line timestamped divider in YYYY-MM-DD HH:mm local time. Render the timestamp centered in Reading view and Live Preview while keeping the Markdown source editable as one plain line. Ignore standard --- rules and fenced code blocks, and show the original source while the Live Preview cursor is on the line for predictable editing."
```
