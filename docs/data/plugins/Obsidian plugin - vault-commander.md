# Vault Commander

Presents the vault as a blue, dual-panel orthodox file manager modelled on classic DOS file commanders. Notes and attachments are browsed, copied, moved, renamed, previewed and bookmarked across two panels under full keyboard control, with panel sorting and view options and prompts before an overwrite. The recorded About states that it runs entirely inside the vault, on desktop and mobile.
