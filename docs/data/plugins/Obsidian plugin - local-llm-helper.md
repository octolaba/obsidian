# Local LLM Helper

Uses a local LLM server to process text, chat and run semantic searches over notes, which the recorded inputs describe as keeping data private and local. The vault can be indexed for retrieval, text commands such as summarize or extract actions are available, and the plugin switches between OpenAI-compatible local providers.
