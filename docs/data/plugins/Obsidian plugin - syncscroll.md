# SyncScroll

Synchronizes scrolling between two files opened side by side, aligning the panes by percentage. Triple-clicking a line jumps the other pane to the same line and keeps the resulting offset while scrolling. The recorded inputs describe the synchronization as bidirectional and name comparing documents and reading translations as the intended uses.
