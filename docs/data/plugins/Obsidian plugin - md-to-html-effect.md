# MD to HTML Effectiveness

Converts an Obsidian note into a standalone single-file HTML document that follows the html-effectiveness standard and opens in any browser from the local filesystem. The output is written beside the source note under the same name, with inline CSS, responsive dark or light styling, and headings, tables, code blocks, lists, links and images preserved. Whole folders are converted in a batch, and the recorded description names compare, timeline, SVG diagram, report and slide output with zoom controls.

    name:   "MD to HTML Effectiveness"
