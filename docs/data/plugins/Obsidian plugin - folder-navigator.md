# Folder Navigator

Navigates to folders in the vault by fuzzy search and expands the chosen folder in the file explorer. Results are ordered alphabetically, by recently visited or by frequently visited. The navigation history can be reset.

```cue
plugin: {
    id:     "folder-navigator"
    name:   "Folder Navigator"
    author: "wenlzhang"
    repo:   "wenlzhang/obsidian-folder-navigator"

    html_url:    "https://community.obsidian.md/plugins/folder-navigator"
    github_url:  "https://github.com/wenlzhang/obsidian-folder-navigator"
    description: "Quickly navigate to folders in your vault using fuzzy search."
    about:       "Navigate vault folders instantly using fuzzy search and expand the target folder in the file explorer on selection. Prioritize results by alphabetical, recently visited, or frequently visited order, and reset navigation history when needed."
```
