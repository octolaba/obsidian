# Task Director

Task Director acts on all the tasks of one selected file: it switches every task from todo to done, or reverts every done task back to todo, in a single action. A page-level todo summary reports the totals. Completion dates are removed from tasks that are reverted.

```cue
plugin: {
    id:     "task-director"
    name:   "Task Director"
    author: "cybertramp"
    repo:   "cybertramp/obsidian-task-director"

    html_url:    "https://community.obsidian.md/plugins/task-director"
    github_url:  "https://github.com/cybertramp/obsidian-task-director"
    description: "Manage and change tasks targeting a specific page"
    about:       "Change all tasks in the selected file from todo to done or revert all done tasks back to todo in one action. Show a page-level todo summary with total counts. Remove completion dates from tasks when reverting them to todo."

    stats: {
        downloads:  399
        updated_at: 1731637511000
    }
}
```
