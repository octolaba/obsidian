# Select to Note

Select to Note clips selected browser content into the vault as Markdown, using a Chromium browser extension paired with a local companion plugin. The capture is appended to the end of the active note, or a target is chosen when no note is open.

```cue
plugin: {
    id:     "select-to-note"
    name:   "Select to Note"
    author: "TYzzt"
    repo:   "tyzzt/select2obsidian"

    html_url:    "https://community.obsidian.md/plugins/select-to-note"
    github_url:  "https://github.com/tyzzt/select2obsidian"
    description: "Clip selected browser content into your active note through a local companion extension. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Send selected web page content as Markdown into Obsidian using a Chromium browser extension paired with a local companion plugin. Append captures to the end of the active note or choose a target when no note is open."
```
