# Chartdown

Chartdown renders chartdown fenced blocks in place as SVG, so TTRPG maps are written as plain text in Markdown and drawn entirely on the local machine. Battlemaps, hex charts and region maps can be multi-level and carry lighting, sight, themes and tokens visible only to the GM. Maps export to SVG or to .dd2vtt for import into a virtual tabletop.
