# Previous Daily Note

Opens the daily note preceding today rather than the one preceding the daily note currently open. A ribbon icon and a command are added for quick, one-click access.

```cue
plugin: {
    id:     "previous-daily-note"
    name:   "Previous Daily Note"
    author: "talau"
    repo:   "talau/obsidian-previous-daily-note"

    html_url:    "https://community.obsidian.md/plugins/previous-daily-note"
    github_url:  "https://github.com/talau/obsidian-previous-daily-note"
    description: "Open yesterday's daily note."
    about:       "Open the previous daily note relative to today instead of the daily note currently open. Add a ribbon icon and a command for quick, one-click access."

    stats: {
        downloads:  409
        updated_at: 1741698907000
    }
}
```
