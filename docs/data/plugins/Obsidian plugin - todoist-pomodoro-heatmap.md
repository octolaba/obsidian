# Todoist Pomodoro Heatmap

Times work on Todoist tasks with a Pomodoro timer and logs the time spent, along with other productive time, on a GitHub-style contribution heatmap. The work-to-rest ratio is configurable, and the break can be doubled as a reward for getting up and working out.

```cue
plugin: {
    id:     "todoist-pomodoro-heatmap"
    name:   "Todoist Pomodoro Heatmap"
    author: "mimo"
    repo:   "keptan/obsidian-todoist-pomodoro"

    html_url:    "https://community.obsidian.md/plugins/todoist-pomodoro-heatmap"
    github_url:  "https://github.com/keptan/obsidian-todoist-pomodoro"
    description: "Track Todoist tasks with a Pomodoro timer and a pretty contribution heatmap. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Track time spent on Todoist tasks using a Pomodoro timer, or log other productive time you've spent on a Github style heat-map. Customize your work-rest ratio, and you can also reward yourself for getting up and working out by doubling your break."

    stats: {
        downloads:  25
        updated_at: 1786082714000
    }
}
```
