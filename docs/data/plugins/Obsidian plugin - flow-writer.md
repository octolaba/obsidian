# Flow Writer

A distraction-free writing mode that dims everything already written and keeps only the word being typed lit. While Flow Mode is active, finished words cannot be edited; editing becomes possible again on leaving the mode.

```cue
plugin: {
    id:     "flow-writer"
    name:   "Flow Writer"
    author: "David Cohen-Tanugi"
    repo:   "dctanugi/obsidian-flow-writer"

    html_url:    "https://community.obsidian.md/plugins/flow-writer"
    github_url:  "https://github.com/dctanugi/obsidian-flow-writer"
    description: "A distraction-free writing mode that promotes flow and focus. Everything already written dims away, only the word you are typing stays lit, and finished words cannot be edited. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "A distraction-free writing mode that promotes flow and focus. Everything already written dims away, only the word you are typing stays lit, and finished words cannot be edited (until you exit Flow Mode)."

    stats: {

}
```
