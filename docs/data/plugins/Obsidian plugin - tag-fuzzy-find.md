# Tag Fuzzy Find

Tag Fuzzy Find searches the tags of a vault with fuzzy matching, shows their usage counts, and jumps to a note that uses a tag without leaving the keyboard. Nested tags are honoured, so a parent tag also matches its children, and a matching note opens immediately or in a new pane. Tag search can also be triggered from the Quick Switcher with a prefix.

```cue
plugin: {
    id:     "tag-fuzzy-find"
    name:   "Tag Fuzzy Find"
    author: "etaiso"
    repo:   "etaiso/obsidian-tag-fuzzy-find"

    html_url:    "https://community.obsidian.md/plugins/tag-fuzzy-find"
    github_url:  "https://github.com/etaiso/obsidian-tag-fuzzy-find"
    description: "Quickly find a tag in your vault, then jump to a note that uses it. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Fuzzy-find tags across your vault, see usage counts, and jump straight to notes that use a tag without leaving the keyboard. Honor nested tags (e.g., #project finds #project/work) and open matching notes immediately or in a new pane; trigger tag search from the Quick Switcher with a prefix."

    stats: {
        downloads:  127
        updated_at: 1778666547000
    }
}
```
