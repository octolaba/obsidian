# Surfing

Web pages are opened inside Obsidian in an integrated web view, covering file, http and https links including local HTML. Selected text is searched from the editor or within a page, links to a highlight or to a video timestamp are copied, and history is kept. Pages are also opened in an external browser, and addresses are launched through bookmarklets.
