# Calendar

Calendar displays a monthly calendar in the sidebar for navigating and opening daily and weekly notes. New daily and weekly notes are created from the configured template, and each day can show up to five dots reflecting its word count.

```cue
plugin: {
    id:     "calendar"
    name:   "Calendar"
    author: "Liam Cain"
    repo:   "liamcain/obsidian-calendar-plugin"

    html_url:    "https://community.obsidian.md/plugins/calendar"
    github_url:  "https://github.com/liamcain/obsidian-calendar-plugin"
    description: "Explore your daily notes."
    about:       "Display a monthly calendar in the sidebar to navigate and open daily and weekly notes. Create new daily/weekly notes from your template and visualize writing with up to five dots that reflect each day's word count."

    stats: {
        downloads:  2992761

}
```
