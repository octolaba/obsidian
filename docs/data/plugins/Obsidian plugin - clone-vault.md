# Clone Vault

Creates a new vault from the current one by copying the settings folder, including a custom-named one, and reproducing the folder structure without the note contents. Contents of chosen folders such as templates, snippets or assets can be copied along, and the new vault is named through a prompt with a configurable default location.

    id:     "clone-vault"
    name:   "Clone Vault"
    author: "laantorchaweb"

    github_url:  "https://github.com/laantorchaweb/clone-vault"

    about:       "Create a new vault by cloning your current vault's settings folder (including custom-named settings) and reproduce the vault's folder structure.
