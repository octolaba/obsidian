# Hans Kanban

Renders notes as a columned Kanban board for Bases, where dragging a card updates the status stored on its note. Cards can be coloured by their leading emoji or automatically, arranged in swimlanes or a masonry layout, with adjustable column widths, hidden empty columns and a minimal mode. Card positions survive file renames, and the interface is available in English and Traditional Chinese.
