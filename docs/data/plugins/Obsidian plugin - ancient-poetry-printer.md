# Ancient Poetry Printer

Creates and edits classical Chinese poems and prose in a form-based .sc editor and renders them into typeset HTML. Per-character pinyin can be added, vertical or centered layouts chosen, the formatting previewed, and standalone HTML files exported.

```cue
plugin: {
    id:     "ancient-poetry-printer"
    name:   "Ancient Poetry Printer"
    author: "Calf"
    repo:   "fenmirs/ob-extends-gwsc"

    html_url:    "https://community.obsidian.md/plugins/ancient-poetry-printer"
    github_url:  "https://github.com/fenmirs/ob-extends-gwsc"
```
