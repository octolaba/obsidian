# Multi Properties

Adds, edits or removes frontmatter properties across many notes in one action. The target is the current note, a selection of files, a folder with optional recursion, search results, or the open tabs. Values are either overwritten or appended, and selected properties can be removed.

```cue
plugin: {
    id:     "multi-properties"
    name:   "Multi Properties"
    author: "technohiker"
    repo:   "technohiker/obsidian-multi-properties"

    html_url:    "https://community.obsidian.md/plugins/multi-properties"
    github_url:  "https://github.com/technohiker/obsidian-multi-properties"
    description: "Add properties to multiple notes at once. Either right-click a folder or select multiple notes and right-click the selection."
    about:       "Edit, add, or remove frontmatter properties across multiple notes at once. Apply changes to the current note, selected files, folders (optionally recursive), search results, or open tabs; choose to overwrite or append values and remove selected properties."

    stats: {
        downloads:  107581

    }
}
```
