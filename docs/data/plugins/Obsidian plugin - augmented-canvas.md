# Augmented Canvas

Adds AI actions to Canvas that query a note's content and generate linked response notes, follow-up questions or images from the note's context. Flashcards can be created for spaced repetition, system prompts run across a folder, and curated or custom system prompts inserted into the canvas. An OpenAI API key and GPT-4 are required.
