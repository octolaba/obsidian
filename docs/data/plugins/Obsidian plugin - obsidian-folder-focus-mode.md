# Folder Focus Mode

Restricts the file explorer to a chosen folder with its files and subdirectories, hiding all other files and directories. Focus is toggled from the folder context menu, an optional explorer icon, or a global command, and folder notes can focus the folder they link to.

```cue
plugin: {
    id:     "obsidian-folder-focus-mode"
    name:   "Folder Focus Mode"
    author: "grochowski"
    repo:   "grochowski/obsidian-folder-focus-mode"

    html_url:    "https://community.obsidian.md/plugins/obsidian-folder-focus-mode"
    github_url:  "https://github.com/grochowski/obsidian-folder-focus-mode"
    description: "Focus the file explorer on chosen folder and its files and subdirectories, while hiding all the other elements."
    about:       "Focus the file explorer on a selected folder and its files and subdirectories, hiding all other files and directories. Toggle focus via the folder context menu, an optional explorer icon, or a global command, and enable focusing on linked folders from folder notes."

    stats: {

    }
}
```
