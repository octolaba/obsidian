# Daily Activity

Inserts into the active file a list of the files created or modified in a date range, as links or as plain text, with ranges given in natural language. It also generates stats tables, recent activity logs, daily summaries and weekly overviews recording edits, event types and content changes.

```cue
plugin: {
    id:     "daily-activity"
    name:   "Daily Activity"
    author: "trydalch"
    repo:   "trydalch/obsidian-daily-activity"

    html_url:    "https://community.obsidian.md/plugins/daily-activity"
    github_url:  "https://github.com/trydalch/obsidian-daily-activity"
    description: "Output a list of the files changed/created today in the active file."
    about:       "Track daily file activity and insert linked or plain-text lists of files created or modified between dates using natural-language date ranges. Generate stats tables, recent activity logs, daily summaries and weekly overviews to record edits, event types, and content changes alongside your daily notes."

    stats: {
        downloads:  17370
        updated_at: 1744419754000
    }
}
```
