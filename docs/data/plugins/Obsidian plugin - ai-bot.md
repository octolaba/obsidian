# AI bot

AI bot runs an AI assistant inside Obsidian that polishes, summarizes, translates and analyzes text and interprets code, generating and organizing notes from context-aware suggestions. It connects to OpenAI or custom AI services and is driven from a modal interface, keeping responses tied to the note context.
