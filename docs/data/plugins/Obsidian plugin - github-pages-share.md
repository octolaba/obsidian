# GitHub Pages share

Publishes Markdown notes to a GitHub repository served through GitHub Pages and copies a shareable link to the clipboard. Wiki links become relative links, embedded images are uploaded to an assets folder, callouts and mermaid are rendered through a CDN, and notes can be published in batches, republished automatically on save, or unpublished.

```cue
plugin: {
    id:     "github-pages-share"
    name:   "GitHub Pages share"
    author: "Mark Chang"
    repo:   "wzmf399443/github-pages-share"

    html_url:    "https://community.obsidian.md/plugins/github-pages-share"
    github_url:  "https://github.com/wzmf399443/github-pages-share"
    description: "Publish notes to a GitHub Pages site and copy shareable links. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Publish Markdown notes from Obsidian to a GitHub repository served via GitHub Pages and copy a shareable link to your clipboard. Convert wiki links to relative links, upload embedded images to an assets folder, render callouts and mermaid via CDN, support batch publishing, auto-republish on save, and unpublish files."

    stats: {
        downloads:  50

    }
}
```
