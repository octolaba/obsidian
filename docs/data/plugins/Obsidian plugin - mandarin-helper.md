# Mandarin Helper

Annotates Chinese text with pinyin above the Hanzi in both reading and editing view, and colorizes characters and pinyin by tone. A CEDICT-compatible dictionary popup opens from the keyboard or the sidebar, local dictionaries can be downloaded, and Hanzi, pinyin or translations are copied with one click.
