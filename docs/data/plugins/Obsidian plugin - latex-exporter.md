# Latex Exporter

Latex Exporter converts a note into a complete LaTeX paper, mapping Markdown headers onto sections and pulling in embedded content, figures, equations and LaTeX environments. Citations, cross-references, YAML title and author fields, abstracts and appendices are carried across, and output is produced through templates or by copying a selection to the clipboard.
