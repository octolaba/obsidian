# Property Explorer

Explores every property in the vault as an expandable tree in the right pane, descending from a property key to its unique values and then to the notes carrying each value. Keys, values, and titles are searched with scope filters, results sorted by name or frequency, and notes opened directly; the index is rebuilt live as notes change.
