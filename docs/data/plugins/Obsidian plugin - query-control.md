# Query Control

Adds a control bar to embedded queries in Live Preview and Reading modes, with actions to collapse, show context, sort, hide the title or the results, render Markdown and copy results. Default behavior is set in the settings and overridden per query through an extended query syntax. The recorded description calls the plugin experimental.
