# Cockpit Dashboard

Assembles a home dashboard for the vault that gathers a calendar, todos, priority tasks, global search, bookmarks, recent notes, category navigation, statistics, edit activity, quick capture and Pomodoro focus tracking in one place. Sections are reordered or hidden, toolbar buttons customized, and custom URLs or local commands added. The recorded inputs state that all plugin data stays local, transparent and editable, and can be backed up or migrated by the user.
