# Easy Codeblock

Inserts a code block after picking its language from a fuzzy-matching picker covering more than 200 languages, with the five most recently used pinned to the top. Selected text is wrapped automatically, favourite languages are marked visually, and hotkeys insert either a highlighted or a plain code block.

```cue
plugin: {
    id:     "easy-codeblock"
    name:   "Easy Codeblock"
    author: "matse2005"
    repo:   "matse2005/obsidian-easy-codeblock"

    html_url:    "https://community.obsidian.md/plugins/easy-codeblock"
    github_url:  "https://github.com/matse2005/obsidian-easy-codeblock"
    description: "Insert code blocks quick and easily. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert code blocks with an instant language picker that searches 200+ languages via fuzzy matching and pins your five most recent languages to the top. Wrap selected text automatically, mark favorites visually, and use hotkeys to insert highlighted or plain code blocks in seconds."
```
