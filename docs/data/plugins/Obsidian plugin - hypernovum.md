# Hypernovum

Renders the vault as a 3D city in which notes become buildings, color shows status, height indicates priority, and glowing arcs trace backlinks. Local AI coding agents can be launched with the full vault as context, research quests posted, and Git activity watched as it happens. It is desktop-only and runs locally, making no network calls.
