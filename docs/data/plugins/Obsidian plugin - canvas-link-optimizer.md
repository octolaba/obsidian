# Canvas Link Optimizer

Canvas Link Optimizer replaces the auto-loading of canvas link nodes with lightweight preview thumbnails, which the inputs say cuts CPU and RAM use, reduces visual flicker and limits exposure to unwanted web content. Clicking a thumbnail opens the full page, and previews are cached locally without modifying the vault.

    id:     "canvas-link-optimizer"
    name:   "Canvas Link Optimizer"
    author: "qbject"
