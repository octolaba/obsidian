# Places

Manages points of interest and geospatial files such as GPX, GeoJSON and CSV inside notes, and plots them on interactive maps with markers, tracks, overlays, heatmaps and custom styling. Geocoding, routing, isochrones, elevation, track snapping and matching, and environment data are built in for analyzing and annotating tracks and map overlays. Image alignment, VaultQuery data, charts, search, directions and provider extensions extend the map surface further.
