# Pin Tab Guard

Pin Tab Guard protects pinned tabs from accidental closing or unpinning by blocking the built-in close commands from acting on pinned notes, including the close shortcut, close all other tabs and close tab group. Tab behaviour elsewhere is left unchanged, and closing from the context menu still works.

```cue
plugin: {
    id:     "pin-tab-guard"
    name:   "Pin Tab Guard"
    author: "wildskyf"
    repo:   "wildskyf/obsidian-pin-tab-guard"

    html_url:    "https://community.obsidian.md/plugins/pin-tab-guard"
    github_url:  "https://github.com/wildskyf/obsidian-pin-tab-guard"
    description: "Prevents Cmd/Ctrl+W from unpinning pinned tabs. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Protect pinned tabs from accidental closing or unpinning by blocking built-in close commands (Cmd/Ctrl+W, Close all other tabs, Close tab group) from affecting pinned notes. Preserve normal tab behavior elsewhere and allow context-menu closes to still work."
```
