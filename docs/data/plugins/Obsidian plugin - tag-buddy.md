# Tag Buddy

Adds, edits and removes tags in reading mode, for the active note or across the vault. Tag summaries query tagged content, and tagged blocks are copied or moved to sections of another note in reading and edit mode. Tags are also renamed, converted or removed for a single instance, a note, or the whole vault.
