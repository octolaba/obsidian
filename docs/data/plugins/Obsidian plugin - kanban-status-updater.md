# Kanban Status Updater

Updates the frontmatter of a linked note to match the column name whenever its card is moved on a Kanban board. The target property name is configurable, visual feedback and debug information are available, and only the active board is monitored to keep updates quick.

```cue
plugin: {
    id:     "kanban-status-updater"
    name:   "Kanban Status Updater"
    author: "ankit-kapur"
    repo:   "ankit-kapur/obsidian-kanban-status-updater-plugin"

    html_url:    "https://community.obsidian.md/plugins/kanban-status-updater"
    github_url:  "https://github.com/ankit-kapur/obsidian-kanban-status-updater-plugin"
    description: "Automatically updates a 'status' property in a note when its card is moved on a Kanban board"
    about:       "Update linked note frontmatter to match the column name when moving cards on an Obsidian Kanban board. Customize the target property name, view visual feedback and debug info, and keep updates snappy by monitoring only the active board."

    stats: {
        downloads:  6181
        updated_at: 1743147374000
    }
}
```
