# Slash Cmd

Slash Cmd adds a Notion-style slash menu for inserting headings, tables, callouts, code blocks, lists, math blocks, links, dividers and today's date. Typing after the trigger filters the options, and pressing Enter inserts the chosen block with the cursor placed correctly.

```cue
plugin: {
    id:     "slash-cmd"
    name:   "Slash Cmd"
    author: "maniarasan.s"
    repo:   "maniarasan-zuper/slash-cmd"

    html_url:    "https://community.obsidian.md/plugins/slash-cmd"
    github_url:  "https://github.com/maniarasan-zuper/slash-cmd"
    description: "Type / for a quick menu to insert headings, tables, callouts, code blocks, lists and more. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert a Notion-style slash menu to quickly add blocks like headings, tables, callouts, code blocks, lists, math blocks, links, dividers, and today's date. Type '/' and keep typing to filter options, pick a block and press Enter to insert with the cursor placed correctly."

    stats: {
        downloads:  311
        updated_at: 1782821238000
    }
}
```
