# Digital Archive

Searches the Aladin open API for books and creates Markdown notes carrying cover images and frontmatter for title, author, publisher, pages, ISBN, category and status. The collection is browsed in a built-in cover-first gallery view rendered inside Obsidian.

```cue
plugin: {
    id:     "digital-archive"
    name:   "Digital Archive"
    author: "HyoYoonNam"
    repo:   "hyoyoonnam/digital-archive"

    html_url:    "https://community.obsidian.md/plugins/digital-archive"
    github_url:  "https://github.com/hyoyoonnam/digital-archive"
    description: "Search books through the Aladin open API, generate notes with cover images and metadata, and browse your library in a card gallery view. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Search the Aladin open API to fetch book metadata and cover images, then create richly populated Markdown notes with frontmatter (title, author, publisher, pages, ISBN, category, status). Browse your collection in a built-in cover-first gallery view rendered natively in Obsidian, turning your vault into a personal bookshelf."

    stats: {
        downloads:  41
        updated_at: 1784024372000
    }
}
```
