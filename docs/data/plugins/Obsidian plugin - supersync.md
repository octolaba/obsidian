# SuperSync

A vault is synced with a private GitHub repository through the GitHub API, without Git or command-line setup. Authentication runs through a GitHub device code, and syncing is automatic or manual on desktop and on mobile. Conflicting edits are preserved, file history is browsed, and files are excluded with simple glob rules.
