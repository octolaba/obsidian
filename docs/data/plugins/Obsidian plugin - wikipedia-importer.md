# Wikipedia Importer

Fetches a Wikipedia article and drops it into a new or existing note as clean Markdown, turning every Wikipedia link into an internal wikilink and optionally adding manual or automatically generated tags. Clutter such as edit markers, navboxes and citation scaffolding is removed. Equations are converted to Obsidian LaTeX, content images are embedded, and sources are preserved as plaintext in a references section.

```cue
plugin: {
    id:     "wikipedia-importer"
    name:   "Wikipedia Importer"
    author: "Concomitant"
    repo:   "aedraaelynn/Wikipedia-Importer"

    html_url:    "https://community.obsidian.md/plugins/wikipedia-importer"
    github_url:  "https://github.com/aedraaelynn/Wikipedia-Importer"
    description: "Fetches any Wikipedia article and drops it into a new or existing Note in your Vault. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Import Wikipedia pages as clean, fully-linked Obsidian notes, converting every Wikipedia link into an internal [[wikilink]], and/or you can utilize tags (manually and/or automatically generated). Remove clutter like edit markers, navboxes, and citation scaffolding. Convert equations to Obsidian LaTeX, embed content images, and preserve sources as plaintext in a References section."
```
