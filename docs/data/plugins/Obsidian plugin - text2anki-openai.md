# text2anki-openai

text2anki-openai generates flashcards from bullet points in notes using OpenAI and pushes them into a local Anki deck. The deck name, the prompt and the GPT model are all specified, which is what controls the cards that come out.

```cue
plugin: {
    id:     "text2anki-openai"
    name:   "text2anki-openai"
    author: "manibatra"
    repo:   "manibatra/obsidian-text2anki-openai"

    html_url:    "https://community.obsidian.md/plugins/text2anki-openai"
    github_url:  "https://github.com/manibatra/obsidian-text2anki-openai"
    description: "Use OpenAI to generate flashcards from text and add them to Anki."
    about:       "Generate flashcards from bullet points in your Obsidian notes using OpenAI and push them directly to a local Anki deck. Specify custom deck names and prompts and choose the GPT model to control card output."

    stats: {
        downloads:  4375

}
```
