# OmniFocus Task Sync

OmniFocus Task Sync sends uncompleted tasks from the active note to the OmniFocus inbox and marks them complete in the editor, each forwarded task carrying a link back to its source note. A single task, a selection or every task in the note can be sent, nested checkboxes become subtasks, and inline fields such as due, defer, flag, estimate and tags map onto OmniFocus fields.
