# Insert New Line

Insert New Line adds two commands that insert a blank line above or below the current line. They add spacing inside a note without otherwise altering the surrounding text layout.

```cue
plugin: {
    id:     "insert-new-line"
    name:   "Insert New Line"
    author: "freddyouellette"
    repo:   "freddyouellette/obsidian-insert-new-line-plugin"

    html_url:    "https://community.obsidian.md/plugins/insert-new-line"
```
