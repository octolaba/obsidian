# Markdown Minimap

Markdown Minimap adds a minimap panel to the editor that gives a scaled-down overview of the whole note and updates as it is edited. The viewport slider can be dragged to jump or scroll through the file, and the minimap can be toggled per note from the note header. It is aimed at navigating very long Markdown files and follows the active theme.

plugin: {
    id:     "markdown-minimap"
    name:   "Markdown Minimap"
    author: "Nymbo"
    repo:   "nymbo/Markdown-Minimap"

    github_url:  "https://github.com/nymbo/Markdown-Minimap"
    description: "Add a minimap to your Markdown notes. - This plugin has not been manually reviewed by Obsidian staff."

Drag the viewport slider to jump or scroll quickly, toggle the minimap per note from the header, and navigate very long Markdown files reliably with smooth, pane-aware behavior and theme support."
