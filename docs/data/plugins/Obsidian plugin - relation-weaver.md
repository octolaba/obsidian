# relation-weaver

Parses Markdown files to manage characters, factions, relationships and timelines for novels, worldbuilding, TRPGs and notes. Lifecycles, appearance heatmaps, intimacy-evolution curves and dashboards visualize the material, and timeline events are tracked with generated statistics. Data is imported and exported as JSON or CSV.
