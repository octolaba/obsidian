# Lockbox

Encrypts note contents at rest while the title stays visible, so files remain usable in the file explorer, the graph and links. Notes are locked with a vault-wide or a per-note password using authenticated AES-GCM encryption. They auto-lock on navigation and on quit, and the status bar shows how many are unlocked.
