# i18n+

Manages plugin translations from a single panel, with hot-reload of languages and overlays that let only unsatisfactory strings be corrected. Translation data can be imported and exported as JSON, and community translation packs synced. For plugin development it adds zero-runtime adapters, automated migration to t() calls and TypeScript-aware i18n.
