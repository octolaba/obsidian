# Auto Note Mover

Auto Note Mover moves the active note into a destination folder when its tags or title match a rule you set. Moves run on create, edit or rename or are triggered manually, and notes created from links or by other plugins are included. A missing destination or a name conflict aborts the move with a warning.

```cue
plugin: {
    id:     "auto-note-mover"
    name:   "Auto Note Mover"
    author: "farux"
    repo:   "farux/obsidian-auto-note-mover"

    html_url:    "https://community.obsidian.md/plugins/auto-note-mover"
    github_url:  "https://github.com/farux/obsidian-auto-note-mover"
    description: "Automatically move the active notes to their respective folders according to rules you set."
    about:       "Move active notes into destination folders based on matching tags or title rules. Apply moves automatically on create/edit/rename or run them manually; abort with a warning if the destination is missing or a name conflict exists. Include notes created from links or other plugins."

    stats: {
        downloads:  115221
        updated_at: 1650103882000
    }
}
```
