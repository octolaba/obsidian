# Santi Younger Tools

Santi Younger Tools is for existing Santi Younger buyers: signing in with a one-time email code opens the catalog linked to that account. From there the plugins and themes already purchased can be installed and updated. The catalog lists Santi Younger products only.

plugin: {
    id:     "santi-younger-tools"
    name:   "Santi Younger Tools"
    author: "Santi Younger"
    repo:   "santiyounger/obsidian-santi-younger-tools"

    html_url:    "https://community.obsidian.md/plugins/santi-younger-tools"
    github_url:  "https://github.com/santiyounger/obsidian-santi-younger-tools"
    description: "Install and update purchased Santi Younger plugins and themes after signing in with a one-time email code. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "For existing Santi Younger buyers only. Sign in with a one-time email code to access the catalog linked to your account. After signing in, you can install and update the Santi Younger plugins and themes you have already purchased. The catalog lists Santi Younger products only."

}
