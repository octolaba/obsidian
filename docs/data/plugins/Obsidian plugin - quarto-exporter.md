# Quarto Exporter

Exports notes to Quarto-compatible QMD files, converting Obsidian syntax into Quarto format on the way out. Creation or modification dates are added with a custom format, tags are included or excluded, and the output folder and overwrite behaviour are chosen per export.

```cue
plugin: {
    id:     "quarto-exporter"
    name:   "Quarto Exporter"
    author: "andreasthinks"
    repo:   "andreasthinks/obsidian-to-quarto-exporter"

    html_url:    "https://community.obsidian.md/plugins/quarto-exporter"
    github_url:  "https://github.com/andreasthinks/obsidian-to-quarto-exporter"
```
