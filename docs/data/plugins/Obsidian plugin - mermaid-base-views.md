# Mermaid Base Views

Creates Mermaid diagrams and charts inside bases, adding Flowchart, Mindmap, Timeline, Sankey, Pie, XY and Quadrant views over the notes a base collects. Note links, timelines, flows and charts are visualized this way, with grouping, sorting and filtering applied to the underlying data. Mermaid configuration is set globally, per view or locally.
