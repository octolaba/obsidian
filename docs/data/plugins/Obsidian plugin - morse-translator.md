# Morse Translator

Opens a draggable floating window for entering Morse code, translating it live and inserting the decoded text into the active note. Spaces separate letters and a slash separates words, and auto-insert can fire once typing stops. Case, dot and dash characters are configurable, and the window opens from the command palette or a hotkey.

```cue
plugin: {
    id:     "morse-translator"
    name:   "Morse Translator"
    author: "shangchengwen"
    repo:   "shangchengwen/obsidian-morse-translator"

    html_url:    "https://community.obsidian.md/plugins/morse-translator"
    github_url:  "https://github.com/shangchengwen/obsidian-morse-translator"
    description: "Enter Morse code in a floating window, translate it in real time, and insert it into the document. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Translate Morse from a draggable floating window with live preview and insert decoded text into the active note. Use spaces for letters and / for words, enable auto-insert after typing stops, pick case, customize dot/dash characters, and open via command palette or hotkeys."

    stats: {
        downloads:  66
        updated_at: 1780919590000
    }
}
```
