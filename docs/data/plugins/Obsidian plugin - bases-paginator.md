# Bases Paginator

Bases Paginator adds a paginated, sortable table view to Bases with configurable page sizes, real-time global search, multi-select column filters and natural sorting. Filter presets can be saved, list rendering styles chosen, and columns reordered by dragging for the session, while links and tags render natively; the view itself is read-only.
