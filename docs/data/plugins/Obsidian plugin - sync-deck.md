# Sync Deck

Syncs a vault across devices and with teammates using Google sign-in, with real-time updates and live presence. Several synced vaults can be managed, the synced scope chosen, and shared files recovered when leaving a vault. The recorded About text also states that Task Deck boards stay synchronized and show who is on each card.
