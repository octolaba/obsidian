# Inline AI

Inline AI writes model output into the note itself: typing /ai followed by a prompt and pressing Enter inserts the response at that point. It can generate text, brainstorm ideas, summarise, refactor or expand content, with OpenAI, Claude, Gemini or a local Ollama model as the provider.

```cue
plugin: {
    id:     "nitinvishway-inline-ai"
    name:   "Inline AI"
    author: "nitinvishway"
    repo:   "nitinvishway/Inline-AI"

    html_url:    "https://community.obsidian.md/plugins/nitinvishway-inline-ai"
    github_url:  "https://github.com/nitinvishway/Inline-AI"
    description: "Type /ai <prompt> in any note, press Enter, and your local Ollama model writes inline. Thus, Inline AI - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Inline AI responses directly into notes by typing /ai plus your prompt and pressing Enter. Generate text, brainstorm ideas, summarize, refactor, or expand content inline using OpenAI, Claude, Gemini, or local Ollama as the provider."

    stats: {

}
```
