# Running Head

Running Head places a blog-style metadata header under a note title, showing publication date, estimated reading time, a last-updated badge, breadcrumb, tabs and selected frontmatter fields. Blog and Wiki layouts are available, a scroll progress bar can be enabled, dates and colors are locale-aware, fields can be scoped by folder, and the settings can be exported and imported. The recorded description also names integration with Typify.
