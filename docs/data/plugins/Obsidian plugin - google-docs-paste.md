# Google Docs Paste

Handles pasting from Google Docs so formatting survives instead of collapsing to plain text. The Google Docs HTML is converted into semantic markup, restoring bold, italic, underline, strikethrough, subscript and superscript, detecting headings, flattening lists, fixing Google redirect links, converting tables to Markdown and keeping images as remote or downloaded attachments.
