# Wave Analyzer

Renders audio files as interactive waveforms and spectrograms inside notes through a wa code block. Playback, stopping and seeking use a draggable playhead, and loop regions can be marked out. Spectral centroid and harmonicity overlays can be toggled, and the analysis runs at one of six FFT resolutions.
