# Monthly Tracker

Monthly Tracker renders configurable monthly heatmap strips inside monthly notes from data in daily note frontmatter, for habits, moods, sleep, exercise and similar series. Frontmatter values or the mere existence of a file are mapped to coloured cells, and clicking a cell opens that day's note.

```cue
plugin: {
    id:     "monthly-tracker"
    name:   "Monthly Tracker"
    author: "shin-young-in"
    repo:   "younginshin115/obsidian-monthly-tracker"

    html_url:    "https://community.obsidian.md/plugins/monthly-tracker"
    github_url:  "https://github.com/younginshin115/obsidian-monthly-tracker"
    description: "Renders configurable monthly heatmap trackers from daily note frontmatter. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Visualize daily note data as color-coded monthly tracker strips directly inside monthly notes for habits, moods, sleep, exercise and more. Map frontmatter values or file existence to colored cells and click any cell to open that day's note."

    stats: {
        downloads:  114
        updated_at: 1780870540000
    }
}
```
