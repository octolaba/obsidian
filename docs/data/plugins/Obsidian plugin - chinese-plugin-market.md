# Chinese Market

A search tool for Obsidian community plugins aimed at Chinese-speaking users, where a keyword query returns matching entries shown as cards whose text has been translated. Searching by AI semantics, by plugin name and by author is supported.

```cue
plugin: {
    id:     "chinese-plugin-market"
    name:   "Chinese Market"
    author: "羽鳞君"
    repo:   "miaoziguan/obsidian-chinese-plugin-market"

    html_url:    "https://community.obsidian.md/plugins/chinese-plugin-market"
    github_url:  "https://github.com/miaoziguan/obsidian-chinese-plugin-market"
    description: "面向中文用户的 Obsidian 社区插件搜索工具：输入关键词即可检索并展示翻译后的插件卡片，支持 AI 语义 / 名称 / 作者搜索。 - This plugin has not been manually reviewed by Obsidian staff."
}
```
