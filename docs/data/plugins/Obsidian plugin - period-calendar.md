# Period Calendar

Shows a calendar in which every period is clickable, covering day, week, month, quarter and year, with ISO and locale week rules applied correctly. An existing Periodic Notes or Daily Notes setup is imported, filenames are strictly parsed and validated, and collisions between week and year tokens are detected with one-click fixes so notes keep resolving to the same files.
