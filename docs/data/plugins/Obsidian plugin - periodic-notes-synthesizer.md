# Periodic Notes Synthesizer

Periodic Notes Synthesizer produces monthly and quarterly rollups from accumulated daily and periodic notes. It extracts recurring themes, unresolved open loops, commitments and concise per-note summaries, and writes a Periodic Synthesis note. That note highlights themes, said-versus-did progress, stale loops and topical consensus across entries.
