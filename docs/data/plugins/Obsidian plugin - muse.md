# Muse

Opens a full-screen distraction-free writing surface that hides Obsidian's interface and starts a date-stamped note with the generated prompt kept as a blockquote. Prompts are blog topics personalized from the author's GitHub projects and profile, checked against recent prompts to avoid repeats. The recorded text names Anthropic and OpenAI models, and the work is autosaved.

```cue
plugin: {
    id:     "muse"
    name:   "Muse"
    author: "tekgadgt"
    repo:   "tekgadgt/obsidian-muse"

    html_url:    "https://community.obsidian.md/plugins/muse"
    github_url:  "https://github.com/tekgadgt/obsidian-muse"
    description: "Distraction-free writing mode with AI-generated prompts personalized to your projects and interests. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Enter a distraction-free full-screen writing mode that hides Obsidian's UI and opens a clean surface with your AI prompt preserved as a blockquote in a new date-stamped note. Generate personalized blog-topic prompts from your GitHub projects and profile, avoid repeats by checking recent prompts, use Anthropic or OpenAI models, and autosave your work."

    stats: {
        downloads:  104
        updated_at: 1777699190000
    }
}
```
