# Sync Trakt

Syncs a Trakt.tv watchlist, watch history, favorites and ratings into localized Markdown notes with per-episode watch timestamps and TMDB metadata in more than fifteen languages. English originals are preserved in separate frontmatter fields, bundled note templates can be chosen, and chronologically sorted watch events are injected into daily notes. The recorded About text states that incremental syncs rewrite only changed notes.
