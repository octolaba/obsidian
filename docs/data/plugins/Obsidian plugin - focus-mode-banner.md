# Focus Mode Banner

Starts a focus session on the note that is open and then shows a bold banner every time a different note is opened. The banner dismisses itself after a few seconds or is closed by hand, and focus mode is toggled from the ribbon or the command palette.

```cue
plugin: {
    id:     "focus-mode-banner"
    name:   "Focus Mode Banner"
    author: "adrianofontanari"
    repo:   "adrianofontanari/obsidian-focus-mode-banner"

    html_url:    "https://community.obsidian.md/plugins/focus-mode-banner"
    github_url:  "https://github.com/adrianofontanari/obsidian-focus-mode-banner"
    description: "Activates a Focus Mode: a bold banner appears every time you open a note different from the one where you started your focus session. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display a bold warning banner whenever you navigate away from the note where you started to make context loss deliberate. Auto-dismiss the banner after a few seconds or close it manually; toggle Focus Mode from the ribbon or command palette."

    stats: {
        downloads:  529
        updated_at: 1775933295000
    }
}
```
