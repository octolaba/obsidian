# Pdftion

Adds editable annotations and a handwriting canvas to Obsidian's PDF reader, with pen, highlighter, text overlay, selection, corner resizing, eraser, undo and redo and touch gestures, as its recorded About text states. An annotated PDF can be exported, annotations exported as Markdown or summarized into a DOCX file, and a scripting interface is opened for statistics, batch operations, inserting Obsidian links and vault images, and automatic export.
