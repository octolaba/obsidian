# Ima Copilot Sync

Imports Tencent IMA knowledge bases and standalone notes into the vault as Markdown, mirroring the source folder structure. Original PDF, Word, PPT, Excel and image files are downloaded alongside same-name Markdown placeholders, and web bookmarks are converted to Markdown with images localized. Metadata is written for offline search, and syncs run incrementally or on a schedule with quota and cache safeguards.

```cue
plugin: {
    id:     "imasync"
    name:   "Ima Copilot Sync"
    author: "hifengzy"
    repo:   "hifengzy/ima-sync"

    html_url:    "https://community.obsidian.md/plugins/imasync"
    github_url:  "https://github.com/hifengzy/ima-sync"
    description: "Import Tencent IMA knowledge base and notes, automatically convert to Markdown. - This plugin has not been manually reviewed by Obsidian staff."

Convert web bookmarks to Markdown with localized images, write metadata for offline search, and run incremental or scheduled syncs with quota and cache safeguards."
