# Bullet Depth Markers

Rewrites nested bullets to a distinct Markdown marker per depth and writes that change into the file, so exports, greps and diffs carry the hierarchy. The markers are shown in Live Preview and Reading view. Numbered lists, code blocks and frontmatter are left alone, and edits preserve the cursor position and stay a single undo step.
