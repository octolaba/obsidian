# Image Picker

Browses and searches images and other media across the vault, backed by a background index so results appear as the query is typed. Thumbnails are generated automatically, search covers name and file type, and media is previewed before being embedded.

```cue
plugin: {
    id:     "image-picker"
    name:   "Image Picker"
    author: "ariamckinley"
    repo:   "ariamckinley/obsidian-image-picker"

    html_url:    "https://community.obsidian.md/plugins/image-picker"
    github_url:  "https://github.com/ariamckinley/obsidian-image-picker"
    description: "A blazingly fast way to browse, search, and embed pictures across your vault"
    about:       "Browse and find images and media across your Obsidian vault with background indexing for instant search results. Generate thumbnails automatically, search by name or file type, and preview media instantly for quick selection."
```
