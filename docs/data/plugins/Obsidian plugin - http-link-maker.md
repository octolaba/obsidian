# HTTP Link Maker

HTTP Link Maker turns Obsidian URI links into clickable HTTPS links so a vault file opens across devices and applications. Its recorded inputs state that such a link conveys only the title and requires access to the vault to open, leaving file contents private, and that the redirect can be self-hosted.

```cue
plugin: {
    id:     "http-link-maker"
    name:   "HTTP Link Maker"
    author: "kennethac"
    repo:   "kennethac/obsidian-http-links-plugin"

    html_url:    "https://community.obsidian.md/plugins/http-link-maker"
    github_url:  "https://github.com/kennethac/obsidian-http-links-plugin"
    description: "Generate HTTP Links to your vault files for universal URL recognition"
    about:       "Create clickable HTTPS links from Obsidian obsidian:// URLs so notes open reliably across devices and apps. Keep file contents private: links only convey the title and require access to your vault to open, with optional self-hosted redirect."

    stats: {
        downloads:  635

    }
}
```
