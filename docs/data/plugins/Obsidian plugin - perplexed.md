# Perplexed

Perplexed generates source-cited research content in notes using Perplexity, Anthropic, Perplexica or a local LM Studio instance. Results stream in real time, and a deep research mode works across many sources. The recorded inputs state that only prompts the user invokes are sent, with no automatic uploads and no telemetry.
