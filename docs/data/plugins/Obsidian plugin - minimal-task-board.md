# Minimal Task Board

Minimal Task Board arranges tasks into customizable buckets and groups them by any frontmatter property, so one board can serve as a Kanban board, an Eisenhower matrix or a GTD workflow. Inline tasks marked with the task tag in any note are tracked and kept synced in both directions. Tasks are reordered or moved by drag and drop in a clean, frameless design.
