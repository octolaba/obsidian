# Readability Score

Scores the readability of writing with the Flesch Reading Ease formula, applied to a whole note or to a selection. A live r9y value in the status bar gives quick feedback on text complexity.

plugin: {
    id:     "readability-score"
    name:   "Readability Score"
    author: "zuchka"
    repo:   "zuchka/obsidian-readability"

    html_url:    "https://community.obsidian.md/plugins/readability-score"
    github_url:  "https://github.com/zuchka/obsidian-readability"
    description: "Score the readabilty of your writing using the Flesch Reading Ease (FRE) formula."
    about:       "Analyze whole notes or selections with the Flesch Reading Ease formula to get a readability score. Show a live r9y value in the status bar for quick feedback on text complexity."
