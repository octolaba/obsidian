# Birthday Reminder

The plugin tracks contact birthdays, calculating the next birthday and the current age, converting between Gregorian and Lunar calendars, and deriving astrological and Chinese zodiac signs. Upcoming birthdays appear in stats cards and a monthly calendar view that can be filtered by folder, and calendar cells jump to the corresponding notes.

```cue
plugin: {
    id:     "birthday-reminder"
    name:   "Birthday Reminder"
    author: "Lifein"
    repo:   "ichris007/Obsidian-Birthday-Reminder"

    html_url:    "https://community.obsidian.md/plugins/birthday-reminder"
    github_url:  "https://github.com/ichris007/Obsidian-Birthday-Reminder"
    description: "Show contact's birthday reminder, support Gregorian/Lunar calendar conversion, astrological sign and zodiac sign, calendar view - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Manage and track birthdays with automatic next-birthday and age calculations, Gregorian/Lunar conversion, and zodiac/Chinese animal signs. Display upcoming birthdays with stats cards and an intelligent monthly calendar, filter by folder, and jump from calendar cells to the corresponding notes."

}
```
