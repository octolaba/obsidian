# CalcCraft

CalcCraft adds spreadsheet-style formulas to Markdown tables and computes them with mathjs functions. Formulas stay visible while editing through live overlays and are replaced by computed results in preview or reading mode. It supports a1 and column-row references and matrix ranges that expand into cells, highlights the parent cells a result depends on, and identifies circular references.
