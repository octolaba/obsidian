# Send Tasks to OmniFocus

Send Tasks to OmniFocus extracts the tasks of the active note and creates them in OmniFocus, skipping items that are already checked and interpreting inline due dates. Projects and further task properties are assigned in the OmniFocus modal. Tasks that were sent can optionally be marked complete in Obsidian.
