# Agent Fleet

Agent Fleet builds and runs autonomous AI agents on Claude Code or OpenAI Codex from inside the vault. Tasks can be scheduled and agents chatted with in real time, with connections to Slack, Telegram and Discord. Every agent is defined as markdown kept in the vault.
