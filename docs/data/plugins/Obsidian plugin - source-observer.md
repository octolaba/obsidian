# Source Observer

A local folder anywhere on disk is browsed from inside the vault through a collapsible file tree with file-type icons and language colors. Files are displayed syntax-highlighted in the active theme, and git changes are reviewed with modified, added and deleted badges, diffs and searchable lists.
