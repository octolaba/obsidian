# Section Variants

Section Variants keeps parallel versions of a Markdown section inline in one note, so that labeled variants can be switched and compared without splitting the content across notes. Variants can be created, renamed, copied, hidden or deleted, shown in columns or stacked, labeled consistently across a note, and a variant's raw Markdown can be copied for reuse.
