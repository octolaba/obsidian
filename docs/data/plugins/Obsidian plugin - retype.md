# Retype

Retype manages Retype documentation projects from a sidebar panel with Start, Stop and Build controls and a color-coded, scrollable CLI console. Live server status is shown with a clickable URL and an optional status bar item. The nearest retype.yml file and the Retype CLI are detected automatically, and the CLI can be installed with one click when it is missing.

```cue
plugin: {
    id:     "retype"
    name:   "Retype"
    author: "retypeapp"
    repo:   "retypeapp/retype-for-obsidian"

    html_url:    "https://community.obsidian.md/plugins/retype"
    github_url:  "https://github.com/retypeapp/retype-for-obsidian"
    description: "Build and preview your documentation with Retype. - This plugin has not been manually reviewed by Obsidian staff."
```
