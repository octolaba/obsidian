# Templify

Templify renders a note through a selectable template, either Cornell, Eisenhower or a custom one, to give it a different layout and structured content. Obsidian views are embedded into notes through templify-embed blocks or an Embed view command. The plugin is closed source, and advanced features are unlocked with a PKMer account.
