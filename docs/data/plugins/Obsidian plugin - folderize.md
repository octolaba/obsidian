# Folderize

Organizes attachments into a predictable folder hierarchy derived from each file's SHA-256 checksum, so identical files end up on the same path. The nesting spreads files across folders to keep a single directory from growing oversized. Organization runs manually or automatically, with optional cleanup of empty folders.
