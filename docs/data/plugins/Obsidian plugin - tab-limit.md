# Tab Limiter

Limits the number of tabs that can be open to a configurable maximum. The recorded inputs state that new tabs are blocked once the limit is reached and that the oldest tabs are closed automatically to keep the workspace within it.

```cue
plugin: {
    id:     "tab-limit"
    name:   "Tab Limiter"
    author: "lizard-heart"
    repo:   "lizard-heart/obsidian-tab-limit"

    html_url:    "https://community.obsidian.md/plugins/tab-limit"
    github_url:  "https://github.com/lizard-heart/obsidian-tab-limit"
    description: "Limits the number of tabs that can be opened."
    about:       "Limit the number of open tabs to a configurable maximum and block new tabs when the limit is reached. Automatically close the oldest tabs to keep your workspace within the set limit."
```
