# TOML Editor

TOML Editor opens toml files in a native pane backed by a CodeMirror 6 editor with line numbers and TOML syntax highlighting. Changes are written by a debounced autosave, parse diagnostics are shown inline, and the status bar reports whether the current document is valid TOML.

```cue
plugin: {
    id:     "toml-editor"
    name:   "TOML Editor"
    author: "Jason Crawford"
    repo:   "jasoncrawford/obsidian-toml"

    html_url:    "https://community.obsidian.md/plugins/toml-editor"
    github_url:  "https://github.com/jasoncrawford/obsidian-toml"
    description: "Open and edit TOML files with syntax highlighting and parse diagnostics. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open .toml files inside a native pane with a CodeMirror 6 editor, line numbers, and TOML syntax highlighting. Use debounced autosave and inline parse diagnostics, with a status bar showing whether the current document is valid TOML."
```
