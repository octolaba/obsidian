# Picote

Picote adds column layouts to notes with live preview and, per the recorded inputs, minimal interference with editing. Images dragged from web pages and social sites are downloaded silently, renamed, and their remote URLs replaced with local embeds, including for complex CDNs, anti-hotlinking and extensionless links. The recorded description also lists drag and drop and inline editing.
