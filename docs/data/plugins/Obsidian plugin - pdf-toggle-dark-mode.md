# PDF Toggle Dark Mode

Switches PDF viewers and their sidebar thumbnails between dark and light appearance by applying a PDF-specific dark mode. The toggle is available from a ribbon icon, a status-bar item and a command. The chosen mode persists across restarts and is re-applied to PDFs opened afterwards.

plugin: {
    id:     "pdf-toggle-dark-mode"
    name:   "PDF Toggle Dark Mode"
    author: "Vivek Galatage"
    repo:   "vivekgalatage/pdf-toggle-dark-mode"

    html_url:    "https://community.obsidian.md/plugins/pdf-toggle-dark-mode"
