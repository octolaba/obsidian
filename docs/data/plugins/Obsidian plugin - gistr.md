# Gistr

Creates, converts and updates notes as GitHub Gists or OpenGist snippets from within Obsidian, with line numbers, syntax highlighting, public or secret saving and manual or autosave modes. It also embeds gists into notes in codeblock or website mode with adjustable frame size, CSS overrides, themes and caching, and can open an embedded gist in the browser.
