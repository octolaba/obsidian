# Quick Chinese Translate

Translates the whole current note into Simplified Chinese and writes the result as a new note. YAML frontmatter is preserved, code blocks and prompts are left unchanged, and the translated top heading becomes the filename of the copy. Translation runs through Google, DeepL or any OpenAI-compatible LLM.

```cue
plugin: {
    id:     "quick-zh"
    name:   "Quick Chinese Translate"
    author: "jack"
    repo:   "sany2ng0226-boop/quick-zh"

    html_url:    "https://community.obsidian.md/plugins/quick-zh"
    github_url:  "https://github.com/sany2ng0226-boop/quick-zh"
    description: "一键把当前笔记整篇翻译成中文（标题/文件名也翻），生成中文副本。支持 Google/DeepL/LLM 多引擎，不破坏笔记属性。 - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Translate the entire current note into Simplified Chinese and create a new Chinese copy with one click. Preserve YAML frontmatter, keep code blocks and prompts unchanged, and use the translated top heading as the new filename. Choose Google, DeepL, or any OpenAI-compatible LLM for translation."
```
