# Simple Mindmap

Markdown notes become editable, linkable mind-map nodes that are navigated entirely from the keyboard, with bi-directional link support. Linked notes are compiled into a single structured Markdown file or exported as a hierarchical outliner, and nodes are reordered by drag-and-drop or hotkeys. The index records that this plugin has not been manually reviewed by Obsidian staff.
