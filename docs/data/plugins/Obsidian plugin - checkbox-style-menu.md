# Checkbox Style Menu

Checkbox Style Menu opens a menu on a long press or a right-click over a checkbox for changing its style. Twenty-two checkbox designs taken from Minimal and Things are offered and applied at once, and the menu works on desktop and mobile while adapting to the current theme.
