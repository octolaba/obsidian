# PF2e Statblocks

PF2e Statblocks renders Pathfinder Second Edition and Starfinder 2e statblocks from pf2e-stats and sf2e-stats Markdown code blocks, using Markdown syntax alone. Statblocks are styled with a heading-based name and level, trait highlighting, automatic size and rarity coloring, action icons and dividers. A compact brief format is also available.

```cue
plugin: {
    id:     "pf2e-statblocks"
    name:   "PF2e Statblocks"
    author: "pixley"
    repo:   "pixley/pf2e-statblock-for-obsidian"

    html_url:    "https://community.obsidian.md/plugins/pf2e-statblocks"
    github_url:  "https://github.com/pixley/pf2e-statblock-for-obsidian"
    description: "Render Pathfinder 2e statblocks cleanly, using only Markdown-based syntax."
    about:       "Create Pathfinder Second Edition (or Starfinder 2e) statblocks in Obsidian using pf2e-stats or sf2e-stats Markdown codeblocks. Render styled statblocks with heading-based name/level, trait highlighting (==Trait==), automatic size/rarity coloring, action icons, dividers, and compact brief formats."

    stats: {
        downloads:  13320
        updated_at: 1786295229000
    }
}
```
