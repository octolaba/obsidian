# Minimize on Close

Minimize on Close minimizes the app window to the dock or taskbar once the last open pane is closed, matching the behaviour of a macOS application. The behaviour can apply on macOS, Windows and Linux or be restricted to macOS only, and minimize or exit can also be triggered from command-palette actions.

```cue
plugin: {
    id:     "minimize-on-close"
    name:   "Minimize on Close"
    author: "alberti42"
    repo:   "alberti42/obsidian-minimize-on-close"

    html_url:    "https://community.obsidian.md/plugins/minimize-on-close"
    github_url:  "https://github.com/alberti42/obsidian-minimize-on-close"
    description: "Minimizes the app window to an icon after closing the last open pane"
    about:       "Minimize the Obsidian window to the dock or taskbar whenever all panes are closed, matching macOS app behavior. Apply the behavior across macOS, Windows, and Linux or keep it macOS-only, and trigger minimize or exit via command-palette actions."

    stats: {
        downloads:  1863
        updated_at: 1727268926000
    }
}
```
