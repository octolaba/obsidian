# Academic Export

Exports Markdown notes as documents styled to APA 7, MLA 9, Chicago 18, IEEE, Harvard or AMA conventions. Output can be PDF, DOCX or HTML, document metadata is supplied through YAML frontmatter, and tables and figures can be placed as addenda after the References section. Previous export settings are kept for reuse.
