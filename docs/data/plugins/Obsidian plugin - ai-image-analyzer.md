# AI image analyzer

Analyzes images in the vault with a local Ollama instance to extract keyword lists from JPG, JPEG, PNG and WEBP files. Analysis results are cached and synced so repeat lookups are faster, and the extracted keywords can be integrated into OmniSearch for indexed searching.
