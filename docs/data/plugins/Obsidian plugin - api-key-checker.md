# AI API Key Checker

Validates API keys and detects rate limits for 21 AI providers from inside Obsidian, running real provider checks rather than regex matching. Dozens of keys can be tested in bulk, with quota and reset times and rate limits surfaced, failures sorted to the top, and masked keys copied on click. A stats bar shows OK, LIMIT and INVALID counts and the time of the last check.
