# Broken Links

Broken Links finds internal links in the vault that do not resolve to a file, heading or block. Results are grouped by folder, file or link with counts and sorting, and from there the source note can be opened or the missing target created to repair the connection.

```cue
plugin: {
    id:     "broken-links"
    name:   "Broken Links"
    author: "ipshing"
    repo:   "ipshing/obsidian-broken-links"

    html_url:    "https://community.obsidian.md/plugins/broken-links"
    github_url:  "https://github.com/ipshing/obsidian-broken-links"
    description: "Find broken links in your vault that don't connect to notes."
    about:       "Locate internal links across your vault that don't resolve to files, headings, or blocks. View broken links by folder, file, or link with counts and sorting, then open the source note or create the missing target to repair connections."

    stats: {
        downloads:  6290
        updated_at: 1708574787000
    }
}
```
