# Extended Base

Extended Base renders a Bases view as a Notion-style table with column wrap, top-aligned cells and a transparent background. Values are shown as colored pills whose colors persist, with a per-value color picker, and rows expose hover open buttons and inline cell editing. A note can be opened in a centered page panel where its title, properties and body are edited inline with live saving.
