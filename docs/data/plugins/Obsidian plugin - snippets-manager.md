# Snippets Manager

Text snippets kept as Markdown files or folders, subfolders included, are located by fuzzy search and inserted where they are needed. A snippet is copied to the clipboard or pasted at the cursor, and Templater tags inside it are processed before insertion. Snippets export as Alfred-compatible JSON, and the community ChatGPT prompt collection the recorded inputs name can be imported. The recorded inputs name code, passport numbers and email signatures as example content, with full mobile support.
