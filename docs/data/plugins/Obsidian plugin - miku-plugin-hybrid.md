# Miku Hybrid

Miku Hybrid applies Hatsune Miku-inspired hybrid styling and a bundled palette across Obsidian without requiring a separate Appearance theme. Four modes, MinimalMiku, Concert, NightNeon and SnowMiku Ribbon, can be cycled through, optional status bar, banner, quote and profile widgets added, and a Miku dashboard opened with original ASCII presets. The recorded text states that it ships with no audio assets, APIs or dependencies.
