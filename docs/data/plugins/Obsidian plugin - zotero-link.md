# Zotero Link

Zotero Link inserts links to Zotero items into notes, reaching Zotero through its local API or through ZotServer. The link text is produced from Nunjucks templates and can include metadata such as the item key, title, authors and publication date.

```cue
plugin: {
    id:     "zotero-link"
    name:   "Zotero Link"
    author: "vanakat"
    repo:   "vanakat/zotero-link"
```
