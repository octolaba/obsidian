# Vaultbox

Synchronizes the vault directly with a chosen Dropbox folder on desktop and mobile, without the Dropbox desktop client. Planned changes can be previewed and simulated before they are applied, syncs run manually or automatically, the .obsidian folder is ignored by default, and detected conflicts pause the run for a decision.
