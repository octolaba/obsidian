# Callout Suggestions

Callout Suggestions opens a fuzzy-searched suggestion modal for callouts, triggered by typing the callout opener sequence. Callout definitions are pulled from Callout Manager, so both built-in and custom callouts are listed. Selecting a suggestion inserts a formatted callout block into the note.

```cue
plugin: {
    id:     "callout-suggestions"
    name:   "Callout Suggestions"
    author: "cwfryer"
    repo:   "cwfryer/obsidian-callout-suggestions"

    html_url:    "https://community.obsidian.md/plugins/callout-suggestions"
    github_url:  "https://github.com/cwfryer/obsidian-callout-suggestions"
    description: "Adds a fuzzy searched suggestion modal for callouts."
    about:       "Insert callouts quickly with an autosuggest modal triggered by typing >!. Pull callout definitions from Callout Manager to list built-in and custom callouts. Select a suggestion to insert a formatted callout block into your note."

    stats: {
        downloads:  12354
        updated_at: 1721668994000
    }
}
```
