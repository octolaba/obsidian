# Header navigation

Header navigation jumps between Markdown headers and moves to a specific section of the current note. Folding is toggled for any header, collapsing or expanding its section to manage the document structure.

```cue
plugin: {
    id:     "header-navigation"
    name:   "Header navigation"
    author: "talwrii"
    repo:   "talwrii/obsidian-header-navigation"

    html_url:    "https://community.obsidian.md/plugins/header-navigation"
    github_url:  "https://github.com/talwrii/obsidian-header-navigation"
    description: "Quickly jump between headers and toggle folding"
    about:       "Navigate quickly between Markdown headers and jump to specific sections. Toggle folding for any header to collapse or expand sections and manage document structure."

    stats: {
        downloads:  1486
        updated_at: 1733683225000
    }
}
```
