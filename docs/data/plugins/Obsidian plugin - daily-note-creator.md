# Daily note creator

Creates missing daily notes automatically at vault startup, without opening them, following the Daily Notes settings. Missed days are filled in on startup, and a command backfills any date range, asking for confirmation when the gap is longer than a week.

```cue
plugin: {
    id:     "daily-note-creator"
    name:   "Daily note creator"
    author: "mario-holubar"
    repo:   "mario-holubar/obsidian-daily-note-creator"

    html_url:    "https://community.obsidian.md/plugins/daily-note-creator"
    github_url:  "https://github.com/mario-holubar/obsidian-daily-note-creator"
    description: "Automatically creates missing daily notes"
    about:       "Create daily notes automatically at vault startup without opening them, using your Daily Notes settings. Auto-fill missed days on startup or trigger a command to backfill any date range, with confirmation for gaps longer than a week."
```
