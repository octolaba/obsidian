# Quote of the Day

Inserts random famous quotes into the editor as Markdown, fetched from the Quotable API. A qotd template marker sets where the quote is inserted, and tags are optionally added in a footer.

```cue
plugin: {
    id:     "quote-of-the-day"
    name:   "Quote of the Day"
    author: "twentytwokhz"
    repo:   "twentytwokhz/quote-of-the-day"

    html_url:    "https://community.obsidian.md/plugins/quote-of-the-day"
    github_url:  "https://github.com/twentytwokhz/quote-of-the-day"
    description: "Insert random quotes in the editor."
    about:       "Insert random famous quotes as Markdown from the Quotable API. Use the {{qotd}} template to insert quotes and optionally include tags in a footer."

    stats: {
        downloads:  15636
        updated_at: 1732812896000
    }
}
```
