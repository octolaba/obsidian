# Scrobble

Scrobble creates song and album notes from Spotify: the currently playing or a recently played track can be logged, or Spotify searched, and the note's frontmatter is populated from the Spotify metadata. Timestamped thoughts are captured and related songs can be linked with contextual logs. A Spotify Premium account is needed for API access.

plugin: {
    id:     "scrobble"
    name:   "Scrobble"
    author: "yipqp"
    repo:   "yipqp/obsidian-scrobble"

    html_url:    "https://community.obsidian.md/plugins/scrobble"
    github_url:  "https://github.com/yipqp/obsidian-scrobble"
    description: "Log and connect thoughts on Spotify songs and albums. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Log currently playing or recently played tracks or search Spotify and create song or album notes with populated frontmatter.
