# Table Checkbox Row Color

Makes checkboxes in Markdown tables interactive in Reading Mode and writes each toggle back to the source file. A row is highlighted when any checkbox in it is checked, and completed rows can optionally be struck through. Multiple checkboxes per cell and complex table layouts are supported.

```cue
plugin: {
    id:     "table-checkbox-row-color"
    name:   "Table Checkbox Row Color"
    author: "mtplr"
    repo:   "mtplr/obsidian-table-checkbox-row-color"

    html_url:    "https://community.obsidian.md/plugins/table-checkbox-row-color"
    github_url:  "https://github.com/mtplr/obsidian-table-checkbox-row-color"
    description: "Interactive Markdown table checkboxes with row highlighting and optional strikethrough support. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Enable interactive checkboxes in Markdown tables in Reading Mode and save toggles back to the source file. Highlight entire rows when any checkbox in a row is checked and optionally apply strikethrough to completed rows; support multiple checkboxes per cell and complex table layouts."

    stats: {
        downloads:  266
        updated_at: 1775501134000
    }
}
```
