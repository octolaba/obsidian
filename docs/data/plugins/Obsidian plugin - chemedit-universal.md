# ChemEdit Universal

Draws and edits chemical structures inside notes with a touch-friendly editor that works offline on desktop and mobile. Molecular properties are calculated, including molecular weight, exact mass, LogP and LogS, PSA, hydrogen-bond donors and acceptors, rotatable bonds and stereocenters. SMILES or MOL text pasted into a note renders immediately, and .mol files can be embedded as editable SVGs.
