# Kale Graph

Renders graph-theory diagrams from kale code blocks in notes. Vertices, edges and paths are declared with a line-based syntax, and flags control directed, simple, auto and flipped graphs. A leading underscore marks a vertex as invisible, which is how layout is influenced.

```cue

    id:     "kale-graph"
    name:   "Kale Graph"
    author: "olillin"
    repo:   "olillin/obsidian-kale-graph"

    html_url:    "https://community.obsidian.md/plugins/kale-graph"
    github_url:  "https://github.com/olillin/obsidian-kale-graph"
    description: "Render mathematical graphs."
    about:       "Create and render graph-theory diagrams directly in Obsidian using kale code blocks. Define vertices, edges and paths with simple line-based syntax, use flags for directed/simple/auto/flipped graphs, and mark invisible vertices with a leading underscore to control layout."
```
