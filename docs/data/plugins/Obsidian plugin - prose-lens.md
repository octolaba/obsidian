# Prose Lens

Marks readability and style issues in the editor as you type, among them adverbs, passive voice, hedges, weasel words, cliches, doubled words and long sentences, and shows a live Flesch reading ease and grade in the status bar. Code fences, inline code, math, frontmatter, links, wikilinks, headings and table rows are masked to avoid false positives. The recorded description states that analysis runs locally and that nothing is written to the notes.
