# Simple Disguise

Simple Disguise obscures markdown content in the editor by swapping the background and text colors, so a passerby cannot easily read the note. The disguise is toggled on demand and applies only in edit mode; reading view is left unchanged.

```cue
plugin: {
    id:     "simple-disguise"
    name:   "Simple Disguise"
    author: "ctxinf"
    repo:   "ctxinf/simple-disguise"

    html_url:    "https://community.obsidian.md/plugins/simple-disguise"
    github_url:  "https://github.com/ctxinf/simple-disguise"
    description: "disguise/obscure/hide the markdown content in a very simple way."
    about:       "Toggle a disguise in the editor to obscure content by swapping background and text colors, preventing passersby from easily reading your notes. Apply only in edit mode; reading view remains unchanged."

    stats: {
        downloads:  365

}
```
