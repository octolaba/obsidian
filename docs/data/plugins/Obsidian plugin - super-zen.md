# Super Zen

A minimal zen mode hides the sidebars, status bar, tab headers and document metadata and turns on full screen, leaving the editor showing only the text. A left reference pane can be kept while the right side becomes the focused full-screen area, and the layout offers floating vertical tabs and centered typewriter-style spacing. The About text recorded for this entry is written in Chinese.
