# Homepage Studio

Opens a desktop homepage gathering writing activity, a single-file journal split into date sections, active and archived homepage tasks, time plans, curated file groups and configurable image banners. A writing heatmap shows per-file change details, daily and weekly plan templates are available, and missing files can be recovered. Built-in light and dark themes can be switched from the homepage.

plugin: {
    id:     "homepage-studio"
    name:   "Homepage Studio"
    author: "Aluxes"
    repo:   "ashenashes/homepage-studio"

    html_url:    "https://community.obsidian.md/plugins/homepage-studio"
    github_url:  "https://github.com/ashenashes/homepage-studio"

View a writing heatmap with per-file change details, use daily/weekly plan templates, recover missing files, and switch built-in light/dark themes."
