# Korean Grammar Assistant

Checks and corrects Korean spelling and grammar with suggestions from Bareun.ai, OpenAI, Anthropic, Google or a local Ollama model. Editing works inline, described as beta, or in a popup. Color-coded states and several suggestions with confidence scores can be previewed before a fix is applied with one click.
