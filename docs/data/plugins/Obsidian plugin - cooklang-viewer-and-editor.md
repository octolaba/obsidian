# Cooklang

This plugin displays and edits recipes written in the Cooklang format, with localized section titles and full Cooklang syntax editing. Ingredient quantities can be scaled with a slider and shown as fractions or decimals, and webp images are supported.

```cue
plugin: {
    id:     "cooklang-viewer-and-editor"
    name:   "Cooklang"
    author: "rveciana"
    repo:   "rveciana/obsidian-cooklang"

    html_url:    "https://community.obsidian.md/plugins/cooklang-viewer-and-editor"
    github_url:  "https://github.com/rveciana/obsidian-cooklang"
    description: "Display and edit recipes written in the Cooklang format."
    about:       "Edit and view recipes in Cooklang format inside Obsidian with localized section titles. Scale ingredient quantities with a slider and choose fraction or decimal displays; include webp image support and full Cooklang syntax editing."
```
