# Dialogue

Dialogue creates formatted dialogues in Markdown, placing each message on the left or the right according to the angle-bracket marker that prefixes its line. Participant names are set, title rendering controlled, and message and comment widths adjusted with inline parameters.

```cue
plugin: {
    id:     "obsidian-dialogue-plugin"
    name:   "Dialogue"
    author: "holubj"
    repo:   "holubj/obsidian-dialogue-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-dialogue-plugin"
    github_url:  "https://github.com/holubj/obsidian-dialogue-plugin"
    description: "Create dialogues in Markdown."
    about:       "Create formatted left/right dialogues directly in Markdown by prefixing lines with < or > to place messages. Set participant names, control title rendering, and adjust message/comment widths with inline parameters to customize dialogue appearance."
```
