# Media Grid

Wraps local images and MP4 videos into a grid through a block syntax that sets the column count, the gap and a container id for CSS targeting. Supported extensions are jpg, jpeg, png and webp for images and mp4 for video; anything else renders an error callout. Row height matches the tallest item, which preserves the media dimensions.

    id:     "media-grid"
    name:   "Media Grid"
    author: "subhash-sarangi"

    github_url:  "https://github.com/subhash3/obsidian-plugin-media-grid"
    description: "Wrap media inside a grid layout. - This plugin has not been manually reviewed by Obsidian staff."

Match row height to the tallest item to preserve media dimensions."
