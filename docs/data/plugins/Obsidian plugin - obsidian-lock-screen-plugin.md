# Lock Screen

This plugin protects the vault with a lock screen that hides notes in the interface without encrypting files. The screen can appear when the window loses focus on desktop, when interaction stops on mobile, when a vault opens, or on a command from the palette. The desktop and mobile triggers accept an optional delay.

    id:     "obsidian-lock-screen-plugin"
    name:   "Lock Screen"
