# fakelink

fakelink creates virtual links for text that matches the titles, aliases or headers of other notes, giving glossary-like behaviour based on virtual linker. The links are rendered dynamically in the editor and the Markdown files themselves are unchanged, and a link that targets a header jumps straight to it. A virtual link can be converted into a real link when that is wanted.

```cue
plugin: {
    id:     "fakelink"
    name:   "fakelink"
    author: "godfatherlg"
    repo:   "godfatherlg/fakelink"

    html_url:    "https://community.obsidian.md/plugins/fakelink"
    github_url:  "https://github.com/godfatherlg/fakelink"
    description: "Automatically creates virtual links for text that match the titles or headers of other notes in your vault. Create a glossary-like functionality, based on virtual linker - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Generate virtual links from note titles, aliases, and headers to auto-link mentions across your vault. Render links dynamically in the editor without changing Markdown files, jump straight to header targets, and convert virtual links into real links when needed."

    stats: {
        downloads:  1465
        updated_at: 1784209947000
    }
}
```
