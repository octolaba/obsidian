# Go Playground

Runs, formats and shares Go code snippets through the Go Playground API from inside Obsidian. Snippets can be inserted from Go Playground share links or identifiers, and the API endpoint can be pointed at a third-party playground. The interface is available in English and in simplified and traditional Chinese.

```cue
plugin: {
    id:     "go-playground"
    name:   "Go Playground"
    author: "huluntuntao"
    repo:   "huluntuntao/go-playground-plugin-for-obsidian"

    html_url:    "https://community.obsidian.md/plugins/go-playground"
    github_url:  "https://github.com/huluntuntao/go-playground-plugin-for-obsidian"
    description: "Run, format, and share Golang code snippets using the Go Playground API. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Run, format, and share Go code snippets directly in Obsidian using the Go Playground API. Insert snippets from Go Playground share links or IDs and change the API endpoint to use third‑party playgrounds; supports English, 简体中文, 繁體中文."

    stats: {
        downloads:  138
        updated_at: 1769773575000
    }
}
```
