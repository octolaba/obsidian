# Easy Typing

Formats text while it is being typed: spacing between CJK and Latin letters or digits, automatic full-width punctuation, and automatic pairing of CJK brackets and quotes. Editing aids include Tab to jump out of a pair, a smart backspace that clears empty list and quote lines, and inline code from two middle dots. A rule engine handles custom text transformations.
