# Timer

Timer measures elapsed time and counts down through commands, a ribbon icon or on-screen timer buttons. Timers can be started, stopped, paused, resumed, reset or cancelled, the active one appears in the status bar, and a notification fires when a timer ends. Favorite presets can be saved and durations entered as HH:MM:SS or in a form such as 10m 11s, with an optional verbose display.
