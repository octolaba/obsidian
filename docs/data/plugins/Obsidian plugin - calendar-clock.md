# Calendar Clock Companion

Calendar Clock Companion embeds a live clock at the top of Liam Cain's Calendar sidebar and requires that plugin to be installed. Monospace digits and theme-aware colors keep the layout stable, and settings enable a 12-hour format or a seconds display.

```cue
plugin: {
    id:     "calendar-clock"
    name:   "Calendar Clock Companion"
    author: "Izzan Mirza"
    repo:   "izz4n/obsidian-calendar-clock-plugin"

    html_url:    "https://community.obsidian.md/plugins/calendar-clock"
    github_url:  "https://github.com/izz4n/obsidian-calendar-clock-plugin"
    description: "Simple, live clock above the Liam Cain's Calendar plugin - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed a live clock at the top of Liam Cain's Calendar sidebar for at-a-glance current time (requires Liam Cain's Calendar plugin). Keep layouts stable with monospace digits and theme-aware colors, and enable 12-hour or seconds display in the plugin Settings."

    stats: {
        downloads:  36
        updated_at: 1784055663000
    }
}
```
