# Harmony Progression Player

Harmony Progression Player detects harmonic progressions written as numeric degrees, Roman numerals or chord symbols, covering extensions, altered chords, sus and add chords, diminished and half-diminished chords, and slash chords. Progressions found in configured folders are played with a bundled sampled piano or a soft or bright synth. The plugin parses inline code while ignoring fenced code blocks, and resolves numeric and Roman progressions relative to a chosen key root.
