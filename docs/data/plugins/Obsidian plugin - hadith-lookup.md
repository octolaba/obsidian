# Hadith Lookup

Inserts hadith and Quranic passages by reference ID from the Hadith Unlocked API, using identifiers such as quran:2:255 or bukhari:99. The selected reference is replaced with the sourced text and its English translation, formatted as an Obsidian callout.

```cue
plugin: {
    id:     "hadith-lookup"
    name:   "Hadith Lookup"
    author: "iadnanmukhtar"
    repo:   "iadnanmukhtar/obsidian-hadith-lookup-plugin"

    html_url:    "https://community.obsidian.md/plugins/hadith-lookup"
    github_url:  "https://github.com/iadnanmukhtar/obsidian-hadith-lookup-plugin"
    description: "Inserts Hadith and Quranic ayat and passages using a reference ID from the Ḥadīth Unlocked API (https://hadithunlocked.com)"
    about:       "Fetch Quranic āyahs and ḥadīths by selecting a Hadith Unlocked reference ID (e.g. quran:2:255, bukhari:99). Replace the reference with the sourced text and English translation from Hadith Unlocked, formatted as an Obsidian callout."

    stats: {
        downloads:  405
        updated_at: 1776012075000
    }
}
```
