# SnipDock

CSS snippets are toggled, created, renamed, opened in an external editor and reloaded from a status-bar dock without leaving the current note. A master switch flips a whole set on or off, the snippets folder is opened directly, and new snippet files are created from a template that can be enabled automatically.

    id:     "snipdock"
    name:   "SnipDock"
    author: "Joe Raad"

    github_url:  "https://github.com/joeraad/obsidian-snipdock"

Use a master switch to flip sets on/off, open the snippets folder, and create files from a template that can be auto-enabled."
