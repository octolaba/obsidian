# LanTai

Uploads images from the vault to S3-compatible object storage and replaces the note links with the remote URLs. Remote images can be localized back into the vault or their links rewritten, and images can be written to disk through Save As without touching the notes. Several built-in object-storage profiles can be managed for quick transfers.
