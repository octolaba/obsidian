# Theme Engine

Theme Engine manages Obsidian's appearance from one visual place instead of hand-written CSS. Profiles bundle colors, snippets, backgrounds and customization settings, switch instantly, and import and export as JSON. Changes build dynamically on top of the active theme rather than replacing it entirely.

```cue
plugin: {
    id:     "theme-engine"
    name:   "Theme Engine"
    author: "Yazan Ammar"
    repo:   "yazanammar/obsidian-theme-engine"

    html_url:    "https://community.obsidian.md/plugins/theme-engine"
    github_url:  "https://github.com/yazanammar/obsidian-theme-engine"
    description: "Customize Obsidian without touching CSS. Create profiles with colors, snippets, backgrounds, and themes - all managed from one place. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Customize and manage Obsidian from a unified visual workflow without touching CSS. Create reusable profiles that bundle colors, snippets, backgrounds, and customization settings, switch between them instantly, import or export them as JSON, and dynamically build on top of your active theme instead of replacing it entirely."

    stats: {
        downloads:  2681

    }
}
```
