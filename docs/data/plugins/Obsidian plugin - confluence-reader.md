# Confluence Reader

Confluence Reader performs a read-only sync of Confluence Server pages into the vault as Markdown, preserving the page hierarchy and attachments with downloads optional. Confluence content is converted into Obsidian-friendly forms — callouts, code blocks, wikilinks, a table of contents and expanded macros — and Confluence metadata and version tracking are embedded in the frontmatter.

```cue
plugin: {
    id:     "confluence-reader"
    name:   "Confluence Reader"
    author: "keonyrus"
    repo:   "keonyrus/obsidian-confluence-sync"

    html_url:    "https://community.obsidian.md/plugins/confluence-reader"
    github_url:  "https://github.com/keonyrus/obsidian-confluence-sync"
    description: "Read-only sync of Confluence Server pages into your vault as Markdown. - This plugin has not been manually reviewed by Obsidian staff."

Convert Confluence content to Obsidian-friendly formats—callouts, code blocks, wikilinks, TOC, expanded macros—and embed Confluence metadata and version tracking in frontmatter."
