# sync-to-xlog

Pushes notes to xlog.app and writes the returned post metadata back into each note's front matter. Notes are uploaded from the context menu, embedded images are converted to IPFS, and posts are created or updated while upload progress and status are shown.

    id:     "sync-to-xlog"
    name:   "sync-to-xlog"
    author: "otto-j"
