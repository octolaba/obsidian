# Property Annotations

Displays read-only inline annotations beside boolean properties in daily notes, showing how long it has been since the property was last set. Labels such as today, yesterday, never, or a count of days since last are shown, the daily notes settings are detected automatically, and the files themselves are not modified.

```cue
plugin: {
    id:     "property-annotations"
    name:   "Property Annotations"
    author: "ppeirce"
    repo:   "ppeirce/property-annotations"

    html_url:    "https://community.obsidian.md/plugins/property-annotations"
    github_url:  "https://github.com/ppeirce/property-annotations"
    description: "Display inline annotations for note properties in daily notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display inline, read-only annotations for boolean properties in daily notes (e.g., went_outside: true → <3 days since last>). Detect daily notes settings automatically and show labels like <today>, <yesterday>, <never>, or <N days since last> without modifying your files."

    stats: {
        downloads:  96
        updated_at: 1767994484000
    }
}
```
