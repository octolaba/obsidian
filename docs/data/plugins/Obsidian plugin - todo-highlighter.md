# TODO Highlighter

TODO Highlighter colors every exact occurrence of the word TODO in both edit and preview mode. Matching is whole-word; preview renders a colored span while edit mode uses a CodeMirror decoration, and changing the chosen color updates the highlights immediately.

```cue
plugin: {
    id:     "todo-highlighter"
    name:   "TODO Highlighter"
    author: "heavenlygaze"
    repo:   "heavenlygaze/obsidian-todo-highlighter"

    html_url:    "https://community.obsidian.md/plugins/todo-highlighter"
    github_url:  "https://github.com/heavenlygaze/obsidian-todo-highlighter"
    description: "Highlights TODO regex as green."
    about:       "Highlight all exact TODO occurrences in edit and preview with a user-selected color. Detect whole-word TODO and render preview as a colored span and edit mode via CodeMirror decoration. Update highlights live when you change the color."
```
