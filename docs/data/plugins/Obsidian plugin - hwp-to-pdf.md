# HWP to PDF

HWP to PDF converts Korean HWP and HWPX files to PDF, and optionally Markdown, when they appear in the vault or from the command palette, rendering locally with a Rust and WebAssembly engine and requiring no external server or API key. Output is either an image-based searchable PDF with an invisible text layer, a compact text-based PDF, or a small Markdown note with reconstructed paragraphs and tables.
