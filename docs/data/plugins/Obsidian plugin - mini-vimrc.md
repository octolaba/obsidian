# Mini Vimrc

Mini Vimrc loads a .vimrc from the vault and applies its key mappings to Obsidian's Vim mode. It supports the standard mapping commands map, imap, nmap, vmap, noremap, inoremap, nnoremap, vnoremap and unmap, and treats Markdown or plain text files as a .vimrc so the mappings can be edited inside the vault.

```cue
plugin: {
    id:     "mini-vimrc"
    name:   "Mini Vimrc"
    author: "cabra-arretado"
    repo:   "cabra-arretado/mini-vimrc-obsidian"

    html_url:    "https://community.obsidian.md/plugins/mini-vimrc"
    github_url:  "https://github.com/cabra-arretado/mini-vimrc-obsidian"
    description: "Add Vim keybindings via .vimrc"
    about:       "Load a .vimrc from your vault and apply its Vim key mappings to Obsidian's Vim mode. Support standard Vim commands (map, imap, nmap, vmap, noremap, inoremap, nnoremap, vnoremap, unmap) and treat Markdown or plain text files as .vimrc for in-vault editing."

    stats: {
        downloads:  5172
        updated_at: 1707790773000
    }
}
```
