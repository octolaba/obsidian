# ABC Music Notation

Renders ABC music notation from abc code blocks using the abcjs library, covering multi-voice scores, tablature, clefs, swing feel and MIDI playback. Rendering options are set by inline JSON at the top of a code block.

```cue
plugin: {
    id:     "music-code-blocks"
    name:   "ABC Music Notation"
    author: "abcjs-music"
    repo:   "abcjs-music/obsidian-plugin-abcjs"

    html_url:    "https://community.obsidian.md/plugins/music-code-blocks"
    github_url:  "https://github.com/abcjs-music/obsidian-plugin-abcjs"
    description: "Render music sheets directly from code blocks using ABC music notation via abcjs."
    about:       "Render ABC music notation from abc code blocks with the abcjs library, including multi-voice scores, tablature, clefs, swing feel and MIDI playback. Pass inline JSON at the top of code blocks to customize rendering options."
```
