# Zotero Highlights Sync

Creates linked book notes in the vault and synchronizes PDF annotations from a locally running Zotero desktop instance. Annotation text, Zotero comments, colors, pages, ordering and deep links are carried over, paragraph and list boundaries are restored, and annotation numbers stay stable between runs. Each annotation becomes its own atomic note, with manual renames and user-authored content preserved; synchronization is triggered manually on demand.
