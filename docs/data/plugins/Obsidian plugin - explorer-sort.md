# Explorer Sort

Replaces alphabetical or date sorting in the file explorer with a manual order kept per folder. Items are moved through right-click commands or a drag-and-drop reorder modal that also has commands and hotkeys, and their order survives renames and moves. New items are appended at the bottom, and the custom sorting can be switched off.
