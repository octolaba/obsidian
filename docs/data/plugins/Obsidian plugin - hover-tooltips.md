# Hover Tooltips

Hover Tooltips adds tooltips that render Markdown, including bold, italic, inline code, highlights and links. Tips pair a word with a description in a brace-and-slash syntax, appear on hover and are pinned with a left click, and may carry clickable internal and external links.

```cue
plugin: {
    id:     "hover-tooltips"
    name:   "Hover Tooltips"
    author: "chetscmd"
    repo:   "chetscmd/Hover-Tooltips-Obsidian"

    html_url:    "https://community.obsidian.md/plugins/hover-tooltips"
    github_url:  "https://github.com/chetscmd/Hover-Tooltips-Obsidian"
    description: "Adds custom tooltips on hover. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add interactive hover tooltips with full Markdown support for bold, italic, inline code, highlights and links. Hover to view descriptions, left-click to pin tooltips, and create tips using the {/{word/description}/} syntax with clickable internal [[wiki]] and external links."

    stats: {
        downloads:  318
        updated_at: 1782681941000
    }
}
```
