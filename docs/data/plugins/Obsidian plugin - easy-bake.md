# Easy Bake

Compiles several notes into a single document by recursively expanding links and embeds that stand on their own line. Inline links are replaced by their display text, and the content of the linked files is pulled into the compiled document.

```cue
plugin: {
    id:     "easy-bake"
    name:   "Easy Bake"
    author: "obsidian-community"
    repo:   "obsidian-community/obsidian-easy-bake"

    html_url:    "https://community.obsidian.md/plugins/easy-bake"
    github_url:  "https://github.com/obsidian-community/obsidian-easy-bake"
    description: "Easily compile many notes down to a single file."
    about:       "Compile notes into larger documents by recursively expanding links and embeds that appear on their own line. Replace inline links with their display text and include content from linked files in the final document."

        downloads:  11377

}
```
