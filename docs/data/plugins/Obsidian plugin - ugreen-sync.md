# UGREEN NAS Sync

Syncs the whole vault with a UGREEN NAS running UGOS Pro, addressed either by a direct UGOS URL or by a UGREENlink ID. The recorded text recommends the UGREENlink ID as the option needing the least setup, and describes automatic syncing as best-effort.
