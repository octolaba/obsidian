# Upcoming

Upcoming and past daily notes are opened in their own panes, tabs or windows for planning ahead. The sequence starts from the active daily note, or from today when no daily note is active. A single action closes every daily note opened this way.

```cue
plugin: {
    id:     "obsidian-upcoming"
    name:   "Upcoming"
    author: "charliecm"
    repo:   "charliecm/obsidian-upcoming"

    html_url:    "https://community.obsidian.md/plugins/obsidian-upcoming"
    github_url:  "https://github.com/charliecm/obsidian-upcoming"
    description: "Open upcoming daily notes in their own panes."
    about:       "Open upcoming and past daily notes in separate panes, tabs, or windows to view and plan ahead. Start the sequence from the active daily note or from today when no daily note is active. Close all previously opened daily notes with a single action."

}
```
