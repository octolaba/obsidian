# Places - Nominatim

Searches places and points of interest through Nominatim and OpenStreetMap, returning place suggestions with coordinates and resolving coordinates back to addresses. It supplies search data only and renders no maps, so its results are used with any map provider.

    about:       "Search places and POIs via Nominatim/OpenStreetMap to return place suggestions with coordinates. Resolve coordinates to addresses and use results with any map provider, as the plugin provides search-only data without rendering maps."
