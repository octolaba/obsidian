# Alignment Tracker

Tracks a character's alignment by tallying Lawful, Chaotic, Good and Evil actions on two axes. An alignmenttracker block increments the counts and generates a 3x3 grid showing the character's perceived alignment.

    id:     "alignment-tracker"
    name:   "Alignment Tracker"
