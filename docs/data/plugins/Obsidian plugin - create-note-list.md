# Create List of Notes

Create List of Notes builds a bulleted list of the notes in the current note's parent folder and inserts it at the cursor. The list can cover files, folder notes or both, be sorted A to Z or Z to A, and optionally include only notes whose titles begin with a YYYY-MM-DD date, which suits tables of contents.

```cue
plugin: {
    id:     "create-note-list"
    name:   "Create List of Notes"
    author: "andrewheekin"
    repo:   "andrewheekin/obsidian-create-note-list"

    html_url:    "https://community.obsidian.md/plugins/create-note-list"
    github_url:  "https://github.com/andrewheekin/obsidian-create-note-list"
    description: "Creates a bulleted list of notes contained within the parent folder and prepends to current note content after YAML frontmatter."
    about:       "Create a bulleted list of notes from the current note's parent folder at the cursor position. List files, folder notes, or both; sort A–Z or Z–A and optionally include only notes whose titles start with YYYY-MM-DD for quick tables of contents."

    stats: {
        downloads:  2087
        updated_at: 1715174923000
    }
}
```
