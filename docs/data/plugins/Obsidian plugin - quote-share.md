# Quote Share

Generates gradient images from text by dropping the text onto the gradient, then copies them to the clipboard for pasting into a note or into Twitter. The recorded About additionally states that a website can be embedded directly into a note to display live web content inline, which the recorded description does not mention.

```cue
plugin: {
    id:     "quote-share"
    name:   "Quote Share"
    author: "nguyenvanduocit"
    repo:   "nguyenvanduocit/quote-share"

    html_url:    "https://community.obsidian.md/plugins/quote-share"
    github_url:  "https://github.com/nguyenvanduocit/quote-share"
    description: "Easily generate beautiful gradient images from text and share them on social media."
    about:       "Embed any website directly into Obsidian notes to display live web content inline. Generate gradient images from text by dropping text onto the gradient and copy them to the clipboard for pasting into notes or Twitter."

    stats: {
        downloads:  5096
        updated_at: 1675621873000

}
```
