# Pinup

Pinup adds two pinning modes to the File Explorer. Pin moves an item above its unpinned siblings inside the same folder, while Pin up places it on a compact shelf below the File Explorer toolbar and keeps its entry in the tree. Multiple pins are held in a deterministic order, and the recorded inputs state that files, folders, note content and frontmatter are not modified.
