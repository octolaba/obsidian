# Spoilers

Blocks of content are hidden behind spoiler controls that show and hide them inline. A block holds plain text, Markdown or environment variables, and copy buttons take either the whole content or an individual key or value.

```cue
plugin: {
    id:     "spoilers"
    name:   "Spoilers"
    author: "jacobtread"
    repo:   "jacobtread/obsidian-spoilers"

    html_url:    "https://community.obsidian.md/plugins/spoilers"
    github_url:  "https://github.com/jacobtread/obsidian-spoilers"
    description: "Hide and reveal blocks of information"
    about:       "Create hidable spoiler blocks to hide and reveal content inline. Use plain-text, markdown, or env-variable blocks with show/hide controls and copy buttons, and copy full content or individual keys/values."

    stats: {

}
```
