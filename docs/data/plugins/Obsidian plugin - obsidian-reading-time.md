# Reading Time

This plugin adds the current note's estimated reading time to the status bar. The estimate updates automatically when notes are switched, so the reading time shown always belongs to the active note.

```cue
plugin: {
    id:     "obsidian-reading-time"
    name:   "Reading Time"
    author: "avr"
    repo:   "avr/obsidian-reading-time"

    html_url:    "https://community.obsidian.md/plugins/obsidian-reading-time"
    github_url:  "https://github.com/avr/obsidian-reading-time"
    description: "Add the current note's reading time to the status bar."
    about:       "Display an estimated reading time for the active note in the status bar. Update the estimate automatically when switching notes so you always see how long a note will take to read."

    stats: {
        downloads:  107833
        updated_at: 1725068071000
    }
}
```
