# Power Extract

Reads text inside images with the OCR built into Windows, running locally through a PowerShell worker with no uploads, downloads or account. The extracted text is handed to other plugins and commands so screenshots become searchable, and text can be copied from any image through the context menu or the command palette.

```cue
plugin: {
    id:     "powerextract"
    name:   "Power Extract"
    author: "Power Plugins"
    repo:   "obsidian-power-plugins/power-extract"

    html_url:    "https://community.obsidian.md/plugins/powerextract"
    github_url:  "https://github.com/obsidian-power-plugins/power-extract"
    description: "Read the text inside images so other plugins can search it. Uses the OCR built into Windows, so nothing is downloaded and no image ever leaves your device. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Read text inside images using Windows' built-in OCR with no uploads, downloads, or accounts—everything runs locally. Hand extracted text to other plugins and commands so screenshots become searchable, and copy text from any image via the context menu or command palette while processing runs through a local PowerShell worker."

    stats: {
        downloads:  75

    }
}
```
