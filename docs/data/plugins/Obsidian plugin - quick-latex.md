# Quick Latex

Speeds up typing LaTeX math by auto-closing single and double dollar delimiters and placing the cursor between them. Shorthands expand into Greek letters and into custom sequences, alignment ampersands are inserted automatically inside align blocks, and Tab jumps out of align, matrix and cases environments.
