# Reference Map

Builds a reference and citation map for literature review from the citations detected in a document. A sidebar shows index cards and searchable lists of citing and cited works, online search creates or inserts reference details, and an interactive graph visualizes the citing and cited relationships.

```cue
plugin: {
    id:     "reference-map"
    name:   "Reference Map"
    author: "anoopkcn"
    repo:   "anoopkcn/obsidian-reference-map"

    html_url:    "https://community.obsidian.md/plugins/reference-map"
    github_url:  "https://github.com/anoopkcn/obsidian-reference-map"
    description: "Reference and citation map for literature review and discovery."
    about:       "Manage and explore references and citations from a sidebar that shows index cards and searchable lists of citing/cited works detected in your document. Search online to create or insert reference details and visualize relationships with an interactive graph of citing/cited connections."
```
