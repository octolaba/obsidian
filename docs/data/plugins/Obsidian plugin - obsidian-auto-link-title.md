# Auto Link Title

Auto Link Title fetches the titles of links from the web when a URL is pasted and inserts them as Markdown links carrying the correct title. A command converts an existing raw URL the same way, or replaces the text of an existing Markdown link with the fetched title.

```cue
plugin: {
    id:     "obsidian-auto-link-title"
    name:   "Auto Link Title"
    author: "zolrath"
    repo:   "zolrath/obsidian-auto-link-title"

    html_url:    "https://community.obsidian.md/plugins/obsidian-auto-link-title"
    github_url:  "https://github.com/zolrath/obsidian-auto-link-title"
    description: "Automatically fetches the titles of links from the web."
    about:       "Fetch webpage titles for pasted URLs and insert them as Markdown links with the correct title. Convert existing raw URLs or replace the text of existing Markdown links with fetched titles via a command."

    stats: {
        downloads:  369535
        updated_at: 1733348135000
    }
}
```
