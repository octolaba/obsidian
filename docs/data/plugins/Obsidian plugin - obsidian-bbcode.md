# BBCode Convertor

BBCode Convertor converts Markdown files to BBCode for posting on forums. A single command from the command palette copies the converted BBCode to the clipboard.

```cue
plugin: {
    id:     "obsidian-bbcode"
    name:   "BBCode Convertor"
    author: "salockhart"
    repo:   "salockhart/obsidian-bbcode"

    html_url:    "https://community.obsidian.md/plugins/obsidian-bbcode"
    github_url:  "https://github.com/salockhart/obsidian-bbcode"
    description: "Convert Markdown files to BBCode."
    about:       "Convert Markdown notes to BBCode for posting on forums. Copy the converted BBCode to the clipboard with a single command from the command palette."

        downloads:  4447
```
