# Group Snippets

Organizes CSS snippets into named groups that are activated in one click or by command. Groups are linked to themes and to light or dark schemes so that matching snippets are enabled automatically when the theme or the device changes between phone, tablet and desktop.

```cue
plugin: {
    id:     "obsidian-group-snippets"
    name:   "Group Snippets"
    author: "Mara"
    repo:   "mara-li/obsidian-group-snippets"

    html_url:    "https://community.obsidian.md/plugins/obsidian-group-snippets"
    github_url:  "https://github.com/mara-li/obsidian-group-snippets"
    description: "Create folder of snippets to activate them in one click!"
    about:       "Organize CSS snippets into named groups and toggle entire groups with a single click or command. Link groups to themes and light/dark schemes to auto-enable matching snippets when switching themes or devices (phone/tablet/desktop)."
```
