# Seafile Sync Improved

Syncs notes across devices through Seafile, with realtime notifications and an automatic fallback to periodic sync. Authentication is token-based, a shared seafile-ignore file controls what is skipped, uploads and downloads are verified and preserve conflicts, and large syncs use accelerated transfers. Progress and status are reported in detail on desktop and mobile.
