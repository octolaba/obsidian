# Auto Template Trigger

Auto Template Trigger applies a template when a note is created and shows a selector when more than one template matches. Templates are assigned to folders, the most specific folder path taking precedence, and the prompt can be disabled so the folder-specific template is always used.

```cue
plugin: {
    id:     "auto-template-trigger"
    name:   "Auto Template Trigger"
    author: "numeroflip"
    repo:   "numeroflip/obsidian-auto-template-trigger"

    html_url:    "https://community.obsidian.md/plugins/auto-template-trigger"
    github_url:  "https://github.com/numeroflip/obsidian-auto-template-trigger"
    description: "Automatically prompt for a template, when creating a note."
    about:       "Apply templates automatically to new notes and show a template selector when multiple templates match. Assign templates to folders so the most specific folder path takes precedence, or disable prompts to always use folder-specific templates."

    stats: {
        downloads:  39302

}
```
