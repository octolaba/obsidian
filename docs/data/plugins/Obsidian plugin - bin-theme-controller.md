# Theme Controller

Theme Controller decides when and how themes are displayed in Obsidian. A theme and its colors are applied automatically based on a note's path or its tags, light and dark mode is toggled from a status-bar switch, and a fallback default theme covers notes that match no rule.

    id:     "bin-theme-controller"
