# WeChat Article Composer

Generates a WeChat Official Account layout preview for the current note in Obsidian, together with a cover image and inline illustrations, and publishes the article into the account's draft box. Several layout and illustration styles are offered, and the plugin plans where the illustrations go, how many there are and how they are arranged. Individual images can be regenerated or deleted, and a language model and an image-generation model can be connected so illustrations and text stay consistent.

```cue
plugin: {
    id:     "wechat-article"
    name:   "WeChat Article Composer"
    author: "frankl1u"
    repo:   "frankl1u/wechat-article-obsidian"

    html_url:    "https://community.obsidian.md/plugins/wechat-article"
    github_url:  "https://github.com/frankl1u/wechat-article-obsidian"
    description: "基于当前笔记预览公众号样式、生成配图并发布到微信公众号草稿箱. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "生成公众号排版预览、封面与正文配图，并将文章发布到微信公众号草稿箱。选择多种排版与配图风格，自动规划插图位置、数量与视觉结构，支持单图重生成与删除，并可接入 LLM 与生图模型提升配图与文稿一致性。"

    stats: {
```
