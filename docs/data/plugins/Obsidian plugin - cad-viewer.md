# CAD Viewer

CAD Viewer previews DXF and DWG drawings inside notes through an embedded WebGL viewer that renders in place and supports pan, zoom and layer-aware rendering. DWG files are read via LibreDWG parsing, so drawings can be inspected without leaving Obsidian. The recorded inputs state that it is desktop only and based on mlightcad/cad-viewer.
