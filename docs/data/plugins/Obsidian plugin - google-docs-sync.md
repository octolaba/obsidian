# Google Docs Sync

Publishes a single note as a Google Doc and keeps the two in two-way sync, so collaborators can edit it without the author leaving Obsidian. Local changes are pushed and remote edits pulled, and conflicting edits are marked with inline merge markers rather than being overwritten silently.
