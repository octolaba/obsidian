# Slackify Note

Slackify Note converts an entire note, or the current selection, into Slack-compliant Markdown. The converted text is copied to the clipboard for quick pasting into Slack.

```cue
plugin: {
    id:     "slackify-note"
    name:   "Slackify Note"
    author: "jeremyoverman"
    repo:   "jeremyoverman/obsidian-slackify-note"

    html_url:    "https://community.obsidian.md/plugins/slackify-note"
    github_url:  "https://github.com/jeremyoverman/obsidian-slackify-note"
    description: "Convert a note to Slack-compliant Markdown."
    about:       "Convert an entire note or the current selection to Slack-compliant Markdown. Copy the converted text to the clipboard for quick pasting into Slack."

    stats: {
```
