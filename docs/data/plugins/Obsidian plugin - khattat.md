# Khattat

Supports handwriting and annotation directly inside Markdown notes, with fountain, calligraphy, marker and pencil pens, adjustable stroke smoothing, ruled lines and pan and zoom drawing tools. Handwriting can be extracted to editable text through MyScript or Google Cloud Vision OCR. Auto-save, full undo and redo, and stylus pressure and angle are supported.
