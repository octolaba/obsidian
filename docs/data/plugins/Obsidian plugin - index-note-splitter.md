# Index Note Splitter

Splits a long note into linked section notes and turns the source note into an index of links to them. The split works on a selection or on H1 to H4 headings, names notes from headings or first lines, copies the YAML into each and preserves heading levels. Originals are replaced by links, and backlinks plus sequential Next links are added.

```cue
plugin: {
    id:     "index-note-splitter"
    name:   "Index Note Splitter"
    author: "michellegdyason"
    repo:   "michellegdyason/index-note-splitter"

    html_url:    "https://community.obsidian.md/plugins/index-note-splitter"
    github_url:  "https://github.com/michellegdyason/index-note-splitter"
    description: "Split long notes into linked section notes and turn the source note into an index. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Extract selected text or split a note by H1–H4 headings into new linked notes and turn the source into an index of links. Name notes from headings or first lines, copy YAML into each, preserve heading levels, replace originals with links, and add backlinks plus sequential Next links."
```
