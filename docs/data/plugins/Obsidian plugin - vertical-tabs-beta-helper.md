# Vertical Tabs Beta Helper

The plugin manages beta versions of Vertical Tabs from inside Obsidian. Beta builds can be installed, updated and validated without leaving the app.

    id:     "vertical-tabs-beta-helper"
    name:   "Vertical Tabs Beta Helper"
    author: "oxdc"
    repo:   "oxdc/obsidian-vertical-tabs-beta-helper"
