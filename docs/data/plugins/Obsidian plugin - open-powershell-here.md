# Open PowerShell Here

Opens PowerShell 7 or newer at the vault root or at any single folder, from a left-ribbon button or the folder context menu in the file explorer. Sessions run a verified pwsh.exe hosted in Windows Terminal, with the chosen folder as the working directory. It is limited to Windows.

```cue
plugin: {
    id:     "open-powershell-here"
    name:   "Open PowerShell Here"
    author: "Ethan Fu"
    repo:   "ethanffu/open-powershell-here"

    html_url:    "https://community.obsidian.md/plugins/open-powershell-here"
    github_url:  "https://github.com/ethanffu/open-powershell-here"
    description: "Open PowerShell 7+ at the vault root or any folder (Windows only). - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open PowerShell 7+ at the vault root or any single folder from Obsidian using a left-ribbon button or file-explorer folder context menu. Launch verified pwsh.exe sessions hosted in Windows Terminal with the chosen folder set as the working directory."

    stats: {
        downloads:  9
        updated_at: 1786339542000
    }
}
```
