# Font Size Adjuster

Adjusts the editor font size through Increment and Decrement commands. The size can be changed from hotkeys or the command palette without affecting other parts of the interface.

    id:     "font-size"
    name:   "Font Size Adjuster"
    author: "ryotaushio"
    repo:   "ryotaushio/obsidian-font-size"
