# Reveal Hidden Files

Reveal Hidden Files shows dot-prefixed files and folders in the File Explorer panel, exposing entries such as .obsidian, .env and .DS_Store. Visibility is controlled by a toggle together with a per-pattern deny list written in gitignore-style patterns, and the defaults keep heavy folders such as .git and .venv hidden.

```cue
plugin: {
    id:     "reveal-hidden-files"
    name:   "Reveal Hidden Files"
    author: "Josip Markus"
    repo:   "josipmarkus/obsidian-reveal-hidden-files"

    html_url:    "https://community.obsidian.md/plugins/reveal-hidden-files"
    github_url:  "https://github.com/josipmarkus/obsidian-reveal-hidden-files"
    description: "Reveal dot-prefixed files and folders in the File Explorer panel, with a per-pattern deny list. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Show dot-prefixed files and folders in the File Explorer to reveal hidden entries like .obsidian, .env, and .DS_Store. Manage visibility with a toggle and a per-pattern deny list using gitignore-style patterns; defaults keep heavy folders like .git and .venv hidden."

    stats: {
        downloads:  258

    }
}
```
