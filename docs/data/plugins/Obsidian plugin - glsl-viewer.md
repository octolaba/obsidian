# GLSL Viewer

Previews GLSL shaders inside Obsidian with Shadertoy-compatible syntax so shaders can be ported. Vault images can be loaded as iChannel textures and browsed visually, and templates reduce the amount of shader code that has to be written. Thumbnails are generated, and canvas aspect, autoplay and code visibility are configurable.
