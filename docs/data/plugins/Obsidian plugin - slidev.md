# Slidev

Slidev previews Markdown presentations inside Obsidian by starting a local Node.js Slidev server and rendering them live. Existing Slidev projects, themes, addons and components can be used with notes kept in the vault. It is recorded as working on desktop Obsidian and requiring Node.js 20.12 or later together with a local Slidev command-line tool.
