# Adapt to Current View

Adapt to Current View sets a different accent color for Reading view, Live Preview and Source view. The color makes the current mode recognizable at a glance, which avoids editing in Reading view or expecting Live Preview behavior in the wrong mode.

```cue

    id:     "adapt-to-current-view"
    name:   "Adapt to Current View"
    author: "churnish"
    repo:   "churnish/adapt-to-current-view"
```
