# Graph Chat

Opens the vault as an interactive graph in which clicking a note spawns an AI chat that reads that note and its linked neighborhood, backed by a local Claude Code CLI. Conversations can be branched into diverging threads, and every chat is saved as a real Markdown note. Notes can be linked by dragging, the view pans and zooms, clusters can be collapsed, and node positions persist.
