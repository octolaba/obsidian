# Change Case

Change Case rewrites the case of the current selection through commands for lower, UPPER, camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE, Sentence case, Train-Case, dot.case and path/case among others. Multiple selections are changed inside a single undoable transaction, and a selection modal offers the available actions with locale-aware casing.

```cue
plugin: {
    id:     "change-case"
    name:   "Change Case"
    author: "dbrockman"
    repo:   "dbrockman/obsidian-change-case"

    html_url:    "https://community.obsidian.md/plugins/change-case"
    github_url:  "https://github.com/dbrockman/obsidian-change-case"
    description: "Change the case (UPPER CASE, camelCase, snake_case, etc) of the current selection."
    about:       "Change the case of selected text with commands for lower, UPPER, camelCase, PascalCase, snake_case, kebab-case, CONSTANT_CASE, Sentence case, Train-Case, dot.case, path/case and more. Apply changes to multiple selections in a single undoable transaction and pick actions from a selection modal with locale-aware casing."
```
