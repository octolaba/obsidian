# Image Grid

Image Grid renders images in a responsive CSS grid defined by image-grid fenced code blocks. Columns, gap and per-image maximum width are set with inline options or a pipe syntax, and an image opens in a fullscreen lightbox.

```cue

    id:     "image-grid"
    name:   "Image Grid"
    author: "skydiver"
    repo:   "skydiver/obsidian-image-grid"

    github_url:  "https://github.com/skydiver/obsidian-image-grid"
```
