# Enhanced Annotations

Adds a sidebar view listing the comments and highlights of the active file. Notes are created from a comment or highlight through the editor context menu, comments are copied from files selected in the file explorer, labels such as todo can be given their own styles, and a trigger phrase inserts a labeled comment.

```cue
plugin: {
    id:     "enhanced-annotations"
    name:   "Enhanced Annotations"
    author: "ycnmhd"
    repo:   "ycnmhd/obsidian-enhanced-annotations"

    html_url:    "https://community.obsidian.md/plugins/enhanced-annotations"
    github_url:  "https://github.com/ycnmhd/obsidian-enhanced-annotations"
    description: "Add a sidebar view for comments and highlights."
    about:       "Explore comments and highlights from the active file in a dedicated sidebar view. Create notes from comments/highlights via the editor context menu, copy comments from selected files via the file-explorer menu, assign custom styles by label (e.g., <!--todo: ...-->), and insert labeled comments with a trigger phrase."

    stats: {
        downloads:  17520

}
```
