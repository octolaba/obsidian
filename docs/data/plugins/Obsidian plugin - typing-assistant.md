# Typing Assistant

Offers several shortcut menus intended to make input faster. A slash-activated command menu opens at the cursor and inserts different line types, while a selection menu applies or switches Markdown styles. Link-based cards can be generated, and custom command sets are ordered by drag-and-drop and found by search.
