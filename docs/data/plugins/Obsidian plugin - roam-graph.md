# Roam Graph

Roam Graph keeps a focus-following local graph in the right sidebar that tracks the active Markdown note. Backlinks are placed to the left, outgoing links to the right, and nearby daily notes above and below where applicable. The graph is written as a real Obsidian Canvas file with native nodes and links, so its nodes are clickable for navigation while writing.
