# CodeSplash Themes

CodeSplash Themes creates and manages custom color themes through a visual editor with live preview. A two-layer color palette is defined and its variables are assigned to semantic interface elements; built-in themes can be edited, duplicated, renamed or deleted, themes import and export as JSON, and switching between them is immediate.
