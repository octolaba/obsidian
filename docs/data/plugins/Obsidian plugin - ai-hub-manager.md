# AI Hub Manager

AI Hub Manager aggregates more than twenty AI assistants in a tabbed interface with drag-to-scroll switching. Supported assistants are embedded and the others open in popups, models can be added, edited, removed and reordered, one or all can be refreshed, the tab bar can be hidden, and the interface switches between English and Chinese.
