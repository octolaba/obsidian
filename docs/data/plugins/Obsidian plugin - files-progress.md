# Files Progress

Files Progress draws a small horizontal progress bar under each Markdown file in the file explorer, showing how full the note is relative to a target character count. The bars are rendered inside the native rows with theme-aware colors running from red through yellow to green, with an optional purple for overflow. They update live as the files change.

```cue
plugin: {
    id:     "files-progress"
    name:   "Files Progress"
    author: "Sonna"
    repo:   "sonna-io/obsidian-files-progress"

    html_url:    "https://community.obsidian.md/plugins/files-progress"
    github_url:  "https://github.com/sonna-io/obsidian-files-progress"
    description: "Tiny progress bars in the file explorer showing how full each note is, relative to a target character count. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Show a tiny horizontal progress bar under each Markdown file in the file explorer to indicate note fullness relative to a target character count. Render bars inside native rows with theme-aware colors (red→yellow→green, optional purple for overflow) and update live as files change."

    stats: {
        downloads:  74
        updated_at: 1784234001000
    }
}
```
