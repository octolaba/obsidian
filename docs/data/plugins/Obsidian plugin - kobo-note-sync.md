# Kobo Note Sync

Imports highlights and annotations from the Kobo Desktop App's SQLite database into Markdown notes. Note and highlight output is rendered through Eta.js templates, and sync is append-only so existing highlights are kept. Book and highlight metadata is included, and the plugin states support for macOS and Windows with English and Traditional Chinese interfaces.

plugin: {
    id:     "kobo-note-sync"
    name:   "Kobo Note Sync"

    html_url:    "https://community.obsidian.md/plugins/kobo-note-sync"
    github_url:  "https://github.com/kennkyou/obsidian-kobo-note-sync"

Apply Eta.js note and highlight templates, keep existing highlights with append-only sync, and include rich book/highlight metadata (macOS & Windows; English/Traditional Chinese)."
