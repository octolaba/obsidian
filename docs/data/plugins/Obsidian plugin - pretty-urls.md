# Pretty URLs

Improves how URLs are displayed in reading view by removing common prefixes and subdomains, among them the http and https protocols and the www, m, mobile and amp prefixes. The note content and the link targets are left unchanged, so only the displayed link text becomes shorter.

```cue
plugin: {
    id:     "pretty-urls"
    name:   "Pretty URLs"
    author: "daun"
    repo:   "daun/obsidian-pretty-urls"

    html_url:    "https://community.obsidian.md/plugins/pretty-urls"
    github_url:  "https://github.com/daun/obsidian-pretty-urls"
    description: "Improve display of URLs in reading view by removing https:// and www. prefixes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Strip common URL prefixes in reading view, removing protocols and subdomains such as http://, https://, www., m., mobile., and amp. Keep original note content and link targets unchanged while showing cleaner, shorter link text."

    stats: {
        downloads:  265
        updated_at: 1779022857000
    }
}
```
