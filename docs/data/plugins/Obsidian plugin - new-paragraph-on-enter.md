# New Paragraph on Enter

New Paragraph on Enter makes a single Enter press insert a double newline, so one keystroke starts a new paragraph. Shift+Enter still produces a single line break, and lists, tasks, tables and code blocks are left unaffected.

```cue
plugin: {
    id:     "new-paragraph-on-enter"
    name:   "New Paragraph on Enter"
    author: "biigfish"
    repo:   "biigfish/new-paragraph-on-enter"

    html_url:    "https://community.obsidian.md/plugins/new-paragraph-on-enter"
    github_url:  "https://github.com/biigfish/new-paragraph-on-enter"
    description: "Create a new paragraph by pressing the enter key once. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert a double newline when pressing Enter to create paragraphs with a single keystroke. Use Shift+Enter for a single line break and keep lists, tasks, tables, and code blocks unaffected."

    stats: {
        downloads:  140
        updated_at: 1770933740000
    }
}
```
