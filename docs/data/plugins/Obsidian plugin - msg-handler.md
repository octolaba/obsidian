# MSG Handler

Displays and searches Outlook .msg and .eml files inside the vault through a custom file view and a matching search panel. Messages are indexed for fast queries and shown with headers, plain-text body and attachments. Images render behind a toggle and non-image attachments can be saved into the vault.
