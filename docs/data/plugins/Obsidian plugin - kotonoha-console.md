# Kotonoha Console

Drives Kotonoha review-destination workflows and RDE outputs from inside Obsidian, covering proposal, RDE audit and human approval. RDE review summary blocks can be copied or inserted into notes, copy-ready GitHub issue drafts generated from RDE categories, and issue or pull-request references parsed as correlation metadata. It talks to either a local CLI or an HTTP orchestrator backend, for local-first work or model-generated proposals.
