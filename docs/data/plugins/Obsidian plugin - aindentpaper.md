# AindentPaper

Adds first-line paragraph indentation in preview to match Chinese typography, and controls paragraph spacing and line height. Paragraphs broken by line-break tags are split into separate paragraphs so the spacing applies to each, while headings, lists, code blocks, tables and whiteboard areas are skipped. Paper-texture backgrounds are available in kraft, white, parchment, textured, grid or none, with dark-mode adaptation.
