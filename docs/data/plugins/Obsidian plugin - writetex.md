# WriteTex

Connects the WriteTex mobile app to Obsidian through a local proxy and inserts its OCR output — LaTeX, TikZ or Markdown — at the cursor. Surrounding text is sent along for context-aware recognition, the app is discovered on the local network over mDNS, and generated code is streamed as it arrives.

```cue

    id:     "writetex"
    name:   "WriteTex"
    author: "jacklitstar"

    github_url:  "https://github.com/jacklitstar/writetex-obsidian"
    description: "Use WriteTex to write math on tablet. - This plugin has not been manually reviewed by Obsidian staff."

Send surrounding text for context-aware recognition, auto-discover the app on your network via mDNS, and stream the generated code as it appears."
