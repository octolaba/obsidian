# Vault Audit AI

Connects large language models — OpenRouter, Ollama, OpenAI, Groq or a custom endpoint — to the vault for generating, analyzing and rewriting text, including batch processing over filtered notes. A two-phase MapReduce audit finds orphan notes, recommends tags and links, and clusters topics. Results export as Markdown reports carrying Dataview links.
