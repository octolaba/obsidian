# PDF Highlights

Extracts highlighted and underlined text from PDFs into Markdown notes in the vault. Page numbers and highlight colors are optional, and links back to the source PDF are created for quick reference.

```cue
plugin: {
    id:     "obsidian-extract-pdf-highlights"
    name:   "PDF Highlights"
    author: "akaalias"
    repo:   "akaalias/obsidian-extract-pdf-highlights"

    html_url:    "https://community.obsidian.md/plugins/obsidian-extract-pdf-highlights"
    github_url:  "https://github.com/akaalias/obsidian-extract-pdf-highlights"
    description: "Extract highlights, underlines and annotations from your PDFs."
    about:       "Extract highlighted and underlined text from PDFs into Markdown notes in your Obsidian vault. Include optional page numbers, highlight colors, and create links back to the source PDF for quick reference."

    stats: {

}
```
