# Fastimer

Fastimer tracks intermittent fasting through a fastimer code block showing elapsed time, remaining time, a progress bar and fasting-zone milestones. A fast is started or ended by adding a timestamp or a duration, and the block updates each time the note renders.

```cue
plugin: {
    id:     "fastimer"
    name:   "Fastimer"
    author: "vkostyanetsky"
    repo:   "vkostyanetsky/ObsidianFastimer"

    html_url:    "https://community.obsidian.md/plugins/fastimer"
    github_url:  "https://github.com/vkostyanetsky/ObsidianFastimer"
    description: "Intermittent fasting tracker."
    about:       "Track fasting sessions with a fastimer code block that shows elapsed time, remaining time, a progress bar, and fasting-zone milestones. Start or end fasts by adding timestamps or a duration and watch the block update each time the note renders."

    stats: {
        downloads:  2014
        updated_at: 1717430136000
    }
}
```
