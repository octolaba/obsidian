# Hexmap World Creator

Hexmap World Creator builds an interactive hex-grid world in the vault and attaches terrain, locations, paths and notes to each hex. Terrain is painted, styled paths are drawn, town, dungeon and feature notes are linked, and weighted random tables can be rolled. Every hex is also a Markdown file that can be browsed or edited in a spreadsheet, and the recorded description calls the toolbox system agnostic.
