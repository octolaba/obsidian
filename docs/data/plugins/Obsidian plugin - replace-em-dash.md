# Replace Em Dash

Replace Em Dash converts two consecutive hyphens into an em dash as the text is typed. The recorded text presents this as inline punctuation conversion that does not interrupt editing.

```cue
plugin: {
    id:     "replace-em-dash"
    name:   "Replace Em Dash"
    author: "joaonoturno"
    repo:   "joaonoturno/Em-dash-plugin"

    html_url:    "https://community.obsidian.md/plugins/replace-em-dash"
    github_url:  "https://github.com/joaonoturno/Em-dash-plugin"
    description: "Automatically replaces -- with — (em dash) - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Replace two consecutive hyphens with an em dash as you type. Convert punctuation inline without interrupting your editing flow."

    stats: {
        downloads:  193

    }
}
```
