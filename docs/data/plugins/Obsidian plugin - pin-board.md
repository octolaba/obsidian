# Pin Board

Pin Board shows the images and short videos of a chosen folder, or of the whole vault, as a Pinterest-style vertical masonry feed. A note can be attached to any pin, files are added by dragging them onto the board, and the board tab can be pinned so it stays visible while browsing.

```cue
plugin: {
    id:     "pin-board"
    name:   "Pin Board"
    author: "Rayvven"
    repo:   "rayvven/obsidian-pin-board"

    html_url:    "https://community.obsidian.md/plugins/pin-board"
    github_url:  "https://github.com/rayvven/obsidian-pin-board"
    description: "A Pinterest-style vertical scrolling board for the images and videos in a folder. Point it at a folder, scroll, and optionally attach a note to any pin. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display a Pinterest-style masonry feed of every image and short video from a chosen folder or the entire vault. Attach notes to pins, drag files onto the board to add them, and pin the board tab to keep it visible while browsing."

    stats: {
        downloads:  165
        updated_at: 1783481664000
    }
}
```
