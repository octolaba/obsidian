# Lock Cards

Locks selected Canvas cards so they cannot be moved or resized. Locked cards are marked visually and attempted moves or resizes are reverted, while holding Shift allows a locked card to be moved temporarily.

```cue
plugin: {
    id:     "lock-cards"
    name:   "Lock Cards"
    author: "erezak"
    repo:   "erezak/obsidian-lock-cards"

    html_url:    "https://community.obsidian.md/plugins/lock-cards"
    github_url:  "https://github.com/erezak/obsidian-lock-cards"
    description: "Lock selected Canvas cards to prevent moving and resizing. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Lock selected Canvas cards to prevent moving and resizing. Mark locked cards visually and revert attempted moves or resizes; hold Shift to temporarily move locked cards."
```
