# Asana Connect

Embeds, creates, searches and syncs Asana tasks inside notes, showing task name, assignee, due date, project and custom fields with a checkbox that completes or reopens the task. Single-task embeds and live task lists can be inserted, a My Tasks sidebar groups tasks by due status, and tasks can be created from selected text. The Asana token is stored encrypted locally.
