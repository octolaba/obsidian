# Mathify Notes

Mathify Notes rewrites raw text into typographic forms as soon as the space bar is pressed, converting fractions such as 1/2, chemistry such as H2O, roots written as sqrt(x) and Greek letter names into their symbol equivalents. Formulas, variables and symbols can therefore be written without typing LaTeX or wrapping the text in dollar signs.

```cue
plugin: {
    id:     "mathify-notes"
    name:   "Mathify Notes"
    author: "katananananna"
    repo:   "katananananna/obsidian-mathify-notes"

    html_url:    "https://community.obsidian.md/plugins/mathify-notes"
    github_url:  "https://github.com/katananananna/obsidian-mathify-notes"
    description: "Automatically converts 1/2 ➔ ½ (Fractions), H2O ➔ H₂O (Chemistry), sqrt(x) ➔ √x (Roots) and more - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Automatically converts raw text into beautiful formatting the moment you press Space: H2O ➔ H₂O (Chemistry) | 1/2 ➔ ½ (Fractions) | sqrt(x) ➔ √x (Roots) | pi ➔ π (Greek) Write formulas, variables, and symbols naturally without ever typing manual LaTeX or wrapping your text in dollar signs."

    stats: {
        downloads:  119

    }
}
```
