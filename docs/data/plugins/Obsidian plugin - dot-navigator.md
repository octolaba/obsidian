# Dot Navigator

Organizes notes in a Dendron-like hierarchical tree for navigating and managing a vault by hierarchy. Large vaults load through IndexedDB caching with mobile-first performance, and rule-based dotted-child suggestions scaffold the hierarchy, with a double-click creating a note from a suggestion.
