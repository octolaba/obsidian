# Window Collapse

Collapses the sidebars to reclaim screen space without switching to fullscreen. Separate commands toggle the left sidebar, the right sidebar, or both at once.

    id:     "window-collapse"
    name:   "Window Collapse"
    author: "gquental"
    repo:   "gquental/obsidian-window-collapse"

    html_url:    "https://community.obsidian.md/plugins/window-collapse"
