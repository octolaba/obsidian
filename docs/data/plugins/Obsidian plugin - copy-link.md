# Copy Link

Copy Link adds commands that copy a link to a file, a heading or a block from the file and editor context menus. It can produce wikilinks, embeds, footnote-wrapped links, anchor-only links and obsidian://open block URLs, and it creates or finds block identifiers for single or multi-block selections. The selection can optionally be used as the link caption.

```cue
plugin: {
    id:     "copy-link"
    name:   "Copy Link"
    author: "greetclammy"
    repo:   "greetclammy/copy-link"

    html_url:    "https://community.obsidian.md/plugins/copy-link"
    github_url:  "https://github.com/greetclammy/copy-link"
    description: "Add commands to copy link to file, heading or block. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Copy links to notes, headings, and blocks directly from file and editor context menus. Generate wikilinks, embeds, footnote-wrapped links, anchor-only links, obsidian://open block URLs, and auto-create or find block IDs for single or multi-block selections, with optional selection-as-caption."

    stats: {
        downloads:  725

    }
}
```
