# Hearth

Hearth is a customizable home screen that combines search, a dashboard and an application launcher. Its fuzzy search finds notes, tags, properties, file types and commands as you type, and can run on the Omnisearch engine instead for full-text ranking with snippets. The dashboard is built from drag-and-drop cards that embed notes, images, canvas, Excalidraw drawings and Bases, pin a Dataview query, host another plugin's view, or show web pages, the daily note, a mini calendar, an activity heatmap and vault statistics. A tasks card reads Markdown checkboxes or TaskNotes as a list or a Kanban board, cards move, resize and snap, and the recorded About states desktop and mobile support under an MIT licence.
