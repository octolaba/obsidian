# Zhongwen Block

Zhongwen Block annotates Chinese text inside code blocks with pronunciation shown as ruby text on hover: pinyin for a zh-cn block and jyutping for a zh-hk block. An option shows the pronunciations at all times instead, and the interface language can be set to English or Japanese.

```cue
plugin: {
    id:     "zhongwen-block"
    name:   "Zhongwen Block"
    author: "0918nobita"
    repo:   "0918nobita/obsidian-zhongwen-block"

    html_url:    "https://community.obsidian.md/plugins/zhongwen-block"
    github_url:  "https://github.com/0918nobita/obsidian-zhongwen-block"
    description: "Code blocks with features for Chinese learners."
    about:       "Annotate Chinese code blocks with pinyin (zh-cn) or jyutping (zh-hk) as ruby text that appears on hover. Enable an option to always show pronunciations and select English or Japanese UI."

    stats: {
        downloads:  4573
        updated_at: 1751892547000
    }
}
```
