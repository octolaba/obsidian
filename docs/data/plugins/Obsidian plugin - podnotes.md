# PodNotes

Plays podcasts inside Obsidian through a mobile-friendly player; shows are added by search or feed URL, episodes downloaded, and local audio files used for offline listening. Episode notes are created from templates with metadata, playback progress is tracked, and timestamped links capture moments in the audio. An API is exposed for automation with QuickAdd or Templater.
