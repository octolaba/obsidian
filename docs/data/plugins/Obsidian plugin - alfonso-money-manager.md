# Alfonso Money Manager

Syncs data from the Alfonso mobile app into the vault for expense and budget tracking. Reports are built with Alfonso Query Language (AQL) to filter, group and analyze the finances, and the results render as interactive ApexCharts charts inside Obsidian.
