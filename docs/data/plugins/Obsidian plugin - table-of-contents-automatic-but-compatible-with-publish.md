# TOC compatible with Publish

Creates a table of contents that remains present when the page is pushed to Publish. It is inserted at the top of the note or at the cursor. The recorded About text names settings for automatic or manual updating, the arrow type, and how entry text is displayed, including removing characters from it.

```cue
plugin: {
    id:     "table-of-contents-automatic-but-compatible-with-publish"
    name:   "TOC compatible with Publish"
    author: "brmaccath"
    repo:   "brmaccath/Table-of-Contents"

    html_url:    "https://community.obsidian.md/plugins/table-of-contents-automatic-but-compatible-with-publish"
    github_url:  "https://github.com/brmaccath/Table-of-Contents"
    description: "Creates a table of contents that is compatible with publish i.e. that if the page is pushed to publish the table of contents will still be there."
    about:       "Create a Publish-compatible table of contents at the top of a note or at the cursor. There are several features that the user can adjust in the settings tab to their desire. - Automatically or manual update. - Adjust arrow types - Adjust text display in the table of contents. - Remove characters in text display of table of contents."

    stats: {
        downloads:  1831
        updated_at: 1780581965000
    }
}
```
