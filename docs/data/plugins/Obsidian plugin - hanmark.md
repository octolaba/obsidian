# HanMark

Imports HWP, HWPX, PDF, DOCX and XLSX files into Markdown with a bundled offline parser, recording source metadata in frontmatter. HWP and DOCX files can be previewed side by side inside Obsidian. Notes can be exported back to HWP, DOCX or HTML through templates, while Markdown stays the canonical source.

    id:     "hanmark"
    name:   "HanMark"
