# Zotero Citations

Zotero Citations manages Zotero citations in Obsidian, inserting references through the Zotero picker or the plugin's own search with page and locator support. Footnote and endnote modes can be toggled, citations are shown Word-style as superscripts with hover preview and inline locator editing, and a formatted bibliography is generated. Export to .docx runs through Pandoc and preserves footnotes and endnotes.

```cue
plugin: {
    id:     "zotero-citations"
    name:   "Zotero Citations"
    author: "westerngua"
    repo:   "westerngua/obsidian-zotero-citations"

    html_url:    "https://community.obsidian.md/plugins/zotero-citations"
    github_url:  "https://github.com/westerngua/obsidian-zotero-citations"
    description: "Zotero citation management with Word export via Pandoc. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Manage Zotero citations in Obsidian and insert references via the Zotero picker or the plugin search with page/locator support. Toggle footnote or endnote modes, show Word-style superscript with hover preview and inline locator editing, generate a formatted bibliography, and export .docx via Pandoc while preserving footnotes/endnotes."
```
