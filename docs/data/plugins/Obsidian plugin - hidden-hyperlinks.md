# Ghost Text

Ghost Text hides a payload of text behind display text and copies the hidden text to the clipboard when it is clicked. Delimiters and separators are configurable, the payload can be shown on hover, and theme-aware notifications confirm that text was copied.

```cue
plugin: {
    id:     "hidden-hyperlinks"
    name:   "Ghost Text"
    author: "lawrencefeng17"
    repo:   "lawrencefeng17/obsidian-hidden-hyperlinks"

    html_url:    "https://community.obsidian.md/plugins/hidden-hyperlinks"
    github_url:  "https://github.com/lawrencefeng17/obsidian-hidden-hyperlinks"
    description: "Hide text behind display text and copy on click."
    about:       "Hide secret text behind display text and copy the hidden payload to the clipboard with a click. Configure custom delimiters and separators, show the payload on hover, and receive unobtrusive, theme-aware notifications when text is copied."

    stats: {
        downloads:  418

    }
}
```
