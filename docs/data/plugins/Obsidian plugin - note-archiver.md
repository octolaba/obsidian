# Note archiver

Note archiver moves notes into a designated archive folder, optionally grouping the archived files by year or by month. Archiving runs from the command palette or from the editor and file menus.

```cue
plugin: {
    id:     "note-archiver"
    name:   "Note archiver"
    author: "thenomadlad"
    repo:   "thenomadlad/obsidian-note-archiver"

    html_url:    "https://community.obsidian.md/plugins/note-archiver"
    github_url:  "https://github.com/thenomadlad/obsidian-note-archiver"
    description: "Tools to archive your notes in another folder."
    about:       "Archive notes to a designated folder. Group archived files by year or month and run archiving from the command palette or the editor and file menus."

    stats: {
        downloads:  6305
        updated_at: 1685915016000
    }
}
```
