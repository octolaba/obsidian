# Watermelon Workbench

A long-form writing workbench that leaves Markdown files plain while providing a typographically comfortable editor with auto-scroll and Chinese-style first-line indentation. Sibling chapters can be navigated from the workbench, names are generated locally without network access, and compact live statistics are shown while writing. Time Machine backups take snapshots that can be restored later.

```cue
plugin: {
    id:     "watermelon-workbench"
    name:   "Watermelon Workbench"
    author: "Lynn"
    repo:   "pan75291386-hue/watermelon-workbench"

    html_url:    "https://community.obsidian.md/plugins/watermelon-workbench"
    github_url:  "https://github.com/pan75291386-hue/watermelon-workbench"
    description: "A cozy novel-writing workbench for Obsidian with chapter navigation, local name generation, time-machine backups, and live writing stats. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open a focused long-form writing workbench that keeps Markdown files plain while providing a typographically comfortable editor with auto-scroll and Chinese-style first-line indentation. Navigate sibling chapters, generate names locally without network, view compact live stats, and restore snapshots with Time Machine backups."
}
```
