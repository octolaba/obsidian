# Local Backup

Creates local backups of the vault on startup, on quit, at intervals or on demand. Output paths are configurable, files and folders are included or excluded with wildcards, external archivers such as 7-Zip, WinRAR and Bandizip can be called, and failed backups are retried.

plugin: {
    id:     "local-backup"
    name:   "Local Backup"
    author: "velviagris"
    repo:   "velviagris/obsidian-local-backup"

    html_url:    "https://community.obsidian.md/plugins/local-backup"
    github_url:  "https://github.com/velviagris/obsidian-local-backup"
