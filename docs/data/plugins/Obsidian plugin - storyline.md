# StoryLine

The vault is arranged as a book planning workspace that organizes scenes, characters, locations and plotlines and tracks writing progress. A corkboard holds sticky notes and image pins, a board shows Kanban-style cards, and a spreadsheet-style plotgrid maps and arranges the material. Notes are converted into scenes, and the recorded description also lists a timeline view.
