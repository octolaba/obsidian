# AI Tag Curator

Recommends tags with AI that prefer tags already in use, explaining confidence and alternatives, and applies changes only after confirmation. A vault-level tag health report surfaces low-frequency and duplicate tags, hierarchy inconsistencies and naming drift, with prioritized actions and supporting evidence.
