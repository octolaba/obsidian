# Scales and Chords

Scales and Chords captures guitar and piano tab notation in fenced code blocks, and a chord line ending in a percent sign renders its chords as bold, clickable links in preview. Clicking a chord opens a modal with a visual diagram provided by scales-chords.com, all captured chords are stacked beneath the tab, and changing the instrument shows different diagrams.

```cue
plugin: {
    id:     "scales-chords"
    name:   "Scales and Chords"
    author: "egradman"
    repo:   "egradman/scales-chords"

    html_url:    "https://community.obsidian.md/plugins/scales-chords"
    github_url:  "https://github.com/egradman/scales-chords"

    about:       "Capture guitar and piano tabs in fenced code blocks; end chord lines with % to render chords as bold, clickable links in preview. Click a chord to open a modal with a visual diagram and view all captured chords stacked beneath the tab; change instrument to show different diagrams."
```
