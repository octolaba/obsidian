# AuraGraph

Replaces the visual graph canvas with a keyboard-first, screen-reader-friendly interface of three panes, aimed at blind note takers. A left deck holds curated notes, a center tree navigates from a dynamic root, and a right list shows incoming and outgoing links. Movement is announced through text-to-speech and marked with earcons.
