# Dainvo Task Manager

Synchronizes tasks from one or more vaults to the Dainvo calendar and task planner application over a localhost bridge. Each synchronized task keeps a link back to the note it was created on, and daily notes can be opened and edited from the Dainvo calendar. Dainvo itself is described as an external application that gathers task managers, calendars and meeting clients in one place.
