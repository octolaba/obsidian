# Group Tabs

Combines related files into a single native tab that shows the group name and member count and opens members in place, without creating extra previews. Groups are created and managed by drag-and-drop or File Explorer multi-select, large groups are searched and reordered in a virtualized popup, and a group can be expanded back into regular tabs. Recent groups are kept in a persistent left-sidebar history, and Markdown members can be exported as one file.
