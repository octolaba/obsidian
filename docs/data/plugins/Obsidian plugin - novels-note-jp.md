# Novels Note JP

Supports writing Japanese novels with a vertical-writing preview, ruby (furigana) insertion, emphasis dots, automatic paragraph indentation, and manuscript export. A novel mode is activated per note and scopes monospace fonts, line-wrap rulers, editing of .txt files, and category-based highlighting that marks tagged filenames as terms.
