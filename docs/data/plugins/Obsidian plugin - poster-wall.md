# Poster Wall

Displays tagged Markdown notes as a responsive grid of posters, where clicking a card opens the underlying note. Tag hierarchies, title and path search, and sorting by name or most recent edit are supported, and covers come from local files, HTTPS URLs or images imported from Finder. The grid follows vault changes live and needs neither Dataview nor an external media database.

    id:     "poster-wall"
