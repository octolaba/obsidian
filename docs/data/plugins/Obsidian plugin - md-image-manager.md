# Markdown Image Manager

Manages vault images with compression, a gallery browser, batch operations and uploads to remote hosting on Aliyun OSS, Qiniu, S3 or a custom target. Wiki image references are converted to standard Markdown, pasted images are uploaded automatically, orphan files are detected and cleaned, and renaming an image updates the references to it. Resources are organized by template.
