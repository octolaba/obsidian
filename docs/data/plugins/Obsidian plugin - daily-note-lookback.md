# Daily Note Lookback

Renders lookbacks of a chosen daily-note section from previous years, months or custom intervals, listing the selected offsets and showing whether an entry exists for each date. Rows stay collapsed until expanded, and each section is loaded on demand rather than embedded outright.

```cue
plugin: {
    id:     "daily-note-lookback"
    name:   "Daily Note Lookback"
    author: "Dylan Wright"
    repo:   "dyllonwright/Obsidian-Daily-Note-Lookback-Plugin"

    html_url:    "https://community.obsidian.md/plugins/daily-note-lookback"
    github_url:  "https://github.com/dyllonwright/Obsidian-Daily-Note-Lookback-Plugin"
    description: "Render lazy lookbacks of any daily-note section from previous years, months, or custom intervals — collapsed until expanded, far lighter than native embeds. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render a compact chrono-retrospection in daily notes that lists chosen offsets (years, months, days) and shows whether an entry exists for each date. Keep rows collapsed and cost-free until expanded, loading each section on demand so daily notes open instantly on desktop and phone."

    stats: {
        downloads:  55
        updated_at: 1783994173000
    }
}
```
