# Datacore

Indexes and queries Markdown notes through a Dataview-compatible index and renders the results with a React-based JavaScript API that updates live without flicker. Values are edited inline, tables are responsive and editable in place, pages, images and videos can be embedded in views, and queries reach section and block level across files and attachments. The project states a two to ten times speed improvement over its predecessor.
