# Snippetsaurus

Text and code snippets are created and managed from a modal, with a language specified for code snippets. A snippet is inserted into a note directly, or expanded automatically when its name is typed and followed by a space.

```cue
plugin: {
    id:     "obsnippets"
    name:   "Snippetsaurus"
    author: "chrstn67"
    repo:   "chrstn67/Snippetsaurus"

    html_url:    "https://community.obsidian.md/plugins/obsnippets"
    github_url:  "https://github.com/chrstn67/Snippetsaurus"
    description: "Create and managing text and code snippets."
    about:       "Create and manage text and code snippets with a user-friendly modal, specifying languages for code snippets. Insert snippets directly into notes or automatically expand a snippet when its name is typed and followed by a space."

    stats: {

}
```
