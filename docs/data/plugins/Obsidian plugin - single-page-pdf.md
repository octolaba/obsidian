# Single Page PDF Export

Exports a note as a single-page PDF with no page breaks, so the whole document sits on one continuous page at A4 width. The page height is calculated from the content, and the rendered output can be previewed before export. Obsidian's fonts are respected, and export runs from the file explorer or the Command Palette.

```cue
plugin: {
    id:     "single-page-pdf"
    name:   "Single Page PDF Export"
    author: "IO"
    repo:   "ilinuxio/obsidian-single-page-pdf"

    html_url:    "https://community.obsidian.md/plugins/single-page-pdf"
    github_url:  "https://github.com/ilinuxio/obsidian-single-page-pdf"
    description: "Export obsidian notes as single-page PDF without page breaks. Height is auto-calculated from content. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Export notes as a single-page PDF with no page breaks so the entire document prints on one continuous A4-width page. Calculate page height automatically based on content, preview the rendered output, and respect your Obsidian fonts. Export directly from the file explorer or via the Command Palette."

    stats: {
        downloads:  38

    }
}
```
