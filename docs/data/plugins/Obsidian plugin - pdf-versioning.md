# PDF versioning

Opens an embedded PDF in the default external editor for annotation while keeping several chronological versions of it inside Obsidian. A version picker detects and swaps between the saved variants and live-embeds the chosen file, and a vault-wide scan finds and removes outdated duplicates.

    id:     "pdf-versioning"

    author: "Andrea Salomone"
