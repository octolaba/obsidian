# Routine Streaks

Routine Streaks reads Daily Note checkboxes that carry a routine tag and marks a date complete when every matching item is checked. Progress appears in a sidebar dashboard or in embedded widgets, and iOS Scriptable widgets can be generated. Routines are managed with weekday schedules and streak freeze days.

```cue
plugin: {
    id:     "routine-streaks"
    name:   "Routine Streaks"
    author: "Taehyun A. Kim"
    repo:   "holyhooly/routine-streaks"

    html_url:    "https://community.obsidian.md/plugins/routine-streaks"
    github_url:  "https://github.com/holyhooly/routine-streaks"
    description: "Track routine streaks from tagged Daily Note tasks. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Track routine streaks by reading Daily Note checkboxes tagged like #routine/morning and marking a date complete when all matching items are checked. View progress in a sidebar dashboard or embedded widgets, generate iOS Scriptable widgets, manage routines, and use weekday schedules and streak freeze days."

    stats: {
        downloads:  290
        updated_at: 1783154317000
    }
}
```
