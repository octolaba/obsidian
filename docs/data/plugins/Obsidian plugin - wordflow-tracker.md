# Wordflow Tracker

Records focused time, edit counts and word changes per note automatically, and can add an AI-generated summary of the changes or diff. Live statistics appear in a customisable status bar and in a sidebar widget with heatmap and list views. Everything is written to the daily or periodic note through flexible templates as a table, a list or YAML, and the tracking rests on Obsidian's built-in history rather than a separate database.
