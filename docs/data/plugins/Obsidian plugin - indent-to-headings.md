# Indent to Headings

Converts plain indented outlines in a note into Markdown headings. Existing headings, bullets, numbered markers and task checkboxes are preserved, and fenced code blocks are skipped. The conversion applies to a selection, the whole note, the current outline block or marked blocks, can be previewed before it is applied, and renders leaf lines either as body text or as bullets.
