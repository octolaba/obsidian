# Places - Leaflet

Draws interactive maps in Places using Leaflet, rendering raster tiles together with markers, tracks and overlays. Built-in styles cover OpenStreetMap, OpenTopoMap, CartoDB and Esri, and custom XYZ tile layers can be supplied instead.

```cue
plugin: {
    id:     "places-leaflet"
    name:   "Places - Leaflet"
    author: "bobstanton"
    repo:   "bobstanton/places-leaflet"

    html_url:    "https://community.obsidian.md/plugins/places-leaflet"
    github_url:  "https://github.com/bobstanton/places-leaflet"
    description: "Map provider for Places using Leaflet, with raster maps, custom tile layers, markers, tracks, and overlays. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display interactive maps in Places using Leaflet, showing raster tiles with markers, tracks, and overlays. Load built-in styles (OpenStreetMap, OpenTopoMap, CartoDB, Esri) or supply custom XYZ tile layers for bespoke maps."
```
