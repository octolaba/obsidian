# Attachments Cache

Stores remote attachments such as images, audio, video and PDFs locally in the vault and serves the cached copies while a note renders, in place of the remote URLs. Caching is selective through path and URL whitelists and blacklists, an API is exposed for integrations, and archiving rewrites links to the local copies.
