# Easy Tracker

Inserts ready-made tracker modules - an overview, a heatmap, buttons and a goal card - into a note to follow a single goal or habit. Daily progress is logged with one click, and streaks, gaps and an annual heatmap are shown. Check-ins are kept as plain text so they stay searchable and easy to sync, and the interface is available in English and Simplified Chinese.

```cue
plugin: {
    id:     "easy-tracker"
    name:   "Easy Tracker"
    author: "hunter-ji"
    repo:   "hunter-ji/obsidian-easy-tracker"

    html_url:    "https://community.obsidian.md/plugins/easy-tracker"
    github_url:  "https://github.com/hunter-ji/obsidian-easy-tracker"
    description: "Instantly track goals and habits. Simple, beautiful, and configuration-free."
    about:       "Insert ready-made tracker modules (overview, heatmap, buttons, goal card) into any note to track a single goal or habit. Log daily progress with one click, review streaks, gaps and an annual heatmap, and keep all check-ins as plain text for easy search and sync. Use in English or Simplified Chinese."

    stats: {
        downloads:  5457
        updated_at: 1768974821000
    }
}
```
