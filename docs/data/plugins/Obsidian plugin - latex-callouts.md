# Latex Styled Callouts

Latex Styled Callouts restyles callouts as LaTeX-like definitions and theorems by removing the icon, the background and the border. The header is derived from the callout type by title-casing it and replacing hyphens with spaces, and parenthetical content is italicised.

```cue
plugin: {
    id:     "latex-callouts"
    name:   "Latex Styled Callouts"
    author: "Bailey Moir"
    repo:   "bailey-moir/latex-callouts"

    html_url:    "https://community.obsidian.md/plugins/latex-callouts"
    github_url:  "https://github.com/bailey-moir/latex-callouts"
    description: "Callouts themed as LaTeX blocks. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert callouts into LaTeX-style definitions and theorems for cleaner, academic-style notes. Remove the icon, background, and border, and format the header by title-casing the text in the callout type, replacing hyphens with spaces, and italicizing parenthetical content."

    stats: {
        downloads:  79
        updated_at: 1783210871000
    }
}
```
