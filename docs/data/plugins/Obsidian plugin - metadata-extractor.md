# Metadata Extractor

Metadata Extractor writes vault metadata out to JSON files on disk, producing tag indexes and per-note records of tags, headings, links, backlinks and frontmatter as separate exports. The exports can be scheduled so that third-party apps such as launchers or graph analysis software can consume them.

```cue
plugin: {
    id:     "metadata-extractor"
    name:   "Metadata Extractor"
    author: "kometenstaub"
    repo:   "kometenstaub/metadata-extractor"

    html_url:    "https://community.obsidian.md/plugins/metadata-extractor"
```
