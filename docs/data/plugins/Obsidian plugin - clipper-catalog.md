# Clipper Catalog

Collects every note carrying a common source property into one searchable catalog view of clipped web articles. Items are filtered by tag, sorted as the list updates and opened from the view, with directories excluded as needed. The view is reached from the command palette, works on desktop and mobile, and follows the active theme.
