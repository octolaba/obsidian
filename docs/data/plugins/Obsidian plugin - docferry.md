# DocFerry

Publishes exactly one note as a secure share link, with or without a password. It works with DocFerry Cloud by default, which the project describes as free with a quota of five active shares, and can also be pointed at a custom self-hosted server. It is deliberately not a folder publisher, vault publisher, public directory or digital garden: readers can open only the document behind the share URL they receive, and internal links resolve only to notes published the same way.
