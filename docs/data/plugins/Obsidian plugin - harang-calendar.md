# Harang Calendar

Shows events from CalDAV calendars inside notes through @date and @event autocompletes that insert interactive date widgets and inline event chips. Agenda and month views are available, widgets can be scoped to particular calendars through frontmatter, and multiple servers, time zones and recurring events are handled. Access to the calendars is strictly read-only.

```cue
plugin: {
    id:     "harang-calendar"
    name:   "Harang Calendar"
    author: "Ji-ho Lee"
    repo:   "search5/harang-calendar"

    html_url:    "https://community.obsidian.md/plugins/harang-calendar"
    github_url:  "https://github.com/search5/harang-calendar"
    description: "View CalDAV calendar events directly in your notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "View events from CalDAV calendars directly in notes using @date and @event autocompletes that insert interactive date widgets and inline event chips. Display agenda and month views, scope widgets via frontmatter to specific calendars, support multiple servers, time zones, and recurring events, and keep access strictly read-only."

    }
}
```
