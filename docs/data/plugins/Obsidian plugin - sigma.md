# Sigma

Sigma turns fenced code blocks into calculation sheets that evaluate expressions line by line and total each block automatically. Operator precedence, variables, hierarchies with subtotals and scientific functions are supported, and a sheet exports as a clean, syntax-colored HTML table on desktop and mobile.
