# GoBoard

Renders Go diagrams from Markdown code blocks written in a goboard syntax. Board size is configurable, and black or white stones are placed with simple position commands such as B G7 or W C3 to show a game position.

```cue
plugin: {
    id:     "goboard"
    name:   "GoBoard"
    author: "dsokolov"
    repo:   "dsokolov/goboard"

    html_url:    "https://community.obsidian.md/plugins/goboard"
    github_url:  "https://github.com/dsokolov/goboard"
    description: "Render Go game diagrams from Markdown code blocks."
    about:       "Render Go (Weiqi/Baduk) diagrams directly from markdown code blocks using goboard syntax. Draw configurable board sizes and place black or white stones with simple B/W position commands (e.g., B G7 W C3) to visualize game positions."
```
