# Nomnoml Diagram

This plugin draws nomnoml diagrams in notes, either from fenced code blocks or through a New Diagram command. Diagrams render as SVG, accept per-diagram styling directives, and produce output compatible with Obsidian's PDF export.

```cue
plugin: {
    id:     "obsidian-nomnoml-diagram"
    name:   "Nomnoml Diagram"
    author: "daeik"
    repo:   "daeik/obsidian-nomnoml-diagram"

    html_url:    "https://community.obsidian.md/plugins/obsidian-nomnoml-diagram"
```
