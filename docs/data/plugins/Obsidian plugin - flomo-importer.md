# Flomo Importer

Imports Flomo memos into the vault as Markdown notes, preserving highlights and file links. Imports run ad hoc or on auto-sync, write into a chosen target folder, and can produce a Flomo Canvas or Moments. Memos can be merged by date, and bi-directional link support is marked experimental.

    id:     "flomo-importer"
    name:   "Flomo Importer"
    author: "jia6y"
