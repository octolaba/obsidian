# Marvis

Marvis is a project planner and habit tracker that treats Markdown notes as the single source of truth and presents them through Kanban, Timeline or Gantt, Calendar and Table views with drag-and-drop, filters and fuzzy search. The planner can be driven by voice or text through Google Gemini Live for edits and queries. Apple Calendar can be synchronized on macOS, coding agents can be run against task files, and the plugin works on mobile.
