# Date Inserter

Inserts a date at the cursor position using an inline calendar. The output format is customizable, and the formatted date can be copied to the clipboard instead of inserted into the Markdown.

```cue
plugin: {
    id:     "date-inserter"
    name:   "Date Inserter"
    author: "namikaze-40p"
    repo:   "namikaze-40p/obsidian-date-inserter"

    html_url:    "https://community.obsidian.md/plugins/date-inserter"
    github_url:  "https://github.com/namikaze-40p/obsidian-date-inserter"
    description: "Insert a date at the cursor position using a calendar."
    about:       "Insert dates at the cursor using an inline calendar with customizable formats. Pick a date to insert into Markdown or copy the formatted date to the clipboard."

    stats: {
        downloads:  18105
        updated_at: 1785028306000
    }
}
```
