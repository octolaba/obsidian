# Everyday Classical Music

Inserts a different classical music piece, with a YouTube link, into each daily note. The pieces come from a curated list of 366 entries mapped to dates, so the same day yields the same piece from year to year. Links are also backfilled into existing daily notes or removed from them.

```cue
plugin: {
    id:     "everyday-classical-music"
    name:   "Everyday Classical Music"
    author: "eloliuyx"
    repo:   "eloliuyx/everyday-classical-music-plugin"

    html_url:    "https://community.obsidian.md/plugins/everyday-classical-music"
    github_url:  "https://github.com/eloliuyx/everyday-classical-music-plugin"
    description: "Display a different piece of classical music each day with a YouTube link in your daily note."
    about:       "Insert a different classical music piece with a YouTube link into each daily note. Select from a curated, date-mapped list of 366 pieces to keep suggestions consistent across years; backfill or remove links across existing daily notes."

    stats: {
        downloads:  802
        updated_at: 1717991804000
    }
}
```
