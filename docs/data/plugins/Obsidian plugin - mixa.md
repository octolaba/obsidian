# Mixa

Mixa publishes notes and blog posts from the vault as a live website with a single click. Sites are built without code from Markdown, MDX and HTML while the folder structure is preserved, themes can be chosen, a live preview is offered, and drafts are excluded through frontmatter.

plugin: {
    id:     "mixa"
    name:   "Mixa"
    author: "mixasite"
    repo:   "mixasite/obsidian-mixa"

    html_url:    "https://community.obsidian.md/plugins/mixa"
    github_url:  "https://github.com/mixasite/obsidian-mixa"
    description: "Publish your notes and blog posts with Mixa."
    about:       "Publish your Obsidian notes and blog posts as a live, SEO-friendly website with one click. Create customizable no-code sites from Markdown/MDX/HTML while preserving folder structure, pick themes, use live preview, and exclude drafts via frontmatter."
