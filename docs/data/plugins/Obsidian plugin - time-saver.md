# TimeSaver

TimeSaver extracts time ranges from the tasks in the current note and reports the time spent per task and in total, in hours and minutes. Commands and a right-click menu insert todo and checked items and the current timestamp.

```cue
plugin: {
    id:     "time-saver"
    name:   "TimeSaver"
    author: "odayou"
    repo:   "odayou/task-processing-extension"

    html_url:    "https://community.obsidian.md/plugins/time-saver"
    github_url:  "https://github.com/odayou/task-processing-extension"
    description: "Save your time. 1. Quickly insert todo directive. 2. Quickly count the time spent on tasks in the current note and the total time spent."
    about:       "Calculate time spent per task by extracting time ranges from tasks in the current note and display per-task and total durations in hours and minutes. Provide commands and a right-click menu to insert todo/checked items and the current timestamp."
```
