# Immersive Translate

Translates foreign-language Markdown in Obsidian's reading view through the Immersive Translate service, displaying the translation inline. Immersive Translate Lite is offered for compatibility, and settings changes take effect after Obsidian is relaunched.

    id:     "immersive-translate"
    name:   "Immersive Translate"
    author: "imfenghuang"
    repo:   "imfenghuang/obsidian-immersive-translate"

    html_url:    "https://community.obsidian.md/plugins/immersive-translate"
    github_url:  "https://github.com/imfenghuang/obsidian-immersive-translate"
