# Anki Helper

Pairs with obsidian_to_anki to turn headings into question and answer cards, insert target deck entries and add heading-level backlinks for jumping back to the note. Title characters are cleaned, list spacing tidied, and custom cloze markers converted to and from Anki cloze syntax. Processing can be scoped by path, the matching regex can be copied for obsidian_to_anki, and the settings are bilingual.
