# DnD Beyond Importer

Imports public D&D Beyond character sheets into the vault as formatted Markdown notes. The generated note carries ability scores, saves, skills, HP, AC, equipment, spells, features, backstory and currency, with YAML front matter for queries and support for re-importing updates. A dice roller with history and notifications is included.
