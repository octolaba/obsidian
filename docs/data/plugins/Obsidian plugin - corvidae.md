# Corvidae

Corvidae builds a modular dashboard grid that places graph views, notes, web views, terminals and numbered project tickets into a single workspace. It also manages folder notes and hybrid links, applies graph node size and color and custom legends taken from note frontmatter, and creates ticket sidebars with automatic frontmatter and explorer sorting.
