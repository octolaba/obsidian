# Markdown Table to LaTeX

Converts a selected Markdown table into a LaTeX array environment wrapped in double dollar signs so MathJax renders it. Markdown column alignment is parsed into the LaTeX column format, redundant dollar signs are stripped from inline math, and an optional caption is inserted. The recorded description is written in both English and Chinese.
