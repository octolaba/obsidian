# Journalistic Importer

Journalistic Importer reads a Journalistic export file and stores its entries and metadata in the vault as Markdown notes in a Journalistic folder. The importer opens from the left sidebar, where the export file to import is chosen.

```cue
plugin: {
    id:     "journalistic-importer"
    name:   "Journalistic Importer"
    author: "homerokemmerich"
    repo:   "homerokemmerich/journalistic-importer"

    html_url:    "https://community.obsidian.md/plugins/journalistic-importer"
    github_url:  "https://github.com/homerokemmerich/journalistic-importer"
    description: "Import your Journalistic exported entries. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Import Journalistic export files into your Obsidian vault and store entries and metadata as Markdown notes in a Journalistic/ folder. Open the importer from the left sidebar and choose an export file to import entries into your vault."

    stats: {
        downloads:  69

}
```
