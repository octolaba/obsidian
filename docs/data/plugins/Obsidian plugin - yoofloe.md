# Yoofloe

Generates AI insight documents grounded in Yoofloe data and exports the results into the vault as Markdown files. A Yoofloe token and Google Gemini or Vertex AI credentials are configured so that the Yoofloe and Gemini API calls run locally from Obsidian.

```cue
plugin: {
    id:     "yoofloe"
    name:   "Yoofloe"
    author: "yoofloe"
    repo:   "yoofloe/yoofloe-obsidian"

    html_url:    "https://community.obsidian.md/plugins/yoofloe"
    github_url:  "https://github.com/yoofloe/yoofloe-obsidian"
    description: "Yoofloe AI insight documents grounded in your data. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Turn Yoofloe data into grounded AI documents inside Obsidian. Generate AI Insight briefs and export results as Markdown files into your vault. Connect your Yoofloe token and Google Gemini/Vertex AI credentials to run Yoofloe and Gemini API calls locally."

    stats: {
        downloads:  195
        updated_at: 1784066504000
    }
}
```
