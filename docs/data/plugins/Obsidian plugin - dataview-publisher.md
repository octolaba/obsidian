# Dataview Publisher

Writes the output of Dataview queries into notes as Markdown and keeps that Markdown up to date. The generated Markdown can then be published.

```cue
plugin: {
    id:     "dataview-publisher"
    name:   "Dataview Publisher"
    author: "udus122"
    repo:   "udus122/dataview-publisher"

    html_url:    "https://community.obsidian.md/plugins/dataview-publisher"
    github_url:  "https://github.com/udus122/dataview-publisher"
    description: "Output markdown from your Dataview queries and keep them up to date. You can also publish them."
    about:       "Output Markdown from Dataview queries and keep query results up to date inside your notes. Publish the generated Markdown for sharing or static export."

    stats: {
        downloads:  12244
        updated_at: 1731747752000
    }
}
```
