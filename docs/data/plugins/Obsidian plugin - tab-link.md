# Tab Link

Suggests note names as inline ghost text while typing and inserts a wiki-link when Tab is pressed. Matching is context-aware and skips code, frontmatter and existing links. The recorded About text also names frecency ranking, phrase matching and alias support.

```cue
plugin: {
    id:     "tab-link"
    name:   "Tab Link"
    author: "jon-vii"
    repo:   "jon-vii/obsidian-tab-link"

    html_url:    "https://community.obsidian.md/plugins/tab-link"
    github_url:  "https://github.com/jon-vii/obsidian-tab-link"
    description: "Cursor-style ghost text autocomplete for linking to notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert wiki-links with inline ghost-text autocompletion that shows note-name suggestions as you type. Press Tab to accept completions and create links; use context-aware matching that skips code, frontmatter and existing links, with frecency ranking, phrase matching and alias support."

    stats: {
        downloads:  2025
        updated_at: 1769183192000
    }
}
```
