# Code Blocks commands

Provides commands that insert code blocks together with their language markup, and the markup menu can also be opened by typing backticks. The list of markups is sortable and customizable, with custom syntax, names and titles so an entry is retrieved quickly.

```cue
plugin: {
    id:     "code-blocks-commands"
    name:   "Code Blocks commands"
    author: "dragonish"
    repo:   "dragonish/code-blocks-commands"

    html_url:    "https://community.obsidian.md/plugins/code-blocks-commands"
    github_url:  "https://github.com/dragonish/code-blocks-commands"
    description: "Provide commands to insert code blocks with markup, and support triggering commands with backticks."
    about:       "Insert code blocks with markup directly into notes. Trigger the markup selection menu by typing backticks. Sort and customize language markups, adding custom syntax, names, and titles for quick retrieval."
```
