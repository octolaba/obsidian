# Slide Deck

Slide Deck turns a Markdown note into a slide deck and exports it to PDF or a series of PNG images. Slides render in a sandboxed iframe with built-in or user themes, and a live preview reports readability warnings. Settings are controlled from frontmatter, and five per-slide layouts are available.

    id:     "slide-deck"
    name:   "Slide Deck"
    author: "Johannes Kaindl"
    repo:   "johannes-kaindl/slide-deck"

    html_url:    "https://community.obsidian.md/plugins/slide-deck"
    github_url:  "https://github.com/johannes-kaindl/slide-deck"
