# Just Note

Opens any note in a focused, minimal pop-out window without tabs, sidebars or the ribbon, while editing, links, metadata and vault synchronization keep working normally. A persistent color can be assigned per note for its window, and specific notes can be launched through an Obsidian URI to create app-like macOS launchers.
