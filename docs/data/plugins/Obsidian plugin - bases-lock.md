# Bases Lock

Bases Lock hides the action bar at the top of a Bases view and locks header interactions while in Reading view. Each embedded Base is locked or unlocked from a button that appears on hover, and the controls apply only to Base embeds in the current document.

```cue
plugin: {
    id:     "bases-lock"
    name:   "Bases Lock"
    author: "lucas"
    repo:   "tcyeee/obsidian-bases-lock"

    html_url:    "https://community.obsidian.md/plugins/bases-lock"
    github_url:  "https://github.com/tcyeee/obsidian-bases-lock"
    description: "Hides the action bar at the top of the Bases view. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Hide the Obsidian Bases toolbar and lock header interactions while in Reading view. Toggle lock/unlock per embedded Base with a button that appears on hover. Apply controls only to Base embeds in the current document."

    stats: {
        downloads:  1323
        updated_at: 1786091778000
    }
}
```
