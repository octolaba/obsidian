# SideBrace

SideBrace groups a few lines of related text with a large curly brace and a short side note, written with the callout syntax you already know. Braces render on the left or the right in both Reading view and Live Preview, the callout title becomes the label, and the block falls back to an ordinary callout when the plugin is absent.

    id:     "sidebrace"
    name:   "SideBrace"
