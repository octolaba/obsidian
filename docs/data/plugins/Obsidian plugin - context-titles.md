# Context Titles

Context Titles adds folder context to node labels in Graph View and Local Graph so notes that share a filename can be told apart. Files and note contents are left unchanged, and only the graph display is affected. By default context is added to duplicates using the parent folder, with options for deeper path context or for labelling every visible node.
