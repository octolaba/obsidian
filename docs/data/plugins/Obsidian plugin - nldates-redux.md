# Natural Language Dates Redux

Natural Language Dates Redux inserts timestamps and cross-links written as natural-language dates directly in the editor. Inline autosuggestions and a date picker turn a phrase into a date, and an Obsidian URI action opens or creates the matching daily note. Holding Shift keeps the original text as the link alias, and text that is not recognised as a date is left unlinked.
