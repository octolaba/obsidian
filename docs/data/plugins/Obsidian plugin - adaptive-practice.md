# Adaptive Practice

Adaptive Practice generates practice questions from notes and PDFs with an AI provider you supply, drawing multiple choice, select-all and numeric questions from a folder or a filter. A catalog of analytical reasoning moves pushes questions past recall toward application and transfer, and a blind verification pass re-solves each batch and drops questions with wrong answer keys. Scheduling follows an FSRS-style spaced repetition model and difficulty adapts to answers during a session. Notes are sent only to the chosen provider, among them Anthropic, Gemini, OpenAI, DeepSeek, Qwen and OpenRouter.
