# Vault Storage Map

Maps disk usage inside the vault as an interactive treemap with folder drill-down and ranked tables of the largest folders and files. Scans can be compared with each other, file-type statistics and diagnostic warnings about oversized files and common vault issues are shown, and reports export to Markdown, CSV or JSON. The recorded inputs state that scanning is read-only and optionally cached, that data stays local, and that the interface is multilingual.
