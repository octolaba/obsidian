# Memoria

Captures quick memos as plain Markdown in yearly files with time-stamped entries, so they stay readable and searchable with grep outside Obsidian. A waterfall timeline browses them with pinned items, a heatmap sidebar and tag or keyword search. Reports cover a 365-day heatmap, monthly charts, top tags and an annual calendar view.

plugin: {
    id:     "memoria"
    name:   "Memoria"
    author: "i-iooi-i"
    repo:   "i-iooi-i/obsidian-memoria"

    html_url:    "https://community.obsidian.md/plugins/memoria"
    github_url:  "https://github.com/i-iooi-i/obsidian-memoria"
    description: "Waterfall-style memo plugin for flomo-like fleeting thoughts, stored as plain Markdown. - This plugin has not been manually reviewed by Obsidian staff."

Browse a waterfall timeline with pinned items, heatmap sidebar, tag/keyword search and data reports like a 365-day heatmap, monthly charts, top tags and an annual calendar view."
