# Scrolling

Scrolling collects several scrolling and navigation behaviors: keeping the cursor centered, disabling code wrapping, saving and restoring the position in a file, and zooming images with Ctrl-scroll. It also controls scrollbar visibility, sets line-length limits, adjusts mouse and touchpad speed, and enables Vim-like reading keybinds.
