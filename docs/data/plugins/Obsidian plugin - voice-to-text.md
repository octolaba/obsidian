# Voice to Text

Voice to Text transcribes speech with push-to-talk: hold a hotkey, speak, release, and the transcription is inserted at the cursor. Deepgram Nova 2 and Groq Whisper are both selectable. Recordings can optionally be kept as WAV files, and daily activity logs are written into the vault.

```cue
plugin: {
    id:     "voice-to-text"
    name:   "Voice to Text"
    author: "SATOSprod"
    repo:   "satosprod/voice-to-text"

    html_url:    "https://community.obsidian.md/plugins/voice-to-text"
    github_url:  "https://github.com/satosprod/voice-to-text"
    description: "Push-to-talk voice transcription using Deepgram or Groq. Hold a hotkey to record, release to transcribe and insert at cursor. - This plugin has not been manually reviewed by Obsidian staff."

}
```
