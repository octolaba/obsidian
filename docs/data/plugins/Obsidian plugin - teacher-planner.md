# Teacher Planner

Teacher Planner is an academic planner in which the real school day is laid out once, with periods, breaks, registration and custom block types, after which classes repeat through the year; a short setup wizard and saveable templates start it off. A colour-coded weekly grid links straight into lesson notes, which are plain Markdown built from the teacher's own template, and A/B week rotation is tracked automatically. One-off events, cover, duties, trips and meetings are added without disturbing the timetable, and clashes are caught automatically. Directed time is tracked against the UK STPCD limit of 1,265 hours with a one-click Excel report, and the recorded text states that the data never leaves the device.
