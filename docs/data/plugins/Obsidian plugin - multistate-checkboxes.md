# Multistate Checkboxes

Adds 20 checkbox states drawn as embedded SVG icons whose colours come from CSS variables, so they render independently of the theme. A command cycles the states in order from Reading view or Live Preview. Which states appear, and their icons and colours, are customizable.

```cue
plugin: {
    id:     "multistate-checkboxes"
    name:   "Multistate Checkboxes"
    author: "evgene-kopylov"
    repo:   "evgene-kopylov/obsidian-multistate-checkboxes"

    html_url:    "https://community.obsidian.md/plugins/multistate-checkboxes"
    github_url:  "https://github.com/evgene-kopylov/obsidian-multistate-checkboxes"
    description: "Theme-independent extended checkbox states with custom SVG icons - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add 20 theme-independent checkbox states with embedded SVG icons and CSS-variable colors that adapt to any theme. Cycle states in order from Reading view or Live Preview with a command, and customize which states, icons, and colors appear."

    stats: {
        downloads:  43
        updated_at: 1784108700000
    }
}
```
