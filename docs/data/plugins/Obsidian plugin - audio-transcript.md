# Audio Transcript

Records or transcribes audio directly into a note, with speaker identification and timestamps. Gladia, Deepgram and AssemblyAI are the supported transcription services, and the generic speaker labels can be replaced with names supplied by the user. The audio file is saved automatically into the folder of the note. The recorded inputs for this plugin are written in Spanish.

```cue
plugin: {
    id:     "audio-transcript"
    name:   "Audio Transcript"
    author: "Jesús García"
    repo:   "jaliriogbarrios19/Audio_Transcript"

    html_url:    "https://community.obsidian.md/plugins/audio-transcript"
    github_url:  "https://github.com/jaliriogbarrios19/Audio_Transcript"
    description: "Transcribí audios con identificación de hablantes usando Gladia, Deepgram o AssemblyAI - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Graba o transcribe audios directamente en la nota con identificación de hablantes y timestamps. Usa Gladia, Deepgram o AssemblyAI, reemplaza \"Speaker 1/2\" por los nombres que indiques y guarda automáticamente el audio en la carpeta de la nota."

    stats: {
        downloads:  410
        updated_at: 1782818511000
    }
}
```
