# Colored Text

Colored Text colors selected text through reusable color slots shown in the status bar. Slots are switched from the status bar, colors picked from favorites or a palette, and text is colored, highlighted or cleared with hotkeys or from the right-click menu.

```cue
plugin: {
    id:     "colored-text"
    name:   "Colored Text"
    author: "erincayaz"
    repo:   "erincayaz/obsidian-colored-text"
```
