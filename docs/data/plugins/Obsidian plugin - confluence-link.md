# Confluence Link

Confluence Link publishes a note as a Confluence page from a single command, uploading files to the page. A space is chosen for the upload, frequently used spaces are marked as favorites, and fuzzy search reaches spaces beyond the initial listing.

```cue
plugin: {
    id:     "confluence-link"
    name:   "Confluence Link"
    author: "bungarazvan"
    repo:   "bungarazvan/confluence-link"

    html_url:    "https://community.obsidian.md/plugins/confluence-link"
    github_url:  "https://github.com/bungarazvan/confluence-link"
    description: "Upload files to Confluence pages"
    about:       "Publish Obsidian notes as Confluence pages and share them with your team using a single command. Choose a space, mark favorites for quick access, and use fuzzy search to find spaces beyond the initial listing."

    stats: {
        downloads:  2162
        updated_at: 1736533182000
    }
}
```
