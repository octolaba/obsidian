# myBrain

Arranges notes in a fixed semantic network around the current note, placing Parents, Friends, Children and Siblings in set quadrants so the layout stays predictable. Rendering uses hardware-accelerated CSS Grid with off-screen layout isolation to stay usable in large vaults, and navigation relies on constant-time caching. Tag colors and icons from the vault are carried into the graph.
