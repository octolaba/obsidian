# Material File Icons

Material File Icons replaces the default file explorer icons with Material Icon Theme icons matched by filename and extension, covering cases such as canvas notes, templates and dotfiles. Folder icons are added as well, custom rules can be created from a picker of more than five hundred icons, and file and folder icons can be toggled independently.

```cue
plugin: {
    id:     "material-file-icons"
    name:   "Material File Icons"
    author: "liicos"
    repo:   "liicos/obsidian-material-icon"

    html_url:    "https://community.obsidian.md/plugins/material-file-icons"
    github_url:  "https://github.com/liicos/obsidian-material-icon"
    description: "Replace file explorer icons with Material Design icons matched by file extension and filename. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Replace Obsidian's default explorer icons with Material Icon Theme icons matched by filename and extension, covering canvas notes, templates, dotfiles and more. Add folder icons, create custom rules from a 500+ icon picker, and toggle file or folder icons independently."

    stats: {
        downloads:  395
        updated_at: 1780568556000
    }
}
```
