# Sketch Mechanisms

Sketch Mechanisms animates common 2D mechanisms — four-bar linkages, slider-cranks, gear pairs, cams, pendulums and spring-mass systems — from a simple code block in a note. The animation is drawn as a live SVG in a sketchy hand-drawn style and plays in Reading View and Live Preview. It works on mobile, respects reduced-motion settings, and lets a drawing be clicked to play or pause.

```cue
plugin: {
    id:     "sketch-mechanisms"
    name:   "Sketch Mechanisms"
    author: "Masoud Masoumi"
    repo:   "masoudmim/sketch-mechanisms"

    html_url:    "https://community.obsidian.md/plugins/sketch-mechanisms"
    github_url:  "https://github.com/masoudmim/sketch-mechanisms"
    description: "Live hand-drawn animations of 2D mechanisms (four-bar, slider-crank, gears, cam, pendulum, spring) from a simple code block. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render live, hand-drawn animations of common 2D mechanisms—four-bar linkages, slider-cranks, gear pairs, cams, pendulums, and spring-mass systems—directly in your notes from a simple code block. Draw strokes in a sketchy rough.js style as a live SVG that plays in Reading View and Live Preview, works on mobile, respects reduced-motion, and lets you click drawings to play or pause."
```
