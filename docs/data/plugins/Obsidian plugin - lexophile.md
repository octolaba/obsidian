# Lexophile - Personal Dictionary

Lexophile turns a word into a permanent, searchable dictionary note in the vault, holding its definition, part of speech, an example and its source. Words are added by hand, captured from the web through a companion browser extension, or imported from a Kobo My Words list into linked book notes. The lexicon stays local, and an offline dictionary can be used for lookups without a network.
