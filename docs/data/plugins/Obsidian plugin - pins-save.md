# Pins Save

Pins Save remembers which Markdown notes were pinned and reopens and re-pins them the next time Obsidian starts. Pin and unpin actions are tracked in the background, and saved paths are updated when files are renamed or deleted. Commands and a live status panel are provided for managing the saved pins.

```cue
plugin: {
    id:     "pins-save"
    name:   "Pins Save"
    author: "SATOSprod"
    repo:   "satosprod/pins-save"

    html_url:    "https://community.obsidian.md/plugins/pins-save"
    github_url:  "https://github.com/satosprod/pins-save"
    description: "Remembers which Markdown notes you pinned and re-opens them as pinned tabs the next time Obsidian starts. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Restore pinned Markdown tabs across restarts by automatically reopening and re-pinning notes you had pinned. Track pin/unpin actions in the background, update saved paths when files are renamed or deleted, and provide commands plus a live status panel to manage saved pins."

    stats: {
        downloads:  35
        updated_at: 1783486159000
    }
}
```
