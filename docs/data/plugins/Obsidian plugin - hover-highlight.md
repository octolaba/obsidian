# Hover Highlight

Hover Highlight replaces the static dot background of Canvas with a soft radial spotlight that follows the cursor. Movement is smoothed with lerp-based animation and an optional fade-out, and glow radius, dot brightness and follow smoothness are adjustable. The effect is described as GPU-accelerated.
