# Wordy

Synonyms, rhymes, antonyms and alliterative alternatives for a highlighted word are looked up through the Datamuse API. Related terms including hypernyms, hyponyms, holonyms and meronyms are browsed in the Wordy panel, and a word can be replaced in the note directly.

```cue
plugin: {
    id:     "obsidian-wordy"
    name:   "Wordy"
    author: "nqthqn"
    repo:   "nqthqn/obsidian-wordy"

    html_url:    "https://community.obsidian.md/plugins/obsidian-wordy"
    github_url:  "https://github.com/nqthqn/obsidian-wordy"
    description: "Thesaurus, Rhymes and more using the Datamuse API. Find related words easily."
    about:       "Find synonyms, rhymes, antonyms, and alliterative alternatives for any highlighted word using the Datamuse API. Browse related terms — including hypernyms, hyponyms, holonyms and meronyms — in the Wordy panel and replace words directly in your note."

    stats: {

}
```
