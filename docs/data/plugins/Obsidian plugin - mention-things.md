# Mention Things

Defines prefixes such as the at sign that trigger an autocomplete suggestion while typing. Selecting a suggestion inserts a wiki-style link to the mentioned note, or the filename as plain text, and leaves the cursor at the end. Several mention types are defined, each with its own label and matching behaviour.

```cue
plugin: {
    id:     "mention-things"
    name:   "Mention Things"
    author: "stracker-phil"
    repo:   "stracker-phil/obsidian-mention-things"

    html_url:    "https://community.obsidian.md/plugins/mention-things"
    github_url:  "https://github.com/stracker-phil/obsidian-mention-things"
    description: "Define a list of prefixes to trigger an autocomplete suggestion to insert a link."
    about:       "Create custom mention triggers (e.g., @) to insert linked note mentions or autocomplete filenames as plain text. Select suggestions to insert wiki-style links (e.g., [[@Name]]) and leave the cursor at the end. Define multiple mention types with labels and matching behavior for targeted suggestions."

    stats: {
        downloads:  1207
        updated_at: 1772054281000
    }
}
```
