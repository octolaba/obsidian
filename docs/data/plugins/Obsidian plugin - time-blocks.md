# Time Blocks

Time Blocks lays the week out on a seven-day grid onto which tasks written in Obsidian Tasks checkbox format are dragged from the vault, snapping to fifteen-minute increments and resizing by dragging. Read-only ICS feeds are overlaid, or OAuth connects the grid to Google Calendar to push and pull events. The backlog is filterable and schedules persist across reloads.
