# Letterhead

Letterhead formats a note as a business letter in either the German DIN 5008 standard or a modern layout, taking metadata from frontmatter and using the note body as the letter text. The paginated A4 output is previewed and then exported to PDF through the print dialog on desktop or the system share sheet on iPhone and iPad. Letter language, English or German, and visual style are chosen per letter.
