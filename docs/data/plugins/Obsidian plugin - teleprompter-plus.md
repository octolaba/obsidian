# Teleprompter Plus

Teleprompter Plus scrolls notes as a teleprompter with an eyeline guide, adjustable speed and font size, real-time position tracking and hierarchical section navigation. Playback can be driven from a mobile remote or other external clients, and a WebSocket interface exposes Stream Deck integration with 55+ real-time actions and visual feedback. A countdown timer and voice tracking are also recorded.
