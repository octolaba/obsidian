# ClipperMaster

Receives structured web captures from the ClipperMaster Chrome extension and saves them into the vault as Markdown files. Text, images and links are converted on the way in, and templates decide how the resulting note is written and where it is filed.

```cue
plugin: {
    id:     "clippermaster"
    name:   "ClipperMaster"
    author: "aqeja"
    repo:   "aqeja/ClipperMaster-for-Obsidian"

    html_url:    "https://community.obsidian.md/plugins/clippermaster"
    github_url:  "https://github.com/aqeja/ClipperMaster-for-Obsidian"
    description: "Works with the ClipperMaster Chrome extension to clip structured content from the web and save it to your vault as Markdown files."
    about:       "Send structured web captures from ClipperMaster Chrome to Obsidian with one click. Convert text, images, and links into Markdown and save via templates to keep notes organized. Create a seamless browser-to-vault workflow for building your information database."

    stats: {
        downloads:  2559
        updated_at: 1745562011000
    }
}
```
