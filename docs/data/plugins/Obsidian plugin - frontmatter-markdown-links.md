# Frontmatter Markdown Links

Adds support for markdown links written in frontmatter and makes them clickable in Source, Live Preview and Reading modes. Backlink tracking is handled, as are internal, external and embedded link formats, including aliases, angle-bracket URLs and filenames with spaces.
