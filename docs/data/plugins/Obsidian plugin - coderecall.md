# CodeRecall

CodeRecall turns code blocks into spaced-repetition cards that hide cloze fragments and ask you to retype the missing code. Submissions are auto-graded by running them in a sandbox against reference tests, and the pass or fail result feeds an SM-2 scheduler that sets the next review.
