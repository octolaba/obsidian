# Multi State CheckBox Switcher

Cycles three-state checkboxes, written [ ], [/] and [x], as well as custom multistate symbols, by clicking them in a note. Multiline selections are handled, as is toggling empty lines. The recorded text notes that themes displaying state icons show these states visually.

    id:     "multi-state-checkbox-switcher"
    name:   "Multi State CheckBox Switcher"
    author: "kubamiszcz"

    html_url:    "https://community.obsidian.md/plugins/multi-state-checkbox-switcher"
