# Supabase Image Uploader

Images pasted or dragged into a note are uploaded to Supabase Storage and replaced by a Markdown image link pointing at the hosted address. Uploaded images are deleted from Supabase through the editor context menu, files are organized into year, month and day folders, and both Supabase Cloud and self-hosted instances are supported.

```cue
plugin: {
    id:     "supabase-image-uploader"
    name:   "Supabase Image Uploader"
    author: "waymakerlabs"
    repo:   "waymakerlabs/obsidian-supabase-uploader"

    html_url:    "https://community.obsidian.md/plugins/supabase-image-uploader"
    github_url:  "https://github.com/waymakerlabs/obsidian-supabase-uploader"
    description: "Automatically upload images to Supabase Storage when pasting or dropping. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Upload pasted or dragged images to your Supabase Storage automatically and insert Markdown image links with their hosted URLs. Delete uploaded images from Supabase via the editor context menu and keep files organized by YYYY/MM/DD folders; works with Supabase Cloud or self-hosted instances."

    stats: {
        downloads:  89
        updated_at: 1780010515000
    }
}
```
