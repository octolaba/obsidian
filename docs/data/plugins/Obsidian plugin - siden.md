# Siden

Annotates Markdown notes and PDFs by selecting text and writing Markdown comments in a sidebar, where they can be searched, edited, resolved, reopened and deleted. Highlights and margin cards appear beside the annotated passages, and navigation runs both ways between a comment and its source passage. Source files are left unchanged because annotations are stored separately as human-readable Markdown.
