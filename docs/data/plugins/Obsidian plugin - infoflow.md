# InfoFlow

Syncs saved InfoFlow articles, web pages, X posts, YouTube videos, notes and highlights into the vault, a role the recorded description compares to ReadWise and Omnivore. HTML is converted to Markdown, highlights and annotations are imported, and syncs can be filtered or automated with customizable file names and note templates including frontmatter.
