# Songwriter Player

Audio referenced by embeds or links in the open note plays in a right sidebar and keeps playing while the note is scrolled or the panel is closed. Playback is driven from a waveform: click to seek, drag to set an A-B loop zone, double-click to place a per-file marker, and switch tracks from there. Play counts and listened time are recorded per file.
