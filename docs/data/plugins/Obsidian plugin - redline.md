# Redline

Adds pull-request-style review comments to a document and keeps them in a sibling review sidecar file, so the source note stays clean. Comments anchor to paragraphs, headings, lists, images, code blocks, callouts, or tables through block-reference anchors. Gutter markers and a review sidebar make it possible to jump between, filter, and resolve comments.
