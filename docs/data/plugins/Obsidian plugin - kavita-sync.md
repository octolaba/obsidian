# Kavita Sync

Syncs annotations, highlights and notes from a Kavita server into the vault. Output can be written as a hierarchical set of per-series or per-book Markdown files with frontmatter and wiki links, or as a single-file export that groups all annotations by series and chapter.

    id:     "kavita-sync"
    name:   "Kavita Sync"
    author: "david bowman"
    repo:   "davidlbowman/kavita-to-obsidian"

    html_url:    "https://community.obsidian.md/plugins/kavita-sync"
    github_url:  "https://github.com/davidlbowman/kavita-to-obsidian"
