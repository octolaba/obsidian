# Trailmark

Displays a rail of compact bars beside notes that have several headings; hovering a bar previews that section and clicking jumps to the heading. Previews are lightweight and transient, rendering emphasis, inline code, links, lists and blockquotes while skipping heavy embeds, images and code. It works in Live Preview and Reading view, and all data stays local.
