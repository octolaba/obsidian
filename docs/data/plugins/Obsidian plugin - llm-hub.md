# LLM Hub

Runs an AI assistant offering multi-provider chat, workflow automation, and semantic search over the vault. Notes can be read, written, and edited through function calling, visual multi-step workflows can be built, local vector search runs with PDF previews, images can be generated, and models can be connected to Discord. The recorded providers include Gemini, OpenAI, Anthropic, OpenRouter, Grok, local LLMs, and CLI backends.
