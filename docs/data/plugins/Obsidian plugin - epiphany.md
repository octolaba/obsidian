# Epiphany

Synchronises voice notes dictated in the Epiphany app on iPhone or Apple Watch into the vault. Screenshots, links, photos or files can be attached for context, and the transcribed notes arrive as Markdown that is appended to daily notes or routed to project files. Synchronisation continues while offline.
