# TTRPG Tools - Player Screen

Sends notes, selected Markdown, images, videos, PDFs and tabletop RPG maps to a plain second-screen window for a monitor, TV or projector. The popout remembers its size and position and can open automatically when content is sent. A controller pane inside Obsidian queues and switches the sent items and closes tabs.
