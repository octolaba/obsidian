# Arbor

Writes a note as branching, left-to-right blocks that live inside a single Markdown file. While editing, the current branch, the nearby alternatives and the next steps are shown inline, with drag-and-drop reordering, keyboard navigation and block search. The source stays a normal Markdown file, so no canvas or export step is involved.
