# Strong Start

Tabletop campaigns are created and run through a guided board following Sly Flourish's eight steps of lazy roleplaying-game preparation, with a campaign dashboard and rollable random tables. Session preparation carries secrets forward, and a distraction-free run mode keeps them masked until they are revealed. Everything is stored as plain Markdown.
