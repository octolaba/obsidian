# Note Synchronizer

Synchronizes an Obsidian vault with Anki using a one-to-one mapping: Anki notes, decks and tags correspond to Obsidian notes, folders and tags, treating each file as a single note. Anki note types can be imported as Markdown templates, wikilinks are converted to Markdown links, and content is sent either as raw Markdown or as rendered HTML.

```cue
plugin: {
    id:     "note-synchronizer"
    name:   "Note Synchronizer"
    author: "tansongchen"
    repo:   "tansongchen/obsidian-note-synchronizer"

    html_url:    "https://community.obsidian.md/plugins/note-synchronizer"
    github_url:  "https://github.com/tansongchen/obsidian-note-synchronizer"
    description: "Synchronize your notes to other note-based software like Anki, following more strictly the principles of Zettelkasten and treating each file as a note."
    about:       "Sync Anki and Obsidian with 1:1 mapping between Anki notes, decks, and tags and Obsidian notes, folders, and tags. Import Anki note types as Markdown templates and convert Obsidian wikilinks to Markdown links. Choose Markdown mode (raw Markdown) or HTML mode (rendered HTML)."

    stats: {
        downloads:  8247
        updated_at: 1708210843000
    }
}
```
