# Pseudonymizer Tool

Pseudonymizes and corrects interactional transcripts inside Obsidian while preserving timestamps, speakers, metadata and dependent lines, addressed to qualitative researchers in linguistics and conversation analysis. SRT, CHAT/CHA, Jefferson and ICOR Markdown, and plain text are converted into editable Markdown, with diffs reviewed before replacements are validated. Structured JSON mappings are applied across a file, folder or vault, and Coulmont is queried to propose sociologically matched first names.
