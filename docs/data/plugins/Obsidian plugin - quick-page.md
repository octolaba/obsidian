# Quick Page

Creates timestamped Markdown notes in a configured pages directory in one click. A plus button in the left sidebar generates a file named from the year, month, day, hour and minute, and opens it immediately. The recorded About notes that this naming is compatible with the Logseq pages structure.

```cue
plugin: {
    id:     "quick-page"
    name:   "Quick Page"
    author: "fengshuzi"
    repo:   "fengshuzi/quick-page"

    html_url:    "https://community.obsidian.md/plugins/quick-page"
    github_url:  "https://github.com/fengshuzi/quick-page"
    description: "Quickly create timestamped notes in a specified folder. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create timestamped Markdown notes in your pages directory with a single click. Add a left‑sidebar + button to generate files named yyyymmddhhmm.md and open them instantly, compatible with Logseq pages structure."
```
