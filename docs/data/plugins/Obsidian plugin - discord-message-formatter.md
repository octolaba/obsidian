# Discord Message Formatter

Converts messages copied or dragged in from Discord into Obsidian-ready Markdown, carrying over usernames, timestamps and message text and translating Discord markdown into Obsidian syntax. Attachments, custom emojis and links are embedded, and whole conversations can be imported with replies and edit flags.
