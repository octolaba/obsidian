# Goban Viewer

Renders Go, Baduk and Weiqi position diagrams in note preview using the diagram syntax of Sensei's Library. Diagrams are written inside fenced goban blocks and produce lightweight SVG output that displays on desktop and mobile.

```cue
plugin: {
    id:     "goban-viewer"
    name:   "Goban Viewer"
    author: "Davide Aversa"
    repo:   "thek3nger/obsidian-goban"

    html_url:    "https://community.obsidian.md/plugins/goban-viewer"
    github_url:  "https://github.com/thek3nger/obsidian-goban"
    description: "Render Go/Baduk positions diagrams in note preview. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render Go/Baduk/Weiqi diagrams in notes using Sensei's Library diagram syntax. Write diagrams inside fenced goban code blocks to output lightweight SVG goban diagrams that display on desktop and mobile."
```
