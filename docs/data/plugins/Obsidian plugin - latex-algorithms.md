# LaTeX Algorithms

LaTeX Algorithms turns algorithm and pseudocode keywords into LaTeX algorithm environments, so that inputs such as \If, \For and \Switch expand into standard structures. It covers titles and subtitles, conditionals, loops, switch and case handling, proof and theorem environments, and applies indentation as the block is written.
