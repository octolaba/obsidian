# Wisdio Companion

Connects the vault to the Wisdio browser extension through a local companion service bound to 127.0.0.1. Wisdio notes are created and live-synced as local Markdown files, and file events in the vault are sent back to Wisdio. New notes land in a chosen folder with a customisable template, and the local API is protected by a key.
