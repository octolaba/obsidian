# Workbuddian

Connects Obsidian to a local WorkBuddy or CodeBuddy CLI and opens an in-app chat panel that streams the replies and can genuinely stop generation. Conversations are held in several tabs and can be renamed, exported and searched in full text. Note references or selected text can be inserted, files attached, and the model and permissions switched from a toolbar inside the chat.
