# Mobile Toolbar Utilities

Adds three commands to the mobile editing toolbar that act on the current line: delete it, send it to another file, or turn it into an unchecked task. The delete command removes only the active line rather than the whole paragraph, and the send command appends the line to a note chosen by the user, such as an inbox or daily note. The third command rewrites the line as an unchecked checkbox.
