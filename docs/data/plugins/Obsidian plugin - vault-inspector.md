# Vault Inspector

Scans the vault for maintenance problems and presents a navigable report without modifying any file. The checks cover broken internal links and missing headings, orphaned attachments, duplicates by name, size or hash, frontmatter type mismatches, low-usage or missing tags, and oversized notes and attachments.
