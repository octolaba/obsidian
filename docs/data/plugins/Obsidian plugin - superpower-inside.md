# Superpower Inside

Local or cloud language models are used from a right sidebar chat, and in-editor directives summarize, edit or generate content. The vault is indexed for retrieval so context is injected with its provenance, and MCP servers over stdio or a local Ollama instance supply external tool calls and web-search context. The recorded inputs state that the plugin is desktop only.
