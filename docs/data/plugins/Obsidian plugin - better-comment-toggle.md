# Better Comment Toggle

Better Comment Toggle comments a single line or a selected range using configurable start and end tokens while preserving indentation. It also applies inside code and math blocks, including custom languages, without adding hidden tags to the file, and the appearance of commented lines can be customized in the editor without altering the stored Markdown.

```cue
plugin: {
    id:     "better-comment-toggle"
    name:   "Better Comment Toggle"
    author: "mrgvsv"
    repo:   "mrgvsv/obsidian-better-comment-toggle"

    html_url:    "https://community.obsidian.md/plugins/better-comment-toggle"
    github_url:  "https://github.com/mrgvsv/obsidian-better-comment-toggle"
    description: "Improved comment toggling."
    about:       "Toggle comments line-by-line or across a selected range, with configurable start and end tokens and preserved indentation. Apply comments inside code and math blocks (including custom languages) in a WYSIWYG way so no hidden tags are added to your files. Customize commented-line appearance in the editor without altering stored Markdown."

    stats: {
        downloads:  5559
        updated_at: 1703448898000
    }
}
```
