# CJK Academic Count

Counts academic characters in Chinese, Japanese and Korean notes and shows whole-note and selection counts in the status bar. The main metric excludes punctuation, numbers, Latin text and whitespace, counting Han, Hiragana, Katakana and Hangul as grapheme clusters. Further reference metrics appear in a tooltip.
