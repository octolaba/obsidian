# Plugin Update Tracker

This plugin tracks which installed plugins have updates and helps evaluate the risk of upgrading. Update status appears in the status bar or the mobile ribbon, and a list shows the pending updates with release notes rendered as Markdown, code diffs and version stats. Updates can be installed or ignored, and beta releases opted into.

```cue
plugin: {
    id:     "obsidian-plugin-update-tracker"
    name:   "Plugin Update Tracker"
    author: "swar8080"
    repo:   "swar8080/obsidian-plugin-update-tracker"

    html_url:    "https://community.obsidian.md/plugins/obsidian-plugin-update-tracker"
    github_url:  "https://github.com/swar8080/obsidian-plugin-update-tracker"
    description: "Know when installed plugins have updates and evaluate the risk of upgrading."
    about:       "Track available plugin updates and show status in the status bar or mobile ribbon. View a list of updates, read release notes rendered as Markdown, inspect code diffs and version stats, install or ignore updates, and opt into beta releases."

    stats: {
        downloads:  164398
        updated_at: 1748641958000
    }
}
```
