# Divide and Conquer

Divide and Conquer provides commands for bulk enabling and disabling of plugins and CSS snippets, to isolate the source of a bug or a performance issue. It follows a binary search strategy, halving the set under test at each step.

```cue
plugin: {
    id:     "obsidian-divide-and-conquer"
    name:   "Divide and Conquer"
    author: "mikedidomizio"
    repo:   "mikedidomizio/obsidian-divide-and-conquer"

    html_url:    "https://community.obsidian.md/plugins/obsidian-divide-and-conquer"
    github_url:  "https://github.com/mikedidomizio/obsidian-divide-and-conquer"
    description: "Commands for bulk enabling/disabling of plugins. Useful for debugging when you have many plugins."
    about:       "Bulk-enable and disable plugins and CSS snippets to isolate the source of bugs or performance issues. Uses a binary search strategy to cut your debugging time in half with each step."

    stats: {
        downloads:  10283
        updated_at: 1785693344000
    }
}
```
