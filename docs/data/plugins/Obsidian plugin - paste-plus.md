# Paste Plus

Converts pasted URLs into titled Markdown links, saves clipboard images into the attachments folder with clean filenames, and turns rich HTML into tidy Markdown. YouTube and Twitter links are replaced with their page or post titles, and the recorded description states that it runs automatically with no setup.

plugin: {

    name:   "Paste Plus"
    author: "jabaho9523"

    github_url:  "https://github.com/jabaho9523/obsidian-paste-plus"
    description: "Smart paste for URLs, images, HTML, YouTube, and Twitter — one plugin, no setup. - This plugin has not been manually reviewed by Obsidian staff."
