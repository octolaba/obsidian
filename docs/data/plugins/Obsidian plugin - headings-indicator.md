# Headings Indicator

Headings Indicator draws heading level markers before each heading, from a single # for H1 up to six for H6. The markers appear in Live Preview and Reading view, so the document structure stays visible while editing and reading.

```cue
plugin: {
    id:     "headings-indicator"
    name:   "Headings Indicator"
    author: "willwang"
    repo:   "willsho/obsidian-headings-indicator"

    html_url:    "https://community.obsidian.md/plugins/headings-indicator"
    github_url:  "https://github.com/willsho/obsidian-headings-indicator"
    description: "Display heading level markers before headings in Live Preview and Reading view. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display heading level markers before headings — # for H1, ## for H2, ### for H3 up to H6. Show the indicators in Live Preview and Reading view to visualize document structure while editing and reading."

    stats: {
        downloads:  140

}
```
