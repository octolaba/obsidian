# OneNote Integration

OneNote Integration embeds and edits OneNote pages inside Obsidian through the local OneNote COM API, embedding live windows rather than screenshots. Notebooks are browsed in a hierarchical sidebar, pages are picked through cascading notebook, section and page controls, and an embed can be detached into a standalone window. Ink stroke previews and rich HTML content are extracted from pages. It requires Windows with OneNote desktop, and macOS supports only basic sidebar browsing through AppleScript.
