# Note Decay

Note Decay schedules note reviews with the SM-2 spaced-repetition algorithm, graded Again, Hard, Good or Easy. How overdue a note is drives colour-coding in the file explorer, on folders and in the graph, existing notes can be seeded from their file dates, and review state is written to frontmatter as last_reviewed, sr_due, sr_interval, sr_ease, sr_reps and sr_lapses.

    id:     "note-decay"
    name:   "Note Decay"

    description: "Color-codes notes by duration since you last reviewed them, using SM-2 spaced repetition. - This plugin has not been manually reviewed by Obsidian staff."

Color-code the file explorer, folders, and graph by overdue status, seed existing notes from file dates, and write review metadata (last_reviewed, sr_due, sr_interval, sr_ease, sr_reps, sr_lapses) to frontmatter."
