# Graph Edge Notes

Renders short relationship labels on graph-view edges, reading the relations from note frontmatter and showing optional detail on hover in a configurable label colour. A command adds relations for the current note, and an optional debug panel and log are available. The linked notes must already create the graph edges being annotated.

```cue
plugin: {
    id:     "graph-edge-notes"
    name:   "Graph Edge Notes"
    author: "li-zane"
    repo:   "li-zane/obsidian-graph-edge-notes"

    html_url:    "https://community.obsidian.md/plugins/graph-edge-notes"
    github_url:  "https://github.com/li-zane/obsidian-graph-edge-notes"
    description: "Display and edit short relationship labels on graph edges. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render short relationship labels on graph-view edges by reading relations from note frontmatter and show optional detail on hover with a configurable label color. Add relations for the current note via a command, view an optional debug panel and log, and require that linked notes already create the graph edges being annotated."
```
