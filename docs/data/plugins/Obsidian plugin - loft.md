# Loft

Uploads pasted or dragged images to Google Drive and inserts remote links in the note instead, which the recorded description presents as a way to keep the vault small. Existing local embeds can be converted, and Drive link formats re-resolved or changed without uploading again. Sign-in uses the Google OAuth device flow on desktop and mobile.
