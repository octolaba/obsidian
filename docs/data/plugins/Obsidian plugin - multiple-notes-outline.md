# Multiple Notes Outline

Adds views that show the outlines of several notes at once, listing headings, links, tags and list items. File View shows the active file together with the outlines of its outgoing links and backlinks, a local graph at depth one. Folder View lists the outlines of every file in a selected folder.

    id:     "multiple-notes-outline"
    name:   "Multiple Notes Outline"
    author: "iiz00"
