# Knowledge Objects

Renders semantic objects declared in Markdown fenced code blocks. Local music blocks become interactive audio players showing title, artist, cover image, playback progress and duration. Audio and image files are referenced relative to the vault, it works on desktop and mobile, and the Markdown stays readable when the plugin is disabled.

```cue
plugin: {
    id:     "knowledge-objects"
    name:   "Knowledge Objects"
    author: "LockedCore"
    repo:   "linye0/knowledge-objects"

    html_url:    "https://community.obsidian.md/plugins/knowledge-objects"
    github_url:  "https://github.com/linye0/knowledge-objects"
    description: "Render semantic objects in Markdown. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render local music fenced code blocks as interactive audio players that show title, artist, cover image, playback progress, and duration. Use vault-relative audio and image files, work on desktop and mobile, and preserve readable Markdown when the plugin is disabled."
```
