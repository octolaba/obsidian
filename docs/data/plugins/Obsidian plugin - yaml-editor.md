# YAML Editor

Provides a focused YAML editing mode for frontmatter, fenced yaml or yml code blocks, and standalone .yaml and .yml files. Completions are schema-aware, learned from the vault or from JSON Schemas, and a snippet palette, structural indentation and folding assist editing. Key order, comments and whitespace survive the round trip.
