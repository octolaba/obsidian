# Transcription

Audio and video files linked from Markdown are transcribed into text by a local, open-source Whisper engine. Lines can carry start and end timestamps, several files are processed at once, transcription runs in the background, and many formats are handled through ffmpeg.

```cue
plugin: {
    id:     "obsidian-transcription"
    name:   "Transcription"
    author: "djmango"
    repo:   "djmango/obsidian-transcription"

    html_url:    "https://community.obsidian.md/plugins/obsidian-transcription"
    github_url:  "https://github.com/djmango/obsidian-transcription"
    description: "Create high-quality transcriptions via Whisper from Markdown linked audio files."
    about:       "Transcribe audio and video files into accurate text using a local, open-source Whisper ASR engine. Include start/end timestamps per line, process multiple files simultaneously, run transcriptions in the background, and handle many formats via ffmpeg."

    stats: {
        downloads:  32095
        updated_at: 1712940954000
    }
}
```
