# RU AI Assist

Rewrites selected text in place with a language model, applying the change immediately, and opens a sidebar chat whose conversations can be saved to notes. Every edit is recorded in a side-panel journal with word-level diffs and undo buttons. A built-in local cleanup removes extra spaces and invisible characters without sending data to a server.
