# Lava VTT Uploader

Lava VTT Uploader displays images from the vault on a self-hosted Lava VTT instance. Once the server connection is configured, any image in a note can be pushed to the tabletop display from its right-click menu.

```cue
plugin: {
    id:     "lava-vtt-uploader"
    name:   "Lava VTT Uploader"
    author: "lavaforge"
    repo:   "lavaforge/obsidian-lava-vtt-uploader"

    html_url:    "https://community.obsidian.md/plugins/lava-vtt-uploader"
    github_url:  "https://github.com/lavaforge/obsidian-lava-vtt-uploader"
    description: "Display images from your vault in Lava VTT."
```
