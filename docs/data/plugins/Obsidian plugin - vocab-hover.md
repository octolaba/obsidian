# Vocab Hover

Vocab Hover attaches a tooltip to selected text from the right-click menu and stores it inline as a word and tooltip pair in braces, which suits translations, definitions and short annotations. Tooltips appear on hover in Reading View, and the highlight appearance is customizable. An auto-updating vocabulary list collects the entries and links back to the source notes.

```cue
plugin: {
    id:     "vocab-hover"
    name:   "Vocab Hover"
    author: "chingchen0119"
    repo:   "chingchen0119/obsidian-vocab-hover"

    html_url:    "https://community.obsidian.md/plugins/vocab-hover"
    github_url:  "https://github.com/chingchen0119/obsidian-vocab-hover"
    description: "Add hover tooltips to words by right-clicking selected text. Perfect for vocabulary learning. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add hover tooltips to any word or phrase and save them inline as {word::tooltip} for quick translations, definitions, or annotations. View tooltips by hovering in Reading View, customize highlight appearance, and generate an auto-updating vocabulary list that links back to source notes."

    stats: {
        downloads:  188
        updated_at: 1776488430000
    }
}
```
