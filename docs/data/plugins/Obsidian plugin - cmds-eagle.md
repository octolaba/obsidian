# CMDS Eagle

Connects an Eagle asset library to the vault so images can be searched and embedded straight into notes. Pasted, dropped or local images are uploaded to ImgHippo, Cloudflare R2, S3 or WebDAV storage, local images are converted to cloud URLs in bulk, and image paths are converted for syncing between macOS and Windows.
