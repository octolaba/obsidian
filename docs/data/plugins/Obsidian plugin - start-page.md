# Startpage

A startup dashboard opens in place of new tabs, showing vault statistics, pinned notes and recently modified files. Notes are pinned and reordered, a built-in box searches instantly, and the page is reachable from the toolbar or the command palette. Timestamps are relative and the view refreshes in real time.
