# Advanced PDF Export

Advanced PDF Export exports notes to PDF with a full-resolution live page preview in A4, A3, A5, Letter or Legal that follows edits as they happen. Style presets, manual page breaks, automatic breaks before a first or second level heading, and controls for layout, typography, margins, headers, footers and colors shape the result, which is written out through a native save dialog.
