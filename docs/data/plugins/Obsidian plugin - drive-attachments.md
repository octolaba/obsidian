# Drive Attachments

Offloads attachments to Google Drive: a file dropped into a note is uploaded and replaced by a durable Drive link, with content-hash deduplication, so the vault stays small. A sidebar file manager browses, searches, uploads and organizes Drive content, and Drive notes can be inserted from a search. Authentication goes through direct OAuth with a Google account rather than a third-party server.
