# Image OCR

Runs OCR on pasted images and writes the recognized text into each image's description box. That makes the contents of an image searchable and keeps the extracted text beside the note.

```cue
plugin: {
    id:     "image-ocr"
    name:   "Image OCR"
    author: "kaffarell"
    repo:   "kaffarell/obsidian-tesseract-ocr"

    html_url:    "https://community.obsidian.md/plugins/image-ocr"
    github_url:  "https://github.com/kaffarell/obsidian-tesseract-ocr"
    description: "Run OCR on images and paste the result in the description."
    about:       "Run OCR on pasted images and add the extracted text to each image's details box. Make image contents searchable and include recognized text alongside your notes for quick reference."

    stats: {
        downloads:  6695
        updated_at: 1692029362000
    }
}
```
