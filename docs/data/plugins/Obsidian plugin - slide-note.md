# Slide Note

Slide Note binds plaintext class notes to specific pages of a PDF slide deck and renders the slides alongside the notes together with graphic annotations. Per-file frontmatter controls the rendering, large slide decks are handled efficiently, and the view re-renders automatically when the source PDF changes.

```cue
plugin: {
    id:     "slide-note"
    name:   "Slide Note"
    author: "phantom1003"
    repo:   "phantom1003/obsidian-slide-note"

    html_url:    "https://community.obsidian.md/plugins/slide-note"
    github_url:  "https://github.com/phantom1003/obsidian-slide-note"
    description: "Conveniently take notes on PDF course slides."
    about:       "Take plaintext class notes bound to specific slide pages and render slides alongside your graphic annotations. Use per-file frontmatter to control rendering, handle large slide decks efficiently, and auto-rerender when the source PDF changes."
```
