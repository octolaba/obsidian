# Spoiler

Selected text is wrapped in a collapsible spoiler callout from a button in the left ribbon, and any Markdown inside the selection is preserved. Pressing the button again on an existing spoiler unwraps it back to plain text.

```cue
plugin: {
    id:     "spoiler"
    name:   "Spoiler"
    author: "PatruusBarba"
    repo:   "patruusbarba/ObsidianSpoilerPlugin"

    html_url:    "https://community.obsidian.md/plugins/spoiler"
    github_url:  "https://github.com/patruusbarba/ObsidianSpoilerPlugin"
    description: "Wrap selected text in a collapsible spoiler callout, or unwrap an existing spoiler, from a ribbon button. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Hide and reveal sensitive text with a single click. Select text and click the left-ribbon Spoiler button to wrap it in a collapsible spoiler callout that preserves any Markdown. Click the button again on a spoiler to unwrap it back to plain text."

    stats: {
        downloads:  329
        updated_at: 1781566639000
    }
}
```
