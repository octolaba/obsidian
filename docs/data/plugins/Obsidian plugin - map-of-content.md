# Map of Content

Map of Content generates a map of content for the vault by showing the shortest path or paths from a chosen central note to the note currently open, together with that note's descendants. The map updates automatically as notes are switched, and all equal-length alternative paths are listed so a note can appear in several contexts. It is rendered in a side pane beside the editor.
