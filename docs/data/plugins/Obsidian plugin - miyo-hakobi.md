# MiYo Hakobi

MiYo Hakobi ferries files on a schedule between the vault and local filesystem paths, with no network surface, cloud APIs or background daemon according to its recorded text. Import and export rules are defined individually with a folder, tag or note source, devices opt in one by one, and each run writes a metadata-only NDJSON audit log.

    id:     "miyo-hakobi"
    name:   "MiYo Hakobi"

Local Filesystem <=> Vault - Import / Export — import voice memos / snippets / etc. into your inbox, export folders / tags / notes to external locations. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Ferry files on a schedule between your Obsidian vault and local filesystem paths with no network surface, cloud APIs, or background daemon. Create per-rule import or export rules (folder, tag, or note sources), opt in per device, and record metadata-only NDJSON audit logs for each run."
