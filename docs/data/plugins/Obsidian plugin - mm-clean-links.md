# MM Clean Links

Changes what a click does on a link in Live Preview so links can be edited without being followed: a single click places the cursor and a double click selects the whole phrase between the brackets, for internal links, external links or raw URLs. A hotkey formats the titles of external links consistently across the current note or the whole vault, toggling between sentence style and Associated Press style. Both behaviors are configurable, and a third formatting option is available with a warning attached.

```cue
plugin: {
    id:     "mm-clean-links"
    name:   "MM Clean Links"
    author: "Math Math"
    repo:   "lemathmath/Obsidian_MM-Clean-Links"

    html_url:    "https://community.obsidian.md/plugins/mm-clean-links"
    github_url:  "https://github.com/lemathmath/Obsidian_MM-Clean-Links"
    description: "Streamlines editing various types of links while in Live Preview mode, as well as automating consistent formatting for the titles of external links. #cleaner #links #capitalize #lowercase #uppercase - This plugin has not been manually reviewed by Obsidian staff."
    about:       "• Click behavior while in \"Live Preview\" editing: Allows to click on links without activating them, to make editing text or addresses easier. Single-click places the cursor. Double-click selects the whole phrase between the brackets. Can work for internal links, external links, or raw URLs. • External links title formatting: Allows to make the titles formatted consistently in the current note or throughout the whole vault. With the assigned hotkey, toggle once for the \"Sentence\" style (Upper, then all lower) and again for the \"Associated Press\" style (Upper, Then Upper and Upper Again). • Both enhancement can be customized via a few handy settings, as well as adding a third formatting option (comes with a warning)"
```
