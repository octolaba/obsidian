# Open vault in VS Code

Open vault in VS Code opens the vault as a Visual Studio Code workspace from a ribbon button, the file explorer context menu or a command. It launches through the code CLI or a vscode URL handler and can be bound to a hotkey, leaving git, formatting, linting and similar workspace work to VS Code.
