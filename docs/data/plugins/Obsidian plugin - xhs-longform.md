# XHS Longform Exporter

Turns the active note into a paginated set of 3:4 image cards for Xiaohongshu, previewed inside Obsidian and exported as one PNG per page. Title, subheading and body font sizes control how the text splits across pages, the filename becomes the card title, and H1 and H2 headings become visual section headings. Three OFL-licensed Chinese fonts are bundled, compatible system fonts or imported TTF, OTF, WOFF and WOFF2 files can be used instead, and rendering and export stay local with no analytics and no network requests.
