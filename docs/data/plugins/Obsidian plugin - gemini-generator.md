# Gemini Generator

Generates the content of a note from its title with a single command by sending the title to the Google Gemini API. The recorded text names custom prompt templates and automatic response formatting as planned rather than existing features.

```cue
plugin: {
    id:     "gemini-generator"
    name:   "Gemini Generator"
    author: "bjarnerentz"
    repo:   "bjarnerentz/obsidian-gemini-generator"

    html_url:    "https://community.obsidian.md/plugins/gemini-generator"
    github_url:  "https://github.com/bjarnerentz/obsidian-gemini-generator"
    description: "Let Google Gemini generator your notes!"
    about:       "Generate notes from a note title using Google Gemini with a single command. Send the note title to the Gemini API to produce content, with planned support for custom prompt templates and automatic response formatting."

    stats: {
        downloads:  4550
        updated_at: 1771166774000
    }
}
```
