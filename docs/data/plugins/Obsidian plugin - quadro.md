# Quadro

Supports qualitative data analysis in Obsidian, storing both the data and the research codes as Markdown so the material stays readable and future-proof. Coding follows Grounded Theory, findings are extracted and aggregated through Qualitative Content Analysis workflows, and progress and theoretical saturation are tracked. The recorded description positions it as an open alternative to MAXQDA and atlas.ti for social scientists.
