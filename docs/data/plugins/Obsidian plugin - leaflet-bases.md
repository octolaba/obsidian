# Leaflet bases

Leaflet bases adds a Leaflet map view to Bases together with a marker property type, so that notes carry interactive markers whose data is stored inside the note. Image-based maps are embedded with zoom and scale, which its recorded inputs aim at fantasy maps. It also works with vaults published through Quartz gardens, using a separate Quartz plugin.

plugin: {
    id:     "leaflet-bases"
    name:   "Leaflet bases"
    author: "Sara Lilith Slootmaker"

    html_url:    "https://community.obsidian.md/plugins/leaflet-bases"
    github_url:  "https://github.com/requiae/obsidian-leaflet-bases-plugin"
    description: "Interactive fantasy map view inside your bases. - This plugin has not been manually reviewed by Obsidian staff."

Ideal for fantasy maps! Also works with vaults published with Quartz gardens (using a separate Quartz plugin)."
