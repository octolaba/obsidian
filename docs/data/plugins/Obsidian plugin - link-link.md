# Link Link

Finds semantically similar notes and lists them in a side panel, ranked by a similarity score between 0.00 and 1.00 and color-coded for relevance. Results can be opened, viewed as a native-style graph, dragged into the editor to paste a link, or clicked to add and remove relations, and the whole vault can be interconnected in one command. The recorded inputs state that all processing stays local.

```cue
plugin: {
    id:     "link-link"
    name:   "Link Link"
    author: "Artie Tsoy"
    repo:   "artieficr/link-link"

    html_url:    "https://community.obsidian.md/plugins/link-link"
    github_url:  "https://github.com/artieficr/link-link"
    description: "Link Link! finds semantically similar notes and shows them in a side panel. Click to open, drag into the editor to paste a [[link]], or batch-interconnect your entire vault in one command! - This plugin has not been manually reviewed by Obsidian staff."

Keep all processing local and private."
