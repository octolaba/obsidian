# Note Age Highlighter

Note Age Highlighter marks notes in the file explorer that have not been modified for a configurable number of days. The age threshold and the highlight colour are settings, staleness is judged from the last-modified time, and the recorded description states that changes apply instantly and that the plugin is lightweight and dependency-free.

    id:     "note-age-highlighter"
    name:   "Note Age Highlighter"
    author: "ImeMine"

    html_url:    "https://community.obsidian.md/plugins/note-age-highlighter"
    github_url:  "https://github.com/memineoff/note-age-highlighter"
