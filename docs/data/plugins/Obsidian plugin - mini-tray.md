# Mini Tray

Mini Tray makes closing Obsidian hide it in the system tray instead of quitting. Clicking the tray icon toggles show and hide, and right-clicking quits the app. The recorded description gives its size as roughly 5 KB with zero configuration, and it is limited to a single desktop window.

```cue
plugin: {
    id:     "mini-tray"
    name:   "Mini Tray"
    author: "Damon"
    repo:   "wangdamon6-hub/obsidian-mini-tray"

    html_url:    "https://community.obsidian.md/plugins/mini-tray"
    github_url:  "https://github.com/wangdamon6-hub/obsidian-mini-tray"
    description: "Close Obsidian to system tray. ~5 KB, zero config. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Close Obsidian to hide it in the system tray instead of quitting. Click the tray icon to toggle show/hide and right-click to quit; desktop single-window only."

    stats: {
        downloads:  110
        updated_at: 1784034336000
    }
}
```
