# Timetracker

Timetracker adds a persistent stopwatch whose elapsed value is restored across restarts. The current value can be inserted into the editor with a hotkey, a custom start value set when the timer was started late, and the pasted format adjusted through options for trimming zeros, a line break and color.

```cue
plugin: {
    id:     "timetracker"
    name:   "Timetracker"
    author: "hedgehog1833"
    repo:   "hedgehog1833/obsidian-timetracker"

    html_url:    "https://community.obsidian.md/plugins/timetracker"
    github_url:  "https://github.com/hedgehog1833/obsidian-timetracker"

    about:       "Add a persistent stopwatch to Obsidian to track elapsed time and restore the value across restarts. Insert the current timestamp into notes via hotkey or set a custom start value if you forgot to start, and paste using customizable formats (trim zeros, line break, color)."
```
