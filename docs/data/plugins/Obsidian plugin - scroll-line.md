# Scroll Line

Scroll Line scrolls the editor viewport up or down by a configurable number of lines while leaving the cursor where it is. Scrolling can be smoothly animated and repeats continuously while a key is held, using CodeMirror 6's native key handling and the actual line height so that the result stays accurate across themes.

```cue
plugin: {
    id:     "scroll-line"
    name:   "Scroll Line"
    author: "abdelrahmanhafez"
    repo:   "abdelrahmanhafez/obsidian-scroll-line"

    html_url:    "https://community.obsidian.md/plugins/scroll-line"
```
