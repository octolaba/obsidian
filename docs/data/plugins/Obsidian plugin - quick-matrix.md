# Quick Matrix

Adds a command for working with LaTeX matrices inside a note. Common matrix templates are inserted, a selection is converted into a matrix environment, and entries are edited inline.

```cue
plugin: {
    id:     "quick-matrix"
    name:   "Quick Matrix"
    author: "thewheelbarrow"
    repo:   "thewheelbarrow/quick-matrix"

    html_url:    "https://community.obsidian.md/plugins/quick-matrix"
    github_url:  "https://github.com/thewheelbarrow/quick-matrix"
    description: "Adds command to make LaTeX matrices quickly."
    about:       "Add a command to interact with LaTeX matrices inside notes. Insert common matrix templates, convert selections into matrix environments, and edit entries inline for faster LaTeX matrix authoring."
```
