# OpenAugi

OpenAugi gathers bounded context from the vault for agents by following wikilinks and backlinks, filtering journals and enforcing token budgets. Persistent agent sessions are launched and managed from task notes, with the assembled context injected and results written back. Raw content, including voice notes, is distilled into atomic notes, transcripts, tasks and summaries.
