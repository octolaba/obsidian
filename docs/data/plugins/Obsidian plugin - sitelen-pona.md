# Sitelen Pona

Sitelen Pona toggles note display between a regular font and the sitelen-pona script used for Toki Pona notes. The line currently being edited is shown in the regular font for easier editing, and prefixing a line with two exclamation marks forces the regular font.

```cue
plugin: {
    id:     "sitelen-pona"
    name:   "Sitelen Pona"
    author: "luanalatte"
    repo:   "luanalatte/obsidian-sitelen-pona"

    html_url:    "https://community.obsidian.md/plugins/sitelen-pona"
    github_url:  "https://github.com/luanalatte/obsidian-sitelen-pona"
    description: "Toggle a Sitelen Pona font in your notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Toggle note display between regular and Sitelen Pona script for Toki Pona notes to view content in the sitelen-pona font. Show the current editing line in regular font for easier editing, and prefix a line with !! to force regular font."

    stats: {
        downloads:  153
        updated_at: 1773337488000
    }
}
```
