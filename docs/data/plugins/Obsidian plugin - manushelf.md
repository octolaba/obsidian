# Manushelf

Manushelf presents a folder of Markdown manuscripts as a responsive 3D bookshelf, rendering each direct child folder as a book with a discovered cover and entry note. Title, description, cover and entry are edited through a prefilled form rather than hand-written JSON. The shelf is drawn with Three.js using asset-backed lighting and a reversible book-opening animation, with responsive column layouts, a cover-list fallback where WebGL is unavailable, and fully offline operation.
