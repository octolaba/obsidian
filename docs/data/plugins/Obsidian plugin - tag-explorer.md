# Tag Explorer

Presents the vault as a folder tree generated from tags, where each tag namespace becomes an independent folder and a note tagged in several namespaces appears in each of them. Custom icons and item counts are assigned, namespaces isolated, and cross-namespace filters applied. The recorded About text names namespace-aware deduplication and prefix-based ignoreTag matching as what keeps the listings accurate.

Assign custom icons, show item counts, isolate namespaces or apply cross-namespace filters, and rely on namespace-aware deduplication and prefix-based ignoreTag matching for accurate listings."
