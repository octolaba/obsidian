# Dialogue Mode

Dialogue Mode fades out non-dialogue text so that spoken lines stand out while writing. Both the fade intensity and the color of dialogue text are adjustable.

```cue
plugin: {
    id:     "dialogue-mode"
    name:   "Dialogue Mode"
    author: "patrickchiang"
    repo:   "patrickchiang/obsidian-dialogue-mode"

    html_url:    "https://community.obsidian.md/plugins/dialogue-mode"
    github_url:  "https://github.com/patrickchiang/obsidian-dialogue-mode"
    description: "Dialogue mode for editing speech in writing."
    about:       "Fade out non-dialogue text to spotlight spoken lines while writing. Adjust fade intensity and dialogue text color to suit your focus and style."

    stats: {
        downloads:  2039
        updated_at: 1727650955000
    }
}
```
