# Diff and Patch Viewer

Opens .diff and .patch files in a read-only pane with additions and deletions highlighted. It shows the file list, per-file statistics and hunk headers, and falls back to raw read-only text when no unified diff hunk is detected.

```cue
plugin: {
    id:     "diff-patch-viewer"
    name:   "Diff and Patch Viewer"
    author: "Viggo Meesters"
    repo:   "viggomeesters/obsidian-diff-patch-viewer"

    html_url:    "https://community.obsidian.md/plugins/diff-patch-viewer"
    github_url:  "https://github.com/viggomeesters/obsidian-diff-patch-viewer"
    description: "Read-only viewer for .diff and .patch files with file, hunk, and additions/deletions summaries. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "View .diff and .patch files in a read-only Obsidian pane with highlights for additions and deletions. Show file lists, per-file stats and hunk headers; fall back to raw read-only text when no unified diff hunk is detected."

    stats: {
        downloads:  79
        updated_at: 1781424777000
    }
}
```
