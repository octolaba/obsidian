# ZettelFlow

ZettelFlow builds Zettelkasten note workflows on the Obsidian canvas. A root note is linked by arrows to steps, which may be notes, groups or canvas cards, and each step carries actions that create or edit notes as the flow is walked through.

    id:     "zettelflow"
