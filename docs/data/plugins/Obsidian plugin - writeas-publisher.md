# Writeas Blog Publisher

Publishes notes to Write.as blogs the author owns, or to a self-hosted WriteFreely instance, from inside the vault. The post identifier and URL are written into the note frontmatter, so a later publish updates that same post instead of creating a new one.

```cue
plugin: {
    id:     "writeas-publisher"
    name:   "Writeas Blog Publisher"
    author: "encima"
    repo:   "encima/obsidian-writeas-plugin"

    html_url:    "https://community.obsidian.md/plugins/writeas-publisher"
    github_url:  "https://github.com/encima/obsidian-writeas-plugin"
    description: "Publish notes to any write.as blogs you own."
    about:       "Publish Obsidian notes to Write.as or a self-hosted WriteFreely instance directly from your vault. Add the post ID and URL to note frontmatter and update the same post on subsequent publishes."

    stats: {
        downloads:  3413
        updated_at: 1693759001000
    }
}
```
