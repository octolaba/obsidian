# Auto Tag

Auto Tag generates tags for whole notes or for a selected passage of text. Its recorded description states only that those tags are meant to be relevant to the content.

```cue
plugin: {
    id:     "auto-tag"
    name:   "Auto Tag"
    author: "ctrlaltfocus"
    repo:   "ctrlaltfocus/obsidian-plugin-auto-tag"

    html_url:    "https://community.obsidian.md/plugins/auto-tag"
    github_url:  "https://github.com/ctrlaltfocus/obsidian-plugin-auto-tag"
    description: "Easily generate relevant tags for your notes or selected text."
```
