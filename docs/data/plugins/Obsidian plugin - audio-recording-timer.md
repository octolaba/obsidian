# Audio Recording Timer

Starts the core Obsidian audio recorder with a countdown duration or a scheduled end time and stops it automatically when the time is up. Remaining time is shown in the status bar, durations can be quick-added, and a running recording can be stopped or extended. The core Audio recorder plugin has to be enabled for the timer to work.

```cue
plugin: {
    id:     "audio-recording-timer"
    name:   "Audio Recording Timer"
    author: "Musashino Software"
    repo:   "mssoftjp/obsidian-audio-recording-timer"

    html_url:    "https://community.obsidian.md/plugins/audio-recording-timer"
    github_url:  "https://github.com/mssoftjp/obsidian-audio-recording-timer"
    description: "Start audio recording with a countdown or end time. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Start Obsidian's core audio recorder with a countdown duration or a scheduled end time and auto-stop when time is up. Display remaining time in the status bar, use quick-add durations, and stop or extend recording while underway. Enable Obsidian's core Audio recorder to use the timer."

    stats: {
        downloads:  129
        updated_at: 1779284484000
    }
}
```
