# Leadsheet

Leadsheet renders ChordPro lead sheets as performance-ready scores with per-file transposition, capo-aware chord shapes and CJK-safe alignment of chords over lyrics. Guitar chord diagrams, scrollable set lists and hands-free autoscroll paced to the song duration support playing from the rendered sheet. Live authoring aids and a command-line tool for validation and export are also recorded.
