# Fancy Charts

Renders interactive charts inside notes from a plain Markdown table held in each block, so the data stays readable without the plugin. Eight chart types are available - bar, line, pie, scatter, area, funnel, heatmap and sankey - and raw ECharts options can be supplied instead for full control. Charts are edited through a live-preview builder.

```cue
plugin: {
    id:     "fancy-charts"
    name:   "Fancy Charts"
    author: "Roberto Allende"
    repo:   "robertoallende/fancy-charts"

    html_url:    "https://community.obsidian.md/plugins/fancy-charts"
    github_url:  "https://github.com/robertoallende/fancy-charts"
    description: "Interactive charts inside any note. The data lives as a plain Markdown table inside each block — readable and AI-friendly even without the plugin. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed interactive charts directly in notes using plain Markdown tables as the data source. Choose from eight chart types — bar, line, pie, scatter, area, funnel, heatmap, and sankey — or supply raw ECharts options for full control. Edit charts via a live-preview builder while keeping data human-readable in any editor."

    stats: {
        downloads:  99
        updated_at: 1785831411000
    }
}
```
