# HTML Viewer Plus

HTML Viewer Plus previews and embeds HTML and MHTML files through wiki-link embeds, optionally targeting an element by its identifier. Embeds take custom sizes or ratios, and the viewer adds zoom, in-page search, full-screen and external opening, automatic reload on edits and dark-mode syncing. A right-click menu copies the embed or link syntax.
