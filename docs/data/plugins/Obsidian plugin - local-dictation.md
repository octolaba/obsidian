# Local Dictation

Provides local speech-to-text and text-to-speech for notes and meetings: live dictation, transcription of microphone and system audio with Whisper and other models, speaker labels and timestamps, and reshaping of transcripts. The recorded About text, written for the renamed Speech Kit, adds translation across eight languages and read-aloud voices, and states that core dictation, transcription, translation and read aloud run on the device and keep working offline without an account, subscription or API key. It targets desktop Obsidian on macOS, Windows and Linux, and optional LLM tools may use a local model or a remote provider.

Built for desktop Obsidian on macOS, Windows, and Linux, Speech Kit lets you choose the models that fit your language, hardware, and priorities.
