# Speech Kit

Adds speech tooling to desktop Obsidian on macOS, Windows and Linux: dictation, transcription of meetings and calls, translation across eight languages, and reading text aloud with natural voices. Models are selectable, with NVIDIA and Whisper engines named, and core dictation, transcription, translation and read-aloud run on the device and offline, without an account, subscription, API key or metered usage. Optional cleanup, summarizing and reshaping of transcripts can use a local model or a remote provider. The plugin was formerly called Local Dictation and is presented as Speech Kit.
