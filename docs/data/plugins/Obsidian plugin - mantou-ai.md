# MantouAI

MantouAI works as a personal assistant inside Obsidian, using large language models for translation, writing polish, general question answering and summarizing. It answers questions about selected text, extracts viewpoints from it and supports deep reading. Conversational roles are assigned to the assistant through note properties.
