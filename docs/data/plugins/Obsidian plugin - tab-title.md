# Tab Title Customization

Customizes how tab titles are rendered, showing the full file path so notes with identical names can be told apart. File extensions and leading slashes can also be displayed, and title truncation is configurable to keep tabs readable.

```cue
plugin: {
    id:     "tab-title"
    name:   "Tab Title Customization"
    author: "Bridger Herman"
    repo:   "bridger-herman/obsidian-tab-title-plugin"

    html_url:    "https://community.obsidian.md/plugins/tab-title"
    github_url:  "https://github.com/bridger-herman/obsidian-tab-title-plugin"
    description: "Provides customization options for tab titles, including truncation, adding file extensions, and paths. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Customize tab titles to display full file paths and disambiguate notes with identical names. Show file extensions and leading slashes and control title truncation to keep tabs readable."

    stats: {
        downloads:  29
        updated_at: 1785443146000
    }
}
```
