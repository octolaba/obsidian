# Scroll Control

Scrolls the editor viewport one line at a time with Ctrl+Up and Ctrl+Down, leaving the cursor fixed, as code editors do. Separate scroll-up and scroll-down commands are exposed in the command palette, so alternate keys can be bound to them.

```cue
plugin: {
    id:     "scroll-control"
    name:   "Scroll Control"
    author: "Sorin Gherghisan"
    repo:   "soringherghisan/obsidian-scroll-control"

    html_url:    "https://community.obsidian.md/plugins/scroll-control"
    github_url:  "https://github.com/soringherghisan/obsidian-scroll-control"
    description: "Scroll one line at a time with Ctrl+Up/Down, just like in VSCode and other code editors. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Scroll the editor viewport one line at a time with Ctrl+Up and Ctrl+Down while keeping the cursor fixed. Access dedicated scroll-up/scroll-down commands from the command palette to use or rebind alternate keys."

    stats: {
        downloads:  31
        updated_at: 1785681813000
    }
}
```
