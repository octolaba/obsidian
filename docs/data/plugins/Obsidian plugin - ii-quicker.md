# ii

ii inserts common Markdown and HTML snippets, among them superscript and subscript, audio, video, iframes, left, center and right alignment, variables, footnotes, callouts, anchors and HTML comments. A color panel and media dialogs pick colors and add images, links or embeds. Custom insertion commands can be defined, and which commands appear in the context menu is configurable.

```cue
plugin: {
    id:     "ii-quicker"
    name:   "ii"
    author: "wish5115"
    repo:   "wish5115/obsidian-ii-quicker"

    html_url:    "https://community.obsidian.md/plugins/ii-quicker"
    github_url:  "https://github.com/wish5115/obsidian-ii-quicker"
    description: "Quickly insert common Markdown code and HTML code, and customize your own insertion commands."
    about:       "Insert common Markdown and HTML snippets quickly, including sup/sub, audio, video, iframe, left/center/right alignment, variables, footnotes, callouts, anchors and HTML comments. Use a color panel and media dialogs to pick colors, add images, links or embeds. Create custom commands and toggle which commands appear in the context menu for quick access."

    stats: {

}
```
