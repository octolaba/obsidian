# Setting Renamer

Setting Renamer customises the Settings sidebar by renaming tabs, swapping their Lucide icons and hiding plugin panels that are not wanted, including one-click renaming to Chinese. A responsive dashboard searches and jumps to any settings panel. A fail-safe lock prevents hiding the renamer itself, and defaults are restored automatically when the plugin is disabled.
