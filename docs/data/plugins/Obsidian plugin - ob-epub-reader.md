# EPUB Marginalia

Reads EPUB files inside Obsidian with a table-of-contents sidebar, progress tracking, and a choice of paginated or scrolling modes. Passages can be highlighted and annotated with colored margin notes, which export to Markdown excerpts carrying deep links back to the exact passage. Selections can optionally be sent to OpenAI-compatible APIs for interpretation.
