# Marp Extended

Marp Extended creates Marp slide decks from Markdown notes inside Obsidian, with preview, presentation and export to HTML, PDF or PPTX through the Marp CLI. Obsidian image wiki-links are converted to standard Markdown so they resolve in the deck, and Mermaid diagrams are rendered. Bundled or custom Marp themes can be applied.

```cue
plugin: {
    id:     "marp-extended"
    name:   "Marp Extended"
    author: "shuuul"
    repo:   "shuuul/obsidian-marp-extended"

    html_url:    "https://community.obsidian.md/plugins/marp-extended"
    github_url:  "https://github.com/shuuul/obsidian-marp-extended"
    description: "Create markdown-based Marp presentations in Obsidian with extended Marp support - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create Marp slide decks from Markdown notes inside Obsidian. Preview, present, and export decks as HTML, PDF, or PPTX using Marp CLI; convert Obsidian image wiki-links to standard Markdown, render Mermaid diagrams, and apply bundled or custom Marp themes."

    stats: {
        downloads:  175
        updated_at: 1783788296000
    }
}
```
