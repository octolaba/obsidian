# Granola Notes and Transcript Merger

Merges Granola meeting notes with their raw transcripts into a single document or into clipboard-ready text. Matching transcripts are discovered automatically, with a fuzzy-finder fallback, and the merged output can be previewed in an interactive dashboard before a unified Markdown file is created or the text is copied. Output layout is controlled by customizable templates.
