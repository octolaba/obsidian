# Advanced Graph View

An alternative graph view for large vaults that draws a WebGL graph in which node size, colour and glow are driven by metrics such as usage, hubs, orphaned notes and missing links. Clusters, local opens and a timeline are surfaced, and the graph can be filtered or zoomed into N-hop neighborhoods for focused analysis. The index description also lists 3D visualization, PageRank and colour schemes.
