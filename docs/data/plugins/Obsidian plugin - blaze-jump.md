# BlazeJump

BlazeJump moves the cursor through text with five navigation modes: word start, word end, line start, line end, and any character. Targets are indexed and tagged for keyboard selection, with support for several keyboard layouts, customizable bindings, and a toggle-and-jump action that cycles between the modes.
