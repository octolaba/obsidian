# PDF.notes

Opens PDFs in Obsidian and draws on their pages, saving the strokes and shapes back into the PDF file. An adjustable pen, shape tools and an eraser are available, blank, lined, grid, dotted and Cornell pages can be inserted or deleted, auto-save and optional backups can be enabled, and annotations can be flattened for any PDF viewer.
