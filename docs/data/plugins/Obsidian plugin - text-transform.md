# Text Transform

Text Transform converts selected text between casings, among them lowercase, UPPERCASE, Title Case, camelCase, PascalCase, snake_case and kebab-case, driven from keyboard shortcuts. Simple edits such as adding a line above or below are included, and Title Case is tuned with ignored words and alternate word boundaries.
