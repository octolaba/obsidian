# Open in IDE

Open in IDE opens the active vault file in an external IDE, covering .md, .base, .canvas and other file types. It reuses or spawns a Cursor window, can focus a configured .code-workspace, and jumps to the exact file and cursor position, which requires the Cursor CLI.

```cue
plugin: {
    id:     "open-in-ide"
    name:   "Open in IDE"
    author: "Erik-Jan"
    repo:   "carlstedt1/open-in-ide"

    html_url:    "https://community.obsidian.md/plugins/open-in-ide"
    github_url:  "https://github.com/carlstedt1/open-in-ide"

    about:       "Open the current vault file in your IDE of choice, including .md, .base, .canvas and other file types. Reuse or spawn Cursor windows, optionally focus a configured .code-workspace, and jump to the exact file and cursor position (requires Cursor CLI)."
```
