# YourPulse - Your Writing Activity Visualised

Counts words written per day across the vault and shows the writing activity as a GitHub-style contribution graph with streaks and daily averages. Selected notes can be shared and a public profile published, with Dataview content rendered and internal links resolved. A private mode keeps the data inside the vault.
