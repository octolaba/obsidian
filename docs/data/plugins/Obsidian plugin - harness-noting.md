# Harness Noting

Harness Noting validates notes against scoped rules covering files, folders, tags, filename patterns, headings and frontmatter properties, using equals, contains and regex checks. Checks run from inside Obsidian or from the command line, with JSON output and failure exit codes. Folder structures, required files and vault root entries can be inspected, and readable conclusions can be copied for AI-assisted fixes.
