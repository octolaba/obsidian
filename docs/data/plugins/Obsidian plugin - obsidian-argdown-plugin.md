# Argument Map with Argdown

Argument Map with Argdown turns Argdown code blocks into argument maps that are viewed in reading mode, without any extra program. Fenced argdown or argdown-map blocks are rendered in the preview pane with syntax highlighting, and several Argdown blocks may appear in one file.
