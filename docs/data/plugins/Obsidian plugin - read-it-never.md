# Read It Never

Archives web pages and media into the vault as Markdown notes, using dedicated templates for articles, videos, social posts, and other content types. Images can be downloaded and URLs processed in batches, and a simple template engine with predefined variables keeps archived notes consistent. It runs on desktop and mobile.

plugin: {
    id:     "read-it-never"
    name:   "Read It Never"
