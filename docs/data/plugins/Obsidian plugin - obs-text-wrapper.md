# Text Wrapper

Wraps the selected text in an HTML tag from a shortcut or the command palette. Up to three preset tags can be configured and bound to hotkeys, a modal accepts a new tag instead, and with nothing selected the opening and closing tags are inserted around the cursor.

```cue
plugin: {
    id:     "obs-text-wrapper"
    name:   "Text Wrapper"
    author: "smx0"
    repo:   "smx0/obs-text-wrapper"

    html_url:    "https://community.obsidian.md/plugins/obs-text-wrapper"
    github_url:  "https://github.com/smx0/obs-text-wrapper"
    description: "Quickly wrap selected text with HTML tags by using a shortcut or from the command palette."
    about:       "Wrap selected text with customizable HTML tags in the editor. Configure up to three preset tags and bind them to hotkeys or open a command-palette modal to enter a new tag; when no text is selected, insert the adjacent tag pair."

    stats: {
        downloads:  5527

}
```
