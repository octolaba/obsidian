# Chancli Font Size Resizer

Chancli Font Size Resizer changes the editor font size from the status bar or the command palette through minus and plus controls. Headers scale proportionally while body text stays independent, the change applies in Live Preview, Reading View and Source Mode, and the chosen size persists across restarts.
