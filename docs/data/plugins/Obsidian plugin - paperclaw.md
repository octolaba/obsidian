# PaperClaw

Publishes the active note to p2pclaw.com, where the recorded description says it becomes a peer-reviewed and academically formatted research paper. A ribbon icon publishes in one click with the note prefilled as a paper draft, and a dashboard is available inside Obsidian. The index entry records that the plugin has not been manually reviewed by Obsidian staff.

plugin: {
    id:     "paperclaw"
    name:   "PaperClaw"
    author: "agnuxo1"
    repo:   "agnuxo1/paperclaw-obsidian"

    html_url:    "https://community.obsidian.md/plugins/paperclaw"
    github_url:  "https://github.com/agnuxo1/paperclaw-obsidian"
