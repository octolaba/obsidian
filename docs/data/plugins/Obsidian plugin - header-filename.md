# Header Filename

Header Filename renames a note's file automatically from its first H1 heading. Its recorded description states support for kebab-case and for Polish diacritics. No About text is recorded for this plugin, so nothing beyond that description is claimed here.

```cue
plugin: {
    id:     "header-filename"
    name:   "Header Filename"
    author: "rbrauner"
    repo:   "rbrauner/obsidian-header-filename"

    html_url:    "https://community.obsidian.md/plugins/header-filename"
    github_url:  "https://github.com/rbrauner/obsidian-header-filename"
    description: "Automatically renames files based on the first H1 heading, with kebab-case and Polish diacritics support. - This plugin has not been manually reviewed by Obsidian staff."

    stats: {
        downloads:  89
```
