# AnySocket Sync

Syncs the vault to a self-hosted AnySocket server over end-to-end encrypted transport, with no device limit. Version history and deleted files are retained for a configurable period, all file types including mobile ones are covered, offline work is supported, and updates run on demand or automatically. Because sync is file-based rather than CRDT, conflicts resolve last-write-wins.
