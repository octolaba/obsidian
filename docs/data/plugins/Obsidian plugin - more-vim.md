# More Vim

Adds Vim behaviours that Obsidian's own Vim mode lacks: surround operations with ys, ds, cs and visual S, multi-cursor motions, and Mod-D to select and add the next match. A scrolloff setting keeps context around the cursor and the unnamed register can be synced with the system clipboard. Pressing o continues Markdown lists, and gd and gx open internal and external links.

```cue
plugin: {
    id:     "more-vim"
    name:   "More Vim"
    author: "Colin Lienard"
    repo:   "colinlienard/obsidian-more-vim"

    html_url:    "https://community.obsidian.md/plugins/more-vim"
    github_url:  "https://github.com/colinlienard/obsidian-more-vim"
    description: "Adds missing Vim features such as surround, multi-cursor, scrolloff, gd, gx, and more. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add missing Vim behaviors to Obsidian: surround operations (ys, ds, cs, visual S), multi-cursor motions, Mod-D to select and add the next match, scrolloff for cursor context, and unnamed-register syncing with the system clipboard. Preserve Markdown list continuation with o and open internal/external links with gd/gx."

    stats: {
        downloads:  300
        updated_at: 1779020022000
    }
}
```
