# Browser Interface

Browser Interface manages Chrome tabs saved by a companion Chrome extension from inside Obsidian. Saved tabs are shown in a list with buttons to open or delete them, and the recorded inputs state that the Meta Bind plugin is required.

```cue
plugin: {
    id:     "browser-interface"
    name:   "Browser Interface"
    author: "jason-lieb"
    repo:   "jason-lieb/obsidian-browser-interface-plugin"

    html_url:    "https://community.obsidian.md/plugins/browser-interface"
    github_url:  "https://github.com/jason-lieb/obsidian-browser-interface-plugin"
    description: "Allows you to interact with the browser."
    about:       "Manage Chrome tabs saved by the companion Chrome extension directly inside Obsidian. Display saved tabs in a list and open or delete them with built-in buttons. Require the Meta Bind plugin."
```
