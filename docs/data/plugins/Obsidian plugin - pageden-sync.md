# Pageden Sync

Connects the vault to a Pageden workspace so that server-owned team documents can be browsed, searched, opened and downloaded, or a whole vault imported. Local edits are pushed back by manual or background sync, new notes can be pushed to the server, and conflicts are handled while sync metadata is recorded.
