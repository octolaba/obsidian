# Better Export PDF

Better Export PDF exports notes to PDF with an export preview, outline bookmarks and page numbers, preserving internal links and front-matter metadata and allowing customized margins. Several files or whole folders can be combined into one PDF or batch-exported as many, and any page size or a single-page output can be chosen.
