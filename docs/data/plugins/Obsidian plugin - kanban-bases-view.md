# Kanban Bases View

Generates a kanban-style board from any Base property, with dynamic columns, drag-and-drop cards and a column order that persists. Columns can be assigned colors, cards can display selected properties or a custom title, and uncategorized entries are grouped automatically. Clicking a card opens the underlying note.
