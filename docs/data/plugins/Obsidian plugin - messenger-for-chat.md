# Messenger for chat view

Adds a persistent, draggable chatbox that hovers over the editor and writes into the active Markdown file, for conversational notes, role-play dialogue or internal monologue. Messages are sent in Chat View syntax with a chosen custom role and an optional formatted timestamp appended. The recorded description states that it drives the Chat View plugin by adifyr, and the chat interface is described as responsive and mobile-friendly.
