# URL Cleaner

Removes tracking parameters from the URLs in the current note. The stripped entries are the utm_ family and common trackers such as fbclid, gclid, igshid, mc_cid, mc_eid, rcm, ref and ref_src.

```cue
plugin: {
    id:     "url-cleaner"
    name:   "URL Cleaner"
    author: "Ashish"
    repo:   "ashishbhateja/obsidian-url-cleaner"

    html_url:    "https://community.obsidian.md/plugins/url-cleaner"
    github_url:  "https://github.com/ashishbhateja/obsidian-url-cleaner"
    description: "Remove tracking parameters from URLs. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Clean tracking parameters from URLs in the current note. Strip utm_* entries and common trackers like fbclid, gclid, igshid, mc_cid, mc_eid, rcm, ref, and ref_src to leave clean links."

    stats: {
        downloads:  92
        updated_at: 1781540994000
    }
}
```
