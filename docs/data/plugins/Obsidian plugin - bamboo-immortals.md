# Bamboo Immortals

Bamboo Immortals is a Chinese-style goal automation system that breaks multi-level goals into tasks and logs activity across a nine-period timeline. Deep reviews earn bamboo coins that are redeemed for rewards, and progress runs through ten stages covering a hundred levels. Procedural bamboo ambient sounds and animated themes accompany the system.
