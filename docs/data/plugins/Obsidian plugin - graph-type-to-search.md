# Graph Type to Search

Filters the graph as you type while it has focus, drawing a highlight ring around nodes whose title matches and keeping the ring aligned through pan and zoom. Every node can stay visible so only matches are ringed, or non-matching nodes can be hidden instead. Matching titles can be enlarged and others dimmed, and IME composition is supported for CJK input.

```cue
plugin: {
    id:     "graph-type-to-search"
    name:   "Graph Type to Search"
    author: "Jeonghyeon Park"
    repo:   "junghyunbak/graph-type-to-search"

    html_url:    "https://community.obsidian.md/plugins/graph-type-to-search"
    github_url:  "https://github.com/junghyunbak/graph-type-to-search"
    description: "Type-ahead in the graph view: start typing while the graph is focused to filter, and draw a highlight ring around nodes whose title matches. Optionally keep every node visible and only ring the matches. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Start typing in the graph to search instantly and ring matching nodes with a visible glow that tracks pan and zoom. Keep the whole graph visible for context or switch to filtering to hide non-matches. Enlarge titles and dim others to spotlight matches; supports IME composition for CJK."

    stats: {
        downloads:  142
        updated_at: 1782949912000
    }
}
```
