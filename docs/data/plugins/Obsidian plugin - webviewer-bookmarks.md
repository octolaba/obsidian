# Web viewer Bookmarks

Creates and manages bookmarks for Obsidian's built-in web viewer so a site can be opened quickly. Bookmarks can be placed on the ribbon or reached from the command palette, and their icons are set by Lucide icon name. A URL containing the selection placeholder picks up the selected editor text, URL-encoded, when the bookmark is opened.

    id:     "webviewer-bookmarks"
