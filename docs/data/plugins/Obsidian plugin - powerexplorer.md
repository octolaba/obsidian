# Power Explorer

Arranges folders and notes by hand in the file explorer with drag-and-drop, saving the exact manual order. Per-folder sort hooks are applied in proportion to the visible folders, which keeps the explorer quick in large vaults, and the whole vault can be searched by word prefix. A folder and a same-named note are shown as one row, and a Recent Pages section is pinned above the tree.
