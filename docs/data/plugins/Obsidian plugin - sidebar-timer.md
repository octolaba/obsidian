# Sidebar Timer

Sidebar Timer shows a minimalist floating capsule countdown that mounts in the main window and in popout windows, with custom durations and notification messages. Timing is calibrated against a target timestamp so it survives sleep and wake, the capsule position is remembered and clamped, touch and pen pointer events are handled, and timers unload fully so none keeps drifting in the background.
