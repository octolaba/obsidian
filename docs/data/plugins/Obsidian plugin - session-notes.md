# Session Notes

Session Notes creates temporary one-off notes for transient ideas. Some of them delete themselves as soon as you switch away; session notes persist for the length of the app session and are removed when Obsidian closes, so scratch material never accumulates in the vault.

```cue
plugin: {
    id:     "session-notes"
    name:   "Session Notes"
    author: "tabibyte"
    repo:   "tabibyte/session-notes"

    html_url:    "https://community.obsidian.md/plugins/session-notes"
    github_url:  "https://github.com/tabibyte/session-notes"
    description: "Create temporary one-off session notes."
    about:       "Create temporary notes that auto-delete when you switch away, and session notes that persist through the app session and are removed when Obsidian closes. Manage transient ideas without cluttering your vault."

    stats: {
        downloads:  936

    }
}
```
