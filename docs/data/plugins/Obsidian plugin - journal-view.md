# Journal View

Presents existing daily notes as one continuous, editable timeline that can be scrolled through time, jumped to any date with a calendar, or returned to today in one click. Notes are edited in place in the timeline, and writing on an empty day creates that note only at that point. Search runs across the journal, no plugin-specific data format or duplicate note is introduced, and only nearby days are kept active so long histories stay responsive.
