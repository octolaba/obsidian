# Auto Date on Open

Inserts today's date into a note when the note is opened, adding at most one dated heading per day to start a new section. Additions can be restricted to notes carrying an auto-date property or to chosen folders, and the date is appended below the note properties. A command adds today's date to any note by hand.

```cue
plugin: {
    id:     "auto-date-on-open"
    name:   "Auto Date on Open"
    author: "Kaicui"
    repo:   "kaicuichen-git/Obsidian-date-on-open"

    html_url:    "https://community.obsidian.md/plugins/auto-date-on-open"
    github_url:  "https://github.com/kaicuichen-git/Obsidian-date-on-open"
    description: "Adds today's date to a note when you open it, using your own line template, date format and choice of which notes to include. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert today's date into a note when you open it, adding at most one dated heading per day to start a new section. Restrict additions to notes marked with auto-date: true or chosen folders, append the date below note properties, and run a command to add today's date manually to any note."
```
