# Desktop Sticky Notes

Opens real Markdown files from the vault in resizable popout sticky-note windows that stay in sync with the vault. New Markdown sticky notes can be created, and one top-level note can be designated to toggle or bring forward, including through a global shortcut. Each window has its own controls for color, keep-on-top and edit or preview mode.
