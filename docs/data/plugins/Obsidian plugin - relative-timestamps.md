# Relative Timestamps

Inserts the current time and shows the elapsed time since a chosen reference timestamp, which makes the gaps between log entries visible. The reference timestamp can be set or reset to now, changing what later elapsed-time insertions are measured against.

```cue
plugin: {
    id:     "relative-timestamps"
    name:   "Relative Timestamps"
    author: "agctute"
    repo:   "agctute/relative-timestamps"

    html_url:    "https://community.obsidian.md/plugins/relative-timestamps"
    github_url:  "https://github.com/agctute/relative-timestamps"
    description: "Track the time between log entries."
    about:       "Insert the current time and automatically display the elapsed time since a chosen reference timestamp to reveal gaps between entries. Set or reset the reference timestamp to now to update subsequent elapsed-time insertions."

    stats: {
        downloads:  1020
        updated_at: 1718795323000
    }
}
```
