# Movie Search

Searches for films and turns a selected result into a new Markdown file populated with movie metadata. Templates and the target folder are configurable. The recorded text names Templater and Dataview integration for rendering and scripting the resulting notes, and support for a TMDB API key.

```cue
plugin: {
    id:     "movie-search"
    name:   "Movie Search"
    author: "gubchik123"
    repo:   "gubchik123/obsidian-movie-search-plugin"

    html_url:    "https://community.obsidian.md/plugins/movie-search"
    github_url:  "https://github.com/gubchik123/obsidian-movie-search-plugin"
    description: "Helps you find movies and create notes."
    about:       "Create movie notes by searching films and selecting results to populate a new Markdown file with full movie metadata. Use templates and choose the target folder, and integrate with Templater and Dataview to render and script movie notes (TMDB API key supported)."

    stats: {
        downloads:  3953
        updated_at: 1711704009000
    }
}
```
