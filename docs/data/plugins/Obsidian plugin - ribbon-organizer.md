# Ribbon Organizer

Ribbon Organizer launches commands from a configurable ribbon menu, with custom labels and icons including Iconize custom-pack icons. Entries are grouped with separators, and commands whose plugins are unavailable appear greyed out and are restored automatically once those plugins are installed.

```cue
plugin: {
    id:     "ribbon-organizer"
    name:   "Ribbon Organizer"
    author: "xooooooooox"
    repo:   "xooooooooox/obsidian-ribbon-organizer"

    html_url:    "https://community.obsidian.md/plugins/ribbon-organizer"
    github_url:  "https://github.com/xooooooooox/obsidian-ribbon-organizer"
    description: "Group your ribbon and launch commands from a configurable ribbon menu. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Launch commands from a configurable ribbon menu and assign custom labels and icons, including Iconize custom-pack icons. Group entries with separators and show unavailable commands greyed out, restoring them automatically when their plugins are installed."
```
