# Code block from selection

Wraps the selected text, or the current line when nothing is selected, in a fenced Markdown code block with a single command. One or several languages are configured in the settings, and hotkeys can be assigned for quick insertion.

    id:     "code-block-from-selection"

    author: "dy-sh"
