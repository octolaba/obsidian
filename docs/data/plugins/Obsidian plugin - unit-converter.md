# Unit Converter

Converts units inline in Markdown: a bracketed expression pairs a value and its source unit with a target unit and is replaced by the result. Unit names are autosuggested, a conversion modal serves mobile use, and the supported dimensions include length, area, mass, volume, temperature, time, pressure, energy and digital units.

```cue
plugin: {
    id:     "unit-converter"
    name:   "Unit Converter"
    author: "ruszabarov"
    repo:   "ruszabarov/obsidian-unit-converter"

    html_url:    "https://community.obsidian.md/plugins/unit-converter"
    github_url:  "https://github.com/ruszabarov/obsidian-unit-converter"
    description: "Converts units right in your Markdown files."
    about:       "Convert units inline using [<value><source unit>|<target unit>] syntax and get instant results inside your notes. Use autosuggest for unit names and open a conversion modal for mobile; support dozens of units across length, area, mass, volume, temperature, time, pressure, energy, digital, and more."

    stats: {
        downloads:  1897
        updated_at: 1779325144000
    }
}
```
