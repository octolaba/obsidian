# View Count

View Count records how often each file in the vault is opened, on desktop and on mobile. The count appears in the status bar, and a sidebar view lists most-viewed and trending notes. Counts can be synced into note frontmatter so they stay visible on mobile and can be queried with Dataview.

```cue
plugin: {
    id:     "view-count"
    name:   "View Count"
    author: "decaf-dev"
    repo:   "decaf-dev/obsidian-view-count"

    html_url:    "https://community.obsidian.md/plugins/view-count"
    github_url:  "https://github.com/decaf-dev/obsidian-view-count"
    description: "Tracks view count for each vault file."
    about:       "Track view counts for every file in your vault on desktop and mobile. Display counts in the status bar and open a sidebar view that lists most-viewed and trending notes. Sync counts to note frontmatter for mobile visibility and Dataview queries."

    stats: {
        downloads:  6201
        updated_at: 1726554996000
    }
}
```
