# Tokenz

Tokenz inserts short codes into a document and expands them into icons, special characters or frequently used snippets, including smileys and emojis. Over 1,800 built-in emoji and classic smiley maps are supplied, and users can define their own token maps in any format.

plugin: {
    id:     "tokenz"
    name:   "Tokenz"
    author: "ferenk"
    repo:   "ferenk/obsidian-tokenz"

    description: "Insert any type of short codes into your document. You can add smileys (:), ;), ...) or emojis (:smile:, :wink:, ...). More code maps will be added later. Even you, as a user can create your own."
