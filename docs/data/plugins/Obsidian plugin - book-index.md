# Book Index

Book Index builds an alphabetized, book-style index of the terms defined in a code block by searching the vault for them. Terms are auto-scanned from headings, bold or italic text and code, or tracked manually; entries link to the exact line, are ranked by relevance and can be filtered live. The links are displayed in a compact multi-column grid with smart wrapping.
