# OpenAgent Canvas

OpenAgent Canvas runs OpenAgent tasks from the vault and from Canvas by connecting Obsidian to a local Codex server and Codex Desktop. Tasks start from selected Canvas nodes or notes, active threads are tracked, and results and follow-up nodes are written back into the vault.
