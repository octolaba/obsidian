# Hotkeys for templates

Turns individual note templates into commands so a template is inserted with a hotkey. Both core Templates and Templater templates are listed in the plugin settings, and the ones enabled there become commands to bind in Obsidian's Hotkeys.

```cue
plugin: {
    id:     "obsidian-hotkeys-for-templates"
    name:   "Hotkeys for templates"
    author: "Vinzent"
    repo:   "vinzent03/obsidian-hotkeys-for-templates"

    html_url:    "https://community.obsidian.md/plugins/obsidian-hotkeys-for-templates"
    github_url:  "https://github.com/vinzent03/obsidian-hotkeys-for-templates"
    description: "Add commands to insert specific templates with a hotkey."
    about:       "Assign hotkeys to individual note templates, supporting both core Templates and Templater templates. List templates in the plugin settings, enable the ones you want to turn into commands, and bind them in Obsidian's Hotkeys to insert templates quickly."

    stats: {
        downloads:  32007
        updated_at: 1632809493000
    }
}
```
