# Otoha TTS

Otoha TTS reads the current note aloud while highlighting the spoken sentence in place and smoothly scrolling to follow it. Playback uses the device voice for offline and mobile use, or connects to the local Otoha app for higher-quality neural voices. Clicking any sentence jumps playback to it.

```cue
plugin: {
    id:     "otoha-tts"
    name:   "Otoha TTS"
    author: "Otoha"
    repo:   "spacegrowth/otoha-tts"

    html_url:    "https://community.obsidian.md/plugins/otoha-tts"
    github_url:  "https://github.com/spacegrowth/otoha-tts"
    description: "Read the current note aloud — device voice, or high-quality neural voices via the free Otoha app — with sentence highlighting and smooth follow-scrolling. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Read notes aloud with in-place sentence highlighting and smooth teleprompter auto-scroll that follows the spoken line. Use built-in OS speech for offline/mobile playback or connect to the local Otoha app for higher-quality neural voices; click any sentence to jump and control playback."

    stats: {
        downloads:  434
        updated_at: 1782193969000
    }
}
```
