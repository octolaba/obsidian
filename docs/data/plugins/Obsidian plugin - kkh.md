# kkh

Converts selected text between historical and modern Japanese orthography using a dictionary. The conversions cover kyujitai and kyukana against shinjitai and shinkana, old and new kana usage, odori-ji, contracted kana, y-row e, and historical katakana. They are run from the editor through the context menu or a command.

```cue
plugin: {
    id:     "kkh"
    name:   "kkh"
    author: "okikae"
    repo:   "okikae/obsid-kkh"

    html_url:    "https://community.obsidian.md/plugins/kkh"
    github_url:  "https://github.com/okikae/obsid-kkh"
    description: "Replace words in a string using kkh dictionary."
```
