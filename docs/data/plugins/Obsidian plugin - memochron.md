# MemoChron

Imports iCalendar events from public URLs or local .ics files and shows them in a calendar sidebar together with a daily agenda view. Notes are created from an event by clicking or by drag-and-drop, then filed into date-based folders using templates. Calendars are color-coded, attendees are linked, and feeds refresh automatically.
