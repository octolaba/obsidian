# Code Reference Library

Keeps a personal coding reference library of snippets, patterns, links and notes in plain Markdown, tagged by language and framework. Snippets and patterns are captured with metadata and searched by tag, and a filterable Reference sidebar with Snippets and Patterns tabs is used to browse them.

```cue
plugin: {
    id:     "code-reference-library"
    name:   "Code Reference Library"
    author: "wesswart77"
    repo:   "wesswart77/obsidian-code-reference"

    html_url:    "https://community.obsidian.md/plugins/code-reference-library"
    github_url:  "https://github.com/wesswart77/obsidian-code-reference"
    description: "A personal coding reference library: patterns and snippets tagged by language and framework, all in plain markdown. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create and organize a personal coding reference library of snippets, patterns, links, and notes tagged by language and framework. Capture snippets and patterns with metadata, search by tag, and browse via a filterable Reference sidebar with Snippets and Patterns tabs."

    stats: {
        downloads:  161
        updated_at: 1779653120000
    }
}
```
