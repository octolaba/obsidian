# YNote Sync

Synchronizes a Youdao Note workspace with an Obsidian vault in both directions, pulling cloud changes, tracking local edits, surfacing conflicts for review and pushing approved updates. Markdown files are handled alongside native formats including MindMap, LXTable, Draw.io, Excalidraw and Canvas, plus images and attachments. Full pulls are resumable, earlier versions can be previewed, and local repositories can be filtered out.
