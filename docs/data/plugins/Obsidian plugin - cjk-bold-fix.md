# CJK Bold Fix

Restores bold and italic rendering for Chinese, Japanese and Korean text in Live Preview, where CJK punctuation breaks CommonMark emphasis parsing. The correct styling is applied and the emphasis markers hidden in the editor only, leaving the files unchanged, and only visible ranges are processed for performance.
