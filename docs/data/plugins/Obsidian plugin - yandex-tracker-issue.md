# Yandex Tracker Issue

Renders Yandex Tracker data inside notes — issues, boards, queues, sprints, users and projects — as tables or Gantt charts. Code blocks and queries named yt-issue, yt-gantt, yt-issue-query, yt-gantt-query, yt-boards and yt-queues declare what live Tracker data to display.

```cue
plugin: {
    id:     "yandex-tracker-issue"
    name:   "Yandex Tracker Issue"
    author: "cubieprog"
    repo:   "cubieprog/Obsidian-Yandex-Tracker-Issue"

    html_url:    "https://community.obsidian.md/plugins/yandex-tracker-issue"
    github_url:  "https://github.com/cubieprog/Obsidian-Yandex-Tracker-Issue"
```
