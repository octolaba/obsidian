# Block Step Reader

Block Step Reader walks through a note block by block from the keyboard, auto-centering and highlighting the current block. It shows reading progress and time remaining and saves the reading position per user. A library sidebar filters and sorts notes and marks them read or unread, and the interface is available in several languages.
