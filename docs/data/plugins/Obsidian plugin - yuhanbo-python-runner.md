# Yuhanbo Python Runner

Runs Python code blocks from a note with a local Python interpreter, on desktop only. Standard output and errors appear in a modal and can be copied to the clipboard. The interpreter path is configurable, and runs that exceed 30 seconds are aborted.

```cue
plugin: {
    id:     "yuhanbo-python-runner"
    name:   "Yuhanbo Python Runner"
    author: "yuhanbo"
    repo:   "yuhanbo758/obsidian-yuhanbo-python"

    html_url:    "https://community.obsidian.md/plugins/yuhanbo-python-runner"
    github_url:  "https://github.com/yuhanbo758/obsidian-yuhanbo-python"
    description: "Run Python code blocks with a local interpreter and view their output inside your notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Run Python code blocks using a local Python interpreter directly from Obsidian on desktop. View standard output and errors in a modal, copy execution results to the clipboard, configure the interpreter path, and abort runs that exceed 30 seconds."

    stats: {
        downloads:  23
        updated_at: 1785940797000
    }
}
```
