# Ghost Fade Focus

Fades the text around the cursor so the current line stands out, progressively dimming the five lines above and below it. Fading is applied as the cursor moves, and a command toggles the effect on or off.

```cue
plugin: {
    id:     "ghost-fade-focus"
    name:   "Ghost Fade Focus"
    author: "skipadu"
    repo:   "skipadu/obsidian-ghost-fade-focus"

    html_url:    "https://community.obsidian.md/plugins/ghost-fade-focus"
    github_url:  "https://github.com/skipadu/obsidian-ghost-fade-focus"
    description: "Focused on the current line, others faded like a ghost!"
    about:       "Fade surrounding text to reduce distractions by progressively dimming the 5 lines above and below the cursor. Activate fading on cursor movement and toggle the effect on or off with a command."
```
