# Week Planner

Todos are organized across Inbox, Week and Today documents, and the folder structure for daily and weekly notes is created automatically. Commands open the current week, today, tomorrow and yesterday, add a new todo from a modal, and move tasks between the inbox, days, or any given date.

    id:     "obsidian-week-planner"
    name:   "Week Planner"
    author: "rwirdemann"
