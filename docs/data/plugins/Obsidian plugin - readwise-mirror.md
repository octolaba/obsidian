# Readwise Mirror

Mirrors a Readwise library into the vault by downloading highlights and notes as Markdown files and performing incremental syncs afterwards. Internal links and frontmatter are kept intact, filenames can be customized, and book titles, authors, and highlights are converted into links and block-level references.

```cue
plugin: {
    id:     "readwise-mirror"
    name:   "Readwise Mirror"
    author: "jsonmartin"
    repo:   "jsonmartin/readwise-mirror"

    html_url:    "https://community.obsidian.md/plugins/readwise-mirror"
    github_url:  "https://github.com/jsonmartin/readwise-mirror"
    description: "Mirror your Readwise library."
    about:       "Mirror your Readwise library into Obsidian by automatically downloading highlights and notes as Markdown files and performing incremental syncs. Keep internal links and frontmatter intact, generate custom filenames, and convert book titles, authors and highlights into [[links]] and block-level references."

    stats: {
        downloads:  15827
        updated_at: 1783961438000
    }
}
```
