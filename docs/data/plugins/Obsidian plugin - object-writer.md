# Object Writer

Creates an object-writing note from a ribbon button, inserting a random word to write about and starting a countdown timer. When the timer ends the note switches to read mode, and the new file is tagged so the sessions can be tracked.

```cue
plugin: {
    id:     "object-writer"
    name:   "Object Writer"
    author: "iagograh"
    repo:   "iagograh/obsidian-object-writer"

    html_url:    "https://community.obsidian.md/plugins/object-writer"
    github_url:  "https://github.com/iagograh/obsidian-object-writer"
    description: "Utility for object writing with random words."
    about:       "Create a quick object-writing note with one click using a ribbon button that inserts a random word and starts a countdown timer. Enter read mode automatically when the timer ends and tag the new file for easy tracking."

    stats: {
        downloads:  2608
        updated_at: 1730384117000
    }
}
```
