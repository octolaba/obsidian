# Agent Dashboard

Brings vault health, the inbox, task flow, active projects, agent runs and note-creation activity together on one control surface. Today's tasks carry persistent TODO, DOING and DONE states, projects are filtered by folder and frontmatter, and daily GitHub and research feeds are archived. Feeds and notes can be scheduled daily, and deep-research reports can optionally be run through the Codex CLI.
