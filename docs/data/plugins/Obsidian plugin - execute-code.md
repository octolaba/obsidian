# Execute Code

Runs code blocks from inside a note through a run button, covering more than thirty languages including Python, JavaScript, Rust, R, Java, C, C++ and shell. Results appear inline, interactive input fields serve prompts, and embedded plots from Python, R and Octave are rendered. Output persists in the note so it survives a PDF export.
