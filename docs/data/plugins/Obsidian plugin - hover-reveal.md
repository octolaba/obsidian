# Hover Reveal

Hover Reveal hides text behind a tooltip using a bracketed visible-text and braced tooltip-text syntax, rendering the visible part underlined and bold. Commands insert and navigate that syntax, tooltip colors and styles are configurable, and the rendering adapts to the theme and supports live preview.

    id:     "hover-reveal"
    name:   "Hover Reveal"
