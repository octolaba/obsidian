# Slash snippets

Slash snippets inserts frequently used text while writing, through a chosen trigger that defaults to a slash. Snippets are stored as plain-text files and may carry variables for the cursor position and the current text selection. Enabling Templater syntax makes snippets dynamic, which the recorded inputs illustrate with Dataview blocks, callouts, HTML and mermaid.

```cue
plugin: {
    id:     "slash-snippets"
    name:   "Slash snippets"
    author: "echo-saurav"
    repo:   "echo-saurav/slash-snippets-plugin"

    html_url:    "https://community.obsidian.md/plugins/slash-snippets"
    github_url:  "https://github.com/echo-saurav/slash-snippets-plugin"
    description: "Use slash command to insert quick text"
    about:       "Insert frequently used text snippets instantly while writing in Obsidian using a chosen trigger (default '/'). Store snippets as plain-text files and include variables like %%cursor%% and %%textSelection%%; enable Templater syntax to create dynamic snippets for Dataview blocks, callouts, HTML, mermaid, and more."

    stats: {
        downloads:  11044
        updated_at: 1770444460000
    }
}
```
