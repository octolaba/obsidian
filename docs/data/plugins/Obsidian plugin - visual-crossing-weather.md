# Visual Crossing Weather

Visual Crossing Weather pulls current conditions, forecasts and alerts for up to five locations from the Visual Crossing API. The status bar shows weather through customizable template strings and CSS and can cycle between two templates. Detailed weather tables or modals can be inserted into notes and into daily templates.
