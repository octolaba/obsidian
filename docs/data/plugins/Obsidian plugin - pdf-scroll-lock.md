# PDF Scroll Lock

Locks embedded PDFs against scrolling by default, so that a chosen page view is not moved accidentally while reading the note. A per-embed toolbar toggle turns scrolling back on or off.

```cue
plugin: {
    id:     "pdf-scroll-lock"
    name:   "PDF Scroll Lock"
    author: "divyanshu9821"
    repo:   "divyanshu9821/pdf-scroll-lock"

    html_url:    "https://community.obsidian.md/plugins/pdf-scroll-lock"
    github_url:  "https://github.com/divyanshu9821/pdf-scroll-lock"
    description: "Lock the pdfs from scrolling. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Lock embedded PDFs by default to prevent accidental scrolling while reading notes. Provide a per-embed toolbar toggle to enable or disable scrolling and keep specified page views intact."
```
