# Image2LaTEX

Converts the latest clipboard image containing math into LaTeX, emitted as Markdown or MathJax. Texify, SimpleTex and pix2tex are selectable as OCR providers, and the generated result is inserted directly into the note.

```cue
plugin: {
    id:     "image2latex"
    name:   "Image2LaTEX"
    author: "hugo-persson"
    repo:   "hugo-persson/obsidian-ocrlatex"

    html_url:    "https://community.obsidian.md/plugins/image2latex"
    github_url:  "https://github.com/hugo-persson/obsidian-ocrlatex"
    description: "Convert your images with math to LaTeX code."
    about:       "Convert the latest image in your clipboard into Markdown or MathJax using selectable OCR providers (Texify, SimpleTex, pix2tex). Insert the generated LaTeX or Markdown directly into your note for quick capture of formulas and equations."

    stats: {
        downloads:  6602
        updated_at: 1712249654000
    }
}
```
