# Scribe

Scribe records voice notes and turns them into transcriptions, summaries and structured Obsidian pages, saving progressively and supporting pause and resume. Questions can be asked mid-recording so that the answers are inserted, custom prompt templates can be applied, and Mermaid charts and multilingual output can be generated automatically.
