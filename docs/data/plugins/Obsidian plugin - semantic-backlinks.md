# Semantic Backlinks

Semantic Backlinks suggests notes to link as you type, combining fast lexical matching with semantic search over embeddings from a local Ollama or LM Studio instance or from the OpenAI API. An inline suggestion popup inserts the chosen link, and a Related Notes sidebar lists semantically similar notes, with the index kept current by live auto-indexing.
