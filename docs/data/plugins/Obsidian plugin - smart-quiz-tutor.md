# Smart Question Tutor

Smart Question Tutor generates exam-style question sets from local Markdown notes, or extracts questions from an existing Markdown document, using Ollama or an OpenAI-compatible API and covering five question types with batch processing. Practice sessions are graded instantly and mistakes are archived into a wrong-question notebook scheduled by SM-2 spaced repetition, with review reminders, analytics and knowledge-point tagging. Question sets export to DOCX, PDF and Markdown.
