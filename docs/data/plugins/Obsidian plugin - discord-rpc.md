# Discord RPC

Shows Obsidian activity on Discord through Rich Presence, displaying the vault and file name, edit or preview mode and elapsed timers. Auto-reconnect, idle detection, a pause mode and exclusion lists cover privacy, and custom status formats, up to two profile buttons or a custom Discord application allow the presence to be personalized.
