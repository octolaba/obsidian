# Concordance

Concordance generates Markdown indexes from filename prefixes, folders, tags or frontmatter properties and writes the resulting lists of wikilinks into a clearly marked block inside a note. Edits are confined to the region between the concordance start and end markers, diffs can be previewed or scans run read-only, and link style, sorting, recursion and exclusions are configurable.

```cue
plugin: {
    id:     "concordance"
    name:   "Concordance"
    author: "nsyout"
    repo:   "nsyout/obsidian-concordance"

    html_url:    "https://community.obsidian.md/plugins/concordance"
    github_url:  "https://github.com/nsyout/obsidian-concordance"
    description: "Generate safe Markdown indexes from folders, tags, properties, and filename patterns. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Generate safe Markdown indexes from filename prefixes, folders, tags, or frontmatter properties and write lists of [[wikilinks]] into a clearly marked block inside any note. Limit edits to between concordance:start/end markers, preview diffs or run read-only scans, and configure link style, sort, recursion and exclusions."
```
