# Task Journal Checkbox Sink

Task Journal Checkbox Sink keeps task lists on a central page and records outcomes in the day's daily note, with optional summaries. Completed tasks sink to the end of their current list, whole task blocks moving together, and partial completions can be marked without sinking. Completed items are archived by their real completion date, the latest operation can be undone even after a restart, and the recorded text states that the data stays local and offline.
