# Ankify Plus

Converts the current note into Anki cards through the DeepSeek API, with alternate models, custom endpoints and image recognition supported. Card type can be chosen per card, and Cloze deletions are detected automatically or generated. Cards can be previewed and copied, tags batch-replaced, Cloze fields merged and Anki Connect tested, with collapsible request details and an automatically added ankify tag.
