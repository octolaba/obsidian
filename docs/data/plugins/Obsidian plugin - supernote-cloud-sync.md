# Supernote Cloud Sync

Mirrors selected Supernote Cloud folders into the vault with their folder structure intact and renders .note notebooks locally, with paging, zoom, pan and a thumbnail grid. Pages can be embedded in Markdown or exported as Markdown, PDF or images, and optional AI transcription is available. Files can be sent back through an explicit Send command or through a Paired folder that performs conflict-aware two-way sync.
