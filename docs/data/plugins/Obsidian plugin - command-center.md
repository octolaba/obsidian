# Command Center

Runs an orchestrator-worker multi-agent framework over the vault to automate daily operations, indexing and template generation. Workflows run headless but pause for approval before files are changed, and model routing is provider-aware with stationary vault indexes for token-efficient local processing. An interactive sidebar chat adds voice input, persistent memory and retrieval over the knowledge base, and configuration is done through an interview-style setup.
