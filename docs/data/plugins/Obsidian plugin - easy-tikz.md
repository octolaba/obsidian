# Easy TikZ

Designs TikZ and pgfplots graphs visually against a live SVG preview rendered in the note, with no TeX installation needed for in-vault use, and exports pgfplots code when the chart is ready to publish. A chart is inserted with one click and reopened for editing by clicking it. Plots cover 2D functions and 3D surfaces, parametric and polar modes, tangents and extrema, and the preview can be rotated, panned and zoomed.
