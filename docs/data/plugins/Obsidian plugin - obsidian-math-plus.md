# Math+

This plugin is for taking math notes with Excalidraw. Math blocks render LaTeX or intuitively typed equations into formatted math, and equations can be annotated with an Excalidraw overlay whose drawings are saved as SVG. Custom shortcuts auto-convert typed patterns into LaTeX.

    id:     "obsidian-math-plus"
