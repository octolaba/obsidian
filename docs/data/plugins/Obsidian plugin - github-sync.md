# GitHub Sync

Syncs a vault to a personal GitHub repository through a single ribbon action that pulls remote changes and pushes local edits. Unmerged files are opened for conflict resolution, HTTPS and SSH remotes are supported, sync can run at startup, and the sync notices can be made concise or hidden.

    id:     "github-sync"
