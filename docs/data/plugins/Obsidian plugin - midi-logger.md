# MIDI Logger

MIDI Logger captures live input from MIDI devices and inserts the played notes into the editor. Notes can be written as raw MIDI codes, as scientific pitch notation or as ABC notation, and ABC output is rendered by the ABC Music Notation plugin.

```cue
plugin: {
    id:     "midi-logger"
    name:   "MIDI Logger"
    author: "maybe-hello-world"
    repo:   "maybe-hello-world/midi-logger"

    html_url:    "https://community.obsidian.md/plugins/midi-logger"
    github_url:  "https://github.com/maybe-hello-world/midi-logger"
    description: "Insert parsed musical notes from MIDI input devices."
    about:       "Capture live MIDI input and insert played notes directly into the editor. Output notes as raw MIDI codes, scientific pitch notation, or ABC notation, and render ABC output with the ABC Music Notation plugin."
```
