# Goldilocks Essentials

Bundles a set of small, opt-in interface changes: renameable colored tabs, placing a new note into the last-clicked folder, a Print command for Markdown files, pressing E to start editing, and a sidebar button for community plugins. Each feature is toggled separately, and conflicting standalone plugins are detected and skipped.
