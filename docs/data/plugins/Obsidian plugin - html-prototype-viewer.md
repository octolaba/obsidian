# HTML Prototype Viewer

Previews HTML files stored in the vault inside an iframe, so the page keeps its own CSS and scripts isolated from Obsidian. Device widths can be switched and edits reload live. Previews can be embedded in notes through an html-preview block, and prototypes can be opened in the system browser without running a local web server.

    id:     "html-prototype-viewer"
    name:   "HTML Prototype Viewer"

    html_url:    "https://community.obsidian.md/plugins/html-prototype-viewer"
    github_url:  "https://github.com/gloumi/obsidian-html-prototype-viewer"
