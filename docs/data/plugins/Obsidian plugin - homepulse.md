# HomePulse

A local-first homepage dashboard assembled from components in a draggable, responsive grid, covering focus, execution pulse, knowledge profile, an activity heatmap and a capability map. Widgets can be arranged and resized, and named layouts saved. Built-in widgets include Projects, Tasks, Calendar, Habits, Pomodoro, Tech Tree and Bookmarks.
