# OZSync

Syncs the vault with ZimaOS storage for backup and cross-device access, and lets ZimaOS be browsed inside Obsidian to upload, download, preview, create and delete files. Sync runs manually or on an interval with newer-file-wins conflict resolution and local timestamped backups before remote overwrites, and its state is shown in the status bar and a status view. The recorded description states that it is for Obsidian desktop only.
