# Latex Suite Extension

Renders inline LaTeX without flicker in Live Preview and Reading view and accepts spaced or empty inline math expressions, with optional inline displaystyle rendering. Right-to-left text can be mixed into math through dedicated Hebrew and Arabic commands, and the keyboard switches automatically based on cursor context. A solve command evaluates the last expression, and built-in math snippets are included.
