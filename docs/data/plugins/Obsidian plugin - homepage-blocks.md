# Homepage Blocks

Homepage Blocks composes a drag-and-drop homepage from fifteen block types, among them a greeting, clock, quotes, quick links, image gallery, embedded notes, pomodoro, bookmarks, recent files and random note. Blocks are resized and reordered in two dimensions, styled individually with accent tints, and collapsed by section. The layout is responsive and the gallery opens a full-screen lightbox.
