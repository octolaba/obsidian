# mpv links

Adds buttons that open a local video file in mpv at a saved timestamp. Timestamps are saved and updated automatically when playback closes. The links live in mpv_link code blocks and take relative or absolute paths so they survive relocation.

```cue
plugin: {
    id:     "mpv-links"
    name:   "mpv links"
    author: "patsh90"
    repo:   "patsh90/mpv-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/mpv-links"
    github_url:  "https://github.com/patsh90/mpv-obsidian-plugin"
    description: "Add mpv links with timestamps"
    about:       "Add buttons that link to local video files and open them in mpv at a saved timestamp. Save and update playback timestamps automatically on close and keep links portable using mpv_link code blocks with relative or absolute paths for relocalization."

    stats: {
        downloads:  828
        updated_at: 1780215437000
    }
}
```
