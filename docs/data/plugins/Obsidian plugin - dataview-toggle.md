# Dataview Toggle

Pauses and resumes the automatic refresh of Dataview from the status bar or the command palette, so that views stop re-rendering while you type. Per-note frontmatter can force the refresh on or off, and resuming triggers an immediate refresh of all views.

```cue
plugin: {
    id:     "dataview-toggle"
    name:   "Dataview Toggle"
    author: "p1tt1"
    repo:   "p1tt1/obsidian-dataview-toggle"

    html_url:    "https://community.obsidian.md/plugins/dataview-toggle"
    github_url:  "https://github.com/p1tt1/obsidian-dataview-toggle"
    description: "Toggle Dataview auto-refresh on/off from the status bar or command palette. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Pause and resume Dataview's automatic refresh with a single click or hotkey to stop repeated re-renders while you type. Use per-note frontmatter overrides to force refresh on or off and trigger an immediate refresh of all views when resuming."

    stats: {
        downloads:  228
        updated_at: 1778082126000
    }
}
```
