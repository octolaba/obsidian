# LskyPro Image Uploader

Uploads pasted, dragged or attached local images to LskyPro automatically and replaces them with the hosted URLs. The LskyPro V1 and V2 APIs are supported, uploads run in batches and concurrently, several input methods and network images are handled, and the source files can optionally be deleted.
