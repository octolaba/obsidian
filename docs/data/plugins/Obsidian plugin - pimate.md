# Pimate

Pimate embeds the Pi Coding Agent in Obsidian as a collaborator that can chat, read and edit vault files and run commands without leaving the app. Files are attached with the at sign, and editor selections are sent for inline edits with a diff preview. Several conversation tabs can be kept open, and multiple providers and multimodal models are supported.
