# TLP Classification

TLP Classification labels notes with the Traffic Light Protocol through a visual selector in the properties panel, a command-palette modal and a status bar indicator. It generates PDF header and footer badges in the official TLP colors for Better Export PDF and regenerates those templates when the TLP frontmatter is edited. Organization-specific classification levels can be defined in a vault markdown file.
