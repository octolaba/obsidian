# Folder Tabulation

Moves between the files of a folder with hotkeys and commands, going to the next or previous file and wrapping around at the ends. A file is opened in the same tab, a new tab, a new pane or a new window. Buttons in the file bar cycle through the files and focus notes that are already open.
