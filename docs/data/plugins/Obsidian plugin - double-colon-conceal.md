# Double Colon Conceal

Displays the double colon of Dataview inline fields as a single colon for a more natural reading experience. Concealment applies in Reading View and optionally in edit and live preview, stays off on the active line and in Source-mode selections, and marks concealed colons with a dedicated CSS class.

```cue
plugin: {
    id:     "double-colon-conceal"
    name:   "Double Colon Conceal"
    author: "msrch"
    repo:   "msrch/obsidian-double-colon-conceal"

    html_url:    "https://community.obsidian.md/plugins/double-colon-conceal"
    github_url:  "https://github.com/msrch/obsidian-double-colon-conceal"
    description: "Display double colon (i.e. Dataview inline fields) as a single colon for more natural reading experience."
    about:       "Display double-colon inline fields (::) as a single colon (:) for cleaner, more natural reading. Conceal in Reading View and optionally in edit/live preview. Preserve visibility on the active line and in Source-mode selections; mark concealed colons with .cm-double-colon-conceal."
```
