# Documents Bundle

Treats a note as a self-contained bundle by storing its attachments in an assets folder beside the Markdown file. Pasted or dropped images, PDFs and other files are saved into the bundle, older local attachment links can be migrated, and renaming the bundle folder stays in step with the note.

```cue
plugin: {
    id:     "documents-bundle"
    name:   "Documents Bundle"
    author: "kq996"
    repo:   "keqing996/ob-plugin-document-bundle"

    html_url:    "https://community.obsidian.md/plugins/documents-bundle"
    github_url:  "https://github.com/keqing996/ob-plugin-document-bundle"
    description: "Treat each Markdown document as a self-contained bundle with local assets. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create self-contained bundle notes that store attachments beside the Markdown file in an assets/ folder, keeping files portable and easy to inspect. Save pasted or dropped images, PDFs and other files into the bundle, migrate old local attachment links, and keep bundle folder renames synced with the main .md."

    stats: {
        downloads:  176
        updated_at: 1782920401000
    }
}
```
