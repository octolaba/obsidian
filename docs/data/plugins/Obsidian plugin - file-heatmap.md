# File Heatmap

File Heatmap overlays the file explorer with a color-coded indication of how recently each file was modified, expressing age through color and vertical block density. Files modified within the last two weeks also show a numeric day count, while older files show no indicator so the sidebar stays minimal. The 30-day color scale and the block density are customizable, and no hotkeys or popups are involved.

```cue
plugin: {
    id:     "file-heatmap"
    name:   "File Heatmap"
    author: "sato"
    repo:   "sato-note/file-heatmap"

    html_url:    "https://community.obsidian.md/plugins/file-heatmap"
    github_url:  "https://github.com/sato-note/file-heatmap"
    description: "Shows a color-coded heatmap of recently modified files - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display a real-time heatmap overlay in the file explorer to highlight recently modified files using color and vertical block density that reflect age. Show numeric day counts for items modified within two weeks, hide indicators for older files to keep the sidebar minimal, and require no hotkeys or popups. Customize the 30-day color scale and block density to match your workflow."

    stats: {
        downloads:  133
        updated_at: 1782181719000
    }
}
```
