# Adjacency Matrix Maker

Adjacency Matrix Maker builds an interactive adjacency matrix image of the vault, mapping note-to-note links onto colored grid cells. The matrix can be panned and zoomed, tooltips appear on hover or with Ctrl held, cells open the linked notes, folder-level color squares can be shown, and the image can be saved into the vault.

```cue
plugin: {
    id:     "adjacency-matrix-maker"
    name:   "Adjacency Matrix Maker"
    author: "skepticmystic"
    repo:   "skepticmystic/adjacency-matrix-maker"

    html_url:    "https://community.obsidian.md/plugins/adjacency-matrix-maker"
    github_url:  "https://github.com/skepticmystic/adjacency-matrix-maker"
    description: "Create an interactive adjacency matrix of your vault."
    about:       "Generate an adjacency matrix image of your vault that maps note-to-note links as colored grid cells. Pan and zoom the matrix, hover or hold Ctrl for interactive tooltips, click cells to open linked notes, show folder-level color squares, and save the image to your vault."
```
