# neoloopy

neoloopy builds systems-thinking causal-loop diagrams inside the vault, using Markdown notes as variables and links as causal arrows carrying polarity. An interactive canvas draws and edits those links, marks delays and indirect or nonlinear relations, and detects and labels reinforcing (R) and balancing (B) feedback loops. Loops can be navigated one by one and the diagram exported as JSON, Markdown or Mermaid, and the recorded description states that everything stays local and offline.
