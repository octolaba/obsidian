# Snipd Official

Podcast highlights from Snipd are synced into the vault together with transcripts, AI summaries, notes, links and metadata such as cover image, title and publish date. Episode and snip templates are customizable, syncing can be limited to snips that were edited, and the metadata is exposed as note properties for Obsidian Bases.

```cue
plugin: {
    id:     "snipd-official"
    name:   "Snipd Official"
    author: "snipd-app"
    repo:   "snipd-app/snipd-obsidian"

    html_url:    "https://community.obsidian.md/plugins/snipd-official"
    github_url:  "https://github.com/snipd-app/snipd-obsidian"
    description: "Sync Snipd podcast highlights to your vault with transcript, notes, AI summaries and metadata. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync Snipd podcast highlights to your Obsidian vault with transcripts, AI summaries, notes, links and rich metadata (cover image, title, publish date). Customize episode and snip templates, choose to sync only edited snips, and expose metadata as properties for Obsidian Bases."

    stats: {
        downloads:  64383
        updated_at: 1778752429000
    }
}
```
