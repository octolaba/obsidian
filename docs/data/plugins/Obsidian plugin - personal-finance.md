# Personal Finance

Personal Finance reads a single CSV file and presents monthly finances as summary cards for income, expenses and balance. It draws a daily cumulative balance chart with coloured positive and negative areas, and a monthly income versus expenses bar chart. Category and sub-category breakdowns are sortable, the CSV is auto-refreshed, and the layout is described as mobile-friendly.
