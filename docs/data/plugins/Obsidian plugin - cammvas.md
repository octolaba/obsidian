# Cammvas

Brings mind-mapping workflows to Obsidian Canvas, with keyboard-driven editing, drag-to-reparent branches, collapsible subtrees and branch-aware dragging. Every map stays a standard .canvas file in the vault. Automatic tree layout, a synchronised map outline and configurable branch colours are provided.
