# NeoGDSync

NeoGDSync synchronises a vault with Google Drive through a path-based index, so only changed files are uploaded, and it detects conflicts instead of overwriting silently. It offers Smart, Push and Pull modes, saves the Drive copy as a conflict file, can keep Drive revisions, applies glob excludes, and can be triggered from an obsidian:// URI.
