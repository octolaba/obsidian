# Markdown Columns

Markdown Columns creates responsive multi-column layouts from a simple columns block, without writing HTML. Any number of columns can be rendered, and their contents keep full Markdown support including code blocks, callouts, tables, lists, images and links.

```cue
plugin: {
    id:     "markdown-columns"
    name:   "Markdown Columns"
    author: "Czeglédy Péter"
    repo:   "peterczegledy/Obsidian-markdown-columns"

    html_url:    "https://community.obsidian.md/plugins/markdown-columns"
    github_url:  "https://github.com/peterczegledy/Obsidian-markdown-columns"
    description: "Create responsive Markdown columns using a simple syntax. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create responsive multi-column layouts directly in Markdown using a columns block. Render unlimited columns with full Markdown support — including code blocks, callouts, tables, lists, images, and links — without writing HTML."
```
