# Every Day Calendar

Renders a yearly habit tracker as a heatmap through dataviewjs, in the style of Simone Giertz's Every Day Calendar. Each date maps to a numeric completion value that colours the day with the current theme's colours, and CSS snippets extend the visuals or add further values.

    name:   "Every Day Calendar"
    author: "sporarum"
