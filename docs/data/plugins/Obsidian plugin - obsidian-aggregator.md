# Aggregator

Aggregator gathers information from files and writes a summary into a note. Content is collected with user-defined regular expressions and rendered through Handlebars templates, extracting blocks or tagged items and generating stat tables across files or folders. Results can be sorted by field, previewed, and embedded inline.
