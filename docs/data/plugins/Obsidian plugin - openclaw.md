# OpenClaw

OpenClaw chats with an OpenClaw AI agent in a persistent sidebar, with the vault as the agent's workspace and conversations synced across devices. Replies stream in as natively rendered Markdown, and the panel shows which files were read or written, which commands were run and which pages were fetched. Any note is sent as context with one command.

```cue
plugin: {
    id:     "openclaw"
    name:   "OpenClaw"
    author: "oscarhenrycollins"
    repo:   "oscarhenrycollins/obsidianclaw"

    html_url:    "https://community.obsidian.md/plugins/openclaw"
    github_url:  "https://github.com/oscarhenrycollins/obsidianclaw"
    description: "Chat with your OpenClaw AI agent in a sidebar. Your vault is the agent's workspace. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Chat with your OpenClaw AI agent in a persistent Obsidian sidebar and keep conversations synced across devices. See streaming, natively rendered Markdown replies and visibility into files read/written, commands run, and pages fetched. Send any note as context with one command."

}
```
