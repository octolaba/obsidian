# Antinomia

Maps the contradictions in a vault, its tensions, tradeoffs and conflicting goals, across five layers: tension, substrate, principle, defeated and meta. Tension and substrate notes are created through guided modals with optional AI classification, and each note's layer is stored in frontmatter as antinomia_type, so files never move. The recorded description also names an AI Contradiction Hunter and PDF concept extraction, working against cloud APIs or fully local models.
