# Chess Puzzles

Chess Puzzles keeps chess puzzles written in Markdown and reviews them with a built-in spaced repetition system. A puzzle is a code block carrying a FEN and a best line, which keeps it portable, and the review history is stored in the Markdown itself so puzzles transfer between vaults. Reviews run over a single puzzle, a deck, only the pending items, or the whole vault.

    id:     "chess-puzzles"
