# Maximise Active Pane

Maximise Active Pane expands the active pane so that it fills the entire workspace and the other panes are hidden. Toggling the command again restores the previous layout.

```cue
plugin: {
    id:     "maximise-active-pane-obsidian"
    name:   "Maximise Active Pane"
    author: "deathau"
    repo:   "deathau/maximise-active-pane-obsidian"

    html_url:    "https://community.obsidian.md/plugins/maximise-active-pane-obsidian"
```
