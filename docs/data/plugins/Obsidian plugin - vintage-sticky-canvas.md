# Vintage Sticky Canvas

Styles Canvas boards with a restrained vintage-academia look: warm paper backgrounds, ink-like paths, handwritten edge labels, alpha shadows and transparent torn-note PNGs. A handwriting font is bundled so it runs offline, and light and dark backgrounds are coordinated. Optional integrations with Claudian Plus and Codex are available.
