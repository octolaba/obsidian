# Random Writing Prompt

Opens random writing prompts as a way to start a writing session. It can pick a random unstarted prompt and create a note for it, or open a random started prompt to resume earlier work. Prompts can be browsed in a fuzzy-search modal and added from the command palette with duplicate checks, and new prompt notes can use a template.

```cue
plugin: {
    id:     "random-writing-prompt"
    name:   "Random Writing Prompt"
    author: "tallvincent"
    repo:   "tallvincent/obsidian-random-writing-prompt"

    html_url:    "https://community.obsidian.md/plugins/random-writing-prompt"
    github_url:  "https://github.com/tallvincent/obsidian-random-writing-prompt"
    description: "Open random writing prompts to spark some creativity - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Pick a random unstarted prompt and create a note for it, or open a random started prompt to jump back into your work. Browse all prompts in a fuzzy-search modal, add new prompts from the command palette with duplicate checks, and optionally use a template for new prompt notes."

    stats: {
        downloads:  91
        updated_at: 1783756374000
    }
}
```
