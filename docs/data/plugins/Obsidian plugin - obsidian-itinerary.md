# Itinerary

Renders a calendar from event information found in notes, written as itinerary code blocks. Events are displayed on monthly, weekly or daily calendars and can be color-coded and tagged, so that conflicts or overlaps in a trip or event plan are visible at a glance.

```cue
plugin: {
    id:     "obsidian-itinerary"
    name:   "Itinerary"
    author: "Adam Coddington"
    repo:   "coddingtonbear/obsidian-itinerary"

    html_url:    "https://community.obsidian.md/plugins/obsidian-itinerary"
    github_url:  "https://github.com/coddingtonbear/obsidian-itinerary"
    description: "Make planning your trip or event easier by rendering a calendar from event information found in your notes."
    about:       "Plan trips and schedules in Markdown using simple itinerary code blocks. Display events on monthly, weekly, or daily calendars inside Obsidian, color-code and tag items, and spot conflicts or overlaps at a glance."
```
