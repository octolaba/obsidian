# Terminal Workbench Cursor

Terminal Workbench Cursor replaces Obsidian's caret with a canvas-driven engine offering box, line or underline cursors with gliding motion, glow, blink and layered trails. A torch spotlight dims the surrounding workspace, and a Ghost Trail peels a small ghost off typed characters. Pixel trails, motion smear and CRT afterimages adopt Terminal Workbench accent colors.
