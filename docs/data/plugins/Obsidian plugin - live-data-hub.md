# Live Data Hub

Displays live MQTT and REST API data inside notes, turning a note into a dashboard of real-time widgets. Livedata blocks cover MQTT over WebSocket, TCP on desktop, and REST polling, with number, text, badge, and toggle displays, live, stale, and offline status, and an overview sidebar. The recorded inputs state that credentials are stored in the operating system keychain.
