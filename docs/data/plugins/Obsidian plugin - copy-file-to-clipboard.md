# Copy File to Clipboard

Copy File to Clipboard adds a copy option to the file explorer context menu. Text files can be copied as plain text, images as PNG image data ready to paste, or any file placed on the clipboard in its raw form, and the behaviour is configurable per file type.

```cue
plugin: {
    id:     "copy-file-to-clipboard"
    name:   "Copy File to Clipboard"
    author: "Xabi"
    repo:   "ezxabi/copy-file-to-clipboard"

    html_url:    "https://community.obsidian.md/plugins/copy-file-to-clipboard"
    github_url:  "https://github.com/ezxabi/copy-file-to-clipboard"
    description: "Right-click any file in the file explorer to copy it to the clipboard. Configurable: text files as text or raw file, images as PNG or raw file. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add a Copy to clipboard option to the file explorer context menu to copy files in the most useful format. Copy text files as plain text, images as PNG image data ready to paste, or place the raw file on the clipboard and configure behavior per file type."

    stats: {
        downloads:  74
        updated_at: 1783354212000
    }
}
```
