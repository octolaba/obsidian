# Agentic Git Sync

Agentic Git Sync synchronizes the vault two-way with GitHub and maps folders to independent repositories with submodule support, so folder-specific repos are managed from one vault. Git failures are recovered by an AI agent that classifies the error and applies a fix, and conflicts are resolved in a three-pane semantic merge interface that explains the choices made.
