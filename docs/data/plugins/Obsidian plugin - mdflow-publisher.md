# Jacky-mdflow

Turns Markdown notes into layouts ready to publish on WeChat Official Accounts, X Articles and Xiaohongshu. The recorded About text, written in Chinese, describes converting Markdown into WeChat-pasteable HTML with images inlined as Base64, generating long-form X Articles exported as an image ZIP with placeholder markers left in the text, and previewing or batch-exporting 3:4 Xiaohongshu cards with paging, covers and several templates.

    id:     "mdflow-publisher"
    name:   "Jacky-mdflow"
    author: "Jackywxsz"

    html_url:    "https://community.obsidian.md/plugins/mdflow-publisher"
