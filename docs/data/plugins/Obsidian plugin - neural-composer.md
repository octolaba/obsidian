# Neural Composer

Neural Composer builds a knowledge graph over the vault and answers questions through graph-based retrieval, so connections between notes are followed rather than single notes matched. The recorded description names LightRAG as the local Graph RAG engine behind it, and aims the plugin at context-rich queries for research, writing, journaling and project planning.
