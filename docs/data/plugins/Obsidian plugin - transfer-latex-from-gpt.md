# Transfer LaTeX from GPT

Transfer LaTeX from GPT converts LaTeX equations produced by GPT into Obsidian-compatible Markdown so that the math renders correctly in a note. Pasted ChatGPT output is transformed into inline and block LaTeX from a command or a sidebar button.

```cue
plugin: {
    id:     "transfer-latex-from-gpt"
    name:   "Transfer LaTeX from GPT"
    author: "xixia123"
    repo:   "xixia123/obsidian-transfer-latex-from-gpt"

    html_url:    "https://community.obsidian.md/plugins/transfer-latex-from-gpt"
```
