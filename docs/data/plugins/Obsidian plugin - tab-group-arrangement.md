# Tab Group Arrangement

Arranges a tab group evenly, or expands the active group while shrinking the others, which the recorded inputs compare to VS Code behaviour. Manual and auto-expand modes can be switched, with auto-expand enlarging the active group on focus change or on an editor tab click. The mode is changed by clicking the status bar or by running commands.

```cue
plugin: {
    id:     "tab-group-arrangement"
    name:   "Tab Group Arrangement"
    author: "situ2001"
    repo:   "situ2001/obsidian-tab-group-arrangement"

    html_url:    "https://community.obsidian.md/plugins/tab-group-arrangement"
    github_url:  "https://github.com/situ2001/obsidian-tab-group-arrangement"
    description: "Arrange the tab group in a more flexible way. For now, it supports arranging evenly and expanded like VSCode. User can make action and switch mode of arrangement by clicking the status bar or executing commands."
    about:       "Arrange tab groups evenly or expand the active group while shrinking the others, mirroring VS Code behavior. Switch between manual and auto-expand modes to auto-expand the active group on focus change or editor tab click."

    }
```
