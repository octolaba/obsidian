# kumihimo

Renders AV signal-flow diagrams from kumihimo or khm code blocks, placing ports, device groups and cable runs annotated with numbers, lengths and jacket colors. Folded cable, wireless, equipment and parts schedules are generated beside the diagram. Connections are checked for physical compatibility, and signal mismatches produce warnings.
