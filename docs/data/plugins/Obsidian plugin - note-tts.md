# Note TTS

Converts the current note or a text selection to speech through a text-to-speech provider, saving the audio into the vault and opening a built-in player. MiniMax, Replicate or a custom HTTP provider can be configured, the cleaned text can be previewed before it is sent, and conversion starts from the command palette, the sidebar, the file menu or the note context menu.

```cue
plugin: {
    id:     "note-tts"
    name:   "Note TTS"
    author: "sourit2001"
    repo:   "sourit2001/obsidian-note-tts"

    html_url:    "https://community.obsidian.md/plugins/note-tts"
    github_url:  "https://github.com/sourit2001/obsidian-note-tts"
    description: "Convert the current note or selected text to MP3 audio through user-configured TTS APIs. - This plugin has not been manually reviewed by Obsidian staff."

Use MiniMax, Replicate or a custom HTTP provider, preview cleaned text before sending, and trigger conversion from the command palette, sidebar, file menu or note context menu."
