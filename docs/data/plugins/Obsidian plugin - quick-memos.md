# Quick Memos

Captures short memos in a Flomo-style flow, saving each one as a local Markdown file. Memos take images, carry tags, are filtered and browsed as a card stream, and selected text is saved as a memo. Memos also export as PNG cards or are sent as a filtered set to Obsidian Canvas.

```cue
plugin: {
    id:     "quick-memos"
    name:   "Quick Memos"
    author: "liqiuyue9597"
    repo:   "liqiuyue9597/obsidian-memos"

    html_url:    "https://community.obsidian.md/plugins/quick-memos"
    github_url:  "https://github.com/liqiuyue9597/obsidian-memos"
    description: "A flomo-style quick capture and card view for your vault. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Capture ideas fast like Flomo inside Obsidian, saving each memo as a local Markdown file. Insert images, tag and filter memos, browse as a card stream, export memos as PNG cards or send filtered memos to Obsidian Canvas, and save selected text as memos."

    stats: {
        downloads:  455
        updated_at: 1778920360000
    }
}
```
