# NoteTweet

Posts single messages and full threads to X from inside the vault, composed in a writing-first modal, created from a selection or a whole note, and split into a thread automatically when the text is long. Images can be attached by pasting, by picking from the vault, or by embedding wikilinks. Posts can be scheduled through a self-hosted scheduler, reviewed afterwards, and recent ones deleted, and the API credentials are held in the application's secure secret storage.
