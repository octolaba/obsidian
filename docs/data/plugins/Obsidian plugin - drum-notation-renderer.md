# Drum Notation Renderer

Renders drum grooves written as musical positions or token grids into responsive SVG drum notation. Rhythms share one timeline and support independent upper and lower voices, chord stems, beat-aware beams, a percussion clef, time signatures and automatic system wrapping. A compact position syntax covers presets, techniques and repeats.
