# Bluesky

The plugin posts to Bluesky from inside Obsidian, either from a dedicated tab or from selected text. Posts and threads are composed in a tab opened from the sidebar or the command palette and sent directly to the configured account.

```cue
plugin: {
    id:     "bluesky"
    name:   "Bluesky"
    author: "eharris128"
    repo:   "eharris128/obsidian-bluesky"

    html_url:    "https://community.obsidian.md/plugins/bluesky"
    github_url:  "https://github.com/eharris128/obsidian-bluesky"
    description: "Post to Bluesky."
    about:       "Post to Bluesky from inside Obsidian using a dedicated tab or by selecting text. Compose posts or threads, open the Bluesky tab from the sidebar or command palette, and post directly to your Bluesky account."

    stats: {
        downloads:  976
        updated_at: 1782153101000
    }
}
```
