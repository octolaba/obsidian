# Scroller

Scroller adds a typewriter mode that keeps the active line vertically centered and a focus mode that dims text outside the current line, sentence, paragraph or section. Commands jump to the top or bottom of a note, daily notes can be scrolled to the end automatically, the cursor line can be moved line by line with the mouse wheel, and scrollbars can be hidden.
