# Stack Overflow Answers

Given a question URL, the plugin fetches a Stack Overflow answer and embeds its full content in the note. Code blocks, the original formatting and link titles are preserved for copy-ready references.

```cue
plugin: {
    id:     "obsidian-stack-overflow"
    name:   "Stack Overflow Answers"
    author: "bramses"
    repo:   "bramses/obsidian-stack-overflow"

    html_url:    "https://community.obsidian.md/plugins/obsidian-stack-overflow"
    github_url:  "https://github.com/bramses/obsidian-stack-overflow"
    description: "Copy and paste Stack Overflow answers."
    about:       "Insert Stack Overflow answers directly into notes by fetching and embedding full answer content from a question URL. Preserve code blocks, original formatting, and link titles for clean, copy-ready references."

    stats: {
        downloads:  4329
        updated_at: 1654134518000
    }
}
```
