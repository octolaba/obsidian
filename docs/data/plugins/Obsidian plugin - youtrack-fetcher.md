# YouTrack Fetcher

Fetches YouTrack issues by identifier, URL or search query and creates structured Markdown notes in the vault. The note layout comes from a customizable template whose placeholders address issue fields, including arbitrarily nested ones, and paginated search results are imported in bulk.

```cue
plugin: {
    id:     "youtrack-fetcher"
    name:   "YouTrack Fetcher"
    author: "forketyfork"
    repo:   "forketyfork/obsidian-youtrack-fetcher"

    html_url:    "https://community.obsidian.md/plugins/youtrack-fetcher"
    github_url:  "https://github.com/forketyfork/obsidian-youtrack-fetcher"
    description: "Fetches YouTrack issues into notes"
    about:       "Fetch YouTrack issues by ID, URL, or search query and create structured Markdown notes in your vault. Use customizable templates with ${field} placeholders (including arbitrarily nested fields) and import issues from paginated search results."

    stats: {
        downloads:  454
        updated_at: 1779096493000
    }
}
```
