# PennyWallet

PennyWallet records expenses, income, transfers and credit-card repayments as plain Markdown tables inside the vault. It presents monthly summaries, charts and category pies, and tracks account balances and net assets. Transactions can be filtered and edited across cash, bank and credit-card accounts, including debt tracking.
