# Foldable Frontmatter Groups

Groups frontmatter keys into collapsible sections in the native Properties panel and pins the keys to a canonical order. Folder-scoped templates are applied and notes are auto-reconciled to insert defaults and to remove stale or empty fields. Exclusions and cleanup are managed from the settings.

```cue
plugin: {
    id:     "foldable-frontmatter-groups"
    name:   "Foldable Frontmatter Groups"
    author: "Christopher Wagner"
    repo:   "cwagner223355/obsidian-foldable-frontmatter-groups"

    html_url:    "https://community.obsidian.md/plugins/foldable-frontmatter-groups"
```
