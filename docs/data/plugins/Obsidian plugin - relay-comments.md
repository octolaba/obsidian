# Relay Comments

Adds comments and suggestions to Markdown notes in the vault. Both kinds of annotation are described as Relay-aware.

```cue
plugin: {
    id:     "relay-comments"
    name:   "Relay Comments"
    author: "Relay.md"
    repo:   "no-instructions/Relay-Comments"

    html_url:    "https://community.obsidian.md/plugins/relay-comments"
    github_url:  "https://github.com/no-instructions/Relay-Comments"
    description: "Add Relay-aware comments and suggestions to Markdown notes. - This plugin has not been manually reviewed by Obsidian staff."

    stats: {
        downloads:  5
        updated_at: 1786481790000
    }
}
```
