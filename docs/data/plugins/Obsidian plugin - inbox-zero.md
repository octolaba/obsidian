# Inbox Zero

Builds dynamic checklists from inline tags across selected folders, showing each matching note as a checkbox inside a note. Checking an item permanently deletes the underlying file, and drag-and-drop ordering is preserved across sessions. A list is active only where an inbox-zero code block has been inserted.
