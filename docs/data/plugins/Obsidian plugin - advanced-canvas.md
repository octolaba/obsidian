# Advanced Canvas

Advanced Canvas extends Canvas with node, edge, presentation and metadata features for flowcharts, presentations and embedded canvases. Nodes resize automatically and take custom shapes and colors, edges support varied styles and pathfinding, frontmatter drives links, groups collapse, canvas search behaves like the native one, and canvases export to transparent PNG or SVG.
