# Agent MCP

Agent MCP runs coding agents such as Claude Code, Codex or local Ollama models inside a built-in terminal panel. A local IDE bridge streams active file paths and selections to the agent over MCP, and proposed edits appear as terminal-gated diff previews that can be approved or rejected.
