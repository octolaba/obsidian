# Graphite

A calm, Todoist-like task manager in which tasks are plain Markdown lines stored one file per month inside the vault, keeping the history portable and human-readable. It offers Inbox, Today with overdue items, Upcoming, Projects and Filters views, plus a 26-week activity heatmap, subtasks, recurring rules, attachments and quick capture. There are no accounts and no network calls.
