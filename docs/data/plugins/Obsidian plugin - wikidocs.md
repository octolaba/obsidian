# WikiDocs

Fetches WikiDocs books and blogs into Obsidian so they can be written and edited locally and offline, and can upload the result back to WikiDocs. Images and documents are attached by drag and drop, and fast search together with other community plugins can be used on the material while working.

```cue
plugin: {
    id:     "wikidocs"
    name:   "WikiDocs"
    author: "pahkey"
    repo:   "pahkey/obsidian-wikidocs-plugin"

    html_url:    "https://community.obsidian.md/plugins/wikidocs"
    github_url:  "https://github.com/pahkey/obsidian-wikidocs-plugin"
    description: "Fetch, edit, and upload WikiDocs books."
    about:       "편집하세요 위키독스 책과 블로그를 옵시디언에서 직접. 이미지·문서 드래그앤드롭으로 첨부하고 로컬·오프라인에서 빠르게 작성한 뒤 바로 위키독스로 업로드하세요. 빠른 검색과 커뮤니티 플러그인 연동으로 작업 흐름을 원활하게 만드세요."

    stats: {
        downloads:  1060
        updated_at: 1776336839000
    }
}
```
