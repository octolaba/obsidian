# Task Collector

Task status is changed from hotkeys and context menus through a completion modal and configurable task marks. Tasks are collected and regrouped into designated areas within a note, marks are cycled through a sequence, and a timestamp can be appended or matched text removed when a task is marked.

    id:     "obsidian-task-collector"
