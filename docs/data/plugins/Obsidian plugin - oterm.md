# oterm

oterm runs a full terminal emulator inside Obsidian on xterm.js and node-pty, with WebGL rendering, truecolor and Unicode support. Multiple tabs are managed, terminal output is searched, links are clickable, and terminals can be docked in the sidebar. It works with PowerShell, WSL, zsh, tmux and other CLI tools, and ships a Catppuccin Mocha dark theme.
