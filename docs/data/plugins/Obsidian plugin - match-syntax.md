# MatchSyntax

MatchSyntax highlights the parts of the active note that match a flexible, regex-like query, using the compromise grammar library. Queries combine plain word matches, part-of-speech tags such as Noun and Verb, regular expressions and the operators for conjunction and negation. Searching is limited to English.
