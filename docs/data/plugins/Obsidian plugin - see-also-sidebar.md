# See Also Sidebar

See Also Sidebar shows related notes in a dedicated sidebar view, taken either from a see-also property in a note's frontmatter or from notes sharing the same tags. The links appear in the panel as soon as the property is set, so there is no need to scroll back to the top of the note or hunt through the properties view.

```cue
plugin: {
    id:     "see-also-sidebar"
    name:   "See Also Sidebar"
    author: "David Breece"
    repo:   "davidbreece/obsidian-see-also-sidebar"

    html_url:    "https://community.obsidian.md/plugins/see-also-sidebar"
    github_url:  "https://github.com/davidbreece/obsidian-see-also-sidebar"
    description: "Display related notes in a sidebar view using a custom property or using notes with the same tags. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Keep related notes handy in a dedicated sidebar. Add a see-also property to any note's frontmatter and those links appear instantly in the panel — no need to scroll back to the top of the note or hunt through the properties view."

    stats: {
        downloads:  197
        updated_at: 1786214688000
    }
}
```
