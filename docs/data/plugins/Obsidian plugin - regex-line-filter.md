# Regex Line Filter

Filters the active note so that only lines matching a JavaScript regular expression are displayed, and those lines stay editable with changes saved back to the file. Custom filters can be created, assigned hotkeys, and reused from a list of recent regexes, including date-template variables, while empty lines and indents are configurable. A subtle editor indicator shows the filter is on, and copied text contains only the visible lines.
