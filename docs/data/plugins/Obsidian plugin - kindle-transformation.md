# Kindle Transformation

Transforms Kindle-exported HTML notes into structured Markdown through a drag-and-drop modal. Kindle highlight colors can be mapped to Obsidian callouts, highlights formatted as nested blockquotes, stray line breaks cleaned up and content organized by chapter. The resulting notes are saved to a folder you specify.

```cue
plugin: {
    id:     "kindle-transformation"
    name:   "Kindle Transformation"
    author: "tristan0929"
    repo:   "tristan0929/Kindle-Transformation"

    html_url:    "https://community.obsidian.md/plugins/kindle-transformation"
    github_url:  "https://github.com/tristan0929/Kindle-Transformation"
    description: "Elegantly transform Kindle exported HTML notes into beautifully formatted markdown files. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Transform Kindle-exported HTML notes into clean, structured Obsidian Markdown using a drag-and-drop modal. Map Kindle highlight colors to Obsidian callouts, format highlights as nested blockquotes, clean up line breaks, organize by chapter, and save notes to a specified folder."

    stats: {
        downloads:  149
        updated_at: 1784170890000
    }
}
```
