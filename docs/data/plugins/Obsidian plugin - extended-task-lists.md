# Extended Task Lists

Extended Task Lists adds reader-view rendering for in-progress and won't do task items, with dedicated UI and live-preview support. It can also scan task lists across the vault to generate a top-level TODO. Files and folders are kept out of that scan with an exclude TODO comment or an .exclude_todos file.

    id:     "extended-task-lists"
    name:   "Extended Task Lists"
