# Link indexer

Generates index notes that list and count links across the vault according to configurable conditions. Named presets run the reports, covering used links, non-existent targets and embed counts, and toggle wiki-link output, strict line breaks and regex-based excludes for source or target files.

```cue
plugin: {
    id:     "obsidian-link-indexer"
    name:   "Link indexer"
    author: "aviskase"
    repo:   "aviskase/obsidian-link-indexer"

    html_url:    "https://community.obsidian.md/plugins/obsidian-link-indexer"
    github_url:  "https://github.com/aviskase/obsidian-link-indexer"
    description: "Generate index notes with links based on various conditions."
    about:       "Create index notes that list and count links across your vault according to flexible rules. Use named presets to run reports (used links, non-existent targets, embed counts) and toggle wiki-link output, strict line breaks, and regex-based excludes for source or target files."
```
