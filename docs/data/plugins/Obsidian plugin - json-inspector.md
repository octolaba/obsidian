# JSON Inspector

JSON Inspector renders JSON code blocks as an interactive inspector with Tree, Raw and JSONPath query views. Big integers and high-precision decimals are preserved losslessly, and search, copy actions, lazy rendering and keyboard navigation help explore the data. It states that it runs fully locally, with no network, telemetry or eval.
