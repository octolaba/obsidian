# Edit mode switch

Edit mode switch adds a button to the file header for switching between Source, Live Preview and Reading modes. It can be a single cycling button or separate icons per mode with the active one highlighted, and it can show the next mode's icon instead of the current one. The file header and Live Preview must be enabled.

```cue
plugin: {
    id:     "shortcut-edit-mode"
    name:   "Edit mode switch"
    author: "Mara"
    repo:   "mara-li/obsidian-edit-shortcut"

    html_url:    "https://community.obsidian.md/plugins/shortcut-edit-mode"
    github_url:  "https://github.com/mara-li/obsidian-edit-shortcut"
    description: "Add a button in the file header, in edit mode, to switch between source and live-preview."
    about:       "Add a file-header button to switch between Source, Live Preview, and Reading modes. Use a single cycling button or display separate icons for each mode with active highlighting, and optionally show the next-mode icon instead of the current one. Requires file header and Live Preview enabled."

    stats: {
        downloads:  5118
        updated_at: 1781207882000
    }
}
```
