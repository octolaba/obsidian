# Unique Tab Labels

Makes tab labels unique by prefixing the filename with its parent folder, adding further parent levels until each label differs from the rest. Only as many levels as needed are added, so labels stay minimal.

```cue
plugin: {
    id:     "unique-tab-labels"
    name:   "Unique Tab Labels"
    author: "stephencarboni"
    repo:   "stephencarboni/obsidian-unique-tab-labels"

    html_url:    "https://community.obsidian.md/plugins/unique-tab-labels"
    github_url:  "https://github.com/stephencarboni/obsidian-unique-tab-labels"
```
