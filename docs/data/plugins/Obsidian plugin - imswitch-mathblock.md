# IMSwitch in Math Block

Switches the input method when the cursor enters or leaves inline math delimited by dollar signs, forcing English input inside a formula and restoring the previous IME on exit. Math areas are detected automatically and the IME switch commands are configurable, working with macism on macOS or any command-line IME switcher.

    name:   "IMSwitch in Math Block"
