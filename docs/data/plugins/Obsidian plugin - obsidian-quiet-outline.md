# Quiet Outline

This plugin replaces the outline with a quieter one that does not auto-expand, renders headings as Markdown and supports search. The search pierces Markdown and HTML and accepts regular expressions while respecting the rendered output. Heading levels, auto-expand and collapse, drag-reordering, hover previews and Vim-like navigation in Canvas or Kanban are available, and per-note scroll, cursor and heading expansion state is remembered.

```cue
plugin: {
    id:     "obsidian-quiet-outline"
    name:   "Quiet Outline"
    author: "guopenghui"
    repo:   "guopenghui/obsidian-quiet-outline"

    html_url:    "https://community.obsidian.md/plugins/obsidian-quiet-outline"
    github_url:  "https://github.com/guopenghui/obsidian-quiet-outline"
    description: "Make outline quiet and more powerful, including no-auto-expand, rendering heading as Markdown, and search support."
    about:       "Display a compact, quiet outline of headings with search that pierces Markdown/HTML and supports regex while respecting Markdown render. Control heading levels, auto-expand/collapse, drag and reorder notes, preview content on hover, and navigate outlines in Canvas or Kanban with Vim-like keybindings. Remember per-note scroll, cursor, and heading expansion state."
```
