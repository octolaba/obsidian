# Note Companion

Note Companion transcribes YouTube links and audio or video files, records meetings, and produces transcripts, summaries, discussion points and action items from them. It chats with the vault using file, folder and tag context, and organizes notes by suggesting folders, tags, titles and templates. It runs against the cloud service, your own AI keys, or self-hosted models, and requires a subscription or self-hosting.
