# MetaEdit

MetaEdit edits YAML and Dataview metadata across files through a quick menu, adding, updating, deleting and transforming properties. Auto-properties offer selectable values and multi-value arrays, and progress properties update task counts on their own. Changes can also be applied from Kanban lane changes or through the plugin API.
