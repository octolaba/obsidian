# Johnny.Decimal Manager

Johnny.Decimal Manager creates and manages items under the Johnny.Decimal classification, automating the creation and enforcement of Area, Category and Item addresses. Missing parent folders are created on demand, and the on-disk hierarchy and filenames are kept consistent. The stated aim is clean file explorer views and a layout that travels across platforms, cloud storage and AI-oriented workflows.
