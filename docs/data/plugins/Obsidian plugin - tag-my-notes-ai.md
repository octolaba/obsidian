# Tag My Notes (AI)

Tag My Notes (AI) tags notes with a chosen AI model and applies the selected tags to a folder, the active note, or every note. Tagging progress is shown live, and the model's chain-of-thought and the tag list it draws from can be customized. Persisted tagging operations can be viewed, cancelled or deleted, and OpenAI, Vercel Gateway, Ollama, OpenRouter and Mistral are supported, with custom endpoints.
