# EasySync

Synchronizes notes and settings with OneDrive in both directions, on desktop and mobile. File content is compared by SHA-256, conflicts are surfaced side by side with the differences highlighted, and files that failed or were skipped stay listed in the sidebar. What is synced can be chosen per item, and syncs are incremental.
