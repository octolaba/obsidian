# Autoscroller

Autoscroller scrolls the active note by itself at a configurable pace, for hands-free reading or during presentations. Scrolling is toggled from a command or a ribbon icon, and the speed is changed with increase and decrease commands or by right-clicking the icon to cycle through rates.
