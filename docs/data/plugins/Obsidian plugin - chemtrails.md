# Chemtrails

Chemtrails renders SMILES notation as vector SVG diagrams inside notes without contacting an external server. Empty whitespace is cropped automatically, molecules are scaled to fit the pane, and the drawing follows the light and dark themes of Obsidian. The plugin describes itself as a bridge to the Smiles-Drawer of the Reymond Group.

    id:     "chemtrails"
    name:   "Chemtrails"
