# Semantic Linker

Semantic Linker recommends semantically related notes from local metadata, indexing titles, filenames, tags and frontmatter rather than full note bodies, and presents them in an interactive graph sidebar. Connected nodes are shown alongside ranked unlinked candidates: clicking a candidate inserts a link and clicking a context node removes one, with embeddings computed locally or through an OpenAI-compatible service.
