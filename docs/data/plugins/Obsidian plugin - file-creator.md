# File Creator

File Creator creates files from templates in any vault folder - Markdown notes, PDFs, Kanban boards, base files and Excalidraw drawings - and can embed them into an existing note. The folder tree is browsable, dates are added to filenames as a prefix or suffix, and Kanban boards are generated with columns and sample tasks. Markdown, PDF, Excalidraw and base templates are reused for consistent files.
