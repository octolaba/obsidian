# Folder Sort

Sorts folders A to Z or Z to A in the file explorer while leaving the Obsidian file sorting unchanged. The ordering is natural and case-insensitive at every level of the tree and the direction is kept per vault. Folders keep their existing order or are placed first or last.

```cue
plugin: {
    id:     "folder-sort"
    name:   "Folder Sort"
    author: "Tomas Gutierrez"
    repo:   "t0masgutierrez/folder-sort"

    html_url:    "https://community.obsidian.md/plugins/folder-sort"
    github_url:  "https://github.com/t0masgutierrez/folder-sort"
    description: "Sort folders A-Z or Z-A - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sort folders A–Z or Z–A in the file explorer and keep Obsidian's file sorting unchanged. Use natural, case-insensitive ordering at every tree level, persist direction per vault, and choose folder placement (existing order, folders first, or folders last)."

}
```
