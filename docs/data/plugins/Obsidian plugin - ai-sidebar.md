# AI Sidebar

Adds a right-sidebar assistant panel that connects local CLI agents or OpenAI-compatible and OAuth providers to relevant vault context: the active note, the selection, links, backlinks, Bases files and search matches. Slash-command skills run from the panel, conversation memory is optional, and vault write actions are gated by Read, Confirm or Full modes.
