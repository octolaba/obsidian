# YouVersion Linker

Turns Bible verse references typed in a note into links to YouVersion. A configurable trigger character inserts a link, an inline quote or a footnote quote; ranges and comma-separated passages are handled, book names are recognized in several languages, and the Bible version is selectable.

```cue
plugin: {
    id:     "youversion-linker"
    name:   "YouVersion Linker"
    author: "jaanonim"
    repo:   "jaanonim/obsidian-youversion-linker"

    html_url:    "https://community.obsidian.md/plugins/youversion-linker"
    github_url:  "https://github.com/jaanonim/obsidian-youversion-linker"
    description: "Automatically link bible verses in your notes to YouVersion bible."
    about:       "Link Bible verses to YouVersion directly from your notes by typing verse references. Use @, >, or ^ (configurable) to insert links, inline quotes, or footnote quotes; handle ranges and comma-separated passages and recognize book names in multiple languages while letting you pick a Bible version."

    stats: {
        downloads:  12329
        updated_at: 1779360828000
    }
}
```
