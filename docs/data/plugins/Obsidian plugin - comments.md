# Comments

Comments adds inline comment callouts written as a comment callout carrying a name, a date and the content, and lists them in a right-hand pane showing author, date and content. From the pane you can jump to a comment's location, add subcomments, and remove entries. Comments stay hidden in reading mode and are excluded from exports.

```cue
plugin: {
    id:     "comments"
    name:   "Comments"
    author: "jaspersurmont"
    repo:   "jaspersurmont/obsidian-comments"

    html_url:    "https://community.obsidian.md/plugins/comments"
    github_url:  "https://github.com/jaspersurmont/obsidian-comments"
    description: "Add comments to your notes to facilitate collaberation"
    about:       "Add inline comment callouts using a simple > [!comment] NAME | DATE > CONTENT format and view all comments in a right-hand pane showing author, date, and content. Navigate to comment locations, add subcomments, and remove entries from the pane; keep comments hidden in reading mode and excluded from exports."

    stats: {
        downloads:  2625
        updated_at: 1751290587000
    }
}
```
