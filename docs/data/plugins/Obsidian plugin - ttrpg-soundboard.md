# TTRPG Tools - Soundboard

A soundboard for tabletop RPG sessions that plays sound effects, music and ambience from a folder-based library, shown as image tiles in grid or list views and triggerable from buttons in a note. Playback is controlled per track with stop, loop, fades and volume, and Stop All clears everything at once. Playlists play sequentially or shuffled, and long ambience files are handled with a global ambience volume.
