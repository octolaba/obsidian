# Windy

Treats the open note as the agent's workspace, so a page-native agent follows whichever page is active. Conversations tied to a page are restored on return, and drafts and streaming state survive navigation. Background agent tasks keep running while notes are switched, and a floating entry point opens page conversations without managing chat tabs.
