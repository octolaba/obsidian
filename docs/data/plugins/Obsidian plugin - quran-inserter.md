# Quran inserter

Inserts Quran verses into the editor through the Al Quran Cloud API, addressed by surah and ayah number. The fetched text is placed at the cursor with proper line breaks, and insertion is triggered from the command palette, the ribbon or a hotkey.

```cue
plugin: {
    id:     "quran-inserter"
    name:   "Quran inserter"
    author: "ramysami"
    repo:   "ramysami/obsidian-quran-plugin"

    html_url:    "https://community.obsidian.md/plugins/quran-inserter"
    github_url:  "https://github.com/ramysami/obsidian-quran-plugin"
    description: "Insert Quran verses into the editor by specifying the surah and ayah number. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert Quranic verses directly into your notes via the Al Quran Cloud API. Search by surah:verse (e.g., 2:255) and place the fetched text at the cursor with proper line breaks; trigger from the command palette, ribbon, or a hotkey."

    stats: {
        downloads:  110
        updated_at: 1776810485000
    }
}
```
