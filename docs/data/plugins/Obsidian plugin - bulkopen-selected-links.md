# Bulk open selected links

The plugin opens every link inside the current selection at once while editing. The targets can be opened as tabs, windows or splits.

```cue
plugin: {
    id:     "bulkopen-selected-links"
    name:   "Bulk open selected links"
    author: "autohub7"
    repo:   "autohub7/obsidian-open-selected-links"

    html_url:    "https://community.obsidian.md/plugins/bulkopen-selected-links"
    github_url:  "https://github.com/autohub7/obsidian-open-selected-links"
    description: "Easily open all selected links in edit mode."
    about:       "Open all selected links in edit mode at once. Choose to open them in tabs, windows, or splits for streamlined multi-link editing."
```
