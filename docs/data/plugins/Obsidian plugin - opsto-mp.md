# OpsToMP

OpsToMP converts Markdown notes into HTML compatible with the WeChat Official Account platform and previews the rendered output inside Obsidian in real time. Notes are uploaded to the draft box or published directly, local images are uploaded automatically, WeChat styling is applied, and dangerous tags are filtered for XSS protection. Drafts and posts are managed from the plugin.

plugin: {
    id:     "opsto-mp"
    name:   "OpsToMP"
    author: "eatmelonsec"
    repo:   "eatmelonsec/OpsToMP"

    html_url:    "https://community.obsidian.md/plugins/opsto-mp"
    github_url:  "https://github.com/eatmelonsec/OpsToMP"
