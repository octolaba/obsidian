# Ruled template

Ruled template picks the template for a new file automatically, using ordered rules that match the file path. Rules are written with regex or glob patterns and can be reordered or deleted, and a path can be tested to see which template matches and to validate patterns and templates.

```cue
plugin: {
    id:     "ruled-template"
    name:   "Ruled template"
    author: "ypetremann"
    repo:   "ypetremann/obsidian-ruled-template"

    html_url:    "https://community.obsidian.md/plugins/ruled-template"
    github_url:  "https://github.com/ypetremann/obsidian-ruled-template"
```
