# Window Spaces

Saves and restores window layouts for individual Obsidian popout windows, leaving the main workspace untouched. A saved layout keeps splits, tabs, view modes and the window's position and size, so multi-monitor arrangements can be reproduced or used to spawn a new popout. Layouts carry smart names, per-layout auto-save and file hover previews.
