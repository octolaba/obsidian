# Mirror Archive

Mirror Archive moves selected files and folders into a configurable mirror archive root while preserving their original vault path and creating intermediate folders as needed. The active file or a selection, covering Markdown, PDFs, images, Office documents and other file types, is archived from a command or from the file-explorer context menu, with configurable conflict handling.

```cue
plugin: {
    id:     "mirror-archive"
    name:   "Mirror Archive"
    author: "MapleCheng"
    repo:   "maplecheng/obsidian-mirror-archive"

    html_url:    "https://community.obsidian.md/plugins/mirror-archive"
    github_url:  "https://github.com/maplecheng/obsidian-mirror-archive"
    description: "Move selected files and folders to a configurable mirror archive root while preserving their original vault path. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Move files and folders into a configurable archive root while preserving their original vault paths and auto-creating intermediate folders. Archive the active file or selected items (Markdown, PDFs, images, Office docs, and other files) from commands or the file-explorer context menu with configurable conflict handling."
```
