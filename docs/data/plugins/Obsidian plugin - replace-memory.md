# Replace Memory

Stores a list of plain-text find and replace rules and applies them either one at a time or all enabled rules in one click. The rules run sequentially in list order, and that order can be rearranged. Settings are kept locally, with no network requests and no telemetry.

```cue
plugin: {
    id:     "replace-memory"
    name:   "Replace Memory"
    author: "lau"
    repo:   "397327/replace-memory"

    html_url:    "https://community.obsidian.md/plugins/replace-memory"
    github_url:  "https://github.com/397327/replace-memory"
    description: "Remember common replacement rules and apply them all with one click, in your chosen order. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Remember common plain-text Find→Replace rules and run them individually or execute all enabled rules with one click. Apply rules sequentially in list order, reorder entries as needed, and store all settings locally with no network requests or telemetry."

        downloads:  254

}
```
