# Task Center

Task Center builds Today, Week, Month, Completed and Unscheduled views on top of Obsidian Tasks markdown, so work can be planned visually without leaving the vault. Tasks are dragged between dates, nested under parent tasks, abandoned without deleting the markdown, and reviewed with estimate against actual summaries, while Quick Add captures tasks from natural language including English and Chinese date words. The source of truth stays plain markdown, and Obsidian Tasks metadata, tags and inline fields are preserved. A command-line interface for agents and automation is included, with a companion skill installed separately.
