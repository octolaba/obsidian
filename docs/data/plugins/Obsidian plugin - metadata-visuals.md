# Metadata Visuals

Metadata Visuals drives File Explorer colours and icons, inline metadata highlighting, smart folders and bulk metadata updates from frontmatter values, without altering the stored files. Rule groups, live previews and inherited folder states let workflow values be visualized and acted on across the vault.
