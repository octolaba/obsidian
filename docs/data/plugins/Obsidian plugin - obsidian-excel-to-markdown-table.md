# Excel to Markdown Table

Pastes spreadsheet data copied from Microsoft Excel, Google Sheets, Apple Numbers or LibreOffice Calc into a note as a Markdown table. Single-column and multi-column clipboard ranges are converted into formatted Markdown tables through a plain paste or through the plugin's own paste and command options.
