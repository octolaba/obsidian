# Note Diary

Note Diary places every note on a calendar at the day it was created, so a vault can be browsed by date without a Daily Note setup. Days are shaded according to how many notes were made on them.

```cue
plugin: {
    id:     "note-diary"
    name:   "Note Diary"
    author: "yaye.work"
    repo:   "yaye-work/note-diary"

    html_url:    "https://community.obsidian.md/plugins/note-diary"
    github_url:  "https://github.com/yaye-work/note-diary"
    description: "Browse your notes on a calendar. Every note appears on the day you created it, like a Daily Note setup but automatic. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Browse your vault on a calendar that places each note on its creation date and highlights days by how many notes you made."

    stats: {
        downloads:  75
        updated_at: 1784133240000
    }
}
```
