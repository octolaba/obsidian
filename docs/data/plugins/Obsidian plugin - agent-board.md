# AgentBoard

AgentBoard keeps a visual board synchronized in real time with a Markdown todo file, so edits made on the board, in the file, or externally appear on both sides. Headings become columns, tasks are edited inline, critical items carry a badge, completed tasks collapse and columns can be reordered. Wiki-links render, and About lines appear as tooltips.
