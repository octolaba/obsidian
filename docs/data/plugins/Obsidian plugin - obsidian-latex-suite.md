# Latex Suite

Speeds up typesetting LaTeX math with snippet-driven text expansion, including custom snippets that turn a short shortcut into a full command such as a square root or a fraction. Auto-fraction, matrix-aware Tab and Enter behavior, and an optional conceal feature further shorten input and tidy the displayed equations.
