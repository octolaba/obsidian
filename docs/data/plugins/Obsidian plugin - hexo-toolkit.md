# Hexo Toolkit

Hexo Toolkit converts Obsidian notes into Hexo-compatible Markdown, extracting front-matter and translating internal title links, images including size variants, and embedded Excalidraw drawings into Hexo-friendly forms. Images can be uploaded to SM.MS or matched against local copies. The result is shown in a Hexo Conversion Result window before use.
