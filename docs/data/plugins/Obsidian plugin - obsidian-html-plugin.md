# HTML Reader

Opens files with the .html and .htm extensions inside Obsidian and renders them in place for reading. Operating modes control scripting, styles, images, CSP and HTML sanitization for safer viewing.

```cue
plugin: {
    id:     "obsidian-html-plugin"
    name:   "HTML Reader"
    author: "nuthrash"
    repo:   "nuthrash/obsidian-html-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-html-plugin"
    github_url:  "https://github.com/nuthrash/obsidian-html-plugin"
    description: "Open .html and .htm files."
    about:       "Open .html and .htm files directly inside Obsidian and render them in-place for quick reading. Choose operating modes to control scripting, styles, images, CSP and HTML sanitization for safer viewing."
```
