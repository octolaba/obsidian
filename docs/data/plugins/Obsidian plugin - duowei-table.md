# Duowei Table

Stores structured data in plain-text .duowei files inside the vault, keeping each record as a readable JSON file with no account, server or network involved. Table, kanban and gallery views display the data, alongside a Bases-compatible layout. Nine field types, CSV and TSV import, drag-fill, filtering and sorting are available, and records can be bound to Markdown frontmatter.
