# Note Placeholder

Replaces the text of a note link in view mode with text taken from a placeholder property on the linked note, so custom text is shown instead of the link title. The placeholder property name is configurable, placeholders can be forced over link names, header and block separators can be added, and placeholders can be disabled per link.

```cue
plugin: {
    id:     "note-placeholder"
    name:   "Note Placeholder"
    author: "xzst4nce"
    repo:   "xzst4nce/note-placeholder"

    html_url:    "https://community.obsidian.md/plugins/note-placeholder"
```
