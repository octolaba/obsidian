# Footprint Studio

Creates and edits travel footprint notes backed by an interactive map, structured frontmatter and managed photo attachments. All footprints can be viewed on a single map with draft markers, photos imported, reordered and captioned with EXIF GPS and timestamp support, and places searched or reverse-geocoded. Footprints link to Markdown or MDX posts, images stay in dedicated attachment folders, and the interface is also available in Simplified Chinese on desktop and mobile.
