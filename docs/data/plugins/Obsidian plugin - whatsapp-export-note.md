# WhatsApp export note

Converts the current note into the formatting WhatsApp accepts so that it can be shared there. Headings and highlights become bold, equations are rendered as code, and bold, italics, blockquotes and strikethrough are kept. Images and horizontal lines are removed and links keep only their text, while Obsidian links have to be deleted by hand.

    id:     "whatsapp-export-note"
    name:   "WhatsApp export note"

    html_url:    "https://community.obsidian.md/plugins/whatsapp-export-note"
