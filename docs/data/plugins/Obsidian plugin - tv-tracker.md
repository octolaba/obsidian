# Movie and TV show tracker

Tracks movies and TV shows by searching for a title and adding it to a library with status and ratings. Episode lists can be added to the current file, new seasons and episodes fetched, and metadata updated together with country-specific streaming availability filtered by OTT provider. A command adds a title from anywhere.

```cue
plugin: {
    id:     "tv-tracker"
    name:   "Movie and TV show tracker"
    author: "shreshth-mehra"
    repo:   "shreshth-mehra/Obsidian-TV-Tracker"

    html_url:    "https://community.obsidian.md/plugins/tv-tracker"
    github_url:  "https://github.com/shreshth-mehra/Obsidian-TV-Tracker"
    description: "A movie and TV show tracker."
    about:       "Track movies and TV shows in your vault by searching and adding titles to a library with status and ratings. Add episode lists to the current file, fetch new seasons and episodes, update metadata and country-specific streaming availability with OTT provider filters, and add titles from anywhere via a command."
```
