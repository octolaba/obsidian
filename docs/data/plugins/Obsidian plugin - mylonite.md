# Mylonite

Pairs Obsidian devices against a sync server the user hosts, so vault data moves through storage they control. The recorded text states that content is end-to-end encrypted and stays encrypted during transfer.

    github_url:  "https://github.com/z1xus/mylonite"

    about:       "Host a self-managed sync server and pair Obsidian devices to synchronize vault data end-to-end encrypted through your own storage. Keep vault content encrypted during transfer and sync notes across devices via a remote server you control."
