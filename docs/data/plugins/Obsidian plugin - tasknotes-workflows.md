# TaskNotes Workflows

TaskNotes Workflows automates TaskNotes through workflow definitions written as editable Markdown files kept in the vault. A status change can start or stop time tracking, scheduled dates can be cleared or rolled forward, and priority can rise as a due date approaches. Parent metadata can be mirrored into subtasks, and blocked tasks can trigger reminders.

    id:     "tasknotes-workflows"
