# Research Hub

Research Hub creates structured research projects, each with auto-generated Sources, Claims and Synthesis subfolders plus a project index. Sources are captured with key findings and a credibility rating, claims are recorded against the sources supporting them with a confidence value, and synthesis notes are written on top. A sidebar lists the projects with counts.

```cue
plugin: {
    id:     "research-hub"
    name:   "Research Hub"
    author: "wesswart77"
    repo:   "wesswart77/obsidian-research-hub"

    html_url:    "https://community.obsidian.md/plugins/research-hub"
    github_url:  "https://github.com/wesswart77/obsidian-research-hub"
    description: "A focused research workspace for Obsidian: capture sources, evidence, claims, and synthesis notes for any topic or project. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create structured research projects with auto-generated Sources, Claims, and Synthesis subfolders plus a project index. Capture sources with key findings and credibility, record claims linked to supporting sources with confidence, and write synthesis notes. View projects in a sidebar with counts."

    stats: {
```
