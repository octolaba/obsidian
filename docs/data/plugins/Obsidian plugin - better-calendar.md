# Better Calendar

Better Calendar shows a compact, space-filling calendar that fits several months on screen while keeping day cells at a comfortable size. Daily notes are opened or created from the configured template, days that already have a note are marked with a dot, and custom regex rules drop colored highlights on matching days. The view keeps today centered with the recent weeks in sight.
