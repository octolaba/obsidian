# Media Atlas

Browses the images in a vault through a responsive gallery covering PNG, JPG, WebP, GIF and SVG. Images are dragged from the gallery into notes and located through fast filtering search. Added, renamed and deleted files are detected in real time, so the gallery stays in step with the vault.
