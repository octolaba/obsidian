# worktable

Provides a dashboard for focus, tasks, learning, review and news, with a focus mode, a task kanban, study trackers and review lists. Vault data is displayed through native custom views rather than an external query engine, with hot-reload styles and real-time service status. Local AI service tokens are configured and their connection state is monitored.
