# Better Canvas Lock

Better Canvas Lock extends the read-only mode of Canvas so that scrolling, zooming and drag-and-drop are locked as well. The lock is patched to apply automatically when switching between canvases, and dragging and scrolling are re-enabled temporarily while a canvas card is focused.
