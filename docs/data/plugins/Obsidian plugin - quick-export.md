# Quick Export

Exports a whole note or a text selection to a folder outside the vault as a .md or .txt file, using the live editor content so unsaved edits are included. Commands are reachable from context menus and hotkeys. Written files are timestamped, illegal filename characters are replaced and names are capped at 80 characters; desktop only.

```cue
plugin: {
    id:     "quick-export"
    name:   "Quick Export"
    author: "mikagosz"
    repo:   "mikagosz/obsidian-quick-export"

    html_url:    "https://community.obsidian.md/plugins/quick-export"
    github_url:  "https://github.com/mikagosz/obsidian-quick-export"
    description: "Right-click a note or a text selection to save a copy outside the vault as .md or .txt. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Export notes or selected text to a folder outside the vault as .md or .txt, using live editor content for unsaved edits. Access commands from context menus or hotkeys to write timestamped files with illegal characters replaced and an 80‑char name cap; desktop only."
```
