# Publish Note to Mowen Note

Publishes a note to the Mowen mini program in one action, converting Markdown to Mowen rich text, uploading linked images and turning internal links into embedded notes. An LLM assistant can generate the title, tags and summary, and Mowen ids and metadata are written back into the note frontmatter. Privacy and sharing settings are chosen before posting.
