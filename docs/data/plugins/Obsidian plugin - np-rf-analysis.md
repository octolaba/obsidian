# nPort RF Analysis

Embeds RF and microwave network analysis in Markdown notes, running nP JavaScript on demand. Results render inline as SVG line charts, Smith charts or tables, and the JSON render instructions are saved so exports are repeatable. Obsidian on desktop is supported, and the recorded description states that mobile is pending testing.

```cue
plugin: {
    id:     "np-rf-analysis"
    name:   "nPort RF Analysis"
    author: "Jerome G Wiltz"
    repo:   "jerrywiltz/np-rf-analysis"

    html_url:    "https://community.obsidian.md/plugins/np-rf-analysis"
    github_url:  "https://github.com/jerrywiltz/np-rf-analysis"
    description: "Analyze RF and microwave networks from Markdown and render SVG charts, tables, and Smith plots. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed RF and microwave network analysis in Obsidian Markdown notes. Run nP JavaScript on demand and render inline SVG line charts, Smith charts, or tables while saving JSON render instructions for safe, repeatable exports. Support Obsidian desktop; mobile pending testing."

    stats: {
        downloads:  24
        updated_at: 1784740301000
    }
}
```
