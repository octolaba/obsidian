# Read in Edge

Opens the active Markdown file in Microsoft Edge so that Edge's built-in Read Aloud text-to-speech can read it. A ribbon icon and a command launch the note in Edge Workspace on desktop and start Read Aloud there.

```cue
plugin: {
    id:     "read-in-edge"
    name:   "Read in Edge"
    author: "Ooheroism"
    repo:   "ooheroism/obsidian-open-edge-tts"

    html_url:    "https://community.obsidian.md/plugins/read-in-edge"
    github_url:  "https://github.com/ooheroism/obsidian-open-edge-tts"
    description: "Opens the current active Markdown file using Microsoft Edge browser. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open the active Markdown file in Microsoft Edge to use its built-in Read Aloud text-to-speech. Use the ribbon icon or command to launch the note in Edge Workspace on desktop and start Read Aloud there."

    stats: {
        downloads:  64
        updated_at: 1783504636000
    }
}
```
