# Oh My Claudian

Embeds coding agents - Claude Code, Codex, Cursor, Grok, OpenCode, Oh My Pi and Pi - in the vault, where they read, write, search, run commands and carry out multi-step workflows; it is a fork of Claudian. A sidebar chat provides tabs, history, forks and resumes, inline edits with word-level diff previews, slash commands, skills and @mentions. Providers and models are selectable, including OMP over ACP, alongside provider-level planning, permission and reasoning controls.
