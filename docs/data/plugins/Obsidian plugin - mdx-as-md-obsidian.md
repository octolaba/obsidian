# mdx as md

Lets MDX files be edited as plain Markdown inside Obsidian, exposing the Markdown content while the MDX syntax for code and components is preserved. The recorded text states that Obsidian 0.10.12 or later is required.

```cue
plugin: {
    id:     "mdx-as-md-obsidian"
    name:   "mdx as md"
    author: "mkozhukharenko"
    repo:   "mkozhukharenko/mdx-as-md-obsidian"

    html_url:    "https://community.obsidian.md/plugins/mdx-as-md-obsidian"
    github_url:  "https://github.com/mkozhukharenko/mdx-as-md-obsidian"
    description: "Edit mdx files as Markdown."
    about:       "Edit MDX files as plain Markdown inside Obsidian, exposing markdown content while preserving MDX syntax for code and components. Use with Obsidian 0.10.12 or later."
```
