# Task Mover

Task Mover gathers unfinished tasks from a specified folder and consolidates them into a single daily note. Tasks are grouped by their original file or topic, and surrounding context is preserved because task blocks move together. It handles simple checkbox tasks or task-block formats without queries or code, and the originals can optionally be removed after the move.
