# TOON Syntax Highlight

Highlights TOON, Token-Oriented Object Notation, inside fenced code blocks, using the theme's own code color variables so tabular dumps stay readable in light and dark themes. Strings, numbers, booleans, nulls and comments are parsed and colored in Reading View and Live Preview. Source mode is left as plain text.

```cue
plugin: {
    id:     "toon-syntax"
    name:   "TOON Syntax Highlight"
    author: "Sebastián Salas"
    repo:   "sebasalas/obsidian-toon-syntax"

    html_url:    "https://community.obsidian.md/plugins/toon-syntax"
    github_url:  "https://github.com/sebasalas/obsidian-toon-syntax"
    description: "Syntax highlighting for TOON (Token-Oriented Object Notation) in fenced code blocks. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Highlight TOON (Token-Oriented Object Notation) in fenced code blocks using Obsidian's --code-* theme colors so tabular dumps stay readable in both light and dark themes. Render in Reading View and Live Preview with correct parsing of strings, numbers, booleans, nulls and comments; Source mode stays plain text."
```
