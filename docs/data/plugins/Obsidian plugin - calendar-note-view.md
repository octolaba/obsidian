# Calendar Note View

Adds a note-backed month calendar to Obsidian, both as a sidebar calendar and as a Calendar view for Bases entries. Date-only and inclusive multi-day events are drawn as continuous bars on stable lanes, and daily notes get indicators with quick opening and creation. Source profiles match notes by folder, tag or property, and today is highlighted in a timezone-aware way.
