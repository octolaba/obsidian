# Discrete

Filters the file explorer by frontmatter metadata, hiding or showing matching notes as the filter changes. Comparison operators cover equality, contains, exists, includes, greater-than and less-than, filters combine with AND or OR, and a quick filter can be created from the right-click menu of a file.
