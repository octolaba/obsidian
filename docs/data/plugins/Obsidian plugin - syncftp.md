# SyncFTP

Connects to an SFTP server and pushes or pulls vault file changes, with optional proxy support. Transfers are triggered from toolbar icons or commands, and download-on-open and notification toggles are available. The recorded About text warns that syncing can overwrite remote data and that local files are moved to the trash folder.
