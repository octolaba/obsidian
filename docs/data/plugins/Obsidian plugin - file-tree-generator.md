# File Tree Generator

File Tree Generator writes a file tree into a note using Obsidian callouts. On desktop a local folder is imported through the filesystem. Files and folders are excluded with gitignore-spec patterns.

```cue
plugin: {
    id:     "file-tree-generator"
    name:   "File Tree Generator"
    author: "unarray"
    repo:   "unarray/file-tree-generator"

    html_url:    "https://community.obsidian.md/plugins/file-tree-generator"
    github_url:  "https://github.com/unarray/file-tree-generator"
    description: "Generate a file tree using callouts."
    about:       "Generate file trees inside notes using Obsidian callouts. Import local folders on desktop via the filesystem and exclude files or folders using gitignore-spec patterns."

    stats: {
        downloads:  4347

}
```
