# File Hider

File Hider hides selected files and folders from the file explorer through a right-click action. Hidden items can be revealed with a visibility toggle, unhidden from the context menu, and managed as a list in the plugin settings.

```cue
plugin: {
    id:     "OA-file-hider"
    name:   "File Hider"
    author: "eldritch-oliver"
    repo:   "eldritch-oliver/file-hider"

    html_url:    "https://community.obsidian.md/plugins/OA-file-hider"
    github_url:  "https://github.com/eldritch-oliver/file-hider"
    description: "Hide files and folders from the file explorer."
    about:       "Hide specific files and folders from the file explorer with a right-click. Toggle hidden items' visibility, unhide via the context menu, and manage the hidden list from the plugin settings."
```
