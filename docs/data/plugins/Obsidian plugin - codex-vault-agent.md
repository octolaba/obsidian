# Codex Vault Agent

Codex Vault Agent collects a focused evidence set from a chosen scope of folders, backlinks and outlinks, with candidates reviewed through Dataview or frontmatter. Only the selected evidence is then synthesized by the local Codex CLI into reports, dashboards or audits, and the final notes are created only after approval.
