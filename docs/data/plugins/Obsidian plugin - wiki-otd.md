# On This Day in History

Inserts Wikipedia's On This Day events, births and deaths into the current note as readable Markdown. Entries can be fetched for today or for any other date, with relative links converted to full URLs and page noise stripped out. The links themselves can be placed inline, grouped at the end, or removed.

```cue
plugin: {
    id:     "wiki-otd"
    name:   "On This Day in History"
    author: "arcticleo"
    repo:   "arcticleo/wiki-otd"

    html_url:    "https://community.obsidian.md/plugins/wiki-otd"
    github_url:  "https://github.com/arcticleo/wiki-otd"
    description: "Fetch what happened today in history from Wikipedia. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert Wikipedia's \"On This Day\" Events, Births, and Deaths into your current note as clean, readable Markdown. Fetch entries for today or any date, convert relative links to full URLs, strip page noise, and output links inline, grouped at the end, or removed."

    stats: {
        downloads:  123
        updated_at: 1778888954000
    }
}
```
