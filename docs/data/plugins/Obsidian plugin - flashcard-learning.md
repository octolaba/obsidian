# Flashcard Learning

Creates and manages flashcards in which each prompt carries an expectation description stating what the answer should contain. Cards can be reviewed several times a day, and a long session can be paused and resumed without losing progress. Unknown cards return every session while well-known cards appear less often, and new cards are added after reviews.

```cue
plugin: {
    id:     "flashcard-learning"
    name:   "Flashcard Learning"
    author: "gaetanmuck"
    repo:   "gaetanmuck/obsidian-flashcard-learning"

    html_url:    "https://community.obsidian.md/plugins/flashcard-learning"
    github_url:  "https://github.com/gaetanmuck/obsidian-flashcard-learning"
    description: "Improved flashcard learning system."
    about:       "Create and manage flashcards with clear expectation descriptions so each prompt shows exactly what's expected on the answer. Review cards multiple times per day or pause and resume long sessions without losing progress. Show unknown cards every session and reduce frequency for well-known cards while adding new cards after reviews."

    stats: {
        downloads:  6033
        updated_at: 1723547838000
    }
}
```
