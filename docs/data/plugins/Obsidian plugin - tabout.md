# Tabout

Presses Tab to move the cursor past surrounding markup such as brackets, quotes and Markdown formatting tokens, so typing continues without extra keystrokes. Custom rules per environment define which characters Tab jumps to.

```cue
plugin: {
    id:     "tabout"
    name:   "Tabout"
    author: "phibr0"
    repo:   "phibr0/obsidian-tabout"

    html_url:    "https://community.obsidian.md/plugins/tabout"
    github_url:  "https://github.com/phibr0/obsidian-tabout"
    description: "Easily 'tab out' of links or other Markdown formatting characters."
    about:       "Press Tab to jump the cursor next to surrounding markup (brackets, quotes, markdown tokens) so you can continue typing without extra keystrokes. Add custom rules per environment to define which characters Tab jumps to."
```
