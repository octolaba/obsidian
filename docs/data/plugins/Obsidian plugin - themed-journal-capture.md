# Themed Journal Capture

Themed Journal Capture opens a quick-capture modal from a hotkey anywhere and files what is written as a dated bullet. The entry goes to any note found by fuzzy search, to one of the configured categories, or straight to an inbox note, and multi-line bullets stay indented so list structure is preserved.

```cue
plugin: {
    id:     "themed-journal-capture"
    name:   "Themed Journal Capture"
    author: "sharfaroz"
    repo:   "sharfaroz7/themed-journal-capture"

    html_url:    "https://community.obsidian.md/plugins/themed-journal-capture"
    github_url:  "https://github.com/sharfaroz7/themed-journal-capture"
    description: "Capture a quick journal entry from anywhere, then file it as a dated bullet under a heading in any note (or send it straight to your inbox note). - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open a hotkey-triggered quick-capture modal from anywhere to write and file dated bullet entries. Send entries to any note via fuzzy search, pick from configured categories, or send directly to your inbox, keeping multi-line bullets indented to preserve list structure."

    stats: {
        downloads:  110
        updated_at: 1784402313000
    }
}
```
