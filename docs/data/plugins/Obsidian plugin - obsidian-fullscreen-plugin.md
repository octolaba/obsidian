# Fullscreen mode plugin

Adds a command that puts a single document leaf into a fullscreen focus mode, hiding the other panes. The previous layout returns with Escape, and the mode is triggered from the command palette or from a keyboard shortcut.

```cue
plugin: {
    id:     "obsidian-fullscreen-plugin"
    name:   "Fullscreen mode plugin"
    author: "razumihin"
    repo:   "razumihin/obsidian-fullscreen-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-fullscreen-plugin"
    github_url:  "https://github.com/razumihin/obsidian-fullscreen-plugin"
    description: "Add a command to view a single document leaf in a fullscreen focus mode."
    about:       "Enter fullscreen focus mode for the current pane to hide other panes and concentrate on a single note. Return to the previous layout with Esc or trigger the mode from the command palette or a keyboard shortcut."

    stats: {
        downloads:  44853
        updated_at: 1641645712000
    }
}
```
