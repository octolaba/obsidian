# Codeblock Template

Codeblock Template reuses the content of a code block as a template in other notes, with named variables, anonymous CSV-style variables and array loops for repeated entries. A template is inserted by referencing the code block's name and passing variables for inline substitution, and short inline markers trigger insertion through autocompletion.
