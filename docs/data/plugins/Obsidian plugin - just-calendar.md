# Just Calendar

Displays a compact calendar synced bidirectionally with the Daily Notes core plugin. Months and years can be jumped between, and navigation works entirely from the keyboard or by scrolling with the mouse wheel.

```cue
plugin: {
    id:     "just-calendar"
    name:   "Just Calendar"
    author: "aidistan"
    repo:   "aidistan/obsidian-just-calendar"

    html_url:    "https://community.obsidian.md/plugins/just-calendar"
    github_url:  "https://github.com/aidistan/obsidian-just-calendar"
    description: "Just a calendar which works with the core plugins. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display a compact calendar synced bidirectionally with Obsidian's Daily Notes. Jump quickly between months and years and navigate entirely via keyboard or mouse-wheel scrolling."
```
