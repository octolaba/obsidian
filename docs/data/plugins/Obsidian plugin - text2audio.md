# Text2Audio

Text2Audio converts a selection or a whole note to speech through Microsoft Azure Text-to-Speech and plays the audio inside Obsidian. Playback is started, paused, resumed and stopped from keyboard shortcuts or the plugin window, with Simplified Chinese, Traditional Chinese and English supported.
