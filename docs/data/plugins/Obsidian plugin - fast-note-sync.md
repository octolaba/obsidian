# Fast Note Sync

Fast Note Sync synchronizes vaults in real time across a server, mobile devices and the web, and a vault can be shared with individuals or teams. Version history preserves edits and allows rollback, a recycle bin recovers deleted items, and cloud-based attachment previews show documents, images and other media without downloading them. Server-side it offers vault backups, vault mirroring for high availability and disaster recovery, and automatic sync to Git. REST and MCP integrations connect it to external tools.
