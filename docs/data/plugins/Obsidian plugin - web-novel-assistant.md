# WebNovel Assistant

A writing environment aimed at web novel authors, built around a dashboard that tracks ongoing novels, daily goals and writing progress. Word counting reports added words, focused writing time and custom goals, while world-building tools cover character profiles, timelines and foreshadowing. A timed task tracker runs time-boxed sprints, an OBS overlay serves real-time statistics over a built-in HTTP server for livestreams, and search handles folder-specific queries with memory of earlier ones. The interface is bilingual and follows the English or Chinese language setting.
