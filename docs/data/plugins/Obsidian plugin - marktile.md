# marktile

marktile is a Markdown editor pane in which the markers stay visible: headings grow in size while the hash markers remain in place, so what is shown is the literal file rather than a rendered layer. Smart Enter continues lists, Tab indents against a tab-versus-space ruler, two modes named Seasoned and Plain are available, and a drag-reorderable table of contents is provided. A header button switches back to Obsidian's native editor, or across to the card table when tugtile is installed, on the same file. It is described as CJK-friendly.
