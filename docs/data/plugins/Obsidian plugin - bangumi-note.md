# bangumi

This plugin syncs Bangumi collections and episode progress into local Markdown notes, covering anime, books, music, games and real subjects. Which collection statuses are synced is configurable, the note template is customizable, text outside the generated block is preserved, and frontmatter fields suit Dataview or Bases. Incremental sync, single-subject sync by URL, ID or title search, Daily Notes blocks, weekly On Air notes and a Bangumi-style board for ongoing items are included. Its recorded About states that write-back of episode progress, status, comments and rating happens only with explicit confirmation and never in the background.

```cue
plugin: {
    id:     "bangumi-note"
    name:   "bangumi"
    author: "Kuanphough"
    repo:   "kuanphough/obsidian-bangumi"

    html_url:    "https://community.obsidian.md/plugins/bangumi-note"
    github_url:  "https://github.com/kuanphough/obsidian-bangumi"
    description: "Sync Bangumi collection and episode progress into notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Bangumi syncs your Bangumi collections into local Markdown notes. It supports anime, books, music, games, and real subjects. You can choose which collection statuses to sync, customize the note template, preserve your own notes outside the generated block, and use frontmatter fields with Dataview or Bases. Features include incremental sync, single-subject sync by URL/ID/title search, Daily Notes blocks, weekly On Air notes, optional subject details, and a Bangumi-style board for ongoing items. The board can update episode progress, status, comments, and rating with explicit confirmation. All write-back actions are manual and confirmed by you. The plugin does not modify your Bangumi account in the background."

    stats: {

}
```
