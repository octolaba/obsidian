# Citations

Citations searches a Zotero library and inserts citations into notes, reading the library from BibTeX, BibLaTeX or CSL-JSON exports. Literature notes are created or opened, links or full reference content inserted into a document, and sources cited from the editor.

```cue
plugin: {
    id:     "obsidian-citation-plugin"
    name:   "Citations"
    author: "hans"
    repo:   "hans/obsidian-citation-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-citation-plugin"
    github_url:  "https://github.com/hans/obsidian-citation-plugin"
    description: "Automatically search and insert citations from a Zotero library."
    about:       "Integrate your reference library into Obsidian by reading BibTeX/BibLaTeX (.bib) or CSL-JSON exports and enable in-editor reference search. Create or open literature notes, insert links or full reference content into documents, and cite sources directly from the editor."

    stats: {
        downloads:  231623
        updated_at: 1664033158000
    }
}
```
