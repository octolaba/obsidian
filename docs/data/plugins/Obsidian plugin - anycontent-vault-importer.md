# AnyContent Vault Importer

Takes a pasted Douyin, TikTok, WeChat Official Account or YouTube link, sends the content to a local backend and writes a clean Markdown note into the vault. Depending on the source it produces ASR transcripts, per-image OCR, scraped article bodies or timestamped transcripts, with title and channel metadata in YAML frontmatter for Dataview.
