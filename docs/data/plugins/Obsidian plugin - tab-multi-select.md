# Tab Multi Select

Selects and controls several tabs at once with browser-like inputs such as Shift-click and Ctrl-click. Selected tabs are closed with a middle click or acted on in bulk from a context menu. Selections can be dragged between tab groups or windows, and a hotkey undoes closed-tab selections.
