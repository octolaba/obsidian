# Fast Callout

Fast Callout expands short triggers such as ;ex or @example into Obsidian callout syntax and puts the cursor at the callout title. Nicknames and custom trigger prefixes are configurable, and custom callouts can be added. Slash commands can be bound to hotkeys for quicker insertion.

```cue
plugin: {
    id:     "fast-callout"
    name:   "Fast Callout"
    author: "vkalahas"
    repo:   "vkalahas/fast-callout"

    html_url:    "https://community.obsidian.md/plugins/fast-callout"
    github_url:  "https://github.com/vkalahas/fast-callout"
    description: "Lets you create callouts faster. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create callouts faster by typing short triggers like ;ex or @example to expand into Obsidian callout syntax and place the cursor at the title. Define nicknames and custom trigger prefixes, add custom callouts, and bind slash commands to hotkeys for quick insertion."

}
```
