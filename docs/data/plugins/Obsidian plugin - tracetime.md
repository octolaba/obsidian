# TraceTime

TraceTime records and displays when each block of a note was last edited, covering paragraphs, headings, code blocks, lists and tables, with the labels aligned to the right side of the editor. Timestamps are restored after undo, redo and external file changes, earlier generations can be rolled back to, and edits are tracked incrementally per block to keep rendering fast.
