# Photo Search

Photo Search jumps from a note to a Google Photos or Immich search for that note's date, opening the app or the web search for that day. Dates are parsed from the active note's filename or collected from outgoing links, embeds, frontmatter and daily-note backlinks. A single match opens immediately, while several matches are offered in a fuzzy picker.

    id:     "photo-date-search"
    name:   "Photo Search"
