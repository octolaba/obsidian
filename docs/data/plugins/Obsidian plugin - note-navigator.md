# Note Navigator

Note Navigator moves through notes in folder or vault order, respecting the sort order you have selected, and opens the next logical note automatically when the current one is deleted. It also removes orphaned attachments and empty folders, keeps track of deleted items, and allows scrolling past the end of a note for tail logging.
