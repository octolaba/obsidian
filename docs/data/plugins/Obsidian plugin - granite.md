# Granite

Displays animated shard characters, among them Gemmy and Granite, that deliver periodic sarcastic, scathing or encouraging quotes while you write. Characters are selectable and their lines can be set per character. A writing mode lets Granite interrupt extended pauses with prods, praise or playful mockery.
