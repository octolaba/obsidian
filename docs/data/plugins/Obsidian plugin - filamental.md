# 3D Filamental Graph

3D Filamental Graph displays the vault as a 3D knowledge graph through Filamental. It runs a full physics simulation, colours nodes by type, and stays in live sync with the Filamental desktop app.

```cue
plugin: {
    id:     "filamental"
    name:   "3D Filamental Graph"
    author: "CosimoScott"
    repo:   "scottnine/obsidian-filamental"

    html_url:    "https://community.obsidian.md/plugins/filamental"
    github_url:  "https://github.com/scottnine/obsidian-filamental"
    description: "Your vault in 3D using Filamental. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Explore your vault as a living 3D knowledge graph. Full physics simulation, type-coloured nodes, and live sync with the Filamental desktop app."

    stats: {
        downloads:  186
        updated_at: 1782389766000
    }
}
```
