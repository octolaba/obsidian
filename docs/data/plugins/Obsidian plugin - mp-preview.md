# MP Preview

Converts Obsidian Markdown into WeChat public-account format and copies the resulting HTML to the clipboard. Templates, fonts, sizes and backgrounds are configurable and the preview updates in real time, with a lock that pauses refreshing. Code blocks, tables and images survive the conversion.

```cue
plugin: {
    id:     "mp-preview"
    name:   "MP Preview"
    author: "yeban8090"
    repo:   "yeban8090/mp-preview"

    html_url:    "https://community.obsidian.md/plugins/mp-preview"
    github_url:  "https://github.com/yeban8090/mp-preview"
    description: "Preview and convert Markdown files to MP format"
    about:       "Convert Obsidian Markdown to WeChat public-account format with one click and copy ready HTML to the clipboard. Choose from templates and customize fonts, sizes and backgrounds, preview edits in real time (lock preview to pause refresh) while preserving code blocks, tables and images."
```
