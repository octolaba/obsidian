# Dataview Serializer

Converts Dataview queries into static Markdown and saves the generated output directly into the note. Because the result is stored Markdown, its query results produce real links that appear on the graph and show up on Obsidian Publish.

```cue
plugin: {
    id:     "dataview-serializer"
    name:   "Dataview Serializer"
    author: "Sébastien Dubois"
    repo:   "dsebastien/obsidian-dataview-serializer"

    html_url:    "https://community.obsidian.md/plugins/dataview-serializer"
    github_url:  "https://github.com/dsebastien/obsidian-dataview-serializer"
    description: "Serialize Dataview queries to Markdown, and keep the Markdown representation up to date"
    about:       "Convert Dataview queries into static Markdown and save the generated output directly into your notes. Make query results produce real links that appear on the Graph and show up on Obsidian Publish so generated content is stored and discoverable."

    stats: {
        downloads:  16005
        updated_at: 1785338186000
    }
}
```
