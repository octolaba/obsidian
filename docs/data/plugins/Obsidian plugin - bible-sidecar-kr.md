# Bible Sidecar KR

Bible Sidecar KR opens a Bible panel in the sidebar with Korean book names and four translations, two Korean revisions alongside NIV and KJV. A reference is searched by book, chapter and verse using Korean or English names, jumping to and highlighting the verse, and clicking copies the formatted passage to the clipboard. One Korean translation is loaded from a local JSON file while the other texts come from a public API.
