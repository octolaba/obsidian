# Lyrio - Song Helper

Synchronizes song sections such as chorus, verse and bridge across a note by tagging blocks with a marker, so an edit propagates to every tagged instance. Bare tags are auto-filled from the nearest instance. Inline bar content such as chords or metadata can be attached, a starred tag keeps changes local, and exception tags sync the bars while leaving the lyrics unique.

```cue
plugin: {
    id:     "lyrio"
    name:   "Lyrio - Song Helper"
    author: "whitte-h"
    repo:   "whitte-h/Lyrio"

    html_url:    "https://community.obsidian.md/plugins/lyrio"
    github_url:  "https://github.com/whitte-h/Lyrio"
    description: "Automatically synchronize song sections (Chorus, Verse, Bridge, etc.) across your note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync song sections across notes by tagging blocks like ::Chorus so edits propagate automatically. Auto-fill bare tags from the nearest instance. Attach inline bar content (| Am C F G |) for chords/metadata, use ::Tag* to keep changes local, or mark exception tags to sync bars but keep lyrics unique."

    stats: {
        downloads:  101
        updated_at: 1778698486000
    }
}
```
