# Red Pen

Acts as a proofreader, highlighting phrases in a note that could be simplified. It flags weasel words, hedges, filler, and other weak or verbose constructions so the writing can be tightened.

plugin: {
    id:     "red-pen"
    name:   "Red Pen"
    author: "lucasmelin"
    repo:   "lucasmelin/red-pen"

    html_url:    "https://community.obsidian.md/plugins/red-pen"
    github_url:  "https://github.com/lucasmelin/red-pen"
    description: "Red Pen acts as a proofreader for your writing."
    about:       "Proofread notes and highlight phrases that could be simplified. Identify weasel words, hedges, filler, and other weak or verbose constructions to tighten your writing."
