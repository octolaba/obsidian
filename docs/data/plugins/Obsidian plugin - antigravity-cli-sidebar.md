# Antigravity CLI Sidebar

Runs the Antigravity CLI in an Obsidian sidebar pane, so the CLI can be used without leaving the notes. The pane is a fully interactive xterm.js terminal with typing, scrolling, resizing and customizable command arguments. It is desktop only, relying on Node.js and a PTY.

```cue
plugin: {
    id:     "antigravity-cli-sidebar"
    name:   "Antigravity CLI Sidebar"
    author: "desmond wen"
    repo:   "desmondwen/obsidian-antigravity-cli-sidebar"

    html_url:    "https://community.obsidian.md/plugins/antigravity-cli-sidebar"
    github_url:  "https://github.com/desmondwen/obsidian-antigravity-cli-sidebar"
    description: "Run Antigravity CLI directly in an Obsidian sidebar pane. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed Antigravity CLI into Obsidian's sidebar and chat with Antigravity without leaving your notes. Run a fully interactive xterm.js terminal with typing, scrolling, resizing and customizable command arguments, desktop-only via Node.js/PTY."

    stats: {
        downloads:  1680
        updated_at: 1779891297000
    }
}
```
