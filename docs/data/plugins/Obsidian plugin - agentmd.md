# Agentmd

Agentmd runs, monitors and manages agents defined as markdown agent files against a local agentmd backend. A single sidebar lists them under Agents, Live and History tabs, runs start with one click, executions and tool calls stream live, and the full execution history can be reviewed. It is desktop only.
