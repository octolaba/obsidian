# Google Selection Translate

Shows a Google translation of the selected text in a read-only side panel as soon as the selection is made, without buttons or copy-paste. The original note is left untouched and broken line breaks are merged into coherent paragraphs. Translations can be locked to prevent overwriting, copied with one click, and reused from a cache to save API quota.
