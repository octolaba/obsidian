# Book Metasearch

Creates book notes from a metasearch that queries Aladin, Kakao, Google Books and Open Library in parallel. Notes are built from frontmatter presets with path variables for author, title, ISBN and category, and regeneration preserves manual edits inside protected markers. Cover images fall back through higher-quality sources, and the workflow is oriented toward Korean-language books.
