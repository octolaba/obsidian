# Spatial Task Graph

Tasks and their dependencies are laid out on an interactive infinite canvas with automatic layout and drag-to-create and drag-to-connect gestures. A kanban-style sidebar changes status and sticky notes add context. The canvas stays synchronized with the underlying Markdown files in both directions.

    id:     "spatial-task-graph"
    name:   "Spatial Task Graph"
