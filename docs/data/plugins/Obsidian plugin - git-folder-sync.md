# Git Folder Sync

Synchronizes vault files with a specified directory inside a GitHub repository rather than the whole repository, in both directions and preserving recursive folder structure, for single files or batch operations. Pasted images are uploaded to cloud storage, file sync status and last-modified times are shown with caching that reduces GitHub API calls, and the interface can be switched between English and Chinese.

```cue
plugin: {
    id:     "git-folder-sync"
    name:   "Git Folder Sync"
    author: "Xheldon"
    repo:   "xheldon/git-folder-sync"

    html_url:    "https://community.obsidian.md/plugins/git-folder-sync"
    github_url:  "https://github.com/xheldon/git-folder-sync"
    description: "Synchronize files in your Vault with a specified directory in the designated GitHub repository (rather than the entire repository); send your images to cloud storage services. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync notes bidirectionally with GitHub while preserving recursive folder structures and supporting single-file edits or batch vault operations. Upload pasted images to cloud storage automatically and display real-time file sync status and last-modified times with smart caching to reduce GitHub API calls. Switch interface between English and Chinese."

    stats: {
```
