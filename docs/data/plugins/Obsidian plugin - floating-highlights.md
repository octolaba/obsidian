# Floating Highlights

Animates highlighted text as it enters the viewport in reading mode, so attention stays on the marked content while scrolling. Scale and duration are set independently per tag for highlight, bold and italic. The background behind non-highlights can be dimmed, the float applies to a word or a whole block, and the transitions use transforms only.
