# Better Link Clicker

Better Link Clicker changes what a click on a link does: in Live Preview a plain click edits the link, and navigation moves to Ctrl-click. A link without a target prompts before a new note is created, modifier clicks still open new panes or windows, and wikilinks, Markdown links and plain URLs are all handled.
