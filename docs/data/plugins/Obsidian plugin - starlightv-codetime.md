# Codetime

Tracks writing activity in Obsidian and syncs it to a codetime.dev account, recording file opens, edits, creations and modifications. Today's tracked project time is shown in the status bar, and a filterable activity log is available for diagnostics, with filenames hidden by default. It states that it is not made by or affiliated with codetime.dev.
