# CoNote Git

CoNote Git syncs selected vault subfolders with collaborators through GitHub repositories you control, leaving the rest of the vault private and untracked. Edits are committed automatically after a period of inactivity and pulled and merged frequently, so no manual commits are needed. Conflicts are resolved in a side-by-side merge modal rather than through raw conflict markers, and neither an external server nor a system git installation is required.
