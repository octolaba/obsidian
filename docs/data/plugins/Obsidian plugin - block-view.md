# Block View

Block View lists note content as individual blocks from across the vault inside a Bases view, with filtering, grouping and sorting. The recorded inputs describe resurfacing tagged paragraphs, collecting incomplete tasks or code snippets, and checking off tasks in the view without opening each file.
