# Next TOC

Next TOC shows a floating panel carrying the current document's reading progress, its table of contents and navigation aids. Headings can be jumped to and the reading position tracked from that persistent, movable panel, which is aimed at moving through long notes.

```cue
plugin: {
    id:     "next-toc"
    name:   "Next TOC"
    author: "ravenhogwarts"
    repo:   "raven-pensieve/obsidian-next-toc"

    html_url:    "https://community.obsidian.md/plugins/next-toc"
    github_url:  "https://github.com/raven-pensieve/obsidian-next-toc"
    description: "Floating panel displaying the current document's reading progress, table of contents, and navigation aids."
    about:       "Display a floating panel with the current document's reading progress, table of contents, and navigation aids. Jump to headings, track your reading position, and navigate long notes quickly from a persistent, movable panel."

    stats: {
        downloads:  11268
        updated_at: 1784991200000
    }
}
```
