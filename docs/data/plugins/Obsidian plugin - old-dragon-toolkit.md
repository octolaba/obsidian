# Old Dragon 2 Toolkit

Old Dragon 2 Toolkit builds interactive character sheets, statblocks and an SRD compendium for the Old Dragon 2 tabletop system from od2-ficha and od2-monstro YAML blocks. It calculates attribute modifiers, armour class and attack and save bonuses, rolls attribute and save tests, attacks and damage, and tracks and persists hit points. Attacks and equipment are edited through forms that rewrite the underlying YAML.
