# Steemit

The current note is published to a Steemit account from inside Obsidian. Front-matter metadata supplies the post title, permlink, category and tags, and sections can be kept out of the published document using HTML or %% comments.

```cue
plugin: {
    id:     "obsidian-steemit"
    name:   "Steemit"
    author: "anpigon"
    repo:   "anpigon/obsidian-steemit-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-steemit"
    github_url:  "https://github.com/anpigon/obsidian-steemit-plugin"
    description: "Publish documents to Steemit."
    about:       "Publish the current note directly to your Steemit account from Obsidian. Set front-matter metadata (title, permlink, category, tags) for the post and hide sections from publication using HTML or %% comments."

    stats: {
        downloads:  4017
        updated_at: 1719493527000
    }
}
```
