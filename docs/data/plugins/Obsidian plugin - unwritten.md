# Unwritten

Scans the link graph of the vault and writes a gap report listing unexplained link pairs, stub hubs and decisions recorded without a stated reason. Link patterns, word counts and frontmatter decide what counts as a thin spot. Its own text asks that the report be read as a prompt rather than as a task list.

```cue
plugin: {
    id:     "unwritten"
    name:   "Unwritten"
    author: "saiken"
    repo:   "israerusan/unwritten"

    html_url:    "https://community.obsidian.md/plugins/unwritten"
    github_url:  "https://github.com/israerusan/unwritten"
    description: "Report the notes you never wrote: unexplained link pairs, stub hubs, and decisions with no stated reason. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Report unwritten connections by scanning your vault's link graph and writing a Gap Report.md that lists unexplained link pairs, stub hubs, and decisions lacking stated rationale. Use link patterns, word counts, and frontmatter to flag thin spots; treat the report as a prompt, not a task list."

    stats: {
        downloads:  41
        updated_at: 1785001341000
    }
}
```
