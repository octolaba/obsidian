# Korean Spellchecker

Checks Korean spelling, grammar and spacing in the selected editor text through an online service and returns correction suggestions. Originals and edits are compared in an interactive modal and changes can be applied at once. A custom dictionary excludes registered proper nouns such as names and technical terms, and long documents are handled with automatic pagination.
