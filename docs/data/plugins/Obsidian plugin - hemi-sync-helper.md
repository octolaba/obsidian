# Hemi-Sync Helper

Logs Hemi-Sync and Gateway Experience meditation sessions into the daily note through picker-driven entry, with wave and track pickers. The active note is read and the previous session parsed, so the session number and focus level are filled in already. A consistent, ready-to-edit notes block is inserted, and an embeddable one-tap button can trigger the same entry.
