# Better Markdown Links

Better Markdown Links writes Markdown links in angle brackets so paths containing spaces stay readable and remain compatible with other Markdown editors. Relative links are prefixed to make them explicit, existing links can be converted in one note or across the whole vault, new links are converted as they are created, and links are updated automatically when a file is renamed or moved.

plugin: {
    id:     "better-markdown-links"
    name:   "Better Markdown Links"
    author: "Michael Naumov"
    repo:   "mnaoumov/obsidian-better-markdown-links"

    html_url:    "https://community.obsidian.md/plugins/better-markdown-links"
    github_url:  "https://github.com/mnaoumov/obsidian-better-markdown-links"

    about:       "Generate Markdown angle-bracket links for readable paths with spaces and ensure compatibility with other Markdown editors. Prepend ./ to relative links, convert links in a note or the entire vault, auto-convert new links, and update links automatically on file rename or move."
