# Click Unsupported Twice

Changes how unsupported files behave in the file explorer: a single click only selects the file, and a double click opens it in the default external application. This prevents accidental launches while leaving files the app handles natively - Markdown, PDF, images, audio and video - unchanged. Desktop only.
