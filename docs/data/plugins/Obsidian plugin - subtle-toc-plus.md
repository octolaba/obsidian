# Subtle TOC Plus

Shows a subtle floating table of contents and a heading minimap at the edge of a note, plus a popover listing headings and open tasks for scanning and jumping. Headings can be searched, folded by branch and labeled with H1 to H6 badges, and unfinished tasks are managed from the same panel. Panel size and opacity are configurable, the popover can be pinned or set to auto-hide on blur, and the interface switches between English and Chinese.
