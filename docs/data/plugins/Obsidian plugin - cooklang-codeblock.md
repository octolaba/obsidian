# Cooklang Codeblock

Cooklang Codeblock renders recipes written in Cooklang inside a note as a recipe block showing ingredients, cookware and the method. Meta information such as cook time and serving size can optionally be shown at the top of the block.

```cue
plugin: {
    id:     "cooklang-codeblock"
    name:   "Cooklang Codeblock"
    author: "Raunaq Gupta"
    repo:   "raunaqgupta/obsidian-cooklang-codeblock-plugin"

    html_url:    "https://community.obsidian.md/plugins/cooklang-codeblock"
    github_url:  "https://github.com/raunaqgupta/obsidian-cooklang-codeblock-plugin"
    description: "Add recipes written in cooklang to your notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed Cooklang recipes as rendered recipe blocks that display ingredients, cookware, and method in your notes. Optionally display meta information such as cook time and serving size at the top of the block."

    stats: {
        downloads:  138
        updated_at: 1779298751000
    }
}
```
