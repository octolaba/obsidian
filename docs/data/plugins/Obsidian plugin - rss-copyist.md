# Rss Copyist

Rss Copyist collects updated RSS articles into per-feed folders and saves each entry as a Markdown note built from a shared template.md file. A note is tagged to mark it as a feed, and fetching pulls the newest items from all feeds into those folders as formatted articles.

```cue
plugin: {
    id:     "rss-copyist"
    name:   "Rss Copyist"
    author: "aoout"
    repo:   "aoout/obsidian-rss-copyist"

    html_url:    "https://community.obsidian.md/plugins/rss-copyist"
    github_url:  "https://github.com/aoout/obsidian-rss-copyist"
    description: "Get RSS articles as notes."
    about:       "Collect updated RSS articles into per-feed folders and save each entry as a templated Markdown note using a shared template.md. Tag a note as a feed and fetch the newest items from all feeds to populate folders with formatted articles."

    stats: {
        downloads:  2995
        updated_at: 1708700997000
    }
}
```
