# SteamGridDB Embedder

SteamGridDB is searched for game images based on the note title, and the correct game and the specific grid artwork are chosen interactively before the image is embedded. Embedding can also be triggered from a Templater template. The recorded inputs state that a SteamGridDB API key is required.

```cue
plugin: {
    id:     "steamgriddb-embedder"
    name:   "SteamGridDB Embedder"
    author: "abduznik"
    repo:   "abduznik/obsidian-steamgriddb"

    html_url:    "https://community.obsidian.md/plugins/steamgriddb-embedder"
    github_url:  "https://github.com/abduznik/obsidian-steamgriddb"
    description: "Embeds images from SteamGridDB based on the note title. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Search SteamGridDB for game images, interactively choose the correct game and specific grid art, and embed the selected image into your note. Trigger embedding automatically from Templater templates (SteamGridDB API key required)."

    stats: {
        downloads:  315
        updated_at: 1778939693000
    }
}
```
