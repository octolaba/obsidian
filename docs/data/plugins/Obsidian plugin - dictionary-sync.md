# Dictionary Sync

Keeps the custom spell-check dictionary in a note inside the vault, so the same words travel across devices through Obsidian Sync. The dictionary is read and written through Obsidian's own APIs, so changes apply immediately without external scripts or quitting the app.

plugin: {
    id:     "dictionary-sync"
    name:   "Dictionary Sync"
    author: "kquinsland"
    repo:   "kquinsland/obsidian-plugin-dictionary-sync"

    html_url:    "https://community.obsidian.md/plugins/dictionary-sync"
    github_url:  "https://github.com/kquinsland/obsidian-plugin-dictionary-sync"
