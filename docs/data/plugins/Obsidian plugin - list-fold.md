# List Fold

Toggles folding for list items only, so outlines can be collapsed while headings stay expanded. Commands fold and unfold top-level lists or all nested levels and detect the current fold state themselves, and the recorded inputs state that they work alongside Outliner and require Obsidian on desktop with CodeMirror 6.

```cue
plugin: {
    id:     "list-fold"
    name:   "List Fold"
    author: "Amin Ica"
    repo:   "rezgi/obsidian-list-fold"

    html_url:    "https://community.obsidian.md/plugins/list-fold"
    github_url:  "https://github.com/rezgi/obsidian-list-fold"
    description: "Toggle fold/unfold on list items only, without affecting headings. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Toggle folding for list items only, leaving headings expanded so you can collapse outlines without hiding section headers.
```
