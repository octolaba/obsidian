# Latex Matrices

Latex Matrices assembles a LaTeX matrix and inserts the resulting string ready for embedding between double-dollar delimiters. The bracket type is selectable, and cells accept built-in fraction formatting as well as subscript and superscript entry.

```cue
plugin: {
    id:     "latex-matrices"
    name:   "Latex Matrices"
    author: "deltekk"
    repo:   "deltekk/Obsidian-Latex-Matrices"

    html_url:    "https://community.obsidian.md/plugins/latex-matrices"
    github_url:  "https://github.com/deltekk/Obsidian-Latex-Matrices"
    description: "Speed up LaTeX matrices writing."
    about:       "Create LaTeX matrices and insert a ready-to-use LaTeX string for embedding in your note between $$ delimiters. Choose bracket type, use built-in fraction formatting, and enter fractions ({n}/{m}), subscripts (n_{m}) or superscripts (n^{m}) in cells."

    stats: {
        downloads:  4784
        updated_at: 1679514820000
    }
}
```
