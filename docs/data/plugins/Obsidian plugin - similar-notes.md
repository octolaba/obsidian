# Similar Notes

Similar Notes finds semantically similar notes with AI and lists related notes at the bottom of the current file as you write, and the vault can also be searched by meaning. Embeddings run on local on-device models for full privacy or through OpenAI or Ollama cloud models for larger or cross-device use. The built-in models work on mobile and desktop without an API key.
