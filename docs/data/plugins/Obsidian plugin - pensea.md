# Pensea

Pensea applies the PARA method through a sidebar kanban and calendar that surface today's priorities, the Inbox count and review progress. Idea cards are created from selected text and advanced through lifecycle stages with SM-2 spaced-repetition scheduling. Optional AI handles Inbox summarization, auto-naming and vault question answering, while the recorded inputs state that core features run offline.
