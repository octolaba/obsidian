# Folder Info

Shows separate file and folder counts beside every folder in the native File Explorer, counting either all descendants or only direct children. Counts update live and cover every file type Obsidian exposes, while the rest of the Explorer's behaviour is preserved. It works offline with no network access, telemetry or writes to the vault.

```cue
plugin: {
    id:     "folder-info"
    name:   "Folder Info"
    author: "Stagars"
    repo:   "stagars-m/folder-info"

    html_url:    "https://community.obsidian.md/plugins/folder-info"
    github_url:  "https://github.com/stagars-m/folder-info"
    description: "Shows separate file and folder counts beside folders in the native File Explorer. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Show separate file and folder counts beside every folder in the native File Explorer, with a choice of recursive (all descendants) or direct-child counting. Update counts live for every Obsidian-exposed file type and preserve Explorer behavior while running offline with no network, telemetry, or vault writes."

    stats: {
        downloads:  71
        updated_at: 1785942421000
    }
}
```
