# Wayfinder

Shows a Pathfinder 1st Edition character sheet in the right sidebar, laid out for one-handed iPad use. Character data is stored in the plugin while rule text is linked from the vault, and the sheet calculates armour class, saves, attacks, skill totals and spell DCs. Prerequisites are not enforced: some defaults are seeded, but legality is left to the player.
