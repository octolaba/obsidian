# Related Notes Finder

This plugin finds notes whose titles contain words from the active note, filtering out short terms and user-defined stopwords and optionally ignoring a dailies folder. Links to the matched notes can be appended into the active note, and that appending can be toggled off.

```cue
plugin: {
    id:     "obsidian-related-notes-finder"
    name:   "Related Notes Finder"
    author: "lifegems"
    repo:   "lifegems/obsidian-related-notes-finder"

    html_url:    "https://community.obsidian.md/plugins/obsidian-related-notes-finder"
    github_url:  "https://github.com/lifegems/obsidian-related-notes-finder"
    description: "Add extra features for finding related notes."
    about:       "Find notes whose titles contain words from the active note, filtering short terms and user-defined stopwords and optionally ignoring a dailies folder. Append links to matched notes into the active note and toggle whether links are added."

    stats: {
        downloads:  7897

    }
}
```
