# LanguageTool

This unofficial integration runs the LanguageTool spell, grammar and style checker over notes and shows in-line suggestions with corrections, synonyms and mother-tongue support. Automatic checking can be toggled, individual rules disabled from the suggestion tooltip, and language options set per note. Pointing it at a self-hosted LanguageTool instance keeps the checks local.

```cue
plugin: {
    id:     "languagetool"
    name:   "LanguageTool"
    author: "wrenger"
    repo:   "wrenger/obsidian-languagetool"

    html_url:    "https://community.obsidian.md/plugins/languagetool"
    github_url:  "https://github.com/wrenger/obsidian-languagetool"
    description: "Unofficial integration of the LanguageTool spell and grammar checker."
    about:       "Check grammar, spelling, and style in Obsidian using LanguageTool and get in-line suggestions with corrections, synonyms, and mother-tongue support. Toggle automatic checking, disable specific rules via tooltips, and set note-specific language options. Self-host LanguageTool to keep checks local."

    stats: {
        downloads:  43747

    }
}
```
