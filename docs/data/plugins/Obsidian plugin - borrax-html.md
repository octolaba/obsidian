# Borrax HTML

Borrax HTML opens .html and .htm files stored in the vault with their CSS, scripts and relative links working, rendered inside a sandboxed frame. Desktop uses an isolated webview and mobile an iframe with base injection so relative assets resolve. Vault links open in Obsidian and external links in the system browser, with adjustable zoom and folder badges.

```cue
plugin: {
    id:     "borrax-html"
    name:   "Borrax HTML"
    author: "dogukansahil"
    repo:   "dogukansahil/Borrax-HTML"

    html_url:    "https://community.obsidian.md/plugins/borrax-html"
    github_url:  "https://github.com/dogukansahil/Borrax-HTML"
    description: "View HTML files inside your vault with working links, CSS and scripts. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "View .html and .htm files from your vault with working CSS, scripts and relative links rendered in a sandboxed frame. Open files in an isolated desktop webview or a mobile iframe with base injection so relative assets resolve; vault links open in Obsidian, external links in your browser, with adjustable zoom and folder H-badges."

    stats: {

    }
}
```
