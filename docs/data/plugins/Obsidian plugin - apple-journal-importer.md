# Apple Journal Importer

Imports Apple Journal exports into the vault as Markdown notes carrying YAML frontmatter, embedded media and the full entry text. HTML entries and their Resources are converted into date-named files plus a media folder, preserving titles, timestamps and tags. Several entries on the same day are handled.

```cue
plugin: {
    id:     "apple-journal-importer"
    name:   "Apple Journal Importer"
    author: "tarikbc"
    repo:   "tarikbc/apple-journal-importer"

    html_url:    "https://community.obsidian.md/plugins/apple-journal-importer"
    github_url:  "https://github.com/tarikbc/apple-journal-importer"
    description: "Import Apple Journal exports into your vault as Markdown notes, with media conversion. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Import Apple Journal exports into organized Markdown notes with YAML frontmatter, embedded media, and the full entry text. Convert HTML entries and Resources into date‑named files and a media folder, preserving titles, timestamps, tags and multiple entries per day."

    stats: {
        downloads:  58
        updated_at: 1785869707000
    }
}
```
