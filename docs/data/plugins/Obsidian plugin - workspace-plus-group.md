# WorkSpace Plus Group

Organizes workspaces as parent-child trees with drag-and-drop reordering, shown with indentation and collapsible groups. A fuzzy-search switcher reachable from the command palette, the status bar or a shortcut changes workspace and creates a new one by typing a name. Per-workspace modes bind a theme, font and global settings that apply on switch, and the status bar shows and saves the current workspace and mode.
