# Student Repo

Photographs of exams, notes or artworks are converted into editable Markdown and organized automatically by the order in which they were captured. Key problems and drawings are analyzed with AI to produce summaries and further practice questions. English study tools cover text-to-speech, translation, vocabulary tracking and grammar analysis, while the recorded description states more briefly that the plugin manages student repositories.
