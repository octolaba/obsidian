# Dev Loader Updater

Installs and updates private development plugins from endpoints that the user defines. A fallback endpoint is used when the primary source is unavailable, and update checks and installs run through the same chain of sources.

```cue
plugin: {
    id:     "dev-loader-updater"
    name:   "Dev Loader Updater"
    author: "???"
    repo:   "anonymisedfellow/dev-loader-updater"

    html_url:    "https://community.obsidian.md/plugins/dev-loader-updater"
    github_url:  "https://github.com/anonymisedfellow/dev-loader-updater"
    description: "Install and update private development plugins from user-defined endpoints with fallback transport support. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Install and update private Obsidian plugins from user-defined remote sources. Use endpoint fallback when a primary source is unavailable and check/apply updates through the same source chain."

    stats: {
        downloads:  100
        updated_at: 1780239354000
    }
}
```
