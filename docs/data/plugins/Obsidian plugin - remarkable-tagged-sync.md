# Tagged Sync for reMarkable

Imports tagged reMarkable notebooks into the vault as searchable Markdown notes, routing each notebook to a folder chosen by its tag, in a one-way desktop-only sync; the free version maps a single tag to a single folder. Handwriting arrives as an embedded PDF render. On macOS the pages are also transcribed to searchable text locally with no network access, while Windows and Linux imports include the renders but no transcripts.
