# Embed Code File

Embeds a code file into a note through a code block, reading it either from the vault or from a remote URL such as a GitHub raw address. A specific line range can be selected and a custom title added, and the block renders in live preview.

```cue
plugin: {
    id:     "embed-code-file"
    name:   "Embed Code File"
    author: "almariah"
    repo:   "almariah/embed-code-file"

    html_url:    "https://community.obsidian.md/plugins/embed-code-file"
    github_url:  "https://github.com/almariah/embed-code-file"
    description: "Embed code file from vault using code blocks."
    about:       "Embed code files from your vault or from remote URLs (for example GitHub raw) directly into Markdown code blocks. Include specific line ranges, add custom titles, and render cleanly in Obsidian's live preview for readable inline code snippets."

    stats: {
        downloads:  8802
        updated_at: 1662749453000
    }
}
```
