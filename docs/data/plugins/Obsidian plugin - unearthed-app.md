# Unearthed (Kindle and KOReader Sync)

Syncs Kindle and KOReader highlights, notes and tags into the vault through Unearthed, using custom templates to control how book files are written. Highlights from several sources are merged and only new quotes are appended to an existing file. Daily reflections can also be imported.

    id:     "unearthed-app"
    name:   "Unearthed (Kindle and KOReader Sync)"
    author: "unearthed-app"

    html_url:    "https://community.obsidian.md/plugins/unearthed-app"
