# Azure Wiki Preview

Previews Azure DevOps Wiki Markdown inside Obsidian as it will appear once published, rendering Azure's dialect without altering the source files. Azure-style mermaid blocks are drawn as diagrams, table-of-contents macros are displayed as labeled chips, and Azure's heading, encoded page name and other quirks are matched so the local view lines up with the published output.

```cue
plugin: {
    id:     "azure-wiki-preview"
    name:   "Azure Wiki Preview"
    author: "Harshit Singhal"
    repo:   "harshitsnghl/obsidian-azure-wiki-preview"

    html_url:    "https://community.obsidian.md/plugins/azure-wiki-preview"
    github_url:  "https://github.com/harshitsnghl/obsidian-azure-wiki-preview"
    description: "Preview Azure DevOps Wiki pages as they will publish: :::mermaid diagrams, table of contents macros, and decoded page names. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Preview Azure DevOps Wiki markdown inside Obsidian exactly as it will publish by rendering Azure's markdown dialect without altering source files. Render :::mermaid blocks, display [[_TOC_]]/[[_TOSP_]] as labeled chips, and match Azure heading, encoded filename, and other quirks so local view equals published output."

    stats: {
        downloads:  24
        updated_at: 1785602033000
    }
}
```
