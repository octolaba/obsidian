# Modal Keys Remapper

Modal Keys Remapper customizes the keyboard shortcuts used to navigate modal dialogs and suggestion lists, including move up, move down, confirm and close. Target CSS classes scope where a shortcut applies, and up to ten shortcuts can be assigned per action.

```cue
plugin: {
    id:     "modal-keys-remapper"
    name:   "Modal Keys Remapper"
    author: "naoki-mizuno"
    repo:   "naoki-mizuno/obsidian-modal-keys"

    html_url:    "https://community.obsidian.md/plugins/modal-keys-remapper"
    github_url:  "https://github.com/naoki-mizuno/obsidian-modal-keys"
    description: "Customize keyboard shortcuts for navigating modal dialogs and suggestion lists. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Remap keyboard shortcuts for navigating modal dialogs and suggestion lists, including move up/down and confirm/close actions. Define target CSS classes to scope shortcuts and assign multiple shortcuts per action (up to 10) for flexible modal navigation."

    stats: {
        downloads:  119
        updated_at: 1782687023000
    }
}
```
