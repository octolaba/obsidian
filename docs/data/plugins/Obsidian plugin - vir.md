# Vir

Vir surfaces notes distilled from LLM sessions in Obsidian's sidebar, with Recent and Related tabs showing what is relevant to the file being edited. A dot in the status bar reports daemon health as healthy, stale or down.

```cue
plugin: {
    id:     "vir"
    name:   "Vir"
    author: "Djordje Marković"
    repo:   "djolex999/vir-obsidian"

    html_url:    "https://community.obsidian.md/plugins/vir"
    github_url:  "https://github.com/djolex999/vir-obsidian"
    description: "An LLM Wiki for Claude Code, in your Obsidian sidebar. Surface relevant notes from your distilled session knowledge as you work. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Surface vir-distilled LLM wiki notes in Obsidian's sidebar, offering Recent and Related tabs that show notes relevant to the file you're editing. Display a live daemon-health dot in the status bar to indicate healthy, stale, or down states."

    stats: {
        downloads:  129
        updated_at: 1785502031000
    }
}
```
