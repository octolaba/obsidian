# Advanced Random Note

Advanced Random Note opens random notes and files matched by custom queries written in its built-in query language, in Dataview syntax or as regular expressions. Results appear in a selection modal or run as commands, folders can be excluded from searches, and matches can be opened in new tabs.

    id:     "advanced-random-note"
    name:   "Advanced Random Note"
    author: "karstenpedersen"
    repo:   "karstenpedersen/obsidian-advanced-random-note"

    html_url:    "https://community.obsidian.md/plugins/advanced-random-note"
