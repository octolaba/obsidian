# Recipe Box

Turns Markdown recipe notes into an interactive cookbook: opening a recipe shows a card with scaled ingredients, inline cooking timers, nutrition, and customizable metadata badges. A drag-and-drop meal planner covers recipes, custom meals, and leftovers and generates a grocery list, recipes can be imported from websites with one command using a template, and cook history records dates, notes, and photos. Meal suggestions are drawn from favorites, go-to recipes, neglected dishes, or custom selection modes. Everything stays as plain Markdown in the vault, searchable with Dataview or Bases and readable without the plugin.
