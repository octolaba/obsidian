# TagMany

TagMany adds the same tags to every note in a folder at once. Right-clicking a folder offers to tag all notes in it, then takes comma-separated tags and optionally recurses into subfolders. The recorded text states that tagging the root directory and canvases is not supported yet.

```cue
plugin: {
    id:     "tag-many"
    name:   "TagMany"
    author: "joshua-martius"
    repo:   "joshua-martius/tagmany"

    html_url:    "https://community.obsidian.md/plugins/tag-many"
    github_url:  "https://github.com/joshua-martius/tagmany"
    description: "Add the same tag(s) to multiple notes in a folder (optionally including subfolders) at once."
    about:       "Add the same tag(s) to multiple notes in a folder at once. Right-click a folder, choose \"Tag all Notes in this Folder\", enter comma-separated tags and optionally include subfolders to apply tags recursively. Note that tagging the root directory and canvases is not supported yet."
```
