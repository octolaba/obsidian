# Azer

Azer organizes D&D campaigns as typed Markdown notes: NPC, Session, Adventure Log, Location and PC files are created with azer-type frontmatter and content scaffolds, scoped to a campaign folder. Random tables are rolled and rendered as die-face lookup tables with nested wikilinks. A device-local Anthropic API key lets the plugin generate tables or recap recent adventure logs into grounded summaries.
