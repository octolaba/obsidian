# Gentle Pomodoro

Provides a task-aware Pomodoro timer whose display is a day-to-night gradient instead of a ticking clock. Focus sessions are linked to items from the Tasks plugin with a counter per task and a daily focus goal in the status bar, and every session is logged for Dataview with start, end, pauses, total and break type.

```cue
plugin: {
    id:     "gentle-pomo"
    name:   "Gentle Pomodoro"
    author: "jamiestudio-lab"
    repo:   "jamiestudio-lab/obsidian-gentlepomodoro"

    html_url:    "https://community.obsidian.md/plugins/gentle-pomo"
    github_url:  "https://github.com/jamiestudio-lab/obsidian-gentlepomodoro"
    description: "A visually soothing, task-integrated Pomodoro timer. Focus on your work with gentle animations and Pomodoro logging. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "A gentle, task-aware Pomodoro timer for Obsidian. A soft day→night gradient replaces the ticking clock so you stay in flow. Link focus sessions to your Tasks-plugin items, watch a counter tick up on each task, chase a daily focus goal in the status bar, and end the day with a Dataview-ready log of every session — start, end, pauses, total, and break type."

    stats: {
```
