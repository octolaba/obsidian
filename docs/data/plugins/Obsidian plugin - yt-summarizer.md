# YTSummarizer

Fetches the transcript of a YouTube video and summarizes it with OpenAI GPT models. The transcript is shown in a sidebar or written into a new note with interactive timestamps that jump to a given point in the video. Transcript languages, timestamp frequency and the model used for the summary are configurable.

```cue
plugin: {
    id:     "yt-summarizer"
    name:   "YTSummarizer"
    author: "ardakalayci"
    repo:   "ardakalayci/ytsummarizer"

    html_url:    "https://community.obsidian.md/plugins/yt-summarizer"
    github_url:  "https://github.com/ardakalayci/ytsummarizer"
    description: "Fetch YouTube video transcripts and generate summaries using OpenAI models."
    about:       "Fetch YouTube transcripts and generate concise summaries using OpenAI GPT models. View transcripts in a sidebar or create new notes with interactive timestamps that jump to specific video points. Support multiple languages, configurable timestamp frequency, and choose the OpenAI model for summaries."

    stats: {
        downloads:  1224
        updated_at: 1742302225000
    }
}
```
