# Reader Mode

Ensures notes open in reader mode, giving a Wikipedia-style view of footnotes, embeds, images, and code snippets. Empty notes open in edit mode instead, so writing can start immediately. It also prevents links from becoming unclickable when notes open.

```cue
plugin: {
    id:     "reader-mode"
    name:   "Reader Mode"
    author: "dominikmayer"
    repo:   "dominikmayer/obsidian-reader-mode"

    html_url:    "https://community.obsidian.md/plugins/reader-mode"
    github_url:  "https://github.com/dominikmayer/obsidian-reader-mode"
    description: "Ensures notes are always opened in reader mode."
    about:       "Open filled notes in reader mode by default for a comfortable, Wikipedia-style view of footnotes, embeds, images, and code snippets. Open empty notes in edit mode to start writing immediately. Prevent links from becoming unclickable when notes open."

    stats: {
        downloads:  1131
        updated_at: 1738508057000
    }
}
```
