# Dangling links

Dangling links adds a sidebar listing the dangling links in a vault, the orphaned links that point at nothing, and shows where each missing target is referenced. Entries are grouped by file or folder, occurrences opened one at a time, items collapsed, and folders ignored to narrow the list.

```cue
plugin: {
    id:     "obsidian-dangling-links"
    name:   "Dangling links"
    author: "graydon"
    repo:   "graydon/obsidian-dangling-links"

    html_url:    "https://community.obsidian.md/plugins/obsidian-dangling-links"
    github_url:  "https://github.com/graydon/obsidian-dangling-links"
    description: "Add a sidebar showing any dangling links in a vault. Dangling links are orphaned links that don't point to anything in the vault."
    about:       "Display all dangling links in your vault in a side panel, showing where each missing target is referenced. Group by file or folder, view occurrences and jump to each reference, collapse items, and ignore folders to narrow the list."

    stats: {
        downloads:  18749
        updated_at: 1621364776000
    }
}
```
