# Custom Classes

Adds custom HTML classes to chosen Markdown blocks and inline elements from within the note itself. A class declaration written on the line before a block, or inside an element, renders that class on lists, tables, table cells, list items and other blocks.

```cue
plugin: {
    id:     "custom-classes"
    name:   "Custom Classes"
    author: "lilarest"
    repo:   "lilarest/obsidian-custom-classes"

    html_url:    "https://community.obsidian.md/plugins/custom-classes"
    github_url:  "https://github.com/lilarest/obsidian-custom-classes"
    description: "Add your own HTML classes to chosen Markdown elements directly from your notes."
    about:       "Add custom HTML classes to selected Markdown blocks and inline elements directly from your notes. Insert class: <customClass> on the line before a block or inside an element to render that class on lists, tables, table cells, list items and other blocks."

    stats: {

    }
}
```
