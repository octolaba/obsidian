# Vaultkeeper AI

Vaultkeeper AI connects Claude, Gemini, OpenAI and Mistral to the vault so notes can be read, searched, created and edited, alongside PDFs, Office documents and images. Read-only and agent modes are separate, multi-step workflows can be planned, and diffs are previewed before changes apply. Conversations and privacy settings are managed in the plugin, web search is optional, responses stream, and API keys are stored locally.
