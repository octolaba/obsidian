# SQLite DB

SQL code blocks in a note query a SQLite database and render the results in the document as a natural list or a custom format. Query output is also drawn as pie, line or bar charts, table schemas are inspected, and table rows are exported as new notes. The data source is a local database file or a remote API endpoint.
