# Caretsort

Caretsort adds a caret to each table header; clicking it sorts the column A to Z or Z to A and writes the new row order back to the Markdown file. Numbers sort numerically, alphabetical sorting uses the displayed text of wiki links, and the last sort can be undone. It works in reading view and in live preview.

```cue
plugin: {
    id:     "caretsort"
    name:   "Caretsort"
    author: "simratt"
    repo:   "simratt/obsidian-caretsort"

    html_url:    "https://community.obsidian.md/plugins/caretsort"
    github_url:  "https://github.com/simratt/obsidian-caretsort"
    description: "Minimalist table sort. Click the caret in any column header to sort rows A→Z, Z→A, or numerically. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add a ▾ caret to table headers and click to sort columns A→Z or Z→A. Write the new order back to the Markdown file, sorting numbers numerically and using displayed wiki-link text for alphabetical sorts. Work in reading view and live preview and provide an undo for the last sort."

}
```
