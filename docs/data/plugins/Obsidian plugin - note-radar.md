# Note Radar

Tracks view statistics for the notes in a vault, recording which files are revisited and which are never opened. A dashboard presents the data with summary cards, Hot, Warm, Mild and Never-viewed badges, search and sorting by view count and dates, pagination, and direct opening of a note, and the collected data can be exported or reset.
