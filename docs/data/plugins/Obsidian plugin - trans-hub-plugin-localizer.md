# Trans-Hub Localizer

Trans-Hub Localizer translates the names, descriptions, settings, commands and interface text of Obsidian community plugins into a chosen language at runtime through Trans-Hub. Plugin files and notes are left untouched, and matching is version-aware and exact, excluding editors, reading views, code, scripts and other editable content.

```cue
plugin: {
    id:     "trans-hub-plugin-localizer"
    name:   "Trans-Hub Localizer"
    author: "Saken"
    repo:   "sakenw/trans-hub-obsidian-localizer"

    html_url:    "https://community.obsidian.md/plugins/trans-hub-plugin-localizer"
    github_url:  "https://github.com/sakenw/trans-hub-obsidian-localizer"
    description: "Automatically translate and localize Obsidian community plugin names, descriptions, and interfaces into your preferred language with Trans-Hub. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Localize Obsidian community plugins into your chosen language by applying verified translations to plugin names, descriptions, settings, commands, and interface text at runtime. Keep plugin files and notes untouched while using version-aware, exact matches that exclude editors, reading views, code, scripts, and editable content."

    }
}
```
