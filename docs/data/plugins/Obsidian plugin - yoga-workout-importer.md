# Yoga Workout Importer

Converts copied yoga workout text into a structured Markdown note and inserts matching images already held in the vault. Processing stays local: missing images are prompted for, selected files are copied into the vault, and external files are never uploaded or altered.

```cue
plugin: {
    id:     "yoga-workout-importer"
    name:   "Yoga Workout Importer"
    author: "Konstantin Valuiskii"
    repo:   "sveekey/yoga-workout-importer"

    html_url:    "https://community.obsidian.md/plugins/yoga-workout-importer"
    github_url:  "https://github.com/sveekey/yoga-workout-importer"
```
