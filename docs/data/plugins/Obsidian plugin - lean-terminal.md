# Lean Terminal

Lean Terminal embeds a PTY terminal panel built on xterm.js and node-pty inside the vault, so that interactive shell sessions run without an external window. Several tabs can be reordered by dragging, renamed and colour-coded, shells are detected automatically, URLs are clickable, a dragged file inserts its path, and clipboard support and colour schemes are configurable. It is desktop-only and requires Obsidian 1.5 or later.
