# Simple Prompt

Simple Prompt generates or rewrites note content with large language models from a small interface, inserting at the cursor or rewriting a selection or the whole document. It works with OpenAI or Ollama models, can generate from YouTube captions, and streams responses so output appears as it arrives. Prompt templates can be customized and reused.
