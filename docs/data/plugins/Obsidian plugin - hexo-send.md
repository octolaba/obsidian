# Hexo Send

Prepares notes, folders or several files at once for a local Hexo repository, organizing images into a per-post images folder and validating that Hexo, Node and Git are present. Categories, tags, keywords, descriptions and image metadata can be reviewed and edited beforehand, with optional AI suggestions. A single local commit is created, and nothing is pushed until it is explicitly confirmed.

```cue
plugin: {
    id:     "hexo-send"
    name:   "Hexo Send"
    author: "BeckChan"
    repo:   "fountainchan/obsidian-hexo-send"

    html_url:    "https://community.obsidian.md/plugins/hexo-send"
    github_url:  "https://github.com/fountainchan/obsidian-hexo-send"
    description: "Prepare Obsidian notes for Hexo, create a local commit, and push only after confirmation. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Publish selected notes, folders, or multiple files to a local Hexo repository, organize images into /images/<abbrlink>/, validate Hexo/Node/Git and create a single local commit without auto-pushing. Review and edit categories, tags, keywords, descriptions and image metadata with optional AI suggestions, then push only when you explicitly confirm."

    stats: {

}
```
