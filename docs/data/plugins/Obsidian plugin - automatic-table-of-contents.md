# Automatic Table Of Contents

Automatic Table Of Contents inserts a table of contents that updates itself whenever a note's headings change. It is added through a table-of-contents codeblock or a command, its entries are clickable, and the layout can be nested or inline with configurable depth and filters.

```cue
plugin: {
    id:     "automatic-table-of-contents"
    name:   "Automatic Table Of Contents"
    author: "johansatge"
    repo:   "johansatge/obsidian-automatic-table-of-contents"

    html_url:    "https://community.obsidian.md/plugins/automatic-table-of-contents"
```
