# Advanced Note Mover

Advanced Note Mover moves a single file, or every note in a vault, into a predefined target folder chosen from tags, frontmatter properties, filenames, content, paths and dates. Moves can run automatically when a file is edited or at a set interval, and blacklist and whitelist filters decide which notes match.

```cue
plugin: {
    id:     "note-mover-shortcut"
    name:   "Advanced Note Mover"
    author: "Lars Bücker"
    repo:   "bueckerlars/obsidian-note-mover-shortcut"

    html_url:    "https://community.obsidian.md/plugins/note-mover-shortcut"
    github_url:  "https://github.com/bueckerlars/obsidian-note-mover-shortcut"
    description: "Quickly and easily move notes to a predefined folder. Perfect for organizing your notes."
    about:       "Move single files or batch-move entire vaults into target folders based on tags, frontmatter properties, filenames, content, paths, and dates. Run moves automatically on file edit or at set intervals, and apply blacklist/whitelist filters to include or exclude matches."

    stats: {
        downloads:  8952
        updated_at: 1784800331000
    }
}
```
