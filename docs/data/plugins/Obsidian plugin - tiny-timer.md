# Tiny Timer

Tiny Timer spawns compact, draggable floating timers anchored in the workspace and driven by keyboard-first decimal input. The clock face follows the theme, showing twelve ticks under twelve minutes and sixty ticks for longer durations, and a short procedural ascending alarm plays when a timer ends. Further timers are created from the status bar icon.
