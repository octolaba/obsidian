# VitePress Theme

VitePress Theme styles Obsidian after VitePress documentation sites, matching its typography, links, tables, emoji and relative path and line reference behavior. It renders VitePress features such as alert containers, collapsible details and badge components, and enhances code blocks with filename labels and grouped code tabs. Native callouts are restyled to VitePress colors.

```cue
plugin: {
    id:     "vitepress-theme"
    name:   "VitePress Theme"
    author: "weizwz"
    repo:   "weizwz/obsidian-vitepress"

    html_url:    "https://community.obsidian.md/plugins/vitepress-theme"
    github_url:  "https://github.com/weizwz/obsidian-vitepress"
    description: "VitePress-style theme with custom containers, enhanced code blocks, and modern typography. - This plugin has not been manually reviewed by Obsidian staff."

Render VitePress features like alert containers, collapsible details, badge components, enhanced code blocks with filename labels, grouped code tabs, and style native callouts to VitePress colors."
