# Enhanced Tab Settings

Changes how files open and how tabs behave: files open in a new tab by default, an already open tab is switched to instead of duplicated, new-tab placement is configurable, and in a split workspace a file can open in the opposite pane. Preview tabs in the style of VSCode make a single click open a temporary tab that a double click or an edit promotes to a permanent one.

```cue
plugin: {
    id:     "enhanced-tab-settings"
    name:   "Enhanced Tab Settings"
    author: "boerlabs"
    repo:   "boerlabs/obsidian-enhanced-tab-settings"

    html_url:    "https://community.obsidian.md/plugins/enhanced-tab-settings"
    github_url:  "https://github.com/boerlabs/obsidian-enhanced-tab-settings"
    description: "Customize tab opening behavior with preview tabs, deduplication, and placement control. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Customize how files open and how tabs behave: open files in new tabs by default, switch to existing tabs instead of duplicating, control new-tab placement, and open in the opposite pane in split workspaces. Enable VSCode-style preview tabs to single-click a temporary preview and double-click or edit to promote it to a permanent tab."

    stats: {
        downloads:  358

    }
}
```
