# Better Edit

Better Edit collects editing controls that change how notes are composed rather than how they are rendered. Pasted or dropped images can be resized, aligned, cropped, captioned, replaced, duplicated, given alt text, or grouped into image rows for comparisons, tutorials and reviews. It also adds block drag-and-drop for reorganizing text, configurable slash commands, a floating text styling toolbar, and a searchable symbol and emoji picker.
