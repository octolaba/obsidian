# Plot Vectors and Graphs

Plot Vectors and Graphs draws LaTeX equations and vectors in Obsidian using FunctionPlot. It generates a new page carrying the rendered graphs or vector diagrams, with built-in evaluators, colour-coded traces and support for vector addition and resultants. Multiple expressions are handled through a newline separator.
