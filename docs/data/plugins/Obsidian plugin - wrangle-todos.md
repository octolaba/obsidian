# TODO Wrangler

Collects every line of the current note beginning with TODO, including the list and checkbox variants, and appends them to a single TODOs section at the end of the file. The extraction runs from a ribbon icon or from the command palette.

```cue
plugin: {
    id:     "wrangle-todos"
    name:   "TODO Wrangler"
    author: "jeel-shah"
    repo:   "jeel-shah/todo-wrangler"

    html_url:    "https://community.obsidian.md/plugins/wrangle-todos"
    github_url:  "https://github.com/jeel-shah/todo-wrangler"
    description: "Wrangle your TODOs and put them at the bottom of the file."
    about:       "Consolidate all lines beginning with \"TODO\" (including \"- TODO\" and \"- [] TODO\") from the current note into a unified \"TODOs\" section appended to the end of the file. Run the extraction with a single click from the ribbon or via the command palette."

    stats: {
        downloads:  3812
        updated_at: 1707787783000
    }
}
```
