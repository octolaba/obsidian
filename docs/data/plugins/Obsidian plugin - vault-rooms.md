# Vault Rooms

Shares selected vault folders with trusted people on the same local network as rooms, joined through invite links, with no cloud service and no separate server required. Access control lists grant read, write or delete per file path to a user or a team and deny by default, and edits sync live over WebSocket so Markdown-backed workflows such as Kanban boards and Tasks keep working across synced devices. The relay runs embedded inside Obsidian or standalone on an always-on machine, and the recorded About states that there is no telemetry, no account and no traffic leaving the network.
