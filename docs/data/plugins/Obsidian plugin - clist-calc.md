# CList Calc

Computes statistics over simple or nested Markdown task lists placed inside its own code blocks, covering sums, averages, counts, minimum, maximum, median and mode. Math expressions are available too, including powers, roots, rounding, logarithms and trigonometry, and totals can take checkbox state into account.

```cue
plugin: {
    id:     "clist-calc"
    name:   "CList Calc"
    author: "abdur-nur-porag"
    repo:   "abdur-nur-porag/CList-Calc"

    html_url:    "https://community.obsidian.md/plugins/clist-calc"
    github_url:  "https://github.com/abdur-nur-porag/CList-Calc"
    description: "Perform calculations on nested or simple task lists using sum, average, and math expressions. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Calculate totals, averages, counts, min/max, median, mode and other list-based statistics from simple or nested Markdown lists. Apply math functions—powers, roots, rounding, logs, trig—and checkbox-aware totals directly inside Obsidian notes using ccalc-list blocks."
```
