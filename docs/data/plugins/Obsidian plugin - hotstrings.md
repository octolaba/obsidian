# Hotstrings

Hotstrings expands short custom triggers into longer text as they are typed. Simple and complex replacements are defined once and work in any note or editor, and the hotstring list can be reloaded without restarting Obsidian.

```cue
plugin: {
    id:     "hotstrings"
    name:   "Hotstrings"
    author: "wakywayne"
    repo:   "wakywayne/obsidian-hotstrings"

    html_url:    "https://community.obsidian.md/plugins/hotstrings"
    github_url:  "https://github.com/wakywayne/obsidian-hotstrings"
    description: "Allows you to set custom hot strings that get expanded to text once typed."
    about:       "Create custom hotstrings to automatically expand short triggers into longer text as you type. Define simple or complex replacements, use them in any note or editor, and reload hotstrings on the fly without restarting Obsidian."

    stats: {
        downloads:  980

    }
}
```
