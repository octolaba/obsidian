# Gamified Writing Suite

Tracks words written, session statistics and daily energy, taking hormonal cycle phases and hyperfocus bursts into account. Writing earns XP across a level progression from 1 to 300, in either a Stardew-style crop mode or a D&D monster mode, with daily streaks and AuDHD-affirming prompts. Session logs are exported to Markdown automatically.
