# Moviegrabber

Generates movie and series notes from OMDb metadata, with optional YouTube trailer embeds, shaped for use with dataview and properties. Templates carry {{tags}} placeholders for fields such as Title, Year, Genre, Director, Actors, Poster and Ratings, and each field can take prefixes, suffixes or regex transforms.

    id:     "moviegrabber"
