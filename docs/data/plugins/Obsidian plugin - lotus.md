# Lotus

Runs ordinary fenced Markdown code blocks while native syntax highlighting is kept. Output is rendered in transient panels beneath each block and toolbar controls are added, the source stays unchanged, and outputs update in place through stable IDs derived from path, language, ordinal and content hash. Code runs locally or in containers and on remote hosts.
