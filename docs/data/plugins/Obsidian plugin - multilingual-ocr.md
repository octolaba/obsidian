# Multilingual OCR

Extracts text from images in over 100 languages, including right-to-left scripts such as Arabic. Results go to the clipboard or into a sidebar where they can be highlighted and copied. OCR runs on the last image in the active note, on a given file path, or from the file explorer context menu.

```cue
plugin: {
    id:     "multilingual-ocr"
    name:   "Multilingual OCR"
    author: "Ahmed Alzuhair"
    repo:   "ahmedexe/obsidian-images-ocr"

    html_url:    "https://community.obsidian.md/plugins/multilingual-ocr"
    github_url:  "https://github.com/ahmedexe/obsidian-images-ocr"
    description: "Multilingual extraction of texts from images - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Extract text from images in over 100 languages, including RTL scripts like Arabic. Save OCR results to the clipboard or display them in a sidebar for easy highlighting and copying. Run OCR on the last image in the active note, by file path, or via right-click in the file explorer."

    stats: {
        downloads:  934
        updated_at: 1779901863000
    }
}
```
