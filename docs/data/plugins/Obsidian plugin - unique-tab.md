# Unique Tab

Prevents a second tab from opening for a note, Canvas or custom view that is already open, moving focus to the existing tab instead. Redundant empty placeholder tabs are closed at once to avoid visual flicker. Markdown, Canvas, databases and third-party custom views are covered.
