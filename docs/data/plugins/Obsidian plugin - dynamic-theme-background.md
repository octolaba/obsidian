# Dynamic Theme Background

Builds a wallpaper library for the Obsidian background from Unsplash, Pixabay, Pexels, Wallhaven, custom APIs or local folders. Blur, brightness, saturation and hue are adjustable, and backgrounds rotate on a time window or an interval or are switched, saved and fetched from the status bar or the command palette. Loading and caching are asynchronous so the editor stays responsive.
