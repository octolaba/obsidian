# Blog AI Generator

Blog AI Generator turns notes into blog posts using OpenAI language models. Embedded images are processed and converted, Chinese, English, Japanese and Korean are supported, and the result is saved as a new Markdown file. Prompts and the API endpoint are configurable.

```cue
plugin: {
    id:     "ai-blog-generator"
    name:   "Blog AI Generator"
    author: "garethng"
    repo:   "garethng/obsidian-blog-generator"

    html_url:    "https://community.obsidian.md/plugins/ai-blog-generator"
    github_url:  "https://github.com/garethng/obsidian-blog-generator"
    description: "Generate blog posts from your notes using OpenAI"
    about:       "Generate polished blog posts from your Obsidian notes using OpenAI language models. Process and convert embedded images, support Chinese, English, Japanese and Korean, and save results as new Markdown files with customizable prompts and API endpoints."
```
