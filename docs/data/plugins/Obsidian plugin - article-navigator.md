# Article Navigator

Adds Previous, Next and See Also navigation to notes from frontmatter properties. Navigation renders as inline cards in the VitePress style, as floating side buttons, or as a related-note list. Reciprocal backlinks are kept synchronized, new notes can be seeded with the navigation keys, and edge or tap navigation can be enabled.

```cue
plugin: {
    id:     "article-navigator"
    name:   "Article Navigator"
    author: "IvanHanloth"
    repo:   "ivanhanloth/Obsidian-Article-Navigator"

    html_url:    "https://community.obsidian.md/plugins/article-navigator"
    github_url:  "https://github.com/ivanhanloth/Obsidian-Article-Navigator"
    description: "Adds Previous / Next / SeeAlso navigation to notes via frontmatter properties. Supports floating buttons or VitePress-style inline navigation. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add Previous / Next / See Also navigation to notes using standard frontmatter properties. Render VitePress-style inline nav cards, floating side buttons and a related-note list; keep reciprocal backlinks synchronized, auto-seed new notes with navigation keys, and enable edge/tap navigation."

    stats: {
        downloads:  179
        updated_at: 1780153672000
    }
}
```
