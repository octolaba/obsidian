# Post To Bluesky

Posts selected text or an entire note to Bluesky from inside Obsidian. Up to four images can be attached, emojis picked with a built-in picker, and default hashtags added to the posts.

```cue
plugin: {
    id:     "post-to-bluesky"
    name:   "Post To Bluesky"
    author: "rietamura"
    repo:   "rietamura/Post-To-Bluesky"

    html_url:    "https://community.obsidian.md/plugins/post-to-bluesky"
    github_url:  "https://github.com/rietamura/Post-To-Bluesky"
    description: "Post selected text or entire note to Bluesky."
    about:       "Post to Bluesky from Obsidian. Attach up to four images, pick emojis with a built-in emoji picker, and add default hashtags to posts."

    stats: {
        downloads:  268

    }
}
```
