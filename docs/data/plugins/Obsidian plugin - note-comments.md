# Note Comments

Note Comments anchors comments to selected passages, marking them with coloured highlights and underlines that respect light and dark themes. A right-side panel lists every comment with sorting and filtering, while each document's comments live in a separate note written as readable callouts over hidden JSON. Anchors are tracked so highlights follow edits, and a comment whose quoted text is lost is shown faded as an orphan. The plugin's own description is written in Portuguese.

```cue
plugin: {
    id:     "note-comments"
    name:   "Note Comments"
    author: "Rafael Santos"
    repo:   "rafamss/obsidian-note-comments"

    html_url:    "https://community.obsidian.md/plugins/note-comments"
    github_url:  "https://github.com/rafamss/obsidian-note-comments"
    description: "Adicione comentários a trechos de texto com destaque colorido e um painel lateral. Os comentários ficam em notas separadas, linkadas ao documento. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add anchored comments to any selected text with color highlights and underlines that respect light/dark themes. Show all comments in a right-side panel with sorting and filtering, and store each document's comments in a separate note (readable callouts with hidden JSON). Keep anchors tracked so highlights follow edits and become faded \"orphans\" if the quoted text is lost."

    stats: {
```
