# VaultCast

Plays local audio files stored in the vault as a private podcast player. The recorded description calls it a cute player for local audio and names nothing else, and no About text is recorded for this plugin.

    id:     "vaultcast"
    name:   "VaultCast"
    author: "sourit2001"
    repo:   "sourit2001/vault-cast"

    html_url:    "https://community.obsidian.md/plugins/vaultcast"
    github_url:  "https://github.com/sourit2001/vault-cast"
