# Note Auto Creator

This plugin creates notes automatically when links to them are inserted, generating the target file when it does not exist. A configurable trigger summons link suggestions, which can point at headers or blocks and can search aliases. Folders are suggested as well, and templates can be applied when a new note is created.

```cue
plugin: {
    id:     "obsidian-note-autocreator"
    name:   "Note Auto Creator"
    author: "simontc"
    repo:   "simontc/obsidian-note-autocreation"

    html_url:    "https://community.obsidian.md/plugins/obsidian-note-autocreator"
    github_url:  "https://github.com/simontc/obsidian-note-autocreation"
    description: "Automatically create notes when links are created to them."
    about:       "Create notes automatically when inserting links and auto-generate the target file if it doesn't exist. Use a configurable trigger to summon link suggestions, insert links to headers or blocks, search aliases, suggest folders, and apply templates when new notes are created."

    stats: {
        downloads:  14336
        updated_at: 1750183323000
    }
}
```
