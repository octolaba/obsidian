# Heatmap Calendar

Heatmap Calendar renders note-based data as a GitHub-style year overview for tracking goals, progress, habits, tasks, exercise, finances and similar series. Heatmaps are produced from DataviewJS or from plain JavaScript, with intensity-scaled daily entries, colour themes and current-day highlighting.
