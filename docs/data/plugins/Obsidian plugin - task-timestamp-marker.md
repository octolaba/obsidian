# Task Timestamp Marker

Appends a start date when a task is created and a completion date when it is checked off, written as @start and @done followed by the date. Completed tasks are archived into year, month and week notes so the working page stays short. No setup is required.

```cue
plugin: {
    id:     "task-timestamp-marker"
    name:   "Task Timestamp Marker"
    author: "gansxx"
    repo:   "gansxx/task_manager"

    html_url:    "https://community.obsidian.md/plugins/task-timestamp-marker"
    github_url:  "https://github.com/gansxx/task_manager"
    description: "Mark task timestamp and Archieve tasks. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Track task start and completion dates automatically by appending @start(YYYY-MM-DD) when you create tasks and @done(YYYY-MM-DD) when you complete them. Archive completed tasks into year/month/week notes to keep pages clean with zero setup required."

    stats: {
        downloads:  183
        updated_at: 1785583972000
    }
}
```
