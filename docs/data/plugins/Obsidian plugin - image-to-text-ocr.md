# Image to text OCR

Converts an image in a note to text by running character recognition over it. Commands append the recognized text or replace the image with it, the recognition language is selectable, and Obsidian links, Markdown images and URLs are all accepted as the image reference.

```cue
plugin: {
    id:     "image-to-text-ocr"
    name:   "Image to text OCR"
    author: "dario-baumberger"
    repo:   "dario-baumberger/obsidian-image-to-text-ocr"

    html_url:    "https://community.obsidian.md/plugins/image-to-text-ocr"
    github_url:  "https://github.com/dario-baumberger/obsidian-image-to-text-ocr"
    description: "Convert a image in your note to text."
    about:       "Extract text from images in your notes. Select an image and run commands to append or replace the image with recognized text, choosing the recognition language and handling common image tags and formats (Obsidian links, Markdown, URLs)."

    stats: {
        downloads:  6091
        updated_at: 1777546537000
    }
}
```
