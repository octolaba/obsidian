# LLM Summary

Summarizes collections of PDFs with GPT-based LLMs into structured Markdown summaries imported into the vault, which the recorded inputs frame as batch academic reading. Concept notes can also be created from selected text as new Markdown files and linked automatically, building a note network around a paper.

```cue
plugin: {
    id:     "llm-summary"
    name:   "LLM Summary"
    author: "larksq"
    repo:   "larksq/obsidian-llm-summary"

    html_url:    "https://community.obsidian.md/plugins/llm-summary"
    github_url:  "https://github.com/larksq/obsidian-llm-summary"
    description: "Quick note taking with the help of LLMs. LLMs help you to summarize / organize PDFs or existing notes."
    about:       "Summarize PDF collections with GPT-based LLMs into structured Markdown summaries and import them into your vault for batch academic reading. Create concept notes from selected text as new Markdown files and auto-link them to build a paper-focused note network."

    stats: {
        downloads:  8364
        updated_at: 1726234902000
    }
}
```
