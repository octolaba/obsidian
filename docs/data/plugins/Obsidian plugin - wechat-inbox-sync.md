# WeChat Inbox Sync

Pulls content sent through a WeChat mini program into the vault as dated Markdown notes with local attachments. Text, links, webpages, audio and files are captured, with optional transcription for audio and Markdown snapshots for supported pages. Items are filed into readable daily inbox folders.
