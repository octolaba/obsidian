# Device Theme Switcher

Device Theme Switcher applies a different theme depending on whether the vault is opened on mobile or on desktop. Separate themes are set for each platform and applied at startup or on demand through a manual command.

```cue
plugin: {
    id:     "mobile-desktop-theme-switcher"
    name:   "Device Theme Switcher"
    author: "asingularphoton"
    repo:   "asingularphoton/different-mobile-desktop-themes"

    html_url:    "https://community.obsidian.md/plugins/mobile-desktop-theme-switcher"
    github_url:  "https://github.com/asingularphoton/different-mobile-desktop-themes"
    description: "Automatically switch between different themes based on whether you're accessing your vault on mobile or desktop. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Switch themes automatically between mobile and desktop based on the platform. Set separate themes for mobile and desktop and apply the correct theme at startup or on demand with a manual command."

    stats: {
        downloads:  609
        updated_at: 1780807669000
    }
}
```
