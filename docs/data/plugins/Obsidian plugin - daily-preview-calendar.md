# Daily Preview Calendar

Shows daily notes in week or month calendar views with Markdown previews rendered inside each day cell. Inline and block Markdown are displayed, sections can be filtered by heading, keywords highlighted, and a full-note preview opened on hover or long-press. The grid is responsive with mobile support, and a note can open in the sidebar or in the main area.
