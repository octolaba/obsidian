# Ribbon Hider

Hides a ribbon button when it is right-clicked, thinning out the left sidebar. Hidden items are managed from a settings dashboard, restored all at once, and orphaned entries left by removed or disabled plugins can be cleaned up. Visibility is toggled with CSS, so the DOM stays intact.

```cue
plugin: {
    id:     "ribbon-hider"
    name:   "Ribbon Hider"
    author: "Lucy Roh"
    repo:   "lucytheboss/obsidian-ribbon-hider"

    html_url:    "https://community.obsidian.md/plugins/ribbon-hider"
    github_url:  "https://github.com/lucytheboss/obsidian-ribbon-hider"
    description: "Hide ribbon buttons by right-clicking on them, and manage them in settings. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Hide ribbon buttons with a right-click to declutter your left sidebar. Manage hidden items from a dedicated settings dashboard, restore all at once, and clean up orphaned entries from removed or disabled plugins. Toggle visibility via lightweight CSS that keeps the DOM intact and compatible with other plugins."

    stats: {
        downloads:  45
        updated_at: 1785175040000
    }
}
```
