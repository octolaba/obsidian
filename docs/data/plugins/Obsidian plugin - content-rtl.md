# Content RTL

Applies right-to-left direction to Markdown content in Editing view, Live Preview and Reading view while leaving the interface left-to-right, including Properties, the inline title, the footer, the sidebars and the status bar. Raw frontmatter, inline code, fenced code blocks and math also stay left-to-right, RTL is toggled per note, and it runs offline on desktop and mobile with no telemetry.
