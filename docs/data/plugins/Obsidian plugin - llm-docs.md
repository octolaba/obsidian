# LLM docs

Provides an LLM chat client built out of plain Markdown documents, so conversations live in ordinary notes and their history can be edited inline. Linked notes and images can be included as prompt context, and the recorded inputs name OpenAI and OpenAI-compatible local models such as Ollama, alongside execution controls and loading indicators.

```cue
plugin: {
    id:     "llm-docs"
    name:   "LLM docs"
    author: "shane-lamb"
    repo:   "shane-lamb/obsidian-llm-docs"

    html_url:    "https://community.obsidian.md/plugins/llm-docs"
    github_url:  "https://github.com/shane-lamb/obsidian-llm-docs"
    description: "Simple LLM (AI chat) client using pure markdown documents"
    about:       "Chat with LLMs directly inside plain Markdown files and edit conversation history inline. Include linked Obsidian notes and images as prompt context and connect to OpenAI or OpenAI‑compatible local models like Ollama. Display execution controls and loading indicators for clearer interactions."

    stats: {
        downloads:  958
        updated_at: 1752913964000
    }
}
```
