# Taskmap

Taskmap plans projects as interactive task trees whose layout is computed automatically on a canvas-style surface, so nothing has to be positioned by hand. Status, dependency flow and blocked areas are color-coded, tasks link to notes, and a parent's status updates from its children. Irrelevant branches can be hidden to navigate large projects.
