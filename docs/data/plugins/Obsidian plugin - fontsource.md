# Fontsource

Imports custom fonts from Fontsource and makes any Fontsource family available in the editor and in preview. Installed families can be applied and managed across the vault for consistent typography.

```cue
plugin: {
    id:     "fontsource"
    name:   "Fontsource"
    author: "fontsource"
    repo:   "fontsource/obsidian-fontsource"

    html_url:    "https://community.obsidian.md/plugins/fontsource"
    github_url:  "https://github.com/fontsource/obsidian-fontsource"
    description: "Load custom fonts from Fontsource into your notes."
    about:       "Import Fontsource custom fonts into Obsidian and make any Fontsource family available for editor and preview. Apply and manage installed Fontsource fonts across your vault for consistent typography."
```
