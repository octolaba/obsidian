# Ledgr

Ledgr keeps personal finance data in the vault as plain Markdown and JSON files, with transactions recorded as Markdown table rows carrying Dataview inline fields so that they can be queried like any other note. It covers daily spending capture, a monthly dashboard, category budgets, net worth across multiple accounts and currencies, a liability tracker with payment reminders, savings goals, monthly review notes and a year-end summary. Financial statements for profit and loss, cash flow and the balance sheet are generated, with custom exchange rates and an opt-in international transfer tracker.
