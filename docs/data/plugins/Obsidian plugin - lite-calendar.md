# Lite Calendar

Integrates the macOS Calendar into Obsidian through an interactive calendar view in the style of a flash-note interface. Events for the coming three days are shown, and events can be created, edited, or deleted across several calendars, including all-day items, locations, and notes. The recorded inputs state that macOS and granted calendar access are required.
