# Callout Control Panel

Callout Control Panel inserts any callout from a single modal or hotkey, offering built-in, theme, snippet-defined and custom types with a title, a collapse state and smart Markdown insertion. Callout types defined by themes and CSS snippets are detected live. Custom types with icons and colors can be created, edited, imported and exported.
