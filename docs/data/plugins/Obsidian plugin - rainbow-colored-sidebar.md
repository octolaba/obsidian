# Rainbow-Colored Sidebar

Colors the sidebar with repeating palettes that adapt to light and dark mode, and the recorded description states that no configuration is needed. Nine built-in themes are offered — several rainbow starting points, Blue Wave, Summer Vibes, a mixed palette and an accessibility palette — with subfolders colored automatically and an indicator for the active file. Colors are assigned in alphabetical order of folder name.
