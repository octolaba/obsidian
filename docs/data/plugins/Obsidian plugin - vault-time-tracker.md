# Vault Time Tracker

Tracks the time spent on each note and keeps the timer running while Obsidian is in the background or minimized. Daily, weekly and monthly summaries appear in a sidebar, a sortable full-page dashboard shows folders and full paths, and a live timer sits in the status bar. History is retained across renames and for deleted notes.
