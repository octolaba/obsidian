# Harang Nextcloud

Turns pasted Nextcloud internal links into file cards inside notes, showing name, path, size, upload date and a button that opens the file in a browser. Multiple Nextcloud profiles are supported through Login Flow v2, and non-image files can be uploaded automatically to a note's nc-folder with the corresponding file block inserted. Deleted blocks can optionally be moved to the Nextcloud trash.
