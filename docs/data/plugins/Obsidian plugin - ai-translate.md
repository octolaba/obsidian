# AI Translate

Looks up a single English word for phonetics, bilingual definitions and UK/US audio, translates selected phrases, sentences or passages, and accepts text entered from the Command Palette. Chinese text translates to English while other text uses a chosen target language, served by the built-in Youdao mobile dictionary and translation services or an OpenAI-compatible endpoint configured as a fallback. Successful English lookups can optionally be sent to your own vocabulary service, an integration that is off by default and supports flexible request templates, authentication and custom headers.
