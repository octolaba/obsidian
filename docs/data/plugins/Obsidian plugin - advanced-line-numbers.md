# Advanced Line Numbers

Advanced Line Numbers shows absolute, relative or hybrid line numbers in Markdown files, the relative and hybrid modes serving vim-style navigation. The active line, the gutter or the line number can be highlighted, and the cursor position is reported as line and column in the status bar.

```cue
plugin: {
    id:     "advanced-line-numbers"
    name:   "Advanced Line Numbers"
    author: "anamaydev"
    repo:   "anamaydev/advanced-line-numbers"

    html_url:    "https://community.obsidian.md/plugins/advanced-line-numbers"
    github_url:  "https://github.com/anamaydev/advanced-line-numbers"
    description: "Show absolute, relative, and hybrid line numbers in markdown files, with cursor position (line and column) in the status bar. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add customizable line numbers to the editor with Absolute, Relative, or Hybrid modes for vim-style navigation. Highlight the active line, gutter, or line number and display cursor position (Ln X, Col Y) in the status bar."

    stats: {
        downloads:  1028
        updated_at: 1784156592000
    }
}
```
