# Share my plugin list

Share my plugin list exports the plugins active or inactive in a vault as a formatted list or table, ready to hand to someone as a recommendation. Names, authors and versions are included with direct install links, and a single command installs every missing plugin at once.

```cue
plugin: {
    id:     "share-my-plugin-list"
    name:   "Share my plugin list"
    author: "benature"
    repo:   "benature/obsidian-share-my-plugin-list"

    html_url:    "https://community.obsidian.md/plugins/share-my-plugin-list"
    github_url:  "https://github.com/benature/obsidian-share-my-plugin-list"
    description: "Share the enabled plugins in list/table format."
    about:       "Share the plugins active or inactive in your vault as a formatted list or table for easy recommendations. Export names, authors and versions with direct install links and run one command to install all missing plugins at once."

    stats: {
        downloads:  7092

    }
}
```
