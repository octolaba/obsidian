# Strava Periodic Note Sync

Strava activities are synced into periodic or daily notes after OAuth2 authentication, with credentials kept in what the recorded inputs call secure storage. An activities section lists each activity with an emoji, pace or speed, distance, duration and elevation, and frontmatter metrics such as running, cycling and walking distance are updated. Up to 90 days can be backfilled.

```cue
plugin: {
    id:     "strava-periodic-note-sync"
    name:   "Strava Periodic Note Sync"
    author: "jamesjarvis"
    repo:   "jamesjarvis/obsidian-strava-periodic-sync"

    html_url:    "https://community.obsidian.md/plugins/strava-periodic-note-sync"
    github_url:  "https://github.com/jamesjarvis/obsidian-strava-periodic-sync"
    description: "Sync Strava activities to your periodic notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync Strava activities to Periodic or Daily Notes using OAuth2 authentication and secure credential storage. Add an Activities section showing emoji, pace/speed, distance, duration and elevation; update frontmatter metrics (running_distance_m, cycling_distance_m, walking_distance_m, etc.) and backfill up to 90 days."

    stats: {
```
