# TaskWarrior Task Wiki

Wraps Taskwarrior so its database can be viewed and edited from a note: a tw code block embeds a report, with optional filters and templates. Tasks are created, edited and deleted straight from the rows of a report, while the configured Taskwarrior binary executes the queries.

```cue
plugin: {
    id:     "tw-task-wiki"
    name:   "TaskWarrior Task Wiki"
    author: "snttgr"
    repo:   "snttgr/obsidian-tw-task-wiki"

    html_url:    "https://community.obsidian.md/plugins/tw-task-wiki"
    github_url:  "https://github.com/snttgr/obsidian-tw-task-wiki"
    description: "Wrapper and integration around TaskWarrior. Allows you to view and edit tasks in your TaskWarrior database as tables."
    about:       "Embed Taskwarrior reports in notes using a tw code block with optional filters and templates. Create, edit, and delete tasks directly from report rows while the plugin runs your configured Taskwarrior binary to execute queries."

    stats: {
        downloads:  1846
        updated_at: 1776103965000
    }
}
```
