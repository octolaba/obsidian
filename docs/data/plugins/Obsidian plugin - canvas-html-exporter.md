# Canvas HTML Exporter

Canvas HTML Exporter exports a canvas as interactive HTML for any browser, preserving layout, node styling, groups, connections, labels and markers. The output is either a package folder or a single self-contained page, carrying rendered Markdown, media, LaTeX, code highlighting, rewritten links, zoom and a minimap.
