# Release Timeline

This plugin renders a release timeline from note metadata using a Dataview-like query syntax. Year, month and week timelines are generated, dates written as a year, a year and month, or a full date are extracted automatically, and alias fields and sort order are honored. The result is displayed as a chronological timeline.

```cue
plugin: {
    id:     "obsidian-release-timeline"
    name:   "Release Timeline"
    author: "cakechaser"
    repo:   "cakechaser/obsidian-release-timeline"

    html_url:    "https://community.obsidian.md/plugins/obsidian-release-timeline"
    github_url:  "https://github.com/cakechaser/obsidian-release-timeline"
    description: "Release timeline rendered based on notes metadata with a Dataview-like syntax."
    about:       "Create release timelines from note metadata using Dataview-compatible queries. Generate year, month, or week timelines that auto-extract dates (YYYY, YYYY-MM, YYYY-MM-DD), honor alias fields and sort order, and render results as a clear chronological timeline."

    stats: {
        downloads:  10331
        updated_at: 1705605392000
    }
}
```
