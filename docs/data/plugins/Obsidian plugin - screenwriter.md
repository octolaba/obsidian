# Screenwriter

Screenwriter develops screenplays in plain Markdown. Creating a project lays down five prestructured files, namely Treatment, Outline, Characters, a Beat Sheet built on Blake Snyder's fifteen beats, and Notes, to which character entries and scene cards are added. A sidebar browses the projects and shows their format, status and scene counts.
