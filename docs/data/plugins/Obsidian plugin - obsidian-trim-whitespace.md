# Trim Whitespace

Unnecessary blank characters, meaning spaces, tabs and extra blank lines, are trimmed from a note. Trailing, leading or repeated whitespace is targeted in the whole document or in a selection, code blocks and indented lists are preserved, and trimming runs manually or automatically.

```cue
plugin: {
    id:     "obsidian-trim-whitespace"
    name:   "Trim Whitespace"
    author: "zlovatt"
    repo:   "zlovatt/obsidian-trim-whitespace"

    html_url:    "https://community.obsidian.md/plugins/obsidian-trim-whitespace"
    github_url:  "https://github.com/zlovatt/obsidian-trim-whitespace"
```
