# Minio Uploader

Minio Uploader sends images, videos, audio, PDFs and other files to Minio object storage rather than saving them locally. Files are uploaded by drag and drop, by pasting, or by selecting a command, with Editing ToolBar integration to insert previews and links. The stated aim is to reduce local disk usage and speed up sync across devices.
