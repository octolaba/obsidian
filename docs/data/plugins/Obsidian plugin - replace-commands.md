# Replace Commands

Replace Commands stores named, reusable search-and-replace actions defined with plain text or JavaScript regular expressions and applied to a selection or a whole document. Rules can be tested live with step-by-step previews, chained and reordered, and can use capture groups and custom flags. Each run applies as a single undoable operation, invoked from the Command Palette or the editor context menu.

    id:     "replace-commands"
    name:   "Replace Commands"
    author: "Eric Lowry"
