# External File Linker

Embeds external files in notes through an external-prefixed embed link that takes absolute or relative paths and handles common formats such as Markdown, PDF, PNG, JPG, MP3 and MP4. Groups map a group name to device-specific base paths, so that the same links resolve across several devices and operating systems.

```cue
plugin: {
    id:     "pathlinker"
    name:   "External File Linker"
    author: "kay607"
    repo:   "kay607/obsidian-pathlinker"

    html_url:    "https://community.obsidian.md/plugins/pathlinker"
    github_url:  "https://github.com/kay607/obsidian-pathlinker"
    description: "Embed external files into your notes."
    about:       "Link and embed external files with ![[external:...]] using absolute or relative paths, handling common formats like md, pdf, png, jpg, mp3, and mp4. Define groups that map a group name to device-specific base paths so the same links resolve correctly across multiple devices and operating systems."
```
