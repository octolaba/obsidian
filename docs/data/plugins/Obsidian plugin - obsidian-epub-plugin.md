# ePub Reader

Opens documents with the .epub file extension that are stored in the vault and reads them inside Obsidian. Book content is shown in a built-in reading view and navigated through the table of contents.

```cue
plugin: {
    id:     "obsidian-epub-plugin"
    name:   "ePub Reader"
    author: "caronchen"
    repo:   "caronchen/obsidian-epub-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-epub-plugin"
    github_url:  "https://github.com/caronchen/obsidian-epub-plugin"
    description: "Open documents with \".epub\" file extension."
    about:       "Open and read .epub files stored in your vault directly inside Obsidian. Display book content in a built-in reading view and navigate using the table of contents."

    stats: {
        downloads:  57704

    }
}
```
