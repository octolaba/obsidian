# AI Zhipu

Generates content, images and knowledge-base question answering through the Zhipu AI API from inside Obsidian, driven by customizable prompt templates. Multi-turn conversations are managed in the plugin, prompt and token usage is shown, and templates and history are kept in an Aizhipu folder.
