# Random Note Plus

Opens a random note from the vault while excluding chosen folders from the selection, which is what separates it from the core random note plugin. The picker is triggered from a ribbon icon or a command, and reports a notice when no eligible note remains.

```cue
plugin: {
    id:     "random-note-plus"
    name:   "Random Note Plus"
    author: "wogong"
    repo:   "wogong/obsidian-random-plus"

    html_url:    "https://community.obsidian.md/plugins/random-note-plus"
    github_url:  "https://github.com/wogong/obsidian-random-plus"
    description: "Like the core random note plugin, but with folder exclusions. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open a random note from your vault while excluding specific folders to refine selection. Use a ribbon icon or command to trigger the picker and receive a notice if no eligible notes remain."
```
