# Tategaki

Tategaki lays Markdown out vertically for reading and editing on desktop, with inline source editing and keyboard navigation tuned for vertical text. Ruby, tate-chu-yoko, images and embeds are rendered, and outline navigation, folding and outliner-style list editing are provided. A book mode paginates the text by measurement.
