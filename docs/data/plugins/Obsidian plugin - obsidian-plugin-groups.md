# Plugin Groups

This plugin manages other plugins as named groups, so several can be enabled or disabled at once. A group can also delay the startup of its plugins to shorten Obsidian's start-up time. Groups can be nested into parent and child loading arrangements and organized by role.

```cue
plugin: {
    id:     "obsidian-plugin-groups"
    name:   "Plugin Groups"
    author: "mocca101"
    repo:   "mocca101/obsidian-plugin-groups"

    html_url:    "https://community.obsidian.md/plugins/obsidian-plugin-groups"
    github_url:  "https://github.com/mocca101/obsidian-plugin-groups"
    description: "Manage your Plugins with groups: Enable & disable multiple plugins at once or delay their startup to speed up your Obsidian start up time."
    about:       "Group your Obsidian plugins into named collections for easier management. Enable or disable entire groups at once and set delayed loading to reduce startup time. Nest groups to create parent/child loading arrangements and organize plugins by role."
```
