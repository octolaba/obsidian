# Chinese Comprehensible Input

Chinese Comprehensible Input turns a Chinese note into a reading environment for learners, tokenizing the text against a dictionary and tracking exposure to each item. A built-in spaced repetition system and optional story generation through an OpenAI-compatible model support reading-based retention. It runs on desktop and on mobile.
