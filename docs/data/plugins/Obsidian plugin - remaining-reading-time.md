# Remaining reading time

Shows the remaining reading time for the current note in the status bar, derived from the cursor position. Reading progress as a percentage is displayed live beside it, so the time left in an article, note, or book can be used to pace a reading session.

```cue
plugin: {
    id:     "remaining-reading-time"
    name:   "Remaining reading time"
    author: "ununnamed"
    repo:   "ununnamed/remaining-reading-time"

    html_url:    "https://community.obsidian.md/plugins/remaining-reading-time"
    github_url:  "https://github.com/ununnamed/remaining-reading-time"
```
