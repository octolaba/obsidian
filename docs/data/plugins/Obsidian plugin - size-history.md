# Size History

Size History draws a hand-drawn line chart of the vault file-count history, tracked daily. Earlier history is recreated from file creation dates and recording continues from installation onward, so files deleted before installation do not appear. All the data stays local.

```cue
plugin: {
    id:     "size-history"
    name:   "Size History"
    author: "pbrw"
    repo:   "pbrw/obsidian-size-history"

    html_url:    "https://community.obsidian.md/plugins/size-history"
    github_url:  "https://github.com/pbrw/obsidian-size-history"
    description: "Admire the growth of your vault with a \"hand-drawn\" chart."
    about:       "View a hand-drawn line chart of your vault’s file-count history with daily tracking. Recreate prior history from file creation dates and continue recording changes from installation onward; files deleted before installation won’t appear and all data stays local."

    stats: {
        downloads:  4407
        updated_at: 1693430665000
    }
}
```
