# Convert to Markdown

Converts PDF, Word, PowerPoint, Excel and image files in the vault into Markdown notes, keeping headings, tables and lists and listing embedded images and dropped assets alongside the output. Everything is parsed natively on the machine, with no Python, no cloud service, no external binary and no API key. Documents parse deterministically, while text inside images is read by local OCR that reports its confidence.
