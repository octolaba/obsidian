# Path Finder

This plugin finds paths between two notes and renders them as a graph or as text. It can compute the shortest path between two files or enumerate all link paths connecting them, showing the result as a sorted list or an interactive graph. An optional path-length limit keeps the output manageable.

```cue
plugin: {
    id:     "obsidian-path-finder"
    name:   "Path Finder"
    author: "jerrywcy"
    repo:   "jerrywcy/obsidian-path-finder"

    html_url:    "https://community.obsidian.md/plugins/obsidian-path-finder"
    github_url:  "https://github.com/jerrywcy/obsidian-path-finder"
    description: "Find all paths between two notes and render them as graph or text."
    about:       "Find the shortest path between two files or enumerate all link paths connecting them. Display results as a sorted list or interactive graph and apply optional path-length limits to keep outputs manageable."
```
