# CBT Exam Simulator

CBT Exam Simulator builds interactive timed exams from Markdown notes written in a human-readable syntax, running them offline in a native workspace tab with a timer and a navigator. Seven question types are supported alongside an adaptive study mode, exam history, mark-for-review, color-coded review, detailed results and quick retakes. Questions and options may contain full Markdown and LaTeX rendered through MathJax.
