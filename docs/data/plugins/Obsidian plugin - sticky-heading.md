# Sticky Headings

The heading or headings covering the current position are pinned to the top of the editor while scrolling, together with the heading level. Several sticky levels can be shown at once and update as the document is navigated. Operation can be limited to edit mode.

```cue
plugin: {
    id:     "sticky-heading"
    name:   "Sticky Headings"
    author: "imshenshen"
    repo:   "imshenshen/obsidian-sticky-heading"

    html_url:    "https://community.obsidian.md/plugins/sticky-heading"
    github_url:  "https://github.com/imshenshen/obsidian-sticky-heading"
    description: "Sticky headings and shows the heading level"
    about:       "Display current heading(s) pinned to the top of the editor as you scroll to keep track of your section and heading level. Show multiple sticky levels and update them dynamically while navigating the document. Limit operation to edit mode only."

    stats: {
        downloads:  5673
        updated_at: 1750237074000
    }
}
```
