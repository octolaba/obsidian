# Native Cursor

Widens the editor cursor and gives it a colour, snapping instantly instead of animating its movement. Width is set between 1 and 6 pixels, dark and light colours are configured separately, blinking is toggled, and all settings reset to defaults. The styling applies to the main editor in source and live preview.

```cue
plugin: {
    id:     "native-cursor"
    name:   "Native Cursor"
    author: "olivertedwards"
    repo:   "olivertedwards/native-cursor-obsidian"

    html_url:    "https://community.obsidian.md/plugins/native-cursor"
    github_url:  "https://github.com/olivertedwards/native-cursor-obsidian"
    description: "Wider cursor with a native feel; custom light/dark mode colour, width, and blink toggle. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Give the editor cursor a wider, colored, and optionally static native feel with instant snapping and no movement animations. Adjust width (1–6px), set separate dark/light colors, toggle blinking, and reset all settings to defaults. Apply styling to the main editor (source and live preview)."
```
