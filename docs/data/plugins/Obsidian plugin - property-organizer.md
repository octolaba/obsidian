# Property Organizer

Keeps YAML frontmatter properties in a defined order per folder, rewriting the order without changing values, names or any other note content. Folder templates cover subfolders and are prioritized from top to bottom, and sorting runs on demand or optionally when the vault opens, leaving notes untouched during creation, edits, renames and moves.

    id:     "property-organizer"
    name:   "Property Organizer"
    author: "vkostyanetsky"

    github_url:  "https://github.com/vkostyanetsky/ObsidianPropertyOrganizer"
    description: "Keep frontmatter properties in a custom order. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Keep YAML frontmatter properties in the order you define per folder and rewrite property order without changing values, names, or note content. Apply folder templates (including subfolders) with top-to-bottom priority and run sorting on demand or optionally at vault open while leaving notes untouched during creation, edits, renames, or moves."
