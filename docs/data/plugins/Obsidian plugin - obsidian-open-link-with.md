# Open Link With

This plugin opens external links in a browser of your choice. Custom browser profiles are defined with command paths and arguments, and modifier-key and mouse-button bindings decide which profile a link opens with, matched from top to bottom. A global browser can be set for default clicks.

```cue
plugin: {
    id:     "obsidian-open-link-with"
    name:   "Open Link With"
    author: "mamoruds"
    repo:   "mamoruds/obsidian-open-link-with"

    html_url:    "https://community.obsidian.md/plugins/obsidian-open-link-with"
    github_url:  "https://github.com/mamoruds/obsidian-open-link-with"
```
