# EPUB Transfer to Markdown

Imports an EPUB file on desktop into the vault as a chapter-based Markdown reading workspace. Each import creates a book folder holding numbered chapter files, an AI reading guide, the embedded media and the original EPUB source.

```cue
plugin: {
    id:     "epub-reading-importer"
    name:   "EPUB Transfer to Markdown"
    author: "Taoye"
    repo:   "skye1349/epub-reading-importer"

    html_url:    "https://community.obsidian.md/plugins/epub-reading-importer"
    github_url:  "https://github.com/skye1349/epub-reading-importer"
    description: "Import EPUB files into a vault as chapter-based Markdown reading workspaces. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Import EPUB files on desktop into your vault as chapter-based Markdown reading workspaces. Create a book folder with numbered chapter files, an AI Reading Guide, embedded media, and the original EPUB source."

    stats: {
        downloads:  426
        updated_at: 1782106534000
    }
}
```
