# Life RPG

Life RPG collects habits, water intake, rewards, XP, inventory and wallet records into a compact dashboard framed as a role-playing game. It shows a hero profile with level, class and avatar alongside quests, a reward shop, a calendar and a sidebar with the day's progress. Data stays local, with no network requests and no telemetry.
