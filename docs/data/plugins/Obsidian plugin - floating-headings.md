# Floating Headings

Displays a collapsible outline of a note's headings beside the editor, as compact indicators that expand on hover into the full heading text. Clicking a heading navigates to it, and the outline is filtered and searched in real time. Heading hierarchies collapse, the sidebar sits on the left or the right, and it adapts to the theme.
