# Simplest Todo

Simplest Todo keeps tasks in a single note and automatically archives completed items into a rolling monthly archive organized by completion date. Unchecking a task in the archive restores it, and manual archiving or a monthly rollover can be triggered from the ribbon or the command palette. The interface is available in English and Russian.

plugin: {
    id:     "simplest-todo"
    name:   "Simplest Todo"
    author: "kintolayli"

    html_url:    "https://community.obsidian.md/plugins/simplest-todo"
    github_url:  "https://github.com/kintolayli/simplest-todo"

Restore tasks by unchecking them in the archive, trigger manual archiving or monthly rollover from the ribbon or command palette, and use the interface in English or Russian."
