# iCalendar

iCalendar shows tasks from daily notes and project files in an interactive calendar with month, week and list views. Tasks are created and edited in place, dragged to reschedule, and color-coded by source and status, notes are opened by date, and statistics and charts are available in a mobile-friendly layout.
