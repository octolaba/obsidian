# Local Zotero Mirror

Synchronizes Zotero collections, item metadata and native notes into local Markdown, creating one canonical note per Zotero item. Collection index notes are regenerated to link to those canonical notes, user-written sections outside the managed blocks are preserved, and native notes are migrated into protected blocks. Items and PDFs can be opened from Obsidian.
