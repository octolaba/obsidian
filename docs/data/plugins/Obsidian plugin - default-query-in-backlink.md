# Default query in backlinks

Fills the search input of the backlinks panel with a default query when a file is opened. The default can filter by path, collapse results, show more context, control sort order and expand unlinked mentions, and the panel's display state is remembered per file and per leaf.

```cue
plugin: {
    id:     "default-query-in-backlink"
    name:   "Default query in backlinks"
    author: "benature"
    repo:   "benature/obsidian-default-query-in-backlink"

    html_url:    "https://community.obsidian.md/plugins/default-query-in-backlink"
    github_url:  "https://github.com/benature/obsidian-default-query-in-backlink"
    description: "Automatically input default query in search input of backlinks in document."
    about:       "Set custom default queries and view options for the backlinks panel — filter by path, collapse results, show more context, control sort order and expand unlinked mentions. Remember panel display per file/leaf and automatically run or update the saved query when a file opens."

}
```
