# Ollama Notes Chat

Ollama Notes Chat puts a chat panel in the right sidebar backed by an Ollama server, so requests stay on the local network. Responses stream live, the context mode covers the current note, a selection, linked notes or RAG, and Markdown renders with clickable internal links. Conversations can be saved or inserted into a note.

```cue
plugin: {
    id:     "ollama-notes-chat"
    name:   "Ollama Notes Chat"
    author: "Taylor D. Marchetta"
    repo:   "tdmarchetta/obsidian-ollama-notes-chat"

    html_url:    "https://community.obsidian.md/plugins/ollama-notes-chat"
    github_url:  "https://github.com/tdmarchetta/obsidian-ollama-notes-chat"
    description: "Chat with your notes in a right sidebar using a remote Ollama server. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Chat with your notes from a right-sidebar panel via a local Ollama server so requests stay on your LAN. Stream responses live, switch context modes (note, selection, linked notes, RAG), render Markdown with clickable [[wikilinks]], and save or insert conversations."
```
