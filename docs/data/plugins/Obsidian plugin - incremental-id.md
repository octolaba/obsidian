# Incremental ID

Generates Jira-like incremental IDs for notes from a customizable prefix, for instance DN-1 and DN-2. An ID is inserted by command or called from a template, and the current ID can be reused where it is needed.

```cue
plugin: {
    id:     "incremental-id"
    name:   "Incremental ID"
    author: "adziok"
    repo:   "adziok/obsidian-incremental-id"

    html_url:    "https://community.obsidian.md/plugins/incremental-id"
    github_url:  "https://github.com/adziok/obsidian-incremental-id"
    description: "Generate Jira-like IDs for each note."
    about:       "Generate unique incremental IDs with customizable prefixes (e.g., DN-1, DN-2). Insert IDs via command or call them in templates and reuse the current ID where needed."

    stats: {
        downloads:  5366
        updated_at: 1704545848000
    }
}
```
