# Split Web Viewer Modifier

External links open in Obsidian's Web Viewer in a split pane, and later links reuse the same pane instead of stacking new ones. Shift-click opens a new Web Viewer tab and Cmd or Ctrl click sends the link to the browser instead, and the recorded inputs state that this click behaviour is configurable.

```cue
plugin: {
    id:     "split-web-viewer-modifier"
    name:   "Split Web Viewer Modifier"
    author: "hucy"
    repo:   "hucy/split-link-router"

    html_url:    "https://community.obsidian.md/plugins/split-web-viewer-modifier"
    github_url:  "https://github.com/hucy/split-link-router"
    description: "Open external links in a split-pane Web Viewer. Supports reuse, new tab, new split, and browser modes. Configurable Shift / Cmd/Ctrl click behavior. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open external links in Obsidian's split Web Viewer pane and reuse the same Web Viewer pane for subsequent links. Use Shift+Click to open a new Web Viewer tab and Cmd/Ctrl+Click to toggle the target between the Web Viewer and your browser."

    stats: {
        downloads:  143
        updated_at: 1776484281000
    }
}
```
