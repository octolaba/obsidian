# Heading Level Indent

Heading Level Indent indents the content under each heading according to that heading's level, so the document structure is easier to scan. Indentation is configurable per heading level and applies in the editor, Live Preview, Reading view, PDF export and common embeds. A frontmatter key toggles the behaviour for an individual note.

```cue
plugin: {
    id:     "heading-level-indent"
    name:   "Heading Level Indent"
    author: "svonjoi"
    repo:   "svonjoi/obsidian-heading-level-indent"

    html_url:    "https://community.obsidian.md/plugins/heading-level-indent"
    github_url:  "https://github.com/svonjoi/obsidian-heading-level-indent"
    description: "Indenting content under headers based on their level."
    about:       "Indent content under headings to create a clear visual hierarchy and make document structure easier to scan. Customize indentation for each heading level to match your layout. Apply indentation across editor, live preview, reading view, PDF export and common embeds, and toggle per note with the heading-indent frontmatter."

    stats: {
        downloads:  33286

    }
}
```
