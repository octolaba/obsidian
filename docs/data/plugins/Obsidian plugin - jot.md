# Jot

Jot annotates PDFs with an Apple Pencil, offering pressure-sensitive ink with pen, highlighter and eraser tools reached from a radial palette that also sets color and width, with undo and redo. Strokes are stored in a small JSON sidecar next to each PDF, so the original file is never modified and annotations sync through Git or iCloud across devices. Annotations can also be merged into a flattened PDF.
