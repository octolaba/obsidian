# Living Graph

Animates the graph view with dynamic motion, pulsing edges and reactive node behavior, described in its own recorded inputs as a for-fun plugin. Twelve presets are offered and the effect is toggled on or off; the inputs warn that it may increase CPU usage and cause fans to run.
