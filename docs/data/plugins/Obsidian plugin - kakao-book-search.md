# Kakao Book Search

Searches for books through the Kakao Book Search API and creates a Markdown note from the chosen result. The note is generated from a template and populated with the cover image and its URL, authors, translators, publisher, ISBN, price, publication date and description, then saved to a folder in the vault.

    name:   "Kakao Book Search"
