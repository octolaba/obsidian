# Drag and Drop Sort

Lets files and folders be dragged into a custom order in the File explorer, with notes and folders freely interspersed rather than grouped. The order persists and survives renames and moves. Context-menu entries and Command Palette commands move individual items or reset a folder's order.

```cue

    id:     "drag-drop-sort"
    name:   "Drag and Drop Sort"
    author: "singularitopian"
    repo:   "summerdawn-ai/obsidian-drag-drop-sort"

    html_url:    "https://community.obsidian.md/plugins/drag-drop-sort"
    github_url:  "https://github.com/summerdawn-ai/obsidian-drag-drop-sort"
    description: "Drag & drop to reorder files and folders in the File explorer, with context-menu and command-palette controls. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Drag and drop files and folders in the File explorer to create a custom, persistent order that lets notes and folders be freely interspersed. Keep ordering through renames and moves, and use context-menu or Command Palette commands to move items or reset folder order."
```
