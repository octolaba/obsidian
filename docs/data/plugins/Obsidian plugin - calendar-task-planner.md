# Calendar Task Planner

Calendar Task Planner offers a monthly calendar with Monday-first weeks and checkbox-enabled day cards for managing tasks day by day. Tasks are added, edited and deleted in a modal, and monthly statistics show the total, the done count and a percentage. A day can be exported to a dated note or added to Canvas, and all data is stored locally and available offline.
