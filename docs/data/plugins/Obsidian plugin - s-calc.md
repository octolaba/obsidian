# S-Calc

S-Calc evaluates expressions written in an s-calc code block and shows each line's result to its right in the theme's accent color, updating live as the text is typed. Supported input includes arithmetic, labels and variables, running totals through sum and prev, percentages, unit and currency conversions with live rates, and plain-language dates.
