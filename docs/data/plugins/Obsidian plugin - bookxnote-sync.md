# BookXNote Sync

BookXNote Sync imports reading notes from BookXNote into the vault as organized Markdown files. It reads BookXNote's JSON notebooks and imports all of them or individual notes, keeping the notebook structure and the note content intact.

    id:     "bookxnote-sync"
    name:   "BookXNote Sync"
    author: "codelistening"
    repo:   "codelistening/obsidian-bookxnote"
