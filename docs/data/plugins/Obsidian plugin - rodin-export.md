# Export to Rodin

Export to Rodin sends the vault to Rodin, which returns an intellectual fingerprint covering themes, open questions, mental models, influences, blind spots and the core question behind the user's thinking. A Rodin profile can be connected so later exports merge new insights into the same fingerprint. The recorded text states that vault text is sent to rodin.fyi for processing and that only the derived fingerprint is retained.
