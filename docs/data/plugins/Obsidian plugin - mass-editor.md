# Mass Editor

Mass Editor searches and edits across the vault in bulk, building queries visually with nested AND, OR and NOT conditions. Matching notes can then be changed in one operation, covering frontmatter, tags, body text and regular-expression find and replace, with live match previews and per-result selection. Backups, undo, Git-style diffs, exportable run reports and saved presets are provided around the edits.
