# Vault Pulse

Draws a GitHub-style activity heatmap of file activity over the last 365 days, as a grid of 53 by 7 cells in a collapsible right sidebar. Clicking a day lists the files edited on it. Colors follow adaptive quantiles across five palettes, a 30-day sparkline accompanies the grid, results can be filtered by folder or tag, and streak milestones and the lifetime best are tracked.
