# Expanded Bookmarks

Extends the core Bookmarks feature with a panel offering moving, sorting, multi-select, grouping, statistics, search filters and import and export. Moving a bookmarked file into a vault folder from the panel moves the real file on disk. Bookmarked files are marked in the file explorer and can be shown exclusively or hidden in Search, and duplicate or broken entries can be removed.
