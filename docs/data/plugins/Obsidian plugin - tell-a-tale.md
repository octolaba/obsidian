# Tell-A-Tale

Writes dialogue, monologue, narration, scene direction and cast changes as structured callout blocks that stay visually distinct from one another. Speakers are picked through a fuzzy search, blocks can be colour-coded per character, and character avatars appear in reading view. Blocks can be edited or removed inline with keyboard shortcuts.

plugin: {
    id:     "tell-a-tale"
    name:   "Tell-A-Tale"
