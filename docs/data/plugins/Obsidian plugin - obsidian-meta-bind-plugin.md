# Meta Bind

This plugin makes notes interactive with inline input fields, view fields that display metadata, and buttons. Those fields are bound to frontmatter properties, so metadata can be edited and displayed in place and note content stays synchronized with the frontmatter.

```cue
plugin: {
    id:     "obsidian-meta-bind-plugin"
    name:   "Meta Bind"
    author: "Moritz Jung"
    repo:   "mprojectscode/obsidian-meta-bind-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-meta-bind-plugin"
    github_url:  "https://github.com/mprojectscode/obsidian-meta-bind-plugin"
    description: "Make your notes interactive with inline input fields, metadata displays, and buttons."
    about:       "Create interactive inline input fields, view fields, and buttons inside your notes. Bind those fields to frontmatter properties to edit and display metadata in-place and keep note content and frontmatter synchronized."
```
