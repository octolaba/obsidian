# Media Companion

Builds a searchable gallery of the attachments in a vault and creates a sidecar file for each item to hold notes, tags and metadata. Media is searched by folder, tag, file type or visual color, which the recorded text states is done without AI.

```cue
plugin: {
    id:     "media-companion"
    name:   "Media Companion"
    author: "Nick"
    repo:   "nick-de-bruin/obsidian-media-companion"

    html_url:    "https://community.obsidian.md/plugins/media-companion"
    github_url:  "https://github.com/nick-de-bruin/obsidian-media-companion"
    description: "Creates a searchable gallery and sidecar files for attachments such as images and videos. The sidecar files allow you to add notes and tags to your media files."
    about:       "Create a browsable gallery of all media files and add editable sidecar files for each item to store notes, tags, and metadata. Search media by folder, tag, file type, or visual color (no AI) to quickly locate and organize assets."

    stats: {
        downloads:  7829
        updated_at: 1771962540000
    }
}
```
