# PDF++ Exporter

Exports annotations made with PDF++ back into the PDF file itself, writing native highlights and pop-up comments so the result opens in any standard viewer. Text highlights, rectangular selections and sticky-note popups are covered. The export is driven from the Markdown notes holding the annotations and runs standalone.

```cue
plugin: {
    id:     "pdfplus-exporter"
    name:   "PDF++ Exporter"
    author: "jldiaz"
    repo:   "jldiaz/pdfplus-exporter"

    html_url:    "https://community.obsidian.md/plugins/pdfplus-exporter"
    github_url:  "https://github.com/jldiaz/pdfplus-exporter"
    description: "Exports PDF++ annotations to PDF files. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Export PDF++'s annotated PDFs with native highlights and pop-up comments directly from your Markdown notes, writing highlights and comments back into the PDF so others can open them in any standard viewer. Support text highlights, rectangular selections, and sticky-note popups, with standalone operation."

    stats: {

}
```
