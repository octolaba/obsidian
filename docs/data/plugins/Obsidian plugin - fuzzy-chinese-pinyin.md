# Fuzzy Chinese Pinyin

Searches notes, tags, paths and headings by Chinese pinyin, either in full or by initials, with Traditional, double-pinyin and fuzzy-sound modes. Files and folders can be moved through a pinyin file picker, folder paths autocompleted, commands run and pinned from a pinyin command palette, templates inserted, and Chinese tag and backlink suggestions offered while typing.

plugin: {
    id:     "fuzzy-chinese-pinyin"
    name:   "Fuzzy Chinese Pinyin"
    author: "lazyloong"
    repo:   "lazyloong/obsidian-fuzzy-chinese"

    html_url:    "https://community.obsidian.md/plugins/fuzzy-chinese-pinyin"
    github_url:  "https://github.com/lazyloong/obsidian-fuzzy-chinese"
    description: "Fuzzy search using Chinese Pinyin."

Move files and folders with a pinyin file picker, autocomplete folder paths, run and pin commands from a pinyin command palette, insert templates, and get Chinese tag/backlink suggestions when typing # or in YAML."
