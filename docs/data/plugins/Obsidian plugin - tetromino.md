# Tetromino

Tetromino imports Are.na channels, blocks, metadata and attachments into the vault as stable, deterministic Markdown notes. Imports are run manually with dry-run previews, pagination and retry handling, and channel index notes plus a master Are.na overview are written. The flow is one-way, from Are.na into the vault only.

```cue
plugin: {
    id:     "tetromino"
    name:   "Tetromino"
    author: "Jonathan 'frostmute' Wagner"
    repo:   "frostmute/tetromino"

    html_url:    "https://community.obsidian.md/plugins/tetromino"
    github_url:  "https://github.com/frostmute/tetromino"
    description: "One-way import Are.na blocks and attachments into your vault as Markdown notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Import Are.na channels, blocks, metadata, and attachments into your vault as stable, deterministic Markdown notes. Run manual imports with dry-run previews, pagination and retry handling, and write channel index notes plus a master Are.na overview while keeping the flow one-way."

    stats: {
        downloads:  27
        updated_at: 1784199120000
    }
}
```
