# Tome

Tome searches books by ISBN or title across Google Books, Open Library and OpenAlex with automatic fallback between them, and downloads covers into the vault. Book details are written as frontmatter-first Markdown notes carrying reading status, ratings and progress, and a built-in gallery view works alongside Dataview and Obsidian Bases.
