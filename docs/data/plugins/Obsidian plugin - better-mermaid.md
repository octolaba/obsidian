# Better Mermaid

Better Mermaid opens a Mermaid diagram in a full-size frosted-glass modal when it is clicked in reading mode. The diagram can be panned and dragged, zoomed with Ctrl and the scroll wheel or through presets between 20 and 100 percent, and exported as a high-resolution PNG at twice the size, while custom CSS can be injected and the interface switched between English and Chinese. The About text also records a configurable default zoom level added in a recent version.

    id:     "better-mermaid"
    name:   "Better Mermaid"

Pan, drag and Ctrl+scroll to zoom with quick presets (20/50/75/100%), export high-resolution PNGs (2x), and inject custom CSS or switch UI language between English and Chinese."
