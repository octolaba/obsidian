# Yori Dashboard

Collects daily events, data logs, tasks, check-ins, moments, monthly plans and quick links on one editable dashboard with a mini-calendar, an events column and a weekly view. Metrics are tracked across months, moments are recorded with timestamps, tasks are grouped into category boxes, habit streaks show as colored check-ins, and quick links speed up navigation. It is described for desktop and mobile alike.
