# Visit History

Visit History records time spent in notes, canvases and Excalidraw drawings locally and offline, building a per-file visit history. Vault activity is visualized as a zoomable treemap heatmap where tile size follows file size and color follows recency or visit count. Filtering and drilling down surface hot, stale and untouched files.
