# Better Mind Map

Better Mind Map renders a Markdown outline as an interactive mind map inside Obsidian. The layout switches between vertical and horizontal, rank and node spacing are adjusted with sliders in the view, and the map can be panned, zoomed and collapsed or expanded per node. Links inside nodes open their notes, and the map follows edits to the outline.
