# OnlyWorlds Builder

OnlyWorlds Builder manages worldbuilding projects that follow the OnlyWorlds data standard from inside Obsidian. Elements are kept as notes in a dedicated OnlyWorlds folder, a full world is exported or copied as JSON, and worlds are uploaded to or imported from the OnlyWorlds framework.
