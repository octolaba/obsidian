# Google Tasks

Lists, creates, edits and marks Google Tasks as done or to-do from inside Obsidian. Unfinished tasks are inserted into notes, and lists are viewed and updated from a sidebar panel where completed tasks can be deleted. The recorded inputs note that specific task times are not supported by the Google API.
