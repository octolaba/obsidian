# Gyazo Viewer

Shows Gyazo captures in a sidebar gallery and embeds them into notes by drag and drop, with a detail preview exposing metadata and OCR text. Ready-to-use Markdown can be copied and context-menu actions apply to individual captures. Free accounts reach the latest ten captures and Pro accounts up to one hundred, and the interface is available in English and Japanese.
