# Calendar Period Week Notes

Calendar Period Week Notes provides a calendar grid for weekly and period-based notes, supporting 13-period four-week cycles or standard weeks, heatmaps, dot indicators and a scrollable vertical grid. Tabbed panels hold tasks, a scratchpad, pinned notes and asset views. Configurable widgets and charts assemble a dashboard for tracking task and project progress.
