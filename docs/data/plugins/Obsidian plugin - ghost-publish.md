# Ghost Publish

Publishes vault notes to a Ghost blog using configurable presets for tags, newsletter, canonical URL and publication status. A side panel manages those presets across Triage, Queue and Recent tabs, syncing only changed notes, uploading image embeds, resolving wikilinks, converting embeds to Ghost cards and recording post identifiers in frontmatter.
