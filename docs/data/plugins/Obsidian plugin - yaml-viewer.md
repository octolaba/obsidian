# YAML Viewer

Opens .yaml and .yml files read-only as a structured tree beside a raw source pane with syntax highlighting and line numbers. Entries are filtered by key, value or YAML path, an outline navigates the document, nodes expand and collapse, and node paths or raw YAML are copied out.

```cue
plugin: {
    id:     "yaml-viewer"
    name:   "YAML Viewer"
    author: "Viggo Meesters"
    repo:   "viggomeesters/obsidian-yaml-viewer"

    html_url:    "https://community.obsidian.md/plugins/yaml-viewer"
    github_url:  "https://github.com/viggomeesters/obsidian-yaml-viewer"
    description: "Browse .yaml and .yml files as a read-only tree with search, outline navigation, and syntax-highlighted source. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Browse .yaml/.yml files in a structured, read-only tree alongside a raw source pane with syntax highlighting and line numbers. Filter by key, value or YAML path, use the outline for quick navigation, expand/collapse nodes, and copy node paths or raw YAML."

    stats: {
        downloads:  765

    }
}
```
