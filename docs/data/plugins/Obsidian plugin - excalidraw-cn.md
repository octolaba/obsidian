# Excalidraw CN

A hand-drawn whiteboard built on Excalidraw that ships a Chinese handwritten font by default. Shapes link to Obsidian notes through double links, and table, mind map and markdown cards can be added. Multi-canvas layouts, cloud storage and custom fonts are supported.
