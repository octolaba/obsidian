# Reader Margins

Adds editable, draggable annotation cards to the margins of Obsidian's built-in PDF reader, created by highlighting or underlining text, with dashed connector lines back to the source. Annotations are saved as Markdown quote blocks in a per-PDF note, so they can be searched, synced and linked, and the display switches between margin cards and popovers while card positions are preserved.
