# LucrJournal

Records trades as local Markdown files and links each entry to its key levels, confluences, market analysis and news. Positions, playbooks, criteria, symbols, accounts and market analysis are managed in a dedicated workspace, trades carry execution, risk and account context, screenshots and chart evidence can be attached, and fields can be extracted with OCR. Performance is reviewed from dashboard views while everything stays as local Markdown and attachments.
