# Sync Todoist

Syncs Markdown tasks with Todoist in both directions, preserving nested outlines, labels, projects and local notes. Checkboxes tagged for Todoist become Todoist tasks, subtasks are linked automatically by ID, and filter queries are rendered live. The recorded inputs also name completed-task queries, inline query blocks, and populating a region of the daily note.
