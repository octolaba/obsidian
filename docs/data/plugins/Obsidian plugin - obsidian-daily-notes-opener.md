# Daily notes opener

Daily notes opener opens a daily or periodic note in a new pane, or focuses it when it is already open so it is not duplicated. An end-of-day time is set for correct midnight rollovers, a line can be appended to a specific section when the note opens, and the daily note pane coloured through Style Settings; periodic notes are supported.

```cue
plugin: {
    id:     "obsidian-daily-notes-opener"
    name:   "Daily notes opener"
    author: "reorx"
    repo:   "reorx/obsidian-daily-notes-opener"

    html_url:    "https://community.obsidian.md/plugins/obsidian-daily-notes-opener"
    github_url:  "https://github.com/reorx/obsidian-daily-notes-opener"
    description: "Easily open daily notes and periodic notes in new pane; customize periodic notes background; quick append new line to daily notes."
    about:       "Open today's daily note in a new pane or focus an already-open note to avoid duplicates. Set end-of-day time for correct midnight rollovers, append a line to a specific section when opening, and colorize the daily note pane via Style Settings; supports Periodic Notes."

    stats: {
        downloads:  8668
        updated_at: 1650253703000
    }
}
```
