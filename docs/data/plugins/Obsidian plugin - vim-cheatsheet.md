# Vim Cheatsheet

Vim Cheatsheet opens a searchable, categorized Vim command reference inside the app, alongside the built-in vim key bindings. More than 150 motions, operators, text objects and commands are listed with examples and word-by-word search. The reference shows as a modal or a pinned sidebar, follows the current theme and works on mobile.

```cue
plugin: {
    id:     "vim-cheatsheet"
    name:   "Vim Cheatsheet"
    author: "Rafael Mehdiyev"
    repo:   "rafaelmehdiyev/obsidian-vim-cheatsheet"

    html_url:    "https://community.obsidian.md/plugins/vim-cheatsheet"
    github_url:  "https://github.com/rafaelmehdiyev/obsidian-vim-cheatsheet"
    description: "Searchable, categorized vim command reference inside app. Works alongside the built-in vim key bindings. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open a searchable Vim command reference inside Obsidian. Browse 150+ motions, operators, text objects and commands with examples and word-by-word search. Display as a modal or pinned sidebar that follows your theme and works on mobile."

    stats: {
        downloads:  269
        updated_at: 1779881700000
    }
}
```
