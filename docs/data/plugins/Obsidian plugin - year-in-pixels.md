# Year in Pixels

Visualizes a frontmatter variable taken from daily notes as a yearly grid or a circular chart. Values map to hex colors and several date formats are accepted. The chart opens as a main tab or a compact sidebar, where hovering shows the exact date and a click opens the source note.

```cue
plugin: {
    id:     "year-in-pixels"
    name:   "Year in Pixels"
    author: "juanchiparra"
    repo:   "juanchiparra/obsidian-year-in-pixels"

    html_url:    "https://community.obsidian.md/plugins/year-in-pixels"
    github_url:  "https://github.com/juanchiparra/obsidian-year-in-pixels"
```
