# Note Companion Folder

Note Companion Folder gives each note its own folder of attachments, named after the note without its extension. Companion folders sit either beside their note or under a common base path, and they can be opened or created from the ribbon, a command, the context menu or file actions.

```cue
plugin: {
    id:     "note-companion-folder"
    name:   "Note Companion Folder"
    author: "vkodocha"
    repo:   "vkodocha/NoteCompanionFolder"

    html_url:    "https://community.obsidian.md/plugins/note-companion-folder"
    github_url:  "https://github.com/vkodocha/NoteCompanionFolder"
    description: "Manage a separate folder of attachments for each note."
    about:       "Store attachments in a dedicated companion folder for each note, named after the note without its extension. Place companion folders next to notes or under a common base path, and open or create them via ribbon, command, context, or file actions."
```
