# Rho Reader

Rho Reader stores every feed and every post as its own Markdown file in the vault. It reads RSS, Atom and JSON Feed content, imports and exports OPML, and uses tags to organize reading lists. Articles open either in the browser or inside Obsidian.

```cue
plugin: {
    id:     "rho-reader"
    name:   "Rho Reader"
    author: "Vishnu Bharathi"
    repo:   "scriptnull/rho-reader"

    html_url:    "https://community.obsidian.md/plugins/rho-reader"
    github_url:  "https://github.com/scriptnull/rho-reader"
    description: "Read and manage RSS feeds. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Store every feed and post as its own Markdown file in your vault. Read RSS, Atom, and JSON Feed content, import and export OPML, and tag posts to organize reading lists. Open articles in your browser or inside Obsidian."
```
