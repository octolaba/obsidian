# Line Count

Shows the number of lines in the active document in the status bar. The label text is customizable, so it can be set to lines, lineas, or a non-Latin equivalent to match the language in use. The recorded description notes that the plugin has not been manually reviewed by Obsidian staff.

```cue
plugin: {
    id:     "line-count-display"
    name:   "Line Count"
    author: "leolaurindo"
    repo:   "leolaurindo/line-count-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/line-count-display"
    github_url:  "https://github.com/leolaurindo/line-count-obsidian-plugin"
```
