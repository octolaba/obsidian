# Inline Encrypter

Inline Encrypter encrypts selected text into a code block inside the note, or inserts an already encrypted value, and exposes a clickable decrypt button in Reading and Live Preview modes. Decryption happens in place, or as a temporary view whose text can be copied to the clipboard. The plugin states that passwords are never stored and that decrypted content stays only in memory.
