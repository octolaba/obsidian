# Memo Lite

Captures fleeting notes and organizes them with tags, instant search, pins and in-place editing, storing each memo as a plain Markdown file in the vault. A GitHub-style activity heatmap reviews capture habits, memos are exported as styled PNG cards, and File Flow creates standalone note files from them. The recorded text states that the interface is currently Chinese-only.
