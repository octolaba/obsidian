# Crosslink Advanced

Manages ftags, the clones and symlinks used to tag files through folders, with commands that add or remove them. It also creates child notes by converting the current file into a folder note, opens a random inbox item, and renames a file while keeping the old name as an alias. File operations move files and update symlinks; the recorded inputs advise backing up the vault before use.
