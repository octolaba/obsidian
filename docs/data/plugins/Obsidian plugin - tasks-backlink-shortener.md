# Tasks Backlink Shortener

Tasks Backlink Shortener rewrites the backlink that the Tasks plugin displays under each task so that only the note basename is shown, dropping the folder path, the heading and the file extension. It changes nothing except those rendered backlinks.

```cue
plugin: {
    id:     "tasks-backlink-shortener"
    name:   "Tasks Backlink Shortener"
    author: "Serena"
    repo:   "vishae/tasks-backlink-shortener"

    html_url:    "https://community.obsidian.md/plugins/tasks-backlink-shortener"
    github_url:  "https://github.com/vishae/tasks-backlink-shortener"
    description: "Shortens the backlink the Tasks plugin displays under each task to just the note basename, instead of the full path, heading, and .md extension. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Shorten Tasks plugin backlinks to show only the note name, stripping folder path, heading, and the .md extension. Limit changes to backlinks rendered by Tasks and make no other modifications."

    stats: {
        downloads:  66
        updated_at: 1784309544000
    }
}
```
