# Text Alchemy

Cleans and normalizes a selection or a whole note into tidier Markdown. It removes line gaps, repairs wrapping and hyphenated breaks in text copied from PDFs, trims wiki links and whitespace, and removes duplicate lines. Lists can be converted or renumbered, heading spacing or dividers added, and lines or headings sorted, while YAML and fenced code blocks are left untouched.
