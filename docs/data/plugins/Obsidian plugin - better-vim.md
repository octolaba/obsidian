# Better Vim

Better Vim adjusts Obsidian's built-in Vim mode. Yanked text is highlighted, a bullet point is inserted on a new line, and yanks are copied to the system clipboard.

```cue
plugin: {
    id:     "better-vim"
    name:   "Better Vim"
    author: "Nils"
    repo:   "nilsgke/obsidian-better-vim"

    html_url:    "https://community.obsidian.md/plugins/better-vim"
    github_url:  "https://github.com/nilsgke/obsidian-better-vim"
    description: "Fixes some annoyances with the built in vim mode. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add enhancements to Obsidian's built-in Vim mode. Highlight yanked text, insert a bullet point on new lines, and copy yanks to the system clipboard."

    stats: {
        downloads:  474
        updated_at: 1780777084000
    }
}
```
