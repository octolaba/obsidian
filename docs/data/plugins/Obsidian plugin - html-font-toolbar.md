# HTML Font Toolbar

HTML Font Toolbar is a floating toolbar that writes each formatting change as a single inline HTML span rather than nested Markdown and HTML. It applies color and highlight presets, font size and family, bold, italic, underline and strikethrough, and table-aware alignment, merging repeated formatting into one span. Existing spans are edited or toggled in place and repaired, so a note renders identically without the plugin.
