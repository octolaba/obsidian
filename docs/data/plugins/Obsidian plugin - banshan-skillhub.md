# Banshan Skill Hub

Banshan Skill Hub discovers and imports AI agent skills from GitHub directories, local folders or permitted npx packages, and organizes them inside the vault. Imported skills are copied into the vault's Skill folder with collision-safe names, and selected skills are installed into agent workspaces under an agents skills directory by symlink or copy.
