# NodeFlow

NodeFlow renders node streams of the kind used by ComfyUI, Blender, Unreal Engine and Houdini, so notes about those tools can show their graphs. Diagrams are written in a lightweight grammar or loaded from exported JSON and embedded inline through Obsidian code blocks or canvas JSON. It also runs functional nodes covering text processing, web requests and AI workflows.
