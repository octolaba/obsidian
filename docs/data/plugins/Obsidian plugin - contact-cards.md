# Contact Cards

Contact Cards turns a YAML code block into a rendered contact card in preview mode. Profile photos and company logos are populated from an email address or from vault images, and the name, title, company, email, phone and location fields are shown and made clickable.

```cue
plugin: {
    id:     "contact-cards"
    name:   "Contact Cards"
    author: "aegixx"
    repo:   "aegixx/obsidian-contact-cards"

    html_url:    "https://community.obsidian.md/plugins/contact-cards"
    github_url:  "https://github.com/aegixx/obsidian-contact-cards"
    description: "Transforms YAML data into a simple business/contact card with power features."
    about:       "Render YAML contact-card code blocks as clean, interactive contact cards in preview mode. Populate profile photos and company logos from email or vault images, show name, title, company, email, phone and location, and make fields clickable."

    stats: {
        downloads:  1798

    }
}
```
