# Literature Review Synthesizer

Turns academic reading notes into structured literature review outputs using a chosen LLM and a locally held API key. The recorded outputs are thematic syntheses, methodological comparison matrices, research-gap analyses, and citation-ready draft sections, saved as new notes with frontmatter and backlinks. The recorded inputs state that data stays local.
