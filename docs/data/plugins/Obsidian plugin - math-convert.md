# Math Convert - Local Image-to-LaTeX

Math Convert turns image regions containing equations, such as photos, screenshots or clipboard images, into LaTeX formulas inside Obsidian. Inference runs locally through the compact FormulaNet model compiled to WebAssembly, so conversion happens offline. The recorded description states that no cloud service or subscription is involved and that data does not leave the device.
