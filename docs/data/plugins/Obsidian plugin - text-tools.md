# Local Text Tools

Local Text Tools exposes over eighty local text-manipulation commands in the Command Palette that transform a selection or an entire note, and works with single and multiple selections. Commands convert case, sort, shuffle and filter lines, encode and decode text, generate GUIDs, timestamps and random values, and format or extract with regular expressions. Five persistent text slots hold intermediate values.
