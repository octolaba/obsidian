# Root Folder Context Menu

Root Folder Context Menu adds the full folder context menu to the vault root and to the empty area of the Files pane. The folder actions available on any other folder become reachable from the vault root or from blank space in the sidebar.

```cue

    id:     "root-folder-context-menu"
    name:   "Root Folder Context Menu"
    author: "Michael Naumov"
    repo:   "mnaoumov/obsidian-root-folder-context-menu"

    html_url:    "https://community.obsidian.md/plugins/root-folder-context-menu"
```
