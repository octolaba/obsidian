# Copilot

Copilot is an in-vault AI assistant offering chat-based vault search, web and YouTube parsing, and the option to run OpenAI-compatible or local models while keeping data local. Webpages, videos, images, PDFs and EPUBs can be dropped in for contextual analysis, edits can be composed and applied, and AI-ready project contexts or agent workflows can be created.
