# Analogy - RAG in your vault

Indexes the vault with local vector embeddings and retrieves the notes relevant to a query, forming a local knowledge base. A connected language model then produces context-aware answers or concise summaries that reference those notes. The recorded description adds that this RAG search is also exposed to MCP clients.
