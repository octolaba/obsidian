# Cloudinary Uploader

Cloudinary Uploader uploads images pasted from the clipboard, and also video, audio and raw files, to a Cloudinary account instead of storing them locally. Cloudinary transformations are applied through custom parameters or a default transformation, single and multi-file uploads are handled, and unsigned uploads avoid storing an API secret.
