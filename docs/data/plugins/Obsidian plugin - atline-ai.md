# AtLine AI

Sends inline questions to a language model from custom triggers and a hotkey, streaming the response straight into the note. Providers are reachable over API or CLI, including Claude, OpenAI, Google and local Ollama models, and wikilinked notes can be pulled in as context. Agents with custom prompts can be defined.

    id:     "atline-ai"
    name:   "AtLine AI"
    author: "ergesmema"

    github_url:  "https://github.com/ergesmema/obsidian-atline-ai"
