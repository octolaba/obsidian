# BuJo Bullets

BuJo Bullets renders alternate checkbox types for Bullet Journal notation — incomplete, completed, irrelevant, migrated, scheduled and events — in reading mode. Bullet types are changed from a right-click menu, commands or hotkeys, and signifiers such as an exclamation or question mark are highlighted for quick context.
