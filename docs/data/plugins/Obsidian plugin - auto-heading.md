# Auto Heading

Auto Heading numbers headings in real time and writes the numbers into the Markdown file, so they appear in the sidebar table of contents, in PDF exports and on Obsidian Publish. Numbering supports Arabic digits, uppercase and lowercase letters and Roman numerals at any level, and styles can be mixed freely. A visual-only overlay is available instead when the files themselves must stay unchanged.

    id:     "auto-heading"
    name:   "Auto Heading"

    description: "Automatic heading numbering with burn-in for TOC/PDF/Publish, visual-only decorations, per-note control, and smart detection of existing numbers. - This plugin has not been manually reviewed by Obsidian staff."
