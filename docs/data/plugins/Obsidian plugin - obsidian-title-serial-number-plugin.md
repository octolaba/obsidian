# Title Serial Number Plugin

Serial numbers are added to Markdown headings in seven styles, among them Arabic, Roman, Chinese and alphabetic. The heading levels to number, a per-level style and a custom separator are configurable, changes are previewed live, and numbers are applied or cleared across a document.

```cue
plugin: {
    id:     "obsidian-title-serial-number-plugin"
    name:   "Title Serial Number Plugin"
    author: "yalvhe2009"
    repo:   "yalvhe2009/obsidian-title-serial-number-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-title-serial-number-plugin"
    github_url:  "https://github.com/yalvhe2009/obsidian-title-serial-number-plugin"
    description: "Add serial numbers to your Markdown title."
    about:       "Add serial numbers to Markdown headings with seven styles including Arabic, Roman, Chinese, and alphabetic. Choose which heading levels to number, set per-level styles and a custom separator, preview changes live, and apply or clear numbers across a document."
```
