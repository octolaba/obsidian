# Tufte Figures

Inserts Tufte-style figures by dropping an image into a note, producing column, full-width or margin figures with captions and adjustable size. Multi-image rows and an image-quilt generator are included, along with click-to-enlarge, edit-at-cursor, and auto-numbered clickable references. Figures are rendered in Reading view.

    id:     "tufte-figures"
    name:   "Tufte Figures"
