# Language Learn

Language Learn analyses a selected word or phrase with an AI model and writes a structured note recording part of speech, pronunciation, morphology, derivations and contextual example sentences. Meanings and etymology can be previewed on hover, a note can be reinterpreted in context, and known vocabulary is highlighted in place. It also provides an AI chat sidebar and generates verified synonym, antonym and cognate relationships that form the relation graph named in its description.
