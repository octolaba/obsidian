# Engram Vault Sync

Synchronises a vault across devices through a hosted or self-hosted Engram server and exposes it to AI applications such as Claude and Cursor, which can read and write notes. Notes stay plain Markdown in ordinary folders, ideas are found by description rather than by exact title, conflicting edits are merged or kept side by side, and offline changes replay on reconnection. Its recorded About states that notes travel only to the Engram server configured and are not sold, analysed or used to train a model.
