# Dotpass

Controls which files and folders appear in the Obsidian file explorer, including dot-prefixed items such as .git or .env that are normally hidden. Rules match by name, path, glob or regex, follow their targets after a move, and can be reordered by dragging. Settings stay local, and revealing dotfiles requires the desktop app.
