# Definitions detector

Scans the active note for words that match notes kept in a definitions folder and replaces them with links to those definition files. Definition notes may be organized in nested subfolders up to four levels deep.

```cue
plugin: {
    id:     "definitions-detector"
    name:   "Definitions detector"
    author: "rapphcd"
    repo:   "rapphcd/definitions-detector"

    html_url:    "https://community.obsidian.md/plugins/definitions-detector"
    github_url:  "https://github.com/rapphcd/definitions-detector"
    description: "Auto-detects all definitions of your texts and creates links. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Scan the active note for words that match definition notes and automatically replace them with links to those definition files stored in your definitions folder. Support nested definitions organized up to four subfolders."

    stats: {
        downloads:  108
        updated_at: 1779394458000
    }
}
```
