# Unread Badge

Shows a dot badge beside a file or folder in the file explorer when a note has not been opened since it was last modified. Opening the note marks it read, and context-menu actions and commands toggle read state for a file, for a folder recursively, or for every note.

```cue
plugin: {
    id:     "unread-badge"
    name:   "Unread Badge"
    author: "dzplnk"
    repo:   "dzplnk/obsidian-unread-badge"

    html_url:    "https://community.obsidian.md/plugins/unread-badge"
    github_url:  "https://github.com/dzplnk/obsidian-unread-badge"
    description: "Shows an unread badge next to notes and folders that haven't been opened since they were last modified. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Show a dot badge next to files and folders in the file explorer when a note hasn't been opened since it was last modified. Mark notes read by opening them or use context-menu actions and commands to toggle read/unread per file, folder (recursive), or all notes."

    stats: {
        downloads:  154

    }
}
```
