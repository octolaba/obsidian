# Paragraph Break

Changes Obsidian's default Enter behaviour so that a single Enter starts a new paragraph, as in an ordinary text editor, instead of a soft line break. Lists and code blocks are not affected and keep their standard behavior.

```cue
plugin: {
    id:     "paragraph-break"
    name:   "Paragraph Break"
    author: "Mateusz Nitka"
    repo:   "mateusznitka/obsidian-paragraph-break"

    html_url:    "https://community.obsidian.md/plugins/paragraph-break"
    github_url:  "https://github.com/mateusznitka/obsidian-paragraph-break"
    description: "Create new paragraph after hitting Enter once instead of twice. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Simple plugin to change default Obsidian Enter behaviour: Single Enter creates a new paragraph just like in \"normal\" text editor instead of a soft line break. Lists or code blocks are not affected, so they keep their standard behavior."

    stats: {
        downloads:  271
        updated_at: 1779376368000
    }
}
```
