# Latex Render

Latex Render turns LaTeX-marked code blocks into SVG images shown inline in note preview, so that small snippets stay crisp and scalable. Rendering is delegated to the local LaTeX toolchain through a configurable conversion command that produces SVG from a .tex file.

```cue
plugin: {
    id:     "latex-render"
    name:   "Latex Render"
    author: "jvsteiner"
    repo:   "jvsteiner/obsidian-latex-render"

    html_url:    "https://community.obsidian.md/plugins/latex-render"
    github_url:  "https://github.com/jvsteiner/obsidian-latex-render"
    description: "Render small latex snippets in your notes as SVG and PNG files."
    about:       "Render LaTeX-marked code blocks into SVG and display them inline in note preview. Use your LaTeX toolchain by specifying a conversion command to generate SVG from .tex files, keeping mathematical output crisp and scalable."

    stats: {

}
```
