# Skill and Harness Manager

Skill and Harness Manager, recorded as macOS only, uses Obsidian as a consolidated location for agents, skills, commands and harnesses. Skills are browsed, tagged, managed and launched from ribbon icons or the right-click command palette, and a skill management pane configures each skill and assigns the harness and agent that runs it when invoked. Its recorded About text gives formatting Markdown files to a specification, processing audio files into transcriptions and running daily automations as example uses.
