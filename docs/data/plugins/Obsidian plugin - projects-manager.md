# Projects Planner

Manages projects held in plain Markdown through a kanban-style sidebar with Planning, Active, On Hold, and Complete columns. Projects are created with a name, status, due date and priority; milestones are added, percent-complete updates logged, progress bars and priority badges shown on the cards, and finished projects archived.

plugin: {
    id:     "projects-manager"
    name:   "Projects Planner"
    author: "wesswart77"
    repo:   "wesswart77/obsidian-project-manager"

    html_url:    "https://community.obsidian.md/plugins/projects-manager"
    github_url:  "https://github.com/wesswart77/obsidian-project-manager"
    description: "Manage projects in plain markdown: track status, milestones, tasks, and progress with a kanban-style sidebar view. - This plugin has not been manually reviewed by Obsidian staff."

Create projects with name, status, due date and priority; add milestones, log percent-complete updates, view progress bars and priority badges on cards, and archive projects."
