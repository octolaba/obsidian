# MrDoc

Synchronizes Markdown files and folder structures between the vault and MrDoc collections, using mappings and timestamps to decide updates and avoid accidental overwrites. Notes are browsed and edited offline in Obsidian, then pushed or pulled so MrDoc serves them for online viewing and management.
