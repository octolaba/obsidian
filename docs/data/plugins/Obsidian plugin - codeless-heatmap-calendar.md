# Codeless Heatmap Calendar

Codeless Heatmap Calendar visualizes Toggl time entries as a heatmap calendar inside Obsidian, with fake data available for testing. Several instances can be configured independently, each with its own theme, color gradient, layout and tooltip styling, project filters, streaks, statistics and billable-hours tracking.
