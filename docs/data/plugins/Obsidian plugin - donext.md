# Do Next Task

Marks the first unchecked task in the current note and appends the completion time in HH:MM format. Cursor and scroll position are preserved, and both dash and asterisk task syntaxes are recognised at any indentation level.

```cue
plugin: {
    id:     "donext"
    name:   "Do Next Task"
    author: "alexesdev"
    repo:   "alexesdev/donext"

    html_url:    "https://community.obsidian.md/plugins/donext"
    github_url:  "https://github.com/alexesdev/donext"
    description: "Mark the first uncompleted task in the current note with timestamp. Your monkey should just do a next task. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Mark the next unchecked task in the current note and append the completion time in HH:MM format. Preserve cursor and scroll position and support both - [ ] and * [ ] task formats at any indentation level."

    stats: {
        downloads:  102
        updated_at: 1762960943000
    }
}
```
