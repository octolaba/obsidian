# Note Image Manager

Note Image Manager covers the image workflow around notes: pasted or external images are imported into a managed folder, converted between formats including AVIF, compressed, renamed and lightly edited. Operations run in batches, galleries can be opened, orphan files cleaned up, and moves and renames kept in sync. Actions are recorded in a persistent history with undo and redo, so earlier steps can be recovered.
