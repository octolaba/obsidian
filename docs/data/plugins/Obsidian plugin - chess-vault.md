# Chess Vault

Chess Vault pulls games from Lichess and Chess.com into the vault as embedded boards that are viewed and analyzed inside the notes. Games go to a single file or to daily files with incremental sync, optional date or rating prefixes and automatic folder creation. Daily frontmatter records statistics for wins, losses, draws and win rate.
