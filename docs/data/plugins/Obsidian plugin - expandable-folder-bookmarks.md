# Bookmark Folder Expand

Expands bookmarked folders inline in the Bookmarks pane and reveals subfolders recursively, so files can be reached without switching to the File Explorer. Files open in the current tab or a new one, the active file is highlighted, and existing theme styling is kept; everything stays inside the local vault.

```cue
plugin: {
    id:     "expandable-folder-bookmarks"
    name:   "Bookmark Folder Expand"
    author: "Samuel-YSZ"
    repo:   "samuel-ysz/expandable-folder-bookmarks"

    html_url:    "https://community.obsidian.md/plugins/expandable-folder-bookmarks"
    github_url:  "https://github.com/samuel-ysz/expandable-folder-bookmarks"
```
