# NoteRelay

Formats the current Markdown note for WeChat Official Accounts, Xiaohongshu and X, producing a preview and clipboard content for each. The outputs are inline-styled HTML for WeChat, high-resolution 3:4 card images as PNG or ZIP for Xiaohongshu, and rich text or plain text plus a media list for X. Multiple accounts, themes and templates can be previewed, and the recorded description states that the plugin does not log into any platform or publish automatically — the user pastes the result into the target editor.

plugin: {
    id:     "noterelay"
    name:   "NoteRelay"
    author: "super meng"
    repo:   "x-supermeng/noterelay"

    html_url:    "https://community.obsidian.md/plugins/noterelay"
    github_url:  "https://github.com/x-supermeng/noterelay"
    description: "将 Obsidian 笔记排版后复制到公众号、小红书和 X。 - This plugin has not been manually reviewed by Obsidian staff."
    about:       "生成适合微信公众号、小红书和 X 的平台预览与剪贴板内容，将当前 Markdown 笔记转换为带内联样式的 HTML（公众号）、3:4 高清卡片 PNG/ZIP（小红书）和富文本/纯文本加媒体清单（X）。 预览多账号、主题与模板并复制或导出准备粘贴到目标编辑器；不登录平台或自动发布，所有发布由用户在目标平台完成。"
