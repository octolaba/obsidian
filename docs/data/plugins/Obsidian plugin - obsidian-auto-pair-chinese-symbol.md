# Auto pair chinese symbol

Auto pair chinese symbol pairs Chinese punctuation automatically as it is typed, covering bracket, parenthesis, corner-bracket and quotation forms. A matching pair is deleted together, selected text can be wrapped with a pair, ignore lists are supported, and single and double quotes auto-complete forward.

```cue
plugin: {
    id:     "obsidian-auto-pair-chinese-symbol"
    name:   "Auto pair chinese symbol"
    author: "renmu123"
    repo:   "renmu123/obsidian-auto-pair-chinese-symbol"

    html_url:    "https://community.obsidian.md/plugins/obsidian-auto-pair-chinese-symbol"
    github_url:  "https://github.com/renmu123/obsidian-auto-pair-chinese-symbol"
    description: "Auto-pair Chinese symbols."
    about:       "Pair Chinese punctuation such as 《》、【】、（）、‘’、“”、「」 automatically as you type. Delete matching pairs together, wrap selected text with pairs, support ignore lists, and auto-complete single and double quotes forward."
```
