# Transcription Audio

Transcription Audio transcribes audio files linked or embedded in the active note with Google Gemini and inserts structured Markdown holding the full transcript and a summary at the cursor. A right-hand progress panel reports the filename, upload and API timings, the Gemini prompt, output and token logs, and offers a cancel button while processing runs.

plugin: {
    id:     "transcription-audio"
    name:   "Transcription Audio"
    author: "cha-yh"
    repo:   "cha-yh/transcription-audio-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/transcription-audio"
