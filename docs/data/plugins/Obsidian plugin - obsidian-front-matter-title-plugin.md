# Front Matter Title

Displays a value taken from YAML frontmatter as the title of a file in the file explorer and the graph. A template path with dot notation selects the key, whether string, number or array, and its value is shown without renaming the file itself.

```cue
plugin: {
    id:     "obsidian-front-matter-title-plugin"
    name:   "Front Matter Title"
    author: "snezhig"
    repo:   "snezhig/obsidian-front-matter-title"

    html_url:    "https://community.obsidian.md/plugins/obsidian-front-matter-title-plugin"
    github_url:  "https://github.com/snezhig/obsidian-front-matter-title"
    description: "Define a title in frontmatter to be displayed as the filename."
    about:       "Display YAML front-matter values as file titles in the file explorer and graph. Use a template path with dot-notation to select keys (string, number, or array) and show their value without renaming files."
```
