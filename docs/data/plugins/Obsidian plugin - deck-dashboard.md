# Deck

Opens .dashboard files in a custom view where widget slots are arranged in a draggable grid. The index description names tasks, Dataview queries, Bases, notes, calendar and mail as the intended widgets, while the directory text describes the current state as a first-phase scaffold with those widgets not yet implemented.
