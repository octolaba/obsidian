# SketchMatter

Renders SVG images from objects, layers and views defined in a note's frontmatter, using built-in shapes - polygon, polyline, line, circle, rect, ellipse and text - plus custom type definitions for maps, diagrams and illustrations. A live panel previews and edits the drawing with drag-and-drop, a grid, zoom and pan, layer ordering and filtering, masks and noise. The result can be exported as SVG or embedded inline in the note.
