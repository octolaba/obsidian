# Note Database

Note Database builds database views over note frontmatter and shows notes as a table, board, gallery, list, chart, calendar or timeline, with inline edits written back into the Markdown frontmatter. Fields can be computed with formulas, and views filtered, sorted, grouped or embedded read-only, and the data exchanged as CSV, Markdown ZIP or XLSX. The recorded description states that it is local-first and that data stays local.
