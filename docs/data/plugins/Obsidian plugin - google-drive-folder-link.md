# Google Drive Folder Link

Attaches a Google Drive folder to a note through fuzzy search and stores the association in the note's frontmatter. The search covers configured root folders in My Drive and in Shared Drives, and the linked folder opens with one click from the note's Properties pane.

```cue
plugin: {
    id:     "google-drive-folder-link"
    name:   "Google Drive Folder Link"
    author: "andrewmarconi"
    repo:   "andrewmarconi/GoogleDriveFolderLink"

    html_url:    "https://community.obsidian.md/plugins/google-drive-folder-link"
    github_url:  "https://github.com/andrewmarconi/GoogleDriveFolderLink"
    description: "Attach a Google Drive folder to any note via fuzzy search. Search across configured root folders in My Drive and Shared Drives, and access linked folders with one click from the note's properties pane. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Attach a Google Drive folder to a note via fuzzy search and save the association in the note’s frontmatter. Search across My Drive and Shared Drives roots and open linked folders with one click from the note’s Properties pane."

    stats: {
        downloads:  254

    }
}
```
