# Galaxy View

Presents the vault as a three-dimensional graph in which notes are luminous nodes and links form filament trails, with a camera that glides and orbits between them. Real-time physics reshapes the layout, a focus mode spotlights a neighborhood, fuzzy search navigates between notes, and the visuals follow the dark or light theme.
