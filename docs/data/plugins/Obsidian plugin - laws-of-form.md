# Laws of Form

This plugin renders Laws of Form bracket expressions, such as ((a)) (b) = a (b), as two-dimensional diagrams from lof code blocks. Nested distinctions, crosses and re-entries written with $id and [id] are supported, including multiple re-entries, and separators keep plain text and equations apart.

```cue
plugin: {
    id:     "laws-of-form"
    name:   "Laws of Form"
    author: "kevger"
    repo:   "kevger/obsidian-laws-of-form"

    html_url:    "https://community.obsidian.md/plugins/laws-of-form"
    github_url:  "https://github.com/kevger/obsidian-laws-of-form"
    description: "Create, manage and display Laws of Form expressions like ((a)) (b) = a (b)."
    about:       "Render Laws of Form bracket expressions into two-dimensional graphical diagrams directly from lof code blocks. Support nested distinctions, crosses and re-entries using $id and [id], multiple re-entries, and separators to mix plain text and equations cleanly."
```
