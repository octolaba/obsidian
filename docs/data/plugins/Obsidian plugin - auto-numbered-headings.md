# Auto Numbered Headings

Auto Numbered Headings numbers headings in real time as you type and writes the numbers into the Markdown itself, so the numbering is preserved across editors and exports. A section is activated by prefixing its heading with a number and a dot, and the hierarchy is renumbered when sections are moved, added or deleted.

```cue
plugin: {
    id:     "auto-numbered-headings"
    name:   "Auto Numbered Headings"
    author: "Yu Zou"
    repo:   "yu-zou/obsidian-auto-numbered-headings"

    html_url:    "https://community.obsidian.md/plugins/auto-numbered-headings"
    github_url:  "https://github.com/yu-zou/obsidian-auto-numbered-headings"
    description: "Automatically numbers headings in your Markdown notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Auto-number headings in real time as you type, writing numbers directly into your Markdown so numbering is preserved across editors and exports. Activate a section by prefixing its heading with a number and dot (e.g. \"# 1. Title\"); support hierarchical renumbering when moving, adding, or deleting sections."

    stats: {
        downloads:  632
        updated_at: 1785690231000
    }
}
```
