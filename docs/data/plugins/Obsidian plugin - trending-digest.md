# Trending Digest

Aggregates trending items from more than twenty sources, among them GitHub, Hacker News, Medium, arXiv, Reddit and X via Nitter, and scores each one with AI on relevance, usefulness, novelty and popularity. A daily curated Markdown digest is written into the vault with summaries, scores, tags and frontmatter. Runs are scheduled or triggered manually and filtered by focus area, and a repeat run appends new items instead of overwriting.
