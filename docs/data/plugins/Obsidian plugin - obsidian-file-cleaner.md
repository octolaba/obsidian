# File Cleaner

Finds empty files, meaning zero bytes or whitespace only, and locates unused attachments across the vault in jpg, jpeg, png, gif, svg and pdf formats. What it finds is deleted or moved to the system trash or to the Obsidian trash to reclaim space.

```cue
plugin: {
    id:     "obsidian-file-cleaner"
    name:   "File Cleaner"
    author: "johnsonhong997"
    repo:   "johnsonhong997/obsidian-file-cleaner"

    html_url:    "https://community.obsidian.md/plugins/obsidian-file-cleaner"
    github_url:  "https://github.com/johnsonhong997/obsidian-file-cleaner"
    description: "Clean empty files and unused attachments in your vault."
    about:       "Clean empty files (zero bytes or only whitespace) and locate unused attachments — jpg, jpeg, png, gif, svg, pdf — across your vault. Delete or move found items to system or Obsidian trash to tidy and reclaim space."
```
