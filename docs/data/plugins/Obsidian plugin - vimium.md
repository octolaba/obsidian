# Vimium

Vimium marks clickable elements with keyboard labels in the spirit of Vim, so pressing the shown keys activates a link or a button. The CSS selectors that are scanned can be customized, and the marker font size is adjustable for readability.

```cue
plugin: {
    id:     "vimium"
    name:   "Vimium"
    author: "karstenpedersen"
    repo:   "karstenpedersen/obsidian-vimium"

    html_url:    "https://community.obsidian.md/plugins/vimium"
    github_url:  "https://github.com/karstenpedersen/obsidian-vimium"
    description: "Interact with elements using keyboard shortcuts in the spirit of Vim."
    about:       "Show Vimium-style markers on clickable elements and press the corresponding keys to activate links and buttons. Customize the CSS selectors scanned and change marker font size for better readability."

    stats: {
        downloads:  9418
        updated_at: 1718992305000
    }
}
```
