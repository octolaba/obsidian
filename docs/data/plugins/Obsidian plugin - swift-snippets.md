# SwiftSwitch

Switches CSS snippets, themes and light or dark mode from a status bar popup and a floating button rather than from the settings pane. The recorded inputs describe snippet grouping and drag reordering, eye-care modes including five breathing effects such as 4-7-8 and Box breathing, and holding Ctrl while scrolling to move through installed themes. Auto-switching by page can change snippets, themes and mode while notes are navigated, and the interface is multi-language.
