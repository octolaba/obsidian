# Intelligence Assistant

Intelligence Assistant adds a streaming chat over the vault with provider and model badges, token usage display and configurable agents across several LLM providers. Notes can be indexed for RAG, and agents can be backed by CLI tools or MCP, call web search, or call OpenAPI and HTTP tools. Files and vault references can be attached to a message.
