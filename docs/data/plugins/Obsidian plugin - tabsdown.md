# Tabsdown

Turns a fenced Markdown block into a set of tabs styled by the active theme. Ordinary Markdown goes inside the tabs, including queries, embeds, callouts, math, Mermaid diagrams and content from compatible community plugins. Tabs work in Reading View and Live Preview, support keyboard navigation and mobile touch input, and expose optional Style Settings controls.
