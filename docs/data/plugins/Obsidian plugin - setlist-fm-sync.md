# Setlist.fm Sync

Setlist.fm Sync pulls attended concerts from setlist.fm into one Obsidian note. Each show gets a date-specific backlink and city backlinks track the places visited, kept as a bulleted list in the note Setlist Concerts Attended. A setlist.fm API key is required.

```cue
plugin: {
    id:     "setlist-fm-sync"
    name:   "Setlist.fm Sync"
    author: "fleker"
    repo:   "fleker/setlist-for-obsidian"

    html_url:    "https://community.obsidian.md/plugins/setlist-fm-sync"
    github_url:  "https://github.com/fleker/setlist-for-obsidian"
    description: "Syncs your setlist.fm attended concerts."
    about:       "Sync attended concerts from setlist.fm into a single Obsidian note, creating date-specific backlinks for each show. Add city backlinks to track places you've visited and keep a bulleted, readable list in Setlist Concerts Attended.md (requires setlist.fm API key)."

    stats: {
        downloads:  244
        updated_at: 1733421207000
    }
}
```
