# ESQL Syntax

Adds syntax highlighting for Elasticsearch ES|QL inside fenced code blocks, in Reading View, Live Preview and source mode on desktop and mobile. Directives, commands, functions, fields, strings, literals and operators are recognized and colored from the current theme's code colors. It highlights esql blocks and templates only, and does not execute them.
