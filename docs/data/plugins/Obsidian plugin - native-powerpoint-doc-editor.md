# Native PowerPoint Doc Editor

Opens, views and edits .docx and .pptx files inside the vault, keeping Office files in place instead of converting them to Markdown. Word documents and PowerPoint decks are searchable, and slide text, tables, charts and shapes are editable for supported decks. Files can be exported or duplicated, and save conflicts and hidden text are detected.
