# Kanban for Professionals

Local-first Kanban and project boards that read and write the same on-disk Markdown format used by the community Kanban plugin, so existing boards are preserved. Board, table and list views with templates are free, while an optional paid Pro tier adds recurrence, time tracking and calendar export. The plugin states that data stays local and offline.
