# Markdown Spreadsheets

Opens the Markdown tables of a note in a spreadsheet-style grid in a dedicated tab, with cells rendered as they appear in the note and raw Markdown editing one click away. Edits are written back as strictly valid GitHub-Flavored Markdown with column alignment preserved. A selection reports its sum, average and count, one-off calculations can be run, and tables can be exported to CSV or Excel.
