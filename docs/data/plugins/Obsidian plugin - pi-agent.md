# Pi Agent

Pi Agent puts a Pi chat in an Obsidian sidebar with context drawn from the current note, linked notes, backlinks, tags, metadata, headings and the current selection. Chat, Review, Edit and Full agent modes control which tools Pi may use. Diffs can be reviewed, notes created from answers, responses copied, and cited notes opened.

```cue
plugin: {
    id:     "pi-agent"
    name:   "Pi Agent"
    author: "Christian Lempa"
    repo:   "christianlempa/obsidian-pi"

    html_url:    "https://community.obsidian.md/plugins/pi-agent"
    github_url:  "https://github.com/christianlempa/obsidian-pi"
    description: "Chat with Pi using context from your notes, links, backlinks, tags, and search results. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Chat with Pi in an Obsidian sidebar using context from the current note, linked notes, backlinks, tags, metadata, headings and selected text. Pick Chat, Review, Edit or Full agent modes to control Pi's tools, review diffs, create notes from answers, copy responses and open cited notes."

    stats: {

}
```
