# Inline Note

Inline Note expands a wikilink into an editable note body shown inline beneath the link. Pressing tab after a link creates the inline note, and tab also toggles between expanded and collapsed. Inline notes nest up to five levels, and their presentation can be styled as cards or with a vertical accent line.
