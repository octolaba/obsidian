# Stashpad Classic

This is a fork of the Stashpad plugin, published so that users who are not on Insider builds can run it. Notes are captured in a chat-style composer that stacks entries and can split them on newlines, and content is organized as an arbitrarily deep outliner. Notes export to Open Knowledge Format for language models and agents. The recorded inputs state that this version targets the latest stable Obsidian release and omits the encryption features of the other one.
