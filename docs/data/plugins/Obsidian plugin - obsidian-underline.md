# Underline

A shortcut wraps the selection in underline tags, inserts an empty pair when nothing is selected, and removes them again from text already underlined. The same mechanism applies other wrapper pairs, heading anchors and block references, and custom wrappers can be defined.

```cue
plugin: {
    id:     "obsidian-underline"
    name:   "Underline"
    author: "benature"
    repo:   "benature/obsidian-underline"

    html_url:    "https://community.obsidian.md/plugins/obsidian-underline"
    github_url:  "https://github.com/benature/obsidian-underline"
    description: "Add underline with shortcut."
    about:       "Add underline formatting by wrapping text in <u>...</u>, insert an empty underline when no selection, and toggle/remove underline on selected underlined text. Apply other wrapper pairs like <center>...</center>, heading anchors ([[#heading]]) and block refs ([[#^block]]), and support custom wrappers."

    stats: {
        downloads:  65635
        updated_at: 1710744866000
    }
}
```
