# Stream Embed

Converts pasted Spotify and YouTube links into embedded players inside notes. A link pasted on an empty line renders immediately, covering tracks, albums, playlists, videos, shorts, live streams and timestamped links. The YouTube embed keeps a responsive aspect ratio, and the Spotify embed height is configurable.

```cue
plugin: {
    id:     "stream-embed"
    name:   "Stream Embed"
    author: "devsdocs"
    repo:   "devsdocs/obsidian_media_embed"

    html_url:    "https://community.obsidian.md/plugins/stream-embed"
    github_url:  "https://github.com/devsdocs/obsidian_media_embed"
    description: "Automatically convert pasted Spotify and YouTube links into embedded players. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert pasted Spotify and YouTube links into playable embedded players inside Obsidian notes. Paste a link on an empty line to instantly render tracks, albums, playlists, videos, shorts, live streams and timestamped links, with responsive YouTube aspect ratio and configurable Spotify height."

    stats: {
        downloads:  1
        updated_at: 1786474166000
    }
}
```
