# Text Snippets

Text Snippets expands custom text shortcuts into longer templates to speed up typing. Cursor placement is controlled with an end marker, line breaks with a newline marker, and multi-step expansions move between tab stops, with replacements shown in live preview.

```cue
plugin: {
    id:     "text-snippets-obsidian"
    name:   "Text Snippets"
    author: "arianakhit"
    repo:   "arianakhit/text-snippets-obsidian"

    html_url:    "https://community.obsidian.md/plugins/text-snippets-obsidian"
    github_url:  "https://github.com/arianakhit/text-snippets-obsidian"
    description: "Snippets for faster typing. Replace text templates, create your own, and expand text shortcuts."
    about:       "Create and expand custom text snippets and templates to speed up typing in Obsidian notes. Control cursor placement with $end$, insert line breaks with $nl$, and jump between tab stops with $tb$ for multi-step expansions, with live preview of replacements."
```
