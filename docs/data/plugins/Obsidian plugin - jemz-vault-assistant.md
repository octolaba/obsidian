# Jemz Vault Assistant

Combines capture, vault health and retrieval in a single dashboard. Captured items are triaged from a keyboard-driven inbox where they can be processed, converted, moved, tagged, linked, archived or deleted. Vault scans find broken links, orphan and empty notes, unused attachments, duplicates, misspelled tags and missing properties and offer fixes, while notes are retrieved through saved views and visual filters; it runs fully locally.
