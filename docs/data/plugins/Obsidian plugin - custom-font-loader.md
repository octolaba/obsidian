# Custom Font Loader

Loads custom fonts into the vault on all platforms, including Android and iOS, by embedding the font files as base64 so no operating-system installation is needed. It supports .woff, .woff2, .ttf and .otf, previews and switches fonts, applies them globally or per page, and converts fonts to base64 CSS through the web tool.
