# Sync Embeds

Turns static embeds into blocks that are edited in place, with two-way syncing back to the source file. Section-specific embeds written with the standard note and header anchor form are supported. The recorded About text also names keyboard shortcut support, dynamic date and title patterns, custom display names, and instant saving.

    name:   "Sync Embeds"
