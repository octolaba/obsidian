# Folder Index

Generates an index file, a map of content, for a folder and its subfolders and opens it when the folder is clicked; the index is renamed when its folder is renamed. Files and headings are linked and sorted alphabetically, index content is injected with the folder-index-content block, and folders are shown in the graph view. A title in frontmatter overrides the index filename.

```cue
plugin: {
    id:     "obsidian-folder-index"
    name:   "Folder Index"
    author: "turulix"
    repo:   "turulix/obsidian-folder-index"

    html_url:    "https://community.obsidian.md/plugins/obsidian-folder-index"
    github_url:  "https://github.com/turulix/obsidian-folder-index"
    description: "Automatically generate a Map of Content for the current Folder and Subfolders."
    about:       "Generate automatic index files for folders and open them on click; rename index files when folders are renamed. Link and alphabetically sort files and headings, inject index content with the folder-index-content block, and show folders in the Graph View. Respect the title frontmatter to override the index filename."
```
