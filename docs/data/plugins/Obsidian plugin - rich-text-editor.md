# Rich Text Editor

Rich Text Editor is a rich text Markdown editor for Obsidian built on MDXEditor. The recorded About describes it as a writing experience that keeps the capabilities of Markdown without showing raw syntax, and states that the author made it because editing text quickly on a phone had become cumbersome.
