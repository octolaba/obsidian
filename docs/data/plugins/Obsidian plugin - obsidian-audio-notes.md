# Audio Notes

Audio Notes creates notes for podcasts and other audio files and generates transcripts while listening, so passages can be captured as they play. A time-synced audio callout embeds a player and holds a quoted excerpt, with quotes auto-generated from a transcript. Start and end times and playback speed are set per callout, and live updating makes the note follow playback.

```cue
plugin: {
    id:     "obsidian-audio-notes"
    name:   "Audio Notes"
    author: "jjmaldonis"
    repo:   "jjmaldonis/obsidian-audio-notes"

    html_url:    "https://community.obsidian.md/plugins/obsidian-audio-notes"
    github_url:  "https://github.com/jjmaldonis/obsidian-audio-notes"
    description: "Create notes for podcasts and audio files, and automatically generate transcripts while listening so you can quickly take notes on the best parts of the podcast."
    about:       "Create time-synced audio callouts that embed an audio player and capture quoted excerpts from podcasts or other audio files. Auto-generate quotes from transcripts, set start/end times and playback speed, and enable live updating so notes follow playback."

    stats: {
        downloads:  28448
        updated_at: 1683046284000
    }
}
```
