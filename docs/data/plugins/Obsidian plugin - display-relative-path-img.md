# Display Relative Path Img

Displays local images referenced by img tags in notes without modifying the original files. Rendering happens while scrolling and after edits in both reading and live preview, which keeps the files portable.

```cue
plugin: {
    id:     "display-relative-path-img"
    name:   "Display Relative Path Img"
    author: "dyc2424748461"
    repo:   "dyc2424748461/obsidian-display-relative-path-img"

    html_url:    "https://community.obsidian.md/plugins/display-relative-path-img"
    github_url:  "https://github.com/dyc2424748461/obsidian-display-relative-path-img"
    description: "Display the image of the <img> tag"
```
