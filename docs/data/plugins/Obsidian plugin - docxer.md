# Docxer

Adds a preview mode for docx files so that a Word document can be read inside the vault. A single Convert action produces a Markdown version that keeps layout, headings, lists and basic formatting.

```cue
plugin: {
    id:     "docxer"
    name:   "Docxer"
    author: "mika-dev"
    repo:   "developer-mike/obsidian-docxer"

    html_url:    "https://community.obsidian.md/plugins/docxer"
    github_url:  "https://github.com/developer-mike/obsidian-docxer"
    description: "Import Word files easily. Adds a preview mode for .docx files and the ability to convert them to markdown (.md) files."
    about:       "Preview .docx files directly in your vault and convert them to Markdown with a single click. Open a Word file to view its contents and click Convert to generate a Markdown version that preserves layout, headings, lists, and basic formatting."

    stats: {
        downloads:  99529
        updated_at: 1779374017000
    }
}
```
