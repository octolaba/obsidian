# Tier List

Tier List renders a nested Markdown list as a visual tier list with customizable tiers, showing internal or external images and covers taken from a file's Image frontmatter property. Items are ranked by hand, unplaced items stay in an auto-collapsing To Rank section, and Markdown links are preserved so graph connections survive.
