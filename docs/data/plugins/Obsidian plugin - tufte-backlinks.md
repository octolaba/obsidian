# Tufte Backlinks

Renders linked and unlinked mention snippets as formatted Markdown in the Backlinks pane and in the in-document backlinks block. Headings inside snippets are kept at body size, and backlink references are shown bold, underlined and in accent red. Existing match highlights are preserved, and the global Search pane is left untouched.

```cue
plugin: {
    id:     "tufte-backlinks"
    name:   "Tufte Backlinks"
    author: "PleiadesM"
    repo:   "pleiadesm/Tufte-Backlinks"

    html_url:    "https://community.obsidian.md/plugins/tufte-backlinks"
    github_url:  "https://github.com/pleiadesm/Tufte-Backlinks"
    description: "Renders Linked/Unlinked mention snippets as formatted Markdown in the Backlinks pane and the in-document backlinks block. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render linked and unlinked mention snippets as formatted Markdown in the Backlinks pane and in-document backlinks block. Keep headings at body size, display backlink references bold, underlined and accent red, and preserve match highlights while leaving the global Search pane untouched."

    stats: {
        downloads:  45
        updated_at: 1785733723000
    }
}
```
