# Canvas Filter

Canvas Filter shows only the canvas items matching a color, a tag, or a connection to or from the selected nodes. Selected nodes can also be hidden temporarily while their positions are preserved, and closing and reopening the canvas restores visibility.

```cue

    id:     "canvas-filter"
    name:   "Canvas Filter"
    author: "ikoshelev"
    repo:   "ikoshelev/Obsidian-Canvas-Filter"

    github_url:  "https://github.com/ikoshelev/Obsidian-Canvas-Filter"
```
