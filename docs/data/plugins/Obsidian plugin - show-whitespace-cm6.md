# Show Whitespace

Show Whitespace highlights leading and trailing whitespace in Source and Live Preview through CSS styles and CM6 extensions, rendering visible characters at line starts and line endings. Blockquote carets are marked and list-marker whitespace is shaded subtly. The built-in CSS is optional and can be disabled or replaced with your own.
