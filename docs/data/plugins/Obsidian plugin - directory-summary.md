# Directory Summary

Generates a summary note for a folder that lists its files as backlinks grouped by subfolder. Depth and item count can be limited, and a chosen file property is shown next to each backlink.

```cue
plugin: {
    id:     "directory-summary"
    name:   "Directory Summary"
    author: "va9id"
    repo:   "va9id/obsidian-directory-summary"

    html_url:    "https://community.obsidian.md/plugins/directory-summary"
    github_url:  "https://github.com/va9id/obsidian-directory-summary"
    description: "Generate a summary note for any directory in your vault. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Generate a summary note for any folder that lists files as backlinks and groups entries by subfolder. Limit depth and item count and show a specified file property value next to each backlink."

    stats: {
        downloads:  115
        updated_at: 1778888762000
    }
}
```
