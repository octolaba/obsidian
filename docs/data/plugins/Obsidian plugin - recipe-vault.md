# Recipe Vault

A recipe management system for the vault: recipes are imported from web pages via JSON-LD or added manually, and the collection is browsed in a visual gallery. Shopping lists are built from the ingredients with unit merging, when a recipe was last made is tracked, and notes can be edited with AI or Handlebars templates.
