# QuackBlocks

Runs SQL inside Obsidian through DuckDB WASM, including queries against Parquet files held in the vault. Results render inline as formatted HTML tables or as SVG charts — bar, line, area, dot, heatmap, box and waffle among them — which the recorded About says export reliably to PDF.
