# Vision Recall

Vision Recall processes screenshots taken from an intake folder, the clipboard, uploads or deep links, extracting text with OCR and analyzing the image with a vision language model. It then generates notes with summaries, tags and metadata that link back to the original. Results are browsed and searched through a gallery or list, with text, tag and date filters.
