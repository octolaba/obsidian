# Calendar Heatmap Tracker

Calendar Heatmap Tracker renders inline calendar heatmap trackers directly in notes, modeled after the GitHub contributions graph. Daily activity appears as a color-coded grid that reveals patterns, streaks and gaps, and a quick input field logs today's value. The data is stored in a local JSON file.
