# Paste URL into selection

Pastes a URL into selected text with Ctrl/Cmd+V, turning the selection into a Markdown link in the Notion style. Text can also be inserted into a selected URL from the command palette, replacing the link label. The recorded About states that it runs on Obsidian v0.9.8 and later.

```cue
plugin: {
    id:     "url-into-selection"
    name:   "Paste URL into selection"
    author: "denolehov"
    repo:   "denolehov/obsidian-url-into-selection"

    html_url:    "https://community.obsidian.md/plugins/url-into-selection"
    github_url:  "https://github.com/denolehov/obsidian-url-into-selection"
```
