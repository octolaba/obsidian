# code-snippet-manager

Collects and organizes reusable code snippets in Markdown files, so the vault stays the single source of truth for them. The index is searched and filtered by keyword, language, tag or project, and a snippet is copied, inserted or opened at its original block. SQL, JavaScript and TypeScript can be formatted, and an AI explanation can be requested with common secrets redacted.
