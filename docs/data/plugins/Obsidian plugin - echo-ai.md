# Echo

An AI writing assistant with inline writing, actions on the current selection and streaming output, working against OpenAI and Gemini. It defines no fixed functions: commands are built from your own prompts combined with variables such as the selection, for work like translation, polishing or continuation.

```cue
plugin: {
    id:     "echo-ai"
    name:   "Echo"
    author: "9b9387"
    repo:   "9b9387/obsidian-echo"

    html_url:    "https://community.obsidian.md/plugins/echo-ai"
    github_url:  "https://github.com/9b9387/obsidian-echo"
    description: "AI-powered writing assistant with inline write, selection actions, and streaming output. Supports OpenAI and Gemini. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "It's designed entirely for custom actions and prompts—use it to have AI assist with translation, polishing, continuation, or any content you'd like generated. Combine your own prompts with variables like {{selection}} to create personalized commands that perfectly match your note-taking habits. No predefined functions; everything is fully customizable by you."
```
