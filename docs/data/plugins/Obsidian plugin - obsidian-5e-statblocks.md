# Fantasy Statblocks

Fantasy Statblocks creates, manages and views a fantasy bestiary of tabletop RPG statblocks inside Obsidian. Statblocks are stored as Markdown so they stay local, searchable and linkable, and layouts are provided for D&D 5e, Pathfinder 2e, 13th Age and other systems.

```cue
plugin: {
    id:     "obsidian-5e-statblocks"
    name:   "Fantasy Statblocks"
    author: "obsidian-ttrpg-community"
    repo:   "obsidian-ttrpg-community/fantasy-statblocks"

    html_url:    "https://community.obsidian.md/plugins/obsidian-5e-statblocks"
    github_url:  "https://github.com/obsidian-ttrpg-community/fantasy-statblocks"
    description: "Create, manage and view a Fantasy Bestiary with Dungeons and Dragons style statblocks."
    about:       "Create, manage and view a Fantasy Bestiary in Obsidian with structured statblocks for tabletop RPGs. Store statblocks as Markdown for local, searchable, and linkable notes, with layouts for D&D 5e, Pathfinder 2e, 13th Age and other systems."

    stats: {

}
```
