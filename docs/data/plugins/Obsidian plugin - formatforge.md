# formatForge

A typography and palette plugin built for the Forge plugin family but usable without it. Common theme palettes such as Nord and Solarized are built in, and custom colors can be supplied instead. Font families and weights can be set separately for body text and each heading level from H1 to H6, and the text-styling interface also covers heading dividers, hiding H1 links, small caps per heading, and the colors used for bold and italic emphasis.

Use typographical colour selectors. Configure heading dividers, hide H1 links, apply small caps per heading, and set bold/italic emphasis colours via the full text-styling UI."
