# Unofficial Fabric Integration

Brings Fabric-style AI workflows into the vault without requiring Fabric itself or fabric-connector. Custom patterns are synced and managed from a watched folder, YouTube links are detected, and external APIs are called to fetch, manipulate and render content dynamically, with optional debug logging.
