# Kandyban

Presents Markdown project items as a non-destructive Kanban board and sortable list, reading bold-key fields such as Status and Milestone directly from the files. Cards can be dragged between status columns, enums edited inline, and items searched and filtered. Saved changes preserve the rest of the file's content and annotations.
