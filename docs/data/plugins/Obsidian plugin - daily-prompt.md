# Daily Prompt

Defines custom prompts and fills the answers into daily notes. A field can be text, a textarea, a checkbox, a slider, or an embedded note or file, and the daily note is created when it does not exist. Prompts are inserted under a unique heading with configurable line prefixes.

```cue
plugin: {
    id:     "daily-prompt"
    name:   "Daily Prompt"
    author: "erl-koenig"
    repo:   "erl-koenig/obsidian-dailyPrompt"

    html_url:    "https://community.obsidian.md/plugins/daily-prompt"
    github_url:  "https://github.com/erl-koenig/obsidian-dailyPrompt"
    description: "Set up custom prompts and automatically fill them into your daily notes."
    about:       "Define daily prompts with multiple field types (text, embedded note/file, checkbox, textarea, slider) and auto-fill answers into your daily notes. Create the daily note if missing and insert prompts under a unique heading with customizable line prefixes."

    stats: {
        downloads:  1427
        updated_at: 1712079983000
    }
}
```
