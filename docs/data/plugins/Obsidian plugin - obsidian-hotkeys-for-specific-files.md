# Hotkeys for specific files

Generates one command per designated file so that the file is opened with its own hotkey, assigned in Obsidian's hotkey settings. When Hover Editor support is enabled, the file opens in the Hover Editor instead.

```cue
plugin: {
    id:     "obsidian-hotkeys-for-specific-files"
    name:   "Hotkeys for specific files"
    author: "Vinzent"
    repo:   "vinzent03/obsidian-hotkeys-for-specific-files"

    html_url:    "https://community.obsidian.md/plugins/obsidian-hotkeys-for-specific-files"
    github_url:  "https://github.com/vinzent03/obsidian-hotkeys-for-specific-files"
    description: "Add commands for specific files and open them with a hotkey."
    about:       "Open specific files with custom hotkeys for instant access. Generate a command per designated file and assign shortcuts in Obsidian's hotkey settings. Open files in the Hover Editor when Hover Editor support is enabled."

    stats: {
        downloads:  32397
        updated_at: 1706561161000
    }
}
```
