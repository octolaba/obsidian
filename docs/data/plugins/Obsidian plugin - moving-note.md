# Moving Note

Synchronizes a vault across desktop and Android, using the system Git installation on desktop and the GitHub API on mobile so Android needs no local Git. Desktop can commit and push automatically, mobile pulls and pushes through the API, and sync runs on one click or on a schedule. Conflicts produce hint files.
