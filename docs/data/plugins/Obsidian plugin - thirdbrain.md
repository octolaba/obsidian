# ThirdBrain

ThirdBrain extracts verifiable atomic propositions from text, connects them with typed logical edges, and resolves hidden contradictions so the resulting knowledge graph stays free of them. Every step, cross-domain folder analysis included, runs locally against a chosen model, either Gemini, the Claude API, the GPT API or Claude Code, which the recorded inputs present as data sovereignty. Its description and About are written in both English and Korean.
