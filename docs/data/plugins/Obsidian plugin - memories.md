# Memories

Displays media files as interactive galleries inside notes, with a fullscreen lightbox, slideshows and zoomable images, covering images, video and audio. Large collections are handled by a responsive grid with lazy loading, several source folders, flexible sorting and a random slideshow mode. A file manager is built in.
