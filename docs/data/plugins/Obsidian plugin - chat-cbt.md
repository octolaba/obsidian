# ChatCBT

ChatCBT is a journaling assistant that prompts the writer to reframe negative thoughts, name thinking patterns and consider other angles, drawing on cognitive behavioral therapy. Conversations are kept as local Markdown files and can run against cloud or local AI models. Reframed thoughts can be summarized into tables for affirmations and later review.
