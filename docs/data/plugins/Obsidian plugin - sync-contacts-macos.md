# Sync Contacts on macOS

Syncs contacts from the Mac Contacts app into a folder in the vault, writing one Markdown file per contact with configurable details. The sync can be limited to a named Smart List. The recorded About text states that Obsidian has to be granted access to Contacts through AppleScript when prompted.

```cue
plugin: {
    id:     "sync-contacts-macos"
    name:   "Sync Contacts on macOS"
    author: "motschel123"
    repo:   "motschel123/Mac-Contact-Sync-Obsidian"

    html_url:    "https://community.obsidian.md/plugins/sync-contacts-macos"
    github_url:  "https://github.com/motschel123/Mac-Contact-Sync-Obsidian"
    description: "Sync your macOS contacts."
    about:       "Sync contacts from the Mac Contacts app into a folder in your Obsidian vault, creating one Markdown file per contact with configurable details. Limit sync to a specified Smart List and enable Obsidian access to Contacts (via AppleScript) when prompted."
```
