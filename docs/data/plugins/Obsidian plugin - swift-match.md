# SwiftMatch

Matches and marks selected text across the vault with visual highlights, grouping matches by file, headings, tags and file names. A floating toggle with match counters and a search box navigates and opens matches, copies entries, or exports the results as Markdown. Highlight styles are customizable, pinned keywords keep highlights across sessions, and the interface can be switched between Chinese and English.
