# Map View

This plugin turns notes into an interactive map by extracting geolocations and paths and plotting them on embeddable, offline maps. Locations can be added from search, from the map, from external services or from GPS, shapes can be drawn, and GeoJSON, GPX, KML and TCX data imported or exported. It also calculates driving, cycling and walking routes, customizes markers and filters with boolean queries.
