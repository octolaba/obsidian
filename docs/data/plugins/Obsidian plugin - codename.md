# Codename

Codename generates random codenames for projects, notes or secret items, so naming does not hold up the work. A Command Palette command inserts a generated codename at the editor cursor.

```cue
plugin: {
    id:     "codename"
    name:   "Codename"
    author: "dstack"
    repo:   "dstack/obsidian-codename"

    html_url:    "https://community.obsidian.md/plugins/codename"
    github_url:  "https://github.com/dstack/obsidian-codename"
    description: "Solve the hardest problem: naming things."
    about:       "Generate random codenames for projects, notes, or secret items to avoid getting hung up on naming. Insert a generated codename directly at the editor cursor via a Command Palette command."

    stats: {
        downloads:  3913
        updated_at: 1691359213000
    }
}
```
