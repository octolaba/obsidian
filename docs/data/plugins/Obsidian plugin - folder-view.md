# FolderView

Renders a live folder tree inside a note from a Markdown code block, listing every subfolder and file recursively, including empty and non-Markdown files. Files open on click and can be previewed on hover, and the collapsed state of the tree is remembered across sessions. Entries can be filtered, sorted and given custom icons.
