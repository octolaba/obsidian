# Vault Aquarium

Represents the vault as a single betta fish whose colors come from graph-view color groups, taking the top two matching colors as the primary for body and fins and the secondary for markings. The fish swims and slowly morphs after notes or links change, and can be clicked or dragged to move it. Monthly statistics are stored locally and all data stays on the device, which reads .obsidian/graph.json for the color groups.
