# Note Batcher

Note Batcher creates the notes behind all unresolved links in the vault in a single action. It uses Dataview to scan pages and their outgoing links, then generates the missing target notes in one batch.

```cue
plugin: {
    id:     "note-batcher"
    name:   "Note Batcher"
    author: "mranyx"
    repo:   "mranyx/obsidian-note-batcher"

    html_url:    "https://community.obsidian.md/plugins/note-batcher"
    github_url:  "https://github.com/mranyx/obsidian-note-batcher"
    description: "Create all unresolvered links with a single click."
    about:       "Create all unresolved links in your vault with a single click. Use Dataview to scan pages and outgoing links and batch-generate the missing target notes to quickly resolve and organize your links."
```
