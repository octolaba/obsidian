# Songwriter

Song notes are created with metadata — title, status, key, tempo, time signature, genre, themes and influences — and with frontmatter-based sections for lyrics, chords, notes and recording ideas. Lyric snippets are captured as they come, and a rhyme helper is launched from the note. A sidebar lists songs grouped by status with title, key and badges.
