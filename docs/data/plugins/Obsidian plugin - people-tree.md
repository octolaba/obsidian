# People Tree

People Tree builds family trees, org charts, timelines and sortable lists from the YAML frontmatter of Markdown notes. Notes or photos are dragged onto the board, fields are edited inline so changes write back to the note, and cards can be repositioned and zoomed. Connections are highlighted on the board, and the recorded inputs state that all data stays local.
