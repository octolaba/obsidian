# Visual Card Writer

Turns a Markdown note into a card-based editor by mapping ATX headings onto a hierarchy of cards, saving every edit back to the same source file. Cards sit in aligned columns that can be navigated, collapsed or dimmed, and both columns and cards can be resized. Editing happens inline through an embedded CodeMirror 6 editor with live preview, and the file stays plain Markdown.
