# Corkboard

Corkboard gives each folder a Scrivener-style board in which every Markdown file appears as an index card in a flowing grid. Cards show a title, a separate synopsis, a status and a color, and can be dragged, multi-selected, reordered and acted on through context menus. The board syncs with filesystem changes and persists card size and layout, and it runs on desktop only.
