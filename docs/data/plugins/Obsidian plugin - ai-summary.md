# AI Notes Summary

Summarizes every note linked from the current note using OpenAI GPT-3. Each linked note's summary is presented in a dialog for review and copying, and no file is modified. The prompt comes from the note's front matter, or from the default when none is set.

```cue
plugin: {
    id:     "ai-summary"
    name:   "AI Notes Summary"
    author: "irbull"
    repo:   "irbull/obsidian-ai-summary"

    html_url:    "https://community.obsidian.md/plugins/ai-summary"
    github_url:  "https://github.com/irbull/obsidian-ai-summary"
    description: "Use OpenAI to generate a summary of referenced notes."
    about:       "Summarize all notes linked from the current note using OpenAI GPT-3. Present each linked note’s summary in a dialog for quick review and copying without modifying your files. Use a prompt from the note’s front matter or the default prompt to control the output."

    stats: {
        downloads:  5497

    }
}
```
