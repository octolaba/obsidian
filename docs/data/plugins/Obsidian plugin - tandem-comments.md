# Tandem Comments

Tandem Comments attaches quote-anchored comment threads to a note and stores them all in one fenced JSON block at the end of the file, leaving the prose untouched. Threads are managed in a sidebar with live editor highlights and re-anchoring as the text is edited, and reading view shows a compact comment-count pill. Because the threads are plain JSON inside the file, AI assistants can read and write them as well.

    id:     "tandem-comments"
