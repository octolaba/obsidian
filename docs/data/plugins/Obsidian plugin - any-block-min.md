# AnyBlock Min

A lightweight AnyBlock build that drops the mermaid, plantuml and markmap dependencies to shrink the package and shorten startup. Core AnyBlock features remain, with lower memory use and load times. The removed renderers can be brought back through compatible third-party plugins.

```cue
plugin: {
    id:     "any-block-min"
    name:   "AnyBlock Min"
    author: "any-block"
    repo:   "any-block/obsidian-any-block-min"

    html_url:    "https://community.obsidian.md/plugins/any-block-min"
    github_url:  "https://github.com/any-block/obsidian-any-block-min"
    description: "AnyBlock min version. Remove some features and dependencies to reduce size and improve performance. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Run a lightweight AnyBlock build that removes mermaid, plantuml and markmap dependencies to dramatically shrink package size and speed startup. Preserve core AnyBlock features while cutting memory use and load times. Re-enable removed renderers via compatible third‑party plugins."

    stats: {
        downloads:  4724
        updated_at: 1783363182000
    }
}
```
