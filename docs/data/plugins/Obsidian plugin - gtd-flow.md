# GTD Flow

Organizes tasks and projects with Getting Things Done structure kept as plain Markdown, so every task stays an ordinary checklist line. Sequential and parallel project flow, defer dates and next-action logic are applied on top, together with forecast and review views and quick capture. A Mermaid-powered timeline is included.
