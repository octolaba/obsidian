# Contextual Vocabulary

Contextual Vocabulary defines a selected word with AI, links it in place, and maintains a navigable dictionary note. Definitions and usage reviews are generated from the surrounding sentence, and entries are added alphabetically to a compact index. Existing entries are reused so the dictionary does not accumulate duplicates.
