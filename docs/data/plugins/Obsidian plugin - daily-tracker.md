# Daily Tracker

Tracks daily habits, logs work and sleep hours, and records short daily summaries from a sidebar with a clickable monthly calendar. An analytics modal charts habits and time as bar, radar and pie charts with monthly averages and seven-day comparisons, and the counters reset automatically at midnight.
