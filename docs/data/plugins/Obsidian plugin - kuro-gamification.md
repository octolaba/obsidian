# Kuro Gamification

Adds gamification aimed at being neurodivergence-friendly, with XP, levels, streaks and freeze tokens. Progress is tracked automatically from daily notes, deterministic loot drops and optional lore can be redeemed, and XP can also be adjusted by hand. Status appears live in the sidebar or in an embedded block, anything that could escalate is off by default, and the plugin states that data is stored locally.
