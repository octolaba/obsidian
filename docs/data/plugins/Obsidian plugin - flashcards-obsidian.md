# Flashcards

Creates Anki flashcards from Obsidian notes through card tags and inline question-and-answer or cloze syntax. Cards are synced, updated and deleted in Anki over AnkiConnect. Reversed and spaced cards, LaTeX, images, audio, code highlighting and context-aware note references are covered.
