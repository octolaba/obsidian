# Diagram Popup

Opens diagrams from Mermaid, PlantUML, Graphviz and other formats in a draggable, zoomable popup. The popup is opened with Ctrl+click or from a toolbar button, then panned and zoomed with the mouse, touch gestures or on-screen navigation controls.
