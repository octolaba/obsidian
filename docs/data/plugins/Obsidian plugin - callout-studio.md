# Callout Studio

Callout Studio provides three ways to highlight text, namely regular callouts, inline callouts and callout headings, and lets entirely new custom styles be created. Colors can be tweaked and icons chosen from seven icon libraries. Autocomplete, context menu actions and a single settings tab for bulk editing and vault-wide syncing are included.
