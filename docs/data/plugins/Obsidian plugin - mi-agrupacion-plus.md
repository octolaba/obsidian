# Mi Agrupacion Plus

Mi Agrupacion Plus records Bahá'í community activities centrally and keeps each grouping's data isolated from the others. A grouping connects through an invitation code, and synchronization with an already-configured Supabase backend runs in both directions, automatically or on demand. The recorded description and About text are written in Spanish, and the directory entry notes that the plugin has not been manually reviewed by Obsidian staff.
