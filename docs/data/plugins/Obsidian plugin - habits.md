# Habits

Logs daily habits as plain Markdown notes in the vault and builds streaks from them. Progress is shown through heatmaps, 30-day and 12-week charts, streak counts and completion rates, and can be exported as printable PDF reports. Habits are marked from an inline carousel dashboard or a sidebar quick-log panel, and can be paused for a day without breaking a streak.
