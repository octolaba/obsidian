# Blackboard

Blackboard adds pressure-sensitive drawing with an Apple Pencil or stylus inside Canvas nodes and Markdown embeds, with palm rejection and touch navigation so writing happens in place rather than in a separate editor. It offers pen, highlighter and eraser tools on a shared floating toolbar, keeps per-embed sizing, can export SVG, and stores drawings as readable .blackboard JSON.
