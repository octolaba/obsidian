# Ctrl-XA cycle various items

Cycles the item at the cursor through predefined keyword lists, such as Monday to Tuesday or yes and no, and increments or decrements numbers and dates inline. Custom lists are configurable and hotkeys cycle the items up or down.

```cue
plugin: {
    id:     "ctrl-xa"
    name:   "Ctrl-XA cycle various items"
    author: "nbossard"
    repo:   "nbossard/obsidian-CtrlXA"

    html_url:    "https://community.obsidian.md/plugins/ctrl-xa"
    github_url:  "https://github.com/nbossard/obsidian-CtrlXA"
    description: "Cycle through various items with keyboard shortcuts. Such as days, months, true-false, log level,... anything you need."
    about:       "Cycle through predefined keyword lists (e.g., Monday→Tuesday, yes↔no, I→II) or automatically increment/decrement numbers and dates inline in your notes. Configure custom lists and assign hotkeys to cycle items up or down."

    stats: {
        downloads:  1644
        updated_at: 1707812700000
    }
}
```
