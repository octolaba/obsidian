# SystemSculpt AI

Chats with notes through vault-aware AI agents, switching between a tool-assisted agent mode and pure reasoning, with system prompts selected from Markdown files in the vault. The recorded About text also names semantic search over embeddings, recording and transcribing audio, capture-folder automations, and generating Canvas images.
