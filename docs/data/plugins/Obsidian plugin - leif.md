# Leif

Leif organises study for concursos, Brazilian public-service examinations, covering contests, subjects, the topics of an edital, question notebooks and study sessions. It shows what to study today, records completed sessions and tracks progress per subject inside Obsidian. Its recorded description and About are written in Portuguese.

```cue
plugin: {
    id:     "leif"
    name:   "Leif"
    author: "Luiz Gustavo"
    repo:   "ttusk/leif"

    html_url:    "https://community.obsidian.md/plugins/leif"
    github_url:  "https://github.com/ttusk/leif"
    description: "Organize concursos, ciclos, editais, materiais e sessões de estudo. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Organize estudos para concursos em uma estrutura clara com concursos, matérias, assuntos do edital, cadernos de questões e sessões de estudo. Veja o que estudar hoje, registre sessões concluídas e acompanhe o progresso por matéria direto no Obsidian."

    stats: {
        downloads:  81
        updated_at: 1785275713000
    }
}
```
