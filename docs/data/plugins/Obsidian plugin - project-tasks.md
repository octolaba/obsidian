# Project Tasks

Creates linked project tasks by assigning task identifiers automatically and managing the dependencies between them to build sequential workflows. Project-specific tags are applied, standard Tasks features such as due dates and recurrence continue to work, project views can use Dataview queries, and optional or conditional tasks are supported.
