# TXT Viewer

Opens .txt files in a dedicated read-only view with stable line numbers, line-ending warnings and file statistics for lines, characters and bytes, never writing back to disk. Matches are searched and stepped through, and a filter shows only matching lines while keeping the original numbering. Large files are guarded by rendering caps, the view refreshes automatically, and no network request is made.
