# NotePack

Scans the vault's Markdown files for unchecked todos and collects them in a sidebar with Overdue and Due Soon sections. Tasks can be assigned with @mentions and otherwise default to the user, and natural-language due dates such as a weekday, EOD, EOM or an ISO date are parsed, with relative dates resolved from a file's date prefix and badges color-coded.

    id:     "notepack"
    name:   "NotePack"

    description: "Scans your vault's markdown files for unchecked todos and collates them in a todos sidebar. Supports @mention for team members and natural language due date logic. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Scan your vault for unchecked todos, assign tasks via @mentions (or default to you), and display organized sidebar views with Overdue and Due Soon sections. Parse natural-language due dates (e.g., \"due by Friday\", EOD, EOM, ISO) and color-code badges, resolving relative dates from file date prefixes."
