# Loom

Provides a recursively branching interface to GPT-3 and other language models: from any cursor position it generates several continuations as alternative child nodes. Branches are explored and managed in a right-sidebar tree and a node pane. Completions come from OpenAI, Azure OpenAI, Cohere, TextSynth or compatible proxies.
