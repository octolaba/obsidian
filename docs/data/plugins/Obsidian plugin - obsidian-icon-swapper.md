# Icon Swapper

Swaps out Obsidian's default interface icons for custom SVG files. Icon configuration files are exported and imported to save, share or restore a setup, and an included Boxicons example is there to test replacements.

```cue
plugin: {
    id:     "obsidian-icon-swapper"
    name:   "Icon Swapper"
    author: "mgmeyers"
    repo:   "mgmeyers/obsidian-icon-swapper"

    html_url:    "https://community.obsidian.md/plugins/obsidian-icon-swapper"
    github_url:  "https://github.com/mgmeyers/obsidian-icon-swapper"
    description: "Swap out Obsidian's default icons."
    about:       "Replace Obsidian UI icons with custom SVG files. Export and import icon configuration files to save, share, or restore setups. Try the included Boxicons example to test replacements."
```
