# Embedding

Navigates the vault by semantic similarity using embeddings, through a floating, keyboard-first pop-out panel that moves between related notes without the sidebar. Embeddings are built and updated in batches, with OpenAI supported, and connections can be recomputed on demand. An optional MCP JSON-RPC server exposes the semantic search programmatically.
