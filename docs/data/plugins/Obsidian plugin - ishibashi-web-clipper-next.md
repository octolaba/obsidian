# Ishibashi Web Clipper V2

Ishibashi Web Clipper V2 saves user-shared web links as local Markdown notes without requesting or scraping the source page, so no page content or metadata is fetched. Captures arrive through the mobile share sheet, the clipboard, a bookmarklet or an obsidian URL, duplicate URLs are prevented, and tags are derived from the domain and the folder. Clips collect in an inbox with searchable history and recorded capture provenance.
