# D.O.M.S

A mobile-first workout tracker that records each session as plain Markdown in the vault, counting sets per muscle group and marking week completion with minimal logging. Statistics cover sessions, streaks, total sets, a month activity calendar and 12-week muscle coverage. Exercise and rehab libraries with technique videos are included, and activity widgets can be embedded in any note.
