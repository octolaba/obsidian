# Influx

Aggregates a terse stream of backlinked clippings in the footer of a note, showing the content surrounding each backlink instead of a bare title. Related contexts are grouped automatically, and sorting, layout and filtering are configurable.

```cue

    id:     "influx"
    name:   "Influx"
    author: "jensmtg"
    repo:   "jensmtg/influx"

    html_url:    "https://community.obsidian.md/plugins/influx"
    github_url:  "https://github.com/jensmtg/influx"
```
