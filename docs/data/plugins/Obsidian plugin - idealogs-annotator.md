# Idealogs Annotator

Idealogs Annotator inserts and views Idealogs articles in Obsidian, with article suggestions and WritingLinks that open an article in a dedicated WritingView with rendered Markdown and syntax highlighting. Annotations and inline comments link Markdown text to a specific article passage with automatic validation, Prev and Next navigation and a flash highlight on the target passage. Idealogs files are fetched read-only and cleaned up automatically.
