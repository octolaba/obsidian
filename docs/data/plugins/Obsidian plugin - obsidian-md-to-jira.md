# Markdown to Jira Converter

This plugin converts whole notes or selected text between Obsidian Markdown and Jira markup in both directions. Converted content can be copied to the clipboard for pasting into Jira, and Jira markup can be converted back into Markdown inside the editor.

```cue
plugin: {
    id:     "obsidian-md-to-jira"
    name:   "Markdown to Jira Converter"
    author: "muckmuck96"
    repo:   "muckmuck96/obsidian-md-to-jira"

    html_url:    "https://community.obsidian.md/plugins/obsidian-md-to-jira"
    github_url:  "https://github.com/muckmuck96/obsidian-md-to-jira"
    description: "Convert notes or selections to Jira markup and vice versa."
    about:       "Convert entire notes or selected text between Obsidian Markdown and Jira markup. Copy converted content to the clipboard for pasting into Jira, or convert Jira markup back into Markdown within the editor."

    stats: {
        downloads:  10470
        updated_at: 1778854612000
    }
}
```
