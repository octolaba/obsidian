# Easy Test

Extracts the bolded text of the active editor and turns each item into an input field shown in a modal. Answers are checked in real time and a hint can be revealed for the focused question, which makes a note repeatable as a quick self-test.

```cue
plugin: {
    id:     "easy-test"
    name:   "Easy Test"
    author: "forrest1398"
    repo:   "forrest1398/obsidian-easyTest-plugin"

    html_url:    "https://community.obsidian.md/plugins/easy-test"
    github_url:  "https://github.com/forrest1398/obsidian-easyTest-plugin"
    description: "Easily create simple tests"
    about:       "Extract bolded text from the active editor and convert each item into interactive input fields displayed in a modal. Enter answers, check them in real time, and reveal hints for the focused question to run quick, repeatable self-tests."
```
