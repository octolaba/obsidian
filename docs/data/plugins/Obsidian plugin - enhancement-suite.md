# Enhancement Suite

Bundles several independently configurable editing modules into one plugin, switching automatically between English and Simplified Chinese. The modules validate frontmatter in real time and summarize or batch-edit properties, sort and filter table columns, view and edit JSON in a tree viewer, export clean Markdown, standalone HTML or PDF, run cross-file search and replace, and show live note statistics.
