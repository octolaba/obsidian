# External Links View

External Links View collects every external link in the vault into one place, organized by the note each link comes from. The view opens from the ribbon or the command palette, and a click opens the link in the default browser. Unwanted URLs are excluded with configurable regex patterns.

```cue
plugin: {
    id:     "external-links-view"
    name:   "External Links View"
    author: "theamritanair"
    repo:   "theamritanair/obsidian-external-links"

    html_url:    "https://community.obsidian.md/plugins/external-links-view"
    github_url:  "https://github.com/theamritanair/obsidian-external-links"
    description: "View all external links from your notes in one organized place, sorted by their source notes."
    about:       "Collect all external links from your vault and display them organized by their source notes. Open links in your default browser with a click and access the view from the ribbon or command palette. Exclude unwanted URLs using configurable regex patterns."

    stats: {
        downloads:  821

}
```
