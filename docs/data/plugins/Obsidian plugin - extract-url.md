# Extract url content

Extract url content converts a URL into Markdown - a selected link, a link named in the note's frontmatter, or every link in the note in archive mode. It can create archived Markdown files, replace external links with internal copies, or insert title-only anchors. When youtube-dl is available it also extracts extra YouTube metadata.

```cue
plugin: {
    id:     "extract-url"
    name:   "Extract url content"
    author: "trashhalo"
    repo:   "trashhalo/obsidian-extract-url"

    html_url:    "https://community.obsidian.md/plugins/extract-url"
    github_url:  "https://github.com/trashhalo/obsidian-extract-url"
    description: "Extract URL converting content into Markdown."
    about:       "Convert a URL into readable Markdown by replacing a selected link, a frontmatter-specified link in a note, or all links in a note (archive mode). Create archived markdown files, replace external links with internal copies, insert title-only anchors, or extract extra YouTube metadata when youtube-dl is available."

    stats: {
        downloads:  35380
        updated_at: 1654005149000
    }
}
```
