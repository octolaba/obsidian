# Apple Reminders

Apple Reminders imports Apple Reminders into Obsidian through AppleScript. It displays the contents of a list, fetches uncompleted reminders by default, pulls or creates specific reminders, and applies basic date and priority filters. It runs only on Apple devices.

    id:     "obsidian-apple-reminders-plugin"
    name:   "Apple Reminders"
    author: "urishiraval"
