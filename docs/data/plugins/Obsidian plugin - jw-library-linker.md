# JW Library Linker

Converts typed Bible references into clickable JW Library links, in either a command or a silent mode. Bible quotes fetched from jw.org can be inserted into notes using customizable quote templates. The interface adapts to Obsidian's language and supplies translated Bible book names.

```cue
plugin: {
    id:     "jw-library-linker"
    name:   "JW Library Linker"
    author: "msakowski"
    repo:   "msakowski/obsidian-library-linker"

    html_url:    "https://community.obsidian.md/plugins/jw-library-linker"
    github_url:  "https://github.com/msakowski/obsidian-library-linker"
    description: "Converts JW Library and Bible references to actual links in JW Library."
    about:       "Create clickable JW Library links from typed Bible references in Obsidian using command or silent mode. Insert actual Bible quotes fetched from jw.org into notes with customizable quote templates. Use a UI that adapts to Obsidian's language and provides translated Bible book names."

    stats: {
        downloads:  2374
        updated_at: 1780648036000
    }
}
```
