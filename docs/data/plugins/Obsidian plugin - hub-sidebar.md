# Hub Sidebar

Hub Sidebar frames the local graph and an On this page outline in a Publish-style card in the right sidebar. A clickable switcher toggles between the local graph, incoming links and outgoing links, hairline borders can be removed and the editor column centered, and the sidebar is opened by command or an optional status-bar button.

    id:     "hub-sidebar"
    name:   "Hub Sidebar"

Remove hairline borders, center the editor column when desired, and toggle the sidebar via command or optional status-bar button."
