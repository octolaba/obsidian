# Morgen Tasks

Connects the vault to Morgen so vault tasks can be viewed beside any calendar and time-blocked by drag and drop. Completions and done dates are synced back to Obsidian, and recurring tasks can be auto-scheduled. Lists are filtered by due date or priority, and task IDs hidden or replaced.
