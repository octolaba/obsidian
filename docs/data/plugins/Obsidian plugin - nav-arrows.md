# Nav Arrows

Adds back and forward navigation arrows to the top bar, beside the sidebar collapse button. They stay visible whatever the sidebar state and are disabled when there is no history in that direction, matching Obsidian's native icon style.

```cue
plugin: {
    id:     "nav-arrows"
    name:   "Nav Arrows"
    author: "antoineart"
    repo:   "antoineart/obsidian-nav-buttons"

    html_url:    "https://community.obsidian.md/plugins/nav-arrows"
    github_url:  "https://github.com/antoineart/obsidian-nav-buttons"
    description: "Adds back/forward navigation arrows to the top bar, next to the sidebar collapse button. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add back and forward navigation arrows to the top bar next to the sidebar collapse button. Keep arrows always visible regardless of sidebar state and disable them when no back or forward history exists, matching Obsidian's native icon style."
```
