# Typing Interface Hider

Hides selected parts of the Obsidian interface while typing, giving a focus mode without changing the note layout. The interface returns on mouse movement, click, scroll or window blur, and an idle delay or a mouse-only restore can be used instead. Sidebars, ribbon, headers, status bar, title bar and scrollbars are chosen individually.
