# Literature Flow

Supports open-access literature discovery and citation mapping from inside Obsidian, searching online through Semantic Scholar or OpenAlex. Cited and citing works are listed in a sidebar, reference details can be inserted or created as notes, and a literature graph maps the citation relationships.

```cue
plugin: {
    id:     "literature-flow"
    name:   "Literature Flow"
    author: "michellegdyason"
    repo:   "michellegdyason/obsidian-literature-flow"

    html_url:    "https://community.obsidian.md/plugins/literature-flow"
    github_url:  "https://github.com/michellegdyason/obsidian-literature-flow"
```
