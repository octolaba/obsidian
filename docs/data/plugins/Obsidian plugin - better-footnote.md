# Better Footnote

Better Footnote opens a sidebar for editing Markdown footnote definitions, with normal selection, multiline input and automatic saving back to the source note. A footnote card jumps to its reference in the text and briefly outlines it, numeric labels are shown while the underlying identifiers are preserved, and positions are remembered per file.

```cue
plugin: {
    id:     "better-footnote"
    name:   "Better Footnote"
    author: "alcatrazyu"
    repo:   "alcatrazyu/better-footnote"

    html_url:    "https://community.obsidian.md/plugins/better-footnote"
    github_url:  "https://github.com/alcatrazyu/better-footnote"
    description: "A writing-focused footnote sidebar for editing, navigating, and preserving context in academic Markdown notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open a right sidebar to edit Markdown footnote definitions with normal selection, multiline input, and auto-save to the source note. Jump from footnote cards to their reference (briefly outlined), show numeric labels while preserving [^id], and remember positions per file."

    stats: {
        downloads:  3413
        updated_at: 1786289334000
    }
}
```
