# Retrieva

Retrieva schedules spaced repetition with FSRS while keeping questions, answers, identifiers and review history in ordinary Markdown files. Card state is rebuilt from the vault itself, so no external database is involved. Decks are selected by tag with nested counts, cards can be skipped for a session or suspended, and forward or linked front and back pairs can be created.
