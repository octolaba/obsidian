# Kindle

Exports notes as a single .epub file that includes embedded images and linked Markdown files. The .epub is then sent by email to a Kindle or PocketBook through a self-hosted or public PHP backend.

```cue
plugin: {
    id:     "obsidian-kindle-export"
    name:   "Kindle"
    author: "simeonlukas"
    repo:   "simeonlukas/obsidian-kindle-export"

    html_url:    "https://community.obsidian.md/plugins/obsidian-kindle-export"
    github_url:  "https://github.com/simeonlukas/obsidian-kindle-export"
```
