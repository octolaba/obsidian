# Mermaid Export Fit

Keeps wide Mermaid diagrams from being clipped when a note is exported to PDF or HTML. Diagrams are fitted to the page width during export and SVG clarity is preserved. The reading pane gains horizontal scrolling for diagrams wider than it.

```cue
plugin: {
    id:     "mermaid-fit"
    name:   "Mermaid Export Fit"
    author: "Rosetta Zidian Guo"
    repo:   "fyaic/Mermaid-Export-Fit-Plugin"

    html_url:    "https://community.obsidian.md/plugins/mermaid-fit"
    github_url:  "https://github.com/fyaic/Mermaid-Export-Fit-Plugin"
    description: "Prevents wide Mermaid diagrams from breaking during PDF/HTML export. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Keep wide Mermaid diagrams intact in Obsidian and prevent clipping during PDF/HTML export. Preserve SVG clarity, add horizontal scrolling in the reading pane, and fit diagrams to page width during exports automatically."
```
