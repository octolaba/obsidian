# Tab Swap

Swaps the active editor tab with the one to its left or right through a single command. Custom hotkeys can be assigned for the swaps and for jumping to the previous or next tab.

```cue
plugin: {
    id:     "tab-swap"
    name:   "Tab Swap"
    author: "masaki39"
    repo:   "masaki39/tab-swap"

    html_url:    "https://community.obsidian.md/plugins/tab-swap"
    github_url:  "https://github.com/masaki39/tab-swap"
    description: "Swap the active tab left or right. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Swap active editor tabs left or right with a single command. Assign custom hotkeys to swap tabs or jump to previous/next tabs for faster tab management."

    stats: {
        downloads:  206
        updated_at: 1779346403000
    }
}
```
