# Image Alignment

Image Alignment aligns an image left, center or right from the image context menu or the command palette. The alignment is written into the image embed text itself so notes stay portable and readable, and existing size markers are preserved when the alignment changes.

```cue
plugin: {
    id:     "image-alignment"
    name:   "Image Alignment"
    author: "Dong Yang"
    repo:   "ydd0729/obsidian-image-alignment"

    html_url:    "https://community.obsidian.md/plugins/image-alignment"
    github_url:  "https://github.com/ydd0729/obsidian-image-alignment"
    description: "Adds quick image alignment controls to image context menus and commands. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Align images left, center, or right from the image context menu or command palette. Edit the image embed text directly so notes stay portable and readable, while preserving existing size markers (e.g., |300) when changing alignment."

    stats: {
        downloads:  416
        updated_at: 1779206102000
    }
}
```
