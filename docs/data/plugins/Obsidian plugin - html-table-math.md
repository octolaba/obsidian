# HTML Table Math

Renders LaTeX math inside the cells of raw HTML tables using MathJax. The Obsidian delimiters for inline and display math are supported, along with an escaped dollar sign for a literal dollar. Rendering happens in both Reading View and Live Preview, and the rest of a cell's content is left unchanged.

```cue
plugin: {
    id:     "html-table-math"
    name:   "HTML Table Math"
    author: "timeofmei"
    repo:   "timeofmei/html-table-math"

    html_url:    "https://community.obsidian.md/plugins/html-table-math"
    github_url:  "https://github.com/timeofmei/html-table-math"
    description: "Render LaTeX math inside raw HTML table cells. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render LaTeX math inside raw HTML table cells in Obsidian notes using MathJax. Support Obsidian math delimiters $...$, $$...$$ and \\$ for literal dollars, and show rendered math in both Reading View and Live Preview while leaving other cell content unchanged."
```
