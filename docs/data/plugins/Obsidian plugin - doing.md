# doing

Shows the task currently being worked on in the status bar, so context survives switching between tasks. Completed tasks are logged with timestamps to doing.md, and past tasks can be browsed as a history.

```cue
plugin: {
    id:     "doing"
    name:   "doing"
    author: "rooyca"
    repo:   "rooyca/doing"

    html_url:    "https://community.obsidian.md/plugins/doing"
    github_url:  "https://github.com/rooyca/doing"
    description: "It helps you remember what you were doing."
    about:       "Display the current task in the status bar to keep context when switching tasks. Log completed tasks with timestamps to doing.md and browse a history of past tasks."

    stats: {
        downloads:  964
        updated_at: 1754528142000
    }
}
```
