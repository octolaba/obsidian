# Header Backlinks

Header Backlinks shows an anchor icon in the editor gutter beside any heading that wiki-style internal links or embeds target. Clicking the anchor lists the notes and the specific occurrences that reference that heading and jumps to the exact link line. The heading can also be renamed from there, with links updated throughout the vault.

```cue
plugin: {
    id:     "header-backlinks"
    name:   "Header Backlinks"
    author: "rekby"
    repo:   "rekby/obsidian-header-backlinks"

    html_url:    "https://community.obsidian.md/plugins/header-backlinks"
    github_url:  "https://github.com/rekby/obsidian-header-backlinks"
    description: "Displays anchor icons next to headings targeted by internal links and lets you navigate to every note that references each heading. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Show an anchor icon in the editor gutter beside any heading targeted by wiki-style internal links or embeds. Click the anchor to list all notes and specific occurrences that link to that heading, jump to the exact link line, or rename the heading and update links throughout the vault."

    stats: {
        downloads:  245
        updated_at: 1778925838000
    }
}
```
