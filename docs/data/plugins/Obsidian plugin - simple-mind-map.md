# Simple mind map

Simple mind map creates interactive mind maps stored as .smm.md files that open either in a visual mind-map view or as Markdown. Maps can be embedded as images, their nodes linked to vault files, and switched between diagram and outline modes. Maps can also be exported and imported, and split views stay synchronized.
