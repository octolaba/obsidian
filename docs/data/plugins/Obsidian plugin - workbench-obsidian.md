# Workbench

Collects thinking from any note into a persistent Workbench note. Pages, headers and blocks can be linked or embedded, the current line can be copied, and items are added with alt-click or with cmd or windows plus alt-click. Workbench contents can be inserted elsewhere or cleared, and the Workbench name and the item line prefix are set in the settings.

```cue
plugin: {
    id:     "workbench-obsidian"
    name:   "Workbench"
    author: "ryanjamurphy"
    repo:   "ryanjamurphy/workbench-obsidian"

    html_url:    "https://community.obsidian.md/plugins/workbench-obsidian"
    github_url:  "https://github.com/ryanjamurphy/workbench-obsidian"
    description: "Keep a workbench of knowledge materials."

Customize the Workbench name and item line prefix in settings."
