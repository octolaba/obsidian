# Mobile PDF Exporter

Exports preview-style PDFs on mobile and desktop in one click, taking the page layout from the rendered preview DOM. Text stays selectable through a real PDF text layer, images are embedded, code, tables, quotes and callouts keep their styling, and blocks avoid breaking across pages where possible. Excalidraw files export as image PDFs with automatic lower-resolution retries and page slicing, and interface text is offered as Auto, Chinese or English with a bundled Chinese font for offline use.
