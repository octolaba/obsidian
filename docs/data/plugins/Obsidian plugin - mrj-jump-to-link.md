# Jump to link

Jumps to links or to any word on the page using hotkeys and on-screen hint labels. A regex-based Jump to Anywhere mode navigates the editor and works in Vim mode, and a Lightspeed mode jumps by character and supports quick selection.

```cue
plugin: {
    id:     "mrj-jump-to-link"
    name:   "Jump to link"
    author: "mrjackphil"
    repo:   "mrjackphil/obsidian-jump-to-link"

    html_url:    "https://community.obsidian.md/plugins/mrj-jump-to-link"
    github_url:  "https://github.com/mrjackphil/obsidian-jump-to-link"
```
