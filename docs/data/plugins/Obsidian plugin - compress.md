# File Compressor

File Compressor stores Markdown and plain text in compact .ctxt files that are compressed on save and decompressed transparently when opened. A .ctxt file is created and edited like a normal note.

```cue
plugin: {
    id:     "compress"
    name:   "File Compressor"
    author: "networkmastered"
    repo:   "networkmastered/obsidian-compress"

    html_url:    "https://community.obsidian.md/plugins/compress"
    github_url:  "https://github.com/networkmastered/obsidian-compress"
    description: "Make your files smaller with compression!"
    about:       "Create .ctxt compressed text files and edit them like normal notes while the plugin compresses content automatically on save. Store Markdown and plain text in compact .ctxt files and have them decompressed transparently when opened."

    stats: {
        downloads:  333
        updated_at: 1743052976000
    }
}
```
