# Chess Tree

Chess Tree renders and plays chess games from FEN and PGN on an interactive draggable board that implements the full rules, including castling, en passant, promotions, repetition and the fifty-move count. Branching variations are managed in a tree view, FEN can be edited visually, annotations and marks added, and the result saved back to the source file.
