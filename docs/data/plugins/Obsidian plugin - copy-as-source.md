# Copy as source

Copy as source copies the HTML of selected elements from reading view to the clipboard as formatted source code. The HTML is run through Prettier before copying so the result stays readable.

```cue
plugin: {
    id:     "copy-as-source"
    name:   "Copy as source"
    author: "gapmiss"
    repo:   "gapmiss/copy-as-source"

    html_url:    "https://community.obsidian.md/plugins/copy-as-source"
    github_url:  "https://github.com/gapmiss/copy-as-source"
    description: "Select and copy source HTML in reading view."
    about:       "Copy selected elements' HTML from reading view to the clipboard as formatted source code. Format the HTML with Prettier before copying for clean, readable output."

    stats: {
        downloads:  2008
        updated_at: 1780255343000
    }
}
```
