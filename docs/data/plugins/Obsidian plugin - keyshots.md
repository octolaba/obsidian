# Keyshots

Adds classic hotkeys from Visual Studio Code, the JetBrains family and Visual Studio, so familiar editor commands are available in Obsidian. The commands cover line and selection actions such as move, duplicate, insert, join and split, sort, change case, encode and decode URIs, and toggling line numbers or readable line length.
