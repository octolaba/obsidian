# New Tab

New Tab replaces Obsidian's empty new-tab view with a customizable dashboard carrying seasonal or custom backgrounds, a 12- or 24-hour clock, a time-aware greeting, online or custom quotes, quick search, bookmarks and five recent files. Backgrounds can come from Unsplash, a local file or a URL, every element can be toggled individually, and settings can be imported from BeautiTab.

```cue
plugin: {
    id:     "newtab"
    name:   "New Tab"
    author: "Marcus Breiden"
    repo:   "mmomm-org/obsidian-newtab"

    html_url:    "https://community.obsidian.md/plugins/newtab"
    github_url:  "https://github.com/mmomm-org/obsidian-newtab"
    description: "Creates a customizable new tab view with beautiful backgrounds, quotes, search, and more. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Replace the empty new-tab view with a customizable dashboard showing seasonal or custom backgrounds, a 12/24 clock, time-aware greeting, online or custom quotes, quick search, bookmarks, and five recent files. Import BeautiTab settings or pick Unsplash/local/URL backgrounds and toggle each element individually."

    stats: {
        downloads:  308

    }
}
```
