# Export to HTML

Exports a note's content as HTML, either to the clipboard or as a downloadable file. Formatting is preserved and images are embedded as base64, so the exported HTML keeps its appearance when pasted or opened elsewhere.

```cue
plugin: {
    id:     "export-to-html"
    name:   "Export to HTML"
    author: "kalvn"
    repo:   "kalvn/obsidian-export-to-html"

    html_url:    "https://community.obsidian.md/plugins/export-to-html"
    github_url:  "https://github.com/kalvn/obsidian-export-to-html"
    description: "Export your Markdown notes as HTML, directly in the clipboard or as a file."
    about:       "Export note content as HTML to the clipboard or as a downloadable HTML file. Preserve formatting and embed images as base64 so exported HTML retains visual fidelity when pasted or opened elsewhere."
```
