# Target Word Count

Target Word Count disables editing until a target number of new words has been added across all documents. Progress is tracked across notes, and the restriction can be reset or stopped to resume editing.

```cue
plugin: {
    id:     "target-word-count"
    name:   "Target Word Count"
    author: "twofive-labs"
    repo:   "twofive-labs/target-word-count"

    html_url:    "https://community.obsidian.md/plugins/target-word-count"
    github_url:  "https://github.com/twofive-labs/target-word-count"
    description: "Disable editing until you've added a target number of words."
    about:       "Set a target word count and lock editing until you add that many new words across all documents. Track progress across notes and reset or stop the restriction to resume editing."

    stats: {
        downloads:  1089
        updated_at: 1712696577000
    }
}
```
