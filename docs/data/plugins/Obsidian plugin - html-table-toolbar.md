# HTML Table Toolbar

Edits real HTML tables inside Obsidian in place of Markdown pipe tables, which allows merged cells, multi-block content and centered tables. A contextual Word-style toolbar inserts and deletes rows and columns, merges and splits cells, toggles header rows, and aligns and sizes columns. Cells can be shaded from a swatch or a color picker, and borders can be set per row and per column.
