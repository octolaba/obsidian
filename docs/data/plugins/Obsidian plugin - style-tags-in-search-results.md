# Style Tags in Search Results

Tags shown in search results are given a CSS class, by default named search-tag, so they can be styled from a snippet. The same class hides the tags outright through injected CSS, which shortens matched lines and declutters the results pane.

```cue
plugin: {
    id:     "style-tags-in-search-results"
    name:   "Style Tags in Search Results"
    author: "fanis"
    repo:   "fanis/obsidian-style-tags-in-search-results"

    html_url:    "https://community.obsidian.md/plugins/style-tags-in-search-results"
    github_url:  "https://github.com/fanis/obsidian-style-tags-in-search-results"
    description: "Decorates tags in search results with a CSS class. Optionally it one-click hides them using injected CSS. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add a customizable CSS class (default .search-tag) to tags in search results to style or hide them. Hide tags automatically to declutter and shorten matched lines for a cleaner, more readable results pane."

    stats: {
        downloads:  145
        updated_at: 1783163415000
    }
}
```
