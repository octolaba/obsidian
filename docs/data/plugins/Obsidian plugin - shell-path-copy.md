# Shell Path Copy

Shell Path Copy copies vault file and folder paths in shell-friendly form for Windows, macOS and Linux, aimed at AI coding tools such as Claude Code and the Gemini CLI. Right-click entries in the explorer and command-palette options grab a relative or absolute path formatted for the target terminal or remote environment, on desktop and mobile.
