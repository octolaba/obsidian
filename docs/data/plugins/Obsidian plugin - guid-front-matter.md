# Add an ID to the front matter

Adds a globally unique GUID to the YAML front matter of every Markdown document as it is edited. A command inserts identifiers into all existing notes in the vault.

```cue
plugin: {
    id:     "guid-front-matter"
    name:   "Add an ID to the front matter"
    author: "llimllib"
    repo:   "llimllib/obsidian-guid-plugin"

    html_url:    "https://community.obsidian.md/plugins/guid-front-matter"
    github_url:  "https://github.com/llimllib/obsidian-guid-plugin"
    description: "Add a globally unique ID to every Markdown document's frontmatter."
    about:       "Add a unique GUID to the YAML front matter of Markdown files as you edit them. Run a command to insert IDs into all existing notes in your vault."

    stats: {
        downloads:  5596
        updated_at: 1687309573000
    }
}
```
