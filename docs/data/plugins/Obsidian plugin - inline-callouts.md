# Inline Callouts

Adds inline callouts, badges and icons to notes through a compact bracketed syntax carrying an icon, a label and a color. All Lucide icons are available, a modal and an editor autocomplete help insert, modify and search callouts, and the styles follow the active theme in preview.

```cue
plugin: {
    id:     "inline-callouts"
    name:   "Inline Callouts"
    author: "gapmiss"
    repo:   "gapmiss/inline-callouts"

    html_url:    "https://community.obsidian.md/plugins/inline-callouts"
    github_url:  "https://github.com/gapmiss/inline-callouts"
    description: "Add inline callouts/badges/icons to notes."
    about:       "Display inline callouts with a compact [!!ICON|LABEL|COLOR] syntax to embed icon, label and color directly in Markdown. Access all Lucide icons and use modal tools plus an editor autocomplete to insert, modify, and search callouts. Apply theme-aware styles for consistent rendering in preview."

    stats: {
        downloads:  8147

    }
}
```
