# Min Width

This plugin sets a minimum width for the active pane. The active pane is resized automatically and other panes shrink to preserve that width. Defaults are configurable with per-view-type overrides, and the CSS class min-width-plugin-active is added for custom styling.

```cue
plugin: {
    id:     "obsidian-min-width"
    name:   "Min Width"
    author: "doitian"
    repo:   "doitian/obsidian-min-width"

    html_url:    "https://community.obsidian.md/plugins/obsidian-min-width"
    github_url:  "https://github.com/doitian/obsidian-min-width"
    description: "Set the Minimum Width of the Active Pane."
```
