# Plotly

This plugin embeds Plotly charts in notes from plotly code blocks carrying JSON or YAML payloads for data, layout and config. Full Plotly JavaScript examples can be rendered, and dynamic plots built from note data through DataviewJS, which requires the Dataview plugin, using a provided wrapper that draws the plot inside the block.

```cue
plugin: {
    id:     "obsidian-plotly"
    name:   "Plotly"
    author: "dmytro-shulha"
    repo:   "dmytro-shulha/obsidian-plotly"

    html_url:    "https://community.obsidian.md/plugins/obsidian-plotly"
    github_url:  "https://github.com/dmytro-shulha/obsidian-plotly"
    description: "Embed Plotly charts in your notes."
    about:       "Embed Plotly charts in Markdown using plotly code blocks with JSON or YAML payloads for data, layout, and config. Render full Plotly JavaScript examples and create dynamic plots from note data via DataviewJS (requires Dataview), using a provided wrapper to draw plots inside blocks."

}
```
