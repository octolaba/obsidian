# Tab Numbers

Shows numbered badges from 1 to 8 on tabs while Ctrl or Cmd is held, revealing the tab-switch shortcuts for keyboard navigation. Numbering can be limited to the active split pane, and badge text and background colors are configurable.

```cue
plugin: {
    id:     "tab-numbers"
    name:   "Tab Numbers"
    author: "Jordan Duabe"
    repo:   "j4ckofalltrades/obsidian-tab-numbers"

    html_url:    "https://community.obsidian.md/plugins/tab-numbers"
    github_url:  "https://github.com/j4ckofalltrades/obsidian-tab-numbers"
    description: "Shows numbered badges (1-8) on tabs when holding Ctrl/Cmd for quick keyboard navigation. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display numbered badges (1–8) on tabs while holding Ctrl/Cmd to reveal tab-switch shortcuts. Limit numbers to the active split pane and customize badge text and background colors."

    stats: {
        downloads:  194
        updated_at: 1779526783000
    }
}
```
