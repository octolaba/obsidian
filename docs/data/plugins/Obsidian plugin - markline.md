# Markline

Markline displays a timeline view generated from Markdown inside the Obsidian editor, defined in markline code blocks. Years, months, days and date ranges are parsed, and headings are treated as groups. Optional metadata such as age and mention links can be attached to entries.

```cue
plugin: {
    id:     "markline"
    name:   "Markline"
    author: "hotoo"
    repo:   "hotoo/obsidian-markline"

    html_url:    "https://community.obsidian.md/plugins/markline"
    github_url:  "https://github.com/hotoo/obsidian-markline"
    description: "Timeline view from Markdown"
    about:       "Display timeline views from Markdown directly in the Obsidian editor using markline code blocks. Parse years, months, days and date ranges, treat headings as groups, and include optional metadata like age and mention links to enrich entries."
```
