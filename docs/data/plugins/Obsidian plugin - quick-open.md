# Quick Select

Selects an item in any Obsidian modal by pressing a modifier together with a number, jumping straight to a file, command, tag or suggestion. It applies across the quick switcher, command palette, slash commands, search, tags and aliases, so selection stays on the keyboard.

```cue
plugin: {
    id:     "quick-open"
    name:   "Quick Select"
    author: "James Alexandre"
    repo:   "itsonlyjames/obsidian-quick-select"

    html_url:    "https://community.obsidian.md/plugins/quick-open"
    github_url:  "https://github.com/itsonlyjames/obsidian-quick-select"
    description: "Quickly select items in any modal using keyboard shortcuts. Supercharge your workflow with fast, efficient item selection."
    about:       "Open items in any Obsidian modal by pressing Mod+number to jump to files, run commands, select tags, or pick suggestions. Use across the quick switcher, command palette, slash commands, search, tags and aliases for instant, keyboard-driven selection."

}
```
