# Image Actions

Image Actions adds a hover toolbar on images that copies an image to the clipboard, reveals a local image in the system file explorer, or opens a remote image in the browser. It works in Reading view and Live Preview, copied images are re-encoded as PNG, and touch-and-hold copies an image on mobile.
