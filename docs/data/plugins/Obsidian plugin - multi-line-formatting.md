# Multi-line Formatting

Applies paired formatting delimiters to a whole selection even when the selection spans paragraph breaks. Custom formatting styles and their commands can be defined, and toggling a format with nothing selected applies it to the following keystrokes.

```cue
plugin: {
    id:     "multi-line-formatting"
    name:   "Multi-line Formatting"
    author: "nmady"
    repo:   "nmady/obsidian-multi-line-formatting"

    html_url:    "https://community.obsidian.md/plugins/multi-line-formatting"
    github_url:  "https://github.com/nmady/obsidian-multi-line-formatting"
    description: "Apply formatting to selected text, dealing with the paragraph breaks."
    about:       "Format entire selections across paragraph breaks, applying paired delimiters to text even when the selection spans multiple paragraphs. Create custom formatting styles and commands, and toggle formatting on with no selection to apply to your next keystrokes."

    stats: {
        downloads:  8746
        updated_at: 1632496690000
    }
}
```
