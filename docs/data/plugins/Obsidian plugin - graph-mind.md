# Graph Mind

Indexes the vault into a local semantic search engine and ranks relevant passages with embeddings. A sidebar chat answers from those notes and its citations jump to the source, while filters narrow results by tags, path, extension or exact phrase. Everything runs locally, with a local Ollama server providing chat and embeddings.
