# Node Auto Resize

Node Auto Resize resizes a canvas node to fit its content whenever that content changes. Width auto-resize can be enabled and a maximum width set, so node layouts stay bounded.

```cue
plugin: {
    id:     "node-auto-resize"
    name:   "Node Auto Resize"
    author: "Boninall"
    repo:   "quorafind/Obsidian-Node-Auto-Resize"

    html_url:    "https://community.obsidian.md/plugins/node-auto-resize"
    github_url:  "https://github.com/quorafind/Obsidian-Node-Auto-Resize"
    description: "Automatically resize the node when the content changes."
    about:       "Resize canvas nodes to fit their content automatically. Enable width auto-resize and set a maximum width to keep node layouts tidy."

    stats: {
        downloads:  8787

}
```
