# Bible Verse

Bible Verse looks up and displays verses in a note through the HelloAO Bible API, which the recorded inputs state needs no API key. An inline reference in braces produces a linked verse while a bible code block renders a full passage, with autocomplete, side-by-side translation comparison and links to major Bible websites. Verses are cached locally and Scripture can optionally be baked permanently into the Markdown.

```cue
plugin: {
    id:     "bible-verse"
    name:   "Bible Verse"
    author: "kilrkrow"
    repo:   "kilrkrow/obsidian-bible-verse"

    html_url:    "https://community.obsidian.md/plugins/bible-verse"
    github_url:  "https://github.com/kilrkrow/obsidian-bible-verse"
    description: "Look up and display Bible verses directly in your notes using the HelloAO Bible API. Supports inline references, code blocks, comparison views, and multiple Bible websites. No API key required. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Look up and display Bible verses directly in your notes. Type {John 3:16} for inline linked verses or use bible code blocks to render full passages, use autocomplete, compare translations side-by-side, link to major Bible sites, cache verses locally, and optionally bake scripture into your Markdown — no API key required."

    stats: {
        downloads:  229
        updated_at: 1783633141000
    }
}
```
