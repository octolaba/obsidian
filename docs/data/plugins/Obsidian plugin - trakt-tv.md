# Trakt.tv Sync

Trakt.tv Sync writes watched shows from Trakt into a dated note in the vault, recording each check-in as an entry with a date backlink. A Trakt Rating History file is populated with bulleted entries linking every show and episode to its Trakt page and to the daily note for that date.

```cue
plugin: {
    id:     "trakt-tv"
    name:   "Trakt.tv Sync"
    author: "fleker"
    repo:   "fleker/trakt-for-obsidian"

    html_url:    "https://community.obsidian.md/plugins/trakt-tv"
    github_url:  "https://github.com/fleker/trakt-for-obsidian"
    description: "Syncs your watched Trakt.tv shows to a file."
    about:       "Sync Trakt check-ins into a dated Obsidian note with per-entry date backlinks. Populate a Trakt Rating History.md as bulleted entries linking shows and episodes to their Trakt pages and to [[YYYY-MM-DD]] daily notes."

    stats: {
        downloads:  723
        updated_at: 1771985232000
    }
}
```
