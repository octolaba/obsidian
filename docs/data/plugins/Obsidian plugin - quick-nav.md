# Quick Nav

Exposes cursor navigation and selection commands for fine-grained movement, shipping no preset shortcuts of its own. Custom hotkeys are assigned for line, page and end movements and for the matching selection variants.

    id:     "quick-nav"
    name:   "Quick Nav"
    author: "exoticknight"
    repo:   "exoticknight/quick-nav"

    html_url:    "https://community.obsidian.md/plugins/quick-nav"
