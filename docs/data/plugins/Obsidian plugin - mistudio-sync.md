# MiStudio Sync

MiStudio Sync synchronizes MiStudio folders and notes with an Obsidian vault, always downloading notes as Markdown and optionally uploading edits for two-way sync, including task check-in. It generates a tasks note, a calendar note and a daily note from the MiStudio workspace, and adds mistudio_id, mistudio_folder_id, created and synced frontmatter so that synced notes are recognized and duplicates avoided. The recorded About text is written in Spanish.
