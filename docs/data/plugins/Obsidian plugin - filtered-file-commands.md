# Note Types

Defines custom note types, each with its own template, save folder and frontmatter-driven fields. Create and Find commands open filtered pickers for a type, notes can be created from a selection, and a type can be triggered inline. Links to typed notes are styled and show hover preview cards, and a collapsible Filtered Files sidebar widget browses matches.
