# Places - OpenRouteService

Adds OpenRouteService routing to Places, with directions, isochrones, POI search, elevation replacement and track snapping. Routes are built between waypoints, reachability polygons are generated, search terms resolve to place suggestions, elevation is read for track points, and recorded tracks are aligned to roads and paths.
