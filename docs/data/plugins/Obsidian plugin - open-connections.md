# Open Connections

Open Connections finds semantically related notes and searches the vault by meaning rather than by keyword. Embeddings run on-device without an API key, or through OpenAI, Gemini, Ollama and other remote models, and a live Connections view lists what relates to the current note. Embeddings are cached locally, and notes can also be chatted with.
