# Harvest

Harvest connects Obsidian to Harvest time tracking so timers are controlled without leaving a note. Timers are started, stopped and inspected from the plugin, and the status bar shows the running project, task and duration. Time reports are generated inside notes through a query language.

```cue

    id:     "harvest"
    name:   "Harvest"
    author: "nwbort"
    repo:   "nwbort/obsidian-harvest"

    github_url:  "https://github.com/nwbort/obsidian-harvest"
```
