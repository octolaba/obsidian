# Graph Styler

Applies curated one-click presets to the graph view, setting colour palettes, glow effects and layout forces without writing CSS. Palettes are mapped automatically onto the top folders or tags and the colours are written into Obsidian's native graph groups. Custom presets can be saved with live previews, and backups can be restored.
