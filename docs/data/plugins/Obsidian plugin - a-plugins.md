# A Loader

A Loader manages when community plugins start, from a single-page list meant to make plugin-heavy vaults load more smoothly. Nonessential plugins can be delayed and unused ones disabled, and recorded plugin load times inform those decisions. It works on mobile as well as desktop.

```cue
plugin: {
    id:     "a-plugins"
    name:   "A Loader"
    author: "Jiao Yingxing"
    repo:   "jiaoyingxing/a-plugins"

    html_url:    "https://community.obsidian.md/plugins/a-plugins"
    github_url:  "https://github.com/jiaoyingxing/a-plugins"
    description: "Make plugin-heavy Obsidian vaults start smoother, especially on mobile. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Manage community plugins' startup timing from a lightweight one‑page list. Delay nonessential plugins to cut Obsidian startup load and disable unused plugins. Record simple plugin load times to guide decisions and support both mobile and desktop."

    stats: {
        downloads:  466
        updated_at: 1785252366000
    }
}
```
