# Virus Total Enrichment

Virus Total Enrichment queries VirusTotal from Obsidian for intelligence on files, URLs, IPs and domains. Results enrich a note with properties such as hashes, filetype and creation date, added either as note content or as metadata for Dataview queries. A VirusTotal API key is required.

```cue
plugin: {
    id:     "virustotal-enrich"
    name:   "Virus Total Enrichment"
    author: "ytisf"
    repo:   "ytisf/virustotal-enrich"

    html_url:    "https://community.obsidian.md/plugins/virustotal-enrich"
    github_url:  "https://github.com/ytisf/virustotal-enrich"
    description: "Enrich your notes with information from VirusTotal."
    about:       "Query VirusTotal directly in Obsidian to fetch intelligence on files, URLs, IPs, and domains. Enrich notes with detailed properties like hashes, filetype, and creation date, and add them as note content or metadata for Dataview queries. Provide a VirusTotal API key to enable queries."
```
