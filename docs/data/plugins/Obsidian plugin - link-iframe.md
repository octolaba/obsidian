# I link therefore iframe

Converts selected URLs into native inline iframe embeds, with a live preview shown before the embed is inserted. More than thirty providers are supported, images and Google Docs can be saved into the vault, and Quizlet flashcard sets can be exported to local Markdown notes.

```cue
plugin: {
    id:     "link-iframe"
    name:   "I link therefore iframe"
    author: "gilgamesh-tamarian"
    repo:   "gilgamesh-tamarian/obsidian-link-iframe"

    html_url:    "https://community.obsidian.md/plugins/link-iframe"
    github_url:  "https://github.com/gilgamesh-tamarian/obsidian-link-iframe"
    description: "Converts URLs into native iframe embeds and auto-formats embeddables. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert selected URLs into rich inline iframe embeds with a live preview to confirm before inserting. Support 30+ providers, save images and Google Docs into your vault, and export Quizlet flashcard sets to local Markdown notes."

    stats: {
        downloads:  1034
        updated_at: 1774349520000
    }
}
```
