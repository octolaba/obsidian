# Text Format

Selected text or a note title is converted to lowercase, uppercase, capitalized, title case, slug or snake case, or cycled between cases. Further commands clean redundant spaces and newlines, fix Markdown headings and convert citation indexes for academic notes. Format-on-paste is offered as experimental.
