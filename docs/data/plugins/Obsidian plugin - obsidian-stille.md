# Stille

A minimalist overlay dims the surrounding text and highlights the active section, so writing proceeds one section at a time. The overlay is toggled on and off as needed.

```cue
plugin: {
    id:     "obsidian-stille"
    name:   "Stille"
    author: "michaellee"
    repo:   "michaellee/stille"

    html_url:    "https://community.obsidian.md/plugins/obsidian-stille"
    github_url:  "https://github.com/michaellee/stille"
    description: "Focus on your writing, a section at a time."
    about:       "Focus on one section at a time to write without distractions. Toggle a minimalist overlay that dims surrounding text and highlights the active section for clearer, uninterrupted composition."
```
