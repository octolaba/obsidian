# Annotate Audio

Plays audio in a note with adjustable volume, speed, looping and millisecond-precise seeking. Timestamped comments in LRC format annotate positions and jump to them, and annotations can be edited or deleted. Keyboard commands, mobile controls and interface localization are included.

```cue
plugin: {
    id:     "annotate-audio"
    name:   "Annotate Audio"
    author: "12-vide"
    repo:   "12-vide/annotate-audio"

    html_url:    "https://community.obsidian.md/plugins/annotate-audio"
    github_url:  "https://github.com/12-vide/annotate-audio"
    description: "Listen to an audio and add comments to it."
    about:       "Play and tweak audio with adjustable volume, speed, looping and millisecond-precise seeking. Add LRC-formatted timestamped comments to jump to sections, edit or delete annotations, use keyboard commands or mobile controls, and localize the interface."
```
