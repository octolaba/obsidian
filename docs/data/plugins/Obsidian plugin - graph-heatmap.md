# Graph Heatmap

Colours graph nodes by recency, connectedness, word count or file size, with twelve palettes and a relative or absolute scale. A focus mode isolates hubs, orphans, stubs or stale notes and fades or hides the rest, while a halo marks recent edits. Hovering a node shows its path, metric value, modified time, connection count and rank, and controls sit in an in-graph panel.
