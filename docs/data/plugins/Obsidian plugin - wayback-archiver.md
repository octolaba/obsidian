# Wayback Archiver

Archives web links through the Wayback Machine and appends the archived snapshot beside the original link in the note. A single note or the entire vault can be scanned, with include and exclude filters and URL substitution rules deciding what is sent. Failed attempts can be retried, and settings are kept in profiles for targeted or vault-wide runs.
