# Feedly Annotations Sync

Feedly Annotations Sync writes Feedly highlights, annotations and comments into a folder in the vault as one Markdown file per article, with frontmatter metadata and quoted highlights. Article URLs, dates, authors and publishers are preserved. A sync interrupted by Feedly API rate limits can be resumed.

```cue
plugin: {
    id:     "feedly-annotations"
    name:   "Feedly Annotations Sync"
    author: "fleker"
    repo:   "fleker/feedly-for-obsidian"

    html_url:    "https://community.obsidian.md/plugins/feedly-annotations"
    github_url:  "https://github.com/fleker/feedly-for-obsidian"
    description: "Syncs Feedly highlights and annotations to a folder in your vault."
    about:       "Sync Feedly annotations and comments into your vault as individual Markdown files, one per article, with frontmatter metadata and quoted highlights. Place files in a dedicated folder and preserve article URLs, dates, authors and publishers. Resume interrupted syncs after Feedly API rate limits."

    stats: {
        downloads:  635
        updated_at: 1785597792000
    }
}
```
