# Canvas Export

Canvas Export writes .canvas files out as HTML in a light or dark variant, Excalidraw, Mermaid, D2 or print-ready PDF. The HTML output is self-contained and clickable and preserves layout and colors. Text, groups, edges and embeds are converted into editable or best-fit representations, and YAML frontmatter is stripped.
