# OneDrive Sync

OneDrive Sync connects a vault to OneDrive Personal with zero-configuration authentication and a mobile-friendly device code flow. Syncing is event-driven and file-change based for battery efficiency, runs in both directions with conflict resolution, and works in App Folder or full access mode.
