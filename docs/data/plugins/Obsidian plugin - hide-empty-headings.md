# Hide Empty Headings

Hide Empty Headings hides headings that have no content beneath them while a note is shown in reading mode. The view is refreshed when the note is switched, so only headings with content stay visible.

```cue
plugin: {
    id:     "hide-empty-headings"
    name:   "Hide Empty Headings"
    author: "醒醒-关于我(https://xingxing.aigongxue.cfd/)"
    repo:   "duluodexiaopiqiu/hide-empty-headings"

    html_url:    "https://community.obsidian.md/plugins/hide-empty-headings"
    github_url:  "https://github.com/duluodexiaopiqiu/hide-empty-headings"
    description: "隐藏阅读模式下没有内容的标题 - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Hide empty headings in reading mode when no content exists beneath them. Refresh on note switch to keep only headings with content visible."

    stats: {
        downloads:  63
        updated_at: 1781599572000
    }
}
```
