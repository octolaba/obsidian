# VaultPrune - Unused Attachment Cleaner

VaultPrune scans the vault for attachments that nothing references any more, including references inside Markdown and Canvas files. Candidates are reviewed with search, filters, sorting and bulk selection, and a report can be previewed before anything is removed. Chosen files are then moved to Obsidian's trash.
