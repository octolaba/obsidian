# Morning OS

Builds a daily briefing dashboard from the vault that surfaces tasks, goals, rules and AI-picked insights each morning. It detects carryover tasks and records what was resolved and what is still open. Identity affirmations and suggestions come from several AI providers named by the recorded text.

    id:     "morning-os"
    name:   "Morning OS"
    author: "Satya Akhil Galla"
    repo:   "satyagalla/Morning-OS-obsidian"

    github_url:  "https://github.com/satyagalla/Morning-OS-obsidian"
