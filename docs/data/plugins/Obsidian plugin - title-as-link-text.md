# Title As Link Text

Title As Link Text rewrites link text so links display note titles instead of filenames, covering both wikilink and Markdown link forms. The title is inferred from frontmatter, the first H1 or the filename, aliases are respected through fuzzy matching, and links are updated automatically on save or rename.

```cue
plugin: {
    id:     "title-as-link-text"
    name:   "Title As Link Text"
    author: "lextoumbourou"
    repo:   "lextoumbourou/obsidian-title-as-link-text"

    html_url:    "https://community.obsidian.md/plugins/title-as-link-text"
    github_url:  "https://github.com/lextoumbourou/obsidian-title-as-link-text"
    description: "Automatically updates link text to use note titles instead of filenames."
    about:       "Transform links to use note titles instead of filenames, converting Wikilinks and Markdown links to display titles inferred from frontmatter, the first H1, or filename. Automatically update links on save or rename and respect aliases with fuzzy matching."

    stats: {
        downloads:  4330

    }
}
```
