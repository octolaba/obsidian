# newslog

newslog bundles newsletters, RSS feeds and articles into one daily digest carrying an index and an AI-generated summary, meant to help decide what to read. Digests can be sent to Kindle or email, and the plugin syncs the full Markdown bundles from newslog.me, together with Kindle highlights, into the vault.

```cue
plugin: {
    id:     "newslog"
    name:   "newslog"
    author: "protoavatar"
    repo:   "protoavatar/obsidian-newsletters"

    html_url:    "https://community.obsidian.md/plugins/newslog"
    github_url:  "https://github.com/protoavatar/obsidian-newsletters"
    description: "Sync newsletters and kindle highlights from your newslog.me daily bundles."
    about:       "Bundle newsletters, RSS feeds, and articles into a single daily digest with an index and AI-generated summary to help decide what to read. Send digests to Kindle or email, and save full Markdown bundles plus synced Kindle highlights directly into your Obsidian vault."

    stats: {
        downloads:  508
        updated_at: 1765820345000
    }
}
```
