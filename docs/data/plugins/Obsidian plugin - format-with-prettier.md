# Format with Prettier

Formats files in the vault with Prettier so Markdown and other supported files stay consistently styled. Formatting runs on save or through the Format Current File command, and is controlled by a prettierrc.json placed at the vault root.

```cue
plugin: {
    id:     "format-with-prettier"
    name:   "Format with Prettier"
    author: "alexgavrusev"
    repo:   "alexgavrusev/obsidian-format-with-prettier"

    html_url:    "https://community.obsidian.md/plugins/format-with-prettier"
```
