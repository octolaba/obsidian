# Micro.publish

Micro.publish sends notes, pages and short microposts from the vault to Micro.blog with titles, tags, draft or public visibility, and an optional scheduled date. Local images are uploaded and their links replaced with hosted URLs, categories are synced for tag suggestions, and YAML frontmatter is read and written. Multiple blogs are supported, and post URLs are saved so entries can be updated later.

```cue
plugin: {
    id:     "microblog-publish-plugin"
    name:   "Micro.publish"
    author: "Otávio Cordeiro"
    repo:   "otaviocc/obsidian-microblog"

    html_url:    "https://community.obsidian.md/plugins/microblog-publish-plugin"
    github_url:  "https://github.com/otaviocc/obsidian-microblog"
    description: "Publish notes to Micro.blog."
    about:       "Publish notes, pages, and short microposts from your vault to Micro.blog with titles, tags, visibility (draft/public), and optional scheduled dates. Upload local images and replace links with hosted URLs, sync categories for tag suggestions, read/write YAML frontmatter, support multiple blogs, and save post URLs for easy updates."
```
