# Flash Memo

Captures fleeting thoughts from a dedicated sidebar panel, saving each memo as a standalone Markdown file in a memos folder with YAML date and tags. The memos are displayed in a timeline view that is searched and filtered in real time by content or tags. Sorting is by creation or modification time.

```cue
plugin: {
    id:     "flash-memo"
    name:   "Flash Memo"
    author: "ydhawesome"
    repo:   "ydhawesome/flash-memo"

    html_url:    "https://community.obsidian.md/plugins/flash-memo"
    github_url:  "https://github.com/ydhawesome/flash-memo"
    description: "Capture fleeting thoughts instantly. Each memo is a standalone file, displayed in a timeline view. - This plugin has not been manually reviewed by Obsidian staff."
```
