# Note Image Gallery

Note Image Gallery collects all images from the current note into a responsive masonry gallery with a lightbox offering keyboard navigation, zoom and a context menu for copying or downloading. Local and remote images are both supported, and lazy loading, virtual scrolling and a file-based cache with automatic cleanup keep the view smooth.
