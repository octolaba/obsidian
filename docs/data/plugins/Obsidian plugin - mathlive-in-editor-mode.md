# MathLive in Editor Mode

MathLive in Editor Mode edits LaTeX inline or in blocks through MathLive widgets inside the Obsidian editor, with a choice of display modes. MathLive can be toggled per note or per block, or switched to the built-in MathJax. Macros, shortcuts and hotkeys are available for live editing.
