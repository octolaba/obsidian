# Lens

Lens examines a note or a selection through thinking lenses such as Challenge, Steelman and Concretize, and further lenses can be added. Results stream into a side panel and can be saved as linked, tagged notes. Models are run through Anthropic, OpenAI-compatible hosts or local servers.

plugin: {
    id:     "lens"
    name:   "Lens"
    author: "Fred Oliveira"
