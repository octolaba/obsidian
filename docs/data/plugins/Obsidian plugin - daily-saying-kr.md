# Daily Saying KR

Inserts a random Korean one-line saying into the current note from a local dataset. The saying can be inserted from the command palette or substituted for a template placeholder, and because the dataset is local the plugin works offline.

```cue
plugin: {
    id:     "daily-saying-kr"
    name:   "Daily Saying KR"
    author: "Rando209"
    repo:   "randonneurs/daily-saying-kr"

    html_url:    "https://community.obsidian.md/plugins/daily-saying-kr"
    github_url:  "https://github.com/randonneurs/daily-saying-kr"
    description: "Insert a random Korean saying into the current note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Daily Saying KR inserts a random Korean one-line saying into the current note from a local dataset. Use the {{daily-saying-kr}} template placeholder for automatic replacement, or insert a saying instantly from the command palette. Works fully offline."

    stats: {
        downloads:  78
        updated_at: 1778921269000
    }
}
```
