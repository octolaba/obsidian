# Image Baker

Image Baker embeds images into a note as Base64 so the note becomes a single self-contained Markdown file without separate attachments. Baking is reversible: embeds are extracted back to files with their original names and folders, conversion runs per image, per note or across the vault, and images can be re-encoded to WebP or JPEG with a dry-run preview.

```cue
plugin: {
    id:     "image-baker"
    name:   "Image Baker"
    author: "bartekmp"
    repo:   "bartekmp/obsidian-image-baker"

    html_url:    "https://community.obsidian.md/plugins/image-baker"
    github_url:  "https://github.com/bartekmp/obsidian-image-baker"
    description: "Bake images into your notes as self-contained Base64 embeds, and extract them back into vault files at any time. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Bake images into notes as self-contained Base64 embeds so each note becomes a single portable .md file without attachment clutter. Un-bake images back to regular files with original names and folders, convert embeds per image/note/vault, and optionally re-encode to WebP/JPEG with a dry-run preview."

    stats: {
        downloads:  387
        updated_at: 1781126340000
    }
}
```
