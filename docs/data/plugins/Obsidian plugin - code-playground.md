# Code Playground

Embeds editable Sandpack playgrounds in a note and previews them in place, covering React, Vue, Svelte, Angular, Solid, Next.js and plain HTML, CSS, TypeScript and JavaScript. Each block can override the configuration in JSON, and edits persist in sidecar files. Previews are compiled by CodeSandbox's hosted bundler, so code and dependencies are sent externally unless a self-hosted bundler is used.

```cue
plugin: {
    id:     "code-playground"
    name:   "Code Playground"
    author: "touss59"
    repo:   "touss59/obsidian-code-playground"

    html_url:    "https://community.obsidian.md/plugins/code-playground"
    github_url:  "https://github.com/touss59/obsidian-code-playground"
    description: "Live, editable code playgrounds with instant preview inside your notes: HTML/CSS, React, Vue, Svelte, Angular, Solid, Next.js, TypeScript, JavaScript and more. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed live, editable Sandpack code playgrounds directly in Obsidian notes. Run React, Vue, Svelte, Angular or vanilla sandboxes in-place with per-block JSON overrides and persistent sidecar edits; previews compile via CodeSandbox's hosted bundler so code and dependencies are sent externally unless you use a self-hosted bundler."
```
