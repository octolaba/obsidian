# Easy Copy

Copies content according to where the cursor sits, extracting inline code, bold, italic or highlighted text, or a whole heading or block, without the surrounding formatting characters. It can also generate and copy a link to a heading, or create a new block ID and copy the resulting block link.

    id:     "easy-copy"
    name:   "Easy Copy"
    author: "Moy"
    repo:   "moyf/easy-copy"

    github_url:  "https://github.com/moyf/easy-copy"
    description: "Easily copy the text within inline code, bold text (and many other formats), or quickly generate an elegant link to a heading or block."
