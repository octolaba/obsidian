# Local Office Preview

Provides a read-only local preview for PPT/PPTX, XLS/XLSX, DOC/DOCX, TXT and LOG files without creating duplicate preview files in the vault. Modern Office files open in HTML and table previews, legacy formats get a temporary PDF preview, and extractable text can be copied. Conversions are cached in the system temp directory and nothing is uploaded.
