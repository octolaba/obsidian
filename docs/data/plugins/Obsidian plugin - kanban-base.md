# Kanban Base

Adds two Kanban views to Bases: one groups notes into columns by a text property, the other treats each immediate subfolder as a column. Dragging a card between columns either updates the note's property or physically moves the file between folders, in which case Obsidian updates links automatically.

```cue
plugin: {
    id:     "kanban-base"
    name:   "Kanban Base"
    author: "Jay"
    repo:   "jaidetree/obsidian-kanban-base"

    html_url:    "https://community.obsidian.md/plugins/kanban-base"
    github_url:  "https://github.com/jaidetree/obsidian-kanban-base"
    description: "Add kanban views to Bases, organized by folder structure or property values. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add two Kanban views to Bases: group notes into columns by a text property or use each immediate subfolder as a column. Drag cards between columns to update the note's property or physically move the file between folders with Obsidian updating links automatically."
```
