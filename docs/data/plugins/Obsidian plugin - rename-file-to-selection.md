# Rename File to Selection

Renames the active file to the current text selection, sanitizing it first into a filesystem-safe filename. A single command does this, so a file can be renamed from highlighted text without retyping.

```cue
plugin: {
    id:     "rename-file-to-selection"
    name:   "Rename File to Selection"
    author: "aavagames"
    repo:   "aavagames/obsidian-rename-file-to-selection"

    html_url:    "https://community.obsidian.md/plugins/rename-file-to-selection"
    github_url:  "https://github.com/aavagames/obsidian-rename-file-to-selection"
    description: "Rename your file to the current text selection."
    about:       "Rename the active file to the current text selection after sanitizing it into a filesystem-safe filename. Trigger the command to quickly rename files from highlighted text without retyping."

    stats: {
        downloads:  456

}
```
