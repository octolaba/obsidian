# GitHub Pager

Treats Obsidian as a headless CMS and publishes selected notes and images to a GitHub repository feeding Hugo, Jekyll, Hexo or another static site generator. Local files are mapped to remote paths, sync runs on save or as a batch commit, wikilinks are converted to Markdown links and embedded images are uploaded.

```cue
plugin: {
    id:     "github-pager"
    name:   "GitHub Pager"
    author: "cloudac7"
    repo:   "cloudac7/obsidian-github-pager"

    html_url:    "https://community.obsidian.md/plugins/github-pager"
    github_url:  "https://github.com/cloudac7/obsidian-github-pager"
    description: "Selectively publish your notes and images to GitHub for Hugo/Jekyll/Hexo sites. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Treat Obsidian as a headless CMS and publish selected notes and images to a GitHub repo for Hugo, Jekyll, Hexo, or other static site generators. Map local files to remote paths, auto-sync on save or batch commit, convert [[WikiLinks]] to Markdown, and upload embedded images."

    stats: {
        downloads:  130
        updated_at: 1778489230000
    }
}
```
