# Ordered List Style

Sets the numbering style of an ordered list inline, by placing a style token in the first list item, so alphabetic, Roman-numeral, and zero-padded lists are possible. Full style names or shorthands can be used, and the recorded inputs note that the style applies to the whole list and cannot be changed part-way through it.

```cue
plugin: {
    id:     "list-style"
    name:   "Ordered List Style"
    author: "erykwalder"
    repo:   "erykwalder/obsidian-list-style"

    html_url:    "https://community.obsidian.md/plugins/list-style"
    github_url:  "https://github.com/erykwalder/obsidian-list-style"
    description: "Set ordered list style inline. Alphabetic lists, Roman numeral lists, etc."
    about:       "Set ordered list numbering style inline by placing a style token in the first list item (e.g., {A}, {i}, {01}). Use full style names or shorthands for common types; note the style applies to the entire list and cannot be changed mid-list."

    stats: {
        downloads:  10653
        updated_at: 1666384268000
    }
}
```
