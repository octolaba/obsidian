# Selection Format Toolbar

Selection Format Toolbar shows a floating formatting toolbar when text is selected, offering bold, italic, heading levels one through six, six highlight colors and a clear button. The selection is kept after each action so that formats can be chained, and highlights are written as inline mark elements that render in Live Preview and Reading mode.
