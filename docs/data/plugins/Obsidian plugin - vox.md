# Vox

Vox transcribes voice notes into searchable Markdown files carrying frontmatter, tags and an automatic category. It watches an unprocessed folder and queues new audio for remote transcription, tuned for English and capped at 100 transcriptions per day. Completed notes are then saved into the vault.
