# Enzyme

A chat agent over the vault that surfaces connections with semantic search and weaves them into clickable digests, pushing the reader back to older thinking. Embeddings run on-device, so it can operate fully locally, and a catalyst reasoning layer surfaces relationships beyond keyword overlap. Clicking an excerpt opens its source note in Obsidian.
