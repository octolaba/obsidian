# Paper Manager

Turns the vault into a local library for importing, reading, annotating and analyzing academic PDFs, keeping the papers and annotations as local files. The library can be searched and filtered, metadata edited, and PDFs annotated and exported. Optional paid AI analyses upload the selected papers.

    id:     "paper-manager"
    name:   "Paper Manager"
    author: "Elliot Dong"
