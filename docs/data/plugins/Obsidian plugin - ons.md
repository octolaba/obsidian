# BetaX NAS Sync

BetaX NAS Sync keeps a vault synchronised with a NAS on the home intranet so notes stay stored on a private network. The NAS is registered with the central server to pair devices, a connection password can be enabled for security, and updates are run manually from Obsidian to push or pull vault contents.
