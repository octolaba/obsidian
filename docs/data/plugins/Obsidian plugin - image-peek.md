# Image Peek

Opens an image in a Quick Look style preview that zooms out from the thumbnail with a FLIP animation, compared in the recorded description to Finder and Freeform. Clicking an image or pressing Space opens it, and the preview supports panning, pinch and scroll zoom, and arrow-based browsing across the images on the page. Images, including external ones, can be shared or copied, the source file can be opened, and closing zooms the image back into place.
