# Daily Routine

Manages recurring routines and one-off todos, generating daily routine notes that record the tasks by date. Routines and todos are shown on a calendar, and completion is tracked with visual statistics. The interface is usable on mobile.

    id:     "daily-routine"
    name:   "Daily Routine"
    author: "sechan100"
    repo:   "sechan100/daily-routine-2"

    html_url:    "https://community.obsidian.md/plugins/daily-routine"
    github_url:  "https://github.com/sechan100/daily-routine-2"
    description: "Manage your daily tasks as 'ROUTINES' and organize your everyday life more effectively."
