# Lina

Lina builds a local textual index of the vault, splitting notes into searchable text blocks stored in a .lina index. Searches run over note name, path or content, and a hybrid mode combines textual with local semantic search, reporting relevance, similarity and source indicators. With a local model through Ollama it analyses notes and suggests YAML, tags, links, tasks and folder organisation without modifying files by itself.
