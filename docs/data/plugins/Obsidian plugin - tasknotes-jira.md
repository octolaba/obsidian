# TaskNotes for Jira

Imports Jira issues into TaskNotes tasks using configurable field mappings, merged sources, remapped status and priority values, and optional backlinks to Jira. Resolved values can be previewed and the raw JSON sample inspected and copied before import. Mapped tasks are submitted through the TaskNotes API, preserving descriptions and producing safe filenames.

    id:     "tasknotes-jira"
