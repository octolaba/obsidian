# Noor

Noor inserts random Quran or Hadith quotes at the cursor, carrying the Arabic text, selectable translation and recitation information, and source links. It can also create or update a Dhikr file holding one Quran and one Hadith quote. The calls noorJS.randomQuranQuote() and noorJS.randomHadithQuote() expose the same fetches to scripts and templates.

```cue
plugin: {
    id:     "noor"
    name:   "Noor"
    author: "mksherbini"
    repo:   "mksherbini/obsidian-noor"

    html_url:    "https://community.obsidian.md/plugins/noor"
    github_url:  "https://github.com/mksherbini/obsidian-noor"
    description: "Aims to help Muslims stay enlightened with Islam, Quran, Hadith, and Sunnah"
    about:       "Insert random Quran or Hadith quotes at the cursor with Arabic text, selectable translation and recitation info, and source links. Create or update a Dhikr file containing a Quran and Hadith quote and call noorJS.randomQuranQuote() / noorJS.randomHadithQuote() from scripts or templates to fetch quotes programmatically."

    stats: {
        downloads:  913
        updated_at: 1729288559000
    }
}
```
