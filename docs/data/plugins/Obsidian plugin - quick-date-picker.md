# Quick Date Picker

Summons a mini calendar in a document by typing @ or another configured trigger, so a date is picked with mouse or keyboard and inserted. Relative shortcuts such as +3d or -1w resolve directly to a date, several output formats are switched from the popup, and the picker also works in note titles. The interface adapts to English and Chinese.

```cue
plugin: {
    id:     "quick-date-picker"
    name:   "Quick Date Picker"
    author: "LDD"
    repo:   "ritalee2333/obsidian-quick-date-picker"

    html_url:    "https://community.obsidian.md/plugins/quick-date-picker"
    github_url:  "https://github.com/ritalee2333/obsidian-quick-date-picker"
    description: "Quickly summon a mini calendar by typing @ (or your custom trigger) in documents to pick dates and choose output formats on the fly. Also supports relative date shortcuts like @+3d. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert dates quickly by typing @ (or a custom trigger) to summon a mini calendar; pick a date with mouse or keyboard or type relative shortcuts like +3d or -1w to insert the resolved date. Switch between multiple output formats from the popup and use the date picker in note titles; UI adapts to English and Chinese."
```
