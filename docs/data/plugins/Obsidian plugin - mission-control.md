# Mission Control

Replaces the new tab page with a search field and small dashboards for viewing tasks, projects and bookmarks, sourced from a single folder. Search integrates with Omnisearch. It builds on the Home Tab plugin by olrenso, which its author describes as deprecated.

    id:     "mission-control"
    name:   "Mission Control"
    author: "Andrewkfb"
