# Mobile Webviewer

Mobile Webviewer opens a mobile-first web viewer inside Obsidian in two modes: Browser View gives a browser pane with address and search, tabs, history, bookmarks, downloads and one-tap link capture, while Note Browser renders a Markdown note that embeds live web content. Reader-style web notes or doodles can be edited while a Chromium webview runs in the background and changes are saved automatically.
