# Citation Callouts

Formats quotes with citations from various sources into custom callouts. The source name is extracted automatically and a book icon is displayed as the callout title, and rich text such as bold, italic and links is preserved when clipboard content is pasted or the insert command is invoked.

```cue
plugin: {
    id:     "citation-callouts"
    name:   "Citation Callouts"
    author: "marvive"
    repo:   "marvive/Citation-Callouts"

    html_url:    "https://community.obsidian.md/plugins/citation-callouts"
    github_url:  "https://github.com/marvive/Citation-Callouts"
    description: "Elegantly formats quotes with citations from various sources into custom callouts."
    about:       "Format quotes with citations into styled callouts that automatically extract the source name and display a book icon as the title. Preserve rich text (bold, italic, links) when pasting clipboard content or invoking the command to insert citation callouts."
```
