# Tasks Datetime

Tasks Datetime extends task dates with time down to seconds, while keeping compact date-only displays when time support is disabled. A combined date and time picker and recurrence presets are provided, and importance and urgency are edited in a four-quadrant editor. Dashboards cover today, this week and this month, and the date and time values stay queryable.

```cue
plugin: {
    id:     "tasks-datetime"
    name:   "Tasks Datetime"
    author: "DXShelley"
    repo:   "dxshelley/obsidian-tasks-datetime"

    html_url:    "https://community.obsidian.md/plugins/tasks-datetime"
    github_url:  "https://github.com/dxshelley/obsidian-tasks-datetime"
    description: "Tasks with date and time support down to seconds. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add precise task timestamps down to seconds while keeping compact date-only displays when time support is disabled. Use a combined date/time picker, set recurrence presets, edit importance/urgency with a four-quadrant editor, and view dashboards for today, this week, and this month with queryable date/time values."
}
```
