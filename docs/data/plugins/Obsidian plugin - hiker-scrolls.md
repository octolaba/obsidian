# HikerScrolls

HikerScrolls builds scrollytelling journals from photos, notes and GPX tracks, synchronized with an animated topographic map that traces the route as the page is scrolled. Trips are pinned into a personal atlas and reached from a timeline, and multi-segment routes are drawn and animated in real time.
