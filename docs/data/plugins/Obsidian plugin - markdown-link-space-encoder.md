# Markdown Link Space Encoder

Markdown Link Space Encoder converts spaces in selected text into %20 so Markdown-style links resolve correctly. Link text is selected in Markdown view and the command replaces its spaces with the URL-encoded form.

```cue
plugin: {
    id:     "markdown-link-space-encoder"
    name:   "Markdown Link Space Encoder"
    author: "rkosova"
    repo:   "rkosova/obsidian-markdown-link-space-encoder"

    html_url:    "https://community.obsidian.md/plugins/markdown-link-space-encoder"
    github_url:  "https://github.com/rkosova/obsidian-markdown-link-space-encoder"
    description: "Automatically encode spaces to %20 in Markdown-style links."
    about:       "Encode spaces in selected text to %20 for Markdown-style links so file paths resolve correctly. Select link text in Markdown view and run the command to convert spaces into URL-encoded %20."
```
