# SpellFix

Suggestions from the native spellchecker are accepted with keyboard shortcuts rather than through the context menu. Suggestions are cycled, the original word is restored, and a suggestion is added to the ignore list; an optional autocorrect applies to the last word when space is pressed.

    id:     "spellfix"
    name:   "SpellFix"
    author: "yoav6"
    repo:   "yoav6/Obsidian-SpellFix"

    github_url:  "https://github.com/yoav6/Obsidian-SpellFix"
