# Portals

Pins any folder or tag as a customizable tab, a Portal into the selected folder trees, with icons, background colors, gradients, and free rearranging; tabs can be grouped into collapsible stacks. Six visual styles ship with the plugin along with icons from the Phosphor set bundled for offline use, plus multi-select, range-select, custom re-ordering, recursive tag trees, and tag grouping. A Side Portal pane adds context notes, trash, properties, recent files, bookmarks, journal, and hidden items. The recorded description presents this as help for single vaults holding several subjects, and states the plugin is fully offline and free.
