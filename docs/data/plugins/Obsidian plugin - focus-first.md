# Focus First

Sorts tasks into the Eisenhower matrix by urgency, taken from the due date, and importance, taken from the priority. It reads checkboxes in the Tasks format, pins top tasks marked with a focus tag and hides those marked with a hide tag, and dragging a task retags it. Tasks are filtered and grouped across folders and update live.

```cue
plugin: {
    id:     "focus-first"
    name:   "Focus First"
    author: "Christian Luger"
    repo:   "christian-luger-at/obsidian-focus-first"

    html_url:    "https://community.obsidian.md/plugins/focus-first"
    github_url:  "https://github.com/christian-luger-at/obsidian-focus-first"
    description: "Prioritize your tasks with the Eisenhower matrix. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sort your Obsidian tasks into the Eisenhower matrix by urgency (due date) and importance (priority) so the next right action is obvious. Read Tasks-format checkboxes, pin top tasks with #focus, hide with #hide, drag to retag, and filter/group tasks across folders with live updates."

    stats: {
        downloads:  278

}
```
