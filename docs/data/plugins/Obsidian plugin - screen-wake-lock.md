# Cook Mode

Cook Mode keeps the display awake while Obsidian is in the foreground, so that a device does not sleep while you cook from your notes or work through a long writing session. Activation can be always on, tied to editor focus or triggered by typing, and the wake lock state is shown in the status bar. It runs on desktop and mobile, with limited support on iOS.

plugin: {
    id:     "screen-wake-lock"
    name:   "Cook Mode"

    repo:   "blotspot/obsidian-wake-lock"
