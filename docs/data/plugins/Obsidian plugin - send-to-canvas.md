# Send to Canvas

Send to Canvas sends tasks, blocks and notes into Canvas files, as plain text, as block or note links, or as embeds. Block IDs, timestamps and node sizes can be customized, text can be appended to open tasks with formatting preserved, and the target canvas is tracked in the status bar.
