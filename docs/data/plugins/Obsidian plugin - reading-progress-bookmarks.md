# Reading Progress and Bookmarks

Remembers the reading position in Markdown notes and PDFs and keeps one bookmark per file, highlighting the bookmarked paragraph or PDF page. Progress and current position are shown in the status bar, and the most recent spot can be resumed. Restores are line-based so they survive small edits to the note, and automatic restoring stops as soon as scrolling begins.

```cue
plugin: {
    id:     "reading-progress-bookmarks"
    name:   "Reading Progress and Bookmarks"
    author: "Maxy Park"
    repo:   "ironunicorn66/reading-progress-bookmarks"

    html_url:    "https://community.obsidian.md/plugins/reading-progress-bookmarks"
    github_url:  "https://github.com/ironunicorn66/reading-progress-bookmarks"
    description: "Tracks reading progress and bookmarks for Markdown and PDF files. - This plugin has not been manually reviewed by Obsidian staff."

Display progress and position in the status bar, resume the most recent spot with line-based restores to survive small edits, and stop automatic restore as soon as you start scrolling."
