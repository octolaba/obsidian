# VK Inbox

VK Inbox imports VK community messages and voice notes into a chosen note, stamping each with a timestamp, skipping duplicates and working without an external server. Voice messages are downloaded as attachments, play inline, and can be transcribed locally with whisper.cpp on desktop. Updates run manually or automatically, and text and audio import also works on mobile.
