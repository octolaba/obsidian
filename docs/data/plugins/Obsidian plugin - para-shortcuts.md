# PARA Shortcuts

Creates a PARA folder structure in the vault and adds new entries from ready-made Markdown templates. Its commands move files to an archive, restore archived items, postpone entries into a postponed folder and reschedule them, creating and cleaning up folders automatically.

```cue
plugin: {
    id:     "para-shortcuts"
    name:   "PARA Shortcuts"
    author: "goatiful"
    repo:   "goatiful/para-shortcuts"

    html_url:    "https://community.obsidian.md/plugins/para-shortcuts"
    github_url:  "https://github.com/goatiful/para-shortcuts"
    description: "Useful commands to set up and manage your knowledge using the PARA method."
    about:       "Create a PARA folder structure in your vault and add new entries with ready-made Markdown templates. Move files to archive, restore archived items, postpone entries into a 'postponed' folder and reschedule them, with automatic folder creation and cleanup."

    stats: {
        downloads:  6854
        updated_at: 1708769963000
    }
}
```
