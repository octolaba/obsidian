# OK Standby Jukebox

OK Standby Jukebox imports music source URLs and assets from source_docs into structured song notes. It takes in links, audio, video and image files and ZIP exports, extracts the archives, moves media into a songs folder and groups common asset suffixes. Markdown song notes are then created or updated with the collected metadata.
