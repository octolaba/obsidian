# Math Chords

Math Chords inserts LaTeX math through a configurable leader key followed by short key sequences, so snippets are added without typing out the full LaTeX. A floating MathJax panel previews the math inline, and selections can be wrapped in display-math environments or in double-dollar delimiters. The keyboard shortcuts are customizable and the bindings persist.
