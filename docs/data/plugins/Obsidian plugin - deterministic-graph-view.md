# Deterministic Graph View

Draws the vault's link graph with a deterministic breadth-first layout that keeps node positions consistent between sessions. Clicking a node opens the note in a new tab, hovering highlights, the view refreshes when files or the excluded-files setting change, and node and edge colors are configurable. The author describes the plugin as being at an early stage and expects bugs.
