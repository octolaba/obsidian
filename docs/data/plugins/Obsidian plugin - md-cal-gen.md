# Markdown Calendar Generator

Markdown Calendar Generator inserts month or week calendars as Markdown tables into a note with a single command, and is described as intentionally simple. A quick-insert option covers the current date. The table output is customizable and the plugin works on both mobile and desktop.

```cue
plugin: {
    id:     "md-cal-gen"
    name:   "Markdown Calendar Generator"
    author: "zachatrocity"
    repo:   "zachatrocity/md-cal-gen"

    html_url:    "https://community.obsidian.md/plugins/md-cal-gen"
    github_url:  "https://github.com/zachatrocity/md-cal-gen"
    description: "An intentionally simple markdown table calendar generator"
    about:       "Generate markdown month or week table calendars and insert them into notes with a single command. Provide quick-insert for the current date, mobile/desktop compatibility, and clean, customizable table output for planning and tracking."

    stats: {
        downloads:  1083
        updated_at: 1752008923000
    }
}
```
