# Relative Dates

Converts date references in task lists into color-coded relative dates. The prefix and the colors are configurable, so overdue, today, tomorrow, this week, and future dates each get their own highlight.

```cue
plugin: {
    id:     "relative-dates"
    name:   "Relative Dates"
    author: "munckenh"
    repo:   "munckenh/obsidian-relative-dates"

    html_url:    "https://community.obsidian.md/plugins/relative-dates"
    github_url:  "https://github.com/munckenh/obsidian-relative-dates"
    description: "Relative, color-coded dates. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert date references in task lists into color-coded relative date elements. Customize the prefix and colors to highlight overdue, today, tomorrow, this week, and future dates."

    stats: {
        downloads:  246
        updated_at: 1778809055000
    }
}
```
