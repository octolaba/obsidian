# Cognitive Architect Sync

Cognitive Architect Sync imports architectures from Cognitive Architect, also known as IBM IT Architect Assistant, into the vault as Markdown notes with embedded images. Selected architectures or all artifacts can be imported, instances are preserved and the resulting notes are interlinked for local editing. Access to the models requires a Personal Token.
