# Windrose MapDesigner

Draws dungeon and world maps for tabletop role-playing games inside notes, on either a grid or a hex layout. Maps are painted with image tiles and carry objects, labels and fog of war, and sub-maps can be nested while everything stays linked to the notes. It is operated by touch on tablets or by keyboard and mouse on the desktop.
