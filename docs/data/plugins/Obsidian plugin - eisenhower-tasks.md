# Eisenhower Tasks

Organizes tasks in a colour-coded two-by-two Eisenhower matrix labelled by urgency and importance. Named sections group the tasks, cards are added and dragged across quadrants, and any quadrant expands to fullscreen. Completed items are archived to a dedicated Markdown archive file in the vault, with persistent storage.
