# Mindo

Mindo is a local-first AI companion that chats with the active note and searches the vault and the web. It creates and edits Markdown notes, runs local speech-to-text and text-to-speech voice workflows, accepts file attachments, and maintains a structured Mindo Wiki memory with source-backed references. An optional Rust sidecar is offered for faster search and RAG.
