# FLOWnote

Presents an AI note workspace whose dashboard home shows the day's note, focus, tasks, progress, recent activity, project tracking, knowledge metrics and an activity heatmap. Ideas are captured on desktop or mobile, spoken notes are cleaned up with AI, and text is sent into Obsidian through iOS Shortcuts. A built-in chat workspace and skill pack cover daily planning, note creation, capture processing, progress review and project management.
