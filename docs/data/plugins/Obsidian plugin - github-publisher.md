# GitHub Publisher

Publishes Markdown notes and their embedded images to a GitHub repository, with support for content collections. Wikilinks are converted to standard Markdown, images are uploaded to an assets folder, and posts are organized by pb-type or in a flat structure. Orphaned images are tracked and removed, and publishing is triggered by setting pb-publish to true.

```cue
plugin: {
    id:     "github-publisher"
    name:   "GitHub Publisher"
    author: "buckleyresearchltd"
    repo:   "buckleyresearchltd/ObsidianGithubPublisher"

    html_url:    "https://community.obsidian.md/plugins/github-publisher"
    github_url:  "https://github.com/buckleyresearchltd/ObsidianGithubPublisher"
    description: "Publish markdown notes and images to a GitHub repo. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Publish Markdown notes and embedded images from Obsidian to a GitHub repository with support for content collections. Convert Wikilinks to standard Markdown, upload images to an assets folder, organize posts by pb-type or flat structure, track and remove orphaned images, and trigger publishing with pb-publish: true."
```
