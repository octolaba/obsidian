# Vault SVN

Manages Subversion working copies inside the vault from Obsidian on desktop. Status can be refreshed and a change tree inspected showing added, modified, deleted, conflicted and untracked items; files and folders are staged or unstaged, commit summaries generated and staged changes committed. Conflicts are detected and can be marked resolved, and the recorded About states that the svn command-line tool is required.

    id:     "vault-svn"

Stage and unstage files or folders, generate commit summaries, commit staged changes, detect conflicts and mark them resolved (requires svn CLI)."
