# Traverse

A keyboard-driven file browser that previews files inline instead of opening extra tabs. Files and folders can be created, renamed, copied, moved and deleted from the view, with fuzzy filtering and search over items. Previews cover Markdown, media, PDFs and text, and a folder can be opened in the system file manager or a terminal.
