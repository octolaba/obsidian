# KiloCode

Turns the vault into persistent project memory for KiloCode, storing sessions, skills and notes as contextual memory in Markdown. It syncs bidirectionally with the KiloCode CLI so vault content is injected into conversations, and architecture decisions, coding standards and workflows are preserved.

```cue
plugin: {
    id:     "kilocode"
    name:   "KiloCode"
    author: "Henry Lan"
    repo:   "realhenrylan/obsidian-with-kilocode"

    html_url:    "https://community.obsidian.md/plugins/kilocode"
    github_url:  "https://github.com/realhenrylan/obsidian-with-kilocode"
    description: "Give KiloCode persistent project memory from your vault. Architecture decisions, skills, workflows, and sessions — all stored in markdown. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Turn your Obsidian vault into persistent memory for KiloCode, storing sessions, skills, and notes as contextual memory. Sync bidirectionally with the KiloCode CLI to inject vault content into conversations and preserve architecture decisions, coding standards, and workflows."

    stats: {
        downloads:  265
        updated_at: 1781277824000
    }
}
```
