# Timeline for Bases

Plots notes from frontmatter date properties along a horizontal, zoomable and pannable time axis, drawing single dates as dots and date ranges as bars. ISO dates, year-month, bare years and BC/AD forms are accepted, BC dates are rendered in the correct order, and items are colored and labeled by category with details on hover.

```cue
plugin: {
    id:     "timeline-bases"
    name:   "Timeline for Bases"
    author: "Harry Brown"
    repo:   "purplelawnchairs/Timeline-View"

    html_url:    "https://community.obsidian.md/plugins/timeline-bases"
    github_url:  "https://github.com/purplelawnchairs/Timeline-View"
    description: "Plots dated notes from a Base as dots and ranges along a zoomable, pannable time axis. - This plugin has not been manually reviewed by Obsidian staff."
```
