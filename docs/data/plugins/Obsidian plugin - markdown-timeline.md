# Markdown Timeline

Markdown Timeline converts Markdown notes into a timeline visualization, including BCE and CE dates expressed as negative years. Date formats are configurable and events can be ordered ascending or descending, searched and filtered. New events can be added directly from the timeline view.

```cue
plugin: {
    id:     "markdown-timeline"
    name:   "Markdown Timeline"
    author: "recklyss"
    repo:   "recklyss/markdown-timeline"

    html_url:    "https://community.obsidian.md/plugins/markdown-timeline"
    github_url:  "https://github.com/recklyss/markdown-timeline"
    description: "Convert markdown into timeline visualization"
    about:       "Create timelines from your Markdown notes, including BCE/CE dates using negative years. Customize date formats, choose ascending or descending order, search and filter events, and add new events directly from the timeline view."
```
