# Crisp Annotations

Builds hand-drawn inline annotations on top of Markdown highlights, adding directional arrows, colored connectors and handwritten-style labels. The note source stays plain and portable in edit mode, while reading mode renders the arrows, colors and fonts. A sidebar outline lists the annotations in a note, and summaries can be exported to the clipboard.
