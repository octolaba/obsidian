# Fight Note

Fight Note renders Tekken notation from fight code blocks into an easier-to-read visual format, and is partially useful for other fighting games such as Guilty Gear and Street Fighter. Full, short and loose syntax are parsed, and fields such as name, damage and hits are shown. Custom abbreviations, colors, icons and effects are applied to buttons and stances.
