# Redacted

Replaces selected text with block characters, using per-character, preserve-spaces or fixed-length styles. Any single character can be used in place of the presets, and line breaks are preserved across multi-line selections. It runs from the command palette, the context menu or the ribbon, and can be restricted to chosen folders.

```cue
plugin: {
    id:     "redacted"
    name:   "Redacted"
    author: "Julie Sandburg"
    repo:   "jsandburg/obsidian-redacted"

    html_url:    "https://community.obsidian.md/plugins/redacted"
    github_url:  "https://github.com/jsandburg/obsidian-redacted"
    description: "Permanently redact selected text using block characters or custom characters - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Redact selected text with block characters using per-character, preserve-spaces, or fixed-length styles. Choose preset or any single custom character and preserve line breaks for multi-line selections. Run from command palette, context menu, or ribbon and restrict to chosen folders."
```
