# Last Position

Last Position saves the scroll position of each Markdown document and restores it automatically when the file is reopened. The current position can be displayed in the status bar, and the save interval, retry attempts, data import and export, optional automatic cleanup and interface language are all configurable.

```cue
plugin: {
    id:     "last-position"
    name:   "Last Position"
    author: "saktawdi"
    repo:   "saktawdi/obsidian-last-position"

    html_url:    "https://community.obsidian.md/plugins/last-position"
    github_url:  "https://github.com/saktawdi/obsidian-last-position"
    description: "Automatically scroll to the last viewed position when opening the markdown document."
    about:       "Save and restore each note's scroll position automatically so reopening a file jumps back to where you left off. Display current position in the status bar and offer configurable save intervals, retry attempts, data import/export, optional automatic cleanup, and multilingual support."

    stats: {
        downloads:  1695

    }
}
```
