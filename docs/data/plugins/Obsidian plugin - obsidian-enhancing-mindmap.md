# Enhancing Mindmap

Builds interactive mind maps from Markdown, with links, inline styles, multiline text, inline code and KaTeX inside nodes. Nodes are edited inline, dragged to reorganize, undone and redone, zoomed and centered. The mindmap and markdown views are toggled and stay synchronized.
