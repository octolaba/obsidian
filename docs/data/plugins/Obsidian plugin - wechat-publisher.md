# WeChat Publisher

Renders a note's Markdown into HTML that a WeChat Official Account accepts, covering code highlighting, mathematics, Mermaid diagrams and tables, and uploading images automatically. The rendered result can be previewed, copied as HTML, or pushed to the Official Account as a draft in one step.
