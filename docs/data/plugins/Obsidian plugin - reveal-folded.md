# Reveal Folded

Reveal Folded reveals the current file in the file explorer while collapsing every other tree item. Auto-reveal can be enabled on desktop so the active file is refocused as the vault is navigated.

```cue
plugin: {
    id:     "reveal-folded"
    name:   "Reveal Folded"
    author: "d7sd6u"
    repo:   "d7sd6u/obsidian-reveal-folded"

    html_url:    "https://community.obsidian.md/plugins/reveal-folded"
    github_url:  "https://github.com/d7sd6u/obsidian-reveal-folded"
    description: "Reveal the current file in the file explorer while collapsing all other tree items."
    about:       "Reveal the current file in the file explorer while collapsing all other tree items. Enable auto-reveal on desktop to refocus the active file as you move around your vault."
```
