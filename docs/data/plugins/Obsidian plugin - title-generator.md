# Title Generator

Title Generator titles notes with OpenAI's GPT-3.5, deriving a descriptive title from each note's own content. It runs over a single note or several at once, sets the title on the note directly, and can be rerun to produce alternative variations.

```cue
plugin: {
    id:     "title-generator"
    name:   "Title Generator"
    author: "jaschaephraim"
    repo:   "jaschaephraim/obsidian-title-generator"

    html_url:    "https://community.obsidian.md/plugins/title-generator"
    github_url:  "https://github.com/jaschaephraim/obsidian-title-generator"
    description: "Quickly and easily title your notes using OpenAI's GPT-3.5."
    about:       "Generate descriptive titles for single or multiple notes using OpenAI's GPT-3.5, based on each note's content. Set titles directly on notes and rerun to produce alternative variations."

    stats: {
        downloads:  3993
        updated_at: 1697044224000
    }
}
```
