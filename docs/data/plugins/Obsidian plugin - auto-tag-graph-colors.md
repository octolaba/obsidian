# Auto Tag Graph Colors

Auto Tag Graph Colors assigns a stable, distinct color to every tag and updates the graph view in real time as tags change. Normal, Heat and Monochrome modes are offered alongside curated palettes, heat coloring works by connection count, and deterministic tag blending marks hubs and connections.
