# PDF Page Numbers

Adds page numbers to PDFs exported from Obsidian. Position, a preset or custom format, skipping the first page, font, color and margins are all configured from the export dialog.

```cue
plugin: {
    id:     "pdf-page-numbers"
    name:   "PDF Page Numbers"
    author: "dwbutler"
    repo:   "dwbutler/obsidian-pdf-page-numbers"

    html_url:    "https://community.obsidian.md/plugins/pdf-page-numbers"
    github_url:  "https://github.com/dwbutler/obsidian-pdf-page-numbers"
    description: "Adds page numbers to PDF exports (e.g. 'Page 1 of 5'). - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add configurable page numbers to PDFs exported from Obsidian. Choose position (top/bottom, left/center/right), pick a format or custom template, skip the first page, and set font, color, and margins from the export dialog."

    stats: {
        downloads:  363
        updated_at: 1773333694000
    }
}
```
