# Icons

Inserts icons into notes through an inline icon picker and renders them directly in Markdown. Icons are chosen from the Remix Icon and FontAwesome collections and displayed inline.

```cue
plugin: {
    id:     "obsidian-icons-plugin"
    name:   "Icons"
    author: "visini"
    repo:   "visini/obsidian-icons-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-icons-plugin"
    github_url:  "https://github.com/visini/obsidian-icons-plugin"
    description: "Add icons to your notes."
    about:       "Insert icons into notes using an inline icon picker and render them directly in Markdown. Pick from Remix Icon and Font Awesome collections and display chosen icons inline."

    stats: {
        downloads:  108514
        updated_at: 1613557429000
    }
}
```
