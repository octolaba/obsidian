# Notion Bases

Turns any folder into a database in the style of Notion, offering Table, Board, Gallery, List, Calendar, Timeline and Chart views built from plain Markdown and frontmatter. Data models can use eighteen column types, spreadsheet-style formulas, relations, rollups, subtasks and advanced filters, with charts drawn as SVG, and everything stays in local Markdown files.
