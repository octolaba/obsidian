# Remarkable Synchronizer

Connects to the reMarkable cloud or to a self-hosted rmfakecloud instance and lists, downloads, and syncs notebook pages as PNG or JPEG images. Stroke data in the version 6 .rm format is rendered, notebooks are browsed in a sidebar that preserves the folder hierarchy, and local .rmdoc files can be imported without any cloud connection.
