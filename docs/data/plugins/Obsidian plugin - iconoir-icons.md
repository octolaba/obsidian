# Iconoir Icons

Iconoir Icons renders customized Iconoir SVG icons inside notes from a concise inline syntax that sets the icon name, color, width, height and custom CSS. Icons are found through in-editor search suggestions.

```cue
plugin: {
    id:     "iconoir-icons"
    name:   "Iconoir Icons"
    author: "gapmiss"
    repo:   "gapmiss/iconoir-icons"

    html_url:    "https://community.obsidian.md/plugins/iconoir-icons"
    github_url:  "https://github.com/gapmiss/iconoir-icons"
    description: "Create and display customized SVG Iconoir icons."
    about:       "Insert and display Iconoir SVG icons with a concise inline syntax that sets name, color, width, height, and custom CSS. Search icons with in-editor suggestions and render customizable SVGs directly inside your notes."

    stats: {
        downloads:  5769
        updated_at: 1780254331000
    }
}
```
