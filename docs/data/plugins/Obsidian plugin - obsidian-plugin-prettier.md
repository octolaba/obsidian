# Prettier Format

This plugin formats notes with Prettier, applying opinionated and consistent Markdown and code styling. Whole files or only the selected text can be formatted, code blocks can be included, and formatting can run automatically on save.

```cue
plugin: {
    id:     "obsidian-plugin-prettier"
    name:   "Prettier Format"
    author: "hipstersmoothie"
    repo:   "hipstersmoothie/obsidian-plugin-prettier"

    html_url:    "https://community.obsidian.md/plugins/obsidian-plugin-prettier"
    github_url:  "https://github.com/hipstersmoothie/obsidian-plugin-prettier"
    description: "Opinionated formatting for your notes."
    about:       "Format notes and selections with Prettier to apply consistent Markdown and code styling. Format entire files or only selected text, include code blocks, or run automatically on save."
```
