# AI LLM

Runs local LLM models through Ollama against text selected in the editor. A running model is picked first, and the command palette sends the selection to it and replaces the selection with the model's output.

```cue
plugin: {
    id:     "ai_llm"
    name:   "AI LLM"
    author: "sparky4567"
    repo:   "sparky4567/obsidian_ai_plugin"

    html_url:    "https://community.obsidian.md/plugins/ai_llm"
    github_url:  "https://github.com/sparky4567/obsidian_ai_plugin"
    description: "Integrate local machine learning (OLLAMA) functionality into your notes, enhancing their capabilities."
    about:       "Use local LLM models via Ollama to process, rewrite, or augment selected text directly in the editor. Pick a running model and send selected text from the command palette to replace it with the model's output."
```
