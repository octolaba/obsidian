# Sheet Plus

Sheet Plus creates Excel-like spreadsheets in the vault and embeds them in Markdown notes. Cells can link to other files, hold images and be validated with checkboxes, dropdowns and dates, fonts and number formats are customizable, and charts are generated from sheet data. Further features cover REST API automation, XLSX import and export, embeddable chart links and Kanban views.
