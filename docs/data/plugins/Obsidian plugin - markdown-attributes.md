# Markdown Attributes

Markdown Attributes adds Pandoc-style attributes to elements in a note. Attributes are attached by placing a brace-delimited block after an element, and they apply to inline text such as italics, bold and highlights, as well as paragraphs, headers, tables and cells, wikilinks and Markdown links, lists and list items, code blocks, block quotes and callouts. Classes, IDs and key-value pairs can be set this way for styling or metadata.

```cue
plugin: {
    id:     "markdown-attributes"
    name:   "Markdown Attributes"
    author: "javalent"
    repo:   "javalent/markdown-attributes"

    html_url:    "https://community.obsidian.md/plugins/markdown-attributes"
    github_url:  "https://github.com/javalent/markdown-attributes"
    description: "Add Markdown attributes to elements."
    about:       "Add Pandoc-style Markdown attributes to inline text (italics, bold, highlights), paragraphs, headers, tables and cells, links (Wikilinks and Markdown links), lists and list items, code blocks, block quotes, and callouts. Attach classes, IDs, or key=value pairs by placing {...} after elements to apply styling or metadata."
```
