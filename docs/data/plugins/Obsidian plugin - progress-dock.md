# Progress Dock

Tracks numeric goals, deadlines, countdowns, and branching learning roadmaps in a dockable side panel. Progress is shown as bars, rings, or numbers, deadlines are calendar-backed with countdowns and notes, and roadmap branches can be sequential or parallel. The recorded description states that data is stored locally, with no network access and no changes to the Markdown notes.
