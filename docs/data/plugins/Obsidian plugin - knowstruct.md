# KnowStruct

Organizes knowledge into editable Markdown content cards and question-and-answer cards, maps them into native Canvas mind maps, and schedules spaced reviews. Images and PDFs can be converted into Markdown through an optional MinerU or local parser. The plugin states that notes and review data stay local by default.
