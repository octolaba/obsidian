# Dust Calendar

Displays a Chinese-style calendar in month or year view, showing Gregorian and lunar dates, weekdays, solar terms, holidays and adjusted workdays. Periodic notes - daily, weekly, monthly, quarterly and yearly - are created and opened from the calendar using templates. Note statistics such as word count and todo status are marked as coloured or hollow dots.
