# Vault Backup

Creates ZIP archives of the whole vault on demand or automatically at startup and shutdown, using atomic writes for backup integrity. Retention follows configurable policies, hidden dotfiles can be included, and file names use customizable date and time templates. The recorded About limits the plugin to desktop, on macOS, Windows and Linux.

```cue
plugin: {
    id:     "vault-backup"
    name:   "Vault Backup"
    author: "Masahiro Hiramori"
    repo:   "mshr-h/obsidian-vault-backup"

    html_url:    "https://community.obsidian.md/plugins/vault-backup"
    github_url:  "https://github.com/mshr-h/obsidian-vault-backup"
    description: "Create local ZIP backups of your vault with automatic retention management. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create ZIP archives of your entire vault on demand or automatically at startup/shutdown, using atomic writes to guarantee backup integrity. Manage retention with configurable policies, include hidden dotfiles, and name files with customizable date/time templates; desktop-only (macOS, Windows, Linux)."
```
