# Alipan Sync

Syncs notes bidirectionally with Alipan, the Alibaba Cloud Drive, over OAuth, using incremental transfers and a loose mode for large vaults. Remote files can be browsed, progress tracked and oversized files skipped. Conflicts merge automatically by character-level diff or by timestamp rules, and the run is logged in detail.
