# Image Darkmodifier

Image Darkmodifier applies visual filters to images referenced in Markdown, among them a darkmode shorthand that inverts the image, removes its background and boosts lightness. Filters are written in the image alias or alt text and chained from left to right, and local embeds, Markdown links and remote images are all supported.
