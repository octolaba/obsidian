# Butter Editor

Butter Editor adds a WYSIWYG editing mode that renders Obsidian Markdown — headings, lists, tables, code, math, footnotes, embeds, callouts, comments and wikilinks — while the files stay plain Markdown on disk. It runs on desktop and mobile with touch-optimized controls, block reordering and a customizable toolbar.
