# CleanView

Renders dashboards from cleanview code blocks, covering task lists, tables, key figures, countdowns and hand-drawn SVG charts. Refreshes read only the relevant files through Obsidian's metadataCache rather than scanning the whole vault. Everything runs locally, with no network access, no JavaScript evaluation and no external dependencies.
