# Vim IM Select

Vim IM Select switches the system input method as the editor moves between Vim modes, so a non-English input method does not break normal-mode commands. Platform-specific commands detect the current input method and switch it, keeping normal-mode keys predictable.

```cue
plugin: {
    id:     "vim-im-select"
    name:   "Vim IM Select"
    author: "alonelur"
    repo:   "alonelur/vim-im-select-obsidian"

    html_url:    "https://community.obsidian.md/plugins/vim-im-select"
    github_url:  "https://github.com/alonelur/vim-im-select-obsidian"
    description: "Support auto select the apposite input method in different vim mode."
    about:       "Switch the system input method automatically when using Vim keybindings in Obsidian to prevent non-English input methods from breaking normal-mode commands. Use platform-specific commands to detect and switch the current input method so Vim normal-mode keys behave reliably."
```
