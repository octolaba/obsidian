# Mantle Kanban

Provides a visual Kanban board in the vault where cards are dragged and dropped across customisable columns to update status. Cards render full Markdown preview content, links, images and frontmatter metadata, and sub-task checklists appear as progress bars. The board carries a responsive dot-pattern background that reacts to mouse movement, and the recorded text says it takes visual accents and glows from the Zenith theme.
