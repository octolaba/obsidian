# Multimuse Tracker

Tracks Discord roleplay threads and syncs scene state with the MultiMuse Discord bot. Selected text is sent as a muse to a thread, the Discord user ID is detected automatically, and scene files are created or imported with properties filled in. Frontmatter updates on its own while the plugin polls for replies.
