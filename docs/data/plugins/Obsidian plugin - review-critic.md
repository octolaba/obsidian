# Review Critic

Review Critic marks additions, deletions, replacements, highlights and inline comments in plain Markdown through quick commands, rendering them in both Reading View and Live Preview. A Track Changes toggle records edits, and unified Changes and Comments panes accept or reject changes and comments. Named color presets can be applied, and the recorded text says syntax-sensitive Markdown is protected so notes stay portable.
