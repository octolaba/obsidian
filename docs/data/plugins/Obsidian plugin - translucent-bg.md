# Translucent BG

Translucent BG applies the native Windows 11 background materials Mica, Acrylic and Tabbed to the Obsidian window on Windows 10 and 11. Theme compatibility is retained, and tinting is either managed by the plugin or left to the theme, which gives control over color and opacity across themes.

```cue
plugin: {
    id:     "translucent-bg"
    name:   "Translucent BG"
    author: "MellowMarsh"
    repo:   "mellowmarsh-git/Obsidian-Translucent-BG"

    html_url:    "https://community.obsidian.md/plugins/translucent-bg"
    github_url:  "https://github.com/mellowmarsh-git/Obsidian-Translucent-BG"
    description: "Translucent window backgrounds on Windows — acrylic blur, mica, and theme-aware tint overlays. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Apply native Windows 11 background materials (Mica, Acrylic, Tabbed) to the Obsidian window on Windows 10/11. Keep full theme compatibility and choose plugin-managed or theme-managed tinting for precise color and opacity control that adapts across themes."

    stats: {
        downloads:  891
        updated_at: 1780412791000
    }
}
```
