# Clear Unused Images

Scans the Markdown links of the vault and clears image files that are no longer referenced anywhere, to save space. Deletions can go to the Obsidian trash or the system trash or be permanent, and folders can be excluded from the scan to protect assets.

```cue
plugin: {
    id:     "oz-clear-unused-images"
    name:   "Clear Unused Images"
    author: "ozntel"
    repo:   "ozntel/oz-clear-unused-images-obsidian"

    html_url:    "https://community.obsidian.md/plugins/oz-clear-unused-images"
    github_url:  "https://github.com/ozntel/oz-clear-unused-images-obsidian"
    description: "Clear the images that you are not using anymore in your Markdown notes to save space."
    about:       "Clear unused image files by scanning all markdown links and removing image files not referenced anywhere in your vault. Move deletions to Obsidian trash, system trash, or delete permanently, and exclude folders from scans to protect assets."

    stats: {
        downloads:  150014
        updated_at: 1724187207000
    }
}
```
