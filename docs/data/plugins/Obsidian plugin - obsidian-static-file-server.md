# Static File Server

A vault subfolder is hosted as a local static file server on a chosen port, serving HTML, CSS, JavaScript and other files. Served pages can be displayed in iframes, which bypasses CORS for embedded sites, and vault files become reachable from other applications over HTTP.

    id:     "obsidian-static-file-server"
