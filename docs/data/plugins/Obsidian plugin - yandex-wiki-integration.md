# Yandex Wiki Integration

Connects the vault to a Yandex Wiki knowledge base, authenticating through the browser. The wiki tree is browsed from Obsidian, a working directory is set, and the repository is exported into the vault with a progress indicator.

```cue
plugin: {
    id:     "yandex-wiki-integration"
    name:   "Yandex Wiki Integration"
    author: "cubieprog"
    repo:   "cubieprog/Obsidian-Yandex-Wiki-Integration"

    html_url:    "https://community.obsidian.md/plugins/yandex-wiki-integration"
    github_url:  "https://github.com/cubieprog/Obsidian-Yandex-Wiki-Integration"
    description: "Integration with Yandex Wiki knowledge base"
    about:       "Integrate Obsidian with your Yandex Wiki knowledge base and authenticate via your browser. Browse the Wiki tree, set a working directory, and export the repository into your vault with an export progress indicator."

    stats: {
        downloads:  1197
        updated_at: 1754990523000
    }
}
```
