# SwiftGlossa

Highlights keywords in notes using regular expressions and custom CSS, then indexes every match into a highlight database, so clicking a keyword surfaces its occurrences across the vault. Each keyword can carry interlinear notes shown beside the text, occurrence counts, an info panel of AI-generated detail, and short remarks with backlinks. Floating notes stay visible either in the app or in a standalone window, and a draggable floating ball serves as a quick-action hub.
