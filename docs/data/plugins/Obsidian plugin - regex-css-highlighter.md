# SwiftGlossa

Highlights text matched by regular expressions with custom CSS and indexes the matches into a highlight database, so clicking a keyword surfaces every match across the vault. Interlinear notes attach small annotations to each keyword, counts track how often it is touched, info panels hold AI-generated factual detail, and remarks are quick notes carrying backlinks. Floating notes keep always-visible questions pinned in the app or in a standalone window, and a draggable floating ball serves as the quick-action hub.
