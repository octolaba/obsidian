# Code Block Fold

Folds a code block into a one-line preview with a single click, showing the language and the first line together with a copy button that takes the whole block without expanding it. The fold state is written inline in the file, so it travels with the note, and commands fold or unfold every block or toggle the one under the cursor.

```cue
plugin: {
    id:     "code-block-fold"
    name:   "Code Block Fold"
    author: "mkali"
    repo:   "mkali-personal/obsidian-code-block-fold"

    html_url:    "https://community.obsidian.md/plugins/code-block-fold"
    github_url:  "https://github.com/mkali-personal/obsidian-code-block-fold"
    description: "Fold and unfold code blocks in the editor with a single click. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Fold and unfold code blocks with a single click, collapsing them into a one-line preview that shows the language, first line, and a copy button to copy the block without expanding. Save fold state inline as {fold} so it syncs with your files, and run commands to fold/unfold all blocks or toggle the block under the cursor."
```
