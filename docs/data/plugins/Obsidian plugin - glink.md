# GLink

Opens Google Drive placeholder files such as .gdoc, .gsheet and .gslides in embedded Obsidian views on Windows. A local link registry maps vault-relative paths to Google URLs, filled automatically from Google Drive for desktop or by supplying a URL by hand, and it supports embeds and renames. An adjustable dark filter can be applied to the embedded view.

```cue
plugin: {
    id:     "glink"
    name:   "GLink"
    author: "Nathan Kelly"
    repo:   "nedkelly/obsidian-glink"

    html_url:    "https://community.obsidian.md/plugins/glink"
    github_url:  "https://github.com/nedkelly/obsidian-glink"

Maintain local mappings between vault-relative paths and Google URLs, auto-link from Google Drive for desktop on Windows or accept manual URLs, support embeds and renames, and offer an adjustable dark filter."
