# TinyChart

TinyChart generates simple ASCII charts in notes, with horizontal, vertical and line chart types. Fill and empty characters, optional prefixes and suffixes, chart length and value labels are configurable, and charts render inside code blocks or in paragraphs. Values can be taken from Dataview queries so that a chart updates live.
