# GoalToDo

Builds hierarchies of goals and tasks inside ordinary Markdown task lists, keeping the Markdown as the single source of truth. A parent task becomes a derived goal whose status and progress are calculated recursively from its children, and only leaf tasks can be completed directly. Inline properties such as @due(), @priority() and @assignee() are edited with suggestions and compact controls in Live Preview.
