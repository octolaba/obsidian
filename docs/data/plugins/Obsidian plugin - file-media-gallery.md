# File Media Gallery

File Media Gallery collects the media a note references and shows it as a gallery reached from the note's right-click menu, with tabs for Images, Video, Audio, PDF and other files. Thumbnails open in a fullscreen lightbox with sequential navigation, and external files open directly. The media is gathered both from vault attachments and from external URLs.

    id:     "file-media-gallery"
    name:   "File Media Gallery"
