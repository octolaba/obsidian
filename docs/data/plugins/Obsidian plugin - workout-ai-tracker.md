# Workout AI Tracker

Logs workouts from templates or quick entry, recording sets, weight, reps, RPE, heart rate, warmups, cooldowns and duration. Each session is written as a Markdown file with frontmatter into organized folders, so entries stay searchable in full text and versionable in Git. Progress analysis, program recommendations, and recovery and imbalance insights are produced through the Claude API.
