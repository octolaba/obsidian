# Custom list character

Chooses which character is used when a bullet list is created, among the hyphen, the asterisk and the plus. A hotkey inserts or reformats a list with the selected character, and the command can be added to the mobile toolbar.

```cue
plugin: {
    id:     "custom-list-character"
    name:   "Custom list character"
    author: "lilian-pouliquen"
    repo:   "lilian-pouliquen/obsidian-custom-list-character"

    html_url:    "https://community.obsidian.md/plugins/custom-list-character"
    github_url:  "https://github.com/lilian-pouliquen/obsidian-custom-list-character"
    description: "Choose the character to use when creating a bullet list between '-', '*' and '+'."
    about:       "Choose the bullet character (-, * or +) used when creating bullet lists in Obsidian. Bind a hotkey to insert or reformat lists with the selected character and add the command to the mobile toolbar for quick access."

    stats: {
        downloads:  5380
        updated_at: 1701465878000
    }
}
```
