# File Tree Alternative

File Tree Alternative replaces the file tree with separate panes for folders and files, or with an Evernote-style combined view. Note and file counts are shown, a folder can be focused into, and views expand, collapse or split horizontally or vertically. Paths are excluded, files from subfolders can be listed, and the folder state is remembered across sessions.
