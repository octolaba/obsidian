# Neighbouring Files

Adds commands to move to the next or previous file in the current directory, to move up or down folders, and to loop within a folder. Ordering is by name, creation date or modification date, and which file types take part in the navigation can be limited or widened.

```cue
plugin: {
    id:     "neighbouring-files"
    name:   "Neighbouring Files"
    author: "fabianuntermoser"
    repo:   "fabianuntermoser/obsidian-neighbouring-files-plugin"

    html_url:    "https://community.obsidian.md/plugins/neighbouring-files"
    github_url:  "https://github.com/fabianuntermoser/obsidian-neighbouring-files-plugin"
```
