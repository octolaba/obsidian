# Canvas Card Info

Canvas Card Info adds a Copy card info entry to the Canvas card context menu that places the selected card's details on the clipboard. The output can be readable text, raw JSON or both, capturing the id, type-specific fields for text, file, link and group cards, position, size and color. Several selected cards can be exported at once.
