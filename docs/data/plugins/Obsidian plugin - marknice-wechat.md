# MarkNice WeChat

MarkNice WeChat converts Obsidian notes into WeChat Official Account articles, with a real-time preview on the right and switchable mobile and desktop modes. Seventeen themes are available with adjustable font and spacing, HTML can be copied with inline styles for pasting in one step, or a draft can be published to WeChat with automatic image upload and frontmatter mapping. Obsidian embeds, links, highlights, callouts, tasks, tables and code blocks are preserved in the output, and the recorded description is bilingual Chinese and English.
