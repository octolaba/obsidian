# Extended Graph

Extended Graph builds on the core Graph view: nodes can carry images, take different shapes, and be pinned or focused to inspect relationships. Filtering works on tags and properties, links are removable by relationship type, saved states can be switched between, and the graph exports to SVG. Node and link sizes scale with statistical functions, search results and open tabs are reflected in the graph, and the active node's appearance is customizable.
