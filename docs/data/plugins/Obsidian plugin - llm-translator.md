# LLM Translator

Translates selected text in Obsidian's native PDF reader and in Markdown in real time, using local LLMs, cloud APIs, or Google and Bing. A sidebar accepts manual input and allows switching services or languages, copying or retrying a translation, and setting custom prompts. The recorded inputs state that offline models keep the data local.
