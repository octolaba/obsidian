# Daily Echoes

Resurfaces daily notes from previous years in a sidebar panel, covering this day, this week, this month, or a given day of the month across years. Dates are read from the core Daily Notes settings and only valid daily notes are listed, each labelled with how long ago it was written.

```cue
plugin: {
    id:     "daily-echoes"
    name:   "Daily Echoes"
    author: "Wojciech Polak"
    repo:   "wojciechpolak/obsidian-daily-echoes"

    html_url:    "https://community.obsidian.md/plugins/daily-echoes"
    github_url:  "https://github.com/wojciechpolak/obsidian-daily-echoes"
    description: "Revisit your daily notes from previous years: on this day, this week, this month, or this day of the month. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Resurface daily notes from previous years in a sidebar panel to revisit what you wrote on this day, this week, this month, or on a specific day-of-month across years. Read dates from your core Daily Notes settings and show only valid daily notes, labeling each entry with how long ago it was."

    stats: {
        downloads:  26
        updated_at: 1784748473000
    }
}
```
