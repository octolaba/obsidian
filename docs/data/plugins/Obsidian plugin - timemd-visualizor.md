# time.md

time.md navigates and visualizes data exported from the time.md screen-time analytics app inside Obsidian. Overview, Trends, Calendar, Details, Apps and Categories, Projects, Web History, Reports and Input Tracking views are recreated for in-place analysis. JSON, CSV, Markdown and Obsidian export formats are detected automatically, and the plugin renders cursor heatmaps, typing intensity, session tables, aggregated app and category statistics and exportable daily and weekly reports.
