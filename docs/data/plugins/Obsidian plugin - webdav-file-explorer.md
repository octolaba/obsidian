# Webdav File Explorer

Browses files held on WebDAV-compatible cloud or network storage through a collapsible file tree. A mirrored Markdown file tree can be created in the vault so remote files are documented, linked and easy to retrieve later.

```cue
plugin: {
    id:     "webdav-file-explorer"
    name:   "Webdav File Explorer"
    author: "red0orange"
    repo:   "red0orange/obsidian-webdav-file-explorer"

    html_url:    "https://community.obsidian.md/plugins/webdav-file-explorer"
    github_url:  "https://github.com/red0orange/obsidian-webdav-file-explorer"
    description: "Explore your webdav files."
    about:       "Browse and reference files on any WebDAV-compatible cloud or network storage using a collapsible file tree. Create mirrored Markdown file trees in your vault to document and link to remote files for easy retrieval."

    stats: {
        downloads:  5514
        updated_at: 1736616090000
    }
}
```
