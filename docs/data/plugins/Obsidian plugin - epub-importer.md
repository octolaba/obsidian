# Epub Importer

Converts an EPUB file into a folder of Markdown notes inside the vault and extracts its assets alongside them. The imported book can then be read, annotated and highlighted, and linked to other notes like any other Markdown content.

```cue
plugin: {
    id:     "epub-importer"
    name:   "Epub Importer"
    author: "aoout"
    repo:   "aoout/obsidian-epub-importer"

    html_url:    "https://community.obsidian.md/plugins/epub-importer"
    github_url:  "https://github.com/aoout/obsidian-epub-importer"
    description: "Import EPUB files as Markdown."
    about:       "Convert EPUB files into a folder of Markdown notes with extracted assets inside your vault. Read and annotate books, highlight passages, and create links between notes to organize and reference your ebooks directly in Obsidian."
```
