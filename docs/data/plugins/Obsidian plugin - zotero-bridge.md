# Zotero Bridge

Zotero Bridge exposes a standard API that other Obsidian plugins use to connect to Zotero, supporting the Zotero 7 local API and older Zotero through ZotServer. Plugins and user scripts can then search, fetch and read Zotero item data directly inside Obsidian.
