# Transcript Refine

Transcript Refine sends speech-to-text transcripts to an AI model to fix errors, improve their structure and turn spoken language into clear, readable text. Four presets, namely General, Meeting Minutes, Interview and Polish, are provided and further templates can be created. A selection or a whole file can be refined, several APIs are supported, and keys are stored securely.
