# Modal forms

Modal forms defines forms as JSON and opens them in modal dialogs from templates, QuickAdd, DataviewJS or any other JavaScript context. Named forms are managed centrally, note templates built from them, and command-palette triggers registered. Inputs include autocompleted note fields, lists, dates, toggles and multi-choice selections.
