# ObDrawIO

Edits and manages draw.io diagrams in .drawio and .dio files directly inside Obsidian, embedding the draw.io editor for flowcharts, UML, wireframes, entity-relationship diagrams and more. Changes are saved to the vault automatically, the editor follows Obsidian's light and dark theme, and a searchable picker inserts diagram links into notes.
