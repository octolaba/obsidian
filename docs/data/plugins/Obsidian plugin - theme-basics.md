# Theme Basics

Theme Basics changes Obsidian's appearance without writing CSS, covering backgrounds, typography, spacing, headers from H1 to H6, lists, dividers, blockquotes, code blocks and tag styles. Separate light and dark profiles are kept, and link and emphasis colors, per-heading size and weight, and list indents are set from its settings.

```cue
plugin: {
    id:     "theme-basics"
    name:   "Theme Basics"
    author: "Roman Soriano"
    repo:   "narwhai/theme-basics"

    html_url:    "https://community.obsidian.md/plugins/theme-basics"
    github_url:  "https://github.com/narwhai/theme-basics"
    description: "Customize the appearance of Obsidian without plugins. Modify colors, text sizing/spacing, and more - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Customize backgrounds, typography, spacing, headers (H1–H6), lists, dividers, blockquotes, code blocks, and tag styles without writing CSS. Set separate light/dark profiles and control link and emphasis colors, per-heading size/weight, and list indents for consistent visuals."
```
