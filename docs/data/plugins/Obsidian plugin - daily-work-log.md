# Daily Work Log

Reads time tracking and to-do information out of YYYY-MM-DD Markdown notes and shows it in a right-sidebar monthly calendar, an event timeline and a to-do list, without requiring YAML frontmatter. Events and to-dos are edited inline, English and Korean headings are recognized, and the sidebar carries its own light or dark theme. A dashboard reports streaks, totals and thirty-day to-do completion and event time.

```cue
plugin: {
    id:     "daily-work-log"
    name:   "Daily Work Log"
    author: "Hong SeongChan"
    repo:   "seongchan/DailyWorkLog"

    html_url:    "https://community.obsidian.md/plugins/daily-work-log"
    github_url:  "https://github.com/seongchan/DailyWorkLog"
    description: "Visualize daily time tracking and To-Do lists directly from daily notes with minimal metadata. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Visualize daily time tracking and To-Dos from your YYYY-MM-DD markdown notes in a right‑sidebar monthly calendar, event timeline, and To-Do list — no YAML frontmatter needed. Edit Events and To-Dos inline, recognize English and Korean headings, toggle a separate sidebar Light/Dark theme, and view a dashboard with streaks, totals, and 30‑day To-Do completion and Event time."
```
