# Style Controller

Reusable style profiles, path-specific overrides and visual settings are managed from a native settings interface. Runtime CSS is generated and scoped to the open note rather than editing a theme or a snippet, covering typography, headings, links, tables, code, callouts, images and explorer styling. Profiles are imported and exported.
