# Page Properties

Styles Dataview full-line inline fields with tag-like visuals and turns field names into inner links, giving page properties similar to Logseq. Configurable patterns convert specified field values into links, and selected fields can be hidden from reader view.

```cue
plugin: {
    id:     "page-properties"
    name:   "Page Properties"
    author: "necauqua"
    repo:   "necauqua/obsidian-page-properties"

    html_url:    "https://community.obsidian.md/plugins/page-properties"
    github_url:  "https://github.com/necauqua/obsidian-page-properties"
    description: "Add page properties similar to Logseq."
    about:       "Style Dataview full-line inline fields with tag-like visuals and turn field names into inner links for Logseq-style page properties. Convert specified field values into links via configurable patterns and hide selected fields from reader view."
```
