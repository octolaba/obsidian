# BackDrop

Syncs BackDrop wiki and timeline articles with the vault, uploads vault files as BackDrop assets, and caches world metadata such as categories and pins. Notes marked as BackDrop content gain header tools for inserting images and audio, adding spoilers and wikilinks, managing properties and viewing sync state. Conflicts are resolved by keeping the local copy, taking the remote one, or force-publishing.
