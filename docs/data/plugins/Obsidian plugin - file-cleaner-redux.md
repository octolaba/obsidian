# File Cleaner Redux

File Cleaner Redux removes empty files, unused attachments and empty folders according to configurable rules, including files that contain nothing but specific frontmatter. Found items are previewed first and can then be deleted, moved to the system or Obsidian trash, or removed permanently. Folders are included or excluded, and Admonition and Excalidraw files are handled.

```cue
plugin: {
    id:     "file-cleaner-redux"
    name:   "File Cleaner Redux"
    author: "husjon"
    repo:   "husjon/obsidian-file-cleaner-redux"

    html_url:    "https://community.obsidian.md/plugins/file-cleaner-redux"
    github_url:  "https://github.com/husjon/obsidian-file-cleaner-redux"
    description: "Help you to clean empty files and unused attachments in the vault."
    about:       "Remove unused or empty Markdown files, attachments, and empty folders based on configurable rules, including files that only contain specific frontmatter. Preview found items and choose to delete, move to system or Obsidian trash, or permanently remove. Include or exclude folders and handle Admonition and Excalidraw files."

    stats: {
        downloads:  72564
        updated_at: 1785958931000
    }
}
```
