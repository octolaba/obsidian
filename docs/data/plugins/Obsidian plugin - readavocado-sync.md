# Readavocado Sync

Syncs Readavocado highlights into the vault using a Readavocado token, importing new highlights as notes each time Obsidian opens. A manual sync can also be triggered from the plugin settings to pull updates on demand.

```cue
plugin: {
    id:     "readavocado-sync"
    name:   "Readavocado Sync"
    author: "innneang"
    repo:   "innneang/obsidian-readavocado-sync"

    html_url:    "https://community.obsidian.md/plugins/readavocado-sync"
    github_url:  "https://github.com/innneang/obsidian-readavocado-sync"
    description: "Sync your Readavocado highlights."
    about:       "Sync Readavocado highlights into your Obsidian vault automatically using your Readavocado token, importing new highlights as notes whenever Obsidian opens. Trigger a manual sync in the plugin settings to pull updates on demand."

    stats: {
        downloads:  3457

}
```
