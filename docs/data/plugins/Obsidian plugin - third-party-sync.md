# Third-party Sync

Third-party Sync is an unofficial fork of the remotely-save plugin that synchronizes a vault with S3, WebDAV or OneDrive under end-to-end AES-256-GCM encryption with per-file random IVs and integrity checks. Bidirectional and incremental sync, auto-sync, conflict handling and modification-ratio protection are provided. The recorded inputs state that it is not backwards compatible and advise backing up the vault before switching to it.
