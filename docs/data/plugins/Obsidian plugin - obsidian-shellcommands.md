# Shell commands

Shell commands are defined in settings and executed from the command palette, hotkeys, URI links or automated events. A command can carry note-related variables such as the current file name and path, the parent folder and custom timestamps, and its output can be inserted into the note. Opening external applications and performing automated file modifications are the recorded uses.
