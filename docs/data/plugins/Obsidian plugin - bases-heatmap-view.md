# Bases heatmap view

Bases heatmap view renders a GitHub-contributions-style heatmap for any date-based property in a Bases table. Activity, habits, progress and other numeric or date-related values appear as color-coded squares, with filters to narrow the records that are counted.

```cue
plugin: {
    id:     "bases-heatmap-view"
    name:   "Bases heatmap view"
    author: "serafinovsky"
    repo:   "serafinovsky/bases-heatmap-view"

    html_url:    "https://community.obsidian.md/plugins/bases-heatmap-view"
    github_url:  "https://github.com/serafinovsky/bases-heatmap-view"
    description: "Github-style heatmap visualization for any date-based property in your Bases tables. Track activity, habits, progress, or any numeric/date-related data with color-coded squares. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display GitHub-contributions-style heatmaps for any date-based property in Bases tables. Track activity, habits, and progress with color-coded squares and filters to focus on the records that matter."

    stats: {

}
```
