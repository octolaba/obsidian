# SVG Viewer

Renders inline SVG code fences as live graphics in Reading View and Live Preview. Before rendering, the recorded inputs state that the SVG is sanitized to remove scripts, event handlers and dangerous URIs, with external resources optionally blocked. Clicking a graphic shows or copies its raw SVG source, and an optional SVG badge can be displayed.
