# Auto Reading Mode

Auto Reading Mode switches Markdown files from Live Preview or Source into Reading view after a configurable idle timeout. The timer keeps running while Obsidian is active or minimized, and previously opened documents can start in Reading view at launch.

```cue
plugin: {
    id:     "auto-reading-mode"
    name:   "Auto Reading Mode"
    author: "kelvinc6"
    repo:   "kelvinc6/auto-reading-mode"

    html_url:    "https://community.obsidian.md/plugins/auto-reading-mode"
    github_url:  "https://github.com/kelvinc6/auto-reading-mode"
    description: "Automatically switches previously opened Markdown pages into reading mode."
    about:       "Switch Markdown files in Live Preview or Source into Reading view after a configurable idle timeout. Keep the timer running while Obsidian is active or minimized and start previously opened documents in Reading view on launch."
```
