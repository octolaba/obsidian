# MyLoc

Inserts the current location into a note as GPS coordinates, a reverse-geocoded address and timezone information. Named places are saved and matched by radius, and location notes or frontmatter are produced for map plotting, in several output formats or a custom template. On mobile it uses GPS and on desktop IP-based geolocation, and check-in and check-out entries track time.
