# Csv to table

Converts a selection of CSV-like text into a Markdown table. Comma-separated lines become a pipe-formatted table that replaces the original selection.

```cue
plugin: {
    id:     "csv-to-table"
    name:   "Csv to table"
    author: "Giacomo D’angelo"
    repo:   "jackydangelo/obsidian-csv-to-table"

    html_url:    "https://community.obsidian.md/plugins/csv-to-table"
    github_url:  "https://github.com/jackydangelo/obsidian-csv-to-table"
    description: "Convert selected CSV text into a Markdown table. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert selected CSV-like text into a Markdown table. Turn comma-separated lines into a pipe-formatted table that replaces your selection for quick table creation."
```
