# Gradient Text

Applies gradient colours to headings, bold and italic text, wikilinks, external links and regular text, from five curated palettes or a custom colour picker with two or three stops. Gradients are configured per element with live previews and can be toggled globally or individually, falling back to theme colours when disabled. It works in Reading view and Live Preview.
