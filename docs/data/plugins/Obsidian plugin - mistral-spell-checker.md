# Mistal Spell Checker

Mistal Spell Checker checks and corrects spelling and grammar in selected text using Mistral AI, invoked from the editor context menu or the command palette. The Mistral model and a custom system prompt are configurable, the interface can be switched between Russian and English, and the API key can be verified from the settings.
