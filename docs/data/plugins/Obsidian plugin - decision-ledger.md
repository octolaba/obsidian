# Decision Ledger

Renders the live code that a decision note governs inside the note itself, with a status badge marking it as tracked, drifted with a percentage, or gone. A sidebar lists every decision sorted by worst rot first, so the most stale notes surface at the top. A separate ledger CLI and desktop Obsidian are required.

```cue

    id:     "decision-ledger"
    name:   "Decision Ledger"
    author: "Dinesh S"
```
