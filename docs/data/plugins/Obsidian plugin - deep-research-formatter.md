# Deep Research Formatter

Cleans Markdown exported from ChatGPT Deep Research by removing inline cite markers and rewriting entity and URL annotations into readable labels. YAML frontmatter, fenced code blocks and inline code are preserved, unknown marker types fall back safely, and whitespace cleanup is kept minimal.
