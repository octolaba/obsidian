# Simply Scroll

Simply Scroll records only the scroll position of files, not the cursor position, and restores reading and editing positions when switching between Markdown files. To prevent flickering and layout shifts it cloaks and smooths editor opacity during load and blurs aggressive focus. Saved scroll states are updated and cleaned when a file is renamed or deleted.
