# SuperAdd

A single natural-language line is parsed into a structured task file, taking title, tags, estimates, due and scheduled dates and recurrence into clean frontmatter. Custom properties are recognized across string, number, boolean, array, date and datetime types, templates are merged while key order is kept, and parsed fields are previewed as pills. A file picker inserts links quickly.
