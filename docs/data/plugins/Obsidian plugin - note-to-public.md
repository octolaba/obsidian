# Note to Public

Publishes notes to WeChat Official Accounts through the official API, generating WeChat-compatible HTML. Obsidian syntax such as wikilinks, highlights, strikethrough and callouts is rendered, Mermaid diagrams are converted to images, and local images are uploaded to WeChat media automatically. A right sidebar previews the article and updates when the active file changes.
