# Merefolk

Renders mermaid erDiagram blocks as editable Excalidraw diagrams with crow's-foot cardinality, orthogonal routing, uncluttered labels and table-style entities. A diagram can be opened in Excalidraw and saved to a companion scene file; the Mermaid block stays the source until that first edit. Malformed lines are flagged with warnings, and a resync regenerates the drawing from the Mermaid source.
