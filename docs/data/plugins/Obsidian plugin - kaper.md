# Kaper

Renders Kaper code blocks as structured, editable recipes in Live Preview while the surrounding Markdown stays an ordinary note. Title, servings, tags, ingredient groups and steps are edited in an auto-saving form. A single click jumps to Cook Mode on kaper.me, and new recipes can be created from the ribbon.
