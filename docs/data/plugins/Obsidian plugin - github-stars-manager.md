# GitHub Stars Manager

Manages starred GitHub repositories inside Obsidian, with several accounts, custom tags, local notes and manual or automatic syncing. Starred repositories can be searched and filtered by name, description, language or tag using fuzzy and regular-expression matching, sorted by several fields, and shown in card or liquid-glass themes with a responsive waterfall layout.
