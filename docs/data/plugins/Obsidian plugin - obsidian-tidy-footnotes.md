# Tidy Footnotes

Footnote definitions scattered through a note are consolidated into a single block sorted by appearance. Numbered footnotes are then re-indexed so that their inline order becomes sequential.

```cue
plugin: {
    id:     "obsidian-tidy-footnotes"
    name:   "Tidy Footnotes"
    author: "charliecm"
    repo:   "charliecm/obsidian-tidy-footnotes"

    html_url:    "https://community.obsidian.md/plugins/obsidian-tidy-footnotes"
    github_url:  "https://github.com/charliecm/obsidian-tidy-footnotes"
    description: "Tidy your footnotes seamlessly."
    about:       "Tidy footnotes by consolidating all definitions into a single block sorted by appearance. Re-index numbered footnotes so inline order becomes sequential (e.g., [^1][^4][^2] → [^1][^2][^3])."

    stats: {
        downloads:  23412
        updated_at: 1728974868000
    }
}
```
