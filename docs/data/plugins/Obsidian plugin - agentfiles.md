# Agentfiles

Agentfiles discovers, organizes and edits AI agent skills, commands and agents across Claude Code, Cursor, Codex, Windsurf and other tools. Skills and their file contents are browsed and deep-searched, new skills created through a stepped wizard, and existing ones edited inline with Markdown preview. Marketplace skills can be installed, and conversations and analytics exported.
