# Easy Links

Displays only the file name of un-aliased internal links, in reading view and live preview, while the link target stays intact so clicks navigate unchanged. Heading references, block references, aliases and the full paths of embeds are preserved, and full paths can optionally be revealed while editing. An optional link suggester floats notes from your most-used or top-level folders to the top.
