# CodeBlock CRBasic

CodeBlock CRBasic adds syntax highlighting to Markdown code blocks written in CRBasic. CRBasic is the Campbell Scientific language, and the recorded inputs name no other language and no further behaviour.

```cue
plugin: {
    id:     "codeblock-crbasic"
    name:   "CodeBlock CRBasic"
    author: "samutley"
    repo:   "utleysam/codeblock-crbasic"

    html_url:    "https://community.obsidian.md/plugins/codeblock-crbasic"
    github_url:  "https://github.com/utleysam/codeblock-crbasic"
    description: "Syntax highlighting for CRBasic (Campbell Scientific) markdown code blocks. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add CRBasic syntax highlighting to markdown code blocks."

    stats: {
        downloads:  76
        updated_at: 1780635598000
    }
}
```
