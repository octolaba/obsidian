# Structure Commander

Headings are treated as a tree for working with long notes and documentation: branches are moved, depth is changed across headings, lists and text, sections fold and unfold, outlines are renumbered, and a branch is exported to its own Markdown file. A side panel and a compact toolbar track the structure of the document. The About text recorded for this entry is written in Russian.
