# SonicNote Sync

Recordings from SonicNote are synced into Obsidian as individual Markdown files, along with verbatim transcripts carrying speaker identifiers and timestamps, AI summaries, study reports and handwritten notes. Each note is self-contained, its frontmatter metadata is configurable, and optional auto-sync keeps the set current.

```cue
plugin: {
    id:     "sonicnote-sync"
    name:   "SonicNote Sync"
    author: "EasyLinkIn"
    repo:   "long2icc/sonicnote-sync"

    html_url:    "https://community.obsidian.md/plugins/sonicnote-sync"
    github_url:  "https://github.com/long2icc/sonicnote-sync"
    description: "Sync recordings from SonicNote to Obsidian as Markdown files - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync recordings, verbatim transcripts with speaker IDs and timestamps, AI-generated summaries, study reports, and handwritten notes from SonicNote into Obsidian as individual Markdown files. Create self-contained notes with configurable frontmatter metadata and optional auto-sync to keep recordings up to date."
```
