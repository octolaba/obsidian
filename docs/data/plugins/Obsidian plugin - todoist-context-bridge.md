# Todoist Context Bridge

Todoist Context Bridge links note-taking and Todoist task management, syncing in both directions while preserving the full context and temporal metadata. It integrates with the Dataview and Tasks plugins, lets important tasks be highlighted selectively, and handles lists, tasks, callouts, quotes and other content formats.
