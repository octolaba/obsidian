# ObShare

Uploads notes to Feishu Cloud Docs in one click, converting Markdown, Mermaid diagrams, YAML and images into formats Feishu accepts. Credentials are encrypted locally with AES-GCM 256, upload history and progress are tracked, and document permissions can be set from within Obsidian.
