# Rin Image Toolbar

Shows a floating toolbar when an image is hovered in Live Preview, offering copy, crop and fullscreen actions, while Reading view offers only copy and fullscreen. Cropping opens an interactive dialog with drag handles and pixel input, saves the result under a name ending in _crop and updates the note's image reference automatically.
