# Typster

Compiles Typst files and generates a live PDF preview of a chosen entry file, set as a vault-relative path or picked from the .typ and .typ.md files in the vault. Export to PDF is provided, together with source-mode Typst formatting and template tools. The preview is opened from the command palette or a ribbon icon and refreshed with a compile command.
