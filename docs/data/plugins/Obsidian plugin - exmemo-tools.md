# ExMemo Tools

Applies large language models to document management: archiving files, generating metadata, building directory indexes and assisting edits. Tags, titles and descriptions are generated, a suitable folder is recommended for a file, text is inserted or continued in context, and Luhmann cards or directory indexes are created from files or selections.
