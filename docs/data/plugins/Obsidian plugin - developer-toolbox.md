# Developer Toolbox

Captures annotated screenshots and turns them into paste-ready Markdown issue payloads carrying structured context, with path redaction for privacy. Plugins are reloaded live during development, either on command or automatically when a watched build changes. Icon ids, CSS variables and registered commands can be inspected from the same toolbox.

```cue
plugin: {
    id:     "developer-toolbox"
    name:   "Developer Toolbox"
    author: "Charles Kelsoe"
    repo:   "ckelsoe/obsidian-developer-toolbox"

    html_url:    "https://community.obsidian.md/plugins/developer-toolbox"
    github_url:  "https://github.com/ckelsoe/obsidian-developer-toolbox"
    description: "Developer tools to capture annotated screenshots with structured context, reload plugins live, and inspect icons, CSS variables, and commands. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Capture annotated screenshots and generate paste-ready Markdown issue payloads with structured context and privacy-minded path redaction. Reload plugins instantly during development and auto-reload watched builds. Browse icon IDs and inspect CSS variables and registered commands."

    stats: {
        downloads:  454
        updated_at: 1786459675000
    }
}
```
