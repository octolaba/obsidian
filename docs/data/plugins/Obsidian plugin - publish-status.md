# Publish Status

Shows Obsidian Publish sync status beside filenames in the file explorer, using VSCode Git-style one-letter colored badges: A in green for Added, M in yellow for Modified, D in red for Deleted. Statuses update automatically on startup and when files are switched or edited, and a command refreshes them by hand.

```cue
plugin: {
    id:     "publish-status"
    name:   "Publish Status"
    author: "ときくん"
    repo:   "toki1703/publish-status"

    html_url:    "https://community.obsidian.md/plugins/publish-status"
    github_url:  "https://github.com/toki1703/publish-status"
    description: "Show Publish Status in File Explorer - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display Obsidian Publish sync status next to filenames in the file explorer with VSCode Git-style one-letter colored badges: A (green) Added, M (yellow) Modified, D (red) Deleted. Update statuses automatically on startup, when switching or editing files, and refresh manually via command."

    stats: {
        downloads:  77
        updated_at: 1781735345000
    }
}
```
