# Code Style Keys

Code Style Keys wraps a selection in backticks from a single keystroke: a single-line selection becomes inline code and a multi-line selection becomes a fenced code block. Accidental duplicate trailing backticks are removed so the code formatting stays clean.

```cue
plugin: {
    id:     "code-style-keys"
    name:   "Code Style Keys"
    author: "Aiday Marlen Kyzy"
    repo:   "aiday-mar/code-style-keys"

    html_url:    "https://community.obsidian.md/plugins/code-style-keys"
    github_url:  "https://github.com/aiday-mar/code-style-keys"
```
