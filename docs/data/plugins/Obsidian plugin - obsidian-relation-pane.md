# Relation Pane

This plugin displays a right-sidebar pane that summarizes the relations between notes. It lists outgoing links, incoming links, and links pointing at notes that have not been created, so connections and missing targets are visible at a glance.

```cue
plugin: {
    id:     "obsidian-relation-pane"
    name:   "Relation Pane"
    author: "mottox2"
    repo:   "mottox2/obsidian-relation-pane"

    html_url:    "https://community.obsidian.md/plugins/obsidian-relation-pane"
    github_url:  "https://github.com/mottox2/obsidian-relation-pane"
    description: "Display a panel that summarize relations between notes."
    about:       "Display linked and referring notes in a right‑sidebar pane to summarize relationships between notes. List outgoing links, incoming links, and links that point to uncreated notes so you can spot connections and missing targets at a glance."

    stats: {
        downloads:  6589
        updated_at: 1707719507000
    }
}
```
