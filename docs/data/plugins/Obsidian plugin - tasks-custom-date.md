# Tasks custom date

Records timestamps when a task changes state and writes them into configurable fields using format templates with a {{time}} placeholder. Custom intermediate states and click-to-cycle flows can be defined globally or per tag. One unified time format applies throughout, creation-time suggestions are offered, and several languages are supported.
