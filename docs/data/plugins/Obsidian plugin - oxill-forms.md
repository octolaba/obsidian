# Oxill Forms

Defines reusable forms with custom fields, headings and metadata, which are then filled in a modal to produce consistent notes. Submitting a form can create a new note, insert text at the cursor, or update the current note's properties, with headings placed and the cursor left ready for continued writing. The interface speaks six languages.
