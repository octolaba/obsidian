# Neat File Tree

Pins folder headers to the top of the file explorer while it scrolls, stacked by folder depth so the current position in a deep vault stays visible. Folder names, bars and indentation guides are coloured by depth from six schemes, Aurora, Rainbow, Ocean, Sunset, Forest and Mono, and top-level folders stay bold. The recorded text states that it is pure CSS with no DOM changes, which it gives as the reason performance impact is minimized.
