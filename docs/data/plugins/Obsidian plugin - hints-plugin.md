# Hints Flow

Hints Flow captures messages and content from Telegram, WhatsApp, Slack, email, SMS, Raycast and other sources into Obsidian through the Hints AI Assistant, using customizable templates. Flows route captures from connected applications such as Notion, ClickUp, Trello, HubSpot, Pipedrive, Jira and Calendar into organized notes for review.
