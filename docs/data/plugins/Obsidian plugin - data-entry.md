# Data Entry

Renders frontmatter metadata as an interactive form built from JSON Schema and JSON Forms. A data-entry codeblock names the datasource and the schema; opening the note in read mode shows the form, and edits are persisted back to the file's frontmatter.

```cue
plugin: {
    id:     "data-entry"
    name:   "Data Entry"
    author: "waynevanson"
    repo:   "waynevanson/data-entry-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/data-entry"
    github_url:  "https://github.com/waynevanson/data-entry-obsidian-plugin"
    description: "Create forms that save data simply; the data view of data entry."
    about:       "Turn frontmatter metadata into interactive forms and edit note data using JSON Schema and JSON Forms. Define a datasource and schema, add a data-entry codeblock, then open the note in read mode to view and edit metadata with a form that persists to the file's frontmatter."

    stats: {

    }
}
```
