# Expiration-Date-Tracker

Tracks expiration dates for items listed in a Markdown table, groceries for example, and shows them in a dedicated view grouped by category with the number of days left. Expired items raise a notice, items and categories can be searched, and the source file, the date format and the thresholds of each category are configurable.
