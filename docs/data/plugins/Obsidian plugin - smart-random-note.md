# Smart Random Note

Smart Random Note opens a random note drawn from the whole vault, from the current search results or from a selected tag. It can also insert a link at the cursor to a random note from the search results, and offers a command mirroring the core Obsidian random-note behavior.

```cue
plugin: {
    id:     "smart-random-note"
    name:   "Smart Random Note"
    author: "erichalldev"
    repo:   "erichalldev/obsidian-smart-random-note"

    html_url:    "https://community.obsidian.md/plugins/smart-random-note"
    github_url:  "https://github.com/erichalldev/obsidian-smart-random-note"
    description: "Open random notes with greater control."
    about:       "Open random notes from your vault, current search results, or a selected tag to jump to unexpected content. Insert a link at the cursor to a random note from search results or run a command that mirrors Obsidian's core random-note behavior."

    stats: {
        downloads:  82903
        updated_at: 1625751354000
    }
}
```
