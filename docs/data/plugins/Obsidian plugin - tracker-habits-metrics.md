# Habitify

Tracks habits and metrics in note-based trackers whose data stays in the vault as readable Markdown rather than a separate database. Six tracker types are available: good habit, bad habit, number, counter, text and scale. Calendar heatmaps, interactive charts, limit indicators, streaks and summary statistics are rendered from the recorded values.
