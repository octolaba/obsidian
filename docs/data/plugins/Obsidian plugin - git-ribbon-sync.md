# Git Ribbon Sync

Puts Git actions on the left ribbon so the vault can be pulled, committed and pushed without opening a terminal. A separate tab shows an interactive commit log for the repository, and pull reports its status back into the interface. The same actions are registered as commands and can be bound to hotkeys.

```cue
plugin: {
    id:     "git-ribbon-sync"
    name:   "Git Ribbon Sync"
    author: "Pietro"
    repo:   "deltaplanoo/git-ribbon-sync"

    html_url:    "https://community.obsidian.md/plugins/git-ribbon-sync"
    github_url:  "https://github.com/deltaplanoo/git-ribbon-sync"
    description: "Sync vault changes: quicky pull, push, and view git history from ribbon icons and commands. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add Git action buttons to the left ribbon to pull, commit & push, and view your repository's commit history without opening a terminal. Open an interactive commit-log tab, run git pull with status feedback, and stage/commit/push changes from the ribbon or via registered commands and hotkeys."

    stats: {
        downloads:  16
        updated_at: 1785246994000
    }
}
```
