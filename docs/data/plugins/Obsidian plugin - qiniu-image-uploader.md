# Qiniu Image Uploader

Uploads images from the clipboard to Qiniu Cloud storage and embeds the returned remote URL in the note instead of saving a file inside the vault. A Qiniu bucket and API keys are configured so that images go straight to that cloud storage.

```cue
plugin: {
    id:     "qiniu-image-uploader"
    name:   "Qiniu Image Uploader"
    author: "jianzs"
    repo:   "jianzs/obsidian-qiniu-image-uploader"

    html_url:    "https://community.obsidian.md/plugins/qiniu-image-uploader"
    github_url:  "https://github.com/jianzs/obsidian-qiniu-image-uploader"
    description: "Upload images from your clipboard to qiniu.com and embed uploaded image to your note."
    about:       "Upload images to Qiniu Cloud from Obsidian and insert remote URLs into your notes instead of saving files in the vault. Connect your Qiniu bucket and API keys to send images directly to your cloud storage."

    stats: {
        downloads:  3357
        updated_at: 1722085215000
    }
}
```
