# PDF Paste

Cleans text pasted from PDFs and other sources by removing unwanted newlines, repairing words broken by hyphenated line breaks and normalizing spacing. Paragraph structure is preserved, so the cleaned text fits into the surrounding note.

    id:     "pdf-paste"
    name:   "PDF Paste"
    author: "cormac-c"
    repo:   "cormac-c/obsidian-paste-plugin"

    github_url:  "https://github.com/cormac-c/obsidian-paste-plugin"
