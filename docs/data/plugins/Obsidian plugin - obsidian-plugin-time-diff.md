# TimeDiff

This plugin calculates the difference in hours and minutes between two dates inside a timediff Markdown block. Each range in the block is displayed as a readable duration, with a summed total at the bottom. It can also show the total time difference for the current file and insert a timediff block or the current time at the cursor.

```cue
plugin: {
    id:     "obsidian-plugin-time-diff"
    name:   "TimeDiff"
    author: "dominiczaq"
    repo:   "dominiczaq/obsidian-plugin-time-diff"

    html_url:    "https://community.obsidian.md/plugins/obsidian-plugin-time-diff"
    github_url:  "https://github.com/dominiczaq/obsidian-plugin-time-diff"
    description: "Calculate and displays diff in hours and minutes between two dates in `timediff` Markdown block."
    about:       "Parse timediff blocks containing ranges like \"11:10 - 12:20\" and display readable durations for each range with a summed total at the bottom. Show total time diff for the current file and insert timediff blocks or the current time at the cursor."

    stats: {
        downloads:  5888
        updated_at: 1772815556000
    }
}
```
