# Project Manager

Manages projects held in plain Markdown files with YAML frontmatter, viewed and edited through Table, Gantt, and Kanban views. Subtasks, dependencies, milestones, time, custom fields, bulk actions, and due date notifications are covered, and the recorded description states that it works fully offline.
