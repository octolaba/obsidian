# Autosave Control

Autosave Control changes how Obsidian saves files: per-file autosaves can be delayed until edits stop, autosave can be disabled entirely, and workspace layout writes can be deferred. Its recorded About gives the purpose as reducing sync conflicts, excessive writes and battery use. The current save state is shown in the status bar as a colored dot whose appearance is customizable.

```cue
plugin: {
    id:     "autosave-control"
    name:   "Autosave Control"
    author: "Miha Smrekar"
    repo:   "mihasm/obsidian-autosave-control"

    html_url:    "https://community.obsidian.md/plugins/autosave-control"
    github_url:  "https://github.com/mihasm/obsidian-autosave-control"
    description: "An Obsidian plugin for delaying or disabling automatic saves. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Control how Obsidian saves files by delaying per-file autosaves until edits stop, disabling autosave entirely, or deferring workspace layout writes to reduce sync conflicts, excessive writes, and battery use. Shows current save state in the status bar using a customizable colored dot."

    stats: {

}
```
