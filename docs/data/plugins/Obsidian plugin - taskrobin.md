# Sync Emails

Sync Emails brings emails and their attachments into the vault through TaskRobin, writing them as dated Markdown files that build a local, searchable archive. Attachments are saved automatically and a custom storage directory can be set. Messages can be pulled from several inboxes or on demand through forwarding aliases.

    id:     "taskrobin"
    name:   "Sync Emails"
    author: "taskrobin"
