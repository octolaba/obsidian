# Speech To Text Keyboard Helper

Commands that insert a newline are added to the command palette, for Android speech-to-text keyboards that cannot produce line breaks themselves. A new line is appended or prepended and the cursor is moved into it. The recorded inputs state that the plugin contains no speech-to-text of its own.

```cue
plugin: {
    id:     "speech2text-helper"
    name:   "Speech To Text Keyboard Helper"
    author: "mwoz123"
    repo:   "mwoz123/speech-to-text-keyboard-helper"

    html_url:    "https://community.obsidian.md/plugins/speech2text-helper"
    github_url:  "https://github.com/mwoz123/speech-to-text-keyboard-helper"
    description: "Make Google Speech to Text on Android available from the command palette."
    about:       "Add newline commands to Obsidian's command palette for Android speech-to-text keyboards that don't handle line breaks. Append or prepend a new line and jump the cursor into it. Does not include speech-to-text functionality."

    stats: {
        downloads:  5080
        updated_at: 1692214269000
    }
}
```
