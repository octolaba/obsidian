# Export Image plugin

Exports a note or selected content as a high-resolution image, saved to a file or copied to the clipboard. Text or image watermarks and author metadata can be added, Obsidian metadata included, long notes split across several images, and whole folders exported in a batch. Width is adjustable and output can be produced at twice the resolution.
