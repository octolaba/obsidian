# MD Formatter

Reformats Markdown files in one action, standardizing the layout without changing the text. Rules for spacing, indentation, alignment and table widths are edited as YAML, with defaults for headings, lists, code and quotes. Formatting runs from the context menu or the command palette, and whole folders can be processed in a batch.
