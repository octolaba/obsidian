# Inkbound

Exports notes to EPUB 3 files with a chapter list, embedded images and metadata taken from note frontmatter. The export scope is a single note, a folder of notes, or a note together with the notes it links to. A finished EPUB can optionally be delivered over the local network to an e-ink reader, with Onyx Boox named as the target.

    id:     "inkbound"
    name:   "Inkbound"
