# Timekeep

Timekeep records time spent on tasks through inline timekeep code blocks or an Insert Tracker command. Entries can be edited or deleted and the tracked data exported as a Markdown table, CSV, JSON or PDF. Timestamps are persisted, so a running timer continues across restarts.

```cue
plugin: {
    id:     "timekeep"
    name:   "Timekeep"
    author: "jacobtread"
    repo:   "jacobtread/obsidian-timekeep"

    html_url:    "https://community.obsidian.md/plugins/timekeep"
```
