# Interval Timer

Interval Timer runs focus and break cycles using methods such as the Pomodoro Technique. Completed intervals are recorded on the Markdown task lines they belong to.

```cue
plugin: {
    id:     "interval-timer"
    name:   "Interval Timer"
    author: "tamiroh"
    repo:   "tamiroh/obsidian-interval-timer"

    html_url:    "https://community.obsidian.md/plugins/interval-timer"
    github_url:  "https://github.com/tamiroh/obsidian-interval-timer"
    description: "Run focus and break cycles using methods like the Pomodoro Technique, and record completed intervals on your Markdown task lines. - This plugin has not been manually reviewed by Obsidian staff."

    stats: {
        downloads:  160
        updated_at: 1786114083000
    }
}
```
