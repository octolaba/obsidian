# Daily Checkbox Focus

Moves the editor cursor to the first truly empty checkbox when a daily note named in the YYYY-MM-DD form is opened, placing the caret at the end of that line. Manual commands jump to that checkbox or report what was found. Checkboxes inside fenced code blocks, callouts and blockquotes are ignored.

    id:     "daily-checkbox-focus"
    name:   "Daily Checkbox Focus"
    author: "Geo"

    html_url:    "https://community.obsidian.md/plugins/daily-checkbox-focus"
    github_url:  "https://github.com/geokhv/obsidian-daily-checkbox-focus"

Provide manual commands to jump to or debug the first empty checkbox, and ignore checkboxes inside fenced code blocks, callouts, and blockquotes."
