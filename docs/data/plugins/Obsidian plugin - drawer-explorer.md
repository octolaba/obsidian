# Drawer Explorer

Opens a pop-up drawer holding a file tree with vim-style modal navigation — hjkl to move, a, r and d for file operations, i to filter, Esc back to normal mode — plus fuzzy filtering, so files can be browsed without a mouse. File operations run inside the drawer, including create, wikilink-aware rename, move, copy and delete. A live pane previews rendered Markdown, images, Canvas minimaps and .base summaries, and further preview types can be added through a small provider API.
