# Bragi Canvas

Bragi Canvas turns Canvas into a node-based generation workspace that uses selected nodes and their incoming edges as prompts and references. It generates images, video, text, speech, music and sound effects, shows upstream media on nodes, batches or tiles outputs and writes results back as connected nodes. Workflows are imported and exported as portable .bragi files, and the canvas can be exposed through a local MCP server for automation.
