# Open Folder Button

Adds a button to each folder row in the file explorer that opens that folder in Windows Explorer, leaving the row's expansion state unchanged. It passes the local folder path to explorer.exe, reads no note contents and makes no external network requests. It is restricted to local vaults on Windows 11 with Obsidian Desktop 1.12.7 or later.
