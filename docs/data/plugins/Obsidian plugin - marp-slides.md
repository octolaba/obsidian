# Marp Slides

Marp Slides creates and previews slide decks written in Markdown using Marp inside Obsidian. Decks export to HTML, PDF, PPTX or images through the Marp CLI API, custom theme CSS can be applied, and slides can be presented directly from the plugin.

```cue
plugin: {
    id:     "marp-slides"
    name:   "Marp Slides"
    author: "samuele-cozzi"
    repo:   "samuele-cozzi/obsidian-marp-slides"

    html_url:    "https://community.obsidian.md/plugins/marp-slides"
    github_url:  "https://github.com/samuele-cozzi/obsidian-marp-slides"
    description: "Create Marp presentations."
    about:       "Create and preview slide decks from Markdown using Marp inside Obsidian. Export decks to HTML, PDF, PPTX, or images via the Marp CLI API, apply custom theme CSS, and present slides directly."

    stats: {
        downloads:  52146

}
```
