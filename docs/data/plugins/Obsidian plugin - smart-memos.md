# Smart Memos

Smart Memos records audio directly into a note with pause, resume and restart controls, and also accepts imported recordings. Recordings are transcribed with AI and turned into detailed Markdown notes and Mermaid charts derived from the transcript. Prompts can be customized to shape the analysis and the output, and the recorded formats are mp3, mp4, mpeg, wav and webm.

```cue
plugin: {
    id:     "smart-memos"
    name:   "Smart Memos"
    author: "mossy1022"
    repo:   "mossy1022/Smart-Memos"

    html_url:    "https://community.obsidian.md/plugins/smart-memos"
    github_url:  "https://github.com/mossy1022/Smart-Memos"
    description: "Create personalized and intelligent analysis, brainstorms, summaries, transcriptions, and more for audio recordings that can be imported or spoken directly into a note"
    about:       "Record audio directly into notes with pause, resume, and restart controls. Transcribe spoken or imported audio with AI and generate detailed Markdown notes and Mermaid charts from the transcript. Customize prompts to shape analysis and output; supports mp3, mp4, mpeg, wav, webm."

    stats: {
        downloads:  8721
        updated_at: 1727645923000
    }
}
```
