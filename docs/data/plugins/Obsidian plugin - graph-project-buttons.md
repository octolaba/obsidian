# Graph Project Buttons

Adds one-click project filter buttons to every graph view, so a subfolder can be filtered without typing a path query by hand. Buttons are discovered automatically for each project subfolder, alongside Curated and All buttons, with the active one highlighted. The bar is collapsible and dockable and updates automatically as the graph changes.
