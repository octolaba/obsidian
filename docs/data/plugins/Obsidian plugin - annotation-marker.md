# Annotation Marker

Adds colored highlights, inline comments and ruby phonetic annotations to notes while leaving the original Markdown untouched, storing the annotations in separate files that re-sync when a note changes. Marks can span paragraphs and nest or overlap, editing works in both preview and editor modes, and all annotations are managed from a floating panel and a sidebar list.
