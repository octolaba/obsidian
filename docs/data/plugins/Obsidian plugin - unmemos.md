# UNmemos

Captures quick thoughts through a flash composer and files them into a chronological timeline stored as native Obsidian Canvas files. Memos are grouped by day, tags are extracted automatically, and stars, an archive, full-text and tag filters and inline editing are available. At-mentions link memos to notes, and everything stays local and offline.
