# Get Stock Information

Takes a stock symbol and inserts a callout block carrying the latest information for it. The block shows bid and ask, spread, name, currency, volume, market cap, the day and 52-week ranges, and a timestamp.

```cue
plugin: {
    id:     "get-stock-information"
    name:   "Get Stock Information"
    author: "mikejongbloet"
    repo:   "mikejongbloet/obsidian-get-stock-information"

    html_url:    "https://community.obsidian.md/plugins/get-stock-information"
    github_url:  "https://github.com/mikejongbloet/obsidian-get-stock-information"
    description: "Take a stock symbol and returns a callout block with the latest stock information."
    about:       "Insert live stock data for any symbol directly into your note. Display bid/ask, spread, name, currency, volume, market cap, day and 52-week ranges, and a timestamp in a callout block."

    stats: {
        downloads:  5642
        updated_at: 1680469317000
    }
}
```
