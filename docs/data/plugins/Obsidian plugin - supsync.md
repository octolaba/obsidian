# SupSync

Vaults are synced in real time between several users through Supabase, covering notes, canvases, Excalidraw drawings, images, PDFs and audio. A file is locked automatically while it is being edited, and conflicts are resolved in a side-by-side diff. A multi-user vault is created or joined by sharing a vault identifier.
