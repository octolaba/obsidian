# MarkItDown Importer

MarkItDown Importer brings files, folders, ZIP archives, images, audio, web pages and YouTube links into the vault as Markdown notes by dragging them into Obsidian. It converts PDFs, Word, Excel and PowerPoint documents, HTML, Markdown, CSV and RTF files, and common image and audio formats, running OCR on images and transcription on audio, and it recurses through folders. The result is either inserted as a wiki link at the cursor or saved as a note in a chosen folder.

```cue
plugin: {
    id:     "markitdown-importer"
    name:   "MarkItDown Importer"
    author: "Elek"
    repo:   "renoirtian/markitdown-obsidian-importer"

    html_url:    "https://community.obsidian.md/plugins/markitdown-importer"
    github_url:  "https://github.com/renoirtian/markitdown-obsidian-importer"
    description: "Drag files, folders, archives, images, audio, web pages, and YouTube links into Obsidian and import them as Markdown notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Import files, folders, ZIP archives, images (with OCR), audio (with transcription), web pages, and YouTube links into your vault as Markdown notes. Convert PDFs, Word/Excel/PowerPoint, HTML/MD/CSV/RTF and common image/audio formats recursively and insert wiki links at the cursor or save notes to a chosen folder."
```
