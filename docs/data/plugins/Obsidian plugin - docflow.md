# DocFlow

Renders IT project artifacts with type-aware views by detecting ERD definitions, OpenAPI or Swagger specifications, Mermaid architecture diagrams, WBS and meeting notes. Interactive ER diagrams and an embedded Swagger UI are displayed, and diagrams export to SVG or PNG. A left-hand explorer groups files by type, status and project, shows frontmatter metadata, and inserts English or Korean templates.
