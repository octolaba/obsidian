# Molren

Renders 2D chemical structures from SMILES, molfile, SDF or reaction (rxn) input written in fenced code blocks, drawing them inline with RDKit.js running locally. Molecules stay in the note as plain, searchable text, and the drawing updates live in preview and reading view. Several molecules can be placed in one block, with captions and comments.
