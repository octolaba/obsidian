# Theme School

Theme School teaches theme development through an interactive studio in which each visual control is tied to the CSS variable behind it, and body-text contrast is checked against WCAG AA. Separate light and dark baselines, hierarchy, type and spacing systems and UI controls are explored, and the result exports as a standalone theme.css and manifest.json, which is the graduation its description names.
