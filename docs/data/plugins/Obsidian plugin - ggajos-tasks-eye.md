# Tasks Eye

Reads Tasks checkboxes across the vault and treats each note as a project, surfacing the single next actionable task for it based on scheduled or due dates. Three views organize the result: Focus for tasks due today or overdue, Open for all upcoming active notes, and Inbox for notes with missing metadata. The tasks stay in the notes, which remain the source of truth.
