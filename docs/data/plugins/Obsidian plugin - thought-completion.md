# Thought Completion

Thought Completion suggests what to think or write about next, showing prompts inline as faded ghost text at the cursor rather than writing for you. It analyzes the surrounding context and offers Questions, Structural, Critical and Connector modes, with smart or manual triggers and a status bar indicator.

```cue
plugin: {
    id:     "thought-completion"
    name:   "Thought Completion"
    author: "talhabw"
    repo:   "talhabw/obsidian-thought-completion"

    html_url:    "https://community.obsidian.md/plugins/thought-completion"
    github_url:  "https://github.com/talhabw/obsidian-thought-completion"
    description: "A thinking companion that suggests what to think or write about next. Like IDE tab completion, but for thoughts. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Suggest thought-provoking prompts inline as faded ghost text at your cursor to nudge idea development without writing for you. Analyze your context and offer multiple modes — Questions, Structural, Critical, Connector — with smart or manual triggers and a status bar indicator."

    stats: {
        downloads:  229
        updated_at: 1769940115000
    }
}
```
