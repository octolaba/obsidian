# Version History Diff

Version histories from the core Sync and File Recovery plugins and from Git are diffed for the active file, line by line or side by side. Any version opens in a modal rendered as Markdown or plain text, Git hashes can be copied, and the file can be overwritten with the selected revision. A color-blind mode is available.
