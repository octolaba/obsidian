# Buildian

Buildian connects the vault to external coding-agent CLIs and provider-backed runtimes, among them xAI Grok Build, Cursor Agent, Factory Droid and Amp code. It offers a sidebar chat, inline note editing with word-level diff previews, agent read, write, edit and search access to vault files, mentions of notes or subagents as context, reusable slash commands and skills, a Plan Mode for reviewing changes, and several conversations across tabs. The recorded inputs state that it is built on Claudian and is unofficial and unaffiliated with the providers it supports.
