# BRAT

Beta versions of plugins and themes are installed and updated from GitHub by adding repository paths to a test list. Updates are downloaded and plugins reloaded automatically, so a beta release can be tested without manual downloads or file copying.

```cue
plugin: {
    id:     "obsidian42-brat"
    name:   "BRAT"
    author: "tfthacker"
    repo:   "tfthacker/obsidian42-brat"

    html_url:    "https://community.obsidian.md/plugins/obsidian42-brat"
    github_url:  "https://github.com/tfthacker/obsidian42-brat"
    description: "Easily install a beta version of a plugin for testing."
    about:       "Update beta plugins and themes from GitHub by adding repository paths to a test list. Download updates and reload plugins automatically so you can test new releases without manual downloads or file copying."

    stats: {
        downloads:  950519
        updated_at: 1782921864000
    }
}
```
