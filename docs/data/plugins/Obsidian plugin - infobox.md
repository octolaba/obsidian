# Infobox

Renders Wikipedia-style infoboxes from YAML frontmatter as a floating panel pinned to the top-right of the reading pane. A box holds a title, subtitle, an image with a caption, and structured key-value fields grouped by named section dividers. Local vault images are resolved, and light and dark themes work on desktop and mobile.

```cue
plugin: {
    id:     "infobox"
    name:   "Infobox"
    author: "ozzycosmo"
    repo:   "ozzycosmo/obsidian-infobox"

    html_url:    "https://community.obsidian.md/plugins/infobox"
    github_url:  "https://github.com/ozzycosmo/obsidian-infobox"
    description: "Renders Wikipedia-style infoboxes from YAML frontmatter. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render Wikipedia-style infoboxes from YAML frontmatter and pin a floating panel to the top-right of the reading pane. Include title, subtitle, image with caption, and structured key-value fields with named section dividers; resolve local vault images and support light/dark themes on desktop and mobile."
```
