# Image Upload Toolkit

Uploads local images embedded in Markdown to a remote store and exports the Markdown with public image URLs for publishing to a static site, naming Imgur, Aliyun OSS, ImageKit and AWS S3 as targets. Markdown and wiki links are detected and processed in batches, mermaid diagrams are converted to PNG, web images can be re-uploaded, and PNG, JPG, GIF, SVG, WebP and Excalidraw formats are handled with progress shown.

Convert mermaid diagrams to PNG, re-upload web images, handle PNG/JPG/GIF/SVG/WebP/Excalidraw formats, show real-time progress, and support flexible relative paths."
