# Day and Night

Day and Night switches automatically between a chosen day theme and night theme on a set time schedule. A ribbon icon toggles the theme immediately and pauses the automatic switching for the rest of the day, and the automatic switching is turned on or off in the plugin settings.

```cue
plugin: {
    id:     "obsidian-day-and-night"
    name:   "Day and Night"
    author: "cybert17"
    repo:   "cybert17/obsidian-day-and-night"

    html_url:    "https://community.obsidian.md/plugins/obsidian-day-and-night"
    github_url:  "https://github.com/cybert17/obsidian-day-and-night"
    description: "Automatically toggle themes between day theme and night theme on a set time schedule."
    about:       "Switch between light and dark themes on a set schedule to apply chosen day and night color schemes. Toggle themes instantly with a ribbon icon and pause automatic switching for the rest of the day when overridden. Turn automatic switching on or off from plugin settings."
```
