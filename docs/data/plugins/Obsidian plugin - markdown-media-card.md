# Markdown Media Card

Markdown Media Card inserts media information cards into notes for items such as books, music and movies. Fields including title, cover, author or artist or director, rating and summary are defined per card, and the block is rendered as a styled card inside the vault.

```cue
plugin: {
    id:     "markdown-media-card"
    name:   "Markdown Media Card"
    author: "zhouhua"
    repo:   "zhouhua/obsidian-markdown-media-card"

    html_url:    "https://community.obsidian.md/plugins/markdown-media-card"
    github_url:  "https://github.com/zhouhua/obsidian-markdown-media-card"
    description: "Insert media information cards in Markdown, such as books, music, movies, etc."
    about:       "Insert customizable media info cards into Markdown notes for books, music, movies and other items. Define fields like title, cover, author/artist/director, rating and summary to render styled, shareable card blocks directly in your vault."

    stats: {
        downloads:  3074

    }
}
```
