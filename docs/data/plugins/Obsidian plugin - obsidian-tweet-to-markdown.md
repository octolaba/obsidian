# Tweet to Markdown

Tweets are saved as Markdown files carrying the tweet text, author, timestamp and media links, along with images and polls. A Twitter v2 API bearer token or API key connects the plugin so that tweets are fetched into the vault.

```cue
plugin: {
    id:     "obsidian-tweet-to-markdown"
    name:   "Tweet to Markdown"
    author: "kbravh"
    repo:   "kbravh/obsidian-tweet-to-markdown"

    html_url:    "https://community.obsidian.md/plugins/obsidian-tweet-to-markdown"
    github_url:  "https://github.com/kbravh/obsidian-tweet-to-markdown"
    description: "Save tweets as Markdown files, along with their images, polls, etc."
    about:       "Save tweets as clean Markdown files with tweet text, author, timestamp, and media links. Connect using a Twitter v2 API bearer token or API key to fetch tweets directly into your vault."

    stats: {
        downloads:  13711
        updated_at: 1670272301000
    }
}
```
