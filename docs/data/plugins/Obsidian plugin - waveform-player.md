# Waveform Player

Replaces the default audio preview with a player that draws the file as a waveform and offers controls for visual scrubbing and playback. It covers audio attachments such as MP3 and WAV as well as recordings made inside Obsidian.

```cue
plugin: {
    id:     "waveform-player"
    name:   "Waveform Player"
    author: "zhouhua"
    repo:   "zhouhua/obsidian-waveform-player"

    html_url:    "https://community.obsidian.md/plugins/waveform-player"
    github_url:  "https://github.com/zhouhua/obsidian-waveform-player"
    description: "Render audio files as waveforms"
    about:       "Display audio files with a sleek waveform player and attractive controls for visual scrubbing and playback. Support audio attachments (MP3, WAV, etc.) and Obsidian's recorded audio, replacing default previews with the waveform player automatically."
```
