# Copy as HTML

Copy as HTML converts the selected Markdown to HTML and places it on the clipboard. Pasting into Slack, Google Docs or any other editor that accepts HTML retains the original formatting.

```cue
plugin: {
    id:     "copy-as-html"
    name:   "Copy as HTML"
    author: "jenningsb2"
    repo:   "jenningsb2/copy-as-html"

    html_url:    "https://community.obsidian.md/plugins/copy-as-html"
    github_url:  "https://github.com/jenningsb2/copy-as-html"
    description: "Convert the selected Markdown to HTML and copy it to the clipboard."
    about:       "Convert selected Markdown to HTML and copy it to the clipboard. Paste into Slack, Google Docs, or any editor that accepts HTML to retain original formatting."
```
