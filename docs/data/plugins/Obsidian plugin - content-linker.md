# Content Linker

Content Linker searches the vault for repeated phrases that are not yet wrapped as wiki links and ranks them as candidate bi-directional links. Selected entries can be converted into links, and chosen links can be reverted back to plain text. Folders can be excluded from scans and individual items added to or removed from an ignore list.

```cue
plugin: {
    id:     "content-linker"
    name:   "Content Linker"
    author: "medill-east"
    repo:   "medill-east/obsidian-content-linker"

    html_url:    "https://community.obsidian.md/plugins/content-linker"
    github_url:  "https://github.com/medill-east/obsidian-content-linker"
    description: "Search and add bi-directional links to existing content."
    about:       "Search the vault for repeated phrases not wrapped in [[...]] and display a ranked list of potential bi-links. Convert selected entries into [[...]] links, exclude folders from scans, add/remove items from an ignore list, and revert chosen links back to plain text."

    stats: {
        downloads:  4125
        updated_at: 1712212490000
    }
}
```
