# Vocabulary Highlighter

Vocabulary Highlighter colors English words according to how frequent they are, to support reading and language study. Frequency thresholds and colors are adjustable so that either high- or low-frequency vocabulary stands out, and the highlighting can be toggled off.

```cue
plugin: {
    id:     "vocabulary-highlighter"
    name:   "Vocabulary Highlighter"
    author: "eatgrass"
    repo:   "eatgrass/obsidian-vocab-highlighter"

    html_url:    "https://community.obsidian.md/plugins/vocabulary-highlighter"
    github_url:  "https://github.com/eatgrass/obsidian-vocab-highlighter"
    description: "Hightlight vocabulary based on the word frequency."
    about:       "Highlight English words by frequency to focus reading and language study. Adjust frequency thresholds and colors to emphasize high- or low-frequency vocabulary, and toggle vocabulary highlighting on or off as needed."

    stats: {
        downloads:  5562
        updated_at: 1700126962000
    }
}
```
