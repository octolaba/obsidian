# Editor Mode Button

Adds a ribbon button and a command that switch all open notes between a reading mode and an editing mode, and apply the chosen default to new tabs. Each mode can be styled with custom CSS, and toggling reloads the open files.

```cue
plugin: {
    id:     "editor-mode-button"
    name:   "Editor Mode Button"
    author: "kubaxius"
    repo:   "kubaxius/obsidian-editor-mode-button"

    html_url:    "https://community.obsidian.md/plugins/editor-mode-button"
    github_url:  "https://github.com/kubaxius/obsidian-editor-mode-button"
    description: "Adds a button to toggle global editor mode. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Switch between distinct reading and editing modes for all open notes, and apply the chosen default to new tabs. Style each mode with custom CSS and use the ribbon indicator or built-in command to toggle modes and reload open files."

    stats: {
        downloads:  202

    }
}
```
