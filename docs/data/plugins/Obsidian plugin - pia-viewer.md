# Pia viewer

Pia viewer applies Munpia and Novelpia typesetting templates to notes so web novels are laid out as they appear on those platforms. The recorded description summarises the effect as making the note look mobile on a PC, and the About text invites requests for additional platform styles.

    id:     "pia-viewer"
