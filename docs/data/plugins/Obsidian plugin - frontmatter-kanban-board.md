# TaskManagement

Builds a Kanban board from Markdown task files that carry frontmatter, with cards dragged between status columns. Frontmatter is edited on the card or in the note, covering due, create, complete and work-on dates, priority and notification lead times. Filters combine nested AND and OR groups, and sorting works over built-in or custom fields of type text, number, date, datetime, range, select or checkbox, with weighted priorities.
