# Data Files Editor

Opens and edits .txt, .json and .xml files inside Obsidian, and creates new ones. New files are added from the file-tree context menu, either inside a folder or alongside a selected file.

    id:     "data-files-editor"
    name:   "Data Files Editor"
    author: "zuktol"
    repo:   "zuktol/obsidian-data-files-editor"
