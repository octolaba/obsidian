# Share as Gist

A note is shared as a public or private GitHub Gist and the share URL is copied to the clipboard. Gists created this way are updated or deleted from within Obsidian, optionally with a table of contents for navigation. GitHub.com and GitHub Enterprise Cloud with data residency are both supported.

```cue
plugin: {
    id:     "obsidian-share-as-gist"
    name:   "Share as Gist"
    author: "timrogers"
    repo:   "timrogers/obsidian-share-as-gist"

    html_url:    "https://community.obsidian.md/plugins/obsidian-share-as-gist"
    github_url:  "https://github.com/timrogers/obsidian-share-as-gist"
    description: "Share a note as a GitHub.com Gist."
    about:       "Share notes as public or private GitHub Gists and copy the share URL to your clipboard. Update or delete gists directly from Obsidian, work with GitHub.com and Gitahub Enterprise Cloud with data residency, and optionally include a table of contents for easier navigation."

    stats: {
        downloads:  10089

    }
}
```
