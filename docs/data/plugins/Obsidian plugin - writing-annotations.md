# Writing Annotations

Adds text annotations and footnotes inside an Obsidian note and performs simple text replacement. Outlines and fragments of inspiration for a novel are recorded alongside the draft, and their version history is saved and managed. The recorded About text is written in Chinese; this is an English restatement of it.

plugin: {
    id:     "writing-annotations"
    name:   "Writing Annotations"
    author: "hornat"
    repo:   "hornatx/writing-annotations"

    html_url:    "https://community.obsidian.md/plugins/writing-annotations"
    github_url:  "https://github.com/hornatx/writing-annotations"
