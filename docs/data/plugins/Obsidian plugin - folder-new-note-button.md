# Folder New Note Button

Adds a small plus button to every folder in the Files view, appearing when the folder title is hovered or focused. Pressing it creates a uniquely named Markdown file and selects its title so it can be renamed straight away. It works with inline or header titles, across multiple explorer panes, and on mobile.

```cue
plugin: {
    id:     "folder-new-note-button"
    name:   "Folder New Note Button"
    author: "wuhup"
    repo:   "wuhup/obsidian-folder-new-note-button"

    html_url:    "https://community.obsidian.md/plugins/folder-new-note-button"
    github_url:  "https://github.com/wuhup/obsidian-folder-new-note-button"
    description: "Create new notes from a hover button on each folder in the Files view. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add a subtle \"+\" button to every folder in the Files view to create a new note by hovering or focusing the folder title. Create a uniquely named Markdown file and select its title for immediate renaming; support inline or header titles and keep the button mobile-friendly across multiple explorer panes."

}
```
