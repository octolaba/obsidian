# TickTickSync

TickTickSync synchronizes tasks and notes bidirectionally between Obsidian and TickTick, keeping task states aligned and understanding the Tasks plugin's date and time formats. TickTick tasks are created and updated automatically from Obsidian, and mobile compatibility is retained.
