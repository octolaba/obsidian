# Table Line Break Mobile

Inserts a line break inside a Markdown table cell on mobile devices, through a command or a toolbar icon. The recorded About text states that the break is written as an HTML line-break element, so several lines can be typed in one cell without a hardware keyboard.

    id:     "table-line-break"
