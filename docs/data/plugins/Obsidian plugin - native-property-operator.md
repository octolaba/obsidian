# Native Property Operator

Previews and then applies YAML frontmatter property operations across visible Markdown notes. A catalog of property names with native Obsidian types backs saved manual or automatic actions that add, remove, rename or set values, with every change previewed before it is written. Results report changed, skipped and failed counts with reasons, and multi-file or overwrite operations ask for confirmation.
