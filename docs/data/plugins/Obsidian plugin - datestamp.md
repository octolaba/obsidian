# Datestamp

Prefixes the filename of a new note with today's date, using a configurable date format, separator and default title, with YYYY-MM-DD as the default. Untitled notes are preserved, a built-in delay accommodates Templater, and the project states compatibility with QuickAdd.

```cue
plugin: {
    id:     "datestamp"
    name:   "Datestamp"
    author: "huynhtranhoanglong"
    repo:   "huynhtranhoanglong/obsidian-datestamp"

    html_url:    "https://community.obsidian.md/plugins/datestamp"
    github_url:  "https://github.com/huynhtranhoanglong/obsidian-datestamp"
    description: "Automatically prefix new note names with today's date. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Prefix new note filenames with today's date using a configurable date format, separator, and default title (default YYYY-MM-DD). Preserve untitled notes and work immediately after install, with a built-in delay for Templater and seamless QuickAdd compatibility."

    stats: {
        downloads:  112
        updated_at: 1770072262000
    }
}
```
