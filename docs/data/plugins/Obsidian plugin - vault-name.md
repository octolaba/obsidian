# Vault Name

Displays the vault name in the side navigation file explorer, which the recorded About presents as restoring the behaviour Obsidian had before version 1.6.0. Its styling can be customized and the title given a sticky position, and it integrates with the Legacy Vault Switcher for quick switching between vaults.

```cue
plugin: {
    id:     "vault-name"
    name:   "Vault Name"
    author: "gapmiss"
    repo:   "gapmiss/vault-name"

    html_url:    "https://community.obsidian.md/plugins/vault-name"
    github_url:  "https://github.com/gapmiss/vault-name"
    description: "Display and customize the vault name (title) in the side navigation file explorer."
```
