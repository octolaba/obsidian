# JSON Collapsible

JSON Collapsible displays JSON data in a note as an interactive collapsible tree, color-coding strings, numbers, booleans and null. Standard JSON code blocks become readable, expandable views, and the viewer is described as lightweight and quick to render on desktop and mobile.

    id:     "json-collapsible"
