# Infostacker Note Publish

Publishes notes together with their attachments to a remote server, from where they can also be edited or deleted inside Obsidian. The generated links let recipients view the note and its attachments as HTML. The recorded inputs state that server storage is free with a daily limit of 100 published notes.

```cue
plugin: {
    id:     "infostacker"
    name:   "Infostacker Note Publish"
    author: "taskscape"
    repo:   "taskscape/InfostackerPlugin"

    html_url:    "https://community.obsidian.md/plugins/infostacker"
    github_url:  "https://github.com/taskscape/InfostackerPlugin"
    description: "Share your notes with attachments easy!"
    about:       "Publish notes and attachments to a remote server and edit or delete them directly from Obsidian. Share generated links so recipients can view notes and attachments as HTML; free server storage with a daily limit of 100 published notes."

    stats: {
        downloads:  818
        updated_at: 1786094882000
    }
}
```
