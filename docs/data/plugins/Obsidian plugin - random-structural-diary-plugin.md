# Random Structural Diary

Inserts randomly picked questions from a prepared list into a note, so different questions are answered each time. The list is either the built-in one or a Markdown file whose sections are marked by headings with one question per line. Questions are picked globally or from one section and inserted at the cursor.

```cue
plugin: {
    id:     "random-structural-diary-plugin"
    name:   "Random Structural Diary"
    author: "shockthunder"
    repo:   "shockthunder/RandomStructuralDiary"

    html_url:    "https://community.obsidian.md/plugins/random-structural-diary-plugin"
    github_url:  "https://github.com/shockthunder/RandomStructuralDiary"
    description: "Pick random questions from a prepared question list and answer different questions each time."
    about:       "Insert random structural diary questions into your note to spark new thoughts. Load the built-in list or specify a Markdown file with # section headers and one question per line, pick questions globally or by section, and insert chosen questions at the cursor."

    stats: {
        downloads:  8099
        updated_at: 1657980236000
    }
}
```
