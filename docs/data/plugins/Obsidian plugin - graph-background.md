# Graph Background

Sets the background of the global and local graph views to a solid colour, a linear or radial gradient, or an image, configured from the plugin settings without switching themes or writing CSS. The image can be a vault file or an external URL, with cover, contain, repeat or centre fit, plus dim and blur overlays that keep nodes readable. Changes apply live on desktop and mobile.

plugin: {
    id:     "graph-background"
    name:   "Graph Background"
    author: "You"

    html_url:    "https://community.obsidian.md/plugins/graph-background"
    github_url:  "https://github.com/jk-cpu-jpg/Graph-Background"

Use a vault file or external URL, pick fit (cover/contain/repeat/center), add dim/blur overlays for readable nodes, and see changes live on desktop and mobile."
