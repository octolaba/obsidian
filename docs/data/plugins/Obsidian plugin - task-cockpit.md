# Tasks Cockpit

Tasks Cockpit gathers every open task carrying the chosen tags into one hand-orderable list grouped by three horizons: in progress, upcoming and later. Drag-and-drop sets a custom order that survives later edits, ticking a task completes it in its source note, and the original note is one jump away. Recurring rollovers are tracked and the list refreshes itself.
