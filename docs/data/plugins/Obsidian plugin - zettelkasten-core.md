# Zettelkasten Core

Zettelkasten Core assembles a fleeting, literature and permanent note workflow in one plugin. Fleeting thoughts are captured through a quick-capture modal and an inbox sidebar, auto-tagged for processing, then promoted either to permanent notes carrying timestamp Zettel IDs or to structured literature summaries. Notes are organized into configurable folders, and permanent notes are linked to each other to build the knowledge graph.
