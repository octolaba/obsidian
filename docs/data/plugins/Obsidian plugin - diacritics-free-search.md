# Diacritics-Free Search

Searches and replaces text while ignoring diacritical marks, covering Hebrew nikud, Arabic tashkil, Latin accents, Greek polytonic and other Unicode combining marks. An in-note search offers real-time highlights, navigation and scrollbar markers, and a vault-wide modal lists matched lines with per-file counts and a global replace option.
