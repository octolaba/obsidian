# Embedded Terminal

Embeds a native PTY terminal in Obsidian for running interactive shells, Git commands and other command-line tools inside the workspace. It builds on xterm.js with node-pty and Windows ConPTY, supports ANSI colours, cursor control and tab completion, and keeps shell sessions running while the view is hidden.
