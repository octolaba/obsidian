# Scoped Search

Scoped Search searches only the folders you choose, from a dedicated modal or a dockable tab, with a folder picker offered as a list or as a collapsed tree. Results open in an expandable preview pane, filenames of non-Markdown files can be searched, advanced search syntax is supported, and folder selections are restored between sessions.
