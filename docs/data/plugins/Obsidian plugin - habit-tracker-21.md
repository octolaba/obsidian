# Habit Tracker 21

Tracks daily habits in a minimalist grid that matches the current theme, where clicking a cell logs a day and progress and streaks stay visible. Appearance and tracking behaviour are configurable, folders or files can be monitored, streaks tolerate gaps, and daily notes can be opened from the grid.
