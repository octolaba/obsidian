# Slides Extended

Slides Extended creates reveal.js presentations from Markdown notes and is recorded as a fork of Advanced Slides. Notes can be embedded into slides, edits previewed live, and themes and annotations applied. Decks export to PDF or HTML while the Obsidian Markdown is preserved.

```cue
plugin: {
    id:     "slides-extended"
    name:   "Slides Extended"
    author: "ebullient"
    repo:   "ebullient/obsidian-slides-extended"

    html_url:    "https://community.obsidian.md/plugins/slides-extended"
    github_url:  "https://github.com/ebullient/obsidian-slides-extended"
    description: "Create markdown-based reveal.js presentations. Fork of Advanced Slides."
    about:       "Create slide decks from your Obsidian notes. Embed notes into slides, preview edits live, apply themes and annotations, and export as PDF or HTML while preserving Obsidian Markdown."
```
