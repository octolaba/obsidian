# Basecraft

Basecraft adds a Pivot view to a .base file that cross-tabulates notes by row and column properties with aggregations. Count and Sum are free, while average, minimum, maximum, median and distinct belong to a Pro tier; cells can be clicked to open notes, shown as heatmaps or percentages, and exported to CSV or Excel.
