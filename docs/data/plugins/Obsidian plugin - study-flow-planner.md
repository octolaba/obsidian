# Study Flow Planner

A week or a month is planned on a scrollable timeline calendar covering 5:00 to 23:00 with several zoom levels. Color-coded events are created and linked to notes with autocomplete, events are detected from daily notes, and a study mode highlights academic items. Tasks are marked done against a live current-time line, and the recorded description states that Portuguese and English are supported.
