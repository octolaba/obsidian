# Tag and Tally

Runs Tag and Tally tabletop RPG sessions inside the vault, with inline resolution rolls covering advantage, disadvantage, tag bonuses and qualifiers, plus polyhedral dice presets. A sidebar searches the bundled rulebook and holds lookup tables and card decks for improvisation. NPC appearances, traits and hooks are generated procedurally.
