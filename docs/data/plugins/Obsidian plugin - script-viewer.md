# Script Viewer

Script Viewer opens shell, batch, PowerShell and AutoHotkey files as read-only source, covering extensions such as .sh, .bash, .zsh, .bat, .cmd, .ps1, .ahk, .command and .bats. The viewer offers stable line numbers, soft wrap, lightweight syntax hints and a searchable, filterable outline, and it highlights comments, variables, paths and risky command patterns alongside safety-focused summaries. It never executes a script, starts a terminal, changes files or makes network requests.

plugin: {
    id:     "script-viewer"
    name:   "Script Viewer"
    author: "Viggo Meesters"
    repo:   "viggomeesters/obsidian-script-viewer"

    about:       "Inspect shell, batch, PowerShell and AutoHotkey scripts (.sh/.bash/.zsh/.bat/.cmd/.ps1/.ahk/.command/.bats) in a read-only viewer with stable line numbers, soft-wrap, lightweight syntax hints, searchable outline, and filtering. Highlight comments, variables, paths and risky command patterns, and show safety-focused summaries while never executing, starting terminals, changing files, or making network requests."
