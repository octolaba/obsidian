# GH Links Shortener

Modifies GitHub links as they are pasted so the link title becomes a short GitHub reference instead of the full URL. It captures the pasted text and sets a compact repository and ref title for repositories, issues, pull requests and other GitHub pages.

```cue
plugin: {
    id:     "gh-links-shortener"
    name:   "GH Links Shortener"
    author: "dbarnett"
    repo:   "dbarnett/obsidian-gh-links-shortener"

    html_url:    "https://community.obsidian.md/plugins/gh-links-shortener"
    github_url:  "https://github.com/dbarnett/obsidian-gh-links-shortener"
    description: "Modifies pasted GitHub links to use short GitHub ref text as the link title."
    about:       "Shorten pasted GitHub URLs into concise repo/ref titles. Capture pasted text and set the link title to a compact GitHub reference (e.g., EnterpriseQualityCoding/FizzBuzzEnterpriseEdition#1) for repositories, issues, pull requests, and other GitHub pages."

    stats: {
        downloads:  356
        updated_at: 1755577063000
    }
}
```
