# Go To Heading

Go To Heading moves between headings with next and previous commands, and jumps to the start or end of the file when already at the first or last heading. A quick switcher lists the headings of the current document or of every file in the active folder so any one of them can be opened directly.

```cue
plugin: {
    id:     "oin-gotoheading"
    name:   "Go To Heading"
    author: "oin"
    repo:   "oin/obsidian-gotoheading"

    html_url:    "https://community.obsidian.md/plugins/oin-gotoheading"
    github_url:  "https://github.com/oin/obsidian-gotoheading"
    description: "Quickly navigate between headings."
```
