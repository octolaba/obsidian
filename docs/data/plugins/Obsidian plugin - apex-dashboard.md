# Apex Dashboard

Collects memos, todos, projects and reference notes into one customizable dashboard. Memo cards capture ideas, interactive checklists and progress bars manage tasks, and project cards link to notes, files and media. Sidebar widgets add a calendar, weather, a heatmap and a Pomodoro timer.
