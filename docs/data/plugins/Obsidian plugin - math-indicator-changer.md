# Math Indicator Changer

Math Indicator Changer converts LaTeX parenthesis and bracket math delimiters into the Markdown dollar and double-dollar forms, so formulas produced by GPT and other AI tools display correctly in Obsidian. It runs over the whole file or a selected region from a command or a toolbar button. The recorded description notes that the replacement is regex-based and may change unintended matches.

    id:     "math-indicator-changer"

    html_url:    "https://community.obsidian.md/plugins/math-indicator-changer"

    about:       "Convert LaTeX \\( \\) and \\[ \\] math delimiters to Markdown $ $ and $$ $$ so AI-generated equations display correctly in Obsidian. Apply to the whole file or a selected region via command or toolbar button; note the regex-based replacement may change unintended matches."
