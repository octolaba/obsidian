# Vault File Refresh

Polls the vault recursively for files added from outside Obsidian and reconciles them, so they become available in the file explorer, search, graph view and Dataview. The poller tracks new folders automatically and removes stale paths, and is described as lightweight, working out of the box with minimal performance impact.
