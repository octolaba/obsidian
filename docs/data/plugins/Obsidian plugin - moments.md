# Moments

Moments collects dated headings, standalone dated notes, and files created or modified on a given day into one chronological timeline view. Inline dated headings can be inserted in any note and standalone moments included alongside them. Files touched on a day can be revealed, so that everything worked on for a selected date is reconstructed.
