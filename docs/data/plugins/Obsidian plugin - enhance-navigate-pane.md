# Enhance Navigate Pane

Extends the native file explorer with inline heading navigation, multi-term filtering, custom icons and appearance settings. Files, folders and headings of any file type are searched with multi-word and OR queries, folder and heading context is preserved, matches are highlighted, and any heading can be opened from the sidebar.
