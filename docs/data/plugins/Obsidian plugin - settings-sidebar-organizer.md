# Settings Sidebar Organizer

Settings Sidebar Organizer groups Community Plugins into custom collapsible folders, sorting them automatically by keyword match and collecting the rest in an optional Ungrouped folder. Plugins can be renamed with aliases and reordered by hand, and Settings sidebar headers can be compacted or collapsed for a tighter layout.

    id:     "settings-sidebar-organizer"
    name:   "Settings Sidebar Organizer"
    author: "cyrylsz"

    html_url:    "https://community.obsidian.md/plugins/settings-sidebar-organizer"
