# Linkosaurus

Linkosaurus converts keywords into wikilinks as you type, dictate or paste, on desktop and mobile. It recognizes multi-word keywords, frontmatter aliases and an alias-mapping syntax, and it can scan the vault so that note titles and aliases become link targets.

```cue
plugin: {
    id:     "autolink-keywords"
    name:   "Linkosaurus"
    author: "polygonhunter"
    repo:   "polygonhunter/linkosaurus"

    html_url:    "https://community.obsidian.md/plugins/autolink-keywords"
    github_url:  "https://github.com/polygonhunter/linkosaurus"
    description: "Automatically converts keywords into Obsidian wikilinks as you type. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create wikilinks automatically as you type, dictate, or paste to keep your writing flow uninterrupted on desktop and mobile. Recognize multi-word keywords, frontmatter aliases and alias-mapping (///), and scan your vault to turn note titles and aliases into instant wikilinks."

    stats: {
        downloads:  908
        updated_at: 1784803021000
    }
}
```
