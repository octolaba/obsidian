# Index Flow

Renumbers Markdown files in a folder with zero-padded numeric prefixes, renaming in two phases to avoid collisions and showing a highlighted diff before the change is applied. Leading numeric prefixes can also be removed, name conflicts are resolved automatically, and the last batch can be undone.

    id:     "index-flow"
    name:   "Index Flow"
    author: "phongviez"
    repo:   "phongviez/obsidian-index-flow"

    html_url:    "https://community.obsidian.md/plugins/index-flow"
    github_url:  "https://github.com/phongviez/obsidian-index-flow"
    description: "Smart renumber and remove numbering for markdown files. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Renumber Markdown files in a folder using zero-padded numeric prefixes, perform safe two-phase renaming to avoid collisions, and preview highlighted diffs before applying changes. Remove leading numeric prefixes, auto-resolve name conflicts, and undo the last batch for predictable reversions."
