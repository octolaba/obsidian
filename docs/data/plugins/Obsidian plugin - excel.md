# Excel

Embeds x-spreadsheet in Obsidian so XLSX files are stored and edited in the vault, sheets are created, and spreadsheets are imported or exported. Sheet ranges are embedded in Markdown and selected cells are copied as HTML. Its recorded About states that the plugin is no longer maintained and points to Obsidian-Sheet-Plus instead.
