# Open Plugin Settings

Open Plugin Settings creates a command that opens a specified plugin's settings from the command palette. The command list is managed by adding plugins, refreshing deleted entries and disabling commands for disabled plugins, and unregistered plugins are opened through a search.

```cue
plugin: {
    id:     "open-plugin-settings"
    name:   "Open Plugin Settings"
    author: "Mara"
    repo:   "mara-li/obsidian-open-settings"

    html_url:    "https://community.obsidian.md/plugins/open-plugin-settings"
    github_url:  "https://github.com/mara-li/obsidian-open-settings"
```
