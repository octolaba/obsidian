# Spell Picker

Spells from the basic D&D 5e set are filtered and browsed by name, level or class in order to assemble a character's spell list. Searching works through tags or through separate inputs, and the matching options are listed in one place instead of across separate tabs.

```cue
plugin: {
    id:     "spell-picker"
    name:   "Spell Picker"
    author: "Szynszyl320"
    repo:   "szynszyl320/spell-picker-obsidian"

    html_url:    "https://community.obsidian.md/plugins/spell-picker"
    github_url:  "https://github.com/szynszyl320/spell-picker-obsidian"
    description: "Allows the user to pick out from all the basic dnd spells - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Filter and browse D&D 5e spells by name, level, or class to assemble character spell lists quickly. Use tag-based or separate input searches to narrow results and view all options in one place without jumping between tabs."

    stats: {
        downloads:  101
        updated_at: 1783844025000
    }
}
```
