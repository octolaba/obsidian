# Canvas Keyboard Pan

Canvas Keyboard Pan moves around the canvas with the keyboard instead of the pointer. The keybindings default to WASD and are configurable, and the maximum pan speed can be adjusted.

```cue
plugin: {
    id:     "canvas-keyboard-pan"
    name:   "Canvas Keyboard Pan"
    author: "nathonius"
    repo:   "nathonius/obsidian-canvas-pan"

    html_url:    "https://community.obsidian.md/plugins/canvas-keyboard-pan"
    github_url:  "https://github.com/nathonius/obsidian-canvas-pan"
    description: "Pan around your canvas using the keyboard"
    about:       "Pan the Obsidian canvas using keyboard keys for quick, hands-on navigation. Configure keybindings (default WASD) and tweak the maximum pan speed to match your workflow."
```
