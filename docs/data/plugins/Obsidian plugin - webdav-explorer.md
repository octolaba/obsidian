# WebDAV Explorer

Connects to a WebDAV server and browses its files from inside Obsidian. Files dragged into a note produce Markdown links automatically, a double click opens an item in the app, and media can be previewed in place. Items are uploaded and downloaded from the same view, with duplicates resolved by overwriting or renaming.
