# Interlinear

Interlinear renders paragraph-by-paragraph translations in Reading view, either bilingual or translation-only, alongside the original text. Translations are injected into the render layer, so the file itself is never modified, and they run on demand with a local cache. Backends are bring-your-own-key LLMs and machine translation, and the view offers five visual styles, a toggle and hovering to reveal the original.
