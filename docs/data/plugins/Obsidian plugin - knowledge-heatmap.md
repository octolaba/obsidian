# Knowledge Heatmap

Shows a dashboard of the notes and folders that need review, scored on signals for recency, connections and substance. Each note can be inspected for its score, with a breakdown of the contributing factors, a plain-language explanation and suggested maintenance actions. All processing is local, with no network requests.
