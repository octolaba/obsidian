# Notes Merger

Traverses links from an index Markdown file to build a content tree, whose nested hierarchy can be previewed interactively. The files in that structure are then merged into a single Markdown document. Slideshow templates compatible with Advanced Slides can be created, and Markdown can be translated into XeLaTeX with images copied into a chosen folder.

```cue
plugin: {
    id:     "notes-merger"
    name:   "Notes Merger"
    author: "niffka"
    repo:   "niffka/notes-merger"

    html_url:    "https://community.obsidian.md/plugins/notes-merger"
    github_url:  "https://github.com/niffka/notes-merger"
    description: "Merge notes into a single Markdown document based on index Markdown file."
    about:       "Generate a content tree by traversing links and preview the nested hierarchy interactively. Merge multiple Markdown files into a single unified Markdown file following the generated structure. Create slideshow templates compatible with Advanced Slides and translate Markdown into XeLaTeX (.tex), copying images into a chosen folder."
```
