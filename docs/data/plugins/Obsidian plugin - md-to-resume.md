# MD2Resume

Turns a Markdown note into a print-ready resume with a live preview inside Obsidian. Header fields and sectioned entries are written with plain Markdown conventions, separating title from date with a pipe and title from subtitle with a colon, producing styled job and project entries with contact links generated automatically. The result is exported as PDF.

```cue
plugin: {
    id:     "md-to-resume"
    name:   "MD2Resume"
    author: "Bradin Rohde"
    repo:   "brohdexc/MD2Resume"

    html_url:    "https://community.obsidian.md/plugins/md-to-resume"
    github_url:  "https://github.com/brohdexc/MD2Resume"
    description: "Convert a Markdown resume to a print-ready, modularly ordered PDF. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert Markdown notes into a clean, print-ready resume with live preview in Obsidian. Define header fields and sectioned entries using simple Markdown conventions (title|date, title:subtitle) to produce styled job/project entries with automatic contact links, then export as PDF."

    stats: {
        downloads:  41
        updated_at: 1785006533000
    }
}
```
