# InsightA

InsightA extracts a set of atomic, interlinked notes from a long article using an LLM, adding links back to the source note and relevant tags. It also generates Maps of Content keyed by note title, grouping the related notes for navigation.

```cue
plugin: {
    id:     "insighta"
    name:   "InsightA"
    author: "hongjiantang"
    repo:   "hongjiantang/obsidian-insighta"

    html_url:    "https://community.obsidian.md/plugins/insighta"
    github_url:  "https://github.com/hongjiantang/obsidian-insighta"
```
