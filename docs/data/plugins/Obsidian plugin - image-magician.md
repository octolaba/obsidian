# Image Magician

Previews and embeds more than 100 image formats inside Obsidian without external applications, including PSD through a dedicated engine. Markdown and HTML image links are resolved with path detection, and images can be exported or auto-exported to PNG, JPG or WebP with optional resizing. The recorded description names ImageMagick as the underlying technology.
