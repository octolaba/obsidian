# Helix Keybindings

Helix Keybindings adds Helix-style modal keybindings to Obsidian's editor through the Helix CodeMirror 6 extension. The bindings are switched on and off with a plugin command. The recorded inputs describe early-stage behaviour, since the underlying extension is still in development.

```cue
plugin: {
    id:     "helix"
    name:   "Helix Keybindings"
    author: "obsidian-helix"
    repo:   "obsidian-helix/obsidian-helix"

    html_url:    "https://community.obsidian.md/plugins/helix"
    github_url:  "https://github.com/obsidian-helix/obsidian-helix"
    description: "Use Helix key bindings when editing. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add Helix-style modal keybindings to Obsidian's editor using the Helix CodeMirror6 extension. Toggle the bindings via the plugin command and anticipate early-stage behavior while the underlying extension remains in development."

    stats: {
        downloads:  20389

    }
}
```
