# Search and Replace Regex

Search and Replace Regex searches notes with plain text or full regular expressions, with case-sensitive and whole-word matching as toggles. A single match or all occurrences can be replaced using regex capture groups, matches can be navigated with a match count shown, and recent search and replace history and default preferences are kept.

```cue
plugin: {
    id:     "search-and-replace-regex"
    name:   "Search and Replace Regex"
    author: "Justice Vellacott"
    repo:   "thejusticeman/obsidian-find-replace-regex"

    html_url:    "https://community.obsidian.md/plugins/search-and-replace-regex"
    github_url:  "https://github.com/thejusticeman/obsidian-find-replace-regex"
    description: "A powerful regex-based search and replace tool for the app with search highlighting and navigation. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Search notes using plain text or full regular expressions and toggle case-sensitive or whole-word matching. Replace single matches or all occurrences with regex capture groups, navigate between matches, view match counts, access recent search/replace history, and save default preferences."
```
