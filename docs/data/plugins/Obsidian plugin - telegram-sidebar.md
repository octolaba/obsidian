# Telegram Sidebar

Embeds Telegram Web in an Obsidian sidebar panel for chatting with bots, contacts, groups and channels without leaving the vault. The session persists between launches, a default chat can be opened automatically, the Web version and the panel side are configurable, and the panel is controlled from the command palette.

```cue
plugin: {
    id:     "telegram-sidebar"
    name:   "Telegram Sidebar"
    author: "reallygood83"
    repo:   "reallygood83/teledian"

    html_url:    "https://community.obsidian.md/plugins/telegram-sidebar"
    github_url:  "https://github.com/reallygood83/teledian"
    description: "Embed Telegram Web in Obsidian sidebar. Chat with bots and contacts without leaving your vault. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed Telegram Web in your Obsidian sidebar to chat with bots, contacts, groups, and channels without leaving your vault. Keep sessions persistent, auto-open a default chat, choose Web version and panel side, and control the sidebar via the Command Palette."
```
