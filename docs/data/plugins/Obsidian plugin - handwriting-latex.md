# Handwriting and Image to LaTeX

Converts hand-drawn or imported formula images into LaTeX through OCR. Drawing happens on an infinite touch-friendly canvas with zoom, pan and rotation, images can be cropped precisely, and the result is inserted as inline, display or raw LaTeX. Several backends are selectable, among them the free SimpleTex, Mathpix, GPT-4o Vision and custom APIs.
