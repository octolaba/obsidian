# Typecho Publisher

Publishes notes to a Typecho blog over XML-RPC, creating or updating a post in one action. Images go to Cloudflare R2 or the Typecho media library with an upload cache, frontmatter fields are mapped with strict type validation, wiki-links are converted to post URLs, and sections can be stripped by heading before publishing.
