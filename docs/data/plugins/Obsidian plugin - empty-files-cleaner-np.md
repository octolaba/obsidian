# Empty Files Cleaner NP

Scans the vault for Markdown files that contain nothing or only whitespace and lists them with checkboxes. Files are picked individually or through select-all and deselect-all, then deleted permanently after a confirmation, and the list refreshes itself once the deletions are done.

```cue
plugin: {
    id:     "empty-files-cleaner-np"
    name:   "Empty Files Cleaner NP"
    author: "leruetkins"
    repo:   "leruetkins/obsidian-empty-files-cleaner-np"

    html_url:    "https://community.obsidian.md/plugins/empty-files-cleaner-np"
    github_url:  "https://github.com/leruetkins/obsidian-empty-files-cleaner-np"
    description: "Find and delete empty markdown files in your vault. Shows a list with checkboxes to select and bulk-delete. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Scan your vault for empty Markdown files and list notes that contain no content or only whitespace. Select files via a checkbox list, use Select all/Deselect all, and delete chosen files permanently with a confirmation prompt; the list auto-refreshes after deletions."

    stats: {
        downloads:  113
        updated_at: 1779652112000
    }
}
```
