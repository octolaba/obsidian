# Voice Input

Voice Input records speech and transcribes it with OpenAI GPT-4o audio transcriptions, tuned for Japanese, English, Chinese and Korean. Recording starts with one click or push-to-talk, the GPT-4o model is selectable, and the interface language and the recognition language are set separately. Transcriptions can be cleaned up by AI and then inserted or appended, with auto-save and quick controls.

    id:     "voice-input"
