# Frontmatter Alias Display

Shows frontmatter aliases as note names in the File Explorer, so readable titles appear instead of identifiers. The original file identifiers stay intact, which the recorded text presents as navigation help for Zettelkasten-style vaults.

```cue
plugin: {
    id:     "frontmatter-alias-display"
    name:   "Frontmatter Alias Display"
    author: "notmuhammad"
    repo:   "notmuhammad/obsidian-frontmatter-alias-display"

    html_url:    "https://community.obsidian.md/plugins/frontmatter-alias-display"
    github_url:  "https://github.com/notmuhammad/obsidian-frontmatter-alias-display"
    description: "Show frontmatter aliases as display names in the File Explorer."
    about:       "Display frontmatter aliases as File Explorer names to show readable titles instead of IDs. Keep original file IDs intact while showing informative aliases for easier navigation in Zettelkasten-style vaults."

    stats: {
        downloads:  5635
        updated_at: 1683728831000
    }
}
```
