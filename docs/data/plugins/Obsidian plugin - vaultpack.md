# VaultPack

VaultPack exports selected notes and Bases views into a self-contained offline website. The result can be shared as a folder, an encrypted ZIP or a password-protected web package. The initial public release also ships documentation localized in English, Traditional Chinese and Japanese, together with sample screenshots.
