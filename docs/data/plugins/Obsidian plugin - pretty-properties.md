# Pretty Properties

Makes the note properties block more visual by adding a side image, banners, icons, and colors for list property values. Covers, banners, and icons can come from local files, external links, or icon names, with configurable shapes and sizes, and specific properties can be hidden to keep notes tidy.

```cue
plugin: {
    id:     "pretty-properties"
    name:   "Pretty Properties"
    author: "Reaty"
    repo:   "anareaty/pretty-properties"

    html_url:    "https://community.obsidian.md/plugins/pretty-properties"
    github_url:  "https://github.com/anareaty/pretty-properties"
    description: "Makes note properties look more fun: adds side image, banners, list property colors and allows to hide specific properties."
    about:       "Make metadata blocks more visually appealing with cover images, banners, icons, and color accents. Add covers, banners, or icons from local files, external links, or icon names, customize shapes and sizes, and hide properties to keep notes tidy."
```
