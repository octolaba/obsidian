# Tree Modal

Opens files from the file explorer in a large modal preview instead of the editor, keeping Obsidian's native view header and its read and edit toggle. Internal links can be followed inside the same modal, while Cmd or Ctrl-click and the file menu still open a file in the editor.

```cue
plugin: {
    id:     "tree-modal"
    name:   "Tree Modal"
    author: "krannich"
    repo:   "krannich/obsidian-tree-modal"

    html_url:    "https://community.obsidian.md/plugins/tree-modal"
    github_url:  "https://github.com/krannich/obsidian-tree-modal"
    description: "Open files from the file explorer in a modal preview instead of in the editor. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open files from the file explorer in a large modal preview that preserves Obsidian's native view header and read/edit toggle. Navigate internal links inside the same modal and fall back to Cmd/Ctrl-click or the file-menu/right-click to open files in the editor."

    stats: {
        downloads:  145
        updated_at: 1777288675000
    }
}
```
