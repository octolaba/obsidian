# WeChat Obsync

Synchronises WeChat Official Account articles and Mini Program memos into the vault as formatted Markdown, dropping duplicates automatically. The sync status and the time of the last sync are shown in the status bar, and the interface uses a dark glassmorphism style that mirrors the Mini Program.

```cue
plugin: {
    id:     "wechat-obsync"
    name:   "WeChat Obsync"
    author: "Obsync"
    repo:   "less1001/obsync"

    html_url:    "https://community.obsidian.md/plugins/wechat-obsync"
    github_url:  "https://github.com/less1001/obsync"
    description: "Sync WeChat Official Account articles from a Mini Program into Obsidian. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync WeChat Official Account articles and Mini Program memos directly into your Obsidian vault as formatted Markdown with automatic de-duplication. Show real-time sync status and last-sync time in the status bar and present a dark glassmorphism UI that mirrors the Mini Program."

    stats: {
        downloads:  3522
        updated_at: 1784011136000
    }
}
```
