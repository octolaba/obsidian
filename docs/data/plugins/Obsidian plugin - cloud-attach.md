# CloudAttach

Browses WebDAV servers compatible with OpenList and S3 object storage from a sidebar file panel and inserts cloud files into notes as signed links. Local attachments can be uploaded to the server to free local space, images, video, audio and documents preview inline, and several accounts can be switched between.

```cue
plugin: {
    id:     "cloud-attach"
    name:   "CloudAttach"
    author: "Garry"
    repo:   "curryhendry/obsidian-cloud-attach"

    html_url:    "https://community.obsidian.md/plugins/cloud-attach"
    github_url:  "https://github.com/curryhendry/obsidian-cloud-attach"
    description: "Connect to OpenList and manage cloud attachments, insert signed file links into notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Browse and insert cloud files from WebDAV (OpenList-compatible) and S3 object storage directly into notes via a sidebar file panel. Upload local attachments to the server, generate signed URLs, preview images/video/audio/documents inline, and switch between multiple accounts to free local space."

    stats: {
        downloads:  363

    }
}
```
