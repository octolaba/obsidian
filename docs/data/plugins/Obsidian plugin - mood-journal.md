# Mood Journal

Mood Journal logs a five-level mood, optional activities and a Markdown note into the daily note. Entries are saved locally with timestamps and nested journal tags, in English or Japanese form, and support up to two activity levels. It writes plain Markdown without editing frontmatter and runs on desktop and mobile.

```cue
plugin: {
    id:     "mood-journal"
    name:   "Mood Journal"
    author: "nyonyataro"
    repo:   "nyonyataro/obsidian-mood-journal"

    html_url:    "https://community.obsidian.md/plugins/mood-journal"
    github_url:  "https://github.com/nyonyataro/obsidian-mood-journal"
    description: "Quickly log mood, activities, and notes to daily notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Record a five-level mood, optional activities, and a Markdown note in your daily note. Save entries locally with timestamps and nested journal tags (#journal or #日記) and up to two activity levels. Keep plain Markdown (no frontmatter edits) and run on desktop and mobile with English/Japanese sections."
```
