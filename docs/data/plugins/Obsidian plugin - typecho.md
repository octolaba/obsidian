# Typecho

Syncs Markdown files with a Typecho blog over its RESTful API, publishing posts and creating categories and tags. Remote posts are browsed and managed from inside Obsidian, with local copies saved for offline editing. Users are retrieved automatically and the controls sit in a publishing panel.
