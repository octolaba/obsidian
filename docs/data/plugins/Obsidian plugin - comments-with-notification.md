# Comments with Notification

Comments with Notification is a comment and notification system for shared vaults, where comments are addressed with a member tag to notify a teammate and callout templates are inserted by a single command. Unread comments are surfaced by a ribbon bell badge and a sidebar panel with previews and click-to-navigate links. Comments are stored as callouts with invisible timestamps, and read status is tracked per machine across a synced vault.

```cue
plugin: {
    id:     "comments-with-notification"
    name:   "Comments with Notification"
    author: "mkali"
    repo:   "mkali-personal/obsidian-comments-with-notifications"

    html_url:    "https://community.obsidian.md/plugins/comments-with-notification"
    github_url:  "https://github.com/mkali-personal/obsidian-comments-with-notifications"
    description: "Comment and notification system for shared Obsidian vaults. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Leave structured, tag-addressed comments using #member/username to notify teammates and insert callout templates with a single command. Monitor unread comments via a ribbon bell badge and a sidebar panel with previews and click-to-navigate links. Store comments as callouts with invisible timestamps and track read status per machine across synced vaults."
```
