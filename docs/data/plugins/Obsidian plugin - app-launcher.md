# App Launcher

Adds a rocket icon to the ribbon that launches a specified application or URL scheme with a single click. It is aimed at running sync tools before or after editing, or opening companion apps such as Zotero or Notion without leaving the vault.

```cue
plugin: {
    id:     "app-launcher"
    name:   "App Launcher"
    author: "bob"
    repo:   "iibob/obsidian-app-launcher"

    html_url:    "https://community.obsidian.md/plugins/app-launcher"
    github_url:  "https://github.com/iibob/obsidian-app-launcher"
    description: "Launch sync tools, system apps, or mobile shortcuts directly from the ribbon to streamline your workflow. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add a Rocket icon to the ribbon and launch any specified application or URL scheme with a single click. Launch sync tools before or after editing, or open companion apps like Zotero or Notion to keep notes up to date and move between tools quickly."

    stats: {
        downloads:  493
        updated_at: 1779421751000
    }
}
```
