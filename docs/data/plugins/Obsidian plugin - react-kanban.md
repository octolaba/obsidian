# React Kanban

A Kanban board UI that works on existing Markdown kanban notes and keeps their board format in place. Cards can be dragged, columns reordered, notes edited and rendered as Markdown, and completed work tracked. The index records that this plugin has not been manually reviewed by Obsidian staff.
