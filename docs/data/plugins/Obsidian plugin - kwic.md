# Keyword in Context

A collocation explorer grounded in corpus linguistics that extracts habitual lexical patterns from the vault using sliding-window co-occurrence, PMI and log-likelihood. Frequent collocates are shown as a rotating 3D word sphere that can be dragged to rotate, with hover revealing co-occurrences within a token window. Clicking a collocate opens a keyword-in-context concordance with the partner highlighted and a jump to the source, and analysis can be filtered by note modification time.
