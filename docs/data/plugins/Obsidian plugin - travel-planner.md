# Travel Planner

Travel Planner organizes trips as a trip note with Itinerary, Packing List, Accommodation and Budget sub-notes. A trip is created through a modal, itinerary days are added to it, and the packing list starts pre-filled and categorized. A sidebar lists trips sorted into current, upcoming and past.
