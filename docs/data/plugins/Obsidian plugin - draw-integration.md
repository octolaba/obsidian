# Draw Integration

Opens a drawing project from an ordinary Obsidian image link and hands it to an external drawing application such as Krita, MyPaint or GIMP. The edited result is exported back as a PNG saved directly into the vault.

```cue
plugin: {
    id:     "draw-integration"
    name:   "Draw Integration"
    author: "absolute"
    repo:   "evolutiontrash/draw_integration"

    html_url:    "https://community.obsidian.md/plugins/draw-integration"
    github_url:  "https://github.com/evolutiontrash/draw_integration"
    description: "Integrate a draw application into your obsidian workflow, Krita, MyPaint, GIMP, etc., everything at the speed of thought. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create and open drawing projects from standard Obsidian image links like ![[path/to/image.png]]. Edit in your external drawing app and export the result as a PNG saved directly into your vault."

    stats: {
        downloads:  174
        updated_at: 1781147480000
    }
}
```
