# RPG Homebrew Importer

RPG Homebrew Importer brings creations from RPG Homebrew into Obsidian as searchable Markdown notes rendered as compact, game-ready cards. The original JSON stays inside each note so a card can be rerendered, and cards use theme-safe CSS grids. Dice notation on a card is clickable and rolls with detailed totals and history, and both direct website exports and JSON files are accepted.
