# Reader Highlighter Tags

Highlights, tags, annotates, and organizes text directly in Reading View, without switching to Edit mode. Highlights are mapped precisely back to the underlying Markdown, including across transclusions, and literal characters in technical text are preserved. Highlights from across the vault can be aggregated with frontmatter filtering.
