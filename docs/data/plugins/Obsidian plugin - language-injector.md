# Language Injector

Language Injector adds language markers to code blocks by reading a property set on the block. Applying consistent language tags keeps syntax highlighting and tooling behaviour correct across notes.

```cue

    id:     "language-injector"
    name:   "Language Injector"
    author: "sunmagicshow"
    repo:   "sunmagicshow/obsidian-language-injector"

    html_url:    "https://community.obsidian.md/plugins/language-injector"
```
