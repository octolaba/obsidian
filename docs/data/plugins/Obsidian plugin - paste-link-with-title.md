# Paste link with title

Converts pasted URLs into reference-style Markdown links by fetching the page title. A command converts selected URLs manually, and a configurable placeholder replaces titles that cannot be fetched.

```cue
plugin: {
    id:     "paste-link-with-title"
    name:   "Paste link with title"
    author: "haradaiko100"
    repo:   "haradaiko100/obsidian-auto-link-converter"

    html_url:    "https://community.obsidian.md/plugins/paste-link-with-title"
    github_url:  "https://github.com/haradaiko100/obsidian-auto-link-converter"
    description: "Automatically converts pasted URLs to reference-style markdown links with page titles. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert pasted URLs into reference-style Markdown links by fetching page titles. Run a command to convert selected URLs manually and replace unfetchable titles with a configurable placeholder."

    stats: {
        downloads:  558
        updated_at: 1770570030000
    }
}
```
