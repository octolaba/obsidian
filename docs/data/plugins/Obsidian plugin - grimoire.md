# Grimoire

Runs local CLI coding agents from one vault-native side panel, among them Claude Code, Codex, Grok Build, Mimo Code, Kimi Code, AntiGravity, Qwen Code, Gemini CLI and OpenCode, with a single picker for switching models. Agents can read notes, edit files, run commands, call tools and continue sessions from vault history, and inline editing sits alongside chat. Because it drives local CLIs it is desktop-only, and it ships no hosted backend, telemetry, ads or proxy; data leaves the machine only through whichever provider or tool is chosen.
