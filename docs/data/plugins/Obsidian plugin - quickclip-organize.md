# Quick Organize

Triages captured notes in a Portent-based dashboard that classifies, links and tracks each entry from a raw clip through to organized knowledge. Any note is surfaced by adding a type field to its frontmatter, views group by type, domain or status, and metadata is edited inline with instant saves. The recorded description says it works with any note and is extended by the QuickClip extension.
