# Auto Headings

Auto Headings numbers headings automatically and keeps the numbering correct as notes are edited, renamed or reorganized. Heading renames are synced across the vault in the same edit, so links pointing at a note heading do not break. Numbering templates apply per folder or per file, and individual headings can be whitelisted out of numbering.

```cue
plugin: {
    id:     "auto-headings"
    name:   "Auto Headings"
    author: "AArlert"
    repo:   "aarlert/obsidian-auto-headings"

    html_url:    "https://community.obsidian.md/plugins/auto-headings"
    github_url:  "https://github.com/aarlert/obsidian-auto-headings"
    description: "Automatic heading numbering with fully customizable templates, per-folder rules, whitelist and backlink sync. Bilingual UI (English / 中文). - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Number headings automatically and keep numbering correct as you edit, rename, or reorganize notes. Sync heading renames across your vault so [[note#heading]] links update in the same edit and avoid broken anchors. Apply per-folder or per-file numbering templates and whitelist headings to exclude from numbering."
```
