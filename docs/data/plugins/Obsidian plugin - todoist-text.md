# Todoist Text

Todoist Text inserts Todoist tasks into a note as Markdown checkboxes, replacing configurable keywords with a filtered task list either manually or automatically. Toggling such a checkbox completes the task in Todoist and updates the file, and several keywords can be mapped to different filters for templates or particular projects.
