# Rollover

Rollover closes the most recent pending date-stamped note and creates the next one in the same folder, renaming the old file to mark it done and updating internal links. Content can be carried over or a template applied, today's date can be chosen or advanced past an existing same-day note, and naming conventions are customizable.

```cue
plugin: {
    id:     "rollover"
    name:   "Rollover"
    author: "Stefan Imbesi"
    repo:   "stefan-imbesi/obsidian-rollover"

    html_url:    "https://community.obsidian.md/plugins/rollover"
    github_url:  "https://github.com/stefan-imbesi/obsidian-rollover"
    description: "Close the previous dated note and open the next one, in one command — date-stamped, with optional templating. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Close the most recent pending date-stamped note and create the next date-stamped note in the same folder, renaming the old file to mark it done and updating internal links. Carry over content or apply a template, choose today's date (or advance past an existing same-day note), and support customizable naming conventions."

    }
```
