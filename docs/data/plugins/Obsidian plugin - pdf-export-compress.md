# Export PDF Compress

Exports Markdown notes to PDF with automatic image compression, where JPEG quality and maximum width are adjustable to produce smaller files. Rendering runs through a Python engine using reportlab and Pillow, resolving Obsidian wiki-links and standard Markdown images, and CJK text is rendered with macOS system fonts. The recorded description states that it is macOS only.
