# EmoTagsTitler

EmoTagsTitler copies the emoji contained in a note's tags to the beginning of its title. Emoji can also be removed again from the titles of notes that carry emoji tags, and commands run either operation as a batch across the vault.

```cue
plugin: {
    id:     "emoji-tags-titler"
    name:   "EmoTagsTitler"
    author: "cyfine"
    repo:   "cyfine/EmoTagsTitler"

    html_url:    "https://community.obsidian.md/plugins/emoji-tags-titler"
    github_url:  "https://github.com/cyfine/EmoTagsTitler"
    description: "Add the emojis contained in the tags to the beginning of the note title."
    about:       "Add emoji from emoji tags to note titles. Remove emoji from titles for notes with emoji tags and run batch add/remove across the vault using commands."

    stats: {
        downloads:  4282
        updated_at: 1689604931000
    }
}
```
