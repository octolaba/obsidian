# Daily Day Nav

Opens the previous or the next calendar daily note, creating it from the Daily notes template when it does not exist yet. Jumps move by calendar day across empty days, so the journal is traversed without creating notes by hand.

```cue
plugin: {
    id:     "daily-day-nav"
    name:   "Daily Day Nav"
    author: "antoineart"
    repo:   "antoineart/obsidian-daily-day-nav"

    html_url:    "https://community.obsidian.md/plugins/daily-day-nav"
    github_url:  "https://github.com/antoineart/obsidian-daily-day-nav"
    description: "Open the previous or next calendar daily note, creating it from your template if it does not exist yet. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Navigate to the previous or next calendar daily note and auto-create it from your Daily notes template if missing. Jump by calendar day across empty days to move through your journal without manual note creation."

    stats: {
        downloads:  116
        updated_at: 1780554908000
    }
}
```
