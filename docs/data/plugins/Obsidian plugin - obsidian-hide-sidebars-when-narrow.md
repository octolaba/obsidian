# Hide Sidebars on Window Resize

Hides the sidebars automatically when the window becomes narrow on resize, and restores them when it widens again. Minimum widths for the left and right sidebar decide when each one collapses.

```cue
plugin: {
    id:     "obsidian-hide-sidebars-when-narrow"
    name:   "Hide Sidebars on Window Resize"
    author: "nomarcub"
    repo:   "nomarcub/obsidian-hide-sidebars-on-window-resize"

    html_url:    "https://community.obsidian.md/plugins/obsidian-hide-sidebars-when-narrow"
```
