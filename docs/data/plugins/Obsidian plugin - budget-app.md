# Budget Vault

Budget Vault keeps a personal budget inside the vault as plain Markdown files, one file per account per month, covering transactions, category budgets, savings, accounts, money owed, services, tax and CSV import. A dashboard and a transaction browser read and write those files, and the recorded inputs state that it makes no network requests and leaves syncing to the user's own cloud.
