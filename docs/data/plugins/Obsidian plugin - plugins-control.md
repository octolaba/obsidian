# Control Center

Manages installed plugins from a sortable table, toggling enabled state, setting a delayed startup per plugin and applying device-specific disable rules for phone, tablet and desktop. Markdown notes with internal links can be attached to plugins, and the table can be jumped by initial letter or searched by name or note. All plugin states, rules, delays and notes can be backed up and restored, and the interface is available in English and Chinese.
