# Python Viewer

Opens .py files in a dedicated read-only view with line numbers and lightweight Python highlighting. A compact outline lists imports, decorators, classes, functions, methods and top-level constants, which are filtered and jumped to, alongside parse diagnostics. Up to 10k lines are rendered, and files are never written or run.
