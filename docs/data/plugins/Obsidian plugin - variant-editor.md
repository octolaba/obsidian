# Variant Editor

Creates alternative phrasings for words, phrases or whole sentences and keeps every option inline in the Markdown. Variants are compared in context with a single click, switched or reordered, and the chosen version committed when the text is settled. The recorded About names a compact brace-delimited syntax carrying the alternatives together with an index marker.

```cue
plugin: {
    id:     "variant-editor"
    name:   "Variant Editor"
    author: "kunalja"
    repo:   "kunalja/VariantEditor"

    html_url:    "https://community.obsidian.md/plugins/variant-editor"
    github_url:  "https://github.com/kunalja/VariantEditor"
    description: "Create variations of words and sentences and compare them, in context, with a single click"
    about:       "Create multiple phrasing variants for words, phrases, or entire sentences and keep all options inline in your Markdown. View and compare alternatives in context, switch or reorder variants, and commit the chosen version when ready using a compact {{variant1|variant2|variant3}}^INDEX syntax."

    stats: {
        downloads:  1274
        updated_at: 1756441854000
    }
}
```
