# CardBoard

CardBoard displays Markdown tasks from any file on kanban-style boards with date-based and tag-based columns. Tasks appear as cards showing subtasks, indented notes, tags and due dates, and column types can be mixed on a single board.

    id:     "card-board"
    name:   "CardBoard"
