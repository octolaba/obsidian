# Simple Quiz

Simple Quiz creates spaced-repetition flashcards inside notes, through inline quiz blocks or menu commands. Cards are loaded manually, from JSON or through a JavaScript API, and organized into pools and tags. It tracks streaks, daily quiz counts and repeated cards, and charts monthly and yearly progress on desktop and mobile.
