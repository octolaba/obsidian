# AI Rewrite

Rewrites the current line or a selection with a local Ollama model and shows the suggestion as a ghost line below it, applied with Tab and dismissed with Esc. Markdown prefixes are preserved, Proofread and Translate modes ship alongside custom ones, and rewriting can trigger on demand, on line leave, or while typing.

```cue
plugin: {
    id:     "ai-rewrite"
    name:   "AI Rewrite"
    author: "masaki39"
    repo:   "masaki39/obsidian-ai-rewrite"

    html_url:    "https://community.obsidian.md/plugins/ai-rewrite"
    github_url:  "https://github.com/masaki39/obsidian-ai-rewrite"
    description: "Local-first, line-level AI rewriting: proofread, translate, or your own custom modes. Shows a ghost preview below the line; Tab to apply. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Rewrite the current line or a selection with local AI (Ollama) and preview the suggestion as a ghost line below; press Tab to apply or Esc to dismiss. Preserve Markdown prefixes, offer Proofread and Translate modes, and trigger on demand, on line leave, or while typing."

    stats: {
        downloads:  137

    }
}
```
