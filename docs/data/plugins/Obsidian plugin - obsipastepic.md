# Pastepic

Images that are pasted, dragged or newly inserted locally are uploaded to GitHub or another image host and replaced in place with customizable CDN or proxy Markdown links. Asynchronous placeholders are shown while an upload runs, local links are restored on failure, and multiple images are replaced individually. The index records that this plugin has not been manually reviewed by Obsidian staff.

```cue
plugin: {
    id:     "obsipastepic"
    name:   "Pastepic"
    author: "zengyincen"
    repo:   "zengyincen/Obsidian-PastePic"

    html_url:    "https://community.obsidian.md/plugins/obsipastepic"
    github_url:  "https://github.com/zengyincen/Obsidian-PastePic"
    description: "Paste images, upload to GitHub or your image host, and insert customizable CDN links. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Upload pasted, dragged, or newly inserted local images to GitHub or any image host and replace them in-place with customizable CDN/proxy Markdown links. Show asynchronous placeholders during upload, restore local links on failure, and handle multiple images with automatic, per-image replacements."

    stats: {
        downloads:  70
        updated_at: 1785055828000
    }
}
```
