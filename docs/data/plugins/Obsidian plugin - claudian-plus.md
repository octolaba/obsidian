# Claudian Plus

This is a Codex-first fork of Claudian that unifies Codex, Claude, OpenCode and Pi in one workspace while keeping note context, provider sessions and memory local. A floating conversation outline extracts questions and assistant headings, notes or folders are dragged in to insert path and folder references, and vault searches feed source-backed insights.
