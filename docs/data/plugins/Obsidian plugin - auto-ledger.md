# Auto Ledger

Auto Ledger summarizes local Markdown transaction logs into an offline finance dashboard. One Markdown line is appended per transaction, and the dashboard reports monthly income and expenses, recent records, category rankings, member distribution and low-confidence items. Its recorded About states that all data stays local, with no network access and no telemetry.
