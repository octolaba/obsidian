# HWPX writer

HWPX writer converts notes to HWPX documents for Hancom Office Hangul, mapping headings, paragraphs, lists, GFM tables, blockquotes, code blocks, inline styles, task lists and LaTeX math. A sidebar previews the conversion live, and HWPX templates and style presets are applied or imported to carry over fonts, heading styles and table borders. Obsidian links, embeds, callouts and highlights are preserved.
