# Embed Plus

Extends embedding of external web pages, for example Bluesky posts and GitHub Gists, using the same Markdown syntax as an external image. Live-preview mode is supported as well.

```cue
plugin: {
    id:     "embed-plus"
    name:   "Embed Plus"
    author: "Hibiki"
    repo:   "4513echo/obsidian-embed-plus"

    html_url:    "https://community.obsidian.md/plugins/embed-plus"
    github_url:  "https://github.com/4513echo/obsidian-embed-plus"
    description: "Embed more external web pages, with external-image syntax and live-preview support. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed more external websites, for example posts of Bluesky, GitHub Gist, and more in the future. You can simply use the same Markdown syntax as external images. Live-preview mode is supported as well."

    stats: {
        downloads:  428
        updated_at: 1784369881000
    }
}
```
