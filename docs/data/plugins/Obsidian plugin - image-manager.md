# Image Manager

Inserts, renames and sorts images in notes and properties from local files, the clipboard, drag-and-drop, or remote search against Unsplash, Pexels and Pixabay. Naming follows templates with deduplication, a description can be prompted for, and remote images can be converted to local ones on open or save. MDX and several link formats are supported.
