# asciimath

asciimath adds AsciiMath support to Obsidian, rendering inline and display equations from dollar-sign blocks or asciimath code fences. Symbols can be inserted, AsciiMath converted to LaTeX, and existing LaTeX notes migrated or mixed with it for compatibility.

plugin: {
    id:     "obsidian-asciimath"
    name:   "asciimath"
    author: "widcardw"
