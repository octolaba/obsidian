# Reading Time Status

Shows an estimated reading time for the active note in the status bar, updating as notes are switched or typed in. CJK characters are counted as words so mixed-language estimates stay accurate, the words-per-minute rate is adjustable, and the word count can optionally be shown as well.

```cue
plugin: {
    id:     "reading-time-status"
    name:   "Reading Time Status"
    author: "loispsq"
    repo:   "loispsq/reading-time-status"

    html_url:    "https://community.obsidian.md/plugins/reading-time-status"
    github_url:  "https://github.com/loispsq/reading-time-status"
    description: "Show word count and estimated reading time for the current note in the status bar (CJK-aware). - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display an estimated reading time for the active note in the status bar, updating live as you switch notes or type. Count CJK characters as words for accurate mixed-language estimates, allow adjusting words‑per‑minute, and optionally show the word count."

    stats: {
        downloads:  23
        updated_at: 1783752733000
    }
}
```
