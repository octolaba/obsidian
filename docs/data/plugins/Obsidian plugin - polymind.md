# PolyMind

Integrates Groq AI models into Obsidian for chat over text, vision, coder, and audio models. Model lists are managed dynamically with model information shown, chat history is stored and reloaded from memory, localStorage, IndexedDB, or files, and AI messages can be turned into Markdown notes with code highlighting. The interface is localized in English and Russian with mobile-ready panels, and the recorded description says OpenAI and Claude support is planned.
