# Taskline

Captures tasks and shows a Today view built from tasks read out of selected notes, writing updates back to the Markdown. Capture accepts natural language for dates, priorities, recurrence, tags and owners, and Today, Upcoming and All lists are available. Tasks are edited inline on desktop or mobile, and proposal rows can optionally be reviewed before changes are applied.
