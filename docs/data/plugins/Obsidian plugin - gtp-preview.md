# GTP Preview

Renders Guitar Pro files with the gtp, gp, gp5 and gpx extensions directly in Obsidian, showing tablature and standard notation. Individual tracks can be selected or several rendered together, and the file's MIDI export can be downloaded.

```cue
plugin: {
    id:     "gtp-preview"
    name:   "GTP Preview"
    author: "barba828"
    repo:   "barba828/obsidian-plugin-gtp-preview"

    html_url:    "https://community.obsidian.md/plugins/gtp-preview"
    github_url:  "https://github.com/barba828/obsidian-plugin-gtp-preview"
    description: "Supports rendering of GuitarPro files such as `gtp/gp/gp5/gpx`."
    about:       "Preview Guitar Pro files (gtp/gp/gp5/gpx) directly in Obsidian with rendered tablature and standard notation. Switch between tracks, render multiple tracks, and download the file's MIDI export."

    stats: {
        downloads:  753

    }
}
```
