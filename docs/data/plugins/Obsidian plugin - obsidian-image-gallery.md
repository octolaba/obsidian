# Image Gallery

Builds a masonry image gallery from any folder in the vault with no setup, in a horizontal or vertical layout. Images open in a built-in lightbox, with the originals opening in a new tab. Spacing, border radius, sorting and the column or row layout are configurable for responsive galleries.
