# Knowledge Graph Analysis

Turns the vault into a knowledge graph and computes graph-theory metrics using Rust compiled to WASM, in order to give an AI structured, quantitative context. A force-directed network is drawn with nodes sized and colored by centrality, alongside semantic, structure and evolution analyses. It can suggest links, surface priority review cards and produce per-note AI summaries.
