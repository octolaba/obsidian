# Pseudocode

Renders LaTeX-style pseudocode written inside a code block into publication-quality HTML that mirrors LaTeX algorithm output and supports inline math. Macros are customized through a preamble, auto-completion is available inside the block, compilable LaTeX files can be exported, and light and dark themes are respected.
