# SQLite DB Viewer

SQLite files in the vault are queried, edited and visualized through a WASM SQLite engine that runs fully offline. Results render with working Obsidian links and Markdown, tables are created through a visual interface, and a Markdown table is converted into a relational SQLite table.

```cue
plugin: {
    id:     "sqlite-db-viewer"
    name:   "SQLite DB Viewer"
    author: "Alexander Bakanovskii"
    repo:   "bakanovskii/obsidian-sqlite-db-viewer"

    html_url:    "https://community.obsidian.md/plugins/sqlite-db-viewer"
    github_url:  "https://github.com/bakanovskii/obsidian-sqlite-db-viewer"
    description: "View and query SQLite files directly in Obsidian. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Manage SQLite .db/.sqlite files directly in your vault using a WASM SQLite engine that runs fully offline. Query, edit, and visualize tables with rendered Obsidian links and Markdown, create tables with a visual UI, and convert Markdown tables into relational SQLite tables."

    stats: {
        downloads:  522

}
```
