# Canvas Read-Only Copy

Restores text copying from Markdown and text cards while a Canvas is in read-only mode. The Markdown source is placed on the plain-text clipboard and the rendered content on the HTML clipboard. Copy behavior outside the read-only Canvas, and inside editable controls, is left as it is.

```cue
plugin: {
    id:     "canvas-readonly-copy-fix"
    name:   "Canvas Read-Only Copy"
    author: "J"
    repo:   "jeffreyl-3/ObsidianCanvasFixer"

    html_url:    "https://community.obsidian.md/plugins/canvas-readonly-copy-fix"
    github_url:  "https://github.com/jeffreyl-3/ObsidianCanvasFixer"
    description: "Copies selected text from read-only Obsidian Canvas cards. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Copy highlighted text from Markdown and text cards while a Canvas is in read-only mode. Put Markdown into the plain-text clipboard and rendered content into the HTML clipboard, while keeping normal copy behavior outside the read-only Canvas and inside editable controls."

    stats: {
        downloads:  33
        updated_at: 1786041275000
    }
}
```
