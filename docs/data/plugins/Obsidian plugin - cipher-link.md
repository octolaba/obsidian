# CipherLink

CipherLink writes encrypted Markdown notes that still expose selected metadata, tags and relationship links to Obsidian's native search, backlinks and Graph view. Decrypted content lives in an in-memory secure editor so the public envelope never holds plain text, and a session can be locked. Storage is either standalone or through a gateway, which the recorded description ties to conflict control and audit.
