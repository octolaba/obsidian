# Colorful Folders

Colorful Folders color-codes the sidebar with hierarchical folder palettes, smart icons, tags, the Graph View and glowing connector lines. A one-click privacy dashboard and a Ghost Mode hide files or folders, and Markdown divider popovers and adjustable icon positioning are provided for navigation.
