# Linear Integration

Syncs Linear issues and notes in both directions, with inline issue creation, autocomplete, conflict resolution, and automatic label creation. Issues can be created and edited from Markdown using tags and expressions, and the recorded inputs describe color-coded labels, hover previews, and quick or bulk edits without leaving Obsidian.
