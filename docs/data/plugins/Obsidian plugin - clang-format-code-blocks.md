# Clang-Format Code Blocks

Formats fenced code blocks by piping each one through clang-format and replacing it in place, covering the C family and the other languages clang-format supports. The active note can be scanned as a whole, or only the block at the cursor formatted, with formatting on save as an option. It is desktop only and requires clang-format to be installed.

```cue
plugin: {
    id:     "clang-format-code-blocks"
    name:   "Clang-Format Code Blocks"
    author: "Ömer Kara"
    repo:   "oemer-kara/clang-format-obsidian-code-blocks"

    html_url:    "https://community.obsidian.md/plugins/clang-format-code-blocks"
    github_url:  "https://github.com/oemer-kara/clang-format-obsidian-code-blocks"
    description: "Format fenced code blocks in your notes using clang-format. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Format fenced C-family and other clang-format–supported code blocks in your notes by piping each block through clang-format and replacing it in place. Scan the active note or format only the block at cursor, with optional format-on-save (desktop only; clang-format must be installed)."
```
