# Auto Tags

Auto Tags asks a large language model to generate tags for the current file, taking the vault's tag history into account. It appends the tags to frontmatter, returning up to five previously used tags and up to three new suggestions, and it runs on a single file or recursively across a folder for batch tagging.

```cue
plugin: {
    id:     "auto-tags"
    name:   "Auto Tags"
    author: "li-xiu-qi"
    repo:   "li-xiu-qi/obsidian-auto-tags"

    html_url:    "https://community.obsidian.md/plugins/auto-tags"
    github_url:  "https://github.com/li-xiu-qi/obsidian-auto-tags"
    description: "Analyze and tag your document with one click for efficient note organization using AI. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Generate relevant tags for notes using large language models that analyze the current file and your vault's tag history. Append tags to frontmatter, return up to five previously used tags plus up to three new suggestions, and run on single files or recursively across folders for batch tagging."

    stats: {
        downloads:  119
        updated_at: 1764445327000
    }
}
```
