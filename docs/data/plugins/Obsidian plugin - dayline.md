# Dayline

Captures short daily check-ins from a right-sidebar timeline and creates one Markdown timeline file per day in the vault. Entries are stored as Markdown blocks with hidden JSON metadata and can carry images, files or audio, and they are searched and filtered by text, tag, time or date. A source entry can be opened or embedded elsewhere.
