# S3 Image Uploader

S3 Image Uploader sends images from the clipboard or from local files to a self-hosted AWS S3 bucket and inserts the resulting Markdown links into the note. The recorded text presents this as hosting images on personal S3 storage instead of third-party services, serving them directly from that bucket.

```cue
plugin: {
    id:     "s3-image-uploader"
    name:   "S3 Image Uploader"
    author: "jvsteiner"
    repo:   "jvsteiner/s3-image-uploader"

    html_url:    "https://community.obsidian.md/plugins/s3-image-uploader"
    github_url:  "https://github.com/jvsteiner/s3-image-uploader"
    description: "Self-host images on AWS S3."
    about:       "Upload images from the clipboard or local files to your own S3 bucket and automatically insert Markdown links into your notes. Host images on personal S3 storage instead of third-party services and serve them directly from your bucket."

    stats: {
        downloads:  8277
        updated_at: 1770203101000
    }
}
```
