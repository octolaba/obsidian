# Metadata Auto Classifier

Metadata Auto Classifier applies metadata to notes automatically by generating context-aware tags and populating customizable frontmatter with AI. Per-field prompts and classification rules govern what is produced, suggestions can be previewed before they are applied, and several AI providers are supported.
