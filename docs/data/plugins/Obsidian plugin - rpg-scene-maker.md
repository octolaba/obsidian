# Ambient Director

Ambient Director fires Ambient Director scenes, events and sounds from session notes through compact inline tokens that render as clickable buttons. Buttons can carry live art or emoji, autocomplete offers scenes from the server, and an active state is shown with pulsing highlights. A control panel opens in a pane while the note stays in Reading view or Live Preview.
