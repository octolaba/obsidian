# Hilo

Hilo adds multi-color highlights using Obsidian's native ==text== syntax without breaking inline Markdown, so bold, italics and links inside a highlight still render. Notes store only semantic colour slugs while the hex values live in settings, and highlights render identically in Source, Live Preview and Reading view. Colours are changed from the context menu or by hotkey.
