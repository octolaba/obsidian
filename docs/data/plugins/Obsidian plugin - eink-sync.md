# E-Ink Sync

Syncs a reMarkable tablet over the local network via SFTP or Syncthing, without the reMarkable Cloud. PDF highlights are extracted into linked Markdown notes and pen-stroke annotations are rendered as embedded PNGs. The tablet library is browsed, searched, archived and deleted from the sidebar, and data stays local.
