# Daily Notes Compiler

Compiles daily notes or journals from a chosen date range into a single note. A start and end date or a preset such as last week or last month selects the range, and both the source folder for the daily notes and the destination folder for the compiled note are configurable. The upstream index description still carries sample-plugin text about demonstrating the Obsidian API.

plugin: {
    id:     "daily-notes-compiler"
    name:   "Daily Notes Compiler"
    author: "pragatinath"
    repo:   "pragatinath/obsidianplugin-daily-notes-compiler"

    html_url:    "https://community.obsidian.md/plugins/daily-notes-compiler"
