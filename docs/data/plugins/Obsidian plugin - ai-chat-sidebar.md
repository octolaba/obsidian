# AI Chat Sidebar

AI Chat Sidebar adds a desktop-only chat sidebar backed by Claude Max OAuth, an Anthropic API key as fallback, and optionally ChatGPT Plus or Codex. Responses stream, the active note and file mentions supply context, multi-file diff reviews are available, and agent-proposed edits are shown as diffs before they are applied.

    id:     "ai-chat-sidebar"
