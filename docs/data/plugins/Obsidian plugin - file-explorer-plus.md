# File Explorer++

File Explorer++ hides or pins files and folders in the file explorer using custom filters, matched by wildcard or regex against names, paths and tags. Filters are toggled globally or one at a time, and an item is hidden or pinned directly from the file menu. The affected paths can be inspected, and mobile devices are supported.
