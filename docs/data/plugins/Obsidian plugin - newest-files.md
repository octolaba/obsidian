# Newest Files

Newest Files lists the newest files added to the vault in a compact sidebar view, including attachments and other non-Markdown items that have never been opened. Entries can show timestamps, filenames and subtle extension labels, and a first-seen index, backfilled from created or modified timestamps, updates live as files are created, deleted, renamed or modified.

```cue
plugin: {
    id:     "newest-files"
    name:   "Newest Files"
    author: "Viggo Meesters"
    repo:   "viggomeesters/obsidian-newest-files"

    html_url:    "https://community.obsidian.md/plugins/newest-files"
    github_url:  "https://github.com/viggomeesters/obsidian-newest-files"
    description: "List the newest files added to the vault, including attachments that have never been opened. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "List newest files in a compact sidebar view, including attachments and non‑Markdown items, with optional timestamps, filenames, and subtle extension labels. Track a first-seen index (backfilled from created or modified timestamps) and update live on file create, delete, rename, and modify."
```
