# Narrate

Reads Markdown notes aloud through a local OpenAI-compatible text-to-speech server. Playback is chunked with prefetching for gapless audio and per-note resume, driven from a draggable mini-player and inline play buttons on a selected sentence. Reading queues, a jump-to-chunk modal, a sleep timer, estimated duration, table, parenthesis and code filters and WAV export are part of the recorded feature set.
