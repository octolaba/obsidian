# Horme

Horme indexes the vault with a local embedding model and chats with a local interaction model to find, summarize and explore notes offline. Its recorded About states that all data stays on the machine, with no API keys and no cloud. Its recorded description instead lists chat, right-click actions, vault-wide retrieval and an extensible skill system with support for Ollama, Claude, Gemini, OpenAI, Groq, OpenRouter and LM Studio, so the two recorded inputs disagree about remote providers.
