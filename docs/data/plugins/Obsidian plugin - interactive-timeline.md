# Interactive Timeline

Interactive Timeline places notes on an infinite timeline canvas with pan and zoom, covering dates from 20 billion BCE to 20 billion CE. Cards are selected, dragged and resized across layers, color-coded from frontmatter, and actions can be undone and redone. Several timelines can exist, each scoped to a folder.

plugin: {
    id:     "interactive-timeline"
    name:   "Interactive Timeline"
    author: "tulgardinc"
