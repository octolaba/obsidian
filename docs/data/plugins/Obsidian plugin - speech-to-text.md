# Speech to Text

Audio recordings are transcribed inside Obsidian through several AI providers — the recorded inputs name OpenAI Whisper and Deepgram — with automatic provider selection and speaker diarization. A transcript is inserted at the cursor or written into a new note, more than forty languages are supported with automatic detection, and batches of files report progress while they run.

```cue
plugin: {
    id:     "speech-to-text"
    name:   "Speech to Text"
    author: "asyouplz"
    repo:   "asyouplz/SpeechNote"

    html_url:    "https://community.obsidian.md/plugins/speech-to-text"
    github_url:  "https://github.com/asyouplz/SpeechNote"
    description: "Convert audio recordings to text using multiple AI providers (OpenAI Whisper, Deepgram) - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Transcribe audio recordings to text directly in Obsidian using multiple AI providers with automatic provider selection and speaker diarization. Insert transcripts at the cursor or create new notes, support 40+ languages with auto language detection, and handle batch files with real-time progress."

    stats: {

}
```
