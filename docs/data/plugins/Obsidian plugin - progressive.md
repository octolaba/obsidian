# Progressive

Shows a persistent progress bar in the file explorer with the percentage of completed tasks across notes. Daily, weekly, monthly or custom notes can be tracked, over the latest note, today's note, or all notes in a folder. Colors follow a theme-aware twelve-level gradient or black and white modes, and update automatically.
