# Wikipedia

The first section of a Wikipedia article is inserted into the active note, looked up by the note title or by a search term. The extract is shaped by the chosen language, a template, paragraph-level templating and an option to bold the search term.

```cue
plugin: {
    id:     "obsidian-wikipedia"
    name:   "Wikipedia"
    author: "jmilldotdev"
    repo:   "jmilldotdev/obsidian-wikipedia"

    html_url:    "https://community.obsidian.md/plugins/obsidian-wikipedia"
    github_url:  "https://github.com/jmilldotdev/obsidian-wikipedia"
    description: "Get the first section of Wikipedia for a note title or search term."
    about:       "Insert the first section of a Wikipedia article into the active note using the note title or a custom search term. Customize the extract with language selection, templates, paragraph-level templating, and optional bolding of the search term."

    stats: {
        downloads:  29225
        updated_at: 1634391466000
    }
}
```
