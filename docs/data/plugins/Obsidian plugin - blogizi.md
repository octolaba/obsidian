# Blogizi

Publishes notes from Obsidian to a Blogizi blog and updates existing posts by matching their slug. New post notes can be created with Blogizi-compatible YAML frontmatter, and a frontmatter template can be inserted into an existing note. Uploads go out as a draft or as a published post, with a choice of which project to target.

```cue
plugin: {
    id:     "blogizi"
    name:   "Blogizi"
    author: "Rudolfs Rijkuris"
    repo:   "bytemindlab/blogizi-obsidian"

    html_url:    "https://community.obsidian.md/plugins/blogizi"
    github_url:  "https://github.com/bytemindlab/blogizi-obsidian"
    description: "Publish Obsidian notes to your Blogizi blog — frontmatter templates, drafts, and updates by slug. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Publish notes from Obsidian to your Blogizi blog and update existing posts by slug. Create new post notes with a Blogizi-compatible YAML frontmatter, insert frontmatter templates, and upload as draft or publish while choosing which project to target."

    stats: {
        downloads:  18
        updated_at: 1786092287000
    }
}
```
