# Task Manager Bases View

Task Manager Bases View renders Kanban and timeline views over Bases queries and adds a weekly-log calendar built from daily notes. Cards are dragged to change status or to archive, timeline bars are dragged to reschedule, and calendar log blocks are created or deleted. It owns no data model and hard-codes no field names: grouping, filtering and dates come from the Bases setup, and edits write back to the note properties, so the Markdown remains the single source of truth.
