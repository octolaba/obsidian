# Bitiful Helper

Bitiful Helper manages Bitiful cloud storage from a sidebar file browser, with drag-and-drop and clipboard uploads, bucket copying, bulk operations and global search. It can compress and watermark images during upload, report EXIF data and capacity statistics, and insert Markdown or media links for images, audio, video and PDF files.
