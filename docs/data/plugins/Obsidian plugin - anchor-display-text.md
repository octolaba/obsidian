# Anchor Link Display Text

Sets the display text of an anchor link to the linked heading automatically, so a heading link renders with the heading as its label. The format can be the heading alone, the note plus heading, or an order-based form; links matching several headings can show all, the first or the last; and a file property can be used in place of the note name.

```cue
plugin: {
    id:     "anchor-display-text"
    name:   "Anchor Link Display Text"
    author: "rca-umb"
    repo:   "rca-umb/anchor-link-display-text"

    html_url:    "https://community.obsidian.md/plugins/anchor-display-text"
    github_url:  "https://github.com/rca-umb/anchor-link-display-text"
    description: "Automatically uses the linked heading as the display text for anchor links."
    about:       "Set anchor link display text to match linked headings automatically, converting [[Title#Heading]] into [[Title#Heading|Heading]]. Choose display formats (heading, note+heading, order), control multi-heading behavior (show all/first/last), or use a file property instead of the note name."

    stats: {
        downloads:  1812
        updated_at: 1767731744000
    }
}
```
