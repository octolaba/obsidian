# iCal Pro

iCal Pro publishes Markdown tasks and daily notes as a standards-compliant iCalendar feed for Google, Apple and Outlook calendars. It states strict RFC 5545 compliance and splits entries into VEVENT and VTODO while keeping UIDs stable and task metadata intact. Data stays local, with optional syncing through a GitHub Gist, and dates are inherited where a task carries none of its own.
