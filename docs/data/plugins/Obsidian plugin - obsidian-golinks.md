# GoLinks

Renders plaintext go links, written either as go/link or with a scheme prefix, as clickable links in Reading, Source and Live Preview modes. Links inside code blocks or backticks are ignored, as are URLs that have already been linkified.

```cue
plugin: {
    id:     "obsidian-golinks"
    name:   "GoLinks"
    author: "xavdid"
    repo:   "xavdid/obsidian-golinks"

    html_url:    "https://community.obsidian.md/plugins/obsidian-golinks"
    github_url:  "https://github.com/xavdid/obsidian-golinks"
    description: "Render go/links as clickable links."
    about:       "Render plaintext GoLinks (e.g., go/link or https://go/link) as clickable links across Obsidian in Reading, Source, and Live Preview modes. Ignore links inside code blocks or backticks and skip URLs that are already linkified."

    stats: {
        downloads:  4530
        updated_at: 1745813545000
    }
}
```
