# Outline for All Files

Shows one outline panel covering both Markdown notes and PDF documents, built from real Markdown headings and PDF bookmarks. The outline follows the active file, jumps to the correct heading, deep-links into a PDF by page and offset, keeps expand state per file, and can show page-number badges.

plugin: {
    id:     "all-outline"
    name:   "Outline for All Files"
    author: "cemtan"
    repo:   "cemtan/all-outline"

    html_url:    "https://community.obsidian.md/plugins/all-outline"
    github_url:  "https://github.com/cemtan/all-outline"
    description: "A single, unified outline panel for both Markdown notes and PDF documents. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "View a single unified outline panel for Markdown notes and PDF documents, built from real Markdown headings and PDF bookmarks. Switch files and see the outline update automatically; navigate precisely with correct heading jumps, PDF page+offset deep links, per-file expand state, and optional page-number badges."
