# Monthly notes

Monthly notes opens or creates the current month's note from a single click or command. Missing folders are created, and templates are applied through the {{title}}, {{date}} and {{time}} placeholders, with support for custom date and time formats.

```cue
plugin: {
    id:     "monthly-note"
    name:   "Monthly notes"
    author: "Ben Johnson"
    repo:   "benjohnson/obsidian-monthly-notes"

    html_url:    "https://community.obsidian.md/plugins/monthly-note"
    github_url:  "https://github.com/benjohnson/obsidian-monthly-notes"
    description: "Create or open this month's monthly note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open or create the current month's note with a single click or command. Create missing folders and apply templates using {{title}}, {{date}} and {{time}}, with support for custom date/time formats."

    stats: {
        downloads:  72
        updated_at: 1782697058000
    }
}
```
