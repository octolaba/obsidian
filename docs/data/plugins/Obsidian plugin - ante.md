# Ante

Runs a local Ante runtime inside Obsidian to add note-aware editing, diff review, interactive sidebars and chat-driven workflows. The editorial assistant runs locally, reviewing changes, suggesting edits and guiding interactive note workflows. It is powered by the Ante agent core from Antigma Labs, with continuous ingestion and indexing.
