# WordWise

Edits, rewrites and suggests text inside Obsidian by sending prompts to a language model. Built-in prompts can be used or custom ones kept in files, and the recorded providers are OpenAI, Gemini, Cohere, Anthropic, DeepSeek and OpenRouter. The recorded inputs describe the workflow as lightweight and usable on mobile.
