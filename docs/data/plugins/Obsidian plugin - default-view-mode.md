# Default View Mode

Sets the default view mode of a note, reading or editing, from a field in its YAML frontmatter. The configured view is applied when the note opens, and three command palette commands set or clear the field for the current note.

```cue
plugin: {
    id:     "default-view-mode"
    name:   "Default View Mode"
    author: "Sun Zhenyu"
    repo:   "sunzyyu/obsidian-default-view"

    html_url:    "https://community.obsidian.md/plugins/default-view-mode"
    github_url:  "https://github.com/sunzyyu/obsidian-default-view"
    description: "Set a default view mode (reading or editing) for each note via frontmatter. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Set a per-note default view (read or edit) via a simple YAML frontmatter field. Switch to the configured view automatically when opening a note and manage per-note settings with three command-palette commands to set or clear the view. Keep global settings off and control view behavior directly in each note."

    stats: {
        downloads:  159
        updated_at: 1780393891000
    }
}
```
