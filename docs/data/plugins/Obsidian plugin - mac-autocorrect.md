# macOS Autocorrect

Autocorrects as you type through the native macOS NSSpellChecker, with the Electron spellchecker as a fallback, and applies capitalization rules and system Text Replacements. Corrections are skipped in code, math, links and frontmatter, in ALLCAPS and camelCase words and during IME composition. A correction can be undone immediately, the last correction can be reverted for the session, and a permanent ignore list is kept.
