# Terminal Workbench Pet

Terminal Workbench Pet displays a floating ghost that drifts through the workspace, peeks at headings, reads along the current paragraph, spooks away from the cursor and naps when idle. It can float, follow the cursor, or be switched off, and booping it changes its color and triggers a happy squish. The chosen color is remembered, and the pet matches the Terminal Workbench palette when that theme is available.
