# Canvas Cover Overlay

Canvas Cover Overlay gives each canvas its own embedded thumbnail and canvas view background, read from cover fields in the target .canvas frontmatter. The overlay layer is non-interactive so native rendering is preserved, and the frontmatter keys and overlay opacity are configurable. The inputs state that it requires Advanced Canvas and is desktop only.

plugin: {
    id:     "canvas-cover-overlay"
    name:   "Canvas Cover Overlay"
