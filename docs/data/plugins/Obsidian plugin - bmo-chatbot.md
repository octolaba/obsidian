# BMO Chatbot

BMO Chatbot talks to OpenAI, Anthropic, Google Gemini, Mistral, Ollama, LM Studio and self-hosted models to brainstorm and draft while notes are being written. Bot profiles and system prompts are customizable, generation can be started from the editor, chats render Obsidian Markdown, and conversations are saved and loaded as Markdown.

```cue
plugin: {
    id:     "bmo-chatbot"
    name:   "BMO Chatbot"
    author: "longy2k"
    repo:   "longy2k/obsidian-bmo-chatbot"

    html_url:    "https://community.obsidian.md/plugins/bmo-chatbot"
    github_url:  "https://github.com/longy2k/obsidian-bmo-chatbot"
    description: "Generate and brainstorm ideas while creating your notes using Large Language Models (LLMs) such as OpenAI's \"gpt-3.5-turbo\" and \"gpt-4\"."
    about:       "Chat with OpenAI, Anthropic, Google Gemini, Mistral, Ollama, LM Studio and self‑hosted LLMs to brainstorm and draft directly in Obsidian. Create customizable bot profiles and system prompts, generate from the editor, render Obsidian Markdown in chats, and save or load conversations as markdown."

    stats: {
        downloads:  50446

}
```
