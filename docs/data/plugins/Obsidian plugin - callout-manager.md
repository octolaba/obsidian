# Callout Manager

Callout Manager browses and previews the available callout types and lets their colors and icons be customized or new callouts created. Callouts defined by snippets and themes are detected automatically. It works on mobile and exposes a Plugin API through which other plugins can integrate.

```cue
plugin: {
    id:     "callout-manager"
    name:   "Callout Manager"
    author: "eth-p"
    repo:   "eth-p/obsidian-callout-manager"

    html_url:    "https://community.obsidian.md/plugins/callout-manager"
    github_url:  "https://github.com/eth-p/obsidian-callout-manager"
    description: "Easily create and customize callouts."
    about:       "Manage callouts with a visual browser and preview available types. Customize colors and icons or create new callouts; auto-detect callouts from snippets and themes. Use on mobile and integrate with other plugins via the Plugin API."

    stats: {
        downloads:  192087
        updated_at: 1785567483000
    }
}
```
