# Cover Image

Cover Image inserts the image linked in a note's cover property at the top of the note body. When the cover link changes, the displayed image is updated automatically.

```cue
plugin: {
    id:     "cover-image"
    name:   "Cover Image"
    author: "Mirco Macrelli"
    repo:   "mircomacrelli/cover-image"

    html_url:    "https://community.obsidian.md/plugins/cover-image"
    github_url:  "https://github.com/mircomacrelli/cover-image"
    description: "Automatically include the image linked in the property cover at the top of the note body - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert the image linked in the cover property at the top of the note body. Update the displayed image automatically when the cover link changes."

    stats: {
        downloads:  154

}
```
