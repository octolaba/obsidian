# DQL Syntax

Highlights Dynatrace Query Language code blocks with token coloring and adds a copy button in reading mode. Commands, functions, data types, operators, durations, numbers, strings and comments are recognised, and ready-to-use query templates are included.

    author: "Andrew Usher"

    github_url:  "https://github.com/andrewusher/obsidian-dynatrace-dql"
