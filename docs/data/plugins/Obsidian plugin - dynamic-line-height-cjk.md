# Dynamic Line Height for CJK

Adjusts line and paragraph height when the text contains CJK characters, in both Editing and Reading views. Affected lines receive a CSS class for custom styling, and the CJK line heights themselves are set through Style Settings.

```cue
plugin: {
    id:     "dynamic-line-height-cjk"
    name:   "Dynamic Line Height for CJK"
    author: "ryotaushio"
    repo:   "ryotaushio/obsidian-dynamic-line-height-cjk"

    html_url:    "https://community.obsidian.md/plugins/dynamic-line-height-cjk"
```
