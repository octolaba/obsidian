# MTG Card Links

Turns a card name enclosed in square brackets into a link to that trading-card entry. Fuzzy matching handles alternate and split names, and a set name or collector number can follow the name after a pipe to pin an exact printing.

```cue
plugin: {
    id:     "mtg-card-links"
    name:   "MTG Card Links"
    author: "aedans"
    repo:   "aedans/mtg-card-links"

    html_url:    "https://community.obsidian.md/plugins/mtg-card-links"
    github_url:  "https://github.com/aedans/mtg-card-links"
    description: "Link to Magic the Gathering cards by enclosing the card name in square brackets."
    about:       "Link Magic: The Gathering cards by enclosing a card name in square brackets. Use fuzzy matching for alternate or split names, and specify set or collector number with [Card Name|Set Name] or [Card Name|Set Name|123]."

    stats: {
        downloads:  4444
        updated_at: 1774490173000
    }
}
```
