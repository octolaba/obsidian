# Minder Nexus

Minder Nexus defines formal relationships between notes, written in alias or Dataview inline syntax, to build a semantic knowledge graph over the vault. Connections are shown and managed through type-specific badges, live and hover previews, dead-link indicators, bidirectional property sync and backlinks grouped by type. A vault-wide scanner reports dead links.
