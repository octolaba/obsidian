# SmartTask

Tasks are managed in list, kanban, calendar and timeline views, the timeline offering classic, zigzag, card and Gantt variants. Tasks are created quickly with inline metadata and an automatic start timestamp, subtasks nest without a stated depth limit, and filtering and sorting run over status, priority, tags or date. Native Markdown links and tags in the task text are left intact.
