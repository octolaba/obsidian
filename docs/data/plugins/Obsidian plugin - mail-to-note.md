# mail-to-note

Imports emails sent to a personal mail2note address into the vault as Markdown notes, with attachments preserved. Synchronization runs on a schedule or is triggered immediately, notes are saved to a target folder, and filenames follow templates built from the date, the subject or the message ID.

```cue
plugin: {
    id:     "mail-to-note"
    name:   "mail-to-note"
    author: "moszinet"
    repo:   "moszinet/mail2note-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/mail-to-note"
    github_url:  "https://github.com/moszinet/mail2note-obsidian-plugin"
    description: "Sync emails sent to your mail2note address into your vault as Markdown notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Forward emails to your personal mail2note address to import them as Markdown notes in your vault with attachments preserved. Sync automatically on a schedule or trigger immediate sync; save notes to a target folder and apply filename templates using date, subject, or message ID."

    stats: {
        downloads:  148
        updated_at: 1779110105000
    }
}
```
