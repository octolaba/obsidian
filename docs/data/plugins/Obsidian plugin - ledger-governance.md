# Ledger Governance

Ledger Governance adds a document status lifecycle from draft to published, owner and review tracking, a governance dashboard and an in-vault audit log. Its About describes a shared organisation vault with review and approval workflows, enforced ownership and last-reviewed metadata, org-wide search, read-only published portals and collected compliance evidence, all kept in native Markdown with YAML frontmatter and wikilinks. The description states that it runs entirely locally, with no account and no network.
