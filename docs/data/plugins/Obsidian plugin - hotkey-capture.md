# Hotkey Capture

Hotkey Capture records keyboard shortcuts and inserts them into a note at the cursor. Modifier keys, comma-separated key sequences and readable names for special keys are shown, and a status bar indicator reports the capture as it happens.

```cue
plugin: {
    id:     "hotkey-capture"
    name:   "Hotkey Capture"
    author: "mihailgusev"
    repo:   "mihailgusev/hotkey-capture"

    html_url:    "https://community.obsidian.md/plugins/hotkey-capture"
    github_url:  "https://github.com/mihailgusev/hotkey-capture"
    description: "Capture and insert keyboard shortcuts into your notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Capture and insert keyboard shortcuts directly into your notes. Show modifier keys, comma-separated key sequences, and readable names for special keys, with a live status-bar indicator and direct insertion at the cursor."

    stats: {
        downloads:  111
        updated_at: 1770569460000
    }
}
```
