# gpgCrypt

Encrypts notes with OpenPGP.js or a local GnuPG installation, using asymmetric key pairs and OpenPGP smartcards such as YubiKey and Nitrokey. Normal Obsidian editing and workflow continue, with a status-bar indicator, an option to encrypt all notes, and mobile support through OpenPGP.js. The recorded description notes that encrypted notes may still be cached unencrypted on disk.
