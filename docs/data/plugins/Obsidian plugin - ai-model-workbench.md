# AI Model Workbench

Renders 3D assets inside notes, handling GLB/GLTF, STL, OBJ, PLY and SPLAT directly and offering optional local conversion for CAD, FBX and other exchange formats. Parts can be annotated with depth-aware pins and labels, several models arranged in a grid, and snapshots captured. Linked Markdown knowledge notes are generated from the result, on desktop and mobile, in English and Simplified Chinese.
