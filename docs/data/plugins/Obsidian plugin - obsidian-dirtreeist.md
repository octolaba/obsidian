# Dirtreeist

Dirtreeist renders a directory structure diagram from a Markdown list placed in a dirtree codeblock. Nested, sequential and mixed listings are converted into readable ASCII tree diagrams showing folders and files.

    id:     "obsidian-dirtreeist"
    name:   "Dirtreeist"
