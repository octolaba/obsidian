# Eisenhower Matrix Blocks

Embeds independent four-quadrant Eisenhower task boards inside a note, editable directly in the rendered matrix. Tasks, their quadrant, order and completion times are stored as Markdown, so each board keeps a per-note, filterable completion history that travels with the file. The interface is available in Chinese and English.
