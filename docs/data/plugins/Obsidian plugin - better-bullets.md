# Better Bullets

Better Bullets changes bullet symbols and scales list items by nesting depth so the outline of a bulleted note is easier to read. It also auto-formats lines to bold higher-level headers, mark notes and examples, highlight term and definition pairs, italicize quotes and parentheses, underline years, and hide the control markers while leaving the underlying Markdown intact.

```cue
plugin: {
    id:     "better-bullets"
    name:   "Better Bullets"
    author: "lualum"
    repo:   "lualum/obsidian-better-bullets"

    html_url:    "https://community.obsidian.md/plugins/better-bullets"
    github_url:  "https://github.com/lualum/obsidian-better-bullets"
    description: "Improves readability of bulleted notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Transform list readability by swapping bullet symbols and scaling items by nesting depth to create a clear visual outline. Auto-format lines to bold higher-level headers, mark notes and examples, highlight term|definition pairs, italicize quotes/parentheses, underline years, and hide control markers while keeping Markdown intact."
```
