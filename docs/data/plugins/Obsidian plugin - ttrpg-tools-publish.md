# TTRPG Tools - Publish

Prepares Zoom Map and Timeline content for Obsidian Publish by generating the publish runtime, data notes and an asset manifest. Runtime blocks are written into publish.js and publish.css, and maps and timelines are converted into publishable Markdown notes with linked asset files.

```cue
plugin: {
    id:     "ttrpg-tools-publish"
    name:   "TTRPG Tools - Publish"
    author: "Johannes Schwartz"
    repo:   "jareika/TTRPG-Tools-Publish"

    html_url:    "https://community.obsidian.md/plugins/ttrpg-tools-publish"
    github_url:  "https://github.com/jareika/TTRPG-Tools-Publish"
    description: "Generates publish.js/publish.css and a publish-assets manifest for TTRPG Tools: Maps (Zoom Map). - This plugin has not been manually reviewed by Obsidian staff."

Write runtime blocks into publish.js/publish.css and convert maps and timelines into publishable Markdown notes with linked asset files for your Publish site."
