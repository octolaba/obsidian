# Command Tracker

Command Tracker records each command execution and reports last-used dates together with daily usage counts. Per-command histories and hotkey associations can be inspected, which is how frequently used commands are found for assigning hotkeys and rarely used bindings are reclaimed.

```cue
plugin: {
    id:     "command-tracker"
    name:   "Command Tracker"
    author: "namikaze-40p"
    repo:   "namikaze-40p/obsidian-command-tracker"

    html_url:    "https://community.obsidian.md/plugins/command-tracker"
    github_url:  "https://github.com/namikaze-40p/obsidian-command-tracker"
    description: "Track the number of times the command is used."
    about:       "Track each command execution and display last-used dates and daily usage counts. Inspect per-command histories and hotkey associations to spot frequently used commands to assign hotkeys or reclaim rarely used bindings."

    stats: {
        downloads:  1898
        updated_at: 1778043509000
    }
}
```
