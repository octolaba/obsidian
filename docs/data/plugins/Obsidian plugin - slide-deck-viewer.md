# Slide Deck Viewer

Slide Deck Viewer opens .pptx slide decks in a read-only inspection view inside Obsidian. The OOXML package is parsed locally to show slide text, speaker notes, media references and package diagnostics. Filters and warnings cover external links, macros and decks that are large or malformed.
