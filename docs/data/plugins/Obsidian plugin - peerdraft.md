# Peerdraft

Peerdraft provides real-time collaboration on notes and folders through the Peerdraft service, with visible collaborator cursors, notifications and folder sync. End-to-end encrypted ad-hoc sessions can be started without an account, while persistent shared vaults support asynchronous or offline editing and a web editor. The recorded inputs note that persistent shares require an optional paid plan.
