# Noesis Flow

Keeps tasks as standard Markdown checkbox lines in the notes chosen for them, with optional extra metadata alongside. Tasks can be captured into a central task note, or existing notes can be indexed in place without moving them. Planning surfaces include a dashboard, task list and calendar, with optional kanban, timeline and monthly planner views, recurring tasks and a Pomodoro timer.
