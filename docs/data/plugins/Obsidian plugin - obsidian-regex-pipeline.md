# Regex Pipeline

This plugin applies custom regex rulesets to reformat notes automatically, written in a simple search-to-replace syntax that supports multiline replacements and regex flags. Rulesets are applied from the right-click menu or from Obsidian commands, and the ruleset files themselves are reusable and shareable.
