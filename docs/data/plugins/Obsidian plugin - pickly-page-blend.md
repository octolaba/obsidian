# Pickly PageBlend

Pickly PageBlend publishes notes as shareable web pages with full Markdown support, automatic inclusion of linked notes and files, permanent links and social media preview images. Page meta tags are set from note properties so titles and descriptions can be customised. The recorded inputs also list article-to-video pages through a Viqeo integration.
