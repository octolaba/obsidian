# Image Gin

Image Gin generates AI images, searches stock photos, and rewrites local image references to ImageKit CDN URLs from within a note. An image_prompt and per-file image settings are read from frontmatter, generated image paths are written back as per-size keys, and external images are cached for offline viewing.

```cue
plugin: {
    id:     "image-gin"
    name:   "Image Gin"
    author: "The Lossless Group"
    repo:   "lossless-group/image-gin"

    html_url:    "https://community.obsidian.md/plugins/image-gin"
    github_url:  "https://github.com/lossless-group/image-gin"
    description: "Generate AI images, search stock images, and upload to ImageKit CDN. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Generate AI images, search stock photos, and rewrite local image references to ImageKit CDN URLs directly from your notes. Read image_prompt and per-file image settings from frontmatter, write generated image paths back as per-size keys, and cache external images for offline viewing."

    stats: {
        downloads:  109
        updated_at: 1779091778000
    }
}
```
