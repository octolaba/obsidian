# Wheel Picker

Draws a roulette-style wheel from a code block and picks a random item from it when the wheel is spun. A title and one line of data per slice define the wheel, and the central spin button animates the spin and selects a choice. It works in both view and edit mode.

```cue
plugin: {
    id:     "wheel-picker"
    name:   "Wheel Picker"
    author: "EZRA-DVLPR"
    repo:   "ezra-dvlpr/WheelPicker"

    html_url:    "https://community.obsidian.md/plugins/wheel-picker"
    github_url:  "https://github.com/ezra-dvlpr/WheelPicker"
    description: "Displays a wheel that when clicked, selects a random item from the wheel. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create interactive roulette-style wheels from codeblocks to spin and randomly pick an item. Works in View or Edit mode. Simply add a title and one line of data per slice, then press the central \"Spin\" button to animate a spin and randomly select a choice."

    stats: {
        downloads:  277
        updated_at: 1779728957000
    }
}
```
