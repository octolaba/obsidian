# Note Copilot

Note Copilot puts an AI assistant in Obsidian's right side panel for asking questions about, summarising, translating and organising content drawn from notes, attachments and PDFs. The current file and PDF context can be attached, models from OpenAI, Anthropic, Gemini, Codex and others switched between, and answers saved back into notes, with chat history kept per file.
