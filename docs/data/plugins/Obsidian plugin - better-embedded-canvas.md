# Better Embedded Canvas

Better Embedded Canvas gives an embedded canvas the styling of the full canvas view and enables panning and zooming inside the embed. The height of the embed is adjustable inline in the note and canvases display in both preview and canvas modes, while editing their contents still means opening the canvas file.

```cue
plugin: {
    id:     "better-embedded-canvas"
    name:   "Better Embedded Canvas"
    author: "kotaindah55"
    repo:   "kotaindah55/better-embedded-canvas"

    html_url:    "https://community.obsidian.md/plugins/better-embedded-canvas"
    github_url:  "https://github.com/kotaindah55/better-embedded-canvas"
    description: "Give your embedded canvas better display and interactivity. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display embedded canvases with the same canvas view styling and enable panning and zooming for full navigation. Adjust embedded canvas height inline in notes and view canvases in both preview and canvas modes; open the canvas file to edit its contents."

    stats: {
        downloads:  3133

}
```
