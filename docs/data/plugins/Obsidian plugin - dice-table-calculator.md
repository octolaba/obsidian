# Dice Table Calculator

Detects TTRPG dice notation such as d6, 2d8 or d100 in the first column of a table header. The first column of that table is then filled automatically with evenly distributed roll ranges.

```cue

    id:     "dice-table-calculator"
    name:   "Dice Table Calculator"
    author: "jpcranford"
    repo:   "jpcranford/obsidian-plugin-dice-table"
```
