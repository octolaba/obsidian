# Emoticon Picker

Inserts emoticons into a note from the command palette, a hotkey or a ribbon icon. More than 200 emoticons ship with the plugin, custom ones can be added, and individual entries are marked as favourites or hidden.

```cue
plugin: {
    id:     "emoticon-picker"
    name:   "Emoticon Picker"
    author: "Kazi Aidah Haque"
    repo:   "kazi-aidah/emoticon-picker"

    html_url:    "https://community.obsidian.md/plugins/emoticon-picker"
    github_url:  "https://github.com/kazi-aidah/emoticon-picker"
    description: "Allows you to pick emoticons and insert them into your notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert emoticons into notes via the Command Palette, hotkeys, or ribbon icon. Choose from 200+ built-in emoticons, add custom ones, mark favorites for quick access, and hide emoticons you don’t use."

    stats: {
        downloads:  144
        updated_at: 1779448818000
    }
}
```
