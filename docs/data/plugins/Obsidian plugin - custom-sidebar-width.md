# Custom Sidebar Width

Sets the left and right sidebar widths per note from frontmatter properties or tags. Ordered rules carry a pixel value per side, an empty side leaves that sidebar unchanged, the first matching rule is applied, and a rule can be marked as the default that resets the widths when nothing matches. The recorded inputs state that it is desktop-only.

```cue
plugin: {
    id:     "custom-sidebar-width"
    name:   "Custom Sidebar Width"
    author: "Avni Bilgin"
    repo:   "avnibilgin/custom-sidebar-width"

    html_url:    "https://community.obsidian.md/plugins/custom-sidebar-width"
    github_url:  "https://github.com/avnibilgin/custom-sidebar-width"
    description: "Sets the left and right sidebar widths per note based on frontmatter properties or tags. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Set left and right sidebar widths per note using frontmatter properties or tags. Define ordered rules with per-side pixel values (leave a side empty to keep it unchanged); apply the first matching rule and optionally mark a default to reset when no rule matches. Desktop-only."

    stats: {
        downloads:  91
        updated_at: 1781971075000
    }
}
```
