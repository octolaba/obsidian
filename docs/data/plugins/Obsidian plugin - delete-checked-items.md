# Delete Checked Items

Deletes every checked checklist item in a note in a single action. The action is available from the command list and from the file menu, on desktop and on mobile.

```cue
plugin: {
    id:     "delete-checked-items"
    name:   "Delete Checked Items"
    author: "wanja-l"
    repo:   "wanja-l/delete-checked-items"

    html_url:    "https://community.obsidian.md/plugins/delete-checked-items"
    github_url:  "https://github.com/wanja-l/delete-checked-items"
    description: "Enables easy deletion of completed checklist items. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Delete all checked checklist items in a note with a single action. Run the action from the command list or the file menu on desktop and mobile."
```
