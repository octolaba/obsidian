# Headings in Explorer

Headings in Explorer lists a file's headings in the file explorer as a clickable hierarchy beneath it, giving direct navigation and one consolidated place to see outlines. A Highlight Location button reveals and focuses the heading under the cursor. Custom lines can also be matched so that they appear as explorer entries.
