# EPUB Reader and Highlighter

Reads EPUB files inside Obsidian in a scrolling or paginated view with adjustable reading themes. Passages are highlighted in several colours, a note can be attached to a highlight, and a panel lists the highlights and jumps to them. All highlights export to a Markdown note with their page, text and note.
