# Jira Sync Projects Issues Dashboard

Jira Sync Projects Issues Dashboard mirrors one or many Jira projects into the vault as one Markdown note per issue, stored in project folders with YAML frontmatter. A local, filterable KPI dashboard reports completion, overdue items, workload by assignee, weekly productivity and bug accountability across projects, sprints, assignees and statuses, backed by a local cache.
