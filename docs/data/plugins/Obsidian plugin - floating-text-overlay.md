# Floating Text Overlay

Creates movable, resizable Markdown labels that attach to a part of a note and scroll with the document. A label can be linked to selected text so that it shows and hides with it, and it switches between Markdown source and rendered preview. Each label is styled on its own and the original file is not changed.
