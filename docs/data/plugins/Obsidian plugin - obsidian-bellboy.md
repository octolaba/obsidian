# Bellboy

Bellboy is an opinionated file structure manager that renames a note to the kebab-case of its first header and puts an icon drawn from front matter into the filename for easier discovery. Its Idea Processor workflow moves notes automatically between inbox, waiting, working and archive folders according to their metadata status.
