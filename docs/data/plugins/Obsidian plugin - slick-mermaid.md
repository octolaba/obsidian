# Slick Mermaid

Slick Mermaid restyles Mermaid diagrams to match Obsidian native theme and typography, mapping Obsidian CSS variables onto Mermaid so diagrams follow light and dark mode. It uses subdued fills, thin strokes and readable labels, disables theme SVG invert filters, and normalizes unquoted labels and escaped newlines. A larger pan and zoom viewer is provided for complex graphs.
