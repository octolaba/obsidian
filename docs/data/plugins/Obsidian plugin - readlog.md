# Readlog

Tracks books in plain Markdown with one note per book, frontmatter-backed metadata, manual covers, and unit-based progress in pages, locations, or percent. Reading sessions are appended to a vault-native reading log, with compact session lines added to book notes and daily notes. Kindle highlights and notes can be imported from a My Clippings file, with conservative matching and deduplicated clips.

```cue
plugin: {
    id:     "readlog"
    name:   "Readlog"
    author: "mrcnkobu"
    repo:   "mrcnkobu/readlog"

    html_url:    "https://community.obsidian.md/plugins/readlog"
    github_url:  "https://github.com/mrcnkobu/readlog"
    description: "Track books in plain markdown with vault-native logs and daily note integration. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Track books in plain Markdown with one note per book, frontmatter-backed metadata, manual covers, and unit-based progress (pages, loc, percent). Append reading sessions to a vault-native reading log and add compact session lines to book and daily notes; import Kindle highlights/notes from My Clippings.txt with conservative matching and deduplicated clips."
```
