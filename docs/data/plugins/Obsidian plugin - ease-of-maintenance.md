# Ease of Maintenance

Builds a GraphRAG index of the vault and runs LLM agents over it to clean notes, sort the inbox and answer questions with cited sources. Edits arrive as editable diffs and inbox items come back with placement suggestions. Everything runs inside Obsidian, with no Python, server or Docker required.

```cue
plugin: {
    id:     "ease-of-maintenance"
    name:   "Ease of Maintenance"
    author: "nhan"
    repo:   "t-nhannguyen/obsidian-vault-ease-of-maintenance"

    html_url:    "https://community.obsidian.md/plugins/ease-of-maintenance"
    github_url:  "https://github.com/t-nhannguyen/obsidian-vault-ease-of-maintenance"
    description: "A vault management tool with integrated agentic capabilities that is Self contained inside Obsidian. - This plugin has not been manually reviewed by Obsidian staff."

}
```
