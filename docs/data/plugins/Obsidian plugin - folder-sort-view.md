# Folder Sort View

Adds a read-only alternate navigation pane listing folders and files with its own sorting, folders from Z to A and files from A to Z, without replacing or patching the File Explorer. Expanding a folder renders its descendants lazily and files open through the normal Obsidian workspace. Vault files are left untouched and file-management actions are blocked.

    id:     "folder-sort-view"
    name:   "Folder Sort View"
    author: "Viggo Meesters"
    repo:   "viggomeesters/obsidian-folder-sort-view"

    html_url:    "https://community.obsidian.md/plugins/folder-sort-view"
    github_url:  "https://github.com/viggomeesters/obsidian-folder-sort-view"
    description: "Read-only alternate navigation pane for folders/files with custom sorting. Does not replace or patch Obsidian File Explorer. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display a safe, read-only sidebar that presents vault folders and files with custom sorting: folders Z-to-A and files A-to-Z. Expand folders to lazily render descendants and open files through Obsidian's normal workspace while leaving vault files untouched and blocking file-management actions."
