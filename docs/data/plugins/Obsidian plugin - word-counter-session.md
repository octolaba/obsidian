# Word Counter Session

Counts the words added and removed during a writing session and shows the net change in the status bar, optionally beside an elapsed timer. Markdown syntax is filtered out of the count and CJK characters are counted correctly. The session pauses automatically when the file changes and can stop after a period of inactivity.

```cue
plugin: {
    id:     "word-counter-session"
    name:   "Word Counter Session"
    author: "mingmingsoeasy"
    repo:   "mingmingsoeasy/obsidianSessionWordCounter"

    html_url:    "https://community.obsidian.md/plugins/word-counter-session"
    github_url:  "https://github.com/mingmingsoeasy/obsidianSessionWordCounter"
    description: "Track newly added words in your writing session with timer support and status bar display. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Track words added or removed during a writing session and show the net change in the status bar with an optional elapsed timer. Filter out Markdown syntax, count CJK characters correctly, auto-pause on file switches, and optionally stop after inactivity."

    stats: {
        downloads:  354
        updated_at: 1768145160000
    }
}
```
