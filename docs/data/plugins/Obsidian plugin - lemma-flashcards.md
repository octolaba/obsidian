# Lemma

Lemma turns any tagged note into a flashcard deck, with cards written in plain Markdown using basic question-and-answer or cloze syntax and scheduled by the FSRS 4.5 spaced repetition algorithm. Cards render full Markdown, including LaTeX, images and callouts, and a dashboard reports due counts alongside thirty-day statistics and custom study sessions. Mobile is supported natively and CouchDB sync is optional.
