# Theme Toggler

A toggle button is added to every pane so that light or dark mode is set per panel rather than for the whole window. Three commands toggle the active pane's theme or force dark or light mode.

```cue
plugin: {
    id:     "obsidian-theme-toggler"
    name:   "Theme Toggler"
    author: "larsmagnus"
    repo:   "larsmagnus/obsidian-theme-toggler"

    html_url:    "https://community.obsidian.md/plugins/obsidian-theme-toggler"
    github_url:  "https://github.com/larsmagnus/obsidian-theme-toggler"
    description: "Toggle light or dark mode separately for each tab."
    about:       "Add a theme toggle button to every pane and set themes on a per-panel basis. Use three commands to toggle the active pane's theme or force dark or light mode."
```
