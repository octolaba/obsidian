# Frontmatter Tag Suggest

Autocompletes tags in the frontmatter tags field without requiring a leading hash character. Suggestions appear on lines that start with the tags or tag key, and plain tag names are inserted so that the frontmatter stays valid.

```cue
plugin: {
    id:     "obsidian-frontmatter-tag-suggest"
    name:   "Frontmatter Tag Suggest"
    author: "jmilldotdev"
    repo:   "jmilldotdev/obsidian-frontmatter-tag-suggest"

    html_url:    "https://community.obsidian.md/plugins/obsidian-frontmatter-tag-suggest"
    github_url:  "https://github.com/jmilldotdev/obsidian-frontmatter-tag-suggest"
    description: "Autocomplete tags in the frontmatter tags field."
    about:       "Autocomplete tags in YAML frontmatter without requiring a leading #. Show tag suggestions on lines starting with tags: or tag: and insert plain tag names so frontmatter remains valid."

    stats: {
        downloads:  28323
        updated_at: 1649273521000
    }
}
```
