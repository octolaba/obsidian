# HTML Experience

HTML Experience opens HTML, HTM, MHT and MHTML files inside the vault with sandboxed JavaScript enabled. Reading is switched between dark and light modes, original page colors, or a custom background, and the view offers in-page text search, zoom, full-screen viewing and routing of external links to the default browser. Files reload automatically when they are edited outside Obsidian.
