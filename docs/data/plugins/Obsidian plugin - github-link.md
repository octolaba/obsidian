# GitHub Link

Turns GitHub links in notes into inline tags showing the issue or pull request number, title, author and status. A github-query code block generates a live table of search results for issues or pull requests, refreshed when the note is opened.

```cue
plugin: {
    id:     "github-link"
    name:   "GitHub Link"
    author: "nathonius"
    repo:   "nathonius/obsidian-github-link"

    html_url:    "https://community.obsidian.md/plugins/github-link"
    github_url:  "https://github.com/nathonius/obsidian-github-link"
    description: "Enrich your notes with issue and pull request content from GitHub."
    about:       "Transform GitHub links into rich inline tags showing issue and pull request numbers, titles, authors, and statuses. Embed a github-query codeblock to generate live-updating tables of search results (issues or PRs) that refresh when opening the note."

    stats: {
        downloads:  4946
        updated_at: 1786055180000
    }
}
```
