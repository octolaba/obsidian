# Note Loom

Note Loom weaves free-form Markdown into structured notes using your own templates and {{field}} placeholders. The generated frontmatter and body are previewed and can be adjusted before they are written, and templates may contain headings, lists, tables, task lists, repeated fields and Dataview inline fields.

    id:     "note-loom"
    name:   "Note Loom"
