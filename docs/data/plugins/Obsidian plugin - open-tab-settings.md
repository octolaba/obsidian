# Open Tab Settings

Open Tab Settings adds options for how Obsidian opens tabs and navigates between files. Files can open in a new tab by default, an already-open file can switch to its existing tab instead of opening a duplicate, and new tab placement and order are configurable. In a split workspace, new tabs can open in the opposite pane.

    id:     "open-tab-settings"
    name:   "Open Tab Settings"
    author: "jesse-r-s-hines"
