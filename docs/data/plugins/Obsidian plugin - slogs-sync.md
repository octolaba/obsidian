# Slogs Sync

Slogs Sync synchronizes Markdown notes with a remote Slogs vault through its Vault API. Files can be pushed, pulled or synced as a whole, posts mapped through frontmatter, and attachments and .obsidian settings optionally included. Conflicts open a modal offering to keep the remote copy, keep the local one, or skip the file.
