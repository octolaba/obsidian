# Vault Reader

Provides focused speed reading for notes in a side panel while the original Markdown stays visible. Words per minute, text size, panel zoom and the reading focus point are adjustable, per-note progress is resumed, and the current word can optionally be highlighted in the note itself in yellow, orange or blue. The recorded About states that everything runs locally, with no accounts and no network calls.
