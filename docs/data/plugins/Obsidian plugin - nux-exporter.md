# Nux Exporter

Consolidates a whole vault or a chosen folder into one structured Markdown document aimed at navigation and AI tools. A hierarchical table of contents is generated with wikilinks, embeds and Excalidraw drawings are converted to readable text, and YAML frontmatter is stripped. Each section carries its source path and a link back to the index.

```cue
plugin: {
    id:     "nux-exporter"
    name:   "Nux Exporter"
    author: "Jason Quesada Gomez"
    repo:   "jasonqg26/Nux-Exporter"

    html_url:    "https://community.obsidian.md/plugins/nux-exporter"
    github_url:  "https://github.com/jasonqg26/Nux-Exporter"
    description: "Consolidate a vault or folder into structured Markdown optimized for AI. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Export a vault or selected folder into a single, structured Markdown document optimized for navigation and AI tools. Generate a hierarchical table of contents with wikilinks, convert embeds and Excalidraw to readable text, strip YAML frontmatter, and add source paths with navigation back to the index."

    stats: {
        downloads:  21
        updated_at: 1786225428000
    }
}
```
