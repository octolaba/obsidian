# DROS Doctrinal Copilot

A companion for DROS that searches Chinese canonical texts and synthesizes academic English summaries from high-precision retrieval. The current note's context can be synced into the copilot chat, reasoning switched between strict and creative modes, and structured replies saved into the vault. It runs against a local DROS backend, with a direct or cloud fallback on mobile.
