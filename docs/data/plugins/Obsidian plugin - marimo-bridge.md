# marimo Bridge

marimo Bridge opens and edits marimo .py notebooks inside Obsidian through an embedded web editor whose edits are saved straight to disk. It starts and manages a local token-authenticated marimo server, embeds the interface as full tabs or inline app blocks, and terminates the server processes when they are no longer needed. It is desktop only.
