# Navigate Headings

Shows the headings of a Markdown file inside the file explorer, so they can be seen and jumped to without switching tabs. A file expands to reveal its headings, clicking one jumps to that section, and the active heading is highlighted while the note is scrolled.

```cue
plugin: {
    id:     "navigate-headings"
    name:   "Navigate Headings"
    author: "rumcajsev"
    repo:   "rumcajsev/obsidian-navigate-headings"

    html_url:    "https://community.obsidian.md/plugins/navigate-headings"
    github_url:  "https://github.com/rumcajsev/obsidian-navigate-headings"
    description: "Navigate markdown file headings and their structure directly in the file explorer. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "See and jump between all file headings directly in the explorer without switching tabs. Expand files to reveal their headings, click any heading to jump to that section, and watch the active heading highlight as you scroll."

    stats: {
        downloads:  292
        updated_at: 1778978014000
    }
}
```
