# Survey Log

A timestamped survey log entry is written from a keyboard-only modal opened by a single hotkey, with the time nudged quickly. Locations are chosen from an autocompleting list or added to it and inserted as tags or wikilinks, and note text is suggested from earlier entries. The finished line is inserted into the active note as a tagged entry that is easy to search.

```cue
plugin: {
    id:     "survey-log"
    name:   "Survey Log"
    author: "jannik-el"
    repo:   "jannik-el/survey-log-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/survey-log"
    github_url:  "https://github.com/jannik-el/survey-log-obsidian-plugin"
    description: "Create timestamped survey log entries with location tags via a fast, keyboard-only modal with autocomplete. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create timestamped, keyboard-only survey log entries with a single hotkey and quick time nudging. Pick or add locations from an autocompleting list (inserted as tags or wikilinks), accept note suggestions from past entries, and insert a clean tagged log line into the active note for easy searching."

    stats: {
        downloads:  21

}
```
