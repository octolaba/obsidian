# draw.io

Creates and edits draw.io diagrams inside Obsidian through a local offline web server. Shapes can be linked to notes and external URLs, carry attached markdown fragments, and hold Mermaid or LaTeX content. Diagrams can be inserted into Canvas as interactive elements and exported to PDF.
