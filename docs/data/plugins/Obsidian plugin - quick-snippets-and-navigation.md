# Quick snippets and navigation

Adds keyboard navigation between headings and empty lines, and selection of a whole heading block while editing. Code blocks are copied either from a searchable list or by taking the block nearest the cursor. Preset code blocks and callouts are inserted with the cursor placed for immediate editing, and Quick Switcher extensions search notes by tag.

```cue
plugin: {
    id:     "quick-snippets-and-navigation"
    name:   "Quick snippets and navigation"
    author: "ieviev"
    repo:   "ieviev/obsidian-keyboard-shortcuts"

    html_url:    "https://community.obsidian.md/plugins/quick-snippets-and-navigation"
    github_url:  "https://github.com/ieviev/obsidian-keyboard-shortcuts"
    description: "Keyboard navigation up/down for headings\n- Configurable default code block and callout\n- Copy code block via keyboard shortcut."
    about:       "Navigate headings and empty lines with keyboard commands and select entire heading blocks while editing. Copy code blocks quickly—pick from a searchable list or copy the next block nearest the cursor. Insert preset code blocks or callouts with the cursor positioned for immediate editing and search notes by tag via Quick Switcher extensions."
```
