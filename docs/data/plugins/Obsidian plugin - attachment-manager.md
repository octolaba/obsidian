# Attachment Manager

Binds an attachment folder name to its note name and keeps the two in step, renaming folders and files when the note changes. Remote images in the current Markdown or Canvas note are downloaded into that folder, pasted images renamed automatically, empty folders deleted, and folder visibility toggled on demand.

    id:     "attachment-manager"
    name:   "Attachment Manager"
