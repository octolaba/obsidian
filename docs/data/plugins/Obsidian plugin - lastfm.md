# Last.fm

This plugin fetches recent scrobbles, top tracks, artists and albums for a chosen period and limit, together with weekly charts, from Last.fm, including album artwork where it is available. The results are written as Markdown notes into a chosen vault folder, with previews and a ribbon entry for quick access.

```cue
plugin: {
    id:     "lastfm"
    name:   "Last.fm"
    author: "txoldi"
    repo:   "txoldi/obsidian-lastfm-plugin"

    html_url:    "https://community.obsidian.md/plugins/lastfm"
    github_url:  "https://github.com/txoldi/obsidian-lastfm-plugin"
    description: "Fetch recent scrobbles, top tracks, artists, and albums from Last.fm. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Fetch recent scrobbles, top tracks, artists, albums (by period and limit), and weekly charts from Last.fm, including album artwork where available. Generate Markdown notes into a chosen vault folder with previews and quick ribbon access."

    stats: {
        downloads:  315
        updated_at: 1764444935000
    }
}
```
