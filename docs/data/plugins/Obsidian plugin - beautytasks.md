# BeautyTasks

BeautyTasks is a task and project manager modeled on Todoist that keeps one Markdown note per task, with its own interface and no external service or additional plugin required. Task states, labels and priorities are styled through CSS custom properties or Style Settings color pickers, with a built-in palette and a monochrome toggle.
