# Resize Mobile Split View

Resize Mobile Split View lets the divider line between tab groups be dragged on phones and tablets to change their widths. Touch uses hold-and-drag with the line lighting up, and a pointer uses press-and-drag, moving dividers the way they move on desktop.

```cue
plugin: {
    id:     "resize-mobile-split-view"
    name:   "Resize Mobile Split View"
    author: "churnish"
    repo:   "churnish/resize-mobile-split-view"

    html_url:    "https://community.obsidian.md/plugins/resize-mobile-split-view"
    github_url:  "https://github.com/churnish/resize-mobile-split-view"
    description: "Drag divider line to resize tab groups on mobile. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Resize mobile split view panels by dragging the divider line to adjust tab-group widths on phones and tablets. Use touch hold-and-drag (line lights up) or press-and-drag with a pointer to move dividers like on desktop."

    stats: {
        downloads:  1482
        updated_at: 1774250959000
    }
}
```
