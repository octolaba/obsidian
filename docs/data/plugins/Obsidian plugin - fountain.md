# Fountain

Formats Fountain scripts in real time with screenplay styling, bold scene numbers in the margins, foldable scenes and boneyard support. Index cards can be reordered, content filtered, dialogue blacked out for rehearsals, margin marks and todos added, and snippets and embedded Fountain blocks used, while PDF export is configurable.
