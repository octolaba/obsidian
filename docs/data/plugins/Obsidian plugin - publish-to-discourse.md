# Publish to Discourse

Posts notes to a Discourse forum from Obsidian and opens the created thread in the browser. Posts published earlier from Obsidian are updated in place, tracked through a discourse_post_id frontmatter property. Several forum presets can be managed, the first H1 skipped, highlight syntax converted, and Discourse tags picked when posting.

```cue
plugin: {
    id:     "publish-to-discourse"
    name:   "Publish to Discourse"
    author: "woodchen-ink"
    repo:   "woodchen-ink/obsidian-publish-to-discourse"

    html_url:    "https://community.obsidian.md/plugins/publish-to-discourse"
    github_url:  "https://github.com/woodchen-ink/obsidian-publish-to-discourse"
    description: "Post notes to the Discourse forum."
    about:       "Publish notes to Discourse directly from Obsidian and automatically open the created thread in your browser. Update posts previously published from Obsidian with changes tracked via a discourse_post_id frontmatter property. Manage multiple forum presets, control title/content handling (skip first H1, convert highlight syntax), and pick Discourse tags when posting."

    stats: {
        downloads:  860
        updated_at: 1770805905000
    }
}
```
