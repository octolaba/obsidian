# Publish url

Copies the Obsidian Publish URL of the current view to the clipboard, and can also open it. Permalinks are respected, and theog.io links can be copied for sharing.

```cue
plugin: {
    id:     "publish-url"
    name:   "Publish url"
    author: "hananoshikayomaru"
    repo:   "hananoshikayomaru/obsidian-publish-url"

    html_url:    "https://community.obsidian.md/plugins/publish-url"
    github_url:  "https://github.com/hananoshikayomaru/obsidian-publish-url"
    description: "Copy Obsidian Publish URL to the clipboard."
    about:       "Copy and open your Publish URL quickly from the current view. Respect permalinks and copy theog.io links for fast sharing."

    stats: {
        downloads:  2908
        updated_at: 1702404175000
    }
}
```
