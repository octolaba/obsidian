# Property Kanban

Drives a Kanban board from note frontmatter, so that the notes stay the single source of truth and their properties are updated as cards are created, moved, edited or deleted. Cards are grouped by any frontmatter field with swimlanes, dragged between columns or lanes to write the frontmatter immediately, and file changes are reflected on the board in real time.
