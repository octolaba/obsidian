# Checkbox Reorder

Checkbox Reorder moves completed checkboxes to the end of their list, placing half-checked items between the checked and the unchecked ones. Sorting can be set to Top or Bottom, and the reorder command runs from the command palette or from a bound shortcut.

```cue

    id:     "checkbox-reorder"
    name:   "Checkbox Reorder"
    author: "erl-koenig"
    repo:   "erl-koenig/obsidian-checkboxReorder"
```
