# Flashcard Genius

Opens Markdown flashcard decks from the vault in a dedicated study view, with every card left as an ordinary Markdown table. Whole decks are shown grouped by heading, and a Library mode and a Study mode switch between inspecting sources and revealing answers. Editing the Markdown updates the view immediately, and no import step or network access is involved.
