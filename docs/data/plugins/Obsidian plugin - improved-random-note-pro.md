# Improved Random Note Pro

Opens a random note filtered by folders, tags and YAML properties, with AND/OR matching and exclusion rules. Filter sets can be saved as commands, a history avoids repeats, and a sidebar widget previews, refreshes and opens random notes.

plugin: {
    id:     "improved-random-note-pro"
    name:   "Improved Random Note Pro"
    author: "secondbrainprod"
    repo:   "secondbrainprod/obsidian-improved-random-note"

    html_url:    "https://community.obsidian.md/plugins/improved-random-note-pro"
    github_url:  "https://github.com/secondbrainprod/obsidian-improved-random-note"
