# Backlink Full Path

Backlink Full Path shows each backlink's full file path in the backlinks panel, so notes that share a name across folders can be told apart. The folder hierarchy is displayed alongside the note title.

```cue
plugin: {
    id:     "backlink-full-path"
    name:   "Backlink Full Path"
    author: "Michael Naumov"
    repo:   "mnaoumov/obsidian-backlink-full-path"

    html_url:    "https://community.obsidian.md/plugins/backlink-full-path"
    github_url:  "https://github.com/mnaoumov/obsidian-backlink-full-path"
    description: "Shows the backlink's full path in the backlinks panel."
    about:       "Show full file paths for backlinks in the backlinks panel to distinguish same-named notes across folders. Display folder hierarchy alongside note titles for clearer backlink identification."
```
