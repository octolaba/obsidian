# Aloha

Adds a date autocomplete to the editor. Typing @ opens a list offering Today, Tomorrow and Yesterday, and picking one inserts the corresponding date into the note as a wikilink.

```cue
plugin: {
    id:     "aloha"
    name:   "Aloha"
    author: "kepano"
    repo:   "kepano/aloha"

    html_url:    "https://community.obsidian.md/plugins/aloha"
    github_url:  "https://github.com/kepano/aloha"
    description: "Type @ to insert a date link in natural language. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Adds a date autocomplete in the editor. Type @ and pick Today, Tomorrow, or Yesterday to insert the date as a wikilink."

    stats: {
        downloads:  46
        updated_at: 1785533507000
    }
}
```
