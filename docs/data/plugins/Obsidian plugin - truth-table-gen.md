# Truth Table+

Generates autofilled truth tables from JavaScript-style logical expressions using operators such as `&&`, `||` and `!`, then inserts the completed table into the current note. It is aimed at logic-oriented note-taking and analysis inside Markdown files.

```cue
plugin: {
    id:     "truth-table-gen"
    name:   "Truth Table+"
    author: "max-schulten"
    repo:   "max-schulten/truth-table-plus"

    html_url:    "https://community.obsidian.md/plugins/truth-table-gen"
    github_url:  "https://github.com/max-schulten/truth-table-plus"

    about:       "Generate autofilled truth tables from JavaScript-style logical expressions using operators like &&, ||, and !. Insert the completed table directly into the current note for quick logic-oriented note-taking and analysis."
```
