# Reverse Prompter

Reverse Prompter generates writing prompts with ChatGPT from a selection, or from the cursor back to the previous header or horizontal rule. The prompts are reader-style questions meant to spark ideas, tease out missing details and get past writer's block.

plugin: {
    id:     "reverse-prompter"
    name:   "Reverse Prompter"
    author: "ryanhalliday"
    repo:   "ryanhalliday/obsidian-reverse-prompter"
