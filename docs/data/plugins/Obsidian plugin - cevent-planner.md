# CEvent-Planner

CEvent-Planner keeps events and tasks inside Markdown notes and surfaces them in a live calendar, a day list or an all-tasks dashboard. It scans the vault for events, supports per-event alarms and recurring rules, and rewrites the Markdown automatically when an item is dragged to a new time. Events carry colors, icons and tags, and subtasks are tracked live.
