# HTML Visual Editor

HTML Visual Editor opens HTML and HTM files from the vault in a visual WYSIWYG editor. Elements are dragged, resized, selected, duplicated, deleted and styled, and text, images, tables, layouts, canvas elements and charts are inserted. Changes are saved back to the same vault file with relative links preserved, and pasted images can be exported to a local assets folder.
