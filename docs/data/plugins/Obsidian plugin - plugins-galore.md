# Plugins Galore

Sideloads plugins that are not listed in the official directory by pasting a repository URL from GitHub, GitLab, or Gitea. Sideloaded plugins are then managed like regular community plugins, with update checks run on demand and selected sideloaded plugins updated.

```cue
plugin: {
    id:     "plugins-galore"
    name:   "Plugins Galore"
    author: "plugins-galore"
    repo:   "plugins-galore/obsidian-plugins-galore"

    html_url:    "https://community.obsidian.md/plugins/plugins-galore"
    github_url:  "https://github.com/plugins-galore/obsidian-plugins-galore"
    description: "Easily sideload other plugins."
    about:       "Install plugins by pasting a repository URL to sideload plugins not listed in the official directory. Sideload from GitHub, GitLab, or Gitea repos and manage them like regular community plugins. Check for updates on demand and update selected sideloaded plugins."

    stats: {
        downloads:  6187
        updated_at: 1651031195000
    }
}
```
