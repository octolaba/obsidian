# Pubcopy

Pubcopy copies a note as platform-optimized HTML for Medium and Substack, converting 56 Markdown elements including headers, lists, code blocks, tables, images, footnotes and KaTeX while preserving formatting. It works on a whole note or on selected text, and the converted HTML is pasted directly into Medium or Substack.
