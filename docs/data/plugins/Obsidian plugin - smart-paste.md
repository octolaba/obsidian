# Smart Paste

Smart Paste cleans and transforms clipboard content as it is pasted, converting HTML into Markdown while preserving headings, lists, tables, images and code blocks with language detection. Bare URLs are replaced with titled Markdown links, common tracking parameters and Amazon ref paths are stripped, and whitespace is normalized. Nothing is transformed inside code fences or YAML frontmatter.

    id:     "smart-paste"
    name:   "Smart Paste"
    author: "konstantinosgkilas"
    repo:   "konstantinosgkilas/smart-paste"

    github_url:  "https://github.com/konstantinosgkilas/smart-paste"
    description: "Automatically cleans and transforms clipboard content on paste — converts HTML to markdown, fetches link titles, strips trackers, and normalizes whitespace. - This plugin has not been manually reviewed by Obsidian staff."
