# Modules

Modules loads JavaScript and TypeScript modules from the vault and from the Internet on all platforms, treating Markdown files as loadable code. It resolves relative paths, vault paths, Markdown links, wikilinks and external URLs. CommonJS and ES modules are supported, including circular CommonJS dependencies, nested imports and source maps for debugging.
