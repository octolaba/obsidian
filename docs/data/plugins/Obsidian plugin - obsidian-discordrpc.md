# Discord Rich Presence

Discord Rich Presence updates a Discord status to show current Obsidian activity, including the vault and current file names. Which information appears is configurable, optional time tracking and connection notices can be shown, and the plugin reconnects automatically when Discord is available.

```cue
plugin: {
    id:     "obsidian-discordrpc"
    name:   "Discord Rich Presence"
    author: "lukeleppan"
    repo:   "lukeleppan/obsidian-discordrpc"

    html_url:    "https://community.obsidian.md/plugins/obsidian-discordrpc"
    github_url:  "https://github.com/lukeleppan/obsidian-discordrpc"
    description: "Update your Discord Status to show your friends what you are working on."
    about:       "Update your Discord status to display your Obsidian activity, including vault and current file names. Customize which info appears and show optional time tracking and connection notices, with automatic reconnect when Discord is available."

    stats: {
        downloads:  34700
        updated_at: 1692003751000
    }
}
```
