# SimpleDraw

SimpleDraw is a lightweight drawing plugin for simple flowcharts, editing its own drawing files inside Obsidian. Textboxes are drawn as rectangles, ellipses or diamonds with Markdown rendering and vertical text, orthogonal arrows come in four styles, and elements drag-resize and snap-align with undo and redo. Drawings export as WYSIWYG PNG with a grid or a transparent background.
