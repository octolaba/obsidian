# Privacy Screen

Blurs the workspace while keeping a clear spotlight around the cursor, intended for working in public spaces. The spotlight can be a circle or a square, and its size, horizontal offset, tracking mode, and blur intensity are adjustable; the active state is preserved across sessions.
