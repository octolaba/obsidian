# AnimeList

Tracks anime, manga and novels as plain Markdown files, with the files themselves as the source of truth and no Dataview dependency or private media database. A native library view browses the collection, metadata is searched against Bangumi, AniList and Open Library, and covers are downloaded locally. Scores and progress are recorded, filters and favorites applied, and a pannable completion timeline shows what was finished when.
