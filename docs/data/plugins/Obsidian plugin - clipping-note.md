# Clipping Note

Creates a timestamped clipping note from a template with one click on a sidebar icon or through a command, saves it into a Clippings folder and opens it immediately. The filename prefix and the date and time format are configurable, templates accept title, date and time placeholders, and the folder is created automatically with collision-safe naming.

    id:     "clipping-note"
    name:   "Clipping Note"
