# Banner Images

Banner Images displays a banner at the top of a note from a single frontmatter field, which accepts a vault-relative path, a wikilink or an external URL. Height, opacity, vertical position, fit mode and a gradient fade are configurable, and banners render in Reading View, Live Preview and on mobile.

```cue
plugin: {
    id:     "banner-images"
    name:   "Banner Images"
    author: "saltyfireball"
    repo:   "saltyfireball/obsidian-banner-images"

    html_url:    "https://community.obsidian.md/plugins/banner-images"
    github_url:  "https://github.com/saltyfireball/obsidian-banner-images"
    description: "Display banner images at the top of notes using frontmatter fields. Supports vault images, external URLs, custom height, opacity, vertical positioning, and gradient transparency. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display banner images at the top of notes via a single frontmatter field. Use vault-relative paths, wikilinks, or external URLs; control height, opacity, vertical position, fit mode and gradient fade; render in Reading View, Live Preview and on mobile."

    stats: {
        downloads:  905
        updated_at: 1779127840000
    }
}
```
