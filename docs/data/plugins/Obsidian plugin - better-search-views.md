# Better Search Views

Better Search Views decorates global search, backlinks and embedded queries with outliner-style context around every match. Matched Markdown is rendered to HTML, ancestor headings and list items are chained into clickable breadcrumbs, and sub-list items or the first section under a matched heading are displayed with the hit.
