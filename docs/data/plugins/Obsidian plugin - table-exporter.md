# Table Exporter

Exports rendered Markdown tables to PNG, CSV, Excel or paginated PDF while keeping the reading-view appearance. Export styles are chosen per run, and when a note holds several tables they are detected so one can be picked. PNG output is copied to the clipboard or saved into the vault.

```cue
plugin: {
    id:     "table-exporter"
    name:   "Table Exporter"
    author: "Shaw"
    repo:   "wikty/obsidian-table-exporter"

    html_url:    "https://community.obsidian.md/plugins/table-exporter"
    github_url:  "https://github.com/wikty/obsidian-table-exporter"
    description: "Export rendered Markdown tables in Obsidian to PNG, CSV, Excel, and PDF. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Export rendered Markdown tables to PNG, CSV, Excel (.xlsx), or paginated PDF while preserving the reading-view appearance. Choose per-run export styles, detect and pick among multiple tables in a note, copy PNGs to the clipboard, or save exports to your vault."

    stats: {
        downloads:  456

    }
}
```
