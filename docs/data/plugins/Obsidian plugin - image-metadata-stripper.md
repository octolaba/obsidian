# Image Metadata Stripper

Strips privacy-sensitive metadata from images and PDFs as they enter the vault, under automatic and manual controls. Bulk stripping is available, support can be toggled per format, and ICC color profiles can be preserved. The recorded inputs describe the processing as local and irreversible.
