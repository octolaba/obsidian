# Things Link

A Things project is created from the current note, with deeplinks written in both directions for navigation. A Things task can likewise be created from the current line and sent to the Things Inbox, linking back to the originating line.

```cue
plugin: {
    id:     "obsidian-things-link"
    name:   "Things Link"
    author: "gavinmn"
    repo:   "gavinmn/obsidian-things-link"

    html_url:    "https://community.obsidian.md/plugins/obsidian-things-link"
    github_url:  "https://github.com/gavinmn/obsidian-things-link"
    description: "Seamlessly link an Note to a Things Project."
    about:       "Create Things projects from the current note and add deeplinks between the note and project for quick navigation. Create Things tasks from the current line and send them to the Things Inbox while adding deeplinks back to the originating note line."

    stats: {
        downloads:  7534
        updated_at: 1645807657000
    }
}
```
