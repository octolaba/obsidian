# Restore Tab Key

Restore Tab Key makes the Tab key insert a real tab character and perform IDE-like indentation in the editor and in code blocks. Indentation can use tabs or spaces, hard-space indentation can be enabled, and the behavior can be restricted to code blocks only.

```cue
plugin: {
    id:     "restore-tab-key"
    name:   "Restore Tab Key"
    author: "jrymk"
    repo:   "jrymk/restore-tab-key"

    html_url:    "https://community.obsidian.md/plugins/restore-tab-key"
    github_url:  "https://github.com/jrymk/restore-tab-key"
    description: "Restore tab key behavior: tab key inserts a tab, the way it should be."
    about:       "Restore native Tab behavior so pressing Tab inserts a real tab character and performs IDE-like indentation in the editor and code blocks. Choose tabs or spaces, enable hard-space indentation, or restrict the behavior to code blocks."

    stats: {
        downloads:  15926
        updated_at: 1742312575000
    }
}
```
