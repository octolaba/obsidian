# Overboard

Embeds Overboard Studio AI whiteboards inside notes through a fenced code block or a command. The recorded description states that sketches, flowcharts, mind maps and sticky notes can be generated from plain sentences with more than a hundred templates, and that real-time collaboration supports up to 500 teammates. The index entry records that the plugin has not been manually reviewed by Obsidian staff.
