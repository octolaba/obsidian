# Buttons Panel

Buttons Panel builds a customizable panel of buttons that open files, run commands, follow links or execute scripts with a single click. Buttons are grouped into categories or tabs, given icons, reordered by drag-and-drop and searched in real time, and one button can chain several actions.

    name:   "Buttons Panel"
    author: "Kevin"
