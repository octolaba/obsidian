# Buckwalter Transliteration

The plugin renders Arabic written in Buckwalter transliteration as Arabic script inside notes. Marked text works inline and also inside internal links, and backticked text is ignored. The recorded inputs state that rendering is not supported in Live Preview.

```cue
plugin: {
    id:     "buckwalter-transliteration"
    name:   "Buckwalter Transliteration"
    author: "amrojjeh"
    repo:   "amrojjeh/obsidian-buckwalter"

    html_url:    "https://community.obsidian.md/plugins/buckwalter-transliteration"
    github_url:  "https://github.com/amrojjeh/obsidian-buckwalter"
    description: "Renders Arabic using Buckwalter's encoding scheme."
    about:       "Render Arabic text written in Buckwalter transliteration into Arabic script within notes. Use the b/ prefix (e.g., b/Asmy Emrw) and include it inline or inside internal links like [[b/Asmy Emrw]]—backticks are ignored; rendering is not supported in Live Preview."

    stats: {
        downloads:  1044
        updated_at: 1711753698000
    }
}
```
