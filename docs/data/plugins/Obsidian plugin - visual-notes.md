# Visual Notes

Visual Notes builds visual boards on Obsidian's Canvas format, combining icon tile grids, a freeform canvas, kanban, tables, sticky notes, checklists, callouts, maps and colour swatches. Boards are real .canvas files that nest inside each other and inside Obsidian Canvas. Tiles take icons or images, connections are styled, cards drag and resize, frames group them, and a minimap, search, tag and type filters and an archive help navigate.
