# Asciinema Player

Embeds local and remote Asciinema asciicast recordings into Markdown notes and renders them with an interactive player. Casts play inside the note, with playback controls and seek support for replaying recorded demos.

```cue
plugin: {
    id:     "asciinema-player"
    name:   "Asciinema Player"
    author: "deeplook"
    repo:   "deeplook/obsidian-asciinema-player"

    html_url:    "https://community.obsidian.md/plugins/asciinema-player"
    github_url:  "https://github.com/deeplook/obsidian-asciinema-player"
    description: "Embed local and remote Asciinema asciicast files in Markdown notes."
    about:       "Embed Asciinema terminal recordings (.cast) into Markdown notes and render them with an interactive player UI. Play local or remote casts with in-note playback controls and seek support for replaying demos."
```
