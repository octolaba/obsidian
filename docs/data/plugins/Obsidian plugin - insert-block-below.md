# Insert Block Below

Insert Block Below inserts math blocks and code fences on the line below the cursor while preserving blockquote, callout and ordered or unordered list indentation. The insertion runs from the command palette, or expands automatically when the triple-dollar or triple-backtick trigger is typed at the end of a line. Empty-line cases are handled, and an optional two-line code-block mode is available.

```cue
plugin: {
    id:     "insert-block-below"
    name:   "Insert Block Below"
    author: "homura144"
    repo:   "homura144/obsidian-insert-block-below"

    html_url:    "https://community.obsidian.md/plugins/insert-block-below"
    github_url:  "https://github.com/homura144/obsidian-insert-block-below"
    description: "Insert math blocks and code fences below the current line with list, quote, and callout aware indentation. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert math blocks and code fences below the current line while preserving blockquote, callout, and ordered/unordered list indentation. Trigger via command palette or auto-expand by typing $$$ or ``` at a line end; supports empty-line cases and an optional two-line code-block mode."
