# Twine

Syncs the vault to an S3-compatible object store such as Cloudflare R2 or Backblaze B2, end-to-end encrypted and with no server of its own. File contents and paths are encrypted on the client, conflicting edits and versions are preserved, and sync runs on file changes and when the app resumes.
