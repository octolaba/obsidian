# Floor notes

Presents one Markdown file as a forum-style thread, keeping every floor and reply as plain Markdown in the vault. Floors and replies are added, edited, deleted, sorted and marked as favorites. Four layouts are available, writing and preview modes switch with local draft saving, and either bundled or Obsidian themes are applied.
