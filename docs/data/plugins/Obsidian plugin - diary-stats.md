# Diary Stats

Draws charts for weekly, monthly and yearly notes from a single code block, taking the period from the note's frontmatter. Panels include project donuts, activity over time, four-week splits, task-status breakdowns and key metrics with sparklines and change against the prior period. Optional goal panels compare plan with actual, and all of it is built from dated session notes and task markers already written in the vault.

```cue
plugin: {
    id:     "diary-stats"
    name:   "Diary Stats"
    author: "mikagosz"
    repo:   "mikagosz/obsidian-diary-stats"

    html_url:    "https://community.obsidian.md/plugins/diary-stats"
    github_url:  "https://github.com/mikagosz/obsidian-diary-stats"
    description: "Charts for periodic notes: how sessions were spread over time, which projects took the period, task states, and goal progress. Reads the notes you already write. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Draw charts for weekly, monthly and yearly notes with a single code block, using the note's frontmatter to determine the period. Show project donuts, activity-over-time, four-week splits, task-status breakdowns, key metrics with sparklines and change vs prior period, and optional goal plan-vs-actual panels based on your dated session notes and task markers."

    stats: {
        downloads:  14
        updated_at: 1786353015000
    }
}
```
