# QuickLink

Inserts links to files from an @ trigger character, with suggestion rules narrowed by folder, regular expression or tag. A document scan replaces matching text with internal links or with advanced-uri links. Suggestions and scans are confined to defined main folders and skip excluded paths.

```cue
plugin: {
    id:     "quicklink"
    name:   "QuickLink"
    author: "jamailar"
    repo:   "jamailar/QuickLink-Obsidian"

    html_url:    "https://community.obsidian.md/plugins/quicklink"
    github_url:  "https://github.com/jamailar/QuickLink-Obsidian"
    description: "Quickly create links to files using @ trigger character"
    about:       "Insert intelligent file links using trigger characters and customizable suggestion rules, including folder, regex, and tag filters. Scan documents to auto-replace matching text with internal links or obsidian://advanced-uri links. Limit suggestions and scans to defined main folders and excluded paths."

    stats: {

}
```
