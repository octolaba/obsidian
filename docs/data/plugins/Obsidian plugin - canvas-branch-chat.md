# Canvas Branch Chat

Canvas Branch Chat creates branching AI conversations on Obsidian Canvas in the style of Flowith. A conversation can be forked from any node, each direction labeled and each branch given its own AI context. The result is a color-coded conversation map that can be navigated and exported as structured Markdown.
