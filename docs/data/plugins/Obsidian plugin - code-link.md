# Code Link

Links notes to code files the way they link to other notes, referencing a particular class, function or method rather than a whole file. Projects are imported and symbols or tags searched, and hover or embed previews show only the referenced snippet inline.

```cue
plugin: {
    id:     "code-link"
    name:   "Code Link"
    author: "observerw"
    repo:   "observerw/obsidian-code-link"

    html_url:    "https://community.obsidian.md/plugins/code-link"
    github_url:  "https://github.com/observerw/obsidian-code-link"
    description: "Link to code files in your notes"
    about:       "Link to code files like notes and preview only the parts you care about, referencing specific classes, functions, or methods. Import projects, search symbols or tags, and use hover or embed previews to display focused code snippets inline."

    stats: {
        downloads:  946
        updated_at: 1730019174000
    }
}
```
