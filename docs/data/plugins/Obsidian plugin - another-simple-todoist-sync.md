# Another Simple Todoist Sync

Syncs tasks between Obsidian and Todoist, so tasks created, edited or deleted in Obsidian carry over along with due dates, times, labels, reminders, priorities and completion status. Todoist-only fields such as comments are preserved, and specific metadata can sync one way or in both directions. It is a fork of an earlier Todoist Sync plugin.
