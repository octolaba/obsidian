# Desktop Dashboard

Replaces the startup screen with a desktop-first dashboard laid out in two columns with an interactive calendar and a timeline. Dates are parsed from YAML, filenames and folder paths so that ordering survives syncing, traditional serif typography and Chinese almanac indicators are displayed, and a quick-capture modal adds notes.
