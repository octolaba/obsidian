# Quick Preview

Previews a suggestion before it is selected: link suggestions, Quick Switcher results and Canvas note or media suggestions are shown while Alt or Option is held. An API lets other plugins add quick-preview support to their own suggestion lists.

```cue
plugin: {
    id:     "quick-preview"
    name:   "Quick Preview"
    author: "ryotaushio"
    repo:   "ryotaushio/obsidian-quick-preview"

    html_url:    "https://community.obsidian.md/plugins/quick-preview"
    github_url:  "https://github.com/ryotaushio/obsidian-quick-preview"
    description: "Quickly preview a suggestion before selecting it in link suggestions & quick switcher."
    about:       "Preview link suggestions, Quick Switcher results, and Canvas note/media suggestions by holding Alt/Option to view content before opening it. Enable other plugins to add quick-preview support via a simple API."

    stats: {
        downloads:  11331
        updated_at: 1717657297000
    }
}
```
