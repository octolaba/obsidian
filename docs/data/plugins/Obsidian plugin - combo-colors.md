# Combo Colors

Combo Colors renders fighting-game combo notation as color-coded icons or styled text, using the Arc System Works, Traditional and Modern preset profiles or custom profiles of your own. Each profile defines its own colors and notation inputs, and text and icon modes are toggled inline.
