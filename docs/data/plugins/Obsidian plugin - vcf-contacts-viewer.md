# VCF Contacts Viewer

VCF Contacts Viewer opens .vcf files in a dedicated read-only view, showing each vCard as a contact card or as raw source with line numbers. Names, organizations, emails and phones are searchable, and import-preflight warnings flag malformed, unsupported, folded-line, encoded or version-mismatched fields. PHOTO data is kept private, and the plugin makes no network requests and never imports, exports or writes to .vcf files.

    about:       "Open .vcf files in a dedicated view and inspect vCards as contact cards or raw source with line numbers. Keep PHOTO data private and stay read-only — no network requests, imports, exports, or writes to .vcf files."
