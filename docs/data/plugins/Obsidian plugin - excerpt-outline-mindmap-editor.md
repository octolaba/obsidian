# Excerpt-Outline-Mindmap-Editor

Shows a Markdown outline as a mindmap whose nodes can be dragged, with each node corresponding to a list item and children moving with their parent. Hover controls add a sibling or a child node and delete a node with or without its descendants. The underlying file stays a standard Markdown outline, so native Obsidian handling is preserved.
