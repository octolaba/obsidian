# Custom Badges

Renders inline badges in notes from a bracketed key and value marker, with a shorthand form for the built-in types. Badge types, their icons and their colors are user-definable, and any Lucide icon name can be used. GitHub-style variants provide compact status styling.

```cue
plugin: {
    id:     "custom-badges"
    name:   "Custom Badges"
    author: "AbbaraS"
    repo:   "abbaras/custom-badges"

    html_url:    "https://community.obsidian.md/plugins/custom-badges"
    github_url:  "https://github.com/abbaras/custom-badges"
    description: "Add inline badges/callouts to notes, with user-definable badge types, icons and colors. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display inline badges in notes with custom types, icons, and colors. Create badges with [!!KEY:VAL] or shorthand for built-ins, use any Lucide icon name, and apply GitHub-style variants for compact status styling."

    stats: {
        downloads:  33
        updated_at: 1786002603000
    }
}
```
