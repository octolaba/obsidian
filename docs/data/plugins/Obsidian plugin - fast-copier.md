# Fast Copier

Adds a copy button beside formatted text in both Editing and Reading modes, covering inline code, bold, italic and underline, highlights, headings, tags and internal and external links. Clicking copies the exact content, with tags keeping their leading hash character. Button visibility can be toggled with a command, the icon is configurable, an optional notification confirms the copy, and there are no external dependencies.
