# Outlook Meeting Notes

Creates meeting notes from Outlook appointments and meetings by dragging a meeting from the Outlook desktop app onto an Obsidian ribbon icon, which reads the .msg file. The generated note is prefilled with date and time, subject, recipients and the invite message through a customizable template, and its filename is based on the meeting date and time. The recorded description states that no Outlook add-in and no Microsoft Graph access are required.
