# Sidet

Opens an AI chat workspace in a dedicated tab, with sessions managed in the sidebar through search, folders, pinning and export. Notes, selections, webpages and images are dragged into a conversation as context. Output is previewed and then written back as a new note, appended to an existing one, or used to overwrite it, and chats can be sunk into a folder with an Index.md.
