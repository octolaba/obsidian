# CSDN Sync

Opens the active note in the CSDN Markdown editor and fills in its title and Markdown body, uploading local images through a local bridge and a companion Chrome extension. It requires Obsidian on the desktop with Chrome signed into CSDN, and the draft is reviewed and then saved or published manually in CSDN.

```cue
plugin: {
    id:     "csdn-sync"
    name:   "CSDN Sync"
    author: "Julien Lin"
    repo:   "jul1en-lin/obsidian-plugin-csdnsync"

    html_url:    "https://community.obsidian.md/plugins/csdn-sync"
    github_url:  "https://github.com/jul1en-lin/obsidian-plugin-csdnsync"
    description: "Open the current note in the CSDN Markdown editor and fill it through a local Chrome extension bridge. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open the active Obsidian note in the CSDN Markdown editor and auto-fill the title, Markdown body, and upload local images via a local bridge and companion Chrome extension. Use Obsidian desktop with Chrome signed into CSDN, then review and save or publish the draft manually in CSDN."
```
