# Vault Script Runner

Runs configured local scripts from Obsidian, prompting for their parameters. Scripts come from a version-tracked JSON catalog that can be discovered and downloaded on demand, installed versions and updates are tracked, and presets expand template variables such as the vault and script paths. The recorded About states that it is desktop-only.

```cue

    id:     "vault-script-runner"
    name:   "Vault Script Runner"
    author: "Joscha Bisping"

    html_url:    "https://community.obsidian.md/plugins/vault-script-runner"
    github_url:  "https://github.com/jlb-jlb/vault-script-runner"
```
