# UseSemaLogic

UseSemaLogic brings the SemaLogic formal language into Obsidian, converting between natural, technical and practical representations of logic without losing the relationships between them. The technical language and diagrams are displayed in realtime, SemaLogic commands can be previewed as HTML, and a problem can be sent to a SemaLogic service to be solved.
