# Bridge Control

Bridge Control decides which folders an external Obsidian Bridge runtime may read from or propose writes to. A searchable visual picker offers separate read and write toggles with recursive coverage of parent folders, plus save-and-verify checks and CLI diagnostics. The recorded inputs state that note bodies stay local.
