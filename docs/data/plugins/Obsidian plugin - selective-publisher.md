# Selective Publisher

Selective Publisher publishes chosen notes and their attachments to a Git repository. Which notes are published is decided by filters on tag, frontmatter, folder, title, path or content, combined with logical operators, and the changed files can optionally be reviewed before the push.

```cue
plugin: {
    id:     "selective-publisher"
    name:   "Selective Publisher"
    author: "ivan1248"
    repo:   "ivan1248/obsidian-selective-publisher"

    html_url:    "https://community.obsidian.md/plugins/selective-publisher"
    github_url:  "https://github.com/ivan1248/obsidian-selective-publisher"
    description: "Selectively publishes notes to a Git repository. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Publishes notes and attachments to a Git repository using filters by tag, frontmatter, folder, title, path, or content combined with logical operators. Optionally, review changed files before pushing to the target repository."

    stats: {
        downloads:  89
        updated_at: 1778608779000
    }
}
```
