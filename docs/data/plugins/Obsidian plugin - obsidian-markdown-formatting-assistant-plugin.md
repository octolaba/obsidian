# Markdown Formatting Assistant

This plugin adds a formatting sidebar that inserts ready-made Markdown, HTML and LaTeX snippets and callouts from a customizable side panel. A color picker with history lets colors be chosen and saved. A quick suggestion window, bound to Alt+Q by default, searches and applies commands without leaving the keyboard, and LaTeX symbols can be inserted inside inline or display math sections.
