# Just Another Hotkey Addon

Adds a collection of hotkeys for text editing, selection, navigation and section management. Sections can be moved and reordered, ranges and headings selected including parent and child levels, and heading levels jumped between. Dedicated commands also edit the display text of a link.

```cue
plugin: {
    id:     "just-another-hotkey-addon"
    name:   "Just Another Hotkey Addon"
    author: "chern-kp"
    repo:   "chern-kp/JustAnotherHotkeyAddon"

    html_url:    "https://community.obsidian.md/plugins/just-another-hotkey-addon"
    github_url:  "https://github.com/chern-kp/JustAnotherHotkeyAddon"
    description: "New useful hotkeys for text editing and several additional features - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add a collection of hotkeys for text editing, selection, navigation, and section management in Obsidian. Move and reorder sections, select ranges and headings (including parent/child levels), jump between heading levels, and quickly edit link display text with dedicated commands."

    }
```
