# GDScript Syntax Highlighting

Highlights GDScript inside fenced code blocks labeled gdscript. The coloring is applied live so that Godot's GDScript is easier to read and edit inside a note.

```cue
plugin: {
    id:     "gdscript-syntax-highlighting"
    name:   "GDScript Syntax Highlighting"
    author: "robthefivenine"
    repo:   "robthefivenine/obsidian-gdscript"

    html_url:    "https://community.obsidian.md/plugins/gdscript-syntax-highlighting"
    github_url:  "https://github.com/robthefivenine/obsidian-gdscript"
    description: "Add live GDScript syntax highlighting to code block."
    about:       "Highlight GDScript code blocks using fenced code blocks labeled gdscript. Apply live, accurate syntax coloring for Godot's GDScript to improve readability and editing inside notes."

    stats: {
        downloads:  5725
        updated_at: 1768430585000
    }
}
```
