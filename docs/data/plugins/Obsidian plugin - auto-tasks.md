# Auto Tasks

Auto Tasks carries incomplete tasks over from previous daily or weekly periodic notes into the new note, so TODO lists stay current; it requires the Periodic Notes and Tasks plugins. A tasks header can be inserted, original dates preserved as due dates and specific headers searched, and tasks collected from across the vault into a synced Kanban board.

```cue
plugin: {
    id:     "auto-tasks"
    name:   "Auto Tasks"
    author: "jamiefdhurst"
    repo:   "jamiefdhurst/obsidian-auto-tasks"

    html_url:    "https://community.obsidian.md/plugins/auto-tasks"
    github_url:  "https://github.com/jamiefdhurst/obsidian-auto-tasks"
    description: "Combine periodic notes with tags and tasks to automatically manage your daily, weekly and project TODO lists. Requires the Periodic Notes and Tasks plugins."
    about:       "Carry over incomplete tasks from previous daily or weekly periodic notes into new notes to keep TODOs current. Insert a tasks header, preserve original dates as due dates, search specific headers, and collect tasks across your vault into a synced Kanban board."

    stats: {
        downloads:  6684
        updated_at: 1784796463000
    }
}
```
