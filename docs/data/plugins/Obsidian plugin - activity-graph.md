# Activity Graph

Activity Graph renders GitHub-style activity heatmaps from Dataview query results, plotting daily activity or numeric metrics across a rolling date range. Queries supply date and value output, and per-query overrides adjust the range, colors, labels and value scale. Dataview is required.
