# Quick Bookmarks

Searches Obsidian bookmarks through a fuzzy-search modal covering files, folders, saved searches and bookmark groups. Nested groups are navigated with breadcrumb paths, and the view switches between separate and flattened groups. Per-group commands are created, and individual bookmarks are hidden from results.

```cue
plugin: {
    id:     "quick-bookmarks"
    name:   "Quick Bookmarks"
    author: "Kieran Mansfield"
    repo:   "kieranmansfield/obsidian-quick-bookmarks"

    html_url:    "https://community.obsidian.md/plugins/quick-bookmarks"
    github_url:  "https://github.com/kieranmansfield/obsidian-quick-bookmarks"
    description: "Quickly access bookmarks through a fuzzy search modal. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Search your Obsidian bookmarks with a fuzzy-search modal that finds files, folders, saved searches, and bookmark groups. Navigate nested groups with breadcrumb paths, switch between separate or flattened group views, create per-group commands, and hide bookmarks from results for cleaner access."

    stats: {
        downloads:  1054
```
