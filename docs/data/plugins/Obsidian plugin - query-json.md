# Query JSON

Reads and queries JSON held inline in a note or in external files, addressed through a simple path notation and @ references. Queries filter with logical and comparison operators, use array wildcards, and substitute values from frontmatter. Results are displayed as JSON, lists, tables or images, and expand live as the query is typed.
