# File Order

File Order defines a custom order for files and folders through number prefixes in their names, and that order is changed by dragging items in the file explorer. Because the order lives in the filenames it persists after uninstalling, and all links are updated automatically when a name changes. Clearing the custom prefixes restores the default sorting.
