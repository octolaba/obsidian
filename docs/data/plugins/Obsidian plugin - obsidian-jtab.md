# jTab Guitar Codeblocks

Renders guitar chords and tabs inline from jtab code blocks using the jTab library. Chords and tabs are auto-detected, several lines are allowed in one block, and markdown lines may sit inside the block. Quick jtab-examples and jtab-chords views and customizable color schemes with live preview are included.

    id:     "obsidian-jtab"
