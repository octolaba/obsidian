# Nested Properties

Nested Properties renders nested YAML frontmatter as a collapsible tree inside Obsidian's Properties editor, so nested keys can be viewed and edited there. Branches collapse and expand, context-menu actions cover cut, copy, paste and remove, properties can be added at any nesting level, and deep structures scroll horizontally.

```cue
plugin: {
    id:     "nested-properties"
    name:   "Nested Properties"
    author: "Michael Naumov"
    repo:   "mnaoumov/obsidian-nested-properties"

    html_url:    "https://community.obsidian.md/plugins/nested-properties"
    github_url:  "https://github.com/mnaoumov/obsidian-nested-properties"
    description: "Allows to view/edit nested frontmatter properties. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "View and edit nested YAML frontmatter as a collapsible tree inside the Properties editor. Collapse or expand branches, use context menu actions (cut, copy, paste, remove), add properties at any nesting level, and scroll horizontally for deep structures."
```
