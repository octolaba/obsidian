# Palette Vault

Generates color palettes and renders palette blocks in notes, with hex codes previewed inline and copied in one click. Dominant colors can be extracted from images in the vault, and an eyedropper picks any pixel on screen. Inline swatches show RGB, HSL and OKLCH values along with contrast information.
