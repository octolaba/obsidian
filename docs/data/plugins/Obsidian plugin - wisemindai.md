# WiseMindAI

Connects Obsidian to the WiseMindAI desktop application so that selected notes or passages can be summarised, rewritten, expanded or discussed in a chat. Knowledge cards, templates and ideas are generated from the same material, and Markdown is synchronised in both directions between the application and the vault. Output is inserted into the current note, saved as a new note, copied to the clipboard, or carried on in the conversation.
