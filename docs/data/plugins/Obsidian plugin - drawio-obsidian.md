# Diagrams

Creates and edits draw.io diagrams inside Obsidian, either embedded in notes or stored as standalone files. Diagrams are saved as SVG or .drawio and can be inserted into a note or reopened later for further editing.

```cue
plugin: {
    id:     "drawio-obsidian"
    name:   "Diagrams"
    author: "zapthedingbat"
    repo:   "zapthedingbat/drawio-obsidian"

    html_url:    "https://community.obsidian.md/plugins/drawio-obsidian"
    github_url:  "https://github.com/zapthedingbat/drawio-obsidian"
    description: "Create and edit Draw.io diagrams."
    about:       "Create and edit draw.io diagrams inside Obsidian, embedding them in notes or storing them as standalone files. Save diagrams as SVG or .drawio and insert or reopen them for further editing."

    stats: {
        downloads:  210127
        updated_at: 1737350413000
    }
}
```
