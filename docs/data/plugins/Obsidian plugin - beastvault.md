# BeastVault

BeastVault manages adversary and environment stat blocks for the Daggerheart tabletop role-playing game, taken from the SRD or a homebrew library and searchable, creatable and editable in the vault. Stat blocks render as editable formatted cards with one-click attack and damage rolls, tracking for HP, stress, countdowns and feature uses, summon buttons and condition markers. Battle points appear in the status bar, and Canvas is supported for building encounters.
