# I Will Never Leave the Graph View

Lets notes be previewed, edited and created without leaving the graph view, using a companion sidebar pane. Hovering a node shows a preview, clicking one opens it for editing in the pane, and clicking a greyed node creates a note at that node's position. Active graph filters are respected.
