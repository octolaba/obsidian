# Substitutions

Text fragments typed in the editor are replaced with symbols or other text, with defaults such as an arrow written from a hyphen pair and a fraction written as one half. Built-in and custom rules are managed and edited, and regular-expression patterns can match text ending at the cursor. Substitution applies only while typing directly, not retroactively and not to pasted content.
