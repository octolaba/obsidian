# Document Exporter

Exports notes, folders or query results as Markdown bundles, standalone HTML documents with a table of contents, or print-ready HTML aimed at browser-to-PDF printing. A bundle combines the selected notes into a single Markdown file with attachments copied and links rewritten, while the HTML output is self-contained with linked assets.
