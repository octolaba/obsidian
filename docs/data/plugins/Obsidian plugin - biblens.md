# BibLens

BibLens detects Bible references in Markdown notes and shows the verse or passage text as a hover preview in the editor, Live Preview and Reading View. Verse text can be inserted after a reference or a reference replaced with a blockquote, and downloadable translations and language packs let the plugin work fully offline.

```cue
plugin: {
    id:     "biblens"
    name:   "BibLens"
    author: "marekpola"
    repo:   "marekpola/obsidian-biblens"

    html_url:    "https://community.obsidian.md/plugins/biblens"
    github_url:  "https://github.com/marekpola/obsidian-biblens"
    description: "Detects Bible references, displays verse or passage text on hover, and lets you insert it into your note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Detect Bible references in your Markdown notes and show verse text as a hover preview in the editor, Live Preview and Reading View. Insert verse text after a reference or replace a reference with a blockquote, and use downloadable translations and language packs to work fully offline."
```
