# Markmind

This closed-source plugin provides mind maps, outlines and PDF annotation. Maps are created in Basic and Rich modes, embedded in notes as boards, and rich maps can be converted to Markdown. It also annotates and exports PDFs, accepts dragged-and-dropped images, copies and pastes nodes, and allows links, inline styles, multiline text, code and KaTeX inside nodes.
