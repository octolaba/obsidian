# Git History

Manages Git from inside Obsidian: staging, committing, pushing, pulling, fetching, stashing, switching branches and discarding changes at file or folder level. A commit graph and table show commit metadata, file history is followed across renames, and diffs are shown side by side or inline with syntax highlighting.

```cue
plugin: {
    id:     "git-history"
    name:   "Git History"
    author: "Chris Oguntolu"
    repo:   "chrisurf/obsidian-git-history"

    html_url:    "https://community.obsidian.md/plugins/git-history"
    github_url:  "https://github.com/chrisurf/obsidian-git-history"

Browse a GitLens-style commit graph and table with metadata, inspect file history across renames, and view syntax-highlighted side-by-side or inline diffs."
