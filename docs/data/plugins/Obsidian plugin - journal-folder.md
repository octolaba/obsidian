# Journal Folder

Journal Folder turns any folder in the vault into a journal, keyed on fixed filename formats for daily, weekly, monthly and yearly notes, so several separate journals can coexist for different projects or clients. A code-block processor renders structured journal headers. The vault root is documented as unsuitable for use as a journal folder.

```cue
plugin: {
    id:     "journal-folder"
    name:   "Journal Folder"
    author: "chfourie"
    repo:   "chfourie/obsidian-journal-folder"

    html_url:    "https://community.obsidian.md/plugins/journal-folder"
    github_url:  "https://github.com/chfourie/obsidian-journal-folder"
    description: "Utilities for folder-based journaling."
    about:       "Use any folder in your vault as a journal by following fixed filename formats for daily, weekly, monthly, and yearly notes to maintain multiple, separate journals (project, client, etc.). Render structured journal headers via a code-block processor and do not use the vault root as a journal folder."

    stats: {
        downloads:  3362

    }
}
```
