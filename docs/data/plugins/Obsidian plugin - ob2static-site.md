# Static Site MD Exporter

Exports the notes marked with published: true in their front matter to plain Markdown for a static site generator such as Hugo, Hexo or Astro, converting wiki links and image embeds into standard Markdown and leaving the vault files untouched. Tags are merged into the front matter, and the generated files can be uploaded to a chosen folder in a Git repository.

```cue
plugin: {
    id:     "ob2static-site"
    name:   "Static Site MD Exporter"
    author: "yy4382"
    repo:   "yy4382/obsidian-static-site-export"

    html_url:    "https://community.obsidian.md/plugins/ob2static-site"
    github_url:  "https://github.com/yy4382/obsidian-static-site-export"
```
