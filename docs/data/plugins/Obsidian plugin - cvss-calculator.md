# CVSS 3.1 Calculator

Computes CVSS 3.1 scores in a single wide modal that shows all eight base metrics and updates the score as options are selected. The full vector can be copied or the score inserted into the note, the CVSS frontmatter of the current note or of open findings updated, and a color-coded severity badge shown. Privileges Required weights are adjusted automatically when Scope changes, as CVSS 3.1 prescribes.
