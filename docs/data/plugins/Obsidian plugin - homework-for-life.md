# Homework for Life

Homework for Life captures a daily story-worthy moment through a click, a command or a URI and appends it to a single monthly Markdown file. A multi-line modal merges several captures into the same day's row or heading, and the output is written either as a table or as headings with bullets, with dates written as dated links. The recorded inputs credit the method to Matthew Dicks.
