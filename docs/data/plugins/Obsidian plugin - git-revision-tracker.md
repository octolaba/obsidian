# Git Revision Tracker

Analyses Git commits to classify changes as additions, deletions or true revisions, using word-frequency comparison and word-level Levenshtein diffs. It reports net word change, gross work volume and revision effort through overview, per-commit and daily heatmap views, with configurable weighting and filters by file and author.
