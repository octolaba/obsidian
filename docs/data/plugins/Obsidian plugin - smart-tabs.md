# Smart Tabs

Files open in a new tab by default, and an optional deduplication step focuses an already-open tab instead of creating a second one. The behaviour applies across the file explorer, Quick Switcher, internal links, bookmarks and API calls, and covers Markdown, canvas, image, audio, video and PDF files. A processing delay is adjustable to match the system.
