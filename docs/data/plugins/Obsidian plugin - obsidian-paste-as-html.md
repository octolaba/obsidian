# Paste As Html

This plugin pastes HTML copied from a web browser into notes as formatted HTML. The original CSS styles and structure are retained, so the pasted web content appears as it did on the source page.

```cue
plugin: {
    id:     "obsidian-paste-as-html"
    name:   "Paste As Html"
    author: "maotong06"
    repo:   "maotong06/obsidian-paste-as-html-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-paste-as-html"
    github_url:  "https://github.com/maotong06/obsidian-paste-as-html-plugin"
    description: "Paste As HTML, Keep the original CSS style. Paste from web browser."
    about:       "Paste HTML copied from a browser into Obsidian notes as formatted HTML. Retain original CSS styles and structure so web content appears like the source page."

    stats: {
        downloads:  13548
        updated_at: 1672389503000
    }
}
```
