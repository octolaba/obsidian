# Draw a Mermaid

Builds mermaid flowcharts visually on a canvas inside Obsidian, where blocks and connectors are dragged into place and renamed inline while the mermaid code is generated from them. A live preview renders as the chart is built, and an editor is attached to mermaid code blocks alongside a ribbon button.
