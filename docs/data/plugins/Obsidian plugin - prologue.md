# Prologue

Displays a random note, quote, or reminder each time a new tab is opened. Entries come from a generated collection.md file in the vault, where items are separated by blank lines, and a different collection can be chosen in the settings.

```cue
plugin: {
    id:     "prologue"
    name:   "Prologue"
    author: "joshavanier"
    repo:   "joshavanier/prologue"

    html_url:    "https://community.obsidian.md/plugins/prologue"
    github_url:  "https://github.com/joshavanier/prologue"
    description: "Display a random quote or reminder on the new tab page."
    about:       "Display a random note, quote, or reminder each time you open a new tab. Source entries from a generated collection.md in your vault—add items separated by blank lines and choose a different collection in settings."

    stats: {
        downloads:  535
        updated_at: 1759805389000
    }
}
```
