# Waypoint

Generates a table of contents inside a folder note wherever a waypoint marker is placed. The generated links update automatically when files are created, moved, renamed or deleted, and files in subfolders can be included. Nested waypoints prevent redundant links, and the result makes folders appear in the graph view.

```cue
plugin: {
    id:     "waypoint"
    name:   "Waypoint"
    author: "Idrees"
    repo:   "idreesinc/Waypoint"

    html_url:    "https://community.obsidian.md/plugins/waypoint"
    github_url:  "https://github.com/idreesinc/Waypoint"
    description: "Easily generate dynamic MOCs in your folder notes using waypoints. Enables folders to show up in the graph view and removes the need for messy tags!"
    about:       "Generate automatic tables of contents inside folder notes by inserting a waypoint marker. Auto-update links when files are created, moved, renamed, or deleted; include files in subfolders, nest waypoints to prevent redundant links, and expose folders in the graph view."
```
