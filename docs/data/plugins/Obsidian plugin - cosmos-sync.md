# Cosmos

Cosmos maps the structure of each file, its length, density and form, onto bodies in a solar system such as planets, moons, asteroids and comets. The transforms are cryptographic, one-way and run on the device, so only the resulting orbital parameters of size, mass, eccentricity and color leave the machine and the words themselves do not.
