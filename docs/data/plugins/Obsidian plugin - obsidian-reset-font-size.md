# Reset Font Size

This plugin adds a button and a command that reset the note font size, and optionally the global window zoom, back to a configurable default value. The command can be bound to a hotkey or run from the command palette to recover from accidental zooming.

```cue
plugin: {
    id:     "obsidian-reset-font-size"
    name:   "Reset Font Size"
    author: "luckman212"
    repo:   "luckman212/obsidian-reset-font-size"

    html_url:    "https://community.obsidian.md/plugins/obsidian-reset-font-size"
    github_url:  "https://github.com/luckman212/obsidian-reset-font-size"
```
