# Quick Editing

Applies Markdown edits from within the editor: symbol completion, a format brush, a smart paste that converts HTML and Office tables, and internal link generation. Batch cleanups handle punctuation, spacing, blank lines and images while respecting Markdown context, and each run offers a preview of the changes and a single-action undo.
