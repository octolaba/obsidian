# Web Card

Turns a copied web highlight into a styled card, detecting the source URL and the page title and including them in the card. The layout can be a callout, a code block or an embed, and the card is inserted either straight from the clipboard or from the current selection.

```cue
plugin: {
    id:     "web-card"
    name:   "Web Card"
    author: "xuxiaominger2024"
    repo:   "xuxiaominger/obsidian-web-card"

    html_url:    "https://community.obsidian.md/plugins/web-card"
    github_url:  "https://github.com/xuxiaominger/obsidian-web-card"
    description: "Paste web highlights into beautiful info cards — 一键粘贴网页高亮为精美信息卡片 - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert copied web highlights into styled cards that auto-detect and include the source URL and page title. Switch between callout, code block, or embed layouts and insert cards directly from the clipboard or from selected text."

    stats: {
        downloads:  9
        updated_at: 1784794298000
    }
}
```
