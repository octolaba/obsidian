# Weekly Music Practice Planner

Plans and tracks weekly music practice in a single Markdown note per week, holding a goals section, a skills by days tracking table, and per-day note sections. Any week's plan is opened or created from the Command Palette, with navigation to the previous and next weeks, and notes are stored by the week's start year and week number.
