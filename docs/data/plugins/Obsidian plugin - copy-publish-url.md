# Publish and GitHub URL

Publish and GitHub URL copies the URL of a note on an Obsidian Publish site and can open the published note in the browser. An optional file-menu command copies those URLs directly from the file list. It can also open the note's Git commit history on GitHub, which requires the repository URL and branch to be configured.

```cue
plugin: {
    id:     "copy-publish-url"
    name:   "Publish and GitHub URL"
    author: "kometenstaub"
    repo:   "kometenstaub/copy-publish-url"

    html_url:    "https://community.obsidian.md/plugins/copy-publish-url"
    github_url:  "https://github.com/kometenstaub/copy-publish-url"
    description: "Copy or open the URL of the corresponding note on your Publish site. You can also open its Git commit history on GitHub."
    about:       "Copy the URL of any note on your Obsidian Publish site. Open the current note on the published site in your browser and add an optional file-menu command to copy URLs. Open the note's Git commit history on GitHub (requires repository URL and branch)."

    stats: {
        downloads:  6611
        updated_at: 1682792451000
    }
}
```
