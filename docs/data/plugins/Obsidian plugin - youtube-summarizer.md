# Youtube Summarizer

Downloads the transcript of a YouTube video and summarizes it with OpenAI's ChatGPT-3.5, extracting the key points. Long transcripts are split into chunks, and the output is written as a clean note ready to save in the vault.

```cue
plugin: {
    id:     "youtube-summarizer"
    name:   "Youtube Summarizer"
    author: "ozdemir08"
    repo:   "ozdemir08/youtube-video-summarizer"

    html_url:    "https://community.obsidian.md/plugins/youtube-summarizer"
    github_url:  "https://github.com/ozdemir08/youtube-video-summarizer"
    description: "Summarize Youtube videos using ChatGPT 3.5."
    about:       "Download YouTube transcripts and use OpenAI's ChatGPT-3.5 to extract key points into a concise summary. Chunk long transcripts and output clean, ready-to-save Obsidian notes for quick review and knowledge capture."

    stats: {
        downloads:  6674
        updated_at: 1707911533000
    }
}
```
