# Initiative Tracker

Tracks initiative and turn order for tabletop RPG combat. Creatures and NPCs are added by name, dice roll or bestiary entry, and the tracker manages HP, AC and status, groups duplicates, calculates XP and sorts by initiative. Several encounters can be run from a single code block.
