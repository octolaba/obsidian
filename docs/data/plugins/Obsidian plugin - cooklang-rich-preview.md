# Cooklang Rich Preview

Cooklang Rich Preview renders Cooklang recipe files with ingredients, cookware and timers highlighted, showing inline quantities and checkboxes. The output is section-aware and includes YAML frontmatter metadata and numbered directions, with syntax highlighting for Cooklang and plain-text recipes.

```cue
plugin: {
    id:     "cooklang-rich-preview"
    name:   "Cooklang Rich Preview"
    author: "shepherdjerred"
    repo:   "shepherdjerred/cooklang-for-obsidian"

    html_url:    "https://community.obsidian.md/plugins/cooklang-rich-preview"
    github_url:  "https://github.com/shepherdjerred/cooklang-for-obsidian"
    description: "Preview Cooklang .cook files. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Preview Cooklang .cook recipes with rich rendering that highlights ingredients, cookware, timers, and shows inline quantities and checkboxes. Render section-aware output with YAML frontmatter metadata, numbered directions, and syntax highlighting for Cooklang and plain-text recipes."

    stats: {
        downloads:  454
        updated_at: 1785542978000
    }
}
```
