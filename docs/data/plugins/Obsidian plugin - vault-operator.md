# Vault Operator

Runs an AI agent over the vault that uses the existing plugins, skills and tools and adds new ones as a task requires. The recorded About lists planning, semantic vault search, reading and editing notes, ingesting research papers and linking them into notes, generating PPTX, DOCX and XLSX, browsing the web, connecting to any MCP server, and building structures with Canvas, Bases, Draw.io, Dataview, Excalidraw and Tasks. The model is brought by the user — Anthropic, OpenAI, OpenRouter, Bedrock, Gemini, GitHub Copilot or local Ollama and LM Studio — a persistent memory layer records habits and workflows, autonomous multi-agent runs are described as operating under safety controls, and chat history and memory from other AI tools are unified into the vault.
