# GTD Tasks

Organizes Markdown tasks from across the vault in a dedicated panel following the Getting Things Done method, grouping them into time-horizon buckets such as Today, This Week and Someday. Items move between buckets with one-click buttons, drag-and-drop or a context menu, and can be assigned automatically from due dates read from the Tasks plugin. Completion can trigger optional celebration animations.
