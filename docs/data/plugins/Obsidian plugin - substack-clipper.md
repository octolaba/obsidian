# Substack Clipper

Substack posts are archived as Obsidian-flavored Markdown with YAML frontmatter, and images, videos, audio, transcripts and PDFs are downloaded beside the note. Footnotes are converted to standard Markdown footnote syntax and CDN prefixes are stripped. Threaded comments are saved as a separate note that can be embedded, media is embedded so it plays natively, paywalled previews are preserved, and the plugin runs on desktop and on mobile.

```cue
plugin: {
    id:     "substack-clipper"
    name:   "Substack Clipper"
    author: "gapmiss"
    repo:   "gapmiss/substack-clipper"

    html_url:    "https://community.obsidian.md/plugins/substack-clipper"
    github_url:  "https://github.com/gapmiss/substack-clipper"
    description: "Archive Substack posts as Markdown with images, media, and comments. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Archive Substack posts as Obsidian-flavored Markdown with YAML frontmatter, images, media and threaded comments saved alongside the note. Download images, videos, audio, transcripts and PDFs; convert footnotes to standard [^N] Markdown, strip CDN prefixes, save comments as a separate embeddable note with media embedded as ![[wikilink]] for native playback, and preserve paywalled previews on desktop and mobile."

    stats: {
        downloads:  229
        updated_at: 1786054191000
    }
}
```
