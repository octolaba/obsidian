# GitHub Embeds

Embeds GitHub issues, pull requests and file snippets in reader mode wherever such links appear in a note. Issue and pull request previews are rendered, and file snippets honor a line range given in the link. A GitHub personal access token is required for API access and for private repositories.

```cue
plugin: {
    id:     "github-embeds"
    name:   "GitHub Embeds"
    author: "mrgvsv"
    repo:   "mrgvsv/obsidian-github-embeds"

    html_url:    "https://community.obsidian.md/plugins/github-embeds"
    github_url:  "https://github.com/mrgvsv/obsidian-github-embeds"
    description: "Embed GitHub issues, PRs, and code snippets."
    about:       "Embed GitHub issues, pull requests, and file snippets directly in Obsidian when links appear in reader mode. Display issue/PR previews and inline file snippets with line-range support (e.g. #L12-L19). Require a GitHub personal access token for API and private repo access."

    stats: {
        downloads:  7542
        updated_at: 1705784317000
    }
}
```
