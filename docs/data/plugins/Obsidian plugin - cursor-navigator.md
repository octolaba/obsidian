# Cursor Navigator

Remembers and restores the cursor and scroll position of every note so editing resumes where it stopped. A global, deduplicated cursor history is walked with back and forward bindings in the manner of VS Code, tab switches and link jumps are tracked, and invalid entries are cleaned automatically.

```cue
plugin: {
    id:     "cursor-navigator"
    name:   "Cursor Navigator"
    author: "malele"
    repo:   "malelestudyhome/cursor-navigator"

    html_url:    "https://community.obsidian.md/plugins/cursor-navigator"
    github_url:  "https://github.com/malelestudyhome/cursor-navigator"
    description: "Remember cursor position per note + VS Code-style global back/forward cursor navigation history. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Remember and restore cursor and scroll positions for every note to resume editing exactly where you left off. Navigate a global, deduplicated cursor history across notes with VS Code–style back/forward (Alt+← / Alt+→), track tab switches and link jumps, and auto-clean invalid entries."
```
