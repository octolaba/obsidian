# Outlook Teams and Calendar

Syncs Microsoft 365 mail, calendar events and Teams chats and channels into the vault through one Azure app registration using read-only PKCE authentication. Each email, event or conversation becomes a Markdown note with metadata, thread and conversation indexes are kept, upcoming meetings appear in a sidebar, and syncing is incremental. The recorded description states that it runs on desktop only and that the plugin has not been manually reviewed by Obsidian staff.
