# Links with Icons

Shows native operating-system file icons next to wiki-links and local file paths, and website favicons next to external links, in Live Preview and Reading View. The icons are clickable and open their target, they scale with font size and headings, and Lucide icons are used as a fallback when extraction fails.

```cue
plugin: {
    id:     "links-with-icons"
    name:   "Links with Icons"
    author: "radegast546"
    repo:   "radegast546/links-with-icons"

    html_url:    "https://community.obsidian.md/plugins/links-with-icons"
    github_url:  "https://github.com/radegast546/links-with-icons"
    description: "Dynamically shows native OS file icons and website favicons for links in your notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display native OS app icons next to wiki-links and local file paths, and show website favicons for external links in Live Preview and Reading View. Make icons clickable to open targets, scale with font size and headings, and fall back to Lucide icons when extraction fails."

    stats: {
        downloads:  108
        updated_at: 1781295548000
    }
}
```
