# Diagrams.net

Diagrams.net embeds the diagrams.net editor, previously known as draw.io, so diagrams can be inserted and edited with its full shape libraries; the embedded editor requires an internet connection. A diagram is saved as a paired svg.xml editable source and svg image file. The recorded description notes that edits may not refresh an open preview until reload and that a copied diagram needs both files duplicated by hand.

```cue
plugin: {
    id:     "obsidian-diagrams-net"
    name:   "Diagrams.net"
    author: "jensmtg"
    repo:   "jensmtg/obsidian-diagrams-net"

    html_url:    "https://community.obsidian.md/plugins/obsidian-diagrams-net"
    github_url:  "https://github.com/jensmtg/obsidian-diagrams-net"
    description: "Enable diagrams.net (previously draw.io) type diagrams, with the diagrams.net embedded editor."

Save diagrams as paired .svg.xml (editable source) and .svg image files; edits may not refresh the open preview until reload and copied diagrams need manual duplication of both files."
