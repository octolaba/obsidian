# Codex Bridge

Codex Bridge connects the local vault to Codex through a localhost MCP endpoint, letting Codex search, read and write notes without hardcoded paths. Note context is exported and request files created, replies from the bridge are appended to notes or create new ones, and generated summaries land in daily notes with deduplication and automatic tagging.
