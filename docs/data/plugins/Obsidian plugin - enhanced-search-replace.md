# Enhanced search and replace

Opens a search-and-replace panel inside the editor rather than in a separate dialog. Matching supports case sensitivity, whole words and regular expressions, matches are highlighted in the current editor, and Esc closes the panel even when the input is not focused.

```cue
plugin: {
    id:     "enhanced-search-replace"
    name:   "Enhanced search and replace"
    author: "liuhaoxd"
    repo:   "liuhaoxd/obsidian-enhanced-search-replace"

    html_url:    "https://community.obsidian.md/plugins/enhanced-search-replace"
    github_url:  "https://github.com/liuhaoxd/obsidian-enhanced-search-replace"
    description: "Inline editor search and replace panel with match case, whole word, and regex. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open an inline search-and-replace panel inside the editor. Find and replace with match-case, whole-word, and regex support, preview highlighted matches in the current editor, and close the panel with Esc even when the input is not focused."

    stats: {
        downloads:  427
        updated_at: 1776136345000
    }
}
```
