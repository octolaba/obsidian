# Word Progress Bar

Shows a small progress bar in the status bar for a word-count goal. The bar fills in real time as words are written and turns green once the target is reached.

```cue
plugin: {
    id:     "word-progress-bar"
    name:   "Word Progress Bar"
    author: "somenoy"
    repo:   "somenoy/obsidian-word-progress-bar"

    html_url:    "https://community.obsidian.md/plugins/word-progress-bar"
    github_url:  "https://github.com/somenoy/obsidian-word-progress-bar"
    description: "Progress bar in the status bar that shows goal of words. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Track writing progress with a miniature progress bar in the status bar. Set a word-count goal and watch the bar fill in real time, turning green when you hit your target."

    stats: {
        downloads:  167
        updated_at: 1779099928000
    }
}
```
