# Pieces for Developers

Pieces for Developers queries cloud or local LLMs and exposes long-term memory across workflows from inside Obsidian. Pieces Copilot answers over a note or the whole vault, Pieces Drive saves and organises reusable code and materials, and inline quick actions capture and share content. The recorded About text states that the plugin is closed source.
