# Require Final Newline

Require Final Newline appends a final newline on save so files always end with one. The recorded text gives the purpose as preventing missing end-of-file newline issues and editor warnings.

```cue
plugin: {
    id:     "require-final-newline"
    name:   "Require Final Newline"
    author: "nnoodle"
    repo:   "nnoodle/obsidian-require-final-newline"

    html_url:    "https://community.obsidian.md/plugins/require-final-newline"
    github_url:  "https://github.com/nnoodle/obsidian-require-final-newline"
```
