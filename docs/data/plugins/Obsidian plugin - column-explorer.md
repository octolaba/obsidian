# Column Explorer

Column Explorer is a Finder-style file explorer built on Miller columns, opening each folder in an adjacent column. It switches between list and icon views, previews files and images, and offers breadcrumbs and folder colors. File management covers multi-select, drag and drop, file operations and context menus.
