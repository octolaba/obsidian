# Product Backlog

Adds a Product Backlog view to Bases that renders a flat folder of Markdown notes as a sortable work-item tree of Epics, Features, PBIs and Tasks. Hierarchy and ranking are held in frontmatter fields for type, parent and order, so the notes stay flat and editable. Items can be created, dragged to re-rank, and auto-filled from the view.

```cue
plugin: {
    id:     "product-backlog-view"
    name:   "Product Backlog"
    author: "Luis Mendez"
    repo:   "luis85/backlog-view"

    html_url:    "https://community.obsidian.md/plugins/product-backlog-view"
    github_url:  "https://github.com/luis85/backlog-view"
    description: "Display Bases results as a sortable product backlog tree of Epics, Features, PBIs and Tasks with drag-and-drop ranking, inspired by Azure DevOps Boards. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add a Product Backlog view to Bases and turn a flat folder of Markdown notes into a sortable work-item tree (Epic → Feature → PBI → Task). Manage hierarchy via frontmatter (type, parent, order); create, drag, and auto-fill items while keeping notes flat and editable."
```
