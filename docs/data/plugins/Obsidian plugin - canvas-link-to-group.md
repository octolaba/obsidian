# Canvas Link to Group

Canvas Link to Group creates links that point at a specific group in a canvas and jumps to it in one click. Links are copied from the group's context menu or through the command palette. A left click opens the target in the current tab and a Ctrl or Cmd click in a new one, with notifications for missing or duplicate group names.
