# Vault Lens

Previews DOCX, XLSX and PPTX documents and more than sixty code and text file types inside Obsidian, keeping layout, images, tables and spreadsheet formatting. Documents can be zoomed and panned, text and code edited with line numbers and saved back, and multi-sheet workbooks switched by tab.

    id:     "vault-lens"
    name:   "Vault Lens"
    author: "suzhan"

    github_url:  "https://github.com/leo-su-zhan/obsidian-vault-lens"
    description: "Preview docx/xlsx/pptx and 60+ code files (sql/java/py/js/ts/…). Zoom, edit & save, line numbers, XLSX tabs. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Preview DOCX, XLSX, PPTX and 60+ code/text file types directly inside Obsidian, preserving layout, images, tables and spreadsheet formatting. Zoom and pan documents, edit text/code with line numbers and save changes, and switch sheets for multi-sheet Excel files."
