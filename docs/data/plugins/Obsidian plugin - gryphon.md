# Gryphon

Provides a reactive chat surface for Claude inside Obsidian that can read and edit vault files and run tools, using the Anthropic API or an optional local Claude CLI. Guardrails require approval before dangerous files or commands are touched, edits are shown as diffs, and responses stream inline.
