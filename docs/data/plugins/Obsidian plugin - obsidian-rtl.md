# RTL Support

This plugin adds right-to-left text direction support for languages such as Arabic, Hebrew and Farsi. Each note's direction can be set to left-to-right, right-to-left or automatic and is remembered per file, read or written through front matter, with a default for files carrying no explicit setting. The note direction is also applied to Canvas cards for linked notes, while unlinked cards follow the default.

```cue
plugin: {
    id:     "obsidian-rtl"
    name:   "RTL Support"
    author: "esm7"
    repo:   "esm7/obsidian-rtl"

    html_url:    "https://community.obsidian.md/plugins/obsidian-rtl"
    github_url:  "https://github.com/esm7/obsidian-rtl"
    description: "Right-to-left (RTL) text direction support for languages like Arabic, Hebrew, and Farsi."
    about:       "Set individual notes' text direction to LTR, RTL, or Auto and remember it per file. Get or set note direction via front matter and define a default direction for files without explicit settings. Apply note direction to Canvas cards for linked notes; unlinked cards follow the default."
```
