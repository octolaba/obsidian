# Attachment Audit

Scans the vault for genuinely unused attachments, exact duplicates, oversized files, junk-named captures and misplaced files, and previews what a cleanup would reclaim before anything is deleted. Cleanup preserves links and re-validates its actions by cross-checking Markdown, frontmatter and canvas references. Bulk cleanup, saved scan profiles, custom rules and Markdown reports belong to a Pro tier.
