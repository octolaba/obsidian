# LLM workspace

Creates LLM workspaces as notes that link related files and open beside them, so a model can be grounded in a chosen part of the vault. Workspace content is indexed by chunking it and computing embeddings, which backs grounded and debuggable chats and exploratory question generation, and chats can also target a single note or a curated set of sources with customizable models and prompts.
