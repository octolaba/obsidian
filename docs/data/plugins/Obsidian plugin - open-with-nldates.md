# Open with Natural Language Dates

Open with Natural Language Dates opens a daily note by typing a date in natural language instead of searching the calendar or file names. It requires the Natural Language Dates plugin to parse phrases such as next Friday or 3 days from now, then jumps to the matching past or future daily note.

```cue
plugin: {
    id:     "open-with-nldates"
    name:   "Open with Natural Language Dates"
    author: "charliecm"
    repo:   "charliecm/obsidian-open-with-nldates"

    html_url:    "https://community.obsidian.md/plugins/open-with-nldates"
    github_url:  "https://github.com/charliecm/obsidian-open-with-nldates"
    description: "Open a daily note using natural language. Requires \"Natural Language Dates\" plugin to work."
    about:       "Open daily notes by typing natural-language dates instead of searching the calendar or file names. Use the Natural Language Dates plugin to parse phrases like \"next Friday\" or \"3 days from now\" and jump directly to past or future daily notes."

    stats: {
        downloads:  1286
        updated_at: 1729143580000
    }
}
```
