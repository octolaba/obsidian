# Short links

Short links displays internal links to files, notes, headings and blocks in a shortened, compact form. Optional icons at the start or the end of a link indicate its type, and the change applies in both live preview and reading view.

```cue
plugin: {
    id:     "short-internal-links-to-headings"
    name:   "Short links"
    author: "scottwillmoore"
    repo:   "scottwillmoore/obsidian-short-links"

    html_url:    "https://community.obsidian.md/plugins/short-internal-links-to-headings"
    github_url:  "https://github.com/scottwillmoore/obsidian-short-links"
    description: "Display short internal links to files, notes, headings, and blocks."
    about:       "Shorten internal Obsidian links to files, notes, headings, and blocks for a cleaner, compact display. Show optional icons at the start or end of links to indicate type. Apply changes in both live preview and reading view."
```
