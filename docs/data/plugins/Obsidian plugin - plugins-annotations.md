# Plugins Annotations

Adds personal, Markdown-formatted annotations to each installed plugin and displays them beneath the plugin entries in the Community Plugins pane. Annotations may contain Obsidian links, are saved persistently, and can be locked; empty annotation fields can be hidden for a cleaner view.

```cue
plugin: {
    id:     "plugins-annotations"
    name:   "Plugins Annotations"
    author: "alberti42"
    repo:   "alberti42/obsidian-plugins-annotations"

    html_url:    "https://community.obsidian.md/plugins/plugins-annotations"
    github_url:  "https://github.com/alberti42/obsidian-plugins-annotations"
    description: "Allows adding personal comments to each installed plugin."
    about:       "Add personal Markdown-formatted annotations to each installed plugin and display them beneath plugin entries in the Community Plugins pane. Include Obsidian links, save edits persistently, and lock annotations or hide empty annotation fields for a cleaner view."

    stats: {
        downloads:  4702

    }
}
```
