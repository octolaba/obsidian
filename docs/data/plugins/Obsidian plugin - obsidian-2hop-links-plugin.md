# 2Hop Links Plugin

Shows the pages that are two links away from the current note in a section beneath the editor, so they can be previewed without leaving the note. Live Preview is supported, and commands enable the two-hop view or disable it temporarily.

```cue
plugin: {
    id:     "obsidian-2hop-links-plugin"
    name:   "2Hop Links Plugin"
    author: "tokuhirom"
    repo:   "tokuhirom/obsidian-2hop-links-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-2hop-links-plugin"
    github_url:  "https://github.com/tokuhirom/obsidian-2hop-links-plugin"
    description: "Display the page linked 2hop ahead."
    about:       "Show two-hop links beneath the editor to preview pages linked two steps away without leaving your note. Support Live Preview and provide commands to enable or temporarily disable the 2-hop view."

    stats: {
        downloads:  8584
        updated_at: 1655390118000
    }
}
```
