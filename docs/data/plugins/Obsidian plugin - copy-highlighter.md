# Copy Highlighter

Copy Highlighter highlights text as it is copied and keeps the highlight visible while the copy shortcut is held, which gives a visual confirmation. Highlight color, editor and rendered-text opacity, corner radius and fallback timing are configurable. It runs fully offline with no telemetry or network access.

```cue
plugin: {
    id:     "copy-highlighter"
    name:   "Copy Highlighter"
    author: "Nymbo"
    repo:   "nymbo/Copy-Highlighter"

    html_url:    "https://community.obsidian.md/plugins/copy-highlighter"
    github_url:  "https://github.com/nymbo/Copy-Highlighter"
    description: "Highlights copied text. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Highlight copied text instantly and keep the highlight visible while the copy shortcut is held to provide a clear visual confirmation.
```
