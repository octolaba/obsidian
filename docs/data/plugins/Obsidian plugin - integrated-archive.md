# Integrated Archive

Moves files out of active work into a configurable archive folder instead of deleting them, optionally preserving the original folder structure and adding archive tags and a frontmatter date. Archive, Delete or Cancel is offered from a command or the file menu. Filenames are made collision-safe so nothing is overwritten, and deletions follow Obsidian's own trash setting.
