# Photo Album

Photo Album groups photos into folder-based albums and renders them as a configurable grid gallery inside a note. Thumbnails are generated automatically, albums are inserted inline or in a collapsible callout, and images are sorted by modification time. Clicking a thumbnail opens the photo in Obsidian's image viewer.

plugin: {
    id:     "photo-album"
    name:   "Photo Album"
    author: "Alexander Cheryomukhin"
    repo:   "solargate/obsidian-photo-album"
