# Tab Switcher

Switches the tabs of a window in either left-to-right order or most-recently-used order, in the manner of a browser's Ctrl and Tab. Pane groups are ignored, so navigation works per window. The recorded inputs suggest combining it with Jump to Link and Vim keybindings to operate Obsidian without a mouse.

    id:     "cycle-through-panes"
    name:   "Tab Switcher"
