# Semantic JSON

Semantic JSON compiles canvas layouts into deterministic, spec-compliant JSON that preserves position, containment, color taxonomy and directionality, giving stable, legible output that diffs cleanly in Git. Import and export detect the format automatically, compilation can run on save, semantic identifiers can optionally be assigned by an LLM, and a CLI handles batch processing.
