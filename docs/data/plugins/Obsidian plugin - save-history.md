# Save History

Save History keeps versions of a file, taken as manual snapshots, on autosave at a configurable interval, and on tab close, and restores a previous version in one click after an automatic pre-restore backup. Versions can be previewed and compared, grouped and labelled by day, week, month or year, kept in a custom snapshot folder, exported and imported, and deletion can require confirmation. Per-file settings override the autosave interval and the maximum number of versions, and previews can embed images.
