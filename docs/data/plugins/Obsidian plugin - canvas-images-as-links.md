# Canvas Images As Links

Canvas Images As Links attaches a link to a canvas image and opens it on a double click. Links are assigned through the right-click menu or a command and may be a vault URL, a web URL or a file on the local computer. The configured link is displayed beneath the image.

```cue
plugin: {
    id:     "canvas-images-as-links"
    name:   "Canvas Images As Links"
    author: "jffaust"
    repo:   "jffaust/obsidian-canvas-images-as-links"

    html_url:    "https://community.obsidian.md/plugins/canvas-images-as-links"
    github_url:  "https://github.com/jffaust/obsidian-canvas-images-as-links"
    description: "Add links to canvas images and open them by double clicking. Links can be an vault URL, web URL or even a file on your computer. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Set links on Canvas images and open them by double-clicking. Use the right-click menu or a command to assign web, file, or Obsidian links and display the configured link beneath the image."

    stats: {
        downloads:  572
        updated_at: 1772822462000
    }
}
```
