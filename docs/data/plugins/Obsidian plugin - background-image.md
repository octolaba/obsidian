# Background Image

Background Image sets a remote image or animated GIF, addressed by URL, as the editor background. Background blur and the contrast of the editor input area are adjustable, so the image can be balanced against readability.

```cue
plugin: {
    id:     "background-image"
    name:   "Background Image"
    author: "shmolf"
    repo:   "shmolf/obsidian-editor-background"

    html_url:    "https://community.obsidian.md/plugins/background-image"
    github_url:  "https://github.com/shmolf/obsidian-editor-background"
    description: "Specify a remote URL as the background image, and a few settings to tweak the experience."
    about:       "Apply remote-hosted images or animated GIFs as the Editor background to personalize your workspace. Adjust background blur and the editor input area's contrast to balance aesthetics and readability."
```
