# Mermaid ELK

Restores the ELK (Eclipse Layout Kernel) layout renderer for Mermaid diagrams in Obsidian. A diagram uses it when the code block is prefixed with a YAML configuration header selecting the elk layout.

```cue
plugin: {
    id:     "mermaid-elk"
    name:   "Mermaid ELK"
    author: "keksnet"
    repo:   "keksnet/obsidian-mermaid-elk"

    html_url:    "https://community.obsidian.md/plugins/mermaid-elk"
    github_url:  "https://github.com/keksnet/obsidian-mermaid-elk"
    description: "Brings back the elk (Eclipse Layout Kernel) renderer for Mermaid diagrams. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Restore ELK (Eclipse Layout Kernel) layout support for Mermaid diagrams in Obsidian. Switch to the ELK renderer by prepending your Mermaid diagram with a YAML config header specifying layout: \"elk\"."

    stats: {
        downloads:  1522
        updated_at: 1764001032000
    }
}
```
