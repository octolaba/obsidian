# Editing Toolbar

Adds a toolbar in the style of MS Word plus a minimal text-editor modal, so markup can be applied without typing it. Modified from cMenu, it offers more customization settings, top or cursor-following toolbar positions, and support for multiple windows and tabs. Built-in commands cover font and background colour, list indenting, undo and redo, horizontal rules and justification.
