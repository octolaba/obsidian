# Mermaid.js Helper (OMH)

Cleans Mermaid graph and flowchart code by moving variable declarations to the top and tidying style and class rows, with regex-based edits available for them. Global color groups are copied into a local graph. Beyond diagrams, empty files are created from a newline list or from second-level headings, and comma or newline lists are converted into links.
