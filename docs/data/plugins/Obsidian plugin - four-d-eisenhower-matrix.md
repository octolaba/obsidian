# 4D Eisenhower Matrix

Shows tasks from across the vault in a five-quadrant Eisenhower matrix of DO, DECIDE, DELEGATE, DELETE and OPEN, with a switch to a Kanban view. Checklists in the Obsidian Tasks format are read and written with full create, read, update and delete support, vault-wide aggregation, priority handling, tag autocomplete, filters and date navigation, plus a three-second undo after completion.
