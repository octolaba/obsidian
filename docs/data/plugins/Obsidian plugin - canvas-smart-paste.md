# Canvas Smart Paste

Canvas Smart Paste inserts clipboard content into Canvas as nodes in several modes: a single node, a heading-based tree, a list-based tree, paragraph nodes, or auto-detection. Arrow connections are created to reflect heading and list hierarchies, and nodes are laid out top-to-bottom or left-to-right.
