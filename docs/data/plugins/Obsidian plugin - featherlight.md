# Featherlight

Enforces a hard character ceiling on a note, blocking typing and pasting past the limit while still allowing deletions and selections. A live status-bar counter shows characters used and remaining, with color warnings as the limit approaches. Limits come from 140, 280 or custom presets, can be set per note in YAML frontmatter, and can be scoped to particular folders.

```cue
plugin: {
    id:     "featherlight"
    name:   "Featherlight"
    author: "Julie Sandburg"
    repo:   "jsandburg/obsidian-featherlight"

    html_url:    "https://community.obsidian.md/plugins/featherlight"
    github_url:  "https://github.com/jsandburg/obsidian-featherlight"
    description: "Enforces character limits on notes, with a live status bar counter showing characters used and remaining. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Enforce a hard character ceiling that blocks typing and pasting past the limit while still allowing deletions and selections. Show a live status-bar counter with color warnings, support 140/280/custom presets, per-note YAML limits, and optional folder scoping."

    stats: {
        downloads:  21

    }
}
```
