# Motes

Captures flow-style notes through input cards that embed the native Obsidian editor and keep all content as plain Markdown. Notes appear in a waterfall masonry grid or in an independent responsive sidebar, and storage is one file per day or per year, with migration between the two. Wiki links preview natively, and year statistics and a tag cloud are available.
