# Clip Link

Turns Markdown links written with a clip scheme into copy actions, so clicking one puts its target on the clipboard instead of navigating. Such links are shown in cyan to set them apart, ordinary links keep navigating, and both Reading View and Live Preview are supported without configuration.

```cue
plugin: {
    id:     "clip-link"
    name:   "Clip Link"
    author: "kanade2511"
    repo:   "kanade2511/clip-link-obsidian"

    html_url:    "https://community.obsidian.md/plugins/clip-link"
    github_url:  "https://github.com/kanade2511/clip-link-obsidian"
    description: "Copy any text to clipboard by clicking a Markdown link with clip: scheme. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Copy text to clipboard with a single click using clip: links in your notes; clicking a clip: link copies its target instead of navigating. Display clip: links in cyan to distinguish them, intercept only clip: links while regular links navigate normally, and work in Reading View and Live Preview with no configuration."

    stats: {
        downloads:  122
        updated_at: 1782614356000
    }
}
```
