# Prose Toolkit

Adds sentence-aware navigation and editing commands to the editor, including toggling highlights and bold formatting on a whole sentence. Highlighted text is extracted to the clipboard as paragraphs or bullets, with optional headings and source footnotes, or turned into linked per-highlight notes without overwriting existing files. It operates fully locally, with no network requests or telemetry.

```cue
plugin: {
    id:     "prose-toolkit"
    name:   "Prose Toolkit"
    author: "Gabriel Bacha"
    repo:   "gabrielbacha/Obsidian-Prose-Toolkit"

    html_url:    "https://community.obsidian.md/plugins/prose-toolkit"
    github_url:  "https://github.com/gabrielbacha/Obsidian-Prose-Toolkit"
    description: "Navigate, format, and extract sentences and highlights without leaving your note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Navigate and edit prose with sentence-aware commands directly in your notes. Toggle sentence-level highlights and bold formatting while writing. Extract highlighted text to the clipboard as paragraphs or bullets, add headings and source footnotes, and create linked per-highlight notes without overwriting files while operating fully locally with no network requests or telemetry."
```
