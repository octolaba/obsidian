# Enhance Copy Note

Enhance Copy Note adds a command that copies the active note, duplicating it the way the file explorer's Make a copy action does, and exposes it in both the command palette and the file menu. A second command copies a selected folder together with all of its contents.

```cue
plugin: {
    id:     "copy-note"
    name:   "Enhance Copy Note"
    author: "kzhovn"
    repo:   "kzhovn/copy-command-obsidian"

    html_url:    "https://community.obsidian.md/plugins/copy-note"
    github_url:  "https://github.com/kzhovn/copy-command-obsidian"
    description: "Add commands to copy active note and copy folders."
    about:       "Add a \"Copy active note\" command to the command palette and file menu to duplicate the currently open note, matching the file-explorer \"Make a copy\" behavior. Add a \"Copy folder\" command to duplicate a selected folder and all its contents."
```
