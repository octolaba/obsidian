# Meta Quest Sync

Connects the vault to a Meta Quest WebXR viewer by exporting a graph snapshot and launching a local Rust bridge behind an HTTPS tunnel. A QR code pairs the headset, requested notes and media are served to the Quest for the length of the session, and stopping the session revokes access.
