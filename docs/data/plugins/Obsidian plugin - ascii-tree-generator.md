# ASCII Tree Generator

Converts indented Markdown lists or outlines marked with equals signs into ASCII tree diagrams inside the note. Trees are drawn with box-drawing characters, support unlimited nesting and automatic hierarchy detection, and render in both edit and preview modes.

    id:     "ascii-tree-generator"

    html_url:    "https://community.obsidian.md/plugins/ascii-tree-generator"
