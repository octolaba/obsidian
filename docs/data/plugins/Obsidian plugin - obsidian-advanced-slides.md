# Advanced Slides

Advanced Slides builds Markdown-based presentations from Obsidian notes and embeds note content directly into slides. Edits are previewed live, themes and annotations applied, and a deck exported as PDF or as standalone HTML with Obsidian Markdown support.

```cue
plugin: {
    id:     "obsidian-advanced-slides"
    name:   "Advanced Slides"
    author: "mszturc"
    repo:   "mszturc/obsidian-advanced-slides"

    html_url:    "https://community.obsidian.md/plugins/obsidian-advanced-slides"
    github_url:  "https://github.com/mszturc/obsidian-advanced-slides"
```
