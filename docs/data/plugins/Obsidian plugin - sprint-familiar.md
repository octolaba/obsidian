# Sprint Familiar

Runs timed research sprints that begin by naming a decision and a finish condition and end by recording what changed in the argument: claims written, sources linked, assumptions marked, questions opened and paths ruled out. Each sprint is written to a dated Markdown note. Daily and weekly summaries collect those notes.

```cue
plugin: {
    id:     "sprint-familiar"
    name:   "Sprint Familiar"
    author: "Heidi Andersén"
    repo:   "heidihelena/obsidian-sprint-familiar"

    html_url:    "https://community.obsidian.md/plugins/sprint-familiar"
    github_url:  "https://github.com/heidihelena/obsidian-sprint-familiar"
    description: "A research sprint timer that ends by recording what changed in your argument: claims written, sources linked, assumptions marked, questions opened, paths ruled out. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Start timed research sprints by naming a decision and a finish condition, then work until you reach it. Watch for claims, sources, assumptions, open questions and closed alternatives; record what changed and write a dated Markdown note, with daily and weekly summaries."

    stats: {

    }
}
```
