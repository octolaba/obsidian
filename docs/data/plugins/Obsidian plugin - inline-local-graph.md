# Inline Local Graph

Inline Local Graph displays a local graph at the bottom of the current note, showing its links and backlinks in otherwise unused space. The network graph is interactive inside the note itself, and its visuals are kept uncluttered for navigating between related notes.

    id:     "inline-local-graph"
    name:   "Inline Local Graph"
    author: "tkoxff"
    repo:   "tkoxff/obsidian-inline-local-graph"
