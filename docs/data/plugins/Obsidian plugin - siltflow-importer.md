# Siltflow Importer

Imports Siltflow language-learning data from its SQLite database into the vault as Markdown files with YAML frontmatter and AI summary callouts. One note is created per document, and each annotation is rendered as a bilingual callout card covering CEFR and lemma, meanings, definitions, examples, collocations and synonyms. Sync is incremental and can be filtered to words, phrases or sentences.

```cue
plugin: {
    id:     "siltflow-importer"
    name:   "Siltflow Importer"
    author: "MYQ"
    repo:   "tyblhqy/obsidian-siltflow-importer"

    html_url:    "https://community.obsidian.md/plugins/siltflow-importer"
    github_url:  "https://github.com/tyblhqy/obsidian-siltflow-importer"
    description: "Import Siltflow SQLite database into your vault as Markdown notes with bilingual AI annotation cards. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Import Siltflow language-learning data into Obsidian as Markdown files with YAML frontmatter and AI summary callouts. Create one note per document and render each annotation as a bilingual callout card (CEFR & Lemma, Meanings, Definitions, Examples, Collocations, Synonyms), with incremental sync and filters for words, phrases, or sentences."
```
