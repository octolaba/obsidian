# Vault 2 Book

Converts the vault or a selected folder into a single Markdown file containing all the linked notes. Internal links and structure are preserved so the result can serve as a book-ready file for PDF export, and generated books can be removed again.

```cue
plugin: {
    id:     "vault-2-book"
    name:   "Vault 2 Book"
    author: "mitra98t"
    repo:   "mitra98t/vault2book-plugin"

    html_url:    "https://community.obsidian.md/plugins/vault-2-book"
    github_url:  "https://github.com/mitra98t/vault2book-plugin"
    description: "Convert your notes to a book creating a single file containing all the notes linked."
    about:       "Convert your Obsidian vault or a selected folder into a single Markdown file that preserves internal links and structure. Generate a book-ready file for PDF export and remove all generated books when needed."

    stats: {
        downloads:  5793
        updated_at: 1686861902000
    }
}
```
