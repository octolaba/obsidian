# Graph Untangler

Untangles the graph view by pulsing link forces, cycling through force values so overlapping nodes separate and connections become clearer. The untangling process can be started and stopped on demand.

```cue

    id:     "graph-untangler"
    name:   "Graph Untangler"
    author: "G-Chist"
    repo:   "g-chist/obsidian-graph-untangler-plugin"

    html_url:    "https://community.obsidian.md/plugins/graph-untangler"
    github_url:  "https://github.com/g-chist/obsidian-graph-untangler-plugin"
```
