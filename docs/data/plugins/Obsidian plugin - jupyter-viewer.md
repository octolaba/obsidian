# Jupyter Notebook Viewer

Renders .ipynb notebook files natively, showing markdown cells through Obsidian's own renderer and code cells with Python syntax highlighting and execution-count badges. Outputs appear inline, covering stdout and stderr as monospace streams, cleaned error tracebacks, inline images and scrollable, theme-aware HTML tables.
