# Auto-Properties

Auto-Properties builds auto-updating frontmatter properties from a note's own content using rules you define, such as pulling the first or all lines, counting lines, matching a regex, or detecting that the text starts with, contains or ends with something. Updates are triggered on an edit pause, when file focus changes, or manually.

```cue
plugin: {
    id:     "auto-properties"
    name:   "Auto-Properties"
    author: "Aaron Gillespie"
    repo:   "aarongilly/obsidian-auto-properties"

    html_url:    "https://community.obsidian.md/plugins/auto-properties"
    github_url:  "https://github.com/aarongilly/obsidian-auto-properties"
    description: "Create automated properties based on note content and rules. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create auto-updating frontmatter properties from note content using user-defined rules. Define rules like pull first/all lines, count lines, match regex, or detect starts/contains/ends, and choose triggers (on edit pause, on file-focus change, or manual) to keep metadata current."

    stats: {
        downloads:  9285
        updated_at: 1784154714000
    }
}
```
