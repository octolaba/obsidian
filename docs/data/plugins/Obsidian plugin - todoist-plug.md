# Todoist-Plug

Manages Todoist tasks from inside Obsidian through a Quick Add modal that pre-fills the title from the selected text or the active file and appends a deep link back to the note. Project, label, date and priority are chosen through searchable popovers, native Todoist colors are synced, task defaults can be set, and the API token is stored in the operating-system keychain.
