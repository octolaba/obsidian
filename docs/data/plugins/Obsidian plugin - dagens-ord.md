# Dagens Ord

Presents one Danish word a day with English and Chinese glosses, example sentences with translations, and pronunciation audio. The deck can be navigated, words starred or marked mastered, entries filtered by CEFR level, and audio downloaded on demand. Progress is saved locally, and a Today action jumps to the current word.

    id:     "dagens-ord"
    name:   "Dagens Ord"
