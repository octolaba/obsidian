# Supercharged Links

Internal links receive attributes carrying values from the target note's frontmatter, so a link can be styled from note metadata such as tags, YAML fields or file path. Colors, emojis, backgrounds and other visual styles apply in the editor, in preview and in the file browser, which the recorded inputs present as a way to make notes for people, papers or todos stand out while navigating.

```cue
plugin: {
    id:     "supercharged-links-obsidian"
    name:   "Supercharged Links"
    author: "mdelobelle"
    repo:   "mdelobelle/obsidian_supercharged_links"

    html_url:    "https://community.obsidian.md/plugins/supercharged-links-obsidian"
    github_url:  "https://github.com/mdelobelle/obsidian_supercharged_links"
    description: "Add attributes to internal links with the values of target note's frontmatter attributes."
    about:       "Style links across your vault based on note metadata like tags, YAML frontmatter, or file path. Apply colors, emojis, backgrounds and other visual styles in editor, preview and file browser to make notes (people, papers, todos) stand out for faster navigation."

    stats: {
        downloads:  206618

    }
}
```
