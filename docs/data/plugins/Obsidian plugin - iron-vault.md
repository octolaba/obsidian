# Iron Vault

Iron Vault is a gameplay plugin and virtual tabletop for the Ironsworn and Starforged family of tabletop RPGs, driven by datasworn-formatted data. Interactive blocks, commands and a right-side sidebar are used to make moves, manage entities and advance progress tracks. Multiple campaigns are supported, and play is either local or shared online with others through modal links.
