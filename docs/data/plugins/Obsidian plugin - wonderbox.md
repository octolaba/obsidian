# WonderBox

Turns custom Markdown blocks written with triple-colon markers, a type and a title into stylized boxes. The recorded types include note, tip, info, warning, danger, success, error, announcement and progress, so tips, warnings and critical messages stand out from the surrounding text.

```cue
plugin: {
    id:     "wonderbox"
    name:   "WonderBox"
    author: "chrstn67"
    repo:   "chrstn67/WonderBox"

    html_url:    "https://community.obsidian.md/plugins/wonderbox"
    github_url:  "https://github.com/chrstn67/WonderBox"
    description: "Create more relevant text sections your tips, top notes, warnings and more"
    about:       "Transform custom Markdown blocks like :::type[Title]...::: into stylized boxes inside Obsidian. Support multiple box types (note, tip, info, warning, danger, success, error, announcement, progress, etc.) to highlight notes, tips, warnings and critical messages."

    stats: {

}
```
