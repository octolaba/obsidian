# Mood Calendar

Mood Calendar shows a sidebar calendar in which each day carries the mood emoji read from note frontmatter, and the same calendar can be embedded in any note. A one-click mood picker creates or updates the daily note, mood values can be edited on hover, and the calendar stays synced to the active file through daily-notes integration.

```cue
plugin: {
    id:     "mood-calendar"
    name:   "Mood Calendar"
    author: "xzhi"
    repo:   "github-xzhi/obsidian-mood-calendar"

    html_url:    "https://community.obsidian.md/plugins/mood-calendar"
    github_url:  "https://github.com/github-xzhi/obsidian-mood-calendar"
    description: "Calendar view of your daily notes, with a mood emoji displayed beneath. 以日历视图展示你的日记，并在下方显示心情 emoji。 - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display a sidebar calendar with each day's mood emoji read from note frontmatter and embed it in any note. Create or update daily notes with a one-click mood picker, hover-edit mood values, and keep the calendar synced to the active file via daily-notes integration."
```
