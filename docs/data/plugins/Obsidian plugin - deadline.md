# Deadline

Combines a monthly calendar, a Pomodoro timer and a task manager in one workspace. Daily notes are created or opened from the calendar, work and break sessions are customizable with animated progress and sound, and tasks are added, checked off or deleted inline. The project states that Obsidian themes are preserved.
