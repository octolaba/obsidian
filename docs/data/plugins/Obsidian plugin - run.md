# Run

Run generates Markdown in a note from inline expressions, JavaScript code blocks or Dataview queries. The generated content is written between run start and end tags, file and page variables are available to the code, and optional run metadata such as update time and errors can be included.

```cue
plugin: {
    id:     "run"
    name:   "Run"
    author: "hananoshikayomaru"
    repo:   "hananoshikayomaru/obsidian-run"

    html_url:    "https://community.obsidian.md/plugins/run"
    github_url:  "https://github.com/hananoshikayomaru/obsidian-run"
    description: "Generate Markdown from dataview query and JavaScript."
    about:       "Generate Markdown from inline expressions, JavaScript code blocks, or Dataview queries directly in your notes. Update content between run start/end tags, access file and page variables, and include optional run metadata like update time and errors."

    stats: {
        downloads:  3508
        updated_at: 1700530382000
    }
}
```
