# Scripture Indexer

Scripture Indexer scans notes for Scripture references and writes a consolidated index file for the vault. The index is updated and cleaned automatically when a file is saved, renamed or deleted, and common citation formats of the Book Chapter:Verse kind are recognized, including ranges, commas and semicolons.

```cue
plugin: {
    id:     "scripture-indexer"
    name:   "Scripture Indexer"
    author: "jdrbrn"
    repo:   "jdrbrn/obsidian-scripture-indexer"

    html_url:    "https://community.obsidian.md/plugins/scripture-indexer"
    github_url:  "https://github.com/jdrbrn/obsidian-scripture-indexer"
    description: "Indexes references to scriptures in notes."
    about:       "Index Scripture references across your vault by scanning notes and writing a consolidated index file. Update and clean the index automatically on file save, rename, or deletion, and support common citation formats like Book Chapter:Verse with ranges, commas, and semicolons."

    stats: {

    }
}
```
