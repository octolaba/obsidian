# List Modified

Links modified files that meet chosen criteria into daily, weekly or monthly notes, building an archive of what changed. Output is a static plain-text log, and change detection is internal rather than based on system file timestamps, which keeps entries correct when files move or sync.

```cue
plugin: {
    id:     "obsidian-list-modified"
    name:   "List Modified"
    author: "franciskafieh"
    repo:   "franciskafieh/obsidian-list-modified"

    html_url:    "https://community.obsidian.md/plugins/obsidian-list-modified"
    github_url:  "https://github.com/franciskafieh/obsidian-list-modified"

    about:       "Link modified files that meet your criteria into daily, weekly, or monthly notes to build an accurate archive of changes. Output static plain-text logs and rely on internal change detection rather than system file timestamps to keep entries correct when files move or sync."
```
