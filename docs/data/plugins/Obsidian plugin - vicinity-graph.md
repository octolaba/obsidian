# Vicinity Graph

Renders the vicinity of the active note as a grouped, canvas-like graph in place of the native local graph. Nodes carry a title, thumbnail, image and outline, and notes are grouped into labelled boxes by folder. Link depth can be set per channel, and a central note can be pinned while browsing.

    id:     "vicinity-graph"
    name:   "Vicinity Graph"
    author: "Nickolay Kondratyev"

    html_url:    "https://community.obsidian.md/plugins/vicinity-graph"
