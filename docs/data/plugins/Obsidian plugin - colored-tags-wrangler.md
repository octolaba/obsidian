# Colored Tags Wrangler

Colored Tags Wrangler assigns colors to tags through a built-in color picker, with separate text and background shades per tag. Tag colors also apply to Canvas cards, to Kanban cards and lists, and to folders through folder-note properties, and the leading hash can optionally be omitted in the Kanban view.

```cue
plugin: {
    id:     "colored-tags-wrangler"
    name:   "Colored Tags Wrangler"
    author: "code-of-chaos"
    repo:   "code-of-chaos/obsidian-colored_tags_wrangler"

    html_url:    "https://community.obsidian.md/plugins/colored-tags-wrangler"
    github_url:  "https://github.com/code-of-chaos/obsidian-colored_tags_wrangler"
    description: "Assign colors to tags. Has integrations with other plugins, like Kanban."
```
