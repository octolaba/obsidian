# Linter

Formats and styles Markdown notes with a configurable rule set covering YAML tags, aliases, arrays and metadata, footnotes, headings, spacing, math blocks and ordinary content such as lists, italics and bold styles. Individual rules are toggled and configured to enforce consistent structure and automate cleanup across the vault.
