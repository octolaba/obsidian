# Min3ditorHotkeys

This plugin adds editor hotkeys inspired by coding editors. A new line can be added above or below the current line even when the cursor is not at the end of that line. A single hotkey duplicates the current line or the selected text.

```cue
plugin: {
    id:     "obsidian-min3ditorhotkeys-plugin"
    name:   "Min3ditorHotkeys"
    author: "d-sauer"
    repo:   "d-sauer/Obsidian-Min3ditorHotkeys-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-min3ditorhotkeys-plugin"
    github_url:  "https://github.com/d-sauer/Obsidian-Min3ditorHotkeys-plugin"
    description: "Additional editor hotkeys inspired by coding editors."
    about:       "Add a new line above the current line even when the cursor isn’t at the line end. Add a new line below the current line even when the cursor isn’t at the line end. Duplicate the current line or selected text with a single hotkey."

    stats: {
        downloads:  4863
        updated_at: 1611421761000
    }
}
```
