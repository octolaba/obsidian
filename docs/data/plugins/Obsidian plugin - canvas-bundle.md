# Canvas Bundle

Canvas Bundle exports the open canvas together with its linked notes, embeds and attachments into a single portable ZIP archive. Markdown files, non-Markdown assets and group background images are included, canvas paths and note links are rewritten, and duplicate files receive unique names. The inputs state that it runs on desktop only and saves the archive to the vault root.
