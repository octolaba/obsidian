# Link As

Links selected text to any note while keeping the selection as the inline display text. It can also run without a selection, taking a typed display text or falling back to the target note's title, and it writes inline wikilinks or Markdown links without touching the target note's properties. The recorded inputs note that link format is respected, redundant aliases are skipped, and Property Over File Name is supported in the picker.

```cue
plugin: {
    id:     "link-as"
    name:   "Link As"
    author: "David V. Kimball"
    repo:   "davidvkimball/obsidian-link-as"

    html_url:    "https://community.obsidian.md/plugins/link-as"
    github_url:  "https://github.com/davidvkimball/obsidian-link-as"
    description: "Link selected text to any note, keeping it as the display text. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Link selected text to any note while keeping your selection as the inline display, or run without a selection and type a display (leave empty to use the note's title). Create inline wikilinks or Markdown links to chosen notes without writing to target note properties, respect link format, and skip redundant aliases; work with Property Over File Name to show titles in the picker."

    stats: {

}
```
