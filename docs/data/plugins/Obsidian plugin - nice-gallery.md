# Nice Gallery

Nice Gallery turns a Markdown code block listing embedded images into a responsive gallery inside the note, drawing on attachments already present there. The images open in a full-screen, touch-friendly viewer with zoom, pan and swipe navigation, and the layout adapts to desktop and mobile.

```cue
plugin: {
    id:     "nice-gallery"
    name:   "Nice Gallery"
    author: "konfetigr"
    repo:   "konfetigr/obsidian-nice-gallery"

    html_url:    "https://community.obsidian.md/plugins/nice-gallery"
    github_url:  "https://github.com/konfetigr/obsidian-nice-gallery"
    description: "Convert code blocks with ![[images]] into interactive galleries. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create responsive image galleries inside any note using simple markdown code blocks that pull attachments already in the note. View images in a full-screen, touch-friendly viewer with zoom, pan, swipe navigation and adaptive layouts for desktop and mobile."

}
```
