# Second Window

Opens a note or an image file in a separate pop-up Obsidian window for viewing beside the main one. Later opens are sent to the window that already exists, and images are stretched to fill it for full-size display.

```cue
plugin: {
    id:     "image-window"
    name:   "Second Window"
    author: "javalent"
    repo:   "javalent/second-window"

    html_url:    "https://community.obsidian.md/plugins/image-window"
    github_url:  "https://github.com/javalent/second-window"
    description: "Allow images & notes to be viewed in new windows."
    about:       "Open notes or image files in a separate pop-up Obsidian window for focused viewing. Send subsequent opens to the existing second window and stretch images to fill the window for comfortable, full-size display."

    stats: {
        downloads:  37668
        updated_at: 1704303174000
    }
}
```
