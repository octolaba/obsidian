# Jira Confluence Converter

Converts the current selection or the whole note into Jira Wiki Markup or Confluence rich text and puts the result on the clipboard. Both formats can be bundled into a single copy, and an optional ribbon icon is available on desktop and mobile. Conversion runs offline, with best-effort handling of Obsidian-specific content.

```cue
plugin: {
    id:     "jira-confluence-converter"
    name:   "Jira Confluence Converter"
    author: "Ildar Kamalov"
    repo:   "topk36/obsidian-jira-confluence-converter"

    html_url:    "https://community.obsidian.md/plugins/jira-confluence-converter"
    github_url:  "https://github.com/topk36/obsidian-jira-confluence-converter"
    description: "Copy Markdown as Jira Wiki Markup or Confluence rich text - This plugin has not been manually reviewed by Obsidian staff."

Bundle both formats in one copy and add an optional ribbon icon for quick access on desktop and mobile. Perform conversions offline with best-effort handling of Obsidian-specific content."
