# HackMD Push

Pushes the current note to HackMD from a command or a single click, remembering the remote note ID so later pushes update the same document instead of creating another one. Title and tags are taken from the note's frontmatter, which is stripped before upload. Further commands copy the HackMD link, open the note in a browser, or unlink it from the remote copy.

plugin: {
    id:     "hackmd-push"
    name:   "HackMD Push"

Sync title and tags from frontmatter while stripping the frontmatter before upload, and use quick commands to copy the HackMD link, open the note in a browser, or unlink."
