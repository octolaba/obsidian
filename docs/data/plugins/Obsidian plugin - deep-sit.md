# Deep Sit

Cites and references items from a Zotero library inside Obsidian notes. Citations, bibliographies and linked annotations are inserted while writing, with Zotero and Better BibTeX running in the background.

    name:   "Deep Sit"
    author: "bassio"
    repo:   "bassio/obsidian-deepsit"

    html_url:    "https://community.obsidian.md/plugins/deep-sit"
    github_url:  "https://github.com/bassio/obsidian-deepsit"
