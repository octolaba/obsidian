# Note Gallery

Note Gallery displays notes and images as a masonry gallery inside a note, rendering cached Markdown cards so previews appear quickly. Its contents come from a single Obsidian search query, regular expressions included, which can be sorted and limited; folders are scanned recursively and creations, edits and deletions are reflected. Column breakpoints are configurable for responsive layouts.

```cue
plugin: {
    id:     "note-gallery"
    name:   "Note Gallery"
    author: "pashashocky"
    repo:   "pashashocky/obsidian-note-gallery"

    html_url:    "https://community.obsidian.md/plugins/note-gallery"
    github_url:  "https://github.com/pashashocky/obsidian-note-gallery"
    description: "A masonry gallery that will visualize your notes, similar to Craft note view."
    about:       "Display notes and images in a fast masonry-style gallery inside a note, using cached markdown cards for near-instant previews. Filter and search with a single Obsidian search query (including regex), sort and limit results, recursively scan folders, and reflect CRUD updates. Customize column breakpoints for responsive layouts."
```
