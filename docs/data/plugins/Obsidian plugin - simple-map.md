# Simple Map

Simple Map builds interactive maps from images in the vault and pins notes to specific coordinates on them. Pins link back to their notes, preview content on hover, and can be filtered, searched and given custom icons and sizes. Maps support infinite panning and zoom, with per-map identifiers.
