# ChordPro Viewer

ChordPro Viewer renders ChordPro code blocks as song sheets with chords aligned over the lyrics and the frontmatter metadata displayed. A whole file can be transposed and chord notation normalized. Songs or flow-controlled sections are transcluded through chopro callouts, which is how setlists and practice sheets are assembled.

```cue
plugin: {
    id:     "chopro-viewer"
    name:   "ChordPro Viewer"
    author: "Jason Heddings"
    repo:   "jheddings/obsidian-chopro"

    html_url:    "https://community.obsidian.md/plugins/chopro-viewer"
    github_url:  "https://github.com/jheddings/obsidian-chopro"
    description: "Render ChordPro format code blocks in Obsidian. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render ChordPro song sheets with precise chord-to-lyric alignment and frontmatter metadata display. Transpose entire files, normalize chord notation, and transclude songs or flow-controlled sections via [!chopro] callouts for dynamic setlists and practice sheets."

    stats: {
        downloads:  864
        updated_at: 1778704053000
    }
}
```
