# Patina

Scores every note's staleness from its edits, opens and inbound-link recency, and ranks notes by a decay half-life with per-note profiles. A sortable review queue works through that ranking, stale notes are dimmed in the file explorer, and a decay frontmatter line is written only when a profile is set explicitly.
