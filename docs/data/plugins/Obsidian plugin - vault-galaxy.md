# Vault Galaxy

Renders the vault as a living galaxy in which the most-linked notes become suns, hubs orbit them and every other note orbits what it links to, with orbit distance reflecting shared-link strength. Nodes can be grabbed and dragged against link-coupled spring physics, hovering highlights a constellation and clicking opens the note. Gravity, rotation, node sizes and colors are tuned live.
