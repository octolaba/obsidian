# Checklist Progress

Checklist Progress fills the heading of a checklist with its completion as a fraction and as a percentage, counting nested task lists. The counts refresh on a command or automatically in Live Preview, and a leading minus sign switches the report from checked to unchecked items.

```cue
plugin: {
    id:     "checklist-progress"
    name:   "Checklist Progress"
    author: "acidghost"
    repo:   "acidghost/obsidian-checklist-progress"

    html_url:    "https://community.obsidian.md/plugins/checklist-progress"
    github_url:  "https://github.com/acidghost/obsidian-checklist-progress"
    description: "Automatically fill progress (as fraction or percentage) of check-lists."
    about:       "Update checklist headings with completion fractions and percentages for nested task lists. Run a command or enable auto-update in Live Preview to refresh counts (e.g., 2/3 or 50%), and prefix with a minus sign to report unchecked items instead of checked ones."

    stats: {
        downloads:  3533
        updated_at: 1718344268000
    }
}
```
