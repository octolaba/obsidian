# Library Search

Library Search searches the vault using terms taken from the active note, its aliases or a custom property, together with linked context, to surface the most relevant notes. Results can be grouped and matched inside headings and callouts, and are shown through an inline panel or a side view. PDF outlines are indexed automatically and their sections converted into Zettelkasten-style card index entries linked back to the source note.
