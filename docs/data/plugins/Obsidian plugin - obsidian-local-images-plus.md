# Local Images Plus

Described as a reincarnation of Local Images, this plugin downloads images in Markdown notes to local storage. It localizes images and media from pasted web content, Word and OpenOffice documents, Markdown embeds and base64 data, saving attachments next to notes or into note-named folders. It can also convert PNGs to JPEGs, deduplicate by MD5 and remove orphaned files.
