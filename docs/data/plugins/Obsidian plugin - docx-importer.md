# DOCX Importer

Imports docx files into the vault as Markdown, creating a subfolder that holds the converted note, a copy of the original document and an attachments folder for extracted images. The active note can also be exported back to docx with headings, emphasis, highlights, links, lists, tables, blockquotes, code blocks and images preserved.

    id:     "docx-importer"
    name:   "DOCX Importer"

Export active Markdown notes back to .docx while preserving headings, emphasis, highlights, links, lists, tables, blockquotes, code blocks, and images."
