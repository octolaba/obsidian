# Hemingway Typewriter

Hemingway Typewriter locks writing to the forward direction by blocking cursor movement, delete and undo, so earlier text cannot be revised. Typewriter scrolling keeps the current line centred, and a focus mode hides interface chrome. The write-only lock can be disabled at any time to edit freely.

```cue
plugin: {
    id:     "hemingway-typewriter"
    name:   "Hemingway Typewriter"
    author: "David Yarzebinski"
    repo:   "coffeegerm/hemingway-typewriter-obsidian"

    html_url:    "https://community.obsidian.md/plugins/hemingway-typewriter"
    github_url:  "https://github.com/coffeegerm/hemingway-typewriter-obsidian"
    description: "A write-only typewriter mode: you can only write forward, with a distraction-free focus environment. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Write forward-only with a typewriter-style lock that blocks cursor movement, delete and undo so you can't go back to revise. Keep the current line centered with typewriter scrolling. Enter a distraction-free focus mode that hides interface chrome, and disable the write-only lock anytime to edit freely."
```
