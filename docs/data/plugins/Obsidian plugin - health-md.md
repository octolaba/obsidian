# Health.md Visualizations

Health.md Visualizations renders Apple Health data as interactive charts inside notes, reading local JSON, CSV, Markdown frontmatter or Obsidian Bases YAML files held in the vault. A code block or an insert command embeds an interactive canvas chart, and custom date and time range filters narrow what it shows.

```cue
plugin: {
    id:     "health-md"
    name:   "Health.md Visualizations"
    author: "codybontecou"
    repo:   "codybontecou/health-md-visualizations"

    html_url:    "https://community.obsidian.md/plugins/health-md"
    github_url:  "https://github.com/codybontecou/health-md-visualizations"
    description: "Render Apple Health data visualizations from JSON, CSV, or Markdown files, with custom date and time range filters. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render interactive Apple Health visualizations directly in your notes from local JSON, CSV, Markdown frontmatter, or Obsidian Bases (YAML) data files. Drop a fenced code block or run the insert command to embed an interactive canvas chart that reads health export files from your vault."

    stats: {
        downloads:  3468
        updated_at: 1784304822000
    }
}
```
