# Image Search

Searches the web for images from inside Obsidian, previews the results, and inserts a chosen image into the current note. The two recorded inputs disagree about the backend: the index description names a Google API, while the About text names the Brave Search API and states that a Brave Search API key is required.

```cue
plugin: {
    id:     "image-search"
    name:   "Image Search"
    author: "razeghi71"
    repo:   "razeghi71/obsidian-image-search"

    html_url:    "https://community.obsidian.md/plugins/image-search"
    github_url:  "https://github.com/razeghi71/obsidian-image-search"
    description: "Search and insert images using Google API"
    about:       "Search the web for images via the Brave Search API directly inside Obsidian. Preview results and insert selected images into your current note; requires a Brave Search API key."
```
