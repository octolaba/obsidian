# Song Links

A link to the track currently playing on Spotify is inserted into a note. The account is connected once, after which the insert song link command adds the reference where the cursor sits.

```cue
plugin: {
    id:     "spotify-links"
    name:   "Song Links"
    author: "cutaiar"
    repo:   "cutaiar/obsidian-song-links"

    html_url:    "https://community.obsidian.md/plugins/spotify-links"
    github_url:  "https://github.com/cutaiar/obsidian-song-links"
    description: "Insert a link to the song currently playing on your Spotify."
    about:       "Insert song links from Spotify directly into your notes. Connect Spotify and run the Insert song link command to add a link to the currently playing track for quick music referencing."

    stats: {
        downloads:  3427
        updated_at: 1717718313000
    }
}
```
