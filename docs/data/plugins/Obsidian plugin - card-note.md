# CardNote

CardNote extracts a selection or a foldable block into a new note and inserts a linked card onto Obsidian Canvas or Excalidraw by drag-and-drop. Linked files can open automatically in a split view, and automatic link labels and arrow styles keep the resulting maps navigable.
