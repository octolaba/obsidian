# Blockspace Workspace

Provides a Notion-style block workspace in its own Obsidian view, storing page bodies as a structured JSON block tree so nesting, columns, tables, media and rich-text ranges are first-class data. Container blocks are edited directly, with drag-and-drop and native table support. Markdown can be imported and exported losslessly, and a read-only Bridge keeps the content visible to Obsidian's index. The workspace is local-first.
