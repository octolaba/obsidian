# TabJump

Toggles between the two most recently active tabs with a single hotkey, which the recorded inputs describe as Alt-Tab behaviour, and moves the current tab left or right in the tab bar. Hotkeys are assigned in the plugin settings. The recorded About text states that it works across split panes and on mobile and handles closed tabs and pane boundaries.
