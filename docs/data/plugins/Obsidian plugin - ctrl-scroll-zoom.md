# Ctrl+Scroll Zoom

Zooms the whole Obsidian window with Ctrl and the mouse wheel or a trackpad pinch, scaling the interface and the note text together the way a browser does. Zoom levels persist across restarts, a clickable status-bar percentage resets them, and commands zoom in, zoom out or reset.
