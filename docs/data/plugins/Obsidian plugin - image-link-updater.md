# Image Link Updater

Updates Markdown and wiki image links across the vault when image files are renamed, moved, cut and pasted, or moved outside Obsidian. It also saves pasted images into the attachments folder and inserts them as Markdown image links, handling spaces and URI-encoded names.

```cue
plugin: {
    id:     "image-link-updater"
    name:   "Image Link Updater"
    author: "hikosalaidarkcommit"
    repo:   "andy51002000/obsidian-image-link-updater"

    html_url:    "https://community.obsidian.md/plugins/image-link-updater"
    github_url:  "https://github.com/andy51002000/obsidian-image-link-updater"
    description: "Automatically updates markdown image links when image files are renamed or moved in the vault. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Update every image link in your vault automatically when images are moved, renamed, cut/pasted, or moved outside Obsidian to preserve Markdown and wiki references. Save pasted images to your attachments and insert them as Markdown image links, handling spaces and URI‑encoded names."

    stats: {
        downloads:  87
        updated_at: 1784793119000
    }
}
```
