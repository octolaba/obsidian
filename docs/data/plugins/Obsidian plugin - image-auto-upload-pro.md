# Image Auto Upload Pro

Image Auto Upload Pro uploads pasted, dropped or selected local images through PicGo, PicList or PicGo-Core and replaces the Markdown image links with the hosted URLs. Network images in notes or in watched folders are downloaded and relayed to the configured host, and already-relayed URLs are skipped so images are not uploaded in a loop.
