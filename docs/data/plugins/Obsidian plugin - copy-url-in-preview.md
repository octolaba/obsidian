# Image Context Menus

Image Context Menus adds right-click actions to images and to the canvas, including copying the image to the clipboard, copying its URL, opening it in the default application, showing it in the system explorer, revealing it in the file tree, opening it in a new tab and renaming it. Most actions also work on mobile, tested on Android, while online embeds support only copying to the clipboard.
