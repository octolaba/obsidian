# Better Kanban Bases View

Better Kanban Bases View adds a Kanban layout to Bases whose columns come from the active Bases grouping and whose cards show each note's title and the properties already selected in Bases, formula values included. Columns and cards are reordered by drag-and-drop, keyboard shortcuts or context menus, layouts are saved per grouping, and card order resets when the Base sort changes. Moving a card between columns updates the note's frontmatter when the grouping property is writable, notes can be added to writable columns, and notes can be renamed or deleted from the card menu. The recorded description states that the plugin makes no network requests and has no telemetry.
