# Tidy Titles

Tidy Titles slugifies a note's filename while keeping the human-readable title in frontmatter. New note filenames are slugified, links are updated on rename, and commands create or rename notes with a live preview of the resulting slug.

```cue
plugin: {
    id:     "tidy-titles"
    name:   "Tidy Titles"
    author: "Magnus Wållberg"
    repo:   "hoxi/tidy-titles"

    html_url:    "https://community.obsidian.md/plugins/tidy-titles"
    github_url:  "https://github.com/hoxi/tidy-titles"
    description: "Slugify filename from note title - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Keep filenames tidy while preserving human-readable titles. Slugify new note filenames and store the original title in frontmatter; update links when renaming and offer commands to create or rename notes with live slug previews."

    stats: {
        downloads:  16
        updated_at: 1784568581000
    }
}
```
