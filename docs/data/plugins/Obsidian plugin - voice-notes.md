# Voice Notes

Reads Obsidian notes aloud with text-to-speech, either in full or as a compressed summary produced by a language model. Playback can run automatically through the vault and is controlled with pause, resume, loop and stop. Markdown is converted into text suited to speech before it is read.

```cue
plugin: {
    id:     "voice-notes"
    name:   "Voice Notes"
    author: "again"
    repo:   "jhm531/obsidian-voice-notes"

    html_url:    "https://community.obsidian.md/plugins/voice-notes"
    github_url:  "https://github.com/jhm531/obsidian-voice-notes"
    description: "朗读当前笔记，或用大模型概括后朗读。 - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Listen to your Obsidian notes aloud with natural-sounding TTS and optional LLM summaries. Read entire notes or compressed takeaways, auto-play through your vault, control playback with pause/resume/loop/stop, and hear markdown converted into readable speech."

    stats: {
        downloads:  10
        updated_at: 1786370778000
    }
}
```
