# TodoApp Blocks

TodoApp Blocks embeds a Todoist-like local-first task app into a note through a single code block, with projects, due dates, priorities from P1 to P4 and Today, Tomorrow, Week and All views. Independent task spaces are created by giving each block an id, tasks are edited inline and task notes opened in a popup, and all data is stored inside the vault as JSON and Markdown.

```cue
plugin: {
    id:     "todoapp"
    name:   "TodoApp Blocks"
    author: "Max Dvorkin"
    repo:   "kaiso12/todoapp"

    html_url:    "https://community.obsidian.md/plugins/todoapp"
    github_url:  "https://github.com/kaiso12/todoapp"
    description: "Embed a Todoist-like local-first task app inside any Obsidian note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed a Todoist-style task app in any note with a single code block and manage projects, due dates, priorities (P1–P4), and views for Today, Tomorrow, Week, and All. Create multiple independent task spaces by id, edit tasks inline, open task notes in a popup, and store all data locally as JSON and Markdown inside your vault."
```
