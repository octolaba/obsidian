# Plain Text Kanban

Plain Text Kanban renders nested Markdown lists as an interactive kanban board while the underlying files stay plain text and readable in any editor. Fixed-width columns and cards support drag and drop, inline edits, interactive checkboxes and full Markdown in card bodies. Coloured labels are derived from hashtags, file paths in cards are clickable, and the recorded description also lists images, archiving and swimlanes.
