# AsciiDoc Blocks Plugin

AsciiDoc Blocks Plugin renders AsciiDoc blocks in notes, starting with tables. It covers headerless layouts, CSV-format input, grid and frame options and row and column spans, so an AsciiDoc table layout appears in the note as written.

```cue
plugin: {
    id:     "obsidian-asciidoc-blocks"
    name:   "AsciiDoc Blocks Plugin"
    author: "juracy"
    repo:   "juracy/obsidian-asciidoc-blocks"

    html_url:    "https://community.obsidian.md/plugins/obsidian-asciidoc-blocks"
    github_url:  "https://github.com/juracy/obsidian-asciidoc-blocks"
    description: "Render asciidoc blocks, initially asciidoc tables."
    about:       "Render AsciiDoc blocks in Obsidian, focusing on tables with headerless layouts, CSV-format input, grid/frame options, and row/column spans. Show accurate AsciiDoc table layouts directly in your notes."

    stats: {
        downloads:  6381
        updated_at: 1649184329000
    }
}
```
