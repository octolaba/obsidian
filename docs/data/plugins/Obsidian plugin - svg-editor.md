# SVG Editor

Edits inline SVG code blocks visually, drawing lines, circles, rectangles and freehand scribbles, or in a code mode that edits the SVG source directly. The recorded inputs describe rendering and editing SVG code blocks and embedded .svg files inline, with a visual editor and a synchronized code view, and saving edits back to notes or files. Conversion between inline blocks and embeds, color and opacity adjustment, undo and mobile touch support are recorded, and the output is stated to be sanitized.
