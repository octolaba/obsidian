# Koda

Adds an agentic chat sidebar that searches, reads and writes notes in the vault, showing each tool call inline and streaming answers with a collapsible thinking block. Memory is stored in an editable Markdown file rather than a hidden store. It runs against an OpenAI-compatible endpoint and asks for confirmation before writing outside the Koda folder.
