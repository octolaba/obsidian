# Self-hosted LiveSync

Synchronizes a vault to self-hosted servers, namely CouchDB, S3 or MinIO, or peer-to-peer over WebRTC, so the same vault runs on several devices while material stays inside a designated secure area. Conflicts are resolved by automatic merges for simple edits and data is protected with end-to-end encryption. Settings, snippets, themes and plugins are synchronized too, and the recorded inputs state that compatibility with Obsidian Sync should not be expected.

Keep settings, snippets, themes and plugins in sync and do not expect compatibility with Obsidian Sync."
