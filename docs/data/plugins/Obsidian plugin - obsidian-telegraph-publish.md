# Telegraph Publish

The active note is published to a new or existing Telegraph page, and a published page can be updated or its content cleared. Common Markdown such as bold, italics, links and code blocks is rendered within Telegraph's HTML limits, and the live page URL is returned after publishing. Image upload is recorded as not yet available.

```cue
plugin: {
    id:     "obsidian-telegraph-publish"
    name:   "Telegraph Publish"
    author: "reorx"
    repo:   "reorx/obsidian-telegraph-publish"

    html_url:    "https://community.obsidian.md/plugins/obsidian-telegraph-publish"
    github_url:  "https://github.com/reorx/obsidian-telegraph-publish"
    description: "Publish your note to a Telegraph page."
    about:       "Publish the active note to a new or existing Telegraph page, update published pages, or clear published content. Render common Markdown (bold, italics, links, code blocks) within Telegraph’s HTML limits and provide the live page URL after publishing; image upload support coming soon."

    stats: {
        downloads:  6019
        updated_at: 1768792200000
    }
}
```
