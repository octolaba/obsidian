# Data Fetcher

Runs REST, GraphQL, RPC and gRPC-style requests from data-query code blocks and renders the responses inline. Endpoint aliases and headers are managed in settings, results are cached with an expiration and a cache browser, and individual queries or all of them can be refreshed, copied or saved.

```cue
plugin: {
    id:     "data-fetcher"
    name:   "Data Fetcher"
    author: "qf3l3k"
    repo:   "qf3l3k/obsidian-data-fetcher"

    html_url:    "https://community.obsidian.md/plugins/data-fetcher"
    github_url:  "https://github.com/qf3l3k/obsidian-data-fetcher"
```
