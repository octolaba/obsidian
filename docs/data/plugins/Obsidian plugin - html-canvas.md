# HTML Canvas

HTML Canvas opens local HTML and HTM files in the vault as visual notes. Trusted files are rendered through a browser iframe that preserves CSS, MathML, SVG, anchors and responsive layout while scripts are sandboxed, and search, zoom and restricted fallbacks are offered for untrusted HTML.
