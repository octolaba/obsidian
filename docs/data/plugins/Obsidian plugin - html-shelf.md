# HTML Shelf

Finds the HTML files stored in a vault and renders them inside Obsidian on both desktop and mobile, without going through the file explorer. Relative links between pages keep working, and Back and Shelf controls handle navigation. Pages can be searched and filtered by title, path or section, and an optional html-shelf.json manifest curates them into libraries.

```cue
plugin: {
    id:     "html-shelf"
    name:   "HTML Shelf"
    author: "Marco Gomiero"
    repo:   "prof18/html-shelf"

    html_url:    "https://community.obsidian.md/plugins/html-shelf"
    github_url:  "https://github.com/prof18/html-shelf"
    description: "Browse and read the HTML files in your vault on mobile and desktop, without the file explorer. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Discover and render HTML files from your vault directly inside Obsidian on mobile and desktop, keeping relative links working and pages navigable with Back and Shelf controls. Search and filter pages by title, path, or section and curate libraries with optional html-shelf.json manifests."

    stats: {
        downloads:  63
        updated_at: 1785432126000
    }
}
```
