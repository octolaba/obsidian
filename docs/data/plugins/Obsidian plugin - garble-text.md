# Garble Text

Replaces the text of the whole application with garbled characters and blurs images so screenshots can be taken without exposing sensitive data. The garbled view covers notes, sidebars and other interface elements, and hovering reveals the original content without disabling it.

```cue
plugin: {
    id:     "garble-text"
    name:   "Garble Text"
    author: "kurakart"
    repo:   "kurakart/garble-text"

    html_url:    "https://community.obsidian.md/plugins/garble-text"
    github_url:  "https://github.com/kurakart/garble-text"
    description: "Turn all content in the app (notes, sidebar, etc) into garbled text so you can take screenshots without exposing sensitive data."
    about:       "Toggle a garbled view across the entire app to hide sensitive text and blur images for safe screenshots. Reveal original content on hover to verify details without disabling the garble, covering notes, sidebars and other UI elements."

    stats: {
        downloads:  7148
        updated_at: 1629902777000
    }
}
```
