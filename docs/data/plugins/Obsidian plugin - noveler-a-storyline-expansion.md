# Noveler - A StoryLine Expansion

Opens a dedicated manuscript editor inside Obsidian with page layout controls, a focus writing mode, and formatting tools aimed at long-form fiction. StoryLine scenes can be routed, manuscripts exported in formatted form, and Antidote connected for grammar and style checking.
