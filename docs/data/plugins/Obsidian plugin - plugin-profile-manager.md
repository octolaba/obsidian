# Profile Manager

Profile Manager compares and edits which community plugins are enabled across several Obsidian configuration profiles. Profile folders are registered, each plugin's state is shown as on, off, not installed or blocked, plugins are toggled, missing plugin folders are copied between profiles, and a backup is taken before uninstalling. A privacy mode masks names for screenshots, and the manager protects itself from accidental removal.
