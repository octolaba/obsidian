# CodeBlock Language Detector

CodeBlock Language Detector tags fenced code blocks that carry no language identifier, so syntax highlighting applies to them. Detection combines Highlight.js with pattern matching over 70 or more languages and runs automatically or on demand, and every detection is kept in an undoable history.

```cue
plugin: {
    id:     "codeblock-language-detector"
    name:   "CodeBlock Language Detector"
    author: "Lars Bücker"
    repo:   "bueckerlars/obsidian-codeblock-language-detector"

    html_url:    "https://community.obsidian.md/plugins/codeblock-language-detector"
    github_url:  "https://github.com/bueckerlars/obsidian-codeblock-language-detector"
    description: "Automatically detects and adds language tags to code blocks without specified language for proper syntax highlighting. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Detect and tag fenced code blocks with language identifiers to enable correct syntax highlighting. Use Highlight.js and pattern matching to recognize 70+ languages, run automatically or on demand, and keep an undoable history of detections."

    stats: {
        downloads:  937
        updated_at: 1785063298000
    }
}
```
