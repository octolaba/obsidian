# MermaidMaker

Edits Mermaid diagrams inline on a visual canvas in the note, dragging nodes and adding, removing or connecting them. Node labels are rendered as Obsidian Markdown, so wikilinks, tags, inline math and bold or italic text work inside a node. Node positions are written into the Mermaid source and edits are synchronized in both directions between text and canvas.
