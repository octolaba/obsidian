# MarkTex

MarkTex converts Markdown to LaTeX with a live preview and compiles PDFs locally with latexmk. Tables are handled by selecting between tabular, tabularx and longtable, computing column widths, enabling cell wrapping and applying booktabs styling. Documents can also be previewed and compiled in-browser through SwiftLaTeX built to WebAssembly, exported as .tex or copied as LaTeX, with Unicode and Chinese support offline.
