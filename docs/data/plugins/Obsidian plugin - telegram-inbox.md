# Telegram Inbox

Telegram Inbox receives messages from Telegram bots and appends them to the daily note for centralized logging and journaling. Senders are controlled with a whitelist of Telegram usernames or identifiers. The recorded text notes that incoming messages remain on Telegram for up to 24 hours while the plugin is offline.
