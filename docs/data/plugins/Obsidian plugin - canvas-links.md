# Canvas Links

Canvas Links adds outgoing links and backlinks views for canvases, displaying the links between canvas elements and regular notes. A dedicated view lists those canvas-to-file relationships so they can be browsed and navigated.

```cue
plugin: {
    id:     "canvas-links"
    name:   "Canvas Links"
    author: "aqav"
    repo:   "aqav/obsidian-canvas-links"

    html_url:    "https://community.obsidian.md/plugins/canvas-links"
    github_url:  "https://github.com/aqav/obsidian-canvas-links"
    description: "Add views to show \"outgoing links\" and \"backlinks\" of canvas in Obsidian."
    about:       "Display links between Canvas elements and regular notes to reveal connections across your vault. Open a dedicated view to browse and navigate Canvas-to-file relationships at a glance."

    stats: {
        downloads:  16480
        updated_at: 1740731801000
    }
}
```
