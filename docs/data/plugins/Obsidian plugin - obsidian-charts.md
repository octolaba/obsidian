# Charts

The plugin renders interactive charts inside notes from Markdown tables or embedded CSV. Several chart types are available, and the rendered chart stays embedded in the note it was declared in.

```cue
plugin: {
    id:     "obsidian-charts"
    name:   "Charts"
    author: "phibr0"
    repo:   "phibr0/obsidian-charts"

    html_url:    "https://community.obsidian.md/plugins/obsidian-charts"
    github_url:  "https://github.com/phibr0/obsidian-charts"
    description: "Easily create interactive charts in your notes."
    about:       "Create interactive charts directly inside Obsidian from Markdown tables or embedded CSV. Visualize and explore data with multiple chart types and built-in interactivity for responsive, embeddable charts."

    stats: {
        downloads:  316478
        updated_at: 1706264023000
    }
}
```
