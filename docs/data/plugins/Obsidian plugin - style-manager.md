# Style Manager

CSS variables belonging to themes, snippets and plugin styles are collected into one settings pane and turned into adjustable controls with sliders, text inputs and color pickers. HTML body classes are toggled, configurations are saved as presets and exported or switched between, and shared or isolate modes control the scope of a change.
