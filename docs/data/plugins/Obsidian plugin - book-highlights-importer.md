# Book Highlights Importer

Imports highlights and comments from Yandex Books into Markdown files, creating managed book notes that carry the source metadata. The Yandex library can be searched by title or author and browsed by reading status. Re-importing updates only the plugin-managed section, so manual edits elsewhere in the note survive.

```cue
plugin: {
    id:     "book-highlights-importer"
    name:   "Book Highlights Importer"
    author: "Evgeniy Yadlovskiy"
    repo:   "zhenya-yadlovskij/obsidian-book-highlights-importer"

    html_url:    "https://community.obsidian.md/plugins/book-highlights-importer"
    github_url:  "https://github.com/zhenya-yadlovskij/obsidian-book-highlights-importer"
    description: "Import book highlights and notes into managed Markdown sections. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Import highlights and comments from Yandex Books into Markdown files, creating managed book notes with source metadata. Search your Yandex library by title or author, browse by reading status, and re-import without overwriting your edits by updating only the plugin-managed section."

    stats: {
        downloads:  12
        updated_at: 1786265452000
    }
}
```
