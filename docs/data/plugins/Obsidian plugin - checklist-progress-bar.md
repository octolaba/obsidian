# Checklist Progress Bar

Checklist Progress Bar draws a progress bar above a checklist when a progress callout is placed directly before the list. The bar updates in real time as items are checked, handles nested checklists and allows several independent bars in one note. It needs no configuration and carries its own dark and light styling.

```cue
plugin: {
    id:     "checklist-progress-bar"
    name:   "Checklist Progress Bar"
    author: "Adam Tweedie"
    repo:   "profesr-chaos/obsidian-checklist-progress-bar"

    html_url:    "https://community.obsidian.md/plugins/checklist-progress-bar"
    github_url:  "https://github.com/profesr-chaos/obsidian-checklist-progress-bar"
    description: "Display a progress bar for your checklist (todo) items. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display a live progress bar above any checklist block by placing a > [!progress] callout directly before the list. Update the bar in real time as items are checked, support nested checklists and multiple independent bars per note, with clean dark/light styling and zero configuration."

    stats: {
        downloads:  360
        updated_at: 1780575331000
    }
}
```
