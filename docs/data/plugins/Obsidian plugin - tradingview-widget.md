# TradingView Widget

TradingView Widget opens a customizable stock view built from TradingView's free embeddable widgets, covering advanced charts, heatmaps, tickers, single quotes and symbol summaries. The widgets are loaded from TradingView's servers, so an internet connection is needed, and the view works on desktop only.

```cue
plugin: {
    id:     "tradingview-widget"
    name:   "TradingView Widget"
    author: "Manuel Magaña"
    repo:   "themanuelml/obsidian-tradeview"

    html_url:    "https://community.obsidian.md/plugins/tradingview-widget"
    github_url:  "https://github.com/themanuelml/obsidian-tradeview"
    description: "Open a customizable stock view that displays charts and widgets (heatmaps, tickers, symbol summaries, advanced charts, and more) powered by TradingView's free embeddable widgets. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open a customizable stock view in Obsidian to browse live market data using TradingView's embeddable widgets. Switch among charts, heatmaps, tickers, single quotes, and symbol summaries; work on desktop only and load widgets from TradingView's servers (internet required)."

    stats: {
        downloads:  409
        updated_at: 1781404526000
    }
}
```
