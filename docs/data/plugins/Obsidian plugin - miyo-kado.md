# MiYo Kado

MiYo Kado is a security-first MCP gateway that controls AI access to the vault with default-deny, per-key permissions and audit logging. Assistants are granted granular read, write, delete and search access to notes, frontmatter, files and Dataview fields through a local MCP server. Path and type scopes, optimistic concurrency and rate limits bound what a key may do.
