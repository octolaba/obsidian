# Mermaid Exporter

Exports a rendered Mermaid diagram as a PNG image from inside Obsidian, keeping the current theme's rendering. A scale factor up to four times produces higher-resolution output, and the file is saved through the native system file picker. The export button appears on hover in Live Preview and Reading mode.

    id:     "mermaid-exporter"
    name:   "Mermaid Exporter"
    author: "addozhang"

    html_url:    "https://community.obsidian.md/plugins/mermaid-exporter"
    github_url:  "https://github.com/addozhang/obsidian-mermaid-exporter"

Save files anywhere with the native system file picker; export button appears on hover in Live Preview and Reading modes."
