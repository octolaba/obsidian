# Wetstone

Builds quizzes from notes by extracting key concepts with an LLM, on a key supplied by the user, and generating multiple choice, cloze, fill-in, ordering and true/false questions. Review is scheduled locally by FSRS and adapts to the answers given. Question banks and review state are stored as plain Markdown and JSON.
