# Copy Metadata

Copy Metadata copies file metadata such as the creation time to the clipboard, and can append the note's creation timestamp to the active file name in the Zettelkasten style. It is aimed at renaming and migrating quick mobile notes when they are moved to the desktop.

```cue
plugin: {
    id:     "copy-metadata"
    name:   "Copy Metadata"
    author: "wenlzhang"
    repo:   "wenlzhang/obsidian-copy-metadata"

    html_url:    "https://community.obsidian.md/plugins/copy-metadata"
    github_url:  "https://github.com/wenlzhang/obsidian-copy-metadata"
    description: "Copy file metadata, e.g., creation time, to clipboard. Insert copied metadata to file name."
    about:       "Copy metadata to the clipboard and append the note's creation timestamp to the active file name to add Zettelkasten-style timestamps. Speed up renaming and migrating quick mobile notes when moving them to desktop."

    stats: {
        downloads:  3516
        updated_at: 1774687531000
    }
}
```
