# JokerType

JokerType adds game-like feedback to typing: floating pixel glyph particles, rising-pitch sampled typing sounds and themed visual effects modeled on arcade and HyperType feedback, with special-key glyphs. Custom sounds can be uploaded and presets range from Subtle to Chaotic. Effect intensity, glyph lifetime and pitch or streak behavior are all adjustable.
