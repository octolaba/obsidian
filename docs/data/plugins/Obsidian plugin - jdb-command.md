# JDB Command

JDB Command turns a jdb-command code block into a mobile-first command entry for Jason's Digital Brain. An instruction is dictated or typed, photos, audio, PDFs, documents or Markdown can be attached, and selections are previewed or removed before submitting. Submitting saves the command and its attachments under an inbox commands folder with a persistent receipt, and the plugin states that data stays local and vault content is never sent to third parties.

```cue
plugin: {
    id:     "jdb-command"
    name:   "JDB Command"
    author: "chao chih hung "
    repo:   "c8vzn4ym5g-ai/jdb-command"

    html_url:    "https://community.obsidian.md/plugins/jdb-command"
    github_url:  "https://github.com/c8vzn4ym5g-ai/jdb-command"
    description: "Unified command entry for Jason's Digital Brain. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Turn a jdb-command code block into a mobile-first command center for Jason's Digital Brain inside Obsidian. Dictate or type an instruction, attach photos, audio, PDFs, documents or Markdown, preview and remove selections, then submit to save the command and attachments in inbox/commands with a persistent receipt. Keep data local; never send vault content to third parties."
```
