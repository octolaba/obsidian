# Simple Git

Simple Git is a lightweight Git client driven from the status bar: pull, commit, push, create branches and switch branches without leaving the vault. A commit window stages files or auto-stages them with a per-branch message, and new branches follow a type and issue-key naming pattern and push with upstream tracking. It runs on desktop against the local Git and Git LFS installation.

```cue
plugin: {
    id:     "simple-git"
    name:   "Simple Git"
    author: "Mikhail Soldatkin"
    repo:   "mikealexsoldatkin/obsidian-simple-git"

    html_url:    "https://community.obsidian.md/plugins/simple-git"
    github_url:  "https://github.com/mikealexsoldatkin/obsidian-simple-git"
    description: "A lightweight and simple git client. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Manage Git from the status bar: pull, commit, push, create branches, and switch branches without leaving your vault. Open a commit window to stage files or auto-stage with per-branch messages; create branches named type/issue-key (e.g., feature/KEY-1234) and push with upstream tracking, running on desktop with your local Git/Git LFS."

}
```
