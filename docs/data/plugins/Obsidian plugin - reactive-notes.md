# Reactive Notes

Creates interactive React components inline in notes, built on React 18 and TypeScript. Components can render 2D and 3D visuals through Canvas and THREE.js, charts and D3 graphs, and keep persistent state across notes, with lifecycle and error handling provided. The recorded description states that it is optimized for desktop.
