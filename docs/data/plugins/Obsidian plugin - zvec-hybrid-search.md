# ZVec Hybrid Search

Searches the vault locally by exact words and by related ideas, combining ZVec BM25 keyword scoring with semantic embeddings in one hybrid index that updates automatically and is stored outside the vault. Titles, headings, content and metadata are indexed, results jump to the matching section, and they can be sorted by relevance, date or title. No external server is involved.
