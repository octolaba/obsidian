# Clipboard Manager

Captures clipboard history automatically and stores each entry with a timestamp. The history is searched and filtered as it updates in real time, long items are previewed, and an entry is pasted again from the ribbon or the command palette. Selected entries or the whole history can be exported to Markdown with formatting preserved.
