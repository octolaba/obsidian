# Amazing Life

Builds a four-level goal tree spanning life, phase, year and short-term goals, in which parent goals update automatically as child tasks are completed while daily notes are written. Tasks and highlights carry goal tags so progress rolls up, and noteworthy items are gathered into weekly and monthly summaries. Progress can be explored through dashboard, list, kanban, gallery and calendar views, with everything stored as plain Markdown.
