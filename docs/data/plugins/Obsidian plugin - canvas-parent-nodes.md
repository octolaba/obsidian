# Canvas Parent Nodes

Canvas Parent Nodes lists all parent nodes for the current canvas in a right-hand sidebar. Clicking a node title navigates to its parent node, and the visible length of node titles can be adjusted in settings.

```cue
plugin: {
    id:     "canvas-parent-nodes"
    name:   "Canvas Parent Nodes"
    author: "TommyRoy776"
    repo:   "tommyroy776/obsidian-canvas-parent-nodes"

    html_url:    "https://community.obsidian.md/plugins/canvas-parent-nodes"
    github_url:  "https://github.com/tommyroy776/obsidian-canvas-parent-nodes"
    description: "Display and navigate to all canvas parent nodes - This plugin has not been manually reviewed by Obsidian staff."
```
