# Emoji Toolbar

Searches for emojis and inserts them directly into the editor. Results are filtered with fuzzy or semantic matching, skin tones are supported, and a recently used list is kept. Twitter-style emoji formatting can be previewed and inserted when preferred.

```cue
plugin: {
    id:     "obsidian-emoji-toolbar"
    name:   "Emoji Toolbar"
    author: "oliveryh"
    repo:   "oliveryh/obsidian-emoji-toolbar"

    html_url:    "https://community.obsidian.md/plugins/obsidian-emoji-toolbar"
    github_url:  "https://github.com/oliveryh/obsidian-emoji-toolbar"
```
