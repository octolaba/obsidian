# CBZ Reader

CBZ Reader opens .cbz comic archives inside the vault with a native viewer that does not extract them first. Large comics stay usable through lazy image loading and automatic memory unloading, and navigation uses a minimap in the style of VS Code with thumbnail previews, click-to-jump and one-to-one drag.
