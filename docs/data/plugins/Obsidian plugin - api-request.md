# APIRequest

Makes API requests from within a note and inserts the response into a code block for inline viewing, delivered as JSON for integration with the notes. Requests and outputs are guarded by URL and path validation, directory traversal defenses, safe JSONPath evaluation and XSS prevention.

    id:     "api-request"
