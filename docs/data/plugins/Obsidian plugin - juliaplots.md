# JuliaPlots

Generates 2D and 3D function plots inside notes using Julia, driven by concise script-like inputs. Colors, line width, titles, axis labels and dark mode are configurable, and multiple functions or scatter points can be drawn in one graph. Ranges and resolution can be adjusted to control how smooth the result is.

```cue
plugin: {
    id:     "juliaplots"
    name:   "JuliaPlots"
    author: "ivnmansi"
    repo:   "ivnmansi/juliaplots"

    html_url:    "https://community.obsidian.md/plugins/juliaplots"
```
