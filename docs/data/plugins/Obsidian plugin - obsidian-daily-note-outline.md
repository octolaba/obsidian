# Daily Note Outline

Daily Note Outline adds a custom view showing a combined outline of several daily notes, with their headings, links, tags and list items. Missing daily note files in YYYY-MM-DD form can be created from unresolved links so that backlinks appear in the outline, either on demand or automatically at startup.

```cue
plugin: {
    id:     "obsidian-daily-note-outline"
    name:   "Daily Note Outline"
    author: "iiz00"
    repo:   "iiz00/obsidian-daily-note-outline"

    html_url:    "https://community.obsidian.md/plugins/obsidian-daily-note-outline"
    github_url:  "https://github.com/iiz00/obsidian-daily-note-outline"
    description: "Add a custom view which shows outline of multiple daily notes with headings, links, tags and list items."
    about:       "Display a combined outline of multiple daily notes, showing headings, links, tags, and list items. Create missing YYYY-MM-DD daily note files from unresolved links so backlinks appear in the outline, running manually or automatically at startup."

    stats: {
        downloads:  24665

}
```
