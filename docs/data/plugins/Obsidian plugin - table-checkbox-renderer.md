# Table Checkbox Renderer

Renders checkboxes inside Markdown tables as interactive controls that are toggled in Reading Mode. Each toggle updates the Markdown file, keeping the rendered table and the source in sync. Multiple checkboxes per cell and any table layout are supported.

```cue
plugin: {
    id:     "table-checkbox-renderer"
    name:   "Table Checkbox Renderer"
    author: "dannns"
    repo:   "dannns/obsidian-table-checkbox-renderer"

    html_url:    "https://community.obsidian.md/plugins/table-checkbox-renderer"
    github_url:  "https://github.com/dannns/obsidian-table-checkbox-renderer"
    description: "Interactive checkboxes for Markdown tables. Toggle checkboxes in Reading Mode to instantly update the Markdown file. Supports multiple checkboxes per cell and any table layout."
    about:       "Enable interactive checkboxes inside Markdown tables and toggle them directly in Reading Mode. Keep the rendered table and Markdown file in sync by updating the source on each toggle, with support for multiple checkboxes per cell and complex table layouts."
```
