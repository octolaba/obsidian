# Proton Drive Integration

Connects Obsidian to Proton Drive through a browser sign-in so that Proton files can be used inside notes. Images, videos, PDFs, plain text and Markdown are embedded in reading view through stable node-UID links or by pasting a drive link.

```cue
plugin: {
    id:     "proton-integration"
    name:   "Proton Drive Integration"
    author: "yunusey"
    repo:   "yunusey/obsidian-proton-integration"

    html_url:    "https://community.obsidian.md/plugins/proton-integration"
    github_url:  "https://github.com/yunusey/obsidian-proton-integration"
    description: "Embed Proton Drive files in Obsidian notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Connect Obsidian to Proton Drive via browser sign-in and access your Proton files inside notes. Embed images, videos, PDFs, plain text and Markdown in reading view using stable node-UID links (proton-drive:///volumeId~nodeId) or paste drive links."

    stats: {
        downloads:  520
        updated_at: 1785795704000
    }
}
```
