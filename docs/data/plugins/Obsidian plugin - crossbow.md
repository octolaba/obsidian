# Crossbow

Suggests link targets among headings, tags and files for words found in the active note, ranking matches with Obsidian's internal cache. Occurrences are listed in a sidebar and can be jumped to, and a ranked match can be inserted as a link with optional display text.

```cue
plugin: {
    id:     "crossbow"
    name:   "Crossbow"
    author: "shoedler"
    repo:   "shoedler/crossbow"

    html_url:    "https://community.obsidian.md/plugins/crossbow"
    github_url:  "https://github.com/shoedler/crossbow"
    description: "Find backlinks in your notes."
    about:       "Suggest link targets for headings, tags, and files based on words in your active note and rank matches using Obsidian's internal cache. Display occurrences in a sidebar, let you jump to matches, and insert ranked links with optional display text."

    }
}
```
