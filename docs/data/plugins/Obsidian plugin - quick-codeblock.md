# XU Quick CodeBlock

Inserts Markdown code blocks with the cursor placed inside and line breaks handled, or wraps a selection in a language-tagged block. Custom languages are defined and picked from a language popup, and per-language shortcuts are assigned with conflict detection reported as they are entered.

```cue
plugin: {
    id:     "quick-codeblock"
    name:   "XU Quick CodeBlock"
    author: "xcloud-ai"
    repo:   "xcloud-ai/quick-codeblock"

    github_url:  "https://github.com/xcloud-ai/quick-codeblock"

    about:       "Insert Markdown code blocks with the cursor positioned inside and intelligent line breaks, or wrap selected text in a language-tagged block. Define custom languages, choose from a language popup, and assign per-language shortcuts with real-time conflict detection."
```
