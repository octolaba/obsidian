# Things Logbook

Things Logbook copies completed Things tasks into Obsidian daily notes, inserting each task into the note for the date it was completed. The entire Things Logbook is backfilled on the first run, subtasks, tags and areas can be included, and tasks are refetched at a configurable interval.

    id:     "things-logbook"
    name:   "Things Logbook"
    author: "Liam Cain"
