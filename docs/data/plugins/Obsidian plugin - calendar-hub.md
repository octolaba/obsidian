# Calendar Hub

Calendar Hub turns the calendar sidebar into a view of every note created on a selected date, no matter which folder it lives in. Matching notes are found through filename date matching, extra formats and a frontmatter fallback, with folder filters and note-count dots. All of them can be found, opened and managed from that one panel.
