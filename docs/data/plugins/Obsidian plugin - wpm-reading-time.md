# WPM Reading Time - How Long to Read This Text

Estimates reading time for selected text from a reading speed given in words per minute, using personalized presets. The display reports word count, the current speed and live timing, and switching between silent, speaking and presentation presets adapts the estimate to podcasts, videos or talks.
