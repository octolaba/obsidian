# Sortable Tables

Markdown tables become sortable in preview mode: clicking a column header toggles ascending and descending order. Shift-clicking further headers adds secondary and tertiary sorting. Sorting applies only in preview, so the Markdown source is left as it was written.

```cue
plugin: {
    id:     "sortable-tables"
    name:   "Sortable Tables"
    author: "filippov112"
    repo:   "filippov112/obsidian-sortable-tables"

    html_url:    "https://community.obsidian.md/plugins/sortable-tables"
    github_url:  "https://github.com/filippov112/obsidian-sortable-tables"
    description: "Adds sortable columns to markdown tables in preview mode."
    about:       "Sort tables in preview mode by clicking column headers to toggle ascending and descending order. Add secondary and tertiary sorting with Shift+click while preserving the original Markdown (sorting applies only in preview)."

    stats: {
        downloads:  6517
        updated_at: 1750809968000
    }
}
```
