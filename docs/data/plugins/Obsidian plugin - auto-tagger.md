# Auto Tagger

Auto Tagger suggests tags semantically and keeps several collections side by side. Each collection is a specialized classifier for a different note type, with its own training and filtering.

```cue
plugin: {
    id:     "auto-tagger"
    name:   "Auto Tagger"
    author: "Alessandro Canepa"
    repo:   "canepa/plugin-obsidian-classifier"

    html_url:    "https://community.obsidian.md/plugins/auto-tagger"
    github_url:  "https://github.com/canepa/plugin-obsidian-classifier"
    description: "Multi-collection semantic tag suggestions. Create specialized classifiers for different note types with independent training and filtering. - This plugin has not been manually reviewed by Obsidian staff."
```
