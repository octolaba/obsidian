# Omd2Typst

Omd2Typst exports notes to Typst source files and, when Typst is installed, to typeset PDFs. The output can carry a cover page, a revision page, an auto-numbered table of contents, an optional figure list, callout blocks, tables and images, in five languages. Exports run on macOS, Windows and Linux, and without Typst installed only .typ files are produced.

Run exports on desktop (macOS, Windows, Linux). Without Typst installed only exports .typ files."
