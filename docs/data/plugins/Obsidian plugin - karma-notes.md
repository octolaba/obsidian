# Karma Notes

Adds a Reddit-style voting system to notes, where up and down votes move a note by one point per day. New notes start at 2 karma, and a note decays by one point after two weeks without activity. Scores can be viewed and filtered in a sidebar, and the active note's karma is shown with an emoji in the status bar.
