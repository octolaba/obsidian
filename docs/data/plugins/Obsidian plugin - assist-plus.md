# Assist Plus

Adds a right-hand sidebar for chatting with Claude, driven by a user-supplied API key, with replies streamed in as rendered Markdown. What the model can see is set explicitly by attaching individual notes or groups of them and by allow and deny lists, and each request can be inspected before and after it is sent. Suggested edits stay read-only until they are explicitly inserted into a note.

```cue
plugin: {
    id:     "assist-plus"
    name:   "Assist Plus"
    author: "jabaho9523"
    repo:   "jabaho9523/obsidian-assist-plus"

    html_url:    "https://community.obsidian.md/plugins/assist-plus"
    github_url:  "https://github.com/jabaho9523/obsidian-assist-plus"
    description: "Chat with Claude (Anthropic) inside your vault — on your own API key, with strict control over what it can see and change. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Chat with Claude inside your vault using your own API key and streamed Markdown replies in a right-hand sidebar. Control exactly what Claude can access by attaching notes or groups, using allow/deny lists, inspecting each request before and after send, and keeping edits read-only or suggest-only until you insert them."

    stats: {
        downloads:  36
        updated_at: 1785857734000
    }
}
```
