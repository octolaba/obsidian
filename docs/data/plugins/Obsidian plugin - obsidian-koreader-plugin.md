# KOReader Highlights

Syncs KOReader highlights and annotations into the vault as Markdown notes carrying frontmatter metadata. The KOReader device is connected to the device running Obsidian to keep those notes updated, per-book folders are optional, and note bodies are rendered with customizable Eta.js templates.
