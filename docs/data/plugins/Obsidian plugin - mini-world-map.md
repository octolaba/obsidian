# Mini World Map

Mini World Map draws the vault as a hierarchy-first world map with internal links layered on top to reveal structure and relationships. An Atlas view browses folders and notes, while a Focus view spotlights one note together with its ancestors, siblings, outgoing links and backlinks. Depth, node and link limits, spacing and zoom are adjustable, and the appearance can be set to day, night or automatic.
