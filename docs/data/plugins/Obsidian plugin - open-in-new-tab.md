# Open In New Tab

Open In New Tab opens files from the File Explorer in a new tab, activating the existing tab when the file is already open so duplicates are avoided. It is restricted to the File Explorer and leaves the quick switcher and other parts of Obsidian unchanged.

```cue
plugin: {
    id:     "open-in-new-tab"
    name:   "Open In New Tab"
    author: "patleeman"
    repo:   "patleeman/obsidian-open-in-new-tab"

    html_url:    "https://community.obsidian.md/plugins/open-in-new-tab"
    github_url:  "https://github.com/patleeman/obsidian-open-in-new-tab"
    description: "Open files in new tabs."
    about:       "Open files from the File Explorer in a new tab, activating an existing tab if the file is already open to avoid duplicates. Restrict operation to the File Explorer; won't affect the quick switcher or other Obsidian areas."

    stats: {
        downloads:  43183
        updated_at: 1677641867000
    }
}
```
