# Periodic Notes

Periodic Notes creates and manages daily, weekly and monthly notes, handling file creation and templates. It opens the current weekly note and jumps to the next or previous weekly note, skipping weeks that have no file. The recorded inputs state that it integrates with Calendar week numbers while preserving existing Calendar settings.
