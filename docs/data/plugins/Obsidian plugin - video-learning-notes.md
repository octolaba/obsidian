# Video Learning Notes

Links timestamped learning notes to local video files on Windows and opens the associated file in a single draggable pop-out player. The player seeks to millisecond timestamps, verifies files by SHA-256, finds the nearest evidence line, and copies the current playback position back as a timestamp link.
