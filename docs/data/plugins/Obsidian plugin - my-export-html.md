# My Export To HTML

Exports a note to a single HTML file with images embedded and a hierarchical table of contents generated automatically. LaTeX math is rendered through KaTeX and code blocks carry line numbers and one-click copying. Export runs from the right-click menu with a chosen save location, and the recorded text also mentions previewing exports online.

```cue
plugin: {
    id:     "my-export-html"
    name:   "My Export To HTML"
    author: "justwsh"
    repo:   "justwsh/obsidianExportHTML"

    html_url:    "https://community.obsidian.md/plugins/my-export-html"
    github_url:  "https://github.com/justwsh/obsidianExportHTML"
    description: "Export notes to beautiful HTML files. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Export Obsidian notes to a single, professional HTML file with embedded images and an automatic hierarchical table of contents. Preview exports online, render LaTeX math via KaTeX, and include code blocks with line numbers and one-click copy. Right-click to export and choose the save location."

    stats: {
        downloads:  157
        updated_at: 1772862297000
    }
}
```
