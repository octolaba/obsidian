# SupSub

Selected text is formatted as superscript or subscript using the corresponding HTML tags. A typing mode writes directly in superscript or subscript with an indicator in the status bar, existing tags are toggled or removed, and a modifier key reveals popup buttons.

```cue
plugin: {
    id:     "supsub"
    name:   "SupSub"
    author: "wjgoarxiv"
    repo:   "wjgoarxiv/obsidian-supsub"

    html_url:    "https://community.obsidian.md/plugins/supsub"
    github_url:  "https://github.com/wjgoarxiv/obsidian-supsub"
    description: "Easily format superscripts and subscripts in your notes."
    about:       "Format selected text as superscript or subscript using <sup> and <sub> tags. Activate typing mode to type directly in superscript or subscript with a status-bar indicator, intelligently toggle or remove tags, and reveal popup buttons with a modifier key."

    stats: {
        downloads:  15402
        updated_at: 1771376861000
    }
}
```
