# Weekly Routine Planner

Plans recurring weekly routines in a timetable-style editor driven by a fenced weekly-routine block. The focus is repeating weekly structure rather than dated calendar events or one-off schedules, with time-blocked entries per weekday and coloured categories. Only the text between the planner markers is written, so the rest of the note is left untouched.
