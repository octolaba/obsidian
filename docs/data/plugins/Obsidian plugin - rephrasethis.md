# RephraseThis

RephraseThis rewrites selected text in the editor and replaces it in place with rephrase suggestions the writer reviews first. Alternate suggestions are cycled from the keyboard. Generation runs through Ollama, OpenAI, OpenRouter or any OpenAI-compatible chat API.

```cue
plugin: {
    id:     "rephrasethis"
    name:   "RephraseThis"
    author: "George Pickett"
    repo:   "grp06/RephraseThis"

    html_url:    "https://community.obsidian.md/plugins/rephrasethis"
    github_url:  "https://github.com/grp06/RephraseThis"
    description: "Polish selected text with instant rephrase suggestions. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Polish selected text directly in the editor and replace it in place with reviewed rephrase suggestions. Cycle through alternate suggestions with the keyboard and use Ollama, OpenAI, OpenRouter or any OpenAI-compatible chat API for generation."
```
