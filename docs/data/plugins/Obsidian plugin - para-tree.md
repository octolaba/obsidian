# PARA-Tree

Draws a PARA vault as a git-graph-style map in which areas are trunks, projects are branches, resources are commits and contributes-to relations appear as merges. Frontmatter is read live to show status, colors, last-edited time and review cadence, and a sidebar with search, focus and collapse controls plus attention dots for overdue projects supports navigation. The recorded description states that it is desktop only.

```cue
plugin: {
    id:     "para-tree"
    name:   "PARA-Tree"
    author: "Devin Krizwold"
    repo:   "sparky-code/para-tree"

    html_url:    "https://community.obsidian.md/plugins/para-tree"
    github_url:  "https://github.com/sparky-code/para-tree"
    description: "A git-graph-style view of your PARA vault: Areas are trunks, projects are feature branches, resources are commits — see how work ladders up to your life-areas. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "View your PARA vault as a git-graph-style map with Areas as trunks, Projects as branches, Resources as commits, and contributes-to as merges. Inspect frontmatter live—see status, colors, last-edited and review cadence—and navigate with sidebar, search, focus/collapse controls and attention dots for overdue projects (desktop only)."
```
