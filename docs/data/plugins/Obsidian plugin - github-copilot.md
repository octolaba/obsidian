# GitHub Copilot

Brings GitHub Copilot into the Obsidian editor, offering inline completions and suggestions while typing that can be accepted or dismissed in place. Copilot Chat can also be used to ask questions about notes and to summarize, explain or expand them conversationally.

```cue
plugin: {
    id:     "github-copilot"
    name:   "GitHub Copilot"
    author: "pierrad"
    repo:   "pierrad/obsidian-github-copilot"

    html_url:    "https://community.obsidian.md/plugins/github-copilot"
    github_url:  "https://github.com/pierrad/obsidian-github-copilot"
    description: "Implement suggestions from Github Copilot directly in your editor."
    about:       "Use GitHub Copilot inside Obsidian to get inline completions and suggestions as you type, accepting or dismissing recommendations directly in the editor. Ask questions via GitHub Copilot Chat to summarize, explain, or expand your notes conversationally."
```
