# Writing Assistant Chat

Adds a chat and editing surface backed by local or cloud LLM providers that keeps the active note in context. Vault-wide semantic retrieval supplies passages to the model, and an extracted knowledge graph supports entity-aware search. Agentic tool actions are available, approved per operation or applied automatically.
