# Writing Assistant Chat

Provides a chat and editing surface backed by a language model, connecting to local or cloud providers while keeping the active note in context. Vault-wide semantic retrieval answers from note content, and an extracted knowledge graph supports entity-aware search. Agentic tool actions are applied per operation with approval, or automatically when auto-apply is enabled.
