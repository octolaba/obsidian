# Fast Text Color

Fast Text Color applies text coloring through a compact custom syntax of the form ~={id}...=~ and previews the result live while editing. Colors are applied and removed from the context menu, from editor integrations or from the keyboard, palettes are bundled into themes, and a note overrides the theme with an ftcTheme frontmatter key. No HTML is put into the editor: text is styled with CSS classes, which also cover bold, italics and caps.

    id:     "fast-text-color"
    name:   "Fast Text Color"
