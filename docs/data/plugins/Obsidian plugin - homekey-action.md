# HOME key

HOME key moves the cursor to the beginning of the visible text, skipping indentation and list, quote and task markers, and moves to the absolute line start when pressed again. The command binds to any hotkey, and an advanced variant additionally recognizes Markdown heading characters and footnotes.

```cue
plugin: {
    id:     "homekey-action"
    name:   "HOME key"
    author: "shichishima"
    repo:   "shichishima/obsidian-homekey-plugin"

    html_url:    "https://community.obsidian.md/plugins/homekey-action"
    github_url:  "https://github.com/shichishima/obsidian-homekey-plugin"
```
