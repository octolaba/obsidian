# Vault Dictionary

Highlights words that match a personal dictionary and shows their definitions throughout the vault, in Live Preview and Reading Mode. Terms are added from selected text or from a settings dashboard, and entries are stored in a JSON file under the .obsidian folder so they can be edited or synced directly.

```cue
plugin: {
    id:     "vault-dictionary"
    name:   "Vault Dictionary"
    author: "tahayigitmelek"
    repo:   "tahayigitmelek/vault-dictionary"

    html_url:    "https://community.obsidian.md/plugins/vault-dictionary"
    github_url:  "https://github.com/tahayigitmelek/vault-dictionary"
    description: "Automatically highlight and display definitions for specific words throughout your notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Highlight and display definitions for matching words throughout your vault, visible in Live Preview and Reading Mode. Build and manage a personal dictionary by adding terms from selected text or the settings dashboard, with entries saved to .obsidian/vault-dictionary.json for easy editing and syncing."

    stats: {
        downloads:  410

    }
}
```
