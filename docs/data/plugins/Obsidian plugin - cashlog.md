# cashlog

cashlog records income and expenses inside Markdown using emoji-based markers, then queries, groups and summarizes those entries through a built-in query language and natural-language dates. An interactive dashboard shows balances, budgets, goals and charts across multiple accounts, with transfers, tag categorization and attached receipt photos.
