# CSS Editor

Edits the CSS snippet files in the vault's snippets folder in a built-in editor with syntax highlighting, code completion and basic VIM support. Snippets can be created, renamed, deleted, opened and enabled or disabled from a quick switcher, on desktop and mobile.
