# Mobile Tab Bar

Mobile Tab Bar replaces the title bar on mobile with a scrollable, browser-style row of tabs for the open notes. Tapping a tab switches to it, a long press closes it, and the active tab scrolls into view automatically. An optional save-status dot, green when saved and red when pending, appears when autosave-control is installed.
