# Auto Periodic Notes

Auto Periodic Notes creates daily, weekly, monthly, quarterly and yearly notes in the background, respecting the templates, formats and locations configured in the Periodic Notes plugin it requires. New notes can be opened and pinned automatically, older notes closed, and weekends excluded from daily generation.

```cue
plugin: {
    id:     "auto-periodic-notes"
    name:   "Auto Periodic Notes"
    author: "jamiefdhurst"
    repo:   "jamiefdhurst/obsidian-auto-periodic-notes"

    html_url:    "https://community.obsidian.md/plugins/auto-periodic-notes"
    github_url:  "https://github.com/jamiefdhurst/obsidian-auto-periodic-notes"
    description: "Creates new periodic notes automatically in the background and allows these to be pinned in your open tabs, requires the Periodic Notes plugin."
    about:       "Create periodic notes automatically in the background for daily, weekly, monthly, quarterly, and yearly intervals, respecting your Periodic Notes templates, formats, and locations. Open and pin new notes automatically, optionally close older notes, and exclude weekends from daily generation."

    stats: {
        downloads:  5685
        updated_at: 1768226622000
    }
}
```
