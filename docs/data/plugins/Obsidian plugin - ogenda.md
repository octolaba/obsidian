# Ogenda

Ogenda adds a two-way CalDAV and iCloud calendar with an agenda panel. Events are stored as monthly Markdown notes and synchronised in both directions, merging remote changes. List, day, week, month and stats views are available, events carry categories, attendees and recurrence, and the interface is mobile-friendly in English and Chinese.
