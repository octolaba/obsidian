# Bookmarker

Bookmarker saves web pages into the vault as Markdown notes carrying a preview image, AI-proposed tags and a suggested destination folder, kept locally with no external backend. Title, tags and folder can be reviewed and edited before saving. Saved bookmarks are browsed in a cover-style board, with duplicate detection, content-type detection and broken-link checking.
