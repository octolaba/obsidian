# Code Runner

Runs code blocks from inside a note interactively, with standard input support, on desktop as well as iOS and Android. Python executes through Pyodide compiled to WebAssembly, and the recorded inputs count more than eighteen supported languages, among them C, C++, Java, Go, JavaScript, TypeScript, Rust and Kotlin, with no configuration required.
