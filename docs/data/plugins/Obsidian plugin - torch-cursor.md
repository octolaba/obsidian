# Torch Cursor

Torch Cursor darkens the app and draws a warm, flickering torch glow around the text cursor. The light follows either the text cursor or the mouse, leaving the rest of the interface dimmed for a candlelit writing atmosphere.

```cue
plugin: {
    id:     "torch-cursor"
    name:   "Torch Cursor"
    author: "acxtrilla"
    repo:   "0xatrilla/obsidian-torch-cursor"

    html_url:    "https://community.obsidian.md/plugins/torch-cursor"
    github_url:  "https://github.com/0xatrilla/obsidian-torch-cursor"
    description: "Darkens the app and lights a warm torch glow around your text cursor. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Darken the interface and spotlight the editor with a warm, flickering torch glow around the text cursor. Make the light follow your text cursor or mouse to create a candlelit writing atmosphere while the rest of the UI dims."
```
