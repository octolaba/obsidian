# Caret

Caret brings LLMs into the vault through a chat interface and an AI Canvas, saving everything it generates as local Markdown files. Chats can draw context from other notes, and models run locally or remotely through Caret OP, which covers Ollama, OpenAI, Anthropic, Groq, OpenRouter and custom models.
