# Account Viewer

Account Viewer turns Markdown code blocks tagged with the accounting alias into accounting tables. It parses dates, account names, amounts, pages and descriptions from the block and renders the transactions and journal entries as tables.

```cue
plugin: {
    id:     "account-viewer"
    name:   "Account Viewer"
    author: "muaz742"
    repo:   "muaz742/obsidian-accointing-viewer"

    html_url:    "https://community.obsidian.md/plugins/account-viewer"
    github_url:  "https://github.com/muaz742/obsidian-accointing-viewer"
```
