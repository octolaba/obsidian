# DyResearch AI Sidecar

Bridges the vault to a multi-agent backend built with Google ADK, which runs as a separate DyResearch server, exposing Professor, Librarian and Researcher agents for tutoring, research and source discovery. Documents can be ingested into a vector store for retrieval-augmented search, sessions and history are managed from the plugin, and generated notes are structured and support Mermaid diagrams.
