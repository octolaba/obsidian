# Metronome

This plugin adds interactive metronomes to notes. A visual metronome is displayed with an optional click or beep, and its tempo, meter, instrument and size are customizable. It can be embedded alongside music notation rendered by abcjs, so a score and its tempo reference sit together.

```cue
plugin: {
    id:     "obsidian-metronome-plugin"
    name:   "Metronome"
    author: "curtgrimes"
    repo:   "curtgrimes/obsidian-metronome-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-metronome-plugin"
    github_url:  "https://github.com/curtgrimes/obsidian-metronome-plugin"
    description: "Add interactive metronomes to your notes."
    about:       "Add interactive metronomes to your notes. Display a visual metronome with optional click or beep, customize tempo, meter, instrument and size, and embed it alongside music notation (abcjs) for synchronized score and tempo reference."

    }
}
```
