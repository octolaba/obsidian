# Link Cards

Renders URLs as rich preview cards inside notes, fetching metadata such as thumbnails, descriptions and favicons. Pasted links are detected and an embed is offered for supported addresses, with an optional blurred background behind the card. Metadata is drawn from YouTube, OMDb and OpenGraph sources.

```cue
plugin: {
    id:     "link-cards"
    name:   "Link Cards"
    author: "mainamirh"
    repo:   "mainamirh/obsidian-link-cards"

    html_url:    "https://community.obsidian.md/plugins/link-cards"
    github_url:  "https://github.com/mainamirh/obsidian-link-cards"
    description: "Fetches URL metadata and displays it as rich embed cards in your notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed rich preview cards for supported URLs directly in your notes. Detect pasted links and offer to create embeds that render metadata—thumbnails, descriptions, favicons and optional blurred backgrounds—using YouTube, OMDb and OpenGraph sources."

    stats: {
        downloads:  44
        updated_at: 1785851962000
    }
}
```
