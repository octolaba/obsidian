# Odyssey

Odyssey turns Markdown notes into an interactive calendar, a map and a replay that tie events to time and place. Single-day events, timed blocks and multi-day journeys appear on a month grid, geotagged entries are plotted on a MapLibre map, and journeys are played back with a flying camera that highlights entries across both views.
