# Note Content Pusher

This plugin prepends or appends specified content to an existing or new note without opening another pane. An inline syntax pushes content into a target note named by title, creating the file on demand and appending or prepending the text. Aliases can also be added into a note's YAML frontmatter through the same inline settings.

```cue
plugin: {
    id:     "obsidian-note-content-pusher"
    name:   "Note Content Pusher"
    author: "lizard-heart"
    repo:   "lizard-heart/obsidian-note-content-pusher"

    html_url:    "https://community.obsidian.md/plugins/obsidian-note-content-pusher"
    github_url:  "https://github.com/lizard-heart/obsidian-note-content-pusher"
    description: "Prepend or append specified content to a note (existing or new) without opening another pane."
    about:       "Push specified content into new or existing notes without leaving the current pane using inline syntax like [[Title]]>>{content}. Create files on demand, append or prepend text, and add aliases into a note's YAML frontmatter with simple inline settings."

    stats: {
        downloads:  4159
        updated_at: 1655179145000
    }
}
```
