# ImgBox Pro

Searches notes for external media links, downloads the files, saves them locally and adjusts the note links to point at the local copies. Localized images and attachments, whether from the web, a paste or a drag-and-drop, are named by timestamp and MD5 with deduplication controls, and can be previewed and navigated on desktop and mobile with a jump back to the original note. Unused images and attachments can be cleaned up vault-wide or per folder.
