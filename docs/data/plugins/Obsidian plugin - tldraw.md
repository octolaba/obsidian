# tldraw

tldraw integrates the tldraw whiteboard into Obsidian so drawings and sketches are made with its vector tools. Each drawing is stored as a Markdown file, and the view switches between the visual canvas and the raw Markdown, which allows backlinks and tags to be added and drawings embedded elsewhere in the vault.

```cue
plugin: {
    id:     "tldraw"
    name:   "tldraw"
    author: "tldraw"
    repo:   "tldraw/obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/tldraw"
    github_url:  "https://github.com/tldraw/obsidian-plugin"
    description: "Integration with tldraw, allowing users to draw and edit content on a virtual whiteboard."
    about:       "Draw diagrams and sketches inside Obsidian using Tldraw's vector tools. Store each drawing as a Markdown file and switch between visual canvas and raw Markdown to add backlinks, tags, and embed drawings into your vault."
```
