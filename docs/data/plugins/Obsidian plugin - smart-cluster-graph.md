# Smart Cluster Graph

Displays the vault as a cluster graph that partitions notes into folder-based communities, draws tight convex hulls around them, and marks the active note with a selection ring. Between clusters only the strongest bridge edges are drawn, and cross-cluster links are routed to avoid line crossings. Navigation uses smooth panning and centered zoom.
