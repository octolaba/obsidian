# Simple Note Review

Simple Note Review defines note sets from tags, folders or DataviewJS queries and uses Dataview-powered search to populate review lists. The resulting queues persist and can be advanced in order or randomized, with items skipped and queues reset as needed. Individual notes carry a review frequency or can be ignored, and each noteset reports its own statistics.

```cue
plugin: {
    id:     "simple-note-review"
    name:   "Simple Note Review"
    author: "Daniel Nikolaev"
    repo:   "dartungar/obsidian-simple-note-review"

    html_url:    "https://community.obsidian.md/plugins/simple-note-review"
    github_url:  "https://github.com/dartungar/obsidian-simple-note-review"
    description: "Simple, customizable plugin for easy note review, resurfacing and repetition."
    about:       "Define note sets with tags, folders, or DataviewJS queries and use Dataview-powered search to populate flexible review lists. Create persistent review queues you can progress or randomize, skip items, reset queues, set per-note frequency or ignore notes, and view noteset stats."
```
