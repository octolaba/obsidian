# Markdoc

Markdoc adds basic support for Markdoc files in Obsidian. Files with the .mdoc extension can be edited directly and opened from the file explorer like ordinary Markdown notes, and Markdoc tags get basic syntax highlighting while authoring.

```cue
plugin: {
    id:     "markdoc"
    name:   "Markdoc"
    author: "kamoshi"
    repo:   "kamoshi/obsidian-markdoc"

    html_url:    "https://community.obsidian.md/plugins/markdoc"
    github_url:  "https://github.com/kamoshi/obsidian-markdoc"
    description: "Basic support for Markdoc files."
    about:       "Edit .mdoc files directly in Obsidian and access them from the file explorer like regular Markdown notes. Add basic syntax highlighting for Markdoc tags to improve readability while authoring."

    stats: {
        downloads:  3554
        updated_at: 1682630868000
    }
}
```
