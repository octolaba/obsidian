# Simple Image Slider

Simple Image Slider renders groups of Obsidian image embeds as a swipeable slider with captions shown below the images. It handles both Obsidian wikilinks and ordinary image embeds, supports click, keyboard and swipe navigation with wraparound, and keeps a stable 4:3 canvas.

```cue
plugin: {
    id:     "simple-image-slider"
    name:   "Simple Image Slider"
    author: "XIN"
    repo:   "xinworks/obsidian-simple-image-slider"

    html_url:    "https://community.obsidian.md/plugins/simple-image-slider"
    github_url:  "https://github.com/xinworks/obsidian-simple-image-slider"
    description: "Render Obsidian image embeds as a lightweight slider and show image captions. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render groups of Obsidian image embeds as a clean, swipeable slider with captions. Support Obsidian wikilinks and ordinary image embeds, enable click/keyboard/swipe navigation with wraparound, and keep captions below images on a stable 4:3 canvas."
```
