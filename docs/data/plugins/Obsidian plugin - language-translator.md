# Language Translator

Language Translator translates the selected text into a chosen language through the built-in Azure Translator or a self-hosted Azure or LibreTranslate backend. The target language comes from a language-code prefix or a configured default, and the result is inserted inline or replaces the selection.

    id:     "language-translator"
    name:   "Language Translator"
    author: "twentytwokhz"
