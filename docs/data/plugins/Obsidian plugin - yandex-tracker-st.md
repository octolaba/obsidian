# Unofficial Yandex Tracker ST

Renders Yandex Tracker issues and queries inside notes, turning issue keys and Tracker URLs into interactive cards. Query results can be laid out as tables with selectable columns, a result limit and sorting, or single issues inserted inline for reference. The plugin is unofficial and not affiliated with or supported by Yandex.

```cue
plugin: {
    id:     "yandex-tracker-st"
    name:   "Unofficial Yandex Tracker ST"
    author: "Daniil"
    repo:   "yaishenka/obsidian-yandex-st"

    html_url:    "https://community.obsidian.md/plugins/yandex-tracker-st"
    github_url:  "https://github.com/yaishenka/obsidian-yandex-st"
    description: "Unofficial plugin for rendering Yandex Tracker issues and queries in notes. Not affiliated with or supported by Yandex. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render Yandex Tracker issues and queries as live embeds in notes, turning issue keys and Tracker URLs into interactive cards. Populate tables from Tracker queries with selectable columns, limits and sorting, or insert single issues inline for quick reference."

    stats: {
        downloads:  19
        updated_at: 1785173696000
    }
}
```
