# AI RAG + LLM Wiki

Maintains a persistent, auditable Markdown wiki alongside retrieval-augmented question answering over ingested sources. Indices update automatically, dense and sparse recalls are fused with rerank and compression, and imported source summaries become interlinked wiki pages. Query chains are logged, conflicts flagged, and answers returned with citations.
