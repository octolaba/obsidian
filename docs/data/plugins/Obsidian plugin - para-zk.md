# Para-ZK

Builds a PARA and Zettelkasten wiki in which LLM workflows ingest sources into interlinked notes while preserving frontmatter, references and backlinks. A native CLI and an MCP-aware server expose shell-safe edit operations - replace, set and add - so that vault automation can be scripted or driven by clients such as Claude Code and Codex.
