# BaseForm

Adds an editable Form view to Bases that renders each matching note as its own interactive form. Text, list, number, checkbox, date and date-and-time properties can be edited and are saved straight into note frontmatter through Obsidian's file API. File and formula properties are shown read-only, and file-name visibility, empty-only fields and item spacing are set per view.
