# GATE Calculator

Opens a floating, draggable scientific calculator inside Obsidian for offline calculations. More than 50 functions are available, among them trigonometric functions in degrees or radians, hyperbolic functions, logarithms including an arbitrary base, powers and roots, factorial and memory, with full keyboard input.
