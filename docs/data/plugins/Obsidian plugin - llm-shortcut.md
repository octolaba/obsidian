# LLM Shortcut

Turns Markdown prompt files into Obsidian commands, mapping a folder of prompts, nested folders included, to entries in the command palette. Prompts run against the active note through any OpenAI-compatible provider, and the response is streamed into the editor selection or shown in an info popup.

```cue
plugin: {
    id:     "llm-shortcut"
    name:   "LLM Shortcut"
    author: "chernodub"
    repo:   "chernodub/obsidian-llm-shortcut"

    html_url:    "https://community.obsidian.md/plugins/llm-shortcut"
    github_url:  "https://github.com/chernodub/obsidian-llm-shortcut"
    description: "Provides a way to create shortcuts for commands powered by LLM capabilities."
    about:       "Turn Markdown prompt files into Obsidian commands. Map a folder of .md prompts (including nested folders) to command-palette entries, run prompts against the active note with any OpenAI-compatible provider, and stream responses into the editor selection or show them in an info popup."

    stats: {
        downloads:  839

    }
}
```
