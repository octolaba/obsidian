# Replace Pencil

Replace Pencil turns custom placeholders inside code blocks into live input fields in Reading view. A placeholder prefix is configured, typing updates the rendered code immediately, and the replaced result can be copied to the clipboard. An eraser button resets all changes.

```cue
plugin: {
    id:     "replace-pencil"
    name:   "Replace Pencil"
    author: "penyt"
    repo:   "penyt/replace-pencil"

    html_url:    "https://community.obsidian.md/plugins/replace-pencil"
    github_url:  "https://github.com/penyt/replace-pencil"
```
