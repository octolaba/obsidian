# Quickly

Opens a quick-capture modal from an operating-system shortcut, with a title field and a body field for creating a note or jumping to an existing one. Typing surfaces matching note paths, which are navigated to open a note, while submitting creates a new note with the entered content. A warning appears when a similar note already exists.
