# TaskLoops

TaskLoops collects tagged task lines from across the vault into a sidebar inbox to surface open loops that were committed to but never closed. Each item is walked through a GTD clarify flow one question at a time, sorted lines are marked as handled, and captures are appended to a single inbox note. Projects that have quietly stalled raise a notification, and the state is kept in the plugin data file.
