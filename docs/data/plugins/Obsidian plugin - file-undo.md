# File Undo

Undoes recent file operations, restoring deleted files out of Obsidian's .trash folder and moving renamed or relocated files back to their original paths. A configurable history of recent operations is kept, and dedicated commands undo entries from it or redo them.

```cue
plugin: {
    id:     "file-undo"
    name:   "File Undo"
    author: "Jeff1024"
    repo:   "2607044640/a1-file-undo"

    html_url:    "https://community.obsidian.md/plugins/file-undo"
    github_url:  "https://github.com/2607044640/a1-file-undo"
    description: "Undo recent file deletions and moves (renames). - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Restore deleted files from Obsidian's .trash and revert moved or renamed files back to their original paths. Keep a configurable history of recent file operations and redo undone actions with dedicated commands."

    stats: {

}
```
