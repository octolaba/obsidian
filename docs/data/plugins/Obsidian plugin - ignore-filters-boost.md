# Ignore Filters Boost

Ignore Filters Boost manages Obsidian's excluded files list by clicking folders to add or remove them, without opening settings. Focus commands exclude everything except one folder, unignoring a subfolder removes its parents and adds its siblings, and one command restores or sets default ignore filters.
