# Things3 Sync

Todos, tags and dates are synced between Obsidian and Things3 on macOS and iOS. Todos are created from a line or from a whole note with backlinks, status toggles in either application, and any language is supported. A Things3 auth token has to be stored in the vault.

```cue
plugin: {
    id:     "obsidian-things3-sync"
    name:   "Things3 Sync"
    author: "royxue"
    repo:   "royxue/obsidian-things3-sync"

    html_url:    "https://community.obsidian.md/plugins/obsidian-things3-sync"
    github_url:  "https://github.com/royxue/obsidian-things3-sync"
```
