# Stardust Importer

Watched movies are imported from Trakt and full-album listens are reconstructed from Last.fm scrobbles by session detection, with the notes written through Templater templates. Movie and album notes carry TMDB and MusicBrainz metadata, re-watches and relistens are marked, and album matches of low confidence are flagged for review.

```cue
plugin: {
    id:     "stardust-importer"
    name:   "Stardust Importer"
    author: "Sonophage"
    repo:   "sonophage/stardust-importer"

    html_url:    "https://community.obsidian.md/plugins/stardust-importer"
    github_url:  "https://github.com/sonophage/stardust-importer"
    description: "Pulls watched movies (Trakt) and full-album listens (Last.fm) into reference notes via Templater. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Import watched movies from Trakt and reconstruct full-album listens from Last.fm scrobbles using session detection into notes via your Templater templates. Create Movies - <title> and Albums - <title> notes with TMDB and MusicBrainz metadata, mark re-watches and relistens, and flag low-confidence album matches for review."

    stats: {
        downloads:  149
        updated_at: 1781563699000
    }
}
```
