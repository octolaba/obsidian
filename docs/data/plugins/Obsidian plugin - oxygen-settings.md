# Oxygen Theme Settings

Exposes advanced customization options of the Oxygen theme in Obsidian's own settings. Animations, auto-hiding file-explorer icons, navbar reveal and background blur can be adjusted, with optional Style Settings support for finer theme tweaks.

```cue
plugin: {
    id:     "oxygen-settings"
    name:   "Oxygen Theme Settings"
    author: "David V. Kimball"
    repo:   "davidvkimball/obsidian-oxygen-settings"

    html_url:    "https://community.obsidian.md/plugins/oxygen-settings"
    github_url:  "https://github.com/davidvkimball/obsidian-oxygen-settings"
    description: "Configure advanced customization options in Oxygen Theme. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Configure Oxygen Theme visuals and behavior from Obsidian's settings. Adjust animations, auto-hide file-explorer icons and navbar reveal, and background blur, with optional Style Settings support for finer theme tweaks."
```
