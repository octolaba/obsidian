# Sentinel

Sentinel triggers actions when a document's visibility changes: notes opening, closing, or changing visibility. Target notes are selected by tag, folder, name, or regex. The actions include updating properties, auto-incrementing a views counter, stamping a modified datetime on exit, and running a linter.
