# Vantell

Scans the folders chosen for sharing on the device and publishes topic labels, note counts and a few sample note titles to colleagues, all shown verbatim before anything is sent, while note contents stay local. A teammate who wants to go deeper sends a knock, a request that is explicitly approved or denied; the reply can be written by hand or drafted from shareable notes through the sharer's own AI account, attaching only the sources ticked. Every exchange leaves a consent receipt, organisation admins see metadata only, and a side panel lists connected brains, waiting requests and answers. One command restores the vault byte-for-byte, and a free account is required.
