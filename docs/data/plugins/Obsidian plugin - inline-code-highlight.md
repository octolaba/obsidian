# InlineCodeHighlight

InlineCodeHighlight applies syntax highlighting to inline code spans, using a language tag to decide the colouring. Inline snippets such as TypeScript, JSON or Markdown are rendered with that formatting so the code stays readable inside a sentence.

    id:     "inline-code-highlight"
