# Inline Admonitions

Formats inline code spans into styled inline callouts, triggered by a prefix, a suffix, a contained string or a regular expression. Background and text colors, opacity, icons and fonts are configurable so that the inline note stands out.

```cue
plugin: {
    id:     "inline-admonitions"
    name:   "Inline Admonitions"
    author: "Scott Tomaszewski"
    repo:   "scotttomaszewski/obsidian-inline-admonitions"

    html_url:    "https://community.obsidian.md/plugins/inline-admonitions"
    github_url:  "https://github.com/scotttomaszewski/obsidian-inline-admonitions"
    description: "Inline callouts to make text pop."
    about:       "Format inline codeblocks into styled inline admonitions triggered by prefix, suffix, contains, or regex patterns. Customize background and text colors, opacity, icons, and fonts to make inline notes stand out."
```
