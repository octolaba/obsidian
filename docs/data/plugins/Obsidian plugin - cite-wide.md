# Cite Wide

Manages citations across a whole vault by converting numeric footnotes into unique hex codes and logging each reference's metadata into a central base. The same hex identifier is reused for a given source, which keeps citations stable across notes and exports. The recorded inputs name inconsistent output from Perplexity, Google and Claude as the case it is meant to absorb.
