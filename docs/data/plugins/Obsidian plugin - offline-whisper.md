# Offline Whisper Transcription

Offline Whisper Transcription converts speech to text locally with Whisper models, running offline after the initial model download. Desktop uses whisper.cpp and mobile uses transformers.js through WebAssembly, and both audio and transcriptions stay on the device.

```cue
plugin: {
    id:     "offline-whisper"
    name:   "Offline Whisper Transcription"
    author: "David Manthey"
    repo:   "manthey/offline-whisper"

    html_url:    "https://community.obsidian.md/plugins/offline-whisper"
    github_url:  "https://github.com/manthey/offline-whisper"

    about:       "Transcribe speech to text locally using Whisper models. Run offline after the initial model download, support desktop (whisper.cpp) and mobile (transformers.js via WebAssembly), and keep audio and transcriptions fully on your device."
```
