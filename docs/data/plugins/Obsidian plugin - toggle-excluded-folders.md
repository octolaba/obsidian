# Toggle Excluded Folders

Toggle Excluded Folders hides or shows user-defined folders in the file explorer, search and graph by switching Obsidian's Excluded files setting on and off. The native excluded filters, covering folders, files, tags and regular expressions, are stashed and restored rather than duplicated into a separate list, and the search and graph views are refreshed automatically.

```cue

    id:     "toggle-excluded-folders"
    name:   "Toggle Excluded Folders"
    author: "Alexander Leonov"
    repo:   "ssurfthekaliyuga/obsidian-toggle-excluded-folders"

    html_url:    "https://community.obsidian.md/plugins/toggle-excluded-folders"

    description: "Quickly hide or show user-defined folders from the file explorer, search and graph by toggling Obsidian's Excluded files setting. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Toggle your Excluded files list on and off with a single click to reveal or hide archived or noisy folders and notes. Stash and restore Obsidian's native excluded filters (folders, files, tags, regex) without creating a separate list and refresh Search and Graph views automatically."
```
