# Lowlight

Highlights text in different colours using span tags. Colours are chosen and applied from the command palette, and the palette itself is customized in the settings for quick, consistent markup.

```cue
plugin: {
    id:     "lowlight"
    name:   "Lowlight"
    author: "stikypiston"
    repo:   "stikypiston/lowlight"

    html_url:    "https://community.obsidian.md/plugins/lowlight"
    github_url:  "https://github.com/stikypiston/lowlight"
    description: "A simple plugin allowing you to highlight text in different colours using span tags. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Highlight selected text in multiple colours to visually organize notes. Choose and apply colours from the command palette and customize your colour palette in settings for quick, consistent markup."
```
