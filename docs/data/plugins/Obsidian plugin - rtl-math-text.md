# RTL Math Text

RTL Math Text lets right-to-left and left-to-right text be mixed inside MathJax expressions through custom LaTeX commands whose names are configurable. Math can be nested inside the RTL and LTR wrappers. The recorded text states that combining-letter scripts such as Arabic are not supported yet.

```cue
plugin: {
    id:     "rtl-math-text"
    name:   "RTL Math Text"
    author: "orelby"
    repo:   "orelby/obsidian-rtl-math-text-plugin"

    html_url:    "https://community.obsidian.md/plugins/rtl-math-text"
    github_url:  "https://github.com/orelby/obsidian-rtl-math-text-plugin"
    description: "Mix right-to-left and left-to-right text in math expressions using configurable commands."
    about:       "Add support for mixing right-to-left (RTL) and left-to-right (LTR) text inside MathJax expressions using custom LaTeX commands like \\R{\\text{...}} and \\L{...}. Nest math inside RTL/LTR and configure the command names. Expect no support for combining-letter scripts (e.g., Arabic) yet."

    stats: {
        downloads:  378
        updated_at: 1751644467000
    }
}
```
