# HandTranscriptMd

Embeds a handwriting canvas in a Markdown file for drawing with a stylus or mouse. Drawings are saved as SVG files visible in the vault, and Google Gemini OCR converts the handwriting into structured Markdown with headings, lists and tables, replacing the drawing block with editable text. It requires a free Gemini API key and is recorded as working on Windows and Android.
