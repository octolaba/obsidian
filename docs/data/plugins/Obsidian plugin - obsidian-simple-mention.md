# Simple Mention

Mentions written with a configurable trigger prefix, @ by default, are highlighted while you write and completed from existing matches, with code blocks ignored. A side pane lists every occurrence of a mention and jumps to the corresponding line in the note. Personal mentions can be colored separately and the list filtered by phrase.

    id:     "obsidian-simple-mention"
    name:   "Simple Mention"
    author: "der-tobi"
