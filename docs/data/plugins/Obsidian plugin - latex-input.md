# LaTeX Input

Provides a clickable symbol palette of roughly 250 symbols across 10 categories that generates LaTeX source and shows a live preview before the equation is inserted into the current note. Screenshots taken from the screen and images on the clipboard can be converted to LaTeX through OCR and inserted directly. The generated source stays editable, history is preserved, the panel follows Obsidian dark themes, and no external dependencies are required.
