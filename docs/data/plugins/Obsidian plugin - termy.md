# Termy

Termy runs terminal sessions inside the editor on a bundled Rust PTY backend with an xterm.js front-end, covering cmd, PowerShell, PowerShell Core, WSL, Git Bash, bash, zsh and custom shells. Split panes, multiple sessions, search, copy and paste, prompt navigation and font sizing are provided, and reusable workflows combine terminal commands, editor commands and external links into one launcher. Files are dragged into a session, file references in output open in the vault, and the active-note context is handed off to local AI CLIs such as Claude Code, Codex, OpenCode and Gemini. No Node.js, node-pty or build toolchain is required.
