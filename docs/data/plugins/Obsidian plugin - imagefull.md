# ImageFull

Opens an embedded image fullscreen in a minimal overlay on a double-click or double-tap, and closes it the same way. Pinching or a trackpad gesture zooms up to ten times, and dragging or a two-finger swipe pans. It works in reading view and live preview on desktop and mobile.
