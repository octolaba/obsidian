# Auto-expand backlinks

Auto-expand backlinks expands the surrounding context of each match in the backlinks panel, so linked mentions are shown with their text rather than as a bare reference. Its recorded description likens the behaviour to Roam Research.

```cue
plugin: {
    id:     "auto-expand-backlinks"
    name:   "Auto-expand backlinks"
    author: "younggyolee"
    repo:   "younggyolee/obsidian-auto-expand-backlinks"

    html_url:    "https://community.obsidian.md/plugins/auto-expand-backlinks"
    github_url:  "https://github.com/younggyolee/obsidian-auto-expand-backlinks"
    description: "Automatically expand the surrounding context of each match in the backlinks panel, similar to Roam Research. - This plugin has not been manually reviewed by Obsidian staff."

    stats: {

    }
}
```
