# Linear

Embeds Linear issues in notes by fetching one or more issue IDs and rendering them inline. Results can be filtered and sorted by team, status, assignee, or due date, with a limit on how many issues are displayed, and the recorded inputs also mention due-date indicators, status colors, and debug logging. The plugin is recorded as desktop-only.
