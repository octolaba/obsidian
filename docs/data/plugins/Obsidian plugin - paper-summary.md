# Paper Summary

Generates a structured Markdown paper note from a PDF in the vault, with frontmatter, sectioned summaries and a filename-safe name. Related-paper links are produced locally by matching tags, title, author, venue, year and section keywords. The note is rendered from the built-in or a custom template, and the output language can be selected.

```cue
plugin: {
    id:     "paper-summary"
    name:   "Paper Summary"
    author: "todfrog"
    repo:   "todfrog/obsidian-paper-summary"

    html_url:    "https://community.obsidian.md/plugins/paper-summary"
    github_url:  "https://github.com/todfrog/obsidian-paper-summary"
    description: "Generate structured paper summary notes from PDFs. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Summarize a vault PDF into a ready-to-read Markdown paper note with frontmatter, sectioned summaries, and filename-safe naming. Generate local related-paper links by matching tags, title/author/venue/year, and section keywords. Render notes from the built-in or a custom template and select output language."

    stats: {
        downloads:  184

    }
}
```
