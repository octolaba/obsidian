# Gemini Helper

Integrates Google Gemini for chat, vault-aware note operations, semantic search or RAG, workflow automation and Open Knowledge Format bundles acting as an LLM wiki. Streaming chat, file attachments, slash commands, AI-proposed edits, web search, reusable agent skills, MCP workflow steps, usage tracking, encryption, edit history and image generation are listed. Dashboards arrange Bases views, files, web pages, kanban boards, timelines and workflow output in a drag-and-resize widget grid, and the File widget reads Markdown, PDF and EPUB with text-anchored reading memos. The recorded text states that it works on desktop and mobile and that a Gemini API key from Google AI Studio is required.
