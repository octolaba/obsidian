# Publora

Sends the current note or a selection to Publora, either scheduled for a chosen time or saved as a draft. Targets include LinkedIn, X, Instagram, Threads, TikTok, YouTube, Facebook, Bluesky, Mastodon and Telegram. YAML frontmatter is stripped before sending, character counts update live, and recently used accounts are remembered.

```cue
plugin: {
    id:     "publora"
    name:   "Publora"
    author: "Publora"
    repo:   "publora/obsidian-publora"

    html_url:    "https://community.obsidian.md/plugins/publora"
    github_url:  "https://github.com/publora/obsidian-publora"
    description: "Publish or schedule the current note to LinkedIn, X, Instagram, Threads, TikTok, YouTube, Facebook, Bluesky, Mastodon and Telegram. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Send the current note or a selection from Obsidian to Publora, scheduling it for a time you pick or saving it as a draft. Choose from LinkedIn, X, Instagram, Threads, TikTok, YouTube, Facebook, Bluesky, Mastodon and Telegram; strip YAML frontmatter, show live character counts, and remember recent accounts."

    stats: {
        downloads:  3
        updated_at: 1786455288000
    }
}
```
