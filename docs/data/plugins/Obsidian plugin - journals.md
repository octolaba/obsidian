# Journals

Journals creates and manages structured journal entries across daily, weekly, monthly, quarterly and custom periods. Multiple journals are organized into shelves, entries auto-numbered, and templates and frontmatter applied. Calendar and timeline views serve for navigation, and navigation blocks link related entries.
