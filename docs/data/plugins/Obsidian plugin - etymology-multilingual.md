# Etymology Multilingual

Looks up word origins in English, Spanish and French from inside a note. A result is written to the note's frontmatter or to a matching dictionary note, inserted at the cursor, or copied to the clipboard, and lookups are cached in memory so a repeat is immediate.

```cue
plugin: {
    id:     "etymology-multilingual"
    name:   "Etymology Multilingual"
    author: "ducktapekiller"
    repo:   "ducktapekiller/etymology-multilingual"

    html_url:    "https://community.obsidian.md/plugins/etymology-multilingual"
    github_url:  "https://github.com/ducktapekiller/etymology-multilingual"
    description: "Get the etymology of words in your notes, supporting multiple languages. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Look up word origins in English, Spanish, and French directly inside your notes. Save etymologies to a note's frontmatter or matching dictionary notes, insert results at the cursor, or copy to clipboard, with in-memory caching for instant repeats."

    stats: {
        downloads:  122
        updated_at: 1779330620000
    }
}
```
