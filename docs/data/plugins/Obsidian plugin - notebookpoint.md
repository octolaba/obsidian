# NotebookPoint

Synchronizes articles and links forwarded inside WeChat into Obsidian Markdown notes carrying their full text. A hosted service receives and parses the forwarded content, and the plugin pulls the resulting notes into the vault. Activation uses a card key that the recorded description says is stored only locally.

```cue
plugin: {
    id:     "notebookpoint"
    name:   "NotebookPoint"
    author: "monoi"
    repo:   "jiangzizhao/notebookpoint"

    html_url:    "https://community.obsidian.md/plugins/notebookpoint"
    github_url:  "https://github.com/jiangzizhao/notebookpoint"
    description: "在微信里把文章、链接、资料转发给客服,自动同步成 Obsidian 笔记。 - This plugin has not been manually reviewed by Obsidian staff."
    about:       "同步你在微信转发的文章与链接为带全文的 Obsidian Markdown 笔记，使用本地卡密激活。让托管服务接收并解析内容，插件自动将生成的笔记拉入你的 vault，卡密仅保存在本地。"

    stats: {
        downloads:  247

}
```
