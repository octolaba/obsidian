# Fantasy Content Generator

Fantasy Content Generator produces content for tabletop role-playing and world-building: character names by race, inns, settlements, loot, drinks, groups, currency and dungeon descriptions. Custom word lists can be defined for it. An inline callout generator inserts a name or a short description into a note directly.

```cue
plugin: {
    id:     "fantasy-content-generator"
    name:   "Fantasy Content Generator"
    author: "gregory-jagermeister"
    repo:   "gregory-jagermeister/Fantasy-Content-Generator"

    html_url:    "https://community.obsidian.md/plugins/fantasy-content-generator"
    github_url:  "https://github.com/gregory-jagermeister/Fantasy-Content-Generator"
    description: "A fantasy content generator for all your TTRPG and world-building needs."
    about:       "Generate fantasy content such as character names by race, inns, settlements, loot, drinks, groups, currency and dungeon descriptions directly in Obsidian. Create custom word lists and use an inline callout generator to quickly insert names or short descriptions into notes."
```
