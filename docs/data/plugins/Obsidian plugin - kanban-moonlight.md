# Kanban Moonlight

Turns Markdown notes into an interactive Kanban board driven by frontmatter metadata. Dragging cards updates their state and records a frontmatter history, tasks can be created and deleted from the board, and completed tasks move into a dedicated column. Real-time search and filtering are available, and columns, categories and icons are customizable.
