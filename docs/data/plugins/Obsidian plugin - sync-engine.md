# Sync Engine

Synchronizes a vault in both directions through a modular engine with pluggable storage backends, including WebDAV and S3. Conflict resolution, scheduling, rate and memory limits, and custom request headers are configurable. An SDK allows further modules to be built, covering backends, optimizers and triggers.
