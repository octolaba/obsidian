# Yet Another All-In-One

Syncs a vault with Git locally across platforms through a pure JavaScript Git engine, which the recorded text presents as safe on Android. A pull runs at startup and syncing continues automatically, and every action is written to an audit log kept in the SyncLog note of the _System folder.
