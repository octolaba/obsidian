# Note Doctor

Note Doctor tags new notes as incomplete and gathers them into a stacked, swipeable queue for triage. A note can be marked healed, which removes the tag, skipped, or opened for full review, and commands exist to complete or re-mark a note. The recorded description calls the interface clean and keyboard-driven.
