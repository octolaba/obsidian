# Marp TikZ Plus

Marp TikZ Plus renders TikZ and LaTeX diagrams inline through a local TeX engine compiled to WebAssembly, so diagrams build offline and appear as live SVGs. It also supports full Marp presentations with live preview, a Slide Navigator and Speaker Notes. PPTX export runs in one step and keeps math as native PowerPoint objects.
