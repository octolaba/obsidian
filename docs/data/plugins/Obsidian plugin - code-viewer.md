# Code Viewer

Opens code files with Obsidian's native syntax highlighting, so colors follow the current theme, covering more than 50 extensions with an optional line-number gutter. Files are read-only by default to avoid accidental edits; inline editing is opt-in and works through a temporary Markdown file with save and view controls.
