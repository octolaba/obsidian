# Unmarkdown

Copies a note for pasting into another application with its formatting intact: a destination is chosen, and headings, tables, code blocks, lists and links are converted for that target. The six recorded destinations are Google Docs, Word, Slack, OneNote, email and plain text, with native heading styles for Google Docs, mrkdwn for Slack, inline CSS for email and Word-compatible HTML for Word. A note can also be published to the web as a styled page with a shareable URL from 62 templates, and the plugin pairs with an MCP server so an AI agent can format and publish from a conversation.
