# Continuous Mode

Continuous Mode displays all notes open in a tab group as a single scrollable document, a layout sometimes called Scrivenings mode, and works across splits, sidebars and floating windows. It offers default, semi-compact and compact display modes together with keyboard navigation between notes. Multiple files or whole folders can be opened at once from the file explorer, links, search or queries.
