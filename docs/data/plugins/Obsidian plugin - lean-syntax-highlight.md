# Lean Syntax Highlight

This plugin provides live syntax highlighting for the Lean programming language, colouring Lean files and code blocks as they are edited. Tokenisation and editor styling are specific to Lean and are applied to improve readability.

    id:     "lean-syntax-highlight"
    name:   "Lean Syntax Highlight"
