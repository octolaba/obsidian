# Feed Bases

Feed Bases adds a feed layout to Bases, showing each note of a base in a scrollable list with its content inline. Notes are edited directly in the feed and the changes are auto-saved to the source files. Entries sort by modified, created or name, and titles and context menus open notes or expose further actions.

```cue
plugin: {
    id:     "feed-bases"
    name:   "Feed Bases"
    author: "edrickleong"
    repo:   "edrickleong/obsidian-feed-bases"

    html_url:    "https://community.obsidian.md/plugins/feed-bases"
    github_url:  "https://github.com/edrickleong/obsidian-feed-bases"
    description: "Adds a feed layout to bases so you can display notes with their content in an editable feed view. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display notes from your Bases in a scrollable, editable feed that shows each note's content inline. Edit notes directly with changes auto-saved to source files, sort by modified/created/name, and open notes or access actions via titles and context menus."

    stats: {
        downloads:  37283
        updated_at: 1766407196000
    }
}
```
