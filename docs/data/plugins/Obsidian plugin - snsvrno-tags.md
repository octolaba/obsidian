# Tag Formatter

Tag display in preview mode is reshaped: the leading hash symbol is hidden, and parent segments of a nested tag are collapsed or removed. Tags are shortened by pattern, and CSS classes are attached to shortened tags, to tags derived from a parent, or to every tag for custom styling.

plugin: {
    id:     "snsvrno-tags"
    name:   "Tag Formatter"
    author: "snsvrno"
    repo:   "snsvrno/snsvrno-short-tags"

    html_url:    "https://community.obsidian.md/plugins/snsvrno-tags"
    github_url:  "https://github.com/snsvrno/snsvrno-short-tags"
