# Katazuke

Scores each file by link count and untouched age in order to surface dense, neglected catch-all notes. Notes intended as hubs can be excluded by tag. Triage runs on a single note or on several at once, so the sprawling ones can be opened and tidied.

```cue
plugin: {
    id:     "katazuke"
    name:   "Katazuke"
    author: "DaisukeMiyazaki"
    repo:   "daisukemiyazaki/katazuke"

    html_url:    "https://community.obsidian.md/plugins/katazuke"
    github_url:  "https://github.com/daisukemiyazaki/katazuke"
    description: "Surface over-connected, stale notes by link degree and freshness so you can tidy the ones that grew sprawling, one or several at a time. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Confront over-connected notes by scoring each file using link count and untouched age to surface dense, neglected catch-alls. Exclude intentional hubs by tag and choose single-note or multi-note triage to open and tidy notes quickly."

    stats: {
        downloads:  55
        updated_at: 1784196293000
    }
}
```
