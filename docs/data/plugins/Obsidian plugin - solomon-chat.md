# Solomon Chat

A note becomes a two-sided text conversation with a chosen persona — an older self, a mentor — for self-distanced journaling. The exchange is written back and forth like a chat and stays in the note as Markdown, keeping an ongoing record of the reflection.

```cue
plugin: {
    id:     "solomon-chat"
    name:   "Solomon Chat"
    author: "West B"
    repo:   "westb-dev/Solomon-Chat"

    html_url:    "https://community.obsidian.md/plugins/solomon-chat"
    github_url:  "https://github.com/westb-dev/Solomon-Chat"
    description: "A calm, Markdown-first two-sided chat for self-distanced journaling and reflection. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Turn any Obsidian note into a private text conversation with a wiser version of yourself for self-distanced journaling. Write back-and-forth like a chat with an older self, mentor, or chosen persona to clarify thinking, surface honest insights, and keep an ongoing record."

    stats: {
        downloads:  20
        updated_at: 1784478654000
    }
}
```
