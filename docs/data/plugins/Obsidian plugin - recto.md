# Recto Zotero Translation

Converts Zotero PDFs into Markdown, generates structured AI summaries and produces aligned Chinese translations for side-by-side bilingual reading. Zotero metadata is imported into a searchable local paper library, and a central Hub shows the conversion and translation status of each paper. Papers are then read and searched inside Obsidian.
