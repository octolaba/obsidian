# PaperFlow

Imports arXiv papers by ID or URL, downloading the PDF and creating a Markdown paper note. AI summaries covering idea, method, limitations, future work and key sentences are generated, and exact-match highlights for PDF++ can be added with configurable concepts and colors.

```cue
plugin: {
    id:     "paperflow"
    name:   "PaperFlow"
    author: "Quan Meng"
    repo:   "quan-meng/paperflow"

    html_url:    "https://community.obsidian.md/plugins/paperflow"
    github_url:  "https://github.com/quan-meng/paperflow"
    description: "Import, read, and annotate arXiv papers. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Import arXiv papers by ID or URL to download PDFs and create Markdown paper notes. Generate concise AI summaries (idea, method, limitations, future work, key sentences) and add exact-match PDF++ highlights with configurable concepts and colors."
```
