# Tree Obs

Converts a Tree Chat export, or Markdown marked up in the same style by hand, into one Obsidian note per node, linking parent and child notes with wikilinks. Generated notes are written into a folder named after the root node, and the original export file is left untouched.

```cue
plugin: {
    id:     "tree-obs"
    name:   "Tree Obs"
    author: "Yuyang"
    repo:   "kanye-shen/tree-obs"

    html_url:    "https://community.obsidian.md/plugins/tree-obs"
    github_url:  "https://github.com/kanye-shen/tree-obs"
    description: "Turn marked TreeChat exports into linked tree notes for graph view. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert a Tree Chat or manually marked Tree Chat–style Markdown export into one Obsidian note per node and link parent and child notes with wikilinks. Write generated notes into a folder named after the root node and keep the original export file untouched."

    stats: {
        downloads:  1
        updated_at: 1786471148000
    }
}
```
