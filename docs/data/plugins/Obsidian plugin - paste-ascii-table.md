# Paste ASCII Table

Turns box-drawing and ASCII-art tables pasted from terminal output into real Markdown tables at paste time. Light, heavy, double and rounded Unicode borders are recognized, along with plus-and-dash ASCII frames and borderless psql output. Cells that the terminal wrapped across several lines are rejoined, ANSI color codes and leading indentation are stripped, column alignment is inferred, and surrounding prose is left in place.
