# Enhancing Export

Exports notes through Pandoc to Markdown, including Hugo, as well as HTML, DOCX, ePub, LaTeX and PDF. Media is preserved for the Markdown and HTML exports. Export templates and commands are customized with built-in variables that control output paths, filenames and formats.
