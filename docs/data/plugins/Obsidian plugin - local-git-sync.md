# Local Git Sync

Syncs and backs up the vault through the local Git executable. Commit, pull, push and auto-sync run from inside Obsidian, rebase conflicts raise warnings, and GitHub, GitLab, Gitee or self-hosted remotes are supported. Optional placeholder files let empty folders be tracked in Git.

    id:     "local-git-sync"
    name:   "Local Git Sync"
    author: "AstonDky66"

    html_url:    "https://community.obsidian.md/plugins/local-git-sync"
    github_url:  "https://github.com/astondky/obsidian-local-git-sync"
