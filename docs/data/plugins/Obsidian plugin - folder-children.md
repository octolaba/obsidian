# Folder Children

Syncs each folder's direct children into a collapsible Children callout on that folder's folder note. Direct child notes and subfolders are listed alphabetically and subfolders link to their own folder notes. It requires the Folder Notes plugin and skips hidden files, the .obsidian directory and folders without a folder note.

plugin: {
    id:     "folder-children"
    name:   "Folder Children"
    author: "Aaron"
    repo:   "aaronarcade/Obsidian-Folder-Children"

    html_url:    "https://community.obsidian.md/plugins/folder-children"
