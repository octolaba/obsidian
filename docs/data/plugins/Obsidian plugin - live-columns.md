# Live Columns

Creates editable multi-column layouts that can be typed into directly in Live Preview. Two-column, three-column, and full-width sections are inserted and edited without switching to source mode, and each column can be styled with its own background and border colors.

```cue
plugin: {
    id:     "live-columns"
    name:   "Live Columns"
    author: "nhiwentwest"
    repo:   "nhiwentwest/live-columns"

    html_url:    "https://community.obsidian.md/plugins/live-columns"
    github_url:  "https://github.com/nhiwentwest/live-columns"
    description: "Create editable columns in your notes with customizable colors. Type directly in columns in Live Preview mode. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create multi-column layouts visually in Live Preview. Insert and edit 2-column, 3-column, or full-width sections and style each column with background and border colors without switching to Source Mode."

    stats: {

}
```
