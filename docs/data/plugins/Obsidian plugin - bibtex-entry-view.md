# Bibtex Entry View

Bibtex Entry View renders a bibkey code block as a compact preview of the matching entry loaded from a configured bib file. The bibkey is highlighted in Obsidian's accent color and author or editor names are shown in last, first order, missing keys are flagged in red with strikethrough, and suggestions appear while a key is typed from partial field matches.

```cue
plugin: {
    id:     "bibtex-entry-view"
    name:   "Bibtex Entry View"
    author: "awfrok"
    repo:   "awfrok/obsidian-plugin-bibtex-entry-view"

    html_url:    "https://community.obsidian.md/plugins/bibtex-entry-view"
    github_url:  "https://github.com/awfrok/obsidian-plugin-bibtex-entry-view"
    description: "Load the bibtex entry of a given bibkey from a given bib file and show the entry in the code block of bibkey."
    about:       "Render bibkey code blocks as compact entry previews from your .bib file, highlighting the bibkey in Obsidian's accent color and showing author or editor names in \"last, first\" format. Flag missing keys in red with strikethrough and show live suggestions while typing {bibkey} based on partial field matches."

    stats: {
        downloads:  332

    }
}
```
