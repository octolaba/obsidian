# Heading Decorator

Heading Decorator displays configurable content around headings according to their level, without modifying note content. Decorations apply in Reading view, Live Preview, Source mode, the Outline, Quiet Outline and Headings in Explorer. A metadata key controls whether a given note is decorated, and ordered, independent, splice and unordered decoration modes are available.
