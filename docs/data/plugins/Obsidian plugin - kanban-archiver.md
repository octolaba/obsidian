# Kanban Archiver

Archives completed Kanban cards older than a configurable number of days into per-board Archive_[boardname].md files, keeping history while boards stay uncluttered. Ticked items without a date are stamped with today's date, and undated completed cards are moved to an Undated section for review. It runs per file or across the whole vault, with configurable Done column names.

```cue
plugin: {
    id:     "kanban-archiver"
    name:   "Kanban Archiver"
    author: "Starsha"
    repo:   "eiger3970/obsidian-kanban-archiver"

    html_url:    "https://community.obsidian.md/plugins/kanban-archiver"
    github_url:  "https://github.com/eiger3970/obsidian-kanban-archiver"
    description: "Archive completed Kanban cards older than a configurable number of days to a separate archive file. Auto-stamps completion dates so cards are always archivable. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Archive completed Kanban cards older than a configurable number of days into per-board Archive_[boardname].md files to preserve history and keep boards uncluttered. Stamp today's date on ticked items without one, move undated completed cards to an \"Undated (review)\" section, and run per-file or vault-wide with configurable Done column names"

    stats: {

}
```
