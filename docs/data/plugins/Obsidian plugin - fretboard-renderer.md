# Fretboard Renderer

Renders guitar fretboard diagrams as SVG from a lightweight YAML syntax written inside fenced code blocks. Diagrams cover chords, scales and positions, are customisable, and need little typing, which suits analysing progressions and visualising pentatonic and modal patterns.

```cue
plugin: {
    id:     "fretboard-renderer"
    name:   "Fretboard Renderer"
    author: "Hiroshi Watanabe"
    repo:   "hiroshi-watanabe/fretboard-renderer"

    html_url:    "https://community.obsidian.md/plugins/fretboard-renderer"
    github_url:  "https://github.com/hiroshi-watanabe/fretboard-renderer"
    description: "Render guitar fretboard diagrams from lightweight YAML in fenced code blocks. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render guitar fretboard diagrams as SVG in your notes from a lightweight YAML syntax inside fenced code blocks. Create clean, customizable diagrams for chords, scales and positions with minimal typing to analyze progressions and visualize pentatonic and modal patterns."
}
```
