# Hugo preview

Hugo preview renders a Hugo site inside Obsidian in a custom iframe. A Hugo server is started in the background with configurable server flags and a customizable command shortcut for launching a terminal or another tool, and the preview is opened from a status-bar button.

    id:     "hugo-preview-obsidian"
    name:   "Hugo preview"
    author: "fzdwx"
