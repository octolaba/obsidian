# Knowledge Base Command Center

Builds a configurable visual workspace for indexing, arranging, finding and creating Markdown notes across any folder-based vault. A searchable index is combined with manual memberships, visual parent and child nesting, drag-and-drop collections, and queues for Inbox, Next and pinned items. A bulk Index Manager, undo and redo, snapshots, and portable export and import of a whole workspace are included, on desktop and iOS.
