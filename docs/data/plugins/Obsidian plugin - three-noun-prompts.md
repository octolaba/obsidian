# Three Noun Prompts

Three Noun Prompts generates three-word creative prompts for writing, composing or illustration and saves them into a designated note. Prompts update automatically at a set interval and past prompts are kept as a history. It runs on desktop only, and the recorded description states the prompts can be synced offline.

```cue
plugin: {
    id:     "three-noun-prompts"
    name:   "Three Noun Prompts"
    author: "jamespeachh"
    repo:   "jamespeachh/Three-Noun-Prompts"

    html_url:    "https://community.obsidian.md/plugins/three-noun-prompts"
    github_url:  "https://github.com/jamespeachh/Three-Noun-Prompts"
    description: "Creative writing prompts that can be synced offline."
    about:       "Generate three-word creative prompts for writing, composing, or illustration and save them to a designated note. Update prompts automatically at a set interval and review a history of past prompts. Run on desktop only."

    stats: {
        downloads:  421
        updated_at: 1732077261000
    }
}
```
