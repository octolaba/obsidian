# Linkwarden

Searches saved Linkwarden bookmarks and inserts them into notes as stable deep-URL bindings, keeping Linkwarden as the single source of truth. Highlights from linked pages are shown in a sidebar as a reading aid without creating files and can be inserted as callout quotes carrying referenceable block IDs, and external URLs can be archived back to Linkwarden and rewritten to their bindings.

```cue
plugin: {
    id:     "linkwarden"
    name:   "Linkwarden"
    author: "heiss"
    repo:   "heiss/obsidian-linkwarden"

    html_url:    "https://community.obsidian.md/plugins/linkwarden"
    github_url:  "https://github.com/heiss/obsidian-linkwarden"
    description: "Search and link your Linkwarden bookmarks, archive URLs, show their highlights beside your notes, and insert highlights as quotes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Search and insert saved Linkwarden links into notes as stable deep-URL bindings, keeping Linkwarden as the single source of truth. Display linked pages' highlights in a sidebar as a living reading aid without creating files, insert highlights as callout quotes with referenceable block IDs, and archive external URLs back to Linkwarden while rewriting them to their bindings."

    stats: {
        downloads:  70

    }
}
```
