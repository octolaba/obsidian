# VolleyBoard SVG

VolleyBoard SVG puts a tactical volleyball whiteboard inside a note, stored as a JSON block and drawn with SVG. The board opens for visual editing of plays and drills, and changes are saved back into the same block so the diagram stays portable and editable.

```cue
plugin: {
    id:     "volleyboard-svg"
    name:   "VolleyBoard SVG"
    author: "davidaffo"
    repo:   "davidaffo/volleyboard_svg_app"

    html_url:    "https://community.obsidian.md/plugins/volleyboard-svg"
    github_url:  "https://github.com/davidaffo/volleyboard_svg_app"
    description: "Tactical volleyball whiteboard with SVG + JSON, built for interactive drills and diagrams. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create tactical volleyball diagrams directly inside notes using an interactive whiteboard stored as a JSON block. Open the board to edit plays visually, then save changes back into the same block for portable, editable diagrams."

    stats: {
        downloads:  99
        updated_at: 1779619832000
    }
}
```
