# Beyond TOC

Shows a floating table of contents beside a note that follows the scroll position and highlights the current heading and its path. Headings can be clicked to jump, and branches collapsed or expanded. The card shrinks or floats on narrow panes so the note's own width never changes, and its visibility can be overridden per note through frontmatter.
