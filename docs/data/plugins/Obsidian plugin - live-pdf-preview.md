# Live PDF Preview

Provides real-time PDF preview and export. Print layout settings such as page size, margins, and font scales are adjusted through a graphical interface, and simple comment-prefixed commands insert page breaks, format multi-column layouts, and center content. Exported print-ready PDFs carry clickable heading outline bookmarks.
