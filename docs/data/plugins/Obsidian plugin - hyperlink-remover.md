# Link Remover

Link Remover strips hyperlinks and wikilinks from a selection or a whole file, leaving plain text and removing image and file embeds. Removal is filtered by internal or external type, and whitelist or blacklist rules preserve or target specific domains, URLs or wikilink paths.

```cue
plugin: {
    id:     "hyperlink-remover"
    name:   "Link Remover"
    author: "alphahasher"
    repo:   "alphahasher/obsidian-remove-links"

    html_url:    "https://community.obsidian.md/plugins/hyperlink-remover"
    github_url:  "https://github.com/alphahasher/obsidian-remove-links"
    description: "Easily remove hyperlinks and wikilinks from selected text or the entire note."
    about:       "Remove hyperlinks and wikilinks from a selection or entire file, converting linked text to plain text and stripping image and file embeds. Filter removals by internal/external type and apply whitelist or blacklist rules to preserve or target specific domains, URLs, or wikilink paths."

    stats: {
        downloads:  6036
        updated_at: 1785785406000
    }
}
```
