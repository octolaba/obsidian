# Bold Folder Name

Makes folder names bold in the native File Explorer, using Obsidian's own bold font weight, with an option to limit the styling to top-level folders. Files, folder counters, collapse icons and inline rename fields keep their normal appearance, and disabling the plugin restores native styling.

```cue
plugin: {
    id:     "bold-folder-name"
    name:   "Bold Folder Name"
    author: "Stagars"
    repo:   "stagars-m/bold-folder-name"

    html_url:    "https://community.obsidian.md/plugins/bold-folder-name"
    github_url:  "https://github.com/stagars-m/bold-folder-name"
    description: "Makes native File Explorer folder names bold, with an option to limit styling to top-level folders. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Make folder names bold in the native File Explorer using Obsidian's --font-bold weight. Limit bold styling to only top-level folders when desired, while leaving files, folder counters, collapse icons, and inline rename fields unchanged. Restore native styling when disabled."

    stats: {
        downloads:  17
        updated_at: 1785911389000
    }
}
```
