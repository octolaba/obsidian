# Inkswell

Provides a workbench for novelists inside the vault, with a single host view organizing Home, Plan, Write, Revise and Publish alongside Codex and Track tools. Beat sheets and a story bible cover planning, sprints and goals cover drafting, an audit toolkit covers revision, and a compile and export pipeline prepares publication. The recorded inputs state that manuscript data stays local, with no accounts, no AI and no network calls.
