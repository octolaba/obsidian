# Always Color Text

Colors and highlights chosen keywords, names, dates or arbitrary text across the whole vault, applying automatically in Live Preview and Reading view. A color is picked for a selection from a unified picker, and flexible match rules and per-entry styling, including borders, transparency and case sensitivity, control how each entry is drawn.
