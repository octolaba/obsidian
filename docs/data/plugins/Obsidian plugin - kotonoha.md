# Kotonoha

A lightweight quick-capture plugin that saves everyday words and tasks into Daily Notes, creating the current day's note when it does not exist yet. Saved items are reviewed in a simple timeline. It also handles task saving and completion toggles, attachments, search, tags, filters, a heatmap and reflection tools.
