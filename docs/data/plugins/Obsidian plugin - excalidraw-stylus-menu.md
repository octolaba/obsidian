# Excalidraw Stylus Menu

Adds a pen-triggered insertion menu to Excalidraw, opened by an S Pen tap or a hover-button tap, that places text, stickers, shapes, embedded notes or images at the point touched. Tapping the edge of an object enters connector mode for drawing arrows, and hover-button gestures copy and paste through Excalidraw's API rather than the system clipboard.
