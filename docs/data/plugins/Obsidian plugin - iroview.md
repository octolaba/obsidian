# IroView

IroView previews HEX, RGB and HSL color values inline in the editor and in reading view, drawing swatches and optionally colorizing the text, comparably to the color preview in VSCode. Text is colorized only when the contrast is sufficient, and the plugin states that large notes are processed efficiently.

    id:     "iroview"
    name:   "IroView"

    about:       "Preview HEX, RGB(A), and HSL(A) color values inline in the editor and reading view with swatches and optional text colorization. Keep text readable by only colorizing when contrast is sufficient and process large notes efficiently."
