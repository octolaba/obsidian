# Pretty Paragraphs

Styles paragraphs in the manner of a novel, replacing the vertical space between paragraphs with a 2em first-line indent for a book-like layout. The style applies in both Live Preview and Reading view, with optional justification and folder whitelisting.

```cue
plugin: {
    id:     "pretty-paragraphs"
    name:   "Pretty Paragraphs"
    author: "meljadyn"
    repo:   "meljadyn/obsidian-pretty-paragraphs"

    html_url:    "https://community.obsidian.md/plugins/pretty-paragraphs"
    github_url:  "https://github.com/meljadyn/obsidian-pretty-paragraphs"
    description: "Styles paragraphs to be indented in the style of a novel: indents first lines and removes space between paragraphs. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Apply manuscript-style typography by replacing vertical paragraph spacing with 2em first-line indents for a book-like layout. Show the style in both Editor (Live Preview) and Reading views, with optional justification and folder whitelisting"

    stats: {
        downloads:  384
        updated_at: 1784267588000
    }
}
```
