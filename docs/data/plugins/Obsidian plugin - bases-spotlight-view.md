# Bases Spotlight View

Bases Spotlight View presents files in two panes, a large center pane for the content and a right sidebar for structured metadata. Markdown, images and PDFs render natively, binaries receive a shadow sidecar note, and metadata fields are edited, reordered and resized inline with the layout persisted.
