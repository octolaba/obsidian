# Scholia

Scholia imports academic PDFs into per-paper folders and converts them to Markdown for close reading. It generates key-sentence highlights, extracts likely technical terms into a local Markdown glossary, and shows cached, paper-grounded explanations on hover, with an explicit Explain action when one is needed.
