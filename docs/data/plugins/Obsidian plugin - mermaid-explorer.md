# Mermaid Explorer

Indexes every Mermaid diagram in the vault into a dedicated explorer with search, filters and dashboard statistics. Diagrams are previewed and zoomed, and edited with live rendering and error diagnostics, with the edit written back to the original Markdown block. Diagrams are exported as SVG or PNG.
