# Time Stamp Hider

Time Stamp Hider hides Zettelkasten-style timestamp prefixes from the display text of internal links so only the human title shows. Filenames, Markdown source, aliases and backlinks are left unchanged, the prefix is matched by a custom regular expression, and hiding applies in Reading View and Live Preview where rendering is stable.

```cue
plugin: {
    id:     "time-stamp-hider"
    name:   "Time Stamp Hider"
    author: "LeonYew-Ley"
    repo:   "leonyew-ley/obsidian-time-stamp-hider"

    html_url:    "https://community.obsidian.md/plugins/time-stamp-hider"
    github_url:  "https://github.com/leonyew-ley/obsidian-time-stamp-hider"
    description: "Hide timestamp prefixes in Zettelkasten-style internal link display text without changing notes or filenames. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Hide timestamp prefixes (e.g., 2603040057) from Zettelkasten-style internal link display text so links show only the human title. Keep filenames, Markdown source, aliases and backlinks unchanged, support a custom prefix regular expression, and apply hiding in Reading View and Live Preview where stable rendering allows."
```
