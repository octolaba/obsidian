# Daily Note Pinner

Keeps the daily note of the present day pinned and unpins the daily notes of past and future days. It expects the default YYYY-MM-DD daily note format.

```cue
plugin: {
    id:     "daily-note-pinner"
    name:   "Daily Note Pinner"
    author: "lukemt"
    repo:   "lukemt/obsidian-daily-note-pinner"

    html_url:    "https://community.obsidian.md/plugins/daily-note-pinner"
    github_url:  "https://github.com/lukemt/obsidian-daily-note-pinner"
    description: "Pin the daily note of the present day. Unpin all daily notes of past and future days."
    about:       "Keep today's Daily Note pinned and unpin all past and future Daily Notes automatically to keep focus on the current day. Require the default YYYY-MM-DD Daily Note format."

    stats: {
        downloads:  9790
        updated_at: 1698431793000
    }
}
```
