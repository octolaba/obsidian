# Wayback Linker

Archives the external http and https links of the active note, or of the whole vault, by sending them to the Wayback Machine through Save Page Now. The original links are then replaced with the archived snapshot addresses, falling back to a recent snapshot when a fresh capture is not available. Vault-wide scans can be cancelled while running, and ignored domains are skipped.

```cue
plugin: {
    id:     "wayback-linker"
    name:   "Wayback Linker"
    author: "Real-Fruit-Snacks"
    repo:   "real-fruit-snacks/wayback-linker"

    html_url:    "https://community.obsidian.md/plugins/wayback-linker"
    github_url:  "https://github.com/real-fruit-snacks/wayback-linker"
    description: "Archive external links in the active note with the Wayback Machine and replace them with snapshot URLs. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Archive external http and https links in the active note or across the entire vault using the Wayback Machine. Replace original links with archived snapshot URLs, send captures via Save Page Now, fall back to recent snapshots if needed, run cancelable vault-wide scans, and skip ignored domains."

    stats: {
        downloads:  112
        updated_at: 1783649319000
    }
}
```
