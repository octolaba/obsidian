# Vale Linter

Integrates the Vale prose linter so style and grammar issues appear inline in the editor. Checking is configurable and offline-first, with severity-based highlights, hover tooltips and real-time updates as the text changes. A status bar item summarizes the issues found in the current document.

```cue
plugin: {
    id:     "vale-linter"
    name:   "Vale Linter"
    author: "chrischinchilla"
    repo:   "chrischinchilla/obsidian-vale"

    html_url:    "https://community.obsidian.md/plugins/vale-linter"
    github_url:  "https://github.com/chrischinchilla/obsidian-vale"
    description: "Integrates Vale prose linter, showing style and grammar issues inline. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Integrate the Vale prose linter into Obsidian to get configurable, offline-first inline style and grammar checking directly in your editor. Show severity-based highlights with hover tooltips, real-time checking, and a status-bar summary of document issues."

    stats: {
        downloads:  89
        updated_at: 1785841772000
    }
}
```
