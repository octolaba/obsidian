# Flash Navigation

Jumps to visible text by typing characters, which highlights the exact matches and assigns a label to each of them. Pressing a single label key moves to that location, while a status bar shows the current query. The highlight styling is customizable.

```cue
plugin: {
    id:     "flash-navigation"
    name:   "Flash Navigation"
    author: "erl-koenig"
    repo:   "erl-koenig/obsidian-flash-navigation"

    html_url:    "https://community.obsidian.md/plugins/flash-navigation"
    github_url:  "https://github.com/erl-koenig/obsidian-flash-navigation"
    description: "Jump to any visible text instantly by typing characters and using labeled shortcuts for fast navigation. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Jump to any visible text by typing characters to highlight exact matches and auto-assign jump labels. Press a single label key to jump to a location while a live status bar shows your query and styling keeps highlights precise and customizable."

    stats: {
        downloads:  2131
        updated_at: 1778962229000
    }
}
```
