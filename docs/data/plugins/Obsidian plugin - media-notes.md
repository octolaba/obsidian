# Media Notes

Takes notes on YouTube videos and podcasts from inside Obsidian: a video is saved to a media note in one click and playback is driven by in-note hotkeys. Clickable timestamps are inserted to jump back to a moment, and playback resumes where it was left off.

```cue
plugin: {
    id:     "media-notes"
    name:   "Media Notes"
    author: "jemstelos"
    repo:   "jemstelos/obsidian-media-notes"

    html_url:    "https://community.obsidian.md/plugins/media-notes"
    github_url:  "https://github.com/jemstelos/obsidian-media-notes"
    description: "Take notes on YouTube videos and podcasts with media controls and timestamps."
    about:       "Capture and replay insights from YouTube, podcasts, and lectures directly into Obsidian notes. Save a YouTube video to a media note with one click, control playback with in-note hotkeys, and insert clickable timestamps to jump back to key moments. Resume playback where you left off."

    stats: {
        downloads:  25247
        updated_at: 1724475961000
    }
}
```
