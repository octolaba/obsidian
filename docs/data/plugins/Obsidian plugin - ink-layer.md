# Inkplane

Provides an infinite handwriting canvas built for Apple Pencil and other pens, with pressure-aware ink, palm rejection, coalesced pointer sampling and smooth pan and zoom. Each sketch is stored as a portable JSON file with an inklayer extension in the vault, so drawings move, sync and back up with the notes. Read-only previews can be embedded in any note, the original canvas opens for edits, SVG export is available, and the recorded inputs describe everything as staying local and private.
