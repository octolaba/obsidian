# Microsoft-Compatible Link

Copies or opens a shareable obsid.net URL for the current note. The plugin wraps Obsidian's obsidian:// deep link in a standard https:// address so that it stays clickable in chat applications and email, and the copy or open action runs from the command palette or a ribbon icon.

```cue
plugin: {
    id:     "obsid-link"
    name:   "Microsoft-Compatible Link"
    author: "Leon Greil"
    repo:   "lgreil/obsid-link"

    html_url:    "https://community.obsidian.md/plugins/obsid-link"
    github_url:  "https://github.com/lgreil/obsid-link"
    description: "Copy or open a shareable obsid.net link for the current note — a clickable HTTPS wrapper around Obsidian deep links. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Copy or open a shareable obsid.net URL for any note with one click. Wrap Obsidian's obsidian:// deep links in a standard https:// URL so links stay clickable in chat apps and email, and use the Command Palette or ribbon icon to copy or open the current note via obsid.net."

    stats: {
        downloads:  464
        updated_at: 1780917139000
    }
}
```
