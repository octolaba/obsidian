# Previous River

Navigates between notes using the previous frontmatter property or backlinks, jumping to the previous, next, first, or last note in a chain. When several candidates exist a suggestion modal offers the choice, and a note can be inserted into a backlink sequence or detached from it.

    id:     "previous-river"
    name:   "Previous River"
    author: "ongaeshi"
    repo:   "ongaeshi/previous-river"

    github_url:  "https://github.com/ongaeshi/previous-river"
