# Awesome Image

This plugin centralizes image files by copying pasted or linked images into a folder you define, giving them uniform names and updating the Markdown links. Images from the web are downloaded and pasted or binary images processed immediately, so the vault stays offline and consistent. Unlinked images are listed for cleanup.

```cue
plugin: {
    id:     "awesome-image"
    name:   "Awesome Image"
    author: "awesomedog"
    repo:   "awesomedog/obsidian-awesome-image"

    html_url:    "https://community.obsidian.md/plugins/awesome-image"
    github_url:  "https://github.com/awesomedog/obsidian-awesome-image"
    description: "One-stop solution for image management and viewing."
    about:       "Centralize image files by copying pasted or linked images into a user-defined folder with uniform names and update Markdown links. Auto-download web images and process pasted or binary images immediately to keep your vault offline and consistent. List unlinked images for easy cleanup."

    stats: {
        downloads:  15296
        updated_at: 1706770830000
    }
}
```
