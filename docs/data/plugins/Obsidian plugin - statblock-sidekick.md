# Statblock Sidekick

Custom D&D 5e sidekicks are built from the rules of Tasha's Cauldron and written out as new statblock notes in Fantasy Statblocks format. Class, level and features are selected interactively, and the result is saved beside the original statblock or into a chosen folder.

plugin: {
    id:     "statblock-sidekick"
    name:   "Statblock Sidekick"
    author: "n21rl"
    repo:   "n21rl/stablock-sidekick"

    html_url:    "https://community.obsidian.md/plugins/statblock-sidekick"
    github_url:  "https://github.com/n21rl/stablock-sidekick"
