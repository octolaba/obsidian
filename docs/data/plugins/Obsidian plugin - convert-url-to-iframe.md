# Convert url to preview (iframe)

This plugin converts a URL into an embedded iframe preview inside the note. YouTube timestamps are preserved and OEmbed is used for correct sizing, with fullscreen allowed and responsive aspect ratios. Links can be embedded from the right-click menu or from a command.

```cue
plugin: {
    id:     "convert-url-to-iframe"
    name:   "Convert url to preview (iframe)"
    author: "fhachez"
    repo:   "fhachez/obsidian-convert-url-to-iframe"

    html_url:    "https://community.obsidian.md/plugins/convert-url-to-iframe"
    github_url:  "https://github.com/fhachez/obsidian-convert-url-to-iframe"
    description: "Convert a URL (e.g. YouTube) into an iframe (preview)."
    about:       "Convert any URL into an embedded iframe preview directly inside your note. Preserve YouTube timestamps and rely on OEmbed for correct sizing, allow fullscreen and responsive aspect ratios, and embed links via right-click or command."

    stats: {
        downloads:  106204
        updated_at: 1651923369000
    }
}
```
