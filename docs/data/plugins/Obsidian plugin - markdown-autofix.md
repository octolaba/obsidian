# Markdown Autofix

Checks the active note for Markdown syntax errors as it is edited and repairs the ones it treats as safely fixable, applying each repair as a fully undoable editor transaction. Problems are marked with wavy underlines, counted, and listed in a sidebar with jump-and-fix actions. Code fences and the line under the cursor are ignored, and commands are provided to promote or demote headings across a selection.

```cue
plugin: {
    id:     "markdown-autofix"
    name:   "Markdown Autofix"
    author: "swift"
    repo:   "bwtymdb/obsidian-md-autofix"

    html_url:    "https://community.obsidian.md/plugins/markdown-autofix"
    github_url:  "https://github.com/bwtymdb/obsidian-md-autofix"
    description: "Detects Markdown syntax errors in the active note in real time and automatically fixes the safely fixable ones. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Detect Markdown syntax errors in real time and auto-fix safely fixable issues with fully undoable editor transactions. Show wavy underlines, an error count and a sidebar list with jump-and-fix actions, plus commands to promote/demote headings in a selection; ignore code fences and the cursor line."
```
