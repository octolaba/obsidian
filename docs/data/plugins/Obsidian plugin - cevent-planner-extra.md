# CEvent Planner Extra

CEvent Planner Extra generates formatted event Markdown through a Material Design modal and copies it to the clipboard instead of forcing a file to be created. Single or multi-day schedules, time ranges, alarms, emojis, tags, notes and recurrence can be specified before the result is pasted anywhere. Tracking those events requires the CEvent Planner plugin itself.

```cue
plugin: {
    id:     "cevent-planner-extra"
    name:   "CEvent Planner Extra"
    author: "abdur-nur-porag"
    repo:   "abdur-nur-porag/CEvent-Planner-Extra"

    html_url:    "https://community.obsidian.md/plugins/cevent-planner-extra"
    github_url:  "https://github.com/abdur-nur-porag/CEvent-Planner-Extra"
    description: "A extra plugin for CEvent-Planner - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Generate and copy formatted event Markdown using a clean Material Design modal. Specify single or multi-day schedules, time ranges, alarms, emojis, tags, notes and recurrence, then paste anywhere via clipboard mode without forcing file creation (requires CEvent Planner for tracking)."

    stats: {
        downloads:  119
        updated_at: 1780045784000
    }
}
```
