# Link Favicons

Shows the favicon of a linked website directly in notes, without custom CSS, and the recorded inputs state that it works alongside several community plugins such as Admonition and RSS Reader. Several icon providers can be chosen, icons can be overridden or defined for URI schemes, and an individual link can opt out with a nofavicon marker.

```cue
plugin: {
    id:     "link-favicon"
    name:   "Link Favicons"
    author: "Johannes Theiner"
    repo:   "joethei/obsidian-link-favicon"

    html_url:    "https://community.obsidian.md/plugins/link-favicon"
    github_url:  "https://github.com/joethei/obsidian-link-favicon"
    description: "See the favicon for a linked website."
    about:       "Display favicons for web links directly in notes without custom CSS, working with many community plugins (Admonition, RSS Reader, etc.). Choose from multiple icon providers, override icons or define icons for URI schemes, and disable per-link display with |nofavicon."

    stats: {
        downloads:  62005
        updated_at: 1778608815000
    }
}
```
