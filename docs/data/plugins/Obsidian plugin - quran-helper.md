# Quran Helper

Finds and inserts Quran verses, whole surahs and mushaf pages into a note, formatted as a callout, as a blockquote or inline within a paragraph. Search matches partial input, supports Arabic normalization and accepts numeric references, and the recorded About states that it works fully offline. A modifier with Enter inserts the verse inline immediately.

```cue
plugin: {
    id:     "quran-helper"
    name:   "Quran Helper"
    author: "Ammar Alakkad"
    repo:   "ammarcodes/obsidian-quran-helper-plugin"

    html_url:    "https://community.obsidian.md/plugins/quran-helper"
    github_url:  "https://github.com/ammarcodes/obsidian-quran-helper-plugin"
    description: "Find and insert any Quran Ayah (verse) in your notes."
    about:       "أدرج آيات القرآن والسور وصفحات المصحف مباشرة في ملاحظات Obsidian بصيغ Callout أو Blockquote أو مدمج داخل الفقرة. ابحث بسرعة بمطابقة جزئية مع دعم التطبيع العربي والبحث بالأرقام واعمل بالكامل دون اتصال؛ أدخل مدمجًا فورًا بالضغط Mod+Enter."

    stats: {
        downloads:  1752

}
```
