# ManicTime

Sends the path of the active file to a locally installed ManicTime client. The current note then shows up as ManicTime activity, which the recorded text presents as a way to track time accurately.

```cue
plugin: {
    id:     "manictime"
    name:   "ManicTime"
    author: "manictime"
    repo:   "manictime/manictime-obsidian"

    html_url:    "https://community.obsidian.md/plugins/manictime"
    github_url:  "https://github.com/manictime/manictime-obsidian"
    description: "Send the path of the active file to locally installed ManicTime client."
    about:       "Send the path of the active file to a locally installed ManicTime client. Display the current Obsidian note as ManicTime activity for accurate time tracking."

    stats: {
        downloads:  2225
        updated_at: 1701771384000
    }
}
```
