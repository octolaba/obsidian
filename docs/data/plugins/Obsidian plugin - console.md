# Console Markdown

Console Markdown renders console commands and their output as styled blocks. A fenced code block marked console is shown with its prompts, its commands and the resulting output distinguished from one another.

```cue
plugin: {
    id:     "console"
    name:   "Console Markdown"
    author: "dellermann"
    repo:   "dellermann/obsidian-console"

    html_url:    "https://community.obsidian.md/plugins/console"
    github_url:  "https://github.com/dellermann/obsidian-console"
    description: "Render console commands and their output."
    about:       "Render console commands and their output as styled blocks in your notes. Use fenced code blocks marked \"console\" to show prompts, commands, and resulting output clearly."

    stats: {
        downloads:  5654
        updated_at: 1707127677000
    }
}
```
