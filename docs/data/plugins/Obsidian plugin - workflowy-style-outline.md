# Workflowy-Style Outline

Turns a Markdown note into a Workflowy-style outline editor with block-level editing, drag-and-drop reordering, collapsing and expanding, zoom focus, multi-selection and real-time search. The underlying content stays native Obsidian Markdown, and a save queue backs the real-time sync together with atomic undo and redo. Mobile is supported.
