# Shogi KIF Viewer

Shogi KIF Viewer renders interactive shogi boards from KIF, SFEN, BOD and CSA code blocks in notes. The embedded board navigates moves and variations, shows captured pieces, comments, elapsed time and game metadata, and can autoplay or jump to any move.
