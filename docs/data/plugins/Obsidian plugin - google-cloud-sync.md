# Google Sync

Synchronizes the vault to a Google backend the user owns, either Google Drive or a Google Cloud Storage bucket, through their own Google account and with no third-party server in between. The sync is two-way, preserves conflicts, injects no metadata and rewrites no files, and end-to-end encryption is optional. Large vaults, attachments and filenames with special characters or non-English text are handled.
