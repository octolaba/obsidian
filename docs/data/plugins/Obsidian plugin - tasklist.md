# Projex

Projex manages tasks in a centralized SQLite database, with creation, editing, status cycling and removal, priority filters, a sidebar task panel, and inline tasklist code blocks that reference tasks by identifier. OKRs are tracked through their own code blocks, and calendar workboards provide dashboards and multiple project databases. Reports are generated with integrated AI tools.
