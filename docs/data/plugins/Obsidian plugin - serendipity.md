# Serendipity

Serendipity displays a random note from the vault each time Obsidian opens, forcing chance rediscoveries. Folders can be included or excluded, the note appears in a themed modal, and the source file can be opened from there.

```cue
plugin: {
    id:     "serendipity"
    name:   "Serendipity"
    author: "ggauravr"
    repo:   "ggauravr/obsidian-serendipity-plugin"

    html_url:    "https://community.obsidian.md/plugins/serendipity"
    github_url:  "https://github.com/ggauravr/obsidian-serendipity-plugin"
    description: "Forces serendipitous discoveries by displaying random notes from your vault each time you open the app"
    about:       "Display a random note from your vault each time you open Obsidian. Choose folders to include or exclude, view the note in a themed modal, and jump straight to the source file."

    stats: {
        downloads:  1050
        updated_at: 1722580090000
    }
}
```
