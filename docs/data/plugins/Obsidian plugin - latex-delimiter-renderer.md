# LaTeX Delimiter Renderer

Renders LaTeX math written with backslash-parenthesis and backslash-bracket delimiters alongside Obsidian's own dollar-sign syntax, without changing the Markdown files. Math appears in Live Preview and Reading View, including multiline display equations, and the original delimiters reappear while the cursor sits inside a formula. Inline and fenced code blocks are left untouched, and rendering uses the MathJax that Obsidian already bundles, so it works offline.
