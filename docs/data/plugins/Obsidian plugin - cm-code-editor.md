# CM Code Editor

Edits code files inside Obsidian through a CodeMirror 6 editor with syntax highlighting for more than twenty languages and more than forty-five themes. Autocompletion covers JavaScript, TypeScript, CSS, HTML, SQL and Python, alongside code folding, indent guides, multiple cursors, bracket matching, search and replace, and line numbers. New code files are created from a command or a context menu.
