# Table Fields

Gives table columns a type, covering checkbox, select, date, currency and percentage, and renders inline controls for them in Live Preview and Reading view. Checkboxes are ticked, dropdown values picked, and dates and money shown formatted, inside the note. The recorded description states that the table stays a plain pipe table on disk.
