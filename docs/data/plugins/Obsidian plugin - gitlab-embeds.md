# GitLab Embeds

Embeds GitLab issues, merge requests, projects and other resources into notes for reference in place. Content is fetched from gitlab.com or a self-hosted instance and rendered in preview mode.

```cue
plugin: {
    id:     "gitlab-embeds"
    name:   "GitLab Embeds"
    author: "oliviergoulet5"
    repo:   "oliviergoulet5/obsidian-gitlab-plugin"

    html_url:    "https://community.obsidian.md/plugins/gitlab-embeds"
    github_url:  "https://github.com/oliviergoulet5/obsidian-gitlab-plugin"
    description: "Integrate GitLab embeds into your notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed GitLab issues, merge requests, projects and other resources directly into notes for quick reference and richer context. Fetch and render content from gitlab.com or self-hosted GitLab instances in preview mode."

    stats: {
        downloads:  126
        updated_at: 1770265531000
    }
}
```
