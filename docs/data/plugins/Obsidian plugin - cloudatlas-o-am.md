# Amazing Marvin Integration

Imports Marvin categories, projects and tasks into the vault as matching folders, folder-notes and Markdown checklists, with nested subtasks and parent wiki links. New Marvin tasks are created from Obsidian using Marvin shorthand, and deep links lead back to Marvin. The import runs one way and replaces the previously synced folders and notes on each run, and the integration is recorded as unofficial.

```cue
plugin: {
    id:     "cloudatlas-o-am"
    name:   "Amazing Marvin Integration"
    author: "open-horizon-labs"
    repo:   "open-horizon-labs/obsidian-am"

    html_url:    "https://community.obsidian.md/plugins/cloudatlas-o-am"
    github_url:  "https://github.com/open-horizon-labs/obsidian-am"
    description: "Integration with Amazing Marvin (unofficial). Supports exporting AM tasks/projects, creating new tasks and completing tasks."
    about:       "Sync Amazing Marvin categories, projects, and tasks into Obsidian as matching folders, folder-notes, and markdown checklists with nested subtasks and parent wiki links. Create Amazing Marvin tasks from Obsidian using Marvin shorthand and open deep links back to Marvin. Import runs unidirectionally and replaces previously synced folders and notes on each sync."
```
