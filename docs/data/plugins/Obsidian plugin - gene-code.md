# Gene Code

Renders lollipop and pedigree diagrams for DNA variants as inline SVG figures written as gene-code blocks in a note. The figures are described as staying meaningful across light and dark themes, and a block that cannot be parsed shows an inline error.

```cue
plugin: {
    id:     "gene-code"
    name:   "Gene Code"
    author: "Anton"
    repo:   "neznayer/obsidian-gene-code"

    html_url:    "https://community.obsidian.md/plugins/gene-code"
    github_url:  "https://github.com/neznayer/obsidian-gene-code"
    description: "Render lifescience DNA variants lollipop and pedigree diagrams in Obsidian notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render gene-code lollipop and pedigree diagrams inline as SVG figures by writing code blocks in Obsidian notes. Stay meaningful across light and dark themes, and show inline errors for unparseable blocks. Proposals for new additional types of diagrams are highly appreciated! Write me an Issue on the Github page."

    stats: {
        downloads:  56
        updated_at: 1783013055000
    }
}
```
