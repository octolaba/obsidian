# Inline Ruby Annotation

Renders Inline Annotation syntax, covering ruby, bouten, underline and two-slot annotations, in reading view and Live Preview. Existing links, code, preformatted blocks, ruby, scripts, styles and elements marked with the ignore attribute are skipped, and phonetic readings are aligned per character while multi-word glosses stay grouped.

```cue
plugin: {
    id:     "inline-annotation"
    name:   "Inline Ruby Annotation"
    author: "Baksi Li"
    repo:   "baksili/obsidian-inline-annotation"
```
