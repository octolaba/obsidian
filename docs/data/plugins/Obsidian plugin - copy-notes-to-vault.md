# Copy Notes to Vault

Copy Notes to Vault copies notes from one vault to another through a searchable folder-tree selector, optionally preserving the source folder hierarchy. All referenced attachments, both embedded and linked, are copied along with the notes. The destination is chosen with a native folder picker, and the last used destination and preferences are remembered.
