# Inline spoilers

Inline spoilers adds Discord-like syntax that hides text inside a note between double pipes. A hidden span is revealed or hidden again by clicking, all spoilers can optionally be shown at once, and the appearance is adjustable through the CSS variables and classes the plugin provides.

```cue
plugin: {
    id:     "inline-spoilers"
    name:   "Inline spoilers"
    author: "logonoff"
    repo:   "logonoff/obsidian-inline-spoilers"

    html_url:    "https://community.obsidian.md/plugins/inline-spoilers"
    github_url:  "https://github.com/logonoff/obsidian-inline-spoilers"
    description: "Adds Discord-like syntax for inline spoilers."
    about:       "Add inline spoilers using the ||...|| syntax to hide text within notes. Reveal or hide spoilers by clicking, optionally show all spoilers at once, and customize appearance with provided CSS variables and classes."
```
