# Safi Site Audit

Safi Site Audit runs website audits from inside the vault, crawling multiple pages and covering SEO, content, links, images, security and crawlability. Each audit is saved as a self-contained Markdown note, and a built-in dashboard shows overall scores, category breakdowns, per-page issues and the fuller report data. Adding PageSpeed Insights extends an audit with Core Web Vitals and accessibility checks.

```cue
plugin: {
    id:     "safi-site-audit"
    name:   "Safi Site Audit"
    author: "Abdulkader Safi"
    repo:   "abdulkader-safi/obsidian-safi-site-audit-plugins"

    html_url:    "https://community.obsidian.md/plugins/safi-site-audit"
    github_url:  "https://github.com/abdulkader-safi/obsidian-safi-site-audit-plugins"
    description: "Run website audits (SEO, content, links, images, security, crawlability and more) and save each one as a Markdown note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Run website audits from inside your vault and crawl multiple pages. Save each audit as a self-contained Markdown note and view overall scores, category breakdowns, per-page issues and rich report data in a built-in dashboard; add PageSpeed Insights to include Core Web Vitals and accessibility checks."
```
