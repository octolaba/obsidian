# Smart Chat

Stores AI conversations inside the note they belong to, embedding a chat block that holds the thread URL and its status so the thread can be resumed later or marked as done. ChatGPT, Claude, Gemini and Grok are supported without an API key. Saved threads can be surfaced with Dataview.

```cue
plugin: {
    id:     "smart-chatgpt"
    name:   "Smart Chat"
    author: "🌴 Brian"
    repo:   "brianpetro/smart-chatgpt-obsidian"

    html_url:    "https://community.obsidian.md/plugins/smart-chatgpt"
    github_url:  "https://github.com/brianpetro/smart-chatgpt-obsidian"
    description: "Integrate OpenAI's ChatGPT seamlessly in notes. Automatically saves links, allows marking threads as done, and integrates with Dataview."
```
