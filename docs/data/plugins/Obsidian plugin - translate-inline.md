# Translate Inline

Translate Inline translates a word or a sentence written in a bracket syntax and replaces the original text once the cursor leaves the brackets. Source and target languages can be given inline, and DeepL or Google Cloud Translation is used through an API key.

```cue
plugin: {
    id:     "translate-inline"
    name:   "Translate Inline"
    author: "kon-foo"
    repo:   "kon-foo/Obsidian-Translate-Inline"

    html_url:    "https://community.obsidian.md/plugins/translate-inline"
    github_url:  "https://github.com/kon-foo/Obsidian-Translate-Inline"
    description: "Translations at your fingertips. Inline Translations for your Notes."
    about:       "Translate words or sentences inline using bracket syntax like [>Buenos días] and replace the original text automatically when the cursor leaves the brackets. Specify source and/or target languages inline (e.g., es>de>text) and use DeepL or Google Cloud Translation via your API key."

    stats: {
        downloads:  889
        updated_at: 1709672357000
    }
}
```
