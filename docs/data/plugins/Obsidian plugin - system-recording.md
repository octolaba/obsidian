# System Recording

Records macOS system audio from calls such as Zoom, Meet and Teams together with the microphone, saving M4A files encoded as AAC into the vault. Recording is started from a ribbon button or the command palette, with elapsed time shown in the status bar. When a recording finishes, a link to the file is inserted into the current note.

```cue
plugin: {
    id:     "system-recording"
    name:   "System Recording"
    author: "Yuto Takagi"
    repo:   "yut0takagi/obsidian-system-recording"

    html_url:    "https://community.obsidian.md/plugins/system-recording"
    github_url:  "https://github.com/yut0takagi/obsidian-system-recording"
    description: "Record system audio (Zoom, Meet, Teams) and save as M4A in your vault - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Record macOS system audio (Zoom/Meet/Teams) and microphone simultaneously and save M4A (AAC) files directly into your Vault. Control recordings from a ribbon button or command palette, view elapsed time in the status bar, and auto-insert a link to the file into the current note upon completion."
```
