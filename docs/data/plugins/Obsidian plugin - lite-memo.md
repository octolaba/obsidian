# Lite Memo

Captures short inspirations and stray thoughts through a shortcut that opens an input box, timestamps the entry automatically, and saves it into a daily Markdown log. Keywords add tags automatically, and tags can be aggregated and searched. The recorded inputs also describe converting an entry into a task with time tracking, a built-in Pomodoro timer, a log view that updates in real time, and compatibility with the Logseq journal format.

    id:     "lite-memo"
    name:   "Lite Memo"
    author: "fengshuzi"
    repo:   "fengshuzi/lite-memo"

    github_url:  "https://github.com/fengshuzi/lite-memo"
    description: "Quickly jot down inspirations and random thoughts. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Quickly jot down inspirations and random thoughts, like posting on Weibo, with a shortcut key to pop up an input box, automatically timestamp, and save as a daily Markdown log. Use smart keywords to automatically add tags, supporting tag aggregation and search. Convert inspiration directly into tasks and track time spent; a built-in Pomodoro timer and real-time updated log view, compatible with Logseq journal format."
