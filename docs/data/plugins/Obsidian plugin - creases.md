# Creases

Creases folds Markdown sections using inline comment markers called creases, and a fold-along-creases command restores the saved fold state. Creases can be toggled, created from the current folds, and ironed out to remove a saved fold layout. Folding can also be driven by heading level, with commands to change the fold level in a vim-style way.

```cue
plugin: {
    id:     "creases"
    name:   "Creases"
    author: "Liam Cain"
    repo:   "liamcain/obsidian-creases"

    html_url:    "https://community.obsidian.md/plugins/creases"
    github_url:  "https://github.com/liamcain/obsidian-creases"
    description: "Tools for effectively folding Markdown sections."
    about:       "Fold markdown sections using %% fold %% markers called creases and run Fold along creases to restore saved fold states. Toggle creases, crease current folds, and iron out creases to manage and remove saved fold layouts. Fold by heading level or change fold level for vim-style control."

    stats: {

}
```
