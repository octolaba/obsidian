# Explain Selection With AI

Expands on a selected passage using an LLM endpoint compatible with the OpenAI chat completion API, invoked from the editor context menu. The explanation is generated with the surrounding notes as context rather than from the selection alone.

```cue
plugin: {
    id:     "explain-selection-with-ai"
    name:   "Explain Selection With AI"
    author: "bwurster"
    repo:   "bwurster/explain-selection-with-ai"

    html_url:    "https://community.obsidian.md/plugins/explain-selection-with-ai"
    github_url:  "https://github.com/bwurster/explain-selection-with-ai"
```
