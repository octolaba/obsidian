# Floccus Bookmarks to Markdown

Imports bookmarks from Floccus by reading an XBEL file and converting it into a Markdown file inside the vault. Backup copies are created, and automatic updates keep the generated bookmark file current.

```cue
plugin: {
    id:     "floccus-bookmarks-to-markdown"
    name:   "Floccus Bookmarks to Markdown"
    author: "mddevils"
    repo:   "mddevils/floccus-bookmarks-to-markdown"

    html_url:    "https://community.obsidian.md/plugins/floccus-bookmarks-to-markdown"
    github_url:  "https://github.com/mddevils/floccus-bookmarks-to-markdown"
    description: "Import and convert your bookmarks from Floccus."
    about:       "Import and convert bookmarks from an XBEL file into a Markdown file inside your vault. Create backup copies and enable automatic updates to keep the generated bookmark file current."

    stats: {
        downloads:  7099
        updated_at: 1690307356000
    }
}
```
