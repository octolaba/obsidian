# Law Lookup for Germany + Austria + Switzerland

Looks up references to supported German federal laws and previews the official German or the published English text before inserting it. The text is inserted into the active note with optional source, reference, retrieval date and cache metadata, official German text is the default, and lookups are restricted to the supported federal laws. The plugin name also names Austria and Switzerland, while the recorded description and About text mention German federal law only.

```cue
plugin: {
    id:     "german-law-lookup"
    name:   "Law Lookup for Germany + Austria + Switzerland"
    author: "GammaFunds"
    repo:   "gammafunds/german-law-lookup"

    html_url:    "https://community.obsidian.md/plugins/german-law-lookup"
    github_url:  "https://github.com/gammafunds/german-law-lookup"
    description: "Look up German federal law references in Obsidian and insert formatted law text into notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Look up supported German federal law references in Obsidian and preview official German or published English law text before inserting. Insert formatted law text into the active note with optional source, reference, retrieval date and cache metadata, defaulting to official German text and restricting lookups to supported federal laws only."

    stats: {
        downloads:  130
        updated_at: 1784283713000
    }
}
```
