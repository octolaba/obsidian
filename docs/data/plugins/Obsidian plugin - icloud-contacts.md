# iCloud Contacts

iCloud Contacts imports contacts from iCloud and manages one note per contact in a vault folder, storing details such as name, organization, telephone, email, birthday and social profiles in frontmatter. Any other file content is left untouched when a contact is updated, sync can be limited to selected groups, and a Nextcloud address book URL can be targeted instead.

```cue
plugin: {
    id:     "icloud-contacts"
    name:   "iCloud Contacts"
    author: "trulsaa"
    repo:   "trulsaa/obsidian-icloud-contacts"

    html_url:    "https://community.obsidian.md/plugins/icloud-contacts"
    github_url:  "https://github.com/trulsaa/obsidian-icloud-contacts"
    description: "Imports contacts from iCloud and manages a note for each contact."
    about:       "Sync iCloud contacts to a folder in your vault as individual Markdown files with contact details stored in frontmatter. Create or update each contact's title and properties (name, organization, telephone, email, birthday, social profiles) while leaving any extra file content untouched. Limit sync to selected groups or target a Nextcloud address book URL."
```
