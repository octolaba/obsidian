# Any AI CLI

Runs a local AI coding CLI, Claude Code, Codex, Aider or a custom one, inside a PTY-backed terminal in the right sidebar. Any number of CLI runtimes can be declared with their launch commands, picked from a dropdown and started in the active vault folder. The active file or folder is inserted into the CLI standard input with one click, processes are controlled from a toolbar, and runtime status and errors are displayed.
