# Code Space

Manages code files in the vault from a visual dashboard with a unified index, dynamic filtering and the standard file operations. Editing happens in a CodeMirror 6 space with syntax highlighting, outline navigation and regex search and replace, and code can be embedded and previewed inside Markdown. PDF export and mounting external folders through symlinks are included.
