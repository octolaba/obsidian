# O-Dashboard

Collects memos, todos, projects and shortcuts on a single dashboard page for the vault. Memo cards are writable and accept wikilinks, checklists are interactive with drag-and-drop and progress, project cards carry previews and covers, a native month calendar shows dated tasks, and quick actions can be pinned alongside sidebar widgets such as a week calendar and weather. The interface is styled as glassmorphism.
