# Ollama

Ollama runs local models over note text to summarise, explain, expand, rewrite or caption a selection. Rewrites cover formal, casual, active-voice and bullet variants, prompts are customisable, and the model and temperature are chosen in settings. A prompt is sent with the selection or the whole note and the result is inserted at the cursor.
