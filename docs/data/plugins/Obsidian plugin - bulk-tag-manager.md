# Bulk Tag Manager

Manages vault tags from a single dashboard, where tags are renamed, merged and standardized, including conversion to lowercase. Renames can be driven by regular expressions, and operations are aware of tag nesting and of the chosen scope. Tag statistics and the list of files a change would affect are shown before bulk modifications run.
