# GitHub Repo Tools

Monitors and manages a GitHub repository from Obsidian's sidebar, covering staleness alerts, branch switching, staging files, committing or committing and pushing, and running fetch, pull and push. Pull request dashboards carry activity badges and status-bar counts. It works against a local clone with git installed and is desktop only.

```cue
plugin: {
    id:     "github-repo-tools"
    name:   "GitHub Repo Tools"
    author: "Kyle Whittle"
    repo:   "kwhittle/obsidian-github-tools"

    html_url:    "https://community.obsidian.md/plugins/github-repo-tools"
    github_url:  "https://github.com/kwhittle/obsidian-github-tools"
    description: "Monitor a GitHub repo — staleness alerts, PR dashboard, and activity notifications. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Manage GitHub repositories from Obsidian's sidebar. Monitor staleness, switch branches, stage files, commit or commit+push, run fetch/pull/push, and view PR dashboards with activity badges and status-bar counts. Use with git and a local clone (desktop only)."

    stats: {
        downloads:  158

    }
}
```
