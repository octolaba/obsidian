# Paragraph Copy

Adds copy buttons to paragraphs whose text matches custom regular expressions. Any text block can be targeted by a regex pattern so that its content is copied in one click.

```cue
plugin: {
    id:     "paragraph-copy"
    name:   "Paragraph Copy"
    author: "chaosnino"
    repo:   "chaosnino/obsidian-paragraph-copy"

    html_url:    "https://community.obsidian.md/plugins/paragraph-copy"
    github_url:  "https://github.com/chaosnino/obsidian-paragraph-copy"
    description: "Custom regex matching for paragraphs to auto-add copy buttons. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add copy buttons to paragraphs that match custom regular expressions. Target any text blocks with regex patterns for one-click copying."

    stats: {
        downloads:  96
        updated_at: 1768528201000
    }
}
```
