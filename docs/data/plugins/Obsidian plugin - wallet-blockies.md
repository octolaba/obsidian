# Wallet Blockies

Wallet Blockies renders a deterministic blockie identicon next to Ethereum-style wallet addresses in a note. Addresses matching 0x followed by 40 hexadecimal characters are detected in Live Preview and Reading mode, and the identicon is appended while the original address stays readable and copyable.

```cue
plugin: {
    id:     "wallet-blockies"
    name:   "Wallet Blockies"
    author: "geeknees"
    repo:   "geeknees/obsidian-blockie"

    html_url:    "https://community.obsidian.md/plugins/wallet-blockies"
    github_url:  "https://github.com/geeknees/obsidian-blockie"
    description: "Show inline blockie identicons for Ethereum wallet addresses. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display deterministic inline blockie identicons beside Ethereum-style wallet addresses in notes. Detect addresses matching 0x plus 40 hexadecimal characters in Live Preview and Reading mode, and append a blockie while keeping the original address text readable and copyable."
```
