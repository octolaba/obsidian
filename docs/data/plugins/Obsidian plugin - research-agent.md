# Research Agent

Research Agent runs conversational research workflows with chat-driven tasks, progress tracking, separate evidence notes and Markdown deliverables. It can connect to Deep Research Cloud for online search, fact-checking and long-running runs; the recorded text states that the current note or selected text is sent only when explicitly shared. Completed research is exported back into the vault as Markdown.
