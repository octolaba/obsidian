# timeflow

timeflow tracks flexible work hours and time off through a dashboard combining built-in timers, live balances, an interactive calendar and daily, weekly, monthly and yearly summaries. Work hours, week structure, languages and absence types are configurable, entries can carry comments, and the data can be exported as CSV.
