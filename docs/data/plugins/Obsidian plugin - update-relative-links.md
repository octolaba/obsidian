# Update Relative Links

Updates relative Markdown links when files move, fixing both the links inside a moved file and the links in other notes that point to it. A command fixes relative links across the whole vault in one pass. Its own text states that Markdown link syntax must be used and wiki-style links disabled for this to work.

```cue
plugin: {
    id:     "update-relative-links"
    name:   "Update Relative Links"
    author: "val3344"
    repo:   "val3344/obsidian-update-relative-links"

    html_url:    "https://community.obsidian.md/plugins/update-relative-links"
    github_url:  "https://github.com/val3344/obsidian-update-relative-links"
    description: "Update relative links."
    about:       "Update relative Markdown links automatically when files move, fixing links inside moved files and in other notes that reference them. Run a command to batch-fix relative links across the vault. Use Markdown link syntax (disable wiki-style [[links]]) for proper operation."

    stats: {
        downloads:  7955
        updated_at: 1760787537000
    }
}
```
