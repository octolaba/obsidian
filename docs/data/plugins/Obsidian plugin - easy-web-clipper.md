# Easy Web Clipper

Turns a pasted link into a Markdown note without a browser extension or an external service: article content is extracted with Mozilla Readability, and navigation and ads are dropped. The result is converted to GitHub-flavored Markdown with images, tables and code preserved, and YAML front matter carrying title, source, author, date and excerpt is generated automatically.

```cue
plugin: {
    id:     "easy-web-clipper"
    name:   "Easy Web Clipper"
    author: "JC5"
    repo:   "gibsonchan-5/easy-web-clipper"

    html_url:    "https://community.obsidian.md/plugins/easy-web-clipper"
    github_url:  "https://github.com/gibsonchan-5/easy-web-clipper"
    description: "Clip web pages to clean Markdown notes with one click. Auto-extracts main content, removes ads and navigation. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Clip web pages into clean Markdown notes with one click by pasting a link inside Obsidian — no external services or browser extensions required. Extract article content with Mozilla Readability, convert to GitHub-flavored Markdown while preserving images, tables and code, and auto-generate YAML front matter with title, source, author, date and excerpt."
}
```
