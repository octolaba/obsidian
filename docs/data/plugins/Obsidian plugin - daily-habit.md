# Daily Habit

Tracks habits from diary entries through tag-based check-ins, showing a habit list, a seven-day dot view, automatic streak counts and completion totals. Results can be filtered by week or by month to review trends. The recorded inputs attribute fast loading to date-file scanning and caching.
