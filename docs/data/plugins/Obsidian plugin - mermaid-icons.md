# Mermaid Icons

Renders FontAwesome and further icon sets, including logos and Lucide, inside Mermaid diagrams. Icons are written in a diagram with a set prefix followed by the icon name, for instance fa:home. A fuzzy modal searches and inserts icons, and the supported sets are browsed and filtered from the settings tab.

```cue
plugin: {
    id:     "mermaid-icons"
    name:   "Mermaid Icons"
    author: "toshs"
    repo:   "toshs/obsidian-mermaid-icons"

    html_url:    "https://community.obsidian.md/plugins/mermaid-icons"
    github_url:  "https://github.com/toshs/obsidian-mermaid-icons"
    description: "Use Font Awesome and other icon sets within your Mermaid diagrams."
    about:       "Render Font Awesome and additional icon sets (logos, Lucide) inside Mermaid diagrams in Obsidian. Search and insert icons via a fuzzy modal and browse/filter all supported icons from settings. Add icons in diagrams using prefix:[icon-name] (e.g., fa:home)."

    stats: {
        downloads:  3127
        updated_at: 1780318183000
    }
}
```
