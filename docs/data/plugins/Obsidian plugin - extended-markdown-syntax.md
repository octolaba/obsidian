# Extended Markdown Syntax

Extended Markdown Syntax adds inline and block markup written with delimiters instead of HTML tags, covering underline, spoiler, superscript, subscript, colored highlights and custom spans. Parsing is context-aware and ignores codeblocks and codespans, so formatted text stays directly editable. Blocks use modified Pandoc-style fenced divs, and the results also render in exported PDFs.
