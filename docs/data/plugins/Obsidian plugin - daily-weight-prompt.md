# Daily Weight Prompt

Prompts for the current body weight at startup or on command, accepting integers, decimals, or a skip that is stored as null. The value is written into today's daily note frontmatter under a configurable property, the note is created when missing, and the automatic startup prompt fires at most once a day.

```cue
plugin: {
    id:     "daily-weight-prompt"
    name:   "Daily Weight Prompt"
    author: "Simplevolk"
    repo:   "lightvolk/daily-weight-prompt"

    html_url:    "https://community.obsidian.md/plugins/daily-weight-prompt"
    github_url:  "https://github.com/lightvolk/daily-weight-prompt"
    description: "Prompts for current body weight and saves it into today's daily note frontmatter. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Prompt for your current body weight at startup or on command, accepting integers, decimals, or a skip saved as null. Save the value to today's daily note frontmatter under a configurable property, create the note if needed, and prevent automatic startup prompts more than once per day."

    stats: {
        downloads:  81
        updated_at: 1779352505000
    }
}
```
