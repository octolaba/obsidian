# Consecutive Lists

Consecutive Lists lets adjacent lists render as separate lists in reading mode by alternating the list markers of neighbouring lists automatically. The Markdown stays compatible with other parsers, so the notes remain readable and transferable without the plugin.

```cue
plugin: {
    id:     "consecutive-lists"
    name:   "Consecutive Lists"
    author: "jtucker2"
    repo:   "jtucker2/obsidian-consecutive-lists"

    html_url:    "https://community.obsidian.md/plugins/consecutive-lists"
    github_url:  "https://github.com/jtucker2/obsidian-consecutive-lists"
    description: "Create consecutive lists that are displayed separately in reading mode."
    about:       "Create consecutive lists that render as separate lists in reading mode by automatically alternating list markers for adjacent lists. Keep Markdown fully compatible with other parsers so notes remain transferable and readable without the plugin."
```
