# Image Markdown Description

Edits an image description as Markdown and persists it into the image file's own metadata, using the PNG tEXt Description field and the JPEG EXIF ImageDescription field. Opening an image shows an inline editor below the preview with an edit and preview toggle, internal-link autocompletion and auto-save on blur, so the description travels with the file.

    id:     "image-md-description"
    name:   "Image Markdown Description"

    html_url:    "https://community.obsidian.md/plugins/image-md-description"
    github_url:  "https://github.com/satojin219/obsidian-image-md-description-plugin"
    description: "Edit image (PNG/JPEG) descriptions as Markdown and persist them as image metadata. - This plugin has not been manually reviewed by Obsidian staff."
