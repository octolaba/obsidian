# Markdown Chords

Markdown Chords adds musical chord notation and chord diagrams for stringed instruments such as guitar. Fenced code blocks labeled song or lyrics are rendered with markdown-it-chords syntax, turning inline chords and fingering diagrams into styled chord output. Chords in any Western scale or mode are supported, including extended jazz chords and slash chords.
