# Memodack

Memorizes vocabulary and phrases written in a compact value-and-translation syntax, with images attached by linking words. A hotkey converts a selection into that syntax, and translation and text-to-speech providers supply the rest. A focused review mode works offline on desktop and mobile.

    id:     "memodack"
    name:   "Memodack"
    author: "memodack"
    repo:   "memodack/memodack"
