# Jira Issue Notes

Jira Issue Notes creates Markdown notes from Jira issues using a customizable template and keeps them synced with the vault. A single tracked issue or all of them can be updated, and a note can also be generated from text selected in the editor. The Jira connection and the tracked issues are managed from settings, with a status bar button for a quick update.

```cue
plugin: {
    id:     "jira-issue-notes"
    name:   "Jira Issue Notes"
    author: "maksim77"
    repo:   "maksim77/obsidian-jira"

    html_url:    "https://community.obsidian.md/plugins/jira-issue-notes"
    github_url:  "https://github.com/maksim77/obsidian-jira"
    description: "Integration for accessing and managing Jira issues directly in your notes - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create Markdown notes from Jira issues using a customizable template and keep them synced with your vault. Update individual or all tracked issues, generate notes from selected editor text, and manage your Jira connection and tracked issues with a status bar quick-update button."

    stats: {
        downloads:  110
        updated_at: 1755698067000
    }
}
```
