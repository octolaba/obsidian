# Simple Progress Bar

Simple Progress Bar shows a minimal progress bar in the note header that reflects checkbox completion across the entire note and updates in real time. An sp-bar code block adds embedded section progress bars that report counts and percentages for the checkboxes inside a specific heading.

```cue
plugin: {
    id:     "simple-progress-bar"
    name:   "Simple Progress Bar"
    author: "Toby Chen"
    repo:   "pochihh/obsidian-simple-progress-bar"

    html_url:    "https://community.obsidian.md/plugins/simple-progress-bar"
    github_url:  "https://github.com/pochihh/obsidian-simple-progress-bar"
    description: "A minimal and elegant plugin that visualizes your checkbox completion with beautiful progress bars. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Show a clean, minimal progress bar in the note header that updates in real time to reflect checkbox completion across the entire note. Add embedded section progress bars with an sp-bar code block to display counts and percentages for checkboxes inside specific headings."

    stats: {
        downloads:  372

    }
}
```
