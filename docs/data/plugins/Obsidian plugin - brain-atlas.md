# Brain Atlas

Brain Atlas renders the vault as an interactive 3D anatomical brain in which notes become nodes and wikilinks become pathways. Folders, tags or frontmatter can be mapped onto brain regions, and regions and labels can be toggled, classification decisions inspected, notes opened from the graph, palettes switched and performance tuned. The recorded inputs state that rendering stays local to the vault.
