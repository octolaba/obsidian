# Markr

Markr renders trigger-based list and task markers as colored badges, line tints and Lucide icons in both Live Preview and Reading View. Triggers are one to three characters long and can use the built-in priority forms or custom labels and colors. Commands apply, remove or cycle markers, theme backgrounds are left intact, and style variables are exposed for further customization.
