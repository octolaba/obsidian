# Searchosaurus

Searchosaurus is a Spotlight-style search panel that pins exact title and alias matches to the top and ranks the remaining results deterministically. Notes, images, PDFs and saved links are previewed live, including text extracted from images and PDFs by OCR, and the whole search runs offline. Type filters narrow the result list.
