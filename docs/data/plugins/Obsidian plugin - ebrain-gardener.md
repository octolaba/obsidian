# eBrain Gardener

Runs a digital-garden pipeline over the vault in three stages - process, triage and publish - scoring inbox notes, suggesting wikilinks and enriching frontmatter with an LLM, without a terminal. A sidebar shows the scored inbox live, a sortable table drives triage, and the publish command is gated behind an approval step.
