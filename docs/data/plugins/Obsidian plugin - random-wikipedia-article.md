# Random Wikipedia Article

Fetches a random Wikipedia article and generates a note for it in the vault, parsing the article's headers into Obsidian sections. Results can be filtered by a minimum number of headers and by excluded headings, retrying until a suitable article is found. The created note is saved and opened automatically.

```cue
plugin: {
    id:     "random-wikipedia-article"
    name:   "Random Wikipedia Article"
    author: "spencerf718"
    repo:   "spencerf718/obsidian-random-wikipedia"

    html_url:    "https://community.obsidian.md/plugins/random-wikipedia-article"
    github_url:  "https://github.com/spencerf718/obsidian-random-wikipedia"
    description: "Generates a note for a random Wikipedia article."
    about:       "Fetch a random Wikipedia article and create a well-formatted note in your vault, parsing article headers into Obsidian sections. Filter results by minimum headers and excluded headings, retry for suitable articles, and save and open the note automatically."

}
```
