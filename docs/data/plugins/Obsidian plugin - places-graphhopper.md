# Places - GraphHopper

Provides GraphHopper routing for Places, covering directions, isochrones, POI search, elevation replacement, track snapping with way details, and track matching. Routes and reachability polygons are built from waypoints, elevations are read for track points, recorded tracks are snapped to the road network, and search terms resolve to place suggestions.
