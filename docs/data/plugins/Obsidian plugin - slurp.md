# Slurp

Slurp saves webpages into the vault as clean Markdown with ads, scripts and layout clutter removed. Page metadata is extracted into frontmatter, covering tags, excerpt, author, site, dates, permalink and page type. Pages can be captured from the command palette, from bookmarklets or through the mobile share sheet, and an option imports only the frontmatter.

```cue
plugin: {
    id:     "slurp"
    name:   "Slurp"
    author: "inhumantsar"
    repo:   "inhumantsar/slurp"

    html_url:    "https://community.obsidian.md/plugins/slurp"
    github_url:  "https://github.com/inhumantsar/slurp"
    description: "Saves webpages as clean, uncluttered Markdown."
    about:       "Save webpages to Obsidian as clean, readable Markdown files by stripping ads, scripts and layout clutter. Extract metadata into frontmatter—tags, excerpt, author, site, dates, permalink and page type—and slurp via the command palette, bookmarklets or mobile share; opt to import only frontmatter."
```
