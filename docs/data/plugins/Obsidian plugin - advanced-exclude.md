# Advanced Exclude

Advanced Exclude extends the Excluded files setting with gitignore syntax and obsidianignore files, and can import patterns from an existing gitignore or reuse the current Excluded files patterns. Ignored files disappear from the Files view, backlinks and other places, so Obsidian treats them as if they did not exist.

```cue
plugin: {
    id:     "advanced-exclude"
    name:   "Advanced Exclude"
    author: "Michael Naumov"
    repo:   "mnaoumov/obsidian-advanced-exclude"

    html_url:    "https://community.obsidian.md/plugins/advanced-exclude"
    github_url:  "https://github.com/mnaoumov/obsidian-advanced-exclude"
    description: "Enhances the Excluded files setting bringing gitignore syntax. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Configure ignore patterns using gitignore syntax and .obsidianignore files, with optional import from .gitignore and reuse of existing Excluded files patterns. Hide ignored files from the Files view, Backlinks and other places so Obsidian treats them as if they do not exist."

    stats: {
        downloads:  13537
        updated_at: 1784743583000
    }
}
```
