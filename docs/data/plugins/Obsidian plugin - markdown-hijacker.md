# Synaptic Bridge

Synaptic Bridge synchronizes Markdown and selected other file types between an Obsidian vault and external folders in real time, and detects changes made while Obsidian was closed. Multiple folder mappings can be connected, each set to one-way or bidirectional sync. Frontmatter metadata and sync status are preserved across the mapped locations.
