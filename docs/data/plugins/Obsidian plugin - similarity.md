# Similarity

Similarity brings semantic search to Obsidian, finding related notes by meaning rather than by shared keywords. A local semantic index lists related notes and lets you jump from one connected idea to the next. Embedding generation and search run entirely on the device, with no API keys and no data leaving the machine.
