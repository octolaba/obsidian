# Mermaid Copy

Adds a copy button beside the edit icon on Mermaid diagrams rendered in Live Preview. One click copies the diagram to the clipboard as PNG, where a transparent background keeps the theme colors, or as SVG.

```cue
plugin: {
    id:     "mermaid-copy"
    name:   "Mermaid Copy"
    author: "mblogs"
    repo:   "mblogs/mermaid-copy"

    html_url:    "https://community.obsidian.md/plugins/mermaid-copy"
    github_url:  "https://github.com/mblogs/mermaid-copy"
    description: "Adds a copy button to rendered Mermaid diagrams in Live Preview. Copy as PNG or SVG with one click. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add a copy button to rendered Mermaid diagrams in Live Preview. Copy any diagram to the clipboard as PNG (transparent background preserves theme colors) or SVG with one click from the button next to the edit icon."

    stats: {
        downloads:  835

}
```
