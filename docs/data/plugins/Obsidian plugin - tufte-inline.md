# Tufte Inline

Renders three inline typographic shorthands in Reading view and Live Preview: doubled carets around text produce a small-caps new-thought opener, doubled ampersands an italic run-in lead-in, and doubled at-signs a two-line CJK drop cap. Styling for the shorthands comes from the Tufte theme, which the plugin is meant to be paired with.

```cue
plugin: {
    id:     "tufte-inline"
    name:   "Tufte Inline"
    author: "PleiadesM"
    repo:   "pleiadesm/Tufte-Inline"

    html_url:    "https://community.obsidian.md/plugins/tufte-inline"
    github_url:  "https://github.com/pleiadesm/Tufte-Inline"
    description: "Inline typography shorthands rendered in Reading view and Live Preview: ^^text^^ for a small-caps new-thought opener, &&text&& for an italic run-in lead-in, and @@字@@ for a two-line CJK drop cap (首字下沉). Styling is provided by the Tufte theme. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render inline Tufte-style typographic shorthands in Reading view and Live Preview: ^^text^^ for small-caps openers, &&text&& for italic run-in lead-ins, and @@字@@ for two-line CJK drop caps. Pair with the Tufte theme to style the shorthands."
```
