# Translator

Selected text or a typed phrase is translated from a modal inside Obsidian. Youdao, Microsoft or Baidu is chosen as the translation engine, and a hotkey opens the modal.

```cue
plugin: {
    id:     "obsidian-translator"
    name:   "Translator"
    author: "luhaifeng666"
    repo:   "luhaifeng666/obsidian-translator"

    html_url:    "https://community.obsidian.md/plugins/obsidian-translator"
    github_url:  "https://github.com/luhaifeng666/obsidian-translator"
    description: "Translate selected text."
    about:       "Translate selected text or typed phrases directly in Obsidian using a simple translator modal. Choose Youdao, Microsoft, or Baidu as the translation engine and set a hotkey for quick access."
```
