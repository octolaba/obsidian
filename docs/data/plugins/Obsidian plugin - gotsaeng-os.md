# GotSaeng OS

Compiles a local Markdown vault into model-ready context packs and auditable Markdown or JSON artifacts. Notes are scanned and classified to extract facts, decisions, actions, risks and insights, and contradiction candidates are flagged for human review. Memory diffs are emitted deterministically, carrying provenance and confidence scores.
