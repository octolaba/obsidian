# BuddyBridge

BuddyBridge connects Obsidian to the WorkBuddy and CodeBuddy CLI on Windows and runs chats in a sidebar panel. Conversations stream over multiple turns with thought visualization, tool-call previews for file reads and searches, vault-aware context injection, session management, and automatic detection of the CodeBuddy and Node.js paths.
