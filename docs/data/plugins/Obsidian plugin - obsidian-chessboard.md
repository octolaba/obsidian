# Chessboard Viewer

Chessboard Viewer renders chess positions given as FEN strings into static SVG diagrams in note preview and in HTML or PDF exports. Annotations such as arrows, highlights, shapes and icons can be added and the board orientation set, keeping the diagrams export-friendly.

```cue
plugin: {
    id:     "obsidian-chessboard"
    name:   "Chessboard Viewer"
    author: "Davide Aversa"
    repo:   "thek3nger/obsidian-chessboard"

    html_url:    "https://community.obsidian.md/plugins/obsidian-chessboard"
    github_url:  "https://github.com/thek3nger/obsidian-chessboard"
    description: "Render chess positions diagrams in note preview."
    about:       "Render Chess FEN positions as static SVG chessboards directly in preview and in HTML/PDF exports. Add annotations—arrows, highlights, shapes and icons—and set board orientation for clear, export-friendly diagrams."
```
