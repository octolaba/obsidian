# HTML Effectiveness

HTML Effectiveness renders spatial HTML content in notes following the html-effectiveness methodology, covering side-by-side comparisons, timelines, ASCII diagrams, KPI reports and paged slides. Views are created by inserting html-effect code blocks for compare, timeline, diagram, report and slides, and a note can be exported as standalone HTML.

```cue
plugin: {
    id:     "html-effectiveness"
    name:   "HTML Effectiveness"
    author: "rosswang"
    repo:   "yanqingwang/obsidian-html-effectiveness"

    html_url:    "https://community.obsidian.md/plugins/html-effectiveness"
    github_url:  "https://github.com/yanqingwang/obsidian-html-effectiveness"
    description: "边对比 / 流程图 / 幻灯片 / 报告 / 时间线 — 在 Obsidian 中直接渲染空间化 HTML 内容。基于 html-effectiveness 方法论。 - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render spatial HTML content in Obsidian using the html-effectiveness methodology, including side-by-side comparisons, timelines, ASCII diagrams, KPI reports and paged slides. Insert html-effect code blocks to create compare, timeline, diagram, report and slides views and export notes as standalone HTML."
```
