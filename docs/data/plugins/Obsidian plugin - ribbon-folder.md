# Ribbon Folder

Groups several commands behind one ribbon button, so clicking or hovering the group expands a menu from which any command runs. Group buttons take Lucide or custom SVG icons, and icon and label display is configurable.

```cue
plugin: {
    id:     "ribbon-folder"
    name:   "Ribbon Folder"
    author: "limniemdung"
    repo:   "limniemdung/obsidian-ribbon-folder"

    html_url:    "https://community.obsidian.md/plugins/ribbon-folder"
    github_url:  "https://github.com/limniemdung/obsidian-ribbon-folder"
    description: "Organize multiple commands into grouped buttons on the Ribbon, click to expand and execute commands from a menu for a cleaner interface. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Organize commands into grouped buttons on the Obsidian ribbon. Click or hover a group to expand a menu and execute any command, with Lucide or custom SVG icons and configurable icon/label display."

    stats: {
        downloads:  129
        updated_at: 1786351071000
    }
}
```
