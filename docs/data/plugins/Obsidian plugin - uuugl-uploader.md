# uuu.gl Markdown Uploader

Uploads notes to uuu.gl as rendered GitHub-Flavored Markdown pages with syntax highlighting, preserving images, attachments and internal links. Custom short URLs can be created, a note can optionally be protected with a password, and auto-saved version history is kept. The published link is copied from the status bar.

```cue
plugin: {
    id:     "uuugl-uploader"
    name:   "uuu.gl Markdown Uploader"
    author: "johnkim05"
    repo:   "johnkim05/obsidian-uuugl-plugin"

    html_url:    "https://community.obsidian.md/plugins/uuugl-uploader"
    github_url:  "https://github.com/johnkim05/obsidian-uuugl-plugin"
    description: "Upload your notes to uuu.gl as rendered Markdown documents. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Upload Obsidian notes to uuu.gl as rendered GitHub-Flavored Markdown pages with syntax highlighting, preserving images, attachments, and internal links. Create custom short URLs, optionally protect notes with a password, and keep auto-saved version history; copy the published link from the status bar."

    stats: {
        downloads:  84
        updated_at: 1762349089000
    }
}
```
