# Rainbow Highlight

Highlights selected text from a floating color palette offering six colors that adapt to light and dark themes. Bold, italic and strikethrough formatting inside the selection is preserved, a highlight is removed in one click, and each color is also reachable from the command palette.

    id:     "rainbow-highlight"
    name:   "Rainbow Highlight"
    author: "norman-lawyer"
    repo:   "norman-lawyer/obsidian-rainbow-highlight"
