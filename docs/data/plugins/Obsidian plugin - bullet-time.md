# Bullet-time

Bullet-time turns a bullet list into a Gantt-style timeline by chaining tasks top to bottom so each one starts when the previous ends. Sibling tasks are auto-scheduled, workday or calendar arithmetic can be chosen, durations use hour, day and week shorthands, and nesting maps lanes to projects to subtasks with per-task colors.
