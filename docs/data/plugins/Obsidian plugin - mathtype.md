# MathType

MathType suggests MathJax syntax from natural language through inline autocompletion. The autocompletion is triggered and an English description is typed, and suggestions for symbols, functions and more complex equations are returned as it is written.

```cue
plugin: {
    id:     "mathtype"
    name:   "MathType"
    author: "slateblua"
    repo:   "slateblua/mathtype"

    html_url:    "https://community.obsidian.md/plugins/mathtype"
    github_url:  "https://github.com/slateblua/mathtype"
    description: "Get MathJax syntax suggestions from natural language."
    about:       "Convert natural language into MathJax mathematical expressions using inline autocompletion. Trigger the autocompletion and type an English description to receive fast suggestions for symbols, functions, and complex equations."

    stats: {
        downloads:  1604
        updated_at: 1742462891000
    }
}
```
