# Copy As PlainText

Copy As PlainText adds a command and a context-menu entry that copy selected Markdown as clean plain text. Stripping runs either in a Super Simple regex mode or in a Unified and Remark AST mode with full GFM support for tables, task lists, footnotes, math and frontmatter, and the elements to remove can be chosen individually.

    id:     "copy-plaintext"
