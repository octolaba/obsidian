# Lite Gallery

Creates carousel image galleries inside a note from a litegal code block listing image files or wiki links. Configured image folders are searched for matches so full paths are not required, which the recorded inputs present as a way to keep several images organized and easier to view.

```cue
plugin: {
    id:     "litegallery"
    name:   "Lite Gallery"
    author: "jpoles1"
    repo:   "jpoles1/obsidian-litegal"

    html_url:    "https://community.obsidian.md/plugins/litegallery"
    github_url:  "https://github.com/jpoles1/obsidian-litegal"
    description: "Easily create carousel galleries to better organize/view images in your notes."
    about:       "Create carousel image galleries inside notes by listing image files or [[wiki links]] in a litegal code block. Search configured image folders for matches so full paths aren’t required and keep multiple images neatly organized for easier viewing."

    stats: {
        downloads:  5440
        updated_at: 1728264517000
    }
}
```
