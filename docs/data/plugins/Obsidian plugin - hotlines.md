# Hotlines

Hotlines highlights whole lines matching keywords or regular expressions, with a configurable background, text color, weight and CSS. Markers such as TODO, PROBLEM or IMPORTANT are matched as plain text, so no callout or added Markdown syntax is required. Highlighting works in Reading Mode and Live Preview, on desktop and mobile.

```cue
plugin: {
    id:     "hotlines"
    name:   "Hotlines"
    author: "Steve Crutchfield"
    repo:   "crufi/obsidian-hotlines"

    html_url:    "https://community.obsidian.md/plugins/hotlines"
    github_url:  "https://github.com/crufi/obsidian-hotlines"
    description: "Grab your attention by highlighting entire lines matching keywords or regex patterns with custom styles. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Highlight whole lines in your notes that match keywords or regex patterns — with custom background, text color, weight, and CSS. Great for making `TODO`, `PROBLEM`, `IMPORTANT`, or any marker you use jump off the page. Highlighting is automatic based on plain text in your note, no callout or other added markdown syntax required. Works in both Reading Mode and Live Preview, on desktop and mobile."
```
