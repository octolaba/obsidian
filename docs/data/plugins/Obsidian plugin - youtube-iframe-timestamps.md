# Youtube Iframe Timestamps

Embeds a YouTube video in a note inside an iframe container together with timestamped links. Clicking a timestamp jumps the embedded player to that moment without opening a separate browser window. The recorded About text notes that iframes only render in Reading view while the editor is in Source mode.

```cue
plugin: {
    id:     "youtube-iframe-timestamps"
    name:   "Youtube Iframe Timestamps"
    author: "nilsleo"
    repo:   "nilsleo/obsidian-youtube-iframe-timestamps"

    html_url:    "https://community.obsidian.md/plugins/youtube-iframe-timestamps"
    github_url:  "https://github.com/nilsleo/obsidian-youtube-iframe-timestamps"
    description: "Allows you to embed YouTube videos with timestamps directly in your notes, enabling seamless referencing and note-taking without needing to open a separate browser window."
    about:       "Embed YouTube videos with timestamped links directly in your notes using an iframe container. Click timestamps to jump to specific moments without leaving Obsidian. Be aware iframes only render in Reading View when the editor is in Source mode."

    stats: {
        downloads:  3608
        updated_at: 1727969074000
    }
}
```
