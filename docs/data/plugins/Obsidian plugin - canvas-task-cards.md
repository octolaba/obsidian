# Canvas Task Cards

Canvas Task Cards turns Canvas cards into task cards carrying a left-border completion indicator, an assignable card type and a colored priority dot. Completion is toggled from the indicator, and a completed card gains a colored border and reduced opacity. Type and priority are edited from a floating popup or the context menu, and cards can be filtered by type or priority.
