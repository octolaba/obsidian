# ToWrite Open Questions

ToWrite Open Questions tracks ToThink and ToWrite annotations beside the source note, attaching unfinished ideas and draft fragments to a specific line, PDF highlight or selection. The cards are collected in a collapsible sidebar with source highlighting and a jump back to their origin, stored in sidecar JSON, and exported as JSON or through an optional local HTTP API.
