# VaultChat

Chats with several AI providers inside Obsidian — Anthropic, OpenAI, Google Gemini, OpenRouter and Ollama — attaching vault files or the active note as context so the model sees the full file tree. Files can be edited, created or deleted through AI proposals shown as diff previews, responses stream in real time, and per-vault conversation history is searchable and resumable.
