# AI LLM Search

Chats over selected text, the current note or relevant vault notes through an OpenAI-compatible or local model. Vault search uses BM25 rather than embeddings, DuckDuckGo or Tavily web results can be folded in, and source notes and pages are shown with the answer. The sidebar is written in Simplified Chinese and adapts to desktop and mobile.
