# BibDesk Integration

BibDesk Integration imports BibTeX citations into notes and opens the PDF documents linked from a BibDesk library, working together with PDF++. Large external BibTeX files are parsed on a background thread to keep the interface responsive, and the file is watched for changes. BibDesk macOS bookmarks are resolved so linked files remain reachable after being renamed or moved.
