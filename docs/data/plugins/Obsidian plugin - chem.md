# Chem

Chem renders chemical structures from SMILES strings, either inside code blocks or on inline-prefixed lines, using SmilesDrawer and RDKit.js. Scale and theme are adjustable, and a rendered structure can be copied or exported as a PNG image. Output from Dataview and DataviewJS queries can also be rendered as molecules.
