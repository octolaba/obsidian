# Tickban

Tickban collects checkbox tasks from across the entire vault and arranges them on a Kanban board, mapping the empty, slash and x markers onto TODO, DOING and DONE columns. Status is changed by drag and drop or from a card menu, the original note is opened from a card, and tags and file paths are shown on it.
