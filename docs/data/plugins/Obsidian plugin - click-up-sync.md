# ClickUp sync

Syncs ClickUp lists and tasks into the vault as Markdown notes, so tasks stay viewable and editable inside the notes. Selected note text can be turned into a new ClickUp task and assigned to a list, and task details and status are shown within the note.

```cue
plugin: {
    id:     "click-up-sync"
    name:   "ClickUp sync"
    author: "hokim-m"
    repo:   "hokim-m/click-up-x-obsidian"

    html_url:    "https://community.obsidian.md/plugins/click-up-sync"
    github_url:  "https://github.com/hokim-m/click-up-x-obsidian"
    description: "Manage ClickUp space from notes."
    about:       "Sync ClickUp lists and tasks as Markdown notes in your Obsidian vault, keeping tasks viewable and editable inside notes. Create ClickUp tasks from selected note text and assign them to a list. View task details and status directly within notes."

    stats: {
        downloads:  2525

}
```
