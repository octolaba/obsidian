# PDF break page

The plugin inserts a manual page break for PDF export, through a configurable hotkey or a break command. The marker is typed where the exported PDF should begin a new page, leaving the note content otherwise unchanged.

```cue
plugin: {
    id:     "break-page"
    name:   "PDF break page"
    author: "corentin-godefroy"
    repo:   "corentin-godefroy/Obsidian-BreakPage"

    html_url:    "https://community.obsidian.md/plugins/break-page"
    github_url:  "https://github.com/corentin-godefroy/Obsidian-BreakPage"
    description: "Add shortkey and command to insert a break page formating for pdf exports."
    about:       "Insert manual page breaks into notes for PDF exports using a configurable hotkey or the /break command. Type the shortcut where you want a new PDF page to begin. Preserve note content while controlling exported page layout."

    stats: {
        downloads:  17094
        updated_at: 1707968131000
    }
}
```
