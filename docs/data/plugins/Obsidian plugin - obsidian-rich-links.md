# Rich Links

This plugin converts URLs in notes into rich link previews in the style of Notion. A single command generates an inline preview card for a link, giving a cleaner and more informative view of the external content.

```cue
plugin: {
    id:     "obsidian-rich-links"
    name:   "Rich Links"
    author: "dhamaniasad"
    repo:   "dhamaniasad/obsidian-rich-links"

    html_url:    "https://community.obsidian.md/plugins/obsidian-rich-links"
    github_url:  "https://github.com/dhamaniasad/obsidian-rich-links"
    description: "Convert URLs in your notes to rich link previews."
    about:       "Convert URLs in your notes into Notion-style rich link previews. Generate inline preview cards for links with a single command to show a cleaner, more informative view of external content."

    stats: {
        downloads:  32102
        updated_at: 1682955207000
    }
}
```
