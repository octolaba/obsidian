# Star ImageMaster

Images pasted or dropped into the vault are saved automatically in folder, central or date modes with customizable filename patterns. A thumbnail or list gallery filters in-use and orphan files, duplicates are detected by SHA-256 hash so an existing link can be reused, and every note reference is updated when an image is moved or renamed.
