# Franklin

Brings an AI agent into Obsidian that reads the vault and proposes changes to Markdown files. Proposed additions, edits and deletions are reviewed before they are applied, model providers can be swapped mid-conversation, and the agent runs with sandboxed filesystem access. The index description states that it is powered by an OpenAI subscription.
