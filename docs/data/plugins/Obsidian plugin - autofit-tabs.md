# Autofit Tabs

Autofit Tabs resizes tab headers in real time so that each one fits its title instead of being truncated. Resize animations, optional icon hiding, pinned-tab behavior, maximum width limits, a scrollable tab bar and auto-centering of off-screen tabs are all configurable.

```cue
plugin: {
    id:     "autofit-tabs"
    name:   "Autofit Tabs"
    author: "bwya77"
    repo:   "bwya77/autofit-tabs"

    html_url:    "https://community.obsidian.md/plugins/autofit-tabs"
    github_url:  "https://github.com/bwya77/autofit-tabs"
    description: "Automatically adjusts tab header widths to fit each tab's title content."
    about:       "Resize tab headers in real time to perfectly fit each title and eliminate awkward truncation. Keep a clean interface with smooth resize animations, optional icon hiding and pinned-tab behavior, max-width limits, scrollable tab bars and auto-centering for off-screen tabs."

    stats: {
        downloads:  7519
        updated_at: 1768623201000
    }
}
```
