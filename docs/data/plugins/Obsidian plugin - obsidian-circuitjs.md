# CircuitJS

CircuitJS embeds interactive CircuitJS circuit simulations into notes and runs them offline with a bundled engine. A simulation is live and interactive in reading view, a circuit can be opened for quick editing, and its source is stored in a fenced code block so it can be versioned and backed up.

```cue
plugin: {
    id:     "obsidian-circuitjs"
    name:   "CircuitJS"
    author: "stevengann"
    repo:   "stevengann/obsidian-circuitjs"

    html_url:    "https://community.obsidian.md/plugins/obsidian-circuitjs"
```
