# JADOU

JADOU is an in-context Japanese language toolbox: readings and meanings are looked up, furigana inserted, and entries added to a sortable glossary from inside Obsidian. Inflected forms are handled, and a sentence is selected with one click or a hotkey. It runs entirely offline apart from dictionary updates and supports mobile and PDF files.
