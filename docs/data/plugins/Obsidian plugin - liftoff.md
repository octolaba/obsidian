# LiftOff

LiftOff logs gym workouts from a mobile-first interface, recording sets, reps, weight and RPE as plain Markdown files in the vault. Workouts start from templates or custom routines, exercises are chosen from a searchable library, and rest and interval timers start automatically. Recent workout history is shown alongside the current session.
