# NAS Vault Sync

Synchronizes the vault with a NAS or any WebDAV server, keeping notes between the user's own devices and a server they control, on both desktop and mobile. The two-way sync is Unicode-safe, resolves conflicts causally, records deletions as tombstones and supports resumable transfers. A mass-delete guard and safeguards against plugin-induced edit loops are also included.
