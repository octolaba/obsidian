# Highlight Inbox Synthesizer

Highlight Inbox Synthesizer reads a folder of saved highlights and writes one note containing per-source summaries, key claims and topic lists. Themes shared across sources are surfaced, with consensus and tensions recorded. The synthesis note is written to the vault root, and sources that have not changed are skipped when it runs again.
