# Japanese Manuscript Counter

Japanese Manuscript Counter displays a real-time count of Japanese characters in the status bar and converts it into the equivalent number of 400-character manuscript sheets. It also reports the count for a selection and opens a detailed modal that accounts for full-width and half-width characters, line breaks, paragraphs and kinsoku rules.
