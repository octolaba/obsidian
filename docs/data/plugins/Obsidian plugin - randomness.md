# Randomness

Renders randomness code blocks that roll random generators, with tables written in plain text and called either inline or in a dedicated block. Results render as full Markdown with embedded images and clickable links, can be locked to make them permanent or rerolled, and a sidebar pane lists every generator in the vault. Autocomplete suggests tables while typing and auto-imports them, and an in-app reference documents the syntax. Legacy Inspiration Pad Pro 3 .ipt files work as generator sources.

Results render with full Markdown — embedded portraits, clickable links, formatted text. A sidebar pane lists every generator in your vault.
