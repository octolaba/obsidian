# ActionDeck

Adds a right-side panel whose buttons each run an Obsidian command with a single click. Buttons are organized into named groups and take emoji, Lucide icons, vault images, external URLs or raw SVG as icons. Deleted items are restored from history, and the interface is mobile-friendly and available in English and Japanese.
