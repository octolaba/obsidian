# LongtimeDiary

Shows past daily notes from the same day in previous years inside the current daily note. A LongtimeDiary code block placed in the daily note searches the vault and renders the previous entries for that day.

```cue
plugin: {
    id:     "longtime-diary"
    name:   "LongtimeDiary"
    author: "sawamaru"
    repo:   "sawamaru/obsidian-LongtimeDiary"

    html_url:    "https://community.obsidian.md/plugins/longtime-diary"
    github_url:  "https://github.com/sawamaru/obsidian-LongtimeDiary"
    description: "Show past Daily notes on the same day in previous years."
    about:       "Display past Daily notes that share the same day-of-month directly inside your current Daily note. Place a LongtimeDiary code block in the Daily note to search and render previous entries for that day across your vault."

    stats: {
        downloads:  1450
        updated_at: 1771242897000
    }
}
```
