# Daily Note Icon

Replaces the document icon on today's Daily Note tab with a solid yellow star. The star stays yellow while the tab is active and darkens slightly on hover. Which file counts as today's note follows the Daily Notes folder and date format, and the icon refreshes after file changes and again at midnight.

```cue
plugin: {
    id:     "daily-note-icon"
    name:   "Daily Note Icon"
    author: "Ben Hancock"
    repo:   "benhancock/daily-note-icon"

    html_url:    "https://community.obsidian.md/plugins/daily-note-icon"
    github_url:  "https://github.com/benhancock/daily-note-icon"
    description: "Replaces today's Daily Note tab icon with a solid yellow star. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Replace the document icon in today's Daily Note tab with a solid yellow star. Keep the star yellow when the tab is active and darken it slightly on hover. Follow Daily Notes' folder and date format and refresh automatically after file changes and at midnight."

    stats: {
        downloads:  26
        updated_at: 1785611868000
    }
}
```
