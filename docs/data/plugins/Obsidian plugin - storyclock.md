# Storyclock Viewer

Story events are plotted on a circular clock from a total runtime and a list of timestamps in hours, minutes and seconds written in a note. The clock is rendered when edit mode is left, and switching back to the code view returns to editing the timestamps. The recorded description names Plot Devices Storyclock as the inspiration.

```cue
plugin: {
    id:     "storyclock"
    name:   "Storyclock Viewer"
    author: "jonzfisher"
    repo:   "jonzfisher/obsidian-chronostory"

    html_url:    "https://community.obsidian.md/plugins/storyclock"
    github_url:  "https://github.com/jonzfisher/obsidian-chronostory"
    description: "Map timing onto a storyclock. Inspired by Plot Devices Storyclock."
    about:       "Visualize story events on a circular clock by writing the total runtime and HH:MM:SS timestamps in a note. Render the Storyclock when you exit edit mode and switch back to code view to resume editing timestamps."

    stats: {
        downloads:  3195
        updated_at: 1702524529000
    }
}
```
