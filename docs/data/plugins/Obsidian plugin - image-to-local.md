# Image2Local

Saves remote images, base64 data and bare image URLs found in notes to local files and replaces them with Markdown image links. Storage paths can be relative or absolute, including system paths outside the vault, and saves run singly or in batches from the right-click menu or from commands. Markdown images, HTML image tags and bare URLs are all detected.
