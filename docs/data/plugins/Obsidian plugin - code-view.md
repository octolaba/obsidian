# Code View

Code View is a read-only viewer for developer files such as py, ps1, sh, ts, cs, sql and yml, showing them with Prism syntax highlighting inside Obsidian and without executing their contents. Prompts, tool configs and scripts therefore become browsable, searchable and linkable alongside notes.

    name:   "Code View"
    author: "casualbot"

    github_url:  "https://github.com/casualbot/obsidian-codeviewer-plugin"
    description: "Read-only viewer for source code and developer-centric files (py, ps1, sh, ts, etc.) with syntax highlighting via Prism. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "View syntax-highlighted, read-only developer files (py, ps1, sh, ts, cs, sql, yml, and more) directly inside Obsidian without executing their contents. Make prompts, tool configs, scripts, and other source files browsable, searchable, and linkable alongside your notes."
