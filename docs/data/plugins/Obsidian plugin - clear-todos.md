# Clear Todos

Removes completed todo lines from a note with a single command. The command applies to the current selection when there is one and to the whole document otherwise.

```cue
plugin: {
    id:     "clear-todos"
    name:   "Clear Todos"
    author: "gutentag2012"
    repo:   "gutentag2012/obsidian-plugin-clear-todos"

    html_url:    "https://community.obsidian.md/plugins/clear-todos"
    github_url:  "https://github.com/gutentag2012/obsidian-plugin-clear-todos"
    description: "Quickly remove all completed todos from your notes or selected text."
    about:       "Clear all completed todos from the current selection or the entire document. Run a single command to remove finished task lines quickly, applying to the selection if present or to the whole file if not."

    stats: {
        downloads:  882
        updated_at: 1735290479000
    }
}
```
