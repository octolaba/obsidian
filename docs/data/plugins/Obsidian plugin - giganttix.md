# Giganttix

Renders notes carrying startDate and endDate frontmatter as an interactive Gantt chart, where clicking a bar opens its note. Bars can be dragged or resized to write the new dates back into frontmatter and a progress handle sets completion, while the chart can be filtered by status, folder or a required property across Day, Week and Month views.
