# Auto Correct Capitals Misspellings

Corrects words whose first two letters are uppercase and whose third is lowercase, restoring the usual capitalization. Corrections are skipped inside fenced and inline code, LaTeX math and YAML front matter, and exclusion and abbreviation lists are respected. First letters in list items can optionally be capitalized or fixed as well.

```cue
plugin: {
    id:     "auto-correct-capitals"
    name:   "Auto Correct Capitals Misspellings"
    author: "ummler"
    repo:   "ummler/obsidian-auto-correct-capitals"

    html_url:    "https://community.obsidian.md/plugins/auto-correct-capitals"
    github_url:  "https://github.com/ummler/obsidian-auto-correct-capitals"
    description: "Correct words with the first two letters in uppercase."
    about:       "Correct common capitalization mistakes where the first two letters are uppercase and the third is lowercase (e.g., HAllo → Hallo). Skip corrections inside fenced/inline code, LaTeX math, and YAML front matter; respect exclusion and abbreviation lists, and optionally capitalize or fix first letters in list items."

    stats: {
        downloads:  6535
        updated_at: 1763309579000
    }
}
```
