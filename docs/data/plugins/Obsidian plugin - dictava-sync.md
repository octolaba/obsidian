# Dictava

Dictava syncs voice-note artifacts from the Dictava service into the vault as structured notes such as daily notes, blog drafts and meeting summaries. Pending deliveries are pulled manually or by background auto-sync, which fetches artifacts with the account API key and marks them delivered. The plugin states that vault contents stay local and that only the API key and vault name are sent.

```cue
plugin: {
    id:     "dictava-sync"
    name:   "Dictava"
    author: "Dictava"
    repo:   "dictava/obsidian-sync"

    html_url:    "https://community.obsidian.md/plugins/dictava-sync"
    github_url:  "https://github.com/dictava/obsidian-sync"
    description: "Sync voice notes from Dictava into your vault - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync voice-note artifacts from Dictava into your Obsidian vault as structured notes (daily notes, blog drafts, meeting summaries). Pull pending deliveries manually or enable background auto-sync to fetch artifacts and mark them delivered using your Dictava API key. Keep vault contents local; only your API key and vault name are sent."
```
