# Dynamic Wallpapers

Sets a background wallpaper per note from a frontmatter property, and a note without one can inherit the wallpaper of linked notes or backlinks. A thumbnail gallery browses wallpapers, related ones are picked or randomized, the inheritance tiers can be inspected and the thumbnail cache managed. It is desktop only.

```cue
plugin: {
    id:     "dynamic-wallpapers"
    name:   "Dynamic Wallpapers"
    author: "Josh Medeski"
    repo:   "joshmedeski/obsidian-dynamic-wallpapers"

    html_url:    "https://community.obsidian.md/plugins/dynamic-wallpapers"
    github_url:  "https://github.com/joshmedeski/obsidian-dynamic-wallpapers"
    description: "Dynamically change your Obsidian background with wallpapers that adapt to what you're doing. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Set per-note background wallpapers with a frontmatter property. Inherit from linked notes or backlinks, browse a thumbnail gallery, pick or randomize from related wallpapers, inspect inheritance tiers, and manage the thumbnail cache — desktop only."

    stats: {
        downloads:  209
        updated_at: 1785511518000
    }
}
```
