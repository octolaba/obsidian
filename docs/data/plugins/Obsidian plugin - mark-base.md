# MarkBase

Renders selected Bases properties and formulas as a continuous Markdown Freeform view. Property order and separators are configurable, internal links can be followed, and the rendered text can be copied. A reusable Markdown template can override the layout, and the whole thing runs inside the vault.

```cue
plugin: {
    id:     "mark-base"
    name:   "MarkBase"
    author: "Tyler Carrol"
    repo:   "tylercarrol/obsidian-mark-base"

    html_url:    "https://community.obsidian.md/plugins/mark-base"
    github_url:  "https://github.com/tylercarrol/obsidian-mark-base"
```
