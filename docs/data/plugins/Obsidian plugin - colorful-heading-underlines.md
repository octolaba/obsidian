# Colorful Heading Underlines

Colorful Heading Underlines draws colored underlines under headings so heading levels can be told apart. For a multi-line heading the underline follows either the last line or the widest line, and the colors and appearance are adjusted through Style Settings.

    id:     "colorful-heading-underlines"
