# OzanShare Publish

Publishes Markdown notes together with their linked and transcluded files to OzanShare web pages from a single click. Nested transclusions, Excalidraw, Mermaid, MathJax and code blocks are rendered, custom CSS can be applied, and republishing keeps a stable unique URL. Publishing on desktop and mobile requires an Exclusive Support Level token, and the index records the plugin as closed source.

```cue
plugin: {
    id:     "ozanshare-publish"
    name:   "OzanShare Publish"
    author: "ozntel"
    repo:   "ozntel/ozanshare-publish-plugin"

    html_url:    "https://community.obsidian.md/plugins/ozanshare-publish"
    github_url:  "https://github.com/ozntel/ozanshare-publish-plugin"
    description: "Publish your Markdown notes with a single click from your vault. (Closed source)"
    about:       "Publish Markdown notes and linked/transcluded files from Obsidian to OzanShare web pages with one click. Render nested transclusions, Excalidraw, Mermaid, MathJax and code blocks, and apply custom CSS while preserving a stable unique URL when republishing. Provide an Exclusive Support Level token to enable publishing on desktop and mobile."
```
