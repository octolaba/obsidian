# Bases Improvements

Bases Improvements adds a live search input above every Bases code block. As text is typed, a file.name.contains filter is added to the query, so the results of a base narrow instantly without editing the block by hand.

```cue
plugin: {
    id:     "bases-improvements"
    name:   "Bases Improvements"
    author: "Matej Vavro Productivity"
    repo:   "real1tyy/BasesImprovements"

    html_url:    "https://community.obsidian.md/plugins/bases-improvements"
    github_url:  "https://github.com/real1tyy/BasesImprovements"
    description: "Enhances Bases by adding dynamic search filtering to base code blocks. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Inject a live search input above every Bases code block and automatically add file.name.contains(\"value\") filters to queries as you type. Filter base query results instantly for faster, in-note searching and refinement."

    stats: {
        downloads:  3728
        updated_at: 1767811442000
    }
}
```
