# TreeGen

Generates copyable ASCII folder and file trees for the whole vault or any folder in it, in several styles and in Tree, Paths or JSON form. A sidebar panel previews the tree interactively, filters it with live search, and opens a file when an entry is clicked. Trees are copied from that panel or from the file explorer.
