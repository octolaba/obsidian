# Are.na Manager

Publishes notes from the vault to Are.na and pulls blocks back into Obsidian as individual notes. The current note can be pushed to an Are.na block, blocks imported by channel, id or URL, and a block opened on the Are.na site. Attachments are downloaded and frontmatter metadata added when blocks are imported.
