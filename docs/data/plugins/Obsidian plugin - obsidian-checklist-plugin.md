# Checklist

Checklist consolidates checklist items from across the vault into a single sidebar view that updates as notes change. Items are filtered by tag, defaulting to a todo tag, then grouped and sorted, and completing an item in the sidebar updates the original Markdown file. Glob patterns control which files are included.
