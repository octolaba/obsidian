# Mails Blog Publisher

Publishes the current note to Mails Blog using an Obsidian plugin token and manages the linked posts from inside Obsidian. Drafts are saved, linked posts published or updated, and remote posts synced with conflict protection. Vault images are uploaded and the returned Markdown inserted, and blog binding fields are written to or removed from the frontmatter.

```cue
plugin: {
    id:     "mails-blog-publisher"
    name:   "Mails Blog Publisher"
    author: "FengXuan"
    repo:   "fengxuan/mails-blog-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/mails-blog-publisher"
    github_url:  "https://github.com/fengxuan/mails-blog-obsidian-plugin"
    description: "Publish the current note to Mails Blog using an Obsidian plugin token. - This plugin has not been manually reviewed by Obsidian staff."

Save drafts, publish or update linked posts, sync remote posts with conflict protection, upload vault images and insert returned Markdown, and write or remove blog binding fields in frontmatter."
