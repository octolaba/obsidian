# Dired

Lists a directory as an editable CodeMirror buffer for keyboard-driven file management, in the manner of the Dired mode of Emacs. Names can be edited inline, several files marked for batch moves or deletes, and renames or moves update wiki links and embeds. Deletes go to the trash with confirmation, folders can be bookmarked, files preview in a split as the cursor moves, and listings refresh automatically.
