# Auto File Organizer

Auto File Organizer moves newly added files into designated folders according to their extension or their tags. Extension-to-folder and tag-to-folder mappings can be created, edited, prioritized or generated automatically, and chosen folders are excluded from automatic moves.

    id:     "auto-file-organizer"
