# LeetCode

LeetCode opens problems as notes with rendered statements and locked frontmatter, so that a problem stays readable offline. Solutions are written in fenced code blocks and can be tested or submitted from the note, with the verdict shown in place. Techniques are added as backlinks, building a graph of problems and methods.

```cue
plugin: {
    id:     "leetcode"
    name:   "LeetCode"
    author: "Mo Xu"
    repo:   "likesundaylikerain/obsidian-leetcode"

    html_url:    "https://community.obsidian.md/plugins/leetcode"
    github_url:  "https://github.com/likesundaylikerain/obsidian-leetcode"
    description: "Browse, solve, and note LeetCode problems inside your vault. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Browse LeetCode problems and open them as Obsidian notes with rendered statements and locked frontmatter. Write solutions in fenced code blocks, run tests or submit with verdicts shown, add techniques as backlinks to build a knowledge graph, and keep problems readable offline."

    stats: {
        downloads:  456
        updated_at: 1782146334000
    }
}
```
