# Charts View

Charts View visualizes data from notes as interactive charts and graphs built with Ant Design Charts. Data is loaded from CSV or from Dataview, and ready-made templates cover pie, bar, word cloud, treemap, dual axes, mix, radar and organization tree graph types, including data combined from several files or a folder.
