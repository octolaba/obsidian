# Hunchly

Hunchly imports a Hunchly export archive into the vault as notes, bringing in captioned images and converting captured selectors into tags. Several captures of the same URL are consolidated into a single note for one unified record.

    id:     "hunchly"
    name:   "Hunchly"
    author: "shadowoption"
    repo:   "shadowoption/Hunchly-obsidian-plugin"
