# Smart HTML Select

Smart HTML Select inserts configurable select controls with custom-numbered options into notes, and adds an action button to the left ribbon. When the value of a select changes in view mode the Markdown is updated, so the choice is recorded in the note itself.

```cue
plugin: {
    id:     "smart-html-select"
    name:   "Smart HTML Select"
    author: "isaiascope"
    repo:   "isaiascope/smart-html-select-plugin"

    html_url:    "https://community.obsidian.md/plugins/smart-html-select"
    github_url:  "https://github.com/isaiascope/smart-html-select-plugin"
    description: "Create select that change the markdown on change adding an action button to the ribbon (left sidebar)"
    about:       "Insert configurable HTML select elements into your notes with custom-numbered options. Make selection changes permanent by updating the Markdown dynamically whenever the select value changes in view mode."

    stats: {
        downloads:  670
        updated_at: 1716819362000
    }
}
```
