# Markdown Blogger

Markdown Blogger pushes Markdown notes from Obsidian to a local blog, portfolio or static site folder, creating or overwriting files at a project or custom path. It works with Astro, Next.js and any other framework that renders Markdown pages. Project Markdown can also be pulled back into notes, so push and pull commands keep the two sides in step.

plugin: {
    id:     "markdown-blogger"
    name:   "Markdown Blogger"
    author: "afazio1"
    repo:   "afazio1/obsidian-markdown-blogger"

    html_url:    "https://community.obsidian.md/plugins/markdown-blogger"
    github_url:  "https://github.com/afazio1/obsidian-markdown-blogger"

    about:       "Push markdown notes from Obsidian to a local project folder or custom path, creating or overwriting files for Astro, Next.js, or any static site. Pull project markdown into notes to sync changes back and forth with simple push/pull commands."
