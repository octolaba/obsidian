# Eink Cursor

Replaces the editing cursor with a static, non-animated one intended for e-ink displays, to reduce flicker and improve readability. It has no settings, and other plugins that replace the cursor should be disabled to avoid conflicts.

```cue
plugin: {
    id:     "eink-cursor"
    name:   "Eink Cursor"
    author: "l'Atelier"
    repo:   "atelier-recherche/einkcursor"

    html_url:    "https://community.obsidian.md/plugins/eink-cursor"
    github_url:  "https://github.com/atelier-recherche/einkcursor"
    description: "Static cursor for e-ink displays. No settings, no animations. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Use a static, non-animated editing cursor optimized for e-ink screens to reduce flicker and improve readability. Disable other cursor-replacing plugins to avoid conflicts."

    stats: {
        downloads:  44
        updated_at: 1783287582000
    }
}
```
