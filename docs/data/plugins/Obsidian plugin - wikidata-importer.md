# Wikidata Importer

Imports data from Wikidata into the vault: a note carrying a Wikidata entity ID is filled with that entity's statements as note properties when the importer runs. New Wikidata entities can also be imported into the vault as notes of their own.

```cue
plugin: {
    id:     "wikidata-importer"
    name:   "Wikidata Importer"
    author: "samwho"
    repo:   "samwho/obsidian-wikidata-importer"

    html_url:    "https://community.obsidian.md/plugins/wikidata-importer"
    github_url:  "https://github.com/samwho/obsidian-wikidata-importer"
    description: "Import data from Wikidata into your vault."
    about:       "Import Wikidata properties into a note by adding a Wikidata entity ID and running the importer. Add Wikidata statements as note properties and import new Wikidata entities into your vault."

    stats: {
        downloads:  6923
        updated_at: 1777731773000
    }
}
```
