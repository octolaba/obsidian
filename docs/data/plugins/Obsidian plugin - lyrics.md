# Lyrics

Extends the audio player with interactive lyrics: an audio file is attached by file path or internal link and synced with LRC or SRT subtitles. Playback is navigated and controlled from the lyrics view, with play and pause, seeking, auto-scroll and sentence mode toggles, line editing and custom CSS styling.
