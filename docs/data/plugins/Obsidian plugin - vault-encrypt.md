# Vault Encrypt

Encrypts the contents of a vault with a password and decrypts them again, keeping files encrypted across restarts and controlling the state from a lock icon. The recorded About advises backing up the vault and remembering the password, and states that the plugin is early-stage and has not been security-audited.
