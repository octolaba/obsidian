# DoMD

Turns a note into a real-time collaborative document synced peer-to-peer, with no account required. Others can be invited to edit with visible cursors, or given a read-only live view. The file on disk is watched so changes propagate between editors, and edits are merged at span granularity to avoid conflicts.

    id:     "domd"
    name:   "DoMD"
    author: "Jayden"

    github_url:  "https://github.com/do-md/domd-obsidian"
    description: "Real-time, account-free peer-to-peer collaboration on your notes: edit together or share a read-only live view, synced at span granularity. - This plugin has not been manually reviewed by Obsidian staff."
