# Vaultbridge

Synchronizes a vault across desktop and mobile through the user's own CouchDB, encrypted end to end so that, as the recorded inputs put it, servers see only ciphertext. Conflicts open in a two-column diff resolved hunk by hunk, file history can be browsed and restored, and passphrases can be rotated across devices. Setup is described as a single string, with no accounts and no third-party servers.

```cue
plugin: {
    id:     "vaultbridge"
    name:   "Vaultbridge"
    author: "wenzel1983"
    repo:   "donnervs/vaultbridge"

    about:       "Sync your Obsidian vault across desktop and mobile via your own CouchDB with end-to-end encryption so servers see only ciphertext. View two-column conflict diffs with hunk-by-hunk resolution, browse and restore file history, and rotate passphrases across devices without accounts or third-party servers."
```
