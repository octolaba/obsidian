# Banners

Banners adds banner images and emoji icons to notes, taken from local files or from a pasted image URL. A banner can be dragged to reposition it and then locked, and banners or icons removed again. Banner data is stored in the file's front matter, so it can be edited by hand or used by other plugins.

```cue
plugin: {
    id:     "obsidian-banners"
    name:   "Banners"
    author: "noatpad"
    repo:   "noatpad/obsidian-banners"

    html_url:    "https://community.obsidian.md/plugins/obsidian-banners"
    github_url:  "https://github.com/noatpad/obsidian-banners"
    description: "Add banner images to your notes!"
    about:       "Add banner images and emoji icons to notes by selecting local files or pasting image URLs. Drag to reposition and lock banner placement, remove banners or icons, and store banner data in your file's frontmatter for manual editing or integration with other plugins."

    stats: {

}
```
