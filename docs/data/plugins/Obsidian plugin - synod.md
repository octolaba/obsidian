# Synod

Runs a council of LLM value agents over a journal to surface unresolved tensions and decisions that have not been made. The recorded About text states that the agents never propose compromises, and describes importing notes and connecting to OpenAI-compatible endpoints, with Ollama and OpenRouter named. The output is a bulletin and a side-panel report produced by a three-pass compiler and parallel agents.
