# Floating Sticky Notes

Creates, edits, colours and organises sticky notes that are stored as ordinary Markdown files in the vault. Notes open in popout or main windows, and filenames and content are managed from a sticky-note list. Each note's colour is kept in its own YAML frontmatter.

```cue
plugin: {
    id:     "floating-sticky-notes"
    name:   "Floating Sticky Notes"
    author: "kasairo"
    repo:   "kasairo/floating-sticky-notes"

    html_url:    "https://community.obsidian.md/plugins/floating-sticky-notes"
    github_url:  "https://github.com/kasairo/floating-sticky-notes"
```
