# Media Transcript

Opens audio and video files together with a matching sidecar subtitle file and shows a synchronized transcript whose current line is highlighted as the media plays. Subtitles are read from JSON, SRT or VTT files in the same folder, with matching captions selected automatically. Playback runs from 0.75x to 2x, clicking a line seeks to it, timestamps or text can be copied, and the transcript can be exported as a Markdown note.

```cue
plugin: {
    id:     "media-transcript"
    name:   "Media Transcript"
    author: "semsevens"
    repo:   "semsevens/obsidian-media-transcript"

    html_url:    "https://community.obsidian.md/plugins/media-transcript"
    github_url:  "https://github.com/semsevens/obsidian-media-transcript"
    description: "Play video/audio with synchronized, clickable transcripts. Click any line to seek; playing line auto-highlights. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open audio and video files with matching sidecar subtitles and read synchronized, clickable transcripts with follow-along highlighting. Read JSON, SRT, or VTT subtitle files from the same folder and auto-select matching captions. Play at 0.75–2×, click lines to seek and play, copy timestamps or text, and export the current transcript as a Markdown note."

    stats: {
        downloads:  40
        updated_at: 1785655954000
    }
```
