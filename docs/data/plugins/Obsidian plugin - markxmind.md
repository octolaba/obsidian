# MarkXMind

MarkXMind renders XMindMark syntax as XMind mind maps from xmind or xmindmark code blocks, drawn directly in Obsidian. Markers such as boundary, summary and relationship are supported, along with links and notes, and the rendering respects light and dark themes.

```cue
plugin: {
    id:     "markxmind"
    name:   "MarkXMind"
    author: "jinzcdev"
    repo:   "jinzcdev/obsidian-markxmind"

    html_url:    "https://community.obsidian.md/plugins/markxmind"
    github_url:  "https://github.com/jinzcdev/obsidian-markxmind"
    description: "Render XMindMark syntax as XMind mind maps in `xmind/xmindmark` code blocks. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render XMindMark syntax inside xmind or xmindmark code blocks as XMind mind maps directly in Obsidian. Include markers like boundary, summary, relationship, links, notes and respect light/dark themes."
```
