# Graphnosis

Indexes and encrypts the vault into a local semantic memory through the Graphnosis sidecar, keeping the data AES-256-GCM encrypted on the machine. Semantic search runs from the command palette and results can be inserted at the cursor, notes are saved into the encrypted cortex, and sync runs on save and at launch. Notes can be routed into separate engrams to keep topics apart.
