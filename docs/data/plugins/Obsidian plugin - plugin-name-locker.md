# Custom Extension Names

Replaces the display names of installed plugins with custom text, emoji or prefixes. Custom names can optionally be kept across plugin updates, and the original or community name can be restored. Search, filters, templates and batch actions handle many plugins at once.

```cue
plugin: {
    id:     "plugin-name-locker"
    name:   "Custom Extension Names"
    author: "AQiong 阿琼"
    repo:   "agarcabin/plugin-name-locker"

    html_url:    "https://community.obsidian.md/plugins/plugin-name-locker"
    github_url:  "https://github.com/agarcabin/plugin-name-locker"
    description: "Customize the display names of your installed plugins and optionally keep them unchanged across updates. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Customize the display names of installed plugins with your own text, emojis, or prefixes. Optionally preserve custom names across updates, restore original or community names, and manage multiple plugins with search, filters, templates, and batch actions."

    stats: {
        downloads:  123
        updated_at: 1785497094000
    }
}
```
