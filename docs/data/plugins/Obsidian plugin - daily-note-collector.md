# Daily Note Collector

Adds a link to the daily note for every newly created file, so new notes are tracked by the date on which they appeared. The result is a simple per-day index for navigating back to recently created files.

```cue
plugin: {
    id:     "daily-note-collector"
    name:   "Daily Note Collector"
    author: "la"
    repo:   "la/obsidian-daily-note-collector"

    html_url:    "https://community.obsidian.md/plugins/daily-note-collector"
    github_url:  "https://github.com/la/obsidian-daily-note-collector"
    description: "Adds links to new notes to your daily note."
    about:       "Add links to your daily note for every newly created file to keep new notes tracked by date. Maintain a simple per-day index for quick navigation back to recently created files."

    stats: {
        downloads:  2091
        updated_at: 1775387224000
    }
}
```
