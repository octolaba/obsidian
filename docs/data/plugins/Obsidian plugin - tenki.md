# Tenki

Tenki displays local weather and forecasts inside Obsidian through WeatherAPI. A WeatherAPI key and a city are entered in settings, after which current conditions, forecasts and sunrise and sunset times are shown and refreshed automatically, with a thirty-minute minimum update interval.

```cue
plugin: {
    id:     "tenki"
    name:   "Tenki"
    author: "ms3056"
    repo:   "ms3056/Tenki"

    html_url:    "https://community.obsidian.md/plugins/tenki"
    github_url:  "https://github.com/ms3056/Tenki"
    description: "A simple weather display."
```
