# Abbreviations and Acronyms

Abbreviations and Acronyms marks terminology automatically in reading view, Live Preview and optionally source mode. Definitions are read from note metadata or Markdown Extra syntax, every abbreviation in the current file can be listed, and each marked abbreviation carries a context menu.

```cue
plugin: {
    id:     "abbreviations-mark"
    name:   "Abbreviations and Acronyms"
    author: "dragonish"
    repo:   "dragonish/obsidian-abbreviations"

    html_url:    "https://community.obsidian.md/plugins/abbreviations-mark"
    github_url:  "https://github.com/dragonish/obsidian-abbreviations"
    description: "Implements automatic marking of abbreviations and acronyms (terminology)."
    about:       "Mark abbreviations and acronyms automatically in reading view, Live Preview, and optional source mode. Read definitions from note metadata or Markdown Extra syntax, list all abbreviations in the current file, and provide a context menu for each abbreviation."

    stats: {
        downloads:  3698
        updated_at: 1785944923000
    }
}
```
