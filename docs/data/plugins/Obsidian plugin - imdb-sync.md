# IMDb

Syncs an IMDb list or watchlist into the vault as individual templated notes, keeping IMDb fields such as title, year, rating, genres and links. Posters and extended metadata are fetched from OMDb, and Mustache templates control the note content, including plot, cast, writers and runtime.
