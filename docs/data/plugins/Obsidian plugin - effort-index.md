# Effort Index

Measures the editing time and revision effort behind each note, crediting bursts of keystrokes and separating revision sessions that are spaced apart. Notes with the highest measured effort that have not been opened for ninety days are resurfaced, per-note effort can be inspected and exported as CSV, and the project states that activity logs stay local.

```cue
plugin: {
    id:     "effort-index"
    name:   "Effort Index"
    author: "saiken"
    repo:   "israerusan/effort-index"

    html_url:    "https://community.obsidian.md/plugins/effort-index"
    github_url:  "https://github.com/israerusan/effort-index"
    description: "Measure the editing time and revision effort behind every note, then resurface the expensive ones you stopped reading. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Measure editing time and revision effort per note by crediting bursts of keystrokes and separating spaced revision sessions. Resurface the most expensive notes you haven't opened in 90 days, view per-note effort, export CSV, and keep all activity logs local for offline privacy."

    stats: {
        downloads:  40
        updated_at: 1785001264000
    }
}
```
