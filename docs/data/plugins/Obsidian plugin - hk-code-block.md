# HK Code Block

HK Code Block improves how code blocks are displayed in reading view by adding titles, collapsible sections, configurable line numbers and line highlighting. A quoted title labels a block, collapse is toggled, the line-number start can be set or the numbers hidden, and individual lines or ranges are marked for emphasis.
