# Sort Frontmatter

Frontmatter properties of the current note are sorted alphabetically. Sorting descends recursively through objects, arrays and nested structures up to five levels deep, which standardizes how the YAML metadata is written.

```cue

    id:     "sort-frontmatter"
    name:   "Sort Frontmatter"
    author: "mariomui"
    repo:   "mariomui/obsidian-sort-frontmatter"
```
