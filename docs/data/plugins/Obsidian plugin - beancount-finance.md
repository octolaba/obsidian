# Beancount Ledger

Beancount Ledger connects the vault to Beancount plain-text accounting files and presents a dashboard with net worth tracking, balance sheets, interactive charts and live financial metrics. BQL queries are embedded inline in notes, transactions are created with account autocomplete and validation, and commodity prices are fetched automatically into the Beancount files. It also provides connection validation and an auto-starting backend.
