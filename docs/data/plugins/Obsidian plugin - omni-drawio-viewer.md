# Omni Drawio Viewer

Views multi-page Drawio diagrams offline through a read-only viewer with a page selector, covering .drawio and .dio files. Files ending in .drawio.svg are shown from their embedded page data, or as a safe single-page SVG when that data is absent. A specific page can be embedded in a note through a page anchor or a drawio-preview code block.
