# Chronology

Chronology adds a calendar sidebar for navigating notes by day, week, month or a custom date range. The notes appear as a timeline that groups those created or modified in the same slot, or as a plain list, and clicking a month lists its notes. File metadata is read to infer the true creation date of synced files.
