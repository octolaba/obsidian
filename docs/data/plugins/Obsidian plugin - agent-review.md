# Agent Review

Keeps structured highlights, annotations, replies, tags, history, spatial notes and Bezier relations without writing any of that review data into the Markdown itself. A ReviewView offers document-wide and vault-wide filtering, statistics and batch management. Human users and external AI agents share the same local review data layer through a file command queue, a CLI and a versioned plugin API. Review data lives in the vault under .agent-review with local indexing, backups and recovery, and there is no built-in LLM, telemetry or automatic network access.
