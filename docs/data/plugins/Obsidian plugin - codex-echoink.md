# Codex EchoInk

Codex EchoInk opens a session-scoped Codex or OpenCode workspace in the Obsidian sidebar, where an agent can read and inspect files, edit them, and run local commands inside the vault. A process timeline shows the agent's reasoning, commands and file edits. A persistent Knowledge channel adds slash commands, Wiki-based evidence search and a health dashboard for maintaining vault knowledge.
