# Created Daily Note Sync

Reads the created field in a note's frontmatter and generates the corresponding Obsidian daily note when that file is missing. The vault or individual files can be scanned to backfill daily notes, following the Daily Notes settings and common date formats.

```cue
plugin: {
    id:     "created-daily-note-sync"
    name:   "Created Daily Note Sync"
    author: "zgfdada"
    repo:   "zgfdada/created-daily-note-sync"

    html_url:    "https://community.obsidian.md/plugins/created-daily-note-sync"
    github_url:  "https://github.com/zgfdada/created-daily-note-sync"
    description: "Automatically create corresponding Obsidian daily notes based on the created date in the note's frontmatter. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create missing daily notes from the created field in a note's frontmatter, auto-generating the corresponding daily file when absent. Scan the vault or individual files to backfill daily notes, respecting Obsidian's Daily Notes settings and common date formats."

    stats: {
        downloads:  91
        updated_at: 1779078267000
    }
}
```
