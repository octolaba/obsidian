# Star Gate

Web pages are browsed in a multi-tab browser embedded in Obsidian, and a whole page, a selected region or clipboard content is captured into a note. Analysis templates driven by several AI providers extract metadata such as YouTube channel, duration and tags and insert the result into a note template. The About text recorded for this entry is written in Korean.
