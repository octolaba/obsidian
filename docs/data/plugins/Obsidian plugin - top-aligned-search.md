# Top Aligned Search

Top Aligned Search searches within the active note through a floating find bar that stays above the editor and highlights all matches. Jumping to the next match aligns its line to the top of the editor, and the search window stays open while editing and can be dragged or resized without closing.

```cue
plugin: {
    id:     "top-aligned-search"
    name:   "Top Aligned Search"
    author: "Sean local"
    repo:   "tyronewj/top-aligned-search"

    html_url:    "https://community.obsidian.md/plugins/top-aligned-search"
    github_url:  "https://github.com/tyronewj/top-aligned-search"
    description: "Search within the active note and align each next match's line to the top of the editor. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Search the active Markdown note with a floating find bar that stays above the editor and highlights all matches. Align the selected match to the top of the editor as you jump between results, keep the search window open while editing, and drag or resize it without closing."

        downloads:  73

    }
}
```
