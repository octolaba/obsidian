# JotDrop

JotDrop presents vault notes as a Google Keep-style quick-capture card grid with colors, tags, pins, reminders, search and filtering, while every note stays a plain Markdown file in the vault. It is described as one part of a trio: a companion Android app adds share-sheet capture, OCR and voice-to-text, and a Chrome web clipper saves a page straight into the vault. The project states that it is open-source and offline, with no Google account, cloud, ads or tracking, and leaves syncing to Syncthing or any folder sync.
