# Kami Reader Companion

Keeps the workspace on one continuous shell across New Tab, Reading, Editing, Graph, Canvas and other root views. Active Markdown views get a continuous reading and editing presentation, the exact current heading is highlighted in the core Outline, and spare pane width is given to wide diagrams, tables, code and embeds. A Reading Stage can be toggled for focused reading; it targets desktop Obsidian 1.13 and later with the Default Theme.
