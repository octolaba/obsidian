# Granola API Sync

Syncs Granola meeting notes and full timestamped transcripts into the vault through Granola's official API, so no credentials are scraped. Only the API key is kept locally. Each meeting produces a note with metadata and a linked transcript file, on desktop and mobile.

```cue
plugin: {
    id:     "granola-api-sync"
    name:   "Granola API Sync"
    author: "StratosHouse"
    repo:   "arshiaecho/obsidian-granola-api-sync"

    html_url:    "https://community.obsidian.md/plugins/granola-api-sync"
    github_url:  "https://github.com/arshiaecho/obsidian-granola-api-sync"
    description: "Sync meeting notes and full transcripts from Granola into your vault using the official Granola API. Just paste an API key, no credential scraping. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync Granola meeting notes and full timestamped transcripts into your Obsidian vault via Granola's official API. Keep just your API key locally while generating per-meeting notes with metadata and linked transcript files; works on desktop and mobile."

    stats: {
        downloads:  239
        updated_at: 1784271554000
    }
}
```
