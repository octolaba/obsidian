# Image Embedder

Image Embedder downloads an image from a pasted URL and embeds it in the note, saving the file to a configurable attachment folder. Filename format, placeholders and optional timestamps are configurable, embedding can ask for confirmation, the saved path can be displayed, and a Markdown link to the embedded image is inserted.

```cue
plugin: {
    id:     "image-embedder"
    name:   "Image Embedder"
    author: "sky150"
    repo:   "sky150/obsidian-image-embedder"

    html_url:    "https://community.obsidian.md/plugins/image-embedder"
    github_url:  "https://github.com/sky150/obsidian-image-embedder"
    description: "Automatically downloads and embeds images from URLs when pasting"
    about:       "Download and embed images from pasted URLs into your vault, saving files to a configurable attachment folder with customizable filename formats and optional timestamps. Customize filename placeholders, enable confirmation before embedding, display saved file paths, and insert markdown links to the embedded images."

    stats: {
        downloads:  2104
        updated_at: 1784303527000
    }
}
```
