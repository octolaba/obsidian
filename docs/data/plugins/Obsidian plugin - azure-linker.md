# Azure DevOps Linker

Azure DevOps Linker formats an Azure DevOps work item identifier as a link, either to the item's web URL or to a local issue folder, creating that folder and its main info file when missing. Links are inserted from the editor or by entering an ID, and several Azure instances can be configured with one marked as the default.

```cue
plugin: {
    id:     "azure-linker"
    name:   "Azure DevOps Linker"
    author: "srz2"
    repo:   "srz2/obsidian-azure-devops-linker"

    html_url:    "https://community.obsidian.md/plugins/azure-linker"
    github_url:  "https://github.com/srz2/obsidian-azure-devops-linker"
    description: "Quickly format an Azure DevOps issue tag as a link to you Azure DevOps instance."
    about:       "Link Azure DevOps work items to their web URL or to a local issue folder, creating the folder and main info file if missing. Insert links from the editor or by entering an ID, and support multiple Azure instances with a default for quick linking."

    stats: {
        downloads:  949
        updated_at: 1736050462000
    }
}
```
