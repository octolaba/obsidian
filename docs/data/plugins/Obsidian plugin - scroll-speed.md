# Scroll Speed

Scroll Speed changes the mouse scroll speed inside files, from very slow to very fast. Holding the Alt key applies a multiplier that temporarily increases the speed for faster navigation.

```cue

    id:     "scroll-speed"
    name:   "Scroll Speed"
    author: "flolu"
    repo:   "flolu/obsidian-scroll-speed"

    html_url:    "https://community.obsidian.md/plugins/scroll-speed"
```
