# Vim Marker Sharpener

Vim Marker Sharpener applies text formatting from Vim's VISUAL and VISUAL LINE modes, turning the selection bold, italic, strikethrough, code or comment with a single command. Styles can be combined or stripped, and formatting can also be triggered from NORMAL mode through vim leader keys or hotkeys.

```cue
plugin: {
    id:     "vim-marker-sharpener"
    name:   "Vim Marker Sharpener"
    author: "artemdvoryadkin"
    repo:   "artemdvoryadkin/obsidian-vim-marker-sharpener"

    html_url:    "https://community.obsidian.md/plugins/vim-marker-sharpener"
    github_url:  "https://github.com/artemdvoryadkin/obsidian-vim-marker-sharpener"
    description: "Text formatting commands in Vim mode. Supports applying styles (bold, italic, etc.). Works correctly in visual mode with selected text."
    about:       "Format selected text in VIM VISUAL and VISUAL LINE modes as bold, italic, strikethrough, code, or comment with a single command. Combine multiple styles, strip formatting, and trigger formatting from NORMAL mode or via vim leader keys and hotkeys."

}
```
