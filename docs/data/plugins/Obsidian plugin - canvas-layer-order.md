# Canvas Layer Order

Canvas Layer Order provides presentation-style layer controls for overlapping Canvas cards: bring a card to front, send it to back, or move it forward or backward in the stack. Saved layer order is preserved when a card is focused, so the visual stack stays aligned with the node order.
