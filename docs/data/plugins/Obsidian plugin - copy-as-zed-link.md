# Copy as Zed Link

Copies the contents selected in Obsidian as a Zed-compatible link and places it on the clipboard. Pasting that link into Zed's agent panel attaches it there.

```cue
plugin: {
    id:     "copy-as-zed-link"
    name:   "Copy as Zed Link"
    author: "Santuzius"
    repo:   "santuzius/copy-as-zed-link"

    html_url:    "https://community.obsidian.md/plugins/copy-as-zed-link"
    github_url:  "https://github.com/santuzius/copy-as-zed-link"
    description: "Select contents in Obsidian and link them into your agent panel in Zed. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Copy selected contents as a Zed-compatible link and place it on the clipboard. Paste into Zed's agent panel to attach the link."

    stats: {
        downloads:  18
        updated_at: 1786431165000
    }
}
```
