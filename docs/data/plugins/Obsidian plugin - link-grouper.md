# Link Grouper

Groups every file linked or embedded in the active note into a newly created sibling folder named after that note. Naming collisions are handled by appending incremental numbers, and links across the vault are updated so link integrity survives the move. The recorded description notes that the plugin has not been manually reviewed by Obsidian staff.
