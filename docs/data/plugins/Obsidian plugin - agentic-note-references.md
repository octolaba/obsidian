# Agentic Note References

Agentic Note References copies a citation containing the file link, the line numbers and a custom prompt, ready to paste into an AI agent chat. The referenced lines come from the selection or the cursor position, and a configurable citation template and file path format carry placeholders for the filename and the line numbers.

```cue
plugin: {
    id:     "agentic-note-references"
    name:   "Agentic Note References"
    author: "imavinash"
    repo:   "avinashkanaujiya/obsidian-agentic-note-references"

    html_url:    "https://community.obsidian.md/plugins/agentic-note-references"
    github_url:  "https://github.com/avinashkanaujiya/obsidian-agentic-note-references"
    description: "Copy a citation with file link, line numbers, and a custom prompt for AI agents. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Copy a citation with file link, line numbers, and a custom prompt ready to paste into any AI agent chat. Select text or place the cursor to capture the referenced lines to the clipboard using a configurable citation template and file path format with placeholders for filename and line numbers."

    stats: {
        downloads:  337
        updated_at: 1783596094000
    }
}
```
