# Curtis AI Chat

A polyglot AI sidebar that talks to more than thirty providers, among them Anthropic, OpenAI, Gemini, Ollama, OpenRouter and Groq, through one interface, with image attachments, long-term memory kept as editable Markdown, slash commands and inline actions on the selection. An agent mode reads, edits and creates notes, one prompt can be run across two to five models side by side, selected text is rewritten with an accept or reject diff, Whisper provides voice input and output, and vault notes are mentioned as silent context. The plugin states that it is desktop preferred, that API keys live in the OS keychain, that data stays local, and that it is MIT licensed with zero telemetry.
