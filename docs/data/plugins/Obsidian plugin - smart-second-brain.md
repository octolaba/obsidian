# Smart Second Brain

Vault notes are queried in a chat driven by a retrieval pipeline that embeds vault content and retrieves the relevant parts to answer. Answers are traced back to their source notes through Obsidian links, chats are saved and resumed, and the model is switched between local and cloud providers such as Ollama and OpenAI. The recorded inputs state it can run fully offline so that data stays local.
