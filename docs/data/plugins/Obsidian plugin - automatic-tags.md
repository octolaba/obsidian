# Automatic Tags

Automatic Tags tags a note when it is created according to where the file is stored, through a simple mapping from path to tag. Simplified glob-style paths pick out the folders or files that a mapping applies to.

```cue
plugin: {
    id:     "automatic-tags"
    name:   "Automatic Tags"
    author: "jamalam360"
    repo:   "jamalam360/obsidian-automatic-tags"

    html_url:    "https://community.obsidian.md/plugins/automatic-tags"
    github_url:  "https://github.com/jamalam360/obsidian-automatic-tags"
    description: "Add tags to new notes automatically based on their path."
    about:       "Add tags to new notes based on their file path via a simple path-to-tag mapping. Use simplified glob-style paths to target folders or files and tag notes automatically on creation."

    stats: {
        downloads:  6630
        updated_at: 1713094550000
    }
}
```
