# Weread Vault

Syncs WeRead book metadata, highlights, ideas and reviews into the vault. Reading lists can be imported alongside external notes in MD, TXT or DOCX form, and personal reading notes are saved as separate Markdown files so a later sync does not overwrite them. A combined view shows book details, notes and reading statistics.

```cue

    id:     "weread-vault"
    name:   "Weread Vault"
    author: "茜宁郑"

    html_url:    "https://community.obsidian.md/plugins/weread-vault"

    about:       "Sync WeRead (微信读书) book metadata, highlights, ideas and reviews into your Obsidian vault. Import reading lists and external MD/TXT/DOCX notes, save personal reading notes as independent Markdown files to prevent overwrite, and view combined book details, notes and reading stats."
```
