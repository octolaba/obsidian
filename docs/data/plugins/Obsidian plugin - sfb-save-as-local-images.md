# Save as Local Images

Save as Local Images downloads every remote image in the current note into the vault's attachment folder, organised by the note's path. Markdown, HTML and wiki embed URLs are rewritten to the local copies, filenames get unique IDs and extensions derived from the content type, and progress plus individual download errors are reported.
