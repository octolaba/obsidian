# Blueprint

Blueprint applies per-note templates written as Nunjucks-backed blueprints, interpolating frontmatter properties into section-aware layouts. A blueprint can be applied to a single note, a folder or the whole vault, and the recorded inputs state that the update is non-destructive and preserves existing content.

```cue
plugin: {
    id:     "blueprint"
    name:   "Blueprint"
    author: "François Vaux"
    repo:   "madx/blueprint-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/blueprint"
    github_url:  "https://github.com/madx/blueprint-obsidian-plugin"
```
