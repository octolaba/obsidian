# Emoji Picker

Opens a searchable emoji picker from the editor toolbar or a hotkey and inserts the chosen emoji at the cursor. Skin-tone and category filters narrow the set, which is drawn from the emoji v15 release.

```cue
plugin: {
    id:     "emoji-picker"
    name:   "Emoji Picker"
    author: "alifa98"
    repo:   "alifa98/obsidian-emoji-picker"

    html_url:    "https://community.obsidian.md/plugins/emoji-picker"
    github_url:  "https://github.com/alifa98/obsidian-emoji-picker"
    description: "An Emoji Picker that allows you to insert the latest released emojis in your notes."
    about:       "Open a searchable emoji picker from the editor toolbar or with a hotkey. Insert selected emojis at the cursor with skin-tone and category filters, backed by the up-to-date emoji v15 set."

    stats: {
        downloads:  2385
        updated_at: 1732657902000
    }
}
```
