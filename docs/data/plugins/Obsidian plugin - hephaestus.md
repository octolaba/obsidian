# Hephaestus

Adds a chat pane for local models with live token streaming and native Markdown rendering. Notes, images, files or web pages can be sent as context, replies carry inline source citations, messages can be edited or regenerated, and a gauge tracks context usage. It connects to Ollama, LM Studio or any OpenAI-compatible local model server.
