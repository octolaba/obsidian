# Advanced Multi Column

Advanced Multi Column creates nested, interactive multi-column layouts whose sibling columns stay rendered while editing in Live Preview and Reading View. Columns are delimited by lightweight comment markers for column start, break and end, dragged to resize or reorder, edited inline with wikilink and image support, and styled per column.
