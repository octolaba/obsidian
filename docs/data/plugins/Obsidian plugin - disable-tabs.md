# Disable Tabs

Enforces a single tab by replacing the current view whenever a note is opened or closed, including pinned tabs, so every note reuses the same tab. The tabs button can be hidden on mobile.

```cue
plugin: {
    id:     "disable-tabs"
    name:   "Disable Tabs"
    author: "David V. Kimball"
    repo:   "davidvkimball/obsidian-disable-tabs"

    html_url:    "https://community.obsidian.md/plugins/disable-tabs"
    github_url:  "https://github.com/davidvkimball/obsidian-disable-tabs"
    description: "Disables having more than one tab open at a time."
    about:       "Enforce a single-tab interface by disabling multiple tabs in Obsidian. Replace the current view whenever you open or close a note — including pinned tabs — so new notes always reuse the same tab. Hide the tabs button on mobile for a cleaner UI."

    stats: {
        downloads:  4996
        updated_at: 1780170546000
    }
}
```
