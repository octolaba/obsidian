# comshit

comshit extends Canvas with Lovely-Mindmap-style shortcuts, directional navigation and node commands for mind mapping. Markdown and canvas files are synced bidirectionally, OSINT command-line tools such as Sherlock, Maigret and Social Analyzer can be run on a node's text, and spreadsheet .sheet files are embedded within the plugin folder.

    id:     "comshit"
    name:   "comshit"
