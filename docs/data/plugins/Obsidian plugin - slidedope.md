# SlideDope

SlideDope builds self-contained single-file HTML slide decks inside the vault, edited in a PPTX-like editor and playable in any browser. Editing covers a thumbnail sidebar, drag-to-reorder, inline text with a format toolbar, a slide clipboard and full undo and redo. Pasted images are stored as files in a deck images folder and can be dragged, nudged or resized, and standalone decks play or print with section progress and page counts.
