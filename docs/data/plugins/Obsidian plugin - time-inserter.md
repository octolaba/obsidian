# Time Inserter

Time Inserter writes the current time at the cursor position, rounded to the nearest five minutes and formatted as zero-padded 24-hour hours and minutes. It is described as ultra-lightweight and zero-dependency, running only when invoked so insertion is instant.

```cue
plugin: {
    id:     "time-inserter"
    name:   "Time Inserter"
    author: "heycalmdown"
    repo:   "heycalmdown/obsidian-time-inserter"

    html_url:    "https://community.obsidian.md/plugins/time-inserter"
    github_url:  "https://github.com/heycalmdown/obsidian-time-inserter"
    description: "Insert current time at cursor position, rounded to nearest 5-minute interval."
    about:       "Insert the current time rounded to the nearest 5 minutes in zero-padded 24-hour HH:MM format. Keep Obsidian fast with an ultra-lightweight, zero-dependency plugin that runs only when invoked for instant, no-delay insertion."

    stats: {
        downloads:  397
        updated_at: 1760665792000
    }
}
```
