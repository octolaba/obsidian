# Text Autocomplete

Text Autocomplete shows inline word suggestions in a dropdown as you type. The current word is replaced by clicking a suggestion or pressing Enter or Tab, arrow keys move through the list, Esc dismisses it, and Shift with Enter keeps Enter's default behaviour. A custom dictionary is maintained in settings and .txt word lists can be imported to widen the suggestions.
