# Mark and Select

This plugin sets a mark, lets the cursors move freely, and selects the text between the mark and the cursor position. Combined with ordinary cursor navigation that makes range-based selections such as an entire heading straightforward. The recorded text also notes it speeds up selection on mobile, where long-tap scrolling is slow.

    id:     "obsidian-mark-and-select"
    name:   "Mark and Select"
