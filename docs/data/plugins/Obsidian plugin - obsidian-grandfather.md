# Grandfather

Displays the current time, and optionally the date, in the status bar. The format is chosen from predefined options or set as a custom format.

```cue
plugin: {
    id:     "obsidian-grandfather"
    name:   "Grandfather"
    author: "noatpad"
    repo:   "noatpad/obsidian-grandfather"

    html_url:    "https://community.obsidian.md/plugins/obsidian-grandfather"
    github_url:  "https://github.com/noatpad/obsidian-grandfather"
    description: "Display the time and date in the status bar."
    about:       "Display the current time and optional date in the status bar. Choose from predefined time formats or set a custom format for a personalized clock."
```
