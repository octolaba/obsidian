# Zhongwen Reader

Zhongwen Reader is a lightweight hover dictionary for Chinese text based on CC-CEDICT: hovering shows simplified and traditional characters, pinyin or bopomofo, and definitions. Hovered words and their example sentences can be saved to a vocab list, browsed in a sidebar with HSK colour highlighting, and exported as Markdown flashcards.

```cue
plugin: {
    id:     "zhongwen-reader"
    name:   "Zhongwen Reader"
    author: "natipt"
    repo:   "natipt/obsidian-zhongwen-reader"

    html_url:    "https://community.obsidian.md/plugins/zhongwen-reader"
    github_url:  "https://github.com/natipt/obsidian-zhongwen-reader"
    description: "This lightweight plugin helps you read Chinese more easily with a CEDICT based hover-dictionary and vocabulary saving features."
    about:       "Hover over Chinese text to display simplified and traditional characters, pinyin or bopomofo, plus CC-CEDICT definitions. Save hovered words and example sentences to a vocab list, browse words in a sidebar with HSK color highlighting, and export vocab as Markdown flashcards."

}
```
