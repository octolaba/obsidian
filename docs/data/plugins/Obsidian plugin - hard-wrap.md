# Hard Wrap

Hard-wraps Markdown files on disk at a configurable column width while the editor still shows the paragraphs as soft-wrapped lines. Per-file frontmatter can override the width. A Reformat command normalizes pasted or externally edited text and rewraps files without a reload.

```cue
plugin: {
    id:     "hard-wrap"
    name:   "Hard Wrap"
    author: "alethiophile"
    repo:   "alethiophile/obsidian-hard-wrap"

    html_url:    "https://community.obsidian.md/plugins/hard-wrap"
    github_url:  "https://github.com/alethiophile/obsidian-hard-wrap"
    description: "Transparently hard-wrap markdown files on disk while displaying them as soft-wrapped paragraphs in the editor. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Hard-wrap Markdown files on disk at a configurable column width while rendering paragraphs as soft-wrapped lines in the editor. Allow per-file frontmatter overrides and run a Reformat command to normalize pasted or external edits and rewrap files without reload."

    stats: {
        downloads:  136
        updated_at: 1774383989000
    }
}
```
