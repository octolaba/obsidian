# Cimu Print

Prints notes, selections, folders or the active view through Obsidian's own renderer, first as a paginated PDF preview and then as a final PDF. Verified PDFs are streamed to local printers over CUPS on macOS and Linux, and an included command-line tool submits authenticated print jobs. Themes, embeds, Mermaid diagrams and MathJax are preserved in the output.
