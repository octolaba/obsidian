# Offline Spell Checker

An offline spell checker that reads standard .dic and .aff dictionary files. The recorded About text states that only the words visible on screen are scanned, which it attributes to avoiding lag and battery drain, and that right-clicking an underlined word offers top suggestions and one-click replacement. Further dictionary files or personal words can be added so specialized terms are no longer flagged.

    id:     "sxjeel-spell-checker"
    name:   "Offline Spell Checker"
    author: "sxjeel"

    html_url:    "https://community.obsidian.md/plugins/sxjeel-spell-checker"

Right-click underlined words to see top suggestions and replace them with one click. Add dictionary files or personal words to stop flagging specialized terms."
