# Dashboard Hub

Combines Bases, notes, PDFs and EPUBs, Kanban boards, calendars, timelines, web pages and encrypted secrets into a single-screen workspace. Widgets are draggable and resizable, files can be edited inline, and moving a Kanban card updates the source note. Dashboards are stored as readable YAML files inside the vault, and the project states that no external account is involved.
