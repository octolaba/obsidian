# Task Project Tree

Task Project Tree marks a folder as a project and generates an overview note summarizing its checkbox task progress and the breakdown of its child projects. Live completion badges appear in the file explorer, and nested child totals roll up into the parent summaries. The overviews update automatically as files change.
