# Sync Wechat Data

Copies articles and Markdown from a WeChat official account into the vault for offline, searchable access. Files land in a dedicated sync folder under sanitized names of the form date plus title, and updates are incremental, overwriting only what changed. Sync runs hourly or on demand.

plugin: {
    id:     "sync-wechat-data"
    name:   "Sync Wechat Data"
    author: "frank"
    repo:   "r3215407/obsidian-plugin"

    github_url:  "https://github.com/r3215407/obsidian-plugin"
    description: "sync wechat data - This plugin has not been manually reviewed by Obsidian staff."

Auto-sync hourly or trigger manual sync to keep content current."
