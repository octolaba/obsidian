# Favorite Note

Favorite Note marks a note as a favorite directly from the note list. A heart icon appears on hover, so preferred notes are highlighted and reachable quickly.

```cue
plugin: {
    id:     "favorite-note"
    name:   "Favorite Note"
    author: "mahmudz"
    repo:   "mahmudz/obsidian-favorite-plugin"

    html_url:    "https://community.obsidian.md/plugins/favorite-note"
    github_url:  "https://github.com/mahmudz/obsidian-favorite-plugin"
    description: "Mark your note as favorite."
    about:       "Mark notes as favorites directly from the note list. Show a heart icon when hovering over notes to quickly highlight and access preferred items."

    stats: {
        downloads:  6997
        updated_at: 1730052058000
    }
}
```
