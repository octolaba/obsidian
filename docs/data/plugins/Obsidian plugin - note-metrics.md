# Daily Note Metrics

Daily Note Metrics parses the tags and checkbox completions in Daily Notes and charts them in a dashboard view over a weekly, monthly or yearly period. Charts can be limited to particular folders or headings, combo, single and emoji tags are parsed while URL fragments and code blocks are skipped, and the charts refresh on demand.

```cue
plugin: {
    id:     "note-metrics"
    name:   "Daily Note Metrics"
    author: "andre-diamond"
    repo:   "andre-diamond/note-metrics"

    html_url:    "https://community.obsidian.md/plugins/note-metrics"
    github_url:  "https://github.com/andre-diamond/note-metrics"
    description: "Parses the tags in your Daily Notes and create interactive charts in a dashboard view."
    about:       "Visualize checkbox completions and tag usage from your Daily Notes with interactive charts and selectable weekly, monthly, or yearly periods. Filter by folders or specific headings, parse combo/single/emoji tags while skipping URL fragments and code blocks, and refresh charts on demand."

    }
}
```
