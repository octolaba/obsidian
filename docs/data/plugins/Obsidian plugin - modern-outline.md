# Modern Outline

Modern Outline overlays a customizable minimap outline on the edge of a note, showing headings as markers whose labels appear on hover and which jump to that heading when clicked. The active heading is highlighted in edit and reading modes, hierarchy is conveyed through indent and size or through tree lines, and spacing can be compressed for dense notes.
