# UNagent

A mobile-first AI assistant that is self-contained on phones and tablets and, on desktop, connects to a local hermes runtime through ACP to carry out heavier tasks, prompting for approval before local operations run. Conversations stream against models from several vendors, and 16 tools read from and write to notes. Semantic search is backed by a local vector cache, and conversation branches and memory sessions can be saved and restored.
