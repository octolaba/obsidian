# UI Tweaker

Adds, hides or modifies interface elements: sidebars, title bar, ribbon, tab bar, status bar, scrollbars and mobile controls are each hidden, always shown, or revealed on hover. Configurable command buttons can be added to the explorer and to tab headers, then reordered and styled. File properties can be de-emphasised for a plainer reading view.

```cue
plugin: {
    id:     "ui-tweaker"
    name:   "UI Tweaker"
    author: "David V. Kimball"
    repo:   "davidvkimball/obsidian-ui-tweaker"

    html_url:    "https://community.obsidian.md/plugins/ui-tweaker"
    github_url:  "https://github.com/davidvkimball/obsidian-ui-tweaker"
    description: "Add, hide, or modify various interface elements. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Customize Obsidian's interface by hiding, always showing, or reveal-on-hover virtually any UI element — sidebars, title bar, ribbon, tab bar, status bar, scrollbars, and mobile controls. Add configurable command buttons to explorer and tab headers, reorder and style them. Deemphasize file properties for a cleaner reading view."
```
