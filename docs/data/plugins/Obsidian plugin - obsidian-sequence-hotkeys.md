# Sequence Hotkeys

Any Obsidian command can be bound to a sequence of chords rather than to a single one, and the sequences are searched and managed in the plugin options. Enter and Escape may take part in a sequence. The recorded caveats are that a sequence can conflict with a default single-chord hotkey and that alternate keyboard layouts are not supported.

```cue
plugin: {
    id:     "obsidian-sequence-hotkeys"
    name:   "Sequence Hotkeys"
    author: "moolmanruan"
    repo:   "moolmanruan/obsidian-sequence-hotkeys"

    html_url:    "https://community.obsidian.md/plugins/obsidian-sequence-hotkeys"
    github_url:  "https://github.com/moolmanruan/obsidian-sequence-hotkeys"
    description: "Set hotkeys with key sequences instead of a single chord."
    about:       "Assign sequence-based hotkeys by chaining multiple chord inputs to trigger any Obsidian command. Search and manage sequences in the plugin options, include Enter or Escape in a sequence, and note sequences can conflict with default single-chord hotkeys and don't support alternate keyboard layouts."

    stats: {
        downloads:  7583

}
```
