# Knowledge Atlas

Presents every Markdown note as an interactive map: folders become planets and moons in an animated galaxy, and node size reflects knowledge depth. A readable tree view allows drilling down and following links. Notes can be searched, and activity heatmaps and knowledge-health panels surface orphans and unresolved links for daily review.

```cue
plugin: {
    id:     "knowledge-atlas"
    name:   "Knowledge Atlas"
    author: "Eason38467"
    repo:   "eason38467/Obsidian-Knowledge-Atlas"

    html_url:    "https://community.obsidian.md/plugins/knowledge-atlas"
    github_url:  "https://github.com/eason38467/Obsidian-Knowledge-Atlas"
    description: "Explore every Markdown note in your vault as an interactive, searchable knowledge map. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Explore your vault as an animated galaxy — folders become planets and moons, node size reflects knowledge depth, and switch to a readable tree to drill down and follow Obsidian links. Search notes, view activity heatmaps and knowledge-health panels to spot orphans, unresolved links, and run stable daily reviews."
```
