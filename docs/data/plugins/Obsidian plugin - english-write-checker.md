# English Write Checker

Analyses English writing in real time through a local LLM served by Ollama and marks its suggestions inline. Grammar errors are underlined in red and style upgrades in blue, suggestion chips explain themselves on hover, and a fix is accepted with one click. All processing stays local.

```cue
plugin: {
    id:     "english-write-checker"
    name:   "English Write Checker"
    author: "julioagh"
    repo:   "julioagh/english-write-checker"

    html_url:    "https://community.obsidian.md/plugins/english-write-checker"
    github_url:  "https://github.com/julioagh/english-write-checker"
    description: "Real-time English writing suggestions powered by a local LLM (Ollama) to reach C1-C2 level. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Analyze English writing in real time using a local LLM via Ollama and receive grammar and style suggestions inline. Highlight grammar errors with red underlines and style upgrades with blue, show clickable suggestion chips with hover explanations, accept fixes with one click, and keep all processing local."

    stats: {
        downloads:  125
        updated_at: 1778880071000
    }
}
```
