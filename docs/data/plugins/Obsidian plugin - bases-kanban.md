# Bases Kanban

Bases Kanban displays a Bases query as a live Kanban board, with one column per group-by value and one card per note. Dragging a card to another column writes the new group-by value into the note's frontmatter, cards open their note on click, and all data stays in standard Markdown frontmatter.

    id:     "bases-kanban"
    name:   "Bases Kanban"
    author: "kotserge"
