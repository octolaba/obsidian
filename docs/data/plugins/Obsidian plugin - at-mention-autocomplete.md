# Mention Autocomplete

Typing an at sign searches the vault by full-text content rather than by title, highlighting the matching sentence in each result. The full note renders as a preview, and choosing a result inserts a wikilink whose alias is the matching sentence or heading. Results stay current as notes change, and IME input is handled for languages such as Chinese.

```cue

    id:     "at-mention-autocomplete"
    name:   "Mention Autocomplete"
    author: "Darren Zheng"
    repo:   "slow-coding/obsidian-at-mention-autocomplete"

    html_url:    "https://community.obsidian.md/plugins/at-mention-autocomplete"
    github_url:  "https://github.com/slow-coding/obsidian-at-mention-autocomplete"
    description: "Type @ to full-text search and link notes. Rendered preview, smart sentence alias, keyboard-first. - This plugin has not been manually reviewed by Obsidian staff."

Preview full rendered notes and insert a smart wikilink using the matching sentence or heading as the alias. Keep results live as notes change and handle IME input for languages like Chinese."
