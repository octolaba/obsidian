# FlowScript Diagrams

Renders fenced flow code blocks as inline SVG flowcharts in Live Preview and Reading view using the FlowScript language. Its indentation-driven syntax describes start and end nodes, decisions, processes, branches, groups, swimlanes and flow direction. Theme overrides and transparent backgrounds are optional.
