# List Callouts

Creates callouts inside lists when a configurable character is typed at the start of a list item. The trigger character is replaced by an icon, and callout padding is adjusted through Style Settings.

```cue
plugin: {
    id:     "obsidian-list-callouts"
    name:   "List Callouts"
    author: "mgmeyers"
    repo:   "mgmeyers/obsidian-list-callouts"

    html_url:    "https://community.obsidian.md/plugins/obsidian-list-callouts"
    github_url:  "https://github.com/mgmeyers/obsidian-list-callouts"
```
