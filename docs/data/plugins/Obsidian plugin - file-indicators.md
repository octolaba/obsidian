# File indicators

File indicators marks files and folders in the file explorer with custom colored indicators, applied at file, folder or root level. Built-in shapes are available and an SVG shape can be supplied instead, rendered in the chosen color. Indicators are assigned from the right-click menu, from commands, or in the settings.

```cue
plugin: {
    id:     "file-indicators"
    name:   "File indicators"
    author: "jakobmick"
    repo:   "jakobmick/obsidian-file-indicators"

    html_url:    "https://community.obsidian.md/plugins/file-indicators"
    github_url:  "https://github.com/jakobmick/obsidian-file-indicators"
```
