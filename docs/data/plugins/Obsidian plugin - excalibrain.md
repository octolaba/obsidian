# ExcaliBrain

Draws an interactive, structured mind-map of the vault by interpreting links, tags, YAML fields and Dataview fields. Five relationship types — children, parents, friends, other friends and siblings — are inferred from forward links, backlinks, mutual links and explicit Dataview fields. Rendering the editable, navigable map relies on Dataview and Excalidraw.
