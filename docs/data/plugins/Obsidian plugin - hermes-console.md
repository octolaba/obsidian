# Hermes Console

Hermes Console gives Hermes Agent the note text you select or the cursor context you are working from, so it can rewrite, sharpen, research, critique, summarize or continue from that text while you keep writing in another tab. Several Hermes agents run at once, with tabs that can be renamed, reordered by drag and drop, and coloured. A spinner animation shows when Hermes is working.
