# Glimpse

Highlights text dynamically from the current selection or a search query, marking every occurrence with scrollbar markers and a minimap. Persistent highlights are defined by regex or keyword queries, with capture groups, line, start and end widgets, custom CSS and group management. A highlight index scans equals-delimited highlights and organizes them in a sidebar by heading hierarchy, and a desktop-only teleprompter opens karaoke-style floating windows that follow the document and cursor in real time, with multiple instances.
