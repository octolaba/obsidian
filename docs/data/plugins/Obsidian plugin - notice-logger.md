# Notice logger

Logs every Obsidian notice to the developer console, with an optional prefix and a timestamp, so notices can be inspected while debugging. Logging is switched on and off through commands.

```cue
plugin: {
    id:     "notice-logger"
    name:   "Notice logger"
    author: "gapmiss"
    repo:   "gapmiss/notice-logger"

    html_url:    "https://community.obsidian.md/plugins/notice-logger"
    github_url:  "https://github.com/gapmiss/notice-logger"
    description: "Logs all notices to the developer console, with optional prefix."
    about:       "Log all Obsidian notices to the developer console with an optional prefix and timestamp for easier debugging. Use quick commands to enable or disable logging."

    stats: {
        downloads:  3092
        updated_at: 1784326871000
    }
}
```
