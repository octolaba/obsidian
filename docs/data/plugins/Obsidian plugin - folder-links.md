# Folder Links

Turns internal links that end in a slash into links to folders. Clicking one reveals the folder in the file explorer, or creates the folder when it is missing. Resolved and unresolved styling is applied, custom display text is supported, and folder links appear in outgoing links and in the graph.

```cue
plugin: {
    id:     "folder-links"
    name:   "Folder Links"
    author: "steveoversea"
    repo:   "steveoversea/obsidian-folder-links"

    html_url:    "https://community.obsidian.md/plugins/folder-links"
    github_url:  "https://github.com/steveoversea/obsidian-folder-links"
    description: "Clicking a link to a folder makes it revealed in the navigation."
    about:       "Link to folders by adding a trailing slash to internal links. Reveal existing folders in the file explorer or create missing folders by clicking their links. Display resolved/unresolved styling, include folder links in outgoing links and the graph, and support custom display text."

    stats: {

}
```
