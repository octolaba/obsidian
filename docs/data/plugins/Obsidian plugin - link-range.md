# Link Range

Adds ranged wikilink support, so a range of headers inside a note can be addressed with wiki-link syntax while native backlink behavior is preserved. Standard or custom link patterns are supported, hover previews are provided, and ranged content can be embedded directly into notes.

```cue
plugin: {
    id:     "link-range"
    name:   "Link Range"
    author: "rmellmer"
    repo:   "rmellmer/obsidian-link-range"

    html_url:    "https://community.obsidian.md/plugins/link-range"
    github_url:  "https://github.com/rmellmer/obsidian-link-range"
    description: "Add ranged wikilink support."
    about:       "Query header ranges within notes using wiki-link syntax (e.g., [[Recipe#Ingredients..Directions]]) while preserving native backlink behavior. Support standard or custom link patterns, provide hover previews, and embed ranged content directly into notes."
```
