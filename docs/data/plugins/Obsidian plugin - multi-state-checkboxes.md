# Multi-State Checkboxes

Cycles checkboxes through a customizable list of statuses such as not started, in progress, complete and cancelled, by left-click, right-click menu or keyboard command. The status list and its cycle order are configurable. The recorded text states that a theme styling multi-state checkboxes is needed for distinct visuals, and that without one the characters still change in the source.
