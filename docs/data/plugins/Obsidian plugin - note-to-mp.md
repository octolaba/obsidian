# NoteToMP

Copies notes into the WeChat Official Account editor while preserving styles, code highlighting with line numbers, theme backgrounds, and LaTeX or AsciiMath rendering. Local images are uploaded, links are shown inline or collected as endnotes, and formatted drafts can be sent to the account instead of being reformatted by hand.
