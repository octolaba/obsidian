# Worktree Viewer

Watches the git worktrees of a repository from inside the vault, showing presence dots for agents or collaborators and the changed files of each worktree. Changes are reviewed as colored diffs or rendered previews, and accepting the work commits it, pushes it and opens a pull request in one click.

```cue
plugin: {
    id:     "worktree-viewer"
    name:   "Worktree Viewer"
    author: "Sebastian Winkler"
    repo:   "sjwinkler19/obsidian-worktree-viewer"

    html_url:    "https://community.obsidian.md/plugins/worktree-viewer"
    github_url:  "https://github.com/sjwinkler19/obsidian-worktree-viewer"
```
