# Pandoc Export Buttons

Exports the current note to Word, PDF, HTML, EPUB, LaTeX or any other format Pandoc supports, from one-click sidebar buttons or commands. Transclusions are expanded and images and citations resolved while preview output is preserved; PDFs are produced with a TeX engine or fall back to Chromium rendering. Export location and extra Pandoc arguments are configurable.
