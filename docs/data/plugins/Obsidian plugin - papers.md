# Papers

Searches arXiv by URL or title and imports the matching paper into the vault. A new note is created holding title, authors, publication year and URL, and the paper's PDF can be downloaded or embedded.

```cue
plugin: {
    id:     "papers"
    name:   "Papers"
    author: "willjhliang"
    repo:   "willjhliang/obsidian-papers"

    html_url:    "https://community.obsidian.md/plugins/papers"
    github_url:  "https://github.com/willjhliang/obsidian-papers"
    description: "Retrieve and import research papers."
    about:       "Search arXiv by URL or title and import papers directly into your vault. Create a new note containing title, authors, publication year and URL, and download or embed the paper's PDF."

    stats: {
        downloads:  863
        updated_at: 1782762563000
    }
}
```
