# Vaultkeeper

Vaultkeeper manages attachments inside the vault by moving files, sorting them into subfolders and cleaning up empty folders. Pasted files are renamed and the embeds that reference them are updated automatically. Unlinked attachments can be found and purged, and text can be extracted from images and PDFs with OCR.
