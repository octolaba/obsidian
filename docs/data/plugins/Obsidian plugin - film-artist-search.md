# Film Artist Search

Film Artist Search queries TMDb for actors, directors, producers, writers and other people and brings their data into the vault. It can create a structured Markdown person note, insert a link inline while editing, or replace a note's content with the fetched metadata rendered through your template.

```cue
plugin: {
    id:     "film-artist-search"
    name:   "Film Artist Search"
    author: "Hamza Moiyadi"
    repo:   "hamzamoiyadi/obsidian-film-artist-search"

    html_url:    "https://community.obsidian.md/plugins/film-artist-search"
    github_url:  "https://github.com/hamzamoiyadi/obsidian-film-artist-search"
    description: "Search TMDb for actors, directors, producers, writers, etc. and create structured vault notes or insert wikilinks. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Search TMDb for actors, directors, producers and bring their data directly into your vault as structured Markdown notes or quick [[wikilink]]s. Create full person notes, insert inline links while editing, or replace a note's content with fetched metadata rendered from your template."

    stats: {

    }
}
```
