# Bookmark List File Generator

The plugin writes Obsidian's bookmarks into a Markdown file automatically. The output filename is configurable and the file is regenerated at a chosen interval so the list stays up to date.

```cue
plugin: {
    id:     "bookmark-list-generator"
    name:   "Bookmark List File Generator"
    author: "newcodejin"
    repo:   "newcodejin/obsidian-bookmark-list-generator"

    html_url:    "https://community.obsidian.md/plugins/bookmark-list-generator"
    github_url:  "https://github.com/newcodejin/obsidian-bookmark-list-generator"
    description: "Generate a markdown file from Obsidian bookmarks automatically - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Generate a Markdown file of your Obsidian bookmarks automatically. Customize the output filename and auto-regenerate the file at a chosen interval to keep your bookmark list up to date."

    stats: {
        downloads:  74
        updated_at: 1784117975000
    }
}
```
