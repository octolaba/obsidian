# Copy for Email and Chat

Copies a selection or a whole note as rich text aimed at email, preserving headings, tables, callouts, code blocks and task lists while converting Mermaid diagrams, charts, math and SVGs into embedded images. Styles are inlined and vault images are embedded as data URIs, with a light palette suited to white email bodies. The same copy also carries a chat-styled plain-text flavor in which headings, emphasis, ordered lists and quotes are redrawn with visible markers, every marker configurable in settings and a Minimal style available for undecorated text. A ribbon button copies the selection, or the whole note when nothing is selected.
