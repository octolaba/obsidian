# Wechat Reading

Synchronises a WeChat Reading shelf together with highlights, notes, reviews, reading progress and statistics into local Markdown notes. A summary page groups books by reading status while individual book notes are filed into category folders, and covers are downloaded into a local assets folder. Handwritten text between the keep-me markers survives a resync, runs can be incremental or a full re-sync, and a synchronisation log is written for auditing.

```cue
plugin: {
    id:     "wechatreading-highlights"
    name:   "Wechat Reading"
    author: "EricZheng"
    repo:   "ezdever/obsidian-wechatreading-highlights-sync"

    html_url:    "https://community.obsidian.md/plugins/wechatreading-highlights"
    github_url:  "https://github.com/ezdever/obsidian-wechatreading-highlights-sync"
    description: "Sync WeChat Reading shelf, highlights, notes, and reading stats to Markdown notes. - This plugin has not been manually reviewed by Obsidian staff."

Generate a summary page grouped by reading status and individual book notes organized into category folders, download covers into a local assets folder, and preserve handwritten content between %% keep-me %% markers. Perform incremental or full re-sync and write synchronization logs for auditing."
