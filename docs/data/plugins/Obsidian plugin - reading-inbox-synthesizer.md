# Reading Inbox Synthesizer

Turns a backlog of web clippings into a single Reading Synthesis note holding short summaries, key claims, cross-article themes, weekly highlights, and a prioritized list of items needing attention. Estimated read times, shared topics, and stale items are shown, so what to read next or discard can be decided from one place.
