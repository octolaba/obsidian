# Mochi Cards Exporter

Mochi Cards Exporter turns Markdown notes into Mochi-compatible flashcard packages, carrying images, audio, video and other attachments with them. A card is written by tagging a line as its front and separating the back with section dividers, after which a mochi file is generated ready for import into Mochi.
