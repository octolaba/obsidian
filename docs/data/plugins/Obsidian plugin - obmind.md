# MindBraid

Turns the headings and nested lists of the active Markdown note into an interactive, editable mind map, with the Markdown remaining the source of truth and updates applied live. Topics are created from the keyboard and restructured by drag-and-drop, with layouts, independent styles and color schemes, search and import. Export covers SVG, PNG, JPG and PDF, and it makes no network requests and collects no telemetry.
