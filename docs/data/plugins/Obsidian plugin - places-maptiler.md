# Places - MapTiler

Supplies MapTiler vector maps, geocoding and elevation data to Places, covering map tiles, POI search and elevation replacement. Selected map styles, glyphs, sprites, tiles and DEM terrain are loaded for 3D relief, and search terms resolve into place suggestions and coordinates.
