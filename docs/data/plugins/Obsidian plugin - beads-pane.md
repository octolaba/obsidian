# Beads

Shows issues from the Beads (bd) tracker in a live pane with Ready, In progress, Blocked and Closed tabs, live counts, pagination and auto-refresh. An issue opens in its own tab as YAML frontmatter plus a Markdown body, and edits are saved back to bd. Live queries can also be embedded in notes and new beads captured quickly; the plugin is desktop-only and needs the bd CLI.

```cue
plugin: {
    id:     "beads-pane"
    name:   "Beads"
    author: "Rome Thorstenson"
    repo:   "rome-1/obsidian-beads"

    html_url:    "https://community.obsidian.md/plugins/beads-pane"
    github_url:  "https://github.com/rome-1/obsidian-beads"
    description: "A live pane and editor for the Beads (bd) issue tracker — see what's ready, edit issues inline, and embed live queries in your notes. Desktop only. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render a live, clickable pane for Beads (bd) issues with Ready · In progress · Blocked · Closed tabs, live counts, pagination and auto-refresh. Open issues in tabs as YAML frontmatter plus a Markdown body, edit and save changes back to bd, embed live queries inline and capture new beads quickly. Use Obsidian Desktop with the bd CLI to sync edits."

    stats: {
        downloads:  31
        updated_at: 1785299841000
    }
}
```
