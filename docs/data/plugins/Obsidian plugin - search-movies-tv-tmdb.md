# Search Movies and TV Shows TMDB

Search Movies and TV Shows TMDB searches for movies and television shows through the TMDB API from inside Obsidian and creates notes with ratings automatically. Key metadata and summaries are displayed for quick reference.

```cue
plugin: {
    id:     "search-movies-tv-tmdb"
    name:   "Search Movies and TV Shows TMDB"
    author: "Bernardo Nogueira"
    repo:   "bernardonogueira8/search-movies-tv-tmdb"

    html_url:    "https://community.obsidian.md/plugins/search-movies-tv-tmdb"
    github_url:  "https://github.com/bernardonogueira8/search-movies-tv-tmdb"
    description: "Search for movies and TV shows on TMDB and automatically create notes with ratings. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Search movies and TV shows using the TMDB API directly from Obsidian. Display key metadata and summaries for quick reference."

    stats: {

}
```
