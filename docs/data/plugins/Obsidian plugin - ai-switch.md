# AI Switch

Copies local AI coding tool configuration files in .toml, .json and .yaml form into the vault as Markdown snapshots, grouped by machine and tool. Snapshots are managed from a sidebar and refreshed on demand, and can be applied back to the local configs after confirmation, with timestamped backups taken automatically.

    id:     "ai-switch"
    name:   "AI Switch"
    author: "fengshuzi"
    repo:   "fengshuzi/ai-switch"

    github_url:  "https://github.com/fengshuzi/ai-switch"

Manage snapshots from a sidebar, refresh on demand, and apply snapshots back to local configs with confirmation and automatic timestamped backups."
