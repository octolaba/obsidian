# Current Pane Media Gallery Viewer

Displays the images and videos of the active Markdown note in a customizable side pane, so media under the cursor can be previewed while editing. Cursor moves and clicks are synced between the document and the gallery, a double-click zooms, and repeated occurrences are cycled through. Six layouts are available, with lazy rendering for very long notes.
