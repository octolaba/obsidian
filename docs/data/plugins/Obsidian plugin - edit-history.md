# Edit History

Keeps an automatic per-file, per-vault history of note edits that can later be diffed, copied or restored. Edits are browsed by calendar or timeline and compared side by side or inline, with previous and next navigation and keyboard control. Storage is bounded through compressed diffs, limits and selective file or path rules, and the history file stays accessible from outside.
