# Advanced Audio Recorder

Advanced Audio Recorder captures audio with pause and resume and records several tracks at once from up to eight input devices, with status-bar and ribbon feedback. Recordings are saved to any vault folder or beside the active note in WAV, MP3, FLAC, OGG, WebM, MP4, M4A or AAC, converted between formats and linked into notes. Diagnostics and test recordings help check the configured input.
