# Auto Index

Auto Index generates and maintains index notes for chosen folders, listing their files and subfolders recursively as a tree. The indexes are updated at configurable intervals, and folder labels and bolded names mark the structure.

```cue
plugin: {
    id:     "auto-index"
    name:   "Auto Index"
    author: "rakushkatop"
    repo:   "rakushkatop/obsidian-auto-index"

    html_url:    "https://community.obsidian.md/plugins/auto-index"
    github_url:  "https://github.com/rakushkatop/obsidian-auto-index"
    description: "Automatically generates index notes for specified folders, listing files and subfolders recursively. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Generate and maintain index notes for chosen folders, listing files and subfolders recursively as a tree. Update indexes at configurable intervals and add folder labels and bolded names for clearer structure."
```
