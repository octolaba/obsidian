# Podcast Note

Creates podcast notes from a single episode URL and fetches the title, image, description, and further metadata automatically. Custom templates style the generated notes, and linked notes can be created in batch from selected episode links across popular podcast services.

```cue
plugin: {
    id:     "podcast-note"
    name:   "Podcast Note"
    author: "marcjulianschwarz"
    repo:   "marcjulianschwarz/obsidian-podcast-note"

    html_url:    "https://community.obsidian.md/plugins/podcast-note"
    github_url:  "https://github.com/marcjulianschwarz/obsidian-podcast-note"
    description: "Podcast Note lets you automatically add podcast information to your notes."
    about:       "Create podcast notes from a single episode URL and auto-fetch title, image, description, and metadata. Use custom templates to style generated notes and batch-create linked notes from selected episode links across popular podcast services."
```
