# Inbox Curator

Reviews, summarizes and auto-sorts inbox notes using OpenAI, Gemini or Anthropic, classifying each item into Archive, Read Later or Tasks. It processes articles, chat logs, PDFs, images and URLs in bulk from within the vault. Content is sent to the chosen AI provider, and the plugin states that its actions remain reversible.
