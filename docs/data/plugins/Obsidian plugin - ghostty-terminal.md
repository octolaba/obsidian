# Ghostty Terminal

Embeds a Ghostty-powered terminal pane in Obsidian using the same libghostty-vt WASM parser as the native application, together with the user's real Ghostty configuration. A shell runs through a Python PTY proxy with Canvas rendering, full Unicode and truecolor, OSC 8 links, Kitty graphics and independent splits. An Open here entry is added to the file-explorer context menu.

```cue
plugin: {
    id:     "ghostty-terminal"
    name:   "Ghostty Terminal"
    author: "lavs9"
    repo:   "lavs9/obsidian-ghostty-terminal"

    html_url:    "https://community.obsidian.md/plugins/ghostty-terminal"
    github_url:  "https://github.com/lavs9/obsidian-ghostty-terminal"
    description: "True Ghostty embedded terminal (libghostty-vt WASM) – with your real Ghostty config, multi-split support, and file-explorer context menu. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed a Ghostty-powered terminal pane inside Obsidian using the same WASM VT parser as the native app. Run a real shell via a Python PTY proxy with pixel-perfect Canvas rendering, full Unicode & truecolor, OSC 8 links, Kitty graphics, independent splits, and file-explorer \"Open here\"."
```
