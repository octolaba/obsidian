# New Tab Here

Opens new tabs directly beside the active tab instead of at the end of the tab strip. The New tab command, the ribbon plus button and any configured hotkey are intercepted so the new tab is inserted next to the active one, and custom bindings are respected.

```cue
plugin: {
    id:     "new-tab-here"
    name:   "New Tab Here"
    author: "Ash RuDral"
    repo:   "ashrudral/new-tab-here"

    html_url:    "https://community.obsidian.md/plugins/new-tab-here"
    github_url:  "https://github.com/ashrudral/new-tab-here"
    description: "Opens new tabs, via the command palette or your configured hotkey, directly next to the active tab instead of at the end of the tab strip. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open new tabs directly next to the active tab instead of at the end of the tab strip. Intercept the New tab command, ribbon \"+\" button, and your configured hotkey to insert the new tab beside the active one and respect custom bindings."

    stats: {
        downloads:  23
        updated_at: 1785834040000
    }
}
```
