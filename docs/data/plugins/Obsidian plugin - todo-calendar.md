# Todo Calendar

Todo Calendar renders the Markdown to-dos of a bound file as a visual monthly calendar and timeline showing task dates and completion status. Edits sync in both directions with the source Markdown, which can be any file, and the view updates in real time as files change. Date tags in the at-sign YYYY-MM-DD form are parsed, English and Traditional Chinese are supported, and tasks can be filtered by range or by having no deadline.

```cue
plugin: {
    id:     "todo-calendar"
    name:   "Todo Calendar"
    author: "qingyu"
    repo:   "itzqingyu/todo-calendar"

    html_url:    "https://community.obsidian.md/plugins/todo-calendar"
    github_url:  "https://github.com/itzqingyu/todo-calendar"
    description: "Visual calendar for your to-do-calendar.md. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display your Markdown to-dos in a visual monthly calendar and timeline that highlights task dates and completion status. Sync edits bi-directionally with the source Markdown (bind to any file) and update in real time when files change. Parse date tags like @ YYYY-MM-DD, support English and Traditional Chinese, and filter tasks by ranges or no-deadline items."

    stats: {
        downloads:  23
        updated_at: 1784591772000
    }
}
```
