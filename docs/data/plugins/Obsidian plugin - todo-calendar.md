# Todo Calendar

Shows Markdown to-dos in a monthly calendar and a timeline that mark task dates and completion status. Edits flow both ways with the bound source file, which can be any Markdown file, and the views update in real time as files change. Dates are parsed from at-sign date tags in YYYY-MM-DD form, tasks can be filtered by range or by having no deadline, and the interface is available in English and Traditional Chinese.

```cue
plugin: {
    id:     "todo-calendar"
    name:   "Todo Calendar"
    author: "qingyu"
    repo:   "itzqingyu/todo-calendar"

    html_url:    "https://community.obsidian.md/plugins/todo-calendar"
    github_url:  "https://github.com/itzqingyu/todo-calendar"
    description: "Visual calendar for your to-do-calendar.md (or any markdown file keeping your to-do tasks). - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display your Markdown to-dos in a visual monthly calendar and timeline that highlights task dates and completion status. Sync edits bi-directionally with the source Markdown (bind to any file) and update in real time when files change. Parse date tags like @ YYYY-MM-DD, support English and Traditional Chinese, and filter tasks by ranges or no-deadline items."

    stats: {

    }
}
```
