# Idle Monitor

Idle Monitor tracks idle time and shows it in the status bar, with a hover tooltip giving the exact time typing stopped. The idle threshold is configurable, mouse movement can be included or excluded as activity, tooltips use 12- or 24-hour time, and the status text can be colored or given a glowing rainbow gradient.

```cue
plugin: {
    id:     "idle-monitor"
    name:   "Idle Monitor"
    author: "alberto98fx"
    repo:   "alberto98fx/idle-monitor-obsidian"

    html_url:    "https://community.obsidian.md/plugins/idle-monitor"
    github_url:  "https://github.com/alberto98fx/idle-monitor-obsidian"
    description: "Get notified when you stop typing to stay motivated."
    about:       "Track idle time and display real-time status in the status bar, with a hover tooltip showing the exact time you stopped typing. Customize the idle threshold, include or exclude mouse movement, pick 12/24-hour tooltips, and apply a colored or glowing rainbow gradient to the status text."
```
