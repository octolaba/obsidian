# Emoji Autocomplete

Suggests emoji as a shortcode is typed, matching fuzzily and highlighting the candidates. Tag search and recent history narrow the list, and a shortcode is either replaced immediately or kept with a live preview. The emoji list comes from gemoji.

```cue
plugin: {
    id:     "emoji-autocomplete"
    name:   "Emoji Autocomplete"
    author: "kraxen72"
    repo:   "kraxen72/obsidian-emoji-autocomplete"

    html_url:    "https://community.obsidian.md/plugins/emoji-autocomplete"
    github_url:  "https://github.com/kraxen72/obsidian-emoji-autocomplete"
    description: "Smart suggestions when typing emoji shortcodes & more! :star:"
    about:       "Insert emoji quickly using shortcode autocomplete with fuzzy matching and highlighted suggestions. Use tag search and recent history to find emojis, choose immediate replacement or keep shortcodes with live preview, powered by gemoji for an up-to-date list and fast performance."

    stats: {
        downloads:  12895
        updated_at: 1778619406000
    }
}
```
