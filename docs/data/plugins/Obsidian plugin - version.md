# Multi-Version Notes

Keeps several parallel texts of the same subject as independent vault files and presents them as one topic in the File Explorer. Editable versions can be switched inside the same pane, and links can point either at the topic as a whole or at one specific version. Backlinks are aggregated across Markdown, Canvas and Excalidraw files.
