# Block Reference Enhancer

The plugin renders Logseq-style UUID block references and embed transclusions in Live Preview and Reading Mode, including child blocks, backlinks, source navigation, autocomplete and reference badges. It keeps a local index for large Markdown vaults and can hide properties. It is aimed at Logseq-to-Obsidian migration and offers optional page-property and YAML frontmatter sync while preserving the original Markdown.

    id:     "block-reference-enhancer"
    name:   "Block Reference Enhancer"
    author: "EllisMorrow"

    about:       "Bring Logseq-style UUID block references, block embeds, and outlines to Obsidian.
