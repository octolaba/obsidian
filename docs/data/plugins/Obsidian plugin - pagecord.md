# Pagecord

Publishes notes from Obsidian to a Pagecord blog with a single command. Title, slug, tags and status are read from frontmatter, embedded images are uploaded automatically, and posts and drafts are created or updated with their tracking recorded back in frontmatter.

```cue
plugin: {
    id:     "pagecord"
    name:   "Pagecord"
    author: "lylo"
    repo:   "lylo/obsidian-pagecord"

    html_url:    "https://community.obsidian.md/plugins/pagecord"
    github_url:  "https://github.com/lylo/obsidian-pagecord"
    description: "Publish notes to your Pagecord blog. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Publish notes from Obsidian to your Pagecord blog with a single command. Read frontmatter for title, slug, tags and status, upload embedded images automatically, and create or update posts and drafts tracked via frontmatter."

    stats: {
        downloads:  199
        updated_at: 1781994162000
    }
}
```
