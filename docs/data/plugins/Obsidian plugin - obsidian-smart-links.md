# Smart Links

Regular-expression patterns paired with replacement strings turn matching text into links in reading view. Tokens such as a stock symbol or an issue key become full URLs, and a match is taken only at the start of a line or after whitespace.

```cue
plugin: {
    id:     "obsidian-smart-links"
    name:   "Smart Links"
    author: "kemayo"
    repo:   "kemayo/obsidian-smart-links"

    html_url:    "https://community.obsidian.md/plugins/obsidian-smart-links"
    github_url:  "https://github.com/kemayo/obsidian-smart-links"
    description: "Automatically detect strings using regular expressions and turn them into links in reading view. Useful for stock symbols, issue tracking, etc."
    about:       "Define custom smart-link patterns to auto-link matching text when reading notes. Write regular-expression patterns and replacement strings to turn tokens like T12345 or #4324 into full URLs, with matches applied only at line start or after whitespace."

    stats: {
        downloads:  6327

}
```
