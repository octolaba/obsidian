# Hidden Folder

Hidden Folder hides folders in the file explorer by matching their names against regular expressions. A ribbon icon toggles the hiding, and the regex rules that select which folders to hide are configurable.

    id:     "hidden-folder-obsidian"
    name:   "Hidden Folder"
