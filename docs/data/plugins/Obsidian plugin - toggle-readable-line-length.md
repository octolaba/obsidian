# Toggle Readable line length

Toggle Readable line length adds a command that switches the Readable line length editor setting on and off. Bound to a hotkey it moves between wrapped readable width and full-width editing without opening the settings.

```cue
plugin: {
    id:     "toggle-readable-line-length"
    name:   "Toggle Readable line length"
    author: "drichardson"
    repo:   "drichardson/obsidian-toggle-readable-line-length"

    html_url:    "https://community.obsidian.md/plugins/toggle-readable-line-length"
```
