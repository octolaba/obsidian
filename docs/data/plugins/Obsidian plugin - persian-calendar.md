# Persian Calendar

Persian Calendar shows the Persian solar calendar and Iranian official events beside Gregorian and Hijri dates in a single sidebar view. It creates daily, weekly, monthly, seasonal and yearly notes from templates that support placeholders and note references through the at sign. The recorded inputs state that files are stored in Gregorian dates for compatibility with other plugins.
