# Images Preview

Opens a popup preview when a note image is clicked, with zoom, dragging, cropping and a double-click toggle between fit and actual size. Wheel and touch gestures drive it, filenames can be copied from the preview, and browsing runs through a thumbnail gallery or previous and next controls. Several images can be pinned side by side for comparison, or Normal mode used for a single overlay.
