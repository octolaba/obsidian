# Knowledge Overview

Generates structured subject overviews, study outlines and chapter notes from a subject name using OpenAI-compatible LLMs. One Markdown note is created per chapter, with formulas rendered through KaTeX and progress shown while the run proceeds. Failed chapters can be resumed, transient API failures are retried, and several output languages are supported with English key-term glossaries.
