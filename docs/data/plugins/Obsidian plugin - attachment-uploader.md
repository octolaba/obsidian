# Attachment Uploader

Uploads local attachments to cloud storage by running a configurable shell command, with uPic and Picsee supplied as examples. The targeted file types are configurable, uploads can trigger when a file is pasted or dragged in, originals can be deleted afterwards, and the resulting URL is extracted from the command output.

```cue
plugin: {
    id:     "attachment-uploader"
    name:   "Attachment Uploader"
    author: "zhuxining"
    repo:   "zhuxining/obsidian-attachment-uploader"

    html_url:    "https://community.obsidian.md/plugins/attachment-uploader"
    github_url:  "https://github.com/zhuxining/obsidian-attachment-uploader"
    description: "Upload attachments to PicSee or uPic, with customization for commands and file type."
    about:       "Upload local attachments to cloud storage using a customizable shell upload command with built-in uPic and Picsee examples. Specify which file types to target, auto-upload when pasting or dragging files into Obsidian, optionally delete originals, and extract the returned URL from the command output."

    stats: {
        downloads:  2761
        updated_at: 1785737929000
    }
}
```
