# Easy Recall

Turns native Markdown into flashcards with no configuration, using highlight syntax for cloze deletions and a question marker for question-and-answer cards. Decks are organized by file-level tags, and cards are rated Again, Hard or Good, with Again cards returned to the queue. Review runs in a modal or in a reused Obsidian tab on desktop and mobile, and the interface language follows the Obsidian setting.

```cue
plugin: {
    id:     "easy-recall"
    name:   "Easy Recall"
    author: "Geno Zhou"
    repo:   "genozhou/easy-recall"

    html_url:    "https://community.obsidian.md/plugins/easy-recall"
    github_url:  "https://github.com/genozhou/easy-recall"
    description: "Simple spaced repetition for flashcards: Cloze, Q&A, zero-config. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Start spaced repetition with zero setup using native Markdown cloze ==highlight== and ?question syntax. Organize decks with file-level #easy-recall/ tags and rate cards Again/Hard/Good with instant feedback that returns Again cards to the queue. Review in a modal or reuse an Obsidian tab on desktop and mobile, with interface language auto-matching Obsidian settings."

    stats: {
        downloads:  473
        updated_at: 1786286704000
    }
}
```
