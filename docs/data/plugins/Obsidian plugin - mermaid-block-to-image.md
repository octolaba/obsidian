# Mermaid Block to Image

Converts a Mermaid code block into a static image URL in SVG, PNG or WebP through the Kroki or Mermaid.ink services, and converts it back to an editable code block again. The recorded text states that this is meant to speed up note loading, keep the vault free of generated clutter and keep rendering consistent across devices.
