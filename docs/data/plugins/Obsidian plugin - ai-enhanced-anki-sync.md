# AI-AnkiSync

AI-AnkiSync detects Remnote-style flashcards in notes, expands and polishes their content with OpenAI models from brief keywords, and syncs them to Anki through AnkiConnect. Decks are assigned from file names, hierarchical tags are built from headings, and a customizable system prompt shapes the AI output.
