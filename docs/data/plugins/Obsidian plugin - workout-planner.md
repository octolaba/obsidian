# Workout Planner

Reads workout logs kept in a single CSV and renders them as interactive charts, sortable tables, timers and a dashboard covering volume, weight, reps, duration, pace and heart rate. Protocols and muscle maps are tracked, session duration is estimated, and a touch-friendly modal handles quick logging.
