# Nifty Links

Nifty Links renders Notion-style rich link cards in place of bare URLs, in a clean and minimalist shape. Page metadata is fetched through Crestify and Microlink, and the resulting compact previews are styled for dark mode as well as light.

```cue
plugin: {
    id:     "nifty-links"
    name:   "Nifty Links"
    author: "x-ai"
    repo:   "x-ai/obsidian-nifty-links"

    html_url:    "https://community.obsidian.md/plugins/nifty-links"
    github_url:  "https://github.com/x-ai/obsidian-nifty-links"
```
