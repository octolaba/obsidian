# Tabula

Transforms Markdown files with spreadsheet-inspired formulas and cell references, running Tabula scripts over CSV blocks to compute and update table columns and rows. Scripts run automatically on save or manually from the command palette. Auto-execution and the visibility of row and column names can be toggled.
