# Owen Mermaid

Displays Mermaid SVG diagrams inline with a toolbar and a right-click menu offering zoom, full-screen pan-and-zoom and PNG or JPG export. A visual flowchart editor allows dragging nodes, creating and deleting connectors and editing text, writing the changes back into the original Mermaid code block.
