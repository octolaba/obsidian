# Easy Git

Synchronizes selected vault folders with GitHub repositories, public or private, by push, pull or bidirectional sync with a prompt on conflict. Several folder-to-repository mappings can exist at once, each with its own branch and remote path, and syncs run manually or on a schedule.

```cue
plugin: {
    id:     "easy-git"
    name:   "Easy Git"
    author: "Saiki77"
    repo:   "saiki77/Easy-Git"

    html_url:    "https://community.obsidian.md/plugins/easy-git"
    github_url:  "https://github.com/saiki77/Easy-Git"
    description: "A secure, plug-and-play way to sync individual vault folders or sections with GitHub. Private repos supported, multiple folder mappings, bidirectional sync, and conflict resolution. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync selected vault folders with GitHub repos (public or private) using push, pull, or bidirectional sync with prompt-on-conflict. Create multiple folder-to-repo mappings, choose branch and remote path per mapping, and run manual or scheduled syncs."
```
