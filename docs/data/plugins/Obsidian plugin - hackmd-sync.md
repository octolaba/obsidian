# HackMD Sync

Syncs notes between Obsidian and HackMD in both directions. Push and pull detect conflicts against the last sync and create a remote copy when none exists, while force push and force pull overwrite instead. The remote note URL can be copied, and the remote note deleted.

```cue
plugin: {
    id:     "hackmd-sync"
    name:   "HackMD Sync"
    author: "thor314"
    repo:   "thor314/hackmd-obsidian"

    html_url:    "https://community.obsidian.md/plugins/hackmd-sync"
    github_url:  "https://github.com/thor314/hackmd-obsidian"
    description: "Sync notes to from HackMD"
    about:       "Sync notes between Obsidian and HackMD. Push and pull contents with conflict detection based on last sync, create remote copies when needed, use force push/pull to overwrite, and copy or delete the remote note URL."
```
