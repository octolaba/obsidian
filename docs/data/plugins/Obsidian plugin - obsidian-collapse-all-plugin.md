# Collapse All

Collapse All extends the built-in collapse and expand actions with commands that can be bound to hotkeys. Collapse, expand and toggle commands exist for the file explorer, tag pane, search, bookmarks or all supported views, with search offering only expand and collapse and bookmarks only toggle.

```cue
plugin: {
    id:     "obsidian-collapse-all-plugin"
    name:   "Collapse All"
    author: "nathonius"
    repo:   "nathonius/obsidian-collapse-all"

    html_url:    "https://community.obsidian.md/plugins/obsidian-collapse-all-plugin"
    github_url:  "https://github.com/nathonius/obsidian-collapse-all"

    about:       "Bind collapse, expand, and toggle commands for File Explorer, Tag Pane, Search, Bookmarks, or all supported views to the command palette or hotkeys. Use view-specific behavior: Search offers only expand/collapse, Bookmarks offers only toggle."
```
