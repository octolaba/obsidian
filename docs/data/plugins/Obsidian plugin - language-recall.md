# Language Recall

Language Recall keeps Anki-style decks and cards inside the vault, rendering card content as Markdown with Obsidian links supported. Due cards are reviewed with Again, Hard, Good and Easy grading and estimated next-review times, and cards can be edited mid-review or moved between decks. Front-to-back translation is available in the editor without an API key.
