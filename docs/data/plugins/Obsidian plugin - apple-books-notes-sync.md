# Apple Books Notes Sync

Syncs Apple Books highlights, notes and PDF annotations into local Markdown notes in the vault. A companion command-line tool named absync reads the local Apple Books data and performs sync work outside the Obsidian interface. A managed Apple Books folder is created together with a Books.base view for browsing the synced notes, on macOS desktop only.
