# Office Reader

Opens .docx and .pptx files inside Obsidian as local read-only previews, leaving the originals unchanged. Word documents get searchable text, heading navigation, continuous zoom, image preview and copying as plain text or Markdown; presentations get slide thumbnails, deck-wide search, speaker notes, keyboard navigation, fit-to-window and fullscreen viewing. A linked Markdown summary note can be created for either format, and the source file can still be opened in the system's default Office application.
