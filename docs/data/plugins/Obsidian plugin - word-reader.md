# Office Reader

Opens .docx and .pptx files inside Obsidian as local read-only previews, leaving the original files unchanged. Word documents are shown with searchable text, heading navigation, continuous zoom, image preview and copying as plain text or Markdown. Presentations offer slide thumbnails, search across the whole deck, speaker notes, keyboard navigation, fit-to-window and fullscreen viewing. A linked Markdown summary note can be created for either format, or the source file handed to the system's default Office application.
