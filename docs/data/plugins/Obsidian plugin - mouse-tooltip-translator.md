# Mouse Tooltip Translator

Translates hovered or selected text into a tooltip carrying dictionary entries, parts of speech and romanization. Engines are assigned per trigger, the recorded text naming Google, DeepL, Bing and local or remote LLMs, and whole pages can be translated with reverse tooltips that reveal the original text. Lookups are saved to a sortable sidebar wordbook for later review.
