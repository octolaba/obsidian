# Crosspost Studio

Creates and updates drafts on WeChat Official Account, Zhihu, Juejin, CSDN, OSChina and CNBlogs from a single Obsidian Markdown source, saving drafts only and never publishing. Images, MathJax and Mermaid are converted into platform-compatible assets and deduplicated by SHA-256 hash. Syncing runs locally through a Chromium extension rather than through a cloud transfer.
