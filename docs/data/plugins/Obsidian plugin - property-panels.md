# Property Panels

Renders frontmatter properties as configurable panels inside the note's scrollable content, where they can be read and edited. Panels are built in a visual editor from common field types - text, number, date, select, multi-select and links - and laid out in responsive grids with icons. Which panel applies to a note is decided by folder, tag or wikilink rules.
