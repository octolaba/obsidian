# Wheel Tab Switcher

Switches tabs with the mouse wheel while the pointer hovers over the tab headers. Scrolling up moves to the previous tab and scrolling down to the next, wrapping around at the ends, and this works in all Obsidian windows.

```cue
plugin: {
    id:     "wheel-tab-switcher"
    name:   "Wheel Tab Switcher"
    author: "22-2"
    repo:   "22-2/wheel-tab-switcher"

    html_url:    "https://community.obsidian.md/plugins/wheel-tab-switcher"
    github_url:  "https://github.com/22-2/wheel-tab-switcher"
    description: "Switch between Tabs using your mouse wheel when hovering over tab headers"
    about:       "Switch tabs using the mouse wheel while hovering over tab headers. Scroll up to go to the previous tab and scroll down to go to the next; loop around at the ends and work in all Obsidian windows."

    stats: {
        downloads:  1997

}
```
