# Tag Tactician

Tag Tactician bulk-edits frontmatter tags across many notes, adding or removing tags, previewing the proposed changes, and applying updates only to the files chosen. It also lists related notes derived from tag, filename and link similarity, and shows the vault as a tag-based hierarchy in a Tag Navigation view. It operates on frontmatter tags only, so inline tags in note bodies are left unchanged.

    id:     "tag-tactician"
    name:   "Tag Tactician"
    author: "Scott Tomaszewski"
    repo:   "scotttomaszewski/obsidian-tag-tactician"

    html_url:    "https://community.obsidian.md/plugins/tag-tactician"
    github_url:  "https://github.com/scotttomaszewski/obsidian-tag-tactician"
    description: "Tag operations and helpers"
    about:       "Bulk-edit frontmatter tags across multiple notes by adding or removing tags, preview proposed changes, and selectively apply updates to chosen files. Display related notes determined by tag, filename, and link similarity, and visualize your vault in a tag-based hierarchy with Tag Navigation. Operate on frontmatter tags only; inline #tags in note bodies are not changed."
