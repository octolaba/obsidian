# Mermaid Flow

Edits Mermaid flowcharts visually by dragging nodes and drawing connections instead of writing Mermaid syntax. Manual layout is preserved in hidden comments inside the code block. The editor opens in an embedded pane or a modal from edit buttons in Live Preview and Reading mode.

```cue
plugin: {
    id:     "mermaid-flow"
    name:   "Mermaid Flow"
    author: "Mohammed Thanseer"
    repo:   "thansheer/obsidian-mermaid-flow"

    html_url:    "https://community.obsidian.md/plugins/mermaid-flow"
    github_url:  "https://github.com/thansheer/obsidian-mermaid-flow"
    description: "Create and edit Mermaid flowcharts visually by dragging nodes and drawing connections. No Mermaid syntax required. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Edit Mermaid flowcharts visually inside Obsidian with a WYSIWYG drag-and-drop editor. Drag nodes and draw connections without writing Mermaid code, preserve manual layouts via hidden comments, and work in an embedded pane or modal with Live Preview and Reading Mode edit buttons."

    stats: {
        downloads:  1683
        updated_at: 1785834892000
    }
}
```
