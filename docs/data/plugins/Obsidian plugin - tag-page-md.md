# Tag Page

Tag Page generates and updates Markdown pages dedicated to a single tag, consolidating that tag's references from across the vault. A page is seeded with a tag-page block so generated content and hand-written notes sit together, and tag content can also be rendered inline from a code block. Matching lines or bulleted sub-items can be included, nested tags scoped, and storage, sorting, titles, links and reference placement configured.

```cue
plugin: {
    id:     "tag-page-md"
    name:   "Tag Page"
    author: "mjsumpter"
    repo:   "mjsumpter/obsidian-tag-page"

    html_url:    "https://community.obsidian.md/plugins/tag-page-md"
    github_url:  "https://github.com/mjsumpter/obsidian-tag-page"
    description: "Dynamically generate and update tag-specific pages, offering a consolidated view of each tag's references across your vault."
```
