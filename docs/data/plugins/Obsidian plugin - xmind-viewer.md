# XMind Viewer

Renders .xmind files inside the vault, including maps embedded in Markdown notes. Opening a file shows a read-only XMind viewer, which needs an internet connection to work.

```cue
plugin: {
    id:     "xmind-viewer"
    name:   "XMind Viewer"
    author: "ssentiago"
    repo:   "ssentiago/obsidian-xmind-viewer"

    html_url:    "https://community.obsidian.md/plugins/xmind-viewer"
    github_url:  "https://github.com/ssentiago/obsidian-xmind-viewer"
    description: "Integrate viewing of your XMind files"
    about:       "View .xmind files directly inside your Obsidian vault, including embedded maps within Markdown notes. Open any .xmind file to render a read-only XMind viewer. Connect to the internet to use the viewer."

    stats: {
        downloads:  9150
```
