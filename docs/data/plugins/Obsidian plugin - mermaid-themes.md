# Mermaid Themes

Applies and customizes themes for mermaid.js diagrams in Obsidian. A full Mermaid theme object is supplied, or parts of one are overridden and merged into a base theme. Themed diagrams are rendered from a merm code fence rather than the standard one.

```cue
plugin: {
    id:     "mermaid-themes"
    name:   "Mermaid Themes"
    author: "jvsteiner"
    repo:   "jvsteiner/mermaid-themes"

    html_url:    "https://community.obsidian.md/plugins/mermaid-themes"
    github_url:  "https://github.com/jvsteiner/mermaid-themes"
    description: "Alternate support for mermaid.js that supports theming and customization."
    about:       "Apply and customize themes to mermaid.js diagrams in Obsidian. Supply a full mermaid theme object or override parts to merge with a base theme, and use the merm code fence to render themed diagrams."

    stats: {
        downloads:  16314
        updated_at: 1685644788000
    }
}
```
