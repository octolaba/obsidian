# Plaud Importer

Plaud Importer brings meeting recordings, AI summaries, transcripts and attachments from Plaud.AI into the vault as Markdown notes. Each recording becomes one note with frontmatter metadata, the Plaud-generated summary and a heading-based transcript with chapter navigation. A matching assets folder holds the images and other artifacts for that recording.

    id:     "plaud-importer"
    name:   "Plaud Importer"
    author: "Charles Kelsoe"
