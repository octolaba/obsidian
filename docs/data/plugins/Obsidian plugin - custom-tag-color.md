# Custom Tag Color

Assigns text colors to tags through regular-expression rules, together with background colors derived from them. Rules are ordered and the first match wins, so names, prefixes, numbers, dates, times and emojis can each be targeted. Rules are edited or reset from the settings panel, on desktop and on mobile.

```cue
plugin: {
    id:     "custom-tag-color"
    name:   "Custom Tag Color"
    author: "Anand Baghel"
    repo:   "anandrajbaghel/obsidian-custom-tag-color"

    html_url:    "https://community.obsidian.md/plugins/custom-tag-color"
    github_url:  "https://github.com/anandrajbaghel/obsidian-custom-tag-color"
    description: "Define custom text colors (and derived backgrounds) for tags based on regex patterns. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Assign custom colors to tags using regular-expression rules to match names, prefixes, numbers, dates, times, emojis, and more. Create ordered rules where the first match wins and auto-generate complementary background colors; edit or reset rules from the settings panel and use on desktop or mobile."

    }
}
```
