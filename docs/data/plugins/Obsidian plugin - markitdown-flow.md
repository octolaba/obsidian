# MarkItDown Flow

MarkItDown Flow converts PDFs, Word, Excel and PowerPoint documents, images, audio, ZIP archives and HTML into structured Markdown in the vault, using the Microsoft MarkItDown engine. Offline parsing is attempted first, and for complex or scanned files it falls back to vision models such as GPT-4o or Gemini and to Azure Document Intelligence. Files can be dragged into the editor or converted from a right-click on files and folders, entire folders can be converted in the background, and post-processing cleans OCR artifacts and repairs Markdown tables. Its recorded description is written in a promotional register.
