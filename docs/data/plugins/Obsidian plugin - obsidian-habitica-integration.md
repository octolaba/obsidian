# Habitica Sync

Shows a Habitica account inside Obsidian, with stats such as HP, XP and coins beside task lists that render Markdown and emoji. Tabs cover To-Dos, Dailies, Habits and Rewards. Tasks are checked off or unchecked, habit counters are adjusted, and task descriptions and subtasks can be viewed.
