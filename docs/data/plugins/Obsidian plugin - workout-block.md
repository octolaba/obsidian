# Workout Block

Defines custom workout types and records per-set data in code blocks stored as plain-text CSV or JSON. Derived metrics are built with guided builders or expressions, per-set training plans are flexible, and exercises mapped to muscles produce anatomical heatmaps.

    id:     "workout-block"
    name:   "Workout Block"
    author: "wanguliux"
    repo:   "wanguliux/workout-block"

    github_url:  "https://github.com/wanguliux/workout-block"
