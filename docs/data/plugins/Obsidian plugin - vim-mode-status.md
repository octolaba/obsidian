# Vim Mode Status

Vim Mode Status shows the current Vim mode in Obsidian's status bar in real time, covering Normal, Insert, Visual, Replace and Command. Each mode gets a customizable background color. Labels can be full words or shortened to a single letter to save status bar space.

```cue
plugin: {
    id:     "vim-mode-status"
    name:   "Vim Mode Status"
    author: "penyt"
    repo:   "penyt/vim-mode-status"

    html_url:    "https://community.obsidian.md/plugins/vim-mode-status"
    github_url:  "https://github.com/penyt/vim-mode-status"
    description: "Show Vim mode (Normal/Insert/Visual) in the status bar with colors. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display the current Vim mode (Normal, Insert, Visual, Replace, Command) in Obsidian's status bar in real time. Color-code modes with customizable background colors. Choose full or short labels (e.g., NORMAL or N) to save status bar space."

    stats: {
        downloads:  483
        updated_at: 1782059574000
    }
}
```
