# Share to Flomo

Selected text or a whole note is shared to Flomo or Catnote from commands and the editor menu. A selection is sent as a single entry, one entry per line, or one entry per paragraph. An API key for the target service has to be set first.

```cue
plugin: {
    id:     "obsidian-to-flomo"
    name:   "Share to Flomo"
    author: "kaminono"
    repo:   "kaminono/obsidian-to-flomo"

    html_url:    "https://community.obsidian.md/plugins/obsidian-to-flomo"
    github_url:  "https://github.com/kaminono/obsidian-to-flomo"
    description: "Quickly share content to Flomo."
    about:       "Share selected text or entire notes to Flomo or Catnote using commands and an editor menu. Send selections as a single entry, each line, or each paragraph. Set your Flomo or Catnote API key to enable sending."

    stats: {
        downloads:  5531
        updated_at: 1706923892000
    }
}
```
