# Syntactic Trees in Forest

Renders LaTeX forest-style syntactic trees inline as SVG, with node labels processed by MathJax so primes, superscripts, subscripts and inline math typeset correctly. Trees are written in bracket syntax with per-node options that propagate through for-tree and for-descendants, and support roof or triangle phrases, edge labels, and movement arrows drawn between named nodes.
