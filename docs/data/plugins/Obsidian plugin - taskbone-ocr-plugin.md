# Taskbone

Taskbone extracts text and equations from images and PDFs through built-in OCR so their content becomes searchable, applies templates to format the output, and inserts annotations or image content into notes. The recorded About text additionally describes bidirectional Todoist synchronization, automatic links between tasks and notes, and compatibility with the Tasks plugin, which the plugin description does not mention; both claims are recorded here rather than reconciled.
