# Chronotyper

Chronotyper tracks how long each note is edited and writes the edit timestamp and the total seconds into the note's properties. It runs continuously in the background, and folders can be excluded and the frontmatter property names customized.

```cue
plugin: {
    id:     "chronotyper"
    name:   "Chronotyper"
    author: "bambuscontrol"
    repo:   "bambuscontrol/obsidian-chronotyper"

    html_url:    "https://community.obsidian.md/plugins/chronotyper"
    github_url:  "https://github.com/bambuscontrol/obsidian-chronotyper"
    description: "Track how long you edit notes directly in the note properties"
    about:       "Track total time spent editing notes and write the edit timestamp and total seconds into each note's frontmatter. Run continuously in the background and support excluding folders and customizing frontmatter property names."

    stats: {
        downloads:  801
        updated_at: 1755719598000
    }
}
```
