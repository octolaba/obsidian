# Chew It

Chew It analyzes the note currently in view with an LLM and streams the Markdown result token by token into the sidebar, leaving the original file unmodified. Several perspectives, among them Outline, Key concepts and Distill as well as custom roles, run in parallel tabs and can be regenerated or exported to a Markdown note or to Canvas. It works with Claude from Anthropic and with any OpenAI-compatible endpoint, using a key supplied by the reader.

    id:     "chew-it"
    name:   "Chew It"
    author: "Jakob He"

    description: "Analyze the current note with an LLM in the sidebar — outline, key-concept explanations, and a distilled summary. Works with Claude (Anthropic) and any OpenAI-compatible API. - This plugin has not been manually reviewed by Obsidian staff."

Select perspectives (Outline, Key concepts, Distill or custom roles) to run in parallel tabs, then regenerate or export results to a Markdown note or Canvas; works with Claude and OpenAI-compatible endpoints—bring your API key."
