# Path in tab title

Shows folder names from the file path in the tab title, so the containing folders are visible instead of the file name alone. Only focused tabs are updated, after a short delay, and the recorded description states that tab titles revert to their defaults after Obsidian restarts.

```cue
plugin: {
    id:     "path-in-tab-title"
    name:   "Path in tab title"
    author: "d9k"
    repo:   "d9k/obsidian-path-in-tab-title"

    html_url:    "https://community.obsidian.md/plugins/path-in-tab-title"
    github_url:  "https://github.com/d9k/obsidian-path-in-tab-title"
    description: "Show folders names in the tabs titles. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display the file path in the active tab title so you see contextual folders instead of only the filename. Update only focused tabs with a short delay before refreshing; tab titles revert to defaults after restarting Obsidian."

    stats: {
        downloads:  149
        updated_at: 1776897018000
    }
}
```
