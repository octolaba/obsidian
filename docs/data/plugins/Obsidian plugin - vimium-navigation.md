# Vimium Navigation

Vimium Navigation drives Obsidian from the keyboard with Vim-style modal controls: Normal mode for interface actions, and i or a click to enter Insert mode. Compact hint overlays cover links, buttons, tabs and sidebar items. Notes can be searched and opened, scrolled and searched within, history and workspace tabs navigated, and obsidian:// links copied.

```cue
plugin: {
    id:     "vimium-navigation"
    name:   "Vimium Navigation"
    author: "Giuseppe"
    repo:   "giuseqpe/vimium-for-obsidian"

    html_url:    "https://community.obsidian.md/plugins/vimium-navigation"
    github_url:  "https://github.com/giuseqpe/vimium-for-obsidian"
    description: "Navigate notes, links, sidebars, and tabs with Vimium-style keyboard controls. - This plugin has not been manually reviewed by Obsidian staff."
```
