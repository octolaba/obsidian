# Collapsible Code Blocks

Collapsible Code Blocks makes code blocks collapsible in preview mode and adds a toggle for expanding and collapsing long snippets, along with horizontally scrollable blocks. The default collapse state, the number of visible lines, the icons and the scrolling behaviour are configurable, per-note state is controlled through frontmatter, and transitions are animated with the layout preserved.
