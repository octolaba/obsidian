# Wonderful Cards

Creates themed item cards for D&D in notes from itemcard YAML code blocks. Image, price, rarity and description are set per card, and items can be saved into a global catalog. A card is previewed inline through a wc reference to the item name, or by clicking an internal link.

```cue
plugin: {
    id:     "wonderful-cards"
    name:   "Wonderful Cards"
    author: "trikorka"
    repo:   "trikorka/wonderful-cards"

    html_url:    "https://community.obsidian.md/plugins/wonderful-cards"
    github_url:  "https://github.com/trikorka/wonderful-cards"
    description: "Создавайте и отображайте красивые карточки магических предметов для D&D (RU) - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create beautiful, themed D&D magic item cards in your notes using simple itemcard YAML code blocks. Customize images, price, rarity and descriptions, save items to a global catalog, and preview cards inline with wc:Item Name or by clicking internal links."

    stats: {
        downloads:  227
        updated_at: 1783452808000
    }
}
```
