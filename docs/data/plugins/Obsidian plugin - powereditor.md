# Power Editor

Edits Markdown in true WYSIWYG with a floating toolbar, an inline selection bubble, block drag handles, image-resize handles and dictation, while the file itself stays plain Markdown. The toolbar is cursor-aware and slash commands reflect the exact formatting at that position, and every action is also exposed as a command so other plugins keep working.

```cue
plugin: {
    id:     "powereditor"
    name:   "Power Editor"
    author: "Power Plugins"
    repo:   "obsidian-power-plugins/obsidian-power-editor"

    html_url:    "https://community.obsidian.md/plugins/powereditor"
    github_url:  "https://github.com/obsidian-power-plugins/obsidian-power-editor"
    description: "Format any note from a toolbar, selection bubble, or slash menu: WYSIWYG editing, block drag handles, image resizing, dictation, and AI edits, all staying plain Markdown. - This plugin has not been manually reviewed by Obsidian staff."

Use a cursor-aware toolbar and slash commands that reflect exact formatting and expose every action as a command to preserve plugin compatibility."
