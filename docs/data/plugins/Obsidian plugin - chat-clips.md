# Chat clips

Chat clips records a chat as an ordinary Markdown list in the editor and renders it in reading view as comment-style clips. List markers group clips into folders or pages, and the visual style is customized with CSS.

```cue
plugin: {
    id:     "chat-clips"
    name:   "Chat clips"
    author: "sleepingraven"
    repo:   "sleepingraven/obsidian-chat-clips"

    html_url:    "https://community.obsidian.md/plugins/chat-clips"
    github_url:  "https://github.com/sleepingraven/obsidian-chat-clips"
    description: "Record chat in ordinary markdown list."
    about:       "Record chats as simple Markdown lists in the editor and render them as comment-style chat clips in reading view. Group clips into folders or pages with list markers and customize the visual style with CSS."

    stats: {
        downloads:  506
        updated_at: 1745643487000
    }
}
```
