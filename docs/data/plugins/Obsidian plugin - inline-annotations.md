# Inline Annotations

Attaches a short note to selected text with a brace syntax, adding hidden context without creating a new file. Clicking or hovering the text reveals the annotation in a popup above it, which the recorded inputs suggest for TTRPG notes, study material and manuscripts.

```cue
plugin: {
    id:     "inline-annotations"
    name:   "Inline Annotations"
    author: "cetrodk"
    repo:   "cetrodk/obsidian-inline-annotations"

    html_url:    "https://community.obsidian.md/plugins/inline-annotations"
    github_url:  "https://github.com/cetrodk/obsidian-inline-annotations"
    description: "Add inline annotations to selected text that show in a popup on click. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add short notes inline using {text::note} syntax to attach hidden context without creating new files. Reveal annotations with a click or hover to show popups above text, ideal for TTRPG notes, study material, manuscripts, or any text needing inline commentary."

}
```
