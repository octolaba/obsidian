# Agent Client

Agent Client chats with AI agents such as Claude Code, Codex and Gemini CLI through the Agent Client Protocol, in a floating, collapsible chat window inside the vault. Notes are referenced by an at-mention of their name, images can be pasted, several agents and sessions run at once, models are switchable, terminal commands can be executed, and conversations are saved as Markdown.
