# Improved Random Note

Opens a random note directly, without the intermediate search term the recorded description says is otherwise needed. The note can be opened in a new panel, and the pool can be narrowed by excluding folders or limiting the draw to notes carrying a given tag.

```cue
plugin: {
    id:     "improved-random-note"
    name:   "Improved Random Note"
    author: "shockthunder"
    repo:   "shockthunder/improved-random-note"

    html_url:    "https://community.obsidian.md/plugins/improved-random-note"
    github_url:  "https://github.com/shockthunder/improved-random-note"
    description: "Improved interaction with the knowledge base in so-called wandering mode by opening specific Random Notes."
    about:       "Open a random note instantly without creating an intermediate search term. Launch it in a new panel and refine results by excluding folders or limiting to notes with a specific tag."

        downloads:  13230

}
```
