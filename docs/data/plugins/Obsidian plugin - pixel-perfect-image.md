# Pixel Perfect Image

Pixel Perfect Image adds right-click controls to images inside notes, showing the filename and dimensions and resizing to exact pixel values or preset percentages. File actions cover copying to the clipboard, renaming and revealing the file in Finder or Explorer, and images can be opened in system viewers. Resizing is also available from the mousewheel with awareness of the original dimensions, and both wikilinks and standard Markdown image links are handled.
