# Local Sidekick

Opens an agent chat in a right-hand sidebar backed by local Ollama and Pi models. Sessions persist, vault files are referenced with @mentions, Markdown and math are rendered, and @search and @semantic query the notes for vault-aware context with what the recorded text calls conservative file linking.
