# Auto Card Link

Fetches metadata from a URL and writes it as a card-styled link inside a YAML code block, so the note itself stays free of HTML. Pasted or selected URLs are converted into card links, local images can be included through Obsidian internal links, and the card appearance comes from separate CSS snippets.

```cue
plugin: {
    id:     "auto-card-link"
    name:   "Auto Card Link"
    author: "nekoshita"
    repo:   "nekoshita/obsidian-auto-card-link"

    html_url:    "https://community.obsidian.md/plugins/auto-card-link"
    github_url:  "https://github.com/nekoshita/obsidian-auto-card-link"
    description: "Automatically fetches metadata from a URL and makes it as a card-styled link."
    about:       "Fetch metadata from URLs and generate Markdown-safe, card-styled links as YAML code blocks so notes stay free of HTML. Convert pasted or selected URLs into card links, include local images via Obsidian internal links, and style cards with separate CSS snippets."

    stats: {
        downloads:  76396
        updated_at: 1708757240000
    }
}
```
