# Linked Note Exporter

Exports a note together with its attachments and its linked notes into a single folder or ZIP for sharing. Both wikilinks and Markdown links are followed to a selectable link depth, and the recorded inputs describe preserving the folder structure or organizing linked notes by headers, with backlinks included for context.

    id:     "linked-note-exporter"
