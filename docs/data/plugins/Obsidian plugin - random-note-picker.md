# Random Note Picker

Opens a random note from the whole vault, from a recent time range of 24 hours or 7, 14, 30 or 365 days, or from up to three configured folders. Each scope has its own quick command, so a random note within it can be opened directly from the command palette.

```cue
plugin: {
    id:     "random-note-picker"
    name:   "Random Note Picker"
    author: "tai"
    repo:   "taisukemino/random-note-obsidian"

    html_url:    "https://community.obsidian.md/plugins/random-note-picker"
    github_url:  "https://github.com/taisukemino/random-note-obsidian"
    description: "Open random notes from your vault, specific time periods, or custom directories. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open a random note from your entire vault, from recent time ranges (24h, 7d, 14d, 30d, 365d), or from up to three configured folders. Use quick commands to instantly jump to a random note within the chosen scope."

    stats: {
        downloads:  41
        updated_at: 1785609175000
    }
}
```
