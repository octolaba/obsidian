# YouTube Template

Creates a note from a YouTube URL through a configurable template, formatting chapters and hashtags to preference. A Google Cloud API key lets the plugin query the YouTube Data API for video details and chapters.

```cue
plugin: {
    id:     "youtube-template"
    name:   "YouTube Template"
    author: "sundevista"
    repo:   "sundevista/youtube-template"

    html_url:    "https://community.obsidian.md/plugins/youtube-template"
    github_url:  "https://github.com/sundevista/youtube-template"
    description: "Fetch YouTube video data into your vault."
    about:       "Create a note from a YouTube URL using a configurable template and format chapters and hashtags to your preference. Provide a Google Cloud API key to let the plugin query the YouTube Data API for video details and chapters."

    stats: {
        downloads:  8558
        updated_at: 1747482011000
    }
}
```
