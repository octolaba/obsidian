# Zotero Lib View

Zotero Lib View browses and manages a Zotero library inside Obsidian through a dedicated table-style Library View that reads Better BibTeX JSON. Literature notes are opened or created from a citation key, the view syncs automatically when the JSON updates, and it can be pinned as a tab or in a sidebar.
