# Hugo Publish

Hugo Publish converts notes and their linked images into Hugo-ready Markdown, rewriting internal links and image embeds as standard Markdown and static URLs. Front matter fields for title, date and lastmod are written automatically, and the converted files are synced into the Hugo site directory.

```cue
plugin: {
    id:     "hugo-publish"
    name:   "Hugo Publish"
    author: "kirito41dd"
    repo:   "kirito41dd/obsidian-hugo-publish"

    html_url:    "https://community.obsidian.md/plugins/hugo-publish"
    github_url:  "https://github.com/kirito41dd/obsidian-hugo-publish"
    description: "Publish your blog to hugo site."
    about:       "Convert Obsidian notes and linked images into Hugo-ready Markdown, translating internal links and image embeds into standard Markdown and static URLs. Auto-write front matter (title, date, lastmod) and sync converted files to your Hugo site directory for publishing."

    stats: {
        downloads:  3075
        updated_at: 1776087076000
    }
}
```
