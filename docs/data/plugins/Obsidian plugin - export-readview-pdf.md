# export-readview-pdf

Exports the active Reading view to PDF through the native Chromium print engine, keeping the rendered layout and theme as displayed. Second-pass plugin renderings from Dataview, Excalidraw, Mermaid and canvases are captured, images and canvases are inlined, and styles including Shadow DOM are collected. Output paths are flexible, with page-size and layout options.
