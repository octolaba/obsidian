# TimeMeter

TimeMeter records app activity and session notes into daily Markdown logs named by date under a TimeMeter folder. On macOS it tracks the frontmost app and its window title automatically and detects AFK periods, and one-line memos can be added by hand. All data stays local in the vault; automatic tracking is macOS desktop only, while mobile supports viewing and manual logging.
