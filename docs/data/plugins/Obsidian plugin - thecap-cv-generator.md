# Thecap cv generator

Thecap cv generator produces a PDF curriculum vitae from Markdown held in the vault. Resume sections are written and edited in the plugin's structured Markdown notation, and the previewed PDF matches the formatting of the web version.

```cue
plugin: {
    id:     "thecap-cv-generator"
    name:   "Thecap cv generator"
    author: "xthecapx"
    repo:   "xthecapx/Thecap-cv-generator"

    html_url:    "https://community.obsidian.md/plugins/thecap-cv-generator"
    github_url:  "https://github.com/xthecapx/Thecap-cv-generator"
    description: "Generate PDF curriculum from your notes."
    about:       "Generate a PDF CV directly from Markdown in your Obsidian vault. Create and edit resume sections using the plugin's structured Markdown notation and preview a PDF that matches the web version's formatting."

        downloads:  1095
```
