# Snippets Catcher

CSS snippets are downloaded from a GitHub repository and managed inside Obsidian instead of in the file system. Downloaded snippets are activated in the Appearance settings, and the source can be pointed at a custom repository to use or contribute another collection.

```cue
plugin: {
    id:     "snippets-catcher"
    name:   "Snippets Catcher"
    author: "opa-oz"
    repo:   "opa-oz/obsidian-snippets-plugin"

    html_url:    "https://community.obsidian.md/plugins/snippets-catcher"
    github_url:  "https://github.com/opa-oz/obsidian-snippets-plugin"
    description: "Manage CSS snippets within your vault. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Download and manage CSS snippets from a GitHub repository directly inside Obsidian. Activate downloaded snippets in Appearance and switch to a custom repo to use or contribute your own collection."

    stats: {
        downloads:  130
        updated_at: 1779869579000
    }
}
```
