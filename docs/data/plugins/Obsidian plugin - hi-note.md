# HiNote

HiNote extracts highlighted text into sidebar cards automatically. Comments are added by hand or generated by AI, highlights can be conversed with, and knowledge-card images or linked notes are produced from them. The recorded About lists support for == markup, mark and span tags and custom regular expressions, and states that FSRS spaced repetition is available in a Pro tier.
