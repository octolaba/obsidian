# Tengwar

Tengwar renders Elvish script from fenced blocks tagged teng, or teng-fontname to pick a font for a note, with support for the ISO-8859-1 and ConScript Unicode Registry encodings. It can be combined with spaced-repetition plugins to study Elvish. Editing-mode rendering and some Apple font rendering are recorded as work in progress.
