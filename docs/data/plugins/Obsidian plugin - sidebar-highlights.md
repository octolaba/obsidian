# Sidebar Highlights

Sidebar Highlights collects text highlights, comments on highlights, native comments and tasks from across the vault into one sidebar, with color-coded highlights and highlight collections. Search and filtering use logical operators and tag autocomplete, detected tasks carry natural-language dates and contextual grouping, and edits appear in real time with one click back to the source.
