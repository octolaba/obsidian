# Companion MCP

Companion MCP exposes vault-wide semantic search and real-time editor context to AI agents over the Model Context Protocol, with multilingual search across Japanese, English and more than a hundred other languages. Embeddings and indexes stay local, and the server also offers precise Markdown CRUD, frontmatter management and machine-readable edit handoffs for agent workflows.
