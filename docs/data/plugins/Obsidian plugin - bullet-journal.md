# Bullet Journal

Cycles Bullet Journal symbols on a line to mark it as a task, completed, migrated, scheduled, a note or an event, and toggles priority, inspiration and explore signifiers that are highlighted in reading view. Daily, monthly and future logs can be opened or created, and unfinished tasks migrated between logs or scheduled into a future month. An index can be generated that links all journal entries.

```cue
plugin: {
    id:     "bullet-journal"
    name:   "Bullet Journal"
    author: "カク スエイ"
    repo:   "asinkluno/bullet-journal"

    html_url:    "https://community.obsidian.md/plugins/bullet-journal"
    github_url:  "https://github.com/asinkluno/bullet-journal"
    description: "Add and cycle Bullet Journal symbols in Markdown notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Cycle Bullet Journal symbols on lines to mark items as task, completed, migrated, scheduled, note, or event, and toggle priority/inspiration/explore signifiers highlighted in reading view. Open or create daily, monthly, and future logs, migrate unfinished tasks between logs or schedule them into future months, and generate an index linking all journal entries."

    stats: {
        downloads:  40
        updated_at: 1785602910000
    }
}
```
