# Note Toolbar

Adds customizable toolbars to notes that run commands, open files or URLs, show menus, or execute Dataview, Templater or JavaScript snippets, with the toolbar chosen by context. Toolbars can sit at the top or bottom of a note, in the tab bar, as floating buttons or in callouts, and can appear on text selection. An API is included for showing interface components.
