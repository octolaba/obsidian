# Zotero Sync

Zotero Sync mirrors a Zotero library as Markdown files in Obsidian through the Zotero web API with an API key, or through a local Zotero connection. The copy is read-only and incrementally cached, so it can be linked and searched without modifying the Zotero library itself. Generated files sync to mobile like any other vault content.
