# Skeletal

Skeletal provides a searchable library of 47 configurable Markdown templates arranged by category, with favorites and recent items. Template fields are customizable and the output can be previewed raw or rendered before being inserted at the cursor or copied. It also maintains managed task progress bars that recalculate from checkbox changes without rewriting the rest of the note.
