# Mantle Docs

Provides a read-only viewer for code and data files kept in the vault, such as JSON, TypeScript, CSV, CSS and YAML, with syntax highlighting and without editor-keystroke lag or accidental edits. The view is virtualised so large files and codebases stay smooth, and controls toggle line numbers, wrap text and copy snippets in one click. The recorded text says its code-block formatting is taken from the Zenith theme.
