# Ignore

Ignore hides files and folders listed in an obsidianignore file written in standard gitignore syntax. Matching items are excluded from the File Explorer, Quick Switcher, Search, Graph and backlinks, and manually added excluded entries are preserved and restored.

```cue
plugin: {
    id:     "ignore"
    name:   "Ignore"
    author: "devxoul"
    repo:   "devxoul/obsidian-ignore"

    html_url:    "https://community.obsidian.md/plugins/ignore"
    github_url:  "https://github.com/devxoul/obsidian-ignore"
    description: "Hide files matching .obsidianignore (gitignore syntax) from the Obsidian UI. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Hide files and folders using a .obsidianignore file with standard gitignore syntax. Exclude matching items from the File Explorer, Quick Switcher, Search, Graph, and backlinks while preserving and restoring any manually added excluded entries."

}
```
