# Uncheck All

Unchecks every checkbox in the current note with a single command. The line text is left intact and only the checkbox marks are cleared.

plugin: {
    id:     "uncheck-all"
    name:   "Uncheck All"
    author: "shacharharshuv"
    repo:   "shacharharshuv/obsidian-uncheck-all"

    html_url:    "https://community.obsidian.md/plugins/uncheck-all"
    github_url:  "https://github.com/shacharharshuv/obsidian-uncheck-all"
    description: "Uncheck all checkboxes in the current note using one command."
