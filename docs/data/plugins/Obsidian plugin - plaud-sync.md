# Plaud Sync

Plaud Sync pulls Plaud voice recordings into Markdown notes carrying titles, dates, durations, AI summaries, key highlights and full transcripts with speaker labels. Updates are incremental and idempotent, with secure token storage, automatic retries, trash filtering and content hydration. The recorded About text states that the plugin uses a reverse-engineered Plaud API and may break without notice.
