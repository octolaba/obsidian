# File Tree Selector Hue Rotate

Draws an animated color-rotating border overlay around hovered or active items in the file tree. The overlay is rendered on a separate layout plane so it is not clipped by overflow, and the sequential border-color frames run as hardware-accelerated CSS keyframe animations.
