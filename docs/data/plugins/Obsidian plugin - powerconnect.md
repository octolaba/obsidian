# Power Connect

Syncs a vault two-way with the owner's own Dropbox, selectively and across platforms, without third-party servers or a subscription. A sync can be previewed first, only deltas are transferred, identical files are paired by content, conflicting edits are preserved as separate versions, and everything can optionally be encrypted end-to-end.
