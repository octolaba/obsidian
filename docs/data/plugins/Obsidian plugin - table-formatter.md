# Table Formatter

Formats Markdown tables when a file is saved, giving consistent alignment and spacing. Cell padding is either fixed or a single automatic space, and the number of delimiter dashes is automatic or fixed, which together control table width and appearance.

```cue
plugin: {
    id:     "table-formatter"
    name:   "Table Formatter"
    author: "fangface-hub"
    repo:   "fangface-hub/obsidian_table_formatter"

    html_url:    "https://community.obsidian.md/plugins/table-formatter"
    github_url:  "https://github.com/fangface-hub/obsidian_table_formatter"
    description: "Formats Markdown tables when files are saved. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Format Markdown tables on save to ensure consistent alignment and spacing. Configure cell padding (fixed or automatic single-space) and set delimiter dash count (automatic or fixed) to control table width and appearance."

    stats: {
        downloads:  434
        updated_at: 1786150181000
    }
}
```
