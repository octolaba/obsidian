# Visual Flashcards

Provides a visual flashcard system in which cards flip in 3D and answers are revealed by tapping. Performance is tracked with Got it and Missed it scoring, an end screen of results, and a per-note session history, missed cards can be retried immediately, decks can be shuffled, and any note in the vault can be used as a deck.
