# Nightly Journal

Nightly Journal interviews you at the end of the day with a local model run through Ollama and writes the daily note from your answers, capturing mood, energy, a summary, wins, to-dos and wikilinked person and project notes once the writing plan is confirmed. It also builds a local embeddings memory over past notes and attachments that can be queried, answering with dated citations, and offers optional local voice input and output. The recorded description states that it runs entirely locally.
