# Meetings Plus

Subscribes to ICS calendar feeds and lists the day's meetings in a sidebar, sorted by time. A meeting note can be created in one click, pre-filled with attendees, time, location and agenda, while an existing note is opened rather than duplicated. Optional pre-meeting reminders, daily-note insertion and Templater support are included, and ICS feeds are fetched directly over HTTPS.
