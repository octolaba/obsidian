# CSV Flashcards

Quizzes from standard two-column CSV files in a distraction-free interface, including decks exported from NotebookLM. Cards can be edited inline and given optional hints, decks can be shuffled, and missed or skipped cards are reviewed again automatically. Spaced repetition is deliberately left out.
