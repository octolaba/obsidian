# Comic Scripter

Comic Scripter scripts comics with a Markdown-like syntax that marks Pages, Panels and Dialogue. Pages and panels are numbered automatically, character names and dialogue are formatted, and page separators and left or right page handedness can be toggled for print or manga layouts.

```cue
plugin: {
    id:     "comic-scripter"
    name:   "Comic Scripter"
    author: "Victoria Douglas"
    repo:   "victoriadouglas/Comic-Scripter-Obsidian"

    html_url:    "https://community.obsidian.md/plugins/comic-scripter"
    github_url:  "https://github.com/victoriadouglas/Comic-Scripter-Obsidian"
    description: "Automatic Page and Panel Numbering for Comic Scripting. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Script comics with Markdown-like syntax that marks Pages, Panels, and Dialogue for easy reading. Auto-number pages and panels, format character names and dialogue, and toggle page separators and left/right page handedness for print or manga layouts."

    stats: {
        downloads:  301

    }
}
```
