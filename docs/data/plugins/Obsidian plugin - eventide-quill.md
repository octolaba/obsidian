# Eventide Quill

A writing assistant aimed at novelists that combines deterministic lints with AI editorial feedback, in-place rewrites and strict style constraints. Characters, locations and plot points are extracted automatically into manuscript intelligence, supported by lorebook coaching and pacing and dialogue analytics. It is built to run against a local model first.
