# Yuhanbo Voice Assistant

Records microphone audio and transcribes it with iFlytek online speech recognition, or dictates straight into the active note, and reads selected text or the current note aloud with iFlytek text-to-speech. Configurable wake words start voice workflows, and recognized text can be sent to Google Gemini, OpenRouter or iFlytek Spark for optional AI conversation. Audio files and chat output are saved into the vault.
