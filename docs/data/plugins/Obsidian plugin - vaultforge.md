# VaultForge

Runs a local MCP server bound to 127.0.0.1 that gives Claude Code and Claude Desktop live read, write and search access to the vault without a separate REST API or bridge. An in-app chat sidebar authenticates through an existing Claude login, so conversations run on that subscription. Claude Skills are managed locally as well.
