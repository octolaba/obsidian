# Notion block

Adds Notion-style block interactions to Live Preview. Gutter handles convert a line into a heading, list, code block, math block, callout, divider or quote, and a plus menu quick-inserts tables, footnotes and frontmatter. Long-pressing a handle drags and reorders blocks and toggles between line and paragraph modes.
