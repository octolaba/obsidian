# Khiip

Captures web content into the vault as Markdown and recalls it semantically across everything kept. A pasted URL from sources such as X, Reddit, YouTube, Wikipedia or the wider web is fetched by a local Khiip daemon, which extracts a typed note and files it into per-source folders. From the sidebar or command palette you can capture URLs, run semantic recall, check daemon status and recent captures, and open, re-capture or copy a captured link. The daemon is free and open source, runs locally on desktop only, and an optional paid Plus tier adds platform-styled rendering and deeper per-source extraction.
