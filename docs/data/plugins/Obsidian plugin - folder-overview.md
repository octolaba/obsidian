# Folder overview

Renders a code block giving a dynamic overview of the vault or of selected folders and reflecting their contents. It is the standalone form of the folder overview feature of the Folder Notes plugin and cannot run alongside that plugin.

```cue
plugin: {
    id:     "folder-overview"
    name:   "Folder overview"
    author: "lostpaul"
    repo:   "lostpaul/obsidian-folder-overview"

    html_url:    "https://community.obsidian.md/plugins/folder-overview"
    github_url:  "https://github.com/lostpaul/obsidian-folder-overview"
    description: "Provides a dynamic overview of your vault or folders in the format of a codeblock."
    about:       "Display a dynamic code-block overview of your vault or selected folders that reflects folder contents. Use as a standalone alternative to the Folder Notes folder-overview feature; cannot run alongside the Folder Notes plugin."

    stats: {
        downloads:  2662
        updated_at: 1764446520000
    }
}
```
