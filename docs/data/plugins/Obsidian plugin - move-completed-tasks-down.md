# Move Completed Tasks Down

Moves a completed task to the end of its sibling list five seconds after it is checked, carrying any nested sub-items with it. Unchecking before the timer expires cancels the pending move. Incomplete items, tasks inside code blocks and sibling order stay intact, and the recorded text names Source, Live Preview, Reading and mobile as covered.
