# Browser Note

Runs a localhost HTTP API, protected by an API key, through which vault notes can be viewed, created, edited and deleted. Images, PDFs and other binary assets are served over the same interface, and Obsidian wiki-link targets are resolved precisely. A built-in browser UI uses the API to browse and edit notes, including journals.
