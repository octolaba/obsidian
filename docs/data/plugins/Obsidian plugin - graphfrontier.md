# GraphFrontier

Provides an independent physics-driven graph view meant to stay smooth on large vaults. Node positions can be pinned and saved, linked nodes arranged into orbits, and links painted or hidden for clarity. Right-click actions select or copy linked nodes and paths, alongside pin modes, strong pull and physics controls.
