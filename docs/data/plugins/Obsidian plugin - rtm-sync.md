# RTM Sync

RTM Sync exchanges tasks between Obsidian and Remember The Milk, downloading, adding and completing items while preserving due dates, priorities, tags and stable RTM ID links in the notes. Which tasks are imported is chosen through a popup or an RTM search query, RTM lists and tags become Obsidian hashtags, and new tasks can be written with RTM Smart Add syntax.

```cue
plugin: {
    id:     "rtm-sync"
    name:   "RTM Sync"
    author: "Ishigami_D"
    repo:   "kissyjpf/rtm-sync"

    html_url:    "https://community.obsidian.md/plugins/rtm-sync"
    github_url:  "https://github.com/kissyjpf/rtm-sync"
    description: "Sync Remember The Milk Task. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync tasks between Obsidian and Remember The Milk by downloading, adding, and completing items while preserving due dates, priorities, tags and stable RTM ID links in your notes. Select exactly which tasks to import with a popup or RTM search queries, convert RTM lists and tags into Obsidian hashtags, and add tasks using RTM Smart Add syntax."
```
