# Bracket to Checkbox

Typing an empty bracket pair followed by a space at the start of a line turns it into a Markdown checkbox. It works inside bullets and indented lines, preserving the existing list marker and indentation, and ignores bracket pairs typed in the middle of a line.

```cue
plugin: {
    id:     "bracket-to-checkbox"
    name:   "Bracket to Checkbox"
    author: "jihan"
    repo:   "2jihan/bracket-to-checkbox"

    html_url:    "https://community.obsidian.md/plugins/bracket-to-checkbox"
    github_url:  "https://github.com/2jihan/bracket-to-checkbox"
    description: "Type [ ] then space to turn it into a Markdown checkbox (- [ ] ). - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert a leading [] followed by a space into a Markdown checkbox (- [ ]) when typed at the start of any line, including inside bullets or indents. Preserve existing list markers and indentation and ignore [] typed in the middle of a line."

    stats: {
        downloads:  80
        updated_at: 1782721017000
    }
}
```
