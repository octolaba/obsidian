# Send to Ghost

Send to Ghost pushes the current note to a Ghost blog as a published post or as a draft, from the ribbon or the command palette. Authentication uses either a Staff Access Token or an Admin API Key.

```cue
plugin: {
    id:     "send-to-ghost"
    name:   "Send to Ghost"
    author: "southpaw1496"
    repo:   "southpaw1496/obsidian-send-to-ghost"

    html_url:    "https://community.obsidian.md/plugins/send-to-ghost"
    github_url:  "https://github.com/southpaw1496/obsidian-send-to-ghost"
```
