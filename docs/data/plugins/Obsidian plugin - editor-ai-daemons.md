# AI Editors

Summons configurable AI editors and panels that review the open note inline, highlight precise findings, argue with the text and propose surgical edits to accept or reject. Actions and questions are run as anchored findings, and a compatible backend of the reader's own choosing is used. It is desktop-only, and nothing is written into a note without confirmation.
