# Highlightr Plus

Highlightr Plus adds colour-coded highlights and inline tag annotations from a compact menu that follows light and dark modes. Marks are managed from the context menu, where a colour can be changed, a highlight removed, or an annotation added, edited or erased. Inline CSS is preserved so that exports remain self-contained.
