# Kings CalcLaTeX

Evaluates LaTeX expressions written with trigger suffixes and shows the result or an interactive 2D graph inline, running in the browser with no backend. A symbolic CAS handles differentiation, integration, solving and factoring, and an optional Giac WASM module adds limits, Taylor series and step-by-step solutions. LaTeX inside Excalidraw drawings is rendered automatically as images.
