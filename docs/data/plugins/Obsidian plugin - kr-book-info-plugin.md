# Korean Book Info

Crawls Yes24 for book information and writes it into a note's front matter. The imported fields cover title, author, publish date, cover URL, page count, tags, status, rating and reading dates. The front matter is inserted above the existing content, and the note title and content are updated.

    id:     "kr-book-info-plugin"
    name:   "Korean Book Info"
    author: "kmsk99"

    html_url:    "https://community.obsidian.md/plugins/kr-book-info-plugin"
