# Understory

A local-first knowledge layer that surfaces related notes, flags stale knowledge and offers a map of the vault to an agent when one is used. Its recorded material covers relationship discovery, entity-relationship facts, graph analysis and optional model-powered insights. The same text frames the wider project as a memory-maintenance layer for agents working across long horizons, of which this plugin is one version.
