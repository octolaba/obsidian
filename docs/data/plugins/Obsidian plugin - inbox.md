# Inbox

Shows an in-app notification on startup when there is data to process in the inbox note. A single file or a whole folder can be tracked, and the comparison runs against the last snapshot or a defined base so that unchanged content raises no alert.

```cue
plugin: {
    id:     "inbox"
    name:   "Inbox"
    author: "zachatoo"
    repo:   "zachatoo/obsidian-inbox"

    html_url:    "https://community.obsidian.md/plugins/inbox"
    github_url:  "https://github.com/zachatoo/obsidian-inbox"
    description: "Show in app notification on startup if there is data to process in the \"inbox\" note."
    about:       "Notify on vault launch when new content appears in your inbox note or folder. Track a single file or a folder and compare against the last snapshot or a defined base to avoid false alerts."

    stats: {
        downloads:  6595
        updated_at: 1709701580000
    }
}
```
