# Ownly

Tracks objects, subscriptions and experience costs in the vault as plain Markdown, using lifecycle statuses and structured reviews. Recorded functions include net worth snapshots, analysis of recurring and acquisition costs, archiving and restoring items, travel mapping and local diagnostics, with the data kept fully local.
