# Move Active Folder

Moves the folder that contains the currently active file. A parent folder is chosen as the scope and a destination picked, and built-in checks block moving a folder into itself or one of its subfolders and detect duplicate folder names.

```cue
plugin: {
    id:     "move-active-folder"
    name:   "Move Active Folder"
    author: "jinmugo"
    repo:   "jinmugo/obsidian-move-active-folder"

    html_url:    "https://community.obsidian.md/plugins/move-active-folder"
    github_url:  "https://github.com/jinmugo/obsidian-move-active-folder"
    description: "Move the folder containing the currently active file. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Move the folder containing the active file. Choose any parent folder as the scope and pick a destination, with built-in checks that block moving a folder into itself or its subfolders and detect duplicate folder names."
```
