# ReverySky 3D Graph

ReverySky 3D Graph renders a vault as an interactive 3D graph built with the Unity engine, generated from notes, links, tags, dates and file metadata. The view pans, zooms and rotates, notes open directly from the graph, and the node for the active note can be focused automatically. Filters by path, tag or date combine into a single query, and links can be displayed with or without tag nodes. The recorded text lists Dynamic Links, Scalable Links and Dates layouts, plus detailed and simplified rendering modes for graphs of different sizes.
