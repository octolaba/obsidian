# Spellcheck Toggler

Spellchecking is switched off for chosen block types in the editing view — external and internal links, HTML comments, block quotes, emphasis and strong text — so their underlines stop distracting. Each option is set globally or overridden per file from frontmatter, with always, frontmatter and never behaviours.

```cue
plugin: {
    id:     "spellcheck-toggler"
    name:   "Spellcheck Toggler"
    author: "julzerinos"
    repo:   "julzerinos/spellcheck-toggler-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/spellcheck-toggler"
    github_url:  "https://github.com/julzerinos/spellcheck-toggler-obsidian-plugin"
    description: "Toggle spellchecking for types of text blocks in the editing view."
    about:       "Toggle spellcheck for specific block types (external/internal links, HTML comments, block quotes, emphasis/italic, strong/bold) to remove distracting red underlines in edit view. Control each option globally or per-file via frontmatter overrides and choose always/frontmatter/never behaviors."

    stats: {
        downloads:  6847
        updated_at: 1772377439000
    }
}
```
