# Hatena Blog Publisher

Hatena Blog Publisher posts notes from Obsidian directly to Hatena Blog once the blog's API key and root endpoint are supplied and Hatena is set to Markdown editing mode. Notes are published as live entries or drafts, published articles can be deleted, and a Hatena-only table of contents can be inserted. Text wrapped in %% stays an Obsidian-only comment and is not published.

```cue
plugin: {
    id:     "hatena"
    name:   "Hatena Blog Publisher"
    author: "takmatsukawa"
    repo:   "takmatsukawa/obsidian-hatena"

    html_url:    "https://community.obsidian.md/plugins/hatena"
    github_url:  "https://github.com/takmatsukawa/obsidian-hatena"
    description: "Post directly to your Hatena Blog."
    about:       "Publish notes from Obsidian directly to Hatena Blog; provide your blog's API key, root endpoint, and set Hatena to Markdown editing mode. Post notes as live entries or drafts, delete published articles, and insert a Hatena-only table of contents. Add Obsidian-only comments by wrapping text with %% so they won't be published."

    stats: {
        downloads:  1505
        updated_at: 1749162952000
    }
}
```
