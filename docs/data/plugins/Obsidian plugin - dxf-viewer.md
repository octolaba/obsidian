# DXF Viewer

Opens DXF drawings in a dedicated view and embeds them inline in notes for rendering in reading mode. Drawings can be panned and zoomed, and measurement covers vertex distances, curve centers and circle or arc diameters, with automatic unit detection and a manual override.
