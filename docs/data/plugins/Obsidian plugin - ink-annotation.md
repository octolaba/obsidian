# Ink-Annotation

Adds handwriting over Markdown notes and PDFs on an overlay that leaves the source files unchanged, offering pen, highlighter and eraser tools with color and width settings plus undo, redo, save and exit. PDF text selection is page-aware and supports highlight, underline, strikethrough and note annotations. Drawing works with a pen or a mouse while finger touches pan the view, the toolbar can be moved, and annotations are stored offline.
