# Auto Paste Link

Auto Paste Link formats a single pasted URL as a Markdown link, an image embed or a video embed. Titles are filled in automatically for supported sites such as YouTube and Bilibili, selected text becomes the link text, and the cursor stays inside the brackets for immediate editing.

```cue
plugin: {
    id:     "auto-paste-link"
    name:   "Auto Paste Link"
    author: "cnwenzhihong"
    repo:   "cnwenzhihong/Obsidian-auto-paste-link"

    html_url:    "https://community.obsidian.md/plugins/auto-paste-link"
    github_url:  "https://github.com/cnwenzhihong/Obsidian-auto-paste-link"
    description: "Auto formats pasted URLs as Markdown links, media embeds, and supported site titles. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Format a single pasted URL into a Markdown link, image embed, or video embed. Auto-fill titles for supported sites like YouTube and Bilibili. Use selected text as link text and keep the cursor inside [] for immediate editing."

    stats: {
        downloads:  257
        updated_at: 1781468914000
    }
}
```
