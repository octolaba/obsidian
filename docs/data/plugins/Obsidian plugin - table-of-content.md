# Table of Content

Inserts a nested, clickable table of contents at the top of the active note, built from its headings. The maximum heading depth is configurable, running it again updates the existing table in place, and headings inside fenced code blocks are ignored.

```cue
plugin: {
    id:     "table-of-content"
    name:   "Table of Content"
    author: "secum3r"
    repo:   "secum3r/table-of-content"

    html_url:    "https://community.obsidian.md/plugins/table-of-content"
    github_url:  "https://github.com/secum3r/table-of-content"
    description: "Inserts a clickable table of contents at the top of the note, with a configurable maximum heading depth. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Insert a nested, clickable table of contents at the top of the active note built from its headings. Configure maximum heading depth, update the TOC in place when rerun, and ignore headings inside fenced code blocks."

    stats: {
        downloads:  166
        updated_at: 1782822632000
    }
}
```
