# GenWiki

Builds an incremental personal knowledge base from web clippings by merging findings into wikilinked notes and archiving the sources. Questions are asked in a conversational sidebar that answers with wikilinked citations, syntheses are saved as wiki pages, and an audit reveals contradictions and gaps. The recorded description names LLMs as the mechanism behind this.
