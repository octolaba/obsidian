# JSON Editor

JSON Editor opens json files with a toggle between a structural tree editor and a syntax-highlighted source view, and renders JSON code blocks in notes as collapsible, theme-aware trees. Entries can be added, renamed, deleted, reordered and switched between types, with unified undo and redo. JSON Schema validation is opt-in, and the controls are touch-friendly on mobile.
