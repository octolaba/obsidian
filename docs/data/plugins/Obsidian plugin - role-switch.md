# Role Switch

Role Switch moves between custom work roles such as developer, writer or researcher, using intentional transitions, visual cues and session locks meant to prevent task-jumping and support deep focus. Roles are defined with a color and a letter icon, time is tracked with live timers and historical analytics, and the statistics are shown in a mobile-friendly dashboard.
