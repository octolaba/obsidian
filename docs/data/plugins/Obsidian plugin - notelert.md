# Notelert

Turns a chosen line of a note into a mobile reminder delivered by a companion Android application, so the alert arrives even when Obsidian is closed. Reminders can be one-time, scheduled through quick shortcuts, recurring with custom end rules, triggered on arrival at a saved location, or sent by email, and tapping a notification reopens the note at that line. The recorded description states that only the selected line is used, with no vault scanning, and that setup means installing the Android application and pasting an app link token into the settings.
