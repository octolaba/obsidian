# Auto Definition Link

Converts typed text into links to definitions held in the current folder, matching block identifiers while preserving capitalization, plurality and the difference between dashes and spaces. The links are either offered as inline suggestions or created automatically when an interrupter such as a space or a punctuation mark is typed.

```cue
plugin: {
    id:     "auto-definition-link"
    name:   "Auto Definition Link"
    author: "nmcarp99"
    repo:   "nmcarp99/Obsidian-Auto-Definition-Link"

    html_url:    "https://community.obsidian.md/plugins/auto-definition-link"
    github_url:  "https://github.com/nmcarp99/Obsidian-Auto-Definition-Link"
```
