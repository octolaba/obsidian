# Pin on Top

Keeps the Obsidian window pinned above other application windows, toggled from a ribbon button. The window transparency is adjustable, so what sits behind Obsidian, such as a video meeting, stays visible. Its stated purpose is working across many applications or across multiple monitors without losing the window.

```cue
plugin: {
    id:     "float-on-top"
    name:   "Pin on Top"
    author: "Joe Utke"
    repo:   "joeutke-dev/obsidian-float"

    html_url:    "https://community.obsidian.md/plugins/float-on-top"
    github_url:  "https://github.com/joeutke-dev/obsidian-float"
    description: "Pin Obsidian window above all other application windows. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Keep Obsidian floating or pinned above other windows on your desktop with a button in the ribbon so it doesn't get lost. Adjust window transparency to keep obsidian above other windows like video meetings while remaining aware of what sits behind the obsidian window. Simple, but useful plugin to better integrate obsidian into your day to day especially when working in lots of applications or across multiple monitors."

    stats: {

    }
}
```
