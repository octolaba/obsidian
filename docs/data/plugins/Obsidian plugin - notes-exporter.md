# Notes Exporter

Brings Apple Notes and Bear notes that were exported with Notes Exporter into the vault as Markdown files that can be edited and linked. The rich YAML frontmatter is preserved, and each note gains native deep links, the source application's icon, an open-in-app command, and source and last-modified information.

```cue
plugin: {
    id:     "notes-exporter"
    name:   "Notes Exporter"
    author: "anton"
    repo:   "podviaznikov/notes-exporter-obsidian"

    html_url:    "https://community.obsidian.md/plugins/notes-exporter"
    github_url:  "https://github.com/podviaznikov/notes-exporter-obsidian"
    description: "Decorate exported Apple Notes and Bear Notes with native app icons. Open notes in their source app. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Bring Apple Notes and Bear notes exported via Notes Exporter into Obsidian as Markdown so your captured notes become editable, linkable vault files. Preserve rich YAML frontmatter and add native deep links, app icons, open-in-app commands, and source/last-modified info for each note."

    stats: {
        downloads:  172

    }
}
```
