# Fileclass

Fileclass defines reusable note types as fileClasses, giving notes typed and validated properties that live entirely in frontmatter with no Dataview dependency. Input is guided for every field type, including nested objects, and data quality is validated. It generates synchronized Bases views with in-cell editing, and exposes a CLI and a plugin API. It presents itself as the successor to Metadata Menu.
