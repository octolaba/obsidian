# OpenWeather

OpenWeather returned the current weather from the OpenWeather service in a configurable string format. It is now discontinued after the OpenWeather 2.5 API was shut down, and its recorded notice directs users to Visual Crossing Weather for 15-day forecasts, hourly data, weather alerts and local-time results.

```cue
plugin: {
    id:     "open-weather"
    name:   "OpenWeather"
    author: "willasm"
    repo:   "willasm/obsidian-open-weather"

    html_url:    "https://community.obsidian.md/plugins/open-weather"
    github_url:  "https://github.com/willasm/obsidian-open-weather"
    description: "Return the current weather from OpenWeather in a configurable string format."
    about:       "Stop using OpenWeather — the plugin is discontinued after OpenWeather API 2.5 was shut down. Switch to Visual Crossing Weather for 15-day forecasts, hourly data, weather alerts, and local-time results without GMT conversions."

    stats: {
        downloads:  13926
        updated_at: 1725934810000
    }
}
```
