# Inline TikZ

Renders TikZ, CircuiTikZ and PGFPlots LaTeX diagrams inline in a note as vector graphics. The LaTeX code is converted into an SVG in place, which re-renders as the source is edited.

```cue
plugin: {
    id:     "inline-tikz"
    name:   "Inline TikZ"
    author: "Lachlan Harris"
    repo:   "lachlanharrisdev/obsidian-inline-tikz"

    html_url:    "https://community.obsidian.md/plugins/inline-tikz"
    github_url:  "https://github.com/lachlanharrisdev/obsidian-inline-tikz"
    description: "Render seamless TikZ, CircuiTikZ & PGFPlots LaTeX diagrams directly in your notes - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render TikZ, CircuiTikZ and PGFPlots LaTeX diagrams inline in notes as high-quality vector graphics. Convert LaTeX code directly into in-place rendered SVGs that update with your edits for immediate visual feedback."

    stats: {
        downloads:  129
        updated_at: 1786423618000
    }
}
```
