# hledger Dashboard

hledger Dashboard renders a financial dashboard for hledger journals inside Obsidian. It shows a balance sheet and net worth, income against expenses, budget against actual with forecasts, searchable paginated transactions, transfer history and KPIs. Charts and detailed tables cover multi-month trends and price conversion.
