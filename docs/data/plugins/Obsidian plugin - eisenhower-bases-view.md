# Eisenhower Matrix for Bases

Renders the notes of an Obsidian Base as a two-by-two Eisenhower matrix along urgency and importance. Dragging a card between quadrants writes the classification back into that note's frontmatter, with a one-step undo for the last move. It runs locally, can show uncategorized and locked notes, and follows the Obsidian language or is forced to English or Japanese.
