# HackerNews

Periodically fetches top stories from Hacker News and displays them in an Obsidian pane, picking a random top story to keep the feed fresh. Any story can be saved as a Markdown note to read, archive or revisit later.

```cue
plugin: {
    id:     "obsidian-hackernews"
    name:   "HackerNews"
    author: "arpitbbhayani"
    repo:   "arpitbbhayani/obsidian-hackernews"

    html_url:    "https://community.obsidian.md/plugins/obsidian-hackernews"
    github_url:  "https://github.com/arpitbbhayani/obsidian-hackernews"
    description: "Periodically fetches and displays top stories from HackerNews."
    about:       "Display top Hacker News stories in an Obsidian pane, periodically fetching a random top story to keep your feed fresh. Save any story as a Markdown note to read, archive, or revisit later."

    stats: {
        downloads:  6595
        updated_at: 1631086074000
    }
}
```
