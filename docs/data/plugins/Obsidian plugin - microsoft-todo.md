# Microsoft To Do

Shows Microsoft To Do lists in an Obsidian sidebar panel, where tasks can be created, edited, completed and reopened, with changes syncing back to Microsoft To Do and Outlook. Highlighted text or a whole note can be sent as a task with a link back to the note. Tasks stay in Microsoft To Do, so no files are added to the vault.

```cue
plugin: {
    id:     "microsoft-todo"
    name:   "Microsoft To Do"
    author: "Jimmie Davis"
    repo:   "jimmieldavisjr/microsoft-todo-obsidian"

    html_url:    "https://community.obsidian.md/plugins/microsoft-todo"
    github_url:  "https://github.com/jimmieldavisjr/microsoft-todo-obsidian"
    description: "Browse your Microsoft To Do lists, create, edit, complete and reopen tasks, and send notes or selected text to To Do - without leaving your vault. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display your Microsoft To Do lists in a sidebar panel inside Obsidian, syncing edits and completions instantly with Microsoft To Do and Outlook. Send highlighted text or whole notes as tasks with links back to the note, and keep tasks in Microsoft To Do without adding files to your vault."
}
```
