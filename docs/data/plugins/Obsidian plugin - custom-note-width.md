# Custom Note Width

Changes the editor line width of each note individually or globally, from a status-bar slider or a text field, with the change applied in real time. Widths are expressed in percent, pixels or ch units, and can be set through YAML front matter or commands so they persist.

```cue

    id:     "custom-note-width"
```
