# Alissa Sync

Mirrors an Alissa vault into Obsidian as wikilinked Markdown files covering projects, tasks, contexts, deliverables and entities. The whole knowledge graph refreshes with one click, the API token is stored locally, and communication runs over HTTPS.

    id:     "alissa-sync"
