# Halo

Publishes notes to a Halo site directly from the editor. Posts can also be pulled from Halo into the vault, and note content updated from the site, so the two stay synchronized. Several Halo sites can be configured, with one marked as the default for quick publishing.

```cue
plugin: {
    id:     "halo"
    name:   "Halo"
    author: "halo-sigs"
    repo:   "halo-sigs/obsidian-halo"

    html_url:    "https://community.obsidian.md/plugins/halo"
    github_url:  "https://github.com/halo-sigs/obsidian-halo"
    description: "Publish content to Halo sites."
    about:       "Publish Obsidian notes to your Halo site directly from the editor. Pull posts from Halo into your vault and update note content from the site to keep them synchronized. Configure multiple Halo sites and mark one as the default for quick publishing."

    stats: {
        downloads:  3957
        updated_at: 1782285019000
    }
}
```
