# Sentence Navigator

The plugin treats a sentence as the unit of movement in the editor. Commands select, move and delete whole sentences and jump between sentence starts, so editing happens at sentence level rather than by character or line.

```cue
plugin: {
    id:     "obsidian-sentence-navigator"
    name:   "Sentence Navigator"
    author: "timhor"
    repo:   "timhor/obsidian-sentence-navigator"

    html_url:    "https://community.obsidian.md/plugins/obsidian-sentence-navigator"
```
