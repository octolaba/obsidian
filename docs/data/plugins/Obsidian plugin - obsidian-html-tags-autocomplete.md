# HTML Tags Autocomplete

Adds the matching closing HTML tag automatically as a tag is typed. The cursor skips across tags, editing one tag updates its counterpart, and a jump moves between matching tags for navigation.

```cue
plugin: {
    id:     "obsidian-html-tags-autocomplete"
    name:   "HTML Tags Autocomplete"
    author: "bicarlsen"
    repo:   "bicarlsen/obsidian_html_tags_autocomplete"

    html_url:    "https://community.obsidian.md/plugins/obsidian-html-tags-autocomplete"
    github_url:  "https://github.com/bicarlsen/obsidian_html_tags_autocomplete"
    description: "Automatically add closing HTML tags."
    about:       "Insert matching closing HTML tags as you type. Skip across tags, update the corresponding tag when you edit one, and jump to matching tags for quick navigation."
```
