# Clipboard Monitor

Watches the system clipboard and inserts newly copied text and images into a pinned note at the cursor, continuing while Obsidian runs in the background rather than focused. One command toggles watch mode on and off, and the note being written to is chosen by pinning it as the target. Watching stops automatically when that note is closed.

```cue
plugin: {
    id:     "clipboard-monitor"
    name:   "Clipboard Monitor"
    author: "Pierre Awaragi"
    repo:   "awaragi/obsidian-clipboard-monitor"

    html_url:    "https://community.obsidian.md/plugins/clipboard-monitor"
    github_url:  "https://github.com/awaragi/obsidian-clipboard-monitor"
    description: "Watch the system clipboard and insert new content into a pinned note at its cursor, even when Obsidian isn't focused. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Capture clipboard content as a live feed into any note, inserting copied text and images at your cursor automatically, even while Obsidian runs in the background. Pin a note as the active target, toggle watch mode with one command, and stop automatically if the target is closed."

    stats: {
        downloads:  158

    }
}
```
