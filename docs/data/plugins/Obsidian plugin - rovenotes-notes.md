# RoveNotes

RoveNotes syncs voice recordings and handwritten notes from RoveNotes into the vault as Markdown pages. Each recording becomes one file with embedded audio, a summary and the full transcript, and each handwritten note becomes one file with recognized Markdown and summaries. Audio is saved beside the note as .ogg for inline playback, YAML metadata and links back to RoveNotes are included, and files are reconciled as transcripts, renames or late updates arrive.

```cue
plugin: {
    id:     "rovenotes-notes"
    name:   "RoveNotes"
    author: "rsteckler"
    repo:   "radiant-maple-studios/rovenotes-obsidian"

    html_url:    "https://community.obsidian.md/plugins/rovenotes-notes"

Save .ogg audio next to each note for inline playback, include YAML metadata and links back to RoveNotes, and keep files reconciled as transcripts, renames, or late updates arrive."
