# Crumbs

Adds breadcrumb navigation to Obsidian. A clickable trail of parent folders and notes is shown for the current file, giving quick navigation and context.

    id:     "crumbs-obsidian"
    name:   "Crumbs"
    author: "Tony Grosinger"
    repo:   "tgrosinger/crumbs-obsidian"
