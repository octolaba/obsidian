# TG Emoji Search

TG Emoji Search inserts emojis by typing a trigger character, a colon by default, followed by a keyword, which yields Telegram-style suggestions with multilingual keyword support. A command inserts a random emoji, and the most-used emojis are viewed or reset. Search is implemented in Rust compiled to WebAssembly.
