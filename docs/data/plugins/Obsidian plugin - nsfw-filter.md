# NSFW filter

Toggles the visibility of notes marked NSFW from a sidebar button or a command. Hiding moves those notes into a designated .NSFW folder and restoring brings them back, with their original locations kept in a cache so each note returns to where it was.

```cue
plugin: {
    id:     "nsfw-filter"
    name:   "NSFW filter"
    author: "catvatar"
    repo:   "catvatar/Obsidian-NSFW-Plugin"

    html_url:    "https://community.obsidian.md/plugins/nsfw-filter"
    github_url:  "https://github.com/catvatar/Obsidian-NSFW-Plugin"
    description: "Adds customizable and easly togglable NSFW filter"
    about:       "Toggle visibility of NSFW-marked notes with a sidebar button or command. Move notes into a designated .NSFW folder to hide them from the vault and restore them back when toggled; original locations are saved to a cache so notes return to their previous places."

    stats: {
        downloads:  578
        updated_at: 1719338565000
    }
}
```
