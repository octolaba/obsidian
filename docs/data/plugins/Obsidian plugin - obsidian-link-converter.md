# Link Converter

Scans the links in the whole vault or in the active file and converts them between wiki-link and Markdown formats. Link targets are also rewritten as relative, absolute or shortest possible paths, and conversions are run from commands or from the file context menu.

```cue
plugin: {
    id:     "obsidian-link-converter"
    name:   "Link Converter"
    author: "ozntel"
    repo:   "ozntel/obsidian-link-converter"

    html_url:    "https://community.obsidian.md/plugins/obsidian-link-converter"
    github_url:  "https://github.com/ozntel/obsidian-link-converter"
    description: "Scan all your links in the vault and convert them to your desired format."
    about:       "Scan all links in your vault or active file and convert between WikiLinks and Markdown formats. Convert link targets to relative, absolute, or shortest possible paths and run conversions via commands or the file context menu."

    stats: {
        downloads:  33005

}
```
