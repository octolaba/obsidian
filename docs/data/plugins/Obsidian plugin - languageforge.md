# languageForge

languageForge generates names from constructed languages, each with a pronunciation guide and a meaning, so word forms stay readable and stable within a culture. Language family trees can be created and evolved, languages mixed or spawned as dialects, and a visual tree is used to pick a language and mint names for any culture. Its description also records culture cards, gate-filtered name batches, reverse-seeding and naming traditions.
