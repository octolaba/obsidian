# Text2Math

Converts natural-language descriptions in Chinese or English into LaTeX math, either from selected text or from a dedicated input box. The candidate formula is shown in a live preview and inserted as inline, block or automatically chosen markup, and replacement is skipped when rendering fails. Conversion runs against an OpenAI-compatible or local API, with the key stored locally.
