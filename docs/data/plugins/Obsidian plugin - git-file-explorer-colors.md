# Git File Explorer Colors

Colors the File Explorer by Git status on desktop so changed files and folders stand out without the repository being modified. Untracked and new files are green, modified files muted orange, and deleted changes roll up to parent folders in muted red under a deleted over modified over new priority. Coloring refreshes on file events with a fallback poll and a manual refresh.

```cue
plugin: {
    id:     "git-file-explorer-colors"
    name:   "Git File Explorer Colors"
    author: "peteszym"
    repo:   "peteszym/obsidian-git-file-colors"

    html_url:    "https://community.obsidian.md/plugins/git-file-explorer-colors"
    github_url:  "https://github.com/peteszym/obsidian-git-file-colors"
    description: "Color the File Explorer from Git status so changed files and folders stand out at a glance. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Color the File Explorer by Git status on desktop to spot changed files at a glance without modifying your repository. Highlight untracked/new files in green, mark modified files in muted orange, and roll deleted changes up to parent folders in muted red with a deleted>modified>new priority; refresh on file events with a fallback poll and a manual refresh."

    stats: {
```
