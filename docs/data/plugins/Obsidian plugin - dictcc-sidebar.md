# dict.cc Sidebar

Looks up German and English words on the dict.cc dictionary from inside the vault. A sidebar opened from a right-click selection or from the command palette shows grouped bilingual translation tables with part-of-speech headers, misspelling suggestions and direction filtering, and follows Obsidian's light and dark themes.
