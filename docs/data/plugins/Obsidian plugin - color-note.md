# Color Note

Colors note and folder titles in the file explorer from the right-click menu, without editing CSS. States are written into a note's front matter as a status property, and each reusable state carries per-theme colors and an explanatory sentence. A single item can also be given a custom color that overrides its state.

```cue
plugin: {
    id:     "color-note"
    name:   "Color Note"
    author: "mikagosz"
    repo:   "mikagosz/obsidian-color-note"

    html_url:    "https://community.obsidian.md/plugins/color-note"
    github_url:  "https://github.com/mikagosz/obsidian-color-note"
    description: "Colour note and folder titles in the file explorer from the right-click menu, using states you define yourself. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Color note and folder titles in the file explorer to reflect custom states or per-item colors without editing CSS. Write states to a note's front matter (status:<value>), define reusable states with per-theme colors and explanatory sentences, and override with single-item custom colors. Apply colors from the file explorer context menu."

    stats: {
        downloads:  31
        updated_at: 1786270201000
    }
}
```
