# Status Bar Organizer

Status bar elements are reordered by drag and drop and hidden individually. Named presets, including separate fullscreen and windowed ones, are created and switched between and persist across restarts. Stale entries left behind by removed plugins are cleared out.

```cue
plugin: {
    id:     "statusbar-organizer"
    name:   "Status Bar Organizer"
    author: "opisek"
    repo:   "opisek/obsidian-statusbar-organizer"

    html_url:    "https://community.obsidian.md/plugins/statusbar-organizer"
    github_url:  "https://github.com/opisek/obsidian-statusbar-organizer"
    description: "Rearrange and hide status bar elements."
    about:       "Reorder status bar elements with drag-and-drop and toggle their visibility to customize what appears. Create and switch between named presets — including separate fullscreen and windowed presets — that persist across restarts, and remove stale entries for deleted plugins."
```
