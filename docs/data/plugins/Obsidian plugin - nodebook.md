# nodeBook

Renders nodeBook code fences as interactive CNL knowledge graphs inside notes. Concept maps are draggable and come with an inspector panel, morph switching, inferred relations that show proof tooltips, and a Nest containment view. Petri-net process notation can be simulated by clicking to fire tokens, and the rendering follows Obsidian's light and dark themes.
