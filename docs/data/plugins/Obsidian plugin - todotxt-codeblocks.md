# TodoTxt Codeblocks

TodoTxt Codeblocks manages tasks inside code blocks according to the Todo.txt specification. A codeblock can be linked to a txt file for two-way sync, and tasks are sorted and grouped by project or context, previewed and edited inline, and archived once completed. Projects and contexts autocomplete, and Markdown links inside tasks are rendered.
