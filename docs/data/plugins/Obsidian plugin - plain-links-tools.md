# Plain Links Tools

Plain Links Tools converts Markdown links and Obsidian wikilinks in the current note into their display text or their raw URLs. Bare email addresses are rendered as plain text in Reading View and Live Preview, while explicit mailto links are preserved. A modifier click still opens an address whose linking has been suppressed.

```cue
plugin: {
    id:     "plain-links-tools"
    name:   "Plain Links Tools"
    author: "Sohei Ide"
    repo:   "soheidon/Plain-Links-Tools"

    html_url:    "https://community.obsidian.md/plugins/plain-links-tools"
    github_url:  "https://github.com/soheidon/Plain-Links-Tools"
    description: "Make bare email addresses and selected links behave like plain text in Obsidian. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert Markdown links and Obsidian wikilinks in the current note to display text or raw URLs. Render bare email addresses as plain text in Reading View and Live Preview while preserving explicit mailto links and allowing Ctrl/Cmd+click to open suppressed addresses."

    stats: {
        downloads:  68
        updated_at: 1782996646000
    }
}
```
