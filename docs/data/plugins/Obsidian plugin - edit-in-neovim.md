# Edit in Neovim

Starts a persistent Neovim instance in a terminal and opens every file of the vault as a buffer in that session. Opening a note in Obsidian focuses the matching Neovim buffer, and companion bridge plugins enable editing in both directions.

```cue
plugin: {
    id:     "edit-in-neovim"
    name:   "Edit in Neovim"
    author: "theseusgrey"
    repo:   "theseusgrey/edit-in-neovim"

    html_url:    "https://community.obsidian.md/plugins/edit-in-neovim"
    github_url:  "https://github.com/theseusgrey/edit-in-neovim"
    description: "Open a Neovim buffer for the currently open file"
    about:       "Launch a persistent Neovim instance in a terminal and open every Obsidian file as a buffer in that Neovim session. Mirror note navigation so opening a file in Obsidian focuses the matching Neovim buffer, and enable two-way editing with companion bridge plugins."
```
