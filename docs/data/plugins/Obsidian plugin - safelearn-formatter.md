# SafeLearn Formatter

SafeLearn Formatter renders visual aids for the Markdown tags used by the SafeLearn project: Reveal.js fragments, role-based permission blocks and multi-column side-by-side layouts. Role-specific blocks, for example teacher blocks, can be marked, and incremental fragments and side-by-side columns are previewed while editing. The plugin is purely visual and does not enforce the permissions it displays.
