# Yuque Publish

Publishes notes to Yuque with a single command, creating a document or updating an existing one. Personal and team spaces are both targets, document visibility is set from Obsidian, and several group configurations are managed side by side.

```cue
plugin: {
    id:     "yuque-publish"
    name:   "Yuque Publish"
    author: "oylbin"
    repo:   "oylbin/obsidian-yuque-publish"

    html_url:    "https://community.obsidian.md/plugins/yuque-publish"
    github_url:  "https://github.com/oylbin/obsidian-yuque-publish"
    description: "Publish your notes to Yuque."
```
