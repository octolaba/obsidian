# New Tab Pins

Replaces the empty-tab screen with a home view listing pinned notes, a quick search box and recently edited files. Markdown files are pinned from the file explorer or by dragging them onto the view, and the pins can be reordered. It makes no network requests, stores only its settings and the pinned paths, and never modifies note contents.
