# Fold Properties By Default

Keeps editor and metadata properties folded by default. Open notes are detected and any unfolded metadata is toggled to folded, so properties stay out of the way without being hidden. Newly created notes are left unfolded so that metadata can be entered before folding.

```cue
plugin: {
    id:     "fold-properties-by-default"
    name:   "Fold Properties By Default"
    author: "Tommy Bergeron"
    repo:   "tbergeron/obsidian-fold-properties-by-default"

    html_url:    "https://community.obsidian.md/plugins/fold-properties-by-default"
    github_url:  "https://github.com/tbergeron/obsidian-fold-properties-by-default"
    description: "Always have editor/metadata properties folded by default"
    about:       "Fold metadata and frontmatter properties by default. Detect open notes and toggle any unfolded metadata to folded so properties stay out of the way without hiding them. Leave newly created notes unfolded to allow entering metadata before folding."
```
