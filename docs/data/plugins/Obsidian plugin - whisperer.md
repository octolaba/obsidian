# WHISPERER.md

Assigns audio to the vault and to individual files through metadata, so a note or a whole vault can carry its own ambience. Both audio stored in the vault and URLs from YouTube or SoundCloud are supported, and playback is managed inside Obsidian, including on mobile vaults.

```cue
plugin: {
    id:     "whisperer"
    name:   "WHISPERER.md"
    author: "falcion"
    repo:   "falcion/Whisperer.md"

    html_url:    "https://community.obsidian.md/plugins/whisperer"
    github_url:  "https://github.com/falcion/Whisperer.md"
    description: "Play ambience in your vault, assign audio to files through metadata with support of local (from vault) and URLs (Youtube, Soundcloud) versions of audio: works on mobile vaults."
    about:       "Attach music to vaults and individual notes to set an atmosphere or working mood. Play and manage flexible audio accompaniment per file or across your vault directly inside Obsidian."

    stats: {
        downloads:  1890
        updated_at: 1747225023000
    }
}
```
