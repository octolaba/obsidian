# Sortable File Explorer

A separate file explorer view supports drag-and-drop reordering with a custom order that persists, and a clearer visual hierarchy than the built-in list. Several items are selected at once for a batch move, duplicate or delete, files are renamed inline, and files are imported by dragging them in. The ordering set on desktop is kept on mobile.
