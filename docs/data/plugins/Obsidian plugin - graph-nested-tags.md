# Nested tags graph

Links nested tags in the graph view by connecting each sub-tag to its parent tag. Hierarchical tag relationships are therefore rendered as connected nodes in Obsidian's graph.

```cue
plugin: {
    id:     "graph-nested-tags"
    name:   "Nested tags graph"
    author: "drpilman"
    repo:   "drpilman/obsidian-graph-nested-tags"

    html_url:    "https://community.obsidian.md/plugins/graph-nested-tags"
    github_url:  "https://github.com/drpilman/obsidian-graph-nested-tags"
    description: "Link nested tags in graph view."
    about:       "Link nested tags in the graph view by connecting sub-tags to their parent tags. Render hierarchical tag relationships so nested tags appear as connected nodes in Obsidian's graph."

    stats: {
        downloads:  19354
```
