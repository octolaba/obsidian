# Stratum

A Zotero library is turned into structured literature notes with readable filenames and frontmatter. Annotations and color-grouped highlights are synced with deep links back into Zotero, whole libraries or single collections are imported, and content below the stratum marker is preserved. Pandoc citations are maintained automatically using OpenAlex metadata.
