# Ghosty Posty

Posts notes to a Ghost blog with a single command, converting Markdown to Ghost-compatible HTML and uploading local images, with the first image of the note used as the featured image. Title, tags and status can be edited before posting, a post can be marked featured or scheduled, and values in YAML frontmatter are honored.

```cue
plugin: {
    id:     "ghosty-posty"
    name:   "Ghosty Posty"
    author: "mattbirchler"
    repo:   "mattbirchler/ghosty-posty-obsidian"

    html_url:    "https://community.obsidian.md/plugins/ghosty-posty"
    github_url:  "https://github.com/mattbirchler/ghosty-posty-obsidian"
    description: "Post your notes to your Ghost blog. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Publish Obsidian notes to Ghost with a single command, converting Markdown to Ghost-compatible HTML and uploading local images automatically (first-line image becomes the featured image). Edit title, tags, status, toggle featured, schedule posts, and honor YAML frontmatter."

    stats: {
        downloads:  476
        updated_at: 1783635418000
    }
}
```
