# CiteMe - Academic Citations

Searches academic papers across more than eleven databases and inserts formatted citations in 43 styles. In-text citations, full bibliography entries or both can be inserted, and a References section is built and maintained automatically with DOI and text checks against duplicates. The remaining quota is shown in the status bar, and the recorded inputs distinguish free from Pro style handling.

    id:     "citeme"
    name:   "CiteMe - Academic Citations"
