# Cisco Syntax

Cisco Syntax highlights Cisco IOS, IOS-XE, IOS-XR and NX-OS configuration inside fenced code blocks, in Reading mode and in Live Preview. One grammar covers all four so the styling stays consistent, colors follow the theme with an optional Vibrant palette, and Reading mode gains a copy button that stays visible.

```cue
plugin: {
    id:     "cisco-syntax"
    name:   "Cisco Syntax"
    author: "Blake Bratcher"
    repo:   "blakebratcher/obsidian-cisco-syntax"

    html_url:    "https://community.obsidian.md/plugins/cisco-syntax"
    github_url:  "https://github.com/blakebratcher/obsidian-cisco-syntax"
```
