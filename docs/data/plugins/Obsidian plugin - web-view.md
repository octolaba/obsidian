# Web View

Opens HTTP and HTTPS links inside Obsidian rather than handing them to the system browser. Each link is loaded as a web page in a new tab through an embedded browser.

```cue
plugin: {
    id:     "web-view"
    name:   "Web View"
    author: "serhat-can"
    repo:   "canserhat77/obsidian-web-view"

    html_url:    "https://community.obsidian.md/plugins/web-view"
    github_url:  "https://github.com/canserhat77/obsidian-web-view"
    description: "Opens HTTP/HTTPS links inside Obsidian as web pages in new tabs using an embedded browser. - This plugin has not been manually reviewed by Obsidian staff."

    stats: {
        downloads:  383
        updated_at: 1780579940000
    }
}
```
