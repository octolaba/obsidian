# Set to Root

Set to Root opens additional File Explorer tabs rooted at a specific folder, leaving the built-in full-vault explorer unaltered. A single reusable rooted view or several rooted tabs can be created, tab icons are chosen from a searchable picker, and rooted views are restored after a restart.
