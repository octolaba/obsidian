# Vim KeyNav

Vim KeyNav brings Vim-style keyboard navigation to reading mode and the built-in browser. Scrolling uses j and k, gg and G jump to the ends, and links are opened through Vimium-style hint labels. Host-level keybindings are injected into webviews, including cross-origin iframes, and the keys are disabled inside input fields.

```cue
plugin: {
    id:     "vim-keynav"
    name:   "Vim KeyNav"
    author: "guoang"
    repo:   "guoang/obsidian-vim-keynav"

    html_url:    "https://community.obsidian.md/plugins/vim-keynav"
    github_url:  "https://github.com/guoang/obsidian-vim-keynav"
    description: "Vim-style keyboard navigation for reading mode and built-in browser. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Bring Vim-style navigation to reading mode and built-in browser tabs. Scroll with j/k, jump with gg/G, open links via Vimium-style hint labels, and inject host-level keybindings into webviews (including cross-origin iframes) while disabling keys in input fields."
```
