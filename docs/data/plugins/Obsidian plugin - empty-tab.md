# Empty Tab

Adds a command palette entry that replaces the current tab with Obsidian's empty view, the screen shown when a new tab is opened. The tab and its history stay in place, and its recorded About states that no file is read, written or deleted.

```cue
plugin: {
    id:     "empty-tab"
    name:   "Empty Tab"
    author: "Waldemar"
    repo:   "waldemar-one/obsidian-empty-tab"

    html_url:    "https://community.obsidian.md/plugins/empty-tab"
    github_url:  "https://github.com/waldemar-one/obsidian-empty-tab"
    description: "Adds a command to replace the current tab with an empty page, the same screen shown when opening a new tab. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add a Command Palette command to replace the current tab with Obsidian's empty view. Clear the tab's content while keeping the tab open and history intact; no files are read, written, or deleted."

    stats: {
        downloads:  44
        updated_at: 1783073108000
    }
}
```
