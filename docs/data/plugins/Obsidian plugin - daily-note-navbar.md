# Daily Note Navbar

Replaces the view header of a daily note with a navigation bar for moving between sequential dates and switching weeks. Date formats are configurable, and the bar indicates which daily notes are the current one, the active one, or missing.

```cue
plugin: {
    id:     "daily-note-navbar"
    name:   "Daily Note Navbar"
    author: "karstenpedersen"
    repo:   "karstenpedersen/obsidian-daily-note-navbar"

    html_url:    "https://community.obsidian.md/plugins/daily-note-navbar"
    github_url:  "https://github.com/karstenpedersen/obsidian-daily-note-navbar"
    description: "Navigate between sequential daily notes with ease."
    about:       "Replace the view header in daily notes with a navigation bar to jump between dates and switch weeks quickly. Customize date formats and see clear indicators for the current, active, or non-existent daily notes."
```
