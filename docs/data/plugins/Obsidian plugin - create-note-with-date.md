# Create Note with Date in This Directory

Create Note with Date in This Directory creates a note named after today's date in YYYY-MM-DD form in the current directory, for journals, meeting notes or any date-based entry. The new note opens immediately for editing. Seven languages are supported with system-language detection, and there are no external dependencies.
