# New Note New Window

This plugin opens new notes in a floating window. Each note can be created in its own floating pane, or a single floating window can be reused. New files are saved to the default folder or to a specified one.

```cue
plugin: {
    id:     "obsidian-new-note-new-window"
    name:   "New Note New Window"
    author: "pr0dt0s"
    repo:   "pr0dt0s/new-note-new-window"

    html_url:    "https://community.obsidian.md/plugins/obsidian-new-note-new-window"
    github_url:  "https://github.com/pr0dt0s/new-note-new-window"
    description: "Easily open new notes in a floating window."
    about:       "Open new notes in a floating window. Create each note in its own floating pane or reuse a single floating window, and save new files to your default or a specified folder."
```
