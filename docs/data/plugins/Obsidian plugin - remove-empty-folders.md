# Remove Empty Folders

Removes empty folders from selected locations in the file explorer. Running it repeatedly clears nested empty folders, and removed folders are moved to Obsidian's own trash so they can be recovered.

```cue
plugin: {
    id:     "remove-empty-folders"
    name:   "Remove Empty Folders"
    author: "fnya"
    repo:   "fnya/remove-empty-folders"

    html_url:    "https://community.obsidian.md/plugins/remove-empty-folders"
    github_url:  "https://github.com/fnya/remove-empty-folders"
    description: "Easily remove empty folders."
    about:       "Remove empty folders from selected locations in the file explorer. Run repeatedly to clear nested empties; removed folders are moved to Obsidian's .trash for easy recovery."

    stats: {
        downloads:  3558

    }
}
```
