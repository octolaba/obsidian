# MultiDim Virtual Folders

Builds several virtual folder trees out of note frontmatter, so one Markdown file appears in many hierarchies without the real file moving. Each dimension is shown as a sidebar tree, and dragging a note into a virtual folder updates its frontmatter. Virtual folders are renamed or deleted without affecting real files.
