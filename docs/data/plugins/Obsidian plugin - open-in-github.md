# Open in GitHub

Open in GitHub opens the current file or the project path behind the vault on github.com. The page opens in the browser, where it can be viewed or edited.

```cue
plugin: {
    id:     "open-in-github"
    name:   "Open in GitHub"
    author: "hacker-c"
    repo:   "hacker-c/obsidian-open-in-github-plugin"

    html_url:    "https://community.obsidian.md/plugins/open-in-github"
    github_url:  "https://github.com/hacker-c/obsidian-open-in-github-plugin"
    description: "Open the current project or file in github.com."
    about:       "Open projects and files on GitHub directly from Obsidian. Launch the current file or repository path in your browser to view or edit it on GitHub."

        downloads:  503

    }
}
```
