# Note Village

Renders the vault as a two-dimensional pixel-art village in which frequent tags become themed zones and notes appear as villagers. The village can be explored, and villagers can be chatted with through Claude, which requires an Anthropic API key. Layouts are procedurally generated and deterministic, and the graphics are customizable.
