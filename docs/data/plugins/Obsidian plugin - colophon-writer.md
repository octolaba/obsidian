# Colophon

Colophon provides a typographically refined, distraction-free writing canvas for long-form manuscripts and screenplays, with the feel of a word processor. A custom editor and a dedicated .colophon file format preserve footnotes, comments and precise layout, and Manuscript and Script modes switch between industry-standard formats.
