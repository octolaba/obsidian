# YACHT

Tracks habits locally in the vault from a sidebar, a tab, or a view embedded in a note. Habits are added, edited and archived, streaks are displayed, and the data imports and exports as JSON with a merge or replace option.

    id:     "yacht-habit-tracker"

    author: "jayandoh"
    repo:   "jayandoh/obsidian-habit-tracker"

    html_url:    "https://community.obsidian.md/plugins/yacht-habit-tracker"
    github_url:  "https://github.com/jayandoh/obsidian-habit-tracker"
