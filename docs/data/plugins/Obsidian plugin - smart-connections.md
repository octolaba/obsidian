# Smart Connections

Smart Connections resurfaces notes and excerpts related by meaning to the one being written, shown in a graph and list view, with a blocks mode that narrows results to excerpts such as a single paragraph or a list. Results can be previewed, dragged into the note, hidden, pinned, copied as a link tree or sent to a Smart Context. A built-in local embedding model provides the retrieval, which the recorded inputs say requires no setup and no API key.
