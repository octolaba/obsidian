# Chillight Graph

Chillight Graph replaces the Obsidian Graph View with an animated rendering whose nodes glow and whose links are drawn as curved garland-style wires. Node and wire color, glow, size, thickness and sag are configurable, and fourteen built-in visual themes and several animation modes are provided. The plugin is desktop only.
