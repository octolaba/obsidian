# Bases Style Enhancer

Bases Style Enhancer adjusts the appearance of Bases views, starting with a table font size applied globally across every Bases view. The size is given in rem or px units and can optionally be applied to table headers as well.

```cue
plugin: {
    id:     "bases-style-enhancer"
    name:   "Bases Style Enhancer"
    author: "uniqueclone"
    repo:   "uniqueclone/bases-style-enhancer"

    html_url:    "https://community.obsidian.md/plugins/bases-style-enhancer"
    github_url:  "https://github.com/uniqueclone/bases-style-enhancer"
    description: "Enhance the appearance of Bases views (starting with table font size) - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Adjust Bases table font size globally to improve readability across all Bases views. Choose rem or px units and optionally apply the same size to table headers for consistent table styling."

    stats: {
        downloads:  517
        updated_at: 1769009327000
    }
}
```
