# Foldable Embedded Notes

Makes embedded notes foldable in reading view and in Live Preview. A trailing-dash syntax on the embed marks it as folded by default.

```cue
plugin: {
    id:     "foldable-embedded-notes"
    name:   "Foldable Embedded Notes"
    author: "Nickolay Kondratyev"
    repo:   "nickolay-kondratyev/obsidian-foldable-embedded-notes"

    html_url:    "https://community.obsidian.md/plugins/foldable-embedded-notes"
    github_url:  "https://github.com/nickolay-kondratyev/obsidian-foldable-embedded-notes"
```
