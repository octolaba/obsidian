# Year Glance

Renders a full-year calendar with events marked by colored category indicators and bars spanning multi-day events. The view switches between compact and expanded forms with a 3x4 or single-row month layout, and an optional marker highlights today.

```cue
plugin: {
    id:     "year-glance"
    name:   "Year Glance"
    author: "yy"
    repo:   "yy/obsidian-year-glance"

    html_url:    "https://community.obsidian.md/plugins/year-glance"
    github_url:  "https://github.com/yy/obsidian-year-glance"
    description: "Render yearly calendar views with events marked and color-coded. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display a full-year calendar with events marked by colored category indicators and spanning bars for multi-day events. Choose compact or expanded views with 3x4 or single-row month layouts and an optional today marker for quick annual planning."

    stats: {
        downloads:  168

    }
}
```
