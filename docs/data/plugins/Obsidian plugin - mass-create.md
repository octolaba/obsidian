# Mass Create

Mass Create makes large numbers of notes and folders at once inside a chosen vault folder. An existing file can be used as a template so all the new notes start with the same content. Creation is triggered from a folder's right-click menu or from the command palette.

```cue
plugin: {
    id:     "mass-create"
    name:   "Mass Create"
    author: "vellikhor"
    repo:   "vellikhor/mass-create"

    html_url:    "https://community.obsidian.md/plugins/mass-create"
    github_url:  "https://github.com/vellikhor/mass-create"
    description: "Create large quantities of notes easily at one time."
    about:       "Create multiple files and folders at once inside a chosen vault folder. Apply an existing file as a template to populate content across all new notes and trigger mass creation from a folder's right-click menu or the command palette."

    }
}
```
