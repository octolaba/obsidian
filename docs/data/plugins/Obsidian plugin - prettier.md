# Prettier

Formats notes with Prettier, either a whole file or a selection, including embedded code blocks in JavaScript, TypeScript, CSS, SCSS, Less, HTML, JSON, and YAML. Code block languages can be remapped, trailing spaces added to preserve live preview rendering, and formatting toggled per file through frontmatter.
