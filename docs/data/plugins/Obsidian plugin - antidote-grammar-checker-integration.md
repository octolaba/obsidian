# Antidote Grammar Checker Integration

An unofficial integration of the Antidote grammar checker, dictionary and guide for English and French. Status-bar icons and commands run Correct All over the whole document or a selection, run a cursor-aware Simple Correct, and open the Antidote dictionary and guide. It is available on desktop.

```cue
plugin: {
    id:     "antidote-grammar-checker-integration"
    name:   "Antidote Grammar Checker Integration"
    author: "heziode"
    repo:   "heziode/obsidian-antidote"

    html_url:    "https://community.obsidian.md/plugins/antidote-grammar-checker-integration"
    github_url:  "https://github.com/heziode/obsidian-antidote"
```
