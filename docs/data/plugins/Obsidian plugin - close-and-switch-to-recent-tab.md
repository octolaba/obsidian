# Close and Switch to Recent Tab

Switches to the most recently used tab when the current one is closed, matching browser MRU behavior rather than jumping to the adjacent tab. The last 30 visited tabs are tracked, and a dedicated Close and Switch to Recent Tab command is available for binding to a hotkey. No configuration is required.

```cue
plugin: {
    id:     "close-and-switch-to-recent-tab"
    name:   "Close and Switch to Recent Tab"
    author: "xzhi"
    repo:   "github-xzhi/obsidian-close-and-switch-to-recent-tab"

    html_url:    "https://community.obsidian.md/plugins/close-and-switch-to-recent-tab"
```
