# Open Manage

Personal Funds tracks income, expenses, credit card payments and repayments, lending, loan collections and account adjustments locally in the vault. Account, card, expense, income and lending summaries are shown in a responsive modal. A Markdown dashboard note or an Obsidian Canvas can be generated from the records, which the recorded inputs state are stored locally.
