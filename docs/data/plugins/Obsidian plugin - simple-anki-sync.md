# Simple Anki Sync

Simple Anki Sync pushes basic flashcards to Anki from a minimal Markdown-table format, creating Basic cards. One command syncs the current file or the whole vault, and Anki has to be running with the AnkiConnect add-on.

```cue
plugin: {
    id:     "simple-anki-sync"
    name:   "Simple Anki Sync"
    author: "lukmay"
    repo:   "lukmay/simple-anki-sync"

    html_url:    "https://community.obsidian.md/plugins/simple-anki-sync"
    github_url:  "https://github.com/lukmay/simple-anki-sync"
    description: "Simple way to sync basic flashcards with Anki with zero time tweaking settings and 100 % of your time learning."
    about:       "Sync notes to Anki using a minimal Markdown-table format that creates Basic cards. Push the current file or entire vault with a single command; requires Anki running with the AnkiConnect add-on."

    stats: {
        downloads:  1165
        updated_at: 1779735374000
    }
}
```
