# promChip

Places AI prompt chips in a draggable floating ball that can be pinned to the desktop, with each prompt button movable on its own. Selecting text in the editor and clicking a chip streams the reply, rendered as Markdown, into a collapsible floating window that can also be pinned, and the reply can then be edited or discarded. Providers with an OpenAI-compatible API can be switched between, more than twenty color schemes are offered, annotation markers are shown in the editor, and touch gestures are supported on mobile.
