# Note UID Generator

Generates unique identifiers for notes and records them in frontmatter, giving each note a stable reference for linking, scripting or external systems. UUIDv4, a customizable NanoID or a lexicographic ULID can be chosen, identifiers can be added or removed manually, automatically or in bulk, and a UID or a title plus UID can be copied. Built-in duplicate detection guards against collisions.
