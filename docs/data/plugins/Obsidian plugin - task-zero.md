# Task Zero

Task Zero is a keyboard-first task management system for GTD, modelled on the MyLifeOrganized interface. Everything is driven from a single main task page under full keyboard control. An API is exposed so that other plugins and scripts can interact with the tasks.

    id:     "task-zero"
    name:   "Task Zero"
    author: "Alan Grainger"
    repo:   "alangrainger/obsidian-task-zero"

    github_url:  "https://github.com/alangrainger/obsidian-task-zero"
