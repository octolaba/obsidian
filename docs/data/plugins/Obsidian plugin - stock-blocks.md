# Stock Blocks

Stock and crypto prices, changes and sparkline charts are rendered in notes, either as a compact table for a list of symbols or as a larger detailed chart for a single one. The recorded inputs describe signed, dependency-free releases with SHA256 checksums and automated builds that can be verified for file integrity.
