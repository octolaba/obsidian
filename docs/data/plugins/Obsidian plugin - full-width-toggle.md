# Full Width Toggle

Adds a compact Notion-style Full Width switch to the status bar that toggles the active note between full width and readable width. The state is stored per note in the note's cssclasses property, and other classes already there are preserved. The whole control is clickable rather than just its label.

```cue
plugin: {
    id:     "full-width-toggle"
    name:   "Full Width Toggle"
    author: "JaeKyung Hwang"
    repo:   "do0ori/obsidian-full-width-toggle"

    html_url:    "https://community.obsidian.md/plugins/full-width-toggle"
    github_url:  "https://github.com/do0ori/obsidian-full-width-toggle"
    description: "Toggle full width per note from a Notion-style switch in the status bar. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add a compact Notion-style Full Width switch to Obsidian's status bar. Toggle the active note between full-width and readable width with a fully clickable control and save per-note state to the note's cssclasses while preserving other classes."

    stats: {
        downloads:  267
        updated_at: 1785221860000
    }
}
```
