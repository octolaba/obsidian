# Gongkao Sprint

A vault-native study workflow for civil service exam preparation that keeps Markdown files as the single source of truth. Desktop and mobile dashboards plan daily study, capture text or photo error cards, run front-and-back review sessions with mastery feedback, and log practice and reflections. Weaknesses and effort are tracked across sessions.
