# Hover External Link Plugin

Hover External Link shows the destination URL of an external link in a tooltip when the link is hovered in preview mode. The tooltip appears only where the link text differs from its URL, so links written as plain URLs are left unchanged.

```cue
plugin: {
    id:     "hover-external-link"
    name:   "Hover External Link Plugin"
    author: "jamiebrynes7"
    repo:   "jamiebrynes7/obsidian-hover-external-link"

    html_url:    "https://community.obsidian.md/plugins/hover-external-link"
    github_url:  "https://github.com/jamiebrynes7/obsidian-hover-external-link"
    description: "Hover on external links to see the destination URL."
    about:       "Show hover URL previews for external links in preview mode. Display lightweight tooltips only when link text differs from its URL so plain URL links remain unchanged."

    stats: {
        downloads:  7792
        updated_at: 1629754445000
    }
}
```
