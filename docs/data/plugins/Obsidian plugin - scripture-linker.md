# Scripture Linker

Scripture Linker scans notes for Bible references and turns them into clickable links to Logos Bible Software and Bolls Bible. It detects contextual and shorthand references, recognizes more than 500 book-name variants, supports multiple translations, and leaves existing Markdown links alone rather than linking them a second time.

```cue
plugin: {
    id:     "scripture-linker"
    name:   "Scripture Linker"
    author: "marvive"
    repo:   "marvive/scripture-linker"

    html_url:    "https://community.obsidian.md/plugins/scripture-linker"
    github_url:  "https://github.com/marvive/scripture-linker"
    description: "Scan notes for Bible references and link them to Logos Bible Software and Bolls Bible. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Scan notes for Bible references and convert them into clickable links to Logos and Bolls Bible. Detect contextual and shorthand references, recognize 500+ book name variants, support multiple translations, and avoid re-linking existing markdown links."

    stats: {
        downloads:  143
        updated_at: 1770513555000
    }
}
```
