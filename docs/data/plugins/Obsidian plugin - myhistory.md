# MyHistory

Keeps a local version history for Markdown notes by recording an immutable snapshot whenever a note's content changes. A sidebar timeline lists the versions of the open note for previewing, pinning and restoring. Histories survive renames, moves and deletions, retention is configured per note, and a scan at startup catches missed edits.
