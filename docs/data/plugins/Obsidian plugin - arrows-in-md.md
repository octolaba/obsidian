# Arrows

Draws arrows between parts of a note in Live Preview, using inline identifiers that mark the start and end points and set the color. Diagonal arrows, several end targets for one start, and margin-positioned connectors are supported.

```cue
plugin: {
    id:     "arrows-in-md"
    name:   "Arrows"
    author: "artisticat"
    repo:   "artisticat1/arrows"

    html_url:    "https://community.obsidian.md/plugins/arrows-in-md"
    github_url:  "https://github.com/artisticat1/arrows"
    description: "Draw arrows across different parts of your notes, similar to on paper."
    about:       "Draw arrows in Live Preview by inserting inline identifiers that mark start and end points and specify color. Create diagonal arrows, multiple end targets per start, and margin-positioned connectors to visually link parts of your notes."
```
