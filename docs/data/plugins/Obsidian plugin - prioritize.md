# Prioritize

Marks notes and tasks with priority levels by selecting text and applying a level. The number and the names of the levels are configurable, presets can be saved and switched between to reuse priority schemes, and commands increase, decrease, or remove a priority.

    id:     "prioritize"
    name:   "Prioritize"
    author: "tekknoman"
    repo:   "tekknoman/obsidian-prio-plugin"
