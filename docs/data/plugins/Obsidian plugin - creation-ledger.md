# Creation Ledger

Captures what is being worked on as lightweight activity notes stored as plain Markdown in a CreationLedger folder, so progress on long-running creative projects can be resumed. Each quick entry records a title, status, project and tags. Optional dashboards and a Kanban board present the recorded work when it is paired with Dataview.
