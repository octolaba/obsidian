# Header Adjuster

Header Adjuster increases or decreases Markdown header levels across a whole note or within a chosen line range, by a chosen number of levels. Adjustments are run from the command palette or the ribbon, and default level increments cover quick edits.

```cue
plugin: {
    id:     "header-adjuster"
    name:   "Header Adjuster"
    author: "netajam"
    repo:   "netajam/header-adjuster"

    html_url:    "https://community.obsidian.md/plugins/header-adjuster"
    github_url:  "https://github.com/netajam/header-adjuster"
    description: "Easily adjust header levels in Markdown documents by increasing or decreasing their levels."
    about:       "Adjust Markdown header levels across an entire note or within a specific line range by a chosen number. Apply changes via the command palette or ribbon and use default level increments for quick edits."
```
