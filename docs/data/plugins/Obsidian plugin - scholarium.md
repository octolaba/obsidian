# Scholarium

Scholarium is a local-first scholarly workspace that keeps notes as plain Markdown in the vault. Structured experiment records carry metadata such as date, reagents, SMILES and status, and natural-language descriptions or OCR images can be converted into editable entries with integrated AI. A role-aware dashboard manages experiments, tasks, focus sessions, habit logs, material libraries and submissions.
