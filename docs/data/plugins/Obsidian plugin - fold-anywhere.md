# Fold Anywhere

Folds arbitrary text in live preview by setting a start and an end marker, or by selecting text to make a collapsible region. Commands mark the start and end positions and fold or unfold between them. Marks are removed again to clean up the folds.

```cue
plugin: {
    id:     "fold-anywhere"
    name:   "Fold Anywhere"
    author: "Boninall"
```
