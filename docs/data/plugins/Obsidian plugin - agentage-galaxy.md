# Agentage Galaxy

Agentage Galaxy draws the vault as a rotating 3D force-graph in which notes are nodes and links are edges, every top-level folder forming its own colored cluster and nodes growing with their number of connections. It mirrors the built-in graph view, keeping the same node kinds and the same filters for search, tags, attachments, existing files only and orphans. Center, repel, link and distance forces, node size, link thickness, labels, arrows and auto-orbit speed are adjustable, while dragging, scrolling and clicking rotate, zoom and open a note. Everything runs on the device with no network calls.
