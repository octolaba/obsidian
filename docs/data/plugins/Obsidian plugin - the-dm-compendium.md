# The DM Compendium

The DM Compendium searches Dungeons and Dragons 5th Edition monsters, spells and items and inserts them into notes. Statblocks are generated as YAML compatible with Obsidian TTRPG plugins, spell and item cards render inline in reading view, and selected compendium data is cached so searches stay fast.

```cue
plugin: {
    id:     "the-dm-compendium"
    name:   "The DM Compendium"
    author: "guykahalani"
    repo:   "guykahalani/the-dm-compendium"

    html_url:    "https://community.obsidian.md/plugins/the-dm-compendium"
    github_url:  "https://github.com/guykahalani/the-dm-compendium"
    description: "Search and insert Dungeons & Dragons 5th Edition monsters, spells, and items into notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Search and insert Dungeons & Dragons 5e monsters, spells, and items into your notes. Generate YAML statblocks compatible with Obsidian TTRPG plugins, render inline spell and item cards in reading view, and cache selected compendium data for fast searches."

    stats: {
        downloads:  1082
        updated_at: 1784149849000
    }
}
```
