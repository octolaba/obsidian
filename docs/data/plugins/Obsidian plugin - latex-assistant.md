# LaTeX Assistant

LaTeX Assistant reproduces a VS Code and LaTeX Workshop style of editing, auto-pairing the dollar sign and toggling between inline and display math. Common LaTeX snippets are inserted by trigger expansion or by a slash command inside math, with the cursor jumping to the first editable field. Custom snippets can be created, managed and exchanged as JSON.
