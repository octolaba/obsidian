# Custom Attachment Location

Custom Attachment Location customizes where attachments are saved and how they are named, using variables such as the note filename and date formats. Pasted files are renamed, attachments already referenced by notes collected into the configured folders, and the way attachment links are inserted into Markdown is controlled.

```cue
plugin: {
    id:     "obsidian-custom-attachment-location"
    name:   "Custom Attachment Location"
    author: "Michael Naumov"
    repo:   "mnaoumov/obsidian-custom-attachment-location"

    html_url:    "https://community.obsidian.md/plugins/obsidian-custom-attachment-location"
    github_url:  "https://github.com/mnaoumov/obsidian-custom-attachment-location"
    description: "Customize attachment location with variables($filename, $data, etc) like Typora."
    about:       "Customize attachment save paths and filenames using tokens (like ${noteFileName} and date formats). Rename pasted files, collect attachments from notes into configured folders, and control how links to attachments are inserted into Markdown."

    stats: {
        downloads:  89180
        updated_at: 1786210578000
    }
}
```
