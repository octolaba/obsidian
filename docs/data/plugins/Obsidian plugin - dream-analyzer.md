# Dream Analyzer

Analyzes dream entries with AI to pull out summaries, characters, places, objects, emotions, symbols and concepts, then creates or updates a note per entity recording its appearances, history and connections. Related dreams are found by combining semantic similarity with shared entities. A dashboard collects lucid-dream statistics, trends and recurring signs, and references stay in sync when notes are moved or renamed.
