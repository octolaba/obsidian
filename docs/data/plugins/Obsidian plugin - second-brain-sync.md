# Second Brain Sync

Second Brain Sync pushes notes to a self-hosted Second Brain MCP server running on Cloudflare Workers, with one-click sync, bulk sync by tag, or automatic sync on save. The Second Brain can be searched from an Obsidian sidebar, long notes are chunked automatically for cleaner embeddings, and the last sync status is shown.

plugin: {
    id:     "second-brain-sync"
    name:   "Second Brain Sync"
    author: "Rahil Pirani"
    repo:   "rahilp/second-brain-obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/second-brain-sync"
