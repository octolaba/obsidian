# EPUB Reader with TTS

Reads EPUB files inside Obsidian in scrolling or paginated mode, with a clickable table of contents, in-book search and automatic restoration of the last chapter and scroll position. Text-to-speech uses the system or Google voices and highlights each sentence as it is read, with playback from the cursor, immediate speed changes and paragraph skipping.
