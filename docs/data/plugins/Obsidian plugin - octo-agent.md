# Octo Agent

Octo Agent embeds a coding assistant in the vault and makes the vault its working directory, so the assistant can read, write, edit and search files, run bash commands and execute multi-step workflows. Inline edits arrive with a word-level diff, and the assistant is driven through slash commands and Skills, @mentions, instruction mode and multi-tab conversations.
