# Note Linker

Scans the vault for text that matches the names or aliases of other notes and gathers the resulting link candidates. The matches are presented as a selectable list for review, and the chosen ones are turned into links between the notes.

```cue
plugin: {
    id:     "obisidian-note-linker"
    name:   "Note Linker"
    author: "alexw00"
    repo:   "alexw00/obsidian-note-linker"

    html_url:    "https://community.obsidian.md/plugins/obisidian-note-linker"
    github_url:  "https://github.com/alexw00/obsidian-note-linker"
    description: "Automatically find and create new links between notes."
    about:       "Scan your vault for references to other note names or aliases and gather suggested link targets. Present a selectable list of matches for review. Create chosen links between notes."

    stats: {
        downloads:  50707
        updated_at: 1765132196000
    }
}
```
