# Local Agent Office

Turns the vault into a team of AI agents where each agent is itself a Markdown note. Personas are authored as notes, then think and hand off to one another in a spatial office view, chat inline, and crystallize conversations back into notes. Agents that have been approved can act on the vault, and the recorded text states that data stays local and that the user supplies their own API key.
