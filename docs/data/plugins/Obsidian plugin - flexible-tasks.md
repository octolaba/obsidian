# Flexible Tasks

Makes checkboxes inside Markdown table cells and lists interactive, writing each toggle back to the source file. A right-click menu sets custom single-character statuses such as done, in progress, cancelled and forwarded, which render in Live Preview and Reading view with the current theme's styling.

```cue
plugin: {
    id:     "flexible-tasks"
    name:   "Flexible Tasks"
    author: "KB Benton"
    repo:   "kbcmdba/kbcmdba-flexible-obsidian-tasks"

    html_url:    "https://community.obsidian.md/plugins/flexible-tasks"
    github_url:  "https://github.com/kbcmdba/kbcmdba-flexible-obsidian-tasks"
    description: "Interactive task checkboxes in Markdown table cells and lists, with custom statuses such as done, in progress, cancelled, forwarded, and more, styled by your theme. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Enable interactive checkboxes inside Markdown table cells and write toggles back to the source file. Add a right-click status menu to set custom single-character statuses (e.g. [x], [/], [-], [?], [!]) that render in Live Preview and Reading view using your theme."
```
