# Timebox daily

Timebox daily creates structured daily TimeBox notes divided into morning, afternoon and evening time blocks. Unfinished tasks roll forward automatically while completed items are recorded, and a persistent brain dump is kept alongside the blocks. Today's TimeBox can be opened on startup.

```cue
plugin: {
    id:     "timebox-daily"
    name:   "Timebox daily"
    author: "rvzenteno"
    repo:   "rvzenteno/O-Timebox-Daily"

    html_url:    "https://community.obsidian.md/plugins/timebox-daily"
    github_url:  "https://github.com/rvzenteno/O-Timebox-Daily"
    description: "Smart daily timeboxing with automatic task rollover and structured planning. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create structured daily TimeBox notes with clear morning, afternoon, and evening time blocks. Roll unfinished tasks forward automatically and record completed items. Maintain a persistent brain dump and open today’s TimeBox on startup for quick access."

    stats: {
        downloads:  206

}
```
