# Journaling

Journaling displays daily notes in a continuous journal-like format similar to Logseq, consolidating dated notes from several folders. The date format, journal filename, sort order between newest and oldest, and the update interval are all configurable.

```cue
plugin: {
    id:     "journaling"
    name:   "Journaling"
    author: "ordeeper"
    repo:   "ordeeper/obsidian-journaling-plugin"

    html_url:    "https://community.obsidian.md/plugins/journaling"
    github_url:  "https://github.com/ordeeper/obsidian-journaling-plugin"
    description: "View daily notes in a journal-like format, similar to Logseq. It enhances note organization and facilitates better reflection by consolidating daily notes into a continuous journaling view."
    about:       "View daily notes in a continuous journal-like format similar to Logseq. Consolidate dated notes from multiple folders, set custom date formats and journal filename, filter by newest or oldest, and configure update intervals."

    stats: {
        downloads:  9337
        updated_at: 1735064565000
    }
}
```
