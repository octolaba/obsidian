# History Today

History Today surfaces notes from this day in previous years by reading dates out of the notes themselves. Which folders are included and the display language are configurable. An entry uses the note's metadata date when one exists and otherwise falls back to the file creation time.

```cue
plugin: {
    id:     "history-today"
    name:   "History Today"
    author: "yaob1990"
    repo:   "yaob1990/obsidian-history-today"

    html_url:    "https://community.obsidian.md/plugins/history-today"
    github_url:  "https://github.com/yaob1990/obsidian-history-today"
    description: "View and review your historical notes from this day across previous years"
    about:       "Display historical events that happened on this day by pulling dates from your notes. Filter which folders to include and set the display language; events use the note's metadata date when available or fall back to file ctime."

    stats: {
        downloads:  752
        updated_at: 1731852699000
    }
}
```
