# Emoji selector

Inserts custom emoji either by typing a trigger sequence such as two colons or from a searchable selector panel. OWO emoji packs and local images can be loaded, insertion templates and CSS styles are configurable, and search accepts regular expressions or fuzzy matching.

```cue
plugin: {
    id:     "emoji-selector"
    name:   "Emoji selector"
    author: "infinitesum"
    repo:   "infinitesum/obsidian-emoji-selector"

    html_url:    "https://community.obsidian.md/plugins/emoji-selector"
    github_url:  "https://github.com/infinitesum/obsidian-emoji-selector"
    description: "Insert custom emojis with quick search, auto-suggestions, and customizable templates."
    about:       "Insert custom emojis into notes by typing trigger characters (e.g., ::) or opening a searchable selector panel. Load OWO emoji packs or local images, apply custom insertion templates and CSS styles, and find emojis with regex or fuzzy search."

    stats: {
        downloads:  1405
        updated_at: 1765457160000
    }
}
```
