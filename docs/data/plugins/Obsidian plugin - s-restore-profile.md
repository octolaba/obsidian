# S-Restore Profile

S-Restore Profile exports the community plugins and themes of a vault into a single portable JSON profile and reinstalls them in bulk elsewhere. Importing that profile into another vault auto-installs the listed items, activates the recorded active theme, and skips anything already installed, with verbose restore logs available.

```cue
plugin: {
    id:     "s-restore-profile"
    name:   "S-Restore Profile"
    author: "Stepheson Alves"
    repo:   "stepheson/s-restore-profile_obsidian-plugin"

    html_url:    "https://community.obsidian.md/plugins/s-restore-profile"
    github_url:  "https://github.com/stepheson/s-restore-profile_obsidian-plugin"
    description: "Bulk reinstall your community plugins from your existing plugin list. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync and bulk-reinstall community plugins and themes across vaults or machines using a single portable JSON profile. Export your current setup, import it into another vault to auto-install and activate the active theme, skip already-installed items, and monitor verbose restore logs."

    stats: {
        downloads:  109
        updated_at: 1782221653000
    }
}
```
