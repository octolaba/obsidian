# Anki Heading Sync

Turns Obsidian headings into Anki flashcards, using the heading text, H4 recommended, as the question. Four card types are generated: basic question and answer, nested-list question and answer, single cloze and all cloze. Files or the whole vault can be converted in batches, decks are mapped by file or folder, and backlinks and tags can optionally be synced.
