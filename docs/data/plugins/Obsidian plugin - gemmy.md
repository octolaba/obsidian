# Gemmy

Displays an Unhelper that blurts out remarks at random or appears to nudge the writer when typing stops. Random and writing modes decide how those interruptions arrive. The index description records it as an April Fool's plugin published by Obsidian in 2023.

```cue
plugin: {
    id:     "gemmy"
    name:   "Gemmy"
    author: "silver"
    repo:   "ericaxu/gemmy"

    html_url:    "https://community.obsidian.md/plugins/gemmy"
    github_url:  "https://github.com/ericaxu/gemmy"
    description: "Obsidian Unhelper. 2023 April Fool's plugin brought to you by Obsidian."
    about:       "Display a whimsical Unhelper that randomly blurts remarks or pops up to nudge you when you stop typing. Choose random or writing modes to inject playful interruptions that may, unexpectedly, spark creativity."
```
