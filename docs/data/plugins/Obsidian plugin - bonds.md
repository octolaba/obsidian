# Bonds

Bonds treats a link as a note in its own right: a connection becomes a standalone bond note carrying its own content, type and history. Each bond is rendered automatically in both notes it joins, so information belonging to the relationship lives in one place and appears at both ends.

```cue
plugin: {
    id:     "bonds"
    name:   "Bonds"
    author: "Zak"
    repo:   "zakiruz/synapse"

    html_url:    "https://community.obsidian.md/plugins/bonds"
    github_url:  "https://github.com/zakiruz/synapse"
    description: "Links as first-class notes. Bonds between atoms carry their own content, rendered on both ends. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Make links first-class citizens by turning connections into standalone bond notes that hold content, type, and history. Render bonds automatically in both endpoint notes so relationship-specific information lives in one place and appears where it's relevant."

}
```
