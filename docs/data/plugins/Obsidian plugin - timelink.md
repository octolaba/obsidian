# TimeLink

TimeLink connects calendar, timeline and kanban board views with a board-level Gantt so dated work and schedules are handled in one place. Notes and events can be created from kanban cards with backlinks kept in sync, per-board colors applied, and tasks reviewed from daily views up to a year-based Gantt overview.
