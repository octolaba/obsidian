# Flowcharts

Renders flowcharts from flowchart.js markup written in dedicated code blocks. Styles and element appearance are configurable, so the diagrams are drawn inside the note itself.

```cue
plugin: {
    id:     "flowcharts"
    name:   "Flowcharts"
    author: "land0r"
    repo:   "land0r/obsidian-flowchart-plugin"

    html_url:    "https://community.obsidian.md/plugins/flowcharts"
    github_url:  "https://github.com/land0r/obsidian-flowchart-plugin"
    description: "Render flowcharts using flowchart.js markup."
    about:       "Render flowcharts in Obsidian using flowchart.js syntax via dedicated code blocks. Customize styles and element appearance to craft interactive, visually appealing diagrams directly inside your notes."

    stats: {
        downloads:  4040
        updated_at: 1740340515000
    }
}
```
