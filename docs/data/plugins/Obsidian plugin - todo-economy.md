# Todo Economy

Keeps tasks as checkboxes in a single Markdown file and drives them from an ASCII interface in Obsidian's right sidebar. Completed tasks earn points, which are spent on rewards whose prices are computed from the real monthly point income rather than set by hand. Higher-priority items pay more, while harmful ones cost more and are capped.

    id:     "todo-economy"
    name:   "Todo Economy"
    author: "Denis S"
    repo:   "solidens/obsidian-todo-economy"

    github_url:  "https://github.com/solidens/obsidian-todo-economy"
    description: "Тудушник, где выполненные задачи приносят баллы, а баллы тратятся на награды. Цены не выдуманы: система решает их из твоего реального месячного прихода. Интерфейс — ASCII. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Ведите задачи как галочки в одном Markdown‑файле и управляйте ими из ASCII‑интерфейса в правой панели Obsidian. Получайте баллы за выполненные дела и тратьте их на награды с ценами, вычисленными по вашему реальному месячному доходу очков; приоритеты дают больше, вредное дороже и лимитировано."
