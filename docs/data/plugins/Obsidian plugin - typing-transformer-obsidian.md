# Typing Transformer

Applies configurable auto-formatting as text is typed, driven by input conversion, deletion and selection rules. Those rules insert auto-pairs, expand abbreviations, convert character widths, adjust spacing between languages and symbols, and control where the cursor lands after an edit.
