# ExcaVelo

Rewrites raw memos into structured notes — meeting minutes, one-to-one summaries, decision records or custom templates — using Claude through a Claude Code subscription, an Anthropic API key, or an OpenAI-compatible endpoint. The original memo is preserved, default and per-note context is injected from context callouts, and the markdown template is chosen from the plugin's templates folder. The output is previewed before it is saved or appended.
