# Emotion Picker

Presents a list of emotions, either customizable or a sensible default, and pastes the one clicked into the note at the cursor. Formatting options recorded for it include adding a comma, wrapping the entry as a link, inserting it as a tag, or capitalizing it, which suits journal and mood tracking.

```cue
plugin: {
    id:     "obsidian-emotion-picker"
    name:   "Emotion Picker"
    author: "Daniel Nikolaev"
    repo:   "dartungar/obsidian-emotion-picker"

    html_url:    "https://community.obsidian.md/plugins/obsidian-emotion-picker"
    github_url:  "https://github.com/dartungar/obsidian-emotion-picker"
    description: "Choose an emotion from a list to insert into a note."
    about:       "Insert emotions into notes from a customizable list or a sensible default. Click an emotion to paste it at the cursor and apply formatting like adding a comma, wrapping as [[link]], inserting as #tag, or capitalizing for journal and mood tracking."

}
```
