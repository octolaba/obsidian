# IRIS-Transcript

IRIS-Transcript turns a YouTube URL into a Markdown note holding the transcript, an interactive mindmap with zoom, pan and collapsible nodes, and an optional summary generated by an LLM. The transcript comes from YouTube subtitles rather than a paid API, and metadata is stored in frontmatter for Dataview to index. The mindmap output is Markmap-compatible.

```cue
plugin: {
    id:     "iris-transcript"
    name:   "IRIS-Transcript"
    author: "Othman Ben Brahim"
    repo:   "othman-benbrahim/iris-transcript-obsidian"

    html_url:    "https://community.obsidian.md/plugins/iris-transcript"
    github_url:  "https://github.com/othman-benbrahim/iris-transcript-obsidian"
    description: "Transcrit une vidéo YouTube, la structure en mindmap (compatible Markmap) et en produit un résumé, dans une note Markdown. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Transform a YouTube URL into a Markdown note containing a transcript, an interactive mindmap (zoom, pan, collapsible nodes), and an optional LLM-generated summary. Use YouTube subtitles (free, no API) and store metadata in frontmatter for Dataview indexing."

    stats: {
        downloads:  77
        updated_at: 1782632689000
    }
}
```
