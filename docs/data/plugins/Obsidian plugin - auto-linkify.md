# Auto Linkify

Auto Linkify turns a pasted URL into a Markdown link by fetching the title of the page behind it. The formatted link, carrying that page title and the address, is inserted at the cursor.

```cue
plugin: {
    id:     "auto-linkify"
    name:   "Auto Linkify"
    author: "jiawei-hong"
    repo:   "jiawei-hong/obsidian-linkify"

    html_url:    "https://community.obsidian.md/plugins/auto-linkify"
    github_url:  "https://github.com/jiawei-hong/obsidian-linkify"
    description: "Automatically formats pasted URLs into Markdown links. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert pasted URLs into Markdown links by fetching each page's title. Insert formatted [Page Title](URL) links at the cursor when you paste a URL."

    stats: {
        downloads:  141
        updated_at: 1776001141000
    }
}
```
