# StandardForm

Fenced code blocks labeled standardform are rendered as styled standard-form logical reconstructions. The parser reads numbered premises, optional identifiers ending in a colon or a period, escaped punctuation, blank or labeled conclusions, and single or double inference lines. The recorded description positions the result for philosophy, logic and argument reconstruction.
