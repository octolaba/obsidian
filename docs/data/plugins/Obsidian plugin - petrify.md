# Petrify

Petrify converts handwritten notes into searchable Excalidraw or Markdown files in the vault using OCR. Handwriting can be preserved on an Excalidraw canvas, or the text extracted so it can be searched, linked and annotated. The recorded inputs list support for Viwoods note files, Supernote X-series note files and PDFs.

```cue
plugin: {
    id:     "petrify"
    name:   "Petrify"
    author: "jo-minjun"
    repo:   "jo-minjun/petrify"

    html_url:    "https://community.obsidian.md/plugins/petrify"
    github_url:  "https://github.com/jo-minjun/petrify"
    description: "Convert handwriting notes to Excalidraw or Markdown with OCR support to unify your knowledge base. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert handwritten notes into searchable Excalidraw or Markdown files in your Obsidian vault using OCR. Preserve handwriting on Excalidraw canvases or extract text for search, linking, and annotation; supports Viwoods (.note), Supernote X-series (.note), and PDFs."
```
