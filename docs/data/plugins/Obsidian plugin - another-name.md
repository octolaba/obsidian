# Another Name

Displays an alternate name beneath a file's inline title, read from the another-name frontmatter attribute. It is meant for translations, secondary names or aliases, keeping the title itself concise. Inline titles must be enabled for the secondary name to appear.

```cue
plugin: {
    id:     "another-name"
    name:   "Another Name"
    author: "eurfelux"
    repo:   "eurfelux/obsidian-another-name-plugin"

    html_url:    "https://community.obsidian.md/plugins/another-name"
    github_url:  "https://github.com/eurfelux/obsidian-another-name-plugin"
    description: "Add an another name after your inline title!"
    about:       "Display an alternate name beneath your file's inline title using the frontmatter attribute another-name. Attach translations, secondary names, or aliases to keep titles concise and readable. Enable inline titles to show the secondary name under the main title."

        downloads:  555

}
```
