# Simple Timestamp

Simple Timestamp writes the current date and time into a frontmatter property whenever a Markdown note is created or saved. The property name and date format are configurable, missing properties can be created on demand, and folders or templates excluded. It applies a cooldown, skips Excalidraw files, and operates quietly without moving the cursor or causing update loops.

```cue
plugin: {
    id:     "simple-timestamp"
    name:   "Simple Timestamp"
    author: "Keven B."
    repo:   "mkauto/obsidian-simple-timestamp"

    html_url:    "https://community.obsidian.md/plugins/simple-timestamp"
    github_url:  "https://github.com/mkauto/obsidian-simple-timestamp"
    description: "Automatically writes the current date/time to a frontmatter property every time a note is created or saved. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Stamp a configurable frontmatter property with the current date/time whenever a Markdown note changes. Choose property name and date format, opt into creating missing properties, exclude folders or templates, set a cooldown, and skip Excalidraw files while operating quietly without moving the cursor or causing update loops."
```
