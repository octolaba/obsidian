# Auto Reveal in Explorer

Auto Reveal in Explorer reveals the active file in the File Explorer when a tab is switched or a note is opened, without moving keyboard focus out of the editor. Keeping focus in the editor prevents accidental file actions, and the reveal can also be run manually or tuned with an adjustable debounce; it works on desktop and mobile.

    id:     "auto-reveal-in-explorer"
