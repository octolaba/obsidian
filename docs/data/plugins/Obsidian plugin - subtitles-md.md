# Subtitles MD

Subtitle files in srt and vtt form are read as searchable Markdown, either converted into a note or opened in a read-only transcript view. Transcripts are also embedded inline in a note through a transcript code block. The output is plain text, so it stays searchable, linkable and ready for annotation.

```cue
plugin: {
    id:     "subtitles-md"
    name:   "Subtitles MD"
    author: "Pedro Fuentes"
    repo:   "pedrofuentes/obsidian-subtitles-md"

    html_url:    "https://community.obsidian.md/plugins/subtitles-md"
    github_url:  "https://github.com/pedrofuentes/obsidian-subtitles-md"
    description: "An Obsidian plugin that reads .srt/.vtt transcripts as readable, searchable Markdown. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Read .srt and .vtt subtitle files as readable, searchable Markdown notes or open them in a read-only transcript view. Convert files into Markdown notes, embed transcripts inline with transcript code blocks, and keep plain-text output that's searchable, linkable, and ready for annotation."

    stats: {
        downloads:  194
        updated_at: 1783548361000
    }
}
```
