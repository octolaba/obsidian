# AI Summarize

Summarizes notes with OpenAI models, from GPT-3.5 through GPT-5 and reasoning models, streaming the result and chunking large documents. Summaries can be inserted inline, below the selection, or into frontmatter, with multiple profiles and custom prompts. Requests can be cancelled, and overlapping requests are prevented.
