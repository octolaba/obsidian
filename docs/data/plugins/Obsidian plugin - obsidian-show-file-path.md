# Show Current File Path

The full path of the active file is shown in the status bar and follows whichever pane has focus, with icons for each folder and file and an option to hide the file name. Clicking the item or running the copy command puts the absolute or relative path on the clipboard. The status bar is not visible on mobile, although the copy command works on Android.

```cue
plugin: {
    id:     "obsidian-show-file-path"
    name:   "Show Current File Path"
    author: "ravimashru"
    repo:   "ravimashru/obsidian-show-file-path"

    html_url:    "https://community.obsidian.md/plugins/obsidian-show-file-path"
    github_url:  "https://github.com/ravimashru/obsidian-show-file-path"
    description: "Show the full path of the currently open file in the status bar."
    about:       "Show the full file path of the active file in the status bar, updating to the pane that has focus. Display icons for each folder and file, toggle the file name, and click or use the copy command to copy absolute or relative paths to the clipboard. Note the status bar isn't visible on mobile; the copy command works on Android."

    stats: {
```
