# Flashcard Generator

Generates flashcards, quizzes and questions from notes using OpenAI or local language models. Generated questions can be validated or refined before they are saved. Quizzes sync with the Spaced Repetition plugin so that they enter a scheduled review.

```cue
plugin: {
    id:     "flashcard-gen"
    name:   "Flashcard Generator"
    author: "chloedia"
    repo:   "chloedia/Obsidian_Quiz_Generator"

    html_url:    "https://community.obsidian.md/plugins/flashcard-gen"
    github_url:  "https://github.com/chloedia/Obsidian_Quiz_Generator"
```
