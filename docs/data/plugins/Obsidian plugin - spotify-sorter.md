# Spotify Sorter

Liked Spotify tracks that belong to no playlist are collected and saved as a dated Markdown note in the vault. The run is started from the command palette or the ribbon on desktop and produces a report file named for the day, listing each unorganized track.

```cue
plugin: {
    id:     "spotify-sorter"
    name:   "Spotify Sorter"
    author: "fleker"
    repo:   "fleker/spotify-organizer-for-obsidian"

    html_url:    "https://community.obsidian.md/plugins/spotify-sorter"
    github_url:  "https://github.com/fleker/spotify-organizer-for-obsidian"
    description: "Find Liked Songs that aren't in any of your Spotify playlists and save them as a note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Find liked Spotify tracks that aren't in any playlist and save them as a dated Markdown note in your vault. Run from the command palette or ribbon on Obsidian desktop to generate a \"Spotify Unorganized Tracks YYYY-MM-DD.md\" report listing each unorganized track."

    stats: {
        downloads:  89
        updated_at: 1778627957000
    }
}
```
