# iDoRecall

iDoRecall creates spaced-repetition flashcards, called recalls, linked to exact locations in notes. Practicing a recall can open its source note with the linked text highlighted, so the surrounding context is at hand when an answer does not come to mind.

```cue
plugin: {
    id:     "idorecall"
    name:   "iDoRecall"
    author: "idorecall"
    repo:   "idorecall/idorecall"

    html_url:    "https://community.obsidian.md/plugins/idorecall"
    github_url:  "https://github.com/idorecall/idorecall"
    description: "Create recalls from your notes."
    about:       "Create spaced-repetition flashcards (recalls) linked to exact locations in your Obsidian notes. Practice recalls and open the source note with the linked text highlighted to refresh context when you struggle to remember."
```
