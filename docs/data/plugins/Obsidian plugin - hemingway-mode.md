# Hemingway Mode

Hemingway Mode prevents editing and lets text be appended only at the end of the current note. Cursor movement, backspace, cut shortcuts and other editing keys are disabled while it is active, and a command turns the mode on and off.

```cue
plugin: {
    id:     "hemingway-mode"
    name:   "Hemingway Mode"
    author: "jobedom"
    repo:   "jobedom/obsidian-hemingway-mode"

    html_url:    "https://community.obsidian.md/plugins/hemingway-mode"
    github_url:  "https://github.com/jobedom/obsidian-hemingway-mode"
    description: "Prevents any editing, only letting you write ahead."
    about:       "Force yourself to write without editing by disabling cursor movement, backspace, cut shortcuts and other editing keys. Allow only appending text at the end of the current note and toggle Hemingway Mode on or off via a command."

    stats: {
        downloads:  1629

}
```
