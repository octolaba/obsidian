# Kindle Highlights

Syncs and resyncs Kindle book highlights and notes into the vault, either from the Amazon Kindle Reader cloud using an Amazon login or from a device's My Clippings file. Syncing is incremental with clear progress and cancellation, book metadata is enriched, and Nunjucks templates control how highlights are formatted.

    id:     "obsidian-kindle-plugin"
