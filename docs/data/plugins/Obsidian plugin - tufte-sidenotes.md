# Tufte Sidenotes

Renders Markdown footnotes and sidenote or marginnote callouts as Tufte-style sidenotes in the margin gutter during Reading view. The editor stays single-column while the notes are displayed in the page margin. It is meant to be paired with the Tufte theme, whose gutter layout it relies on.

```cue
plugin: {
    id:     "tufte-sidenotes"
    name:   "Tufte Sidenotes"
    author: "PleiadesM"
    repo:   "pleiadesm/Tufte-Sidenote"

    html_url:    "https://community.obsidian.md/plugins/tufte-sidenotes"
    github_url:  "https://github.com/pleiadesm/Tufte-Sidenote"
    description: "Renders Tufte sidenotes and marginnotes in Reading view while keeping the editor single-column. - This plugin has not been manually reviewed by Obsidian staff."
```
