# Trader Journal

Records backtest and live trades as JSON blocks inside daily per-symbol Markdown journals. Trades render as readable cards in Reading View, and entries are added or edited through modals or the sidebar calendar. Filtered economic events are shown, holding time and daily statistics are calculated automatically, and pasted images are previewed.

```cue
plugin: {
    id:     "trader-journal"
    name:   "Trader Journal"
    author: "Lam Phuc Hai"
    repo:   "hailp-vn38/trader-journal-plugin"

    html_url:    "https://community.obsidian.md/plugins/trader-journal"
    github_url:  "https://github.com/hailp-vn38/trader-journal-plugin"
    description: "Record backtest and live trades with plans, statistics, images, and an economic calendar. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Log backtest and live trades into daily per-symbol Markdown journals as JSON blocks. Render trades as readable cards in Reading View and add or edit entries via modals or the sidebar calendar. See filtered economic events, auto-calc holding time and daily stats, and preview pasted images."
}
```
