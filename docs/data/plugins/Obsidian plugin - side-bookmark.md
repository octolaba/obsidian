# Side Bookmark

Side Bookmark puts a web browser and a bookmark manager in Obsidian's sidebar. Bookmarks are organized into folders and reordered by drag-and-drop, external links in notes can open in the sidebar instead of the system browser, and bookmarks and settings persist in the vault.

```cue
plugin: {
    id:     "side-bookmark"
    name:   "Side Bookmark"
    author: "bcs"
    repo:   "bcs1037/side-bookmark"

    html_url:    "https://community.obsidian.md/plugins/side-bookmark"
    github_url:  "https://github.com/bcs1037/side-bookmark"
    description: "A sidebar bookmark browser. Browse websites and manage bookmarks right in the sidebar. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Browse websites directly inside Obsidian's sidebar with a built-in web browser. Save and organize bookmarks into folders, reorder them via drag-and-drop, and open external links from notes in the sidebar instead of your system browser; bookmarks and settings persist in your vault."

    stats: {
        downloads:  485
        updated_at: 1778663876000
    }
}
```
