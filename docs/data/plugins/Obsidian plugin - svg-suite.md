# SVG Suite

Views and edits SVG files with pan and zoom, a live source editor with syntax highlighting, PNG export, background presets, and hover controls for SVGs embedded in notes. The recorded About text describes a dedicated viewer that opens SVG files automatically, a syntax-highlighted XML source editor, and export of the current view as PNG at up to 4x.
