# StepVox

A voice assistant listens, acts on the vault and replies aloud through a streamed pipeline of microphone input, speech recognition, a language model and speech synthesis. Spoken commands query, read, create, append, update, move and open notes in single-shot or multi-turn sessions with barge-in, and optional web search and several model providers can be enabled. The recorded description names StepFun speech services with a configurable model from StepFun, OpenAI or Anthropic, and states that API keys are required.
