# Screwdriver

This plugin puts arbitrary files in and out of the vault. Files from specified directories can be dumped using filters and ignore rules and exported into a single Markdown file, and dumped files can be put into any path inside the vault, including hidden directories. The recorded text warns that the export can be very large and should be excluded from processing by other plugins.

```cue
plugin: {
    id:     "obsidian-screwdriver"
    name:   "Screwdriver"
    author: "vrtmrz"
    repo:   "vrtmrz/obsidian-screwdriver"

    html_url:    "https://community.obsidian.md/plugins/obsidian-screwdriver"
    github_url:  "https://github.com/vrtmrz/obsidian-screwdriver"
    description: "Utility to put any files in and out under your vault."
    about:       "Dump files from specified directories using filters and ignore rules and export them into a single Markdown file. Put dumped files into any path inside your vault (including hidden directories); note the export can be very large, so exclude it from other plugin processing."

    stats: {
        downloads:  5090

    }
}
```
