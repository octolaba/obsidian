# Lazy Album

Lazy Album renders images as a masonry, or waterfall, gallery drawn from web URLs, individual files or entire folders. Columns, gaps and pagination are configurable, individual images can be excluded, hover captions come from a Path and Caption form, and paths are repaired automatically when files are moved or renamed.

```cue
plugin: {
    id:     "lazy-album"
    name:   "Lazy Album"
    author: "somehowitworks"
    repo:   "somehowitworks/lazy-album"

    html_url:    "https://community.obsidian.md/plugins/lazy-album"
    github_url:  "https://github.com/somehowitworks/lazy-album"
    description: "Render images as a masonry gallery. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display images in a Masonry (waterfall) layout from multiple sources: web URLs, individual files, or entire folders. Customize columns, gaps and pagination; exclude specific images, show hover captions via \"Path | Caption\", and auto-repair paths when files are moved or renamed."
```
