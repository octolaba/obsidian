# Command Alias

Command Alias gives an alias to any Obsidian command, shortening or translating its name. The command palette searches those aliases so a command can be found and run through them, and aliases are edited or removed in the settings.

```cue
plugin: {
    id:     "obsidian-command-alias-plugin"
    name:   "Command Alias"
    author: "yajamon"
    repo:   "yajamon/obsidian-command-alias-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-command-alias-plugin"
    github_url:  "https://github.com/yajamon/obsidian-command-alias-plugin"
    description: "Give aliases to commands."
    about:       "Assign aliases to any Obsidian command to shorten or translate command names. Search the command palette with aliases to quickly find and run commands. Edit or remove aliases from settings as needed."

    stats: {
        downloads:  6810
        updated_at: 1718291479000
    }
}
```
