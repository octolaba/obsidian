# Code Block Plus

Adds a Siyuan-style header to every code block, with a clickable language pill, a copy button and consistent styling in editing and preview modes. The language picker is searchable and holds presets alongside custom entries, and a run of Chinese punctuation opens a code block. Selection is staged so the first select takes the block and the second takes everything, fences can be collapsed, controls appear on hover, and touch input is supported in a bilingual interface.
