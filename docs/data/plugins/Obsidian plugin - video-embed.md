# Media Embed

Media Embed converts a YouTube link pasted on an empty line into the embed format you prefer, choosing between markdown, iframe and div output. The conversion happens on paste, with no command and no shortcut.

```cue
plugin: {
    id:     "video-embed"
    name:   "Media Embed"
    author: "punkyard"
    repo:   "punkyard/obsidian-video-embed"

    html_url:    "https://community.obsidian.md/plugins/video-embed"
    github_url:  "https://github.com/punkyard/obsidian-video-embed"
    description: "Automatically converts pasted YouTube links into your preferred embed format on an empty line. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Paste a YouTube link on an empty line to automatically convert it into your chosen embed format (markdown, iframe, or div) — no command no shortcut."

    stats: {
        downloads:  705
        updated_at: 1782342065000
    }
}
```
