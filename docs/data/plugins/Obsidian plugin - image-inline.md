# Image Inline

Embeds pasted or dropped images inline as base64 instead of attachment files, while large files are still kept as attachments. Large images can be resized automatically or their originals saved to a media folder, and images can be exported or batch-converted to base64. The actions run from context menus or the command palette.

```cue
plugin: {
    id:     "image-inline"
    name:   "Image Inline"
    author: "zackaryw"
    repo:   "zackaryw/obsidian-image-inline"

    html_url:    "https://community.obsidian.md/plugins/image-inline"
    github_url:  "https://github.com/zackaryw/obsidian-image-inline"
    description: "Paste your image without attachment files"
    about:       "Inline images in notes by pasting or dropping them, embedding small images as base64 while keeping large files as attachments. Resize large images automatically or save originals to the media folder, export or batch-convert images to base64, and run actions from context menus or the command palette."
```
