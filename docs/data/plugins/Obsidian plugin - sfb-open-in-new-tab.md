# Open in New Tab

Open in New Tab forces files to open in a new tab instead of replacing the current one, covering the Quick Switcher, command palette, bookmarks, search results, backlinks, graph view, sidebar clicks and markdown links. A file that is already open is focused rather than duplicated, and heading or block links inside the same file stay in the current tab. An optional synced split preview pairs an edit pane with a reading pane.
