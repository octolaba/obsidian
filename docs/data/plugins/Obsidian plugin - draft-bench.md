# Draft Bench

Manages writing projects, scenes and versioned drafts as plain Markdown files whose metadata lives in frontmatter, which keeps them usable from Bases. Per-scene draft history is kept as real files, so snapshots can be compared side by side. Scenes may sit anywhere in the vault, and a form-based Builder compiles them into a manuscript without requiring JavaScript.
