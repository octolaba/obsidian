# Oura Ring

This plugin imports Oura Ring data into a note, adding sleep, readiness, activity and body metrics for a chosen date. The data is fetched from an Oura account with a personal access token and inserted automatically for pages dated in year-month-day form, or for today's date.

```cue
plugin: {
    id:     "obsidian-oura-plugin"
    name:   "Oura Ring"
    author: "kinabalu"
    repo:   "kinabalu/obsidian-oura-plugin"

    html_url:    "https://community.obsidian.md/plugins/obsidian-oura-plugin"
    github_url:  "https://github.com/kinabalu/obsidian-oura-plugin"
    description: "Import Oura Ring data into a note."
    about:       "Add Oura Ring sleep, readiness, activity, and body metrics to any Obsidian note for a chosen date. Fetch data from your Oura account using a personal access token and insert metrics automatically for pages dated YYYY-MM-DD or for today's date."

}
```
