# Quick Tagger

Adds and removes tags through a searchable interface, the command palette or hotkeys. Several notes are tagged at once from a right-click, and favorite tags are starred for quick access. Ribbon icons and commands toggle a tag on the active note.

```cue
plugin: {
    id:     "quick-tagger"
    name:   "Quick Tagger"
    author: "gorkycreator"
    repo:   "gorkycreator/obsidian-quick-tagger"

    html_url:    "https://community.obsidian.md/plugins/quick-tagger"
    github_url:  "https://github.com/gorkycreator/obsidian-quick-tagger"
    description: "Add and remove tags quickly. Tag search results, bulk tag, and add dedicated buttons/commands for your favorites!"
    about:       "Add tags to notes using a searchable GUI, command palette, or hotkeys. Tag multiple notes in bulk via right-click and star favorite tags for quick access. Toggle tags from ribbon icons or commands to update the active note."

    stats: {
        downloads:  17522
        updated_at: 1772428106000
    }
}
```
