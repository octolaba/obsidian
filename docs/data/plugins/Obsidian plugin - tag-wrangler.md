# Tag Wrangler

Tag Wrangler adds a context menu for tags in the Tags view and in note bodies. From it a tag page can be opened or created, searches run or refined, and tags renamed or reorganized, including subtags, by menu or by drag and drop. Tags can also be dragged into an editor as text, hierarchies collapsed or expanded, and a random tagged note opened.

    id:     "tag-wrangler"
    name:   "Tag Wrangler"
    author: "pjeby"
    repo:   "pjeby/tag-wrangler"
