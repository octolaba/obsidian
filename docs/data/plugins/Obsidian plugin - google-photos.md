# Google Photos

Inserts photos from Google Photos into notes through the official Google Photos Picker API. Thumbnails are downloaded locally and Markdown image links generated from customizable templates and filenames, with links back to the original photo and configurable save locations.

```cue
plugin: {
    id:     "google-photos"
    name:   "Google Photos"
    author: "Alan Grainger"
    repo:   "alangrainger/obsidian-google-photos"

    html_url:    "https://community.obsidian.md/plugins/google-photos"
    github_url:  "https://github.com/alangrainger/obsidian-google-photos"
    description: "Google Photos integration."
    about:       "Insert photos from Google Photos into your notes using the official Google Photos Picker API. Download thumbnails locally and generate markdown image links with customizable templates and filenames. Link back to original photos and save images into configurable locations for flexible file organization."

    stats: {
        downloads:  17179
        updated_at: 1751419708000
    }
}
```
