# Markdown Tree

Markdown Tree turns a simple indented list, written with tabs, spaces and line breaks, into a rendered directory tree. The output is a filesystem-style ASCII tree showing nested folders and files, so a directory structure can be read at a glance inside a note.

```cue
plugin: {
    id:     "markdown-tree"
    name:   "Markdown Tree"
    author: "carvah"
    repo:   "carvah/markdown-tree-plugin"

    html_url:    "https://community.obsidian.md/plugins/markdown-tree"
    github_url:  "https://github.com/carvah/markdown-tree-plugin"
    description: "Create a beautiful and intuitive directory tree using Markdown-oriented code style using tabs, spaces and enters."
    about:       "Create prettier directory trees from simple indented or space/tab-separated lists in your Markdown files. Render clean, filesystem-style ASCII trees showing nested folders and files for easy visual navigation of your directory structure."

    stats: {
        downloads:  8354

}
```
