# Traystone

Runs Obsidian from the system tray: closing a window hides it, the app keeps running in the background, and auto-start at login can be enabled. Global hotkeys and the tray menu create quick notes and toggle window focus, and the Dock or taskbar icon can be hidden. The tray icon and tooltip are customisable, and the plugin quits cleanly during system shutdown.

```cue
plugin: {
    id:     "traystone"
    name:   "Traystone"
    author: "tinswangtao-web"
    repo:   "tinswangtao-web/traystone"

    html_url:    "https://community.obsidian.md/plugins/traystone"
    github_url:  "https://github.com/tinswangtao-web/traystone"
    description: "将 Obsidian 运行到系统托盘，支持自定义窗口管理和全局快速笔记 - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Run Obsidian from the system tray to hide windows on close, keep the app running in the background, and enable auto-start at login. Use global hotkeys and the tray/menu to create quick notes and toggle window focus, and hide or show Dock/taskbar icons. Quit cleanly during system shutdown and customize the tray icon and tooltip."
```
