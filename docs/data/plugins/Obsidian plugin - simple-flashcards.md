# Simple Flashcards

Simple Flashcards writes RemNote-style flashcards inline, using block markers and simple delimiters for front and back, bidirectional, cloze and multiline answers. Cards are organized into decks through inline tags and reviewed by deck, by the current note or across the whole vault, with optional spaced repetition.
