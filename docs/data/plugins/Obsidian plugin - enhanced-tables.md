# Enhanced tables

Adds sorting, filtering, pagination and per-column formatting to ordinary Markdown tables. A YAML block placed above a table declares the controls, including date and number formats, enum columns, hidden columns and custom cell formatters, while the data itself stays plain editable Markdown.

```cue
plugin: {
    id:     "enhanced-tables"
    name:   "Enhanced tables"
    author: "pistacchio"
    repo:   "pistacchio/obsidian-enhanced-tables"

    html_url:    "https://community.obsidian.md/plugins/enhanced-tables"
    github_url:  "https://github.com/pistacchio/obsidian-enhanced-tables"
    description: "Add programmable controls to selected tables."
    about:       "Add sorting, filtering, pagination and per-column formatting to standard Markdown tables, including date and number formats, enum columns, hidden columns and custom cell formatters. Apply a YAML block above any table to keep data as simple, editable Markdown while adding dynamic controls."

    stats: {
        downloads:  9630
        updated_at: 1710229811000
    }
}
```
