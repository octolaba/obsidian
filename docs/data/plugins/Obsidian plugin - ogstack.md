# ogstack

ogstack runs AI skills inside Obsidian to brainstorm, research, plan and write with linked notes as context. It walks the note graph, scores linked notes by relevance and recency, assembles context windows, and streams model output directly into notes. It is compatible with gstack SKILL.md files and supports several providers.
