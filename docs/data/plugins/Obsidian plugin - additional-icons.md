# Additional Icons

Additional Icons adds further icon sets, among them GovIcons, Weather Icons and an RPG set, to the icon library Obsidian uses wherever Lucide icons appear. Icons such as ra-axe, gi-dna and wi-tornado can decorate file classes, metadata fields and interface elements, and individual sets can be toggled on or off.

```cue
plugin: {
    id:     "additional-icons"
    name:   "Additional Icons"
    author: "matthewturk"
    repo:   "matthewturk/obsidian-additional-icons"

    html_url:    "https://community.obsidian.md/plugins/additional-icons"
    github_url:  "https://github.com/matthewturk/obsidian-additional-icons"
    description: "Add additional iconsets."
    about:       "Add additional icon sets (RPG Awesome, GovIcons, Weather Icons and more) to Obsidian's icon library for use wherever Obsidian uses Lucide icons. Use icons like ra-axe, gi-dna, and wi-tornado to decorate file classes, metadata fields, and UI elements, and toggle sets on or off."

    stats: {

}
```
