# Watched-Metadata

Watched-Metadata watches metadata fields and reacts when their values change. Headers can be replaced with the updated metadata value, and configured Obsidian commands can be run automatically.

```cue
plugin: {
    id:     "watched-metadata"
    name:   "Watched-Metadata"
    author: "nailahmed"
    repo:   "nailahmed/Watched-Metadata"

    html_url:    "https://community.obsidian.md/plugins/watched-metadata"
    github_url:  "https://github.com/nailahmed/Watched-Metadata"
    description: "Watches for changes in metadata and performs user-specified actions based on these changes."
    about:       "Watch metadata fields and trigger actions when they change. Replace headers with updated metadata values and run configured Obsidian commands automatically."

    stats: {
        downloads:  701
        updated_at: 1717273528000
    }
}
```
