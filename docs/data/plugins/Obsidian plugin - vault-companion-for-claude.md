# Vault Companion for Claude

Chats with Claude on desktop and mobile, giving the model agentic access to read, search, create and update notes in the vault. Every write action is held behind an approval card. The recorded inputs name two ways to connect: the user's own Anthropic API key, or a Claude subscription through a self-hosted relay.
