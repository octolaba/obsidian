# Notion Vault Sync

Synchronizes an entire vault to Notion while preserving the folder hierarchy, Markdown formatting, internal links, frontmatter metadata and attachments. Changes can be mirrored in full or incrementally, on save or on a schedule, Notion pages can be pulled back into the vault, and a detailed history and log of each sync can be inspected.
