# Gemini AI Commander

Provides a chat with Google Gemini inside the vault whose responses can be inserted into notes, and can process attached files. Notes and media, including text, images, audio and embedded notes, can be summarized, output is streamed in real time, generation can be cancelled, and errors can be reverted.
