# Pinboard Sync

Pinboard Sync brings recent Pinboard bookmarks into daily notes, adding each saved link to the note matching the date it was saved and importing its tags. Syncs run periodically and automatically, and an option creates an individual note per pin so bookmarks become editable notes in the vault.

plugin: {
    id:     "pinboard-sync"
    name:   "Pinboard Sync"
    author: "automatt"
    repo:   "automatt/obsidian-pinboard-sync"

    github_url:  "https://github.com/automatt/obsidian-pinboard-sync"
