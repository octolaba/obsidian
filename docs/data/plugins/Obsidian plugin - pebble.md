# Pebble

Pebble opens a minimal, distraction-free writing window in the menu bar or system tray for instant note taking. It is pointed at a single Markdown file in the vault and reads and writes that one note with fast autosave and auto-close on blur. The recorded inputs also list an anchored macOS pop-out and a choice of color or monochrome tray icons.

```cue
plugin: {
    id:     "pebble"
    name:   "Pebble"
    author: "pedrojreis"
    repo:   "pedrojreis/Pebble"

    html_url:    "https://community.obsidian.md/plugins/pebble"
    github_url:  "https://github.com/pedrojreis/Pebble"
    description: "A Minimal companion for quick note taking. - This plugin has not been manually reviewed by Obsidian staff."
```
