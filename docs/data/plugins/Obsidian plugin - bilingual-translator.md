# Bilingual Translator

Bilingual Translator converts English notes into a paragraph-by-paragraph Chinese and English parallel layout for reading, study and reference. Markdown, LaTeX and code blocks are preserved while YAML frontmatter and internal links are skipped, long articles are split into chunks with progress notifications, and several LLM translation engines are selectable to trade off speed, quality and cost.
