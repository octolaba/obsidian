# Handwriting Natively

Adds handwriting on PDFs with a stylus or mouse using pen, graphite pencil, circular eraser and lasso tools from a compact Draw toolbar. Annotations are stored as vault sidecars so the original PDF is untouched, and an annotated PDF can be exported. The recorded text states that it works entirely locally, with opt-in Draw mode, autosave and recovery.
