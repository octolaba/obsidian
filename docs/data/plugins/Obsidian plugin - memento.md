# Memento

Tracks events from the Obsidian Calendar plugin and creates new ones by right-clicking a date. An interactive sidebar timeline shows upcoming items, filtered by month or across all future occurrences. Recurring schedules are supported, event notes are scaffolded with YAML frontmatter, and English and Spanish dates are parsed.
