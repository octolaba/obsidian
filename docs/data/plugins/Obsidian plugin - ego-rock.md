# Ego Rock

Shows Taskwarrior tasks in Obsidian's reading view through task-table and task-count code blocks. The blocks are written as YAML and can define custom reports, filter expressions or command-line overrides, and results render either as an HTML table or as monospace ASCII.

```cue
plugin: {
    id:     "ego-rock"
    name:   "Ego Rock"
    author: "echo-bravo-yahoo"
    repo:   "echo-bravo-yahoo/ego-rock"

    html_url:    "https://community.obsidian.md/plugins/ego-rock"
    github_url:  "https://github.com/echo-bravo-yahoo/ego-rock"
    description: "A basic taskwarrior UI for listing and modifying tasks."
    about:       "View Taskwarrior tasks directly in Obsidian's reading view using task-table and task-count code blocks. Render results as HTML tables or monospace ASCII and define custom reports, filter expressions, or command-line overrides via YAML-formatted code blocks."

    stats: {
        downloads:  10276
        updated_at: 1711126866000
    }
}
```
