# Task Calendar Bridge

Task Calendar Bridge exports Markdown tasks that carry due dates into a local calendar file for import into Google Calendar, Apple Calendar, Outlook, TickTick or another calendar application. Exporting the tasks of the current note is free. A one-time Pro unlock adds full-vault export, automatic exports, completed tasks, reminder alarms, timed and multi-day events, and folder filters.
