# Google Calendar Importer

Imports Google Calendar events and tasks into a note, either injected automatically into daily notes or pulled in anywhere through a command. Events are rendered as configurable Markdown code blocks, any date can be chosen for import, and authentication goes through Google OAuth 2.0.

```cue
plugin: {
    id:     "google-calendar-importer"
    name:   "Google Calendar Importer"
    author: "lexafaxine"
    repo:   "lexafaxine/GoogleCalendarImporter"

    html_url:    "https://community.obsidian.md/plugins/google-calendar-importer"
    github_url:  "https://github.com/lexafaxine/GoogleCalendarImporter"
    description: "A simple and light-weighted google calendar importer, allow injecting the events / tasks of a day automatically to your daily notes, or import it to anywhere with a command."
    about:       "Import Google Calendar events and tasks into any note or automatically inject them into Daily Notes using an automatic integration or a manual import command. Render events as configurable markdown code blocks, pick any date to import, and authenticate with Google via OAuth 2.0."

    stats: {
        downloads:  2275
        updated_at: 1760142543000
    }
}
```
