# Title Case Converter

Title Case Converter converts selected text in the editor to title case following citation-style rules, with AMA implemented and further styles planned. It handles title and subtitle splits, colons and hyphenated compounds, keeps exact capitalizations listed as exceptions, and auto-detects mixed-case words such as iPhone or macOS.

```cue
plugin: {
    id:     "title-case-converter"
    name:   "Title Case Converter"
    author: "Max S. Rodenkirchen"
    repo:   "maxsrodenkirchen/Title-Case-Converter-Plugin"

    html_url:    "https://community.obsidian.md/plugins/title-case-converter"
    github_url:  "https://github.com/maxsrodenkirchen/Title-Case-Converter-Plugin"
    description: "Convert selected text to proper title case using citation-style rules (AMA, with more styles planned). - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert selected text to AMA title case in the editor, handling title/subtitle splits, colons, hyphenated compounds, and other edge cases. Preserve exact capitalizations with an exception list and auto-detect mixed-case words like iPhone or macOS; extendable to additional citation styles."
```
