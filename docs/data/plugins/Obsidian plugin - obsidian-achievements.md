# Achievements

Achievements adds achievements to Obsidian, earned for common actions and milestones. Tracked goals include a first note, 100 and 1,000 notes, internal links, nested headings, tags, and command and quick-switch usage.

    id:     "obsidian-achievements"
    name:   "Achievements"
    author: "zachatoo"
    repo:   "zachatoo/obsidian-achievements"

    github_url:  "https://github.com/zachatoo/obsidian-achievements"
