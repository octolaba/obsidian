# Porygon

Connects Obsidian to a local Ollama model and streams Markdown responses as they generate, turning the vault into a chat workspace. Notes can be mentioned to include their latest content as chat context, and files searched and filtered. Built-in tools list, view, search, or edit Markdown notes, and the recorded description states that processing stays local.
