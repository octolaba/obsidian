# Orbital

Orbital collects everything connected to the active note in one tabbed sidebar pane: outgoing links, backlinks, second-hop related notes and unlinked mentions. Dangling links are found vault-wide and repaired in bulk from grouped lists, with actions to rename, merge, alias, create or delete. A recent files tab sits in the same pane.
