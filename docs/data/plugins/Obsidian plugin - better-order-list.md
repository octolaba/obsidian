# Better Order List

Better Order List recognizes ordered lists written with markers other than the plain numeral form, including parenthesized numbers and East Asian numeral characters. Sequence and formatting are preserved so these lists display correctly in the editor and in preview.

```cue
plugin: {
    id:     "better-order-list"
    name:   "Better Order List"
    author: "Boninall"
    repo:   "quorafind/Obsidian-Better-Order-List"

    html_url:    "https://community.obsidian.md/plugins/better-order-list"
    github_url:  "https://github.com/quorafind/Obsidian-Better-Order-List"
    description: "Support new line order list like 1. or (1)., etc."
    about:       "Recognize and render ordered lists written with numbered parentheses like (1). (2). (3). or East Asian markers like 一、二、三、. Preserve sequence and formatting in editor and preview so numbered lists display properly."

    stats: {
        downloads:  2277
        updated_at: 1705061738000
    }
}
```
