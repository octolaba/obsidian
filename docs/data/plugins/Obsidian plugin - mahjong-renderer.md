# Mahjong Renderer

Renders riichi Mahjong hands written in MPSZ notation into inline tile graphics when they are placed in a mahjong code block. Rotated tiles and kans have their own notation marks, the red five is written as a zero, and multiline layouts cover discards. Light and dark themes are supported.

    id:     "mahjong-renderer"
    name:   "Mahjong Renderer"
    author: "h-sphere"
    repo:   "h-sphere/obsidian-mahjong-renderer"

    html_url:    "https://community.obsidian.md/plugins/mahjong-renderer"
    github_url:  "https://github.com/h-sphere/obsidian-mahjong-renderer"
    description: "Render mahjong tiles (riichi mahjong) using MPSZ notation"
