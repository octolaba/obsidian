# Documentation Command Center

A native dashboard for navigating a documentation vault, with a collapsible tree and expansion controls, search by filename or path, and filters for Markdown, PDFs, Excalidraw, Draw.io and media. A folder can be pinned as the root, recent updates tracked, and unresolved-link and orphan-note metrics reviewed. Media is previewed in a keyboard-navigable gallery with native handoff, and everything runs offline without Dataview, telemetry or cloud services.
