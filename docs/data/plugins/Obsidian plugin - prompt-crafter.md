# PromptCrafter

Builds modular, reusable prompts from pc code blocks with mustache-style placeholders. Placeholder values are defined in frontmatter, linked note content and section anchors are resolved, and nested blocks are expanded to produce a finished prompt ready to copy into an LLM.
