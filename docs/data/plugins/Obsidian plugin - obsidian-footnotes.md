# Footnote Shortcut

Inserts an auto-numbered or named footnote marker and appends the matching footnote detail at the end of the document from a single hotkey. Indexes are incremented automatically, the cursor is placed in the new detail for immediate editing, and the same shortcut jumps between a marker and its detail.

```cue
plugin: {
    id:     "obsidian-footnotes"
    name:   "Footnote Shortcut"
    author: "michabrugger"
    repo:   "michabrugger/obsidian-footnotes"

    html_url:    "https://community.obsidian.md/plugins/obsidian-footnotes"
    github_url:  "https://github.com/michabrugger/obsidian-footnotes"
    description: "Makes creating footnotes more fun!"
    about:       "Insert auto-numbered or named footnote markers with auto-incremented indexes and append corresponding footnote details at the end of the document via a hotkey. Place the cursor in the new footnote detail for immediate editing and jump quickly between markers and their details."
```
