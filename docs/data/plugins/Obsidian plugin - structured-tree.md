# Structured Tree

Hierarchical notes whose names are separated by a period are navigated through a file tree that maps each path segment to a nested node, with a configurable separator. A fuzzy lookup opens or creates notes, frontmatter is generated for new files, and files are renamed and created from the tree. Paths are excluded, multiple vaults are supported, and all Obsidian file types are handled with Canvas marked experimental.
