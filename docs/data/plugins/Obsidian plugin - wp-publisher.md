# WP Publisher

Publishes notes to WordPress as Gutenberg blocks and synchronizes them explicitly rather than continuously, deduplicating media instead of re-uploading it. A preview precedes publishing, and pulling changes back is a reviewed two-way flow with guarded merge steps.

```cue
plugin: {
    id:     "wp-publisher"
    name:   "WP Publisher"
    author: "Irisable"
    repo:   "irisable/wp-publisher-for-obsidian"

    html_url:    "https://community.obsidian.md/plugins/wp-publisher"
    github_url:  "https://github.com/irisable/wp-publisher-for-obsidian"
    description: "Publish and explicitly synchronize notes with WordPress using Gutenberg blocks, media reuse, previews, and guarded pull and merge workflows. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Publish and safely synchronize Obsidian notes with WordPress using Gutenberg blocks, media deduplication, previews, and reviewed two-way sync."
}
```
