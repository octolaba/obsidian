# Snipsy

Hotstrings expand short shortcuts into formatted Markdown as they are typed, with cursor placement handled and no expansion inside code blocks or YAML frontmatter. Snippets are inserted through a hotstring or through a searchable picker in the command palette, and libraries are organized in folders with bulk editing. The recorded inputs state that Espanso-compatible packs are supported.

    id:     "snipsidian"
    name:   "Snipsy"
