# Mobile Suggestion Helper

Mobile Suggestion Helper moves the highlighted entry in the mobile suggester up or down so that a specific file can be selected. This makes results other than the first one reachable, and headings or block anchors can then be chosen to insert a precise link.

```cue
plugin: {
    id:     "mobile-suggestion-helper"
    name:   "Mobile Suggestion Helper"
    author: "Aqua Cat"
    repo:   "pjkaufman/obsidian-mobile-suggester-helper"

    html_url:    "https://community.obsidian.md/plugins/mobile-suggestion-helper"
    github_url:  "https://github.com/pjkaufman/obsidian-mobile-suggester-helper"
    description: "Helps move the selected element in a suggester up or down on mobile. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Navigate the mobile link suggester by moving the highlighted entry up or down and selecting the desired file. Select specific files from the dropdown—including non-first results—and choose headings or block anchors to insert precise links."

    stats: {
        downloads:  96
        updated_at: 1777612412000
    }
}
```
