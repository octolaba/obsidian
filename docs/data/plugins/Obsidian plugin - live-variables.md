# Live Variables

Defines variables in a note's properties and reuses them throughout the content, so that notes update everywhere at once. Queries and transformations run from code blocks or a visual form, custom functions can be saved, variable references can be edited inline, and dynamic content can be highlighted so it is easy to identify.
