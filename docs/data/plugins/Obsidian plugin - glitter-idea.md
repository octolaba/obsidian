# Glitter

Captures brief ideas as lightweight cards, holding text, links, images and videos, so a fleeting thought does not require a full note first. Saved cards can later be reviewed and organized, turned into Markdown files, or referenced inside notes as reusable snippets. A visual roam board arranges the accumulated cards so they can be connected, compared and expanded.
