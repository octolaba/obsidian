# Safe Attachment Trash

Safe Attachment Trash finds unused attachments and moves the approved ones into a managed trash, recording each file's original path so it can be restored exactly. Files can be reviewed and opened before being moved, restored individually or all at once with folders recreated and name conflicts resolved, or deleted permanently. The recorded description calls the trash bilingual.
