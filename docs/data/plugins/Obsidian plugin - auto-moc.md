# AutoMOC

AutoMOC collects linked mentions, tag matches and defined aliases for the current note and imports the missing ones at the cursor, which keeps maps of content and tag lists up to date. Separate commands pull linked mentions, pick a tag through a modal, with frontmatter tags supported, or choose an alias.

```cue
plugin: {
    id:     "auto-moc"
    name:   "AutoMOC"
    author: "dalcantara7"
    repo:   "dalcantara7/obsidian-auto-moc"

    html_url:    "https://community.obsidian.md/plugins/auto-moc"
    github_url:  "https://github.com/dalcantara7/obsidian-auto-moc"
    description: "Look for missing linked mentions to the current note and import them into the current note."
    about:       "Import missing backlinks and references into the current note at the cursor to keep MOCs and tag lists up to date by collecting linked mentions, tag matches, or defined aliases. Run commands to pull linked mentions, pick a tag (frontmatter tags supported) or choose an alias via a modal, and insert matching note links where you edit."

    stats: {
        downloads:  17229
        updated_at: 1749435010000
    }
}
```
