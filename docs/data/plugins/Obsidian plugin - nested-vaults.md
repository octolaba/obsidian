# Nested Vaults

Nested Vaults scopes the vault to a chosen folder and treats it as a temporary sub-vault while themes, plugins and settings stay in place. File explorer, search, graph, tag pane and backlinks are restricted to that folder and opening outside files is blocked, with folders such as attachments and templates whitelisted.

```cue
plugin: {
    id:     "nested-vaults"
    name:   "Nested Vaults"
    author: "Real-Fruit-Snacks"
    repo:   "real-fruit-snacks/obsidian-nested-vaults"

    html_url:    "https://community.obsidian.md/plugins/nested-vaults"
    github_url:  "https://github.com/real-fruit-snacks/obsidian-nested-vaults"
    description: "Scope your vault to a specific folder, effectively treating it as a nested sub-vault. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Scope your vault to any folder and work inside it as a temporary vault while keeping your themes, plugins, and settings. Restrict file explorer, search, graph, tag pane, and backlinks to that folder, block opening outside files, and whitelist folders like attachments and templates."

    stats: {
        downloads:  328

    }
}
```
