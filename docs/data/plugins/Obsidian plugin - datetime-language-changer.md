# Datetime Language Changer

Sets the language used for datetime formatting by changing the locale of moment.js. The locale applies to plugins that format dates through moment.js, Tasks among them, and the project notes that the plugin has to stay enabled rather than be disabled or deleted.

```cue
plugin: {
    id:     "datetime-language-changer"
    name:   "Datetime Language Changer"
    author: "zetabs"
    repo:   "zetabs/datetime-language-changer"

    html_url:    "https://community.obsidian.md/plugins/datetime-language-changer"
    github_url:  "https://github.com/zetabs/datetime-language-changer"
    description: "Customize the language used for datetime formatting by changing moment.js's locale."
    about:       "Set the language used for datetime formatting by changing moment.js's locale. Apply the locale to plugins that use moment.js (e.g., Tasks) and keep the plugin enabled—do not disable or delete it—to maintain consistent datetime language."

    stats: {
        downloads:  3010
        updated_at: 1698775555000
    }
}
```
