# Horizontal Scroll View

Splits a note at its H1, H2 and H3 headings into side-by-side columns, each scrolling vertically while the view as a whole scrolls horizontally. Columns can be resized, collapsed and jumped to, and a column's Markdown can be copied. Column widths are remembered per file, rendering stays live, and text remains selectable.
