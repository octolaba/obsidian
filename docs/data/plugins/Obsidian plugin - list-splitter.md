# Canvas List Splitter

Splits a bulleted or numbered list inside a Canvas text card into separate plain-text cards, one per list item, stacked vertically at the original card's position. It also merges two or more Canvas text cards into a single bulleted list card placed at the top-left card's position, ordering cards top to bottom and then left to right. The recorded inputs list the markers it understands, including hyphens, asterisks, bullets, and numbered forms.
