# CalendarZ

CalendarZ displays a visual calendar with heatmap and dot tracking of daily note or word counts, or a None view for plain date navigation. Dates are recognized from YAML frontmatter or from filenames, and daily, weekly, monthly and yearly notes can be opened or created from templates. It also shows todo completion and per-day statistics.

plugin: {
    id:     "calendarz"
    name:   "CalendarZ"
    author: "Kecheng Zhang"
    repo:   "kechengzhang28/Obsidian-CalendarZ-Plugin"

    github_url:  "https://github.com/kechengzhang28/Obsidian-CalendarZ-Plugin"
