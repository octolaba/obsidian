# OpenAgent

OpenAgent runs an AI agent over the vault that reads, writes, edits, appends, searches and lists notes and manages frontmatter and links. Any OpenAI-compatible provider can be used with your own API key, including OpenAI, Anthropic through a proxy, Ollama and LM Studio, so requests go only to the chosen endpoint. Destructive writes are confirmed with a diff preview, and the same plugin runs on desktop and mobile.
