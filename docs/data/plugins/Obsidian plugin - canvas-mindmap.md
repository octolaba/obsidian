# Canvas Mindmap

Canvas Mindmap makes a canvas behave like a mindmap, with hierarchical nodes and auto-layout in specific directions. Hotkeys add child, sibling or floating nodes and move between them, node subtrees can be selected, and node edge colors can be changed for visual grouping.
