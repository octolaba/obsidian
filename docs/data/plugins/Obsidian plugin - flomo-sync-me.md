# Flomo Sync Me

Syncs Flomo memos into Obsidian and merges each month's memos into a single Markdown file, with one folder per year. Incremental syncs detect new, updated and deleted memos and rebuild only the affected months. Authentication uses an access token or desktop auto-login.

```cue

    id:     "flomo-sync-me"
    name:   "Flomo Sync Me"
    author: "fanthus"
    repo:   "fanthus/flomo2obsidian"

    html_url:    "https://community.obsidian.md/plugins/flomo-sync-me"
    github_url:  "https://github.com/fanthus/flomo2obsidian"
    description: "Sync Flomo memos into Obsidian with per-year folders, monthly merge, and incremental updates. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync Flomo memos into Obsidian and merge each month's notes into a single Markdown file. Map years to separate folders and run incremental syncs that detect new, updated, or deleted memos, rebuilding only affected months when needed. Authenticate with an access token or desktop auto-login."
```
