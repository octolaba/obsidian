# FB2 Reader

FB2 Reader opens FictionBook .fb2 files held in the vault in a formatted reader showing the cover, title, authors, chapters, footnotes and images. A clickable table of contents is used to navigate and the reading position is restored for up to 300 books. The appearance can be set to light, dark or sepia, and legacy encodings are detected automatically.

    id:     "fiction-book-reader"
    name:   "FB2 Reader"
