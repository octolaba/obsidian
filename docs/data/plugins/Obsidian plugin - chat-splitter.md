# Chat Splitter

Chat Splitter breaks long AI chat transcripts and documents into topic-specific notes carrying generated titles, tags, summaries, key points and bidirectional wikilinks. Text, JSON, ZIP or Markdown can be imported or pasted, and the segments are previewed and edited before they are saved. A Map of Content is generated to tie the resulting topic notes together.
