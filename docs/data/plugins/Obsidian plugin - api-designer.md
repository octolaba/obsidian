# API Designer

Designs and documents API endpoints visually inside a note, including request and response bodies with named, typed properties. Fields are added or removed directly, and the resulting API schema is saved as Markdown. The color scheme is configurable and the responsive layout adapts to the workspace.

    id:     "api-designer"
    name:   "API Designer"
    author: "Ruveyda"
