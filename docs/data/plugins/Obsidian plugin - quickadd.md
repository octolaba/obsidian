# QuickAdd

Creates notes from templates and captures content into predefined files, with macros chaining several actions into one multi-step workflow. Choices are grouped into folders, called multis, and template syntax injects dynamic values such as a date into filenames and content.

    id:     "quickadd"
    name:   "QuickAdd"
    author: "chhoumann"
    repo:   "chhoumann/quickadd"

    html_url:    "https://community.obsidian.md/plugins/quickadd"
    github_url:  "https://github.com/chhoumann/quickadd"
    description: "Quickly add new notes or content to your vault."
    about:       "Create templated notes, capture content into predefined files, and chain actions with macros to automate multi-step workflows. Organize choices into folders (multis) and inject dynamic values into filenames and content using QuickAdd's template syntax like {{DATE}}."
