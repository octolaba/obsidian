# Gay Toolbar

Replaces the default mobile toolbar with a floating, collapsible toolbar that sits above the keyboard. Each button carries a primary tap action and can also take a long-press action and directional swipe commands, and buttons are dragged to rearrange them. Button colors and the toolbar background are customized with CSS, rows and columns are configurable, and layouts can be saved and loaded.
