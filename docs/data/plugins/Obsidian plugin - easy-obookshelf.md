# Easy Bookshelf

Fetches book metadata by ISBN from NDL, Google Books and Open Library and creates a note for each book. Cover images are downloaded and cached locally with WebP conversion, books are viewed through Want to read, Reading and Finished bases, and entries or covers are added by manual entry, drag-and-drop, paste or a file picker.
