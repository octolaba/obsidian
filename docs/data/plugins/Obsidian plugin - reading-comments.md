# Reading comments

Creates inline comments while reading books or articles, written as inline comments in the note, with the native comment syntax supported for compatibility. Comments can be grouped hierarchically by tags and searched and navigated in a comments panel, where entries are toggled or removed. The original note can be extracted with clean internal links to the comment notes.

```cue
plugin: {
    id:     "reading-comments"
    name:   "Reading comments"
    author: "bumbrt"
    repo:   "bumbrt/obsidian-reading-comments"

    html_url:    "https://community.obsidian.md/plugins/reading-comments"
    github_url:  "https://github.com/bumbrt/obsidian-reading-comments"
    description: "Create inline comments while you read books or articles. Comments could be grouped hierarchically by tags."
    about:       "Create inline HTML comments while reading Markdown notes and use native %%comments%% for compatibility. Group comments hierarchically by tags, search and navigate them in a comments panel, toggle or remove entries, and extract the original note with clean internal links to comment notes for vault integration."

    stats: {
        downloads:  10441

    }
}
```
