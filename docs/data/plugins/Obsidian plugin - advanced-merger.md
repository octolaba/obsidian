# Advanced Merger

Advanced Merger merges a folder of notes into a single Markdown file for easier export and sharing. The merge is invoked by right-clicking a folder and choosing the merge folder action, which combines its notes into one consolidated file.

```cue
plugin: {
    id:     "advanced-merger"
    name:   "Advanced Merger"
    author: "antokeinanen"
    repo:   "antokeinanen/obsidian-advanced-merger"

    html_url:    "https://community.obsidian.md/plugins/advanced-merger"
    github_url:  "https://github.com/antokeinanen/obsidian-advanced-merger"
    description: "Merge a folder of notes for easier export."
    about:       "Merge a folder of notes into a single Markdown file for easier export and sharing. Right-click any folder and choose \"merge folder\" to combine its notes into one consolidated file."
```
