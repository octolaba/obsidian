# Update Time Updater

Updates the modified datetime in a note's frontmatter on demand, from the left ribbon or the command palette rather than automatically. The frontmatter key to write and the datetime format are both configurable.

```cue
plugin: {
    id:     "update-time-updater"
    name:   "Update Time Updater"
    author: "muratagawa"
    repo:   "muratagawa/update-time-updater"

    html_url:    "https://community.obsidian.md/plugins/update-time-updater"
    github_url:  "https://github.com/muratagawa/update-time-updater"
    description: "Manually update the modified date field in frontmatter."
    about:       "Update the modified datetime in a note's frontmatter manually from the left ribbon or the command palette. Specify the frontmatter key to update and choose the datetime format for the timestamp."

    stats: {
        downloads:  1029
        updated_at: 1712709062000
    }
}
```
