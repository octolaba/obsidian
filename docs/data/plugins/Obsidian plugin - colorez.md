# Colorez

Colorez changes text color using the active theme's CSS variables, so the colors follow a theme switch or a change between dark and light mode. Colors and translucent highlights are picked from the right-click menu with small previews, an Eraser removes the styling, and the same actions are available from the Command Palette.
