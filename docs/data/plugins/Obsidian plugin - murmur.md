# Murmur

Reads a note aloud through a chosen text-to-speech provider, highlighting words as they are spoken in both source mode and Live Preview. The whole note or the current selection can be read, and playback is controlled from a widget at the top of the file or a draggable one, with skip and speed controls. Markdown is stripped before synthesis so the speech reads as prose, and audio is cached on disk.
