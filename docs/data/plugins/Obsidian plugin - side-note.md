# SideNote

SideNote attaches comments to a selected part of a sentence and shows them in a dedicated side pane or split pane, leaving the note itself uncluttered. Commented text is highlighted and tracked through hash-based matching as the text moves, clicking an item jumps to its location, and orphaned or moved comments can be managed.
