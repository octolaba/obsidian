# Wielder

Runs Clojure and ClojureScript code blocks inside notes, executing them block by block so that data pipelines sit beside the prose. Reagent React components can be rendered, and the Obsidian API is reachable from the code, which allows interactive apps and manipulation of the vault from within a document.

    name:   "Wielder"
