# Card Viewer

Card Viewer renders card views for movies, TV shows, books and music, showing covers and metadata. It also previews image code blocks as a grid with a lightbox in reading mode, and can render optional HTML code blocks.

    id:     "card-viewer"
    name:   "Card Viewer"
