# Canvas SVG Export

Canvas SVG Export writes canvases out as clean SVG built from rendered SVG elements rather than PNG. The vector output keeps canvas visuals sharp when zoomed, printed or edited downstream.

    id:     "canvas-svg-export"
    name:   "Canvas SVG Export"
    author: "Hēsperus"
    repo:   "hesprs/obsidian-canvas-svg-export"

    github_url:  "https://github.com/hesprs/obsidian-canvas-svg-export"
