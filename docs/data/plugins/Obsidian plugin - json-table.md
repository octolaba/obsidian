# JSON table

JSON table converts between JSON and Markdown tables in both directions. A table is generated from a selected JSON string or from a URL that returns JSON, and JSON is produced from a selected Markdown table.

```cue
plugin: {
    id:     "json-table"
    name:   "JSON table"
    author: "dario-baumberger"
    repo:   "dario-baumberger/obsidian-json-table"

    html_url:    "https://community.obsidian.md/plugins/json-table"
    github_url:  "https://github.com/dario-baumberger/obsidian-json-table"
    description: "Simply switch between JSON and tables. Generate a table from a JSON string or a URL (which returns JSON) in your notes. Generate JSON from a table in your notes."
    about:       "Convert JSON to Markdown tables and back. Generate a table from a selected JSON string or from a URL returning JSON, and produce JSON from a selected Markdown table."

    stats: {
        downloads:  8387

}
```
