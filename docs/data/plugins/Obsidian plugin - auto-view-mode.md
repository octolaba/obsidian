# Auto View Mode

Auto View Mode opens a note in Reading View, Source Mode or Live Preview according to a frontmatter key set on that note. The name of the key is configurable, and its recorded About states that the plugin carries no external dependencies.

```cue
plugin: {
    id:     "auto-view-mode"
    name:   "Auto View Mode"
    author: "saltyfireball"
    repo:   "saltyfireball/obsidian-auto-view-mode"

    html_url:    "https://community.obsidian.md/plugins/auto-view-mode"
    github_url:  "https://github.com/saltyfireball/obsidian-auto-view-mode"
    description: "Automatically switch between Reading View, Source Mode, and Live Preview based on a frontmatter key in your notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Open notes automatically in Reading View, Source Mode, or Live Preview by setting a per-note frontmatter key. Configure the frontmatter key name to match your workflow and keep the plugin lightweight with no external dependencies."

    stats: {
        downloads:  295
        updated_at: 1779127840000
    }
}
```
