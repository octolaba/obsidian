# Show Diff

Show Diff renders Git diffs as readable Markdown code blocks inside notes. The vault or any other repository can be targeted, with date or commit ranges and path exclusions, and a ready-made block showing today's changes can be inserted.

```cue
plugin: {
    id:     "show-diff"
    name:   "Show Diff"
    author: "ivan-lednev"
    repo:   "ivan-lednev/obsidian-automatic-changelog"

    html_url:    "https://community.obsidian.md/plugins/show-diff"
    github_url:  "https://github.com/ivan-lednev/obsidian-automatic-changelog"
    description: "Render Git diffs in your notes."
    about:       "Render Git diffs as readable Markdown code blocks inside notes. Point to your vault or any repo, specify date or commit ranges and path exclusions, or insert a ready-made code block showing today's changes."

    stats: {
        downloads:  4325
        updated_at: 1682325553000
    }
}
```
