# Writing Tracker Heatmap Streaks

Tracks the number of new words written each day and shows them in a compact sidebar heatmap together with today's count and the current streak. A webhook is sent when the daily word goal is reached. A detailed statistics view covers yearly and monthly history, and earlier history can be imported from Daily Stats.

    id:     "word-goal-webhook"
    name:   "Writing Tracker Heatmap Streaks"
