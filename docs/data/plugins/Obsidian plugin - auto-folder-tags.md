# Auto folder tags

Auto folder tags injects configured tags into the frontmatter of notes as they are created. On demand it also applies those tags to every markdown file in the current folder, skipping tags that are already present.

```cue
plugin: {
    id:     "auto-folder-tags"
    name:   "Auto folder tags"
    author: "gansxx"
    repo:   "gansxx/auto-folder-tags"

    html_url:    "https://community.obsidian.md/plugins/auto-folder-tags"
    github_url:  "https://github.com/gansxx/auto-folder-tags"
    description: "Automatically apply configured tags to new notes and supplement tags for files in the current folder. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Apply configured tags to new notes by injecting frontmatter tags when files are created. Apply those tags to all markdown files in the current folder on demand while avoiding duplicate tags."

    stats: {
        downloads:  200
        updated_at: 1780564332000
    }
}
```
