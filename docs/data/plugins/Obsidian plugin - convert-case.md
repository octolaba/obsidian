# Convert case

Convert case changes selected text between case styles, including Title Case, UPPER, lower, swapped case, camelCase, PascalCase, snake_case and kebab-case. The command set is small and dependency-free, and conversions apply to multiple selections at once.

```cue
plugin: {
    id:     "convert-case"
    name:   "Convert case"
    author: "Ryan Morrissey"
    repo:   "23maverick23/obsidian-convert-case"

    html_url:    "https://community.obsidian.md/plugins/convert-case"
    github_url:  "https://github.com/23maverick23/obsidian-convert-case"
    description: "Change selected text to familiar case styles with a small, dependency-free command set. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert selected text between multiple case styles, including Title Case, UPPER, lower, swap, camelCase, PascalCase, snake_case, and kebab-case. Apply conversions to multiple selections without extra dependencies."
```
