# Sentence Enhancers

Sentence Enhancers adds contextual CSS classes to workspace and Markdown view containers, prefixed ose_ and ose--, that expose temporal information such as month, weekday, day of month, hour and minute. Snippets and themes can then style notes and workspace elements according to that date and time context.

```cue
plugin: {
    id:     "sentence-enhancers"
    name:   "Sentence Enhancers"
    author: "garrett-is-a-swann"
    repo:   "garrett-is-a-swann/obsidian-sentence-enhancers"

    html_url:    "https://community.obsidian.md/plugins/sentence-enhancers"
    github_url:  "https://github.com/garrett-is-a-swann/obsidian-sentence-enhancers"
    description: "Enhances customization by adding additional contextual classes for use by plugins and themes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Add contextual CSS classes to workspace and Markdown view containers (prefixed ose_ / ose--) to expose temporal info like month, weekday, day-of-month, hour and minute. Use those classes in snippets or themes to style notes and workspace elements based on date/time context."
```
