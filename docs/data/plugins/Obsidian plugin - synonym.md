# Synonym

Looks up synonyms for English and Swedish words using offline dictionary files, with optional online lookup. Custom synonyms can be added and override the other sources. Lookups are reachable from the right-click menu, the command palette or the ribbon, and the interface can be switched between English and Swedish.

```cue
plugin: {
    id:     "synonym"
    name:   "Synonym"
    author: "Jan Sandström"
    repo:   "pixerojan/obsidian-synonym"

    html_url:    "https://community.obsidian.md/plugins/synonym"
    github_url:  "https://github.com/pixerojan/obsidian-synonym"
    description: "Synonyms for Swedish and English words. - This plugin has not been manually reviewed by Obsidian staff."
```
