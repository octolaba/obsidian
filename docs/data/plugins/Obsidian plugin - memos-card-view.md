# Memos Card View

Connects to a Memos instance and shows memo records as editable cards, covering create, edit, delete, paging, refresh, visibility, tags, pins, timestamps, attachments and live Markdown preview. Pages are clipped through an embedded browser or a companion Chromium extension. A local OpenAI-compatible model summarizes a page, and the summary and its source link are saved back to Memos. The recorded text states that the card view is desktop-only.
