# Yaml Manager

YAML front matter is edited through commands instead of being opened directly. Single key-value fields are updated, items are inserted into or removed from array fields, and bulk updates run from the command palette in edit mode. Front matter is created when missing, and both array formats are supported.

```cue
plugin: {
    id:     "obsidian-state-switcher"
    name:   "Yaml Manager"
    author: "lijyze"
    repo:   "lijyze/obsidian-state-switcher"

    html_url:    "https://community.obsidian.md/plugins/obsidian-state-switcher"
    github_url:  "https://github.com/lijyze/obsidian-state-switcher"
    description: "Keep you away from directly operating YAML frontmatter."
    about:       "Edit YAML front matter safely without opening it directly. Update single key-value fields, insert or remove items in array fields, and perform bulk updates from the command palette (edit mode). Auto-create front matter if missing and support customizable array formats (- item or [item])."

    stats: {
        downloads:  12563
        updated_at: 1656554529000
    }
}
```
