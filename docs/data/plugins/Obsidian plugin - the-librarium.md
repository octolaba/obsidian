# The Librarium

Orchestrates chat against local Ollama models with topic-separated memory kept in hierarchical layers, from an Overview through a Comprehensive Summary to the original text. Queries are routed to the relevant topics and the layers are searched from least to most detailed, so deeper context is loaded only when it is needed. Retrieval is adjustable and everything runs locally.
