# Simple Code Formatter

Simple Code Formatter formats the code block the cursor sits in, using language-specific formatters such as Prettier, js-beautify, xml-formatter and sqlformatter. JavaScript, TypeScript, Java, HTML, CSS, JSON, Markdown, YAML, SQL and XML are covered. Prettier checks syntax before formatting, and switching to a js-beautify language bypasses that strict check so malformed code is still beautified.
