# Rsync

Rsync synchronizes files and folders between local and remote systems with rsync in push or pull mode over SSH, authenticating by password or private key and honoring custom exclusion rules. Syncs can be scheduled periodically, previewed with a dry run, recorded in detailed logs, and watched with real-time progress.
