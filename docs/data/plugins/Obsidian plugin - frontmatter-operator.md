# Frontmatter Operator

Bulk-edits YAML frontmatter across the vault through an interactive spreadsheet view or a typed programmatic API. Notes are filtered by property conditions with live counts, and set, delete, rename, copy, merge and transform actions are applied with a snapshot of every change for undo. Missing fields such as descriptions, keywords or MOC links can be generated from note content with a chosen LLM provider, and the recorded text names Open Knowledge Format migration as its purpose.
