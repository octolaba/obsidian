# Smart Connections Visualizer

Smart Connections Visualizer displays the Smart Connections of a single note as an interactive force-directed graph. Node and link appearance can be adjusted, along with the repel, link and center forces and relevance-based distances. Hovering a node previews the note behind it.

```cue
plugin: {
    id:     "smart-connections-visualizer"
    name:   "Smart Connections Visualizer"
    author: "mossy1022"
    repo:   "mossy1022/Smart-Connections-Visualizer"

    html_url:    "https://community.obsidian.md/plugins/smart-connections-visualizer"
    github_url:  "https://github.com/mossy1022/Smart-Connections-Visualizer"

    about:       "Visualize connections for a single note as an interactive force-directed graph. Adjust node and link appearance, tweak repel/link/center forces and relevance-based distances, and preview notes by hovering nodes to explore relationships and insights."
```
