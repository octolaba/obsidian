# Link Unlinked Mentions

Converts plain-text mentions of other notes' titles and aliases in the active note into wikilinks, in bulk and with one click. A dry-run preview lists every note that would be linked, ambiguous matches are skipped rather than guessed, and code, inline code, math, existing links, tags, HTML comments, and YAML frontmatter are left alone.

```cue
plugin: {
    id:     "link-unlinked-mentions"
    name:   "Link Unlinked Mentions"
    author: "Jordan Vasu"
    repo:   "jordanvasu/link-unlinked-mentions"

    html_url:    "https://community.obsidian.md/plugins/link-unlinked-mentions"
    github_url:  "https://github.com/jordanvasu/link-unlinked-mentions"
    description: "Bulk-link all unlinked mentions of the active note (and its aliases) across the vault. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert plain-text mentions of other notes' titles and aliases into wikilinks in the active note with one click. Show a dry-run preview of all the notes that will be turned into wikilinks, skip ambiguous matches instead of guessing, and avoid converting inside code, inline code, math, existing links, tags, HTML comments and YAML frontmatter."

    stats: {
        downloads:  201
        updated_at: 1778991085000
    }
}
```
