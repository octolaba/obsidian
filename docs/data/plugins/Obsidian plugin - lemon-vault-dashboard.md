# Lemon Vault Dashboard

Lemon Vault Dashboard reports vault storage composition, file distribution and health through headline figures, a category breakdown and treemap, sunburst, donut and bar visualisations. Folders can be drilled into, large or orphan attachments spotted, and growth and activity trends tracked, with files opened or revealed directly from the dashboard.
