# Multi Tag

Adds a tag to every note in a folder, or to several selected notes, from the right-click menu on the folder or the selection. Tags are appended inline at the bottom of each note or written into YAML frontmatter. The recorded text notes that the YAML path checks for duplicate tags while the inline path does not.

```cue
plugin: {
    id:     "multi-tag"
    name:   "Multi Tag"
    author: "technohiker"
    repo:   "technohiker/obsidian-multi-tag"

    html_url:    "https://community.obsidian.md/plugins/multi-tag"
    github_url:  "https://github.com/technohiker/obsidian-multi-tag"
    description: "Add tags to multiple notes at once. Either right-click a folder, or select multiple notes and right-click the selection."
    about:       "Add a tag to every note in a folder or to multiple selected notes by right-clicking the folder or selection. Append tags inline at the bottom of notes or add them to YAML frontmatter; YAML mode checks for duplicate tags while inline does not."

    stats: {
        downloads:  21120
        updated_at: 1701224051000
    }
}
```
