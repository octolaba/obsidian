# Zhongwen Vault

Zhongwen Vault shows a floating card when a Chinese character is hovered in editor or reading view, carrying tone-coloured pinyin, up to five CC-CEDICT senses, measure words, register tags and a traditional-form toggle. Pressing S saves the current word to the configured word list, creating the note when it is missing. It works in Live Preview, Source mode and Reading view, uses the greedy word segmentation of the Zhongwen browser extension that inspired it, and bundles CC-CEDICT so that no internet connection is required.
