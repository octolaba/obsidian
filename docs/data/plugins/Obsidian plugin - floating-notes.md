# Floating Notes

Opens a floating popout editor for quick capture that is toggled on and off without losing its state. Capture targets the active note, a fixed note, or a new timestamped note, and the window is triggered from an in-app command, an obsidian:// URI, or a local HTTP endpoint. The popout can optionally be kept on top of other windows.

plugin: {
    id:     "floating-notes"
    name:   "Floating Notes"
