# Hotkeys for Bookmarks

Individual hotkeys open the first nine bookmarked files from the keyboard alone. Each bookmark has commands for opening it in the current pane or in a new pane. Bookmarks have to be registered first with the core Bookmarks plugin.

```cue
plugin: {
    id:     "obsidian-shortcuts-for-starred-files"
    name:   "Hotkeys for Bookmarks"
    author: "Vinzent"
    repo:   "vinzent03/obsidian-shortcuts-for-starred-files"

    html_url:    "https://community.obsidian.md/plugins/obsidian-shortcuts-for-starred-files"
    github_url:  "https://github.com/vinzent03/obsidian-shortcuts-for-starred-files"
    description: "Set an individual hotkey for the first 9 bookmarked files and open them just with your keyboard."
    about:       "Open bookmarks 1–9 using customizable hotkeys for quick access. Open each bookmark in the current pane or open them in a new pane with dedicated commands. Use the core Bookmarks plugin to register bookmarks first."

    stats: {
        downloads:  10928
        updated_at: 1712156301000
    }
}
```
