# Faster Stacked Tabs

Shortens the time it takes to switch between stacked tabs while keeping the horizontal sliding animation. The ease-out duration of the horizontal scroll is adjustable from 40 to 400 milliseconds, defaulting to 120, and normal tabs and other scrolling are left alone.

```cue
plugin: {
    id:     "faster-stacked-tabs"
    name:   "Faster Stacked Tabs"
    author: "Ben Hancock"
    repo:   "benhancock/faster-stacked-tabs"

    html_url:    "https://community.obsidian.md/plugins/faster-stacked-tabs"
    github_url:  "https://github.com/benhancock/faster-stacked-tabs"
    description: "Makes stacked-tab switching faster while preserving its sliding animation. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Speed up switching between stacked tabs while preserving the horizontal sliding animation. Adjust the horizontal scroll ease-out duration from 40–400 ms (default 120 ms) to shorten tab transitions without changing normal tabs or other scrolling."

    stats: {
        downloads:  79
        updated_at: 1785107458000
    }
}
```
