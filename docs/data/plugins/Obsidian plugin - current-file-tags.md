# Current File Tags

Displays the tags of the active Markdown file, both inline tags and the frontmatter tags property. Clicking a tag lists the files that contain it and opens them, while Ctrl-clicking searches for the tag with Obsidian Search.

```cue
plugin: {
    id:     "current-file-tags"
    name:   "Current File Tags"
    author: "trung-tran-swe"
    repo:   "trung-tran-swe/obsidian-current-file-tags"

    html_url:    "https://community.obsidian.md/plugins/current-file-tags"
    github_url:  "https://github.com/trung-tran-swe/obsidian-current-file-tags"
    description: "Display the active Markdown file's tags and associated files."
    about:       "Display tags from the active Markdown file, including inline tags and the frontmatter \"tags\" property. Click a tag to list and open files that contain it, or Ctrl-click a tag to search it with Obsidian Search."

    stats: {
        downloads:  980
        updated_at: 1748708733000
    }
}
```
