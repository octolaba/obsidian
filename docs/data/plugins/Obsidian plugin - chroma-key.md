# Chroma Key Paste

Chroma Key Paste removes the background color from a pasted image, run from the right-click menu or the command palette. Tolerance and edge softening are adjustable and the background color is detected automatically or entered as a hex value. The transparent PNG is written to a chroma folder and the image link in the note is updated.

```cue
plugin: {
    id:     "chroma-key"
    name:   "Chroma Key Paste"
    author: "Aziz Zahran"
    repo:   "aziz-zahran/obsidian-chroma-key"

    html_url:    "https://community.obsidian.md/plugins/chroma-key"
    github_url:  "https://github.com/aziz-zahran/obsidian-chroma-key"
    description: "Automatically removes the background color from pasted images. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Remove backgrounds from pasted images with a single click via the right-click menu or the command palette. Fine-tune cutouts with adjustable tolerance and edge softening, auto-detect or enter a hex background color, and save transparent PNGs to a chroma/ folder while updating image links."

    stats: {
        downloads:  201
        updated_at: 1783577279000
    }
}
```
