# Vault Spotlight

Opens a keyboard-first, Spotlight-style launcher that fuzzy-searches file names, boosts recently used files and shows relative modification times. Results can be filtered by tags and frontmatter properties. The recorded inputs assign ripgrep-backed content search behind a prefix operator, starred pins, canvas and PDF support, multi-select batch open and saved custom commands to a Pro tier.
