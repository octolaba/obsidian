# Bottom to Top

The plugin makes Enter insert a new line above the current line instead of below it. It can also reverse every line in the current note, and reverse mode is toggled per note.

```cue
plugin: {
    id:     "bottom-to-top"
    name:   "Bottom to Top"
    author: "lizard-heart"
    repo:   "lizard-heart/obsidian-bottom-to-top-text"

    html_url:    "https://community.obsidian.md/plugins/bottom-to-top"
    github_url:  "https://github.com/lizard-heart/obsidian-bottom-to-top-text"
    description: "Makes text go from left-to-right, bottom-to-top."
    about:       "Insert new lines above the current line when pressing Enter instead of below. Reverse all lines in the current note or toggle reverse mode per note to enable or disable the behavior."

    stats: {
        downloads:  365
        updated_at: 1731808090000
    }
}
```
