# Open Interpreter

Open Interpreter runs AI automations in the vault from natural-language commands. An integrated chat reads, writes and edits Markdown files, and every change requires explicit user approval first. The plugin verifies that Open Interpreter is installed and gives guidance for running it against the vault.
