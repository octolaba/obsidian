# Syro

Brings spaced repetition, flashcards and incremental reading to a Markdown vault, with reviews scheduled by FSRS. Inline cards jump back to the paragraph they came from, long reads are queued as daily micro-tasks, and articles resume at the exact scroll position. The recorded description positions it as an interface alternative to Anki for a plain-text knowledge base.
