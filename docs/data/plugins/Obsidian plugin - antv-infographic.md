# Infographic

Renders AntV Infographic code blocks inside notes. A fenced block using the language infographic displays templates such as radial-tree and other AntV Infographic visualizations.

```cue
plugin: {
    id:     "antv-infographic"
    name:   "Infographic"
    author: "larchliu"
    repo:   "larchliu/obsidian-infographic-plugin"

    html_url:    "https://community.obsidian.md/plugins/antv-infographic"
    github_url:  "https://github.com/larchliu/obsidian-infographic-plugin"
    description: "Render AntV Infographic (infographic.antv.vision) code blocks. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render AntV Infographic code blocks directly inside Obsidian notes to display diagrams and layouts. Create fenced code blocks with language \"infographic\" to show templates like radial-tree and other AntV Infographic visualizations."

    stats: {
        downloads:  152
        updated_at: 1769785009000
    }
}
```
