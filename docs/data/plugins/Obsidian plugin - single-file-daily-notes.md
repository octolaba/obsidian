# Single File Daily Notes

Single File Daily Notes keeps all daily notes in one Markdown file, with each day as a heading so entries stay outline-friendly. The entry for today is created automatically and the cursor placed for immediate writing. A built-in calendar sidebar jumps to other dates or creates them.

```cue
plugin: {
    id:     "single-file-daily-notes"
    name:   "Single File Daily Notes"
    author: "pranavmangal"
    repo:   "pranavmangal/obsidian-single-file-daily-notes"

    html_url:    "https://community.obsidian.md/plugins/single-file-daily-notes"
    github_url:  "https://github.com/pranavmangal/obsidian-single-file-daily-notes"
    description: "Create and manage daily notes in a single file."
    about:       "Create and manage daily notes in a single Markdown file, with each day as a heading so entries stay outline-friendly. Auto-create today's entry and position the cursor for immediate editing; jump to or create other dates via the built-in calendar sidebar."
```
