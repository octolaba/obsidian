# Email Reader

Email Reader previews embedded .eml files inline in a note instead of handing them to the default mail application. The email is rendered inside an embedded frame in Preview mode, and the file link can carry width and height values; dimensions left unspecified are detected automatically.

```cue
plugin: {
    id:     "eml-reader"
    name:   "Email Reader"
    author: "pulsovi"
    repo:   "pulsovi/obsidian_eml_reader"

    html_url:    "https://community.obsidian.md/plugins/eml-reader"
    github_url:  "https://github.com/pulsovi/obsidian_eml_reader"
    description: "A preview mode for embedded .eml files."
    about:       "Preview .eml files inline in notes, rendering email content inside an embedded frame in Preview mode instead of opening your default mail app. Set frame dimensions in the file link to control width and height; unspecified dimensions auto-detect."

    stats: {
        downloads:  8635
        updated_at: 1745322952000
    }
}
```
