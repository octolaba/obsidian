# LaTeX autocomplete

This plugin suggests LaTeX commands as soon as a backslash is typed and completes the command from a single selection. It also expands simple shortcuts, turning an input such as \a/b into \frac{a}{b}.

```cue
plugin: {
    id:     "latex-autocomplete"
    name:   "LaTeX autocomplete"
    author: "yanis-gerst"
    repo:   "yanis-gerst/latex-autocomplete"

    html_url:    "https://community.obsidian.md/plugins/latex-autocomplete"
    github_url:  "https://github.com/yanis-gerst/latex-autocomplete"
    description: "Simple auto-completion for LaTeX. As simple as typing '\\'."
    about:       "Show LaTeX command suggestions as you type \"\\\" and complete commands with a single selection. Support simple shortcut expansions (for example \"\\a/b\" → \"\\frac{a}{b}\") to speed LaTeX input."

    stats: {
        downloads:  922
        updated_at: 1763543895000
    }
}
```
