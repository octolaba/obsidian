# AI integration Hub

AI integration Hub generates and refines content inside notes with Google's Gemini and other compatible services. Selected text serves as the prompt and is replaced by the output, generation is reachable from the ribbon, and the API key and model are set in the plugin settings.

```cue
plugin: {
    id:     "ai-hub"
    name:   "AI integration Hub"
    author: "hish-math"
    repo:   "hish-math/obsidian-ai-hub"

    html_url:    "https://community.obsidian.md/plugins/ai-hub"
    github_url:  "https://github.com/hish-math/obsidian-ai-hub"
    description: "Integrate with AI models (currently Google's Gemini only) to quickly generate and refine notes."
    about:       "Generate AI content inside your notes with Google Gemini and other compatible services. Select text as a prompt to replace it with AI output, access generation from the ribbon for quick use, and set your API key and model in the plugin settings."

    stats: {
        downloads:  1518
        updated_at: 1736982255000
    }
}
```
