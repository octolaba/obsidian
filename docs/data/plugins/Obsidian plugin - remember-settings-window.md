# Remember Settings Window

Remembers the size and screen position of the Settings popout window and restores them each time it is opened. A default width and height can be set, and the interface is available in English or Chinese.

```cue
plugin: {
    id:     "remember-settings-window"
    name:   "Remember Settings Window"
    author: "xzhi"
    repo:   "github-xzhi/obsidian-remember-settings-window"

    html_url:    "https://community.obsidian.md/plugins/remember-settings-window"
    github_url:  "https://github.com/github-xzhi/obsidian-remember-settings-window"
    description: "Remember and restore the size and position of the settings popout window. 记住并恢复【在独立窗口中打开设置】窗口的尺寸和位置。 - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Remember and restore the Settings popout window's size and screen position each time you open it. Set a default width and height and choose English or Chinese locale to keep placement consistent across sessions."

    stats: {
        downloads:  26
        updated_at: 1785607988000
    }
}
```
