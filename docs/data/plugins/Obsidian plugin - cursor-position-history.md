# Cursor Position History

Remembers the previous cursor positions across files and scrolls to the right place when a note is opened or reopened. The recorded history can be stepped backward and forward with shortcuts so that context is not lost.

```cue

    id:     "cursor-position-history"
    name:   "Cursor Position History"
    author: "fgubler"
    repo:   "fgubler/obsidian-cursor-position-history"

    html_url:    "https://community.obsidian.md/plugins/cursor-position-history"
    github_url:  "https://github.com/fgubler/obsidian-cursor-position-history"
```
