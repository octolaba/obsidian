# Interactive Ratings

Interactive Ratings turns rating symbols in a note into controls that change on click, updating the symbols and any optional numeric rating at the same time. Symbols come from built-in sets or custom emojis, and the score is displayed as a fraction or a percentage that stays synced.

    id:     "interactive-ratings"
    name:   "Interactive Ratings"
    author: "peritus"
