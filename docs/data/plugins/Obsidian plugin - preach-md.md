# Preach MD

Presents sermon notes and other presentations in a full-screen preach view with large serif text, hidden interface, free vertical scrolling, and a remembered position. A live timer with amber and red thresholds, a section outline, and a two-step exit are provided, scripture references expand inline from the vault, and the screen is kept awake.
