# Another Sticky Headings

Keeps the current heading and its ancestors visible while reading or editing, indicating the position in a long note. Clicking a displayed heading jumps to that section, and a concise or full mode chooses between a minimal indicator and a detailed contextual breadcrumb.

```cue
plugin: {
    id:     "another-sticky-headings"
    name:   "Another Sticky Headings"
    author: "zhouhua"
    repo:   "zhouhua/obsidian-sticky-headings"

    html_url:    "https://community.obsidian.md/plugins/another-sticky-headings"
    github_url:  "https://github.com/zhouhua/obsidian-sticky-headings"
    description: "Display headings tree during editing and preview to indicate the current position."
    about:       "Keep current and ancestor headings visible while reading or editing to maintain orientation and track progress. Click displayed headings to jump to sections and switch between concise or full modes for minimal or detailed contextual breadcrumbs."

    stats: {
        downloads:  7982

}
```
