# MOC Link Helper

MOC Link Helper manages and synchronizes the links between a Map of Content and its child notes. A dedicated view adds or removes up frontmatter links in bulk and finds notes that reference the MOC without being included in it. Included notes can be inserted or filtered when a MOC is split or synced.

```cue
plugin: {
    id:     "moc-link-helper"
    name:   "MOC Link Helper"
    author: "bogdancodreanu"
    repo:   "bogdancodreanu/obsidian-moc-link-helper"

    html_url:    "https://community.obsidian.md/plugins/moc-link-helper"
    github_url:  "https://github.com/bogdancodreanu/obsidian-moc-link-helper"
    description: "Helps with some MOC janitor-linking tasks."
    about:       "Manage and sync links between a Map of Content (MOC) and its child notes. Open a dedicated view to add or remove 'up' frontmatter links in bulk, find notes that reference the MOC but aren’t included, and insert or filter included notes for splitting or syncing MOCs."

    stats: {

    }
}
```
