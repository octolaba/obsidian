# Storyteller Suite

Characters, locations, events and galleries are managed together for story planning, worldbuilding, campaign play and manuscript compilation. Timelines run in a standard or Gantt mode with grouped tracks, dependencies, forks, eras and conflict detection. Sessions are run from a campaign view with a party tracker, shared inventory and a branching scene graph.
