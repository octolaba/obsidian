# FlowBoard PM

Provides a lightweight project-management board with Linear-style columns kept in local board files. Cards carry title, context, project, owner, stage, type, priority, due date and tags, and dragging them between Backlog, Todo, In Progress and Done saves automatically. Cards are searched, created, edited and deleted from the board.
