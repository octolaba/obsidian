# Notes Explorer

Presents the vault as visual note cards in a masonry or fixed-height grid, intended for browsing and revising content. Cards can be filtered, sorted and searched with saved queries, folder and tag filters, and filtered views that can themselves be linked to, while tag-based colors distinguish cards and the interface is adapted for mobile.
