# Better Quick Switcher

Searches Markdown headings across the vault with fuzzy matching and jumps to the one selected, with the scope set to all files or the current file. Results are filtered by heading level, folders can be excluded, and the number of suggestions is capped.

```cue
plugin: {
    id:     "better-quick-switcher"
    name:   "Better Quick Switcher"
    author: "Ji"
    repo:   "reticenceji/better-quick-switcher"

    html_url:    "https://community.obsidian.md/plugins/better-quick-switcher"
    github_url:  "https://github.com/reticenceji/better-quick-switcher"
    description: "Search markdown headings with fuzzy matching — like Quick Switcher but for headings. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Search and jump to any heading across your vault using fuzzy matching and selectable search scope (all files or current file). Filter results by heading level, exclude folders from results, and limit suggestion counts for focused navigation."

    stats: {
        downloads:  37
        updated_at: 1785229305000
    }
}
```
