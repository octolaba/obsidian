# Cite Engine

Builds closed-corpus citations by stamping source notes with stable citekeys and block IDs, so an inserted citation is a live block reference that always resolves to the original passage. Integrity checks flag citations that no longer resolve and quoted text that has drifted from its source. The recorded inputs describe this construction as making fabrication impossible, since only clipped sources can be cited.
