# Roim PicX Uploader

Roim PicX Uploader uploads images to a Roim PicX instance and replaces external image URLs in notes with PicX links. It handles Markdown, HTML and reference link formats, detects new, pasted or dragged images, supports Web Clipper, skips badges and shields, decodes camo URLs, and copies the resulting PicX link to the clipboard after upload.
