# cMenu

Adds a minimal text formatting toolbar as an editor modal, so formatting does not depend on remembering dozens of hotkeys. The menu bar is configurable and applies bold, italics, strikethrough, underline, superscript, subscript, code, code block and blockquote, and any Obsidian command can be added to it.

```cue
plugin: {
    id:     "cmenu-plugin"
    name:   "cMenu"
    author: "chetachiezikeuzor"
    repo:   "chetachiezikeuzor/cMenu-Plugin"

    html_url:    "https://community.obsidian.md/plugins/cmenu-plugin"
    github_url:  "https://github.com/chetachiezikeuzor/cMenu-Plugin"
    description: "Add a minimal text formatting toolbar for a smoother writing/editing experience."
    about:       "Open a minimal, user-friendly text-editor modal for focused writing and editing without memorizing dozens of hotkeys. Use a configurable menu bar to apply formatting (bold, italics, strikethrough, underline, superscript, subscript, code, codeblock, blockquote) and add any Obsidian command."

    stats: {
        downloads:  233285

    }
}
```
