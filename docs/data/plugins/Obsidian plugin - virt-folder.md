# VirtFolder

VirtFolder builds hierarchical virtual folders so notes can be navigated like a book's table of contents, in the spirit of Luhmann's Zettelkasten. Notes are created, deleted, dragged and dropped through the mouse, context menus or hotkeys, and files can be added from the file explorer. It also supports emoji icons, unique note creation, Front Matter Title and database optimizations.
