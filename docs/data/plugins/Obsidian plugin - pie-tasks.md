# Pie Tasks

Pie Tasks manages tasks that live in Markdown files and presents them as a board, list, calendar or dashboard, writing checkbox state straight back to the file. Several named task files can be used as boards and switched between instantly. Lanes and task-detail drawers organise the board, people can be assigned with optional avatars, and all data stays in plain Markdown.
