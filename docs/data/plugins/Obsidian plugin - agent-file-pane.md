# Agent File Pane

Agent File Pane hides AI instruction files such as AGENTS.md and CLAUDE.md from the file explorer. It lists them instead in a dedicated right-side pane that mirrors the folder tree.

```cue
plugin: {
    id:     "agent-file-pane"
    name:   "Agent File Pane"
    author: "philphilphil"
    repo:   "philphilphil/obsidian-agent-file-pane"

    html_url:    "https://community.obsidian.md/plugins/agent-file-pane"
    github_url:  "https://github.com/philphilphil/obsidian-agent-file-pane"
    description: "Hides AGENTS.md and CLAUDE.md from the file explorer and lists them in a dedicated side pane. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Hide AI instruction files (e.g., AGENTS.md, CLAUDE.md) from the file explorer and list them in a right-side pane that mirrors your folder tree."

    stats: {
        downloads:  175
        updated_at: 1779005982000
    }
}
```
