# Seamless Embeds

This plugin renders embedded and transcluded notes inline with the surrounding text, so that a reader cannot tell where one note ends and another begins. Borders, padding, titles and link icons are removed while full-width dividers are preserved, and nested embeds are supported in Reading view and Live Preview.

```cue
plugin: {
    id:     "seamless-embeds"
    name:   "Seamless Embeds"
    author: "5krus"
    repo:   "5krus/obsidian-seamless-embeds"

    html_url:    "https://community.obsidian.md/plugins/seamless-embeds"
    github_url:  "https://github.com/5krus/obsidian-seamless-embeds"
    description: "Makes embedded/transcluded notes visually indistinguishable from surrounding text. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render embedded notes seamlessly inline with surrounding text so readers can't tell where one note ends and another begins. Remove borders, padding, titles, and link icons; preserve full-width dividers and support nested embeds in Reading and Live Preview."
```
