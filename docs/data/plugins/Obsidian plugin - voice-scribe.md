# Voice Scribe

Voice Scribe records voice notes and transcribes them on the device with Whisper, working offline with no cloud service and no API keys. Transcripts are inserted into the last-focused input or into a new note, and existing audio files can be transcribed as well. Toggle and push-to-talk hotkeys are available, on desktop and on mobile.
