# Commando

Commando repeats any command from a dedicated Commando Palette, iterating it a specified number of times from a single invocation. The count comes from a Vim-style numeric prefix or an explicit value, and default or per-invocation delays control the pacing. Testing a command before running bulk iterations is advised.
