# Task Card

Turns tagged Markdown tasks into interactive cards carrying priorities, due dates, projects, labels, durations and recurrence. Everything stays readable plain Markdown, using Dataview inline fields and native block identifiers. Tasks can be queried into lists or an Eisenhower matrix, and metadata is edited with autosuggest and natural-language dates.
