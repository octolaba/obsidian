# Card Forge

Card Forge converts notes into printable poker cards measuring 2.5 by 3.5 inches and shows them through a dedicated preview command. Card content and appearance are controlled by frontmatter fields for card type, custom title and additional CSS classes.

```cue
plugin: {
    id:     "card-forge"
    name:   "Card Forge"
    author: "carlsverre"
    repo:   "carlsverre/obsidian-card-forge"

    html_url:    "https://community.obsidian.md/plugins/card-forge"
    github_url:  "https://github.com/carlsverre/obsidian-card-forge"
```
