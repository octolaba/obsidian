# Minitabs

Minitabs defines nested tabbed panels and split-column layouts inside a code block and renders their contents as standard Obsidian markdown. Tab bars can sit at the top or the bottom, tabs can be nested arbitrarily, and 2x2 or 2xN quadrant views can be composed for dashboards and multi-panel notes.

```cue
plugin: {
    id:     "minitabs"
    name:   "Minitabs"
    author: "ssjy1919"
    repo:   "ssjy1919/Obsidian-minitabs"
```
