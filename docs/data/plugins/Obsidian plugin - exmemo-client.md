# ExMemo Client

A client for the ExMemo service that searches local notes and remote ExMemo content from a sidebar or a popup. Searches run by keyword, filename, tag, fuzzy match or semantic vectors, and results are previewed before insertion. Single notes or batches synchronise with an ExMemo server in both directions for cross-device consistency.
