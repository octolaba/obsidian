# Zoottelkeeper Plugin

Zoottelkeeper maintains index files for the folders of a vault, updating file and subfolder links, tags and optional emojis automatically when a note is created, deleted or moved. Include and exclude paths, index templates, sorting and frontmatter separators are configurable, child indexes can be embedded in previews, and indexing can also be triggered manually. Because every folder gains an index note, folders can be shown in the graph view.
