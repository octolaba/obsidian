# Telegram Sync Amvera R

Collects messages sent to a personal Telegram bot through a sync server hosted on Amvera and pulls them into notes on command. Voice and audio messages can be transcribed through ProxyAPI, and synced messages can be post-processed with AI. It runs on desktop only and requires Obsidian 1.5.0 or newer.
