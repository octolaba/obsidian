# GitFacil

Commits and pushes the vault to Git in one click, from a ribbon icon or the command palette, with a step-by-step setup wizard and a status panel of checkboxes plus a pull button. Automatic synchronization can be enabled to schedule periodic backups and keep the remote repository up to date. The interface is in Spanish.

plugin: {
    id:     "git-facil"
    name:   "GitFacil"
    author: "Alex"
    repo:   "alecwce/obsidian-git-facil"

    html_url:    "https://community.obsidian.md/plugins/git-facil"
    github_url:  "https://github.com/alecwce/obsidian-git-facil"
    description: "One-click commit & push for your vault: step-by-step setup wizard, status panel with checkboxes, pull button and auto-backup. Simple Git for non-developers. (UI in Spanish) - This plugin has not been manually reviewed by Obsidian staff."
