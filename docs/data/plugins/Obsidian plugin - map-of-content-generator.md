# Map of Content Generator

Map of Content Generator builds pre-filtered maps of content from a chosen folder, creating or updating root and child MOC notes based on the folder structure. Generation can run automatically at startup or be triggered manually, and empty subfolders can optionally be removed after each run.

```cue
plugin: {
    id:     "map-of-content-generator"
    name:   "Map of Content Generator"
    author: "danybeam"
    repo:   "danybeam/map-of-content-generator"

    html_url:    "https://community.obsidian.md/plugins/map-of-content-generator"
    github_url:  "https://github.com/danybeam/map-of-content-generator"

    about:       "Generate pre-filtered Maps of Content (MOCs) from a chosen folder and automatically create or update root and child MOC notes. Automate generation on startup or run manually and optionally remove empty subfolders after each run."
```
