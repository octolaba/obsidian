# open-as-md

open-as-md lets non-Markdown file types be edited as Markdown inside Obsidian. The extensions to treat as .md are listed in the plugin settings, and the plugin has to be re-enabled for a change to take effect. It requires Obsidian 0.10.12 or later.

```cue
plugin: {
    id:     "open-as-md"
    name:   "open-as-md"
    author: "kursad-k"
    repo:   "kursad-k/obsidian-openasmd"

    html_url:    "https://community.obsidian.md/plugins/open-as-md"
    github_url:  "https://github.com/kursad-k/obsidian-openasmd"
    description: "Edit non-md file types as Markdown files."
    about:       "Edit non‑Markdown files as Markdown directly inside Obsidian. Specify file extensions to treat as .md in the plugin settings and re-enable the plugin to apply changes. Requires Obsidian 0.10.12 or later."

    stats: {
        downloads:  5588
        updated_at: 1702148277000
    }
}
```
