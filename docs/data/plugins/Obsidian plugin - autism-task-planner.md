# Autism Task Planner

Turns Markdown task lists into a sequenced, timed schedule shown in a sidebar panel. Start times and total duration are calculated, tasks are reordered by drag-and-drop, durations and categories edited inline, and tasks marked done as work proceeds. Changes can optionally be written back to the file.
