# Infographic

Renders AntV Infographic visualizations from fenced code blocks, with the source code viewable. Charts are authored in JSON or the AntV DSL against more than 200 templates, exported to PDF and resized responsively with live reload, and the light or dark theme is detected automatically.

    id:     "infographic"

    author: "shuuul"
