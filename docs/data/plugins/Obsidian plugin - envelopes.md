# Envelopes

Turns the vault into an envelope budget, tracking monthly budgets, expenses, income, bills and cash flow in plain Markdown. Bank CSV files can be imported, each expense logged as its own note, payment methods tagged, and leftover funds rolled forward into the next month. All data stays local and searchable in the vault.

plugin: {
    id:     "envelopes"
    name:   "Envelopes"
    author: "Sebastien Delisle"
    repo:   "lumargh/obsidian-budgets"

    html_url:    "https://community.obsidian.md/plugins/envelopes"
    github_url:  "https://github.com/lumargh/obsidian-budgets"
