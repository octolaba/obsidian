# Content Publisher

Content Publisher publishes notes to Substack, WordPress and LinkedIn, converting Markdown and uploading local images to the target platform's CDN. It supports drafts, audience targeting, bilingual publishing, and syncing of tags, categories and sections. Publications and servers can be managed, previews edited, and publishes chained across platforms.
