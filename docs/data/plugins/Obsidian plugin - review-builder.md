# Review Builder

Review Builder combines many daily and weekly notes into single review files named quarterly_days.md and quarterly_weeks.md, giving one view over a whole period. Weekly and quarterly reviews are built from the relevant notes, with the weekly build also including the prior week's review. The recorded text states that only files the plugin itself creates in a temp folder are modified.

```cue
plugin: {
    id:     "review-builder"
    name:   "Review Builder"
    author: "Mark Levison"
    repo:   "mlevison/obsidian-review-builder"

    html_url:    "https://community.obsidian.md/plugins/review-builder"
    github_url:  "https://github.com/mlevison/obsidian-review-builder"
    description: "Simplify quarterly and weekly reviews by combining many Daily and Weekly notes - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Consolidate daily and weekly notes into single review files (quarterly_days.md and quarterly_weeks.md) to view a complete period overview and spot patterns. Build weekly or quarterly reviews that compile relevant notes (weekly includes the prior week's review) and only modify files the plugin creates in a temp folder."

    stats: {
        downloads:  680
        updated_at: 1778864328000
    }
}
```
