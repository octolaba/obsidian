# Publish with Flowershow

Publishes notes from the vault to a Flowershow site without leaving Obsidian. A status view lists files as changed, new, deleted or unchanged, and either selected notes or the whole set of site updates can be published. Local custom.css and config.json files are picked up for styling and configuration.

```cue
plugin: {
    id:     "flowershow"
    name:   "Publish with Flowershow"
    author: "Flowershow"
    repo:   "flowershow/obsidian-flowershow"

    html_url:    "https://community.obsidian.md/plugins/flowershow"
    github_url:  "https://github.com/flowershow/obsidian-flowershow"
    description: "Publish your Obsidian vault as a beautiful website. Perfect for digital gardens, blogs, documentation, wikis, and knowledge bases."
    about:       "Publish your Obsidian vault online directly from Obsidian with Flowershow. View publication status for changed, new, deleted, and unchanged files, publish selected notes or site updates, and include local custom.css and config.json for styling and configuration."

    stats: {
        downloads:  8180
        updated_at: 1785780509000
    }
}
```
