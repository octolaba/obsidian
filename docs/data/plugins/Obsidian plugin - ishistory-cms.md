# isHistory CMS

isHistory CMS manages the content of an Astro site from inside Obsidian, with a dashboard that lists posts and organizes types such as articles, profiles and events. Frontmatter is validated live against the collection schema, and inline errors appear in a quick-validate sidebar. Drafts are marked individually or in bulk as pre-flight ready for deployment.
