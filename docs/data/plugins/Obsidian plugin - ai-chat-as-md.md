# AI Chat as Markdown

AI Chat as Markdown holds conversations with models such as GPT-4 Omni and Claude 3.5 inside Markdown notes, branching them as a hierarchy of nested headings. Images can be included for multimodal context, citations from search-integrated models are rendered, and the model or system prompt is set per file through frontmatter or embeds.

```cue
plugin: {
    id:     "ai-chat-as-md"
    name:   "AI Chat as Markdown"
    author: "cpbotha"
    repo:   "cpbotha/obsidian-ai-chat-as-md"

    html_url:    "https://community.obsidian.md/plugins/ai-chat-as-md"
    github_url:  "https://github.com/cpbotha/obsidian-ai-chat-as-md"
    description: "Multiple branching AI conversations as Markdown hierarchy"
    about:       "Chat with GPT-4 Omni or Claude 3.5 directly inside your Obsidian Markdown notes. Create branching conversations as nested headings, include images for multimodal context, render citations from search-integrated models, and set per-file models or system prompts via frontmatter or embeds."

    stats: {
        downloads:  1369

    }
}
```
