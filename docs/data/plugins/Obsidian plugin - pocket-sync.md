# Pocket Sync

Syncs Pocket AI conversations and daily highlights into Markdown notes, carrying summaries, action items, transcripts, and Pocket metadata as Obsidian properties. Imported content stays inside a managed block so your own notes can surround it, and sync runs automatically, at startup, or manually with customizable folders and filename templates.

```cue
plugin: {
    id:     "pocket-sync"
    name:   "Pocket Sync"
    author: "Maclean (Silk Ribbon)"
    repo:   "maclean-d/obsidian-pocket"

    html_url:    "https://community.obsidian.md/plugins/pocket-sync"
    github_url:  "https://github.com/maclean-d/obsidian-pocket"
    description: "Sync Pocket AI conversations and daily highlights into Markdown notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync Pocket AI conversations and daily highlights into Markdown notes with summaries, action items, transcripts, and Pocket metadata as Obsidian properties. Keep imported content in a managed block so you can add your own notes around it, and run auto, startup, or manual sync with customizable folders and filename templates."

    stats: {
        downloads:  1202

    }
}
```
