# Smart Done Mover

Moves completed checkbox tasks, including their indented subtasks, into a customizable Done heading within the same note. Commands and the editor menu move a selection or a whole completed block, and an auto mode moves tasks as soon as they are checked. Filters and exclusions limit what is moved, completion dates can be appended, and indentation is preserved.
