# Margin Notes

Places notes in the margin next to a paragraph, leaving a small inline superscript marker and the full content in a chip beside the text. Margin notes can be enabled per file, per folder or vault-wide, and are inserted with an mn: syntax or a command, with live previews of the wikilinks inside them. An optional AI agent can suggest notes and place them.

```cue
plugin: {
    id:     "margin-notes"
    name:   "Margin Notes"
    author: "Abdul Majeed"
    repo:   "writing-editor/margin-notes"

    html_url:    "https://community.obsidian.md/plugins/margin-notes"
    github_url:  "https://github.com/writing-editor/margin-notes"
    description: "Add literal book-margin notes with per-file selective activation, plus an optional AI notes agent that suggests and places them for you. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Jot margin-style notes next to any paragraph, placing a small inline superscript marker and a full-content chip in the margin. Enable them per file, folder, or vault, insert notes with [mn:] syntax or a command, get live wikilink previews, and optionally run an AI agent to suggest or place notes."
```
