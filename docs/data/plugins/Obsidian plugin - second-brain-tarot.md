# Second-Brain Tarot

Second-Brain Tarot draws from a complete 78-card deck and interprets each card against the content of your own vault rather than from a lookup table or generic tarot copy. Six spreads are available, a synthesis of the spread is produced, and a vault-grounded chat continues the reading. Readings can be saved as notes carrying wikilinks, and requests go to the AI provider you choose with your own API key.
