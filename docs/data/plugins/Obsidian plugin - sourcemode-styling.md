# Source Mode Styling

Source mode is given a raw monospace look so that it reads differently from Live Preview. Fonts and styling are customizable, available fonts are detected automatically, changes apply instantly, and theme colors are respected on desktop and mobile.

```cue
plugin: {
    id:     "sourcemode-styling"
    name:   "Source Mode Styling"
    author: "chrishoward-projects"
    repo:   "chrishoward-projects/sourcemode-styling"

    html_url:    "https://community.obsidian.md/plugins/sourcemode-styling"
    github_url:  "https://github.com/chrishoward-projects/sourcemode-styling"

    about:       "Differentiate Obsidian's source mode from Live Preview by applying a raw, monospace editor aesthetic with customizable fonts and styling. Detect fonts automatically, apply changes instantly, and respect theme colors across desktop and mobile."
```
