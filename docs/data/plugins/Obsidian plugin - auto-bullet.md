# Auto Bullet

Inserts a bullet marker automatically when a space or a tab is typed at the beginning of a line. The behaviour can be turned off entirely and configured separately for half-width spaces, full-width spaces and tabs.

```cue
plugin: {
    id:     "auto-bullet"
    name:   "Auto Bullet"
    author: "takitsuba"
    repo:   "takitsuba/obsidian-auto-bullet"

    html_url:    "https://community.obsidian.md/plugins/auto-bullet"
    github_url:  "https://github.com/takitsuba/obsidian-auto-bullet"
    description: "Automatically inserts bullet points when you type spaces or tabs at the beginning of a line."
    about:       "Insert \"- \" automatically when you type a space or tab at the start of a line to create bullet points. Toggle the feature on/off and control behavior separately for half-width spaces, full-width spaces, and tabs."

    stats: {
        downloads:  2045
        updated_at: 1750949651000
    }
}
```
