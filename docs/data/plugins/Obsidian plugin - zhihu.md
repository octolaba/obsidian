# Zhihu

This plugin publishes Markdown files from the vault to Zhihu as articles or answers, converting a note into Zhihu-formatted HTML. Article and answer drafts can be created, and an article can be submitted to a Zhihu question. Personalized recommendations, followings and hot lists are browsable from inside Obsidian.

```cue
plugin: {
    id:     "zhihu"
    name:   "Zhihu"
    author: "zimya"
    repo:   "zimya/zhihu_obsidian"

    html_url:    "https://community.obsidian.md/plugins/zhihu"
    github_url:  "https://github.com/zimya/zhihu_obsidian"
    description: "Enable you to publish your articles and answers to Zhihu."
    about:       "Publish Markdown files directly to Zhihu as articles or answers, converting notes into Zhihu-formatted HTML. Create article and answer drafts, submit articles to Zhihu questions, and browse personalized recommendations, followings, and hot lists from within Obsidian."

    stats: {
        downloads:  4583
        updated_at: 1778503308000
    }
}
```
