# PaperFolio for Kobo

Imports Kobo highlights into Obsidian as one note per book, sorted by true reading order and grouped by real chapter names. Generated highlights are synced into a sentinel block so that the reader's own writing is protected, and sources from a connected Kobo eReader, the Kobo desktop app or the local network can be merged. Sync is local, incremental and de-duplicated, with an auto-generated index.
