# Mobile Sidebar Notes

Mobile Sidebar Notes opens notes and new editor tabs in the mobile app's left or right sidebar while keeping the full editor, canvases included. Commands can be created to open specific notes, duplicate tabs are prevented, and sidebar tabs can be auto-pinned so that links open in new tabs.

```cue
plugin: {
    id:     "mobile-sidebar-notes"
    name:   "Mobile Sidebar Notes"
    author: "ckep1"
    repo:   "ckep1/obsidian-mobile-sidebar-notes"

    html_url:    "https://community.obsidian.md/plugins/mobile-sidebar-notes"
    github_url:  "https://github.com/ckep1/obsidian-mobile-sidebar-notes"
    description: "Open notes & new tabs in the sidebar in the mobile app."
```
