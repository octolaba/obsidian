# Full File Extensions

Shows complete filenames in the native File Explorer, including multi-dot extensions such as archive.tar.gz, and hides Obsidian's separate extension badge so labels are not duplicated. Disabling the plugin restores the basenames. It runs entirely locally with no network access, telemetry or writes to the vault.

    id:     "full-file-extensions"
    name:   "Full File Extensions"
    author: "Stagars"
