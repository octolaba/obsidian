# Weather Widget

Shows multi-city weather forecasts inline in a note, in a dedicated sidebar panel, or as Canvas nodes styled to match the vault. Time-zone offsets are applied automatically, and the display uses sunrise and sunset easing together with temperature-driven gradients. Inline city lists are merged with the global settings, and the data comes from Open-Meteo or OpenWeather with caching to stay inside rate limits.
