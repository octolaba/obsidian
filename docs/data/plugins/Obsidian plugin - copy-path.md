# Copy Path

Copy Path adds context menu actions that copy the full or vault-relative path of a file or folder. Folder paths can optionally carry a trailing slash so they are distinguishable from files.

```cue
plugin: {
    id:     "copy-path"
    name:   "Copy Path"
    author: "shumadrid"
    repo:   "shumadrid/obsidian-copy-path"

    html_url:    "https://community.obsidian.md/plugins/copy-path"
    github_url:  "https://github.com/shumadrid/obsidian-copy-path"
    description: "Adds context menu actions for copying the full/vault-relative path of files and folders."
    about:       "Copy full or vault-relative paths of files and folders from the context menu. Add an optional trailing slash to folder paths to distinguish them from files."
```
