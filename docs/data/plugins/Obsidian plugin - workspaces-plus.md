# Workspaces Plus

Shows the active workspace in the status bar, where a click opens a workspace picker and a shift-click saves the current layout. Workspaces are switched, created, renamed or deleted from the picker or from an assignable switcher modal. A workspace-name data attribute on the body element allows workspace-specific styling, and template variables override pages.
