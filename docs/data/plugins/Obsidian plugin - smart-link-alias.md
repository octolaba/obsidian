# Smart Link Alias

Smart Link Alias controls how internal links display a note title, using custom entries in the note frontmatter for a full title and a short title. Choosing short, full or long in the link alias then shows the abbreviation, the full title, or both.

```cue
plugin: {
    id:     "smart-link-alias"
    name:   "Smart Link Alias"
    author: "vpcano"
    repo:   "vpcano/obsidian-smart-link-alias"

    html_url:    "https://community.obsidian.md/plugins/smart-link-alias"
    github_url:  "https://github.com/vpcano/obsidian-smart-link-alias"
    description: "Enhance your internal links management with dynamic alias customization. Display short, full, or combined titles for your notes effortlessly."
    about:       "Define custom display titles in a note's YAML (full-title and short-title) to control how links render. Choose short, full, or long in link aliases to show an abbreviation, the full title, or both."

    stats: {
        downloads:  821
        updated_at: 1735218550000
    }
}
```
