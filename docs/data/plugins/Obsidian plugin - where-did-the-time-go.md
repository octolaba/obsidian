# Where Did The Time Go

Logs hours on an infinite-scroll timeline where entries are created by dragging, then moved, resized or clicked open for editing. The data is stored as plain Markdown tables inside the vault, and hierarchical reports show where the time went. Invoices are exported in one click, and the plugin works offline with no cloud service and no account.
