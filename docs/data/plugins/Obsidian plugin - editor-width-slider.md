# Editor Width Slider

Adds a slider to the status bar that changes the editor line width in real time. A single note can override that with an editor-width field between 0 and 100 in its YAML frontmatter, applied as a percentage of the viewport width.

```cue
plugin: {
    id:     "editor-width-slider"
    name:   "Editor Width Slider"
    author: "mugishomp"
    repo:   "mugishomp/obsidian-editor-width-slider"

    html_url:    "https://community.obsidian.md/plugins/editor-width-slider"
    github_url:  "https://github.com/mugishomp/obsidian-editor-width-slider"
    description: "Customize Obsidian's editor width with a slider for a tailored editing experience."
    about:       "Adjust editor line width with a simple status bar slider for real-time control. Set per-file widths by adding an editor-width field (0–100) in a note’s YAML frontmatter to apply a percentage of the viewport width."

    stats: {
        downloads:  80361
        updated_at: 1697622562000
    }
}
```
