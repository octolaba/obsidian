# Monday.com Integration

Monday.com Integration shows Monday.com boards and items inside notes or in a dedicated sidebar with real-time data. Board dashboards can be embedded, boards and team summaries browsed, and linked notes or tasks created from an item or from selected text. Statuses can be updated, people assigned and comments posted.
