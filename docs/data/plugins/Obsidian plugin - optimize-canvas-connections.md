# Optimize Canvas Connections

Optimize Canvas Connections declutters a canvas by reconnecting its notes through their nearest edges. Shortest-path mode produces the absolute shortest links, while preserve-axes mode keeps the original vertical or horizontal flow. It runs over the current selection, or over the whole canvas when nothing is selected.
