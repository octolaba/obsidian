# Git

The plugin brings Git into the vault, so commit, pull and push run from inside Obsidian, with scheduled commit-and-sync, auto-pull at startup and submodule support. It also stages and diffs files, browses commit history, shows line-change signs in the editor and opens items on GitHub.

```cue
plugin: {
    id:     "obsidian-git"
    name:   "Git"
    author: "Vinzent"
    repo:   "vinzent03/obsidian-git"

    html_url:    "https://community.obsidian.md/plugins/obsidian-git"
    github_url:  "https://github.com/vinzent03/obsidian-git"
    description: "Integrate Git version control with automatic backup and other advanced features."
    about:       "Integrate Git into your vault to commit, pull, and push changes directly from Obsidian. Automate scheduled commit-and-sync and auto-pull at startup, with submodule support. Stage and diff files, browse commit history, view editor line-change signs, and open items on GitHub."

    stats: {
        downloads:  2985309

    }
}
```
