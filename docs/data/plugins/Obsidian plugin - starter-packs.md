# Starter Packs

Named packs bundle community plugins and themes and are shared as links, short codes, Markdown or exported notes. A recipient previews or imports a pack and installs items individually or installs all missing ones with progress tracking, then enables the plugins or applies a theme. The recorded inputs state that plugin settings, CSS snippets and other Obsidian settings are not part of a pack.

```cue
plugin: {
    id:     "starter-packs"
    name:   "Starter Packs"
    author: "Grub Basket"
    repo:   "grub-basket/starter-packs"

    html_url:    "https://community.obsidian.md/plugins/starter-packs"
    github_url:  "https://github.com/grub-basket/starter-packs"
    description: "Create and share curated lists of community plugins. Share a pack as a link or code; recipients preview the pack and install everything in a couple of clicks. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create named starter packs that bundle community plugins and themes and share them as links, short codes, Markdown, or exportable notes. Import or preview a pack, install items individually or install all missing with progress tracking and notifications, then enable plugins or apply themes. Obviously plugin settings, CSS snippets, and other Obsidian settings are not included."

    stats: {
        downloads:  130
        updated_at: 1784819946000
    }
}
```
