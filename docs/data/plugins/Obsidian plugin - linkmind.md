# linkmind

Edits a Markdown note as an interactive mind map, rendering its headings and lists into an SVG and DOM tree and writing every change back to plain Markdown. The map is reorganized by keyboard or drag-and-drop, emoji and tags can be added, wikilinks can be followed across branches, and maps or single branches can be exported as SVG or PNG.
