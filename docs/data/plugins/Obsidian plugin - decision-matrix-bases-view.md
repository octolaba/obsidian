# Decision Matrix Bases View

Provides a weighted decision matrix as a custom view for Bases, scoring options across criteria and ranking the results. Scores are edited inline and saved back to frontmatter, weights are set per criterion and may be negative, and columns can be converted to ranks or normalized. Results appear as a scoring table or a ranked podium, with defined handling for ties and for blank against zero.
