# Etch - Weather

Writes daily weather forecasts into notes so they remain available locally and offline. An etch-weather code block, optionally carrying a date or coordinates, renders the forecast and saves it into the Markdown file as a historical record.

```cue
plugin: {
    id:     "etch-weather"
    name:   "Etch - Weather"
    author: "parente"
    repo:   "parente/obsidian-etch-weather"

    html_url:    "https://community.obsidian.md/plugins/etch-weather"
    github_url:  "https://github.com/parente/obsidian-etch-weather"
    description: "Etches weather forecasts into your local notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Etch daily weather forecasts into your notes for permanent, local, offline access. Insert an etch-weather fenced code block—optionally include a date or coordinates—to render and save the forecast in your Markdown file as a historical record."

    stats: {
        downloads:  210
        updated_at: 1767561259000
    }
}
```
