# Quick Emoji

Inserts emoji from an in-editor picker opened by typing a colon, searching names and descriptions with debounced results. Insertion happens as Unicode or as a shortcode, with shortcodes shown in Source Mode while Live Preview and Reading show the emoji itself. Recent emoji, favorites and skin tones are available, and loading is on demand.

```cue
plugin: {
    id:     "quick-emoji"
    name:   "Quick Emoji"
    author: "asibilia"
    repo:   "asibilia/obsidian-quick-emoji"

    html_url:    "https://community.obsidian.md/plugins/quick-emoji"
    github_url:  "https://github.com/asibilia/obsidian-quick-emoji"
    description: "Quick, in-editor, emoji inserting. Type \":\" to start selecting an emoji to insert."
    about:       "Insert emojis quickly from an in-editor picker by typing ':' and searching names or descriptions with fast, debounced results. Choose Unicode or shortcode insertion, view shortcodes in Source Mode while seeing emojis in Live Preview/Reading, and access recent emojis, favorites, skin tones, and cross-platform-compatible output via lightweight on-demand loading."

    stats: {
        downloads:  1407
        updated_at: 1755176276000
    }
}
```
