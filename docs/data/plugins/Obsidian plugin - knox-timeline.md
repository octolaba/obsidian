# Knox Timeline

Shows a timeline of a Fastmail calendar, or read-only iCal and calDAV URLs, in a sidebar leaf with single-day or two-day views and an all-day events strip. A meeting note can be created from any event with one click. Calendars can be toggled, noisy events hidden, and the view refreshes automatically at midnight.
