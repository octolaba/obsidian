# LJ OS

Builds standalone local Git activity snapshots for daily notes, turning local repositories into a daily-note Git wall. Scan roots are added, repositories discovered, and cached activity snapshots refreshed in the background, with summary metrics, per-repo activity, unpushed commits, tidy-up queues, and reorderable dashboard sections. The recorded inputs state that everything stays local, with no login, APIs, cloud service, or companion app.

Review summary metrics, per-repo activity, unpushed commits, tidy-up queues, and reorder dashboard sections to fit your workflow. Everything stays local: no login, no APIs, no cloud service, and no companion app."
