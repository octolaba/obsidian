# Publish to Telegram

Posts notes directly to Telegram channels, groups, forum topics and personal messages, either as your own account or as a bot. Standard and rich-text Telegram formatting, media and document attachments and custom emoji are supported. Publishing settings allow previewing each message, scheduling it, splitting one note across several posts, and editing what has already been published.
