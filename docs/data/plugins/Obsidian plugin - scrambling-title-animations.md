# Scrambling Title Animations

Scrambling Title Animations animates the title of a note when it is opened, scrambling the text and then revealing it. Several scramble styles are available, producing different title transitions.

```cue
plugin: {
    id:     "scrambling-title-animations"
    name:   "Scrambling Title Animations"
    author: "dvorakdwarf"
    repo:   "dvorakdwarf/scrambling-title-animations"

    html_url:    "https://community.obsidian.md/plugins/scrambling-title-animations"
    github_url:  "https://github.com/dvorakdwarf/scrambling-title-animations"
    description: "Animates the title of any note you open by scrambling and revealing it in several visually appealing ways."
```
