# Note Heatmap

Note Heatmap draws note activity as a GitHub-style annual heatmap with five levels of colour depth. Edits are read from frontmatter date fields, accepting ISO strings, list-format dates and Obsidian date objects, so a note contributes to every day on which it was edited. Clicking a day lists the notes modified then, clicking a month gives a summary, and daily, monthly and yearly notes can be opened from the grid; per-file Git diffs appear when a Git or version-history plugin is available.
