# AI Selection Toolbar

Shows a floating toolbar when text is selected, offering read aloud, translate, explain, summarize and word lookup in one click. Results stream from OpenAI or Ollama, or use built-in browser text-to-speech, with phonetics and example sentences displayed. Output can be inserted, copied or used to replace the selection.
