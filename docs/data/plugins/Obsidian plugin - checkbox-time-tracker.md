# Checkbox Time Tracker

Checkbox Time Tracker writes a timestamp when a checkbox is checked off, recording a time or a date. Start and end times can both be recorded, with optional dates and links to daily notes, and a duplicate end date is omitted to keep the log compact.

```cue
plugin: {
    id:     "checkbox-time-tracker"
    name:   "Checkbox Time Tracker"
    author: "udus122"
    repo:   "udus122/checkbox-time-tracker"

    html_url:    "https://community.obsidian.md/plugins/checkbox-time-tracker"
    github_url:  "https://github.com/udus122/checkbox-time-tracker"
    description: "Insert timestamp when you check off the checkbox"
    about:       "Insert timestamps when you check off checkboxes to record time or date. Record start and end times for tasks with optional dates, links to daily notes, and automatic omission of duplicate end dates to keep logs compact."

        downloads:  3308
```
