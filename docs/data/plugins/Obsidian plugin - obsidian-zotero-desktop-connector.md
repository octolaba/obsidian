# Zotero Integration

Citations, bibliographies, item notes and PDF annotations are inserted and imported from Zotero into Obsidian. Better BibTeX is used on the Zotero side for compatible exports and formatted citations.

```cue
plugin: {
    id:     "obsidian-zotero-desktop-connector"
    name:   "Zotero Integration"
    author: "obsidian-community"
    repo:   "obsidian-community/obsidian-zotero-integration"

    html_url:    "https://community.obsidian.md/plugins/obsidian-zotero-desktop-connector"
    github_url:  "https://github.com/obsidian-community/obsidian-zotero-integration"
```
