# Advanced Word Count

Advanced Word Count defines word-count presets shown in the status bar or a right pane tab, covering words, pages, characters with and without spaces, lines, paragraphs, markdown links, wikilinks and citekeys. Presets specify how formatting elements are counted, cycle quickly, and carry limit warnings and writing goals. Community extensions install further presets, metrics and settings.
