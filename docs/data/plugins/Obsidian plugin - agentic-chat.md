# Agentic Chat

Agentic Chat runs an agent-led AI chat in the right sidebar that acts on the vault directly, reading, searching, writing, editing, renaming, traversing links and managing frontmatter. Every tool call is rendered inline, mutating actions are gated by approval and deletions go to trash. Requests are routed to zero-data-retention providers by default, or kept local with Ollama.
