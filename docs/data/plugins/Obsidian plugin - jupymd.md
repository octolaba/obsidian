# JupyMD

Brings Jupyter notebook support into the vault for interactive programming, live outputs and notebook syncing. Python code can be run from notes, with matplotlib plots, pandas dataframe analysis and model building using sklearn or pytorch. The project states that it is independent and not affiliated with Project Jupyter, Jupytext or Obsidian.
