# Smart Link Note

Smart Link Note creates a new note linked bidirectionally to the active file and appends a backlink to both notes. Wiki-style links to a note title can be copied to the clipboard from the active note or from the file explorer context menu. It can also insert an empty wiki link at the cursor and trigger the Obsidian link autocomplete.

```cue
plugin: {
    id:     "smart-link-note"
    name:   "Smart Link Note"
    author: "ShaneJ"
    repo:   "whiteblack1858/smart-link-note"

    html_url:    "https://community.obsidian.md/plugins/smart-link-note"
    github_url:  "https://github.com/whiteblack1858/smart-link-note"
    description: "Create new notes, auto-link, and copy wiki links easily - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create new notes linked bidirectionally to the active file and automatically append backlinks to both notes. Copy wiki-style [[Note Title]] links to the clipboard from the active note or via the file explorer context menu. Insert [[]] at the cursor and trigger Obsidian's link autocomplete for fast linking."

}
```
