# Edit MDX

Registers .mdx as a Markdown type so those files can be created and edited as plain Markdown in Obsidian. A ribbon button and a file context-menu entry create new .mdx files. MDX content is not previewed; it is edited in raw Markdown mode.

```cue
plugin: {
    id:     "edit-mdx"
    name:   "Edit MDX"
    author: "timppeters"
    repo:   "timppeters/obsidian-edit-mdx"

    html_url:    "https://community.obsidian.md/plugins/edit-mdx"
    github_url:  "https://github.com/timppeters/obsidian-edit-mdx"
    description: "Edit and create .mdx files."
    about:       "Create and edit .mdx files as plain Markdown directly in Obsidian. Register .mdx as a markdown type and add a ribbon button plus a file context-menu item to create new .mdx files. Do not preview MDX content; edit in raw markdown mode."

    stats: {

}
```
