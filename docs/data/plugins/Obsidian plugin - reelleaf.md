# ReelLeaf

Syncs public web pages, images and videos captured through ReelLeaf into the vault as structured Markdown notes with their attachments. Notes are written into a dedicated dated folder, attachments are verified by SHA-256, and duplicates or overwrites are prevented. The access token is stored locally.
