# Note Pilot

Adds an AI work panel that answers questions about the active note or a text selection, connecting either to major providers or to local endpoints. Requests that would write are turned into reviewed vault actions — creating, appending, or modifying Markdown files — and are applied only after they are inspected and confirmed.
