# Yandex Calendar Integration

Inserts the events of the day from Yandex Calendar into daily notes using a customizable template. The formatted events are placed at the cursor position, and the Yandex app password used for access is stored by the plugin.

```cue
plugin: {
    id:     "yandex-calendar-integration"
    name:   "Yandex Calendar Integration"
    author: "caduct-3ateuhuk"
    repo:   "caduct-3ateuhuk/obsidian-yandex-calendar-integration"

    html_url:    "https://community.obsidian.md/plugins/yandex-calendar-integration"
    github_url:  "https://github.com/caduct-3ateuhuk/obsidian-yandex-calendar-integration"
    description: "Plugin for integrating daily notes with Yandex Calendar. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync Yandex Calendar with Obsidian and insert today's events into your daily notes using a customizable template. Store your Yandex app password securely and insert formatted events at the cursor position automatically."

    stats: {
        downloads:  160
        updated_at: 1764128751000
    }
}
```
