# Slash Blocks

Slash Blocks opens a quick-access block menu when a slash is typed at the start of a line, inserting common Markdown blocks directly. Tasks, headings, lists, quotes, dividers, images and attachments are offered, and the correct Markdown is inserted with the cursor left ready for editing.

```cue
plugin: {
    id:     "slash-blocks"
    name:   "Slash Blocks"
    author: "Stefan Imbesi"
    repo:   "stefan-imbesi/obsidian-slash-blocks"

    html_url:    "https://community.obsidian.md/plugins/slash-blocks"
    github_url:  "https://github.com/stefan-imbesi/obsidian-slash-blocks"
    description: "Type `/` to open a menu and insert content blocks (task, headings, lists, etc.). - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Type / at the start of a line to open a quick-access block menu and insert common Markdown blocks instantly. Choose tasks, headings, lists, quotes, dividers, images or attachments and get the correct Markdown inserted with the cursor ready for editing."

    stats: {
        downloads:  167
        updated_at: 1778976457000
    }
}
```
