# NoteFlare

Publishes a whole vault, a folder or a single note as a static website, and keeps automatic private backups, without a terminal or a backend to manage. Deployment goes through Cloudflare Pages or GitHub Pages, one-way GitHub backups can be automated, several sites can be managed from one vault, and the recorded description states that API tokens are kept encrypted in the operating system keychain.
