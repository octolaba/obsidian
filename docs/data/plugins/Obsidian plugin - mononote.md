# Mononote

Mononote keeps each note to a single tab per pane: when the note is already open, its existing tab is focused instead of opening the same file again. It applies to notes opened through links, menus and hotkeys, and it asks that the Editor setting Always focus new tabs be enabled for correct operation.

```cue
plugin: {
    id:     "mononote"
    name:   "Mononote"
    author: "Carlo Zottmann"
    repo:   "czottmann/obsidian-mononote"

    html_url:    "https://community.obsidian.md/plugins/mononote"
    github_url:  "https://github.com/czottmann/obsidian-mononote"
    description: "Ensure each note occupies only one tab. If a note is already open, its existing tab will be focussed instead of opening the same file in the current tab."
    about:       "Keep each note to a single tab per pane by focusing its existing tab instead of opening duplicates. Enable Editor → Always focus new tabs to ensure correct operation; works for opening notes via links, menus, and hotkeys."

    stats: {
        downloads:  31846

    }
}
```
