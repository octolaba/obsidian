# GTD Workflow

Arranges notes into a GTD folder structure of Inbox, Next Actions, Waiting, Someday and Projects, using Markdown checkboxes with org-mode style metadata such as TODO and DONE states, priorities and scheduled or deadline dates. Tasks can be captured quickly, time tracked with CLOCK records and a built-in Pomodoro, and reviewed through agenda, 24-hour timeline and time statistics views with CSV export. Inline priorities and task indentation are adjustable, and both Chinese and English metadata are supported.
