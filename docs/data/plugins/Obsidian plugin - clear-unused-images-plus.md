# Clear Unused Images Plus

Removes image files that no longer appear in any Markdown note, comparing the links found in documents against the files in the vault. Cleanups run when the vault loads or at a set interval, and removed images go to the Obsidian trash, to the system trash, or are deleted permanently. It is recorded as a fork of oz-clear-unused-images.

```cue
plugin: {
    id:     "clear-unused-images-plus"
    name:   "Clear Unused Images Plus"
    author: "puhhh"
    repo:   "puhhh/clear-unused-images-obsidian"

    html_url:    "https://community.obsidian.md/plugins/clear-unused-images-plus"
    github_url:  "https://github.com/puhhh/clear-unused-images-obsidian"
    description: "Fork of oz-clear-unused-images for clearing unused images from vaults. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Remove image files no longer referenced in your Markdown notes by scanning document links and comparing them to vault files. Run cleanups automatically on vault load or at set intervals, and choose where removed images go (Obsidian trash, system trash, or permanent delete)."
```
