# IStart-Note-AI

IStart-Note-AI generates structured knowledge notes from a question or selected text using DeepSeek, creating concept pages with source references, backlinks and bidirectional links. Questions are classified as new, refinement or expansion and tracked in a question graph index, and concepts can be appended to or completed in batches. Incremental backups are synced to Baidu Netdisk.
