# Foxycape PDF

Reads PDFs inside Obsidian and syncs highlights into Markdown notes, appending the excerpt and a backlink to its exact source. Embedded images can be extracted, and text or image citations copied with precise deep links that carry page, selection and mark identifiers. Page colouring follows the active theme.

```cue
plugin: {
    id:     "foxycape-pdf"
    name:   "Foxycape PDF"
    author: "jansxue"
    repo:   "foxycape/obsidian-pdf"

    html_url:    "https://community.obsidian.md/plugins/foxycape-pdf"
    github_url:  "https://github.com/foxycape/obsidian-pdf"
    description: "Embed Foxycape PDF reader in Obsidian with annotation sync. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Read PDFs inside Obsidian and sync highlights into Markdown notes that append excerpts and backlinks to the exact source. Extract embedded images, copy text and image citations with precise #page/#selection/#markId deep links, and apply theme-aware page coloring to match your vault."

    stats: {
        downloads:  1
        updated_at: 1786445403000
    }
}
```
