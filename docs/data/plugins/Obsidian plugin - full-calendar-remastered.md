# Full Calendar Remastered

Keeps a calendar inside the vault with a FullCalendar view whose events link directly to notes. Each event is stored as a separate note with frontmatter, and the plugin syncs across Daily Notes, frontmatter-based notes, read-only ICS, two-way CalDAV and Google Calendar, Bases and Obsidian Tasks.
