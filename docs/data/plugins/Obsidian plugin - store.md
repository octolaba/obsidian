# Store

Store uses UUIDs as note filenames, flattening a vault that would otherwise rely on deeply nested folders and descriptive names, and automates the day-to-day steps that this kind of workflow needs. A backup of the vault before the first use is advised.

```cue

    id:     "store"
    name:   "Store"
    author: "shimeoki"
    repo:   "shimeoki/obsidian-store"

    html_url:    "https://community.obsidian.md/plugins/store"
    github_url:  "https://github.com/shimeoki/obsidian-store"
    description: "Manage your notes within a single store. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Are you tired of managing deep nested folders and filenames? Store uses UUIDs as the filenames to effectively flatten your vault.
```
