# Simple Kanban

Simple Kanban presents the notes of a folder as Kanban cards in configurable columns driven by a frontmatter status property. Folders are scanned recursively for Markdown notes, drag and drop updates the files immediately, and cards can show custom frontmatter fields. Special columns collect notes whose status is missing or unknown.

plugin: {
    id:     "simple-kanban"
    name:   "Simple Kanban"
    author: "denis2710"
    repo:   "denis2710/simple-kanban"

    html_url:    "https://community.obsidian.md/plugins/simple-kanban"
    github_url:  "https://github.com/denis2710/simple-kanban"
    description: "Kanban view for folder with status-based columns and drag & drop. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Organize notes as Kanban cards in configurable columns driven by a frontmatter status property. Drag and drop to update files instantly, scan folders recursively for .md notes, show custom frontmatter fields on cards, and use special columns for missing or unknown statuses."
