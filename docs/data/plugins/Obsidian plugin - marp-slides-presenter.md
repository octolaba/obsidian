# Marp Slides Presenter

Marp Slides Presenter creates and presents Marp Markdown slides with a live preview and either fullscreen or popout presentation. A presenter view shows the current and next slide, the speaker notes and an elapsed timer, and a built-in laser pointer can be toggled while presenting. Slides export to HTML, PDF, PNG, image-based PPTX or editable PPTX for PowerPoint.
