# Custom Image Auto Uploader

Uploads images from notes to a remote server, a home NAS or cloud storage, with WebDAV, Amazon S3, Alibaba Cloud OSS, Cloudflare R2, MinIO and self-hosted endpoints named, one image at a time or in batch across the vault. Images can be cropped, compressed, resized or stretched before upload, uploading can be triggered by drag-and-drop or paste, and unlinked local images removed in a single action. The recorded inputs name Windows, macOS, Linux, Android and iOS.
