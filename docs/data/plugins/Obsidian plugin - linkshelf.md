# LinkStowr

Saves links from the browser into the vault by syncing bookmarks captured with the LinkStowr Chrome extension as Markdown files built from customizable templates. Title, URL, tags, and notes are captured, and the recorded inputs state that the remote copies are removed so the vault becomes the long-term home for those links.

```cue
plugin: {
    id:     "linkshelf"
    name:   "LinkStowr"
    author: "joelseq"
    repo:   "joelseq/obsidian-linkstowr"

    html_url:    "https://community.obsidian.md/plugins/linkshelf"
    github_url:  "https://github.com/joelseq/obsidian-linkstowr"
    description: "Save links from your browser."
    about:       "Sync bookmarks saved with the LinkStowr Chrome extension into your Obsidian vault as Markdown files using customizable templates. Capture title, URL, tags and notes, and remove remote copies so your vault becomes the long-term home for those links."
```
