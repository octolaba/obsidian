# Paste image rename

This plugin renames images after pasting through an editable prompt, replacing the internal links automatically. Filenames can be generated from custom name patterns or from frontmatter keys, and other attachments are covered as well. Attachments can also be renamed in batches.

```cue
plugin: {
    id:     "obsidian-paste-image-rename"
    name:   "Paste image rename"
    author: "reorx"
    repo:   "reorx/obsidian-paste-image-rename"

    html_url:    "https://community.obsidian.md/plugins/obsidian-paste-image-rename"
    github_url:  "https://github.com/reorx/obsidian-paste-image-rename"
    description: "Rename image after pasting, support name pattern and auto renaming."
    about:       "Rename pasted images and other attachments via an editable prompt that replaces internal links automatically. Auto-generate filenames from custom patterns or frontmatter keys and batch-rename attachments to keep your vault organized."

    stats: {
        downloads:  153737
        updated_at: 1675069703000
    }
}
```
