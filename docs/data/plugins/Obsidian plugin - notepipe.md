# NotePipe

Copies selected text together with its file path and line numbers as a Markdown blockquote, formatted for pasting into an AI agent terminal. A floating button appears near a selection in edit and reading modes, file-explorer selections are handled, absolute filesystem paths are produced, and a customizable template controls how path, line and selection are laid out.
