# Base View Switcher

Base View Switcher adds custom view-switching buttons to the title bar of a Base, generated from the named views recorded in a .base file's frontmatter and shown as icons alone or as icons with names. Unneeded toolbar elements can be hidden, an always-visible home button added, and each .base file given its own configuration with icon selection and drag ordering. The recorded About text for this plugin is written in Chinese; this summary restates it in English.
