# Quip

Imports Quip documents into the vault as notes and publishes new notes to Quip as HTML. An existing Quip document is updated with a fresh rendering of its Obsidian note. A connection to your Quip account carries content in both directions.

```cue
plugin: {
    id:     "quip"
    name:   "Quip"
    author: "sblakey"
    repo:   "sblakey/obsidian-quip"

    html_url:    "https://community.obsidian.md/plugins/quip"
    github_url:  "https://github.com/sblakey/obsidian-quip"
    description: "Commands to publish notes to Quip.com."
    about:       "Import Quip documents into Obsidian as notes. Publish new Obsidian notes to Quip as HTML and update existing Quip documents with fresh Obsidian renderings. Connect to your Quip account to sync content between Obsidian and Quip."

    stats: {
        downloads:  7360
        updated_at: 1713818778000
    }
}
```
