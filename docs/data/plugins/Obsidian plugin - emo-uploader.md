# Emo

Emo uploads images to hosting platforms and files to GitHub, then writes the resulting Markdown image or file link into the note. Clipboard and drag-and-drop input are accepted, and the output is either an inline image or a plain file link. Providers include GitHub, Imgur, Cloudinary, SM.MS and Catbox, and the interface is multilingual.

```cue
plugin: {
    id:     "emo-uploader"
    name:   "Emo"
    author: "yaleiyale"
    repo:   "yaleiyale/obsidian-emo-uploader"

    html_url:    "https://community.obsidian.md/plugins/emo-uploader"
    github_url:  "https://github.com/yaleiyale/obsidian-emo-uploader"
    description: "Upload images to hosting platforms, or files to GitHub and embed them as Markdown file/image links."
    about:       "Upload images and files to multiple hosting services and embed Markdown links directly into notes. Support clipboard and drag-and-drop, output inline images or plain file links, and connect to GitHub, Imgur, Cloudinary, SM.MS, Catbox and other providers with multilingual support."

    stats: {
        downloads:  5833
        updated_at: 1723268666000
    }
}
```
