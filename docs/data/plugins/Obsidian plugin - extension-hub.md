# Extension Hub

Extension Hub browses GitHub, the Official Community Archive and the Obsidian Forum to find plugins and announcements. Plugins are installed and updated across multiple vaults at once or across a selected subset, and available updates can be checked and selected. Groups of plugins are saved as Sets and deployed together.

```cue
plugin: {
    id:     "extension-hub"
    name:   "Extension Hub"
    author: "Jan Sandström"
    repo:   "pixerojan/obsidian-extension-hub"

    html_url:    "https://community.obsidian.md/plugins/extension-hub"
    github_url:  "https://github.com/pixerojan/obsidian-extension-hub"
    description: "Browse GitHub and the community forum to install plugins across multiple vaults simultaneously. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Browse GitHub, the Official Community Archive, and the Obsidian Forum to find plugins and announcements. Install and update plugins across multiple vaults or selected vaults, save plugin Sets to deploy groups at once, and check/select available updates."

    stats: {
        downloads:  2460
        updated_at: 1778757899000
    }
}
```
