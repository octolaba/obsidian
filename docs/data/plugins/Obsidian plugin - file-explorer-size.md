# File Explorer Size

File Explorer Size shows file sizes and recursive folder totals in the file explorer and in the MAKE.md Navigator. Large items are highlighted in red, and a separate sidebar ranks the largest files and folders. Sizes are updated incrementally as files are created, modified, moved or deleted.
