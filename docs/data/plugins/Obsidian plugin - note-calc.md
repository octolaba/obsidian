# Note Calc

Note Calc evaluates the arithmetic on any line ending with an equals sign and shows the result inline in Live Preview and Reading view, leaving the Markdown source unchanged. It handles addition, subtraction, multiplication, division, percentages, exponentiation, parentheses, decimals and scientific notation, and ignores code blocks, math, frontmatter and links. The recorded description states that answers are never written into the file.
