# CSV Codeblock

Renders csv and tsv code blocks as tables inside notes. Comma-separated or tab-separated rows are parsed into HTML table cells for inline display.

```cue
plugin: {
    id:     "csv-codeblock"
    name:   "CSV Codeblock"
    author: "elrindir"
    repo:   "elrindir/obsidian-csv-codeblock"

    html_url:    "https://community.obsidian.md/plugins/csv-codeblock"
    github_url:  "https://github.com/elrindir/obsidian-csv-codeblock"
    description: "Render code blocks with CSV format."
```
