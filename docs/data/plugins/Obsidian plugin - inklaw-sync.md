# Inklaw Sync

Syncs notes forwarded to the Inklaw service, where they are transcribed and polished, into the vault together with cover images and media attachments. Incoming notes land in a chosen folder and the plugin works on desktop and mobile, requiring an Inklaw account and a personal sync token.

```cue
plugin: {
    id:     "inklaw-sync"
    name:   "Inklaw Sync"
    author: "墨爪 Inklaw"
    repo:   "jsjixu/obsidian-inklaw-sync"

    html_url:    "https://community.obsidian.md/plugins/inklaw-sync"
    github_url:  "https://github.com/jsjixu/obsidian-inklaw-sync"
    description: "Sync notes you forwarded to Inklaw (auto-transcribed and polished) into your vault, with media attachments. Works on desktop and mobile. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync notes forwarded to Inklaw into your Obsidian vault automatically, pulling finished, transcribed notes with cover images and media. Store incoming notes in a chosen folder and keep your vault up-to-date; requires an Inklaw account and personal sync token."

    stats: {
        downloads:  93
        updated_at: 1782976286000
    }
}
```
