# Better Flashcards

Better Flashcards synchronizes flashcards with Anki through AnkiConnect, creating, updating and deleting cards directly from Markdown. Simple, reversed, spaced, inline question-and-answer and cloze cards are supported, along with LaTeX, images, audio, code highlighting, global and local tags, note references and Obsidian URI links. The recorded description identifies it as a fork of the original Flashcards plugin with bug fixes.
