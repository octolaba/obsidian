# Image to Markdown

Transcribes the images and PDFs embedded in a note into editable Markdown with an OpenAI-compatible vision model that the recorded inputs describe as local and fully offline. Transcripts stream into the sidebar and land as one transcript note per image, leaving the originals unchanged, and the model's reasoning is shown in expandable thinking blocks.
