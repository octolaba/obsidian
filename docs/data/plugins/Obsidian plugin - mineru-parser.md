# MinerU Parser

MinerU Parser parses a document from the file explorer into Markdown, singly or in batches, through the right-click menu. Note content and image attachments are saved to separate customizable folders using {filename}, {date}, {noteName} and rename templates. Seven parsing backends, cloud and local, are available, and progress plus success and failure summaries are reported.
