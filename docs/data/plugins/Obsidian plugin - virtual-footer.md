# Virtual Content

Virtual Content displays Markdown at the bottom or top of a note, or in the sidebar, for every note matching a rule based on folder, tag, property or Dataview. The rendered content can include Dataview, Datacore and Bases output, and the notes themselves are never modified. Source text comes from the plugin settings or from a vault file, so the same block is not duplicated.

```cue
plugin: {
    id:     "virtual-footer"
    name:   "Virtual Content"
    author: "signynt"
    repo:   "signynt/virtual-content"

    html_url:    "https://community.obsidian.md/plugins/virtual-footer"
    github_url:  "https://github.com/signynt/virtual-content"
    description: "Display markdown text (including dataview queries or Bases) at the bottom, top or in the sidebar for all notes which match a specified rule, without modifying them."
    about:       "Add virtual headers, footers, or sidebar panels to notes based on folder, tag, property, or Dataview rules. Render full Markdown (including Dataview, Datacore and Bases) without changing files and source content from plugin settings or a vault file to avoid duplicating code."

    stats: {
        downloads:  9507
        updated_at: 1784380557000
    }
}
```
