# PDF++

Turns backlinks and text-selection links into highlight annotations on a PDF, and can embed annotations into the PDF file so that they are visible outside Obsidian. The built-in PDF viewer is extended, and sidenotes are stored as plain Markdown across the vault so that annotations stay readable and portable.

    id:     "pdf-plus"
    name:   "PDF++"
    author: "ryotaushio"
