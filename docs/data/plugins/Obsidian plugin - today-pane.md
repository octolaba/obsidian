# Today Pane

Today Pane keeps today's daily note open in the right side panel from startup. If the note is missing it is created from the configured template with the template's frontmatter date replaced by today's date, duplicate opens are prevented, and the pane is desktop-only.

```cue
plugin: {
    id:     "today-pane"
    name:   "Today Pane"
    author: "imaikosuke"
    repo:   "imaikosuke/obsidian-today-pane"

    html_url:    "https://community.obsidian.md/plugins/today-pane"
    github_url:  "https://github.com/imaikosuke/obsidian-today-pane"
    description: "Always display today's daily note in a side panel. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Display today's daily note in the right sidebar at startup to keep daily records and tasks immediately accessible. Create today's note from your template if missing, replace the template's frontmatter date with today's date, prevent duplicate opens, and keep the pane desktop-only."

    stats: {
        downloads:  506
        updated_at: 1781708547000
    }
}
```
