# Relative Line Numbers

This plugin enables relative line numbers in editor mode, mirroring Vim's relativenumber so the distance to other lines is visible. Line numbers have to be enabled in the editor options; the current line then reads as 0 and every other line as its distance.

```cue
plugin: {
    id:     "obsidian-relative-line-numbers"
    name:   "Relative Line Numbers"
    author: "nadavspi"
    repo:   "nadavspi/obsidian-relative-line-numbers"

    html_url:    "https://community.obsidian.md/plugins/obsidian-relative-line-numbers"
    github_url:  "https://github.com/nadavspi/obsidian-relative-line-numbers"
    description: "Enable relative line numbers in editor mode."
    about:       "Display relative line numbers in Obsidian's editor mode, mirroring Vim's relativenumber for quick movement context. Enable line numbers in Editor options to show the current line as 0 and other lines as distance counts."
```
