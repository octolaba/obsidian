# Kanban Sync

Syncs Kanban board state into note frontmatter: when a card moves between columns, the linked note's state field is updated automatically. Several Kanban files can be monitored at once, and the column name detected from the heading is written as the state value in uppercase.

```cue
plugin: {
    id:     "kanban-sync"
    name:   "Kanban Sync"
    author: "jcacdc"
    repo:   "jcacdc/obsidian-kanban-sync"

    html_url:    "https://community.obsidian.md/plugins/kanban-sync"
    github_url:  "https://github.com/jcacdc/obsidian-kanban-sync"
    description: "Syncs Kanban board state with note frontmatter. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync Kanban card column changes to the linked note's frontmatter state field automatically when cards move between columns. Monitor multiple Kanban files and use column names (detected from headings) as the state value in uppercase."

    stats: {
        downloads:  1549
        updated_at: 1778379664000
    }
}
```
