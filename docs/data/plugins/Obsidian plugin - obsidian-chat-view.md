# Chat View

Chat View builds chat interfaces inside Markdown files from a minimal format, and also reads WebVTT, ZenDesk and Intercom transcripts. Message bodies may span several lines and render full Markdown, blocks can be aligned left, right or centre, headers are auto-coloured for up to eight participants, and comments and delimiters are supported. Chat blocks are styled for both light and dark mode.

    id:     "obsidian-chat-view"

We have a host of styling features that include: - Writing multi-line message bodies that render full-blown markdown! - Chat blocks that look good in both light & dark mode. - Aligning chat blocks left, right and center. - Auto-colored headers that accept up to 8 participants. - The ability to add comments and delimiters."
