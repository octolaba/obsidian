# SideCard

SideCard keeps Markdown notes, PDFs and images visible as cards in a sidebar library for cross-referencing while writing. Vault files are found by search or by dragging an editor tab into a card, cards are reordered, resized and pinned, content previews inline, and a Markdown reference to a card's source can be inserted.
