# Mini-RAG

Mini-RAG chats with a locally running Ollama model, using the content of selected notes and folders as retrieval-augmented context. Chats open from the note or folder menu, any installed Ollama model can answer, and conversations are saved back into the vault. It runs on desktop against a local Ollama instance.

plugin: {
    id:     "mini-rag"
    name:   "Mini-RAG"
    author: "jjwheatley"
    repo:   "jjwheatley/mini-rag"

    html_url:    "https://community.obsidian.md/plugins/mini-rag"
    github_url:  "https://github.com/jjwheatley/mini-rag"
    description: "Leverage Retrieval Augmented Generation (RAG) for your notes using a locally running LLM or AI."
    about:       "Chat with a locally running Ollama LLM using the content of selected Obsidian notes and folders as context. Open chats from note or folder menus, pick any installed Ollama model for responses, and save conversations back into your vault. Run on desktop with a local Ollama instance."
