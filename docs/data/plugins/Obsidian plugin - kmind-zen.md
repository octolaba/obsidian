# KMind Zen

Brings the KMind Zen mind mapping editor into Obsidian, where local-first .kmindz maps are created and edited inside the vault, XMind files can be imported, and the same map opens in SiYuan Note, the web app and other KMind Zen hosts. Maps support rich-text nodes, a formula editor, recursive summary nodes, node backlinks, node notes, comments and a multi-hyperlink system that attaches several links to one node. Light and dark themes adapt to the environment, and a theme editor allows a custom visual style. The project states that map contents stay local during normal editing and are not uploaded for license activation, and that unlimited local maps and nodes are free to manage.
