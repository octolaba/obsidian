# SQLSeal

Files, tags and tasks in the vault are queried with SQL syntax from inside a note. CSV files are previewed as tables and declared as in-note tables so that SELECT queries run across them. Edits made to tasks in a query result are applied back to the source Markdown files.

```cue
plugin: {
    id:     "sqlseal"
    name:   "SQLSeal"
    author: "h-sphere"
    repo:   "h-sphere/sql-seal"

    html_url:    "https://community.obsidian.md/plugins/sqlseal"
    github_url:  "https://github.com/h-sphere/sql-seal"
```
