# Talon CQL

Talon CQL adds syntax highlighting for CrowdStrike CQL, the LogScale Query Language, inside code blocks, in both edit and preview modes, and accepts logscale as an alias. Event fields, built-in and namespaced functions, keywords, operators, strings, regex, numbers and comments are highlighted. Ready-to-use hunting query templates are included.
