# Easy LaTeX

Auto-completes LaTeX commands inside math zones - inline math, display math and LaTeX code blocks - from a searchable list of more than 200 commands, filtered by prefix or by description. Chinese, English, Japanese and Korean math keywords match commands without typing a backslash, and a formula can be generated from a natural-language description through any OpenAI-compatible API.
