# DataCharts

Renders interactive charts and plots mathematical functions directly in Markdown. Chart.js supplies line, bar, scatter, pie and radar charts, Mathjs parses the equations, and the data comes from Markdown tables or from manually entered datasets. Styling, zoom, pan and inspection are configurable, and a chart exports as PNG or SVG.
