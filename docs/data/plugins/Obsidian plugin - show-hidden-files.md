# Show Hidden Files

Show Hidden Files reveals hidden dotfiles and dotfolders in the file explorer and exposes unsupported file types such as env, gitignore, json and yml files. It stays in step with Obsidian's native file-extension detection and fully reverts the visibility changes when the plugin is disabled.

```cue
plugin: {
    id:     "show-hidden-files"
    name:   "Show Hidden Files"
    author: "witi42"
    repo:   "witi42/obsidian-show-hidden-files"

    html_url:    "https://community.obsidian.md/plugins/show-hidden-files"
    github_url:  "https://github.com/witi42/obsidian-show-hidden-files"
    description: "Reveals hidden dotfiles and all file types in the file explorer. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Reveal hidden dotfiles and dotfolders and expose unsupported file types (e.g., .env, .gitignore, .json, .yml) directly in the Obsidian file explorer. Sync with Obsidian's native file-extension detection and fully revert visibility when the plugin is disabled."

    stats: {
        downloads:  7091
        updated_at: 1776285188000
    }
}
```
