# Git File Explorer

Adds Git information from detected repositories to the file explorer, showing repository status, changed-file counts and markers for uncommitted changes. Changes can be staged and committed in one click with an optionally generated message, pull-then-push syncs run manually or on a schedule, the system diff tool opens from the context menu, and repositories can be initialized from the explorer.

```cue
plugin: {
    id:     "git-file-explorer"
    name:   "Git File Explorer"
    author: "mateusmolina"
    repo:   "mateusmolina/obsidian-git-file-explorer"

    html_url:    "https://community.obsidian.md/plugins/git-file-explorer"
    github_url:  "https://github.com/mateusmolina/obsidian-git-file-explorer"
    description: "Add relevant git information of detected git repositories to the file explorer."
    about:       "Integrate Git into the file explorer to show repository status, changed-file counts, and visual markers for uncommitted changes. Stage and commit all changes in one click with optional auto-generated messages. Run pull-then-push syncs with visual feedback or scheduled auto-sync, open the system diff tool from the context menu, and initialize repositories from the explorer."

    stats: {
        downloads:  3480

    }
}
```
