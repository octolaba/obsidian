# Checkbox Progress

Shows a checkbox completion counter in the status bar and a progress bar with a reset button in the note header, on desktop and mobile alike. Every checkbox state in the active note is counted, including checked, unchecked and indeterminate, while code blocks and frontmatter are ignored. The display hides itself when a note contains no checkboxes.
