# Task List Kanban

Task List Kanban imports every Markdown task item in the vault into a live kanban board that stays synced with the original files. Columns are assigned by tags, tasks are dragged to reorder, and items can be archived or cancelled. Filters narrow the board, and a task jumps back to its source file.
