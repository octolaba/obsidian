# Onto Tracker

Onto Tracker manages projects against an ontology by tracking a source folder and categorizing its files with user-defined rules. Freezes snapshot file metadata and notes, ontologies are unpacked into the vault, and ontology metadata is mapped onto files for tasks such as CMS uploads.
