# Spark Assistant

Automations are defined as files, and agents are triggered from Markdown, from slash commands and from mentions. A persistent chat widget works against the whole vault, multi-step workflows are assembled visually, and a file change can run a workflow whose results are written back into notes. The recorded inputs describe this as turning Obsidian into an AI-driven business operating system.
