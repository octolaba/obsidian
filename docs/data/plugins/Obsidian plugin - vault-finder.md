# Vault Finder

Searches the vault with a fast local full-text index that uses n-gram tokenization for mixed Chinese and English content. Vector retrieval, AI-assisted keyword expansion, relevance filtering and concise result summarization are optional additions. Summaries can be saved as notes, and earlier searches revisited from a keyboard-navigable sidebar.
