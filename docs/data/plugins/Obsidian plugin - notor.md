# Notor

Adds a side-panel AI assistant that reads, searches, creates and edits vault notes, injecting workspace context and attachments into the conversation. Every change requires approval against a diff preview and automatic checkpoints allow rolling back. Local or cloud models can be used, sub-agents can be spawned, and personas and workflows can be applied.
