# Specorator

AI agents are planned, run and reviewed inside the vault, with drafts, chats, summaries and edits kept as Markdown notes the user owns. The agents are provider-native and can read and write files, run searches and shell commands, and execute multi-step workflows. Handoffs are managed on an agent kanban board, saved prompts are fired from vault notes, and edits are previewed before they are applied.
