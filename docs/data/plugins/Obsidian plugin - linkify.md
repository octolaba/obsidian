# Linkify

Converts matching text into clickable links using configurable regular-expression patterns. Each pattern maps to a URL through a replacement pattern and an optional CSS class, and matches render as links in Live Preview that open in the browser. The recorded inputs state that the underlying Markdown files are not altered.

```cue
plugin: {
    id:     "linkify"
    name:   "Linkify"
    author: "matthewhchan"
    repo:   "matthewhchan/linkify"

    html_url:    "https://community.obsidian.md/plugins/linkify"
    github_url:  "https://github.com/matthewhchan/linkify"
    description: "Convert matching text into links."
```
