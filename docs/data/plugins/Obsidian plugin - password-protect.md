# Password Protect

Locks notes and folders with passwords and hides them by changing file extensions, keeping their content out of Obsidian search and graph view until they are unlocked for the session. The recorded description is explicit that hidden files are obfuscation rather than encryption: they stay readable in external editors, so the protection is against casual viewers and not against strong attacks.
