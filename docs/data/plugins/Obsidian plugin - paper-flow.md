# Paper Flow

Detects paper URLs in Markdown notes and resolves their metadata from Semantic Scholar, arXiv, Crossref and OpenAlex, inserting a managed metadata table into the note. Open-access PDFs are downloaded into the vault, citation counts are refreshed periodically, and Mermaid literature maps can be generated for the current note.
