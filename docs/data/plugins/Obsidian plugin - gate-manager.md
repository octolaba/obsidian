# GATE Manager

Syncs a vault with the official GATE study repository and downloads the current notes, diagrams and resources in a single step. Highlights and personal notes are preserved during an update, and release notes are readable from the dashboard.

```cue
plugin: {
    id:     "gate-manager"
    name:   "GATE Manager"
    author: "Anand Baghel"
    repo:   "anandrajbaghel/obsidian-gate-manager"

    html_url:    "https://community.obsidian.md/plugins/gate-manager"
    github_url:  "https://github.com/anandrajbaghel/obsidian-gate-manager"
    description: "Community-managed installer and updater for GATE Obsidian vaults. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync your vault with the official GATE study repository and download the latest notes, diagrams, and resources with a single click. Preserve your highlights and personal notes during updates and read built-in release notes from the dashboard."

    stats: {
        downloads:  88
        updated_at: 1784344220000
    }
}
```
