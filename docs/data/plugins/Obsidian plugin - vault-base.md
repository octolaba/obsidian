# Vault Base

Synchronises a vault with a WebDAV server in both directions across desktop and mobile, using three-way comparison and merging to resolve conflicts. Syncs run manually, on a schedule or in real time, with deletion propagation, optional client-side encryption and a chosen remote directory. Progress appears in the status bar, and concurrency, rate and large-file limits are configurable.
