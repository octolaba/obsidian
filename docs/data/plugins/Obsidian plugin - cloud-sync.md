# Cloud sync

Synchronizes notes to cloud storage with AES-256 end-to-end encryption applied before anything is uploaded. WebDAV is the backend available now, with bidirectional, automatic, scheduled and selective sync, basic conflict resolution and Markdown link conversion, while GitHub and iCloud support are described as still in development. The recorded inputs call this an alpha release and advise backing up important data.
