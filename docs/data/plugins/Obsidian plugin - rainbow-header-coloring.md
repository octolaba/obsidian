# Rainbow Header Coloring

Colors Markdown headers from H1 to H6 in editor and reading view, setting both font and background colors. Palettes come either from automatic colormaps — HSV, cool, warm and greyscale — or from per-level colors set by hand, with optional bold and italic. The colors apply in Live Preview, Source and Reading views and come from a lightweight built-in generator with no external dependencies.
