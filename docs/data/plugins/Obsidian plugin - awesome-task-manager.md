# Awesome Task Manager

This plugin manages tasks visually in a dashboard that organizes work across Today, Week, Open and All tabs. Tasks are edited inline, automations handle status transitions and completion dates, images can be attached and managed, and task lists export to Excel with formatting and formulas.
