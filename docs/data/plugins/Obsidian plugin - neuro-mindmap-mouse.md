# MapTheMind

MapTheMind presents mouse neuroscience data as a hierarchical visual database built on the Allen Mouse Brain Atlas (CCFv3). It renders the brain in 3D, drills into CCFv3 reference sections, and attaches Markdown notes to regions, viewpoints or individual cells. Anatomical structures and neuron morphologies are loaded from public atlases, and notes can be searched across nested anatomical contexts.
