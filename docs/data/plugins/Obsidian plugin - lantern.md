# Lantern

Lantern builds vault search and a chat agent on top of a locally installed qmd index, which it requires; answers are grounded in the notes with citations and generated by a local OpenAI-compatible LLM server. Searches run in hybrid, BM25 or vector mode with optional reranking and recent boosts, and are narrowed with scope tokens for tags, folders, time windows and frontmatter. Tag and link autocomplete, saved searches and external qmd libraries are also recorded.
