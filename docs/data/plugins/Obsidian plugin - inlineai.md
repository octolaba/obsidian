# InlineAI

InlineAI puts suggestions, contextual edits and text transformations into the Obsidian editor itself. Suggested changes appear as inline diffs that are accepted or discarded with one click. It connects to OpenAI, Gemini, Ollama or local models, covering both online and locally run workflows.
