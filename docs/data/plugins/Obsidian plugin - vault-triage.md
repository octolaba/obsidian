# Vault Triage

Scans the vault for stale, thin, orphan and missing-metadata notes as well as draft markers, and presents the findings as a review queue worked through one note at a time. The recorded About assigns saved audits, custom rules, bulk workflows, severity tuning and Markdown reports to a Pro tier.
