# Learnie

Learnie turns a file into a tracked learning note carrying a unique identifier and linked revision and question files. Edits are tracked and shown in a diff view, and flashcard-style review questions are created from selected text. Daily spaced-repetition reviews are driven by reminders that open the review set and let a revision be marked as reviewed.
