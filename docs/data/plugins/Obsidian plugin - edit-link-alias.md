# Edit Link Alias

Adds a command that edits the alias of a link from inside the note. With a Markdown link selected, its displayed alias is changed in place instead of retyping the whole link.

```cue
plugin: {
    id:     "edit-link-alias"
    name:   "Edit Link Alias"
    author: "Michael Naumov"
    repo:   "mnaoumov/obsidian-edit-link-alias"

    html_url:    "https://community.obsidian.md/plugins/edit-link-alias"
    github_url:  "https://github.com/mnaoumov/obsidian-edit-link-alias"
    description: "Adds edit link alias command."
    about:       "Edit link aliases directly from notes using a single command. Select a Markdown link and change its displayed alias inline without retyping the entire link."

    stats: {
        downloads:  805
        updated_at: 1784754649000
    }
}
```
