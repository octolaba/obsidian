# New Tab +

New Tab + makes opening in a new tab the default behaviour for Markdown files, graphs and canvases, and also for images, audio, video and PDFs. It can avoid duplicate tabs by focusing a tab that already holds the file or canvas.

```cue
plugin: {
    id:     "new-tab-plus"
    name:   "New Tab +"
    author: "raphlette"
    repo:   "raphlette/obsidian-new-tab-plus"

    html_url:    "https://community.obsidian.md/plugins/new-tab-plus"
    github_url:  "https://github.com/raphlette/obsidian-new-tab-plus"
    description: "Allow to open markdown files, graph and canvas in new tab as the default behavior."
    about:       "Open Markdown files, graphs, canvases, images, audio, video, and PDFs in a new tab by default. Prevent duplicate tabs by focusing an already-open tab for a file or canvas when desired."

    stats: {
        downloads:  13694
        updated_at: 1738951388000
    }
}
```
