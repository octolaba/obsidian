# Swagger JSON to Markdown

Converts Swagger 2.0 or OpenAPI 3.x JSON into static, Swagger-style Markdown intended for Obsidian and PDF export. The recorded inputs describe generating full documents or reusable fragments with real Markdown headings, grouping operations by tag, and including endpoints, parameters, bodies, responses and examples. Internal $ref entries are resolved and code blocks are emitted sanitized.
