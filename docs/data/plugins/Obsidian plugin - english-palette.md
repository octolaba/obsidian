# English Palette

Makes commands searchable in English in the command palette whatever the interface language is. Readable English keywords derived from each command identifier are appended to the command name, so a command identified as workspace split-vertical also matches those words.

```cue
plugin: {
    id:     "english-palette"
    name:   "English Palette"
    author: "tzengyuxio"
    repo:   "tzengyuxio/obsidian-english-palette"

    html_url:    "https://community.obsidian.md/plugins/english-palette"
    github_url:  "https://github.com/tzengyuxio/obsidian-english-palette"
    description: "Search commands in English within the Command Palette, regardless of your UI language. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Search commands in English from the Command Palette regardless of your UI language. Append readable English keywords (derived from command IDs, e.g., workspace:split-vertical → workspace split vertical) to each command name so both localized and English terms are searchable."

    stats: {
        downloads:  455
        updated_at: 1775777290000
    }
}
```
