# Indented Table

Renders Markdown pipe tables that are indented inside list items, styling them in live preview without changing the Markdown itself. Separator rows are hidden, headers are bolded with a background, pipe characters are faded, rows are kept from breaking across lines, and row borders are scoped to the table width.

```cue
plugin: {
    id:     "indented-table"
    name:   "Indented Table"
    author: "nnyj"
    repo:   "nnyj/obsidian-indented-table"

    html_url:    "https://community.obsidian.md/plugins/indented-table"
    github_url:  "https://github.com/nnyj/obsidian-indented-table"
    description: "Renders markdown pipe tables that are indented inside list items. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Style indented pipe tables nested in list items in live preview so they render correctly without changing your Markdown. Hide separator rows, bold headers with background, fade pipe characters, prevent line breaks in rows, and scope row borders to the table width."

    stats: {
        downloads:  160
        updated_at: 1782824739000
    }
}
```
