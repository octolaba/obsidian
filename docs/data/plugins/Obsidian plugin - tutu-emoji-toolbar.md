# Tutu Emoji Toolbar

A global emoji insertion tool with a searchable picker that matches by fuzzy and semantic search. Skin tones can be chosen, recently used emoji are kept to hand, and a character can be previewed or inserted with optional Twitter-style formatting. The recorded scenarios include headings, file renaming, the context menu and mobile use.
