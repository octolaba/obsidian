# Camera Embed

Camera Embed captures a photo on Android and embeds it as a Markdown image link at the cursor position. Images are saved next to the note or in a vault folder, with optional automatic compression to reduce file size.

```cue
plugin: {
    id:     "camera-embed"
    name:   "Camera Embed"
    author: "Sviatoslav Melnyk"
    repo:   "slavkomelnyk/camera-embed"

    html_url:    "https://community.obsidian.md/plugins/camera-embed"
    github_url:  "https://github.com/slavkomelnyk/camera-embed"
    description: "Capture and compress a photo on Android, then embed it into your note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Capture photos on Android and embed them as Markdown image links at the cursor position. Save images next to the note or in a vault folder with optional automatic compression to reduce file size."

    stats: {
        downloads:  1237
        updated_at: 1780213387000
    }
}
```
