# Snowflake Method

Provides a guided, Markdown-native workspace for the ten-step Snowflake Method of planning fiction, with a bilingual interface. Summaries, characters, scenes and drafts are stored as local, linkable notes, and a single dashboard tracks progress and raises non-blocking reminders when related content changes.
