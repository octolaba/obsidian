# memorry

Browses the memory records that the memorry MCP server mirrors into the vault, in a dedicated sidebar pane. Records can be filtered by title or project as the filter is typed, and pinned records are surfaced at the top. The list is read-only and live-updating, parsing frontmatter from Obsidian's metadata cache, and a record's note opens with one click.

```cue
plugin: {
    id:     "memorry"
    name:   "memorry"
    author: "Mehmet Ali Çalapverdi"
    repo:   "macbyclp/obsidian-memorry"

    html_url:    "https://community.obsidian.md/plugins/memorry"
    github_url:  "https://github.com/macbyclp/obsidian-memorry"
    description: "Search, filter, and browse the memory records the memorry MCP server syncs into your vault, from a dedicated sidebar pane. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Browse memorry-mirrored memory records in a dedicated sidebar pane, filter by title or project as you type, and surface pinned records at the top. View a live-updating, vault-native read-only list that parses frontmatter from Obsidian's metadata cache and open any record's note with one click."
}
```
