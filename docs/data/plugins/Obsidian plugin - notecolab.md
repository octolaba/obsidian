# Note Colab

Shares notes as web pages, as expiring view-only links, or directly to another Obsidian vault, with encryption performed on the device. Notes can be edited together in real time through editable browser or Obsidian links, and specific users can be invited. Links, collaborators and storage are managed from one dashboard, backed by hosted or self-hosted servers.
