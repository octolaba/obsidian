# Mini Toolbar

Mini Toolbar shows a compact inline toolbar in the editor whenever text is selected in Live Preview. Its buttons apply common formatting, links and actions directly to the selection.

```cue
plugin: {
    id:     "mini-toolbar"
    name:   "Mini Toolbar"
    author: "Boninall"
    repo:   "quorafind/Obsidian-Mini-Toolbar"

    html_url:    "https://community.obsidian.md/plugins/mini-toolbar"
    github_url:  "https://github.com/quorafind/Obsidian-Mini-Toolbar"
    description: "Mini context toolbar in editor."
```
