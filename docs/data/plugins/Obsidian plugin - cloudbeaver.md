# CloudBeaver

Runs SQL against databases on a CloudBeaver server from inside Obsidian, with results shown in a sidebar panel or a tab. Queries are written in cloudbeaver code blocks that name a connection alias, or entered in a console tab. They default to read-only, and recent queries can be browsed and copied to the clipboard.

```cue
plugin: {
    id:     "cloudbeaver"
    name:   "CloudBeaver"
    author: "DBeaver"
    repo:   "daelynum/obsidian-cloudbeaver-plugin"

    html_url:    "https://community.obsidian.md/plugins/cloudbeaver"
    github_url:  "https://github.com/daelynum/obsidian-cloudbeaver-plugin"
    description: "Run SQL against a CloudBeaver server from a console tab or from code blocks in your notes. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Run SQL against databases on your CloudBeaver server from notes and view results in a sidebar panel or tab. Place queries in cloudbeaver code blocks using a connection alias; queries default to read-only and you can browse recent queries and copy them to the clipboard."

    stats: {
        downloads:  17
        updated_at: 1785610860000
    }
}
```
