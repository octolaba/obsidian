# Large Language Models

This plugin connects Obsidian to remote and local language models, covering OpenAI, Anthropic, Google, Mistral, GPT4All and Ollama. Chats open in a tab, in the sidebar or in a floating action button popup, and the model can be switched per chat.

```cue
plugin: {
    id:     "large-language-models"
    name:   "Large Language Models"
    author: "eharris128"
    repo:   "eharris128/Obsidian-LLM-Plugin"

    github_url:  "https://github.com/eharris128/Obsidian-LLM-Plugin"
```
