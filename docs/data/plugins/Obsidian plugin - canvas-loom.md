# Canvas Loom

Canvas Loom extends the Obsidian Canvas with card-level editing operations. It splits long text cards by custom delimiters or Markdown headings, merges, copies and previews selected cards, and exports the result to the clipboard, new canvas cards or Markdown documents. It also adds numeric, text or emoji markers and batch-edits card properties such as size and position.
