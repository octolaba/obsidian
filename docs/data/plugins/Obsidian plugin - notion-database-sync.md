# Notion Database Sync

Synchronizes the active Markdown note with a selected Notion database in both directions, storing the linked page identifier as notionPageId and keeping the mapped frontmatter properties aligned. The note can be pushed to Notion or the linked Notion page pulled back, and properties are mapped through dropdowns with the property list fetched for quick mapping.
