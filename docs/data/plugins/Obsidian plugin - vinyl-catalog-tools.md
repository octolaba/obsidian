# Vinyl Catalog Tools

Vinyl Catalog Tools manages a vinyl collection inside the vault: record cards are added with an optional cover download and browsed as a sortable table or as cover cards. Discogs CSV files import with upsert behavior and cover backfill. The collection exports to CSV, Markdown or a .base file, and card grids export to PNG or JPEG as single or multi-file images with custom layouts and aspect-ratio options.
