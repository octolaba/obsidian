# Bible Search

Bible Search adds a dedicated view for full-text search and reading of the Bible, with results that jump to a verse and link back to notes in the vault. A setup wizard downloads public-domain translations, among them KJV, BSB and WEB, and builds the search page, resuming interrupted downloads and adopting an existing setup when one is present. The view stays in theme on desktop and mobile.
