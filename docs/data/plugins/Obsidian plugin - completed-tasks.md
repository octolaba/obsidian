# Completed Tasks

Completed Tasks sorts completed tasks to the bottom of their list automatically, reordering at a configurable interval while keeping the cursor position intact. Subtasks stay attached to their parent, the sorting runs in Reader mode, the Tasks plugin is supported but not required, and a note can opt out through its frontmatter.
