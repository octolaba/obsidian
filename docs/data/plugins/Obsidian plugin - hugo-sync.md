# Hugo Sync

Hugo Sync copies selected notes to a Hugo site, converting Obsidian-style Markdown and frontmatter into the format Hugo expects. Obsidian tags become Hugo tags, specified headers and their nested content are filtered out, and files are exported to a configurable Hugo content path.

```cue
plugin: {
    id:     "hugo-sync"
    name:   "Hugo Sync"
    author: "crayhuang"
    repo:   "crayhuang/Obsidian-Hugo-Sync"

    html_url:    "https://community.obsidian.md/plugins/hugo-sync"
    github_url:  "https://github.com/crayhuang/Obsidian-Hugo-Sync"
```
