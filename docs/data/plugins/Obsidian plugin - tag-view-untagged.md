# Tag View Untagged

Tag View Untagged adds an indicator of untagged files to the Tags pane in one of several display styles: gauge, pill, header badge, nav badge or list item. A browser modal lists, searches and opens the untagged notes. The count stays synced live as files or tags change.

    id:     "tag-view-untagged"
    name:   "Tag View Untagged"
