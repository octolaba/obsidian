# Galley Studio

Converts Markdown into editable, publish-ready HTML using OpenAI-compatible models or local Codex and Claude command-line tools, applying built-in layout skills and theme components aimed at WeChat-style article formatting. The result is previewed as sandboxed HTML and edited visually or in source with syntax highlighting, generation dialogs and history are tracked, and the final HTML is copied or exported.
