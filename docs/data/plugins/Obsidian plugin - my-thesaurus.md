# My Thesaurus

Adds tags to a note from a thesaurus stored as a CSV file or a Markdown table. Title, body and properties are scanned for exact phrase matches, case-insensitive and without truncation, with accent sensitivity configurable. The term-and-synonym mappings support multiple synonyms and many-to-many associations.

```cue
plugin: {
    id:     "my-thesaurus"
    name:   "My Thesaurus"
    author: "Mara"
    repo:   "mara-li/obsidian-my-thesaurus"

    html_url:    "https://community.obsidian.md/plugins/my-thesaurus"
    github_url:  "https://github.com/mara-li/obsidian-my-thesaurus"
    description: "Automagically adds tags based on a simple csv file or a Markdown table."
    about:       "Add tags automatically from a thesaurus stored as a CSV or Markdown table. Scan note title, body and properties for exact phrase matches (case-insensitive, no truncation; accent sensitivity configurable) and apply tags based on term–synonym mappings, supporting multiple synonyms and many-to-many associations."

    stats: {
        downloads:  857

    }
}
```
