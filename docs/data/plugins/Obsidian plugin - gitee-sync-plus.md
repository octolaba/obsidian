# Gitee Sync Plus

Stores a vault in a private Gitee or GitHub repository through direct API calls, with no server and no local Git installation. Synchronization runs in both directions across desktop, iOS and Android, comparing three ways with git blob hashes, updating incrementally and propagating deletions. Conflicts resolve to the newer version, and dry-run previews and diagnostic logs are available.
