# Task Priority Matrix

Task Priority Matrix arranges tasks by urgency and importance in a four-quadrant Eisenhower grid of do, schedule, delegate and eliminate. Tasks are added, edited inline, dragged between quadrants and completed, with relative due dates, undo and revive, and a collapsible bin of completed items carrying timestamps. Touch input on mobile and Obsidian Sync are supported.
