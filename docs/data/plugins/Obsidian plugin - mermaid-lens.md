# Mermaid Lens

Applies one global Mermaid configuration of theme, colors, fonts and layout to every diagram in the vault. A separate viewer opens a diagram outside the note's width, with panning, cursor-centered zoom, touch gestures and clickable links preserved. Only JSON configuration that Mermaid itself accepts is validated and saved.

    id:     "mermaid-lens"
    name:   "Mermaid Lens"
