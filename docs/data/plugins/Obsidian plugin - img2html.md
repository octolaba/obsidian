# Image to HTML

Pastes images as HTML image tags rather than as wikilinks or Markdown, while saving the image file into the vault. The save path and the image width are configurable, an optional alt attribute can be added, and paste notifications can be enabled.

```cue
plugin: {
    id:     "img2html"
    name:   "Image to HTML"
    author: "0x1da9430"
    repo:   "0x1da9430/img2html"

    html_url:    "https://community.obsidian.md/plugins/img2html"
    github_url:  "https://github.com/0x1da9430/img2html"
    description: "Paste images as HTML format instead of wikilink or markdown format."
    about:       "Convert pasted images to HTML <img> tags and save the image files in your vault instead of Markdown or Obsidian wikilinks. Set custom save paths and image widths, add optional alt attributes, and enable paste notifications for smoother cross-platform sharing."

    stats: {
        downloads:  1082
        updated_at: 1778335473000
    }
}
```
