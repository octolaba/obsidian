# Cooksync

Cooksync imports recipes collected with the Cooksync service into the vault, bringing full recipe data, source links and cover images. Tags can be added on import, and syncing runs automatically or manually from a connected Cooksync account. A paid Cooksync subscription is required.

```cue
plugin: {
    id:     "cooksync"
    name:   "Cooksync"
    author: "furst"
    repo:   "furst/cooksync-obsidian"

    html_url:    "https://community.obsidian.md/plugins/cooksync"
    github_url:  "https://github.com/furst/cooksync-obsidian"
```
