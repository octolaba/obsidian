# Photopea Editor

Photopea Editor embeds the Photopea web editor in the same panel and uses it in place of the default image viewer, so PNG, JPG and JPEG images open there when clicked. Edits are saved in Photopea, and the recorded inputs state that the updated file has to be re-imported into the vault manually.

```cue
plugin: {
    id:     "photopea-editor"
    name:   "Photopea Editor"
    author: "karmatoast40340"
    repo:   "karmatoast40340/photopea-editor"

    html_url:    "https://community.obsidian.md/plugins/photopea-editor"
    github_url:  "https://github.com/karmatoast40340/photopea-editor"
    description: "Automatically opens images in Photopea when clicked in your vault."
    about:       "Edit PNG, JPG, and JPEG images directly inside Obsidian by embedding the Photopea web editor in the same panel and replacing the default image viewer. Save edits in Photopea and re-import the updated file manually into your vault."

    stats: {
        downloads:  1013
        updated_at: 1733840453000
    }
}
```
