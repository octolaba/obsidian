# Masking as MD

Masking as MD opens non-Markdown files such as .py, .html, .txt, .js, .css and .json as editable text documents in the vault, without converting them to Markdown. Editing uses CodeMirror 6 with syntax highlighting and optional line numbers, word wrap and an adjustable font size. Changes are written only on an explicit save.

plugin: {
    id:     "masking-as-md"
    name:   "Masking as MD"

    repo:   "ahseyg/Masking-as-MD"

    html_url:    "https://community.obsidian.md/plugins/masking-as-md"

Use a CodeMirror 6 editor with syntax highlighting, optional line numbers, word wrap and adjustable font size; changes save only when you explicitly save."
