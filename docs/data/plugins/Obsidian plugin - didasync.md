# DidaSync

Syncs tasks in both directions between Obsidian and TickTick or Dida365, keeping status, details and recurrence aligned. Tasks can be viewed and managed as calendar time-blocks, timelines, sidebar lists and a Pomodoro view, with drag-and-drop scheduling and insertion of Markdown-linked tasks. A token-protected local MCP HTTP API can optionally be enabled.
