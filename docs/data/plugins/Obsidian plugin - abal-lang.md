# ABAL Language highlighter

ABAL Language highlighter adds syntax highlighting for ABAL inside fenced abal code blocks, in Live Preview, source mode and reading mode. It marks case-insensitive keywords, strings, comments introduced by a semicolon, decimal and hexadecimal numbers, operators and punctuation through CodeMirror 6 and a Markdown post-processor.
