# Finnish Spellcheck

Checks Finnish spelling and grammar inside Obsidian using the Voikko morphological analysis, spelling and hyphenation data. Errors are highlighted inline and corrections are suggested. Word morphology is analysed so that the suggestions match the inflected forms.

```cue
plugin: {
    id:     "finnish-spellcheck"
    name:   "Finnish Spellcheck"
    author: "antokeinanen"
    repo:   "antokeinanen/obsidian-finnish-spellcheck"

    html_url:    "https://community.obsidian.md/plugins/finnish-spellcheck"
```
