# Content Cards

Content Cards adds Markdown code blocks that render as cards: vertical and horizontal timelines, highlight blocks, target cards, book, music and movie information, photo albums, business cards, countdowns, content subfields, and SWOT and BCG matrices. It runs on Obsidian Mobile and supports English and Chinese, local images, custom codeblock languages and colored cards.

```cue
plugin: {
    id:     "content-cards"
    name:   "Content Cards"
    author: "liqms"
    repo:   "liqms/obsidian-content-cards"

    html_url:    "https://community.obsidian.md/plugins/content-cards"
    github_url:  "https://github.com/liqms/obsidian-content-cards"
    description: "Insert various types of content cards in Markdown, such as timeline, highlightblock, and more."
    about:       "Insert content cards in Markdown to create timelines (vertical/horizontal), highlight blocks, target cards, book/music/movie info, photo albums, business cards, countdowns, content subfields, SWOT and BCG matrices. Run on Obsidian Mobile and support English/Chinese, local images, custom codeblock languages and colored cards."
```
