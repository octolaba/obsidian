# Inboxer

Adds commands that append entries to the INBOX and TIMELINE sections of a note. New headings go to INBOX and timestamped entries to TIMELINE, with the section hierarchy preserved and the cursor placed for immediate typing.

```cue
plugin: {
    id:     "inboxer"
    name:   "Inboxer"
    author: "eoinhurrell"
    repo:   "eoinhurrell/obsidian-inboxer"

    html_url:    "https://community.obsidian.md/plugins/inboxer"
    github_url:  "https://github.com/eoinhurrell/obsidian-inboxer"
```
