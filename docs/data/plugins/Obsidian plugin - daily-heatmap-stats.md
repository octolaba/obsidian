# Daily Writing Stats

Tracks the daily word count across the notes of the vault and shows today's count live in the status bar. A contribution heatmap in the style of GitHub is shown in the right panel, and a daily writing goal and the total words of the past year can be reviewed.

```cue
plugin: {
    id:     "daily-heatmap-stats"
    name:   "Daily Writing Stats"
    author: "xsixteen"
    repo:   "xsixteen/obsidian-daily-heatmap"

    html_url:    "https://community.obsidian.md/plugins/daily-heatmap-stats"
    github_url:  "https://github.com/xsixteen/obsidian-daily-heatmap"
    description: "Track your daily word count across all notes in your vaults and display them in a heatmap and on the status bar. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Track today's word count live in the bottom-right corner and view a GitHub-style contribution heatmap in the right panel. Set a daily writing goal and review your total words across the past year."

    stats: {
        downloads:  592
        updated_at: 1779462953000
    }
}
```
