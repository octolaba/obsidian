# Movie

Fetches movie metadata from OMDB and pulls YouTube trailers into the vault, creating notes and saving poster images into the configured movies and assets folders. Searches run by title, with the year in parentheses, or by IMDB ID for an exact match.

```cue
plugin: {
    id:     "movie-obsidian"
    name:   "Movie"
    author: "onuraycicek"
    repo:   "onuraycicek/obsidian-movie"

    html_url:    "https://community.obsidian.md/plugins/movie-obsidian"
    github_url:  "https://github.com/onuraycicek/obsidian-movie"
    description: "Search movies info and trailers."
    about:       "Fetch movie metadata from OMDB and pull YouTube trailers into your vault, creating notes and saving poster images to your movies and assets folders. Search by title (include year in parentheses) or use an IMDB ID for exact matches."
```
