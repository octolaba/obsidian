# Abbreviations expander

Abbreviations expander defines abbreviations and expands them as you type after a space, turning short snippets into longer words or sentences or correcting common misspellings. Entries can be created, enabled, disabled and deleted, and case-insensitive matching lets an expansion trigger regardless of capitalization.

```cue
plugin: {
    id:     "abbreviations"
    name:   "Abbreviations expander"
    author: "woodenmaiden"
    repo:   "woodenmaiden/obsidian-abbreviations"

    html_url:    "https://community.obsidian.md/plugins/abbreviations"
    github_url:  "https://github.com/woodenmaiden/obsidian-abbreviations"
    description: "Easily create abbreviations that will be expanded after hitting `Space`."
    about:       "Define abbreviations and expand them automatically as you type to correct common misspellings or expand short snippets into longer words or sentences. Create, enable, disable, delete entries and set case-insensitive matches so expansions trigger regardless of capitalization."
```
