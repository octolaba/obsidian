# Node Graph View

Node Graph View visualizes the links between Markdown files as an interactive force-directed graph, converted from mkdocs-nodegraph. Clicking a node opens the corresponding note and nodes can be searched by filename, while node positions and preferences persist across sessions. The graph refreshes automatically when files change, and physics and appearance are adjusted with live controls.
