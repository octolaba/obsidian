# Codex Panel

Codex Panel puts Codex into an Obsidian sidebar, driving the local Codex CLI through app-server so AI-assisted work stays beside the notes and projects. It understands vault links and attachments, handles approvals and threads, reviews file changes, rewrites selected note text, and archives conversations as Markdown. Provider credentials are not stored.
