# Markdown Furigana

This plugin displays furigana using Markdown syntax, rendering kanji and other scripts with ruby-style readings from simple inline markup. Multiple readings per character are supported. The furigana is produced in preview only, through post-processing, so the Markdown files themselves stay unchanged.

```cue
plugin: {
    id:     "obsidian-markdown-furigana"
    name:   "Markdown Furigana"
    author: "steven-kraft"
    repo:   "steven-kraft/obsidian-markdown-furigana"

    html_url:    "https://community.obsidian.md/plugins/obsidian-markdown-furigana"
    github_url:  "https://github.com/steven-kraft/obsidian-markdown-furigana"
    description: "Display furigana using Markdown syntax."
    about:       "Render kanji and other scripts with ruby-style furigana from simple inline markdown like {漢字|かんじ} or multiple readings per character. Display furigana in preview only via post-processing so your Markdown files remain unchanged."

    stats: {
        downloads:  17076
        updated_at: 1686887814000
    }
}
```
