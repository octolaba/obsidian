# Anki Flashcard Sync

Syncs cloze, Q/A, QC/AC code-practice and image-occlusion cards from Obsidian Markdown to Anki through AnkiConnect, using stable IDs so an edit updates the existing Anki note instead of creating a duplicate. Image occlusions can be edited inline, Markdown LaTeX is converted to MathJax, and local media is imported alongside the cards. Changes can be previewed before syncing, and review history is preserved when a card is removed.
