# Clear Checklist

Resets a recurring checklist by unchecking every completed item instead of recreating the list. A labeled reset button can be inserted under a checklist, an automatic button is available in any view, and a command clears every checkbox in the current note. Dash, asterisk, plus and numbered lists, nested tasks and alternative checkbox states are all handled.

    id:     "clear-checklist"
