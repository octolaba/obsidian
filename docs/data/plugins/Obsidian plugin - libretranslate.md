# LibreTranslate

This plugin translates a selection or a whole Markdown note through a LibreTranslate-compatible server. Markdown structure is preserved where possible, with callouts, links, code spans and other sensitive content protected, and the translation is written back inline or as a callout.

```cue
plugin: {
    id:     "libretranslate"
    name:   "LibreTranslate"
    author: "p0shkar"
    repo:   "p0shkar/LibreTranslate-for-Obsidian"

    html_url:    "https://community.obsidian.md/plugins/libretranslate"
    github_url:  "https://github.com/p0shkar/LibreTranslate-for-Obsidian"
    description: "Translate text using LibreTranslate. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Translate selected text or entire Markdown notes via a LibreTranslate-compatible server. Preserve Markdown structure where possible and protect callouts, links, code spans, and other markdown-sensitive content, with inline replacement or callout-based translation output."

    stats: {
        downloads:  89
        updated_at: 1783321710000
    }
}
```
