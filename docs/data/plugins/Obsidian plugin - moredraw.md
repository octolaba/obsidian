# MoreDraw

Provides an infinite-canvas whiteboard for flowcharts, mind maps, other diagrams and freehand sketches, with AI assistance for drawing them. Whiteboards can be inserted live into notes and exported to PDF, PNG or PPT. Syncing goes through the MoreDraw remote service, which the recorded text says requires an account and makes some features paid.
