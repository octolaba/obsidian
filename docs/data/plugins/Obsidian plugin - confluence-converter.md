# Confluence Converter

Confluence Converter converts Obsidian Markdown to Confluence Storage Format XHTML or to the legacy Wiki Markup and puts the result on the clipboard for pasting into Confluence. Headings, lists, code blocks, tables, syntax highlighting and Obsidian image links are preserved through the conversion. Storage Format allows a one-step paste, while Wiki Markup targets traditional Confluence pages.
