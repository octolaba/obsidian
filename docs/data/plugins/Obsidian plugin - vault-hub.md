# Vault Hub

Publishes notes, CSS snippets, templates or entire vaults to GitHub, generating hub.md and README.md files for indexing by the Vault Hub community platform. The live Vault Hub catalog can be browsed inside Obsidian, note packs and CSS snippets install directly into the vault, and installed snippets are managed from the plugin sidebar.

```cue
plugin: {
    id:     "vault-hub"
    name:   "Vault Hub"
    author: "maws7140"
    repo:   "maws7140/vault-hub-plugin"

    html_url:    "https://community.obsidian.md/plugins/vault-hub"
    github_url:  "https://github.com/maws7140/vault-hub-plugin"
    description: "Publish CSS snippets, notes, and templates to the Vault Hub community platform. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Publish notes, CSS snippets, or entire vaults to GitHub with autogenerated hub.md and README.md for Vault Hub indexing. Browse the live Vault Hub catalog inside Obsidian, install note packs and CSS snippets directly into your vault, and manage installed snippets from the plugin sidebar."

    stats: {
        downloads:  373
        updated_at: 1783105862000
    }
}
```
