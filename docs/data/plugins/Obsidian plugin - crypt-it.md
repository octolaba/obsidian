# Crypt It

Generates an encrypted copy of a file in the rclone crypt format, started by right-clicking the file and protected with a password. The recorded inputs state that passwords are not stored, so a lost password leaves the encrypted file inaccessible.

```cue
plugin: {
    id:     "crypt-it"
    name:   "Crypt It"
    author: "remotely-save"
    repo:   "remotely-save/crypt-it"

    html_url:    "https://community.obsidian.md/plugins/crypt-it"
    github_url:  "https://github.com/remotely-save/crypt-it"
    description: "Generate encrypted version of file(s) using rclone encryption format."
    about:       "Encrypt any file by right-clicking it and generating an rclone-crypt–formatted encrypted copy protected with a password. Remember that passwords are not stored; lost passwords cannot be recovered and encrypted files will be inaccessible."

    stats: {
        downloads:  1660
        updated_at: 1711176709000
    }
}
```
