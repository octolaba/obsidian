# Export Selection to Word (RTF)

Exports the current selection, or the whole note when nothing is selected, to an RTF file that Word can open. Headings, bold, italics, underline, strikethrough, inline code, lists and tables are preserved, and links or wikilinks can optionally be stripped. The file is saved beside the source note or in a chosen vault folder, on desktop only.
