# Finkey

Renders interactive Sankey diagrams from a finkey code block in a note. Nodes can be dragged and dropped, and automatic alignment can be turned off to keep a chosen order. Hovering a node shows its flows and its remaining value.

```cue
plugin: {
    id:     "finkey"
    name:   "Finkey"
    author: "FloRenzi"
    repo:   "mrmupfel/FinKey"

    html_url:    "https://community.obsidian.md/plugins/finkey"
    github_url:  "https://github.com/mrmupfel/FinKey"
    description: "Generates interactive Sankey diagrams - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create beautiful, interactive Sankey diagrams directly in your notes with a finkey code block. Drag and drop nodes or disable automatic alignment to preserve your order, and hover to view flows and remaining values per node."

    stats: {
        downloads:  30
        updated_at: 1785238348000
    }
}
```
