# Image Border Style

Image Border Style applies rounded borders to images in notes, offering nine radius sizes from no border to 4XL and six border widths from 0 to 5 pixels. The border color either follows the theme automatically or is set to a custom color, at what its recorded inputs describe as minimal performance cost.
