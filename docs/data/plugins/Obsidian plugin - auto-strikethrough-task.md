# Auto Strikethrough Tasks

Auto Strikethrough Tasks applies strikethrough to the text of a task when it is checked and removes it again when the task is unchecked. The formatting is updated in real time as task lists are edited.

```cue
plugin: {
    id:     "auto-strikethrough-task"
    name:   "Auto Strikethrough Tasks"
    author: "nomekuma"
    repo:   "nomekuma/auto-strikethrough-task-obsidian-pluggin"

    html_url:    "https://community.obsidian.md/plugins/auto-strikethrough-task"
    github_url:  "https://github.com/nomekuma/auto-strikethrough-task-obsidian-pluggin"
    description: "Automatically adds strikethrough to completed tasks."
    about:       "Apply strikethrough to task text when you check tasks and remove it when you uncheck them. Update task formatting in real time as you edit task lists across your notes."

    stats: {
        downloads:  916
        updated_at: 1728400845000
    }
}
```
