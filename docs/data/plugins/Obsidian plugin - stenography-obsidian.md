# Stenography

Selected code blocks are translated into plain English through the Stenography API, which also detects the programming language. Translation is started from the plugin's ribbon icon and returns a readable explanation of the highlighted code.

```cue
plugin: {
    id:     "stenography-obsidian"
    name:   "Stenography"
    author: "bramses"
    repo:   "bramses/stenography-obsidian"

    html_url:    "https://community.obsidian.md/plugins/stenography-obsidian"
    github_url:  "https://github.com/bramses/stenography-obsidian"
    description: "Translate code blocks into simple English using Machine Learning with the Stenography API."
    about:       "Translate selected code blocks into plain English and detect the programming language. Trigger translations from the Stenography ribbon icon to receive readable explanations for highlighted code."

    stats: {
        downloads:  4892

    }
}
```
