# Yori Task

Organizes daily, weekly and monthly tasks in dedicated Task, Week and Year views for short- and long-term planning. Tasks are arranged and edited by drag-and-drop and right-click actions, and dragging a note into a block converts it into a linked task. The current view is archived into a summary note for later reference.
