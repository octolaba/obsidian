# Canvas LLM

Canvas LLM provides a canvas-like workspace for branching conversations with language models, built from Input, File, Web and Generate nodes. Each node can call a different model, and files and web content can be combined into prompts. Connecting API keys allows non-linear chat flows for research and complex tasks.
