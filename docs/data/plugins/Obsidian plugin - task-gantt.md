# Task Gantt

Task Gantt opens a folder as a combined table and timeline in which every Markdown file is one task and direct subfolders become groups. Bars are dragged or resized to reschedule, and clicking a task opens a side panel for start and end dates, status, assignee and body. Changes are written into each note's frontmatter, and the timeline shows bars, milestones and dependency arrows for finish-start, start-start and finish-finish links.
