# Thino

This closed-source plugin captures memos quickly and displays them in the sidebar with a heatmap. Captures are appended to the diary or to any specified note as time-stamped entries, which are parsed back into individual Thinos. Thinos can be read from several sources, and a global or live-preview editor composes, previews and inserts captures into notes.

plugin: {
    id:     "obsidian-memos"
    name:   "Thino"
    author: "Boninall"
    repo:   "quorafind/Obsidian-Thino"
