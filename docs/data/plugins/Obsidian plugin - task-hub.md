# Task Hub

Task Hub indexes Markdown checkboxes across the vault and groups them by status, date, tag, source or search text, letting the original note be opened or a task completed in place. On macOS it connects to Apple Reminders and Apple Calendar through a local helper, so items that already sync through iCloud appear beside vault tasks, and public read-only ICS calendars are also supported. The stated intent is to view the work in one lightweight place without replacing the existing setup.

It also supports public read-only ICS calendars. The goal is simple: keep notes in Obsidian, keep system reminders and calendars in Apple’s apps, and view the work in one lightweight place without replacing your existing setup."
