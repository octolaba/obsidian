# CQuiz

CQuiz turns Markdown notes into interactive, scored quizzes that run inside Obsidian. Questions are written as checkbox lists with single or multiple answers and can carry hints and notes, and the engine applies spaced repetition and scoring. Results can be reviewed as analytics or exported.

```cue
plugin: {
    id:     "cquiz"
    name:   "CQuiz"
    author: "abdur-nur-porag"
    repo:   "carbon-softlab/CQuiz"

    html_url:    "https://community.obsidian.md/plugins/cquiz"
    github_url:  "https://github.com/carbon-softlab/CQuiz"
    description: "Continuous Learning Material — Advanced Quiz Engine. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Turn Markdown notes into interactive, scored quizzes that run inside Obsidian. Create questions with checkbox lists (single or multi-answer), include hints/notes, use spaced-repetition and scoring, and review analytics or export results."

}
```
