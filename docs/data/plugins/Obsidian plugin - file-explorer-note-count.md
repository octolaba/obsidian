# File Explorer Note Count

File Explorer Note Count shows how many notes and files each folder holds next to it in the File Explorer, summing the items across subfolders. An option adds the counts to expanded folders as well, which are otherwise hidden once a folder has subfolders.

```cue
plugin: {
    id:     "file-explorer-note-count"
    name:   "File Explorer Note Count"
    author: "ozntel"
    repo:   "ozntel/file-explorer-note-count"

    html_url:    "https://community.obsidian.md/plugins/file-explorer-note-count"
    github_url:  "https://github.com/ozntel/file-explorer-note-count"
    description: "See the number of notes in each folder within the file explorer."
    about:       "Display total note and file counts next to folders in the File Explorer, summing items across subfolders. Enable an option to show counts on expanded folders or keep them hidden by default when subfolders exist."

    stats: {
        downloads:  286098

}
```
