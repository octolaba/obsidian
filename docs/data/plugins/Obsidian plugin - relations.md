# Relations

Visualizes relationships between notes declared in frontmatter, with portraits, typed line styles, and a focused family view. Graphs can be embedded inside callouts and infoboxes. The recorded text names worldbuilding, fiction casts, factions, genealogies, and TTRPG NPC networks as the intended uses.

plugin: {
    id:     "relations"
    name:   "Relations"
    author: "Obsidian TTRPG Community"
    repo:   "obsidian-ttrpg-community/Relations"

    github_url:  "https://github.com/obsidian-ttrpg-community/Relations"
    description: "Visualise relationships between notes — for worldbuilding, fiction, TTRPG campaigns, genealogies, or any project where seeing how things connect matters. - This plugin has not been manually reviewed by Obsidian staff."
