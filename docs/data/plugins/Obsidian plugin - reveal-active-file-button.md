# Reveal Active File Button

Reveal Active File Button places a crosshairs button at the top of the File Explorer that reveals the active file in a single click. The recorded text says the navigator jumps to the active file, and that clicking again helps when the explorer does not scroll correctly in very large folders.

```cue
plugin: {
    id:     "reveal-active-file-button"
    name:   "Reveal Active File Button"
    author: "Clare Macrae"
    repo:   "claremacrae/reveal-active-file-button-plugin"

    html_url:    "https://community.obsidian.md/plugins/reveal-active-file-button"
    github_url:  "https://github.com/claremacrae/reveal-active-file-button-plugin"
    description: "Add a button to the top of the File Explorer, to reveal the active file."
    about:       "Add a single-click crosshairs button to reveal the active file in the File Explorer and quickly locate neighboring notes. Click the button to jump the navigator to the active file; click again if the explorer doesn't scroll correctly in very large folders."

    stats: {
        downloads:  23034
        updated_at: 1781176448000
    }
}
```
