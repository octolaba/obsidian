# Time Tracker Statistics

Time Tracker Statistics adds daily and monthly statistics views across the whole vault for the Super Simple Time Tracker by Ellpeck. Entries can be grouped by file tags, with category target times and time-off days configured, and the views report totals, per-entry breakdowns, running trackers and deviation calculations.
