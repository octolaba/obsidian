# Manuscript Outliner

Manuscript Outliner generates structured outlines from the Markdown headings of manuscript notes, showing each section's status tag and word count. Outlines are produced as nested numbered headings with wikilinks and as hierarchical Markdown tables numbered like 1.2.3, and they update as the notes are edited. Each entry links straight to its section.

```cue
plugin: {
    id:     "manuscript-outliner"
    name:   "Manuscript Outliner"
    author: "Joe Kovach"
    repo:   "joe-iq/obsidian-manuscript-outliner"

    html_url:    "https://community.obsidian.md/plugins/manuscript-outliner"
    github_url:  "https://github.com/joe-iq/obsidian-manuscript-outliner"
    description: "Generate outlines from markdown headings. Track progress with status tags and word counts per section. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Generate structured outlines from manuscript notes that display each section's status tag and word count at a glance. Create nested numbered-heading outlines with wikilinks and hierarchical Markdown tables (1.2.3) that auto-update as you edit and let you jump directly to any section."

    stats: {
        downloads:  287
        updated_at: 1779899699000
    }
}
```
