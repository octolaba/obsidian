# Copy Contents

Copy Contents copies or exports the contents of a file or an entire folder, either to the clipboard or to a file in the vault, in Markdown, plain text or JSON. Nested folder paths can be preserved when files are combined, and the selection can be narrowed by picking files or filtering on extension and size. Actions run from the file menu, the command palette or custom hotkeys.

```cue
plugin: {
    id:     "copy-contents"
    name:   "Copy Contents"
    author: "Richard Jones"
    repo:   "accsimplify/obsidian-copy-contents"

    html_url:    "https://community.obsidian.md/plugins/copy-contents"
    github_url:  "https://github.com/accsimplify/obsidian-copy-contents"
```
