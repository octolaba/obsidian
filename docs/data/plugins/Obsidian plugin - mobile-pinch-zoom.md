# Mobile Pinch Zoom

Mobile Pinch Zoom lets a two-finger pinch zoom notes in and out on iPad, iPhone and Android. A floating indicator shows the current level and resets it to 100% when tapped, and commands are provided to zoom in, zoom out and reset. Content mode scales the whole note, which may shift the editor cursor, while font-size mode scales only the text.
