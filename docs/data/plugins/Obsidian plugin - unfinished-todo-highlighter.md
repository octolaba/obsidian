# Unfinished Todo Highlighter

Highlights files in the file explorer that still contain unfinished Markdown tasks and clears the highlight once every task is complete. Colour, background or filename highlighting, glow, bold text and dot indicators are configurable, and the scan covers a folder or the whole vault with automatic updates on edits and file changes. A vault-wide summary lists the tasks with links that check them in their source, and the status bar shows a note count.

```cue
plugin: {
    id:     "unfinished-todo-highlighter"
    name:   "Unfinished Todo Highlighter"
    author: "Aoba Suzuki"
    repo:   "7jo-yamato/unfinished-todo-highlighter"

    html_url:    "https://community.obsidian.md/plugins/unfinished-todo-highlighter"

Customize color, background or filename highlighting, glow, bold text and dot indicators; scan a folder or the whole vault, auto-update on edits and file changes, create a vault-wide summary with links that let you check tasks in their source, and show a note count in the status bar."
