# Music Catalog

Catalogs vinyl and CD collections by scanning a UPC barcode or searching by title, artist, label, composer or conductor, pulling metadata from Discogs and MusicBrainz. Notes are saved with cover art, condition grade, number of copies, value, acquisition date and custom fields. Entries are managed in a dedicated catalog table built with Obsidian Bases.
