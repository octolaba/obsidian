# Companion

Companion adds AI autocomplete through a copilot-like interface, suggesting words, phrases and whole sentences as ghost text from the surrounding note context. A suggestion is either accepted or ignored, and the models supported include OpenAI GPT-3, GPT-3.5 and ChatGPT as well as locally hosted Ollama models.
