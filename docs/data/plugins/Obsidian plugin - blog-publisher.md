# Blog Publisher

The plugin publishes notes to an arbitrary GitHub repository, uploading images and generating permalinks, one post at a time or in batches, with a publishing centre and an optional GitHub Actions deployment triggered afterwards. Private notes are held back and publication is selective through a pub-blog marker. Its recorded About text is written in Chinese and states support for Markdown, note links, Dataview, Canvas and Excalidraw, Mermaid, PlantUML, MathJax and PDF embedding.

```cue
plugin: {
    id:     "blog-publisher"
    name:   "Blog Publisher"
    author: "joeytoday"
    repo:   "joeytoday/obsidian-blog-publisher"

    html_url:    "https://community.obsidian.md/plugins/blog-publisher"
    github_url:  "https://github.com/joeytoday/obsidian-blog-publisher"
    description: "Publish my posts to my site. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "发布 Obsidian 笔记到任意 GitHub 仓库并自动上传图片、生成 permalink，支持单篇与批量发布、发布中心管理及发布后触发 GitHub Actions 部署。保留私有笔记、按 pub-blog 标记选择性发布，支持 Markdown、笔记链接、Dataview、Canvas/Excalidraw、Mermaid、PlantUML、MathJax、PDF 等嵌入与渲染。"

    stats: {
        downloads:  74
        updated_at: 1782884955000
    }
}
```
