# Copilot Personal

Copilot Personal is a multimodal chat assistant that streams responses from eleven LLM providers, including OpenAI, Anthropic, Gemini, DeepSeek, Mistral, Groq, xAI, OpenRouter, Perplexity, LM Studio and a built-in Copilot AI offering five queries a day without an API key. It runs autonomous agents with seventeen tools covering anti-loop detection, plan verification, keyword narrowing and custom instructions. It also performs semantic RAG search over vault-wide embeddings, extracts text and images from PDFs, searches the web, processes whole folders of notes in batch, searches saved chat history, and pops the chat out into its own window.
