# 3D Graph New

3D Graph New renders the vault as an interactive 3D graph with zoom, rotate and pan, adjustable node size, degree-based scaling, label fade and a node limit that protects performance. Local graphs open around a single note with depth and link-type filters, and nodes can be filtered, grouped and colored by query.
