# Cortex Chat

Cortex Chat is a sidebar chat with Codex, available through OAuth only, that draws on vault context, outgoing links, references and text extracted from Markdown notes and PDFs. Session history, a shared memory folder, outbox files and backups are stored locally, and the assistant runs in read-only Planner and Copilot modes or in an action-oriented Execute mode. It works on Obsidian desktop only.
