# Lapel

Lapel draws heading-level markers in the editor gutter so that h1, h2, h3 and the rest are distinguishable at a glance. A gutter menu switches a heading to another level, and each level's marker or style can be changed with CSS.

```cue
plugin: {
    id:     "lapel"
    name:   "Lapel"
    author: "Liam Cain"
    repo:   "liamcain/obsidian-lapel"

    html_url:    "https://community.obsidian.md/plugins/lapel"
    github_url:  "https://github.com/liamcain/obsidian-lapel"
    description: "Show the heading levels in the gutter of the editor."
    about:       "Show heading-level markers in the editor gutter to clearly distinguish h1, h2, h3, etc. Switch heading levels quickly from a gutter menu. Customize each level with CSS to change markers or styles per heading."
```
