# Bible Reference

Bible Reference supports Bible study notes by suggesting verses automatically as a reference is typed, for example --John1:1. Full verses are pasted into the note for inline referencing, and a verse of the day is fetched with --vod.

```cue
plugin: {
    id:     "obsidian-bible-reference"
    name:   "Bible Reference"
    author: "tim-hub"
    repo:   "tim-hub/obsidian-bible-reference"

    html_url:    "https://community.obsidian.md/plugins/obsidian-bible-reference"
    github_url:  "https://github.com/tim-hub/obsidian-bible-reference"
    description: "Take Bible study notes easily. Automatically suggests Bible verses as references."
    about:       "Insert Bible verse references and receive automatic verse suggestions as you type (e.g., --John1:1). Fetch a verse of the day with --vod and paste full verses into notes for quick, inline Bible study and referencing."

    stats: {
        downloads:  58254
        updated_at: 1786092953000
    }
}
```
