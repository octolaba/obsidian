# Image Inserter

Image Inserter searches Unsplash, Pixabay and Pexels and inserts the results into the editor. An image is either downloaded into the configured resource folder or inserted as a remote URL, with a choice of quality, size and orientation. An image can also be written into frontmatter under a custom key and value.

```cue
plugin: {
    id:     "insert-unsplash-image"
    name:   "Image Inserter"
    author: "cloudy9101"
    repo:   "cloudy9101/obsidian-image-inserter"

    html_url:    "https://community.obsidian.md/plugins/insert-unsplash-image"
    github_url:  "https://github.com/cloudy9101/obsidian-image-inserter"
    description: "Help users easily search and insert images to editors from Unsplash."
    about:       "Search and insert images from Unsplash, Pixabay, and Pexels directly into notes. Download images into your resource folder or insert remote URLs, choose image quality, size and orientation, and add images into frontmatter with a custom key/value."

    stats: {
        downloads:  18537
        updated_at: 1758019916000
    }
}
```
