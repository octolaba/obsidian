# PrimeTask

Promotes selected note text into a linked PrimeTask task, converting the selection into a wiki link and creating a permanent backlink to the source. Tasks are standalone Markdown files with frontmatter for status, priority, due date and progress, so they stay full notes that keep their source context and can be queried with Bases or Dataview. It requires the PrimeTask desktop application running on the same macOS or Windows machine, and runs locally.

    id:     "primetask-sync"
    name:   "PrimeTask"
    author: "PrimeTask"

Run the PrimeTask desktop app on the same machine (macOS or Windows) to connect Obsidian with PrimeTask."
