# Tags Color Files

Tags Color Files colors files in the file explorer according to the tags they contain, using tag-to-color rules with a tag priority that settles conflicts. A color can be applied to the text, to the background, or as markers, with up to three colored dots shown so several tags are visible at once. Settings can be exported and imported, and the interface is available in English and Russian.

```cue
plugin: {
    id:     "tags-color-files"
    name:   "Tags Color Files"
    author: "pan4ratte"
    repo:   "pan4ratte/obsidian-tags-color-files"

    html_url:    "https://community.obsidian.md/plugins/tags-color-files"
    github_url:  "https://github.com/pan4ratte/obsidian-tags-color-files"
    description: "Allows you to automatically color files in file explorer based on the tags they contain. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Highlight files in the Obsidian file explorer by assigning colors to tags via tag→color rules. Set tag priority for conflicts and choose text, background, or multi-dot markers (display up to three colored dots) to show multiple tags at once. Export/import settings and use English or Russian localization."

    stats: {

}
```
