# Omnisearch

Omnisearch ranks vault search results with a BM25 engine that weights matches in filenames, headings and content. It indexes PDFs, Office documents and images through text extraction, tolerates typos, and filters by file type or quoted expression. Results are navigated with Quick Switcher-style keyboard controls and can be inserted as links.

    id:     "omnisearch"
    name:   "Omnisearch"
