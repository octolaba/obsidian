# Advanced Maps

Extends Obsidian's built-in Maps view with tracks read from note embeds, drawing GPX, GeoJSON, KML and TCX files and geotagged photos onto the map, including an inline map for an embedded track. Basemaps can be aligned for the GCJ-02 and BD-09 coordinate systems, and a zoom-to-fit action frames the drawn data. Coordinates can be taken from a pasted map link, a place search, a photo or the device.
