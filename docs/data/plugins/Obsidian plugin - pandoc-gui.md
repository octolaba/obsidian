# Pandoc GUI

Exports and imports notes through Pandoc from the Obsidian interface rather than the command line, exposing Pandoc's options in the settings UI. Export templates can be built for Word, PDF, LaTeX, HTML, EPUB and other formats, and additional lua filters can be installed from a store inside the plugin. Mobile devices are supported and updates are tracked.

    id:     "pandoc-gui"
    name:   "Pandoc GUI"
    author: "pan4ratte"

Mobile devices support is ensured as well as updates tracking."
