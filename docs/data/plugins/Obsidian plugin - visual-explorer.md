# Visual Explorer

Visual Explorer browses notes as cards showing an image thumbnail, category tags, dates and a text preview. Folders are navigated with breadcrumbs and a floating back button, live search matches title or tag, and favorites can be marked. Notes and folders can be created, context actions cover rename and delete, and the gallery refreshes itself and reopens the last folder.
