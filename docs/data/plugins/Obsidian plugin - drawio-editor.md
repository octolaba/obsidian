# Drawio

Embeds, previews and edits draw.io diagrams in notes, with each diagram stored either inline in a drawio code block or as a separate .drawio file. SVG previews render inline, and a full-screen or in-place editor opens either online or from the bundled offline build. Diagrams are saved as readable, pretty-printed XML, and the editor matches the light and dark theme of Obsidian.
