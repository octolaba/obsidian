# Lofi Focus

Plays lofi music and runs a Pomodoro focus timer inside the vault. Pre-configured lofi radios are streamed or local MP3s played, with playback and volume controls and a visual timer in the status bar. Ambient particle animations are optional.

```cue
plugin: {
    id:     "lofi-focus"
    name:   "Lofi Focus"
    author: "jatin-shihora"
    repo:   "jatin-shihora/Obsidian-lofi-plugin"

    html_url:    "https://community.obsidian.md/plugins/lofi-focus"
    github_url:  "https://github.com/jatin-shihora/Obsidian-lofi-plugin"
    description: "Focus better with lofi vibes and Pomodoro sessions. Stream radio or play your music library, all within your vault. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Play lofi music and run a Pomodoro focus timer directly in Obsidian. Stream pre-configured lofi radios or play local MP3s, control playback and volume, and view a visual timer and controls in the status bar. Enable optional ambient particle animations."

    stats: {
        downloads:  297
        updated_at: 1774547998000
    }
}
```
