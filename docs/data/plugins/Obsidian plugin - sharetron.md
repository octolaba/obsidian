# Sharetron

Sharetron sends a note to messages or email in one click through the native OS share sheet, either as the original Markdown file or as a rendered, text-selectable PDF with embedded images. Sharing is reachable from the ribbon, the editor, context menus and the command palette, on macOS for both Markdown and PDF and on iOS. It makes no network calls, and the temporary PDFs it writes are readable only by their owner.
