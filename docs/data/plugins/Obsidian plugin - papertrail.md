# Papertrail

Lists every Markdown note in the sidebar as compact cards showing title, excerpt and modified date, so the list stays beside the editor. A footer filters or quick-creates notes, and right-clicking a row offers File Explorer actions such as open in new tab, rename, delete and reveal.
