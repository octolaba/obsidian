# Coder Engram

Stores durable, structured Claude Code memory as plain Markdown inside a Claude Code folder in the vault. Proposed memories land in a review inbox and require human approval, so an agent can propose but never edit notes directly. Retrieval is local by default, with an optional localhost-only server.
