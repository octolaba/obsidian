# Note Minimap

Note Minimap displays a live minimap of the current note, giving a scaled-down overview for navigating long Markdown files. Dragging the viewport slider jumps to a section, and the map updates as the note is edited and scrolled. Visibility can be toggled per note, the minimap resizes with the editor, and all themes and view modes are supported.
