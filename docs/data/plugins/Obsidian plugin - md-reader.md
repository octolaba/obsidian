# MD Reader

Lays rendered Markdown out as fixed-size pages that are flipped sideways by swipe, tap or arrow keys, as a single page or a two-page spread. Reading position is remembered across resizes, the interface can be hidden for immersive reading, and theme fonts and colors are reused. Pagination is automatic, and the recorded text names both desktop and mobile.
