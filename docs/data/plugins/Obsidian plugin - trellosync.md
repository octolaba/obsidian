# Trello-Sync

Mirrors Trello cards into the vault as Markdown notes so boards and tasks stay aligned with Obsidian. Updates made in the notes can be pushed back to Trello for two-way synchronization. It is described as a work in progress, with further features planned.

    id:     "trellosync"
    name:   "Trello-Sync"
    author: "KfirG"
