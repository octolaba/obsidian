# YouTube Links

Expands a pasted YouTube URL into a readable Markdown link carrying the channel name and the video title. Standard, short and Shorts URLs are recognized without an API key, and a loading placeholder is shown while the title is fetched.

```cue
plugin: {
    id:     "youtube-links"
    name:   "YouTube Links"
    author: "Yash Bavadiya"
    repo:   "xevrion/obsidian-youtube-links"

    html_url:    "https://community.obsidian.md/plugins/youtube-links"
    github_url:  "https://github.com/xevrion/obsidian-youtube-links"
    description: "Paste YouTube links and they automatically expand into a readable link with the channel name and video title. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert pasted YouTube URLs into clean, readable Markdown links that display the channel name and video title. Support standard, short, and Shorts URLs without an API key and show a loading placeholder while fetching titles."

    stats: {
        downloads:  235
        updated_at: 1782587586000
    }
}
```
