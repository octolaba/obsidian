# Metrics

Metrics views and edits structured metric records stored as plain metrics.ndjson files, aimed at measurements, scores, counts, durations and other discrete data that its recorded text says do not fit naturally into notes. The files stay readable and editable outside the interface so that humans and AI agents work with the same records, following the Plaintext Commons idea that the folder is the platform and the file is the protocol.

It is designed for measurements, scores, counts, durations, and other discrete data that do not fit naturally into notes. Obsidian is already excellent at handling prose and documents. Metrics handles the structured side, keeping the files readable and editable outside the UI so humans and AI agents can work with the same records. It follows the Plaintext Commons idea that the folder is the platform and the file is the protocol."
