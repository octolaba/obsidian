# Draw Steel Retainer

Provides Director-facing sidebar tools for the Draw Steel tabletop system, centred on an initiative tracker matched to that system. The tracker opens from the scroll ribbon and shows two tables for Draw Steel initiative, automatically including the player characters listed in settings.
