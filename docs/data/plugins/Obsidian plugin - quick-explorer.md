# Quick Explorer

Performs file explorer operations from the title bar with mouse or keyboard, while showing the path of the current file. Navigation is menu-based and starts at the vault root or in the current folder, with typing to search inside a folder and Vim-style navigation hotkeys. Notes, including folder notes, are previewed page-by-page without opening the sidebar.
