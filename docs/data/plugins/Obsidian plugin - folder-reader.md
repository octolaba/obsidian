# Folder Reader

Renders every note in a folder one after another as a single continuous scrolling view, each Markdown file carrying a header with its filename. A folder is opened this way from the explorer context menu or the command palette and the files are assembled in name order. Large folders load lazily, titles stay clickable, and wikilinks, embeds and images are preserved.
