# Light Mindmap

Light Mindmap renders the Markdown headings of a note as an interactive, colourful mindmap that replaces the editor or preview and updates live as the note is edited, with no extra syntax required. Balanced, left and right layouts, six colour themes, several connection styles and node shapes are selectable. Fenced code blocks are skipped and inline Markdown stripped for clean node labels, and a virtual root is added automatically when a note has several top-level headings.
