# YAOS

Synchronizes a vault across devices in real time through a Cloudflare Worker the user runs, which the recorded text presents as avoiding conflicted copies and delayed file sync. Attachments are stored and point-in-time backups enabled with an optional Cloudflare R2 bucket, and the setup is described as needing neither a database nor the terminal.
