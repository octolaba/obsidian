# Tasks Map

Tasks Map draws tasks as an interactive, draggable graph whose nodes are tasks and whose edges show dependencies. Inline checkbox tasks read through Dataview and file-based note tasks are both supported, relationships are declared with emoji or link syntax or in frontmatter, and the graph can be filtered by tag. Tasks can be marked done or undone from the graph itself.
