# Mac Now Playing

Shows the song currently playing in Spotify or Apple Music in Obsidian's status bar on Mac. Clicking the item opens an interactive popover with album art, live progress and media controls, and the status icon can be customized. The recorded text states that it works natively through AppleScript, with no API keys and no internet.

```cue
plugin: {
    id:     "mac-now-playing"
    name:   "Mac Now Playing"
    author: "Hajorda"
    repo:   "hajorda/obsidian-mac-now-playing"

    html_url:    "https://community.obsidian.md/plugins/mac-now-playing"
    github_url:  "https://github.com/hajorda/obsidian-mac-now-playing"
    description: "Displays the currently playing Spotify song in the status bar on Mac. - This plugin has not been manually reviewed by Obsidian staff."
```
