# Doubleshift

Doubleshift runs a command when a modifier key such as Shift is pressed twice, in the manner of IntelliJ. Left and right modifiers are distinguished and several double-press bindings assigned, each to any Obsidian command, including commands contributed by other plugins.

```cue
plugin: {
    id:     "obsidian-doubleshift"
    name:   "Doubleshift"
    author: "qwyntex"
    repo:   "qwyntex/doubleshift"

    html_url:    "https://community.obsidian.md/plugins/obsidian-doubleshift"
    github_url:  "https://github.com/qwyntex/doubleshift"
    description: "Open the command palette by pressing Shift (or any other key) twice like in IntelliJ and create your own shortcuts."
    about:       "Activate commands by double-pressing a modifier key (e.g., Shift) to trigger any Obsidian command. Distinguish left/right modifiers and assign multiple double-press bindings to run different commands, including those from other plugins."
```
