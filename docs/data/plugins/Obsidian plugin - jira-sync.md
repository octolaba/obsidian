# Jira Issue Manager

Jira Issue Manager fetches Jira issues and creates and updates them from Obsidian, with customizable templates and field mapping that covers standard, custom and plugin fields. Changes sync in both directions, work continues offline, and updates are pushed back to Jira afterwards. Time is tracked through integrated work logs, issue status is managed, and batch operations handle bulk updates.
