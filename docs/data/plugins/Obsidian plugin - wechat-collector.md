# WeChat Collector

Synchronises WeChat Official Account articles into the vault through a backend server, converting the article HTML to Markdown and downloading its images as local attachments. Notes are archived into folders named by year and month, and pulls can be incremental, scheduled or started by hand, on desktop and on mobile.

```cue
plugin: {
    id:     "wechat-collector"
    name:   "WeChat Collector"
    author: "lizhen"
    repo:   "lizhen0628/obsidian-wechat-sync"

    html_url:    "https://community.obsidian.md/plugins/wechat-collector"
    github_url:  "https://github.com/lizhen0628/obsidian-wechat-sync"
    description: "Sync WeChat Official Account articles to your vault as Markdown, archived by date. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Sync WeChat public-account articles to your Obsidian vault via a backend server, converting HTML to Markdown and downloading images into local attachments. Archive notes by YYYY‑MM folders and perform incremental, scheduled, or manual pulls on desktop and mobile."

    stats: {
        downloads:  10
        updated_at: 1784703469000
    }
}
```
