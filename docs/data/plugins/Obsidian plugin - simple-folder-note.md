# Simple Folder Note

Simple Folder Note treats a markdown file that shares its folder's name as that folder's note, whether the file sits inside the folder or beside it, with the inside copy taking priority. The note is hidden from the file explorer to avoid a duplicate entry, and clicking the folder name opens it in the current tab.

```cue
plugin: {
    id:     "simple-folder-note"
    name:   "Simple Folder Note"
    author: "heono3h"
    repo:   "heono3h/simple-folder-note"

    html_url:    "https://community.obsidian.md/plugins/simple-folder-note"
    github_url:  "https://github.com/heono3h/simple-folder-note"
    description: "Treats a .md file with the same name as its folder as a folder note. Hides it from the file explorer and opens it when the folder is clicked. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Treat a .md file that shares a folder's name as that folder's note, supporting notes stored inside the folder or beside it (inside takes priority). Hide the note from the file explorer to avoid duplicates and open the folder note in the current tab when clicking the folder name."

    stats: {
        downloads:  163
        updated_at: 1776695835000
    }
}
```
