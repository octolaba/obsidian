# Word-Smith

Adds a zen mode that hides interface chrome, focuses the active file and enters fullscreen. Typewriter scrolling, adjustable letterbox masks and a retro status bar with customizable tokens and word-goal tracking support long writing sessions. Word counts per file and per heading are shown in the file explorer and the outline.
