# Rich Table

Renders a fenced code block as a spreadsheet-like table while the data itself stays readable YAML in the note. Cells take full Markdown, including bold, math, images, lists, multi-line text and wikilinks with autocomplete, and are edited by click or from the keyboard, where arrow keys and Tab move between cells. Rows and columns can be merged and split, reordered, resized, hidden or frozen, styled by background, text color and font size or by a built-in theme, and typed columns show values as colored pills with six built-in types plus custom ones. Filtering, sorting and Sum, Average, Min, Max and Count summary rows are available; the same rows also browse as a Kanban board or a month calendar, several sheets fit behind a tab bar, and ranges copy to and from Excel.
