# Easy Link to Daily Note

Creates a timestamped note named by date and time with a single click. A link to that note is appended at the bottom of the corresponding daily note, so the daily note accumulates the ideas and logs written that day.

```cue
plugin: {
    id:     "easy-link-to-daily-note"
    name:   "Easy Link to Daily Note"
    author: "kdnk"
    repo:   "kdnk/obsidian-easy-link-to-daily-note"

    html_url:    "https://community.obsidian.md/plugins/easy-link-to-daily-note"
    github_url:  "https://github.com/kdnk/obsidian-easy-link-to-daily-note"
    description: "A simple plugin to link new notes to the daily note. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Create unique timestamped notes (YYYY-MM-DD-HH-mm-ss) with a single click. Append a link to the new note at the bottom of the corresponding daily note to build and connect daily logs and Zettelkasten-style ideas."

    stats: {
        downloads:  213
        updated_at: 1779799839000
    }
}
```
