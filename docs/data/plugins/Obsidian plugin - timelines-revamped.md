# Timelines (Revamped)

Timelines (Revamped) generates a chronological timeline from notes that carry a specific tag or set of tags, rendered in a vertical or horizontal layout. Dates can be formatted with custom patterns, events connected with arrows, and entries organized into reorderable groups and subgroups.

```cue

    id:     "timelines-revamped"
    name:   "Timelines (Revamped)"
    author: "seanlowe"
    repo:   "seanlowe/obsidian-timelines"

    html_url:    "https://community.obsidian.md/plugins/timelines-revamped"
    github_url:  "https://github.com/seanlowe/obsidian-timelines"
```
