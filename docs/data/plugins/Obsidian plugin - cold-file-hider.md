# Cold File Hider

Cold File Hider hides files from the file explorer once they have gone a configured number of days without edits, and restores them when they are reached through search, the Quick Switcher, links, backlinks or graph view. Folders collapse when all their contents go cold, cold files can be temporarily revealed at reduced opacity, and renames, deletions and exclusion patterns are respected.

```cue
plugin: {
    id:     "cold-file-hider"
    name:   "Cold File Hider"
    author: "hehongxi"
    repo:   "hehongxi/obsidian-cold-file-hider"

    html_url:    "https://community.obsidian.md/plugins/cold-file-hider"
    github_url:  "https://github.com/hehongxi/obsidian-cold-file-hider"
    description: "Automatically hide inactive (cold) files from the file explorer. Files re-appear when accessed via search, quick switcher, or links. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Hide inactive files from the file explorer after N days without edits, restoring them when opened via search, Quick Switcher, links, backlinks, or graph view. Collapse folders when all contents go cold, allow temporary reveal at reduced opacity, and respect renames, deletions, and exclusion patterns."
```
