# Flat Financing

Tracks personal finances inside Obsidian through a Beancount integration that records accounts, transactions, expenses, income and date-wise net worth flows. A dashboard shows summaries and transaction lists with filtering, multi-column sorting, privacy mode and live editing. Data is exported to CSV or PDF.
