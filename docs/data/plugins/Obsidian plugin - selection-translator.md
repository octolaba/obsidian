# Selection Translator

Selection Translator translates a selection, a paragraph, a whole Markdown document, an embedded image or speech using AI and machine-translation providers. Translated notes open side by side and stay synced, bilingual notes can be read or played back with TTS, translated images are inserted inline, and a local cache and a small runtime dashboard show usage.

    id:     "selection-translator"
    name:   "Selection Translator"

Read bilingual notes or play TTS, insert translated images inline, and monitor usage via local cache and a small runtime dashboard."
