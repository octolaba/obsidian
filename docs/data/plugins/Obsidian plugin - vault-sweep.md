# VaultSweep

Scans the vault and reports cleanup candidates: duplicate files, unused attachments, empty or untitled notes, orphaned notes and large files. Each result can be kept, ignored, moved to the system trash or deleted permanently. Nothing is deleted automatically, and the scan runs with no network access and no telemetry.
