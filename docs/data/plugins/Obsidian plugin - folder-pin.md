# Folder Pin

Pins folders as tabs in the default file explorer, so a project context is switched with one click while the rest of the vault stays hidden. Several independent views can be open, and each tab keeps its expand state, scroll position and selection. Tabs are laid out as a grid or vertically or horizontally, and a go up button is optional.
