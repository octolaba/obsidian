# Draftline

Creates manual Markdown snapshots that are stored inside the note itself as structured callouts, so version history travels with the file and stays readable to an agent. Any snapshot can be switched back into the editable note body, and inline comparison shows additions in green and deletions as red strikethrough.

```cue
plugin: {
    id:     "draftline"
    name:   "Draftline"
    author: "Noah Zender"
    repo:   "noahzender/draftline"

    html_url:    "https://community.obsidian.md/plugins/draftline"
    github_url:  "https://github.com/noahzender/draftline"
```
