# Easy Push

Reviews changed files and pushes commits to a Git remote from inside Obsidian, without a terminal. The current file, a chosen selection or all changes can be included, the commit message edited and the branch picked, and push status appears as markers in the file explorer. It uses only local git, with no account or external service.

```cue
plugin: {
    id:     "easy-push"
    name:   "Easy Push"
    author: "Arturs Bridaks"
    repo:   "artursbridaks/easy-push"

    html_url:    "https://community.obsidian.md/plugins/easy-push"
    github_url:  "https://github.com/artursbridaks/easy-push"
    description: "Review changes and push them without the terminal. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Review changed files and push commits to any Git remote directly from Obsidian. Select current, chosen, or all changes, edit commit messages, pick the branch, and view push-status markers in the file explorer using only local git—no accounts or external services."

    stats: {
        downloads:  87
        updated_at: 1779468389000
    }
}
```
