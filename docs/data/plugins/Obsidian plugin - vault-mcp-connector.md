# Vault MCP Connector

Connects the vault to MCP clients such as ChatGPT, Claude and Codex under explicit access controls over what is indexed and shared. An optional local MCP server can be run, access levels govern local reads and direct writes, and writes proposed by hosted deployments are queued for review.
