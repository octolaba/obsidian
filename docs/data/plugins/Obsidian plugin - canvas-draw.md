# CanvasDraw

Embeds interactive Excalidraw diagrams inside Markdown through native excalidraw code blocks. A canvas opens click-to-edit in a full-screen modal with the drawing tools, bundled libraries and zoom and resize controls, and pasted images are saved as local assets. Per-block layout is preserved and the drawing theme follows Obsidian's automatically.

    id:     "canvas-draw"
    name:   "CanvasDraw"
