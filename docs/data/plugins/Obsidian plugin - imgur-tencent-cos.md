# Tencent COS for Imgur

Uploads images and other file types, among them PDF, MP3, MP4, DOCX and ZIP, to Tencent COS by drag-and-drop or paste and replaces the local links with cloud URLs. A panel previews, refreshes and deletes uploads, images resize on hover, link expiry is configurable and the COS connection can be tested. Local and online note backups are also offered.
