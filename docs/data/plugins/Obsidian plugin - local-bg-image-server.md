# Local Background Image Server

Runs a lightweight local HTTP server that maps a folder to addresses usable in Obsidian's wallpaper settings, working around the desktop app accepting only online URLs for wallpapers. Traffic stays local with no uploads, images are previewed with one-click URL copying, and ports auto-increment when one is already taken.
