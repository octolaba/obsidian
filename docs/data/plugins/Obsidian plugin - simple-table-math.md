# Simple Table Math

Simple Table Math computes sums, averages, minimums, maximums, products and subtractions inside Markdown tables. Operation tags placed in a cell target a column or a row, with an optional range, and results appear live while editing. Output can be formatted with currency codes or scientific notation and copied to the clipboard from the context menu or a shortcut.
