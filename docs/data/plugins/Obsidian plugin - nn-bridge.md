# NN Bridge

NN Bridge adjusts the Notebook Navigator pane, hiding shortcut labels, section headers, the vault title, note counts and similar elements, and overriding its layout. It adds pinned commands, recents filtering, collapsible custom sections, and Markdown or button content rendered in the sidebar, and can override the left sidebar's tab icons and buttons. It requires the Notebook Navigator plugin to operate.
