# pdf-to-md

Converts handwritten PDFs into Markdown with LaTeX formulas from a right-click, sending the pages to an AI model. The recorded description names OpenAI GPT models, Alibaba Qwen and Google Gemini as the providers used, shows conversion progress in a bar, and states that API keys are read from environment variables.

```cue
plugin: {
    id:     "pdf-to-md"
    name:   "pdf-to-md"
    author: "kkbin505"
    repo:   "kkbin505/pdf-to-md"

    html_url:    "https://community.obsidian.md/plugins/pdf-to-md"
    github_url:  "https://github.com/kkbin505/pdf-to-md"
    description: "Convert handwritten PDFs to Markdown with LaTeX formulas using AI (OpenAI GPT or Alibaba Qwen). - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Convert handwritten PDFs in Obsidian to Markdown with a right-click, leveraging AI models like GPT-4o, GPT-5.4, Alibaba Qwen, or Google Gemini. Monitor conversion with a visual progress bar and keep API keys secure by reading them from environment variables."

    stats: {

    }
}
```
