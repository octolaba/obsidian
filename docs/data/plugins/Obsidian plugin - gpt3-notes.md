# GPT-3 Notes

Generates notes from natural-language prompts using OpenAI language models, listed as GPT-3 and older models in the captured About and as GPT-3.5 and GPT-4 in the index description. Outlines, articles, bullet lists and essays can be produced and inserted into the vault as drafts. The generator is reached from the command palette or the ribbon.

```cue
plugin: {
    id:     "gpt3-notes"
    name:   "GPT-3 Notes"
    author: "micahke"
    repo:   "micahke/obsidian-gpt3-notes"

    html_url:    "https://community.obsidian.md/plugins/gpt3-notes"
    github_url:  "https://github.com/micahke/obsidian-gpt3-notes"
    description: "Generate notes on any subject using OpenAI's GPT-3.5 and GPT-4 language models."
    about:       "Generate notes from natural-language prompts using OpenAI GPT-3 or older models. Create outlines, articles, bullet lists, or essays and insert AI-generated drafts into your vault. Access the tool from the command palette or the ribbon to produce content quickly."

    stats: {
        downloads:  37819
        updated_at: 1688721094000
    }
}
```
