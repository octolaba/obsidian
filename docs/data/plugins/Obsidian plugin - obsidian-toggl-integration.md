# Toggl Track

Toggl Track timers are created, started, stopped and restarted from the command palette through the Toggl Track API. The running timer is shown in the status bar and a daily summary in the side panel. Time-tracking reports are generated inside notes from code blocks.

```cue
plugin: {
    id:     "obsidian-toggl-integration"
    name:   "Toggl Track"
    author: "mcndt"
    repo:   "mcndt/obsidian-toggl-integration"

    html_url:    "https://community.obsidian.md/plugins/obsidian-toggl-integration"
    github_url:  "https://github.com/mcndt/obsidian-toggl-integration"
    description: "Add integration with the Toggl Track API to manage your timers."
    about:       "Manage Toggl Track timers directly inside Obsidian, creating, starting, stopping, and restarting recent timers from the command palette. Generate time-tracking reports inside notes with simple code blocks and view your current timer in the status bar plus a daily summary in the side panel."
```
