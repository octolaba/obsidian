# Known

Keeps a local directory of people as readable Markdown notes carrying YAML metadata, photos, relationships and a full Markdown body. Contacts can be searched, sorted and filtered, birthdays show a live age calculation, favourites can be marked, and email, call and website actions can be triggered from a profile. Edits preserve unknown frontmatter fields, and external changes to a file are detected.

    id:     "known"
    name:   "Known"

    github_url:  "https://github.com/nameiskyro/known"
