# Formula Library

Edits LaTeX formulas in a MathLive WYSIWYG editor with real-time preview, a virtual keyboard and a toggle between visual and source editing. More than 2,100 categorized formulas can be inserted through a search that accepts pinyin, LaTeX aliases and fuzzy matching, custom formula folders can be added, and editing works inline or from a sidebar quick-insert.
