# Remove Task Format

Removes task checkbox formatting from the current line with a keyboard shortcut, turning a checked or unchecked task back into an ordinary list item. Indentation and the original bullet are preserved.

```cue
plugin: {
    id:     "remove-task-format"
    name:   "Remove Task Format"
    author: "eluisjonathan"
    repo:   "eluisjonathann/obsidian-remove-task-format"

    html_url:    "https://community.obsidian.md/plugins/remove-task-format"
    github_url:  "https://github.com/eluisjonathann/obsidian-remove-task-format"
    description: "Remove task checkbox formatting ([ ] or [x]) from the current line using a keyboard shortcut. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Remove task formatting from the current line while preserving indentation and original bullets. Convert '- [ ]' or '- [x]' tasks back into normal list items with a single command."

    stats: {
        downloads:  78
        updated_at: 1782163563000
    }
}
```
