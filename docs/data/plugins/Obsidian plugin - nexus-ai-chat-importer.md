# Nexus AI Chat Importer

Nexus AI Chat Importer turns chat exports from ChatGPT, Claude, Mistral Vibe (formerly Le Chat), Perplexity and others into readable Markdown files in the local vault. It offers selective import with an interactive preview, deduplication across multiple ZIP exports, attachment handling for images, documents, DALL-E output and artifacts where the provider supplies them, Claude artifact versioning and LaTeX math support. Imports can also be driven from a CLI for headless setups, and the plugin writes detailed import reports and localises its interface into ten languages.
