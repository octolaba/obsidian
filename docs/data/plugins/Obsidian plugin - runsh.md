# Runsh

Runsh creates clickable buttons from a runsh code block in a note, and each button runs a shell command, such as launching a development environment. The recorded About states that commands should be verified before running, because the plugin provides no security protections.

```cue
plugin: {
    id:     "runsh"
    name:   "Runsh"
    author: "deedone"
    repo:   "deedone/obsidian-runsh"

    html_url:    "https://community.obsidian.md/plugins/runsh"
    github_url:  "https://github.com/deedone/obsidian-runsh"
    description: "Create buttons that run shell commands from your notes."
    about:       "Run shell commands from Obsidian and launch development environments or any scripts with clickable buttons created by adding a runsh code block to a note. Verify commands before running; the plugin provides no security protections."

    stats: {
        downloads:  1044
        updated_at: 1737555965000
    }
}
```
