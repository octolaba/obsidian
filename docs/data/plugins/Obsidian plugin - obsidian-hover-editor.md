# Hover Editor

Transforms the page preview hover popover into a fully working editor instance supporting both reading and editing mode. Multiple popovers can be dragged, resized and pinned, auto-scroll to headers or block references, and keep focus so that keyboard shortcuts still apply. A nav bar and a top handle give access to the title, the controls and minimize.
