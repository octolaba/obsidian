# Speech Bubbles

Transcription notes are rendered as message-style speech bubbles with per-speaker colors, icons and aliases, and the owner's bubbles aligned to the right. Inline timestamps, date separators and speaker groups or sides cover transcripts as well as roleplay and tabletop logs. Bubble width, corner radius and text and icon sizes are set from the note's frontmatter.

```cue
plugin: {
    id:     "speech-bubbles"
    name:   "Speech Bubbles"
    author: "forketyfork"
    repo:   "forketyfork/obsidian-speech-bubbles"

    html_url:    "https://community.obsidian.md/plugins/speech-bubbles"
    github_url:  "https://github.com/forketyfork/obsidian-speech-bubbles"
    description: "Renders transcription notes as message app style speech bubbles, similar to Apple Messages. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Render transcript notes as message-style speech bubbles with speaker-specific colors, icons, aliases, and right-aligned owner bubbles. Display inline timestamps, date separators, speaker groups/sides for roleplay or D&D, and fine-tune bubble width, radius, and text/icon sizes via note frontmatter."

}
```
