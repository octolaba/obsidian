# Heading Level Changer

Promotes or demotes Markdown heading levels between h1 and h6 for the selected lines, through hotkeys or the editor context menu, applying to several selections at once or to the current line when nothing is selected. Code fences, comment blocks, tags, images, tables and body text are skipped, levels are clamped at h1 and h6, and a single undo restores the previous selection. It works in Live Preview and Source mode on desktop and mobile.
