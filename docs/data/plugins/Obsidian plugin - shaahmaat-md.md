# ShaahMaat-md

ShaahMaat-md renders chess positions inside notes from FEN or PGN input. Board orientation can be flipped, squares highlighted in sequence and arrows drawn to illustrate ideas, and colors, piece sets and individual board sizes are configurable.

```cue
plugin: {
    id:     "shaahmaat-md"
    name:   "ShaahMaat-md"
    author: "mihailkovachev"
    repo:   "mihailkovachev/shaahmaat-md"

    html_url:    "https://community.obsidian.md/plugins/shaahmaat-md"
    github_url:  "https://github.com/mihailkovachev/shaahmaat-md"
    description: "Render chess positions."
    about:       "Render chess positions inside notes from FEN or PGN. Flip board orientation, highlight squares in sequence, draw arrows to illustrate ideas, and set custom colors, piece sets and individual board sizes."
```
