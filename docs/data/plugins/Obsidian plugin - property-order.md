# Property Order

Reorders YAML frontmatter list values by dragging items within or between supported properties on desktop, writing the change back to the note and preserving or converting the list format between bracket and bullet styles. It also customizes the order of the native property key suggestion dropdown through pinned, bottom, hidden, mixed-language and usage-count rules, so keyboard navigation follows the visible order.
