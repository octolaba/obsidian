# Heading Numerals

Separates the storage of heading numbers from their presentation, so numbers can be written into the file, removed from it, displayed virtually or visually concealed. Hierarchical, Chinese, legal and custom numbering schemes are available, and edits can be previewed before they are applied. Edits run offline and touch only ATX headings, skipping YAML, code blocks and comments.

    id:     "heading-numerals"
    name:   "Heading Numerals"

    github_url:  "https://github.com/zhyx91/obsidian-heading-numerals"
    description: "Write, remove, show, or conceal heading numbers without losing control of your Markdown source. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Separate heading-number storage from presentation and choose whether numbers are written to file, removed, displayed virtually, or visually concealed in Obsidian. Use hierarchical, Chinese, legal or custom numbering schemes, preview edits before applying, and run safe offline edits that only touch ATX headings and skip YAML, code blocks and comments."
