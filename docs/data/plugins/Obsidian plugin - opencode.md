# OpenCode

OpenCode embeds the OpenCode CLI in Obsidian and runs coding sessions in a WebGL-accelerated terminal with direct access to vault files. Past sessions are browsed and restored with their timestamps and working directories, conversation history is previewed, and threads export to Markdown. Windows support is in beta.
