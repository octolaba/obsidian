# Aurora Glass

A glass-inspired theme in graphite and cool blue tones, using soft gradients, subtle transparency and clear separation between interface elements. Dark and light modes are both supported, with styling for tabs, sidebars, settings, graphs, Canvas, Bases, code blocks, highlights and inputs.
