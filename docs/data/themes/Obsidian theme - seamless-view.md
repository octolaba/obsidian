# Seamless View

This theme matches live preview and read mode so that editing and canvas card sizes stay consistent between them. Spacing is reduced under a minimalist layout, low-contrast dark and warm papyrus light palettes are added, and plugin styles are aligned for Dataview, Kanban, admonitions and callouts.
