# Gothic

Gothic is a typography-focused writing surface with centered uppercase headings, red links, generous line height and a wider readable line length. The font stack is described as inspired by Century Gothic and TeX Gyre Adventor, the design is light-first with dark-mode support, and the CSS is stated to be local-only so styling is predictable offline.

![Gothic screenshot](https://raw.githubusercontent.com/highway-wu/obsidian-gothic/HEAD/screenshot-light.png)
