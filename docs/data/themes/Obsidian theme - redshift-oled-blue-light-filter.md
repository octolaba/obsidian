# RedShift - OLED Blue Light Filter

RedShift is a pure-red, true-black theme for OLED screens intended to reduce blue light exposure at night. Red-scale filtering is applied to images, and true black backgrounds keep pixels off, which the description ties to emitting zero blue light, cutting glare and saving OLED power. Only a dark mode is recorded.
