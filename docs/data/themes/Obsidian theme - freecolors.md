# FreeColors

FreeColors is a modular theme framework paired with a standalone Color Engine for designing a complete color system. The recorded description says palettes are crafted visually with a preview of the whole interface hierarchy, then exported as JSON profiles that import directly into Style Settings to apply custom colors in Obsidian.

![FreeColors screenshot](https://raw.githubusercontent.com/erulmu/freecolors/HEAD/screenshot.png)

```cue
theme: {
    name:   "FreeColors"
    author: "erulmu"
    repo:   "erulmu/freecolors"
```
