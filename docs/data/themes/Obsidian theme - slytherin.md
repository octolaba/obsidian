# Slytherin

Slytherin uses rich gradients, clean typography and contrast tuned for late-night writing and campaign planning. Solid colours can be selected instead through Style Settings, heading, bold, italic and link styles are previewed live, and graph-view and interface tweaks follow the same deep-green aesthetic.
