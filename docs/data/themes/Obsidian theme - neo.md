# Neo

Neo is a colorful, clean interface with light and dark modes, mobile support, alternate tabs and heading indicators. Alternate checkboxes and cssclasses style tasks and turn Dataview tables and lists into cards, and the recorded description names support for Dataview, Tasks and Kanban.

![Neo screenshot](https://raw.githubusercontent.com/x0aa7i/obsidian-neo/HEAD/cover.png)
