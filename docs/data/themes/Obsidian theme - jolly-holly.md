# Jolly Holly

Jolly Holly applies a festive winter aesthetic through five themed color schemes named Holly, Berries, Snowflake, Cinnamon and Winter Night. The recorded description prefers dark mode, records that Snowflake is light-only, and says callouts stay clearly visible across the interface. The theme index lists dark mode only.
