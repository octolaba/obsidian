# deeper work

Deeper work is a dark theme inspired by the original Deep Work, with stacked panes, shadow accents and calendar support. Callouts are rendered with large titles and ruled lines, and the color scheme follows the original Deep Work, optimized for JetBrains Mono and ligatures.
