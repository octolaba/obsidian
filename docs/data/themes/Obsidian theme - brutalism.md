# Brutalism

Brutalism strips visual frills to put the focus on text, using raw beton brut typography for a brutalist, minimal interface. It applies fluid typography and an optional inline-title gradient, and it includes a snippet that hides interface elements for keyboard-focused, distraction-free writing.

![Brutalism screenshot](https://raw.githubusercontent.com/abrahambahez/Brutalism/HEAD/brutalism_dark.png)

```cue
theme: {
    name:   "Brutalism"
    author: "abrahambahez"
    repo:   "abrahambahez/Brutalism"
    slug:   "brutalism"

    html_url:       "https://community.obsidian.md/themes/brutalism"
    github_url:     "https://github.com/abrahambahez/Brutalism"
    screenshot_url: "https://raw.githubusercontent.com/abrahambahez/Brutalism/HEAD/brutalism_dark.png"

    modes: ["dark", "light"]
    about: "Apply a brutalist, minimal UI that strips visual frills and puts focus on text with raw, béton brut typography. Use fluid typography and an optional inline-title gradient, and enable the included snippet to hide UI elements for a keyboard-focused, distraction-free writing experience."
}
```
