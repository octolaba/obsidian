# Vignelli

A Vignelli-inspired serif theme built on Bodoni headings, Georgia body text and Courier code, laid out on a strict grid with gold rules for headers, dividers and table bars. Light and dark modes work in black and bone with a teal highlighter, callouts carry a gold left rule and small-caps labels, and code syntax is desaturated to the palette.

![Vignelli screenshot](https://raw.githubusercontent.com/wesellis/vignelli-obsidian-theme/HEAD/assets/vignelli-hero.png)
