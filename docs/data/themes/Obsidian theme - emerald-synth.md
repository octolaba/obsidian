# Emerald Synth

Emerald Synth is a synthwave-styled dark interface that sets deep purple backgrounds against emerald-green foreground text. Bright pink and cyan accents are used for headings, code and emphasis to produce a neon-retro aesthetic, and the theme index records dark mode only.

![Emerald Synth screenshot](https://raw.githubusercontent.com/malleroid/emerald-synth-obsidian/HEAD/screenshot.png)

```cue
theme: {
    name:   "Emerald Synth"
    author: "malleroid"
    repo:   "malleroid/emerald-synth-obsidian"
    slug:   "emerald-synth"

    html_url:       "https://community.obsidian.md/themes/emerald-synth"
    github_url:     "https://github.com/malleroid/emerald-synth-obsidian"
    screenshot_url: "https://raw.githubusercontent.com/malleroid/emerald-synth-obsidian/HEAD/screenshot.png"

    modes: ["dark"]
    about: "Apply a synthwave-inspired dark interface with deep purple backgrounds and emerald-green foreground text. Use bright pink and cyan accents for headings, code, and emphasis to give notes a neon-retro aesthetic."
}
```
