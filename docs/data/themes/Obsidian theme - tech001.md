# Tech001

Tech001 is a developer-focused theme with dark and light modes whose stated inspiration is Google AI Studio and Material Design 3. It adds VS Code-style syntax highlighting, file-extension badges, code-block headers in Live Preview, a Notion-style centered layout and refined Material icons.

![Tech001 screenshot](https://raw.githubusercontent.com/volodinroman/obsidian-tech001-theme/HEAD/screenshot.png)

}
