# Dolch

Dolch is a dark Dolch-inspired color scheme with blue, red, green, yellow, cyan and purple accents. It gives headings distinct colors and adds syntax-friendly code block styling, a clear distinction between internal and external links, refined table styling and custom checkboxes.

![Dolch screenshot](https://raw.githubusercontent.com/futurecreator/obsidian-dolch-theme/HEAD/screenshot.png)

}
