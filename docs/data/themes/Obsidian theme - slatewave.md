# Slatewave

Slatewave builds on a slate foundation with a teal signature across headings, active states, tabs, the status bar and other UI elements. Its palette is matched to the Slatewave VSCode and oh-my-posh themes, and it adds distinct callout colours and pink list markers. The description names both dark and light modes, while the index records this theme as dark only.

![Slatewave screenshot](https://raw.githubusercontent.com/kevinlangleyjr/obsidian-slatewave/HEAD/docs/preview-scaled.png)

theme: {
    name:   "Slatewave"

Match the Slatewave VSCode and oh-my-posh palette for a unified editor, terminal, and notes look; include distinct callout colors, pink list markers, and both dark and light modes."
