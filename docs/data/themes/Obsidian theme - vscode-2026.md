# VSCode 2026

VSCode 2026 brings the Fluent UI of Visual Studio 2026 to Obsidian with light and dark modes and, on macOS, vibrancy and translucency. It applies the VSCode Dark+ and Light+ syntax highlighting across editor and reading view, and its recorded description names SF Pro and SF Mono typography, overlay scrollbars, macOS-style accents and CSS-variable theming for colour tweaks.
