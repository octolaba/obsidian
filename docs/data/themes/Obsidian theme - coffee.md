# Coffee

Coffee is a warm, coffee-inspired theme with distinct Dark Coffee and Light Coffee modes. Its coffee-named CSS variables are meant for customization, and it adds active-line and hover highlighting in source view, animated list folding, print-ready Times New Roman PDFs, and emoji file-explorer icons.

![Coffee screenshot](https://raw.githubusercontent.com/regawaras/Coffee/HEAD/coffee.png)

```cue
theme: {
    name:   "Coffee"
    author: "regawaras"
    repo:   "regawaras/Coffee"
    slug:   "coffee"

    html_url:       "https://community.obsidian.md/themes/coffee"
    github_url:     "https://github.com/regawaras/Coffee"
    screenshot_url: "https://raw.githubusercontent.com/regawaras/Coffee/HEAD/coffee.png"

    modes: ["dark", "light"]
    about: "Apply a warm, coffee-inspired theme with distinct Dark Coffee and Light Coffee modes for a soothing, ergonomic workspace. Use coffee-named CSS variables for easy customization, get active-line and hover highlighting in source view, animated list folding, print-ready Times New Roman PDFs, and simple emoji file-explorer icons."
}
```
