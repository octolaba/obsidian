# Atom

Atom brings the One Dark and One Light styles of the Atom editor to Obsidian, keeping the familiar interface and adding subtle refinements. It also replaces the default code-block syntax colours with what the recorded description calls cleaner, more readable highlighting.

![Atom screenshot](https://raw.githubusercontent.com/kognise/obsidian-atom/HEAD/screenshot-hybrid.png)

```cue
theme: {
    name:   "Atom"
    author: "kognise"
    repo:   "kognise/obsidian-atom"
    slug:   "atom"

    html_url:       "https://community.obsidian.md/themes/atom"
    github_url:     "https://github.com/kognise/obsidian-atom"
    screenshot_url: "https://raw.githubusercontent.com/kognise/obsidian-atom/HEAD/screenshot-hybrid.png"

    modes: ["dark", "light"]
    about: "Apply Atom's One Dark and One Light styles to Obsidian to keep the familiar interface while adding subtle visual refinements. Replace the default code-block syntax theme with cleaner, more readable highlighting."
}
```
