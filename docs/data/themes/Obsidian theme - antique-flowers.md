# Antique Flowers

Antique Flowers is a vintage floral layout for Obsidian offering both dark and light modes. Its recorded description claims compatibility with common banner plugins, naming Pixel Banner and the classic banner plugins. It also asks that layout conflicts caused by other plugins that change styling be reported on the theme's GitHub repository.

![Antique Flowers screenshot](https://raw.githubusercontent.com/incantatem2/Obsidian-antique-flowers/HEAD/images/antique-flowers-dark-thumbnail.jpg)
