# Ember Graphite

Ember Graphite offers dark and light variants of a warm, Ember-inspired color palette, presented for writing, note-taking and long reading sessions. The recorded description covers readable typography, code block styling and consistent callout and markdown rendering, keeping the interface minimal and free of distraction.
