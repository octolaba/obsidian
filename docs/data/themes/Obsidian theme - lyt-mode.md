# LYT Mode

LYT Mode is a dark, contrast-rich theme that emphasizes markdown formatting and adds syntax highlighting so links and ideas stay visible. It uses DM Sans and DM Mono, tightens sidebar spacing, and adds custom icons, subtle animations and larger popovers. Live Preview, mobile, callouts and slides are all supported.

![LYT Mode screenshot](https://raw.githubusercontent.com/nickmilo/LYT-Mode/HEAD/lyt-mode-graphic-1.jpg)
