# Border

Border is a customizable theme offering card layouts, a hover-line indicator, an auto-hiding tab bar and alternate styles for callouts, checkboxes and code blocks. The Style Settings plugin drives those adjustments and also loads presets, among them light, dark, translucent and borderless variants.

![Border screenshot](https://raw.githubusercontent.com/akifyss/obsidian-border/HEAD/cover.png)

```cue
theme: {
    name:   "Border"
    author: "akifyss"

    slug:   "border"

}
```
