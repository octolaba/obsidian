# Eldritch

Eldritch is a dark theme built from a Lovecraftian palette of deep greens and blues that its recorded description says gives Obsidian an abyssal, horror-tinged look. The styling is described as community-driven and aims to keep interface contrast and typography cohesive and readable. The theme index records dark mode only.

![Eldritch screenshot](https://raw.githubusercontent.com/eldritch-theme/obsidian/HEAD/eldritch.png)
