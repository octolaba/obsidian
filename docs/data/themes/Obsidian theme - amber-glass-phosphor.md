# Amber Glass Phosphor

A dark, CRT-inspired interface offering amber, green or white phosphor palettes with multicolored headings, plus optional scanlines and a vignette. Fonts are embedded for offline use, reading view, Live Preview and PDF output are styled alike, and terminal-style square controls are used throughout. Style Settings is supported.
