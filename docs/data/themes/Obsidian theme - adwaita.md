# Adwaita

Adwaita makes Obsidian follow the visual language of the GNOME desktop, including its window buttons. It offers a dark or a light base and lets colours, fonts, tabs and icons be changed, with the Style Settings plugin exposing the deeper adjustments.

![Adwaita screenshot](https://raw.githubusercontent.com/birneee/obsidian-adwaita-theme/HEAD/generated/theme-store-preview.png)
