# AMOLED Serenity

AMOLED Serenity is a low-contrast dark theme built for AMOLED screens, where the deep blacks are recorded as both reducing eye strain and conserving battery. Colours and layout can be adjusted through the Style Settings plugin. The recorded description frames it as a calm interface for prolonged reading and note-taking.
