# RBR

RBR maps a three-accent palette onto a deep navy base: kerb red for active elements, RB yellow for attention and chequer white for functions. Workspace chrome, editor and preview are coloured together, code tokens are mapped by kind with keywords red, strings green, functions white and types yellow, and headings, tags and callouts follow the same scheme. Only a dark mode is recorded.

![RBR screenshot](https://raw.githubusercontent.com/amdhj22/rbr.obsidian/HEAD/screenshot.png)
