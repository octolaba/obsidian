# Dracula Gemini

Dracula Gemini is a dark Dracula theme that reworks Source-mode typography and spacing so the Editing view sits visually close to the Reading view. Markdown punctuation is dimmed while the characters stay editable, and headers, lists, code blocks and blockquotes are aligned between the two views.
