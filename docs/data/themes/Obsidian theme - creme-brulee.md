# Creme brulee

Creme brulee is a cozy, minimalistic theme with soft colors and subtle typographic tweaks for a cleaner, warmer look. It adds color styling to Markdown without HTML, visible only inside Obsidian, and per-note CSS classes such as hide-inline-title, hide-backlinks and hide-properties. The layout also drops the properties heading and narrows live-preview spacing.

![Creme brulee screenshot](https://raw.githubusercontent.com/anareaty/creme-brulee-obsidian-theme/HEAD/screenshot.png)
