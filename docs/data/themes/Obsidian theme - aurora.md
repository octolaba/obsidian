# Aurora

Aurora applies an auroral colour scheme with soft gradients and neon accents while keeping typography readable across the interface. Its recorded description also names companion themes for VSCode and Hexo, so the same look can be carried to those tools.

![Aurora screenshot](https://raw.githubusercontent.com/auroral-ui/aurora-obsidian-md/HEAD/screenshots/screenshot-1.png)

```cue
theme: {
    name:   "Aurora"
    author: "auroral-ui"
    repo:   "auroral-ui/aurora-obsidian-md"
    slug:   "aurora"

    html_url:       "https://community.obsidian.md/themes/aurora"
    github_url:     "https://github.com/auroral-ui/aurora-obsidian-md"
    screenshot_url: "https://raw.githubusercontent.com/auroral-ui/aurora-obsidian-md/HEAD/screenshots/screenshot-1.png"

    modes: ["dark"]
    about: "Apply a futuristic auroral color scheme with soft gradients, neon accents, and readable typography across Obsidian's interface. Match visuals with companion VSCode and Hexo themes to keep a cohesive cross-tool workspace."
}
```
