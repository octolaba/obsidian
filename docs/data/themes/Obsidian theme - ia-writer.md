# iA Writer

iA Writer brings the styling of the writing application of that name to Obsidian, with focused typography, a muted palette and an optional accent color. The recorded description also hides interface elements and uses translucent windows to leave a minimal, thought-focused workspace.

![iA Writer screenshot](https://raw.githubusercontent.com/mrowa44/obsidian-ia-writer/HEAD/promo_screenshot.png)

}
