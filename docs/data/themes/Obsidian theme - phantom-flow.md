# Phantom Flow

Phantom Flow is a dark, cool-toned theme with bundled Roboto typography, so text renders without network access, over a deepened background. Top-level folders take distinct gradient hues and larger titles, and three palettes, Nord, Sunset and Forest, can be switched live through Style Settings.

![Phantom Flow screenshot](https://raw.githubusercontent.com/robisonweb/phantom-flow/HEAD/Screenshot.png)

```cue
theme: {
    name:   "Phantom Flow"
    author: "robisonweb"
    repo:   "robisonweb/phantom-flow"
    slug:   "phantom-flow"

    html_url:       "https://community.obsidian.md/themes/phantom-flow"
    github_url:     "https://github.com/robisonweb/phantom-flow"
    screenshot_url: "https://raw.githubusercontent.com/robisonweb/phantom-flow/HEAD/Screenshot.png"

    modes: ["dark", "light"]
    about: "Use a dark, cool-toned theme with bundled Roboto typography and a deeper background for clearer, offline-ready text. Color top-level folders with distinct gradient hues and larger titles, and switch live between three palettes (Nord, Sunset, Forest) via Style Settings."
}
```
