# Powered by Lancer

Powered by Lancer brings the aesthetics of the Lancer tabletop RPG to Obsidian in a Wasp-inspired dark sci-fi color scheme with sharp typographic choices. Its recorded description presents the layout as a daily driver for long-form writing and note navigation.
