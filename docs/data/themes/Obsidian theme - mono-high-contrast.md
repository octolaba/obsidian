# Mono High Contrast

Mono High Contrast is a clean, minimal theme whose recorded description names the default High Contrast look of VS Code as its inspiration. It relies on strong contrast and clear typography for focused note-taking.

![Mono High Contrast screenshot](https://raw.githubusercontent.com/manuelcoca/obsidian-mono-high-contrast-theme/HEAD/assets/thumbnail.png)

theme: {
    name:   "Mono High Contrast"

}
