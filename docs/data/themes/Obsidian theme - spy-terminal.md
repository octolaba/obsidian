# Spy Terminal

Spy Terminal styles Obsidian as a spy-movie terminal with dark gray and black backgrounds, monospace fonts and classic green text. Glowing link and task effects, green-highlighted code blocks, task-query styling and graph-view visuals extend the retro hacker look.
