# Space

Space turns Obsidian into a space-themed workspace with deep-space backgrounds, glowing accents, futuristic fonts and custom space icons. The description records desktop, tablet and mobile use with a dark-friendly palette and high-contrast text, and only a dark mode is listed in the index.

![Space screenshot](https://raw.githubusercontent.com/bhappen/obsidian-space/HEAD/obsidian-space.png)

```cue
theme: {
    name:   "Space"
    author: "bhappen"
    repo:   "bhappen/obsidian-space"
    slug:   "space"

    html_url:       "https://community.obsidian.md/themes/space"
    github_url:     "https://github.com/bhappen/obsidian-space"
    screenshot_url: "https://raw.githubusercontent.com/bhappen/obsidian-space/HEAD/obsidian-space.png"

    modes: ["dark"]
    about: "Transform Obsidian into a space-themed workspace with deep-space backgrounds, glowing accents, futuristic fonts, and custom space icons. Work comfortably on desktop, tablet, and mobile with a dark-friendly palette and high-contrast text for better legibility."
}
```
