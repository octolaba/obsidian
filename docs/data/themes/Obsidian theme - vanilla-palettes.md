# Vanilla Palettes

Vanilla Palettes swaps Obsidian's colour palette for popular theme palettes while leaving the vanilla interface itself unchanged. Palettes are switched through the Style Settings plugin, and the recorded description lists Atom One Dark, Catppuccin, Dracula, Gruvbox, Horizon, Kanagawa, Nord, Rose Pine and Tokyo Night.

![Vanilla Palettes screenshot](https://raw.githubusercontent.com/gnrlleclerc/Vanilla-Theme-Palettes/HEAD/thumbnail.png)
