# Third Brain Neon

A dark neon aesthetic in cyan, magenta and violet, with glass-pane workspaces and an AI-generated neon room wallpaper bundled as a single offline WebP data URI. File explorer icons are colored by state, headings, links and highlights take on distinct neon roles, and editor spacing is set for click accuracy. Dark mode is forced so the look stays consistent.
