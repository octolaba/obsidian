# Shimmering Focus

Shimmering Focus is a keyboard-centric theme that hides nonessential UI, shows controls only when they are needed, and condenses spacing for compact navigation. More than a hundred options are exposed through Style Settings, covering colours, headings, tables, image captions and zoom, and styling for Vim and Longform.

![Shimmering Focus screenshot](https://raw.githubusercontent.com/chrisgrieser/shimmering-focus/HEAD/assets/promo-screenshot.webp)
