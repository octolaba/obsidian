# BrutalGarden

A neo-brutalist skin with paper textures, hard three-pixel borders, crisp cardboard-cut shadows and a 24-pixel dot grid. Two modes are offered: Paper for light and Soft Night for dark, the latter with lime-tinted shadows. Fifteen hand-designed callouts carry distinct styles, and the type stack uses iA Writer Duo S, Quattro S and Mono S.
