# Arzaba

Arzaba is a colourful but minimal theme its recorded description aims at long hours of focused note-taking. It ships six preset styles, named Wiki, Past, Black and White, Retro, Ivy and Future, so the look can be switched to suit a workflow.

![Arzaba screenshot](https://raw.githubusercontent.com/darioarzaba/Obsidian-Theme-Arzaba/HEAD/screenshot.png)

```cue
theme: {
    name:   "Arzaba"
    author: "darioarzaba"
    repo:   "darioarzaba/Obsidian-Theme-Arzaba"
    slug:   "arzaba"

    html_url:       "https://community.obsidian.md/themes/arzaba"
    github_url:     "https://github.com/darioarzaba/Obsidian-Theme-Arzaba"
    screenshot_url: "https://raw.githubusercontent.com/darioarzaba/Obsidian-Theme-Arzaba/HEAD/screenshot.png"

    modes: ["dark", "light"]
    about: "Use a vibrant, colorful yet minimal and sleek theme designed for long hours of focused note-taking. Switch between preset styles — Wiki, Past, Black and White, Retro, Ivy and Future — to tailor the look to your workflow."
}
```
