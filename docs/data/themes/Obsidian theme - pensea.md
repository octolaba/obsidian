# Pensea

Pensea gives a vault a warm, book-like look with warm-gray backgrounds, softened shadows and serif titles. It provides light and dark modes, revised callouts, pill tags, link styles and a tuned graph palette, and the recorded description names mobile-friendly layouts and pairing with the Pensea plugin.
