# Atelier

Atelier is a warm editorial skin with a cream parchment background, coral accents, Newsreader serif headings and monospaced small-caps labels. It adds webpage-style cards composed in plain Markdown on a responsive grid, plus reusable utilities for restyling inline text, and the whole palette can be recoloured from a single accent token. A warm dark variant and a companion skin called Lucid are available and keep the card layout intact.

![Atelier screenshot](https://raw.githubusercontent.com/bsbbera/atelier-obsidian/HEAD/screenshot.png)
