# Retroma

Retroma is described by its author as a tribute to the past, drawing on retro arcade machines, vintage software and the early web to bring back tactile controls that look like you could press them. Its palette is generated from a single accent colour that the user picks, with the rest of the colours derived from it automatically.

![Retroma screenshot](https://raw.githubusercontent.com/emarpiee/Retroma/HEAD/assets/screenshots/retroma-banner.png)

```cue
theme: {
    name:   "Retroma"
    author: "emarpiee"
    repo:   "emarpiee/Retroma"
    slug:   "retroma"

    html_url:       "https://community.obsidian.md/themes/retroma"
    github_url:     "https://github.com/emarpiee/Retroma"
    screenshot_url: "https://raw.githubusercontent.com/emarpiee/Retroma/HEAD/assets/screenshots/retroma-banner.png"

    modes: ["dark", "light"]
    about: "Retroma is a tribute to the past, reminding us of a time when buttons looked like you could actually press them and when UI actually had personality. It draws inspiration from retro arcade machines, vintage software, and the early web, bringing back actual tactile designs and personality. You don't need design skills to make it look good, either. Simply pick a single accent color and Retroma handles the rest of the palette automatically, protecting you from your own worst styling instincts."
}
```
