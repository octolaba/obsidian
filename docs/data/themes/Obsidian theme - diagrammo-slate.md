# Diagrammo Slate

Applies a Slate palette in which a nine-hue spectrum is mapped consistently onto headings, callouts, tags, folders, syntax, task states, graph nodes and canvas. Light and dark keep distinct palettes with verbatim palette colors, and subtle washed blocks mark headings H1 to H6 on a warm-to-cool progression.

![Diagrammo Slate screenshot](https://raw.githubusercontent.com/demian0311/obsidian-slate/HEAD/screenshot.png)
