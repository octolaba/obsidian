# Ecdysis

Ecdysis gives Obsidian a retro terminal look, setting neon colors on a near-black background with pixel-game typography, Press Start 2P for headings and Roboto Mono for body and interface text. Each note is framed by a thin glowing green border, and the recorded description adds neon-glow headers, colored inline formatting, magenta links, neon-tinted tables and terminal-style syntax highlighting. The theme index records dark mode only.

![Ecdysis screenshot](https://raw.githubusercontent.com/kodamachameleon/Ecdysis/HEAD/screenshot.png)
