# termina

termina is a TUI-style monospace theme that draws every pane, including the editor, sidebars, status bar and command palette, as a bordered box with lowercase labels and no rounded corners. Its palette is a neutral oklch grayscale with a purple accent, and the matching dark and light styles use DM Mono with JetBrains Mono and Fira Code as fallbacks.

![termina screenshot](https://raw.githubusercontent.com/xevrion/obsidian-termina/HEAD/screenshot.png)
