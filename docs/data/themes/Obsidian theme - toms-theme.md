# Tom's Theme

Tom's Theme is a minimalist Game Boy-inspired theme that narrows the editor to 520px, which the recorded description ties to an optimal line length of 54 characters. It offers dark or light modes over a black background with Game Boy green text, and its CSS is commented so that it can be customized further.

![Tom's Theme screenshot](https://raw.githubusercontent.com/tomkaygames/Tom-s-Theme/HEAD/screenshot.png)

```cue
theme: {
    name:   "Tom's Theme"
    author: "tomkaygames"
    repo:   "tomkaygames/Tom-s-Theme"
    slug:   "toms-theme"

    html_url:       "https://community.obsidian.md/themes/toms-theme"
    github_url:     "https://github.com/tomkaygames/Tom-s-Theme"
    screenshot_url: "https://raw.githubusercontent.com/tomkaygames/Tom-s-Theme/HEAD/screenshot.png"

    modes: ["dark", "light"]
    about: "Apply a minimalist Game Boy–inspired theme that narrows editor width to 520px for optimal 54-character line length and keeps focus on writing. Use dark or light modes with a black background and Game Boy green text; theme includes commented CSS for easy customization."
}
```
