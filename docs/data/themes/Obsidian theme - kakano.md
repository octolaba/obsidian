# Kakano

Kakano generates an interface from a single chosen base color, adding a smooth gradient background and controls that follow the operating system. Light, dark and mobile modes are supported, and the recorded description claims wide compatibility with core and community plugins.

![Kakano screenshot](https://raw.githubusercontent.com/isaacfreeman/kakano-obsidian-theme/HEAD/screenshot.png)

```cue
theme: {
    name:   "Kakano"
    author: "Isaac Freeman"
    repo:   "isaacfreeman/kakano-obsidian-theme"
    slug:   "kakano"

    html_url:       "https://community.obsidian.md/themes/kakano"
    github_url:     "https://github.com/isaacfreeman/kakano-obsidian-theme"
    screenshot_url: "https://raw.githubusercontent.com/isaacfreeman/kakano-obsidian-theme/HEAD/screenshot.png"

    modes: ["dark", "light"]
    about: "Bring color to your desktop. Choose a base color to generate a clean, consistent interface with a smooth gradient background and OS-native controls. Support light, dark and mobile modes with wide compatibility for core and community plugins."
}
```
