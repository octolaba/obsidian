# Monokai Syntax

Monokai Syntax recreates the dark and light visual language of Monokai Pro in Obsidian, tuned for readable notes and code in knowledge-management workflows. Fonts, icons and images are kept local, which its recorded description ties to Obsidian's runtime restrictions and to offline-friendly theming.

![Monokai Syntax screenshot](https://raw.githubusercontent.com/darkings/Obsidian-MonokaiSyntax/HEAD/screenshot.png)

```cue
theme: {
    name:   "Monokai Syntax"
    author: "darkings"
    repo:   "darkings/Obsidian-MonokaiSyntax"
    slug:   "monokai-syntax"

    html_url:       "https://community.obsidian.md/themes/monokai-syntax"
    github_url:     "https://github.com/darkings/Obsidian-MonokaiSyntax"
    screenshot_url: "https://raw.githubusercontent.com/darkings/Obsidian-MonokaiSyntax/HEAD/screenshot.png"

    modes: ["dark", "light"]
    about: "Recreate Monokai Pro's dark and light visual language in Obsidian, tuned for readable notes and code in knowledge-management workflows. Keep fonts, icons, and images local to comply with Obsidian's runtime restrictions and ensure offline-friendly theming."
}
```
