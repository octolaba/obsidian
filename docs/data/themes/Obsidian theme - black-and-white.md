# Black and White

Black and White is a monochrome theme of crisp whites and deep charcoal. It keeps vibrant coloured highlights for key terms, and it turns a line carrying the flashcard tag into a glowing prompt. Grouped callouts are styled as a set, and adding the collage cssclass renders Dataview output as cards.

![Black and White screenshot](https://raw.githubusercontent.com/wulflo/obsidian-BlackAndWhite/HEAD/cover.png)

```cue
theme: {
    name:   "Black and White"
    author: "wulflo"
    repo:   "wulflo/obsidian-BlackAndWhite"
    slug:   "black-and-white"

    html_url:       "https://community.obsidian.md/themes/black-and-white"
    github_url:     "https://github.com/wulflo/obsidian-BlackAndWhite"
    screenshot_url: "https://raw.githubusercontent.com/wulflo/obsidian-BlackAndWhite/HEAD/cover.png"

    modes: ["dark", "light"]
    about: "Apply a refined monochrome palette of crisp whites and deep charcoal for a timeless, minimalist interface. Highlight key terms with vibrant colored highlights and turn any line into a glowing flashcard prompt by adding the #flashcard tag. Style grouped callouts and enable Dataview cards by adding the collage cssclass."
}
```
