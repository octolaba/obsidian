# Retro Relay

A warm analog palette pairing cream on cocoa in dark mode with ink on paper in light mode, unified by an amber accent. Contrast is measured against WCAG 2.1 AA, and accessible cues include icons on callouts, a dotted underline for unresolved links and visible focus rings. Graph view, code tokens and tables are styled to match.
