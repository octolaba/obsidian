# Material Gruvbox

Material Gruvbox is a Material-styled Gruvbox theme with coordinated dark and light variants, based on the Gruvbox Material palette. Light-tone options switch between warmer yellowed tones and a softer, lighter palette.

![Material Gruvbox screenshot](https://raw.githubusercontent.com/alljavi/material_gruvbox_obsidian/HEAD/promo_screenshot.png)
