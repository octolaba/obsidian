# Nott Dagr

Nott Dagr is a paired dark and light theme whose two halves, Nott and Dagr, hold identical semantic color roles so that tokens and UI elements keep the same meaning in either mode. Nott provides cool, aurora-inspired night surfaces and Dagr warm, parchment-like daytime surfaces.

![Nott Dagr screenshot](https://raw.githubusercontent.com/asgardehs/nott-dagr-obsidian/HEAD/Nott.png)
