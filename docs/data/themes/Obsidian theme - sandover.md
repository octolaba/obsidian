# Sandover

Sandover styles a vault as a typewritten manuscript page, with the TT2020 font embedded and manuscript-inspired accent colours. Blockquote syntax renders as blue comments, heading and bold characters are visibly dissimilar, and colours can be adjusted through Style Settings.

![Sandover screenshot](https://raw.githubusercontent.com/eliz-abeth/sandover/HEAD//images/sandover-plain.png)

```cue
theme: {
    name:   "Sandover"
    author: "eliz-abeth"
    repo:   "eliz-abeth/sandover"
    slug:   "sandover"

    github_url:     "https://github.com/eliz-abeth/sandover"

}
```
