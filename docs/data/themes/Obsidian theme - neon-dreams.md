# Neon Dreams

Neon Dreams is a near-black blue theme with cool-toned text, thin borders and indigo accents, aimed at personal knowledge management, journaling and project tracking. The palette is driven by two HSL hues and the dark and light variants can be switched. It adds semantic callouts, native task-state icons, rounded tag pills, terminal-style code blocks and Inter with JetBrains Mono typography.
