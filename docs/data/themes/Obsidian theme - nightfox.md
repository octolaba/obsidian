# Nightfox

Nightfox brings the Nightfox.nvim color palette and styling to Obsidian. Its recorded description names a cohesive dark color scheme with consistent syntax highlighting across editor panes and interface elements.

![Nightfox screenshot](https://raw.githubusercontent.com/markmacode/obsidian-nightfox/HEAD/thumbnail.png)

```cue
theme: {
    name:   "Nightfox"
    author: "markmacode"
    repo:   "markmacode/obsidian-nightfox"
    slug:   "nightfox"

    html_url:       "https://community.obsidian.md/themes/nightfox"
    github_url:     "https://github.com/markmacode/obsidian-nightfox"
    screenshot_url: "https://raw.githubusercontent.com/markmacode/obsidian-nightfox/HEAD/thumbnail.png"

    modes: ["dark", "light"]
    about: "Apply Nightfox to bring the Nightfox.nvim color palette and styling to Obsidian. Get a cohesive dark color scheme with consistent syntax highlighting across editor panes and UI elements."
}
```
