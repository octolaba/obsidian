# Shade Sanctuary

Shade Sanctuary is an academic, colourful dark theme whose stated inspiration is lecture notes and Vauxhall, aimed at writing educational content. Colour schemes and interface intensity are adjustable through Style Settings, and it adds math callouts, gradient headers and animated snippets.

![Shade Sanctuary screenshot](https://raw.githubusercontent.com/elevict/Shade-Sanctuary/HEAD/cover.png)

```cue
theme: {
    name:   "Shade Sanctuary"
    author: "elevict"
    repo:   "elevict/Shade-Sanctuary"
    slug:   "shade-sanctuary"

    html_url:       "https://community.obsidian.md/themes/shade-sanctuary"
    github_url:     "https://github.com/elevict/Shade-Sanctuary"
    screenshot_url: "https://raw.githubusercontent.com/elevict/Shade-Sanctuary/HEAD/cover.png"

    modes: ["dark", "light"]
    about: "Style Obsidian with an academic, colorful dark theme inspired by lecture notes and Vauxhall to create a focused writing environment for educational content. Customize color schemes and interface intensity with Style Settings and add math callouts, gradient headers, and animated snippets."
}
```
