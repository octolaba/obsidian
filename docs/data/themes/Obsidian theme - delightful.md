# Delightful

Delightful is a warm neo-brutalist skin with bold 2px borders, solid zero-blur shadows, generous radii, and warm neutral palettes in light and dark modes. It styles eight color-coded callouts, tables, code syntax, task checkboxes, Canvas nodes and Graph view with perceptual color tokens, and adds a motion system, themed scrollbars and mobile-friendly touch targets.
