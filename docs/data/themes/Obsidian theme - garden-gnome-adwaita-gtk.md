# Garden Gnome (Adwaita, GTK)

Garden Gnome imitates GTK and Adwaita visuals inside Obsidian so notes take on a native GNOME look. The recorded description describes minimal styling that echoes Adwaita colors, spacing and controls for consistency with the desktop, and the theme index lists both dark and light modes.
