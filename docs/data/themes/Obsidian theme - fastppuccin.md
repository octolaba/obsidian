# FastPpuccin

FastPpuccin is described as a speed-optimized clone of AnuPpuccin that preserves the original look while stripping extras. It states compatibility with AnuPpuccin Themes Extended and keeps interface touches such as forced accents, custom checkboxes, file icons, colored headings, Safari-style tabs and table hover transitions. The performance claim is the recorded description own and was not measured here.

![FastPpuccin screenshot](https://raw.githubusercontent.com/lostviking09/obsidian-fastppuccin/HEAD/theme_image.png)
