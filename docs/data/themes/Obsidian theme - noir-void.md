# Noir Void

A monochrome workspace pairing a deep charcoal dark mode with a warm ivory light one. Dedicated reading and source modes, layered surfaces and a subtle accent color shape the writing view, while graph view, code blocks and tables are given their own treatment. The layout responds on mobile.
