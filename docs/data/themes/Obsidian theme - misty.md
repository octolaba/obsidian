# Misty

Misty pairs an ivory-and-charcoal palette with terracotta accents for long reading in both light and dark modes. It sets distinct typefaces, Charter and Songti SC for body text and JetBrains Mono for code, and adds colorful code highlighting beside a refined sidebar and polished search. Tables and callouts are rendered with rounded corners and soft shadows.

![Misty screenshot](https://raw.githubusercontent.com/perinchiang/obsidian-misty-theme/HEAD/screenshot.png)
