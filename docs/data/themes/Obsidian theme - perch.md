# Perch

Perch is a dual-mode theme with a warm Dawn palette and a muted-teal Dusk palette, described as calibrated to WCAG contrast and as avoiding the 460nm blue-light peak in order to reduce eye strain. A focus mode dims non-active lines, and the theme ships its own font stacks. The contrast and eye-strain claims are the description's own.

![Perch screenshot](https://raw.githubusercontent.com/bewater8066/obsidian-theme-perch/HEAD/composite.png)
