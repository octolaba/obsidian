# Obuntu

Obuntu is an Ubuntu-inspired light and dark theme that integrates Ubuntu colors with the Roboto and Fira Code fonts. It shows colored tags, visible indentation lines, expressive tables, custom checklists and adjusted vim-mode colors, and its edit mode hides most hashes while inactive.

![Obuntu screenshot](https://raw.githubusercontent.com/dmytrodubinin/Obuntu-theme-for-Obsidian/HEAD/screenshot.jpg)

```cue
theme: {
    name:   "Obuntu"
    author: "dmytrodubinin"
    repo:   "dmytrodubinin/Obuntu-theme-for-Obsidian"
    slug:   "obuntu"

    html_url:       "https://community.obsidian.md/themes/obuntu"
    github_url:     "https://github.com/dmytrodubinin/Obuntu-theme-for-Obsidian"
    screenshot_url: "https://raw.githubusercontent.com/dmytrodubinin/Obuntu-theme-for-Obsidian/HEAD/screenshot.jpg"

    modes: ["dark", "light"]
    about: "Apply an Ubuntu-inspired light and dark theme with integrated Ubuntu colors and Roboto + Fira Code fonts. Show colored tags, visible indentation lines, expressive tables, custom checklists, improved vim-mode colors, and a clutter-free edit mode that hides most hashes when inactive."
}
```
