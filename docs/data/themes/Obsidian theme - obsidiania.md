# obsidian_ia

obsidian_ia is a minimal theme modeled on iA Writer. It sets the iA Writer Quattro font for readable typography and uses subtle spacing, which the recorded description frames as keeping the focus on writing.

![obsidian_ia screenshot](https://raw.githubusercontent.com/rcvd/obsidian_ia/HEAD/light.png)
