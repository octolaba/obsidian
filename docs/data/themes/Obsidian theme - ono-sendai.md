# Ono Sendai

Ono Sendai is a retro terminal look with dark-first styling, a distraction-free layout, text-based tab icons, larger popovers, image hover-zoom and visible edit margins. It enables file-explorer columns, long-name wrapping and consistent footnote superscripts. The recorded description states that the theme is unmaintained and may not work properly in newer Obsidian versions.
