# Celestial Abyss

A theme built around deep space, observatories and celestial libraries, offering an abyssal dark mode and an ivory light one with nebula-inspired accents and layouts meant for long writing sessions. Editor styling, a constellation-inspired graph view, archive-style tables, metadata panels and callouts are all covered.
