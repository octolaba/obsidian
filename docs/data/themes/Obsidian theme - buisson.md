# Buisson

Buisson is a botanical color scheme for editors and terminals, with a palette inspired by Everforest, Evergarden and Flexoki. It is designed for long coding and writing sessions, combining warm paper backgrounds, botanical ink accents and WCAG-calibrated contrasts.
