# Typewriter

Typewriter arranges the editor for focused writing with a monospace editor font, semi-proportional fonts for the UI and preview, faded markdown, and an active-line highlight on the current line. Its recorded description also lists base64-embedded fonts for mobile, embeds rendered without file titles, and support for community plugins.
