# Flexoki

Flexoki is the standalone Obsidian version of the Flexoki color scheme, described as minimalistic and high-contrast. Its colors are stated to be calibrated for legibility and perceptual balance across devices and when switching between light and dark modes. The description also records that Flexoki exists as a color scheme inside the Minimal theme, which it says offers more options and customizability.

![Flexoki screenshot](https://raw.githubusercontent.com/kepano/flexoki-obsidian/HEAD/cover-small.png)
