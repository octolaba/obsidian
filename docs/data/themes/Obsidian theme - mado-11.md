# Mado 11

Mado 11 is a Windows 11-inspired theme with a spacious layout and larger sidebar buttons. Colors, layout and element visibility are customizable through Style Settings, and the theme supplies CSS classes for a pseudo File Explorer, styled headings and special table layouts.

![Mado 11 screenshot](https://raw.githubusercontent.com/hydescarf/Obsidian-Theme-Mado-11/HEAD/img/store-cover.png)
