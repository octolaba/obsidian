# Lumines

Lumines is a minimal theme with an updated color palette and cross-platform support for Android, iOS, macOS and Windows. It adds more than 300 situational icons that change automatically by property type or keyword so metadata and documents are easier to scan, and its recorded description names regular fixes and compatibility updates.

![Lumines screenshot](https://raw.githubusercontent.com/danielkhmara/obsidian-lumines/HEAD/obsidian-lumines.png)
