# Serendipity

Serendipity is a minimal colour palette with clean contrast and subtle details for distraction-free note-taking. Morning is its light appearance and Midnight its dark one, and a Sunset variant is available as an optional CSS snippet.

![Serendipity screenshot](https://raw.githubusercontent.com/michael-andreuzza/serendipity-obsidian/HEAD/screenshot.png)

```cue
theme: {
    name:   "Serendipity"
    author: "Micheal Andreuzza"
    repo:   "michael-andreuzza/serendipity-obsidian"
    slug:   "serendipity"

    html_url:       "https://community.obsidian.md/themes/serendipity"
    github_url:     "https://github.com/michael-andreuzza/serendipity-obsidian"
    screenshot_url: "https://raw.githubusercontent.com/michael-andreuzza/serendipity-obsidian/HEAD/screenshot.png"

    modes: ["dark", "light"]
    about: "Apply an elegant, minimal color palette with clean contrast and subtle details for distraction-free note-taking. Switch between Morning (light) and Midnight (dark), or enable the Sunset variant as an optional CSS snippet."
}
```
