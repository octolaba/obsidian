# Infosecwarrior UI

Infosecwarrior UI is a dark, information-dense theme designed for compact, readable documentation. Color-coded hierarchies for headings and lists are the stated means of keeping complex notes easy to scan and navigate, and the theme index lists both dark and light modes.
