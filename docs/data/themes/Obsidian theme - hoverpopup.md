# HoverPopup

HoverPopup is a dark theme that adds hover pop-up previews, animated GIF accents, cute interface elements and keyboard hint styling. The recorded description confines the hover effects to preview mode while edit mode stays minimal, and says flicker, animations and a holo variant are adjusted by editing the CSS.

![HoverPopup screenshot](https://raw.githubusercontent.com/cogqod/hoverpopup-obsidian-theme/HEAD/screenshots/screenshot.png)
