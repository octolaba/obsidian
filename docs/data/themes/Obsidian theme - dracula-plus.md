# Dracula Plus

Dracula Plus is a Dracula-inspired dark theme covering desktop, tablet and mobile. RGB accent colors are customizable, code blocks use vivid palettes, and extended checkbox types cover task states such as to-do, done, cancelled, question and pull request statuses.
