# Modern GenZ Vibedose

Modern GenZ Vibedose is a modern, expressive desktop theme optimized for Live Preview, its recorded description aiming at students, writers and digital thinkers. Gradient folder coloring is not built in and arrives through external snippets the project provides.

![Modern GenZ Vibedose screenshot](https://raw.githubusercontent.com/omkar-4/Modern-GenZ-Vibedose/HEAD/screenshot.png)

```cue
theme: {
    name:   "Modern GenZ Vibedose"
    author: "omkar-4"
    repo:   "omkar-4/Modern-GenZ-Vibedose"
    slug:   "modern-genz-vibedose"

    html_url:       "https://community.obsidian.md/themes/modern-genz-vibedose"
    github_url:     "https://github.com/omkar-4/Modern-GenZ-Vibedose"
    screenshot_url: "https://raw.githubusercontent.com/omkar-4/Modern-GenZ-Vibedose/HEAD/screenshot.png"

    modes: ["dark", "light"]
    about: "Style Obsidian with a clean, modern, expressive desktop theme optimized for Live Preview. Create a playful yet professional workspace suited to students, writers, and digital thinkers. Add gradient folder coloring through provided external snippets."
}
```
