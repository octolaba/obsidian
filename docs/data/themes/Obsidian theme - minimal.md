# Minimal

Minimal is configured through the Minimal Theme Settings plugin, which adjusts colors, fonts and layouts across devices and offers low-contrast, high-contrast and true-black backgrounds. It adds a focus mode, an image grid and helper classes for tables and cards, and ships built-in styling for Calendar, Kanban, Dataview, Outliner and Excalidraw.
