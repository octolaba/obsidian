# Lumen

Lumen carries six color schemes, three light and three dark, that share sans-serif typography, a six-level heading hierarchy, gradient-underline links and accent-tinted blockquotes. Switching schemes requires the Style Settings plugin; without it the theme defaults to dark, which is also the only mode the index records.

![Lumen screenshot](https://raw.githubusercontent.com/stephanteig/obsidian-lumen/HEAD/lumen_preview.png)

```cue
theme: {
    name:   "Lumen"
    author: "stephanteig"
    repo:   "stephanteig/obsidian-lumen"
    slug:   "lumen"

    html_url:       "https://community.obsidian.md/themes/lumen"
    github_url:     "https://github.com/stephanteig/obsidian-lumen"
    screenshot_url: "https://raw.githubusercontent.com/stephanteig/obsidian-lumen/HEAD/lumen_preview.png"

    modes: ["dark"]
    about: "Choose from six refined color schemes — three light, three dark — sharing clean sans-serif typography, a strong six-level heading hierarchy, gradient-underline links, and accent-tinted blockquotes for clear, readable notes. Enable Style Settings to switch schemes; theme defaults to dark without it."
}
```
