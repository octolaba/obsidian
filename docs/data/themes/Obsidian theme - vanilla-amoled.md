# Vanilla AMOLED

Vanilla AMOLED sets the Obsidian background to true black for AMOLED screens while keeping the default vanilla appearance. Its recorded description describes the result as simple and minimal, with clear contrast for distraction-free note-taking.

![Vanilla AMOLED screenshot](https://raw.githubusercontent.com/sakuraisayeki/vanilla-amoled-theme/HEAD/sample-screenshot-sm.png)

    name:   "Vanilla AMOLED"
    author: "sakuraisayeki"
    repo:   "sakuraisayeki/vanilla-amoled-theme"

    html_url:       "https://community.obsidian.md/themes/vanilla-amoled"

    about: "Apply a vanilla-styled ultra-dark theme that sets Obsidian’s background to true black for AMOLED screens. Keep a simple, minimal look with clear contrast and vanilla aesthetics for distraction-free note-taking."
}
