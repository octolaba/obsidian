# Alice Velvet

Alice Velvet is a dark theme drawing on an Alice in Wonderland palette: deep onyx backgrounds, muted purple panels, pale readable text and rich red accents. Its styling covers the editor views, sidebars, tabs, links, tags, checkboxes, callouts, code blocks, tables and graph view. The recorded description points questions, feedback and issue reports to the author on Discord.
