# Firefly

Firefly is a minimal theme with subtle color accents and deliberately different editor and preview styling, giving a code-editor feel while editing and a blog-like presentation while reading. The recorded description adds experimental code-style tags, abbreviated CST, for styled note blocks, and recommends Inter and JetBrains Mono. The theme index records dark mode only, although the description names dark and light modes.

![Firefly screenshot](https://raw.githubusercontent.com/lazercaveman/obsidian-firefly-theme/HEAD/firefly-theme-screenshot.png)
