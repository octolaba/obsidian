# Half-Life

Half-Life applies a programming-style color scheme to Obsidian for a high-contrast editing experience. The recorded description says subtle syntax-like colors and balanced contrast are meant to make notes and code blocks easier to read, and the theme index records dark mode only.

![Half-Life screenshot](https://raw.githubusercontent.com/saucy/obsidian-half-life-theme/HEAD/images/thumbnail.png)

    name:   "Half-Life"
