# Dracula Official

Dracula Official applies the dark Dracula color palette to Obsidian for a cohesive, high-contrast interface intended to reduce eye strain. The editor, sidebar and interface elements stay visually consistent, with vivid syntax colors and clear contrasts.

![Dracula Official screenshot](https://raw.githubusercontent.com/dracula/obsidian/HEAD/screenshot.png)

theme: {
    name:   "Dracula Official"
    author: "dracula"
    repo:   "dracula/obsidian"
    slug:   "dracula-official"

    html_url:       "https://community.obsidian.md/themes/dracula-official"
    github_url:     "https://github.com/dracula/obsidian"

}
