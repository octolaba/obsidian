# Wyrd

Wyrd is a purple-hued, low-contrast theme with dual modes, expressive colours and subtle animations. Fonts are customizable via Google Fonts with responsive scaling, and its Markdown styles are driven by unique CSS. Its recorded description also offers playful text obfuscation in Preview and Publish and states explicitly that this is not a privacy feature.

![Wyrd screenshot](https://raw.githubusercontent.com/curio-heart/obsidian-wyrd/HEAD/img/Wyrd.png)
