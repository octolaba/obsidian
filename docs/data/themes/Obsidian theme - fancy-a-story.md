# Fancy-a-Story

Fancy-a-Story turns notes into a storybook-style interface with dark and light modes, handwritten checkboxes, custom list and blockquote treatments, cassette-style audio embeds and faded embeds that blend into the text. Callouts, CSS classes, snippets and layout details are adjusted through Style Settings for narrative-focused pages.
