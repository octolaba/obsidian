# Vision

Vision gives notes an editorial manuscript look built on cream paper, a subtle 32px grid, serif headings and crisp ink accents. Tables carry tracked uppercase headers, pull-quotes are indented, tags render as outlined chips, and section dividers are centered. A companion dark mode inverts the ink-on-paper scheme.
