# Silver

Silver reduces paragraph spacing for a tighter, more compact note layout. Its recorded description names that single change and nothing else, although the index lists the theme in both dark and light modes.

![Silver screenshot](https://raw.githubusercontent.com/wn2try/obsidian-theme-silver/HEAD/thumbnail.jpg)

```cue
theme: {
    name:   "Silver"
    author: "wn2t"
    repo:   "wn2try/obsidian-theme-silver"
    slug:   "silver"

    html_url:       "https://community.obsidian.md/themes/silver"
    github_url:     "https://github.com/wn2try/obsidian-theme-silver"
    screenshot_url: "https://raw.githubusercontent.com/wn2try/obsidian-theme-silver/HEAD/thumbnail.jpg"

    modes: ["dark", "light"]
    about: "Reduce paragraph spacing for a tighter, more compact note layout."
}
```
