# Hojicha

Hojicha is a warm, toasty palette drawn from roasted hojicha, with golden-brown accents over a soft charcoal glow. The recorded description calls the styling dark-mode-first and grounded, claims it reduces eye strain, and suggests the theme for daily journals, Zettelkasten and research notes. That eye-strain claim is the description own and was not measured here.
