# Gastown

Gastown is a light visual style that its recorded description presents as emphasizing readability through balanced spacing and classic typography. Merriweather and Open Sans are recommended for rendering, and the description states that the theme is no longer actively maintained. The theme index records light mode only and marks the entry as legacy.
