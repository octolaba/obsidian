# Iridium

Iridium is a customizable theme that emphasizes the chosen accent color and streamlines the Obsidian interface. The recorded description lists alternate checkbox glyphs for many task and status types, among them to-do, done, canceled, question, important, hearts and color markers, with the visuals adjusted through the Style Settings plugin.
