# macOS Tahoe

Reworks the interface toward native macOS, with SF Pro chrome, system materials, traffic-light window controls and System Blue accents. Dual light and dark palettes, frosted materials, soft radii and native-feeling shadows are applied to the sidebar, titlebar, menus and form controls. Obsidian's native font sizes are preserved and metadata chrome is kept minimal.
