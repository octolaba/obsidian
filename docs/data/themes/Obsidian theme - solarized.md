# Solarized

Solarized brings the Solarized colour scheme to Obsidian with matched light and dark modes and its balanced, low-contrast colours, while keeping hue contrast in syntax highlighting. It respects Obsidian's accent colour and integrates with dynamic highlights and the vim-mode status for consistent UI and editor colouring.

![Solarized screenshot](https://raw.githubusercontent.com/harmtemolder/obsidian-solarized/HEAD/screenshot.png)

```cue

    name:   "Solarized"
    author: "harmtemolder"
    repo:   "harmtemolder/obsidian-solarized"

}
```
