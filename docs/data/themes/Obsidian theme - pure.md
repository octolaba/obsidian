# Pure

Pure preserves Obsidian's original look while adding subtle usability tweaks and minor layout fixes. The left ribbon is auto-hidden and revealed on hover, task checkboxes are round, and four list levels take tiered solid and hollow bullets.

![Pure screenshot](https://raw.githubusercontent.com/lychileng/Obsidian-Theme-Pure/HEAD/screenshots/cover.png)

}
