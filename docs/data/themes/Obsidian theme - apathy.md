# Apathy

Apathy is a dark theme built on deep purple-black backgrounds with mint accents, and callouts styled to stay distinct from one another while remaining harmonious. Code blocks get syntax-aware colours, and the styling extends to tabs, the navigation, the titlebar and input fields for a consistent surface.

![Apathy screenshot](https://raw.githubusercontent.com/czxtm/apathy-obsidian/HEAD/screenshot.png)

```cue
theme: {
    name:   "Apathy"
    author: "czxtm"
    repo:   "czxtm/apathy-obsidian"
    slug:   "apathy"

    html_url:       "https://community.obsidian.md/themes/apathy"
    github_url:     "https://github.com/czxtm/apathy-obsidian"
    screenshot_url: "https://raw.githubusercontent.com/czxtm/apathy-obsidian/HEAD/screenshot.png"

    modes: ["dark"]
    about: "Apply deep purple‑black backgrounds with vibrant mint accents and distinct, harmonious callouts for a focused dark workspace. Style code blocks with syntax-aware colors and polish UI elements like tabs, nav, titlebar, and inputs for a consistent, readable look."
}
```
