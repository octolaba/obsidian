# Mia

Mia is a lightweight theme for macOS and iOS that builds on Obsidian's default theme with an emphasis on a distraction-free experience. It supports light and dark modes, offers a true source view with a monospace font and hanging headings, and a serif reading view. Configuration goes through the Style Settings plugin.

![Mia screenshot](https://raw.githubusercontent.com/playerofgames/obsidian-mia-theme/HEAD/preview.png)
