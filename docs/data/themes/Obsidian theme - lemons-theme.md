# Lemons Theme

Lemons Theme is a dark, rounded and borderless monospace style. Rounded corners, borderless panes and a consistent monospaced font are what its recorded description names for a distraction-free writing and reading workspace.

![Lemons Theme screenshot](https://raw.githubusercontent.com/mprojectscode/obsidian-lemons-theme/HEAD/lemons-theme-picture-low-res.PNG)

}
