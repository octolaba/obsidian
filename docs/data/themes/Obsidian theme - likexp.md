# LikeXP

LikeXP recreates the 2000s Windows XP look in Obsidian with a Luna Blue light mode and a Royale Noir dark mode. Retro interface elements include 3D beveled buttons, classic scrollbars, period dialog styles and Windows Explorer-style folder icons in the file tree.

![LikeXP screenshot](https://raw.githubusercontent.com/usero2/obsidian-themes-LikeXP/HEAD/images/dark_mode.png)
