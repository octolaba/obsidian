# MagicUser

A theme configured through the Style Settings plugin, which exposes more than 200 individual options. It ships several light and dark presets along with interface modes and preset styles for tables, checkboxes and callouts, aimed at academic and professional use. A quick-start section of the Style Settings menu applies a finished look without going through the detailed options.

![MagicUser screenshot](https://raw.githubusercontent.com/drbap/magicuser-theme-for-obsidian/HEAD/screenshot.png)

```cue
theme: {
    name:   "MagicUser"
    author: "Bernardo Pires"
    repo:   "drbap/magicuser-theme-for-obsidian"
    slug:   "magicuser"

    html_url:       "https://community.obsidian.md/themes/magicuser"
    github_url:     "https://github.com/drbap/magicuser-theme-for-obsidian"
    screenshot_url: "https://raw.githubusercontent.com/drbap/magicuser-theme-for-obsidian/HEAD/screenshot.png"

    modes: ["dark", "light"]
    about: "MagicUser is a comprehensive, highly customizable Obsidian theme built to elevate your daily note-taking. Featuring over 200 granular options via the Style Settings plugin, it gives you deep control over your workspace—including multiple light and dark presets, UI modes, preset tables, checkboxes, and callouts tailored for both demanding academic study and professional environments. Use the quick start Style Settings menu to skip the deep customization and achieve a polished, personalized workflow in minutes."
}
```
