# Green Nightmare

Green Nightmare replaces the Obsidian colors with neon green on black, using layered green shades for accents, highlights and code syntax. The default layout is left in place so only the colors change, and the theme index records dark mode only.

![Green Nightmare screenshot](https://raw.githubusercontent.com/prradox/green-nightmare/HEAD/screenshot.png)

```cue
theme: {
    name:   "Green Nightmare"
    author: "prradox"
    repo:   "prradox/green-nightmare"
    slug:   "green-nightmare"

    html_url:       "https://community.obsidian.md/themes/green-nightmare"
    github_url:     "https://github.com/prradox/green-nightmare"
    screenshot_url: "https://raw.githubusercontent.com/prradox/green-nightmare/HEAD/screenshot.png"

    modes: ["dark"]
    about: "Apply a neon green-on-black color scheme with layered green shades for accents, highlights, and code syntax. Maintain Obsidian's default layout while replacing colors for a high-contrast, focused, retro-inspired interface."
}
```
