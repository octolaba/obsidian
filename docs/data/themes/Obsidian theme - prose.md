# Prose

Prose is a typographic theme that sets IBM Plex for body text, headings and UI, with a monospace face for code. Its type scale is a fluid minor third of 1.2 and its measure is about 700px. The palette is warm neutrals in refined light and dark modes.

![Prose screenshot](https://raw.githubusercontent.com/zojer-studio/prose-obsidian/HEAD/screenshot.png)

```cue
theme: {
    name:   "Prose"
    author: "zojer-studio"
    repo:   "zojer-studio/prose-obsidian"
    slug:   "prose"

    html_url:       "https://community.obsidian.md/themes/prose"
    github_url:     "https://github.com/zojer-studio/prose-obsidian"
    screenshot_url: "https://raw.githubusercontent.com/zojer-studio/prose-obsidian/HEAD/screenshot.png"

    modes: ["dark", "light"]
    about: "Apply a typographic Obsidian theme using IBM Plex for body, headings, and UI, with a mono font for code to keep prose readable. Use a fluid minor-third (1.2) type scale and ~700px measure for comfortable reading. Choose warm neutrals with refined light and dark modes."
}
```
