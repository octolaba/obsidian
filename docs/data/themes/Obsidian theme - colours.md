# COLOURS

COLOURS is an accent-driven minimal theme that derives its whole palette from a single accent through oklch(), keeping tones consistent across light and dark modes. Auto-contrast and optional auto-dark dimming keep text readable, Style Settings adjusts colours, typography and layout, and alternate task checkboxes are available for special items.
