# Comfort Smooth

Comfort Smooth is a dark theme that smooths interface elements for low-contrast reading and writing. Its soft colors and balanced contrast are meant to reduce eye strain and keep notes readable across panes.

![Comfort Smooth screenshot](https://raw.githubusercontent.com/sparklau/comfort-smooth/HEAD/comfort-smooth.png)
