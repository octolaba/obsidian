# Kage

A theme that imitates printed matter: matte surfaces, pressed ink, and a light source anchored outside the frame, so the centre of the page stays dark while the edges glow, the reverse of a camera vignette. Grain is one fixed image rather than screen noise, so it never flickers, shifts or scrolls, and text sits in the darkest area to read like ink pressed into paper. Headings and body are serif, navigation and dates sans, with one orange-brown accent, one-pixel corners and no floating cards. A paper mode mirrors the same specification with an aged-paper base, edge yellowing and multiplied grain, keeping every threshold value and only flipping direction.

A paper mode mirrors the same specification instead of inventing a second look: the base becomes aged paper, the leak becomes edge yellowing, the grain multiplies instead of screening.
