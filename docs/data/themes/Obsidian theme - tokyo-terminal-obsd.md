# tokyo-terminal-obsd

tokyo-terminal turns Obsidian into a neon-lit, retro-futurist terminal, presented in its own recorded text as a high-contrast workspace rather than only a color scheme. It applies crisp cyan on deep purple and near-black backgrounds, with hot pink, sunset orange, gold and deep violet highlights across syntax and interface. The recorded description names Tokyo electric nights and a terminal circa 1984 as its reference points.
