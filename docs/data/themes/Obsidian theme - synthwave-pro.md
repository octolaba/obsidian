# Synthwave Pro

Synthwave Pro is a VaporWave and Retrowave theme with a deep indigo background, warm off-white body text and restrained neon accents on headings, links, focus and syntax highlighting. Retro effects such as neon glow, a perspective grid and CRT scanlines can be toggled, palettes include Outrun, Miami, Tokyo Night and Soft Reading, and it uses monospace headings and neon-bordered code blocks.

![Synthwave Pro screenshot](https://raw.githubusercontent.com/robertobissanti/obsidian-synthwave-pro/HEAD/background.png)
