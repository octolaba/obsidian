# Aether Core

A low-glare workspace built from refined material layers, soft accents and typography aimed at long-form reading, writing, research and coding. Dark and light modes are both available, a Source mode narrows the view for focused editing, and tables, graph view, metadata panels and code blocks share one visual treatment.
