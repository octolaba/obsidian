# Forgotten Golden Sanctuary

A warm parchment interface with antique gold accents in both dark and light modes, aimed at comfortable reading and focused writing. Cinzel and Inter set the typography, while metadata panels, tables, callouts, code blocks, a golden graph view and custom tag badges carry the same archive aesthetic.
