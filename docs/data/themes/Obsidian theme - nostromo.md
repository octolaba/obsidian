# Nostromo

Nostromo styles Obsidian as an 80s retro-futuristic terminal, using the VT323 monospace font, an amber and green palette, scanlines, subtle CRT flicker and glowing text. It adds a persistent terminal status indicator, cyberpunk heading prefixes, cassette-style scrollbars and several retro horizontal rules. The recorded description sums the result up as a starship console look.

![Nostromo screenshot](https://raw.githubusercontent.com/gvorbeck/Nostromo/HEAD/assets/screenshot.png)
