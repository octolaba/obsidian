# Vaporwave Void

Vaporwave Void combines translucent glass-morphism panes over a deep purple-to-black gradient with vivid neon heading colours. Its recorded description states that the theme is dark mode only so the neon typography is preserved, and it lists a neon heading hierarchy, cyber swatches and consistent styling for the file explorer and modals.
