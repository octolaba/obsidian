Zen is a minimalist, distraction-free theme that removes visual clutter and applies soft Gaussian-blur backgrounds. Its recorded description also covers Chinese typography and layout, with tuned spacing, aligned list guides, coloured numbered headings and consistent editor and preview behaviour across devices.
