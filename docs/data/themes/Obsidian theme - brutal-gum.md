# Brutal Gum

Brutal Gum is a Gumroad-inspired minimalist theme with light and dark modes for a clean, modern look. Its own notes describe it as fan-made and in early development, and it is not affiliated with Gumroad.

![Brutal Gum screenshot](https://raw.githubusercontent.com/moyf/obsidian-gumroad-theme/HEAD/screenshot.png)

```cue
theme: {
    name:   "Brutal Gum"
    author: "Moy"
    repo:   "moyf/obsidian-gumroad-theme"
    slug:   "brutal-gum"

    html_url:       "https://community.obsidian.md/themes/brutal-gum"
    github_url:     "https://github.com/moyf/obsidian-gumroad-theme"
    screenshot_url: "https://raw.githubusercontent.com/moyf/obsidian-gumroad-theme/HEAD/screenshot.png"

    modes: ["dark", "light"]
    about: "Apply a Gumroad-inspired minimalist theme to Obsidian for a clean, modern look with light and dark modes. Use with caution — fan-made and in early development, not affiliated with Gumroad."
}
```
