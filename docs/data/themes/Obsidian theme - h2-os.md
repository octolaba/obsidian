# H2 OS

H2 OS is a geometric light interface on a white canvas, with a restrained OnePlus red that appears only as a single-purpose signal. Non-text marks are replaced by a three-shape system of square, circle and triangle, and dividers, bullets, checkmarks and icons are redrawn for desktop and mobile alike. The theme index records light mode only.

![H2 OS screenshot](https://raw.githubusercontent.com/elijahchan2019/obsidian-h2os-theme/HEAD/screenshot.png)
