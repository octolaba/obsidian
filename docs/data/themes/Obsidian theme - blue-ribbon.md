# Blue Ribbon

Blue Ribbon applies a vintage-inspired palette of blues, reds and creams to the reading and writing surface. It offers light and dark modes and lets the note and code block widths be adjusted. Headings, tags and metadata are themed, custom callouts are added, and the recorded description also names mobile refinements and print-friendly notes.

![Blue Ribbon screenshot](https://raw.githubusercontent.com/kaymade/blue-ribbon/HEAD/blue-ribbon-preview.png)
