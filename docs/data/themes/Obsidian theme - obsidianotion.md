# Obsidianotion

Obsidianotion gives Obsidian a Notion-style interface while leaving the native Markdown and linking workflows in place. It uses varied checklist symbols, colorful tags, compact pinned tabs and wide callout color variations, and offers Inter, IBM Plex or iA Writer Quattro as its typeface.

![Obsidianotion screenshot](https://raw.githubusercontent.com/diegoeis/obsidianotion/HEAD/cover.png)
