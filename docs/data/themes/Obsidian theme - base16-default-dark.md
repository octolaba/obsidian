# Base16 Default Dark

Base16 Default Dark is a terminal-style dark interface built on the classic Base16 Default Dark palette, described by its author as brutalist and low-distraction. It keeps interface clutter to a minimum and recommends specific professional fonts for body text, headings and monospaced code in the name of readability for focused research.
