# Sparkling Night

Sparkling Night is a dark, glittering theme with jewel-toned accents and sparkling coloured checkboxes that mark task states such as working, pause or stand-by, stop and to be scheduled. Tables are centered and heading, link and code readability is adjusted for night reading.

![Sparkling Night screenshot](https://raw.githubusercontent.com/isax785/obsidian-sparkling-night/HEAD/img/sparkling_night.png)
