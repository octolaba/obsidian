# KXC Cipher

KXC Cipher is a dark Korthcore Cipher theme built on a teal-and-purple palette with matching VSCode-style syntax highlighting. Headings H1 through H6 are coloured, and the theme styles callouts, tag accents and graph node colours, with teal accents on links, checkboxes and other interactive elements.

![KXC Cipher screenshot](https://raw.githubusercontent.com/kxc-korthcore/obsidian-kxc-cipher/HEAD/screenshot.png)
