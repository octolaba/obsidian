# Everforest Clarity

Tuned for long-form reading of LaTeX-heavy documents mixing CJK and Latin text, with contrast verified against WCAG AA. Inline math has its line height locked to fix spacing, display math scrolls, fonts are Latin-first with raised line height for CJK, and an Everforest dark background is paired with seven highlight colors.

![Everforest Clarity screenshot](https://raw.githubusercontent.com/ziangchen7/obsidian-everforest-clarity/HEAD/screenshot.png)
