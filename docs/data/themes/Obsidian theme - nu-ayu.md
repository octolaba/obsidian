# Nu Ayu

Nu Ayu is a minimal, distraction-free interface with soft rounded surfaces, transparent dividers and a muted text palette. It offers an Ayu-inspired warm light mode and a deep violet dark mode, with mobile-first tweaks, smoother embeds, custom callout and code colors, thin headers and optional full-black mobile backgrounds.
