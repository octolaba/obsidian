# Isinglass

A minimal translucent theme with a frosted-glass treatment in light and dark modes across platforms. Surfaces are kept colourless so that luminance alone conveys depth, with the accent color reserved for highlights and links. Floating panes use a backdrop blur, contrast is held to WCAG AA, and high-contrast and reduced-transparency modes are provided.
