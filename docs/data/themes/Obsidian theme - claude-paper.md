# Claude Paper

Claude Paper is a warm, paper-like theme with clay accents, editorial body text, and matched light and dark modes. It ships English, CJK and code font stacks, six distinct heading levels, responsive layouts, and is pure CSS with no telemetry and no external requests.

![Claude Paper screenshot](https://raw.githubusercontent.com/law-of-cycles/claude-paper-obsidian/HEAD/screenshot.png)
