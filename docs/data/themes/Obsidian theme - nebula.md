# Nebula

A dark theme with cyan and violet accents on a blue-black canvas, plus a light mode using warm turmeric accents on a cool paper background. Sora sets the interface and editor text and JetBrains Mono the code, and reading width and accent colors are adjustable.

![Nebula screenshot](https://raw.githubusercontent.com/devmandalia/Nebula/HEAD/screenshots/dark-kanban.png)

```cue
    name:   "Nebula"

}
```
