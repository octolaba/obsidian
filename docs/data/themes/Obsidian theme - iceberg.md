# Iceberg

Iceberg is a dark color scheme for Obsidian inspired by iceberg.vim. The recorded description holds calm contrast and subtle accent colors across the editor, code blocks and interface to improve readability during long writing sessions, and the theme index lists dark mode only.

![Iceberg screenshot](https://raw.githubusercontent.com/izumin5210/obsidian-iceberg/HEAD/screenshot.png)

```cue
theme: {
    name:   "Iceberg"
    author: "izumin5210"
    repo:   "izumin5210/obsidian-iceberg"
    slug:   "iceberg"

    html_url:       "https://community.obsidian.md/themes/iceberg"
    github_url:     "https://github.com/izumin5210/obsidian-iceberg"
    screenshot_url: "https://raw.githubusercontent.com/izumin5210/obsidian-iceberg/HEAD/screenshot.png"

    modes: ["dark"]
    about: "Apply a balanced dark color scheme to Obsidian inspired by iceberg.vim. Maintain calm contrast and subtle accent colors across the editor, code blocks, and UI to improve readability during long writing sessions."
}
```
