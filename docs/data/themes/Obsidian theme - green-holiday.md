# Green Holiday

Green Holiday applies a lime-green palette with a dot-grid gradient background that shifts from soft mint at the top to bright green at the bottom, so each note carries a distinct visual identity. Both light and dark modes are supported with matched color scales. The recorded description also lists GitHub-style inline code on a semi-transparent white background, dark code blocks with syntax highlighting, fluorescent green highlights, pill-style tags kept consistent in body text and in Properties, and heading and paragraph spacing tuned for reading.
