# Zenburn

Zenburn brings the classic Zenburn colour palette, a low-contrast Vim-inspired scheme, to Obsidian as a dark theme. Its recorded description names Inter UI and Inconsolata as the fonts to pair it with for typography and code rendering.

![Zenburn screenshot](https://raw.githubusercontent.com/danyim/obsidian-zenburn/HEAD/screen.png)

```cue
theme: {
    name:   "Zenburn"
    author: "danyim"
    repo:   "danyim/obsidian-zenburn"
    slug:   "zenburn"

    html_url:       "https://community.obsidian.md/themes/zenburn"
    github_url:     "https://github.com/danyim/obsidian-zenburn"
    screenshot_url: "https://raw.githubusercontent.com/danyim/obsidian-zenburn/HEAD/screen.png"

    modes: ["dark"]
    about: "Apply a low-contrast, Vim-inspired dark theme that brings the classic Zenburn color palette to Obsidian. Pair with Inter UI and Inconsolata for best typography and code rendering."
}
```
