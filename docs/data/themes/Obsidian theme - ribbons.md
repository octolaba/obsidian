# Ribbons

Ribbons is a modular theme built around decorative ribbon callouts, with styling for markdown, the editor, code blocks, embeds, tags, tasks and UI components. Its sources are organised SCSS, which can be edited to change variables, layouts and feature-specific styles.

![Ribbons screenshot](https://raw.githubusercontent.com/ddspog/obsidian-ribbons-theme/HEAD/screenshot.png)

```cue
theme: {
    name:   "Ribbons"
    author: "ddspog"
    repo:   "ddspog/obsidian-ribbons-theme"
    slug:   "ribbons"

    html_url:       "https://community.obsidian.md/themes/ribbons"
    github_url:     "https://github.com/ddspog/obsidian-ribbons-theme"
    screenshot_url: "https://raw.githubusercontent.com/ddspog/obsidian-ribbons-theme/HEAD/screenshot.png"

    modes: ["dark", "light"]
    about: "Apply a modular, customizable visual style with decorative ribbon callouts, tailored markdown and editor styling, and themed support for code blocks, embeds, tags, tasks, and UI components. Modify the organized SCSS sources to tweak variables, layouts, and feature-specific styles for a personalized look."
}
```
