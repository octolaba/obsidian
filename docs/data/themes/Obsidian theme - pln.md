# PLN

PLN pairs a Nord-inspired color palette with a compact UI, unique table styles and multi-row tabs. Style Settings options cover smaller fonts, flipped stacked titles, hidden icons and scrollbars, a coloured file explorer and simplified link and embed visuals.
