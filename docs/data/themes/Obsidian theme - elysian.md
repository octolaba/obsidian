# Elysian

Elysian is a Disco Elysium inspired interface with embedded backgrounds, film-like markings and a grainy texture that its recorded description compares to a rolling film as the page scrolls. It adds inline titles, colorful text formatting and a terminal-style interface font, and supports both light and dark modes.

![Elysian screenshot](https://raw.githubusercontent.com/matothetomato/Elysian/HEAD/cover.png)
