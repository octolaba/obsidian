# Ink

Ink is a monochrome color scheme optimized for e-ink and e-paper screens, with high-contrast interface and text styling. The recorded description states that a dark theme is deliberately omitted because it is not suited to e-ink displays, and the theme index accordingly records light mode only.

![Ink screenshot](https://raw.githubusercontent.com/harmtemolder/obsidian-ink/HEAD/screenshot.png)

```cue
theme: {
    name:   "Ink"
    author: "harmtemolder"
    repo:   "harmtemolder/obsidian-ink"
    slug:   "ink"

    html_url:       "https://community.obsidian.md/themes/ink"
    github_url:     "https://github.com/harmtemolder/obsidian-ink"
    screenshot_url: "https://raw.githubusercontent.com/harmtemolder/obsidian-ink/HEAD/screenshot.png"

}
```
