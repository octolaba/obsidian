# Olivier’s Theme

Olivier's Theme aims at a calm, paper-like writing environment with clear typography and tuned spacing, and it lays out Reading, Live Preview and Source modes distinctly to keep long notes readable. It offers cascading light and dark palettes, optional paper textures, revised styles for lists, tables and images, and a discreet status bar in the lower right.
