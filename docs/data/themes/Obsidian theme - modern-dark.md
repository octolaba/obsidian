# Modern Dark

Modern Dark is a dark interface whose recorded description names Adwaita and VSCode as its inspirations and states that only dark mode is supported. A bundled icon font supplies consistent folder and file icons across the interface.

![Modern Dark screenshot](https://raw.githubusercontent.com/roberts-code/obsidian-theme-modern-dark/HEAD/screenshot.png)
