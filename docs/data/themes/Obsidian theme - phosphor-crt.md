# Phosphor CRT

Phosphor CRT recreates a green-phosphor CRT aesthetic with monospace text, chunky uppercase headings prefixed like an Applesoft BASIC prompt, and a blinking block cursor timed to the Apple II. Its light mode is a paper terminal in warm cream, with flat printed text, terminal-style selections and hard-edged, zero-radius UI.

![Phosphor CRT screenshot](https://raw.githubusercontent.com/jaminbrazil2/phosphor-crt/HEAD/screenshot.png)
