# Comfort Dark

Comfort Dark is a dark theme with soft rounded corners and accent colors kept consistent with the Kanban and Jira issue plugins. Code blocks are left unwrapped in Read and Preview modes, and table font sizing is preserved after Obsidian updates.

![Comfort Dark screenshot](https://raw.githubusercontent.com/ooopz/obsidianmd-theme-comfort-dark/HEAD/screenshot.png)
