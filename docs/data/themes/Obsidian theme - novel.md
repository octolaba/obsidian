# Novel

Novel builds a paper-like reading and writing environment from soft parchment tones, serif typography and a centered max-width layout for long-form work. It offers full dark and light modes, embedded Merriweather and JetBrains Mono fonts, styled callouts, clean tables and native task list styling.

![Novel screenshot](https://raw.githubusercontent.com/toniim/obsidian-novel-theme/HEAD/screenshot.png)
