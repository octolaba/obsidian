# TTRPG - Rathgar Gold

TTRPG - Rathgar Gold is a gold-and-parchment theme for running a tabletop campaign out of an Obsidian vault, in dark or light mode. The recorded description says that any note can become a dashboard of uniform card grids and glass panels with an optional full-bleed backdrop photo and no manual CSS, and that Canvas boards get matching backgrounds and crimson card accents. It also lists a gold glow frame for Fantasy Statblocks, die-shaped buttons for Dice Roller, matching gold accents for Kanban, Buttons and Dataview, all nine native callout types restyled, and a floating infobox for character and item reference boxes.
