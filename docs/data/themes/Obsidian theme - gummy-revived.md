# Gummy-Revived

Gummy-Revived restates the Gummy aesthetic as a minimalist theme pairing plain interface elements with vivid gradients. Peace Sans is used for titles and Space Grotesk for body text, and the recorded description says interface accents follow the color the reader chooses.

![Gummy-Revived screenshot](https://raw.githubusercontent.com/winnerwind/gummy-revived/HEAD/screenshot.png)
