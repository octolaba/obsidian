# calm nights

Calm nights applies a simple, darker interface with almost no layout or styling changes. It preserves the default Obsidian look and behavior while lowering brightness and contrast for comfortable low-light reading.

![calm nights screenshot](https://raw.githubusercontent.com/yejun-exe/calm-nights/HEAD/theme-sample-ss.png)
