# GitHub Flavored Markdown

The GitHub Flavored Markdown theme styles Obsidian toward GitHub's own rendering, supporting light and dark modes and GFM alerts. Its README records the theme as a fork of obsidian-theme-github that keeps the Kanban styling, removes some custom settings and moves closer to a GFM experience. Theme settings are exposed through the Style Settings plugin and currently cover a Kanban style toggle and color-blind-friendly color scheme variants.

![GitHub Flavored Markdown screenshot](https://raw.githubusercontent.com/tofrankie/obsidian-gfm-theme/HEAD/images/banner.png)

```cue
theme: {
    name:   "GitHub Flavored Markdown"
    author: "Frankie"
    repo:   "tofrankie/obsidian-gfm-theme"
    slug:   "github-flavored-markdown"

    html_url:       "https://community.obsidian.md/themes/github-flavored-markdown"
    github_url:     "https://github.com/tofrankie/obsidian-gfm-theme"
    screenshot_url: "https://raw.githubusercontent.com/tofrankie/obsidian-gfm-theme/HEAD/images/banner.png"

    modes: ["dark", "light"]
}
```
