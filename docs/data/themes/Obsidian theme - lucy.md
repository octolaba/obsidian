# Lucy

Lucy is a Notion-inspired layout with auto-hiding titles and low-contrast Markdown markers, aimed at a calm, distraction-free writing space. It draws edge-to-edge H1 accent lines, borders H2s, connects blockquotes, cycles bullets through three levels and ships tailored light and dark color palettes.
