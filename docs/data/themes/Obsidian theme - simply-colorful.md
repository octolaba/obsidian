# Simply Colorful

Simply Colorful applies vivid, customizable accent colours and animated, colourful headings in both Live Preview and Reading mode. It covers light and dark modes on desktop and mobile, handles multiple window frames and pane styles, and states compatibility with core and popular community plugins and with Style Settings.

![Simply Colorful screenshot](https://raw.githubusercontent.com/lorenzopegorari/SimplyColorful/HEAD/preview.png)
