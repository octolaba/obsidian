# Universitario

Universitario lets an accent colour and a brightness level be chosen to adjust how readable the interface is. Headings and callouts pick up the matching colour, and nested numbering such as 1.1.1 is applied so hierarchical outlines stay clear.

![Universitario screenshot](https://raw.githubusercontent.com/wulflo/obsidian-3Sumaq/HEAD/cover.png)

```cue
theme: {
    name:   "Universitario"
    author: "wulflo"
    repo:   "wulflo/obsidian-3Sumaq"
    slug:   "universitario"

    html_url:       "https://community.obsidian.md/themes/universitario"
    github_url:     "https://github.com/wulflo/obsidian-3Sumaq"
    screenshot_url: "https://raw.githubusercontent.com/wulflo/obsidian-3Sumaq/HEAD/cover.png"

    modes: ["dark", "light"]
    about: "Pick an accent color and adjust brightness to create a personalized, readable Obsidian interface. Apply color-matched headings and callouts for consistent, vibrant notes. Use nested numbering (1.1, 1.1.1…) to build clear hierarchical outlines."
}
```
