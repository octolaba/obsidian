# TerraFlow

TerraFlow offers seven seasonal light and dark palettes together with a readable six-colour heading hierarchy. Subtle glass panel effects, smooth animations and refined typography are included, along with an optional monochrome mode, and appearance is adjustable through style settings.

![TerraFlow screenshot](https://raw.githubusercontent.com/dubefab/obsidian-TerraFlow/HEAD/Terraflow-cover.png)

```cue
theme: {
    name:   "TerraFlow"
    author: "dubefab"
    repo:   "dubefab/obsidian-TerraFlow"
    slug:   "terraflow"

    html_url:       "https://community.obsidian.md/themes/terraflow"
    github_url:     "https://github.com/dubefab/obsidian-TerraFlow"
    screenshot_url: "https://raw.githubusercontent.com/dubefab/obsidian-TerraFlow/HEAD/Terraflow-cover.png"

    modes: ["dark", "light"]
    about: "Bring nature's palette to Obsidian with seven seasonal light and dark palettes and a readable six-color heading hierarchy. Apply subtle glass panel effects, smooth animations, refined typography, an optional monochrome mode, and tweak appearance via style settings."
}
```
