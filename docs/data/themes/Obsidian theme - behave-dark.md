# Behave dark

Behave dark is a dark theme its recorded description presents as eye-friendly for note-taking in low light. It carries the Behave look that also exists in FreeCAD and KiCAD, so the same appearance can be kept across those tools.

![Behave dark screenshot](https://raw.githubusercontent.com/chrismettal/Obsidian-Behave-dark/HEAD/Screenshot.png)

```cue
theme: {
    name:   "Behave dark"
    author: "chrismettal"
    repo:   "chrismettal/Obsidian-Behave-dark"
    slug:   "behave-dark"

    html_url:       "https://community.obsidian.md/themes/behave-dark"
    github_url:     "https://github.com/chrismettal/Obsidian-Behave-dark"
    screenshot_url: "https://raw.githubusercontent.com/chrismettal/Obsidian-Behave-dark/HEAD/Screenshot.png"

    modes: ["dark"]
    about: "Apply an eye-friendly dark theme to Obsidian for comfortable low-light note-taking. Match visuals across tools by using the Behave look found in FreeCAD and KiCAD for a cohesive workflow."
}
```
