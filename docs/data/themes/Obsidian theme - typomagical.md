# Typomagical

Typomagical styles notes around refined typography, adding magazine-style quote callouts and responsive text sizing that adapts to desktop, mobile and zoom. It ships light, dark and high-contrast modes, a ligature toggle, and extra colour schemes selectable through Style Settings. The recorded description presents its CSS as handcrafted and minimal so that overrides stay easy.

![Typomagical screenshot](https://raw.githubusercontent.com/hungsu/typomagical-obsidian/HEAD/Typomagical-split.jpg)
