# Lapfly

Lapfly takes a GitHub-dark-inspired aesthetic and adds electric-blue accents with a racing-lime highlight. Dark and light modes are both available, and lime speed-line touches appear on active tabs, checked task boxes, blockquote rules and link-hover underlines.

![Lapfly screenshot](https://raw.githubusercontent.com/johncattrall/obsidian-lapfly/HEAD/screenshot/lapfly-screenshot-dark.png)
