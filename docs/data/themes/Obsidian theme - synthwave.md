# SynthWave

SynthWave applies 1980s neon aesthetics with bold synthwave colours, neon gradients and a dark backdrop. Editor panes, code blocks and syntax highlighting use high-contrast pink, purple and cyan accents, and only a dark mode is recorded.

![SynthWave screenshot](https://raw.githubusercontent.com/marcoluzi/obsidian-synthwave/HEAD/screenshot.jpeg)

```cue
theme: {
    name:   "SynthWave"
    author: "marcoluzi"
    repo:   "marcoluzi/obsidian-synthwave"
    slug:   "synthwave"

    html_url:       "https://community.obsidian.md/themes/synthwave"
    github_url:     "https://github.com/marcoluzi/obsidian-synthwave"
    screenshot_url: "https://raw.githubusercontent.com/marcoluzi/obsidian-synthwave/HEAD/screenshot.jpeg"

    modes: ["dark"]
    about: "Bring 80s neon aesthetics to Obsidian with bold synthwave colors, neon gradients and a dark backdrop. Style editor panes, code blocks, and syntax highlighting with high-contrast pink, purple, and cyan accents for a retro, cinematic vibe."
}
```
