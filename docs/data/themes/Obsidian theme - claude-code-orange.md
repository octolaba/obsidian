# Claude Code Orange

Claude Code Orange recreates the mobile app aesthetic of Claude Code with warm cream and charcoal surfaces, a coral accent, and a Styrene-style grotesque interface in light and dark modes. It adds an optional serif reading mode, monospace code in framed code cards, pill inline code, and a warm syntax palette.
