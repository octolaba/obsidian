# Carnelian

Carnelian applies a warm carnelian-orange palette across the Obsidian interface and editor, optimized for dark mode. It preserves contrast and readability in notes, panels and code blocks, and supports Palatinate theme snippets for extra styling.

![Carnelian screenshot](https://raw.githubusercontent.com/gracejoseph1236/obsidian-carnelian/HEAD/example.png)

```cue
theme: {
    name:   "Carnelian"
    author: "gracejoseph1236"
    repo:   "gracejoseph1236/obsidian-carnelian"
    slug:   "carnelian"

    html_url:       "https://community.obsidian.md/themes/carnelian"
    github_url:     "https://github.com/gracejoseph1236/obsidian-carnelian"
    screenshot_url: "https://raw.githubusercontent.com/gracejoseph1236/obsidian-carnelian/HEAD/example.png"

    modes:  ["dark"]
    legacy: true
    about:  "Apply a warm carnelian-orange color palette across Obsidian’s UI and editor, optimized for dark mode. Preserve contrast and readability for notes, panels, and code blocks while supporting Palatinate theme snippets for extra styling."
}
```
