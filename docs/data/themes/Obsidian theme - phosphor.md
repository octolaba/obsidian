# Phosphor

Phosphor is built on a warm-to-cool spectral palette whose amber-to-sage headings are described as guiding visual flow. Its typography targets long-form reading: an 18px base, a 1.72 line-height, a measure of about 68 characters and a perfect fourth scale, in dark and light modes. It adds more than 20 custom task checkboxes and is written in pure CSS with a serif body and JetBrains Mono for code.

![Phosphor screenshot](https://raw.githubusercontent.com/johanviberg/obsidian-phosphor/HEAD/screenshot.png)
