# Mado Miniflow

Mado Miniflow is a minimalist, center-focused layout with a subtle wave background meant to keep attention on the notes. Colors, basic layout and markdown styling are customizable through style settings, and included CSS classes produce a pseudo file-explorer and specially styled tables.

![Mado Miniflow screenshot](https://raw.githubusercontent.com/hydescarf/Obsidian-Theme-Mado-Miniflow/HEAD/img/store-cover.png)
