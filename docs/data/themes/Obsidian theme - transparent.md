# Transparent

Transparent is a lightweight, minimal transparent theme with a soft color palette, offering light and dark modes together with mobile support. The recorded description says that the background image is set through the Style Settings plugin and that the native accent color can be adapted, and it mentions subtle animations as part of the result.
