# Dayspring

Dayspring is a rounded color theme built on Obsidian variables with minimal custom CSS, and it includes the Crimson Pro and Figtree fonts. H6 headings are placed beside paragraphs to act as unobtrusive verse or side numbers, working on mobile and in embeds, frontmatter is hidden in preview, and a CSS class enables an alternative serif, darker note style.

![Dayspring screenshot](https://raw.githubusercontent.com/erykwalder/dayspring-theme/HEAD/screenshots/thumbnail.png)
