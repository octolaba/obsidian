# Papyrus Nox

Papyrus Nox builds a dark aged-paper surface entirely in CSS, layering SVG turbulence, fiber lines, subtle stains and a deep vignette without image files. Headings are set in earthy colors with letterpress shadows, body text is narrowed for screen reading, and the sidebar is dark and flat.

![Papyrus Nox screenshot](https://raw.githubusercontent.com/bkindler/papyrus-nox/HEAD/screenshot.png)
