# Arcadia

Arcadia is a OneNote-inspired theme shipping 34 colour schemes, 16 dark and 18 light, alongside sticky notes, alternate checkboxes, paper styles, custom callouts and reworked code blocks. Its recorded description counts more than 55 Style Settings options covering typography, icons, tag colours, rainbow folders, progress bars, cards and media embedding.
