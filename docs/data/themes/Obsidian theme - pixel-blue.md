# pixel-blue

A soft blue-and-pink Y2K look with crisp pixel-grid detailing and matching light and dark modes. Tabs, navigation, prompts, menus, settings and the status bar are styled together, with high-contrast notices. All assets are local, so nothing is loaded externally.
