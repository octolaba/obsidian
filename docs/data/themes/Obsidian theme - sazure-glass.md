# SAzure Glass

SAzure Glass is a blue glass theme with bold Willemstadt-style headings and a navy-and-neon note pane meant to give clear visual hierarchy. Green accents drawn from Hack The Box and reworked callout and heading bars complete the interface, and only a dark mode is recorded.
