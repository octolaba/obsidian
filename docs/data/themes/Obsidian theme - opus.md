# Opus

Opus builds its interface on a single amber accent for structure and the active element, with teal for a good state and clay for a bad one, used the same way across callouts, tasks, syntax, canvas and boards. Headings are monospace on a fixed scale and carry a tonally leveled tint ramp, one hue per level at matched lightness, which can be toggled off for a monochrome ladder. Three flavors are offered — Prima Materia, Nigredo and Citrinitas — and Canvas and Kanban are rebuilt for readable cards, groups and connector labels at overview zoom. Mobile is tuned and Style Settings exposes the options.
