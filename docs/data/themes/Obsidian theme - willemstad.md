# Willemstad

Willemstad is a minimalist, work-focused theme configured through responsive Style Settings with a RealDisplay preview. Its recorded description names millions of colour permutations, a Focused Mode, callout types covering image grids, slide galleries and infoboxes, block widths, LaTeX and Cornell CSS classes, and alternative checkboxes.
