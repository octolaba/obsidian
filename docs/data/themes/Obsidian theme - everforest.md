# Everforest

Everforest applies a green-based Everforest palette with warm, soft contrast that its recorded description credits with reducing eye strain. Light and dark modes are both supported, together with semantic and italic syntax highlighting and styling across a broad range of file types, and the description states that the theme remains compatible with redshift and f.lux. Customization is recorded as covering the Medium Material modes.

![Everforest screenshot](https://raw.githubusercontent.com/0xglitchbyte/obsidian_everforest/HEAD/dark_v2.png)
