# Serenity

Serenity is a minimal, distraction-free interface meant to keep attention on the words. It adds customizable checklists and callouts with dozens of checkbox states, speech bubbles rendered with bold titles and inline images, and custom HTML attributes used for hover comment tooltips.

![Serenity screenshot](https://raw.githubusercontent.com/bluemoondragon07/Obsidian-Serenity/HEAD/cover-small.png)
