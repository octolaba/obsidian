# Brainhack

Brainhack is a minimal, distraction-free theme that uses the accent color as its main point of customization. Its styling stays consistent in both light and dark modes.

![Brainhack screenshot](https://raw.githubusercontent.com/spekulucius/obsidian-brainhack/HEAD/preview.png)

```cue
theme: {
    name:   "Brainhack"
    author: "spekulucius"
    repo:   "spekulucius/obsidian-brainhack"
    slug:   "brainhack"

    html_url:       "https://community.obsidian.md/themes/brainhack"
    github_url:     "https://github.com/spekulucius/obsidian-brainhack"
    screenshot_url: "https://raw.githubusercontent.com/spekulucius/obsidian-brainhack/HEAD/preview.png"

    modes: ["light", "dark"]
    about: "Apply a minimal, distraction-free theme that uses the accent color for quick visual customization. Maintain consistent styling in both light and dark modes."
}
```
