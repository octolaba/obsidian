# Clawdia

Clawdia gives a vault a warm, gothic candlelit look with creamy ink backgrounds, ember-orange accents and serif reading fonts. Its matched dark and light modes come with full syntax highlighting, themed callouts, custom graph node colors, and styled canvas and interface elements.
