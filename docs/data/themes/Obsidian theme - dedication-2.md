# Dedication 2

Dedication 2 is a customizable dark theme with sci-fi, fantasy and cinematic color presets and matching light variants. Seven presets and six typography options are available, alongside colored heading bars, an animated startup pendulum, styled tables and tooltips, and a colorized calendar.
