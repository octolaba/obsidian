# Ultra Lobster

Ultra Lobster gives Obsidian a glassmorphism and card-style layout, so a layered, frosted-glass interface lets a custom wallpaper show through. The recorded description counts dozens of subthemes, among them the adaptive Chameleon and the frosted Abaddon Glass, and an optional halo gradient animation that pulses slowly behind the workspace.
