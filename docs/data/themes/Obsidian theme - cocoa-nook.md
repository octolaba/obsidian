# Cocoa Nook

Cocoa Nook is a warm-toned light theme meant to reduce visual fatigue while leaving note formatting intact. Its interface changes are minimal and non-disruptive, so it can be enabled or disabled at any time.

![Cocoa Nook screenshot](https://raw.githubusercontent.com/tttt-k/obsidian-cocoa-nook/HEAD/images/obsidian-cocoa-nook.png)

```cue
theme: {
    name:   "Cocoa Nook"
    author: "ttt"
    repo:   "tttt-k/obsidian-cocoa-nook"
    slug:   "cocoa-nook"

    html_url:       "https://community.obsidian.md/themes/cocoa-nook"
    github_url:     "https://github.com/tttt-k/obsidian-cocoa-nook"
    screenshot_url: "https://raw.githubusercontent.com/tttt-k/obsidian-cocoa-nook/HEAD/images/obsidian-cocoa-nook.png"

    modes: ["dark", "light"]
    about: "Apply a warm-toned, eye-friendly light theme that reduces visual fatigue while keeping note formatting intact. Enable or disable at any time with minimal, non-disruptive UI changes."
}
```
