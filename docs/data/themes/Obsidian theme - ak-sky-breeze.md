# AK Sky Breeze

AK Sky Breeze aims at a spacious, breathable interface, with soft borders, a simplified palette and generous spacing intended for long reading and quick skimming. It keeps fonts large and readable and adds only subtle colour accents, so clarity is preserved while the interface gains some personality.
