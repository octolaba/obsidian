# Night Owl Native

Night Owl Native pairs an eye-friendly deep-blue dark mode with a polished high-contrast light mode, aimed at late-night writing and daytime readability. Glassmorphic sidebars, neon-glow headings, neo-brutalist borders, typography and content line width are all customizable.
