# Tokyo Night Storm

Tokyo Night Storm applies the Tokyo Night Storm dark color scheme to Obsidian, described as cool blues and deep grays drawn from the tokyonight palette. The recorded description says that the interface, the editor and code blocks are all restyled for a consistent, high-contrast night aesthetic.
