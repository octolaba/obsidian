# Improved Potato

Improved Potato exposes headers, dividers, base colors, line-number styling and markers as configurable options in the Style Settings plugin. The recorded description adds fancy code blocks, per-header Mermaid styling and a set of custom callouts with four selectable icons named c1 to c4, alongside predefined info, text, warn and mt styles.

![Improved Potato screenshot](https://raw.githubusercontent.com/dmeurer/improved-potato/HEAD/images/image2.png)
