# Sacred Geometry Systems

Sacred Geometry Systems offers dark and light palettes built on gold, copper, deep indigo and signal-cyan accents. Its stated focus is mapping complex vaults and Canvas systems, using luminous cards, focused nodes and meaningful edge colours so that roles, flow and hierarchy stay visible.
