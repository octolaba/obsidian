# Nightly Wolf

Nightly Wolf is a minimal, eye-friendly dark purple theme meant to hold focus during late-night writing and extended research sessions. It includes a translucent sidebar, a custom vault logo and reddish indentation guides that add depth and clarify structure in the editor and file explorer.
