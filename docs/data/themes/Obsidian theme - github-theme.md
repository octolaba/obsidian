# GitHub Theme

GitHub Theme applies a GitHub-inspired look to Obsidian, including kanban boards styled after GitHub Projects, GitHub-style callouts, inline code blocks and interface buttons. The Style Settings plugin is used to customize header colors, toggle the kanban and callout styles and choose colorblind-friendly variants.

![GitHub Theme screenshot](https://raw.githubusercontent.com/krios2146/obsidian-theme-github/HEAD/imgs/thumbnail.png)

```cue
theme: {
    name:   "GitHub Theme"
    author: "krios2146"
    repo:   "krios2146/obsidian-theme-github"
    slug:   "github-theme"

    html_url:       "https://community.obsidian.md/themes/github-theme"
    github_url:     "https://github.com/krios2146/obsidian-theme-github"
    screenshot_url: "https://raw.githubusercontent.com/krios2146/obsidian-theme-github/HEAD/imgs/thumbnail.png"

    modes: ["dark", "light"]
    about: "Apply a GitHub-inspired look to Obsidian with GitHub Projects–style kanban boards, GitHub-style callouts, inline code blocks, and UI buttons. Customize header colors, toggle kanban and callout styles, and choose colorblind-friendly variants via the Style Settings plugin."
}
```
