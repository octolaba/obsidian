# SALEM

SALEM is a dark theme with adjusted UI spacing, minimal borderless canvas cards and low-light styling. It adds CENTER and ListGrid callouts, the first to center text and the second to handle Dataview lists, plus folder icons and coloured tags for visual organization.

![SALEM screenshot](https://raw.githubusercontent.com/salemelatar/salem-obsidian-theme/HEAD/screenshot.png)
