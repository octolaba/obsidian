# Feather

Feather gives Obsidian an airy look with matching dark and light palettes, Things 2 style checkboxes and refined code blocks with syntax highlighting. Typography, highlighter and block-quote colors are adjusted through the Style Settings plugin. The theme index records dark mode only, although the recorded description names both palettes.

![Feather screenshot](https://raw.githubusercontent.com/zfmohammed/obsidian-feather/HEAD/assets/Screenshot.png)

```cue

    name:   "Feather"
    author: "zfmohammed"
    repo:   "zfmohammed/obsidian-feather"

}
```
