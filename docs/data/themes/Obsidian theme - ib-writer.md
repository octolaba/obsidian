# iB Writer

iB Writer applies iA Writer inspired styling for a clean, minimal writing layout. Its recorded description singles out one behavior in particular, the removal of list indicators in preview mode, so lists are presented without extra markers.

![iB Writer screenshot](https://raw.githubusercontent.com/whereiswhere/iB-Writer/HEAD/store-screenshot.png)
