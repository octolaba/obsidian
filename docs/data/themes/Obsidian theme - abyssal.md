# Abyssal

Abyssal targets a calmer reading and writing surface through roomy vertical rhythm, asymmetrical spacing and a heading line-height of its own, together with muted colours the description calls accessible and reworked highlights, lists, tables and front matter. It uses system fonts out of the box and covers light, dark and translucent modes. The Style Settings plugin adds colourful headings and a larger line height on top of that.

![Abyssal screenshot](https://raw.githubusercontent.com/tazpellegrini/abyssalobsidian/HEAD/abyssal-thumbnail.png)

```cue
theme: {
    name:   "Abyssal"
    author: "tazpellegrini"
    repo:   "tazpellegrini/abyssalobsidian"
    slug:   "abyssal"

    html_url:       "https://community.obsidian.md/themes/abyssal"
    github_url:     "https://github.com/tazpellegrini/abyssalobsidian"
    screenshot_url: "https://raw.githubusercontent.com/tazpellegrini/abyssalobsidian/HEAD/abyssal-thumbnail.png"

    modes: ["dark", "light"]
    about: "Create a calmer reading and writing environment with roomy vertical rhythm, asymmetrical spacing, bespoke heading line-height, muted accessible colors, and polished styling for highlights, lists, tables, and front-matter. Use system fonts out-of-the-box across light/dark and translucent modes, and enable Style Settings to add colorful headings and larger line height."
}
```
