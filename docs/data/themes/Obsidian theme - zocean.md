# Zocean

Zocean is a calm, paper-like theme with generous whitespace, soft dark text and a friendly blue accent applied to callouts, code blocks, tables, checkboxes and headings. Its recorded description names a centered 708px reading column, Inter and system fonts, red pill inline code, soft-gray code blocks and a quiet sidebar, tabs and scrollbars, with light and dark modes supported.
