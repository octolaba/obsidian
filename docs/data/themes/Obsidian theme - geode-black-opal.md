# Geode Black Opal

A theme drawn from black opal crystals and underground mineral formations, pairing a dark interface with a soft light mode and contrast tuned for long-form reading. Crystal-inspired callouts, readable tables, soft code blocks, metadata panels, custom tags, task styling, graph view and canvas are styled together, and layouts respond to desktop and mobile.
