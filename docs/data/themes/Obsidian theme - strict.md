# Strict

Strict is a compact dark theme with pointed corners, disabled animations, reduced indents and smaller headers and tabs. Body text is justified, code blocks follow a darker VS Code styling with decorated line numbers, and it adds dark input highlights, heading borders and capped image heights.

![Strict screenshot](https://raw.githubusercontent.com/nikolai2038/strict-obsidian-theme/HEAD/screenshot_edit_mode.png)
