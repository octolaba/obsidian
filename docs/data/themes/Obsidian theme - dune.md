# Dune

Dune styles Obsidian with warm daylight palettes of wood, sand and rose and cool nighttime palettes of dusk, midnight and black, with flat tones that can be customized. It adds interface refinements and Mermaid styling for a clutter-free workspace, and its own notes point to a Dune Gold edition for extra pages and plugin tweaks.

![Dune screenshot](https://raw.githubusercontent.com/jopp-gh/Obsidian-Dune84/HEAD/Dune-Obsidian.jpg)

```cue
theme: {
    name:   "Dune"
    author: "jopp-gh"
    repo:   "jopp-gh/Obsidian-Dune84"
    slug:   "dune"

    html_url:       "https://community.obsidian.md/themes/dune"
    github_url:     "https://github.com/jopp-gh/Obsidian-Dune84"
    screenshot_url: "https://raw.githubusercontent.com/jopp-gh/Obsidian-Dune84/HEAD/Dune-Obsidian.jpg"

    modes: ["dark", "light"]
    about: "Apply Dune to style Obsidian with warm daylight (wood, sand, rosé) and cool nighttime (dusk, midnight, black) palettes while customizing flat tones. Use UI refinements and Mermaid styling for a cleaner, clutter-free workspace; access extra pages and plugin tweaks in Dune Gold."
}
```
