# Material Ocean

Material Ocean is a navy-blue dark theme with pastel highlights that refines spacing, typography and editor layout for both mobile and desktop. Long code lines can scroll horizontally, and code blocks are scrollable in reading mode. The theme also uses rounded images, underlined headings, circular checkboxes and refined Lucide icons.

![Material Ocean screenshot](https://raw.githubusercontent.com/dragonwocky/obsidian-material-ocean/HEAD/thumbnail.png)
