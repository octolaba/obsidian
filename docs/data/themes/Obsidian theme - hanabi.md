# Hanabi

Hanabi is a high-contrast, dark-first theme family with matching light aliases shared across terminals, editors and Obsidian. The recorded description names VS Code, iTerm2, Windows Terminal, tmux and Vim or Neovim as the other supported targets, all drawing on one palette for consistent accents and color harmony.
