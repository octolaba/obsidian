# OLED.Black

OLED.Black is a pure-black, minimalist interface described as optimized for OLED screens, where the stated aim is reduced battery draw and glare. High-contrast typography and subtle spacing are combined, and UI elements stay legible while true black pixels are maximized. The battery claim belongs to the description; nothing here measures it.
