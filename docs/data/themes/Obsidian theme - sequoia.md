# Sequoia

Sequoia is a minimal theme with a clean colour palette and coordinated Moonlight light and dark styles. Monochrome and retro variants ship as CSS snippets that change the visual tone.

![Sequoia screenshot](https://raw.githubusercontent.com/michael-andreuzza/sequoia-obsidian/HEAD/screenshot.png)

```cue
theme: {
    name:   "Sequoia"
    author: "Micheal Andreuzza"
    repo:   "michael-andreuzza/sequoia-obsidian"
    slug:   "sequoia"

    html_url:       "https://community.obsidian.md/themes/sequoia"
    github_url:     "https://github.com/michael-andreuzza/sequoia-obsidian"
    screenshot_url: "https://raw.githubusercontent.com/michael-andreuzza/sequoia-obsidian/HEAD/screenshot.png"

    modes: ["dark", "light"]
    about: "Apply an elegant, minimal theme with a clean color palette and coordinated Moonlight light and dark styles. Switch to monochrome or retro variants as CSS snippets to change the visual tone."
}
```
