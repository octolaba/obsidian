# Gruber Darker

Gruber Darker ports the Gruber Darker palette to Obsidian with deep blacks, warm accents and a warm-light fallback. The recorded description lists syntax highlighting, distinct colors for headings from H1 to H6, and styling for the graph, canvas, Mermaid, PDF, callouts and tables, with Style Settings available for offline customization.
