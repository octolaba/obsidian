# Al Dente

Al Dente is a simple, minimal theme built on warm colours, clean alignment and reduced visual clutter. Fonts can be changed through its theme variables. Its recorded description marks the light variant as the more complete one and the dark variant as experimental, and states that no further maintenance is expected.

![Al Dente screenshot](https://raw.githubusercontent.com/chad-bennett/al-dente-obsidian-theme/HEAD/aldente-screenshot.png)
