# Synthwave '84

This theme ports the Synthwave '84 color scheme to Obsidian. Dark backgrounds are combined with purple and hot-pink accents across the editor, panes and syntax highlighting for a retro look.

![Synthwave '84 screenshot](https://raw.githubusercontent.com/g2jose/synthwave-84-obsidian-theme/HEAD/screenshot-512x288.png)

}
