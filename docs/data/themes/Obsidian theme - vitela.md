# Vitela

Vitela styles long-form reading and writing with book-style typography and a quieter interface. Paragraphs are justified with automatic hyphenation, the bundled fonts are Lora, EB Garamond and IBM Plex Mono, a restrained teal serves as the accent, and sizing is rem-based for accessibility. The recorded description also names matching Publish CSS so published notes stay consistent.
