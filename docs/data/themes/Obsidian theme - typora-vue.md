# Typora-Vue

Typora-Vue carries the Vue theme from Typora into Obsidian, mirroring the Typora-Vue file styles so the two applications look alike when switching between them. It includes a dark mode, an eye-protection light snippet, header markers shown on hover, and a highlighted cursor line, and the recorded description states that the accent colour is easy to change.

![Typora-Vue screenshot](https://raw.githubusercontent.com/zekunc/Obsidian-Typora-Vue-Theme/HEAD/obsidian-typora-vue.png)

```cue
theme: {
    name:   "Typora-Vue"
    author: "zekunc"
    repo:   "zekunc/Obsidian-Typora-Vue-Theme"
    slug:   "typora-vue"

    html_url:       "https://community.obsidian.md/themes/typora-vue"
    github_url:     "https://github.com/zekunc/Obsidian-Typora-Vue-Theme"
    screenshot_url: "https://raw.githubusercontent.com/zekunc/Obsidian-Typora-Vue-Theme/HEAD/obsidian-typora-vue.png"

    modes: ["dark", "light"]
    about: "Apply a Typora-inspired Vue theme to Obsidian that mirrors Typora-Vue file styles for smooth switching between apps. Enable dark mode, an eye-protection light snippet, hover-on-header markers and a highlighted cursor line, with easy accent-color customization."
}
```
