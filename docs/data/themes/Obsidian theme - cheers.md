# cheers

A simple, default-inspired layout with refined typography and subtle color tweaks. Twenty color schemes are available in dark and light modes and can be adjusted through Style Settings. Hongmeng and Xialu Wenkai are suggested as fonts.

![cheers screenshot](https://raw.githubusercontent.com/jdjshhc/cheers/HEAD/screenshot.png)

```cue
theme: {
    name:   "cheers"
    author: "xi gua"
    repo:   "jdjshhc/cheers"
    slug:   "cheers"

    html_url:       "https://community.obsidian.md/themes/cheers"
    github_url:     "https://github.com/jdjshhc/cheers"
    screenshot_url: "https://raw.githubusercontent.com/jdjshhc/cheers/HEAD/screenshot.png"

    modes: ["dark", "light"]
    about: "Apply a simple, default-inspired layout with refined typography and subtle color tweaks for an out-of-the-box experience. Choose from 20 color schemes in dark and light modes, adjust via Style Settings, and try recommended fonts Hongmeng (鸿蒙) or Xialu Wenkai (霞鹭文楷)."
}
```
