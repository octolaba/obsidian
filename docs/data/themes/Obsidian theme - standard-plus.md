# Standard Plus

Standard Plus refines the default Obsidian look with custom open and closed folder icons and a cleaner folder layout. Folder indent lines are removed for a tidier sidebar and pointer cursors are shown on interactive elements, with matching light and dark modes.

![Standard Plus screenshot](https://raw.githubusercontent.com/adamkdean/standard-plus-obsidian-theme/HEAD/preview.png)
