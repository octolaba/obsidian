# Primary Simplified

Primary Simplified is a warm, quiet theme on a soft Primary palette, with rounded UI details, readable typography, expressive checkboxes and tuned callouts in place of visual clutter. Light and dark palettes, alternative checkbox icons, folder and bookmark color presets and optional density and accent choices are selectable. The recorded description names reduced-motion and forced-colors compatibility for Obsidian 1.13 and later.
