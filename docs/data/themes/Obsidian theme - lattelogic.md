# LatteLogic

LatteLogic pairs a soft, eye-friendly palette with a crisp orthogonal interface, using a 0px border-radius for tabs, buttons and tags. A Step-Down header staircase visualizes document hierarchy, Obsidian accent colors are honored, and the theme works on the readability of dense tables and source-mode headers across devices.
