# Kanagawa Paper

Kanagawa Paper styles Obsidian with a Kanagawa-inspired look and carries both dark and light modes. Its recorded description names dark mode as the most polished appearance and calls light mode available but less optimized.

![Kanagawa Paper screenshot](https://raw.githubusercontent.com/sspaeti/obsidian_kanagawa_paper/HEAD/dark.jpg)

```cue
theme: {
    name:   "Kanagawa Paper"
    author: "Simon Späti"
    repo:   "sspaeti/obsidian_kanagawa_paper"
    slug:   "kanagawa-paper"

    html_url:       "https://community.obsidian.md/themes/kanagawa-paper"
    github_url:     "https://github.com/sspaeti/obsidian_kanagawa_paper"
    screenshot_url: "https://raw.githubusercontent.com/sspaeti/obsidian_kanagawa_paper/HEAD/dark.jpg"

    modes: ["dark", "light"]
    about: "Apply Kanagawa Paper to style Obsidian with a Kanagawa-inspired look and support for both dark and light modes. Use dark mode for the most polished appearance; light mode is available but less optimized."
}
```
