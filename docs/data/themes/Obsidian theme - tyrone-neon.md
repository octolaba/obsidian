# Tyrone Neon

Tyrone Neon applies a neon-infused look whose customizable accent colour propagates to UI elements, links, tabs and code blocks. It offers a pure-black dark mode alongside a clean light mode, and its recorded description lists rounded corners, Inter typography, improved syntax highlighting and a clearer visual hierarchy.
