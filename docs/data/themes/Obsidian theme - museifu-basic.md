# Museifu Basic

Museifu Basic is a simpler, fixed variant of Museifu that centers a single accent color across the interface. Notes and callouts are styled with an accented callout type and with pen colors matching the theme's accent.

![Museifu Basic screenshot](https://raw.githubusercontent.com/account-not-relevant/museifu-basic-theme/HEAD/cover.png)
