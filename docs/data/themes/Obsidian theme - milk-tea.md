# Milk Tea

Milk Tea is a warm theme with light and dark modes, terracotta accents and a deep warm night background, its recorded description naming Claude's desktop palette as the inspiration. The same description names matching syntax colors, accessible focus outlines, mobile-friendly spacing and Style Settings support.

![Milk Tea screenshot](https://raw.githubusercontent.com/artemislin/obsidian-milk-tea-theme/HEAD/obsidian.png)
