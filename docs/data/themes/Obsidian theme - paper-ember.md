# Paper Ember

Soft paper-like backgrounds with restrained terracotta accents in both light and dark modes, keeping a calm visual hierarchy. Editor and reading styles stay consistent, with subtle headings, callouts, tables and code blocks, and Obsidian's native font settings are respected. Optional Style Settings controls cover color, typography and layout tweaks.

![Paper Ember screenshot](https://raw.githubusercontent.com/eonewg/paper-ember/HEAD/screenshot.png)
