# Dark Clarity

Dark Clarity is a high-contrast dark theme that colors H1 through H6 to make the heading hierarchy clear, and it offers Genshin, Shinkai, Jay Chou, Rainbow, Nord and DarkMoss palettes. It adds bolder text, framed images, non-italic blockquotes, consistent code rendering, light-mode support, and optional sidebar, folder color and scrolling tweaks through Style Settings.
