# Sanguine

Sanguine is a slasher-horror inspired dark theme with blood-red accents, moody typography and cinematic contrast. Panels, menus and buttons are styled together, and the description records compatibility with community plugins including Advanced Tables, Kanban, Calendar and File Tree.
