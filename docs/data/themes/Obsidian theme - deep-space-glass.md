# Deep Space Glass

A dark glass interface on a near-black background, overlaid with a cyan, violet and magenta aurora radial gradient and a subtle technical grid. Callouts, tables and code blocks are translucent with glowing duotone accents, and the active-file pill glows cyan. Chakra Petch sets titles, Inter the body and JetBrains Mono the code, with contrast held at AA and AAA levels.
