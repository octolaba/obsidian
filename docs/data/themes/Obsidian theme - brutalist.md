# Brutalist

Brutalist is a stark, angular theme that removes rounded corners and pairs low-contrast greys with restrained accents for reading and drafting. Style Settings controls fonts, spacing and widths, and the theme adds dashboard, masonry, callout, CSS timeline and gallery layouts.

![Brutalist screenshot](https://raw.githubusercontent.com/ducktapekiller/Brutalist/HEAD/screenshot.png)
