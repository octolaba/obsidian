# Omega

Omega is a dark, cosmic-inspired theme with a bold palette and subtle gradient accents, described for late-night note-taking. Inline underline and highlight syntax is available for emphasis, and entire table cells can be highlighted. The recorded description states that the theme is in early development, with visual and plugin updates ongoing.
