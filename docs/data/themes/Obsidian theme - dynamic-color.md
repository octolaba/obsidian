# Dynamic Color

Dynamic Color generates Material Design color palettes from the selected accent color and applies them to the Obsidian interface. Colors adapt automatically so the look stays consistent across light and dark modes.

![Dynamic Color screenshot](https://raw.githubusercontent.com/rodydavis/obsidian-dynamic-color/HEAD/screenshots/light-purple.png)

```cue
theme: {
    name:   "Dynamic Color"
    author: "rodydavis"
    repo:   "rodydavis/obsidian-dynamic-color"
    slug:   "dynamic-color"

    html_url:       "https://community.obsidian.md/themes/dynamic-color"
    github_url:     "https://github.com/rodydavis/obsidian-dynamic-color"
    screenshot_url: "https://raw.githubusercontent.com/rodydavis/obsidian-dynamic-color/HEAD/screenshots/light-purple.png"

    modes: ["dark", "light"]
    about: "Generate dynamic Material Design color palettes from your selected accent color to theme Obsidian's UI. Keep a consistent look across light and dark modes with automatic color adaptation."
}
```
