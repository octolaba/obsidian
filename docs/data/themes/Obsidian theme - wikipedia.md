# Wikipedia

Wikipedia styles a vault after an encyclopedia, with matching headings, image treatment and a sidebar. Info callouts float as infoboxes, and bracketed dataview fields inside them render as infobox rows. Callout and image alt text decides whether an element floats left, right or centered, and an H6 produces a yellow infobox heading.

![Wikipedia screenshot](https://raw.githubusercontent.com/bluemoondragon07/Wikipedia-Theme/HEAD/example.png)

```cue
theme: {
    name:   "Wikipedia"
    author: "bluemoondragon07"
    repo:   "bluemoondragon07/Wikipedia-Theme"
    slug:   "wikipedia"

    html_url:       "https://community.obsidian.md/themes/wikipedia"
    github_url:     "https://github.com/bluemoondragon07/Wikipedia-Theme"
    screenshot_url: "https://raw.githubusercontent.com/bluemoondragon07/Wikipedia-Theme/HEAD/example.png"

    modes: ["dark", "light"]
    about: "Make your vault look like Wikipedia with encyclopedia-style headings, images, and sidebar. Float info callouts as infoboxes and render bracketed dataview fields inside them as infobox rows; use callout and image alts to float left, right, or center. Create yellow infobox headings with H6."
}
```
