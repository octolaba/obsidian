# Stratus

Stratus is dark-first, with a near-black canvas, crisp typography, cool blue accents, restrained borders and readable code, plus a matched light appearance. Its styling covers Reading, Live Preview, Source mode, Graph, Canvas and Bases, and the description records accessible colours, keyboard-visible focus, reduced-motion support, no remote assets and no required plugins.
