# Night Ridge

Night Ridge is a low-glare theme aimed at notes, technical writing and vault operations, using small beacon accents on headings, navigation, properties, callouts and graph nodes to mark hierarchy. Its muted palette of pine, copper, lichen, ember and seafoam is carried through refined dark and light modes.
