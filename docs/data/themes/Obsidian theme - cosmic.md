# Cosmic

A colorful, customizable theme inspired by painted night skies, with coordinated light and dark modes and seven complete color schemes. Typography, workspace backgrounds, colorful headings, continuous code blocks, tables, callouts, embeds and the Canvas, Graph and PDF views are all styled, and per-note layouts are optional. Enabling Style Settings unlocks deeper controls.

![Cosmic screenshot](https://raw.githubusercontent.com/kaymade/cosmic/HEAD/cosmic-screenshot.png)

}
