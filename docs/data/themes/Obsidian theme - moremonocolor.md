# MoreMonoColor

MoreMonoColor is a monochromatic interface driven by a single accent color. It offers colored highlights, centralized tables and colored callouts, and supports Iconize for iconized elements.

![MoreMonoColor screenshot](https://raw.githubusercontent.com/alanfgn/obsidian-more-mono-color/HEAD/more_mono_color.png)
