# Tokyo Night Simple

Tokyo Night Simple applies the Tokyo Night color palette to Obsidian's interface and text while preserving the default styling of UI elements. The recorded description states that the styling stays deliberately minimal and that the theme is dark mode only.

![Tokyo Night Simple screenshot](https://raw.githubusercontent.com/danarnold/tokyonight-simple/HEAD/directory-screenshot.png)
