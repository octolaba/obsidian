# Sodalite

Sodalite is a dark-only theme with a Fluent and Mica-inspired UI that scales note titles to H1 size and moves the status bar into the right side of the title bar to save vertical space. Optional CSS snippets center and cap the content width or adjust smaller visual details.

![Sodalite screenshot](https://raw.githubusercontent.com/tomzorz/Sodalite/HEAD/screenshot.png)

```cue
theme: {
    name:   "Sodalite"
    author: "tomzorz"
    repo:   "tomzorz/Sodalite"
    slug:   "sodalite"

    html_url:       "https://community.obsidian.md/themes/sodalite"
    github_url:     "https://github.com/tomzorz/Sodalite"
    screenshot_url: "https://raw.githubusercontent.com/tomzorz/Sodalite/HEAD/screenshot.png"

    modes: ["dark"]
    about: "Apply Sodalite for a dark-only, Fluent/Mica-inspired UI that scales note titles to H1 size and moves the status bar into the right side of the title bar to save vertical space. Enable optional CSS snippets to center and cap content width or tweak small visual details."
}
```
