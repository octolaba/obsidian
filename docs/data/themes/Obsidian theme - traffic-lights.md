# Traffic Lights

Traffic Lights is a light and dark CSS theme for Obsidian that adds a dedicated mode inspired by Andy Matuschak's notes. The recorded description lists optional visual tweaks for accents, spacing and layout, so a reader can choose between the classic, light, dark and Andy Matuschak styling.

![Traffic Lights screenshot](https://raw.githubusercontent.com/elliotboyd/obsidian-traffic-lights/HEAD/dark.png)

```cue
theme: {
    name:   "Traffic Lights"
    author: "elliotboyd"
    repo:   "elliotboyd/obsidian-traffic-lights"
    slug:   "traffic-lights"

    html_url:       "https://community.obsidian.md/themes/traffic-lights"
    github_url:     "https://github.com/elliotboyd/obsidian-traffic-lights"
    screenshot_url: "https://raw.githubusercontent.com/elliotboyd/obsidian-traffic-lights/HEAD/dark.png"

    modes:  ["dark", "light"]
    legacy: true
    about:  "Apply a clean light/dark CSS theme for Obsidian with a dedicated Andy Matuschak–inspired mode. Offer optional visual tweaks for accents, spacing, and layout to choose between classic, light, dark, and Andy Matuschak styling."
}
```
