# Orange Book Cloth

Orange Book Cloth is a dark, paper-like theme the description attributes to Claude and Anthropic, combining warm toasted-charcoal surfaces, clay-coral accents and warm off-white ink for high-contrast reading. Its Newsreader serif headings are bundled rather than fetched over the network, and the styling is carried across editor, callouts, tables, code and app UI.
