# Quietus

Quietus is a minimalist theme with uniform header prefixes across H1 to H6 and a configurable accent color. Images are centered with hover effects, internal links carry arrow prefixes and hover highlights, and checkboxes and scrollbars are restyled. Dark and light modes are both available.

![Quietus screenshot](https://raw.githubusercontent.com/yuanzhixiang/obsidian-theme-quietus/HEAD/screenshot.png)

```cue
theme: {
    name:   "Quietus"
    author: "yuanzhixiang"
    repo:   "yuanzhixiang/obsidian-theme-quietus"
    slug:   "quietus"

    html_url:       "https://community.obsidian.md/themes/quietus"
    github_url:     "https://github.com/yuanzhixiang/obsidian-theme-quietus"
    screenshot_url: "https://raw.githubusercontent.com/yuanzhixiang/obsidian-theme-quietus/HEAD/screenshot.png"

    modes: ["dark", "light"]
    about: "Apply a minimalist theme with clean typography, uniform header prefixes (H1–H6), and accent color customization. Center images with smooth hover effects, style internal links with arrow prefixes and hover highlights, use custom checkboxes and subtle scrollbars, and switch between dark and light modes."
}
```
