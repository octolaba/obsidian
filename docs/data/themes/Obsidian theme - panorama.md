# Panorama

Panorama is a minimal theme with three light palettes, Cornflower, Lavender and Marigold, and five dark ones: Mountain, Meadow, Space, Hearth and Forest. Accent highlighting, bold folder titles, centered headings, tags and tables, and a LaTeX background can be toggled, and the editor and interface fonts can be swapped to Space Grotesk and JetBrains Mono.

![Panorama screenshot](https://raw.githubusercontent.com/magmabits/Panorama-Theme/HEAD/panorama-screen.png)

```cue
theme: {
    name:   "Panorama"
    author: "magmabits"
    repo:   "magmabits/Panorama-Theme"
    slug:   "panorama"

    html_url:       "https://community.obsidian.md/themes/panorama"
    github_url:     "https://github.com/magmabits/Panorama-Theme"
    screenshot_url: "https://raw.githubusercontent.com/magmabits/Panorama-Theme/HEAD/panorama-screen.png"

    modes: ["dark", "light"]
    about: "Apply a minimal theme with 3 light palettes (Cornflower, Lavender, Marigold) and 5 dark palettes (Mountain, Meadow, Space, Hearth, Forest). Toggle accent highlight, bold folder titles, centered H1/tags/tables, LaTeX background, and swap editor/interface fonts to Space Grotesk and JetBrains Mono."
}
```
