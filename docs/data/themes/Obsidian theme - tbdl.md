# tbdl

An editorial news-magazine design setting body text in Merriweather and headings in condensed Oswald, with a signature yellow accent and a drop cap on the first paragraph. Lists, blockquotes, code blocks, tables and callouts are styled to match, and the Google Material Icons font is included for inline icons. A dedicated dark variant, editor gutter color variables and utility classes for icon sizes and accent colors are also provided.
