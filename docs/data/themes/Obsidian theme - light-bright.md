# Light & Bright

Light & Bright applies a weightless design with accent colors kept consistent across sidebars and the main note pane in both light and dark modes. Rounded elements, subtle box shadows, centered H1 and H2 headings and amplified header size differences mark the hierarchy. The recorded description also names minimal card styling and compatibility with Dataview and Style Settings.
