# Meridian

Meridian hides interface chrome until it is hovered, minimizing sidebars, tab bars, the status bar and tooltips for focused reading. Notes can be adjusted through cssclasses frontmatter to invert, grayscale, sepia, blur or align images and text. The recorded description says the theme is designed for macOS and that blur is limited on Windows.
