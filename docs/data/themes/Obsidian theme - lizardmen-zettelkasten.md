# Lizardmen Zettelkasten

Lizardmen Zettelkasten is a light theme aimed at Zettelkasten work, using muted tones and clean typography for readability. Links are underlined by default, with internal links highlighted in red on hover and external links in blue so the two stay distinguishable.

![Lizardmen Zettelkasten screenshot](https://raw.githubusercontent.com/dogwaddle/lizardmen-zettelkasten/HEAD/screenshot.png)
