# Mammoth

Mammoth is a dark theme tuned for a three-vertical-pane fullscreen workflow. It uses playful, vivid colors and reworks headers, blockquotes, code blocks and the command palette. Its recorded description also names Todoist plugin support and states that this support is broken in v1.0.

![Mammoth screenshot](https://raw.githubusercontent.com/wittionary/mammoth-obsidian-theme/HEAD/screenshots/thumbnail.png)
