# Biggs

Biggs is a square-edged theme with bold heading markers and bright, retro-inspired accents, published in both a dark and a light palette. Heading levels are colour-coded and the square geometry is carried through the interface. Links, tags, callouts, blockquotes, tables and code are styled to match, and heading sizes scale on mobile.

![Biggs screenshot](https://raw.githubusercontent.com/briancbiggs/biggs-obsidian-theme/HEAD/screenshot.png)
