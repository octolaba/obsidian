# Everforest Spruce

Everforest Spruce is a dark, minimal take on Everforest with subtle colors and colored accents used for visual separation. The recorded description credits a dimmed background with reducing eye strain and lists mono-color headings, readable code block highlighting and simplified tables for a plain writing view. The theme index records dark mode only.
