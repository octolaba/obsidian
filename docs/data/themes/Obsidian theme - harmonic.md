# Harmonic

Harmonic is a minimal, customizable theme shipping ready presets named Bear light and Cobalt dark, with Style Settings integration. Logos, accent colors, fonts, menu styles, focus and fullwidth modes, line width and paragraph offsets are all adjustable, and the recorded description adds plugin-aware styling for Kanban, Calendar, Sliding Panes, Checklist, File Explorer and Note Count. The theme index marks the entry as legacy.
