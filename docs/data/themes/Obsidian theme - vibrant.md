# Vibrant

Vibrant gives Obsidian a high-contrast colour palette and bold, experimental UI styling, described by its own recorded input as eye-piercing. That input is explicit that the visuals are unconventional and that rough edges and bugs are to be expected, and it asks users to report issues.

![Vibrant screenshot](https://raw.githubusercontent.com/jameslemony/obsidian_vibrant/HEAD/images/demo1.png)

```cue
theme: {
    name:   "Vibrant"
    author: "jameslemony"
    repo:   "jameslemony/obsidian_vibrant"
    slug:   "vibrant"

    html_url:       "https://community.obsidian.md/themes/vibrant"
    github_url:     "https://github.com/jameslemony/obsidian_vibrant"
    screenshot_url: "https://raw.githubusercontent.com/jameslemony/obsidian_vibrant/HEAD/images/demo1.png"

    modes: ["dark"]
    about: "Apply Vibrant to give Obsidian a high-contrast, eye-piercing color palette and bold, experimental UI styling. Test unconventional visuals, expect rough edges and bugs, and report issues to help improve the experience."
}
```
