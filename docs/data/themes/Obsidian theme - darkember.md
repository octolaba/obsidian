# DarkEmber

DarkEmber is a customizable dark and light theme with four color presets and SVG-based icons that remove reliance on external fonts. Heading decorations can be toggled, heading and table spacing are improved, and the theme works with Style Settings.

![DarkEmber screenshot](https://raw.githubusercontent.com/miz-i/Obsidian-theme-DarkEmber/HEAD/images/screenshot.png)

```cue
theme: {
    name:   "DarkEmber"
    author: "miz-i"
    repo:   "miz-i/Obsidian-theme-DarkEmber"
    slug:   "darkember"

    html_url:       "https://community.obsidian.md/themes/darkember"
    github_url:     "https://github.com/miz-i/Obsidian-theme-DarkEmber"
    screenshot_url: "https://raw.githubusercontent.com/miz-i/Obsidian-theme-DarkEmber/HEAD/images/screenshot.png"

    modes: ["dark", "light"]
    about: "Apply a customizable dark/light theme with four color presets and SVG-based icons that remove reliance on external fonts. Toggle heading decorations, enjoy improved heading and table spacing, and tweak visuals via Style Settings compatibility."
}
```
