# Base2Tone

Base2Tone styles Obsidian with a duotone palette taken from base2t.one, defaulting to the Duotone Dark Sky syntax hues. Its two primary hues are exposed as CSS variables, so the palette can be changed by editing them. The recorded description notes one accent colour that needs the second hue converted to RGB before it applies.

![Base2Tone screenshot](https://raw.githubusercontent.com/deathau/Base2Tone-For-Obsidian.md/HEAD/colours.gif)
