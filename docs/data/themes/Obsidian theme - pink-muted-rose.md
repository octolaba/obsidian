# Pink Muted Rose

Pink Muted Rose is a soft palette of dark muted rose and light pale blush that avoids pure black and white. Heading colors, fonts, accents, callouts and tag styles are configured through Style Settings, and the theme carries styling for Calendar, Kanban and Dataview alongside rose-toned code blocks.
