# Scanline

Scanline takes a terminal and TUI look, with monospace-forward typography, quiet borders, a phosphor glow in dark mode and warm sepia tones in light mode. The palette follows the accent colour across headings, links, tags and syntax, and it adds terminal-style code blocks, thin scrollbars and a minimal UI.

![Scanline screenshot](https://raw.githubusercontent.com/vforge/obsidian-scanline/HEAD/screenshot.png)
