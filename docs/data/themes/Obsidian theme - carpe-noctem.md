# Carpe Noctem

Carpe Noctem is a night-focused, minimalist theme with mobile-friendly layouts and broad plugin compatibility, including support for Sliding Panes. Its icons can be changed through built-in CSS instructions, and other visual details can be tweaked to match a given workflow.
