# Jotter

Jotter is a borderless theme with Style Settings support, offering 6 color themes and 13 accent colors. Headings, typography, bold and italic colors and underlines are adjustable, note titles can be hidden and explorer names wrapped, and the recorded description adds compatibility tweaks for Canvas, Kanban, Calendar and Dataview.

![Jotter screenshot](https://raw.githubusercontent.com/lnbgc/obsidian-jotter/HEAD/jotter.png)
