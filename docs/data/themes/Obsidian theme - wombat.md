# Wombat

Wombat is a minimalist dark theme with a dark gray background and a desert-inspired palette meant to be easy on the eyes. Its recorded description states that its syntax highlighting derives from Wombat256 for Vim with touches from Obsidian Nord, and that subtle contrasts are what it uses to improve focus.

![Wombat screenshot](https://raw.githubusercontent.com/hush-hush/obsidian_wombat/HEAD/main_thumbnail.png)

```cue
}
```
