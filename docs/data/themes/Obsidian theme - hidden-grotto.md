# Hidden Grotto

Hidden Grotto is a sharp theme with an optimized mobile interface, a vertical-scrolling toolbar and refined callouts whose icons can be hidden. Light or dark mode and 25 built-in palettes are offered, notes can be blurred or redacted for privacy, and the recorded description says custom color presets are added through snippets.
