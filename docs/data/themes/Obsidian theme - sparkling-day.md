# Sparkling Day

Sparkling Day is a bright, readable light theme based on Sparkling Night. Coloured checkboxes mark task states with symbols: work in progress, pause or stand-by, stop, and to be scheduled.

![Sparkling Day screenshot](https://raw.githubusercontent.com/isax785/obsidian-sparkling-day/HEAD/img/sparkling_day_small.png)

```cue
theme: {
    name:   "Sparkling Day"
    author: "isax785"
    repo:   "isax785/obsidian-sparkling-day"
    slug:   "sparkling-day"

    html_url:       "https://community.obsidian.md/themes/sparkling-day"
    github_url:     "https://github.com/isax785/obsidian-sparkling-day"
    screenshot_url: "https://raw.githubusercontent.com/isax785/obsidian-sparkling-day/HEAD/img/sparkling_day_small.png"

    modes: ["light"]
    about: "Apply a bright, readable light theme based on Sparkling Night. Use colored checkboxes to mark task states with intuitive symbols: [>] work in progress, [-] pause/stand-by, [/] stop, [<] to be scheduled."
}
```
