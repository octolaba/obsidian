# Dekurai

Dekurai is a clean, minimalist color scheme that keeps editing and reading modes visually consistent to prevent confusion when switching between them. Highlights appear as colored backgrounds while editing and as underscores in preview, code is shown with line counters, and the focused file is indicated during multiple selection.

![Dekurai screenshot](https://raw.githubusercontent.com/sergey900553/obsidian_dekurai_theme/HEAD/screenshot.png)

    name:   "Dekurai"

}
