# Lancer-OS

A high-contrast science-fiction terminal appearance built on deep black and grey backgrounds with aggressive neon orange accents for headers and icons. Bright cyan marks active states and links, directory and file entries carry terminal-style markers, and Dataview tables, callouts and internal links have their own styles.
