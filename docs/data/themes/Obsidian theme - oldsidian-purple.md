# Oldsidian Purple

Oldsidian Purple restores the pre-1.0 Obsidian look in a dark purple design with old-style callouts, legacy checkboxes and stronger purple highlights. It keeps YAML at regular font and size, shows unspecified code in red and enforces a minimum tab width. It also supplies CSS classes for aligning tables or hiding base field labels.

![Oldsidian Purple screenshot](https://raw.githubusercontent.com/ltctceplrm/oldsidian-purple/HEAD/cover.png)
