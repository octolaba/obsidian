# Cyber

A dark-only theme in the Night City vein, with pure-black chrome, cyber-yellow accents and cyan HUD highlights. Geometry is clipped and notched in HUD style, with hard borders, ghost-outline buttons, sharp rectangular tags, yellow-filled checkboxes and distinct callouts, plus solid fills that stay print-friendly. Type is set in embedded Rajdhani with a JetBrains Mono-first monospace stack.

![Cyber screenshot](https://raw.githubusercontent.com/alex-yelisieiev/cyber-obsidian/HEAD/screenshot.png)
