# Bumblebee

Bumblebee is a warm, high-contrast theme built on near-black backgrounds, with amber accents for links and controls and red emphasis for bold text. The design is dark-first and adds a WCAG AA-friendly light mode, tuned code syntax highlighting, and Style Settings options for callouts, header colors and underlines, and Kanban accents.

![Bumblebee screenshot](https://raw.githubusercontent.com/kulysocc/obsidian-bumblebee/HEAD/screenshot.png)
