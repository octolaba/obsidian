# Hackthebox

Hackthebox applies a look inspired by HackTheBox Academy, with dark, high-contrast visuals and learning-focused accents. The recorded description says body text stays readable and code blocks stay clearly monospaced for walkthroughs, labs and technical notes.

![Hackthebox screenshot](https://raw.githubusercontent.com/golam71/obsidian-hackthebox/HEAD/dark.png)

}
