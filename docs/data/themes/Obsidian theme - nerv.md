# nerv

This theme is inspired by Neon Genesis Evangelion, building a NERV interface on MAGI and EVA-01 terminal aesthetics with bold, high-contrast styling. Style Settings exposes the terminal colors, namely Central Dogma red, emergency alerts and telemetry accents, and both Dark and Light modes are supported.

![nerv screenshot](https://raw.githubusercontent.com/ethanthatonekid/obsidian-nerv/HEAD/screenshot.png)

theme: {

    modes: ["dark", "light"]
    about: "Apply a Neon Genesis Evangelion–inspired NERV UI with MAGI/EVA-01 terminal aesthetics and bold, high-contrast styling. Customize terminal colors—Central Dogma red, emergency alerts, and telemetry accents—via Style Settings, with both Dark and Light modes supported."
}
