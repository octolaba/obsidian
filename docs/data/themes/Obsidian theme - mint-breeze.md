# Mint-Breeze

Mint-Breeze is a light theme built on a mint-green palette with soft contrasts, readable typography and gentle shadows. Generous spacing and subtle accent colors are used to keep notes easy to scan.

![Mint-Breeze screenshot](https://raw.githubusercontent.com/quinta0/Mint-Breeze/HEAD/Mint-Breeze-small.png)
