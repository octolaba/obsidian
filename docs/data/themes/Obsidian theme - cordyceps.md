# Cordyceps

Cordyceps is a weathered survival-log theme with dark and aged light modes, charcoal panels, tarnished-gold accents, olive navigation and subtle CRT grain. It is pure CSS with monospace type, and it restyles panel frames, callouts, folder icons, gold checkboxes, headings, tables and code.

![Cordyceps screenshot](https://raw.githubusercontent.com/frank-pw/cordyceps/HEAD/preview.png)
