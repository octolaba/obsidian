# Composed

Composed is a paper-like light theme with a LaTeX-inspired hierarchy and consistent typography in both Reading view and Live Preview. It optimizes print and PDF output for A4, applies full justification with automatic hyphenation, and refines tables, lists, code, blockquotes and callouts.

![Composed screenshot](https://raw.githubusercontent.com/zjie-wang/obsidian-composed/HEAD/screenshot.png)

```cue
theme: {
    name:   "Composed"
    author: "Zijie Wang"
    repo:   "zjie-wang/obsidian-composed"

    screenshot_url: "https://raw.githubusercontent.com/zjie-wang/obsidian-composed/HEAD/screenshot.png"

    modes: ["light"]

}
```
