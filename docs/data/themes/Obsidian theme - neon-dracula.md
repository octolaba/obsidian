# Neon Dracula

Neon Dracula is a cyberpunk neon skin with glowing headers, outlined text and luminous effects on inline code, code blocks, tables, blockquotes, links, tags and horizontal rules. It sets a mono font stack of Intel One Mono, Fira Code and JetBrains Mono and a palette of purple, green, orange, cyan and gold accents.
