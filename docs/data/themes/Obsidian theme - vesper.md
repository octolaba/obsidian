# Vesper

Vesper is a minimal theme built on the palette of the original Vesper theme for VS Code, with both dark and light modes for day and night workflows. Its recorded description names JetBrainsMono Nerd Font as the font that matches its intended look.

![Vesper screenshot](https://raw.githubusercontent.com/omarrashad/obsidian-vesper/HEAD/assets/cover.png)

```cue
theme: {
    name:   "Vesper"
    author: "omarrashad"
    repo:   "omarrashad/obsidian-vesper"
    slug:   "vesper"

    html_url:       "https://community.obsidian.md/themes/vesper"
    github_url:     "https://github.com/omarrashad/obsidian-vesper"
    screenshot_url: "https://raw.githubusercontent.com/omarrashad/obsidian-vesper/HEAD/assets/cover.png"

    modes: ["dark", "light"]
    about: "Apply a minimal, clean theme inspired by the original Vesper VS Code palette. Use both dark and light modes for day/night workflows and a streamlined, distraction-free editor. Match the intended look with JetBrainsMono Nerd Font."
}
```
