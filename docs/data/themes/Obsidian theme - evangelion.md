# evangelion

The evangelion theme applies a Neon Genesis Evangelion inspired color scheme with Japanese stylings, adjusted icon sizes, Amiga fonts, tablet sizing fixes and interface tweaks meant to suit ASCII art. It also restyles the plugins its recorded description names as supported, among them Shiki, Iconize, Commander, Beautitab, Git, Omnisearch, Dataview, Trash Explorer and Reading View Enhancer, and ships SVG icons together with extra CSS snippets.

![evangelion screenshot](https://raw.githubusercontent.com/xero/evangelion.obsidian/HEAD/preview.png)
