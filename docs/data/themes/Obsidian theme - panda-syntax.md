# Panda Syntax

Panda Syntax styles Obsidian in a dark palette of soft pink, teal and blue, with a light variant alongside. Headings follow a full hierarchy mapped to the Panda colors of cyan, pink, orange, blue and purple, and syntax highlighting covers code blocks and inline code. Callouts, tables, tags, blockquotes and highlights are styled as well, with subtle pink file-explorer hover states and thin custom scrollbars.

![Panda Syntax screenshot](https://raw.githubusercontent.com/linyanna/panda-syntax-obsidian/HEAD/panda-syntax-dark.png)
