# Kurokula

Kurokula is a dark, high-contrast color scheme tuned for comfortable low-light writing and reading. It keeps syntax highlighting and interface elements consistent across code blocks, headings and notes, and the index records it as dark-only.

![Kurokula screenshot](https://raw.githubusercontent.com/indyandie/kurokula-obsidian-theme/HEAD/dark.png)
