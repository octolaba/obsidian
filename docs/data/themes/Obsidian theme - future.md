# Future

Future sets a gradient workspace background and offers an OLED-friendly dark mode toggle for higher-contrast viewing. The recorded description also allows heading colorfulness to be changed and the displayed username and icon to be customized in the sidebar and settings.

![Future screenshot](https://raw.githubusercontent.com/bluemoondragon07/obsidian-future/HEAD/cover.jpg)

```cue
theme: {
    name:   "Future"
    author: "bluemoondragon07"
    repo:   "bluemoondragon07/obsidian-future"
    slug:   "future"

    html_url:       "https://community.obsidian.md/themes/future"
    github_url:     "https://github.com/bluemoondragon07/obsidian-future"
    screenshot_url: "https://raw.githubusercontent.com/bluemoondragon07/obsidian-future/HEAD/cover.jpg"

    modes: ["dark", "light"]
    about: "Set a sleek gradient workspace background and toggle an OLED-friendly dark mode for cleaner, high-contrast viewing. Change heading colorfulness and customize the displayed username and icon to personalize the sidebar and settings."
}
```
