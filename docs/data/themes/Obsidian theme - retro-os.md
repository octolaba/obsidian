# Retro OS

A pastel neo-brutalist take on a 1990s operating system, with thick black borders, hard flat shadows and press-down button effects. Traffic-light window controls, the embedded VT323 pixel font, retro tabs, pixel scrollbars, callouts and tags come in light and dark modes. DataviewJS dashboards are styled to match.

![Retro OS screenshot](https://raw.githubusercontent.com/preval85/obsidian-retro-os/HEAD/screenshot.png)
