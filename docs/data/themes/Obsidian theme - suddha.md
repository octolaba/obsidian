# Suddha

Suddha is a clean, minimal light and dark theme with modern typography and polished UI elements. Accent and element colours can be customized, background brightness adjusted, and a compact file explorer with extra icons and hidden main buttons enabled. It also adds calendar and day-planner widgets while stating plugin compatibility.

![Suddha screenshot](https://raw.githubusercontent.com/dxcore35/Suddha-theme/HEAD/Images/Preview1.jpg)
