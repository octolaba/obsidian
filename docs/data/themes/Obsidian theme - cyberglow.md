# CyberGlow

CyberGlow is a neon cyberpunk dark theme with cyan and magenta accents and Xcode Midnight syntax highlighting for code. Style Settings controls colors, background intensity, tabs and a card-based workspace, and the theme adds hidden borders, slim scrollbars, three background presets and Code Styler compatibility.
