# March

A colorful, accent-aware theme with soft surfaces, playful typography and matched light and dark modes that leaves native Obsidian behavior in place. Headings are color-coded, text and interface styles are refined, code blocks carry line numbers, and alternate task states are styled. Catppuccin and Nord palettes are available as options.
