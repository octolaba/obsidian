# Simplicity

Simplicity is a minimal, clean theme that emphasises readability and a distraction-free workspace. Title text, accent colour, menu styles, title fonts, rounded corners, bold, italic and link styling, a focus mode and full-width pages are all customizable.

![Simplicity screenshot](https://raw.githubusercontent.com/thiews/obsidian-simplicity/HEAD/cover.png)

```cue
theme: {
    name:   "Simplicity"
    author: "thiews"
    repo:   "thiews/obsidian-simplicity"
    slug:   "simplicity"

    html_url:       "https://community.obsidian.md/themes/simplicity"
    github_url:     "https://github.com/thiews/obsidian-simplicity"
    screenshot_url: "https://raw.githubusercontent.com/thiews/obsidian-simplicity/HEAD/cover.png"

    modes: ["dark", "light"]
    about: "Apply a minimal, clean Obsidian theme that emphasizes readability and a distraction-free workspace. Customize title text, accent color, menu styles, title fonts, rounded corners, bold/italic and link styling, focus mode and full-width pages."
}
```
