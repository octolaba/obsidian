# Blue Topaz

Blue Topaz applies a blue color scheme with a colored titlebar, notebook-like note styling, command-palette tweaks and a reworked PDF view. Colors and backgrounds are customizable through Style Settings, and background image URLs are supplied by the reader.

![Blue Topaz screenshot](https://raw.githubusercontent.com/pkm-er/Blue-Topaz_Obsidian-css/HEAD/preview_Blue%20Topaz.png)

```cue
theme: {
    name:   "Blue Topaz"
    author: "pkm-er"
    repo:   "pkm-er/Blue-Topaz_Obsidian-css"
    slug:   "blue-topaz"

    html_url:       "https://community.obsidian.md/themes/blue-topaz"
    github_url:     "https://github.com/pkm-er/Blue-Topaz_Obsidian-css"
    screenshot_url: "https://raw.githubusercontent.com/pkm-er/Blue-Topaz_Obsidian-css/HEAD/preview_Blue%20Topaz.png"

    modes: ["dark", "light"]
    about: "Apply the Blue Topaz visual theme for a refined color scheme, colorful titlebar, notebook-like note styling, command-palette tweaks, and improved PDF view. Customize colors and backgrounds with Style Settings and set your own background image URLs; includes a TIPS example vault."
}
```
