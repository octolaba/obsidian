# Powered by Lancer - Retouched

Powered by Lancer - Retouched is a dark theme the description traces to the Lancer tabletop RPG and to the Wasp theme by Santi Younger. Its color palette is retouched for eye comfort while the Lancer aesthetics and accent colors are kept.
