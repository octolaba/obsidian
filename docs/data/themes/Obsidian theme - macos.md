# macOS

macOS brings native Mac styling to Obsidian through frosted-glass sidebars, subtle blur, soft edges and layered depth. Apple's SF Pro text scale and the system accent colors are applied across interface elements.

![macOS screenshot](https://raw.githubusercontent.com/stefan-imbesi/obsidian-macos-theme/HEAD/screenshot.png)
