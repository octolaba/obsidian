# Litos

Litos is an academic-inspired layout with clean typography, Tufte-style sidenotes and CJK font support for multilingual notes. Light and dark modes rest on an HSL accent color system, and the theme adds custom callout variants, styled checkboxes, tables and Mermaid diagrams within a minimal interface.
