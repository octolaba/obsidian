# EMRALD

EMRALD colors the vault in deep emerald with warm gold, offering a dark mode its recorded description compares to a well-lit study and a light mode in warm parchment tones. The description says the theme pairs with the EMRALD plugin but also works on its own, supports the Style Settings plugin for a few tweaks, and includes styled callouts, blockquotes and tables plus a stepped header hierarchy.

![EMRALD screenshot](https://raw.githubusercontent.com/admiral9k/emrald-obsidian-theme/HEAD/screenshot.png)

```cue
theme: {
    name:   "EMRALD"
    author: "Devon"
    repo:   "admiral9k/emrald-obsidian-theme"
    slug:   "emrald"

    html_url:       "https://community.obsidian.md/themes/emrald"

    screenshot_url: "https://raw.githubusercontent.com/admiral9k/emrald-obsidian-theme/HEAD/screenshot.png"

    modes: ["dark", "light"]
    about: "The EMRALD theme wraps your vault in deep emerald and warm gold for a calm, rich feel that helps you focus. Dark mode feels like a well-lit study, easy on the eyes for long sessions. Light mode swaps to warm parchment tones, like writing on quality stationery in morning light. The theme pairs naturally with the EMRALD plugin, but works beautifully on its own. It supports the Style Settings plugin for a few subtle tweaks, and includes styled callouts, blockquotes, tables, and a stepped header hierarchy that makes structure feel intentional."
}
```
