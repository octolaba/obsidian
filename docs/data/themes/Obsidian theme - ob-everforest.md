# OB Everforest

OB Everforest carries the Everforest green palette into Obsidian in both light and dark modes. It keeps the platform-adaptive UI elements of Baseline so that controls look native on macOS, Windows, Linux and Android, and its appearance is customized through the Style Settings plugin.

![OB Everforest screenshot](https://raw.githubusercontent.com/smoosex/ob-everforest/HEAD/obsidian-everforest.png)

```cue
theme: {
    name:   "OB Everforest"
    author: "smoose"
    repo:   "smoosex/ob-everforest"
    slug:   "ob-everforest"

    html_url:       "https://community.obsidian.md/themes/ob-everforest"
    github_url:     "https://github.com/smoosex/ob-everforest"
    screenshot_url: "https://raw.githubusercontent.com/smoosex/ob-everforest/HEAD/obsidian-everforest.png"

    modes: ["dark", "light"]
    about: "Apply Everforest's soothing green palette in both light and dark modes. Keep platform-adaptive, native-looking UI elements from Baseline so controls feel native on macOS, Windows, Linux, and Android. Customize appearance with the Style Settings plugin."
}
```
