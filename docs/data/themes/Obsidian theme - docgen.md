# Docgen

Docgen uses a warm near-black palette with honey-amber accents and Geist typography for documentation reading. The Geist and Geist Mono fonts are embedded as base64 so they render offline, and matched dark and light modes are provided.

![Docgen screenshot](https://raw.githubusercontent.com/iammaxim/obsidian-docgen-theme/HEAD/screenshot.png)

```cue
theme: {
    name:   "Docgen"
    author: "Maxim Stepanov"
    repo:   "iammaxim/obsidian-docgen-theme"
    slug:   "docgen"

    html_url:       "https://community.obsidian.md/themes/docgen"
    github_url:     "https://github.com/iammaxim/obsidian-docgen-theme"
    screenshot_url: "https://raw.githubusercontent.com/iammaxim/obsidian-docgen-theme/HEAD/screenshot.png"

    modes: ["dark", "light"]
    about: "Apply a warm near-black palette with honey-amber accents and Geist typography for comfortable documentation reading. Use embedded Geist and Geist Mono fonts (base64) for offline rendering and choose matched dark and light modes."
}
```
