# ForestRest

A warm rice-paper look with a soft beige surface, restrained forest-green accents and ink-like code blocks intended for low-fatigue reading. Syntax colors follow a forest-inspired palette, body text uses a brush-style font and code uses JetBrains Mono. A night-forest dark mode accompanies the light one.
