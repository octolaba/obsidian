# Handwriting (Kalam)

Handwriting (Kalam) uses the Kalam font with sky-blue body text, pen-blue headings and purple bold emphasis to give a vault a handwritten look. Math and inline code are styled to match, and the recorded description says the theme applies either globally or to individual notes through a CSS class, working in Preview and in Live Preview. The theme index records light mode only.
