# One Oracle Developer

One Oracle Developer is aimed at long-form technical writing and tight note taxonomies, with book-like serif headings, opinionated typography and adjusted chrome for daily developer use. It hides frontmatter while leaving properties editable, renders lists with em-dash bullets and readable strikethrough, and shows accent tag pills. The file explorer gains indentation guides and an arrow marking the active file.
