# Tyliz/KanbanMoon

Kanban Moonlight turns notes carrying frontmatter metadata into interactive Kanban boards inside Obsidian. Several independent boards can be defined, each with its own columns, categories, tag and folder configuration and reachable from a tab bar, and each offers board, Gantt chart and dashboard views. Dragging a card between columns updates the note's state property and appends a timestamped entry to a history array in its frontmatter, from which the Gantt view derives task start and end dates, while completed tasks collect in a dedicated column with a configurable time window. Columns and categories are added, renamed, reordered and given Lucide icons and colours, tasks are created and deleted from the board or the command palette, search covers titles, descriptions, categories and tags, and the interface follows the Obsidian locale for English or Spanish.
