# zhengyuan-public/obsidian-node-tree-graph

Node Tree Graph is an Obsidian graph plugin that breaks each Markdown file into a hierarchy of nodes instead of drawing it as a single one: the file is the root node and its H1 to H6 headings become leaf nodes for sections and sub-topics. The maximum heading level is configurable, and links belonging to hidden headings either roll up to the nearest visible ancestor node or are discarded. Hovering highlights related nodes, with the search direction set to downward, upward or both and a depth limit, and node coloring and radius, edge width, color, style and alpha, font settings and simulation physics are all configurable.
