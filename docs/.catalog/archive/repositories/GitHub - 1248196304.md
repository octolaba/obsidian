# jepicaju862-lab/Side-Comments-origin

Side Comments is a local sidebar annotation plugin that marks selected Markdown text visually and stores standalone Markdown comments without adding syntax to the source note. It offers highlight, underline, strikethrough, bold, custom colors, selection-toolbar and hover actions, searchable cards, precise backlinks, image support, exports, backups, and short-term restore after deletion. Text tracking uses positions, selected text, hashes, heading paths, occurrence indexes, and surrounding context to relocate annotations or identify orphaned comments.
