# swalrus1/obsidian-note-chain

This repository holds Chain, an Obsidian plugin that organises notes by linking each new note to the last note on the same topic, so that notes on one topic form the sequence the README calls a chain. It adds two things: a command that links a new note into a chain in two clicks while listing the notes not yet linked, and a view that displays all notes in a chain so they can be read in order. The README argues that chains scale better than tags, since merging two chains needs one new note referencing both rather than an edit to every tagged note. The repository description also mentions a command-line tool and an LLM skill beside the plugin.
