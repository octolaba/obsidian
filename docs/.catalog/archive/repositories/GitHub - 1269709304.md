# arias007/obsidian-cancip-ai

This repository holds Obsidian Cancip AI, a right-side chat panel shaped toward a mobile-first agent workflow for managing a vault, which the README calls a lightweight prototype. Note edits made by the agent are review-gated, and the recorded description names a command bus, skills, memory and automation beside the chat panel. Model sources and models are configured separately: each source stores its own base URL, key and API mode, each model id is bound to one source, and a single default model drives the modules unless one overrides it. The interface is multilingual with automatic device-language detection across twelve languages, falling back to English for missing strings and using right-to-left layout hints for Arabic and Uyghur.
