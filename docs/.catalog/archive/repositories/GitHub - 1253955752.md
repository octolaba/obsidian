# aiken884/obsidian-h1aligner

H1Aligner keeps an Obsidian note's filename synchronized with its first H1 in one direction, using Obsidian's rename operation so backlinks follow. Users can choose open, edit, leave, combined, or manual triggers, while locks, folder rules, sanitization, collision checks, dry-run previews, and undo protect renames.
