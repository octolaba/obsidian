# SharbelMarshi/obsidian-LuaTikz-plugin

LuaTikZ renders tikz and luatikz code blocks in Obsidian using local LuaLaTeX on desktop or TikZJax on mobile. It offers live previews, a visual touch/stylus editor with drawing, shapes, circuit components, text, math, and plots, plus lossless source synchronization that preserves unsupported statements and comments. The editor can draw over the compiled diagram, supports RTL content, and records completed operations as normal undo steps.
