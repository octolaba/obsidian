# oxilldat/obsidian-emotion-book

Obsidian plugin for recording emotional state through the day from within daily notes. An entry is added through a dialog that offers a list of emotions and a text note, and the day's entries are shown as a chronological feed inside the daily note; emotions themselves can be created, recoloured and given weights. Each entry is saved as its own Markdown file with YAML frontmatter carrying tags, date and emotion, with the day resolved from a configurable frontmatter field, then the file name, then the file creation date. The README records a bilingual Russian and English interface and compatibility with an older block-embedded JSON format.
