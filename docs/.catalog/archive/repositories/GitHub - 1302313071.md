# def-peter/obsidian-aera-theme

Aera is a Chinese-first Obsidian theme shaped around calm reading and clear hierarchy, giving Chinese text a comfortable rhythm while keeping English typography, code and interface elements in balance. It respects the app's reading width and the user's font size and builds its light and dark palettes around a blue accent of #1677FF. Its README lists borderless semantic callouts carrying Fluent Emoji Flat illustrations, paper-like blockquotes with a folded corner, Monokai fenced code blocks with understated inline code, and refined headings, links, lists, tables, properties, tags and embeds. Desktop and mobile are both supported without overriding user-controlled text sizing, and the repository documents a build step and a combined test, policy and contrast suite.
