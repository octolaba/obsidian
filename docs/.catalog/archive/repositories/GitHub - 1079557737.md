# eng618/obsidian-encrypted-folders

Obsidian Encrypted Folders encrypts folder trees inside a vault, including nested subfolders, and temporarily restores plaintext to disk while a folder is unlocked so Search, Graph view and backlinks keep working. The README states that encrypted files carry a .locked extension, that access goes through an encrypted master key unwrapped by a password or a 32-character recovery key, and that plaintext is overwritten with random data before re-encryption. It also describes automatic re-locking when the plugin is disabled, when Obsidian closes or after configurable inactivity, and an exit option that removes encryption from a folder permanently.
