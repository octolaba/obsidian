# arias007/obsidian-notedraw

NoteDraw adds a shared drawing and text-editing layer to Obsidian reading, source, embedded-note, and supported webview surfaces. It supports pens, watercolor, shapes, text styling, selection, copy and paste, persistent tool settings, portable single-file storage, mind maps, imported media, public scripting and agent APIs, and viewport-aware rendering.
