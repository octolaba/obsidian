# magmabits/Panorama-Theme

Panorama is a minimal Obsidian theme with ten colour palettes: four light ones named after flowers, Cornflower, Lavender, Marigold and Hydrangea, and six dark ones named after landscapes, Mountain, Meadow, Space, Hearth, Forest and Caves. The README also lists optional toggles for an accent highlight colour, bold folder titles, centred H1 tags, centred tables and a LaTeX background.
