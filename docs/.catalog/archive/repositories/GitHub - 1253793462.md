# jabaho9523/AlienTheme

Alien is a deep-space terminal Obsidian theme built on near-black backgrounds with a phosphor-green accent, acid lime for bold text and code strings, scanner cyan for italics and external links, and hazard amber for highlights, numbers and warnings. A red alert colour is held back for errors, unresolved links and destructive actions so that it stays meaningful. H1 to H3 carry the green glow while H4 to H6 fall back to scanner cyan and vapor grey, code blocks use a near-black terminal background with green keywords, and blockquotes get a green left bar and a faint glow. The README lists Obsidian 1.4 and later, the default core plugins, and an included light mode.
