# skyue/obsidian-nldates-chinese

This repository holds Natural Language Dates (Chinese), an Obsidian plugin for entering dates as Chinese natural language and then inserting a date link or opening the matching daily note. Typing a trigger character, by default the at sign, opens a date suggestion menu, while commands parse a selected Chinese date expression into a link or into plain date text, or jump to the daily note for it. The README records support for both simplified and traditional Chinese across relative days, weekdays, months, years, quantity-and-unit expressions, ordinals, festivals and numeric dates, and settings for the Moment.js output format, the first day of the week, the trigger character, whether suggested dates are wrapped as links, and the alias format used for those links.
