# sarath/gemmanotes

Records push-to-talk voice notes and transcribes them on the device with a Gemma model running in process through a browser machine-learning runtime, so no server or API key is involved after a one-time model download. Recording is toggled from a ribbon button or a command, a placeholder is pinned into the current note on stop, audio is decoded to 16 kHz mono and split into chunks of at most 25 seconds, transcription runs through a queue so a new recording can start while one is processing, and the placeholder is then replaced by the text. A rewrite action can rephrase any selected text with the same local model. The README states that network requests are made only to download model weights and runtime files, that no recording is ever sent to a remote server, and that clipboard access is optional and write-only.
