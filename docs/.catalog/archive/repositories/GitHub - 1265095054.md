# leonpawelzik/obsidian-tandem-comments

Tandem Comments stores quote-anchored discussion threads and edit suggestions in a fenced block at the end of an Obsidian note, leaving the prose untouched until a suggestion is accepted. A sidebar supports replies, resolution, re-anchoring, per-author colors, export, and live highlights, while the self-describing JSON format is intended for file-based AI workflows.
