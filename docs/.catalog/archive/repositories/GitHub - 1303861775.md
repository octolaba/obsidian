# 2607044640/fluent-tasks

A task manager with drag-and-drop lists and groups, presented in a sidebar that opens on startup or from the command palette. Task lists can be nested into groups and reordered, tasks carry checklist subtasks, notes, starring and completion state, and the accent colour is configurable. The README states that lists and tasks are stored in standard Markdown files and positions the plugin as a local alternative to hosted to-do services.
