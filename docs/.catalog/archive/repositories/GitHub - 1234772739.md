# rogerdigital/smart-explorer

Repository for Smart Explorer, a side-pane file explorer aimed at vaults where the default tree falls short and a human priority order is wanted instead of alphabetical sorting. Its README records a folder tree with counts and hover details, creating and renaming notes and folders inline, sorting by name, modified or created date, extension, size or a manual drag order, filtering by name or path, file kind and date range, a tree and list toggle, command palette entries and keyboard navigation. Manual sort begins from whichever order was being viewed, and settings cover the default sort mode, hidden extensions and resetting the manual order.
