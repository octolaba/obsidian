# any-menu/obsidian-any-menu

This repository is an only-obsidian mapping of the any-menu/any-menu monorepo, which holds the Obsidian plugin version alongside an app version and others. Its README states that it exists for search promotion, for releasing the Obsidian plugin independently, and to keep out code the Obsidian automated plugin review does not need. Readers are directed to star the upstream monorepo rather than this repository.
