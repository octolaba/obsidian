# Aubade

Aubade is a retro-brutalist interface built on strict geometry: square corners, two-pixel high-contrast borders and directional shadows. Its typography is monospaced in a terminal register, and several colour schemes are offered. The recorded description also names dashboard grid layouts, timelines built in CSS alone, and a bottom navigation bar for mobile.

![Aubade screenshot](https://raw.githubusercontent.com/ducktapekiller/obsidian-aubade/HEAD/screenshot.png)
