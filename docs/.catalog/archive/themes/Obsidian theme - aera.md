# Aera

Aera provides a quiet, distraction-free Obsidian interface, with readability for Chinese-first notes named as its focus. It ships light and dark palettes and records layouts tuned for both desktop and mobile.

![Aera screenshot](https://raw.githubusercontent.com/def-peter/obsidian-aera-theme/HEAD/screenshot.png)

```cue
theme: {
    name:   "Aera"
    author: "def-peter"
    repo:   "def-peter/obsidian-aera-theme"
    slug:   "aera"

    html_url:       "https://community.obsidian.md/themes/aera"
    github_url:     "https://github.com/def-peter/obsidian-aera-theme"
    screenshot_url: "https://raw.githubusercontent.com/def-peter/obsidian-aera-theme/HEAD/screenshot.png"

    modes: ["dark", "light"]
    about: "Provide a quiet, distraction-free interface for clear thinking and readable Chinese-first notes. Support light and dark palettes with layouts optimized for desktop and mobile."
}
```
