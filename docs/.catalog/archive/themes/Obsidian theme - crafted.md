# Crafted

Crafted is a dark, readable interface with a deep navy background and soft green accents, intended to reduce eye strain during long writing, coding and thinking sessions. It combines rounded interface elements, tuned high-contrast typography, code-friendly monospace fonts, a responsive mobile layout and print-ready styles.
