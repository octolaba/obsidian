# Chain

Chain organises notes into chains by linking each new note to the last note on the same topic, so that notes on one topic form long sequences. The plugin links relevant chains in two clicks and provides navigation along them.

```cue
plugin: {
    id:     "chain"
    name:   "Chain"
    author: "semyon"
    repo:   "swalrus1/obsidian-note-chain"

    html_url:    "https://community.obsidian.md/plugins/chain"
    github_url:  "https://github.com/swalrus1/obsidian-note-chain"
    description: "Organise notes in chains to easily expand a large knowledge base - This plugin has not been manually reviewed by Obsidian staff."
    about:       "To organise your knowledge base, link each new note to the last note on the same topic. Notes on the same topic will naturally form long sequences, a.k.a. chains. \"Chains\" plugin allows linking relevant chains in 2 clicks and navigating chains."

    stats: {
        downloads:  152
        updated_at: 1779813763000
    }
}
```
