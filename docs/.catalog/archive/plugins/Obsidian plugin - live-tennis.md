# Live Tennis

Embeds live tennis scores in a note through a tennis code block that renders current matches on preview without storing results, using the Live Tennis API. Any query can be frozen into a static Markdown snapshot table carrying players, per-set scores, event, surface, and winner, and one-line player profiles can be inserted.

```cue
plugin: {
    id:     "live-tennis"
    name:   "Live Tennis"
    author: "Live Tennis Api"
    repo:   "livetennisapi/obsidian-live-tennis"

    html_url:    "https://community.obsidian.md/plugins/live-tennis"
    github_url:  "https://github.com/livetennisapi/obsidian-live-tennis"
    description: "Embed live tennis scores in notes and freeze match snapshots or player profiles into permanent markdown, powered by the Live Tennis API. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Embed live tennis scores in notes via a tennis code block that renders current matches on preview without storing results. Freeze any query into a static markdown snapshot table (players, per-set scores, event, surface, winner) for permanent journaling. Insert one-line player profiles."
}
```
