# Atomic Insights

Suggests related atomic notes by analyzing the vault's link graph with the Adamic Adar index, optionally weighted by context signals such as metadata and time, in order to surface niche connections. Suggestions appear in a dedicated sidebar and in a footer under the current note, with native page previews and click-to-navigate links.
