# Text Brush

Text Brush applies, switches or clears text color and font size from the editor's right-click context menu, drawing on a theme-aware default palette or on custom colors and sizes. A smart replace prevents nesting and allows color and size to be stacked, and the output carries CSS classes alongside inline styles so it survives HTML and PDF export.
