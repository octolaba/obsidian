# Agenter

Agenter brings a tool-using AI assistant into Obsidian as docked, floating and contextual chats that work with notes, search the web and reuse saved prompts. Several AI providers can be connected, vault-scoped context is applied, replies stream and render as Markdown, and note changes are proposed for approval before being applied.
