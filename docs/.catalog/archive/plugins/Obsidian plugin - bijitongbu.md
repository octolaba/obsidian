# Biji Tongbu

Biji Tongbu collects material from common platforms and hands it to an AI assistant that organizes it into Obsidian. Links to articles and videos are sent to the assistant, which structures the content and, for a video, also produces a transcript. Chat logs, images and file attachments can be gathered from platforms including WeChat, Feishu, Telegram and X. The recorded description and About text for this plugin are written in Chinese; this summary restates them in English.
