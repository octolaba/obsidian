# Daily Five

A daily five-letter word game played inside Obsidian, with one new puzzle a day, six guesses and a touch keyboard. Lifetime stats are tracked, and a result block is inserted or updated in the Daily Note. Puzzles come from a local cache with an API fallback, and progress and settings stay stored in the vault.
