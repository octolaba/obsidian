# Notes Dashboard

Turns any note into a card and arranges the cards in customizable columns as a Kanban-style dashboard of favorites. Cards can be added, removed, organized and sorted by name or by creation or modification date, and their tags are displayed for context. The interface is responsive and follows the active Obsidian theme.
