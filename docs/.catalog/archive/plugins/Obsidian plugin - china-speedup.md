# China Speedup

China Speedup presents the community plugin store for browsing, searching and one-click installation, routing downloads through relay nodes inside China rather than reaching GitHub directly. The fastest relay is selected automatically and manifest and plugin downloads are cached. It also covers a server-side blacklist, special import configuration, deeplink installs triggered from the website, and atomic self-updates.
