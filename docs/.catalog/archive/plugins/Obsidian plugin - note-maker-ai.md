# NoteMakerAI

NoteMakerAI creates structured notes from photos, using AI to extract a title, author, description, date, camera metadata and subject-specific fields. Subjects are defined in simple YAML, so which fields are extracted depends on what the photo shows. Images can be processed in batches, results iterated on with redo instructions, and images optimised to reduce file size and AI token usage.
