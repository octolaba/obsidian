# Link Plus

Finds unlinked mentions across the vault and converts them to wikilinks, either one at a time or in batches, with no setup recorded. Results are grouped by target note, aliases can be managed and mentions dismissed, and matching is whole-word and case-insensitive while skipping code blocks, frontmatter, and existing links.
