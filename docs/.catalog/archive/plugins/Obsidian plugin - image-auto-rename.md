# Rename Img

Rename Img renames newly created or pasted images after the current file with a sequence number and repairs Markdown and Canvas references afterwards. PNG files can be hidden from the file explorer, and Canvas image filenames shown, hidden or shown on hover. It also creates a default Bases file with preset filters and visible properties, styles Base name cells by file extension, and ships the Baseline theme, installing and switching to it.

```cue
plugin: {
    id:     "image-auto-rename"
    name:   "Rename Img"
    author: "Contributors"
    repo:   "milin-jad/Obsidian_plugins"

    html_url:    "https://community.obsidian.md/plugins/image-auto-rename"
    github_url:  "https://github.com/milin-jad/Obsidian_plugins"
    description: "Automatically rename pasted images, clean image file lists, style Bases rows, and install the Baseline theme. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Image Auto Rename helps keep Obsidian vaults cleaner when working with pasted images and Canvas files. Features: - Automatically rename newly created or pasted images with the current file name and sequence number. - Repair Markdown and Canvas image references after automatic renaming. - Hide PNG files from the file explorer visually. - Control Canvas image filename display: show, hide, or show on hover. - Create a default Bases file with preset filters and visible properties. - Style Base name cells by file extension with custom bold colors. - Include Baseline theme files and automatically install and switch to the Baseline theme. Default settings include hover-only image filenames, hidden PNG files, Baseline theme enabled, and Base style rules for canvas and md files."
```
