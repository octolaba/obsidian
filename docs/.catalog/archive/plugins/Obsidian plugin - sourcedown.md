# SourceDown

Documents, media, archives, web pages and vault files are imported as Markdown notes through Microsoft MarkItDown, with source metadata recorded on the result. Embedded images are saved beside the note in asset folders and duplicate imports are numbered automatically. MarkItDown runs inside a private virtual environment, so the system Python installation and its global packages are left unchanged.
