# Freewrite

Starts timed, distraction-free writing sessions in a full-pane editor that hides formatting and editing tools. Sessions are saved automatically and come with presets of 5, 10, 15 and 25 minutes, cycling fonts and sizes, and an optional mode that disables backspace.
