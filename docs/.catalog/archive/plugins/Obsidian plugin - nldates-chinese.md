# Natural Language Dates - Chinese

Natural Language Dates - Chinese accepts dates written in Chinese natural language, entered after an @ trigger, and turns them into concrete dates. The plugin's own description and About text are written in Chinese and state that it handles relative dates, weekdays, months, years, festivals, ordinals and numeric dates. Typing the trigger or running a command inserts the date as text, generates a wiki or Markdown link, opens the matching Obsidian daily note, or brings up a date picker.

```cue
plugin: {
    id:     "nldates-chinese"
    name:   "Natural Language Dates - Chinese"
    author: "SKYue"
    repo:   "skyue/obsidian-nldates-chinese"

    html_url:    "https://community.obsidian.md/plugins/nldates-chinese"
    github_url:  "https://github.com/skyue/obsidian-nldates-chinese"
    description: "支持中文自然语言输入日期，如 @今天、@下周三、@3天后 - This plugin has not been manually reviewed by Obsidian staff."
    about:       "输入中文自然语言日期以快速生成或插入日期。支持相对日期、星期、月份、年份、节日、序数与数字日期；按 @ 或运行命令可插入日期文本、生成 wiki/Markdown 链接、打开对应日记或调出日期选择器。"

    stats: {
```
