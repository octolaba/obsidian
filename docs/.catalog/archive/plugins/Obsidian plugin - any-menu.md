# AnyMenu

Integrates AnyMenu into Obsidian, exposing app-style menus and quick actions inside the editor for quicker input, conversion and search. The recorded About text describes it as carrying independent Obsidian releases, isolating editor-specific features and bug fixes from the upstream monorepo.
