# Cancip

Cancip opens a right-side, mobile-friendly AI chat panel for reading and writing the vault, with Codex and Claude Code style tools and Obsidian-rendered Markdown messages. Vault actions such as read, write, append, patch, mkdir, rename and copy are validated and run in either confirmation or full-access mode. It supports multiple API profiles, a multilingual interface, long-term memory and on-demand vault search for context.
