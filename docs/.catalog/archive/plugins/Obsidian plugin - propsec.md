# Propsec

Validates frontmatter and file properties against user-defined schemas to catch structural errors without modifying the notes. Schemas are targeted by path, tags or property filters, and can declare custom reusable types, union types, required, warn and unique flags, and cross-field constraints. Violations are reported in the status bar or in a sidebar.
