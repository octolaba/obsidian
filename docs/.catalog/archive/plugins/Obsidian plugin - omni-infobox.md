# Omni Infobox

Omni Infobox renders Wikipedia-style infoboxes from a note's YAML frontmatter, shown in a floating panel pinned to the top-right of the reading pane. A box can carry a title, subtitle, image with caption, tags, named section dividers and key-value fields, resolves local vault images, and follows light and dark themes on desktop and mobile.
