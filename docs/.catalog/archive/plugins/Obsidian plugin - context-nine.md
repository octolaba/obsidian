# Context Nine

Context Nine captures selections into new or existing TaskNotes tasks and routes pasted or inbox attachments into destination context folders. It moves TaskNotes files when their context fields change and adds delete actions to the file explorer, kanban and edit modals. A Vault Cockpit in the right sidebar runs local vault commands and shows their output live.
