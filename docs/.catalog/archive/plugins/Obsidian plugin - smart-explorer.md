# Smart Explorer

Smart Explorer replaces the default side pane with an explorer that sorts by name, dates, extension or size, groups by folder, extension, top-level folder or modified month, and filters by name or path search, Markdown only, attachments only or recent files. Files can be inspected without being opened: the first heading and tags for Markdown, thumbnails for images, and type, size and modified date for everything else. The preferred sort, group and preview settings are stored locally.
