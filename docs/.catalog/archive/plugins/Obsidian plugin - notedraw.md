# NoteDraw

Allows drawing directly on notes with pen and watercolor brushes, arrows, lines, shapes, floating text, selection and multi-select, movement, resize handles and double-click text editing, and allows rendered note text to be edited in place. Drawing layers are stored outside the Markdown, one set per note, and are loaded lazily so opening a note stays fast. A public API is exposed for scripts and other plugins.
