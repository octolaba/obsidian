# MySpace Tasks

Sends the current line or the selected text to a linked MySpace task list on demand, without scanning the vault. The source line is marked as sent and its Markdown checkbox is checked automatically. Chinese natural-language dates are understood, and the recorded text states that a MySpace account and network access are required.

```cue
plugin: {
    id:     "myspace-tasks"
    name:   "MySpace Tasks"
    author: "李向阳"
    repo:   "hankleechn/myspace-tasks"

    html_url:    "https://community.obsidian.md/plugins/myspace-tasks"
    github_url:  "https://github.com/hankleechn/myspace-tasks"
    description: "Send the current line or selected text to your linked MySpace task account. - This plugin has not been manually reviewed by Obsidian staff."
    about:       "Send a line or selection from your note to your linked MySpace task list on demand, without scanning your vault. Mark the source line as sent and check its Markdown checkbox automatically, and support Chinese natural-language dates like 今天, 明天, 下午3点. Require a MySpace account and network access."

    stats: {
        downloads:  12
        updated_at: 1784617269000
    }
}
```
