# CloudWeave

Adds cloud-storage file nodes to Obsidian Canvas, browsing Aliyun, Baidu, Quark and OneDrive and recording each node's cloud source and path. Selected Canvas nodes, local notes and cloud files alike, can be analyzed by an AI that reads PDF, text and code content, offers presets and free-form questions, and jumps to video or audio timestamps.
