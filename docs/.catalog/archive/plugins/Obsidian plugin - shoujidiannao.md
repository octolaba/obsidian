# Shouji Diannao

Shouji Diannao synchronizes an Obsidian vault between mobile devices and computers, with devices linked by a dynamic code so syncing starts immediately. The recorded Chinese About text names Windows, macOS, Android, iOS, HarmonyOS and tablets as targets, end-to-end encryption whose private key stays on the local device, on-demand loading so the whole vault need not be downloaded, and a recycle bin with earlier versions. It also states a price of 48 yuan a year for 5G of space.
