# Fluent Tasks

Manages tasks in a drag-and-drop sidebar styled after Fluent Design, with light and dark themes, glassmorphism, colour palettes and animations. Lists are organized into hierarchical groups, and items carry subtasks, stars and notes. Everything is stored locally in the vault as standard Markdown checklists.
