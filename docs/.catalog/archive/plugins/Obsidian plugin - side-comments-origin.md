# Side Comments origin

Side Comments origin annotates any text in a note with standalone Markdown comments that may contain images, links and rendered formatting. A dedicated sidebar manages every comment with hover previews, jump-to-source, orphan detection and sorting, and comments can be exported or backed up to Markdown.

    id:     "side-comments-origin"
    name:   "Side Comments origin"
    author: "jepicaju862-lab"

    html_url:    "https://community.obsidian.md/plugins/side-comments-origin"
