# Colorful Note Background

Colorful Note Background applies a subtle colored background to a note based on its folder location or its frontmatter metadata, so note types are distinguishable without distraction. Rules match a folder name anywhere in the path or a frontmatter key and value, and are evaluated in order so the first match wins.
